Paso 2: Agregar

Música

Presiona 5 para cambiar a la vista del explorador de archivos para que podamos agregar algo de música. Deberías ver algo

así: 
+---------------------------------------------------------------------+
| Explorador - /home/jasonwoof                                         |

| config/                                                               |

|                                                                       |

Ahora, usa las teclas de flecha, Enter y Retroceso para navegar hasta donde tienes almacenados tus archivos de audio. Para agregar música a tu biblioteca de cmus, usa las teclas de flecha para resaltar un archivo o carpeta, y presiona a. Cuando presiones a cmus te moverá a la siguiente línea hacia abajo (para que sea fácil agregar un montón de archivos/carpetas seguidos) y comenzará a agregar el archivo/carpeta sobre el que presionaste a a tu biblioteca. Esto puede tardar un rato si agregaste una carpeta con muchos archivos. A medida que se agregan los archivos, verás que el tiempo en la esquina inferior derecha aumenta. Esta es la duración total de toda la música en la biblioteca de

cmus.

Nota: cmus no mueve, duplica ni cambia tus archivos. Solo recuerda dónde están y almacena en caché los metadatos (duración, artista, etc.

)

Solo por si acaso, vamos a guardar. Escribe :save y presiona

Enter.

Nota: Cmus guarda automáticamente tus ajustes y bi

blioteca y todo lo demás cuando sales, así que
probablemente no usarás mucho el comando save.

Paso 3: Reproducir Pistas desde la

Biblioteca

Presiona 2 para ir a la vista simple de la biblioteca. Deberías ver algo

así: 
+---------------------------------------------------------------------+
| Biblioteca - 31 pistas (1:35:11) ordenadas por albumartist date album dis… |
| Flying Lizards         . Money (That's What I Want)           02:31 |
| Jason Woofenden        . VoR Theme                       2009 01:20 |
| Keali'i Reichel      06. Wanting Memories                1994 04:28 |
| Molly Lewis            . Tom Cruise Crazy                     03:13 |
| NonMemory              . pista1                          2009 03:18 |
| NonMemory            01. pista1                    2009-04-21 04:13 |
| Ray Charles          06. Halleluja I Love Her So              02:33 |
|                                                                       |
| . 00:00                           artista de la biblioteca | 100% | C    |
|                                                                       |
+---------------------------------------------------------------------
+

Usa las teclas de flecha arriba y abajo para seleccionar una pista que te gustaría escuchar, y presiona Enter para reproducirla. Aquí tienes algunas teclas para controlar la

reproducción:

Presiona c para pausar/reanudar. Presiona derecha/izquierda para buscar 10 segundos. Presiona ,/. para buscar hacia atrás/adelante un minuto. Presiona z para reproducir la pista anterior y b para reproducir la siguiente

pista.

cmus tiene algunas opciones geniales para controlar qué se reproduce a continuación (si es que algo se reproduce) cuando termina la pista. El estado de estos ajustes se muestra en la esquina inferior derecha. El primero de ellos muestra qué colección de pistas estamos reproduciendo (mostrado aquí como "artista de la biblioteca"). Presiona m para ciclar entre las diferentes opciones para este ajuste. A la derecha de eso (después del volumen) cmus muestra el estado de cuatro conmutadores. Solo se muestran los conmutadores que están "activados", así que ahora solo vemos el C. Aquí están los

conmutadores:

[C]

ontinuar


Si esto está desactivado, cmus siempre se detendrá al final de la pista. Puedes alternar este ajuste presionando shift-C

.

[F]ollow

(Seguir)


Si esto está activado, cmus seleccionará la pista que se está reproduciendo actualmente al cambiar de pista. Presiona f para alternar esta

opción.

[R]epeat

(Repetir)


Si esto está activado (y continuar está activado), cuando cmus llegue al final del grupo de pistas que estás reproduciendo (seleccionado con la tecla m) comenzará de nuevo desde el principio. Presiona r para alternar este

ajuste.

[S]huffle (Aleatorio) o [&]lbum shuffle (Aleatorio de

álbum)


Si esto es 'S', cmus elegirá un orden aleatorio para reproducir todas las pistas una vez, mientras que '&' hará lo mismo con álbumes completos. Presiona s para alterna

r esta
opción.

Paso 4: Gestionar la

Cola

Digamos que estás escuchando una canción, y quieres seleccionar qué canción se reproducirá a continuación, sin interrumpir la canción que se está reproduciendo. ¡No hay problema! Simplemente ve a la canción que quieres escuchar a continuación (en cualquiera de las vistas) y presiona e. La cola es FIFO, lo que significa que si encolas otra pista, se reproducirá después de la que ya tenías

encolada.

Nota: La cola no se ve afectada por la opción "aleatorio" descrita

anteriormente.

Presiona 4 para ver/editar la cola. Esta vista funciona y se parece mucho a la vista simple de la biblioteca. La principal diferencia es que puedes cambiar el orden de las pistas con las teclas p y P. Puedes presionar shift-D para eliminar una pista de la

cola.

Cuando cmus esté listo para reproducir otra pista (ha llegado al

final de una pista y el ajuste "continuar" está activado) elimi
nará la primera entrada de la cola y comenzará a reproducirla.

Paso 5: Las Listas de

Reproducción

Las listas de reproducción funcionan como otro conjunto de bibliotecas (como la vista 2) excepto que (como la cola) tú estableces manualmente el orden de las pistas. Esto puede ser bastante útil si quieres crear una mezcla de pistas específicas o si quieres escuchar un audiolibro sin que los capítulos se reproduzcan cuando estás reproduciendo desde la

biblioteca.

Las listas de reproducción están en la vista 3. Pero antes de ir allí, vamos a agregar algunas pistas. Presiona 2 para ir a la vista simple de la biblioteca, ve a una pista que quieras y presiona y para agregarla a una lista de reproducción. La única respuesta visual que obtendrás de que algo ocurrió es que el resaltado se moverá una fila hacia abajo. Agrega algunas más para que tengas algo con lo que

trabajar.

Ahora presiona 3 para ir a la lista de reproducción. Deberías ver algo

así: 
+---------------------------------------------------------------------+
| Lista de reproducción       Predeterminada                     11:32 |
| * Predeterminada        | Flying Lizards     . Money (Th...  02:31 |
|                          | Jason Woofenden    . VoR T... 2009 01:20 |
|                          | Keali'i Reichel  06. Wanti... 1994 04:28 |
|                          | Molly Lewis        . Tom Cruis...  03:13 |
|                          |                                          |
|                          |                                          |
|                          |                                          |
|                                                                     |
| . 00:00                                       biblioteca | 100% | C    |
|                                                                     |
+---------------------------------------------------------------------
+

Igual que con la cola, puedes usar las p, P y D teclas para mover y eliminar pistas de la lista de

reproducción.

Nota: Cambiar la vista (por ejemplo, presionando 3) no afecta lo que cmus reproducirá a continuación. Para poner cmus en el modo "reproducir desde la lista de reproducción", presiona Intro sobre una de las pistas en la lista de reproducción. Para cambiar de modo sin interrumpir la canción que se está reproduciendo, puedes presionar shif

t-
M.

Paso 6: Encuentra esa

pista

Este paso muestra varias formas en que puedes encontrar las pistas que estás

buscando.

Búsqueda: Presiona 2 para asegurarte de que estás en la vista simple de la biblioteca, luego presiona / para iniciar una búsqueda. Escribe una o dos palabras de la pista que estás buscando. cmus buscará pistas que contengan todas esas palabras. Presiona Intro para sacar el teclado del comando de búsqueda, y n para encontrar la siguiente

coincidencia.

Vista de árbol: Presiona 1 para seleccionar la vista de árbol. Desplázate hasta el artista, presiona espacio para mostrar sus álbumes, desplázate hasta el álbum que deseas, luego presiona tab para que el teclado controle la columna derecha. Presiona tab de nuevo para volver a la columna

izquierda.

Filtros: Consulta el manual de referencia (consulta Más abajo en

Lecturas adicionales) para una descripción detallada de cómo oc
ultar rápidamente (y temporalmente) la mayor parte de tu música.

Paso 7:

Personalización

Cmus tiene algunas configuraciones muy interesantes que puedes ajustar, como cambiar la forma en que se muestran las pistas (por ejemplo, para mostrar los números de disco), habilitar el soporte de replaygain o cambiar las asignaciones de

teclas.

Presiona 7 para obtener una vista general rápida de las asignaciones de teclas y configuraciones

actuales.

Para cambiar una configuración o una asignación de tecla, simplemente selecciónala (teclas arriba/abajo) y presiona Intro. Esto colocará el comando de la configuración actual en la línea de comandos (parte inferior izquierda de tu pantalla), que puedes editar para introducir un nuevo

valor/tecla.

Consulta el manual de referencia (consulta Más abajo e

n Lecturas adicionales) para una descripción detallad
a de todos los comandos y configuraciones disponibles.

Salir

Cuando termines, escribe :q y presiona Intro para salir. Esto guardará tus co

ista de reproducción y cola.
