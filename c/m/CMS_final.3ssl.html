CMS_final(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_FINAL(3ssl) OpenSSL CMS_FINAL(3ssl)

NOMBRE

CMS_final, CMS_final_digest - finalizar una estructura CMS_ContentInfo

SINOPSIS

#include <openssl/cms.h>
int CMS_final(CMS_ContentInfo *cms, BIO *data, BIO *dcont, unsigned int flags);
int CMS_final_digest(CMS_ContentInfo *cms, const unsigned char *md,
                     unsigned int mdlen, BIO *dcont, unsigned int flags);

DESCRIPCIÓN

CMS_final() finaliza la estructura cms. Su propósito es realizar cualquier operación necesaria en cms (cálculo de digest, por ejemplo) y establecer los campos apropiados. El parámetro data contiene los datos a procesar. El parámetro dcont contiene un BIO para escribir contenido después del procesamiento: esto solo se usa con datos separados y generalmente se establecerá en NULL.

CMS_final_digest() finaliza la estructura cms usando un digest precalculado, en lugar de calcular el digest a partir de los datos originales.

NOTAS

Estas funciones normalmente se llamarán cuando se utilice la marca CMS_PARTIAL. Solo debe usarse cuando no se realiza streaming porque las funciones de E/S de streaming realizan operaciones de finalización internamente.

Para firmar un digest precalculado, se llama a CMS_sign(3) o CMS_sign_ex() con el parámetro data establecido en NULL antes de finalizar la estructura CMS con el digest proporcionado a CMS_final_digest() en formato binario. Al firmar un digest precalculado, la seguridad depende de que el digest y su cálculo a partir del mensaje original sean de confianza.

VALORES DE RETORNO

CMS_final() y CMS_final_digest() devuelven 1 para éxito o 0 para fallo.

VER TAMBIÉN

ERR_get_error(3), CMS_sign(3), CMS_encrypt(3)

HISTORIA

CMS_final_digest() se añadió en OpenSSL 3.2.
