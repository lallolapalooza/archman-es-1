NOMBRE

cmark - convierte texto con formato CommonMark a HTML

SINOPSIS

cmark [opciones] archivo*

DESCRIPCIÓN

cmark convierte texto plano con formato Markdown a HTML, groff man, XML de CommonMark, LaTeX o CommonMark, utilizando las convenciones descritas en la especificación de CommonMark. Lee la entrada de stdin o de los archivos especificados (concatenando sus contenidos) y escribe la salida en stdout.

OPCIONES

--a, -a FORMATO
Especifica el formato de salida (html, man, xml, latex, commonmark).
--ancho ANCHO
Especifica un ancho de columna al que se ajustará la salida. Para que no haya saltos de línea, usa el valor 0 (por defecto). Esta opción solo afecta actualmente a los renderizadores commonmark, latex y man.
--saltos-duros
Renderiza los saltos suaves (saltos de línea dentro de párrafos en el código fuente de CommonMark) como saltos de línea duros en el formato destino. Si se especifica esta opción, el ajuste de línea duro se deshabilita para la salida de CommonMark, independientemente del valor dado con --ancho.
--sin-saltos
Renderiza los saltos suaves como espacios. Si se especifica esta opción, el ajuste de línea duro se deshabilita para todos los formatos de salida, independientemente del valor dado con --ancho.
--posicion-fuente
Incluye el atributo de posición de origen.
--validar-utf8
Valida UTF-8, reemplazando las secuencias ilegales con U+FFFD.
--inteligente
Usa puntuación inteligente. Las comillas dobles y simples rectas se renderizarán como comillas rizadas, dependiendo de su posición. -- se renderizará como un guion en. --- se renderizará como un guion largo. ... se renderizará como elipsis.
--seguro
Omite HTML sin procesar y URLs potencialmente peligrosas (por defecto). El HTML sin procesar se reemplaza por un comentario marcador de posición y las URLs potencialmente peligrosas se reemplazan por cadenas vacías. Las URLs potencialmente peligrosas son aquellas que comienzan con `javascript:`, `vbscript:`, `file:`, o `data:` (excepto para los tipos MIME `image/png`, `image/gif`, `image/jpeg`, o `image/webp`).
--inseguro
Renderiza HTML sin procesar o URLs potencialmente peligrosas, anulando el comportamiento por defecto (--seguro).
--ayuda
Imprime información de uso.
--version
Imprime la versión.
