NOMBRE

cmis-client - herramienta cliente CMIS de línea de comandos.

SINOPSIS


cmis-client
help

cmis-client
[-v] --url url://to/binding list-repos

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id repo-infos

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id show-root

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id get-content id

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id --input-file path/to/file --input-type mime/type [--input-name name.ext] set-content id

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id [--object-type some:cmistype] [--object-property prop-id=prop-value]... create-folder parent-id name

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id --input-file path/to/file --input-type mime/type [--input-name name.ext] [--object-type some:cmistype] [--object-property prop-id=prop-value]... create-document parent-id name

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id [--object-property prop-id=prop-value]... update-object object-id

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id type-by-id | show-by-id | show-by-path | delete arg ...

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id checkout | cancel-checkout | get-versions arg

cmis-client
[-v] [-u login] [-p secret] --url url://to/binding -r repo-id [--input-file path/to/file] [--input-type mime/type] [--input-name name.ext] [--object-property prop-id=prop-value]... [--major] [--message] checkin pwc id

DESCRIPCIÓN

La herramienta cmis-client envía consultas a través de la red a un servidor compatible con CMIS para acceder a su contenido o modificarlo. Originalmente, demuestra las capacidades de libcmis.

OPCIONES

OPCIONES GLOBALES

-v, --verbose
Muestra mucha información para monitorizar lo que está sucediendo detrás de escena. Esto ayuda mucho a depurar libcmis.
--help
Muestra la ayuda y sale. Esto es equivalente a usar el comando help.
--url url://to/binding
url://to/binding debe apuntar al documento de servicio del enlace AtomPub o WebService.
-r,--repository repo-id
Opera en el repositorio CMIS repo-id . Si solo hay un repositorio en el servidor, este parámetro no es necesario y ese repositorio se seleccionará automáticamente. Usa este parámetro si hay varios repositorios en el servidor.
-u,--username login
Conecta como login al servidor CMIS. Si no se proporciona, se conecta de forma anónima.
-p,--password secret
Usa secret para autenticarse en el servidor CMIS.
--no-ssl-check
Desactiva las verificaciones de certificados SSL. Reduce la seguridad, pero puede ser útil para sortear certificados malos, como los caducados o los autofirmados.
--proxy url
Usa url como proxy HTTP. Establecer este valor anula la configuración del proxy del sistema.
--proxy-username login
Usa login para autenticarse en el proxy HTTP.
--proxy-password secret
Usa secret para autenticarse en el proxy HTTP.
--noproxy list
La configuración del proxy no se aplicará a los nombres de host y de dominio listados en list. Este valor es una lista separada por comas.
--oauth2-client-id client_id
ID de cliente de la aplicación a usar en el flujo de autenticación OAuth2.
--oauth2-client-secret client_secret
Secreto de cliente de la aplicación a usar en el flujo de autenticación OAuth2.
--oauth2-auth-url url
URL para autenticar al usuario en el flujo de autenticación OAuth2.
--oauth2-token-url url
URL para autenticar a la aplicación en el flujo de autenticación OAuth2. Los tokens de acceso y de actualización son proporcionados por esta URL.
--oauth2-redirect-uri uri
URI a la que el flujo de autenticación OAuth2 redirigirá después de una autenticación exitosa.
--oauth2-scope scope
Alcance solicitado para acceder en el flujo de autenticación OAuth2.

OPCIONES DE OPERACIONES DE MODIFICACIÓN

--input-file path/to/file
Sube path/to/file como el nuevo flujo de contenido del objeto.
--input-type mime/type
Establece el tipo mime del nuevo flujo de contenido del objeto a mime/type.
--input-name name.ext
Establece el nombre de archivo del flujo de contenido remoto del nuevo flujo de contenido del objeto a name.ext.
--object-type some:cmistype
Establece el tipo de objeto del objeto CMIS a crear a some:cmistype. Esto es equivalente a --object-property cmis:objectTypeId=some:cmistype.
--object-property prop-id=prop-value
Establece una propiedad a actualizar o añadir al objeto CMIS. prop-id es el id de la definición de la propiedad y prop-value es el valor a establecer en ella.
--major
Crea una versión mayor al realizar un checkin.
-m, --message message
Establece el mensaje de checkin.

COMANDOS

help
Muestra la ayuda y sale.
list-repos
Lista los repositorios disponibles en el servidor.
repo-infos
Muestra la información y las capacidades del repositorio seleccionado.
show-root
Muestra la información y los hijos del nodo raíz.
get-content id
Descarga el contenido del objeto CMIS correspondiente a id en el directorio actual.
set-content id
Sube un archivo como el flujo de contenido del objeto CMIS correspondiente a id.
create-folder parent-id name
Crea una subcarlder in folder parent-id named name. El tipo por defecto de la carpeta a crear es cmis:folder, pero esto puede cambiarse usando la opción --object-type.
create-document parent-id name
Crear un documento en la carpeta parent-id named name. El tipo por defecto del documento a crear es cmis:document, pero esto puede cambiarse usando la opción --object-type.

Tenga en cuenta que --input-file y --input-type pueden ser obligatorios, dependiendo del tipo de documento a crear y sus restricciones.

update-object object-id
Reemplaza las propiedades escribibles dadas con la opción --object-property en el objeto que coincide con el id object-id.
type-by-id arg...
Muestra la información y los hijos (si los hay) de todos los tipos CMIS correspondientes a los ids listados.
show-by-id arg...
Muestra la información y los hijos (si los hay) de todos los objetos CMIS correspondientes a los ids listados.
show-by-path arg...
Muestra la información y los hijos (si los hay) de todos los objetos CMIS correspondientes a las rutas listadas.
delete arg...
Elimina los objetos CMIS correspondientes a los ids listados. Si el nodo es una carpeta, su contenido también será eliminado.
checkout arg
Realiza el checkout del documento correspondiente al id proporcionado y muestra la información de la copia privada de trabajo creada.
cancel-checkout arg
Cancela la copia privada de trabajo correspondiente al id del nodo.
get-versions arg
Muestra las versiones (si las hay) de todos los objetos CMIS correspondientes al id proporcionado.
checkin arg
Realiza el checkin de la copia privada de trabajo correspondiente al id proporcionado y muestra la información del documento resultante. Use las opciones --major y --message para definir la versión a crear y el commit a asociarle. Tenga en cuenta que los repositorios sin la capacidad de actualizar las copias privadas de trabajo necesitarán las opciones --input-file, --input-type y --object-property.

USO

Muestra el nodo raíz del repositorio A1:

cmis-client -r A1 --url http://localhost/atom show-root

Muestra los nodos con id 133 y 116 del repositorio A1:

cmis-client -r A1 --url http://localhost/atom show-by id 133 116
