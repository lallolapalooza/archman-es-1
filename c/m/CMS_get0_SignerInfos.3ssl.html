CMS_get0_SignerInfos(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_GET0_SIGNERINFOS(3ssl) OpenSSL CMS_GET0_SIGNERINFOS(3ssl)

NOMBRE

CMS_SignerInfo_set1_signer_cert, CMS_get0_SignerInfos, CMS_SignerInfo_get0_signer_id, CMS_SignerInfo_get0_signature, CMS_SignerInfo_cert_cmp - Funciones de firmante de datos firmados CMS

SINOPSIS

#include <openssl/cms.h>
STACK_OF(CMS_SignerInfo) *CMS_get0_SignerInfos(CMS_ContentInfo *cms);
int CMS_SignerInfo_get0_signer_id(CMS_SignerInfo *si, ASN1_OCTET_STRING **keyid,
                                  X509_NAME **issuer, ASN1_INTEGER **sno);
ASN1_OCTET_STRING *CMS_SignerInfo_get0_signature(CMS_SignerInfo *si);
int CMS_SignerInfo_cert_cmp(CMS_SignerInfo *si, X509 *cert);
void CMS_SignerInfo_set1_signer_cert(CMS_SignerInfo *si, X509 *signer);

DESCRIPCIÓN

La función CMS_get0_SignerInfos() devuelve todas las estructuras CMS_SignerInfo asociadas con una estructura de datos firmados CMS.

CMS_SignerInfo_get0_signer_id() recupera el identificador del firmante del certificado asociado con una estructura CMS_SignerInfo específica si. Se establecerá el identificador de clave en keyid o el nombre del emisor y el número de serie en issuer y sno.

CMS_SignerInfo_get0_signature() recupera la firma asociada con si en un puntero a una estructura ASN1_OCTET_STRING. Este puntero devuelto corresponde al valor de firma interno si si, por lo que puede leerse o modificarse.

CMS_SignerInfo_cert_cmp() compara el certificado cert con el identificador del firmante si. Devuelve cero si la comparación es exitosa y un valor distinto de cero si no.

CMS_SignerInfo_set1_signer_cert() establece el certificado del firmante de si a signer.

NOTAS

El propósito principal de estas funciones es permitir que una aplicación busque certificados de firmantes utilizando cualquier técnica apropiada cuando el método más simple de CMS_verify() no es adecuado.

En un uso típico, una aplicación recuperará todas las estructuras CMS_SignerInfo usando CMS_get0_SignerInfo() y recuperará la información del identificador usando CMS. Luego obtendrá el certificado del firmante por algún medio no especificado (o devolverá un error si no se puede encontrar) y lo establecerá usando CMS_SignerInfo_set1_signer_cert().

Una vez que todos los certificados de firmantes hayan sido establecidos, se puede usar CMS_verify().

Aunque CMS_get0_SignerInfos() puede devolver NULL si ocurre un error o si no hay firmantes, esto no es un problema en la práctica porque el único error que puede ocurrir es si la estructura cms no es del tipo signedData debido a un error de la aplicación.

VALORES DE RETORNO

CMS_get0_SignerInfos() devuelve todas las estructuras CMS_SignerInfo, o NULL si no hay firmantes o ocurre un error.

CMS_SignerInfo_get0_signer_id() devuelve 1 para éxito y 0 para fallo.

CMS_SignerInfo_cert_cmp() devuelve 0 para una comparación exitosa y un valor distinto de cero en caso contrario.

CMS_SignerInfo_set1_signer_cert() no devuelve ningún valor.

Cualquier error puede obtenerse de ERR_get_error(3)

VER TAMBIÉN

ERR_get_error(3), CMS_verify(3)
