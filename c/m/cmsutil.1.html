DESCRIPCIÓ

N

El comando cmsutil utiliza el S/MIME Toolkit para realizar operaciones básicas, como cifrado y descifrado, en mensajes de Sintaxis de Mensaje Criptográfico (CMS)

.

Para ejecutar cmsutil, escriba el comando cmsutil opción [argumentos] donde opción y argumentos son combin

aciones de las opciones y argumentos listados en la siguiente sección. Cada comando toma una opción. Cada
opción puede tomar cero o más argumentos. Para ver una cadena de uso, ejecute el comando sin opciones.

OPCIONES Y

ARGUMENTOS

Opcione

s

Las opciones especifican una acción. Los argumentos de opción modifican una acción. Las opciones y argumentos para el comando cmsutil se definen como

sigue:

-

C
Cifrar un
mensaje.

-

D
Decodificar un
mensaje.

-

E
Sobreenvolver un
mensaje.

-

O
Crear un mensaje solo de
certificados.

-

S
Firmar un
mensaje.

Argumento

s

Los argumentos de opción modifican una

acción.

-

b
Decodificar un lote de archivos nombrados en
infile.

-c

content
Usar este contenido desprendido (solo decodificación)
.

-d

dbdir
Especificar el directorio de la base de datos de claves/certificados (el valor predeterminado es ".
")

-e

envfile
Especificar un archivo que contiene un mensaje sobreenvuelto para un conjunto de destinatarios al que le gustaría enviar un mensaje cifrado. Si este es el primer mensaje cifrado para ese conjunto de destinatarios, se creará un nuevo mensaje sobreenvuelto que luego podrá usar para futuros mensajes (solo cifrado)
.

-f

pwfile
Usar el archivo de contraseña para establecer la contraseña en todos los tokens
PKCS#11.

-

G
Incluir un atributo de hora de firma (solo firma)
.

-H

hash
Usar el algoritmo de hash especificado (predeterminado:SHA1)
.

-h

num
Generar encabezados de correo electrónico con información sobre el mensaje CMS (solo decodificación)
.

-i

infile
Usar infile como fuente de datos (el valor predeterminado es stdin)
.

-

k
Mantener los certificados de cifrado decodificados en la base de datos de certificados
permanente.

-N

nickname
Especificar el apodo del certificado con el que firmar (solo firma)
.

-

n
Suprimir la salida del contenido (solo decodificación)
.

-o

outfile
Usar outfile como destino de datos (el valor predeterminado es stdout)
.

-

P
Incluir un atributo de capacidades
S/MIME.

-p

password
Usar password como contraseña de la base de datos de
claves.

-r recipient1,recipient2, ..

.
Especificar la lista de destinatarios (direcciones de correo electrónico) para un mensaje cifrado o sobreenvuelto. Para un mensaje solo de certificados, la lista de certificados a
enviar.

-

T
Suprimir el contenido en el mensaje CMS (solo firma)
.

-u

certusage
Establecer el tipo de uso del certificado (el valor predeterminado es certUsageEmailSigner)
.

-

v
Imprimir información de
depuración.

-Y

ekprefnick
Especificar una pre
ferencia de clave de
cifrado por apodo.

O

cmsutil -C [-i infile] [-o outfile]
