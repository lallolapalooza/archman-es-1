CMS_EncryptedData_encrypt(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_ENCRYPTEDDATA_ENCRYPT(3ssl) OpenSSL CMS_ENCRYPTEDDATA_ENCRYPT(3ssl)

NOMBRE

CMS_EncryptedData_encrypt_ex, CMS_EncryptedData_encrypt - Crear CMS EncryptedData

SINOPSIS

#include <openssl/cms.h>
CMS_ContentInfo *CMS_EncryptedData_encrypt_ex(BIO *in,
                                              const EVP_CIPHER *cipher,
                                              const unsigned char *key,
                                              size_t keylen,
                                              unsigned int flags,
                                              OSSL_LIB_CTX *ctx,
                                              const char *propq);
CMS_ContentInfo *CMS_EncryptedData_encrypt(BIO *in,
    const EVP_CIPHER *cipher, const unsigned char *key, size_t keylen,
    unsigned int flags);

DESCRIPCIÓN

CMS_EncryptedData_encrypt_ex() crea una estructura CMS_ContentInfo con un tipo NID_pkcs7_encrypted. in es un BIO que contiene los datos a cifrar usando cipher y la clave de cifrado key de tamaño keylen bytes. El contexto de librería libctx y la consulta de propiedades propq se utilizan al recuperar algoritmos de los proveedores. flags es un conjunto de indicadores opcionales.

El campo flags soporta las opciones CMS_DETACHED, CMS_STREAM y CMS_PARTIAL. Internamente se llama a CMS_final() a menos que se especifique CMS_STREAM y/o CMS_PARTIAL.

El algoritmo pasado en el parámetro cipher debe soportar la codificación ASN1 de sus parámetros.

La estructura CMS_ContentInfo puede ser liberada usando CMS_ContentInfo_free(3).

CMS_EncryptedData_encrypt() es similar a CMS_EncryptedData_encrypt_ex() pero utiliza los valores predeterminados de NULL para el contexto de librería libctx y la consulta de propiedades propq.

VALORES DE RETORNO

Si la asignación falla, CMS_EncryptedData_encrypt_ex() y CMS_EncryptedData_encrypt() devuelven NULL y establecen un código de error que puede ser obtenido por ERR_get_error(3). De lo contrario, devuelven un puntero a la estructura recién asignada.

VER TAMBIÉN

ERR_get_error(3), CMS_final(3), CMS_EncryptedData_decrypt(3)

HISTORIA

El método CMS_EncryptedData_encrypt_ex() se añadió en OpenSSL 3.0.
