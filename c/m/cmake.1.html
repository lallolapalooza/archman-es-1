DESCRIPCIÓ

N

El ejecutable cmake es la interfaz de línea de comandos del generador de sistemas de compilación multiplataforma CMake. La Sinopsis anterior enumera varias acciones que la herramienta puede realizar, como se describe en las secciones

siguientes.

Para compilar un proyecto de software con CMake, genere un sistema de compilación de proyecto. Opcionalmente, use cmake para compilar un proyecto, instalar un proyecto o simplemente ejecute la herramienta de compilación correspondiente (por ejemplo, make) directamente. cmake también se puede usar para ver la

ayuda.

Las otras acciones están destinadas a ser usadas por desarrolladores de software que escriben scripts en el lenguaje de CMake <#manual:cmake-language(7)> para soportar sus

compilaciones.

Para interfaces gráficas de usuario que puedan usarse en lugar de cmake, vea ccmake <#manual:ccmake(1)> y cmake-gui <#manual:cmake-gui(1)>. Para interfaces de línea de comandos a las instalaciones de prueba y empaquetado de CMake, vea ctest <#manual:ctest(1)> y cpack <#manual:cpack(1)>

.

en general, vea también los enla

INTRODUCCIÓN A LOS SISTEMAS DE COMPILACIÓN DE

CMAKE

Un sistema de compilación describe cómo compilar los ejecutables y bibliotecas de un proyecto a partir de su código fuente usando una herramienta de compilación para automatizar el proceso. Por ejemplo, un sistema de compilación puede ser un Makefile para usar con una herramienta de línea de comandos make o un archivo de proyecto para un Entorno de Desarrollo Integrado (IDE). Para evitar mantener múltiples sistemas de compilación como estos, un proyecto puede especificar su sistema de compilación de forma abstracta usando archivos escritos en el lenguaje de CMake <#manual:cmake-language(7)>. A partir de estos archivos, CMake genera un sistema de compilación preferido localmente para cada usuario a través de un backend llamado un generador

.

Para generar un sistema de compilación con CMake, se debe seleccionar lo

siguiente:
Árbol de
fuente
El directorio de nivel superior que contiene los archivos fuente proporcionados por el proyecto. El proyecto especifica su sistema de compilación usando archivos como se describe en el manual cmake-language(7) <#manual:cmake-language(7)>, comenzando con un archivo de nivel superior llamado CMakeLists.txt. Estos archivos especifican los objetivos de compilación y sus dependencias como se describe en el manual cmake-buildsystem(7) <#manual:cmake-buildsystem(7)
>.
Árbol de
compilación
El directorio de nivel superior en el que se almacenarán los archivos del sistema de compilación y los artefactos de salida de la compilación (por ejemplo, ejecutables y bibliotecas). CMake escribirá un archivo CMakeCache.txt para identificar el directorio como un árbol de compilación y almacenar información persistente como las opciones de configuración del sistema de compilación.

Para mantener un árbol de fuente intacto, realice una compilación fuera de la fuente usando un árbol de compilación dedicado separado. Una compilación en la fuente en la que el árbol de compilación se coloca en el mismo

directorio que el árbol de fuente t

Generad

Esto elige el tipo de sistema de compilación a generar. Vea el manual cmake-generators(7) <#manual:cmake-generators(7)> para documentación de todos los generadores. Ejecute cmake --help para ver una lista de generadores disponibles localmente. Opcionalmente, use la opción -G a continuación para especificar un generador, o simplemente acepte el que CMake elija por defecto para la plataforma actual.

Al usar uno de los Generadores de Herramienta de Compilación de Líne
