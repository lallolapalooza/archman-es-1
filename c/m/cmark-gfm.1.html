cmark-gfm(1) Manual de Comandos Generales cmark-gfm(1)

NOMBRE

cmark - convierte texto formateado con CommonMark y extensiones de GitHub Flavored Markdown a HTML

SINOPSIS

cmark-gfm [opciones] archivo*

DESCRIPCIÓN

cmark-gfm convierte texto plano formateado con Markdown a HTML, groff man, CommonMark XML, LaTeX o CommonMark, utilizando las convenciones descritas en la especificación CommonMark. Lee la entrada de stdin o de los archivos especificados (concatenando sus contenidos) y escribe la salida en stdout.

OPCIONES

--to, -t FORMATO
Especifica el formato de salida (html, man, xml, latex, commonmark).
--width ANCHO
Especifica un ancho de columna al que ajustar la salida. Para no ajustar, usa el valor 0 (el predeterminado). Esta opción actualmente solo afecta a los renderizadores commonmark, latex y man.
--hardbreaks
Renderiza saltos de línea suaves (saltos de línea dentro de párrafos en la fuente CommonMark) como saltos de línea duros en el formato de destino. Si se especifica esta opción, el ajuste de línea duro se deshabilita para la salida CommonMark, independientemente del valor dado con --width.
--nobreaks
Renderiza saltos de línea suaves como espacios. Si se especifica esta opción, el ajuste de línea duro se deshabilita para todos los formatos de salida, independientemente del valor dado con --width.
--sourcepos
Incluye el atributo de posición de origen.
--normalize
Consolida nodos de texto adyacentes.
--extension, -e NOMBRE_EXTENSIÓN
Especifica un nombre de extensión a usar.
--list-extensions
Lista las extensiones disponibles y sale.
--validate-utf8
Valida UTF-8, reemplazando secuencias ilegales con U+FFFD.
--smart
Usa puntuación inteligente. Las comillas dobles y simples rectas se renderizarán como comillas rizadas, dependiendo de su posición. -- se renderizará como un guion largo. --- se renderizará como un guion em. ... se renderizará como elipses.
--unsafe
Renderiza HTML en bruto y URLs potencialmente peligrosas. (El HTML en bruto no se reemplaza con un comentario de marcador de posición; las URLs potencialmente peligrosas no se reemplazan con cadenas vacías.) Las URLs peligrosas son aquellas que comienzan con `javascript:`, `vbscript:`, `file:`, o `data:` (excepto para los tipos MIME `image/png`, `image/gif`, `image/jpeg` o `image/webp`).
--help
Imprime información de uso.
--version
Imprime la versión.
