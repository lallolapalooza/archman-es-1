cmake-qt - Referencia de características de Qt

para CMake

INTR

ODUC
CIÓN

CMake puede encontrar y usar las bibliotecas Qt 4, Qt 5 y Qt 6. Las bibliotecas Qt 4 se encuentran

mediante el

módulo de búsqueda FindQt4 <#module:FindQt4> incluido con CMake, mientras que las bibliotecas Qt 5 y Qt 6 se encuentran usando los "Paquetes de archivos de configuración" incluidos con Qt 5 y Qt 6. Véase cmake-packages(7) <#manual:cmake-packages(7)> para más información sobre los paquetes de CMake, y consulte el manual de cmake de Qt https://doc.qt.io/qt-6/cmake-manual.html para su versión de Qt. Qt 4, Qt 5 y Qt 6 pueden usarse juntos en el

mismo

sistema de construcción de CMake <#manual:cmake-buildsystem(7)>: cmake_minimum_required(VERSION 3.16 FATAL_ERROR) project(Qt4_5_6) set(CMAKE_AUTOMOC ON) find_package(Qt6 COMPONENTS Widgets DBus REQUIRED) add_executable(publisher publisher.cpp) target_link_libraries(publisher Qt6::Widgets Qt6::DBus) find_package(Qt5 COMPONENTS Gui DBus REQUIRED) add_executable(subscriber1 subscriber1.cpp) target_link_libraries(subscriber1 Qt5::Gui Qt5::DBus) find_package(Qt4 REQUIRED) add_executable(subscriber2 subscriber2.cpp) target_link_libraries(subscriber2 Qt4::QtGui Qt4:

:QtDBus) 
Un objetivo de CMake no puede enlazar con más
de una versión de Qt. Se emite un diagnóstico
si se intenta esto o si resulta de la evalua
ción de dependencias transitivas de objetivos.

Qt se basa en algunas herramientas incluidas para la generación de código,

como

moc para la generación de código de objetos meta, uic para la disposición y el llenado de widgets, y rcc para la generación de contenido del sistema de archivos virtual. Estas herramientas pueden ser invocadas automáticamente por cmake(1) <#manual:cmake(1)> si se cumplen las condiciones adecuadas. La invocación automática de herramientas puede usarse con las versiones de Qt de la 4 a la 6. AUTOMO

PROPERTY


Propiedades relativas a la automatización de Qt.




AUTOMOC


La propiedad de destino AUTOMOC controla si cmake(1) crea reglas para ejecutar
    moc en los archivos fuente que tienen el sufijo .cpp, .cxx
    o .h y que se declaran como parte de un destino.






add_library(myLib STATIC
    myClass.cpp
    myClass.h
)






La propiedad de destino AUTOMOC puede ser preestablecida para todos los
    destinos siguientes al definir la variable CMAKE_AUTOMOC. La propiedad
    de destino AUTOMOC_OPTIONS puede ser poblada para establecer opciones
    que se pasarán a moc. La variable CMAKE_AUTOMOC_OPTIONS puede
    ser poblada para preestablecer las opciones para todos los destinos
    siguientes. La propiedad de archivo fuente AUTOMOC_OPTIONS puede ser
    establecida en un archivo fuente para establecer opciones particulares para
    ese archivo. Esto anula las opciones de la propiedad de destino
    AUTOMOC_OPTIONS.


Se pueden excluir archivos fuente del procesamiento AUTOMOC
    habilitando SKIP_AUTOMOC o el más general SKIP_AUTOGEN.






AUTOUIC


La propiedad de destino AUTOUIC controla si cmake(1) crea reglas para ejecutar
    uic en los archivos fuente que tienen el sufijo .ui.






add_library(myLib STATIC
    myWidget.cpp
    myWidget.ui
)






La propiedad de destino AUTOUIC puede ser preestablecida para todos los
    destinos siguientes al definir la variable CMAKE_AUTOUIC. La propiedad
    de destino AUTOUIC_OPTIONS puede ser poblada para establecer opciones
    que se pasarán a uic. La variable CMAKE_AUTOUIC_OPTIONS puede
    ser poblada para preestablecer las opciones para todos los destinos
    siguientes. La propiedad de archivo fuente AUTOUIC_OPTIONS puede ser
    establecida en un archivo fuente para establecer opciones particulares para
    ese archivo. Esto anula las opciones de la propiedad de destino
    AUTOUIC_OPTIONS.


Un proyecto consumidor que se enlaza con el destino exportado desde
    el upstream utiliza automáticamente las opciones apropiadas cuando se ejecuta
    uic por AUTOUIC, como resultado de enlazar con el destino
    IMPORTED:






set(CMAKE_AUTOUIC ON)
# Utiliza un archivo libwidget.ui:
add_library(LibWidget libwidget.cpp)
target_link_libraries(LibWidget
  KF5::KI18n
  Qt5::Widgets
)






Se pueden excluir archivos fuente del procesamiento AUTOUIC
    habilitando SKIP_AUTOUIC o el más general SKIP_AUTOGEN.






AUTORCC


La propiedad de destino AUTORCC controla si cmake(1) crea reglas para ejecutar
    rcc en el momento adecuado en los archivos fuente que tienen el sufijo
    .qrc.






add_executable(myexe main.cpp resource_file.qrc)






La propiedad de destino AUTORCC puede ser preestablecida para todos los
    destinos siguientes al definir la variable CMAKE_AUTORCC. La propiedad
    de destino AUTORCC_OPTIONS puede ser poblada para establecer opciones
    que se pasarán a rcc. La variable CMAKE_AUTORCC_OPTIONS puede
    ser poblada para preestablecer las opciones para todos los destinos
    siguientes. La propiedad de archivo fuente AUTORCC_OPTIONS puede ser
    establecida en el archivo <name>.qrc para establecer opciones
    particulares para el archivo. Esto anula las opciones de la propiedad de
    destino AUTORCC_OPTIONS.


Se pueden excluir archivos fuente del procesamiento AUTORCC
    habilitando SKIP_AUTORCC o el más general SKIP_AUTOGEN.








EL DESTINO  <ORIGIN>_AUTOGEN


Las herramientas moc y uic se ejecutan como parte de un
    destino personalizado <ORIGIN>_autogen sintetizado por CMake. Por defecto,
    ese destino <ORIGIN>_autogen hereda las dependencias del destino
    <ORIGIN> (ver AUTOGEN_ORIGIN_DEPENDS). Se pueden añadir
    dependencias de destino al destino <ORIGIN>_autogen añadiéndolas a
    la propiedad de destino AUTOGEN_TARGET_DEPENDS.


Nota:




Si se utiliza Qt 5.15 o posterior y el generador es
  Ninja o los Generadores de Makefiles, ver El destino
  <ORIGIN>_autogen_timestamp_deps.








EL DESTINO  <ORIGIN>_AUTOGEN_TIMESTAMP_DEPS


Si se utiliza Qt 5.15 o posterior y el generador es Ninja o los
    Generadores de Makefiles, el destino
    <ORIGIN>_autogen_timestamp_deps también se crea además del destino
    <ORIGIN>_autogen. Este destino no tiene fuentes ni comandos que ejecutar,
    pero tiene dependencias que fueron previamente heredadas por el destino
    <ORIGIN>_autogen pre-Qt 5.15. Estas dependencias servirán como una lista
    de dependencias de solo orden para el comando personalizado, sin forzar la
    re-ejecución del comando personalizado.






GENERADORES DE VISUAL STUDIO


Al utilizar los Generadores de Visual Studio, CMake genera un
    comando personalizado PRE_BUILD en lugar del destino
    personalizado <ORIGIN>_autogen (para AUTOMOC y AUTOUIC).
    Esto no siempre es posible y se utiliza un destino personalizado
    <ORIGIN>_autogen, cuando:




    
  
  • el destino <ORIGIN> depende de archivos GENERATED que no
      están excluidos de AUTOMOC y AUTOUIC por SKIP_AUTOMOC,
      SKIP_AUTOUIC, SKIP_AUTOGEN o CMP0071
    • 
  
  • AUTOGEN_TARGET_DEPENDS lista un archivo fuente
    • 
  
  • CMAKE_GLOBAL_AUTOGEN_TARGET está habilitado
    • 









QTMAIN.LIB EN WINDOWS


Los destinos IMPORTED de Qt 4 y 5 para las bibliotecas QtGui
    especifican que la biblioteca estática qtmain.lib que se distribuye con Qt se
    enlazará con todos los ejecutables dependientes que tengan habilitado
    WIN32_EXECUTABLE.


Para deshabilitar este comportamiento, habilite la propiedad de
    destino Qt5_NO_LINK_QTMAIN para destinos basados en Qt 5 o la
    propiedad de destino QT4_NO_LINK_QTMAIN para destinos basados en Qt
    4.






add_executable(myexe WIN32 main.cpp)
target_link_libraries(myexe Qt4::QtGui)
add_executable(myexe_no_qtmain WIN32 main_no_qtmain.cpp)
set_property(TARGET main_no_qtmain PROPERTY QT4_NO_LINK_QTMAIN ON)
target_link_libraries(main_no_qtmain Qt4::QtGui)
