programa cblat3

CBLAT3

Propósito:

!>
!> Programa de prueba para el Blas de Nivel 3 COMPLEJO.
!>
!> El programa debe ser impulsado por un archivo de datos corto. Los primeros 14 registros
!> del archivo se leen utilizando entrada dirigida por lista, los últimos 10 registros
!> se leen utilizando el formato ( A6, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las
!> siguientes 23 líneas:
!> 'cblat3.out'      NOMBRE DEL ARCHIVO DE SALIDA RESUMEN
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO RESUMEN
!> 'CBLAT3.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO SE USA SI ES .LT. 0)
!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN CASO DE FALLOS.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR DE UMBRAL DE LA RAZÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 3                 NÚMERO DE VALORES DE ALPHA
!> (0.0,0.0) (1.0,0.0) (0.7,-0.9)       VALORES DE ALPHA
!> 3                 NÚMERO DE VALORES DE BETA
!> (0.0,0.0) (1.0,0.0) (1.3,-1.1)       VALORES DE BETA
!> CGEMM  T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CHEMM  T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CSYMM  T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CTRMM  T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CTRSM  T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CHERK  T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CSYRK  T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CHER2K T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CSYR2K T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> CGEMMTR T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
