CMAC_CTX(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMAC_CTX(3ssl) OpenSSL CMAC_CTX(3ssl)

NOMBRE

CMAC_CTX, CMAC_CTX_new, CMAC_CTX_cleanup, CMAC_CTX_free, CMAC_CTX_get0_cipher_ctx, CMAC_CTX_copy, CMAC_Init, CMAC_Update, CMAC_Final, CMAC_resume - crear códigos de autenticación de mensajes basados en cifrado

SINOPSIS

#include <openssl/cmac.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0 y pueden ser deshabilitadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7).

typedef struct CMAC_CTX_st CMAC_CTX;
CMAC_CTX *CMAC_CTX_new(void);
void CMAC_CTX_cleanup(CMAC_CTX *ctx);
void CMAC_CTX_free(CMAC_CTX *ctx);
EVP_CIPHER_CTX *CMAC_CTX_get0_cipher_ctx(CMAC_CTX *ctx);
int CMAC_CTX_copy(CMAC_CTX *out, const CMAC_CTX *in);
int CMAC_Init(CMAC_CTX *ctx, const void *key, size_t keylen,
              const EVP_CIPHER *cipher, ENGINE *impl);
int CMAC_Update(CMAC_CTX *ctx, const void *data, size_t dlen);
int CMAC_Final(CMAC_CTX *ctx, unsigned char *out, size_t *poutlen);
int CMAC_resume(CMAC_CTX *ctx);

DESCRIPCIÓN

Las funciones MAC de bajo nivel documentadas en esta página están obsoletas. Las aplicaciones deben usar la nueva interfaz EVP_MAC(3). Específicamente, utilice las siguientes funciones para operaciones MAC:

EVP_MAC_CTX_new(3) para crear un nuevo contexto MAC.
EVP_MAC_CTX_free(3) para liberar el contexto MAC.
EVP_MAC_init(3) para inicializar el contexto MAC.
EVP_MAC_update(3) para actualizar el MAC con datos.
EVP_MAC_final(3) para finalizar el MAC y obtener la salida.

Alternativamente, para un cálculo MAC de un solo paso, use la función EVP_Q_mac(3).

El tipo CMAC_CTX es una estructura utilizada para la provisión de operaciones CMAC (Cipher-based Message Authentication Code).

CMAC_CTX_new() crea una nueva estructura CMAC_CTX y devuelve un puntero a ella.

CMAC_CTX_cleanup() restablece la estructura CMAC_CTX, limpiando cualquier dato interno pero sin liberar la estructura en sí.

CMAC_CTX_free() libera la estructura CMAC_CTX y cualquier recurso asociado. Si el argumento es NULL, no se realiza ninguna acción.

CMAC_CTX_get0_cipher_ctx() devuelve un puntero a la estructura interna EVP_CIPHER_CTX dentro de CMAC_CTX.

CMAC_CTX_copy() copia el estado de una estructura CMAC_CTX a otra.

CMAC_Init() inicializa la estructura CMAC_CTX para un nuevo cálculo CMAC con la clave, longitud de clave y tipo de cifrado especificados. Opcionalmente, se puede proporcionar un ENGINE.

CMAC_Update() procesa los datos que se incluirán en el cálculo CMAC. Esta función se puede llamar varias veces para actualizar el contexto con datos adicionales.

CMAC_Final() finaliza el cálculo CMAC y recupera el valor MAC resultante. La salida se almacena en el búfer proporcionado y la longitud se almacena en la variable apuntada por poutlen. Para determinar el tamaño de búfer requerido, llame con out establecido a NULL, lo que almacena solo la longitud en poutlen. Asigne un búfer de este tamaño y llame a CMAC_Final() nuevamente con el búfer asignado para obtener el MAC.

CMAC_resume() reanuda un cálculo CMAC finalizado previamente, permitiendo procesar datos adicionales y generar un nuevo MAC.

VALORES DE RETORNO

CMAC_CTX_new() devuelve un puntero a una nueva estructura CMAC_CTX o NULL si ocurre un error.

CMAC_CTX_get0_cipher_ctx() devuelve un puntero a la estructura interna EVP_CIPHER_CTX, o NULL si ocurre un error.

CMAC_CTX_copy(), CMAC_Init(), CMAC_Update(), CMAC_Final() y CMAC_resume() devuelven 1 en caso de éxito o 0 si ocurre un error.

HISTORIA

Todas las funciones descritas aquí fueron marcadas como obsoletas en OpenSSL 3.0. Para reemplazos, ver EVP_MAC_CTX_new(3), EVP_MAC_CTX_free(3), EVP_MAC_init(3), EVP_MAC_update(3), y EVP_MAC_final(3).
