DESCRIPCIÓ

N

Los objetos de la clase CmdFinder determinan qué función (miembro) llamar dado un comando. Aunque las asociaciones entre comandos y funciones (miembro) se definen a menudo en un switch, un switch no es la forma preferida de definir estas asociaciones debido al hecho de que la mantenibilidad y claridad de los switches se ven afectadas incluso con conjuntos de comandos moderadamente grandes. Además, el switch casi nunca se sostiene por sí mismo, ya que normalmente se requiere algún procesamiento de comandos para determinar las asociaciones entre comandos y valores de case.asociaciones entre comandos y valores de

case.

El enfoque alternativo (y preferido), que también es adoptado por CmdFinder, es definir un array de punteros a funciones (miembro), y definir las asociaciones entre comandos y funciones miembro como un mapeo de comandos a índices de array. Las asociaciones simples entre comandos (textuales) y las funciones a llamar también pueden definirse fácilmente usando un std::map u otra estructura de datos de tipo hash. Sin embargo, los requisitos sintácticos para una estructura std::map no son triviales, y además: los comandos introducidos por el usuario a menudo requieren algún preprocesamiento antes de que un comando pueda usarse como índice en un std::m

ap.

La clase CmdFinder es un intento de ofrecer una implementación versátil de asociaciones entre comandos y funciones (miembro). En particular, la clase ofrece las siguientes características

:
o
Las asociaciones entre comandos textuales y funciones (miembro) se definen en un array simple de pares: el primer elemento define un comando, el segundo contiene la dirección de la función asociada con el comando. Las direcciones de función pueden ser direcciones de funciones libres o estáticas, o pueden definirse como direcciones de funciones
miembro.
o
Los comandos pueden usarse "tal cual", o la primera palabra de un std::string puede usarse como el
comando;
o
Los comandos pueden especificarse distinguiendo mayúsculas y minúsculas o sin
distinguirlas;
o
Los comandos pueden tener que especificarse por completo, o pueden aceptarse abreviaturas únicas de los
comandos;
o
La clase define varios tipos CmdFinder, simplificando aún más la derivación de clases a partir de CmdFi
nde
r.

La clase CmdFinder en sí misma se define como una clase plantilla. Esta clase plantilla debe usarse como clase base de una clase derivada definida por el usuario que defina el array de asociaciones comando-función. La clase CmdFinder en sí misma es una clase derivada de la clase CmdFinderBase, que define alguna funcionalidad independiente de la plantilla que es utilizada por CmdFinder. Las secciones de enumeración y funciones miembro a continuación también contienen los miembros disponibles para las clases derivadas de CmdFinder, pero que en realidad están definidos en la clase CmdFinderBas

ENUMERACIÓ

N

La enumeración Mode está definida en la clase CmdFinderBase. Contiene los siguientes valores, que pueden combinarse con el operador bit_or para especificar el modo de operación requerido del objeto

CmdFinder:
o
USE_FIRST:
Este valor puede especificarse cuando la primera palabra (cualquier serie de caracteres separados por espacios en blanco) de un comando textual proporcionado debe usarse como el comando a buscar. Tanto el comando que se usa como cualquier información adicional que pueda estar presente se pueden obtener del objeto CmdFinder. Por defecto, se usa el contenido completo del comando
proporcionado.
o
UNIQUE:
Este valor puede especificarse cuando puede aceptarse cualquier abreviatura única de un comando. Asumiendo que los comandos help y version están definidos, entonces la siguiente serie (no exhaustiva) es aceptada como especificación del comando help si UNIQUE está especificado: h, he, el, p. Por defecto, el comando debe coincidir exactamente con una clave de comando encontrada en el array de asociaciones
comando-función.
o
INSENSITIVE:
Cuando se especifica este valor, los comandos pueden especificarse sin considerar las mayúsculas y minúsculas. Por ejemplo, cuando INSENSITIVE está especificado, tanto Help como HELP se reconocen como help. Por defecto, se respeta el uso de mayúsculas y minúsculas. Por lo tanto, por d
efecto, se requiere una coincidencia l

EJEMPL

O 
#include <iostream>
#include <string>
#include <bobcat/cmdfinder>
using namespace std;
using namespace FBB;
// Define una clase `Command’ en la que el arreglo s_action define las
// asociaciones comando-función. Command deriva de CmdFinder,
// especificando el prototipo de las funciones miembro a llamar
class Command: public CmdFinder<bool (Command::*)() const>
{
    static Entry s_action[];
    bool add() const                       // algunas funciones miembro
    {
        cout << "add called: command was `" << cmd() << "’\n";
        if (beyond().length())
            cout << "Beyond " << cmd() << " `" << beyond() << "’\n";
        return true;
    }
    bool error() const
    {
        cout << "unrecognized command: `" << cmd() << "’ called\n" <<
                count() << " matching alternatives found\n";
        return true;
    }
    bool quit() const
    {
        cout << "quit called: quitting this series\n";
        return false;
    }
    public:
        Command();                      // Declara el constructor por defecto
        bool run(std::string const &cmd)    // ejecuta un comando
        {
            return (this->*findCmd(cmd))(); // ejecuta el comando que coincide
                                            // con ’cmd’
        }
};
// Define las asociaciones comando-función. Nótese que la última tiene un
// texto de comando vacío. Esto no es obligatorio, se podría haber especificado
// un texto de comando para el último comando también.
Command::Entry Command::s_action[] =
{
    Entry("add",    &Command::add),
    Entry("quit",   &Command::quit),
    Entry("",       &Command::error),
};
// Define el constructor por defecto
Command::Command()                       // Define el constructor por defecto
:                               // Nótese el uso de `FunctionPtr’
    CmdFinder<FunctionPtr>(s_action, s_action +
                                    sizeof(s_action) / sizeof(Entry))
{}
void run(Command &cmd, char const *descr, size_t mode = 0)
{
    if (mode)
        cmd.setMode(mode);
    cout << "Enter 5 x a command using " << descr << ".\n";
    for (size_t idx = 0; idx++ < 5; )
    {
        cout << "Enter command " << idx << ": ";
        string text;
        getline(cin, text);
        if (!cmd.run(text))     // ejecuta un comando
            break;
    }
}
int main()
{
    Command cmd;                // define un comando
                                // introduce 5 comandos usando el modo por defecto
    run (cmd, "the default mode");
    run (cmd, "abbreviated commands", Command::UNIQUE);
    run (cmd, "abbreviated case-insensitive commands",
                                   Command::UNIQUE | Command::INSENSITIVE);
    run (cmd, "abbreviated command lines",
                                   Command::USE_FIRST | Command::UNIQUE);
    run (cmd, "abbreviated case-insensitive command lines",
                                   Command::USE_FIRST | Command::UNIQUE |
                                                        Command::INSENSITIVE);
}
