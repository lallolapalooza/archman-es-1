CMS_digest_create(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_DIGEST_CREATE(3ssl) OpenSSL CMS_DIGEST_CREATE(3ssl)

NOMBRE

CMS_digest_create_ex, CMS_digest_create - Crear objeto CMS DigestedData

SINOPSIS

#include <openssl/cms.h>
CMS_ContentInfo *CMS_digest_create_ex(BIO *in, const EVP_MD *md,
                                      unsigned int flags, OSSL_LIB_CTX *ctx,
                                      const char *propq);
CMS_ContentInfo *CMS_digest_create(BIO *in, const EVP_MD *md,
                                   unsigned int flags);

DESCRIPCIÓN

CMS_digest_create_ex() crea una estructura CMS_ContentInfo con un tipo NID_pkcs7_digest. Los datos suministrados a través del BIO in se digieren utilizando md. El contexto de biblioteca libctx y la consulta de propiedad propq se utilizan al recuperar algoritmos de los proveedores. El campo flags admite las banderas CMS_DETACHED y CMS_STREAM. Internamente se llama a CMS_final() a menos que se especifique CMS_STREAM.

La estructura CMS_ContentInfo se puede liberar usando CMS_ContentInfo_free(3).

CMS_digest_create() es similar a CMS_digest_create_ex() pero utiliza los valores predeterminados de NULL para el contexto de biblioteca libctx y la consulta de propiedad propq.

VALORES DE RETORNO

Si la asignación falla, CMS_digest_create_ex() y CMS_digest_create() devuelven NULL y establecen un código de error que se puede obtener con ERR_get_error(3). De lo contrario, devuelven un puntero a la estructura recién asignada.

VER TAMBIÉN

ERR_get_error(3), CMS_final(3).

HISTORIA

El método CMS_digest_create_ex() se agregó en OpenSSL 3.0.
