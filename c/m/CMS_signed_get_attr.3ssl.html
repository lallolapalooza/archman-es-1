CMS_signed_add1_attr(), CMS_signed_add1_attr_by_OBJ(), CMS_signed_add1_attr_by_NID(), CMS_signed_add1_attr_by_txt() y las funciones equivalentes CMS_unsigned_add1_attrXXX() permiten añadir atributos duplicados. Las reglas de atributos no se comprueban durante estas llamadas a funciones, y se difieren hasta el proceso de firma o verificación (es decir, durante las llamadas a cualquiera de CMS_sign_ex(), CMS_sign(), CMS_sign_receipt(), CMS_add1_signer(), CMS_Final(), CMS_dataFinal(), CMS_final_digest(), CMS_verify(), CMS_verify_receipt() o CMS_SignedData_verify()).

Para las reglas de atributos de CMS, consulte la Sección 11 del RFC 5652. Para las reglas de atributos de ESS, consulte la Sección 1.3.4 del RFC 2634 y la Sección 5.4 del RFC 5035.
