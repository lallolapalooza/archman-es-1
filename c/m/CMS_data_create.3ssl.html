CMS_data_create(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_DATA_CREATE(3ssl) OpenSSL CMS_DATA_CREATE(3ssl)

NOMBRE

CMS_data_create_ex, CMS_data_create - Crear objeto CMS Data

SINOPSIS

#include <openssl/cms.h>
CMS_ContentInfo *CMS_data_create_ex(BIO *in, unsigned int flags,
                                    OSSL_LIB_CTX *libctx, const char *propq);
CMS_ContentInfo *CMS_data_create(BIO *in, unsigned int flags);

DESCRIPCIÓN

CMS_data_create_ex() crea una estructura CMS_ContentInfo con un tipo NID_pkcs7_data. Los datos se suministran a través del BIO in. El contexto de biblioteca libctx y la consulta de propiedades propq se utilizan al recuperar algoritmos de los proveedores. El campo flags admite la bandera CMS_STREAM. Internamente se llama a CMS_final() a menos que se especifique CMS_STREAM.

La estructura CMS_ContentInfo puede liberarse usando CMS_ContentInfo_free(3).

CMS_data_create() es similar a CMS_data_create_ex() pero utiliza los valores predeterminados de NULL para el contexto de biblioteca libctx y la consulta de propiedades propq.

VALORES DE RETORNO

Si falla la asignación, CMS_data_create_ex() y CMS_data_create() devuelven NULL y establecen un código de error que puede obtenerse con ERR_get_error(3). En caso contrario, devuelven un puntero a la estructura recién asignada.

VER TAMBIÉN

ERR_get_error(3), CMS_final(3)

HISTORIA

El método CMS_data_create_ex() se añadió en OpenSSL 3.0.
