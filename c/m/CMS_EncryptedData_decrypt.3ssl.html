CMS_EncryptedData_decrypt(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_ENCRYPTEDDATA_DECRYPT(3ssl) OpenSSL CMS_ENCRYPTEDDATA_DECRYPT(3ssl)

NOMBRE

CMS_EncryptedData_decrypt, CMS_EnvelopedData_decrypt - Descifra CMS EncryptedData o EnvelopedData

SINOPSIS

#include <openssl/cms.h>
int CMS_EncryptedData_decrypt(CMS_ContentInfo *cms,
                              const unsigned char *key, size_t keylen,
                              BIO *dcont, BIO *out, unsigned int flags);
BIO *CMS_EnvelopedData_decrypt(CMS_EnvelopedData *env, BIO *detached_data,
                               EVP_PKEY *pkey, X509 *cert,
                               ASN1_OCTET_STRING *secret, unsigned int flags,
                               OSSL_LIB_CTX *libctx, const char *propq);

DESCRIPCIÓN

CMS_EncryptedData_decrypt() descifra un objeto EncryptedData cms utilizando la clave simétrica key de tamaño keylen bytes. out es un BIO para escribir el contenido y flags es un conjunto opcional de indicadores. dcont se usa en el raro caso de que el contenido cifrado esté separado. Normalmente se establecerá en NULL.

Los siguientes indicadores se pueden pasar en el parámetro flags.

Si se establece el indicador CMS_TEXT, se eliminan las cabeceras MIME de tipo "text/plain" del contenido. Si el contenido no es de tipo "text/plain", se devuelve un error.

CMS_EnvelopedData_decrypt() descifra, de manera similar a CMS_decrypt(3), un objeto CMS EnvelopedData env utilizando la clave simétrica secret si no es NULL, de lo contrario, la clave privada del destinatario pkey. Si se proporciona pkey, se recomienda proporcionar también el certificado asociado en cert; consulte CMS_decrypt(3) y las NOTAS sobre cert allí. Los parámetros opcionales flags y dcont se utilizan como se describe anteriormente. Los parámetros opcionales de contexto de biblioteca libctx y consulta de propiedad propq se utilizan al recuperar algoritmos de los proveedores.

VALORES DE RETORNO

CMS_EncryptedData_decrypt() devuelve 0 si ocurrió un error, de lo contrario devuelve 1.

CMS_EnvelopedData_decrypt() devuelve NULL si ocurrió un error, de lo contrario, un BIO que contiene el contenido descifrado.

VER TAMBIÉN

ERR_get_error(3), CMS_EncryptedData_encrypt(3), CMS_decrypt(3)

HISTORIA

CMS_EnvelopedData_decrypt() se añadió en OpenSSL 3.2.
