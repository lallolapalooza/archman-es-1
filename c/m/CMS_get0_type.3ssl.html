CMS_get0_type(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_GET0_TYPE(3ssl) OpenSSL CMS_GET0_TYPE(3ssl)

NOMBRE

CMS_get0_type, CMS_set1_eContentType, CMS_get0_eContentType, CMS_get0_content - obtener y establecer tipos y contenido de CMS

SINOPSIS

#include <openssl/cms.h>
const ASN1_OBJECT *CMS_get0_type(const CMS_ContentInfo *cms);
int CMS_set1_eContentType(CMS_ContentInfo *cms, const ASN1_OBJECT *oid);
const ASN1_OBJECT *CMS_get0_eContentType(CMS_ContentInfo *cms);
ASN1_OCTET_STRING **CMS_get0_content(CMS_ContentInfo *cms);

DESCRIPCIÓN

CMS_get0_type() devuelve el tipo de contenido de una estructura CMS_ContentInfo como un puntero ASN1_OBJECT. Una aplicación puede entonces decidir cómo procesar la estructura CMS_ContentInfo basándose en este valor.

CMS_set1_eContentType() establece el tipo de contenido incrustado de una estructura CMS_ContentInfo. Debe llamarse con funciones CMS (como CMS_sign(3), CMS_encrypt(3)) con la bandera CMS_PARTIAL y antes de que la estructura se finalice, de lo contrario los resultados no están definidos.

ASN1_OBJECT *CMS_get0_eContentType() devuelve un puntero al tipo de contenido incrustado.

CMS_get0_content() devuelve un puntero al puntero ASN1_OCTET_STRING que contiene el contenido incrustado.

NOTAS

Como el 0 implica CMS_get0_type(), CMS_get0_eContentType() y CMS_get0_content() devuelven punteros internos que no deben liberarse. CMS_set1_eContentType() copia el OID proporcionado y debe liberarse después de su uso.

Los valores ASN1_OBJECT devueltos pueden convertirse en un valor entero NID usando OBJ_obj2nid(). Para los tipos de contenido actualmente soportados se devuelven los siguientes valores:

NID_pkcs7_data
NID_pkcs7_signed
NID_pkcs7_digest
NID_id_smime_ct_compressedData:
NID_pkcs7_encrypted
NID_pkcs7_enveloped

El valor de retorno de CMS_get0_content() es un puntero al puntero de contenido ASN1_OCTET_STRING. Esto significa que, por ejemplo:

ASN1_OCTET_STRING **pconf = CMS_get0_content(cms);

*pconf podría ser NULL si no hay contenido incrustado. Las aplicaciones pueden acceder, modificar o crear el contenido incrustado en una estructura CMS_ContentInfo usando esta función. Las aplicaciones normalmente no necesitarán modificar el contenido incrustado, ya que normalmente es establecido por funciones de nivel superior.

VALORES DE RETORNO

CMS_get0_type() y CMS_get0_eContentType() devuelven una estructura ASN1_OBJECT.

CMS_set1_eContentType() devuelve 1 si tiene éxito o 0 si ocurrió un error. El error puede obtenerse de ERR_get_error(3).
