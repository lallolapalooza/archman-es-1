INTRODUCCIÓ

N

Un generador de CMake es responsable de escribir los archivos de entrada para un sistema de compilación nativo. Exactamente uno de los generadores de CMake debe ser seleccionado para un árbol de compilación para determinar qué sistema de compilación nativo se va a usar. Opcionalmente, uno de los generadores extra puede ser seleccionado como una variante de algunos de los generadores de herramientas de compilación de línea de comandos para producir archivos de proyecto para un IDE

auxiliar.

Los generadores de CMake son específicos de la plataforma, por lo que cada uno solo puede estar disponible en ciertas plataformas. El comando de línea de herramientas cmake(1) <#manual:cmake(1)> --help <#cmdoption-cmake-h> lista los generadores disponibles en la plataforma actual. Use su opción -G <#cmdoption-cmake-G> para especificar el generador para un nuevo árbol de compilación. El cmake-gui(1) <#manual:cmake-gui(1)> ofrece una selección inter

activa de un generador al crear
un nuevo árbol de compilación.

NAME

cmake-generators - CMake Generators

INTRODUCTION

This document describes the generators known to CMake. A generator is a component of CMake that creates IDE project files or build system Makefiles from CMake's intermediate representation. The available generators depend on the platform and the version of CMake.

A list of generators for a specific CMake installation can be obtained by running:

cmake --help

Generators are selected with the -G option when running CMake for the first time in a build directory. For example:

cmake -G "Unix Makefiles" ..

Generators are identified by name. Some generators are specific to certain IDEs or build tools, while others are more generic.

Generates Kate project files.

A project file for Kate will be created in the top directory in the top level build directory. To use it in Kate, the Project plugin must be enabled. The project file is loaded in Kate by opening the ProjectName.kateproject file in the editor. If the Kate Build-plugin is enabled, all targets generated by CMake are available for building.

Generates Sublime Text 2 project files.

Project files for Sublime Text 2 will be created in the top directory and in every subdirectory which features a CMakeLists.txt file containing a project() <#command:project> call. Additionally Makefiles (or build.ninja files) are generated into the build tree. The appropriate make program can build the project through the default all target. An install target is also provided.
