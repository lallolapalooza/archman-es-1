CMS_get1_ReceiptRequest(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_GET1_RECEIPTREQUEST(3ssl) OpenSSL CMS_GET1_RECEIPTREQUEST(3ssl)

NOMBRE

CMS_ReceiptRequest_create0_ex, CMS_ReceiptRequest_create0, CMS_add1_ReceiptRequest, CMS_get1_ReceiptRequest, CMS_ReceiptRequest_get0_values - Funciones de solicitud de recibo firmado CMS

SINOPSIS

#include <openssl/cms.h>
CMS_ReceiptRequest *CMS_ReceiptRequest_create0_ex(
    unsigned char *id, int idlen, int allorfirst,
    STACK_OF(GENERAL_NAMES) *receiptList, STACK_OF(GENERAL_NAMES) *receiptsTo,
    OSSL_LIB_CTX *libctx);
CMS_ReceiptRequest *CMS_ReceiptRequest_create0(
    unsigned char *id, int idlen, int allorfirst,
    STACK_OF(GENERAL_NAMES) *receiptList, STACK_OF(GENERAL_NAMES) *receiptsTo);
int CMS_add1_ReceiptRequest(CMS_SignerInfo *si, CMS_ReceiptRequest *rr);
int CMS_get1_ReceiptRequest(CMS_SignerInfo *si, CMS_ReceiptRequest **prr);
void CMS_ReceiptRequest_get0_values(CMS_ReceiptRequest *rr, ASN1_STRING **pcid,
                                    int *pallorfirst,
                                    STACK_OF(GENERAL_NAMES) **plist,
                                    STACK_OF(GENERAL_NAMES) **prto);

DESCRIPCIÓN

CMS_ReceiptRequest_create0_ex() crea una estructura de solicitud de recibo firmado. El campo signedContentIdentifier se establece utilizando id e idlen, o se establece a 32 bytes de datos pseudoaleatorios si id es NULL. Si receiptList es NULL, se utiliza la opción allOrFirstTier en receiptsFrom y se establece con el valor del parámetro allorfirst. Si receiptList no es NULL, se utiliza la opción receiptList en receiptsFrom. El parámetro receiptsTo especifica el valor del campo receiptsTo. El contexto de la biblioteca libctx se utiliza para encontrar el generador aleatorio público.

CMS_ReceiptRequest_create0() es similar a CMS_ReceiptRequest_create0_ex() pero utiliza los valores por defecto de NULL para el contexto de la biblioteca libctx.

La función CMS_add1_ReceiptRequest() añade una solicitud de recibo firmado rr a la estructura SignerInfo si.

int CMS_get1_ReceiptRequest() busca una solicitud de recibo firmado en si; si se encuentra alguna, se decodifica y se escribe en prr.

CMS_ReceiptRequest_get0_values() recupera los valores de una solicitud de recibo. El signedContentIdentifier se copia a pcid. Si se utiliza la opción allOrFirstTier de receiptsFrom, su valor se copia a pallorfirst; de lo contrario, el campo receiptList se copia a plist. El parámetro receiptsTo se copia a prto.

NOTAS

Para más detalles sobre el significado de los campos, consulte RFC2634.

El contenido de un recibo firmado solo debe considerarse significativo si la estructura CMS_ContentInfo correspondiente se puede verificar correctamente utilizando CMS_verify().

VALORES DE RETORNO

CMS_ReceiptRequest_create0_ex() y CMS_ReceiptRequest_create0() devuelven una estructura de solicitud de recibo firmado o NULL si ocurre un error.

CMS_add1_ReceiptRequest() devuelve 1 para éxito o 0 si ocurre un error.

CMS_get1_ReceiptRequest() devuelve 1 si se encuentra y decodifica una solicitud de recibo firmado. Devuelve 0 si no está presente una solicitud de recibo firmado y -1 si está presente pero malformada.

VER TAMBIÉN

ERR_get_error(3), CMS_sign(3), CMS_sign_receipt(3), CMS_verify(3) CMS_verify_receipt(3)

HISTORIAL

La función CMS_ReceiptRequest_create0_ex() se añadió en OpenSSL 3.0.
