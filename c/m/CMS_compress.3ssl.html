CMS_compress(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CMS_COMPRESS(3ssl) OpenSSL CMS_COMPRESS(3ssl)

NOMBRE

CMS_compress - crear una estructura CMS CompressedData

SINOPSIS

#include <openssl/cms.h>
CMS_ContentInfo *CMS_compress(BIO *in, int comp_nid, unsigned int flags);

DESCRIPCIÓN

CMS_compress() crea y devuelve una estructura CMS CompressedData. comp_nid es el algoritmo de compresión a utilizar o NID_undef para usar el algoritmo por defecto (compresión zlib). in es el contenido a comprimir. flags es un conjunto opcional de banderas.

El único algoritmo de compresión soportado actualmente es zlib utilizando el NID NID_zlib_compression.

Si el soporte zlib no está compilado en OpenSSL, entonces CMS_compress() devolverá un error.

Si se establece la bandera CMS_TEXT, se anteponen cabeceras MIME del tipo text/plain a los datos.

Normalmente el contenido proporcionado se traduce al formato canónico MIME (como requieren las especificaciones S/MIME). Si se establece CMS_BINARY, no se realiza ninguna traducción. Esta opción debe utilizarse si los datos proporcionados están en formato binario, de lo contrario la traducción los corromperá. Si se establece CMS_BINARY, se ignora CMS_TEXT.

Si se establece la bandera CMS_STREAM, se devuelve una estructura CMS_ContentInfo parcial, adecuada para E/S en streaming: no se leen datos del BIO in.

Los datos comprimidos se incluyen en la estructura CMS_ContentInfo, a menos que se establezca CMS_DETACHED, en cuyo caso se omiten. Esto rara vez se usa en la práctica y no es soportado por SMIME_write_CMS().

Si se establece la bandera CMS_STREAM, la estructura CMS_ContentInfo devuelta no está completa y la salida de sus contenidos a través de una función que no finaliza correctamente la estructura CMS_ContentInfo dará resultados impredecibles.

Varias funciones, incluyendo SMIME_write_CMS(), i2d_CMS_bio_stream(), PEM_write_bio_CMS_stream(), finalizan la estructura. Alternativamente, la finalización puede realizarse obteniendo el BIO de ASN1 en streaming directamente usando BIO_new_CMS().

Actualmente no se pueden establecer parámetros de compresión adicionales como el nivel de compresión zlib.

VALORES DE RETORNO

CMS_compress() devuelve una estructura CMS_ContentInfo o NULL si ocurrió un error. El error puede obtenerse de ERR_get_error(3).

VER TAMBIÉN

ERR_get_error(3), CMS_uncompress(3)

HISTORIAL

La bandera CMS_STREAM se añadió en OpenSSL 1.0.0.
