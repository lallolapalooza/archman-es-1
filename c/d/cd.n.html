NOMBRE

cd - Cambiar directorio de trabajo

SINOPSIS

cd ?nombreDir?

DESCRIPCIÓN

Cambia el directorio de trabajo actual a nombreDir, o al directorio de inicio (según se especifica en la variable de entorno HOME) si nombreDir no se proporciona. Devuelve una cadena vacía. Tenga en cuenta que el directorio de trabajo actual es un recurso por proceso; el comando cd cambia el directorio de trabajo para todos los intérpretes y (en un entorno con hilos) todos los hilos.

EJEMPLOS

Cambiar al directorio de inicio del usuario fred:

cd ~fred

Cambiar al directorio lib que es un directorio hermano del actual:

cd ../lib

VER TAMBIÉN

filename(n), glob(n), pwd(n)
