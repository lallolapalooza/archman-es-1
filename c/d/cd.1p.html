CD(1P) Manual de Programador POSIX CD(1P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

cd — cambiar el directorio de trabajo

SINOPSIS

cd [-L|-P] [directorio]
cd -

DESCRIPCIÓN

La utilidad cd cambiará el directorio de trabajo del entorno de ejecución del shell actual (ver Sección 2.12, Entorno de Ejecución del Shell) ejecutando los siguientes pasos en secuencia. (En los siguientes pasos, el símbolo curpath representa un valor intermedio utilizado para simplificar la descripción del algoritmo utilizado por cd. No hay requisito de que curpath sea visible para la aplicación.)

1.
Si no se proporciona un operando directorio y la variable de entorno HOME está vacía o no definida, el comportamiento por defecto es definido por la implementación y no se tomarán más pasos.
2.
Si no se proporciona un operando directorio y la variable de entorno HOME está establecida a un valor no vacío, la utilidad cd se comportará como si el directorio nombrado en la variable de entorno HOME hubiera sido especificado como el operando directorio.
3.
Si el operando directorio comienza con un carácter de <barra>, establezca curpath al operando y proceda al paso 7.
4.
Si el primer componente del operando directorio es punto o punto-punto, proceda al paso 6.
5.
Comenzando con el primer nombre de ruta en los nombres de ruta separados por <dos puntos> de CDPATH (ver la sección VARIABLES DE ENTORNO), si el nombre de ruta no está vacío, pruebe si la concatenación de ese nombre de ruta, un carácter de <barra> si ese nombre de ruta no terminaba en un carácter de <barra>, y el operando directorio nombra un directorio. Si el nombre de ruta está vacío, pruebe si la concatenación de punto, un carácter de <barra>, y el operando nombra un directorio. En cualquier caso, si la cadena resultante nombra un directorio existente, establezca curpath a esa cadena y proceda al paso 7. De lo contrario, repita este paso con el siguiente nombre de ruta en CDPATH hasta que se hayan probado todos los nombres de ruta.
6.
Establezca curpath al operando directorio.
7.
Si la opción -P está en efecto, proceda al paso 10. Si curpath no comienza con un carácter de <barra>, establezca curpath a la cadena formada por la concatenación del valor de PWD, un carácter de <barra> si el valor de PWD no terminaba con un carácter de <barra>, y curpath.
8.
El valor de curpath será entonces convertido a forma canónica como sigue, considerando cada componente desde el principio hasta el final, en secuencia:
a.
Los componentes de punto y cualquier carácter de <barra> que los separe del siguiente componente serán eliminados.
b.
Para cada componente punto-punto, si hay un componente precedente y no es raíz ni punto-punto, entonces:
i.
Si el componente precedente no se refiere (en el contexto de la resolución de nombres de ruta con enlaces simbólicos seguidos) a un directorio, entonces la utilidad cd mostrará un mensaje de error apropiado y no se tomarán más pasos.
ii.
El componente precedente, todos los caracteres de <barra> que separen el componente precedente de punto-punto, punto-punto, y todos los caracteres de <barra> que separen punto-punto del siguiente componente (si lo hay) serán eliminados.
c.
Una implementación puede simplificar aún más curpath eliminando cualquier carácter de <barra> final que no sean también caracteres de <barra> iniciales, reemplazando múltiples caracteres de <barra> consecutivos no iniciales con una única <barra>, y reemplazando tres o más caracteres de <barra> iniciales con una única <barra>. Si, como resultado de esta canonización, la variable curpath está vacía, no se tomarán más pasos.
9.
Si curpath es más largo que {PATH_MAX} bytes (incluyendo el nulo de terminación) y el operando directorio no era más largo que {PATH_MAX} bytes (incluyendo el nulo de terminación), entonces curpath será convertido de un nombre de ruta absoluto a un nombre de ruta relativo equivalente si es posible. Esta conversión siempre se considerará posible si el valor de PWD, con una <barra> final añadida si no la tiene ya, es una subcadena inicial de curpath. Si se considera posible bajo otras circunstancias o no es un asunto no especificado. Las implementaciones también pueden aplicar esta conversión si curpath no es más largo que {PATH_MAX} bytes o el operando directorio era más largo que {PATH_MAX} bytes.
10.
La utilidad cd entonces realizará acciones equivalentes a la función chdir() llamada con curpath como argumento path. Si estas acciones fallan por cualquier motivo, la utilidad cd mostrará un mensaje de error apropiado y el resto de este paso no se ejecutará. Si la opción -P no está en efecto, la variable de entorno PWD se establecerá al valor que curpath tenía al entrar al paso 9 (es decir, antes de la conversión a un nombre de ruta relativo). Si la opción -P está en efecto, la variable de entorno PWD se establecerá a la cadena que sería generada por pwd -P. Si no hay suficiente permiso en el nuevo directorio, o en cualquier padre de ese directorio, para determinar el directorio de trabajo actual, el valor de la variable de entorno PWD no está especificado.

Si, durante la ejecución de los pasos anteriores, la variable de entorno PWD se establece, la variable de entorno OLDPWD también se establecerá al valor del directorio anterior (que es el directorio de trabajo actual inmediatamente antes de la llamada a cd).

OPCIONES

La utilidad cd se ajustará a las Definiciones Base del volumen de POSIX.1‐2017, Sección 12.2, Pautas de Sintaxis de Utilidad.

Las siguientes opciones serán soportadas por la implementación:

-L
Manejar el operando punto-punto lógicamente; los componentes de enlace simbólico no serán resueltos antes de que se procesen los componentes de punto-punto (ver pasos 8. y 9. en la DESCRIPCIÓN).
-P
Manejar el operando punto-punto físicamente; los componentes de enlace simbólico serán resueltos antes de que se procesen los componentes de punto-punto (ver paso 7. en la DESCRIPCIÓN).

Si se especifican ambas opciones -L y -P, la última de estas opciones será utilizada y todas las demás serán ignoradas. Si no se especifica ni -L ni -P, el operando será manejado punto-punto lógicamente; ver la DESCRIPCIÓN.

OPERANDOS

Los siguientes operandos serán soportados:

directorio
Un nombre de ruta absoluto o relativo del directorio que se convertirá en el nuevo directorio de trabajo. La interpretación de un nombre de ruta relativo por cd depende de la opción -L y de las variables de entorno CDPATH y PWD. Si directorio es una cadena vacía, los resultados no están especificados.
-
Cuando se usa un <guion menos> como operando, esto será equivalente a el comando:
cd "$OLDPWD" && pwd

que cambia al directorio anterior y luego escribe su nombre.

STDIN

No se usa.

ARCHIVOS DE ENTRADA

Ninguno.

AMBIENTE

Las siguientes variables de entorno afectarán la ejecución de cd:

CDPATH
Determine la búsqueda de directorio si no es un nombre de ruta absoluto. Si no está establecida o está vacía, el comportamiento es el mismo que si estuviera establecida a un solo punto (.), significando que la búsqueda de directorio se realizará primero en el directorio actual. La sintaxis de CDPATH es una lista de nombres de directorio separados por <dos puntos>. Una entrada de lista vacía se interpreta como un punto (.).
HOME
Determine el directorio predeterminado si no se proporciona el operando directorio.
OLDPWD
Utilizado por la opción -.
PWD
Se utiliza para construir nombres de ruta relativos y para establecer el directorio de trabajo actual. Si no está establecida, el comportamiento es definido por la implementación.

Las siguientes variables de entorno se verán afectadas por la ejecución de cd:

OLDPWD
Se establecerá al valor del directorio de trabajo anterior.
PWD
Se establecerá al nuevo directorio de trabajo actual.

EVENTOS ASÍNCRONOS

Ninguno.

ESTADO DE SALIDA

La utilidad cd devolverá uno de los siguientes valores de salida:

0
Se cambió el directorio de trabajo con éxito.
1-125
Ocurrió un error.
>125
Se encontró un error y el comando fue invocado a través de `automount`.

CONSECUENCIAS DE LOS ERRORES

Si ocurre un error, el directorio de trabajo actual no se cambiará y las variables de entorno OLDPWD y PWD no se modificarán.

ERRORES

Cuando se invoca con -, el comportamiento de pwd es independiente del directorio de trabajo actual. La primera vez que se invoca un shell y se ejecuta cd, OLDPWD no está definido. Si cd - se invoca en este caso, la ejecución de pwd se basa en un valor no definido de OLDPWD.
