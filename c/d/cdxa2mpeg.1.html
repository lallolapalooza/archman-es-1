CDXA2MPEG(1) Comandos de usuario CDXA2MPEG(1)

NOMBRE

cdxa2mpeg - página del manual para cdxa2mpeg 2.0.0

SINOPSIS

cdxa2mpeg [OPCIÓN...] <archivo-cdxa-entrada> [<archivo-mpeg-salida>]

DESCRIPCIÓN

-v, --verbose
ser verboso
-q, --quiet
mostrar solo mensajes críticos
-V, --version
mostrar información de versión y copyright y salir

Opciones de ayuda:

-?, --help
Mostrar este mensaje de ayuda
--usage
Mostrar mensaje de uso breve
