CDRVES

DOCUMENTACIÓN DE FUNCIONES/SUBRUTINAS

subrutina cdrves (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, complex, dimension( lda, * ) a, integer lda, complex, dimension( lda, * ) h, complex, dimension( lda, * ) ht, complex, dimension( * ) w, complex, dimension( * ) wt, complex, dimension( ldvs, * ) vs, integer ldvs, real, dimension( 13 ) result, complex, dimension( * ) work, integer nwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, logical, dimension( * ) bwork, integer info)

CDRVES

Propósito:

!>
!>    CDRVES comprueba el problema del autovalor no simétrico (forma de Schur)
!>    controlador CGEES.
!>
!>    Cuando se llama a CDRVES, se especifica un número de tamaños de matriz () y
!>    un número de tipos de matriz. Para cada tamaño () y cada tipo de matriz,
!>    se generará y utilizará una matriz para probar las rutinas de autovalores
!>    no simétricos. Para cada matriz, se realizarán 13 pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenar autovalores)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (sin ordenar autovalores).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenar autovalores).
!>
!>    (4)     0     si W son autovalores de T
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (6)     0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (con ordenación de autovalores).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de autovalores).
!>
!>    (10)    0     si W son autovalores de T
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (12)    0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            autovalores que fueron SELECCIONADOS
!>
!>    Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con unos en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1)
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicada por una constante cercana
!>         al umbral de desbordamiento.
!>    (8)  Igual que (4), pero multiplicada por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (9)  Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con
!>         ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con
!>         ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas 1, ULP, ..., ULP con
!>         ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene autovalores complejos elegidos aleatoriamente de
!>         ULP < |z| < 1 y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas 1, ULP, ..., ULP con
!>         ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene autovalores complejos elegidos aleatoriamente
!>         de ULP < |z| < 1 y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (17) Igual que (16), pero multiplicada por una constante cercana
!>         al umbral de desbordamiento.
!>    (18) Igual que (16), pero multiplicada por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>         Si N es al menos 4, todas las entradas en las dos primeras filas y la
!>         última fila, y la primera columna y las dos últimas columnas son cero.
!>    (20) Igual que (19), pero multiplicada por una constante cercana
!>         al umbral de desbordamiento.
!>    (21) Igual que (19), pero multiplicada por una constante cercana
!>         al umbral de subdesbordamiento.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          CDRVES no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, de dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Se omitirán los valores cero. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CDRVES
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE..
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER M
AXTYP), entonces los tipos NTYPES+1 hasta !> MAXTYP no serán generados. Si NTYPES es mayor !> que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES) !> serán ignorados. !>

ISEE

D 
!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador
!>          de números aleatorios. Los elementos del arreglo deben estar
!>          entre 0 y 4095; si no lo están, serán reducidos módulo 4096.
!>          Además, ISEED(4) debe ser impar. El generador de números
!>          aleatorios utiliza una secuencia congruencial lineal limitada
!>          a enteros pequeños, y por lo tanto debería producir números
!>          aleatorios independientes de la máquina. Los valores de ISEED
!>          se modifican en la salida, y pueden usarse en la siguiente
!>          llamada a CDRVES para continuar la misma secuencia de números
!>          aleatorios.
!
>

THRES

H 
!>          THRESH es REAL
!>          Una prueba se contará como fallida si el , calculado como
!>          se describe arriba, excede THRESH.  Note que el error
!>          está escalado para ser O(1), por lo que THRESH debería ser un
!>          múltiplo razonablemente pequeño de 1, p. ej., 10 o 100.  En
!>          particular, no debería depender de la precisión (simple vs.
!>          doble) o del tamaño de la matriz. Debe ser al menos cero.
!
>

NOUNI

T 
!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve INFO distinto de 0.)
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA, max(NN))
!>          Utilizado para contener la matriz cuyos eigenvalores deben ser
!>          calculados.  En la salida, A contiene la última matriz
!>          realmente usada.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal de A, y H. LDA debe ser al menos 1 y
!>          al menos max( NN ).
!
>

H 
!>          H es un arreglo COMPLEX, dimensión (LDA, max(NN))
!>          Otra copia de la matriz de prueba A, modificada por CGEES.
!
>

H

T 
!>          HT es un arreglo COMPLEX, dimensión (LDA, max(NN))
!>          Otra copia más de la matriz de prueba A, modificada por CGEES.
!
>

W 
!>          W es un arreglo COMPLEX, dimensión (max(NN))
!>          Los eigenvalores calculados de A.
!
>

W

T 
!>          WT es un arreglo COMPLEX, dimensión (max(NN))
!>          Al igual que W, este arreglo contiene los eigenvalores de A,
!>          pero aquellos calculados cuando CGEES solo calcula una
!>          descomposición parcial de eigenvalores, es decir, sin
!>          vectores de Schur
!
>

V

S 
!>          VS es un arreglo COMPLEX, dimensión (LDVS, max(NN))
!>          VS contiene los vectores de Schur calculados.
!
>

LDV

S 
!>          LDVS es INTEGER
!>          Dimensión principal de VS. Debe ser al menos max(1,max(NN)).
!
>

RESUL

T 
!>          RESULT es un arreglo REAL, dimensión (13)
!>          Los valores calculados por las 13 pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (NWORK)
!
>

NWOR

K 
!>          NWORK es INTEGER
!>          El número de entradas en WORK.  Este debe ser al menos
!>          5*NN(j)+2*NN(j)**2 para todo j.
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (max(NN))
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (max(NN))
!
>

BWOR

K 
!>          BWORK es un arreglo LOGICAL, dimensión (max(NN))
!
>

INF

O 
!>          INFO es INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algunos NN(j) < 0
!>           -3: NTYPES < 0
!>           -6: THRESH < 0
!>           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>          -15: LDVS < 1 o LDVS < NMAX, donde NMAX es max( NN(j) ).
!>          -18: NWORK demasiado pequeño.
!>          Si  CLATMR, CLATMS, CLATME o CGEES devuelve un código de
!>              error, se devuelve su valor absoluto.
!>
!>-----------------------------------------------------------------------
!>
!>     Algunas Variables y Parámetros Locales:
!>     ---- ----- --------- --- ----------
!>     ZERO, ONE       Real 0 y 1.
!>     MAXTYP          El número de tipos definidos.
!>     NMAX            El valor más grande en NN.
!>     NERRS           El número de pruebas que han excedido THRESH
!>     COND, CONDS,
!>     IMODE           Valores a pasar a los generadores de matrices.
!>     ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>     OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>     ULP, ULPINV     Precisión relativa más fina y su inversa.
!>     RTULP, RTULPI   Raíces cuadradas de los 4 valores anteriores.
!>             Los siguientes cuatro arreglos decodifican JTYPE:
!>     KTYPE(j)        El tipo general (1-10) para el tipo .
!>     KMODE(j)        El valor MODE a pasar al generador de matrices
!>                     para el tipo .
!>     KMAGN(j)        El orden de magnitud ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!>     KCONDS(j)       Selecciona si CONDS debe ser 1 o
!>                     1/sqrt(ulp).  (0 significa irrelevante.)
!>
