NOMBRE

cdv - Script para iniciar el Visor de volcados de caída desde la línea de comandos del sistema operativo

DESCRIPCIÓN

El script de shell cdv se encuentra en el directorio priv de la aplicación Observer. El script se utiliza para iniciar la herramienta Visor de volcados de caída desde la línea de comandos del sistema operativo.

Para usuarios de Windows, cdv.bat se encuentra en la misma ubicación.

cdv [archivo]

El argumento archivo es opcional. Si no se especifica, se muestra un cuadro de diálogo de archivo, lo que le permite seleccionar un volcado de caída del sistema de archivos.
