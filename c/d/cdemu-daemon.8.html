CDEMU-DAEMON(8) Manual del Administrador del Sistema CDEMU-DAEMON(8)

NOMBRE

cdemud - El demonio de CDEmu

SINOPSIS

cdemu-daemon [opciones]

DESCRIPCIÓN

Este es el demonio de CDEmu, la parte de espacio de usuario de la suite cdemu, un emulador de dispositivos de CD/DVD-ROM libre y GPL para Linux.

Recibe comandos SCSI del módulo del kernel y los procesa, devolviendo los datos solicitados al kernel. El demonio implementa el dispositivo virtual real; una instancia por cada dispositivo registrado por el módulo del kernel. Utiliza libMirage, una biblioteca de acceso a imágenes que forma parte de la suite cdemu, para el acceso a imágenes (por ejemplo, lectura de sectores).

El demonio se registra en el bus de sistema o de sesión de D-BUS (dependiendo de las opciones que se le pasen) donde expone una interfaz que puede ser utilizada por los clientes para controlarlo.

OPCIONES

--archivo-configuracion=nombre_archivo
Archivo de configuración a cargar. Ver la sección Archivo de configuración para más detalles.
-n --num-dispositivos=N
Número de dispositivos. Especifica el número de dispositivos virtuales que la instancia del demonio debe registrar con el módulo del kernel y controlar. Por defecto, se crea 1 dispositivo virtual.
-c --dispositivo-control=ruta
Dispositivo de control. Especifica la ruta del dispositivo de control. El dispositivo de control es un dispositivo de caracteres proporcionado por el módulo del kernel; se utiliza para la comunicación entre el kernel y la parte del espacio de usuario de la suite CDEmu. Por defecto, se utiliza /dev/vhba_ctl.
-a --driver-audio=driver
Controlador de audio. Especifica el controlador de audio a ser utilizado por la reproducción de audio de los dispositivos virtuales. Dado que se usa libao para la reproducción de audio, se puede especificar cualquier controlador válido de libao. Si se utiliza default como controlador, entonces se usa el controlador predeterminado de libao. Pocos ejemplos de controladores válidos de libao son alsa, oss, pulse o null. Para todos los controladores, se utiliza el dispositivo predeterminado. Por defecto, si no se especifica explícitamente un controlador de audio a través de esta opción, se utiliza null.
-b --bus=tipo_bus
Tipo de bus. Las opciones válidas son system o session. Por defecto, se utiliza el bus de sesión. (Por favor, tenga en cuenta que la ejecución del demonio CDEmu en el bus del sistema se considera obsoleta y se desaconseja por razones de seguridad).
-l --archivo-registro=archivo_registro
Archivo de registro donde escribir la salida de registro. Por defecto, el uso del archivo de registro está deshabilitado y los mensajes se escriben en la salida estándar.
--default-cdemu-debug-mask=mascara
Máscara de depuración predeterminada para los dispositivos CDEmu (a nivel de implementación del demonio CDEmu). El valor predeterminado es 0.
--default-mirage-debug-mask=mascara
Máscara de depuración predeterminada para los dispositivos CDEmu (a nivel de implementación de libMirage). El valor predeterminado es 0.
-? --ayuda
Mostrar el mensaje de ayuda.

EJEMPLOS

Ejecución del demonio en el bus predeterminado con el controlador de audio PulseAudio y 4 dispositivos virtuales:
cdemu-daemon --num-dispositivos=4 --driver-audio=pulse
Ejecución del demonio en el bus del sistema con 2 dispositivos virtuales y registro redirigido a un archivo:
cdemu-daemon --num-dispositivos=2 --bus=system --archivo-registro=/tmp/cdemu-daemon.log

ARCHIVO DE CONFIGURACIÓN

La configuración del demonio se puede recopilar en un archivo de configuración, que se pasa al demonio a través de la opción --archivo-configuracion. El archivo de configuración contiene pares de clave=valor contenidos en una única sección [settings]. Las claves en el archivo de configuración corresponden a los nombres largos de los interruptores de línea de comandos.

Si una opción se especifica tanto en el archivo de configuración como en la línea de comandos, esta última tiene prioridad.

Si el archivo de configuración especificado no existe, se ignora silenciosamente. Si el archivo de configuración especificado es inválido (por ejemplo, tiene sintaxis inválida o no contiene una sección), se genera un error.

Ejemplo

Guardar la siguiente configuración en un archivo y pasarlo al demonio a través de --archivo-configuracion es equivalente a pasar --num-dispositivos=2 --driver-audio=pulse directamente al demonio:

[settings]
num-dispositivos=2
driver-audio=pulse
