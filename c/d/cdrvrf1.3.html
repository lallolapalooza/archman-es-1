CDRVRF1

Propósito:

!>
!> CDRVRF1 prueba las rutinas RFP de LAPACK:
!>     CLANHF.F
!>

Parámetros

NOUT 
!>          NOUT es INTEGER
!>                El número de unidad para la salida.
!>

NN

!>          NN es INTEGER
!>                El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, dimensión (NN)
!>                Los valores de la dimensión de la matriz N.
!>

THRESH

!>          THRESH es REAL
!>                El valor umbral para las relaciones de prueba. Un resultado se
!>                incluye en el archivo de salida si RESULT >= THRESH. Para que
!>                cada relación de prueba se imprima, use THRESH = 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,NMAX)
!>

LDA

!>          LDA es INTEGER
!>                La dimensión principal del array A. LDA >= max(1,NMAX).
!>

ARF

!>          ARF es un array COMPLEX, dimensión ((NMAX*(NMAX+1))/2).
!>

WORK

!>          WORK es un array COMPLEX, dimensión ( NMAX )
