CD-INFO(1) Comandos de usuario CD-INFO(1)

NOMBRE

cd-info - muestra información sobre un CD o imagen de CD

SINOPSIS

cd-info [OPCIÓN...]

DESCRIPCIÓN

-a, --access-mode=CADENA
Establece el método de acceso al CD
-d, --debug=INT
Establece la depuración en NIVEL
-T, --no-tracks
No mostrar información de pistas
-A, --no-analyze
No mostrar análisis del sistema de archivos
--no-cddb
No hace nada ya que este programa no es
-P, --cddb-port=INT
compatible con CDDB

-H, --cddb-http

--cddb-server=CADENA

--cddb-cache=CADENA

--cddb-email=CADENA

--no-cddb-cache

--cddb-timeout=INT

--no-device-info
No mostrar información del dispositivo, solo información del CD
--no-disc-mode
No mostrar información del modo del disco
--dvd
Intenta proporcionar información de DVD si se encuentra un DVD.
-v, --no-vcd
No buscar información de Video CD - para esta compilación, esto siempre está configurado
-I, --no-ioctl
No mostrar información de ioctl()
-b, --bin-file[=ARCHIVO]
establece el archivo de imagen de disco CD-ROM "bin" como origen
-c, --cue-file[=ARCHIVO]
establece el archivo de imagen de disco CD-ROM "cue" como origen
-N, --nrg-file[=ARCHIVO]
establece el archivo de imagen de disco CD-ROM de Nero como origen
-t, --toc-file[=ARCHIVO]
establece el archivo de imagen de disco CD-ROM de cdrdao como origen
-i, --input[=ARCHIVO]
establece el origen y determina si es una imagen "bin" o un dispositivo
--iso9660
imprime el contenido del directorio de cualquier sistema de archivos ISO-9660
-C, --cdrom-device[=DISPOSITIVO]
establece el dispositivo CD-ROM como origen
-l, --list-drives
Proporciona una lista de unidades de CD
--no-header
No mostrar encabezado ni derechos de autor (para pruebas de regresión)
--no-joliet
No usar extensiones Joliet
--no-rock-ridge
No usar información de extensión Rock-Ridge
--no-xa
No usar información de extensión XA
-q, --quiet
No producir salida de advertencia
-V, --version
mostrar información de versión y derechos de autor y salir

Opciones de ayuda:

-?, --help
Mostrar este mensaje de ayuda
--usage
Mostrar mensaje de uso breve
