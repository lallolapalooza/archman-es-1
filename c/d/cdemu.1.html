CDEMU(1) Manual de Comandos Generales CDEMU(1)

NOMBRE

cdemu - un cliente simple de CDEmu por línea de comandos

SINOPSIS

cdemu [opciones] <comando> <parámetros del comando>

DESCRIPCIÓN

Este es cdemu, un cliente por línea de comandos para controlar el demonio CDEmu. Forma parte del conjunto cdemu, un emulador de dispositivos CD/DVD-ROM gratuito bajo GPL para Linux.

Proporciona una forma de realizar las tareas clave relacionadas con el control del demonio CDEmu, como cargar y descargar dispositivos, mostrar el estado de los dispositivos y recuperar/establecer las máscaras de depuración de los dispositivos.

Al conectarse al demonio, el cliente cdemu puede usar el bus de sesión o el bus del sistema. Por defecto, está programado para usar el bus del sistema. El bus por defecto a utilizar puede especificarse a través de los archivos /etc/cdemu-client.conf o ~/.cdemu-client; para más información, por favor, lea el archivo README. El valor por defecto puede ser anulado utilizando la opción --bus.

SOPORTE PARA IMÁGENES CIFRADAS

El demonio CDEmu ofrece soporte para imágenes cifradas. Cuando se requiere una contraseña para cargar una imagen, cdemu-client la solicitará y luego la enviará al demonio.

TENGA EN CUENTA, SIN EMBARGO, QUE LA CONTRASEÑA SE ENVÍA A TRAVÉS DE D-BUS EN UNA CADENA DE TEXTO SIN CIFRAR, SIN NINGUNA PROTECCIÓN.

OPCIONES

-h --help
Muestra el mensaje de ayuda. Si se especifica un comando, se muestra el mensaje de ayuda con la sinopsis y la descripción de ese comando.
-v --version
Imprime la información de la versión y sale.
-b --bus
Establece el tipo de bus D-BUS a utilizar para la conexión. Los valores válidos son session y system. Si no se especifica ningún bus, se utiliza el bus por defecto.

COMANDOS

load [parámetros-del-analizador] <dispositivo> <nombre_archivo> [...]
Carga el dispositivo; dispositivo es el número del dispositivo deseado, o any. Si se usa any, el cliente intentará cargar la imagen en el primer dispositivo vacío que encuentre (si hay uno disponible). nombre_archivo es el nombre del archivo de imagen. Para imágenes de múltiples archivos, se pueden proporcionar múltiples nombres de archivo.

Los siguientes parámetros opcionales del analizador pueden pasarse al intentar cargar la imagen (si son compatibles con un analizador particular o no depende de la implementación del analizador):

--encoding <cadena> Permite especificar una codificación para formatos de imagen basados en texto (como CUE). Esto puede ser necesario si el archivo descriptor de la imagen contiene caracteres no ASCII y no utiliza Unicode.

create-blank [opciones] --writer_id=<id_escritor> <dispositivo> <archivo_imagen>
Crea un disco grabable en blanco en el dispositivo especificado. dispositivo es el número del dispositivo deseado, o any. Si se usa any, el cliente intentará cargar la imagen en el primer dispositivo vacío que encuentre (si hay uno disponible). archivo_imagen es el nombre/base del archivo de imagen. También se debe proporcionar un id_escritor válido. Otras opciones válidas son:

--medium-type <tipo> Establece el tipo de medio en blanco. Los valores válidos son: cdr74, cdr80, cdr90, cdr99 y dvd+r.

--param="writer.id_parametro=valor_parametro" Permite al usuario pasar parámetros adicionales del escritor de imágenes. id_parametro debe ser un ID de parámetro válido de la hoja de parámetros del escritor de imágenes, precedido por "writer.".

unload <dispositivo>
Descarga el dispositivo; dispositivo es el número del dispositivo deseado, o all.
status
Muestra el estado de los dispositivos.
add-device
Crea otro dispositivo virtual.
remove-device
Elimina el último dispositivo virtual.
device-mapping
Muestra la información de mapeo de dispositivos.
daemon-debug-mask <dispositivo> [nuevo-valor]
Muestra/establece la máscara de depuración del demonio; dispositivo es el número del dispositivo deseado, o all. nuevo-valor es el nuevo valor de la máscara de depuración. Si este argumento se omite, se muestra la máscara de depuración actual. La lista de identificadores y valores de máscara de depuración compatibles se puede obtener con el comando enum-daemon-debug-masks. El nuevo-valor puede ser un único valor numérico (por ejemplo, 0x03), una cadena de valores numéricos separados por el carácter de barra vertical (por ejemplo, "0x01|0x02"), o una cadena de identificadores separados por el carácter de barra vertical (por ejemplo, "DAEMON_DEBUG_DEVICE|DAEMON_DEBUG_MMC").
library-debug-mask <dispositivo> [nuevo-valor]
Muestra/establece la máscara de depuración de la biblioteca; dispositivo es el número del dispositivo deseado, o all. nuevo-valor es el nuevo valor de la máscara de depuración. Si este argumento se omite, se muestra la máscara de depuración actual. La lista de identificadores y valores de máscara de depuración compatibles se puede obtener con el comando enum-library-debug-masks. El nuevo-valor puede ser un único valor numérico (por ejemplo, 0x03), una cadena de valores numéricos separados por el carácter de barra vertical (por ejemplo, "0x01|0x02"), o una cadena de identificadores separados por el carácter de barra vertical (por ejemplo, "MIRAGE_DEBUG_PARSER|MIRAGE_DEBUG_DISC").
dpm-emulation <dispositivo> [nuevo-valor]
Muestra/establece el indicador de emulación DPM. dispositivo es el número del dispositivo deseado, o all. nuevo-valor es el nuevo valor a establecer. Si este argumento se omite, se muestra el valor actualmente establecido.
tr-emulation <dispositivo> [nuevo-valor]
Muestra/establece el indicador de emulación de velocidad de transferencia. dispositivo es el número del dispositivo deseado, o all. nuevo-valor es el nuevo valor a establecer. Si este argumento se omite, se muestra el valor actualmente establecido.
bad-sector-emulation <dispositivo> [nuevo-valor]
Muestra/establece el indicador de emulación de sectores defectuosos. dispositivo es el número del dispositivo deseado, o all. nuevo-valor es el nuevo valor a establecer. Si este argumento se omite, se muestra el valor actualmente establecido.
dvd-report-css <dispositivo> [nuevo-valor]
Informa el DVD cargado como cifrado con CSS. dispositivo es el número del dispositivo deseado, o all. nuevo-valor es el nuevo valor a establecer. Si este argumento se omite, se muestra el valor actualmente establecido.

Este indicador influye en la generación de la Estructura de Disco 0x01 falsa, y como tal solo funciona con imágenes de video DVD que no proporcionan esta información (la mayoría de las imágenes, con la excepción quizás de mds/mdf, no lo hacen). Habilitar esta opción permite que las imágenes de DVD cifrados con CSS (por ejemplo, creadas usando 'dd' o 'readcd' sin pasar por un paso de descifrado CSS al crear la imagen) sean reproducidas por un reproductor multimedia de Linux con soporte deCSS.

device-id <dispositivo> [nuevo-id-proveedor] [nuevo-id-producto] [nueva-revision] [nuevo-id-especifico-proveedor]
Muestra/establece el ID del dispositivo. dispositivo es el número del dispositivo deseado. nuevo-id-proveedor es la nueva cadena del ID del proveedor a establecer (máximo 8 caracteres). nuevo-id-producto es la nueva cadena del ID del producto a establecer (máximo 16 caracteres). nueva-revision es la nueva cadena de revisión a establecer (máximo 4 caracteres). nuevo-id-especifico-proveedor es la nueva cadena específica del proveedor a establecer (máximo 20 caracteres). Si se omiten los nuevos valores, se muestran los valores actualmente establecidos.
enum-parsers
Enumera los analizadores de imágenes compatibles.
enum-writers
Enumera los escritores de imágenes compatibles.

COMANDOS

enum-parsers
Enumera los analizadores de imágenes admitidos.
enum-writers
Enumera los escritores de imágenes admitidos.
enum-filter-streams
Enumera los flujos de filtro admitidos.
enum-daemon-debug-masks
Enumera las máscaras de depuración de demonio admitidas.
enum-library-debug-masks
Enumera las máscaras de depuración de bibliotecas admitidas.
enum-writer-parameters <id-escritor>
Recupera y muestra la hoja de parámetros para el escritor de imágenes especificado.
version
Muestra información de la versión

EJEMPLOS

Cargar una imagen única al primer dispositivo:
cdemu load 0 ~/image.mds
Cargar una imagen de varios archivos al primer dispositivo:
cdemu load 0 ~/session1.toc ~/session2.toc ~/session3.toc
Cargar una imagen basada en texto en una codificación no ASCII/no Unicode:

cdemu load 0 ~/image.cue --encoding=windows-1250
Cargar una imagen RAW de un DVD encriptado con CSS creado por 'dd', para que pueda ser reproducido por mplayer:

cdemu load 0 ~/image.iso
cdemu dvd-report-css 0 1
Crear un disco grabable en blanco: DVD+R SL con escritor de imágenes ISO:
cdemu create-blank --writer-id=WRITER-ISO --medium-type=dvd+r 0 ~/output-image.iso
Crear un disco grabable en blanco: CD-R de 80 minutos con escritor de imágenes TOC, con parámetros de escritor adicionales:
cdemu create-blank --writer-id=WRITER-TOC --medium-type=cdr80 --param="writer.write_raw=1" --param="writer.write_subchannel=1" 0 ~/output-image.toc
Descargar el primer dispositivo:
cdemu unload 0
Mostrar el estado del dispositivo:
cdemu status
Agregar otro dispositivo:
cdemu add-device
Quitar el último dispositivo:
cdemu remove-device
Mostrar información de mapeo de dispositivos:
cdemu device-mapping
Establecer la máscara de depuración del demonio para el primer dispositivo:
cdemu daemon-debug-mask 0 0x01
Establecer la máscara de depuración del demonio para el primer dispositivo (compuesta):
cdemu daemon-debug-mask 0 "0x01|0x02"
Establecer la máscara de depuración del demonio para el primer dispositivo (compuesta, por nombre):
cdemu daemon-debug-mask 0 "DAEMON_DEBUG_DEVICE|DAEMON_DEBUG_MMC"
Obtener la máscara de depuración de la biblioteca para el primer dispositivo:
cdemu library-debug-mask 0
Deshabilitar la emulación DPM en todos los dispositivos:
cdemu dpm-emulation all 0
Habilitar la emulación de velocidad de transferencia en el primer dispositivo:
cdemu tr-emulation 0 1
Habilitar la emulación de sectores defectuosos en el primer dispositivo:
cdemu tr-emulation 0 1
Cambiar el ID del dispositivo del primer dispositivo:
cdemu device-id 0 "MyVendor" "MyProduct" "1.0.0" "Test device ID"
Enumerar los analizadores de imágenes admitidos:
cdemu enum-parsers
Enumerar los escritores de imágenes admitidos:
cdemu enum-writers
Enumerar los flujos de filtro admitidos:
cdemu enum-filter-streams
Enumerar las máscaras de depuración de demonio admitidas:
cdemu enum-daemon-debug-masks
Enumerar las máscaras de depuración de biblioteca admitidas:
cdemu enum-library-debug-masks
Obtener la hoja de parámetros para el escritor de imágenes TOC:
cdemu enum-writer-parameters WRITER-TOC
Mostrar la versión del demonio y la biblioteca:
cdemu version
