CDRVVX

Propósito:

!>
!>    CDRVVX comprueba el controlador experto del problema de valores propios no simétrico
!>    CGEEVX.
!>
!>    CDRVVX utiliza tanto matrices de prueba generadas aleatoriamente dependiendo de
!>    los datos proporcionados en la secuencia de llamada, como datos
!>    leídos de un archivo de entrada e incluyendo números de condición
!>    precalculados con los cuales compara los que él calcula.
!>
!>    Cuando se llama a CDRVVX, se especifican en la secuencia de llamada un número de
!>    matrices  () y un número de matrices .
!>    Para cada tamaño () y cada tipo de matriz, se generará una
!>    matriz y se usará para probar las rutinas de eigen no simétricas. Para
!>    cada matriz, se realizarán 9 pruebas:
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de autovectores derechos unitarios.
!>      W es una matriz diagonal con entradas diagonales W(j).
!>
!>    (2)     | A**H  * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de autovectores izquierdos unitarios, A**H es la
!>      transpuesta conjugada de A, y W es como arriba.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y el componente más grande real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y el componente más grande real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     W(full) = W(partial)
!>
!>      W(full) denota los valores propios calculados cuando también se calculan VR, VL, RCONDV
!>      y RCONDE, y W(partial) denota los
!>      valores propios calculados cuando solo se calculan algunos de VR, VL, RCONDV y
!>      RCONDE.
!>
!>    (6)     VR(full) = VR(partial)
!>
!>      VR(full) denota los autovectores derechos calculados cuando se calculan VL, RCONDV
!>      y RCONDE, y VR(partial) denota el resultado
!>      cuando solo se calculan algunos de VL y RCONDV.
!>
!>    (7)     VL(full) = VL(partial)
!>
!>      VL(full) denota los autovectores izquierdos calculados cuando se calculan VR, RCONDV
!>      y RCONDE, y VL(partial) denota el resultado
!>      cuando solo se calculan algunos de VR y RCONDV.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (full) =
!>                 SCALE, ILO, IHI, ABNRM (partial)
!>            1/ulp en caso contrario
!>
!>      SCALE, ILO, IHI y ABNRM describen cómo se equilibra la matriz.
!>      (full) es cuando también se calculan VR, VL, RCONDE y RCONDV, y
!>      (partial) es cuando algunos no se calculan.
!>
!>    (9)     RCONDV(full) = RCONDV(partial)
!>
!>      RCONDV(full) denota los números de condición recíprocos de los
!>      autovectores derechos calculados cuando también se calculan VR, VL y RCONDE.
!>      RCONDV(partial) denota los números de condición recíprocos
!>      cuando solo se calculan algunos de VR, VL y RCONDE.
!>
!>    Los  se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1's en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP  y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP  y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con  entradas 1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicada por una constante cerca de
!>         el umbral de desbordamiento
!>    (8)  Igual que (4), pero multiplicada por una constante cerca de
!>         el umbral de desbordamiento inferior
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con ángulos complejos
!>         aleatorios en la diagonal y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con ángulos complejos
!>         aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene  entradas 1, ULP,..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene valores propios complejos elegidos aleatoriamente de
!>         ULP < |z| < 1   y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene  entradas 1, ULP,..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios complejos elegidos aleatoriamente
!>         de ULP < |z| < 1 y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (17) Igual que (16), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento
!>    (18) Igual que (16), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento inferior
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de |z| < 1
!>         Si N es al menos 4, todas las entradas en las primeras dos filas y la última
!>         fila, y la primera columna y las últimas dos columnas son cero.
!>    (20) Igual que (19), pero mult


NAME


CDRVVX - the main routine for testing the drivers CGEEV, CGESV, and CGESVX.






SYNOPSIS


 SUBROUTINE CDRVVX(          NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH,
                               NIUNIT, NOUNIT, A, LDA, H, W, W1, VL, LDVL,
                               VR, LDVR, LRE, LDLRE, RCONDV, RCNDV1, RCDVIN,
                               RCONDE, RCNDE1, RCDEIN, SCALE, SCALE1, RESULT,
                               WORK, NWORK, RWORK, INFO )



The types of matrices are:


    

  • Type 1: Zero matrix
    • 

  • Type 2: Identity matrix
    • 

  • Type 3: Orthogonal matrix, Ilr = 0
    • 

  • Type 4: Orthogonal matrix, Ilr = N-1
    • 

  • Type 5: Random orthogonal matrix
    • 

  • Type 6: Random triangular matrix
    • 

  • Type 7: Random symmetric matrix
    • 

  • Type 8: Random Hermitian matrix
    • 

  • Type 9: Random full matrix, Ilr = 0
    • 

  • Type 10: Random full matrix, Ilr = N-1
    • 



The following tests are performed:


    

  • (1) Compute norm(A) and norm(inv(A))
    • 

  • (2) Compute the condition number of A from the two norms
    • 

  • (3) Compute the eigenvalues and eigenvectors
    • 

  • (4) Compute the condition numbers for the eigenvalues and eigenvectors
    • 

  • (5) Compute the reciprocal condition numbers for the eigenvalues and eigenvectors
    • 

  • (6) Compute the reciprocal condition numbers for the eigenvalues and eigenvectors using values near overflow
    • 

  • (7) Compute the reciprocal condition numbers for the eigenvalues and eigenvectors using values near underflow
    • 

  • (8) Compute the reciprocal condition numbers for the eigenvalues and eigenvectors using values multiplied by a constant near overflow
    • 

  • (9) Same as (7), but multiplied by a constant near underflow
    • 



In addition, an input file will be read from logical unit number NIUNIT. The file contains matrices along with precomputed eigenvalues and reciprocal condition numbers for the eigenvalues and right eigenvectors. For these matrices, in addition to tests (1) to (9) we will compute the following two tests:


    

  • (10)  |RCONDV - RCDVIN| / cond(RCONDV)

    RCONDV is the reciprocal right eigenvector condition number computed by CGEEVX and RCDVIN (the precomputed true value) is supplied as input. cond(RCONDV) is the condition number of RCONDV, and takes errors in computing RCONDV into account, so that the resulting quantity should be O(ULP). cond(RCONDV) is essentially given by norm(A)/RCONDE.
    

    • 

  • (11)  |RCONDE - RCDEIN| / cond(RCONDE)

    RCONDE is the reciprocal eigenvalue condition number computed by CGEEVX and RCDEIN (the precomputed true value) is supplied as input.  cond(RCONDE) is the condition number of RCONDE, and takes errors in computing RCONDE into account, so that the resulting quantity should be O(ULP). cond(RCONDE) is essentially given by norm(A)/RCONDV.
    

    • 







Parameters




NSIZES




NSIZES is INTEGER


The number of sizes of matrices to use.  NSIZES must be at least zero. If it is zero, no randomly generated matrices are tested, but any test matrices read from NIUNIT will be tested.




NN




NN is INTEGER array, dimension (NSIZES)


An array containing the sizes to be used for the matrices. Zero values will be skipped.  The values must be at least zero.




NTYPES




NTYPES is INTEGER


The number of elements in DOTYPE. NTYPES must be at least zero. If it is zero, no randomly generated test matrices are tested, but any test matrices read from NIUNIT will be tested. If it is MAXTYP+1 and NSIZES is 1, then an additional type, MAXTYP+1 is defined, which is to use whatever matrix is in A.  This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and DOTYPE(MAXTYP+1) is .TRUE. .




DOTYPE




DOTYPE is LOGICAL array, dimension (NTYPES)


If DOTYPE(j) is .TRUE., then for each size in NN a matrix of that size and of type j will be generated. If NTYPES is smaller than the maximum number of types defined (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be generated.  If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored.




ISEED




ISEED is INTEGER array, dimension (4)


On entry ISEED specifies the seed of the random number generator. The array elements should be between 0 and 4095; if not they will be reduced mod 4096.  Also, ISEED(4) must be odd.  The random number generator uses a linear congruential sequence limited to small integers, and so should produce machine independent random numbers. The values of ISEED are changed on exit, and can be used in the next call to CDRVVX to continue the same random number sequence.




THRESH




THRESH is REAL


A test will count as an error if the relative error, computed as described above, exceeds THRESH.  Note that the error is scaled to be O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100.  In particular, it should not depend on the precision (single vs. double) or the size of the matrix.  It must be at least zero.




NIUNIT




NIUNIT is INTEGER


The FORTRAN unit number for reading in the data file of problems to solve.




NOUNIT




NOUNIT is INTEGER


The FORTRAN unit number for printing out error messages (e.g., if a routine returns INFO not equal to 0.)




A




A is COMPLEX array, dimension (LDA, max(NN,12))


Used to hold the matrix whose eigenvalues are to be computed.  On exit, A contains the last matrix actually used.




LDA




LDA is INTEGER


The leading dimension of A, and H. LDA must be at least 1 and at least max( NN, 12 ). (12 is the dimension of the largest matrix on the precomputed input file.)




H




H is COMPLEX array, dimension (LDA, max(NN,12))


Another copy of the test matrix A, modified by CGEEVX.




W




W is COMPLEX array, dimension (max(NN,12))


Contains the eigenvalues of A.




W1




W1 is COMPLEX array, dimension (max(NN,12))


Like W, this array contains the eigenvalues of A, but those computed when CGEEVX only computes a partial eigendecomposition, i.e. not the eigenvalues and left and right eigenvectors.




VL




VL is COMPLEX array, dimension (LDVL, max(NN,12))


VL holds the computed left eigenvectors.




LDVL




LDVL is INTEGER


Leading dimension of VL. Must be at least max(1,max(NN,12)).




VR




VR is COMPLEX array, dimension (LDVR, max(NN,12))


VR holds the computed right eigenvectors.




LDVR




LDVR is INTEGER


Leading dimension of VR. Must be at least max(1,max(NN,12)).




LRE




LRE is COMPLEX array, dimension (LDLRE, max(NN,12))


LRE holds the computed right or left eigenvectors.




LDLRE




LDLRE is INTEGER


Leading dimension of LRE. Must be at least max(1,max(NN,12))




RCONDV




RCONDV is REAL array, dimension (N)


RCONDV holds the computed reciprocal condition numbers for eigenvectors.




RCNDV1




RCNDV1 is REAL array, dimension (N)


RCNDV1 holds more computed reciprocal condition numbers for eigenvectors.




RCDVIN




RCDVIN is REAL array, dimension (N)


When COMP = .TRUE. RCDVIN holds the precomputed reciprocal condition numbers for eigenvectors to be compared with RCONDV.




RCONDE




RCONDE is REAL array, dimension (N)


RCONDE holds the computed reciprocal condition numbers for eigenvalues.




RCNDE1




RCNDE1 is REAL array, dimension (N)


RCNDE1 holds more computed reciprocal condition numbers for eigenvalues.




RCDEIN




RCDEIN is REAL array, dimension (N)


When COMP = .TRUE. RCDEIN holds the precomputed reciprocal condition numbers for eigenvalues to be compared with RCONDE.




SCALE




SCALE is REAL array, dimension (N)


Holds information describing balancing of matrix.




SCALE1




SCALE1 is REAL array, dimension (N)


Holds information describing balancing of matrix.




RESULT




RESULT is REAL array, dimension (11)


The values computed by the eleven tests described above. The values are currently limited to 1/ulp, to avoid overflow.




WORK




WORK is COMPLEX array, dimension (NWORK)




NWORK




NWORK is INTEGER


The number of entries in WORK.  This must be at least max(6*12+2*12**2,6*NN(j)+2*NN(j)**2) = max(    360     ,6*NN(j)+2*NN(j)**2)    for all j.




RWORK




RWORK is REAL array, dimension (2*max(NN,12))




INFO




INFO is INTEGER


If 0, then successful exit. If <0, then input parameter -INFO is incorrect. If >0, CLATMR, CLATMS, CLATME or CGET23 returned an error code, and INFO is its absolute value.








Local Variables and Parameters


ZERO, ONE: Real 0 and 1.


MAXTYP: The number of types defined.


NMAX: Largest value in NN or 12.


NERRS: The number of tests which have exceeded THRESH


COND, CONDS, IMODE: Values to be passed to the matrix generators.


ANORM: Norm of A; passed to matrix generators.


OVFL, UNFL: Overflow and underflow thresholds.


ULP, ULPINV: Finest relative precision and its inverse.


RTULP, RTULPI: Square roots of the previous 4 values.


The following four arrays decode JTYPE:




KTYPE(j)


The general type (1-10) for type j.


KMODE(j)


The MODE value to be passed to the matrix generator for type j.


KMAGN(j)


The order of magnitude ( O(1), O(overflow^(1/2) ), O(underflow^(1/2) ) ).


KCONDS(j)


Selects whether CONDS is to be 1 or 1/sqrt(ulp). (0 means irrelevant.)
