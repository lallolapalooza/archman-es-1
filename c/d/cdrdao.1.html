DESCRIPCIÓ

N

cdrdao crea CD-R de audio y de datos en modo disco completo (DAO) dirigido por un archivo de descripción llamado toc-file. En el modo DAO es posible crear pre-gaps de pistas no estándar que tienen longitudes distintas de 2 segundos y contienen datos de audio no nulos. Esto es, por ejemplo, útil para dividir grabaciones en directo en pistas donde los espacios de 2 segundos serían algo

molestos.

En lugar de un toc-file se puede usar un archivo cue (utilizado por una famosa herramienta de m

asterización de DOS/Windows). Consulte la s
ección ARCHIVOS CUE para más detalles.

OPTIONS

copy
Copies the contents of a CD. The default file placed in the toc-file by read-toc. Use "-" to indicate STDIN. For commands read-cd and copy it specifies the name of the created image file.
--read-raw
Only used for commands read-cd and read-toc. All data sectors will be written as 2352 byte blocks including the sector header and L-EC data to the image file. The track mode will be set to MODE1_RAW or MODE2_RAW in the created toc-file.
--read-subchan mode
Used by commands read-cd, read-toc and copy. Specifies the type of sub-channel data that is extracted from the source CD and written to the track image or copied to the destination CD. Mode may be rw for reading packed R-W sub-channel data (de-interleaved and error corrected) and rw_raw for reading raw R-W sub-channel data (not de-interleaved, not error corrected, L-EC data included in the track image). If this option is not specified no sub-channel data will be extracted.
--no-mode2-mixed
Only used for commands read-cd and read-toc. If we have MODE2_FORM1 or MODE2_FORM2, don't extract it as MODE2_FORM_MIX. toc-file.
--tao-source
This option indicates to the commands read-toc and read-cd that the source CD was written in TAO mode. It will be assumed that the pre-gap length between all tracks (except between two audio tracks) is the standard 150 blocks plus the number of link blocks (usually 2). The number of link blocks can be controlled with option --tao-source-adjust.

Use this option only if read-toc or read-cd give error messages in the transition areas between two tracks. If you use this option with pressed CDs or CDs written in DAO mode you will get wrong results.

--tao-source-adjust link-blocks
Specifies the number of link blocks for tracks written in TAO mode. This option has only an effect if option --tao-source is given.
--fast-toc
Only used for command read-toc. This option suppresses the pre-gap length and index mark extraction which speeds up the read-toc process. Standard 2 second pre-gaps (but no silence!) will be placed into the toc-file. The resulting CD will sound like the source CD. Only the CD player's display will behave slightly different in the transition area between two tracks.

This option might help, too, if read-toc fails with your drive otherwise.

--buffers buffer-count
Specifies the number of buffers that are allocated to avoid buffer under runs. The minimal buffer count is fixed to 10, default is 32 except on FreeBSD systems, on which default is 20. Each buffer holds 1 second of audio data so that dividing buffer-count by the writing speed gives the maximum time for which reading of audio data may be stalled.
--multi
If this option is given the session will not be closed after the audio data is successfully written. It is possible to append another session on such disks, e.g. to create a CD-EXTRA.
--overburn
By default cdrdao will not allow one to write more data on a medium than specified by the current medium. This option allows to ignore this condition.
--eject
Eject the CD-R after writing or write simulation.
--swap
Swap the byte order of all samples that are send to the CD-recorder.
--session session-nr
Used for read-toc and read-cd to specify the session which should be processed on multi session CDs.
--reload
Indicates that the tray may be opened before writing without prompting the user to reset the disk status after a simulation run.
--force
Forces the execution of an operation that otherwise would not be performed.
--paranoia-mode mode
Sets the correction mode for digital audio extraction. 0: No checking, data is copied directly from the drive. 1: Perform overlapped reading to avoid jitter. 2: Like 1 but with additional checks of the read audio data. 3: Like 2 but with additional scratch detection and repair.

The extraction speed reduces from 0 to 3.

Default is the full paranoia mode (3).

Perform CD copy on the fly without creating an image file.

ARCHIVOS TOC

El archivo toc describe qué datos se graban en el CD-R y permite controlar las posiciones de pista/índice, pre-gaps y la información del subcanal. Es un archivo de texto simple, usa tu editor de texto favorito para crearlo.

Un archivo toc contiene una cabecera opcional y una secuencia de especificaciones de pista. Los comentarios que comienzan con '//' hasta el final de la línea se pueden colocar en cualquier lugar.

Cabecera

CATALOG "ddddddddddddd"
Especifica el número de catálogo opcional del CD. La cadena debe contener exactamente 13 dígitos.

Las siguientes banderas especifican el tipo de sesión que se creará. Se utiliza para crear el formato correcto de TOC de CD y para verificar la consistencia de los modos de pista para el tipo de sesión deseado. Si se dan varias banderas, la última tendrá efecto.

CD_DA
El disco contiene solo pistas de audio.
CD_ROM
El disco contiene solo pistas de modo 1 o pistas de modo 1 y audio (CD de modo mixto).
CD_ROM_XA
El disco contiene pistas de modo 2 forma 1 o modo 2 forma 2. También se permiten pistas de audio. Este tipo debe usarse si se crean discos de múltiples sesiones (opción --multi).
CD_TEXT { ... }
Define datos globales de CD-TEXT como el título del álbum y los idiomas utilizados. Consulte la sección CD-TEXT a continuación para ver la sintaxis del contenido del bloque CD-TEXT.

CDDA AUDIO Y CD-TEXT

CDDA audio tracks consist of raw audio data. The cdrdao program understands these raw audio files. Raw audio files are not contained in RIFF/WAVE headers. The toc-file may contain CD-TEXT information. CD-TEXT is a superset of the old CD-PLUS standard. CD-TEXT information is only written to audio tracks.

CD_DA
CD_TEXT {
  LANGUAGE_MAP {
    0 : EN
  }
  LANGUAGE 0 {
    TITLE "CD Title"
    PERFORMER "Performer"
    DISC_ID "XY12345"
    UPC_EAN ""
  }
}
TRACK AUDIO
ISRC "DEXXX9800001"
CD_TEXT {
  LANGUAGE 0 {
    TITLE "Track Title"
    PERFORMER "Performer"
    ISRC "DE-XXX-98-00001"

ARCHIVOS CUE

Los archivos Cue pueden usarse donde se espere un archivo toc. El archivo bin correspondiente no se toma de la declaración FILE de un archivo cue, sino que se construye a partir del nombre del archivo cue reemplazando ".cue" por ".bin". El archivo cue debe tener exactamente una declaración FILE.

Actualmente, se admiten los siguientes modos de pista: MODE1/2048, MODE1/2352, MODE2/2336, MODE2/2352. Las declaraciones CATALOG, ISRC y POSTGAP se analizan pero aún no se evalúan.

CONFIGURACIÓN

Algunas de las opciones de la línea de comandos se pueden almacenar como configuraciones en las siguientes ubicaciones. Los archivos se leerán al iniciar cdrdao en ese orden:

1. /etc/cdrdao.conf

2. /etc/defaults/cdrdao

3. /etc/default/cdrdao

4. $HOME/.cdrdao

Las opciones de la línea de comandos anularán la configuración cargada. El archivo de configuración contiene pares nombre - valor separados por dos puntos. Los valores de cadena deben ir entre comillas. El archivo se escribe automáticamente si se utiliza la opción de línea de comandos --save, pero también es posible modificarlo manualmente. Se definen los siguientes valores:

write_device
Dispositivo utilizado para las operaciones simulate, write, copy, blank, disk-info y unlock. Opción correspondiente: --device
write_driver
Controlador (incluidas las opciones del controlador) que se utiliza para las operaciones simulate, write, copy, blank, disk-info y unlock. Opción correspondiente: --driver
write_speed
Especifica la velocidad de escritura. Opción correspondiente: --speed
write_buffers
Especifica los búferes fifo utilizados para la grabación. Opción correspondiente: --buffers
read_device
Dispositivo utilizado para las operaciones read-toc, read-cd y copy. Opción correspondiente: --device o --source-device
read_driver
Controlador (incluidas las opciones del controlador) utilizado para las operaciones read-toc, read-cd y copy. Opción correspondiente: --driver o --source-driver
read_paranoia_mode
Modo paranoia utilizado para las operaciones read-cd y copy. Opción correspondiente: --paranoia-mode
cddb_server_list
Lista de servidores CDDB para read-cddb. Opción correspondiente: --cddb-servers
cddb_timeout
Tiempo de espera de conexión CDDB en segundos utilizado por read-cddb. Opción correspondiente: --cddb-timeout
cddb_directory
Directorio local donde se almacenarán los registros CDDB obtenidos, utilizado por read-cddb. Opción correspondiente: --cddb-directory
tmp_file_dir
Directorio donde se crearán archivos WAV temporales a partir de la decodificación de archivos MP3 y Ogg Vorbis. Opción correspondiente: --tmpdir

ERRORES

Si el programa se termina durante el proceso de escritura/simulación, los recursos IPC utilizados pueden no liberarse. Utilice ipcs(8) e ipcrm(8) para eliminarlos.
