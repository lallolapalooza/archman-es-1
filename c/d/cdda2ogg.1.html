cdda2ogg(1) Manual de Comandos Generales cdda2ogg(1)

NOMBRE

cdda2ogg, cdda2mp3 - extraer pistas de CD y codificarlas

SINOPSIS

cdda2ogg [ opciones ][ dev=dispositivo ] [prefijo de archivo] [opciones ogg]

cdda2mp3 [ opciones ][ dev=dispositivo ] [prefijo de archivo] [opciones lame]

DESCRIPCIÓN

cdda2ogg es un script que utiliza el comando cdda2wav para extraer todas las pistas de audio con el comando cdda2wav y codificarlas usando el codificador Ogg Vorbis oggenc(1).

cdda2mp3 es un script que utiliza el comando cdda2wav para extraer todas las pistas de audio con el comando cdda2wav y codificarlas usando el codificador MP3 lame(1).

Aún no hay soporte para CDDB.

OPCIONES

-help
muestra un breve mensaje de uso en línea y sale.
dev=dispositivo
El dispositivo desde el cual leer los datos. Si solo hay una unidad de CD-ROM en el sistema, se puede omitir la opción dev=. Para valores posibles del parámetro dispositivo, consulte la página del manual de cdrecord(1).
-*
Cualquier otra opción que comience con un guión ('-') se pasará al programa cdda2wav.

Cualquier otra opción posterior al argumento prefijo de archivo y que comience con un guión ('-') se pasará al programa codificador.

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden usarse para cambiar el comportamiento de los comandos cdda2ogg y cdda2mp3:

CDDA2WAV
Define el comando para extraer datos WAV del CD. El valor por defecto es cdda2wav.
CDDA2WAV_OPTS
Define las opciones que se pasan al programa CDDA al extraer del CD. El valor por defecto es -H -q.
MP_CODER
El programa codificador utilizado para comprimir los datos de audio. El valor por defecto es oggenc para cdda2ogg y lame para cdda2mp3.
MP_OPTIONS
Opciones que se pasan al programa codificador. El valor por defecto está vacío.
FILEPREFIX
La parte base del nombre del archivo para los archivos de audio resultantes. El nombre de archivo por defecto es $TRACK-$FILEPREFIX.ogg para cdda2ogg y $TRACK-$FILEPREFIX.mp3 para cdda2mp3 si no se proporcionó un argumento prefijo de archivo en la línea de comandos.

ARCHIVOS

Si los siguientes archivos están presentes, los scripts los procesan para establecer valores predeterminados locales:

/etc/default/cdda2ogg
Para establecer valores predeterminados para cdda2ogg.
/etc/default/cdda2mp3
Para establecer valores predeterminados para cdda2mp3.

El contenido puede configurarse para modificar variables de entorno o para establecer valores predeterminados locales.

VER TAMBIÉN

cdda2wav(1), cdrecord(1), oggenc(1), lame(1).

NOTAS

Si un CD contiene una pista de audio oculta antes de la pista 1, se crea un archivo con el número de pista 00 con el contenido de la pista oculta.

El programa oggenc(1) forma parte del proyecto vorbis-tools. Consulte http://www.vorbis.com para más información.

El programa lame(1) forma parte del proyecto lame. Consulte http://lame.sourceforge.net/ para más información.

AUTOR

Las primeras versiones de los scripts se basaron en un artículo de noticias de Tom Kludy.
