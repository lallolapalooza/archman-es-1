CD-IT8(1) Comandos de usuario CD-IT8(1)

NOMBRE

cd-it8 - Herramienta de prueba del gestor de color

SINOPSIS

cd-it8 [--verbose]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando cd-it8.

cd-it8 permite a un administrador modificar archivos IT8, como .sp, .ti1, .ti3, .ccmx de diversas maneras.

OPCIONES

Este programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (‘-’). A continuación se incluye un resumen de las opciones.
