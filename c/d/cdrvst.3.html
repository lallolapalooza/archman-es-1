T

Propósito

: 
!>
!>      CDRVST comprueba los controladores del problema de autovalores hermitiano.
!>
!>              CHEEVD calcula todos los autovalores y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja,
!>              usando un algoritmo de divide y vencerás.
!>
!>              CHEEVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja.
!>
!>              CHEEVR calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja
!>              usando la Representación Relativamente Robusta cuando es posible.
!>
!>              CHPEVD calcula todos los autovalores y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja en almacenamiento
!>              empaquetado, usando un algoritmo de divide y vencerás.
!>
!>              CHPEVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja en almacenamiento
!>              empaquetado.
!>
!>              CHBEVD calcula todos los autovalores y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja de banda,
!>              usando un algoritmo de divide y vencerás.
!>
!>              CHBEVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja de banda.
!>
!>              CHEEV calcula todos los autovalores y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja.
!>
!>              CHPEV calcula todos los autovalores y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja en almacenamiento
!>              empaquetado.
!>
!>              CHBEV calcula todos los autovalores y, opcionalmente,
!>              autovectores de una matriz hermitiana compleja de banda.
!>
!>      Cuando se llama a CDRVST, se especifica un número de tamaños de matriz  () y un
!>      número de tipos de matriz.  Para cada tamaño ()
!>      y cada tipo de matriz, se generará una matriz y se usará
!>      para probar los controladores apropiados.  Para cada matriz y cada
!>      rutina controladora llamada, se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de autovectores devuelta cuando se
!>      da la opción de autovectores y D1 y D2 son los autovalores
!>      devueltos con y sin la opción de autovectores.
!>
!>      Los  se especifican por un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los  se especifican por un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con elementos espaciados uniformemente
!>           1, ..., ULP  y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con elementos espaciados geométricamente
!>           1, ..., ULP  y signos aleatorios.
!>      (5)  Una matriz diagonal con  elementos 1, ULP, ..., ULP
!>           y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!>      (8)  Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene elementos espaciados uniformemente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (9)  Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene elementos espaciados geométricamente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene  elementos 1, ULP,..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!>      (13) Matriz simétrica con elementos aleatorios elegidos de (-1,1).
!>      (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>      (16) Una matriz de banda con semiancho de banda elegido aleatoriamente entre
!>           0 y N-1, con autovalores espaciados uniformemente 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!
> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a usar.  Si es cero,
!>          CDRVST no hace nada.  Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos.  Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, CDRVST
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que esté en A.  Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  array LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no serán generados.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>          serán ignorados.
!>          No modificado.
!>
!>  ISEED   array INTEGER, dimensión (4)
!>          En la entrada ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, serán reducidos mod 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se cambian en la salida, y pueden usarse en la
!>          siguiente llamada a CDRVST para continuar la misma secuencia de números aleatorios
!>          secuencia.
!>          Modificado.
!>
!>  THRESH  REAL
!>          Una prueba contará como si el , calculado como
!>          se describe arriba, excede THRESH. Tenga en cuenta que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>          No modificado.
!>
!>  NOUNIT  INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0.)
!>          No modificado.
!>
!>  A       Arreglo COMPLEX, dimensión (LDA , max(NN))
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular. Al salir, A contiene la última matriz realmente
!>          utilizada.
!>          Modificado.
!>
!>  LDA     INTEGER
!>          La dimensión principal de A. Debe ser al
!>          menos 1 y al menos max( NN ).
!>          No modificado.
!>
!>  D1      Arreglo REAL, dimensión (max(NN))
!>          Los valores propios de A, calculados por CSTEQR simultáneamente
!>          con Z. Al salir, los valores propios en D1 corresponden con la
!>          matriz en A.
!>          Modificado.
!>
!>  D2      Arreglo REAL, dimensión (max(NN))
!>          Los valores propios de A, calculados por CSTEQR si Z no se
!>          calcula. Al salir, los valores propios en D2 corresponden con
!>          la matriz en A.
!>          Modificado.
!>
!>  D3      Arreglo REAL, dimensión (max(NN))
!>          Los valores propios de A, calculados por SSTERF. Al salir, los
!>          valores propios en D3 corresponden con la matriz en A.
!>          Modificado.
!>
!>  WA1     Arreglo REAL, dimensión
!>
!>  WA2     Arreglo REAL, dimensión
!>
!>  WA3     Arreglo REAL, dimensión
!>
!>  U       Arreglo COMPLEX, dimensión (LDU, max(NN))
!>          La matriz unitaria calculada por CHETRD + CUNGC3.
!>          Modificado.
!>
!>  LDU     INTEGER
!>          La dimensión principal de U, Z y V. Debe ser al
!>          menos 1 y al menos max( NN ).
!>          No modificado.
!>
!>  V       Arreglo COMPLEX, dimensión (LDU, max(NN))
!>          Los vectores de Householder calculados por CHETRD al reducir A a
!>          forma tridiagonal.
!>          Modificado.
!>
!>  TAU     Arreglo COMPLEX, dimensión (max(NN))
!>          Los factores de Householder calculados por CHETRD al reducir A
!>          a forma tridiagonal.
!>          Modificado.
!>
!>  Z       Arreglo COMPLEX, dimensión (LDU, max(NN))
!>          La matriz unitaria de vectores propios calculada por CHEEVD,
!>          CHEEVX, CHPEVD, CHPEVX, CHBEVD y CHBEVX.
!>          Modificado.
!>
!>  WORK  - Arreglo COMPLEX de dimensión ( LWORK )
!>           Espacio de trabajo.
!>           Modificado.
!>
!>  LWORK - INTEGER
!>           El número de entradas en WORK. Debe ser al menos
!>           2*max( NN(j), 2 )**2.
!>           No modificado.
!>
!>  RWORK   Arreglo REAL de dimensión (3*max(NN))
!>           Espacio de trabajo.
!>           Modificado.
!>
!>  LRWORK - INTEGER
!>           El número de entradas en RWORK.
!>
!>  IWORK   Arreglo INTEGER de dimensión (6*max(NN))
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  LIWORK - INTEGER
!>           El número de entradas en IWORK.
!>
!>  RESULT  Arreglo REAL de dimensión (??)
!>          Los valores calculados por las pruebas descritas anteriormente.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!>          Modificado.
!>
!>  INFO    INTEGER
!>          Si 0, entonces todo funcionó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algún NN(j) < 0
!>           -3: NTYPES < 0
!>           -5: THRESH < 0
!>           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>          -16: LDU < 1 o LDU < NMAX.
!>          -21: LWORK demasiado pequeño.
!>          Si SLATMR, SLATMS, CHETRD, SORGC3, CSTEQR, SSTERF,
!!>              o SORMC2 devuelven un código de error, el
!>              valor absoluto de este se devuelve.
!>          Modificado.
!>
!>-----------------------------------------------------------------------
!>
!>       Algunas variables y parámetros locales:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Reales 0 y 1.
!>       MAXTYP          El número de tipos definidos.
!>       NTEST           El número de pruebas realizadas, o que pueden
!>                       ser realizadas hasta ahora, para la matriz actual.
!>       NTESTT          El número total de pruebas realizadas hasta ahora.
!>       NMAX            Valor más grande en NN.
!>       NMATS           El número de matrices generadas hasta ahora.
!>       NERRS           El número de pruebas que han excedido THRESH
!>                       hasta ahora (calculado por SLAFTS).
!>       COND, IMODE     Valores para pasar a los generadores de matrices.
!>       ANORM           Norma de A; pasado a los generadores de matrices.
!>
!>       OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>       ULP, ULPINV     Precisión relativa más fina y su inversa.
!>       RTOVFL, RTUNFL  Raíces cuadradas de los dos valores anteriores.
!>               Los siguientes cuatro arreglos decodifican JTYPE:
!>       KTYPE(j)        El tipo general (1-10) para el tipo .
!>       KMODE(j)        El valor MODE para pasar al generador de matrices
!>                       para el tipo .
!>       KMAGN(j)        El orden de magnitud ( O(1),
!>                       O(desbordamiento^(1/2) ), O(subdesbordamiento^(1/2) )
!>
