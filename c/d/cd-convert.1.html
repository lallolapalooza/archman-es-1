CD-CONVERT(1) Comandos de usuario CD-CONVERT(1)

NOMBRE

cd-convert - Herramienta de prueba del gestor de color

SINOPSIS

cd-convert [--verbose]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando cd-convert.

cd-convert permite a un administrador crear archivos IT8, como .ti3, .ccmx de varias maneras.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.
