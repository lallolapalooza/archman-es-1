!>    CDRVVX comprueba el controlador experto del problema de eigenvalores no simétrico

!>
!>    CDRVVX utiliza tanto matrices de prueba generadas aleatoriamente dependiendo de
!>    los datos proporcionados en la secuencia de llamada, como datos

!>    precalculados con los que compara los que él calcula.
!>
!>    Cuando se llama a CDRVVX, se especifican un número de matrices  () y un
!>    número de matrices  en la secuencia de llamada.

!>
!>      Aquí VL es la matriz de autovectores izquierdos unitarios, A**H es la
!>    transpuesta conjugada de A, y W es como arriba.

!>    (3)     | |VR(i)| - 1 | / ulp y el componente más grande real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y el componente más grande real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     W(full) = W(partial)
!>
!>      W(full) denota los eigenvalores calculados cuando también se calculan VR, VL, RCONDV
!>      y RCONDE, y W(partial) denota los
!>      eigenvalores calculados cuando solo se calculan algunos de VR, VL, RCONDV y
!>      RCONDE.
!>
!>    (6)     VR(full) = VR(partial)
!>
!>      VR(full) denota los autovectores derechos calculados cuando se calculan VL, RCONDV
!>      y RCONDE, y VR(partial) denota el resultado
!>      cuando solo se calculan algunos de VL y RCONDV.
!>
!>    (7)     VL(full) = VL(partial)
!>
!>      VL(full) denota los autovectores izquierdos calculados cuando se calculan VR, RCONDV

NAME
       CGEEVX - Computes the eigenvalues and left and right eigenvectors of a general complex matrix.

SYNOPSIS
       SUBROUTINE CGEEVX( JOBVL, JOBVR, N, A, LDA, W, VL, LDVL, VR, LDVR,
                          TAU, WORK, LWORK, RWORK, INFO )

       INTEGER INFO
       INTEGER LDA, LDVL, LDVR, N, LWORK
       REAL RWORK(*)
       COMPLEX A( LDA, * ), W( * ), VL( LDVL, * ), VR( LDVR, * ),
       &             TAU( * ), WORK( LWORK )
       CHARACTER          JOBVL, JOBVR

PARAMETERS
       JOBVL   (input) CHARACTER*1
               Specifies whether to compute the left eigenvectors.
               = 'N': Do not compute the left eigenvectors.
               = 'V': Compute the left eigenvectors.

       JOBVR   (input) CHARACTER*1
               Specifies whether to compute the right eigenvectors.
               = 'N': Do not compute the right eigenvectors.
               = 'V': Compute the right eigenvectors.

       N       (input) INTEGER
               The order of the matrix A. N >= 0.

       A       (input/output) COMPLEX array, dimension (LDA,N)
               On entry, the N-by-N matrix A.
               On exit, the matrix A has been destroyed.

       LDA     (input) INTEGER
               The leading dimension of A. LDA >= max(1,N).

       W       (output) COMPLEX array, dimension (N)
               The computed eigenvalues, each stored in the array element
               that corresponds to the order of the eigenvectors in VL and VR.

       VL      (output) COMPLEX array, dimension (LDVL,N)
               If JOBVL = 'V', VL contains the left eigenvectors of A,
               with the i-th vector stored in the i-th column of VL.
               If JOBVL = 'N', VL is not used.

       LDVL    (input) INTEGER
               The leading dimension of VL.
               If JOBVL = 'V', LDVL >= max(1,N).

       VR      (output) COMPLEX array, dimension (LDVR,N)
               If JOBVR = 'V', VR contains the right eigenvectors of A,
               with the i-th vector stored in the i-th column of VR.
               If JOBVR = 'N', VR is not used.

       LDVR    (input) INTEGER
               The leading dimension of VR.
               If JOBVR = 'V', LDVR >= max(1,N).

       TAU     (output) COMPLEX array, dimension (N)
               The imaginary parts of the eigenvalues of A, such that the i-th
               eigenvalue is W(i) + i*TAU(i).

       WORK    (workspace) COMPLEX array, dimension (LWORK)
               On exit, WORK(1) contains the minimum required value of LWORK.

       LWORK   (input) INTEGER
               The dimension of the array WORK.
               If LWORK = -1, then a workspace query is assumed and the
               routine only calculates the minimum size needed for LWORK.
               The minimum size is max(2*N, 6*N + 2*N*iimag(i) + 2*N**2),
               where iimag(i) is the imaginary part of the i-th eigenvalue.

       RWORK   (workspace) REAL array, dimension (5*N)

       INFO    (output) INTEGER
               = 0: successful exit.
               < 0: If -INFO is an argument value, the k-th argument
                    had an illegal value.
               > 0: If INFO = k, and k is not equal to 2*, then the
                    QR algorithm failed to compute all the eigenvalues,
                    and INFO is the number of eigenvalues which could
                    not be computed.
                    If INFO = 2*N, then the Schur decomposition failed,
                    but the eigenvalues were computed successfully.

DESCRIPTION
       This routine computes the eigenvalues and the left and right eigenvectors
       of a general complex square matrix A of order N.

       The left eigenvectors are the rows of the matrix L such that L*A = diag(W)*L,
       and the right eigenvectors are the columns of the matrix R such that A*R = R*diag(W).

       The condition number of the eigenvalue computation is estimated by
       RCONDE, and the condition number of the eigenvector computation is
       estimated by RCONDV.

       If JOBVL='V', the left eigenvectors are normalized to the form
       L*A = diag(W)*L.
       If JOBVR='V', the right eigenvectors are normalized to the form
       A*R = R*diag(W).

       The eigenvalue and eigenvector problems are solved using the QR algorithm.
       The matrix is first reduced to upper triangular form (Schur form)
       and then the QR algorithm is applied to the triangular matrix.
       The eigenvectors are computed by computing the eigenvectors of the
       triangular matrix and then transforming them back to the original basis.

       The condition number estimation is performed using the algorithm
       described in the following paper:

       "Estimating the Condition Number of a Complex General Matrix"
       by Demmel and Kagstrom, BIT 23 (1983), pp. 247-260.

       The reciprocal condition number for eigenvalues is computed by
       RCONDE and RCNDE1. The reciprocal condition number for the
       eigenvectors is computed by RCONDV and RCNDV1.

       The array TAU is used to store the imaginary parts of the computed
       eigenvalues, i.e., the i-th eigenvalue is W(i) + i*TAU(i).

       The routine uses LAPACK routines DLAMC3, DLASCL, ZLATME, ZLACPY, ZLACON,
       ZGEESX, ZTREVC, ZGEBAL, ZGEGS.

       The tests are performed as follows:
       1.  Eigenvalues: Compare the computed eigenvalues with the precomputed
           eigenvalues supplied in the input file.
       2.  Left eigenvectors: Check if L*A is approximately equal to diag(W)*L.
       3.  Right eigenvectors: Check if A*R is approximately equal to R*diag(W).
       4.  Left eigenvector condition numbers: Compare the computed reciprocal
           condition numbers for left eigenvectors with the precomputed values.
       5.  Right eigenvector condition numbers: Compare the computed reciprocal
           condition numbers for right eigenvectors with the precomputed values.

       The input file specified by NIUNIT contains matrices along with precomputed
       eigenvalues, eigenvectors, and reciprocal condition numbers. For each
       matrix in the file, the routine performs the following tests:

       (1)  |W_computed - W_true| / cond(W_computed)
            cond(W_computed) is the condition number of W_computed.

       (2)  || L*A - diag(W)*L || / (N * cond(L) * ||A||)
            cond(L) is the condition number of L.

       (3)  || A*R - R*diag(W) || / (N * cond(R) * ||A||)
            cond(R) is the condition number of R.

       (4)  |RCONDE - RCDEIN| / cond(RCONDE)
            RCONDE is the reciprocal eigenvalue condition number computed by CGEEVX,
            and RCDEIN is the precomputed true value. cond(RCONDE) is the condition
            number of RCONDE, and takes errors in computing RCONDE into account,
            so that the resulting quantity should be O(ULP). cond(RCONDE) is
            essentially given by norm(A)/RCONDV.

       (5)  |RCONDV - RCDVIN| / cond(RCONDV)
            RCONDV is the reciprocal right eigenvector condition number computed by CGEEVX,
            and RCDVIN is the precomputed true value. cond(RCONDV) is the condition
            number of RCONDV, and takes errors in computing RCONDV into account,
            so that the resulting quantity should be O(ULP). cond(RCONDV) is
            essentially given by norm(A)/RCONDE.

       In addition to these tests, the routine also performs tests on matrices
       generated randomly with different properties, such as near-singular matrices,
       matrices with large or small norms, and matrices with overflow or underflow
       potential.

       The following tests are performed for randomly generated matrices:

       (6)  Same as (1), but for eigenvalues computed when only a partial
            eigendecomposition is performed (e.g., not computing eigenvectors).

       (7)  Same as (2), but for left eigenvectors computed when only a partial
            eigendecomposition is performed.

       (8)  Same as (3), but for right eigenvectors computed when only a partial
            eigendecomposition is performed.

       (9)  Same as (4), but for eigenvalues computed when only a partial
            eigendecomposition is performed.

       (10) Same as (5), but for right eigenvectors computed when only a partial
            eigendecomposition is performed.

       (11) Same as (4), but multiplied by a constant near the overflow threshold.

       (12) Same as (4), but multiplied by a constant near the underflow threshold.

       (13) Same as (5), but multiplied by a constant near the overflow threshold.

       (14) Same as (5), but multiplied by a constant near the underflow threshold.

       In addition, an input file will be read from logical unit number
       NIUNIT. The file contains matrices along with precomputed
       eigenvalues and reciprocal condition numbers for the eigenvalues
       and right eigenvectors. For these matrices, in addition to tests
       (1) to (9) we will compute the following two tests:

       (10)  |RCONDV - RCDVIN| / cond(RCONDV)

          RCONDV is the reciprocal right eigenvector condition number
          computed by CGEEVX and RCDVIN (the precomputed true value)
          is supplied as input. cond(RCONDV) is the condition number of
          RCONDV, and takes errors in computing RCONDV into account, so
          that the resulting quantity should be O(ULP). cond(RCONDV) is
          essentially given by norm(A)/RCONDE.

       (11)  |RCONDE - RCDEIN| / cond(RCONDE)

          RCONDE is the reciprocal eigenvalue condition number
          computed by CGEEVX and RCDEIN (the precomputed true value)
          is supplied as input.  cond(RCONDE) is the condition number
          of RCONDE, and takes errors in computing RCONDE into account,
          so that the resulting quantity should be O(ULP). cond(RCONDE)
          is essentially given by norm(A)/RCONDV.

PARAMETERS
       NSIZES
              NSIZES is INTEGER
              The number of sizes of matrices to use.  NSIZES must be at
              least zero. If it is zero, no randomly generated matrices
              are tested, but any test matrices read from NIUNIT will be
              tested.

       NN
              NN is INTEGER array, dimension (NSIZES)
              An array containing the sizes to be used for the matrices.
              Zero values will be skipped.  The values must be at least
              zero.

       NTYPES
              NTYPES is INTEGER
              The number of elements in DOTYPE. NTYPES must be at least
              zero. If it is zero, no randomly generated test matrices
              are tested, but and test matrices read from NIUNIT will be
              tested. If it is MAXTYP+1 and NSIZES is 1, then an
              additional type, MAXTYP+1 is defined, which is to use
              whatever matrix is in A.  This is only useful if
              DOTYPE(1:MAXTYP) is .FALSE. and DOTYPE(MAXTYP+1) is .TRUE. .

       DOTYPE
              DOTYPE is LOGICAL array, dimension (NTYPES)
              If DOTYPE(j) is .TRUE., then for each size in NN a
              matrix of that size and of type j will be generated.
              If NTYPES is smaller than the maximum number of types
              defined (PARAMETER MAXTYP), then types NTYPES+1 through
              MAXTYP will not be generated.  If NTYPES is larger
              than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
              will be ignored.

       ISEED
              ISEED is INTEGER array, dimension (4)
              On entry ISEED specifies the seed of the random number
              generator. The array elements should be between 0 and 4095;
              if not they will be reduced mod 4096.  Also, ISEED(4) must
              be odd.  The random number generator uses a linear
              congruential sequence limited to small integers, and so
              should produce machine independent random numbers. The
              values of ISEED are changed on exit, and can be used in the
              next call to CDRVVX to continue the same random number
              sequence.

       THRESH
              THRESH is REAL
              A test will count as  if the , computed as
              described above, exceeds THRESH.  Note that the error
              is scaled to be O(1), so THRESH should be a reasonably
              small multiple of 1, e.g., 10 or 100.  In particular,
              it should not depend on the precision (single vs. double)
              or the size of the matrix.  It must be at least zero.

       NIUNIT
              NIUNIT is INTEGER
              The FORTRAN unit number for reading in the data file of
              problems to solve.

       NOUNIT
              NOUNIT is INTEGER
              The FORTRAN unit number for printing out error messages
              (e.g., if a routine returns INFO not equal to 0.)

       A
              A is COMPLEX array, dimension (LDA, max(NN,12))
              Used to hold the matrix whose eigenvalues are to be
              computed.  On exit, A contains the last matrix actually used.

       LDA
              LDA is INTEGER
              The leading dimension of A, and H. LDA must be at
              least 1 and at least max( NN, 12 ). (12 is the
              dimension of the largest matrix on the precomputed
              input file.)

       H
              H is COMPLEX array, dimension (LDA, max(NN,12))
              Another copy of the test matrix A, modified by CGEEVX.

       W
              W is COMPLEX array, dimension (max(NN,12))
              Contains the eigenvalues of A.

       W1
              W1 is COMPLEX array, dimension (max(NN,12))
              Like W, this array contains the eigenvalues of A,
              but those computed when CGEEVX only computes a partial
              eigendecomposition, i.e. not the eigenvalues and left
              and right eigenvectors.

       VL
              VL is COMPLEX array, dimension (LDVL, max(NN,12))
              VL holds the computed left eigenvectors.

       LDVL
              LDVL is INTEGER
              Leading dimension of VL. Must be at least max(1,max(NN,12)).

       VR
              VR is COMPLEX array, dimension (LDVR, max(NN,12))
              VR holds the computed right eigenvectors.

       LDVR
              LDVR is INTEGER
              Leading dimension of VR. Must be at least max(1,max(NN,12)).

       LRE
              LRE is COMPLEX array, dimension (LDLRE, max(NN,12))
              LRE holds the computed right or left eigenvectors.

       LDLRE
              LDLRE is INTEGER
              Leading dimension of LRE. Must be at least max(1,max(NN,12))

       RCONDV
              RCONDV is REAL array, dimension (N)
              RCONDV holds the computed reciprocal condition numbers
              for eigenvectors.

       RCNDV1
              RCNDV1 is REAL array, dimension (N)
              RCNDV1 holds more computed reciprocal condition numbers
              for eigenvectors.

       RCDVIN
              RCDVIN is REAL array, dimension (N)
              When COMP = .TRUE. RCDVIN holds the precomputed reciprocal
              condition numbers for eigenvectors to be compared with
              RCONDV.

       RCONDE
              RCONDE is REAL array, dimension (N)
              RCONDE holds the computed reciprocal condition numbers
              for eigenvalues.

       RCNDE1
              RCNDE1 is REAL array, dimension (N)
              RCNDE1 holds more computed reciprocal condition numbers
              for eigenvalues.

       RCDEIN
              RCDEIN is REAL array, dimension (N)
              When COMP = .TRUE. RCDEIN holds the precomputed reciprocal
              condition numbers for eigenvalues to be compared with
              RCONDE.

       SCALE
              SCALE is REAL array, dimension (N)
              Holds information describing balancing of matrix.

       SCALE1
              SCALE1 is REAL array, dimension (N)
              Holds information describing balancing of matrix.

       RESULT
              RESULT is REAL array, dimension (11)
              The values computed by the seven tests described above.
              The values are currently limited to 1/ulp, to avoid
              overflow.

       WORK
              WORK is COMPLEX array, dimension (NWORK)

       NWORK
              NWORK is INTEGER
              The number of entries in WORK.  This must be at least
              max(6*12+2*12**2,6*NN(j)+2*NN(j)**2) =
              max(    360     ,6*NN(j)+2*NN(j)**2)    for all j.

       RWORK
              RWORK is REAL array, dimension (2*max(NN,12))

       INFO
              INFO is INTEGER
              If 0,  then successful exit.
              If <0, then input parameter -INFO is incorrect.
              If >0, CLATMR, CLATMS, CLATME or CGET23 returned an error
                     code, and INFO is its absolute value.
