CD-DRIVE(1) Comandos de usuario CD-DRIVE(1)

NOMBRE

cd-drive - muestra las características de la unidad de CD-ROM

SINOPSIS

cd-drive [OPCIÓN...]

DESCRIPCIÓN

-d, --debug=INT
Establece la depuración en NIVEL
-i, --cdrom-device[=DISPOSITIVO]
muestra solo información sobre el dispositivo CD-ROM
-q, --quiet
No producir salida de advertencia
-V, --version
muestra la versión y la información de copyright y sale

Opciones de ayuda:

-?, --help
Muestra este mensaje de ayuda
--usage
Muestra un breve mensaje de uso

VER TAMBIÉN

cd-info(1) para obtener información sobre el CD dentro de un CD-ROM.
