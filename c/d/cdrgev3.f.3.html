CDRGEV

3

Propósito

: 
!>
!> CDRGEV3 comprueba la rutina controladora del problema de valores propios generalizados no simétricos CGGEV3.
!>
!> CGGEV3 calcula para un par de matrices no simétricas n-por-n (A,B) los valores propios generalizados y, opcionalmente, los vectores propios izquierdos y derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w o una razón alpha/beta = w, tal que A - w*B es singular. Generalmente se representa como el par (alpha,beta), ya que hay una interpretación razonable para beta=0, e incluso para ambos siendo cero.
!>
!> Un vector propio generalizado derecho correspondiente a un valor propio generalizado w para un par de matrices (A,B) es un vector r tal que (A - wB) * r = 0. Un vector propio generalizado izquierdo es un vector l tal que l**H * (A - wB) = 0, donde l**H es la transpuesta conjugada de l.
!>
!> Cuando se llama a CDRGEV3, se especifica un número de tamaños de matriz y un número de tipos de matriz. Para cada tamaño y cada tipo de matriz, se generará un par de matrices (A, B) y se usará para las pruebas. Para cada par de matrices, se realizarán las siguientes pruebas y se compararán con el umbral THRESH.
!>
!> Resultados de CGGEV3:
!>
!> (1)  máximo sobre todos los pares de valores propios izquierdos/-vectores (alpha/beta,l) de
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      donde VL**H es la transpuesta conjugada de VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!> (3)  máximo sobre todos los pares de valores propios izquierdos/-vectores (alpha/beta,r) de
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!> (5)  W(full) = W(partial)
!>      W(full) denota los valores propios calculados cuando tanto l como r también se calculan, y W(partial) denota los valores propios calculados cuando solo se calcula W, solo W y r, o solo W y l.
!>
!> (6)  VL(full) = VL(partial)
!>      VL(full) denota los vectores propios izquierdos calculados cuando tanto l como r se calculan, y VL(partial) denota el resultado cuando solo se calcula l.
!>
!> (7)  VR(full) = VR(partial)
!>      VR(full) denota los vectores propios derechos calculados cuando tanto l como r también se calculan, y VR(partial) denota el resultado cuando solo se calcula l.
!>
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño. Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j. Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una matriz identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una matriz identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       e I es una identidad k x k y J un bloque de Jordan (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde big está cerca del desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores con entradas aleatorias O(1) por encima de la diagonal y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de la máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorios.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares superiores aleatorias.
!>
!
>

Parámetro

s
NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero, CDRGEV3 no hace nada. NSIZES >= 0.
!
>

N

N 
!>          NN es un array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños a usar para las matrices. Los valores cero serán omitidos. NN >= 0.
!
>

NTYPE

S 
!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CDRGEV3t;          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1, el cual
!>          usará la matriz que se encuentre en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no serán generados. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>          serán ignorados.
!
>

ISEE

D 
!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no, serán reducidos módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican en la salida, y pueden usarse en la
!>          siguiente llamada a CDRGEV3 para continuar la misma secuencia de
!>          números aleatorios.
!
>

THRES

H 
!>          THRESH es REAL
!>          Una prueba se considerará fallida si el , calculado como
!>          se describe arriba, excede THRESH. Nótese que el error está
!>          escalado para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100. En particular, no debería
!>          depender de la precisión (simple vs. doble) ni del tamaño
!>          de la matriz. Debe ser al menos cero.
!
>

NOUNI

T 
!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina retorna IERR distinto de 0.)
!
>

A 
!>          A es un arreglo COMPLEX, dimensión(LDA, max(NN))
!>          Usado para contener la matriz original A. Se usa solo como
!>          entrada si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal de A, B, S y T.
!>          Debe ser al menos 1 y al menos max( NN ).
!
>

B 
!>          B es un arreglo COMPLEX, dimensión(LDA, max(NN))
!>          Usado para contener la matriz original B. Se usa solo como
!>          entrada si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

S 
!>          S es un arreglo COMPLEX, dimensión (LDA, max(NN))
!>          La matriz de forma de Schur calculada a partir de A por CGGEV3. En la salida, S
!>          contiene la matriz de forma de Schur correspondiente a la matriz
!>          en A.
!
>

T 
!>          T es un arreglo COMPLEX, dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de B por CGGEV3.
!
>

Q 
!>          Q es un arreglo COMPLEX, dimensión (LDQ, max(NN))
!>          La matriz de autovectores (izquierdos) calculada por CGGEV3.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal de Q y Z. Debe
!>          ser al menos 1 y al menos max( NN ).
!
>

Z 
!>          Z es un arreglo COMPLEX, dimensión( LDQ, max(NN) )
!>          La matriz ortogonal (derecha) calculada por CGGEV3.
!
>

Q

E 
!>          QE es un arreglo COMPLEX, dimensión( LDQ, max(NN) )
!>          QE contiene los autovectores derechos o izquierdos calculados.
!
>

LDQ

E 
!>          LDQE es INTEGER
!>          La dimensión principal de QE. LDQE >= max(1,max(NN)).
!
>

ALPH

A 
!>          ALPHA es un arreglo COMPLEX, dimensión (max(NN))
!
>

BET

A 
!>          BETA es un arreglo COMPLEX, dimensión (max(NN))
!>
!>          Los autovalores generalizados de (A,B) calculados por CGGEV3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) es el k-ésimo
!>          autovalor generalizado de A y B.
!
>

ALPHA

1 
!>          ALPHA1 es un arreglo COMPLEX, dimensión (max(NN))
!
>

BETA

1 
!>          BETA1 es un arreglo COMPLEX, dimensión (max(NN))
!>
!>          Al igual que ALPHAR, ALPHAI, BETA, estos arreglos contienen los
!>          autovalores de A y B, pero aquellos calculados cuando CGGEV3 solo
!>          calcula una descomposición propia parcial, es decir, no los
!>          autovalores y los autovectores izquierdos y derechos.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (LWORK)
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          El número de entradas en WORK.  LWORK >= N*(N+1)
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (8*N)
!>          Espacio de trabajo real.
!
>

RESUL

T 
!>          RESULT es un arreglo REAL, dimensión (2)
!>          Los valores calculados por las pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar desbordamiento.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  Una rutina devolvió un código de error. INFO es el
!>                valor absoluto del valor de INFO devuelto.
!
