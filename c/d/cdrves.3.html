S

Propósito

: 
!>
!>    CDRVES verifica el controlador CGEES del problema de valores propios no simétricos (forma de Schur).
!>
!>    Cuando se llama a CDRVES, se especifican un número de tamaños de matrices () y un número de tipos de matrices. Para cada tamaño () y cada tipo de matriz, se generará una matriz y se usará para probar las rutinas de valores propios no simétricos. Para cada matriz, se realizarán 13 pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenación de valores propios)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de vectores propios de Schur, y T está en forma de Schur (sin ordenación de valores propios).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenación de valores propios).
!>
!>    (4)     0     si W son valores propios de T
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (6)     0     si valores propios(con VS) = valores propios(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de vectores propios de Schur, y T está en forma de Schur (con ordenación de valores propios).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de valores propios).
!>
!>    (10)    0     si W son valores propios de T
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (12)    0     si valores propios(con VS) = valores propios(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            valores propios que fueron SELECCIONADOS
!>
!>    Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!>    Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1's en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicada por una constante cerca
!>         del umbral de desbordamiento
!>    (8)  Igual que (4), pero multiplicada por una constante cerca
!>         del umbral de desbordamiento inferior
!>
!>    (9)  Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas 1, ULP,..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene valores propios complejos elegidos aleatoriamente de
!>         ULP < |z| < 1 y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas 1, ULP,..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios complejos elegidos aleatoriamente
!>         de ULP < |z| < 1 y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (17) Igual que (16), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento
!>    (18) Igual que (16), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento inferior
!>
!>    (19) Matriz no simétrica con entradas elegidas aleatoriamente de (-1,1).
!>         Si N es al menos 4, todas las entradas en las primeras dos filas y la última
!>         fila, y la primera columna y las últimas dos columnas son cero.
!>    (20) Igual que (19), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento
!>    (21) Igual que (19), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento inferior
!
>

NAME


cdrves - performs a series of tests for the subroutine CGEES, which
  computes the eigenvalues and the Schur factorization of a complex general matrix.






SYNOPSIS


SUBROUTINE CDRVES( NSIZES, NN, NTYPES, THRESH, NOUNIT, A, LDA, H, HT, W,
&                   WT, VS, LDVS, RESULT, WORK, NWORK, RWORK, IWORK,
&                   BWORK, INFO )



Parameters:


  CHARACTER * ( * )  A, H, HT, W, WT, VS, WORK
  INTEGER            INFO, LDA, LDVS, NMAX, NOUNIT, NNS, NNT, NSIZES,
&                    NWORK
  INTEGER            IWORK( * )
  REAL               RESULT( * ), RWORK( * ), THRESH
  COMPLEX            A( * ), H( * ), HT( * ), W( * ), WT( * ),
&                    VS( * ), WORK( * )



This subroutine is called, in this order, by the following
  subroutines:

  CDRVER DRIVER ROUTINE FOR CGEES









Function/Subroutine Documentation


NSIZES


!>          NSIZES is INTEGER
!>          The number of values in the array NN.
!> 


NN


!>          NN is INTEGER array, dimension (NSIZES)
!>          An array of matrix dimensions for the problems to be solved.
!> 


NTYPES


!>          NTYPES is INTEGER
!>          The number of types of matrices to be generated.
!>          NTYPES = 14 ;   NTYPES = 15
!>          In NTYPES = 14:
!>          If NTYPES=1, then only type 1070 is generated.
!>          If NTYPES=2, then types 1070 and 1071 are generated.
!>          If NTYPES=3, then types 1070, 1071, and 1072 are generated.
!>          If NTYPES=4, then types 1070, 1071, 1072, and 1073 are generated.
!>          If NTYPES > 4, then types 1070, 1071, 1072, 1073, and 1074
!>          are generated.
!>          The value of NTYPES may be larger than 14, in which case the
!>          excess types will not be generated. If NTYPES is smaller than
!>          MAXTYP, then types NTYPES+1 through MAXTYP will not be
!>          generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1)
!>          through DOTYPE(NTYPES) will be ignored.
!> 


ISEED


!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to CDRVES to continue the same random number
!>          sequence.
!> 


THRESH


!>          THRESH is REAL
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  It must be at least zero.
!> 


NOUNIT


!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns INFO not equal to 0.)
!> 


A


!>          A is COMPLEX array, dimension (LDA, max(NN))
!>          Used to hold the matrix whose eigenvalues are to be
!>          computed.  On exit, A contains the last matrix actually used.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of A, and H. LDA must be at
!>          least 1 and at least max( NN ).
!> 


H


!>          H is COMPLEX array, dimension (LDA, max(NN))
!>          Another copy of the test matrix A, modified by CGEES.
!> 


HT


!>          HT is COMPLEX array, dimension (LDA, max(NN))
!>          Yet another copy of the test matrix A, modified by CGEES.
!> 


W


!>          W is COMPLEX array, dimension (max(NN))
!>          The computed eigenvalues of A.
!> 


WT


!>          WT is COMPLEX array, dimension (max(NN))
!>          Like W, this array contains the eigenvalues of A,
!>          but those computed when CGEES only computes a partial
!>          eigendecomposition, i.e. not Schur vectors
!> 


VS


!>          VS is COMPLEX array, dimension (LDVS, max(NN))
!>          VS holds the computed Schur vectors.
!> 


LDVS


!>          LDVS is INTEGER
!>          Leading dimension of VS. Must be at least max(1,max(NN)).
!> 


RESULT


!>          RESULT is REAL array, dimension (13)
!>          The values computed by the 13 tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.
!> 


WORK


!>          WORK is COMPLEX array, dimension (NWORK)
!> 


NWORK


!>          NWORK is INTEGER
!>          The number of entries in WORK.  This must be at least
!>          5*NN(j)+2*NN(j)**2 for all j.
!> 


RWORK


!>          RWORK is REAL array, dimension (max(NN))
!> 


IWORK


!>          IWORK is INTEGER array, dimension (max(NN))
!> 


BWORK


!>          BWORK is LOGICAL array, dimension (max(NN))
!> 


INFO


!>          INFO is INTEGER
!>          If 0, then everything ran OK.
!>           -1: NSIZES < 0
!>           -2: Some NN(j) < 0
!>           -3: NTYPES < 0
!>           -6: THRESH < 0
!>           -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
!>          -15: LDVS < 1 or LDVS < NMAX, where NMAX is max( NN(j) ).
!>          -18: NWORK too small.
!>          If  CLATMR, CLATMS, CLATME or CGEES returns an error code,
!>              the absolute value of it is returned.
!>

!>
!>     Some Local Variables and Parameters:
!>     ---- ----- --------- --- ----------
!>     ZERO, ONE       Real 0 and 1.
!>     MAXTYP          The number of types defined.
!>     NMAX            Largest value in NN.
!>     NERRS           The number of tests which have exceeded THRESH
!>     COND, CONDS,
!>     IMODE           Values to be passed to the matrix generators.
!>     ANORM           Norm of A; passed to matrix generators.
!>
!>     OVFL, UNFL      Overflow and underflow thresholds.
!>     ULP, ULPINV     Finest relative precision and its inverse.
!>     RTULP, RTULPI   Square roots of the previous 4 values.
!>             The following four arrays decode JTYPE:
!>     KTYPE(j)        The general type (1-10) for type .
!>     KMODE(j)        The MODE value to be passed to the matrix
!>                     generator for type .
!>     KMAGN(j)        The order of magnitude ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!>     KCONDS(j)       Select whether CONDS is to be 1 or
!>                     1/sqrt(ulp).  (0 means irrelevant.)
