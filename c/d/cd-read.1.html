CD-READ(1) Comandos de usuario CD-READ(1)

NOMBRE

cd-read - lee información de un CD o imagen de CD

SINOPSIS

cd-read [OPCIÓN...]

DESCRIPCIÓN

-a, --modo-acceso=CADENA
Establece el modo de acceso de control del CD
-m, --modo=TIPO-MODO
Establece el modo de lectura del CD-ROM (audio, m1f1, m1f2, m2mf1, m2f2)
-d, --depuracion=INT
Establece la depuración al NIVEL
-x, --volcado-hex
Muestra la salida como un volcado hexadecimal. El valor predeterminado es un volcado hexadecimal cuando la salida va a stdout y no hay volcado hexadecimal cuando la salida va a un archivo.
-j, --solo-hex
No muestra caracteres imprimibles en el volcado hexadecimal. El valor predeterminado es mostrar también los caracteres.
--sin-cabecera
No muestra la cabecera y los derechos de autor (para pruebas de regresión)
--sin-volcado-hex
No muestra la salida como un volcado hexadecimal.
-s, --inicio=INT
Establece la LBA para comenzar a leer desde
-e, --fin=INT
Establece la LBA para terminar de leer desde
-n, --numero=INT
Establece el número de sectores a leer
-b, --archivo-bin[=ARCHIVO]
establece el archivo de imagen de disco CD-ROM "bin" como fuente
-c, --archivo-cue[=ARCHIVO]
establece el archivo de imagen de disco CD-ROM "cue" como fuente
-i, --entrada[=ARCHIVO]
establece la fuente y determina si es una imagen "bin" o un dispositivo
-C, --dispositivo-cdrom[=DISPOSITIVO]
establece el dispositivo CD-ROM como fuente
-N, --archivo-nrg[=ARCHIVO]
establece el archivo de imagen de disco CD-ROM de Nero como fuente
-t, --archivo-toc[=ARCHIVO]
establece el archivo de imagen de disco CD-ROM "TOC" como fuente
-o, --archivo-salida=ARCHIVO
Escribe los bloques en un archivo en lugar de generar un volcado hexadecimal.
-V, --version
muestra la información de versión y derechos de autor y sale

Opciones de ayuda:

-?, --help
Muestra este mensaje de ayuda
--uso
Muestra un breve mensaje de uso
