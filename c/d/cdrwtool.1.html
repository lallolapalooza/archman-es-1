CDRWTOOL(1) Manual de Comandos Generales CDRWTOOL(1)

NOMBRE

cdrwtool - realiza varias acciones en un CD-R, CD-RW y DVD-R

SINOPSIS

cdrwtool -d dispositivo -i | -g

cdrwtool -d dispositivo -s [ parametros-escritura ]

cdrwtool -d dispositivo -q [ parametros-escritura ]

cdrwtool -d dispositivo -m desplazamiento [ parametros-escritura ]

cdwrtool -d dispositivo -u bloques [ parametros-escritura ]

cdrwtool -d dispositivo -b modo-b [ parametros-escritura ]

cdrwtool -d dispositivo -c bloques [ parametros-escritura ]

cdwrtool -d dispositivo -f nombre-archivo [ parametros-escritura ]

cdwrtool -d dispositivo -r pista [ parametros-escritura ]

cdrwtool -h

DESCRIPCIÓN

El comando cdwrtool puede realizar ciertas acciones en un dispositivo CD-R, CD-RW o DVD-R. Principalmente, estas son borrar el medio, formatearlo para su uso con el dispositivo packet-cd y aplicar un sistema de archivos UDF.

El uso más común es probablemente la opción de 'configuración rápida':

cdrwtool -d dispositivo -q

que borrará el disco, lo formateará como una gran pista y escribirá las estructuras del sistema de archivos UDF.

Otras opciones obtienen y establecen varios parámetros de cómo se configura el dispositivo, y proporcionan diferentes desplazamientos, modos y configuraciones respecto a los valores predeterminados.

La utilidad de la mayoría de las opciones no se explica.

OPCIONES

Directivas principales:

-d dispositivo
Especifica el dispositivo a usar. Por ejemplo, /dev/sr0
-i
Imprime información de la pista del disco.
-g
Imprime los parámetros de escritura.
-u longitud
Crea un sistema de archivos UDF usando longitud número de bloques.
-q
Configuración rápida: borra el disco, lo formatea como una gran pista y escribe un sistema de archivos UDF.
-m desplazamiento
Formatea el disco en el desplazamiento número de bloques.
-b modo
Borra el disco usando un modo de `full' (completo) o `fast' (rápido).
-f nombre-archivo
Escribe el archivo.
-c pista
Cierra la pista.
-r pista
Reserva la pista.
-z longitud
Longitud fija de paquete.
-s
Establece los parámetros de escritura determinados por las opciones -l, -w y -p para el disco.
-v versión
Especifica la revisión udf a utilizar. Las revisiones válidas son 0x0201, 0x0200 y 0x0150. Si se omite, la versión udf de mkudffs es 0x0150.
-h
Imprime un mensaje de ayuda disperso.

Parámetros de escritura:

-t velocidad
Establece la velocidad de escritura. (Por defecto 12x?)
-l tipo
Establece el campo de multiservicio. Ya sea `0' (predeterminado), `1', o `3', que corresponden a `Sin puntero B0. Siguiente sesión no permitida', `Puntero B0 = FF:FF:FF. Siguiente sesión no permitida', y `Siguiente sesión permitida. Puntero B0 = área de programa siguiente posible', respectivamente.
-w modo
Establece el modo de escritura. Ya sea `mode1' o `mode2' (predeterminado).
-p tipo
Establece el tipo de paquete. Ya sea `0' o `1' (predeterminado), correspondiente a tamaños de paquete variables y fijos, respectivamente.
-o desplazamiento
Establece el desplazamiento de escritura.

ERRORES

Muchas unidades modernas rechazan las preparaciones para formatear medios CD-RW nuevos, en blanco o grabables. Esto causa un mensaje como

Comando fallido: 55 ... - sense ...

La solución es usar un programa de grabación capaz de leer CD para escribir una sesión y cerrar el medio. Por ejemplo, utilizando cualquiera de "cdrecord", "wodim", "cdrskin", o "xorriso -as cdrecord" como contenido de la variable prog en:


prog="xorriso -as cdrecord"
drive="/dev/sr0"
dd if=/dev/zero bs=1M count=10 | $prog -v -eject dev="$drive" -
