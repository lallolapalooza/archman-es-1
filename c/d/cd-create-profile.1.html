CD-CREATE-PROFILE(1) Comandos de usuario CD-CREATE-PROFILE(1)

NOMBRE

cd-create-profile - Herramienta de creación de perfiles de Color Manager

SINOPSIS

cd-create-profile [--verbose]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando cd-create-profile.

cd-create-profile permite a un administrador crear perfiles ICC en su sistema.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (‘-’). A continuación se incluye un resumen de las opciones.

--help

Muestra un resumen de las opciones.

--description (opcional)

Establece la descripción del perfil.

--copyright (opcional)

Establece los derechos de autor del perfil.

--model (opcional)

Establece el modelo del perfil.

--manufacturer (opcional)

Establece el fabricante del perfil.

--srgb-palette

Especifica un archivo de valores separados por comas que se utiliza para el color con nombre.

El formato del archivo CSV debe ser "Nombre del color",0-255(rojo),0-255(verde),0-255(azul).

--output

Especifica el nombre del archivo ICC de salida.

--nc-prefix (opcional)

Especifica el prefijo de la paleta de colores con nombre.

--nc-suffix (opcional)

Especifica el sufijo de la paleta de colores con nombre.
