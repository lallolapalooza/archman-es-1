subroutine cdrgsx (integer nsize, integer ncmax, real thresh, integer nin, integer nout, complex, dimension( lda, * ) a, integer lda, complex, dimension( lda, * ) b, complex, dimension( lda, * ) ai, complex, dimension( lda, * ) bi, complex, dimension( lda, * ) z, complex, dimension( lda, * ) q, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( ldc, * ) c, integer ldc, real, dimension( * ) s, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

CDRGSX

Propósito:

!>
!> CDRGSX verifica el controlador experto del problema de valores propios generalizados no simétricos (forma de Schur)
!> CGGESX.
!>
!> CGGES factoriza A y B como Q*S*Z' y Q*T*Z', donde ' significa transpuesta conjugada,
!> S y T están en forma triangular superior (es decir, en forma de Schur generalizada),
!> y Q y Z son unitarias. También calcula los valores propios generalizados
!> (alpha(j),beta(j)), j=1,...,n. Por lo tanto,
!> w(j) = alpha(j)/beta(j) es una raíz de la ecuación característica
!>
!>                 det( A - w(j) B ) = 0
!>
!> Opcionalmente, también reordena los valores propios para que un clúster seleccionado
!> de valores propios aparezca en el bloque diagonal principal de las formas de Schur;
!> calcula un número de condición recíproco para el promedio de los valores propios seleccionados;
!> y calcula un número de condición recíproco para los subespacios de deflexión derecho e izquierdo correspondientes
!> a los valores propios seleccionados.
!>
!> Cuando CDRGSX se llama con NSIZE > 0, se utilizan cinco (5) tipos de pares de matrices
!> incorporados para probar la rutina CGGESX.
!>
!> Cuando CDRGSX se llama con NSIZE = 0, lee datos de matrices de prueba
!> para probar CGGESX.
!> (se necesitan más detalles sobre qué tipo de datos de lectura se necesitan).
!>
!> Para cada par de matrices, se realizarán las siguientes pruebas
!> y se compararán con el umbral THRESH, excepto para las pruebas (7) y (9):
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A está en forma de Schur (es decir, forma triangular)
!>
!> (6)   máximo sobre j de D(j), donde:
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!> (7)   si la ordenación funcionó y SDIM es el número de valores propios
!>       que se seleccionaron.
!>
!> (8)   el valor estimado DIF no difiere de los valores verdaderos de
!>       Difu y Difl más que un factor de 10*THRESH. Si la estimación DIF
!>       es cero, los valores verdaderos correspondientes de Difu y Difl
!>       deben ser menores que EPS*norm(A, B). Si el valor verdadero de Difu
!>       y Difl son cero, la estimación DIF debe ser menor que
!>       EPS*norm(A, B).
!>
!> (9)   Si CGGESX devuelve INFO = N+3, la reordenación
!>       y verificamos que DIF = PL = PR = 0 y que el valor verdadero de
!>       Difu y Difl es < EPS*norm(A, B). Contamos los eventos cuando
!>       INFO=N+3.
!>
!> Para matrices de prueba leídas, se ejecutan las mismas pruebas excepto que el
!> valor exacto de DIF (y PL) son datos de entrada. Adicionalmente, hay
!> una prueba más para matrices de prueba leídas:
!>
!> (10)  el valor estimado PL no difiere del valor verdadero de
!>       PLTRU más que un factor THRESH. Si la estimación PL es
!>       cero, el valor verdadero correspondiente de PLTRU debe ser menor que
!>       EPS*norm(A, B). Si el valor verdadero de PLTRU es cero, la
!>       estimación PL debe ser menor que EPS*norm(A, B).
!>
!> Tenga en cuenta que para las pruebas integradas, se generan y prueban un total de
!> 10*NSIZE*(NSIZE-1) pares de matrices. NSIZE debe mantenerse pequeño.
!>
!> Se utiliza SVD (rutina CGESVD) para calcular el valor verdadero de DIF_u
!> y DIF_l al probar los problemas de prueba integrados.
!>
!> Matrices de Prueba Integradas
!> ======================
!>
!> Todas las matrices de prueba integradas son el bloque de 2x2 de matrices
!> triangulares
!>
!>          A = [ A11 A12 ]    y      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> donde para diferentes tipos de A11 y A22 se dan como se muestra a continuación.
!> A12 y B12 se eligen de modo que la ecuación de Sylvester generalizada
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> tengan soluciones prescritas R y L.
!>
!> Tipo 1:  A11 = J_m(1,-1) y A_22 = J_k(1-a,1).
!>          B11 = I_m, B22 = I_k
!>          donde J_k(a,b) es el bloque de Jordan kxk con "a" en la diagonal
!>          y "b" en la superdiagonal.
!>
!> Tipo 2:  A11 = (a_ij) = ( 2(.5-sin(i)) ) y
!>          B11 = (b_ij) = ( 2(.5-sin(ij)) ) para i=1,...,m, j=i,...,m
!>          A22 = (a_ij) = ( 2(.5-sin(i+j)) ) y
!>          B22 = (b_ij) = ( 2(.5-sin(ij)) ) para i=m+1,...,k, j=i,...,k
!>
!> Tipo 3:  A11, A22 y B11, B22 se eligen como para el Tipo 2, pero cada
!>          segundo bloque diagonal en A_11 y cada tercer bloque diagonal
!>          en A_22 se convierten en bloques de 2x2.
!>
!> Tipo 4:  A11 = ( 20(.5 - sin(ij)) ) y B22 = ( 2(.5 - sin(i+j)) )
!>             para i=1,...,m,  j=1,...,m y
!>          A22 = ( 20(.5 - sin(i+j)) ) y B22 = ( 2(.5 - sin(ij)) )
!>             para i=m+1,...,k,  j=m+1,...,k
!>
!> Tipo 5:  (A,B) tienen valores propios potencialmente cercanos o comunes y
!>          una gran desviación de la diagonalidad por bloques. A_11 se elige
!>          como la submatriz principal mxm de A_1:
!>                  |  1  b                            |
!>                  | -b  1                            |
!>                  |        1+d  b                    |
!>                  |         -b 1+d                   |
!>           A_1 =  |                  d  1            |
!>                  |                 -1  d            |
!>                  |                        -d  1     |
!>                  |                        -1 -d     |
!>                  |                               1  |
!>          y A_22 se elige como la submatriz principal kxk de A_2:
!>                  | -1  b                            |
!>                  | -b -1                            |
!>                  |       1-d  b                     |
!>                  |       -b  1-d                    |
!>           A_2 =  |                 d 1+b            |
!>                  |               -1-b d             |
!>                  |                       -d  1+b    |
!>                  |                      -1+b  -d    |
!>                  |                              1-d |
!>          y las matrices B se eligen como matrices identidad (ver SLATM5).
!>
!>

Parámetros

NSIZE 
!>          NSIZE es INTEGER
!>          El tamaño máximo de las matrices a utilizar. NSIZE >= 0.
!>          Si NSIZE = 0, no se utilizan matrices de prueba integradas,
!>          pero se utilizan matrices de prueba leídas para probar SGGESX.
!>

NCMAX

!>          NCMAX es INTEGER
!>          Tamaño NMAX máximo permitido para generar matrices de Kronecker
!>          en la llamada a CLAKF2
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se contará como si el , calculado como
!>          d
