cdb(5) Manual de formatos de archivo cdb(5)

NOMBRE

cdb - formato de archivo de Base de Datos Constante

DESCRIPCIÓN

Una base de datos cdb es un único archivo utilizado para mapear `claves' a `valores', teniendo registros de pares (clave,valor). El archivo consta de 3 partes: tabla de contenido (toc), datos e índice (tablas hash).

La tabla de contenido tiene una longitud fija de 2048 bytes, que contiene 256 punteros a tablas hash dentro de las secciones de índice. Cada puntero consta de la posición de una tabla hash en bytes desde el principio del archivo, y el tamaño de una tabla hash en entradas, ambos son enteros sin signo de 4 bytes (32 bits) en formato little-endian. La longitud de la tabla hash puede ser cero, lo que significa que la tabla hash correspondiente está vacía.

Justo después de la sección de tabla de contenido, sigue la sección de datos sin ninguna alineación. Consiste en una serie de registros, cada uno es una longitud de clave, longitud de valor (datos), clave y valor. Nuevamente, la longitud de la clave y el valor son enteros sin signo de 4 bytes. Cada registro siguiente sigue al anterior sin ninguna alineación especial.

Después de la sección de datos, sigue la sección de índice (tablas hash). Debe mirarse junto con la sección de tabla de contenido, donde se definen cada una de las 256 tablas hash como máximo. La sección de índice consta de una serie de tablas hash, con la posición de inicio y la longitud definidas en la sección de tabla de contenido. Cada tabla hash es una secuencia de registros que contiene dos números: el valor hash de la clave y la posición del registro dentro de la sección de datos (bytes desde el principio del archivo hasta el primer byte de la longitud de la clave que inicia el registro de datos). Si la posición del registro es cero, entonces esta es una ranura de tabla hash vacía, que no apunta a ninguna parte.

La función hash de CDB es

  hv = ((hv << 5) + hv) ^ c
para cada byte c de una clave, comenzando con hv = 5381.

La sección de tabla de contenido se indexa por (hv % 256), es decir, el valor hash módulo 256 (número de entradas en la sección de tabla de contenido).

Para encontrar un registro, se debe: primero, calcular el valor hash (hv) de una clave. Segundo, mirar la tabla hash número hv módulo 256. Si está vacía, entonces no existe tal clave. Si no está vacía, entonces tercero, iterar por las ranuras dentro de esa tabla hash, comenzando desde la ranura con el número hv dividido por 256 módulo la longitud de esa tabla, o ((hv / 256) % htlen), buscando este hv en la tabla hash. Detener la búsqueda en una ranura vacía (si la posición del registro es cero) o cuando se han sondeado todas las ranuras (tenga en cuenta la búsqueda cíclica, saltando del final al principio de una tabla). Cuando se encuentra el valor hash en cuestión en la tabla hash, mirar la clave del registro correspondiente, comparándola con la clave en cuestión. Si tienen la misma longitud y son iguales entre sí, entonces se encuentra el registro, de lo contrario, repetir con la siguiente ranura de la tabla hash. Tenga en cuenta que puede haber varios registros con la misma clave.
