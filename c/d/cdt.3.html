DESCRIPCIÓN

Cdt gestiona diccionarios en tiempo de ejecución utilizando tipos de datos de contenedores estándar: conjunto/multiconjunto no ordenado, conjunto/multiconjunto ordenado, lista y pila.

TIPOS DE DICCIONARIO

Dt_t

Este es el tipo de un manejador de diccionario.

Dtdisc_t

Esto define el tipo de una estructura de disciplina que describe el diseño del objeto y las funciones de manipulación.

Dtmethod_t

Este define el tipo de un método de contenedor.

Dtlink_t

Este es el tipo de un contenedor de objetos de diccionario (ver dtdisc().)

Dtstat_t

Este es el tipo de una estructura para devolver estadísticas del diccionario (ver dtstat().)

CONTROL DE DICCIONARIO

Dt_t* dtopen(const Dtdisc_t* disc, const Dtmethod_t* meth)

Esto crea un nuevo diccionario. disc es una estructura de disciplina para describir el formato del objeto. meth especifica un método de manipulación. dtopen() devuelve el nuevo diccionario o NULL en caso de error.

int dtclose(Dt_t* dt)

Esto elimina dt y sus objetos. Nota: dtclose() falla si dt está siendo visto por otros diccionarios (ver dtview()). dtclose() devuelve 0 con éxito y -1 en caso de error.

void dtclear(Dt_t* dt)

Esto elimina todos los objetos en dt sin cerrar dt.

Dtmethod_t dtmethod(Dt_t* dt, const Dtmethod_t* meth)

Si meth es NULL, dtmethod() devuelve el método actual. De lo contrario, cambia el método de almacenamiento de dt a meth. Cambiar a y desde Dtset y Dtoset/Dtobag puede causar que los objetos sean re-hashados, reordenados o eliminados según sea el caso. dtmethod() devuelve el método anterior o NULL en caso de error.

Dtdisc_t* dtdisc(Dt_t* dt, const Dtdisc_t* disc)

Si disc es NULL, dtdisc() devuelve la disciplina actual. De lo contrario, cambia la disciplina de dt a disc. Los objetos pueden ser re-hashados, reordenados o eliminados según corresponda. dtdisc() devuelve la disciplina anterior con éxito y NULL en caso de error.

Dt_t* dtview(Dt_t* dt, Dt_t* view)

Una ruta de vista permite que una búsqueda o recorrido que comienza desde un diccionario continúe hacia otro. dtview() primero termina cualquier vista actual de dt a otro diccionario. Luego, si view es NULL, dtview devuelve el diccionario de vista terminado. Si view no es NULL, se establece una ruta de vista desde dt a view. dtview() devuelve dt con éxito y NULL en caso de error.

Es un error tener diccionarios en una ruta de vista con métodos de almacenamiento diferentes. Además, los diccionarios en la misma ruta de vista deben tratar los objetos de manera consistente con respecto a la comparación o el hash. Si no es así, pueden producirse comportamientos indefinidos.

MÉTODOS DE ALMACENAMIENTO

Los métodos de almacenamiento son de tipo Dtmethod_t*. Cdt soporta los siguientes métodos:

Dtoset

Dtobag

Los objetos se ordenan por comparaciones. Dtoset mantiene objetos únicos. Dtobag permite objetos repetibles.

Dtset

Los objetos no están ordenados. Dtset mantiene objetos únicos. Este método utiliza una tabla hash con encadenamiento para gestionar los objetos.

DISCIPLINA

El formato del objeto y las funciones de gestión asociadas se definen en el tipo Dtdisc_t:

    typedef struct
    { int        key, size;
      int        link;
      Dtmake_f   makef;
      Dtfree_f   freef;
      Dtcompar_f comparf;
    } Dtdisc_t;

int key, size

Cada objeto obj se identifica por una clave utilizada para la comparación o el hash del objeto. key debe ser no negativo y define un desplazamiento dentro de obj. Si size es negativo, la clave es una cadena terminada en nulo con la dirección de inicio *(void**)((char*)obj+key). Si size es cero, la clave es una cadena terminada en nulo con la dirección de inicio (void*)((char*)obj+key). Finalmente, si size es positivo, la clave es una matriz de bytes de longitud size que comienza en (void*)((char*)obj+key).

int link

Sea obj un objeto que se insertará en dt como se describe a continuación. Si link es negativo, se utilizará un contenedor de objetos asignado internamente para contener obj. De lo contrario, obj debe tener una estructura Dtlink_t incrustada link bytes en él, es decir, en la dirección (Dtlink_t*)((char*)obj+link).

void* (*makef)(void* obj, Dtdisc_t* disc)

Si makef no es NULL, dtinsert(dt,obj) lo llamará para crear una copia de obj adecuada para su inserción en dt. Si makef es NULL, se insertará el propio obj en dt.

void (*freef)(void* obj, Dtdisc_t* disc)

Si freef no es NULL, dtdelete(dt,obj) y dtclose(dt) lo llamarán para liberar el objeto obj. Si freef es NULL, no se libera ningún objeto.

int (*comparf)(Dt_t* dt, void* obj1, void* obj2, Dtdisc_t* disc)

Si comparf no es NULL, se utiliza para comparar dos objetos obj1 y obj2 en dt. Debe devolver un valor negativo si obj1 es menor que obj2, cero si son iguales y un valor positivo si obj1 es mayor que obj2. Si comparf es NULL, se utiliza la clave definida por disc para comparar los objetos. Si dt se está utilizando para Dtset, el campo hash de Dtdisc_t se utiliza en su lugar.

OPERACIONES DE OBJETO

void* dtinsert(Dt_t* dt, void* obj)

Inserta el objeto obj en el diccionario dt. Si el objeto ya existe, el objeto original se devuelve y el diccionario no se modifica. Si el objeto no existe, se inserta y se devuelve el objeto. Si se especifica una función makef en la disciplina, se llama para crear una copia del objeto.

void* dtdelete(Dt_t* dt, void* obj)

Elimina el objeto obj del diccionario dt. El objeto eliminado se devuelve. Si no se encuentra el objeto, se devuelve NULL.

void* dtdetach(Dt_t* dt, void* obj)

Elimina el objeto obj del diccionario dt pero no lo libera. El objeto desvinculado se devuelve. Si no se encuentra el objeto, se devuelve NULL.

void* dtsearch(Dt_t* dt, void* obj)

Busca el objeto obj en el diccionario dt. Si se encuentra, se devuelve el objeto. De lo contrario, se devuelve NULL.

void* dtmatch(Dt_t* dt, void* key)

Busca un objeto en el diccionario dt cuyo clave coincide con key. Si se encuentra, se devuelve el objeto. De lo contrario, se devuelve NULL.

void* dtfirst(Dt_t* dt)

Devuelve el primer objeto en el diccionario dt. Si el diccionario está vacío, devuelve NULL.

void* dtnext(Dt_t* dt, void* obj)

Devuelve el siguiente objeto después de obj en el diccionario dt. Si obj es el último objeto, devuelve NULL.

void* dtlast(Dt_t* dt)

Devuelve el último objeto en el diccionario dt. Si el diccionario está vacío, devuelve NULL.

void* dtprev(Dt_t* dt, void* obj)

Devuelve el objeto anterior a obj en el diccionario dt. Si obj es el primer objeto, devuelve NULL.

void* dtfinger(Dt_t* dt)

Devuelve un "dedo" del diccionario dt. Este es un puntero a un objeto utilizado para realizar un seguimiento de la posición actual durante un recorrido.

void* dtrenew(Dt_t* dt, void* obj)

Actualiza el objeto obj en el diccionario dt. Esto elimina el objeto original y lo reemplaza con el nuevo obj. Si el objeto original no existe, se inserta el nuevo obj. Se devuelve el objeto original.

int dtwalk(Dt_t* dt, int (*userf)(void*, void*), void* data)

Recorre el diccionario dt y aplica la función userf a cada objeto. La función userf toma un puntero al objeto y los datos del usuario como argumentos. Si userf devuelve un valor distinto de cero, se detiene el recorrido. La función dtwalk devuelve el número de objetos procesados.

Dtlink_t* dtflatten(Dt_t* dt)

Convierte el diccionario dt en una lista enlazada. Devuelve el primer enlace de la lista enlazada.

Dtlink_t* dtlink(Dt_t* dt, Dtlink_t* link)

Devuelve el enlace Dtlink_t asociado con el objeto link en el diccionario dt.

void* dtobj(Dt_t* dt, Dtlink_t* link)

Devuelve el objeto asociado con el enlace Dtlink_t en el diccionario dt.

Dtlink_t* dtextract(Dt_t* dt)

Extrae todos los objetos del diccionario dt y los devuelve como una lista enlazada. El diccionario dt queda vacío.

int dtrestore(Dt_t* dt, Dtlink_t* link)

Restaura los objetos de la lista enlazada en el diccionario dt. Devuelve 0 con éxito y -1 en caso de error.

ESTADO DEL DICCIONARIO

int dtsize(Dt_t* dt)

Devuelve el número de objetos en el diccionario dt.

int dtstat(Dt_t* dt, Dtstat_t* stat, int all)

Devuelve estadísticas sobre el diccionario dt y las almacena en la estructura stat. Si all es distinto de cero, se devuelven todas las estadísticas. De lo contrario, solo se devuelven las estadísticas más importantes. La función dtstat devuelve 0 con éxito y -1 en caso de error.

FUNCIONES DE HASH

unsigned int dtstrhash(void* str, int n)

Calcula un valor hash para la cadena str. El parámetro n especifica el número de bytes a utilizar de la cadena. Si n es cero, se utiliza toda la cadena hasta el terminador nulo.

Si no es NULL, freef se utiliza para destruir los datos asociados con obj.

int (*comparf)(Dt_t* dt, void* key1, void* key2, Dtdisc_t* disc)

Si no es NULL, comparf se utiliza para comparar dos claves. Su valor de retorno debe ser <0, =0, o >0 para indicar si key1 es menor, igual a, o mayor que key2. Los tres valores son significativos para los métodos Dtoset y Dtobag. Para otros métodos, un valor cero indica igualdad y un valor distinto de cero indica desigualdad. Si (*comparf)() es NULL, se utiliza una función interna para comparar las claves según lo definido por el campo Dtdisc_t.size.

#define DTDISC(disc,key,size,link,makef,freef,comparf)

Esta macro de función inicializa la disciplina a la que apunta disc con los valores dados.

OPERACIONES DE OBJETO

void* dtinsert(Dt_t* dt, void* obj)

Esta función añade un objeto prototipado por obj en dt. dtinsert() realiza la misma función para todos los métodos. Si existe un objeto en dt que coincide con obj y el método de almacenamiento es Dtset o Dtoset, dtinsert() simplemente devolverá el objeto coincidente. De lo contrario, se inserta un nuevo objeto según el método en uso. Consulte Dtdisc_t.makef para la construcción de objetos. Se devolverá el nuevo objeto o el objeto coincidente, según se indique, en caso de éxito, mientras que se devuelve NULL en caso de error.

void* dtdelete(Dt_t* dt, void* obj)

Si obj no es NULL, hay dos casos. Si el método en uso no es Dtobag, se elimina el primer objeto que coincida con obj. Por otro lado, si el método en uso es Dtobag, la biblioteca comprueba si obj está en el diccionario y lo elimina. Si obj no está en el diccionario, se eliminará algún objeto que coincida con él. Consulte Dtdisc_t.freef para la destrucción de objetos. dtdelete() devuelve el objeto eliminado (incluso si fue desasignado) o NULL en caso de error.

void* dtdetach(Dt_t* dt, void* obj)

Esta función es similar a dtdelete() pero el objeto a ser eliminado de dt no será liberado (mediante la función de disciplina freef).

void* dtsearch(Dt_t* dt, void* obj)

void* dtmatch(Dt_t* dt, void* key)

Estas funciones encuentran un objeto que coincida con obj o key ya sea desde dt o desde algún diccionario accesible desde dt a través de un viewpath (ver dtview().) dtsearch() y dtmatch() devuelven el objeto coincidente o NULL en caso de fallo.

void* dtfirst(Dt_t* dt)

void* dtnext(Dt_t* dt, void* obj)

dtfirst() devuelve el primer objeto en dt. dtnext() devuelve el objeto que sigue a obj. Los objetos se ordenan según el método de almacenamiento en uso. Para Dtoset y Dtobag, los objetos se ordenan por comparaciones de objetos. Para Dtset, los objetos se ordenan según algún orden interno (más adelante). Así, los objetos en un diccionario o un viewpath se pueden recorrer usando un bucle for(;;) como se muestra a continuación.

    for(obj = dtfirst(dt); obj; obj = dtnext(dt,obj))

Cuando un diccionario usa Dtset, el orden de los objetos se determina al llamar a dtfirst()/dtlast(). Este orden se congela hasta que una llamada a dtnext()/dtprev() devuelve NULL o cuando estas mismas funciones se llaman con un argumento de objeto NULL. Es importante que una llamada a dtfirst()/dtlast() esté equilibrada por una llamada a dtnext()/dtprev() como se describe. Los bucles anidados requerirán múltiples equilibraciones, una por bucle. Si el equilibrado de bucles no se realiza con cuidado, se degradará el rendimiento o pueden resultar comportamientos inesperados.

void* dtlast(Dt_t* dt)

void* dtprev(Dt_t* dt, void* obj)

dtlast() y dtprev() son como dtfirst() y dtnext() pero trabajan en orden inverso. Tenga en cuenta que los diccionarios en un viewpath todavía se recorren en orden pero los objetos en cada diccionario se recorren en orden inverso.

void* dtfinger(Dt_t* dt)

Esta función devuelve el objeto actual de dt, si existe. El objeto actual se define después de una llamada exitosa a una de dtsearch(), dtmatch(), dtinsert(), dtfirst(), dtnext(), dtlast(), o dtprev(). Como efecto secundario de esta implementación de Cdt, cuando un diccionario se basa en Dtoset y Dtobag, el objeto actual siempre está definido y es la raíz del árbol.

void* dtrenew(Dt_t* dt, void* obj)

Esta función reposiciona y posiblemente recalcula el hash de un objeto obj después de que su clave ha sido cambiada. dtrenew() solo funciona si obj es el objeto actual (ver dtfinger()).

dtwalk(Dt_t* dt, int (*userf)(void*, void*), void* data)

Esta función llama a (*userf)(obj,data) en cada objeto en dt y en otros diccionarios visibles desde él. Si userf() devuelve un valor <0 , dtwalk() termina y devuelve el mismo valor. dtwalk() devuelve 0 al completarse.

Dtlink_t* dtflatten(Dt_t* dt)

Dtlink_t* dtlink(Dt_t* dt, Dtlink_t* link)

void* dtobj(Dt_t* dt, Dtlink_t* link)

Usar dtfirst()/dtnext() o dtlast()/dtprev() para recorrer un solo diccionario puede incurrir en un costo significativo debido a las llamadas a funciones. Para un recorrido eficiente de un solo directorio (es decir, sin viewpathing), se pueden usar dtflatten() y dtlink() . Los objetos en dt se convierten en una lista enlazada y se recorren como sigue:

    for(link = dtflatten(dt); link; link = dtlink(dt,link) )

Tenga en cuenta que dtflatten() devuelve una lista de tipo Dtlink_t*, no void*. Es decir, devuelve un puntero al contenedor del diccionario, no un puntero al objeto del usuario (aunque ambos son lo mismo si el campo de disciplina link es cero.) La macro función dtlink() devuelve el objeto contenedor del diccionario que sigue a link. La macro función dtobj(dt,link) devuelve el objeto del usuario asociado con link. Tenga cuidado de que la lista de objetos aplanada se desaplanada en cualquier operación de diccionario que no sea dtlink().

Dtlink_t* dtextract(Dt_t* dt)

int dtrestore(Dt_t* dt, Dtlink_t* link)

dtextract() extrae todos los objetos de dt y lo hace parecer vacío. dtrestore() vuelve a poblar dt con los objetos obtenidos previamente a través de dtextract(). dtrestore() fallará si dt no está vacío. Estas funciones se pueden usar para compartir un mismo manejador dt entre muchos conjuntos de objetos. Son útiles para reducir la sobrecarga del diccionario en una aplicación que crea muchos diccionarios concurrentes. Es importante que se utilice la misma disciplina y método tanto en la extracción como en la restauración. De lo contrario, pueden resultar comportamientos indefinidos.

INFORMACIÓN DEL DICCIONARIO

int dtsize(Dt_t* dt)

Esta función devuelve el número de objetos almacenados en dt.

int dtstat(Dt_t *dt, Dtstat_t* st, int all)

Esta función informa estadísticas del diccionario. Si all no es cero, se rellenan todos los campos de st. De lo contrario, solo se rellenan los campos dt_type y dt_size. Devuelve 0 en caso de éxito y -1 en caso de error.

Dtstat_t contiene los siguientes campos:

int dt_type:
Este es uno de DT_SET, DT_OSET, y DT_OBAG.
int dt_size:
Contiene el número de objetos en el diccionario.
size_t dt_n:
Para Dtset, este es el número de cadenas no vacías en la tabla hash. Para Dtoset y Dtobag, este es el nivel más profundo del árbol (contando desde cero.) Cada nivel del árbol contiene todos los nodos a igual distancia del nodo raíz. dt_n y los dos campos siguientes no están definidos para otros métodos.
size_t dt_max:
Para Dtset, este es el tamaño de una cadena más grande. Para Dtoset y Dtobag, este es el tamaño de un nivel más grande.
size_t *dt_count:
Para Dtset, esta es la lista de conteos para cadenas de tamaños particulares. Por ejemplo, dt_count[1] es el número de cadenas de tamaño 1. Para Dtoset y Dtobag, esta es la lista de tamaños de los niveles. Por ejemplo, dt_count[1] es el tamaño del nivel 1.

NAME

cdt - collection data types

SYNOPSIS

#include <cdt.h>

DESCRIPTION

The cdt library provides several fundamental collection data types, including sets, bags, dictionaries (maps), and dictionaries mapping strings to objects.

The library provides the following data types:

  • Dtset_t: A set data type, which stores unique elements.
  • Dtdisc_t: A discipline structure used to control the behavior of collection types.
  • Dt_t: An abstract data type representing a collection.
  • Dt_t*: A pointer to a collection data type.

The cdt library is designed to be efficient and flexible, offering various implementation choices for different needs.

A number of functions are provided to manipulate these data types, including creation, destruction, insertion, deletion, lookup, and iteration.

The following hashing functions are available:

  • dtstring(d, s): Hash a null-terminated string s.
  • dthash(d, k): Hash a generic key k.
  • dtstrhash(d, s, n): Hash a string s of length n. If n is positive, s is a byte array of length n; otherwise, s is a null-terminated string.

IMPLEMENTATION NOTES

Dtset are based on hash tables with move-to-front collision chains. Dtoset and Dtobag are based on top-down splay trees.
