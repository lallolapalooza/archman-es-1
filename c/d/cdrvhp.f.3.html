Documentación de función/subrutina

subrutina cdrvhp (lógico, dimensión( * ) dotype, entero nn, entero, dimensión( * ) nval, entero nrhs, real thresh, lógico tsterr, entero nmax, complejo, dimensión( * ) a, complejo, dimensión( * ) afac, complejo, dimensión( * ) ainv, complejo, dimensión( * ) b, complejo, dimensión( * ) x, complejo, dimensión( * ) xact, complejo, dimensión( * ) work, real, dimensión( * ) rwork, entero, dimensión( * ) iwork, entero nout)

CDRVHP

Propósito:

!>
!> CDRVHP prueba las rutinas de controlador CHPSV y -SVX.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LÓGICO, de dimensión (NTYPES)
!>          Los tipos de matriz que se utilizarán para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NN

!>          NN es un ENTERO
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array de ENTEROS, de dimensión (NN)
!>          Los valores de la dimensión de la matriz N.
!>

NRHS

!>          NRHS es un ENTERO
!>          El número de vectores del lado derecho que se generarán para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          cada relación de prueba se imprima, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LÓGICO
!>          Indicador que indica si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es un ENTERO
!>          El valor máximo permitido para N, utilizado en la dimensionamiento de los
!>          arrays de trabajo.
!>

A

!>          A es un array COMPLEJO, de dimensión
!>                      (NMAX*(NMAX+1)/2)
!>

AFAC

!>          AFAC es un array COMPLEJO, de dimensión
!>                      (NMAX*(NMAX+1)/2)
!>

AINV

!>          AINV es un array COMPLEJO, de dimensión
!>                      (NMAX*(NMAX+1)/2)
!>

B

!>          B es un array COMPLEJO, de dimensión (NMAX*NRHS)
!>

X

!>          X es un array COMPLEJO, de dimensión (NMAX*NRHS)
!>

XACT

!>          XACT es un array COMPLEJO, de dimensión (NMAX*NRHS)
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión
!>                      (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK es un array REAL, de dimensión (NMAX+2*NRHS)
!>

IWORK

!>          IWORK es un array de ENTEROS, de dimensión (NMAX)
!>

NOUT

!>          NOUT es un ENTERO
!>          El número de unidad para la salida.
!>
