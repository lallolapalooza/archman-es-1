Propósito:

!>
!>      CDRVST2STG  comprueba los drivers del problema de valores propios Hermíticos.
!>
!>              CHEEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              CHEEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja.
!>
!>              CHEEVR calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja
!>              utilizando la Representación Relativamente Robusta cuando es posible.
!>
!>              CHPEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja en almacenamiento empaquetado,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              CHPEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja en almacenamiento empaquetado.
!>
!>              CHBEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz banda Hermítica compleja,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              CHBEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz banda Hermítica compleja.
!>
!>              CHEEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja.
!>
!>              CHPEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja en almacenamiento empaquetado.
!>
!>              CHBEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz banda Hermítica compleja.
!>
!>      Cuando se llama a CDRVST2STG, se especifican un número de tamaños de matriz y un
!>      número de tipos de matriz. Para cada tamaño y cada tipo de matriz, se generará una matriz y se utilizará
!>      para probar los drivers apropiados. Para cada matriz y cada
!>      rutina de driver llamada, se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de vectores propios devuelta cuando se da la opción de vectores propios y D1 y D2 son los valores propios
!>      devueltos con y sin la opción de vectores propios.
!>
!>      Los tamaños se especifican mediante una matriz NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los tipos se especifican mediante una matriz lógica DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1)
!>      (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>           1, ..., ULP y signos aleatorios.
!>      (5)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>           y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8)  Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (9)  Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas 1, ULP,..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>      (16) Una matriz banda con ancho de banda medio elegido aleatoriamente entre
!>           0 y N-1, con valores propios espaciados uniformemente 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matriz a utilizar. Si es cero,
!>          CDRVST2STG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Una matriz que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CDRVST2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN, se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>          No modificado.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          En la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos de la matriz deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y se pueden usar en la
