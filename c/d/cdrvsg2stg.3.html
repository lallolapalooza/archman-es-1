CDRVSG2STG

Propósito:

!>
!>      CDRVSG2STG comprueba los controladores del problema de autovalores
!>      generalizado hermítico complejo.
!>
!>              CHEGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema de autovalores
!>              generalizado hermítico-definido complejo.
!>
!>              CHEGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema de autovalores
!>              generalizado hermítico-definido complejo utilizando un
!>              algoritmo de dividir y conquistar.
!>
!>              CHEGVX calcula autovalores seleccionados y,
!>              opcionalmente, los autovectores de un problema de
!>              autovalores generalizado hermítico-definido complejo.
!>
!>              CHPGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema de autovalores
!>              generalizado hermítico-definido complejo en almacenamiento
!>              empaquetado.
!>
!>              CHPGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema de autovalores
!>              generalizado hermítico-definido complejo en almacenamiento
!>              empaquetado utilizando un algoritmo de dividir y
!>              conquistar.
!>
!>              CHPGVX calcula autovalores seleccionados y,
!>              opcionalmente, los autovectores de un problema de
!>              autovalores generalizado hermítico-definido complejo en
!>              almacenamiento empaquetado.
!>
!>              CHBGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema de autovalores
!>              generalizado hermítico-definido complejo en banda.
!>
!>              CHBGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema de autovalores
!>              generalizado hermítico-definido complejo en banda
!>              utilizando un algoritmo de dividir y conquistar.
!>
!>              CHBGVX calcula autovalores seleccionados y,
!>              opcionalmente, los autovectores de un problema de
!>              autovalores generalizado hermítico-definido complejo en
!>              banda.
!>
!>      Cuando se llama a CDRVSG2STG, se especifica un número de tamaños
!>      de matriz y un número de tipos de matriz. Para cada tamaño y
!>      cada tipo de matriz, se generará una matriz A del tipo dado; también
!>      se genera una matriz B aleatoria bien condicionada y el par (A,B)
!>      se utiliza para probar los controladores.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) CHEGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>              | D - D2 | / ( |D| ulp )   donde D es calculado por
!>                                         CHEGV y  D2 es calculado por
!>                                         CHEGV_2STAGE. Esta prueba es
!>                                         realizada solo para DSYGV
!>
!>      (2) como (1) pero llamando a CHPGV
!>      (3) como (1) pero llamando a CHBGV
!>      (4) como (1) pero con UPLO = 'L'
!>      (5) como (4) pero llamando a CHPGV
!>      (6) como (4) pero llamando a CHBGV
!>
!>      (7) CHEGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) como (7) pero llamando a CHPGV
!>      (9) como (7) pero con UPLO = 'L'
!>      (10) como (9) pero llamando a CHPGV
!>
!>      (11) CHEGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) como (11) pero llamando a CHPGV
!>      (13) como (11) pero con UPLO = 'L'
!>      (14) como (13) pero llamando a CHPGV
!>
!>      CHEGVD, CHPGVD y CHBGVD realizaron las mismas 14 pruebas.
!>
!>      CHEGVX, CHPGVX y CHBGVX realizaron las 14 pruebas anteriores con
!>      el parámetro RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los tamaños son especificados por un arreglo NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los tipos son especificados por un arreglo lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!>      Este tipo es utilizado para la matriz A que tiene semianchura KA.
!>      B es generada como una matriz definida positiva bien condicionada
!>      con semianchura KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con elementos espaciados uniformemente
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con elementos espaciados geométricamente
!>           1, ..., ULP y signos aleatorios.
!>      (5)  Una matriz diagonal con elementos 1, ULP, ..., ULP
!>           y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!>      (8)  Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene elementos espaciados uniformemente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (9)  Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene elementos espaciados geométricamente 1, ..., ULP con
!>           signos aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene elementos 1, ULP,..., ULP con
!>           signos aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!>      (13) Matriz hermítica con elementos aleatorios elegidos de (-1,1).
!>      (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          CDRVSG2STG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un arreglo que contiene los tamaños a ser utilizados para las
!>          matrices. Los valores cero serán omitidos. Los valores deben
!>          ser al menos cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CDRVSG2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se genera un tipo adicional


NAME


CDRVSD2STG


driver routine for generalized eigenvalue problem







SYNOPSIS


This routine is part of the LAPACK driver routines. It is used to test
    the generalized eigenvalue routines.


SUBROUTINE CDRVSD2STG( NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT,
                       A, LDA, B, LDB, D, Z, LDZ, AB, BB, AP, BP, WORK,
                       NWORK, RWORK, LRWORK, IWORK, LIWORK, RESULT, INFO )



It is called by the user at least as often as is the routine
    being tested. The number of calls to CDRVSD2STG is equal to the number
    of test matrices, which is the product of the number of matrix sizes and
    the number of matrix types.


The input arguments are:




NSIZES


INTEGER. The number of sizes of matrices to be generated.


NN


INTEGER array, dimension (NSIZES). The sizes of the matrices to be
      generated. NN(j) is the dimension of the matrices of size j.


NTYPES


INTEGER. The number of types of matrices to be generated.
      Types 1 to MAXTYP are defined in the subroutine CHKYQ2.


DOTYPE


LOGICAL array, dimension (NTYPES). If DOTYPE(j) is .TRUE., then for
      each size in NN a matrix of that size and of type j will be generated.
      If NTYPES is smaller than the maximum number of types defined (PARAMETER
      MAXTYP), then types NTYPES+1 through MAXTYP will not be generated. If
      NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
      will be ignored.


ISEED


INTEGER array, dimension (4). On entry ISEED specifies the seed of the
      random number generator. The array elements should be between 0 and 4095;
      if not they will be reduced mod 4096. Also, ISEED(4) must be odd. The
      random number generator uses a linear congruential sequence limited to
      small integers, and so should produce machine independent random
      numbers. The values of ISEED are changed on exit, and can be used in
      the next call to CDRVSD2STG to continue the same random number
      sequence.


THRESH


REAL. A test will count as passed if the relative error, computed as
      described above, is less than or equal to THRESH. Note that the error
      is scaled to be O(1), so THRESH should be a reasonably small multiple
      of 1, e.g., 10 or 100. In particular, it should not depend on the
      precision (single vs. double) or the size of the matrix. It must be
      at least zero.


NOUNIT


INTEGER. The FORTRAN unit number for printing out error messages
      (e.g., if a routine returns INFO not equal to 0.)


A


COMPLEX array, dimension (LDA , max(NN)). Used to hold the matrix whose
      eigenvalues are to be computed. On exit, A contains the last matrix
      actually used.


LDA


INTEGER. The leading dimension of A. It must be at least 1 and at least
      max( NN ).


B


COMPLEX array, dimension (LDB , max(NN)). Used to hold the Hermitian
      positive definite matrix for the generalized problem. On exit, B
      contains the last matrix actually used.


LDB


INTEGER. The leading dimension of B. It must be at least 1 and at least
      max( NN ).


D


REAL array, dimension (max(NN)). The eigenvalues of A. On exit, the
      eigenvalues in D correspond with the matrix in A.


Z


COMPLEX array, dimension (LDZ, max(NN)). The matrix of eigenvectors.


LDZ


INTEGER. The leading dimension of Z. It must be at least 1 and at least
      max( NN ).


AB


COMPLEX array, dimension (LDA, max(NN)). Workspace.


BB


COMPLEX array, dimension (LDB, max(NN)). Workspace.


AP


COMPLEX array, dimension (max(NN)**2). Workspace.


BP


COMPLEX array, dimension (max(NN)**2). Workspace.


WORK


COMPLEX array, dimension (NWORK). Workspace.


NWORK


INTEGER. The number of entries in WORK. This must be at least 2*N + N**2
      where N = max( NN(j), 2 ).


RWORK


REAL array, dimension (LRWORK). Workspace.


LRWORK


INTEGER. The number of entries in RWORK. This must be at least max( 7*N,
      1 + 4*N + 2*N*lg(N) + 3*N**2 ) where N = max( NN(j) ) and lg( N ) =
      smallest integer k such that 2**k >= N .


IWORK


INTEGER array, dimension (LIWORK). Workspace.


LIWORK


INTEGER. The number of entries in IWORK. This must be at least 2 + 5*max(
      NN(j) ).


RESULT


REAL array, dimension (70). The values computed by the 70 tests
      described above.


INFO


INTEGER. If 0, then everything ran OK.
      -1: NSIZES < 0
      -2: Some NN(j) < 0
      -3: NTYPES < 0
      -5: THRESH < 0
      -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
      -16: LDZ < 1 or LDZ < NMAX.
      -21: NWORK too small.
      -23: LRWORK too small.
      -25: LIWORK too small.
      If CLATMR, CLATMS, CHEGV, CHPGV, CHBGV, CHEGVD, CHPGVD, CHPGVD, CHEGVX,
      CHPGVX, CHBGVX returns an error code, the absolute value of it is
      returned.









Function/Subroutine Documentation


  Subroutine CDRVSD2STG(NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT,
                        A, LDA, B, LDB, D, Z, LDZ, AB, BB, AP, BP, WORK,
                        NWORK, RWORK, LRWORK, IWORK, LIWORK, RESULT, INFO)
  


CDRVSD2STG is a driver routine for the generalized eigenvalue
    problem Ax = lambda Bx, where A and B are general matrices. It generates
    test matrices of various dimensions and types, calls the relevant LAPACK
    routines to solve the problem, and then checks the accuracy of the results.


The following describes the parameters of the routine:




NSIZES


INTEGER. The number of different matrix sizes to test.


NN


INTEGER array, dimension (NSIZES). Specifies the matrix dimensions. NN(j)
      is the dimension of the matrices to be generated for the j-th test
      size.


NTYPES


INTEGER. The number of different matrix types to test. The types are
      defined by the subroutine CHKYQ2.


DOTYPE


LOGICAL array, dimension (NTYPES). If DOTYPE(j) is .TRUE., then
      matrices of type j are generated and tested. If NTYPES is less than
      the maximum number of types defined (MAXTYP), then types NTYPES+1 to
      MAXTYP will not be generated. If NTYPES is greater than MAXTYP, then
      DOTYPE(MAXTYP+1) to DOTYPE(NTYPES) will be ignored.


ISEED


INTEGER array, dimension (4). On entry, ISEED specifies the seed for the
      random number generator. The values must be between 0 and 4095. If any
      value is outside this range, it will be reduced modulo 4096. ISEED(4)
      must be odd. On exit, ISEED is updated to be used in subsequent calls
      to continue the random sequence.


THRESH


REAL. A threshold value for error checking. If the computed relative
      error exceeds THRESH, the test is considered to have failed. This value
      should be a small multiple of 1 (e.g., 10 or 100) and should not depend
      on matrix precision or size.


NOUNIT


INTEGER. The FORTRAN logical unit number for outputting error messages
      and test results.


A


COMPLEX array, dimension (LDA, max(NN)). This array is used to store the
      matrix A. On exit, it contains the last matrix generated and processed.


LDA


INTEGER. The leading dimension of array A. Must be at least 1 and at
      least max(NN).


B


COMPLEX array, dimension (LDB, max(NN)). This array is used to store the
      matrix B. On exit, it contains the last matrix generated and processed.


LDB


INTEGER. The leading dimension of array B. Must be at least 1 and at
      least max(NN).


D


REAL array, dimension (max(NN)). On exit, this array stores the computed
      eigenvalues of the generalized problem.


Z


COMPLEX array, dimension (LDZ, max(NN)). On exit, this array stores the
      computed eigenvectors of the generalized problem.


LDZ


INTEGER. The leading dimension of array Z. Must be at least 1 and at
      least max(NN).


AB


COMPLEX array, dimension (LDA, max(NN)). Workspace array.


BB


COMPLEX array, dimension (LDB, max(NN)). Workspace array.


AP


COMPLEX array, dimension (max(NN)**2). Workspace array.


BP


COMPLEX array, dimension (max(NN)**2). Workspace array.


WORK


COMPLEX array, dimension (NWORK). Workspace array.


NWORK


INTEGER. The size of the WORK array. Must be at least 2*N + N**2, where N
      = max(NN(j), 2).


RWORK


REAL array, dimension (LRWORK). Workspace array.


LRWORK


INTEGER. The size of the RWORK array. Must be at least max( 7*N, 1 + 4*N
      + 2*N*lg(N) + 3*N**2 ), where N = max(NN(j)) and lg(N) is the smallest
      integer k such that 2**k >= N.


IWORK


INTEGER array, dimension (LIWORK). Workspace array.


LIWORK


INTEGER. The size of the IWORK array. Must be at least 2 + 5*max(NN(j)).


RESULT


REAL array, dimension (70). Stores the results of the various tests
      performed by the routine.


INFO


INTEGER. An exit status code. If INFO is 0, all tests passed. Negative
      values indicate errors in the input parameters or errors returned by
      called LAPACK routines. Specific error codes are detailed in the
      documentation.




Note on parameter MAXTYP:


The value of MAXTYP is determined by the number of matrix types
    defined within the testing routines (e.g., CHKYQ2). If DOTYPE is set to use
    types beyond MAXTYP, those requests will be ignored. Conversely, if DOTYPE
    does not cover all types up to MAXTYP, the remaining types will not be
    generated.


Note on parameter ISEED:


The random number generator is a linear congruential sequence
    generator designed for generating machine-independent random numbers within
    a limited integer range. The updated ISEED values on exit allow for
    continuation of the same random sequence in subsequent calls.


Note on parameter THRESH:


The error is scaled to be approximately O(1). Therefore, THRESH
    should be a reasonably small multiple of 1, such as 10 or 100, and should
    not be dependent on the precision or size of the matrix.


Note on parameter A (and B):


When DOTYPE(MAXTYP+1) is .TRUE., it indicates that the user
    should supply the matrix A (and B if applicable) instead of it being
    generated by the routine. This is only useful if DOTYPE(1:MAXTYP) is
    .FALSE. and DOTYPE(MAXTYP+1) is .TRUE. The parameter A is modified by the
    routine.


Some Local Variables and Parameters:




    ZERO, ONE       Real 0 and 1.
    MAXTYP          The number of types defined.
    NTEST           The number of tests that have been run
                    on this matrix.
    NTESTT          The total number of tests for this call.
    NMAX            Largest value in NN.
    NMATS           The number of matrices generated so far.
    NERRS           The number of tests which have exceeded THRESH
                    so far (computed by SLAFTS).
    COND, IMODE     Values to be passed to the matrix generators.
    ANORM           Norm of A; passed to matrix generators.

    OVFL, UNFL      Overflow and underflow thresholds.
    ULP, ULPINV     Finest relative precision and its inverse.
    RTOVFL, RTUNFL  Square roots of the previous 2 values.
            The following four arrays decode JTYPE:
    KTYPE(j)        The general type (1-10) for type j.
    KMODE(j)        The MODE value to be passed to the matrix
                    generator for type j.
    KMAGN(j)        The order of magnitude ( O(1),
                    O(overflow^(1/2) ), O(underflow^(1/2) )
