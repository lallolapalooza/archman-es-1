subrutina cdrvbd (integer nsizes, integer, dimension( * ) mm, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( ldvt, * ) vt, integer ldvt, complex, dimension( lda, * ) asav, complex, dimension( ldu, * ) usav, complex, dimension( ldvt, * ) vtsav, real, dimension( * ) s, real, dimension( * ) ssav, real, dimension( * ) e, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer nounit, integer info)

CDRVBD

Propósito:

!>
!> CDRVBD comprueba los controladores de descomposición en valores singulares (SVD) CGESVD,
!> CGESDD, CGESVJ, CGEJSV, CGESVDX y CGESVDQ.
!>
!> CGESVD y CGESDD factorizan A = U diag(S) VT, donde U y VT son
!> unitarias y diag(S) es diagonal con los elementos del array S en
!> su diagonal. Los elementos de S son los valores singulares, no negativos
!> y almacenados en orden decreciente. U y VT pueden opcionalmente no
!> ser calculados, sobrescritos en A, o calculados parcialmente.
!>
!> A es M por N. Sea MNMIN = min( M, N ). S tiene dimensión MNMIN.
!> U puede ser M por M o M por MNMIN. VT puede ser N por N o MNMIN por N.
!>
!> Cuando se llama a CDRVBD, se especifica un número de tamaños de matrices (M's y N's)
!> y un número de tipos de matrices. Para cada tamaño (M,N)
!> y cada tipo de matriz, y para el espacio de trabajo mínimo así como
!> un espacio de trabajo adecuado para permitir el bloqueo, se generará una
!> matriz M x N y se usará para probar las rutinas SVD. Para cada matriz, A será
!> factorizada como A = U diag(S) VT y se calcularán los siguientes 12 tests:
!>
!> Test para CGESVD:
!>
!> (1)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)   | I - U'U | / ( M ulp )
!>
!> (3)   | I - VT VT' | / ( N ulp )
!>
!> (4)   S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (5)   | U - Upartial | / ( M ulp ) donde Upartial es un U
!>       calculado parcialmente.
!>
!> (6)   | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT
!>       calculado parcialmente.
!>
!> (7)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares del SVD parcial
!>
!> Test para CGESDD:
!>
!> (8)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)   | I - U'U | / ( M ulp )
!>
!> (10)  | I - VT VT' | / ( N ulp )
!>
!> (11)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (12)  | U - Upartial | / ( M ulp ) donde Upartial es un U
!>       calculado parcialmente.
!>
!> (13)  | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT
!>       calculado parcialmente.
!>
!> (14)  | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares del SVD parcial
!>
!> Test para CGESVDQ:
!>
!> (36)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)  | I - U'U | / ( M ulp )
!>
!> (38)  | I - VT VT' | / ( N ulp )
!>
!> (39)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Test para CGESVJ:
!>
!> (15)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)  | I - U'U | / ( M ulp )
!>
!> (17)  | I - VT VT' | / ( N ulp )
!>
!> (18)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Test para CGEJSV:
!>
!> (19)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)  | I - U'U | / ( M ulp )
!>
!> (21)  | I - VT VT' | / ( N ulp )
!>
!> (22)  S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Test para CGESVDX( 'V', 'V', 'A' )/CGESVDX( 'N', 'N', 'A' )
!>
!> (23)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)  | I - U'U | / ( M ulp )
!>
!> (25)  | I - VT VT' | / ( N ulp )
!>
!> (26)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (27)  | U - Upartial | / ( M ulp ) donde Upartial es un U
!>       calculado parcialmente.
!>
!> (28)  | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT
!>       calculado parcialmente.
!>
!> (29)  | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares del SVD parcial
!>
!> Test para CGESVDX( 'V', 'V', 'I' )
!>
!> (30)  | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)  | I - U'U | / ( M ulp )
!>
!> (32)  | I - VT VT' | / ( N ulp )
!>
!> Test para CGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Los tamaños de las matrices se especifican por los arrays MM(1:NSIZES) y
!> NN(1:NSIZES); el valor de cada par de elementos (MM(j),NN(j))
!> especifica un tamaño. Los tipos de matrices se especifican por un array lógico
!> DOTYPE( 1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!> (3)  Una matriz de la forma U D V, donde U y V son unitarias y
!>      D tiene elementos espaciados uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!> (4)  Igual que (3), pero multiplicada por el umbral de desbordamiento inferior / ULP.
!> (5)  Igual que (3), pero multiplicada por el umbral de desbordamiento superior * ULP.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero,
!>          CDRVBD no hace nada. Debe ser al menos cero.
!>

MM

!>          MM es un array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños de las matrices a usar. Para
!>          cada j=1,...,NSIZES, si MM(j) es cero, entonces MM(j) y NN(j)
!>          serán ignorados. Los valores MM(j) deben ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños de las matrices a usar. Para
!>          cada j=1,...,NSIZES, si NN(j) es cero, entonces MM(j) y NN(j)
!>          serán ignorados. Los valores NN(j) deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CDRVBD
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar las matrices que haya en A y B.
!>          Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño (m,n), se generará una matriz
!>          de tipo j. Si NTYPES es menor que el
!>          número máximo de tipos definidos (PARÁMETRO MAXTYP), entonces
!>          los tipos NTYPES+1 hasta MAXTYP no serán generados. Si
!>          NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) a          DOTYPE(NTYPES) será ignorado.
!>

ISEED

!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador
!>          de números aleatorios. Los elementos del arreglo deben estar
!>          entre 0 y 4095; si no lo están, se reducirán módulo 4096.
!>          Además, ISEED(4) debe ser impar. El generador de números
!>          aleatorios utiliza una secuencia congruencial lineal
!>          limitada a enteros pequeños, y por lo tanto debería
!>          producir números aleatorios independientes de la máquina.
!>          Los valores de ISEED se modifican en la salida, y pueden
!>          usarse en la siguiente llamada a CDRVBD para continuar la
!>          misma secuencia de números aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se considerará fallida si , calculado como se
!>          describe arriba, supera THRESH. Tenga en cuenta que el
!>          error se escala para ser O(1), por lo que THRESH debe ser
!>          un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o
!>          100. En particular, no debe depender de la precisión
!>          (simple vs. doble) ni del tamaño de la matriz. Debe ser al
!>          menos cero.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,max(NN))
!>          Se usa para contener la matriz cuyos valores singulares
!>          deben ser calculados. En la salida, A contiene la última
!>          matriz realmente utilizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 1 y al
!>          menos max( MM ).
!>

U

!>          U es un arreglo COMPLEX, dimensión (LDU,max(MM))
!>          Se usa para contener la matriz calculada de vectores
!>          singulares derechos. En la salida, U contiene los últimos
!>          vectores realmente calculados.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. Debe ser al menos 1 y al
!>          menos max( MM ).
!>

VT

!>          VT es un arreglo COMPLEX, dimensión (LDVT,max(NN))
!>          Se usa para contener la matriz calculada de vectores
!>          singulares izquierdos. En la salida, VT contiene los
!>          últimos vectores realmente calculados.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal de VT. Debe ser al menos 1 y al
!>          menos max( NN ).
!>

ASAV

!>          ASAV es un arreglo COMPLEX, dimensión (LDA,max(NN))
!>          Se usa para contener una copia diferente de la matriz
!>          cuyos valores singulares deben ser calculados. En la
!>          salida, A contiene la última matriz realmente utilizada.
!>

USAV

!>          USAV es un arreglo COMPLEX, dimensión (LDU,max(MM))
!>          Se usa para contener una copia diferente de la matriz
!>          calculada de vectores singulares derechos. En la salida,
!>          USAV contiene los últimos vectores realmente calculados.
!>

VTSAV

!>          VTSAV es un arreglo COMPLEX, dimensión (LDVT,max(NN))
!>          Se usa para contener una copia diferente de la matriz
!>          calculada de vectores singulares izquierdos. En la salida,
!>          VTSAV contiene los últimos vectores realmente calculados.
!>

S

!>          S es un arreglo REAL, dimensión (max(min(MM,NN)))
!>          Contiene los valores singulares calculados.
!>

SSAV

!>          SSAV es un arreglo REAL, dimensión (max(min(MM,NN)))
!>          Contiene otra copia de los valores singulares calculados.
!>

E

!>          E es un arreglo REAL, dimensión (max(min(MM,NN)))
!>          Espacio de trabajo para CGESVD.
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          El número de entradas en WORK. Debe ser al menos
!>          MAX(3*MIN(M,N)+MAX(M,N)**2,5*MIN(M,N),3*MAX(M,N)) para
!>          todos los pares (M,N)=(MM(j),NN(j))
!>

RWORK

!>          RWORK es un arreglo REAL,
!>                      dimensión ( 5*max(max(MM,NN)) )
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión al menos 8*min(M,N)
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de
!>          error (por ejemplo, si una rutina devuelve IINFO distinto
!>          de 0.)
!>

INFO

!>          INFO es INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Alguno de los MM(j) < 0
!>           -3: Alguno de los NN(j) < 0
!>           -4: NTYPES < 0
!>           -7: THRESH < 0
!>          -10: LDA < 1 o LDA < MMAX, donde MMAX es max( MM(j) ).
!>          -12: LDU < 1 o LDU < MMAX.
!>          -14: LDVT < 1 o LDVT < NMAX, donde NMAX es max( NN(j) ).
!>          -29: LWORK demasiado pequeño.
!>          Si CLATMS, o CGESVD devuelve un código de error, se
!>              devuelve el valor absoluto del mismo.
!>
