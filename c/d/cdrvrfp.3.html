CDRVRFP

Propósito:

!>
!> CDRVRFP prueba las rutinas RFP de LAPACK:
!>     CPFTRF, CPFTRS, y CPFTRI.
!>
!> Esta rutina de prueba sigue las mismas pruebas que CDRVPO (prueba para el
!> solucionador Simétrico Definido Positivo en formato completo).
!>
!> Las pruebas se realizan en Formato Completo, la conversión de ida y vuelta
!> del formato completo al formato RFP se realiza utilizando las rutinas CTRTTF
!> y CTFTTR.
!>
!> Primero, se crea una matriz A específica de tamaño N. Hay nueve tipos de
!> matrices diferentes posibles.
!>  1. Diagonal                        6. Aleatoria, CNDNUM = sqrt(0.1/EPS)
!>  2. Aleatoria, CNDNUM = 2           7. Aleatoria, CNDNUM = 0.1/EPS
!> *3. Primera fila y columna cero     8. Escalada cerca del desbordamiento inferior
!> *4. Última fila y columna cero      9. Escalada cerca del desbordamiento superior
!> *5. Fila y columna del medio cero
!> (* - prueba las salidas de error de CPFTRF, no se calculan relaciones de prueba)
!> Se crea una solución XACT de tamaño N-by-NRHS y el lado derecho asociado
!> B. Luego se llama a CPFTRF para calcular L (o U), el factor de Cholesky de A.
!> Luego se usa L (o U) para resolver el sistema lineal de ecuaciones AX = B.
!> Esto da X. Luego se usa L (o U) para calcular el inverso de A, AINV. Luego se
!> realizan las siguientes cuatro pruebas:
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> donde EPS es la precisión de la máquina, RCOND el número de condición de A, y
!> norm( . ) la norma-1 para (1,2,3) y la norma-infinito para (4).
!> Ocurren errores cuando el parámetro INFO no es el esperado. Se producen fallos
!> cuando una relación de prueba es mayor que THRES.
!>

Parámetros

NOUT 
!>          NOUT es INTEGER
!>                El número de unidad para la salida.
!>

NN

!>          NN es INTEGER
!>                El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un arreglo INTEGER, dimensión (NN)
!>                Los valores de la dimensión de la matriz N.
!>

NNS

!>          NNS es INTEGER
!>                El número de valores de NRHS contenidos en el vector NSVAL.
!>

NSVAL

!>          NSVAL es un arreglo INTEGER, dimensión (NNS)
!>                Los valores del número de lados derechos NRHS.
!>

NNT

!>          NNT es INTEGER
!>                El número de valores de TIPO DE MATRIZ contenidos en el vector NTVAL.
!>

NTVAL

!>          NTVAL es un arreglo INTEGER, dimensión (NNT)
!>                Los valores del tipo de matriz (entre 0 y 9 para matrices PO/PP/PF).
!>

THRESH

!>          THRESH es REAL
!>                El valor umbral para las relaciones de prueba. Un resultado se
!>                incluye en el archivo de salida si RESULT >= THRESH. Para que
!>                se impriman todas las relaciones de prueba, use THRESH = 0.
!>
