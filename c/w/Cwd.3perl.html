Cwd(3perl) Guía de referencia para programadores de Perl Cwd(3perl)

NOMBRE

Cwd - obtener la ruta del directorio de trabajo actual

SINOPSIS

use Cwd;
my $dir = getcwd;
use Cwd 'abs_path';
my $abs_path = abs_path($file);

DESCRIPCIÓN

Este módulo proporciona funciones para determinar la ruta del directorio de trabajo actual. Se recomienda usar getcwd (o alguna otra función *cwd()) en *todo* el código para garantizar la portabilidad.

Por defecto, exporta las funciones cwd(), getcwd(), fastcwd() y fastgetcwd() (y, en Win32, getdcwd()) al espacio de nombres del llamador.

getcwd y amigos

Cada una de estas funciones se llama sin argumentos y devuelve la ruta absoluta del directorio de trabajo actual.

getcwd
my $cwd = getcwd();

Devuelve el directorio de trabajo actual. En caso de error, devuelve "undef", con $! configurado para indicar el error.

Expone la función POSIX getcwd(3) o la reimplementa si no está disponible.

cwd
my $cwd = cwd();

cwd() es la forma más natural para la arquitectura actual. Para la mayoría de los sistemas, es idéntica a `pwd` (pero sin el terminador de línea final).

fastcwd
my $cwd = fastcwd();

Una versión más peligrosa de getcwd(), pero potencialmente más rápida.

Podría, concebiblemente, sacarte de un directorio al que no pueda volver a entrar. Si fastcwd encuentra un problema, devolverá undef pero probablemente te dejará en un directorio diferente. Como medida de seguridad adicional, si todo parece haber funcionado, la función fastcwd() comprobará que te deja en el mismo directorio en el que empezó. Si ha cambiado, hará "die" con el mensaje "Unstable directory path, current directory changed unexpectedly". Eso nunca debería suceder.

fastgetcwd
my $cwd = fastgetcwd();

La función fastgetcwd() se proporciona como un sinónimo de cwd().

getdcwd
my $cwd = getdcwd();
my $cwd = getdcwd('C:');

La función getdcwd() también se proporciona en Win32 para obtener el directorio de trabajo actual en la unidad especificada, ya que Windows mantiene un directorio de trabajo actual separado para cada unidad. Si no se especifica ninguna unidad, se asume la unidad actual.

Esta función simplemente llama a la función _getdcwd() de la biblioteca C de Microsoft.

abs_path y amigos

Estas funciones se exportan solo bajo petición. Cada una toma un único argumento y devuelve la ruta absoluta para él. Si no se proporciona ningún argumento, utilizarán el directorio de trabajo actual.

abs_path
my $abs_path = abs_path($file);

Utiliza el mismo algoritmo que getcwd(). Los enlaces simbólicos y los componentes de ruta relativa ("." y "..") se resuelven para devolver la ruta canónica, al igual que realpath(3). En caso de error, devuelve "undef", con $! configurado para indicar el error.

realpath
my $abs_path = realpath($file);

Un sinónimo de abs_path().

fast_abs_path
my $abs_path = fast_abs_path($file);

Una versión más peligrosa, pero potencialmente más rápida, de abs_path.

$ENV{PWD}

Si solicitas anular la función incorporada chdir(),

use Cwd qw(chdir);

entonces tu variable de entorno PWD se mantendrá actualizada. Ten en cuenta que solo se mantendrá actualizada si todos los paquetes que usan chdir la importan de Cwd.

NOTAS

  • Dado que los separadores de ruta son diferentes en algunos sistemas operativos ('/' en Unix, ':' en MacPerl, etc.), recomendamos utilizar los módulos File::Spec siempre que la portabilidad sea una preocupación.
  • En realidad, en Mac OS, las funciones getcwd(), fastgetcwd() y fastcwd() son alias de la función cwd(), que, en Mac OS, llama a `pwd`. Del mismo modo, la función abs_path() es un alias de fast_abs_path().
