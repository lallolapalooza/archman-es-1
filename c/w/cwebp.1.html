DESCRIPCIÓ

N

Esta página de manual documenta el comando c

webp.

cwebp comprime una imagen usando el formato WebP. El formato de entrada puede ser PNG, JPEG, TI

FF, WebP o muestras Y'CbCr en bruto. Nota: lo
s archivos PNG y WebP animados no son compatibles.

Especifica el nivel de preprocesamiento de imagen casi sin pérdida. Esta opción ajusta los valores de los píxeles para ayudar a la compresibilidad, pero tiene un impacto mínimo en la calidad visual. -q flo
at
Especifica el factor de compresión para los canales RGB entre 0 y 100. El predeterminado es 75.
En caso de compresión con pérdida (predeterminada), un factor pequeño produce un archivo más pequeño con menor calidad. La mejor calidad se logra usando un valor de 100.
En caso de compresión sin pérdida (especificada por la opción -lossless), un factor pequeño permite una velocidad de compresión más rápida, pero produce un archivo más grande. La compresión máxima se logra usando un valor de
100.
-z in
t
Activa el modo de compresión sin pérdida con el nivel especificado entre 0 y 9, siendo el nivel 0 el más rápido y el 9 el más lento. El modo rápido produce un tamaño de archivo más grande que los más lentos. Un buen valor predeterminado es -z 6. Esta opción es en realidad un acceso directo para algunos ajustes predefinidos de calidad y método. Si las opciones -q o -m se usan posteriormente, invalidarán el efecto de esta
opción.
-alpha_q in
t
Especifica el factor de compresión para la compresión alfa entre 0 y 100. La compresión sin pérdida del alfa se logra usando un valor de 100, mientras que los valores más bajos resultan en una compresión con pérdida. El predeterminado es
100.

a
Especifica un conjunto de parámetros predefinidos para adaptarse a un tipo particular de material fuente. Los valores posibles son: default, photo, picture, drawing, icon, text. Dado que -preset sobrescribe los valores de los otros parámetros (excepto el de -q), esta opción debe aparecer preferiblemente al principio del orden de los
argumentos.
-m in
t
Especifica el método de compresión a utilizar. Este parámetro controla la compensación entre la velocidad de codificación y el tamaño y calidad del archivo comprimido. Los valores posibles van de 0 a 6. El valor predeterminado es 4. Cuando se usan valores más altos, el codificador dedicará más tiempo a inspeccionar posibilidades de codificación adicionales y decidir sobre la mejora de calidad. Un valor más bajo puede resultar en un tiempo de procesamiento más rápido a costa de un tamaño de archivo más grande y una calidad de compresión más
baja.

alto

De manera similar, up_only solo redimensionará si el ancho o alto de entrada es menor que las dimensiones

OPCIONES CON

PÉRDIDA

Estas opciones solo son efectivas al hacer codificación con pérdida (la predeterminada, con o sin alfa)

.
-size in
t
Especifica un tamaño objetivo (en bytes) para intentar alcanzar para la salida comprimida. El compresor realizará varios pasos de codificación parcial para acercarse lo más posible a este objetivo. Si se usan tanto -size como -psnr, prevalecerá el valor de
-size.
-psnr floa
t
Especifica un PSNR objetivo (en dB) para intentar alcanzar para la salida comprimida. El compresor realizará varios pasos de codificación parcial para acercarse lo más posible a este objetivo. Si se usan tanto -size como -psnr, prevalecerá el valor de
-size.
-pass in
t
Establece un número máximo de pasos a usar durante la dicotomía utilizada por las opciones -size o -psnr. El valor máximo es 10, el predeterminado es 1. Si se usaron las opciones -size o -psnr, pero no se especificó -pass, se usará un valor predeterminado de '6' pasos. Si se especifica -pass, pero no se especifica -size ni -psnr, se usará un PSNR objetivo de
40dB.
-qrange int
int
Especifica el intervalo permitido para el factor de calidad. Esto es particularmente útil al usar multipaso (-size o -psnr opciones). El predeterminado es 0 100. Si el factor de calidad está fuera de este rango, se limitará. El valor mínimo debe ser menor o igual al
máximo.
-a
f
Activa el autofiltro. Este algoritmo dedicará tiempo adicional a optimizar la fuerza del filtro para alcanzar una calidad bien
equilibrada.
-jpeg_li
ke
Cambia el mapeo de parámetros internos para coincidir mejor con el tamaño esperado de la compresión JPEG. Este indicador generalmente producirá un archivo de salida de tamaño similar a su equivalente JPEG (para la misma configuración -q), pero con menos distorsión visual.
Opciones avanzadas:
-f entero
Especifica la fuerza del filtro de desbloqueo, entre 0 (sin filtrado) y 100 (filtrado máximo). Un valor de 0 desactivará cualquier filtrado. Un valor más alto aumentará la fuerza del proceso de filtrado aplicado después de decodificar la imagen. Cuanto mayor sea el valor, más suave aparecerá la imagen. Los valores típicos suelen estar en el rango de 20 a 50.
-sharpness entero
Especifica la nitidez del filtrado (si se usa). El rango es de 0 (más nítido) a 7 (menos nítido). El valor predeterminado es 0.
-strong
Utiliza filtrado fuerte (si el filtrado se está utilizando gracias a la opción -f). El filtrado fuerte está activado por defecto.
-nostrong
Desactiva el filtrado fuerte (si el filtrado se está utilizando gracias a la opción -f) y utiliza filtrado simple en su lugar.
-sharp_yuv
Utiliza una conversión RGB->YUV más precisa y nítida. Ten en cuenta que este proceso es más lento que la conversión RGB->YUV 'rápida' por defecto.
-sns entero
Especifica la amplitud de la conformación espacial de ruido. La conformación espacial de ruido (o sns para abreviar) se refiere a una colección general de algoritmos incorporados utilizados para decidir qué área de la imagen debe usar relativamente menos bits, y dónde transferir mejor estos bits. El rango posible va de 0 (algoritmo desactivado) a 100 (efecto máximo). El valor predeterminado es 50.
-segments entero
Cambia el número de particiones a utilizar durante la segmentación del algoritmo sns. Los segmentos deben estar en el rango de 1 a 4. El valor predeterminado es 4. Esta opción no tiene efecto para los métodos 3 y superiores, a menos que se utilice -low_memory.
-partition_limit entero
Degrada la calidad limitando el número de bits utilizados por algunos macrobloques. El rango es de 0 (sin degradación, el predeterminado) a 100 (degradación completa). Los valores útiles suelen rondar los 30-70 para imágenes moderadamente grandes. En el formato VP8, la llamada partición de control tiene un límite de 512k y se utiliza para almacenar la siguiente información: si el macrobloque se omite, a qué segmento pertenece, si se codifica en modo intra 4x4 o intra 16x16, y finalmente los modos de predicción a utilizar para cada uno de los subbloques. Para una imagen muy grande, 512k solo deja espacio para unos pocos bits por macrobloque de 16x16. El mínimo absoluto es de 4 bits por macrobloque. La información de omisión, segmento y modo puede ocupar casi estos 4 bits (aunque es poco probable), lo que es problemático para imágenes muy grandes. El factor partition_limit controla con qué frecuencia se utilizará el modo más costoso en bits (intra 4x4). Esto es útil en caso de que se alcance el límite de 512k y se muestre el siguiente mensaje: Error code: 6 (PARTITION0_OVERFLOW: Partition #0 is too big to fit 512k). Si usar -partition_limit no es suficiente para cumplir la restricción de 512k, se deben usar menos segmentos para ahorrar más bits de encabezado por macrobloque. Ver la opción -segments. Ten en cuenta que las opciones -m y -q también influyen en las decisiones del codificador y en su capacidad para alcanzar este límite.

OPCIONES DE REGISTRO

Estas opciones controlan el nivel de salida:

-v
Imprime información adicional (tiempo de codificación en particular).
-print_psnr
Calcula e informa el PSNR promedio (relación señal-ruido pico).
-print_ssim
Calcula e informa la SSIM promedio (métrica de similitud estructural, ver https://en.wikipedia.org/wiki/SSIM para detalles adicionales).
-print_lsim
Calcula e informa la métrica de similitud local (suma del error más bajo entre los píxeles vecinos colocalizados).
-progress
Informa el progreso de la codificación en porcentaje.
-quiet
No imprime nada.
-short
Solo imprime información breve (tamaño del archivo de salida y PSNR) para fines de prueba.
-map entero
Salida adicional de mapa ASCII de información de codificación. Los valores de mapa posibles varían de 1 a 6. Esto solo está destinado a ayudar en la depuración.

OPCIONES ADICIONALES

Opciones más avanzadas son:

-s ancho alto
Especifica que el archivo de entrada consiste en muestras crudas Y'CbCr siguiendo la recomendación ITU-R BT.601, en formato lineal 4:2:0. El plano de luma tiene un tamaño de ancho x alto.
-pre entero
Especifica algunos pasos de preprocesamiento. Usar un valor de '2' activará un dithering pseudoaleatorio dependiente de la calidad durante la conversión RGBA->YUVA (solo compresión con pérdida).
-alpha_filter cadena
Especifica el método de filtrado predictivo para el plano alfa. Una de 'none', 'fast' o 'best', en orden creciente de complejidad y lentitud. El valor predeterminado es 'fast'. Internamente, el filtrado alfa se realiza utilizando cuatro predicciones posibles (ninguna, horizontal, vertical, gradiente). El modo 'best' probará cada modo sucesivamente y elegirá el que dé un tamaño menor. El modo 'fast' simplemente intentará formar una suposición a priori sin probar todos los modos.
-alpha_method entero
Especifica el algoritmo utilizado para la compresión alfa: 0 o 1. El algoritmo 0 indica sin compresión, 1 utiliza el formato sin pérdida WebP para la compresión. El valor predeterminado es 1.
-exact
Preserva los valores RGB en el área transparente. El valor predeterminado está desactivado, para ayudar a la compresibilidad.
-blend_alpha entero
Esta opción mezcla el canal alfa (si está presente) con la fuente usando el color de fondo especificado en hexadecimal como 0xrrggbb. El canal alfa se restablece después al valor opaco 255.
-noalpha
Usar esta opción descartará el canal alfa.
-hint cadena
Especifica la pista sobre el tipo de imagen de entrada. Los valores posibles son: photo, picture o graph.
-metadata cadena
Una lista separada por comas de metadatos para copiar de la entrada a la salida si están presentes. Valores válidos: all, none, exif, icc, xmp. El valor predeterminado es none.

Nota: cada formato de entrada puede no admitir todas las combinaciones.

-noasm
Desactiva todas las optimizaciones de ensamblaje.

ESTADO DE SALIDA

Si no hubo problemas durante la ejecución, cwebp sale con el valor de la constante C EXIT_SUCCESS. Esto suele ser cero.

Si ocurre un error, cwebp sale con el valor de la constante C EXIT_FAILURE. Esto suele ser uno.

EJEMPLOS

cwebp -q 50 -lossless picture.png -o picture_lossless.webp
cwebp -q 70 picture_with_alpha.png -o picture_with_alpha.webp
cwebp -sns 70 -f 50 -size 60000 picture.png -o picture.webp
cwebp -o picture.webp -- ---picture.png
