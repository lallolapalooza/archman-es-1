DESCRIPCIÓ

N

El programa ctangle convierte un documento fuente CWEB en un programa C/C++ que puede compilarse de la manera habitual. El archivo de salida incluye especificaciones #line para que la depuración pueda realizarse en términos del archivo fuente

CWEB.

El programa cweave convierte el mismo archivo CWEB en un archivo TeX que puede formatearse e imprimirse de la manera habitual. Se ocupa adecuadamente de detalles tipográficos como la disposición de la página y el uso de la indentación, cursiva, negrita, etc., y proporciona una extensa información de índice cruzado que recopila automáticamente

.

CWEB le permite preparar un único documento que contenga toda la información necesaria tanto para producir un p

rograma C/C++ compilable como para producir un documento bien formateado que describa el programa con todo
el detalle que el escritor desee. El usuario de CWEB debería estar familiarizado tanto con TeX como con C/C++.

US

O

La línea de comandos debe tener uno, dos o tres nombres. El primero se toma como el archivo de entrada CWEB (y se le añade .w si no tiene extensión). Si hay un segundo nombre, es un archivo de cambios (y se le añade .ch si no tiene extensión). El archivo de cambios anula partes del archivo CWEB, como se describe en la documentación. Si hay un tercer nombre, anula el nombre por defecto del archivo de salida, que normalmente es el mismo que el nombre del archivo de entrada (pero en el directorio actual) con la extensión .tex. Si solo desea cambiar el nombre del archivo de salida, pero no tiene un archivo de cambios que aplicar, puede usar `-' como el s

egundo ar
gumento.

DIFERENCIAS RESPECTO AL CWEB

ORIGINAL

CWEBbin se esfuerza por ser un reemplazo directo de CWEB, por lo que en general no debería notar ninguna diferencia al invocar los programas ni en la salida resultante. Sin embargo, hay algunas diferencias que vale la pena

señalar:
•
Las opciones --help, --quiet, --verbose, --version, y las banderas +c, -i, -o, +u y +lX son nuevas en CWEBbin y TeX
Live.
•
La opción +lX va acompañada de varios archivos envoltorio para cwebmac.tex con pies de página traducidos para alemán (+ld), francés (+lf) e italiano (+li
).
•
CWEB en TeX Live opera silenciosamente por defecto (a partir de 2019); use la opción --verbose para obtener el comportamiento
original.
•
La búsqueda de archivos con la variable de entorno CWEBINPUTS se ha extendido para permitir varios rutas separadas por dos puntos; véase ENTORNO más
abajo.
•
Si está correctamente configurado, los programas principales ctangle y cweave están localiz
ados con las
"utilidades
GNU gettext".

S

De hecho, las opciones se procesan de izquierda a derecha, de modo que una secuencia como --verbose -h solo mostrará la línea de presentación (+b) y el informe de progreso (+p), pero omitirá el mensaje de felicitación (-h)

ENTORN

O

La variable de entorno CWEBINPUTS se usa para buscar los archivos de entrada, o el valor predeterminado del sistema si CWEBINPUTS no está definida. Consulte tex(1) para conocer los detalles de la búsqueda. Para evitar conflictos con otros programas que también usan el entorno CWEBINPUTS, puede ser más específico y usar CWEBINPUTS_cweb para requisitos especiales en

CWEB.

Si está preparado para el soporte de NLS, ctangle y cweave usan la variable de entorno TEXMFLOCALEDIR para configurar el directorio principal donde las "utilidades GNU gettext" buscan los catálogos de

traducción.

Estas variables están preconfiguradas en el texmf.cnf d

e TeX
Live.
