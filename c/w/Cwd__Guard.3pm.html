NOMBRE

Cwd::Guard - Cambio temporal del directorio de trabajo (chdir)

SINOPSIS

use Cwd::Guard qw/cwd_guard/;
use Cwd;
my $dir = getcwd;
MYBLOCK: {
    my $guard = cwd_guard('/tmp/xxxxx') or die "falló chdir: $Cwd::Guard::Error";
    # chdir a /tmp/xxxxx
}
# de vuelta a $dir

DESCRIPCIÓN

CORE::chdir Cwd:: Guard puede cambiar el directorio actual (chdir) utilizando un ámbito limitado.

FUNCIONES

cwd_guard($dir);
Hace chdir a $dir y devuelve un objeto Cwd::Guard. Vuelve al directorio de trabajo actual si este objeto se destruye. Si falla el chdir, cwd_guard devuelve un valor indefinido. Puede obtener mensajes de error con $Gwd::Guard::Error.
