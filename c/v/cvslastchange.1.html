NOMBRE

cvslastchange - Muestra el último cambio confirmado en CVS para un archivo

SINOPSIS

cvslastchange [archivo]

DESCRIPCIÓN

cvslastchange muestra el último cambio confirmado en CVS para un archivo. Utiliza cvs diff y cvs log para hacer esto.

cvslastchange funciona en cualquier rama de CVS, no solo en HEAD.

Esta utilidad forma parte del Kit de Desarrollo de Software de KDE.

VER TAMBIÉN

cvslastlog(1) cvsrevertlast(1) cvs(1)
