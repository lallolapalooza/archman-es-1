NOMBRE

cvtbatch - Convierte archivos batch de Usenet al formato INN

SINOPSIS

cvtbatch [-w elementos]

DESCRIPCIÓN

cvtbatch lee la entrada estándar como una secuencia de líneas, convierte cada línea y la escribe en la salida estándar. Se utiliza para convertir archivos batch simples que solo contienen el token de la API de almacenamiento de un artículo a archivos batch de INN que contienen información adicional sobre cada artículo.

Cada línea se toma como un token de la API de almacenamiento que indica un artículo de Usenet. Solo se analiza la primera palabra de cada línea; todo lo que sigue a los espacios en blanco se ignora. Las líneas que no comienzan con un token válido también se ignoran silenciosamente.

Si el archivo de entrada consiste en una serie de IDs de mensaje, entonces use grephistory con la opción -s canalizada a cvtbatch.

OPCIONES

-w elementos
La opción -w especifica cómo se debe escribir cada línea de salida. Los elementos para esta opción deben elegirse de los elementos de opción "W" según se especifica en newsfeeds(5). Pueden elegirse del siguiente conjunto: 
b    Tamaño del artículo en bytes.
f    Token de la API de almacenamiento del artículo (igual que "n").
m    ID del mensaje del artículo.
n    Token de la API de almacenamiento del artículo.
t    Hora de llegada del artículo como segundos desde la época.

El valor predeterminado es "nm", es decir, el token de la API de almacenamiento seguido del ID del mensaje del artículo.
