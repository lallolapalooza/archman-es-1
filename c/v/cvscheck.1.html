NOMBRE

cvscheck - Informe de estado sin conexión para archivos en un módulo CVS extraído.

SINOPSIS

cvscheck [dir]

DESCRIPCIÓN

cvscheck imprime información sobre el estado de tu extracción local de CVS sin comunicarse con el servidor. Esto significa que es extremadamente rápido y no requiere conexión de red.

El directorio dado y todos sus subdirectorios se procesarán recursivamente. Si no se proporciona ningún directorio, se utilizará el directorio actual y sus subdirectorios recursivos.

Cada archivo con un estado interesante se imprimirá con un carácter de estado delante de su nombre. Los caracteres de estado son los siguientes.

? foobar.c

El archivo no es conocido por CVS

M foobar.c

El archivo está definitivamente modificado localmente

m foobar.c

El archivo *podría* tener cambios locales. Deberías hacer un diff con el servidor para asegurarte.

C foobar.c

El archivo tiene un conflicto de CVS y por lo tanto no se puede confirmar.

U foobar.c

Este archivo está en CVS pero falta en tu extracción local.

T foobar.c

Este archivo tiene una etiqueta CVS pegajosa inusual.

A foobar.c

Has realizado un cvs add para este archivo, pero aún no lo has confirmado.

R foobar.c

Has realizado un cvs rm para este archivo, pero aún no lo has confirmado.

Esta utilidad es parte del Kit de Desarrollo de Software de KDE.

VER TAMBIÉN

cvs(1)
