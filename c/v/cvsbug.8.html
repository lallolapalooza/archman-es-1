DESCRIPCIÓ

N

cvsbug es una herramienta utilizada para enviar informes de problema (PR) a un sitio central de soporte. En la mayoría de los casos, el site correcto será el predeterminado. Este argumento indica el sitio de soporte que es responsable de la categoría de problema involucrada. Algunos sitios pueden usar una dirección local como predeterminada. Los valores de site se definen utilizando aliases

(5).

cvsbug invoca un editor en una plantilla de informe de problema (después de intentar completar algunos campos con valores predeterminados razonables). Cuando sales del editor, cvsbug envía el formulario completado al Sistema de Gestión de Informes de Problema (GNATS) en un sitio central de soporte. En el sitio de soporte, al PR se le asigna un número único y se almacena en la base de datos GNATS según su categoría y su submitter-id. GNATS responde automáticamente con un acuse de recibo, citando la categoría y el número del

PR.

Para asegurar que un PR se maneje rápidamente, debe contener tu (único) submitter-id y una de las categorías disponibles para identificar el área del problema. (Usa `cvsbug -L' para ver una lista de categorías.

)

La plantilla de cvsbug en tu sitio ya debería estar personalizada con tu submitter-id (ejecutar `install-sid submitter-id' para lograr esto es parte de los procedimientos de instalación de cvsbug). Si esto no se ha hecho, consulta a tu administrador de sistema para obtener tu submitter-id, o solicita uno a tu sitio de soporte invocando `cvsbug --request-id'. Si tu sitio no distingue entre diferentes sitios de usuario, o si no estás afiliado con el sitio de soporte, usa `net' para este

campo.

Cuanto más precisa sea tu descripción del problem

a y más completa tu información, más rápido t
u equipo de soporte podrá resolver tus problemas.

CÓMO RELLENAR UN INFORME DE

PROBLEMA

Los informes de problema deben tener una forma particular para que un programa pueda gestionarlos fácilmente. Por favor, recuerda las siguientes

directrices:
  • describe solo un problema con cada informe de
    • problema.
  • Para el correo de seguimiento, usa la misma línea de asunto que la del acuse de recibo automático. Consiste en la categoría, el número del PR y la línea de sinopsis original. Esto permite al sitio de soporte relacionar varios mensajes de correo con un PR particular y registrarlos
    • automáticamente.
  • Por favor, intenta ser lo más preciso posible en la línea de asunto y/o
    • sinopsis.
  • La línea de asunto y la de sinopsis no son confidenciales. Esto
    • se debe a que las listas de errores abiertos se compila
n a partir de ellas. Evita información confidencial allí.

Consulta el archivo Info de GNU Info file cvsbug.info o el documento Reporting Problems With cvsbug para informació

n detallada sobre
cómo reportar problemas
