CCKGQR

Propósito:

!>
!> CCKGQR prueba
!> CGGQRF: Factorización GQR para la matriz A de N por M y la matriz B de N por P,
!> CGGRQF: Factorización GRQ para la matriz A de M por N y la matriz B de P por N.
!>

Parámetros

NM 
!>          NM es ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array de ENTEROS, dimensión (NM)
!>          Los valores de la dimensión fila(columna) M de la matriz.
!>

NP

!>          NP es ENTERO
!>          El número de valores de P contenidos en el vector PVAL.
!>

PVAL

!>          PVAL es un array de ENTEROS, dimensión (NP)
!>          Los valores de la dimensión fila(columna) P de la matriz.
!>

NN

!>          NN es ENTERO
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array de ENTEROS, dimensión (NN)
!>          Los valores de la dimensión columna(fila) N de la matriz.
!>

NMATS

!>          NMATS es ENTERO
!>          El número de tipos de matrices a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número máximo
!>          de tipos de matrices), entonces se generan todos los tipos diferentes
!>          para la prueba. Si NMATS < NTYPES, se lee otra línea de entrada
!>          para obtener los números de los tipos de matrices a usar.
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los elementos
!>          del array deben estar entre 0 y 4095, de lo contrario se reducirán
!>          módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números aleatorios
!>          después de que todas las matrices de prueba hayan sido generadas.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que se imprima
!>          cada relación de prueba, use THRESH = 0.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para M o N, utilizado en la dimensionamiento
!>          de los arrays de trabajo.
!>

A

!>          A es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

AQ

!>          AQ es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

AR

!>          AR es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

TAUA

!>          TAUA es un array COMPLEJO, dimensión (NMAX)
!>

B

!>          B es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

BF

!>          BF es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

BZ

!>          BZ es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

BT

!>          BT es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

BWK

!>          BWK es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

TAUB

!>          TAUB es un array COMPLEJO, dimensión (NMAX)
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array REAL, dimensión (NMAX)
!>

NIN

!>          NIN es ENTERO
!>          La unidad de número para entrada.
!>

NOUT

!>          NOUT es ENTERO
!>          La unidad de número para salida.
!>

INFO

!>          INFO es ENTERO
!>          = 0 :  salida exitosa
!>          > 0 :  Si CLATMS devuelve un código de error, se devuelve su valor absoluto.
!>
