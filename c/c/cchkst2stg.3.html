CCHKST2ST

G

Propósito

: 
!>
!> CCHKST2STG verifica las rutinas del problema de autovalores hermitiano
!> utilizando las técnicas de reducción de 2 etapas. Dado que la generación
!> de Q o de los vectores no está disponible en esta versión, solo
!> comparamos el autovalor resultante al usar la de 2 etapas con el
!> considerado como referencia usando la reducción estándar de 1 etapa
!> CHETRD. Para ello, llamamos al CHETRD estándar y calculamos D1 usando
!> DSTEQR, luego llamamos al CHETRD_2STAGE de 2 etapas con Upper y Lower
!> y calculamos D2 y D3 usando DSTEQR y luego reemplazamos las pruebas
!> 3 y 4 por las pruebas 11 y 12. Las pruebas 1 y 2 permanecen para verificar que
!> los resultados de 1 etapa son correctos y pueden ser confiados.
!> Esta rutina de prueba convergerá hacia CCHKST en la próxima
!> versión cuando se implementen los vectores y la generación de Q.
!>
!>    CHETRD factoriza A como  U S U* , donde * significa traspuesta conjugada,
!>    S es simétrica real tridiagonal, y U es unitaria.
!>    CHETRD puede usar solo el triángulo inferior o solo el superior
!>    de A; CCHKST2STG verifica ambos casos.
!>    U está representada como un producto de transformaciones
!>    de Householder, cuyos vectores están almacenados en las primeras
!>    n-1 columnas de V, y cuyos factores de escala están en TAU.
!>
!>    CHPTRD hace lo mismo que CHETRD, excepto que A y V están almacenados
!>    en formato .
!>
!>    CUNGTR construye la matriz U a partir del contenido de V y TAU.
!>
!>    CUPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!>    CSTEQR factoriza S como  Z D1 Z* , donde Z es la matriz
!>    unitaria de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal.  D2 es la matriz de
!>    autovalores calculada cuando Z no se calcula.
!>
!>    SSTERF calcula D3, la matriz de autovalores, por el
!>    método PWK, que no produce autovectores.
!>
!>    CPTEQR factoriza S como  Z4 D4 Z4* , para una
!>    matriz tridiagonal hermitiana definida positiva.
!>    D5 es la matriz de autovalores calculada cuando Z no se
!>    calcula.
!>
!>    SSTEBZ calcula autovalores seleccionados.  WA1, WA2, y
!>    WA3 denotarán autovalores calculados con alta
!>    precisión absoluta, con diferentes opciones de rango.
!>    WR denotará autovalores calculados con alta precisión
!>    relativa.
!>
!>    CSTEIN calcula Y, los autovectores de S, dados los
!>    autovalores.
!>
!>    CSTEDC factoriza S como Z D1 Z* , donde Z es la matriz
!>    unitaria de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal (opción 'I'). También puede
!>    actualizar una matriz unitaria de entrada, usualmente la salida
!>    de CHETRD/CUNGTR o CHPTRD/CUPGTR (opción 'V'). También puede
!>    solo calcular autovalores (opción 'N').
!>
!>    CSTEMR factoriza S como Z D1 Z* , donde Z es la matriz
!>    unitaria de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal (opción 'I').  CSTEMR
!>    usa la Representación Robusta Relativa siempre que sea posible.
!>
!> Cuando se llama a CCHKST2STG, se especifica un número de tamaños de matriz  () y un
!> número de tipos de matriz . Para cada tamaño ()
!> y cada tipo de matriz, se generará una matriz y se usará
!> para probar las rutinas hermitianas de autovalores. Para cada matriz, se realizará un número
!> de pruebas:
!>
!> (1)     | A - V S V* | / ( |A| n ulp ) CHETRD( UPLO='U', ... )
!>
!> (2)     | I - UV* | / ( n ulp )        CUNGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V* | / ( |A| n ulp ) CHETRD( UPLO='L', ... )
!>         reemplazado por | D1 - D2 | / ( |D1| ulp ) donde D1 es la
!>         matriz de autovalores calculada usando S y D2 es la
!>         matriz de autovalores calculada usando S_2stage la salida de
!>         CHETRD_2STAGE(, ,....). D1 y D2 se calculan
!>         vía DSTEQR('N',...)
!>
!> (4)     | I - UV* | / ( n ulp )        CUNGTR( UPLO='L', ... )
!>         reemplazado por | D1 - D3 | / ( |D1| ulp ) donde D1 es la
!>         matriz de autovalores calculada usando S y D3 es la
!>         matriz de autovalores calculada usando S_2stage la salida de
!>         CHETRD_2STAGE(, ,....). D1 y D3 se calculan
!>         vía DSTEQR('N',...)
!>
!> (5-8)   Igual que 1-4, pero para CHPTRD y CUPGTR.
!>
!> (9)     | S - Z D Z* | / ( |S| n ulp ) CSTEQR('V',...)
!>
!> (10)    | I - ZZ* | / ( n ulp )        CSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        CSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        SSTERF
!>
!> (13)    0 si los autovalores verdaderos (calculados por conteo de sturm)
!>         de S están dentro de THRESH de
!>         los de D1.  2*THRESH si no lo están.  (Probado usando
!>         SSTECH)
!>
!> Para S definida positiva,
!>
!> (14)    | S - Z4 D4 Z4* | / ( |S| n ulp ) CPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4* | / ( n ulp )        CPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       CPTEQR('N',...)
!>
!> Cuando S también es diagonalmente dominante por el factor gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          SSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              SSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y* | / ( |S| n ulp )  SSTEBZ, CSTEIN
!>
!> (21)    | I - Y Y* | / ( n ulp )          SSTEBZ, CSTEIN
!>
!> (22)    | S - Z D Z* | / ( |S| n ulp )    CSTEDC('I')
!>
!> (23)    | I - ZZ* | / ( n ulp )           CSTEDC('I')
!>
!> (24)    | S - Z D Z* | / ( |S| n ulp )    CSTEDC('V')
!>
!> (25)    | I - ZZ* | / ( n ulp )           CSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           CSTEDC('V'

!>                                              CSTEDC('N')
!>
!> La prueba 27 está deshabilitada en este momento porque CSTEMR no
!> garantiza una alta precisión relativa.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              CSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              CSTEMR('V', 'I')
!>
!> Las pruebas 29 a 34 están deshabilitadas en este momento porque CSTEMR
!> no maneja solicitudes de espectro parcial.
!>
!> (29)    | S - Z D Z* | / ( |S| n ulp )    CSTEMR('V', 'I')
!>
!> (30)    | I - ZZ* | / ( n ulp )           CSTEMR('V', 'I')
!>
!> (31)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         CSTEMR('N', 'I') vs. CSTEMR('V', 'I')
!>
!> (32)    | S - Z D Z* | / ( |S| n ulp )    CSTEMR('V', 'V')
!>
!> (33)    | I - ZZ* | / ( n ulp )           CSTEMR('V', 'V')
!>
!> (34)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         CSTEMR('N', 'V') vs. CSTEMR('V', 'V')
!>
!> (35)    | S - Z D Z* | / ( |S| n ulp )    CSTEMR('V', 'A')
!>
!> (36)    | I - ZZ* | / ( n ulp )           CSTEMR('V', 'A')
!>
!> (37)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         CSTEMR('N', 'A') vs. CSTEMR('V', 'A')
!>
!> Los  se especifican mediante un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (8)  Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (10) Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz hermitiana con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!> (16) Igual que (8), pero los elementos diagonales son todos positivos.
!> (17) Igual que (9), pero los elementos diagonales son todos positivos.
!> (18) Igual que (10), pero los elementos diagonales son todos positivos.
!> (19) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!> (20) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!> (21) Una matriz tridiagonal con predominio diagonal y entradas diagonales espaciadas geométricamente
!>      1, ..., ULP.
!> 




Parámetros


NSIZES

!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero,
!>          CCHKST2STG no hace nada. Debe ser al menos cero.
!> 


NN


!>          NN es un array INTEGER, de dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Se omitirán los valores cero. Los valores deben ser al menos
!>          cero.
!> 


NTYPES


!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CCHKST2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!> 


DOTYPE


!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!> 


ISEED


!>          ISEED es un array INTEGER, de dimensión (4)
!>          A la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y se pueden usar en la
!>          siguiente llamada a CCHKST2STG para continuar la misma secuencia de números
!>          aleatorios.
!> 


THRESH


!>          THRESH es REAL
!>          Una prueba se considerará como  si el , calculado como
!>          se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          está escalado para ser O(1), por lo que THRESH debería ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!> 


NOUNIT


!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0).
!> 


A


!>          A es un array COMPLEX de
!>                                  dimensión ( LDA , max(NN) )
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular. A la salida, A contiene la última matriz realmente
!>          utilizada.
!> 


LDA


!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al
!>          menos 1 y al menos max( NN ).
!> 


AP


!>          AP es un array COMPLEX de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz A almacenada en formato empaquetado.
!> 


SD


!>          SD es un array REAL de
!>                             dimensión( max(NN) )
!>          La diagonal de la matriz tridiagonal calculada por CHETRD.
!>          A la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!> 


SE


!>          SE es un array REAL de
!>                             dimensión( max(NN) )
!>          La antidiagonal de la matriz tridiagonal calculada por
!>          CHETRD. A la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!> 


D1


!>          D1 es un array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por CSTEQR simultáneamente
!>          con Z. A la salida, los valores propios en D1 corresponden con la
!>          matriz en A.
!> 


D2


!>          D2 es un array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por CSTEQR si Z no se
!>          calcula. A la salida, los valores propios en D2 corresponden con
!>          la matriz en A.
!> 


D3


!>          D3 es un array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por SSTERF. A la salida, los
!>          valores propios en D3 corresponden con la matriz en A.
!> 


D4


!>          D4 es un array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por CPTEQR(V).
!>          CPTEQR factoriza S como  Z4 D4 Z4*
!>          A la salida, los valores propios en D4 corresponden con la matriz en A.
!> 


D5


!>          D5 es un array REAL de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por CPTEQR(N)
!>          cuando Z no se calcula. A la salida, los
!>          valores propios en D4 corresponden con la matriz en A.
!> 


WA1


!>          WA1 es un array REAL de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          calculados por SSTEBZ.
!> 


WA2


!>          WA2 es un array REAL de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          calculados por SSTEBZ.
!>          Seleccionar valores aleatorios para IL y IU, y solicitar los
!>          valores propios del IL-ésimo al IU-ésimo.
!> 


WA3


!>          WA3 es un array REAL de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          calculados por SSTEBZ.
!>          Determinar los valores VL y VU de los valores propios IL-ésimo y IU-ésimo
!>          y solicitar todos los valores propios en este rango.
!> 


WR


!>          WR es un array REAL de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones.
!>          calculados por SSTEBZ.
!> 


U


!>          U es un array COMPLEX de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz unitaria calculada por CHETRD + CUNGTR.
!> 


LDU


!>          LDU es INTEGER
!>          La dimensión principal de U, Z, y V. Debe ser al menos 1
!>          y al menos max( NN ).
!> 


V


!>          V es un array COMPLEX de
!>                             dimensión( LDU, max(NN) ).
!>          Los vectores de Householder calculados por CHETRD al reducir A a
!>          forma tridiagonal. Los vectores calculados con UPLO='U' están
!>          en el triángulo superior, y los vectores calculados con UPLO='L'
!> 

     están en el triángulo inferior. (Como se describe en CHETRD, la
!>          subdiagonal y superdiagonal no se establecen a 1, aunque el
!>          vector de Householder real tiene un 1 en esa posición. Las
!>          rutinas que usan V, como CUNGTR, establecen esas entradas a
!>          1 antes de usarlas y luego las restauran.)
!
>

V

P 
!>          VP es un arreglo COMPLEX de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz V almacenada en formato empaquetado.
!
>

TA

U 
!>          TAU es un arreglo COMPLEX de
!>                             dimensión( max(NN) )
!>          Los factores de Householder calculados por CHETRD al reducir A
!>          a forma tridiagonal.
!
>

Z 
!>          Z es un arreglo COMPLEX de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz unitaria de autovectores calculada por CSTEQR,
!>          CPTEQR y CSTEIN.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX de
!>                      dimensión( LWORK )
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          El número de entradas en WORK. Este debe ser al menos
!>          1 + 4 * Nmax + 2 * Nmax * lg Nmax + 3 * Nmax**2
!>          donde Nmax = max( NN(j), 2 ) y lg = logaritmo en base 2.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER,
!>          Espacio de trabajo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          El número de entradas en IWORK. Este debe ser al menos
!>                  6 + 6*Nmax + 5 * Nmax * lg Nmax
!>          donde Nmax = max( NN(j), 2 ) y lg = logaritmo en base 2.
!
>

RWOR

K 
!>          RWORK es un arreglo REAL
!
>

LRWOR

K 
!>          LRWORK es INTEGER
!>          El número de entradas en LRWORK (dimensión( ??? )
!
>

RESUL

T 
!>          RESULT es un arreglo REAL, dimensión (26)
!>          Los valores calculados por las pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!
>

INF

O 
!>          INFO es INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algunos NN(j) < 0
