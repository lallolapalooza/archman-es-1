CCHKB

D

Propósito

: 
!>
!> CCHKBD comprueba las rutinas de descomposición en valores singulares (SVD).
!>
!> CGEBRD reduce una matriz general compleja A de m por n a forma bidiagonal
!> real superior o inferior mediante una transformación ortogonal: Q' * A * P = B
!> (o A = Q * B * P'). La matriz B es bidiagonal superior si m >= n
!> y bidiagonal inferior si m < n.
!>
!> CUNGBR genera las matrices ortogonales Q y P' a partir de CGEBRD.
!> Nótese que Q y P no son necesariamente cuadradas.
!>
!> CBDSQR calcula la descomposición en valores singulares de la matriz
!> bidiagonal B como B = U S V'. Se llama tres veces para calcular
!>    1)  B = U S1 V', donde S1 es la matriz diagonal de valores
!>        singulares y las columnas de las matrices U y V son los
!>        vectores singulares izquierdo y derecho, respectivamente, de B.
!>    2)  Igual que 1), pero los valores singulares se almacenan en S2 y
!>        los vectores singulares no se calculan.
!>    3)  A = (UQ) S (P'V'), la SVD de la matriz original A.
!> Además, CBDSQR tiene una opción para aplicar la matriz ortogonal izquierda
!> U a una matriz X, útil en aplicaciones de mínimos cuadrados.
!>
!> Para cada par de dimensiones de matriz (M,N) y cada tipo de matriz
!> seleccionado, se generan una matriz A de M por N y una matriz X de M por NRHS.
!> Las dimensiones del problema son las siguientes
!>    A:          M x N
!>    Q:          M x min(M,N) (pero M x M si NRHS > 0)
!>    P:          min(M,N) x N
!>    B:          min(M,N) x min(M,N)
!>    U, V:       min(M,N) x min(M,N)
!>    S1, S2      diagonal, orden min(M,N)
!>    X:          M x NRHS
!>
!> Para cada matriz generada, se realizan 14 pruebas:
!>
!> Probar CGEBRD y CUNGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Probar CBDSQR en la matriz bidiagonal B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), donde Y = Q' X
!>                                                  y   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contiene min(M,N) valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (9)   0 si los valores singulares reales de B están dentro de THRESH de
!>       los de S1. 2*THRESH si no lo están. (Probado usando
!>       SSVDCH)
!>
!> (10)  | S1 - S2 | / ( |S1| ulp ), donde S2 se calcula sin
!>                                   calcular U y V.
!>
!> Probar CBDSQR en la matriz A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Los tipos de matriz posibles son
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con elementos equiespaciados
!>      1, ..., ULP y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con elementos geométricamente espaciados
!>      1, ..., ULP y signos aleatorios.
!> (5)  Una matriz diagonal con elementos 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (3), pero multiplicada por SQRT( umbral de desbordamiento )
!> (7)  Igual que (3), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!> (8)  Una matriz de la forma U D V, donde U y V son ortogonales y
!>      D tiene elementos equiespaciados 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma U D V, donde U y V son ortogonales y
!>      D tiene elementos geométricamente espaciados 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (10) Una matriz de la forma U D V, donde U y V son ortogonales y
!>      D tiene elementos 1, ULP,..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!> (13) Matriz rectangular con elementos aleatorios elegidos de (-1,1).
!> (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!> Caso especial:
!> (16) Una matriz bidiagonal con elementos aleatorios elegidos de una
!>      distribución logarítmica en [ulp^2,ulp^(-2)]  (Es decir, cada
!>      elemento es e^x, donde x se elige uniformemente en
!>      [ 2 log(ulp), -2 log(ulp) ] .) Para *este* tipo:
!>      (a) No se llama a CGEBRD para reducirla a forma bidiagonal.
!>      (b) la bidiagonal es min(M,N) x min(M,N); si M<N, la
!>          matriz será bidiagonal inferior, de lo contrario superior.
!>      (c) solo se realizan las pruebas 5--8 y 14.
!>
!> Se puede seleccionar un subconjunto del conjunto completo de tipos de matriz a través
!> del array lógico DOTYPE.
!
>

Parámetro

s
NSIZES 
!>          NSIZES es INTEGER
!>          El número de valores de M y N contenidos en los vectores
!>          MVAL y NVAL. Los tamaños de matriz se usan en pares (M,N).
!
>

MVA

L 
!>          MVAL es un array INTEGER, dimensión (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!
>

NVA

L 
!>          NVAL es un array INTEGER, dimensión (NM)
!>          Los valores de la dimensión de columna de la matriz N.
!
>

NTYPE

S 
!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CCHKBD
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar las matrices que haya en A y B.
!>          Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE es un array LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño (m,n), se generará una matriz
!>          de tipo j. Si NTYPES es menor que el
!>          número máximo de tipos definidos (PARÁMETRO MAXTYP), entonces
!>          los tipos NTYPES+1 hasta MAXTYP no se generarán. Si
!>          NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) hasta
!>          DOTYPE(NTYPES) serán ignorados.
!
>

NRHS/i

> 
!>          NRHS es INTEGER
!>          El número de columnas en las matrices X, Y,
!>          y Z, utilizadas en la prueba de CBDSQR. Si NRHS = 0, entonces las
!>          operaciones en el lado derecho no serán probadas.
!>          NRHS debe ser al menos 0.
!
>

ISEE

D 
!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, serán reducidos módulo 4096. Además, ISEED(4) debe
!>          ser impar. Los valores de ISEED se modifican en la salida, y pueden
!>          usarse en la siguiente llamada a CCHKBD para continuar la misma secuencia
!>          de números aleatorios.
!
>

THRES

H 
!>          THRESH es REAL
!>          El valor umbral para las razones de prueba. Un resultado es
!>          incluido en el archivo de salida si RESULT >= THRESH. Para que
!>          se impriman todas las razones de prueba, use THRESH = 0. Tenga en cuenta que el
!>          valor esperado de las razones de prueba es O(1), por lo que THRESH debería
!>          ser un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,NMAX)
!>          donde NMAX es el valor máximo de N en NVAL.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,MMAX),
!>          donde MMAX es el valor máximo de M en MVAL.
!
>

B

D 
!>          BD es un array REAL, dimensión
!>                      (max(min(MVAL(j),NVAL(j))))
!
>

B

E 
!>          BE es un array REAL, dimensión
!>                      (max(min(MVAL(j),NVAL(j))))
!

1 
!>          S1 es un array REAL, dimensión
!>                      (max(min(MVAL(j),NVAL(j))))
!
>

S

2 
!>          S2 es un array REAL, dimensión
!>                      (max(min(MVAL(j),NVAL(j))))
!
>

X 
!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!
>

LD

X 
!>          LDX es INTEGER
!>          La dimensión principal de los arrays X, Y y Z.
!>          LDX >= max(1,MMAX).
!
>

Y 
!>          Y es un array COMPLEX, dimensión (LDX,NRHS)
!
>

Z 
!>          Z es un array COMPLEX, dimensión (LDX,NRHS)
!
>

Q 
!>          Q es un array COMPLEX, dimensión (LDQ,MMAX)

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,MMAX).

P

T

LDP

T 
!>          LDPT es INTEGER
!>          La dimensión principal de los arrays PT, U y V.
!>          LDPT >= max(1, max(min(MVAL(j),NVAL(j)))).

U

K

!>          El número de entradas en WORK. Este debe ser al menos
!>          3(M+N) y M(M + max(M,N,k) + 1) + N*min(M,N) para todos
!>          los pares (M,N)=(MM(j),NN(j))

K 
!>          RWORK es un array REAL, dimensión

NOU

T 
!>          NOUT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0.)
!
>

INF

O 
!>          INFO es INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algún MM(j) < 0
!>           -3: Algún NN(j) < 0
!>           -4: NTYPES < 0
!>           -6: NRHS  < 0
!>           -8: THRESH < 0
!>          -11: LDA < 1 o LDA < MMAX, donde MMAX es max( MM(j) ).
!>          -17: LDB < 1 o LDB < MMAX.
!>          -21: LDQ < 1 o LDQ < MMAX.
!>          -23: LDP < 1 o LDP < MNMAX.
!>          -27: LWORK demasiado pequeño.
!>          Si CLATMR, CLATMS, CGEBRD, CUNGBR o CBDSQR
!>              devuelve un código de error, se devuelve
!>              su valor absoluto.
!>
!>-----------------------------------------------------------------------
!>
!>     Algunas Variables y Parámetros Locales:
!>     ---- ----- --------- --- ----------
!>
!>     ZERO, ONE       Real 0 y 1.
!>     MAXTYP          El número de tipos definidos.
!>     NTEST           El número de pruebas realizadas, o que pueden
!>                     realizarse hasta ahora, para la matriz actual.
!>     MMAX            El valor más grande en NN.
!>     NMAX            El valor más grande en NN.
!>     MNMIN           min(MM(j), NN(j)) (la dimensión de la matriz
!>                     bidiagonal.)
!>     MNMAX           El valor máximo de MNMIN para j=1,...,NSIZES.
!>     NFAIL           El número de pruebas que han excedido THRESH
!>     COND, IMODE     Valores a pasar a los generadores de matrices.
!>     ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>     OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>     RTOVFL, RTUNFL  Raíces cuadradas de los 2 valores anteriores.
!>     ULP, ULPINV     Precisión relativa más fina y su inverso.
!>
!>             Los siguientes cuatro arrays decodifican JTYPE:
!>     KTYPE(j)        El tipo general (1-10) para el tipo .
!>     KMODE(j)        El valor MODE a pasar al generador de
!>                     matrices para el tipo .
!>     KMAGN(j)        El orden de magnitud ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!
