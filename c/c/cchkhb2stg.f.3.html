subrutina cchkhb2stg (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) sd, real, dimension( * ) se, real, dimension( * ) d1, real, dimension( * ) d2, real, dimension( * ) d3, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result, integer info)

CCHKHB2STG

Propósito:

!>
!> CCHKHB2STG prueba la reducción de una matriz bandada hermítica a tridiagonal
!> forma, usada con el problema de valores propios hermítico.
!>
!> CHBTRD factoriza una matriz bandada hermítica A como  U S U* , donde * significa
!> transpuesta conjugada, S es tridiagonal simétrica, y U es unitaria.
!> CHBTRD puede usar solo el triángulo inferior o solo el superior
!> de A; CCHKHB2STG verifica ambos casos.
!>
!> CHETRD_HB2ST factoriza una matriz bandada hermítica A como  U S U* ,
!> donde * significa transpuesta conjugada, S es tridiagonal simétrica, y U es
!> unitaria. CHETRD_HB2ST puede usar solo el triángulo inferior o solo
!> el superior de A; CCHKHB2STG verifica ambos casos.
!>
!> DSTEQR factoriza S como  Z D1 Z'.
!> D1 es la matriz de valores propios calculada cuando Z no se calcula
!> y a partir de la S resultante de DSBTRD  (usada como referencia para DSYTRD_SB2ST)
!> D2 es la matriz de valores propios calculada cuando Z no se calcula
!> y a partir de la S resultante de DSYTRD_SB2ST .
!> D3 es la matriz de valores propios calculada cuando Z no se calcula
!> y a partir de la S resultante de DSYTRD_SB2ST .
!>
!> Cuando se llama a CCHKHB2STG, se especifica un número de matrices  (), un número
!> de anchos de banda (), y un número de matrices  son
!> especificados.  Para cada tamaño (), cada ancho de banda () menor o
!> igual a , y cada tipo de matriz, se generará una matriz
!> y se usará para probar la rutina de reducción bandada hermítica.  Para cada
!> matriz, se realizarán una serie de pruebas:
!>
!> (1)     | A - V S V* | / ( |A| n ulp )  calculado por CHBTRD con
!>                                         UPLO='U'
!>
!> (2)     | I - UU* | / ( n ulp )
!>
!> (3)     | A - V S V* | / ( |A| n ulp )  calculado por CHBTRD con
!>                                         UPLO='L'
!>
!> (4)     | I - UU* | / ( n ulp )
!>
!> (5)     | D1 - D2 | / ( |D1| ulp )      donde D1 es calculado por
!>                                         DSBTRD con UPLO='U' y
!>                                         D2 es calculado por
!>                                         CHETRD_HB2ST con UPLO='U'
!>
!> (6)     | D1 - D3 | / ( |D1| ulp )      donde D1 es calculado por
!>                                         DSBTRD con UPLO='U' y
!>                                         D3 es calculado por
!>                                         CHETRD_HB2ST con UPLO='L'
!>
!> Los  se especifican por un arreglo NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican por un arreglo lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con elementos espaciados uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con elementos espaciados geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con  elementos 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento por defecto )
!>
!> (8)  Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene elementos espaciados uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene elementos espaciados geométricamente 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (10) Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene  elementos 1, ULP,..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento por defecto )
!>
!> (13) Matriz hermítica con elementos aleatorios elegidos de (-1,1).
!> (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento por defecto )
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar.  Si es cero,
!>          CCHKHB2STG no hace nada.  Debe ser al menos cero.
!>

NN

!>          NN es un arreglo INTEGER, dimensión (NSIZES)
!>          Un arreglo que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos.  Los valores deben ser al menos
!>          cero.
!>

NWDTHS

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a usar.  Si es cero,
!>          CCHKHB2STG no hace nada.  Debe ser al menos cero.
!>

KK

!>          KK es un arreglo INTEGER, dimensión (NWDTHS)
!>          Un arreglo que contiene los anchos de banda a usar para las matrices
!>          bandadas.  Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, CCHKHB2STG
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que haya en A.  Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no serán generados.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no, serán reducidos módulo 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED son modificados en la salida, y pueden usarse en la
!>          siguiente llamada a CCHKHB2STG para continuar la misma secuencia de números aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba contará como  si el , calculado como
!>          se describió arriba, excede THRESH.  Nótese que el error
!>          está escalado para ser O(1), por lo que THRESH debería ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100.  En particular,
!>          no debería depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0).
!>

A

!>          A es un array COMPLEX, dimensión
!>                            (LDA, max(NN))
!>          Se usa para almacenar la matriz cuyos autovalores deben ser
!>          calculados.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  Debe ser al menos 2 (¡no 1!)
!>          y al menos max( KK )+1.
!>

SD

!>          SD es un array REAL, dimensión (max(NN))
!>          Se usa para almacenar la diagonal de la matriz tridiagonal
!>          calculada por CHBTRD.
!>

SE

!>          SE es un array REAL, dimensión (max(NN))
!>          Se usa para almacenar la superdiagonal de la matriz
!>          tridiagonal calculada por CHBTRD.
!>

D1

!>          D1 es un array REAL, dimensión (max(NN))
!>          Se usa para almacenar los autovalores resultantes de la
!>          forma tridiagonal usando DSBTRD.
!>

D2

!>          D2 es un array REAL, dimensión (max(NN))
!>

D3

!>          D3 es un array REAL, dimensión (max(NN))
!>

U

!>          U es un array COMPLEX, dimensión (LDU, max(NN))
!>          Se usa para almacenar la matriz unitaria calculada por CHBTRD.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U.  Debe ser al menos 1
!>          y al menos max( NN ).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          El número de entradas en WORK.  Debe ser al menos
!>          max( LDA+1, max(NN)+1 )*max(NN).
!>

RWORK

!>          RWORK es un array REAL
!>

RESULT

!>          RESULT es un array REAL, dimensión (4)
!>          Los valores calculados por las pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!>

INFO

!>          INFO es INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>
!>-----------------------------------------------------------------------
!>
!>       Algunas Variables y Parámetros Locales:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 y 1.
!>       MAXTYP          El número de tipos definidos.
!>       NTEST           El número de pruebas realizadas, o que pueden
!>                       realizarse hasta ahora, para la matriz actual.
!>       NTESTT          El número total de pruebas realizadas hasta ahora.
!>       NMAX            El valor más grande en NN.
!>       NMATS           El número de matrices generadas hasta ahora.
!>       NERRS           El número de pruebas que han excedido THRESH
!>                       hasta ahora.
!>       COND, IMODE     Valores a pasar a los generadores de matrices.
!>       ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>       OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>       ULP, ULPINV     Precisión relativa más fina y su inversa.
!>       RTOVFL, RTUNFL  Raíces cuadradas de los 2 valores anteriores.
!>               Las siguientes cuatro matrices decodifican JTYPE:
!>       KTYPE(j)        El tipo general (1-10) para el tipo .
!>       KMODE(j)        El valor MODE a pasar al generador de matrices
!>                       para el tipo .
!>       KMAGN(j)        El orden de magnitud ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!>
