CCSDT

S

Propósito

: 
!>
!> CCSDTS prueba CUNCSD, que, dada una matriz unitaria X particionada M-por-M,
!>              Q  M-Q
!>       X = [ X11 X12 ] P   ,
!>           [ X21 X22 ] M-P
!>
!> calcula la CSD
!>
!>       [ U1    ]**T * [ X11 X12 ] * [ V1    ]
!>       [    U2 ]      [ X21 X22 ]   [    V2 ]
!>
!>                             [  I  0  0 |  0  0  0 ]
!>                             [  0  C  0 |  0 -S  0 ]
!>                             [  0  0  0 |  0  0 -I ]
!>                           = [---------------------] = [ D11 D12 ] .
!>                             [  0  0  0 |  I  0  0 ]   [ D21 D22 ]
!>                             [  0  S  0 |  0  C  0 ]
!>                             [  0  0  I |  0  0  0 ]
!>
!> y también SORCSD2BY1, que, dada
!>          Q
!>       [ X11 ] P   ,
!>       [ X21 ] M-P
!>
!> calcula la CSD 2-por-1
!>
!>                                     [  I  0  0 ]
!>                                     [  0  C  0 ]
!>                                     [  0  0  0 ]
!>       [ U1    ]**T * [ X11 ] * V1 = [----------] = [ D11 ] ,
!>       [    U2 ]      [ X21 ]        [  0  0  0 ]   [ D21 ]
!>                                     [  0  S  0 ]
!>                                     [  0  0  I ]
!
>

Parámetro

s

!>          El número de filas de la matriz X.  M >= 0.

>

!>          P es INTEGER
!>          El número de filas de la matriz X11.  P >= 0.
!
>

!>          El número de columnas de la matriz X11.  Q >= 0.
!
>

!>          La matriz X de M-por-M.
!
>

!>          ver CUNCSD para más detalles.

1

!

1 
!>          LDU1 es INTEGER
!>          La dimensión principal del arreglo U1. LDU >= max(1,P).
!
>

U

2 
!>          U2 es un arreglo COMPLEX, dimensión(LDU2,M-P)
!>          La matriz unitaria U2 de (M-P)-por-(M-P).

>

2

!>          La dimensión principal del arreglo U2. LDU >= max(1,M-P).

IWOR

K

K 
!>          RWORK es un arreglo REAL
!

RESUL

T 
!>          RESULT es un arreglo REAL, dimensión (15)
!>          Los cocientes de prueba:
!>          Primero, la CSD 2-por-2:
!>          RESULT(1) = norm( U1'*X11*V1 - D11 ) / ( MAX(1,P,Q)*EPS2 )
!>          RESULT(2) = norm( U1'*X12*V2 - D12 ) / ( MAX(1,P,M-Q)*EPS2 )
!>          RESULT(3) = norm( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(4) = norm( U2'*X22*V2 - D22 ) / ( MAX(1,M-P,M-Q)*EPS2 )
!>          RESULT(5) = norm( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(6) = norm( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(7) = norm( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(8) = norm( I - V2T'*V2T ) / ( MAX(1,M-Q)*ULP )
!>          RESULT(9) = 0        si THETA está en orden creciente y
!>                               todos los ángulos están en [0,pi/2] 
!>                    = ULPINV   en caso contrario.
!>          Luego, la CSD 2-por-1:
!>          RESULT(10) = norm( U1'*X11*V1 - D11 ) / ( MAX(1,P,Q)*EPS2 )
!>          RESULT(11) = norm( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(12) = norm( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(13) = norm( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(14) = norm( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(15) = 0        si THETA está en orden creciente y
!>                                todos los ángulos están en [0,pi/2] 
!>                     = ULPINV   en caso contrario.
!>          ( EPS2 = MAX( norm( I - X'*X ) / M, ULP ). )
!
>
