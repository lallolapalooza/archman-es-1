NOMBRE

cccheck - Realiza la verificación estática de contratos de código para ensamblajes CLR.

SINOPSIS

cccheck --assembly=<ensamblado> [opciones]

DESCRIPCIÓN

Realiza la verificación estática de contratos de código para encontrar errores e inconsistencias entre el código y la especificación. Esto incluye análisis de no nulidad y de enteros.

El ensamblado debe haber sido compilado con CONTRACTS_FULL definido, de lo contrario, las llamadas a los métodos de contrato habrán sido eliminadas por el compilador.

Actualmente, solo se admiten los métodos Contract.Assume() y Contract.Assert(). Solo se admite el análisis de no nulidad, los análisis consecutivos están en desarrollo. Se mostrará un mensaje de error si cccheck no puede procesar todos o algunos de los métodos del ensamblado especificado.

OPCIONES DE CONFIGURACIÓN

--assembly <nombre-de-ensamblado>
El ensamblado para realizar la verificación estática.
--debug
Muestra información de depuración sobre el proceso de demostración de las aserciones. Muestra cuatro capas de abstracción: capa bruta, capa de pila, capa de montón y nivel de expresión sustituida.
--method=<subcadena-del-nombre-del-método>
Cadena para encontrar el método. Filtra todos los métodos en el ensamblado donde el nombre del método tiene este parámetro como subcadena.
--help
Muestra la ayuda para cccheck, enumerando las opciones de configuración.

EJEMPLOS

Supongamos que tiene un método:

void Method() {
object x = null;
int y = 1;
if (y % 2 == 1)
x = new object();
else
x = new string();


Contract.Assert(x != null); }

Después de la verificación, la herramienta mostrará los resultados en el siguiente formato: "Aserción en: [Subrutina: <id> Bloque <id-bloque> PC <id>] :
es (verdadero|falso|no demostrado|no alcanzable)". (PC es un contador de programa)
