CCKGQR

Propósito:

!>
!> CCKGQR prueba
!> CGGQRF: factorización GQR para la matriz A de N por M y la matriz B de N por P,
!> CGGRQF: factorización GRQ para la matriz A de M por N y la matriz B de P por N.
!>

Parámetros

NM 
!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array INTEGER, dimensión (NM)
!>          Los valores de la dimensión de filas(columnas) de la matriz M.
!>

NP

!>          NP es INTEGER
!>          El número de valores de P contenidos en el vector PVAL.
!>

PVAL

!>          PVAL es un array INTEGER, dimensión (NP)
!>          Los valores de la dimensión de filas(columnas) de la matriz P.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, dimensión (NN)
!>          Los valores de la dimensión de columnas(filas) de la matriz N.
!>

NMATS

!>          NMATS es INTEGER
!>          El número de tipos de matriz a probar para cada combinación
!>          de dimensiones de matriz.  Si NMATS >= NTYPES (el número
!>          máximo de tipos de matriz), se generan todos los tipos
!>          diferentes para la prueba.  Si NMATS < NTYPES, se lee otra línea de
!>          entrada para obtener los números de los tipos de matriz a utilizar.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios.  Los elementos del array
!>          deben estar entre 0 y 4095, de lo contrario se reducirán
!>          módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números aleatorios después de
!>          que se hayan generado todas las matrices de prueba.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las razones de prueba.  Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH.  Para que se
!>          impriman todas las razones de prueba, use THRESH = 0.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, utilizado en la definición de
!>          las dimensiones de los arrays de trabajo.
!>

A

!>          A es un array COMPLEX, dimensión (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEX, dimensión (NMAX*NMAX)
!>

AQ

!>          AQ es un array COMPLEX, dimensión (NMAX*NMAX)
!>

AR

!>          AR es un array COMPLEX, dimensión (NMAX*NMAX)
!>

TAUA

!>          TAUA es un array COMPLEX, dimensión (NMAX)
!>

B

!>          B es un array COMPLEX, dimensión (NMAX*NMAX)
!>

BF

!>          BF es un array COMPLEX, dimensión (NMAX*NMAX)
!>

BZ

!>          BZ es un array COMPLEX, dimensión (NMAX*NMAX)
!>

BT

!>          BT es un array COMPLEX, dimensión (NMAX*NMAX)
!>

BWK

!>          BWK es un array COMPLEX, dimensión (NMAX*NMAX)
!>

TAUB

!>          TAUB es un array COMPLEX, dimensión (NMAX)
!>

WORK

!>          WORK es un array COMPLEX, dimensión (NMAX*NMAX)
!>

RWORK

!>          RWORK es un array REAL, dimensión (NMAX)
!>

NIN

!>          NIN es INTEGER
!>          El número de unidad para la entrada.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0 :  salida exitosa
!>          > 0 :  Si CLATMS devuelve un código de error, se devuelve el valor absoluto
!>                 del mismo.
!>
