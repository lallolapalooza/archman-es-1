CCOMPS(1) Manual de Comandos Generales CCOMPS(1)

NOMBRE

ccomps - filtro de componentes conexos para grafos

SINOPSIS

ccomps [ -sxvenzC? ] [ -X[#%]s[-f] ] [ -oarchivo_salida ] [ archivos ]

DESCRIPCIÓN

ccomps descompone grafos en sus componentes conexos, imprimiendo los componentes en la salida estándar.

OPCIONES

Se soportan las siguientes opciones:

-e
No inducir aristas en los componentes conexos.
-s
No se imprime ningún grafo de salida. El valor de retorno se puede usar para comprobar si el grafo está conectado o no.
-x
Solo se imprimen los componentes conexos, como grafos separados.
-v
Se imprimen recuentos de nodos, aristas y componentes conexos.
-z
Ordenar los componentes por tamaño, con el más grande primero. Esto solo es efectivo si está presente -x o -X#. Por lo tanto, -zX#0 hará que se imprima el componente más grande.
-C
Usar clústeres al calcular los componentes además de la conectividad normal de aristas. En esencia, esto da los componentes conexos del grafo derivado en el que los nodos son clústeres de nivel superior y nodos del grafo original. Esto mantiene toda la estructura de subgrafos dentro de un componente, incluso si un subgrafo no contiene ningún nodo.
-n
No proyectar la estructura del subgrafo. Normalmente, si ccomps produce componentes como grafos distintos del grafo de entrada, definirá subgrafos que son proyecciones de subgrafos del grafo de entrada sobre el componente. (Si la proyección está vacía, no se produce ningún subgrafo). Si se establece esta bandera, el componente contendrá solo los nodos y aristas relevantes.
-X nombre_nodo
Imprime solo el componente que contiene el nodo nombre_nodo, si existe.
-X# inicio
-X# inicio-
-X# inicio-fin
Imprime solo los componentes en el rango de índices dado. En la primera forma, solo se imprime el componente cuyo índice es inicio, si existe. En la segunda forma, se imprime cada componente cuyo índice es al menos inicio. En la última forma, solo se imprimen aquellos componentes cuyos índices están en el rango [inicio,fin]. Por lo tanto, la bandera -x es equivalente a -X#0-.
-X% min
-X% min-
-X% min-max
Imprime solo los componentes en el rango de tamaños dado. En la primera forma, solo se imprime un componente cuyo tamaño es min, si existe. En la segunda forma, se imprime cada componente cuyo tamaño es al menos min. En la última forma, solo se imprimen aquellos componentes cuyos tamaños están en el rango [min,max].
-o archivo_salida
Si se especifica, cada grafo se escribirá en un archivo diferente con nombres derivados de archivo_salida. En particular, si se utilizan ambas banderas -o y -x, entonces cada componente conexo se escribe en un archivo diferente. Si archivo_salida no tiene una extensión, el primer archivo se llamará archivo_salida; luego el siguiente archivo_salida_1, luego el siguiente archivo_salida_2, y así sucesivamente. Si archivo_salida tiene una extensión, es decir, tiene la forma base.sfx, entonces los archivos se llamarán base.sfx, base_1.sfx, base_2.sfx, etc.

Por defecto, se imprime cada grafo de entrada, y cada componente conexo se da como un subgrafo cuyo nombre es una concatenación del nombre del grafo de entrada, la cadena "_cc_" y el número del componente.

OPERANDOS

Se soporta el siguiente operando:

archivos
Nombres de archivos que contienen 1 o más grafos en formato dot. Si no se especifica ningún operando archivos, se usará la entrada estándar.

CÓDIGOS DE RETORNO

A menos que se use para extraer un único componente conexo, ccomps devuelve 0 si todos los grafos de entrada están conectados; y un valor distinto de cero si algún grafo tiene múltiples componentes o si ocurrió algún error. Si solo se está extrayendo un único componente, ccomps devuelve 0 en caso de éxito y un valor distinto de cero si ocurrió un error.

ERRORES

Es posible, aunque improbable, que los nombres utilizados para los componentes conexos y sus subgrafos entren en conflicto con nombres de subgrafos existentes.
