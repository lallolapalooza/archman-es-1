ccmakedep(1) Manual de Comandos Generales ccmakedep(1)

NOMBRE

ccmakedep - crea dependencias en makefiles usando un compilador C

SINOPSIS

ccmakedep [ flags-cpp ] [ -wancho ] [ -scadena-mágica ] [ -fmakefile ] [ -osufijo-objeto ] [ -v ] [ -a ] [ -cccompilador ] [ -- opciones -- ] archivo-fuente ...

DESCRIPCIÓN

El programa ccmakedep llama a un compilador C para preprocesar cada archivo-fuente, y utiliza la salida para construir reglas de makefile que describen sus dependencias. Estas reglas instruyen a make(1) sobre qué archivos objeto deben ser recompilados cuando una dependencia ha cambiado.

Por defecto, ccmakedep coloca su salida en el archivo llamado makefile si existe, de lo contrario en Makefile. Se puede especificar un makefile alternativo con la opción -f. Primero busca en el makefile una línea que comience con

# NO BORRAR

o una proporcionada con la opción -s, como delimitador para la salida de dependencias. Si la encuentra, eliminará todo lo que siga hasta el final del makefile y colocará la salida después de esta línea. Si no la encuentra, el programa añadirá la cadena al makefile y colocará la salida después de ella.

EJEMPLO

Normalmente, ccmakedep se utilizará en un objetivo de makefile para que al escribir 'make depend' se actualicen las dependencias del makefile. Por ejemplo,

    SRCS = archivo1.c archivo2.c ...
    CFLAGS = -O -DHACK -I../foobar -xyz
    depend:
            ccmakedep -- $(CFLAGS) -- $(SRCS)

OPCIONES

El programa ignorará cualquier opción que no entienda, por lo que puedes usar los mismos argumentos que usarías para cc(1), incluyendo las opciones -D y -U para definir y anular la definición de símbolos, y -I para establecer la ruta de inclusión.

-a
Añade las dependencias al archivo en lugar de reemplazar las existentes.
-cccompilador
Utiliza este compilador para generar dependencias.
-fmakefile
Nombre del archivo. Esto te permite especificar un makefile alternativo en el que ccmakedep pueda colocar su salida. Especificar “-” como nombre de archivo (es decir, -f-) envía la salida a la salida estándar en lugar de modificar un archivo existente.
-scadena
Cadena delimitadora de inicio. Esta opción te permite especificar una cadena diferente para que ccmakedep la busque en el makefile. La predeterminada es “# NO BORRAR”.
-v
Sea verboso: muestre el comando del compilador C antes de ejecutarlo.
-- opciones --
Si ccmakedep encuentra un doble guion (--) en la lista de argumentos, entonces cualquier argumento no reconocido que siga será ignorado silenciosamente. Un segundo doble guion termina este tratamiento especial. De esta manera, ccmakedep puede ignorar de forma segura argumentos esotéricos del compilador que normalmente se encontrarían en una macro CFLAGS de make (ver la sección de EJEMPLO anterior). Las opciones -D, -I y -U que aparezcan entre el par de dobles guiones se siguen procesando normalmente.
