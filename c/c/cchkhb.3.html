CCHKHB

Documentación de Función/Subrutina

subroutine cchkhb (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, real thresh, integer nounit, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) sd, real, dimension( * ) se, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result, integer info)

CCHKHB

Propósito:

!>
!> CCHKHB prueba la reducción de una matriz de banda Hermitiana a forma
!> tridiagonal, utilizada con el problema de valores propios Hermitiano.
!>
!> CHBTRD factoriza una matriz de banda Hermitiana A como U S U*, donde * significa
!> transpuesta conjugada, S es tridiagonal simétrica, y U es unitaria.
!> CHBTRD puede usar solo la parte inferior o solo la parte superior
!> del triángulo de A; CCHKHB comprueba ambos casos.
!>
!> Cuando se llama a CCHKHB, se especifican varios tamaños de matriz (),
!> varios anchos de banda () y varios tipos de matriz. Para cada tamaño (),
!> cada ancho de banda () menor o igual que , y cada tipo de matriz, se generará
!> una matriz y se utilizará para probar la rutina de reducción de banda Hermitiana.
!> Para cada matriz, se realizarán varias pruebas:
!>
!> (1)     | A - V S V* | / ( |A| n ulp )  calculado por CHBTRD con
!>                                         UPLO='U'
!>
!> (2)     | I - UU* | / ( n ulp )
!>
!> (3)     | A - V S V* | / ( |A| n ulp )  calculado por CHBTRD con
!>                                         UPLO='L'
!>
!> (4)     | I - UU* | / ( n ulp )
!>
!> Los  se especifican mediante un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (8)  Una matriz de la forma U* D U, donde U es unitaria y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma U* D U, donde U es unitaria y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (10) Una matriz de la forma U* D U, donde U es unitaria y
!>      D tiene entradas  1, ULP,..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz Hermitiana con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>

Parámetros:

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          CCHKHB no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NWDTHS

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a utilizar. Si es cero,
!>          CCHKHB no hace nada. Debe ser al menos cero.
!>

KK

!>          KK es array INTEGER, dimension (NWDTHS)
!>          Un array que contiene los anchos de banda a utilizar para las
!>          matrices de banda. Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CCHKHB
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que esté en A. Esto solo es útil
!>          si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es array INTEGER, dimension (4)
!>          A la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          lineal congruencial limitada a enteros pequeños, por lo que
!>          debería producir números aleatorios independientes de la máquina.
!>          Los valores de ISEED se cambian a la salida y pueden utilizarse en la
!>          siguiente llamada a CCHKHB para continuar la misma secuencia de números
!>          aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se contará como  si el , calculado como
!>          se describe anteriormente, excede THRESH. Tenga en cuenta que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es array COMPLEX, dimension
!>                            (LDA, max(NN))
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 2 (¡no 1!)
!>          y al menos max( KK )+1.
!>

SD

!>          SD es array REAL, dimension (max(NN))
!>          Se utiliza para almacenar la diagonal de la matriz tridiagonal calculada
!>          por CHBTRD.
!>

SE

!>          SE es array REAL, dimension (max(NN))
!>          Se utiliza para almacenar los subdiagonales de la matriz tridiagonal
!>          calculada por CHBTRD.
!>

U

!>          U es array COMPLEX, dimension (LDU, max(NN))
!>          Se utiliza para almacenar la matriz unitaria calculada por CHBTRD.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. Debe ser al menos 1
!>          y al menos max( NN ).
!>

WORK

!>          WORK es array COMPLEX, dimension (LWORK)
!>          Un array de trabajo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. Debe ser al menos
!>          max( 2*N, N*NB ), donde N es el tamaño de la matriz
!>          y NB es el tamaño del bloque utilizado en las rutinas de
!>          LAPACK.  Si LWORK es insuficiente, el comportamiento es
!>          indeterminado.
!>

RWORK

!>          RWORK es array REAL, dimension (max(NN))
!>          Un array de trabajo real.
!>

RESULT

!>          RESULT es array REAL, dimension (4)
!>          Un array que almacena los resultados de las pruebas.
!>          RESULT(1) es el máximo de los errores de la prueba (1) (UPLO='U').
!>          RESULT(2) es el máximo de los errores de la prueba (2).
!>          RESULT(3) es el máximo de los errores de la prueba (3) (UPLO='L').
!>          RESULT(4) es el máximo de los errores de la prueba (4).
!>

INFO

!>          INFO es INTEGER
!>          = 0 si todas las pruebas pasaron.
!>          >0 si hubo un error al calcular los valores propios o vectores propios.
!>          Si INFO es negativo, indica el número de parámetros de entrada no válidos.
!>
