CCHKS

T

Propósito

: 
!>
!> CCHKST  comprueba las rutinas del problema de autovalores hermítico.
!>
!>    CHETRD factoriza A como  U S U* , donde * significa transpuesta conjugada,
!>    S es simétrica real tridiagonal, y U es unitaria.
!>    CHETRD puede usar solo el triángulo inferior o solo el superior
!>    de A; CCHKST comprueba ambos casos.
!>    U está representada como un producto de transformaciones
!>    de Householder, cuyos vectores están almacenados en las primeras
!>    n-1 columnas de V, y cuyos factores de escala están en TAU.
!>
!>    CHPTRD hace lo mismo que CHETRD, excepto que A y V están almacenados
!>    en formato .
!>
!>    CUNGTR construye la matriz U a partir del contenido de V y TAU.
!>
!>    CUPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!>    CSTEQR factoriza S como  Z D1 Z* , donde Z es la matriz
!>    unitaria de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal.  D2 es la matriz de
!>    autovalores calculada cuando Z no se calcula.
!>
!>    SSTERF calcula D3, la matriz de autovalores, mediante el
!>    método PWK, que no produce autovectores.
!>
!>    CPTEQR factoriza S como  Z4 D4 Z4* , para una
!>    matriz tridiagonal hermítica definida positiva.
!>    D5 es la matriz de autovalores calculada cuando Z no se
!>    calcula.
!>
!>    SSTEBZ calcula autovalores seleccionados.  WA1, WA2, y
!>    WA3 denotarán autovalores calculados con alta
!>    precisión absoluta, con diferentes opciones de rango.
!>    WR denotará autovalores calculados con alta precisión
!>    relativa.
!>
!>    CSTEIN calcula Y, los autovectores de S, dados los
!>    autovalores.
!>
!>    CSTEDC factoriza S como Z D1 Z* , donde Z es la matriz
!>    unitaria de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal (opción 'I'). También puede
!>    actualizar una matriz unitaria de entrada, usualmente la salida
!>    de CHETRD/CUNGTR o CHPTRD/CUPGTR (opción 'V'). También puede
!>    solo calcular autovalores (opción 'N').
!>
!>    CSTEMR factoriza S como Z D1 Z* , donde Z es la matriz
!>    unitaria de autovectores y D1 es una matriz diagonal con
!>    los autovalores en la diagonal (opción 'I').  CSTEMR
!>    usa la Representación Robusta Relativa siempre que sea posible.
!>
!> Cuando se llama a CCHKST, se especifica un número de tamaños de matriz  () y un
!> número de tipos de matriz . Para cada tamaño ()
!> y cada tipo de matriz, se generará una matriz y se usará
!> para probar las rutinas hermíticas de autovalores. Para cada matriz, se realizará un número
!> de pruebas:
!>
!> (1)     | A - V S V* | / ( |A| n ulp ) CHETRD( UPLO='U', ... )
!>
!> (2)     | I - UV* | / ( n ulp )        CUNGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V* | / ( |A| n ulp ) CHETRD( UPLO='L', ... )
!>
!> (4)     | I - UV* | / ( n ulp )        CUNGTR( UPLO='L', ... )
!>
!> (5-8)   Igual que 1-4, pero para CHPTRD y CUPGTR.
!>
!> (9)     | S - Z D Z* | / ( |S| n ulp ) CSTEQR('V',...)
!>
!> (10)    | I - ZZ* | / ( n ulp )        CSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        CSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        SSTERF
!>
!> (13)    0 si los autovalores verdaderos (calculados por conteo de sturm)
!>         de S están dentro de THRESH de
!>         los de D1.  2*THRESH si no lo están.  (Probado usando
!>         SSTECH)
!>
!> Para S definida positiva,
!>
!> (14)    | S - Z4 D4 Z4* | / ( |S| n ulp ) CPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4* | / ( n ulp )        CPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       CPTEQR('N',...)
!>
!> Cuando S también es diagonalmente dominante por el factor gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          SSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              SSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y* | / ( |S| n ulp )  SSTEBZ, CSTEIN
!>
!> (21)    | I - Y Y* | / ( n ulp )          SSTEBZ, CSTEIN
!>
!> (22)    | S - Z D Z* | / ( |S| n ulp )    CSTEDC('I')
!>
!> (23)    | I - ZZ* | / ( n ulp )           CSTEDC('I')
!>
!> (24)    | S - Z D Z* | / ( |S| n ulp )    CSTEDC('V')
!>
!> (25)    | I - ZZ* | / ( n ulp )           CSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           CSTEDC('V') y
!>                                              CSTEDC('N')
!>
!> La prueba 27 está deshabilitada en este momento porque CSTEMR no
!> garantiza alta precisión relativa.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              CSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              CSTEMR('V', 'I')
!>
!> Las pruebas 29 a 34 están deshabilitadas en la actualidad porque CSTEMR
!> no maneja solicitudes de espectro parcial.
!>
!> (29)    | S - Z D Z* | / ( |S| n ulp )    CSTEMR('V', 'I')
!>
!> (30)    | I - ZZ* | / ( n ulp )           CSTEMR('V', 'I')
!>
!> (31)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         CSTEMR('N', 'I') vs. CSTEMR('V', 'I')
!>
!> (32)    | S - Z D Z* | / ( |S| n ulp )    CSTEMR('V', 'V')
!>
!> (33)    | I - ZZ* | / ( n ulp )           CSTEMR('V', 'V')
!>
!> (34)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         CSTEMR('N', 'V') vs. CSTEMR('V', 'V')
!>
!> (35)    | S - Z D Z* | / ( |S| n ulp )    CSTEMR('V', 'A')
!>
!> (36)    | I - ZZ* | / ( n ulp )           CSTEMR('V', 'A')
!>
!> (37)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         CSTEMR('N', 'A') vs. CSTEMR('V', 'A')
!>
!> Los  se especifican mediante un arreglo NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un arreglo lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con elementos espaciados uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con elementos espaciados geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con  elementos 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento por debajo )
!>
!> (8)  Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene elementos espaciados uniformemente 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (9)  Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene elementos espaciados geométricamente 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (10) Una matriz de la forma  U* D U, donde U es unitaria y
!>      D tiene  elementos 1, ULP,..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento por debajo )
!>
!> (13) Matriz hermítica con elementos aleatorios elegidos de (-1,1).
!> (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento por debajo )
!> (16) Igual que (8), pero los elementos diagonales son todos positivos.
!> (17) Igual que (9), pero los elementos diagonales son todos positivos.
!> (18) Igual que (10), pero los elementos diagonales son todos positivos.
!> (19) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento )
!> (20) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento por debajo )
!> (21) Una matriz tridiagonal diagonalmente dominante con elementos
!>      diagonales espaciados geométricamente 1, ..., ULP.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar.  Si es cero,
!>          CCHKST no hace nada.  Debe ser al menos cero.
!>

NN

!>          NN es un arreglo INTEGER, dimensión (NSIZES)
!>          Un arreglo que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos.  Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, CCHKST
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es utilizar cualquier matriz que esté en A.  Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no serán generados.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no, serán reducidos módulo 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se cambian en la salida, y pueden usarse en la
!>          siguiente llamada a CCHKST para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se contará como  si el , calculado como
!>          se describe arriba, excede THRESH.  Nótese que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100.  En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es un arreglo COMPLEX de
!>                                  dimensión ( LDA , max(NN) )
!>          Utilizado para almacenar la matriz cuyos autovalores deben ser
!>          calculados.  En la salida, A contiene la última matriz realmente
!>          utilizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  Debe ser al
!>          menos 1 y al menos max( NN ).
!>

AP

!>          AP es un arreglo COMPLEX de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz A almacenada en formato empaquetado.
!>

SD

!>          SD es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          La diagonal de la matriz tridiagonal calculada por CHETRD.
!>          En la salida, SD y SE contienen la forma tridiagonal de la
!>          matriz en A.
!>

SE

!>          SE es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          La superdiagonal de la matriz tridiagonal calculada por
!>          CHETRD.  En la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!>

D1

!>          D1 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los autovalores de A, calculados por CSTEQR simultáneamente
!>          con Z.  En la salida, los autovalores en D1 corresponden con la
!>          matriz en A.
!>

D2

!>          D2 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los autovalores de A, calculados por CSTEQR si Z no es
!>          calculado.  En la salida, los autovalores en D2 corresponden con
!>          la matriz en A.
!>

D3

!>          D3 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los autovalores de A, calculados por SSTERF.  En la salida, los
!>          autovalores en D3 corresponden con la matriz en A.
!>

D4

!>          D4 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los autovalores de A, calculados por CPTEQR(V).
!>          ZPTEQR factoriza S como  Z4 D4 Z4*
!>          En la salida, los autovalores en D4 corresponden con la matriz en A.
!>

D5

!>          D5 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los autovalores de A, calculados por ZPTEQR(N)
!>          cuando Z no es calculado. En la salida, los
!>          autovalores en D4 corresponden con la matriz en A.
!>

WA1

!>          WA1 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Todos los autovalores de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          como calculados por SSTEBZ.
!>

WA2

!>          WA2 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Autovalores seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          como calculados por SSTEBZ.
!>          Elija valores aleatorios para IL e IU, y solicite los
!>          autovalores del IL-ésimo al IU-ésimo.
!>

WA3

!>          WA3 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Autovalores seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          como calculados por SSTEBZ.
!>          Determine los valores VL y VU del IL-ésimo y IU-ésimo
!>          autovalores y solicite todos los autovalores en este rango.
!>

WR

!>          WR es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Todos los autovalores de A, calculados con alta
!>          precisión absoluta, con diferentes opciones.
!>          como calculados por DSTEBZ.
!>

U

!>          U es un arreglo COMPLEX de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz unitaria calculada por CHETRD + CUNGTR.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U, Z y V.  Debe ser al menos 1
!>          y al menos max( NN ).
!>

V

!>          V es un arreglo COMPLEX de
!>                             dimensión( LDU, max(NN) ).
!>          Los vectores de Householder calculados por CHETRD al reducir A a
!>          forma tridiagonal.  Los vectores calculados con UPLO='U' están
!>          en el triángulo superior, y los vectores calculados con UPLO='L'
!>          están en el triángulo inferior.  (Como se describe en CHETRD, la
!>          subdiagonal y superdiagonal no se establecen en 1, aunque el
!>          verdadero vector de Householder tiene un 1 en esa posición.  Las
!>          rutinas que usan V, como CUNGTR, establecen esos elementos en
!>          1 antes de usarlos, y luego los restauran más tarde.)
!>

VP

!>          VP es un arreglo COMPLEX de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz V almacenada en formato empaquetado.
!>

TAU

!>          TAU es un arreglo COMPLEX de
!>                             dimensión( max(NN) )
!>          Los factores de Householder calculados por CHETRD al reducir A
!>          a forma tridiagonal.
!>

Z

!>          Z es un arreglo COMPLEX de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz unitaria de autovectores calculada por CSTEQR,
!>          CPTEQR y CSTEIN.
!>

WORK

!>          WORK es un arreglo COMPLEX de
!>                      dimensión( LWORK )
!>

LWORK

!>          LWORK es INTEGER
!>          El número de elementos en WORK.  Este debe ser al menos
!>          1 + 4 * Nmax + 2 * Nmax * lg Nmax + 3 * Nmax**2
!>          waquí Nmax = max( NN(j), 2 ) y lg = log en base 2.
!
>

IWOR

K 
!>          IWORK es un array INTEGER,
!>          Espacio de trabajo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          El número de entradas en IWORK.  Este debe ser al menos
!>                  6 + 6*Nmax + 5 * Nmax * lg Nmax
!>          donde Nmax = max( NN(j), 2 ) y lg = log en base 2.
!
>

RWOR

K 
!>          RWORK es un array REAL
!
>

LRWOR

K 
!>          LRWORK es INTEGER
!>          El número de entradas en LRWORK (dimensión( ??? )
!
>

RESUL

T 
!>          RESULT es un array REAL, dimensión (26)
!>          Los valores calculados por las pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!
>

INF

O 
!>          INFO es INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algunos NN(j) < 0
!>           -3: NTYPES < 0
!>           -5: THRESH < 0
!>           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>          -23: LDU < 1 o LDU < NMAX.
!>          -29: LWORK demasiado pequeño.
!>          Si  CLATMR, CLATMS, CHETRD, CUNGTR, CSTEQR, SSTERF,
!>              o CUNMC2 devuelve un código de error, se
!>              devuelve su valor absoluto.
!>
!>-----------------------------------------------------------------------
!>
!>       Algunas Variables y Parámetros Locales:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 y 1.
!>       MAXTYP          El número de tipos definidos.
!>       NTEST           El número de pruebas realizadas, o que pueden
!>                       realizarse hasta ahora, para la matriz actual.
!>       NTESTT          El número total de pruebas realizadas hasta ahora.
!>       NBLOCK          Tamaño de bloque devuelto por ENVIR.
!>       NMAX            El valor más grande en NN.
!>       NMATS           El número de matrices generadas hasta ahora.
!>       NERRS           El número de pruebas que han excedido THRESH
!>                       hasta ahora.
!>       COND, IMODE     Valores a pasar a los generadores de matrices.
!>       ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>       OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>       ULP, ULPINV     Precisión relativa más fina y su inversa.
