ccosh(3) Manual de Funciones de Biblioteca ccosh(3)

NOMBRE

ccosh, ccoshf, ccoshl - coseno hiperbólico complejo

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <complex.h>
double complex ccosh(double complex z);
float complex ccoshf(float complex z);
long double complex ccoshl(long double complex z);

DESCRIPCIÓN

Estas funciones calculan el coseno hiperbólico complejo de z.

La función coseno hiperbólico complejo se define como:


ccosh(z) = (exp(z)+exp(-z))/2

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIAL

glibc 2.1. C99, POSIX.1-2001.

VER TAMBIÉN

cabs(3), cacosh(3), csinh(3), ctanh(3), complex(7)
