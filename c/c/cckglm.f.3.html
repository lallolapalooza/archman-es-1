Documentación de la función/subrutina

subroutine cckglm (integer nn, integer, dimension( * ) nval, integer, dimension( * ) mval, integer, dimension( * ) pval, integer nmats, integer, dimension( 4 ) iseed, real thresh, integer nmax, complex, dimension( * ) a, complex, dimension( * ) af, complex, dimension( * ) b, complex, dimension( * ) bf, complex, dimension( * ) x, complex, dimension( * ) work, real, dimension( * ) rwork, integer nin, integer nout, integer info)

CCKGLM

Propósito:

!>
!> CCKGLM prueba CGGGLM - subrutina para resolver el problema del modelo
!>                       lineal generalizado.
!>

Parámetros

NN 
!>          NN es INTEGER
!>          El número de valores de N, M y P contenidos en los vectores
!>          NVAL, MVAL y PVAL.
!>

NVAL

!>          NVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión de fila de la matriz N.
!>

MVAL

!>          MVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz M.
!>

PVAL

!>          PVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz P.
!>

NMATS

!>          NMATS es INTEGER
!>          El número de tipos de matriz a probar para cada combinación
!>          de dimensiones de matriz. Si NMATS >= NTYPES (el número
!>          máximo de tipos de matriz), entonces se generan todos los
!>          tipos diferentes para la prueba. Si NMATS < NTYPES, se lee
!>          otra línea de entrada para obtener los números de los tipos
!>          de matriz a utilizar.
!>

ISEED

!>          ISEED es un array INTEGER, dimension (4)
!>          En la entrada, la semilla del generador de números aleatorios.
!>          Los elementos del array deben estar entre 0 y 4095, de lo
!>          contrario se reducirán módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números
!>          aleatorios después de que se hayan generado todas las matrices
!>          de prueba.
!>

THRESH

!>          THRESH es REAL
!>          El valor umbral para las relaciones de prueba. Un resultado
!>          se incluye en el archivo de salida si RESID >= THRESH.
!>          Para imprimir todas las relaciones de prueba, use THRESH = 0.
!>

NMAX

!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, utilizado en la
!>          definición de los arrays de trabajo.
!>

A

!>          A es un array COMPLEX, dimension (NMAX*NMAX)
!>

AF

!>          AF es un array COMPLEX, dimension (NMAX*NMAX)
!>

B

!>          B es un array COMPLEX, dimension (NMAX*NMAX)
!>

BF

!>          BF es un array COMPLEX, dimension (NMAX*NMAX)
!>

X

!>          X es un array COMPLEX, dimension (4*NMAX)
!>

RWORK

!>          RWORK es un array REAL, dimension (NMAX)
!>

WORK

!>          WORK es un array COMPLEX, dimension (NMAX*NMAX)
!>

NIN

!>          NIN es INTEGER
!>          El número de unidad para entrada.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0 : Salida exitosa
!>          > 0 : Si CLATMS devuelve un código de error, se devuelve su
!>                valor absoluto.
!>
