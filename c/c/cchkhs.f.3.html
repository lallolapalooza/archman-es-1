Propósito

: 
!>
!>    CCHKHS  verifica las rutinas del problema de valores propios no simétrico.
!>
!>            CGEHRD factoriza A como  U H U' , donde ' significa transpuesta
!>            conjugada, H es hessenberg, y U es unitaria.
!>
!>            CUNGHR genera la matriz unitaria U.
!>
!>            CUNMHR multiplica una matriz por la matriz unitaria U.
!>
!>            CHSEQR factoriza H como  Z T Z' , donde Z es unitaria y T
!>            es triangular superior. También calcula los valores propios,
!>            w(1), ..., w(n); definimos una matriz diagonal W cuyas
!>            entradas (diagonales) son los valores propios.
!>
!>            CTREVC calcula la matriz de vectores propios izquierdos L y la
!>            matriz de vectores propios derechos R para la matriz T. Las
!>            columnas de L son los conjugados complejos de los vectores
!>            propios izquierdos de T. Las columnas de R son los vectores
!>            propios derechos de T. L es triangular inferior, y R es
!>            triangular superior.
!>
!>            CHSEIN calcula la matriz de vectores propios izquierdos Y y la
!>            matriz de vectores propios derechos X para la matriz H. Las
!>            columnas de Y son los conjugados complejos de los vectores
!>            propios izquierdos de H. Las columnas de X son los vectores
!>            propios derechos de H. Y es triangular inferior, y X es
!>            triangular superior.
!>
!>            CTREVC3 calcula matrices de vectores propios izquierdos y derechos
!>            a partir de una matriz de Schur T y las retrotransforma con Z
!>            a matrices de vectores propios L y R para A. L y R son
!>            matrices GE.
!>
!>    Cuando se llama a CCHKHS, se especifica un número de tamaños de matriz  () y un
!>    número de tipos de matriz . Para cada tamaño ()
!>    y cada tipo de matriz, se generará una matriz y se usará
!>    para probar las rutinas no simétricas de valores propios. Para cada matriz, se realizarán 16
!>    pruebas:
!>
!>    (1)     | A - U H U**H | / ( |A| n ulp )
!>
!>    (2)     | I - UU**H | / ( n ulp )
!>
!>    (3)     | H - Z T Z**H | / ( |H| n ulp )
!>
!>    (4)     | I - ZZ**H | / ( n ulp )
!>
!>    (5)     | A - UZ H (UZ)**H | / ( |A| n ulp )
!>
!>    (6)     | I - UZ (UZ)**H | / ( n ulp )
!>
!>    (7)     | T(Z computed) - T(Z not computed) | / ( |T| ulp )
!>
!>    (8)     | W(Z computed) - W(Z not computed) | / ( |W| ulp )
!>
!>    (9)     | TR - RW | / ( |T| |R| ulp )
!>
!>    (10)    | L**H T - W**H L | / ( |T| |L| ulp )
!>
!>    (11)    | HX - XW | / ( |H| |X| ulp )
!>
!>    (12)    | Y**H H - W**H Y | / ( |H| |Y| ulp )
!>
!>    (13)    | AX - XW | / ( |A| |X| ulp )
!>
!>    (14)    | Y**H A - W**H Y | / ( |A| |Y| ulp )
!>
!>    (15)    | AR - RW | / ( |A| |R| ulp )
!>
!>    (16)    | LA - WL | / ( |A| |L| ulp )
!>
!>    Los  se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1's en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP  y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP  y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con  entradas 1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!>    (8)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con ángulos complejos
!>         aleatorios en la diagonal y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene  entradas 1, ULP,..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene valores propios complejos elegidos aleatoriamente de
!>         ULP < |z| < 1   y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene  entradas 1, ULP,..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios complejos elegidos aleatoriamente
!>         de   ULP < |z| < 1   y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (17) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento )
!>    (18) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de |z| < 1
!>    (20) Igual que (19), pero multiplicada por SQRT( umbral de desbordamiento )
!>    (21) Igual que (19), pero multiplicado por SQRT( umbral de desbordamiento inferior )
!
> 
!>  NSIZES - INTEGER
!>           El número de tamaños de matrices a utilizar. Si es cero,
!>           CCHKHS no hace nada. Debe ser al menos cero.
!>           No modificado.
!>
!>  NN     - Arreglo INTEGER, dimensión (NSIZES)
!>           Un arreglo que contiene los tamaños a usar para las matrices.
!>           Los valores cero serán omitidos. Los valores deben ser al menos
!>           cero.
!>           No modificado.
!>
!>  NTYPES - INTEGER
!>           El número de elementos en DOTYPE. Si es cero, CCHKHS
!>           no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>           y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>           que es usar cualquier matriz que esté en A. Esto
!>           solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>           DOTYPE(MAXTYP+1) es .TRUE. .
!>           No modificado.
!>
!>  DOTYPE - Arreglo LOGICAL, dimensión (NTYPES)
!>           Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>           generará una matriz de ese tamaño y de tipo j.
!>           Si NTYPES es menor que el número máximo de tipos
!>           definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>           MAXTYP no serán generados. Si NTYPES es mayor
!>           que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>           serán ignorados.
!>           No modificado.
!>
!>  ISEED  - Arreglo INTEGER, dimensión (4)
!>           Al entrar, ISEED especifica la semilla del generador de
!>           números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>           si no, serán reducidos módulo 4096. Además, ISEED(4) debe
!>           ser impar. El generador de números aleatorios usa una secuencia
!>           congruencial lineal limitada a enteros pequeños, y por lo tanto
!>           debería producir números aleatorios independientes de la máquina. Los
!>           valores de ISEED se cambian al salir, y pueden usarse en la
!>           siguiente llamada a CCHKHS para continuar la misma secuencia de
!>           números aleatorios.
!>           Modificado.
!>
!>  THRESH - REAL
!>           Una prueba se contará como fallida si el , calculado como
!>           se describe arriba, excede THRESH. Tenga en cuenta que el error
!>           está escalado para ser O(1), por lo que THRESH debería ser un múltiplo
!>           razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>           no debería depender de la precisión (simple vs. doble)
!>           ni del tamaño de la matriz. Debe ser al menos cero.
!>           No modificado.
!>
!>  NOUNIT - INTEGER
!>           El número de unidad FORTRAN para imprimir mensajes de error
!>           (por ejemplo, si una rutina devuelve IINFO distinto de 0.)
!>           No modificado.
!>
!>  A      - Arreglo COMPLEX, dimensión (LDA,max(NN))
!>           Usado para contener la matriz cuyos eigenvalores deben ser
!>           calculados. Al salir, A contiene la última matriz realmente
!>           usada.
!>           Modificado.
!>
!>  LDA    - INTEGER
!>           La dimensión principal de A, H, T1 y T2. Debe ser al
!>           menos 1 y al menos max( NN ).
!>           No modificado.
!>
!>  H      - Arreglo COMPLEX, dimensión (LDA,max(NN))
!>           La matriz hessenberg superior calculada por CGEHRD. Al salir,
!>           H contiene la forma hessenberg de la matriz en A.
!>           Modificado.
!>
!>  T1     - Arreglo COMPLEX, dimensión (LDA,max(NN))
!>           La matriz de Schur (=) calculada por CHSEQR
!>           si Z es calculado. Al salir, T1 contiene la forma de Schur de
!>           la matriz en A.
!>           Modificado.
!>
!>  T2     - Arreglo COMPLEX, dimensión (LDA,max(NN))
!>           La matriz de Schur calculada por CHSEQR cuando Z no es calculado.
!>           Esto debería ser idéntico a T1.
!>           Modificado.
!>
!>  LDU    - INTEGER
!>           La dimensión principal de U, Z, UZ y UU. Debe ser al
!>           menos 1 y al menos max( NN ).
!>           No modificado.
!>
!>  U      - Arreglo COMPLEX, dimensión (LDU,max(NN))
!>           La matriz unitaria calculada por CGEHRD.
!>           Modificado.
!>
!>  Z      - Arreglo COMPLEX, dimensión (LDU,max(NN))
!>           La matriz unitaria calculada por CHSEQR.
!>           Modificado.
!>
!>  UZ     - Arreglo COMPLEX, dimensión (LDU,max(NN))
!>           El producto de U por Z.
!>           Modificado.
!>
!>  W1     - Arreglo COMPLEX, dimensión (max(NN))
!>           Los eigenvalores de A, calculados por una descomposición
!>           de Schur completa H = Z T Z'. Al salir, W1 contiene los
!>           eigenvalores de la matriz en A.
!>           Modificado.
!>
!>  W3     - Arreglo COMPLEX, dimensión (max(NN))
!>           Los eigenvalores de A, calculados por una descomposición
!>           de Schur parcial (Z no calculado, T calculado solo tanto
!>           como es necesario para determinar los eigenvalores). Al salir,
!>           W3 contiene los eigenvalores de la matriz en A, posiblemente
!>           perturbados por CHSEIN.
!>           Modificado.
!>
!>  EVECTL - Arreglo COMPLEX, dimensión (LDU,max(NN))
!>           La transpuesta conjugada de la matriz de eigenvectores izquierdos
!>           (triangular superior) para la matriz en T1.
!>           Modificado.
!>
!>  EVECTR - Arreglo COMPLEX, dimensión (LDU,max(NN))
!>           La matriz de eigenvectores derechos (triangular superior) para la
!>           matriz en T1.
!>           Modificado.
!>
!>  EVECTY - Arreglo COMPLEX, dimensión (LDU,max(NN))
!>           La transpuesta conjugada de la matriz de eigenvectores izquierdos
!>           para la matriz en H.
!>           Modificado.
!>
!>  EVECTX - Arreglo COMPLEX, dimensión (LDU,max(NN))
!>           La matriz de eigenvectores derechos para la matriz en H.
!>           Modificado.
!>
!>  UU     - Arreglo COMPLEX, dimensión (LDU,max(NN))
!>           Detalles de la matriz unitaria calculada por CGEHRD.
!>           Modificado.
!>
!>  TAU    - Arreglo COMPLEX, dimensión (max(NN))
!>           Más detalles de la matriz unitaria calculada por CGEHRD.
!>           Modificado.
!>
!>  WORK   - Arreglo COMPLEX, dimensión (NWORK)
!>           Espacio de trabajo.
!>           Modificado.
!>
!>  NWORK  - INTEGER
!>           El número de entradas en WORK.  NWORK >= 4*NN(j)*NN(j) + 2.
!>
!>  RWORK  - Arreglo REAL, dimensión (max(NN))
!>           Espacio de trabajo. Podría ser equivalenciado a IWORK, pero no a SELECT.
!>           Modificado.
!>
!>  IWORK  - Arreglo INTEGER, dimensión (max(NN))
!>           Espacio de trabajo.
!>           Modificado.
!>
!>  SELECT - Arreglo LOGICAL, dimensión (max(NN))
!>           Espacio de trabajo. Podría ser equivalenciado a IWORK, pero no a RWORK.
!>           Modificado.
!>
!>  RESULT - Arreglo REAL, dimensión (16)
!>           Los valores calculados por las catorce pruebas descritas arriba.
!>           Los valores están actualmente limitados a 1/ulp, para evitar
!>           desbordamiento.
!>           Modificado.
!>
!>  INFO   - INTEGER
!>           Si 0, entonces todo se ejecutó correctamente.
!>            -1: NSIZES < 0
!>            -2: Algunos NN(j) < 0
!>            -3: NTYPES < 0
!>            -6: THRESH < 0
!>            -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>           -14: LDU < 1 o LDU < NMAX.
!>           -26: NWORK demasiado pequeño.
!>           Si CLATMR, CLATMS, o CLATME devuelve un código de error, se
!>               devuelve su valor absoluto.
!>           Si 1, entonces CHSEQR no pudo encontrar todos los desplazamientos.
!>           Si 2, entonces el código EISPACK (para bloques pequeños) falló.
!>           Si >2, entonces 30*N iteraciones no fueron suficientes para encontrar un
!>               eigenvalor o para descomponer el problema.
!>           Modificado.
!>
!>-----------------------------------------------------------------------
!>
!>     Algunas Variables y Parámetros Locales:
!>     ---- ----- --------- --- ----------
!>
!>     ZERO, ONE       Real 0 y 1.
!>     MAXTYP          El número de tipos definidos.
!>     MTEST           El número de pruebas definidas: se debe tener cuidado
!>                     de que (1) el tamaño de RESULT, (2) el número de
!>                     pruebas realmente realizadas, y (3) MTEST coincidan.
!>     NTEST           El número de pruebas realizadas en esta matriz
!>                     hasta ahora. Debe ser menor que MTEST, e
!>                     igual a él en la última prueba. Será menor
!>                     si alguna de las rutinas being probadas indica
!>                     que no pudo calcular las matrices que
!>                     serían probadas.
!>     NMAX            El valor más grande en NN.
!>     NMATS           El número de matrices generadas hasta ahora.
!>     NERRS           El número de pruebas que han excedido THRESH
!>                     hasta ahora (calculado por SLAFTS).
!>     COND, CONDS,
!>     IMODE           Valores a pasar a los generadores de matrices.
!>     ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>     OVFL, UNFL      Umbrales de desbordamiento y desbordamiento inferior.
!>     ULP, ULPINV     Precisión relativa más fina y su inversa.
!>     RTOVFL, RTUNFL,
!>     RTULP, RTULPI   Raíces cuadradas de los 4 valores anteriores.
!>
!>             Los siguientes cuatro arreglos decodifican JTYPE:
!>     KTYPE(j)        El tipo general (1-10) para el tipo .
!>     KMODE(j)        El valor MODE a pasar al generador de
!>                     matrices para el tipo .
!>     KMAGN(j)        El orden de magnitud ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!>     KCONDS(j)       Selecciona si CONDS debe ser 1 o
!>                     1/sqrt(ulp).  (0 significa irrelevante.)
!
