NOMBRE

ccrewrite - Reescribe ensamblados CLR para la verificación de contratos en tiempo de ejecución.

SINOPSIS

ccrewrite --assembly=<ensamblado> [opciones]

DESCRIPCIÓN

Reescribe ensamblados CLR para convertir llamadas al espacio de nombres System.Diagnostics.Contracts para realizar la verificación de contratos en tiempo de ejecución. Esto incluye la herencia de contratos para métodos virtuales.

El ensamblado debe haber sido compilado con el símbolo CONTRACTS_FULL definido, de lo contrario, las llamadas a los métodos de contrato habrán sido eliminadas por el compilador.

Actualmente, solo se admiten precondiciones, utilizando el método Contract.Requires(). Se admite la herencia de contratos para métodos virtuales. Solo se puede utilizar un rango limitado de operaciones y tipos dentro de una precondición; se mostrará un mensaje de error si ccrewrite no puede procesar el ensamblado especificado.

OPCIONES DE CONFIGURACIÓN

--assembly <nombre-del-ensamblado>
El ensamblado a reescribir. Si no se especifica la opción --output, este archivo se sobrescribe con la versión reescrita.
--debug
Utilice la información de depuración si está disponible para mejorar la utilidad de los mensajes de fallo de contrato.
--help
Mostrar ayuda para ccrewrite, listando las opciones de configuración.
--level <nivel> (predeterminado=4)
Establecer qué tipos de contratos están presentes en el ensamblado reescrito: 0 = Sin contratos; 1 = Requires de lanzamiento; 2 = Requires; 3 = Ensures; 4 = Invariants; (Cada nivel incluye todos los niveles anteriores)
--output <nombre-del-archivo>
Escribir el ensamblado reescrito en el archivo especificado. Si esto no está presente, el archivo de ensamblado de entrada se sobrescribe con la versión reescrita.
--rewrite (predeterminado=true)
Reescribir el ensamblado. Si es falso, no se hace nada.
--throwOnFailure (predeterminado=false)
Lanzar una ContractException en caso de fallo de contrato no manejado. El comportamiento predeterminado es Assert.
