Propósito:

!>
!> CCHKST2STG  verifica las rutinas del problema de valores propios Hermíticos
!> utilizando las técnicas de reducción de 2 etapas. Dado que la generación
!> de Q o los vectores no está disponible en esta versión, solo
!> comparamos el valor propio resultante al usar la de 2 etapas con el
!> que se considera como referencia utilizando la reducción estándar de 1 etapa
!> CHETRD. Para ello, llamamos al CHETRD estándar y calculamos D1 usando
!> DSTEQR, luego llamamos al CHETRD_2STAGE de 2 etapas con Superior e Inferior
!> y calculamos D2 y D3 usando DSTEQR y luego reemplazamos las pruebas
!> 3 y 4 por las pruebas 11 y 12. Las pruebas 1 y 2 permanecen para verificar que
!> los resultados de 1 etapa están BIEN y se puede confiar en ellos.
!> Esta rutina de prueba convergerá a CCHKST en la próxima
!> versión cuando se implementen los vectores y la generación de Q.
!>
!>    CHETRD factoriza A como  U S U* , donde * significa transpuesta conjugada,
!>    S es una matriz real simétrica tridiagonal, y U es unitaria.
!>    CHETRD puede usar solo el triángulo inferior o solo el triángulo superior
!>    de A; CCHKST2STG verifica ambos casos.
!>    U se representa como un producto de transformaciones de Householder,
!>    cuyos vectores se almacenan en las primeras
!>    n-1 columnas de V, y cuyos factores de escala están en TAU.
!>
!>    CHPTRD hace lo mismo que CHETRD, excepto que A y V se almacenan
!>    en formato .
!>
!>    CUNGTR construye la matriz U a partir del contenido de V y TAU.
!>
!>    CUPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!>    CSTEQR factoriza S como  Z D1 Z* , donde Z es la matriz unitaria
!>    de autovectores y D1 es una matriz diagonal con
!>    los valores propios en la diagonal.  D2 es la matriz de
!>    valores propios calculados cuando Z no se calcula.
!>
!>    SSTERF calcula D3, la matriz de valores propios, mediante el
!>    método PWK, que no produce autovectores.
!>
!>    CPTEQR factoriza S como  Z4 D4 Z4* , para una
!>    matriz tridiagonal Hermítica positiva definida.
!>    D5 es la matriz de valores propios calculados cuando Z no se
!>    calcula.
!>
!>    SSTEBZ calcula valores propios seleccionados.  WA1, WA2, y
!>    WA3 denotarán valores propios calculados con alta
!>    precisión absoluta, con diferentes opciones de rango.
!>    WR denotará valores propios calculados con alta
!>    precisión relativa.
!>
!>    CSTEIN calcula Y, los autovectores de S, dados los
!>    valores propios.
!>
!>    CSTEDC factoriza S como Z D1 Z* , donde Z es la matriz unitaria
!>    de autovectores y D1 es una matriz diagonal con
!>    los valores propios en la diagonal (opción 'I'). También
!>    puede actualizar una matriz unitaria de entrada, generalmente la salida
!>    de CHETRD/CUNGTR o CHPTRD/CUPGTR (opción 'V'). También
!>    puede simplemente calcular valores propios (opción 'N').
!>
!>    CSTEMR factoriza S como Z D1 Z* , donde Z es la matriz unitaria
!>    de autovectores y D1 es una matriz diagonal con
!>    los valores propios en la diagonal (opción 'I').  CSTEMR
!>    utiliza la Representación Relativamente Robusta siempre que sea posible.
!>
!> Cuando se llama a CCHKST2STG, se especifica un número de matrices () y
!> un número de matrices . Para cada tamaño ()
!> y cada tipo de matriz, se generará y utilizará una matriz
!> para probar las rutinas de valores propios Hermíticos. Para cada matriz, se
!> realizarán una serie de pruebas:
!>
!> (1)     | A - V S V* | / ( |A| n ulp ) CHETRD( UPLO='U', ... )
!>
!> (2)     | I - UV* | / ( n ulp )        CUNGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V* | / ( |A| n ulp ) CHETRD( UPLO='L', ... )
!>         reemplazado por | D1 - D2 | / ( |D1| ulp ) donde D1 es la
!>         matriz de valores propios calculada usando S y D2 es la
!>         matriz de valores propios calculada usando S_2stage la salida de
!>         CHETRD_2STAGE(, ,....). D1 y D2 se calculan
!>         vía DSTEQR('N',...)
!>
!> (4)     | I - UV* | / ( n ulp )        CUNGTR( UPLO='L', ... )
!>         reemplazado por | D1 - D3 | / ( |D1| ulp ) donde D1 es la
!>         matriz de valores propios calculada usando S y D3 es la
!>         matriz de valores propios calculada usando S_2stage la salida de
!>         CHETRD_2STAGE(, ,....). D1 y D3 se calculan
!>         vía DSTEQR('N',...)
!>
!> (5-8)   Igual que 1-4, pero para CHPTRD y CUPGTR.
!>
!> (9)     | S - Z D Z* | / ( |S| n ulp ) CSTEQR('V',...)
!>
!> (10)    | I - ZZ* | / ( n ulp )        CSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        CSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        SSTERF
!>
!> (13)    0 si los verdaderos valores propios (calculados por recuento de Sturm)
!>         de S están dentro de THRESH de
!>         los de D1.  2*THRESH si no lo están.  (Probado usando
!>         SSTECH)
!>
!> Para S definida positiva,
!>
!> (14)    | S - Z4 D4 Z4* | / ( |S| n ulp ) CPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4* | / ( n ulp )        CPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       CPTEQR('N',...)
!>
!> Cuando S también es dominante diagonalmente por el factor gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              SSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          SSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              SSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y* | / ( |S| n ulp )  SSTEBZ, CSTEIN
!>
!> (21)    | I - Y Y* | / ( n ulp )          SSTEBZ, CSTEIN
!>
!> (22)    | S - Z D Z* | / ( |S| n ulp )    CSTEDC('I')
!>
!> (23)    | I - ZZ* | / ( n ulp )           CSTEDC('I')
!>
!> (24)    | S - Z D Z* | / ( |S| n ulp )    CSTEDC('V')
!>
!> (25)    | I - ZZ* | / ( n ulp )           CSTEDC('V')
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar.  Si es cero,
!>          CCHKST2STG no hace nada.  Debe ser al menos cero.
!>

NN

!>          NN es un arreglo INTEGER, dimensión (NSIZES)
!>          Un arreglo que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos.  Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, CCHKST2STG
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que haya en A.  Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no serán generados.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no, serán reducidos módulo 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican en la salida, y pueden usarse en la
!>          siguiente llamada a CCHKST2STG para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          THRESH es REAL
!>          Una prueba se contará como  si el , calculado como
!>          se describió arriba, excede THRESH.  Nótese que el error
!>          se escala para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100.  En particular,
!>          no debería depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es un arreglo COMPLEX de
!>                                  dimensión ( LDA , max(NN) )
!>          Se usa para contener la matriz cuyos eigenvalores se van a
!>          calcular.  En la salida, A contiene la última matriz realmente
!>          usada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  Debe ser al
!>          menos 1 y al menos max( NN ).
!>

AP

!>          AP es un arreglo COMPLEX de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz A almacenada en formato empaquetado.
!>

SD

!>          SD es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          La diagonal de la matriz tridiagonal calculada por CHETRD.
!>          En la salida, SD y SE contienen la forma tridiagonal de la
!>          matriz en A.
!>

SE

!>          SE es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          La subdiagonal de la matriz tridiagonal calculada por
!>          CHETRD.  En la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!>

D1

!>          D1 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los eigenvalores de A, calculados por CSTEQR simultáneamente
!>          con Z.  En la salida, los eigenvalores en D1 corresponden con la
!>          matriz en A.
!>

D2

!>          D2 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los eigenvalores de A, calculados por CSTEQR si Z no se
!>          calcula.  En la salida, los eigenvalores en D2 corresponden con
!>          la matriz en A.
!>

D3

!>          D3 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los eigenvalores de A, calculados por SSTERF.  En la salida, los
!>          eigenvalores en D3 corresponden con la matriz en A.
!>

D4

!>          D4 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los eigenvalores de A, calculados por CPTEQR(V).
!>          CPTEQR factoriza S como  Z4 D4 Z4*
!>          En la salida, los eigenvalores en D4 corresponden con la matriz en A.
!>

D5

!>          D5 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Los eigenvalores de A, calculados por CPTEQR(N)
!>          cuando Z no se calcula. En la salida, los
!>          eigenvalores en D4 corresponden con la matriz en A.
!>

WA1

!>          WA1 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Todos los eigenvalores de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          tal como los calcula SSTEBZ.
!>

WA2

!>          WA2 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Eigenvalores seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          tal como los calcula SSTEBZ.
!>          Elija valores aleatorios para IL e IU, y pida los
!>          eigenvalores delésimo IL-th alésimo IU-th.
!>

WA3

!>          WA3 es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Eigenvalores seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          tal como los calcula SSTEBZ.
!>          Determine los valores VL y VU de los eigenvaloresésimo IL-th yésimo IU-th
!>          y pida todos los eigenvalores en este rango.
!>

WR

!>          WR es un arreglo REAL de
!>                             dimensión( max(NN) )
!>          Todos los eigenvalores de A, calculados con alta
!>          precisión absoluta, con diferentes opciones.
!>          tal como los calcula SSTEBZ.
!>

U

!>          U es un arreglo COMPLEX de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz unitaria calculada por CHETRD + CUNGTR.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U, Z y V.  Debe ser al menos 1
!>          y al menos max( NN ).
!>

V

!>          V es un arreglo COMPLEX de
!>                             dimensión( LDU, max(NN) ).
!>          Los vectores de Householder calculados por CHETRD al reducir A a
!>          forma tridiagonal.  Los vectores calculados con UPLO='U' están
!>          en el triángulo superior, y los vectores calculados con UPLO='L'   son las matrices unitarias de subrutinas que reducen una matriz hermitiana compleja A a su forma tridiagonal hermitiana.
!>
!>       El subprograma CTPQRT calcula los coeficientes Householder y la
!>       matriz unitaria que transforman una matriz general compleja M*N en
!>       una forma triangular superior por la izquierda, mediante una secuencia
!>       de transformaciones unitarias por la izquierda.
!>
!>       CHETRD realiza la descomposición tridiagonal hermitiana de una matriz
!>       hermitiana compleja A y genera la matriz V de subrutinas de
!>       transformación Householder.
!>
!>       CUNGTR genera la matriz V de subrutinas de transformación Householder
!>       y las matrices unitarias Q y P, que transforman una matriz A en su
!>       forma tridiagonal hermitiana.
!>
!>       CSTEIN calcula los subvectores propios de una matriz tridiagonal
!>       hermitiana para los valores propios dados.
!>
!>       CSTEQR calcula los valores propios y subvectores propios de una
!>       matriz tridiagonal hermitiana.
!>
!>       CTEQR (obsoleto) se utiliza para calcular los valores propios y
!>       subvectores propios de una matriz tridiagonal hermitiana.
!>
!>       CHSEQR se utiliza para calcular los valores propios y subvectores
!>       propios de una matriz de Hessenberg general.
!>
!>       CHETRD (obsoleto) se utiliza para reducir una matriz hermitiana
!>       compleja a su forma tridiagonal hermitiana.
!>
!>       CUNGTR (obsoleto) se utiliza para generar la matriz unitaria que
!>       transforma una matriz en su forma tridiagonal hermitiana.
!>
!>       CUNCTR (obsoleto) se utiliza para generar la matriz unitaria que
!>       transforma una matriz en su forma tridiagonal hermitiana.
!>
!>       CPTCON calcula el número de condición de una matriz tridiagonal
!>       compleja.
!>
!>       CPTRFS calcula el número de condición de una matriz tridiagonal
!>       compleja y resuelve un sistema de ecuaciones lineales con ella.
!>
!>       CPTRSvx calcula el número de condición de una matriz tridiagonal
!>       compleja y resuelve un sistema de ecuaciones lineales con ella.
!>
!>       CPTCON (obsoleto) se utiliza para calcular el número de condición
!>       de una matriz tridiagonal compleja.
!>
!>       CPTRFS (obsoleto) se utiliza para resolver un sistema de ecuaciones
!>       lineales con una matriz tridiagonal compleja.
!>
!>       CPTRSvx (obsoleto) se utiliza para resolver un sistema de ecuaciones
!>       lineales con una matriz tridiagonal compleja.
!>
!>       CSTEGR calcula los valores propios y subvectores propios de una
!>       matriz tridiagonal simétrica o hermitiana.
!>
!>       CSTEIN (obsoleto) se utiliza para calcular los subvectores propios
