CCHKGG

Propósito:

!>
!> CCHKGG  verifica las rutinas del problema de valores propios generalizados no simétricos.
!>                                H          H        H
!> CGGHRD factoriza A y B como U H V  y U T V , donde   significa transpuesta conjugada, H es Hessenberg, T es triangular y U y V son unitarias.
!>
!>                                 H          H
!> CHGEQZ factoriza H y T como  Q S Z  y Q P Z , donde P y S son triangulares superiores y Q y Z son unitarias. También calcula los valores propios generalizados (alpha(1),beta(1)),...,(alpha(n),beta(n)), donde
!> alpha(j)=S(j,j) y beta(j)=P(j,j) -- por lo tanto, w(j) = alpha(j)/beta(j)
!> es una raíz del problema de valores propios generalizados
!>
!>     det( A - w(j) B ) = 0
!>
!> y m(j) = beta(j)/alpha(j) es una raíz del problema esencialmente equivalente
!>
!>     det( m(j) A - B ) = 0
!>
!> CTGEVC calcula la matriz L de vectores propios izquierdos y la matriz R
!> de vectores propios derechos para el par de matrices ( S, P ). En la
!> descripción a continuación,  l y r son vectores propios izquierdos y derechos
!> correspondientes a los valores propios generalizados (alpha,beta).
!>
!> Cuando se llama a CCHKGG, se especifican un número de tamaños de matriz  () y un
!> número de tipos de matriz. Para cada tamaño ()
!> y cada tipo de matriz, se generará y utilizará una matriz para
!> probar las rutinas de valores propios no simétricos. Para cada matriz, se realizarán 13
!> pruebas. Los primeros doce  deberían ser
!> pequeños -- O(1). Se compararán con el umbral THRESH:
!>
!>                  H
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  H
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               H
!> (3)   | I - UU  | / ( n ulp )
!>
!>               H
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  H
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  H
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               H
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               H
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)   máx sobre todos los pares de valores propios/vectores izquierdos (beta/alpha,l) de
!>                           H
!>       | (beta A - alpha B) l | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (10)  máx sobre todos los pares de valores propios/vectores izquierdos (beta/alpha,l') de
!>                           H
!>       | (beta H - alpha T) l' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios l' son el resultado de pasar Q a
!>       STGEVC y transformar de vuelta (JOB='B').
!>
!> (11)  máx sobre todos los pares de valores propios/vectores derechos (beta/alpha,r) de
!>
!>       | (beta A - alpha B) r | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (12)  máx sobre todos los pares de valores propios/vectores derechos (beta/alpha,r') de
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios r' son el resultado de pasar Z a
!>       STGEVC y transformar de vuelta (JOB='B').
!>
!> Las últimas tres relaciones de prueba generalmente serán pequeñas, pero no hay
!> requisito matemático de que lo sean. Por lo tanto, se comparan
!> con THRESH solo si TSTDIF es .TRUE.
!>
!> (13)  | S(Q,Z calculado) - S(Q,Z no calculado) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z calculado) - P(Q,Z no calculado) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z calculado) - alpha(Q,Z no calculado)|/|S| ,
!>            |beta(Q,Z calculado) - beta(Q,Z no calculado)|/|P| ) / ulp
!>
!> Además, se verifica la normalización de L y R, y se compara
!> con el umbral THRSHN.
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad k x k y J un bloque de
!>                       Jordan de (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es P*D1, P es una matriz unitaria diagonal aleatoria
!>                       (es decir, con entradas de magnitud 1 aleatorias
!>                       en la diagonal), y D1=diag( 0, 1,..., N-1 )
!>                       (es decir, una matriz diagonal con D1(1,1)=0,
!>                       D1(2,2)=1, ..., D1(N,N)=N-1.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1=P*diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2=Q*diag( 0, N-3, N-4,..., 1, 0, 0 ), y
!>                        P y Q son matrices unitarias diagonales aleatorias.
!>           t   t
!> (16) U ( J , J ) V     donde U y V son matrices unitarias aleatorias.
!>
!> (17) U ( T1, T2 ) V    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas aleatorias de O(1) por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>
; P*( 0, 0, 1, ..., N-3, 0 ) y diag(T2) = !> Q*( 0, N-3, N-4,..., 1, 0, 0 ) !> !> (18) U ( T1, T2 ) V diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 ) !> diag(T2) = ( 0, 1, 0, 1,..., 1, 0 ) !> s = precisión de la máquina. !> !> (19) U ( T1, T2 ) V diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 ) !> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 ) !> !> N-5 !> (20) U ( T1, T2 ) V diag(T1)=( 0, 0, 1, 1, a, ..., a =s, 0 ) !> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 ) !> !> (21) U ( T1, T2 ) V diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 ) !> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 ) !> donde r1,..., r(N-4) son aleatorios. !> !> (22) U ( big*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) !> diag(T2) = ( 0, 1, ..., 1, 0, 0 ) !> !> (23) U ( small*T1, big*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) !> diag(T2) = ( 0, 1, ..., 1, 0, 0 ) !> !> (24) U ( small*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) !> diag(T2) = ( 0, 1, ..., 1, 0, 0 ) !> !> (25) U ( big*T1, big*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) !> diag(T2) = ( 0, 1, ..., 1, 0, 0 ) !> !> (26) U ( T1, T2 ) V donde T1 y T2 son matrices triangulares !> superiores aleatorias. !>

Parámetro

s
NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          CCHKGG no hace nada. Debe ser al menos cero.
!
>

N

N 
!>          NN es un array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!
>

NTYPE

S 
!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, CCHKGG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que utiliza la matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE es un array LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          se ignorarán.
!
>

ISEE

D 
!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican en la salida, y pueden usarse en la
!>          siguiente llamada a CCHKGG para continuar la misma secuencia de
!>          números aleatorios.
!
>

THRES

H 
!>          THRESH es REAL
!>          Una prueba se contará como fallida si el , calculado como
!>          se describe arriba, excede THRESH. Nótese que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz. Debe ser al menos cero.
!
>

TSTDI

F 
!>          TSTDIF es LOGICAL
!>          Especifica si las razones de prueba 13-15 se calcularán y
!>          compararán con THRESH.
!>          = .FALSE.: Solo se calcularán y probarán las razones de prueba 1-12.
!>                     Las razones 13-15 se establecerán en cero.
!>          = .TRUE.:  Se calcularán y probarán todas las razones de prueba 1-15.
!
>

THRSH

N 
!>          THRSHN es REAL
!>          Umbral para informar el error de normalización del autovector.
!>          Si la normalización de cualquier autovector difiere de 1 en
!>          más de THRSHN*ulp, se imprimirá un mensaje de error
!>          especial. (Esto se maneja por separado de las otras pruebas,
!>      ya que solo un error de compilador o de programación debería causar un
!>      mensaje de error, al menos si THRSHN es al menos 5--10.)
!
>

NOUNI

T 
!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA, max(NN))
!>          Se utiliza para almacenar la matriz A original. Se usa como entrada
!>          solo si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal de A, B, H, T, S1, P1, S2 y P2.
!>          Debe ser al menos 1 y al menos max( NN ).
!
>

B 
!>          B es un array COMPLEX, dimensión (LDA, max(NN))
!>          Se utiliza para almacenar la matriz B original. Se usa como entrada
!>          solo si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

H 
!>          H es un array COMPLEX, dimensión (LDA, max(NN))
!>          La matriz de Hessenberg superior calculada a partir de A por CGGHRD.
!
>

T 
!>          T es un array COMPLEX, dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de B por CGGHRD.
!
>

S

1 
!>          S1 es un array COMPLEX, dimensión (LDA, max(NN))
!>          La matriz de Schur (triangular superior) calculada a partir de H por CHGEQZ
!>          cuando también se calculan Q y Z.
!
>

S

2 
!>          S2 es un array COMPLEX, dimensión (LDA, max(NN))
!>          La matriz de Schur (triangular superior) calculada a partir de H por CHGEQZ
!>          cuando no se calculan Q y Z.
!
>

P

1 
!>          P1 es un array COMPLEX, dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de T por CHGEQZ
!>          cuando también se calculan Q y Z.
!
>

P

2 
!>          P2 es un array COMPLEX, dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de T por CHGEQZ
!>          cuando no se calculan Q y Z.
!
>

U 
!>          U es un array COMPLEX, dimensión (LDU, max(NN))
!>          La matriz unitaria (izquierda) calculada por CGGHRD.
!
>

LD

U 
!>          LDU es INTEGER
!>          La dimensión principal de U, V, Q, Z, EVECTL y EVECTR. Debe
!>          ser al menos 1 y al menos max( NN ).
!
>

V 
!>          V es un array COMPLEX, dimensión (LDU, max(NN))
!>          La matriz unitaria (derecha) calculada por CGGHRD.
!
>

Q 
!>          Q es un array COMPLEX, dimensión (LDU, max(NN))
!>          La matriz unitaria (izquierda) calculada por CHGEQZ.
!
>

Z 
!>          Z es un array COMPLEX, dimensión (LDU, max(NN))
!>          La matriz unitaria (izquierda) calculada por CHGEQZ.
!
>

ALPHA

1 
!>          ALPHA1 es un array COMPLEX, dimensión (max(NN))
!
>

BETA

1 
!>          BETA1 es un array COMPLEX, dimensión (max(NN))
!>          Los eigenvalores generalizados de (A,B) calculados por CHGEQZ
!>          cuando se calculan Q, Z y las matrices completas de Schur.
!
>

ALPHA

3 
!>          ALPHA3 es un array COMPLEX, dimensión (max(NN))
!
>

BETA

3 
!>          BETA3 es un array COMPLEX, dimensión (max(NN))
!>          Los eigenvalores generalizados de (A,B) calculados por CHGEQZ
!>          cuando no se calculan Q, Z ni las matrices de Schur.
!
>

EVECT

L 
!>          EVECTL es un array COMPLEX, dimensión (LDU, max(NN))
!>          La matriz de autovectores izquierdos (triangular inferior) para las
!>          matrices en S1 y P1.
!
>

EVECT

R 
!>          EVECTR es un array COMPLEX, dimensión (LDU, max(NN))
!>          La matriz de autovectores derechos (triangular superior) para las
!>          matrices en S1 y P1.
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (LWORK)
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          El número de entradas en WORK. Debe ser al menos
!>          max( 4*N, 2 * N**2, 1 ), para todos N=NN(j).
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (2*max(NN))
!
>

LLWOR

K 
!>          LLWORK es un array LOGICAL, dimensión (max(NN))
!
>

RESUL

T 
!>          RESULT es un array REAL, dimensión (15)
!>          Los valores calculados por las pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!
>

INF

O

!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  Una rutina devolvió un código de error. INFO es el

!
