Propósito

: 
!>
!> CCHKBD comprueba las rutinas de descomposición en valores singulares (SVD).
!>
!> CGEBRD reduce una matriz general compleja A de m por n a forma bidiagonal real superior o
!> inferior mediante una transformación ortogonal: Q' * A * P = B
!> (o A = Q * B * P').  La matriz B es bidiagonal superior si m >= n
!> y bidiagonal inferior si m < n.
!>
!> CUNGBR genera las matrices ortogonales Q y P' a partir de CGEBRD.
!> Nótese que Q y P no son necesariamente cuadradas.
!>
!> CBDSQR calcula la descomposición en valores singulares de la matriz
!> bidiagonal B como B = U S V'.  Se llama tres veces para calcular
!>    1)  B = U S1 V', donde S1 es la matriz diagonal de valores
!>        singulares y las columnas de las matrices U y V son los
!>        vectores singulares izquierdo y derecho, respectivamente, de B.
!>    2)  Igual que 1), pero los valores singulares se almacenan en S2 y los
!>        vectores singulares no se calculan.
!>    3)  A = (UQ) S (P'V'), la SVD de la matriz original A.
!> Además, CBDSQR tiene una opción para aplicar la matriz ortogonal izquierda
!> U a una matriz X, útil en aplicaciones de mínimos cuadrados.
!>
!> Para cada par de dimensiones de matriz (M,N) y cada tipo de matriz
!> seleccionado, se genera una matriz A de M por N y una matriz X de M por NRHS.
!> Las dimensiones del problema son las siguientes
!>    A:          M x N
!>    Q:          M x min(M,N) (pero M x M si NRHS > 0)
!>    P:          min(M,N) x N
!>    B:          min(M,N) x min(M,N)
!>    U, V:       min(M,N) x min(M,N)
!>    S1, S2      diagonal, orden min(M,N)
!>    X:          M x NRHS
!>
!> Para cada matriz generada, se realizan 14 pruebas:
!>
!> Probar CGEBRD y CUNGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp ), PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> Probar CBDSQR en la matriz bidiagonal B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp ), VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp ), donde Y = Q' X
!>                                                  y   Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   S1 contiene min(M,N) valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (9)   0 si los valores singulares verdaderos de B están dentro de THRESH de
!>       los que están en S1.  2*THRESH si no lo están.  (Probado usando
!>       SSVDCH)
!>
!> (10)  | S1 - S2 | / ( |S1| ulp ), donde S2 se calcula sin
!>                                   calcular U y V.
!>
!> Probar CBDSQR en la matriz A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> Los tipos de matriz posibles son
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con elementos equiespaciados
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con elementos geométricamente espaciados
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con elementos 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (3), pero multiplicada por SQRT( umbral de desbordamiento )
!> (7)  Igual que (3), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!> (8)  Una matriz de la forma  U D V, donde U y V son ortogonales y
!>      D tiene elementos equiespaciados 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma  U D V, donde U y V son ortogonales y
!>      D tiene elementos geométricamente espaciados 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (10) Una matriz de la forma  U D V, donde U y V son ortogonales y
!>      D tiene elementos 1, ULP,..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!> (13) Matriz rectangular con elementos aleatorios elegidos de (-1,1).
!> (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!> Caso especial:
!> (16) Una matriz bidiagonal con elementos aleatorios elegidos de una
!>      distribución logarítmica en [ulp^2,ulp^(-2)]  (Es decir, cada
!>      elemento es  e^x, donde x se elige uniformemente en
!>      [ 2 log(ulp), -2 log(ulp) ] .)  Para *este* tipo:
!>      (a) No se llama a CGEBRD para reducirla a forma bidiagonal.
!>      (b) la bidiagonal es  min(M,N) x min(M,N); si M<N, la
!>          matriz será bidiagonal inferior, de lo contrario superior.
!>      (c) solo se realizan las pruebas 5--8 y 14.
!>
!> Se puede seleccionar un subconjunto del conjunto completo de tipos de matriz a través del
!> arreglo lógico DOTYPE.
!
>

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, CCHKBD
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar las matrices que haya en A y B.
!>          Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño (m,n), se generará una matriz
!>          de tipo j.  Si NTYPES es menor que el
!>          número máximo de tipos definidos (PARÁMETRO MAXTYP), entonces
!>          los tipos NTYPES+1 hasta MAXTYP no se generarán.  Si
!>          NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) hasta
!>          DOTYPE(NTYPES) serán ignorados.
!

NRH CCHKBD(3) - LAPACK manual

NAME

CCHKBD - The subroutine CCHKBD is a utility routine that tests the complex BD factorization routines

SYNOPSIS

 SUBROUTINE CCHKBD( NSIZES, NVAL, NTYPES, MVAL, NTMAX, NB, &
                                       NRHS, ISEED, THRESH, A, LDA, BD, BE, S1, S2, &
                                       X, LDX, Y, Z, Q, LDQ, PT, LDPT, U, VT, WORK, &
                                       LWORK, RWORK, NOUT, INFO )

Arguments

NSZES

NSZES is INTEGER, the number of values in the arrays NVAL and MVAL.

NVAL

NVAL is INTEGER array, dimension (NSZES). If NVAL(j) = N, then the number of columns of the matrix is N.

NTYPES

NTYPES is INTEGER, the number of different matrix types to be tested.

MVAL

MVAL is INTEGER array, dimension (NSZES). If MVAL(j) = M, then the number of rows of the matrix is M.

NTMAX

NTMAX is INTEGER, the maximum value of N in NVAL.

NB

NB is INTEGER, the block size used in the reduction to bidiagonal form.

NRHS

NRHS is INTEGER. The number of columns in the matrices X, Y, and Z, used in testing CBDSQR. If NRHS = 0, then the operations on the right-hand side will not be tested. NRHS must be at least 0.

ISEED

ISEED is INTEGER array, dimension (4). On entry ISEED specifies the seed of the random number generator. The array elements should be between 0 and 4095; if not they will be reduced mod 4096. Also, ISEED(4) must be odd. The values of ISEED are changed on exit, and can be used in the next call to CCHKBD to continue the same random number sequence.

THRESH

THRESH is REAL. The threshold value for the test ratios. A result is included in the output file if RESULT >= THRESH. To have every test ratio printed, use THRESH = 0. Note that the expected value of the test ratios is O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100.

A

A is COMPLEX array, dimension (LDA,NMAX) where NMAX is the maximum value of N in NVAL.

LDA

LDA is INTEGER. The leading dimension of the array A. LDA >= max(1,MMAX), where MMAX is the maximum value of M in MVAL.

BD

BD is REAL array, dimension (max(min(MVAL(j),NVAL(j))))

BE

BE is REAL array, dimension (max(min(MVAL(j),NVAL(j))))

S1

S1 is REAL array, dimension (max(min(MVAL(j),NVAL(j))))

S2

S2 is REAL array, dimension (max(min(MVAL(j),NVAL(j))))

X

X is COMPLEX array, dimension (LDX,NRHS)

LDX

LDX is INTEGER. The leading dimension of the arrays X, Y, and Z. LDX >= max(1,MMAX).

Y

Y is COMPLEX array, dimension (LDX,NRHS)

Z

Z is COMPLEX array, dimension (LDX,NRHS)

Q

Q is COMPLEX array, dimension (LDQ,MMAX)

LDQ

LDQ is INTEGER. The leading dimension of the array Q. LDQ >= max(1,MMAX).

PT

PT is COMPLEX array, dimension (LDPT,NMAX)

LDPT

LDPT is INTEGER. The leading dimension of the arrays PT, U, and V. LDPT >= max(1, max(min(MVAL(j),NVAL(j)))).

U

U is COMPLEX array, dimension (LDPT,max(min(MVAL(j),NVAL(j))))

VT

VT is COMPLEX array, dimension (LDPT,max(min(MVAL(j),NVAL(j))))

WORK

WORK is COMPLEX array, dimension (LWORK)

LWORK

LWORK is INTEGER. The number of entries in WORK. This must be at least 3(M+N) and M(M + max(M,N,k) + 1) + N*min(M,N) for all pairs (M,N)=(MM(j),NN(j))

RWORK

RWORK is REAL array, dimension (5*max(min(M,N)))

NOUT

NOUT is INTEGER. The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.)

INFO

INFO is INTEGER. If 0, then everything ran OK. -1: NSIZES < 0 -2: Some MM(j) < 0 -3: Some NN(j) < 0 -4: NTYPES < 0 -6: NRHS < 0 -8: THRESH < 0 -11: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ). -17: LDB < 1 or LDB < MMAX. -21: LDQ < 1 or LDQ < MMAX. -23: LDP < 1 or LDP < MNMAX. -27: LWORK too small. If CLATMR, CLATMS, CGEBRD, CUNGBR, or CBDSQR, returns an error code, the absolute value of it is returned.
