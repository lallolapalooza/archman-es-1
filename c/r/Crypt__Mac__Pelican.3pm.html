Crypt::Mac::Pelican(3) Documentación de Perl aportada por el usuario Crypt::Mac::Pelican(3)

NOMBRE

Crypt::Mac::Pelican - Código de autenticación de mensajes Pelican (MAC basado en AES)

SINOPSIS

### Interfaz funcional:
use Crypt::Mac::Pelican qw( pelican pelican_hex );
# calcular MAC de cadena/buffer
$pelican_raw  = pelican($key, 'buffer de datos');
$pelican_hex  = pelican_hex($key, 'buffer de datos');
$pelican_b64  = pelican_b64($key, 'buffer de datos');
$pelican_b64u = pelican_b64u($key, 'buffer de datos');
### Interfaz OO:
use Crypt::Mac::Pelican;
$d = Crypt::Mac::Pelican->new($key);
$d->add('cualquier dato');
$d->addfile('nombre_archivo.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->mac;     # bytes crudos
$result_hex  = $d->hexmac;  # formato hexadecimal
$result_b64  = $d->b64mac;  # formato Base64
$result_b64u = $d->b64umac; # formato Base64 URL Safe

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de código de autenticación de mensajes (MAC) Pelican.

EXPORTACIÓN

No se exporta nada por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::Mac::Pelican qw(pelican pelican_hex );

O todas a la vez:

use Crypt::Mac::Pelican ':all';

FUNCIONES

pelican

Une lógicamente todos los argumentos en una única cadena y devuelve su código de autenticación de mensajes Pelican codificado como una cadena binaria.

$pelican_raw = pelican($key, 'buffer de datos');
#o
$pelican_raw = pelican($key, 'cualquier dato', 'más datos', 'incluso más datos');

pelican_hex

Une lógicamente todos los argumentos en una única cadena y devuelve su código de autenticación de mensajes Pelican codificado como una cadena hexadecimal.

$pelican_hex = pelican_hex($key, 'buffer de datos');
#o
$pelican_hex = pelican_hex($key, 'cualquier dato', 'más datos', 'incluso más datos');

pelican_b64

Une lógicamente todos los argumentos en una única cadena y devuelve su código de autenticación de mensajes Pelican codificado como una cadena Base64.

$pelican_b64 = pelican_b64($key, 'buffer de datos');
#o
$pelican_b64 = pelican_b64($key, 'cualquier dato', 'más datos', 'incluso más datos');

pelican_b64u

Une lógicamente todos los argumentos en una única cadena y devuelve su código de autenticación de mensajes Pelican codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$pelican_b64url = pelican_b64u($key, 'buffer de datos');
#o
$pelican_b64url = pelican_b64u($key, 'cualquier dato', 'más datos', 'incluso más datos');
