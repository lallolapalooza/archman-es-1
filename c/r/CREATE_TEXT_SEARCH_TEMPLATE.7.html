CREATE TEXT SEARCH TEMPLATE(7) Documentación de PostgreSQL 18.1 CREATE TEXT SEARCH TEMPLATE(7)

NOMBRE

CREATE TEXT SEARCH TEMPLATE - definir una nueva plantilla de búsqueda de texto

SINOPSIS

CREATE TEXT SEARCH TEMPLATE nombre (
    [ INIT = función_init , ]
    LEXIZE = función_lexize
)

DESCRIPCIÓN

CREATE TEXT SEARCH TEMPLATE crea una nueva plantilla de búsqueda de texto. Las plantillas de búsqueda de texto definen las funciones que implementan los diccionarios de búsqueda de texto. Una plantilla no es útil por sí sola, sino que debe ser instanciada como un diccionario para ser utilizada. El diccionario típicamente especifica los parámetros que se pasarán a las funciones de la plantilla.

Si se proporciona un nombre de esquema, la plantilla de búsqueda de texto se crea en el esquema especificado. De lo contrario, se crea en el esquema actual.

Debes ser superusuario para usar CREATE TEXT SEARCH TEMPLATE. Esta restricción se hace porque una definición errónea de una plantilla de búsqueda de texto podría confundir o incluso bloquear el servidor. La razón para separar las plantillas de los diccionarios es que una plantilla encapsula los aspectos “inseguros” de la definición de un diccionario. Los parámetros que se pueden establecer al definir un diccionario son seguros para que los usuarios no privilegiados los establezcan, por lo que la creación de un diccionario no necesita ser una operación privilegiada.

Consulte el Capítulo 12 para obtener más información.

PARÁMETROS

nombre

El nombre de la plantilla de búsqueda de texto a crear. El nombre puede estar calificado por el esquema.

función_init

El nombre de la función de inicialización para la plantilla.

función_lexize

El nombre de la función lexize para la plantilla.

Los nombres de las funciones pueden estar calificados por el esquema si es necesario. No se dan los tipos de argumento, ya que la lista de argumentos para cada tipo de función está predeterminada. La función lexize es obligatoria, pero la función de inicialización es opcional.

Los argumentos pueden aparecer en cualquier orden, no solo en el que se muestra arriba.

COMPATIBILIDAD

No existe una sentencia CREATE TEXT SEARCH TEMPLATE en el estándar SQL.

VER TAMBIÉN

ALTER TEXT SEARCH TEMPLATE (ALTER_TEXT_SEARCH_TEMPLATE(7)), DROP TEXT SEARCH TEMPLATE (DROP_TEXT_SEARCH_TEMPLATE(7))
