NOMBRE

cryptsetup-luksHeaderBackup - almacena una copia de seguridad binaria de la cabecera LUKS y el área de ranuras de claves

SINOPSIS

cryptsetup luksHeaderBackup --header-backup-file <archivo> [<opciones>] <dispositivo>

DESCRIPCIÓN

Almacena una copia de seguridad binaria de la cabecera LUKS y el área de ranuras de claves.

Usar '-' como nombre de archivo escribe la copia de seguridad de la cabecera en un archivo llamado '-'.

El archivo de copia de seguridad y una contraseña válida en el momento de la copia de seguridad permiten descifrar el área de datos LUKS, incluso si la contraseña se cambió o eliminó posteriormente del dispositivo LUKS. Tenga en cuenta que con una copia de seguridad de la cabecera, pierde la capacidad de borrar el dispositivo LUKS de forma segura simplemente sobrescribiendo la cabecera y las ranuras de claves. Debe borrar de forma segura todas las copias de seguridad de la cabecera o sobrescribir el área de datos cifrados.

<opciones> pueden ser [--header, --header-backup-file, --disable-locks].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si no se especifica la opción --verify-passphrase, esta opción también desactiva la verificación de la contraseña.

--debug o --debug-json

Ejecuta en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre van precedidas por #.

Si se usa --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--disable-locks

Desactiva la protección de bloqueo para metadatos en disco. Esta opción solo es válida para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No utilice esta opción a menos que ejecute cryptsetup en un entorno restringido donde el bloqueo sea imposible de realizar (donde el directorio /run no se pueda usar).

--header <dispositivo o archivo que almacena la cabecera LUKS>

Utiliza un dispositivo o archivo de metadatos separado (desvinculado) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para comandos que cambian la cabecera LUKS (por ejemplo, luksAddKey), especifique el dispositivo o archivo con la cabecera LUKS directamente como el dispositivo LUKS.

--header-backup-file archivo

Especifique un archivo con el archivo de copia de seguridad de la cabecera.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--usage

Muestra la ayuda de opciones cortas.

--version, -V

Muestra la versión del programa.

REPORTE DE ERRORES

Reporte errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de incidencias del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Por favor, adjunte la salida del comando fallido con la opción --debug añadida.
