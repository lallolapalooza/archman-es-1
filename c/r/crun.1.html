idmap opciones de

montaje

Si se especifica la opción idmap, el montaje se mapea por ID utilizando el espacio de nombres de usuario de destino del contenedor. Esta es una función experimental y puede cambiar en cualquier momento sin previo

aviso.

La opción idmap admite un mapeo personalizado que puede ser diferente al espacio de nombres de usuario utilizado por el

contenedor.

El mapeo se puede especificar después de la opción idmap como: idmap=uids=0-1-10#10-11-10;

gids=0-100-10.

Para cada trío, el primer valor es el inicio de los ID del sistema de archivos de respaldo que se mapean al segundo valor en el host. La longitud de este mapeo se indica en el tercer

valor.

Los rangos múltiples se separan con #

.

Estos valores se escriben en los archivos /proc/$PID/uid_map y /proc/$PID/gid_map para crear el espacio de nombres de usuario para el montaje con mapeo de

ID.

Las únicas dos opciones que se admiten actualmente después de idmap son uids y gids

.

Cuando se especifica un mapeo personalizado, se crea un nuevo espacio de nombres de usuario para el montaje con mapeo de

ID.

Si no se especifica ninguna opción, se utiliza el espacio de nombres de usuario del

contenedor.

Si el mapeo especificado se precede de un '@', el mapeo se considera relativo al espacio de nombres de usuario del contenedor. El ID del host para el mapeo se cambia para tener en cuenta la posición relativa del usuario del contenedor en el espacio de nombres de usuario del

contenedor.

Por ejemplo, el mapeo: uids=@1-3-10, dada una configuración

como
