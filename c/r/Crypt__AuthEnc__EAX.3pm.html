Crypt::AuthEnc::EAX(3) Documentación de Perl aportada por el usuario Crypt::AuthEnc::EAX(3)

NOMBRE

Crypt::AuthEnc::EAX - Cifrado autenticado en modo EAX

SINOPSIS

### Interfaz OO
use Crypt::AuthEnc::EAX;
# cifrar y autenticar
my $ae = Crypt::AuthEnc::EAX->new("AES", $key, $iv);
$ae->adata_add('datos_adicionales_autenticados1');
$ae->adata_add('datos_adicionales_autenticados2');
my $ct = $ae->encrypt_add('datos1');
$ct .= $ae->encrypt_add('datos2');
$ct .= $ae->encrypt_add('datos3');
my $tag = $ae->encrypt_done();
# descifrar y verificar
my $ae = Crypt::AuthEnc::EAX->new("AES", $key, $iv);
$ae->adata_add('datos_adicionales_autenticados1');
$ae->adata_add('datos_adicionales_autenticados2');
my $pt = $ae->decrypt_add('cifrado1');
$pt .= $ae->decrypt_add('cifrado2');
$pt .= $ae->decrypt_add('cifrado3');
my $tag = $ae->decrypt_done();
die "falla el descifrado" unless $tag eq $expected_tag;
# o
my $result = $ae->decrypt_done($expected_tag); # 0 o 1
### Interfaz funcional
use Crypt::AuthEnc::EAX qw(eax_encrypt_authenticate eax_decrypt_verify);
my ($ciphertext, $tag) = eax_encrypt_authenticate('AES', $key, $iv, $adata, $plaintext);
my $plaintext = eax_decrypt_verify('AES', $key, $iv, $adata, $ciphertext, $tag);

DESCRIPCIÓN

EAX es un modo que requiere un cifrador, soporte CTR y OMAC y proporciona cifrado y autenticación. Se inicializa con un IV aleatorio que puede ser compartido públicamente, datos autenticados adicionales que pueden ser fijos y públicos, y una clave simétrica secreta aleatoria.

EXPORTAR

No se exporta nada por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::AuthEnc::EAX qw(eax_encrypt_authenticate eax_decrypt_verify);

FUNCIONES

eax_encrypt_authenticate

my ($ciphertext, $tag) = eax_encrypt_authenticate($cipher, $key, $iv, $adata, $plaintext);
# $cipher .. 'AES' o el nombre de cualquier otro cifrador con bloque de 16 bytes
# $key ..... clave AES de longitud adecuada (128/192/256 bits)
# $iv ...... vector de inicialización único (no es necesario mantenerlo en secreto)
# $adata ... datos autenticados adicionales

eax_decrypt_verify

my $plaintext = eax_decrypt_verify($cipher, $key, $iv, $adata, $ciphertext, $tag);
# en caso de error devuelve undef

MÉTODOS

new

my $ae = Crypt::AuthEnc::EAX->new($cipher, $key, $iv);
# o
my $ae = Crypt::AuthEnc::EAX->new($cipher, $key, $iv, $adata);
# $cipher .. 'AES' o el nombre de cualquier otro cifrador con bloque de 16 bytes
# $key ..... clave AES de longitud adecuada (128/192/256 bits)
# $iv ...... vector de inicialización único (no es necesario mantenerlo en secreto)
# $adata ... datos autenticados adicionales (opcional)

adata_add

$ae->adata_add($adata);                        # se puede llamar varias veces

encrypt_add

$ciphertext = $ae->encrypt_add($data);         # se puede llamar varias veces

encrypt_done

$tag = $ae->encrypt_done();                    # devuelve el valor de $tag

decrypt_add

$plaintext = $ae->decrypt_add($ciphertext);    # se puede llamar varias veces

decrypt_done

my $tag = $ae->decrypt_done;           # devuelve el valor de $tag
# o
my $result = $ae->decrypt_done($tag);  # devuelve 1 (éxito) o 0 (fallo)

clone

my $ae_new = $ae->clone;
