DESCRIPCIÓN

Argumentos posicionales:

archivos
archivo de entrada y salida FRAT [nargs: 0 o más]

Argumentos opcionales:

-h, --help
muestra el mensaje de ayuda y sale
-v, --version
imprime la información de la versión y sale
--verb
[0-10] Nivel de verbosidad del solucionador. 0 = solo solución [nargs=0..1] [predeterminado: 1]
-v, --version
Imprimir información de la versión
--maxtime
Dejar de resolver después de este tiempo (s)
--maxconfl
Dejar de resolver después de este número de conflictos
-r, --random
[0..] Semilla aleatoria [nargs=0..1] [predeterminado: 0]
-t, --threads
Número de hilos [nargs=0..1] [predeterminado: 1]
-m, --mult
Multiplicador de tiempo para todos los límites de simplificación [nargs=0..1] [predeterminado: 3]
--nextm
Multiplicador global para cuando debe ocurrir el próximo procesamiento interno [nargs=0..1] [predeterminado: 1]
--memoutmult
Multiplicador para comprobaciones de agotamiento de memoria en funciones de procesamiento interno. Limita cosas como clause-link-in. Útil cuando tienes memoria limitada pero aún quieres hacer algún procesamiento interno [nargs=0..1] [predeterminado: 1]
--maxsol
Buscar la cantidad dada de soluciones. Gracias a Jannis Harder por la idea de prohibición basada en decisiones [nargs=0..1] [predeterminado: 1]
--polar
{true,false,rnd,auto,stable} Selecciona el modo de polaridad. 'true' -> selecciona solo polaridad positiva al ramificar. 'false' -> selecciona solo polaridad negativa al ramificar. 'auto' -> selecciona la última polaridad utilizada (también llamada 'caching') [nargs=0..1] [predeterminado: "auto"]
--scc
Encontrar literales equivalentes a través de SCC y reemplazarlos [nargs=0..1] [predeterminado: 1]
--restart
{geom, glue, luby} Estrategia de reinicio a seguir. [nargs=0..1] [predeterminado: "auto"]
--rstfirst
El tamaño del reinicio base [nargs=0..1] [predeterminado: 100]
--gluehist
El tamaño de la ventana móvil para el historial de pegamento a corto plazo de cláusulas redundantes. Si es mayor, el número mínimo de conflictos entre reinicios es más largo [nargs=0..1] [predeterminado: 50]
--lwrbndblkrest
Límite inferior para el reinicio de bloqueo -- no bloquear antes de este número de conflictos [nargs=0..1] [predeterminado: 10000]
--locgmult
El multiplicador utilizado para determinar si debemos reiniciar durante el reinicio basado en pegamento [nargs=0..1] [predeterminado: 0.8]
--ratiogluegeom
Relación entre reinicios de pegamento y geométricos -- más es más pegamento [nargs=0..1] [predeterminado: 5]
--blockingglue
Hacer reinicio de bloqueo para pegamentos [nargs=0..1] [predeterminado: 1]
--gluecut0
Valor de pegamento para el corte de lev 0 ('mantener') [nargs=0..1] [predeterminado: 3]
--gluecut1
Valor de pegamento para el corte de lev 1 ('dar otra oportunidad') [nargs=0..1] [predeterminado: 6]
--adjustglue
Si más de este % de cláusulas tiene pegamento BAJO (nivel 0), entonces baja el corte de pegamento en 1 -- una vez y nunca más [nargs=0..1] [predeterminado: 0.7]
--everylev1
Reducir cláusulas lev1 cada N [nargs=0..1] [predeterminado: 10000]
--everylev2
Reducir cláusulas lev2 cada N [nargs=0..1] [predeterminado: 15000]
--lev1usewithin
Usa las cláusulas lev1 solo si están dentro de este número de conflictos [nargs=0..1] [predeterminado: 10000]
--branchstr
{auto,global,local} Selecciona la estrategia de ramificación. 'auto' -> usa la mejor estrategia [nargs=0..1] [predeterminado: "auto"]
--nobansol

--debuglib

--breakid
Enciende el algoritmo de ruptura de identificadores [nargs=0..1] [predeterminado: 1]
