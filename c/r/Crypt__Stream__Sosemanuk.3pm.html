NOMBRE

Crypt::Stream::Sosemanuk - Cifrado de flujo Sosemanuk

SINOPSIS

use Crypt::Stream::Sosemanuk;
# cifrar
$key = "1234567890123456";
$iv  = "123456789012";
$stream = Crypt::Stream::Sosemanuk->new($key, $iv);
$ct = $stream->crypt("mensaje plano");
# descifrar
$key = "1234567890123456";
$iv  = "123456789012";
$stream = Crypt::Stream::Sosemanuk->new($key, $iv);
$pt = $stream->crypt($ct);

DESCRIPCIÓN

Proporciona una interfaz para el cifrado de flujo Sosemanuk.

MÉTODOS

new

$stream = Crypt::Stream::Sosemanuk->new($key, $iv);
# $key .. la longitud de la clave debe ser múltiplo de 4 bytes
# $iv  .. la longitud del IV debe ser múltiplo de 4 bytes (OPCIONAL)

crypt

$ciphertext = $stream->crypt($plaintext);
# o
$plaintext = $stream->crypt($ciphertext);

keystream

$random_key = $stream->keystream($length);

clone

$stream->clone();
