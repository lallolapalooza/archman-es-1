DESCRIPCIÓ

N

El módulo proporciona un conjunto de funciones ECC fundamentales, así como la implementación de ECDSA y

ECDH.

Soporta curvas elípticas "y^2 = x^3 + a*x + b" sobre campos primos "Fp = Z/pZ" (no se s

oportan campo
s binarios).
