crypt_preferred_method(3)

Paquete: libxcrypt

Licencias: LGPL

CRYPT_PREFERRED_METHOD(3) Manual de funciones de biblioteca CRYPT_PREFERRED_METHOD(3)

NOMBRE

crypt_preferred_method — obtener el prefijo del método de hash preferido

BIBLIOTECA

Biblioteca Crypt (libcrypt, -lcrypt)

SINOPSIS

#include <crypt.h>

const char*
crypt_preferred_method(void);

DESCRIPCIÓN

crypt_preferred_method es una función de conveniencia para obtener el prefijo del método de hash preferido. Si hay un método preferido disponible, es el mismo que el utilizado también por las funciones crypt_gensalt, si su parámetro prefix dado es NULL.

VALORES DE RETORNO

La cadena devuelta es igual al prefijo del método de hash preferido. Si no hay ningún método de hash preferido disponible, es NULL. Es seguro pasar la cadena devuelta por crypt_preferred_method directamente a crypt_gensalt sin saneamiento previo de cadenas ni comprobaciones de puntero NULL.

MACROS DE PRUEBA DE CARACTERÍSTICAS

<crypt.h> definirá la macro CRYPT_PREFERRED_METHOD_AVAILABLE si crypt_preferred_method está disponible en la versión actual de libxcrypt.

NOTAS DE PORTABILIDAD

La función crypt_preferred_method no es parte de ningún estándar. Se añadió a libxcrypt en la versión 4.4.0.
