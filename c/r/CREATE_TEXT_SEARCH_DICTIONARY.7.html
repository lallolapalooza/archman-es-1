CREATE TEXT SEARCH DICTIONARY(7) Documentación de PostgreSQL 18.1 CREATE TEXT SEARCH DICTIONARY(7)

NOMBRE

CREATE TEXT SEARCH DICTIONARY - definir un nuevo diccionario de búsqueda de texto

SINOPSIS

CREATE TEXT SEARCH DICTIONARY nombre (
    TEMPLATE = plantilla
    [, opción = valor [, ... ]]
)

DESCRIPCIÓN

CREATE TEXT SEARCH DICTIONARY crea un nuevo diccionario de búsqueda de texto. Un diccionario de búsqueda de texto especifica una forma de reconocer palabras interesantes o no interesantes para la búsqueda. Un diccionario depende de una plantilla de búsqueda de texto, que especifica las funciones que realizan el trabajo real. Típicamente, el diccionario proporciona algunas opciones que controlan el comportamiento detallado de las funciones de la plantilla.

Si se proporciona un nombre de esquema, el diccionario de búsqueda de texto se crea en el esquema especificado. De lo contrario, se crea en el esquema actual.

El usuario que define un diccionario de búsqueda de texto se convierte en su propietario.

Consulte el Capítulo 12 para obtener más información.

PARÁMETROS

nombre

El nombre del diccionario de búsqueda de texto a crear. El nombre puede estar calificado por un esquema.

plantilla

El nombre de la plantilla de búsqueda de texto que definirá el comportamiento básico de este diccionario.

opción

El nombre de una opción específica de la plantilla que se establecerá para este diccionario.

valor

El valor a utilizar para una opción específica de la plantilla. Si el valor no es un identificador simple o un número, debe estar entre comillas (pero siempre puedes entrecomillarlo, si lo deseas).

Las opciones pueden aparecer en cualquier orden.

EJEMPLOS

El siguiente comando de ejemplo crea un diccionario basado en Snowball con una lista no estándar de palabras vacías.

CREATE TEXT SEARCH DICTIONARY my_russian (
    template = snowball,
    language = russian,
    stopwords = myrussian
);

COMPATIBILIDAD

No existe una sentencia CREATE TEXT SEARCH DICTIONARY en el estándar SQL.

VER TAMBIÉN

ALTER TEXT SEARCH DICTIONARY (ALTER_TEXT_SEARCH_DICTIONARY(7)), DROP TEXT SEARCH DICTIONARY (DROP_TEXT_SEARCH_DICTIONARY(7))
