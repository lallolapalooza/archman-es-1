CRIT(1) Manual de CRIU CRIT(1)



NOMBRE
crit - Herramienta de Imágenes de CRiu



SINOPSIS

crit decode [-h] [-i IN] [-o OUT] [--pretty]

crit encode [-h] [-i IN] [-o OUT]

crit info [-h] in

crit x [-h] dir {ps,fds,mems}

crit show [-h] in



DESCRIPCIÓN

crit es un reemplazo con muchas características para el `criu show` existente.



ARGUMENTOS



Argumentos Posicionales

decode

convierte la imagen de criu de tipo binario a JSON

encode

convierte la imagen de criu de tipo JSON a binario

info

muestra información sobre la imagen

x

explora el directorio de la imagen

show

convierte la imagen de criu de binario a JSON legible



Argumentos Opcionales

-h, --help

Imprime ayuda y sale
