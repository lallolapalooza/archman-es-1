create_module(2) Manual de llamadas al sistema create_module(2)

NOMBRE

create_module - crea una entrada de módulo cargable

SINOPSIS

#include <linux/module.h>
[[deprecated]] caddr_t create_module(const char *name, size_t size);

DESCRIPCIÓN

Nota: Esta llamada al sistema solo está presente antes de Linux 2.6.

create_module() intenta crear una entrada de módulo cargable y reservar la memoria del kernel que se necesitará para alojar el módulo. Esta llamada al sistema requiere privilegios.

VALOR DE RETORNO

En caso de éxito, devuelve la dirección del kernel en la que residirá el módulo. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EEXIST
Ya existe un módulo con ese nombre.
EFAULT
name está fuera del espacio de direcciones accesible del programa.
EINVAL
El tamaño solicitado es demasiado pequeño incluso para la información de la cabecera del módulo.
ENOMEM
El kernel no pudo asignar un bloque contiguo de memoria lo suficientemente grande para el módulo.
ENOSYS
create_module() no está soportado en esta versión del kernel (por ejemplo, Linux 2.6 o posterior).
EPERM
El llamador no tenía privilegios (no tenía la capacidad CAP_SYS_MODULE).

ESTANDARES

Linux.

HISTORIA

Eliminado en Linux 2.6.

Esta llamada al sistema obsoleta no está soportada por glibc. No se proporciona ninguna declaración en las cabeceras de glibc, pero, por una quirúrgica histórica, las versiones de glibc anteriores a glibc 2.23 sí exportaban una ABI para esta llamada al sistema. Por lo tanto, para emplear esta llamada al sistema, era suficiente declarar manualmente la interfaz en su código; alternativamente, podía invocar la llamada al sistema usando syscall(2).

VER TAMBIÉN

delete_module(2), init_module(2), query_module(2)
