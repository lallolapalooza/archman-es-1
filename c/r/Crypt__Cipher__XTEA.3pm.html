NOMBRE

Crypt::Cipher::XTEA - Cifra simétrica XTEA, tamaño de clave: 128 bits

SINOPSIS

### ejemplo 1
use Crypt::Mode::CBC;
my $key = '...'; # la longitud debe ser un tamaño de clave válido para esta cifra
my $iv = '...';  # 16 bytes
my $cbc = Crypt::Mode::CBC->new('XTEA');
my $ciphertext = $cbc->encrypt("datos secretos", $key, $iv);
### ejemplo 2 (más lento)
use Crypt::CBC;
use Crypt::Cipher::XTEA;
my $key = '...'; # la longitud debe ser un tamaño de clave válido para esta cifra
my $iv = '...';  # 16 bytes
my $cbc = Crypt::CBC->new( -cipher=>'Cipher::XTEA', -key=>$key, -iv=>$iv );
my $ciphertext = $cbc->encrypt("datos secretos");

DESCRIPCIÓN

Este módulo implementa la cifra XTEA. La interfaz proporcionada es compatible con el módulo Crypt::CBC.

¡CUIDADO! Este módulo solo implementa la operación elemental de "cifrado/descifrado de un bloque". Si desea cifrar/descifrar datos genéricos, debe utilizar algunos de los modos de bloque de cifra. Consulte, por ejemplo, Crypt::Mode::CBC, Crypt::Mode::CTR o Crypt::CBC (que será más lento).
