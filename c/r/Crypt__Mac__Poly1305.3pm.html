NOMBRE

Crypt::Mac::Poly1305 - Código de autenticación de mensajes Poly1305 (RFC 7539)

SINOPSIS

### Interfaz funcional:
use Crypt::Mac::Poly1305 qw( poly1305 poly1305_hex );
# calcular MAC de cadena/buffer
$poly1305_raw  = poly1305($key, 'buffer de datos');
$poly1305_hex  = poly1305_hex($key, 'buffer de datos');
$poly1305_b64  = poly1305_b64($key, 'buffer de datos');
$poly1305_b64u = poly1305_b64u($key, 'buffer de datos');
### Interfaz OO:
use Crypt::Mac::Poly1305;
$d = Crypt::Mac::Poly1305->new($key);
$d->add('cualquier dato');
$d->addfile('archivo.dat');
$d->addfile(*MANEJADOR_ARCHIVO);
$result_raw  = $d->mac;     # bytes crudos
$result_hex  = $d->hexmac;  # formato hexadecimal
$result_b64  = $d->b64mac;  # formato Base64
$result_b64u = $d->b64umac; # formato Base64 seguro para URL

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de código de autenticación de mensajes (MAC) Poly1305.

EXPORTAR

Nada se exporta por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::Mac::Poly1305 qw(poly1305 poly1305_hex );

O todas a la vez:

use Crypt::Mac::Poly1305 ':all';

FUNCIONES

poly1305

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes Poly1305 codificado como una cadena binaria.

$poly1305_raw = poly1305($key, 'buffer de datos');
#o
$poly1305_raw = poly1305($key, 'cualquier dato', 'más datos', 'aún más datos');

poly1305_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes Poly1305 codificado como una cadena hexadecimal.

$poly1305_hex = poly1305_hex($key, 'buffer de datos');
#o
$poly1305_hex = poly1305_hex($key, 'cualquier dato', 'más datos', 'aún más datos');

poly1305_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes Poly1305 codificado como una cadena Base64.

$poly1305_b64 = poly1305_b64($key, 'buffer de datos');
#o
$poly1305_b64 = poly1305_b64($key, 'cualquier dato', 'más datos', 'aún más datos');

poly1305_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes Poly1305 codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$poly1305_b64url = poly1305_b64u($key, 'buffer de datos');
#o
$poly1305_b64url = poly1305_b64u($key, 'cualquier dato', 'más datos', 'aún más datos');
