CREATE CONVERSION(7) Documentación de PostgreSQL 18.1 CREATE CONVERSION(7)

NOMBRE

CREATE CONVERSION - define una nueva conversión de codificación

SINOPSIS

CREATE [ DEFAULT ] CONVERSION nombre
    FOR codificacion_origen TO codificacion_destino FROM nombre_funcion

DESCRIPCIÓN

CREATE CONVERSION define una nueva conversión entre dos conjuntos de caracteres de codificación.

Las conversiones que se marcan como DEFAULT pueden ser usadas para la conversión automática de codificación entre el cliente y el servidor. Para soportar este uso, deben definirse dos conversiones, de la codificación A a la B *y* de la codificación B a la A.

Para poder crear una conversión, debe tener el privilegio EXECUTE sobre la función y el privilegio CREATE sobre el esquema de destino.

PARÁMETROS

DEFAULT

La cláusula DEFAULT indica que esta conversión es la predeterminada para este par particular de codificación de origen a destino. Debería haber solo una codificación predeterminada en un esquema para el par de codificaciones.

nombre

El nombre de la conversión. El nombre de la conversión puede estar calificado por el esquema. Si no lo está, la conversión se define en el esquema actual. El nombre de la conversión debe ser único dentro de un esquema.

codificacion_origen

El nombre de la codificación de origen.

codificacion_destino

El nombre de la codificación de destino.

nombre_funcion

La función utilizada para realizar la conversión. El nombre de la función puede estar calificado por el esquema. Si no lo está, la función se buscará en el `PATH`.

La función debe tener la siguiente firma:

conv_proc(
    integer,  -- ID de la codificación de origen
    integer,  -- ID de la codificación de destino
    cstring,  -- cadena de origen (cadena C terminada en nulo)
    internal, -- destino (rellenar con una cadena C terminada en nulo)
    integer,  -- longitud de la cadena de origen
    boolean   -- si es verdadero, no lanzar un error si la conversión falla
) RETURNS integer;

El valor de retorno es el número de bytes de origen que se convirtieron con éxito. Si el último argumento es falso, la función debe lanzar un error ante una entrada inválida, y el valor de retorno es siempre igual a la longitud de la cadena de origen.

NOTAS

Ni la codificación de origen ni la de destino pueden ser SQL_ASCII, ya que el comportamiento del servidor en casos que involucran la "codificación" SQL_ASCII está cableado.

Use DROP CONVERSION para eliminar conversiones definidas por el usuario.

Los privilegios requeridos para crear una conversión podrían cambiar en una futura versión.

EJEMPLOS

Para crear una conversión de la codificación UTF8 a LATIN1 usando myfunc:

CREATE CONVERSION myconv FOR 'UTF8' TO 'LATIN1' FROM myfunc;

COMPATIBILIDAD

CREATE CONVERSION es una extensión de PostgreSQL. No existe una sentencia CREATE CONVERSION en el estándar SQL, pero sí una sentencia CREATE TRANSLATION que es muy similar en propósito y sintaxis.

VER TAMBIÉN

ALTER CONVERSION (ALTER_CONVERSION(7)), CREATE FUNCTION (CREATE_FUNCTION(7)), DROP CONVERSION (DROP_CONVERSION(7))
