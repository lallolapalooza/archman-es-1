Crypt::Stream::Salsa20(3) Documentación de Perl contribuida por el usuario Crypt::Stream::Salsa20(3)

NOMBRE

Crypt::Stream::Salsa20 - Cifrado en flujo Salsa20

SINOPSIS

use Crypt::Stream::Salsa20;
# cifrar
$clave = "1234567890123456";
$iv  = "12345678";
$stream = Crypt::Stream::Salsa20->new($clave, $iv);
$ct = $stream->crypt("mensaje en claro");
# descifrar
$clave = "1234567890123456";
$iv  = "12345678";
$stream = Crypt::Stream::Salsa20->new($clave, $iv);
$pt = $stream->crypt($ct);

DESCRIPCIÓN

Proporciona una interfaz para el cifrado en flujo Salsa20.

MÉTODOS

new

$stream = Crypt::Stream::Salsa20->new($clave, $iv);
# o
$stream = Crypt::Stream::Salsa20->new($clave, $iv, $contador, $rondas);
# $clave     .. 32 o 16 bytes
# $iv      .. 8 bytes
# $contador .. valor inicial del contador (POR DEFECTO: 0)
# $rondas  .. rondas (POR DEFECTO: 20)

crypt

$texto_cifrado = $stream->crypt($texto_en_claro);
# o
$texto_en_claro = $stream->crypt($texto_cifrado);

keystream

$clave_aleatoria = $stream->keystream($longitud);

clone

$stream->clone();
