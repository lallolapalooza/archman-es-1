NOMBRE

cryptsetup-luksKillSlot - borrar una ranura de clave del dispositivo LUKS

SINOPSIS

cryptsetup luksKillSlot [<opciones>] <dispositivo> <número>

DESCRIPCIÓN

Borra la ranura de clave con el número especificado del dispositivo LUKS.

Excepto al ejecutarse en modo por lotes (-q), se debe proporcionar una contraseña restante, ya sea interactivamente o a través de --key-file. Este comando puede eliminar la última ranura de clave restante, pero requiere una confirmación interactiva al hacerlo. Eliminar la última contraseña hace que un contenedor LUKS sea permanentemente inaccesible.

Si lee la contraseña desde la entrada estándar (sin argumentos adicionales o con '-' como argumento para --key-file), el modo por lotes (-q) se activará implícitamente y no se dará ninguna advertencia al eliminar la última contraseña restante de un contenedor LUKS. Eliminar la última contraseña hace que el contenedor LUKS sea permanentemente inaccesible.

Si no se proporciona ninguna contraseña (en la entrada estándar o a través del argumento --key-file) y el modo por lotes (-q) está activo, la ranura de clave se elimina sin ninguna otra advertencia.

Esta operación solo elimina la clave en una ranura de clave particular; no borra ningún dato cifrado.

<opciones> pueden ser [--key-file, --keyfile-offset, --keyfile-size, --header, --disable-locks, --type, --verify-passphrase, --timeout].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si no se especifica la opción --verify-passphrase, esta opción también desactiva la verificación de la contraseña.

--debug o --debug-json

Ejecutar en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre están prefijadas por #.

Si se usa --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--disable-locks

Deshabilita la protección de bloqueo para metadatos en disco. Esta opción solo es válida para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No utilice esta opción a menos que ejecute cryptsetup en un entorno restringido donde el bloqueo sea imposible de realizar (donde el directorio /run no pueda utilizarse).

--header <dispositivo o archivo que almacena la cabecera LUKS>

Utiliza un dispositivo o archivo de metadatos separado (desacoplado) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para comandos que cambian la cabecera LUKS (por ejemplo, luksAddKey), especifique directamente el dispositivo o archivo con la cabecera LUKS como dispositivo LUKS.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--key-file, -d archivo

Lee la contraseña del archivo.

Si el nombre dado es "-", la contraseña se leerá de la entrada estándar. En este caso, la lectura no se detendrá en los caracteres de nueva línea.

Consulte la sección NOTAS SOBRE EL PROCESAMIENTO DE CONTRASEÑAS en cryptsetup(8) para obtener más información.

--keyfile-offset valor

Omite valor bytes al principio del archivo de clave.

--keyfile-size, -l valor

Lee un máximo de valor bytes del archivo de clave. El valor predeterminado es leer todo el archivo hasta el máximo compilado que se puede consultar con --help. Proporcionar más datos que el máximo compilado aborta la operación.

Esta opción es útil para eliminar saltos de línea finales, por ejemplo. Si también se proporciona --keyfile-offset, el recuento de tamaño comienza después del desplazamiento.

--timeout, -t segundos

El número de segundos a esperar antes de un tiempo de espera en la entrada de contraseña a través de terminal. Es relevante cada vez que se solicita una contraseña. No tiene efecto si se utiliza junto con --key-file.

Esta opción es útil cuando el sistema no debe detenerse si el usuario no introduce una contraseña, por ejemplo, durante el arranque. El valor predeterminado es 0 segundos, lo que significa esperar indefinidamente.

--type tipo

Especifica el tipo de dispositivo requerido; para más información, lea la sección ACCIONES BÁSICAS en cryptsetup(8).

--usage

Muestra la ayuda de opciones cortas.

--verify-passphrase, -y

Al solicitar interactivamente una contraseña, solicítela dos veces y quejarse si ambas entradas no coinciden. Ignorado en la entrada desde archivo o stdin.

--version, -V

Muestra la versión del programa.

REPORTAR ERRORES

Reporte errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de incidencias del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Por favor, adjunte la salida del comando fallido con la opción --debug añadida.
