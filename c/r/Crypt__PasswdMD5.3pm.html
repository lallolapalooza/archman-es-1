Crypt::PasswdMD5(3) Documentación de Perl contribuida por el usuario Crypt::PasswdMD5(3)

NOMBRE

Crypt::PasswdMD5 - Proporcionar funciones criptográficas basadas en MD5 interoperables

SINOPSIS

use strict;
use warnings;
use Crypt::PasswdMD5;
my($password)       = 'seekrit';
my($salt)           = 'pepperoni';
my($unix_crypted)   = unix_md5_crypt($password, $salt);
my($apache_crypted) = apache_md5_crypt($password, $salt);
O:
use strict;
use warnings;
use Crypt::PasswdMD5 'random_md5_salt';
my($length) = 7;
my($salt_1) = random_md5_salt($length);
my($salt_2) = random_md5_salt(); # Por defecto $length == 8.

DESCRIPCIÓN

apache_md5_crypt() proporciona una función compatible con los archivos ".htpasswd" de Apache. Esto fue contribuido por Bryan Hart <bryan@eai.com>. Esta función se exporta por defecto.

La función unix_md5_crypt() proporciona una interfaz compatible con crypt() para la función crypt() basada en MD5, bastante nueva, que se encuentra en sistemas operativos modernos. Se basa en la implementación encontrada en FreeBSD 2.2.[56]-RELEASE. Esta función también se exporta por defecto.

Para ambas funciones, si no se proporciona un valor de sal, se generará una sal aleatoria, utilizando la función random_md5_salt(). Esta función no se exporta por defecto.

MÉTODOS

apache_md5_crypt($password, $salt)

Esto establece una variable mágica y luego pasa todos los parámetros de llamada a "unix_md5_crypt($password, $salt)".

Devuelve una versión cifrada de la contraseña proporcionada.

Básicamente, es una opción muy pobre para cualquier cosa que no sea la autenticación de contraseñas.

random_md5_salt([$length])

Aquí, [] indican un parámetro opcional.

Devuelve una sal aleatoria de la longitud dada.

La longitud máxima es 8.

Si se omite $length, por defecto es 8.

unix_md5_crypt($password, $salt)

Devuelve una versión cifrada de la contraseña proporcionada.

Básicamente, es una opción muy pobre para cualquier cosa que no sea la autenticación de contraseñas.
