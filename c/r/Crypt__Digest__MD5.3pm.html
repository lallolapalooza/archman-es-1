Crypt::Digest::MD5(3) Documentación de Perl contribuida por usuarios Crypt::Digest::MD5(3)

NOMBRE

Crypt::Digest::MD5 - Función hash MD5 [tamaño: 128 bits]

SINOPSIS

### Interfaz funcional:
use Crypt::Digest::MD5 qw( md5 md5_hex md5_b64 md5_b64u
                             md5_file md5_file_hex md5_file_b64 md5_file_b64u );
# calcular el resumen desde una cadena/búfer
$md5_raw  = md5('data string');
$md5_hex  = md5_hex('data string');
$md5_b64  = md5_b64('data string');
$md5_b64u = md5_b64u('data string');
# calcular el resumen desde un archivo
$md5_raw  = md5_file('filename.dat');
$md5_hex  = md5_file_hex('filename.dat');
$md5_b64  = md5_file_b64('filename.dat');
$md5_b64u = md5_file_b64u('filename.dat');
# calcular el resumen desde un manejador de archivo
$md5_raw  = md5_file(*FILEHANDLE);
$md5_hex  = md5_file_hex(*FILEHANDLE);
$md5_b64  = md5_file_b64(*FILEHANDLE);
$md5_b64u = md5_file_b64u(*FILEHANDLE);
### Interfaz orientada a objetos:
use Crypt::Digest::MD5;
$d = Crypt::Digest::MD5->new;
$d->add('any data');
$d->addfile('filename.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->digest;     # bytes crudos
$result_hex  = $d->hexdigest;  # forma hexadecimal
$result_b64  = $d->b64digest;  # forma Base64
$result_b64u = $d->b64udigest; # forma Base64 segura para URL

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de resumen MD5.

EXPORTACIÓN

No se exporta nada por defecto.

Puede exportar funciones seleccionadas:

use Crypt::Digest::MD5 qw(md5 md5_hex md5_b64 md5_b64u
                                    md5_file md5_file_hex md5_file_b64 md5_file_b64u);

O todas a la vez:

use Crypt::Digest::MD5 ':all';

FUNCIONES

md5

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen MD5 codificado como una cadena binaria.

$md5_raw = md5('data string');
#o
$md5_raw = md5('any data', 'more data', 'even more data');

md5_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen MD5 codificado como una cadena hexadecimal.

$md5_hex = md5_hex('data string');
#o
$md5_hex = md5_hex('any data', 'more data', 'even more data');

md5_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen MD5 codificado como una cadena Base64, con relleno de '=' al final.

$md5_b64 = md5_b64('data string');
#o
$md5_b64 = md5_b64('any data', 'more data', 'even more data');

md5_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen MD5 codificado como una cadena Base64 segura para URL (véase la sección 5 del RFC 4648).

$md5_b64url = md5_b64u('data string');
#o
$md5_b64url = md5_b64u('any data', 'more data', 'even more data');

md5_file

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen MD5 codificado como una cadena binaria.

$md5_raw = md5_file('filename.dat');
#o
$md5_raw = md5_file(*FILEHANDLE);

md5_file_hex

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen MD5 codificado como una cadena hexadecimal.

$md5_hex = md5_file_hex('filename.dat');
#o
$md5_hex = md5_file_hex(*FILEHANDLE);

ADVERTENCIA: Debe asegurarse de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

md5_file_b64

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen MD5 codificado como una cadena Base64, con relleno de '=' al final.

$md5_b64 = md5_file_b64('filename.dat');
#o
$md5_b64 = md5_file_b64(*FILEHANDLE);

md5_file_b64u

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen MD5 codificado como una cadena Base64 segura para URL (véase la sección 5 del RFC 4648).

$md5_b64url = md5_file_b64u('filename.dat');
#o
$md5_b64url = md5_file_b64u(*FILEHANDLE);

MÉTODOS

La interfaz orientada a objetos proporciona el mismo conjunto de funciones que Crypt::Digest.

new

$d = Crypt::Digest::MD5->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('any data');
#o
$d->add('any data', 'more data', 'even more data');

addfile

$d->addfile('filename.dat');
#o
$d->addfile(*FILEHANDLE);

add_bits

$d->add_bits($bit_string);   # p. ej. $d->add_bits("111100001010");
#o
$d->add_bits($data, $nbits); # p. ej. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#o
Crypt::Digest::MD5->hashsize();
#o
Crypt::Digest::MD5::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
