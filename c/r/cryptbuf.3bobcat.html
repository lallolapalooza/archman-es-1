FBB::CryptBuf(3bobcat) Clase base para DecryptBuf y EncryptBuf FBB::CryptBuf(3bobcat)

NOMBRE

FBB::CryptBuf - clase base derivada de std::streambuf para DecryptBuf y EncryptBuf

SINOPSIS

#include <bobcat/cryptbuf>
Opción de enlazado: -lbobcat -lcrypto

DESCRIPCIÓN

Esta clase está obsoleta y será eliminada de Bobcat en una futura versión. Hereda de FBB::EoiBuf. Las clases que usan CryptBuf pueden usar EoiBuf en su lugar. El miembro EVP_CIPHER const *md() de CryptBuf se puede implementar de la siguiente manera:

    #include <openssl/evp.h>
    EVP_CIPHER const *md(char const *cipherName)
    {
        return EVP_CIPHER_fetch(0, cipherName, 0);
    }

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

EoiBuf (y por lo tanto de: std::streambuf)

CONSTRUCTOR PROTEGIDO

Análogamente a std::streambuf, solo está disponible un constructor protegido.

o
CryptBuf(char const *type, size_t bufSize):
El tipo es una cadena de bytes terminada en nulo que especifica el método de cifrado/descifrado. Por ejemplo, aes-128-cbc. Para una visión general, consulte la página del manual encryptbuf(3bobcat). El parámetro bufSize define el tamaño inicial del búfer utilizado internamente (definido por EoiBuf).

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIÓN MIEMBRO PROTEGIDA

Todos los miembros de std:streambuf y EoiBuf están disponibles, ya que FBB::CryptBuf hereda de estas clases.

o
EVP_CIPHER const *md() const:
Se devuelve un puntero a la información del cifrado.
