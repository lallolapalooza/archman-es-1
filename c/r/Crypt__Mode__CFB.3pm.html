Crypt::Mode::CFB(3) Documentación de Perl aportada por el usuario Crypt::Mode::CFB(3)

NOMBRE

Crypt::Mode::CFB - Modo de cifrado de bloque CFB [Retroalimentación de cifrado]

SINOPSIS

use Crypt::Mode::CFB;
my $m = Crypt::Mode::CFB->new('AES');
# cifrar (en) o descifrar (de) a la vez
my $ciphertext = $m->encrypt($plaintext, $key, $iv);
my $plaintext = $m->decrypt($ciphertext, $key, $iv);
# cifrar más fragmentos
$m->start_encrypt($key, $iv);
my $ciphertext = $m->add('algunos datos');
$ciphertext .= $m->add('más datos');
# descifrar más fragmentos
$m->start_decrypt($key, $iv);
my $plaintext = $m->add($some_ciphertext);
$plaintext .= $m->add($more_ciphertext);

DESCRIPCIÓN

Este módulo implementa el modo de cifrado CFB. **NOTA:** solo funciona con cifrados de CryptX (Crypt::Cipher::NNNN).

MÉTODOS

new

my $m = Crypt::Mode::CFB->new($name);
# o
my $m = Crypt::Mode::CFB->new($name, $cipher_rounds);
# $name ............ uno de 'AES', 'Anubis', 'Blowfish', 'CAST5', 'Camellia', 'DES', 'DES_EDE',
#                    'KASUMI', 'Khazad', 'MULTI2', 'Noekeon', 'RC2', 'RC5', 'RC6',
#                    'SAFERP', 'SAFER_K128', 'SAFER_K64', 'SAFER_SK128', 'SAFER_SK64',
#                    'SEED', 'Skipjack', 'Twofish', 'XTEA', 'IDEA', 'Serpent'
#                    simplemente cualquier <NOMBRE> para el que exista Crypt::Cipher::<NOMBRE>
# $cipher_rounds ... número opcional de rondas para el cifrado dado

encrypt

my $ciphertext = $m->encrypt($plaintext, $key, $iv);

decrypt

my $plaintext = $m->decrypt($ciphertext, $key, $iv);

start_encrypt

$m->start_encrypt($key, $iv);

start_decrypt

$m->start_decrypt($key, $iv);

add

# en modo de cifrado
my $plaintext = $m->add($ciphertext);
# en modo de descifrado
my $ciphertext = $m->add($plaintext);
