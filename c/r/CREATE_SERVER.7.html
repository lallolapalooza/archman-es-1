NOMBRE

CREATE SERVER - definir un nuevo servidor externo

SINOPSIS

CREATE SERVER [ IF NOT EXISTS ] nombre_servidor [ TYPE 'tipo_servidor' ] [ VERSION 'version_servidor' ]
    FOREIGN DATA WRAPPER nombre_fdw
    [ OPTIONS ( opcion 'valor' [, ... ] ) ]

DESCRIPCIÓN

CREATE SERVER define un nuevo servidor externo. El usuario que define el servidor se convierte en su propietario.

Un servidor externo típicamente encapsula la información de conexión que un envoltorio de datos externos (foreign-data wrapper) utiliza para acceder a un recurso de datos externo. La información de conexión específica del usuario puede especificarse mediante mapeos de usuario.

El nombre del servidor debe ser único dentro de la base de datos.

Crear un servidor requiere el privilegio USAGE sobre el envoltorio de datos externos que se está utilizando.

PARÁMETROS

IF NOT EXISTS

No lanzar un error si ya existe un servidor con el mismo nombre. En este caso se emitirá una notificación. Tenga en cuenta que no hay garantía de que el servidor existente se parezca en algo al que se habría creado.

nombre_servidor

El nombre del servidor externo a crear.

tipo_servidor

Tipo de servidor opcional, potencialmente útil para los envoltorios de datos externos.

version_servidor

Versión del servidor opcional, potencialmente útil para los envoltorios de datos externos.

nombre_fdw

El nombre del envoltorio de datos externos que administra el servidor.

OPTIONS ( opcion 'valor' [, ... ] )

Esta cláusula especifica las opciones para el servidor. Las opciones típicamente definen los detalles de conexión del servidor, pero los nombres y valores reales dependen del envoltorio de datos externos del servidor.

NOTAS

Al usar el módulo dblink, el nombre de un servidor externo puede usarse como argumento de la función dblink_connect(3) para indicar los parámetros de conexión. Es necesario tener el privilegio USAGE sobre el servidor externo para poder usarlo de esta manera.

Si el servidor externo soporta el envío de ordenamiento (sort pushdown), es necesario que tenga la misma ordenación que el servidor local.

EJEMPLOS

Crear un servidor llamado myserver que utiliza el envoltorio de datos externos postgres_fdw:

CREATE SERVER myserver FOREIGN DATA WRAPPER postgres_fdw OPTIONS (host 'foo', dbname 'foodb', port '5432');

Ver postgres_fdw para más detalles.

COMPATIBILIDAD

CREATE SERVER cumple con ISO/IEC 9075-9 (SQL/MED).
