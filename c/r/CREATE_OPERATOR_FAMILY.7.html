NOMBRE

CREATE OPERATOR FAMILY - definir una nueva familia de operadores

SINOPSIS

CREATE OPERATOR FAMILY nombre USING método_índice

DESCRIPCIÓN

CREATE OPERATOR FAMILY crea una nueva familia de operadores. Una familia de operadores define una colección de clases de operadores relacionadas, y quizás algunos operadores y funciones de soporte adicionales que son compatibles con estas clases de operadores pero que no son esenciales para el funcionamiento de ninguna clase de índice individual. (Los operadores y funciones que son esenciales para los índices deben agruparse dentro de la clase de operador relevante, en lugar de estar "sueltos" en la familia de operadores. Típicamente, los operadores de un solo tipo de datos se vinculan a clases de operadores, mientras que los operadores de tipos de datos cruzados pueden estar sueltos en una familia de operadores que contiene clases de operadores para ambos tipos de datos).

La nueva familia de operadores está inicialmente vacía. Debe poblarse emitriendo comandos posteriores CREATE OPERATOR CLASS para agregar clases de operadores contenidas y, opcionalmente, comandos ALTER OPERATOR FAMILY para agregar operadores "sueltos" y sus funciones de soporte correspondientes.

Si se proporciona un nombre de esquema, la familia de operadores se crea en el esquema especificado. De lo contrario, se crea en el esquema actual. Dos familias de operadores en el mismo esquema pueden tener el mismo nombre solo si son para diferentes métodos de índice.

El usuario que define una familia de operadores se convierte en su propietario. Actualmente, el usuario que la crea debe ser un superusuario. (Esta restricción se impone porque una definición errónea de la familia de operadores podría confundir o incluso bloquear el servidor).

Consulte la Sección 36.16 para obtener más información.

PARÁMETROS

nombre

El nombre de la familia de operadores a crear. El nombre puede estar calificado por un esquema.

método_índice

El nombre del método de índice para el que es esta familia de operadores.

COMPATIBILIDAD

CREATE OPERATOR FAMILY es una extensión de PostgreSQL. No existe una sentencia CREATE OPERATOR FAMILY en el estándar SQL.

VER TAMBIÉN
