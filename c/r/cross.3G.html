NOMBRE

cross - calcula el producto cruz de dos vectores

DECLARACIÓN

vec3 cross(vec3 x, vec3 y);

dvec3 cross(dvec3 x, dvec3 y);

PARÁMETROS

x

Especifica el primero de los dos vectores

y

Especifica el segundo de los dos vectores

DESCRIPCIÓN

cross devuelve el producto cruz de dos vectores, x e y, es decir, $\begin{pmatrix} { x[1] \times y[2] - y[1] \times x[2] } \\ { x[2] \times y[0] - y[2] \times x[0] } \\ { x[0] \times y[1] - y[0] \times x[1] } \end{pmatrix}$.
