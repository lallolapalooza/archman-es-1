Crypt::OpenSSL::Guess(3) Documentación de Perl contribuida por el usuario Crypt::OpenSSL::Guess(3)

NOMBRE

Crypt::OpenSSL::Guess - Adivinar la ruta de inclusión de OpenSSL

SINOPSIS

use ExtUtils::MakeMaker;
use Crypt::OpenSSL::Guess;
WriteMakefile(
    # ...
    LIBS => [openssl_lib_paths() . ' -lssl -lcrypto'],
    INC  => openssl_inc_paths(), # adivinar la ruta de inclusión o obtener de $ENV{OPENSSL_PREFIX}
);

DESCRIPCIÓN

Crypt::OpenSSL::Guess proporciona utilidades para adivinar la ruta de inclusión de OpenSSL en cualquier plataforma.

A menudo, el OpenSSL de homebrew en macOS causa un problema en la instalación debido a que la ruta de inclusión no se agrega. Algunos módulos de CPAN proporcionan la modificación de la ruta de inclusión con configure-args, pero Carton o Module::CPANfile no admiten el paso de configure-args a cada módulo. Los módulos Crypt::OpenSSL::* deberían usarlo en su Makefile.PL.

Este módulo resuelve la ruta de inclusión mediante la solución alternativa de Net::SSLeay. El código original se toma de "inc/Module/Install/PRIVATE/Net/SSLeay.pm" por Net::SSLeay.

FUNCIONES

openssl_inc_paths()
Esta función devuelve las rutas de inclusión en el formato pasado a CC. Si no se encuentra OpenSSL, se devuelve una cadena vacía. 
openssl_inc_paths(); # en macOS: "-I/usr/local/opt/openssl/include"
openssl_lib_paths()
Esta función devuelve las rutas de biblioteca en el formato pasado a CC. Si no se encuentra OpenSSL, se devuelve una cadena vacía. 
openssl_lib_paths(); # en macOS: "-L/usr/local/opt/openssl/lib"
find_openssl_prefix([$dir])
Esta función devuelve el prefijo de OpenSSL. Si se establece la variable de entorno "OPENSSL_PREFIX", puede sobrescribir el valor devuelto. 
find_openssl_prefix(); # en macOS: "/usr/local/opt/openssl"
find_openssl_exec($prefix)
Esta función devuelve la ruta del ejecutable de OpenSSL. 
find_openssl_exec(); # en macOS: "/usr/local/opt/openssl/bin/openssl"
($major, $minor, $letter) = openssl_version()
Esta función devuelve la versión de OpenSSL como mayor, menor, letra. 
openssl_version(); # ("1.0", "2", "n")
