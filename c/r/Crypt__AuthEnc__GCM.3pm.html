Crypt::AuthEnc::GCM(3) Documentación de Perl contribuida por el usuario Crypt::AuthEnc::GCM(3)

NOMBRE

Crypt::AuthEnc::GCM - Cifrado autenticado en modo GCM

SINOPSIS

### Interfaz OO
use Crypt::AuthEnc::GCM;
# cifrar y autenticar
my $ae = Crypt::AuthEnc::GCM->new("AES", $key, $iv);
$ae->adata_add('datos_adicionales_autenticados1');
$ae->adata_add('datos_adicionales_autenticados2');
my $ct = $ae->encrypt_add('datos1');
$ct .= $ae->encrypt_add('datos2');
$ct .= $ae->encrypt_add('datos3');
my $tag = $ae->encrypt_done();
# descifrar y verificar
my $ae = Crypt::AuthEnc::GCM->new("AES", $key, $iv);
$ae->adata_add('datos_adicionales_autenticados1');
$ae->adata_add('datos_adicionales_autenticados2');
my $pt = $ae->decrypt_add('cifrado1');
$pt .= $ae->decrypt_add('cifrado2');
$pt .= $ae->decrypt_add('cifrado3');
my $tag = $ae->decrypt_done();
die "descifrado fallido" unless $tag eq $tag_esperado;
# o
my $result = $ae->decrypt_done($tag_esperado); # 0 o 1
### Interfaz funcional
use Crypt::AuthEnc::GCM qw(gcm_encrypt_authenticate gcm_decrypt_verify);
my ($cifrado, $tag) = gcm_encrypt_authenticate('AES', $key, $iv, $adata, $texto_plano);
my $texto_plano = gcm_decrypt_verify('AES', $key, $iv, $adata, $cifrado, $tag);

DESCRIPCIÓN

Modo Galois/Contador (GCM) - proporciona cifrado y autenticación.

EXPORTAR

No se exporta nada por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::AuthEnc::GCM qw(gcm_encrypt_authenticate gcm_decrypt_verify);

FUNCIONES

gcm_encrypt_authenticate

my ($cifrado, $tag) = gcm_encrypt_authenticate($cipher, $key, $iv, $adata, $texto_plano);
# $cipher .. 'AES' o el nombre de cualquier otro cifrador con longitud de bloque de 16 bytes
# $key ..... clave AES de longitud adecuada (128/192/256 bits)
# $iv ...... vector de inicialización
# $adata ... datos autenticados adicionales

gcm_decrypt_verify

my $texto_plano = gcm_decrypt_verify($cipher, $key, $iv, $adata, $cifrado, $tag);
# en caso de error devuelve undef

MÉTODOS

new

my $ae = Crypt::AuthEnc::GCM->new($cipher, $key);
# o
my $ae = Crypt::AuthEnc::GCM->new($cipher, $key, $iv);
# $cipher .. 'AES' o el nombre de cualquier otro cifrador
# $key ..... clave de cifrado de longitud adecuada
# $iv ...... vector de inicialización (opcional, puedes establecerlo más tarde a través del método iv_add)

iv_add

Establece el vector de inicialización (IV).

$ae->iv_add($datos_iv); #puede ser llamado múltiples veces

adata_add

Añade datos autenticados adicionales. Se puede llamar después de todas las llamadas a "iv_add" pero antes de la primera llamada a "encrypt_add" o "decrypt_add".

$ae->adata_add($datos_aad); # se puede llamar múltiples veces

encrypt_add

$cifrado = $ae->encrypt_add($datos); # se puede llamar múltiples veces

encrypt_done

$tag = $ae->encrypt_done(); # devuelve el valor de $tag

decrypt_add

$texto_plano = $ae->decrypt_add($cifrado); # se puede llamar múltiples veces

decrypt_done

my $tag = $ae->decrypt_done; # devuelve el valor de $tag
# o
my $result = $ae->decrypt_done($tag); # devuelve 1 (éxito) o 0 (fallo)

reset

$ae->reset;

clone

my $ae_new = $ae->clone;
