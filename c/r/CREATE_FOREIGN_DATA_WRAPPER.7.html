NOMBRE

CREATE_FOREIGN_DATA_WRAPPER - definir un nuevo wrapper de datos externos

SINOPSIS

CREATE FOREIGN DATA WRAPPER nombre
    [ HANDLER función_manejadora | NO HANDLER ]
    [ VALIDATOR función_validadora | NO VALIDATOR ]
    [ OPTIONS ( opción 'valor' [, ... ] ) ]

DESCRIPCIÓN

CREATE FOREIGN DATA WRAPPER crea un nuevo wrapper de datos externos. El usuario que define un wrapper de datos externos se convierte en su propietario.

El nombre del wrapper de datos externos debe ser único dentro de la base de datos.

Solo los superusuarios pueden crear wrappers de datos externos.

PARÁMETROS

nombre

El nombre del wrapper de datos externos a crear.

HANDLER función_manejadora

función_manejadora es el nombre de una función registrada previamente que será llamada para recuperar las funciones de ejecución para tablas externas. La función manejadora no debe tomar argumentos y su tipo de retorno debe ser `fdw_handler`.

Es posible crear un wrapper de datos externos sin una función manejadora, pero las tablas externas que usen dicho wrapper solo podrán ser declaradas, no accedidas.

VALIDATOR función_validadora

función_validadora es el nombre de una función registrada previamente que será llamada para verificar las opciones genéricas dadas al wrapper de datos externos, así como las opciones para servidores externos, mapeos de usuario y tablas externas que usen el wrapper de datos externos. Si no se especifica una función validadora o NO VALIDATOR, las opciones no se verificarán en el momento de la creación. (Los wrappers de datos externos posiblemente ignorarán o rechazarán especificaciones de opciones inválidas en tiempo de ejecución, dependiendo de la implementación.) La función validadora debe tomar dos argumentos: uno de tipo `text[]`, que contendrá el array de opciones tal como se almacenan en los catálogos del sistema, y uno de tipo `oid`, que será el OID del catálogo del sistema que contiene las opciones. El tipo de retorno se ignora; la función debe reportar opciones inválidas usando la función ereport(ERROR).

OPTIONS ( opción 'valor' [, ... ] )

Esta cláusula especifica las opciones para el nuevo wrapper de datos externos. Los nombres de opción permitidos y los valores son específicos para cada wrapper de datos externos y se validan utilizando la función validadora del wrapper de datos externos. Los nombres de opción deben ser únicos.

NOTAS

La funcionalidad de datos externos de PostgreSQL todavía está en desarrollo activo. La optimización de consultas es primitiva (y en gran medida dejada al wrapper también). Por lo tanto, existe un margen considerable para futuras mejoras de rendimiento.

EJEMPLOS

Crear un wrapper de datos externos inútil llamado dummy:

CREATE FOREIGN DATA WRAPPER dummy;

Crear un wrapper de datos externos llamado file con la función manejadora file_fdw_handler:

CREATE FOREIGN DATA WRAPPER file HANDLER file_fdw_handler;

Crear un wrapper de datos externos llamado mywrapper con algunas opciones:

CREATE FOREIGN DATA WRAPPER mywrapper
    OPTIONS (debug 'true');

COMPATIBILIDAD

CREATE FOREIGN DATA WRAPPER se ajusta a ISO/IEC 9075-9 (SQL/MED), con la excepción de que las cláusulas HANDLER y VALIDATOR son extensiones y las cláusulas estándar LIBRARY y LANGUAGE no están implementadas en PostgreSQL.

Sin embargo, tenga en cuenta que la funcionalidad SQL/MED en su conjunto aún no es conforme.
