Crypt__Digest__BLAKE2s_160(3pm)

Paquete: perl-cryptx

Licencias: PerlArtistic, GPL

Crypt::Digest::BLAKE2s_160(3) Documentación de Perl aportada por el usuario Crypt::Digest::BLAKE2s_160(3)

NOMBRE

Crypt::Digest::BLAKE2s_160 - Función hash BLAKE2s [tamaño: 160 bits]

SINOPSIS

### Interfaz funcional:
use Crypt::Digest::BLAKE2s_160 qw( blake2s_160 blake2s_160_hex blake2s_160_b64 blake2s_160_b64u
                             blake2s_160_file blake2s_160_file_hex blake2s_160_file_b64 blake2s_160_file_b64u );
# calcular el resumen a partir de una cadena/búfer
$blake2s_160_raw  = blake2s_160('cadena de datos');
$blake2s_160_hex  = blake2s_160_hex('cadena de datos');
$blake2s_160_b64  = blake2s_160_b64('cadena de datos');
$blake2s_160_b64u = blake2s_160_b64u('cadena de datos');
# calcular el resumen a partir de un archivo
$blake2s_160_raw  = blake2s_160_file('nombrearchivo.dat');
$blake2s_160_hex  = blake2s_160_file_hex('nombrearchivo.dat');
$blake2s_160_b64  = blake2s_160_file_b64('nombrearchivo.dat');
$blake2s_160_b64u = blake2s_160_file_b64u('nombrearchivo.dat');
# calcular el resumen a partir de un manejador de archivo
$blake2s_160_raw  = blake2s_160_file(*MANEJADORDEARCHIVO);
$blake2s_160_hex  = blake2s_160_file_hex(*MANEJADORDEARCHIVO);
$blake2s_160_b64  = blake2s_160_file_b64(*MANEJADORDEARCHIVO);
$blake2s_160_b64u = blake2s_160_file_b64u(*MANEJADORDEARCHIVO);
### Interfaz orientada a objetos:
use Crypt::Digest::BLAKE2s_160;
$d = Crypt::Digest::BLAKE2s_160->new;
$d->add('datos cualesquiera');
$d->addfile('nombrearchivo.dat');
$d->addfile(*MANEJADORDEARCHIVO);
$result_raw  = $d->digest;     # bytes sin procesar
$result_hex  = $d->hexdigest;  # forma hexadecimal
$result_b64  = $d->b64digest;  # forma Base64
$result_b64u = $d->b64udigest; # forma Base64 segura para URL

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de resumen BLAKE2s_160.

EXPORTACIÓN

No se exporta nada de forma predeterminada.

Puede exportar funciones seleccionadas:

use Crypt::Digest::BLAKE2s_160 qw(blake2s_160 blake2s_160_hex blake2s_160_b64 blake2s_160_b64u
                                    blake2s_160_file blake2s_160_file_hex blake2s_160_file_b64 blake2s_160_file_b64u);

O todas a la vez:

use Crypt::Digest::BLAKE2s_160 ':all';

FUNCIONES

blake2s_160

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen BLAKE2s_160 codificado como una cadena binaria.

$blake2s_160_raw = blake2s_160('cadena de datos');
#o
$blake2s_160_raw = blake2s_160('datos cualesquiera', 'más datos', 'aún más datos');

blake2s_160_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen BLAKE2s_160 codificado como una cadena hexadecimal.

$blake2s_160_hex = blake2s_160_hex('cadena de datos');
#o
$blake2s_160_hex = blake2s_160_hex('datos cualesquiera', 'más datos', 'aún más datos');

blake2s_160_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen BLAKE2s_160 codificado como una cadena Base64, con relleno '=' al final.

$blake2s_160_b64 = blake2s_160_b64('cadena de datos');
#o
$blake2s_160_b64 = blake2s_160_b64('datos cualesquiera', 'más datos', 'aún más datos');

blake2s_160_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen BLAKE2s_160 codificado como una cadena Base64 segura para URL (véase RFC 4648 sección 5).

$blake2s_160_b64url = blake2s_160_b64u('cadena de datos');
#o
$blake2s_160_b64url = blake2s_160_b64u('datos cualesquiera', 'más datos', 'aún más datos');

blake2s_160_file

Lee el contenido del archivo (definido por el nombre de archivo o el manejador de archivo) y devuelve su resumen BLAKE2s_160 codificado como una cadena binaria.

$blake2s_160_raw = blake2s_160_file('nombrearchivo.dat');
#o
$blake2s_160_raw = blake2s_160_file(*MANEJADORDEARCHIVO);

blake2s_160_file_hex

Lee el contenido del archivo (definido por el nombre de archivo o el manejador de archivo) y devuelve su resumen BLAKE2s_160 codificado como una cadena hexadecimal.

$blake2s_160_hex = blake2s_160_file_hex('nombrearchivo.dat');
#o
$blake2s_160_hex = blake2s_160_file_hex(*MANEJADORDEARCHIVO);

ADVERTENCIA: Debe asegurarse de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

blake2s_160_file_b64

Lee el contenido del archivo (definido por el nombre de archivo o el manejador de archivo) y devuelve su resumen BLAKE2s_160 codificado como una cadena Base64, con relleno '=' al final.

$blake2s_160_b64 = blake2s_160_file_b64('nombrearchivo.dat');
#o
$blake2s_160_b64 = blake2s_160_file_b64(*MANEJADORDEARCHIVO);

blake2s_160_file_b64u

Lee el contenido del archivo (definido por el nombre de archivo o el manejador de archivo) y devuelve su resumen BLAKE2s_160 codificado como una cadena Base64 segura para URL (véase RFC 4648 sección 5).

$blake2s_160_b64url = blake2s_160_file_b64u('nombrearchivo.dat');
#o
$blake2s_160_b64url = blake2s_160_file_b64u(*MANEJADORDEARCHIVO);

MÉTODOS

La interfaz orientada a objetos proporciona el mismo conjunto de funciones que Crypt::Digest.

new

$d = Crypt::Digest::BLAKE2s_160->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('datos cualesquiera');
#o
$d->add('datos cualesquiera', 'más datos', 'aún más datos');

addfile

$d->addfile('nombrearchivo.dat');
#o
$d->addfile(*MANEJADORDEARCHIVO);

add_bits

$d->add_bits($cadena_de_bits);   # p. ej. $d->add_bits("111100001010");
#o
$d->add_bits($datos, $nbits); # p. ej. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#o
Crypt::Digest::BLAKE2s_160->hashsize();
#o
Crypt::Digest::BLAKE2s_160::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
