NOMBRE

CREATE_EVENT_TRIGGER - define un nuevo disparador de eventos

SINOPSIS

CREATE EVENT TRIGGER nombre
    ON evento
    [ WHEN variable_filtro IN (valor_filtro [, ... ]) [ AND ... ] ]
    EXECUTE { FUNCTION | PROCEDURE } nombre_funcion()

DESCRIPCIÓN

CREATE EVENT TRIGGER crea un nuevo disparador de eventos. Cada vez que ocurre el evento designado y la condición WHEN asociada con el disparador, si existe, se satisface, la función del disparador será ejecutada. Para una introducción general a los disparadores de eventos, ver el Capítulo 38. El usuario que crea un disparador de eventos se convierte en su propietario.

PARÁMETROS

nombre

El nombre que se le dará al nuevo disparador. Este nombre debe ser único dentro de la base de datos.

evento

El nombre del evento que activa una llamada a la función dada. Ver la Sección 38.1 para más información sobre nombres de eventos.

variable_filtro

El nombre de una variable utilizada para filtrar eventos. Esto hace posible restringir la activación del disparador a un subconjunto de los casos en los que es compatible. Actualmente, la única variable_filtro compatible es TAG.

valor_filtro

Una lista de valores para la variable_filtro asociada para los cuales el disparador se activará. Para TAG, esto significa una lista de etiquetas de comandos (por ejemplo, 'DROP FUNCTION').

nombre_funcion

Una función suministrada por el usuario que se declara como que no toma argumentos y devuelve el tipo event_trigger.

En la sintaxis de CREATE EVENT TRIGGER, las palabras clave FUNCTION y PROCEDURE son equivalentes, pero la función referenciada debe ser en cualquier caso una función, no un procedimiento. El uso de la palabra clave PROCEDURE aquí es histórico y está obsoleto.

NOTAS

Solo los superusuarios pueden crear disparadores de eventos.

Los disparadores de eventos están deshabilitados en modo mono-usuario (ver postgres(1)) así como cuando event_triggers está establecido en false. Si un disparador de eventos erróneo deshabilita la base de datos tanto que ni siquiera puedes eliminar el disparador, reinicia con event_triggers establecido en false para deshabilitar temporalmente los disparadores de eventos, o en modo mono-usuario, y podrás hacerlo.

EJEMPLOS

Prohibir la ejecución de cualquier comando DDL:

CREATE OR REPLACE FUNCTION abort_any_command()
  RETURNS event_trigger
 LANGUAGE plpgsql
  AS $$
BEGIN
  RAISE EXCEPTION 'command % is disabled', tg_tag;
END;
$$;
CREATE EVENT TRIGGER abort_ddl ON ddl_command_start
   EXECUTE FUNCTION abort_any_command();

COMPATIBILIDAD

No existe una sentencia CREATE EVENT TRIGGER en el estándar SQL.

VER TAMBIÉN

ALTER EVENT TRIGGER (ALTER_EVENT_TRIGGER(7)), DROP EVENT TRIGGER (DROP_EVENT_TRIGGER(7)), CREATE FUNCTION (CREATE_FUNCTION(7))
