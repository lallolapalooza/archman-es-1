CREATE TEXT SEARCH CONFIGURATION(7) Documentación de PostgreSQL 18.1 CREATE TEXT SEARCH CONFIGURATION(7)

NOMBRE

CREATE_TEXT_SEARCH_CONFIGURATION - define una nueva configuración de búsqueda de texto

SINOPSIS

CREATE TEXT SEARCH CONFIGURATION nombre (
    PARSER = nombre_parser |
    COPY = configuracion_origen
)

DESCRIPCIÓN

CREATE TEXT SEARCH CONFIGURATION crea una nueva configuración de búsqueda de texto. Una configuración de búsqueda de texto especifica un analizador de búsqueda de texto que puede dividir una cadena en tokens, además de diccionarios que pueden utilizarse para determinar qué tokens son de interés para la búsqueda.

Si solo se especifica el analizador, la nueva configuración de búsqueda de texto no tendrá inicialmente ninguna correspondencia entre tipos de tokens y diccionarios, por lo que ignorará todas las palabras. Los comandos posteriores de ALTER TEXT SEARCH CONFIGURATION deben utilizarse para crear correspondencias y hacer que la configuración sea útil. Alternativamente, se puede copiar una configuración de búsqueda de texto existente.

Si se proporciona un nombre de esquema, la configuración de búsqueda de texto se creará en el esquema especificado. De lo contrario, se creará en el esquema actual.

El usuario que define una configuración de búsqueda de texto se convierte en su propietario.

Consulte el Capítulo 12 para obtener más información.

PARÁMETROS

nombre

El nombre de la configuración de búsqueda de texto que se va a crear. El nombre puede estar cualificado con un esquema.

nombre_parser

El nombre del analizador de búsqueda de texto que se utilizará para esta configuración.

configuracion_origen

El nombre de una configuración de búsqueda de texto existente que se va a copiar.

NOTAS

Las opciones PARSER y COPY son mutuamente excluyentes, ya que al copiar una configuración existente, su selección de analizador también se copia.

COMPATIBILIDAD

No existe una sentencia CREATE TEXT SEARCH CONFIGURATION en el estándar SQL.

VER TAMBIÉN

ALTER TEXT SEARCH CONFIGURATION (ALTER_TEXT_SEARCH_CONFIGURATION(7)), DROP TEXT SEARCH CONFIGURATION (DROP_TEXT_SEARCH_CONFIGURATION(7))
