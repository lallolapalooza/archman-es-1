Crypt::PRNG(3) Documentación de Perl aportada por el usuario Crypt::PRNG(3)

NOMBRE

Crypt::PRNG - Generador de números aleatorios criptográficamente seguro

SINOPSIS

### Interfaz funcional:
use Crypt::PRNG qw(random_bytes random_bytes_hex random_bytes_b64 random_bytes_b64u
                   random_string random_string_from rand irand);
$octets = random_bytes(45);
$hex_string = random_bytes_hex(45);
$base64_string = random_bytes_b64(45);
$base64url_string = random_bytes_b64u(45);
$alphanumeric_string = random_string(30);
$string = random_string_from('ACGT', 64);
$floating_point_number_0_to_1 = rand;
$floating_point_number_0_to_88 = rand(88);
$unsigned_32bit_int = irand;
### Interfaz orientada a objetos:
use Crypt::PRNG;
$prng = Crypt::PRNG->new;  # por defecto ChaCha20
#o
$prng = Crypt::PRNG->new("RC4");
#o
$prng = Crypt::PRNG->new("RC4", "algunos datos usados para sembrar el PRNG");
$octets = $prng->bytes(45);
$hex_string = $prng->bytes_hex(45);
$base64_string = $prng->bytes_b64(45);
$base64url_string = $prng->bytes_b64u(45);
$alphanumeric_string = $prng->string(30);
$string = $prng->string_from('ACGT', 64);
$floating_point_number_0_to_1 = $prng->double;
$floating_point_number_0_to_88 = $prng->double(88);
$unsigned_32bit_int = $prng->int32;

DESCRIPCIÓN

Proporciona una interfaz para el generador de números pseudoaleatorios basado en ChaCha20 (seguro para hilos y para bifurcaciones).

FUNCIONES

random_bytes

$octets = random_bytes($length);

Devuelve $length octetos aleatorios.

random_bytes_hex

$hex_string = random_bytes_hex($length);

Devuelve $length octetos aleatorios codificados como cadena hexadecimal.

random_bytes_b64

$base64_string = random_bytes_b64($length);

Devuelve $length octetos aleatorios codificados en Base64.

random_bytes_b64u

$base64url_string = random_bytes_b64u($length);

Devuelve $length octetos aleatorios codificados en Base64 URL Safe (RFC 4648 sección 5).

random_string_from

$string = random_string_from($range, $length);
#p.ej.
$string = random_string_from("ABCD", 10);

Devuelve una cadena aleatoria compuesta por $length caracteres elegidos al azar de la $range cadena.

random_string

$alphanumeric_string = random_string($length);
#o
$alphanumeric_string = random_string;  # longitud por defecto = 20

Similar a random_string_from, solo que $range está fijado a 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789'.

rand

$n = rand;
#o
$n = rand($limit);

Devuelve un número aleatorio de punto flotante del rango "[0,1)" (si se llama sin parámetro) o "[0,$limit)".

irand

$i = irand;

Devuelve un entero aleatorio sin signo de 32 bits - rango "0 .. 0xFFFFFFFF".

MÉTODOS

new

$prng = Crypt::PRNG->new;  # por defecto ChaCha20
#o
$prng = Crypt::PRNG->new($alg);
#o
$prng = Crypt::PRNG->new($alg, $seed);
# $alg  ... nombre del algoritmo 'ChaCha20' (POR DEFECTO), 'Fortuna', 'RC4', 'Sober128' o 'Yarrow'
# $seed ... se usará como entropía inicial para sembrar el PRNG

Si $seed no se especifica, el PRNG se siembra automáticamente con 32 bytes de datos aleatorios tomados de "/dev/random" (UNIX) o "CryptGenRandom" (Win32)

add_entropy

$prng->add_entropy($random_data);
#o
$prng->add_entropy();

Si se llama sin parámetro, usa 32 bytes de datos aleatorios tomados de "/dev/random" (UNIX) o "CryptGenRandom" (Win32).

ADVERTENCIA: probablemente no necesitas esta función en absoluto, ya que el módulo realiza una siembra automática en la inicialización, así como un resiembra después de la bifurcación y la creación de hilos.
