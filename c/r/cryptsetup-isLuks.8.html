CRYPTSETUP-ISLUKS(8) Comandos de Mantenimiento CRYPTSETUP-ISLUKS(8)

NOMBRE

cryptsetup-isLuks - comprueba si un dispositivo es un dispositivo LUKS

SINOPSIS

cryptsetup isLuks [<opciones>] <dispositivo>

DESCRIPCIÓN

Devuelve verdadero si <dispositivo> es un dispositivo LUKS, falso en caso contrario.

Utilice la opción -v para obtener retroalimentación legible por humanos. "Comando exitoso." significa que el dispositivo es un dispositivo LUKS.

Especificando --type, puede consultar una versión específica de LUKS.

<opciones> pueden ser [--header, --type, --disable-locks].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si la opción --verify-passphrase no está especificada, esta opción también desactiva la verificación de la frase de contraseña.

--debug o --debug-json

Ejecuta en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre van precedidas por #.

Si se utiliza --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--disable-locks

Desactiva la protección de bloqueo para metadatos en disco. Esta opción solo es válida para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No utilice esta opción a menos que ejecute cryptsetup en un entorno restringido donde el bloqueo sea imposible de realizar (donde el directorio /run no se pueda usar).

--header <dispositivo o archivo que almacena la cabecera LUKS>

Utiliza un dispositivo o archivo de metadatos separado (detached) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para comandos que cambian la cabecera LUKS (por ejemplo, luksAddKey), especifique el dispositivo o archivo con la cabecera LUKS directamente como el dispositivo LUKS.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--type tipo

Especifica el tipo de dispositivo requerido, para más información, lea la sección ACCIONES BÁSICAS en cryptsetup(8).

--usage

Muestra una ayuda breve de opciones.

--verbose, -v

Imprime más información sobre la ejecución del comando.

--version, -V

Muestra la versión del programa.

REPORTAR ERRORES

Reporte errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de incidencias del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Por favor, adjunte la salida del comando fallido con la opción --debug añadida.
