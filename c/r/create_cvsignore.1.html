NOMBRE

create_cvsignore - Crear un archivo .cvsignore preliminar en el directorio actual

SINOPSIS

createcvsignore

DESCRIPCIÓN

create_cvsignore se utiliza para crear un archivo .cvsignore preliminar en el directorio actual. Lo hace basándose en cierto contenido que encuentra en Makefile.am

No se eliminarán líneas de ningún archivo .cvsignore existente. Si aún no existe un archivo .cvsignore, se añadirá al repositorio de cvs.

Tenga en cuenta que debe tener un archivo Makefile.am en el directorio actual para que esta herramienta funcione.

Esta utilidad forma parte del Kit de Desarrollo de Software de KDE.
