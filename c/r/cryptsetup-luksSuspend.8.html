CRYPTSETUP-LUKSSUSPEND(8) Comandos de Mantenimiento CRYPTSETUP-LUKSSUSPEND(8)

NOMBRE

cryptsetup-luksSuspend - suspende un dispositivo activo y borra la clave

SINOPSIS

cryptsetup luksSuspend [<opciones>] <nombre>

DESCRIPCIÓN

Suspende un dispositivo activo (todas las operaciones de E/S se bloquearán y los accesos al dispositivo esperarán indefinidamente) y borra la clave de cifrado de la memoria del kernel.

Mientras que la operación luksSuspend borra las claves de cifrado de la memoria, no elimina posibles datos en texto plano en varias cachés o metadatos dentro del kernel para los sistemas de archivos montados.

Después de esta operación, debes usar luksResume para reinstaurar la clave de cifrado y desbloquear el dispositivo, o close para eliminar el dispositivo mapeado.

ADVERTENCIA: Para evitar un interbloqueo, nunca suspendas el dispositivo en el que reside el binario cryptsetup.

<opciones> pueden ser [--header, --disable-locks].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úsalo con cuidado!

Si la opción --verify-passphrase no se especifica, esta opción también desactiva la verificación de la contraseña.

--debug o --debug-json

Ejecuta en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre van precedidas por #.

Si se utiliza --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--disable-locks

Desactiva la protección de bloqueo para los metadatos en disco. Esta opción solo es válida para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No utilices esta opción a menos que ejecutes cryptsetup en un entorno restringido donde sea imposible realizar el bloqueo (donde el directorio /run no se pueda usar).

--header <dispositivo o archivo que almacena la cabecera LUKS>

Utiliza un dispositivo o archivo de metadatos separado (detached) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para comandos que modifican la cabecera LUKS (por ejemplo, luksAddKey), especifica el dispositivo o archivo con la cabecera LUKS directamente como el dispositivo LUKS.

--help, -?

Muestra el texto de ayuda y los parámetros por defecto.

--usage

Muestra la ayuda de opciones cortas.

--version, -V

Muestra la versión del programa.

REPORTE DE ERRORES

Reporta errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de Issues del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Por favor, adjunta la salida del comando fallido con la opción --debug añadida.
