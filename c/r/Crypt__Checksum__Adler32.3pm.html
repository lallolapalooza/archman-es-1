NOMBRE

Crypt::Checksum::Adler32 - Calcula el checksum Adler32

SINOPSIS

### Interfaz funcional:
use Crypt::Checksum::Adler32 ':all';
# calcula el checksum Adler32 a partir de una cadena/buffer
$checksum_raw  = adler32_data($data);
$checksum_hex  = adler32_data_hex($data);
$checksum_int  = adler32_data_int($data);
# calcula el checksum Adler32 desde un archivo
$checksum_raw  = adler32_file('nombre_archivo.dat');
$checksum_hex  = adler32_file_hex('nombre_archivo.dat');
$checksum_int  = adler32_file_int('nombre_archivo.dat');
# calcula el checksum Adler32 desde un manejador de archivo
$checksum_raw  = adler32_file(*MANEJADOR_ARCHIVO);
$checksum_hex  = adler32_file_hex(*MANEJADOR_ARCHIVO);
$checksum_int  = adler32_file_int(*MANEJADOR_ARCHIVO);
### Interfaz OO:
use Crypt::Checksum::Adler32;
$d = Crypt::Checksum::Adler32->new;
$d->add('cualquier dato');
$d->add('más datos');
$d->addfile('nombre_archivo.dat');
$d->addfile(*MANEJADOR_ARCHIVO);
$checksum_raw  = $d->digest;     # bytes crudos
$checksum_hex  = $d->hexdigest;  # formato hexadecimal
$checksum_int  = $d->intdigest;  # entero sin signo de 32 bits

DESCRIPCIÓN

Cálculo de checksums Adler32.

Actualizado: v0.057

EXPORTAR

Nada se exporta por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::Checksum::Adler32 qw(adler32_data adler32_data_hex adler32_data_int adler32_file adler32_file_hex adler32_file_int);

O todas a la vez:

use Crypt::Checksum::Adler32 ':all';

FUNCIONES

adler32_data

Devuelve el checksum como octetos crudos.

$checksum_raw = adler32_data('cadena de datos');
#o
$checksum_raw = adler32_data('cualquier dato', 'más datos', 'incluso más datos');

adler32_data_hex

Devuelve el checksum como una cadena hexadecimal.

$checksum_hex = adler32_data_hex('cadena de datos');
#o
$checksum_hex = adler32_data_hex('cualquier dato', 'más datos', 'incluso más datos');

adler32_data_int

Devuelve el checksum como un entero sin signo de 32 bits.

$checksum_int = adler32_data_int('cadena de datos');
#o
$checksum_int = adler32_data_int('cualquier dato', 'más datos', 'incluso más datos');

adler32_file

Devuelve el checksum como octetos crudos.

$checksum_raw = adler32_file('nombre_archivo.dat');
#o
$checksum_raw = adler32_file(*MANEJADOR_ARCHIVO);

adler32_file_hex

Devuelve el checksum como una cadena hexadecimal.

$checksum_hex = adler32_file_hex('nombre_archivo.dat');
#o
$checksum_hex = adler32_file_hex(*MANEJADOR_ARCHIVO);

adler32_file_int

Devuelve el checksum como un entero sin signo de 32 bits.

$checksum_int = adler32_file_int('nombre_archivo.dat');
#o
$checksum_int = adler32_file_int(*MANEJADOR_ARCHIVO);

MÉTODOS

new

Constructor, devuelve una referencia al objeto checksum.

$d = Crypt::Checksum::Adler32->new;

clone

Crea una copia del estado del objeto checksum y devuelve una referencia a la copia.

$d->clone();

reset

Reinicializa el estado del objeto checksum y devuelve una referencia al objeto checksum.

$d->reset();

add

Todos los argumentos se añaden al mensaje para el que calculamos el checksum. El valor de retorno es el propio objeto checksum.

$d->add('cualquier dato');
#o
$d->add('cualquier dato', 'más datos', 'incluso más datos');

addfile

El contenido del archivo (o manejador de archivo) se añade al mensaje para el que calculamos el checksum. El valor de retorno es el propio objeto checksum.

$d->addfile('nombre_archivo.dat');
#o
$d->addfile(*MANEJADOR_ARCHIVO);

¡CUIDADO!: Debes asegurarte de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

digest

Devuelve el checksum binario (bytes crudos).

$result_raw = $d->digest();

hexdigest

Devuelve el checksum codificado como una cadena hexadecimal.

$result_hex = $d->hexdigest();

intdigest

Devuelve el checksum codificado como un entero sin signo de 32 bits.

$result_int = $d->intdigest();
