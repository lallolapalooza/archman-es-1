Los tipos de exdata son identificados por un índice , un entero garantizado para ser único dentro de las estructuras durante la vida útil del programa. Las aplicaciones que utilizan exdata típicamente llaman a CRYPTO_get_ex_new_index al inicio, y almacenan el resultado en una variable global, o escriben una función envolvente para proporcionar evaluación perezosa. Para manipular exdata de manera transparente, se deben proporcionar tres funciones de retorno de llamada. La semántica de esas funciones de retorno de llamada se describe a continuación. Al copiar o liberar objetos con exdata, las funciones de retorno de llamada se llaman en orden creciente de su índice valor. Para establecer o obtener el exdata en un objeto, se debe usar la rutina específica del tipo correspondiente. Esto se debe a que la estructura que lo contiene es opaca y el campo CRYPTO_EX_DATA no es accesible. En ambas API, el parámetro idx debe ser un valor de índice ya creado. Al establecer exdata, el puntero especificado con un índice particular se guarda, y se devuelve en una llamada posterior de "obtener". Si la aplicación va a liberar los datos, debe asegurarse de establecer un NULL valor en el índice, para evitar probablemente bloqueos por doble

La función CRYPTO_free_ex_data se usa para liberar todo el exdata adjunto a una estructura. Se debe usar la rutina específica del tipo correspondiente.
