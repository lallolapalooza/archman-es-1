Crypt::Digest::Keccak256(3) Documentación de Perl aportada por el usuario Crypt::Digest::Keccak256(3)

NOMBRE

Crypt::Digest::Keccak256 - Función de hash Keccak-256 [tamaño: 256 bits]

SINOPSIS

### Interfaz funcional:
use Crypt::Digest::Keccak256 qw( keccak256 keccak256_hex keccak256_b64 keccak256_b64u
                             keccak256_file keccak256_file_hex keccak256_file_b64 keccak256_file_b64u );
# calcular el resumen a partir de una cadena/búfer
$keccak256_raw  = keccak256('cadena de datos');
$keccak256_hex  = keccak256_hex('cadena de datos');
$keccak256_b64  = keccak256_b64('cadena de datos');
$keccak256_b64u = keccak256_b64u('cadena de datos');
# calcular el resumen a partir de un archivo
$keccak256_raw  = keccak256_file('nombre_de_archivo.dat');
$keccak256_hex  = keccak256_file_hex('nombre_de_archivo.dat');
$keccak256_b64  = keccak256_file_b64('nombre_de_archivo.dat');
$keccak256_b64u = keccak256_file_b64u('nombre_de_archivo.dat');
# calcular el resumen a partir de un manejador de archivo
$keccak256_raw  = keccak256_file(*MANEJADOR_DE_ARCHIVO);
$keccak256_hex  = keccak256_file_hex(*MANEJADOR_DE_ARCHIVO);
$keccak256_b64  = keccak256_file_b64(*MANEJADOR_DE_ARCHIVO);
$keccak256_b64u = keccak256_file_b64u(*MANEJADOR_DE_ARCHIVO);
### Interfaz orientada a objetos:
use Crypt::Digest::Keccak256;
$d = Crypt::Digest::Keccak256->new;
$d->add('cualquier dato');
$d->addfile('nombre_de_archivo.dat');
$d->addfile(*MANEJADOR_DE_ARCHIVO);
$result_raw  = $d->digest;     # bytes crudos
$result_hex  = $d->hexdigest;  # forma hexadecimal
$result_b64  = $d->b64digest;  # forma Base64
$result_b64u = $d->b64udigest; # forma Base64 segura para URL

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de resumen Keccak256.

EXPORTACIÓN

No se exporta nada por defecto.

Puede exportar funciones seleccionadas:

use Crypt::Digest::Keccak256 qw(keccak256 keccak256_hex keccak256_b64 keccak256_b64u
                                    keccak256_file keccak256_file_hex keccak256_file_b64 keccak256_file_b64u);

O todas a la vez:

use Crypt::Digest::Keccak256 ':all';

FUNCIONES

keccak256

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen Keccak256 codificado como una cadena binaria.

$keccak256_raw = keccak256('cadena de datos');
#o
$keccak256_raw = keccak256('cualquier dato', 'más datos', 'aún más datos');

keccak256_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen Keccak256 codificado como una cadena hexadecimal.

$keccak256_hex = keccak256_hex('cadena de datos');
#o
$keccak256_hex = keccak256_hex('cualquier dato', 'más datos', 'aún más datos');

keccak256_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen Keccak256 codificado como una cadena Base64, con relleno '=' al final.

$keccak256_b64 = keccak256_b64('cadena de datos');
#o
$keccak256_b64 = keccak256_b64('cualquier dato', 'más datos', 'aún más datos');

keccak256_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen Keccak256 codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$keccak256_b64url = keccak256_b64u('cadena de datos');
#o
$keccak256_b64url = keccak256_b64u('cualquier dato', 'más datos', 'aún más datos');

keccak256_file

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen Keccak256 codificado como una cadena binaria.

$keccak256_raw = keccak256_file('nombre_de_archivo.dat');
#o
$keccak256_raw = keccak256_file(*MANEJADOR_DE_ARCHIVO);

keccak256_file_hex

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen Keccak256 codificado como una cadena hexadecimal.

$keccak256_hex = keccak256_file_hex('nombre_de_archivo.dat');
#o
$keccak256_hex = keccak256_file_hex(*MANEJADOR_DE_ARCHIVO);

ADVERTENCIA: Debe asegurarse de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

keccak256_file_b64

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen Keccak256 codificado como una cadena Base64, con relleno '=' al final.

$keccak256_b64 = keccak256_file_b64('nombre_de_archivo.dat');
#o
$keccak256_b64 = keccak256_file_b64(*MANEJADOR_DE_ARCHIVO);

keccak256_file_b64u

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen Keccak256 codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$keccak256_b64url = keccak256_file_b64u('nombre_de_archivo.dat');
#o
$keccak256_b64url = keccak256_file_b64u(*MANEJADOR_DE_ARCHIVO);

MÉTODOS

La interfaz orientada a objetos proporciona el mismo conjunto de funciones que Crypt::Digest.

new

$d = Crypt::Digest::Keccak256->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('cualquier dato');
#o
$d->add('cualquier dato', 'más datos', 'aún más datos');

addfile

$d->addfile('nombre_de_archivo.dat');
#o
$d->addfile(*MANEJADOR_DE_ARCHIVO);

add_bits

$d->add_bits($bit_string);   # p. ej. $d->add_bits("111100001010");
#o
$d->add_bits($data, $nbits); # p. ej. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#o
Crypt::Digest::Keccak256->hashsize();
#o
Crypt::Digest::Keccak256::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
