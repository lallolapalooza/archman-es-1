Crypt__Digest__SHA512(3pm)

Paquete: perl-cryptx

Licencias: PerlArtistic, GPL

Crypt::Digest::SHA512(3) Documentación de Perl aportada por el usuario Crypt::Digest::SHA512(3)

NOMBRE

Crypt::Digest::SHA512 - Función hash SHA-512 [tamaño: 512 bits]

SINOPSIS

### Interfaz funcional:
use Crypt::Digest::SHA512 qw( sha512 sha512_hex sha512_b64 sha512_b64u
                             sha512_file sha512_file_hex sha512_file_b64 sha512_file_b64u );
# calcular el resumen a partir de una cadena/búfer
$sha512_raw  = sha512('cadena de datos');
$sha512_hex  = sha512_hex('cadena de datos');
$sha512_b64  = sha512_b64('cadena de datos');
$sha512_b64u = sha512_b64u('cadena de datos');
# calcular el resumen a partir de un archivo
$sha512_raw  = sha512_file('nombre_archivo.dat');
$sha512_hex  = sha512_file_hex('nombre_archivo.dat');
$sha512_b64  = sha512_file_b64('nombre_archivo.dat');
$sha512_b64u = sha512_file_b64u('nombre_archivo.dat');
# calcular el resumen a partir de un manejador de archivo
$sha512_raw  = sha512_file(*FILEHANDLE);
$sha512_hex  = sha512_file_hex(*FILEHANDLE);
$sha512_b64  = sha512_file_b64(*FILEHANDLE);
$sha512_b64u = sha512_file_b64u(*FILEHANDLE);
### Interfaz orientada a objetos:
use Crypt::Digest::SHA512;
$d = Crypt::Digest::SHA512->new;
$d->add('cualquier dato');
$d->addfile('nombre_archivo.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->digest;     # bytes crudos
$result_hex  = $d->hexdigest;  # forma hexadecimal
$result_b64  = $d->b64digest;  # forma Base64
$result_b64u = $d->b64udigest; # forma Base64 segura para URL

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de resumen SHA512.

EXPORTACIÓN

No se exporta nada de forma predeterminada.

Puede exportar funciones seleccionadas:

use Crypt::Digest::SHA512 qw(sha512 sha512_hex sha512_b64 sha512_b64u
                                    sha512_file sha512_file_hex sha512_file_b64 sha512_file_b64u);

O todas a la vez:

use Crypt::Digest::SHA512 ':all';

FUNCIONES

sha512

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen SHA512 codificado como una cadena binaria.

$sha512_raw = sha512('cadena de datos');
#o
$sha512_raw = sha512('cualquier dato', 'más datos', 'aún más datos');

sha512_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen SHA512 codificado como una cadena hexadecimal.

$sha512_hex = sha512_hex('cadena de datos');
#o
$sha512_hex = sha512_hex('cualquier dato', 'más datos', 'aún más datos');

sha512_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen SHA512 codificado como una cadena Base64, con relleno '=' al final.

$sha512_b64 = sha512_b64('cadena de datos');
#o
$sha512_b64 = sha512_b64('cualquier dato', 'más datos', 'aún más datos');

sha512_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen SHA512 codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$sha512_b64url = sha512_b64u('cadena de datos');
#o
$sha512_b64url = sha512_b64u('cualquier dato', 'más datos', 'aún más datos');

sha512_file

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen SHA512 codificado como una cadena binaria.

$sha512_raw = sha512_file('nombre_archivo.dat');
#o
$sha512_raw = sha512_file(*FILEHANDLE);

sha512_file_hex

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen SHA512 codificado como una cadena hexadecimal.

$sha512_hex = sha512_file_hex('nombre_archivo.dat');
#o
$sha512_hex = sha512_file_hex(*FILEHANDLE);

ADVERTENCIA: Debe asegurarse de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

sha512_file_b64

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen SHA512 codificado como una cadena Base64, con relleno '=' al final.

$sha512_b64 = sha512_file_b64('nombre_archivo.dat');
#o
$sha512_b64 = sha512_file_b64(*FILEHANDLE);

sha512_file_b64u

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen SHA512 codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$sha512_b64url = sha512_file_b64u('nombre_archivo.dat');
#o
$sha512_b64url = sha512_file_b64u(*FILEHANDLE);

MÉTODOS

La interfaz orientada a objetos proporciona el mismo conjunto de funciones que Crypt::Digest.

new

$d = Crypt::Digest::SHA512->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('cualquier dato');
#o
$d->add('cualquier dato', 'más datos', 'aún más datos');

addfile

$d->addfile('nombre_archivo.dat');
#o
$d->addfile(*FILEHANDLE);

add_bits

$d->add_bits($bit_string);   # p. ej. $d->add_bits("111100001010");
#o
$d->add_bits($data, $nbits); # p. ej. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#o
Crypt::Digest::SHA512->hashsize();
#o
Crypt::Digest::SHA512::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
