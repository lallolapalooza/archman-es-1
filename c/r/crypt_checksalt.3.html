CRYPT_CHECKSALT(3) Manual de funciones de biblioteca CRYPT_CHECKSALT(3)

NOMBRE

crypt_checksalt — valida una cadena de configuración de crypt

BIBLIOTECA

Biblioteca Crypt (libcrypt, -lcrypt)

SINOPSIS

#include <crypt.h>

int
crypt_checksalt(const char *setting);

DESCRIPCIÓN

crypt_checksalt comprueba la cadena setting contra la configuración del sistema e informa si el método de hash y los parámetros que especifica son aceptables. Está destinado a ser utilizado por programas como login(1) para determinar si la contraseña del usuario debe volver a hashearse utilizando el método de hash preferido actualmente.

VALORES DE RETORNO

El valor de retorno es 0 si no hay ningún problema con esta configuración. De lo contrario, es una de las siguientes constantes:

CRYPT_SALT_OK
setting es una cadena de configuración completamente correcta. Esta constante está garantizada que sea igual a 0.
CRYPT_SALT_INVALID
setting no es una cadena de configuración válida; especifica un método de hash que no es conocido por esta versión de libxcrypt, o especifica parámetros inválidos para el método.
CRYPT_SALT_METHOD_DISABLED (Aún no implementado)
setting especifica un método de hash que ya no se permite utilizar en absoluto; crypt fallará si se le pasa esta setting. Se requerirá intervención manual para reactivar la cuenta del usuario.
CRYPT_SALT_METHOD_LEGACY
setting especifica un método de hash que ya no se considera lo suficientemente robusto para usar con contraseñas nuevas. crypt seguirá autenticando una contraseña contra esta configuración, pero si la autenticación tiene éxito, la contraseña debería volver a hashearse utilizando el método preferido actualmente.
CRYPT_SALT_TOO_CHEAP (Aún no implementado)
setting especifica parámetros de coste que se consideran demasiado baratos para usar con contraseñas nuevas. crypt seguirá autenticando una contraseña contra esta configuración, pero si la autenticación tiene éxito, la contraseña debería volver a hashearse utilizando el método preferido actualmente.

MACROS DE PRUEBA DE CARACTERÍSTICAS

<crypt.h> definirá la macro CRYPT_CHECKSALT_AVAILABLE si crypt_checksalt está disponible en la versión actual de libxcrypt.

ERRORES

Dado que la configuración completa aún no está implementada, la implementación actual solo devolverá CRYPT_SALT_OK (0) o CRYPT_SALT_INVALID cuando se invoque.

NOTAS DE PORTABILIDAD

La función crypt_checksalt no forma parte de ningún estándar. Se añadió a libxcrypt en la versión 4.3.0.
