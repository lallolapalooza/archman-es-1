NOMBRE

Crypt::OpenSSL::Random - Acceso al generador de números pseudoaleatorios de OpenSSL/LibreSSL

SINOPSIS

use Crypt::OpenSSL::Random;
Crypt::OpenSSL::Random::random_seed($buenos_datos_aleatorios);
Crypt::OpenSSL::Random::random_egd("/tmp/entropia");
Crypt::OpenSSL::Random::random_status() or
  die "No se puede sembrar suficientemente el generador de números aleatorios".
my $diez_bytes_aleatorios_buenos = Crypt::OpenSSL::Random::random_bytes(10);
my $diez_bytes_aleatorios_ok = Crypt::OpenSSL::Random::random_pseudo_bytes(10);

DESCRIPCIÓN

"Crypt::OpenSSL::Random" proporciona la capacidad de sembrar y consultar los generadores de números pseudoaleatorios de la biblioteca OpenSSL y LibreSSL.

Nota: En LibreSSL random_egd() no está definido.

EXPORTAR

Ninguno por defecto.

MÉTODOS ESTÁTICOS

random_bytes (IV num_bytes)
Esta función devuelve un número especificado de bytes pseudoaleatorios criptográficamente fuertes del PRNG. Si el PRNG no ha sido sembrado con suficiente aleatoriedad para garantizar una secuencia de bytes impredecible, entonces se devuelve un valor falso.
random_pseudo_bytes (IV num_bytes)
Esta función, es similar a "random_bytes", pero la secuencia de bytes resultante no es necesariamente impredecible. Se puede usar para fines no criptográficos y para ciertos fines en protocolos criptográficos, pero generalmente no para la generación de claves, etc.
random_seed (PV cadena_bytes_aleatorios)
Esta función siembra el PRNG con una cadena de bytes proporcionada. Devuelve verdadero si el PRNG tiene suficiente siembra. Nota: ¡llamar a esta función con bytes no aleatorios tiene un valor limitado en el mejor de los casos!
random_egd (PV cadena_egd)
Esta función siembra el PRNG con datos del demonio de recolección de entropía especificado. Devuelve el número de bytes leídos del demonio en caso de éxito, o -1 si no se leyeron suficientes bytes, o si la conexión con el demonio falló.

"libressl" considera esta función insegura, por lo que con libressl o un openssl sin egd esta función no existe.

random_status ()
Esta función devuelve 1 si el PRNG tiene suficiente siembra. o 0 si no.

ERRORES

Debido al funcionamiento interno de la biblioteca aleatoria de OpenSSL, el generador de números pseudoaleatorios (PRNG) al que se accede mediante Crypt::OpenSSL::Random será diferente del que se accede mediante cualquier otro módulo perl. Por lo tanto, para usar un módulo como Crypt::OpenSSL::Random, deberá sembrar el PRNG utilizado allí a partir de uno utilizado aquí. Sin embargo, esta clase sigue siendo ventajosa, ya que centraliza otros métodos, como "random_egd", en un solo lugar.
