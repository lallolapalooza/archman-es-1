Crypt::Cipher(3) Documentación de Perl aportada por el usuario Crypt::Cipher(3)

NOMBRE

Crypt::Cipher - Interfaz genérica a funciones de cifrado

SINOPSIS

#### ejemplo 1 (cifrado de un solo bloque)
use Crypt::Cipher;
my $key = '...'; # la longitud debe ser un tamaño de clave válido para este cifrado
my $c = Crypt::Cipher->new('AES', $key);
my $blocksize  = $c->blocksize;
my $ciphertext = $c->encrypt('bloque de texto plano'); # cifra 1 bloque
my $plaintext  = $c->decrypt($ciphertext);         # descifra 1 bloque
### ejemplo 2 (usando modo CBC)
use Crypt::Mode::CBC;
my $key = '...'; # la longitud debe ser un tamaño de clave válido para este cifrado
my $iv = '...';  # 16 bytes
my $cbc = Crypt::Mode::CBC->new('AES');
my $ciphertext = $cbc->encrypt("datos secretos", $key, $iv);
#### ejemplo 3 (compatibilidad con Crypt::CBC)
use Crypt::CBC;
use Crypt::Cipher;
my $key = '...'; # la longitud debe ser un tamaño de clave válido para este cifrado
my $iv = '...';  # 16 bytes
my $cipher = Crypt::Cipher('AES', $key);
my $cbc = Crypt::CBC->new( -cipher=>$cipher, -iv=>$iv );
my $ciphertext = $cbc->encrypt("datos secretos");

DESCRIPCIÓN

Proporciona una interfaz a varios algoritmos de cifrado simétrico.

ADVERTENCIA: este módulo solo implementa la operación básica de "cifrado/descifrado de un solo bloque" - si desea cifrar/descifrar datos genéricos debe usar algunos de los modos de bloque de cifrado - consulte por ejemplo Crypt::Mode::CBC, Crypt::Mode::CTR o Crypt::CBC (que será más lento).

MÉTODOS

new

Constructor, devuelve una referencia al objeto de cifrado.

## escenario básico
$d = Crypt::Cipher->new($name, $key);
# $name = uno de 'AES', 'Anubis', 'Blowfish', 'CAST5', 'Camellia', 'DES', 'DES_EDE',
#                'KASUMI', 'Khazad', 'MULTI2', 'Noekeon', 'RC2', 'RC5', 'RC6',
#                'SAFERP', 'SAFER_K128', 'SAFER_K64', 'SAFER_SK128', 'SAFER_SK64',
#                'SEED', 'Skipjack', 'Twofish', 'XTEA', 'IDEA', 'Serpent'
#                simplemente cualquier <NOMBRE> para el cual exista Crypt::Cipher::<NOMBRE>
# $key = clave binaria (el tamaño de clave debe cumplir con los requisitos del cifrado seleccionado)
## algunos de los cifrados (p. ej., MULTI2, RC5, SAFER) permiten establecer el número de rondas
$d = Crypt::Cipher->new('MULTI2', $key, $rounds);
# $rounds = entero positivo (debe cumplir con los requisitos del cifrado seleccionado)

encrypt

Cifra $plaintext y devuelve $ciphertext donde $plaintext y $ciphertext deben ser de tamaño de bloque bytes.

$ciphertext = $d->encrypt($plaintext);

decrypt

Descifra $ciphertext y devuelve $plaintext donde $plaintext y $ciphertext deben ser de tamaño de bloque bytes.

$plaintext = $d->decrypt($ciphertext);

keysize

Solo un alias para max_keysize (necesario para la compatibilidad con Crypt::CBC).

max_keysize

Devuelve el tamaño máximo de clave permitido (en bytes) para el cifrado dado.

$d->max_keysize;
# o
Crypt::Cipher->max_keysize('AES');
# o
Crypt::Cipher::max_keysize('AES');

min_keysize

Devuelve el tamaño mínimo de clave permitido (en bytes) para el cifrado dado.

$d->min_keysize;
# o
Crypt::Cipher->min_keysize('AES');
# o
Crypt::Cipher::min_keysize('AES');

blocksize

Devuelve el tamaño del bloque (en bytes) para el cifrado dado.

$d->blocksize;
# o
Crypt::Cipher->blocksize('AES');
# o
Crypt::Cipher::blocksize('AES');

default_rounds

Devuelve el número predeterminado de rondas para el cifrado dado. NOTA: solo algunos cifrados (p. ej., MULTI2, RC5, SAFER) permiten establecer el número de rondas a través de new().

$d->default_rounds;
# o
Crypt::Cipher->default_rounds('AES');
# o
Crypt::Cipher::default_rounds('AES');
