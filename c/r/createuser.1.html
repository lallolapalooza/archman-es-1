DESCRIPCIÓ

N

createuser crea un nuevo usuario de PostgreSQL (o más precisamente, un rol). Solo los superusuarios y los usuarios con el privilegio CREATEROLE pueden crear nuevos usuarios, por lo que createuser debe ser invocado por alguien que pueda conectarse como superusuario o como usuario con el privilegio

CREATEROLE.

Si desea crear un rol con el privilegio SUPERUSER, REPLICATION o BYPASSRLS, debe conectarse como superusuario, no solo con el privilegio CREATEROLE. Ser superusuario implica la capacidad de omitir todas las comprobaciones de permisos de acceso dentro de la base de datos, por lo que el acceso de superusuario no debe concederse a la ligera. CREATEROLE también otorga privilegios muy

extensos.

createuser es un envoltorio alrededor del comando SQL CREATE ROLE. No hay diferencia efectiva entre crear usuarios median

te esta utilidad y mediante otr
os métodos para acceder al servidor.

DIAGNÓSTICO

S

En caso de dificultadesy, consulte CREATE ROLE (CREATE_ROLE(7)) y psql(1) para discusiones sobre posibles problemas y mensajes de error. El servidor de base de datos debe estar en ejecución en el host de destino. Además, cualquier configuración de conexión predeterminada y variables de entorno utilizadas por la biblioteca cliente libpq se aplicarán.

EJEMPLOS

Para crear un usuario joe en el servidor de base de datos predeterminado:

$ createuser joe

Para crear un usuario joe en el servidor de base de datos predeterminado solicitando algunos atributos adicionales:

$ createuser --interactive joe
¿Debe el nuevo rol ser un superusuario? (s/n) n
¿Se permitirá al nuevo rol crear bases de datos? (s/n) n
¿Se permitirá al nuevo rol crear más roles nuevos? (s/n) n

Para crear el mismo usuario joe utilizando el servidor en el host eden, puerto 5000, con atributos especificados explícitamente, observando el comando subyacente:

$ createuser -h eden -p 5000 -S -D -R -e joe
CREATE ROLE joe NOSUPERUSER NOCREATEDB NOCREATEROLE INHERIT LOGIN;

Para crear el usuario joe como superusuario y asignar una contraseña inmediatamente:

$ createuser -P -s -e joe
Ingrese la contraseña para el nuevo rol: xyzzy
Ingrese de nuevo: xyzzy
CREATE ROLE joe PASSWORD 'md5b5f5ba1a423792b526f799ae4eb3d59e' SUPERUSER CREATEDB CREATEROLE INHERIT LOGIN;

En el ejemplo anterior, la nueva contraseña no se muestra realmente al escribirla, pero mostramos lo que se escribió para mayor claridad. Como puede ver, la contraseña se cifra antes de enviarse al cliente.
