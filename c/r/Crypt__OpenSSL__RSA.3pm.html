DESCRIPCIÓ

N

"Crypt::OpenSSL::RSA" proporciona la capacidad de cifrar cadenas con RSA que son algo más cortas que el tamaño de bloque de una clave. También permite la decodificación, firmas y verificación de

firmas.

NOTA: Muchos de los métodos de este paquete pueden abortar (croak), así que use "eval", o el mecanismo try/catch de Error.pm para capturar errores. Además, aunque algunos métodos de versiones ante

riores de este paquete devuelven true en caso de éxito, e
ste comportamiento (nunca documentado) ya no es el caso.
