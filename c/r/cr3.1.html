CR3(1) Manual de Comandos Generales CR3(1)

NOMBRE

cr3 - programa para ver libros electrónicos (epub, fb2, html, txt, rtf...)

SINOPSIS

cr3 [opciones] nombre_archivo

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando cr3.

cr3 es una interfaz gráfica para leer libros electrónicos en diferentes formatos.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones. Para una descripción completa, consulte los archivos Info.

-h, --help
Muestra el resumen de opciones.
-v, --version
Muestra la versión del programa.
