Crypt::Stream::Rabbit(3) Documentación de Perl aportada por el usuario Crypt::Stream::Rabbit(3)

NOMBRE

Crypt::Stream::Rabbit - Cifrado de flujo Rabbit

SINOPSIS

use Crypt::Stream::Rabbit;
# cifrar
$key = "1234567890123456";
$iv  = "12345678";
$stream = Crypt::Stream::Rabbit->new($key, $iv);
$ct = $stream->crypt("mensaje plano");
# descifrar
$key = "1234567890123456";
$iv  = "12345678";
$stream = Crypt::Stream::Rabbit->new($key, $iv);
$pt = $stream->crypt($ct);

DESCRIPCIÓN

Proporciona una interfaz para el cifrado de flujo Rabbit.

MÉTODOS

new

$stream = Crypt::Stream::Rabbit->new($key, $iv);
# $key .. la longitud de la clave debe ser de hasta 16 bytes
# $iv  .. la longitud del IV debe ser de hasta 8 bytes
$stream = Crypt::Stream::Rabbit->new($key);
# CUIDADO: esto es diferente de new($key, "")

crypt

$ciphertext = $stream->crypt($plaintext);
# o
$plaintext = $stream->crypt($ciphertext);

keystream

$random_key = $stream->keystream($length);

clone

$stream->clone();
