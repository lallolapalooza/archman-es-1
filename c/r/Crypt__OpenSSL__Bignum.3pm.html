sub print_factorial
{
  my( $n ) = @_;
  my $fac = Crypt::OpenSSL::Bignum->one();
  my $ctx = Crypt::OpenSSL::Bignum::CTX->new();
  foreach my $i (1 .. $n)
  {
    $fac->mul( Crypt::OpenSSL::Bignum->new_from_word( $i ), $ctx, $fac );
  }
  print "$n factorial is ", $fac->to_decimal(), "\n";
}

DESCRIPCIÓ

N

Crypt::OpenSSL::Bignum proporciona acceso a las bibliotecas de aritmética de enteros de precisión múltiple de OpenSSL. Actualmente, muchas (aunque no todas) de las operaciones aritméticas que ofrece OpenSSL están expuestas a Perl. Además, este módulo se puede utilizar para proporcionar acceso a valores bignum producidos por otros módulos de OpenSSL, como los parámetros de clave de Crypt::OpenSSL::

RSA.

NOTA: Muchos de los métodos de este paquete pueden provocar un error fatal (croak),

por lo que use eval o el mecanismo try/ca
tch de Error.pm para capturar los errores.
