Crypt::Mac::XCBC(3) Documentación contribuida por el usuario de Perl Crypt::Mac::XCBC(3)

NOMBRE

Crypt::Mac::XCBC - Código de autenticación de mensajes XCBC (RFC 3566)

SINÓPSIS

### Interfaz funcional:
use Crypt::Mac::XCBC qw( xcbc xcbc_hex );
# calcular MAC desde cadena/buffer
$xcbc_raw  = xcbc($cipher_name, $key, 'buffer de datos');
$xcbc_hex  = xcbc_hex($cipher_name, $key, 'buffer de datos');
$xcbc_b64  = xcbc_b64($cipher_name, $key, 'buffer de datos');
$xcbc_b64u = xcbc_b64u($cipher_name, $key, 'buffer de datos');
### Interfaz OO:
use Crypt::Mac::XCBC;
$d = Crypt::Mac::XCBC->new($cipher_name, $key);
$d->add('cualquier dato');
$d->addfile('nombre_archivo.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->mac;     # bytes crudos
$result_hex  = $d->hexmac;  # formato hexadecimal
$result_b64  = $d->b64mac;  # formato Base64
$result_b64u = $d->b64umac; # formato Base64 seguro para URL

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de código de autenticación de mensajes (MAC) XCBC.

EXPORTACIÓN

No se exporta nada por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::Mac::XCBC qw(xcbc xcbc_hex );

O todas a la vez:

use Crypt::Mac::XCBC ':all';

FUNCIONES

xcbc

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes XCBC codificado como una cadena binaria.

$xcbc_raw = xcbc($cipher_name, $key, 'buffer de datos');
#o
$xcbc_raw = xcbc($cipher_name, $key, 'cualquier dato', 'más datos', 'incluso más datos');

xcbc_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes XCBC codificado como una cadena hexadecimal.

$xcbc_hex = xcbc_hex($cipher_name, $key, 'buffer de datos');
#o
$xcbc_hex = xcbc_hex($cipher_name, $key, 'cualquier dato', 'más datos', 'incluso más datos');

xcbc_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes XCBC codificado como una cadena Base64.

$xcbc_b64 = xcbc_b64($cipher_name, $key, 'buffer de datos');
#o
$xcbc_b64 = xcbc_b64($cipher_name, $key, 'cualquier dato', 'más datos', 'incluso más datos');

xcbc_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes XCBC codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$xcbc_b64url = xcbc_b64u($cipher_name, $key, 'buffer de datos');
#o
$xcbc_b64url = xcbc_b64u($cipher_name, $key, 'cualquier dato', 'más datos', 'incluso más datos');
