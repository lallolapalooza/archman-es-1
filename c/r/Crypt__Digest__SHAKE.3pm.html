Paquete: perl-cryptx

Licencias: PerlArtistic, GPL

Crypt::Digest::SHAKE(3) Documentación de Perl contribuida por usuarios Crypt::Digest::SHAKE(3)

NOMBRE

Crypt::Digest::SHAKE - Funciones hash SHAKE128, SHAKE256 de la familia SHA3

SINOPSIS

use Crypt::Digest::SHAKE
$d = Crypt::Digest::SHAKE->new(128);
$d->add('cualquier dato');
$d->addfile('nombre_archivo.dat');
$d->addfile(*MANEJADOR_ARCHIVO);
$parte1 = $d->done(100); # 100 bytes crudos
$parte2 = $d->done(100); # otros 100 bytes crudos
#...

DESCRIPCIÓN

Proporciona una interfaz a la función de esponja SHAKE de SHA3.

MÉTODOS

new

$d = Crypt::Digest::SHA3-SHAKE->new($num);
# $num ... 128 o 256

clone

$d->clone();

reset

$d->reset();

add

$d->add('cualquier dato');
# o
$d->add('cualquier dato', 'más datos', 'incluso más datos');

addfile

$d->addfile('nombre_archivo.dat');
# o
$d->addfile(*MANEJADOR_ARCHIVO);

done

$resultado_crudo = $d->done($len);
# se puede llamar varias veces
