Crypt::Stream::Sober128(3) Documentación de Perl aportada por el usuario Crypt::Stream::Sober128(3)

NOMBRE

Crypt::Stream::Sober128 - Cifrado de flujo Sober128

SINOPSIS

use Crypt::Stream::Sober128;
# cifrar
$key = "1234567890123456";
$iv  = "123456789012";
$stream = Crypt::Stream::Sober128->new($key, $iv);
$ct = $stream->crypt("mensaje plano");
# descifrar
$key = "1234567890123456";
$iv  = "123456789012";
$stream = Crypt::Stream::Sober128->new($key, $iv);
$pt = $stream->crypt($ct);

DESCRIPCIÓN

Proporciona una interfaz al cifrado de flujo Sober128.

MÉTODOS

new

$stream = Crypt::Stream::Sober128->new($key, $iv);
# $key .. keylen debe ser múltiplo de 4 bytes
# $iv  .. ivlen debe ser múltiplo de 4 bytes

crypt

$ciphertext = $stream->crypt($plaintext);
# o
$plaintext = $stream->crypt($ciphertext);

keystream

$random_key = $stream->keystream($length);

clone

$stream->clone();
