NOMBRE

create_makefiles - Recrea todos los Makefiles bajo un directorio

SINOPSIS

create_makefiles [dir]

DESCRIPCIÓN

create_makefiles recrea todos los Makefiles en dir y sus subdirectorios (recursivamente) a partir de las plantillas Makefile.am correspondientes.

Este script debe ejecutarse desde el directorio raíz (el que contiene configure). Este script ahorra tiempo en comparación con volver a ejecutar configure por completo.

Si el directorio fuente es diferente del directorio de compilación (ver las variables de entorno a continuación), se asumirá que cada Makefile.am y Makefile.in pertenecen bajo el directorio fuente y que cada Makefile pertenece bajo el directorio de compilación.

Esta utilidad forma parte del Kit de Desarrollo de Software de KDE.

ENTORNO

Una de las siguientes variables (pero no ambas) debe establecerse si el directorio fuente es diferente del directorio de compilación. Si el directorio de compilación es simplemente un subdirectorio del directorio fuente, se debe usar la variable más simple OBJ_SUBDIR.

OBJ_SUBDIR

Indica que el directorio de compilación se encuentra en el subdirectorio dado del directorio fuente. Por ejemplo, si el directorio fuente es kdesdk y el directorio de compilación es kdesdk/obj-i386-linux, entonces OBJ_SUBDIR debe establecerse en obj-i386-linux.

OBJ_REPLACEMENT

Una expresión sed que se utiliza para transformar el directorio fuente en el directorio de compilación. Por ejemplo, si el directorio fuente es kdesdk/obj-i386-linux, entonces OBJ_REPLACEMENT debe establecerse en s#kdesdk#kdesdk-obj#.

VER TAMBIÉN
