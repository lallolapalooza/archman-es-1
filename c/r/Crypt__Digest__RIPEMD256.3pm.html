Crypt::Digest::RIPEMD256(3) Documentación de Perl aportada por el usuario Crypt::Digest::RIPEMD256(3)

NOMBRE

Crypt::Digest::RIPEMD256 - Función hash RIPEMD-256 [tamaño: 256 bits]

SINOPSIS

### Interfaz funcional:
use Crypt::Digest::RIPEMD256 qw( ripemd256 ripemd256_hex ripemd256_b64 ripemd256_b64u
                             ripemd256_file ripemd256_file_hex ripemd256_file_b64 ripemd256_file_b64u );
# calcular el resumen a partir de una cadena/búfer
$ripemd256_raw  = ripemd256('cadena de datos');
$ripemd256_hex  = ripemd256_hex('cadena de datos');
$ripemd256_b64  = ripemd256_b64('cadena de datos');
$ripemd256_b64u = ripemd256_b64u('cadena de datos');
# calcular el resumen a partir de un archivo
$ripemd256_raw  = ripemd256_file('nombrearchivo.dat');
$ripemd256_hex  = ripemd256_file_hex('nombrearchivo.dat');
$ripemd256_b64  = ripemd256_file_b64('nombrearchivo.dat');
$ripemd256_b64u = ripemd256_file_b64u('nombrearchivo.dat');
# calcular el resumen a partir de un manejador de archivo
$ripemd256_raw  = ripemd256_file(*MANEJADORARCHIVO);
$ripemd256_hex  = ripemd256_file_hex(*MANEJADORARCHIVO);
$ripemd256_b64  = ripemd256_file_b64(*MANEJADORARCHIVO);
$ripemd256_b64u = ripemd256_file_b64u(*MANEJADORARCHIVO);
### Interfaz orientada a objetos:
use Crypt::Digest::RIPEMD256;
$d = Crypt::Digest::RIPEMD256->new;
$d->add('cualquier dato');
$d->addfile('nombrearchivo.dat');
$d->addfile(*MANEJADORARCHIVO);
$result_raw  = $d->digest;     # bytes crudos
$result_hex  = $d->hexdigest;  # forma hexadecimal
$result_b64  = $d->b64digest;  # forma Base64
$result_b64u = $d->b64udigest; # forma Base64 segura para URL

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de resumen RIPEMD256.

EXPORTACIÓN

No se exporta nada por defecto.

Puede exportar funciones seleccionadas:

use Crypt::Digest::RIPEMD256 qw(ripemd256 ripemd256_hex ripemd256_b64 ripemd256_b64u
                                    ripemd256_file ripemd256_file_hex ripemd256_file_b64 ripemd256_file_b64u);

O todas a la vez:

use Crypt::Digest::RIPEMD256 ':all';

FUNCIONES

ripemd256

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen RIPEMD256 codificado como una cadena binaria.

$ripemd256_raw = ripemd256('cadena de datos');
#o
$ripemd256_raw = ripemd256('cualquier dato', 'más datos', 'aún más datos');

ripemd256_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen RIPEMD256 codificado como una cadena hexadecimal.

$ripemd256_hex = ripemd256_hex('cadena de datos');
#o
$ripemd256_hex = ripemd256_hex('cualquier dato', 'más datos', 'aún más datos');

ripemd256_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen RIPEMD256 codificado como una cadena Base64, con relleno '=' al final.

$ripemd256_b64 = ripemd256_b64('cadena de datos');
#o
$ripemd256_b64 = ripemd256_b64('cualquier dato', 'más datos', 'aún más datos');

ripemd256_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen RIPEMD256 codificado como una cadena Base64 segura para URL (véase la sección 5 del RFC 4648).

$ripemd256_b64url = ripemd256_b64u('cadena de datos');
#o
$ripemd256_b64url = ripemd256_b64u('cualquier dato', 'más datos', 'aún más datos');

ripemd256_file

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen RIPEMD256 codificado como una cadena binaria.

$ripemd256_raw = ripemd256_file('nombrearchivo.dat');
#o
$ripemd256_raw = ripemd256_file(*MANEJADORARCHIVO);

ripemd256_file_hex

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen RIPEMD256 codificado como una cadena hexadecimal.

$ripemd256_hex = ripemd256_file_hex('nombrearchivo.dat');
#o
$ripemd256_hex = ripemd256_file_hex(*MANEJADORARCHIVO);

ADVERTENCIA: Debe asegurarse de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

ripemd256_file_b64

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen RIPEMD256 codificado como una cadena Base64, con relleno '=' al final.

$ripemd256_b64 = ripemd256_file_b64('nombrearchivo.dat');
#o
$ripemd256_b64 = ripemd256_file_b64(*MANEJADORARCHIVO);

ripemd256_file_b64u

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen RIPEMD256 codificado como una cadena Base64 segura para URL (véase la sección 5 del RFC 4648).

$ripemd256_b64url = ripemd256_file_b64u('nombrearchivo.dat');
#o
$ripemd256_b64url = ripemd256_file_b64u(*MANEJADORARCHIVO);

MÉTODOS

La interfaz orientada a objetos proporciona el mismo conjunto de funciones que Crypt::Digest.

new

$d = Crypt::Digest::RIPEMD256->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('cualquier dato');
#o
$d->add('cualquier dato', 'más datos', 'aún más datos');

addfile

$d->addfile('nombrearchivo.dat');
#o
$d->addfile(*MANEJADORARCHIVO);

add_bits

$d->add_bits($cadena_bits);   # p. ej. $d->add_bits("111100001010");
#o
$d->add_bits($datos, $nbits); # p. ej. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#o
Crypt::Digest::RIPEMD256->hashsize();
#o
Crypt::Digest::RIPEMD256::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
