CRYPTOFLEX-TOOL(1) Herramientas OpenSC CRYPTOFLEX-TOOL(1)

NOMBRE

cryptoflex-tool - utilidad para manipular estructuras de datos Schlumberger Cryptoflex

SINOPSIS

cryptoflex-tool [OPCIONES]

DESCRIPCIÓN

cryptoflex-tool se utiliza para manipular estructuras de datos PKCS en tarjetas inteligentes Schlumberger Cryptoflex. Los usuarios pueden crear, listar y leer PIN y claves almacenados en la tarjeta inteligente. La autenticación de PIN de usuario se realiza para las operaciones que lo requieren.

OPCIONES

--app-df num, -a num

Especifica el DF en el que operar

--create-key-files arg, -c arg

Crea nuevos archivos de clave RSA para arg claves

--create-pin-files id, -P id

Crea un nuevo archivo PIN para CHVid

--exponent exp, -e exp

Especifica el exponente RSA, exp, a utilizar en la generación de claves. El valor predeterminado es 3.

--generate-key, -g

Genera un nuevo par de claves RSA

--key-num num, -k num

Especifica el número de clave en el que operar. El valor predeterminado es el número de clave 1.

--list-keys, -l

Lista todas las claves almacenadas en un archivo de clave pública

--modulus-length length, -m length

Especifica la longitud del módulo length a utilizar en la generación de claves. El valor predeterminado es 1024.

--prkey-file id, -p id

Especifica el ID del archivo de clave privada, id, a utilizar

--pubkey-file id, -u id

Especifica el ID del archivo de clave pública, id, a utilizar

--read-key, -R

Lee una clave pública de la tarjeta, permitiendo al usuario extraer y almacenar o usar la clave pública

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--verbose, -v

Hace que cryptoflex-tool sea más verboso. Especifique esta bandera varias veces para habilitar la salida de depuración en la biblioteca opensc.

--verify-pin, -V

Verifica CHV1 antes de emitir comandos

--wait, -w

Hace que cryptoflex-tool espere la inserción de una tarjeta.

VER TAMBIÉN

pkcs15-tool(1)
