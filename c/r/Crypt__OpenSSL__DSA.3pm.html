Crypt::OpenSSL::DSA(3) Documentación de Perl aportada por el usuario Crypt::OpenSSL::DSA(3)

NOMBRE

Crypt::OpenSSL::DSA - Algoritmo de Firma Digital usando OpenSSL

SINOPSIS

use Crypt::OpenSSL::DSA;
# generar claves y escribirlas en archivos PEM
my $dsa = Crypt::OpenSSL::DSA->generate_parameters( 512 );
$dsa->generate_key;
$dsa->write_pub_key( $filename );
$dsa->write_priv_key( $filename );
# usando claves de archivos PEM
my $dsa_priv = Crypt::OpenSSL::DSA->read_priv_key( $filename );
my $sig      = $dsa_priv->sign($message);
my $dsa_pub  = Crypt::OpenSSL::DSA->read_pub_key( $filename );
my $valid    = $dsa_pub->verify($message, $sig);
# usando claves de cadenas PEM
my $dsa_priv = Crypt::OpenSSL::DSA->read_priv_key_str( $key_string );
my $sig      = $dsa_priv->sign($message);
my $dsa_pub  = Crypt::OpenSSL::DSA->read_pub_key_str( $key_string );
my $valid    = $dsa_pub->verify($message, $sig);

DESCRIPCIÓN

Crypt::OpenSSL::DSA implementa el sistema de verificación de firmas DSA (Digital Signature Algorithm).

Es un envoltorio XS delgado de las funciones DSA contenidas en la biblioteca criptográfica OpenSSL, ubicada en http://www.openssl.org

MÉTODOS DE CLASE

$dsa = Crypt::OpenSSL::DSA->generate_parameters( $bits, $seed );
Devuelve un nuevo objeto DSA y genera los parámetros p, q y g necesarios para generar claves.

bits es la longitud del primo a generar; el DSS permite un máximo de 1024 bits.

$dsa = Crypt::OpenSSL::DSA->read_params( $filename );
Lee un archivo de parámetros PEM y devuelve un nuevo objeto DSA con los parámetros p, q y g necesarios para generar claves.
$dsa = Crypt::OpenSSL::DSA->read_pub_key( $filename );
Lee un archivo de clave pública PEM y devuelve un nuevo objeto DSA que puede usarse para verificar firmas DSA.
$dsa = Crypt::OpenSSL::DSA->read_priv_key( $filename );
Lee un archivo de clave privada PEM y devuelve un nuevo objeto DSA que puede usarse para firmar mensajes.
$dsa = Crypt::OpenSSL::DSA->read_pub_key_str( $key_string );
Lee una cadena de clave pública PEM y devuelve un nuevo objeto DSA que puede usarse para verificar firmas DSA. La cadena debe incluir las líneas -----BEGIN...----- y -----END...-----.
$dsa = Crypt::OpenSSL::DSA->read_priv_key_str( $key_string );
Lee una cadena de clave privada PEM y devuelve un nuevo objeto DSA que puede usarse para firmar mensajes. La cadena debe incluir las líneas -----BEGIN...----- y -----END...-----.

MÉTODOS DE OBJETO

$dsa->generate_key;
Genera claves privada y pública, asumiendo que $dsa es el valor de retorno de generate_parameters.
$sig_size = $dsa->get_sig_size( );
Devuelve el tamaño máximo de una firma DSA codificada en ASN.1 para la clave dsa en bytes. 
 claves de 512 bits = 48
claves de 1024 bits = 48
claves de 2024 bits = 72
claves de 3072 bits = 72

Las firmas ASN.1 dsa consisten en:

Sequence 1-byte (0x30) Length 1-byte Integer 1-byte (0x02) Length 1-byte (0x14) = 20 r 20-bytes or 21-bytes Integer 1-byte (0x02) Length 1-byte (0x14) = 20 s 20-bytes or 21-bytes

30 2C 02 14 6C.70.50.7C.93.A8.B5.EC.1E.A1.5E.C5.73.AA.0F.EA.4D.BE.42.7A 02 14 4E.AD.E6.BB.72.54.92.30.2B.03.AB.53.5D.3D.6E.88.B8.AA.D6.30

Nótese que la firma anterior tiene 46 bytes de longitud - los dos bytes extra se usan solo cuando r y/o s son mayores o iguales a 2^159. Los bytes extra se usan para distinguir valores positivos de negativos.

Todo esto para decir que si estás usando get_sig_size() para determinar el tamaño de r + s dependiendo del tamaño de la clave, puedes restar 8 bytes por la sobrecarga de ASN.1.

$sig = $dsa->sign( $message );
Firma $message, devolviendo la firma. Nótese que $meesage no puede exceder 20 caracteres de longitud.

$dsa es la clave privada del firmante.

$sig_obj = $dsa->do_sign( $message );
Similar a "sign", pero devuelve un objeto Crypt::OpenSSL::DSA::Signature.
$valid = $dsa->verify( $message, $sig );
Verifica que la firma $sig de $message es válida.

$dsa es la clave pública del firmante.

Nótese: emite un error fatal si la llamada a la biblioteca subyacente devuelve error (-1).

$valid = $dsa->do_verify( $message, $sig_obj );
Similar a "verify", pero usa un objeto Crypt::OpenSSL::DSA::Signature.

Nótese: emite un error fatal si la llamada a la biblioteca subyacente devuelve error (-1).

$dsa->write_params( $filename );
Escribe los parámetros en un archivo PEM.
$dsa->write_pub_key( $filename );
Escribe la clave pública en un archivo PEM.
$dsa->write_priv_key( $filename );
Escribe la clave privada en un archivo PEM.
$p = $dsa->get_p, $dsa->set_p($p)
Obtiene/establece el número primo en formato binario.
$q = $dsa->get_q, $dsa->set_q($q)
Obtiene/establece el número subprimo (q | p-1) en formato binario.
$g = $dsa->get_g, $dsa->set_g($g)
Obtiene/establece el generador del subgrupo en formato binario.
$pub_key = $dsa->get_pub_key, $dsa->set_pub_key($pub_key)
Obtiene/establece la clave pública (y = g^x) en formato binario.
$priv_key = $dsa->get_priv_key, $dsa->set_priv_key($priv_key)
Obtiene/establece la clave privada en formato binario.
