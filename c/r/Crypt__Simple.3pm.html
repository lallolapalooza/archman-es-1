NOMBRE

Crypt::Simple - cifra cosas de forma sencilla

SINOPSIS

use Crypt::Simple;

my $data = encrypt(@stuff);
my @same_stuff = decrypt($data);

DESCRIPCIÓN

Quizás tengas una aplicación web y necesites almacenar algunos datos de sesión en el lado del cliente (en una cookie o campos ocultos del formulario) pero no quieres que el usuario pueda manipular los datos. Quizás quieras guardar información secreta en un archivo de texto. ¡Quizás tengas mejores ideas de lo que hacer con datos cifrados!

Este pequeño módulo convertirá todos tus datos en un texto base64 bonito que puedes guardar en un archivo de texto, enviar por correo electrónico, almacenar en una cookie o página web, o rebotar por la red. Los datos que cifres pueden ser tan simples o tan complicados como desees.

CLAVE

Si no pasas ninguna opción al usar "Crypt::Simple", generaremos una clave para ti basándonos en el nombre del módulo que utiliza este. En muchos casos, esto funciona bien, pero es posible que desees un mayor control sobre la clave. Aquí te mostramos cómo:

use Crypt::Simple passphrase => 'frase secreta';
Se usa el hash MD5 de la cadena de texto "frase secreta" como clave.
use Crypt::Simple prompt => 'Por favor, escribe las palabras mágicas';
Se le pide al usuario que introduzca una frase secreta, y se utiliza el hash MD5 del texto introducido como clave.
use Crypt::Simple passfile => '/home/marty/secreto';
Se utiliza el contenido del archivo /home/marty/secreto como frase secreta: se utiliza el hash MD5 del archivo como clave.
use Crypt::Simple file => '/home/marty/ruido';
Se utiliza directamente el contenido del archivo /home/marty/ruido como clave.

INTERNOS

"Crypt::Simple" es realmente solo un envoltorio de otros módulos útiles de Perl: es posible que desees leer la documentación de estos módulos también.

Usamos "FreezeThaw" para compactar todos tus datos en una representación textual concisa. Usamos "Compress::Zlib" para comprimir esta cadena, y luego usamos "Crypt::Blowfish" en un modo CBC casero para realizar el cifrado. En algún punto de este proceso, también añadimos un digest MD5 (usando "Digest::MD5"). Luego lanzamos todo a través de "MIME::Base64" para producir un bonito trozo de texto para que juegues con él.

El descifrado, obviamente, es el proceso inverso.

ADVERTENCIA

A los gobiernos de todo el mundo no les gusta el cifrado porque les dificulta ver todas tus cosas. Cada país tiene una política diferente diseñada para evitar que uses el cifrado: algunos gobiernos son lo suficientemente honestos como para hacerlo ilegal; algunos piensan que es un arma peligrosa; algunos insisten en que eres libre de cifrar, pero solo la gente malvada querría hacerlo; algunos crean leyes confusas y contradictorias porque intentan hacer todo lo anterior.

Aunque este módulo en sí no incluye ningún código de cifrado, sí utiliza otro módulo que contiene código de cifrado, y esta documentación menciona el cifrado. Descargar, usar o leer este módulo podría ser ilegal donde vives.
