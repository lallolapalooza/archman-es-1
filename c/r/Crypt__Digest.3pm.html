Paquete: perl-cryptx

Crypt::Digest(3) Documentación de Perl aportada por el usuario Crypt::Digest(3)

NOMBRE

Crypt::Digest - Interfaz genérica para funciones hash/digest

SINOPSIS

### Interfaz funcional:
use Crypt::Digest qw( digest_data digest_data_hex digest_data_b64 digest_data_b64u
                      digest_file digest_file_hex digest_file_b64 digest_file_b64u );
# calcular digest a partir de cadena/búfer
$digest_raw  = digest_data('SHA1', 'cadena de datos');
$digest_hex  = digest_data_hex('SHA1', 'cadena de datos');
$digest_b64  = digest_data_b64('SHA1', 'cadena de datos');
$digest_b64u = digest_data_b64u('SHA1', 'cadena de datos');
# calcular digest a partir de un archivo
$digest_raw  = digest_file('SHA1', 'nombrearchivo.dat');
$digest_hex  = digest_file_hex('SHA1', 'nombrearchivo.dat');
$digest_b64  = digest_file_b64('SHA1', 'nombrearchivo.dat');
$digest_b64u = digest_file_b64u('SHA1', 'nombrearchivo.dat');
# calcular digest a partir de un manejador de archivo
$digest_raw  = digest_file('SHA1', *MANEJADORDEARCHIVO);
$digest_hex  = digest_file_hex('SHA1', *MANEJADORDEARCHIVO);
$digest_b64  = digest_file_b64('SHA1', *MANEJADORDEARCHIVO);
$digest_b64u = digest_file_b64u('SHA1', *MANEJADORDEARCHIVO);
### Interfaz orientada a objetos:
use Crypt::Digest;
$d = Crypt::Digest->new('SHA1');
$d->add('cualquier dato');
$d->addfile('nombrearchivo.dat');
$d->addfile(*MANEJADORDEARCHIVO);
$result_raw  = $d->digest;     # bytes crudos
$result_hex  = $d->hexdigest;  # forma hexadecimal
$result_b64  = $d->b64digest;  # forma Base64
$result_b64u = $d->b64udigest; # forma Base64 segura para URL

DESCRIPCIÓN

Proporciona una interfaz para varios algoritmos hash/digest.

EXPORTACIÓN

No se exporta nada por defecto.

Puede exportar funciones seleccionadas:

use Crypt::Digest qw( digest_data digest_data_hex digest_data_b64 digest_data_b64u
                      digest_file digest_file_hex digest_file_b64 digest_file_b64u );

O todas a la vez:

use Crypt::Digest ':all';

FUNCIONES

Tenga en cuenta que todas las funciones toman como primer argumento el nombre del algoritmo, los valores admitidos son:

'CHAES', 'MD2', 'MD4', 'MD5', 'RIPEMD128', 'RIPEMD160',
'RIPEMD256', 'RIPEMD320', 'SHA1', 'SHA224', 'SHA256',
'SHA384', 'SHA512', 'SHA512_224', 'SHA512_256', 'Tiger192', 'Whirlpool',
'SHA3_224', 'SHA3_256', 'SHA3_384', 'SHA3_512',
'BLAKE2b_160', 'BLAKE2b_256', 'BLAKE2b_384', 'BLAKE2b_512',
'BLAKE2s_128', 'BLAKE2s_160', 'BLAKE2s_224', 'BLAKE2s_256'
(simplemente cualquier <NOMBRE> para el que exista el módulo Crypt::Digest::<NOMBRE>)

digest_data

Une lógicamente todos los argumentos en una sola cadena y devuelve su digest SHA1 codificado como cadena binaria.

$digest_raw = digest_data('SHA1', 'cadena de datos');
#o
$digest_raw = digest_data('SHA1', 'cualquier dato', 'más datos', 'aún más datos');

digest_data_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su digest SHA1 codificado como cadena hexadecimal.

$digest_hex = digest_data_hex('SHA1', 'cadena de datos');
#o
$digest_hex = digest_data_hex('SHA1', 'cualquier dato', 'más datos', 'aún más datos');

digest_data_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su digest SHA1 codificado como cadena Base64, con relleno '=' final.

$digest_b64 = digest_data_b64('SHA1', 'cadena de datos');
#o
$digest_b64 = digest_data_b64('SHA1', 'cualquier dato', 'más datos', 'aún más datos');

digest_data_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su digest SHA1 codificado como cadena Base64 segura para URL (véase RFC 4648 sección 5).

$digest_b64url = digest_data_b64u('SHA1', 'cadena de datos');
#o
$digest_b64url = digest_data_b64u('SHA1', 'cualquier dato', 'más datos', 'aún más datos');

digest_file

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su digest codificado como cadena binaria.

$digest_raw = digest_file('SHA1', 'nombrearchivo.dat');
#o
$digest_raw = digest_file('SHA1', *MANEJADORDEARCHIVO);

digest_file_hex

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su digest codificado como cadena hexadecimal.

$digest_hex = digest_file_hex('SHA1', 'nombrearchivo.dat');
#o
$digest_hex = digest_file_hex('SHA1', *MANEJADORDEARCHIVO);

ADVERTENCIA: Debe asegurarse de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

digest_file_b64

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su digest codificado como cadena Base64, con relleno '=' final.

$digest_b64 = digest_file_b64('SHA1', 'nombrearchivo.dat');
#o
$digest_b64 = digest_file_b64('SHA1', *MANEJADORDEARCHIVO);

digest_file_b64u

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su digest codificado como cadena Base64 segura para URL (véase RFC 4648 sección 5).

$digest_b64url = digest_file_b64u('SHA1', 'nombrearchivo.dat');
#o
$digest_b64url = digest_file_b64u('SHA1', *MANEJADORDEARCHIVO);

MÉTODOS

new

Constructor, devuelve una referencia al objeto digest.

$d = Crypt::Digest->new($nombre);
# $nombre podría ser: 'CHAES', 'MD2', 'MD4', 'MD5', 'RIPEMD128', 'RIPEMD160',
#                     'RIPEMD256', 'RIPEMD320', 'SHA1', 'SHA224', 'SHA256', 'SHA384',
#                     'SHA512', 'SHA512_224', 'SHA512_256', 'Tiger192', 'Whirlpool'
#
# simplemente cualquier <NOMBREFUNCION> para el que exista el módulo Crypt::Digest::<NOMBREFUNCION>

clone

Crea una copia del estado del objeto digest y devuelve una referencia a la copia.

$d->clone();

reset

Reinicializa el estado del objeto digest y devuelve una referencia al objeto digest.

$d->reset();

add

Todos los argumentos se añaden al mensaje para el que calculamos el digest. El valor de retorno es el propio objeto digest.

$d->add('cualquier dato');
#o
$d->add('cualquier dato', 'más datos', 'aún más datos');

Tenga en cuenta que todos los siguientes casos son equivalentes:

# caso 1
$d->add('aa', 'bb', 'cc');
# caso 2
$d->add('aa');
$d->add('bb');
$d->add('cc');
# caso 3
$d->add('aabbcc');
# caso 4
$d->add('aa')->add('bb')->add('cc');

addfile

El contenido del archivo (o manejador de archivo) se añade al mensaje para el que calculamos el digest. El valor de retorno es el propio objeto digest.

$d->addfile('nombrearchivo.dat');
#o
$d->addfile(*MANEJADORDEARCHIVO);

ADVERTENCIA: Debe asegurarse de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

add_bits

Este método está disponible principalmente por compatibilidad con otros módulos Digest::ALGO en CPAN, es muy poco probable que lo necesite. El valor de retorno es el propio objeto digest.

$d->add_bits($cadena_de_bits);   # p. ej. $d->add_bits("111100001010");
#o
$d->add_bits($datos, $nbits); # p. ej. $d->add_bits("\xF0\xA0", 16);

ADVERTENCIA: No es posible añadir bits que no sean un múltiplo de 8.

hashsize

Devuelve la longitud del digest calculado en bytes (p. ej. 32 para SHA-256).

$d->hashsize;
#o
Crypt::Digest->hashsize('SHA1');
#o
Crypt::Digest::hashsize('SHA1');

digest

Devuelve el digest binario (bytes crudos).

$result_raw = $d->digest();

hexdigest

Devuelve el resumen codificado como una cadena hexadecimal.

$result_hex = $d->hexdigest();

b64digest

Devuelve el resumen codificado como una cadena Base64, con relleno '=' final (CUIDADO: este estilo de relleno puede diferir del de otros módulos Digest::<ALGO> en CPAN).

$result_b64 = $d->b64digest();

b64udigest

Devuelve el resumen codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$result_b64url = $d->b64udigest();

VÉASE TAMBIÉN

  • CryptX
  • Crypt::Digest intenta ser compatible con la interfaz de Digest.
  • Consulte subclases como Crypt::Digest::SHA1, Crypt::Digest::MD5, ...
