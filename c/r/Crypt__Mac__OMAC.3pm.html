NOMBRE

Crypt::Mac::OMAC - Código de autenticación de mensajes OMAC

SINOPSIS

### Interfaz funcional:
use Crypt::Mac::OMAC qw( omac omac_hex );
# calcular MAC a partir de cadena/buffer
$omac_raw  = omac($cipher_name, $key, 'buffer de datos');
$omac_hex  = omac_hex($cipher_name, $key, 'buffer de datos');
$omac_b64  = omac_b64($cipher_name, $key, 'buffer de datos');
$omac_b64u = omac_b64u($cipher_name, $key, 'buffer de datos');
### Interfaz OO:
use Crypt::Mac::OMAC;
$d = Crypt::Mac::OMAC->new($cipher_name, $key);
$d->add('cualquier dato');
$d->addfile('nombre_archivo.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->mac;     # bytes crudos
$result_hex  = $d->hexmac;  # formato hexadecimal
$result_b64  = $d->b64mac;  # formato Base64
$result_b64u = $d->b64umac; # formato Base64 seguro para URL

DESCRIPCIÓN

Proporciona una interfaz al algoritmo de código de autenticación de mensajes (MAC) OMAC.

EXPORTAR

No se exporta nada por defecto.

Puede exportar funciones seleccionadas:

use Crypt::Mac::OMAC qw(omac omac_hex );

O todas a la vez:

use Crypt::Mac::OMAC ':all';

FUNCIONES

omac

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes OMAC codificado como una cadena binaria.

$omac_raw = omac($cipher_name, $key, 'buffer de datos');
#o
$omac_raw = omac($cipher_name, $key, 'cualquier dato', 'más datos', 'aún más datos');

omac_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes OMAC codificado como una cadena hexadecimal.

$omac_hex = omac_hex($cipher_name, $key, 'buffer de datos');
#o
$omac_hex = omac_hex($cipher_name, $key, 'cualquier dato', 'más datos', 'aún más datos');

omac_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes OMAC codificado como una cadena Base64.

$omac_b64 = omac_b64($cipher_name, $key, 'buffer de datos');
#o
$omac_b64 = omac_b64($cipher_name, $key, 'cualquier dato', 'más datos', 'aún más datos');

omac_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes OMAC codificado como una cadena Base64 segura para URL (ver RFC 4648 sección 5).

$omac_b64url = omac_b64u($cipher_name, $key, 'buffer de datos');
#o
$omac_b64url = omac_b64u($cipher_name, $key, 'cualquier dato', 'más datos', 'aún más datos');
