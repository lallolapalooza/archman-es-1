Crypt::AuthEnc::ChaCha20Poly1305(3) Documentación de Perl proporcionada por el usuario Crypt::AuthEnc::ChaCha20Poly1305(3)

NOMBRE

Crypt::AuthEnc::ChaCha20Poly1305 - Cifrado autenticado en modo ChaCha20-Poly1305

SINOPSIS

### Interfaz OO
use Crypt::AuthEnc::ChaCha20Poly1305;
# cifrar y autenticar
my $ae = Crypt::AuthEnc::ChaCha20Poly1305->new($key, $iv);
$ae->adata_add('datos_adicionales_autenticados1');
$ae->adata_add('datos_adicionales_autenticados2');
my $ct = $ae->encrypt_add('datos1');
$ct .= $ae->encrypt_add('datos2');
$ct .= $ae->encrypt_add('datos3');
my $tag = $ae->encrypt_done();
# descifrar y verificar
my $ae = Crypt::AuthEnc::ChaCha20Poly1305->new($key, $iv);
$ae->adata_add('datos_adicionales_autenticados1');
$ae->adata_add('datos_adicionales_autenticados2');
my $pt = $ae->decrypt_add('cifrado1');
$pt .= $ae->decrypt_add('cifrado2');
$pt .= $ae->decrypt_add('cifrado3');
my $tag = $ae->decrypt_done();
die "descifrado fallido" unless $tag eq $expected_tag;
# o
my $result = $ae->decrypt_done($expected_tag); # 0 o 1
### Interfaz funcional
use Crypt::AuthEnc::ChaCha20Poly1305 qw(chacha20poly1305_encrypt_authenticate chacha20poly1305_decrypt_verify);
my ($ciphertext, $tag) = chacha20poly1305_encrypt_authenticate($key, $iv, $adata, $plaintext);
my $plaintext = chacha20poly1305_decrypt_verify($key, $iv, $adata, $ciphertext, $tag);

DESCRIPCIÓN

Proporciona cifrado y autenticación basados en ChaCha20 + Poly1305, como se define en RFC 7539 - https://tools.ietf.org/html/rfc7539

EXPORTAR

Nada se exporta por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::AuthEnc::ChaCha20Poly1305 qw(chacha20poly1305_encrypt_authenticate chacha20poly1305_decrypt_verify);

FUNCIONES

chacha20poly1305_encrypt_authenticate

my ($ciphertext, $tag) = chacha20poly1305_encrypt_authenticate($key, $iv, $adata, $plaintext);
# $key ..... clave de longitud adecuada (128 o 256 bits / 16 o 32 bytes)
# $iv ...... vector de inicialización (64 o 96 bits / 8 o 12 bytes)
# $adata ... datos adicionales autenticados (opcional)

chacha20poly1305_decrypt_verify

my $plaintext = chacha20poly1305_decrypt_verify($key, $iv, $adata, $ciphertext, $tag);
# en caso de error devuelve undef

MÉTODOS

new

my $ae = Crypt::AuthEnc::ChaCha20Poly1305->new($key, $iv);
# $key ..... clave de cifrado de longitud adecuada (128 o 256 bits / 16 o 32 bytes)
# $iv ...... vector de inicialización (64 o 96 bits / 8 o 12 bytes)

adata_add

Agrega datos adicionales autenticados. Se puede llamar antes del primer "encrypt_add" o "decrypt_add";

$ae->adata_add($aad_data);                     # se puede llamar varias veces

encrypt_add

$ciphertext = $ae->encrypt_add($data);         # se puede llamar varias veces

encrypt_done

$tag = $ae->encrypt_done();                    # devuelve el valor de $tag

decrypt_add

$plaintext = $ae->decrypt_add($ciphertext);    # se puede llamar varias veces

decrypt_done

my $tag = $ae->decrypt_done;           # devuelve el valor de $tag
# o
my $result = $ae->decrypt_done($tag);  # devuelve 1 (éxito) o 0 (fallo)

set_iv

my $ae = Crypt::AuthEnc::ChaCha20Poly1305->new($key)->set_iv($iv);
# $iv ...... vector de inicialización (64 o 96 bits / 8 o 12 bytes)

set_iv_rfc7905

Ver https://tools.ietf.org/html/rfc7905

my $ae = Crypt::AuthEnc::ChaCha20Poly1305->new($key)->set_iv_rfc7905($iv, $seqnum);
# $iv ...... vector de inicialización (96 bits / 12 bytes)
# $seqnum .. entero de 64 bits (número de secuencia)

clone

my $ae_new = $ae->clone;
