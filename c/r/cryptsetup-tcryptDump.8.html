CRYPTSETUP-TCRYPTDUMP(8) Comandos de mantenimiento CRYPTSETUP-TCRYPTDUMP(8)

NOMBRE

cryptsetup-tcryptDump - vuelca la información de cabecera de un dispositivo TCRYPT (compatible con TrueCrypt o VeraCrypt)

SINOPSIS

cryptsetup tcryptDump [<opciones>] <dispositivo>

DESCRIPCIÓN

Vuelca la información de cabecera de un dispositivo TCRYPT (compatible con TrueCrypt o VeraCrypt).

Si se usa la opción --dump-volume-key, se vuelca la clave de volumen del dispositivo TCRYPT en lugar de la información de la cabecera TCRYPT. Tenga cuidado, ya que la clave de volumen (o las claves de volumen concatenadas si se usa una cadena de cifrado) puede usarse para descifrar los datos almacenados en el contenedor TCRYPT sin una frase de paso. Esto significa que, si la clave de volumen se ve comprometida, hay que borrar todo el dispositivo para evitar un acceso posterior. Use esta opción con cuidado.

La opción --key-file permite una combinación del contenido de un archivo con la frase de paso. La opción --key-file se puede repetir. Tenga en cuenta que el uso de archivos de claves difiere de la lógica de archivos de claves de LUKS.

<opciones> puede ser [--dump-volume-key, --key-file, --tcrypt-hidden, --tcrypt-system, --tcrypt-backup, --veracrypt (ignorado), --disable-veracrypt, --veracrypt-pim, --veracrypt-query-pim, --cipher, --hash, --header, --verify-passphrase, --timeout].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si no se especifica la opción --verify-passphrase, esta opción también desactiva la verificación de la frase de paso.

--cipher, -c <especificación de cifrado>

Establece la cadena de especificación de cifrado para el tipo de dispositivo plain .

Para el tipo de dispositivo tcrypt , restringe las cadenas de cifrado comprobadas al buscar la cabecera.

--debug o --debug-json

Se ejecuta en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre llevan el prefijo #.

Si se usa --debug-json, se imprimen además las estructuras de datos JSON de LUKS2.

--disable-veracrypt

Esta opción se puede usar para desactivar el modo compatible con VeraCrypt (solo se reconocen los dispositivos TrueCrypt). Véase la sección TCRYPT en cryptsetup(8) para más información.

--dump-volume-key, --master-key (alias OBSOLETO)

Imprime la clave de volumen en la información mostrada. Úselo con cuidado, ya que la clave de volumen puede usarse para eludir las frases de paso; véase también la opción --volume-key-file.

--hash, -h <especificación de hash>

Especifica el hash de la frase de paso. Se aplica solo a los tipos de dispositivo plain y loopaes .

Para el tipo de dispositivo tcrypt , restringe las variantes de PBKDF2 comprobadas al buscar la cabecera.

--header <dispositivo o archivo que almacena la cabecera LUKS>

Usa un dispositivo o archivo de metadatos desprendido (separado) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para los comandos que cambian la cabecera LUKS (por ejemplo, luksAddKey), especifique el dispositivo o archivo con la cabecera LUKS directamente como el dispositivo LUKS.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--key-file, -d archivo

Lee la frase de paso del archivo.

Si el nombre dado es "-", la frase de paso se leerá desde stdin. En este caso, la lectura no se detendrá en los caracteres de salto de línea.

Véase la sección NOTAS SOBRE EL PROCESAMIENTO DE FRASES DE PASO en cryptsetup(8) para más información.

--tcrypt-backup, --tcrypt-hidden, --tcrypt-system

Especifica qué cabecera de TrueCrypt en disco se usará para abrir el dispositivo. Véase la sección TCRYPT en cryptsetup(8) para más información.

El uso de un dispositivo cifrado por el sistema con la opción --tcrypt-system requiere configuraciones específicas para que funcione como se espera.

TrueCrypt/VeraCrypt admite el cifrado completo del sistema (solo la tabla de particiones no se cifra) o el cifrado de la partición del sistema (solo se cifra una partición del sistema). La cabecera de metadatos contiene entonces el desplazamiento y el tamaño del área cifrada. Cryptsetup necesita conocer el desplazamiento específico de la partición para calcular los parámetros de cifrado. Para mapear correctamente una partición, debe especificar un dispositivo de partición real para que cryptsetup pueda calcular este desplazamiento.

Aunque puede usar un dispositivo completo como parámetro (/dev/sdb), prefiera siempre especificar la partición que desea mapear (/dev/sdb1), ya que solo de este modo se puede detectar el modo de partición del sistema.

Para mapear imágenes (almacenadas en un archivo), puede usar la opción adicional --header con el dispositivo de partición real. Si se usa --header (y es distinto de la imagen de datos), cryptsetup espera que la imagen de datos contenga solo una instantánea de la partición de datos.

Si no se usa --header (o apunta a la misma imagen), cryptsetup espera que la imagen contenga un disco completo (incluida la tabla de particiones). Esto puede mapear un área cifrada completa que no se puede montar directamente como sistema de archivos. Prefiera crear un dispositivo de bucle con particiones (losetup -P, véase la página de manual losetup(8) ) y usar una partición real (/dev/loopXp1) como parámetro de dispositivo.

--timeout, -t segundos

El número de segundos de espera antes de que se agote el tiempo de entrada de la frase de paso a través del terminal. Es relevante cada vez que se pide una frase de paso. No tiene efecto si se usa junto con --key-file.

Esta opción es útil cuando el sistema no debe bloquearse si el usuario no introduce una frase de paso, por ejemplo, durante el arranque. El valor predeterminado es 0 segundos, lo que significa esperar indefinidamente.

--usage

Muestra la ayuda breve de las opciones.

--veracrypt

Esta opción se ignora, ya que el modo compatible con VeraCrypt se admite de forma predeterminada.

--veracrypt-pim, --veracrypt-query-pim

Usa un Multiplicador de Iteraciones Personalizado (PIM) personalizado para el dispositivo VeraCrypt. Véase la sección TCRYPT en cryptsetup(8) para más información.

--verify-passphrase, -y

Cuando se pide una frase de paso de forma interactiva, la pide dos veces y se queja si las dos entradas no coinciden. Se ignora en la entrada desde un archivo o stdin.

--version, -V

Muestra la versión del programa.

INFORME DE ERRORES

Informe de errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de Issues del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Adjunte por favor la salida del comando fallido con la opción --debug añadida.
