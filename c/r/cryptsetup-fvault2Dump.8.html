CRYPTSETUP-FVAULT2DUMP(8) Comandos de mantenimiento CRYPTSETUP-FVAULT2DUMP(8)

NOMBRE

cryptsetup-fvault2Dump - volcar la información de cabecera de un dispositivo FVAULT2 (compatible con FileVault2)

SINOPSIS

cryptsetup fvault2Dump [<opciones>] <dispositivo>

DESCRIPCIÓN

Vuelca la información de cabecera de un dispositivo FVAULT2 (compatible con FileVault2).

Si se utiliza la opción --dump-volume-key, se vuelca la clave de volumen del dispositivo FVAULT2 en lugar de la información de cabecera. Debe proporcionar una contraseña o un archivo de clave para volcar la clave de volumen.

Tenga en cuenta que la clave de volumen se puede utilizar para descifrar los datos almacenados en el contenedor sin una contraseña. Esto significa que si la clave de volumen se ve comprometida, todo el dispositivo debe ser borrado para evitar un acceso posterior. Utilice esta opción con cuidado.

<opciones> pueden ser [--dump-volume-key, --volume-key-file, --key-file, --keyfile-offset, --keyfile-size, --timeout].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si la opción --verify-passphrase no se especifica, esta opción también desactiva la verificación de la contraseña.

--debug o --debug-json

Ejecutar en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre van precedidas por #.

Si se utiliza --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--dump-volume-key, --dump-master-key (alias OBSOLETO)

Imprime la clave de volumen en la información mostrada. Usar con cuidado, ya que la clave de volumen se puede utilizar para eludir las contraseñas, ver también la opción --volume-key-file.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--key-file, -d archivo

Lee la contraseña del archivo.

Si el nombre dado es "-", la contraseña se leerá desde la entrada estándar. En este caso, la lectura no se detendrá en los caracteres de nueva línea.

Consulte la sección NOTAS SOBRE EL PROCESAMIENTO DE CONTRASEÑAS en cryptsetup(8) para obtener más información.

--keyfile-offset valor

Omite valor bytes al principio del archivo de clave.

--keyfile-size, -l valor

Lee un máximo de valor bytes del archivo de clave. El valor predeterminado es leer todo el archivo hasta el máximo compilado que se puede consultar con --help. Suministrar más datos que el máximo compilado aborta la operación.

Esta opción es útil para cortar las nuevas líneas finales, por ejemplo. Si también se proporciona --keyfile-offset, el recuento del tamaño comienza después del desplazamiento.

--timeout, -t segundos

El número de segundos a esperar antes de un tiempo de espera en la entrada de la contraseña a través de la terminal. Es relevante cada vez que se solicita una contraseña. No tiene ningún efecto si se utiliza junto con --key-file.

Esta opción es útil cuando el sistema no debe detenerse si el usuario no introduce una contraseña, por ejemplo, durante el arranque. El valor predeterminado es 0 segundos, lo que significa esperar indefinidamente.

--usage

Muestra una ayuda breve de las opciones.

--version, -V

Muestra la versión del programa.

--volume-key-file archivo, --master-key-file archivo (alias OBSOLETO)

Utiliza una clave de volumen almacenada en un archivo.

La clave de volumen se almacena en un archivo en lugar de imprimirse en la salida estándar.

REPORTE DE ERRORES

Reporte errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de incidencias del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Adjunte la salida del comando fallido con la opción --debug añadida.
