NOMBRE

cryptsetup-luksHeaderRestore - restaura una copia de seguridad binaria de la cabecera LUKS y el área de claves

SINOPSIS

cryptsetup luksHeaderRestore --header-backup-file <archivo> [<opciones>] <dispositivo>

DESCRIPCIÓN

Restaura una copia de seguridad binaria de la cabecera LUKS y el área de claves desde el archivo especificado.

Usar '-' como nombre de archivo lee la copia de seguridad de la cabecera desde un archivo llamado '-'.

Todas las ranuras de claves serán reemplazadas; solo las contraseñas de la copia de seguridad funcionarán después.

Este comando requiere que el tamaño de la clave del volumen y el desplazamiento de datos de la cabecera LUKS y la copia de seguridad coincidan. Alternativamente, la copia de seguridad también se escribirá si el dispositivo no tiene una cabecera LUKS.

<opciones> pueden ser [--header, --header-backup-file, --disable-locks].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si la opción --verify-passphrase no está especificada, esta opción también desactiva la verificación de la contraseña.

--debug o --debug-json

Ejecutar en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre van precedidas por #.

Si se utiliza --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--disable-locks

Deshabilita la protección de bloqueo para metadatos en el disco. Esta opción solo es válida para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No utilice esta opción a menos que ejecute cryptsetup en un entorno restringido donde sea imposible realizar el bloqueo (donde no se pueda utilizar el directorio /run).

--header <dispositivo o archivo que almacena la cabecera LUKS>

Utilice un dispositivo o archivo de metadatos separado (desvinculado) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para comandos que cambian la cabecera LUKS (por ejemplo, luksAddKey), especifique el dispositivo o archivo con la cabecera LUKS directamente como el dispositivo LUKS.

--header-backup-file archivo

Especifique un archivo con la copia de seguridad de la cabecera.

--help, -?

Mostrar texto de ayuda y parámetros predeterminados.

--usage

Mostrar ayuda de opciones cortas.

--version, -V

Mostrar la versión del programa.

INFORMAR ERRORES

Reporte errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de Issues del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Por favor, adjunte la salida del comando fallido con la opción --debug añadida.
