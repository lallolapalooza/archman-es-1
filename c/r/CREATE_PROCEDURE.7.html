NOTAS

Consulte CREATE FUNCTION (CREATE_FUNCTION(7)) para más detalles sobre la creación de funciones, lo cual también se aplica a los procedimientos.

Utilice CALL(7) para ejecutar un procedimiento.

EJEMPLOS

CREATE PROCEDURE insert_data(a integer, b integer)
LANGUAGE SQL
AS $$
INSERT INTO tbl VALUES (a);
INSERT INTO tbl VALUES (b);
$$;

o

CREATE PROCEDURE insert_data(a integer, b integer)
LANGUAGE SQL
BEGIN ATOMIC
  INSERT INTO tbl VALUES (a);
  INSERT INTO tbl VALUES (b);
END;

y llame de esta manera:

CALL insert_data(1, 2);

COMPATIBILIDAD

Un CREATE PROCEDURE comando está definido en el estándar SQL. La implementación de PostgreSQL puede usarse de forma compatible pero tiene muchas extensiones. Para más detalles, consulte también CREATE FUNCTION (CREATE_FUNCTION(7)).
