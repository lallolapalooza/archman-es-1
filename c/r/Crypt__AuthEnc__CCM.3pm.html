Crypt::AuthEnc::CCM(3) Documentación de Perl contribuida por el usuario Crypt::AuthEnc::CCM(3)

NOMBRE

Crypt::AuthEnc::CCM - Cifrado autenticado en modo CCM

SINOPSIS

### Interfaz OO
use Crypt::AuthEnc::CCM;
# cifrar y autenticar
my $ae = Crypt::AuthEnc::CCM->new("AES", $key, $iv, $adata, $tag_len, $pt_len);
my $ct = $ae->encrypt_add('datos1');
$ct .= $ae->encrypt_add('datos2');
$ct .= $ae->encrypt_add('datos3');
my $tag = $ae->encrypt_done();
# descifrar y verificar
my $ae = Crypt::AuthEnc::CCM->new("AES", $key, $iv, $adata, $tag_len, $pt_len);
my $pt = $ae->decrypt_add('cifradodatos1');
$pt .= $ae->decrypt_add('cifradodatos2');
$pt .= $ae->decrypt_add('cifradodatos3');
my $tag = $ae->decrypt_done();
die "descifrado fallido" unless $tag eq $expected_tag;
#o
my $result = $ae->decrypt_done($expected_tag); # 0 o 1
### Interfaz funcional
use Crypt::AuthEnc::CCM qw(ccm_encrypt_authenticate ccm_decrypt_verify);
($ciphertext, $tag) = ccm_encrypt_authenticate('AES', $key, $nonce, $adata, $tag_len, $plaintext);
$plaintext = ccm_decrypt_verify('AES', $key, $nonce, $adata, $ciphertext, $tag);

DESCRIPCIÓN

CCM es un modo de cifrado+autenticación centrado en el uso de AES (o cualquier cifrado de 16 bytes) como primitiva. A diferencia de los modos EAX y OCB, solo está diseñado para modo de paquete donde la longitud de la entrada se conoce de antemano.

EXPORTACIÓN

No se exporta nada por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::AuthEnc::CCM qw(ccm_encrypt_authenticate ccm_decrypt_verify);

FUNCIONES

ccm_encrypt_authenticate

my ($ciphertext, $tag) = ccm_encrypt_authenticate($cipher, $key, $nonce, $adata, $tag_len, $plaintext);
# $cipher .. 'AES' o nombre de cualquier otro cifrador con longitud de bloque de 16 bytes
# $key ..... clave de longitud adecuada (p. ej., 128/192/256 bits para AES)
# $nonce ... nonce/sal único (no es necesario mantenerlo en secreto)
# $adata ... datos autenticados adicionales
# $tag_len . longitud requerida de la etiqueta de salida

Los parámetros de CCM deben seguir http://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-38c.pdf

# longitud de la etiqueta:   4, 6, 8, 10, 12, 14, 16 (mínimo razonable es 8)
# longitud del nonce: 7, 8, 9, 10, 11, 12, 13 (si no estás seguro, usa 11)
# CUIDADO: la longitud del nonce determina el tamaño máximo de datos cifrados/descifrados: max_data_size = 2^(8*(15-nonce_len))

ccm_decrypt_verify

my $plaintext = ccm_decrypt_verify($cipher, $key, $nonce, $adata, $ciphertext, $tag);
# en caso de error devuelve undef

MÉTODOS

new

my $ae = Crypt::AuthEnc::CCM->new($cipher, $key, $nonce, $adata, $tag_len, $pt_len);
# $cipher .. 'AES' o nombre de cualquier otro cifrador con longitud de bloque de 16 bytes
# $key ..... clave de longitud adecuada (p. ej., 128/192/256 bits para AES)
# $nonce ... nonce/sal único (no es necesario mantenerlo en secreto)
# $adata ... datos autenticados adicionales
# $tag_len . longitud requerida de la etiqueta de salida
# $pt_len .. longitud esperada del texto plano/cifrado para cifrar/descifrar

encrypt_add

$ciphertext = $ae->encrypt_add($data);        # se puede llamar varias veces

encrypt_done

my $tag = $ae->encrypt_done;                  # devuelve el valor de $tag

decrypt_add

$plaintext = $ae->decrypt_add($ciphertext);   # se puede llamar varias veces

decrypt_done

my $tag = $ae->decrypt_done;           # devuelve el valor de $tag
#o
my $result = $ae->decrypt_done($tag);  # devuelve 1 (éxito) o 0 (fallo)

clone

my $ae_new = $ae->clone;
