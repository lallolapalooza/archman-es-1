Crypt::Checksum::CRC32(3) Documentación de Perl contribuida por el usuario Crypt::Checksum::CRC32(3)

NOMBRE

Crypt::Checksum::CRC32 - Calcular checksum CRC32

SINOPSIS

### Interfaz funcional:
use Crypt::Checksum::CRC32 ':all';
# calcular checksum CRC32 desde cadena/buffer
$checksum_raw  = crc32_data($data);
$checksum_hex  = crc32_data_hex($data);
$checksum_int  = crc32_data_int($data);
# calcular checksum CRC32 desde archivo
$checksum_raw  = crc32_file('nombre_archivo.dat');
$checksum_hex  = crc32_file_hex('nombre_archivo.dat');
$checksum_int  = crc32_file_int('nombre_archivo.dat');
# calcular checksum CRC32 desde filehandle
$checksum_raw  = crc32_file(*FILEHANDLE);
$checksum_hex  = crc32_file_hex(*FILEHANDLE);
$checksum_int  = crc32_file_int(*FILEHANDLE);
### Interfaz OO:
use Crypt::Checksum::CRC32;
$d = Crypt::Checksum::CRC32->new;
$d->add('cualquier dato');
$d->add('más datos');
$d->addfile('nombre_archivo.dat');
$d->addfile(*FILEHANDLE);
$checksum_raw = $d->digest;     # 4 bytes en bruto
$checksum_hex = $d->hexdigest;  # forma hexadecimal
$checksum_int = $d->intdigest;  # entero sin signo de 32 bits

DESCRIPCIÓN

Cálculo de checksums CRC32.

Actualizado: v0.057

EXPORTACIÓN

No se exporta nada por defecto.

Puedes exportar funciones seleccionadas:

use Crypt::Checksum::CRC32 qw(crc32_data crc32_data_hex crc32_data_int crc32_file crc32_file_hex crc32_file_int);

O todas a la vez:

use Crypt::Checksum::CRC32 ':all';

FUNCIONES

crc32_data

Devuelve el checksum como octetos brutos.

$checksum_raw = crc32_data('cadena de datos');
# o
$checksum_raw = crc32_data('cualquier dato', 'más datos', 'aún más datos');

crc32_data_hex

Devuelve el checksum como una cadena hexadecimal.

$checksum_hex = crc32_data_hex('cadena de datos');
# o
$checksum_hex = crc32_data_hex('cualquier dato', 'más datos', 'aún más datos');

crc32_data_int

Devuelve el checksum como un entero sin signo de 32 bits.

$checksum_int = crc32_data_int('cadena de datos');
# o
$checksum_int = crc32_data_int('cualquier dato', 'más datos', 'aún más datos');

crc32_file

Devuelve el checksum como octetos brutos.

$checksum_raw = crc32_file('nombre_archivo.dat');
# o
$checksum_raw = crc32_file(*FILEHANDLE);

crc32_file_hex

Devuelve el checksum como una cadena hexadecimal.

$checksum_hex = crc32_file_hex('nombre_archivo.dat');
# o
$checksum_hex = crc32_file_hex(*FILEHANDLE);

crc32_file_int

Devuelve el checksum como un entero sin signo de 32 bits.

$checksum_int = crc32_file_int('nombre_archivo.dat');
# o
$checksum_int = crc32_file_int(*FILEHANDLE);

MÉTODOS

new

Constructor, devuelve una referencia al objeto checksum.

$d = Crypt::Checksum::CRC32->new;

clone

Crea una copia del estado del objeto checksum y devuelve una referencia a la copia.

$d->clone();

reset

Reinicializa el estado del objeto checksum y devuelve una referencia al objeto checksum.

$d->reset();

add

Todos los argumentos se añaden al mensaje para el cual calculamos el checksum. El valor de retorno es el propio objeto checksum.

$d->add('cualquier dato');
# o
$d->add('cualquier dato', 'más datos', 'aún más datos');

addfile

El contenido del archivo (o filehandle) se añade al mensaje para el cual calculamos el checksum. El valor de retorno es el propio objeto checksum.

$d->addfile('nombre_archivo.dat');
# o
$d->addfile(*FILEHANDLE);

¡CUIDADO!: Debes asegurarte de que el filehandle esté en modo binario antes de pasarlo como argumento al método addfile().

digest

Devuelve el checksum binario (bytes brutos).

$result_raw = $d->digest();

hexdigest

Devuelve el checksum codificado como una cadena hexadecimal.

$result_hex = $d->hexdigest();

intdigest

Devuelve el checksum codificado como un entero sin signo de 32 bits.

$result_int = $d->intdigest();
