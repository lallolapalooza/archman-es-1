CRYPTSETUP-LUKSREMOVEKEY(8) Comandos de Mantenimiento CRYPTSETUP-LUKSREMOVEKEY(8)

NOMBRE

cryptsetup-luksRemoveKey - eliminar la frase de contraseña proporcionada del dispositivo LUKS

SINOPSIS

cryptsetup luksRemoveKey [<opciones>] <dispositivo> [<archivo de clave con la frase de contraseña a eliminar>]

DESCRIPCIÓN

Elimina la frase de contraseña proporcionada del dispositivo LUKS. La frase de contraseña a eliminar se puede especificar interactivamente, como argumento posicional o mediante --key-file.

Si lee la frase de contraseña desde stdin (sin argumentos adicionales o con '-' como argumento para --key-file), el modo por lotes (-q) se activará implícitamente y no se mostrará ninguna advertencia al eliminar la última frase de contraseña restante de un contenedor LUKS. Eliminar la última frase de contraseña hace que el contenedor LUKS sea permanentemente inaccesible.

Esta operación elimina solo la clave en una ranura de clave específica; no borra ningún dato cifrado.

<opciones> pueden ser [--key-file, --keyfile-offset, --keyfile-size, --header, --disable-locks, --type, --timeout, --verify-passphrase].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si no se especifica la opción --verify-passphrase, esta opción también desactiva la verificación de la frase de contraseña.

--debug o --debug-json

Ejecutar en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre están prefijadas con #.

Si se usa --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--disable-locks

Deshabilita la protección de bloqueo para metadatos en el disco. Esta opción solo es válida para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No use esta opción a menos que ejecute cryptsetup en un entorno restringido donde el bloqueo sea imposible de realizar (donde el directorio /run no pueda usarse).

--header <dispositivo o archivo que almacena la cabecera LUKS>

Utiliza un dispositivo o archivo de metadatos separado (desacoplado) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para comandos que cambian la cabecera LUKS (por ejemplo, luksAddKey), especifique directamente el dispositivo o archivo con la cabecera LUKS como el dispositivo LUKS.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--key-file, -d archivo

Lee la frase de contraseña del archivo.

Si el nombre dado es "-", entonces la frase de contraseña se leerá de stdin. En este caso, la lectura no se detendrá en los caracteres de nueva línea.

Consulte la sección NOTAS SOBRE EL PROCESAMIENTO DE FRASES DE CONTRASEÑA en cryptsetup(8) para obtener más información.

--keyfile-offset valor

Omite valor bytes al principio del archivo de clave.

--keyfile-size, -l valor

Lee un máximo de valor bytes del archivo de clave. El valor predeterminado es leer el archivo completo hasta el máximo compilado que se puede consultar con --help. Proporcionar más datos que el máximo compilado aborta la operación.

Esta opción es útil para eliminar saltos de línea finales, por ejemplo. Si también se proporciona --keyfile-offset, el recuento del tamaño comienza después del desplazamiento.

--timeout, -t segundos

El número de segundos a esperar antes de un tiempo de espera en la entrada de la frase de contraseña a través de la terminal. Es relevante cada vez que se solicita una frase de contraseña. No tiene efecto si se usa junto con --key-file.

Esta opción es útil cuando el sistema no debe detenerse si el usuario no introduce una frase de contraseña, por ejemplo, durante el arranque. El valor predeterminado es 0 segundos, lo que significa esperar indefinidamente.

--type tipo

Especifica el tipo de dispositivo requerido, para más información, lea la sección ACCIONES BÁSICAS en cryptsetup(8).

--usage

Muestra una ayuda breve de las opciones.

--verify-passphrase, -y

Al solicitar interactivamente una frase de contraseña, solicítela dos veces y quejarse si ambas entradas no coinciden. Ignorado en la entrada desde archivo o stdin.

--version, -V

Muestra la versión del programa.

INFORMAR ERRORES

Informe de errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de problemas del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Adjunte la salida del comando fallido con la opción --debug añadida.
