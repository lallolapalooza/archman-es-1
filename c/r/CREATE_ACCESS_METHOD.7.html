CREATE_ACCESS_METHOD(7)

Paquete: postgresql

Licencias: PostgreSQL

CREATE ACCESS METHOD(7) Documentación de PostgreSQL 18.1 CREATE ACCESS METHOD(7)

NOMBRE

CREATE_ACCESS_METHOD - definir un nuevo método de acceso

SINOPSIS

CREATE ACCESS METHOD nombre
    TYPE tipo_de_metodo_de_acceso
    HANDLER funcion_manejadora

DESCRIPCIÓN

CREATE ACCESS METHOD crea un nuevo método de acceso.

El nombre del método de acceso debe ser único dentro de la base de datos.

Solo los superusuarios pueden definir nuevos métodos de acceso.

PARÁMETROS

nombre

El nombre del método de acceso a crear.

tipo_de_metodo_de_acceso

Esta cláusula especifica el tipo de método de acceso a definir. Actualmente solo se admiten TABLE e INDEX.

funcion_manejadora

funcion_manejadora es el nombre (posiblemente calificado por esquema) de una función previamente registrada que representa el método de acceso. La función manejadora debe declararse para aceptar un único argumento de tipo `internal`, y su tipo de retorno depende del tipo de método de acceso; para métodos de acceso TABLE, debe ser `table_am_handler` y para métodos de acceso INDEX, debe ser `index_am_handler`. La API a nivel C que la función manejadora debe implementar varía según el tipo de método de acceso. La API del método de acceso de tabla se describe en el Capítulo 62 y la API del método de acceso de índice se describe en el Capítulo 63.

EJEMPLOS

Crear un método de acceso de índice `heptree` con la función manejadora `heptree_handler`:

CREATE ACCESS METHOD heptree TYPE INDEX HANDLER heptree_handler;

COMPATIBILIDAD

CREATE ACCESS METHOD es una extensión de PostgreSQL.

VER TAMBIÉN

DROP ACCESS METHOD (DROP_ACCESS_METHOD(7)), CREATE OPERATOR CLASS (CREATE_OPERATOR_CLASS(7)), CREATE OPERATOR FAMILY (CREATE_OPERATOR_FAMILY(7))
