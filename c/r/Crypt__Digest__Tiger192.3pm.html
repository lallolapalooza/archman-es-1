Crypt::Digest::Tiger192(3) Documentación de Perl aportada por el usuario Crypt::Digest::Tiger192(3)

NOMBRE

Crypt::Digest::Tiger192 - Función de hash Tiger-192 [tamaño: 192 bits]

SINOPSIS

### Interfaz funcional:
use Crypt::Digest::Tiger192 qw( tiger192 tiger192_hex tiger192_b64 tiger192_b64u
                             tiger192_file tiger192_file_hex tiger192_file_b64 tiger192_file_b64u );
# calcular el resumen a partir de una cadena/búfer
$tiger192_raw  = tiger192('cadena de datos');
$tiger192_hex  = tiger192_hex('cadena de datos');
$tiger192_b64  = tiger192_b64('cadena de datos');
$tiger192_b64u = tiger192_b64u('cadena de datos');
# calcular el resumen a partir de un archivo
$tiger192_raw  = tiger192_file('nombrearchivo.dat');
$tiger192_hex  = tiger192_file_hex('nombrearchivo.dat');
$tiger192_b64  = tiger192_file_b64('nombrearchivo.dat');
$tiger192_b64u = tiger192_file_b64u('nombrearchivo.dat');
# calcular el resumen a partir de un manejador de archivo
$tiger192_raw  = tiger192_file(*FILEHANDLE);
$tiger192_hex  = tiger192_file_hex(*FILEHANDLE);
$tiger192_b64  = tiger192_file_b64(*FILEHANDLE);
$tiger192_b64u = tiger192_file_b64u(*FILEHANDLE);
### Interfaz orientada a objetos:
use Crypt::Digest::Tiger192;
$d = Crypt::Digest::Tiger192->new;
$d->add('cualquier dato');
$d->addfile('nombrearchivo.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->digest;     # bytes crudos
$result_hex  = $d->hexdigest;  # forma hexadecimal
$result_b64  = $d->b64digest;  # forma Base64
$result_b64u = $d->b64udigest; # forma Base64 segura para URL

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de resumen Tiger192.

EXPORTACIÓN

No se exporta nada por defecto.

Puede exportar funciones seleccionadas:

use Crypt::Digest::Tiger192 qw(tiger192 tiger192_hex tiger192_b64 tiger192_b64u
                                    tiger192_file tiger192_file_hex tiger192_file_b64 tiger192_file_b64u);

O todas a la vez:

use Crypt::Digest::Tiger192 ':all';

FUNCIONES

tiger192

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen Tiger192 codificado como una cadena binaria.

$tiger192_raw = tiger192('cadena de datos');
#o
$tiger192_raw = tiger192('cualquier dato', 'más datos', 'aún más datos');

tiger192_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen Tiger192 codificado como una cadena hexadecimal.

$tiger192_hex = tiger192_hex('cadena de datos');
#o
$tiger192_hex = tiger192_hex('cualquier dato', 'más datos', 'aún más datos');

tiger192_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen Tiger192 codificado como una cadena Base64, con relleno '=' al final.

$tiger192_b64 = tiger192_b64('cadena de datos');
#o
$tiger192_b64 = tiger192_b64('cualquier dato', 'más datos', 'aún más datos');

tiger192_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su resumen Tiger192 codificado como una cadena Base64 segura para URL (véase la sección 5 del RFC 4648).

$tiger192_b64url = tiger192_b64u('cadena de datos');
#o
$tiger192_b64url = tiger192_b64u('cualquier dato', 'más datos', 'aún más datos');

tiger192_file

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen Tiger192 codificado como una cadena binaria.

$tiger192_raw = tiger192_file('nombrearchivo.dat');
#o
$tiger192_raw = tiger192_file(*FILEHANDLE);

tiger192_file_hex

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen Tiger192 codificado como una cadena hexadecimal.

$tiger192_hex = tiger192_file_hex('nombrearchivo.dat');
#o
$tiger192_hex = tiger192_file_hex(*FILEHANDLE);

ADVERTENCIA: Debe asegurarse de que el manejador de archivo esté en modo binario antes de pasarlo como argumento al método addfile().

tiger192_file_b64

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen Tiger192 codificado como una cadena Base64, con relleno '=' al final.

$tiger192_b64 = tiger192_file_b64('nombrearchivo.dat');
#o
$tiger192_b64 = tiger192_file_b64(*FILEHANDLE);

tiger192_file_b64u

Lee el contenido del archivo (definido por nombre de archivo o manejador de archivo) y devuelve su resumen Tiger192 codificado como una cadena Base64 segura para URL (véase la sección 5 del RFC 4648).

$tiger192_b64url = tiger192_file_b64u('nombrearchivo.dat');
#o
$tiger192_b64url = tiger192_file_b64u(*FILEHANDLE);

MÉTODOS

La interfaz orientada a objetos proporciona el mismo conjunto de funciones que Crypt::Digest.

new

$d = Crypt::Digest::Tiger192->new();

clone

$d->clone();

reset

$d->reset();

add

$d->add('cualquier dato');
#o
$d->add('cualquier dato', 'más datos', 'aún más datos');

addfile

$d->addfile('nombrearchivo.dat');
#o
$d->addfile(*FILEHANDLE);

add_bits

$d->add_bits($bit_string);   # p. ej. $d->add_bits("111100001010");
#o
$d->add_bits($data, $nbits); # p. ej. $d->add_bits("\xF0\xA0", 16);

hashsize

$d->hashsize;
#o
Crypt::Digest::Tiger192->hashsize();
#o
Crypt::Digest::Tiger192::hashsize();

digest

$result_raw = $d->digest();

hexdigest

$result_hex = $d->hexdigest();

b64digest

$result_b64 = $d->b64digest();

b64udigest

$result_b64url = $d->b64udigest();
