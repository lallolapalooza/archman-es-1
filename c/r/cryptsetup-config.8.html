CRYPTSETUP-CONFIG(8) Comandos de mantenimiento CRYPTSETUP-CONFIG(8)

NOMBRE

cryptsetup-config - establece opciones de configuración permanentes (almacena en la cabecera LUKS)

SINOPSIS

cryptsetup config <opciones> <dispositivo>

DESCRIPCIÓN

Establece opciones de configuración permanentes (almacena en la cabecera LUKS). El comando config solo se admite para LUKS2.

Las opciones permanentes pueden ser --priority para establecer la prioridad (normal, preferir, ignorar) para una ranura de clave (especificada por --key-slot) o --label y --subsystem.

<opciones> pueden ser [--priority, --label, --subsystem, --key-slot, --header, --disable-locks].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con precaución!

Si no se especifica la opción --verify-passphrase, esta opción también desactiva la verificación de la contraseña.

--debug o --debug-json

Ejecutar en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre van precedidas por #.

Si se usa --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--disable-locks

Desactiva la protección de bloqueo para metadatos en disco. Esta opción solo es válida para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No utilice esta opción a menos que ejecute cryptsetup en un entorno restringido donde el bloqueo sea imposible de realizar (donde no se pueda usar el directorio /run).

--header <dispositivo o archivo que almacena la cabecera LUKS>

Utiliza un dispositivo o archivo de metadatos separado (desconectado) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para comandos que modifican la cabecera LUKS (por ejemplo, luksAddKey), especifique directamente el dispositivo o archivo con la cabecera LUKS como el dispositivo LUKS.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--key-slot, -S <0-N>

Para operaciones LUKS que agregan material de clave, esta opción le permite especificar qué ranura de clave se selecciona para la nueva clave.

El número máximo de ranuras de clave depende de la versión de LUKS. LUKS1 puede tener hasta 8 ranuras de clave. LUKS2 puede tener hasta 32 ranuras de clave basándose en el tamaño del área de ranura de clave y el tamaño de la clave, pero un ID de ranura de clave válido siempre puede estar entre 0 y 31 para LUKS2.

--label <etiqueta>, --subsystem <subsistema>

Establece la etiqueta y la descripción del subsistema para el dispositivo LUKS2. Estos son similares a las etiquetas del sistema de archivos. La etiqueta y el subsistema son campos opcionales y pueden usarse posteriormente en scripts de udev para activar acciones del usuario una vez que se detecta el dispositivo marcado por estas etiquetas.

--priority <normal|prefer|ignore>

Establece una prioridad para la ranura de clave LUKS2. Las ranuras marcadas con prioridad prefer se intentan antes que las de prioridad normal. La prioridad ignore significa que la ranura nunca se usa, a menos que se solicite explícitamente con la opción --key-slot.

--usage

Muestra una ayuda breve de opciones.

--version, -V

Muestra la versión del programa.

REPORTAR ERRORES

Reporte errores a la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de incidencias del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Por favor, adjunte la salida del comando fallido con la opción --debug añadida.
