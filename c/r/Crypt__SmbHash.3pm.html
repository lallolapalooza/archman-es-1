NOMBRE

Crypt::SmbHash - Implementación en Perl de las funciones hash lanman y nt md4, para su uso en entradas smbpasswd estilo Samba

SINOPSIS

use Crypt::SmbHash;
ntlmgen ESCALAR, LMSCALAR, NTSCALAR;

DESCRIPCIÓN

Este módulo genera hashes de contraseña estilo Lanman y NT MD4, utilizando código exclusivo de Perl para mayor portabilidad. El módulo ayuda en la administración de sistemas estilo Samba.

En la distribución Samba, la autenticación se refiere a un archivo privado smbpasswd. Las entradas tienen formas similares a las siguientes:

nombre_usuario:uid_unix:LM:NT

Donde LM y NT son hashes de contraseña unidireccionales de la misma contraseña.

ntlmgen genera los hashes proporcionados en el primer argumento y coloca el resultado en el segundo y tercer argumento.

Ejemplo: Para generar una entrada smbpasswd:

#!/usr/local/bin/perl 
use Crypt::SmbHash;
$username = $ARGV[0];
$password = $ARGV[1];
if ( !$password ) {
        print "No hay suficientes argumentos\n";
        print "Uso: $0 nombre_usuario contraseña\n";
        exit 1;
}
$uid = (getpwnam($username))[2];
my ($login,undef,$uid) = getpwnam($ARGV[0]);
ntlmgen $password, $lm, $nt;
printf "%s:%d:%s:%s:[%-11s]:LCT-%08X\n", $login, $uid, $lm, $nt, "U", time;

ntlmgen devuelve los valores hash en un contexto de lista, por lo que el método alternativo de usarlo es:

( $lm, $nt ) = ntlmgen $password;

Las funciones lmhash y nthash son utilizadas por ntlmgen para generar los hashes y están disponibles cuando se solicitan:

use Crypt::SmbHash qw(lmhash nthash)
$lm = lmhash($pass);
$nt = nthash($pass);

Si Encoding está disponible (parte de perl-5.8), el argumento $pass para ntlmgen, lmhash y nthash debe ser una cadena de Perl. En uso doble:

use Crypt::SmbHash qw(ntlmgen lmhash nthash);
use Encode;
( $lm, $nt ) = ntlmgen decode('iso-8859-1', $pass);
$lm = lmhash(decode_utf8($pass), $pwenc);
$nt = nthash(decode_utf8($pass));

El parámetro $pwenc para lmhash() es opcional y por defecto es 'iso-8859-1'. Especifica la codificación a la que se codifica la contraseña antes de hashear.

MD4

El algoritmo utilizado en nthash requiere el algoritmo md4. Este algoritmo está incluido en este módulo para completitud, pero debido a que está escrito íntegramente en Perl (en lugar de C), no es muy rápido.

Sin embargo, si tiene instalado el módulo Digest::MD4, Crypt::SmbHash intentará usar ese módulo en su lugar, haciéndolo mucho más rápido.

Una prueba simple comparando la llamada a nthash sin Digest::MD4 instalado, y con él, mostró que usar nthash en un sistema con Digest::MD4 instalado resultó ser más de 90 veces más rápido.
