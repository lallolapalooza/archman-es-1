NOMBRE

Crypt::Blowfish - Módulo de cifrado Blowfish para Perl

SINOPSIS

use Crypt::Blowfish;
my $cipher = new Crypt::Blowfish $key; 
my $ciphertext = $cipher->encrypt($plaintext);
my $plaintext  = $cipher->decrypt($ciphertext);
Probablemente querrás usar esto en conjunción con 
un módulo de encadenamiento de bloques como Crypt::CBC.

DESCRIPCIÓN

Blowfish es capaz de un cifrado fuerte y puede usar tamaños de clave de hasta 56 bytes (una clave de 448 bits). Te animamos a aprovechar el tamaño completo de la clave para garantizar el cifrado más fuerte posible de este módulo.

Crypt::Blowfish tiene los siguientes métodos:

blocksize()
keysize()
encrypt()
decrypt()

FUNCIONES

blocksize
Devuelve el tamaño (en bytes) del cifrado por bloques.

Crypt::Blowfish no devuelve un tamaño de clave debido a su capacidad de usar claves de longitud variable. Más precisamente, no debería hacerlo, pero lo hace de todos modos para interactuar bien con otros.

new
my $cipher = new Crypt::Blowfish $key;

Esto crea un nuevo objeto Crypt::Blowfish BlockCipher, usando $key, donde $key es una clave de keysize() bytes (mínimo ocho bytes).

encrypt
my $cipher = new Crypt::Blowfish $key;
my $ciphertext = $cipher->encrypt($plaintext);

Esta función cifra $plaintext y devuelve $ciphertext, donde $plaintext y $ciphertext deben ser de blocksize() bytes. (pista: Blowfish es un cifrado de bloques de 8 bytes)

decrypt
my $cipher = new Crypt::Blowfish $key;
my $plaintext = $cipher->decrypt($ciphertext);

Esta función descifra $ciphertext y devuelve $plaintext, donde $plaintext y $ciphertext deben ser de blocksize() bytes. (pista: ver pista anterior)

EJEMPLO

my $key = pack("H16", "0123456789ABCDEF");  # min. 8 bytes
my $cipher = new Crypt::Blowfish $key;
my $ciphertext = $cipher->encrypt("plaintex");  # VER NOTAS 
print unpack("H16", $ciphertext), "\n";

NOTAS

El módulo es capaz de ser utilizado con Crypt::CBC. Se te anima a leer la documentación de perldoc para Crypt::CBC si tienes la intención de utilizar este módulo para modos de encadenamiento de bloques de cifrado. De hecho, si tienes alguna intención de cifrar más de ocho bytes de datos con este, o cualquier otro cifrado de bloques, vas a necesitar **algún** tipo de ayuda de encadenamiento de bloques. Crypt::CBC tiende a ser muy bueno en esto. Si no vas a cifrar más de ocho bytes, tus datos deben ser **exactamente** de ocho bytes de longitud. Si es necesario, haz tu propio relleno. El carácter nulo ("\0") es perfectamente válido para usarlo para esto.
