update-cracklib(8) Manual del Administrador del Sistema update-cracklib(8)

NOMBRE

update-cracklib - Regenerar el diccionario de cracklib

SINOPSIS

update-cracklib

DESCRIPCIÓN

update-cracklib crea una versión comprimida y acumulada de las listas de palabras almacenadas en los directorios dados en el archivo de configuración de cracklib /etc/cracklib/cracklib.conf. Los programas que utilizan cracklib2 necesitan esta base de datos para ser útiles.

Por defecto, este script es llamado por cron todos los días.

RESULTADO

update-cracklib imprime dos números: el número de palabras leídas de los diccionarios ASCII y el número de palabras finalmente escritas en la base de datos de cracklib; si no hubo ningún error, estos deberían ser iguales.

Se devuelve 0 si la operación fue exitosa, de lo contrario se imprime un mensaje de error en la salida estándar y se devuelve -1.

ARCHIVOS

/etc/cracklib/cracklib.conf
script de shell que establece cracklib_dictpath_src, que debe ser una lista de archivos de diccionario de origen separados por espacios.

VER TAMBIÉN

cracklib(3), crack_mkdict(8)
