Paquete: postgresql

Licencias: PostgreSQL

CREATE TEXT SEARCH PARSER(7) Documentación de PostgreSQL 18.1 CREATE TEXT SEARCH PARSER(7)

NOMBRE

CREATE TEXT SEARCH PARSER - definir un nuevo analizador de búsqueda de texto

SINOPSIS

CREATE TEXT SEARCH PARSER nombre (
    START = función_inicio ,
    GETTOKEN = función_obtener_token ,
    END = función_fin ,
    LEXTYPES = función_tipos_léxicos
    [, HEADLINE = función_resumen ]
)

DESCRIPCIÓN

CREATE TEXT SEARCH PARSER crea un nuevo analizador de búsqueda de texto. Un analizador de búsqueda de texto define un método para dividir una cadena de texto en tokens y asignarles tipos (categorías). Un analizador por sí mismo no es particularmente útil, sino que debe ser enlazado en una configuración de búsqueda de texto junto con algunos diccionarios de búsqueda de texto para ser utilizado en la búsqueda.

Si se proporciona un nombre de esquema, el analizador de búsqueda de texto se crea en el esquema especificado. De lo contrario, se crea en el esquema actual.

Debes ser superusuario para usar CREATE TEXT SEARCH PARSER. (Esta restricción se hace porque una definición errónea del analizador de búsqueda de texto podría confundir o incluso colgar el servidor.)

Consulte el Capítulo 12 para obtener más información.

PARÁMETROS

nombre

El nombre del analizador de búsqueda de texto a crear. El nombre puede estar calificado por un esquema.

función_inicio

El nombre de la función de inicio para el analizador.

función_obtener_token

El nombre de la función para obtener el siguiente token del analizador.

función_fin

El nombre de la función de fin para el analizador.

función_tipos_léxicos

El nombre de la función de tipos léxicos para el analizador (una función que devuelve información sobre el conjunto de tipos de token que produce).

función_resumen

El nombre de la función de resumen para el analizador (una función que resume un conjunto de tokens).

Los nombres de las funciones pueden estar calificados por un esquema si es necesario. Los tipos de argumento no se especifican, ya que la lista de argumentos para cada tipo de función está predeterminada. Todas excepto la función de resumen son obligatorias.

Los argumentos pueden aparecer en cualquier orden, no solo en el mostrado arriba.

COMPATIBILIDAD

No existe la sentencia CREATE TEXT SEARCH PARSER en el estándar SQL.

VER TAMBIÉN

ALTER TEXT SEARCH PARSER (ALTER_TEXT_SEARCH_PARSER(7)), DROP TEXT SEARCH PARSER (DROP_TEXT_SEARCH_PARSER(7))
