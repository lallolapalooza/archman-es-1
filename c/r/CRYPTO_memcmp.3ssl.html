NOMBRE

CRYPTO_memcmp - Comparación de memoria en tiempo constante

SINOPSIS

#include <openssl/crypto.h>
int CRYPTO_memcmp(const void *a, const void *b, size_t len);

DESCRIPCIÓN

La función CRYPTO_memcmp compara los len bytes apuntados por a y b para verificar su igualdad. Tarda un tiempo dependiente de len, pero independiente del contenido de las regiones de memoria apuntadas por a y b.

VALORES DEVUELTOS

CRYPTO_memcmp() devuelve 0 si las regiones de memoria son iguales y un valor distinto de cero en caso contrario.

NOTAS

A diferencia de memcmp(2), esta función no se puede utilizar para ordenar las dos regiones de memoria, ya que el valor de retorno cuando difieren no está definido, más allá de ser distinto de cero.
