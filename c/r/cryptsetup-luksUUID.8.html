CRYPTSETUP-LUKSUUID(8) Comandos de mantenimiento CRYPTSETUP-LUKSUUID(8)

NOMBRE

cryptsetup-luksUUID - imprimir o establecer el UUID de un dispositivo LUKS

SINOPSIS

cryptsetup luksUUID [<opciones>] <dispositivo>

DESCRIPCIÓN

Imprime el UUID de un dispositivo LUKS.

Establece un nuevo UUID si se especifica la opción --uuid.

<opciones> pueden ser [--header, --uuid, --type, --disable-locks].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si la opción --verify-passphrase no se especifica, esta opción también desactiva la verificación de la frase de contraseña.

--debug o --debug-json

Ejecutar en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre van precedidas por #.

Si se utiliza --debug-json, se imprimen estructuras de datos JSON adicionales de LUKS2.

--disable-locks

Deshabilita la protección de bloqueo para metadatos en disco. Esta opción solo es válida para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No utilice esta opción a menos que ejecute cryptsetup en un entorno restringido donde sea imposible realizar bloqueos (donde el directorio /run no se puede usar).

--header <dispositivo o archivo que almacena la cabecera LUKS>

Utiliza un dispositivo o archivo de metadatos separado (desconectado) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para comandos que modifican la cabecera LUKS (por ejemplo, luksAddKey), especifique directamente el dispositivo o archivo con la cabecera LUKS como dispositivo LUKS.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--type tipo

Especifica el tipo de dispositivo requerido, para más información, lea la sección ACCIONES BÁSICAS en cryptsetup(8).

--usage

Muestra ayuda sobre opciones cortas.

--uuid UUID

Utiliza el UUID proporcionado para el comando luksFormat en lugar de generar uno nuevo. Cambia el UUID existente cuando se utiliza con el comando luksUUID.

El UUID debe proporcionarse en el formato UUID estándar, por ejemplo, 12345678-1234-1234-1234-123456789abc.

--version, -V

Muestra la versión del programa.

REPORTAR ERRORES

Reporte errores en la lista de correo de cryptsetup <cryptsetup@lists.linux.dev> o en la sección de Issues del proyecto https://gitlab.com/cryptsetup/cryptsetup/-/issues/new.

Adjunte la salida del comando fallido con la opción --debug añadida.
