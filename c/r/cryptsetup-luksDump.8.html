CRYPTSETUP-LUKSDUMP(8) Comandos de mantenimiento CRYPTSETUP-LUKSDUMP(8)

NOMBRE

cryptsetup-luksDump - vuelca la información de la cabecera de un dispositivo LUKS

SINOPSIS

cryptsetup luksDump [<opciones>] <dispositivo>

DESCRIPCIÓN

Vuelca la información de la cabecera de un dispositivo LUKS.

Si se usa la opción --dump-volume-key, se vuelca la clave de volumen del dispositivo LUKS en lugar de la información del slot de claves. Con la opción --volume-key-file, la clave de volumen se vuelca a un archivo en lugar de a la salida estándar. Tenga cuidado, ya que la clave de volumen no puede cambiarse sin volver a cifrar y puede usarse para descifrar los datos almacenados en el contenedor LUKS sin una frase de paso e incluso sin la cabecera LUKS. Esto significa que, si la clave de volumen se ve comprometida, hay que borrar o volver a cifrar todo el dispositivo para evitar un acceso posterior. Use esta opción con cuidado.

Se debe proporcionar una frase de paso para volcar la clave de volumen, ya sea de forma interactiva o mediante --key-file.

Para volcar una clave no vinculada (solo formato LUKS2), se debe proporcionar el parámetro --unbound, un --key-slot id específico y la frase de paso adecuada, de forma interactiva o mediante --key-file. El parámetro opcional --volume-key-file permite volcar el slot de claves no vinculado a un archivo.

Para volcar los metadatos JSON de LUKS2 (sin la información básica de la cabecera como el UUID), use la opción --dump-json-metadata.

Si --dump-volume-key se usa con --key-file y el argumento de --key-file es '-', no se hará ninguna pregunta de validación ni se emitirá ninguna advertencia.

<opciones> puede ser [--dump-volume-key, --dump-json-metadata, --key-file, --keyfile-offset, --keyfile-size, --header, --disable-locks, --volume-key-file, --type, --unbound, --key-slot, --timeout, --external-tokens-path].

OPCIONES

--batch-mode, -q

Suprime todas las preguntas de confirmación. ¡Úselo con cuidado!

Si no se especifica la opción --verify-passphrase, esta opción también desactiva la verificación de la frase de paso.

--debug o --debug-json

Se ejecuta en modo de depuración con registros de diagnóstico completos. Las líneas de salida de depuración siempre están precedidas por #.

Si se usa --debug-json, se imprimen además las estructuras de datos JSON de LUKS2.

--disable-locks

Desactiva la protección de bloqueo de los metadatos en disco. Esta opción es válida solo para LUKS2 y se ignora para otros formatos.

ADVERTENCIA: No use esta opción a menos que ejecute cryptsetup en un entorno restringido donde el bloqueo sea imposible de realizar (donde no se pueda usar el directorio /run).

--dump-json-metadata

Para luksDump (solo LUKS2), esta opción imprime el contenido del área de metadatos JSON de la cabecera LUKS2.

--dump-volume-key, --dump-master-key (alias OBSOLETO)

Imprime la clave de volumen en la información mostrada. Úselo con cuidado, ya que la clave de volumen puede usarse para eludir las frases de paso; vea también la opción --volume-key-file.

--external-tokens-path <ruta absoluta>

Anula la ruta del directorio del sistema donde cryptsetup busca manejadores de tokens externos (o plugins de tokens). Debe ser una ruta absoluta (que comience con el carácter '/').

--header <dispositivo o archivo que almacena la cabecera LUKS>

Usa un dispositivo o archivo de metadatos desprendido (separado) donde se almacena la cabecera LUKS. Esta opción permite almacenar el texto cifrado y la cabecera LUKS en dispositivos diferentes.

Para los comandos que cambian la cabecera LUKS (por ejemplo, luksAddKey), especifique el dispositivo o archivo con la cabecera LUKS directamente como el dispositivo LUKS.

--help, -?

Muestra el texto de ayuda y los parámetros predeterminados.

--key-description texto

Establece la descripción de la clave en el llavero que se usará para la recuperación de la frase de paso.

--key-file, -d archivo

Lee la frase de paso del archivo.

Si el nombre dado es "-", la frase de paso se leerá de stdin. En este caso, la lectura no se detendrá en los caracteres de nueva línea.

Vea la sección NOTAS SOBRE EL PROCESAMIENTO DE FRASES DE PASO en cryptsetup(8) para más información.

--keyfile-offset valor

Omite valor bytes al principio del archivo de claves.

--keyfile-size, -l valor

Lee un máximo de valor bytes del archivo de claves. El valor predeterminado es leer el archivo completo hasta el máximo compilado, que se puede consultar con --help. Si se proporcionan más datos que el máximo compilado, se aborta la operación.

Esta opción es útil, por ejemplo, para recortar los saltos de línea finales. Si también se da --keyfile-offset, el recuento del tamaño comienza después del desplazamiento.

--key-slot, -S <0-N>

Para las operaciones de LUKS que añaden material de claves, esta opción le permite especificar qué slot de claves se selecciona para la nueva clave.

El número máximo de slots de claves depende de la versión de LUKS. LUKS1 puede tener hasta 8 slots de claves. LUKS2 puede tener hasta 32 slots de claves basados en el tamaño del área del slot de claves y el tamaño de la clave, pero un ID de slot de claves válido siempre puede estar entre 0 y 31 para LUKS2.

--timeout, -t segundos

El número de segundos a esperar antes de que se produzca un tiempo de espera en la entrada de la frase de paso a través del terminal. Es relevante cada vez que se pide una frase de paso. No tiene efecto si se usa junto con --key-file.

Esta opción es útil cuando el sistema no debe bloquearse si el usuario no introduce una frase de paso, por ejemplo, durante el arranque. El valor predeterminado es 0 segundos, lo que significa esperar para siempre.

--type tipo

Especifica el tipo de dispositivo requerido; para más información, lea la sección ACCIONES BÁSICAS en cryptsetup(8).

--unbound

Vuelca el slot de claves no vinculado existente de LUKS2.

--usage

Muestra la ayuda breve de las opciones.

--version, -V

Muestra la versión del programa.

--volume-key-file archivo, --master-key-file archivo (alias OBSOLETO)

Usa una clave de volumen almacenada en un archivo.

La clave de volumen se almacena en un archivo en lugar de imprimirse en la salida estándar.
