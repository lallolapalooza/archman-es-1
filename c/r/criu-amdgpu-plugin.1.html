NOMBRE
criu-amdgpu-plugin - Una extensión de complemento para CRIU para admitir el punto de control/restauración en el espacio de usuario para GPUs AMD.



SOPORTE ACTUAL

Sistemas de GPU única y múltiple (Gfx9) Punto de control / Restauración en un sistema diferente Punto de control / Restauración dentro de un contenedor docker Pytorch Tensorflow Usando CRIU Image Streamer



DESCRIPCIÓN

Aunque criu es una gran herramienta para hacer puntos de control y restaurar aplicaciones en ejecución, tiene ciertas limitaciones, como que no puede manejar aplicaciones que tienen archivos de dispositivo abiertos. Para admitir cargas de trabajo basadas en ROCm con criu, necesitamos aumentar la funcionalidad principal de criu con un mecanismo de extensión basado en complementos. criu-amdgpu-plugin proporciona el soporte necesario a criu para permitir el punto de control / restauración con ROCm.



DEPENDENCIAS

Soporte amdkfd

Para hacer instantáneas de la VRAM y otros estados del dispositivo de la GPU, requerimos una versión actualizada del controlador amdkfd (amdgpu).



OPCIONES

Se pueden pasar parámetros opcionales como variables de entorno antes de ejecutar el comando criu.

KFD_FW_VER_CHECK

Habilita o deshabilita la verificación de la versión del firmware. Si está habilitado, la versión del firmware en la GPU restaurada debe ser mayor o igual a la versión del firmware en la GPU con punto de control. Predeterminado: Habilitado 
Ejemplo:
KFD_FW_VER_CHECK=0

KFD_SDMA_FW_VER_CHECK

Habilita o deshabilita la verificación de la versión del firmware SDMA. Si está habilitado, la versión del firmware SDMA en la GPU restaurada debe ser mayor o igual a la versión del firmware en la GPU con punto de control. Predeterminado: Habilitado 
Ejemplo:
KFD_SDMA_FW_VER_CHECK=0

KFD_CACHES_COUNT_CHECK

Habilita o deshabilita la verificación del recuento de cachés. Si está habilitado, el recuento de cachés en la GPU restaurada debe ser mayor o igual al recuento de cachés en la GPU con punto de control. Predeterminado: Habilitado 
Ejemplo:
KFD_CACHES_COUNT_CHECK=0

KFD_NUM_GWS_CHECK

Habilita o deshabilita la verificación de num_gws. Si está habilitado, el num_gws en la GPU restaurada debe ser mayor o igual al num_gws en la GPU con punto de control. Predeterminado: Habilitado 
Ejemplo:
KFD_NUM_GWS_CHECK=0

KFD_VRAM_SIZE_CHECK

Habilita o deshabilita la verificación del tamaño de VRAM. Si está habilitado, el tamaño de VRAM en la GPU restaurada debe ser mayor o igual al tamaño de VRAM en la GPU con punto de control. Predeterminado: Habilitado 
Ejemplo:
KFD_VRAM_SIZE_CHECK=0

KFD_NUMA_CHECK

Habilita o deshabilita la verificación de la región de CPU NUMA. Si está habilitado, el complemento restaurará las GPUs que pertenecen a una región de CPU NUMA a la misma región de CPU NUMA. Predeterminado: Habilitado 
Ejemplo:
KFD_NUMA_CHECK=1

KFD_CAPABILITY_CHECK

Habilita o deshabilita la verificación de capacidades. Si está habilitado, la capacidad en la GPU restaurada debe ser igual a la capacidad en la GPU con punto de control. Predeterminado: Habilitado 
Ejemplo:
KFD_CAPABILITY_CHECK=1

KFD_MAX_BUFFER_SIZE

En algunos sistemas, los tamaños de VRAM pueden exceder los tamaños de RAM, por lo que los búferes para volcar y restaurar VRAM pueden no caber. Establecer en un valor distinto de cero (en bytes) para establecer un límite en el uso de memoria del complemento. Predeterminado: 0 (Deshabilitado) 
Ejemplo:
KFD_MAX_BUFFER_SIZE="2G"



AUTOR

El equipo de AMDKFD.
