NOMBRE

cracklib-format, cracklib-packer, cracklib-unpacker - utilidades de diccionario cracklib

SINOPSIS

cracklib-format archivo ...

cracklib-packer cracklib_dictpath

cracklib-unpacker cracklib_dictpath

DESCRIPCIÓN

cracklib-format toma una lista de archivos de texto que contienen cada uno una lista de palabras, una por línea. Convierte todas las palabras a minúsculas, elimina los caracteres de control y ordena las listas. Genera la lista limpia en la salida estándar. Los archivos de texto pueden estar opcionalmente comprimidos con gzip(1).

Si proporciona una gran cantidad de texto a cracklib-format, debe tener suficiente espacio libre disponible para su uso por el comando sort(1). Si no tiene 20 MB libres en /var/tmp (o el área temporal que utilice su comando sort(1)), eche un vistazo al programa /usr/sbin/cracklib-format, que es un programa sh(1). Normalmente, puede ajustar el comando sort(1) para que utilice cualquier área de disco grande que desee, mediante la opción -T. cracklib-format tiene un gancho para esto.

cracklib-packer lee desde la entrada estándar una lista de palabras ordenadas y limpias y crea una base de datos en el directorio y prefijo dados por el argumento de línea de comandos cracklib_dictpath. Se crean tres archivos con los sufijos .hwm, .pwd y .pwi. Estos tres archivos están en el formato que entienden la subrutina FascistCheck(3), cracklib-unpacker(8) y cracklib-check(8). El número de palabras leídas y escritas se imprime en stdout(3).

cracklib-unpacker lee desde la base de datos en el directorio y prefijo dados por el argumento de línea de comandos cracklib_dictpath y genera en la salida estándar la lista de palabras que componen la base de datos.

La base de datos está en un formato binario generado por las utilidades cracklib-format(8) y cracklib-packer(8). En un sistema Debian, la base de datos se encuentra en el directorio /var/cache/cracklib/cracklib_dict y se genera diariamente con el programa /etc/cron.daily/cracklib. La ubicación también se define en el archivo de cabecera crack.h utilizando la constante CRACKLIB_DICTPATH, aunque ninguna de las subrutinas en las bibliotecas cracklib tiene esta ubicación codificada en sus implementaciones.

ARCHIVOS

/var/cache/cracklib/cracklib_dict.[hwm|pwd|pwi]
Archivos de base de datos de diccionario cracklib utilizados por las utilidades.
/etc/cron.daily/cracklib
Programa cron diario de cracklib para reconstruir la base de datos del diccionario cracklib.
/etc/cracklib/cracklib.conf
Archivo de configuración de cracklib utilizado por el programa cron diario de cracklib para reconstruir la base de datos del diccionario cracklib.
/usr/include/crack.h
Archivo de cabecera de cracklib que define la subrutina FascistCheck(3) y la constante CRACKLIB_DICTPATH utilizada para compilar la ubicación de la base de datos del diccionario cracklib para estas utilidades.
/usr/sbin/cracklib-format
Script de shell de cracklib para crear la lista inicial de palabras para la base de datos del diccionario.
