Crypt::Mac::HMAC(3) Documentación de Perl contribuida por el usuario Crypt::Mac::HMAC(3)

NOMBRE

Crypt::Mac::HMAC - Código de autenticación de mensajes HMAC

SINOPSIS

### Interfaz funcional:
use Crypt::Mac::HMAC qw( hmac hmac_hex );
# calcular MAC de cadena/buffer
$hmac_raw  = hmac('SHA256', $key, 'buffer de datos');
$hmac_hex  = hmac_hex('SHA256', $key, 'buffer de datos');
$hmac_b64  = hmac_b64('SHA256', $key, 'buffer de datos');
$hmac_b64u = hmac_b64u('SHA256', $key, 'buffer de datos');
### Interfaz OO:
use Crypt::Mac::HMAC;
$d = Crypt::Mac::HMAC->new('SHA256', $key);
$d->add('cualquier dato');
$d->addfile('nombre_archivo.dat');
$d->addfile(*MANEJADOR_ARCHIVO);
$result_raw  = $d->mac;     # bytes crudos
$result_hex  = $d->hexmac;  # forma hexadecimal
$result_b64  = $d->b64mac;  # forma Base64
$result_b64u = $d->b64umac; # forma Base64 URL Safe

DESCRIPCIÓN

Proporciona una interfaz para el algoritmo de código de autenticación de mensajes (MAC) HMAC.

EXPORTACIÓN

No se exporta nada por defecto.

Puede exportar funciones seleccionadas:

use Crypt::Mac::HMAC qw(hmac hmac_hex );

O todas a la vez:

use Crypt::Mac::HMAC ':all';

FUNCIONES

hmac

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes HMAC codificado como una cadena binaria.

$hmac_raw = hmac($hash_name, $key, 'buffer de datos');
#o
$hmac_raw = hmac($hash_name, $key, 'cualquier dato', 'más datos', 'incluso más datos');
# $hash_name ... cualquier <NOMBRE> para el cual exista Crypt::Digest::<NOMBRE>
# $key ......... la clave (octetos/bytes)

hmac_hex

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes HMAC codificado como una cadena hexadecimal.

$hmac_hex = hmac_hex($hash_name, $key, 'buffer de datos');
#o
$hmac_hex = hmac_hex($hash_name, $key, 'cualquier dato', 'más datos', 'incluso más datos');
# $hash_name ... cualquier <NOMBRE> para el cual exista Crypt::Digest::<NOMBRE>
# $key ......... la clave (octetos/bytes, ¡no hexadecimales!)

hmac_b64

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes HMAC codificado como una cadena Base64.

$hmac_b64 = hmac_b64($hash_name, $key, 'buffer de datos');
#o
$hmac_b64 = hmac_b64($hash_name, $key, 'cualquier dato', 'más datos', 'incluso más datos');
# $hash_name ... cualquier <NOMBRE> para el cual exista Crypt::Digest::<NOMBRE>
# $key ......... la clave (octetos/bytes, ¡no Base64!)

hmac_b64u

Une lógicamente todos los argumentos en una sola cadena y devuelve su código de autenticación de mensajes HMAC codificado como una cadena Base64 URL Safe (ver RFC 4648 sección 5).

$hmac_b64url = hmac_b64u($hash_name, $key, 'buffer de datos');
#o
$hmac_b64url = hmac_b64u($hash_name, $key, 'cualquier dato', 'más datos', 'incluso más datos');
# $hash_name ... cualquier <NOMBRE> para el cual exista Crypt::Digest::<NOMBRE>
# $key ......... la clave (octetos/bytes, ¡no Base64url!)
