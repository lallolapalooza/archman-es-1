Crypt::Cipher::RC5(3) Documentación de Perl aportada por el usuario Crypt::Cipher::RC5(3)

NOMBRE

Crypt::Cipher::RC5 - Cifrado simétrico RC5, tamaño de clave: 64-1024 bits

SINOPSIS

### ejemplo 1
use Crypt::Mode::CBC;
my $key = '...'; # la longitud debe ser un tamaño de clave válido para este cifrado
my $iv = '...';  # 16 bytes
my $cbc = Crypt::Mode::CBC->new('RC5');
my $ciphertext = $cbc->encrypt("datos secretos", $key, $iv);
### ejemplo 2 (más lento)
use Crypt::CBC;
use Crypt::Cipher::RC5;
my $key = '...'; # la longitud debe ser un tamaño de clave válido para este cifrado
my $iv = '...';  # 16 bytes
my $cbc = Crypt::CBC->new( -cipher=>'Cipher::RC5', -key=>$key, -iv=>$iv );
my $ciphertext = $cbc->encrypt("datos secretos");

DESCRIPCIÓN

Este módulo implementa el cifrado RC5. La interfaz proporcionada es compatible con el módulo Crypt::CBC.

ADVERTENCIA: Este módulo implementa solo la operación elemental de "cifrado/descifrado de un bloque"; si desea cifrar/descifrar datos genéricos, debe utilizar alguno de los modos de bloque de cifrado. Consulte, por ejemplo, Crypt::Mode::CBC, Crypt::Mode::CTR o Crypt::CBC (que será más lento).
