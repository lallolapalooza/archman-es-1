Los lenguajes C++ y Java proporcionan la sobrecarga de funciones, lo que significa que puede escribir muchas funciones con el mismo nombre, siempre que cada función tome parámetros de tipos diferentes. Para poder distinguir estas funciones de nombres similares, C++ y Java las codifican en un nombre de ensamblador de bajo nivel que identifica de forma única cada versión diferente. Este proceso se conoce comoenmascaramiento. El programa c++filt
[1] realiza la asignación inversa: decodifica (desenmascara ) nombres de bajo nivel a nombres de nivel de usuario para que puedan ser leídos.Cada palabra alfanumérica (consistente en letras, dígitos, guiones bajos, dólares o puntos) vista en la entrada es un nombre enmascarado potencial. Si el nombre se decodifica en un nombre C++, el nombre C++ reemplaza el nombre de bajo nivel en la salida; de lo contrario, se emite la palabra original. De esta manera, puede pasar un archivo fuente de ensamblador completo, que contenga nombres enmascarados, a través dec++filt
y ver el mismo archivo fuente con los nombres desenmascarados.También puede usarc++filtpara descifrar símbolos individuales pasándolos en la línea

Habilita o deshabilita un límite en la cantidad de recursión realizada al desenmascarar cadenas. Dado que los formatos de enmascaramiento de nombres permiten un nivel de recursión
infinito, es posible crear cadenas cuya decodificación agotará la cantidad de espacio de pila disponible en la máquina anfitriona, provocando una falla de memoria. El límite intenta prevenir que esto ocurra restringiendo la recursión a 2048 niveles de anidamiento.

c++filt(1)

Este es un extracto de la página del manual de c++filt. Si tienes instaladas las utilidades de binutils, puedes ver la página completa ejecutando man c++filt en tu terminal.

NAME

c++filt - Descodifica nombres de C++

SYNOPSIS

c++filt [OPTION]... [demangled_name]...

DESCRIPTION

c++filt descodifica uno o más nombres de C++ que han sido codificados por un compilador.

Se espera que la entrada esté en un formato codificado como los generados por los compiladores de C++ (por ejemplo, GCC).

Si no se proporcionan argumentos, c++filt lee desde la entrada estándar.

El programa lee las líneas de la entrada, descodifica cada nombre codificado que encuentra y escribe el nombre descodificado en la salida estándar.

Las líneas que no contienen nombres codificados se copian directamente a la salida estándar.

c++filt es útil para depurar programas y para inspeccionar símbolos en archivos objeto.

Se aplican las siguientes secciones, sin textos en la portada y sin textos en la contraportada. Una copia de la licencia se incluye en la sección titulada "GNU Free Documentation License".

OPTIONS

-n, --no-demangle
No descodificar los nombres. Esto puede ser útil si desea procesar la salida de c++filt de alguna manera, pero todavía desea obtener una salida similar a la de nm.
-p, --strip-underscores
Quita los guiones bajos iniciales de los nombres. Algunos compiladores, como GCC, añaden un guion bajo a los nombres de las funciones para el enlace externo. Esta opción elimina esos guiones bajos.
-h, --help
Muestra un mensaje de ayuda y sale.
-V, --version
Muestra la información de la versión y sale.
