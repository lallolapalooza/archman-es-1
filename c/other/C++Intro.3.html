DESCRIPCIÓ

N

Esta página de manual sirve como una breve introducción a la implementación de la Biblioteca Estándar de C++ de GNU. Para una mejor introducción y documentación más completa, consulte el sitio web de libstdc++ listado al

final.

Todas las entidades de la biblioteca estándar se declaran dentro del espacio de nombres std y tienen entradas de manual que comienzan con "std::". Por ejemplo, para ver la documentación de la clase plantilla std::vector se usaría "man std::vector". Algunas entidades no tienen una página de manual separada; para esas consulte el listado principal en "man

Namespace_std".

Todas las páginas de manual son generadas automáticamente por Doxygen. Para más información sobre esta herramienta, consulte el homólogo HTML de estas páginas de

manual.

Algunas páginas de manual no corresponden a clases o funciones individuales. Más bien describen categorías de la Biblioteca Estándar. (Para una introducción más exhaustiva a las diversas categorías, consulte un texto como el de Josuttis o el de Austern.) Estas páginas de categorías

s
libstdc++.
a
La implementación de la biblioteca en forma de archivo estático. Si no configuró libstdc++ para usar bibliotecas compartidas, esta se usará siempre. De lo contrario, solo se usará si el usuario lo
solicita.
libsupc++.
a
Esta biblioteca contiene rutinas de soporte del lenguaje C++. Normalmente nunca necesitará saber de ella, pero puede ser útil. Vea la pregunta frecuente
2.5.
libstdc++.so[.
N]
La implementación de la biblioteca en forma de objeto compartido. Esta se usará por defecto en lugar de la forma de archivo estático. N será un número igual o mayor que 3. Si N está en la serie 2.x, entonces está usando la antigua biblioteca libstdc++-v2, la cual no
mantenemos.
