CXL-ENABLE-REGION(1) Manual de cxl CXL-ENABLE-REGION(1)

NOMBRE

cxl-enable-region - habilita la(s) región(es) especificada(s).

SINOPSIS

cxl enable-region <region> [<opciones>]

DESCRIPCIÓN

Una región CXL se compone de uno o más segmentos de memdev CXL, con configuraciones de interleaveo configurables: tanto el número de niveles de interleaveo como la granularidad del interleaveo.

EJEMPLO

# cxl enable-region all
regiones habilitadas 2

Dado cualquier comando de habilitación o deshabilitación, si la operación es una operación nula debido al estado actual de un objetivo (es decir, ya habilitado o deshabilitado), aún se considera exitosa al ejecutarse, incluso si no se realiza ninguna operación real. El objetivo puede ser un bus, un decodificador, un memdev o una región. La operación aún tendrá éxito e informará el número de buses/decodificadores/memdev/regiones operados, incluso si la operación es nula.

OPCIONES

-b, --bus=

Restringe la operación al bus especificado.

-d, --decoder=

El decodificador raíz para limitar la operación. Solo se actuarán sobre las regiones que sean hijas del decodificador especificado.

--debug

Activa mensajes de depuración adicionales, incluida la depuración de la biblioteca.
