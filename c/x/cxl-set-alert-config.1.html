NOMBRE

cxl-set-alert-config - establece el umbral de alerta de advertencia en un memdev CXL

SINOPSIS

cxl set-alert-config <mem0> [<mem1>..<memN>] [<opciones>]

DESCRIPCIÓN

El dispositivo CXL genera una alerta cuando su estado de salud cambia. La alerta crítica será configurada automáticamente por el dispositivo después de un reinicio del dispositivo. Si se soporta, los umbrales de advertencia programables también se inicializarán con los valores predeterminados recomendados por el proveedor, y luego podrán ser configurados por el usuario.

Use este comando para configurar los umbrales de alerta de advertencia de un dispositivo. Al emitir este comando, los umbrales de advertencia recién solicitados anularían los umbrales de advertencia previamente programados.

Para habilitar la alerta de advertencia, establezca tanto threshold=valor como alert=on. Para deshabilitar la alerta de advertencia, establezca solo alert=off. Otros casos causarán errores.

Use "cxl list -m <memdev> -A" para examinar las capacidades de umbral de advertencia de programación de un dispositivo.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo memX, o un número de ID de memdev. Restringe la operación a los memdev especificados. La palabra clave all puede ser especificada para indicar la ausencia de cualquier restricción.

-S, --serial

En lugar de un número de ID de memdev, interpreta el argumento (los argumentos) <memdev> como una lista de números de serie.

-L, --life-used-threshold=

Establece <valor> para el umbral de alerta de advertencia de uso de vida útil.

--life-used-alert=

Habilita o deshabilita la alerta de advertencia de uso de vida útil. Las opciones son on u off.

-O, --over-temperature-threshold=

Establece <valor> para el umbral de alerta de advertencia de sobretemperatura del dispositivo.

--over-temperature-alert=

Habilita o deshabilita la alerta de advertencia de sobretemperatura del dispositivo. Las opciones son on u off.

-U, --under-temperature-threshold=

Establece <valor> para el umbral de alerta de advertencia de subtemperatura del dispositivo.

--under-temperature-alert=

Habilita o deshabilita la alerta de advertencia de subtemperatura del dispositivo. Las opciones son on u off.

-V, --volatile-mem-err-threshold=

Establece <valor> para el umbral de alerta de advertencia de error de memoria volátil corregido.

--volatile-mem-err-alert=

Habilita o deshabilita la alerta de advertencia de error de memoria volátil corregido. Las opciones son on u off.

-P, --pmem-err-threshold=

Establece <valor> para el umbral de alerta de advertencia de error de memoria persistente corregido.

--pmem-err-alert=

Habilita o deshabilita la alerta de advertencia de error de memoria persistente corregido. Las opciones son on u off.

-v, --verbose

Activa los mensajes de depuración detallados en la biblioteca (si libcxl fue compilado con registro y depuración habilitados).
