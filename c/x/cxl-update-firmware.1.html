NOMBRE

cxl-update-firmware - actualiza el firmware en un dispositivo de memoria CXL

SINOPSIS

cxl update-firmware <mem0> [<mem1>..<memN>] [<opciones>]

DESCRIPCIÓN

Actualiza el firmware en uno o más dispositivos de memoria CXL. Los dispositivos de memoria deben soportar el conjunto de comandos de buzón relacionados con el firmware.

Este comando no emite directamente los comandos de buzón de transferencia/activación de firmware. En su lugar, se utiliza la instalación de carga de firmware del kernel para proporcionar los datos al kernel, y el kernel se encarga de realizar la actualización real, gestionando al mismo tiempo la división temporal de la transferencia con respecto a otros comandos en segundo plano.

EJEMPLO

# cxl update-firmware mem0 -F firmware.bin -w
[
  {
    "memdev":"mem0",
    "pmem_size":1073741824,
    "ram_size":1073741824,
    "serial":0,
    "numa_node":0,
    "host":"cxl_mem.0",
    "firmware":{
      "num_slots":3,
      "active_slot":2,
      "online_activate_capable":false,
      "slot_1_version":"cxl_test_fw_001",
      "slot_2_version":"cxl_test_fw_002",
      "slot_3_version":"cxl_test_new_fw",
      "fw_update_in_progress":false
    }
  }
]
actualización de firmware completada en 1 dispositivo de memoria

OPCIONES

-b, --bus=

Restringe la operación al bus especificado.

-F, --firmware-file

Archivo de imagen de firmware a utilizar para la actualización.

-c, --cancel

Intenta abortar una actualización de firmware en curso. Esto puede fallar dependiendo de en qué etapa se encuentre el proceso de actualización.

-w, --wait

Por defecto, el comando update-firmware solo inicia la actualización del firmware y regresa, mientras que la operación de actualización ocurre de forma asíncrona en segundo plano. Esta opción hace que el comando de actualización de firmware sea síncrono al esperar a que se complete antes de regresar. 
Si se pasa --wait sin un firmware-file acompañante,
iniciará una espera en cualquier actualización de firmware
en curso y luego regresará.

-v, --verbose

Emite más mensajes de depuración
