CXL-ENABLE-MEMDEV(1) Manual de cxl CXL-ENABLE-MEMDEV(1)

NOMBRE

cxl-enable-memdev - activa / agrega en caliente un memdev CXL dado

SINOPSIS

cxl enable-memdev <mem0> [<mem1>..<memN>] [<opciones>]

Un memdev típicamente se autoactiva al descubrir el dispositivo inicial. Sin embargo, si se deshabilitó manualmente, este comando puede activar al kernel para activarlo nuevamente. Esto implica detectar el estado de los Decodificadores de Memoria Gestionada por el Host (HDM) y validar que CXL.mem esté habilitado para cada puerto en la jerarquía del dispositivo.

Dada cualquier comando de habilitación o deshabilitación, si la operación es una operación nula debido al estado actual de un objetivo (es decir, ya habilitado o deshabilitado), todavía se considera exitosa cuando se ejecuta, incluso si no se realiza ninguna operación real. El objetivo puede ser un bus, un decodificador, un memdev o una región. La operación aún tendrá éxito e informará el número de buses/decodificadores/memdevs/regiones operados, incluso si la operación es nula.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo memX, o un número de identificación de memdev. Restringe la operación a los memdev(s) especificados. La palabra clave all puede ser especificada para indicar la ausencia de cualquier restricción.

-S, --serial

En lugar de un número de identificación de memdev, interpreta el argumento (s) <memdev> como una lista de números de serie.

-b, --bus=

Restringe la operación al bus especificado.

-v

Activa mensajes de depuración detallados en la biblioteca (si libcxl fue compilado con registro y depuración habilitados).
