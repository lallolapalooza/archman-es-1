CXL-CREATE-REGION(1) Manual de cxl CXL-CREATE-REGION(1)

NOMBRE

cxl-create-region - Ensamblar una región CXL estableciendo los atributos de sus memdevs constituyentes.

SINOPSIS

cxl create-region [<opciones>]

DESCRIPCIÓN

Una región CXL se compone de una o más particiones de memdevs CXL, con configuraciones de intercalación (interleave) configurables: tanto el número de formas de intercalación como la granularidad de la intercalación.

Para create-region, opcionalmente se puede especificar un tamaño, pero si no, se utilizará el tamaño máximo posible para cada memdev hasta la capacidad de decodificación disponible en el sistema para el tipo de memoria dado. Para regiones persistentes, opcionalmente se puede especificar una UUID, pero si no, se generará una.

Si la operación de creación de región es exitosa, se emitirá un objeto de región en stdout en formato JSON (ver ejemplos). Si los argumentos especificados no se pueden satisfacer con una configuración legal, se emitirá un error apropiado en stderr.

EJEMPLO

#cxl create-region -m -d decoder0.1 -w 2 -g 1024 mem0 mem1
{
  "region":"region0",
  "resource":"0xc90000000",
  "size":"512.00 MiB (536.87 MB)",
  "interleave_ways":2,
  "interleave_granularity":1024,
  "mappings":[
    {
      "position":1,
      "decoder":"decoder4.0"
    },
    {
      "position":0,
      "decoder":"decoder3.0"
    }
  ]
}
created 1 region

OPCIONES

<objetivo(s)>

Los objetivos CXL que deben usarse para formar la región. El número de argumentos de objetivo debe coincidir con la opción --ways (si se proporciona).

-b, --bus=

Restringir la operación al bus especificado.

-m, --memdevs

Indicar que los argumentos no opcionales para objetivo(s) se refieren a nombres de dispositivos memdev. Si se omite esta opción y no se especifican objetivos, create-region utiliza internamente el equivalente a cxl list -M -d $decoder como lista de objetivos. Tenga en cuenta que, dependiendo de la topología, por ejemplo con switches, el orden automático de la lista de objetivos puede no ser válido y se requiere la especificación manual de la lista de objetivos.

-s, --size=

Especificar el tamaño total de la nueva región. Esto es opcional y, por defecto, se utilizará el tamaño máximo posible. El tamaño máximo posible está limitado tanto por el espacio HPA libre contiguo restante en el decodificador raíz como por el espacio DPA disponible en los memdevs componentes.

-t, --type=

Especificar el tipo de región: pmem o ram. Por defecto, se usa la capacidad del decodificador raíz y, si es ambiguo, se usa pmem.

-U, --uuid=

Especificar una UUID para la nueva región. Normalmente no es necesario especificar esto, ya que se generará una por defecto. Solo aplicable a regiones pmem.

-w, --ways=

El número de formas de intercalación para la intercalación de la nueva región. Debe ser igual al número de memdevs especificados en --memdevs, si se proporciona --memdevs. Si no se especifica --ways, se determinará en función del número de objetivos memdev proporcionados.

-g, --granularity=

La granularidad de intercalación para la nueva región. Debe coincidir con la granularidad del decodificador raíz seleccionado (si se proporciona). Si el decodificador raíz se intercala entre más de un puente de host, este valor debe coincidir con esa granularidad. De lo contrario, para ventanas de decodificación no intercaladas, se puede especificar cualquier granularidad siempre que todos los dispositivos admitan esa configuración.

-d, --decoder=

El decodificador raíz bajo el cual se creará la región. Si no se proporciona, se elegirá el primer puente cruzado de host (si está disponible), el decodificador que admita la mayor intercalación.

-Q, --enforce-qos

Parámetro para forzar el fallo por discrepancia de qos_class. La operación de creación de región fallará si la qos_class del decodificador raíz y uno de los memdev que respaldan la región no coinciden.

-u, --human

Por defecto, el comando mostrará datos numéricos crudos, amigables para la máquina. En su lugar, con esta bandera, los números que representan el tamaño de almacenamiento se formatearán como cadenas legibles por humanos con unidades, otros campos se convertirán a cadenas hexadecimales.

--debug

Activar mensajes de depuración adicionales, incluida la depuración de la biblioteca.
