NOMBRE

cxl-set-partition - establece el particionamiento entre capacidad volátil y persistente en un dispositivo de memoria CXL

SINOPSIS

cxl set-partition <mem0> [ [<mem1>..<memN>] [<opciones>]

DESCRIPCIÓN

Los dispositivos CXL pueden admitir tanto capacidad de memoria volátil como persistente. La cantidad de capacidad del dispositivo reservada para cada tipo se establece típicamente en fábrica, pero algunos dispositivos también permiten un re-particionamiento dinámico.

Use este comando para particionar un dispositivo en capacidad volátil y persistente. El cambio en el particionamiento se convierte en la configuración “siguiente”, que se activará en el próximo reinicio del dispositivo.

Use "cxl list -m <memdev> -I" para examinar las capacidades de particionamiento de un dispositivo. Un valor de partition_alignment_size de cero significa que no hay capacidad disponible y, por lo tanto, las particiones no se pueden cambiar.

El uso de este comando para cambiar el tamaño de la capacidad persistente resultará en la pérdida de los datos almacenados.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo memX, o un número de ID de dispositivo de memoria. Restringe la operación a los dispositivos de memoria especificados. La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción.

-S, --serial

En lugar de un número de ID de dispositivo de memoria, interpreta los argumentos de <memdev> como una lista de números de serie.

-b, --bus=

Restringe la operación al bus especificado.

-t, --type=

Tipo de partición, pmem o ram (volátil), a modificar. Por defecto: pmem

-s, --size=

Tamaño de la partición de <tipo> en bytes. El tamaño debe alinearse con el requisito de alineación del dispositivo. Use cxl list -m <memdev> -I para encontrar partition_alignment_size, o use la opción --align. Por defecto: Toda la capacidad disponible se asigna a <tipo>.

-a, --align

Seleccione esta opción para permitir la alineación automática de --size para cumplir con los requisitos de alineación del dispositivo. Al usar esta opción, especifique el --size mínimo de la partición --type necesaria. Cuando se omite esta opción, el comando falla si --size no está correctamente alineado. Use cxl list -m <memdev> -I para examinar el partition_alignment_size.

-v

Activa mensajes de depuración detallados en la biblioteca (si libcxl se compiló con registro y depuración habilitados).
