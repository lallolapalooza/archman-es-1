NOMBRE

cxl-reserve-dpa - asignar espacio de direcciones físico del dispositivo

SINOPSIS

cxl reserve-dpa <mem0> [<mem1>..<memN>] [<opciones>]

El proceso de aprovisionamiento de regiones CXL procede en múltiples pasos. Uno de los pasos es identificar y reservar el tramo de DPA que cada miembro del conjunto de entrelazado (región) aporta antes de adjuntar esa asignación a una región. Para fines de desarrollo, prueba y depuración, este comando es una ayuda para encontrar el próximo decodificador disponible en el punto final (memdev) y marcar un tramo de DPA como ocupado.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo memX, o un número de id de memdev. Restringe la operación a los memdev especificados. La palabra clave all puede ser especificada para indicar la ausencia de cualquier restricción.

-S, --serial

En lugar de un número de id de memdev, interpreta el(los) argumento(s) <memdev> como una lista de números de serie.

-b, --bus=

Restringe la operación al bus especificado.

-d, --decoder

Especifica el decodificador para intentar la asignación. La especificación CXL exige que las asignaciones se ordenen por DPA e instancia de decodificador. Es decir, la asignación de DPA más baja en el dispositivo está cubierta por el decodificador0, y la última / asignación de DPA más alta está cubierta por el último decodificador. Este orden es impuesto por el kernel. Por defecto, la herramienta elige el próximo decodificador disponible.

-t, --type

Selecciona la partición para la asignación. Los dispositivos CXL implementan una partición que divide la capacidad de ram y pmem, donde la capacidad pmem consume la capacidad DPA superior por encima del límite de partición. El tipo por defecto es pmem. Tenga en cuenta que dadas las restricciones de asignación de DPA de CXL, una vez que se establece cualquier asignación de pmem, toda la capacidad de ram restante se reserva (se omite).

-f, --force

El kernel hace cumplir las restricciones de ordenación de asignación de DPA de CXL, y la herramienta anticipa esas restricciones y falla las operaciones que se espera que fallen sin enviarlas al kernel. Para fines de prueba, continúe intentando operaciones que se espera que fallen para ejercitar el driver.

-s, --size

Especifica el tamaño de la asignación. Esta opción admite los sufijos "k" o "K" para KiB, "m" o "M" para MiB, "g" o "G" para GiB y "t" o "T" para TiB. Por defecto, es "toda la capacidad disponible del tipo especificado".

-v

Activa mensajes de depuración detallados en la biblioteca (si libcxl fue compilado con registro y depuración habilitados).
