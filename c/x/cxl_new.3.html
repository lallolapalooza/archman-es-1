CXL_NEW(3) Manual de libcxl CXL_NEW(3)

NOMBRE

cxl_new - Crear un nuevo objeto de contexto de biblioteca que actúa como un manejador para todas las operaciones de la biblioteca

SINOPSIS

#include <cxl/libcxl.h>
int cxl_new(struct cxl_ctx **ctx);

DESCRIPCIÓN

Instancia un nuevo contexto de biblioteca y almacena un puntero opaco en ctx. El contexto se libera mediante linklibcxl:cxl_unref[3], es decir, cxl_new(3) implica un linklibcxl:cxl_ref[3] interno.

VALOR DE RETORNO

Devuelve 0 en caso de éxito y un errno negativo en caso de fallo. Los códigos de error posibles son:

•-ENOMEM
•-ENXIO

EJEMPLO

Ver el uso de ejemplo en test/libcxl.c
