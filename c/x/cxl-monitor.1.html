NOMBRE

cxl-monitor - Monitorizar los eventos de rastreo de CXL

SINOPSIS

cxl monitor [<opciones>]

DESCRIPCIÓN

cxl-monitor se utiliza para monitorizar los eventos de rastreo de CXL emitidos por el kernel y convertirlos a objetos json y volcar las notificaciones en formato json a la salida estándar o a un archivo de registro.

EJEMPLOS

Ejecutar un monitor como un demonio para monitorizar eventos y enviar la salida a un archivo de registro.

cxl monitor --daemon --log=/var/log/cxl-monitor.log

Ejecutar un monitor como un comando de un solo uso y enviar las notificaciones a stdio.

cxl monitor

Ejecutar un demonio monitor como un servicio del sistema

systemctl start cxl-monitor.service

OPCIONES

-l, --log=

Envía mensajes de registro al destino especificado.
•"<archivo>": Envía mensajes de registro al <archivo> especificado.
•"standard": Envía mensajes a la salida estándar.

El destino de registro predeterminado es /var/log/cxl-monitor.log si se especifica "--daemon", de lo contrario es standard. Tenga en cuenta que la salida estándar y la ruta relativa para <archivo> no funcionarán si se especifica "--daemon".

--daemon

Ejecuta un monitor como un demonio.

-v, --verbose

Emite más mensajes de depuración

-u, --human

Por defecto, el comando emitirá datos numéricos crudos amigables para la máquina. En su lugar, con esta bandera, los números que representan el tamaño del almacenamiento se formatearán como cadenas legibles por humanos con unidades, otros campos se convertirán a cadenas hexadecimales.
