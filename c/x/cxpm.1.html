NOMBRE

cxpm - Comprueba un archivo XPM (X PixMap), versiones XPM 1, 2 o 3.

SINOPSIS

cxpm [nombre_archivo]

DESCRIPCIÓN

El programa cxpm se puede usar para comprobar el formato de cualquier archivo XPM (versión 1, 2 o 3). En caso de error, a diferencia de sxpm, cxpm imprime un mensaje de error que indica dónde falló el analizador. Esto debería ayudar a descubrir qué está mal en un archivo XPM, aunque no esperes demasiado de ello. Esto no es ni de lejos un programa de análisis para XPM. Primero, se detiene en el primer error que encuentra, por lo que pueden ser necesarios varios ciclos de corrección y reintento para que tu archivo se analice correctamente. Segundo, cxpm solo se preocupa por el formato. Si, por ejemplo, tu mapa de bits usa demasiados colores para tu sistema, aún podrías tener dificultades para mostrarlo. Ten cuidado.

Cuando no se proporciona ningún nombre_archivo, cxpm lee de la entrada estándar.
