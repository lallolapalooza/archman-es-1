NOMBRE

cxl-write-labels - escribe datos en el área de etiquetas de un dispositivo de memoria

SINOPSIS

cxl write-labels <mem> [-i <nombre_archivo>]

DESCRIPCIÓN

El área de etiquetas de región es una pequeña partición persistente de capacidad disponible en algunos dispositivos de memoria CXL. El área de etiquetas se utiliza para configurar o determinar el conjunto de dispositivos de memoria que participan en diferentes conjuntos de intercalación. Lee datos del nombre de archivo de entrada, o de la entrada estándar, y los escribe en el dispositivo <mem> especificado. Tenga en cuenta que el dispositivo no debe estar activo en ninguna región, ni registrado activamente con el subsistema nvdimm. Si lo está, el kernel no permitirá el acceso de escritura al área de datos de etiquetas del dispositivo.

OPCIONES

<dispositivo(s) de memoria>

Un nombre de dispositivo memX, o un número de identificación de memdev. Restringe la operación a los memdev(s) especificados. La palabra clave all puede especificarse para indicar la ausencia de cualquier restricción.

-S, --serial

En lugar de un número de identificación de memdev, interpreta los argumentos <memdev> como una lista de números de serie.

-s, --size=

Limita la operación al número dado de bytes. Un tamaño de 0 indica operar sobre la capacidad total de etiquetas.

-O, --offset=

Inicia la operación en el desplazamiento dado dentro del área de etiquetas.

-v

Activa los mensajes de depuración detallados en la biblioteca (si libcxl se compiló con registro y depuración habilitados).

-b, --bus=

Restringe la operación al bus especificado.

-i, --input

archivo de entrada
