NOMBRE

cyclicdeadline - Este programa se utiliza para probar el planificador de plazos (SCHED_DEADLINE) usando un programa estilo cyclictest

SINOPSIS

cyclicdeadline [-a [CPUSET]] [-D TIEMPO] [-h] [-i INTV] [--json NOMBRE_ARCHIVO] [-s PASO] [-t NUM] [-q]

DESCRIPCIÓN

cyclicdeadline es un programa estilo cyclictest para probar el planificador de plazos (deadline scheduler).

OPCIONES

-a --affinity [CPUSET]
Lista de CPUs separadas por comas/guiones en las que ejecutar las tareas de plazo.
-D --duration TIEMPO
Especifica la duración de la prueba. Añada 'm', 'h', o 'd' para especificar minutos, horas o días.
-h --help
Muestra este menú de ayuda.
-i --interval INTV
El plazo más corto para las tareas en microsegundos. (por defecto 1000us)
--json=NOMBRE_ARCHIVO
Escribe los resultados finales en NOMBRE_ARCHIVO, en formato JSON.
-s --step PASO
La cantidad a aumentar el plazo para cada tarea en microsegundos. (por defecto 500us)
-t --threads NUM
El número de hilos a ejecutar como tareas de plazo (por defecto 1).
-q, --quiet
Imprime solo un resumen al salir. Útil para pruebas automatizadas, donde solo se necesita capturar la salida del resumen.
-b, --breaktrace=USEC
Envía un comando de interrupción de traza cuando la latencia > USEC.
--tracemark
Escribe una marca de traza cuando se excede la latencia de -b.
