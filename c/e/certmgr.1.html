NOMBRE

certmgr - Gestor de certificados de Mono (versión CLI)

SINOPSIS

certmgr [acción] [tipo de objeto] [opciones] almacén [nombre de archivo] o certmgr -ssl [opciones] url

DESCRIPCIÓN

Esta herramienta permite listar, añadir, eliminar o extraer certificados, listas de revocación de certificados (CRL) o listas de confianza de certificados (CTL) desde/hacia un almacén de certificados. Los almacenes de certificados se utilizan para construir y validar cadenas de certificados para la validación de firmas de código Authenticode(r) y certificados de servidor SSL.

ALMACENES

El almacén representa el almacén de certificados a utilizar. Puede ser uno de los siguientes:

Mi
Este es el almacén de certificados personales.
LibretaDirecciones
Este es el almacén para otras personas.
CA
Este es un almacén para autoridades de certificación intermedias.
Confianza
Este es para raíces de confianza.
NoPermitido
Este es para raíces no confiables.

ACCIONES

-list
Lista los certificados, CRL o CTL en el almacén especificado.
-add
Añade un certificado, CRL o CTL al almacén especificado. Si el nombre del archivo es un archivo pkcs12 o pfx, y contiene una clave privada, se importará en el contenedor de pares de claves local.
-del
Elimina un certificado, CRL o CTL del almacén especificado. Debe especificar el objeto a eliminar con su valor hash (y no un nombre de archivo). Este valor hash se muestra al realizar un -list en el almacén.
-put
Copia un certificado, CRL o CTL de un almacén a un archivo.
-ssl
Descarga y añade los certificados de una sesión SSL. Se le pedirá que confirme la adición de cada certificado recibido del servidor. Tenga en cuenta que los protocolos SSL/TLS no requieren que un servidor envíe el certificado raíz. Esta acción asume un tipo de objeto certificado (-c) e importará los certificados en los almacenes apropiados (es decir, el certificado del servidor en el almacén de Otras Personas, el certificado raíz en el almacén de Confianza y cualquier otro certificado intermedio en el almacén de CA Intermedia).
-importKey
Permite importar una clave privada de un archivo pkcs12 a un almacén de pares de claves local. (Útil cuando ya tiene el certificado correspondiente a la clave instalado en el almacén específico).

TIPOS DE OBJETO

-c , -cert , -certificate
Añade, elimina o copia certificados. Es decir, el archivo especificado debe contener certificados X.509 en codificación binaria DER.
-crl
Añade, elimina o copia listas de revocación de certificados (CRL). Es decir, el archivo especificado debe contener listas de revocación de certificados X.509 en codificación binaria DER.
-ctl
Añade, elimina o copia listas de confianza de certificados (CTL). NO SOPORTADO.

OPCIONES

-m
Utiliza los almacenes de certificados de la máquina (en lugar de los almacenes del usuario predeterminados).
-v
Se muestran más detalles en la consola.
-p contraseña
Utiliza la contraseña especificada al acceder a un archivo pkcs12.
-help , -h , -? , /?
Muestra ayuda sobre esta herramienta.

ARCHIVOS

ADVERTENCIA: Esto detalla el comportamiento actual de Mono y podría cambiar entre versiones. La única forma segura de interactuar con los almacenes de certificados es usar la herramienta certmgr. Las versiones actuales de Mono guardan todos los almacenes de certificados de usuario en directorios separados bajo ~/.config/.mono/certs/

Por ejemplo, los certificados raíz de confianza para un usuario se guardarían en
~/.config/.mono/certs/Trust/
Los archivos de certificados se guardan en formato DER (binario) (extensión .cer).
Los nombres de archivo comienzan ya sea con
tbp (huella digital) o ski (identificador de clave del sujeto).
El resto del nombre de archivo es el valor codificado en base64 (tbp o ski).
Los datos de clave privada se almacenan en
~/.config/.mono/keypairs/

EJEMPLOS

mono certmgr.exe -list -c -m Trust
Lista todos los certificados en el almacén de máquina Trust. Esto mostrará el valor hash de cada certificado. Este valor se puede utilizar para identificar unívocamente un certificado para algunas operaciones (por ejemplo, eliminar). Por ejemplo: Hash único: FFA3AC0084DA1673B5A031EBB2156B3E8FBBF6D8
mono certmgr.exe -del -c -m Trust FFA3AC0084DA1673B5A031EBB2156B3E8FBBF6D8
Elimina el certificado, representado por el valor hash, del almacén de máquina Trust. Tenga en cuenta que el almacén de máquina está normalmente restringido. Aparecerá el siguiente mensaje de error si el usuario actual no tiene los derechos de acceso mínimos para eliminar el certificado: Acceso al almacén de certificados de máquina 'Trust' denegado.
certmgr -ssl https://www.verisign.com
Importa certificados de www.verisign.com utilizados para HTTP sobre SSL. Vea PROBLEMAS CONOCIDOS (MD2) si está descargando de www.verisign.com.
certmgr -ssl ldaps://www.nldap.com:636
Importa los certificados de www.nldap.com utilizados para LDAP seguro. Esto funciona incluso si no sabemos cómo hablar LDAP porque detenemos la comunicación poco después del apretón de manos SSL (que nos proporciona el certificado).

PROBLEMAS CONOCIDOS

MD2
Algunos certificados raíz antiguos de Autoridades de Certificación (CA) usan el algoritmo de hash MD2. MD2 es lo suficientemente antiguo como para no ser parte del framework estándar de .NET. Esto hace imposible validar una firma digital realizada con MD2. Por esta razón, MD2 está incluido en el ensamblado Mono.Security.dll. Sin embargo, el archivo machine.config debe actualizarse para que el OID de MD2 sea conocido en tiempo de ejecución.

Para corregir esto, inserte el siguiente fragmento XML dentro del elemento <configuration> de su archivo machine.config.
<mscorlib>
<cryptographySettings>
<cryptoNameMapping>
<cryptoClasses>
<cryptoClass monoMD2="Mono.Security.Cryptography.MD2Managed, Mono.Security, Version=1.0.5000.0, Culture=neutral, PublicKeyToken=0738eb9f132ed756" />
</cryptoClasses>
<nameEntry name="MD2" class="monoMD2" />
</cryptoNameMapping>
<oidMap>
<oidEntry OID="1.2.840.113549.2.2" name="MD2" />
</oidMap>
</cryptographySettings>
</mscorlib>
