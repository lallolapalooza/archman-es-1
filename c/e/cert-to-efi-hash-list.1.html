CERT-TO-EFI-HASH-LIST(1) Comandos de usuario CERT-TO-EFI-HASH-LIST(1)

NOMBRE

cert-to-efi-hash-list - herramienta para convertir certificados openssl a listas de revocación de hashes de firmas EFI

SINOPSIS

cert-to-efi-hash-list [-g <guid>][-t <timestamp>][-s <hash>] <archivo crt> <archivo lista sig efi>

DESCRIPCIÓN

Toma un certificado X509 de entrada (en formato PEM) y lo convierte a un archivo de lista de revocación de hashes de firmas EFI que contiene solo ese certificado individual.

OPCIONES

-g <guid>
Usa <guid> como propietario de la firma. Si no se proporciona, se usará un guid de ceros.
-s <hash>
Usa el algoritmo de hash SHA<hash> (256, 384, 512).
-t <timestamp>
Marca de tiempo de revocación para la firma del hash.
Se establece a 0 si no se especifica, lo que significa revocar por todo el tiempo.

NOTA

Los hashes de revocación de firmas solo están implementados en UEFI 2.4 y versiones posteriores.

EJEMPLOS

Para tomar un certificado X509 estándar en formato PEM y producir un archivo de lista de firmas EFI de salida, simplemente haz:

cert-to-efi-hash-list PK.crt PK.esl

Ten en cuenta que el formato de los archivos de lista de firmas EFI es tal que se pueden simplemente concatenar para producir un archivo con múltiples firmas:

cat PK1.esl PK2.esl > PK.esl

Si tu plataforma tiene una capacidad de manipulación de claves en modo de configuración, las claves a menudo solo se mostrarán por GUID, por lo que usar la opción -g para dar a tus claves GUIDs reconocibles será útil si planeas administrar muchas claves.

VER TAMBIÉN

sign-efi-sig-list(1) para detalles sobre cómo crear una actualización autenticada de variables seguras EFI cuando el sistema EFI está en modo de usuario.
