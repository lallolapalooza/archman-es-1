DESCRIPCIÓ

N

Herramienta para analizar y generar certificados X.509, solicitudes y claves privadas. Puede usarse de forma interactiva o no interactiva especificando la opción de plantilla en la línea de

comandos.

La herramienta acepta archivos o URI soportadas a través de la opción --inf

ile. En caso de que se requiera un PIN para acceder a la URI, puede pro
porcionarlo usando las variables de entorno GNUTLS_PIN y GNUTLS_SO_PIN.

ARCHIVO

S

Formato del archivo de plantilla de certtool
Se puede usar un archivo de plantilla para evitar las preguntas interactivas de certtool. Inicialmente, cree un archivo llamado 'cert.cfg' que contenga la información sobre el certificado. La plantilla puede usarse como

sigue: 


$ certtool --generate-certificate --load-privkey key.pem     --template cert.cfg --outfile cert.pem    --load-ca-certificate ca-cert.pem --load-ca-privkey ca-key.pem

A continuación se muestra un ejemplo de archivo de plantilla de certtool que puede usarse para generar una solicitud de certificado o un certificado

autofirmado. 


# Opciones de certificado X.509
#
# Opciones DN

# La organización del sujeto.
organization = "Koko inc."

# La unidad organizativa del sujeto.
unit = "sleeping dept."

# La localidad del sujeto.
# locality =

# El estado del propietario del certificado.
state = "Attiki"

# El país del sujeto. Código de dos letras.
country = GR

# El nombre común del propietario del certificado.
cn = "Cindy Lauper"

# Un id de usuario del propietario del certificado.
#uid = "clauper"

# Establecer componentes de dominio
#dc = "name"
#dc = "domain"

# Si los OID de DN soportados no son adecuados, puede establecer
# cualquier OID aquí.
# Por ejemplo, establezca el Título X.520 y el Pseudónimo X.520
# usando pares de OID y cadena.
#dn_oid = "2.5.4.12 Dr."
#dn_oid = "2.5.4.65 jackal"

# Esto está obsoleto y no debería usarse en nuevos
# certificados.
# pkcs9_email = "none@none.org"

# Una forma alternativa de establecer directamente el nombre distinguido
# del certificado es con la opción "dn". Los nombres de atributo permitidos son:
# C (país), street, O (organización), OU (unidad), title, CN (nombre común),
# L (localidad), ST (estado), placeOfBirth, gender, countryOfCitizenship, 
# countryOfResidence, serialNumber, telephoneNumber, surName, initials, 
# generationQualifier, givenName, pseudonym, dnQualifier, postalCode, name, 
# businessCategory, DC, UID, jurisdictionOfIncorporationLocalityName,

EJEMPLOS

Generando claves privadas
Para crear una clave privada RSA, ejecute: 

$ certtool --generate-privkey --outfile key.pem --rsa

Para crear una clave privada DSA o de curvas elípticas (ECDSA), use el comando anterior combinado con las opciones 'dsa' o 'ecc'.

Generando solicitudes de certificado
Para crear una solicitud de certificado (necesaria cuando el certificado es emitido por otra parte), ejecute: 

certtool --generate-request --load-privkey key.pem    --outfile request.pem

Si la clave privada está almacenada en una tarjeta inteligente, puede generar una solicitud especificando la URL del objeto de la clave privada. 

$ ./certtool --generate-request --load-privkey "pkcs11:..."   --load-pubkey "pkcs11:..." --outfile request.pem

Generando un certificado autofirmado
Para crear un certificado autofirmado, use el comando: 

$ certtool --generate-privkey --outfile ca-key.pem
$ certtool --generate-self-signed --load-privkey ca-key.pem    --outfile ca-cert.pem

Note que un certificado autofirmado usualmente pertenece a una autoridad de certificación, que firma otros certificados.

Generando un certificado
Para generar un certificado usando la solicitud anterior, use el comando: 

$ certtool --generate-certificate --load-request request.pem    --outfile cert.pem --load-ca-certificate ca-cert.pem    --load-ca-privkey ca-key.pem

Para generar un certificado usando solo la clave privada, use el comando: 

$ certtool --generate-certificate --load-privkey key.pem    --outfile cert.pem --load-ca-certificate ca-cert.pem    --load-ca-privkey ca-key.pem

Información del certificado
Para ver la información del certificado, use: 

$ certtool --certificate-info --infile cert.pem

Cambiando el formato del certificado
Para convertir el certificado de formato PEM a DER, use: 

$ certtool --certificate-info --infile cert.pem --outder --outfile cert.der

Generación de estructura PKCS #12
Para generar una estructura PKCS #12 usando la clave y el certificado anteriores, use el comando: 

$ certtool --load-certificate cert.pem --load-privkey key.pem    --to-p12 --outder --outfile key.p12

Algunas herramientas (reportadamente navegadores web) tienen problemas con ese archivo porque no contiene el certificado de CA para el certificado. Para solucionar ese problema en la herramienta, puede usar el parámetro --load-ca-certificate de la siguiente manera:


$ certtool --load-ca-certificate ca.pem   --load-certificate cert.pem --load-privkey key.pem   --to-p12 --outder --outfile key.p12

Obteniendo parámetros Diffie-Hellman
Para obtener los parámetros RFC7919 para el intercambio de claves Diffie-Hellman, use el comando: 

$ certtool --get-dh-params --outfile dh.pem --sec-param medium

Verificando un certificado
Para verificar un certificado en un archivo contra el almacén de confianza de CA del sistema, use el siguiente comando: 

$ certtool --verify --infile cert.pem

También es posible simular la verificación de nombre de host con las siguientes opciones: 

$ certtool --verify --verify-hostname www.example.com --infile cert.pem

Generación de certificado de proxy
El certificado de proxy puede ser used para delegar su credencial a un certificado temporal, generalmente de vida corta. Para crear uno a partir del certificado creado anteriormente, primero cree una clave temporal y luego genere un certificado proxy para ella, usando los

comandos: 


$ certtool --generate-privkey > proxy-key.pem
$ certtool --generate-proxy --load-ca-privkey key.pem   --load-privkey proxy-key.pem --load-certificate cert.pem   --outfile proxy-cert.pem

Generación de lista de revocación de certificados
Para crear una Lista de Revocación de Certificados (CRL) vacía,

haga: 


$ certtool --generate-crl --load-ca-privkey x509-ca-key.pem            --load-ca-certificate x509-ca.pem

Para crear una CRL que contenga algunos certificados revocados, coloque los certificados en un archivo y use --load-certificate de la siguiente

manera: 


$ certtool --generate-crl --load-ca-privkey x509-ca-key.pem   --load-ca-certificate x509-ca.pem --load-certificate revoked-certs.pem

Para verificar una Lista de Revocación de Certificados (CRL),

haga: 


$ certtool --verify-crl --load-ca-certificate x509-ca.pem < crl.pem
