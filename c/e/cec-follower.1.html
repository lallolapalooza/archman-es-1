NOMBRE

cec-follower - Una aplicación para emular seguidores CEC

SINOPSIS

cec-follower [-h] [-d <dev>] [otras opciones]

DESCRIPCIÓN

La herramienta cec-follower se utiliza para emular seguidores CEC. Basándose en la(s) dirección(es) lógica(s) configurada(s) del dispositivo CEC, emulará el comportamiento CEC de acuerdo.

La configuración del dispositivo CEC se realiza utilizando cec-ctl. Ciertas funcionalidades CEC solo se emulan si está configurado el flag correspondiente de Características del Dispositivo (estos se configuran al usar cec-ctl). Estos son:


- Canal de retorno de audio (RX y TX)
- Control de tasa de audio
- Control de unidad (Deck Control)
- Grabación de pantalla de TV

cec-follower es básicamente un bucle de mensajes, esperando a que lleguen mensajes y tomando la acción apropiada para cada mensaje (los mensajes entrantes se pueden mostrar con la opción --show-msgs). El seguidor mantiene un estado interno con parámetros apropiados como volumen, fuente activa actual, estado de energía, etc. (los cambios de estado se pueden mostrar con la opción --show-state).

También tiene como objetivo ser una implementación de referencia sobre cómo debería comportarse un seguidor.

cec-follower realizará un seguimiento de los mensajes entrantes y buscará violaciones de la especificación CEC con respecto a los tiempos. Por ejemplo, advertirá si recibe el mismo mensaje nuevamente dentro de los 200 ms después de haber respondido <Feature Abort> ["Unrecognized Opcode"] a ese mensaje, y verificará que el comportamiento de presionar y mantener se realiza correctamente.

cec-follower enviará periódicamente mensajes de sondeo para descubrir cuándo se elimina un dispositivo remoto o aparece uno nuevo. Cuando se elimina un dispositivo, la información registrada sobre él se borra. Cada dirección lógica se sondea aproximadamente cada 15 segundos. Entre sondeos, no se detecta la eliminación de un dispositivo remoto o su reemplazo por uno nuevo.

Al ejecutar pruebas de conformidad con cec-compliance, cec-follower debe ejecutarse en el mismo dispositivo para actuar sobre los mensajes entrantes que no son respuestas a mensajes enviados por la herramienta de conformidad. Antes de cada ejecución de prueba, cec-follower debe reiniciarse si se está ejecutando, para inicializar el dispositivo emulado con un estado inicial limpio y conocido.

OPCIONES

-d, --device <dev>
Usa el dispositivo <dev> como dispositivo CEC. Si <dev> es un número, entonces se usa /dev/cec<dev>.
-D, --driver <drv>
Usa un dispositivo cec que tenga el nombre de controlador <drv>, según lo devuelto por la ioctl CEC_ADAP_G_CAPS. Esta opción se puede combinar con -a para identificar de forma única un dispositivo CEC sin tener que depender del número del nodo del dispositivo.
-a, --adapter <nombre-adapt>
Usa un dispositivo cec que tenga el nombre de adaptador <nombre-adapt>, según lo devuelto por la ioctl CEC_ADAP_G_CAPS. Esta opción se puede combinar con -D para identificar de forma única un dispositivo CEC sin tener que depender del número del nodo del dispositivo.
-v, --verbose
Activa la notificación detallada.
--version
Muestra información de la versión.
-w, --wall-clock
Muestra las marcas de tiempo como hora del reloj. Esto también activa la notificación detallada.
-T, --trace
Rastrea todas las ioctls llamadas. Útil para depuración.
-h, --help
Imprime el mensaje de ayuda.
-n, --no-warnings
Desactiva los mensajes de advertencia.
-e, --exclusive
Si se especifica, el seguidor utiliza el modo exclusivo (CEC_MODE_EXCL_FOLLOWER).
-m, --show-msgs
Muestra los mensajes recibidos.
-s, --show-state
Muestra los cambios de estado del dispositivo emulado.
--service-by-dig-id
Informa servicios digitales por ID digital en lugar de por canal.
--standby
Inicia el seguidor en estado Standby.
--toggle-power-status <secs>
Alterna el estado de energía cada <secs> segundos. Solo compatible si el seguidor está emulando un televisor.
-i, --ignore <la>,<opcode>
Ignora mensajes de la dirección lógica <la> y opcode <opcode>. Se puede usar 'all' para <la> o <opcode> para coincidir con todas las direcciones lógicas u opcodes.
--ignore-standby <n>
Ignora cada <n>-ésimo mensaje Standby recibido.
--ignore-view-on <n>
Ignora cada <n>-ésimo mensaje Image/Text View On recibido.

ESTADO DE SALIDA

En caso de éxito, devuelve 0. De lo contrario, devolverá el código de error.
