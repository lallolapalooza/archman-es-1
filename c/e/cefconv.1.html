CEFCONV(1) Manual de comandos generales CEFCONV(1)

NOMBRE

cefconv - convierte un documento TeX que contiene macros CEF a forma `preprocesada'.

SINOPSIS

cefconv < archivo_entrada > archivo_salida

DESCRIPCIÓN

El Chinese Encoding Framework (CEF) desarrollado por Christian Wittern <cwittern@conline.central.de> hace posible incluir caracteres CJK en varias codificaciones usando las macros SGML &CX-aabb; para codificación Big 5 y CNS y &U-aabb; para Unicode (X representa un número entre 0 y 7; 0 representa la codificación Big 5, 1-7 planos CNS 1-7. aabb es un número decimal o hexadecimal)

cefconv convierte las macros CEF a una forma que puede ser procesada directamente con LaTeX 2e.

Este filtro es parte del paquete de macros CJK para LaTeX 2e.

VER TAMBIÉN

sjisconv(1), bg5conv(1), cef5conv(1), cefsconv(1), extconv(1),
los archivos de documentación de CJK.
