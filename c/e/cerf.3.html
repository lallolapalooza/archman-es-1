NOMBRE

cerf, cerfc - funciones de error complejas

SINOPSIS

#include <cerf.h>

double _Complex cerf ( double _Complex z );

double _Complex cerfc ( double _Complex z );

DESCRIPCIÓN

La función cerf es la versión compleja de la función de error: erf(z) = 2/sqrt(pi) * integral de 0 a z de exp(-t*t) dt.

La función de error compleja complementaria cerfc se define como erfc(z) = 1-cerf(z).

VER TAMBIÉN

Los cálculos se basan en la función de Faddeeva w_of_z(3).

Otras funciones de error complejas en libcerf: w_of_z(3), dawson(3), voigt(3), erfcx(3), erfi(3).

La función de error real viene con versiones recientes de glibc, como se solicita en el estándar C99: erf(3)
