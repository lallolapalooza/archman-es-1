CEPL:(1) Comandos de usuario CEPL:(1)

NOMBRE

cepl - un REPL de C y C++

SINOPSIS

cepl [-hpvw] [-a<salida.s>] [-c<compilador>] [-e<código a evaluar>] [-l<biblioteca>] [-I<directorio de inclusión>] [-L<directorio de bibliotecas>] [-s<estándar>] [-o<salida.c>]

DESCRIPCIÓN

Un REPL de C y C++ con readline, historial, autocompletado y deshacer.

USO

Se respetan las siguientes variables de entorno: CFLAGS, LDFLAGS, LDLIBS y LIBS.

El historial de comandos se lee y se guarda en ~/.cepl_history.

Para cambiar entre modos C/C++, especifica tu compilador de C o C++ con -c, por ejemplo:


cepl -cg++ -lboost_filesystem -lboost_context -lboost_system

para ejecutar en modo C++ enlazando contra Boost y compilando con g++, o:


cepl -cclang -lelf

para ejecutar en modo C enlazando contra libelf y compilando con clang.

Cuando se pasa la opción -l, el argumento de la biblioteca se escanea en busca de símbolos que luego se agregan a la autocompletación de readline.

OPCIONES

Opciones de línea de comandos:

-a, --asm Nombre del archivo donde volcar el ensamblador

-c, --compiler Especificar compilador alternativo

-e, --eval Evaluar el argumento como código C/C++

-h, --help Mostrar información de ayuda/uso

-o, --output Nombre del archivo donde volcar el código C/C++

-p, --parse Deshabilitar la adición de símbolos de bibliotecas dinámicas a la autocompletación de readline

-s, --std Especificar qué estándar de C/C++ usar

-v, --version Mostrar información de versión

-w, --warnings Compilar con las opciones -Wall -Wextra -pedantic

-l Enlazar contra la biblioteca especificada (la opción puede repetirse)

-I Buscar directorio para archivos de encabezado (la opción puede repetirse)

-L Buscar directorio para bibliotecas (la opción puede repetirse)

COMANDOS

Las líneas que comienzan con un ; se interpretan como comandos (el texto [] es opcional)

;f[unction] La línea se define fuera de main() (por ejemplo, ;f #define SWAP2(X) ((((X) >> 8) & 0xff) | (((X) & 0xff) << 8)))

;h[elp] Mostrar ayuda

;m[an] Mostrar la página del manual para el argumento (por ejemplo, ;m strpbrk)

;q[uit] Salir de CEPL

;r[eset] Restablecer CEPL a su estado de programa inicial

;u[ndo] Deshacer incremental (se puede repetir)

NOTAS
