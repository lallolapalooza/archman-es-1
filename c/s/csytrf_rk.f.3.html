subrutina csytrf_rk (uplo, n, a, lda, e, ipiv, work, lwork, info)
CSYTRF_RK calcula la factorización de una matriz compleja simétrica indefinida utilizando el método de pivote diagonal Bunch-Kaufman acotado (rook) (algoritmo bloqueado BLAS3).

Documentación de Función/Subrutin

a

subrutina csytrf_rk (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer

info)

CSYTRF_RK calcula la factorización de una matriz compleja simétrica indefinida utilizando el método de pivote diagonal Bunch-Kaufman acotado (rook) (algoritmo bloqueado BLAS3)

.

Propósito

: 
!> CSYTRF_RK calcula la factorización de una matriz compleja simétrica A
!> utilizando el método de pivote diagonal Bunch-Kaufman acotado (rook):
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de
!> permutación, P**T es la transpuesta de P, y D es simétrica y
!> diagonal por bloques con bloques diagonales de tamaño 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!> Para más información, consulte la sección de Detalles Adicionales.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si se almacena la parte triangular superior o inferior
!>          de la matriz simétrica A:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte triangular superior N por N
!>            principal de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no
!>            es referenciada.
!>
!>            Si UPLO = 'L': la parte triangular inferior N por N
!>            principal de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no
!>            es referenciada.
!>
!>          En la salida, contiene:
!>            a) Únicamente los elementos diagonales de la matriz diagonal
!>               por bloques simétrica D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el arreglo E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

E 
!>          E es un arreglo COMPLEX, dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz diagonal por bloques simétrica D
!>          con bloques diagonales de tamaño 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal D(k) de tamaño 1x1, donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 tanto en el
!>          caso UPLO = 'U' como en el caso UPLO = 'L'.
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura por bloques de
!>          la matriz diagonal por bloques simétrica D con bloques diagonales
!>          de tamaño 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de la factorización. Para más información, consulte la sección
!>          de Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          ( en el orden de factorización, k decrece de N a 1 ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de tamaño 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de tamaño 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen ÚNICAMENTE en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en el orden de factorización, k incrementa de 1 a N ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de tamaño 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de tamaño 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen ÚNICAMENTE en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión ( MAX(1,LWORK) ).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >=1.  Para un mejor rendimiento
!>          LWORK >= N*NB, donde NB es el tamaño de bloque devuelto
!>          por ILAENV.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del arreglo WORK,

!>          WORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!
>

O

!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:

NAME


csytrf_rk — CHESVTRF’s underlying routine. Computes the factorization of a general complex
    symmetric matrix.






SYNOPSIS


subroutine csytrf_rk(UPLO, N, A, LDA, IMPIV, WORK, LWORK, INFO)
    character UPLO
    integer N, LDA, LWORK, INFO
    complex(kind=8) A(LDA, *)
    integer IMPIV(*)
    complex(kind=8) WORK(*)







Function/Subroutine Documentation




Purpose:




!>
!>  This routine is used to compute the factorization of a general complex
!>  symmetric matrix A of order N using the bordered block
!>  up/down-right recursive algorithm. The factorization computed is
!>  A = P*U*T*U**H*P**H, where P is a permutation matrix, U is
!>  upper triangular, and T is a block diagonal matrix with blocks
!>  of size 1x1 or 2x2.
!>
!>  The symmetric Schur decomposition is computed only when UPLO = 'U'.
!>
!>  The details of scaling and pivoting are discussed in the following
!>  references:
!>
!>  [1] I. S. Duff and C. V. White, "A symmetric-rank-revealing
!>      factorization procedure", SIAM J. Matrix Anal. Appl., 16(4):
!>      1059-1092, 1995.
!>
!>  [2] N. J. Higham, "Symmetric Rank-Revealing Factorizations",
!>      SIAM J. Matrix Anal. Appl., 16(4): 1093-1110, 1995.
!>
!>  This routine is called by CHESVTRF.
!>
!>  In the following table, n is the order of the matrix T, and k is the
!>  number of blocks.
!>
!>  The values of the entries in IMPIV determine the structure of the
!>  factorization.
!>
!>  If IMPIV(i) > 0, then the i-th block is 1x1 and has dimension IMPIV(i).
!>  If IMPIV(i) < 0, then the i-th block is 2x2 and has dimension -IMPIV(i).
!>
!>  The block sizes are returned in the array IMPIV. The first block size
!>  is IMPIV(1), the second is IMPIV(2), and so on.
!>
!>  The factorization is given by A = P * U * T * U**H * P**H.
!>  The matrix T is stored in the array WORK(1:LWORK).
!>  The matrix U is stored in the upper triangle of A.
!>  The matrix P is stored in the array IMPIV.
!>
!>  The algorithm uses bordered block up/down-right recursive
!>  factorization. The algorithm is described in [1, 2].
!>
!>  The routine determines the block sizes of the factorization, computes
!>  the factorization, and then reconstructs the triangular factor U.
!>
!>  The factor T is returned in the array WORK(1:LWORK).
!>  The factor U is returned in the upper triangle of A.
!>  The permutation matrix P is returned in the array IMPIV.
!>  The block sizes are returned in the array IMPIV.
!>  The block sizes are stored in the array IMPIV.
!>  The permutation matrix P is stored in the array IMPIV.
!>
!>  The routine also stores the pivot information in the array IMPIV.
!>  The pivot information indicates the structure of the block diagonal
!>  matrix T.
!>
!>  The factorization is completed even if the matrix is singular.
!>  If the matrix is singular, the routine returns the factorization
!>  of the non-singular part of the matrix.
!>
!>  The factorization is used to solve a system of equations.
!>
!>  NOTE: INFO only stores the first occurrence of
!>  a singularity, any subsequent occurrence of singularity
!>  is not stored in INFO even though the factorization
!>  always completes.
!>
