CSYSV calcula la solución del sistema de ecuaciones lineales A * X = B para matrices SY

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina csysv (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer info)

CSYSV calcula la solución del sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> CSYSV calcula la solución de un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica de N por N y X y B son matrices de N por
!> NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**T,  si UPLO = 'U', o
!>    A = L * D * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> unitarias superiores (inferiores), y D es simétrica y de bloques
!> diagonales con bloques diagonales de 1x1 y 2x2. La forma factorizada
!> de A se utiliza entonces para resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular de N por N de A contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz diagonal de bloques D y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U*D*U**T o A = L*D*L**T tal como la calcula
!>          CSYTRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          tal como la determina CSYTRF.  Si IPIV(k) > 0, entonces las filas
!>          y columnas k e IPIV(k) fueron intercambiadas, y D(k,k) es un
!>          bloque diagonal de 1x1.  Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0,
!>          entonces las filas y columnas k-1 y -IPIV(k) fueron intercambiadas
!>          y D(k-1:k,k-1:k) es un bloque diagonal de 2x2.  Si UPLO = 'L' e
!>          IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas k+1 y
!>          -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1) es un bloque
!>          diagonal de 2x2.
!>

B

!>          B es un array COMPLEX, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de NRHS por N.
!>          En la salida, si INFO = 0, la matriz solución X de NRHS por N.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1, y para un rendimiento óptimo
!>          LWORK >= max(1,N*NB), donde NB es el tamaño de bloque óptimo para
!>          CSYTRF.
!>          para LWORK < N, TRS se realizará con Nivel BLAS 2
!>          para LWORK >= N, TRS se realizará con Nivel BLAS 3
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          ningún mensaje de error relacionado con LWORK es emitido por
!>          XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal de bloques D
!>               es exactamente singular, por lo que la solución no pudo
!>               ser calculada.
!>
