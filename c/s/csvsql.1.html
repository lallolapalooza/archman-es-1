DESCRIPCIÓ

N

Genera sentencias SQL para un archivo CSV o ejecuta esas sentencias directamente en una base de datos. En este último caso, admite tanto la creación de tablas como la inserción de

datos: 
uso: csvsql [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
              [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
              [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
              [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
              [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V]
              [-i {firebird,mssql,mysql,oracle,postgresql,sqlite,sybase}]
              [--db CONNECTION_STRING] [--query QUERIES] [--insert]
              [--prefix PREFIX] [--before-insert BEFORE_INSERT]
              [--after-insert AFTER_INSERT] [--tables TABLE_NAMES]
              [--no-constraints] [--unique-constraint UNIQUE_CONSTRAINT]
              [--no-create] [--create-if-not-exists] [--overwrite]
              [--db-schema DB_SCHEMA] [-y SNIFF_LIMIT] [-I]
              [--chunk-size CHUNK_SIZE]
              [FILE [FILE ...]]
Genera sentencias SQL para uno o más archivos CSV, o ejecuta esas sentencias
directamente en una base de datos, y ejecuta una o más consultas SQL.
argumentos posicionales:
  FILE                  El(los) archivo(s) CSV sobre los que operar. Si se omite,
                        aceptará la entrada como datos canalizados a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este men
saje de ayuda y sale -i {mssql,mysql,oracle,postgresql,sqlite,duckdb,crate,ingres}, --dialect {mssql,mysql,oracle,postgresql,sqlite,duckdb,crate,ingres} Dialecto de SQL a generar. No se puede usar con --db. --db CONNECTION_STRING Si está presente, una cadena de conexión de SQLAlchemy a usar para ejecutar directamente el SQL generado en una base de datos. --engine-option ENGINE_OPTION ENGINE_OPTION Un argumento de palabra clave para create_engine() de SQLAlchemy, como un par separado por espacios. Esta opción se puede especificar varias veces. Por ejemplo: thick_mode True --query QUERIES Ejecuta una o más consultas SQL delimitadas por --sql- delimiter, y muestra el resultado de la última consulta como CSV. QUERY puede ser un nombre de archivo. --query se puede especificar varias veces. --insert Inserta los datos en la tabla. Requiere --db. --prefix PREFIX Añade una expresión después de la palabra clave INSERT, como OR IGNORE u OR REPLACE. --before-insert BEFORE_INSERT
Antes del comando INSERT, ejecuta una o más consultas SQL delimitadas por --sql-delimiter. Requiere --insert. --after-insert AFTER_INSERT Después del comando INSERT, ejecuta una o más consultas SQL delimitadas por --sql-delimiter. Requiere --insert. --sql-delimiter SQL_DELIMITER Delimitador que separa las consultas SQL en --query, --before-insert y --after-insert. --tables TABLE_NAMES Una lista de nombres de tablas a crear, separados por comas. Por defecto, las tablas se nombrarán según los nombres de archivo sin extensiones o "stdin". --no-constraints Genera un esquema sin límites de longitud ni comprobaciones de nulidad. Útil al muestrear tablas grandes. --unique-constraint UNIQUE_CONSTRAINT Una lista de nombres de columnas a incluir en una restricción UNIQUE, separados por comas. --no-create Omite la creación de la tabla. Requiere --insert. --create-if-not-exists Crea la tabla si no existe, de lo contrario continúa.
Requiere --insert. --overwrite Elimina la tabla si ya existe. Requiere --insert. No se puede usar con --no-create. --db-schema DB_SCHEMA Nombre opcional del esquema de la base de datos en el que crear la(s) tabla(s). -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT Limita la detección de dialecto CSV al número especificado de bytes. Especifica "0" para desactivar la detección por completo, o "-1" para detectar el archivo completo. -I, --no-inference Desactiva la inferencia de tipos (y --locale, --date-format, --datetime-format, --no-leading-zeroes) al analizar la entrada. --chunk-size CHUNK_SIZE Tamaño del lote para la inserción por lotes en la tabla. Requiere --insert. --min-col-len MIN_COL_LEN La longitud mínima de las columnas de texto. --col-len-multiplier COL_LEN_MULTIPLIER Multiplica la longitud máxima de la columna por este multiplicador para acomodar valores más grandes en ejecuciones posteriores.

Véase también: Argumentos comunes a todas la

s herramientas.

Consultar y generar archivos CSV usando

SQL

Puedes usar csvsql para "directamente" consultar uno o más archivos CSV. Ten en cuenta que esto creará una base de datos SQLite en memoria, por lo que no será muy

rápido: 
csvsql --query  "SELECT m.usda_id, avg(i.sepal_le
ngth) AS mean_sepal_length FROM iris AS i JOIN ir
ismeta AS m ON (i.species = m.species) GROUP BY m
.species" examples/iris.csv examples/irismeta.csv

Agrupa filas por una

columna: 
csvsql --query "SE
LECT * FROM 'dumm
y3' GROUP BY a" e
xamples/dummy3.csv

Concatena dos

columnas: 
csvsql --query "SELE
CT a || b FROM 'dumm
y3'" --no-inference
examples/dummy3.csv

Si una columna contiene valores nulos, debes COALESCE la

columna: 
csvsql --query "SELECT a || COALESCE(b, '') FROM 'sort_ints_nulls'" --no-infe
rence examp
les/sort_int
s_nulls.csv

La sentencia SQL UPDATE no produce ninguna salida. Recuerda hacer un SELECT de las columnas y filas que

desees: 
csvsql --query
"UPDATE 'dummy3
' SET a = 'foo'
; SELECT * FROM
'dummy3'" exam
ples/dummy3.csv
