NOMBRE

csvlook - Documentación de csvlook

DESCRIPCIÓN

Representa un CSV en la línea de comandos en un formato de ancho fijo compatible con Markdown:

uso: csvlook [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
               [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
               [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
               [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
               [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V]
               [--max-rows MAX_ROWS] [--max-columns MAX_COLUMNS]
               [--max-column-width MAX_COLUMN_WIDTH]
               [--max-precision MAX_PRECISION] [--no-number-ellipsis]
               [-y SNIFF_LIMIT] [-I]
               [ARCHIVO]
Representa un archivo CSV en la consola como una tabla de ancho fijo compatible
con Markdown.
argumentos posicionales:
  ARCHIVO             El archivo CSV a operar. Si se omite, aceptará datos de
                      entrada a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este mensaje de ayuda y sale
  --max-rows MAX_ROWS   El número máximo de filas a mostrar antes de truncar
                      los datos.
  --max-columns MAX_COLUMNS
                        El número máximo de columnas a mostrar antes de truncar
                        los datos.
  --max-column-width MAX_COLUMN_WIDTH
                        Trunca todas las columnas a un máximo de este ancho. El
                        resto se reemplazará con puntos suspensivos.
  --max-precision MAX_PRECISION
                        El número máximo de lugares decimales a mostrar. El
                        resto se reemplazará con puntos suspensivos.
  --no-number-ellipsis  Deshabilita los puntos suspensivos si se excede
                        --max-precision.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limita la detección del dialecto CSV al número de bytes
                        especificado. Especifica "0" para deshabilitar
                        completamente la detección, o "-1" para detectar todo
                        el archivo.
  -I, --no-inference    Deshabilita la inferencia de tipos (y --locale,
                        --date-format, --datetime-format, --no-leading-zeroes)
                        al analizar la entrada.

Si una tabla es demasiado ancha para mostrarse correctamente, intenta redirigir la salida a less -S o truncarla usando csvcut.

Si la tabla es demasiado larga, intenta filtrarla con grep o redirigir la salida a less.

Ver también: Argumentos comunes a todas las herramientas.

NOTA:

La parte fraccionaria de un número decimal siempre se trunca. Para controlar esta truncación, usa --no-inference junto con --max-column-width.

EJEMPLOS

Uso básico:

csvlook examples/testfixed_converted.csv

Esta herramienta es especialmente útil como operación final al redirigir a través de otras herramientas:

csvcut -c 9,1 examples/realdata/FY09_EDU_Recipients_by_State.csv | csvlook

Si una fila de datos contiene más celdas que la fila de encabezado, csvlook dará un error. Usa csvclean para eliminar dichas filas.

Para ignorar las celdas extra, en su lugar:

csvcut -C "" examples/bad.csv | csvlook

Si estas filas están al principio del archivo (por ejemplo, avisos de derechos de autor), puedes omitirlas:

csvlook --skip-lines 1 examples/bad.csv

Este error también puede ocurrir si csvlook deduce incorrectamente (detecta) el formato CSV. Para deshabilitar la detección de CSV, establece --snifflimit 0 y luego, si es necesario, establece tú mismo las opciones --delimiter y --quotechar. O, establece --snifflimit -1 para usar todo el archivo como muestra, en lugar de los primeros 1024 bytes.
