subrutina cspcon (carácter uplo, entero n, complejo, dimensión( * ) ap, entero, dimensión( * ) ipiv, real anorm, real rcond, complejo, dimensión( * ) work, entero info)

CSPCON

Propósito:

!>
!> CSPCON estima la inversa del número de condición (en la norma 1) de una
!> matriz simétrica compleja empaquetada A utilizando la factorización
!> A = U*D*U**T o A = L*D*L**T calculada por CSPTRF.
!>
!> Se obtiene una estimación de norm(inv(A)), y la inversa del número de
!> condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U': Triangular superior, forma es A = U*D*U**T;
!>          = 'L': Triangular inferior, forma es A = L*D*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX, de dimensión (N*(N+1)/2)
!>          La matriz diagonal por bloques D y los multiplicadores utilizados para
!>          obtener el factor U o L tal como fue calculado por CSPTRF, almacenados
!>          como una matriz triangular empaquetada.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como fue determinada por CSPTRF.
!>

ANORM

!>          ANORM es REAL
!>          La norma 1 de la matriz original A.
!>

RCOND

!>          RCOND es REAL
!>          La inversa del número de condición de la matriz A,
!>          calculada como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
