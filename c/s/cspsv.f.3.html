CSPSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTHER

Documentación de la función/subrutina

subrutina cspsv (caracter uplo, entero n, entero nrhs, complejo, dimensión( * ) ap, entero, dimensión( * ) ipiv, complejo, dimensión( ldb, * ) b, entero ldb, entero info)

CSPSV calcula la solución a un sistema complejo de ecuaciones lineales A * X = B,

Propósito:

!>
!> CSPSV calcula la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica N por N almacenada en formato empaquetado y
!> X y B son matrices N por NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**T,  si UPLO = 'U', o
!>    A = L * D * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de permutaciones y matrices triangulares
!> unitarias superiores (inferiores). D es simétrica y diagonal de bloques con
!> bloques diagonales de 1x1 y 2x2. La forma factorizada de A se utiliza luego
!> para resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es un array COMPLEX, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          simétrica A, empaquetado columna por columna en un array lineal.
!>          La j-ésima columna de A se almacena en el array AP como:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Consulte a continuación para más detalles.
!>
!>          En la salida, la matriz diagonal de bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T, tal como se calcula por CSPTRF,
!>          almacenados como una matriz triangular empaquetada en el mismo
!>          formato de almacenamiento que A.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D, tal
!>          como se determinó por CSPTRF. Si IPIV(k) > 0, entonces las filas y
!>          columnas k e IPIV(k) fueron intercambiadas, y D(k,k) es un bloque
!>          diagonal de 1x1. Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces
!>          las filas y columnas k-1 y -IPIV(k) fueron intercambiadas y
!>          D(k-1:k,k-1:k) es un bloque diagonal de 2x2. Si UPLO = 'L' e
!>          IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas k+1 y
!>          -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1) es un bloque
!>          diagonal de 2x2.
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero. La factorización
!>                se ha completado, pero la matriz diagonal de bloques D es
!>                exactamente singular, por lo que la solución no pudo ser
!>                calculada.
!>
