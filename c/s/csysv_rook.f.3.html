CSYSV_ROOK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

a

subrutina csysv_rook (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer

info)

CSYSV_ROOK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

SY

Propósito

: 
!>
!> CSYSV_ROOK calcula la solución a un sistema complejo de ecuaciones
!> lineales
!>    A * X = B,
!> donde A es una matriz simétrica de N por N y X y B son matrices
!> de N por NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**T,  si UPLO = 'U', o
!>    A = L * D * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> superiores (inferiores) unitarias, y D es simétrica y diagonal por bloques
!> con bloques diagonales de 1 por 1 y 2 por 2.
!>
!> Se llama a CSYTRF_ROOK para calcular la factorización de una matriz
!> simétrica compleja A utilizando el método de pivoteo diagonal
!> acotado de Bunch-Kaufman ().
!>
!> La forma factorizada de A se utiliza entonces para resolver el sistema
!> de ecuaciones A * X = B llamando a CSYTRS_ROOK.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de miembros del segundo miembro, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,N)
!>          Al entrar, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          triangular superior principal de A de N por N contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          inferior de A no se referencia.  Si UPLO = 'L', la
!>          parte triangular inferior principal de A de N por N contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          superior de A no se referencia.
!>
!>          Al salir, si INFO = 0, la matriz diagonal por bloques D y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U*D*U**T o A = L*D*L**T tal como se calculó con
!>          CSYTRF_ROOK.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

IPI

V 
!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura por bloques de D,
!>          tal como lo determinó CSYTRF_ROOK.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>
!>               Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>               columnas k y -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k-1 y -IPIV(k-1) fueron intercambiadas,
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2 por 2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>
!>               Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>               columnas k y -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k+1 y -IPIV(k+1) fueron intercambiadas,
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2 por 2.
!
>

B 
!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          Al entrar, la matriz de miembros del segundo miembro B de N por NRHS.
!>          Al salir, si INFO = 0, la matriz de solución X de N por NRHS.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1, y para el mejor rendimiento
!>          LWORK >= max(1,N*NB), donde NB es el tamaño de bloque óptimo para
!>          CSYTRF_ROOK.
!>
!>          TRS se hará con BLAS de Nivel 2
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero.  La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular, por lo que no se pudo calcular la solución.
!
>
