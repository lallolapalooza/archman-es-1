subrutina csytrf_rk (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CSYTRF_RK calcula la factorización de una matriz simétrica compleja indefinida utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook) (algoritmo bloqueado BLAS3).

Propósito:

!> CSYTRF_RK calcula la factorización de una matriz simétrica compleja A
!> utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook):
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!> Para más información, véase la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte superior N por N de A contiene la parte
!>            triangular superior de la matriz A, y la parte estrictamente
!>            triangular inferior de A no se referencia.
!>
!>            Si UPLO = 'L': la parte inferior N por N de A contiene la parte
!>            triangular inferior de la matriz A, y la parte estrictamente
!>            triangular superior de A no se referencia.
!>
!>          En la salida, contiene:
!>            a) SOLO elementos diagonales de la matriz simétrica diagonal
!>               por bloques D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array COMPLEX, de dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz simétrica diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 tanto en
!>          los casos UPLO = 'U' como UPLO = 'L'.
!>

IPIV

!>          IPIV es array INTEGER, de dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques
!>          de la matriz simétrica diagonal por bloques D con bloques
!>          diagonales de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información, véase la
!>          sección Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          (en orden de factorización, k disminuye de N a 1):
!>            a) Una entrada positiva única IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV solo aparecen en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          (en orden de factorización, k aumenta de 1 a N):
!>            a) Una entrada positiva única IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV solo aparecen en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k y -IPIV(k+1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>

WORK

!>          WORK es array COMPLEX, de dimensión ( MAX(1,LWORK) ).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >=1.  Para un rendimiento óptimo
!>          LWORK >= N*NB, donde NB es el tamaño del bloque devuelto
!>          por ILAENV.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, debido a que:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de la columna k de L) son todos ceros. La
!>               factorización se ha completado, pero la matriz diagonal
!>               por bloques D es exactamente singular, y la división por
!>               cero ocurrirá si

Function/Subroutine Documentation

Purpose:

!>  CSYTRF factoriza una matriz simétrica definida por bloques (compleja) A
!>  en la forma:
!>
!>    U * T * U**H  si UPLO = 'U',
!>    L * T * L**H  si UPLO = 'L',
!>
!>  donde T es una matriz triangular superior/inferior definida por bloques
!>  y U o L son matrices unitarias definidas por bloques. T se almacena en la
!>  diagonal y las super/sub-diagonales de la matriz A de entrada.
!>
!>  La factorización se realiza utilizando el método de pivoteo por
!>  bloques de Bunch-Kaufman. Para una matriz simétrica, U*T*U**H
!>  es también simétrica.
!>
!>  Esta rutina es un wrapper para la rutina de LAPACK CSYTRF_RK.
!>
!>  Argumentos:
!>
!>  UPLO    (input) CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          matrix A is to be computed and stored.
!>          = 'U': Upper triangle
!>          = 'L': Lower triangle
!>
!>  N       (input) INTEGER
!>          The order of the matrix A.  N >= 0.
!>
!>  A       (input/output) COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the symmetric matrix A.  If UPLO = 'U', the leading
!>          N-by-N upper triangular part of A may contain this matrix.
!>          If UPLO = 'L', the leading N-by-N lower triangular part of A
!>          may contain this matrix.
!>
!>  LDA     (input) INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>
!>  IPIV    (output) INTEGER array, dimension (N)
!>          Details of the pivot sequence from the factorization.
!>          IPIV[i] records the dimension of the block pivoted at
!>          row i, for the block starting at row i.
!>          IPIV[i] > 0 => blocks of size IPIV[i] were involved in the
!>                      factorization and the sub-block is triangular.
!>          IPIV[i] < 0 => blocks of size -IPIV[i] were involved in the
!>                      factorization and the sub-block is not triangular.
!>
!>  WORK    (workspace) COMPLEX*16 array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) contains the optimal value of LWORK.
!>
!>  LWORK   (input) INTEGER
!>          The dimension of the array WORK. LWORK >= 1.
!>          For optimum performance LWORK >= N.
!>
!>  INFO    (output) INTEGER
!>          = 0: successful exit
!>          > 0: if INFO = k, then:
!>               U(k,k) is exactly zero. The transformation updates
!>               are not numerical. The factorization has been
!>               completed, but the factor T is not positive definite.
!>          < 0: if INFO = -k, the k-th argument had an illegal value.
!>
!>
!>  Level 3: WORK(1) contains the optimal LWORK
!>
!>  =====================================================================
!>
!>  Further Details:
!>  The block factorization is of the form:
!>
!>     A = P * ( U * T * U**H ) * P**H  if UPLO = 'U',
!>     A = P * ( L * T * L**H ) * P**H  if UPLO = 'L',
!>
!>  where P is a permutation matrix, and L is a unit lower triangular matrix.
!>  T is a triangular block matrix. The diagonal blocks of T are
!>  unit triangular matrices and the off-diagonal blocks are arbitrary
!>  rectangular matrices.
!>  The permutation matrix P is implicitly represented by the entries of IPIV.
!>  The factor T is stored in the upper or lower triangular part of A.
!>
!>  NOTE: INFO only stores the first occurrence of
!>  a singularity, any subsequent occurrence of singularity
!>  is not stored in INFO even though the factorization
!>  always completes.
!>
