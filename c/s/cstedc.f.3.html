CSTEDC

Documentación de la Función/Subrutina

subrutina cstedc (character compz, integer n, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

CSTEDC

Propósito:

!>
!> CSTEDC calcula todos los eigenvalores y, opcionalmente, los eigenvectores de una
!> matriz tridiagonal simétrica utilizando el método de divide y vencerás.
!> Los eigenvectores de una matriz compleja Hermitiana completa o en banda también pueden
!> encontrarse si se ha utilizado CHETRD o CHPTRD o CHBTRD para reducir esta
!> matriz a forma tridiagonal.
!>
!>

Parámetros

COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores.
!>          = 'I':  Calcula también los eigenvectores de la matriz tridiagonal.
!>          = 'V':  Calcula también los eigenvectores de la matriz Hermitiana
!>                  original.  En la entrada, Z contiene la matriz unitaria utilizada
!>                  para reducir la matriz original a forma tridiagonal.
!>

N

!>          N es INTEGER
!>          La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es un array REAL, dimensión (N)
!>          En la entrada, los elementos de la diagonal de la matriz tridiagonal.
!>          En la salida, si INFO = 0, los eigenvalores en orden ascendente.
!>

E

!>          E es un array REAL, dimensión (N-1)
!>          En la entrada, los elementos de la subdiagonal de la matriz tridiagonal.
!>          En la salida, E ha sido destruido.
!>

Z

!>          Z es un array COMPLEX, dimensión (LDZ,N)
!>          En la entrada, si COMPZ = 'V', entonces Z contiene la matriz unitaria
!>          utilizada en la reducción a forma tridiagonal.
!>          En la salida, si INFO = 0, entonces si COMPZ = 'V', Z contiene los
!>          eigenvectores ortonormales de la matriz Hermitiana original,
!>          y si COMPZ = 'I', Z contiene los eigenvectores ortonormales
!>          de la matriz tridiagonal simétrica.
!>          Si  COMPZ = 'N', entonces Z no es referenciado.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1.
!>          Si se desean eigenvectores, entonces LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si COMPZ = 'N' o 'I', o N <= 1, LWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LWORK debe ser al menos N*N.
!>          Nótese que para COMPZ = 'V', entonces si N es menor o
!>          igual al tamaño mínimo de división, usualmente 25, entonces LWORK necesita
!>          ser solo 1.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array REAL, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si COMPZ = 'N' o N <= 1, LRWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LRWORK debe ser al menos
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         donde lg( N ) = el entero más pequeño k tal
!>                         que 2**k >= N.
!>          Si COMPZ = 'I' y N > 1, LRWORK debe ser al menos
!>                         1 + 4*N + 2*N**2 .
!>          Nótese que para COMPZ = 'I' o 'V', entonces si N es menor o
!>          igual al tamaño mínimo de división, usualmente 25, entonces LRWORK
!>          necesita ser solo max(1,2*(N-1)).
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si COMPZ = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si COMPZ = 'V' o N > 1,  LIWORK debe ser al menos
!>                                    6 + 6*N + 5*N*lg N.
!>          Si COMPZ = 'I' o N > 1,  LIWORK debe ser al menos
!>                                    3 + 5*N .
!>          Nótese que para COMPZ = 'I' o 'V', entonces si N es menor o
!>          igual al tamaño mínimo de división, usualmente 25, entonces LIWORK
!>          necesita ser solo 1.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo falló al calcular un eigenvalor mientras
!>                trabajaba en la submatriz que se encuentra en las filas y columnas
!>                INFO/(N+1) a mod(INFO,N+1).
!>
