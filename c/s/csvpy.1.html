NOMBRE

csvpy - Documentación de csvpy

DESCRIPCIÓN

Carga un archivo CSV en un objeto agate.csv.Reader y luego entra en un shell de Python para que el usuario pueda inspeccionar los datos como lo considere oportuno:

uso: csvpy [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
             [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
             [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
             [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
             [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [--dict] [--agate]
             [--no-number-ellipsis] [-y SNIFF_LIMIT] [-I]
             [ARCHIVO]
Carga un archivo CSV en un lector CSV y luego entra en un shell de Python.
argumentos posicionales:
  ARCHIVO               El archivo CSV a operar. Si se omite, aceptará la entrada
                        como datos canalizados a través de STDIN.
argumentos opcionales:
  -h, --help            mostrar este mensaje de ayuda y salir
  --dict                Cargar el archivo CSV en un DictReader.
  --agate               Cargar el archivo CSV en una tabla agate.
  --no-number-ellipsis  Deshabilitar la elipsis si se excede la precisión máxima.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limitar la detección del dialecto CSV al número de bytes
                        especificado. Especificar "0" para deshabilitar la
                        detección por completo, o "-1" para detectar todo el
                        archivo.
  -I, --no-inference    Deshabilitar la inferencia de tipos (y --locale,
                        --date-format, --datetime-format, --no-leading-zeroes)
                        al analizar la entrada.

Esta herramienta utilizará automáticamente el shell IPython si está instalado, de lo contrario utilizará el shell de Python en ejecución.

NOTA:

Debido a limitaciones de la plataforma, csvpy no acepta entrada de archivos como datos canalizados a través de STDIN.

Ver también: Argumentos comunes a todas las herramientas.

EJEMPLOS

Uso básico:

$ csvpy examples/dummy.csv
¡Bienvenido! "examples/dummy.csv" se ha cargado en un objeto lector llamado "reader". >>> next(reader) ['a', 'b', 'c']

Como diccionario:

$ csvpy --dict examples/dummy.csv
¡Bienvenido! "examples/dummy.csv" se ha cargado en un objeto DictReader
llamado "reader".
>>> next(reader)
{'a': '1', 'c': '3', 'b': '2'}

Como tabla agate:

$ csvpy --agate examples/dummy.csv
¡Bienvenido! "examples/dummy.csv" se ha cargado en un objeto from_csv
llamado "reader".
>>> reader.print_table()
|    a | b | c |
| ---- | - | - |
| True | 2 | 3 |
