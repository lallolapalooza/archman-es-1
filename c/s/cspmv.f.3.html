subroutine cspmv (character uplo, integer n, complex alpha, complex, dimension( * ) ap, complex, dimension( * ) x, integer incx, complex beta, complex, dimension( * ) y, integer incy)

CSPMV calcula el producto matriz-vector para vectores complejos usando una matriz simétrica empaquetada compleja

Propósito:

!>
!> CSPMV  realiza la operación matriz-vector
!>
!>    y := alpha*A*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores de n elementos y
!> A es una matriz simétrica de n por n, suministrada en formato empaquetado.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz A se suministra en el array AP de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   Se suministra la parte triangular superior de A
!>                                  en AP.
!>
!>              UPLO = 'L' o 'l'   Se suministra la parte triangular inferior de A
!>                                  en AP.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser mayor o igual a cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es COMPLEX
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

AP

!>          AP es un array COMPLEX, con una dimensión de al menos
!>           ( ( N*( N + 1 ) )/2 ).
!>           Antes de la entrada, con UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 1, 2 )
!>           y a( 2, 2 ) respectivamente, y así sucesivamente.
!>           Antes de la entrada, con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 2, 1 )
!>           y a( 3, 1 ) respectivamente, y así sucesivamente.
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX, con una dimensión de al menos
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el vector x
!>           de N elementos.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es COMPLEX
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, Y no necesita ser establecido en la entrada.
!>           Sin cambios a la salida.
!>

Y

!>          Y es un array COMPLEX, con una dimensión de al menos
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array Y incrementado debe contener el vector y
!>           de n elementos. A la salida, Y se sobrescribe con el vector y
!>           actualizado.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios a la salida.
!>
