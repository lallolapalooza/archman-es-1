Documentación de Función/Subrutina

subroutine csytri_rook (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer info)

CSYTRI_ROOK

Purpose:

!>
!> CSYTRI_ROOK calcula la inversa de una matriz compleja simétrica
!> A utilizando la factorización A = U*D*U**T o A = L*D*L**T
!> calculada por CSYTRF_ROOK.
!>

Parameters

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**T;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L calculados por CSYTRF_ROOK.
!>
!>          En la salida, si INFO = 0, la inversa (simétrica) de la matriz
!>          original. Si UPLO = 'U', se forma la parte triangular superior
!>          de la inversa y la parte de A por debajo de la diagonal no se
!>          referencia; si UPLO = 'L', se forma la parte triangular inferior
!>          de la inversa y la parte de A por encima de la diagonal no se
!>          referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          según lo determinado por CSYTRF_ROOK.
!>

WORK

!>          WORK es array COMPLEX, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
