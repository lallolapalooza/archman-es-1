DESCRIPCIÓ

N

cscope es una herramienta interactiva, orientada a pantalla, que permite al usuario examinar archivos fuente de C en busca de elementos de código

específicos.

Por defecto, cscope examina los archivos fuente de C (.c y .h), lex (.l) y yacc (.y) en el directorio actual. cscope también puede invocarse para archivos fuente nombrados en la línea de comandos. En cualquier caso, cscope busca en los directorios estándar los archivos #include que no encuentra en el directorio actual. cscope utiliza una referencia cruzada de símbolos, llamada cscope.out por defecto, para localizar funciones, llamadas a funciones, macros, variables y símbolos del preprocesador en los

archivos.

cscope construye la referencia cruzada de símbolos la primera vez que se usa en los archivos fuente del programa que se está examinando. En una invocación posterior, cscope reconstruye la referencia cruzada solo si un archivo fuente ha cambiado o si la lista de archivos fuente es diferente. Cuando se reconstruye la referencia cruz

ada, los datos de los archivos no modificados se copian de la referencia cruzada ant
igua, lo que hace que la reconstrucción sea más rápida que la construcción inicial.

Interfaz orientada a

líneas

La opción -l le permite usar cscope donde una interfaz orientada a pantalla no sería útil, por ejemplo, desde otro programa orientado a

pantalla.

cscope mostrará el prompt >> cuando esté listo para una línea de entrada que comienza con el número de campo (contando desde 0) seguido inmediatamente por el patrón de búsqueda, por ejemplo, ``lmain'' encuentra la definición de la función

main.

Si solo desea una búsqueda única, en lugar de la opción -l use las opciones -L y -num de patrón, y no obtendrá el prompt >>

.

Para -l, cscope emite el número de líneas de referencia cscope: 2

líneas

Para cada referencia encontrada, cscope emite una línea que consiste en el nombre del archivo, el nombre de la función, el número de línea y el texto de la línea, separados por espacios, por ejemplo, main.c main 161 main(argc,

argv)

Tenga en cuenta que el editor no es llamado para mostrar una sola referencia, a diferencia de la interfaz orientada a

pantalla.

Puede usar el comando c para alternar ignorar/usar mayúsculas y minúsculas al buscar. (Cuando se ignoran las mayúsculas y minúsculas, la búsqueda de ``FILE'' coincidirá con ``File'' y ``file''.

)

Puede usar el comando r para reconstruir la base de

datos.
