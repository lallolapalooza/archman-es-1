CSYCONV

F

Propósito

: 
!> Si el parámetro WAY = 'C':
!> CSYCONVF convierte el formato de salida de la factorización utilizado en
!> CSYTRF proporcionado en la entrada en el parámetro A al formato de salida
!> de la factorización utilizado en CSYTRF_RK (o CSYTRF_BK) que se almacena
!> en la salida en los parámetros A y E. También convierte in situ los detalles
!> de los intercambios almacenados en IPIV del formato utilizado en CSYTRF al
!> formato utilizado en CSYTRF_RK (o CSYTRF_BK).
!>
!> Si el parámetro WAY = 'R':
!> CSYCONVF realiza la conversión en la dirección inversa, es decir,
!> convierte el formato de salida de la factorización utilizado en CSYTRF_RK
!> (o CSYTRF_BK) proporcionado en la entrada en los parámetros A y E al
!> formato de salida de la factorización utilizado en CSYTRF que se almacena
!> en la salida en el parámetro A. También convierte in situ los detalles
!> de los intercambios almacenados en IPIV del formato utilizado en CSYTRF_RK
!> (o CSYTRF_BK) al formato utilizado en CSYTRF.
!>
!> CSYCONVF también puede convertir en el caso de matrices hermíticas, es decir,
!> entre los formatos utilizados en CHETRF y CHETRF_RK (o CHETRF_BK).
!

csyconvf(3)

NAME

csyconvf - Convert strings to and from unsigned characters.

SYNOPSIS

long int csyconvf( const char *s, char **ptr, int base );

DESCRIPTION

The csyconvf function converts the initial portion of the string pointed to by s to an unsigned character value that is represented by an integer type.

The conversion in both directions is performed as follows:

A string is converted to an unsigned character if it represents an unsigned character.

An unsigned character is converted to a string if it represents an unsigned character.

The argument base determines the interpretation of the string, which can be decimal, octal, hexadecimal, or hexadecimal with a “0x” or “0X” prefix.

The argument ptr is a pointer to a pointer to a character; it indicates where the parsing is to stop. If *ptr is not the null pointer, the function stores in *ptr the address of the character that follows the last character used in the conversion.

The csyconvf function returns the converted value. If no conversion can be performed, 0 is returned.

RETURN VALUE

The csyconvf function returns the converted value. If no conversion can be performed, 0 is returned.
