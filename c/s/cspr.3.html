Documentación de función/subrutina

subrutina cspr (character uplo, integer n, complex alpha, complex, dimension( * ) x, integer incx, complex, dimension( * ) ap)

CSPR realiza la actualización de rango 1 simétrica de una matriz compleja simétrica empaquetada.

Propósito:

!>
!> CSPR    realiza la operación de rango 1 simétrica
!>
!>    A := alpha*x*x**H + A,
!>
!> donde alpha es un escalar complejo, x es un vector de n elementos y A es una
!> matriz simétrica de n por n, suministrada en forma empaquetada.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz A se suministra en el array empaquetado AP de la siguiente
!>           manera:
!>
!>              UPLO = 'U' o 'u'   Se suministra la parte triangular superior de A en AP.
!>
!>              UPLO = 'L' o 'l'   Se suministra la parte triangular inferior de A en AP.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es COMPLEX
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el vector
!>           x de N elementos.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

AP

!>          AP es un array COMPLEX, de dimensión al menos
!>           ( ( N*( N + 1 ) )/2 ).
!>           Antes de la entrada, con UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 1, 2 )
!>           y a( 2, 2 ) respectivamente, y así sucesivamente. A la salida, el array
!>           AP se sobrescribe con la parte triangular superior de la
!>           matriz actualizada.
!>           Antes de la entrada, con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 2, 1 )
!>           y a( 3, 1 ) respectivamente, y así sucesivamente. A la salida, el array
!>           AP se sobrescribe con la parte triangular inferior de la
!>           matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos diagonales no
!>           necesitan establecerse, se asumen que son cero, y a la salida se
!>           establecen a cero.
!>
