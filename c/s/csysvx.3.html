CSYSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> CSYSVX utiliza la factorización de pivoteo diagonal para calcular la
!> solución a un sistema complejo de ecuaciones lineales A * X = B,
!> donde A es una matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A.
!>    La forma de la factorización es
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    unitaria superior (inferior), y D es simétrica y diagonal por bloques con
!>    bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo X y calculando las cotas de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular cotas de error y estimaciones de error residual para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha suministrado
!>          en la entrada o no.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma factorizada
!>                  de A. A, AF e IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte superior
!>          triangular N por N de A contiene la parte superior triangular
!>          de la matriz A, y la parte estrictamente inferior triangular de A
!>          no se referencia. Si UPLO = 'L', la parte inferior
!>          triangular N por N de A contiene la parte inferior triangular
!>          de la matriz A, y la parte estrictamente superior triangular de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T calculada por CSYTRF.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>          devuelve la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por CSYTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' y IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' y IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por CSYTRF.
!>

B

!>          B es array COMPLEX, dimensión (LDB,NRHS)
!>          La matriz B del lado derecho N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array COMPLEX, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del recíproco del número de condición de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular para la precisión
!>          de trabajo.  Esta condición se indica con un código de retorno
!>          de INFO > 0.
!>

FERR

!>          FERR es array REAL, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan fiable como la estimación de RCOND,
!>          y es casi siempre una ligera sobreestimación del error verdadero.
!>

BERR

!>          BERR es array REAL, dimensión (NRHS)
!>          El error residual relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si LWORK = -1, entonces se calcula el tamaño óptimo para WORK.
!>          Las llamadas con LWORK = -1 devuelven el valor óptimo en WORK(1).
!>

RWORK

!>          RWORK es array REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución correcta.
!>          < 0: si INFO = -i, la i-ésima argumento no válido fue encontrado.
!>                 Consecuentemente, la ejecución del cálculo se ha detenido.
!>          > 0: si INFO = i, y 1 <= i <= N, entonces el bloque diagonal i por i
!>                 de D es singular, y la solución no se pudo calcular.
!>                 El factor de A se ha calculado hasta el bloque i.
!>          = N+1: La matriz está mal condicionada. Los cálculos de la solución
!>                 y las cotas de error se han realizado, pero las cotas pueden
!>                 no ser fiables.
!>
