CSPSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTHER

Propósito:

!>
!> CSPSVX utiliza la factorización de pivoteo diagonal A = U*D*U**T o
!> A = L*D*L**T para calcular la solución a un sistema de ecuaciones lineales
!> complejo A * X = B, donde A es una matriz simétrica N por N almacenada
!> en formato empaquetado y X y B son matrices N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de
!> condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se usa el método de pivoteo diagonal para factorizar A como
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    unitarias superiores (inferiores) y D es simétrica y diagonal por bloques
!>    con bloques diagonales de 1 por 1 y 2 por 2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, entonces la
!>    rutina retorna con INFO = i. De lo contrario, la forma factorizada de A
!>    se usa para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como advertencia, pero la rutina continúa
!>    para resolver X y calcular límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X usando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular límites de error y estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          proporcionada en la entrada.
!>          = 'F':  En la entrada, AFP e IPIV contienen la forma factorizada
!>                  de A.  AP, AFP e IPIV no serán modificados.
!>          = 'N':  La matriz A será copiada a AFP y factorizada.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz simétrica A, empaquetado
!>          por columnas en un arreglo lineal.  La j-ésima columna de A es almacenada
!>          en el arreglo AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>          Vea más abajo para más detalles.
!>

AFP

!>          AFP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores usados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T como la calcula CSPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          contiene la matriz diagonal por bloques D y los multiplicadores usados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T como la calcula CSPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura por bloques
!>          de D, como la determina CSPTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2 por 2.  Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2 por 2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura por bloques
!>          de D, como la determina CSPTRF.
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          La matriz de lados derechos B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

X

!>          X es un arreglo COMPLEX, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz de solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del recíproco del número de condición de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular a la precisión
!>          de trabajo.  Esta condición es indicada por un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es un arreglo REAL, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del
!>          elemento más grande en X(j).  La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un arreglo REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector
!>          de solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (2*N)
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  D(i,i) es exactamente cero.  La factorización
!>                       ha sido completada pero el factor D es exactamente

Purpose:




CSPSVX uses the sparse LU factorization to compute the solution to a
    set of linear equations AX = B.




Parameters:


    

  • 

    uplo character(*)
    

    Specifies whether the matrix A stored in AP is upper or lower
        triangular.
    

    
uplo = U : Upper triangular
    

    uplo = L : Lower triangular.
    

    • 

  • 

    n integer
    

    The order of the matrix A.  n >= 0.
    

    • 

  • 

    nrhs integer
    

    The number of right hand sides, i.e., the number of systems
        of equations to solve.
    

    • 

  • 

    ap complex,dimension( * )
    

    The matrix A in the packed storage format. See Further
        Details.
    

    • 

  • 

    b complex,dimension( * )
    

    The matrix B of right hand side vectors, packed columnwise.
        The dimension of B is (ldb, nrhs). If SPBFA was used to factor
        AP, then B should be identical to the input B.
    

    • 

  • 

    ldb integer
    

    The leading dimension of the array B. ldb >= max(1, n).
    

    • 

  • 

    x complex,dimension( * )
    

    The solution matrix X, packed columnwise.
    

    • 

  • 

    ldx integer
    

    The leading dimension of the array X. ldx >= max(1, n).
    

    • 

  • 

    rcond real
    

    On exit, the reciprocal condition number of the matrix A.
        The matrix A is singular if rcond is less than the machine
        epsilon. This parameter is not used by the routine itself, but is
        returned for the user.
    

    • 

  • 

    info integer
    

     = 0: Successful exit
    

    
        < 0: If info = -i, the i-th argument had an illegal value.
    

    
        > 0: If info = k, and k <= N, SPFA failed to compute the
        factorization.  k is the first dimension of the first column
        of A that failed to be factorized.  This is the same value as
        returned by SPFA. If info = N+1, the factorization has been
        completed, but the solution could not be computed because RCOND
        is less than machine epsilon.  This means that the matrix is
        singular to working precision.  Nevertheless, the solution and
        error bounds are computed because there are a number of
        situations where the computed solution can be more accurate than
        the value of RCOND would suggest.
    

    
        = N+1: D is nonsingular, but RCOND is less than machine
        precision, meaning that the matrix is singular
        to working precision.  Nevertheless, the
        solution and error bounds are computed because
        there are a number of situations where the
        computed solution can be more accurate than the
        value of RCOND would suggest.

Further Details:




The packed storage scheme is illustrated by the following example
when N = 4, UPLO = 'U':

Two-dimensional storage of the symmetric matrix A:

   a11 a12 a13 a14
       a22 a23 a24
           a33 a34     (aij = aji)
               a44

Packed storage of the upper triangle of A:

AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
