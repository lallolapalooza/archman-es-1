NOMBRE

csvclean - Documentación de csvclean

DESCRIPCIÓN

Informa y corrige errores comunes en un archivo CSV.

Comprobaciones

  • Informa de las filas que tienen un número de columnas diferente al de la fila de encabezado, si se establece la opción --length-mismatch .
  • Informa de las columnas que están vacías, si se establece la opción --empty-columns .

CONSEJO:

Active todas las comprobaciones con --enable-all-checks (-a).

Correcciones

•
Si un CSV tiene celdas sin comillas que contienen saltos de línea, como:
id,address,country
1,1 Main St
Springfield,US
2,123 Acadia Avenue
London,GB

Use --join-short-rows para intentar corregir los errores fusionando las filas cortas en una sola fila:

id,address,country
1,"1 Main St
Springfield",US
2,"123 Acadia Avenue
London",GB

Para cambiar la cadena utilizada para unir las líneas, use --separator. Por ejemplo, con --separator ", ":

id,address,country
1,"1 Main St, Springfield",US
2,"123 Acadia Avenue, London",GB
•
Si un CSV tiene delimitadores faltantes, como:
id,name,country
1,Alice
2,Bob,CA

Puede añadir los delimitadores faltantes con --fill-short-rows:

id,name,country
1,Alice,
2,Bob,CA

CONSEJO:

¡csvcut sin opciones también añade los delimitadores faltantes!

Para cambiar el valor utilizado para rellenar las filas cortas, use --fillvalue. Por ejemplo, con --fillvalue "US":

id,name,country
1,Alice,US
2,Bob,CA

VÉASE TAMBIÉN:

--header-normalize-space en Uso.

NOTA:

Cada herramienta de csvkit hace lo siguiente:
  • Elimina los caracteres de comillas opcionales, a menos que la opción --quoting (-u) esté establecida para cambiar este comportamiento
  • Cambia el delimitador de campo a una coma, si el delimitador de entrada se establece con las opciones --delimiter (-d) o --tabs (-t)
  • Cambia el delimitador de registro a un salto de línea (LF o \n)
  • Cambia el carácter de comillas a una comilla doble, si el carácter se establece con la opción --quotechar (-q)
  • Cambia la codificación de caracteres a UTF-8, si la codificación de entrada se establece con la opción --encoding (-e)

Salida

csvclean intenta realizar las correcciones seleccionadas. Luego:

  • Si la opción --omit-error-rows está establecida, solo se escriben en la salida estándar las filas que pasan las comprobaciones seleccionadas. Si no, todas las filas se escriben en la salida estándar.
  • Si se habilitan algunas comprobaciones, las filas con errores junto con los números de línea y las descripciones se escriben en la salida de error estándar. Si hay filas con errores, el código de salida es 1.

Uso

usage: csvclean [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
                [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-S] [-H]
                [-K SKIP_LINES] [-v] [-l] [--zero] [-V]
                [FILE]
Corrige errores comunes en un archivo CSV.
positional arguments:
  FILE                  The CSV file to operate on. If omitted, will accept
                        input as piped data via STDIN.
optional arguments:
  -h, --help            show this help message and exit
  --length-mismatch     Report data rows that are shorter or longer than the
                        header row.
  --empty-columns       Report empty columns as errors.
  -a, --enable-all-checks
                        Enable all error reporting.
  --omit-error-rows     Omit data rows that contain errors, from standard
                        output.
  --label LABEL         Add a "label" column to standard error. Useful in
                        automated workflows. Use "-" to default to the input
                        filename.
  --header-normalize-space
                        Strip leading and trailing whitespace and replace
                        sequences of whitespace characters by a single space
                        in the header.
  --join-short-rows     Merges short rows into a single row.
  --separator SEPARATOR
                        The string with which to join short rows. Defaults to
                        a newline.
  --fill-short-rows     Fill short rows with the missing cells.
  --fillvalue FILLVALUE
                        The value with which to fill short rows. Defaults to
                        none.

Véase también: Argumentos comunes a todas las herramientas.

EJEMPLOS

Probar un archivo con filas de datos más cortas y más largas que la fila de encabezado:

$ csvclean examples/bad.csv 2> errors.csv
column_a,column_b,column_c
0,mixed types.... uh oh,17
$ cat errors.csv
line_number,msg,column_a,column_b,column_c
1,"Expected 3 columns, found 4 columns",1,27,,I'm too long!
2,"Expected 3 columns, found 2 columns",,I'm too short!

NOTA:

Si alguna fila de datos es más larga que la fila de encabezado, necesita añadir columnas manualmente: por ejemplo, añadiendo uno o más delimitadores (,) al final de la fila de encabezado. csvclean no puede hacer esto, porque está diseñado para funcionar con la entrada estándar, y corregir un error al principio de los datos CSV basándose en una observación posterior en los datos CSV requeriría mantener todos los datos CSV en memoria, lo cual no es una opción para archivos grandes.

Probar un archivo con columnas vacías:

$ csvclean --empty-columns examples/test_empty_columns.csv 2> errors.csv
a,b,c,,
a,,,,
,,c,,
,,,,
$ cat errors.csv
line_number,msg,a,b,c,,
1,"Empty columns named 'b', '', ''! Try: csvcut -C 2,4,5",,,,,

Use csvcut para excluir las columnas vacías:

$ csvcut -C 2,4,5 examples/test_empty_columns.csv
a,c
a,
,c
,

Para cambiar el final de línea de salto de línea (LF o \n) a retorno de carro y salto de línea (CRLF o \r\n), use:

csvformat -M $'\r\n' examples/dummy.csv
