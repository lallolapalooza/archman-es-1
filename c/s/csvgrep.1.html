NOMBRE

csvgrep - Documentación de csvgrep

DESCRIPCIÓN

Filtra datos tabulares para mostrar solo aquellas filas donde ciertas columnas contienen un valor dado o coinciden con una expresión regular:

uso: csvgrep [-h] [-d DELIMITADOR] [-t] [-q CARACTER_DE_COMILLAS] [-u {0,1,2,3}] [-b]
               [-p CARACTER_DE_ESCAPE] [-z LIMITE_TAMAÑO_CAMPO] [-e CODIFICACION] [-S] [-H]
               [-K SALTAR_LINEAS] [-v] [-l] [--zero] [-V] [-n] [-c COLUMNAS]
               [-m PATRON] [-r EXPRESION_REGULAR] [-f ARCHIVO_COINCIDENCIAS] [-i] [-a]
               [ARCHIVO]
Busca archivos CSV. Como el comando Unix "grep", pero para datos tabulares.
argumentos posicionales:
  ARCHIVO               El archivo CSV a procesar. Si se omite, aceptará la entrada
                        como datos enviados por tubería a través de STDIN.
argumentos opcionales:
  -h, --help            Muestra este mensaje de ayuda y sale.
  -n, --names           Muestra los nombres e índices de las columnas del CSV de entrada
                        y sale.
  -c COLUMNAS, --columns COLUMNAS
                        Una lista separada por comas de índices, nombres o rangos de
                        columnas a buscar, p. ej., "1,id,3-5".
  -m PATRON, --match PATTERN
                        Una cadena a buscar.
  -r REGEX, --regex REGEX
                        Una expresión regular para que coincida.
  -f MATCHFILE, --file MATCHFILE
                        Una ruta a un archivo. Para cada fila, si alguna línea del
                        archivo (despojada de separadores de línea) es una coincidencia
                        exacta del valor de la celda, la fila coincide.
  -i, --invert-match    Selecciona filas no coincidentes, en lugar de filas coincidentes.
  -a, --any-match       Selecciona filas en las que alguna columna coincida, en lugar de
                        todas las columnas.

Ver también: Argumentos comunes a todas las herramientas.

NOTA: Aunque '-m', '-r', y '-f' se enumeran como argumentos "opcionales", debes especificar uno de ellos.

EJEMPLOS

Busca la fila relacionada con Illinois:

csvgrep -c 1 -m ILLINOIS examples/realdata/FY09_EDU_Recipients_by_State.csv

Busca filas relacionadas con estados cuyos nombres comiencen con la letra "I":

csvgrep -c 1 -r "^I" examples/realdata/FY09_EDU_Recipients_by_State.csv

Busca filas que no contengan una celda de estado vacía:

csvgrep -c 1 -r "^$" -i examples/realdata/FY09_EDU_Recipients_by_State.csv

Realiza una búsqueda insensible a mayúsculas y minúsculas:

csvgrep -c 1 -r "(?i)illinois" examples/realdata/FY09_EDU_Recipients_by_State.csv

Elimina las filas de comentarios:

printf "a,b\n1,2\n# un comentario\n3,4" | csvgrep --invert-match -c1 -r '^#'

Obtén los índices de las columnas que contienen texto coincidente (\x1e es el carácter separador de registro (RS)):

csvgrep -m 22 -a -c 1- examples/realdata/FY09_EDU_Recipients_by_State.csv | csvformat -M $'\x1e' | xargs -d $'\x1e' -n1 sh -c 'echo $0 | csvcut -n' | grep 22

NOTA:

Este último ejemplo no es eficiente.
