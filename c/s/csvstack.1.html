NOMBRE

csvstack - Documentación de csvstack

DESCRIPCIÓN

Apila las filas de múltiples archivos CSV, añadiendo opcionalmente un valor de agrupación a cada fila:

uso: csvstack [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
                [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-S] [-H]
                [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-g GROUPS]
                [-n GROUP_NAME] [--filenames]
                [ARCHIVO [ARCHIVO ...]]
Apila las filas de múltiples archivos CSV, añadiendo opcionalmente un valor de agrupación.
argumentos posicionales:
  ARCHIVO               Los archivos CSV sobre los que operar. Si se omite, aceptará
                        la entrada como datos canalizados a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este mensaje de ayuda y sale
  -g GROUPS, --groups GROUPS
                        Una lista separada por comas de valores a añadir como "factores de agrupación",
                        uno por cada CSV que se está apilando. Se añaden a la salida como una nueva columna.
                        Puede especificar un nombre para la nueva columna usando la bandera -n.
  -n GROUP_NAME, --group-name GROUP_NAME
                        Un nombre para la columna de agrupación, p. ej. "año". Solo se utiliza
                        cuando también se especifica -g.
  --filenames           Utiliza el nombre de archivo de cada archivo de entrada como su valor de agrupación.
                        Cuando se especifica, se ignorará -g.

Ver también: Argumentos comunes a todas las herramientas.

ADVERTENCIA:

Si rediriges la salida a un archivo de entrada como csvstack archivo.csv > archivo.csv, el archivo crecerá indefinidamente.

EJEMPLOS

Unir un conjunto de archivos para diferentes años:

csvstack -g 2009,2010 examples/realdata/FY09_EDU_Recipients_by_State.csv examples/realdata/Datagov_FY10_EDU_recp_by_State.csv

Añadir una sola columna a la izquierda de un CSV:

csvstack -n NUEVACOL -g "" examples/dummy.csv
