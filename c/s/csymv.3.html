subroutine csymv (character uplo, integer n, complex alpha, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, integer incx, complex beta, complex, dimension( * ) y, integer incy)

CSYMV calcula el producto de una matriz por un vector para una matriz simétrica compleja.

Propósito:

!>
!> CSYMV  realiza la operación de matriz por vector
!>
!>    y := alpha*A*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores de n elementos y
!> A es una matriz simétrica de n por n.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la parte triangular superior o inferior
!>           del array A se va a referenciar como sigue:
!>
!>              UPLO = 'U' o 'u'   Solo se referenciará la parte triangular superior de A.
!>
!>              UPLO = 'L' o 'l'   Solo se referenciará la parte triangular inferior de A.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es COMPLEX
!>           Al entrar, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

A

!>          A es un array COMPLEX, de dimensión ( LDA, N )
!>           Antes de la entrada, con UPLO = 'U' o 'u', la parte superior
!>           triangular principal de n por n del array A debe contener la parte triangular
!>           superior de la matriz simétrica y la parte estrictamente triangular inferior de A no se referencia.
!>           Antes de la entrada, con UPLO = 'L' o 'l', la parte inferior
!>           triangular principal de n por n del array A debe contener la parte triangular
!>           inferior de la matriz simétrica y la parte estrictamente triangular superior de A no se referencia.
!>           Sin cambios a la salida.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa llamador (subrutina). LDA debe ser al menos
!>           max( 1, N ).
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el vector x
!>           de N elementos.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           Al entrar, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es COMPLEX
!>           Al entrar, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, entonces Y no necesita estar configurado a la entrada.
!>           Sin cambios a la salida.
!>

Y

!>          Y es un array COMPLEX, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array Y incrementado debe contener el vector y
!>           de n elementos. A la salida, Y se sobrescribe con el vector y actualizado.
!>

INCY

!>          INCY es INTEGER
!>           Al entrar, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios a la salida.
!>
