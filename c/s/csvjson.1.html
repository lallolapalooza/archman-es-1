NOMBRE

csvjson - Documentación de csvjson

DESCRIPCIÓN

Convierte un archivo CSV en JSON o GeoJSON (dependiendo de las opciones):

uso: csvjson [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
               [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
               [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
               [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
               [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-i INDENT]
               [-k KEY] [--lat LAT] [--lon LON] [--type TYPE]
               [--geometry GEOMETRY] [--crs CRS] [--no-bbox] [--stream]
               [-y SNIFF_LIMIT] [-I]
               [FILE]
Convierte un archivo CSV en JSON (o GeoJSON).
argumentos posicionales:
  FILE                  El archivo CSV a procesar. Si se omite, aceptará la
                        entrada como datos transmitidos a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este mensaje de ayuda y sale
  -i INDENT, --indent INDENT
                        indenta el JSON de salida en tantos espacios. Desactivado
                        por defecto.
  -k KEY, --key KEY     salida JSON como un objeto con clave de una columna dada,
                        KEY, en lugar de como una matriz. Todos los valores de
                        columna deben ser únicos. Si se especifican --lat y --lon,
                        esta columna se utiliza como el ID de la Característica GeoJSON.
  --lat LAT             un índice o nombre de columna que contiene una latitud. La
                        salida será GeoJSON en lugar de JSON. Requiere --lon.
  --lon LON             un índice o nombre de columna que contiene una longitud. La
                        salida será GeoJSON en lugar de JSON. Requiere --lat.
  --type TYPE           un índice o nombre de columna que contiene un tipo GeoJSON.
                        La salida será GeoJSON en lugar de JSON. Requiere --lat
                        y --lon.
  --geometry GEOMETRY   un índice o nombre de columna que contiene una geometría GeoJSON.
                        La salida será GeoJSON en lugar de JSON. Requiere --lat
                        y --lon.
  --crs CRS             una cadena de sistema de referencia de coordenadas a incluir
                        con la salida GeoJSON. Requiere --lat y --lon.
  --no-bbox             desactivar el cálculo de un cuadro delimitador.
  --stream              salida JSON como un flujo de objetos separados por saltos de línea,
                        en lugar de como una matriz.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        limitar la detección del dialecto CSV al número de bytes especificado.
                        Especificar "0" para deshabilitar la detección por completo, o
                        "-1" para detectar todo el archivo.
  -I, --no-inference    deshabilitar la inferencia de tipo (y --locale, --date-format,
                        --datetime-format, --no-leading-zeroes) al analizar la entrada.

Ver también: Argumentos comunes a todas las herramientas.

EJEMPLOS

Convertir el conjunto de datos de educación de veteranos a JSON con clave por abreviatura de estado:

$ csvjson -k "State Abbreviate" -i 4 examples/realdata/FY09_EDU_Recipients_by_State.csv
{
    "AL": {
        "State Name": "ALABAMA",
        "State Abbreviate": "AL",
        "Code": 1.0,
        "Montgomery GI Bill-Active Duty": 6718.0,
        "Montgomery GI Bill- Selective Reserve": 1728.0,
        "Dependents' Educational Assistance": 2703.0,
        "Reserve Educational Assistance Program": 1269.0,
        "Post-Vietnam Era Veteran's Educational Assistance Program": 8.0,
        "TOTAL": 12426.0,
        "j": null
    },
    "...": {
        "...": "..."
    }
}
