subrutina csysvx (character fact, character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CSYSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> CSYSVX usa la factorización de pivoteo diagonal para calcular la
!> solución a un sistema complejo de ecuaciones lineales A * X = B,
!> donde A es una matriz simétrica de N por N y X y B son matrices
!> de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una
!> estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se usa el método de pivoteo diagonal para factorizar A.
!>    La forma de la factorización es
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    superiores (inferiores) unitarias, y D es simétrica y diagonal por bloques
!>    con bloques diagonales de 1 por 1 y 2 por 2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, entonces la
!>    rutina retorna con INFO = i. De lo contrario, la forma factorizada de A
!>    se usa para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de máquina,
!>    se retorna INFO = N+1 como una advertencia, pero la rutina continúa
!>    para resolver X y calcular los límites de error como se describe a
!>    continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X usando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular límites de error y estimaciones de error hacia
!>    atrás para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          proporcionada en la entrada o no.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma
!>                  factorizada de A.  A, AF e IPIV no serán modificados.
!>          = 'N':  La matriz A será copiada a AF y factorizada.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte triangular
!>          superior N por N de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior
!>          de A no es referenciada.  Si UPLO = 'L', la parte triangular
!>          inferior N por N de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior
!>          de A no es referenciada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

AF

!>          AF es un arreglo COMPLEX, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>          entrada contiene la matriz diagonal por bloques D y los
!>          multiplicadores usados para obtener el factor U o L de la
!>          factorización A = U*D*U**T o A = L*D*L**T tal como fue
!>          calculada por CSYTRF.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la
!>          salida retorna la matriz diagonal por bloques D y los
!>          multiplicadores usados para obtener el factor U o L de la
!>          factorización A = U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la
!>          entrada contiene detalles de los intercambios y la estructura
!>          de bloques de D, tal como fueron determinados por CSYTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2 por 2.  Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 e -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2 por 2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la
!>          salida contiene detalles de los intercambios y la estructura
!>          de bloques de D, tal como fueron determinados por CSYTRF.
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          La matriz de miembros derechos B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

X

!>          X es un arreglo COMPLEX, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz de solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del recíproco del número de condición de la
!>          matriz A.  Si RCOND es menor que la precisión de máquina (en
!>          particular, si RCOND = 0), la matriz es singular a la precisión
!>          de trabajo.  Esta condición es indicada por un código de retorno
!>          de INFO > 0.
!>

FERR

!>          FERR es un arreglo REAL, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector
!>          de solución X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento
!>          más grande en (X(j) - XTRUE) dividido por la magnitud del
!>          elemento más grande en X(j).  La estimación es tan confiable
!>          como la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un arreglo REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector de solución X(j) (es decir, el cambio relativo más
!>          pequeño en cualquier elemento de A o B que hace de X(j) una
!>          solución exacta).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) retorna el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= max(1,2*N), y para un mejor
!>          rendimiento, cuando FACT = 'N', LWORK >= max(1,2*N,N*NB), donde
!>          NB es el tamaño de bloque óptimo para CSYTRF.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, y i es
!>                <= N:  D(i,i) es exactamente cero.  La factorización
!>                       se ha completado pero el factor D es exactamente
!>                       singular, por lo que la solución y las cotas de error
!>                       no pudieron calcularse. Se devuelve RCOND = 0.
!>                = N+1: D es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       hasta la precisión de trabajo. Sin embargo,
!>                       la solución y las cotas de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que la
!>                       que sugeriría el valor de RCOND.
!>
