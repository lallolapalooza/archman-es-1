CSYRFSX

Propósito:

!>
!>    CSYRFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales cuando la matriz de coeficientes es simétrica indefinida,
!>    y proporciona cotas de error y estimaciones de error hacia atrás para
!>    la solución.  Además de la cota de error normwise, el código
!>    proporciona la cota de error componente a componente máxima si es posible.
!>    Ver los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP para detalles
!>    de las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe en los
!>    argumentos EQUED y S más abajo. En este caso, la solución y las
!>    cotas de error devueltas son para el sistema original no equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores predeterminados son aceptables. Si los
!>     valores predeterminados son aceptables, los usuarios pueden pasar
!>     NPARAMS = 0, lo que evita que el código fuente acceda al argumento
!>     PARAMS.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'Y':  Equilibrado tanto en filas como en columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte triangular
!>     superior N por N principal de A contiene la parte triangular
!>     superior de la matriz A, y la parte estrictamente triangular
!>     inferior de A no se referencia. Si UPLO = 'L', la parte triangular
!>     inferior N por N principal de A contiene la parte triangular
!>     inferior de la matriz A, y la parte estrictamente triangular
!>     superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX, dimensión (LDAF,N)
!>     La forma factorizada de la matriz A.  AF contiene la matriz
!>     diagonal por bloques D y los multiplicadores utilizados para obtener
!>     U o L de la factorización A = U*D*U**T o A = L*D*L**T tal como fue
!>     calculada por CSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como fueron determinados por CSYTRF.
!>

S

!>          S es array REAL, dimensión (N)
!>     Los factores de escala para A. Si EQUED = 'Y', A se multiplica a
!>     la izquierda y a la derecha por diag(S). S es un argumento de entrada
!>     si FACT = 'F'; de lo contrario, S es un argumento de salida. Si FACT = 'F'
!>     y EQUED = 'Y', cada elemento de S debe ser positivo. Si S es de salida,
!>     cada elemento de S es una potencia de la base. Si S es de entrada,
!>     cada elemento de S debe ser una potencia de la base para garantizar
!>     una solución y estimaciones de error fiables. El escalado por potencias
!>     de la base no causa errores de redondeo a menos que el resultado
!>     sea subdesbordado o sobradesbordado. Los errores de redondeo durante
!>     el escalado conducen a un refinamiento con una matriz que no es
!>     equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

B

!>          B es array COMPLEX, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array COMPLEX, dimensión (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como fue calculada por CGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición escalada recíproca. Esta es una estimación del número
!>     de condición de Skeel escalado recíproco de la matriz A después
!>     del equilibrado (si se realizó). Si esto es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error puede ser
!>     aún pequeño incluso si este número es muy pequeño y la matriz
!>     parece mal condicionada.
!>

BERR

!>          BERR es array REAL, dimensión (NRHS)
!>     Error relativo componente a componente hacia atrás. Este es el
!>     error relativo componente a componente hacia atrás de cada vector
!>     solución X(j) (es decir, el cambio relativo más pequeño en cualquier
!>     elemento de A o B que haga de X(j) una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP más abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos
s:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación normwise
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si el error
!>              la estimación es . Estos recíprocos de condición
!>              los números son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*A, donde S escala cada fila por una potencia del
!>              raíz para que todas las sumas de filas absolutas de Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array REAL, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo por componentes, que se define de la siguiente manera:
!>
!>     Error relativo por componentes en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por el lado derecho i (del que depende el
!>     error relativo por componentes), y el tipo de información de error
!>     como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada lado derecho. Si
!>     no se solicita precisión por componentes (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación del número de
!>              condición recíproco por componentes. Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si el error
!>              la estimación es . Estos recíprocos de condición
!>              los números son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas de filas absolutas
!>              de Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones adicionales.
!>

NPARAMS

!>          NPARAMS es un ENTERO
!>     Especifica el número de parámetros establecidos en PARAMS. Si es <= 0,
!>     el array PARAMS nunca se accede y se utilizan los valores predeterminados.
!>

PARAMS

!>          PARAMS es un array REAL, de dimensión NPARAMS
!>     Especifica los parámetros del algoritmo. Si una entrada es < 0.0, entonces
!>     esa entrada se rellenará con el valor predeterminado utilizado para ese
!>     parámetro. Solo se accede a las posiciones hasta NPARAMS; se utilizan
!>     valores predeterminados para parámetros de mayor número.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar refinamiento iterativo
!>            o no.
!>         Predeterminado: 1.0
!>            = 0.0:  No se realiza refinamiento y no se calculan límites de error.
!>            = 1.0:  Utiliza el algoritmo de refinamiento de doble precisión,
!>                    posiblemente con cálculos de doble precisión simple si el
!>                    entorno de compilación no soporta DOBLE
!>                    PRECISIÓN.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de residuales
!>            cálculos permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecer en 100 para permitir la convergencia utilizando
!>                     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>                     la factorización utiliza una técnica distinta de
!>                     eliminación gaussiana, las garantías en
!>                     err_bnds_norm y err_bnds_comp pueden ya no ser
!>                     confiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicador que determina si el código
!>            intentará encontrar una solución con un pequeño error relativo
!>            por componentes en el algoritmo de doble precisión. Positivo
!>            es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia por componentes)
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL, de dimensión (2*N)
!>

INFO

!>          INFO es un ENTERO
!>       = 0:  Salida exitosa. La solución para cada lado derecho está
!>         garantizada.
!>       < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero. La factorización
!>         se ha completado, pero el factor U es exactamente singular, por lo que
!>         la solución y los límites de error no pudieron calcularse. Se devuelve RCOND = 0.
!>       = N+J: La solución correspondiente al J-ésimo lado derecho
!>         no está garantizada. Las soluciones correspondientes a otros lados
!>         derechos K con K > J tampoco pueden estar garantizadas, pero
!>         solo se informa el primer lado derecho de este tipo. Si no se solicita
!>         un pequeño error por componentes (PARAMS(3) = 0.0), entonces
!>         el J-ésimo lado derecho es el primero con un límite de error normwise
!>         que no está garantizado (el J más pequeño tal que
!>         ERR_BNDS_NORM(J,1) = 0.0). Por defecto (PARAMS(3) = 1.0)
!>         el J-ésimo lado derecho es el primero con un límite de error normwise o
!>         por componentes que no está garantizado (el J más pequeño tal que
!>         ya sea ERR_BNDS_NORM(J,1) = 0.0 o
!>         ERR_BNDS_COMP(J,1) = 0.0). Ver la definición de
!>         ERR_BNDS_NORM(:,1) y ERR_BNDS_COMP(:,1). Para obtener información
!>         sobre todos los lados derechos, compruebe ERR_BNDS_NORM o
!>         ERR_BNDS_COMP.
!>
