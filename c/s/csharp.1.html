DESCRIPCIÓ

N

El comando csharp es un shell interactivo de C# y un host de scripting que permite al usuario introducir y evaluar sentencias y expresiones de C# desde la línea de comandos o ejecutar scripts de C#. Las opciones regulares de la línea de comandos de mcs se pueden utilizar en esta versión del

compilador.

Los archivos especificados en la línea de comandos se cargarán y ejecutarán como

scripts.

A partir de Mono 2.10, el comando csharp se puede usar como un intérptre ejecutado por ejecutables marcados con el atributo de ejecución de Unix. Para hacer esto, haga que la primera línea de su código fuente de C# se vea

así: 
  #!/usr/bin/csharp
  Console.WriteLine ("Hello, World")
;

A partir de Mono 5.0, los argumentos de la línea de comandos ahora se pueden pasar al comando csharp especificando las opciones -s o -- (script)

.

La opción -s es ideal para interpretar scripts ejecutables que utilizan la sintaxis shebang (introducida en Mono 2.10). Esto permite que los argumentos de la línea de comandos se pasen y se consuman limpiamente por el

script: 
  #!/usr/bin/csharp -s
  foreach (var arg in Args)
    Console.WriteLine ($"script argument: {arg}
")
;

comandos:
-s
ARCHIVO_DE_SCRIPT
Esta opción es ideal para crear scripts ejecutables que utilizan la función shebang de Unix. Unix añadirá implícitamente como argumento la ruta del script a ejecutar. Cuando se invoca el ejecutable, cualquier argumento que se le pase estará disponible en la variable global Args. Ejemplo: #!/usr/bin/env csharp

interactivo.

ch
Esta es una opción avanzada y solo debe usarse si tiene un conocimiento profundo de multiprocesamiento. Esta opción está disponible en el comando csharp y permite inyectar el compilador en otros procesos. Esto se hace inyectando el shell de C# en un hilo separado que se ejecuta concurrentemente con su aplicación. Esto significa que debe tomar medidas especiales para evitar que la aplicación de destino se bloquee mientras la usa. Por ejemplo, es posible que deba tomar los bloqueos adecuados antes de emitir cualquier comando que pueda afectar el estado del proceso de destino, o enviar comandos a través de un despachador de

OPERACIÓ

N

Una vez que lance el comando csharp, se le presentará el prompt

interactivo: 
$ csharp
Mono C# Shell, type "help;" for help
Enter statements below.
csharp>

Hay varios espacios de nombres predefinidos en C#, estos incluyen System, System.Linq, System.Collections y System.Collections.Generic. A diferencia del modo compilado, es posible añadir nuevas sentencias using mientras escribe código, por

ejemplo: 
csharp> new XmlDocument ();
<interactive>(1,6): error CS0246: The type or namespace name `XmlDocument' could not be found. Are you missing a using directive or an assembly reference?
csharp> using System.Xml;
csharp> new XmlDocument (); 
System.Xml.
XmlDocument

Cada vez que se escribe un comando, el ámbito de ese comando es el de una clase que deriva de la clase Mono.CSharp.InteractiveBase. Esta clase define una serie de propiedades y métodos estáticos. Para mostrar una lista de comandos disponibles, acceda a la propiedad

`help': 
csharp> help;
"Static methods:
  LoadPackage (pkg); - Loads the given Package (like -pkg:FILE)
  [...]
  ShowVars ();       - Shows defined local variables.
  ShowUsing ();      - Show active using decltions.
  help;
"
csharp>

Cuando se introducen expresiones, el shell de C# mostrará el resultado de ejecutar la

expresión: 
csharp> Math.Sin (Math.PI/4); 
0.707106781186547
csharp> 1+1;
2
csharp> "Hello, world".IndexOf (',');
5

El shell de C# usa el método ToString() del objeto devuelto para mostrar el objeto, esto a veces puede ser limitante ya que los objetos que no sobrescriben el método ToString() obtendrán el comportamiento predeterminado de System.Object, que simplemente es mostrar su nombre de

tipo: 
csharp> var a = new XmlDocument ();
csharp> a;
System.Xml.Document
csharp> csharp> a.Name;    
"#document"
csharp>

Algunos tipos de datos son tratados especialmente por el shell interactivo de C# como arreglos, System.Collections.Hashtable, objetos que implementan System.Collections.IEnumerable e IDictionary y se representan de forma especial en lugar de simplemente usar ToString ()

: 
csharp> var pages = new Hashtable () { 
      >  { "Mono",    "http://www.mono-project.com/" },
      >  { "Linux",   "http://kernel.org" } };
csharp> pages;
{{ "Mono", "http://www.mono-project.com/" }, { "Linux", "http://kernel.org" }
}

Es posible usar LINQ directamente en el shell interactivo de C# ya que el espacio de nombres System.Linq se ha importado al inicio. El siguiente ejemplo obtiene una lista de todos los archivos que no han sido accedidos en una semana de

/tmp: 
csharp> using System.IO;
csharp> var last_week = DateTime.Now - TimeSpan.FromDays (7);
csharp> var old_files = from f in Directory.GetFiles ("/tmp") 
      >   let fi = new FileInfo (f) 
      >   where fi.LastAccessTime < LastWeek select f;
csharp>

Por supuesto, puede imprimir los resultados en una sola sentencia

también: 
csharp> using System.IO;
csharp> var last_week = DateTime.Now - TimeSpan.FromDays (7);
csharp> from f in Directory.GetFiles ("/tmp") 
      >   let fi = new FileInfo (f) 
      >   where fi.LastAccessTime < last_week select f;
[...]
csharp>

LINQ y su fundación funcional producen código bajo demanda para valores de retorno IEnumerable. Por ejemplo, el valor de retorno de un uso `from' es un IEnumerable que se evalúa bajo demanda. La representación automática de IEnumerables en la línea de comandos activará la ejecución de la canalización IEnumerable en ese punto en lugar de tener su ejecución retrasada hasta un punto

posterior.

Si desea evitar que el IEnumerable se represente en este punto, simplemente asigne el valor a una

variable.

A diferencia de C# compilado, el tipo de una variable puede cambiar si se introduce una nueva declaración, por

ejemplo: 
csharp> var a = 1;
csharp> a.GetType ();
System.Int32
csharp> var a = "Hello";
csharp> a.GetType ();
System.String
csharp> ShowVars ();
string a =
"Hello"

En el caso de que una expresión o sentencia no se complete en una sola línea, se muestra un prompt de continuación, por

ejemplo: 
csharp> var protocols = new string [] {
      >    "ftp",
      >    "http",
      >    "gopher" 
      > };
csharp> protocols;
{ "ftp", "http", "gopher"
}

Los cálculos de larga duración se pueden interrumpir usando la secuencia

Control-C: 
csharp> var done = false;
csharp> while (!done) { }
Interrupted!
System.Threading.ThreadAbortExcep
tion: Thread was being aborted at Class1.Host (System.Object& $retval) [0x00000] at Mono.CShar
p.InteractiveShell.ExecuteBlock (Mono.CSharp.Class host, Mono.CSharp.Undo undo) [0x00000] csharp>

EDICIÓN

INTERACTIVA

El shell interactivo de C# contiene un editor de línea que proporciona una funcionalidad de edición de línea de comandos más avanzada que la que proporciona el sistema operativo. Estas están disponibles en la versión de línea de comandos, las versiones gráficas usan los atajos de teclado estándar de

Gtk#.

El conjunto de comandos es similar al de muchas otras aplicaciones (teclas de cursor) e incorpora algunos de los comandos de Emacs para la edición, así como un mecanismo de

historial.

MÉTODOS Y PROPIEDADES DE LA INTERFAZ

GRÁFICA

Además de los métodos y propiedades disponibles en la versión de consola, hay un puñado de propiedades adicionales disponibl

es en la versión de interfaz gráfica. Por ejemplo, se expone un "PaneContainer" Gtk.Container que puede utilizar para al
ojar widgets de Gtk# mientras prototipa, o la propiedad "MainWindow" que le da acceso a la ventana de nivel superior actual.

ARCHIVOS DE

INICIO

El shell de C# cargará todos los ensamblados de Mono y los archivos de script de C# ubicados en el directorio ~/.config/csharp en Unix. Los ensamblados se cargan antes de que se carguen los archivos

fuente.

Los archivos de script de C# son archivos que tienen la extensión .cs y solo deben contener sentenci

as y expresiones, no pueden contener definiciones completas de clases (al menos no a partir de Mono
2.0). Las definiciones completas de clases deben compilarse en dlls y almacenarse en ese directorio.
