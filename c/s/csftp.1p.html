Paquete: clusterssh

Licencias: GPL

CSFTP(1p) Documentación de Perl aportada por el usuario CSFTP(1p)

NOMBRE

csftp - Herramienta de administración de clústeres

VERSIÓN

Esta documentación es para la versión: 4.16

SINOPSIS

csftp [-a '<command>'] [-K <seconds>] [-q] [-c '<filename>'] [-x <cols>] [-C '<filename>'] [--debug [[...] || <INTEGER>]] [-d] [-e '<[user@]<host>[:port]>'] [--fillscreen] [-f '<font>'] [-h] [-L '[tag]'] [-H] [-o '<STRING>'] [-p <port>] [-Q] [-y <rows>] [-s] [-r '<filename>'] [-t '<STRING>'] [-g] [-T '<title>'] [-u] [-?] [-A] [-l '<username>'] [-v]

RELACIONADO

Véase también las páginas de manual individuales de cada una de estas utilidades

ccon - Usar 'console' como método de comunicación
crsh - Usar 'rsh' como método de comunicación
cssh - Usar 'ssh' como método de comunicación
ctel - Usar 'telnet' como método de comunicación

DESCRIPCIÓN

El comando abre una consola de administración y un xterm a todos los hosts especificados. Cualquier texto escrito en la consola de administración se replica en todas las ventanas. También se puede escribir directamente en todas las ventanas.

Esta herramienta está destinada para (pero no se limita a) la administración de clústeres donde la misma configuración o los mismos comandos deben ejecutarse en cada nodo del clúster. Ejecutar estos comandos todos a la vez mediante esta herramienta asegura que todos los nodos se mantengan sincronizados.

Las conexiones se abren usando sftp, que debe estar correctamente instalado y configurado.

Se debe tener especial precaución al editar archivos, ya que las líneas no necesariamente están en el mismo orden; asumir que la línea 5 es la misma en todos los servidores y modificarla es peligroso. Es mejor buscar la línea específica a cambiar y verificar dos veces que todas las terminales están como se espera antes de que se apliquen los cambios.

Notas adicionales

Véase también "ERRORES CONOCIDOS".

  • La línea punteada en cualquier submenú es un desprendible, es decir, haga clic en ella y el submenú se convierte en su propia ventana.
  • Desmarcar un nombre de host en el submenú de Hosts desconectará el host de la ventana de control del clúster, por lo que cualquier texto escrito en la consola no se enviará a ese host. Volver a seleccionarlo lo reconectará.
  • Si las barras de menú de su gestor de ventanas están ocultas por ventanas de terminal, vea las "screen_reserve_XXXXX" opciones en el $HOME/.clusterssh/config archivo (véase "ARCHIVOS").
  • Si las terminales se superponen demasiado, vea las "terminal_reserve_XXXXX" opciones en el $HOME/.clusterssh/config archivo (véase "ARCHIVOS").
  • Cuando se usa ClusterSSH en un gran número de sistemas para conectarse a un solo sistema usando una utilidad SSH (por ejemplo, usted emite un comando para copiar un archivo usando scp desde los ordenadores remotos a un solo host) y cuando estas conexiones requieren autenticación (es decir, usted va a autenticarse con una contraseña), el demonio sshd en esa ubicación puede rechazar conexiones después de que se supere el límite "MaxStartups" en sshd_config (Si este valor no está establecido, el valor por defecto es 10). Este es el comportamiento esperado; sshd usa este mecanismo para prevenir ataques DoS de fuentes no autenticadas. Por favor, ajuste sshd_config y recargue el demonio SSH, o considere usar el mecanismo ~/.ssh/authorized_keys para la autenticación si se encuentra con este problema.
  • Si las ventanas de cliente no se abren, intente ejecutar:

    "csftp -e {single host name}"

    Esto probará los mecanismos utilizados para abrir ventanas en los hosts. Esto podría deberse a la opción de terminal "-xrm" que habilita "AllowSendEvents" (algunas terminales no requieren esta opción, otras terminales tienen otro método para habilitarlo - vea la documentación de su terminal) o a la configuración de "sftp".

OPCIONES

Algunas de estas opciones también pueden definirse dentro del archivo de configuración. Las opciones por defecto se muestran según corresponda.

--action '<command>', -a '<command>'
Ejecuta el comando en cada sesión, por ejemplo "-a 'vi /etc/hosts'" para entrar directamente en una sesión de vi.
--autoclose <seconds>, -K <seconds>
Número de segundos a esperar antes de cerrar las ventanas de terminal terminadas.
--autoquit, -q
Alterna la salida automática después de que se haya cerrado la última ventana de cliente (anulando el archivo de configuración).
--cluster-file '<filename>', -c '<filename>'
Usa el archivo proporcionado como archivo de clúster adicional (véase también "ARCHIVOS").
--cols <cols>, -x <cols>
Número de columnas
--config-file '<filename>', -C '<filename>'
Usa el archivo proporcionado como archivo de configuración adicional (véase también "ARCHIVOS").
--debug [[...] || <INTEGER>]
Habilita la depuración. Se puede proporcionar un nivel o la opción se puede repetir varias veces. El nivel máximo es 9.
--dump-config, -d
Vuelca la configuración actual en el mismo formato utilizado por el archivo $HOME/.clusterssh/config .
--evaluate '<[user@]<host>[:port]>', -e '<[user@]<host>[:port]>'
Muestra y evalúa los argumentos de terminal y conexión para mostrar cualquier error potencial. El <hostname> es necesario para ayudar en la evaluación.
--fillscreen
Redimensiona las ventanas de terminal para llenar toda la pantalla disponible
--font '<font>', -f '<font>'
Especifica la fuente a usar en las ventanas de terminal. Use notación estándar de fuentes X como "5x8".
--help, -h
Muestra el texto de ayuda básico y sale
--list '[tag]', -L '[tag]'
Lista las etiquetas de clúster disponibles. La etiqueta es opcional. Si se proporciona una etiqueta, se listan los hosts para esa etiqueta. NOTA: el formato de la salida cambia al usar la opción "--quiet" o "-Q".
--man, -H
Muestra el texto de ayuda completo (la página de manual) y sale
--options '<STRING>', -o '<STRING>'
Especifica los argumentos a pasar a ssh al hacer la conexión. NOTA: las opciones para ssh normalmente deben ponerse en el archivo de configuración de ssh; véase "ssh_config" y $HOME/.ssh/config para más detalles.

Por defecto: -x -o ConnectTimeout=10

--port <port>, -p <port>
Especifica un puerto alternativo para las conexiones.
--quiet, -Q
No emite texto extra al usar algunas opciones
--rows <rows>, -y <rows>
Número de filas
--show-history, -s
Muestra el historial dentro de la ventana de consola.
--tag-file '<filename>', -r '<filename>'
Usa el archivo proporcionado como archivo de etiquetas adicional (véase también "ARCHIVOS")
--term-args '<STRING>', -t '<STRING>'
Especifica los argumentos a pasar a las terminales que usado.
--tile, -g
Alterna el enventanado de ventanas (anulando el archivo de configuración).
--title '<title>', -T '<title>'
Especifica la parte inicial del título utilizada en las ventanas de consola y de cliente.
--unique-servers, -u
Alterna la conexión a cada host solo una vez cuando un nombre de host se ha especificado varias veces.
--usage, -?
Muestra la sinopsis y sale
--use-all-a-records, -A
Si un nombre de host resuelve a múltiples direcciones IP, alterna si conectarse a todas ellas o solo a la primera (véase también la entrada del archivo de configuración).
--username '<username>', -l '<username>'
Especifica el nombre de usuario por defecto a usar para las conexiones (si es diferente del usuario actualmente conectado). NOTA: será anulado por <user>@<host>.
--version, -v
Muestra la información de versión y sale

ARGUMENTOS

Se admiten los siguientes argumentos:

[user@]<hostname>[:port] ...
Abre un xterm para el nombre de host dado y se conecta a la consola de administración. El número de puerto opcional puede usarse si el servidor no está escuchando en el puerto estándar.
<tag> ...
Abre una serie de xterms definidos por <tag> en uno de los archivos de configuración suplementarios (véase "ARCHIVOS").

Nota: especificar un nombre de usuario en una etiqueta de clúster anulará cualquier nombre de usuario definido en el clúster.

ATAJOS DE TECLAS

Los siguientes atajos de teclas están disponibles dentro de la ventana de consola, y todos ellos pueden cambiarse mediante los archivos de configuración.

Control-Shift-plus
Abre el cuadro de diálogo 'Añadir Host(es) o Clúster(es)'. Se pueden introducir varios nombres de host o de clúster, separados por espacios.
Alt-n
Pega la parte del nombre de host de la cadena de conexión específica en cada cliente, sin ningún nombre de usuario o puerto, p. ej.

"scp /etc/hosts server:files/<Alt-n>.hosts"

reemplazaría <Alt-n> con el nombre del cliente en cada ventana.

Alt-l
Pega el nombre de host del servidor en el que se está ejecutando cssh
Alt-q
Sale del programa y cierra todas las conexiones y ventanas.
Alt-r
Vuelve a enventanar todas las ventanas de cliente.
Alt-u
Pega el nombre de usuario para la conexión
Alt-1
Alt-2
Alt-3
Alt-4
Ejecuta la macro definida por el usuario correspondiente en el servidor y envía la salida al cliente

EJEMPLOS

Abre una sesión con 3 servidores
$ csftp server1 server2 server3
Abre una sesión con un clúster de servidores identificado por la etiqueta 'farm1' y da a la ventana de control un título específico, donde la etiqueta está definida en uno de los archivos de configuración por defecto
$ csftp -T 'Web Farm Cluster 1' farm1
Conecta a diferentes servidores usando diferentes nombres de inicio de sesión. NOTA: esto también puede lograrse configurando las opciones apropiadas en los archivos de configuración. No cierre la consola cuando salga el último terminal.
$ csftp user1@server1 admin@server2
Abre un clúster definido en un archivo de configuración no predeterminado
$ csftp -c$HOME/cssh.extra_clusters db_cluster
Anula el puerto configurado/por defecto para usar 2022 en su lugar
$ csftp -p 2022 server1 server2

ARCHIVOS

/etc/clusters, $HOME/.clusterssh/clusters
Estos archivos contienen una lista de asignaciones de etiquetas a nombres de servidor. Cuando se usa cualquier nombre en la línea de comandos, se comprueba para ver si es una etiqueta. Si es una etiqueta, entonces la etiqueta se reemplaza con la lista de servidores. El formato es el siguiente:

<tag> [user@]<server>[:port] [user@]<server>[:port] [...]

p. ej.

# Lista de servidores en live
live admin1@server1 admin2@server2:2022 server3 server4

Se ignoran todos los comentarios (marcados por un #) y las líneas en blanco. Las etiquetas pueden anidarse, pero tenga cuidado al usar etiquetas recursivas, ya que no se comprueba que lo sean.

Los servidores pueden definirse usando macros de expansión:

"webservers websvr{a,b,c}"

se expandiría a

"webservers websvra websvrb websvrc"

y

"webservers websvr{6..9}"

se expandiría a

"webservers websvr6 websvr7 websvr8 websvr9"

Los archivos de clúster adicionales también pueden especificarse ya sea como una opción en la línea de comandos (véase "cluster-file") o en el archivo $HOME/.clusterssh/config del usuario (véase la opción de configuración "extra_cluster_file").

NOTA: la última etiqueta leída sobrescribe cualquier etiqueta preexistente con ese nombre.

NOTA: existe una etiqueta de clúster especial llamada "default" - cualquier etiqueta o host incluido dentro de esta etiqueta se abrirá automáticamente si no se especifica nada en la línea de comandos.

/etc/tags, $HOME/.clusterssh/tags
Muy similar a los archivos clusters pero la definición está invertida. El formato es:

<host> <tag> [...]

Esto permite que un host se especifique como miembro de un número de etiquetas. Este formato puede ser más claro que usar archivos clusters.

Los archivos de etiquetas adicionales pueden especificarse ya sea como una opción (véase "tag-file") o dentro del archivo $HOME/.clusterssh/config del usuario (véase la opción de configuración "extra_tag_file" ).

NOTA: Todas las etiquetas se añaden juntas

/etc/csshrc & $HOME/.clusterssh/config
Este archivo contiene anulaciones de configuración - los valores predeterminados están marcados como tal. Las opciones predeterminadas se sobrescriben primero por el archivo global y luego por el archivo de usuario.

NOTA: los valores de las entradas no necesitan estar entre comillas a menos que sea necesario para pasar argumentos, p. ej.

"terminal_allow_send_events="-xrm '*.VT100.allowSendEvents:true'""

debería escribirse como

"terminal_allow_send_events=-xrm '*.VT100.allowSendEvents:true'"

auto_close = 5
Cierra la ventana de terminal después de este número de segundos. Si se establece a 0, en su lugar esperará la entrada del usuario en cada ventana antes de cerrar. Véase también --autoclose y --no-autoclose
auto_quit = 1
Sale automáticamente después de que se cierre la última ventana de cliente. Establecer a 0 para desactivar. Véase también --autoquit
auto_wm_decoration_offsets = no
Activa o desactiva el algoritmo alternativo para calcular el posicionamiento de las terminales.
command_pre =
command_post =
Añade comandos extra alrededor del método de comunicación. Por ejemplo:

command_pre= . $HOME/virtualenvs/default/bin/active ; command_post= | ct

permitiría usar entornos virtuales de Python y luego canalizar toda la salida del shell a través de "chromaterm" para resaltado de sintaxis. Nota: debe usar separadores/terminadores de comandos apropiados para mantener el significado de la tubería de comandos (como ";" y "|" entre comandos).

Estos no se someten al análisis de macros.

comms = sftp
Establece el método de comunicación por defecto (inicialmente tomado del nombre del programa, pero puede anularse aquí).
console_position = <null>
Establece la posición inicial de la consola - si está vacío, deja que el gestor de ventanas decida. El formato es '+<x>+<y>', es decir, '+0+0' es la esquina superior izquierda de la pantalla, '+0-70' es el lado inferior izquierdo de la pantalla (más o menos).
external_command_mode = 0600
Bits de modo de archivo para el external_command_pipe.
external_command_pipe = <null>
Define la ruta completa a una tubería de comando externa a la que se puede escribir para controlar algunos aspectos de ClusterSSH, como abrir sesiones a más clústeres.

Comandos:

"open <tag|hostname>" - abre nuevas sesiones al tag o nombre de host proporcionado

- forzar el reajuste de ventanas

p. ej.: "echo 'open localhost'" /ruta/a/external_command_pipe >>

external_cluster_command = <null>
Defina la ruta completa a un comando externo que pueda usarse para resolver etiquetas a nombres de host. Este comando puede escribirse en cualquier lenguaje. El script debe aceptar una lista de etiquetas a resolver y devolver una lista de hosts (separados por espacios en una sola línea). Cualquier etiqueta que no pueda resolverse debe devolverse sin cambios.

Un código de salida distinto de 0 se contará como error, se imprimirá una advertencia y se ignorará la salida.

Si al comando externo se le pasa la opción "-L" debe devolver una lista de etiquetas (separadas por espacios en una sola línea) que puede resolver

extra_cluster_file = <null>
Defina un archivo de clústeres adicional en el formato de /etc/clusters. Se pueden especificar varios archivos, separados por comas. Tanto ~ como $HOME son aceptables como referencia al directorio personal del usuario, p. ej.

"extra_cluster_file = ~/clusters, $HOME/clus"

extra_tag_file = <null>
Defina un archivo de etiquetas adicional en el formato de /etc/tags. Se pueden especificar varios archivos, separados por comas. Tanto ~ como $HOME son aceptables como referencia al directorio personal del usuario, p. ej.

"extra_tag_file = ~/tags, $HOME/tags"

key_addhost = Control-Shift-plus
Secuencia de teclas predeterminada para abrir el menú AddHost. Vea "KEY SHORTCUTS" para más información.
hide_menu = 0
Si se establece en 1, oculta la barra de menús (File, Hosts, Send, Help) en la consola.
key_clientname = Alt-n
Secuencia de teclas predeterminada para enviar los nombres de cliente de cssh al cliente. Vea "KEY SHORTCUTS" para más información.
key_localname = Alt-l
Secuencia de teclas predeterminada para enviar el nombre de host del servidor local al cliente. Vea "KEY SHORTCUTS" para más información.
key_paste = Control-v
Secuencia de teclas predeterminada para pegar texto en la ventana de la consola. Vea "KEY SHORTCUTS" para más información.
key_quit = Control-q
Secuencia de teclas predeterminada para salir del programa (terminará todas las ventanas abiertas). Vea "KEY SHORTCUTS" para más información.
key_retilehosts = Alt-r
Secuencia de teclas predeterminada para reajustar las ventanas de hosts. Vea "KEY SHORTCUTS" para más información.
key_username = Alt-u
Secuencia de teclas predeterminada para enviar el nombre de usuario al cliente. Vea "KEY SHORTCUTS" para más información.
key_user_1 = Alt-1
key_user_2 = Alt-2
key_user_3 = Alt-3
key_user_4 = Alt-4
Secuencia de teclas predeterminada para enviar macros definidas por el usuario al cliente. Si la macro macro_user_1 correspondiente no está definida, la secuencia se pasa directamente a la terminal. Vea "KEY SHORTCUTS" para más información.

macro_user_2 = %2
macro_user_3 = %3
macro_user_4 = %4
Cambie la macro de reemplazo que se usa al usar un elemento del menú 'Send' o al pegar texto en la consola principal.
macro_user_1_command =
macro_user_2_command =
macro_user_3_command =
macro_user_4_command =
Macros definidas por el usuario: la macro se ejecuta a través del shell en el servidor y la salida se envía al cliente. Por ejemplo,

"macro_user_1_command=echo echo macro_user_1"

enviaría el texto C<echo macro_user_1> a la sesión de terminal.

"macro_user_1_command=env | grep CSSH"

enviaría las variables de entorno de CSSH al cliente.

"CSSH_SERVERNAME"
"CSSH_HOSTNAME"
"CSSH_USERNAME"
"CSSH_CONNECTION_STRING"
"CSSH_CONNECTION_PORT"
"CSSH_VERSION"

Active o desactive el reemplazo de macros. Nota: esto afecta a todas las "macro_*" variables anteriores.

rsh = /ruta/a/rsh

rsh_args = <vacío>

NOTA: Cualquier cambio "genérico" en el método (p. ej., especificar el puerto ssh a usar) debe hacerse en el archivo de configuración propio del medio (vea "ssh_config" y $HOME/.ssh/config).

screen_reserve_top = 0
screen_reserve_bottom = 60

Número de píxeles desde el lado de la pantalla a reservar al calcular la geometría de la pantalla para el mosaico. Establecer esto en algo como 50 ayudará a que cssh no posicione ventanas sobre la barra de menús de su gestor de ventanas si dibuja una en ese lado de la pantalla.

Ruta a usar como directorio de trabajo para cada terminal cuando 'terminal_chdir' está activado. La ruta proporcionada se pasa por el analizador de macros (vea la sección anterior sobre 'macros_enabled'.
terminal_font = 6x13
