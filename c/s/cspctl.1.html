cspctl(1) Manual de Comandos Generales cspctl(1)

NOMBRE

cspctl - Programa de control ASP/CSP de Sound Blaster 16

SINOPSIS

cspctl comando [-opciones] <nombre_archivo>

DESCRIPCIÓN

cspctl es un cargador simple de microcódigo CSP para las tarjetas de sonido Creative Sound Blaster 16ASP y algunas Sound Blaster AWE32 con el chip Creative Signal Processor (CSP) (CT1748A) instalado. cspctl también se puede utilizar como una función post-instalación para el módulo snd-sb16-csp para cargar el códec predeterminado al instalar el módulo. Si el chip CSP se detecta e inicializa correctamente, se instalará como un dispositivo dependiente de hardware hwC0D2 en el directorio /dev/snd. Actualmente, los siguientes códecs pueden ser cargados en el dispositivo CSP:

wfm0001a.csp	Decodificador QSound
wfm0006a.csp	Códec A-law
wfm0007a.csp	Códec u-law
wfm0011a.csp	Códec IMA ADPCM (salida distorsionada para archivos de prueba IMA)
wfm0200a.csp	Códec ADPCM de Creative (suena compatible con IMA ADPCM de Intel/DVI)
wfm0202a.csp	Códec Fast Speech 8
wfm0203a.csp	Códec Fast Speech 10

Estos códecs aún no son compatibles con ALSA:

wfm0201a.csp Decodificador Text2Speech

El archivo de microcódigo Qsound tiene cuatro funciones, cada función es un decodificador para una frecuencia de muestreo diferente. Las tasas para las funciones QSound #1, #2, #3 y #4 son 44100, 22050, 11025 y 8000Hz respectivamente. Los códecs IMA ADPCM y FastSpeech están formados por dos funciones, la primera es para captura y la segunda para reproducción. Los códecs A-law y u-law tienen solo una función. Para cargar, por ejemplo, la función #2 del archivo de microcódigo QSound (decodificador para 22050Hz), ejecute lo siguiente:

% cspctl load -f 2 -d QSound wfm0001a.csp

Después de cargar correctamente, /proc/asound/SB16/cspD2 mostrará:

Creative Signal Processor [v1.0]
State: -x--L
Codec: QSound [func #2]
Sample rates: 22050Hz
QSound decoder disabled

Con el archivo de microcódigo del decodificador QSound cargado, todos los formatos simples de archivos PCM se pueden reproducir con el posicionamiento de 180 grados de QSound aplicado. El elemento QSound se agrega dinámicamente a la estructura del mezclador como un elemento 3DEffect1-space. Solo aparecerá si el soporte para CSP se ha compilado en los controladores ALSA, se ha encontrado el chip CSP y el códec QSound se ha cargado en el CSP. Cuando está habilitado, la posición de QSound se puede cambiar dinámicamente mediante un control deslizante del mezclador, y la interfaz proc debería seguir el estado del chip CSP y su posición QSound actual:

Creative Signal Processor [v1.0]
State: Qx-RL
Codec: QSound [func #2]
Sample rates: 22050Hz
QSound decoder enabled
Processing 16bit mono PCM samples
Qsound position: left = 0x9, right = 0x9

El controlador admite la carga automática de los códecs de hardware u-Law, A-Law e Ima-ADPCM. La carga automática está activa solo cuando no hay ningún microcódigo cargado en CSP, y no hay necesidad de precargar los archivos *.csp apropiados. Para descargar el microcódigo cargado manualmente, debe ejecutar

% cspctl unload

Si el microcódigo del códec de hardware se ha cargado manualmente, CSP solo admitirá el formato PCM cargado y la carga automática se deshabilitará. En tal caso, la interfaz proc mostrará las propiedades del códec cargado:

Creative Signal Processor [v1.0]
State: -x--L
Codec: IMA-ADPCM [func #2]
Sample rates: All
PCM format ID: 0x400000 (16bit/-) [mono/stereo] [playback/-]

COMANDOS

cargar
Cargar microcódigo desde el nombre de archivo a CSP.
descargar
Descargar microcódigo desde CSP.

OPCIONES

-h, --ayuda
Mostrar una breve ayuda.
-c tarjeta
Seleccionar un número de tarjeta. La opción por defecto es 0.
-f funcion
Seleccionar una función del archivo de microcódigo. La opción por defecto es 1.
-d descripcion
Cadena de descripción opcional del microcódigo.
