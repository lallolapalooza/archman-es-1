CSTEDC

Documentación de función/subrutina

subroutine cstedc (character compz, integer n, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

CSTEDC

Propósito:

!>
!> CSTEDC calcula todos los valores propios y, opcionalmente, los vectores propios
!> de una matriz tridiagonal simétrica utilizando el método de división y conquista.
!> Los vectores propios de una matriz hermitiana completa o de banda también
!> pueden encontrarse si CHETRD o CHPTRD o CHBTRD se ha utilizado para reducir esta
!> matriz a forma tridiagonal.
!>
!>

Parámetros

COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Solo calcula los valores propios.
!>          = 'I':  También calcula los vectores propios de la matriz tridiagonal.
!>          = 'V':  También calcula los vectores propios de la matriz hermitiana original.
!>                  Al entrar, Z contiene la matriz unitaria utilizada
!>                  para reducir la matriz original a forma tridiagonal.
!>

N

!>          N es INTEGER
!>          La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es array REAL, dimensión (N)
!>          Al entrar, los elementos diagonales de la matriz tridiagonal.
!>          Al salir, si INFO = 0, los valores propios en orden ascendente.
!>

E

!>          E es array REAL, dimensión (N-1)
!>          Al entrar, los elementos subdiagonales de la matriz tridiagonal.
!>          Al salir, E ha sido destruido.
!>

Z

!>          Z es array COMPLEX, dimensión (LDZ,N)
!>          Al entrar, si COMPZ = 'V', entonces Z contiene la matriz unitaria
!>          utilizada en la reducción a forma tridiagonal.
!>          Al salir, si INFO = 0, entonces si COMPZ = 'V', Z contiene los
!>          vectores propios ortonormales de la matriz hermitiana original,
!>          y si COMPZ = 'I', Z contiene los vectores propios ortonormales
!>          de la matriz tridiagonal simétrica.
!>          Si  COMPZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1.
!>          Si se desean vectores propios, entonces LDZ >= max(1,N).
!>

WORK

!>          WORK es array COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si COMPZ = 'N' o 'I', o N <= 1, LWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LWORK debe ser al menos N*N.
!>          Tenga en cuenta que para COMPZ = 'V', si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LWORK solo
!>          necesita ser 1.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es array REAL, dimensión (MAX(1,LRWORK))
!>          Al salir, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si COMPZ = 'N' o N <= 1, LRWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LRWORK debe ser al menos
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         donde lg( N ) es el menor entero k tal que
!>                         2**k >= N.
!>          Si COMPZ = 'I' y N > 1, LRWORK debe ser al menos
!>                         1 + 4*N + 2*N**2 .
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LRWORK
!>          solo necesita ser max(1,2*(N-1)).
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (MAX(1,LIWORK))
!>          Al salir, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si COMPZ = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si COMPZ = 'V' o N > 1,  LIWORK debe ser al menos
!>                                    6 + 6*N + 5*N*lg N.
!>          Si COMPZ = 'I' o N > 1,  LIWORK debe ser al menos
!>                                    3 + 5*N .
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LIWORK
!>          solo necesita ser 1.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>
