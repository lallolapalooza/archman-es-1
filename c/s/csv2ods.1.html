CSV2ODS(1) Comandos de usuario CSV2ODS(1)



NOMBRE
csv2ods - Crea una hoja de cálculo OpenDocument a partir de valores separados por comas



SINOPSIS

csv2ods -i archivo.csv -o archivo.ods



DESCRIPCIÓN

Este programa lee un archivo en formato CSV - una tabla de columnas delimitadas por comas, tabulaciones o cualquier otro carácter. Luego crea una hoja de cálculo. Si un valor parece un número, la celda también se formatea como un número.



OPCIONES

--version

Muestra el número de versión del programa y sale

-h, --help

Muestra el mensaje de ayuda y sale

-i ENTRADA, --input=ENTRADA

Archivo de entrada en formato CSV.

-o SALIDA, --output=SALIDA

Archivo de salida en formato ODS.

-d DELIMITADOR, --delimiter=DELIMITADOR

Especifica una cadena de un solo carácter para usar como separador de campos. Por defecto es ",".

-c CODIFICACION, --encoding=CODIFICACION

Especifica la codificación del archivo CSV. Por defecto es utf-8.

-t NOMBRE_TABLA, --table=NOMBRE_TABLA

El nombre de la tabla en el archivo de salida.

-s SALTAESPACIOINICIAL, --skipinitialspace=SALTAESPACIOINICIAL

Especifica cómo interpretar el espacio en blanco que sigue inmediatamente a un delimitador. Por defecto es Falso, lo que significa que el espacio en blanco que sigue inmediatamente a un delimitador forma parte del siguiente campo.

-l TERMINADORLINEA, --lineterminator=TERMINADORLINEA

Especifica la secuencia de caracteres que deben terminar las filas.

-q COTIZACION, --quoting=COTIZACION

Puede tomar cualquiera de las siguientes constantes del módulo: 0 = QUOTE_MINIMAL significa solo cuando es necesario, por ejemplo, cuando un campo contiene el carácter de comillas o el delimitador. 1 = QUOTE_ALL significa que las comillas siempre se colocan alrededor de los campos. 2 = QUOTE_NONNUMERIC significa que las comillas siempre se colocan alrededor de los campos que no se analizan como números enteros o de punto flotante. 3 = QUOTE_NONE significa que las comillas nunca se colocan alrededor de los campos. Por defecto es QUOTE_MINIMAL.

-e CARÁCTERESCAPAR, --escapechar=CARÁCTERESCAPAR

Especifica una cadena de un solo carácter utilizada para escapar el delimitador cuando la cotización se establece en QUOTE_NONE.

-r CARÁCTERCOTIZAR, --quotechar=CARÁCTERCOTIZAR

Especifica una cadena de un solo carácter para usar como carácter de cotización. Por defecto es ".



EJEMPLO

csv2ods -i /etc/passwd -o accounts.odt -d:
