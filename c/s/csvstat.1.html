NOMBRE

csvstat - Documentación de csvstat

DESCRIPCIÓN

Imprime estadísticas descriptivas para todas las columnas de un archivo CSV. Determinará inteligentemente el tipo de cada columna y luego imprimirá análisis relevantes para ese tipo (rangos para fechas, media y mediana para enteros, etc.):

uso: csvstat [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
               [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
               [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
               [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
               [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [--csv] [--json]
               [-i INDENT] [-n] [-c COLUMNS] [--type] [--nulls] [--non-nulls]
               [--unique] [--min] [--max] [--sum] [--mean] [--median]
               [--stdev] [--len] [--max-precision] [--freq]
               [--freq-count FREQ_COUNT] [--count]
               [--decimal-format DECIMAL_FORMAT] [-G] [-y SNIFF_LIMIT] [-I]
               [FILE]
Imprime estadísticas descriptivas para cada columna en un archivo CSV.
argumentos posicionales:
  FILE                  El archivo CSV a operar. Si se omite, aceptará la entrada
                        como datos enviados a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este mensaje de ayuda y sale
  --csv                 Resultado de la salida como una tabla CSV, en lugar de texto plano.
  --json                Resultado de la salida como texto JSON, en lugar de texto plano.
  -i INDENT, --indent INDENT
                        Indenta el JSON de salida en tantos espacios. Desactivado por defecto.
  -n, --names           Muestra los nombres e índices de las columnas del CSV de entrada y sale.
  -c COLUMNS, --columns COLUMNS
                        Una lista separada por comas de índices, nombres o rangos de columnas a examinar,
                        por ejemplo, "1,id,3-5". Por defecto son todas las columnas.
  --type                Solo muestra el tipo de dato.
  --nulls               Solo muestra si las columnas contienen nulos.
  --non-nulls           Solo muestra recuentos de valores no nulos.
  --unique              Solo muestra recuentos de valores únicos.
  --min                 Solo muestra los valores más pequeños.
  --max                 Solo muestra los valores más grandes.
  --sum                 Solo muestra las sumas.
  --mean                Solo muestra las medias.
  --median              Solo muestra las medianas.
  --stdev               Solo muestra las desviaciones estándar.
  --len                 Solo muestra la longitud de los valores más largos.
  --max-precision       Solo muestra el número máximo de decimales.
  --freq                Solo muestra listas de valores frecuentes.
  --freq-count FREQ_COUNT
                        El número máximo de valores frecuentes a mostrar.
  --count               Solo muestra el recuento total de filas.
  --decimal-format DECIMAL_FORMAT
                        Especificación de formato % para imprimir números decimales.
                        Por defecto es el formato específico de la configuración regional con "%.3f".
  -G, --no-grouping-separator
                        No usar separadores de agrupación en números decimales.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        Limita la detección del dialecto CSV al número de bytes especificado.
                        Especificar "0" para deshabilitar completamente la detección, o "-1" para detectar todo el archivo.
  -I, --no-inference    Deshabilita la inferencia de tipos (y --locale, --date-format, --datetime-format, --no-leading-zeroes) al analizar la entrada.

Ver también: Argumentos comunes a todas las herramientas.

EJEMPLOS

Uso básico:

csvstat examples/realdata/FY09_EDU_Recipients_by_State.csv

Cuando se pasa un nombre de estadística, solo se imprimirá esa estadística:

$ csvstat --min examples/realdata/FY09_EDU_Recipients_by_State.csv
  1. State Name: None
  2. State Abbreviate: None
  3. Code: 1
  4. Montgomery GI Bill-Active Duty: 435
  5. Montgomery GI Bill- Selective Reserve: 48
  6. Dependents' Educational Assistance: 118
  7. Reserve Educational Assistance Program: 60
  8. Post-Vietnam Era Veteran's Educational Assistance Program: 1
  9. TOTAL: 768
 10. j: None

Si se solicitan una sola estadística y una sola columna, solo se devolverá un valor:

$ csvstat -c 4 --mean examples/realdata/FY09_EDU_Recipients_by_State.csv
6,263.904
