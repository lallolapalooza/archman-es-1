Documentación de Función/Subrutin

a

subrutina csytrf_rook (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer

info)

CSYTRF_ROO

K

Propósito

: 
!>
!> CSYTRF_ROOK calcula la factorización de una matriz simétrica compleja A
!> usando el método de pivote diagonal Bunch-Kaufman acotado ().
!> La forma de la factorización es
!>
!>    A = U*D*U**T  o  A = L*D*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> superiores (inferiores) unitarias, y D es simétrica y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          triangular superior principal de A de N por N contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte
!>          triangular inferior principal de A de N por N contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          superior de A no se referencia.
!>
!>          En la salida, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L (ver más abajo para más detalles).
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>               columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k-1 e -IPIV(k-1) fueron intercambiadas,
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>               columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k+1 e -IPIV(k+1) fueron intercambiadas,
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >=1.  Para un mejor rendimiento
!>          LWORK >= N*NB, donde NB es el tamaño de bloque devuelto por ILAENV.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero.  La factorización
!>                se ha completado, pero la matriz diagonal por bloques D es
!>                exactamente singular, y ocurrirá una división por cero si se
!>                usa para resolver un sistema de ecuaciones.
!
>

Detalles

adicionales: 
!>
!>  Si UPLO = 'U', entonces A = U*D*U**T, donde
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  es decir, U es un producto de términos P(k)*U(k), donde k disminuye de n a
!>  1 en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k).  P(k) es una matriz de permutación
!>  definida por IPIV(k), y U(k) es una matriz triangular superior unitaria, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(1:k-1,k).
!>  Si s = 2, el triángulo superior de D(k) sobrescribe A(k-1,k-1), A(k-1,k),
!>  y A(k,k), y v sobrescribe A(1:k-2,k-1:k).
!>
!>  Si UPLO = 'L', entonces A = L*D*L**T, donde
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  es decir, L es un producto de términos P(k)*L(k), donde k aumenta de 1 a
!>  n en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k).  P(k) es una matriz de permutación
!>  definida por IPIV(k), y L(k) es una matriz triangular inferior unitaria, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(k+1:n,k).
!>  Si s = 2, el triángulo inferior de D(k) sobrescribe A(k,k), A(k+1,k),
!>  y A(k+1,k+1), y v sobrescribe A(k+2:n,k:k+1).
!
>
