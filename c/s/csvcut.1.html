NOMBRE

csvcut - Documentación de csvcut

DESCRIPCIÓN

Filtra y trunca archivos CSV. Similar al comando "cut" de Unix, pero para datos tabulares:

uso: csvcut [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
              [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-S] [-H]
              [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-n] [-c COLUMNS]
              [-C NOT_COLUMNS] [-x]
              [ARCHIVO]
Filtra y trunca archivos CSV. Similar al comando "cut" de Unix, pero para datos tabulares.
argumentos posicionales:
  ARCHIVO               El archivo CSV a operar. Si se omite, aceptará entrada como datos piped a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este mensaje de ayuda y sale
  -n, --names           Muestra los nombres e índices de las columnas del CSV de entrada y sale.
  -c COLUMNS, --columns COLUMNS
                        Una lista separada por comas de índices, nombres o rangos de columnas a extraer, por ejemplo, "1,id,3-5". Predeterminado a todas las columnas.
  -C NOT_COLUMNS, --not-columns NOT_COLUMNS
                        Una lista separada por comas de índices, nombres o rangos de columnas a excluir, por ejemplo, "1,id,3-5". Predeterminado a ninguna columna. Ignora columnas desconocidas.
  -x, --delete-empty-rows
                        Después de cortar, elimina las filas que estén completamente vacías.

Ver también: Argumentos comunes a todas las herramientas.

NOTA:

csvcut no implementa el filtrado de filas; para esto, deberías canalizar los datos a csvgrep.

NOTA:

Si una fila de datos es más larga que la fila de encabezado, sus columnas adicionales se truncan.

EJEMPLOS

Imprimir columnas

Imprime los índices y nombres de todas las columnas:

$ csvcut -n examples/realdata/FY09_EDU_Recipients_by_State.csv
  1: State Name
  2: State Abbreviate
  3: Code
  4: Montgomery GI Bill-Active Duty
  5: Montgomery GI Bill- Selective Reserve
  6: Dependents' Educational Assistance
  7: Reserve Educational Assistance Program
  8: Post-Vietnam Era Veteran's Educational Assistance Program
  9: TOTAL
 10:

Imprime solo los nombres de todas las columnas, eliminando los índices con el comando cut:

$ csvcut -n examples/realdata/FY09_EDU_Recipients_by_State.csv | cut -c6-
State Name
State Abbreviate
Code
Montgomery GI Bill-Active Duty
Montgomery GI Bill- Selective Reserve
Dependents' Educational Assistance
Reserve Educational Assistance Program
Post-Vietnam Era Veteran's Educational Assistance Program
TOTAL

Extraer columnas

Extrae la primera y la tercera columna:

csvcut -c 1,3 examples/realdata/FY09_EDU_Recipients_by_State.csv

Extrae las columnas llamadas "TOTAL" y "State Name" (en ese orden):

csvcut -c TOTAL,"State Name" examples/realdata/FY09_EDU_Recipients_by_State.csv

Extrae una columna que puede no existir en todos los archivos:

echo d, | csvjoin examples/dummy.csv - | csvcut -c d
 echo d, | csvjoin examples/join_no_header_row.csv - | csvcut -c d

Otro

Añade números de línea a un archivo, sin hacer ningún otro cambio:

csvcut -l examples/realdata/FY09_EDU_Recipients_by_State.csv

Muestra los valores únicos de una columna:

csvcut -c 1 examples/realdata/FY09_EDU_Recipients_by_State.csv | sed 1d | sort | uniq

O:

csvcut -c 1 examples/realdata/FY09_EDU_Recipients_by_State.csv | csvsql --query 'SELECT DISTINCT("State Name") FROM stdin'
