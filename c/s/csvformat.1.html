NOMBRE

csvformat - Documentación de csvformat

DESCRIPCIÓN

Convierte un archivo CSV a un formato de salida personalizado:

uso: csvformat [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
                 [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING]
                 [-L LOCALE] [-S] [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V]
                 [-E] [-D OUT_DELIMITER] [-T] [-A] [-Q OUT_QUOTECHAR]
                 [-U {0,1,2,3}] [-B] [-P OUT_ESCAPECHAR]
                 [-M OUT_LINETERMINATOR]
                 [ARCHIVO]
Convierte un archivo CSV a un formato de salida personalizado.
argumentos posicionales:
  ARCHIVO             El archivo CSV a procesar. Si se omite, aceptará entrada
                        como datos enviados a través de STDIN.
argumentos opcionales:
  -h, --help            muestra este mensaje de ayuda y sale
  -E, --skip-header     No generar una fila de encabezado.
  -D OUT_DELIMITER, --out-delimiter OUT_DELIMITER
                        Carácter delimitador del archivo de salida.
  -T, --out-tabs        Especifica que el archivo de salida está delimitado por
                        tabulaciones. Anula "-D".
  -A, --out-asv         Especifica que el archivo de salida está delimitado por
                        el separador de unidades ASCII y el separador de
                        registros. Anula "-T", "-D" y "-M".
  -Q OUT_QUOTECHAR, --out-quotechar OUT_QUOTECHAR
                        Carácter utilizado para entrecomillar cadenas en el
                        archivo de salida.
  -U {0,1,2,3}, --out-quoting {0,1,2,3}
                        Estilo de entrecomillado utilizado en el archivo de
                        salida: 0 entrecomillar mínimamente, 1 entrecomillar
                        todo, 2 entrecomillar no numérico, 3 entrecomillar
                        nada.
  -B, --out-no-doublequote
                        Indica si las comillas dobles se duplican o no en el
                        archivo de salida.
  -P OUT_ESCAPECHAR, --out-escapechar OUT_ESCAPECHAR
                        Carácter utilizado para escapar el delimitador en el
                        archivo de salida si se especifica --quoting 3
                        ("Entrecomillar nada") y para escapar el QUOTECHAR si
                        se especifica --out-no-doublequote.
  -M OUT_LINETERMINATOR, --out-lineterminator OUT_LINETERMINATOR
                        Carácter utilizado para terminar líneas en el archivo de
                        salida.

Ver también: Argumentos comunes a todas las herramientas.

EJEMPLOS

Convertir un archivo separado por comas a un archivo delimitado por pipes:

csvformat -D "|" examples/dummy.csv

Convertir a finales de línea de retorno de carro:

csvformat -M $'\r' examples/dummy.csv

Convertir a un archivo delimitado por tabulaciones (TSV) sin duplicación de comillas dobles:

printf 'key,value\n1,"a ""quoted"" string"' | csvformat -T -Q🐍

Para evitar escapar caracteres de comillas al usar --quoting 3, añade --out-quotechar "":

csvformat -u3 -U3 -Q🐍 examples/optional_quote_characters.csv
