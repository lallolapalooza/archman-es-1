subrutina csyrk (carácter uplo, carácter trans, entero n, entero k, complejo alpha, complejo, dimensión(lda,*) a, entero lda, complejo beta, complejo, dimensión(ldc,*) c, entero ldc)

CSYRK

Propósito:

!>
!> CSYRK  realiza una de las operaciones de rango k simétrico
!>
!>    C := alpha*A*A**T + beta*C,
!>
!> o
!>
!>    C := alpha*A**T*A + beta*C,
!>
!> donde  alpha y beta  son escalares,  C es una matriz simétrica de n x n
!> y  A  es una matriz de n x k  en el primer caso y una matriz de k x n
!> en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar,   UPLO  especifica  si la parte  triangular superior o inferior
!>           del array  C  debe ser referenciada como
!>           sigue:
!>
!>              UPLO = 'U' o 'u'   Sólo se referencia la parte triangular superior de C.
!>
!>              UPLO = 'L' o 'l'   Sólo se referencia la parte triangular inferior de C.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar,  TRANS  especifica la operación a realizar como
!>           sigue:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**T + beta*C.
!>
!>              TRANS = 'T' o 't'   C := alpha*A**T*A + beta*C.
!>

N

!>          N es INTEGER
!>           Al entrar,  N  especifica el orden de la matriz C.  N debe ser
!>           al menos cero.
!>

K

!>          K es INTEGER
!>           Al entrar con  TRANS = 'N' o 'n',  K  especifica el número
!>           de  columnas   de la matriz   A,   y al entrar   con
!>           TRANS = 'T' o 't',  K  especifica el número de filas de la
!>           matriz A.  K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es COMPLEX
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX, dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de entrar con  TRANS = 'N' o 'n',  la parte principal n x k
!>           del array  A  debe contener la matriz  A,  en caso contrario
!>           la parte principal k x n  del array  A  debe contener la
!>           matriz A.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declara
!>           en  el  programa  (sub)llamador.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDA debe ser al menos  max( 1, n ), en caso contrario  LDA debe
!>           ser al menos  max( 1, k ).
!>

BETA

!>          BETA es COMPLEX
!>           Al entrar, BETA especifica el escalar beta.
!>

C

!>          C es un array COMPLEX, dimensión ( LDC, N )
!>           Antes de entrar con  UPLO = 'U' o 'u',  la parte principal n x n
!>           superior triangular del array C debe contener la parte triangular superior
!>           de la matriz simétrica  y la parte triangular estrictamente inferior de C no se referencia.  Al salir, la
!>           parte triangular superior del array  C se sobrescribe con la
!>           parte triangular superior de la matriz actualizada.
!>           Antes de entrar con  UPLO = 'L' o 'l',  la parte principal n x n
!>           inferior triangular del array C debe contener la parte triangular inferior
!>           de la matriz simétrica  y la parte triangular estrictamente superior de C no se referencia.  Al salir, la
!>           parte triangular inferior del array  C se sobrescribe con la
!>           parte triangular inferior de la matriz actualizada.
!>

LDC

!>          LDC es INTEGER
!>           Al entrar, LDC especifica la primera dimensión de C tal como se declara
!>           en  el  programa  (sub)llamador.   LDC  debe ser  al menos
!>           max( 1, n ).
!>
