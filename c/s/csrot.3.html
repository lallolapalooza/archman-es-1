DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina csrot (integer n, complex, dimension( * ) cx, integer incx, complex, dimension( * ) cy, integer incy, real c, real s)

CSROT

Propósito:

!>
!> CSROT aplica una rotación de plano, donde el cos y sin (c y s) son reales
!> y los vectores cx y cy son complejos.
!> jack dongarra, linpack, 3/11/78.
!>

Parámetros

N 
!>          N es ENTERO
!>           A la entrada, N especifica el orden de los vectores cx y cy.
!>           N debe ser al menos cero.
!>

CX

!>          CX es un array COMPLEJO, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array incrementado CX debe contener el vector
!>           cx de n elementos. A la salida, CX se sobrescribe con el vector
!>           cx actualizado.
!>

INCX

!>          INCX es ENTERO
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           CX. INCX no debe ser cero.
!>

CY

!>          CY es un array COMPLEJO, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array incrementado CY debe contener el vector
!>           cy de n elementos. A la salida, CY se sobrescribe con el vector
!>           cy actualizado.
!>

INCY

!>          INCY es ENTERO
!>           A la entrada, INCY especifica el incremento para los elementos de
!>           CY. INCY no debe ser cero.
!>

C

!>          C es REAL
!>           A la entrada, C especifica el coseno, cos.
!>

S

!>          S es REAL
!>           A la entrada, S especifica el seno, sin.
!>
