DESCRIPCIÓ

N

Las funciones termios describen una interfaz de terminal general que se proporciona para controlar puertos de comunicaciones

asíncronos.

La estructura

termios

Muchas de las funciones descritas aquí tienen un argumento termios_p que es un puntero a una estructura termios. Esta estructura contiene al menos los siguientes

miembros: 


tcflag_t c_iflag;      /* modos de entrada */
tcflag_t c_oflag;      /* modos de salida */
tcflag_t c_cflag;      /* modos de control */
tcflag_t c_lflag;      /* modos locales */
cc_t     c_cc[NCCS];   /* caracteres especiales
*/

Los valores que pueden asignarse a estos campos se describen a continuación. En el caso de los cuatro primeros campos de máscara de bits, las definiciones de algunas de las banderas asociadas que pueden establecerse solo se exponen si se define una macro de prueba de características específica (ver feature_test_macros(7)), como se indica entre corchetes ("[]")

.

En las descripciones siguientes, "no en POSIX" significa que el valor no está especificado en POSIX.1-2001, y "XSI" significa que el valor está especificado en POSIX.1-2001 como parte de la extensión

XSI.

NAME

man-pages - introduction to the manual pages

LIBRARY

This manual is part of the Linux man-pages project.

SYNOPSIS

man-pages

DESCRIPTION

The Linux man-pages project provides the manual pages for the Linux kernel and GNU C Library. The manual pages are organized into sections, with each section containing pages for a particular type of command or concept. The sections are numbered and have the following general meanings:

1
Executable programs or shell commands
2
System calls (functions provided by the kernel)
3
Library calls (functions within program libraries)
4
Special files (usually found in /dev)
5
File formats and conventions (e.g. passwd(5))
6
Games
7
Miscellaneous (overviews, conventions, etc.)
8
System administration commands (usually for root)
9
Kernel routines [Non standard]

The man command is used to display manual pages. For example, to view the manual page for the ls command, you would type:

man ls

If you want to view a manual page in a specific section, you can specify the section number:

man 1 ls

The manual pages are written in a simple markup language and are typically displayed in plain text. Some manual pages may include formatting such as bold text, italics, and code examples.

RETURN VALUE

N/A

ATTRIBUTES

N/A

STANDARDS

The manual pages are intended to document the Linux operating system and its associated libraries and utilities. They aim to be compliant with relevant POSIX standards where applicable.

HISTORY

The manual page system originated in the early days of Unix. The Linux man-pages project has evolved over time to provide comprehensive documentation for the Linux ecosystem.

NOTES

The content and organization of manual pages can vary slightly between different Unix-like operating systems. The Linux man-pages project focuses specifically on Linux.

BUGS

Any bugs or inaccuracies found in the manual pages should be reported to the Linux man-pages project maintainers.
