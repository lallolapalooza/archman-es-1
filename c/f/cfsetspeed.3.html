DESCRIPCIÓ

N

Las funciones termios describen una interfaz de terminal general que se proporciona para controlar puertos de comunicaciones

asíncronas.

La estructura

termios

Muchas de las funciones descritas aquí tienen un termios_p argumento que es un puntero a una estructura termios. Esta estructura contiene al menos los siguientes

miembros: 


tcflag_t c_iflag;      /* modos de entrada */
tcflag_t c_oflag;      /* modos de salida */
tcflag_t c_cflag;      /* modos de control */
tcflag_t c_lflag;      /* modos locales */
cc_t     c_cc[NCCS];   /* caracteres especiales
*/

Los valores que pueden asignarse a estos campos se describen a continuación. En el caso de los primeros cuatro campos de máscara de bits, las definiciones de algunos de los indicadores asociados que pueden establecerse solo se exponen si se define una macro de prueba de características específica (ver feature_test_macros(7)), como se indica entre corchetes ("[]")

.

En las descripciones siguientes, "no en POSIX" significa que el valor no está especificado en POSIX.1-2001, y "XSI" significa que el valor está especificado en POSIX.1-2001 como parte de la extensión

XSI.

cfsetspeed

cfsetspeed - establecer velocidad de comunicación para un TTY

LIBRERÍA

Librería de control de terminales (libutil), pero se recomienda enlazar con librt o libbsd.

SINOPSIS

#include <termios.h>

speed_t cfgetspeed(const struct termios *termios_p);
int cfsetspeed(struct termios *termios_p, speed_t speed);

DESCRIPCIÓN

La función cfgetspeed devuelve la velocidad de entrada o salida del TTY especificado por termios_p.

La función cfsetspeed establece la velocidad de entrada y salida del TTY especificado por termios_p a speed.

El valor de speed debe ser una de las siguientes constantes simbólicas definidas en <asm-generic/termbits.h>:

  • B0
  • B50
  • B75
  • B110
  • B134
  • B150
  • B200
  • B300
  • B600
  • B1200
  • B1800
  • B2400
  • B4800
  • B9600
  • B19200
  • B38400
  • B57600
  • B115200
  • B230400
  • B460800
  • B500000
  • B576000
  • B921600
  • B1000000
  • B1152000
  • B1500000
  • B2000000
  • B2500000
  • B3000000
  • B3500000
  • B4000000

La constante B0 se usa para colgar.

El valor devuelto por cfgetspeed es de tipo speed_t, que es un alias para un tipo entero sin signo. Los valores de velocidad son las tasas de baudios (bits por segundo).

Las funciones cfgetospeed y cfsetospeed también están disponibles para obtener y establecer explícitamente la velocidad de salida, y cfgetispeed y cfsetispeed para la velocidad de entrada.

En sistemas modernos, la velocidad de entrada y salida suelen ser la misma, por lo que cfgetispeed y cfgetospeed devuelven el mismo valor, y cfsetispeed y cfsetospeed establecen ambas velocidades al mismo valor.

En la práctica, estas funciones solo modifican el miembro c_cflag de la estructura termios.

Para establecer la velocidad de comunicación de un terminal, debes llamar a tcsetattr después de haber modificado la estructura termios con cfsetspeed.

VALOR DE RETORNO

En caso de éxito, cfgetspeed devuelve la velocidad de comunicación. En caso de error, devuelve (speed_t)-1, pero no establece errno.

En caso de éxito, cfsetspeed devuelve 0. En caso de error, devuelve -1 y establece errno apropiadamente.

ATRIBUTOS

Para obtener una explicación de estos atributos, consulta attributes(7).

InterfazAtributo

ESTÁNDARES

POSIX.1-2001, POSIX.1-2008.

HISTORIA

Las funciones cfgetspeed y cfsetspeed son parte de la especificación POSIX y están disponibles en la mayoría de los sistemas tipo Unix.

NOTAS

El valor de speed debe ser una de las constantes predefinidas. Intentar usar un valor arbitrario puede llevar a un comportamiento indefinido o a errores.

Los valores de velocidad disponibles pueden variar entre sistemas. Las constantes de velocidad más altas (por ejemplo, mayores a 38400) pueden no ser compatibles con todo el hardware.

ERRORES

En algunas implementaciones antiguas, cfsetspeed podría no ser capaz de establecer velocidades superiores a 38400 baudios.
