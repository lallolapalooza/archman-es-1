DESCRIPCIÓ

N

Las funciones termios describen una interfaz de terminal general que se proporciona para controlar puertos de comunicación

asíncronos.

La estructura

termios

Muchas de las funciones descritas aquí tienen un termios_p argumento que es un puntero a una estructura termios. Esta estructura contiene al menos los siguientes

miembros: 


tcflag_t c_iflag;      /* modos de entrada */
tcflag_t c_oflag;      /* modos de salida */
tcflag_t c_cflag;      /* modos de control */
tcflag_t c_lflag;      /* modos locales */
cc_t     c_cc[NCCS];   /* caracteres especiales
*/

Los valores que pueden asignarse a estos campos se describen a continuación. En el caso de los cuatro primeros campos de máscara de bits, las definiciones de algunas de las banderas asociadas que pueden establecerse se exponen solo si se define una macro de prueba de características específica (ver feature_test_macros(7)), como se indica entre corchetes ("[]")

.

En las descripciones siguientes, "no en POSIX" significa que el valor no está especificado en POSIX.1-2001, y "XSI" significa que el valor está especificado en POSIX.1-2001 como parte de la extensión

XSI.

NAME

man-pages - format and installation conventions for manual pages

LIBRARY

This section does not apply.

SYNOPSIS

/usr/share/man/*

DESCRIPTION

The man-pages package contains the manual pages that describe the Linux operating system API (system calls and library functions) and the commands and file formats used by the GNU operating system. These manual pages are intended for use by Linux kernel developers and GNU system administrators and users.

The manual pages are organized into sections. The most relevant sections for the man-pages package are:

1
Executable programs or shell commands
2
System calls (functions provided by the kernel)
3
Library calls (functions within program libraries)
4
Special files (usually found in /dev)
5
File formats and conventions
6
Games
7
Miscellaneous (overviews, conventions, etc.)
8
System administration commands (usually for root)
9
Kernel routines [Non standard]

The manual pages are typically installed in subdirectories of /usr/share/man, named by section number. For example, system calls are in /usr/share/man/man2/, and commands are in /usr/share/man/man1/.

This package provides the man pages for the Linux C library (glibc) and the Linux kernel. For documentation on other libraries or programs, you may need to install other packages.

The format of the manual pages is typically groff(7) "man macros".

RETURN VALUE

This section does not apply.

ATTRIBUTES

This section does not apply.

STANDARDS

The manual pages in this package conform to the POSIX standard and the Linux standard.

HISTORY

The man-pages package has been a staple of Linux distributions for many years, providing essential documentation for developers and users.

NOTES

When referring to man pages, you can use the section number to disambiguate entries with the same name. For example, intro(1) refers to the introductory manual page for section 1 commands, while intro(2) refers to the introductory manual page for section 2 system calls.

The man command is used to read manual pages. For example, to read the manual page for the ls command, you would type:

man ls

To read the manual page for the fork system call, you would type:

man 2 fork

BUGS

There are no known bugs in the man-pages package itself. However, documentation errors or omissions in the manual pages may exist. You can report issues on the Linux Kernel Mailing List or the man-pages project's issue tracker.
