SINOPSI

# con argumentos y sin interruptores, instala los módulos especificados
cpan nombre_del_módulo [ nombre_del_módulo ... ]
# con interruptores, instala los módulos con comportamiento adicional
cpan [-cfFimtTw] nombre_del_módulo [ nombre_del_módulo ... ]
# usar local::lib
cpan -I nombre_del_módulo [ nombre_del_módulo ... ]
# anulación de espejo única para espejos más rápidos
cpan -p ...
# con solo el punto, instala desde la distribución en el
# directorio actual
cpan .
# sin argumentos, inicia el shell de CPAN.pm
cpan
# sin argumentos, pero con algunos interruptores
cpan

DESCRIPCIÓ

N

Este script proporciona una interfaz de comandos (no un shell) a CPAN. En el momento usa CPAN.pm para hacer el trabajo, pero no es un ejecutor de comandos único para CPAN.

pm.

Opcione

s
-
a
Crea un autobundle de CPAN.pm con CPAN::Shell->
autobundle.
-A módulo [ módulo ..
. ]
Muestra los mantenedores principales de los módulos
especificados.
-c
módulo
Ejecuta un `make clean` en los directorios del módulo
especificado.
-C módulo [ módulo ..
. ]
Muestra los archivos Changes de los módulos
especificados
-D módulo [ módulo ..
. ]
Muestra los detalles del módulo. Imprime una línea para cada módulo desactualizado (es decir, módulos instalados localmente pero que tienen versiones más nuevas en CPAN). Cada línea tiene tres columnas: nombre del módulo, versión local y versión de
CPAN.
-
f
Fuerza la acción especificada, cuando normalmente habría fallado. Usa esto para instalar un módulo incluso si sus pruebas fallan. Cuando usas esta opción, -i no es opcional para instalar un módulo cuando necesitas forzarlo: 
% cpan -f -i Module:
:
Foo
-
F
Desactiva los intentos de CPAN.pm de bloquear cualquier cosa. Debes tener cuidado con esto, ya que podrías terminar con varios scripts intentando manipular el mismo directorio. Esto no es tan preocupante si estás cargando una configuración especial con "-j", y esa configuración configura sus propios directorios de
trabajo.
-g módulo [ módulo ..
. ]
Descarga al directorio actual la última distribución del
módulo.
-G módulo [ módulo ..
. ]
NO IMPLEMENTADO

Descarga al directorio actual la última distribución de los módulos, desempaqueta cada distribución y crea un repositorio git para cada

Si quieres esta característica, consulta la distribución "Git::CPAN::Patch"

-
h
Imprime un mensaje de ayuda y sale. Cuando especificas "-h", ignora todas las demás opciones y
argumentos.

Instala los módulos especificados. Sin otros interruptores, este interruptor está
implícito.
-
I
Carga "local::lib" (piensa en "-I" para cargar rutas de lib). Qué lástima que "-l" ya estaba
tomado.
-j Config.

Carga el archivo que tiene los datos de configuración de CPAN. Este debe tener el mismo formato que el archivo estándar CPAN/Config.pm, que define $CPAN::Config como un hash
anónimo.
-
J
Vuelca la configuración en el mismo formato que usa CPAN.pm. Esto es útil para verificar la configuración, así como para usar el volcado como punto de partida para una nueva configuración
personalizada.

-
