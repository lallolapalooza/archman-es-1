CPANCOVER(1) Documentación de Perl contribuida por usuarios CPANCOVER(1)

NOMBRE

cpancover - informa estadísticas de cobertura en módulos CPAN

VERSIÓN

versión 1.51

SINOPSIS

cpancover --help --info --version
          --collect --redo_cpancover_html --redo_html --force --dryrun
          --modules nombre_modulo
          --results_dir /ruta/a/directorio
          --outputdir /ruta/a/directorio
          --outputfile nombre_archivo.html
          --report nombre_informe
          --generate_html
          --compress_old_versions numero_a_conservar
          --local
          --local_build

DESCRIPCIÓN

OPCIONES

Se admiten las siguientes opciones de línea de comandos:

-h --help               - mostrar ayuda
-i --info               - mostrar documentación
-v --version            - mostrar versión
--collect               - recopilar cobertura de módulos       (activado)
--compress_old_versions - comprimir datos de versiones antiguas (3)
--directory             - ubicación de los módulos             ($cwd)
--dryrun                - no ejecutar (para algunos comandos)   (desactivado)
--force                 - volver a recopilar cobertura         (desactivado)
--generate_html         - generar html                        (desactivado)
--local                 - usar código local (no instalado)     (desactivado)
--local_build           - construir cobertura para todos los módulos (desactivado)
--modules               - módulos a usar                      (todos en $dir)
--outputdir             - dónde almacenar la salida            ($directory)
--outputfile            - índice de nivel superior            (coverage.html)
--redo_cpancover_html   - no establecer módulos predeterminados (desactivado)
--redo_html             - forzar generación de html para módulos (desactivado)
--report                - informe a usar                       (html_basic)

DETALLES

REQUISITOS

Recopila cobertura para resultados y crea salida html, csv y json.

Se requieren los módulos Template y Parallel::Iterator.

ESTADO DE SALIDA

Los siguientes valores de salida se devuelven:

0
Todas las operaciones se completaron con éxito.
>0
Ocurrió un error.
