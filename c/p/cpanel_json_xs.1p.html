CPANEL_JSON_XS(1) Documentación de Perl aportada por el usuario CPANEL_JSON_XS(1)

NOMBRE

cpanel_json_xs - Utilidad de línea de comandos de Cpanel::JSON::XS

SINOPSIS

cpanel_json_xs [-v] [-f formato_entrada] [-t formato_salida]

DESCRIPCIÓN

cpanel_json_xs convierte entre algunos formatos de entrada y salida (uno de ellos es JSON).

El formato de entrada predeterminado es "json" y el formato de salida predeterminado es "json-pretty".

OPCIONES

-v
Ser un poco más detallado.
-f formato_entrada
Leer un archivo en el formato dado desde STDIN.

"formato_entrada" puede ser uno de:

json - texto json codificado, ya sea utf-8, utf16-be/le, utf32-be/le
json-nonref - json según RFC 7159
json-relaxed - json con todas las opciones relajadas
json-unknown - json con allow_unknown
storable - un valor Storable congelado
storable-file - un archivo Storable (Storable tiene dos formatos incompatibles)
bencode - usa Net::BitTorrent::Protocol::BEP03::Bencode, Bencode o el incorrecto Convert::Bencode, si están disponibles (usado por archivos torrent, entre otros)
clzf - formato Compress::LZF (requiere que ese módulo esté instalado)
eval - evalúa el código dado como Perl (no utf-8), básicamente lo inverso de "-t dump"
yaml - YAML suelto (requiere YAML)
yaml-tiny - YAML suelto (requiere YAML::Tiny o CPAN::Meta::YAML)
yaml-xs - YAML estricto 1.2 (requiere YAML::XS)
yaml-syck - YAML (requiere YAML::Syck)
cbor - CBOR (a través de CBOR::XS)
string - no intentes decodificar los datos del archivo
sereal - Sereal (a través de Sereal::Decoder)
none - no se lee nada, crea un escalar "undef" - principalmente útil con "-e"
-t formato_salida
Escribir el archivo en el formato dado a STDOUT.

"formato_salida" puede ser uno de:

json, json-utf-8 - json, codificado en utf-8
json-pretty - como el anterior, pero con formato bonito y claves de objeto ordenadas
json-stringify - como json-pretty con allow_stringify
json-relaxed - como json-pretty, pero con las opciones adicionales
->allow_stringify->allow_blessed->convert_blessed->allow_unknown ->allow_tags->stringify_infnan(1)
json-utf-16le, json-utf-16be - utf-16 little endian/big endian
json-utf-32le, json-utf-32be - utf-32 little endian/big endian
storable - un valor Storable congelado en formato de red
storable-file - un archivo Storable en formato de red (Storable tiene dos formatos incompatibles)
bencode - usa Net::BitTorrent::Protocol::BEP03::Bencode, Bencode o el incorrecto Convert::Bencode, si están disponibles (usado por archivos torrent, entre otros)
clzf - formato Compress::LZF
yaml - YAML suelto (requiere YAML)
yaml-tiny - YAML suelto (requiere YAML::Tiny o CPAN::Meta::YAML)
yaml-xs - YAML estricto 1.2 (requiere YAML::XS)
yaml-syck - YAML (requiere YAML::Syck)
dump - Data::Dump
dumper - Data::Dumper
string - escribe los datos como si fueran una cadena
sereal - Sereal (a través de Sereal::Encoder)
none - no se escribe nada, principalmente útil junto con "-e"
Nota: Data::Dumper no maneja correctamente las estructuras de datos autorreferenciales; usa "dump" en su lugar.
-e código
Evalúa código perl después de leer los datos y antes de volver a escribirlos; se puede usar para filtrar, crear o extraer datos. Los datos que se han escrito están en $_, y lo que sea que haya allí se escribe después.

EJEMPLOS

cpanel_json_xs -t none <isitreally.json

"JSON Lint" - intenta analizar el archivo isitreally.json como JSON; si es JSON válido, el comando no produce nada, de lo contrario, imprimirá un mensaje de error y saldrá con un estado de salida distinto de cero.

<src.json cpanel_json_xs >pretty.json

Formatear el archivo JSON src.json a dst.json.

cpanel_json_xs -f storable-file <file

Leer el archivo serializado de Storable file e imprimir una versión JSON legible por humanos en STDOUT.

cpanel_json_xs -f storable-file -t yaml <file

Igual que el anterior, pero escribir YAML en su lugar (sin usar JSON en absoluto :)

cpanel_json_xs -f none -e '$_ = [1, 2, 3]'

Imprimir el array de perl como texto JSON codificado en UTF-8.

<torrentfile cpanel_json_xs -f bencode -e '$_ = join "\n", map @$_, @{$_->{"announce-list"}}' -t string

Imprimir la lista de rastreadores dentro de un archivo torrent.

lwp-request http://cpantesters.perl.org/show/Cpanel-JSON-XS.json | cpanel_json_xs

Obtener el resumen de resultados de cpan-testers "Cpanel::JSON::XS" y formatearlo.

cpanel_json_xs -f yaml-xs -t yaml-tiny <META.yml   >MYMETA.yml
cpanel_json_xs -f yaml-tiny -t yaml-xs <MYMETA.yml >XSMETA.yml
cpanel_json_xs -f yaml -t yaml <XSMETA.yml #BOOM!
Error: YAML_LOAD_ERR_BAD_MAP_ELEMENT

Comparar codificadores y decodificadores YAML, y ver que YAML::XS genera YAML no analizable https://github.com/ingydotnet/yaml-libyaml-pm/issues/9
