CPAN::Perl::Releases(3) Documentación de Perl aportada por el usuario CPAN::Perl::Releases(3)

NOMBRE

CPAN::Perl::Releases - Mapeo de lanzamientos de Perl en CPAN a la ubicación de los archivos tarball

VERSIÓN

version 5.20251120

SINOPSIS

use CPAN::Perl::Releases qw[perl_tarballs];
my $perl = '5.14.0';
my $hashref = perl_tarballs( $perl );
print "Ubicación: ", $_, "\n" for values %{ $hashref };

DESCRIPCIÓN

CPAN::Perl::Releases es un módulo que contiene los mapeos de todos los lanzamientos de "perl" que se han subido a CPAN a la ruta "authors/id/" donde residen los archivos tarball.

Estos son datos estáticos, pero se pondrán a disposición versiones más nuevas de este módulo a medida que se suban nuevos lanzamientos de "perl" a CPAN.

FUNCIONES

"perl_tarballs"
Toma un parámetro, una versión de "perl" para buscar. Devuelve un hashref en caso de éxito o "undef" en caso contrario.

El hashref devuelto tendrá una entrada clave/valor para cada tipo de archivo tarball. Una clave de "tar.gz" indica la ubicación de un archivo tar comprimido con gzip y "tar.bz2" de un archivo tar comprimido con bzip2. Los valores serán la ruta relativa bajo "authors/id/" en CPAN donde se ubicará el archivo tarball indicado.

perl_tarballs( '5.14.0' );
Devuelve un hashref como:
{
  "tar.bz2" => "J/JE/JESSE/perl-5.14.0.tar.bz2",
  "tar.gz" => "J/JE/JESSE/perl-5.14.0.tar.gz"
}

No todos los lanzamientos de "perl" tenían "tar.bz2", solo un "tar.gz".

Los archivos tar de Perl también pueden estar comprimidos usando "xz" y, por lo tanto, tener una entrada "tar.xz".

"perl_versions"
Devuelve la lista de todas las versiones de perl soportadas por el módulo en orden ascendente. "TRIAL" y "RC" serán menores que un lanzamiento real.
"perl_pumpkins"
Devuelve una lista ordenada de todos los IDs de PAUSE de calabazas de Perl.
