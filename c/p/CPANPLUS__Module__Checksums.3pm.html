NOMBRE

CPANPLUS::Module::Checksums - comprobación de la suma de control de una distribución

SINOPSIS

$archivo   = $modobj->checksums;
$booleano   = $mobobj->_validate_checksum;

DESCRIPCIÓN

Esta es una clase que proporciona funciones para comprobar la suma de control de una distribución. No debe cargarse directamente, sino utilizarse a través de la interfaz proporcionada por "CPANPLUS::Module".

MÉTODOS

$mod->checksums

Obtiene el archivo de sumas de control para este objeto de módulo. Para las opciones que puede aceptar, consulte CPANPLUS::Module::fetch().

Devuelve la ubicación del archivo de sumas de control en caso de éxito y falso en caso de error.

La ubicación del archivo de sumas de control también se almacena como

$mod->status->checksums
