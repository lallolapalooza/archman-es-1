CPANPLUS::Internals::Fetch(3) Documentación contribuida por el usuario de Perl CPANPLUS::Internals::Fetch(3)

NOMBRE

CPANPLUS::Internals::Fetch - internos para la obtención de archivos

SINOPSIS

mi $salida = $cb->_fetch(
                    modulo      => $objmodulo,
                    directorio_obtencion => '/ruta/para/guardar/en',
                    verbose     => BOOL,
                    forzar      => BOOL,
                );
$cb->_add_fail_host( host => 'foo.com' );
$cb->_host_ok(       host => 'foo.com' );

DESCRIPCIÓN

CPANPLUS::Internals::Fetch obtiene archivos de espejos ftp, http, file o rsync.

Este es el flujo aproximado:

$cb->_fetch
    Delega a File::Fetch;

MÉTODOS

$ruta = _fetch( modulo => $objmodulo, [directorio_obtencion => '/ruta/para/guardar/en', obtener_de => 'esquema://ruta/para/obtener/de', verbose => BOOL, forzar => BOOL, preferir_bin => BOOL, ttl => $segundos] )

"_fetch" obtendrá archivos basándose en la información de un objeto de módulo. Siempre necesitas un objeto de módulo. Si quieres un objeto de módulo falso para una obtención única, mira "CPANPLUS::Module::Fake".

"directorio_obtencion" es el lugar donde guardar el archivo. Normalmente esta información proviene de tu configuración, pero puedes anularla expresamente si es necesario.

"obtener_de" te permite especificar una URI para obtener este archivo. Si no especificas una, tu lista de hosts configurados será sondeada para descargar el archivo.

"forzar" fuerza una nueva descarga, incluso si el archivo ya existe.

"verbose" simplemente indica si imprimir mensajes adicionales o no.

"preferir_bin" indica si prefieres el uso de programas de línea de comandos sobre módulos perl. Por defecto es tu configuración correspondiente.

"ttl" (en segundos) indica cuánto tiempo es válida una copia en caché. Si el tiempo de obtención de la copia local está dentro del ttl, se devuelve la copia en caché. De lo contrario, el archivo se vuelve a obtener.

"_fetch" determina, basándose en la lista de hosts, qué esquema usar y, a partir de ahí, delega a "File::Fetch" para realizar la obtención real.

Devuelve la ruta del archivo de salida en caso de éxito, falso en caso de fallo.

Ten en cuenta que puedes establecer una "lista negra" en ciertos métodos en la configuración. Simplemente añade el nombre identificador del método (es decir, "lwp") a:
$conf->_set_fetch( lista_negra => ['lwp'] );

Y la función "LWP" será omitida por "File::Fetch".

_add_fail_host( host => $hashref_host )

Marca un host particular como defectuoso. Esto hace que "CPANPLUS::Internals::Fetch" lo omita en las obtenciones hasta que se vacíe esta caché.

_host_ok( host => $hashref_host )

Consulta la caché para ver si este host está bien, o si ha sido marcado como defectuoso.

Devuelve verdadero si el host está bien, falso en caso contrario.
