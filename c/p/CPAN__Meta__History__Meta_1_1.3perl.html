build_requires
Ejemplo: 
Data::Dumper: 0
File::Find: 1.03

Un mapeo YAML http://yaml.org/spec/history/2002-10-31.html#syntax-mapping indicando los módulos de Perl necesarios para la compilación y/o las pruebas de esta distribución. Estas dependencias no son necesarias después de que el módulo esté instalado.

conflicts
Ejemplo: 
Data::Dumper: 0
File::Find: 1.03

Un mapeo YAML http://yaml.org/spec/history/2002-10-31.html#syntax-mapping indicando los módulos de Perl que no se pueden instalar mientras esta distribución está instalada. Esta es una situación bastante poco común.

- posiblemente separar los prerrequisitos del tiempo de prueba, las complicaciones incluyen: ¿se pueden conservar las pruebas de manera significativa para ejecutarlas más tarde? ¿los prerrequisitos del tiempo de prueba son adicionales a los del tiempo de compilación, o exclusivos?

- hacer una ubicación oficial para las *distribuciones* instaladas, que pueden contener pruebas, etc.

dynamic_config
Ejemplo: 0

Un indicador booleano que indica si un Build.PL o Makefile.PL (o similar) debe ser ejecutado, o si este módulo puede ser compilado, probado e instalado únicamente consultando su archivo de metadatos. La razón principal para establecer esto en un valor verdadero es que su módulo realiza alguna configuración dinámica (hacer preguntas, detectar el entorno, etc.) como parte de su proceso de compilación/instalación.

Actualmente Module::Build no hace nada realmente con este indicador - probablemente dependerá de herramientas de nivel superior como CPAN.pm para hacer algo útil con él. Potencialmente puede aportar muchas mejoras de seguridad, empaquetado y comodidad.

generated_by
Ejemplo: "Module::Build version 0.16"

Indica la herramienta que se utilizó para crear este archivo META.yml Es buena práctica incluir tanto el nombre de la herramienta como su versión, pero este campo es esencialmente opaco, al menos por el momento.

Sugerencias de Ingy

short_description
agregar como campo, que contenga el resumen, máximo 80 caracteres, se sugiere un mínimo de 40 caracteres
description
versión larga del resumen, ¿debería agregarse?
maturity
alfa, beta, gamma, maduro, estable
author_id, owner_id
categorization, keyword, chapter_id
URL para más información
podría ser search.cpan.org en PAUSE por defecto
namespaces
se pueden especificar para elementos individuales anteponiendo la forma con puntos, es decir, "com.example.my_application.my_property". El espacio de nombres predeterminado para META.yml probablemente sea "org.cpan.meta_author" o algo similar. El precedente para esto son los espacios de nombres de Carbon de Apple, creo.
