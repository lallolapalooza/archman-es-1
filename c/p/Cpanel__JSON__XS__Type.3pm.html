DESCRIPCIÓ

N

Este módulo proporciona soporte de tipos JSON estable para el codificador Cpanel::JSON::XS que no depende de ninguna característica o indicador interno de escalares de perl. También proporciona tipos JSON reales para el decodificador de Cpanel::JSON::

XS.

En la mayoría de los casos, las estructuras de perl pasadas a encode_json provienen de otras funciones o de otros módulos, y el usuario del módulo Cpanel::JSON::XS no tiene control sobre los internos o estos están sujetos a cambios. Por lo tanto, no es fácil soportar la imposición de tipos como se describe en la sección de escalares

simples.

Para servicios basados en el contenido JSON, a veces es necesario procesar e imponer correctamente los tipos

JSON.

La función decode_json acepta un tercer parámetro escalar opcional y lo rellena con la especificación de los tipos

json.

La función encode_json toma una estructura de perl como entrada y opcionalmente también una especificación de tipo json en el segundo

parámetro.

Si la especificación no se proporciona (o es undef), se usan los indicadores internos de escalares de perl para el tipo JSON resultante. Los indicadores internos pueden ser cambiados por el propio perl, pero también por módulos externos. Lo que significa que los tipos en la cadena JSON resultante no son estables. Especialmente, no funciona de forma fiable para variables duales y escalares que se han utilizado tanto en operaciones numéricas como de cadena. Véase escalares

simples.

Para forzar que la especificación siempre se proporcione, use "require_types". En este caso, cuando se llama a "encode" sin segundo argumento (o es undef), se produce un error fatal (croak). Esto se aplica recursivamente a todas las

subestructuras.

Especificaciones

recursivas
json_type_wea
ken
Esta función puede usarse como argumento para las funciones "json_type_arrayof", "json_type_hashof" o "json_type_anyof" para crear referencias débiles (weak references) adecuadas para estructuras recursivas complicadas. Depende de la función weaken del módulo Scalar::Util. Véase el siguiente ejemplo: 
my $struct = {
    type => JSON_TYPE_STRING,
    array => json_type_arrayof(JSON_TYPE_INT),
};
$struct->{recursive} = json_type_anyof(
    json_type_weaken($struct),
    json_type_arrayof(JSON_TYPE_STRING)
, );

Si desea codificar todos los escalares de perl a tipos de cadena JSON, independientemente de lo complicada que sea la estructura de perl de entrada, puede definir la especificación de tipo JSON para alternativas de forma recursiva. Podría

definirse como: 
my $type = json_type_anyof();
$type->[0] = JSON_TYPE_STRING_OR_NULL;
$type->[1] = json_type_arrayof(json_type_weaken($type));
$type->[2] = json_type_hashof(json_type_weaken($type));
print encode_json([ 10, "10", { key => 10 } ], $type);
# ["10","10",{"key":
"10"}]
