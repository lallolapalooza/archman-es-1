CPANPLUS::Shell::Default::Plugins::CustomSource(3) Documentación aportada por el usuario de Perl CPANPLUS::Shell::Default::Plugins::CustomSource(3)

NOMBRE

CPANPLUS::Shell::Default::Plugins::CustomSource - añadir fuentes personalizadas a CPANPLUS

SINOPSIS

### texto de ayuda elaborado
CPAN Terminal> /? cs
### añadir una nueva fuente personalizada
CPAN Terminal> /cs --add file:///ruta/a/releases
### listar todas tus fuentes personalizadas por
CPAN Terminal> /cs --list
### mostrar el contenido de una fuente personalizada por URI o ID
CPAN Terminal> /cs --contents file:///ruta/a/releases
CPAN Terminal> /cs --contents 1
### Actualizar una fuente personalizada por URI o ID
CPAN Terminal> /cs --update file:///ruta/a/releases
CPAN Terminal> /cs --update 1
### Eliminar una fuente personalizada por URI o ID
CPAN Terminal> /cs --remove file:///ruta/a/releases
CPAN Terminal> /cs --remove 1
### Escribir un archivo de índice para una fuente personalizada, para compartir
### con terceros o usuarios remotos
CPAN Terminal> /cs --write file:///ruta/a/releases
### Asegúrate de guardar tus fuentes al añadir/eliminar
### fuentes, para que tus cambios se reflejen en la caché:
CPAN Terminal> x

DESCRIPCIÓN

Este es un plugin de "CPANPLUS::Shell::Default" que puede añadir fuentes personalizadas a tu instalación de CPANPLUS. Es un envoltorio para el código de "fuentes de módulos personalizadas" descrito en "FUENTES DE MÓDULOS PERSONALIZADAS" en CPANPLUS::Backend.

Esto te permite extender tu índice de módulos disponibles más allá de lo que está disponible en "CPAN" con tus propias distribuciones locales, o las ofrecidas por terceros.
