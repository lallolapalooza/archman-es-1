ESPECIFICACIONES DE

VERSIÓN

Algunos campos requieren una especificación de versión (por ejemplo, "requires", "recommends", "build_requires", etc.) para indicar la(s) versión(es) particular(es) de algún otro módulo que puede ser requerido como prerrequisito. Esta sección detalla los formatos de especificación de versión que se admiten

actualmente.

El formato más simple para una especificación de versión es simplemente el número de versión en sí, por ejemplo, 2.4. Esto significa que debe estar presente al menos la versión 2.4. Para indicar que cualquier versión de un prerrequisito es aceptable, incluso si el prerrequisito no define una versión en absoluto, use la versión 0

.

También puede usar los operadores < (menor que), <= (menor o igual), > (mayor que), >= (mayor o igual), == (igual), y != (distinto de). Por ejemplo, la especificación < 2.0 significa que cualquier versión del prerrequisito menor que 2.0 es

adecuada.

Para situaciones más complicadas, las especificaciones de versión pueden combinarse con AND usando comas. La especificación >= 1.2, != 1.5, < 2.0 indica una versión que debe ser al menos 1.2, menor que 2.0, y distinta d

e
1.5.
