CPAN::Plugin(3perl) Guía del programador de Perl CPAN::Plugin(3perl)

NOMBRE

CPAN::Plugin - Clase base para extensiones del shell CPAN

SINOPSIS

package CPAN::Plugin::Flurb;
use parent 'CPAN::Plugin';
sub post_test {
  my ($self, $distribution_object) = @_;
  $self = $self->new (distribution_object => $distribution_object);
  ...;
}

DESCRIPCION

Estado Alfa

El sistema de plugins en el shell CPAN se introdujo en la versión 2.07 y todavía se considera experimental.

¿Cómo funcionan los plugins?

Ver "Soporte de plugins" en CPAN.

MÉTODOS

plugin_requires

devuelve una lista de paquetes que el plugin requiere para su funcionalidad. Esta lista se evalúa usando el método "CPAN->use_inst".

distribution_object

Obtiene el objeto de distribución actual.

distribution

distribution_info

build_dir

Delegados simples para parámetros varios derivados de la distribución.

is_xs

Predicado para detectar si el paquete contiene XS.
