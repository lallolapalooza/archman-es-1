CPANPLUS::Shell(3) Documentación de contribución de usuarios de Perl CPANPLUS::Shell(3)

NOMBRE

CPANPLUS::Shell - clase base para shells de CPANPLUS

SINOPSIS

use CPANPLUS::Shell;             # carga el shell indicado por tu
                                 # configuración -- por defecto
                                 # CPANPLUS::Shell::Default
use CPANPLUS::Shell qw[Classic]  # carga CPANPLUS::Shell::Classic;
my $ui      = CPANPLUS::Shell->new();
my $name    = $ui->which;        # Averigua qué shell cargaste
$ui->shell;                      # ejecuta el shell de la interfaz de usuario

DESCRIPCIÓN

Este módulo es la carga genérica (y clase base) para todos los shells de "CPANPLUS". A través de este módulo puedes cargar cualquier shell de "CPANPLUS" instalado.

Casi toda la funcionalidad es proporcionada por el shell que has cargado, y no por esta clase (que meramente funciona como una clase de carga genérica), así que por favor consulta la documentación de tu shell de elección.
