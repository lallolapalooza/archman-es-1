Licencias: PerlArtistic, GPL

CPANPLUS::Module::Fake(3) Documentación de Perl contribuida por el usuario CPANPLUS::Module::Fake(3)

NOMBRE

CPANPLUS::Module::Fake - objeto de módulo falso para uso interno

SINOPSIS

my $obj = CPANPLUS::Module::Fake->new(
            module  => 'Foo',
            path    => 'ftp/path/to/foo',
            author  => CPANPLUS::Module::Author::Fake->new,
            package => 'fake-1.1.tgz',
            _id     => $cpan->_id,
        );

DESCRIPCIÓN

Una clase para crear objetos de módulo falsos, para uso de acceso directo interno de CPANPLUS.

Hereda de "CPANPLUS::Module".

MÉTODOS

new( module => $mod, path => $path, package => $pkg, [_id => DIGIT] )

Crea un objeto de módulo ficticio a partir de los parámetros anteriores. Puede aceptar más opciones (igual que "CPANPLUS::Module->new" pero los anteriores son obligatorios.
