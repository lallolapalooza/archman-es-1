"best_mirrors" verifica los mejores mirrors basándose en la lista de continentes que pasas o, sin eso, todos los continentes, tal como se definen en "CPAN::Mirrored::By". Hace ping a cada mirror, hasta el valor de "how_many". En contexto de lista, devuelve hasta "how_many" mirrors. En contexto escalar, devuelve el mejor mirror.

Argum

entos 
how_many      - el número de mirrors a devolver. Predeterminado: 1
callback      - un callback para find_best_continents
verbose       - verdadero o falso para todo el quejarse y gemir. Predeterminado: falso
continents    - una referencia de matriz de los continentes a verificar
external_ping - si es verdadero, usa ping externo a través de Net::Ping::External. Predeterminado:
falso

Si no especificas los continentes, "best_mirrors" llama a "find_best_continents" para obtener la lista de continentes a

verificar.

Si no tienes Net::Ping v2.13 o posterior, necesario para los tiempos, esto devuelve el mirror

predeterminado.

"external_ping" debería establecerse y luego "Net::Ping::External" necesita instalars

get_mirrors_timings( MIRROR_LIST, SEEN, CALLBACK, %ARGS
);
Hace ping a los mirrors listados y devuelve una lista de mirrors ordenada en tiempos de ping ascendentes.

"MIRROR_LIST" es una matriz anónima de objetos "CPAN::Mirrored::By" a hacer

ping.

El argumento opcional "SEEN" es una referencia de hash utilizada para rastrear los mirrors a los que ya has hecho

ping.

El argumento opcional "CALLBACK" es una referencia de subrutina a llamar después de cada ping. Recibe el objeto "CPAN::Mirrored::By" después de cada

ping.
find_best_continents( HASH_REF
);
"find_best_continents" recorre cada continente y hace ping a "N" mirrors aleatorios en ese continente. Luego ordena los continentes por tiempo de ping mediano ascendente. En contexto de lista, devuelve la lista ordenada de continentes. En contexto escalar, devuelve la misma lista como una matriz anónima.

Argume

ntos: 
n        - el número de hosts a hacer ping para cada continente. Predeterminado: 3
seen     - una referencia de hash de tiempos de ping de nombres de host en caché
verbose  - verdadero o falso para ruidoso o silencioso. Predeterminado: falso
callback - una subrutina a ejecutar después de cada ping.
ping_cache_limit - cuánto tiempo, en segundos, reutilizar tiempos de ping anteriores.
    Predeterminado:
1 día

El hash "seen" tiene nombres de host como claves y matrices anónimas como valores. La matriz anónima es un trío de un objeto "CPAN::Mirrored::By", un tiempo de ping y la hora epoch de la

medición.

La subrutina de callback recibe el objeto "CPAN::Mirrored::By", el tiempo de ping y el tiempo de medición (las mismas cosas en la referencia de hash "seen") como argumentos. "find_best_continents" no le importa lo que haga el callback e ignora el valor de

retorno.

Con un valor bajo para "N", un solo mirror podría desviar los resulta

dos lo suficiente como para
elegir un continente peor.
Si tienes ese probl
ema, prueba un valor mayor.
