CPAN::Meta::Converter(3perl) Guía de referencia para programadores de Perl CPAN::Meta::Converter(3perl)

NOMBRE

CPAN::Meta::Converter - Convierte estructuras de metadatos de distribuciones CPAN

VERSIÓN

version 2.150010

SINOPSIS

my $struct = decode_json_file('META.json');
my $cmc = CPAN::Meta::Converter->new( $struct );
my $new_struct = $cmc->convert( version => "2" );

DESCRIPCIÓN

Este módulo convierte estructuras de Metadatos de CPAN de una forma a otra. El uso principal es convertir estructuras antiguas a la versión más moderna de la especificación, pero otras transformaciones pueden ser implementadas en el futuro según sea necesario. (Ej. eliminar todos los campos personalizados o eliminar todos los campos opcionales).

MÉTODOS

new

my $cmc = CPAN::Meta::Converter->new( $struct );

Se debe pasar una estructura de metadatos válida al constructor, pero también se aceptan estructuras inválidas. Si no se proporciona una versión de meta-especificación, se asumirá la versión 1.0.

Opcionalmente, puede proporcionar un argumento "default_version" después de $struct:

my $cmc = CPAN::Meta::Converter->new( $struct, default_version => "1.4" );

Esto solo es necesario cuando se convierte un fragmento de metadatos que no incluye un campo "meta-spec".

convert

my $new_struct = $cmc->convert( version => "2" );

Devuelve una nueva referencia de hash con los metadatos convertidos a una forma diferente. "convert" fallará si alguna conversión/estandarización aún resulta en una estructura inválida.

Los parámetros válidos incluyen:

•
"version" -- Indica la versión de especificación deseada (ej. "1.0", "1.1" ... "1.4", "2"). Por defecto, la última versión de la Especificación de Metadatos de CPAN.

La conversión procede versión por versión. Por ejemplo, una estructura de versión 1.2 podría convertirse a 1.3, luego a 1.4 y finalmente a la versión 2. El proceso de conversión intenta corregir errores simples y estandarizar datos. Por ejemplo, si "author" se da como un escalar, se convertirá a una referencia de array que contiene el elemento. (Convertir una estructura a su propia versión también limpiará y estandarizará).

Cuando los datos se limpian y estandarizan, los campos faltantes o inválidos serán reemplazados por valores predeterminados razonables cuando sea posible. Esto puede ser con pérdida de información o impreciso. Por ejemplo, algunos archivos META.yml mal estructurados en CPAN tienen módulos prerrequisito listados como claves y valores:

requires => { 'Foo::Bar' => 'Bam::Baz' }

Estos se dividirán y cada uno se convertirá en un prerrequisito con una versión mínima de cero.

Cuando faltan algunos campos obligatorios o son inválidos, la conversión intentará proporcionar un valor predeterminado razonable o los rellenará con el valor 'unknown'. Por ejemplo, un campo "license" faltante o no reconocido dará como resultado un campo "license" de 'unknown'. Los campos que pueden recibir un valor de 'unknown' incluyen:

  • abstract
  • author
  • license

upgrade_fragment

my $new_struct = $cmc->upgrade_fragment;

Devuelve una nueva referencia de hash con los metadatos convertidos a la última versión de la Especificación de Metadatos de CPAN. No se realiza validación en el resultado: debe validar después de fusionar los fragmentos en un documento de metadatos completo.

Disponible desde la versión 2.141170.
