NOMBRE

CPAN::Distroprefs -- leer y comparar distroprefs

SINOPSIS

use CPAN::Distroprefs;
my %info = (... información de distribución/entorno ...);
my $finder = CPAN::Distroprefs->find($prefs_dir, \%ext_map);
while (my $result = $finder->next) {
    die $result->as_string if $result->is_fatal;
    warn($result->as_string), next if $result->is_warning;
    for my $pref (@{ $result->prefs }) {
        if ($pref->matches(\%info)) {
            return $pref;
        }
    }
}

DESCRIPCIÓN

Este módulo encapsula la lectura de Distroprefs y su comparación con distribuciones de CPAN.

INTERFAZ

my $finder = CPAN::Distroprefs->find($dir, \%ext_map);
while (my $result = $finder->next) { ... }

Construye un iterador que busca archivos distroprefs en el árbol debajo del directorio dado. Dentro del árbol, los directorios que coinciden con "m/^[._]/" se podan.

%ext_map es un hashref cuyas claves son extensiones de archivo y cuyos valores son módulos utilizados para cargar archivos coincidentes:

{
    'yml' => 'YAML::Syck',
    'dd'  => 'Data::Dumper',
    ...
}

Cada vez que se llama a "$finder->next", el iterador devuelve uno de dos valores posibles:

  • un objeto CPAN::Distroprefs::Result
  • "undef", lo que indica que no quedan más archivos de preferencias por encontrar

RESULTADOS

find() devuelve objetos CPAN::Distroprefs::Result para indicar éxito o fallo al leer un archivo de preferencias.

Común

Todos los resultados comparten algunos atributos comunes:

type

"success", "warning", o "fatal"

file

el archivo desde el cual se leyeron estas preferencias, o al cual se refiere este error (nombre de archivo relativo)

ext

la extensión del archivo, que determina cómo cargarlo

dir

el directorio desde el cual se leyó el archivo

abs

la ruta absoluta al archivo

Errores

Los resultados de error (advertencia y fatal) contienen:

msg

el mensaje de error (generalmente $! o un error de YAML)

Éxitos

Los resultados de éxito contienen:

prefs

un arrayref de objetos CPAN::Distroprefs::Pref

PREFS

Los objetos CPAN::Distroprefs::Pref representan documentos individuales de distroprefs. Se construyen automáticamente como parte de los resultados de "success" de find().

data

la información de preferencia como un hashref, adecuado para, por ejemplo, pasar a Kwalify

match_attributes

devuelve una lista de los atributos de coincidencia válidos (ver la sección Distroprefs en CPAN)

actualmente: "env perl perlconfig distribution module"

has_any_match

verdadero si esta preferencia tiene algún atributo 'match' en absoluto

has_valid_subkeys

verdadero si esta preferencia tiene un atributo 'match' y al menos una subclave de coincidencia válida

matches

if ($pref->matches(\%arg)) { ... }

verdadero si esta preferencia coincide con el hashref pasado, que debe tener un valor para cada uno de los "match_attributes" (arriba)
