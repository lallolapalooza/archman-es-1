subroutine cptrfs (character uplo, integer n, integer nrhs, real, dimension( * ) d, complex, dimension( * ) e, real, dimension( * ) df, complex, dimension( * ) ef, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CPTRFS

Propósito:

!>
!> CPTRFS mejora la solución calculada de un sistema de ecuaciones lineales
!> cuando la matriz de coeficientes es hermitiana definida positiva
!> y tridiagonal, y proporciona límites de error y estimaciones de error hacia atrás
!> para la solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la superdiagonal o la subdiagonal de la
!>          matriz tridiagonal A está almacenada y la forma de la
!>          factorización:
!>          = 'U':  E es la superdiagonal de A, y A = U**H*D*U;
!>          = 'L':  E es la subdiagonal de A, y A = L*D*L**H.
!>          (Las dos formas son equivalentes si A es real.)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

D

!>          D es un array REAL, dimensión (N)
!>          Los n elementos diagonales reales de la matriz tridiagonal A.
!>

E

!>          E es un array COMPLEX, dimensión (N-1)
!>          Los elementos fuera de la diagonal (n-1) de la matriz tridiagonal A
!>          (ver UPLO).
!>

DF

!>          DF es un array REAL, dimensión (N)
!>          Los n elementos diagonales de la matriz diagonal D de
!>          la factorización calculada por CPTTRF.
!>

EF

!>          EF es un array COMPLEX, dimensión (N-1)
!>          Los elementos fuera de la diagonal (n-1) de la factor
!>          bidiagonal unitaria U o L de la factorización calculada por CPTTRF
!>          (ver UPLO).
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, calculada por CPTTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimensión (NRHS)
!>          El límite de error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j).
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga de X(j) una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (N)
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
