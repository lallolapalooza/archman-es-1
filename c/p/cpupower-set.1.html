CPUPOWER-SET(1) Manual de cpupower CPUPOWER-SET(1)

NOMBRE

cpupower-set - Establece configuraciones relacionadas con la energía del procesador en el kernel o el hardware

SINOPSIS

cpupower set [ -b VAL | -e POLÍTICA | -m MODO | -t BOLEANO ]

DESCRIPCIÓN

cpupower set establece configuraciones del kernel o accede directamente a registros de hardware que afectan las políticas de ahorro de energía del procesador.

Algunas opciones son generales para la plataforma, otras afectan a núcleos individuales. Por defecto, los valores se aplican a todos los núcleos. Cómo modificar las configuraciones de núcleos individuales se describe en la página del manual de cpupower(1) en la sección de la opción --cpu. Si una opción afecta a todo el sistema o se puede aplicar a núcleos individuales se describe en las secciones de Opciones.

Utilice cpupower info para leer la configuración actual y si es compatible con el sistema.

OPCIONES

--perf-bias, -b

Establece un registro en procesadores Intel compatibles que permite al software comunicar su política sobre la importancia relativa del rendimiento frente al ahorro de energía al procesador.

El rango de números válidos es 0-15, donde 0 es máximo rendimiento y 15 es máxima eficiencia energética.

El procesador utiliza esta información de maneras específicas del modelo cuando debe seleccionar compromisos entre rendimiento y eficiencia energética.

Esta indicación de política no sustituye los estados de rendimiento del procesador (P-states) ni los estados de energía inactivos de la CPU (C-states), pero permite al software tener influencia donde de otro modo no podría expresar una preferencia.

Por ejemplo, esta configuración puede indicar al hardware con qué agresividad controlar la frecuencia en el rango "turbo" por encima del rango de frecuencia de P-state controlado explícitamente por el sistema operativo. También puede indicar al hardware con qué agresividad debe entrar en los C-states solicitados por el sistema operativo.

Esta opción solo se puede aplicar a núcleos individuales a través de la opción --cpu, cpupower(1).

Establecer el valor de rendimiento del sesgo en una CPU puede modificar la configuración en CPUs relacionadas (por ejemplo, todas las CPUs de un socket), debido a restricciones de hardware. Utilice cpupower -c all info -b para verificar.

Esta opción necesita el controlador del kernel msr (CONFIG_X86_MSR) cargado.

--epp, -e

Establece la preferencia de política de rendimiento energético en procesadores Intel o AMD compatibles que utilizan el controlador cpufreq de P-State de Intel o AMD, respectivamente.

Las políticas disponibles se pueden encontrar con cat /sys/devices/system/cpu/cpufreq/policy0/energy_performance_available_preferences :

default performance balance_performance balance_power power

--amd-pstate-mode, -m

Establece el modo P-State de AMD para procesadores AMD compatibles. Los modos disponibles son "active", "guided" o "passive".

Consulte la documentación del kernel de P-State de AMD para obtener más información.

--turbo-boost, --boost, -t

Esta opción se utiliza para habilitar o deshabilitar la función de impulso (boost) en procesadores Intel y AMD compatibles, y otros sistemas que admiten el impulso. (La opción --boost es un alias de la opción --turbo-boost)

Esta opción toma como parámetro 1 para habilitar o 0 para deshabilitar la función.
