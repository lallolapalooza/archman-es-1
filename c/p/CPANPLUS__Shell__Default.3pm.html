CPANPLUS::Shell::Default(3) Documentación de Perl contribuida por el usuario CPANPLUS::Shell::Default(3)

NOMBRE

CPANPLUS::Shell::Default - el shell por defecto de CPANPLUS

SINOPSIS

### cargando el shell:
$ cpanp                     # ejecutar 'cpanp' desde la línea de comandos
$ perl -MCPANPLUS -eshell   # cargar el shell desde la línea de comandos
use CPANPLUS::Shell qw[Default];        # cargar este shell a través de la API
                                        # siempre hecho a través de CPANPLUS::Shell
my $ui = CPANPLUS::Shell->new;
$ui->shell;                             # ejecutar el shell
$ui->dispatch_on_input( input => 'x');  # actualizar la fuente usando el
                                        # método dispatch
### cuando se está en el shell:
### Tenga en cuenta que todos los comandos también pueden tomar opciones.
### Mire sus métodos subyacentes de CPANPLUS::Backend para ver
### qué opciones tienen.
cpanp> h                 # mostrar mensajes de ayuda
cpanp> ?                 # mostrar mensajes de ayuda
cpanp> m Acme            # buscar módulos de acme, permite expresiones regulares
cpanp> a KANE            # buscar módulos por kane, permite expresiones regulares
cpanp> f Acme::Foo       # obtener una lista de todas las versiones de Acme::Foo
cpanp> i Acme::Foo       # instalar Acme::Foo
cpanp> i Acme-Foo-1.3    # instalar la versión 1.3 de Acme::Foo
cpanp> i <URI>           # instalar desde URI, como ftp://foo.com/X.tgz
cpanp> i <DIR>           # instalar desde un directorio absoluto o relativo
cpanp> i 1 3..5          # instalar resultados de búsqueda 1, 3, 4 y 5
cpanp> i *               # instalar todos los resultados de búsqueda
cpanp> a KANE; i *;      # buscar módulos por kane, instalar todos los resultados
cpanp> t Acme::Foo       # probar Acme::Foo, sin instalarlo
cpanp> u Acme::Foo       # desinstalar Acme::Foo
cpanp> d Acme::Foo       # descargar Acme::Foo
cpanp> z Acme::Foo       # descargar y extraer Acme::Foo, luego abrir un
                         # shell en el directorio de extracción
cpanp> c Acme::Foo       # obtener una lista de resultados de pruebas para Acme::Foo
cpanp> l Acme::Foo       # ver detalles sobre el paquete Acme::Foo
cpanp> r Acme::Foo       # ver el archivo README de Acme::Foo
cpanp> o                 # obtener una lista de todos los módulos instalados que
                         # están desactualizados
cpanp> o 1..3            # listar la actualización desde una búsqueda anterior
cpanp> s conf            # mostrar configuraciones
cpanp> s conf md5 1      # habilitar comprobaciones md5
cpanp> s program         # mostrar configuraciones del programa
cpanp> s edit            # editar archivo de configuración
cpanp> s reconfigure     # volver a pasar por la configuración inicial
cpanp> s selfupdate      # actualizar su instalación de CPANPLUS
cpanp> s save            # guardar configuración en disco
cpanp> s mirrors         # mostrar los espejos actualmente seleccionados
cpanp> ! [CÓDIGO PERL]    # ejecutar el siguiente código perl
cpanp> b                 # crear un autobundle para la instalación de
                         # perl de este ordenador
cpanp> x                 # recargar archivos de índice (descarta la caché)
cpanp> x --update_source # recargar archivos de índice, obtener archivos fuente frescos
cpanp> p [ARCHIVO]          # imprimir pila de errores (a un archivo)
cpanp> v                 # mostrar el banner
cpanp> w                 # mostrar nuevamente los últimos resultados de búsqueda
cpanp> q                 # salir del shell
cpanp> e                 # salir del shell y recargar
cpanp> /plugins          # listar plugins disponibles
cpanp> /? PLUGIN         # listar ayuda del plugin <PLUGIN>
### opciones comunes:
cpanp> i ... --skiptest # omitir pruebas
cpanp> i ... --force    # forzar todas las operaciones
cpanp> i ... --verbose  # ejecutar en modo detallado

DESCRIPCIÓN

Este módulo proporciona la interfaz de usuario por defecto para "CPANPLUS". Puede iniciarlo a través del ejecutable "cpanp", o como se detalla en la sección SINOPSIS.
