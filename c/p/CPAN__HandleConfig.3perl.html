NOMBRE

CPAN::HandleConfig - manejo interno de configuración para CPAN.pm

"CLASE->safe_quote ELEMENTO"

Cita un elemento para que sea seguro contra espacios en la interpolación del shell. Un elemento se encierra entre comillas dobles si:

- el elemento contiene espacios en el medio
- el elemento no empieza con una comilla

Esto ocurre para evitar problemas de interpolación del shell cuando hay espacios en blanco en los nombres de directorio.

Este método utiliza "commands_quote" para determinar la comilla correcta. Si "commands_quote" es un espacio, no se realizará ninguna citación.

si empieza y termina con el mismo carácter de comilla: déjalo como está

si no contiene espacios en blanco: déjalo como está

si contiene espacios en blanco, entonces

si contiene comillas: es mejor dejarlo como está

de lo contrario: cítalo con el tipo de comilla correcto para la máquina en la que estamos
