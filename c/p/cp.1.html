NOMBRE

cp - copiar archivos y directorios

SINOPSIS

cp [OPCIÓN]... [-T] FUENTE DEST
cp [OPCIÓN]... FUENTE... DIRECTORIO
cp [OPCIÓN]... -t DIRECTORIO FUENTE...

DESCRIPCIÓN

Copia FUENTE a DEST, o múltiples FUENTE(s) a DIRECTORIO.

Los argumentos obligatorios para las opciones largas son también obligatorios para las opciones cortas.

-a, --archive
igual que -dR --preserve=all
--attributes-only
no copiar los datos del archivo, solo los atributos
--backup[=CONTROL]
hacer una copia de seguridad de cada archivo de destino existente
-b
igual que --backup pero no acepta un argumento
--copy-contents
copiar el contenido de archivos especiales cuando sea recursivo
-d
igual que --no-dereference --preserve=links
--debug
explicar cómo se copia un archivo. Implica -v
-f, --force
si un archivo de destino existente no se puede abrir, elimínalo y vuelve a intentarlo (esta opción se ignora cuando la opción -n también se usa)
-i, --interactive
preguntar antes de sobrescribir (anula una opción -n previa)
-H
seguir los enlaces simbólicos de la línea de comandos en FUENTE
-l, --link
crear enlaces duros en lugar de copiar
-L, --dereference
seguir siempre los enlaces simbólicos en FUENTE
-n, --no-clobber
(obsoleto) omitir silenciosamente los archivos existentes. Ver también --update
-P, --no-dereference
nunca seguir los enlaces simbólicos en FUENTE
-p
igual que --preserve=mode,ownership,timestamps
--preserve[=ATTR_LIST]
preservar los atributos especificados
--no-preserve=ATTR_LIST
no preservar los atributos especificados
--parents
usar el nombre completo del archivo fuente bajo DIRECTORIO
-R, -r, --recursive
copiar directorios recursivamente
--reflink[=WHEN]
controlar copias clone/CoW. Ver abajo
--remove-destination
eliminar cada archivo de destino existente antes de intentar abrirlo (en contraste con --force)
--sparse=WHEN
controlar la creación de archivos dispersos. Ver abajo
--strip-trailing-slashes
eliminar las barras finales de cada argumento FUENTE
-s, --symbolic-link
crear enlaces simbólicos en lugar de copiar
-S, --suffix=SUFIJO
sobrescribir el sufijo de copia de seguridad habitual
-t, --target-directory=DIRECTORIO
copiar todos los argumentos FUENTE en DIRECTORIO
-T, --no-target-directory
tratar DEST como un archivo normal
--update[=UPDATE]
controlar qué archivos existentes se actualizan; UPDATE={all,none,none-fail,older(default)}
-u
equivalente a --update[=older]. Ver abajo
-v, --verbose
explicar lo que se está haciendo
--keep-directory-symlink
seguir los enlaces simbólicos existentes a directorios
-x, --one-file-system
permanecer en este sistema de archivos
-Z
establecer el contexto de seguridad SELinux del archivo de destino al tipo predeterminado
--context[=CTX]
igual que -Z, o si se especifica CTX, entonces establecer el contexto de seguridad SELinux o SMACK a CTX
--help
mostrar esta ayuda y salir
--version
mostrar información de versión y salir

ATTR_LIST es una lista de atributos separada por comas. Los atributos son 'mode' para permisos (incluyendo permisos ACL y xattr), 'ownership' para usuario y grupo, 'timestamps' para marcas de tiempo de archivo, 'links' para enlaces duros, 'context' para contexto de seguridad, 'xattr' para atributos extendidos, y 'all' para todos los atributos.

Por defecto, los archivos FUENTE dispersos se detectan mediante una heurística rudimentaria y el archivo DEST correspondiente también se hace disperso. Ese es el comportamiento seleccionado por --sparse=auto. Especificar --sparse=always para crear un archivo DEST disperso siempre que el archivo FUENTE contenga una secuencia suficientemente larga de bytes cero. Usar --sparse=never para inhibir la creación de archivos dispersos.

UPDATE controla qué archivos existentes en el destino se reemplazan. 'all' es la operación predeterminada cuando no se especifica una opción --update, y da como resultado el reemplazo de todos los archivos existentes en el destino. 'none' es como la opción --no-clobber, en el sentido de que no se reemplaza ningún archivo en el destino, y los archivos omitidos no provocan un error. 'none-fail' también asegura que no se reemplacen archivos en el destino, pero cualquier archivo omitido se diagnostica y provoca un error. 'older' es la operación predeterminada cuando se especifica --update, y da como resultado el reemplazo de archivos si son más antiguos que el archivo fuente correspondiente.

Por defecto o con --reflink=auto, cp intentará una copia ligera, donde los bloques de datos solo se copian cuando se modifican, recurriendo a una copia estándar si esto no es posible. Con --reflink[=always] cp fallará si CoW no es compatible, mientras que --reflink=never asegura que se realiza una copia estándar.

El sufijo de copia de seguridad es '~', a menos que se establezca con --suffix o SIMPLE_BACKUP_SUFFIX. El método de control de versiones se puede seleccionar a través de la opción --backup o mediante la variable de entorno VERSION_CONTROL. Aquí están los valores:

none, off
nunca hacer copias de seguridad (incluso si se proporciona --backup)
numbered, t
hacer copias de seguridad numeradas
existing, e
hacer copias de seguridad de todos los archivos excepto los que ya existen
simple, never
nunca hacer copias de seguridad (incluso si --backup se proporciona)
cp(1) - Arch Linux man pages

NAME

cp - copiar archivos y directorios

SYNOPSIS

cp [OPCIÓN]... ORIGEN DESTINO

cp [OPCIÓN]... ORIGEN... DIRECTORIO

DESCRIPTION

Copiar archivos y directorios.

Los argumentos obligatorios para las opciones largas son también obligatorios para las opciones cortas.

Este manual está diseñado para ser compatible con la documentación original de GNU coreutils. Sin embargo, las opciones y el comportamiento pueden variar según la versión específica de GNU coreutils instalada en su sistema.

--backup[=CONTROL]
hacer una copia de seguridad de cada archivo DEST antes de sobrescribirlo
--copy-contents
copiar el contenido de los directorios en lugar de copiarlos
-d
equivalente a --no-dereference --preserve=links
--explicit-dirs
tratar los directorios de ORIGEN como archivos normales
-T
tratar DESTINO como un archivo normal
-p
equivalente a --preserve=mode,ownership,timestamps
--preserve[=ATTR-LIST]
preservar los atributos especificados en ATTR-LIST; por defecto es mode,ownership,timestamps. ATTR-LIST es una lista separada por comas de los atributos.
-S, --suffix=SUFFIX
sobrescribir el sufijo de copia de seguridadSUFFIX; por defecto es ~
-u, --update
copiar solo cuando el archivo ORIGEN sea más reciente que el archivo DEST o cuando DEST no exista
-v, --verbose
explicar qué se está haciendo
--help
mostrar esta ayuda y salir
--version
mostrar información de versión y salir

Se pueden especificar los siguientes tipos de copia de seguridad: none, off, numbered, existing, simple.

existing,
numerado si existen copias de seguridad numeradas, simple en caso contrario
simple, never
siempre hacer copias de seguridad simples

Como caso especial, cp hace una copia de seguridad de ORIGEN cuando se dan las opciones de forzar y copia de seguridad y ORIGEN y DEST son el mismo nombre para un archivo existente y regular.
