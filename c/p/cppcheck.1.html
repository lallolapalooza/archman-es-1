DESCRIPCIÓ

N

Cppcheck es una herramienta de línea de comandos que intenta detectar errores que su compilador C/C++ no ve. Es versátil y puede verificar código no

estándar, incluyendo varias extensiones de compilador, código de ensamblaje en línea, etc. Su preprocesador interno puede manejar inclusiones, macros
y varios comandos de preprocesador. Aunque Cppcheck es altamente configurable, puede empezar a usarlo simplemente dándole una ruta al código fuente.

OPCIONE

S

Analiza los archivos C/C++ dados en busca de errores

comunes.

--check-confi

g
Verifica la configuración de Cppcheck. El análisis de código normal está deshabilitado por esta
opción.

--check-librar

y
Muestra mensajes de información cuando los archivos de biblioteca tienen información
incompleta.

-D<id

>
Por defecto, Cppcheck verifica todas las configuraciones. Use -D para limitar la verificación. Cuando se usa -D, la verificación se limita a la configuración dada. Ejemplo: -DDEBUG=1
-D__cplusplus

-U<id

>
Por defecto, Cppcheck verifica todas las configuraciones. Use '-U' para ocultar explícitamente ciertas rutas de código #ifdef <id> de la verificación. Ejemplo:
'-UDEBUG'

--disable=<id

>
Deshabilita verificaciones individuales. Consulte la documentación de --enable=<id> para más
detalles.

--enable=<id

>
Habilita verificaciones adicionales. Los identificadores disponibles son:

al

Habilita todas las verificaciones. Se recomienda usar --enable=all solo cuando se escanea todo el programa, porque esto habilita
unusedFunction.

warnin

Habilita mensajes de
advertencia

styl

e
Habilita todas las verificaciones de estilo de codificación. Se habilitan todos los mensajes con las severidades 'style', 'performance' y
'portability'.

performanc

e
Habilita mensajes de
rendimiento

portabilit

y
Habilita mensajes de
portabilidad

informatio

n
Habilita mensajes de
información

unusedFunctio

n
Verifica funciones no utilizadas. Se recomienda habilitar esto solo cuando se escanea todo el
programa

missingInclud

e
Advierte si faltan
inclusiones

Por defecto, ninguna de las verificaciones adicionales está habil

itada. Se pueden dar varios identificadores si los separa con com
as, por ejemplo: --enable=style,unusedFunction. Vea también --std

--error-exitcode=<n

>
Si se encuentran errores, se devuelve el entero <n> en lugar del 0 predeterminado. Se devuelve EXIT_FAILURE si los argumentos no son válidos o si no se proporcionan archivos de entrada. Tenga en cuenta que su sistema operativo puede modificar este valor, por ejemplo, 256 puede convertirse en
0.

--errorlis

t
Imprime una lista de todos los posibles mensajes de error en formato
XML.

--exitcode-suppressions=<file

>
Se usa cuando ciertos mensajes deben mostrarse pero no deben causar un código de salida distinto de
cero.

--file-list=<file

>
Especifica los archivos a verificar en un archivo de texto. Un nombre de archivo por línea. Cuando el archivo es -, la lista de archivos se leerá de la entrada
estándar.

--filesdi

r
Imprime el FILESDIR
integrado.

-f, --forc

e
Fuerza la verificación de archivos que tienen muchas configuraciones. Se imprime un error si se encuentra un archivo así, por lo que no hay razón para usar esto por defecto. Si se usa junto con --max-configs=, la última opción es la que tiene
efecto.

--fsigned-cha

r
Trata el tipo char como con signo. Esto anula las opciones --platform anteriores y es anulado por las
siguientes.

--funsigned-cha

r
Trata el tipo char como sin signo. Esto anula las opciones --platform anteriores y es anulado por las
siguientes.

-h, --hel

p
Imprime el texto de
ayuda.

-I

<dir>
Da la ruta para buscar archivos de inclusión. Dé varios parámetros -I para dar varias rutas. La primera ruta dada se busca primero para los archivos de cabecera contenidos. Si las rutas son relativas a los archivos fuente, esto no es
necesario.

--includes-file=<file

>
Especifica las rutas de directorio para buscar archivos de cabecera incluidos en un archivo de texto. Agregue una ruta de inclusión por línea. La primera ruta dada se busca primero para los archivos de cabecera contenidos. Si las rutas son relativas a los archivos fuente, esto no es
necesario.

--config-exclude=<dir

>
Ruta (prefijo) que se excluirá de la verificación de configuración. Las configuraciones de preprocesador definidas en cabeceras (pero no en fuentes) que coincidan con el prefijo no se considerarán para la evaluación de alternativas de
configuración.

--config-exclude-file=<file

>
Un archivo que contiene una lista de exclusiones de
configuración.

--include=<file

>
Fuerza la inclusión de un archivo antes del archivo verificado. Puede usarse, por ejemplo, al verificar el kernel de Linux, donde autoconf.h necesita incluirse para cada archivo compilado. Funciona de la misma manera que la opción -include de
GCC.

-i

<dir>
Da la ruta a ignorar. Dé varios parámetros -i para ignorar varias rutas. Dé el nombre del directorio o el nombre del archivo con la ruta como parámetro. El nombre del directorio se compara con todas las partes de la
ruta.

--inconclusiv

e
Permite que Cppcheck informe incluso cuando el análisis es inconcluyente. Hay falsos positivos con esta opción. Cada resultado debe investigarse cuidadosamente antes de saber si es bueno o
malo.

--inline-supp

r
Habilita supresiones en línea. Úselas colocando comentarios en la forma: // cppcheck-suppress memleak antes de la línea a
suprimir.

-j

<jobs>
Inicia <jobs> hilos para hacer el trabajo de
verificación.

-l

<load>
Especifica que no se deben iniciar nuevos hilos si hay otros hilos en ejecución y la carga promedio es al menos <load> (ignorado en sistemas no tipo
UNIX)

--language=<language

>
Fuerza a cppcheck a verificar todos los archivos como el lenguaje dado. Los valores válidos son: c,
c++

>
Usa la configuración de
biblioteca.

--max-configs=<limit

>
Número máximo de configuraciones a verificar en un archivo antes de omitirlo. El valor predeterminado es 12. Si se usa junto con --force, la última opción es la que tiene
efecto.

--max-ctu-depth=<limit

>
Profundidad máxima en el análisis de todo el programa. El valor predeterminado es
2.

-rp, -rp=<rutas>, --rutas-relativas;, --rutas-relativas=<rutas

>
Usar rutas relativas en la salida. Cuando se proporciona, <rutas> se usan como base. Puede separar múltiples rutas con ';'. De lo contrario, se usa la ruta donde se buscan los archivos fuente. Por ejemplo, si el valor proporcionado es test, al comprobar test/test.cpp, la ruta en la salida será test.cpp en lugar de test/test.cpp. La función utiliza comparación de cadenas para crear rutas relativas, por lo que usar, por ejemplo, ~ para la carpeta de inicio no funciona. Actualmente solo es posible aplicar las rutas base a archivos que están en un nivel más bajo en el árbol de
directorios.

--suppress=<especificación

>
Suprimir una advertencia específica. El formato de <especificación> es: [id de error]:[nombre de archivo]:[línea]. El [nombre de archivo] y la [línea] son opcionales.
