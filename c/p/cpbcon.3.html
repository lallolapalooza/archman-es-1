Documentación de Función/Subrutina

subroutine cpbcon (character uplo, integer n, integer kd, complex, dimension( ldab, * ) ab, integer ldab, real anorm, real rcond, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CPBCON

Propósito:

!>
!> CPBCON estima el recíproco del número de condición (en la norma 1)
!> de una matriz de banda hermitiana compleja definida positiva utilizando
!> la factorización de Cholesky A = U**H*U o A = L*L**H calculada por
!> CPBTRF.
!>
!> Se obtiene una estimación de norm(inv(A)), y el recíproco del
!> número de condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Factor triangular superior almacenado en AB;
!>          = 'L':  Factor triangular inferior almacenado en AB.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es array COMPLEX, dimension (LDAB,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H de la matriz de banda A, almacenado en las
!>          primeras KD+1 filas del array. La j-ésima columna de U o L
!>          se almacena en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO ='U', AB(kd+1+i-j,j) = U(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO ='L', AB(1+i-j,j)    = L(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

ANORM

!>          ANORM es REAL
!>          La norma 1 (o norma infinito) de la matriz de banda hermitiana A.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es array COMPLEX, dimension (2*N)
!>

RWORK

!>          RWORK es array REAL, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tuvo un valor ilegal
!>
