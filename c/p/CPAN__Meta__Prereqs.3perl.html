CPAN::Meta::Prereqs(3perl) Guía de referencia para programadores de Perl CPAN::Meta::Prereqs(3perl)

NOMBRE

CPAN::Meta::Prereqs - un conjunto de requisitos previos de distribución por fase y tipo

VERSIÓN

version 2.150010

DESCRIPCIÓN

Un objeto CPAN::Meta::Prereqs representa los requisitos previos para una distribución de CPAN o una de sus características opcionales. Cada conjunto de requisitos previos se organiza por fase y tipo, como se describe en CPAN::Meta::Prereqs.

MÉTODOS

new

my $prereq = CPAN::Meta::Prereqs->new( \%prereq_spec );

Este método devuelve un nuevo conjunto de Prereqs. La entrada debe parecerse al contenido del campo "prereqs" descrito en CPAN::Meta::Spec, es decir, algo más o menos así:

my $prereq = CPAN::Meta::Prereqs->new({
  runtime => {
    requires => {
      'Some::Module' => '1.234',
      ...,
    },
    ...,
  },
  ...,
});

También puede construir un conjunto vacío de requisitos previos con:

my $prereqs = CPAN::Meta::Prereqs->new;

Este conjunto vacío de requisitos previos es útil para acumular nuevos requisitos previos antes de finalmente volcar todo el conjunto en una estructura o cadena.

requirements_for

my $requirements = $prereqs->requirements_for( $phase, $type );

Este método devuelve un objeto CPAN::Meta::Requirements para la combinación de fase/tipo dada. Si no hay requisitos previos registrados para esa combinación, se devolverá un nuevo objeto CPAN::Meta::Requirements, y se podrá agregar según sea necesario.

Si $phase o $type no están definidos o son inválidos de otro modo, se generará una excepción.

phases

my @phases = $prereqs->phases;

Este método devuelve la lista de todas las fases actualmente pobladas en el objeto prereqs, adecuadas para iterar.

types_in

my @runtime_types = $prereqs->types_in('runtime');

Este método devuelve la lista de todos los tipos actualmente poblados en el objeto prereqs para la fase proporcionada, adecuados para iterar.

with_merged_prereqs

my $new_prereqs = $prereqs->with_merged_prereqs( $other_prereqs );
my $new_prereqs = $prereqs->with_merged_prereqs( \@other_prereqs );

Este método devuelve un nuevo objeto CPAN::Meta::Prereqs en el que todos los demás requisitos previos proporcionados se fusionan en el conjunto actual. Esto se proporciona principalmente para combinar los requisitos previos principales de una distribución con los requisitos previos de una de sus características opcionales.

El nuevo objeto prereqs no tiene vínculos con los originales, y alterarlo aún más no alterará los originales.

merged_requirements

my $new_reqs = $prereqs->merged_requirements( \@phases, \@types );
my $new_reqs = $prereqs->merged_requirements( \@phases );
my $new_reqs = $prereqs->merged_requirements();

Este método une todos los requisitos de varias fases y tipos en un nuevo objeto CPAN::Meta::Requirements. Si se omiten argumentos, se utilizan por defecto "runtime", "build" y "test" para las fases y "requires" y "recommends" para los tipos.

as_string_hash

Este método devuelve un hashref que contiene estructuras adecuadas para volcar en una estructura de datos distmeta. Está compuesto solo por hashes y cadenas; no habrá objetos Prereqs, CPAN::Meta::Requirements ni "version" dentro de él.

is_finalized

Este método devuelve verdadero si el conjunto de requisitos previos ha sido marcado como "finalizado" y no puede ser alterado.

finalize

Llamar a "finalize" en un objeto Prereqs lo cerrará para futuras modificaciones. Intentar hacer cualquier cambio que realmente altere los requisitos previos resultará en una excepción.

clone

my $cloned_prereqs = $prereqs->clone;

Este método devuelve un objeto Prereqs que es idéntico al objeto original, pero que puede ser alterado sin afectar al objeto original. La finalización no sobrevive a la clonación, lo que significa que puede clonar un conjunto de requisitos previos finalizados y luego modificar la copia.
