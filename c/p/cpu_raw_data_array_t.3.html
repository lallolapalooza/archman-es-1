Descripción detallada

Contiene una matriz de datos de CPUID en bruto.

Esto contiene un cpu_raw_data_t por cada CPU lógica.

Nota

Existe un límite estricto para la matriz en bruto: está limitado por el tipo logical_cpu_t. En otras palabras, el límite es de 65536 CPUs lógicas en el sistema.

bool cpu_raw_data_array_t::con_afinidad

Indica si raw se obtuvo utilizando la afinidad de la CPU. Si es falso, raw contiene un único dato de una copia antigua (versiones 0.5.1 y anteriores). Si es verdadero, raw contiene datos de una nueva copia (versiones 0.6.0 y posteriores). Si es verdadero y si num_raw es 1, indica que solo se detectó un núcleo lógico en el sistema.
