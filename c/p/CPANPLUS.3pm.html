CPANPLUS(3) Documentación de Perl aportada por el usuario CPANPLUS(3)

NOMBRE

CPANPLUS - API y acceso CLI a los mirrors de CPAN

SINOPSIS

### invocación estándar desde la línea de comandos
$ cpanp
$ cpanp -i Some::Module
$ perl -MCPANPLUS -eshell
$ perl -MCPANPLUS -e'fetch Some::Module'

DESCRIPCIÓN

La biblioteca "CPANPLUS" es una API para los "CPAN" mirrors y una colección de shells interactivos, programas de línea de comandos, etc., que utilizan esta API.

GUÍA DE LA DOCUMENTACIÓN

USO GENERAL

Este es el documento que está leyendo actualmente. Describe el uso básico y la información de fondo. Su principal propósito es ayudar al usuario que desea aprender a invocar CPANPLUS e instalar módulos desde la línea de comandos y guiarle hacia una lectura más detallada si es necesario.

REFERENCIA DE LA API

La API "CPANPLUS" está diseñada para permitirle interactuar programáticamente con los "CPAN" mirrors. La documentación en CPANPLUS::Backend le muestra cómo crear un objeto capaz de interactuar con esos mirrors, permitiéndole crear y recuperar objetos de módulos. CPANPLUS::Module le muestra cómo puede usar estos objetos de módulos para realizar acciones como instalar y probar.

El shell predeterminado, documentado en CPANPLUS::Shell::Default, también es scriptable. Puede usar su API para despachar llamadas desde su script al Shell de CPANPLUS.

HERRAMIENTAS DE LÍNEA DE COMANDOS

INICIAR UN SHELL INTERACTIVO

Puede iniciar un shell interactivo ejecutando cualquiera de los dos siguientes comandos:

$ cpanp
$ perl -MCPANPLUS -eshell

Todos los comandos disponibles se listan en el menú de ayuda del shell interactivo. Vea "cpanp -h" o CPANPLUS::Shell::Default para instrucciones sobre cómo usar el shell predeterminado.

ELEGIR UN SHELL

Al ejecutar "cpanp" sin argumentos, iniciará el shell especificado en su configuración, que por defecto es CPANPLUS::Shell::Default. Hay más shells disponibles. "CPANPLUS" incluye por sí mismo un shell de emulación llamado CPANPLUS::Shell::Classic que se ve y se siente igual que el viejo shell "CPAN.pm" .

Puede iniciar este shell escribiendo:

$ perl -MCPANPLUS -e'shell Classic'

Puede haber aún más shells disponibles desde "CPAN".

Tenga en cuenta que si ha cambiado su shell predeterminado en su configuración, se usará ese shell en su lugar. Si por alguna razón hubo un error con su shell especificado, se le dará el shell predeterminado.

CONSTRUIR PAQUETES

"cpan2dist" es una herramienta de línea de comandos para convertir cualquier distribución de "CPAN" en un paquete en el formato de su elección, como por ejemplo ".deb" o "FreeBSD ports".

Vea "cpan2dist -h" para detalles.

FUNCIONES

Para un acceso rápido a comandos comunes, puede usar este módulo, "CPANPLUS" en lugar de la API programática completa situada en "CPANPLUS::Backend". Este módulo ofrece las siguientes funciones:

$bool = install( Module::Name | /A/AU/AUTHOR/Module-Name-1.tgz )

Esta función requiere el nombre completo del módulo, que distingue mayúsculas de minúsculas. El nombre del módulo también puede proporcionarse como un nombre de archivo calificado completamente, que comienza con un /, relativo al directorio /authors/id en un mirror de CPAN.

Descargará, extraerá e instalará el módulo.

$where = fetch( Module::Name | /A/AU/AUTHOR/Module-Name-1.tgz )

Al igual que install, fetch necesita el nombre completo de un módulo o el nombre de archivo calificado completamente, y distingue mayúsculas de minúsculas.

Descargará el módulo especificado al directorio actual.

$where = get( Module::Name | /A/AU/AUTHOR/Module-Name-1.tgz )

Get se proporciona como un alias de fetch para compatibilidad con CPAN.pm.

shell()

Shell inicia el shell de CPAN predeterminado. También puede iniciar el shell usando el comando "cpanp" , que se instalará en su perl bin.
