NOMBRE

cpclean - Eliminar puntos de control incorrectos mediante métodos estadísticos

SINOPSIS

cpclean [opciones] input.pto

DESCRIPCIÓN

cpclean utiliza métodos estadísticos para eliminar puntos de control incorrectos.

El Paso 1 optimiza todos los pares de imágenes, calcula para cada par la media y la desviación estándar, y elimina todos los puntos de control con un error mayor que la media + n*sigma.

El Paso 2 optimiza el panorama completo, calcula la media y la desviación estándar para todos los puntos de control, y elimina todos los puntos de control con un error mayor que la media + n*sigma.

OPCIONES

--output|-o output.pto
Archivo PTO de salida de Hugin. Por defecto: '<nombre_archivo>_clean.pto'.
--max-distance|-n num
factor de distancia para la comprobación (por defecto: 2) (los puntos de control con un error > media + este factor*sigma serán eliminados)
--pairwise-checking|-p
realizar solo la comprobación de pares de imágenes (omitir el paso 2)
--whole-pano-checking|-w
realizar solo la comprobación del panorama completo (omitir el paso 1)
--dont-optimize|-s
omitir el paso de optimización al comprobar el panorama completo
--check-line-cp|-l
incluir también puntos de control de línea para el cálculo y filtrado en el paso 2
--verbose|-v
salida detallada durante la optimización
--help|-h
muestra la ayuda
