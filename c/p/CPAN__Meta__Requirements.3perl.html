add_string_requirement

$req->add_string_requirement('Library::Foo' => '>= 1.208, <= 2.206');
$req->add_string_requirement('Library::Foo' => v1.208);

Este método analiza la cadena pasada y añade el requisito apropiado para el módulo dado. Una versión puede ser un "v-string" de Perl. Entiende rangos de versiones como se describen en "Version Ranges" en CPAN::Meta::Spec. Por ejemplo:

1.3
>= 1.3
<= 1.3
== 1.3
!= 1.3
> 1.3
< 1.3
>= 1.3, != 1.5, <= 2.0
Un número de versión sin un operador es equivalente a especificar un mínimo (">="). Se permite espacio en blanco adicional.

from_string_hash

my $req = CPAN::Meta::Requirements->from_string_hash( \%hash );
my $req = CPAN::Meta::Requirements->from_string_hash( \%hash, \%opts );

Este es un constructor alternativo para un objeto CPAN::Meta::Requirements. Toma un hash de nombres de módulos y cadenas de requisitos de versión y devuelve un nuevo objeto CPAN::Meta::Requirements. Al igual que con add_string_requirement, una versión puede ser un "v-string" de Perl. Opcionalmente, puedes proporcionar una referencia a hash de opciones, exactamente igual que con el método "new".
