CPANPLUS::Module::Author::Fake(3) Documentación de Perl aportada por el usuario CPANPLUS::Module::Author::Fake(3)

NOMBRE

CPANPLUS::Module::Author::Fake - objeto de autor ficticio para CPANPLUS

SINOPSIS

mi $auth = CPANPLUS::Module::Author::Fake->new(
                autor  => 'Foo Bar',
                email   => 'luser@foo.com',
                cpanid  => 'FOO',
                _id     => $cpan->id,
            );

DESCRIPCIÓN

Una clase para crear objetos de autor ficticios, para uso de acceso directo internamente por CPANPLUS.

Hereda de "CPANPLUS::Module::Author".

MÉTODOS

new( _id => DÍGITO )

Crea un objeto de autor ficticio. Puede tomar las mismas opciones que "CPANPLUS::Module::Author->new", pero rellenará las predeterminadas si no se proporcionan. Solo la clave _id es obligatoria.
