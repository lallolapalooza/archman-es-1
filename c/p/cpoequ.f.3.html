Documentación de la función/subrutina

subrutina cpoequ (integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, integer info)

CPOEQU

Propósito:

!>
!> CPOEQU calcula factores de escala de filas y columnas destinados a
!> equilibrar una matriz Hermitiana definida positiva A y reducir su número
!> de condición (con respecto a la norma dos). S contiene los factores de
!> escala, S(i) = 1/sqrt(A(i,i)), elegidos de modo que la matriz escalada B
!> con elementos B(i,j) = S(i)*A(i,j)*S(j) tenga unos en la diagonal. Esta
!> elección de S sitúa el número de condición de B dentro de un factor N del
!> número de condición más pequeño posible sobre todos los escalados diagonales
!> posibles.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX, dimensión (LDA,N)
!>          La matriz Hermitiana definida positiva N-por-N cuyos factores de
!>          escala se van a calcular. Solo se referencian los elementos
!>          diagonales de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

S

!>          S es una matriz REAL, dimensión (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Si INFO = 0, S contiene la relación entre el S(i) más pequeño y
!>          el S(i) más grande. Si SCOND >= 0.1 y AMAX no es ni demasiado
!>          grande ni demasiado pequeño, no vale la pena escalar con S.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está muy
!>          cerca del desbordamiento o del subdesbordamiento, la matriz
!>          debe ser escalada.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal no es positivo.
!>
