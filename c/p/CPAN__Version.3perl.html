NOMBRE

CPAN::Version - funciones de utilidad para comparar versiones de CPAN

SINOPSIS

use CPAN::Version;
CPAN::Version->vgt("1.1","1.1.1");    # 1 porque 1.1 > 1.001001
CPAN::Version->vlt("1.1","1.1");      # 0 porque 1.1 no es < 1.1
CPAN::Version->vcmp("1.1","1.1.1");   # 1 porque el primero es mayor
CPAN::Version->vcmp("1.1.1","1.1");   # -1 porque el primero es menor
CPAN::Version->readable(v1.2.3);      # "v1.2.3"
CPAN::Version->vstring("v1.2.3");     # v1.2.3
CPAN::Version->float2vv(1.002003);    # "v1.2.3"

DESCRIPCIÓN

Este módulo intermedia entre una versión que perl ve en un paquete y la versión que se publica en el índice de CPAN.

Solo está escrito como un módulo de ayuda tanto para CPAN.pm como para CPANPLUS.pm.

Tal como está, es anterior a version.pm pero tiene el mismo objetivo: hacer que las cadenas de versión sean visibles y comparables.
