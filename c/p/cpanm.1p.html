NOMBRE

cpanm - obtener, desempaquetar, compilar e instalar módulos desde CPAN

SINOPSIS

cpanm Test::More                                 # instalar Test::More
cpanm MIYAGAWA/Plack-0.99_05.tar.gz              # ruta completa de la distribución
cpanm http://example.org/LDS/CGI.pm-3.20.tar.gz  # instalar desde una URL
cpanm ~/dists/MyCompany-Enterprise-1.00.tar.gz   # instalar desde un archivo local
cpanm --interactive Task::Kensho                 # Configurar interactivamente
cpanm .                                          # instalar desde un directorio local
cpanm --installdeps .                            # instalar todas las dependencias del directorio actual
cpanm -L extlib Plack                            # instalar Plack y todas las dependencias no nucleares en extlib
cpanm --mirror http://cpan.cpantesters.org/ DBI  # usar el espejo de sincronización rápida
cpanm --from https://cpan.metacpan.org/ Plack    # usar solo el espejo HTTPS

COMANDOS

(argumentos)
Los argumentos de la línea de comandos pueden ser un nombre de módulo, un archivo de distribución, una ruta de archivo local, una URL HTTP o una URL de repositorio git. Los siguientes comandos funcionarán como esperas. 
cpanm Plack
cpanm Plack/Request.pm
cpanm MIYAGAWA/Plack-1.0000.tar.gz
cpanm /ruta/a/Plack-1.0000.tar.gz
cpanm https://cpan.metacpan.org/authors/id/M/MI/MIYAGAWA/Plack-0.9990.tar.gz
cpanm git://github.com/plack/Plack.git

Además, puedes usar la notación utilizando "~" y "@" para especificar la versión de un módulo dado. "~" especifica el requisito de versión en el formato de CPAN::Meta::Spec, mientras que "@" fija la versión exacta, y es un atajo para "~"== VERSION"".

cpanm Plack~1.0000                 # 1.0000 o posterior
cpanm Plack~">= 1.0000, < 2.0000"  # la última de 1.xxxx
cpanm Plack@0.9990                 # versión específica. igual que Plack~"== 0.9990"

La consulta de versión que incluye una versión específica o un rango será enviada a MetaCPAN para buscar lanzamientos anteriores. La consulta buscará en los archivos de BackPAN por defecto, a menos que especifiques la opción "--dev" , en cuyo caso, las versiones archivadas serán filtradas.

Para un repositorio git, puedes especificar una rama, una etiqueta o un SHA de commit para compilar. El valor por defecto es "master"

cpanm git://github.com/plack/Plack.git@1.0000        # etiqueta
cpanm git://github.com/plack/Plack.git@devel         # rama
-i, --install
Instala los módulos. Este es el comportamiento por defecto y esta es solo una opción de compatibilidad para que funcione como cpan o cpanp.
--self-upgrade
Se actualiza a sí mismo. Es solo un alias para: 
cpanm App::cpanminus
--info
Muestra la información de la distribución en el "AUTHOR/Dist-Name-ver.tar.gz" formato en la salida estándar.
--installdeps
Instala las dependencias de la distribución de destino pero no la compila por sí misma. Útil si quieres probar la aplicación desde un repositorio controlado por versiones como git. 
cpanm --installdeps .
--look
Descarga y desempaqueta la distribución y luego abre el directorio con tu shell. Útil para explorar el código fuente o hacer pruebas manuales.
-h, --help
Muestra el mensaje de ayuda.
-V, --version
Muestra el número de versión.

OPCIONES

Puedes especificar las opciones por defecto en la variable de entorno "PERL_CPANM_OPT" .

-f, --force
Fuerza la instalación de módulos incluso si las pruebas fallaron.
-n, --notest
Omite las pruebas de los módulos. Usa esto solo cuando quieras ahorrar tiempo instalando cientos de distribuciones en el mismo perl y arquitectura que ya has probado para asegurarte de que compilan bien.

Por defecto es falso, y puedes decir "--no-notest" para anularlo cuando esté establecido en las opciones por defecto en "PERL_CPANM_OPT".

--test-only
Ejecuta solo las pruebas, e instala el módulo o distribución especificado. Útil si quieres verificar que los nuevos (o incluso viejos) lanzamientos pasan sus pruebas unitarias sin instalar el módulo.

Ten en cuenta que si especificas esta opción con un módulo o distribución que tiene dependencias, estas dependencias serán instaladas si actualmente no las tienes.

-S, --sudo
Cambia al usuario root con "sudo" cuando instales módulos. Usa esto si quieres instalar módulos en la ruta de inclusión del perl del sistema.

Por defecto es falso, y puedes decir "--no-sudo" para anularlo cuando esté establecido en las opciones por defecto en "PERL_CPANM_OPT".

-v, --verbose
Hace que la salida sea detallada. También habilita la configuración interactiva. (Ver --interactive)
-q, --quiet
Hace que la salida sea aún más silenciosa que la predeterminada. Solo muestra las dependencias exitosas/fallidas en la salida.
-l, --local-lib
Establece la ruta compatible con local::lib para instalar módulos. No necesitas establecer esto si ya has configurado las variables de entorno del shell usando local::lib, pero esto también puede usarse para anularlo.
-L, --local-lib-contained
Igual que "--local-lib" pero con --self-contained establecido. Todas las dependencias no nucleares serán instaladas incluso si ya están instaladas.

Por ejemplo,

cpanm -L extlib Plack

instalaría Plack y todas sus dependencias no nucleares en el directorio "extlib", que puede ser cargado desde tu aplicación con:

use local::lib '/ruta/a/extlib';

Ten en cuenta que esta opción NO funciona de manera fiable con instalaciones de perl proporcionadas por proveedores de sistemas operativos que eliminan los módulos estándar de perl, como RHEL, Fedora y CentOS, A MENOS QUE también instales paquetes que proporcionen todos los módulos que han sido eliminados. Para estos sistemas probablemente querrás instalar el "perl-core" meta-paquete que hace exactamente eso.

--self-contained
Al examinar las dependencias, asume que no hay módulos no nucleares instalados en el sistema. Útil si quieres agrupar las dependencias de la aplicación en un directorio para poder distribuirlas a otras máquinas.
--exclude-vendor
No incluir módulos instalados bajo las rutas 'vendor' al buscar módulos nucleares cuando el indicador "--self-contained" está activo. Esto restaura el comportamiento de antes de la versión 1.7023
--mirror
Especifica la URL base del espejo de CPAN a usar, como "http://cpan.cpantesters.org/" (puedes omitir la barra final). Puedes especificar múltiples URLs de espejo repitiendo la opción de la línea de comandos.

Puedes usar un directorio local que tenga una estructura de espejo de CPAN (creado por herramientas como OrePAN o Pinto) usando un esquema de URL especial "file://". Si la URL dada comienza con `/` (sin ningún esquema), se considera como un esquema de archivo también.

cpanm --mirror file:///ruta/al/espejo
cpanm --mirror ~/minicpan      # Porque el shell expande ~ a /home/usuario

Por defecto es "https://www.cpan.org/".

--mirror-only
Descarga el archivo de índice 02packages.details.txt.gz del espejo en lugar de consultar la Meta DB de CPAN. Esto{ "text": "también puede optar efectivamente por no enviar sus versiones locales de perl a servidores de bases de datos de backend como CPAN Meta DB y MetaCPAN.\n

Seleccione esta opción si está utilizando un espejo local de CPAN, como minicpan cuando está sin conexión, o su propio índice de CPAN (también conocido como darkpan).

\n
\n
--from, -M
\n
\n 
cpanm -M https://cpan.metacpan.org/\ncpanm --from https://cpan.metacpan.org/\n
\n

Utilice la URL del espejo dada y su índice como la única fuente para buscar y descargar módulos.

\n

Funciona de manera similar a "--mirror" y "--mirror-only" combinados, con una pequeña diferencia: a diferencia de "--mirror" que agrega la URL a la lista de espejos, "--from" (o "-M" para abreviar) utiliza la URL especificada como su única fuente para descargar el índice y los módulos. Esto hace que la opción anule siempre el espejo predeterminado, que podría haberse establecido a través de opciones globales, como la establecida por la variable de entorno "PERL_CPANM_OPT".

\n

Consejo: Puede ser útil si nombra estas opciones con sus alias de shell, como:

\n 
alias minicpanm='cpanm --from ~/minicpan'\nalias darkpan='cpanm --from http://mycompany.example.com/DPAN'\n
\n
\n
--mirror-index
\n
EXPERIMENTAL: Especifica la ruta del archivo a "02packages.details.txt" para el índice de búsqueda de módulos.
\n
--cpanmetadb
\n
EXPERIMENTAL: Especifica una URI alternativa para las búsquedas de índice de CPAN MetaDB.
\n
--metacpan
\n
Prefiere la API de MetaCPAN sobre CPAN MetaDB.
\n
--cpanfile
\n
EXPERIMENTAL: Especifica una ruta alternativa para que cpanfile la busque, cuando el comando "--installdeps" está en uso. Por defecto es "cpanfile".
\n
--prompt
\n
Pregunta cuando una prueba falla para que puedas omitir, forzar la instalación, reintentar o mirar en el shell para ver qué está saliendo mal. También pregunta cuando una de las dependencias falla si quieres continuar con la instalación.\n

Por defecto es falso, y puedes decir "--no-prompt" para anular si está establecido en las opciones predeterminadas en "PERL_CPANM_OPT".

\n
\n
--dev
\n
EXPERIMENTAL: busca también una versión de desarrollador más nueva. Por defecto es falso.
\n
--reinstall
\n
cpanm, cuando se le da un nombre de módulo en la línea de comandos (es decir, "cpanm Plack"), primero verifica la versión instalada localmente y la omite si ya está instalada. Esta opción hace que omita la verificación, por lo que:\n 
cpanm --reinstall Plack\n
\n

reinstalaría Plack incluso si su versión instalada localmente es la más reciente, o incluso más nueva (lo que sucedería si instala una versión de desarrollador desde repositorios de control de versiones).

\n

Por defecto es falso.

\n
\n
--interactive
\n
Hace que la configuración (como "Makefile.PL" y "Build.PL") sea interactiva, por lo que puedes responder preguntas en la distribución que requiere configuración personalizada o distribuciones de Task::.\n

Por defecto es falso, y puedes decir "--no-interactive" para anular cuando está establecido en las opciones predeterminadas en "PERL_CPANM_OPT".

\n
\n
--pp, --pureperl
\n
Prefiere la compilación de módulos Pure perl estableciendo "PUREPERL_ONLY=1" para MakeMaker y "--pureperl-only" para distribuciones basadas en Build.PL. Ten en cuenta que no todos los módulos CPAN soportan esta convención todavía.
\n
--with-recommends, --with-suggests
\n
EXPERIMENTAL: Instala dependencias declaradas como "recommends" y "suggests" respectivamente, según la especificación META. Cuando estas dependencias fallan al instalarse, cpanm continúa la instalación, ya que son solo recomendaciones. Permitir esto podría potencialmente crear una dependencia circular para algunos módulos en CPAN, cuando "recommends" agrega un módulo que a su vez "recommends" el módulo. También existe "--without-recommend" y "--without-suggests" para anular la decisión predeterminada tomada anteriormente en "PERL_CPANM_OPT". Por defecto es falso para ambos.
\n
--with-develop
\n
EXPERIMENTAL: Instala dependencias de la fase de desarrollo en archivos META o "cpanfile" cuando se usa con "--installdeps". Por defecto es falso.
\n
--with-configure
\n
EXPERIMENTAL: Instala dependencias de la fase de configuración en "cpanfile" cuando se usa con "--installdeps". Por defecto es falso.
\n
--with-feature, --without-feature, --with-all-features
\n
EXPERIMENTAL: Especifica la característica a habilitar, si un módulo soporta características opcionales según la especificación META 2.0.\n 
cpanm --with-feature=opt_csv Spreadsheet::Read\n
\n

Las características también se pueden elegir interactivamente cuando la opción "--interactive" está habilitada.

\n

"--with-all-features" habilita todas las características opcionales, y "--without-feature" puede seleccionar una característica para deshabilitar.

\n
\n
--configure-timeout, --build-timeout, --test-timeout
\n
Especifica la duración del tiempo de espera (en segundos) para esperar el proceso de configuración, compilación y prueba. Los valores predeterminados actuales son: 60 para configurar, 3600 para compilar y 1800 para probar.
\n
--configure-args, --build-args, --test-args, --install-args
\n
EXPERIMENTAL: Pasa argumentos para los comandos de configuración/compilación/prueba/instalación respectivamente, para que un módulo dado se instale.\n 
cpanm DBD::mysql --configure-args="--cflags=... --libs=..."\n
\n

El argumento solo está habilitado para el módulo pasado como argumento de línea de comandos, no para las dependencias.

\n
\n
--scandeps
\n
OBSOLETO: Escanea las dependencias de los módulos dados y muestra el árbol en formato de texto. (Ver "--format" abajo para más opciones)\n

Dado que este comando no instala realmente ninguna distribución, será útil escribir:

\n 
cpanm --scandeps Catalyst::Runtime\n
\n

para asegurarte de qué módulos se instalarán.

\n

Este comando tiene en cuenta qué módulos ya tienes instalados en tu sistema. Si deseas ver qué módulos se instalarán en una instalación de perl limpia, podrías combinarlo con la opción "-L".

\n
\n
--format
\n
OBSOLETO: Determina el formato en el que se mostrará el árbol de dependencias escaneado. Las opciones disponibles son "tree", "json", "yaml" y "dists".
\n
\n
\n
\n
tree
\n
Muestra el árbol en formato de texto plano. Este es el valor predeterminado.
\n
json, yaml
\n
Produce el árbol en formato JSON o YAML. Los módulos JSON y YAML deben instalarse respectivamente. El árbol de salida se representa como una tupla recursiva de:\n 
[ distribution, dependencies ]\n
\n

y el contenedor es una matriz que contiene los nodos raíz. Ten en cuenta que puede haber múltiples nodos raíz, ya que puedes pasar varios módulos al comando "--scandeps".

\n
\n
dists
\n
"dists" es un formato de salida especial, donde imprime el nombre del archivo de distribución en el orden de profundidad primero después de la resolución de dependencias, como:\n 
GAAS/MIME-Base64-3.13.tar.gz\nGAAS/URI-1.58.tar.gz\nPETDANCE/HTML-Tagset-3.20.tar.gz\nGAAS/HTML-Parser-3.68.tar.gz\nGAAS/libwww-perl-5.837.tar.gz\n
\n

lo que significa que puedes instalar estas distribuciones en este orden sin dependencias adicionales. Cuando se combina con la opción "-L", será útil para reproducir instalaciones en otras máquinas.

\n
\n
\n
\n
\n
--save-dists
\n
Especifica la ruta del directorio opcional para copiar los archivos tar descargados en la estructura de directorios compatible con el espejo de CPAN, es decir,
authors/id/A/AU/AUTHORS/Foo-Bar-version.tar.gz\n

Si el archivo tar de la distribución no provino de CPAN, por ejemplo, de un archivo local o de GitHub, se guardará en
vendor/Foo-Bar-version.tar.gz.

\n
\n
--uninst-shadows
\n
Desinstala los archivos sombra de la distribución que estás instalando. Esto elimina la confusión si estás intentando instalar módulos centrales (doble vida) de CPAN contra perl 5.10 o anterior, o módulos que solían basarse en XS pero cambiaron a pure perl en alguna versión.\n

Si ejecutas cpanm como root y usas "INSTALL_BASE" o equivalente para especificar una ruta de instalación personalizada, DEBES deshabilitar esta opción para no desinstalar accidentalmente módulos de doble vida de la ruta de inclusión principal.

\n

Por defecto es verdadero si tu versión de perl es menor que 5.12, y puedes deshabilitarlo con "--no-uninst-shadows".

\n

NAME

cpanm - Perl module installer

SYNOPSIS

cpanm [OPTIONS] MODULE ...
cpanm --uninstall [OPTIONS] MODULE ...
cpanm --version
cpanm --help

COMMANDS

-i, --install
Installs modules. This is the default command, so you can omit it.

Example:

cpanm Path::Class
-U, --uninstall
Uninstalls modules. See the --uninstall, -U option.

Example:

cpanm -U Path::Class

OPTIONS

-l, --local-lib DIR
Installs modules into DIR. This is useful when you don't have root access to install modules globally. It's equivalent to setting the PERL5LIB environment variable to DIR/lib/perl5 and installing executables into DIR/bin.
-L, --local-lib-contained DIR
Installs modules into DIR. Unlike --local-lib, this option does not assume the structure of PERL5LIB. It installs modules into DIR/lib/perl5 and executables into DIR/bin. This is useful when you want to bundle modules with your application.
-S, --setup-local-lib
Sets up a local::lib environment for the current shell. It prints out environment variables to be evaluated. You can execute the output like this:
eval $(cpanm -S)
Or to specify a directory: 
eval $(cpanm -S --local-lib-contained=~/perl5)
-m, --mirror URL
Uses the specified mirror URL for downloading modules. You can specify multiple mirrors by repeating the option.
-M, --mirror-only
Uses only the specified mirror URLs and disables the default mirror list. This is useful when you want to use only a specific set of mirrors.
-a, --auto-install
Automatically installs prerequisites if they are not found. This is the default behavior.
-q, --quiet
Suppresses most output. Use it when you want to run cpanm in a quiet manner.
-v, --verbose
Enables verbose output. Use it for debugging purposes.
-f, --force
Forces installation even if the module is already installed or if there are errors. Use with caution.
-n, --notest
Skips running tests for installed modules. This can speed up installation but might lead to issues if the tests fail.
-r, --recursive
Recursively installs dependencies. This is the default behavior.
-s, --show-build-log
Shows the build log even if the installation is successful. Useful for inspecting the build process.
-e, --edit
Opens the module's build directory in your editor. Useful for debugging build issues.
--uninstallation
For Perl versions 5.12 and newer, this option is deprecated. The default for Perl newer than 5.12, since with 5.12 @INC contains site_perl directory before the perl core library path, and uninstalling shadows is not necessary anymore and does more harm by deleting files from the core library path.

--uninstall, -U
Uninstalls a module from the library path. It finds a packlist for given modules, and removes all the files included in the same distribution.

If you enable local::lib, it only removes files from the local::lib directory.

If you try to uninstall a module in "perl" directory (i.e. core module), an error will be thrown.

A dialog will be prompted to confirm the files to be deleted. If you pass "-f" option as well, the dialog will be skipped and uninstallation will be forced.

--cascade-search
EXPERIMENTAL: Specifies whether to cascade search when you specify multiple mirrors and a mirror doesn't have a module or has a lower version of the module than requested. Defaults to false.
--skip-installed
Specifies whether a module given in the command line is skipped if its latest version is already installed. Defaults to true.

NOTE: The "PERL5LIB" environment variable have to be correctly set for this to work with modules installed using local::lib, unless you always use the "-l" option.

--skip-satisfied
EXPERIMENTAL: Specifies whether a module (and version) given in the command line is skipped if it's already installed.

If you run:

cpanm --skip-satisfied CGI DBI~1.2

cpanm won't install them if you already have CGI (for whatever versions) or have DBI with version higher than 1.2. It is similar to "--skip-installed" but while "--skip-installed" checks if the latest version of CPAN is installed, "--skip-satisfied" checks if a requested version (or not, which means any version) is installed.

Defaults to false.

--verify
Verify the integrity of distribution files retrieved from CPAN using CHECKSUMS file, and SIGNATURES file (if found in the distribution). Defaults to false.

Using this option does not verify the integrity of the CHECKSUMS file, and it's unsafe to rely on this option if you're using a CPAN mirror that you do not trust.

--report-perl-version
Whether it reports the locally installed perl version to the various web server as part of User-Agent. Defaults to true unless CI related environment variables such as "TRAVIS", "CI" or "AUTOMATED_TESTING" is enabled. You can disable it by using "--no-report-perl-version".
--auto-cleanup
Specifies the number of days in which cpanm's work directories expire. Defaults to 7, which means old work directories will be cleaned up in one week.

You can set the value to 0 to make cpan never cleanup those directories.

--man-pages
Generates man pages for executables (man1) and libraries (man3).

Defaults to true (man pages generated) unless "-L|--local-lib-contained" option is supplied in which case it's set to false. You can disable it with "--no-man-pages".

--lwp
Uses LWP module to download stuff over HTTP. Defaults to true, and you can say "--no-lwp" to disable using LWP, when you want to upgrade LWP from CPAN on some broken perl systems.
--wget
Uses GNU Wget (if available) to download stuff. Defaults to true, and you can say "--no-wget" to disable using Wget (versions of Wget older than 1.9 don't support the "--retry-connrefused" option used by cpanm).
--curl
Uses cURL (if available) to download stuff. Defaults to true, and you can say "--no-curl" to disable using cURL.

Normally with "--lwp", "--wget" and "--curl" options set to true (which is the default) cpanm tries LWP, Wget, cURL and HTTP::Tiny (in that order) and uses the first one available.

ENVIRONMENT VARIABLES

PERL_CPANM_HOME
The directory cpanm should use to store downloads and build and test modules. Defaults to the ".cpanm" directory in your user's home directory.
PERL_CPANM_OPT
If set, adds a set of default options to every cpanm command. These options come first, and so are overridden by command-line options.
