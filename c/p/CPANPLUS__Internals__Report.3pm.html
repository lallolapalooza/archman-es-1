Paquete: perl-cpanplus

Licencias: PerlArtistic, GPL

CPANPLUS::Internals::Report(3) Documentación de Perl contribuida por el usuario CPANPLUS::Internals::Report(3)

NOMBRE

CPANPLUS::Internals::Report - internos para el envío de informes de pruebas

SINOPSIS

### habilitar el informe de pruebas
$cb->configure_object->set_conf( cpantest => 1 );
### establecer un host mx personalizado, normalmente no debería ser necesario
$cb->configure_object->set_conf( cpantest_mx => 'smtp.example.com' );

DESCRIPCIÓN

Este módulo proporciona toda la funcionalidad para enviar informes de pruebas a "http://testers.cpan.org" utilizando el módulo "Test::Reporter".

Todos los métodos se llamarán automáticamente si tienes "CPANPLUS" configurado para habilitar el informe de pruebas (ver la "SINOPSIS").

MÉTODOS

$bool = $cb->_have_query_report_modules

Esta función comprueba si todos los módulos requeridos están presentes para consultar informes. Devuelve verdadero y los carga si lo están, o devuelve falso en caso contrario.

$bool = $cb->_have_send_report_modules

Esta función comprueba si todos los módulos requeridos están presentes para enviar informes. Devuelve verdadero y los carga si lo están, o devuelve falso en caso contrario.

@lista = $cb->_query_report( módulo => $obj_módulo, [todas_las_versiones => BOOL, verboso => BOOL] )

Esta función consulta la base de datos de testers de CPAN en http://testers.cpan.org/ para obtener los resultados de pruebas de los objetos de módulo especificados, nombres de módulos o distribuciones.

El argumento opcional "todas_las_versiones" controla si se deben obtener todas las versiones de una distribución dada. Por defecto es falso (solo obtiene informes para la versión actual).

Devuelve una lista con las siguientes estructuras de datos (para la versión 0.042 de CPANPLUS) en caso de éxito, o falso en caso de fallo. El contenido de la estructura de datos depende de lo que devuelva http://testers.cpan.org, pero generalmente se ve así:

{
  'grade' => 'PASS',
  'dist' => 'CPANPLUS-0.042',
  'platform' => 'i686-pld-linux-thread-multi'
  'details' => 'http://nntp.x.perl.org/group/perl.cpan.testers/98316'
  ...
},
{
  'grade' => 'PASS',
  'dist' => 'CPANPLUS-0.042',
  'platform' => 'i686-linux-thread-multi'
  'details' => 'http://nntp.x.perl.org/group/perl.cpan.testers/99416'
  ...
},
{
  'grade' => 'FAIL',
  'dist' => 'CPANPLUS-0.042',
  'platform' => 'cygwin-multi-64int',
  'details' => 'http://nntp.x.perl.org/group/perl.cpan.testers/99371'
  ...
},
{
  'grade' => 'FAIL',
  'dist' => 'CPANPLUS-0.042',
  'platform' => 'i586-linux',
  'details' => 'http://nntp.x.perl.org/group/perl.cpan.testers/99396'
  ...
},

El estado de la prueba puede ser uno de los siguientes: DESCONOCIDO, PASO, FALLO o NA (no aplicable).

$bool = $cb->_send_report( module => $obj_módulo, buffer => $salida_make, fallido => BOOL, [guardar => BOOL, dirección => $email_a, verboso => BOOL, forzar => BOOL]);

Esta función envía un informe de testers a "cpan-testers@perl.org" para una distribución particular. Devuelve verdadero en caso de éxito y falso en caso de fallo.

Toma las siguientes opciones:

módulo
El objeto módulo de esta distribución particular
buffer
El búfer de salida del proceso 'make/make test'
fallido
Booleano que indica si 'make/make test' salió mal
guardar
Booleano que indica si el informe debe guardarse localmente en lugar de enviarse por correo. Si se proporciona, esta función devolverá la ubicación donde se guardó el informe, en lugar de un simple booleano 'TRUE'.

Por defecto es falso.

dirección
La dirección de correo electrónico a la que enviar el informe. Nunca deberías tener que anular esto, pero podría ser útil para fines de depuración.

Por defecto es "cpan-testers@perl.org".

verboso
Booleano que indica si se debe ser verboso o no.

Por defecto son tus ajustes de configuración

forzar
Booleano que indica si se debe forzar el envío, incluso si ya se ha alcanzado la cantidad máxima de informes de fallos, o si ya lo has enviado antes.

Por defecto son tus ajustes de configuración
