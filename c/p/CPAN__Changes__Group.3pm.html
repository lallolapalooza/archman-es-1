NOMBRE

CPAN::Changes::Group - Un grupo de entrada en un archivo de cambios de CPAN

SINOPSIS

my $group = CPAN::Changes::Group->new(
  name    => 'Un grupo de cambios',
  changes => [
    'Una entrada de cambio',
    'Otra entrada de cambio',
  ],
);

DESCRIPCIÓN

Representa un grupo de entradas de cambio en una versión del registro de cambios. Esta es una interfaz heredada para y su uso se desaconseja.

En segundo plano, esto funciona como un proxy para los objetos reales de CPAN::Changes::Entry.

ATRIBUTOS

nombre

El nombre del grupo de cambios.
