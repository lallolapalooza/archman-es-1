DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine cposvxx (character fact, character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, character equed, real, dimension( * ) s, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CPOSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!>    CPOSVXX utiliza la factorización de Cholesky A = U**T*U o A = L*L**T
!>    para calcular la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B, donde A es una matriz Hermitiana positiva definida de N x N
!>    y X y B son matrices de N x NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normativos como de componente máxima. CPOSVXX devolverá una solución con un error garantizado pequeño (O(eps) donde eps es la precisión de la máquina de trabajo) a menos que la matriz esté muy mal condicionada, en cuyo caso se devuelve una advertencia. También se calculan y devuelven los números de condición relevantes.
!>
!>    CPOSVXX acepta factorizaciones y factores de ecualización proporcionados por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada anterior a CPOSVXX también producirá una solución con errores O(eps) o advertencias, pero no podemos afirmar eso para factorizaciones y factores de ecualización proporcionados por el usuario en general si difieren de lo que CPOSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para ecualizar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se ecualizará o no depende de la escala de la matriz A,
!>    pero si se utiliza la ecualización, A se sobrescribe con diag(S)*A*diag(S)
!>    y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después de la ecualización si FACT = 'E') como
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular inferior.
!>
!>    3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina devuelve INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A (ver argumento RCOND). Si la recíproca del número de condición
!>    es menor que la precisión de la máquina, la rutina aún continúa para resolver
!>    para X y calcular los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina utilizará refinamiento iterativo para intentar obtener un error
!>    y límites de error pequeños. El refinamiento calcula el residual con
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó la ecualización, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de la
!>    ecualización.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0, lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada, y si no, si la matriz A debe ser
!>     ecualizada antes de ser factorizada.
!>       = 'F':  En la entrada, AF contiene la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               ecualizada con factores de escala dados por S.
!>               A y AF no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se ecualizará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>     En la entrada, la matriz Hermitiana A, excepto si FACT = 'F' y EQUED =
!>     'Y', entonces A debe contener la matriz ecualizada
!>     diag(S)*A*diag(S).  Si UPLO = 'U', la parte triangular superior
!>     de N x N de A contiene la parte triangular superior de
!>     la matriz A, y la parte estrictamente triangular inferior de A no
!>     se referencia. Si UPLO = 'L', la parte triangular inferior
!>     de N x N de A contiene la parte triangular inferior de la matriz A, y
!>     la parte estrictamente triangular superior de A no se referencia.
!>     A no se modifica si FACT = 'F' o 'N', o si FACT = 'E' y EQUED =
!>     'N' a la salida.
!>
!>     A la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX, de dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, en el mismo formato de almacenamiento
!>     que A. Si EQUED .ne. 'N', entonces AF es la forma factorizada
!>     de la matriz ecualizada diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y a la salida
!>     devuelve el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T de la matriz original
!>     A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y a la salida
!>     devuelve el factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T de la matriz ecualizada
!>     A (consulte la descripción de A para ver la forma de la
!>     matriz ecualizada).
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de ecualización que se realizó.
!>       = 'N':  Sin ecualización (siempre cierto si FACT
= 'N').
!>       = 'Y':  Ambas equilibraciones de fila y columna, es decir, A ha
!>               sido reemplazado por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario,
!>     es un argumento de salida.
!>

S

!>          S es un array REAL, de dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'Y', A se
!>     multiplica a la izquierda y a la derecha por diag(S). S es un
!>     argumento de entrada si FACT = 'F'; de lo contrario, S es un
!>     argumento de salida. Si FACT = 'F' y EQUED = 'Y', cada elemento
!>     de S debe ser positivo. Si S es de salida, cada elemento de S es
!>     una potencia de la base. Si S es de entrada, cada elemento de S
!>     debería ser una potencia de la base para garantizar una solución
!>     y estimaciones de error fiables. El escalado por potencias de la
!>     base no causa errores de redondeo a menos que el resultado sea
!>     subdesbordamiento o desbordamiento. Los errores de redondeo
!>     durante el escalado conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones
!>     de error que pueden no ser fiables.
!>

B

!>          B es un array COMPLEX, de dimensión (LDB,NRHS)
!>     En la entrada, la matriz B del lado derecho de n por NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe con diag(S)*B;
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz solución X de n por NRHS del sistema
!>     original de ecuaciones. Tenga en cuenta que A y B se modifican en
!>     la salida si EQUED .ne. 'N', y la solución del sistema
!>     equilibrado es inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición recíproca escalada. Esta es una estimación del número
!>     de condición de Skeel recíproco de la matriz A después del
!>     equilibrio (si se realizó). Si es menor que la precisión de la
!>     máquina (en particular, si es cero), la matriz es singular con
!>     precisión de trabajo. Tenga en cuenta que el error aún puede ser
!>     pequeño incluso si este número es muy pequeño y la matriz parece
!>     estar mal condicionada.
!>

RPVGRW

!>          RPVGRW es REAL
!>     Crecimiento recíproco de pivote. En la salida, esto contiene el
!>     factor de crecimiento recíproco de pivote norm(A)/norm(U). Se usa
!>     la norma . Si esto es mucho menor que 1, entonces la estabilidad
!>     de la factorización LU de la matriz A (equilibrada) podría ser
!>     mala. Esto también significa que la solución X, los números de
!>     condición estimados y los límites de error podrían no ser fiables.
!>     Si la factorización falla con 0<INFO<=N, entonces esto contiene el
!>     factor de crecimiento recíproco de pivote para las columnas INFO
!>     principales de A.
!>

BERR

!>          BERR es un array REAL, de dimensión (NRHS)
!>     Error relativo componente a componente. Este es el error relativo
!>     componente a componente de cada vector solución X(j) (es decir,
!>     el cambio relativo más pequeño en cualquier elemento de A o B que
!>     haga de X(j) una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componentwise). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array REAL, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes
!>     al error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error como se
!>     describe a continuación. Actualmente hay hasta tres piezas de
!>     información devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confía en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con seguridad dentro de un factor de 10 del error
!>              verdadero, siempre que la siguiente entrada sea mayor
!>              que el umbral sqrt(n) * slamch('Epsilon'). Este límite
!>              de error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco normwise estimado. Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf))
!>              para alguna matriz Z escalada apropiadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de
!>              la base de modo que todas las sumas de filas absolutas de
!>              Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array REAL, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes
!>     al error relativo componente a componente, que se define de la
!>     siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información
!>     de error como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada lado derecho. Si no se
!>     solicita precisión componente a componente (PARAMS(3) = 0.0),
!>     entonces ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces
!>     se devuelven como máximo las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confía en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con seguridad dentro de un factor de 10 del error
!>              verdadero, siempre que la siguiente entrada sea mayor
!>              que el umbral sqrt(n) * slamch('Epsilon'). Este límite
!>              de error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco componente a componente estimado. Comparado con
!>              el umbral sqrt(n) * slamch('Epsilon') para determinar si
!>              la estimación del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf))
!>              para alguna matriz Z escalada apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de A*diag(x)
!>              por una potencia de la base de modo que todas las sumas
!>              de filas absolutas de Z sean aproximadamente 1.
!>
!>     Ver Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS. Si es
!>     <= 0, el array PARAMS nunca se accede y se utilizan los valores
!>     predeterminados.
!>

PARAMS

!>          PARAMS es un array REAL, de dimensión NPARAMS
!>     Especifica los parámetros del algoritmo. Si una entrada es < 0.0,
!>     entonces esa entrada se rellenará con el valor predeterminado
!>     utilizado para ese parámetro. Solo se accede a las posiciones hasta
!>     NPARAMS; se utilizan valores predeterminados para los parámetros
!>     de mayor número.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar o no el refinamiento
!>            iterativo.
!>         Predeterminado: 1.0
!>            = 0.0: No se realiza refinamiento y no se calculan límites
!>                   de error.
!>            = 1.0: Utiliza el algoritmo de refinamiento de doble
!>                   precisión, posiblemente con cálculos de precisión
!>                   simple duplicados si el entorno de compilación no
!>                   soporta DOUBLE PRECISION.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de cálculos
!>            de residuo permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecido en 100 para permitir la convergencia
!>                   utilizando factorizaciones aproximadas o
!>                   factorizaciones distintas de LU. Si la factorización
!>                   utiliza una técnica distinta de la eliminación
!>                   gaussiana, las garantías en err_bnds_norm y
!>                   err_bnds_comp pueden ya no ser fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicador que determina si el
!>            código intentará encontrar una solución con un error relativo
!>            componente a componente pequeño en el algoritmo de doble
!>            precisión. Positivo es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia componente a
!>                         componente)
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL, de dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>       = 0: Salida exitosa. La solución de cada lado derecho está
!>         garantizada.

SUBROUTINE CPOSVXX( UPLO, N, NRHS, A, LDA, AFAC, LDAFAC, IPIV, B, LDB, X,
LDX, RCOND, SRCOND, SOLVE_TF, INFO )



CPOSVXX computes the solution to a complex symmetric
    positive definite system of linear equations


 A * X = B,



where A is an N-by-N complex symmetric positive definite matrix
    and X and B are N-by-NRHS matrices. This subroutine uses the factorization
    from CPOSVX.


This routine is called by CPOSVX


Arguments:




UPLO


CHARACTER*1.
    
Specifies whether the matrix A is upper or lower
        triangular.

    
On entry, UPLO = ‘U’: Upper triangle of A is
        stored and is used.

    
On entry, UPLO = ‘L’: Lower triangle of A is
        stored and is used.




N


INTEGER.
    
The order of the matrix A. N >= 0.




NRHS


INTEGER.
    
The number of right hand sides, i.e., the number of
        columns of the matrices B and X. NRHS >= 0.




A


COMPLEX*16 array, dimension (LDA,N).
    
On entry, the symmetric positive definite matrix A.
        The N-by-N symmetric matrix A is, if UPLO = 'U', stored and
        represented by the upper triangular band of A. If UPLO = 'L',
        the lower triangular band of A is stored and represented.




LDA


INTEGER.
    
The leading dimension of the array A. LDA >= max(1,N).




AFAC


COMPLEX*16 array, dimension (LDAFAC,N).
    
On entry, the factors L or U from the factorization of
        A as computed by CPOTRF, and information about the diagonal
        blocks from the block factorization of A.




LDAFAC


INTEGER.
    
The leading dimension of the array AFAC. LDAFAC
        >= max(1,N).




IPIV


INTEGER array, dimension (N).
    
Details of the block factorization and the pivot
        vector of CPOTRF. The pivot vector must have been computed by
        CPOTRF.




B


COMPLEX*16 array, dimension (LDB,NRHS).
    
On entry, the N-by-NRHS right hand side matrix B.




LDB


INTEGER.
    
The leading dimension of the array B. LDB >=
        max(1,N).




X


COMPLEX*16 array, dimension (LDX,NRHS).
    
On exit, if INFO = 0, the N-by-NRHS solution matrix
        X to the system of equations A*X = B.




LDX


INTEGER.
    
The leading dimension of the array X. LDX >=
        max(1,N).




RCOND


DOUBLE PRECISION.
    
On exit, an estimate of the reciprocal condition
        number of the matrix A. The matrix A is singular if RCOND is
        less than the machine epsilon.




SRCOND


DOUBLE PRECISION.
    
On exit, the reciprocal condition number of the matrix A,
        computed via CTRRS, using the scaled triangular systems.




SOLVE_TF


LOGICAL.
    
On entry, SOLVE_TF = .TRUE. means that the system is
        to be solved for all right-hand sides. SOLVE_TF = .FALSE. means
        that the system is not to be solved.




INFO


INTEGER.
    
On exit, INFO = 0: successful exit.
        < 0: if INFO = -i, the i-th argument had an internal
             problem when debugging.
        > 0: if INFO = i, the i-th argument had an internal
             problem when debugging.






Additional Information:


This routine is called by CPOSVX


The condition number is computed using CTRRS
