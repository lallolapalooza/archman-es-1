NOMBRE

CPAN::Meta::Merge - Fusión de fragmentos de metadatos de CPAN

VERSIÓN

versión 2.150010

SINOPSIS

my $merger = CPAN::Meta::Merge->new(default_version => "2");
my $meta = $merger->merge($base, @additional);

DESCRIPCIÓN

MÉTODOS

new

Esto crea un objeto CPAN::Meta::Merge. Toma un argumento nombrado obligatorio, "version", que declara la versión de la especificación de metadatos que se debe utilizar para la fusión. Opcionalmente, puede tomar un argumento "extra_mappings" que permite agregar funciones de fusión adicionales para elementos específicos.

El argumento "extra_mappings" toma una referencia de hash con el mismo tipo de estructura que se describe en CPAN::Meta::Spec, excepto que sus valores son una de las estrategias de fusión definidas o una referencia de código a una función de fusión.

my $merger = CPAN::Meta::Merge->new(
    default_version => '2',
    extra_mappings => {
        'optional_features' => \&custom_merge_function,
        'x_custom' => 'set_addition',
        'x_meta_meta' => {
            name => 'identical',
            tags => 'set_addition',
        }
    }
);

merge(@fragmentos)

Fusiona todos los @fragmentos juntos. Aceptará tanto objetos CPAN::Meta como referencias hash (posiblemente incompletas) de metadatos.

ESTRATEGIAS DE FUSIÓN

"merge" utiliza varias estrategias para combinar diferentes elementos de los objetos CPAN::Meta. Las siguientes estrategias se pueden usar con el argumento extra_mappings de "new":

identico
Los elementos deben ser idénticos
suma_conjunto
La unión de dos referencias de array 
[ a, b ] U [ a, c]  = [ a, b, c ]
mapa_unico
Los pares de clave-valor del hash de la derecha se fusionan en el hash de la izquierda. Las colisiones de claves solo se permiten si sus valores son los mismos. Esta función de fusión recursará en referencias hash anidadas siguiendo las mismas reglas de fusión.
improvisar
Esta estrategia de fusión intentará elegir la estrategia predefinida apropiada según el tipo de elemento. Las referencias de array intentarán usar la estrategia "suma_conjunto", las referencias de hash intentarán usar la estrategia "mapa_unico", y todo lo demás intentará la estrategia "identico".
