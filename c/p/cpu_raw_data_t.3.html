Descripción Detallada

Contiene solo los datos crudos de CPUID.

Esto contiene solo los datos básicos de la CPU, necesarios para realizar la identificación y el reconocimiento de características. Cada procesador debería ser identificable solo usando estos datos.

uint32_t cpu_raw_data_t::amd_fn8000001dh[MAX_AMDFN8000001DH_LEVEL][NUM_REGS]

cuando la CPU es AMD y soporta la hoja 8000001Dh (información de topología para la DC) esto almacena el resultado de CPUID con eax = 8000001Dh y ecx = 0, 1, 2...
