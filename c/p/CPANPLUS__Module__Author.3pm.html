CPANPLUS::Module::Author(3) Documentación de Perl contribuida por el usuario CPANPLUS::Module::Author(3)

NOMBRE

CPANPLUS::Module::Author - Objeto de autor de CPAN para CPANPLUS

SINOPSIS

my $author = CPANPLUS::Module::Author->new(
                author  => 'Jack Ashton',
                cpanid  => 'JACKASH',
                _id     => INTERNALS_OBJECT_ID,
            );
$author->cpanid;
$author->author;
$author->email;
@dists  = $author->distributions;
@mods   = $author->modules;
@accessors = CPANPLUS::Module::Author->accessors;

DESCRIPCIÓN

"CPANPLUS::Module::Author" crea objetos a partir de la información de los archivos fuente. Estos pueden ser utilizados para realizar consultas.

Estos objetos solo deben ser creados internamente. Para objetos "falsos", existe la clase "CPANPLUS::Module::Author::Fake".

ACCESORES

Un objeto de esta clase tiene los siguientes accesores:

author
Nombre del autor.
cpanid
El ID de CPAN del autor.
email
La dirección de correo electrónico del autor, que por defecto es '' si no se proporciona.
parent
El objeto "CPANPLUS::Internals::Object" que generó este objeto de módulo.

MÉTODOS

$auth = CPANPLUS::Module::Author->new( author => AUTHOR_NAME, cpanid => CPAN_ID, _id => INTERNALS_ID [, email => AUTHOR_EMAIL] )

Este método devuelve un objeto "CPANPLUS::Module::Author", basado en los parámetros dados.

Devuelve falso en caso de fallo.

@mod_objs = $auth->modules()

Devuelve una lista de objetos de módulo que este autor ha lanzado.

@dists = $auth->distributions()

Devuelve una lista de objetos de módulo que representan todas las distribuciones que este autor ha lanzado.

MÉTODOS DE CLASE

accessors ()

Devuelve una lista de todos los métodos accesores del objeto
