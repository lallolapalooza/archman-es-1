NOMBRE

CPAN::API::HOWTO - un libro de recetas para programar con CPAN.pm

RECETAS

Todas estas recetas asumen que has puesto "use CPAN" al principio de tu programa.

¿Qué distribución contiene un módulo particular?

my $distribution = CPAN::Shell->expand(
    "Module", "Data::UUID"
)->distribution()->pretty_id();

Esto devuelve una cadena de la forma "AUTHORID/TARBALL". Si quieres la ruta completa y el nombre de archivo de esta distribución en un espejo de CPAN, entonces es ".../authors/id/A/AU/AUTHORID/TARBALL".

¿Qué módulos contiene una distribución particular?

CPAN::Index->reload();
my @modules = CPAN::Shell->expand(
    "Distribution", "JHI/Graph-0.83.tar.gz"
)->containsmods();

También puedes referirte a una distribución en la forma A/AU/AUTHORID/TARBALL.
