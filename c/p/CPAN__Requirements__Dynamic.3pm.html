CPAN::Requirements::Dynamic(3) Documentación Perl aportada por el usuario CPAN::Requirements::Dynamic(3)

NOMBRE

CPAN::Requirements::Dynamic - Prerrequisitos dinámicos en archivos meta

VERSIÓN

versión 0.002

SINOPSIS

my $result = $dynamic->evaluate({
  expressions => [
    {
      condition => [ 'has_perl' => 'v5.20.0' ],
      prereqs => { Bar => "1.3" },
    },
    {
      condition => [ is_os => 'linux' ],
      prereqs => { Baz => "1.4" },
    },
    {
      condition => [ config_defined => 'usethreads' ],
      prereqs => { Quz => "1.5" },
    },
    {
      condition => [ and =>
        [ config_defined => 'usethreads' ],
        [ is_os => 'openbsd' ],
      ],
      prereqs => { Euz => "1.7" },
    },
    {
      condition => [ not => is_os_type => 'Unix'],
      error => 'OS unsupported',
    },
  ],
});

DESCRIPCIÓN

Este módulo implementa un formato para describir prerrequisitos dinámicos de una distribución.

MÉTODOS

new(%opciones)

Este constructor toma dos argumentos con nombre (opcionales pero recomendados)

  • config

    Este es un objeto ExtUtils::Config (compatible) para leer la configuración.

  • pureperl_only

    Este debería ser el valor de la bandera "pureperl-only" .

evaluate(%opciones)

Toma un hash con dos argumentos con nombre: "version" y "expressions". El primero es la versión del formato, que actualmente por defecto es 1. El segundo es una lista de hashes que pueden contener las siguientes claves:

  • condition

    La condición del requisito dinámico. Es un array con un nombre como primer valor y cero o más argumentos a continuación. La semántica se describe más abajo en "Condiciones"

  • prereqs

    Los prerrequisitos son un hash con módulos como claves y la versión requerida como valores (por ejemplo "{ Foo => '1.234' }").

  • phase

    La fase de los requisitos. Por defecto es 'runtime'. Otros valores válidos incluyen 'build' y 'test'.

  • relation

    La relación de los requisitos. Por defecto es 'requires', pero otros valores válidos incluyen 'recommends', 'suggests' y 'conflicts'.

  • error

    Morirá con este error si está establecido. Los dos mensajes "No support for OS" y "OS unsupported" tienen un significado especial para CPAN Testers y generalmente se recomiendan para situaciones que indican no un fallo de compilación sino una imposibilidad de compilar.

"condition" y una de "prereqs" o "error" son obligatorios.

evaluate_file($nombre_archivo)

Toma un nombre de archivo, que puede ser un archivo YAML o JSON, y lo evalúa.

Condiciones

can_run($comando)

Devuelve verdadero si un $comando puede ser ejecutado.

config_defined($variable)

Devuelve verdadero si una variable de configuración específica está definida.

has_env($variable)

Devuelve verdadero si la variable de entorno con el nombre en $variable es verdadera.

has_perl($versión)

Devuelve verdadero si la versión de perl satisface $versión. $versión se interpreta exactamente como en la especificación CPAN::Meta (por ejemplo 1.2 equivale a '>= 1.2').

is_extended

Devuelve verdadero si se solicita pruebas extendidas.

is_os(@sistemas)

Devuelve verdadero si el nombre del SO es igual a alguno de @sistemas.

is_os_type($tipo)

Devuelve verdadero si el tipo de SO es igual a $tipo. Los valores típicos de $tipo son 'Unix' o 'Windows'.

is_smoker

Devuelve verdadero cuando se ejecuta en un fumador (smoker).

has_env

Devuelve verdadero si la variable de entorno dada es verdadera.

want_xs

Devuelve verdadero si parece que hay un compilador disponible, y la opción "pureperl_only" no ha sido establecida.

not

Toma una expresión y niega su valor.

or

Toma una lista de referencias a arrays, cada una conteniendo una expresión de condición. Si al menos una de las condiciones es verdadera, esto también devolverá verdadero.

and

Toma una lista de referencias a arrays, cada una conteniendo una expresión de condición. Si todas las condiciones son verdaderas, esto también devolverá verdadero.
