CPUPOWER-FREQUENCY-SET(1) Manual de cpupower CPUPOWER-FREQUENCY-SET(1)

NOMBRE

cpupower-frequency-set - Una pequeña herramienta que permite modificar la configuración de cpufreq.

SINTAXIS

cpupower [ -c cpu ] frequency-set [opciones]

DESCRIPCIÓN

cpupower-frequency-set te permite modificar la configuración de cpufreq sin tener que escribir, por ejemplo, "/sys/devices/system/cpu/cpu0/cpufreq/scaling_set_speed" todo el tiempo.

OPCIONES

-d --min <FREQ>
nueva frecuencia mínima de CPU que el gobernador puede seleccionar.
-u --max <FREQ>
nueva frecuencia máxima de CPU que el gobernador puede seleccionar.
-g --governor <GOV>
nuevo gobernador cpufreq.
-f --freq <FREQ>
frecuencia específica a establecer. Requiere que el gobernador userspace esté disponible y cargado.
-r --related
modificar todas las CPUs relacionadas por hardware al mismo tiempo

OBSERVACIONES

Por defecto, los valores se aplican en todos los núcleos. Cómo modificar configuraciones de un solo núcleo se describe en la página del manual de cpupower(1) en la sección de la opción --cpu.

El parámetro -f FREQ, --freq FREQ no se puede combinar con ningún otro parámetro.

Las FRECuencias se pueden pasar en Hz, kHz (por defecto), MHz, GHz o THz añadiendo el sufijo de la unidad deseada al valor, sin ningún espacio (frecuencia en kHz =^ Hz * 0.001 =^ MHz * 1000 =^ GHz * 1000000).

En los kernels de Linux hasta 2.6.29, el parámetro -r o --related se ignora.

ARCHIVOS

/sys/devices/system/cpu/cpu*/cpufreq/  
/proc/cpufreq (obsoleto) 
/proc/sys/cpu/ (obsoleto)
