DESCRIPCIÓ

N

CPANPLUS::Internals::Source controla la actualización de los archivos fuente y el análisis de los mismos en árboles de módulos/autores utilizables para ser usados por "CPANPLUS"

.

Existen funciones para comprobar si los archivos fuente aún son "buenos para usar" así como para actualizarlos y luego

analizarlos.

El flujo es el

siguiente: 
$cb->_author_tree || $cb->_module_tree
    $cb->_check_trees
        $cb->__check_uptodate
            $cb->_update_source
        $cb->__update_custom_module_sources
            $cb->__update_custom_module_source
    $cb->_build_tree
s ### métodos del motor { $cb->_init_trees; $cb->_standard_trees_completed $cb->_custom_trees_completed } $cb->__create_author_tree ### métodos del motor
{ $cb->_add_author_object } $cb->__create_module_tree $cb->__create_dslip_tree ### métodos del motor { $cb->_add_module_object } $cb->__create_custom_module_entries $cb->_dslip_defs
