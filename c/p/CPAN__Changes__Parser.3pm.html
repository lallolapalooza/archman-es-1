CPAN::Changes::Parser(3) Documentación de Perl contribuida por el usuario CPAN::Changes::Parser(3)

NOMBRE

CPAN::Changes::Parser - Analiza un archivo de registro de cambios de CPAN

SINOPSIS

my $parser = CPAN::Changes::Parser->new(
  version_like => qr/\{\{\$NEXT\}\}/,
  version_prefix => qr/=head\d\s+/,
);
my $changelog = $parser->parse_file('Changes', ':utf8');
my $changelog = $parser->parse_string($content);

DESCRIPCIÓN

Analiza un archivo o cadena en un objeto CPAN::Changes. Se aceptan muchas formas de registro de cambios.

ATRIBUTOS

version_like

Una expresión regular para un token que se aceptará en lugar de un número de versión. Por ejemplo, esto podría configurarse en "qr/\{\{\$NEXT\}\}/" si el plugin [NextRelease] de Dist::Zilla está gestionando el archivo.

version_prefix

Una expresión regular para un prefijo que se comparará antes de un número de versión. "qr/=head\d\s+/" podría utilizarse si el registro de cambios está utilizando encabezados de Pod para los encabezados de lanzamiento.

MÉTODOS

parse_file

Analiza un archivo en un objeto CPAN::Changes. Opcionalmente, acepta una cadena de capas que se utilizarán al leer el archivo.

parse_string

Analiza una cadena en un objeto CPAN::Changes.
