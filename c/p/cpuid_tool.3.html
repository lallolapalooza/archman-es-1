NOMBRE

cpuid_tool - Interfaz de línea de comandos para libcpuid.

Fecha

2008-11-19

Autor

Veselin Georgiev

Este archivo proporciona una interfaz directa a libcpuid. Consulte la función usage() (o simplemente ejecute el programa con la opción `--help') para obtener una breve referencia de las opciones de línea de comandos.

Este archivo tiene varios propósitos:

1.
Cuando se inicia sin argumentos, el programa muestra los datos de la CPU en formato RAW y decodificado en archivos (`raw.txt' y `report.txt', respectivamente). Esta es una herramienta simple y directa para usuarios no desarrolladores, que puede proporcionar información de depuración sobre procesadores no reconocidos a los desarrolladores de libcpuid.
2.
Cuando se opera desde la terminal con la opción `--report', es una utilidad genérica de información de CPU.
3.
Puede usarse en scripts de shell, por ejemplo, para obtener el nombre de la CPU, tamaños de caché, características, con opciones de consulta como `--cache', `--brandstr', etc.
4.
Finalmente, sirve para auto-documentar la propia libcpuid :)
