NOMBRE

CPANPLUS::Shell::Classic - Emulación de CPAN.pm para CPANPLUS

DESCRIPCIÓN

El shell Classic está diseñado para proporcionar la sensación del shell de CPAN.pm utilizando CPANPLUS internamente.

Para obtener documentación detallada, consulte CPAN.
