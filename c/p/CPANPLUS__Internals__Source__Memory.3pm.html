NOMBRE

CPANPLUS::Internals::Source::Memory - Implementación en memoria

$cb->__memory_retrieve_source(name => $name, [path => $path, uptodate => BOOL, verbose => BOOL])

Este método recupera un árbol storable identificado por $name.

Toma los siguientes argumentos:

name
El nombre interno del archivo fuente a recuperar.
uptodate
Una bandera que indica si la caché de archivos está actualizada o no.
path
La ruta absoluta al directorio que contiene los archivos fuente.
verbose
Una bandera booleana que indica si se debe ser verboso o no.

Obtendrá información del archivo de configuración por defecto.

Devuelve un árbol en caso de éxito, falso en caso de fallo.

$cb->__memory_save_source([verbose => BOOL, path => $path])

Este método guarda todos los árboles analizados en formato storable si "Storable" está disponible.

Toma los siguientes argumentos:

path
La ruta absoluta al directorio que contiene los archivos fuente.
verbose
Una bandera booleana que indica si se debe ser verboso o no.

Obtendrá información del archivo de configuración por defecto.

Devuelve verdadero en caso de éxito, falso en caso de fallo.
