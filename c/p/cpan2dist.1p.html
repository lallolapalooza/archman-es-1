CPAN2DIST(1) cpan2dist - El creador de distribuciones CPANP
PCIÓN

Est

e

script creará dist

ribuciones de
módulos de "CPAN"

en el

formato

que especifique, incluyendo sus prerequisitos. Estos paquetes pueden luego instalarse usando el gestor de paquetes correspondiente para el formato. Nota, también puede hacer esto de forma interactiva desde el shell por

defecto,

"CPANPLUS::Shell::Default". Vea la documentación de "CPANPLUS::Dist", así como la documentación de su formato de elección para cualquier documentación específica del formato. USO Uso:

cpan2dist [--format FMT] [OPTS] Mod::N
ame [Mod::Name, ...] cpan2dist

[ 
--format FMT] [OPTS] --modulelist /tmp/mods.list
       cpan2dist [--format FMT] [OPTS] --archive /tmp/dist [/tmp/dist2]
   Creará una distribución de tipo FMT de los módulos
   especificados en la línea de comandos, y todos sus prerequisitos.
   También puede crear una distribución de tipo FMT desde un
   archivo local y todos sus prerequisitos.
Opciones:
### no toman argumento:
--help          Muestra este mensaje de ayuda
--install       Instala este paquete (y
cualquier

p 
rerequisito que haya construido)
                después de construirlo.
--skiptest      Omite las pruebas. Puede negarse usando --noskiptest
--force         Fuerza la operación. Puede negarse usando --noforce
--verbose       Ser detallado. Puede negarse usando --noverbose
--keepsource    Mantiene las fuentes después de construir la distribución. Puede
                negarse con --nokeepsource. Puede no ser soportado
                por todos los formatos
--makefile      Prefiere Makefile.PL sobre Build.PL. Puede negarse
                usando --nomakefile. Por defecto usa la configuración
--buildprereq   Construye paquetes de cualquier prerequisito, incluso si ya
                están actualizados en el sistema local. Puede negarse
                usando --nobuildprereq. Por defecto es falso.
--archive       Indica que todos los módulos listados son en realidad archivos
--flushcache    Actualiza la caché de CPANPLUS antes de comenzar cualquier operación
--defaults      Instruye a ExtUtils::MakeMaker y Module::Build para usar
                respuestas por defecto durante las llamadas a 'perl Makefile.PL' o 'perl
                Build.PL' donde sea posible
--edit-metafile Edita el archivo(s) meta de la distribución antes de que la distribución
                sea construida. Requiere un editor configurado.
### toman argumento:
--format      Formato del instalador a usar (por defecto usa la configuración)
--ban         Patrones de nombres de módulos a omitir durante la instalación,
              sin distinguir mayúsculas de minúsculas (afecta también a los prerequisitos)
              Puede darse varias veces
--banlist     Archivo que contiene patrones que podrían darse a --ban
              Se añaden a la lista de prohibidos construida por --ban
              Puede darse varias veces.
--ignore      Patrones de módulos a excluir de la lista de prerequisitos. Útil
              para cuando un prerequisito listado por un módulo de CPAN se resuelve
              de otra manera que desde su paquete de CPAN correspondiente
              (La coincidencia se hace tanto en el nombre del módulo, como en el nombre del
              paquete en el que está el módulo, sin distinguir mayúsculas de minúsculas)
--ignorelist  Archivo que contiene patrones que pueden darse a --ignore.
              Se añaden a la lista de prohibidos construida por --ignore.
              Puede darse varias veces.
--modulelist  Archivo que contiene una lista de módulos que deben ser construidos.
              Se añaden a la lista de módulos de la línea de comandos.
              Puede darse varias veces.
--logfile     Archivo para registrar toda la salida. Por defecto, toda la salida va
              a la consola.
--timeout     El tiempo permitido para construir una distribución antes de
              abortar. Esto es útil para terminar cualquier construcción que
              se cuelgue o sea interactiva a pesar de haberse dicho que no lo fuera.
              Por defecto 300 segundos. Para desactivarlo, puede
              ponerlo a 0.
--set-config  Cambia cualquier opción como se especifica en su configuración solo para
              esta invocación. Vea CPANPLUS::Config para una lista de
              opciones soportadas.
--set-program Cambia cualquier programa como se especifica en su configuración solo para
              esta invocación. Vea CPANPLUS::Config para una lista de
              programas soportados.
--dist-opts   Opciones arbitrarias pasadas a la rutina prepare()/create()
              del formato de instalador elegido. Por favor vea la
              documentación del instalador de su elección para
              las opciones que acepta.
### listas incorporadas
--default-banlist    Usa nuestra lista de prohibidos incorporada. Funciona igual que --ban
                     y --banlist, pero con listas preestablecidas. Vea la
                     sección "Listas Incorporadas" para detalles.
--default-ignorelist Usa nuestra lista de ignorados incorporada. Funciona igual que
                     --ignore y --ignorelist pero con listas preestablecidas.
                     Vea la sección "Listas Incorporadas" para detalles.
