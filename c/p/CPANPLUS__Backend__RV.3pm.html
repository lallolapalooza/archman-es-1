CPANPLUS::Backend::RV(3) Documentación de Perl aportada por el usuario CPANPLUS::Backend::RV(3)

NOMBRE

CPANPLUS::Backend::RV - objetos de valor de retorno

SINOPSIS

### crear un objeto CPANPLUS::Backend::RV
$backend_rv     = CPANPLUS::Backend::RV->new(
                            ok          => $booleano,
                            args        => $args,
                            rv          => $valor_de_retorno
                            function    => $funcion_llamante );
### si tienes un objeto CPANPLUS::Backend::RV
$args_pasados   = $backend_rv->args;    # argumentos pasados a la función
$ok             = $backend_rv->ok;      # indicación booleana del resultado
                                        # general de la llamada
$funcion       = $backend_rv->function # nombre de la función
                                        # llamante
$rv             = $backend_rv->rv       # el valor de retorno real
                                        # de la función llamante

DESCRIPCIÓN

Este módulo proporciona objetos de valor de retorno para llamadas multimódulo a CPANPLUS::Backend. En contexto booleano, devuelve el estado del resultado general (es decir, lo mismo que haría el método "ok").

MÉTODOS

new( ok => BOOL, args => DATOS, rv => DATOS, [function => $nombre_método] )

Crea un nuevo objeto CPANPLUS::Backend::RV a partir de los datos proporcionados. Este método solo debe ser llamado por funciones de CPANPLUS::Backend. Los especificadores de acceso pueden ser utilizados por los usuarios para inspeccionar un objeto RV.

Todos los nombres de los argumentos pueden ser usados como especificadores de acceso posteriormente para recuperar los datos.

Argumentos:

ok
Booleano que indica el éxito general
args
Los argumentos proporcionados a la función que devolvió este objeto rv. Útil para inspeccionar posteriormente y ver qué se pasó realmente a la función en caso de error.
rv
Una estructura de datos arbitraria que contiene los valores de retorno detallados de cada una de tus llamadas multimódulo.
function
El nombre de la función que creó este objeto rv. Puede ser pasado explícitamente. Si no se pasa, new() intentará deducir el nombre de la información de caller().
