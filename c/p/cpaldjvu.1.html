NOMBRE

cpaldjvu - Codificador DjVuDocument para imágenes de bajo color.

SINOPSIS

cpaldjvu [opciones] archivoppmentrada archivodjvuasalida

DESCRIPCIÓN

El programa cpaldjvu es un codificador DjVuDocument para imágenes que contienen pocos colores. Funciona mejor en imágenes que contienen grandes áreas de color sólido, como capturas de pantalla. Las relaciones de compresión en tales imágenes pueden ser mucho mayores que las logradas con la compresión GIF o PNG.

Este programa funciona primero reduciendo el número de colores distintos a un pequeño valor especificado utilizando un algoritmo simple de cuantización de color. El color dominante se codifica en la capa de fondo. Los otros colores se codifican en la capa de primer plano.

OPCIONES

-dpi n
Especifica la información de resolución codificada en el archivo de salida expresada en puntos por pulgada. La información de resolución codificada en los archivos DjVu determina cómo el decodificador escala la imagen en una pantalla particular. Las resoluciones significativas van de 25 a 6000. El valor predeterminado es 300 ppp.
-colors n
Especifica un número máximo de colores distintos para el algoritmo de cuantización de color. El valor predeterminado es 256. Valores más pequeños pueden producir archivos mucho más pequeños.
-bgwhite
Hace que la capa de fondo utilice el color cuantificado más claro en lugar del color dominante.
-verbose
Muestra mensajes informativos mientras se ejecuta.

OBSERVACIONES

La cuantización de color puede introducir una degradación severa si la imagen contiene áreas fotográficas con un gran número de colores muy similares. Los problemas de cuantización de color pueden resolverse preprocesando el archivo de entrada con un programa de cuantización diferente como ppmquant. Evite usar el algoritmo de difuminado de difusión de errores. Este algoritmo genera patrones de difuminado aleatorios que pueden ser muy costosos de codificar.

ERRORES

Este programa debería reescribirse como un preprocesador para csepdjvu.
