CPU_SET(3) Manual de Funciones de la Biblioteca CPU_SET(3)

NOMBRE

CPU_SET, CPU_CLR, CPU_ISSET, CPU_ZERO, CPU_COUNT, CPU_AND, CPU_OR, CPU_XOR, CPU_EQUAL, CPU_ALLOC, CPU_ALLOC_SIZE, CPU_FREE, CPU_SET_S, CPU_CLR_S, CPU_ISSET_S, CPU_ZERO_S, CPU_COUNT_S, CPU_AND_S, CPU_OR_S, CPU_XOR_S, CPU_EQUAL_S - macros para manipular conjuntos de CPU

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#define _GNU_SOURCE             /* Ver feature_test_macros(7) */
#include <sched.h>
void CPU_ZERO(cpu_set_t *set);
void CPU_SET(int cpu, cpu_set_t *set);
void CPU_CLR(int cpu, cpu_set_t *set);
int  CPU_ISSET(int cpu, cpu_set_t *set);
int  CPU_COUNT(cpu_set_t *set);
void CPU_AND(cpu_set_t *destset,
             cpu_set_t *srcset1, cpu_set_t *srcset2);
void CPU_OR(cpu_set_t *destset,
             cpu_set_t *srcset1, cpu_set_t *srcset2);
void CPU_XOR(cpu_set_t *destset,
             cpu_set_t *srcset1, cpu_set_t *srcset2);
int  CPU_EQUAL(cpu_set_t *set1, cpu_set_t *set2);
cpu_set_t *CPU_ALLOC(int num_cpus);
void CPU_FREE(cpu_set_t *set);
size_t CPU_ALLOC_SIZE(int num_cpus);
void CPU_ZERO_S(size_t setsize, cpu_set_t *set);
void CPU_SET_S(int cpu, size_t setsize, cpu_set_t *set);
void CPU_CLR_S(int cpu, size_t setsize, cpu_set_t *set);
int  CPU_ISSET_S(int cpu, size_t setsize, cpu_set_t *set);
int  CPU_COUNT_S(size_t setsize, cpu_set_t *set);
void CPU_AND_S(size_t setsize, cpu_set_t *destset,
             cpu_set_t *srcset1, cpu_set_t *srcset2);
void CPU_OR_S(size_t setsize, cpu_set_t *destset,
             cpu_set_t *srcset1, cpu_set_t *srcset2);
void CPU_XOR_S(size_t setsize, cpu_set_t *destset,
             cpu_set_t *srcset1, cpu_set_t *srcset2);
int  CPU_EQUAL_S(size_t setsize, cpu_set_t *set1, cpu_set_t *set2);

DESCRIPCIÓN

La cpu_set_t estructura de datos representa un conjunto de CPU. Los conjuntos de CPU son utilizados por sched_setaffinity(2) y interfaces similares.

El cpu_set_t tipo de datos está implementado como una máscara de bits. Sin embargo, la estructura de datos debe tratarse como opaca: toda manipulación de conjuntos de CPU debe hacerse a través de las macros descritas en esta página.

Se proporcionan las siguientes macros para operar sobre el conjunto de CPU set:

CPU_ZERO()
Limpia set, de modo que no contenga ninguna CPU.
CPU_SET()
Añade la CPU cpu a set.
CPU_CLR()
Elimina la CPU cpu de set.
CPU_ISSET()
Comprueba si la CPU cpu es miembro de set.
CPU_COUNT()
Devuelve el número de CPU en set.

Cuando se especifica un argumento cpu , este no debe producir efectos secundarios, ya que las macros anteriores pueden evaluar el argumento más de una vez.

La primera CPU del sistema corresponde a un valor cpu de 0, la siguiente CPU corresponde a un valor cpu de 1, y así sucesivamente. No se deben hacer suposiciones sobre la disponibilidad de CPUs particulares, ni que el conjunto de CPUs sea contiguo, ya que las CPUs pueden ponerse fuera de línea dinámicamente o estar ausentes por otras razones. La constante CPU_SETSIZE (actualmente 1024) especifica un valor mayor en uno que el número máximo de CPU que puede almacenarse en cpu_set_t.

Las siguientes macros realizan operaciones lógicas sobre conjuntos de CPU:

CPU_AND()
Almacena la intersección de los conjuntos srcset1 y srcset2 en destset (que puede ser uno de los conjuntos de origen).
CPU_OR()
Almacena la unión de los conjuntos srcset1 y srcset2 en destset (que puede ser uno de los conjuntos de origen).
CPU_XOR()
Almacena el XOR de los conjuntos srcset1 y srcset2 en destset (que puede ser uno de los conjuntos de origen). El XOR significa el conjunto de CPUs que están en srcset1 o en srcset2, pero no en ambos.
CPU_EQUAL()
Comprueba si dos conjuntos de CPU contienen exactamente las mismas CPUs.

Conjuntos de CPU de tamaño dinámico

Debido a que algunas aplicaciones pueden requerir la capacidad de dimensionar dinámicamente los conjuntos de CPU (por ejemplo, para asignar conjuntos más grandes que los definidos por el tipo de datos estándar cpu_set_t ), glibc proporciona actualmente un conjunto de macros para soportar esto.

Las siguientes macros se utilizan para asignar y desasignar conjuntos de CPU:

CPU_ALLOC()
Asigna un conjunto de CPU lo suficientemente grande como para contener las CPUs en el rango 0 a num_cpus-1.
CPU_ALLOC_SIZE()
Devuelve el tamaño en bytes del conjunto de CPU que se necesitaría para contener las CPUs en el rango 0 a num_cpus-1. Esta macro proporciona el valor que puede usarse para el argumento setsize en las macros CPU_*_S() descritas más abajo.
CPU_FREE()
Libera un conjunto de CPU previamente asignado por CPU_ALLOC().

Las macros cuyos nombres terminan con "_S" son los análogos de las macros de nombre similar sin el sufijo. Estas macros realizan las mismas tareas que sus análogos, pero operan sobre el (los) conjunto(s) de CPU dinámicamente asignado(s) cuyo tamaño es setsize bytes.

VALOR DE RETORNO

CPU_ISSET() y CPU_ISSET_S() devuelven un valor distinto de cero si cpu está en set; de lo contrario, devuelve 0.

CPU_COUNT() y CPU_COUNT_S() devuelven el número de CPU en set.

CPU_EQUAL() y CPU_EQUAL_S() devuelven un valor distinto de cero si los dos conjuntos de CPU son iguales; de lo contrario, devuelven 0.

CPU_ALLOC() devuelve un puntero en caso de éxito, o NULL en caso de fallo. (Los errores son como en malloc(3).)

CPU_ALLOC_SIZE() devuelve el número de bytes requeridos para almacenar un conjunto de CPU de la cardinalidad especificada.

Las otras funciones no devuelven un valor.

ESTÁNDARES

Linux.

HISTORIA

Las macros CPU_ZERO(), CPU_SET(), CPU_CLR(), y CPU_ISSET() se añadieron en glibc 2.3.3.

CPU_COUNT() apareció por primera vez en glibc 2.6.

CPU_AND(), CPU_OR(), CPU_XOR(), CPU_EQUAL(), CPU_ALLOC(), CPU_ALLOC_SIZE(), CPU_FREE(), CPU_ZERO_S(), CPU_SET_S(), CPU_CLR_S(), CPU_ISSET_S(), CPU_AND_S(), CPU_OR_S(), CPU_XOR_S(), y CPU_EQUAL_S() aparecieron por primera vez en glibc 2.7.

NOTAS

Para duplicar un conjunto de CPU, usa memcpy(3).

Dado que los conjuntos de CPU son máscaras de bits asignadas en unidades de palabras largas, el número real de CPU en un conjunto de CPU dinámicamente asignado se redondeará al siguiente múltiplo de sizeof(unsigned long). Una aplicación debe considerar el contenido de estos bits extra como indefinido.

A pesar de la similitud en los nomes, ten en cuenta que la constante CPU_SETSIZE indica el número de CPUs en el tipo de datos cpu_set_t (por lo tanto, es efectivamente un recuento de los bits en la máscara de bits), mientras que el argumento setsize de las macros CPU_*_S() es un tamaño en bytes.

Los tipos de datos para los argumentos y los valores de retorno mostrados en el SINOPSIS son pistas sobre lo que se espera en cada caso. Sin embargo, dado que estas interfaces están implementadas como macros, el compilador no detectará necesariamente todos los errores de tipo si usted viola las sugerencias.

ERRORES

En plataformas de 32 bits con glibc 2.8 y versiones anteriores, CPU_ALLOC() asigna el doble del espacio necesario, y CPU_ALLOC_SIZE() devuelve un valor el doble de grande de lo que debería. Este error no debería afectar la semántica de un programa, pero resulta en memoria desperdiciada y una operación menos eficiente de las macros que operan en conjuntos de CPU asignados dinámicamente. Estos errores están corregidos en glibc 2.9.

EJEMPLOS

El siguiente programa demuestra el uso de algunas de las macros utilizadas para conjuntos de CPU asignados dinámicamente.

#define _GNU_SOURCE
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <assert.h>
int
main(int argc, char *argv[])
{
    cpu_set_t *cpusetp;
    size_t size, num_cpus;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s <num-cpus>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    num_cpus = atoi(argv[1]);
    cpusetp = CPU_ALLOC(num_cpus);
    if (cpusetp == NULL) {
        perror("CPU_ALLOC");
        exit(EXIT_FAILURE);
    }
    size = CPU_ALLOC_SIZE(num_cpus);
    CPU_ZERO_S(size, cpusetp);
    for (size_t cpu = 0; cpu < num_cpus; cpu += 2)
        CPU_SET_S(cpu, size, cpusetp);
    printf("CPU_COUNT() of set:    %d\n", CPU_COUNT_S(size, cpusetp));
    CPU_FREE(cpusetp);
    exit(EXIT_SUCCESS);
}
