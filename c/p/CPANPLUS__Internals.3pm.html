CPANPLUS::Internals(3) Documentación de Perl contribuida por el usuario CPANPLUS::Internals(3)

NOMBRE

CPANPLUS::Internals - Internos de CPANPLUS

SINOPSIS

my $internals   = CPANPLUS::Internals->_init( _conf => $conf );
my $backend     = CPANPLUS::Internals->_retrieve_id( $ID );

DESCRIPCIÓN

Este módulo es las entrañas de CPANPLUS -- hereda de todos los demás módulos del espacio de nombres CPANPLUS::Internals::*, desafiando así las reglas normales de la programación orientada a objetos -- pero si estás leyendo esto, ya sabes de qué va todo esto ;)

Por favor, lee la documentación de "CPANPLUS::Backend" para la API normal.

ACCESORES

_conf
Obtener/establecer el objeto de configuración
_id
Obtener/establecer el id

MÉTODOS

$internals = CPANPLUS::Internals->_init( _conf => OBJETO_CONFIGURACIÓN )

"_init" crea un nuevo objeto CPANPLUS::Internals.

Debes pasarle un objeto "CPANPLUS::Configure" válido.

Devuelve el objeto en caso de éxito, o muere en caso de fallo.

$bool = $internals->_flush( list => \@caches )

Vacía las cachés designadas del objeto "CPANPLUS".

Devuelve verdadero en caso de éxito, falso si una o más cachés no pudieron ser vaciadas.

$bool = $internals->_register_callback( name => CALLBACK_NAME, code => CODEREF );

Registra una devolución de llamada para su uso posterior por las bibliotecas internas.

Aquí tienes una lista de las devoluciones de llamada utilizadas actualmente:

install_prerequisite
Se llama cuando se quiere "preguntar" al usuario qué hacer con los prerrequisitos. Debe devolver un booleano indicando verdadero para instalar el prerrequisito y falso para omitirlo.
send_test_report
Se llama cuando se debe preguntar al usuario si desea enviar el informe de pruebas. Debe devolver un booleano indicando verdadero para enviar el informe de pruebas y falso para omitirlo.
munge_test_report
Se llama cuando se ha compuesto el mensaje del informe de pruebas, dando al usuario la oportunidad de alterarlo programáticamente. Debe devolver el mensaje (alterado) a enviar.
edit_test_report
Se llama cuando se debe preguntar al usuario si desea editar los informes de pruebas que está a punto de enviar Test::Reporter. Debe devolver un booleano indicando verdadero para editar el informe de pruebas en un editor y falso para omitirlo.
proceed_on_test_failure
Se llama cuando falla 'make test' o 'Build test'. Debe devolver un booleano que indique si la instalación debe continuar aunque la prueba haya fallado.
munge_dist_metafile
Se llama cuando se crea el metadato "CPANPLUS::Dist::*", como "control" para "CPANPLUS::Dist::Deb", dando al usuario la oportunidad de alterarlo programáticamente. Debe devolver el texto (alterado) que se escribirá en el metadato.

$bool = $internals->_add_to_includepath( directories => \@dirs )

Añade una lista de directorios a la ruta de inclusión. Esto significa que se añaden a @INC así como a $ENV{PERL5LIB}.

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$bool = $internals->_add_to_path( directories => \@dirs )

Añade una lista de directorios a PATH, pero solo si realmente contienen algo.

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$id = CPANPLUS::Internals->_last_id

Devuelve el id del último objeto almacenado.

$id = CPANPLUS::Internals->_store_id( $internals )

Almacena este objeto; devuelve su id.

$obj = CPANPLUS::Internals->_retrieve_id( $ID )

Recupera un objeto basado en su ID -- devuelve falso en caso de error.

CPANPLUS::Internals->_remove_id( $ID )

Elimina el objeto marcado por $ID del almacenamiento.

@objs = CPANPLUS::Internals->_return_all_objects

Devuelve todos los objetos almacenados.
