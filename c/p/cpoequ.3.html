subrutina cpoequ (entero n, complejo, dimensión( lda, * ) a, entero lda, real, dimensión( * ) s, real scond, real amax, entero info)

CPOEQU

Propósito:

!>
!> CPOEQU calcula escalados de fila y columna destinados a equilibrar una
!> matriz Hermítica definida positiva A y reducir su número de condición
!> (con respecto a la norma dos). S contiene los factores de escala,
!> S(i) = 1/sqrt(A(i,i)), elegidos para que la matriz escalada B con
!> elementos B(i,j) = S(i)*A(i,j)*S(j) tenga unos en la diagonal.
!> Esta elección de S pone el número de condición de B dentro de un factor N
!> del número de condición más pequeño posible sobre todos los escalados diagonales
!> posibles.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es matriz COMPLEJA, dimensión (LDA,N)
!>          La matriz Hermítica definida positiva N por N cuyos factores de escala
!>          se van a calcular. Solo se referencian los elementos diagonales de A.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

S

!>          S es array REAL, dimensión (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Si INFO = 0, S contiene la relación del S(i) más pequeño con
!>          el S(i) más grande. Si SCOND >= 0.1 y AMAX no es ni demasiado
!>          grande ni demasiado pequeño, no vale la pena escalar con S.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está muy
!>          cerca del desbordamiento o muy cerca de la falta de memoria, la matriz
!>          debe ser escalada.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>          > 0:  si INFO = i, el elemento diagonal i-ésimo es no positivo.
!>
