NOMBRE

CPANPLUS::Shell::Default::Plugins::Source - leer comandos de CPANPLUS

SINOPSIS

CPAN Terminal> /source /tmp/list_of_commands /tmp/more_commands

DESCRIPCIÓN

Este es un plugin de "CPANPLUS::Shell::Default" que funciona igual que el comando source(1) de los shells de Unix; lee un archivo que contiene comandos para ejecutar, y luego los ejecuta.

Un archivo de ejemplo podría verse así:

# primero, actualiza todos los archivos fuente
x --update_source
# encuentra todos mis módulos que están en CPAN
# pruébalos y almacena el registro de errores
a ^KANE$'
t *
p /home/kane/cpan-autotest/log
# e infórmanos que estamos listos
! print "Autotest completado, registro almacenado; ¡por favor ingrese sus comandos!"

Observa cómo las líneas vacías y las líneas que comienzan con '#' se omiten en la ejecución.
