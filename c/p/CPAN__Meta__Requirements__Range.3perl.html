CPAN::Meta::Requirements::Range(3perl) Guía de referencia para programadores de Perl CPAN::Meta::Requirements::Range(3perl)

NOMBRE

CPAN::Meta::Requirements::Range - un conjunto de requisitos de versión para una distribución CPAN

VERSIÓN

versión 2.143

SINOPSIS

use CPAN::Meta::Requirements::Range;
my $range = CPAN::Meta::Requirements::Range->with_minimum(1);
$range = $range->with_maximum('v2.2');
my $stringified = $range->as_string;

DESCRIPCIÓN

Un objeto CPAN::Meta::Requirements::Range modela un conjunto de restricciones de versión como las especificadas en los archivos META.yml o META.json en distribuciones CPAN, y como se define en CPAN::Meta::Spec; Se puede construir agregando más y más restricciones, y las reducirá a la representación más simple.

Las restricciones lógicamente imposibles se identificarán inmediatamente mediante excepciones lanzadas.

MÉTODOS

with_string_requirement

$req->with_string_requirement('>= 1.208, <= 2.206');
$req->with_string_requirement(v1.208);

Este método analiza la cadena pasada y agrega el requisito apropiado. Una versión puede ser una "v-string" de Perl. Comprende rangos de versiones como se describe en "Version Ranges" en CPAN::Meta::Spec. Por ejemplo:

1.3
>= 1.3
<= 1.3
== 1.3
!= 1.3
> 1.3
< 1.3
>= 1.3, != 1.5, <= 2.0
Un número de versión sin un operador es equivalente a especificar un mínimo (">="). Se permiten espacios en blanco adicionales.

with_range

$range->with_range($other_range)

Esto crea un nuevo objeto de rango que es una fusión de dos existentes.

with_exact_version

$range->with_exact_version( $version );

Esto establece la versión requerida a exactamente la versión dada. Ninguna otra versión sería considerada aceptable.

Este método devuelve el objeto de rango de versión.

with_minimum

$range->with_minimum( $version );

Esto agrega un nuevo requisito de versión mínima. Si el nuevo requisito es redundante con la especificación existente, esto no tiene ningún efecto.

Los requisitos mínimos son inclusivos. Se requiere $version, junto con cualquier número de versión mayor.

Este método devuelve el objeto de rango de versión.

with_maximum

$range->with_maximum( $version );

Esto agrega un nuevo requisito de versión máxima. Si el nuevo requisito es redundante con la especificación existente, esto no tiene ningún efecto.

Los requisitos máximos son inclusivos. No se permiten versiones estrictamente mayores que la versión dada.

Este método devuelve el objeto de rango de versión.

with_exclusion

$range->with_exclusion( $version );

Esto agrega una nueva versión excluida. Por ejemplo, podría usar estas tres llamadas a métodos:

$range->with_minimum( '1.00' );
$range->with_maximum( '1.82' );
$range->with_exclusion( '1.75' );

Cualquier versión entre 1.00 y 1.82 inclusive sería aceptable, excepto 1.75.

Este método devuelve el objeto de requisitos.

as_struct

$range->as_struct( $module );

Esto devuelve una estructura de datos que contiene los requisitos de versión. Esto no debe usarse para comprobaciones de versión (vea "accepts_module" en su lugar).

as_string

$range->as_string;

Esto devuelve una cadena que contiene los requisitos de versión en el formato descrito en CPAN::Meta::Spec. Esto solo debe usarse para fines informativos, como mensajes de error, y no debe interpretarse ni usarse para comparaciones (vea "accepts" en su lugar).

accepts

my $bool = $range->accepts($version);

Dada una versión, este método devuelve verdadero si la especificación de versión acepta la versión proporcionada. En otras palabras, dado:

'>= 1.00, < 2.00'

Aceptaremos 1.00 y 1.75 pero no 0.50 o 2.00.

is_simple

Este método devuelve verdadero si y solo si el rango es un mínimo inclusivo, es decir, si su expresión de cadena es solo el número de versión.
