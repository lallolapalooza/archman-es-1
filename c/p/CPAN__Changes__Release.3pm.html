NOMBRE

CPAN::Changes::Release - Una versión en un archivo de cambios de CPAN

SINOPSIS

my $release = CPAN::Changes::Release->new(
  version => '0.01',
  date    => '2015-07-20',
);
$release->add_entry('Este es un cambio');

DESCRIPCIÓN

Un registro de cambios se compone de una o más versiones. Este objeto proporciona acceso a todos los datos clave que conforman una versión, incluyendo el número de versión, la fecha de lanzamiento y todas las líneas de información del registro de cambios.

ATRIBUTOS

version

El número de versión de la versión.

date

La fecha de la versión.

note

La nota adjunta a la versión.

entries

Una referencia de array de entradas en la versión.

line

El número de línea donde comienza la versión.

MÉTODOS

serialize

Devuelve la entrada de cambios para la versión en formato de cadena.

clone

Devuelve un nuevo objeto de versión con los mismos datos. Puede recibir cualquier atributo para establecerlos de manera diferente en el nuevo objeto.

has_entries

Devuelve verdadero si hay entradas de cambios en esta versión.

find_entry

Acepta una cadena o una expresión regular, devuelve un objeto de entrada coincidente.

add_entry

Agrega una entrada de cambios. Acepta un objeto de entrada de cambios o una cadena.

remove_entry

Dada una cadena o un objeto de entrada de cambios, elimina la entrada de la versión.
