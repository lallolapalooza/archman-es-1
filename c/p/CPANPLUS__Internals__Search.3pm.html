CPANPLUS::Internals::Search(3) Documentación de Perl contribuida por el usuario CPANPLUS::Internals::Search(3)

NOMBRE

CPANPLUS::Internals::Search - internos para buscar módulos

SINOPSIS

my $aref = $cpan->_search_module_tree(
                    type    => 'package',
                    allow   => [qr/DBI/],
                );
my $aref = $cpan->_search_author_tree(
                    type    => 'cpanid',
                    data    => \@old_results,
                    verbose => 1,
                    allow   => [qw|KANE AUTRIJUS|],
                );
my $aref = $cpan->_all_installed( );

DESCRIPCIÓN

Las funciones de este módulo están diseñadas para encontrar objetos de módulo basados en ciertos criterios y devolverlos.

MÉTODOS

_search_module_tree( type => TIPO, allow => \@regexes, [data => \@previous_results ] )

Busca en el árbol de módulos objetos de módulo que coincidan con los criterios que especifiques. Devuelve una referencia de array de objetos de módulo en caso de éxito, y falso en caso de fallo.

Acepta los siguientes argumentos:

type
Puede ser cualquiera de los accesores para los objetos "CPANPLUS::Module". Este es un argumento obligatorio.
allow
Un conjunto de reglas, o más precisamente, una lista de expresiones regulares (mediante "qr//" o cadenas simples) que el "type" debe cumplir. Puedes especificar tantas como desees, y se tratará como una búsqueda "OR". Para una búsqueda "AND", consulta el argumento "data".

Este es un argumento obligatorio.

data
Una referencia de array de resultados de búsqueda anteriores. Esta es la forma de hacer una búsqueda "AND": "_search_module_tree" solo buscará en los objetos de módulo especificados en "data" si se proporciona, en lugar de en el árbol de módulos en sí.

_search_author_tree( type => TIPO, allow => \@regexex, [data => \@previous_results ] )

Busca en el árbol de autores objetos de autor que coincidan con los criterios que especifiques. Devuelve una referencia de array de objetos de autor en caso de éxito, y falso en caso de fallo.

Acepta los siguientes argumentos:

type
Puede ser cualquiera de los accesores para los objetos "CPANPLUS::Module::Author". Este es un argumento obligatorio.
allow
Un conjunto de reglas, o más precisamente, una lista de expresiones regulares (mediante "qr//" o cadenas simples) que el "type" debe cumplir. Puedes especificar tantas como desees, y se tratará como una búsqueda "OR". Para una búsqueda "AND", consulta el argumento "data".

Este es un argumento obligatorio.

data
Una referencia de array de resultados de búsqueda anteriores. Esta es la forma de hacer una búsqueda "and": "_search_author_tree" solo buscará en los objetos de autor especificados en "data" si se proporciona, en lugar de en el árbol de autores en sí.

_all_installed()

Esta función devuelve una referencia de array de objetos de módulo de los módulos que están instalados en este sistema.
