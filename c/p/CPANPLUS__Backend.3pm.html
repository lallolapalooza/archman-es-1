save_state

Comando explícito para guardar el estado en memoria en el disco. Esto puede usarse para guardar información en el disco sobre dónde se extrajo un módulo, el resultado de "make test", etc. Esto se recargará en la memoria cuando comience una nueva

sesión.

La capacidad de guardar el estado en el disco depende del motor de origen que se esté usando (Vea "CPANPLUS::Config" para la opción de elegir su motor de origen). El motor de almacenamiento por defecto soporta esta

opción.

La mayoría de los usuarios no necesitarán este comando, pero puede ser útil para sistemas automatizados como la configuración de probadores de humo (smoke testers) de

CPAN.

PERSONALIZADAS

Además de las fuentes proporcionadas por los espejos generales de "CPAN", es posible añadir su propia lista de fuentes a su índice de "CPANPLUS"

.

La metodología detrás de esto funciona de manera muy similar a "apt-sources de

Debian".

Los métodos siguientes le muestran cómo hacer uso de esta funcionalidad. Tenga en cuenta también que la mayoría de estos métodos están disponibles a través del comando del plugin de shell por defecto "/cs", haciéndolos disponibles como accesos directos a través del shell y vía la línea de

comandos.

%files = $cb->list_custom_source

s

Devuelve un mapeo de las fuentes personalizadas registradas y sus índices locales como

sigue: 
/full/path/to/local/index => http:
//remote/source

Tenga en cuenta que cualquier archivo que comience con un "#" está sie

ndo ign
orado.

$local_index = $cb->add_custom_source( uri => URI, [verbose => BOOL] )

;

Añade una "URI" a su propia lista de fuentes y refleja su índice. Vea la documentación sobre "$cb->update_custom_source" para saber cómo se hace

esto.

Devuelve la ruta completa al índice local en caso de éxito, o falso en caso de

fallo.

Tenga en cuenta que cuando añadiendo una nueva "URI", el cambio en el árbol en memoria no se guarda hasta que vuelvas a construir o guardar el árbor en disco. Puedes hacer esto usando el "$cb->reload_ind

ices"
método.

$local_index = $cb->remove_custom_source( uri => URI, [verbose => BOOL] )

;

de éxito, o falso en caso de fallo.

$bool = $cb->update_custom_source( [remote => URI] )

;

Actualiza los índices de todas tus fuentes personalizadas. Hace esto obteniendo un archivo llamado "packages.txt" en la raíz de las fuentes personalizadas' "URI". Si proporcionas el argumento "remote", solo actualizará el índice para esa "URI" específica. "URI"

.

Aquí hay un ejemplo de cómo las fuentes personalizadas se resolverían en archivos de

índice: 
file:///path/to/sources       =>  file:///path/to/sources/packages.txt
http://example.com/sources    =>  http://example.com/sources/packages.txt
ftp://example.com/sources     =>  ftp://example.com/sources/packages.
txt

El archivo "packages.txt" simplemente contiene una lista de paquetes que se pueden encontrar bajo la raíz del "URI". Este archivo se puede generar automáticamente para ti cuando la fuente remota es una "URI file://". Para "http://", "ftp://", y similares, el administrador de ese repositorio debería ejecutar el método "$cb->write_custom_source_index" en el repositorio para permitir a los usuarios remotos

indexarlo.

Para más detalles, consulta el método "$cb->write_custom_source_index" más

abajo.

Todos los paquetes que se agregan a través de este mecanismo serán atribuidos al autor con "CPANID" "LOCAL". Puedes usar este id para b

uscar todos los p
aquetes agregados.

$file = $cb->write_custom_source_index( path => /path/to/package/root, [to => /path/to/index/file, verbose => BOOL] )

Escribe el índice para una raíz de repositorio personalizada. La mayoría de los usuarios no tendrán que preocuparse por esto, pero los administradores de un repositorio necesitarán asegurarse de que sus índices estén

actualizados.

El índice se escribirá en un archivo llamado "packages.txt" en la raíz de tu repositorio, que puedes especificar con el argumento "path". Puedes anular esta ubicación especificando el argumento "to", pero en operación normal, eso no debería ser

necesario.

Una vez que el archivo de índice esté escrito, los usuarios pueden entonces agregar la "URI" que apunta al repositorio a su lista personalizada de fuentes y empezar a usarla de inmediato. Consulta el método "$cb->add_custom
