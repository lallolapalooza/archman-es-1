CPORFS

Documentación de Función/Subrutina

subrutina cporfs (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CPORFS

Propósito:

!>
!> CPORFS mejora la solución calculada de un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es hermítica definida
!> positiva, y proporciona límites de error y estimaciones de error
!> hacia atrás para la solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A se almacena;
!>          = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es arreglo COMPLEX, dimensión (LDA,N)
!>          La matriz hermítica A.  Si UPLO = 'U', la parte superior
!>          triangular N-por-N principal de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte inferior
!>          triangular N-por-N principal de A contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

AF

!>          AF es arreglo COMPLEX, dimensión (LDAF,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, tal como se calculó por CPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!>

B

!>          B es arreglo COMPLEX, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

X

!>          X es arreglo COMPLEX, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como se calculó por
!>          CPOTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  LDX >= max(1,N).
!>

FERR

!>          FERR es arreglo REAL, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector
!>          solución X(j) (la columna j de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado de la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento
!>          más grande en X(j). La estimación es tan confiable como la
!>          estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es arreglo REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es arreglo COMPLEX, dimensión (2*N)
!>

RWORK

!>          RWORK es arreglo REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
