NOMBRE

cpanp - El lanzador de CPANPLUS

SINOPSIS

cpanp

cpanp [-]a [ --[no-]opción... ]  autor... 

cpanp [-]mfitulrcz [ --[no-]opción... ]  módulo... 

cpanp [-]d [ --[no-]opción... ] [ --directorio_descarga=... ]  módulo... 

cpanp [-]xb [ --[no-]opción... ]

cpanp [-]o [ --[no-]opción... ] [ módulo... ]

DESCRIPCIÓN

Este script lanza la utilidad CPANPLUS para realizar diversas operaciones desde la línea de comandos. Si se invoca sin argumentos, se ejecuta un shell interactivo por defecto.

Opcionalmente, puede tomar un interruptor de una sola letra y uno o más argumentos, para realizar la acción asociada en cada argumento. A continuación se muestra un resumen de los comandos disponibles; "cpanp -h" proporciona una lista detallada.

h                   # información de ayuda
v                   # información de versión
a AUTOR ...        # buscar por autor(es)
m MÓDULO ...        # buscar por módulo(s)
f MÓDULO ...        # listar todas las versiones de un módulo
i MÓDULO ...        # instalar módulo(s)
t MÓDULO ...        # probar módulo(s)
u MÓDULO ...        # desinstalar módulo(s)
d MÓDULO ...        # descargar módulo(s)
l MÓDULO ...        # mostrar información detallada sobre módulo(s)
r MÓDULO ...        # mostrar archivos README de módulo(s)
c MÓDULO ...        # comprobar informes de módulo(s) de cpan-testers
z MÓDULO ...        # extraer módulo(s) y abrir el prompt de comandos en él
x                   # recargar índices de CPAN
o [ MÓDULO ... ]    # listar módulos instalados que no están actualizados
b                   # escribir un archivo de paquete para su configuración

Cada comando puede ir seguido de una o más opciones. Si va precedido por "no", la opción correspondiente se establecerá en 0, de lo contrario se establecerá en 1.

Ejemplo: Para omitir las pruebas de un módulo,

cpanp -i --skiptest MÓDULO ...

Las opciones válidas para la mayoría de los comandos son "cpantest", "debug", "flush", "force", "prereqs", "storable", "verbose", "md5", "signature" y "skiptest"; el comando 'd' también acepta "fetchdir". Consulte CPANPLUS::Configure para obtener una explicación de sus significados.

Ejemplo: Para descargar el archivo tar de un módulo al directorio actual,

cpanp -d --fetchdir=. MÓDULO ...
