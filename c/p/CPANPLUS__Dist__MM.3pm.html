NOMBRE

CPANPLUS::Dist::MM - clase de distribución para módulos relacionados con MakeMaker

SINOPSIS

$mm = CPANPLUS::Dist::MM->new( module => $modobj );
$mm->create;        # ejecuta make && make test
$mm->install;       # ejecuta make install

DESCRIPCIÓN

"CPANPLUS::Dist::MM" es una clase de distribución para módulos relacionados con MakeMaker. Usando este paquete, puedes crear, instalar y desinstalar módulos perl. Hereda de "CPANPLUS::Dist".

ACCESSORES

parent()
Devuelve el "CPANPLUS::Module" objeto que es padre de este objeto.
status()
Devuelve el "Object::Accessor" objeto que guarda el estado de este módulo.

ACCESSORES DE ESTADO

Todos los accessores se pueden acceder de la siguiente manera:
$mm->status->ACCESSOR

makefile ()
Ubicación del Makefile (o archivo Build). Establecer a 0 explícitamente si algo salió mal.
make ()
BOOL que indica si el "make" (o "Build") comando fue exitoso.
test ()
BOOL que indica si el "make test" (o "Build test") comando fue exitoso.
prepared ()
BOOL que indica si la "prepare" llamada terminó exitosamente. Esto se establece después de "perl Makefile.PL"
distdir ()
Ruta completa al directorio en el que tuvo lugar la "prepare" llamada, establecida después de una llamada a "prepare".
created ()
BOOL que indica si la "create" llamada terminó exitosamente. Esto se establece después de "make" y "make test".
installed ()
BOOL que indica si el módulo fue instalado. Esto se establece después de "make install" (o "Build install") termina exitosamente.
uninstalled ()
BOOL que indica si el módulo fue desinstalado correctamente.
_create_args ()
Almacenamiento de los argumentos pasados a "create" para este objeto. Usado para llamadas recursivas al satisfacer prerrequisitos.
_install_args ()
Almacenamiento de los argumentos pasados a "install" para este objeto. Usado para llamadas recursivas al satisfacer prerrequisitos.

MÉTODOS

$bool = $dist->format_available();

Devuelve un booleano que indica si puedes usar este paquete para crear e instalar módulos en tu entorno o no.

$bool = $dist->init();

Prepara el "CPANPLUS::Dist::MM" objeto para su uso. Efectivamente crea todos los accessores de estado necesarios.

Se llama automáticamente cada vez que creas un nuevo "CPANPLUS::Dist" objeto.

$bool = $dist->prepare([perl => '/ruta/a/perl', makemakerflags => 'EXTRA=FLAGS', force => BOOL, verbose => BOOL])

"prepare" prepara una distribución para la instalación. Esto significa que ejecutará "perl Makefile.PL" y determinará qué prerrequisitos declaró esta distribución.

Si estableces "force" a verdadero, pasará por todas las etapas del "prepare" proceso de nuevo, ignorando cualquier resultado previamente en caché.

Al ejecutar "perl Makefile.PL", la variable de entorno "PERL5_CPANPLUS_IS_EXECUTING" se establecerá a la ruta completa del "Makefile.PL" que está siendo ejecutado. Esto permite que cualquier código dentro del "Makefile.PL" sepa que está siendo instalado a través de CPANPLUS.

Devuelve verdadero en caso de éxito y falso en caso de fallo.

Luego puedes llamar a "$dist->create" en el objeto para crear los archivos instalables.

$href = $dist->_find_prereqs( file => '/ruta/a/Makefile', [verbose => BOOL])

Analiza un "Makefile" para "PREREQ_PM" entradas y destila de eso cualquier prerrequisito mencionado en el "Makefile"

Devuelve un hash con pares módulo-versión en caso de éxito y falso en caso de fallo.

$bool = $dist->create([perl => '/ruta/a/perl', make => '/ruta/a/make', makeflags => 'EXTRA=FLAGS', prereq_target => TARGET, skiptest => BOOL, force => BOOL, verbose => BOOL])

"create" crea los archivos necesarios para la instalación. Esto significa que ejecutará "make" y "make test". Esto también escaneará e intentará satisfacer cualquier prerrequisito que el módulo pueda tener.

Si estableces "skiptest" a verdadero, se omitirá la etapa "make test" . Si estableces "force" a verdadero, pasará por todas las etapas del "make" proceso de nuevo, ignorando cualquier resultado previamente en caché. También ignorará un valor de retorno incorrecto de "make test" y aún permitirá que la operación devuelva verdadero.

Devuelve verdadero en caso de éxito y falso en caso de fallo.

Luego puedes llamar a "$dist->install" en el objeto para instalarlo realmente.

$bool = $dist->install([make => '/ruta/a/make', makemakerflags => 'EXTRA=FLAGS', force => BOOL, verbose => BOOL])

"install" ejecuta el siguiente comando:
make install

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$bool = $dist->write_makefile_pl([force => BOOL, verbose => BOOL])

Esta rutina puede escribir un "Makefile.PL" a partir de la información en un objeto de módulo. Se usa para escribir un "Makefile.PL" cuando el autor original lo olvidó (!!).

Devuelve 1 en caso de éxito y falso en caso de fallo.

El archivo se escribe en el directorio al que se ha extraído el módulo.
