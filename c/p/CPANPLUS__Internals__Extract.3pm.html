CPANPLUS::Internals::Extract(3) Documentación de Perl aportada por el usuario CPANPLUS::Internals::Extract(3)

NOMBRE

CPANPLUS::Internals::Extract - internos para la extracción de archivos

SINOPSIS

### para archivos fuente ###
$self->_gunzip( file => 'foo.gz', output => 'blah.txt' );
### para módulos/paquetes ###
$dir = $self->_extract( module      => $modobj,
                        extractdir  => '/some/where' );

DESCRIPCIÓN

CPANPLUS::Internals::Extract extrae archivos comprimidos para CPANPLUS. Puede hacerlo mediante una solución puramente en Perl (preferida) con el uso de "Archive::Tar" y "Compress::Zlib", o con binarios, como "gzip" y "tar".

El flujo se ve así:

$cb->_extract
    Delegar a Archive::Extract

MÉTODOS

$dir = _extract( module => $modobj, [perl => '/path/to/perl', extractdir => '/path/to/extract/to', prefer_bin => BOOL, verbose => BOOL, force => BOOL] )

"_extract" tomará un objeto módulo y lo extraerá en "extractdir" si se proporciona, o en la ubicación predeterminada que se obtiene de su configuración.

El nombre del archivo se obtiene al mirar "$modobj->status->fetch" y se analizará para ver si es un archivo tar o zip.

Si es un archivo zip, se llamará a "__unzip", de lo contrario se llamará a "__untar". En el improbable caso de que el archivo no sea de ninguno de los formatos, se lanzará un error.

"_extract" toma las siguientes opciones:

module
Un objeto "CPANPLUS::Module". Esto es requerido.
extractdir
El directorio donde extraer el archivo. Por defecto, esto se parece a:
/CPANPLUS_BASE/PERL_VERSION/BUILD/NOMBRE_DEL_MODULO
prefer_bin
Un indicador que especifica si se prefiere una solución puramente en Perl, es decir, "Archive::Tar" o "Archive::Zip" respectivamente, o una solución binaria como "unzip" y "tar".
perl
La ruta al ejecutable de Perl que se utilizará para cualquier llamada de Perl. También se utiliza para determinar el directorio de la versión de compilación para la extracción.
verbose
Especifica si se debe ser verboso o no. Por defecto, usa la entrada correspondiente de su configuración.
force
Especifica si se debe forzar la extracción o no. Por defecto, usa la entrada correspondiente de su configuración.

Todas las demás opciones se pasan sin modificaciones a "__unzip" o "__untar".

Devuelve el directorio donde se extrajo el archivo en caso de éxito y falso en caso de fallo.
