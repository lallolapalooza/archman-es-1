CPANPLUS::Internals::Utils(3) Documentación de Perl aportada por el usuario CPANPLUS::Internals::Utils(3)

NOMBRE

CPANPLUS::Internals::Utils - funciones de conveniencia para CPANPLUS

SINOPSIS

mi $bool = $cb->_mkdir( dir => 'blah' );
mi $bool = $cb->_chdir( dir => 'blah' );
mi $bool = $cb->_rmdir( dir => 'blah' );
mi $bool = $cb->_move( from => '/some/file', to => '/other/file' );
mi $bool = $cb->_move( from => '/some/dir',  to => '/other/dir' );
mi $cont = $cb->_get_file_contents( file => '/path/to/file' );
mi $version = $cb->_perl_version( perl => $^X );

DESCRIPCIÓN

"CPANPLUS::Internals::Utils" contiene algunas funciones de conveniencia para las bibliotecas de CPANPLUS.

MÉTODOS

$cb->_mkdir( dir => '/some/dir' )

"_mkdir" crea una ruta completa a un directorio.

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$cb->_chdir( dir => '/some/dir' )

"_chdir" cambia el directorio a uno especificado.

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$cb->_rmdir( dir => '/some/dir' );

Elimina un directorio completamente, incluso si no está vacío.

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$cb->_perl_version ( perl => 'some/perl/binary' );

"_perl_version" devuelve la versión de un binario de Perl específico. Lo hace ejecutando realmente un comando.

Devuelve la versión de Perl en caso de éxito y falso en caso de fallo.

$cb->_version_to_number( version => $version );

Devuelve una versión de módulo correcta, o '0.0' si no había ninguna disponible.

$cb->_whoami

Devuelve el nombre de la subrutina en la que te encuentras actualmente.

_get_file_contents( file => $file );

Devuelve el contenido de un archivo.

$cb->_move( from => $file|$dir, to => $target );

Mueve un archivo o directorio al destino especificado.

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$cb->_copy( from => $file|$dir, to => $target );

Mueve un archivo o directorio al destino especificado.

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$cb->_mode_plus_w( file => '/path/to/file' );

Establece el bit +w para el archivo.

Devuelve verdadero en caso de éxito, falso en caso de fallo.

$uri = $cb->_host_to_uri( scheme => SCHEME, host => HOST, path => PATH );

Convierte una entrada de "host" de estilo CPANPLUS::Config en una cadena URI.

Devuelve la URI en caso de éxito, y falso en caso de fallo.

$cb->_vcmp( VERSION, VERSION );

Normaliza las versiones pasadas y realiza un '<=>' sobre ellas, devolviendo el resultado.

$cb->_home_dir

Devuelve el directorio de inicio del usuario, o "cwd" si no se pudo encontrar.

$path = $cb->_safe_path( path => $path );

Devuelve una ruta segura para usar en Win32 y VMS.

Solo limpia la ruta en Win32 si la ruta existe.

En VMS, codifica los puntos como _ usando "VMS::Filespec::vmsify".

($pkg, $version, $ext) = $cb->_split_package_string( package => PACKAGE_STRING );

Divide el nombre de una cadena de paquete de CPAN en sus partes de paquete, versión y extensión.

Por ejemplo, "Foo-Bar-1.2.tar.gz" devolvería las siguientes partes:

Paquete:    Foo-Bar
Versión:    1.2
Extensión:  tar.gz
13-07-2025 perl v5.42.0
