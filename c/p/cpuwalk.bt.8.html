NOMBRE

cpuwalk.bt - Muestra qué CPUs están ejecutando procesos. Usa bpftrace/eBPF.

SINOPSIS

cpuwalk.bt

DESCRIPCIÓN

Esta herramienta muestrea las CPUs a 99 Hertz y luego imprime un histograma mostrando qué CPUs estaban activas. Se usan 99 Hertz para evitar el muestreo en fase que podría sesgar los resultados. Esta herramienta puede ayudar a identificar si la carga de trabajo de su aplicación está utilizando las CPUs de manera uniforme o si hay un problema de desequilibrio.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Muestrear CPUs e imprimir un resumen al presionar Ctrl-C:
# cpuwalk.bt

CAMPOS

1ro, 2do
La CPU se muestra en el primer campo, después del "[". Ignora el segundo campo.
3ro
Una columna que muestra el número de muestras para esta CPU.
4to
Este es un histograma ASCII que representa la columna de recuento.

SOBRECARGA

Esto debería ser insignificante.

FUENTE

https://github.com/bpftrace/bpftrace
