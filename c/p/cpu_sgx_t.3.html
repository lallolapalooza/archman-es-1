cpu_sgx_t - Contiene información sobre las características SGX del procesador. Ejemplo de uso:

SINOPSIS

#include <libcpuid.h>

Descripción Detallada

Contiene información sobre las características SGX del procesador. Ejemplo de uso:

...
struct cpu_raw_data_t raw;
struct cpu_id_t id;
if (cpuid_get_raw_data(&raw) == 0 && cpu_identify(&raw, &id) == 0 && id.sgx.present) {
  printf("SGX está presente.\n");
  printf("Instrucciones SGX1: %s.\n", id.sgx.flags[INTEL_SGX1] ? "presente" : "ausente");
  printf("Instrucciones SGX2: %s.\n", id.sgx.flags[INTEL_SGX2] ? "presente" : "ausente");
  printf("Tamaño máximo de enclave de 32 bits: 2^%d bytes.\n", id.sgx.max_enclave_32bit);
  printf("Tamaño máximo de enclave de 64 bits: 2^%d bytes.\n", id.sgx.max_enclave_64bit);
  for (int i = 0; i < id.sgx.num_epc_sections; i++) {
    struct cpu_epc_t epc = cpuid_get_epc(i, NULL);
    printf("Sección EPC #%d: dirección = %x, tamaño = %d bytes.\n", epc.address, epc.size);
  }
} else {
  printf("SGX no está presente.\n");
}

Documentación de campos

uint8_t cpu_sgx_t::flags[SGX_FLAGS_MAX]

contiene indicadores de características SGX. Consulte las macros INTEL_SGX* a continuación.

uint8_t cpu_sgx_t::max_enclave_32bit

Tamaño máximo de enclave en modo de 32 bits. Este es un valor de potencia de dos: si es "31", entonces el tamaño máximo del enclave es 2^31 bytes (2 GiB).

uint8_t cpu_sgx_t::max_enclave_64bit

Tamaño máximo de enclave en modo de 64 bits. Este es un valor de potencia de dos: si es "36", entonces el tamaño máximo del enclave es 2^36 bytes (64 GiB).

uint32_t cpu_sgx_t::misc_select

vector de bits de las características extendidas compatibles que se pueden escribir en la región MISC del SSA (Área de Estado de Guardado)

int cpu_sgx_t::num_epc_sections

número de secciones de Caché de Páginas de Enclave (EPC). La información para cada sección está disponible a través de la función cpuid_get_epc()

uint32_t cpu_sgx_t::present

Si SGX está presente (booleano)

uint64_t cpu_sgx_t::secs_attributes

un vector de bits de los atributos que se pueden establecer en SECS.ATTRIBUTES a través de ECREATE. Corresponde a los bits 0-63 (inclusive) de SECS.ATTRIBUTES.

uint64_t cpu_sgx_t::secs_xfrm

un vector de bits de los bits que se pueden establecer en la máscara de solicitud de característica XSAVE; Corresponde a los bits 64-127 de SECS.ATTRIBUTES.
