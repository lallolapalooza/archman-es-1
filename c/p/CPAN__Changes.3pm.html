CPAN::Changes(3) Documentación de Perl contribuida por el usuario CPAN::Changes(3)

NOMBRE

CPAN::Changes - Analizador de registros de cambios estilo CPAN

SINOPSIS

use CPAN::Changes;
my $changes = CPAN::Changes->load('Changes');
$changes->release('0.01');

DESCRIPCIÓN

Es una práctica estándar incluir un archivo Changes en tu distribución. El propósito del archivo Changes es ayudar a un usuario a descubrir qué ha cambiado desde la última versión.

Las personas han ideado muchas formas de escribir el archivo Changes. Se ha creado una especificación preliminar (CPAN::Changes::Spec) para animar a los autores de módulos a escribir Changes claros y concisos.

Este módulo ayudará a los usuarios a leer y escribir programáticamente archivos Changes que cumplan con la especificación.

MÉTODOS

nuevo ( %args )

Crea un objeto CPAN::Changes.

%args

preambulo
La sección de preámbulo del registro de cambios.
versiones
Un arrayref de objetos CPAN::Changes::Release.

cargar ( $nombre_archivo, %args )

Crea un nuevo objeto CPAN::Changes analizando el archivo dado a través de CPAN::Changes::Parser.

cargar_cadena ( $nombre_archivo, %args )

Crea un nuevo objeto CPAN::Changes analizando la cadena dada a través de CPAN::Changes::Parser.

preambulo ( [ $preambulo ] )

Obtiene o establece la sección de preámbulo.

versiones ( [ @versiones ] )

Obtiene o establece la lista de versiones como objetos CPAN::Changes::Release.

agregar_version ( @versiones )

Agrega las versiones dadas al registro de cambios. Si existe una versión del mismo número, será sobrescrita.

eliminar_version ( @versiones )

Elimina los números de versión dados del registro de cambios.

buscar_version ( $version )

Busca una versión con el número dado.

invertido

Devuelve un nuevo objeto CPAN::Changes con las versiones en orden opuesto.

clonar ( %atributos )

Devuelve un nuevo objeto "CPAN::Changes" con los atributos dados modificados.

serializar ( %opciones )

Devuelve el registro de cambios como una cadena adecuada para guardarla como un archivo de Changes.

ancho
El ancho en el que se envolverán las líneas. Por defecto, las líneas se envolverán a 75 caracteres.
estilos
Un arrayref de estilos a usar al generar las entradas, uno para cada nivel de cambio. La primera entrada se usa para la entrada de versión en sí.

Los estilos pueden ser un solo carácter para prefijar las líneas de cambio o dos caracteres para usar como prefijo y sufijo.

indentaciones
Un arrayref de cadenas de indentación a usar al generar las entradas.
invertir (legado)
Si es verdadero, las versiones se generarán en orden inverso.
ordenar_grupos (legado)
Una referencia de código utilizada para ordenar los grupos en las versiones.

MÉTODOS LEGADO

eliminar_grupos_vacíos

Elimina los grupos vacíos.

version

Un alias para buscar_version.
