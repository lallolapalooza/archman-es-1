CPOTRS

Propósito:

!>
!> CPOTRS resuelve un sistema de ecuaciones lineales A*X = B con una matriz
!> hermitiana definida positiva A utilizando la factorización de Cholesky
!> A = U**H*U o A = L*L**H calculada por CPOTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, tal como se calculó por CPOTRF.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEJO, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
