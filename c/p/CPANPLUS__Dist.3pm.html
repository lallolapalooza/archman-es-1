CPANPLUS::Dist(3) Documentación de Perl contribuida por el usuario CPANPLUS::Dist(3)

NOMBRE

CPANPLUS::Dist - clase base para plugins

SINOPSIS

mi $dist = CPANPLUS::Dist::TU_TIPO_DE_DISTRIBUCIÓN_AQUI->new(
                            modulo  => $modobj,
                        );

DESCRIPCIÓN

"CPANPLUS::Dist" es una clase base para "CPANPLUS::Dist::MM" y "CPANPLUS::Dist::Build". Los desarrolladores de otros plugins "CPANPLUS::Dist::*" deberían consultar "CPANPLUS::Dist::Base".

ACCESORES

padre()
Devuelve el objeto "CPANPLUS::Module" que creó este objeto.
estado()
Devuelve el objeto "Object::Accessor" que mantiene el estado de este módulo.

ACCESORES DE ESTADO

Todos los accesores se pueden acceder de la siguiente manera:
$deb->estado->ACCESOR

creado()
Booleano que indica si la distribución se creó correctamente. Se establece explícitamente en 0 cuando falla, por lo que un valor de "undef" puede interpretarse como "aún no intentado".
instalado()
Booleano que indica si la distribución se instaló correctamente. Se establece explícitamente en 0 cuando falla, por lo que un valor de "undef" puede interpretarse como "aún no intentado".
desinstalado()
Booleano que indica si la distribución se desinstaló correctamente. Se establece explícitamente en 0 cuando falla, por lo que un valor de "undef" puede interpretarse como "aún no intentado".
dist()
La ubicación de la distribución final. Puede ser un archivo o un directorio, dependiendo de cómo funcione tu plugin de distribución elegido. Esto se establecerá tras una creación exitosa.

$dist = CPANPLUS::Dist::TU_TIPO_DE_DISTRIBUCIÓN_AQUI->new( modulo => MODOBJ );

Crea un nuevo objeto "CPANPLUS::Dist::TU_TIPO_DE_DISTRIBUCIÓN_AQUI" basado en el "MODOBJ" proporcionado.

*** OBSOLETO *** El argumento opcional "formato" se utiliza para indicar qué tipo de distribución deseas crear (como "CPANPLUS::Dist::MM" o "CPANPLUS::Dist::Build" y similares).

"CPANPLUS::Dist->new" está exclusivamente pensado como un método para ser heredado por "CPANPLUS::Dist::MM|Build".

Devuelve un objeto "CPANPLUS::Dist::TU_TIPO_DE_DISTRIBUCIÓN_AQUI" en caso de éxito y falso en caso de error.

@dists = CPANPLUS::Dist->tipos_de_dist;

Devuelve una lista de las clases CPANPLUS::Dist::* disponibles.

$bool = CPANPLUS::Dist->volver_a_escanear_tipos_de_dist;

Vuelve a escanear &#64;INC en busca de tipos de distribución disponibles. Útil si has instalado nuevas clases "CPANPLUS::Dist::*" y quieres hacerlas disponibles para el proceso actual.

$bool = CPANPLUS::Dist->tiene_tipo_de_dist( $tipo )

Devuelve verdadero si el tipo de distribución $tipo está cargado/soportado.

$bool = $dist->prerequisito_satisfecho( modobj => $modobj, version => $especificación_version )

Devuelve verdadero si este prerequisito está satisfecho. Devuelve falso si no lo está. También emite un error si parece "insatisfacible", es decir, si no se puede encontrar en CPAN o si la última versión de CPAN no lo satisface.

$requiere_configuracion = $dist->encontrar_requiere_configuracion( [archivo => /ruta/a/META.yml] )

Lee los configure_requires para esta distribución desde el archivo META.yml o META.json en el directorio raíz y devuelve un hashref con los nombres de módulos y versiones requeridos.

$bool = $dist->_resolver_prerequisitos( ... )

Asegura que los prerequisitos estén resueltos.

formato         La clase de distribución a usar para construir los prerequisitos
                (es decir, CPANPLUS::Dist::MM)
prerequisitos   Hash de los módulos prerequisitos y sus versiones
objetivo        Qué hacer con los prerequisitos.
                    crear  => Simplemente construirlos
                    instalar => Instalarlos
                    ignorar  => Ignorarlos
prerequisito_construir    Si es verdadero, siempre construir los prerequisitos aunque ya estén
                resueltos
verboso         Ser verboso
forzar          Forzar la construcción del prerequisito, incluso si ya está resuelto
