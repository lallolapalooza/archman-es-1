cpuid(4) Manual de Controladores de Dispositivos cpuid(4)

NOMBRE

cpuid - dispositivo de acceso a CPUID x86

DESCRIPCIÓN

CPUID proporciona una interfaz para consultar información sobre la CPU x86.

Se accede a este dispositivo mediante lseek(2) o pread(2) al nivel CPUID apropiado y leyendo en fragmentos de 16 bytes. Un tamaño de lectura mayor significa múltiples lecturas de niveles consecutivos.

Los 32 bits inferiores de la posición del archivo se utilizan como el %eax entrante, y los 32 bits superiores de la posición del archivo como el %ecx entrante; este último está destinado a "contar" niveles de eax como eax=4.

Este controlador utiliza /dev/cpu/CPUNUM/cpuid, donde CPUNUM es el número menor, y en una caja SMP dirigirá el acceso a la CPU CPUNUM según lo enumerado en /proc/cpuinfo.

Este archivo está protegido de modo que solo el usuario root, o los miembros del grupo root, puedan leerlo.

NOTAS

La instrucción CPUID puede ser ejecutada directamente por un programa utilizando ensamblador en línea. Sin embargo, este dispositivo permite un acceso conveniente a todas las CPUs sin cambiar la afinidad del proceso.

La mayoría de la información en cpuid es reportada por el kernel en formato procesado, ya sea en /proc/cpuinfo o a través de subdirectorios en /sys/devices/system/cpu. El acceso directo a CPUID a través de este dispositivo solo debe usarse en casos excepcionales.

El controlador cpuid no se carga automáticamente. En kernels modulares, es posible que necesite usar el siguiente comando para cargarlo explícitamente antes de usarlo:


$ modprobe cpuid

No hay soporte para funciones CPUID que requieran registros de entrada adicionales.

Las primeras CPUs i486 no soportan la instrucción CPUID; la apertura de este dispositivo para esas CPUs falla con EIO.
