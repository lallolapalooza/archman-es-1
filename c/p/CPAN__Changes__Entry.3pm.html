CPAN::Changes::Entry(3) Documentación de Perl contribuida por el usuario CPAN::Changes::Entry(3)

NOMBRE

CPAN::Changes::Entry - Una entrada de cambio en un archivo Changes de CPAN

SINOPSIS

my $entry = CPAN::Changes::Entry->new(
  text    => 'Una entrada de cambio'
  entries => [
    'Una subentrada',
    'Otra subentrada',
  ],
);

DESCRIPCIÓN

Un registro de cambios se compone de uno o más lanzamientos. Este objeto proporciona acceso a todos los datos clave que conforman un lanzamiento, incluyendo el número de versión, la fecha del lanzamiento y todas las líneas de información del registro de cambios.

ATRIBUTOS

texto

El texto de la entrada de cambio.

entradas

Una referencia de array de subentradas bajo esta entrada de cambio.

linea

El número de línea en el que comienza la entrada de cambio.

MÉTODOS

serializar

Devuelve la entrada de cambios en formato de cadena.

clonar

Devuelve un nuevo objeto de lanzamiento con los mismos datos. Puede recibir cualquier atributo para establecerlo de manera diferente en el nuevo objeto.

tiene_entradas

Devuelve verdadero si hay subentradas para esta entrada.

buscar_entrada

Acepta una cadena o una expresión regular, devuelve un objeto de subentrada coincidente.

agregar_entrada

Agrega una subentrada de cambios. Acepta un objeto de subentrada de cambios o una cadena.

eliminar_entrada

Dada una cadena o un objeto de entrada de cambios, elimina la entrada del lanzamiento.
