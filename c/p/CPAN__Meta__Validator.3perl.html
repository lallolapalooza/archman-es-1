CPAN::Meta::Validator(3perl) Guía del programador de Perl CPAN::Meta::Validator(3perl)

NOMBRE

CPAN::Meta::Validator - valida estructuras de metadatos de distribuciones CPAN

VERSIÓN

version 2.150010

SINOPSIS

my $struct = decode_json_file('META.json');
my $cmv = CPAN::Meta::Validator->new( $struct );
unless ( $cmv->is_valid ) {
  my $msg = "Estructura META inválida. Errores encontrados:\n";
  $msg .= join( "\n", $cmv->errors );
  die $msg;
}

DESCRIPCIÓN

Este módulo valida una estructura de metadatos CPAN contra la versión de la especificación declarada en el campo "meta-spec" de la estructura.

MÉTODOS

new

my $cmv = CPAN::Meta::Validator->new( $struct )

El constructor debe recibir una estructura de metadatos.

is_valid

if ( $cmv->is_valid ) {
  ...
}

Devuelve un valor booleano indicando si los metadatos proporcionados son válidos.

errors

warn( join "\n", $cmv->errors );

Devuelve una lista de errores encontrados durante la validación.
