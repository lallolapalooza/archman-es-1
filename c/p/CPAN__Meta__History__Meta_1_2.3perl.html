DESCRIPCIÓ

N

Este documento describe la versión 1.2 de la especificación META.

yml.

El archivo META.yml describe propiedades importantes de distribuciones de Perl contribuidas, como las que se encuentran en CPAN. Se crea típicamente con herramientas como Module::Build, Module::Install y ExtUtils::

MakeMaker.

Los campos en el archivo META.yml están pensados para ser útiles para personas que mantienen colecciones de módulos (como CPAN), para quienes escriben herramientas de instalación (como CPAN.pm o CPANPLUS), o simplemente para quienes quieren saber algunas cosas sobre una distribución antes de descargarla y empezar a

instalarla.

Nota: La última versión estable de esta especificación siempre se puede encontrar en http://module-build.sourceforge.net/META-spec-current.html, y la última versión de desarrollo (que puede incluir cosas que no llegarán a la versión estable) siempre se puede encontrar en http://module-build.sourcefo

rge.net/META-sp
ec-blead.html.

ESPECIFICACIONES DE

VERSIÓN

Algunos campos requieren una especificación de versión (p. ej. "requires", "recommends", "build_requires", etc.). Esta sección detalla las especificaciones de versión que se admiten

actualmente.

Si se indica una sola versión, entonces esa versión se considera la versión mínima

admitida.

Si se indica 0 como número de versión, entonces se admite cualquier

versión.

Además, para requisitos más complicados, la especificación admite una lista de versiones, cada una de las cuales puede ir precedida opcionalmente por un operador

relacional.

Los operadores admitidos incluyen < (menor que), <= (menor o igual), > (mayor que), >= (mayor o igual), == (igual) y != (distinto de)

.

Si se indica una lista, se evalúa de izquierda a derecha de modo que cualquier especificación de la lista que entre en conflicto con una especificación anterior es anulada por la

posterior.

Ejemplos

: 
>= 1.2, != 1.5, < 2.
0

Cualquier versión desde la versión 1.2

en adelante, excepto la versión 1.5,
que además preceda a la versión 2.0.
