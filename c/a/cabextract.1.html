CABEXTRACT(1) Manual de Comandos Generales CABEXTRACT(1)

NOMBRE

cabextract - programa para extraer archivos de archivos Microsoft cabinet (.cab)

SINOPSIS

cabextract [-ddir] [-ecodificación] [-f] [-Fpatrón] [-h] [-i] [-k] [-l] [-L] [-n] [-p] [-q] [-s] [-t] [-v] archivos cabinet ...

DESCRIPCIÓN

cabextract es un programa que descomprime archivos en el formato de archivo cabinet de Microsoft (.cab) o cualquier archivo binario que contenga un archivo cabinet incrustado (frecuentemente encontrado en archivos .exe).

cabextract extraerá todos los archivos de todos los archivos cabinet especificados en la línea de comandos.

Para extraer un cabinet de varias partes que consta de varios archivos, solo se necesita proporcionar el primer archivo cabinet como argumento a cabextract, ya que buscará automáticamente los archivos restantes. Para evitar que cabextract extraiga archivos cabinet que usted no especificó, use la opción -s.

OPCIONES

A continuación se incluye un resumen de las opciones.

-d dir
Extrae todos los archivos en el directorio dir.
-e codificación
Especifica la codificación de caracteres de los nombres de archivo dentro de los archivos cabinet. Esto solo es necesario si encuentra archivos cabinet con nombres de archivo corruptos; la mayoría del software crea archivos CAB con nombres de archivo ASCII o UTF8. La lista de codificaciones soportadas se da con el comando "iconv -l".
-f
Los archivos cabinet corruptos se 'repararán' para recuperar lo que sea posible de ellos. Las entradas de archivo con carpetas o nombres erróneos se omitirán en lugar de rechazar todo el archivo cabinet. Las longitudes de archivo imposibles se truncarán para extraer lo máximo posible, incluso si faltan archivos posteriores en un conjunto de cabinet. Los bloques MSZIP corruptos y las sumas de verificación de bloques fallidas se ignorarán. Se imprimirán advertencias si se cumplen alguna de estas condiciones.
-F patrón
Solo los archivos con nombres que coincidan con el patrón de shell patrón se listarán, probarán o extraerán. En sistemas que no son GNU, esta coincidencia puede distinguir entre mayúsculas y minúsculas. Use la opción repetidamente para proporcionar más de un patrón. Los archivos se listarán, probarán o extraerán si coinciden con cualquier patrón.
-h
Imprime una página de ayuda y sale.
-i
Pregunta antes de sobrescribir archivos.
-k
No sobrescribir enlaces simbólicos al extraer archivos.
-l
Lista el contenido de los archivos cabinet dados, en lugar de extraerlos.
-L
Al extraer archivos cabinet, convierte el nombre de cada archivo extraído a minúsculas.
-n
Nunca sobrescribir archivos existentes.
-p
Los archivos se extraerán a la salida estándar.
-q
Al extraer archivos cabinet, suprime todos los mensajes excepto los errores y advertencias.
-s
Al probar, listar o extraer cabinets que abarcan varios archivos, solo se utilizarán los archivos cabinet dados en la línea de comandos.
-t
Prueba la integridad del cabinet. Los archivos se descomprimen, pero no se escriben en disco ni en la salida estándar. Si el archivo se descomprime correctamente, se imprime la suma de verificación MD5 del archivo.
-v
Si se da solo en la línea de comandos, imprime la versión de cabextract y sale. Si se da con una lista de archivos cabinet, listará el contenido de los archivos cabinet.
