Carp::Always(3) Documentación de Perl aportada por el usuario Carp::Always(3)

NOMBRE

Carp::Always - Advierte y muere ruidosamente con trazas de pila

SINOPSIS

use Carp::Always;

A menudo se usa en la línea de comandos:

perl -MCarp::Always script.pl

DESCRIPCIÓN

Este módulo está pensado como una ayuda de depuración. Puede usarse para hacer que un script se queje ruidosamente con trazas de pila cuando realiza warn() o die().

Así es como se ven las trazas de pila producidas por este módulo:

# funciona para die's y warn's explícitos
$ perl -MCarp::Always -e 'sub f { die "arghh" }; sub g { f }; g'
arghh at -e line 1
        main::f() called at -e line 1
        main::g() called at -e line 1
# funciona para fallos lanzados por el intérprete
$ perl -MCarp::Always -w -e 'sub f { $a = shift; @a = @$a };' \
                         -e 'sub g { f(undef) }; g'
Use of uninitialized value in array dereference at -e line 1
        main::f('undef') called at -e line 2
        main::g() called at -e line 2

En la implementación, el módulo Carp hace el trabajo pesado, a través de longmess(). La implementación real establece los ganchos de señal $SIG{__WARN__} y $SIG{__DIE__} para emitir las trazas de pila.

Además, todos los usos de "carp" y "croak" se vuelven verbosos, comportándose como "cluck" y "confess".

MÉTODOS

Carp::Always implementa los siguientes métodos.

import

Carp::Always->import()

Habilita Carp::Always. También se activa mediante sentencias como

use Carp::Always;
use Carp::Always 0.14;

pero no mediante

use Carp::Always ();    # no invoca import()

unimport

Carp::Always->unimport();

Deshabilita Carp::Always. También se activa con

no Carp::Always;

AGRADECIMIENTOS

Este módulo nació como reacción a un lanzamiento de Acme::JavaTrace por Sébastien Aperghis-Tramoni. Sébastien también tiene un módulo más nuevo llamado Devel::SimpleTrace con el mismo código y menos comentarios flamígeros en la documentación. La poda de la documentación inútilmente larga de este módulo fue impulsada por Michael Schwern.

Schwern y otros me dijeron "el nombre del módulo apestaba"; se llamaba "Carp::Indeed". Después de pensar mucho y no llegar a nada, seguí la sugerencia de nuffin y ahora se llama "Carp::Always".

BUGS

  • Este módulo no se lleva bien con otros módulos que manipulan "warn", "die", $SIG{__WARN__}, $SIG{__DIE__}.
  • Los scripts de prueba son buenos. Debería escribir más de estos.

Por favor, informe de los errores a través de GitHub https://github.com/aferreira/cpan-Carp-Always/issues
