CARGO-RUSTDOC(1) Manual de Comandos Generales CARGO-RUSTDOC(1)

NOMBRE

cargo-rustdoc — Construye la documentación de un paquete, utilizando flags personalizados especificados

SINOPSIS

cargo rustdoc [opciones] [-- argumentos]

DESCRIPCIÓN

El target especificado para el paquete actual (o el paquete especificado por -p si se proporciona) será documentado con los argumentos especificados, que se pasarán a la invocación final de rustdoc. Las dependencias no se documentarán como parte de este comando. Tenga en cuenta que rustdoc aún recibirá incondicionalmente argumentos como -L, --extern y --crate-type, y los argumentos especificados simplemente se añadirán a la invocación de rustdoc.

Consulte https://doc.rust-lang.org/rustdoc/index.html para obtener documentación sobre los flags de rustdoc.

Este comando requiere que solo se compile un target cuando se proporcionan argumentos adicionales. Si hay más de un target disponible para el paquete actual, se deben usar los filtros de --lib, --bin, etc., para seleccionar qué target se compila.

Para pasar flags a todos los procesos de rustdoc iniciados por Cargo, utilice la variable de entorno RUSTDOCFLAGS https://doc.rust-lang.org/cargo/reference/environment-variables.html o el valor de configuración build.rustdocflags https://doc.rust-lang.org/cargo/reference/config.html.

OPCIONES

Opciones de documentación

--open

Abre la documentación en un navegador después de compilarla. Esto utilizará su navegador predeterminado a menos que defina otro en la variable de entorno BROWSER o utilice la opción de configuración doc.browser https://doc.rust-lang.org/cargo/reference/config.html#doc-browser.

Selección de paquetes

Por defecto, se selecciona el paquete en el directorio de trabajo actual. El flag -p se puede usar para elegir un paquete diferente en un espacio de trabajo.

-p espec, --package espec

El paquete a documentar. Consulte cargo-pkgid(1) para el formato ESPEC.

Selección de target

Cuando no se especifican opciones de selección de target, cargo rustdoc documentará todos los targets binarios y de biblioteca del paquete seleccionado. Se omitirá el binario si su nombre es el mismo que el del target de la biblioteca. Se omitirán los binarios si tienen required-features que no se cumplen.

Los flags de selección de target documentarán solo los targets especificados.

Tenga en cuenta que los flags --bin, --example, --test y --bench también admiten patrones glob comunes de Unix como *, ? y []. Sin embargo, para evitar que su shell expanda accidentalmente los patrones glob antes de que Cargo los maneje, debe usar comillas simples o dobles alrededor de cada patrón glob.

--lib

Documenta la biblioteca del paquete.

--bin nombre…

Documenta el binario especificado. Este flag puede especificarse varias veces y admite patrones glob comunes de Unix.

--bins

Documenta todos los targets binarios.

--example nombre…

Documenta el ejemplo especificado. Este flag puede especificarse varias veces y admite patrones glob comunes de Unix.

--examples

Documenta todos los targets de ejemplo.

--test nombre…

Documenta la prueba de integración especificada. Este flag puede especificarse varias veces y admite patrones glob comunes de Unix.

--tests

Documenta todos los targets que tienen establecido el flag de manifiesto test = true. Por defecto, esto incluye la biblioteca y los binarios compilados como pruebas unitarias, y las pruebas de integración. Tenga en cuenta que esto también compilará las dependencias requeridas, por lo que el target de la biblioteca puede compilarse dos veces (una como prueba unitaria y otra como dependencia para binarios, pruebas de integración, etc.). Los targets pueden habilitarse o deshabilitarse estableciendo el flag test en la configuración del manifiesto para el target.

--bench nombre…

Documenta el benchmark especificado. Este flag puede especificarse varias veces y admite patrones glob comunes de Unix.

--benches

Documenta todos los targets que tienen establecido el flag de manifiesto bench = true. Por defecto, esto incluye la biblioteca y los binarios compilados como benchmarks, y los targets de benchmark. Tenga en cuenta que esto también compilará las dependencias requeridas, por lo que el target de la biblioteca puede compilarse dos veces (una como benchmark y otra como dependencia para binarios, benchmarks, etc.). Los targets pueden habilitarse o deshabilitarse estableciendo el flag bench en la configuración del manifiesto para el target.

--all-targets

Documenta todos los targets. Esto es equivalente a especificar --lib --bins --tests --benches --examples.

Selección de características

Los flags de características permiten controlar qué características se habilitan. Cuando no se proporcionan opciones de características, se activa la característica default para cada paquete seleccionado.

Consulte la documentación de características https://doc.rust-lang.org/cargo/reference/features.html#command-line-feature-options para obtener más detalles.

-F características, --features características

Lista de características a activar, separadas por espacios o comas. Las características de los miembros del espacio de trabajo pueden habilitarse con la sintaxis nombre-del-paquete/nombre-de-característica. Este flag puede especificarse varias veces, lo que habilita todas las características especificadas.

--all-features

Activa todas las características disponibles de todos los paquetes seleccionados.

--no-default-features

No activa la característica default de los paquetes seleccionados.

Opciones de compilación

--target triple

Documenta para la arquitectura de target especificada. El flag puede especificarse varias veces. El valor predeterminado es la arquitectura del host. El formato general de la triple es <arch><sub>-<vendor>-<sys>-<abi>.

Posibles valores:

•Cualquier target compatible en rustc --print target-list.
•"triple-del-host", que se sustituirá internamente por el target de la máquina host. Esto puede ser particularmente útil si estás compilando cruzadamente algunos crates y no quieres especificar la máquina de tu host como target (por ejemplo, un xtask en un proyecto compartido que puede ser trabajado por varios hosts).
•Una ruta a una especificación de target personalizada. Consulte Ruta de búsqueda de target personalizado https://doc.rust-lang.org/rustc/targets/custom.html#custom-target-lookup-path para más información.

Esto también puede especificarse con el valor de configuración build.target https://doc.rust-lang.org/cargo/reference/config.html.

Tenga en cuenta que especificar este flag hace que Cargo funcione en un modo diferente donde los artefactos de target se colocan en un directorio separado. Consulte la documentación del caché de compilación https://doc.rust-lang.org/cargo/reference/build-cache.html para más detalles.

-r, --release

Documenta artefactos optimizados con el perfil release. Consulte también la opción --profile para elegir un perfil específico por nombre.
