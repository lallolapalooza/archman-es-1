RESUME

N

Cairo proporciona enlaces de Perl para la biblioteca de gráficos ve

ctoriales cairo. Admite múltiples destinos de salida, incluyendo PNG, P
DF y SVG. Cairo produce una salida idéntica en todos esos destinos.

cairo

ll".

Rutas -- Creación de rutas y manipulación de datos de

ruta 
$path = [
  { type => "move-to", points => [[1, 2]] },
  { type => "line-to", points => [[3, 4]] },
  { type => "curve-to", points => [[5, 6], [7, 8], [9, 10]] },
  ...
  { type => "close-path", points => [] },
]
;

Cairo::Path es una estructura de datos para contener una ruta. Esta estructura de datos sirve como valor de retorno para "$cr->copy_path" y "$cr->copy_path_flat" así como valor de entrada para "$cr->append_

path".

Cairo::Path se representa como una referencia a un array que contiene elementos de ruta, representados por referencias a hashes con dos claves: type y points. El valor para type puede ser cualquiera de los

siguientes:
"move-t
o"
"line-t
o"
"curve-t
o"
"close-pat
h"

El valor para points es una referencia a un array que contiene cero o más puntos. Los puntos se representan como referencias a arrays que contienen dos dobles: x y y. El número necesario de puntos depende del tipo del elemento de la

ruta:
"move-to": 1
punto
"line_to": 1
punto
"curve-to": 3
puntos
"close-path": 0
puntos

La semántica y el orden de los valores de las coordenadas son consistentes con "$cr->move_to", "$cr->line_to", "$cr->curve_to", y "$cr->close_

path".

Ten en cuenta que las rutas devueltas por Cairo se implementan como referencias a arrays vinculadas que no soportan la adición, eliminación o reordenamiento de segmentos de ruta. Para estas operaciones, necesitas hacer primero una copia

superficial: 
my @path_clone = @{$path};
# ahora puedes alterar @path_clone como
quieras

Los puntos de un solo elemento de la ruta pueden cambiarse directamente, sin embargo, sin necesidad de una copia

superficial: 
$path->[$i]{points} = [[3, 4], [5, 6], [7, 8]]
;
