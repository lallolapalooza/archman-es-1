Descripción detallada

Estas funciones proporcionan rutinas de alto nivel para la inserción, eliminación, copia, etc. de marcos de lienzo.

__extern int caca_set_frame (caca_canvas_t * cv, int id)

Establece el marco activo del lienzo. Todas las operaciones de dibujo posteriores se realizarán en ese marco. El contexto de pintura actual establecido por caca_set_attr() se hereda.

Si el índice del marco está fuera del rango de marcos del lienzo, no ocurre nada.

Si se produce un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL El marco solicitado está fuera de rango.

Parámetros

cv Un lienzo de libcaca
id El marco del lienzo a activar

Devuelve

0 en caso de éxito, -1 si se produjo un error.

__extern int caca_set_frame_name (caca_canvas_t * cv, char const * name)

Establece el nombre del marco actual. Al crearse, un marco tiene un nombre predeterminado de 'frame#xxxxxxxx' donde xxxxxxxx es un número hexadecimal autoincremental.

__extern int caca_create_frame (caca_canvas_t * cv, int id)

Crea un nuevo marco dentro del lienzo dado. Sus contenidos y atributos se copian del marco actualmente activo.

El índice del marco indica dónde debe insertarse el marco. Los valores válidos van desde 0 hasta el recuento de marcos del lienzo actual. Si el índice del marco es mayor o igual que el recuento de marcos del lienzo actual, el nuevo marco se añade al final del lienzo. Si el índice del marco es menor que cero, el nuevo marco se inserta en el índice 0.

El marco activo no cambia, pero su índice puede renumerarse debido a la inserción.

Si se produce un error, se devuelve -1 y errno se establece en consecuencia:

•
ENOMEM No hay suficiente memoria para asignar el nuevo marco.

Parámetros

cv Un lienzo de libcaca
id El índice donde insertar el nuevo marco

Devuelve

0 en caso de éxito, -1 si se produjo un error.

Referenciado por caca_set_canvas_boundaries().

__extern int caca_free_frame (caca_canvas_t * cv, int id)

Elimina un marco de un lienzo dado.

El índice del marco indica el marco a eliminar. Los valores válidos van desde 0 hasta el recuento de marcos del lienzo actual menos 1. Si el índice del marco es mayor o igual que el recuento de marcos del lienzo actual, se elimina el último marco.

Si se elimina el marco activo, el marco 0 se convierte en el nuevo marco activo. De lo contrario, el marco activo no cambia, pero su índice puede renumerarse debido a la eliminación.

Si se produce un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL El marco solicitado está fuera de rango, o se intentó eliminar el último marco del lienzo.

Parámetros

cv Un lienzo de libcaca
id El índice del marco a eliminar

Devuelve

0 en caso de éxito, -1 si se produjo un error.
