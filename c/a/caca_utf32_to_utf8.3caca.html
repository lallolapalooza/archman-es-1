Estas funciones realizan conversiones entre conjuntos de caracteres habituales.

Documentación de funciones

__extern uint32_t caca_utf8_to_utf32 (char const * s, size_t * bytes)

Convierte un carácter UTF-8 leído de una cadena y devuelve su valor en el conjunto de caracteres UTF-32. Si el segundo argumento no es nulo, se escribe en él el número total de bytes leídos.

Si se alcanzó un byte nulo antes del final esperado de la secuencia UTF-8, esta función devuelve cero y el número de bytes leídos se establece en cero.

Esta función nunca falla, pero su comportamiento con secuencias UTF-8 ilegales no está definido.

Parámetros

s Una cadena que contiene el carácter UTF-8.
bytes Un puntero a un size_t para almacenar el número de bytes del carácter, o NULL.

Retorna

El carácter UTF-32 correspondiente, o cero si el carácter está incompleto.

Referenciado por caca_put_str().

__extern size_t caca_utf32_to_utf8 (char * buf, uint32_t ch)

Convierte un carácter UTF-32 leído de una cadena y escribe su valor en el conjunto de caracteres UTF-8 en el búfer dado.

Esta función nunca falla, pero su comportamiento con caracteres UTF-32 ilegales no está definido.

Parámetros

buf Un puntero a un búfer de caracteres donde se escribirá la secuencia UTF-8.
ch El carácter UTF-32.

Retorna

El número de bytes escritos.

__extern uint8_t caca_utf32_to_cp437 (uint32_t ch)

Convierte un carácter UTF-32 leído de una cadena y devuelve su valor en el conjunto de caracteres CP437, o '?' si el carácter no tiene un equivalente.

Esta función nunca falla.

Parámetros

ch El carácter UTF-32.

Retorna

El carácter CP437 correspondiente, o '?' si no es representable.

__extern uint32_t caca_cp437_to_utf32 (uint8_t ch)

Convierte un carácter CP437 leído de una cadena y devuelve su valor en el conjunto de caracteres UTF-32, o cero si el carácter es un carácter de control CP437.

Esta función nunca falla.

Parámetros

ch El carácter CP437.

Retorna

El carácter UTF-32 correspondiente, o cero si no es representable.

__extern char caca_utf32_to_ascii (uint32_t ch)

Convierte un carácter UTF-32 en un carácter ASCII. Cuando no existe un equivalente, se busca un equivalente gráficamente cercano.

Esta función nunca falla, pero su comportamiento con caracteres UTF-32 ilegales no está definido.

Parámetros

ch El carácter UTF-32.

Retorna

El carácter ASCII correspondiente, o un equivalente gráficamente cercano si se encuentra, o '?' si no es representable.

__extern int caca_utf32_is_fullwidth (uint32_t ch)

Comprueba si el carácter UTF-32 dado debe imprimirse con el doble de ancho normal (caracteres de ancho completo). Si el carácter es desconocido o si su estado no se puede determinar, se trata como un carácter de ancho estándar.

Esta función nunca falla.

Parámetros

ch El carácter UTF-32.

Retorna

1 si el carácter es de ancho completo, 0 en caso contrario.

Referenciado por caca_put_char() y caca_put_str().
