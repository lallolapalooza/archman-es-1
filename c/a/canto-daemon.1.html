Canto-daemon(1) Manual de comandos generales Canto-daemon(1)

NOMBRE

Canto-daemon - Un demonio extensible de agregación de RSS.

USO DE LÍNEA DE COMANDOS

canto-daemon (opciones)

OPCIONES

-V/--version
Imprimir información de la versión y salir.
-h/--help
Imprimir ayuda de uso
-v
Habilitar registro detallado (depuración)
-D/--dir [directorio]
Cambiar el directorio base para canto-daemon (por defecto: $XDG_CONFIG_HOME/canto)
-n/--nofetch
No buscar contenido nuevo mientras se ejecuta (depuración).
--noplugins
Deshabilitar todos los plugins
--enableplugins 'plugin1 plugin2...'
Habilitar estos plugins (anula --noplugins)
--disableplugins 'plugin1 plugin2...'
Deshabilitar estos plugins
-a/--address [IP]
Escuchar en la dirección además del socket Unix local. Usar "" para todas las interfaces. Por defecto es el loopback (127.0.0.1)
-p/--port [puerto]
Usar puerto al escuchar con -a

CONFIGURACIÓN

Este demonio gestiona su propia configuración y debe ser manipulado a través de canto-remote o un cliente, como canto-curses.

PLUGINS

Los plugins están empaquetados en <prefix>/canto/plugins (es decir, /usr/lib/canto/plugins) y se pueden habilitar copiándolos a su directorio de configuración (es decir, $XDG_CONFIG_HOME/canto/plugins). Muchos de ellos tienen configuración interna, por lo que es posible que desee abrir los archivos para realizar cambios. Aquí hay algunos plugins de ejemplo incluidos con el código fuente de canto-daemon.

reddit.py
Añade contenido a los elementos de reddit. Incluye un ordenamiento reddit_score_sort que ordenará automáticamente los elementos por votos.
sync-rsync.py
Un plugin de sincronización basado en rsync. Ver la cabecera para la configuración, se puede usar para sincronizar con un servidor remoto vía SSH, o con otro sistema de archivos local (para NFS/sshfs/Dropbox/gdrive etc.)
sync-inoreader.py
Sincroniza (la mayoría de) el contenido con inoreader.com, un servicio con soporte para RSS en la web, así como varios dispositivos móviles.

ARCHIVOS

$XDG_CONFIG_HOME/canto/daemon-log

Archivo de registro de Canto-daemon.

$XDG_CONFIG_HOME/canto/plugins/

Directorio de plugins de Canto-daemon

/usr/lib/canto/plugins

Directorio de plugins empaquetados por defecto.
