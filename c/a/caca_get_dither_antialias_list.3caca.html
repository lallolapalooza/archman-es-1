__extern caca_dither_t * caca_create_dither (int bpp, int w, int h, int pitch, uint32_t rmask, uint32_t gmask, uint32_t bmask, uint32_t amask)

Crea una estructura de difuminado a partir de sus coordenadas (profundidad, ancho, alto y paso) y valores de máscara de píxeles. Si la profundidad es de 8 bits por píxel, los valores de máscara se ignoran y la paleta de colores debe establecerse usando la función caca_set_dither_palette(). Para profundidades mayores a 8 bits por píxel, una máscara alfa cero hace que los valores alfa se ignoren.

Si ocurre un error, se devuelve NULL y se establece errno en consecuencia:

  • EINVAL El valor solicitado de ancho, alto, paso o bits por píxel fue inválido.
  • ENOMEM No hay suficiente memoria para asignar la estructura de difuminado.

Parámetros

bpp Profundidad del mapa de bits en bits por píxel.
w Ancho del mapa de bits en píxeles.
h Alto del mapa de bits en píxeles.
pitch Paso del mapa de bits en bytes.
rmask Máscara de bits para los valores rojos.
gmask Máscara de bits para los valores verdes.
bmask Máscara de bits para los valores azules.
amask Máscara de bits para los valores alfa.

Devuelve

Objeto de difuminado en caso de éxito, NULL si ocurrió un error.

__extern int caca_set_dither_palette (caca_dither_t * d, uint32_t red[], uint32_t green[], uint32_t blue[], uint32_t alpha[])

Establece la paleta de un mapa de bits de 8 bits por píxel. Los valores deben estar entre 0 y 4095 (0xfff).

Si ocurre un error, se devuelve -1 y se establece errno en consecuencia:

•
EINVAL El valor de bits por píxel del difuminado no es 8, o uno de los valores de píxel estaba fuera del rango 0 - 4095.

Parámetros

d Objeto de difuminado.
red Arreglo de 256 valores rojos.
green Arreglo de 256 valores verdes.
blue Arreglo de 256 valores azules.
alpha Arreglo de 256 valores alfa.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_dither_bitmap (caca_canvas_t * cvs, int x, int y, int w, int h, caca_dither_t const * d, void const * bitmap)

Difumina un mapa de bits en el lienzo. El mapa de bits de entrada se espera que esté en formato nativo del sistema, pero el objeto caca_dither_t puede realizar una conversión si es necesario. El área del lienzo se define mediante la posición (x, y) y las dimensiones (w, h). Esto permite la superposición de mapas de bits y el uso de áreas de lienzo más pequeñas que el mapa de bits original.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL Los parámetros de entrada no son válidos.
•
ENOMEM No hay suficiente memoria para realizar la operación.

Parámetros

cvs Lienzo de destino.
x Coordenada X de la esquina superior izquierda del área del lienzo.
y Coordenada Y de la esquina superior izquierda del área del lienzo.
w Ancho del área del lienzo.
h Alto del área del lienzo.
d Objeto de difuminado.
bitmap Puntero al mapa de bits de entrada.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_set_dither_antialias (caca_dither_t * d, char const * str)

Tell the renderer whether to antialias the dither. Antialiasing smoothens the rendered image and avoids the commonly seen staircase effect.

  • 'none': no antialiasing.
  • 'prefilter' or 'default': simple prefilter antialiasing. This is the default value.

If an error occurs, -1 is returned and errno is set accordingly:

•
EINVAL Invalid antialiasing mode.

Parameters

d Dither object.
str A string describing the antialiasing method that will be used for the dithering.

Returns

0 in case of success, -1 if an error occurred.

__extern int caca_set_dither_color (caca_dither_t * d, char const * str)

Tell the renderer which colours should be used to render the bitmap. Valid values for str are:

  • 'mono': use light gray on a black background.
  • 'gray': use white and two shades of gray on a black background.
  • '8': use the 8 ANSI colours on a black background.
  • '16': use the 16 ANSI colours on a black background.
  • 'fullgray': use black, white and two shades of gray for both the characters and the background.
  • 'full8': use the 8 ANSI colours for both the characters and the background.
  • 'full16' or 'default': use the 16 ANSI colours for both the characters and the background. This is the default value.

If an error occurs, -1 is returned and errno is set accordingly:

•
EINVAL Invalid colour set.

Parameters

d Dither object.
str A string describing the colour set that will be used for the dithering.

Returns

0 in case of success, -1 if an error occurred.

__extern int caca_set_dither_algorithm (caca_dither_t * d, char const * str)

Tell the renderer which dithering algorithm should be used. Dithering is necessary because the picture being rendered has usually far more colours than the available palette. Valid values for str are:

  • 'none': no dithering is used, the nearest matching colour is used.
  • 'ordered2': use a 2x2 Bayer matrix for dithering.
  • 'ordered4': use a 4x4 Bayer matrix for dithering.
  • 'ordered8': use a 8x8 Bayer matrix for dithering.
  • 'random': use random dithering.
  • 'fstein': use Floyd-Steinberg dithering. This is the default value.

If an error occurs, -1 is returned and errno is set accordingly:

•
EINVAL Unknown dithering mode.

Parameters

d Dither object.
str A string describing the algorithm that needs to be used for the dithering.

Returns

0 in case of success, -1 if an error occurred.
