calfjackhost(1) Manual de Comandos Generales calfjackhost(1)

NOMBRE

calfjackhost - Envoltorio JACK para plugins Calf

SINOPSIS

calfjackhost [opciones] plugin[:preset] [!] ...

DESCRIPCIÓN

La aplicación host JACK Calf JACK permite usar los plugins Calf directamente, sin necesidad de ninguna aplicación host externa. También ofrece la mejor funcionalidad de interfaz gráfica (usando el conjunto de widgets GTK+ 2), ya que no hay ningún estándar de plugin restrictivo interponiéndose entre la interfaz gráfica y el código de procesamiento de audio.

OPCIONES

-c --client nombre
establece el nombre del cliente JACK (el nombre que usa calfjackhost al registrarse en JACK)
-i --input nombre
prefijo de nombre para las entradas de audio
-o --output nombre
prefijo de nombre para las salidas de audio
-m --midi nombre
prefijo de nombre para las entradas MIDI
-c --connect-midi cliente:puerto
conecta automáticamente todos los puertos MIDI a cliente:puerto
-M --connect-midi !n
conecta automáticamente todos los puertos MIDI a system:midi_capture_n
-v --version
imprime una cadena de versión (calf algún.número.de.versión)
-l --load sesión
Carga el estado de la sesión desde un archivo
-s --state sesión
Carga el estado de la sesión desde un archivo, si dicho archivo existe
-L --list
Lista todos los plugins disponibles
-h -? --help
imprime un texto de ayuda
-t --no-tray
deshabilita el icono de la bandeja al inicio

Un signo de exclamación (!) en lugar del nombre del plugin significa conexión automática. Si "!" se coloca antes del primer nombre de plugin, el primer plugin tiene sus entradas conectadas a system:capture_1 y system:capture_2. Si se coloca entre nombres de plugin, esos plugins se conectan entre sí (la salida del primer plugin se conecta a la entrada del segundo). Si se coloca después del último nombre de plugin, las salidas de audio de ese plugin se conectan a system:playback_1 y system:playback_2 (primer par de salidas).

ERRORES

Por favor, envíe informes de errores a <wdev@foltman.com>.

EJEMPLOS

Para iniciar monosynth con conexión automática a la primera salida de audio del sistema y sin conexión MIDI automática, use:


calfjackhost monosynth !

(! significa "conectar", el último "!" significa "conectar a la salida")

Otros ejemplos:


calfjackhost monosynth ! vintagedelay ! flanger ! -M 2

(ejecuta monosynth en vintagedelay y vintagedelay en flanger, luego a la salida; conecta la entrada MIDI de monosynth a system:midi_capture_2 de JACK)


calfjackhost "monosynth:Fat Bass"

(ejecuta monosynth con el preset Fat Bass en monosynth, no auto-conecta)


calfjackhost ! reverb !

(toma la señal de system:capture_1 y _2, la pasa por el reverb, y luego la envía a system:playback_1 y _2)

Nota: ninguna de las funciones de conexión automática funcionará si la autoconexión está deshabilitada por motivos de gestión de sesiones.
