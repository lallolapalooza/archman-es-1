Descripción Detallada

Estas funciones proporcionan rutinas de impresión de caracteres de bajo nivel y funciones gráficas de alto nivel.

__extern int caca_put_char (caca_canvas_t * cv, int x, int y, uint32_t ch)

Imprime un carácter ASCII o Unicode en las coordenadas dadas, utilizando los valores de color de primer plano y de fondo predeterminados.

Si las coordenadas están fuera de los límites del lienzo, no se imprime nada. Si un carácter Unicode de ancho completo es sobrescrito, sus partes visibles restantes se reemplazan con espacios. Si los límites del lienzo dividieran el carácter de ancho completo en dos, se imprimirá un espacio en su lugar.

El comportamiento al imprimir caracteres no imprimibles o caracteres UTF-32 no válidos no está definido. Para imprimir una secuencia de bytes que forman un carácter UTF-8 en lugar de un carácter UTF-32, use la función caca_put_str().

Esta función devuelve el ancho del carácter impreso. Si es un carácter de ancho completo, devuelve 2. De lo contrario, devuelve 1.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.
ch El carácter a imprimir.

Devoluciones

El ancho del carácter impreso: 2 para un carácter de ancho completo, 1 en caso contrario.

Referencias caca_add_dirty_rect(), CACA_MAGIC_FULLWIDTH, y caca_utf32_is_fullwidth().

Referenciado por caca_conio_cgets(), caca_conio_cputs(), caca_conio_putch(), caca_dither_bitmap(), caca_fill_box(), caca_fill_triangle(), caca_flush_figlet(), caca_put_figchar(), y caca_put_str().

__extern uint32_t caca_get_char (caca_canvas_t const * cv, int x, int y)

Obtiene el valor ASCII o Unicode del carácter en las coordenadas dadas. Si el valor es menor o igual a 127 (0x7f), el carácter se puede imprimir como ASCII. De lo contrario, debe tratarse como un valor UTF-32.

Si las coordenadas están fuera de los límites del lienzo, se devuelve un espacio (0x20).

Una excepción especial es cuando se devuelve CACA_MAGIC_FULLWIDTH. Este valor no es un carácter Unicode válido garantizado y indica que el carácter a la izquierda del solicitado es un carácter de ancho completo.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.

Devoluciones

El carácter Unicode en las coordenadas dadas.

Referenciado por caca_flush_figlet(), y caca_put_figchar().

__extern int caca_put_str (caca_canvas_t * cv, int x, int y, char const * str)

Imprime una cadena de caracteres en el lienzo en las coordenadas dadas. La cadena debe estar codificada en UTF-8. La función avanza el cursor por el número de caracteres impresos. Si una cadena contiene caracteres de ancho completo, los píxeles correspondientes se llenarán con espacios en blanco y el cursor avanzará por dos unidades.

Si las coordenadas están fuera de los límites del lienzo, no se imprime nada. Si una cadena contiene caracteres no imprimibles o secuencias UTF-8 inválidas, el comportamiento no está definido.

Esta función devuelve el número de caracteres impresos en el lienzo. Si se imprime un carácter de ancho completo, se considera como dos caracteres.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.
str La cadena UTF-8 a imprimir.

Devoluciones

El número de caracteres impresos.

Referencias caca_add_dirty_rect(), caca_put_char(), y caca_utf8_to_utf32().

Referenciado por caca_conio_cprintf(), caca_conio_cputs(), caca_conio_printf(), caca_flush_figlet(), y caca_put_figstr().

__extern int caca_printf (caca_canvas_t * cv, int x, int y, char const * fmt,...)

Imprime una cadena formateada en el lienzo en las coordenadas dadas. La cadena debe estar codificada en UTF-8. La función avanza el cursor por el número de caracteres impresos.

Los argumentos de formato son los mismos que los de printf(). Tenga en cuenta que no todos los caracteres de formato son compatibles (por ejemplo, la conversión de flotantes).

Esta función delega a caca_vprintf().

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.
fmt Cadena de formato.

Devoluciones

El número de caracteres impresos.

__extern int caca_set_canvas_handle (caca_canvas_t * cv, int x, int y)

Establece la posición del identificador del lienzo. El identificador se utiliza para posicionar el texto y otros elementos dentro del lienzo. Las funciones que hacen uso del identificador utilizarán los nuevos valores.

Establecer la posición del identificador fuera de los límites del lienzo es legal, pero el identificador no se mostrará. El comportamiento con identificadores fuera de los límites es indefinido.

Esta función nunca falla.

y Posición Y del identificador.

__extern int caca_blit (caca_canvas_t * dst, int x, int y, caca_canvas_t const * src, caca_canvas_t const * mask)

__extern int caca_set_canvas_boundaries (caca_canvas_t * cv, int x, int y, int width, int height)

Establece nuevos límites para el lienzo. Cualquier operación que se salga de estos límites será truncada. Las coordenadas (x, y) son la esquina superior izquierda de los nuevos límites, y width y height son el ancho y alto de los nuevos límites, respectivamente.

Establecer límites más allá del tamaño original del lienzo es legal, pero puede llevar a un comportamiento inesperado en algunas funciones. Establecer un ancho o alto negativo o cero desactiva la función de límites.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X de la esquina superior izquierda de los límites.
y Coordenada Y de la esquina superior izquierda de los límites.
width Ancho de los límites.
height Altura de los límites.

Devoluciones

Esta función siempre devuelve 0.
