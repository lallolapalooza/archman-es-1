NOMBRE

calc_tickadj - Calcula el valor óptimo de tick dado un archivo de deriva ntp.

SINOPSIS

calc_tickadj [-flags] [-flag [valor]] [--nombre-opcion[[=| ]valor]]

Todos los argumentos deben ser opciones.

DESCRIPCIÓN

El script calc_tickadj utiliza el archivo de deriva ntp proporcionado para generar un valor de tick óptimo. Generalmente, ntpd puede hacer un mejor trabajo si el valor de deriva es el número más pequeño posible.

El ejemplo de salida de 

$ ./calc_tickadj
81.699 (deriva)
9999 usec; 9999779 nsec
$ cat /etc/ntp/drift
-23.159

significa lo siguiente. Si el tick en esa máquina es 10,000, al hacer el valor 9999, cambiaremos la máquina de su deriva actual de -23.159 a una deriva de 81.699, y al hacerlo aceleraremos un poco el reloj cada segundo en lugar de ralentizarlo un poco.

Si el 'tick' en esa máquina es 10,000,000, entonces al establecerlo en 9999779, el valor de deriva estará alrededor de 0.0.

calc_tickadj intenta determinar el valor del tick utilizando el programa tickadj del paquete ntp. Si esto no funciona, puede especificar el tick actual manualmente en la línea de comandos.

OPCIONES

-d cadena, --archivo-deriva=cadena

Archivo de deriva de Ntp a utilizar. El valor predeterminado de cadena para esta opción es:
/etc/ntp/drift

Utilice el archivo de deriva especificado para los cálculos

-t número, --tick=número

Valor de tick de este host. Esta opción toma un número entero como argumento.

El tick actual para el cual se calculará el ajuste

-?, --ayuda

Muestra información de uso y sale.
-!, --mas-ayuda

Pasa la información de uso extendida a través de un paginador.
-v [{v|c|n --version [{v|c|n}]}]

Muestra la versión del programa y sale. El modo predeterminado es `v', una versión simple. El modo `c' mostrará información de derechos de autor y `n' mostrará el aviso de derechos de autor completo.
