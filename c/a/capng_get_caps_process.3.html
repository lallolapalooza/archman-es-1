capng_get_caps_process(3)

CAPNG_GET_CAPS_PROCESS(3) API de Libcap-ng CAPNG_GET_CAPS_PROCESS(3)

NOMBRE

capng_get_caps_process - obtener las capacidades de un proceso

SINOPSIS

#include <cap-ng.h>

int capng_get_caps_process(void);

DESCRIPCIÓN

capng_get_caps_process obtendrá las capacidades y el conjunto de límites del pid almacenado en la tabla de estado de libcap-ng. El valor por defecto es el pid del proceso en ejecución. Esto se puede cambiar utilizando la función capng_setpid.

VALOR DE RETORNO

Devuelve 0 en caso de éxito y -1 en caso de fallo.

NOTAS

Si estás realizando programación multihilo, llamar a esta función solo obtendrá las capacidades del hilo que la llama. Si deseas obtener las capacidades generales de un proceso multihilo, solo puedes hacerlo antes de crear ningún hilo. Después, los hilos pueden ser capaces de establecer capacidades de forma independiente.

capng_get_caps_process necesita un /proc montado para leer el conjunto de límites actual, de lo contrario fallará.

VER TAMBIÉN

capng_setpid(3), capabilities(7)
