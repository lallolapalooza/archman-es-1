NOMBRE

cargo-check - Comprueba la compilación de un paquete sin generar artefactos de compilación.

SINOPSIS

cargo check [opciones]

DESCRIPCIÓN

Este comando compila el crate actual y sus dependencias, pero omite la generación de artefactos de compilación. Esto es más rápido que cargo-build(1) y es útil para comprobar si el código se compila sin tener que esperar a que se generen los artefactos.

En caso de encontrar errores, cargo-check(1) saldrá con un código de error no nulo. Si el crate no tiene errores, saldrá con 0.

OPCIONES

Todas las opciones del comando cargo-build(1) son aplicables a cargo-check(1).

--profile NOMBRE
Selecciona un perfil de compilación. Cargo viene con los siguientes perfiles predefinidos:
default
El perfil predeterminado. Es el perfil utilizado si no se especifica ninguno. Tiene optimizaciones habilitadas.
dev
El perfil utilizado para las compilaciones de depuración (cuando se usa cargo-run(1) o cargo-test(1)). Tiene optimizaciones deshabilitadas y depuración habilitada.
release
El perfil utilizado para las compilaciones de lanzamiento (cuando se usa cargo-build(1) con la opción --release). Tiene optimizaciones habilitadas.
--future-incompatible
Muestra un informe de incompatibilidad futura para cualquier advertencia de incompatibilidad futura producida durante la ejecución de este comando.

Ver cargo-report(1)

AMBIENTE

Ver la referencia https://doc.rust-lang.org/cargo/reference/environment-variables.html para detalles sobre las variables de entorno que Cargo lee.

CÓDIGO DE SALIDA

•0: Cargo completado con éxito.
•101: Cargo no pudo completarse.

EJEMPLOS

1. Comprueba el paquete local en busca de errores: 
cargo check
2. Comprueba todos los objetivos, incluidas las pruebas unitarias: 
cargo check --all-targets --profile=test
