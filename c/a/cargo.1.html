CARGO(1) Manual de Comandos Generales CARGO(1)

NOMBRE

cargo — El gestor de paquetes de Rust

SINOPSIS

cargo [opciones] comando [argumentos]
cargo [opciones] --version
cargo [opciones] --list
cargo [opciones] --help
cargo [opciones] --explain código

DESCRIPCIÓN

Este programa es un gestor de paquetes y herramienta de compilación para el lenguaje Rust, disponible en https://rust-lang.org.

COMANDOS

Comandos de compilación

cargo-bench(1)
Ejecutar las pruebas de rendimiento de un paquete.

cargo-build(1)
Compilar un paquete.

cargo-check(1)
Comprobar un paquete local y todas sus dependencias en busca de errores.

cargo-clean(1)
Eliminar los artefactos que Cargo ha generado en el pasado.

cargo-doc(1)
Compilar la documentación de un paquete.

cargo-fetch(1)
Obtener las dependencias de un paquete desde la red.

cargo-fix(1)
Corregir automáticamente las advertencias de lint reportadas por rustc.

cargo-run(1)
Ejecutar un binario o un ejemplo del paquete local.

cargo-rustc(1)
Compilar un paquete y pasar opciones adicionales al compilador.

cargo-rustdoc(1)
Compilar la documentación de un paquete, usando banderas personalizadas especificadas.

cargo-test(1)
Ejecutar las pruebas unitarias y de integración de un paquete.

Comandos de manifiesto

cargo-add(1)
Añadir dependencias a un archivo de manifiesto Cargo.toml .

cargo-generate-lockfile(1)
Generar el archivo Cargo.lock de un proyecto.

cargo-info(1)
Mostrar información sobre un paquete en el registro. El registro por defecto es crates.io.

cargo-locate-project(1)
Imprimir una representación JSON de la ubicación de un archivo Cargo.toml .

cargo-metadata(1)
Mostrar las dependencias resueltas de un paquete en un formato legible por máquina.

cargo-pkgid(1)
Imprimir una especificación de paquete completamente calificada.

cargo-remove(1)
Eliminar dependencias de un archivo de manifiesto Cargo.toml .

cargo-tree(1)
Mostrar una visualización en árbol del grafo de dependencias.

cargo-update(1)
Actualizar las dependencias registradas en el archivo de bloqueo local.

cargo-vendor(1)
Proveer todas las dependencias localmente.

Comandos de paquete

cargo-init(1)
Crear un nuevo paquete de Cargo en un directorio existente.

cargo-install(1)
Compilar e instalar un binario de Rust.

cargo-new(1)
Crear un nuevo paquete de Cargo.

cargo-search(1)
Buscar paquetes en crates.io.

cargo-uninstall(1)
Eliminar un binario de Rust.

Comandos de publicación

cargo-login(1)
Guardar localmente un token de API del registro.

cargo-logout(1)
Eliminar localmente un token de API del registro.

cargo-owner(1)
Gestionar los propietarios de un crate en el registro.

cargo-package(1)
Ensamblar el paquete local en un tarball distribuible.

cargo-publish(1)
Subir un paquete al registro.

cargo-yank(1)
Eliminar un crate subido del índice.

Comandos generales

cargo-help(1)
Mostrar información de ayuda sobre Cargo.

cargo-version(1)
Mostrar la información de la versión.

OPCIONES

Opciones especiales

-V, --version

Imprimir la información de la versión y salir. Si se usa con --verbose, imprime información adicional.

--list

Listar todos los subcomandos de Cargo instalados. Si se usa con --verbose, imprime información adicional.

--explain código

Ejecutar rustc --explain CODE lo que imprimirá una explicación detallada de un mensaje de error (por ejemplo, E0004).

Opciones de visualización

-v, --verbose

Usar salida detallada. Puede especificarse dos veces para una salida «muy detallada» que incluye salida adicional como advertencias de dependencias y la salida del script de compilación. También puede especificarse con el term.verbose valor de configuración https://doc.rust-lang.org/cargo/reference/config.html.

-q, --quiet

No imprimir los mensajes de registro de cargo. También puede especificarse con el term.quiet valor de configuración https://doc.rust-lang.org/cargo/reference/config.html.

--color cuándo

Controlar cuándo se usa la salida con color. Valores válidos:
•auto (por defecto): Detectar automáticamente si el terminal soporta color.
•always: Mostrar siempre colores.
•never: Nunca mostrar colores.

También puede especificarse con el term.color valor de configuración https://doc.rust-lang.org/cargo/reference/config.html.

Opciones de manifiesto
