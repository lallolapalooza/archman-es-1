DESCRIPTION

The caca library provides a simple API to create and manage text-based images. It aims to provide a rich set of features for the creation of text-mode graphics, like drawing primitives, colors, fonts, image import and export, and event handling.

Canvas Management

A canvas is the drawing surface of the library. It is a rectangular buffer of characters and attributes.

The following functions manage the canvas:

caca_create_canvas
Creates a new canvas of the given width and height.
caca_delete_canvas
Deletes a canvas and frees its associated resources.
caca_clear_canvas
Clears the entire canvas.
caca_get_canvas_width
Returns the width of the canvas.
caca_get_canvas_height
Returns the height of the canvas.
caca_set_canvas_size
Resizes the canvas.
caca_set_canvas_handle_brightness
Sets the brightness handling mode for the canvas.
caca_set_canvas_handle_brightness_range
Sets the brightness range for the canvas.
caca_set_canvas_utf8
Enables or disables UTF-8 character handling for the canvas.
caca_set_canvas_limits
Sets the maximum width and height for the canvas.
caca_set_canvas_dirty
Marks the canvas as dirty, indicating that it needs to be redrawn.

Drawing Primitives

The library provides functions to draw basic shapes and characters on a canvas.

caca_draw_text
Draws a string of text on the canvas.
caca_draw_box
Draws a box on the canvas.
caca_draw_cpu
Draws a CPU character on the canvas.
caca_draw_line
Draws a line on the canvas.
caca_draw_pixel
Draws a single character (pixel) on the canvas.
caca_draw_thin_box
Draws a thin box on the canvas.
caca_draw_thin_line
Draws a thin line on the canvas.
caca_draw_thin_pixel
Draws a thin single character (pixel) on the canvas.
caca_put_str
Puts a string of characters on the canvas.

Canvas Content Access

These functions allow reading and writing individual characters and attributes on the canvas.

caca_get_char
Returns the character at the specified coordinates.
caca_get_attr
Returns the attribute at the specified coordinates.
caca_set_char
Sets the character at the specified coordinates.
caca_set_attr
Sets the attribute at the specified coordinates.

Color and Style

Manage color depth, inversion, boundaries, gamma correction, and styles.

caca_set_color_depth
Sets the color depth of the canvas.
caca_invert_canvas
Inverts the colors of the canvas.
caca_set_boundary
Sets a clipping boundary on the canvas.
caca_reset_boundary
Resets the clipping boundary.
caca_apply_gamma_correction
Applies gamma correction to the canvas.
caca_set_style
Sets the drawing style for the canvas.
caca_get_style
Returns the current drawing style of the canvas.

Fonts

Manage fonts for drawing.

caca_get_font_list
Returns a list of available font names.
caca_load_font
Loads a font by name.
caca_load_bitmap_font
Loads a font from a memory buffer.
caca_load_charfont
Loads a character font from a memory buffer.
caca_free_font
Frees a loaded font.
caca_set_font
Sets the font to be used for drawing on a canvas.
caca_set_handle_width
Sets the width of the character cells.
caca_set_handle_height
Sets the height of the character cells.

Import and Export

Import image data into a canvas or export canvas content to various formats.

caca_import_area_from_memory
Imports an area from a memory buffer into the canvas.
caca_import_area_from_file
Imports an area from a file into the canvas.
caca_get_import_list
Returns a list of supported import formats.
caca_export_canvas_to_memory
Exports the entire canvas to a memory buffer in a specified format.
caca_export_area_to_memory
Exports a specific area of the canvas to a memory buffer.
caca_get_export_list
Returns a list of supported export formats.

Display Management

Manage the display output and events.

caca_create_display
Creates a display context attached to a canvas.
caca_create_display_with_driver
Creates a display context with a specific driver.
caca_get_display_driver_list
Returns a list of available display drivers.
caca_get_display_driver
Returns the name of the current display driver.
caca_set_display_driver
Sets the display driver.
caca_free_display
Frees a display context.
caca_get_canvas
Returns the canvas associated with a display context.
caca_refresh_display
Refreshes the display, showing any pending changes.
caca_set_display_time
Sets the display refresh delay.
caca_get_display_time
Returns the average rendering time of the display.
caca_get_display_width
Returns the width of the display.
caca_get_display_height
Returns the height of the display.
caca_set_display_title
Sets the title of the display window.
caca_set_mouse
Shows or hides the mouse pointer.
caca_set_cursor
Shows or hides the text cursor.

Event Handling

Handle keyboard and mouse input events.

caca_get_event
Retrieves the next input event.
caca_get_mouse_x
Returns the X coordinate of the mouse pointer.
caca_get_mouse_y
Returns the Y coordinate of the mouse pointer.
caca_get_event_type
Returns the type of an event.
caca_get_event_key_ch
Returns the character code of a key event.
caca_get_event_key_utf32
Returns the UTF-32 code of a key event.
caca_get_event_key_utf8
Returns the UTF-8 string of a key event.
caca_get_event_mouse_button
Returns the mouse button associated with a mouse event.
caca_get_event_mouse_x
Returns the X coordinate of a mouse event.
caca_get_event_mouse_y
Returns the Y coordinate of a mouse event.
caca_get_event_resize_width
Returns the new width from a resize event.
caca_get_event_resize_height
Returns the new height from a resize event.

Argument Parsing

A function similar to the standard `getopt` function.

caca_getopt
Parses command-line options.

DOS Conio.h Equivalents

caca_conio_cgets
Reads a string from the console.
caca_conio_clreol
Clears the line from the cursor to the end.
caca_conio_clrscr
Clears the entire screen.
caca_conio_cprintf
Prints formatted output to the console.
caca_conio_cputs
Prints a string to the console.
caca_conio_cscanf
Reads formatted input from the console.
caca_conio_delay
Pauses execution for a specified time.
caca_conio_delline
Deletes the current line.
caca_conio_getch
Reads a character from the console without echo.
caca_conio_getche
Reads a character from the console with echo.
caca_conio_getpass
Reads a password from the console.
caca_conio_gettext
Copies text from a specified screen area.
caca_conio_gettextinfo
Gets information about the current text mode.
caca_conio_gotoxy
Moves the cursor to a specified position.
caca_conio_highvideo
Sets the text to high-intensity video.
caca_conio_insline
Inserts a blank line at the current cursor position.
caca_conio_kbhit
Checks if a key has been pressed.
caca_conio_lowvideo
Sets the text to low-intensity video.
caca_conio_movetext
Moves a block of text from one screen location to another.
caca_conio_normvideo
Restores normal video intensity.
caca_conio_nosound
Disables sound.
caca_conio_printf
Prints formatted output to the console.
caca_conio_putch
Writes a character to the console.
caca_conio_puttext
Writes text to a specified screen area.
caca_conio__setcursortype
Sets the cursor type.
caca_conio_sleep
Pauses execution for a specified time.
caca_conio_sound
Generates a sound.
caca_conio_textattr
Sets the current text attributes (color and intensity).
caca_conio_textbackground
Sets the background color.
caca_conio_textcolor
Sets the foreground color.
caca_conio_textmode
Sets the text mode.
caca_conio_ungetch
Pushes a character back onto the keyboard buffer.
caca_conio_wherex
Returns the current X cursor position.
caca_conio_wherey
Returns the current Y cursor position.
caca_conio_window
Sets the active text window.
