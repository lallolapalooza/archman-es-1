NOMBRE

caca-config - script para obtener información sobre la versión instalada de libcaca

SINOPSIS

caca-config [ --prefix= DIR] [ --exec-prefix= DIR] [ --version ] [ --libs ] [ --cflags ]

DESCRIPCIÓN

caca-config es una herramienta que se utiliza para configurar y determinar las banderas del compilador y del enlazador que deben usarse para compilar y enlazar programas, bibliotecas y complementos que utilizan libcaca.

El uso de caca-config está obsoleto. Se debe utilizar la herramienta más genérica pkg-config en su lugar.

OPCIONES

--cflags
Imprime las banderas del compilador que son necesarias para compilar un programa o biblioteca que utiliza libcaca.
--exec-prefix=DIR
Si se especifica, usa DIR en lugar del prefijo de ejecución de instalación con el que se compiló libcaca al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes de cualquiera de las opciones --cflags y --libs.
--libs
Imprime las banderas del enlazador que son necesarias para enlazar un programa o biblioteca que utiliza libcaca.
--prefix=DIR
Si se especifica, usa PREFIX en lugar del prefijo de instalación con el que se compiló libcaca al calcular la salida para las opciones --cflags y --libs. Esta opción también se utiliza para el prefijo de ejecución si no se especificó --exec-prefix. Esta opción debe especificarse antes de cualquiera de las opciones --cflags y --libs.
--version
Imprime la versión actualmente instalada de libcaca en la salida estándar.

EJEMPLOS

gcc -o main.o $(caca-config --cflags) -c main.c
es cómo podrías usar caca-config para compilar un archivo fuente C para un programa ejecutable.
gcc -o my_app $(caca-config --libs) main.o util.o
es cómo podrías usar caca-config para enlazar objetos compilados en un programa ejecutable.
