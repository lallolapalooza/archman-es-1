CAPNG_LOCK(3) API de Libcap-ng CAPNG_LOCK(3)

NOMBRE

capng_lock - bloquea la configuración de capacidades del proceso actual

SINOPSIS

#include <cap-ng.h>

int capng_lock(void);

DESCRIPCIÓN

capng_lock tomará medidas para evitar que los hijos del proceso actual recuperen privilegios completos si el uid es 0. Esto debe llamarse mientras se posee la capacidad CAP_SETPCAP en el kernel. Esta función hará lo siguiente si el kernel lo permite: establecer la opción NOROOT en activado para PR_SET_SECUREBITS, establecer la opción NOROOT_LOCKED en activado para PR_SET_SECUREBITS, establecer la opción PR_NO_SETUID_FIXUP en activado para PR_SET_SECUREBITS, y establecer la opción PR_NO_SETUID_FIXUP_LOCKED en activado para PR_SET_SECUREBITS.

VALOR DE RETORNO

Devuelve 0 en caso de éxito y un número negativo en caso de fallo. -1 significa un fallo al establecer cualquiera de las opciones de PR_SET_SECUREBITS.

VER TAMBIÉN

capng_apply(3), prctl(2), capabilities(7)
