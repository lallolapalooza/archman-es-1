NOMBRE

cacaview - visor de imágenes ASCII

SINOPSIS

cacaview [ARCHIVO...]

DESCRIPCIÓN

cacaview es un visor de imágenes ligero en modo texto. Renderiza imágenes usando caracteres ASCII a color. Es un potente complemento para programas famosos de consola como el cliente de correo mutt, el lector de noticias slrn y los navegadores web links o w3m.

cacaview puede cargar los formatos de imagen más extendidos: PNG, JPEG, GIF, PNG, BMP, etc.

Puedes hacer zoom y desplazar la imagen para ver más detalles, y elegir cuatro modos de difuminado diferentes. Todos los comandos son accesibles con una sola pulsación de tecla.

TECLAS

?
mostrar la pantalla de ayuda
n, p
cambiar a la siguiente imagen, imagen anterior
"Izquierda, Derecha, Arriba, Abajo o h, l, k, j"
desplazar la imagen
+, -
acercar y alejar
z
restablecer el nivel de zoom a normal
f
conmutar modo de pantalla completa (ocultar/mostrar barras de menú y estado)
d
conmutar el modo de difuminado (sin difuminado, difuminado ordenado 4x4, difuminado ordenado 8x8 y difuminado aleatorio)
q
salir del programa

EJEMPLO

cacaview /usr/share/pixmaps/*.*

ERRORES

Todavía no hay soporte para la relación de aspecto. Además, dado que aún no hay forma de cargar una imagen desde cacaview, es completamente inútil cuando se ejecuta sin argumentos.

VER TAMBIÉN

img2txt(1)
