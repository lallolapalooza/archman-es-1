NOMBRE

cache_restore - restaura el archivo de metadatos de caché a un dispositivo o archivo.

SINOPSIS

cache_restore [opciones] -i {archivo xml} -o {dispositivo|archivo}

DESCRIPCIÓN

cache_restore restaura los metadatos de caché creados por el destino respectivo del mapeador de dispositivos volcados en un archivo con formato XML (ver cache_dump(8)), que opcionalmente pueden ser preprocesados antes de restaurarlos a otro dispositivo o archivo. Si se restaura a un dispositivo de metadatos, los metadatos pueden ser procesados por el destino del mapeador de dispositivos.

Esta herramienta no puede ejecutarse sobre metadatos en vivo.

OPCIONES

-h, --help
Imprime la ayuda y sale.
-V, --version
Imprime la información de la versión y sale.
-q, --quiet
No imprime ninguna salida. Comprueba el código de salida para probar el éxito.
-i, --input {archivo xml}
Entrada xml.
-o, --output {dispositivo|archivo}
Archivo o dispositivo de salida para los metadatos binarios restaurados.
    Si se usa un archivo, este debe estar preasignado y ser lo
    suficientemente grande para contener los metadatos.
--metadata-version {1|2}
Elige una versión de metadatos.

OPCIONES DE DEPURACIÓN

--debug-override-metadata-version {entero}
Anula la versión almacenada en los metadatos.
--omit-clean-shutdown
No establece el indicador de apagado limpio.

EJEMPLO

Restaura los metadatos de caché con formato XML en el archivo `metadata` al volumen lógico `/dev/vg/metadata` para su posterior procesamiento por el destino del mapeador de dispositivos correspondiente:

    $ cache_restore -i metadata -o /dev/vg/metadata

DIAGNÓSTICOS

cache_restore devuelve un código de salida de 0 para éxito o 1 para error.

VER TAMBIÉN

cache_dump(8), cache_check(8), cache_repair(8)
