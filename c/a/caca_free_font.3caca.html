__extern caca_font_t * caca_load_font (void const * data, size_t

size)

Esta función carga una fuente y devuelve un manejador a su estructura interna. El manejador puede usarse después con caca_render_canvas() para salida en mapa de

bits.

También se pueden cargar fuentes internas: si size se establece en 0, data debe ser una cadena que contenga el nombre de la fuente

interna.

Si size es distinto de cero, los size bytes de memoria en la dirección data se cargan como una fuente. Esta memoria no debe ser liberada por el programa que llama hasta que el manejador de la fuente haya sido liberado con caca_free_f

ont().

Si ocurre un error, se devuelve NULL y errno se establece en

consecuencia:
  • ENOENT La fuente incorporada solicitada no
    • existe.
  • EINVAL Datos de fuente inválidos en el área de
    • memoria.
  • ENOMEM No hay suficiente
    • memoria para asignar la
estructura de la fuente.

Parámetro

s
data El área de memoria que contiene la fuente o su nombre.
size El tamaño del área de memoria, o 0 si se da el nombre de la
fuente.
