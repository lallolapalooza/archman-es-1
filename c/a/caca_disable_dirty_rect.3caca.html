Descripción detallada

Estas funciones manipulan rectángulos sucios para un blitting optimizado.

Documentación de funciones

__extern int caca_disable_dirty_rect (caca_canvas_t * cv)

Desactiva el manejo de rectángulos sucios para todas las llamadas gráficas de libcaca . Esto es útil cuando la aplicación que llama necesita realizar operaciones lentas dentro de un área conocida. Simplemente llame a caca_add_dirty_rect() después.

Esta función es recursiva. Los rectángulos sucios solo se vuelven a activar cuando se llama a caca_enable_dirty_rect() tantas veces.

Esta función nunca falla.

Parámetros

cv Un lienzo de libcaca.

Devuelve

Esta función siempre devuelve 0.

__extern int caca_enable_dirty_rect (caca_canvas_t * cv)

Esta función solo puede ser llamada después de que caca_disable_dirty_rect() haya sido llamada.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL Los rectángulos sucios no estaban desactivados.

Parámetros

cv Un lienzo de libcaca.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_get_dirty_rect_count (caca_canvas_t * cv)

Obtiene el número de rectángulos sucios en un lienzo. Los rectángulos sucios son áreas que contienen celdas que han cambiado desde el último reinicio.

Los rectángulos sucios son usados internamente por los controladores de visualización para optimizar el renderizado evitando redibujar toda la pantalla. Una vez que el controlador de visualización ha renderizado el lienzo, restablece la lista de rectángulos sucios.

Se garantiza que los rectángulos sucios no se superponen.

Esta función nunca falla.

Parámetros

cv Un lienzo de libcaca.

Devuelve

El número de rectángulos sucios en el lienzo dado.

__extern int caca_get_dirty_rect (caca_canvas_t * cv, int r, int * x, int * y, int * width, int * height)

Obtiene las coordenadas del rectángulo sucio dado del lienzo. El índice debe estar dentro del recuento de rectángulos sucios. Vea caca_get_dirty_rect_count() para cómo calcular este recuento.

Si ocurre un error, no se escriben coordenadas en los argumentos de puntero, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL El índice de rectángulo especificado está fuera de los límites.

Parámetros

cv Un lienzo de libcaca.
r El índice del rectángulo solicitado.
x Un puntero a un entero donde se almacenará el borde más a la izquierda del rectángulo sucio.
y Un puntero a un entero donde se almacenará el borde más alto del rectángulo sucio.
width Un puntero a un entero donde se almacenará el ancho del rectángulo sucio.
height Un puntero a un entero donde se almacenará la altura del rectángulo sucio.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_add_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

Añade una zona de invalidación a la lista de rectángulos sucios del lienzo. Para más información sobre los rectángulos sucios, vea caca_get_dirty_rect().

Esta función puede ser útil para forzar la actualización de una zona dada del lienzo incluso si el seguimiento de rectángulos sucios indica que no ha cambiado. Esto puede ocurrir si el contenido del lienzo fue modificado de alguna manera directa.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL Las coordenadas del rectángulo especificado están fuera de los límites.

Parámetros

cv Un lienzo de libcaca.
x El borde más a la izquierda del rectángulo sucio adicional.
y El borde más alto del rectángulo sucio adicional.
width El ancho del rectángulo sucio adicional.
height La altura del rectángulo sucio adicional.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_remove_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

Marca un área de celdas en el lienzo como no sucia. Para más información sobre los rectángulos sucios, vea caca_get_dirty_rect().

Valores tales que xmin > xmax o ymin > ymax indican que el rectángulo sucio está vacío. Serán ignorados silenciosamente.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL Las coordenadas del rectángulo especificado están fuera de los límites.

Parámetros

cv Un lienzo de libcaca.
x El borde más a la izquierda del rectángulo limpio.
y El borde más alto del rectángulo limpio.
width El ancho del rectángulo limpio.
height La altura del rectángulo limpio.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

NAME

caca_clear_canvas - clear the canvas

SYNOPSIS

#include <cacaca.h>

void caca_clear_canvas(caca_canvas_t *cv);

DESCRIPTION

The caca_clear_canvas function fills the entire canvas with the current background and foreground colours.

PARAMETERS

cv
A libcaca canvas.

RETURNS

This function does not return a value.

EXAMPLE

This function is used in the example program libcaca.

void
caca_clear_canvas (caca_canvas_t * cv)
{
    int x, y;
    caca_color_t color;

    color = caca_get_color_cache (cv, cv->attr.fg, cv->attr.bg);
    for (y = 0; y < cv->height; y++)
    {
        for (x = 0; x < cv->width; x++)
        {
            cv->buf[y * cv->width + x] = color;
        }
    }
    caca_clear_dirty_rect_list (cv);
}

caca_clear_dirty_rect_list

Empty the canvas's dirty rectangle list.

This function never fails.

Parameters

cv A libcaca canvas.

Returns

This function always returns 0.
