__extern ssize_t caca_import_canvas_from_memory ( caca_canvas_t * cv, void const * data, size_t len, char const * format)
Importa un búfer de memoria en el marco actual del lienzo de libcaca proporcionado. El marco actual se redimensiona en consecuencia y su contenido se reemplaza con los datos importados. Los valores válidos para format son: '': intenta autodetectar el formato del archivo. 'caca': importa archivos nativos de libcaca. 'text': importa archivos de texto ASCII.'ansi': importa archivos ANSI. 'utf8': importa archivos UTF-8 con códigos de color ANSI. 'bin': importa archivos BIN.
Se devuelve el número de bytes leídos. Si el formato del archivo es válido, pero no había suficientes datos disponibles, se devuelve 0. Si ocurre un error, se devuelve -1 y errnose establece en consecuencia:

__extern void * caca_export_canvas_to_memory (caca_canvas_t const * cv, char const * format, size_t * bytes)

Esta función exporta un lienzo de libcaca a varios formatos externos como arte ANSI, HTML, colores de IRC, etc. El puntero devuelto debe pasarse a free() para liberar el almacenamiento asignado cuando ya no sea necesario.

Los valores válidos para format son:

  • 'caca': exporta archivos nativos de libcaca.
  • 'ansi': exporta arte ANSI (juego de caracteres CP437 con códigos de color ANSI).
  • 'html': exporta una página HTML con información CSS.
  • 'html3': exporta una tabla HTML que debería ser compatible con la mayoría de los navegadores, incluidos los de modo texto.
  • 'irc': exporta texto UTF-8 con códigos de color mIRC.
  • 'ps': exporta un documento PostScript.
  • 'svg': exporta una imagen vectorial SVG.
  • 'tga': exporta una imagen TGA.
  • 'troff': exporta un código fuente troff.

Si ocurre un error, se devuelve NULL y errno se establece en consecuencia:

  • EINVAL Formato solicitado no soportado.
  • ENOMEM No hay suficiente memoria para asignar el búfer de salida.

Parámetros

cv Un lienzo de libcaca
format Una cadena que describe el formato de salida solicitado.
bytes Un puntero a un size_t donde se escribirá el número de bytes asignados.

Devuelve

Un puntero al área de memoria exportada, o NULL en caso de error.

__extern void * caca_export_area_to_memory (caca_canvas_t const * cv, int x, int y, int w, int h, char const * format, size_t * bytes)

Esta función exporta una porción de un libcaca lienzo a varios formatos. Para más información, ver caca_export_canvas_to_memory().

Si ocurre un error, se devuelve NULL y errno se establece en consecuencia:

  • EINVAL Formato solicitado no soportado o coordenadas inválidas.
  • ENOMEM No hay suficiente memoria para asignar el búfer de salida.

format Una cadena que describe el formato de salida solicitado.
bytes Un puntero a un size_t donde se escribirá el número de bytes asignados.

Devuelve

Un puntero al área de memoria exportada, o NULL en caso de error.
