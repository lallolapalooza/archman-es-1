Descripción Detallada

Estas funciones proporcionan rutinas de alto nivel para la inserción, eliminación, copia, etc. de fotogramas de lienzo.

__extern int caca_set_frame (caca_canvas_t * cv, int id)

Establece el fotograma de lienzo activo. Todas las operaciones de dibujo posteriores se realizarán en ese fotograma. Se hereda el contexto de pintura actual establecido por caca_set_attr().

Si el índice del fotograma está fuera del rango de fotogramas del lienzo, no sucede nada.

Si ocurre un error, se devuelve -1 y se establece errno correspondientemente:

•
EINVAL El fotograma solicitado está fuera de rango.

Parámetros

cv Un lienzo de libcaca
id El fotograma del lienzo a activar

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern char const * caca_get_frame_name (caca_canvas_t const * cv)

Devuelve el nombre del fotograma actual. La cadena devuelta es válida hasta que el fotograma se elimina o se llama a caca_set_frame_name() para cambiar el nombre del fotograma de nuevo.

Esta función nunca falla.

cv Un lienzo de libcaca.

Devuelve

El nombre del fotograma actual.

__extern int caca_set_frame_name (caca_canvas_t * cv, char const * name)

Establece el nombre del fotograma actual. Al crearse, un fotograma tiene un nombre predeterminado de 'frame#xxxxxxxx' donde xxxxxxxx es un número hexadecimal autoincremental.

Si ocurre un error, se devuelve -1 y se establece errno correspondientemente:

•
ENOMEM No hay suficiente memoria para asignar el nuevo fotograma.

Parámetros

cv Un lienzo de libcaca.
name El nombre que se le dará al fotograma actual.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_create_frame (caca_canvas_t * cv, int id)

Crea un nuevo fotograma dentro del lienzo dado. Su contenido y atributos se copian del fotograma activo actual.

El índice del fotograma indica dónde se debe insertar el fotograma. Los valores válidos van de 0 al número actual de fotogramas del lienzo. Si el índice del fotograma es mayor o igual al número actual de fotogramas del lienzo, el nuevo fotograma se adjunta al final del lienzo. Si el índice del fotograma es menor que cero, el nuevo fotograma se inserta en el índice 0.

El fotograma activo no cambia, pero su índice puede ser renombrado debido a la inserción.

Si ocurre un error, se devuelve -1 y se establece errno correspondientemente:

•
ENOMEM No hay suficiente memoria para asignar el nuevo fotograma.

Parámetros

cv Un lienzo de libcaca
id El índice donde insertar el nuevo fotograma

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

Referenciado por caca_set_canvas_boundaries().

__extern int caca_free_frame (caca_canvas_t * cv, int id)

Elimina un fotograma de un lienzo dado.

El índice del fotograma indica el fotograma a eliminar. Los valores válidos van de 0 al número actual de fotogramas del lienzo menos 1. Si el índice del fotograma es mayor o igual al número actual de fotogramas del lienzo, se elimina el último fotograma.

Si se elimina el fotograma activo, el fotograma 0 se convierte en el nuevo fotograma activo. De lo contrario, el fotograma activo no cambia, pero su índice puede ser renombrado debido a la eliminación.

Si ocurre un error, se devuelve -1 y se establece errno correspondientemente:

•
EINVAL El fotograma solicitado está fuera de rango, o intento de eliminar el último fotograma del lienzo.

Parámetros

cv Un lienzo de libcaca
id El índice del fotograma a eliminar

Devuelve

0 en caso de éxito, -1 si ocurrió un error.
