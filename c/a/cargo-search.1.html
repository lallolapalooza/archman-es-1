CARGO-SEARCH(1) Manual de comandos generales CARGO-SEARCH(1)

NOMBRE

cargo-search — Busca paquetes en el registro. El registro predeterminado es crates.io

SINOPSIS

cargo search [opciones] [consulta…]

DESCRIPCIÓN

Esto realiza una búsqueda textual de crates en https://crates.io. Los crates coincidentes se mostrarán junto con sus descripciones en formato TOML adecuado para copiarlo en un manifiesto Cargo.toml.

OPCIONES

Opciones de búsqueda

--limit límite

Limita el número de resultados (predeterminado: 10, máximo: 100).

--index índice

La URL del índice del registro a usar.

--registry registro

Nombre del registro a usar. Los nombres de registro se definen en los archivos de configuración de Cargo https://doc.rust-lang.org/cargo/reference/config.html. Si no se especifica, se usa el registro predeterminado, que se define mediante la clave de configuración registry.default, que por defecto es crates-io.

Opciones de visualización

-v, --verbose

Usa salida detallada. Se puede especificar dos veces para una salida “muy detallada” que incluye información adicional como advertencias de dependencias y salida de scripts de compilación. También se puede especificar con el valor de configuración term.verbose https://doc.rust-lang.org/cargo/reference/config.html.

-q, --quiet

No imprime mensajes de registro de cargo. También se puede especificar con el valor de configuración term.quiet https://doc.rust-lang.org/cargo/reference/config.html.

--color cuándo

Controla cuándo se utiliza la salida con colores. Valores válidos:
•auto (predeterminado): Detecta automáticamente si el soporte de color está disponible en la terminal.
•always: Muestra siempre colores.
•never: Nunca muestra colores.

También se puede especificar con el valor de configuración term.color https://doc.rust-lang.org/cargo/reference/config.html.

Opciones comunes

+toolchain

Si Cargo se ha instalado con rustup, y el primer argumento para cargo comienza con +, se interpretará como un nombre de toolchain de rustup (como +stable o +nightly). Consulte la documentación de rustup https://rust-lang.github.io/rustup/overrides.html para obtener más información sobre cómo funcionan las anulaciones de toolchain.

--config CLAVE=VALOR o RUTA

Anula un valor de configuración de Cargo. El argumento debe estar en sintaxis TOML de CLAVE=VALOR, o proporcionarse como una ruta a un archivo de configuración adicional. Esta bandera se puede especificar varias veces. Consulte la sección de anulaciones de línea de comandos https://doc.rust-lang.org/cargo/reference/config.html#command-line-overrides para obtener más información.

-C RUTA

Cambia el directorio de trabajo actual antes de ejecutar cualquier operación especificada. Esto afecta a dónde busca cargo de forma predeterminada el manifiesto del proyecto (Cargo.toml), así como a los directorios que se buscan para descubrir .cargo/config.toml, por ejemplo. Esta opción debe aparecer antes del nombre del comando, por ejemplo cargo -C ruta/a/mi-proyecto build.

Esta opción solo está disponible en el canal nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html y requiere la bandera -Z unstable-options para habilitarse (consulte #10098 https://github.com/rust-lang/cargo/issues/10098).

-h, --help

Imprime información de ayuda.

-Z bandera

Banderas inestables (solo nightly) para Cargo. Ejecute cargo -Z help para obtener detalles.

ENTORNO

Consulte la referencia https://doc.rust-lang.org/cargo/reference/environment-variables.html para obtener detalles sobre las variables de entorno que Cargo lee.

ESTADO DE SALIDA

•0: Cargo tuvo éxito.
•101: Cargo no pudo completarse.

EJEMPLOS

1. Busca un paquete de crates.io: 
cargo search serde
