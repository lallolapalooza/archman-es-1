__extern caca_font_t * caca_load_font (void const * data, size_t

size)

Esta función carga una fuente y devuelve un identificador a su estructura interna. El identificador puede ser usado con caca_render_canvas() para salida de mapa de

bits.

También se pueden cargar fuentes internas: si size se establece en 0, data debe ser una cadena que contenga el nombre de la fuente

interna.

Si size no es cero, los size bytes de memoria en la dirección data se cargan como una fuente. Esta memoria no debe ser liberada por el programa que llama hasta que el identificador de la fuente haya sido liberado con caca_free_f

ont().

Si ocurre un error, se devuelve NULL y errno se establece en

consecuencia:
  • ENOENT La fuente integrada solicitada no
    • existe.
  • EINVAL Datos de fuente inválidos en el área de
    • memoria.
  • ENOMEM No hay suficiente
    • memoria para asignar la
estructura de la fuente.

Parámetro

s
data El área de memoria que contiene la fuente o su nombre.
size El tamaño del área de memoria, o 0 si se da el nombre de la
fuente.

Devuelv

__extern int caca_render_canvas (caca_canvas_t const * cv, caca_font_t const * f, void * buf, int width, int height, int

pitch)

Esta función renderiza el lienzo dado en un búfer de imagen usando una fuente específica. El formato de píxel es fijo (ARGB de 32 bits, 8 bits para cada componente)

.

El ancho de imagen requerido puede ser calculado usando caca_get_canvas_width() y caca_get_font_width(). La altura requerida puede ser calculada usando caca_get_canvas_height() y caca_get_font_h

futuras.
