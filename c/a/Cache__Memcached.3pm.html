DESCRIPCIÓ

N

Esta es la API de Perl para memcached, un daemon de caché en memoria distribuida. Hay más información disponible

en: http://www.danga.com/
memcached/

CONSTRUCTO

R
"ne
w"
Toma un parámetro, una referencia a hash de opciones. La clave más importante es "servers", pero también se puede establecer más adelante con el método "set_servers". Los servidores deben ser una referencia a array de hosts, cada uno de los cuales es o bien un escalar de la forma "10.0.0.10:11211" o una referencia a array del anterior y un valor entero de peso. (El peso predeterminado si no se especifica es 1.) Se recomienda que los valores de peso se mantengan lo más bajos posible, ya que este módulo actualmente asigna memoria para la distribución de buckets proporcional al peso total de los hosts.

Usa "compress_threshold" para establecer un umbral de compresión, en bytes. Los valores mayores que este umbral serán comprimidos por "set" y descomprimidos por "get

".

Usa "no_rehash" para desactivar la búsqueda de un nuevo servidor memcached cuando uno se cae. Tu aplicación puede o no necesitar esto, dependiendo de tus expiraciones y el uso de

claves.

Usa "readonly" para desactivar las escrituras en los servidores memcached de backend. Solo funcionarán get y get_multi. Esto es útil solo en casos extraños de depuración y

perfilado.

Usa "namespace" para anteponer a todas las claves el valor de espacio de nombres proporcionado. Es decir, si estableces namespace a "app1:" y luego haces un set de "foo" a "bar", memcached en realidad ve que estableces "app1:foo" a

"bar".

Usa "connect_timeout" y "select_timeout" para establecer los tiempos de espera de conexión y de sondeo. El "connect_timeout" tiene un valor predeterminado de .25 segundo, y el "select_timeout" tiene un valor predeterminado de 1

segundo.

La otra clave útil es "debug", que cuando se esta

blece en true
producirá
diagnósti
cos en STDERR.

Recupera una clave de la caché de memoria. Devuelve el valor (descongelado automáticamente con Storable, si es necesario) o

undef.

La $key puede ser opcionalmente una referencia a array, con el primer elemento siendo el valor hash, si quieres evitar que este módulo calcule un valor hash. Podrías preferir,

por ejemplo, mantener todos los objetos de un usuario dado en el mismo servi

Recupera múltiples claves de la caché de memoria haciendo solo una consulta. Devuelve una referencia a hash de pares clave/valor que estaban

disponibles.

Se recomienda este método sobre el 'get' regular, ya que reduce el número total d

t"

Establece incondicionalmente una clave a un valor dado en la caché de memoria. Devuelve true si se almacenó

correctamente.

La $key puede ser opcionalmente una referencia a array, con el primer elemento siendo el valor hash, como se describió

arriba.

El $exptime (tiempo de expiración) tiene un valor predeterminado de "never" si no se especifica. Si quieres que la clave expire en memcached, pasa un entero $exptime. Si el valor es menor que 60*60*24*30 (30 días), se asume que el tiempo es

relativo desde el presente. Si es mayor,
se considera un tiempo Unix absoluto.

$memd->delete($key[, $time]);

Elimina una clave. Puedes proporcionar opcionalmente un valor de tiempo entero (en segundos) para decirle al servidor memcached que bloquee nuevas escrituras a esta clave durante ese número de segundos. (A veces útil como un medio chapucero para prevenir carreras.) Devuelve true si la clave fue encontrada y eliminada, y false en caso

contrario.

También puedes usar el nombre de método alternativo remove, para que Cache::Memcach

"inc
r"
$memd->incr($key[, $value]);

Envía un comando al servidor para incrementar atómicamente el valor de $key en $value, o en 1 si $value está indefinido. Devuelve undef si $key no existe en el servidor, de lo contrario devuelve el nuevo valor después de incrementar. El valor debe ser cero o mayor. No se comprueba el desbordamiento en el servidor. Ten cuidado con los valores que se acerquen a 2**32.

$memd->decr($key[, $value]);

Como incr, pero decrementa. A diferencia de incr, se comprueba el desbordamiento negativo y los nuevos valores se limitan a 0. Si el valor del servidor es 1, una disminución de 2 devuelve 0,

no
-1.

Cierra todos los sockets en caché a todos los servidores de memcached. Debes hacer esto si tu progra

Ejecuta el comando "flush_all" de memcached en todos los hosts configu

ERRORE

S

Cuando un servidor se cae, este módulo lo detecta y re-hasea la petición a los servidores restantes,

pero la forma en que lo hace no es muy limpia. El resultado puede ser que se rinda durante su re-has
heo y se niegue a obtener/establecer algo que podría haber hecho, si se hubiera hecho correctamente.
