NOMBRE

Caja-connect-server - diálogo de Conectar al servidor para Caja

SINOPSIS

caja-connect-server [OPCIONES]

DESCRIPCIÓN

Caja Connect Server es el gestor de conexiones para Caja/MATE. Se proporciona como parte del paquete Caja para el Entorno de Escritorio MATE.

Simplemente ejecutando "caja-connection-server" se abrirá un simple diálogo que le permitirá seleccionar el tipo de servidor, y especificar la dirección del servidor, puerto y credenciales de inicio de sesión para el servidor al que desea conectarse. Este es el mismo diálogo al que se accede a través del menú "Archivo" de Caja, y del menú "Lugares" del Entorno de Escritorio MATE.

Puede usar el gestor de archivos de Caja para acceder a servidores remotos como SSH, FTP y Servidores WebDav (HTTP/HTTPS).

Si desea montar y acceder a servidores remotos a través de comandos de consola, debe usar caja directamente. Ver: caja(1)

OPCIONES

--display=DISPLAY
Pantalla X a usar.
-?, -h, --help
Imprimir opciones estándar de línea de comandos.
--help-all
Imprimir todas las opciones de línea de comandos.
