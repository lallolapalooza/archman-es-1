DESCRIPCIÓN DETALLADA

Estas funciones proporcionan las rutinas básicas de libcaca para la inicialización de la visualización, la recuperación de información del sistema y la configuración.

DOCUMENTACIÓN DE FUNCIONES

__extern caca_display_t * caca_create_display (caca_canvas_t * cv)

Crea un contexto gráfico utilizando características dependientes del dispositivo (ncurses para terminales, una ventana X11, una ventana de comandos de DOS...) que se adjunta a un lienzo de libcaca. Todo lo que se dibuje en el lienzo de libcaca puede ser mostrado por el controlador de libcaca.

Si no se proporciona ningún lienzo de caca, se crea uno nuevo. Su manejador se puede recuperar usando caca_get_canvas() y se destruye automáticamente cuando se llama a caca_free_display().

Tenga en cuenta que para lograr la máxima compatibilidad con Unicode, el código de inicialización del controlador puede cambiar temporalmente la configuración regional global LC_CTYPE del programa usando setlocale(). Se aconseja no llamar a funciones dependientes de LC_CTYPE desde otros hilos durante la llamada a caca_create_display(). La configuración regional se restaura cuando la función devuelve.

Ver también caca_create_display_with_driver().

Si ocurre un error, se devuelve NULL y se establece errno en consecuencia:

  • ENOMEM No hay suficiente memoria.
  • ENODEV No se pudo inicializar el dispositivo gráfico.

Parámetros

cv El lienzo de caca o NULL para crear un lienzo automáticamente.

Devoluciones

El contexto gráfico de caca o NULL si ocurrió un error.

Referencias caca_create_display_with_driver().

__extern caca_display_t * caca_create_display_with_driver (caca_canvas_t * cv, char const * driver)

Crea un contexto gráfico utilizando características dependientes del dispositivo (ncurses para terminales, una ventana X11, una ventana de comandos de DOS...) que se adjunta a un lienzo de caca. Todo lo que se dibuje en el lienzo de libcaca puede ser mostrado por el controlador de libcaca.

Si no se proporciona ningún lienzo de caca, se crea uno nuevo. Su manejador se puede recuperar usando caca_get_canvas() y se destruye automáticamente cuando se llama a caca_free_display().

Si no se proporciona el nombre del controlador, libcaca intentará autodetectar el mejor controlador de salida que pueda.

Ver también caca_create_display().

Si ocurre un error, se devuelve NULL y se establece errno en consecuencia:

  • ENOMEM No hay suficiente memoria.
  • ENODEV No se pudo inicializar el dispositivo gráfico.

Parámetros

cv El lienzo de caca o NULL para crear un lienzo automáticamente.
driver Una cadena que describe el controlador de salida deseado o NULL para elegir el mejor controlador automáticamente.

Devoluciones

El contexto gráfico de caca o NULL si ocurrió un error.

Referencias caca_create_canvas(), caca_free_canvas(), caca_manage_canvas() y caca_unmanage_canvas().

Referenciado por caca_create_display().

__extern char const *const * caca_get_display_driver_list (void )

Devuelve una lista de los controladores de visualización disponibles. La lista es un array de cadenas terminado en NULL, entrelazando una cadena que contiene el valor interno para el controlador de visualización, y una cadena que contiene la descripción en lenguaje natural para ese controlador.

Esta función nunca falla.

Devoluciones

Un array de cadenas.

__extern int caca_free_display (caca_display_t * dp)

Desvincula un contexto gráfico de su backend de caca y lo destruye. El lienzo de libcaca continúa existiendo y otros contextos gráficos pueden adjuntarse a él posteriormente.

Si el lienzo de caca fue creado automáticamente por caca_create_display(), se destruye automáticamente y cualquier manejador a él se vuelve inválido.

Esta función nunca falla.

Parámetros

dp El contexto gráfico de libcaca.

Devoluciones

Esta función siempre devuelve 0.

__extern int caca_refresh_display (caca_display_t * dp)

Vuelca todas las operaciones gráficas y las imprime en el dispositivo de visualización. Nada se mostrará en la pantalla hasta que se llame a esta función.

Si caca_set_display_time() fue llamado con un valor distinto de cero, caca_refresh_display() usará ese valor para lograr una tasa de refresco constante: si dos llamadas consecutivas a caca_refresh_display() están dentro de un intervalo de tiempo más corto que el valor establecido con caca_set_display_time(), la segunda llamada será retrasada antes de realizar la actualización de la pantalla.

Esta función nunca falla.

Parámetros

dp El contexto de visualización de libcaca.

Devuelve

Esta función siempre devuelve 0.

Referencias caca_clear_dirty_rect_list().

__extern int caca_set_display_time (caca_display_t * dp, int usec)

Establece el retardo de actualización en microsegundos. El retardo de actualización es usado por caca_refresh_display() para lograr una tasa de refresco constante. Consulte la documentación de caca_refresh_display() para más detalles.

Si el argumento es cero, la tasa de refresco constante se desactiva. Este es el comportamiento por defecto.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL El valor del retardo de actualización es inválido.

Parámetros

dp El contexto de visualización de libcaca.
usec El retardo de actualización en microsegundos.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_get_display_time (caca_display_t const * dp)

Obtiene el tiempo medio de renderizado, que es el tiempo medio medido entre dos llamadas a caca_refresh_display() , en microsegundos. Si la tasa de refresco constante fue activada llamando a caca_set_display_time(), el tiempo medio de renderizado estará cerca del retardo solicitado incluso si el tiempo real de renderizado fue más corto.

Esta función nunca falla.

Parámetros

dp El contexto de visualización de libcaca.

Devuelve

El tiempo de renderizado en microsegundos.

__extern int caca_get_display_width (caca_display_t const * dp)

Si libcaca se ejecuta en una ventana, obtiene el ancho útil de la ventana. Este valor puede usarse para el cálculo de la relación de aspecto. Si libcaca no se ejecuta en una ventana o si no hay forma de conocer el tamaño de la fuente, la mayoría de los controladores asumirán que se está usando una fuente de 6x10. Tenga en cuenta que las unidades no son necesariamente píxeles.

Esta función nunca falla.

Parámetros

dp El contexto de visualización de libcaca.

Devuelve

El ancho de la visualización.

__extern int caca_set_display_title (caca_display_t * dp, char const * title)

Si libcaca se ejecuta en una ventana, intenta cambiar su título. Esto funciona con los controladores ncurses, S-Lang, OpenGL, X11 y Win32.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
ENOSYS El controlador de visualización no soporta establecer el título de la ventana.

Parámetros

dp El contexto de visualización de libcaca.
title El título de visualización deseado.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_set_mouse (caca_display_t * dp, int flag)

Muestra u oculta el puntero del ratón. Esta función funciona con los controladores ncurses, S-Lang y X11.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
ENOSYS El controlador de visualización no soporta ocultar el puntero del ratón.

Parámetros

dp El contexto de visualización de libcaca.
flag 0 oculta el puntero, 1 muestra el puntero por defecto del sistema (usualmente una flecha). Otros valores están reservados para uso futuro.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.
