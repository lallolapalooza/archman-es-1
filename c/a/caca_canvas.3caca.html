__extern int caca_put_str (caca_canvas_t * cv, int x, int y, char const * s)

Imprime una cadena UTF-8 en las coordenadas dadas, usando los valores de primer plano y fondo predeterminados. Las coordenadas pueden estar fuera de los límites del lienzo (por ejemplo, una coordenada Y negativa) y la cadena se recortará en consecuencia si es demasiado larga.

Consulte caca_put_char() para obtener más información sobre cómo se manejan los caracteres de ancho completo al sobrescribirse entre sí o en los límites del lienzo.

Esta función devuelve el número de celdas impresas por la cadena. No es el número de caracteres impresos, porque los caracteres de ancho completo cuentan para dos celdas.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.
s La cadena a imprimir.

Retorna

El número de celdas impresas.

Referencias a caca_put_char(), caca_utf32_is_fullwidth(), y caca_utf8_to_utf32().

__extern int caca_set_canvas_boundaries (caca_canvas_t * cv, int x, int y, int w, int h)

Establece nuevos límites para un lienzo. Esta función se puede utilizar para recortar un lienzo, expandirlo o para combinaciones de ambas acciones. Todos los fotogramas se ven afectados por esta función.

Si ocurre un error, se devuelve -1 y se establece errno en consecuencia:

  • EINVAL El ancho o la altura especificados no son válidos.
  • EBUSY El lienzo está en uso por un controlador de pantalla y no se puede cambiar su tamaño.
  • ENOMEM No hay suficiente memoria para el tamaño del lienzo solicitado. Si esto sucede, el manejador del lienzo se vuelve inválido y no debe usarse.

Parámetros

cv El lienzo a recortar.
x Coordenada X de la esquina superior izquierda.
y Coordenada Y de la esquina superior izquierda.
w El ancho del área recortada.
h La altura del área recortada.

Retorna

0 en caso de éxito, -1 si ocurrió un error.

Referencias a caca_add_dirty_rect(), caca_blit(), caca_create_canvas(), caca_create_frame(), caca_get_frame_count(), y caca_set_frame().

caca_canvas(3caca)

NAME

caca_canvas - lienzo de gráficos de caracteres

SYNOPSIS

#include <caca.h>

caca_canvas_t * caca_create_canvas(int width, int height);

void caca_free_canvas(caca_canvas_t *canvas);

int caca_get_canvas_width(const caca_canvas_t *canvas);

int caca_get_canvas_height(const caca_canvas_t *canvas);

void caca_set_canvas_size(caca_canvas_t *canvas, int width, int height);

void caca_clear_canvas(caca_canvas_t *canvas);

void caca_set_canvas_handle_events(caca_canvas_t *canvas, int handle_events);

int caca_get_canvas_handle_events(const caca_canvas_t *canvas);

caca_canvas_t * caca_canvas_from_buffer(const char *buffer, int width, int height, int pitch);

const char * caca_canvas_to_buffer(const caca_canvas_t *canvas, int *width, int *height, int *pitch);

caca_canvas_t * caca_clone_canvas(const caca_canvas_t *canvas);

DESCRIPTION

Un lienzo es una estructura de datos que contiene los caracteres y los atributos de color de una salida de texto. La biblioteca libcaca utiliza lienzos para almacenar la salida gráfica de las aplicaciones que utilizan su API.

caca_create_canvas(width, height) crea un lienzo nuevo con las dimensiones especificadas.

caca_free_canvas(canvas) libera la memoria asignada para el lienzo.

caca_get_canvas_width(canvas) y caca_get_canvas_height(canvas) devuelven el ancho y la altura del lienzo, respectivamente.

caca_set_canvas_size(canvas, width, height) cambia el tamaño del lienzo a las dimensiones especificadas. Si el lienzo se expande, las celdas nuevas se inicializan con el carácter nulo. Si el lienzo se reduce, se descartan los caracteres y atributos que queden fuera de las nuevas dimensiones.

caca_clear_canvas(canvas) establece todos los caracteres y atributos del lienzo al valor nulo.

caca_set_canvas_handle_events(canvas, handle_events) establece si el lienzo debe manejar eventos de entrada de teclado y ratón. Si handle_events es distinto de cero, el lienzo intentará capturar eventos de entrada. Si handle_events es cero, el lienzo ignorará estos eventos. Por defecto, los lienzos no manejan eventos.

caca_get_canvas_handle_events(canvas) devuelve el estado del manejo de eventos del lienzo.

caca_canvas_from_buffer(buffer, width, height, pitch) crea un lienzo nuevo a partir de un búfer de memoria lineal. El búfer debe contener height filas de width caracteres. pitch es el número de bytes entre el inicio de dos filas consecutivas en el búfer. Si pitch es cero, se asume que las filas están empaquetadas (es decir, pitch = width ).

caca_canvas_to_buffer(canvas, width, height, pitch) copia el contenido del lienzo en un búfer de memoria lineal. Las variables apuntadas por width , height y pitch se establecen con las dimensiones y el paso del lienzo. La función devuelve un puntero al búfer de memoria. El usuario es responsable de liberar este búfer.

caca_clone_canvas(canvas) crea una copia exacta del lienzo dado.

EXAMPLE


/* Crear un lienzo de 80x24 caracteres */
caca_canvas_t *canvas = caca_create_canvas(80, 24);

if (canvas == NULL) {
    /* Manejar error */
}

/* Obtener el ancho del lienzo */
int width = caca_get_canvas_width(canvas);

/* Cambiar el tamaño del lienzo */
caca_set_canvas_size(canvas, 640, 480);

/* Limpiar el lienzo */
caca_clear_canvas(canvas);

/* Liberar la memoria del lienzo */
caca_free_canvas(canvas);

RETURN VALUE

caca_create_canvas y caca_canvas_from_buffer devuelven un puntero al lienzo creado, o NULL en caso de error.

caca_get_canvas_width y caca_get_canvas_height devuelven el ancho y la altura del lienzo, respectivamente.

caca_get_canvas_handle_events devuelve un valor distinto de cero si el manejo de eventos está habilitado, o cero en caso contrario.

caca_canvas_to_buffer devuelve un puntero al búfer de memoria que contiene los datos del lienzo.
