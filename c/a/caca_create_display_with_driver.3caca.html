__extern caca_display_t * caca_create_display (caca_canvas_t *

cv)

Crea un contexto gráfico usando características dependientes del dispositivo (ncurses para terminales, una ventana X11, una ventana de comando de DOS...) que se adjunta a un lienzo de libcaca. Todo lo que se dibuje en el lienzo de libcaca puede ser entonces mostrado por el controlador de

libcaca.

Si no se proporciona un lienzo de caca, se crea uno nuevo. Su manejador se puede obtener usando caca_get_canvas() y se destruye automáticamente cuando se llama a caca_free_display()

.

Tenga en cuenta que para lograr la máxima compatibilidad Unicode, el código de inicialización del controlador puede cambiar temporalmente la configuración regional LC_CTYPE global del programa usando setlocale(). Se aconseja no llamar a funciones dependientes de LC_CTYPE desde otros hilos durante la llamada a caca_create_display(). La configuración regional se restaura cuando la función

devuelve.

h_driver().

spositivo gráfico.

__extern int caca_refresh_display (caca_display_t *

dp)

Vuelca todas las operaciones gráficas y las imprime en el dispositivo de visualización. Nada se mostrará en la pantalla hasta que se llame a esta

función.

Si caca_set_display_time() se llamó con un valor distinto de cero, caca_refresh_display() usará ese valor para lograr una tasa de refresco constante: si dos llamadas consecutivas a caca_refresh_display() se realizan dentro de un intervalo de tiempo más corto que el valor establecido con caca_set_display_time(), la segunda llamada se retrasará antes de realizar la actualización de la

pantalla.

dp)

Si libcaca se ejecuta en una ventana, obtiene el ancho utilizable de la ventana. Este valor puede usarse para el cálculo de la relación de aspecto. Si libcaca no se ejecuta en una ventana o si no hay forma de conocer el tamaño de la fuente, la mayoría de los controladores asumirán que se está usando una fuente de 6x10.
