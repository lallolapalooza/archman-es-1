DESCRIPTION

The libcaca library provides functions to manage an abstract canvas, import/export graphics, manage a display, and handle input events.

Import/Export functions

caca_import_area_from_memory() imports a memory buffer into a specific area of a canvas.

caca_import_area_from_file() imports a file into a specific area of a canvas.

caca_get_import_list() returns a list of supported image import formats.

caca_export_canvas_to_memory() exports the entire canvas into a memory buffer in a foreign format.

caca_export_area_to_memory() exports a portion of the canvas into a memory buffer in a foreign format.

caca_get_export_list() returns a list of supported image export formats.

Display functions

caca_create_display() attaches a display context to a canvas.

caca_create_display_with_driver() attaches a display context to a canvas using a specific driver.

caca_get_display_driver_list() returns a list of available display drivers.

caca_get_display_driver() returns the current output driver name.

caca_set_display_driver() sets the output driver.

caca_free_display() detaches the display context from the canvas.

caca_get_canvas() returns the canvas attached to the display context.

caca_refresh_display() flushes pending changes and redraws the screen.

caca_set_display_time() sets the refresh delay.

caca_get_display_time() returns the display's average rendering time.

caca_get_display_width() returns the display width.

caca_get_display_height() returns the display height.

caca_set_display_title() sets the display title.

caca_set_mouse() shows or hides the mouse pointer.

caca_set_cursor() shows or hides the cursor.

Event handling functions

caca_get_event() retrieves the next mouse or keyboard input event.

caca_get_mouse_x() returns the X mouse coordinate.

caca_get_mouse_y() returns the Y mouse coordinate.

caca_get_event_type() returns an event's type.

caca_get_event_key_ch() returns a key press or key release event's character value.

caca_get_event_key_utf32() returns a key press or key release event's Unicode value.

caca_get_event_key_utf8() returns a key press or key release event's UTF-8 value.

caca_get_event_mouse_button() returns a mouse press or mouse release event's button.

caca_get_event_mouse_x() returns a mouse motion event's X coordinate.

caca_get_event_mouse_y() returns a mouse motion event's Y coordinate.

caca_get_event_resize_width() returns a resize event's display width value.

caca_get_event_resize_height() returns a resize event's display height value.

getopt function

caca_getopt() is an enhanced version of the standard getopt(3) function.

DOS conio.h functions

The following functions are equivalent to the functions found in the DOS conio.h and dos.h headers:

caca_conio_cgets(), caca_conio_clreol(), caca_conio_clrscr(), caca_conio_cprintf(), caca_conio_cputs(), caca_conio_cscanf(), caca_conio_delay(), caca_conio_delline(), caca_conio_getch(), caca_conio_getche(), caca_conio_getpass(), caca_conio_gettext(), caca_conio_gettextinfo(), caca_conio_gotoxy(), caca_conio_highvideo(), caca_conio_insline(), caca_conio_kbhit(), caca_conio_lowvideo(), caca_conio_movetext(), caca_conio_normvideo(), caca_conio_nosound(), caca_conio_printf(), caca_conio_putch(), caca_conio_puttext(), caca_conio__setcursortype(), caca_conio_sleep(), caca_conio_sound(), caca_conio_textattr(), caca_conio_textbackground(), caca_conio_textcolor(), caca_conio_textmode(), caca_conio_ungetch(), caca_conio_wherex(), caca_conio_wherey(), caca_conio_window().
