case(n) Comandos integrados de Tcl case(n)

NOMBRE

case - Evalúa uno de varios scripts, dependiendo de un valor dado

SINOPSIS

case cadena ?in? listaPatrones cuerpo ?listaPatrones cuerpo ...?

case cadena ?in? {listaPatrones cuerpo ?listaPatrones cuerpo ...?

DESCRIPCIÓN

Nota: el comando case es obsoleto y solo se soporta por compatibilidad con versiones anteriores. En algún momento en el futuro podría ser eliminado por completo. Deberías usar el comando switch en su lugar.

El comando case compara cadena con cada uno de los argumentos listaPatrones en orden. Cada argumento listaPatrones es una lista de uno o más patrones. Si alguno de estos patrones coincide con cadena, entonces case evalúa el argumento cuerpo siguiente pasándolo recursivamente al intérprete Tcl y devuelve el resultado de esa evaluación. Cada argumento listaPatrones consiste en un solo patrón o una lista de patrones. Cada patrón puede contener cualquiera de los comodines descritos en string match. Si un argumento listaPatrones es default, el cuerpo correspondiente se evaluará si ningún listaPatrones coincide con cadena. Si ningún argumento listaPatrones coincide con cadena y no se proporciona un valor predeterminado, el comando case devuelve una cadena vacía.

Se proporcionan dos sintaxis para los argumentos listaPatrones y cuerpo. La primera utiliza un argumento separado para cada uno de los patrones y comandos; esta forma es conveniente si se desean sustituciones en algunos de los patrones o comandos. La segunda forma agrupa todos los patrones y comandos en un solo argumento; el argumento debe tener una estructura de lista adecuada, con los elementos de la lista siendo los patrones y comandos. La segunda forma facilita la construcción de comandos case multilínea, ya que las llaves alrededor de toda la lista hacen innecesario incluir una barra invertida al final de cada línea. Dado que los argumentos listaPatrones están entre llaves en la segunda forma, no se realizan sustituciones de comandos ni de variables en ellos; esto hace que el comportamiento de la segunda forma sea diferente a la primera forma en algunos casos.
