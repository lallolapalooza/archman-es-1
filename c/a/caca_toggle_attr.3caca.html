__extern uint32_t caca_get_attr (caca_canvas_t const * cv, int x, int y)

Obtiene el valor interno del atributo de libcaca del carácter en las coordenadas dadas. El valor del atributo tiene 32 bits significativos, organizados de la siguiente manera, de MSB a LSB:

  • 3 bits para el alfa de fondo
  • 4 bits para el componente rojo del fondo
  • 4 bits para el componente verde del fondo
  • 3 bits para el componente azul del fondo
  • 3 bits para el alfa de primer plano
  • 4 bits para el componente rojo de primer plano
  • 4 bits para el componente verde de primer plano
  • 3 bits para el componente azul de primer plano
  • 4 bits para las banderas de negrita, cursiva, subrayado y parpadeo

Si las coordenadas están fuera de los límites del lienzo, se devuelve el atributo actual.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.

Retorna

El atributo solicitado.

Referenciado por caca_conio_textbackground(), caca_conio_textcolor(), caca_dither_bitmap(), caca_flush_figlet(), y caca_put_figchar().

__extern int caca_set_attr (caca_canvas_t * cv, uint32_t attr)

Establece el atributo de carácter predeterminado para dibujar. Los atributos definen el color de primer plano y fondo, la transparencia, los estilos negrita, cursiva y subrayado, así como el parpadeo. Las funciones de cadena como caca_printf() y las funciones de primitivas gráficas como caca_draw_line() usarán este atributo.

El valor de attr es:

  • un entero de 32 bits como el devuelto por caca_get_attr(), en cuyo caso también contiene información de color,
  • una combinación (OR bit a bit) de valores de estilo (CACA_UNDERLINE, CACA_BLINK, CACA_BOLD y CACA_ITALICS), en cuyo caso establecer el atributo no modifica la información de color actual.

Para recuperar el valor del atributo actual, use caca_get_attr(-1,-1).

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
attr El valor del atributo solicitado.

Retorna

Esta función siempre devuelve 0.

Referenciado por caca_dither_bitmap(), y caca_put_figchar().

__extern int caca_unset_attr (caca_canvas_t * cv, uint32_t attr)

Desactiva las banderas en el atributo de carácter predeterminado para dibujar. Los atributos definen el color de primer plano y fondo, la transparencia, los estilos negrita, cursiva y subrayado, así como el parpadeo. Las funciones de cadena como caca_printf() y las funciones de primitivas gráficas como caca_draw_line() usarán este atributo.

El valor de attr es una combinación (OR bit a bit) de valores de estilo (CACA_UNDERLINE, CACA_BLINK, CACA_BOLD y CACA_ITALICS). Desactivar estos atributos no modifica la información de color actual.

Para recuperar el valor del atributo actual, use caca_get_attr(-1,-1).

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
attr Los valores de atributo solicitados para desactivar.

Retorna

Esta función siempre devuelve 0.

__extern int caca_toggle_attr (caca_canvas_t * cv, uint32_t attr)

Alterna las banderas en el atributo de carácter predeterminado para dibujar. Los atributos definen el color de primer plano y fondo, la transparencia, los estilos negrita, cursiva y subrayado, así como el parpadeo. Las funciones de cadena como caca_printf() y las funciones de primitivas gráficas como caca_draw_line() usarán este atributo.

El valor de attr es una combinación (OR bit a bit) de valores de estilo (CACA_UNDERLINE, CACA_BLINK, CACA_BOLD y CACA_ITALICS). Alternar estos atributos no modifica la información de color actual.

Para recuperar el valor del atributo actual, use caca_get_attr(-1,-1).

__extern int caca_put_attr (caca_canvas_t * cv, int x, int y, uint32_t attr)

Establece el atributo del carácter, sin cambiar el valor del carácter. Si el carácter en las coordenadas dadas es un carácter de ancho completo, los atributos de ambas celdas se reemplazan.

El valor de attr es:

  • una combinación (OR bit a bit) de valores de estilo (CACA_UNDERLINE, CACA_BLINK, CACA_BOLD y CACA_ITALICS), en cuyo caso establecer el atributo no modifica la información de color actual.

Esta función nunca falla.
