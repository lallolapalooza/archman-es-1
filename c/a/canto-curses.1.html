VAN
ZADO

Canto-curses soporta muchas más características como categorizar feeds/etiquetas, filtrar y ordenar, buscar, y más que se pueden

descubrir con

:help También soporta una variedad

de

plugins que pueden añadir mucha funcionalidad extra, que están incluid

os con esta instalación o dispon
ibles en la página principal.

PLUGIN

S

Los plugins están empaquetados en <prefijo>/canto/plugins (es decir. /usr/lib/canto/plugins) y pueden habilitarse copiándolos a tu directorio de configuración (es decir. $XDG_CONFIG_HOME/canto/plugins). Muchos de ellos tienen configuración en ellos, así que puede que quieras abrir los archivos para hacer cambios. Aquí hay algunos plugins de ejemplo incluidos con el código fuente de

canto-curses.
autocmd.
py
Ejecuta comandos automáticamente al inicio (útil para cambiar la configuración al
inicio)
reader-extras.
py
Añade contenido extra a algunos feeds, también útil para ver qué se incluye en un
feed.
xtermtitle.
py
Establece el título de las terminales compatibles con xterm al inicio, y opcionalmente incluye el título del elemento
seleccionado
yank.
py
Añade :yank-link (por defecto 'y') y :
yank-title
comandos (necesita xclip
instalado)
favorites.
py
Una etiqueta de "favoritos" de usuario como prueba de concepto, que puede cambiar el aspecto de ciertos elementos
seleccionados por el usuario.
smartlink.
py
Un plugin que te permite definir manejadores específicos para enlaces basados en la URL o la salida de `file` sobre el contenido descargado. Útil para escuchar enclosures de podcasts o mostrar
contenido PDF/imagen/otro en un programa dedicado.
cle
ant
itle
.py

Un plugin que ayuda a eliminar contenido malo (saltos de línea, HTML, etc.) de los títulos

de los elementos
