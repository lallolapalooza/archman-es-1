CAPNG_UPDATE(3) API de Libcap-ng CAPNG_UPDATE(3)

NOMBRE

capng_update - actualiza la configuración de capacidades almacenada

SINOPSIS

#include <cap-ng.h>

int capng_update(capng_act_t action, capng_type_t type,unsigned int capability);

DESCRIPCIÓN

capng_update actualizará la configuración interna de capacidades POSIX basándose en las opciones que se le pasen. La acción debe ser CAPNG_DROP para establecer el bit de capacidad a 0, o CAPNG_ADD para establecer el bit de capacidad a 1. La operación se realiza sobre el conjunto de capacidades especificado en el parámetro type. Los valores son: CAPNG_EFFECTIVE, CAPNG_PERMITTED, CAPNG_INHERITABLE, CAPNG_BOUNDING_SET, o CAPNG_AMBIENT. Los valores pueden combinarse con OR para realizar la misma operación en múltiples conjuntos. El último parámetro, capability, es la capacidad definida según se indica en linux/capability.h.

VALOR DE RETORNO

Devuelve 0 en caso de éxito y -1 en caso de fallo.

VER TAMBIÉN

capng_updatev(3), capabilities(7)
