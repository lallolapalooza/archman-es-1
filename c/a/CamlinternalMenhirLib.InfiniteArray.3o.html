Módulo InfiniteArray
: sig end

tipo 'a t

Este módulo implementa arrays infinitos. *

val make : 'a -> 'a t

make x crea un array infinito, donde cada celda contiene x . *

val get : 'a t -> int -> 'a

get a i devuelve el elemento contenido en el índice i del array a . Las celdas se numeran a partir de 0. *

val set : 'a t -> int -> 'a -> unit

set a i x establece el elemento contenido en el índice i del array a a x . Las celdas se numeran a partir de 0. *

val extent : 'a t -> int

extent a es la longitud de un segmento inicial del array a que es suficientemente grande para contener todas las operaciones set realizadas. En otras palabras, todos los elementos más allá de ese segmento tienen el valor predeterminado.

val domain : 'a t -> 'a array

domain a es una copia nueva de un segmento inicial del array a cuya longitud es extent a .
