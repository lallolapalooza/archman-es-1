__extern ssize_t caca_import_canvas_from_memory (caca_canvas_t * cv, void const * data, size_t len, char const * format)

Importa un buffer de memoria al fotograma actual del lienzo libcaca dado. El fotograma actual se redimensiona en consecuencia y su contenido se reemplaza con los datos importados.

Los valores válidos para format son:

  • '': intenta autodetectar el formato del archivo.
  • 'caca': importa archivos nativos de libcaca.
  • 'text': importa archivos de texto ASCII.
  • 'ansi': importa archivos ANSI.
  • 'utf8': importa archivos UTF-8 con códigos de color ANSI.
  • 'bin': importa archivos BIN.

Se devuelve el número de bytes leídos. Si el formato del archivo es válido, pero no había suficientes datos disponibles, se devuelve 0.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

  • ENOMEM No hay suficiente memoria para asignar el lienzo.
  • EOVERFLOW La importación de datos provocó un desbordamiento de valor.
  • EINVAL Formato no válido solicitado.

Parámetros

cv Un lienzo de libcaca en el que importar el archivo.
data Un área de memoria que contiene los datos que se cargarán en el lienzo.
len El tamaño en bytes del área de memoria.
format Una cadena que describe el formato de entrada.

Devoluciones

El número de bytes leídos, o 0 si no había suficientes datos, o -1 si ocurrió un error.

__extern ssize_t caca_import_canvas_from_file (caca_canvas_t * cv, char const * filename, char const * format)

Importa un archivo al fotograma actual del lienzo libcaca dado. El fotograma actual se redimensiona en consecuencia y su contenido se reemplaza con los datos importados.

Los valores válidos para format son:

  • '': intenta autodetectar el formato del archivo.
  • 'caca': importa archivos nativos de libcaca.
  • 'text': importa archivos de texto ASCII.
  • 'ansi': importa archivos ANSI.
  • 'utf8': importa archivos UTF-8 con códigos de color ANSI.
  • 'bin': importa archivos BIN.

Se devuelve el número de bytes leídos. Si el formato del archivo es válido, pero no había suficientes datos disponibles, se devuelve 0.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

  • ENOSYS El acceso a archivos no está implementado en este sistema.
  • ENOMEM No hay suficiente memoria para asignar el lienzo.
  • EINVAL Formato no válido solicitado. caca_import_file() también puede fallar y establecer errno para cualquiera de los errores especificados para la rutina fopen().

Parámetros

cv Un lienzo de libcaca en el que importar el archivo.
filename El nombre del archivo a cargar.
format Una cadena que describe el formato de entrada.

Devoluciones

El número de bytes leídos, o 0 si no había suficientes datos, o -1 si ocurrió un error.

__extern void * caca_export_canvas_to_memory (caca_canvas_t const * cv, char const * format, size_t * len)

Exporta el lienzo dado a un formato extranjero. La memoria asignada debe liberarse con free().

El parámetro len se establece en el tamaño en bytes de la memoria exportada.

Los formatos de exportación disponibles son:

  • 'ansi': exporta a archivos ANSI.
  • 'utf8': exporta a archivos UTF-8.
  • 'html': exporta a archivos HTML.
  • 'json': exporta a archivos JSON.
  • 'sar': exporta a archivos SAR.

Si ocurre un error, se devuelve NULL y errno se establece en consecuencia:

  • EINVAL Formato no soportado solicitado.
  • ENOMEM No hay suficiente memoria para asignar el búfer de exportación.

Parámetros

cv El lienzo a exportar.
format Una cadena que describe el formato de salida.
len Un puntero a una variable de tamaño_t que recibe el tamaño en bytes de la memoria exportada.

Devoluciones

Un puntero a la memoria exportada, o NULL si ocurrió un error.

__extern void * caca_export_canvas_to_memory (caca_canvas_t const * cv, char const * format, size_t * bytes)

Esta función exporta un lienzo de libcaca a varios formatos externos como arte ANSI, HTML, colores IRC, etc. El puntero devuelto debe pasarse a free() para liberar el almacenamiento asignado cuando ya no sea necesario.

Los valores válidos para format son:

  • 'caca': exportar archivos nativos de libcaca.
  • 'ansi': exportar arte ANSI (juego de caracteres CP437 con códigos de color ANSI).
  • 'html': exportar una página HTML con información CSS.
  • 'html3': exportar una tabla HTML que debería ser compatible con la mayoría de los navegadores, incluidos los de modo texto.
  • 'irc': exportar texto UTF-8 con códigos de color mIRC.
  • 'ps': exportar un documento PostScript.
  • 'svg': exportar una imagen vectorial SVG.
  • 'tga': exportar una imagen TGA.
  • 'troff': exportar una fuente troff.

Si ocurre un error, se devuelve NULL y errno se establece correspondientemente:

  • EINVAL Formato no soportado solicitado.
  • ENOMEM No hay suficiente memoria para asignar el búfer de salida.

Parámetros

cv Un lienzo de libcaca
format Una cadena que describe el formato de salida solicitado.
bytes Un puntero a un size_t donde se escribirá el número de bytes asignados.

Retorna

Un puntero al área de memoria exportada, o NULL en caso de error.
