CARDDAV-QUERY(1) Manual de Comandos Generales CARDDAV-QUERY(1)

NOMBRE

carddav-query - Consultar un servidor CardDAV para obtener nombres y correos electrónicos de contactos.

SINOPSIS

carddav-query [-h] [-l <límite>] [-v] [-c <archivo>] [-s <sección>] [-k <fuente_clave>] [-C <comando_cred_clave>] [-s <url_servidor>] [-u <nombre_usuario>] [-p <contraseña>] <término> [<término> ...]

Esta herramienta ha sido adaptada para su uso como address-book-cmd en aerc-config(5).

OPCIONES

-h, --help

Mostrar este mensaje de ayuda y salir.

-v, --verbose

Imprimir información de depuración en stderr.

-l <límite>, --limit <límite>

Número máximo de resultados devueltos por el servidor. Si el servidor no admite la limitación, esta opción se ignorará.

Por defecto: 10

-c <archivo>, --config-file <archivo>

Archivo de configuración INI desde el cual leer el punto final de la URL de CardDAV.

Por defecto: ~/.config/aerc/accounts.conf

-S <sección>, --config-section <sección>

Sección de configuración INI donde encontrar <fuente_clave> y <comando_cred_clave>. Por defecto se utilizará la primera sección donde se encuentre <fuente_clave>.

-k <fuente_clave>, --config-key-source <fuente_clave>

Clave de configuración INI a buscar en <sección> de <archivo>. El valor debe respetar el siguiente formato:
https?://<nombre_usuario>[:<contraseña>]@<nombre_host>/<ruta/al/libro_de_direcciones>

Tanto <nombre_usuario> como <contraseña> deben estar codificados en porcentaje. Si se omite <contraseña>, se puede proporcionar a través de --config-key-cred-cmd o --password.

Por defecto: carddav-source

-C <comando_cred_clave>, --config-key-cred-cmd <comando_cred_clave>

Clave de configuración INI a buscar en <sección> de <archivo>. El valor es un comando que se ejecutará con sh -c para determinar la <contraseña> si no está presente en <fuente_clave>.

Por defecto: carddav-source-cred-cmd

-s <url_servidor>, --server-url <url_servidor>

Punto final de la URL del servidor CardDAV. Anula el archivo de configuración.

-u <nombre_usuario>, --username <nombre_usuario>

Nombre de usuario para autenticarse en el servidor. Anula el archivo de configuración.

-p <contraseña>, --password <contraseña>

Contraseña para el usuario especificado. Anula el archivo de configuración.

ARGUMENTOS POSICIONALES

<término>

Término de búsqueda. Se utilizará para buscar contactos en sus campos de FN (nombre formateado), EMAIL, NICKNAME, ORG (empresa) y TITLE (título).

EJEMPLOS

Estos son extractos de ~/.config/aerc/accounts.conf.

Fastmail

[fastmail]
carddav-source = https://janedoe%40fastmail.com@carddav.fastmail.com/dav/addressbooks/user/janedoe@fastmail.com/Default
carddav-source-cred-cmd = pass fastmail.com/janedoe
address-book-cmd = carddav-query -S fastmail %s

Gmail

[gmail]
carddav-source = https://johndoe%40gmail.com@www.googleapis.com/carddav/v1/principals/johndoe@gmail.com/lists/default
carddav-source-cred-cmd = pass gmail.com/johndoe
address-book-cmd = carddav-query -S gmail %s
