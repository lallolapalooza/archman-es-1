CARGO-LOCATE-PROJECT(1) Manual de comandos generales CARGO-LOCATE-PROJECT(1)

NOMBRE

cargo-locate-project — Imprime una representación JSON de la ubicación de un archivo Cargo.toml

SINOPSIS

cargo locate-project [opciones]

DESCRIPCIÓN

Este comando imprimirá un objeto JSON en stdout con la ruta completa al manifiesto. El manifiesto se encuentra buscando hacia arriba un archivo llamado Cargo.toml comenzando desde el directorio de trabajo actual.

Si el proyecto es parte de un espacio de trabajo (workspace), se emitirá el manifiesto del proyecto, en lugar de la raíz del espacio de trabajo. Esto se puede anular con la bandera --workspace. La raíz del espacio de trabajo se encuentra al ascender más o al usar el campo package.workspace después de localizar el manifiesto de un miembro del espacio de trabajo.

OPCIONES

--workspace

Localiza el Cargo.toml en la raíz del espacio de trabajo, en lugar del miembro actual del espacio de trabajo.

Opciones de visualización

--message-format fmt

La representación en la que se imprimirá la ubicación del proyecto. Valores válidos:
•json (predeterminado): Objeto JSON con la ruta bajo la clave "root".
•plain: Solo la ruta.

-v, --verbose

Usa salida detallada. Se puede especificar dos veces para una salida "muy detallada" que incluye información adicional como advertencias de dependencias y salida de scripts de compilación. También se puede especificar con el valor de configuración term.verbose https://doc.rust-lang.org/cargo/reference/config.html.

-q, --quiet

No imprima mensajes de registro de cargo. También se puede especificar con el valor de configuración term.quiet https://doc.rust-lang.org/cargo/reference/config.html.

--color when

Controla cuándo se utiliza la salida en color. Valores válidos:
•auto (predeterminado): Detecta automáticamente si el soporte de color está disponible en la terminal.
•always: Muestra siempre colores.
•never: Nunca muestra colores.

También se puede especificar con el valor de configuración term.color https://doc.rust-lang.org/cargo/reference/config.html.

Opciones de manifiesto

--manifest-path path

Ruta al archivo Cargo.toml. Por defecto, Cargo busca el archivo Cargo.toml en el directorio actual o en cualquier directorio padre.

Opciones comunes

+toolchain

Si Cargo se ha instalado con rustup, y el primer argumento a cargo comienza con +, se interpretará como un nombre de toolchain de rustup (como +stable o +nightly). Consulte la documentación de rustup https://rust-lang.github.io/rustup/overrides.html para obtener más información sobre cómo funcionan las anulaciones de toolchain.

--config KEY=VALUE o PATH

Anula un valor de configuración de Cargo. El argumento debe estar en sintaxis TOML de KEY=VALUE, o proporcionarse como una ruta a un archivo de configuración adicional. Esta bandera se puede especificar varias veces. Consulte la sección de anulaciones de línea de comandos https://doc.rust-lang.org/cargo/reference/config.html#command-line-overrides para obtener más información.

-C PATH

Cambia el directorio de trabajo actual antes de ejecutar cualquier operación especificada. Esto afecta a dónde busca cargo por defecto el manifiesto del proyecto (Cargo.toml), así como a los directorios buscados para descubrir .cargo/config.toml, por ejemplo.

Esta opción solo está disponible en el canal nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html y requiere la bandera -Z unstable-options para habilitarse (ver #10098 https://github.com/rust-lang/cargo/issues/10098).

-h, --help

Imprime información de ayuda.

-Z flag

Banderas inestables (solo para nightly) para Cargo. Ejecute cargo -Z help para obtener detalles.

AMBIENTE

Consulte la referencia https://doc.rust-lang.org/cargo/reference/environment-variables.html para obtener detalles sobre las variables de entorno que Cargo lee.

ESTADO DE SALIDA

•0: Cargo tuvo éxito.
•101: Cargo no pudo completarse.

EJEMPLOS

1.Muestre la ruta al manifiesto basándose en el directorio actual: 
cargo locate-project
