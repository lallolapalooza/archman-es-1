__extern int caca_put_char (caca_canvas_t * cv, int x, int y, uint32_t ch)

Imprime un carácter ASCII o Unicode en las coordenadas dadas, utilizando los valores de color de primer plano y fondo por defecto.

Si las coordenadas están fuera de los límites del lienzo, no se imprime nada. Si un carácter Unicode de ancho completo se sobrescribe, sus partes visibles restantes se reemplazan con espacios. Si los límites del lienzo dividieran el carácter de ancho completo en dos, se imprimirá un espacio en su lugar.

El comportamiento al imprimir caracteres no imprimibles o caracteres UTF-32 inválidos no está definido. Para imprimir una secuencia de bytes que forman un carácter UTF-8 en lugar de un carácter UTF-32, use la función caca_put_str().

Esta función retorna el ancho del carácter impreso. Si es un carácter de ancho completo, se devuelve 2. De lo contrario, se devuelve 1.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.
ch El carácter a imprimir.

Retorna

El ancho del carácter impreso: 2 para un carácter de ancho completo, 1 en caso contrario.

Referencias caca_add_dirty_rect(), CACA_MAGIC_FULLWIDTH y caca_utf32_is_fullwidth().

Referenciado por caca_conio_cgets(), caca_conio_cputs(), caca_conio_putch(), caca_dither_bitmap(), caca_fill_box(), caca_fill_triangle(), caca_flush_figlet(), caca_put_figchar() y caca_put_str().

__extern uint32_t caca_get_char (caca_canvas_t const * cv, int x, int y)

Obtiene el valor ASCII o Unicode del carácter en las coordenadas dadas. Si el valor es menor o igual a 127 (0x7f), el carácter se puede imprimir como ASCII. De lo contrario, debe manejarse como un valor UTF-32.

Si las coordenadas están fuera de los límites del lienzo, se retorna un espacio (0x20).

Una excepción especial es cuando se retorna CACA_MAGIC_FULLWIDTH. Este valor está garantizado que no es un carácter Unicode válido, e indica que el carácter a la izquierda del solicitado es un carácter de ancho completo.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.

Retorna

El carácter Unicode en las coordenadas dadas.

Referenciado por caca_flush_figlet() y caca_put_figchar().

__extern int caca_put_str (caca_canvas_t * cv, int x, int y, char const * str)

Imprime una cadena de caracteres en las coordenadas dadas. La cadena debe estar codificada en UTF-8. La impresión se detiene si se encuentra un carácter de control, un carácter nulo, un carácter inválido o si la cadena sale de los límites del lienzo.

Si se intenta imprimir un carácter de ancho completo que se extiende más allá del límite derecho del lienzo, ese carácter se reemplaza por un espacio.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X de inicio.
y Coordenada Y de inicio.
str La cadena a imprimir (codificada en UTF-8).

Retorna

__extern int caca_blit (caca_canvas_t * cv, int x, int y, caca_canvas_t const * src, caca_canvas_t const * mask)

Copia un lienzo fuente (src) sobre otro lienzo (cv), utilizando un lienzo de máscara opcional (mask). Si la máscara es NULL, se copia todo el lienzo fuente. Si la máscara no es NULL, solo se copian los píxeles del lienzo fuente donde el píxel correspondiente de la máscara es diferente de cero.

Las coordenadas (x, y) especifican la esquina superior izquierda donde se colocará el lienzo fuente.

Si el lienzo fuente o la máscara son más grandes que el lienzo destino, solo se copiará la porción que cabe.

Parámetros

cv Un manejador para el lienzo de destino.
x Coordenada X de la esquina superior izquierda del lienzo fuente.
y Coordenada Y de la esquina superior izquierda del lienzo fuente.
src Un manejador para el lienzo fuente.
mask Un manejador para el lienzo de máscara opcional.

Retorna

0 en caso de éxito, o un valor negativo en caso de error.

__extern int caca_set_canvas_boundaries (caca_canvas_t * cv, int x, int y, int w, int h)

Establece nuevos límites para un lienzo. Esta función se puede usar para recortar un lienzo, expandirlo o para combinaciones de ambas acciones. Todos los fotogramas se ven afectados por esta función.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

  • EINVAL El ancho o alto especificado no es válido.

  • ENOMEM No hay suficiente memoria para el tamaño de lienzo solicitado. Si esto sucede, el manejador del lienzo se vuelve inválido y no debe usarse.

x Coordenada X de la esquina superior izquierda.
y Coordenada Y de la esquina superior izquierda.

    caca_get_char(3caca)

    NAME

    caca_get_char - retrieve the character at a given position

    SYNOPSIS

    #include <caca.h>

unsigned int caca_get_char(caca_handle_t cp, int x, int y);

    DESCRIPTION

    The caca_get_char function returns the character stored at the given coordinates (x, y). The value returned is an integer. You can use the CACA_GETA, CACA_GETC, CACA_GETF, CACA_GETB macros to extract the attribute value, the character value, the foreground colour and the background colour, respectively.

    RETURN VALUE

    Returns the integer value of the character and its attributes at the given coordinates.

    EXAMPLE

    #include <stdio.h>
#include <caca.h>

int main(void) {
    caca_handle_t cp = caca_create_canvas(16, 16);
    unsigned int val;
    char c;
    int fg, bg;

    caca_draw_text(cp, 1, 1, "Hello", 5);
    val = caca_get_char(cp, 1, 1);

    c = CACA_GETC(val);
    fg = CACA_GETF(val);
    bg = CACA_GETB(val);

    printf("Character: '%c', FG: %d, BG: %d\n", c, fg, bg);

    caca_free_canvas(cp);
    return 0;
}
