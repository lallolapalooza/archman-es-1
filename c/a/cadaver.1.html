DESCRIPCIÓ

N

cadaver soporta la subida y descarga de archivos, visualización en pantalla, operaciones de espacio de nombres (mover y copiar), creación y eliminación de colecciones, y operaciones de

bloqueo.

Su funcionamiento es similar al del cliente estándar BSD ftp(1) y el del Proyecto Samba smbclient(1). Un usuario familiarizado con estas herramientas debería sentirse bastante cómodo con

cadaver.

cadaver soporta el inicio de sesión automático en servidores que requieren autenticación mediante un archivo .netrc (similar a ftp(1) - ver la sección "E

L ARCHIVO .net
rc" más abajo).

EL ARCHIVO .

netrc

El archivo ~/.netrc puede usarse para iniciar sesión automáticamente en un servidor que requiere autenticación. Los siguientes tokens (separados por espacios, tabuladores o saltos de línea) pueden

usarse:

machine hos

t
Identifica una máquina remota host que se compara con el nombre de host dado en la línea de comandos o como argumento del comando open. Cualquier token posterior hasta el final del archivo o el siguiente machine o default se asocia con esta
entrada.

defaul

t
Esto es equivalente al token machine pero coincide con cualquier nombre de host. Solo puede usarse un default y debe estar después de todos los machine
.

login nombreusuari

o
Especifica el nombre de usuario a usar al iniciar sesión en la máquina
remota.

password cadena
passwd caden

a
Especifica la contraseña a usar al iniciar sesión en la máquina
remota.

Cualquier otro token

(como se describe e
n ftp(1)) se ignora.
