catanh(3) Manual de funciones de biblioteca catanh(3)

NOMBRE

catanh, catanhf, catanhl - arc tangentes hiperbólicas complejas

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <complex.h>
double complex catanh(double complex z);
float complex catanhf(float complex z);
long double complex catanhl(long double complex z);

DESCRIPCIÓN

Estas funciones calculan la arc tangente hiperbólica compleja de z. Si y = catanh(z), entonces z = ctanh(y). La parte imaginaria de y se elige en el intervalo [-pi/2, pi/2].

Se tiene:


catanh(z) = 0.5 * (clog(1 + z) - clog(1 - z))

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
catanh (), catanhf (), catanhl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

glibc 2.1. C99, POSIX.1-2001.

EJEMPLOS

/* Enlazar con "-lm" */
#include <complex.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    double complex z, c, f;
    if (argc != 3) {
        fprintf(stderr, "Uso: %s <real> <imag>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    z = atof(argv[1]) + atof(argv[2]) * I;
    c = catanh(z);
    printf("catanh() = %6.3f %6.3f*i\n", creal(c), cimag(c));
    f = 0.5 * (clog(1 + z) - clog(1 - z));
    printf("formula  = %6.3f %6.3f*i\n", creal(f), cimag(f));
    exit(EXIT_SUCCESS);
}
