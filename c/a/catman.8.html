DESCRIPCIÓ

N

catman se utiliza para crear un conjunto actualizado de páginas de manual preformateadas conocidas como páginas cat. Las páginas cat generalmente se muestran mucho más rápido que las páginas de manual originales, pero requieren espacio de almacenamiento adicional. La decisión de admitir páginas cat es del administrador local, quien debe proporcionar directorios adecuados para

contenerlas.

Las opciones disponibles para catman son las jerarquías y secciones de páginas de manual a preformatear. Las jerarquías predeterminadas son las especificadas como jerarquías del sistema en el archivo de configuración de man-db, y las secciones predeterminadas son el contenido delimitado por dos puntos de la variable de entorno $MANSECT o el conjunto estándar compilado en man si $MANSECT no está definida. Proporcionar a catman un conjunto de nombres de secciones delimitados por espacios en blanco anulará ambos casos

anteriores.

vos necesitan ser formateados.
