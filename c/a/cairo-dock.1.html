DESCRIPCIÓ

N

Cairo-Dock es una interfaz bonita, ligera y conveniente para tu escritorio, capaz de reemplazar ventajosamente tu panel del

sistema.

Cuenta con múltiples docks, barra de tareas, lanzadores y muchas aplicaciones útiles.
Las aplicaciones pueden desacoplarse del dock para actuar como widgets del escritorio.
Numerosos temas listos para usar se pueden descargar con 1 clic, y pueden personalizarse fácilmente a tu gusto.
Puede usar aceleración por hardware (OpenGL) para ser muy rápido y con bajo uso de

CPU.

Se recomienda instalar el paquete PLUG-INS ( cairo-dock-plug-ins ) para tener acceso a más vistas, diálogos y muchos complementos y

aplicaciones.

OPCIONE

S

Puedes lanzar Cairo-Dock con varias opciones:
(Nota: puedes usar estas opciones en un solo bloque. Por ejemplo: cairo-dock -oia

)
-c,
--cairo
Fuerza el backend Cairo. Usa esta opción si tienes problemas con el modo
OpenGL.
-o,
--opengl
Fuerza el backend OpenGL. Cairo-Dock con OpenGL/aceleración por
hardware.
-O,
--indirect-opengl
Usa el backend OpenGL con renderizado indirecto. Hay muy pocos casos en los que se deba usar esta
opción.
-A,
--ask-backend
Pregunta de nuevo al inicio qué backend
usar.
-l, --log
[opción]
Verbosidad del registro (opciones: debug, message, warning, critical, error - el valor por defecto es 'warning').
Por ejemplo: cairo-dock -l
debug
-F,
--colors
Fuerza a mostrar algunos mensajes de salida con colores incluso si estos mensajes no se muestran en una
tty.
-w,
--wait
Espera N segundos antes de empezar. Esto es útil si notas algunos problemas cuando el dock se inicia con la
sesión.
-a,
--keep-above
Fuerza a mantener el dock por encima de otras
ventanas.
-s,
--no-sticky
No hace que el dock aparezca en todos los
escritorios.
-e,
--env
Fuerza al dock a considerar este entorno (gnome, xfce, etc.) - puede hacer fallar al dock si no se configura
correctamente.
-d,
--dir
Fuerza al dock a cargar la configuración en este directorio (el valor por defecto es ~/.config/cairo-dock)
.
-m,
--maintenance
Permite editar la configuración antes de que el dock se inicie y muestra el panel de configuración al
inicio.
-x,
--exclude
Excluye un complemento dado de activarse (aunque se carga igualmente)
.
-f,
--safe-mode
No carga ningún complemento y muestra el gestor de temas al
inicio.
-W, --metacity-workaro
und
Soluciona algunos errores en el gestor de ventanas Metacity (diálogos invisibles o
sub-docks)
-M,
--modules-dir
Pide al dock cargar módulos adicionales contenidos en este directorio (aunque no es seguro que tu dock cargue módulos no oficiales)
.
-T,
--testing
Solo para propósitos de depuración. El gestor de fallos no se iniciará para cazar los
errores.
-E,
--easter-eggs
Solo para propósitos de depuración. Algunas opciones ocultas e inestables serán
activadas.
-S,
--server
Dirección de un servidor que contiene temas adicionales. Esto sobrescribirá la dirección del servidor por
defecto.
-k,
--locked
Bloquea el dock para
que cualquier modif
icación sea imposibl
e para los usuarios.
