Canto-remote(1) Manual de comandos generales Canto-remote(1)

NOMBRE

Canto-remote - Un control remoto básico para canto-daemon

Esto proporciona cierta capacidad para configurar y consultar canto-daemon sin un cliente completo. Útil para scripting o para interactuar con otros programas.

USO DE LÍNEA DE COMANDOS

canto-remote (opciones) [comando] (argumentos)

OPCIONES

-V
Imprime información de la versión y sale.
-h/--ayuda
Imprime la ayuda de uso.
-D/--directorio [directorio]
Cambia el directorio base para canto-daemon (predeterminado: $XDG_CONFIG_HOME/canto)
--sinplugins
Deshabilita todos los plugins.
--habilitarplugins 'plugin1 plugin2...'
Habilita estos plugins (anula --sinplugins).
--deshabilitarplugins 'plugin1 plugin2...'
Deshabilita estos plugins.
-a/--direccion [IP]
Intenta conectarse a la dirección en lugar del socket Unix local, por predeterminado es el loopback (127.0.0.1).
-p/--puerto [puerto]
Usa el puerto al conectarse con -a.

COMANDOS

Canto-remote soporta varios comandos para configurar canto-daemon, aunque se recomienda usar un cliente real.

ayuda [comando]
Obtiene ayuda sobre un comando específico.
addfeed [URL] (usuario=user contrasena=secret) (nombre="Algún nombre")
Se suscribe a un feed, opcionalmente con argumentos especiales. Si no se especifica un nombre, se usará el título del feed.
listfeeds
Lista todos los feeds suscritos.
delfeed [nombre o índice de listfeeds]
Se da de baja de un feed.
status (--etiqueta=etiqueta) (--leido|--total|--etiquetas)
Imprime el número de elementos no leídos, opcionalmente restringido a una etiqueta específica. --leido imprime elementos leídos, --total imprime elementos totales, --etiquetas imprime el valor para todas las etiquetas.

NOTA: Esto todavía está sujeto a filtros, por lo que si estás filtrando todos los elementos leídos, --leido nunca devolverá nada más que 0.

force-update
Vuelve a obtener todos los feeds, independientemente de las marcas de tiempo.
config (="valor")
Cambia una variable de configuración.
(Probablemente no quieras hacer esto manualmente, usa un cliente)
one-config (= valor)
Cambia una sola variable de configuración, asumiendo que toda la línea es una configuración.
(Probablemente no quieras hacer esto manualmente, usa un cliente)
exportar

Escribe una lista de feeds con formato OPML en la salida estándar.
(ej. canto-remote exportar > feedlist.opml)
importar

Importa una lista de feeds con formato OPML desde la entrada estándar.
(ej. canto-remote importar < feedlist.opml)
kill

Detiene el daemon al que te estás conectando.
script

Ejecuta un script (código de prueba).
NOTA: Los plugins también pueden añadir comandos remotos, como 'sync', que también se
listarán con --ayuda (o sin argumentos).
