Varias interfaces de línea de comandos útiles para depurar calibre. Sin opciones, este comando inicia un intérprete de Python incrustado. También puede ejecutar la interfaz gráfica principal de calibre, el visor de libros electrónicos de calibre y el editor de calibre en modo de

depuración.

También contiene interfaces a varias partes de calibre que no tienen herramientas de línea de comandos dedicadas, como el subconjunto de fuentes, la herramienta de diferencia de libros electrónicos,

etc.

También puede usar calibre-debug para ejecutar scripts independientes. Para hacerlo, úselo

así:
calibre-debug -e myscript.py -- --opcion1 --opcion2 archivo1 archivo2 .
.
.

Todo lo que sigue a -- se pasa al script. También puede usar calibre-debug como shebang en scripts,

así:
#!/usr/bin/env -S calibre-debug -e --
--
