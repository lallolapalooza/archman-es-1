__extern caca_dither_t * caca_create_dither (int bpp, int w, int h, int pitch, uint32_t rmask, uint32_t gmask, uint32_t bmask, uint32_t

amask)

Crea una estructura de tramado a partir de sus coordenadas (profundidad, ancho, alto y paso) y los valores de máscara de píxeles. Si la profundidad es de 8 bits por píxel, los valores de máscara se ignoran y la paleta de colores debe establecerse utilizando la función caca_set_dither_palette(). Para profundidades mayores de 8 bits por píxel, una máscara alfa igual a cero hace que los valores alfa se

ignoren.

Si ocurre un error, se devuelve NULL y errno se establece en

consecuencia:
  • EINVAL El ancho, alto, paso o valor de bits por píxel solicitado era
    • inválido.
  • ENOMEM No hay suficiente
    • memoria para asignar l
a estructura de tramado.

Parámetro

s
bpp Profundidad del mapa de bits en bits por píxel.
w Ancho del mapa de bits en píxeles.
h Alto del mapa de bits en píxeles.
pitch Paso del mapa de bits en bytes.
rmask Máscara de bits para los valores rojos.
gmask Máscara de bits para los valores verdes.
bmask Máscara de bits para los valores azules.
amask Máscara de bits para los valores
alfa.

Devuelv

caso de éxito, NULL

    • fondo.
  • 'full8': usar los 8 colores ANSI tanto para los caracteres como para el
    • fondo.
  • 'full16' o 'default': usar los 16 colores A
    • NSI tanto para los caracteres como p

    • tramado.
  • 'random': usar tramado
    • aleatorio.
