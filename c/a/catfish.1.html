NOMBRE

catfish - Herramienta de búsqueda de archivos configurable desde la línea de comandos

DESCRIPCIÓN

Catfish es una práctica herramienta de búsqueda de archivos para Linux y UNIX. La interfaz es intencionadamente ligera y simple, utilizando solo Gtk+3. Puedes configurarla según tus necesidades usando varias opciones de línea de comandos.

SINOPSIS

catfish [opciones] ruta consulta

OPCIONES

--version
Mostrar el número de versión y salir
-h, --help
Mostrar el mensaje de ayuda y salir
-v, --verbose
Mostrar mensajes de depuración (-vv también depurará catfish_lib)
--large-icons
Usar iconos grandes
--thumbnails
Usar miniaturas
--iso-time
Mostrar la hora en formato ISO
--path=RUTA
Establecer la ruta de búsqueda predeterminada
--exact
Realizar coincidencia exacta
--hidden
Incluir archivos ocultos
--fulltext
Realizar búsqueda de texto completo
--start
Si se proporcionan la ruta y la consulta, iniciar la búsqueda cuando se muestre la aplicación.
--sort=ORDEN
Establecer una columna predeterminada para ordenar (nombre|tamaño|ruta|fecha|tipo),(asc|desc)
