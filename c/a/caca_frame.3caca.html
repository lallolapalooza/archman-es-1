__extern int caca_create_frame (caca_canvas_t * cv, int

id)

Crea un nuevo marco dentro del lienzo dado. Su contenido y atributos se copian del marco actualmente

activo.

El índice del marco indica dónde debe insertarse el marco. Los valores válidos van desde 0 hasta el recuento actual de marcos del lienzo. Si el índice del marco es mayor o igual que el recuento actual de marcos del lienzo, el nuevo marco se añade al final del lienzo. Si el índice del marco es menor que cero, el nuevo marco se inserta en el índice

0.

El marco activo no cambia, pero su índice puede ser renumerado debido a la

inserción.

Si ocurre un error, se devuelve -1 y errno se establece en

consecuencia:
•
ENOMEM No hay sufici
ente memoria para asi
gnar el nuevo marco.

__extern int caca_free_frame (caca_canvas_t * cv, int

id)

Elimina un marco de un lienzo

dado.

El índice del marco indica el marco a eliminar. Los valores válidos van desde 0 hasta el recuento actual de marcos del lienzo menos 1. Si el índice del marco es mayor o igual que el recuento actual de marcos del lienzo, se elimina el último

marco.

Si el marco activo es eliminado, el marco 0 se convierte en el nuevo marco activo. De lo contrario, el marco activo no cambia, pero su índice puede ser renumerado debido a la

eliminación.
