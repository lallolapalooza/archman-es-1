NOMBRE

cardos-tool - muestra información sobre tokens de seguridad basados en Card OS o los formatea

SINOPSIS

cardos-tool [OPCIONES]

DESCRIPCIÓN

La utilidad cardos-tool se utiliza para mostrar información sobre tarjetas inteligentes y tokens de seguridad similares basados en Siemens Card/OS M4.

OPCIONES

--format, -f

Formatea la tarjeta o el token.

--help, -h

Imprime el mensaje de ayuda en pantalla.

--info, -i

Muestra información sobre la tarjeta o el token.

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta que coincida.

--startkey arg, -s arg

Especifica la clave de inicio para el formato.

--change-startkey arg, -S arg

Cambia la clave de inicio con el comando APDU dado.

--verbose, -v

Hace que cardos-tool sea más verboso. Especifique este indicador varias veces para habilitar la salida de depuración en la biblioteca opensc.

--wait, -w

Hace que cardos-tool espere a que el token se inserte en el lector.
