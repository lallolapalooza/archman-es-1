NOMBRE

calibre-customize - calibre-customize

opciones de calibre-customize

Personaliza calibre cargando plugins externos.

Siempre que pase argumentos a calibre-customize que contengan espacios, encierre los argumentos entre comillas. Por ejemplo: "/algunaruta/con espacios"

[OPCIONES]

--add-plugin, -a
Añade un plugin especificando la ruta al archivo ZIP que lo contiene.
--build-plugin, -b
Para desarrolladores de plugins: Ruta a la carpeta donde está desarrollando el plugin. Este comando comprimirá automáticamente el plugin en un ZIP y lo actualizará en calibre.
--customize-plugin
Personaliza un plugin. Especifique el nombre del plugin y la cadena de personalización separados por una coma. La cadena de personalización es la misma que introduciría al personalizar el plugin en la interfaz gráfica principal de calibre.
--disable-plugin
Deshabilita el plugin con el nombre indicado
--enable-plugin
Habilita el plugin con el nombre indicado
--help, -h
muestra este mensaje de ayuda y sale
--list-plugins, -l
Lista todos los plugins instalados
--remove-plugin, -r
Elimina un plugin personalizado por su nombre. No tiene efecto sobre los plugins integrados
--version
muestra el número de versión del'programa y sale
