Descripción Detallada

Estas funciones proporcionan rutinas de manejo de fuentes de mapas de bits y renderizado de alta calidad de lienzo a mapa de bits.

Documentación de Funciones

__extern caca_font_t * caca_load_font (void const * data, size_t size)

Esta función carga una fuente y devuelve un manejador a su estructura interna. El manejador puede ser utilizado posteriormente con caca_render_canvas() para la salida en mapa de bits.

También se pueden cargar fuentes internas: si size se establece en 0, data debe ser una cadena que contenga el nombre de la fuente interna.

Si size no es cero, los bytes de tamaño de memoria en la dirección data se cargan como una fuente. Esta área de memoria no debe ser liberada por el programa que llama hasta que el manejador de la fuente haya sido liberado con caca_free_font().

Si ocurre un error, se devuelve NULL y errno se establece en consecuencia:

  • ENOENT La fuente integrada solicitada no existe.
  • EINVAL Datos de fuente inválidos en el área de memoria.
  • ENOMEM No hay suficiente memoria para asignar la estructura de fuente.

Parámetros

data El área de memoria que contiene la fuente o su nombre.
size El tamaño del área de memoria, o 0 si se proporciona el nombre de la fuente.

Devuelve

Un manejador de fuente o NULL en caso de error.

__extern char const *const * caca_get_font_list (void )

Devuelve una lista de fuentes integradas disponibles. La lista es un arreglo de cadenas terminado en NULL.

Esta función nunca falla.

Devuelve

Un arreglo de cadenas.

__extern int caca_get_font_width (caca_font_t const * f)

Devuelve el valor estándar para los glifos de la fuente actual. La mayoría de los glifos en la fuente tendrán este ancho, excepto los caracteres de ancho completo.

Esta función nunca falla.

Parámetros

f La fuente, tal como la devuelve caca_load_font()

Devuelve

El ancho estándar del glifo.

__extern int caca_get_font_height (caca_font_t const * f)

Devuelve el valor estándar para los glifos de la fuente actual. La mayoría de los glifos en la fuente tendrán esta altura.

Esta función nunca falla.

Parámetros

f La fuente, tal como la devuelve caca_load_font()

Devuelve

La altura estándar del glifo.

__extern uint32_t const * caca_get_font_blocks (caca_font_t const * f)

Esta función devuelve la lista de bloques Unicode compatibles con la fuente dada. La lista es una lista de índices terminada en cero. Aquí hay un ejemplo:

{
   0x0000, 0x0080,   // Latín básico: A, B, C, a, b, c
   0x0080, 0x0100,   // Suplemento Latín-1: "A, 'e, ^u
   0x0530, 0x0590,   // Armenio
   0x0000, 0x0000,   // FIN
};

Esta función nunca falla.

Parámetros

f La fuente, tal como la devuelve caca_load_font()

Devuelve

La lista de bloques Unicode compatibles con la fuente.

__extern int caca_render_canvas (caca_canvas_t const * cv, caca_font_t const * f, void * buf, int width, int height, int pitch)

Esta función renderiza el lienzo dado en un búfer de imagen utilizando una fuente específica. El formato de píxeles es fijo (ARGB de 32 bits, 8 bits para cada componente).

El ancho de imagen requerido se puede calcular usando caca_get_canvas_width() y caca_get_font_width(). La altura requerida se puede calcular usando caca_get_canvas_height() y caca_get_font_height().

Los glifos que no caben en el búfer de imagen actualmente no se renderizan en absoluto. Es posible que se recorten en versiones futuras.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL El ancho, la altura o el pitch especificados no son válidos.

Parámetros

cv El lienzo a renderizar
f La fuente, tal como la devuelve caca_load_font()
buf El búfer de imagen
width El ancho (en píxeles) del búfer de imagen
height La altura (en píxeles) del búfer de imagen
pitch El pitch (en bytes) de una línea del búfer de imagen.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_free_font (caca_font_t * f)

Esta función libera todos los datos asignados por caca_load_font(). La estructura de la fuente ya no es utilizable por otras funciones de libcaca. Una vez que esta función ha devuelto, el área de memoria que se proporcionó a caca_load_font() puede ser liberada.

Esta función nunca falla.

Parámetros

f La fuente, tal como la devuelve caca_load_font()

Devuelve

Esta función siempre devuelve 0.
