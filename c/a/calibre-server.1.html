calibre-server - calibre-server

calibre-server [opciones] [ruta a la carpeta de bibliotecas...]

Inicia el servidor de Contenido de calibre. El servidor de Contenido de calibre expone tus bibliotecas de calibre a través de internet. Puedes especificar la ruta a las carpetas de bibliotecas como argumentos para calibre-server. Si no especificas ninguna ruta, se usarán todas las bibliotecas que el programa principal de calibre conoce.

Siempre que pases argumentos a calibre-server que contengan espacios, encierra los argumentos entre comillas. Por ejemplo: "/alguna ruta/con espacios"

[OPCIONES]

--access-log
Ruta al archivo de registro de acceso. Este registro contiene información sobre los clientes que se conectan al servidor y realizan solicitudes. Por defecto, no se realiza ningún registro de acceso.
--ajax-timeout
Tiempo (en segundos) de espera de respuesta del servidor al realizar consultas.
--auth-mode
Elige el tipo de autenticación utilizada. Establece el modo de autenticación HTTP utilizado por el servidor. Configúralo en "basic" si vas a poner este servidor detrás de un proxy SSL. De lo contrario, déjalo en "auto", que usará "basic" si SSL está configurado, de lo contrario usará "digest".
--auto-reload
Recarga automáticamente el servidor cuando cambian el código fuente. Útil para desarrollo. También deberías especificar un valor pequeño para el tiempo de espera de apagado.
--ban-after
Número de fallos de inicio de sesión para prohibir. El número de fallos de inicio de sesión tras los cuales se prohíbe una dirección IP
--ban-for
Prohibir direcciones IP que tengan fallos repetidos de inicio de sesión. Prohíbe temporalmente el acceso a direcciones IP que tengan fallos repetidos de inicio de sesión durante el número especificado de minutos. Útil para evitar intentos de adivinar contraseñas. Si se establece en cero, no se realiza ninguna prohibición.
--book-list-mode
Elige el modo de lista de libros predeterminado. Establece el modo de lista de libros predeterminado que se utilizará para los nuevos usuarios. Los usuarios individuales pueden anular el predeterminado en su propia configuración. El predeterminado es usar una cuadrícula de portadas.
--compress-min-size
Tamaño mínimo para el cual las respuestas utilizan compresión de datos (en bytes).
--custom-list-template
Ruta a un archivo JSON que contiene una plantilla para el modo de lista de libros personalizado. La forma más fácil de crear un archivo de plantilla es ir a Preferencias -> Compartir por la red -> Plantilla de lista de libros en calibre, crear la plantilla y exportarla.
--daemonize
Ejecuta el proceso en segundo plano como un demonio (solo Linux).
--displayed-fields
Restringe los campos definidos por el usuario que se muestran. Lista separada por comas de los campos de metadatos definidos por el usuario que serán mostrados por el servidor de Contenido en las vistas /opds y /mobile. Si especificas esta opción, los campos que no estén en esta lista no se mostrarán. Por ejemplo: mi_valoración,mis_etiquetas
--enable-allow-socket-preallocation, --disable-allow-socket-preallocation
Preasignación de sockets, por ejemplo, con activación de sockets de systemd. Por defecto, esta opción está habilitada.
--enable-auth, --disable-auth
Autenticación basada en contraseña para acceder al servidor. Normalmente, el servidor no tiene restricciones, permitiendo que cualquiera acceda a él. Puedes restringir el acceso a usuarios predefinidos con esta opción. Por defecto, esta opción está deshabilitada.
--enable-fallback-to-detected-interface, --disable-fallback-to-detected-interface
Fallo de respaldo a la interfaz detectada automáticamente. Si por alguna razón el servidor no puede enlazarse a la interfaz especificada en la opción listen_on, entonces intentará detectar una interfaz que se conecte al exterior y enlazarse a ella. Por defecto, esta opción está habilitada.
--enable-local-write, --disable-local-write
Permite la escritura local no autenticada
ciones para realizar cambios. Normalmente, si no activa la autenticación, el servidor opera en modo de solo lectura, para no permitir que los usuarios anónimos realicen cambios en sus bibliotecas de calibre. Esta opción permite que cualquier persona que se conecte desde la misma computadora en la que se ejecuta el servidor realice cambios. Esto es útil si desea ejecutar el servidor sin autenticación pero seguir usando calibredb para realizar cambios en sus bibliotecas de calibre. Tenga en cuenta que activar es
ta opción significa que cualquier programa que se ejecute en la computadora puede realizar cambios en sus bibliotecas de calibre. Por defecto, esta opción está desactivada.

und
Registra las solicitudes HTTP 404 (No encontrado). Normalmente, el servidor r
egistra todas las solicitudes HTTP para recursos que no se encuentran. Esto p
uede generar mucho ruido en el registro si su servidor es el objetivo de bot
s. Use esta opción para desactivarlo. Por defecto, esta opción está activada.

our
Anuncia los feeds OPDS mediante BonJour. Anuncia los feeds OP
DS a través del servicio BonJour, para que las aplicaciones d
e lectura basadas en OPDS puedan detectar y conectarse al serv
idor automáticamente. Por defecto, esta opción está activada.

ile
Transferencias de archivos de copia cero para un mayor rendimiento. Esto usará transferencias de cop
ia cero en el kernel al enviar archivos a través de la red, aumentando el rendimiento. Sin embargo,
puede causar transferencias de archivos corruptas en algunos sistemas de archivos defectuosos. Si ex
perimenta transferencias de archivos corruptas, desactívelo. Por defecto, esta opción está activada.
