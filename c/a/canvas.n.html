l

comando canvas crea una nueva ventana (dada por el argumento pathName) y la convierte en un widget canvas. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del canvas como sus colores y el relieve 3D. El comando canvas devuelve su argumento pathName. En el momento en que se invoca este comando, no debe existir una ventana llamada pathName, pero el padre de pathName debe existir. Los widgets canvas implementan gráficos estructurados. Un canvas muestra cualquier número

de

elementos, que pueden ser cosas como rectángulos, círculos, líneas y texto. Los elementos pueden manipularse (por ejemplo, moverse o recolorearse) y se pueden asociar comandos con los elementos de la misma manera en que el comando bind permite asociar comandos con widgets. Por ejemplo, un comando particular puede asociarse con el evento <Button-1> de modo que el comando se invoque cada vez que se presiona el botón 1 con el cursor del ratón sobre un elemento. Esto significa que los elementos en un canvas pueden tener comportamientos definidos por los scripts Tcl asociados a ellos. LISTA DE VI

Los elementos en un canvas están ordenados con fines de visualización, con el primer elemento en la lista de visualización mostrándose primero, seguido por el siguiente elemento en la lista, y así sucesivamente. Los elementos posteriores en la lista de visualización ocultan a los que están anteriores en la lista de visualización y a veces se les llama estar “encima” de los elementos anteriores. Cuando se crea un nuevo elemento, se coloca al final de la lista de visualización, encima de todo lo demás. Se pueden usar comandos de widget para reorganizar

el orden de la lista de visualización.

Los elementos de ventana son una excepción a las reglas anteriores. Los sistemas de ventana subyacentes requieren que siempre se dibujen encima de otros elementos. Además, el orden de apilamiento de los elementos de ventana no se ve afectado por ninguno de los comandos del widget canvas; debes usar

Los elementos en un widget canvas pueden nombrarse de dos maneras: por id o por etiqueta. Cada elemento tiene un número de identificación único, que se le asigna cuando se crea. El id de un elemento nunca cambia y los números de id nunca se reutilizan dentro de la vida útil de un

widget canvas.

Cada elemento también puede tener cualquier número

de

etiquetas asociadas con él. Una etiqueta es simplemente una cadena de caracteres, y puede tomar cualquier forma excepto la de un entero. Por ejemplo, “x123” es válido pero “123” no lo es. La misma etiqueta puede asociarse con muchos elementos diferentes. Esto se hace comúnmente para agrupar elementos de varias maneras interesantes; por ejemplo, todos los elementos seleccionados podrían recibir la etiqueta “selected”

.

La etiqueta all está implícitamente asociada con cada elemento en el canvas; puede usarse para invocar operaciones en todos los elementos del

canvas.

La etiqueta current es gestionada automáticamente por Tk; se aplica al elemento actual, que es el elemento más alto cuya área dibujada cubre la posición del cursor del ratón (los diferentes tipos de elementos interpretan esto de diversas maneras; consulta la documentación de cada tipo de elemento para obtener detalles). COORDENADA

S

Todas las coordenadas relacionadas con los lienzos se almacenan como números de punto flotante. Las coordenadas y distancias se especifican en unidades de pantalla, que son números de punto flotante seguidos opcionalmente por una de varias letras. Si no se proporciona ninguna letra, entonces la distancia está en píxeles. Si la letra es m entonces la distancia está en milímetros en la pantalla; si es c entonces la distancia está en centímetros; i significa pulgadas, y p significa puntos de impresora (1/72 de pulgada). Las coordenadas y más grandes se refieren a puntos más abajo en la pantalla; las coordenadas x más grandes se refieren a puntos más a la derecha. Las coordenadas se pueden especificar como un número par de parámetros, o como un único parámetro de lista que contiene un número par de valores de coordenadas x e

y.

TRANSFORMACIONE

S

Normalmente, el origen del sistema de coordenadas del lienzo está en la esquina superior izquierda de la ventana que contiene el lienzo. Es posible ajustar el origen del sistema de coordenadas del lienzo en relación con el origen de la ventana usando los comandos de widget xview y yview; esto se usa típicamente para el desplazamiento. Los lienzos no admiten el escalado o la rotación del sistema de coordenadas del lienzo en relación con el sistema de coordenadas de la

ventana.

Los elementos individuales se pueden mover o escalar usando los comandos de widget descritos a continuación, pero no se pueden

rotar.

Tenga en cuenta que el origen predeterminada del área visible del lienzo es coincidente con el origen de toda la ventana, ya que esto hace que los enlaces usando la posición del ratón funcionen más fácilmente; solo necesita usar los comandos de widget canvasx y canvasy si ajusta el origen del área visible. ELEMENTOS

Las secciones siguientes describen los varios tipos de elementos soportados por los widgets de lienzo. Cada tipo de elemento se caracteriza por dos cosas: primero, la forma del comando create utilizado para crear instancias del tipo; y segundo, un conjunto de opciones de configuración para los elementos de ese tipo, que pueden ser usadas en los comandos de widget create y itemconfigure. La mayoría de los elementos no soportan indexado o selección o los comandos relacionados con ellos, como index y insert. Donde los elementos sí soportan estas instalaciones, se señala explícitamente en las descripciones siguientes. Actualmente, los elementos de texto, línea y polígono proporcionan este soporte. Para líneas y polígonos la facilidad de indexado se usa para manipular las coordenadas del

elemento.
