__extern uint32_t caca_get_attr (caca_canvas_t const * cv, int x, int y)

Obtener el valor de atributo interno de libcaca del carácter en las coordenadas dadas. El valor del atributo tiene 32 bits significativos, organizados de la siguiente manera desde el bit más significativo (MSB) hasta el bit menos significativo (LSB):

  • 3 bits para el canal alfa de fondo
  • 4 bits para el componente rojo de fondo
  • 4 bits para el componente verde de fondo
  • 3 bits para el componente azul de fondo
  • 3 bits para el canal alfa de primer plano
  • 4 bits para el componente rojo de primer plano
  • 4 bits para el componente verde de primer plano
  • 3 bits para el componente azul de primer plano
  • 4 bits para las banderas de negrita, cursiva, subrayado y parpadeo

Si las coordenadas están fuera de los límites del lienzo, se devuelve el atributo actual.

Esta función nunca falla.

Parámetros

cv Un identificador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.

Devuelve

El atributo solicitado.

Referenciado por caca_conio_textbackground(), caca_conio_textcolor(), caca_dither_bitmap(), caca_flush_figlet(), y caca_put_figchar().

__extern int caca_set_attr (caca_canvas_t * cv, uint32_t attr)

Establecer el atributo de carácter predeterminado para el dibujo. Los atributos definen el color de primer plano y de fondo, la transparencia, los estilos de negrita, cursiva y subrayado, así como el parpadeo. Las funciones de cadena como caca_printf() y las funciones de primitivas gráficas como caca_draw_line() usarán este atributo.

El valor de attr es cualquiera de los siguientes:

  • un entero de 32 bits como el devuelto por caca_get_attr(), en cuyo caso también contiene información de color,
  • una combinación (OR bit a bit) de valores de estilo (CACA_UNDERLINE, CACA_BLINK, CACA_BOLD y CACA_ITALICS), en cuyo caso establecer el atributo no modifica la información de color actual.

Para recuperar el valor del atributo actual, use caca_get_attr(-1,-1).

Esta función nunca falla.

Parámetros

cv Un identificador para el lienzo de libcaca.
attr El valor de atributo solicitado.

Devuelve

Esta función siempre devuelve 0.

Referenciado por caca_dither_bitmap(), y caca_put_figchar().

__extern int caca_put_attr (caca_canvas_t * cv, int x, int y, uint32_t attr)

Establecer el atributo de carácter, sin cambiar el valor del carácter. Si el carácter en las coordenadas dadas es un carácter de ancho completo, se reemplazan los atributos de ambas celdas.

__extern int caca_set_color_ansi (caca_canvas_t * cv, uint8_t fg, uint8_t bg)

Establece el par de colores ANSI predeterminado para el dibujo de texto. Las funciones de cadena como caca_printf() y las funciones de primitivas gráficas como caca_draw_line() usarán estos atributos.

Los valores de color son los definidos en caca.h, como CACA_RED o CACA_TRANSPARENT.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL Al menos uno de los valores de color es inválido.

Parámetros

cv Un identificador para el lienzo de libcaca.
fg El color de primer plano ANSI solicitado.
bg El color de fondo ANSI solicitado.

Devoluciones

0 en caso de éxito, -1 si ocurrió un error.

Referenciado por caca_conio_textbackground(), caca_conio_textcolor(), caca_create_canvas(), y caca_dither_bitmap().

__extern int caca_set_color_argb (caca_canvas_t * cv, uint16_t fg, uint16_t bg)

Establece el par de colores ARGB predeterminado para el dibujo de texto. Las funciones de cadena como caca_printf() y las funciones de primitivas gráficas como caca_draw_line() usarán estos atributos.

Los colores son valores ARGB de 16 bits, cada componente codificado en 4 bits. Por ejemplo, 0xf088 es cian oscuro sólido (A=15 R=0 G=8 B=8), y 0x8fff es blanco con 50% de alfa (A=8 R=15 G=15 B=15).

Esta función nunca falla.

Parámetros

cv Un identificador para el lienzo de libcaca.
fg El color de primer plano ARGB solicitado.
bg El color de fondo ARGB solicitado.

Devoluciones

Esta función siempre devuelve 0.

__extern uint8_t caca_attr_to_ansi (uint32_t attr)

Obtiene el par de colores ANSI para un atributo dado. El valor devuelto es un valor de 8 bits cuyos 4 bits superiores son el color de fondo y los 4 bits inferiores son el color de primer plano.

Si el atributo tiene colores ARGB, se usa el color más cercano. Los atributos especiales como CACA_DEFAULT y CACA_TRANSPARENT no se manejan y ambos se reemplazan con CACA_LIGHTGRAY para el color de primer plano y CACA_BLACK para el color de fondo.

Esta función nunca falla. Si el valor del atributo está fuera del rango de 32 bits esperado, los bits de orden superior simplemente se ignoran.

Parámetros

attr El valor de atributo solicitado.

Devoluciones

El valor ANSI de DOS correspondiente.

Referencias CACA_BLACK, y CACA_LIGHTGRAY.

__extern uint8_t caca_attr_to_ansi_fg (uint32_t attr)

Obtiene el valor de color de primer plano ANSI para un atributo dado. El valor devuelto es uno de los colores predefinidos CACA_RED, CACA_BLACK etc., o el valor especial CACA_DEFAULT que significa el valor de primer plano predeterminado del medio, o el valor especial CACA_TRANSPARENT.

Si el atributo tiene colores ARGB, se devuelve el color más cercano.

Esta función nunca falla. Si el valor del atributo está fuera del rango de 32 bits esperado, los bits de orden superior simplemente se ignoran.

Parámetros

attr El valor de atributo solicitado.

Devoluciones

El valor de primer plano ANSI correspondiente.

Referenciado por caca_conio_textbackground().

__extern uint16_t caca_attr_to_rgb12_fg (uint32_t attr)

Obtiene el valor de color de primer plano de 12 bits para un atributo dado. El valor devuelto es un entero codificado en el orden nativo de la máquina con cada valor de rojo, verde y azul codificado en 8 bits en el siguiente orden:

  • bits 8-11 más significativos: rojo
  • bits 4-7 más significativos: verde
  • bits menos significativos: azul

Esta función nunca falla. Si el valor del atributo está fuera del rango de 32 bits esperado, los bits de orden superior simplemente se ignoran.

Parámetros

attr El valor de atributo solicitado.

Devoluciones

El valor de primer plano RGB de 12 bits correspondiente.

Referencias CACA_DEFAULT, CACA_LIGHTGRAY, y CACA_TRANSPARENT.

__extern void caca_attr_to_argb64 (uint32_t attr, uint8_t argb[8])

Obtiene los valores de color y alfa de 64 bits para un atributo dado. Los valores se escriben como enteros de 8 bits en el argb array en el siguiente orden:

  • argb[0]: valor alfa de fondo
  • argb[1]: valor rojo de fondo
  • argb[2]: valor verde de fondo
  • argb[3]: valor azul de fondo
  • argb[4]: valor alfa de primer plano
  • argb[5]: valor rojo de primer plano
  • argb[6]: valor verde de primer plano
  • argb[7]: valor azul de primer plano

Esta función nunca falla. Si el valor del atributo está fuera del rango de 32 bits esperado, los bits de orden superior simplemente se ignoran.

Parámetros

attr El valor de atributo solicitado.
argb Un array de enteros de 8 bits.

Referencias CACA_BLACK, CACA_DEFAULT, CACA_LIGHTGRAY, y CACA_TRANSPARENT.
