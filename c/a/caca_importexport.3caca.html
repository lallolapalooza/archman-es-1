__extern ssize_t caca_import_canvas_from_memory (caca_canvas_t * cv, void const * data, size_t len, char const * format)

Importa un búfer de memoria al marco actual del lienzo de libcaca proporcionado. El marco actual se redimensiona en consecuencia y su contenido se reemplaza con los datos importados.

Los valores válidos para format son:

  • '': intenta autodetectar el formato del archivo.
  • 'caca': importa archivos nativos de libcaca.
  • 'text': importa archivos de texto ASCII.
  • 'ansi': importa archivos ANSI.
  • 'utf8': importa archivos UTF-8 con códigos de color ANSI.
  • 'bin': importa archivos BIN.

Se devuelve el número de bytes leídos. Si el formato del archivo es válido, pero no había suficientes datos disponibles, se devuelve 0.

Si ocurre un error, se devuelve -1 y errno se establece correspondientemente:

  • ENOMEM No hay suficiente memoria para asignar el lienzo.
  • EOVERFLOW La importación de datos causó un desbordamiento de valor.
  • EINVAL Formato no válido solicitado.

Parámetros

cv Un lienzo de libcaca en el que importar el archivo.
data Un área de memoria que contiene los datos a cargar en el lienzo.
len El tamaño en bytes del área de memoria.
format Una cadena que describe el formato de entrada.

Devoluciones

El número de bytes leídos, o 0 si no había suficientes datos, o -1 si ocurrió un error.

Referenciado por caca_import_area_from_memory() y caca_import_canvas_from_file().

__extern ssize_t caca_import_canvas_from_file (caca_canvas_t * cv, char const * filename, char const * format)

Importa un archivo al marco actual del lienzo de libcaca proporcionado. El marco actual se redimensiona en consecuencia y su contenido se reemplaza con los datos importados.

Los valores válidos para format son:

  • '': intenta autodetectar el formato del archivo.
  • 'caca': importa archivos nativos de libcaca.
  • 'text': importa archivos de texto ASCII.
  • 'ansi': importa archivos ANSI.
  • 'utf8': importa archivos UTF-8 con códigos de color ANSI.
  • 'bin': importa archivos BIN.

Se devuelve el número de bytes leídos. Si el formato del archivo es válido, pero no había suficientes datos disponibles, se devuelve 0.

Si ocurre un error, se devuelve -1 y errno se establece correspondientemente:

  • ENOSYS El acceso a archivos no está implementado en este sistema.
  • ENOMEM No hay suficiente memoria para asignar el lienzo.
  • EINVAL Formato no válido solicitado. caca_import_file() también puede fallar y establecer errno para cualquiera de los errores especificados para la rutina fopen().

Parámetros

cv Un lienzo de libcaca en el que importar el archivo.
filename El nombre del archivo a cargar.
format Una cadena que describe el formato de entrada.

Devoluciones

El número de bytes leídos, o 0 si no había suficientes datos, o -1 si ocurrió un error.

Referencia caca_file_close(), caca_file_eof(), caca_file_open(), caca_file_read() y caca_import_canvas_from_memory().

__extern void * caca_export_canvas_to_memory (caca_canvas_t const * cv, char const * format, size_t * len)

Exporta el lienzo dado a un formato externo. El búfer devuelto debe ser liberado con caca_free().

Los valores válidos para format son:

  • 'caca': exporta archivos nativos de libcaca.
  • 'text': exporta archivos de texto ASCII.
  • 'ansi': exporta archivos ANSI.
  • 'utf8': exporta archivos UTF-8 con códigos de color ANSI.
  • 'html': exporta archivos HTML.
  • 'ps': exporta archivos PostScript.
  • 'svg': exporta archivos SVG.
  • 'gif': exporta archivos GIF animados.
  • 'jpg': exporta archivos JPG animados.
  • 'png': exporta archivos PNG animados.
  • 'bmp': exporta archivos BMP animados.
  • 'ppm': exporta archivos PPM animados.
  • 'tbl': exporta archivos Tab-separated Values (Valores separados por tabulaciones).

El tamaño del búfer devuelto se almacena en la variable apuntada por len.

Si ocurre un error, se devuelve un puntero NULL y errno se establece correspondientemente:

  • ENOMEM No hay suficiente memoria para asignar el búfer.
  • EINVAL Formato no válido solicitado.

Parámetros

cv El lienzo de libcaca a exportar.
format Una cadena que describe el formato de salida.
len Un puntero a una variable de tipo size_t donde se almacenará el tamaño del búfer devuelto.

Devoluciones

Un puntero a un búfer que contiene los datos exportados, o un puntero NULL si ocurrió un error.

Referencia caca_free_canvas(), caca_new_canvas(), y caca_import_canvas_from_memory().

Referenciado por caca_export_area_to_memory().

caca_import_canvas_from_file, caca_export_canvas_to_memory, caca_export_area_to_memory - import/export canvas data

Detailed Description

This functions import or export libcaca canvas data from or to various foreign formats.

Function Documentation

__extern int caca_import_canvas_from_file (caca_canvas_t * cv, const char * filename, const char * format)

This function imports a libcaca canvas from a file. The supported formats are listed by caca_get_import_list().

If an error occurs, the function returns 0.

Parameters

cv A libcaca canvas
filename A string containing the name of the file to load.
format A string describing the requested import format.

Returns

The number of bytes read, or 0 if there was not enough data, or -1 if an error occurred.

References caca_blit(), caca_create_canvas(), caca_free_canvas(), and caca_import_canvas_from_file().

__extern char const *const * caca_get_import_list (void )

Return a list of available import formats. The list is a NULL-terminated array of strings, interleaving a string containing the internal value for the import format, to be used with caca_import_canvas(), and a string containing the natural language description for that import format.

This function never fails.

Returns

An array of strings.

__extern void * caca_export_canvas_to_memory (caca_canvas_t const * cv, char const * format, size_t * bytes)

This function exports a libcaca canvas into various foreign formats such as ANSI art, HTML, IRC colours, etc. The returned pointer should be passed to free() to release the allocated storage when it is no longer needed.

Valid values for format are:

  • 'caca': export native libcaca files.
  • 'ansi': export ANSI art (CP437 charset with ANSI colour codes).
  • 'html': export an HTML page with CSS information.
  • 'html3': export an HTML table that should be compatible with most navigators, including textmode ones.
  • 'irc': export UTF-8 text with mIRC colour codes.
  • 'ps': export a PostScript document.
  • 'svg': export an SVG vector image.
  • 'tga': export a TGA image.
  • 'troff': export a troff source.

If an error occurs, NULL is returned and errno is set accordingly:

  • EINVAL Unsupported format requested.
  • ENOMEM Not enough memory to allocate output buffer.

Parameters

cv A libcaca canvas
format A string describing the requested output format.
bytes A pointer to a size_t where the number of allocated bytes will be written.

Returns

A pointer to the exported memory area, or NULL in case of error.

Referenced by caca_export_area_to_memory().

__extern void * caca_export_area_to_memory (caca_canvas_t const * cv, int x, int y, int w, int h, char const * format, size_t * bytes)

This function exports a portion of a libcaca canvas into various formats. For more information, see caca_export_canvas_to_memory().

If an error occurs, NULL is returned and errno is set accordingly:

  • EINVAL Unsupported format requested or invalid coordinates.
  • ENOMEM Not enough memory to allocate output buffer.

Parameters

cv A libcaca canvas
x The leftmost coordinate of the area to export.
y The topmost coordinate of the area to export.
w The width of the area to export.
h The height of the area to export.
format A string describing the requested output format.
bytes A pointer to a size_t where the number of allocated bytes will be written.

Returns

A pointer to the exported memory area, or NULL in case of error.

References caca_blit(), caca_create_canvas(), caca_export_canvas_to_memory(), and caca_free_canvas().

__extern char const *const * caca_get_export_list (void )

Return a list of available export formats. The list is a NULL-terminated array of strings, interleaving a string containing the internal value for the export format, to be used with caca_export_memory(), and a string containing the natural language description for that export format.

This function never fails.

Returns

An array of strings.
