La bandera --locked puede usarse para forzar a Cargo a usar el archivo Cargo.lock empaquetado si está disponible. Esto puede ser útil para asegurar compilaciones reproducibles, para usar el mismo conjunto exacto de dependencias que estaban disponibles cuando se publicó el paquete. También puede ser útil si se publica una versión más nueva de una dependencia que ya no compila en su sistema, o tiene otros problemas. La desventaja de usar --locked es que no recibirá ninguna corrección o actualización de ninguna dependencia. Tenga en cuenta que Cargo no comenzó a publicar archivos Cargo.lock hasta la versión 1.37, lo que significa que los paquetes publicados con versiones anteriores no tendrán un archivo Cargo.lock disponible.
