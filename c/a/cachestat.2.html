cachestat(2) Manual de llamadas al sistema cachestat(2)

NOMBRE

cachestat - consultar las estadísticas de la caché de páginas de un archivo

SINOPSIS

#include <sys/mman.h>
int cachestat(unsigned int fd, struct cachestat_range *cstat_range,
              struct cachestat *cstat, unsigned int flags);
struct cachestat_range {
    __u64 off;
    __u64 len;
};
struct cachestat {
    __u64 nr_cache;
    __u64 nr_dirty;
    __u64 nr_writeback;
    __u64 nr_evicted;
    __u64 nr_recently_evicted;
};

DESCRIPCIÓN

cachestat() consulta el número de páginas cacheadas, páginas sucias, páginas marcadas para escritura, páginas desalojadas y páginas recién desalojadas en el rango de bytes especificado por .off y .len en la estructura cachestat_range.

Una página desalojada es una que estuvo previamente en la caché de páginas pero que desde entonces ha sido desalojada. Una página se considera recién desalojada si su reentrada en la caché indicaría un uso activo bajo presión de memoria.

Los resultados se devuelven en una estructura cachestat, apuntada por el argumento cstat.

Los campos .off y .len deben ser no negativos. Si .len > 0, el rango consultado es [.off, .off+.len]. Si len == 0, el rango es desde .off hasta el final del archivo.

El argumento flags está reservado para uso futuro y debe establecerse en 0.

Actualmente, los archivos hugetlbfs no son compatibles.

VALOR DE RETORNO

En caso de éxito, cachestat() devuelve 0. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
cstat o cstat_range apuntan a una dirección inválida.
EINVAL
Valor de flags inválido.
EBADF
Descriptor de archivo inválido.
EOPNOTSUPP
El descriptor de archivo se refiere a un archivo hugetlbfs, que no es compatible.

ESTANDARES

Linux.

HISTORIA

Linux 6.5.

PRECAUCIONES

Tenga en cuenta que el estado de una página puede cambiar después de que cachestat() lo recupere pero antes de que los valores se devuelvan a la aplicación; por lo tanto, los valores pueden estar ligeramente desactualizados.
