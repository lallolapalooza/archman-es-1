__extern uint32_t caca_get_attr (caca_canvas_t const * cv, int x, int y)

Obtiene el valor de atributo interno de libcaca del carácter en las coordenadas dadas. El valor del atributo tiene 32 bits significativos, organizados de la siguiente manera de MSB a LSB:

  • 3 bits para el alfa de fondo
  • 4 bits para el componente rojo de fondo
  • 4 bits para el componente verde de fondo
  • 3 bits para el componente azul de fondo
  • 3 bits para el alfa de primer plano
  • 4 bits para el componente rojo de primer plano
  • 4 bits para el componente verde de primer plano
  • 3 bits para el componente azul de primer plano
  • 4 bits para las banderas de negrita, cursiva, subrayado y parpadeo

Si las coordenadas están fuera de los límites del lienzo, se devuelve el atributo actual.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.

Devuelve

El atributo solicitado.

Referenciado por caca_conio_textbackground(), caca_conio_textcolor(), caca_dither_bitmap(), caca_flush_figlet() y caca_put_figchar().

__extern int caca_set_attr (caca_canvas_t * cv, uint32_t attr)

Establece el atributo de carácter predeterminado para el dibujo. Los atributos definen el color de primer plano y fondo, la transparencia, los estilos negrita, cursiva y subrayado, así como el parpadeo. Las funciones de cadena como caca_printf() y las funciones de primitivas gráficas como caca_draw_line() utilizarán este atributo.

El valor de attr es:

  • un entero de 32 bits como el devuelto por caca_get_attr(), en cuyo caso también contiene información de color,
  • una combinación (OR bit a bit) de valores de estilo (CACA_UNDERLINE, CACA_BLINK, CACA_BOLD y CACA_ITALICS), en cuyo caso establecer el atributo no modifica la información de color actual.

Para recuperar el valor del atributo actual, use caca_get_attr(-1,-1).

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
attr El valor de atributo solicitado.

Devuelve

Esta función siempre devuelve 0.

Referenciado por caca_dither_bitmap() y caca_put_figchar().

__extern int caca_unset_attr (caca_canvas_t * cv, uint32_t attr)

__extern int caca_put_attr (caca_canvas_t * cv, int x, int y, uint32_t attr)

Establece el atributo del carácter, sin cambiar el valor del carácter. Si el carácter en las coordenadas dadas es un carácter de ancho completo, se reemplazan los atributos de ambas celdas.

__extern uint8_t caca_attr_to_ansi (uint32_t

attr)

Obtiene la pareja de colores ANSI para un atributo dado. El valor devuelto es un valor de 8 bits cuyos 4 bits superiores son el color de fondo y los 4 bits inferiores son el color de primer

plano.

Si el atributo tiene colores ARGB, se usa el color más cercano. Los atributos especiales como CACA_DEFAULT y CACA_TRANSPARENT no se manejan y ambos se reemplazan con CACA_LIGHTGRAY para el color de primer plano y CACA_BLACK para el color de

fondo.

Esta función nunca falla. Si el valor del atributo está fuera del rango de 32 bits esperado, los bits de orden superior simplemente se

ignoran.
