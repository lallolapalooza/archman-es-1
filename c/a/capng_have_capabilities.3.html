capng_have_capabilities(3)

Paquete: libcap-ng

Licencias: GPL-2.0-or-later, LGPL-2.1-or-later

CAPNG_HAVE_CAPABILITIES(3) API de Libcap-ng CAPNG_HAVE_CAPABILITIES(3)

NOMBRE

capng_have_capabilities, capng_have_permitted_capabilities - comprobar capacidades

SINOPSIS

#include <cap-ng.h>

capng_results_t capng_have_capabilities(capng_select_t set); capng_results_t capng_have_permitted_capabilities(void);

DESCRIPCIÓN

capng_have_capabilities comprobará los conjuntos de capacidades internas seleccionados para ver su estado. Los conjuntos de capacidades deben haber sido configurados previamente con llamadas a capng_get_caps_process, capng_get_caps_fd, o de alguna otra manera. Las opciones son CAPNG_SELECT_CAPS para las capacidades tradicionales, CAPNG_SELECT_BOUNDS para el conjunto de límites, CAPNG_SELECT_BOTH si se desea comprobar ambos, CAPNG_SELECT_AMBIENT si solo se comprueban las capacidades ambientales, o CAPNG_SELECT_ALL si se desea probar todos los conjuntos. Al comprobar las capacidades, solo se mirarán las capacidades efectivas.

Sin embargo, si la fuente de las capacidades proviene de un archivo, es posible que necesites comprobar adicionalmente las capacidades permitidas. Por esta razón se creó capng_have_permitted_capabilities. No toma argumentos porque simplemente comprueba el conjunto permitido.

VALOR DE RETORNO

Esta función devolverá uno de los siguientes cuatro valores autoexplicativos: CAPNG_FAIL, CAPNG_NONE, CAPNG_PARTIAL, CAPNG_FULL.

VER TAMBIÉN

capng_get_caps_process(3), capng_get_caps_fd(3), capng_have_capability(3), capabilities(7)
