CAPTEST:(8) Utilidades de administración del sistema CAPTEST:(8)

NOMBRE

captest - un programa para demostrar capacidades

SINOPSIS

captest [ --ambient --drop-all | --drop-caps | --id ] [ --init-grp ] [ --lock ] [ --text ]

DESCRIPCIÓN

captest es un programa que demuestra e imprime las capacidades del proceso actual. Cada opción imprime el mismo informe. Mostrará las capacidades actuales. Luego, intentará acceder directamente a /etc/shadow para mostrar si se puede hacer. Luego crea un proceso hijo que intenta leer /etc/shadow y muestra los resultados de eso. Luego imprime las capacidades que tendría un proceso hijo.

También puedes aplicar capacidades del sistema de archivos a este programa para estudiar cómo funcionan. Por ejemplo, filecap /usr/bin/captest chown. Luego ejecuta captest como un usuario normal. Otra prueba interesante es hacer que captest sea suid root para que puedas ver cuál es la interacción entre las credenciales de root y las capacidades. Por ejemplo, chmod 4755 /usr/bin/captest. Cuando se ejecuta como un usuario normal, el programa verá si la escalada de privilegios es posible. Pero no dejes esta aplicación establecida en setuid root después de haber terminado las pruebas para que un atacante no pueda aprovecharse de ella.

OPCIONES

--ambient
Esto intenta agregar la capacidad ambiental CAP_CHOWN.
--drop-all
Esto elimina todas las capacidades, incluidas las ambientales, y borra el conjunto de límites.
--drop-caps
Esto elimina solo las capacidades tradicionales.
--id
Esto cambia a uid y gid 99, elimina grupos suplementarios y borra el conjunto de límites.
--init-grp
Esto cambia a uid y gid 99 y luego agrega cualquier grupo suplementario que venga con esa cuenta. Deberías agregarlos antes de probar porque, por defecto, no hay grupos suplementarios en la cuenta 99.
--text
Esta opción muestra las capacidades efectivas en texto en lugar de numéricamente.
--lock
Esto impide la capacidad de los procesos hijos para recuperar privilegios si el uid es 0.

VER TAMBIÉN

filecap(8), capabilities(7)
