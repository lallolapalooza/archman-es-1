capng_print_caps_numeric(3)

CAPNG_PRINT_CAPS_NUMERIC(3) API de Libcap-ng CAPNG_PRINT_CAPS_NUMERIC(3)

NOMBRE

capng_print_caps_numeric - imprime valores numéricos para el conjunto de capacidades

SINOPSIS

#include <cap-ng.h>

char *capng_print_caps_numeric(capng_print_t where, capng_select_t set);

DESCRIPCIÓN

capng_print_caps_numeric creará una representación numérica de las capacidades internas. La representación se puede enviar a stdout o a un búfer pasando CAPNG_PRINT_STDOUT o CAPNG_PRINT_BUFFER respectivamente para el parámetro where. Si la opción fue para un búfer, esta función hará malloc de un búfer que el llamador debe liberar.

El parámetro set controla qué se incluye en la representación. Las opciones legales son CAPNG_SELECT_CAPS para las capacidades tradicionales, CAPNG_SELECT_BOUNDS para el conjunto de límites, CAPNG_SELECT_BOTH si se desea imprimir ambos, CAPNG_SELECT_AMBIENT si solo se imprimen las capacidades ambientales, o CAPNG_SELECT_ALL si se desea imprimir todas.

VALOR DE RETORNO

Si se seleccionó CAPNG_PRINT_BUFFER para where, este será el búfer de texto y NULL en caso de fallo. Si se seleccionó CAPNG_PRINT_STDOUT, este valor será NULL sin importar qué.

VER TAMBIÉN

capng_print_caps_text(3), capabilities(7)
