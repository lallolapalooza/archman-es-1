__extern int caca_free_canvas (caca_canvas_t * cv)

Libera todos los recursos asignados por caca_create_canvas(). El puntero al lienzo se invalida y no debe volver a usarse a menos que se realice una nueva llamada a caca_create_canvas().

Si ocurre un error, se devuelve -1 y se establece errno en consecuencia:

•
EBUSY El lienzo está en uso por un controlador de pantalla y no puede ser liberado.

Parámetros

cv Un lienzo libcaca.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.
