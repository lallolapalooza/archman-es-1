__extern int caca_set_canvas_size (caca_canvas_t * cv, int width, int

height)

Establece el ancho y alto del lienzo, en celdas de

caracteres.

El contenido del lienzo se conserva en la medida del nuevo tamaño del lienzo. Las nuevas celdas de caracteres asignadas a la derecha y/o en la parte inferior del lienzo se rellenan con

espacios.

Si como resultado del redimensionado las coordenadas del cursor caen fuera de los nuevos límites del lienzo, se readjustan. Por ejemplo, si la coordenada X actual del cursor es 11 y el ancho solicitado es 10, la nueva coordenada X del cursor será

10.

Es un error intentar redimensionar el lienzo si un controlador de salida ha sido adjuntado al lienzo usando caca_create_display(). Necesitas eliminar el controlador de salida usando caca_free_display() antes de poder cambiar el tamaño del lienzo de nuevo. Sin embargo, el controlador de salida de caca puede causar un redimensionado del lienzo a través de la interacción del usuario. Consulta la documentación de caca_event() para más información al

respecto.

Si ocurre un error, se devuelve -1 y errno se establece en

consecuencia:
  • EINVAL El ancho o alto especificado no es
    • válido.
  • EOVERFLOW El ancho y alto especificados
    • desbordaron.
  • EBUSY El lienzo está en uso por un controlador de visualización y no puede ser
    • redimensionado.
  • ENOMEM No hay suficiente memoria para el tamaño de li
    • enzo solicitado. Si esto ocurre, el manejador d
