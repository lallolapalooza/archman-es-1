Documentación de Funciones

__extern caca_file_t * caca_file_open (char const * path, const char * mode)

Crea un manejador de archivo de caca para un archivo. Si el archivo está comprimido, se descomprime sobre la marcha.

Si ocurre un error, se devuelve NULL y se establece errno en consecuencia:

  • ENOSTS Función no implementada.
  • EINVAL Archivo no encontrado o permiso denegado.

Parámetros

path La ruta del archivo
mode El modo de apertura del archivo

Retorna

Un manejador de archivo para path.

Referenciado por caca_import_canvas_from_file().

__extern int caca_file_close (caca_file_t * fp)

Cierra y destruye los recursos asociados a un manejador de archivo de caca.

Esta función es un envoltorio para fclose() o, si está disponible, gzclose().

Parámetros

fp El manejador de archivo

Retorna

El valor de retorno de fclose() o gzclose().

__extern char * caca_file_gets (caca_file_t * fp, char * s, int size)

Lee una línea de datos de un manejador de archivo, hasta un byte menos que el número de bytes especificado. Se añade un cero final a los datos.

Parámetros

fp El manejador de archivo
s El búfer de destino
size El número máximo de bytes a leer

Retorna

El número de bytes leídos, incluido el cero final

__extern int caca_file_eof (caca_file_t * fp)

Devuelve el estado de fin de archivo del manejador de archivo.

Esta función es un envoltorio para feof() o, si está disponible, gzeof().

Parámetros

fp El manejador de archivo

Retorna

1 si se alcanzó el final del archivo, 0 en caso contrario
