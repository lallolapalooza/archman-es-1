CARGO-UNINSTALL(1) Manual de Comandos Generales CARGO-UNINSTALL(1)

NOMBRE

cargo-uninstall — Eliminar un binario de Rust

SINOPSIS

cargo uninstall [opciones] [especificación…]

DESCRIPCIÓN

Este comando elimina un paquete instalado con cargo-install(1). El argumento especificación es una especificación de ID de paquete del paquete a eliminar (ver cargo-pkgid(1)).

Por defecto, se eliminan todos los binarios de un crate, pero las opciones --bin y --example se pueden usar para eliminar solo binarios específicos.

La raíz de instalación se determina, en orden de precedencia:

•Opción --root
•Variable de entorno CARGO_INSTALL_ROOT
•Valor de configuración config.install.root de Cargo https://doc.rust-lang.org/cargo/reference/config.html
•Variable de entorno CARGO_HOME
•$HOME/.cargo

OPCIONES

Opciones de Desinstalación

-p, --package especificación…

Paquete a desinstalar.

--bin nombre…

Solo desinstalar el binario nombre.

--root dir

Directorio desde el cual desinstalar paquetes.

Opciones de Visualización

-v, --verbose

Usar salida detallada. Se puede especificar dos veces para una salida “muy detallada” que incluye información adicional como advertencias de dependencias y salida de scripts de compilación. También se puede especificar con el valor de configuración term.verbose https://doc.rust-lang.org/cargo/reference/config.html.

-q, --quiet

No imprimir mensajes de registro de cargo. También se puede especificar con el valor de configuración term.quiet https://doc.rust-lang.org/cargo/reference/config.html.

--color cuándo

Controlar cuándo se utiliza la salida en color. Valores válidos:
•auto (predeterminado): Detectar automáticamente si el soporte de color está disponible en la terminal.
•always: Mostrar siempre colores.
•never: Nunca mostrar colores.

También se puede especificar con el valor de configuración term.color https://doc.rust-lang.org/cargo/reference/config.html.

Opciones Comunes

+toolchain

Si Cargo se ha instalado con rustup, y el primer argumento de cargo comienza con +, se interpretará como un nombre de toolchain de rustup (como +stable o +nightly). Consulte la documentación de rustup https://rust-lang.github.io/rustup/overrides.html para obtener más información sobre cómo funcionan las anulaciones de toolchain.

--config CLAVE=VALOR o RUTA

Anula un valor de configuración de Cargo. El argumento debe estar en sintaxis TOML de CLAVE=VALOR, o proporcionarse como una ruta a un archivo de configuración adicional. Esta opción se puede especificar varias veces. Consulte la sección de anulaciones de línea de comandos https://doc.rust-lang.org/cargo/reference/config.html#command-line-overrides para obtener más información.

-C RUTA

Cambia el directorio de trabajo actual antes de ejecutar cualquier operación especificada. Esto afecta a dónde busca Cargo por defecto el manifiesto del proyecto (Cargo.toml), así como a los directorios buscados para descubrir .cargo/config.toml, por ejemplo. Esta opción debe aparecer antes del nombre del comando, por ejemplo cargo -C ruta/a/mi-proyecto build.

Esta opción solo está disponible en el canal nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html y requiere la bandera -Z unstable-options para habilitarse (ver #10098 https://github.com/rust-lang/cargo/issues/10098).

-h, --help

Imprime la información de ayuda.

-Z bandera

Banderas inestables (solo para nightly) para Cargo. Ejecute cargo -Z help para más detalles.

ENTORNO

Consulte la referencia https://doc.rust-lang.org/cargo/reference/environment-variables.html para obtener detalles sobre las variables de entorno que Cargo lee.

ESTADO DE SALIDA

•0: Cargo tuvo éxito.
•101: Cargo no pudo completarse.

EJEMPLOS

1. Desinstalar un paquete previamente instalado. 
cargo uninstall ripgrep
