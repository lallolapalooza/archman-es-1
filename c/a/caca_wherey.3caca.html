__extern int caca_put_char (caca_canvas_t * cv, int x, int y, uint32_t ch)

Print an ASCII or Unicode character at the given coordinates, using the default foreground and background colour values.

If the coordinates are outside the canvas boundaries, nothing is printed. If a fullwidth Unicode character gets overwritten, its remaining visible parts are replaced with spaces. If the canvas' boundaries would split the fullwidth character in two, a space is printed instead.

The behaviour when printing non-printable characters or invalid UTF-32 characters is undefined. To print a sequence of bytes forming an UTF-8 character instead of an UTF-32 character, use the caca_put_str() function.

This function returns the width of the printed character. If it is a fullwidth character, 2 is returned. Otherwise, 1 is returned.

This function never fails.

Parameters

cv A handle to the libcaca canvas.
x X coordinate.
y Y coordinate.
ch The character to print.

Returns

The width of the printed character: 2 for a fullwidth character, 1 otherwise.

References caca_add_dirty_rect(), CACA_MAGIC_FULLWIDTH, and caca_utf32_is_fullwidth().

__extern uint32_t caca_get_char (caca_canvas_t const * cv, int x, int y)

Get the ASCII or Unicode value of the character at the given coordinates. If the value is less or equal to 127 (0x7f), the character can be printed as ASCII. Otherise, it must be handled as a UTF-32 value.

If the coordinates are outside the canvas boundaries, a space (0x20) is returned.

A special exception is when CACA_MAGIC_FULLWIDTH is returned. This value is guaranteed not to be a valid Unicode character, and indicates that the character at the left of the requested one is a fullwidth character.

This function never fails.

__extern int caca_put_char (caca_canvas_t * cv, int x, int y, uint32_t ch)

Imprime un carácter ASCII o Unicode en las coordenadas dadas, utilizando los valores de color de primer plano y fondo por defecto.

Si las coordenadas están fuera de los límites del lienzo, no se imprime nada. Si un carácter Unicode de ancho completo es sobrescrito, sus partes visibles restantes se reemplazan con espacios. Si los límites del lienzo dividieran el carácter de ancho completo en dos, se imprime un espacio en su lugar.

El comportamiento al imprimir caracteres no imprimibles o caracteres UTF-32 inválidos no está definido. Para imprimir una secuencia de bytes que forman un carácter UTF-8 en lugar de un carácter UTF-32, use la función caca_put_str().

Esta función devuelve el ancho del carácter impreso. Si es un carácter de ancho completo, se devuelve 2. De lo contrario, se devuelve 1.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X.
y Coordenada Y.
ch El carácter a imprimir.

Devoluciones

El ancho del carácter impreso: 2 para un carácter de ancho completo, 1 en caso contrario.

Referencias caca_add_dirty_rect(), CACA_MAGIC_FULLWIDTH, y caca_utf32_is_fullwidth().

__extern uint32_t caca_get_char (caca_canvas_t const * cv, int x, int y)

Obtiene el valor ASCII o Unicode del carácter en las coordenadas dadas. Si el valor es menor o igual a 127 (0x7f), el carácter se puede imprimir como ASCII. De lo contrario, debe tratarse como un valor UTF-32.

Si las coordenadas están fuera de los límites del lienzo, se devuelve un espacio (0x20).

Una excepción especial es cuando se devuelve CACA_MAGIC_FULLWIDTH. Este valor se garantiza que no es un carácter Unicode válido, e indica que el carácter a la izquierda del solicitado es un carácter de ancho completo.

Esta función nunca falla.
