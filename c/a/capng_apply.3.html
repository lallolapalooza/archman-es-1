CAPNG_APPLY(3) API de Libcap-ng CAPNG_APPLY(3)

NOMBRE

capng_apply - aplica la configuración de capacidades almacenada

SINOPSIS

#include <cap-ng.h>

int capng_apply(capng_select_t set);

DESCRIPCIÓN

capng_apply transferirá la configuración de capacidades POSIX interna especificada al kernel. Las opciones son CAPNG_SELECT_CAPS para las capacidades tradicionales, CAPNG_SELECT_BOUNDS para el conjunto de límites, CAPNG_SELECT_BOTH si se desea transferir ambos, CAPNG_SELECT_AMBIENT si solo se opera en las capacidades ambientales, o CAPNG_SELECT_ALL si se desea aplicar todas.

VALOR DE RETORNO

Devuelve 0 en caso de éxito y un valor negativo en caso de fallo. Los valores son:

-1 no inicializado
-2 CAPNG_SELECT_BOUNDS y fallo al eliminar una capacidad del conjunto de límites
-3 CAPNG_SELECT_BOUNDS y fallo al volver a leer el conjunto de límites
-4 CAPNG_SELECT_BOUNDS y el proceso no tiene CAP_SETPCAP
-5 CAPNG_SELECT_CAPS y fallo en la llamada al sistema capset
-6 CAPNG_SELECT_AMBIENT y el proceso no tiene capacidades y falló al limpiar las capacidades ambientales
-7 CAPNG_SELECT_AMBIENT y el proceso tiene capacidades y falló al limpiar las capacidades ambientales
-8 CAPNG_SELECT_AMBIENT y el proceso tiene capacidades y falló al establecer una capacidad ambiental
-9 Imposible adquirir las capacidades del proceso para comprobar si CAP_SETPCAP está establecido.

NOTAS

Si estás haciendo programación multihilo, llamar a esta función solo establecerá las capacidades en el hilo que llama. Todos los demás hilos no se verán afectados. Si deseas establecer las capacidades generales para un proceso multihilo, deberás hacerlo antes de crear ningún hilo. Consulta la llamada al sistema capset para obtener más información sobre este tema.

Además, los bits en el conjunto de límites solo se pueden eliminar. No se pueden establecer. Después de eliminar las capacidades del conjunto de límites, el conjunto de límites se sincroniza con el kernel para reflejar el estado real en el kernel.

VER TAMBIÉN

capset(2), capng_update(3), capabilities(7)
