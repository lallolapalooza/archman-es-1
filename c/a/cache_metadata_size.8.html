NOMBRE

cache_metadata_size - Estima el tamaño del dispositivo de metadatos necesario para una configuración dada.

SINOPSIS

cache_metadata_size [opciones]

DESCRIPCIÓN

cache_metadata_size estima el tamaño de los metadatos. Se deben especificar --nr-blocks, o --block-size y --device-size.

OPCIONES

--nr-blocks {natural}
Especifica el número de bloques de caché.
--block-size {sectores}
Especifica el tamaño de cada bloque de caché en sectores de 512 bytes.
--device-size {sectores}
Especifica el tamaño total del dispositivo rápido utilizado en la caché. En sectores de 512 bytes.
--max-hint-width {nr bytes}
Especifica el ancho de la pista.
    Las políticas de caché utilizan una 'pista' por bloque para registrar información
    adicional (por ejemplo, recuentos de aciertos).
    Actualmente, todas las políticas utilizan un ancho de pista de 4 bytes.
    Si desea utilizar un ancho de pista diferente, especifíquelo con esta
    opción.

EJEMPLO

$ cache_metadata_size --nr-blocks 10240

$ cache_metadata_size --block-size 128 --device-size 1024000

VER TAMBIÉN
