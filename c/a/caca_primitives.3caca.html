Descripción Detallada

Estas funciones proporcionan rutinas para el dibujo de primitivas, como líneas, cajas, triángulos y elipses.

__extern int caca_draw_polyline (caca_canvas_t * cv, int const x[], int const y[], int n, uint32_t ch)

Dibuja una polilínea en el lienzo usando el carácter dado y los arreglos de coordenadas. El primer y el último punto no están conectados, por lo tanto, para dibujar un polígono, necesitas especificar el punto inicial también al final de la lista.

Esta función nunca falla.

Parámetros

cv El manejador del lienzo de libcaca.
x Arreglo de coordenadas X. Debe tener n + 1 elementos.
y Arreglo de coordenadas Y. Debe tener n + 1 elementos.
n Número de líneas a dibujar.
ch Carácter UTF-32 a usar para dibujar las líneas.

Devuelve

Esta función siempre devuelve 0.
