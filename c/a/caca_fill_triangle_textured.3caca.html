Estas funciones proporcionan rutinas para el dibujo de primitivas, tales como líneas, cuadros, triángulos y elipses.

__extern int caca_draw_polyline (caca_canvas_t * cv, int const x[], int const y[], int n, uint32_t ch)

Dibuja una polilínea en el lienzo usando el carácter y los arreglos de coordenadas dados. Los puntos primero y último no están conectados, por lo que para dibujar un polígono necesitas especificar el punto de inicio al final de la lista también.

Esta función nunca falla.

Parámetros

cv El manejador del lienzo de libcaca.
x Arreglo de coordenadas X. Debe tener n + 1 elementos.
y Arreglo de coordenadas Y. Debe tener n + 1 elementos.
n Número de líneas a dibujar.
ch Carácter UTF-32 a usar para dibujar las líneas.

Retorna

Esta función siempre retorna 0.

__extern int caca_fill_triangle_textured (caca_canvas_t * cv, int coords[6], caca_canvas_t * tex, float uv[6])

Rellena un triángulo en el lienzo usando una textura de tamaño arbitrario.

Las coordenadas de las esquinas del triángulo son (coords[0], coords[1]), (coords[2], coords[3]) y (coords[4], coords[5]).

Las coordenadas UV correspondientes son (uv[0], uv[1]), (uv[2], uv[3]) y (uv[4], uv[5]).

Las coordenadas de la textura (tex) son relativas al lienzo de textura dado.

Este es un ejemplo de cómo rellenar un triángulo con una textura:

Parámetros

cv El manejador del lienzo de libcaca.
coords Arreglo de 6 enteros que contiene las 3 coordenadas (x,y) del triángulo.
tex El lienzo de textura.
uv Arreglo de 6 flotantes que contiene las 3 coordenadas UV del triángulo.

Retorna

Este función siempre retorna 0.
