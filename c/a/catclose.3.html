catopen(3) Manual de funciones de biblioteca catopen(3)

NOMBRE

catopen, catclose - abrir/cerrar un catálogo de mensajes

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <nl_types.h>
nl_catd catopen(const char *name, int flag);
int catclose(nl_catd catalog);

DESCRIPCIÓN

La función catopen() abre un catálogo de mensajes y devuelve un descriptor de catálogo. El descriptor permanece válido hasta que catclose() o execve(2). Si se utiliza un descriptor de archivo para implementar descriptores de catálogo, se establecerá la bandera FD_CLOEXEC.

El argumento name especifica el nombre del catálogo de mensajes que se abrirá. Si name especifica una ruta absoluta (es decir, contiene una '/'), entonces name especifica una ruta para el catálogo de mensajes. De lo contrario, la variable de entorno NLSPATH se utiliza con name sustituido por %N (ver locale(7)). No está especificado si NLSPATH se usará cuando el proceso tenga privilegios de root. Si NLSPATH no existe en el entorno, o si no se puede abrir un catálogo de mensajes en ninguna de las rutas especificadas por él, se utiliza una ruta definida por la implementación. Esta última ruta predeterminada puede depender de la configuración de localización de LC_MESSAGES cuando el argumento flag sea NL_CAT_LOCALE y de la variable de entorno LANG cuando el argumento flag sea 0. Cambiar la parte LC_MESSAGES de la localización puede invalidar los descriptores de catálogo abiertos.

El argumento flag para catopen() se utiliza para indicar la fuente del idioma a utilizar. Si se establece en NL_CAT_LOCALE, utilizará la configuración de localización actual para LC_MESSAGES. De lo contrario, utilizará la variable de entorno LANG.

La función catclose() cierra el catálogo de mensajes identificado por catalog. Invalida cualquier referencia posterior al catálogo de mensajes definido por catalog.

VALOR DE RETORNO

La función catopen() devuelve un descriptor de catálogo de mensajes de tipo nl_catd en caso de éxito. En caso de fallo, devuelve (nl_catd) -1 y establece errno para indicar el error. Los posibles valores de error incluyen todos los valores posibles para la llamada open(2).

La función catclose() devuelve 0 en caso de éxito, o -1 en caso de fallo.

ENTORNO

LC_MESSAGES
Puede ser la fuente de la configuración de localización de LC_MESSAGES, y por lo tanto determinar el idioma a utilizar si flag se establece en NL_CAT_LOCALE.
LANG
El idioma a utilizar si flag es 0.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
catopen () Seguridad de hilos MT-Safe env
catclose () Seguridad de hilos MT-Safe

VERSIONES

Lo anterior es la descripción de POSIX.1. El valor de glibc para NL_CAT_LOCALE es 1. La ruta predeterminada varía, pero generalmente busca en varios lugares debajo de /usr/share/locale.

ESTÁNDARES

POSIX.1-2008.

HISTORIA
