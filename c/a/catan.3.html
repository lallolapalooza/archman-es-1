catan(3) Manual de funciones de biblioteca catan(3)

NOMBRE

catan, catanf, catanl - arcotangentes complejas

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <complex.h>
double complex catan(double complex z);
float complex catanf(float complex z);
long double complex catanl(long double complex z);

DESCRIPCIÓN

Estas funciones calculan la arcotangente compleja de z. Si y = catan(z), entonces z = ctan(y). La parte real de y se elige en el intervalo [-pi/2, pi/2].

Se tiene:


catan(z) = (clog(1 + i * z) - clog(1 - i * z)) / (2 * i)

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
catan (), catanf (), catanl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

glibc 2.1. C99, POSIX.1-2001.

EJEMPLOS

/* Enlazar con "-lm" */
#include <complex.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    double complex z, c, f;
    double complex i = I;
    if (argc != 3) {
        fprintf(stderr, "Uso: %s <real> <imag>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    z = atof(argv[1]) + atof(argv[2]) * I;
    c = catan(z);
    printf("catan() = %6.3f %6.3f*i\n", creal(c), cimag(c));
    f = (clog(1 + i * z) - clog(1 - i * z)) / (2 * i);
    printf("formula = %6.3f %6.3f*i\n", creal(f), cimag(f));
    exit(EXIT_SUCCESS);
}
