CAP_FROM_TEXT(3) Manual de Programador de Linux CAP_FROM_TEXT(3)

NOMBRE

cap_from_text, cap_to_text, cap_to_name, cap_from_name - traducción de la representación textual del estado de capacidades

SINOPSIS

#include <sys/capability.h>
cap_t cap_from_text(const char *buf_p);
char *cap_to_text(cap_t caps, ssize_t *len_p);
int cap_from_name(const char *name, cap_value_t *cap_p);
char *cap_to_name(cap_value_t cap);

Enlazar con -lcap.

DESCRIPCIÓN

Estas funciones traducen un estado de capacidad entre una representación interna y una textual. La representación interna es gestionada por las funciones de capacidad en el área de trabajo. La representación textual es una cadena de caracteres estructurada y legible por humanos, adecuada para visualización.

cap_from_text() asigna e inicializa un estado de capacidad en el área de trabajo. Luego establece el contenido de este estado de capacidad recién creado al estado representado por una cadena de caracteres legible por humanos y terminada en nulo, apuntada por buf_p. Devuelve un puntero al estado de capacidad recién creado. Cuando el estado de capacidad en el área de trabajo ya no es necesario, el llamador debe liberar cualquier memoria liberable llamando a cap_free() con cap_t como argumento. La función devuelve un error si no puede analizar el contenido de la cadena apuntada por buf_p o si no reconoce ningún capability_name o carácter de bandera como válido. La función también devuelve un error si alguna bandera está establecida y despejada dentro de una única cláusula.

cap_to_text() convierte el estado de capacidad en el área de trabajo identificado por caps en una cadena legible por humanos y terminada en nulo. Esta función asigna cualquier memoria necesaria para contener la cadena y devuelve un puntero a la cadena. Si el puntero len_p no es NULL, la función también devolverá la longitud completa de la cadena (sin incluir el terminador nulo) en la ubicación apuntada por len_p. El estado de capacidad en el área de trabajo, identificado por caps, está completamente representado en la cadena de caracteres. Cuando el estado de capacidad en el área de trabajo ya no es necesario, el llamador debe liberar cualquier memoria liberable llamando a cap_free() con el puntero de cadena devuelto como argumento.

cap_from_name() convierte una representación textual de una capacidad, como "cap_chown", a su representación numérica (CAP_CHOWN=0), escribiendo el valor decodificado en *cap_p. Si cap_p es NULL, no se escribe ningún resultado, pero el código de retorno de la función indica si la capacidad especificada puede ser representada por la biblioteca.

cap_to_name() convierte un valor de índice de capacidad, cap, a una cadena textual asignada por libcap. Esta cadena debe ser liberada con cap_free().

REPRESENTACIÓN TEXTUAL

El formato de texto se describe en la página del manual cap_text_formats(7).

VALOR DE RETORNO

cap_from_text(), cap_to_text() y cap_to_name() devuelven un valor no NULL en caso de éxito, y NULL en caso de fallo. cap_from_name() devuelve 0 para éxito y -1 en caso de fallo (capacidad desconocida).

En caso de fallo, errno se establece en EINVAL o ENOMEM.

CONFORMIDAD

cap_from_text() y cap_to_text() están especificadas por el borrador de especificación POSIX.1e retirado. cap_from_name() y cap_to_name() son extensiones de Linux.

EJEMPLO

El siguiente programa de ejemplo demuestra el uso de cap_from_text() y cap_to_text(). La siguiente sesión de shell muestra algunos ejemplos de ejecución:

$ ./a.out "cap_chown=p cap_chown+e"
caps_to_text() returned "cap_chown=ep"
$ ./a.out "all=pe cap_chown-e cap_kill-pe"
caps_to_text() returned "=ep cap_chown-e cap_kill-ep"

El código fuente del programa es el siguiente:

#include <stdlib.h>
#include <stdio.h>
#include <sys/capability.h>
#define handle_error(msg) \
    do { perror(msg); exit(EXIT_FAILURE); } while (0)
int
main(int argc, char *argv[])
{
    cap_t caps;
    char *txt_caps;
    if (argc != 2) {
        fprintf(stderr, "%s <conjunto-texto-capacidad>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    caps = cap_from_text(argv[1]);
    if (caps == NULL)
        handle_error("cap_from_text");
    txt_caps = cap_to_text(caps, NULL);
    if (txt_caps == NULL)
        handle_error("cap_to_text");
    printf("caps_to_text() devolvió \"%s\"\n", txt_caps);
    if (cap_free(txt_caps) != 0 || cap_free(caps) != 0)
        handle_error("cap_free");
    exit(EXIT_SUCCESS);
}
