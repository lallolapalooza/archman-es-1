__extern int caca_refresh_display (caca_display_t * dp)

Purga todas las operaciones gráficas y las imprime en el dispositivo de visualización. Nada se mostrará en la pantalla hasta que se llame a esta función.

Si caca_set_display_time() fue llamado con un valor distinto de cero, caca_refresh_display() usará ese valor para lograr una tasa de refresco constante: si dos llamadas consecutivas a caca_refresh_display() ocurren dentro de un intervalo de tiempo más corto que el valor establecido con caca_set_display_time(), la segunda llamada será retrasada antes de realizar la actualización de la pantalla.

Esta función nunca falla.

Parámetros

dp El contexto de visualización de libcaca.

Devuelve

Esta función siempre devuelve 0.

Referencias caca_clear_dirty_rect_list().

__extern int caca_set_display_time (caca_display_t * dp, int usec)

Establece el retardo de actualización en microsegundos. El retardo de actualización es utilizado por caca_refresh_display() para lograr una tasa de refresco constante. Consulte la documentación de caca_refresh_display() para más detalles.

Si el argumento es cero, la tasa de refresco constante se desactiva. Este es el comportamiento por defecto.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL El valor del retardo de actualización es inválido.

Parámetros

dp El contexto de visualización de libcaca.
usec El retardo de actualización en microsegundos.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_get_display_time (caca_display_t const * dp)

Obtiene el tiempo medio de renderizado, que es el tiempo medio medido entre dos llamadas a caca_refresh_display() , en microsegundos. Si la tasa de refresco constante fue activada llamando a caca_set_display_time(), el tiempo medio de renderizado estará cerca del retardo solicitado incluso si el tiempo real de renderizado fue más corto.

Esta función nunca falla.

Parámetros

dp El contexto de visualización de libcaca.

Devuelve

El tiempo de renderizado en microsegundos.

__extern int caca_get_display_width (caca_display_t const * dp)

Si libcaca se ejecuta en una ventana, obtiene el ancho utilizable de la ventana. Este valor puede usarse para el cálculo de la relación de aspecto. Si libcaca no se ejecuta en una ventana o si no hay forma de conocer el tamaño de la fuente, la mayoría de los controladores asumirán que se está usando una fuente de 6x10. Tenga en cuenta que las unidades no son necesariamente píxeles.

Esta función nunca falla.

Parámetros

dp El contexto de visualización de libcaca.

Devuelve

El ancho de la pantalla.

__extern int caca_get_display_height (caca_display_t const * dp)

Si libcaca se ejecuta en una ventana, obtiene la altura utilizable de la ventana. Este valor puede usarse para el cálculo de la relación de aspecto. Si libcaca no se ejecuta en una ventana o si no hay forma de conocer el tamaño de la fuente, asuma que se está usando una fuente de 6x10. Tenga en cuenta que las unidades no son necesariamente píxeles.

Esta función nunca falla.

Devuelve

__extern int caca_set_display_title (caca_display_t * dp, char const * title)

Si libcaca se ejecuta en una ventana, intenta cambiar su título. Esto funciona con los controladores ncurses, S-Lang, OpenGL, X11 y Win32.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
ENOSYS El controlador de visualización no soporta establecer el título de la ventana.

Parámetros

dp El contexto de visualización de libcaca.
title El título de visualización deseado.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_set_mouse (caca_display_t * dp, int flag)

Muestra u oculta el puntero del ratón. Esta función funciona con los controladores ncurses, S-Lang y X11.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
ENOSYS El controlador de visualización no soporta ocultar el puntero del ratón.

Parámetros

dp El contexto de visualización de libcaca.
flag 0 oculta el puntero, 1 muestra el puntero por defecto del sistema (usualmente una flecha). Otros valores están reservados para uso futuro.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_set_cursor (caca_display_t * dp, int flag)

Muestra u oculta el cursor, para dispositivos que soportan tal característica.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
ENOSYS El controlador de visualización no soporta mostrar el cursor.

Parámetros

dp El contexto de visualización de libcaca.
flag 0 oculta el cursor, 1 muestra el cursor por defecto del sistema (usualmente un rectángulo blanco). Otros valores están reservados para uso futuro.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.
