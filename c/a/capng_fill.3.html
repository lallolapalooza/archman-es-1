CAPNG_FILL(3) API de Libcap-ng CAPNG_FILL(3)

NOMBRE

capng_fill - rellenar el conjunto de capacidades elegido

SINOPSIS

#include <cap-ng.h>

void capng_fill(capng_select_t set);

DESCRIPCIÓN

capng_fill establece todos los bits a 1 en el conjunto de capacidades POSIX seleccionado. Las opciones son CAPNG_SELECT_CAPS para las capacidades tradicionales, CAPNG_SELECT_BOUNDS para el conjunto de límites, CAPNG_SELECT_BOTH si se desea rellenar ambos, CAPNG_SELECT_AMBIENT si solo se opera en las capacidades ambientales, o CAPNG_SELECT_ALL si se desea borrar todo.

VALOR DE RETORNO

Ninguno.

NOTAS

Durante capng_apply, solo se pueden eliminar bits en el conjunto de límites. No puedes establecerlos.

VER TAMBIÉN

capng_apply(3), capabilities(7)
