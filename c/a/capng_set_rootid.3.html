capng_set_rootid(3)

Paquete: libcap-ng

Licencias: GPL-2.0-or-later, LGPL-2.1-or-later

CAPNG_SET_ROOTID(3) API de Libcap-ng CAPNG_SET_ROOTID(3)

NOMBRE

capng_set_rootid - establecer el ID raíz del espacio de nombres

SINOPSIS

#include <cap-ng.h>

int capng_set_rootid(int rootid);

DESCRIPCIÓN

capng_set_rootid establece el ID raíz para las operaciones de capacidades. Esto solo es aplicable a las operaciones del sistema de archivos.

VALOR DE RETORNO

En caso de éxito, devuelve 0. Devuelve -1 si hay un error interno o si el kernel no admite las capacidades del sistema de archivos V3.

VER TAMBIÉN

capng_set_caps_fd(3), capabilities(7)
