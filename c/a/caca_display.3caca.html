DESCRIPCIÓN DETALLADA

Estas funciones proporcionan las rutinas básicas de libcaca para la inicialización de la visualización, la recuperación de información del sistema y la configuración.

DOCUMENTACIÓN DE FUNCIONES

__extern caca_display_t * caca_create_display (caca_canvas_t * cv)

Crea un contexto gráfico utilizando características dependientes del dispositivo (ncurses para terminales, una ventana X11, una ventana de comandos de DOS...) que se adjunta a un lienzo de libcaca. Todo lo que se dibuje en el lienzo de libcaca puede ser mostrado por el driver de libcaca.

Si no se proporciona ningún lienzo de caca, se crea uno nuevo. Su manejador se puede obtener usando caca_get_canvas() y se destruye automáticamente cuando se llama a caca_free_display().

Tenga en cuenta que para lograr la máxima compatibilidad con Unicode, el código de inicialización del driver puede cambiar temporalmente la configuración regional LC_CTYPE global del programa usando setlocale(). Se recomienda no llamar a funciones dependientes de LC_CTYPE desde otros hilos durante la llamada a caca_create_display(). La configuración regional se restaura cuando la función devuelve.

Ver también caca_create_display_with_driver().

Si ocurre un error, se devuelve NULL y se establece errno en consecuencia:

  • ENOMEM No hay suficiente memoria.
  • ENODEV No se pudo inicializar el dispositivo gráfico.

Parámetros

cv El lienzo de caca o NULL para crear un lienzo automáticamente.

Devuelve

El contexto gráfico de caca o NULL si ocurrió un error.

Referencias caca_create_display_with_driver().

__extern caca_display_t * caca_create_display_with_driver (caca_canvas_t * cv, char const * driver)

Crea un contexto gráfico utilizando características dependientes del dispositivo (ncurses para terminales, una ventana X11, una ventana de comandos de DOS...) que se adjunta a un lienzo de libcaca. Todo lo que se dibuje en el lienzo de libcaca puede ser mostrado por el driver de libcaca.

Si no se proporciona ningún lienzo de caca, se crea uno nuevo. Su manejador se puede obtener usando caca_get_canvas() y se destruye automáticamente cuando se llama a caca_free_display().

Si no se proporciona ningún nombre de driver, libcaca intentará autodetectar el mejor driver de salida que pueda.

__extern char const *const * caca_get_display_driver_list (void )

Devuelve una lista de los drivers de visualización disponibles. La lista es un array de cadenas terminado en NULL, intercalando una cadena que contiene el valor interno para el driver de visualización y una cadena que contiene la descripción en lenguaje natural para ese driver.

Esta función nunca falla.

Un array de cadenas.

__extern int caca_free_display (caca_display_t * dp)

Desconecta un contexto gráfico de su backend de caca y lo destruye. El lienzo de libcaca continúa existiendo y se pueden adjuntar otros contextos gráficos a él posteriormente.

Si el lienzo de caca fue creado automáticamente por caca_create_display(), se destruye automáticamente y cualquier manejador a él se vuelve inválido.

Esta función nunca falla.

Parámetros

dp El contexto gráfico de libcaca.

Devuelve

Esta función siempre devuelve 0.

Referencias caca_free_canvas() y caca_unmanage_canvas().

NAME

caca_display_man_page - libcaca display driver interface

SYNOPSIS

#include <libcaca.h>

int caca_get_data(caca_display_t *dp)

int caca_refresh_display(caca_display_t *dp)

int caca_set_display_time(caca_display_t *dp, int usec)

DESCRIPTION

The caca_display functions manage the libcaca display driver. The display driver is a class that handles the rendering of the characters and graphical primitives. It is the final step of the rendering process in libcaca. The display driver handles the actual output on the screen, in a window, or even in a text file.

The default display driver is chosen automatically according to the host operating system, the available environment variables and the libcaca build options. It is also possible to select a specific driver by setting the LCACADRIVER environment variable.

A display driver is represented by a caca_display_t opaque structure. This structure is created by the caca_create_display() function and must be destroyed by the caca_free_display() function.

FUNCTION DOCUMENTATION

__extern int caca_get_data (caca_display_t * dp)

Get the libcaca canvas. This is the canvas you will draw on. All graphical operations are performed on this canvas.

If an error occurs, NULL is returned and errno is set accordingly:

•
ENOMEM Not enough memory to allocate the requested canvas.

Parameters

dp The libcaca display context.

Returns

The libcaca canvas.

__extern int caca_refresh_display (caca_display_t * dp)

Flush all graphical operations and print them to the display device. Nothing will show on the screen until this function is called.

If caca_set_display_time() was called with a non-zero value, caca_refresh_display() will use that value to achieve constant framerate: if two consecutive calls to caca_refresh_display() are within a time range shorter than the value set with caca_set_display_time(), the second call will be delayed before performing the screen refresh.

This function never fails.

Parameters

dp The libcaca display context.

Returns

This function always returns 0.

References caca_clear_dirty_rect_list().

__extern int caca_set_display_time (caca_display_t * dp, int usec)

Set the refresh delay in microseconds. The refresh delay is used by caca_refresh_display() to achieve constant framerate. See the caca_refresh_display() documentation for more details.

If the argument is zero, constant framerate is disabled. This is the default behaviour.

If an error occurs, -1 is returned and errno is set accordingly:

•
EINVAL Refresh delay value is invalid.

Parameters

dp The libcaca display context.
usec The refresh delay in microseconds.

Returns

0 upon success, -1 if an error occurred.

__extern int caca_get_display_time (caca_display_t const * dp)

Get the average rendering time, which is the average measured time between two caca_refresh_display() calls, in microseconds. If constant framerate was activated by calling caca_set_display_time(), the average rendering time will be close to the requested delay even if the real rendering time was shorter.

This function never fails.

Parameters

dp The libcaca display context.

Returns

The render time in microseconds.

__extern int caca_get_display_width (caca_display_t const * dp)

If libcaca runs in a window, get the usable window width. This value can be used for aspect ratio calculation. If libcaca does not run in a window or if there is no way to know the font size, most drivers will assume a 6x10 font is being used. Note that the units are not necessarily pixels.

This function never fails.

Parameters

dp The libcaca display context.

Returns

The display width.

__extern int caca_set_display_title (caca_display_t * dp, char const * title)

If libcaca runs in a window, try to change its title. This works with the ncurses, S-Lang, OpenGL, X11 and Win32 drivers.

If an error occurs, -1 is returned and errno is set accordingly:

•
ENOSYS Display driver does not support setting the window title.

Parameters

dp The libcaca display context.
title The desired display title.

Returns

0 upon success, -1 if an error occurred.

__extern int caca_set_mouse (caca_display_t * dp, int flag)

Show or hide the mouse pointer. This function works with the ncurses, S-Lang and X11 drivers.

If an error occurs, -1 is returned and errno is set accordingly:

•
ENOSYS Display driver does not support hiding the mouse pointer.

Parameters

dp The libcaca display context.
flag 0 hides the pointer, 1 shows the system's default pointer (usually an arrow). Other values are reserved for future use.

Returns

0 upon success, -1 if an error occurred.

__extern int caca_set_cursor (caca_display_t * dp, int flag)

Show or hide the cursor, for devices that support such a feature.

Parameters

flag 0 hides the cursor, 1 shows the system's default cursor (usually a white rectangle). Other values are reserved for future use.
