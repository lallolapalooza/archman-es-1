DOCUMENTACIÓN

Módulo LexerUtil
: sig end

val init : string -> Lexing.lexbuf -> Lexing.lexbuf

init filename lexbuf inicializa el búfer de análisis léxico lexbuf para que las posiciones que se lean posteriormente de él hagan referencia al archivo filename. Devuelve lexbuf.

val read : string -> string * Lexing.lexbuf

read filename lee el contenido completo del archivo filename y devuelve un par de este contenido (una cadena) y un búfer de análisis léxico que ha sido inicializado, basándose en esta cadena.

val newline : Lexing.lexbuf -> unit

newline lexbuf incrementa el contador de líneas almacenado dentro de lexbuf. Debería ser invocado por el propio analizador léxico cada vez que se consume un carácter de nueva línea. Esto permite mantener un número de línea actual en lexbuf.

val range : Lexing.position * Lexing.position -> string

range (startpos, endpos) imprime una descripción textual del rango delimitado por las posiciones de inicio y fin startpos y endpos. Esta descripción tiene una línea de longitud y termina con un carácter de nueva línea. Esta descripción menciona el nombre del archivo, el número de línea y un rango de caracteres en esta línea. El número de línea es correcto solo si newline se ha utilizado correctamente, como se describe anteriormente.

val tabulate : ('a -> bool) -> (unit -> 'a) -> unit -> 'a

tabulate is_eof lexer tabula el analizador léxico lexer: es decir, ejecuta inmediatamente este analizador léxico hasta que se encuentra un token EOF, almacena los tokens en una matriz en memoria y devuelve un nuevo analizador léxico que (cuando se invoca) lee tokens de esta matriz. La función lexer no tiene permitido lanzar una excepción y debe producir un flujo finito de tokens: es decir, después de un número finito de invocaciones, debe devolver un token que sea identificado por la función is_eof como un token EOF.

Tanto el analizador léxico existente lexer como el nuevo analizador léxico devuelto por tabulate
is_eof lexer son funciones de tipo unit -> 'a, donde el tipo 'a probablemente se instanciará con un triple de un token y dos posiciones, según la API de análisis léxico revisada descrita en el módulo CamlinternalMenhirLib.Convert.
