NOMBRE

cancel - cancelar trabajos

SINOPSIS

cancel [ -h nombrehost[:puerto] ] [ -E ] [ -U nombreusuario ] [ -a ] [ -u nombreusuario ] [ -x ] [ id ] [ destino ] [ id-destino ]

DESCRIPCIÓN

El comando cancel cancela trabajos de impresión. Si no se especifica ningún destino o id, se cancela el trabajo que se está imprimiendo en el destino predeterminado.

OPCIONES

Las siguientes opciones son reconocidas por cancel:

-a
Cancela todos los trabajos en el destino especificado, o todos los trabajos en todos los destinos si no se proporciona ninguno.
-E
Fuerza el cifrado al conectarse al servidor.
-h nombrehost[:puerto]
Especifica un servidor alternativo. Nota: Esta opción debe aparecer antes que todas las demás.
-U nombreusuario
Especifica el nombre de usuario a utilizar al conectarse al servidor.
-u nombreusuario
Cancela los trabajos propiedad de nombreusuario.
-x
Elimina los archivos de datos del trabajo además de cancelarlo.

CONFORMIDAD

A diferencia del sistema de impresión System V, CUPS permite que los nombres de impresora contengan cualquier carácter imprimible excepto ESPACIO, TAB, "/" o "#". Además, los nombres de impresora y clase *no* distinguen entre mayúsculas y minúsculas.

EJEMPLOS

Cancelar el trabajo de impresión actual:

    cancel

Cancelar el trabajo "myprinter-42":

    cancel myprinter-42

Cancelar todos los trabajos:

    cancel -a

NOTAS

Los administradores que deseen evitar la cancelación no autorizada de trabajos a través de la opción -u deben requerir autenticación para las operaciones Cancel-Jobs en cupsd.conf(5).
