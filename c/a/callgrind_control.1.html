NOMBRE

callgrind_control - observar y controlar programas ejecutados por Callgrind

SINOPSIS

callgrind_control [opciones] [pid|nombre-programa...]

DESCRIPCIÓN

callgrind_control controla los programas ejecutados por la herramienta Valgrind Callgrind. Cuando no se especifica un argumento pid/nombre-programa, se utilizarán todas las aplicaciones que se estén ejecutando actualmente por Callgrind en este sistema para las acciones indicadas por las opciones especificadas. La acción predeterminada es proporcionar información breve sobre las aplicaciones ejecutadas por Callgrind.

OPCIONES

-h --help

Muestra una breve descripción, el uso y un resumen de las opciones.

--version

Muestra la versión de callgrind_control.

-l --long

Muestra también el directorio de trabajo, además de la información breve proporcionada por defecto.

-s --stat

Muestra información estadística sobre las ejecuciones activas de Callgrind.

-b --back

Muestra rastreos de pila/llamadas de cada hilo en las ejecuciones activas de Callgrind. Para cada función activa en el rastreo de pila, también se muestra el número de invocaciones desde el inicio del programa (o la última volcada). Esta opción se puede combinar con -e para mostrar el costo inclusivo de las funciones activas.

-e [A,B,...] (predeterminado: todas)

Muestra los valores actuales de costo exclusivo por hilo de los contadores de eventos. Si no se especifican nombres de eventos explícitos, se muestran las cifras de todos los tipos de eventos que se recopilan en la ejecución de Callgrind dada. De lo contrario, solo se muestran las cifras de los tipos de eventos A, B, ... Si esta opción se combina con -b, también se proporciona el costo inclusivo para las funciones de cada marco de pila activo.

--dump[=<desc>] (predeterminado: sin descripción)

Solicita la volcada de información de perfil. Opcionalmente, se puede especificar una descripción que se escribe en la volcada como parte de la información que da el motivo que activó la acción de volcado. Esto se puede usar para distinguir volcados múltiples.

-z --zero

Pone a cero todos los contadores de eventos.

-k --kill

Fuerza la terminación de una ejecución de Callgrind.

--instr=<on|off>

Activa o desactiva el modo de instrumentación. Si la instrumentación está desactivada en una ejecución de Callgrind, no se realiza simulación ni se cuentan eventos. Esto es útil para omitir partes del programa no interesantes, ya que la ralentización es mucho menor (la misma que con la herramienta Valgrind "none"). Consulte también la opción de Callgrind --instr-atstart.

--vgdb-prefix=<prefijo>

Especifica el prefijo vgdb a utilizar por callgrind_control. callgrind_control utiliza internamente vgdb para encontrar y controlar las ejecuciones activas de Callgrind. Si se utilizó la opción --vgdb-prefix para lanzar valgrind, entonces se debe proporcionar la misma opción a callgrind_control.

VER TAMBIÉN

valgrind(1), $INSTALL/share/doc/valgrind/html/index.html o http://www.valgrind.org/docs/manual/index.html.
