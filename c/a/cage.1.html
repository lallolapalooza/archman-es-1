NOMBRE

cage - un compositor de quiosco Wayland

SINOPSIS

cage [opciones...] [--] [aplicación...]

DESCRIPCIÓN

Cage ejecuta una única aplicación maximizada. Cage puede ejecutar múltiples aplicaciones, pero solo una es visible en cualquier momento. Se impide la interacción del usuario y las actividades fuera del alcance de la aplicación en ejecución.

OPCIONES

-d

No dibuje decoraciones del lado del cliente cuando sea posible.

-D

Habilita el registro de depuración.

-h

Muestra el mensaje de ayuda.

-m <modo>

Establece el comportamiento de múltiples monitores. Los modos compatibles son: last Cage utiliza solo el último monitor conectado. extend Cage extiende la pantalla a través de todos los monitores conectados.

-s

Permite el cambio de VT.

-v

Muestra el número de versión y sale.

ENTORNO

DISPLAY

Si se compila con soporte Xwayland, esto se establecerá en el nombre de la pantalla X utilizada para Xwayland. De lo contrario, sondea el backend X11.

WAYLAND_DISPLAY

Especifica el nombre de la pantalla Wayland en la que se ejecuta Cage.

XCURSOR_PATH

Directorio donde se encuentran los cursores.

XCURSOR_SIZE

Especifica el tamaño del cursor configurado.

XCURSOR_THEME

Especifica el tema del cursor configurado.

XKB_DEFAULT_RULES, XKB_DEFAULT_MODEL, XKB_DEFAULT_LAYOUT, XKB_DEFAULT_VARIANT, XKB_DEFAULT_OPTIONS

Configura los ajustes del teclado xkb. Consulte xkeyboard-config(7).

VER TAMBIÉN

xkeyboard-config(7)

ERRORES

Reporta errores en https://github.com/cage-kiosk/cage
