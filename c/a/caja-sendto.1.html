NOMBRE

caja-sendto - aplicación de conveniencia para enviar un archivo por correo electrónico o mensajería instantánea

SINOPSIS

caja-sendto [OPCIONES | ARCHIVOS...]

DESCRIPCIÓN

Envía ARCHIVO(s) por correo electrónico o mensajería instantánea.

Una ventana de diálogo presenta una opción de aplicación de transmisión y destinatario de los archivos. Los nombres de los destinatarios se pueden seleccionar de una lista o autocompletar. Luego se abre la aplicación seleccionada con los archivos y el destinatario listos para la transferencia.

La aplicación está pensada para integrarse con caja y está escrita para el entorno de escritorio gráfico MATE.

OPCIONES

-?, --help
Muestra un mensaje de ayuda que enumera todas las opciones y sus significados.
