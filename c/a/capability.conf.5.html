CAPABILITY.CONF(5) Manual de formatos de archivo CAPABILITY.CONF(5)

NOMBRE

capability.conf - archivo de configuración del módulo pam_cap

SINOPSIS

/etc/security/capability.conf

DESCRIPCIÓN

La sintaxis para las líneas de este archivo de configuración es:

# <-- ´#´ precede un comentario

<IAB><ESPACIO><QUIÉN>

Donde <IAB> se refiere al formato de texto para una tupla de capacidad IAB heredable, ver cap_text_formats(7), o las palabras all o none.

La palabra reservada all no otorga todas las capacidades heredables, sino que actúa como un simple paso para cualquier capacidad de tupla IAB prevalente. La palabra reservada none se refiere a un conjunto de capacidad Heredable vacío (y por extensión un vector Ambiental vacío).

Donde <QUIÉN> se refiere a los valores de nombre de usuario PAM separados por espacios que recibirán la tupla IAB especificada. Un nombre precedido por el carácter @ se refiere a los usuarios definidos localmente en /etc/group etc. listados bajo ese nombre de grupo. Un asterisco (*) se puede usar para denotar a todos los usuarios.

El análisis del archivo elige la primera línea que se aplica al usuario que se autentica e intenta aplicar solo esa.

Ejemplos de sintaxis válida son:

# solo root puede mantener lo que tenía
all                                root
# esto se activará solo para el usuario beta, que tendrá
# cap_chown eliminado de su conjunto limitante.
!cap_chown                         beta
# el siguiente activará para los miembros del grupo ´three´
# otorgándoles cap_setuid y cap_chown
cap_setuid,cap_chown               @three
# esto se aplicaría a beta y gamma, pero beta ya tiene
# otorgada una falta de cap_chown arriba. Además, si gamma está
# en el grupo ´three´, no llegará a esta línea.
cap_chown                          beta gamma
# los miembros del grupo ´one´ reciben la capacidad Heredable
# cap_setuid, pero cap_chown se elimina de su conjunto limitante.
!cap_chown,cap_setuid              @one
# el usuario alpha obtiene una capacidad ambiental (a menos que también
# sea miembro de los grupos ´one´ o ´three´).
^cap_setuid                        alpha
# el usuario delta (si no es miembro de los grupos ´one´ y ´three´) recibirá
# capacidades Ambientales cap_chown y cap_setgid, pero tendrá cap_setuid
# eliminado de su conjunto limitante.
^cap_chown,^cap_setgid,!cap_setuid delta
# los miembros restantes del grupo ´four´ recibirán la capacidad Heredable
# cap_setuid.
cap_setuid                         @four
