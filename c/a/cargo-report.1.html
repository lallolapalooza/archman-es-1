CARGO-REPORT(1) Manual de comandos generales CARGO-REPORT(1)

NOMBRE

cargo-report — Genera y muestra varios tipos de informes

SINOPSIS

cargo report tipo [opciones]

DESCRIPCIÓN

Muestra un informe del tipo dado — actualmente, solo se admite future-incompat

OPCIONES

--id id

Muestra el informe con el ID especificado generado por Cargo

-p espec…, --package espec…

Solo muestra un informe para el paquete especificado

EJEMPLOS

1.Muestra el último informe de incompatibilidad futura: 
cargo report future-incompat
2.Muestra el último informe de incompatibilidad futura para un paquete específico: 
cargo report future-incompat --package mi-dep:0.0.1

VER TAMBIÉN

Informe de incompatibilidad futura https://doc.rust-lang.org/cargo/reference/future-incompat-report.html
