catch(n)

Paquete: tcl

Licencias: TCL

catch(n) Comandos integrados de Tcl catch(n)

NOMBRE

catch - Evaluar script y atrapar retornos excepcionales

SINOPSIS

catch script ?nombreVarResultado? ?nombreVarOpciones?

DESCRIPCIÓN

El comando catch puede ser utilizado para prevenir que los errores aborten la interpretación de comandos. El comando catch llama al intérprete Tcl recursivamente para ejecutar script, y siempre retorna sin lanzar un error, independientemente de cualquier error que pudiera ocurrir mientras se ejecuta script.

Si script lanza un error, catch retornará un valor entero no nulo correspondiente al código de retorno excepcional retornado por la evaluación de script. Tcl define el código de retorno normal de la evaluación de scripts como cero (0), o TCL_OK. Tcl también define cuatro códigos de retorno excepcionales: 1 (TCL_ERROR), 2 (TCL_RETURN), 3 (TCL_BREAK), y 4 (TCL_CONTINUE). Los errores durante la evaluación de un script se indican mediante un código de retorno de TCL_ERROR. Los otros códigos de retorno excepcionales son retornados por los comandos return, break, y continue y en otras situaciones especiales según se documenta. Los paquetes de Tcl pueden definir nuevos comandos que retornen otros valores enteros como códigos de retorno también, y los scripts que hacen uso del comando return -code pueden tener códigos de retorno distintos de los cinco definidos por Tcl.

Si se proporciona el argumento nombreVarResultado, entonces la variable que nombra se establece al resultado de la evaluación del script. Cuando el código de retorno del script es 1 (TCL_ERROR), el valor almacenado en nombreVarResultado es un mensaje de error. Cuando el código de retorno del script es 0 (TCL_OK), el valor almacenado en nombreVarResultado es el valor retornado por script.

Si se proporciona el argumento nombreVarOpciones, entonces la variable que nombra se establece a un diccionario de opciones de retorno retornadas por la evaluación de script. Tcl especifica dos entradas que siempre se definen en el diccionario: -code y -level. Cuando el código de retorno de la evaluación de script no es TCL_RETURN, el valor de la entrada -level será 0, y el valor de la entrada -code será el mismo que el código de retorno. Solo cuando el código de retorno es TCL_RETURN los valores de las entradas -level y -code serán algo diferente, como se describe además en la documentación del comando return.

Cuando el código de retorno de la evaluación de script es TCL_ERROR, se definen cuatro entradas adicionales en el diccionario de opciones de retorno almacenado en nombreVarOpciones: -errorinfo, -errorcode, -errorline, y -errorstack. El valor de la entrada -errorinfo es un rastreo de pila formateado que contiene más información sobre el contexto en el que ocurrió el error. El rastreo de pila formateado está destinado a ser leído por una persona. El valor de la entrada -errorcode es información adicional sobre el error almacenada como una lista. El valor -errorcode está destinado a ser procesado adicionalmente por programas, y puede no ser particularmente legible por personas. El valor de la entrada -errorline es un entero que indica qué línea de script se estaba evaluando cuando ocurrió el error. El valor de la entrada -errorstack es una lista de tamaño par hecha de pares token-parámetro acumulados mientras se desenrolla la pila. El token puede ser “CALL”, en cuyo caso el parámetro es una lista hecha del nombre del proc y los argumentos en el nivel correspondiente; o puede ser “UP”, en cuyo caso el parámetro es el nivel relativo (como en uplevel) de la llamada anterior CALL. Las diferencias notables con respecto a -errorinfo son que:

[1]
es una forma legible por máquina que es susceptible de ser procesada con [foreach {tok prm} ...],
[2]
contiene los valores verdaderos (sustituidos) pasados a las funciones, en lugar del texto estático de los sitios de llamada, y
[3]
es de grano más fino, con un solo elemento por marco de pila (como los procs; no hay elementos separados para construcciones foreach, por ejemplo).

Los valores de las entradas -errorinfo y -errorcode del error más reciente también están disponibles como valores de las variables globales ::errorInfo y ::errorCode respectivamente. El valor de la entrada -errorstack aparece como info errorstack.

Los paquetes de Tcl pueden proporcionar comandos que establecen otras entradas en el diccionario de opciones de retorno, y el comando return puede ser utilizado por los scripts para establecer opciones de retorno además de las definidas anteriormente.

EJEMPLOS

El comando catch puede ser utilizado en un if para ramificarse según el éxito de un script.

if { [catch {open $someFile w} fid] } {
    puts stderr "No se pudo abrir $someFile para escritura\n$fid"
    exit 1
}

Hay ejemplos más complejos de uso de catch en la documentación del comando return.
