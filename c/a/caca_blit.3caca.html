__extern int caca_put_char (caca_canvas_t * cv, int x, int y, uint32_t

ch)

Imprime un carácter ASCII o Unicode en las coordenadas dadas, usando los valores de color de primer plano y de fondo predeterminados

.

Si las coordenadas están fuera de los límites del lienzo, no se imprime nada. Si un carácter Unicode de ancho completo es sobrescrito, sus partes visibles restantes se reemplazan con espacios. Si los límites del lienzo dividirían el carácter de ancho completo en dos, se imprime un espacio en su

lugar.

El comportamiento al imprimir caracteres no imprimibles o caracteres UTF-32 no válidos es indefinido. Para imprimir una secuencia de bytes que forman un carácter UTF-8 en lugar de un carácter UTF-32, use la función caca_put_s

tr().

Esta función devuelve el ancho del carácter impreso. Si es un carácter de ancho completo, se devuelve 2. De lo contrario, se devuelve

1.

falla.

__extern uint32_t caca_get_char (caca_canvas_t const * cv, int x, int

y)

Obtiene el valor ASCII o Unicode del carácter en las coordenadas dadas. Si el valor es menor o igual a 127 (0x7f), el carácter puede imprimirse como ASCII. De lo contrario, debe tratarse como un valor

UTF-32.

Si las coordenadas están fuera de los límites del lienzo, se devuelve un espacio (0x20)

.

Una excepción especial es cuando se devuelve CACA_MAGIC_FULLWIDTH. Se garantiza que este valor no es un carácter Unicode válido, e indica que el carácter a la izquierda del solicitado es un carácter de ancho

completo.

__extern int caca_printf (caca_canvas_t * cv, int x, int y, char const * format, ...)

Format a string at the given coordinates, using the default foreground and background values. The coordinates may be outside the canvas boundaries (eg. a negative Y coordinate) and the string will be cropped accordingly if it is too long. The syntax of the format string is the same as for the C printf() function.

This function returns the number of cells printed by the string. It is not the number of characters printed, because fullwidth characters account for two cells.

__extern int caca_set_canvas_boundaries (caca_canvas_t * cv, int x, int y, int w, int h)

Set new boundaries for a canvas. This function can be used to crop a canvas, to expand it or for combinations of both actions. All frames are affected by this function.

If an error occurs, -1 is returned and errno is set accordingly:

  • EINVAL Specified width or height is invalid.
  • EBUSY The canvas is in use by a display driver and cannot be resized.
  • ENOMEM Not enough memory for the requested canvas size. If this happens, the canvas handle becomes invalid and should not be used.

Parameters

cv The canvas to crop.
x X coordinate of the top-left corner.
y Y coordinate of the top-left corner.
w The width of the cropped area.
h The height of the cropped area.

Returns

0 in case of success, -1 if an error occurred.
