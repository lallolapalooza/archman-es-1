Descripción detallada

Estas funciones proporcionan rutinas de alto nivel para la asignación y el renderizado del tramado.

__extern caca_dither_t * caca_create_dither (int bpp, int w, int h, int pitch, uint32_t rmask, uint32_t gmask, uint32_t bmask, uint32_t amask)

Crea una estructura de tramado a partir de sus coordenadas (profundidad, ancho, alto y paso) y los valores de máscara de píxel. Si la profundidad es de 8 bits por píxel, los valores de máscara se ignoran y la paleta de colores debe establecerse usando la caca_set_dither_palette() función. Para profundidades mayores a 8 bits por píxel, una máscara alfa cero hace que los valores alfa se ignoren.

Si ocurre un error, se devuelve NULL y errno se establece en consecuencia:

  • EINVAL El ancho, alto, paso o valor de bits por píxel solicitado era inválido.
  • ENOMEM No hay suficiente memoria para asignar la estructura de tramado.

Parámetros

bpp Profundidad del mapa de bits en bits por píxel.
w Ancho del mapa de bits en píxeles.
h Alto del mapa de bits en píxeles.
pitch Paso del mapa de bits en bytes.
rmask Máscara de bits para los valores rojos.
gmask Máscara de bits para los valores verdes.
bmask Máscara de bits para los valores azules.
amask Máscara de bits para los valores alfa.

Devuelve

Objeto de tramado en caso de éxito, NULL si ocurrió un error.

__extern int caca_set_dither_palette (caca_dither_t * d, uint32_t red[], uint32_t green[], uint32_t blue[], uint32_t alpha[])

Establece la paleta de un mapa de bits de 8 bits por píxel. Los valores deben estar entre 0 y 4095 (0xfff).

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•
EINVAL El valor de bits por píxel del tramado no es 8, o uno de los valores de píxel estaba fuera del rango 0 - 4095.

Parámetros

d Objeto de tramado.
red Arreglo de 256 valores rojos.
green Arreglo de 256 valores verdes.
blue Arreglo de 256 valores azules.
alpha Arreglo de 256 valores alfa.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_dither_bitmap (caca_canvas_t * cv, int x, int y, int w, int h, caca_dither_t const * d, void const * pixels)

Trama un mapa de bits en las coordenadas dadas. El tramado puede ser de cualquier tamaño y se estirará para ajustarse al área de texto.

Esta función nunca falla.

Parámetros

cv Un manejador para el lienzo de libcaca.
x Coordenada X de la esquina superior izquierda del área de dibujo.
y Coordenada Y de la esquina superior izquierda del área de dibujo.
w Ancho del área de dibujo.
h Alto del área de dibujo.
d Objeto de tramado a dibujar.
pixels Píxeles del mapa de bits.

Devoluciones

Esta función siempre devuelve 0.

Referencias CACA_BLACK, caca_get_attr(), caca_put_char(), caca_set_attr(), y caca_set_color_ansi().
