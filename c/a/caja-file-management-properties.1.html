NOMBRE

Caja-file-management-properties - Preferencias de gestión de archivos de Caja

SINOPSIS

caja-file-management-properties

DESCRIPCIÓN

Las Preferencias de gestión de archivos de Caja se distribuyen como parte del paquete caja y se utilizan para configurar las preferencias de Caja. Normalmente se accede a ellas a través del menú "Editar" en las ventanas del navegador de Caja, o pulsando "ALT+E" y luego "N" una vez abierto el menú.

Las Preferencias de gestión de archivos permiten al usuario configurar el comportamiento de caja.

Puede especificar preferencias de apariencia para la Vista Predeterminada; y valores predeterminados para la Vista de Iconos, Compacta, Lista y Árbol; y seleccionar opciones de ordenación y visualización. Puede configurar Caja para que reconozca la entrada de Clic Único o Doble; así como Incluir un comando de Borrado y una opción de menú que elude la Papelera. Las Preferencias de gestión de archivos de Caja (caja-file-management-properties) también le permiten indicar a Caja cómo manejar ciertos archivos; si Ver o Ejecutar archivos de texto ejecutables; Ver o reproducir automáticamente Medios como CDs, DVDs o fotos, y qué aplicaciones utilizar al realizar estas tareas. Entre otras opciones, este diálogo también le permite ajustar la configuración de vista previa de archivos y la configuración de los complementos instalados, si existen.
