CAPNG_CAPABILITY_TO_NAME(3) API de Libcap-ng CAPNG_CAPABILITY_TO_NAME(3)

NOMBRE

capng_capability_to_name - convierte un entero de capacidad a texto

SINOPSIS

#include <cap-ng.h>

const char *capng_capability_to_name(unsigned int capability);

DESCRIPCIÓN

capng_capability_to_name tomará el entero que se está pasando y lo buscará para ver cuál sería su representación de cadena de texto. El entero de entrada debe estar dentro del rango válido definido en linux/capability.h. La cadena de salida es la misma que la definida como texto en linux/capability.h, pero sin el prefijo CAP_ y en minúsculas. Esto es útil para tomar la representación entera y convertirla en algo más amigable para el usuario en la visualización.

VALOR DE RETORNO

Devuelve un puntero NULL en caso de fallo y la cadena correcta en caso contrario.

VER TAMBIÉN

capng_name_to_capability(3), capabilities(7)
