calibredb es la interfaz de línea de comandos para la base de datos de calibre. Tiene varios subcomandos, documentados a

continuación.

calibredb se puede utilizar para manipular una base de datos de calibre especificada por ruta o un Servidor de contenido de calibre que se ejecute en la máquina local o a través de Internet. Puede iniciar un Servidor de contenido de calibre usando el programa calibre-server o en el programa principal de calibre haga clic en Conectar/compartir  →  Iniciar servidor de contenido. Dado que calibredb puede realizar cambios en sus bibliotecas de calibre, primero debe configurar la autenticación en el servidor. Hay dos formas de

hacerlo:
  • Si planea conectarse solo a un servidor que se ejecuta en la misma computadora, simplemente puede usar la opción --enable-local-write del servidor de contenido, para permitir que cualquier programa, incluido calibredb, que se ejecute en la computadora local realice cambios en sus datos de calibre. Al ejecutar el servidor desde el programa principal de calibre, esta opción se encuentra en Preferencias → Compartir por la
    • red → Avanzado.
  • Si desea habilitar el acceso a través de Internet, debe configurar cuentas de usuario en el servidor y usar las opciones --username y --password para calibredb y darle acceso. Puede configurar la autenticación de usuario para calibre-server usando la opción --enable-auth y usando --manage-users para crear las cuentas de usuario. Si está ejecutando el servidor desde el programa principal de calibre, use Preferencias → Compartir por la red → Requerir nombre de
    • usuario/contras
