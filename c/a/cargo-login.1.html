DESCRIPCIÓ

N

Este comando ejecutará un proveedor de credenciales para guardar un token de modo que los comandos que requieren autenticación, como cargo-publish(1), se autentiquen automáticamente

.

Todos los argumentos que siguen a los dos guiones (--) se pasan al proveedor de

credenciales.

Para el proveedor de credenciales por defecto cargo:token, el token se guarda en $CARGO_HOME/credentials.toml. CARGO_HOME por defecto es .cargo en tu directorio de

inicio.

Si un registro tiene especificado un credential-provider, se usará ese. De lo contrario, se intentarán los proveedores del valor de configuración registry.global-credential-providers, empezando desde el final de la

lista.

El token se leerá de

stdin.

El token de API para crates.io se puede obtener desde https://crates

.io/me.

Ten cuidado de mantener el

token secreto, no debe com
partirse con nadie más.

Opciones

Comunes

+toolchai

n
Si Cargo ha sido instalado con rustup, y el primer argumento de cargo comienza con +, se interpretará como un nombre de toolchain de rustup (como +stable o +nightly). Ver la documentación de rustup https://rust-lang.github.io/rustup/overrides.html para más información sobre cómo funcionan las anulaciones de
toolchain.

--config CLAVE=VALOR o RUT

A
Anula un valor de configuración de Cargo. El argumento debe estar en sintaxis TOML de CLAVE=VALOR, o proporcionarse como una ruta a un archivo de configuración adicional. Esta bandera puede especificarse varias veces. Ver la sección de anulaciones por línea de comandos https://doc.rust-lang.org/cargo/reference/config.html#command-line-overrides para más
información.

-C RUT

A
Cambia el directorio de trabajo actual antes de ejecutar cualquier operación especificada. Esto afecta cosas como dónde busca cargo por defecto el manifiesto del proyecto (Cargo.toml), así como los directorios buscados para descubrir .cargo/config.toml, por ejemplo. Esta opción debe aparecer antes del nombre del comando, por ejemplo cargo -C ruta/a/mi-proyecto build.

Esta opción solo está disponible en el canal nightly https://doc.rust-lang.org/book/appendix-07-nightly-rust.html y requiere la bandera -Z unstable-options para habilitarse (ver #10098 https://github.com/rust-

lang/cargo/is
sues/10098).
