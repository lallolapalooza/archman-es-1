CALC LÍNEA DE

COMANDOS

Sin argumentos calc_cmd, calc opera interactivamente. Si se dan uno o más argumentos en la línea de comandos y NO se da -s, entonces calc los leerá y ejecutará e intentará pasar a interactivo según si la bandera -i estaba presente o

ausente.

Si se da -s, calc no evaluará ningún argumento calc_cmd, sino que los hará disponibles como cadenas para la función incorporada argv()

.

Se pueden ingresar comandos suficientemente simples sin caracteres como paréntesis, corchetes, punto y coma, '*', que tienen interpretaciones especiales en los shells de UNIX, posiblemente con espacios, hasta el salto de línea final. Por

ejemplo: 


calc 23 +
47

imprimirá 70. Sin embargo, las líneas de comandos tendrán

problemas: 


calc 23 * 47

calc -23 +
47

El primer ejemplo anterior falla porque el shell interpreta el '*' como un comodín de archivos. El segundo ejemplo falla porque '-23' se considera una opción de calc (que no lo es) y calc se queja de lo que considera una opción desconocida. Estos casos generalmente pueden hacerse funcionar como se espera encerrando el comando entre

comillas: 


calc '23 * 47'

calc "print sqrt(2), exp(1)
"

o entre paréntesis y comillas para evitar los guiones iniciales como

en: 


calc '(-23 + 47)
'

También se puede usar un guion doble para indicar que las opciones de calc han terminado, como

en: 


calc -- -23 + 47

calc -q -- -23 +
47

Si se va a usar '!' para indicar la función factorial, para shells como csh(1) para los cuales '!' seguido de un carácter no espacio se usa para la sustitución de historial, puede ser necesario incluir un espacio o usar una barra invertida para escapar el significado especial de '!'. Por ejemplo, el

comando:

^2

puede tener que ser reemplazado

por: 


print 27! ^2    o      print 27\!
^2

CALC ARCHIVOS DE

INICIO

Normalmente al inicio, si la variable de entorno $CALCRC no está definida y calc se invoca sin la bandera -q, o si $CALCRC está definida y calc se invoca con -e, calc busca un archivo "startup" en el directorio de recursos de calc, .calcrc en el directorio de inicio del usuario, y .calcinit en el directorio actual. Si se encuentra uno o más de estos, se leen en sucesión como scripts de calc y se ejecutan sus comandos. Cuando está definida, $CALCRC debe contener una lista de nombres de archivos separados por ':', y si calc se invoca entonces sin ninguna de las banderas -q o -e, estos archivos se leen en sucesión y se ejecutan sus comandos. No se produce una condición de error si no se encuentra un archivo de la

lista.

Si el modo especificado por -m deshabilita la apertura de archivos para lectura, entonces la lectura de los archivos de inicio también se deshabilita como si se hubiera

dado
-q.

Cualquier otras_banderas_opcionales se analizarán primero seguidas de las líneas posteriores dentro del propio

script.

Por defecto, usando el inicio de calc en modo de script de shell, calc cerrará la entrada estándar (stdin). Así, las funciones incorporadas como prompt(str) fallarán (devolverán un valor nulo). Los scripts de shell de Calc que llaman a la función incorporada prompt(str) no funcionarán correctamente (la función incorporada prompt siempre fallará y devolverá un valor nulo) a menos quehe -p flag is given on the command

El siguiente script de shell siempre imprimirá "got null" porque stdin será cerrado por calc durante el

inicio: 


#!/usr/bin/calc -q -f

  print("got null");

  print("got " + n);
}

espera:

n = prompt("Test> ");
if (isnull(n)) {
  print("got null");
} else {
  print("got " + n);
}

TIPOS DE

DATOS

Los tipos de datos incorporados fundamentales incluyen enteros, números reales, números racionales, números complejos y

cadenas.

Mediante el uso de un objeto, uno puede definir tipos de datos arbitrariamente complejos. Uno puede definir cómo se comportan dichos objetos ante una amplia gama de operaciones como la suma, la resta, la multiplicación, la división, la negación, el cuadrado, el módulo, el redondeo, la potenciación, la igualdad, la comparación, la impresión y así

sucesivamente.

Para más información use los siguientes comandos de

calc:


help types
help obj
show objfuncs

VARIABLE

S

Las variables en calc no tienen tipo. En otras palabras, el tipo fundamental de una variable está determinado por su contenido. Antes de que a una variable se le asigne un valor, tiene el valor de

cero.

El alcance de una variable puede ser global, local a un archivo, o local a un procedimiento. Los valores pueden agruparse en una matriz, o en una lista que permite operaciones de estilo pila y

cola.

Para más información use los siguientes comandos de

calc:


help variable
help mat
help list
show globals

ENTRADA/SALID

A

Un ``0x'' inicial implica un valor hexadecimal, un ``0b'' inicial implica un valor binario, y un ``0'' seguido de un dígito implica un valor octal. Los números complejos se indican con una ``i'' final, como en ``3+4i''. Las cadenas pueden delimitarse por un par de comillas simples o dobles. Por defecto, calc imprime los valores como si fueran números de punto flotante. Uno puede cambiar el defecto para imprimir valores en una serie de modos incluyendo fracciones, enteros y

exponentiales.

Se proporcionan varias operaciones de E/S de archivos similares a las de stdio. Uno puede abrir, leer, escribir, buscar y cerrar archivos. Los nombres de archivo están sujetos a la expansión de ``~'' a directorios de inicio de una manera similar a la de el Korn o el

C-Shell.

Por

ejemplo:


~/.calcrc
~chongo/lib/fft_multiply.cal

Para más información use el siguiente comando de

calc:


help file

LENGUAJE

CALC

El lenguaje calc es un lenguaje similar a C. El lenguaje incluye comandos como declaraciones de variables, expresiones, pruebas, etiquetas, bucles, operaciones de archivos, llamadas a funciones. Estos comandos son muy similares a sus contrapartes en

C.

El lenguaje también incluye una serie de comandos particulares de calc. Estos incluyen comandos como la definición de funciones, ayuda, lectura de archivos de recursos, volcado de archivos a un archivo, notificación de errores, control de configuración y

estado.

Para más información use el siguiente comando de

calc:


help command
help statement
help expression
help operator
help config
