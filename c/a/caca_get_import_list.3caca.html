format)

Importa un búfer de memoria en el marco actual del lienzo de libcaca dado. El marco actual se redimensiona en consecuencia y su contenido se reemplaza con los datos

importados.

Los valores válidos para format

son:
  • '': intenta autodetectar el formato del
    • archivo.
  • 'caca': importa archivos nativos de
    • libcaca.
  • 'text': importa archivos de texto
    • ASCII.
  • 'ansi': importa archivos
    • ANSI.
  • 'utf8': importa archivos UTF-8 con códigos de color
    • ANSI.

    • porta arch

Se devuelve el número de bytes leídos. Si el formato del archivo es válido, pero no había suficientes datos disponibles, se devuelve

consecuencia:
  • ENOMEM No hay suficiente memoria para asignar el
    • lienzo.
  • EOVERFLOW La importación de datos causó un desbordamiento de
    • valor.
