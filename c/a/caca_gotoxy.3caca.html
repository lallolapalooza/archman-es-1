__extern int caca_put_str (caca_canvas_t * cv, int x, int y, char const * s)

Imprime una cadena UTF-8 en las coordenadas dadas, usando los valores predeterminados de primer plano y fondo. Las coordenadas pueden estar fuera de los límites del lienzo (por ejemplo, una coordenada Y negativa) y la cadena se recortará en consecuencia si es demasiado larga.

Ver caca_put_char() para más información sobre cómo se manejan los caracteres de ancho completo al sobrescribirse entre sí o en los límites del lienzo.

Esta función devuelve el número de celdas impresas por la cadena. No es el número de caracteres impresos, porque los caracteres de ancho completo ocupan dos celdas.

Esta función nunca falla.

Parámetros

cv Un manejador del lienzo de libcaca.
x Coordenada X.
y Coordenada Y.
s La cadena a imprimir.

Devuelve

El número de celdas impresas.

Referencias caca_put_char(), caca_utf32_is_fullwidth(), y caca_utf8_to_utf32().

Referenciado por caca_vprintf().

__extern int caca_blit (caca_canvas_t * dst, int x, int y, caca_canvas_t const * src, caca_canvas_t const * mask)

Hace un blit de un lienzo sobre otro en las coordenadas dadas. Se puede usar una máscara de lienzo opcional.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

•

x Coordenada X.
y Coordenada Y.
src El lienzo de origen.
mask El lienzo de la máscara.

Devuelve

__extern int caca_set_canvas_boundaries (caca_canvas_t * cv, int x, int y, int w, int h)

Establece nuevos límites para un lienzo. Esta función se puede usar para recortar un lienzo, expandirlo o para combinaciones de ambas acciones. Todos los fotogramas se ven afectados por esta función.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

  • EINVAL El ancho o alto especificado no es válido.
  • EBUSY El lienzo está en uso por un controlador de pantalla y no se puede redimensionar.
  • ENOMEM No hay suficiente memoria para el tamaño de lienzo solicitado. Si esto sucede, el manejador del lienzo se vuelve inválido y no debe usarse.

Parámetros

cv El lienzo a recortar.
x Coordenada X de la esquina superior izquierda.
y Coordenada Y de la esquina superior izquierda.
w El ancho del área recortada.
h El alto del área recortada.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

Referencias caca_add_dirty_rect(), caca_blit(), caca_create_canvas(), caca_create_frame(), caca_get_frame_count(), y caca_set_frame().

    caca_gotoxy(3caca)

    LibCaca Manual

    NAME

    caca_gotoxy - Set the current drawing position

    SYNOPSIS

    #include <cacarender.h>

    void caca_gotoxy( caca_canvas_t *canvas, int x, int y );

    DESCRIPTION

    The caca_gotoxy function sets the current drawing position of the canvas to the specified coordinates (x, y). Any subsequent drawing operations will start from this position.

    ARGUMENTS

    canvas
    A pointer to a caca_canvas_t structure.
    x
    The new x-coordinate for the drawing position.
    y
    The new y-coordinate for the drawing position.

    RETURN VALUE

    None.

    EXAMPLE

    #include <cacarender.h>

int main(void) {
    caca_canvas_t *canvas;
    canvas = caca_create_canvas(80, 24);

    /* Set the drawing position to (10, 5) */
    caca_gotoxy(canvas, 10, 5);
    caca_put_str(canvas, 0, 0, "Hello, world!"); /* This will be drawn at (10, 5) */

    /* ... drawing operations ... */

    caca_free_canvas(canvas);
    return 0;
}
