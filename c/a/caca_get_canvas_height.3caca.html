Establece el ancho y el alto del lienzo, en celdas de caracteres.
El contenido del lienzo se conserva en la medida del nuevo tamaño del lienzo. Las celdas de caracteres recién asignadas a la derecha y/o en la parte inferior del lienzo se rellenan con espacios. Si como resultado del redimensionado las coordenadas del cursor caen fuera de los nuevos límites del lienzo, se readjustan. Por ejemplo, si la coordenada X actual del cursor es 11 y el ancho solicitado es 10, la nueva coordenada X del cursor será 10. Es un error intentar redimensionar el lienzo si se ha adjuntado un controlador de salida al lienzo usando
caca_create_display() . Necesitas eliminar el controlador de salida usando caca_free_display(

__extern uint32_t const * caca_get_canvas_chars (caca_canvas_t const * cv)

Devuelve el array de caracteres interno del lienzo actual. Los elementos del array consisten en valores Unicode de 32 bits en orden nativo tal como los devuelve caca_get_char().

Esta función es probablemente solo útil para los controladores de pantalla internos de libcaca.

Esta función nunca falla.

Parámetros

Retorna

__extern int caca_free_canvas (caca_canvas_t * cv)

Libera todos los recursos asignados por caca_create_canvas(). El puntero del lienzo se vuelve inválido y no debe usarse más a menos que se realice una nueva llamada a caca_create_canvas().

Si ocurre un error, se devuelve -1 y se establece errno en consecuencia:

•
EBUSY El lienzo está en uso por un controlador de pantalla y no puede ser liberado.

Parámetros

cv Un lienzo de libcaca.

Retorna

0 en caso de éxito, -1 si ocurrió un error.
