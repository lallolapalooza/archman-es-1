NOMBRE

capable.bt - Rastrea las comprobaciones de capacidades de seguridad (cap_capable()).

SINOPSIS

capable.bt

DESCRIPCIÓN

Esto rastrea las comprobaciones de capacidades de seguridad en el kernel e imprime detalles para cada llamada. Esto puede ser útil para la depuración general y también para la aplicación de políticas de seguridad: determinar una lista blanca de capacidades que una aplicación necesita.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF, bpftrace.

EJEMPLOS

Rastrear todas las comprobaciones de capacidades a nivel de sistema:
# capable.bt

CAMPOS

TIEMPO(s)
Hora de la comprobación de la capacidad: HH:MM:SS.
UID
ID de usuario.
PID
ID de proceso.
COMM
Nombre del proceso. CAP Número de capacidad. NOMBRE Nombre de la capacidad. Ver capabilities(7) para las descripciones.
AUDITORÍA
Si este fue un evento de auditoría.

SOBRECARGA

Esto añade instrumentación de baja sobrecarga a las comprobaciones de capacidades, que se espera que sean de baja frecuencia; sin embargo, eso depende de la aplicación. Pruebe en un entorno de laboratorio antes de usarlo.

FUENTE

Esto es de bpftrace.

https://github.com/bpftrace/bpftrace

También busque en la distribución de bpftrace un archivo complementario _examples.txt que contenga ejemplos de uso, salida y comentarios para esta herramienta.

Esta es una versión de bpftrace de la herramienta bcc del mismo nombre. La herramienta bcc proporciona opciones para personalizar la salida.

https://github.com/iovisor/bcc
