Descripción Detallada

Estas funciones manipulan rectángulos sucios para una representación optimizada.

Documentación de Funciones

__extern int caca_disable_dirty_rect (caca_canvas_t * cv)

Deshabilita el manejo de rectángulos sucios para todas las llamadas gráficas de libcaca. Esto es útil cuando la aplicación que llama necesita realizar operaciones lentas dentro de un área conocida. Simplemente llama a caca_add_dirty_rect() después.

Esta función es recursiva. Los rectángulos sucios solo se vuelven a habilitar cuando caca_enable_dirty_rect() se llama tantas veces como sea necesario.

Esta función nunca falla.

Parámetros

cv Un lienzo de libcaca.

Retorna

Esta función siempre retorna 0.

__extern int caca_enable_dirty_rect (caca_canvas_t * cv)

Esta función solo se puede llamar después de que se haya llamado a caca_disable_dirty_rect().

Si ocurre un error, se retorna -1 y se configura errno en consecuencia:

•
EINVAL Los rectángulos sucios no estaban deshabilitados.

Parámetros

cv Un lienzo de libcaca.

Retorna

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_get_dirty_rect_count (caca_canvas_t * cv)

Obtiene el número de rectángulos sucios en un lienzo. Los rectángulos sucios son áreas que contienen celdas que han cambiado desde el último restablecimiento.

Los rectángulos sucios son utilizados internamente por los controladores de pantalla para optimizar la representación, evitando redibujar toda la pantalla. Una vez que el controlador de pantalla ha representado el lienzo, restablece la lista de rectángulos sucios.

Se garantiza que los rectángulos sucios no se superponen.

Esta función nunca falla.

Parámetros

cv Un lienzo de libcaca.

Retorna

El número de rectángulos sucios en el lienzo dado.

__extern int caca_get_dirty_rect (caca_canvas_t * cv, int r, int * x, int * y, int * width, int * height)

Obtiene las coordenadas del rectángulo sucio dado del lienzo. El índice debe estar dentro del recuento de rectángulos sucios. Consulte caca_get_dirty_rect_count() para saber cómo calcular este recuento.

Si ocurre un error, no se escriben coordenadas en los argumentos de puntero, se retorna -1 y se configura errno en consecuencia:

•
EINVAL El índice del rectángulo especificado está fuera de los límites.

Parámetros

cv Un lienzo de libcaca.
r El índice del rectángulo solicitado.
x Un puntero a un entero donde se almacenará el borde izquierdo del rectángulo sucio.
y Un puntero a un entero donde se almacenará el borde superior del rectángulo sucio.
width Un puntero a un entero donde se almacenará el ancho del rectángulo sucio.
height Un puntero a un entero donde se almacenará la altura del rectángulo sucio.

Retorna

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_add_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

Añade una zona invalidante a la lista de rectángulos sucios del lienzo. Para más información sobre los rectángulos sucios, consulte caca_get_dirty_rect().

Esta función puede ser útil para forzar la actualización de una zona dada del lienzo, incluso si el seguimiento de rectángulos sucios indica que no ha cambiado. Esto puede suceder si el contenido del lienzo fue modificado directamente.

Si ocurre un error, se retorna -1 y se configura errno en consecuencia:

•
EINVAL Las coordenadas del rectángulo especificado están fuera de los límites.

Parámetros

cv Un lienzo de libcaca.
x El borde izquierdo del rectángulo sucio adicional.
y El borde superior del rectángulo sucio adicional.
width El ancho del rectángulo sucio adicional.
height La altura del rectángulo sucio adicional.

Retorna

0 en caso de éxito, -1 si ocurrió un error.

__extern int caca_remove_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

Marca un área de celdas en el lienzo como no sucia. Para más información sobre los rectángulos sucios, consulte caca_get_dirty_rect().

Los valores tales que xmin > xmax o ymin > ymax indican que el rectángulo sucio está vacío. Serán ignorados silenciosamente.

Si ocurre un error, se retorna -1 y se configura errno en consecuencia:

•
EINVAL Las coordenadas del rectángulo especificado están fuera de los límites.

Parámetros

cv Un lienzo de libcaca.
x El borde izquierdo del área limpia.
y El borde superior del área limpia.
width El ancho del área limpia.
height La altura del área limpia.

Retorna

0 en caso de éxito, -1 si ocurrió un error.
