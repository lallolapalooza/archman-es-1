__extern int caca_rotate_left (caca_canvas_t * cv)

Aplica una transformación de 90 grados a un lienzo, eligiendo caracteres que parezcan la versión rotada siempre que sea posible. Las celdas de caracteres se rotan de dos en dos. Algunos caracteres permanecerán sin cambios por el proceso, algunos otros serán reemplazados por equivalentes cercanos. Los caracteres de ancho completo en coordenadas horizontales impares se perderán. La operación no está garantizada para ser reversible en absoluto.

Tenga en cuenta que el ancho del lienzo se divide por dos y se convierte en la nueva altura. La altura se multiplica por dos y se convierte en el nuevo ancho. Si el ancho original es un número impar, la división se redondea hacia arriba.

Si ocurre un error, se devuelve -1 y errno se establece en consecuencia:

  • EBUSY El lienzo está en uso por un controlador de pantalla y no se puede rotar.
  • ENOMEM No hay suficiente memoria para asignar el nuevo tamaño del lienzo. Si esto ocurre, el identificador del lienzo anterior sigue siendo válido.

Parámetros

cv El lienzo a rotar a la izquierda.

Devuelve

0 en caso de éxito, -1 si ocurrió un error.

Referencias caca_add_dirty_rect().

NAME

caca_stretch_right - apply a 270-degree transformation to a canvas

SYNOPSIS

__extern   int caca_stretch_right (caca_canvas_t * cv)

Detailed Description

Apply a 270-degree transformation to a canvas, choosing characters that look like the rotated version wherever possible. Some characters will stay unchanged by the process, some others will be replaced by close equivalents. Fullwidth characters will be lost. The operation is not guaranteed to be reversible at all.

Note that the width and height of the canvas are swapped, causing its aspect ratio to look stretched.

If an error occurs, -1 is returned and errno is set accordingly:

  • EBUSY The canvas is in use by a display driver and cannot be rotated.
  • ENOMEM Not enough memory to allocate the new canvas size. If this happens, the previous canvas handle is still valid.

Returns
