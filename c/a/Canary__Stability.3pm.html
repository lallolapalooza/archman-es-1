Stability(3) Documentación de Perl aportada por el usuario Stability(3)

NOMBRE

Canary::Stability - canario para comprobar la compatibilidad de perl para los módulos de schmorp

SINOPSIS

# en Makefile.PL
use Canary::Stability DISTNAME => 2001, MINIMUM_PERL_VERSION;

DESCRIPCIÓN

Este módulo es utilizado por los módulos de Schmorp durante la etapa de configuración para probar la compatibilidad de la perl instalada con sus módulos.

No está, en esta etapa, pensado como una herramienta para otros autores de módulos, aunque en principio nada les impide suscribirse a las mismas ideas.

Ver el Makefile.PL en Coro o AnyEvent para ejemplos de uso.

VARIABLES DE ENTORNO

"PERL_CANARY_STABILITY_NOPROMPT=1"
No solicitar al usuario mensajes de alerta.
"PERL_CANARY_STABILITY_COLOUR=0"
Deshabilitar el uso de colores.
"PERL_CANARY_STABILITY_COLOUR=1"
Forzar el uso de colores.
"PERL_CANARY_STABILITY_DISABLE=1"
Deshabilitar completamente la funcionalidad de este módulo.
"AUTOMATED_TESTING=1"
Cuando esta variable se establece a un valor verdadero y no se cumple el requisito de versión mínima de perl, el módulo saldrá, lo que debería omitir las pruebas en entornos de prueba automatizados.

Esto se hace para evitar informes falsos de fallo o éxito cuando las posibilidades de éxito ya son bastante bajas y los fallos no son compatibles con el autor.
