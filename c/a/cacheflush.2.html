cacheflush(2) Manual de llamadas al sistema cacheflush(2)

NOMBRE

cacheflush - vacía el contenido de la caché de instrucciones y/o datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/cachectl.h>
int cacheflush(int nbytes;
               void addr[nbytes], int nbytes, int cache);

Nota: En algunas arquitecturas, no existe un envoltorio de glibc para esta llamada al sistema; ver VERSIONS.

DESCRIPCIÓN

cacheflush() vacía el contenido de las cachés indicadas para las direcciones de usuario en el rango addr a (addr+nbytes-1). cache puede ser uno de:

ICACHE
Vacía la caché de instrucciones.
DCACHE
Escribe en memoria e invalida las líneas de caché válidas afectadas.
BCACHE
Igual que (ICACHE|DCACHE).

VALOR DE RETORNO

cacheflush() devuelve 0 si tiene éxito. En caso de error, devuelve -1 y establece errno para indicar el error.

ERRORES

EFAULT
Todo o parte del rango de direcciones addr a (addr+nbytes-1) no es accesible.
EINVAL
cache no es ICACHE, DCACHE o BCACHE (pero ver BUGS).

VERSIONES

cacheflush() no debe usarse en programas destinados a ser portables. En Linux, esta llamada apareció por primera vez en la arquitectura MIPS, pero hoy en día, Linux proporciona una llamada al sistema cacheflush() en algunas otras arquitecturas, pero con argumentos diferentes.

Variantes específicas de arquitectura

glibc proporciona un envoltorio para esta llamada al sistema, con el prototipo que se muestra en SINOPSIS, para las siguientes arquitecturas: ARC, CSKY, MIPS y NIOS2.

En algunas otras arquitecturas, Linux proporciona esta llamada al sistema, con argumentos diferentes:

M68K:
int cacheflush(unsigned long addr, int scope, int cache,
               unsigned long size);
SH:
int cacheflush(unsigned long addr, unsigned long size, int op);
NDS32:
int cacheflush(unsigned int start, unsigned int end, int cache);

En las arquitecturas anteriores, glibc no proporciona un envoltorio para esta llamada al sistema; llámela usando syscall(2).

Alternativa de GCC

A menos que necesite un control más detallado que esta llamada al sistema proporciona, probablemente querrá usar la función integrada de GCC __builtin___clear_cache(), que proporciona una interfaz portable a través de plataformas compatibles con GCC y compiladores similares:


void __builtin___clear_cache(void *begin, void *end);

En plataformas que no requieren vaciados de la caché de instrucciones, __builtin___clear_cache() no tiene ningún efecto.

Nota: En algunos compiladores compatibles con GCC, el prototipo para esta función integrada usa char * en lugar de void * para los parámetros.

ESTÁNDARES

Históricamente, esta llamada al sistema estaba disponible en todas las variantes de UNIX MIPS, incluyendo RISC/os, IRIX, Ultrix, NetBSD, OpenBSD y FreeBSD (y también en algunos sistemas operativos MIPS no UNIX), por lo que la existencia de esta llamada en los sistemas operativos MIPS es un estándar de facto.

BUGS

Los núcleos de Linux anteriores a Linux 2.6.11 ignoran los argumentos addr y nbytes, lo que hace que esta función sea bastante costosa. Por lo tanto, siempre se vacía toda la caché.

Esta función siempre se comporta como si se hubiera pasado BCACHE para el argumento cache y no realiza ninguna comprobación de errores en el argumento cache.
