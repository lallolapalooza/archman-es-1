CAPNG_NAME_TO_CAPABILITY(3) API de Libcap-ng CAPNG_NAME_TO_CAPABILITY(3)

NOMBRE

capng_name_to_capability - convertir texto de capacidad a entero

SINOPSIS

#include <cap-ng.h>

int capng_name_to_capability(const char *name);

DESCRIPCIÓN

capng_name_to_capability tomará la cadena que se le pasa y la buscará para ver cuál sería su valor entero. La cadena de entrada es el mismo nombre que la definición en linux/capability.h con el prefijo CAP_ eliminado. El caso de la cadena no importa. El entero que se devuelve es el mismo que la definición de linux/capability.h. Esto es útil para tomar entrada de cadena y convertirla en algo que se pueda usar con capng_update.

VALOR DE RETORNO

Esto devuelve un número negativo en caso de fallo y la definición correcta en caso contrario.

VER TAMBIÉN

capng_capability_to_name(3), capabilities(7)
