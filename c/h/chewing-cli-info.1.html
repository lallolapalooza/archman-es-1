NOMBRE

chewing-cli info - Muestra información sobre el diccionario

SINOPSIS

chewing-cli info [-p|--path] [-u|--user] [-s|--system] [-j|--json] [-h|--help]

DESCRIPCIÓN

Muestra información sobre el diccionario

OPCIONES

-p, --path=RUTA
Ubicación del archivo del diccionario
-u, --user
Muestra información del diccionario de usuario detectado
-s, --system
Muestra información del diccionario del sistema detectado
-j, --json
Salida en formato JSON
-h, --help
Imprime la ayuda
