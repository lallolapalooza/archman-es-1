CHGRP(1P) Manual del Programador POSIX CHGRP(1P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

chgrp — cambiar la propiedad de grupo de un archivo

SINOPSIS

chgrp [-h] grupo archivo...
chgrp -R [-H|-L|-P] grupo archivo...

DESCRIPCIÓN

La utilidad chgrp establecerá el ID de grupo del archivo nombrado por cada operando archivo en el ID de grupo especificado por el operando grupo .

Para cada operando archivo , o, si se usa la opción -R , para cada archivo encontrado al recorrer los árboles de directorios especificados por los operandos archivo , la utilidad chgrp realizará acciones equivalentes a la función chown() definida en el Volumen de Interfaces del Sistema de POSIX.1‐2017, llamada con los siguientes argumentos:

*
El operando archivo se usará como el argumento ruta .
*
El ID de usuario del archivo se usará como el argumento propietario .
*
El ID de grupo especificado se usará como el argumento grupo .

A menos que chgrp sea invocado por un proceso con privilegios apropiados, los bits set-user-ID y set-group-ID de un archivo regular se borrarán al completarse con éxito; los bits set-user-ID y set-group-ID de otros tipos de archivo pueden borrarse.

OPCIONES

La utilidad chgrp deberá cumplir con el Volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de Sintaxis de Utilidades.

La implementación deberá soportar las siguientes opciones:

-h
Para cada operando archivo que nombre un archivo de tipo enlace simbólico, chgrp intentará establecer el ID de grupo del enlace simbólico en lugar del archivo referenciado por el enlace simbólico.
-H
Si se especifica la opción -R y se especifica en la línea de comandos un enlace simbólico que referencie un archivo de tipo directorio, chgrp cambiará el grupo del directorio referenciado por el enlace simbólico y de todos los archivos en la jerarquía de archivos por debajo de él.
-L
Si se especifica la opción -R y se especifica en la línea de comandos o se encuentra durante el recorrido de una jerarquía de archivos un enlace simbólico que referencie un archivo de tipo directorio, chgrp cambiará el grupo del directorio referenciado por el enlace simbólico y de todos los archivos en la jerarquía de archivos por debajo de él.
-P
Si se especifica la opción -R y se especifica en la línea de comandos o se encuentra durante el recorrido de una jerarquía de archivos un enlace simbólico, chgrp cambiará el ID de grupo del enlace simbólico. La utilidad chgrp no seguirá el enlace simbólico a ninguna otra parte de la jerarquía de archivos.
-R
Cambiar recursivamente los IDs de grupo de los archivos. Para cada operando archivo que nombre un directorio, chgrp cambiará el grupo del directorio y de todos los archivos en la jerarquía de archivos por debajo de él. A menos que se especifique una opción -H, -Lo -P , no se especifica cuál de estas opciones se usará por defecto.

Especificar más de una de las opciones mutuamente excluyentes -H, -Ly -P no se considerará un error. La última opción especificada determinará el comportamiento de la utilidad.

OPERANDOS

Se soportarán los siguientes operandos:

grupo
Un nombre de grupo de la base de datos de grupos o un ID de grupo numérico. Cada uno especifica un ID de grupo a dar a cada archivo nombrado por uno de los operandos archivo . Si un operando numérico grupo existe en la base de datos de grupos como un nombre de grupo, se usará el número de ID de grupo asociado con ese nombre de grupo como el ID de grupo.
archivo
Una ruta de archivo cuyo ID de grupo debe ser modificado.

STDIN

No se usa.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de chgrp:

LANG
Proporcionar un valor por defecto para las variables de internacionalización que no están establecidas o son nulas. (Vea el Volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización para la precedencia de las variables de internacionalización usadas para determinar los valores de las categorías de configuración regional.)
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determinar la configuración regional para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte en lugar de multibyte en los argumentos).
LC_MESSAGES

Determinar la configuración regional que debe usarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determinar la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

CONSECUENCIAS DE ERRORES

Las siguientes secciones son informativas.

USO DE LA APLICACIÓN

Solo el propietario de un archivo o un usuario con privilegios apropiados puede cambiar el propietario o el grupo de un archivo.

Algunas implementaciones restringen el uso de chgrp a un usuario con privilegios apropiados cuando el grupo especificado no es el ID de grupo efectivo o uno de los IDs de grupo suplementarios del proceso que lo invoca.

EJEMPLOS

Ninguno.

JUSTIFICACIÓN

Las versiones de System V y BSD usan códigos de estado de salida diferentes. Algunas implementaciones usaban el estado de salida como un recuento del número de errores que ocurrieron; esta práctica no es viable ya que puede desbordar el rango de valores de estado de salida válidos. Los desarrolladores del estándar optaron por enmascarar estos especificando solo 0 y >0 como valores de salida.

La funcionalidad de chgrp se describe sustancialmentelmente a través de referencias a chown(). De esta manera, no se requiere duplicación de esfuerzo para describir las interacciones de permisos, múltiples grupos, etc.
