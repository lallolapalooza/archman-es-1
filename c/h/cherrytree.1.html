CHERRYTREE(1) Manual de Comandos Generales CHERRYTREE(1)

NOMBRE

cherrytree - una aplicación jerárquica para tomar notas

SINOPSIS

cherrytree [-V] [-N] [ruta_archivo [-n nombre_nodo] [-a nombre_ancla] [-x directorio_exportar_html] [-t directorio_exportar_txt] [-p ruta_exportar_pdf] [-P contraseña] [-w] [-s]]

DESCRIPCIÓN

cherrytree es una aplicación jerárquica para tomar notas, con texto enriquecido, resaltado de sintaxis, manejo de imágenes, hipervínculos, importación/exportación con soporte para múltiples formatos, soporte para múltiples idiomas y más.
