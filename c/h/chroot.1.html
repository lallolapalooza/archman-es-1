CHROOT(1) Comandos de usuario CHROOT(1)

NOMBRE

chroot - ejecuta un comando o un shell interactivo con un directorio raíz especial

SINOPSIS

chroot [OPCIÓN]... NUEVA_RAIZ [COMANDO [ARG]...]

DESCRIPCIÓN

Ejecuta COMANDO con el directorio raíz establecido a NUEVA_RAIZ.

--groups=LISTA_G
especificar grupos suplementarios como g1,g2,..,gN
--userspec=USUARIO:GRUPO
especificar el usuario y grupo (ID o nombre) a utilizar
--skip-chdir
no cambiar el directorio de trabajo a '/'
--help
mostrar esta ayuda y salir
--version
mostrar información de versión y salir

Si no se proporciona ningún comando, ejecuta '"$SHELL" -i' (por defecto: '/bin/sh -i').

Estado de salida:

125
si el propio comando chroot falla
126
si COMANDO se encuentra pero no se puede invocar
127
si COMANDO no se encuentra
-
el estado de salida de COMANDO en caso contrario
