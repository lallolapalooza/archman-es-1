NOMBRE

chromium-bsu - juego de disparos espaciales con desplazamiento suave

SINOPSIS

chromium-bsu [-fwv] [-na] [-nb] [-nt] [-V] [--fullscreen] [--window] [--vidmode <mode>] [--noaudio] [--noblend] [--notexborder] [--version] [--debug]

DESCRIPCIÓN

chromium-bsu es un juego de acción de disparos arcade de ritmo rápido visto desde arriba. Progresas en el juego destruyendo todo lo que ves en pantalla. Hay una variedad de 'potenciadores' para asistirte en el camino. Hay un gran jefe que destruir al final de cada nivel y hay varias naves que destruir antes de llegar a cada jefe.

CONSEJOS

¡No dejes que NINGUNA nave enemiga pase a tus combatientes!

¡Usa tus combatientes como armas!
¡El suicidio estratégico es una táctica poderosa!
¡Autodestrúyete para conservar tu munición!

CONTROLES

Los dispositivos de entrada admitidos dependen de las opciones de compilación utilizadas para construir.

Puedes controlar la nave con tu ratón, teclado (teclas de flecha) o joystick.
Para disparar tus armas, mantén presionado el botón izquierdo del ratón, los botones del joystick o la barra espaciadora.
Para pausar el juego, presiona pause o p en el teclado.
Para hacer explotar tu nave, presiona enter/return o 0 dos veces o haz doble clic derecho.
Para cambiar a la siguiente pista en tu lista de reproducción de música, presiona n en el teclado.

OPCIONES

Cuando se ejecuta con argumentos que no se entienden, se muestra la información de uso.

El juego entiende las siguientes opciones de línea de comandos
-f --fullscreen
se ejecuta en modo pantalla completa.
-w --window
se ejecuta en una ventana.
-na --noaudio
no inicializa el audio.
-v <mode>, --vidmode <mode>
selecciona el modo de vídeo.
mode
0 = 512 x 384
1 = 640 x 480
2 = 800 x 600
3 = 1024 x 768
4 = 1280 x 1024
-nb --noblend
desactiva el blending. (OpenGL)
-nt --notexborder
no establece el color del borde de la textura. (OpenGL)
-V --version
muestra la información de la versión y sale.
--debug
habilita la visualización de información de depuración.

ENTORNO

Se utilizan las siguientes variables de entorno.

CHROMIUM_BSU_SCORE
especifica la ubicación del archivo de puntuaciones altas del usuario.
CHROMIUM_BSU_DATA
especifica la ubicación de los datos del juego personalizados por el usuario con la misma disposición y nombres de archivo que los del sistema.
CHROMIUM_BSU_FONT
Al usar el backend GLC, esto especifica el nombre de la fuente a usar en el menú y el juego, si está disponible.
Al usar el backend FTGL, esto especifica la ruta al archivo de fuente TTF usado en el menú y el juego.

ARCHIVOS

Se utilizan los siguientes archivos.

~/.chromium-bsu
contiene varias preferencias del usuario.
~/.chromium-bsu-score
contiene las puntuaciones altas del usuario.
~/.chromium-bsu-music
contiene una lista de música para reproducir durante el juego.
~/.chromium-bsu-data/
directorio que contiene datos del juego personalizados por el usuario con la misma disposición y nombres de archivo que los del sistema.
El juego también buscará en un directorio del sistema para los datos.

CONFIGURACIÓN

El archivo de configuración es un archivo de texto plano. Cada línea contiene una clave, un separador de un solo espacio y luego un valor numérico (entero o de punto flotante). El juego reconoce las siguientes claves.

use_playList
Habilita/deshabilita el soporte de listas de reproducción. Esto hace que el juego abra el archivo ~/.chromium-bsu-music y reproduzca los archivos listados allí. Deshabilitado por defecto. Solo funciona al usar OpenAL.
use_cdrom
Habilita/deshabilita el soporte de CDROM. Esto hace que el juego intente reproducir cualquier CD de audio que pueda estar disponible. Esto está deshabilitado por defecto porque el constante giro del CD puede ser molesto y porque los CD son menos populares que MP3/OGG en estos días. Solo funciona al compilar con soporte SDL 1.X.
full_screen
Habilita/deshabilita el modo pantalla completa. Esto hace que el juego llene la pantalla en lugar de solo usar una ventana. Deshabilitado por defecto. Solo funciona al usar soporte SDL.
true_color
Habilita/deshabilita el color de 24 bits. Cuando está deshabilitado usa color de 16 bits. Deshabilitado por defecto. Solo funciona al usar soporte SDL.
swap_stereo
Habilita/deshabilita el intercambio de orientación del sonido. Deshabilitado por defecto. Solo funciona al usar OpenAL.
auto_speed
Usa un algoritmo alternativo de ajuste de velocidad en ciertas situaciones. Deshabilitado por defecto. Solo funciona al usar soporte SDL.
show_fps
Imprime los fotogramas por segundo en la parte superior derecha cuando estás en un juego. Por defecto está habilitado.
screenWidth
El número de píxeles de ancho para establecer el tamaño de la pantalla o ventana.
screenHigh
El número de píxeles de alto para establecer el tamaño de la pantalla o ventana.
screenSize
Selecciona el tamaño de la pantalla o ventana. Por defecto es 800x600.
Esta opción solo existe con fines de compatibilidad hacia atrás.
Es reemplazada por las opciones screenWidth y screenHeight.
0 = 512 x 384
1 = 640 x 480
2 = 800 x 600
3 = 1024 x 768
4 = 1280 x 1024
gfxLevel
Selecciona la cantidad deseada de efectos gráficos. Por defecto es efectos completos.
0 = mínimo
1 = medio
2 = completo
gameSkillBase
Selecciona el nivel de habilidad deseado. Por defecto es normal.
0.2 = pez en un barril
0.3 = debilucho
0.4 = fácil
0.5 = normal
0.6 = experimentado
0.7 = divertido
0.8 = demencial
0.9 = imposible
movementSpeed
Velocidad a la que se mueve la nave. El valor mostrado en el menú es 1000 veces el valor en la configuración. Por defecto es 0.03.
maxLevel
El nivel máximo que se puede intentar. Para intentar el siguiente nivel primero debes completar el nivel máximo. chromium-bsu(6) — Arch Linux manual pages

CONFIGURATION

The following settings can be modified in the ~/.config/chromium-bsu/settings file.

volMaster
Sets the master volume. The value shown in the menu is 10 times the value in the configuration. Ranges from 0.0 to 1.0 and defaults to 1.
volSound
Sets the volume of the sound effects. The value shown in the menu is 10 times the value in the configuration. Ranges from 0.0 to 1.0 and defaults to 0.9.
volMusic
Sets the volume of the sound effects. The value shown in the menu is 10 times the value in the configuration. Ranges from 0.0 to 1.0 and defaults to 0.5.
viewGamma
Sets the gamma used when loading the PNG images used for sprites. Defaults to 1.1.
audioType
Sets which audio backend to use. The desired backend must be compiled in for it to work, otherwise the other backend will be used. Defaults to OpenAL.
0 = OpenAL
1 = SDL Mixer
textType
Sets which text backend to use. The desired backend must be compiled in for it to work, otherwise the other backend will be used. Defaults to GLC.
0 = GLC
1 = FTGL
cdromCount
A cache of number of CDROM devices present, not used.
cdromDevice
The number of the CDROM device to use when use_cdrom is enabled. Zero-based. Defaults to first device (0). Only works when compiled with SDL 1.X support.
debug
Enable/disable debug information. This causes the game to print debug information to the terminal. This is disabled by default.
