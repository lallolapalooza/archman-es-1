Documentación de Función/Subrutina

subrutina chesv_rook (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer info)

CHESV_ROOK calcula la solución a un sistema de ecuaciones lineales complejas A * X = B para matrices HE utilizando el método de pivoteo diagonal Bunch-Kaufman acotado ("rook")

Propósito:

!>
!> CHESV_ROOK calcula la solución a un sistema de ecuaciones lineales complejas
!>    A * X = B,
!> donde A es una matriz hermitiana de N por N y X y B son matrices
!> de N por NRHS.
!>
!> Se utiliza el método de pivoteo diagonal Bunch-Kaufman acotado ()
!> para factorizar A como
!>    A = U * D * U**T,  si UPLO = 'U', o
!>    A = L * D * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> superiores (inferiores) unitarias, y D es hermitiana y diagonal por bloques
!> con bloques diagonales de 1 por 1 y 2 por 2.
!>
!> Se llama a CHETRF_ROOK para calcular la factorización de una matriz
!> hermitiana compleja A utilizando el método de pivoteo diagonal
!> Bunch-Kaufman acotado ().
!>
!> La forma factorizada de A se utiliza luego para resolver el sistema
!> de ecuaciones A * X = B llamando a CHETRS_ROOK (usa BLAS 2).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la parte
!>          triangular superior principal de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular inferior
!>          estricta de A no se referencia.  Si UPLO = 'L', la parte
!>          triangular inferior principal de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular superior
!>          estricta de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz diagonal por bloques D y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U*D*U**H o A = L*D*L**H tal como los calcula
!>          CHETRF_ROOK.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura por bloques de D.
!>
!>          Si UPLO = 'U':
!>             Solo se establecen los últimos KB elementos de IPIV.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>
!>             Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>             columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>             columnas k-1 e -IPIV(k-1) fueron intercambiadas,
!>             D(k-1:k,k-1:k) es un bloque diagonal de 2 por 2.
!>
!>          Si UPLO = 'L':
!>             Solo se establecen los primeros KB elementos de IPIV.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>             fueron intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>
!>             Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>             columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>             columnas k+1 e -IPIV(k+1) fueron intercambiadas,
!>             D(k:k+1,k:k+1) es un bloque diagonal de 2 por 2.
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de miembros derechos B de N por NRHS.
!>          En la salida, si INFO = 0, la matriz de solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1, y para el mejor rendimiento
!>          LWORK >= max(1,N*NB), donde NB es el tamaño de bloque óptimo para
!>          CHETRF_ROOK.
!>          para LWORK < N, TRS se hará con BLAS de Nivel 2
!>          para LWORK >= N, TRS se hará con BLAS de Nivel 3
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero.  La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular, por lo que no se pudo calcular la solución.
!>
