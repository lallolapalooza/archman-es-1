CHCPU(8) Administración del Sistema CHCPU(8)

NOMBRE

chcpu - configurar CPUs

SINOPSIS

chcpu -c|-d|-e|-g lista-cpu

chcpu -p modo

chcpu -r|-h|-V

DESCRIPCIÓN

chcpu puede modificar el estado de las CPUs. Puede habilitar o deshabilitar CPUs, buscar nuevas CPUs, cambiar el modo de asignación de CPUs del hipervisor subyacente y solicitar CPUs al hipervisor (configurar) o devolver CPUs al hipervisor (deconfigurar).

Algunas opciones tienen un argumento lista-cpu. Utilice este argumento para especificar una lista de CPUs separadas por comas. La lista puede contener direcciones de CPU individuales o rangos de direcciones. Por ejemplo, 0,5,7,9-11 hace que el comando sea aplicable a las CPUs con las direcciones 0, 5, 7, 9, 10 y 11.

OPCIONES

-c, --configure lista-cpu

Configura las CPUs especificadas. Configurar una CPU significa que el hipervisor toma una CPU del grupo de CPUs y la asigna al hardware virtual en el que se ejecuta su kernel.

-d, --disable lista-cpu

Deshabilita las CPUs especificadas. Deshabilitar una CPU significa que el kernel la pone fuera de línea.

-e, --enable lista-cpu

Habilita las CPUs especificadas. Habilitar una CPU significa que el kernel la pone en línea. Una CPU debe estar configurada, ver -c, antes de poder ser habilitada.

-g, --deconfigure lista-cpu

Deconfigura las CPUs especificadas. Deconfigurar una CPU significa que el hipervisor elimina la CPU del hardware virtual en el que se ejecuta la instancia de Linux y la devuelve al grupo de CPUs. Una CPU debe estar fuera de línea, ver -d, antes de poder ser deconfigurada.

chcpu -g no es compatible con IBM z/VM, las CPUs siempre están en estado configurado.

Si chcpu -g es compatible, las CPUs deshabilitadas deben ser deconfiguradas para informar al hipervisor que estas CPUs no se utilizarán, evitando posibles penalizaciones de rendimiento.

-p, --dispatch modo

Establece el modo de asignación de CPUs (polarización). Esta opción solo tiene efecto si la arquitectura de su hardware y el hipervisor soportan la polarización de CPUs. Los modos disponibles son:

horizontal

La carga de trabajo se distribuye entre todas las CPUs disponibles.

vertical

La carga de trabajo se concentra en pocas CPUs.

-r, --rescan

Inicia un nuevo escaneo de CPUs. Después de un nuevo escaneo, el kernel de Linux reconoce las nuevas CPUs. Utilice esta opción en sistemas que no detectan automáticamente las CPUs adjuntas recientemente.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ESTADO DE SALIDA

chcpu tiene los siguientes valores de estado de salida:

0

éxito

1

fallo

64

éxito parcial
