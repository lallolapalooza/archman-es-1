CHESVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

HE

Propósito

: 
!>
!> CHESVX utiliza la factorización de pivoteo diagonal para calcular la
!> solución a un sistema complejo de ecuaciones lineales A * X = B,
!> donde A es una matriz hermitiana de N por N y X y B son matrices
!> de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una
!> estimación de la condición.
!
>

Descripción

: 
!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A.
!>    La forma de la factorización es
!>       A = U * D * U**H,  si UPLO = 'U', o
!>       A = L * D * L**H,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    superiores (inferiores) unitarias, y D es hermitiana y de bloques
!>    diagonales con bloques diagonales de 1 por 1 y 2 por 2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se
!>    utiliza para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la
!>    máquina, se retorna INFO = N+1 como una advertencia, pero la rutina
!>    continúa para resolver X y calcular los límites de error como se
!>    describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular los límites de error y las estimaciones de
!>    error hacia atrás para ella.
!
>

Parámetro

s
FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          proporcionada en la entrada.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma
!>                  factorizada de A. A, AF e IPIV no serán modificados.
!>          = 'N':  La matriz A será copiada a AF y factorizada.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A. N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          La matriz hermitiana A. Si UPLO = 'U', la parte triangular
!>          superior de A de N por N contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior
!>          de A no es referenciada. Si UPLO = 'L', la parte triangular
!>          inferior de A de N por N contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior
!>          de A no es referenciada.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,N).
!
>

A

F 
!>          AF es un arreglo COMPLEX, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>          entrada contiene la matriz de bloques diagonales D y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U*D*U**H o A = L*D*L**H tal como fue
!>          calculada por CHETRF.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la
!>          salida retorna la matriz de bloques diagonales D y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U*D*U**H o A = L*D*L**H.
!
>

LDA

F 
!>          LDAF es INTEGER
!>          La dimensión principal del arreglo AF. LDAF >= max(1,N).
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la
!>          entrada contiene detalles de los intercambios y la estructura
!>          de bloques de D, tal como fue determinada por CHETRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2 por 2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 e -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2 por 2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la
!>          salida contiene detalles de los intercambios y la estructura
!>          de bloques de D, tal como fue determinada por CHETRF.
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          La matriz de miembros derechos B de N por NRHS.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1,N).
!
>

X 
!>          X es un arreglo COMPLEX, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz de solución X de N por NRHS.
!
>

LD

X 
!>          LDX es INTEGER
!>          La dimensión principal del arreglo X. LDX >= max(1,N).
!
>

RCON

D 
!>          RCOND es REAL
!>          La estimación del recíproco del número de condición de la
!>          matriz A. Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular a la precisión
!>          de trabajo. Esta condición es indicada por un código de retorno
!>          de INFO > 0.
!
>

FER

R 
!>          FERR es un arreglo REAL, dimensión (NRHS)
!>          El límite estimado del error hacia adelante para cada vector
!>          de solución X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento
!>          más grande en X(j). La estimación es tan confiable como la
!>          estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!
>

BER

R 
!>          BERR es un arreglo REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector de solución X(j) (es decir, el cambio relativo más
!>          pequeño en cualquier elemento de A o B que hace que X(j) sea
!>          una solución exacta).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) retorna el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>

Function/Subroutine Documentation


The following is a list of all the arguments for this routine.
    Details for each argument are as follows:


FACT


!>          FACT is CHARACTER*1
!>          = 'E': Computes the equilibrium state and the factorization
!>          = 'N': Computes the factorization
!>          = 'S': Uses the previously computed factorization
!> 


TRANS


!>          TRANS is CHARACTER*1
!>          Specifies the form of the system of equations:
!>          = 'N': Not transpose, A*X = B
!>          = 'C': Conjugate transpose, A**H*X = B
!> 


N


!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!> 


NRHS


!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns of
!>          the matrices B and X. NRHS >= 0.
!> 


A


!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the Hermitian matrix A.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!> 


AF


!>          AF is COMPLEX array, dimension (LDAF,N)
!>          On exit, the factors AF from the factorization
!>          A = P*A*F*U where U is upper triangular.
!> 


LDAF


!>          LDAF is INTEGER
!>          The leading dimension of the array AF. LDAF >= max(1,N).
!> 


IPIV


!>          IPIV is INTEGER array, dimension (N)
!>          Details of the interchanges and the block structure
!>          of the factorization.
!> 


B


!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B.
!> 


LDB


!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).
!> 


X


!>          X is COMPLEX array, dimension (LDX,NRHS)
!>          On exit, the solution matrix X to the system of equations.
!> 


LDX


!>          LDX is INTEGER
!>          The leading dimension of the array X. LDX >= max(1,N).
!> 


RCOND


!>          RCOND is REAL
!>          The reciprocal of the condition number of A.
!>          Computes RCOND by calling ZECON.
!> 


FERR


!>          FERR is REAL array, dimension (NRHS)
!>          The estimated forward error bound for each column of X.
!>          If X is the solution computed by the routine, then the
!>          error is estimated as norm(X - X_true) / norm(X)
!>          where norm(.) is the one norm of the matrix.
!> 


BERR


!>          BERR is REAL array, dimension (NRHS)
!>          The estimated backward error bound for each column of X.
!>          If X is the solution computed by the routine, then the
!>          backward error is estimated as norm(B - A*X) / (norm(A) *
!>          norm(X)).
!> 


WORK


!>          WORK is COMPLEX array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) contains the minimum required
!>          dimension of WORK.
!>          The length of WORK. LWORK >= max(1,2*N), and for best
!>          performance, when FACT = 'N', LWORK >= max(1,2*N,N*NB), where
!>          NB is the optimal blocksize for CHETRF.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


RWORK


!>          RWORK is REAL array, dimension (N)
!> 


INFO


!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0: if INFO = i, and i is
!>                <= N:  D(i,i) is exactly zero.  The factorization
!>                       has been completed but the factor D is exactly
!>                       singular, so the solution and error bounds could
!>                       not be computed. RCOND = 0 is returned.
!>                = N+1: D is nonsingular, but RCOND is less than machine
!>                       precision, meaning that the matrix is singular
!>                       to working precision.  Nevertheless, the
!>                       solution and error bounds are computed because
!>                       there are a number of situations where the
!>                       computed solution can be more accurate than the
!>                       value of RCOND would suggest.
!>
