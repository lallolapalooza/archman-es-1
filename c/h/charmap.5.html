charmap(5) Manual de formatos de archivo charmap(5)

NOMBRE

charmap - archivo de descripción de conjunto de caracteres

DESCRIPCIÓN

Una descripción de conjunto de caracteres (charmap) define todos los caracteres disponibles y sus codificaciones en un conjunto de caracteres. localedef(1) puede utilizar charmaps para crear variantes de localización para diferentes conjuntos de caracteres.

Sintaxis

El archivo charmap comienza con una cabecera que puede consistir en las siguientes palabras clave:

<nombre_del_conjunto_de_códigos>
va seguido del nombre del mapa de caracteres.
<carácter_de_comentario>
va seguido de un carácter que se utilizará como carácter de comentario para el resto del archivo. Por defecto es el signo de almohadilla (#).
<carácter_de_escape>
va seguido de un carácter que debe usarse como carácter de escape para el resto del archivo para marcar caracteres que deben interpretarse de manera especial. Por defecto es la barra invertida (\).
<mb_cur_max>
va seguido del número máximo de bytes para un carácter. El valor por defecto es 1.
<mb_cur_min>
va seguido del número mínimo de bytes para un carácter. Este valor debe ser menor o igual que <mb_cur_max>. Si no se especifica, por defecto es <mb_cur_max>.

La sección de definición del conjunto de caracteres comienza con la palabra clave CHARMAP en la primera columna.

Las siguientes líneas pueden tener una de las dos siguientes formas para definir el conjunto de caracteres:

<carácter> secuencia-de-bytes comentario
Esta forma define exactamente un carácter y su secuencia de bytes, siendo comentario opcional.
<carácter>..<carácter> secuencia-de-bytes comentario
Esta forma define un rango de caracteres y su secuencia de bytes, siendo comentario opcional.

La sección de definición del conjunto de caracteres termina con la cadena END CHARMAP.

La sección de definición del conjunto de caracteres puede ir seguida opcionalmente por una sección para definir los anchos de los caracteres.

La palabra clave WIDTH_DEFAULT se puede utilizar para definir el ancho por defecto para todos los caracteres no listados explícitamente. El ancho de carácter por defecto es 1.

La sección de anchos para caracteres individuales comienza con la palabra clave WIDTH en la primera columna.

Las siguientes líneas pueden tener una de las dos siguientes formas para definir los anchos de los caracteres:

<carácter> ancho
Esta forma define el ancho de exactamente un carácter.
<carácter>...<carácter> ancho
Esta forma define el ancho para todos los caracteres del rango.

La sección de definición de anchos termina con la cadena END WIDTH.

ARCHIVOS

/usr/share/i18n/charmaps
Ruta habitual por defecto de los mapas de caracteres.

ESTÁNDARES

POSIX.2.

EJEMPLOS

El signo del euro se define de la siguiente manera en el charmap UTF-8:

<U20AC>     /xe2/x82/xac EURO SIGN

VER TAMBIÉN

iconv(1), locale(1), localedef(1), locale(5), charsets(7)
