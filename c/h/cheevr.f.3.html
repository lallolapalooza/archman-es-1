CHEEVR calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices

HE

Propósito

: 
!>
!> CHEEVR calcula los eigenvalores seleccionados y, opcionalmente, los eigenvectores
!> de una matriz hermítica compleja A. Los eigenvalores y eigenvectores pueden ser
!> seleccionados especificando ya sea un rango de valores o un rango de índices
!> para los eigenvalores deseados. Las invocaciones con diferentes opciones para
!> estos parámetros pueden resultar en el cálculo de eigenvalores y/o eigenvectores
!> ligeramente diferentes para la misma matriz. La razón de
!> este comportamiento es que existe una variedad de algoritmos (cada uno
!> rinde mejor para un conjunto particular de opciones) con CHEEVR
!> intentando seleccionar el mejor basado en los diversos parámetros. En todos
!> los casos, los valores calculados son precisos dentro de los límites de la aritmética
!> de precisión finita.
!>
!> CHEEVR primero reduce la matriz A a forma tridiagonal T con una llamada
!> a CHETRD. Luego, siempre que sea posible, CHEEVR llama a CSTEMR para calcular
!> el espectro propio usando Representaciones Robustas Relativas. CSTEMR
!> calcula los eigenvalores mediante el algoritmo dqds, mientras que los
!> eigenvectores ortogonales se calculan a partir de varias representaciones L D L^T
!> (también conocidas como Representaciones Robustas Relativas). La ortogonalización
!> de Gram-Schmidt se evita en la medida de lo posible. Más específicamente,
!> los diversos pasos del algoritmo son los siguientes.
!>
!> Para cada bloque (submatriz) no reducido de T,
!>    (a) Calcular T - sigma I = L D L^T, de modo que L y D
!>        definan todos los eigenvalores deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los eigenvalores y
!>        eigenvectores. La representación estándar (sin factorizar) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los eigenvalores con la precisión adecuada.
!>        Si se desean los eigenvectores, el algoritmo alcanza la precisión
!>        completa de los eigenvalores calculados solo justo antes de
!>        que se deban calcular los vectores correspondientes, ver los pasos c) y d).
!>    (c) Para cada grupo de eigenvalores cercanos, seleccionar un nuevo
!>        desplazamiento (shift) cercano al grupo, encontrar una nueva factorización y refinar
!>        los eigenvalores desplazados a la precisión adecuada.
!>    (d) Para cada eigenvalor con una separación relativa suficientemente grande, calcular
!>        el eigenvector correspondiente formando una factorización retorcida que revela el rango.
!>        Volver a (c) para cualquier grupo que permanezca.
!>
!> La precisión deseada de la salida puede ser especificada por el parámetro
!> de entrada ABSTOL.
!>
!> Para más detalles, ver la documentación de CSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, Agosto 2004.
!> - Inderjit Dhillon y Beresford Parlett: SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, Mayo 1997.
!>
!>
!> Nota 1: CHEEVR llama a CSTEMR cuando se solicita el espectro completo
!> en máquinas que se ajustan al estándar de punto flotante ieee-754.
!> CHEEVR llama a SSTEBZ y CSTEIN en máquinas no-ieee y
!> cuando se hacen solicitudes de espectro parcial.
!>
!> La ejecución normal de CSTEMR puede crear NaNs e infinitos y
!> por lo tanto puede abortarse debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos de la manera predeterminada del estándar ieee.
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo eigenvalores;
!>          = 'V':  Calcular eigenvalores y eigenvectores.
!>
!>          Este parámetro influye en la elección del algoritmo y
!>          puede alterar los valores calculados.
!
>

RANG

E 
!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los eigenvalores.
!>          = 'V': se encontrarán todos los eigenvalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los eigenvalores desde el IL-ésimo hasta el IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman a SSTEBZ y
!>          CSTEIN
!>
!>          Este parámetro influye en la elección del algoritmo y
!>          puede alterar los valores calculados.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA, N)
!>          En la entrada, la matriz hermítica A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N inicial de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N-por-N inicial de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

V

L 
!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo en el
!>          que se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

V

U 
!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo en el
!>          que se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

I

L 
!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más pequeño a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

I

U 
!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más grande a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

ABSTO

L 
!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los eigenvalores.
!>          Un eigenvalor aproximado es aceptado como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>      al reducir A a tridiagonal

NAME


cheevr.f - Computes selected eigenvalues and eigenvectors of a
  complex Hermitian eigenvalue problem.






SYNOPSIS


 SUBROUTINE CHEEVR(
     JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL, M, W, Z, LDZ,
     ISUPPZ, WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK, INFO
    )
 IMPLICIT NONE
 CHARACTER          JOBZ, RANGE, UPLO
 INTEGER            IL, INFO, IU, LDA, LDZ, LIWORK, LWORK, LRWORK, M, N
 REAL               ABSTOL, VL, VU
 COMPLEX*16         A( LDA, * ), Z( LDZ, * )
 REAL               W( * )
 REAL               RWORK( * )
 INTEGER            ISUPPZ( * ), IWORK( * )
 COMPLEX*16         WORK( * )






Function/Subroutine
  Documentation


This routine computes the eigenvalues and eigenvectors of a
  complex Hermitian matrix A. It is an LAPACK routine designed to
  provide a robust and efficient solution for this problem.


The routine supports several options for selecting which
  eigenvalues and eigenvectors to compute:




JOBZ


CHARACTER*1.


          = 'N':  Compute only the eigenvalues of A.
          = 'V':  Compute the eigenvalues and eigenvectors of A.


Required argument.


RANGE


CHARACTER*1.


          = 'A': all eigenvalues will be found.
          = 'V': all eigenvalues in the half-open interval (VL, VU]
                 will be found; FLOPs are not relevant by default.
          = 'I': the IL-th through IU-th eigenvalues will be found.


Required argument.


UPLO


CHARACTER*1.


          = 'U':  Upper triangle of A is stored and referenced.
          = 'L':  Lower triangle of A is stored and referenced.


Required argument.


N


INTEGER.


          The order of the matrix A.  N >= 0.


Required argument.


A


COMPLEX*16 array, dimension (LDA, N).


          On entry, the Hermitian matrix A.
          On exit, the principal submatrix of A has been updated.


Required argument.


LDA


INTEGER.


          The leading dimension of the array A.  LDA >= max(1, N).


Required argument.


VL


REAL.


          If RANGE='V', the lower bound of the interval for the
          eigenvalues.


Required argument.


VU


REAL.


          If RANGE='V', the upper bound of the interval for the
          eigenvalues.


Required argument.


IL


INTEGER.


          If RANGE='I', the index of the smallest eigenvalue to be
          returned.


Required argument.


IU


INTEGER.


          If RANGE='I', the index of the largest eigenvalue to be
          returned.


Required argument.


ABSTOL


REAL.


          The tolerance for the eigenvalue calculations.  If ABSTOL is
          negative, the default value is set to SLAMCH('E')*|A|.
          For high relative accuracy, use ABSTOL = SLAMCH('Safe minimum').
          See Further Details.
          


Required argument.


Further Details


          The algorithm satisfies the following error bounds for the
          components of the eigenvectors in the difference
          Z * diag(W) * Z**H - A:
             || U * S * U**H - A || = EPS * || A ||,
          where U is the matrix of eigenvectors, S is the diagonal matrix
          of eigenvalues, and EPS is the relative machine precision.

          The accuracy of the eigenvalues is generally very good, but if
          high relative accuracy is important, set ABSTOL to
          SLAMCH('Safe minimum').  Doing so will guarantee that
          eigenvalues are computed to high relative accuracy when
          possible in future releases.  The current code does not
          make any guarantees about high relative accuracy, but
          future releases will. See J. Barlow and J. Demmel,
          , LAPACK Working Note #7, for a discussion
          of which matrices define their eigenvalues to high relative
          accuracy.
          




M


INTEGER.


          The total number of eigenvalues found.  0 <= M <= N.
          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.


Output argument.


W


REAL array, dimension (N).


          The first M elements contain the selected eigenvalues in
          ascending order.


Output argument.


Z


COMPLEX array, dimension (LDZ, max(1,M)).


          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
          contain the orthonormal eigenvectors of the matrix A
          corresponding to the selected eigenvalues, with the i-th
          column of Z holding the eigenvector associated with W(i).
          If JOBZ = 'N', then Z is not referenced.
          Note: the user must ensure that at least max(1,M) columns are
          supplied in the array Z; if RANGE = 'V', the exact value of M
          is not known in advance and an upper bound must be used.
          Supplying N columns is always safe.
          


Output argument.


LDZ


INTEGER.


          The leading dimension of the array Z.  LDZ >= 1, and if
          JOBZ = 'V', LDZ >= max(1,N).


Required argument.


ISUPPZ


INTEGER array, dimension ( 2*max(1,M) ).


          The support of the eigenvectors in Z, i.e., the indices
          indicating the nonzero elements in Z. The i-th eigenvector
          is nonzero only in elements ISUPPZ( 2*i-1 ) through
          ISUPPZ( 2*i ). This is an output of CSTEMR (tridiagonal
          matrix). The support of the eigenvectors of A is typically
          1:N because of the unitary transformations applied by CUNMTR
          Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
          


Output argument.


WORK


COMPLEX array, dimension (MAX(1,LWORK)).


          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.


Workspace array. Required argument.


LWORK


INTEGER.


          The length of the array WORK.
          If N <= 1, LWORK >= 1, else LWORK >= 2*N.
          For optimal efficiency, LWORK >= (NB+1)*N,
          where NB is the max of the blocksize for CHETRD and for
          CUNMTR as returned by ILAENV.
          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the optimal sizes of the WORK, RWORK and
          IWORK arrays, returns these values as the first entries of
          the WORK, RWORK and IWORK arrays, and no error message
          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
          


Required argument.


RWORK


REAL array, dimension (MAX(1,LRWORK)).


          On exit, if INFO = 0, RWORK(1) returns the optimal
          (and minimal) LRWORK.


Workspace array. Required argument.


LRWORK


INTEGER.


          The length of the array RWORK.
          If N <= 1, LRWORK >= 1, else LRWORK >= 24*N.
          If LRWORK = -1, then a workspace query is assumed; the
          routine only calculates the optimal sizes of the WORK, RWORK
          and IWORK arrays, returns these values as the first entries
          of the WORK, RWORK and IWORK arrays, and no error message
          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
          


Required argument.


IWORK


INTEGER array, dimension (MAX(1,LIWORK)).


          On exit, if INFO = 0, IWORK(1) returns the optimal
          (and minimal) LIWORK.


Workspace array. Required argument.


LIWORK


INTEGER.


          The dimension of the array IWORK.
          If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.
          If LIWORK = -1, then a workspace query is assumed; the
          routine only calculates the optimal sizes of the WORK, RWORK
          and IWORK arrays, returns these values as the first entries
          of the WORK, RWORK and IWORK arrays, and no error message
          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
          


Required argument.


INFO


INTEGER.


          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  Internal error


Output argument.
