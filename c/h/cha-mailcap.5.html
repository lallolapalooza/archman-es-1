Mailca

p

Por defecto, los búferes de Chawan solo manejan HTML y texto plano. El archivo mailcap se puede usar para ver otros formatos de archivo usando comandos externos, o para convertirlos a HTML/texto plano antes de mostrarlos en

Chawan.

Tenga en cuenta que el archivo mime.types predeterminado de Chawan solo reconoce algunas extensiones de archivo, lo que puede resultar en que sus entradas no se ejecuten si su sistema carece de un archivo /etc/mime.types. Por favor, consulte la documentación de cha-mime.types(5) para más

detalles.

Para una descripción exacta del formato mailcap, consulte RFC 1

524.

búsqueda

RFC:

Por defecto, las entradas de mailcap solo se ejecutan si el usuario escribe r (run/ejecutar) después del prompt. Otras opciones son ver el archivo con t (text/texto), o guardar el archivo con s

.

Si se escribe una letra mayúscula (por ejemplo, presione shift y escriba R), se agrega una entrada correspondiente a external.auto-mailcap (por defecto: ~/.chawan/auto.mailcap, o ~/.config/chawan/auto.mailcap con XDG basedirs). (T)ext (texto) y (S)ave (guardar) también se pueden usar para agregar entradas correspondientes a las otras opciones de

visualización.

Las entradas en auto-mailcap se ejecutan automáticamente, por lo q

ue se recomienda agregar sus entradas específicas de Chawan all
í (o simplemente establecerlo en su archivo mailcap personal).

Plantilla

s

%s, %t, y los campos de tipo de contenido con nombre como %{charset} funcionan como se describe en el

estándar.

Si no se aplica ninguna comilla, Chawan cita las plantillas automáticamente. (Esto también funciona con $(sustituciones de comando).) Sin embargo, otro software puede comportarse mal con tales plantillas, por lo que puede ser mejor asignarlas a una variable

primero.

Se puede especificar la plantilla no estándar %u para obtener la URL original del recurso. Esta es una extensión de Netscape que puede no ser compatible con otras implementaciones. Como alternativa, la variable de entorno $MAILCAP_URL s

e establece en el
mismo valor.
