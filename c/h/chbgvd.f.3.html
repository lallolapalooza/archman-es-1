subrutina chbgvd (carácter jobz, carácter uplo, entero n, entero ka, entero kb, complejo, dimensión( ldab, * ) ab, entero ldab, complejo, dimensión( ldbb, * ) bb, entero ldbb, real, dimensión( * ) w, complejo, dimensión( ldz, * ) z, entero ldz, complejo, dimensión( * ) work, entero lwork, real, dimensión( * ) rwork, entero lrwork, entero, dimensión( * ) iwork, entero liwork, entero info)

CHBGVD

Propósito:

!>
!> CHBGVD calcula todos los valores propios y, opcionalmente, los vectores propios
!> de un problema de valores propios generalizado hermítico-definido de banda complejo,
!> de la forma A*x=(lambda)*B*x. Aquí A y B se asumen hermíticos
!> y de banda, y B es también positivo definido. Si se desean vectores propios,
!> utiliza un algoritmo de división y conquista.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo calcula los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

KA

!>          KA es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'. KA >= 0.
!>

KB

!>          KB es INTEGER
!>          El número de superdiagonales de la matriz B si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'. KB >= 0.
!>

AB

!>          AB es array COMPLEX, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          hermítica de banda A, almacenado en las primeras ka+1 filas
!>          del array. La columna j de A se almacena en la columna j
!>          del array AB como sigue:
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) para max(1,j-ka)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+ka).
!>
!>          En la salida, el contenido de AB se destruye.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KA+1.
!>

BB

!>          BB es array COMPLEX, dimensión (LDBB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          hermítica de banda B, almacenado en las primeras kb+1 filas
!>          del array. La columna j de B se almacena en la columna j
!>          del array BB como sigue:
!>          si UPLO = 'U', BB(kb+1+i-j,j) = B(i,j) para max(1,j-kb)<=i<=j;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) para j<=i<=min(n,j+kb).
!>
!>          En la salida, el factor S de la factorización de Cholesky dividida
!>          B = S**H*S, tal como devuelve CPBSTF.
!>

LDBB

!>          LDBB es INTEGER
!>          La dimensión principal del array BB.  LDBB >= KB+1.
!>

W

!>          W es array REAL, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es array COMPLEX, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          vectores propios, con la columna i de Z conteniendo el
!>          vector propio asociado a W(i). Los vectores propios están
!>          normalizados de tal manera que Z**H*B*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= N.
!>

WORK

!>          WORK es array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO=0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LWORK >= N.
!>          Si JOBZ = 'V' y N > 1, LWORK >= 2*N**2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          subrutina solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de
!>          error relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es array REAL, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO=0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si N <= 1,               LRWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LRWORK >= N.
!>          Si JOBZ = 'V' y N > 1, LRWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          subrutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          y IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de
!>          error relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO=0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ = 'N' o N <= 1, LIWORK >= 1.
!>          Si JOBZ = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          subrutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          y IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de
!>          error relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es:
!>             <= N:  el algoritmo no convergió:
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces CPBSTF
!>                    devolvió INFO = i: B no es positivo definido.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon valores propios ni vectores propios.
!>
