NAME

chmem - configurar memoria

SYNOPSIS

chmem [-h] [-V*] [-v] [-e|-d] [SIZE|RANGE -b BLOCKRANGE] [-z ZONE]

DESCRIPTION

El comando chmem establece un tamaño específico o un rango de memoria en línea o fuera de línea.

•Especificar SIZE como <size>[m|M|g|G]. Con m o M, <size> especifica el tamaño de la memoria en MiB (1024 x 1024 bytes). Con g o G, <size> especifica el tamaño de la memoria en GiB (1024 x 1024 x 1024 bytes). La unidad por defecto es MiB.
•Especificar RANGE en la forma 0x<start>-0x<end> tal como se muestra en la salida del comando lsmem(1). <start> es la dirección hexadecimal de la primera byte y <end> es la dirección hexadecimal de la última byte en el rango de memoria.
•Especificar BLOCKRANGE en la forma <first>-<last> o <block> tal como se muestra en la salida del comando lsmem(1). <first> es el número del primer bloque de memoria y <last> es el número del último bloque de memoria en el rango de memoria. Alternativamente, se puede especificar un solo bloque. BLOCKRANGE requiere la opción --blocks.
•Especificar ZONE como el nombre de una zona de memoria, tal como se muestra en la salida del comando lsmem -o +ZONES. La salida muestra una o más zonas de memoria válidas para cada rango de memoria. Si se muestran varias zonas, entonces el rango de memoria pertenece actualmente a la primera zona. Por defecto, chmem establecerá la memoria en línea en la zona Movable, si esta está entre las zonas válidas. Este defecto puede cambiarse especificando la opción --zone con otra zona válida. Para el balanceo de memoria, se recomienda seleccionar la zona Movable para la memoria en línea y fuera de línea, si es posible. La memoria en esta zona es mucho más probable que pueda volver a ser puesta fuera de línea, pero no puede usarse para asignaciones arbitrarias del kernel, solo para páginas migrables (por ejemplo, páginas anónimas y páginas de caché de páginas). Utilice la opción --help para ver todas las zonas disponibles.

SIZE y RANGE deben estar alineados al tamaño de bloque de memoria de Linux, tal como se muestra en la salida del comando lsmem(1).

Poner memoria en línea puede fallar por varias razones. En sistemas virtualizados puede fallar si el hipervisor no tiene suficiente memoria restante, por ejemplo porque la memoria fue sobrecomprometida. Poner memoria fuera de línea puede fallar si Linux no puede liberar la memoria. Si solo parte de la memoria solicitada se puede establecer en línea o fuera de línea, un mensaje le indicará cuánta memoria se estableció en línea o fuera de línea en lugar de la cantidad solicitada.

Al establecer memoria en línea chmem comienza con los números de bloque de memoria más bajos. Al establecer memoria fuera de línea chmem comienza con los números de bloque de memoria más altos.

OPTIONS

-b, --blocks

Use un parámetro BLOCKRANGE en lugar de RANGE o SIZE para las opciones --enable y --disable.

-d, --disable

Establecer la memoria especificada RANGE, SIZE o BLOCKRANGE fuera de línea.

-e, --enable

Establecer la memoria especificada RANGE, SIZE o BLOCKRANGE en línea.

-z, --zone

Seleccionar la memoria ZONE donde establecer la memoria especificada RANGE, SIZE o BLOCKRANGE en línea o fuera de línea. Por defecto, la memoria se establecerá en línea en la zona Movable, si es posible.

-v, --verbose

Modo detallado. Hace que chmem imprima mensajes de depuración sobre su progreso.

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar versión y salir.

EXIT STATUS

chmem tiene los siguientes valores de estado de salida:

0

éxito

1

falla

64

éxito parcial

EXAMPLE

chmem --enable 1024

Este comando solicita 1024 MiB de memoria para establecerse en línea.

chmem -e 2g

Este comando solicita 2 GiB de memoria para establecerse en línea.

chmem --disable 0x00000000e4000000-0x00000000f3ffffff

Este comando solicita que el rango de memoria que comienza con 0x00000000e4000000 y termina con 0x00000000f3ffffff se establezca fuera de línea.

chmem -b -d 10

Este comando solicita que el número de bloque de memoria 10 se establezca fuera de línea.
