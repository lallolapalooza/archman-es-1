Documentación de la Función/Subrutina

subroutine chbmv (character uplo, integer n, integer k, complex alpha, complex, dimension(lda,*) a, integer lda, complex, dimension(*) x, integer incx, complex beta, complex, dimension(*) y, integer incy)

CHBMV

Propósito:

!>
!> CHBMV  realiza la operación de matriz-vector
!>
!>    y := alpha*A*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores de n elementos y
!> A es una matriz de banda hermítica de n por n, con k super-diagonales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si se está suministrando la
!>           parte triangular superior o inferior de la matriz de banda A
!>           de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   Se está suministrando la parte triangular superior de A.
!>
!>              UPLO = 'L' o 'l'   Se está suministrando la parte triangular inferior de A.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser mayor o igual a cero.
!>

K

!>          K es INTEGER
!>           En la entrada, K especifica el número de super-diagonales de
!>           la matriz A. K debe satisfacer 0 .le. K.
!>

ALPHA

!>          ALPHA es COMPLEX
!>           En la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX, de dimensión ( LDA, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte principal
!>           ( k + 1 ) por n del array A debe contener la parte de banda
!>           triangular superior de la matriz hermítica, suministrada
!>           columna por columna, con la diagonal principal de la matriz en
!>           la fila ( k + 1 ) del array, la primera super-diagonal comenzando
!>           en la posición 2 de la fila k, y así sucesivamente. El triángulo
!>           superior izquierdo de k por k del array A no se referencia.
!>           El siguiente segmento de programa transferirá la parte triangular
!>           superior de una matriz hermítica de banda desde el almacenamiento
!>           convencional de matriz completa a almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = K + 1 - J
!>                    DO 10, I = MAX( 1, J - K ), J
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte principal
!>           ( k + 1 ) por n del array A debe contener la parte de banda
!>           triangular inferior de la matriz hermítica, suministrada
!>           columna por columna, con la diagonal principal de la matriz en
!>           la fila 1 del array, la primera sub-diagonal comenzando en la
!>           posición 1 de la fila 2, y así sucesivamente. El triángulo inferior
!>           derecho de k por k del array A no se referencia.
!>           El siguiente segmento de programa transferirá la parte triangular
!>           inferior de una matriz hermítica de banda desde el almacenamiento
!>           convencional de matriz completa a almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = 1 - J
!>                    DO 10, I = J, MIN( N, J + K )
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Tenga en cuenta que las partes imaginarias de los elementos
!>           diagonales no necesitan ser establecidas y se asumen que son cero.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal
!>           como se declara en el programa (sub)llamador. LDA debe ser
!>           al menos ( k + 1 ).
!>

X

!>          X es un array COMPLEX, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array incrementado X debe contener
!>           el vector x.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
!>

BETA

!>          BETA es COMPLEX
!>           En la entrada, BETA especifica el escalar beta.
!>

Y

!>          Y es un array COMPLEX, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array incrementado Y debe contener
!>           el vector y. A la salida, Y se sobrescribe con el vector y
!>           actualizado.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos
!>           de Y. INCY no debe ser cero.
!>
