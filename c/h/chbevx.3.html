CHBEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para otras matrices

Documentación de Función/Subrutina

subrutina chbevx (character jobz, character range, character uplo, integer n, integer kd, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( ldq, * ) q, integer ldq, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

CHBEVX calcula los valores propios seleccionados y, opcionalmente, los vectores propios de una matriz de banda hermitiana compleja A. Los valores propios y los vectores propios pueden seleccionarse especificando un rango de valores o un rango de índices para los valores propios deseados.

Propósito:

!>
!> CHBEVX calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz de banda hermitiana compleja A. Los valores propios y los vectores propios
!> pueden seleccionarse especificando un rango de valores o un rango de índices para los
!> valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular sólo los valores propios;
!>          = 'V':  Calcular los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 ;
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  se almacena el triángulo superior de A;
!>          = 'L':  se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB es array COMPLEX, dimension (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda hermitiana
!>          A, almacenado en las primeras KD+1 filas del array. La
!>          j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con los valores generados durante la
!>          reducción a forma tridiagonal.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB. LDAB >= KD + 1.
!>

Q

!>          Q es array COMPLEX, dimension (LDQ, N)
!>          Si JOBZ = 'V', la matriz unitaria N por N utilizada en la
!>                          reducción a forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*SLAMCH('S'), no en cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*SLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de trabajo de LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array REAL, dimension (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es array COMPLEX, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array COMPLEX, dimension (N)
!>

RWORK

!>          RWORK es array REAL, dimension (7*N)
!>

IWORK

!>          IWORK es array INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL es array INTEGER, dimension (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, entonces i vectores propios fallaron en converger.
!>                Sus índices se almacenan
