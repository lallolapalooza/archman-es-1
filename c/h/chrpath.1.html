CHRPATH(1) cambia rpath/runpath en binarios CHRPATH(1)

NOMBRE

chrpath - cambia el rpath o runpath en binarios

SINOPSIS

chrpath [ -v | --version ] [ -d | --delete ] [ -r <ruta> | --replace <ruta> ] [ -c | --convert ] [ -l | --list ] [ -h | --help ] <programa> [ <programa> ... ]

DESCRIPCIÓN

chrpath cambia, lista o elimina la configuración rpath o runpath en un binario. El rpath, o runpath si está presente, es donde el enlazador en tiempo de ejecución debe buscar las bibliotecas necesarias para un programa.

OPCIONES

-v | --version
Muestra el número de versión del programa
-d | --delete
Elimina la configuración actual de rpath o runpath
-c | --convert
Convierte la configuración de rpath en una configuración de runpath
-r <ruta> | --replace <ruta>
Reemplaza la configuración actual de rpath o runpath con la ruta dada. La nueva ruta debe ser más corta o de la misma longitud que la ruta actual.
-k | --keepgoing
No fallar en el primer error, sino procesar todos los argumentos antes de devolver el error.
-l | --list
Lista el rpath o runpath actual (por defecto)
-h | --help
Muestra información de uso.

ESTADO DE SALIDA

0
Si todas las operaciones fueron exitosas
>0
Si alguna de las operaciones falló. Una operación fallida termina el programa a menos que se especifique -k.

ERRORES CONOCIDOS

Este programa no puede crear una etiqueta RPATH si el ELF no la tiene, y solo puede reemplazar un RPATH por uno de longitud igual o menor. (Mover secciones ELF después de una tabla de cadenas alargada sería difícil y propenso a errores, y a veces imposible debido a problemas como rangos limitados en instrucciones de salto.)
