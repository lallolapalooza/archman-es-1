NOMBRE

chkweb - ejecuta las partes de LaTeX de un archivo CWEB a través de chktex

SINOPSIS

chkweb [-hiqrW] [-l <archivo_rc>] [-[wemn] <[1-42]|all>] [-d[0-...]] [-o <archivo_salida>] [-[btxgI][0|1]] archivo1 archivo2 ...

DESCRIPCIÓN

chkweb ejecuta las partes de LaTeX de un archivo CWEB a través de chktex.

OPCIONES

Opciones misceláneas:

-h --help
Muestra una pantalla de ayuda.
-i --license
Muestra información de distribución.
-l --localrc
Lee un archivo local con formato .chktexrc.
-d --debug
Información de depuración. Dale un número.
-r --reset
Restablece la configuración a los valores predeterminados.

Silenciar mensajes de advertencia:

-w --warnon
Convierte el mensaje # dado en una advertencia y la activa.
-e --erroron
Convierte el mensaje # dado en un error y lo activa.
-m --msgon
Convierte el mensaje # dado en un mensaje y lo activa.
-n --nowarn
Silencia el mensaje # dado.

Indicadores de control de salida:

-V --pipeverb
Cómo se muestran los errores cuando stdout != tty. Por defecto es lo mismo que -v.
-s --splitchar
Cadena utilizada para dividir campos cuando se usa -v0
-o --output
Redirige el informe de errores a un archivo.
-q --quiet
Silencia la información de la versión.
-f --format
Formato a utilizar para la salida.

Interruptores booleanos (1 -> habilita / 0 -> deshabilita):

-b --backup
Copia de seguridad del archivo de salida.
-x --wipeverb
Ignora el contenido de los comandos `\verb'.
-g --globalrc
Lee el archivo global .chktexrc.
-I --inputfiles
Ejecuta las sentencias \input.
-H --headererr
Muestra los errores encontrados antes de \begin{document}
-W --version
Información de la versión.

Si no se especifican archivos LaTeX en la línea de comandos, se leerá desde la entrada estándar (stdin). Para obtener una explicación de los mensajes de advertencia/error, consulte el documento principal /usr/share/doc/chktex/ChkTeX.dvi.gz.
