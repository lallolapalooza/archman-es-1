CHKLREF(1) Comandos de usuario CHKLREF(1)

NOMBRE

chklref - página del manual para chklref 3.1.2

SINOPSIS

chklref [opciones] archivo_tex

DESCRIPCIÓN

Comprueba etiquetas y referencias bibliográficas no utilizadas en un archivo LaTeX

OPCIONES

--tex <compilador>, -t
Especifica el compilador TeX a utilizar. El valor predeterminado es `pdflatex`.
--tex-options
Lista de opciones a pasar al compilador TeX. Debe ser una cadena entrecomillada de opciones separadas por espacios en blanco. Tenga en cuenta que siempre añadimos `-interaction nonstopmode` además de estas opciones.
--debug, -d
Ejecutar en modo de depuración. No limpiar el archivo `.chk` generado.
--quiet, -q
Ejecutar en modo silencioso. No imprimir la salida del compilador TeX.
--parse-only
No ejecutar el compilador LaTeX, sino utilizar el archivo `.chk` ya existente. Cuando se pasa esta opción, las siguientes opciones carecen de sentido: `--tex`, `--tex-options`, `--quiet`, `--debug`.
--version, -v
Imprimir la versión de este script.
--help,h
Imprimir esta ayuda.

REPORTAR ERRORES

Reportar errores en https://github.com/jlelong/chklref. `chklref` es conocido por no funcionar con `cleveref`. Si desea contribuir a `chklref`, no dude en abrir una solicitud de extracción (PR) en https://github.com/jlelong/chklref.

info chklref

debería darle acceso al manual completo.
