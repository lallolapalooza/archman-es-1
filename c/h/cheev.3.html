CHEEV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HE

Documentación de Función/Subrutina

subroutine cheev (character jobz, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) w, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CHEEV calcula todos los valores propios y, opcionalmente, los vectores propios de una matriz Hermítica compleja A.

Propósito:

!>
!> CHEEV calcula todos los valores propios y, opcionalmente, los vectores
!> propios de una matriz Hermítica compleja A.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEXO, dimensión (LDA, N)
!>          A la entrada, la matriz Hermítica A.  Si UPLO = 'U', la
!>          parte superior triangular de N por N de A contiene la
!>          parte superior triangular de la matriz A.  Si UPLO = 'L',
!>          la parte inferior triangular de N por N de A contiene la
!>          parte inferior triangular de la matriz A.
!>          A la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene los
!>          vectores propios ortonormales de la matriz A.
!>          Si JOBZ = 'N', entonces a la salida el triángulo inferior (si UPLO='L')
!>          o el triángulo superior (si UPLO='U') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

W

!>          W es array REAL, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es array COMPLEXO, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= max(1,2*N-1).
!>          Para una eficiencia óptima, LWORK >= (NB+1)*N,
!>          donde NB es el tamaño del bloque para CHETRD devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          ningún mensaje de error relacionado con LWORK es emitido por XERBLA.
!>

RWORK

!>          RWORK es array REAL, dimensión (max(1, 3*N-2))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el algoritmo falló en converger; i
!>                elementos fuera de la diagonal de una forma tridiagonal
!>                intermedia no convergieron a cero.
!>
