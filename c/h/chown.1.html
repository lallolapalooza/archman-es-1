DESCRIPCIÓN

Esta

página de manual documenta la versión GNU de chown. chown cambia el propietario y/o el grupo de cada archivo dado. Si solo se proporciona un propietario (un nombre de usuario o un ID de usuario numérico), ese usuario se convierte en el propietario de cada archivo dado, y el grupo de los archivos no se cambia. Si el propietario va seguido de dos puntos y un nombre de grupo (o un ID de grupo numérico), sin espacios entre ellos, el grupo de los archivos también se cambia. Si los dos puntos pero no el nombre de grupo siguen al nombre de usuario, ese usuario se convierte en el propietario de los archivos y el grupo de los archivos se cambia al grupo de inicio de ese usuario. Si se proporcionan los dos puntos y el grupo, pero se omite el propietario, solo se cambia el grupo de los archivos; en este caso, chown realiza
