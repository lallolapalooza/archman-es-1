Propósito

: 
!>
!> CHEGVX calcula los autovalores seleccionados y, opcionalmente, los autovectores
!> de un problema de autovalores generalizado hermitiano-definitivo, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.  Aquí se asume que A y
!> B son hermitianas y que B es también positiva definida.
!> Los autovalores y autovectores pueden seleccionarse especificando un
!> rango de valores o un rango de índices para los autovalores deseados.
!
>

Parámetro

s
ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!
>

JOB

Z 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo autovalores;
!>          = 'V':  Calcula autovalores y autovectores.
!
>

RANG

E 
!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta el IU-ésimo.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA, N)
!>          Al entrar, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior de A de tamaño N por N inicial contiene
!>          la parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior de A de tamaño N por N inicial contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          Al salir, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB, N)
!>          Al entrar, la matriz hermitiana B.  Si UPLO = 'U', la
!>          parte triangular superior de B de tamaño N por N inicial contiene
!>          la parte triangular superior de la matriz B.  Si UPLO = 'L',
!>          la parte triangular inferior de B de tamaño N por N inicial contiene
!>          la parte triangular inferior de la matriz B.
!>
!>          Al salir, si INFO <= N, la parte de B que contiene la matriz es
!>          sobrescrita por el factor triangular U o L de la factorización
!>          de Cholesky B = U**H*U o B = L*L**H.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!
>

V

L 
!>          VL es REAL
!>
!>          Si RANGE='V', el límite inferior del intervalo en el que
!>          se buscarán los autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

V

U 
!>          VU es REAL
!>
!>          Si RANGE='V', el límite superior del intervalo en el que
!>          se buscarán los autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

I

L 
!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

I

U 
!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

ABSTO

L 
!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los autovalores.
!>          Un autovalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>          al reducir C a forma tridiagonal, donde C es la matriz
!>          simétrica del problema simétrico estándar al que se transforma el
!>          problema generalizado.
!>
!>          Los autovalores se calcularán con mayor precisión cuando ABSTOL se
!>          establezca al doble del umbral de desbordamiento inferior 2*SLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          autovectores no convergieron, intente establecer ABSTOL a
!>          2*SLAMCH('S').
!
>

M 
!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W es un arreglo REAL, dimensión (N)
!>          Los primeros M elementos contienen los autovalores
!>          seleccionados en orden ascendente.
!
>

Z 
!>          Z es un arreglo COMPLEX, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz A
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Los autovectores se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un autovector falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al autovector, y el
!>          índice del autovector se devuelve en IFAIL.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas
!>          en el arreglo Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y debe usarse una cota superior.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del arreglo Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La longitud del arreglo WORK.  LWORK >= max(1,2*N).
!>          Para una eficiencia óptima

NAME


chegvx – computes the eigenvalues and eigenvectors of a complex Hermitian positive-definite definite generalized eigenvalue problem.

Function/Subroutine Documentation

chegvx computes the eigenvalues and eigenvectors of a complex Hermitian positive-definite definite generalized eigenvalue problem. Use this subroutine if you wish to have the eigenvectors returned in the array Z.

Eigenvalues and eigenvectors are computed for the equation:

ITYPE = 1 then $A Z \lambda = B Z$ (other not implemented)

ITYPE = 2 then $A Z = \lambda B Z$ (other not implemented)

ITYPE = 3 then $A B Z = \lambda Z$ (other not implemented)

where A and B are Hermitian positive-definite

matrices. As described in the Arguments section below, to reduce the number of calls to the level 3 BLAS, the routine does not pass the arguments ABSTOL, VL, VU and IL, IU to the internal routines.

    Arguments

ITYPE

    INTEGER ITYPE
    Specifies the form of the problem:
    = 1: A*Z*lambda = B*Z
    = 2: A*Z = B*Z*lambda
    = 3: A*B*Z = lambda*Z

JOBZ

    CHARACTER*1
    = 'V':  Compute the eigenvectors of A and B.
    = 'N':  Compute the eigenvalues of A and B only.
    Unspecified: JOBZ is not referenced.

RANGE

    CHARACTER*1
    = 'A': all eigenvalues will be found.
    = 'V': all eigenvalues between VL and VU will be found.
    = 'I': the IL-th to IU-th eigenvalues will be found.
    Unspecified: RANGE is not referenced.

UPLO

    CHARACTER*1
    = 'U':  Upper triangle of A and B are used.
    = 'L':  Lower triangle of A and B are used.
    Unspecified: UPLO is not referenced.

N

    INTEGER
    The order of the matrices A and B.  N >= 0.

A

    COMPLEX array, dimension (LDA, N)
    On entry, the upper or lower triangle of the Hermitian matrix A.

LDA

    INTEGER
    The leading dimension of the array A. LDA >= max(1, N).

B

    COMPLEX array, dimension (LDB, N)
    On entry, the upper or lower triangle of the Hermitian matrix B,
    which must be positive-definite.

LDB

    INTEGER
    The leading dimension of the array B. LDB >= max(1, N).

VL

    REAL
    If RANGE='V', the lower bound of the interval for the desired
    eigenvalues.

VU

    REAL
    If RANGE='V', the upper bound of the interval for the desired
    eigenvalues.

IL

    INTEGER
    If RANGE='I', the index of the first desired eigenvalue, 1 <= IL <= IU.

IU

    INTEGER
    If RANGE='I', the index of the last desired eigenvalue, IL <= IU <= N.

ABSTOL

    REAL
    If DB = 'V', tolerance used for convergence:
    The routine calls CHEEVX with ABSTOL = max(ABSTOL,eps*max(f2cmax1(f2cmax1(abs(A_ii)))),f2cmax1(f2cmax1(abs(B_ii))))
    where eps is the machine epsilon of the real type, and A_ii and B_ii
    are diagonal elements of the matrices A and B respectively.
    If DB = 'N', ABSTOL is not used.
    Unspecified: ABSTOL is not referenced.

M

    INTEGER
    The total number of eigenvalues found.
    If RANGE='A', M = N.
    If RANGE='V', M = number of eigenvalues between VL and VU.
    If RANGE='I', M = IU - IL + 1.

W

    REAL array, dimension (N)
    On exit, the computed eigenvalues. The entries are sorted in
    increasing order.

Z

    COMPLEX array, dimension (LDZ, N)
    On exit, the computed eigenvectors, with the i-th column of Z
    representing the eigenvector corresponding to the i-th eigenvalue in W.
    The eigenvectors are normalized so that the first element of each
    vector has magnitude 1, and so that Z is unitary if JOBZ = 'V'.

LDZ

    INTEGER
    The leading dimension of the array Z. LDZ >= max(1, N).

WORK

    COMPLEX array, dimension (LWORK)

LWORK

    INTEGER
    The dimension of the array WORK. LWORK >= MAX(2*N, N+NB).
    where NB is the blocksize for CHETRD returned by ILAENV.
    If LWORK = -1, then a workspace query is assumed; the routine
    only calculates the optimal size of the WORK array, returns
    this value as the first entry of the WORK array, and no error
    message related to LWORK is issued by XERBLA.

RWORK

    REAL array, dimension (7*N)

IWORK

    INTEGER array, dimension (5*N)

IFAIL

    INTEGER array, dimension (N)
    If JOBZ = 'V', then if INFO = 0, the first M elements of
    IFAIL are zero.  If INFO > 0, then IFAIL contains the
    indices of the eigenvectors that failed to converge.
    If JOBZ = 'N', then IFAIL is not referenced.

INFO

    INTEGER
    = 0:  successful exit
    < 0:  if INFO = -i, the i-th argument had an illegal value
    > 0:  CPOTRF or CHEEVX returned an error code:
       <= N:  if INFO = i, CHEEVX failed to converge;
              i eigenvectors failed to converge.  Their indices
              are stored in array IFAIL.
       > N:   if INFO = N + i, for 1 <= i <= N, then the leading
              principal minor of order i of B is not positive.
              The factorization of B could not be completed and
              no eigenvalues or eigenvectors were computed.
