--proxy-ser
ver
=
host:
port
Especifica el servidor proxy HTTP/SOCKS4/SOCKS5 a utilizar para las solicitudes. Esto anula cualquier variable de entorno o configuración seleccionada a través del diálogo de opciones. Un servidor proxy individual se especifica utilizando el formato: [<proxy-scheme>://]<proxy-host>[:<proxy-port>] Donde <proxy-scheme> es el protocolo del servidor proxy, y es
uno de:
"http", "socks", "socks4", "socks5".Si se omite <proxy-scheme>, por defecto es "http". Tenga en cuenta también que "socks" es
equivalente a "socks5".
Ejemplos:


--proxy-server="foopy:

99"

Usa el proxy HTTP "foopy:99" para cargar todas las

URL.


--proxy-server="socks://foobar:1080" Usa el proxy SOCKS v5 "foobar:1080" para cargar todas

las URL.

--proxy-server="socks4://foobar:

1080"

Usa el proxy SOCKS v4 "foobar:1080" para

cargar todas las URL.


--proxy-server="socks5://foobar:66"
Usa el proxy SOCKS v5 "foobar:66" para cargar todas las

URL.


También es posible especificar un servidor proxy separado para diferentes tipos de URL, anteponiendo un especificador de URL al especificador del servidor proxy:
Ejemplo

:


--proxy-server="https=proxy1:80;http=socks4://baz:1080"
Carga las URL https://* usando el proxy HTTP "proxy1:80". Y carga las URL

http://*


usando el proxy SOCKS v4 "baz:1080".
