CHECK_HD(1) Manual de Comandos Generales CHECK_HD(1)

NOMBRE

página del manual para check_hd

SINOPSIS

check_hd [opciones] archivos

DESCRIPCIÓN

Intenta poner los datos del hardware en un formato consistente.

--check
realiza muchas comprobaciones y elimina datos innecesarios
--sort
ordena los datos
--reverse
invierte el orden de clasificación
--split
escribe entradas separadas para cada clave
--with-source
añade un comentario a cada elemento indicando la fuente de información
--mini
base de datos mínima (básicamente solo información del controlador)
--join-keys-first
al combinar elementos similares, une primero las entradas con claves comunes (por defecto, se unen por valores comunes)
--cfile archivo
crea un archivo C para ser incluido en libhd
--no-compact
no intentes hacer la versión C lo más pequeña posible
--out archivo
escribe los resultados en un archivo, por defecto es "hd.ids"
--log archivo
escribe información de registro en un archivo, por defecto es "hd.log"
Nota: check_hd solo funciona con el formato interno de libhd/hwinfo; para convertir a otros formatos, usa convert_hd
