NOMBRE

checkbutton - Crea y manipula widgets de selección booleana 'checkbutton'

SINOPSIS

checkbutton pathName ?options?

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre en la línea de comandos:	-command
Nombre en la base de datos:	command
Clase en la base de datos:	Command
Especifica un comando Tcl para asociar con el botón. Este comando se invoca típicamente cuando se suelta el botón 1 del ratón sobre la ventana del botón. La variable global del botón (-variable opción) se actualizará antes de que se invoque el comando.
Nombre en la línea de comandos:	-height
Nombre en la base de datos:	height
Clase en la base de datos:	Height
Especifica una altura deseada para el botón. Si se está mostrando una imagen o un mapa de bits en el botón, el valor está en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto, está en líneas de texto. Si no se especifica esta opción, la altura deseada del botón se calcula a partir del tamaño de la imagen, el mapa de bits o el texto que se muestra en él.
Nombre en la línea de comandos:	-indicatoron
Nombre en la base de datos:	indicatorOn
Clase en la base de datos:	IndicatorOn
Especifica si el indicador debe dibujarse o no. Debe ser un valor booleano válido. Si es falso, la opción -relief se ignora y el relieve del widget siempre es hundido si el widget está seleccionado y elevado en caso contrario.
Nombre en la línea de comandos:	-offrelief
Nombre en la base de datos:	offRelief
Clase en la base de datos:	OffRelief
Especifica el relieve para el checkbutton cuando el indicador no se dibuja y el checkbutton está desactivado. El valor predeterminado es “elevado”. Al establecer esta opción en “plano” y -indicatoron en falso y -overrelief en “elevado”, se logra el efecto de tener un botón plano que se eleva al pasar el ratón por encima y que se hunde al activarse. Este es el comportamiento que típicamente exhiben los checkbuttons de Negrita, Cursiva y Subrayado en la barra de herramientas de un procesador de textos, por ejemplo.
Nombre en la línea de comandos:	-offvalue
Nombre en la base de datos:	offValue
Clase en la base de datos:	Value
Especifica el valor a almacenar en la variable asociada al botón cada vez que este botón se deselecciona. Por defecto es “0”.
Nombre en la línea de comandos:	-onvalue
Nombre en la base de datos:	onValue
Clase en la base de datos:	Value
Especifica el valor a almacenar en la variable asociada al botón cada vez que este botón se selecciona. Por defecto es “1”.
Nombre en la línea de comandos:	-overrelief
Nombre en la base de datos:	overRelief
Clase en la base de datos:	OverRelief
Especifica un relieve alternativo para el checkbutton, para usarse cuando el cursor del ratón está sobre el widget. Esta opción puede usarse para crear botones de barra de herramientas, configurando -relief flat -overrelief raised. Si el valor de esta opción es la cadena vacía, entonces no se usa ningún relieve alternativo cuando el cursor del ratón está sobre el checkbutton. La cadena vacía es el valor predeterminado.
Nombre en la línea de comandos:	-selectcolor
Nombre en la base de datos:	selectColor
Clase en la base de datos:	Background
Especifica un color de fondo para usar cuando el botón está seleccionado. Si indicatorOn es verdadero, entonces el color se usa como fondo para el indicador independientemente del estado de selección. Si indicatorOn es falso, este color se usa como fondo para todo el widget, en lugar de background o activeBackground, siempre que el widget esté seleccionado. Si se especifica como una cadena vacía, entonces no se usa ningún color especial para mostrar cuando el widget está seleccionado.
Nombre en la línea de comandos:	-selectimage
Nombre en la base de datos:	selectImage
Clase en la base de datos:	SelectImage
Especifica una imagen para mostrar (en lugar de la opción -image ) cuando el checkbutton está seleccionado. Esta opción se ignora a menos que se haya especificado la opción -image .
Nombre en la línea de comandos:	-state
Nombre en la base de datos:	state
Clase en la base de datos:	State
Especifica uno de tres estados para el checkbutton: normal, active, o disabled. En estado normal, el checkbutton se muestra usando las opciones -foreground y -background . El estado activo se usa típicamente cuando el puntero está sobre el checkbutton. En estado activo, el checkbutton se muestra usando las opciones -activeforeground y -activebackground . El estado deshabilitado significa que el checkbutton debe ser insensible: las asociaciones predeterminadas se negarán a activar el widget e ignorarán las pulsaciones del botón del ratón. En este estado, las opciones -disabledforeground y -background determinan cómo se muestra el checkbutton.
Nombre en la línea de comandos:	-tristateimage
Nombre en la base de datos:	tristateImage
Clase en la base de datos:	TristateImage
Especifica una imagen para mostrar (en lugar de la opción -image ) cuando el checkbutton está en modo de tres estados. Esta opción se ignora a menos que se haya especificado la opción -image .
Nombre en la línea de comandos:	-tristatevalue
Nombre en la base de datos:	tristateValue
Clase en la base de datos:	Value
Especifica el valor que hace que el checkbutton muestre la selección de múltiples valores, también conocida como el modo de tres estados. Por defecto es “”.
Nombre en la línea de comandos:	-variable
Nombre en la base de datos:	variable
Clase en la base de datos:	Variable
Especifica el nombre de una variable global para establecer e indicar si este botón está seleccionado o no. Por defecto es el nombre del botón dentro de su padre (es decir, el último elemento del nombre de ruta de la ventana del botón).
Nombre en la línea de comandos:	-width
Nombre en la base de datos:	width
Clase en la base de datos:	Width
Especifica un ancho deseado para el botón. Si se está mostrando una imagen o un mapa de bits en el botón, el valor está en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto, está en caracteres. Si no se especifica esta opción, el ancho deseado del botón se calcula a partir del tamaño de la imagen, el mapa de bits o el texto que se muestra en él.

DESCRIPCIÓN

El comando checkbutton crea una nueva ventana (dada por el argumento pathName ) y la convierte en un widget checkbutton. Se pueden especificar opciones adicionales, descritas arriba, en la línea de comandos o en la base de datos de opciones para configurar aspectos del checkbutton como sus colores, fuente, texto y relieve inicial. El comando checkbutton devuelve su argumento pathName . En el momento en que se invoca este comando, no debe existir una ventana llamada pathName, pero el padre de pathNamedebe existir.

Un checkbutton es un widget que muestra una cadena de texto, un mapa de bits o una imagen y un cuadrado llamado un indicador. Si se muestra texto, debe estar todo en una sola fuente, pero puede ocupar varias líneas en la pantalla (si contiene saltos de línea o si se produce un ajuste debido a la opción -wraplength ) y uno de los caracteres puede opcionalmente subrayarse usando la opción -underline . Un checkbutton tiene todo el comportamiento de un botón simple, incluyendo lo siguiente: puede mostrarse de tres maneras diferentes, según la opción -state ; puede hacerse que parezca elevado, hundido o plano; puede hacerse que parpadee; e invoca un comando Tcl cada vez que se hace clic con el botón 1 del ratón sobre el checkbutton.

Además, los checkbuttons pueden seleccionarse. Si un checkbutton está seleccionado, entonces el indicador se dibuja normalmente con una apariencia de seleccionado, y una variable Tcl asociada con el checkbutton se establece en un valor particular (normalmente 1). El indicador se dibuja con una marca de verificación dentro. Si el checkbutton no está seleccionado, entonces el indicador se dibuja con una apariencia de deseleccionado.arance, y la variable asociada se establece en un valor diferente (típicamente 0). El indicador se dibuja sin una marca de verificación en su interior. En el caso especial en que la variable (si se especifica) tiene un valor que coincide con el tristatevalue, el indicador se dibuja con una apariencia de tres estados y está en el modo de tres estados, lo que indica valores mixtos o múltiples. (Esto se utiliza cuando la casilla de verificación representa el estado de múltiples elementos.) El indicador se dibuja de una manera dependiente de la plataforma. En Unix y Windows, el interior de fondo de la casilla está “atenuado”. En Mac, el indicador se dibuja con un guion en su interior. Por defecto, el nombre de la variable asociada con un checkbutton es el mismo que el nom

El nombre de la variable, y los valores “on”, “off” y “tristate” almacenados en ella, pueden modificarse con opciones en la línea de comandos o en la base de datos de opciones. Las opciones de configuración también pueden usarse para modificar la forma en que se muestra el indicador (o si se muestra en absoluto). Por defecto, un checkbutton está configurado para seleccionarse y deseleccionarse en clics alternos del botón. Además, cada checkbutton monitorea su variable asociada y automáticamente se selecciona y deselecciona cuando el valor de la variable cambia a y desde los valores
