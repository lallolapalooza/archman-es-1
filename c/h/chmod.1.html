DESCRIPCIÓ

N

Esta página de manual documenta la versión GNU de chmod. chmod cambia los bits de modo de cada archivo dado de acuerdo con el modo, que puede ser una representación simbólica de los cambios a realizar, o un número octal que representa el patrón de bits para los nuevos bits de modo. El formato de un modo simblico es

[

ugoa...][[-+=][perm...]...], dondeperm es cero o más letras del conjunto rwxXst, o una sola letra del conjunto ugo. Se pueden dar varios modos simbólicos, separados por comas. Una combinación de las

letras

ugoa controla el acceso de qué usuarios al archivo será cambiado: el usuario que lo posee ( u), otros usuarios en el grupo del archivo (g), otros usuarios que no están en el grupo del archivo (o), o todos los usuarios (a). Si no se da ninguna de estas, el efecto es como si se diera (a), pero los bits que están establecidos en la umask no se ven afectados.El oper

ador

+ hace que los bits de modo de archivo seleccionados se añadan a los bits de modo de archivo existentes de cada archivo; - hace que se eliminen; y = hace que se añadan y hace que los bits no mencionados se eliminen, excepto que los bits de ID de usuario y de grupo establecidos no mencionados de un directorio no se ven afectados. Las let

ras

rwxXst seleccionan bits de modo de archivo para los usuarios afectados: lectura ( r), escritura (w), ejecución (o búsqueda para directorios) (x), ejecución/búsqueda solo si el archivo es un directorio o ya tiene permiso de ejecución para algún usuario (X), establecer ID de usuario o de grupo en la ejecución (s), indicador de eliminación restringida o bit pegajoso (t). En lugar de una o más de estas letras, puede especificar exactamente una de las letrasugo: los permisos concedidos al usuario que posee el archivo ( u), los permisos concedidos a otros usuarios que son miembros del grupo del archivo (g), y los permisos concedidos a los usuarios que no están en ninguna de las dos categorías anteriores (o).Un modo numérico es de uno a cuatro dígitos octales (0-7), obtenidos sumando los bits con valores 4, 2 y 1. Se supone que los dígitos omitidos son ceros iniciales. El primer dígitoselecciona los atributos de ID de usuario establecido (4) y de ID de grupo establecido (2) y de eliminación restringida o pegajoso (1). El segundo dígitoselecciona los permisos para el usuario que posee el archivo: lectura (4), escritura (2) y ejecución (1); el tercero selecciona los permisos para

otros usuarios en el grupo del archivo, con los mismos valores; y el cuarto para otros usuarios que no están en el grupo del archivo, con los mismos valores.

chmod no cambia los permisos de los enlaces simbólicos;

la

llamada al sistema chmod no puede cambiar sus permisos en la mayoría de los sistemas, y la mayoría de los sistemas ignoran los permisos de los enlaces simbólicos. Sin embargo, para cada enlace simbólico listado en la línea de comandos, chmod cambia los permisos del archivo al que apunta. En contraste, chmod ignora los enlaces simbólicos encontrados durante los recorridos recursivos de directorios. Las opciones que modifican este comportamiento se describen en la sección OPCIONES. ETGID

chmod limpia el bit de ID de grupo establecido de un archivo normal si el ID de grupo del archivo no coincide con el ID de grupo efectivo del usuario o con uno de los IDs de grupo suplementarios del usuario, a menos que el usuario tenga los privilegios adecuados. Restricciones adicionales pueden causar que los bits de ID de usuario establecido y de ID de grupo

establecido de

MODO o RARCHIVO sean ignorados. Este comportamiento depende de la política y funcionalidad de la llamada al sistema chmod subyacente. En caso de duda, compruebe el comportamiento del sistema subyacente. Para los

directorios

chmod preserva los bits de ID de usuario establecido y de ID de grupo establecido a menos que especifique explícitamente lo contrario. Puede establecer o limpiar los bits con modos simbólicos como u+s y g-s. Para limpiar estos bits para directorios con un modo numérico se requiere un cero inicial adicional como 00755, un signo menos inicial como -6000, o un signo igual inicial como =755. INDICADOR DE ELIMINACIÓN RESTRINGIDA

O BIT
PEGAJOSO

El indicador de eliminación restringida o bit pegajoso es un solo bit, cuya interpretación depende del tipo de archivo. Para los directorios, impide que los usuarios sin privilegios eliminen o renombren un archivo en el directorio a menos que sean propietarios del archivo o del directorio; a esto se le

llama el

indicador de eliminación restringida para el directorio, y se encuentra comúnmente en directorios escribibles por todos como /tmp. Para archivos normales en algunos sistemas más antiguos, el bit guarda la imagen de texto del programa en el dispositivo de intercambio para que se cargue más rápidamente cuando se ejecute; a esto se le llama el bit pegajoso.
