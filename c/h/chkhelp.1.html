CHKHELP(1) Manual de comandos generales CHKHELP(1)

NOMBRE

chkhelp - comprueba los archivos de texto de ayuda de métricas de rendimiento

SINOPSIS

$PCP_BINADM_DIR/chkhelp [-eHiOp?] [-D depuración] [-n pmnsfile] archivo de ayuda [nombre de métrica ...]

DESCRIPCIÓN

chkhelp comprueba la consistencia de los archivos de texto de ayuda de Performance Co-Pilot generados por newhelp(1) y utilizados por los Agentes de Dominio de Métricas de Rendimiento (PMDA). La comprobación implica el escaneo de los archivos y, opcionalmente, la visualización de entradas seleccionadas.

Los archivos archivo de ayuda.dir y archivo de ayuda.pag son creados por newhelp(1) y se asume que ya existen.

Sin ninguna opción o argumento de nombre de métrica, chkhelp verifica silenciosamente la integridad estructural de los archivos de ayuda.

Si se especifican argumentos de nombre de métrica, entonces solo se procesarán las entradas de ayuda para las métricas correspondientes.

Si no se especifican argumentos de nombre de métrica, entonces se debe proporcionar al menos una de las opciones -i o -p. La opción -i hace que se procesen las entradas de todos los dominios de instancias (ignorando las entradas para métricas de rendimiento). La opción -p hace que se muestren las entradas para todas las métricas (ignorando las entradas para dominios de instancias).

Cuando se van a procesar entradas de métricas (ya sea a través de los argumentos nombre de métrica o de la opción -p o la opción -i), las opciones -O y -H solicitan la visualización del texto de ayuda de una línea y del texto de ayuda detallado respectivamente. El valor predeterminado es -O.

Normalmente chkhelp opera en el Espacio de Nombres de Métricas de Rendimiento (PMNS) predeterminado, sin embargo, si se especifica la opción -n, se carga un espacio de nombres alternativo del archivo pmnsfile.

La opción -e proporciona una verificación de existencia donde se escanean todas las métricas especificadas del PMNS (nota, no del archivo de ayuda), y solo se informan los nombres de las métricas para las cuales no existe texto de ayuda. La opción -e es mutuamente excluyente con las opciones -i y/o -p.

OPCIONES

Las opciones de línea de comandos disponibles son:

-e
Informa métricas sin texto de ayuda.
-H
Muestra texto de ayuda detallado y sale.
-i
Procesa todos los dominios de instancias.
-n pmnsfile
Carga un Espacio de Nombres de Métricas de Rendimiento alternativo (PMNS(5)) desde el archivo pmnsfile.
-O
Muestra el resumen de ayuda de una línea.
-p
Procesa todas las métricas (PMID).
-?
Muestra el mensaje de uso y sale.

DIAGNÓSTICO

Hay todo tipo de razones por las que una base de datos de ayuda puede estar inconsistente; la más probable es que una métrica de rendimiento en la base de datos no esté definida en el PMNS cargado.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a diagnosticar problemas, aunque la información a veces es críptica y está destinada principalmente a proporcionar orientación a los desarrolladores en lugar de a los usuarios finales. depuración es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VEA TAMBIÉN

newhelp(1), PMAPI(3), pmLookupInDomText(3), pmLookupText(3), pcp.conf(5), pcp.env(5) y PMNS(5).
