Documentación de Función/Subrutina

subroutine cherk (character uplo, character trans, integer n, integer k, real alpha, complex, dimension(lda,*) a, integer lda, real beta, complex, dimension(ldc,*) c, integer ldc)

CHERK

Propósito:

!>
!> CHERK  realiza una de las operaciones de rango k hermitianas
!>
!>    C := alpha*A*A**H + beta*C,
!>
!> o
!>
!>    C := alpha*A**H*A + beta*C,
!>
!> donde  alpha y beta  son  escalares  reales,  C es una  matriz hermitian n por n
!> y  A  es una  matriz n por k  en el primer caso y una  matriz k por n
!> en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz C debe ser referenciada de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   Solo se debe referenciar la parte triangular superior de C.
!>
!>              UPLO = 'L' o 'l'   Solo se debe referenciar la parte triangular inferior de C.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           A la entrada, TRANS especifica la operación a realizar de la siguiente manera:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**H + beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**H*A + beta*C.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz C. N debe ser
!>           al menos cero.
!>

K

!>          K es INTEGER
!>           A la entrada con TRANS = 'N' o 'n', K especifica el número
!>           de columnas de la matriz A, y a la entrada con
!>           TRANS = 'C' o 'c', K especifica el número de filas de la
!>           matriz A. K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es REAL
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX, dimension ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con TRANS = 'N' o 'n', la parte principal n por k
!>           del array A debe contener la matriz A, en caso contrario
!>           la parte principal k por n del array A debe contener la
!>           matriz A.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como está declarada
!>           en el programa (sub)llamador. Cuando TRANS = 'N' o 'n'
!>           entonces LDA debe ser al menos max( 1, n ), en caso contrario LDA debe
!>           ser al menos max( 1, k ).
!>

BETA

!>          BETA es REAL
!>           A la entrada, BETA especifica el escalar beta.
!>

C

!>          C es un array COMPLEX, dimension ( LDC, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte superior n por n
!>           del array C debe contener la parte triangular superior de la
!>           matriz hermitiana y la parte estrictamente triangular inferior de C no se referencia. A la salida, la
!>           parte triangular superior del array C se sobrescribe con la
!>           parte triangular superior de la matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte inferior n por n
!>           del array C debe contener la parte triangular inferior de la
!>           matriz hermitiana y la parte estrictamente triangular superior de C no se referencia. A la salida, la
!>           parte triangular inferior del array C se sobrescribe con la
!>           parte triangular inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos diagonales no
!>           necesitan ser establecidas, se asumen como cero, y a la salida se establecen a cero.
!>

LDC

!>          LDC es INTEGER
!>           A la entrada, LDC especifica la primera dimensión de C tal como está declarada
!>           en el programa (sub)llamador. LDC debe ser al menos
!>           max( 1, n ).
!>
