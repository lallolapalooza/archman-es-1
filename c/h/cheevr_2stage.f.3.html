subrutina cheevr_2stage (character jobz, character range, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

CHEEVR_2STAGE calcula los valores y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HE

Propósito:

!>
!> CHEEVR_2STAGE calcula los valores y, opcionalmente, los vectores propios
!> de una matriz Hermitiana compleja A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Los valores y vectores propios pueden
!> seleccionarse especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>
!> CHEEVR_2STAGE primero reduce la matriz A a forma tridiagonal T con una llamada
!> a CHETRD. Luego, siempre que sea posible, CHEEVR_2STAGE llama a CSTEMR para calcular
!> el espectro de valores propios utilizando representaciones relativamente robustas.
!> CSTEMR calcula los valores propios mediante el algoritmo dqds, mientras que los
!> vectores propios ortogonales se calculan a partir de varias representaciones L D L^T
!> (también conocidas como representaciones relativamente robustas). La
!> ortogonalización de Gram-Schmidt se evita tanto como sea posible. Más específicamente,
!> los diversos pasos del algoritmo son los siguientes.
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcula T - sigma I  = L D L^T, de modo que L y D
!>        definen todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcula los valores propios con la precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión completa
!>        de los valores propios calculados justo antes
!>        de que los vectores correspondientes deban calcularse, véanse los pasos c) y d).
!>    (c) Para cada clúster de valores propios cercanos, selecciona un nuevo
!>        desplazamiento cercano al clúster, encuentra una nueva factorización y refina
!>        los valores propios desplazados con la precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcula
!>        el vector propio correspondiente formando una factorización retorcida que revele el rango. Vuelve a (c) para los clústeres que queden.
!>
!> La precisión deseada de la salida se puede especificar mediante el parámetro
!> de entrada ABSTOL.
!>
!> Para más detalles, véase la documentación de CSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, agosto de 2004.
!> - Inderjit Dhillon y Beresford Parlett: SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mayo de 1997.
!>
!>
!> Nota 1: CHEEVR_2STAGE llama a CSTEMR cuando se solicita el espectro completo
!> en máquinas que se ajustan al estándar de punto flotante ieee-754.
!> CHEEVR_2STAGE llama a SSTEBZ y CSTEIN en máquinas no ieee y
!> cuando se solicitan espectros parciales.
!>
!> La ejecución normal de CSTEMR puede crear NaNs e infinitos y,
!> por lo tanto, puede abortar debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos de la manera predeterminada estándar ieee.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman SSTEBZ y
!>          CSTEIN.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA, N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N principal de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N-por-N principal de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los valores propios.
!>          Se acepta un valor propio aproximado como convergente
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o igual
!>          que cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Véase  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si la alta precisión relativa es importante, establezca ABSTOL a
!>          SLAMCH( 'Safe minimum' ). Hacer esto garantizará que
!>          los valores propios se calculen con alta precisión relativa cuando
!>          sea posible en futuras versiones. El código actual no
!>          hace ninguna garantía sobre la alta precisión relativa, pero
!>          las futuras versiones lo harán. Véase J. Barlow y J. Demmel,
!>          ,
LAPACK Nota de Trabajo #7, para una discusión !> de qué matrices definen sus eigenvalores con alta precisión !> relativa. !>

M 
!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W es un array REAL, dimensión (N)
!>          Los primeros M elementos contienen los eigenvalores
!>          seleccionados en orden ascendente.
!
>

Z 
!>          Z es un array COMPLEX, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz A
!>          correspondientes a los eigenvalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no es referenciado.
!>          Nota: el usuario debe asegurarse de que al menos max(1,M) columnas son
!>          proporcionadas en el array Z; si RANGE = 'V', el valor exacto de M
!>          no es conocido de antemano y un límite superior debe ser usado.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

ISUPP

Z 
!>          ISUPPZ es un array INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los autovectores en Z, es decir, los índices
!>          que indican los elementos no nulos en Z. El i-ésimo autovector
!>          es no nulo solo en los elementos ISUPPZ( 2*i-1 ) a través de
!>          ISUPPZ( 2*i ). Esto es una salida de CSTEMR (matriz
!>          tridiagonal). El soporte de los autovectores de A es típicamente
!>          1:N debido a las transformaciones unitarias aplicadas por CUNMTR.
!>          Implementado solo para RANGE = 'A' o 'I' y IU - IL = N - 1
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, 26*N, dimensión) donde
!>                                   dimensión = max(etapa1,etapa2) + (KD+1)*N + N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + N
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo usado por el algoritmo QR o LQ,
!>                                   usualmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos usados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK por XERBLA.
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo
!>          (y mínimo).
!
>

LRWOR

K 
!>          LRWORK es INTEGER
!>          La longitud del array RWORK.
!>          Si N <= 1, LRWORK >= 1, de lo contrario LRWORK >= 24*N.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de los arrays WORK, RWORK e IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK por XERBLA.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo
!>          (y mínimo).
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1, LIWORK >= 1, de lo contrario LIWORK >= 10*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de los arrays WORK, RWORK e IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK por XERBLA.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  Error interno
!>
