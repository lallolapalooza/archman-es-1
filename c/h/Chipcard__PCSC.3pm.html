NOMBRE

Chipcard::PCSC - Biblioteca de interfaz para lectores de tarjetas inteligentes

SINOPSIS

my $hContext = new Chipcard::PCSC();
@ReadersList = $hContext->ListReaders ();
$hContext->GetStatusChange(\@readers_states, $timeout);
$apdu = Chipcard::PCSC::array_to_ascii(@apdu);
@apdu = Chipcard::PCSC::ascii_to_array($apdu);
$hContext = undef;

DESCRIPCIÓN

El módulo PCSC implementa la clase Chipcard::PCSC. Los objetos de esta clase se utilizan para comunicarse con el demonio PCSC-lite (véase pcscd(1) para más información).

PC/SC representa una capa de abstracción para lectores de tarjetas inteligentes. Proporciona una capa de comunicación con una amplia variedad de lectores de tarjetas inteligentes a través de una API estandarizada.

Un objeto PCSC puede utilizarse para comunicarse con más de un lector a través de objetos Chipcard::PCSC::Card. Por favor, lea Chipcard::PCSC::Card para obtener información extendida sobre cómo comunicarse con un lector de tarjetas inteligentes.

Un objeto PCSC utiliza la siguiente propiedad: "$pcsc_object->{hContext}" el contexto devuelto por la biblioteca pcsc

CONSTRUCTORES

Los siguientes métodos pueden utilizarse para construir un objeto PCSC:

•
$hContext = new Chipcard::PCSC($scope, $remote_host);
  • $scope es el ámbito de la conexión con el demonio PC/SC. Puede ser cualquiera de los siguientes: 
    $Chipcard::PCSC::SCARD_SCOPE_USER     (no utilizado por PCSClite);
$Chipcard::PCSC::SCARD_SCOPE_TERMINAL (no utilizado por PCSClite);
$Chipcard::PCSC::SCARD_SCOPE_SYSTEM   Servicios en la máquina local;
$Chipcard::PCSC::SCARD_SCOPE_GLOBAL   Servicios en un host remoto.
  • $remote_host es el nombre del host de la máquina remota a contactar. Solo se utiliza cuando $scope es igual a $Chipcard::PCSC::SCARD_SCOPE_GLOBAL. Un valor nulo significa localhost.
  • $hContext = new Chipcard::PCSC($scope);

    Este método es equivalente a:

    $hContext = new Chipcard::PCSC($scope, 0);
  • $hContext = new Chipcard::PCSC();

    Este método es equivalente a:

    $hContext = new Chipcard::PCSC($Chipcard::PCSC::SCARD_SCOPE_SYSTEM, 0);

FALLO EN LA CONSTRUCCIÓN

Los constructores de Chipcard::PCSC devuelven un "undef" valor cuando el objeto no puede ser creado. $Chipcard::PCSC::errno puede utilizarse para obtener más información sobre el error. (Véase la sección "MANEJO DE ERRORES" más abajo para más información)

MÉTODOS DE Chipcard::PCSC

Aquí hay una lista de todos los métodos que pueden utilizarse con un objeto PCSC.

  • hContext->ListReaders( $group );

    Este método devuelve los lectores disponibles en el $groupdado. Si se omite, $group por defecto es un valor nulo que significa "todos los grupos". Por favor, tenga en cuenta que a la fecha de escritura, $group puede omitirse con seguridad ya que no es utilizado por PCSClite.

    El valor de retorno tras una finalización exitosa es un array de cadenas: una cadena por cada lector disponible. Si ocurrió un error, se devuelve el valor undef y $Chipcard::PCSC::errno debería utilizarse para obtener más información sobre el error. (Véase la sección "MANEJO DE ERRORES" más abajo para más información). El siguiente ejemplo describe el uso de ListReaders:

    $hContext = new Chipcard::PCSC();
die ("Can't create the PCSC object: $Chipcard::PCSC::errno\n")
       unless (defined $hContext);
@ReadersList = $hContext->ListReaders ();
die ("Can't get readers' list: $Chipcard::PCSC::errno\n")
       unless (defined($ReadersList[0]));
$, = "\n  ";
print @ReadersList . "\n";
  • $hContext->GetStatusChange(\@readers_states, $timeout);

    El método "$hContext->GetStatusChange(\@readers_states, $timeout)" utiliza una referencia a una lista de hashes.

    # create the list or readers to watch
map { push @readers_states, ({'reader_name'=>"$_"}) } @ReadersList;
@StatusResult = $hContext->GetStatusChange(\@readers_states);

    Las claves del hash son: 'reader_name', 'current_state', 'event_state' y 'ATR'.

    Para detectar un cambio de estado, primero debe obtener el estado y luego copiar 'event_state' en 'current_state'. El método devolverá cuando ambos estados sean diferentes o cuando ocurra un tiempo de espera.

    @StatusResult = $hContext->GetStatusChange(\@readers_states);
foreach $reader (@readers_states)
{
  $reader->{current_state} = $reader->{event_state};
}
@StatusResult = $hContext->GetStatusChange(\@readers_states);
  • $hContext->GetStatusChange(\@readers_states);

    Este método es equivalente a:

    $hContext->GetStatusChange(\@readers_states, 0xFFFFFFFF);

    El tiempo de espera se establece a infinito.

  • $apdu_ref = Chipcard::PCSC::ascii_to_array($apdu);

    El método Chipcard::PCSC::Card::Transmit() utiliza referencias a arrays como parámetros de entrada y salida. El Chipcard::PCSC::ascii_to_array() se utiliza para transformar una APDU en formato ASCII a una referencia a un array en el formato correcto.

    Ejemplo:

    $SendData = Chipcard::PCSC::ascii_to_array("00 A4 01 00 02 01 00");
  • $apdu = Chipcard::PCSC::array_to_ascii($apdu_ref);

    Este método se utiliza para convertir el resultado de un Chipcard::PCSC::Card::Transmit() a formato ASCII.

    Ejemplo:

    $RecvData = $hCard->Transmit($SendData);
print Chipcard::PCSC::array_to_ascii($RecvData);

MANEJO DE ERRORES

Todas las funciones de los objetos PCSC guardan el valor de retorno en una variable global llamada $Chipcard::PCSC::errno. Esta variable contiene por lo tanto el último estado de PCSC.

Es una variable mágica de doble tipo que se comporta igual que $!. Esto significa que contiene tanto un valor numérico que describe el error como la cadena correspondiente. El valor numérico puede cambiar de un sistema a otro ya que depende de la biblioteca PCSC...

Aquí hay un pequeño ejemplo de cómo utilizarla:

$hContext = new Chipcard::PCSC();
die ("Can't create the PCSC object: $Chipcard::PCSC::errno\n")
    unless (defined $hContext);

En caso de que la última llamada fuera exitosa, $Chipcard::PCSC::errno contiene el estado "SCARD_S_SUCCESS" . Aquí hay una lista de todos los códigos de error posibles. Están definidos como variables de solo lectura dentro del módulo PCSC:
