Documentación de Función/Subrutina

subroutine checon_3 (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, real anorm, real rcond, complex, dimension( * ) work, integer info)

CHECON_3

Propósito:

!> CHECON_3 estima el recíproco del número de condición (en la
!> norma 1) de una matriz Hermítica compleja A utilizando la factorización
!> calculada por CHETRF_RK o CHETRF_BK:
!>
!>    A = P*U*D*(U**H)*(P**T) o A = P*L*D*(L**H)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**H (o L**H) es la conjugada de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es Hermítica y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Se obtiene una estimación para norm(inv(A)), y se calcula el recíproco del
!> número de condición como RCOND = 1 / (ANORM * norm(inv(A))).
!> Esta rutina utiliza el solucionador BLAS3 CHETRS_3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se
!>          almacenan como una matriz triangular superior o inferior:
!>          = 'U':  Triangular superior, la forma es A = P*U*D*(U**H)*(P**T);
!>          = 'L':  Triangular inferior, la forma es A = P*L*D*(L**H)*(P**T).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          La diagonal de la matriz diagonal por bloques D y los factores U o L
!>          calculados por CHETRF_RK y CHETRF_BK:
!>            a) SOLAMENTE los elementos diagonales de la matriz Hermítica
!>               diagonal por bloques D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                deben proporcionarse en la entrada en el array E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array COMPLEX, dimensión (N)
!>          En la entrada, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz Hermítica diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) no referenciado;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) no referenciado.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) no se referencia en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          según lo determinado por CHETRF_RK o CHETRF_BK.
!>

ANORM

!>          ANORM es REAL
!>          La norma 1 de la matriz original A.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es array COMPLEX, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>
