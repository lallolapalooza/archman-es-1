CHA(1) Manual de Comandos Generales CHA(1)

NOMBRE

cha - el navegador de texto Chawan

SINOPSIS

cha [opciones] [URL(s) o archivo(s)...]

DESCRIPCIÓN

Chawan es un navegador de modo texto. Puede usarse como paginador, o como navegador web/(S)FTP/gopher/gemini/archivo. Entiende HTML y CSS, y cuando está habilitado por el usuario, también puede ejecutar JavaScript y mostrar imágenes (en terminales que soporten Sixel o el protocolo de imagen Kitty.)

Chawan también puede usarse como visor de documentos basado en texto general, como se describe en cha-mailcap(5), o como visor de páginas man con hipervínculos usando mancha(1).

Este documento describe la invocación de Chawan. Para una lista de atajos de teclado predeterminados, escriba cha about:chawan. Para una descripción detallada del formato de configuración, vea cha-config(5).

ARGUMENTOS

Al invocarse, Chawan intenta abrir todos los argumentos de URL/archivo proporcionados. Si no se pudo abrir ninguna URL con éxito, Chawan sale automáticamente.

Chawan también puede iniciarse sin especificar un archivo, si un archivo es proporcionado a través de un pipe. En este caso, puede especificar el tipo de contenido usando el interruptor -T .

OPCIONES

Todas las opciones de línea de comandos tienen formas cortas (por ejemplo-d) y formas largas (por ejemplo--dump).

Las formas largas deben introducirse con dos guiones; cuando solo se proporciona un guion, cada letra se analiza como una forma corta separada.

En forma corta, también es válido proporcionar valores a los argumentos sin un espacio posterior. Por ejemplo, -obuffer.images=true es válido.

-c, --css hoja-de-estilos
Modifica temporalmente la hoja de estilos del usuario. Si ya se está usando una hoja de estilos de usuario, la hoja de estilos dada se agrega a esa.
-d, --dump
Inicia en modo sin cabeza (headless), e imprime secuencialmente los archivos abiertos a stdout. Esta opción se habilita implícitamente si stdout no es un tty (por ejemplo, al canalizar la salida de cha ).
-h, --help
Imprime una versión corta de esta página, luego sale.
-o, --opt configuración
Pasa opciones de configuración temporales. Acepta el formato de configuración descrito en cha-config(5), así que la cadena pasada debe ser TOML válido.

Para facilitar la especificación de parámetros de cadena, las palabras clave simples no reconocidas se convierten en cadenas. Así que esto funciona:

--opt display.color-mode=eight-bit.

Sin embargo, los símbolos y las palabras que comienzan con un número aún deben estar entre comillas, es decir, tiene que ponerles comillas dos veces para eludir las comillas del shell.

-r, --run script/archivo
Ejecuta la cadena proporcionada como un script JS, o ejecuta el archivo JS proporcionado. Si el archivo termina en .mjs, se ejecuta como un módulo ES.
-v, --version
Imprime información sobre la versión del navegador, luego sale.
-C, --config archivo
Anula la ruta de búsqueda de configuración predeterminada. Se permiten rutas absolutas y relativas.
-I, --input-charset juego-de-caracteres
Anula el juego de caracteres de todos los archivos de entrada. Útil cuando Chawan está reconociendo incorrectamente el juego de caracteres de entrada.

(Si esto sucede a menudo, considere cambiar la lista de reconocimiento de juego de caracteres de entrada predeterminada encoding.document-charset en la configuración.)

-M, --monochrome
Fuerza la salida monocromática. El formato (negrita/cursiva/etc.) no se ve afectado. Este es un atajo para -o display.color-mode=monochrome.
-O, --output-charset juego-de-caracteres
Anula el juego de caracteres de salida. Este es un atajo para -o encoding.display-charset=juego-de-caracteres.
-T, --type tipo-de-contenido
Anula el tipo de contenido de todos los archivos de entrada. Útil cuando el tipo de contenido no puede adivinarse por la extensión del archivo, o al leer un archivo que no es texto plano de stdin.
-V, --visual
Cuando no se pasan archivos/URLs, abre la página especificada en start.visual-home en lugar de imprimir una pantalla de ayuda.
--
Interpretar todos los argumentos siguientes como archivos. Por ejemplo, puede abrir un archivo llamado -o, usando cha -- -o.

ENTORNO

Chawan lee y usa ciertas variables de entorno.

TMPDIR
Cuando está definida, la configuración predeterminada almacena archivos temporales dentro de este directorio (y /tmp/cha-tmp-user en caso contrario.)
HTTP_HOME, WWW_HOME
Cuando están definidas, Chawan inicia en modo visual de forma predeterminada y abre la página especificada por una de estas variables. HTTP_HOME tiene prioridad sobre WWW_HOME.
CHA_DIR
Cuando está definida, cambia el directorio de configuración a la ruta especificada.
COLORTERM
Cuando está definida a 24bit o truecolor, y la display.color-mode opción de configuración está definida a auto, Chawan establece el modo de color a color verdadero.
TERM
Usada por Chawan para adaptarse a peculiaridades específicas del terminal. Cuando no está definida, por defecto es xterm.
VISUAL, EDITOR
Usadas para determinar el editor a usar cuando la external.editor opción de configuración no está definida.
LINES, COLUMNS
Usadas como valores de respaldo cuando la detección del tamaño de la ventana falla.
