CHICKEN-UNINSTALL(1) Manual de comandos generales CHICKEN-UNINSTALL(1)

NOMBRE

chicken-uninstall — desinstalar la biblioteca de extensiones

SINOPSIS

chicken-uninstall [OPCIÓN ...] [NOMBRE ...]

DESCRIPCIÓN

chicken-uninstall elimina una o más bibliotecas de extensiones ya instaladas para el sistema CHICKEN Scheme. PATRÓN puede ser una expresión regular que nombre múltiples extensiones o simplemente un nombre de extensión.

El programa acepta los siguientes argumentos:

-h, -help
Mostrar uso y salir.
-version
Mostrar versión y salir.
-force
No preguntar, simplemente eliminar lo que coincida.
-match
Tratar NOMBRE como un patrón glob.
-s, -sudo
Usar un programa externo para elevar privilegios para eliminar archivos. El programa por defecto es sudo(8) pero puede ser reemplazado por la variable de entorno SUDO.
-host
Al compilar cruzado, desinstalar solo extensiones del host.
-target
Al compilar cruzado, desinstalar solo extensiones del objetivo.

ENTORNO

Las siguientes variables de entorno cambian el comportamiento de chicken-uninstall:

CHICKEN_INSTALL_REPOSITORY
La ruta donde se instalan las bibliotecas de extensiones. Por defecto, es la ruta de la biblioteca de paquetes seleccionada durante la configuración (normalmente $prefix/lib/chicken/<versión-binaria>).
SUDO
El comando a ejecutar al usar la bandera -s en el comando. Si no se proporciona, por defecto es sudo(8).

ESTADO DE SALIDA

La utilidad chicken-uninstall sale con 0 en caso de éxito, y >0 si ocurre un error.

VER TAMBIÉN

chicken(1), chicken-install(1), chicken-status(1)

Se puede encontrar más información en el Manual de usuario de CHICKEN.
