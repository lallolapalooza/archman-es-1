NOMBRE

chronic - ejecuta un comando silenciosamente a menos que falle

SINOPSIS

chronic [-ev] COMANDO...

DESCRIPCIÓN

chronic ejecuta un comando y organiza su salida estándar y error estándar para que solo se muestren si el comando falla (sale con valor distinto de cero o se bloquea). Si el comando tiene éxito, cualquier salida adicional se ocultará.

Un uso común para chronic es ejecutar un trabajo de cron. En lugar de intentar mantener el comando en silencio y tener que lidiar con correos que contienen salida accidental cuando tiene éxito, y no una salida lo suficientemente detallada cuando falla, puede simplemente ejecutarlo siempre con detalle y usar chronic para ocultar la salida exitosa.

0    1 * * * chronic backup # en lugar de backup >/dev/null 2>&1
*/20 * * * * chronic -ve my_script # detallado para depuración

OPCIONES

-v
Salida detallada (distingue entre STDOUT y STDERR, también informa RETVAL)
-e
Activación por error estándar. Activa la salida cuando la longitud de la salida de error estándar es distinta de cero. Sin -e, chronic necesita un valor de retorno distinto de cero para activar la salida.

En este modo, el valor de retorno de chronic será 2 si el valor de retorno del comando es 0 pero el comando imprimió en el error estándar.
