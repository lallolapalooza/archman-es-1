!>         
 El orden de la matriz A.  N >= 0.

A
P

!>          AP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          Al entrar, el triángulo superior o inferior de la matriz hermitiana
!>          A, empaquetado por columnas en un arreglo lineal.  La j-ésima columna de A
!>          se almacena en el arreglo AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          Al salir, AP es sobrescrito por los valores generados durante la
!>          reducción a forma tridiagonal.  Si UPLO 
= 'U', la diagonal
!>          y la primera superdiagonal de la matriz tridiagonal T sobrescriben
!>          los elementos correspondientes de A, y si UPLO = 'L', la
!>          diagonal y la primera subdiagonal de T sobrescriben los
!>          elementos correspondientes de A.
!>

!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar autovalores. VL 
< VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar autovalores. VL 
< VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; 
IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.

!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL 
= 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTO
L

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los autovalores.
!>          Un autovalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>          al reducir AP a forma tridiagonal.
!>
!>          Los autovalores se calcularán con mayor precisión cuando ABSTOL se
!>          establezca al doble del umbral de desbordamiento inferior 2*SLAMCH('S'), no a cero.
!>          Si esta rutina devuelve con INFO>0, indicando que algunos
!>          autovectores no 
convergieron, intente establecer ABSTOL a
!>          2*SLAMCH('S').
!>
!>          Véase  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de autovalores encontrados.  
0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un arreglo REAL, dimensión (N)
!>          Si 
INFO = 0, los autovalores seleccionados en orden ascendente.
!>

Z

!>          Z es un arreglo COMPLEX, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz A
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Si un autovector no converge, entonces esa columna 
de Z
!>          contiene la última aproximación al autovector, y
!>          el índice del autovector se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas
!>          en el arreglo Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y debe usarse una cota superior.
!>

LDZ !>          LDZ es INTEGER
