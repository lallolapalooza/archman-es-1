chmls(1) Utilidad de archivo de ayuda HTML comprimido chmls(1)

NOMBRE

chmls - Utilidad CHM de FPC Pascal

SINOPSIS

chmls [opciones] [comando] [parámetros específicos del comando]

DESCRIPCIÓN

La utilidad chmls realiza varias funciones relacionadas con CHM, como listar el contenido de los archivos CHM, extraer un archivo o todo el archivo y extraer archivos especiales. Sin embargo, el archivado es dominio de la utilidad chmcmd.

COMANDO

list <nombre-archivo> [número de sección]
Muestra el contenido del directorio del archivo. El número de sección puede ser 0 o 1; si no se especifica un número de sección, se muestra el contenido de ambas secciones.
extract <nombre-archivo-chm> <nombre-archivo-a-extraer> [nombre-para-guardar]
Extrae el archivo "nombre-archivo-a-extraer" del archivo "nombre-archivo", y, si se especifica, lo guarda como [nombre-para-guardar].
extractall <nombre-archivo-chm> [directorio]
Extrae todos los archivos del archivo "nombre-archivo" al directorio "directorio".
unblockchm <especificación-archivo1> [especificación-archivo2] ...
(Solo Windows) Desbloquea masivamente (XPsp2+) los CHMs relevantes. Se permiten múltiples archivos y comodines.
extractalias <nombre-archivo-chm> [nombre-base-archivo] [prefijo-símbolo]
Extrae información de contexto del archivo "nombre-archivo-chm" a basefilename.h y basefilename.ali, utilizando los símbolos "prefijo-símbolo" + número de contexto.
extracttoc <nombre-archivo-chm> [nombre-archivo]
Extrae la tabla de contenidos (principalmente para verificar la TOC binaria).
extractindex <nombre-archivo-chm> [nombre-archivo]
Extrae el índice (principalmente para verificar el índice binario).

Por razones de compatibilidad hacia atrás, el comando list es el predeterminado.

OPCIONES

-h, --help
Mostrar texto de ayuda.
-p, --no-page
No paginar la salida del comando list.
-n, --name-only
Mostrar solo la columna "nombre" en la salida del comando list.
