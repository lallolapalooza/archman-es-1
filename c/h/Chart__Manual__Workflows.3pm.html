NOMBRE

Chart::Manual::Workflows - diferentes maneras de crear gráficos

RESUMEN

Cuatro de los cinco pasos principales para crear una imagen de gráfico son fijos en su orden. Primero tienes que cargar el módulo, segundo crear el objeto. Después de eso puedes cambiar algunas propiedades. Y siempre como último paso creas la imagen, sin importar si la salida va a STDOUT o a un archivo.

La única flexibilidad radica en cómo prefieres proporcionar los datos. Y aquí tienes tres opciones. Lo más común es añadir un conjunto de datos a la vez, lo que también podría entenderse como una fila de la tabla de datos completa. La segunda opción es construir la tabla columna por columna. Tercero puedes soltar la tabla completa de una vez, ya sea por referencia a una estructura de datos o a un archivo que contenga los datos. La última opción está cerrada si ya has proporcionado datos al objeto. No es aconsejable reutilizar un objeto gráfico para la creación de imágenes posteriores fuera de los proyectos de arte moderno.

PASOS

La mayoría de los pasos ya están explicados en otro lugar y el RESUMEN solo enlaza allí. Las partes que faltan se presentan aquí.

use Chart

Como con cualquier otro Módulo tienes que:

use Chart::[Type];

Type siendo un marcador de posición para el nombre de un tipo de gráfico, que son: Barras, Compuesto, Dirección, Barras de Error, Barras Horizontales, Líneas, Líneas y Puntos, Montaña, Pareto, Pastel, Puntos, Dividir, Barras Apiladas. Para saber más sobre ellos lee Chart::Manual::Types.

Alternativamente escribe para cargar todos los tipos de gráficos a la vez con

use Chart;

Ambos no importan ningún símbolo en tu espacio de nombres sino que cargan Carp y GD.

drop data

Todos los métodos listados en la última sección, que crean la imagen final, toman como argumento opcional, el segundo argumento, los datos. Estos datos pueden ser entregados ya sea como una referencia a un array de arrays:

my $data = [ [ 1, 4, 3 ... ], # conjunto de datos 0
             [ 5, 8, 2 ... ], # conjunto de datos 1
             ...
];
$graph->png( 'file.png', $data );

o en forma de archivo. Entonces el argumento tiene que ser un nombre de archivo o un manejador de archivo (estilo antiguo como en "FILE" o moderno como en $FH). Alternativamente usa el método add_datafile.

data files

Son archivos de texto de nombre arbitrario que contienen una o varias filas de números, que deben estar separados por espacios o tabulaciones (\t) (se permite mezclar). Los comentarios estilo Perl o las líneas vacías serán ignorados, pero las filas que contengan una cantidad diferente de números causarán problemas.

create image

Actualmente solo soportamos imágenes en formato PNG y JPEG. Los métodos para crearlas tienen nombres directos: ->png y ->jpeg. Ambos toman los mismos argumentos y producen archivos de imagen. Para scripting de shell o programación web necesitas la imagen binaria, que obtienes con: ->cgi_png o ->cgi_jpeg. Algunos usuarios podrían incluso querer el objeto GD para procesamiento adicional por tu programa perl. En ese caso por favor usa: ->scalar_png o ->scalar_jpeg.

Después de haber creado un gráfico para fines web, también podrías querer utilizar imagemap_dump.
