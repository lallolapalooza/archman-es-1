chmcmd(1) Herramienta de compresión de archivos de ayuda HTML chmcmd(1)

NOMBRE

chmcmd - El compilador de ayuda HTML (CHM) de FPC Pascal

SINOPSIS

chmcmd [opciones] <nombre de archivo del proyecto de ayuda>

DESCRIPCIÓN

crea un archivo de Ayuda HTML Comprimida (chm) utilizando un proyecto de ayuda HTML de Microsoft (.hhp) o un archivo XML creado con la clase TCHMProject en la unidad fpc chmfilewriter.

Si no se pasan parámetros, el programa mostrará las opciones disponibles.

OPCIONES

-h, --ayuda
Mostrar texto de ayuda
--escanear-html
Escanear HTML en busca de archivos faltantes e información alink
--no-escanear-html
No escanear HTML en busca de archivos faltantes e información alink
--verbosidad <número>
establecer el nivel de verbosidad 0..5, 0 es el mínimo.
--generar-xml
(si es un archivo .hhp), también generar un proyecto xml a partir de .hhp.
