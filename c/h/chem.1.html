Descripció

n

chem produce diagramas de estructuras químicas. La versión actual es más adecuada para la química orgánica (enlaces, anillos). El programa chem es un preprocesador de groff como eqn, pic, tbl, etc. Genera salida de pic de tal manera que todas las partes de chem se traducen en diagramas del lenguaje de

pic.

Si no se proporcionan operandos, o si archivo es “-”, chem lee el flujo de entrada estándar. -h y --help muestran un mensaje de uso, mientras que -v y --version muestran información de la versión; ambos

terminan.

El programa chem se originó a partir del archivo fuente de Perl chem.pl. Le indica a pic que incluya una copia del archivo de macros chem.pic. Además, se carga el archivo fuente de groff pic.tm

ac.

En un estilo reminiscente de eqn y pic, los diagramas de chem se escriben en un lenguaje

especial.

Un conjunto de líneas de chem se ve

así 
.cstart
datos de

Las líneas que contienen las palabras clave .cstart y .cend inician y finalizan la entrada para chem, respectivamente. En el contexto de pic , es decir, después de la llamada de .PS, la entrada de chem puede iniciarse opcionalmente con la línea begin chem y finalizarse con la línea con la única palabra end

.

Cualquier cosa fuera de estas líneas de inicialización se copia sin modificación; todos los datos entre las líneas de inicialización se convierten en comandos de pic para dibujar el

diagrama.

Grupos funcionales y cadenas2>

Una moiety es una cadena de caracteres que comienza con una letra mayúscula, como N(C2H5)2. Los números se convierten en subíndices (a menos que parezcan valores fraccionarios, como en N2.5H). El nombre de una moiety se determina a partir de la moiety después de eliminar los caracteres especiales: por ejemplo, N(C2H5)2) tiene el nombre NC2H52.

Las moieties se pueden especificar de dos maneras. Normalmente, una moiety se coloca justo después de lo último mencionado, separada por un punto y coma rodeado de espacios, por ejemplo:

B1: bond ; OH

Aquí la moiety es OH; se coloca después de un enlace (bond).

Como segunda forma, una moiety puede posicionarse como la primera palabra en un comando de tipo pic, por ejemplo:

CH3 at C + (0.5,0.5)

Aquí la moiety es CH3. Se coloca en una posición relativa a C, una moiety utilizada anteriormente en la estructura química.

Por lo tanto, los nombres de las moieties se pueden especificar como posiciones chem en cualquier lugar del código chem. Debajo de su impresión, las moieties son nombres para lugares.

La moiety BP es especial. No se imprime sino que simplemente sirve como una marca a la que se puede hacer referencia en comandos chem posteriores. Por ejemplo:

bond ; BP

establece una marca al final del enlace. Esto se puede utilizar para especificar una posición. El nombre BP se deriva de branch point (es decir, cruce de línea).

Una cadena entre comillas dobles " se interpreta como parte de un comando chem. Representa una cadena que debe imprimirse (sin las comillas). El texto entre comillas "..." se trata más o menos como una moiety excepto que no se realizan cambios en la parte entrecomillada.

Nombres

En la cadena alquílica anterior, observe que el átomo de carbono C se usó tanto para dibujar algo como para nombrar un lugar. Una moiety siempre define un nombre para un lugar; puedes usar tus propios nombres para lugares en su lugar, y de hecho, para los anillos tendrás que hacerlo. Un nombre es simplemente

Nombre: ...

Nombre es a menudo el nombre de una moiety como CH3, pero no tiene por qué serlo. Cualquier nombre que comience con una letra mayúscula y que contenga solo letras y números es válido:

First:
bond
bond 30 from First

Misceláneos

La construcción específica

bond ... ; moiety

es equivalente a

bond
moiety

De lo contrario, cada elemento debe estar en una línea separada (y solo una línea). Tenga en cuenta que debe haber un espacio en blanco después del punto y coma que separa los comandos.

Un carácter de punto . o una comilla simple ' en la primera columna de una línea indica un comando de troff, que se copia tal cual.

Una línea cuyo primer carácter no sea espacio en blanco sea un símbolo de almohadilla (#) se trata como un comentario y, por lo tanto, se ignora. Sin embargo, los símbolos de almohadilla dentro de una palabra se conservan.

Una línea cuya primera palabra sea pic se copia tal cual después de eliminar la palabra pic.

El comando

size n

escala el diagrama para que parezca plausible a un tamaño de punto de n (el valor predeterminado es 10 puntos).

Cualquier otra cosa se asume que es código pic, que se copia tal cual con una etiqueta.

Dado que chem es un preprocesador pic, es posible incluir sentencias pic en medio de un diagrama para dibujar cosas no proporcionadas por el propio chem. Tales sentencias pic deben incluirse en el código chem agregando pic como la primera palabra de esa línea para mayor claridad.

Los siguientes comandos pic se aceptan como comandos chem, por lo que no se necesita la palabra de comando pic:

define Inicia la definición de una macro pic dentro de chem.
[
Inicia un bloque compuesto.
]
Finaliza un bloque compuesto.
{
Inicia un bloque de definición de macro.
}
Finaliza un bloque de definición de macro.

Los nombres de macros de las declaraciones define se almacenan y su llamada también se acepta como un comando chem.

Lista de deseos

Esta lista de tareas pendientes fue recopilada por Brian Kernighan.

La verificación de errores es mínima; los errores generalmente son detectados y reportados de manera oblicua por pic.

No existe un mecanismo de biblioteca o inclusión de archivos, y no hay una forma abreviada para estructuras repetitivas.

El mecanismo de extensión es crear macros pic, pero estas son difíciles de configurar correctamente y no tienen todas las propiedades de los objetos incorporados.

Aún no hay química en línea (por ejemplo, análoga a la construcción $...$ de eqn).

No hay forma de controlar el punto de entrada para los enlaces en los grupos. Normalmente, un enlace se conecta al átomo de carbono si se entra desde arriba o desde abajo y de lo contrario a la esquina más cercana.

Los enlaces de átomos sustituidos en heterociclos no se unen en el lugar correcto sin agregar un poco de pic.

No existe un primitivo decente para corchetes.

El texto (cadenas entre comillas) no funciona muy bien.

Se necesita un enlace de tipo ondulado (squiggle bond).
