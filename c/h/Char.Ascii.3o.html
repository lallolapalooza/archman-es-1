Char.Ascii - Soporte del conjunto de caracteres ASCII.

Módulo

Módulo Char.Ascii

DOCUMENTACIÓN

Módulo Ascii
: sig end

Soporte del conjunto de caracteres ASCII.

Estas funciones dan significado a los enteros [ 0x00 ; 0x7F ] del conjunto de caracteres ASCII.

Dado que la codificación UTF-8 de Unicode tiene la misma codificación y semántica de caracteres (U+0000 a U+001F) para estos bytes, las funciones se pueden usar de forma segura en elementos de valores de cadena y bytes codificados en UTF-8. Sin embargo, las funciones solo tratan asuntos relacionados con ASCII. Por ejemplo, la noción de espacio en blanco de Unicode es mucho más amplia que el espacio en blanco ASCII determinado por Char.Ascii.is_white.

Desde 5.4

Caracteres

val min : char

min es '\x00'.

val max : char

max es '\x7F'.

Predicados

val is_valid : char -> bool

is_valid c es true si y solo si c es un carácter ASCII, es decir, un byte en el rango [ Char.Ascii.min ; Char.Ascii.max ].

val is_upper : char -> bool

is_upper c es true si y solo si c es una letra mayúscula ASCII 'A' a 'Z', es decir, un byte en el rango [ 0x41 ; 0x5A ].

val is_lower : char -> bool

is_lower c es true si y solo si c es una letra minúscula ASCII 'a' a 'z', es decir, un byte en el rango [ 0x61 ; 0x7A ].

val is_letter : char -> bool

is_letter c es Char.Ascii.is_lower c || Char.Ascii.is_upper c.

val is_alphanum : char -> bool

is_alphanum c es Char.Ascii.is_letter c || Char.Ascii.is_digit c.

val is_white : char -> bool

is_white c es true si y solo si c es un carácter de espacio en blanco ASCII, es decir, uno de tabulador '\t' ( 0x09 ), nueva línea '\n' ( 0x0A ), tabulador vertical ( 0x0B ), salto de página ( 0x0C ), retorno de carro '\r' ( 0x0D ) o espacio ' ' ( 0x20 ),

val is_blank : char -> bool

is_blank c es true si y solo si c es un carácter en blanco ASCII, es decir, espacio ' ' ( 0x20 ) o tabulador '\t' ( 0x09 ).

val is_graphic : char -> bool

is_graphic c es true si y solo si c es un carácter gráfico ASCII, es decir, un byte en el rango [ 0x21 ; 0x7E ].

val is_print : char -> bool

is_print c es Char.Ascii.is_graphic c || c = ' '.

val is_control : char -> bool

is_control c es true si y solo si c es un carácter de control ASCII, es decir, un byte en el rango [ 0x00 ; 0x1F ] o 0x7F.

Dígitos decimales

val is_digit : char -> bool

is_digit c es true si y solo si c es un dígito decimal ASCII '0' a '9', es decir, un byte en el rango [ 0x30 ; 0x39 ].

val digit_to_int : char -> int

digit_to_int c es el valor numérico de un dígito que cumple con Char.Ascii.is_digit. Lanza Invalid_argument si Char.Ascii.is_digit c es false.

val digit_of_int : int -> char

digit_of_int n es un dígito decimal ASCII para el valor decimal abs (n mod 10).

Dígitos hexadecimales

val is_hex_digit : char -> bool

is_hex_digit c es true si y solo si c es un dígito hexadecimal ASCII '0' a '9', 'a' a 'f' o 'A' a 'F', es decir, un byte en uno de los rangos [ 0x30 ; 0x39 ], [ 0x41 ; 0x46 ], [ 0x61 ; 0x66 ].

val hex_digit_to_int : char -> int

hex_digit_to_int c es el valor numérico de un dígito que cumple con Char.Ascii.is_hex_digit. Lanza Invalid_argument si Char.Ascii.is_hex_digit c es false.

val lower_hex_digit_of_int : int -> char

lower_hex_digit_of_int n es un dígito hexadecimal ASCII en minúsculas para el valor hexadecimal abs (n mod 16).

val upper_hex_digit_of_int : int -> char

upper_hex_digit_of_int n es un dígito hexadecimal ASCII en mayúsculas para el valor hexadecimal abs (n mod 16).

Transformaciones de mayúsculas/minúsculas

val uppercase : char -> char

uppercase c es c con los caracteres ASCII 'a' a 'z' mapeados respectivamente a caracteres en mayúscula 'A' a 'Z'. Otros caracteres se dejan sin cambios.

val lowercase : char -> char

lowercase c es c con los caracteres ASCII 'A' a 'Z' mapeados respectivamente a caracteres en minúscula 'a' a 'z'. Otros caracteres se dejan sin cambios.
