CHCP(8) Manual del Administrador del Sistema CHCP(8)

NOMBRE

chcp - cambiar el modo de los puntos de control de NILFS2

SINOPSIS

chcp [opciones] cp | ss [dispositivo] número-de-punto-de-control ...

DESCRIPCIÓN

chcp es una utilidad para cambiar el modo de los puntos de control especificados para el sistema de archivos NILFS2 encontrado en dispositivo. chcp cambia los puntos de control a instantáneas, o viceversa. Los puntos de control de destino se especifican con uno o más números de punto de control. Cuando se omite dispositivo, intenta encontrar un sistema de archivos NILFS2 en /proc/mounts.

Este comando solo es válido para sistemas de archivos NILFS2 montados y fallará si el dispositivo no tiene montajes activos.

OPCIONES

-h, --help
Muestra el mensaje de ayuda y sale.
-V, --version
Muestra la versión y sale.

AUTOR

Koji Sato

DISPONIBILIDAD

chcp es parte del paquete nilfs-utils y está disponible en https://nilfs.sourceforge.io.

VER TAMBIÉN

nilfs(8), lscp(1), mkcp(8), rmcp(8), nilfs-tune(8).
