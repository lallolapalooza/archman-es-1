NOMBRE

chsh.ldap - cambiar el shell de inicio de sesión en LDAP

SINOPSIS


chsh.ldap
[opciones] [INICIO_SESION]

DESCRIPCIÓN

El comando chsh.ldap se puede utilizar para cambiar el shell de inicio de sesión (intérprete de comandos) del usuario.

El cambio real en LDAP lo realiza el demonio nslcd y está sujeto a los controles de acceso configurados en el servidor LDAP.

OPCIONES

Las opciones que se pueden especificar para el comando chsh.ldap son:

-s, --shell SHELL
El nombre del nuevo shell de inicio de sesión del usuario. Establecer este campo en blanco hace que el sistema seleccione el shell de inicio de sesión predeterminado.
-l, --list-shells
Imprimir la lista de shells que se encuentran en /etc/shells y salir.
-h, --help
Mostrar ayuda breve y salir.
-V, --version
Mostrar información de la versión y salir.

Si no se especifica ninguna opción, chsh.ldap le pedirá al usuario que introduzca un valor para el shell.

ARCHIVOS

/etc/shells - lista de shells de inicio de sesión válidos

VER TAMBIÉN

chsh(1), shells(5), nslcd(8)
