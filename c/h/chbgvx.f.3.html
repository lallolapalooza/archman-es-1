IFAIL

!>          IFAIL es un arreglo de tipo INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los autovectores que no lograron converger.
!>          Si JOBZ = 'N', entonces IFAIL no es referenciado.
!>

INFO

!>          INFO es de tipo INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es:
!>             <= N:  entonces i autovectores no lograron converger. Sus
!>                    índices se almacenan en el arreglo IFAIL.
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces CPBSTF
!>                    devolvió INFO = i: B no es definida positiva.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon autovalores ni autovectores.
!>
