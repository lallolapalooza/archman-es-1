CHICKEN-DO(1) Manual de comandos generales CHICKEN-DO(1)

NOMBRE

chicken-do — ejecuta un comando de shell a menos que el objetivo exista y ninguna dependencia sea más reciente que el objetivo

SINOPSIS

chicken-do [-q] [-h] [--] OBJETIVO ... : DEPENDENCIA ... : COMANDO ...

DESCRIPCIÓN

Si los archivos OBJETIVO ... no existen, o si alguno de los archivos en DEPENDENCIA ... es más reciente que uno de los archivos objetivo, entonces ejecuta los comandos del shell en COMANDO ....

El programa acepta las siguientes opciones:

-h
Muestra el uso y sale.
-q
Operación silenciosa: no imprime los comandos del shell cuando se ejecutan.
--
Trata todos los tokens siguientes como nombres de archivo objetivo, incluso si comienzan con un carácter -.

ESTADO DE SALIDA

La utilidad chicken-do sale con 0 en caso de éxito, y >0 si ocurre un error.

EJEMPLOS

Compila un programa C a partir de fuentes:

$ chicken-do prg: prg.c inc.h: gcc prg.c -o prg

VER TAMBIÉN

chicken(1), chicken-status(1), chicken-install(1), chicken-uninstall(1), csc(1)

Se puede encontrar más información en el Manual del Usuario de CHICKEN.
