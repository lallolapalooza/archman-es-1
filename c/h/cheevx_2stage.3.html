subrutina cheevx_2stage (character jobz, character range, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

CHEEVX_2STAGE calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices HE

Propósito:

!>
!> CHEEVX_2STAGE calcula los eigenvalores seleccionados y, opcionalmente, los eigenvectores
!> de una matriz hermitiana compleja A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Los eigenvalores y eigenvectores pueden
!> ser seleccionados especificando un rango de valores o un rango de
!> índices para los eigenvalores deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo eigenvalores;
!>          = 'V':  Calcular eigenvalores y eigenvectores.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los eigenvalores.
!>          = 'V': se encontrarán todos los eigenvalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los eigenvalores desde el índice IL hasta el IU.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA, N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior principal N-por-N de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior principal N-por-N de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo en el que
!>          se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo en el que
!>          se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los eigenvalores.
!>          Un eigenvalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los eigenvalores se calcularán con mayor precisión cuando ABSTOL se
!>          establezca al doble del umbral de underflow 2*SLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          eigenvectores no convergieron, intente establecer ABSTOL a
!>          2*SLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un arreglo REAL, dimensión (N)
!>          En la salida normal, los primeros M elementos contienen los
!>          eigenvalores seleccionados en orden ascendente.
!>

Z

!>          Z es un arreglo COMPLEX, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los eigenvectores ortonormales de la matriz A
!>          correspondientes a los eigenvalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el eigenvector asociado con W(i).
!>          Si un eigenvector falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al eigenvector, y el
!>          índice del eigenvector se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas en
!>          el arreglo Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar una cota superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del arreglo Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del arreglo WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, 8*N, dimension) donde
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + N
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo usado por el algoritmo QR o LQ,
!>                                   usualmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos usados cuando
!>                                   la compilación con openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

RWORK

NAME


cheevx_2stage - Computes the eigenvalues and eigenvectors of a complex
    Hermitian matrix using the 2stage approach.

 !> INTEGER

 !>

 !> DOUBLE PRECISION
 !> If RANGE='V', the lower and upper bounds of the interval to be
 !> searched for eigenvalues.
 !>
 !> Il, Iu
 !> INTEGER
 !> If RANGE='I', the indices of the first and last eigenvalues to be
 !> computed, given that the eigenvalues are sorted in increasing order.
 !>
 !> Abstol
 !> DOUBLE PRECISION
 !> The absolute tolerance for comparing eigenvalues to the interval [VL, VU]
 !> when RANGE='V', or for comparing eigenvalues to W(I) when RANGE='I'.

 !>
 !> M
 !> INTEGER
 !> The total number of eigenvalues found.
 !>
 !> W
 !> DOUBLE PRECISION array, dimension (N)
 !> Stores the computed eigenvalues.
 !>
 !> Z
 !> COMPLEX*16 array, dimension (LDZ, N)
 !> If JOBZ = 'V', Z stores the computed eigenvectors.
 !> The normalized eigenvectors, such that the column Z(:,I) is the eigenvector

 !>
 !> Ldz
 !> INTEGER
 !> The leading dimension of the array Z.
 !> If JOBZ = 'V', Ldz >= max(1, N).
 !>
 !> WORK
 !> COMPLEX*16 array, dimension (LWORK)
 !> Workspace array.
 !>
 !> Lwork
 !> INTEGER
 !> The dimension of the array WORK.
 !> LWORK >= 2*N
 !> If LWORK = -1, then LWORK is an optimal dimension.
 !>
 !> RWORK
 !> REAL array, dimension (LRWORK)
 !> Real workspace array.
 !>
 !> LRWORK
 !> INTEGER
 !> The dimension of the array RWORK.
 !> LRWORK >= max(N, 2*N)
 !> If LRWORK = -1, then LRWORK is an optimal dimension.
 !>
 !> IWORK
 !> INTEGER array, dimension (LIWORK)
 !> Integer workspace array.
 !>
 !> LIWORK
 !> INTEGER
 !> The dimension of the array IWORK.
 !> LIWORK >= 5*N
 !> If LIWORK = -1, then LIWORK is an optimal dimension.

 !> INFO
 !> INTEGER
