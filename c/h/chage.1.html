CHAGE(1) Comandos de usuario CHAGE(1)

NOMBRE

chage - cambiar la información de caducidad de la contraseña del usuario

SINOPSIS

chage [opciones] LOGIN

DESCRIPCIÓN

El comando chage cambia la información de caducidad de la contraseña de un usuario. Establece el número de días entre cambios de contraseña y la fecha del último cambio de contraseña. Esta información es utilizada por el sistema para determinar cuándo el usuario debe cambiar su contraseña.

OPCIONES

Las opciones que se aplican al comando chage son:

-d, --lastday ÚLTIMO_DÍA

Establece la fecha en que la contraseña fue cambiada por última vez. El valor puede especificarse como una fecha en formato YYYY-MM-DD o como un número de días desde 1970-01-01. La fecha se interpreta utilizando la zona horaria UTC. Si ÚLTIMO_DÍA se establece en 0, se obliga al usuario a cambiar su contraseña en el próximo inicio de sesión.

Pasar el valor -1 o una cadena vacía como ÚLTIMO_DÍA borra el valor y elimina el requisito de cambio de contraseña.

-E, --expiredate FECHA_CADUCIDAD

Establece la fecha en que caducará la contraseña del usuario y su cuenta ya no será accesible. El valor puede especificarse como una fecha en formato YYYY-MM-DD o como un número de días desde 1970-01-01. La fecha se interpreta utilizando la zona horaria UTC. Si la contraseña caduca, el usuario debe contactar al administrador del sistema para recuperar el acceso al sistema.

Por ejemplo, el siguiente comando establece una cuenta para que caduque en 180 días:

chage -E $(date -d +180days +%F)

Pasar el valor -1 o una cadena vacía como FECHA_CADUCIDAD elimina la fecha de caducidad de la cuenta.

-h, --help

Muestra el mensaje de ayuda y sale.

-i, --iso8601

Al mostrar fechas, utiliza el formato YYYY-MM-DD.

-I, --inactive INACTIVO

Establece el número de días de inactividad después de que una contraseña haya caducado antes de que la cuenta se bloquee. La opción INACTIVO es el número de días de inactividad. Un usuario cuya cuenta está bloqueada debe contactar al administrador del sistema antes de poder usar el sistema nuevamente.

Pasar el número -1 como INACTIVO eliminará la inactividad de una cuenta.

-l, --list

Muestra la información de envejecimiento de la cuenta.

-m, --mindays DÍAS_MÍN

Establece el número mínimo de días entre cambios de contraseña a DÍAS_MÍN. Un valor de cero para este campo indica que el usuario puede cambiar su contraseña en cualquier momento.

-M, --maxdays DÍAS_MÁX

Establece el número máximo de días durante los cuales una contraseña es válida. Cuando DÍAS_MÁX más ÚLTIMO_DÍA es menor que el día actual, se requerirá que el usuario cambie su contraseña antes de poder usar su cuenta. Esta ocurrencia puede planificarse con anticipación mediante el uso de la opción -W, que proporciona al usuario una advertencia anticipada.

Pasar el número -1 como DÍAS_MÁX eliminará la verificación de la validez de una contraseña.

-R, --root DIRECTORIO_CHROOT

Aplica cambios en el directorio DIRECTORIO_CHROOT y utiliza los archivos de configuración del directorio DIRECTORIO_CHROOT. Solo se admiten rutas absolutas.

-P, --prefix DIRECTORIO_PREFIJO

Aplica cambios a los archivos de configuración bajo el sistema de archivos raíz que se encuentra en el directorio DIRECTORIO_PREFIJO. Esta opción no realiza chroot y está destinada a preparar un objetivo de compilación cruzada. Algunas limitaciones: los usuarios/grupos NIS y LDAP no se verifican. No hay soporte SELINUX.

-W, --warndays DÍAS_ADVERTENCIA

Establece el número de días de advertencia antes de que se requiera un cambio de contraseña. La opción DÍAS_ADVERTENCIA es el número de días antes de que la contraseña caduque en los que se advertirá al usuario de que su contraseña está a punto de caducar.

Si no se selecciona ninguna de las opciones, chage opera de forma interactiva, solicitando al usuario los valores actuales de todos los campos. Ingrese el nuevo valor para cambiar el campo, o deje la línea en blanco para usar el valor actual. El valor actual se muestra entre corchetes [ ].

NOTA

El programa chage requiere que un archivo de contraseñas shadow esté disponible.

El programa chage solo informará la información del archivo de contraseñas shadow. Esto implica que la configuración de otras fuentes (por ejemplo, LDAP o el campo de hash de contraseña vacío del archivo passwd) que afectan el inicio de sesión del usuario no se mostrarán en la salida de chage.

El programa chage tampoco informará ninguna inconsistencia entre los archivos shadow y passwd (por ejemplo, la falta de 'x' en el archivo passwd). El comando pwck puede usarse para verificar este tipo de inconsistencias.

El comando chage está restringido al usuario root, excepto para la opción -l, que puede ser utilizada por un usuario no privilegiado para determinar cuándo su contraseña o cuenta debe caducar.

CONFIGURACIÓN

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de esta herramienta:

ARCHIVOS

/etc/passwd

Información de la cuenta de usuario.

/etc/shadow

Información segura de la cuenta de usuario.

VALORES DE SALIDA

El comando chage sale con los siguientes valores:

0

éxito

1

permiso denegado

2

sintaxis de comando inválida

15

no se puede encontrar el archivo de contraseñas shadow
