CHACL(1) Listas de control de acceso CHACL(1)

NOMBRE

chacl - cambiar la lista de control de acceso de un archivo o directorio

SINOPSIS

chacl acl pathname...
chacl -b acl dacl pathname...
chacl -d dacl pathname...
chacl -R pathname...
chacl -D pathname...
chacl -B pathname...
chacl -l pathname...
chacl -r pathname...

DESCRIPCIÓN

chacl es un comando de compatibilidad con IRIX, y se mantiene para aquellos usuarios que están familiarizados con su uso en XFS o IRIX. Consulte la sección VER TAMBIÉN a continuación para obtener una descripción de las herramientas que se ajustan más estrechamente al estándar POSIX 1003.1e (borrador retirado) que describe las Listas de Control de Acceso (ACLs).

chacl cambia las ACL(s) de un archivo o directorio. Las ACL(s) especificadas se aplican a cada archivo en los argumentos pathname.

Cada ACL es una cadena que se interpreta utilizando la rutina acl_from_text(3). Estas cadenas están compuestas por cláusulas separadas por comas, cada una de las cuales tiene el formato tag:nombre:perm. Donde tag puede ser:

"user" (o "u")
indicando que la entrada es una entrada ACL de "usuario".
"group" (o "g")
indicando que la entrada es una entrada ACL de "grupo".
"other" (o "o")
indicando que la entrada es una entrada ACL de "otro".
"mask" (o "m")
indicando que la entrada es una entrada ACL de "máscara".

nombre es una cadena que representa el nombre de usuario o grupo para la entrada ACL. Un nombre nulo en una entrada ACL de usuario o grupo indica el propietario del archivo o el grupo del archivo. perm es la cadena "rwx" donde cada una de las entradas puede ser reemplazada por un "-" que indica que no hay acceso de ese tipo, por ejemplo, "r-x", "--x", "---".

OPCIONES

-b
Indica que hay dos ACLs que cambiar, la primera es la ACL de acceso del archivo y la segunda es la ACL predeterminada del directorio.
-d
Se utiliza para establecer solo la ACL predeterminada de un directorio.
-R
Elimina solo la ACL de acceso del archivo.
-D
Elimina solo la ACL predeterminada del directorio.
-B
Elimina todas las ACLs.
-l
Lista la ACL de acceso y posiblemente la ACL predeterminada asociada con los archivos o directorios especificados. Esta opción se agregó durante la portabilidad de XFS a Linux y no es compatible con IRIX.
-r
Establece la ACL de acceso recursivamente para cada subárbol con raíz en los pathname. Esta opción también se agregó durante la portabilidad de XFS a Linux y no es compatible con IRIX.

EJEMPLOS

Una ACL mínima:

  chacl u::rwx,g::r-x,o::r-- archivo

La ACL del archivo se establece para que el propietario del archivo tenga "rwx", el grupo del archivo tenga lectura y ejecución, y los demás solo tengan acceso de lectura al archivo.

Una ACL que no es mínima, es decir, una que especifica un usuario o grupo que no sea el propietario del archivo o el grupo del propietario, debe contener una entrada de máscara:

  chacl u::rwx,g::r-x,o::r--,u:bob:r--,m::r-x archivo1 archivo2

Para establecer las ACLs predeterminada y de acceso en nuevodir para que sean las mismas que en dirantiguo, puede escribir:

  chacl -b `chacl -l dirantiguo | \
      sed -e 's/.*\[//' -e 's#/# #' -e 's/]$//'` nuevodir

PRECAUCIONES

chacl puede reemplazar la ACL existente. Para agregar o eliminar entradas, primero debe ejecutar chacl -l para obtener la ACL existente y usar la salida para formar los argumentos para chacl.

Cambiar los bits de permisos de un archivo cambiará la configuración de la ACL de acceso del archivo (ver chmod(1)). Sin embargo, las máscaras de modo de creación de archivos (ver umask(1)) no afectarán la configuración de la ACL de acceso de los archivos creados utilizando las ACLs predeterminadas del directorio.

Las ACLs son atributos extendidos del sistema de archivos y, por lo tanto, no suelen archivarse ni restaurarse utilizando las utilidades de archivo convencionales. Consulte attr(5) para obtener más información sobre atributos extendidos y consulte xfsdump(8) para conocer un método para hacer copias de seguridad bajo XFS.
