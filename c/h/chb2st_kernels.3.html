Documentación de Función/Subrutina

subrutina chb2st_kernels (character uplo, logical wantz, integer ttype, integer st, integer ed, integer sweep, integer n, integer nb, integer ib, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) v, complex, dimension( * ) tau, integer ldvt, complex, dimension( * ) work)

CHB2ST_KERNELS

Propósito:

!>
!> CHB2ST_KERNELS es una rutina interna utilizada por la subrutina CHETRD_HB2ST.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>

WANTZ

!>          WANTZ es LOGICAL, indica si se solicitan los valores propios o
!>          tanto los valores como los vectores propios.
!>

TTYPE

!>          TTYPE es INTEGER
!>

ST

!>          ST es INTEGER
!>          Parámetro interno para índices.
!>

ED

!>          ED es INTEGER
!>          Parámetro interno para índices.
!>

SWEEP

!>          SWEEP es INTEGER
!>          Parámetro interno para índices.
!>

N

!>          N es INTEGER. El orden de la matriz A.
!>

NB

!>          NB es INTEGER. El tamaño de la banda.
!>

IB

!>          IB es INTEGER.
!>

A

!>          A es un array de tipo COMPLEX. Un puntero a la matriz A.
!>

LDA

!>          LDA es INTEGER. La dimensión principal de la matriz A.
!>

V

!>          V es un array de tipo COMPLEX, dimensión 2*n si solo se solicitan
!>          valores propios o se consultan vectores.
!>

TAU

!>          TAU es un array de tipo COMPLEX, dimensión (2*n).
!>          Los factores escalares de los reflectores de Householder se almacenan
!>          en este array.
!>

LDVT

!>          LDVT es INTEGER.
!>

WORK

!>          WORK es un array de tipo COMPLEX. Espacio de trabajo de tamaño nb.
!>
