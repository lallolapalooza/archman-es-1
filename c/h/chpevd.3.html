subrutina chpevd (jobz, uplo, n, ap, w, z, ldz, work, lwork, rwork, lrwork, iwork, liwork, info)
CHPEVD calcula los valores y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Documentación de Función/Subrutina

subrutina chpevd (carácter jobz, carácter uplo, entero n, complejo, dimensión( * ) ap, real, dimensión( * ) w, complejo, dimensión( ldz, * ) z, entero ldz, complejo, dimensión( * ) work, entero lwork, real, dimensión( * ) rwork, entero lrwork, entero, dimensión( * ) iwork, entero liwork, entero info)

CHPEVD calcula los valores y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Propósito:

!>
!> CHPEVD calcula todos los valores y, opcionalmente, vectores propios de
!> una matriz Hermitiana compleja A en almacenamiento empaquetado. Si se desean vectores propios,
!> utiliza un algoritmo de división y conquista.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo valores propios;
!>          = 'V':  Calcular valores y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEJO, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          A, empaquetado columna por columna en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, AP se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la diagonal
!>          y la primera superdiagonal de la matriz tridiagonal T sobrescriben
!>          los elementos correspondientes de A, y si UPLO = 'L', la
!>          diagonal y la primera subdiagonal de T sobrescriben los
!>          elementos correspondientes de A.
!>

W

!>          W es un array REAL, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array COMPLEJO, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores propios
!>          ortonormales de la matriz A, con la i-ésima columna de Z
!>          conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es ENTERO
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK requerido.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser al menos N.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser al menos 2*N.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños requeridos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array REAL, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK requerido.
!>

LRWORK

!>          LRWORK es ENTERO
!>          La dimensión del array RWORK.
!>          Si N <= 1,               LRWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LRWORK debe ser al menos N.
!>          Si JOBZ = 'V' y N > 1, LRWORK debe ser al menos
!>                    1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños requeridos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array ENTERO, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK requerido.
!>

LIWORK

!>          LIWORK es ENTERO
!>          La dimensión del array IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK debe ser al menos 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños requeridos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo no convergió; i
!>                elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                no convergieron a cero.
!>
