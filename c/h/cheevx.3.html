Documentación de Función/Subrutina

subrutina cheevx (character jobz, character range, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

CHEEVX calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos de matrices HE

Propósito:

!>
!> CHEEVX calcula los eigenvalores seleccionados y, opcionalmente, los eigenvectores
!> de una matriz hermitiana compleja A. Los eigenvalores y eigenvectores pueden
!> seleccionarse especificando un rango de valores o un rango de
!> índices para los eigenvalores deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores;
!>          = 'V':  Calcula los eigenvalores y los eigenvectores.
!>

RANGO

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los eigenvalores.
!>          = 'V': se encontrarán todos los eigenvalores en el intervalo abierto por la derecha (VL,VU]
!>          = 'I': se encontrarán los eigenvalores desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA, N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior de A de tamaño N por N principal contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior de A de tamaño N por N principal contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo donde
!>          se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo donde
!>          se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los eigenvalores.
!>          Un eigenvalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los eigenvalores se calcularán con mayor precisión cuando ABSTOL se
!>          establezca al doble del umbral de desbordamiento inferior 2*SLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          eigenvectores no convergieron, intente establecer ABSTOL a
!>          2*SLAMCH('S').
!>
!>          Vea  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array REAL, dimensión (N)
!>          En la salida normal, los primeros M elementos contienen los eigenvalores
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es un array COMPLEX, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los eigenvectores ortonormales de la matriz A
!>          correspondientes a los eigenvalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el eigenvector asociado con W(i).
!>          Si un eigenvector no converge, entonces esa columna de Z
!>          contiene la última aproximación al eigenvector, y el
!>          índice del eigenvector se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar una cota superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= 1, cuando N <= 1;
!>          de lo contrario 2*N.
!>          Para una eficiencia óptima, LWORK >= (NB+1)*N,
!>          donde NB es el máximo del tamaño de bloque para CHETRD y para
!>          CUNMTR como lo devuelve ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

RWORK

!>          RWORK es un array REAL, dimensión (7*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (5*N)
!>

IFAIL

!>          IFAIL es un array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los eigenvectores que no convergieron.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, entonces i eigenvectores no convergieron.
!>                Sus índices se almacenan en el array IFAIL.
!>

NAME

cheevx - real general matrix eigenvalue/vector problem.

   JOBZ, LAYOUT, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL,

INTEGER N, LDA, LDZ, INFO

Function/Subroutine Documentation

JOBZ

CHARACTER*1. Required argument.

JOBZ ='N': Compute only the eigenvalues of A.

JOBZ ='V': Compute the eigenvalues and eigenvectors of A.

LAYOUT

CHARACTER*1. Input argument.

On entry, LAYOUT specifies the storage format of the matrices A and Z and the layout of the eigenvectors Z. LAYOUT = 'C' => Column-major storage; LAYOUT = 'R' => Row-major storage.

UPLO

CHARACTER*1. Input argument.

On entry, UPLO specifies whether the upper or lower triangular part of the Hermitian matrix A is to be used and how the matrix is stored in the arrays A and Z.

UPLO ='U': Upper triangle of A is to be used.

UPLO ='L': Lower triangle of A is to be used.

N

INTEGER. Input argument.

The order of the matrix A. N >= 0.

A

COMPLEX A( LDA, * ). Input argument.

On entry, the complex upper or lower triangular hermitian matrix A. The following represent

LDA

INTEGER. Input argument.

On entry, LDA is the leading dimension of the array A (or Z, if LAYOUT = 'C'). LDA.

VL

REAL. Input argument.

If JOBZ ='V' and IL = 0 and IU = 0, then VL and VU define the range of interest for the eigenvalues.

The \\(k\\)-th eigenvalue \\( \lambda_k \\) satisfies VL <= \\( \lambda_k \\) <= VU.

The range VL <= \\( \lambda_k \\) <= VU is an interval.

VU

REAL. Input argument.

If JOBZ ='V' and IL = 0 and IU = 0, then VL and VU define the range of interest for the eigenvalues.

The \\(k\\)-th eigenvalue \\( \lambda_k \\) satisfies VL <= \\( \lambda_k \\) <= VU.

The range VL <= \\( \lambda_k \\) <= VU is an interval.

IL

INTEGER. Input argument.

If JOBZ ='V' and IL = 0 and IU = 0, then IL and IU specify the integers that the desired eigenvalues are the IL-th to the IU-th smallest eigenvalues.

If IL = 0 and IU = 0, then VL and VU are used to specify the range of desired eigenvalues.

IU

INTEGER. Input argument.

If JOBZ ='V' and IL = 0 and IU = 0, then IL and IU specify the integers that the desired eigenvalues are the IL-th to the IU-th smallest eigenvalues.

If IL = 0 and IU = 0, then VL and VU are used to specify the range of desired eigenvalues.

ABSTOL

REAL. Input argument.

The absolute tolerance for the eigenvalues for which eigenvectors are to be computed.

An eigenvalue \\( \lambda \\) is considered to be within the interval [VL, VU] if \\( | \lambda - \nu | \le ABSTOL \\), where \\( \nu \\) is the closest endpoint of the interval.

W

COMPLEX W( * ). Output argument.

On exit, the estimated \(\mathrm{N}\) eigenvalues of the matrix A. The eigenvalues are sorted in increasing order.

Z

COMPLEX Z( LDA, * ). Output argument.

On exit, if JOBZ ='V', then the approximate eigenvectors, the eigenvector v_i of the matrix A in the i-th column of Z. The latter is normalized to have unit length.

LDZ

INTEGER. Input argument.

On entry, LDA is the leading dimension of the array Z. LDA.

WORK

COMPLEX WORK( * ). Workspace

RWORK

REAL RWORK( * ). Workspace

INFO

INTEGER. Output argument.

If INFO = 0, the execution is successful.

If INFO < 0, the \\(i\\)-th argument is an internal error (\(1 \le |i| \le 10\)), or the \\(i\\)-th argument is invalid.

If INFO > 0, the algorithm did not converge, and INFO indicates the number of eigenvalues that could not be computed.

INFO is an Integer, the rank of A, and the number of diagonal entries of SUB( A ) that are equal to zero.
