Chart::Font(3pm) Documentación de Perl contribuida por el usuario Chart::Font(3pm)

NOMBRE

Chart::Font - objetos de lectura única que contienen fuentes

SINOPSIS

my $red = Chart::Color->new('red');
say $red->add('blue')->name;              # magenta, mezclado en espacio RGB
Chart::Color->new( 0, 0, 255)->hsl        # 240, 100, 50 = azul
$blue->blend_with({H=> 0, S=> 0, L=> 80}, 0.1);# mezcla azul con un poco de gris
$red->gradient( '#0000FF', 10);           # 10 colores de rojo a azul  
$red->complementary( 3 );                 # obtener rojo, verde y azul complementarios
