CHICKEN-INSTALL(1) Manual de Comandos Generales CHICKEN-INSTALL(1)

NOMBRE

chicken-install — descargar e instalar bibliotecas de extensiones para CHICKEN Scheme

SINOPSIS

chicken-install [OPCIÓN ...] [NOMBRE[:VERSIÓN] ...]

DESCRIPCIÓN

chicken-install descarga, compila e instala una biblioteca de extensiones preempaquetada a partir del código fuente. Si no se proporciona ningún nombre de extensión en la línea de comandos, se ejecutarán todas las descripciones de egg existentes en el directorio actual en un orden no especificado.

El programa acepta los siguientes argumentos:

-h, -help
Muestra el uso y sale.
-version
Muestra la versión y sale.
-v, -verbose
Imprime información adicional durante la instalación.
-force
Instala sin confirmación, incluso si las versiones no coinciden.
-k, -keep
Conserva los archivos temporales.
-s, -sudo
Usa un programa externo para elevar privilegios para las operaciones del sistema de archivos. El programa por defecto es sudo(8) pero se puede anular con la variable de entorno SUDO .
-r, -retrieve
Solo recupera el egg, no lo instala (indicar -r más de una vez implica -recursive).
-recursive
Si se indica -retrieve , también obtiene las dependencias recursivamente.
-dry-run
No compila ni instala, solo imprime las ubicaciones de los scripts de compilación e instalación generados.
-list-versions
Lista las versiones disponibles para los eggs dados.
-purge
Elimina los archivos en caché de los eggs dados (o purga la caché completamente).
-host
Al compilar cruzadamente, solo compila extensiones para el host.
-target
Al compilar cruzadamente, solo compila extensiones para el destino.
-test
Ejecuta los casos de prueba incluidos, si están disponibles.
-n, -no-install
No instala el egg, solo lo compila.
-no-install-dependencies
No instala las dependencias. Tenga en cuenta que esta opción puede provocar fallos de compilación debido a bibliotecas de extensiones faltantes.
-u, -update-db
Actualiza la base de datos de exportación.
-repository
Imprime la ruta utilizada para la instalación de eggs.
-override nombre_archivo
Anula las versiones de los eggs instalados con la información de nombre_archivo.
-from-list nombre_archivo
Instala los eggs listados en nombre_archivo, que tiene el mismo formato que la salida de chicken-status(1)'s -list . Esta opción puede indicarse varias veces.
-cached
Solo instala eggs desde la caché, no descarga.
-l, -location directorio
Obtiene los fuentes de los eggs del directorio dado. Puede proporcionarse varias veces. Las ubicaciones especificadas en la línea de comandos tienen prioridad sobre las especificadas en setup.defaults.
-feature, -D nombre
Registra la característica nombre, utilizable como condición en cláusulas cond-expand.

ENTORNO

Las siguientes variables de entorno cambian el comportamiento de chicken-install:

CHICKEN_EGG_CACHE
Ubicación donde se recuperan y compilan los eggs.
CHICKEN_INSTALL_PREFIX
El prefijo de ruta para todos los archivos de destino, tal como se dio al construir el sistema. Use esta variable para anular dónde se deben instalar los programas, los archivos de inclusión y los archivos de datos adicionales.
CHICKEN_INSTALL_REPOSITORY
La ruta donde se instalan las bibliotecas de extensiones. Por defecto es la ruta de la biblioteca del paquete seleccionada durante la configuración (normalmente $prefix/lib/chicken/<binary-version>). Tenga en cuenta que esta variable tiene prioridad sobre CHICKEN_INSTALL_PREFIX.
SUDO
El comando a ejecutar cuando se usa el indicador -s en el comando. Si no se proporciona, por defecto es sudo(8).

ARCHIVOS

$XDG_CONFIG_HOME/chicken/setup.defaults
Archivo setup.defaults específico del usuario. ( $XDG_CONFIG_HOME por defecto es $HOME/.config )
$prefix/share/chicken/setup.default
Archivo setup.defaults de todo el sistema.
$XDG_CACHE_HOME/chicken-install/
Directorio por defecto para los eggs en caché. ( $XDG_CACHE_HOME por defecto es $HOME/.cache )

ESTADO DE SALIDA

La utilidad chicken-install sale con 0 en caso de éxito, 2 si el usuario abortó una operación, 3 si se invocó sin nombres de egg dados explícitamente y no se encontraron archivos *.egg en el directorio actual, y >0 si ocurre cualquier otro error.

EJEMPLOS

Instalar el egg ‘regex’ como usuario root:

# chicken-install regex

Instalar un egg como usuario normal pero usando sudo(8):

$ chicken-install -s regex

Instalar un egg como usuario normal pero elevando privilegios con un programa diferente, como doas(1)de OpenBSD:

$ SUDO=/usr/bin/doas chicken-install -s regex
