subrutina chet01 (carácter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldafac, * ) afac, entero ldafac, entero, dimensión( * ) ipiv, complejo, dimensión( ldc, * ) c, entero ldc, real, dimensión( * ) rwork, real resid)

CHET01

Propósito:

!>
!> CHET01 reconstruye una matriz Hermítica indefinida A a partir de su
!> factorización en bloque L*D*L' o U*D*U' y calcula el residuo
!>    norma( C - A ) / ( N * norma(A) * EPS ),
!> donde C es la matriz reconstruida, EPS es la epsilon de la máquina,
!> L' es la transpuesta conjugada de L, y U' es la transpuesta conjugada
!> de U.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es ENTERO
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          La matriz Hermítica original A.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC es un array COMPLEJO, dimensión (LDAFAC,N)
!>          La forma factorizada de la matriz A. AFAC contiene la matriz
!>          diagonal de bloques D y los multiplicadores utilizados para
!>          obtener L o U de la factorización en bloque L*D*L' o U*D*U'
!>          tal como es calculada por CHETRF.
!>

LDAFAC

!>          LDAFAC es ENTERO
!>          La dimensión principal del array AFAC.  LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>          Los índices de pivote de CHETRF.
!>

C

!>          C es un array COMPLEJO, dimensión (LDC,N)
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal del array C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

RESID

!>          RESID es REAL
!>          Si UPLO = 'L', norma(L*D*L' - A) / ( N * norma(A) * EPS )
!>          Si UPLO = 'U', norma(U*D*U' - A) / ( N * norma(A) * EPS )
!>
