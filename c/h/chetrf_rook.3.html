Funciones/Subrutinas


subrutina chetrf_rook (uplo, n, a, lda, ipiv, work, lwork, info)
CHETRF_ROOK calcula la factorización de una matriz Hermitiana indefinida compleja utilizando el método de pivoteo de diagonal de Bunch-Kaufman limitado (rook") (algoritmo con bloques, llamando a BLAS de Nivel 3).

Documentación de función/subrutina

subrutina chetrf_rook (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CHETRF_ROOK calcula la factorización de una matriz Hermitiana indefinida compleja utilizando el método de pivoteo de diagonal de Bunch-Kaufman limitado ("rook").

Propósito:

!>
!> CHETRF_ROOK calcula la factorización de una matriz Hermitiana compleja A
!> utilizando el método de pivoteo de diagonal de Bunch-Kaufman limitado.
!> La forma de la factorización es
!>
!>    A = U*D*U**T  o  A = L*D*L**T
!>
!> donde U (o L) es un producto de permutaciones y matrices triangulares unitarias superiores (inferiores), y D es Hermitiana y diagonal por bloques con
!> bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión con bloques del algoritmo, llamando a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX de dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A. Si UPLO = 'U', la parte
!>          superior de N x N de A contiene la parte triangular superior de
!>          la matriz A, y la parte estrictamente inferior triangular de A
!>          no se referencia. Si UPLO = 'L', la parte inferior de N x N
!>          de A contiene la parte triangular inferior de la matriz A, y la
!>          parte estrictamente superior triangular de A no se referencia.
!>
!>          En la salida, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L (ver más abajo para más detalles).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>
!>          Si UPLO = 'U':
!>             Solo los últimos KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>             columnas k e IPIV(k) fueron intercambiadas y las filas y
!>             columnas k-1 e IPIV(k-1) fueron intercambiadas,
!>             D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>             Solo los primeros KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>             fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>             columnas k e IPIV(k) fueron intercambiadas y las filas y
!>             columnas k+1 e IPIV(k+1) fueron intercambiadas,
!>             D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

WORK

!>          WORK es un array COMPLEX de dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1.  Para un rendimiento óptimo,
!>          LWORK >= N*NB, donde NB es el tamaño del bloque devuelto por ILAENV.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tuvo un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero. La factorización
!>                se ha completado, pero la matriz diagonal por bloques D es
!>                exactamente singular, y ocurrirá una división por cero si
!>                se utiliza para resolver un sistema de ecuaciones.
!>

Detalles adicionales:

!>
!>  Si UPLO = 'U', entonces A = U*D*U**T, donde
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  es decir, U es un producto de términos P(k)*U(k), donde k disminuye de n a
!>  1 en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k). P(k) es una matriz de permutación como
!>  se define por IPIV(k), y U(k) es una matriz triangular unitaria superior, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(1:k-1,k).
!>  Si s = 2, el triángulo superior de D(k) sobrescribe A(k-1,k-1), A(k-1,k),
!>  y A(k,k), y v sobrescribe A(1:k-2,k-1:k).
!>
!>  Si UPLO = 'L', entonces A = L*D*L**T, donde
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  es decir, L es un producto de términos P(k)*L(k), donde k aumenta de 1 a
!>  n en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k). P(k) es una matriz de permutación como
!>  se define por IPIV(k), y L(k) es una matriz triangular unitaria inferior, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(k+1:n,k).
!>  Si s = 2, el triángulo inferior de D(k) sobrescribe A(k,k), A(k+1,k),
!>  y A(k+1,k+1), y v sobrescribe A(k+2:n,k:k+1).
!>
