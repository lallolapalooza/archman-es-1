Documentación de la función/subrutina

subroutine cher2k (character uplo, character trans, integer n, integer k, complex alpha, complex, dimension(lda,*) a, integer lda, complex, dimension(ldb,*) b, integer ldb, real beta, complex, dimension(ldc,*) c, integer ldc)

CHER2K

Propósito:

!>
!> CHER2K  realiza una de las operaciones hermíticas de rango 2k
!>
!>    C := alpha*A*B**H + conjg( alpha )*B*A**H + beta*C,
!>
!> o
!>
!>    C := alpha*A**H*B + conjg( alpha )*B**H*A + beta*C,
!>
!> donde  alpha y beta  son escalares con  beta  real,  C es una matriz
!> hermítica de n por n y  A y B  son matrices de n por k en el primer
!> caso y matrices de k por n en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la parte triangular superior
!>           o inferior del array C debe ser referenciada como se indica a
!>           continuación:
!>
!>              UPLO = 'U' o 'u'   Solo la parte triangular superior de C
!>                                  debe ser referenciada.
!>
!>              UPLO = 'L' o 'l'   Solo la parte triangular inferior de C
!>                                  debe ser referenciada.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           A la entrada, TRANS especifica la operación a realizar como
!>           se indica a continuación:
!>
!>              TRANS = 'N' o 'n'    C := alpha*A*B**H          +
!>                                         conjg( alpha )*B*A**H +
!>                                         beta*C.
!>
!>              TRANS = 'C' o 'c'    C := alpha*A**H*B          +
!>                                         conjg( alpha )*B**H*A +
!>                                         beta*C.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz C. N debe
!>           ser al menos cero.
!>

K

!>          K es INTEGER
!>           A la entrada con TRANS = 'N' o 'n', K especifica el número
!>           de columnas de las matrices A y B, y a la entrada con
!>           TRANS = 'C' o 'c', K especifica el número de filas de las
!>           matrices A y B. K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es COMPLEX
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX, de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con TRANS = 'N' o 'n', la parte líder
!>           n por k del array A debe contener la matriz A, en caso
!>           contrario, la parte líder k por n del array A debe contener
!>           la matriz A.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal
!>           como se declaró en el programa (sub)llamador. Cuando
!>           TRANS = 'N' o 'n', LDA debe ser al menos max( 1, n ), en
!>           caso contrario, LDA debe ser al menos max( 1, k ).
!>

B

!>          B es un array COMPLEX, de dimensión ( LDB, kb ), donde kb es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con TRANS = 'N' o 'n', la parte líder
!>           n por k del array B debe contener la matriz B, en caso
!>           contrario, la parte líder k por n del array B debe contener
!>           la matriz B.
!>

LDB

!>          LDB es INTEGER
!>           A la entrada, LDB especifica la primera dimensión de B tal
!>           como se declaró en el programa (sub)llamador. Cuando
!>           TRANS = 'N' o 'n', LDB debe ser al menos max( 1, n ), en
!>           caso contrario, LDB debe ser al menos max( 1, k ).
!>

BETA

!>          BETA es REAL
!>           A la entrada, BETA especifica el escalar beta.
!>

C

!>          C es un array COMPLEX, de dimensión ( LDC, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte líder
!>           n por n de   la matriz C debe contener la parte triangular
!>           superior de la matriz hermítica y la parte triangular
!>           estrictamente inferior de C no se referencia. A la salida,
!>           la parte triangular superior del array C se sobrescribe con
!>           la parte triangular superior de la matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte líder
!>           n por n de la matriz C debe contener la parte triangular
!>           inferior de la matriz hermítica y la parte triangular
!>           estrictamente superior de C no se referencia. A la salida,
!>           la parte triangular inferior del array C se sobrescribe con
!>           la parte triangular inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos
!>           diagonales no necesitan estar establecidas, se asumen cero,
!>           y a la salida se establecen a cero.
!>

LDC

!>          LDC es INTEGER
!>           A la entrada, LDC especifica la primera dimensión de C tal
!>           como se declaró en el programa (sub)llamador. LDC debe ser
!>           al menos max( 1, n ).
!>
