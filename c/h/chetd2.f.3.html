subroutine chetd2 (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( * ) tau, integer info)

CHETD2 reduce una matriz Hermítica compleja a forma tridiagonal simétrica real mediante una transformación de similitud unitaria (algoritmo sin bloques).

Propósito:

!>
!> CHETD2 reduce una matriz Hermítica compleja A a forma tridiagonal
!> simétrica real T mediante una transformación de similitud unitaria:
!> Q**H * A * Q = T.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          superior triangular de tamaño n x n conduce A contiene la parte
!>          superior triangular de la matriz A, y la parte triangular
!>          estrictamente inferior de A no se referencia. Si UPLO = 'L', la
!>          parte inferior triangular de tamaño n x n conduce A contiene la
!>          parte inferior triangular de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>          En la salida, si UPLO = 'U', la diagonal y la primera
!>          superdiagonal de A se sobrescriben con los elementos
!>          correspondientes de la matriz tridiagonal T, y los elementos
!>          por encima de la primera superdiagonal, con el array TAU,
!>          representan la matriz unitaria Q como un producto de
!>          reflectores elementales; si UPLO = 'L', la diagonal y la
!>          primera subdiagonal de A se sobrescriben con los elementos
!>          correspondientes de la matriz tridiagonal T, y los elementos
!>          por debajo de la primera subdiagonal, con el array TAU,
!>          representan la matriz unitaria Q como un producto de
!>          reflectores elementales. Véase Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

D

!>          D es array REAL, dimensión (N)
!>          Los elementos diagonales de la matriz tridiagonal T:
!>          D(i) = A(i,i).
!>

E

!>          E es array REAL, dimensión (N-1)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T:
!>          E(i) = A(i,i+1) si UPLO = 'U', E(i) = A(i+1,i) si UPLO = 'L'.
!>

TAU

!>          TAU es array COMPLEX, dimensión (N-1)
!>          Los factores escalares de los reflectores elementales (ver
!>          Detalles Adicionales).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  Si UPLO = 'U', la matriz Q se representa como un producto de
!>  reflectores elementales
!>
!>     Q = H(n-1) . . . H(2) H(1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(i+1:n) = 0 y v(i) = 1; v(1:i-1) se almacena en la salida en
!>  A(1:i-1,i+1), y tau en TAU(i).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de
!>  reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(n-1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i) = 0 y v(i+1) = 1; v(i+2:n) se almacena en la salida en A(i+2:n,i),
!>  y tau en TAU(i).
!>
!>  Los contenidos de A en la salida se ilustran con los siguientes
!>  ejemplos con n = 5:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  d   e   v2  v3  v4 )              (  d                  )
!>    (      d   e   v3  v4 )              (  e   d              )
!>    (          d   e   v4 )              (  v1  e   d          )
!>    (              d   e  )              (  v1  v2  e   d      )
!>    (                  d  )              (  v1  v2  v3  e   d  )
!>
!>  donde d y e denotan elementos diagonales y fuera de la diagonal de T,
!>  y vi denota un elemento del vector que define H(i).
!>
