add_datase
t

Añade una lista de valores como un conjunto de datos. Es decir, una fila en la tabla

de datos general. El primer conjunto de datos son normalmente las etiquetas del eje x (
conjunto de dominio). Asegúrate de que todos los conjuntos tengan la misma longitud.

$graph->add_dataset( 1, 2, 3, ... ); $graph->add_dataset( [1, 2, 3, .

..] );

En instancias con Puntos, Líneas o Barras, un conjunto de datos es representado por un conjunto de elementos gráficos (puntos, barras o líneas) de un

color. 
add_p
t

Añade (anexa) a cada conjunto de datos ya existente un valor. Eso es una columna en la tabla de datos

general. En este ejemplo, añade al conjunto 0 el valor 3, al conjunto 1 el 6, y así sucesivamente. Aseg
úrate de que las longitudes de las listas coincidan con el número de conjuntos de datos ya existentes.

$graph->add_pt( 3, 6, 9, ... ); $graph->add_pt( [3, 6,

9, ...] );

jpe

g

Crea una imagen JPEG a partir de los datos y propiedades dados. Acepta un nombre de archivo o un manejador de archivos (raw o en un SCALAR). El método cierra el manejador de

archivos. 
$graph->jpeg( 'image.jpg' );
$graph->jpeg( $file_handle );
$graph->jpeg( FILE_HANDLE );

$graph->jpeg( 'image.jpg', $data );
$graph->jpeg( 'image.jpg', 'data_file.tsv' );
$graph->jpeg( 'image.jpg', $file_handle );
$graph->jpeg( 'image.jpg', FILE_HANDLE )
;

El segundo argumento, opcional, son los datos en forma de una referencia a un array de arrays. Esto solo funciona si no se han dado datos ya al objeto. A

lternativamente, los datos también se pueden cargar desde un archivo, simplemente proporciona el nombre de archivo o el manejador (moderno en SCALAR u old sc
hool). Lee más sobre el formato del archivo en "add_datafile" y ten en cuenta que este método tiene otra opción para cargar tablas de datos transpuestas.

ne

w

Crea un nuevo objeto de gráfico. Toma dos argumentos opcionales, que son el ancho y la altura de la imagen a producir en píxeles. Los valores por defecto para eso son 400 x

300. 
my $graph = Chart::Bars->new ( );
my $graph = Chart::Bars->new (600, 700)
;

En lugar de Bars, también puedes usar: Composite, Direction, ErrorBars,

HorizontalBars, Lines, LinesPoints, Mountain, Pareto, Pie, Points, Spl
it y StackedBars. Para saber más sobre ellos, lee Chart::Manual::Types.
