CHPASSWD(8) Comandos de Administración del Sistema CHPASSWD(8)

NOMBRE

chpasswd - actualizar contraseñas en modo por lotes

SINOPSIS

chpasswd [opciones]

DESCRIPCIÓN

El comando chpasswd lee una lista de pares de nombre de usuario y contraseña de la entrada estándar y utiliza esta información para actualizar un grupo de usuarios existentes. Cada línea tiene el formato:

nombre_usuario:contraseña

Por defecto, las contraseñas deben proporcionarse en texto plano y son cifradas por chpasswd. También se actualizará la antigüedad de la contraseña, si está presente.

Por defecto, las contraseñas son cifradas por PAM, pero (incluso si no se recomienda) puedes seleccionar un método de cifrado diferente con las opciones -e, -m o -c.

Excepto cuando se utiliza PAM para cifrar las contraseñas, chpasswd primero actualiza todas las contraseñas en memoria y luego confirma todos los cambios en el disco si no ocurrieron errores para ningún usuario.

Cuando se utiliza PAM para cifrar las contraseñas (y actualizar las contraseñas en la base de datos del sistema), si una contraseña no se puede actualizar, chpasswd continúa actualizando las contraseñas de los siguientes usuarios y devolverá un código de error al salir.

Este comando está destinado a ser utilizado en un entorno de sistema grande donde se crean muchas cuentas a la vez.

OPCIONES

Las opciones que se aplican al comando chpasswd son:

-c, --crypt-method MÉTODO

Utiliza el método especificado para cifrar las contraseñas.

Los métodos disponibles son DES, MD5, SHA256, SHA512, YESCRYPT y NONE si tu libc soporta estos métodos.

Por defecto, se utiliza PAM para cifrar las contraseñas.

-e, --encrypted

Las contraseñas proporcionadas están en formato cifrado.

-h, --help

Muestra el mensaje de ayuda y sale.

-m, --md5

Utiliza cifrado MD5 en lugar de DES cuando las contraseñas proporcionadas no están cifradas.

-R, --root DIRECTORIO_CHROOT

Aplica los cambios en el directorio DIRECTORIO_CHROOT y utiliza los archivos de configuración del directorio DIRECTORIO_CHROOT. Solo se admiten rutas absolutas.

-P, --prefix DIRECTORIO_PREFIJO

Aplica los cambios a los archivos de configuración bajo el sistema de archivos raíz que se encuentra en el directorio DIRECTORIO_PREFIJO. Esta opción no hace chroot y está pensada para preparar un destino de compilación cruzada. Algunas limitaciones: los usuarios/grupos NIS y LDAP no se verifican. La autenticación PAM utiliza los archivos del host. No hay soporte SELINUX.

-s, --sha-rounds RONDAS

Utiliza el número de rondas especificado para cifrar las contraseñas.

Solo puedes usar esta opción con el método de cifrado: SHA256 SHA512 YESCRYPT

Por defecto, el número de rondas para SHA256 o SHA512 se define mediante las variables SHA_CRYPT_MIN_ROUNDS y SHA_CRYPT_MAX_ROUNDS en /etc/login.defs.

Se aplicará un valor mínimo de 1000 y un valor máximo de 999.999.999 para SHA256 y SHA512. El número de rondas por defecto es 5000.

Por defecto, el número de rondas para YESCRYPT se define mediante el YESCRYPT_COST_FACTOR en /etc/login.defs.

Se aplicará un valor mínimo de 1 y un valor máximo de 11 para YESCRYPT. El número de rondas por defecto es 5.

PRECAUCIONES

Recuerda configurar los permisos o la máscara de bits para evitar que los archivos sin cifrar sean legibles por otros usuarios.

CONFIGURACIÓN

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de esta herramienta:

SHA_CRYPT_MIN_ROUNDS (número), SHA_CRYPT_MAX_ROUNDS (número)

Cuando ENCRYPT_METHOD se establece en SHA256 o SHA512, esto define el número de rondas SHA utilizadas por el algoritmo de cifrado por defecto (cuando el número de rondas no se especifica en la línea de comandos).

Con muchas rondas, es más difícil realizar un ataque de fuerza bruta a la contraseña. Pero ten en cuenta también que se necesitarán más recursos de CPU para autenticar a los usuarios.

Si no se especifica, la libc elegirá el número de rondas por defecto (5000), que es órdenes de magnitud demasiado bajo para el hardware moderno.

Los valores deben estar dentro del rango de 1000-999.999.999.

Si solo se establece uno de los valores SHA_CRYPT_MIN_ROUNDS o SHA_CRYPT_MAX_ROUNDS, entonces se utilizará ese valor.

Si SHA_CRYPT_MIN_ROUNDS > SHA_CRYPT_MAX_ROUNDS, se utilizará el valor más alto.

Nota: Esto solo afecta a la generación de contraseñas de grupo. La generación de contraseñas de usuario la realiza PAM y está sujeta a la configuración de PAM. Se recomienda establecer esta variable de forma consistente con la configuración de PAM.

YESCRYPT_COST_FACTOR (número)

Cuando ENCRYPT_METHOD se establece en YESCRYPT, esto define el factor de costo utilizado por el algoritmo de cifrado por defecto (cuando el factor de costo no se especifica en la línea de comandos).

Con un factor de costo alto, es más difícil realizar un ataque de fuerza bruta a la contraseña. Pero ten en cuenta también que se necesitarán más recursos de CPU para autenticar a los usuarios.

El valor debe estar dentro del rango de 1-11.

Nota: Esto solo afecta a la generación de contraseñas de grupo. La generación de contraseñas de usuario la realiza PAM y está sujeta a la configuración de PAM. Se recomienda establecer esta variable de forma consistente con la configuración de PAM.
