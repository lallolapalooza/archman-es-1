NOMBRE

csc — programa controlador para el compilador CHICKEN Scheme

SINOPSIS

csc [OPCIÓN ...] [NOMBRE_DE_ARCHIVO ...]

DESCRIPCIÓN

csc es un programa que invoca el compilador CHICKEN y el compilador C del sistema anfitrión para generar un ejecutable a partir de un archivo fuente Scheme o de archivos C generados por CHICKEN.

NOMBRE_DE_ARCHIVO es un nombre de archivo fuente Scheme con extensión opcional, o un nombre de archivo fuente, objeto o biblioteca C/C++/Objective-C con extensión. OPCIÓN puede ser una de las siguientes:

Opciones generales:

-h, -help
Muestra el texto de uso y termina.
-v, -verbose
Muestra notas del compilador e invocaciones de herramientas.
-vv
Muestra información sobre el progreso de la traducción.
-vvv
Muestra información sobre todas las fases de compilación.
-version
Muestra la versión del compilador Scheme y termina.
-release
Muestra el número de versión y termina.

Opciones de archivos y rutas de acceso:

-o NOMBRE_DE_ARCHIVO, -output-file NOMBRE_DE_ARCHIVO
Especifica el nombre del ejecutable de destino.
-I RUTA_DE_ACCESO, -include-path RUTA_DE_ACCESO
Especifica una ruta alternativa para los archivos incluidos.
-to-stdout
Escribe el compilador en stdout (implica -t).
-s, -shared, -dynamic
Genera un archivo de objeto compartido cargable dinámicamente.

Opciones de lenguaje:

-D SÍMBOLO, -feature SÍMBOLO
Registra un identificador de característica.
-no-feature SÍMBOLO
Desactiva un identificador de característica integrado.
-c++
Compila a través de un archivo fuente C++ (.cpp).
-objc
Compila a través de un archivo fuente Objective-C (.m).

Opciones relacionadas con la sintaxis:

-i, -case-insensitive
No conserva las mayúsculas y minúsculas de los símbolos leídos.
-K, -keyword-style ESTILO
Habilita una sintaxis de palabras clave alternativa (prefijo, sufijo o ninguna).
-no-parentheses-synonyms
Desactiva los sinónimos de delimitadores de listas.
-no-symbol-escape
Desactiva el soporte para símbolos escapados.
-r5rs-syntax
Desactiva las extensiones de CHICKEN a la sintaxis R5RS.
-compile-syntax
Las macros están disponibles en tiempo de ejecución.
-j MÓDULO, -emit-import-library MÓDULO
Escribe la información del módulo de tiempo de compilación en un archivo separado.
-J, -emit-all-import-libraries
Emite bibliotecas de importación para todos los módulos definidos.
-no-compiler-syntax
Desactiva la expansión de macros del compilador.
-m NOMBRE, -module NOMBRE
Envuelve el código compilado en un módulo con el nombre dado.
-M, -module-registration
Genera siempre código de registro de módulo, incluso cuando se emiten bibliotecas de importación.
-N, -no-module-registration
No genera código de registro de módulo. Anula -module-registration.

Opciones de traducción:

-x, -explicit-use
No usa las unidades ‘library’ y ‘eval’ por defecto.
-P, -check-syntax
Detiene la compilación después de la expansión de macros.
-A, -analyze-only
Detiene la compilación después de la primera pasada de análisis.

Opciones de depuración:

-w, -no-warnings
Desactiva las advertencias.
-d0, -d1, -d2, -d3, -debug-level NÚMERO
Establece el nivel de información de depuración disponible.
-no-trace
Desactiva la información de depuración rudimentaria.
-profile
El ejecutable emite información de perfilado.
-accumulate-profile
El ejecutable emite información de perfilado en modo de anexión.
-profile-name NOMBRE_DE_ARCHIVO
Nombre del archivo de información de perfil generado.
-types NOMBRE_DE_ARCHIVO
Carga una base de datos de tipos adicional.

Opciones de optimización:

-O, -O0, -O1, -O2, -O3, -O4, -O5, -optimize-level NÚMERO
Habilita ciertos conjuntos de opciones de optimización.
-optimize-leaf-routines
Habilita la optimización de rutinas hoja.
-no-usual-integrations
Los procedimientos estándar pueden ser redefinidos.
-u, -unsafe
Desactiva las comprobaciones de seguridad.
-local
Asume que los globales solo se modifican en el archivo actual.
-b, -block
Habilita la compilación por bloques.
-disable-interrupts
Desactiva las interrupciones en el código compilado.
-f, -fixnum-arithmetic
Asume que todos los númers son fixnums.
-disable-stack-overflow-checks
Desactiva la detección de desbordamientos de pila.
-inline
Habilita la inserción en línea (inlining).
-inline-limit LÍMITE
Establece el umbral de inserción en línea.
-inline-global
Habilita la inserción en línea entre módulos.
-specialize
Realiza especialización basada en tipos de las llamadas a primitivas.
-oi NOMBRE_DE_ARCHIVO, -emit-inline-file NOMBRE_DE_ARCHIVO
Genera un archivo con procedimientos insertables en línea globalmente (implica -inline -local).
-consult-inline-file NOMBRE_DE_ARCHIVO
Carga explícitamente el archivo de inserción en línea.
-ot NOMBRE_DE_ARCHIVO, -emit-types-file NOMBRE_DE_ARCHIVO
Escribe la información de declaración de tipos en un archivo.
-no-argc-checks
Desactiva las comprobaciones del número de argumentos.
-no-bound-checks
Desactiva las comprobaciones de variables acotadas.
-no-procedure-checks
Desactiva las comprobaciones de llamadas a procedimientos.
-no-procedure-checks-for-usual-bindings
Desactiva las comprobaciones de llamadas a procedimientos solo para enlaces habituales.
-no-procedure-checks-for-toplevel-bindings
Desactiva las comprobaciones de llamadas a procedimientos para enlaces de nivel superior.
-strict-types
Asume que las variables no cambian su tipo.
-clustering
Combina grupos de procedimientos locales en un bucle de despacho.
-lfa2
Realiza una pasada adicional de análisis de flujo ligero.
-unroll-limit LÍMITE
Especifica el límite de inserción en línea para llamadas autorrecursivas.

Opciones de configuración:

-unit NOMBRE
Compila el archivo como una unidad de biblioteca.
-uses NOMBRE
Declara que se usa la unidad de biblioteca.
-heap-size NÚMERO
Especifica el tamaño del montículo del ejecutable compilado.
-nursery NÚMERO -stack-size NÚMERO
Especifica el tamaño del vivero del ejecutable compilado.
-X NOMBRE_DE_ARCHIVO, -extend NOMBRE_DE_ARCHIVO
Carga el archivo antes de que comience la compilación.
-prelude EXPRESIÓN
Añade la expresión al principio del archivo fuente.
-postlude EXPRESIÓN
Añade la expresión al final del archivo fuente.
-prologue NOMBRE_DE_ARCHIVO
Incluye el archivo antes del archivo fuente principal.
-epilogue NOMBRE_DE_ARCHIVO
Incluye el archivo después del archivo fuente principal.
-e, -embedded
Compila como embebido (no genera ‘main()’).
-gui
Compila como aplicación GUI.
-link NOMBRE
Vincula la extensión con el ejecutable compilado (implica ‘-uses’).
-R NOMBRE, -require-extension NOMBRE
Requiere la extensión y la importa en el código compilado.
-dll, -library
Compila múltiples unidades en una biblioteca dinámica.
-libdir DIRECTORIO
Anula la ubicación del directorio de la biblioteca de tiempo de ejecución.

Opciones para otras pasadas:

-C OPCIÓN
Pasa la opción al compilador de C.
-L OPCIÓN
Pasa la opción al enlazador.
-I<DIR>
Pasa “-I<DIR>” al compilador de C (añade ruta de inclusión).
-L<DIR>
Pasa “-L<DIR>” al enlazador (añade ruta de biblioteca).
-k
Conserva los archivos intermedios.
-c
Se detiene después de la compilación a archivos de objeto.
-t
Se detiene después de la traducción a C.
-cc COMPILADOR
Selecciona un compilador de C distinto del predeterminado.
-cxx COMPILADOR
Selecciona un compilador de C++ distinto del predeterminado.
-ld COMPILADOR
Selecciona un enlazador distinto del predeterminado.
-static
Enlaza con bibliotecas y extensiones CHICKEN estáticas.
-F<DIR>
Pasa “-F<DIR>” al compilador de C (añade ruta de cabeceras de framework en Mac OS X).
-framework NOMBRE
Se pasa al enlazador en Mac OS X.
-rpath RUTA
Añade el directorio a la ruta de búsqueda de la biblioteca de tiempo de ejecución.
-Wl,...
Pasa opciones al enlazador.
-strip
Elimina los símbolos del binario resultante.

Opciones de consulta:

-home
Muestra el directorio de inicio (donde van los archivos de soporte).
-cflags
Muestra los indicadores requeridos del compilador de C y sale.
-ldflags
Muestra los indicadores requeridos del enlazador y sale.
-libs
Muestra las bibliotecas requeridas y sale.
-cc-name
Muestra el nombre del compilador de C predeterminado utilizado.
-cxx-name
Muestra el nombre del compilador de C++ predeterminado utilizado.
-ld-name
Muestra el nombre del enlazador predeterminado utilizado.
-dry-run
Solo muestra los comandos ejecutados, no los ejecuta (implica ‘-v’).

Opciones obscuras:

-debug MODOS
Muestra la salida de depuración para los modos dados.
-compiler RUTA
Usa un compilador distinto del predeterminado ‘chicken’.
-raw
No genera código implícito de inicialización y salida.
-emit-external-prototypes-first
Emite prototipos para las funciones de retorno antes de las declaraciones externas.
-regenerate-import-libraries
Siempre emite las bibliotecas de importación, incluso cuando su contenido no haya cambiado. El comportamiento predeterminado es conservar las bibliotecas de importación existentes.
-ignore-repository
No consulta el repositorio para las extensiones.
-keep-shadowed-macros
No elimina las macros ocultadas.
-host
Compila para el host cuando está configurado para compilación cruzada. chicken-csc(1) — Arch Linux

NAME

csc — Compiler for CHICKEN Scheme.

SYNOPSIS

csc [ -options ... ] [ -compile-only | -link-only ] file ...

DESCRIPTION

The csc utility is the CHICKEN Scheme compiler. It compiles Scheme source files into C source files, which are then compiled and linked into an executable file. Alternatively, it can be used to compile Scheme source files into object files, or to link object files into an executable file.

The csc utility takes a list of Scheme source files and compiles them into C source files (which are typically placed in the same directory as the source files, and named appropriately). These C source files are then compiled by the underlying C compiler (usually GCC) into object files. Finally, these object files, along with any other object files or libraries specified on the command line, are linked together to produce an executable file.

The following options are available:

-absolute-paths
Use absolute paths for all files in the generated C source code and Makefile. This is the default.
-no-absolute-paths
Use relative paths for all files in the generated C source code and Makefile.
-alt-c-compiler compiler
Use the specified compiler instead of the default C compiler (usually GCC).
-check-syntax
Perform syntax checking only; do not generate C code.
-compiler-option option
Pass the specified option to the C compiler.
-compiler-option-file file
Pass all options from the specified file to the C compiler.
-debug
Enable debugging information in the generated C code.
-default-object-directory dir
Set the default directory for object files to dir.
-explicit-compile-file
Do not automatically compile source files. Only compile files that are explicitly specified.
-explicit-link-file
Do not automatically link object files. Only link files that are explicitly specified.
-fixnum-arithmetic
Enable hardware fixnum arithmetic. This may lead to a performance improvement, but it can also lead to incorrect results if fixnum arithmetic overflows.
-help
Print a help message and exit.
-keyword-normalization mode
Control keyword normalization. mode can be ascii, case-sensitive, or case-insensitive.
-libs
Print the default libraries and exit.
-list-options
List all available options and exit.
-module-name name
Set the module name for the generated code to name.
-optimize
Enable optimizations in the generated C code.
-o file
Set the output file name to file.
-pipe
Use pipes instead of temporary files for communication between compiler stages.
-prefer-heap-globally
Prefer the heap for all objects. This may lead to a performance improvement, but it can also lead to increased memory usage.
-private-repository
Load extensions from the executable path.
-deployed
Link the support file to be used from a deployed executable (sets ‘rpath’ accordingly, if supported on this platform.)
-no-elevation
Embed manifest on Windows to suppress elevation warnings for programs named ‘install’ or ‘setup’.

Options can be collapsed if unambiguous, so “-vkfO” is the same as “-v -k -fixnum-arithmetic -optimize”.

ENVIRONMENT

The following environment variables change the behaviour of csc:

CSC_OPTIONS
Can hold default options that should be passed to every invocation of csc.

EXIT STATUS

The csc utility exits 0 on success, and >0 if an error occurs.
