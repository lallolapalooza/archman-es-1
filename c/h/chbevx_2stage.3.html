subrutina chbevx_2stage (character jobz, character range, character uplo, integer n, integer kd, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( ldq, * ) q, integer ldq, real vl, real vu, integer il, integer iu, real abstol, integer m, real, dimension( * ) w, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

CHBEVX_2STAGE calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices OTHER

Propósito:

!>
!> CHBEVX_2STAGE calcula eigenvalores seleccionados y, opcionalmente, eigenvectores
!> de una matriz de banda Hermitiana compleja A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Los eigenvalores y eigenvectores
!> pueden seleccionarse especificando un rango de valores o un rango de
!> índices para los eigenvalores deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo eigenvalores;
!>          = 'V':  Calcular eigenvalores y eigenvectores.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los eigenvalores;
!>          = 'V': se encontrarán todos los eigenvalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los eigenvalores desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un arreglo COMPLEX, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          Hermitiana A, almacenado en las primeras KD+1 filas del arreglo. La
!>          j-ésima columna de A se almacena en la j-ésima columna del arreglo AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del arreglo AB.  LDAB >= KD + 1.
!>

Q

!>          Q es un arreglo COMPLEX, dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz unitaria N por N utilizada en la
!>                          reducción a forma tridiagonal.
!>          Si JOBZ = 'N', el arreglo Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del arreglo Q.  Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo donde
!>          se buscarán eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo donde
!>          se buscarán eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es REAL
!>          La tolerancia de error absoluto para los eigenvalores.
!>          Un eigenvalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los eigenvalores se calcularán con mayor precisión cuando ABSTOL se
!>          establezca al doble del umbral de underflow 2*SLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          eigenvectores no convergieron, intente establecer ABSTOL a
!>          2*SLAMCH('S').
!>
!>          Vea  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un arreglo REAL, dimensión (N)
!>          Los primeros M elementos contienen los eigenvalores seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un arreglo COMPLEX, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los eigenvectores ortonormales de la matriz A
!>          correspondientes a los eigenvalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el eigenvector asociado con W(i).
!>          Si un eigenvector no converge, entonces esa columna de Z
!>          contiene la última aproximación al eigenvector, y el
!>          índice del eigenvector se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas en
!>          el arreglo Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar una cota superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del arreglo Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del arreglo WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, se debe consultar LWORK.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = (2KD+1)*N + KD*NTHREADS
!>                                   donde KD es el tamaño de la banda.
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación con openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, se debe consultar LWORK. Aún no está disponible.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de las matrices WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          las matrices WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK, LRWORK o LIWORK.
!
>

RWOR

K 
!>          RWORK es una matriz REAL, dimensión (7*N)
!
>

IWOR

K 
!>          IWORK es una matriz INTEGER, dimensión (5*N)
!
>

IFAI

L 
!>          IFAIL es una matriz INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los autovectores que no lograron converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, entonces i autovectores no lograron converger.
!>                Sus índices se almacenan en la matriz IFAIL.
!
>
