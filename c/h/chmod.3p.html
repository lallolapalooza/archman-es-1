USO DE APLICACIONES

Para garantizar que los bits S_ISUID y S_ISGID estén establecidos, una aplicación que requiera esto debe usar stat() después de un chmod() exitoso para verificarlo.

Cualquier descriptor de archivo actualmente abierto por cualquier proceso en el archivo podría volverse inválido si el modo del archivo se cambia a un valor que denegaría el acceso a ese proceso. Una situación en la que esto podría ocurrir es en un sistema de archivos sin estado. Este comportamiento no ocurrirá en un entorno que cumpla con las normas.

JUSTIFICACION

Este volumen de POSIX.1‐2017 especifica que el bit S_ISGID es borrado por chmod() en un archivo regular bajo ciertas condiciones. Esto se especifica bajo la suposición de que los archivos regulares pueden ser ejecutados, y el sistema debe evitar que los usuarios creen archivos ejecutables setgid() que se ejecuten con privilegios que el llamador no tiene. En implementaciones que admiten la ejecución de otros tipos de archivos, el bit S_ISGID debería ser borrado para esos tipos de archivos bajo las mismas circunstancias.

Las implementaciones que usan el bit S_ISUID para indicar alguna otra función (por ejemplo, bloqueo de registros obligatorio) en archivos no ejecutables no necesitan borrar este bit al escribir. Deben borrar el bit para archivos ejecutables y cualquier otro caso donde el bit otorga poderes especiales a procesos que cambian el contenido del archivo. Comentarios similares se aplican al bit S_ISGID.

El propósito de la función fchmodat() es permitir el cambio del modo de archivos en directorios distintos del directorio de trabajo actual sin exposición a condiciones de carrera. Cualquier parte de la ruta de un archivo podría ser cambiada en paralelo a una llamada a chmod(), resultando en un comportamiento no especificado. Al abrir un descriptor de archivo para el directorio de destino y usar la función fchmodat() se puede garantizar que el archivo modificado se encuentra en relación con el directorio deseado. Algunas implementaciones podrían permitir cambiar el modo de enlaces simbólicos. Esto no es soportado por las interfaces en la especificación POSIX. Los sistemas con dicho soporte proporcionan una interfaz llamada lchmod(). Para soportar dichas implementaciones, fchmodat() tiene un parámetro flag.
