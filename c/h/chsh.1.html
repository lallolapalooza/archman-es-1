CHSH(1) Comandos de usuario CHSH(1)

NOMBRE

chsh - cambiar el shell de inicio de sesión

SINOPSIS

chsh [-s shell] [-l] [-h] [-V] [nombredeusuario]

DESCRIPCIÓN

chsh se utiliza para cambiar el shell de inicio de sesión del usuario. Si no se proporciona un shell en la línea de comandos, chsh lo solicitará.

chsh admite entradas no locales (kerberos, LDAP, etc.) si está enlazado con libuser; de lo contrario, use ypchsh(1), lchsh(1) o cualquier otra implementación para entradas no locales.

OPCIONES

-s, --shell shell

Especifica el shell de inicio de sesión del usuario.

-l, --list-shells

Imprime la lista de shells especificados en /etc/shells y sale.

-h, --help

Muestra el texto de ayuda y sale. (La opción corta -h se usa desde la versión 2.30; las versiones anteriores usaban la ahora obsoleta -u).

-V, --version

Muestra la versión y sale. (La opción corta -V se usa desde la versión 2.39; las versiones anteriores usaban la ahora obsoleta -v).

SHELLS VÁLIDOS

chsh aceptará la ruta completa de cualquier archivo ejecutable en el sistema.

El comportamiento predeterminado para los usuarios que no son root es aceptar solo los shells listados en el archivo /etc/shells, y emitir una advertencia para el usuario root. También puede configurarse en tiempo de compilación para emitir solo una advertencia para todos los usuarios.

ESTADO DE SALIDA

Devuelve 0 si la operación fue exitosa, 1 si la operación falló o la sintaxis del comando no fue válida.
