NOMBRE

CHECKPOINT - forzar un punto de control de registro de escritura anticipada (WAL)

SINOPSIS

CHECKPOINT

DESCRIPCIÓN

Un punto de control es un punto en la secuencia del registro de escritura anticipada (WAL) en el que todos los archivos de datos se han actualizado para reflejar la información del registro. Todos los archivos de datos se volcarán al disco. Consulte la Sección 28.5 para obtener más detalles sobre lo que sucede durante un punto de control.

El comando CHECKPOINT fuerza un punto de control inmediato cuando se emite el comando, sin esperar a un punto de control regular programado por el sistema (controlado por la configuración en la Sección 19.5.2). CHECKPOINT no está diseñado para su uso durante la operación normal.

Si se ejecuta durante la recuperación, el comando CHECKPOINT forzará un punto de reinicio (véase la Sección 28.5) en lugar de escribir un nuevo punto de control.

Solo los superusuarios o los usuarios con los privilegios del rol pg_checkpoint pueden llamar a CHECKPOINT.

COMPATIBILIDAD

El comando CHECKPOINT es una extensión del lenguaje PostgreSQL.
