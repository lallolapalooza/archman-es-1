CHESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

HE

Propósito

: 
!>
!>    CHESVXX utiliza el factorización de pivoteo diagonal para calcular la
!>    solución a un sistema complejo de ecuaciones lineales A * X = B, donde
!>    A es una matriz hermitiana N por N y X y B son matrices
!>    N por NRHS.
!>
!>    Si se solicita, se devuelven tanto límites de error en norma como
!>    límites de error máximo por componente. CHESVXX devolverá una
!>    solución con un error garantizado muy pequeño
!>    (O(eps) donde eps es la precisión de máquina de trabajo)
!>    a menos que la matriz esté muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. Los números de condición relevantes también se
!>    calculan y devuelven.
!>
!>    CHESVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usando una factorización de una llamada
!>    anterior a CHESVXX también producirá una solución con
!>    errores O(eps) o advertencias, pero no podemos hacer esa afirmación para
!>    factorizaciones y factores de equilibrado proporcionados por el usuario generales
!>    si difieren de lo que CHESVXX produciría por sí mismo.
!
>

Descripción

: 
!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibra o no depende de la
!>    escala de la matriz A, pero si se usa el equilibrado, A se
!>    sobrescribe por diag(S)*A*diag(S) y B por diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de matrices de permutación y triangulares superiores (inferiores)
!>    unitarias, y D es hermitiana y diagonal por bloques con
!>    bloques diagonales de 1 por 1 y 2 por 2.
!>
!>    3. Si algún D(i,i)=0, de modo que D es exactamente singular, entonces la
!>    rutina devuelve con INFO = i. De lo contrario, la forma factorizada de A
!>    se usa para estimar el número de condición de la matriz A (ver
!>    el argumento RCOND).  Si el recíproco del número de condición es
!>    menor que la precisión de máquina, la rutina continúa igualmente para resolver
!>    X y calcular los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X usando la forma factorizada
!>    de A.
!>
!>    5. De forma predeterminada (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina usará refinamiento iterativo para intentar obtener un error
!>    pequeño y límites de error.  El refinamiento calcula el residual con al
!>    menos el doble de la precisión de trabajo.
!>
!>    6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(R) de modo que resuelva el sistema original antes
!>    del equilibrado.
!
> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS.  Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables.  Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0 lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!
>

Parámetro

s
FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada, y si no, si la matriz A debe
!>     equilibrarse antes de ser factorizada.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por S.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!
>

!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!

!

!>     triangular inferior de la matriz A, y la parte triangular superior
!>     estricta de A no se referencia.

!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene detalles de los intercambios y la estructura
!>     por bloques de D, tal como lo determinó CHETRF.  Si IPIV(k) > 0,
!>     entonces las filas y columnas k e IPIV(k) fueron intercambiadas y

!>     IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas k-1 y
!>     -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k) es un bloque

chetrf - LAPACK auxiliary routine






This routine is called by the LAPACK driver routines to compute the
factorization of a complex Hermitian matrix A and to solve a system of
equations.



 Synopsis


SUBROUTINE CHETRF( UPLO, N, A, LDA, IPIV, WORK, LWORK, INFO )



Description



CHETRF routines compute the factorization of a complex Hermitian matrix
A such that



A = P * U * P**H




where P is a unitary matrix constructed by the block diagonal unitary
matrix P, U is an upper triangular matrix, and P**H is the conjugate
transpose of P. U is stored in the upper triangular part of the array
A, and the multipliers used to factor U are stored in the lower
triangular part of A. P is not stored explicitly, but is formed from
U and IPIV.




CHETRF can take advantage of the structure of a Hermitian matrix to
reduce the number of floating-point operations.



Parameters




UPLO



(input) CHARACTER*1
Specifies whether the matrix A is upper or lower triangular.
= 'U': Upper triangular part of A is used.
= 'L': Lower triangular part of A is used.



N



(input) INTEGER
The order of the matrix A. N >= 0.



A



(input/output) COMPLEX array, dimension (LDA,N)
On entry, the complex Hermitian matrix A.
On exit, the factors P and U from the factorization
A = P * U * P**H.



LDA



(input) INTEGER
The leading dimension of the array A. LDA >= max(1,N).



IPIV



(output) INTEGER array, dimension (N)
Details of the block structure of U. If IPIV(k) = i, then the
k-th block of U is of order i. If i < 0, then the k-th block
of U is a 2-by-2 block where U(k,k) and U(k+1,k+1) are the
diagonal elements and U(k,k+1) and U(k+1,k) are the off-diagonal
elements. If IPIV(k) = IPIV(k+1) < 0, then rows and columns k+1 and
-IPIV(k) were interchanged and D(k:k+1,k:k+1) is a 2-by-2 diagonal
block.



WORK



(workspace) COMPLEX array, dimension (LWORK)



LWORK



(input) INTEGER
The dimension of the array WORK. LWORK >= 1. For optimal
performance, LWORK >= max(1,N).



INFO



(output) INTEGER
= 0: Successful exit.
< 0: If INFO = -i, the i-th argument had an illegal value.
> 0: If INFO = i, U(i,i) is exactly zero. The factorization has been
completed, but the factor U is exactly singular, so the solution
and error bounds could not be computed.





Example Usage



To factor a 5x5 Hermitian matrix A, you could call:



CALL CHETRF('U', 5, A, LDA, IPIV, WORK, LWORK, INFO)




where LDA is the leading dimension of A, and LWORK is the dimension
of the workspace array WORK.




If the factorization is successful (INFO = 0), the array A will contain
the factors P and U, and the array IPIV will contain details of the
block structure of U.
