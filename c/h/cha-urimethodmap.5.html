SOPORTE DE MAPA DE MÉTODOS URI EN CHAWAN

Chawan se puede utilizar para mapear protocolos no reconocidos a protocolos conocidos utilizando el formato urimethodmap.

El caso de uso principal para esto es implementar manejadores para protocolos desconocidos por Chawan a través de un protocolo que el navegador sí entiende.

RUTA DE BÚSQUEDA

La ruta de búsqueda para archivos urimethodmap puede ser anulada usando la variable de configuración external.urimethodmap.

La ruta de búsqueda predeterminada para archivos urimethodmap es:

$HOME/.urimethodmap:$HOME/.w3m/urimethodmap:/etc/urimethodmap:/usr/local/etc/urimethodmap

FORMATO

El formato urimethodmap se toma 1:1 de w3m, con algunas modificaciones a la interpretación de las plantillas.

Un intento aproximado de la descripción formal de esto:

URIMethodMap-File = *URIMethodMap-line
URIMethodMap-Line = Comment / URIMethodMap-Entry
URIMethodMap-Entry = Protocol *WHITESPACE Template *WHITESPACE CR
Protocol = 1*CHAR COLON
Template = [ver abajo]
Comment = *WHITESPACE CR / "#" *CHAR CR

Tenga en cuenta que debe haber un signo de dos puntos ASCII (:) después del nombre del protocolo. Sin embargo, el espacio en blanco se puede omitir.

Ejemplos:

# Esto está bien:
protocol:	/cgi-bin/interpret-protocol?%s
# Esto también está bien:
protocol:/cgi-bin/interpret-protocol?%s
# Se permiten espacios y tabulaciones, por lo que esto también está bien:
protocol:	/cgi-bin/interpret-protocol?%s
# Sin embargo, esto es incorrecto, porque falta el signo de dos puntos:
protocol	/cgi-bin/interpret-protocol?%s

La plantilla de redirección es la URL de destino. Si la cadena %s está contenida en la plantilla, será reemplazada por la URL de destino.

Para compatibilidad con w3m, las plantillas que comienzan con /cgi-bin/ y file:/cgi-bin/ tienen un tratamiento especial y la cadena inicial se reemplaza con cgi-bin:. Así, por ejemplo, la plantilla /cgi-bin/w3mdict.cgi es lo mismo que cgi-bin:w3mdict.cgi (y también lo es file:/cgi-bin/w3mdict.cgi).

Ejemplo:

# Los siguientes son lo mismo en Chawan
protocol:	/cgi-bin/interpret-protocol?%s
protocol:	file:/cgi-bin/interpret-protocol?%s
# Nota: esta última entrada no funciona en w3m.
protocol:	cgi-bin:interpret-protocol?%s

Tenga en cuenta, sin embargo, que las rutas absolutas a scripts cgi NO tienen un tratamiento especial, por lo que, por ejemplo, file:///usr/local/libexec/w3m/cgi-bin/w3mdict.cgi simplemente abrirá w3mdict.cgi en el visor de archivos. (A diferencia de w3m, donde podría ejecutar w3mdict.cgi según la configuración del usuario).

EJEMPLOS

EN config.toml

# Establece la ruta de búsqueda de urimethodmap a la ruta relativa al
# archivo de configuración. Entonces, si su archivo de configuración está en
# ~/.config/chawan/config.toml, Chawan usará ~/.config/chawan/urimethodmap.
# Si está en ~/.chawan/config.toml, entonces usa ~/.chawan/urimethodmap.
[external]
urimethodmap = "urimethodmap"

EN urimethodmap

magnet.cgi

# Usa el script de shell CGI `magnet.cgi` para pasar enlaces magnet a Transmission.
magnet:		/cgi-bin/magnet.cgi?%s

magnet.cgi se puede encontrar en el directorio bonus/. También puedes escribir un script CGI local para pasar los enlaces a tu cliente BitTorrent preferido.

dict

En w3m, urimethodmap se usa comúnmente (y a veces abusivamente) para definir atajos para scripts CGI.

Esto también funciona en Chawan; por ejemplo, podrías definir un atajo tl: de esta manera:

# (trans.cgi es un script que puedes encontrar y estudiar en el directorio bonus/.)
tl:		/cgi-bin/trans.cgi?%s

Luego, podrías abrir la traducción de cualquier palabra usando tl:palabra.

Sin embargo, tenga en cuenta que Chawan tiene una instalación más potente para atajos de sustitución como esta en forma de omni-reglas. Por lo tanto, si desea redirigir a un sitio de diccionario en línea con tl:palabra en lugar de proporcionar una interfaz CGI local, es más fácil usar omni-reglas en lugar de urimethodmap + redirección CGI local.
