CHECKUPDATES(8) Manual de Pacman-contrib CHECKUPDATES(8)

NOMBRE

checkupdates - imprime de forma segura una lista de actualizaciones pendientes

SINOPSIS

checkupdates [opciones]

DESCRIPCIÓN

checkupdates busca actualizaciones pendientes utilizando una base de datos separada de pacman ubicada en TMPDIR si CHECKUPDATES_DB no está configurada y muestra una lista de actualizaciones con la versión antigua y la nueva.

OPCIONES

-c, --change

Comprueba solo las nuevas actualizaciones disponibles, imprime la lista de actualizaciones disponibles solo si difiere de la última vez que se ejecutó checkupdates con esa opción.

-d, --download

Descarga cualquier actualización pendiente a la caché de pacman.

-h, --help

Muestra la sintaxis y las opciones de la línea de comandos.

--nocolor

No colorear la salida. El color debe estar habilitado en pacman.conf para que la lista se coloree desde el principio.

-n, --nosync

No sincronizar la base de datos temporal, funciona mejor cuando la base de datos temporal se actualiza regularmente por otros medios, como un cronjob o un temporizador de systemd.

-V, --version

Muestra información de la versión.

ENTORNO

CHECKUPDATES_DB

Anula la ubicación predeterminada de la base de datos temporal ${TMPDIR:-/tmp}/checkup-db-${UID}.

CHECKUPDATES_CHANGE

Ubicación del archivo de estado para la opción -c/--change.

TMPDIR

Anula el directorio temporal predeterminado /tmp.

XDG_STATE_HOME

Anula el directorio de estado predeterminado $HOME/.local/state

ERRORES

Al salir, checkupdates devolverá uno de los siguientes códigos de error.

0

Condición de salida normal.

1

Causa desconocida del fallo.

2

No hay actualizaciones disponibles.

VER TAMBIÉN

pacman(8), pacman.conf(5)

ERRORES
