subrutina chesv_rk (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer

CHESV_RK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

SY

Propósito

: 
!> CHESV_RK calcula la solución a un sistema complejo de ecuaciones
!> lineales A * X = B, donde A es una matriz hermitiana N por N
!> y X y B son matrices N por NRHS.
!>
!> Se utiliza el método de pivote diagonal Bunch-Kaufman acotado (rook)
!> para factorizar A como
!>    A = P*U*D*(U**H)*(P**T),  si UPLO = 'U', o
!>    A = P*L*D*(L**H)*(P**T),  si UPLO = 'L',
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**H (o L**H) es el conjugado de U (o L), P es una matriz de
!> permutación, P**T es la transpuesta de P, y D es hermitiana y
!> diagonal por bloques con bloques diagonales de 1 por 1 y 2 por 2.
!>
!> Se llama a CHETRF_RK para calcular la factorización de una matriz
!> hermitiana compleja.  La forma factorizada de A se utiliza entonces
!> para resolver el sistema de ecuaciones A * X = B llamando a la
!> rutina de BLAS3 CHETRS_3.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si se almacena la parte triangular superior o inferior de la
!>          matriz hermitiana A:
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          A la entrada, la matriz hermitiana A.
!>            Si UPLO = 'U': la parte triangular superior N por N
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no se
!>            referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior N por N
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no se
!>            referencia.
!>
!>          A la salida, si INFO = 0, la diagonal de la matriz diagonal
!>          por bloques D y los factores U o L tal como los calcula CHETRF_RK:
!>            a) SOLO los elementos diagonales de la matriz hermitiana
!>               diagonal por bloques D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan a la salida en el arreglo E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>
!>          Para más información, consulte la descripción de la rutina CHETRF_RK.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

E 
!>          E es un arreglo COMPLEX, dimensión (N)
!>          A la salida, contiene la salida calculada por la rutina de
!>          factorización CHETRF_RK, es decir, los elementos superdiagonales (o
!>          subdiagonales) de la matriz hermitiana diagonal por bloques D
!>          con bloques diagonales de 1 por 1 o 2 por 2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1 por 1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 tanto en el
!>          caso UPLO = 'U' como en el caso UPLO = 'L'.
!>
!>          Para más información, consulte la descripción de la rutina CHETRF_RK.
!
>

IPI

V 
!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          tal como los determina CHETRF_RK.
!>
!>          Para más información, consulte la descripción de la rutina CHETRF_RK.
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          A la entrada, la matriz de lados derechos B de N por NRHS.
!>          A la salida, si INFO = 0, la matriz de solución X de N por NRHS.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión ( MAX(1,LWORK) ).
!>          Arreglo de trabajo utilizado en la etapa de factorización.
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1. Para el mejor rendimiento
!>          de la etapa de factorización LWORK >= max(1,N*NB), donde NB es
!>          el tamaño de bloque óptimo para CHETRF_RK.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del arreglo WORK
!>          para la etapa de factorización, devuelve este valor como
!>          la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de la columna k de L) son todos ceros. La
!>               factorización se ha completado, pero la matriz diagonal
!>               por bloques D es exactamente singular, y ocurrirá una
!>               división por cero si se utiliza para resolver un sistema
!>               de ecuaciones.
!>
!>               NOTA: INFO solo almacena la primera aparición de
!>               una singularidad, cualquier aparición posterior de
!>               singularidad no se almacena en INFO aunque la
!>               factorización siempre se completa.
!
>
