subrutina chesv_aa (uplo, n, nrhs, a, lda, ipiv, b, ldb, work, lwork, info)
CHESV_AA calcula la solución al sistema de ecuaciones lineales A * X = B para matrices HE

Documentación de Función/Subrutina

subrutina chesv_aa (character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer info)

CHESV_AA calcula la solución a un sistema de ecuaciones lineales complejas A * X = B,

Propósito:

!>
!> CHESV_AA calcula la solución a un sistema de ecuaciones lineales complejas
!>    A * X = B,
!> donde A es una matriz Hermitiana N por N y X y B son matrices N por NRHS
!>
!> Se utiliza el algoritmo de Aasen para factorizar A como
!>    A = U**H * T * U,  si UPLO = 'U', o
!>    A = L * T * L**H,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares unitarias superiores (inferiores), y T es Hermitiana y tridiagonal. La forma factorizada
!> de A se utiliza luego para resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          superior N por N de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior
!>          de A no se referencia. Si UPLO = 'L', la parte inferior
!>          N por N de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior
!>          de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz tridiagonal T y los
!>          multiplicadores utilizados para obtener el factor U o L de
!>          la factorización A = U**H*T*U o A = L*T*L**H según lo calculado
!>          por CHETRF_AA.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A fueron intercambiadas con la
!>          fila y columna IPIV(k).
!>

B

!>          B es un array COMPLEX, dimension (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= MAX(1,2*N,3*N-2), y para un mejor
!>          rendimiento LWORK >= MAX(1,N*NB), donde NB es el tamaño de bloque óptimo
!>          para CHETRF.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular, por lo que la solución no pudo calcularse.
!>
