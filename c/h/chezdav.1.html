NOMBRE

chezdav - servidor WebDAV simple

SINOPSIS

chezdav [OPCIONES...]

DESCRIPCIÓN

El comando chezdav(1) inicia un servidor WebDAV. Esto permite a los clientes acceder a sus archivos y modificarlos. Un simple navegador web es suficiente para navegar por los archivos. La carpeta compartida predeterminada es el directorio personal, pero puede especificar una carpeta diferente con la opción -P.

OPCIONES

-P, --path=RUTA

Ruta a exportar.

-p, --port=PUERTO

Puerto desde el que escuchar. Por defecto, se asigna un puerto aleatoriamente.

*--local

Escuchar solo en la interfaz de bucle invertido.

*--public

Escuchar en todas las interfaces de red.

*--no-mdns

No transmitir la compartición en la red local. Por defecto, las comparticiones se transmiten con mDNS/DNS-SD (cuando se compila con Avahi).

-d, --htdigest=RUTA

Ruta a un archivo htdigest, para asegurar el servidor con autenticación DIGEST.

--realm=REALM

La cadena REALM de DIGEST (debe ser idéntica a la cadena utilizada en el archivo htdigest). El valor predeterminado es "share público del usuario" (donde USUARIO es el nombre de usuario del propietario del proceso actual).

-v, --verbose

Imprimir verbosamente la información en ejecución.

--version

Imprimir el número de versión del programa.

Éxito

1

Fallo (error de sintaxis o uso; error inesperado).
