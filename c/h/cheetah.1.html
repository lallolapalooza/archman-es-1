CHEETAH(1) Manual de comandos generales CHEETAH(1)

NOMBRE

cheetah - herramienta de línea de comandos de plantillas Python

SINOPSIS

cheetah, cheetah-compile

cheetah COMANDO [opciones] ARCHIVO...
cheetah-compile [opciones] ARCHIVO...

DESCRIPCIÓN

Esta página del manual documenta brevemente la herramienta de línea de comandos cheetah. Esta página del manual fue escrita para la distribución Debian porque el programa original no tiene una página del manual.

cheetah es un motor de plantillas y generador de código basado en Python. Puede ser utilizado como una utilidad independiente o puede ser combinado con otras herramientas. Cheetah tiene muchos usos potenciales, pero se espera que los desarrolladores web que buscan una alternativa viable a ASP, JSP, PHP y PSP sean su principal grupo de usuarios.

La herramienta de línea de comandos cheetah es la parte de utilidad independiente del conjunto de software. cheetah-compile es un script de conveniencia para el comando "cheetah compile ...". La utilidad acepta un solo comando, posibles opciones y una lista de archivos. Si ARCHIVO es un solo "-", lee la entrada estándar y escribe la salida estándar.

COMANDOS

Los comandos posibles de cheetah se enumeran a continuación. Puedes abreviar el comando a la primera letra; por ejemplo, 'h' == 'help'.

compile
Compila definiciones de plantillas
fill
Rellena definiciones de plantillas
help
Muestra el mensaje de ayuda de los comandos
options
Muestra el mensaje de ayuda de las opciones para los comandos compile y fill
test
Ejecuta pruebas de regresión
version
Muestra el número de versión

OPCIONES

Las opciones para cheetah se aplican a los comandos compile y fill. A continuación se incluye un resumen de las opciones.

--idir DIR
Directorios de entrada (por defecto: directorio actual)
--odir ODIR
Directorios de salida (por defecto: directorio actual)
--iext IEXT
Extensión de entrada. La extensión de entrada por defecto para ambos comandos, compile y fill, es "tmpl".
--oext OEXT
Extensión de salida. La extensión de salida por defecto para el comando compile es "py". La extensión de salida por defecto para fill es "html".
-R
Recorre subdirectorios buscando archivos de entrada
--debug
Muestra mucha salida de diagnóstico en el descriptor de archivo de error estándar
--env
Muestra el entorno en la lista de búsqueda
--flat
Sin subdirectorios de destino
--nobackup
No hacer copias de seguridad
--pickle ARCHIVO
Deserializa ARCHIVO y pone esa salida en la lista de búsqueda
--stdout, -p
Salida al descriptor de archivo de salida estándar (tubería)
