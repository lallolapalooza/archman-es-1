Operaciones con caracteres.

Los caracteres son los elementos de los valores string y bytes. Los caracteres representan bytes, es decir, un entero en el rango [ 0x00 ; 0xFF ].

Algunas de las funciones de este módulo interpretan los caracteres en el rango [ 0x00 ; 0x7F ] como los caracteres del conjunto de caracteres ASCII.

Caracteres

type t = char

Un alias para el tipo de caracteres.

val code : char -> int

Devuelve el código entero del argumento.

val chr : int -> char

Devuelve el carácter con el código entero dado.

Raises Invalid_argument si el argumento está fuera del rango [ 0x00 ; 0x7F ].

val escaped : char -> string

Devuelve una cadena que representa el carácter dado, con los caracteres especiales escapados según las convenciones léxicas de OCaml. Todos los caracteres fuera del rango imprimible ASCII [ 0x20 ; 0x7E ] se escapan, así como la barra invertida, la comilla doble y la comilla simple.

Predicados y comparaciones

Ver también el módulo Char.Ascii.

val compare : t -> t -> int

La función de comparación para caracteres, con la misma especificación que compare. Junto con el tipo t, esta función compare permite que el módulo Char se pase como argumento a los funtores Set.Make y Map.Make.

val equal : t -> t -> bool

La función de igualdad para chars.

Since 4.03

Caracteres ASCII

module Ascii : sig end

Soporte para el conjunto de caracteres ASCII.

Estas funciones dan significado a los enteros [ 0x00 ; 0x7F ] del conjunto de caracteres ASCII.

Dado que la codificación UTF-8 de Unicode tiene la misma codificación y semántica de caracteres (U+0000 a U+001F) para estos bytes, las funciones se pueden usar de forma segura en elementos de valores string y bytes codificados en UTF-8. Sin embargo, las funciones solo se ocupan de asuntos relacionados con ASCII. Por ejemplo, la noción de espacio en blanco de Unicode es mucho más amplia que el espacio en blanco ASCII determinado por Char.Ascii.is_white.

Since 5.4

val lowercase_ascii : char -> char

Use el equivalente Char.Ascii.lowercase en su lugar.

Since 4.03

val uppercase_ascii : char -> char

Use el equivalente Char.Ascii.uppercase en su lugar.

Since 4.03

Hashing

val seeded_hash : int -> t -> int

Una función de hash sembrada para caracteres, con el mismo valor de salida que Hashtbl.seeded_hash. Esta función permite que este módulo se pase como argumento al funtor Hashtbl.MakeSeeded.

Since 5.1

val hash : t -> int

Una función de hash no sembrada para caracteres, con el mismo valor de salida que Hashtbl.hash. Esta función permite que este módulo se pase como argumento al funtor Hashtbl.Make.

Since 5.1
