CHECKXML6(1) Manual de usuario de checkXML6 CHECKXML6(1)

NOMBRE

checkXML6 - Una herramienta de validación XML para documentos XML DocBook de KDE

SINOPSIS

checkXML6 [nombre_archivo]

DESCRIPCIÓN

checkXML6 es una herramienta para comprobar errores de sintaxis en archivos XML DocBook de KDE. También se puede utilizar para otros archivos XML basados en DocBook, pero deberías usar la herramienta más genérica xmllint(1) si no estás escribiendo o trabajando de otra manera en la documentación de KDE.

VER TAMBIÉN

meinproc6(1), xmllint(1)
