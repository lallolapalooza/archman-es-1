subrutina chpt21 (integer itype, character uplo, integer n, integer kband, complex, dimension( * ) ap, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( * ) vp, complex, dimension( * ) tau, complex, dimension( * ) work, real, dimension( * ) rwork, real, dimension( 2 ) result)

CHPT21

Propósito:

!>
!> CHPT21 generalmente verifica una descomposición de la forma
!>
!>         A = U S U**H
!>
!> donde **H significa transpuesta conjugada, A es hermitiana, U es
!> unitaria, y S es diagonal (si KBAND=0) o simétrica tridiagonal
!> (real) (si KBAND=1).  Si ITYPE=1, entonces U se representa como
!> una matriz densa, de lo contrario U se expresa como un producto de
!> transformaciones de Householder, cuyos vectores se almacenan en el
!> array  y cuyas constantes de escalado están en  
 usaremos
!> la letra  para referirnos al producto de transformaciones de
!> Householder (que debería ser igual a U).
!>
!> Específicamente, si ITYPE=1, entonces:
!>
!>         RESULT(1) = | A - U S U**H | / ( |A| n ulp ) y
!>         RESULT(2) = | I - U U**H | / ( n ulp )
!>
!> Si ITYPE=2, entonces:
!>
!>         RESULT(1) = | A - V S V**H | / ( |A| n ulp )
!>
!> Si ITYPE=3, entonces:
!>
!>         RESULT(1) = | I - U V**H | / ( n ulp )
!>
!> El almacenamiento empaquetado significa que, por ejemplo, si UPLO='U', entonces las columnas
!> del triángulo superior de A se almacenan una tras otra, de modo que
!> A(1,j+1) sigue inmediatamente a A(j,j) en el array AP.  De manera similar, si
!> UPLO='L', entonces las columnas del triángulo inferior de A se almacenan una
!> tras otra en AP, de modo que A(j+1,j+1) sigue inmediatamente a A(n,j)
!> en el array AP.  Esto significa que A(i,j) se almacena en:
!>
!>    AP( i + j*(j-1)/2 )                 si UPLO='U'
!>
!>    AP( i + (2*n-j)*(j-1)/2 )           si UPLO='L'
!>
!> El array VP mantiene la misma relación con la matriz V que A con
!> AP.
!>
!> Para ITYPE > 1, la transformación U se expresa como un producto
!> de transformaciones de Householder:
!>
!>    Si UPLO='U', entonces  V = H(n-1)...H(1),  donde
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**H
!>
!>    y los primeros j-1 elementos de v(j) se almacenan en V(1:j-1,j+1),
!>    (es decir, VP( j*(j+1)/2 + 1 : j*(j+1)/2 + j-1 ) ),
!>    el j-ésimo elemento es 1, y los últimos n-j elementos son 0.
!>
!>    Si UPLO='L', entonces  V = H(1)...H(n-1),  donde
!>
!>        H(j) I  -  tau(j) v(j) v(j)**H
!>
!>    y los primeros j elementos de v(j) son 0, el (j+1)-ésimo es 1, y los
!>    elementos del (j+2)-ésimo al n-ésimo se almacenan en V(j+2:n,j) (es decir,
!>    en VP( (2*n-j)*(j-1)/2 + j+2 : (2*n-j)*(j-1)/2 + n ) .)
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de pruebas a realizar.
!>          1: U expresada como una matriz unitaria densa:
!>             RESULT(1) = | A - U S U**H | / ( |A| n ulp ) y
!>             RESULT(2) = | I - U U**H | / ( n ulp )
!>
!>          2: U expresada como un producto V de transformaciones de Householder:
!>             RESULT(1) = | A - V S V**H | / ( |A| n ulp )
!>
!>          3: U expresada tanto como una matriz unitaria densa como
!>             como un producto de transformaciones de Householder:
!>             RESULT(1) = | I - U V**H | / ( n ulp )
!>

UPLO

!>          UPLO es CHARACTER
!>          Si UPLO='U', se usará el triángulo superior de A y V y
!>          el triángulo inferior (estrictamente) no será referenciado.
!>          Si UPLO='L', se usará el triángulo inferior de A y V y
!>          el triángulo superior (estrictamente) no será referenciado.
!>

N

!>          N es INTEGER
!>          El tamaño de la matriz.  Si es cero, CHPT21 no hace nada.
!>          Debe ser al menos cero.
!>

KBAND

!>          KBAND es INTEGER
!>          El ancho de banda de la matriz.  Solo puede ser cero o uno.
!>          Si es cero, entonces S es diagonal, y E no es referenciado.  Si
!>          es uno, entonces S es simétrica tridiagonal.
!>

AP

!>          AP es un array COMPLEX, dimensión (N*(N+1)/2)
!>          La matriz original (sin factorizar).  Se asume que es
!>          hermitiana, y contiene las columnas de solo el triángulo
!>          superior (UPLO='U') o solo el triángulo inferior (UPLO='L'),
!>          empaquetadas una tras otra.
!>

D

!>          D es un array REAL, dimensión (N)
!>          La diagonal de la matriz (simétrica tri-) diagonal.
!>

E

!>          E es un array REAL, dimensión (N)
!>          La subdiagonal de la matriz (simétrica tri-) diagonal.
!>          E(1) es el elemento (1,2) y (2,1), E(2) es el elemento (2,3) y
!>          (3,2), etc.
!>          No referenciado si KBAND=0.
!>

U

!>          U es un array COMPLEX, dimensión (LDU, N)
!>          Si ITYPE=1 o 3, contiene la matriz unitaria en
!>          la descomposición, expresada como una matriz densa.  Si ITYPE=2,
!>          entonces no es referenciado.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U.  LDU debe ser al menos N y
!>          al menos 1.
!>

VP

!>          VP es un array REAL, dimensión (N*(N+1)/2)
!>          Si ITYPE=2 o 3, las columnas de este array contienen los
!>          vectores de Householder usados para describir la matriz unitaria
!>          en la descomposición, como se describe en propósito.
!>          *NOTA* Si ITYPE=2 o 3, V es modificada y restaurada.  La
!>          subdiagonal (si UPLO='L') o la superdiagonal (si UPLO='U')
!>          se establece a uno, y luego se restablece a su valor original, durante
!>          el curso del cálculo.
!>          Si ITYPE=1, entonces no es ni referenciada ni modificada.
!>

TAU

!>          TAU es un array COMPLEX, dimensión (N)
!>          Si ITYPE >= 2, entonces TAU(j) es el factor escalar de
!>          v(j) v(j)**H en la transformación de Householder H(j) del
!>          producto  U = H(1)...H(n-2)
!>          Si ITYPE < 2, entonces TAU no es referenciado.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (N**2)
!>          Espacio de trabajo.
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>          Espacio de trabajo.
!>

RESULT

!>          RESULT es un array REAL, dimensión (2)
!>          Los valores calculados por las dos pruebas descritas anteriormente.  Los
!>          valores están actualmente limitados a 1/ulp, para evitar desbordamiento.
!>          RESULT(1) es siempre modificado.  RESULT(2) es modificado solo
!>          si ITYPE=1.
!>
