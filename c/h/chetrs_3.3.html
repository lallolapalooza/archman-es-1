CHETRS_3

Propósito:

!> CHETRS_3 resuelve un sistema de ecuaciones lineales A * X = B con una matriz
!> compleja Hermitiana A utilizando la factorización calculada
!> por CHETRF_RK o CHETRF_BK:
!>
!>    A = P*U*D*(U**H)*(P**T) o A = P*L*D*(L**H)*(P**T),
!>
!> donde U (o L) es una matriz triangular unitaria superior (o inferior),
!> U**H (o L**H) es la conjugada de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es Hermitiana y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Este algoritmo utiliza BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se
!>          almacenan como una matriz triangular superior o inferior:
!>          = 'U':  Triangular superior, la forma es A = P*U*D*(U**H)*(P**T);
!>          = 'L':  Triangular inferior, la forma es A = P*L*D*(L**H)*(P**T).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          La diagonal de la matriz diagonal por bloques D y los factores U o L
!>          calculados por CHETRF_RK y CHETRF_BK:
!>            a) SÓLO los elementos diagonales de la matriz Hermitiana diagonal
!>               por bloques D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                deben proporcionarse en la entrada en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array COMPLEX, dimensión (N)
!>          En la entrada, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz Hermitiana diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) no referenciado;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) no referenciado.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) no se referencia en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como lo determinan CHETRF_RK o CHETRF_BK.
!>

B

!>          B es array COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
