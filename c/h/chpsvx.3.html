subrutina chpsvx (character fact, character uplo, integer n, integer nrhs, complex, dimension( * ) ap, complex, dimension( * ) afp, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CHPSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTHER

Propósito:

!>
!> CHPSVX usa la factorización de pivoteo diagonal A = U*D*U**H o
!> A = L*D*L**H para calcular la solución a un sistema de ecuaciones
!> lineales complejo A * X = B, donde A es una matriz Hermitiana N-por-N
!> almacenada en formato empaquetado y X y B son matrices N-por-NRHS.
!>
!> También se proporcionan límites de error en la solución y una
!> estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se usa el método de pivoteo diagonal para factorizar A como
!>       A = U * D * U**H,  si UPLO = 'U', o
!>       A = L * D * L**H,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    superiores (inferiores) unitarias y D es Hermitiana y diagonal por bloques
!>    con bloques diagonales de 1-por-1 y 2-por-2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se usa
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de máquina,
!>    se retorna INFO = N+1 como una advertencia, pero la rutina continúa
!>    para resolver X y calcular los límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X usando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular límites de error y estimaciones de error hacia atrás
!>    para la misma.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          proporcionada en la entrada.
!>          = 'F':  En la entrada, AFP e IPIV contienen la forma factorizada de
!>                  A.  AFP e IPIV no serán modificados.
!>          = 'N':  La matriz A será copiada a AFP y factorizada.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz Hermitiana A, empaquetado
!>          por columnas en un arreglo lineal.  La j-ésima columna de A se almacena
!>          en el arreglo AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>          Vea más abajo para más detalles.
!>

AFP

!>          AFP es un arreglo COMPLEX, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores usados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**H o A = L*D*L**H como lo calcula CHPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          contiene la matriz diagonal por bloques D y los multiplicadores usados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**H o A = L*D*L**H como lo calcula CHPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura por bloques
!>          de D, como lo determina CHPTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1-por-1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2-por-2.  Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 e -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2-por-2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura por bloques
!>          de D, como lo determina CHPTRF.
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          La matriz de miembros derechos B de dimensión N-por-NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

X

!>          X es un arreglo COMPLEX, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz de solución X de dimensión N-por-NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del recíproco del número de condición de la matriz
!>          A.  Si RCOND es menor que la precisión de máquina (en
!>          particular, si RCOND = 0), la matriz es singular a la precisión
!>          de trabajo.  Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es un arreglo REAL, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector de
!>          solución X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento
!>          más grande en (X(j) - XTRUE) dividido por la magnitud del
!>          elemento más grande en X(j).  La estimación es tan confiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un arreglo REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector de solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (2*N)
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  D(i,i) es exactamente cero.  La factorización
!>                       ha sido completada pero el factor D es exactamente

NAME


chpsvx


complex Hermitian semi-packed preconditioner for a symmetric
    tridiagonal matrix






SYNOPSIS


    SUBROUTINE CHPSVX(FACT, TRANS, N, NRHS, AP, B, LDB, X, LDX, RCOND,
                        FERR, BERR, WORK, RWORK, INFO)

        LOGICAL           :: FACT
        CHARACTER(1)      :: TRANS
        INTEGER           :: INFO, LDB, LDX, N, NRHS
        REAL              :: BERR(*), FERR(*), RCOND
        COMPLEX, ALLOCATABLE :: AP(:), B(:), RWORK(:), WORK(:), X(:)







Function/Subroutine Documentation




SUBROUTINE CHPSVX(FACT, TRANS, N, NRHS, AP, B, LDB, X, LDX, RCOND,
                    FERR, BERR, WORK, RWORK, INFO)

    !>
    Purpose
    =======
    
    CHPSVX uses the diagonal pivoting method to compute the solution to a
    complex system of equations AP * X = B, B = AP * X, or B = TRANS * AP * X,
    where AP is a semi-packed array of the form:
    
       AP = [ A real diagonal        ]
            [ A complex lower        ]
            [ A complex upper        ]
            [ A complex symmetric    ]
    
    Here, A is a complex Hermitian matrix of order N, and is represented in
    the semi-packed storage format. B and X are complex matrices, and AP and
    each of the packed arrays are stored column-wise.
    
    This routine is generally the fastest way to solve a complex Hermitian
    tridiagonal system of equations.
    
    Arguments
    =========
    
    FACT    (input) LOGICAL
            Specifies whether or not the factorization of the matrix A is
            supplied.
            
            = .TRUE.: AP contains the L-factor of A from a previous
                      call to CHPSVX.
                      
            = .FALSE.: The L-factor of A will be computed and factored from
                       the given matrix AP.
                       
    TRANS   (input) CHARACTER(1)
            Specifies the form of the system of equations:
            = 'N':  A * X = B       (No transpose)
            = 'C':  A**H * X = B    (Conjugate transpose)
            
            This is the transpose that is applied to the factors of A, not
            necessarily to the matrix A itself.
            
    N       (input) INTEGER
            The order of the matrix A. N >= 0.
            
    NRHS    (input) INTEGER
            The number of right-hand sides, i.e., the number of columns in the
            arrays B and X. NRHS >= 0.
            
    AP      (input/output) COMPLEX array, dimension (N*(N+1)/2)
            On entry, the array AP must contain the matrix A in the packed
            storage format. If FACT = .TRUE., AP must contain the L-factor
            of A.
            On exit, AP is overwritten by details of the factorization.
            
    B       (input) COMPLEX array, dimension (LDB, NRHS)
            On entry, the n x n matrix of right-hand side vectors, 1 <= NRHS.
            On exit, if INFO = 0, B contains the solution vectors, which
            can be checked for the relative error in the solution.
            
    LDB     (input) INTEGER
            The leading dimension of the array B. LDB >= max(1, N).
            
    X       (output) COMPLEX array, dimension (LDX, NRHS)
            If FACT = .TRUE., X contains the solution vectors corresponding
            to the right-hand side vectors in B.
            
    LDX     (input) INTEGER
            The leading dimension of the array X. LDB >= max(1, N).
            
    RCOND   (output) REAL
            The estimate of the reciprocal condition number of the matrix A.
            The matrix A is singular if RCOND is less than the machine
            epsilon.
            
    FERR    (output) REAL array, dimension (NRHS)
            The estimated forward error bound for each solution vector in X.
            If Ae and be are the exact solution and right hand side, and
            x is the approximate solution vector then the error is ||x - xe||
            and IFERR is an upper bound on the relative error I|x - xe||/||x||.
            
    BERR    (output) REAL array, dimension (NRHS)
            The estimated backward error bound for each solution vector in X.
            BERR(j) is an upper bound on the relative backward error of the
            solution {x_j}.
            
    WORK    (workspace) COMPLEX array, dimension (2*N)
            
    RWORK   (workspace) REAL array, dimension (N)
            
    INFO    (output) INTEGER
            = 0: Successful exit. The solution has been computed.
            < 0: If INFO = -i, the i-th argument had an illegal value.
            > 0: If INFO = i, U(i,i) is zero, and the solution could not be
                   computed. The problem may be too ill-conditioned to be
                   solved. RCOND = 0 is returned.
                   
    Further Details
    ===============
    
    The packed storage scheme is illustrated by the following example
    when N = 4, UPLO = 'U':
    
    Two-dimensional storage of the Hermitian matrix A:
    
       a11 a12 a13 a14
           a22 a23 a24
               a33 a34     (aij = conjg(aji))
                   a44
                   
    Packed storage of the upper triangle of A:
    
    AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
    
    
    The structure of the packed array AP depends on the value of UPLO
    in the call to CHETRF. If UPLO = 'U', then AP is packed by columns
    (a11, a12, a22, a13, a23, a33, a14, a24, a34, a44).
    If UPLO = 'L', then AP is packed by columns (a11, a21, a22, a31, a32,
    a33, a41, a42, a43, a44).
    
    The complex conjugate transpose of a Hermitian matrix H is the same as
    the matrix itself. However, the L-factor of a Hermitian matrix is not
    necessarily Hermitian. Therefore, TRANS = 'C' does not mean that the
    conjugate transpose of the original matrix is solved, but rather that the
    conjugate transpose of the L-factor is used in the computation.
    
    Example
    =======
    
    To solve the system of equations A*x = b, where A is the Hermitian
    Hermitian matrix:
    
       1.0+1.0i  2.0-1.0i  3.0-1.0i
                 4.0+1.0i  5.0-1.0i
                           6.0+1.0i
                           
    and
    
       b = [ 1.0+1.0i ]
           [ 2.0-1.0i ]
           [ 3.0-1.0i ]
           
    represented in packed form as:
    
    AP = [ (1.0+1.0i), (2.0-1.0i), (4.0+1.0i), (3.0-1.0i), (5.0-1.0i), (6.0+1.0i) ]
    
    we can call CHPSVX as follows:
    
    C     CHARACTER CTYPE
    C     LOGICAL   FACT
    C     INTEGER   I, INFO, N, NRHS, LDB, LDX
    C     REAL      RCOND, FERR(1), BERR(1)
    C     COMPLEX   AP(6), B(3,1), X(3,1), WORK(6), RWORK(3)
    C
    C     FACT = .FALSE.
    C     TRANS = 'N'
    C     N = 3
    C     NRHS = 1
    C     LDB = 3
    C     LDX = 3
    C     AP = ...
    C     B = ...
    C     CALL CHPSVX(FACT, TRANS, N, NRHS, AP, B, LDB, X, LDX, RCOND,
    C                 FERR, BERR, WORK, RWORK, INFO)
    C
    The solution vector x would be in X.

    ======

    Date
    ====
    
    October 2013
    
    =====================================================================
    
    !> Auxiliary routine for CHPSVX.
    !>
    !>     When the system is:
    !>         A x = b,
    !>     then it is solved by calls to CHETRF and CHETRI.
    !>
    !>     When the system is:
    !>         A^H x = b,
    !>     then it is solved by calls to CHETRF and CHETRI.
    !>
    !>  The factored form of A is the L-factor, which is stored in AP.
    !>  The complex conjugate transpose of a Hermitian matrix is the matrix itself.
    !>  However, the L-factor of a Hermitian matrix is not necessarily Hermitian.
    !>  Therefore, TRANS = 'C' does not mean that the conjugate transpose of the
    !>  original matrix is solved, but rather that the conjugate transpose of the
    !>  L-factor is used in the computation.
    !>
    !>  RCOND is an estimate of the reciprocal of the condition number of A.
    !>  The estimate is computed as R = 1 / (||A|| * ||inv(A)||).
    !>
    !>  FERR and BERR are error bounds for the solution computed by the
    !>  routine. FERR is an upper bound on the relative forward error, and
    !>  BERR is an upper bound on the relative backward error.
    !>
    !>  INFO
    !>  > 0: A is singular and block i, j is zero, so d(i) = 0. The inverse could
    !>         not be computed. RCOND = 0 is returned.
    !>
    !>  When INFO > 0, the matrix is computationally singular. RCOND is set
    !>  to zero, and the solution and error bounds are not computed.
    !>
    !>  = 0: Normal, successful computation.
    !>
    !>  If RCOND is less than machine precision, the matrix is singular to
    !>  working precision. Nevertheless, the solution and error bounds are
    !>  computed because there are a number of situations where the
    !>  computed solution can be more accurate than the value of RCOND would
    !>  suggest.
    !>
    !>  = -i: The i-th argument had an illegal value.
    !>
    !>  When INFO = N+1, the matrix is singular, so the solution and error
    !>  bounds could not be computed. RCOND = 0 is returned.
    !>  = N+1: D is nonsingular, but RCOND is less than machine
    !>         precision, meaning that the matrix is singular
    !>         to working precision.  Nevertheless, the
    !>         solution and error bounds are computed because
    !>         there are a number of situations where the
    !>         computed solution can be more accurate than the
    !>         value of RCOND would suggest.
    !>
