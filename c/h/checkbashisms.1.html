CHECKBASHISMS(1) Manual de Comandos Generales CHECKBASHISMS(1)

NOMBRE

checkbashisms - comprueba bashismos en scripts de /bin/sh

SINOPSIS

checkbashisms script ...
checkbashisms --help|--version

DESCRIPCIÓN

checkbashisms, basado en una de las comprobaciones del sistema lintian, realiza comprobaciones básicas en scripts de shell de /bin/sh para la posible presencia de bashismos. Toma los nombres de los scripts de shell en la línea de comandos y emite advertencias si se detectan posibles bashismos.

Tenga en cuenta que la definición de un bashismo en este contexto equivale aproximadamente a "una característica del shell que no se requiere que sea compatible con POSIX"; esto significa que algunos problemas señalados pueden permitirse bajo secciones opcionales de POSIX, como XSI o Portabilidad de Usuario.

En los casos en que POSIX y la Política de Debian discrepan, checkbashisms permite por defecto extensiones permitidas por la Política, pero también puede proporcionar opciones para una comprobación más estricta.

OPCIONES

--help, -h
Muestra un resumen de las opciones.
--newline, -n
Comprueba el uso de "echo -n" (no es POSIX pero es requerido por la Política de Debian 10.4).
--posix, -p
Comprueba problemas que no son POSIX pero que se requieren para ser soportados por la Política de Debian 10.4 (implica -n).
--force, -f
Fuerza la comprobación de cada script, incluso si normalmente no se haría (por ejemplo, tiene un shebang de bash o de un shell no POSIX o parece ser un script de envoltura).
--lint, -l
Actúa como un linter, para su integración en un editor de texto. Los posibles bashismos se imprimirán en la salida estándar, de la siguiente manera:
{nombre_archivo}:{numero_linea}:1: advertencia: posible bashismo; {explicación}
--extra, -x
Resalta las líneas que, aunque no contienen bashismos, pueden ser útiles para determinar si un problema particular es un falso positivo que puede ser ignorado. Por ejemplo, el uso de "$BASH_ENV" puede ir precedido de la comprobación de si "$BASH" está definido.
--early-fail, -e
Sale justo después de ver el primer error.
--version, -v
Muestra la información de versión y copyright.

VALORES DE SALIDA

El valor de salida será 0 si no se detectaron posibles bashismos u otros problemas. De lo contrario, será la suma de los siguientes valores de error:

1
Se detectó un posible bashismo.
2
Un archivo fue omitido por alguna razón, por ejemplo, porque no se podía leer o no se encontró. El mensaje de advertencia proporcionará detalles.
4
No se detectaron bashismos en un script de bash.
