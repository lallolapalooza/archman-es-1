CHEGV

D

Propósito

: 
!>
!> CHEGVD calcula todos los eigenvalores y, opcionalmente, los autovectores
!> de un problema de eigenvalores generalizado hermitiano-definido, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.  Aquí se asume que A y
!> B son hermitianas y que B es también definida positiva.
!> Si se desean autovectores, se utiliza un algoritmo de división y conquista.
!>
!
>

Parámetro

s
ITYPE !> ITYPE es INTEGER !> Especifica el tipo de problema a resolver: !> = 1: A*x = (lambda)*B*x !> = 2: A*B*x = (lambda)*x !> = 3: B*A*x = (lambda)*x !> JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores;
!>          = 'V':  Calcula los eigenvalores y los autovectores.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA, N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior de A de tamaño N por N contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior de A de tamaño N por N contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de autovectores.  Los autovectores se normalizan
!>          de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se
destruye. !>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB, N)
!>          En la entrada, la matriz hermitiana B.  Si UPLO = 'U', la
!>          parte triangular superior de B de tamaño N por N contiene la
!>          parte triangular superior de la matriz B.  Si UPLO = 'L',
!>          la parte triangular inferior de B de tamaño N por N contiene
!>          la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz es
!>          sobrescrita por el factor triangular U o L de la factorización
!>          de Cholesky B = U**H*U o B = L*L**H.
!>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!
>

W 
!>          W es un arreglo REAL, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

WO

RK 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.

LWOR

K

!>          Si JOBZ  = 'N' y N > 1, LWORK >= N + 1.

!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina

!>
!>          Si LRWORK = -1, se asume una consulta de espacio de trabajo; la

!>          La dimensión del arreglo IWORK.

!>          Si JOBZ  = 'N' y N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arreglos WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas
!>          de los arreglos WORK, RWORK e IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK por parte de XERBLA.
!>

O 
!>          INFO es INTEGER

!>          > 0:  CPOTRF o CHEEVD devolvió un código de error:
!>             <= N:  si INFO = i y JOBZ = 'N', entonces el algoritmo
!>                    falló al converger; i elementos fuera de la diagonal de una
!>                    forma tridiagonal intermedia no convergieron a
!>                    cero;
!>                    si INFO = i y JOBZ = 'V', entonces el algoritmo
!>                    falló al calcular un eigenvalor mientras trabajaba en
!>                    la submatriz que se encuentra en las filas y columnas INFO/(N+1)
!>                    hasta mod(INFO,N+1);
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y

NAME

chegvd - Computes the eigenvalues and eigenvectors of a complex Hermitian–positive definite generalized eigenvalue problem.

SYNOPSIS

SUBROUTINE CHGVD( ITYPE, JOBZ, RANGE, UPLO, N, A, LDA, B, LDB,
                       VL, VU, IL, IU, M, W, Z, LDZ, WORK, RWORK, INFO )
    
        CHARACTER * 1   JOBZ
        CHARACTER * 1   RANGE
        CHARACTER * 1   UPLO
        INTEGER         IL, IL, INFO, ITYPE, LDA, LDB, LDZ, M, N
        REAL            RWORK( * )
        COMPLEX*16      A( LDA, * ), B( LDB, * ), VL, VU, W( * ),
                        WORK( * ), Z( LDZ, * )

Function/Subroutine Documentation

CHGVD is a complex subroutine that computes the eigenvalues and eigenvectors of a complex Hermitian-positive definite generalized eigenvalue problem of the form:

A*x = lambda*B*x

where A and B are Hermitian-positive definite matrices.

ITYPE
Integer. Specifies the problem type:
1 -- A*x = lambda*B*x
2 -- A*B*x = lambda*x
3 -- A*x = lambda*B**(-1)*x
JOBZ
Character. 'V' compute eigenvectors, 'N' compute only eigenvalues.
RANGE
Character. 'A' all eigenvalues, 'V' range (VL, VU), 'I' Nth eigenvalues.
UPLO
Character. 'U' upper triangle of A and B, 'L' lower triangle of A and B.
N
Integer. Order of the matrices A and B.
A
Complex*16 array, dimension (LDA, N). On entry, the upper or lower triangle of the Hermitian matrix A.
LDA
Integer. Leading dimension of A.
B
Complex*16 array, dimension (LDB, N). On entry, the upper or lower triangle of the Hermitian positive-definite matrix B.
LDB
Integer. Leading dimension of B.
VL
Complex*16. If RANGE='V', the lower bound of the eigenvalue range.
VU
Complex*16. If RANGE='V', the upper bound of the eigenvalue range.
IL
Integer. If RANGE='I', the rank of the first eigenvalue to be computed.
IU
Integer. If RANGE='I', the rank of the last eigenvalue to be computed.
M
Integer. Number of eigenvalues found.
W
Complex*16 array, dimension (N). The computed eigenvalues in ascending order.
Z
Complex*16 array, dimension (LDZ, N). If JOBZ='V', Z contains the eigenvectors. If JOBZ='N', Z is not used.
LDZ
Integer. Leading dimension of Z.
WORK
Complex*16 array, dimension (MAX(1,LWORK)).
RWORK
Real array, dimension (MAX(1,LRWORK)).
INFO
Integer. Zero on success, otherwise a negative return code.
