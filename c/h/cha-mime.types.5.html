CHA-MIME.TYPES(5) Manual de Formatos de Archivo CHA-MIME.TYPES(5)

mime.types

Chawan utiliza el archivo mime.types para reconocer ciertas extensiones de archivo para hacer coincidir entradas de mailcap. Consulte la documentación de cha-mailcap(5) para obtener una descripción de mailcap.

Ruta de búsqueda

Chawan analiza todos los archivos mime.types definidos en external.mime-types. Si no se encuentra ningún archivo mime.types, se utilizan las asociaciones de tipos MIME integradas.

La ruta de búsqueda predeterminada para los archivos mime.types es:

$HOME/.mime.types:/etc/mime.types:/usr/etc/mime.types:/usr/local/etc/mime.types

Formato

El archivo mime.types es una lista de columnas separadas por espacios en blanco. La primera columna representa el tipo MIME, todas las columnas siguientes son extensiones de archivo.

Las líneas que comienzan con un carácter de almohadilla (#) se reconocen como comentarios y se ignoran.

Ejemplo:

# comentario
application/x-example	exmpl	ex

Este archivo mime.types registraría las extensiones de archivo "exmpl" y "ex" para ser reconocidas como el tipo MIME application/x-example.

Nota

Chawan solo utiliza archivos mime.types para encontrar entradas mailcap; los buffers utilizan un archivo mime.types interno para la detección del tipo de contenido en su lugar.

El archivo mime.types predeterminado solo incluye formatos de archivo que los buffers pueden manejar, lo cual es bastante limitado (en el momento de escribir esto, 7 formatos de archivo). Por lo tanto, se recomienda encarecidamente configurar al menos un archivo mime.types externo si utiliza mailcap.
