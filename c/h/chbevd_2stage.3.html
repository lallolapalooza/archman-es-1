SRC/chbevd_2stage.f

SINOPSIS

Funciones/Subrutinas


subrutina chbevd_2stage (jobz, uplo, n, kd, ab, ldab, w, z, ldz, work, lwork, rwork, lrwork, iwork, liwork, info)
CHBEVD_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para MATRICES OTROS

Documentación de Función/Subrutina

subrutina chbevd_2stage (carácter jobz, carácter uplo, entero n, entero kd, complejo, dimensión( ldab, * ) ab, entero ldab, real, dimensión( * ) w, complejo, dimensión( ldz, * ) z, entero ldz, complejo, dimensión( * ) work, entero lwork, real, dimensión( * ) rwork, entero lrwork, entero, dimensión( * ) iwork, entero liwork, entero info)

CHBEVD_2STAGE calcula los valores propios y, opcionalmente, los vectores propios de una matriz banda Hermítica compleja A utilizando la técnica 2stage para la reducción a tridiagonal. Si se desean vectores propios, utiliza un algoritmo de divide y vencerás.

Propósito:

!>
!> CHBEVD_2STAGE calcula todos los valores propios y, opcionalmente, los
!> vectores propios de una matriz banda Hermítica compleja A utilizando la
!> técnica 2stage para la reducción a tridiagonal. Si se desean vectores propios,
!> utiliza un algoritmo de divide y vencerás.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es array COMPLEX, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz banda
!>          Hermítica A, almacenado en las primeras KD+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          como sigue:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

W

!>          W es array REAL, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es array COMPLEX, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los
!>          vectores propios ortonormales de la matriz A, con la columna
!>          i de Z conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          en caso contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = (2KD+1)*N + KD*NTHREADS
!>                                   donde KD es el tamaño de la banda.
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK por XERBLA.
!>

RWORK

!>          RWORK es array REAL,
!>                                         dimensión (LRWORK)
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si N <= 1,               LRWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LRWORK debe ser al menos N.
!>          Si JOBZ = 'V' y N > 1, LRWORK debe ser al menos
!>                        1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK por XERBLA.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si JOBZ = 'V' y N > 1, LIWORK debe ser al menos 3 + 5*N .
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Salida exitosa.
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo no convergió; i
!>                elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                no convergieron a cero.
!>
