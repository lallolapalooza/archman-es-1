CHRT(1) Comandos de usuario CHRT(1)

NOMBRE

chrt - manipular los atributos de tiempo real de un proceso

SINOPSIS

chrt [opciones] prioridad comando argumento ...

chrt [opciones] -p [prioridad] PID

DESCRIPCIÓN

chrt establece o recupera los atributos de planificación en tiempo real de un PID existente, o ejecuta un comando con los atributos dados.

POLÍTICAS

-o, --other

Establece la política de planificación a SCHED_OTHER (planificación de tiempo compartido). Esta es la política de planificación predeterminada de Linux.

-f, --fifo

Establece la política de planificación a SCHED_FIFO (first in, first out).

-r, --rr

Establece la política de planificación a SCHED_RR (planificación round-robin). Cuando no se define ninguna política, se utiliza SCHED_RR como valor predeterminado.

-b, --batch

Establece la política de planificación a SCHED_BATCH (planificación de procesos batch). Específico de Linux, compatible desde la versión 2.6.16. El argumento de prioridad debe establecerse a cero.

-i, --idle

Establece la política de planificación a SCHED_IDLE (planificación de trabajos de muy baja prioridad). Específico de Linux, compatible desde la versión 2.6.23. El argumento de prioridad debe establecerse a cero.

-d, --deadline

Establece la política de planificación a SCHED_DEADLINE (planificación de plazo de tareas esporádicas). Específico de Linux, compatible desde la versión 3.14. El argumento de prioridad debe establecerse a cero. Consulte también --sched-runtime, --sched-deadline y --sched-period. La relación entre las opciones requeridas por el kernel es runtime ⇐ deadline ⇐ period. chrt copia period a deadline si --sched-deadline no se especifica y deadline a runtime si --sched-runtime no se especifica. Esto significa que al menos --sched-period debe especificarse. Consulte sched(7) para más detalles.

OPCIONES DE PLANIFICACIÓN

-T, --sched-runtime nanosegundos

Especifica el parámetro de tiempo de ejecución para SCHED_DEADLINE y la longitud de la porción personalizada para las políticas SCHED_OTHER y SCHED_BATCH (específico de Linux). Tenga en cuenta que la longitud de la porción personalizada a través del parámetro de tiempo de ejecución es compatible desde Linux 6.12.

-P, --sched-period nanosegundos

Especifica el parámetro de período para la política SCHED_DEADLINE (específico de Linux). Tenga en cuenta que el límite inferior del kernel es de 100 milisegundos.

-D, --sched-deadline nanosegundos

Especifica el parámetro de plazo para la política SCHED_DEADLINE (específico de Linux).

-R, --reset-on-fork

Utiliza la bandera SCHED_RESET_ON_FORK o SCHED_FLAG_RESET_ON_FORK. Específico de Linux, compatible desde la versión 2.6.31.

Cada hilo tiene una bandera de planificación de reset-on-fork. Cuando esta bandera está establecida, los hijos creados por fork(2) no heredan políticas de planificación privilegiadas. Después de que la bandera de reset-on-fork se haya habilitado, solo puede restablecerse si el hilo tiene la capacidad CAP_SYS_NICE. Esta bandera está deshabilitada en los procesos hijos creados por fork(2).

Más precisamente, si la bandera de reset-on-fork está establecida, las siguientes reglas se aplican a los hijos creados posteriormente:

•Si la política de planificación del hilo que llama es SCHED_FIFO o SCHED_RR, la política se restablece a SCHED_OTHER en los procesos hijos.
•Si el proceso que llama tiene un valor de nice negativo, el valor de nice se restablece a cero en los procesos hijos.

OPCIONES

-a, --all-tasks

Establece o recupera los atributos de planificación de todas las tareas (hilos) para un PID dado.

-m, --max

Muestra las prioridades mínimas y máximas válidas y luego sale.

-p, --pid

Opera en un PID existente y no inicia una nueva tarea.

-v, --verbose

Muestra información de estado.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

EJEMPLOS

El comportamiento predeterminado es ejecutar un nuevo comando:

chrt prioridad comando [argumentos]

También puedes recuperar los atributos de tiempo real de una tarea existente:

chrt -p PID

O establecerlos:

chrt -r -p prioridad PID

Esto, por ejemplo, establece la planificación en tiempo real a la prioridad 30 para el proceso PID con la clase SCHED_RR (round-robin):

chrt -r -p 30 PID

Restablece las prioridades a los valores predeterminados para un proceso:

chrt -o -p 0 PID

Consulta sched(7) para una discusión detallada de las diferentes clases de planificadores y cómo interactúan.

PERMISOS

Un usuario debe poseer CAP_SYS_NICE para cambiar los atributos de planificación de un proceso. Cualquier usuario puede recuperar la información de planificación.

NOTAS

Solo SCHED_FIFO, SCHED_OTHER y SCHED_RR forman parte de POSIX 1003.1b Process Scheduling. Los otros atributos de planificación pueden ser ignorados en algunos sistemas.

La política de planificación predeterminada de Linux es SCHED_OTHER.
