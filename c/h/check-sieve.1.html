NOMBRE

check-sieve - Verificador de sintaxis para filtros de correo.

SINOPSIS

check-sieve [opciones] archivo [ archivo ... ]
check-sieve --help
check-sieve --version

DESCRIPCIÓN

check-sieve es un simple verificador de sintaxis para filtros de correo del lado del servidor. Soporta muchos RFC de filtros de correo, cuyos detalles se pueden encontrar a continuación.

OPCIONES

-h, --help
Mostrar la ayuda del programa
--max-list-length N
Verificar la longitud de las listas de cadenas, y marcar cualquiera que sea más larga que la longitud especificada
--server <host>:<puerto>
Conectarse al servidor especificado, y habilitar solo las capacidades anunciadas
--trace-parser
Rastrear la operación del analizador sintáctico
--trace-scanner
Rastrear la operación del escáner
--trace-tree
Rastrear el árbol de sintaxis abstracta
--version
Imprimir información de la versión

ERRORES

Para obtener información sobre problemas existentes y para reportar un error, consulte la siguiente URL: https://github.com/dburkart/check-sieve/issues
