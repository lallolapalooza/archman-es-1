chktex(1) Manual de Comandos Generales chktex(1)

NOMBRE

chktex - encuentra errores tipográficos en LaTeX.

SINOPSIS

chktex [-hiqrW] [-v[0-...]] [-l <rcfile>] [-[wemn] <[1-42]|todo>] [-d[0-...]] [-p <nombre>] [-o <salida>] [-[btxgI][0|1]] archivo1 archivo2 ...

DESCRIPCIÓN

chktex encuentra errores tipográficos en LaTeX

OPCIONES

Opciones varias:

-h --ayuda
Imprime una pantalla de ayuda.
-i --licencia
Muestra información de distribución.
-l --rc-local
Lee un archivo local con formato .chktexrc.
-d --debug
Información de depuración. Dale un número.
-r --reiniciar
Restablece la configuración a los valores predeterminados.

Silenciar mensajes de advertencia:

-w --advertencia-activada
Convierte el mensaje # dado en una advertencia y la activa.
-e --error-activado
Convierte el mensaje # dado en un error y lo activa.
-m --mensaje-activado
Convierte el mensaje # dado en un mensaje y lo activa.
-n --sin-advertencia
Silencia el mensaje # dado.
-L --sin-supresion-linea
No permite supresiones por línea. Estos son comentarios TeX del tipo % chktex ## .

Indicadores de control de salida:

-v --verborrea
Cómo se muestran los errores. Predeterminado 1, 0=Menos, 2=Elegante, 3=lacheck.
-V --verborrea-tubería
Cómo se muestran los errores cuando stdout != tty. Por defecto, lo mismo que -v.
-s --caracter-division
Cadena utilizada para dividir campos cuando se usa -v0
-o --salida
Redirige el informe de errores a un archivo.
-q --silencioso
Se calla sobre la información de la versión.
-p --nombre-pseudo
Nombre de archivo de entrada al informar.
-f --formato
Formato a utilizar para la salida

Interruptores booleanos (1 -> habilita / 0 -> deshabilita):

-b --copia-seguridad
Copia de seguridad del archivo de salida.
-x --ignorar-verborrea
Ignora el contenido de los comandos `\verb'
-g --rc-global
Lee el archivo global .chktexrc.
-I --archivos-entrada
Ejecuta las declaraciones \input.
-H --error-encabezado
Muestra errores encontrados antes de \begin{document}
-W --version
Información de versión

Si no se especifican archivos LaTeX en la línea de comandos, leeremos desde la entrada estándar. Para obtener una explicación de los mensajes de advertencia/error, consulte el documento principal /usr/share/doc/chktex/ChkTeX.dvi.gz.
