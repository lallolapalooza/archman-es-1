Nombre

ctags-lang-clojure - Notas aleatorias sobre el etiquetado de código fuente Clojure con Universal Ctags

SINAPSIS

ctags ... --languages=+Clojure ...
ctags ... --language-force=Clojure ...
ctags ... --map-Clojure=+.clj ...
ctags ... --map-Clojure=+.cljs ...
ctags ... --map-Clojure=+.cljc ...

DESCRIPCIÓN

Esta página del manual recopila notas aleatorias sobre el etiquetado de código fuente Clojure.

  • Se añade el campo definer.
