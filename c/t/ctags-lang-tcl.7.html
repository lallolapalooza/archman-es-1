ctags-lang-tcl - Notas aleatorias sobre el etiquetado de código fuente tcl con Universal Ctags

SINÓPSIS

ctags ... --languages=+Tcl ...
ctags ... --language-force=Tcl ...
ctags ... --map-Tcl=+.tcl ...

DESCRIPCIÓN

Esta página del manual recopila notas aleatorias sobre el etiquetado de código fuente tcl.

ETIQUETADO DE objetos de lenguaje de Extensiones OO

El analizador TclOO y el analizador ITcl son subanalizadores que se ejecutan sobre el analizador Tcl. Como indican los nombres de los analizadores, son para etiquetar objetos de lenguaje de extensiones de programación orientada a objetos para el lenguaje Tcl.

Un patrón, "namespace import oo" en un archivo de entrada activa el analizador TclOO. Un patrón, "namespace import itcl" en un archivo de entrada activa el analizador ITcl.

Hay casos en los que se utiliza una de las extensiones OO aunque ninguno de los patrones aparezca en un archivo de entrada.

Considere los siguientes archivos de entrada:

"main.tcl"

package require Itcl
namespace import itcl::*
source input.tcl

"input.tcl"

class MyClass {
        public method foo {} {
        }
}

El patrón para activar el analizador ITcl no aparece en "input.tcl" aunque se utiliza el comando "class". Como resultado, ctags no puede extraer "MyClass".

Los parámetros TclOO.forceUse=true|[false] y ITcl.forceuse=true|[false] para manejar esta situación. Con el parámetro, puedes forzar a ctags a activar uno de los subanalizadores.

Puedes usar los parámetros como --param-ITcl.forceuse=true en la línea de comandos.

Ten en cuenta que solo puedes habilitar un analizador, el analizador ITcl o el analizador TclOO. Habilitar ambos analizadores especificando los parámetros puede producir resultados inesperados.
