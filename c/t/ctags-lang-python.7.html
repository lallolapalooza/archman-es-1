Una etiqueta para un módulo importado tiene el tipo module con el rol imported. El módulo no está definido aquí; está definido en otro archivo. Por lo tanto, la etiqueta para el módulo importado es una etiqueta de referencia; especifique --extras=+r (o --extras=+{reference}) para etiquetarlo. El campo "roles:" habilitado con --fields=+r sirve para registrar que el módulo es "imported" en el archivo de

etiquetas.

"Y1" introduce un nuevo nombre y está definido aquí. Por lo tanto, "Y1" se etiqueta como una etiqueta de definición. "X1" se importa de una manera que su nombre no puede usarse en este archivo fuente. Para que las herramientas cliente sepan que el nombre no puede usarse, se asigna el rol indirectlyImported a "X1". "id".

Si una variable ("id_t") con pista de tipo es inicializada con una expresión lambda, ctags asigna el tipo variable para la etiqueta de "id_t" con los campos typeref: y nameref:. ctags rellena el campo typeref: con el valor de la pista de tipo. La forma de rellenar el

campo

nameref: es un poco complicada. Para la expresión lambda usada en la inicialización de la variable con pista de tipo, ctags crea una etiqueta extra anónima ("anonFunc84011d2c0101"). ctags rellena el campo nameref: de "id_t" con el nombre
