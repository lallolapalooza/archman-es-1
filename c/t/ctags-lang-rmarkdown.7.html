ctags-lang-rmarkdown(7) Universal Ctags ctags-lang-rmarkdown(7)

Nombre

ctags-lang-rmarkdown - Notas aleatorias sobre el etiquetado de código fuente R Markdown con Universal Ctags

SINOPSIS

ctags ...--extras=+{subparser}{guest} --languages=+RMarkdown ...
ctags ...--extras=+{subparser}{guest} --language-force=RMarkdown ...
ctags ...--extras=+{subparser}{guest} --map-RMarkdown=+.rmd ...

DESCRIPCIÓN

El analizador RMarkdown es un sub-analizador exclusivo apilado sobre el analizador Markdown. Funciona cuando:

  • el analizador Markdown está habilitado,
  • la opción extra subparser está habilitada, y
  • el propio analizador RMarkdown está habilitado.

El analizador RMarkdown extiende la forma de detectar codeblocks del analizador Markdown. Esta extensión es para ejecutar analizadores invitados en code chunks.

El analizador Markdown espera que la siguiente sintaxis represente bloques de código:

```language-name
        ...
```

Por ejemplo

```r
        ...
```

El analizador RMarkdown acepta la siguiente sintaxis para los fragmentos de código:

```{language-name chunk-label, ...}
        ...
```

Por ejemplo

```{r precalc fig.height=4}
        ...
```

Proporcione --extras=+{guest} para habilitar guest en la línea de comandos si desea ejecutar analizadores adecuados en las líneas dentro de los fragmentos de código.

El analizador extrae las etiquetas de fragmento que siguen a language-name como objetos de tipo chunklabel. En el ejemplo, el analizador RMarkdown extrae precalc como un objeto de tipo chunklabel. El tipo chunklabel está habilitado por defecto.

EJEMPLOS

"input.rmd"

# Sección 1
```{r myblock}
        zero_fun <- function () {
                return 0
        }
```
# Sección 2

"output.tags" con "--options=NONE --extras=+{guest} --fields=+KZln -o - input.rmd"

Section 1       input.rmd       /^# Section 1$/;"       chapter line:1  language:Markdown
Section 2       input.rmd       /^# Section 2$/;"       chapter line:9  language:Markdown
myblock input.rmd       /^```{r myblock}$/;"    chunklabel      line:3  language:RMarkdown
zero_fun        input.rmd       /^      zero_fun <- function () {$/;"   function        line:4  language:R
