Nombre

ctags-lang-inko -

Sinopsis

ctags ... --languages=+Inko ...
ctags ... --language-force=Inko ...
ctags ... --map-Inko=+.inko ...

Descripción

Esta página del manual describe el analizador de Inko para Universal Ctags.

Se espera que el archivo de entrada sea código fuente de Inko válido; de lo contrario, el resultado de ctags no está definido.

Se generan etiquetas para objetos, traits, métodos, atributos y constantes. Se ignoran los literales de cadena.

Ver también

ctags(1), ctags-client-tools(7)
