Nombre

ctags-lang-autoit - Notas varias sobre el etiquetado de código fuente de AutoIt con Universal Ctags

SINAPSIS

ctags ... --languages=+AutoIt ...
ctags ... --language-force=AutoIt ...
ctags ... --map-AutoIt=+.au3 ...

DESCRIPCIÓN

Esta página del manual recopila notas varias sobre el etiquetado de código fuente de AutoIt.

VERSIONES

Cambio desde "0.0"

•
Eliminar el carácter $ de las etiquetas para nombres de variables.
