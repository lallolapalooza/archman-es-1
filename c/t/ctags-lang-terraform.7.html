Nombre

ctags-lang-terraform - Notas diversas sobre el etiquetado de archivos Terraform con Ctags Universal

Sinopsis

ctags ... --languages=+Terraform ...
ctags ... --language-force=Terraform ...
ctags ... --map-Terraform=+.tf ...
ctags ... --extras=+{reference} --languages=+TerraformVariables ...
ctags ... --extras=+{reference} --language-force=TerraformVariables ...
ctags ... --extras=+{reference} --map-Terraform=+.tfvars ...

Descripción

Esta página del manual recopila notas diversas sobre el etiquetado de archivos Terraform.

Consejos

Extracción de variables asignadas en definiciones de variables

Especifique --extras=+{reference} y --languages=+TerraformVariables para extraer variables asignadas en definiciones de variables (*.tfvars). El analizador TerraformVariables extrae variables en archivos *.tfvars con el tipo variable y el rol assigned del lenguaje Terraform.
