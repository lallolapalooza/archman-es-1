PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ctype.h — tipos de caracteres

SINOPSIS

#include <ctype.h>

DESCRIPCIÓN

Parte de la funcionalidad descrita en esta página de referencia extiende el estándar ISO C. Las aplicaciones deberán definir la macro de prueba de características apropiada (consulte el volumen de Interfaces del Sistema de POSIX.1‐2017, *Sección 2.2*, *El Entorno de Compilación*) para habilitar la visibilidad de estos símbolos en esta cabecera.

La cabecera <ctype.h> definirá el tipo locale_t como se describe en <locale.h>, representando un objeto de localidad.

Las siguientes se declararán como funciones y también podrán definirse como macros. Se proporcionarán prototipos de función para su uso con compiladores estándar ISO C.

int   isalnum(int);
int   isalnum_l(int, locale_t);
int   isalpha(int);
int   isalpha_l(int, locale_t);
int   isascii(int);
int   isblank(int);
int   isblank_l(int, locale_t);
int   iscntrl(int);
int   iscntrl_l(int, locale_t);
int   isdigit(int);
int   isdigit_l(int, locale_t);
int   isgraph(int);
int   isgraph_l(int, locale_t);
int   islower(int);
int   islower_l(int, locale_t);
int   isprint(int);
int   isprint_l(int, locale_t);
int   ispunct(int);
int   ispunct_l(int, locale_t);
int   isspace(int);
int   isspace_l(int, locale_t);
int   isupper(int);
int   isupper_l(int, locale_t);
int   isxdigit(int);
int   isxdigit_l(int, locale_t);
int   toascii(int);
int   tolower(int);
int   tolower_l(int, locale_t);
int   toupper(int);
int   toupper_l(int, locale_t);

La cabecera <ctype.h> definirá lo siguiente como macros:

int   _toupper(int);
int   _tolower(int);
