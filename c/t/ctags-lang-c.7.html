Nombre

ctags-lang-c - Notas varias sobre el etiquetado de código fuente C con Universal Ctags

SINOPSIS

ctags ... --languages=+C ...
ctags ... --language-force=C ...
ctags ... --map-C=+.c ...

DESCRIPCIÓN

Esta página del manual recopila notas varias sobre el etiquetado de código fuente C.

VERSIÓNES

Cambio desde "0.0"

  • Nuevo rol foreigndecl para el tipo function
  • Nuevo rol foreigndecl para el tipo struct
  • Nuevo campo section
  • Nuevo campo alias

VEA TAMBIÉN

ctags(1), ctags-lang-ldscript(7), El nuevo analizador C/C++ https://docs.ctags.io/en/latest/parser-cxx.html (https://docs.ctags.io/en/latest/parser-cxx.html)
