Nombre

ctags-lang-c++ - Notas aleatorias sobre el etiquetado de código fuente C++ con Universal Ctags

SINOPSIS

ctags ... --languages=+C++ ...
ctags ... --language-force=C++ ...
ctags ... --map-C++=+.c++  ...
ctags ... --map-C++=+.cc  ...
ctags ... --map-C++=+.cpp  ...
ctags ... --map-C++=+.h  ...
...

DESCRIPCIÓN

Esta página del manual recopila notas aleatorias sobre el etiquetado de código fuente C++.

VERSIÓNES

Cambio desde "0.0"

  • Nuevo campo section
  • Nuevo campo alias

Cambio desde "1.1"

  • Nuevos tipos module y partition
  • Nuevos roles imported y exported para el tipo header

VER TAMBIÉN

ctags(1), ctags-lang-ldscript(7), El nuevo analizador C/C++ https://docs.ctags.io/en/latest/parser-cxx.html (https://docs.ctags.io/en/latest/parser-cxx.html)
