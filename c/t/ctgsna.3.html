subrutina ctgsna (character job, character howmny, logical, dimension( * ) select, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) s, real, dimension( * ) dif, integer mm, integer m, complex, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer

CTGSN

A

Propósito

: 
!>
!> CTGSNA estima los números de condición recíprocos para autovalores
!> y/o autovectores especificados de un par de matrices (A, B).
!>
!> (A, B) debe estar en forma canónica de Schur generalizada, es decir, A y
!> B son ambas triangulares superiores.
!
>

Parámetro

s
JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          autovalores (S) o autovectores (DIF):
!>          = 'E': solo para autovalores (S);
!>          = 'V': solo para autovectores (DIF);
!>          = 'B': tanto para autovalores como para autovectores (S y DIF).
!
>

HOWMN

Y 
!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular números de condición para todos los autoemparejamientos;
!>          = 'S': calcular números de condición para los autoemparejamientos seleccionados
!>                 especificados por el array SELECT.
!
>

SELEC

T 
!>          SELECT es un array LOGICAL, dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los autoemparejamientos para los cuales
!>          se requieren números de condición. Para seleccionar números de condición
!>          para el j-ésimo autovalor y/o autovector correspondiente,
!>          SELECT(j) debe establecerse en .TRUE..
!>          Si HOWMNY = 'A', SELECT no es referenciado.
!
>

N 
!>          N es INTEGER
!>          El orden del par de matrices cuadradas (A, B). N >= 0.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,N)
!>          La matriz triangular superior A en el par (A,B).
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!
>

B 
!>          B es un array COMPLEX, dimensión (LDB,N)
!>          La matriz triangular superior B en el par (A, B).
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!
>

V

L 
!>          VL es un array COMPLEX, dimensión (LDVL,M)
!>          SI JOB = 'E' o 'B', VL debe contener autovectores izquierdos de
!>          (A, B), correspondientes a los autoemparejamientos especificados por HOWMNY
!>          y SELECT.  Los autovectores deben almacenarse en columnas consecutivas
!>          de VL, como los devuelve CTGEVC.
!>          Si JOB = 'V', VL no es referenciado.
!
>

LDV

L 
!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; y
!>          Si JOB = 'E' o 'B', LDVL >= N.
!
>

V

R 
!>          VR es un array COMPLEX, dimensión (LDVR,M)
!>          SI JOB = 'E' o 'B', VR debe contener autovectores derechos de
!>          (A, B), correspondientes a los autoemparejamientos especificados por HOWMNY
!>          y SELECT.  Los autovectores deben almacenarse en columnas consecutivas
!>          de VR, como los devuelve CTGEVC.
!>          Si JOB = 'V', VR no es referenciado.
!
>

LDV

R 
!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1;
!>          Si JOB = 'E' o 'B', LDVR >= N.
!
>

S 
!>          S es un array REAL, dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          autovalores seleccionados, almacenados en elementos consecutivos del
!>          array.
!>          Si JOB = 'V', S no es referenciado.
!
>

DI

F 
!>          DIF es un array REAL, dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos estimados de los
!>          autovectores seleccionados, almacenados en elementos consecutivos del
!>          array.
!>          Si los autovalores no pueden reordenarse para calcular DIF(j),
!>          DIF(j) se establece en 0; esto solo puede ocurrir cuando el valor real
!>          sería muy pequeño de todos modos.
!>          Para cada autovalor/vector especificado por SELECT, DIF almacena
!>          una estimación basada en la norma de Frobenius de Difl.
!>          Si JOB = 'E', DIF no es referenciado.
!
>

M

M 
!>          MM es INTEGER
!>          El número de elementos en los arrays S y DIF. MM >= M.
!
>

M 
!>          M es INTEGER
!>          El número de elementos de los arrays S y DIF utilizados para almacenar
!>          los números de condición especificados; para cada autovalor seleccionado
!>          se usa un elemento. Si HOWMNY = 'A', M se establece en N.
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' o 'B', LWORK >= max(1,2*N*N).
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (N+2)
!>          Si JOB = 'E', IWORK no es referenciado.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: Salida exitosa
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>

Detalles

Adicionales: 
!>
!>  El recíproco del número de condición del i-ésimo autovalor generalizado
!>  w = (a, b) se define como
!>
!>          S(I) = (|v**HAu|**2 + |v**HBu|**2)**(1/2) / (norm(u)*norm(v))
!>
!>  donde u y v son los autovectores derecho e izquierdo de (A, B)
!>  correspondientes a w; |z| denota el valor absoluto del número complejo
!>  y norm(u) denota la 2-norma del vector u. El par
!>  (a, b) corresponde a un autovalor w = a/b (= v**HAu/v**HBu) del
!>  par de matrices (A, B). Si tanto a como b son iguales a cero, entonces (A,B) es
!>  singular y se devuelve S(I) = -1.
!>
!>  Una cota de error aproximada sobre la distancia cordal entre el i-ésimo
!>  autovalor generalizado calculado w y el autovalor exacto
!>  correspondiente lambda es
!>
!>          chord(w, lambda) <=   EPS * norm(A, B) / S(I),
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El recíproco del número de condición del autovector derecho u
!>  y el autovector izquierdo v correspondientes al autovalor generalizado w
!>  se define como sigue. Supongamos
!>
!>                   (A, B) = ( a   *  ) ( b  *  )  1
!>                            ( 0  A22 ),( 0 B22 )  n-1
!>                              1  n-1     1 n-1
!>
!>  Entonces el número de condición recíproco DIF(I) es
!>
!>          Difl[(a, b), (A22, B22)]  = sigma-min( Zl )
!>
!>  donde sigma-min(Zl) denota el valor singular más pequeño de
!>
!>         Zl = [ kron(a, In-1) -kron(1, A22) ]
!>              [ kron(b, In-1) -kron(1, B22) ].
!>
!>  Aquí In-1 es la matriz identidad de tamaño n-1 y X**H es la transpuesta
!>  conjugada de X. kron(X, Y) es el producto de Kroneckeproducto entre las
!>  matrices X e Y.
!>
!>  Aproximamos el valor singular más pequeño de Zl con una
!>  cota superior. Esto se hace mediante CLATDF.
!>
!>  Se proporciona una cota de error aproximada para un autovector calculado VL(i) o
!>  VR(i) mediante
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!>  Consulte la referencia [2-3] para más detalles y referencias adicionales.
!
>
