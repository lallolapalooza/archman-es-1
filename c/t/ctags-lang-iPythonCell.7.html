Nombre

ctags-lang-iPythonCell - La página del manual del analizador iPythonCell para Universal Ctags

SINOPSIS

ctags ... --extras=+{subparser} --languages=+iPythonCell,Python \
[--extras-IPythonCell=+{doubleSharps}] \
[--regex-IPythonCell=/<PATRÓN>/\n/c/] ...

DESCRIPCIÓN

El analizador iPythonCell es un sub-analizador apilado sobre el analizador de Python. Funciona cuando:

  • el analizador de Python está habilitado,
  • la opción extra subparser está habilitada, y
  • el propio analizador iPythonCell está habilitado.

El analizador iPythonCell extrae celdas explicadas como en vim-ipython-cell (https://github.com/hanschen/vim-ipython-cell/blob/master/README.md).

TIPO(S)

El analizador iPythonCell solo define un tipo cell.

EXTRA(S)

El etiquetado de celdas que comienzan con ##... está deshabilitado por defecto porque el patrón es demasiado genérico; con ese patrón se pueden extraer etiquetas no deseadas.

Habilite el extra específico del lenguaje doubleSharps para etiquetar celdas que comiencen con ##....

PERSONALIZACIÓN

Si su patrón de celda favorito no es compatible con el analizador, puede definir el patrón en su archivo .ctagd.d/tu.ctags o en la línea de comandos. Aquí hay un ejemplo de cómo admitir "# CTAGS: ...":

"input.py"

x=1
# CTAGS: DEFINE F
def F():
        # CTAGS: NO HACER NADA
        pass

"output.tags" con "--options=NONE --sort=no --extras=+{subparser} --regex-IPythonCell=/[ t]*# CTAGS:[ ]?(.*)$/1/c/ -o - input.py"

x    input.py        /^x=1$/;"       v
DEFINE F     input.py        /^# CTAGS: DEFINE F$/;" c
F    input.py        /^def F():$/;"  f
NO HACER NADA    input.py        /^      # CTAGS: DO NOTING$/;"  c

Puede colocar "--regex-IPythonCell=/[ \t]*# CTAGS:[ ]?(.*)$/\1/c/" en tu.ctags para evitar especificar el patrón repetidamente.
