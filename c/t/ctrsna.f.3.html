Documentación de función/subrutina

subrutina ctrsna (character job, character howmny, logical, dimension( * ) select, integer n, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) s, real, dimension( * ) sep, integer mm, integer m, complex, dimension( ldwork, * ) work, integer ldwork, real, dimension( * ) rwork, integer info)

CTRSNA

Propósito:

!>
!> CTRSNA estima los números recíprocos de condición para valores propios
!> y/o vectores propios derechos especificados de una matriz triangular superior
!> compleja T (o de cualquier matriz Q*T*Q**H con Q unitaria).
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (SEP):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (SEP);
!>          = 'B': para ambos, valores propios y vectores propios (S y SEP).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcula los números de condición para todos los pares de valores
!>                 propios;
!>          = 'S': calcula los números de condición para pares de valores propios
!>                 seleccionados especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares de valores propios para los
!>          cuales se requieren los números de condición. Para seleccionar los números
!>          de condición para el j-ésimo par de valores propios, SELECT(j) debe ser
!>          establecido a .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX, de dimensión (LDT,N)
!>          La matriz triangular superior T.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array COMPLEX, de dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios izquierdos de T
!>          (o de cualquier Q*T*Q**H con Q unitaria), correspondientes a los
!>          pares de valores propios especificados por HOWMNY y SELECT. Los vectores
!>          propios deben almacenarse en columnas consecutivas de VL, como los
!>          devuelve CHSEIN o CTREVC.
!>          Si JOB = 'V', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1; y si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX, de dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios derechos de T
!>          (o de cualquier Q*T*Q**H con Q unitaria), correspondientes a los
!>          pares de valores propios especificados por HOWMNY y SELECT. Los vectores
!>          propios deben almacenarse en columnas consecutivas de VR, como los
!>          devuelve CHSEIN o CTREVC.
!>          Si JOB = 'V', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1; y si JOB = 'E' o 'B', LDVR >= N.
!>

S

!>          S es un array REAL, de dimensión (MM)
!>          Si JOB = 'E' o 'B', los números recíprocos de condición de los
!>          valores propios seleccionados, almacenados en elementos
!>          consecutivos del array. Por lo tanto S(j), SEP(j), y las columnas j de VL
!>          y VR corresponden todos al mismo par de valores propios (pero no en
!>          general al j-ésimo par de valores propios, a menos que todos los pares
!>          de valores propios sean seleccionados).
!>          Si JOB = 'V', S no se referencia.
!>

SEP

!>          SEP es un array REAL, de dimensión (MM)
!>          Si JOB = 'V' o 'B', los números recíprocos de condición estimados de los
!>          vectores propios seleccionados, almacenados en elementos
!>          consecutivos del array.
!>          Si JOB = 'E', SEP no se referencia.
!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S (si JOB = 'E' o 'B')
!!>          y/o SEP (si JOB = 'V' o 'B'). MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y/o SEP realmente
!>          utilizados para almacenar los números de condición estimados.
!>          Si HOWMNY = 'A', M se establece en N.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (LDWORK,N+6)
!>          Si JOB = 'E', WORK no se referencia.
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          LDWORK >= 1; y si JOB = 'V' o 'B', LDWORK >= N.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N)
!>          Si JOB = 'E', RWORK no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!>  El recíproco del número de condición de un valor propio lambda se define como
!>
!>          S(lambda) = |v**H*u| / (norm(u)*norm(v))
!>
!>  donde u y v son los vectores propios derechos e izquierdos de T correspondientes
!>  a lambda; v**H denota la transpuesta conjugada de v, y norm(u)
!>  denota la norma euclidiana. Estos números recíprocos de condición siempre
!>  se encuentran entre cero (muy mal condicionado) y uno (muy bien
!>  condicionado). Si n = 1, S(lambda) se define como 1.
!>
!>  Una cota de error aproximada para un valor propio calculado W(i) viene dada por
!>
!>                      EPS * norm(T) / S(i)
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El recíproco del número de condición del vector propio derecho u
!>  correspondiente a lambda se define como sigue. Supongamos
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!>  Entonces el número recíproco de condición es
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!>  donde sigma-min denota el valor singular más pequeño. Aproximamos
!>  el valor singular más pequeño por el recíproco de una estimación de
!>  la norma uno de la inversa de T22 - lambda*I. Si n = 1, SEP(1) es
!>  definido como abs(T(1,1)).
!>
!>  Una cota de error aproximada para un vector propio derecho calculado VR(i)
!>  viene dada por
!>
!>                      EPS * norm(T) / SEP(i)
!>
