NOMBRE

ctwill, ctwill-refsort, ctwill-twinx - traducir CWEB a TeX con mini-índices

SINOPSIS

ctwill [opciones] webfile[.w] [{changefile[.ch]|-} [outfile[.tex]]]

ctwill-refsort < indexfile.ref > indexfile.sref

ctwill-twinx outfile.tex [outfile.tex ...] > index.tex

DESCRIPCIÓN

El ctwill programa convierte un documento fuente CWEB en un archivo TeX que puede ser formateado e impreso de la manera habitual. Se ocupa adecuadamente de los detalles tipográficos como la disposición de la página y el uso de la sangría, cursiva, negrita, etc., y proporciona información extensa de índice cruzado que recopila automáticamente.

CWEB le permite preparar un solo documento que contenga toda la información necesaria tanto para producir un programa C/C++ compilable como para producir un documento bien formateado que describa el programa con tanto detalle como el escritor desee. El usuario de CWEB debería estar familiarizado tanto con TeX como con C/C++.

USO

La línea de comandos debe tener uno, dos o tres nombres. El primero se toma como el archivo de entrada CWEB (y se añade .w si no hay extensión). Si hay un segundo nombre, es un archivo de cambios (y se añade .ch si no hay extensión). El archivo de cambios anula partes del archivo CWEB, como se describe en la documentación. Si hay un tercer nombre, anula el nombre por defecto del archivo de salida, que ordinariamente es el mismo que el nombre del archivo de entrada (pero en el directorio actual) con la extensión .tex. Si solo desea cambiar el nombre del archivo de salida, pero no tiene un archivo de cambios para aplicar, puede usar `-' como el segundo argumento.

ctwill es exactamente igual que cweave excepto que produce mucha mejor documentación, para lo cual debe trabajar mucho más duro. Debería ejecutar ctwill dos veces, una para arrancar y otra para obtener respuestas decentes. Además, debe ejecutar la salida dos veces a través de TeX.

Después de tex foo tendrá una salida que parece páginas finales excepto que las entradas de los mini-índices no estarán ordenadas alfabéticamente. La primera ejecución produce un archivo extraño llamado foo.ref. Ejecute ctwill-refsort < foo.ref > foo.sref y luego otra vez tex foo producirá una salida ordenada alfabéticamente.

El ctwill-twinx programa compila un índice maestro para un conjunto de programas relacionados que han sido procesados por ctwill (no por cweave, ¡tenga cuidado!). Los programas individuales deben definir sus nombres con una línea de la forma \def\title{NAME}. Para su conveniencia, ctwill-twinx toma la primera "palabra" en \title y la convierte en forma de mayúsculas. Debería adaptar el archivo twinx-startup.tex para la primera página del índice maestro.

Los mini-índices listan los identificadores que se usan pero no se definen en cada doble página. Al final de cada sección, ctwill le da a TeX una lista de los identificadores usados en esa sección e información sobre dónde se definen.

El significado actual de cada identificador es inicialmente \uninitialized. Luego ctwill lee el .aux archivo para su trabajo, si existe.

Antes de leer el .aux archivo, ctwill realmente busca un archivo llamado system.bux, que se leerá si está presente. Y después de foo.aux, una tercera posibilidad es foo.bux. La convención general es poner las definiciones de procedimientos del sistema como printf en system.bux, y poner las definiciones encontradas en archivos de cabecera específicamente foo-ish en foo.bux. Al igual que los .aux archivos, .bux archivos deben contener solo @$ especificaciones.

El significado especificado por @$...@> generalmente tiene cuatro componentes: un identificador (seguido de espacio), un nombre de programa (entre llaves), un número de sección (seguido de espacio), y una parte TeX.

Se proporciona un modo especial proofmode para que pueda verificar ctwill's conclusiones sobre referencias cruzadas. Ejecute ctwill con el indicador +P, y TeX producirá un documento especialmente formateado (sin mini-índices) en el que puede verificar que sus especificaciones son correctas.

Se pueden encontrar más detalles sobre cómo usar ctwill en las primeras secciones de su código fuente, respectivamente el archivo de cambios cweav-twill.ch aplicable al cweave.w fuente. Un ejemplo completo con todos los detalles se describe en Mini-Indexes for Literate Programs, páginas 225–245 de Knuth's Digital Typography.

DIFERENCIAS CON EL CTWILL ORIGINAL

La presente encarnación de ctwill y sus utilidades se esfuerzan por ser un reemplazo directo del paquete original. Sin embargo, hay algunas diferencias que vale la pena notar:

•
Esta versión está basada en la versión más reciente de CWEB (4.8).
•
En TeX Live los programas de utilidad tienen el prefijo ctwill- y los archivos de macro ct por razones técnicas.
•
Opciones --help, --quiet, --verbose, --version, e indicadores +c, -i, -o, y +lX son nuevos en CWEBbin y TeX Live.
•
Opción +lX está acompañada por archivos de envoltura de ejemplo para ctwimac.tex y ctproofmac.tex con títulos traducidos para alemán (+ld).
•
Opción +lX también está acompañada por un extendido pdfctwimac.tex para la producción de salida PDF con hipervínculos activos (+lpdf).
•
ctwill en TeX Live opera silenciosamente por defecto; use la --verbose opción para obtener el comportamiento original.
•
La búsqueda de archivos con la variable de entorno CWEBINPUTS está extendida para permitir varios, separados por dos puntos, rutas; ver ENTORNO más abajo.
•
Si está correctamente configurado, el programa principal ctwill está localizado con las "utilidades GNU gettext".

OPCIONES

Las opciones en la línea de comandos pueden ser apagadas con `-' (si están activadas por defecto) o activadas con `+' (si están desactivadas por defecto). De hecho, las opciones se procesan de izquierda a derecha, así que una secuencia como --verbose -h solo mostrará la línea de banner (+b) y el informe de progreso (+p), pero omitirá el mensaje de éxito (-h).

•
+b: imprimir línea de banner en la terminal
•
+h: imprimir mensaje de éxito al completar
•
+p: imprimir mensajes de informe de progreso
•
+q/-q: atajo para -bhp; también --quiet (por defecto)
•
+v/-v: atajo para +bhp; también --verbose
•
+c: verificar la salida temporal para cambios
•
-e: no encerrar el material C/C++ en \PB{...}
•
-f: no forzar un salto de línea después de cada declaración C/C++ en la salida
•
-i: suprimir la sangría de las declaraciones de parámetros
•
-o: suprimir la separación de declaraciones y sentencias
•
-x: omitir índices, nombres de sección, tabla de contenidos
•
+P: \input ctproofmac.tex en lugar de ctwimac.tex
•
+lX/-lX: usar macros para el lenguaje X como en X{ctwimac|ctproofmac}.tex
•
+s: imprimir estadísticas de uso
•
+t: tratar typename en una plantilla como typedef
•
--help: mostrar mensaje de ayuda y salir
•
--version: mostrar información de versión y salir

ENTORNO

La variable de entorno CWEBINPUTS se usa para buscar los archivos de entrada, o el valor predeterminado del sistema si CWEBINPUTS no está definido. Vea tex(1) para los detalles de la búsqueda. Para evitar conflictos con otros programas que también usan el entorno CWEBINPUTS, puede ser más específico y usar CWEBINPUTS_cweb para requisitos especiales en CWEB.

DESCRIPCIÓN

La utilidad ctwill es una versión de cweave que genera un archivo .tex que, al ser procesado por tex, producirá la documentación del programa fuente escrito en WEB.

Los archivos fuente originales escritos en WEB (un dialecto de C extendido para la programación literaria) no son directamente procesables por los compiladores de C. Requieren ser procesados primero por ctangle para extraer el código C y por cweave para producir el archivo de documentación.

Esta implementación de ctwill genera archivos que contienen una combinación de código C y documentación escrita en TeX.

USO

El uso típico de ctwill es el siguiente:

ctwill archivo_fuente.w

Esto generará dos archivos: archivo_fuente.tex (para documentación) y archivo_fuente.c (para el compilador).

Los archivos de salida pueden ser renombrados usando el segundo argumento:

ctwill archivo_fuente.w archivo_salida

En este caso, se generarán archivo_salida.tex y archivo_salida.c.

DIFERENCIAS CON CTWILL ORIGINAL

Esta versión, basada en la implementación de TeX Live, puede tener algunas diferencias sutiles en el comportamiento o en las opciones disponibles en comparación con la versión original de Don Knuth.

OPCIONES

Las opciones disponibles en ctwill son similares a las de cweave, permitiendo controlar la generación del archivo TeX y la extracción del código C.

Algunas opciones comunes incluyen:

-c
Genera un archivo de salida solo con el código C.
-d
Genera un archivo de salida solo con la documentación TeX.
-P
Genera un archivo de salida con código de depuración.
+lPREFIJO
Especifica un prefijo para los archivos de macros de TeX (ej. +lpdf para usar pdfctwimac.tex).

Consulte la documentación completa para obtener una lista exhaustiva de las opciones.

AMBIENTE

ctwill, al igual que ctangle y cweave, utiliza la variable de entorno TEXMFLOCALEDIR para configurar el directorio padre donde las "utilidades GNU gettext" buscan los catálogos de traducción.

Estas variables están preconfiguradas en el archivo texmf.cnf de TeX Live.

ARCHIVOS

La ubicación de los archivos mencionados a continuación varía de un sistema a otro. Utilice la utilidad kpsewhich para encontrar sus ubicaciones.

•
ctwimac.tex: Las macros de TeX por defecto \input en la primera línea del archivo de salida.
•
ctproofmac.tex: Si ctwill se invoca con la opción +P, cambiará la primera línea del archivo de salida a \input ctproofmac.tex.

En ambos casos, puede solicitar un prefijo X con la opción +lX, por ejemplo, +ld hará \input dctwimac.tex y +Pld hará \input dctproofmac.tex. Una aplicación especial es el uso de la opción +lpdf que hará \input pdfctwimac.tex para la producción de salida PDF con hipervínculos activos.

•
archivo_web.bux: Definiciones de referencia a resolver desde otros módulos.
•
system.bux: Definiciones de referencia a resolver desde archivos de cabecera de la biblioteca estándar de C/C++ como <stdio.h>.

Otros archivos auxiliares aux con referencias son creados automáticamente por ctwill y los archivos de índice reales son creados por TeX.

•
cwebman.tex: El manual de usuario de CWEB, disponible en PDF desde CTAN (https://ctan.org/pkg/cweb).
