CTLOG_STORE_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CTLOG_STORE_NEW(3ssl) OpenSSL CTLOG_STORE_NEW(3ssl)

NOMBRE

CTLOG_STORE_new_ex, CTLOG_STORE_new, CTLOG_STORE_free, CTLOG_STORE_load_default_file, CTLOG_STORE_load_file - Crear y poblar una lista de registros de Transparencia de Certificados

SINOPSIS

#include <openssl/ct.h>
CTLOG_STORE *CTLOG_STORE_new_ex(OSSL_LIB_CTX *libctx, const char *propq);
CTLOG_STORE *CTLOG_STORE_new(void);
void CTLOG_STORE_free(CTLOG_STORE *store);
int CTLOG_STORE_load_default_file(CTLOG_STORE *store);
int CTLOG_STORE_load_file(CTLOG_STORE *store, const char *file);

DESCRIPCIÓN

Un CTLOG_STORE es un contenedor para una lista de CTLOGs (registros de Transparencia de Certificados). La lista se puede cargar desde uno o varios archivos y luego buscarse por LogID (ver RFC 6962, Sección 3.2, para la definición de un LogID).

CTLOG_STORE_new_ex() crea una lista vacía de registros CT asociada con el contexto de la biblioteca libctx y la cadena de consulta de propiedades propq.

CTLOG_STORE_new() hace lo mismo que CTLOG_STORE_new_ex() pero con el contexto de la biblioteca predeterminado y la cadena de consulta de propiedades.

El CTLOG_STORE se puebla luego con CTLOG_STORE_load_default_file() o CTLOG_STORE_load_file(). CTLOG_STORE_load_default_file() carga desde el archivo predeterminado, que se llama ct_log_list.cnf en OPENSSLDIR (ver la salida de openssl-version(1)). Esto se puede anular usando una variable de entorno llamada CTLOG_FILE. CTLOG_STORE_load_file() carga desde una ruta de archivo especificada por el llamador. Ambas funciones añaden cualquier registro CT cargado al CTLOG_STORE.

El formato esperado del archivo es:

enabled_logs=foo,bar
[foo]
description = Registro 1
key = <SubjectPublicKeyInfo DER codificada en base64 aquí>
[bar]
description = Registro 2
key = <SubjectPublicKeyInfo DER codificada en base64 aquí>

Una vez que un CTLOG_STORE ya no sea necesario, se debe pasar a CTLOG_STORE_free(). Esto eliminará todos los CTLOGs almacenados dentro, junto con el propio CTLOG_STORE. Si el argumento es NULL, no se hace nada.

NOTAS

Si hay registros CT inválidos en un archivo, se omiten y los registros válidos restantes se añadirán al CTLOG_STORE. Un registro CT se considerará inválido si le falta un campo "key" o "description".

VALORES DE RETORNO

Tanto CTLOG_STORE_load_default_file como CTLOG_STORE_load_file devuelven 1 si todos los registros CT del archivo se analizan y cargan correctamente, 0 en caso contrario.

VER TAMBIÉN

ct(7), CTLOG_STORE_get0_log_by_id(3), SSL_CTX_set_ctlog_list_file(3)

HISTORIA

CTLOG_STORE_new_ex se añadió en OpenSSL 3.0. Todas las demás funciones se añadieron en OpenSSL 1.1.0.
