Documentación de Función/Subrutin

a

subrutina ctgsyl (character trans, integer ijob, integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( ldd, * ) d, integer ldd, complex, dimension( lde, * ) e, integer lde, complex, dimension( ldf, * ) f, integer ldf, real scale, real dif, complex, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer

info)

CTGSY

L

Propósito

: 
!>
!> CTGSYL resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = scale * C            (1)
!>             D * R - L * E = scale * F
!>
!> donde R y L son matrices desconocidas de tamaño m-por-n, (A, D), (B, E) y
!> (C, F) son pares de matrices dados de tamaño m-por-m, n-por-n y m-por-n,
!> respectivamente, con entradas complejas. A, B, D y E son
!> triangulares superiores (es decir, (A,D) y (B,E) en forma
!> de Schur generalizada).
!>
!> La solución (R, L) sobrescribe (C, F). 0 <= SCALE <= 1
!> es un factor de escala de salida elegido para evitar el desbordamiento.
!>
!> En notación matricial (1) es equivalente a resolver Zx = scale*b, donde Z
!> está definida como
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]        (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Aquí Ix es la matriz identidad de tamaño x y X**H es la transpuesta
!> conjugada de X. Kron(X, Y) es el producto de Kronecker entre las
!> matrices X y Y.
!>
!> Si TRANS = 'C', se resuelve y en el sistema conjugado transpuesto Z**H *y = scale*b,
!> lo que es equivalente a resolver para R y L en
!>
!>             A**H * R + D**H * L = scale * C           (3)
!>             R * B**H + L * E**H = scale * -F
!>
!> Este caso (TRANS = 'C') se usa para calcular una estimación basada en la norma
!> uno de Dif[(A,D), (B,E)], la separación entre los pares de matrices (A,D)
!> y (B,E), usando CLACON.
!>
!> Si IJOB >= 1, CTGSYL calcula una estimación basada en la norma de Frobenius de
!> Dif[(A,D),(B,E)]. Es decir, el recíproco de una cota inferior sobre el
!> recíproco del valor singular más pequeño de Z.
!>
!> Este es un algoritmo BLAS de nivel 3.
!
>

Parámetro

s
TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resolver la ecuación de Sylvester generalizada (1).
!>          = 'C': resolver el sistema (3).
!
>

IJO

B 
!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad debe realizarse.
!>          =0: resolver (1) solamente.
!>          =1: La funcionalidad de 0 y 3.
!>          =2: La funcionalidad de 0 y 4.
!>          =3: Solo se calcula una estimación de Dif[(A,D), (B,E)].
!>              (se usa una estrategia de anticipación).
!>          =4: Solo se calcula una estimación de Dif[(A,D), (B,E)].
!>              (se usa CGECON en subsistemas).
!>          No se referencia si TRANS = 'C'.
!
>

M 
!>          M es INTEGER
!>          El orden de las matrices A y D, y la dimensión de filas de
!>          las matrices C, F, R y L.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices B y E, y la dimensión de columnas
!>          de las matrices C, F, R y L.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA, M)
!>          La matriz triangular superior A.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1, M).
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB, N)
!>          La matriz triangular superior B.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1, N).
!
>

C 
!>          C es un arreglo COMPLEX, dimensión (LDC, N)
!>          A la entrada, C contiene el segundo miembro de la primera
!>          ecuación matricial en (1) o (3).
!>          A la salida, si IJOB = 0, 1 o 2, C ha sido sobrescrita por
!>          la solución R. Si IJOB = 3 o 4 y TRANS = 'N', C contiene R,
!>          la solución obtenida durante el cálculo de la
!>          estimación de Dif.
!
>

LD

C 
!>          LDC es INTEGER
!>          La dimensión principal del arreglo C. LDC >= max(1, M).
!
>

D 
!>          D es un arreglo COMPLEX, dimensión (LDD, M)
!>          La matriz triangular superior D.
!
>

LD

D 
!>          LDD es INTEGER
!>          La dimensión principal del arreglo D. LDD >= max(1, M).
!
>

E 
!>          E es un arreglo COMPLEX, dimensión (LDE, N)
!>          La matriz triangular superior E.
!
>

LD

E 
!>          LDE es INTEGER
!>          La dimensión principal del arreglo E. LDE >= max(1, N).
!
>

F 
!>          F es un arreglo COMPLEX, dimensión (LDF, N)
!>          A la entrada, F contiene el segundo miembro de la segunda
!>          ecuación matricial en (1) o (3).
!>          A la salida, si IJOB = 0, 1 o 2, F ha sido sobrescrita por
!>          la solución L. Si IJOB = 3 o 4 y TRANS = 'N', F contiene L,
!>          la solución obtenida durante el cálculo de la
!>          estimación de Dif.
!
>

LD

F 
!>          LDF es INTEGER
!>          La dimensión principal del arreglo F. LDF >= max(1, M).
!
>

DI

F 
!>          DIF es REAL
!>          A la salida DIF es el recíproco de una cota inferior del
!>          recíproco de la función Dif, es decir, DIF es una cota superior de
!>          Dif[(A,D), (B,E)] = sigma-min(Z), donde Z es como en (2).
!>          SI IJOB = 0 o TRANS = 'C', DIF no se referencia.
!
>

SCAL

E 
!>          SCALE es REAL
!>          A la salida SCALE es el factor de escala en (1) o (3).
!>          Si 0 < SCALE < 1, C y F contienen las soluciones R y L, respectivamente,
!>          para un sistema ligeramente perturbado pero las matrices de
!>          entrada A, B, D y E no han sido cambiadas. Si SCALE = 0, R y L
!>          contendrán las soluciones al sistema homogéneo con C = F = 0.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= 1.
!>          Si IJOB = 1 o 2 y TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (M+N+2)
!
>

INF

O 
!>          INFO es INTEGER
!>            =0: salida exitosa
!>            <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>            >0: (A, D) y (B, E) tienen eigenvalores comunes o muy cercanos.
!
>
