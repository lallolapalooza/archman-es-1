ctags-lang-r(7) Universal Ctags ctags-lang-r(7)

Nombre

ctags-lang-r - Notas aleatorias sobre el etiquetado de código fuente de R con Universal Ctags

SINOPIS

ctags ... --languages=+R ...
ctags ... --language-force=R ...
ctags ... --map-R=+.r ...

DESCRIPCIÓN

Esta página del manual reúne notas aleatorias sobre el etiquetado de código fuente de R con Universal Ctags.

Tipos

Si una variable recibe un valor devuelto por un constructor conocido y la variable aparece por primera vez en el archivo de entrada actual, el analizador de R crea una etiqueta para la variable y le adjunta un tipo asociado con el constructor, independientemente de si la variable aparece en el contexto de nivel superior o en una función.

Mapeo de constructores conocidos y tipos

Constructor tipo
function() function
c() vector
list() list
data.frame() dataframe

Si una variable no recibe un valor devuelto por uno de los constructores conocidos, el analizador de R adjunta el tipo globalVar o functionVar a la etiqueta de la variable según el contexto.

Aquí hay un ejemplo que demuestra el uso de los tipos:

"input.r"

G <- 1
v <- c(1, 2)
l <- list(3, 4)
d <- data.frame(n = v)
f <- function(a) {
        g <- function (b) a + b
        w <- c(1, 2)
        m <- list (3, 4)
        e <- data.frame(n = w)
        L <- 2}

"output.tags" con "--options=NONE --sort=no --fields=+KZ -o - input.r"

G       input.r /^G <- 1$/;"    globalVar
v       input.r /^v <- c(1, 2)$/;"      vector
l       input.r /^l <- list(3, 4)$/;"   list
d       input.r /^d <- data.frame(n = v)$/;"    dataframe
n       input.r /^d <- data.frame(n = v)$/;"    nameattr        scope:dataframe:d
f       input.r /^f <- function(a) {$/;"        function
g       input.r /^      g <- function (b) a + b$/;"     function        scope:function:f
w       input.r /^      w <- c(1, 2)$/;"        vector  scope:function:f
m       input.r /^      m <- list (3, 4)$/;"    list    scope:function:f
e       input.r /^      e <- data.frame(n = w)$/;"      dataframe       scope:function:f
n       input.r /^      e <- data.frame(n = w)$/;"      nameattr        scope:dataframe:f.e
L       input.r /^      L <- 2$/;"      functionVar     scope:function:f
