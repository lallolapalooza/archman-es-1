Nombre

ctags-lang-lisp - Notas varias sobre la indexación de código fuente Lisp con Ctags Universal

SINOPSIS

ctags ... --languages=+Lisp ...
ctags ... --language-force=Lisp ...
ctags ... --map-Lisp=+.cl ...
ctags ... --map-Lisp=+.clisp ...
ctags ... --map-Lisp=+.l ...
ctags ... --map-Lisp=+.lisp ...
ctags ... --map-Lisp=+.lsp ...

DESCRIPCIÓN

Esta página del manual recopila notas varias sobre la indexación de código fuente Lisp.
