CTGSJA

Propósito:

!>
!> CTGSJA calcula la descomposición de valores singulares generalizada (GSVD)
!> de dos matrices complejas triangulares superiores (o trapezoidales) A y B.
!>
!> Al entrar, se asume que las matrices A y B tienen las siguientes
!> formas, que pueden ser obtenidas por la subrutina de preprocesamiento CGGSVP
!> a partir de una matriz A general de M por N y una matriz B de P por N:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> donde la matriz A12 de K por K y la matriz B13 de L por L son no singulares
!> triangulares superiores; A23 es triangular superior de L por L si M-K-L >= 0,
!> de lo contrario A23 es trapezoidal superior de (M-K) por L.
!>
!> Al salir,
!>
!>        U**H *A*Q = D1*( 0 R ),    V**H *B*Q = D2*( 0 R ),
!>
!> donde U, V y Q son matrices unitarias.
!> R es una matriz triangular superior no singular, y D1
!> y D2 son matrices ``diagonales'', que tienen las siguientes
!> estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) al salir.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> donde
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N) y R33 se almacena
!>     (  0  R22 R23 )
!> en B(M-K+1:L,N+M-K-L+1:N) al salir.
!>
!> El cálculo de las matrices de transformación unitarias U, V o Q
!> es opcional. Estas matrices pueden formarse explícitamente, o pueden
!> ser post-multiplicadas en las matrices de entrada U1, V1 o Q1.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  U debe contener una matriz unitaria U1 al entrar, y
!>                  se devuelve el producto U1*U;
!>          = 'I':  U se inicializa con la matriz unidad, y se devuelve
!>                  la matriz unitaria U;
!>          = 'N':  U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  V debe contener una matriz unitaria V1 al entrar, y
!>                  se devuelve el producto V1*V;
!>          = 'I':  V se inicializa con la matriz unidad, y se devuelve
!>                  la matriz unitaria V;
!>          = 'N':  V no se calcula.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  Q debe contener una matriz unitaria Q1 al entrar, y
!>                  se devuelve el producto Q1*Q;
!>          = 'I':  Q se inicializa con la matriz unidad, y se devuelve
!>                  la matriz unitaria Q;
!>          = 'N':  Q no se calcula.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          K y L especifican los subbloques en las matrices de entrada A y B:
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) y B13 = B(1:L,,N-L+1:N)
!>          de A y B, cuya GSVD va a ser calculada por CTGSJA.
!>          Vea Detalles Adicionales.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          Al entrar, la matriz A de M por N.
!>          Al salir, A(N-K+1:N,1:MIN(K+L,M) ) contiene la matriz
!>          triangular R o parte de R.  Vea Propósito para más detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,N)
!>          Al entrar, la matriz B de P por N.
!>          Al salir, si es necesario, B(M-K+1:L,N+M-K-L+1:N) contiene
!>          una parte de R.  Vea Propósito para más detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es REAL
!>

TOLB

!>          TOLB es REAL
!>
!>          TOLA y TOLB son los criterios de convergencia para el procedimiento
!>          de iteración Jacobi-Kogbetliantz. Generalmente, son los
!>          mismos que se usan en el paso de preprocesamiento, digamos
!>              TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>              TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>

ALPHA

!>          ALPHA es un arreglo REAL, dimensión (N)
!>

BETA

!>          BETA es un arreglo REAL, dimensión (N)
!>
!>          Al salir, ALPHA y BETA contienen los pares de valores singulares
!>          generalizados de A y B;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          y si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          o si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          Además, si K+L < N,
!>            ALPHA(K+L+1:N) = 0
!>            BETA(K+L+1:N)  = 0.
!>

U

!>          U es un arreglo COMPLEX, dimensión (LDU,M)
!>          Al entrar, si JOBU = 'U', U debe contener una matriz U1 (usualmente
!>          la matriz unitaria devuelta por CGGSVP).
!>          Al salir,
!>          si JOBU = 'I', U contiene la matriz unitaria U;
!>          si JOBU = 'U', U contiene el producto U1*U.
!>          Si JOBU = 'N', U no es referenciado.
!>

LDU

!>          LDU es INTEGER

Function/Subroutine Documentation

                        
This routine is part of the LAPACK routines for computing the generalized singular value decomposition (GSVD) of a matrix pair (A, B).

                        
The GSVD of A and B is defined by the orthogonal transformations:

                        
      A = U * diag(alpha) * Q**H
      B = V * diag(beta) * Q**H


                        
where U, V, and Q are orthogonal matrices, and alpha and beta are diagonal matrices.

                        
CTGSJA essentially uses a variant of the Kogbetliantz algorithm to compute the GSVD.

Further Details:

                        

                            
CTGSJA essentially uses a variant of Kogbetliantz algorithm to reduce
min(L,M-K)-by-L triangular (or trapezoidal) matrix A23 and L-by-L
matrix B13 to the form:

         U1**H *A13*Q1 = C1*R1; V1**H *B13*Q1 = S1*R1,

where U1, V1 and Q1 are unitary matrix.
C1 and S1 are diagonal matrices satisfying

                 C1**2 + S1**2 = I,

and R1 is an L-by-L nonsingular upper triangular matrix.
