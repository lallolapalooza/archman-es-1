CWEB(1) Manual de comandos generales CWEB(1)

NOMBRE

ctangle, cweave - traduce CWEB a C/C++ y/o TeX

SINOPSIS

ctangle [opciones] archivo_web[.w] [{archivo_cambios[.ch]|-} [archivo_salida[.c]]]

cweave [opciones] archivo_web[.w] [{archivo_cambios[.ch]|-} [archivo_salida[.tex]]]

DESCRIPCIÓN

El programa ctangle convierte un documento fuente de CWEB en un programa C/C++ que puede ser compilado de la manera habitual. El archivo de salida incluye especificaciones #line para que la depuración se pueda hacer en términos del archivo fuente de CWEB.

El programa cweave convierte el mismo archivo CWEB en un archivo TeX que puede ser formateado e impreso de la manera habitual. Se encarga apropiadamente de detalles tipográficos como el diseño de la página y el uso de sangría, cursiva, negrita, etc., y proporciona información exhaustiva de índices cruzados que recopila automáticamente.

CWEB te permite preparar un solo documento que contiene toda la información necesaria tanto para producir un programa C/C++ compilable como para producir un documento bien formateado que describe el programa con tanto detalle como el escritor desee. El usuario de CWEB debe estar familiarizado con TeX así como con C/C++.

USO

La línea de comandos debe tener uno, dos o tres nombres. El primero se toma como el archivo de entrada CWEB (y se añade .w si no hay extensión). Si hay un segundo nombre, es un archivo de cambios (y se añade .ch si no hay extensión). El archivo de cambios anula partes del archivo CWEB, como se describe en la documentación. Si hay un tercer nombre, anula el nombre por defecto del archivo de salida, que normalmente es el mismo que el nombre del archivo de entrada (pero en el directorio actual) con la extensión .tex. Si solo quieres cambiar el nombre del archivo de salida, pero no tienes un archivo de cambios para aplicar, puedes usar `-' como segundo argumento.

DIFERENCIAS CON EL CWEB ORIGINAL

CWEBbin intenta ser un reemplazo directo para CWEB, por lo que en general no deberías notar ninguna diferencia al invocar los programas ni en la salida resultante. Sin embargo, hay algunas diferencias que vale la pena notar:

•
Las opciones --help, --quiet, --verbose, --version, y las banderas +c, -i, -o, +u, y +lX son nuevas en CWEBbin y TeX Live.
•
La opción +lX va acompañada de varios archivos envoltorio para cwebmac.tex con subtítulos traducidos para alemán (+ld), francés (+lf) e italiano (+li).
•
CWEB en TeX Live opera silenciosamente por defecto (a partir de 2019); usa la opción --verbose para obtener el comportamiento original.
•
La búsqueda de archivos con la variable de entorno CWEBINPUTS se extiende para permitir varios caminos separados por dos puntos; ver ENTORNO a continuación.
•
Si está configurado correctamente, los programas principales ctangle y cweave están localizados con las utilidades de GNU gettext.

OPCIONES

Las opciones en la línea de comandos pueden ser desactivadas con `-' (si están activadas por defecto) o activadas con `+' (si están desactivadas por defecto). De hecho, las opciones se procesan de izquierda a derecha, por lo que una secuencia como --verbose -h solo mostrará la línea de banner (+b) y el informe de progreso (+p), pero omitirá el mensaje de éxito (-h).

El primer lote de opciones es común tanto para ctangle como para cweave:

•
+b: imprime la línea de banner en la terminal
•
+h: imprime el mensaje de éxito al completar
•
+p: imprime mensajes de informe de progreso
•
+q/-q: atajo para -bhp; también --quiet (por defecto)
•
+v/-v: atajo para +bhp; también --verbose
•
+c: comprueba la salida temporal en busca de cambios
•
+s: imprime estadísticas de uso
•
--help: muestra el mensaje de ayuda y sale
•
--version: muestra la información de la versión y sale

Hay otra opción aplicable solo a ctangle:

•
+k: mantiene los separadores en los literales numéricos en la salida
•
+u: translitera caracteres UTF-8 en código C

Hay otras siete opciones aplicables solo a cweave:

•
-e: no encierra el material C/C++ en \PB{...}
•
-f: no fuerza un salto de línea después de cada sentencia C/C++ en la salida
•
-i: suprime la sangría de las declaraciones de parámetros
•
-o: suprime la separación de declaraciones y sentencias
•
-x: omite índices, nombres de sección, tabla de contenidos
•
+lX/-lX: usa macros para el idioma X según Xcwebmac.tex
•
+t: trata typename en una plantilla como typedef

ENTORNO

La variable de entorno CWEBINPUTS se usa para buscar los archivos de entrada, o el valor predeterminado del sistema si CWEBINPUTS no está configurada. Ver tex(1) para los detalles de la búsqueda. Para evitar conflictos con otros programas que también usan el entorno CWEBINPUTS, puedes ser más específico y usar CWEBINPUTS_cweb para requisitos especiales en CWEB.

Si está preparada para soporte NLS, ctangle y cweave usan la variable de entorno TEXMFLOCALEDIR para configurar el directorio padre donde las utilidades de GNU gettext buscan los catálogos de traducción.

Estas variables están preconfiguradas en el texmf.cnf de TeX Live.

ARCHIVOS

La ubicación de los archivos mencionados a continuación varía de un sistema a otro. Usa la utilidad kpsewhich para encontrar sus ubicaciones.

•
cwebmac.tex: Las macros TeX por defecto \input en la primera línea del archivo de salida de cweave.
•
cwebman.tex: El manual de usuario de CWEB, disponible en PDF desde CTAN (https://ctan.org/pkg/cweb).
