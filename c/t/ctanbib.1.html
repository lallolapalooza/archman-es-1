NOMBRE

ctanbib - recuperar información bibliográfica de paquetes alojados en CTAN.

SINOPSIS

ctanbib <opciones> [nombre del paquete]

DESCRIPCIÓN

Este comando puede recuperar información bibliográfica para paquetes TeX alojados en CTAN en formato BibTeX.

Busca la entrada del Catálogo para cada NOMBREDEP en CTAN (en https://ctan.org/xml/2.0/pkg/NOMBREDEP), y convierte la información relevante a una entrada BibTeX.

Por defecto, el campo url en la entrada de salida es el valor del campo home del paquete si éste está especificado en la entrada del Catálogo; si no lo está, se usa https://ctan.org/pkg/NOMBREDEP.

OPCIONES

-c,--ctan
Usar siempre la URL /pkg/ de CTAN en lugar de la página de inicio del paquete
-C,--CTAN
Usar la ruta CTAN del paquete como url (ej: /support/ctanbib)
-e,--tipo-entrada
(manual por defecto) Cambiar el tipo de entrada
-h,--ayuda
imprimir el mensaje de ayuda.
-p,--nombre-paquete
Envolver el nombre del paquete en un comando tanbibpkgname. Este comando puede ser redefinido en el documento para el formato deseado.
-v,--version
imprimir la información de la versión.

EJEMPLOS

$ ctanbib latex

Esta invocación imprimirá datos en formato BibLaTeX a la salida estándar:

@manual{latex,
  title = {El paquete Latex},
  subtitle = {Un paquete de macros TeX que define LaTeX},
  author = {Lamport, Leslie y The LaTeX Team},
  url = {http://www.latex-project.org/},
  urldate = {2018-08-23}, 
  date = {2018-04-01},
  version = {PL 5}
}

La opción --ctan:

$ ctanbib -c hyperref

Esto produce un registro bib con el tipo @ctan:

@ctan{hyperref,
title = {El paquete Hyperref},
subtitle = {Soporte extenso para hipertexto en LaTeX},
author = {Rahtz, Sebastian y Oberdiek, Heiko},
url = {/macros/latex/contrib/hyperref},
urldate = {2018-08-27}, 
date = {},
version = {6.86b}
}
