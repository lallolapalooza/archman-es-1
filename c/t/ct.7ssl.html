NOMBRE

ct - Certificate Transparency

SINOPSIS

#include <openssl/ct.h>

DESCRIPCIÓN

Esta biblioteca implementa la verificación de Certificate Transparency (CT) para clientes TLS, según se define en RFC 6962. Esta verificación puede proporcionar cierta confianza en que un certificado ha sido registrado públicamente en un conjunto de registros de CT.

Por defecto, estas comprobaciones están deshabilitadas. Se pueden habilitar usando SSL_CTX_enable_ct(3) o SSL_enable_ct(3).

Esta biblioteca también se puede usar para analizar y examinar estructuras de datos de CT, como los Sellos de Tiempo de Certificado Firmado (SCTs), o para leer una lista de registros de CT. Hay funciones para: - decodificar y codificar SCTs en formato DER y formato de cable TLS. - imprimir SCTs. - verificar la autenticidad de los SCTs. - cargar una lista de registros de CT desde un archivo CONF.
