Documentación de Función/Subrutina

subrutina ctgsen (entero ijob, lógico wantq, lógico wantz, lógico, dimensión( * ) select, entero n, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldb, * ) b, entero ldb, complejo, dimensión( * ) alpha, complejo, dimensión( * ) beta, complejo, dimensión( ldq, * ) q, entero ldq, complejo, dimensión( ldz, * ) z, entero ldz, entero m, real pl, real pr, real, dimensión( * ) dif, complejo, dimensión( * ) work, entero lwork, entero, dimensión( * ) iwork, entero liwork, entero info)

CTGSEN

Propósito:

!>
!> CTGSEN reordena la descomposición de Schur generalizada de un par
!> de matrices complejas (A, B) (en términos de una transformación de
!> equivalencia unitaria Q**H * (A, B) * Z), de modo que un grupo
!> seleccionado de eigenvalores aparezca en los bloques diagonales
!> principales del par (A,B). Las columnas principales de Q y Z forman
!> bases unitarias de los autoespacios izquierdo y derecho
!> correspondientes (subespacios deflacionantes). (A, B) debe estar en
!> forma canónica de Schur generalizada, es decir, A y B son ambas
!> triangulares superiores.
!>
!> CTGSEN también calcula los eigenvalores generalizados
!>
!>          w(j)= ALPHA(j) / BETA(j)
!>
!> del par de matrices reordenado (A, B).
!>
!> Opcionalmente, la rutina calcula estimaciones de los números de
!> condición recíprocos para eigenvalores y autoespacios. Estos son
!> Difu[(A11,B11), (A22,B22)] y Difl[(A11,B11), (A22,B22)], es decir,
!> la(s) separación(es) entre los pares de matrices (A11, B11) y
!> (A22,B22) que corresponden al grupo seleccionado y a los
!> eigenvalores fuera del grupo, respectivamente, y las normas de
!>  sobre los autoespacios izquierdo y derecho con respecto al
!> grupo seleccionado en el bloque (1,1).
!>
!>

Parámetros

IJOB 
!>          IJOB es INTEGER
!>          Especifica si se requieren números de condición para el
!>          grupo de eigenvalores (PL y PR) o para los subespacios
!>          deflacionantes (Difu y Difl):
!>           =0: Solo reordenar con respecto a SELECT. Sin extras.
!>           =1: Recíproco de las normas de  sobre los autoespacios
!>               izquierdo y derecho con respecto al grupo seleccionado
!>               (PL y PR).
!>           =2: Cotas superiores de Difu y Difl. Estimación basada en
!>               la norma F (DIF(1:2)).
!>           =3: Estimación de Difu y Difl. Estimación basada en la
!>               norma 1 (DIF(1:2)).
!>               Aproximadamente 5 veces más costosa que IJOB = 2.
!>           =4: Calcular PL, PR y DIF (es decir, 0, 1 y 2 anteriores):
!>               Versión económica para obtener todo.
!>           =5: Calcular PL, PR y DIF (es decir, 0, 1 y 3 anteriores)
!>

WANTQ

!>          WANTQ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación izquierda Q;
!>          .FALSE.: no actualizar Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación derecha Z;
!>          .FALSE.: no actualizar Z.
!>

SELECT

!>          SELECT es un array LOGICAL, dimensión (N)
!>          SELECT especifica los eigenvalores en el grupo seleccionado.
!>          Para seleccionar un eigenvalor w(j), SELECT(j) debe
!>          establecerse a .TRUE..
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión(LDA,N)
!>          A la entrada, la matriz triangular superior A, en forma
!>          canónica de Schur generalizada.
!>          A la salida, A es sobrescrita por la matriz A reordenada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX, dimensión(LDB,N)
!>          A la entrada, la matriz triangular superior B, en forma
!>          canónica de Schur generalizada.
!>          A la salida, B es sobrescrita por la matriz B reordenada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX, dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX, dimensión (N)
!>
!>          Los elementos diagonales de A y B, respectivamente,
!>          cuando el par (A,B) ha sido reducido a la forma de Schur
!>          generalizada. ALPHA(i)/BETA(i) i=1,...,N son los
!>          eigenvalores generalizados.
!>

Q

!>          Q es un array COMPLEX, dimensión (LDQ,N)
!>          A la entrada, si WANTQ = .TRUE., Q es una matriz N-por-N.
!>          A la salida, Q ha sido post-multiplicada por la matriz de
!>          transformación unitaria izquierda que reordena (A, B); Las
!>          columnas principales de Q forman bases ortonormales para el
!>          par especificado de autoespacios izquierdos (subespacios
!>          deflacionantes).
!>          Si WANTQ = .FALSE., Q no es referenciada.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1.
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es un array COMPLEX, dimensión (LDZ,N)
!>          A la entrada, si WANTZ = .TRUE., Z es una matriz N-por-N.
!>          A la salida, Z ha sido post-multiplicada por la matriz de
!>          transformación unitaria izquierda que reordena (A, B); Las
!>          columnas principales de Z forman bases ortonormales para el
!>          par especificado de autoespacios izquierdos (subespacios
!>          deflacionantes).
!>          Si WANTZ = .FALSE., Z no es referenciada.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1.
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

M

!>          M es INTEGER
!>          La dimensión del par especificado de autoespacios izquierdo
!>          y derecho, (subespacios deflacionantes) 0 <= M <= N.
!>

PL

!>          PL es REAL
!>

PR

!>          PR es REAL
!>
!>          Si IJOB = 1, 4 o 5, PL, PR son cotas inferiores del
!>          recíproco de la norma de  sobre el autoespacio izquierdo
!>          y derecho con respecto al grupo seleccionado.
!>          0 < PL, PR <= 1.
!>          Si M = 0 o M = N, PL = PR  = 1.
!>          Si IJOB = 0, 2 o 3 PL, PR no son referenciados.
!>

DIF

!>          DIF es un array REAL, dimensión (2).
!>          Si IJOB >= 2, DIF(1:2) almacena las estimaciones de Difu y Difl.
!>          Si IJOB = 2 o 4, DIF(1:2) son cotas superiores basadas en la
!>          norma F sobre Difu y Difl. Si IJOB = 3 o 5, DIF(1:2) son
!>          estimaciones basadas en la norma 1 de Difu y Difl, calculadas
!>          usando comunicación invertida con CLACN2.
!>          Si M = 0 o N, DIF(1:2) = F-norm([A, B]).
!>          Si IJOB = 0 o 1, DIF no es referenciado.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >=  1
!>          Si IJOB = 1, 2 o 4, LWORK >=  2*M*(N-M)
!>          Si IJOB = 3 o 5, LWORK >=  4*M*(N-M)
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (MAX(1,LIWORK))
!>          Al salir, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del arreglo IWORK. LIWORK >= 1.
!>          Si IJOB = 1, 2 o 4, LIWORK >=  N+2;
!>          Si IJOB = 3 o 5, LIWORK >= MAX(N+2, 2*M*(N-M));
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo IWORK,
!>          devuelve este valor como la primera entrada del arreglo IWORK, y
!>          no se emite ningún mensaje de error relacionado con LIWORK por parte de XERBLA.
!>

INFO

!>          INFO es INTEGER
!>            =0: Salida exitosa.
!>            <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>            =1: El reordenamiento de (A, B) falló porque el par de
!>                matrices transformado (A, B) estaría demasiado lejos de la
!>                forma de Schur generalizada; el problema está muy mal
!>                condicionado. (A, B) puede haber sido parcialmente reordenado.
!>                Si se solicitó, se devuelve 0 en DIF(*), PL y PR.
!>

Detalles adicionales:

!>
!>  CTGSEN primero recopila los autovalores seleccionados calculando unitarias
!>  U y W que los mueven a la esquina superior izquierda de (A, B). En otras
!>  palabras, los autovalores seleccionados son los autovalores de (A11, B11) en
!>
!>              U**H*(A, B)*W = (A11 A12) (B11 B12) n1
!>                              ( 0  A22),( 0  B22) n2
!>                                n1  n2    n1  n2
!>
!>  donde N = n1+n2 y U**H significa la transpuesta conjugada de U. Las primeras
!>  n1 columnas de U y W abarcan el par especificado de autoespacios izquierdos y derechos
!>  (subespacios deflactantes) de (A, B).
!>
!>  Si (A, B) se ha obtenido de la descomposición de Schur real generalizada
!>  de un par de matrices (C, D) = Q*(A, B)*Z', entonces la
!>  forma de Schur generalizada reordenada de (C, D) viene dada por
!>
!>           (C, D) = (Q*U)*(U**H *(A, B)*W)*(Z*W)**H,
!>
!>  y las primeras n1 columnas de Q*U y Z*W abarcan los subespacios
!>  deflactantes correspondientes de (C, D) (Q y Z almacenan Q*U y Z*W, respectivamente).
!>
!>  Nótese que si el autovalor seleccionado está suficientemente mal condicionado,
!>  su valor puede diferir significativamente de su valor antes
!>  del reordenamiento.
!>
!>  Los números de condición recíprocos de los autoespacios izquierdos y derechos
!>  abarcados por las primeras n1 columnas de U y W (o Q*U y Z*W) pueden
!>  devolverse en DIF(1:2), correspondientes a Difu y Difl, respectivamente.
!>
!>  Difu y Difl se definen como:
!>
!>       Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
!>  y
!>       Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],
!>
!>  donde sigma-min(Zu) es el valor singular más pequeño de la
!>  matriz (2*n1*n2)-por-(2*n1*n2)
!>
!>       Zu = [ kron(In2, A11)  -kron(A22**H, In1) ]
!>            [ kron(In2, B11)  -kron(B22**H, In1) ].
!>
!>  Aquí, Inx es la matriz identidad de tamaño nx y A22**H es la
!>  transpuesta conjugada de A22. kron(X, Y) es el producto de Kronecker entre
!>  las matrices X y Y.
!>
!>  Cuando DIF(2) es pequeño, pequeños cambios en (A, B) pueden causar grandes cambios
!>  en el subespacio deflactante. Una cota (asintótica) aproximada sobre el
!>  error angular máximo en los subespacios deflactantes calculados es
!>
!>       EPS * norm((A, B)) / DIF(2),
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  La norma recíproca de los proyectores sobre los autoespacios
!>  izquierdos y derechos asociados con (A11, B11) pueden devolverse en PL y PR.
!>  Se calculan de la siguiente manera. Primero calculamos L y R de modo que
!>  P*(A, B)*Q sea diagonal por bloques, donde
!>
!>       P = ( I -L ) n1           Q = ( I R ) n1
!>           ( 0  I ) n2    y        ( 0 I ) n2
!>             n1 n2                    n1 n2
!>
!>  y (L, R) es la solución a la ecuación de Sylvester generalizada
!>
!>       A11*R - L*A22 = -A12
!>       B11*R - L*B22 = -B12
!>
!>  Entonces PL = (F-norm(L)**2+1)**(-1/2) y PR = (F-norm(R)**2+1)**(-1/2).
!>  Una cota (asintótica) aproximada sobre el error absoluto promedio de
!>  los autovalores seleccionados es
!>
!>       EPS * norm((A, B)) / PL.
!>
!>  También existen cotas de error globales que son válidas para perturbaciones hasta
!>  cierta restricción: una cota inferior (x) sobre la F-norm(E,F) más pequeña
!>  para la cual un autovalor de (A11, B11) puede moverse y
!>  coalescer con un autovalor de (A22, B22) bajo la perturbación (E,F),
!>  (es decir, (A + E, B + F), es
!>
!>   x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).
!>
!>  Se puede calcular una cota aproximada sobre x a partir de DIF(1:2), PL y PR.
!>
!>  Si y = ( F-norm(E,F) / x) <= 1, los ángulos entre los subespacios
!>  deflactantes izquierdos y derechos perturbados (L', R') y no perturbados (L, R)
!>  asociados con el grupo seleccionado en los bloques (1,1) pueden
!>  acotarse como
!>
!>   max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
!>   max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))
!>
!>  Véase la sección 4.11 de la Guía de Usuario de LAPACK o las siguientes referencias
!>  para más información.
!>
!>  Nótese que si no se desea el método por defecto para calcular la estimación DIF
!>  basada en la norma de Frobenius (véase CLATDF), entonces el parámetro
!>  IDIFJB (véase abajo) debería cambiarse de 3 a 4 (se usará la rutina CLATDF
!>  (IJOB = 2)). Véase CTGSYL para más detalles.
!>
