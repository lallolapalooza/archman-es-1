CTIME(3P) Manual del Programador POSIX CTIME(3P)

PRÓLOGO

Esta página de manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página de manual correspondiente de Linux para conocer el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ctime, ctime_r — convierte un valor de tiempo en una cadena de fecha y hora

SINOPSIS

#include <time.h>
char *ctime(const time_t *clock);
char *ctime_r(const time_t *clock, char *buf);

DESCRIPCIÓN

Para ctime(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La ctime() función convertirá el tiempo al que apunta clock, que representa el tiempo en segundos desde la Época, a hora local en forma de cadena. Será equivalente a:

asctime(localtime(clock))

Las funciones asctime(), ctime(), gmtime() y localtime() devolverán valores en uno de dos objetos estáticos: una estructura de tiempo desglosada y una matriz de char. La ejecución de cualquiera de las funciones puede sobrescribir la información devuelta en cualquiera de estos objetos por cualquiera de las otras funciones.

La ctime() función no necesita ser segura para hilos.

La ctime_r() función convertirá el tiempo de calendario al que apunta clock a hora local en exactamente la misma forma que ctime() y colocará la cadena en la matriz a la que apunta buf (que debe tener al menos 26 bytes de tamaño) y devolverá buf.

A diferencia de ctime(), no se requiere que la ctime_r() función establezca tzname. Si ctime_r() establece tzname, también deberá establecer daylight y timezone. Si ctime_r() no establece tzname, no establecerá daylight y no establecerá timezone.

VALOR DE RETORNO

La ctime() función devolverá el puntero devuelto por asctime() con ese tiempo desglosado como argumento.

Tras una finalización exitosa, ctime_r() devolverá un puntero a la cadena a la que apunta buf. Cuando se encuentre un error, se devolverá un puntero nulo.

ERRORES

No se definen errores.

USO EN APLICACIONES

Estas funciones se incluyen solo por compatibilidad con implementaciones anteriores. Tienen comportamiento indefinido si la cadena resultante fuera demasiado larga, por lo que se debe desaconsejar el uso de estas funciones. En implementaciones que no detectan desbordamiento de la longitud de la cadena de salida, es posible desbordar los búferes de salida de tal manera que haga fallar las aplicaciones, o posibles violaciones de seguridad del sistema. Además, estas funciones no admiten formatos de fecha y hora localizados. Para evitar estos problemas, las aplicaciones deben usar strftime() para generar cadenas a partir de tiempos desglosados.

Los valores para la estructura de tiempo desglosada se pueden obtener llamando a gmtime() o localtime().

La ctime_r() función es segura para hilos y devolverá valores en un búfer proporcionado por el usuario en lugar de usar posiblemente un área de datos estática que puede ser sobrescrita en cada llamada.

Los intentos de usar ctime() o ctime_r() para tiempos anteriores a la Época o para tiempos posteriores al año 9999 producen resultados indefinidos. Consulte asctime().

JUSTIFICACIÓN

Los desarrolladores de estándares decidieron marcar las funciones ctime() y ctime_r() como obsoletas, aunque están en el estándar ISO C, debido a la posibilidad de desbordamiento de búfer. El estándar ISO C también proporciona la función strftime() que se puede usar para evitar estos problemas.

DIRECCIONES FUTURAS

Estas funciones pueden eliminarse en una versión futura.
