CTLOG_STORE_get0_log_by_id(3ssl)

NOMBRE

CTLOG_STORE_get0_log_by_id - Obtener un registro CTLOG de un CTLOG_STORE

SINOPSIS

#include <openssl/ct.h>
const CTLOG *CTLOG_STORE_get0_log_by_id(const CTLOG_STORE *store,
                                        const uint8_t *log_id,
                                        size_t log_id_len);

DESCRIPCIÓN

Una Marca de Tiempo de Certificado Firmado (SCT) identifica el registro de Transparencia de Certificados (CT) que la emitió utilizando el LogID del registro (ver RFC 6962, Sección 3.2). Por lo tanto, es útil poder buscar más información sobre un registro (por ejemplo, su clave pública) utilizando este LogID.

CTLOG_STORE_get0_log_by_id() proporciona una forma de hacer esto. Encontrará un CTLOG en un CTLOG_STORE que tenga un LogID dado.

VALORES DE RETORNO

CTLOG_STORE_get0_log_by_id devuelve un CTLOG con el LogID dado, si existe en el CTLOG_STORE dado, de lo contrario devuelve NULL.

VER TAMBIÉN

ct(7), CTLOG_STORE_new(3)

HISTORIAL

La función CTLOG_STORE_get0_log_by_id() se añadió en OpenSSL 1.1.0.
