Nombre

ctags-lang-kconfig - Notas varias sobre el etiquetado de código fuente Kconfig con Universal Ctags

SINOPSIS

ctags ... --languages=+Kconfig ...
ctags ... --language-force=Kconfig ...
ctags ... --map-Kconfig=+(Kconfig*) ...

DESCRIPCIÓN

Esta página del manual recopila notas varias sobre el etiquetado de scripts Kconfig.

VERSIÓNES

Cambio desde "0.0"

•
Nuevo tipo de etiqueta variable
