Nombre

ctags-lang-i18nrubgem - Notas aleatorias sobre el etiquetado de entradas para I18n Ruby Gem con Universal Ctags

SINÓPSIS

ctags ... --extras=+s --languages=+I18nRubyGem ...
ctags ... --extras=+s --language-force=I18nRubyGem ...
ctags ... --extras=+s --map-I18nRubyGem=+.yaml ...
ctags ... --extras=+s --map-I18nRubyGem=+.yml ...

DESCRIPCIÓN

Esta página de manual recopila notas aleatorias sobre el etiquetado de entradas para I18n Ruby Gem [RUBYI18N]. I18nRubyGem es un sub-analizador que se ejecuta en el analizador Yaml. Si un token escalar de nivel superior de una entrada de origen Yaml dada es un nombre local [ISOCODES], I18nRubyGem se activa. Si no, I18nRubyGem no hace nada.

"input.yaml"

---
ja:
  msg:
    error: エラー
    function: 関数

"output.tags" con "--options=NONE -o - --fields=+E input.yaml"

error   input.yaml      /^    error: エラー$/;"    k       keyInMiddle:ja.msg      extras:subparser
function        input.yaml      /^    function: 関数$/;"  k       keyInMiddle:ja.msg      extras:subparser
ja.msg.error    input.yaml      /^    error: エラー$/;"    k       keyInMiddle:ja.msg      extras:subparser,localeful
ja.msg.function input.yaml      /^    function: 関数$/;"  k       keyInMiddle:ja.msg      extras:subparser,localeful
msg.error       input.yaml      /^    error: エラー$/;"    k       locale:ja       extras:subparser,localeless
msg.function    input.yaml      /^    function: 関数$/;"  k       locale:ja       extras:subparser,localeless

Con las opciones, el analizador emite tres entradas de etiqueta para una clave: "error", "js.msg.error" y "msg.error" para la clave "error". El analizador emite "error" en la primera línea siempre.

Para emitir "ja.msg.error", una etiqueta extra localeful, en la quinta línea siempre. Si especifica --extra=+q o --extra=+{qualified}, ctags emite la misma etiqueta dos veces: una etiqueta localeful y una etiqueta qualified. Puede suprimir las etiquetas extra localeful especificando --extras-I18nRubyGem=-{localeful}.

Para emitir "msg.error", una etiqueta extra localeless, en la quinta línea siempre. El analizador crea una etiqueta extra localeless truncando el primer componente (por ejemplo, "ja.") de la etiqueta extra calificada completa asociada (por ejemplo, "ja.msg.error"). La etiqueta extra localeless está habilitada por defecto. Si no necesita etiquetas extra localeless, especifique --extras-I18nRubyGem=-{localeless}.

El analizador no crea entradas de etiqueta para componentes de nivel superior y medio como ja y msg por defecto. Si los necesita, especifique --kinds-I18nRubyGem=+{locale} y/o --kinds-I18nRubyGem=+{keyInMiddle}.

BUGS CONOCIDOS

El mecanismo que activa el sub-analizador I18nRubyGem no funciona bien para entradas de origen YAML que contienen múltiples documentos.
