Documentación de Función/Subrutin

a

subrutina ctrsen (character job, character compq, logical, dimension( * ) select, integer n, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( * ) w, integer m, real s, real sep, complex, dimension( * ) work, integer lwork, integer

info)

CTRSE

N

Propósito

: 
!>
!> CTRSEN reordena la factorización de Schur de una matriz compleja
!> A = Q*T*Q**H, de modo que un grupo seleccionado de autovalores aparezca en
!> las posiciones principales de la diagonal de la matriz triangular superior
!> T, y las columnas principales de Q forman una base ortonormal del
!> subespacio invariante derecho correspondiente.
!>
!> Opcionalmente, la rutina calcula los números de condición recíprocos del
!> grupo de autovalores y/o del subespacio invariante.
!
>

Parámetro

s
JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para el
!>          grupo de autovalores (S) o para el subespacio invariante (SEP):
!>          = 'N': ninguno;
!>          = 'E': solo para autovalores (S);
!>          = 'V': solo para el subespacio invariante (SEP);
!>          = 'B': tanto para autovalores como para el subespacio invariante (S y
!>                 SEP).
!
>

COMP

Q 
!>          COMPQ es CHARACTER*1
!>          = 'V': actualizar la matriz Q de vectores de Schur;
!>          = 'N': no actualizar Q.
!
>

SELEC

T 
!>          SELECT es un arreglo LOGICAL, dimensión (N)
!>          SELECT especifica los autovalores en el grupo seleccionado. Para
!>          seleccionar el j-ésimo autovalor, SELECT(j) debe establecerse en .TRUE..
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!
>

T 
!>          T es un arreglo COMPLEX, dimensión (LDT,N)
!>          Al entrar, la matriz triangular superior T.
!>          Al salir, T se sobrescribe con la matriz T reordenada, con los
!>          autovalores seleccionados como elementos diagonales principales.
!
>

LD

T 
!>          LDT es INTEGER
!>          La dimensión principal del arreglo T. LDT >= max(1,N).
!
>

Q 
!>          Q es un arreglo COMPLEX, dimensión (LDQ,N)
!>          Al entrar, si COMPQ = 'V', la matriz Q de vectores de Schur.
!>          Al salir, si COMPQ = 'V', Q ha sido postmultiplicada por la
!>          matriz de transformación unitaria que reordena T; las primeras M
!>          columnas de Q forman una base ortonormal para el subespacio
!>          invariante especificado.
!>          Si COMPQ = 'N', Q no se referencia.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del arreglo Q.
!>          LDQ >= 1; y si COMPQ = 'V', LDQ >= N.
!
>

W 
!>          W es un arreglo COMPLEX, dimensión (N)
!>          Los autovalores reordenados de T, en el mismo orden en que
!>          aparecen en la diagonal de T.
!
>

M 
!>          M es INTEGER
!>          La dimensión del subespacio invariante especificado.
!>          0 <= M <= N.
!
>

S 
!>          S es REAL
!>          Si JOB = 'E' o 'B', S es una cota inferior para el número de
!>          condición recíproco del grupo seleccionado de autovalores.
!>          S no puede subestimar el verdadero número de condición recíproco
!>          en más de un factor de sqrt(N). Si M = 0 o N, S = 1.
!>          Si JOB = 'N' o 'V', S no se referencia.
!
>

SE

P 
!>          SEP es REAL
!>          Si JOB = 'V' o 'B', SEP es el número de condición recíproco estimado
!>          del subespacio invariante especificado. Si
!>          M = 0 o N, SEP = norm(T).
!>          Si JOB = 'N' o 'E', SEP no se referencia.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.
!>          Si JOB = 'N', LWORK >= 1;
!>          si JOB = 'E', LWORK = max(1,M*(N-M));
!>          si JOB = 'V' o 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>

Detalles

adicionales: 
!>
!>  CTRSEN primero recoge los autovalores seleccionados calculando una transformación unitaria
!>  Z para moverlos a la esquina superior izquierda de T. En otras
!>  palabras, los autovalores seleccionados son los autovalores de T11 en:
!>
!>          Z**H * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  donde N = n1+n2. Las primeras
!>  n1 columnas de Z abarcan el subespacio invariante especificado de T.
!>
!>  Si T se ha obtenido de la factorización de Schur de una matriz
!>  A = Q*T*Q**H, entonces la factorización de Schur reordenada de A es dada por
!>  A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, y las primeras n1 columnas de Q*Z abarcan el
!>  subespacio invariante correspondiente de A.
!>
!>  El número de condición recíproco del promedio de los autovalores de
!>  T11 puede devolverse en S. S se encuentra entre 0 (muy mal condicionado)
!>  y 1 (muy bien condicionado). Se calcula de la siguiente manera. Primero
!>  calculamos R de modo que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!>  es el proyector sobre el subespacio invariante asociado con T11.
!>  R es la solución de la ecuación de Sylvester:
!>
!>                        T11*R - R*T22 = T12.
!>
!>  Sea F-norm(M) la norma de Frobenius de M y 2-norm(M) la
!>  norma 2 de M. Entonces S se calcula como la cota inferior
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!>  sobre el recíproco de 2-norm(P), el verdadero número de condición recíproco.
!>  S no puede subestimar 1 / 2-norm(P) en más de un factor de
!>  sqrt(N).
!>
!>  Una cota de error aproximada para el promedio calculado de los
!>  autovalores de T11 es
!>
!>                         EPS * norm(T) / S
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El número de condición recíproco del subespacio invariante derecho
!>  abarcado por las primeras n1 columnas de Z (o de Q*Z) se devuelve en SEP.
!>  SEP se define como la separación de T11 y T22:
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!>  donde sigma-min(C) es el valor singular más pequeño de la
!>  matriz n1*n2-por-n1*n2
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!>  I(m) es una matriz identidad m por m, y kprod denota el producto de Kronecker.
!>  Estimamos sigma-min(C) por el recíproco de una estimación de
!>  la norma 1 de inverse(C). El verdadero recíproco de la norma 1 de inverse(C)
!>  no puede diferir de sigma-min(C) en más de un factor de sqrt(n1*n2).
!>
!>  Cuando SEP es pequeño, pequeños cambios en T pueden causar grandes cambios en
!>  el subespacio invariante. Una cota aproximada sobre el error angular máximo
!>  en el subespacio invariante derecho calculado es
!>
!>                      EPS * norm(T) / SEP
!
>
