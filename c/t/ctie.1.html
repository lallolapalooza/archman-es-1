CTIE(1) Manual de Comandos Generales CTIE(1)

NOMBRE

ctie - fusionar o aplicar archivos de cambios de CWEB

SINOPSIS

ctie -c|-m archivo_salida archivo_maestro archivo_cambios...

DESCRIPCIÓN

El programa ctie se utiliza para procesar múltiples archivos de cambios utilizados con el sistema CWEB para programación literaria. Los programas CWEB permiten aplicar parches a un archivo fuente (el archivo_maestro) mediante un único archivo de cambios. ctie se puede utilizar para fusionar hasta 32 archivos de cambios en uno solo o para aplicar los cambios al archivo_maestro con el fin de crear un nuevo archivo maestro. La salida, ya sea el nuevo archivo de cambios o el archivo maestro parcheado, va a archivo_salida. Cualquier archivo incluido (indicado mediante el comando @i de CWEB) se expande completamente durante el procesamiento de ctie, lo que significa que los archivos de cambios pueden modificar el contenido de cualquier archivo incluido.

OPCIONES

-c
Crear un único archivo de cambios a partir de los archivo_cambios dados.
-m
Crear un nuevo archivo maestro aplicando los archivo_cambios dados.

ENTORNO

La variable de entorno CWEBINPUTS se utiliza para buscar los archivos de entrada, o el valor predeterminado del sistema si CWEBINPUTS no está configurada. Consulte tex(1) para obtener detalles sobre la búsqueda. Para evitar conflictos con otros programas que también utilizan el entorno CWEBINPUTS, puede ser más específico y usar CWEBINPUTS_ctie para requisitos especiales en CTIE.

VER TAMBIÉN

cweb(1), ctiedoc.tex, tie(1), web(1).
