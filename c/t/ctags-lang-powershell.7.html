Nombre

ctags-lang-powershell - Notas aleatorias sobre el etiquetado de código fuente de PowerShell con Universal Ctags

SINOPSIS

ctags ... --languages=+PowerShell ...
ctags ... --language-force=PowerShell ...
ctags ... --map-powershell=+.ps1 ...
ctags ... --map-powershell=+.psm1 ...

Esta página del manual recopila notas aleatorias sobre el etiquetado de código fuente de PowerShell.
