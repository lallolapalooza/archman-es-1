Nombre

ctags-lang-javascript - Notas aleatorias sobre el etiquetado de código fuente JavaScript con Universal Ctags

Sinopsis

ctags ... --languages=+JavaScript ...
ctags ... --language-force=JavaScript ...
ctags ... --map-JavaScript=+.js ...

Descripción

Esta página del manual recopila notas aleatorias sobre el etiquetado de código fuente JavaScript.

Clases

ES6 introdujo la palabra clave class, pero todavía existe el método original de definir una función y adjuntar un prototype. Ctags sigue la convención de que los nombres de funciones que comienzan con una letra mayúscula son constructores de clases.

Cambio desde "0.0"

•
Nuevo rol foreigndecl para el tipo function
