Documentación de la función/subrutina

subrutina ctbmv (character uplo, character trans, character diag, integer n, integer k, complex, dimension(lda,*) a, integer lda, complex, dimension(*) x, integer incx)

CTBMV

Propósito:

!>
!> CTBMV  realiza una de las operaciones matriz-vector
!>
!>    x := A*x,   o   x := A**T*x,   o   x := A**H*x,
!>
!> donde x es un vector de n elementos y  A es una matriz cuadrada de n por n, unitaria o no unitaria,
!> triangular superior o inferior, de banda, con ( k + 1 ) diagonales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la matriz es superior o
!>           inferior triangular de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           A la entrada, TRANS especifica la operación a realizar de la siguiente manera:
!>
!>              TRANS = 'N' o 'n'   x := A*x.
!>
!>              TRANS = 'T' o 't'   x := A**T*x.
!>
!>              TRANS = 'C' o 'c'   x := A**H*x.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           A la entrada, DIAG especifica si A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es unitaria triangular.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

K

!>          K es INTEGER
!>           A la entrada con UPLO = 'U' o 'u', K especifica el número de
!>           super-diagonales de la matriz A.
!>           A la entrada con UPLO = 'L' o 'l', K especifica el número de
!>           sub-diagonales de la matriz A.
!>           K debe satisfacer  0 .le. K.
!>

A

!>          A es un array COMPLEX de dimensión ( LDA, N ).
!>           A la entrada con UPLO = 'U' o 'u', las ( k + 1 ) primeras
!>           filas por n columnas de la matriz A deben contener la parte
!>           triangular superior de banda de la matriz de coeficientes,
!>           suministrada columna por columna, con la diagonal principal
!>           de la matriz en la fila ( k + 1 ) del array, la primera
!>           super-diagonal comenzando en la posición 2 en la fila k, y
!>           así sucesivamente. El triángulo superior izquierdo de k por k
!>           del array A no se referencia.
!>           El siguiente segmento de programa transferirá una matriz de
!>           banda triangular superior desde almacenamiento de matriz completa
!>           convencional a almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = K + 1 - J
!>                    DO 10, I = MAX( 1, J - K ), J
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Antes de la entrada con UPLO = 'L' o 'l', las ( k + 1 ) primeras
!>           filas por n columnas del array A deben contener la parte
!>           triangular inferior de banda de la matriz de coeficientes,
!>           suministrada columna por columna, con la diagonal principal
!>           de la matriz en la fila 1 del array, la primera sub-diagonal
!>           comenzando en la posición 1 en la fila 2, y así sucesivamente.
!>           El triángulo inferior derecho de k por k del array A no se
!>           referencia.
!>           El siguiente segmento de programa transferirá una matriz de
!>           banda triangular inferior desde almacenamiento de matriz completa
!>           convencional a almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = 1 - J
!>                    DO 10, I = J, MIN( N, J + K )
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Tenga en cuenta que cuando DIAG = 'U' o 'u', los elementos del array A
!>           correspondientes a los elementos diagonales de la matriz no se
!>           referencian, pero se asumen como unidad.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como
!>           se declara en el programa llamador (subrutina). LDA debe ser
!>           al menos ( k + 1 ).
!>

X

!>          X es un array COMPLEX de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x de n elementos. A la salida, X se sobrescribe con el
!>           vector transformado x.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>
