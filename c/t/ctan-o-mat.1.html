NOMBRE

ctan-o-mat - Validar y subir un paquete para CTAN

SINOPSIS

ctan-o-mat [opciones] [<configuración del paquete>]

DESCRIPCIÓN

Este programa se puede utilizar para automatizar la subida de un paquete a la Red Integral de Archivos de TeX (CTAN) (véase https://www.ctan.org). La descripción del paquete se toma de un archivo de configuración. Por lo tanto, se puede actualizar fácilmente sin necesidad de rellenar un formulario web con la misma información antigua una y otra vez.

La información proporcionada se valida en cualquier caso. Si la validación tiene éxito y no solo se solicita la validación, el archivo de archivo proporcionado se coloca en el área de entrada de CTAN para su procesamiento posterior por parte del equipo de CTAN.

En cualquier caso, cualquier hallazgo durante la validación se informa al final del procesamiento. Tenga en cuenta que la validación es la predeterminada y se debe solicitar una presentación oficial mediante la opción de línea de comandos apropiada.

ctan-o-mat requiere una conexión a Internet con el servidor CTAN. Incluso la validación recupera los atributos conocidos y las restricciones básicas del servidor.

CONFIGURACIÓN

La configuración predeterminada se lee de un archivo con el mismo nombre que el directorio actual y la extensión .pkg. Este nombre de archivo se puede sobrescribir en la línea de comandos.

La configuración depende de las características actualmente soportadas por el servidor CTAN. Dado que estas características pueden cambiar con el tiempo, la configuración no está codificada en ctan-o-mat. Puede solicitar una plantilla vacía de la configuración mediante el parámetro de línea de comandos "--init".

OPCIONES

-h
--help
Imprime este breve resumen sobre el uso y sale del programa.
-i
--init
Crea una plantilla vacía para una configuración.
--list licenses
Lista las licencias conocidas de CTAN en el flujo de salida estándar. Cada licencia se representa en una línea. La línea contiene los campos clave, nombre e indicador de libre. Estos campos están separados por tabulaciones. Posteriormente, el programa termina sin procesar ningún argumento más.
--config <configuración del paquete>
--pkg <configuración del paquete>
--package <configuración del paquete>
Establece el archivo de configuración del paquete.
-s
--submit
Sube la presentación, la valida y la envía oficialmente a CTAN si la validación tiene éxito.
-v
--verbose
Imprime información adicional durante el procesamiento (modo detallado).
--version
Imprime el número de versión de este programa y sale.
--validate
-n
--noaction
No realiza la subida final. El paquete se valida y se imprimen los mensajes resultantes.
<package>
Este parámetro es el nombre de una configuración de paquete (véase la sección CONFIGURACIÓN) contenida en un archivo. Si no se especifica lo contrario, la configuración del paquete por defecto es el nombre del directorio actual con ".pkg" añadido.

ENTORNO

Las siguientes variables de entorno son reconocidas por ctan-o-mat.

CTAN_O_MAT_URL
El valor es el prefijo de URL para el servidor CTAN a contactar. El valor predeterminado es "https://ctan.org/submit". La URL completa se construye añadiendo "validate", "upload", o "fields" para usar la API REST de CTAN respectiva.

CONEXIÓN VIA PROXYS

Si necesita conectarse a Internet a través de un proxy, esto se puede lograr configurando algunas variables de entorno antes de ejecutar ctan-o-mat. Para redirigir la solicitud a través del proxy, simplemente defina una variable de entorno "http_proxy" para que apunte al host del proxy, incluyendo el protocolo y el puerto según sea necesario. Tenga en cuenta que el nombre de la variable de entorno debe estar en minúsculas.

AUTOR

Gerd Neugebauer (gene@gerd-neugebauer.de)

ERRORES

•
El programa no se puede utilizar sin una conexión funcional a Internet.
