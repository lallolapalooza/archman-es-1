subroutine ctpt06 (real rcond, real rcondc, character uplo, character diag, integer n, complex, dimension( * ) ap, real, dimension( * ) rwork, real rat)

CTPT06

Propósito:

!>
!> CTPT06 calcula una relación de prueba que compara RCOND (el recíproco
!> del número de condición de la matriz triangular A) y RCONDC, la estimación
!> calculada por CTPCON. Se utiliza información de la matriz triangular
!> si una estimación es cero y la otra no, para decidir si el
!> subdesbordamiento en la estimación está justificado.
!>

Parámetros

RCOND 
!>          RCOND es REAL
!>          La estimación del recíproco del número de condición obtenida
!>          al formar la inversa explícita de la matriz A y calculando
!>          RCOND = 1/( norm(A) * norm(inv(A)) ).
!>

RCONDC

!>          RCONDC es REAL
!>          La estimación del recíproco del número de condición calculada
!>          por CTPCON.
!>

UPLO

!>          UPLO es CHARACTER
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX, dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por
!>          columnas en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) para j<=i<=n.
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

RAT

!>          RAT es REAL
!>          La relación de prueba. Si ambos RCOND y RCONDC son distintos de
!>          cero,
!>             RAT = MAX( RCOND, RCONDC )/MIN( RCOND, RCONDC ) - 1.
!>          Si RAT = 0, las dos estimaciones son exactamente iguales.
!>
