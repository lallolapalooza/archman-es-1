CURLSHOPT_UNSHARE(3)

Paquete: curl

Licencias: MIT

CURLSHOPT_UNSHARE(3) Manual de funciones de biblioteca CURLSHOPT_UNSHARE(3)

NOMBRE

CURLSHOPT_UNSHARE - eliminar datos para compartir

SINOPSIS

#include <curl/curl.h>
CURLSHcode curl_share_setopt(CURLSH *share, CURLSHOPT_UNSHARE, long type);

DESCRIPCIÓN

El parámetro type especifica qué datos específicos ya no se deben compartir y mantener en el objeto de compartición que se creó con curl_share_init(3). En otras palabras, dejar de compartir esos datos en este objeto compartido. El type proporcionado debe ser uno de los valores descritos a continuación. Puede establecer CURLSHOPT_UNSHARE(3) varias veces con diferentes argumentos de datos para eliminar varios tipos del objeto compartido. Añadir datos para compartir de nuevo con CURLSHOPT_SHARE(3).

CURL_LOCK_DATA_COOKIE
Los datos de cookies ya no se compartirán entre los manejadores easy que utilicen este objeto compartido.
CURL_LOCK_DATA_DNS
Los hosts DNS cacheados ya no se compartirán entre los manejadores easy que utilicen este objeto compartido.
CURL_LOCK_DATA_SSL_SESSION
Las IDs de sesión SSL ya no se compartirán entre los manejadores easy que utilicen este objeto compartido.
CURL_LOCK_DATA_CONNECT
La caché de conexiones ya no se compartirá.
CURL_LOCK_DATA_PSL
La lista de sufijos públicos ya no se compartirá.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos.

EJEMPLO

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_UNSHARE, CURL_LOCK_DATA_COOKIE);
  if(sh)
    printf("Error: %s\n", curl_share_strerror(sh));
}

DISPONIBILIDAD

Añadido en curl 7.10.3

VALOR DE RETORNO

CURLSHE_OK (cero) significa que la opción se estableció correctamente, un valor distinto de cero indica que ocurrió un error. Consulte libcurl-errors(3) para ver la lista completa con descripciones.
