curs_addchstr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_addchstr(3x) Llamadas a bibliotecas curs_addchstr(3x)

NOMBRE

addchstr, addchnstr, waddchstr, waddchnstr, mvaddchstr, mvaddchnstr, mvwaddchstr, mvwaddchnstr - agregar una cadena de caracteres curses a una ventana

SINOPSIS

#include <curses.h>
int addchstr(const chtype *chstr);
int waddchstr(WINDOW *win, const chtype *chstr);
int mvaddchstr(int y, int x, const chtype *chstr);
int mvwaddchstr(WINDOW *win, int y, int x, const chtype *chstr);
int addchnstr(const chtype *chstr, int n);
int waddchnstr(WINDOW *win, const chtype *chstr, int n);
int mvaddchnstr(int y, int x, const chtype *chstr, int n);
int mvwaddchnstr(WINDOW *win, int y, int x, const chtype *chstr, int n);

DESCRIPCIÓN

Estas funciones copian la matriz chstr (terminada en nulo) a la estructura de imagen de la ventana comenzando en la posición actual del cursor.

Las cuatro funciones con n como argumento final copian como máximo n elementos, pero no más de los que caben en la línea. Si n=-1, entonces se copia toda la matriz, hasta el número máximo de caracteres que caben en la línea.

El cursor de la ventana no se avanza. Estas funciones son más rápidas que waddnstr. Por otro lado:

  • no realizan comprobaciones (como para los caracteres de nueva línea, retroceso o retorno de carro),
  • no avanzan la posición actual del cursor,
  • no expanden otros caracteres de control a escapes ^-, y
  • truncan la cadena si cruza el margen derecho, en lugar de envolverla a la nueva línea.

VALOR DE RETORNO

Todas las funciones devuelven el entero ERR en caso de fallo y OK en caso de éxito.

X/Open Curses no especifica ninguna condición de error. Esta implementación devuelve un error

  • si el parámetro win es nulo o
  • si el parámetro wchstr es nulo.

Las funciones prefijadas con “mv” primero realizan movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Todas las funciones excepto waddchnstr pueden ser macros.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4.

VER TAMBIÉN

curs_add_wchstr(3X) describe funciones comparables de la biblioteca ncurses en su configuración de caracteres anchos (ncursesw).
