CURLOPT_PRE_PROXY(3)

Paquete: curl

Licencias: MIT

CURLOPT_PRE_PROXY(3) Manual de funciones de biblioteca CURLOPT_PRE_PROXY(3)

NOMBRE

CURLOPT_PRE_PROXY - host pre-proxy a utilizar

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PRE_PROXY, char *preproxy);

DESCRIPCIÓN

Establece el preproxy a utilizar para la próxima solicitud. El parámetro debe ser un puntero a un string terminado en nulo que contenga el nombre del host o la dirección IP numérica con puntos. Una dirección IPv6 numérica debe escribirse entre corchetes [].

Para especificar el número de puerto en este string, añada :[puerto] al final del nombre del host. El número de puerto del proxy puede especificarse opcionalmente con la opción separada CURLOPT_PROXYPORT(3). Si no se especifica, libcurl utiliza por defecto el puerto 1080 para los proxies.

Un pre-proxy es un proxy SOCKS al que curl se conecta antes de conectarse al proxy HTTP(S) especificado en la opción CURLOPT_PROXY(3). El pre-proxy solo puede ser un proxy SOCKS.

El string del pre-proxy debe ir precedido de [esquema]:// para especificar qué tipo de socks se utiliza. Utilice socks4://, socks4a://, socks5:// o socks5h:// (este último para habilitar socks5 y pedir al proxy que realice la resolución, también conocido como tipo CURLPROXY_SOCKS5_HOSTNAME) para solicitar la versión específica de SOCKS que se utilizará. De lo contrario, se utiliza SOCKS4 por defecto.

Establecer el string del pre-proxy a "" (un string vacío) deshabilita explícitamente el uso de un pre-proxy.

Cuando establezca un nombre de host a utilizar, no asuma que hay un número de puerto específico ampliamente utilizado para proxies. Especifíquelo.

La aplicación no tiene que mantener el string disponible después de establecer esta opción.

Utilizar esta opción varias veces hace que el último string establecido anule los anteriores. Establézcalo a NULL para deshabilitar su uso nuevamente.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/file.txt");
    curl_easy_setopt(curl, CURLOPT_PRE_PROXY, "socks4://socks-proxy:1080");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://proxy:80");
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error, consulte libcurl-errors(3).
