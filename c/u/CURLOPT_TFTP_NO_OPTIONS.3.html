CURLOPT_TFTP_NO_OPTIONS(3)

Paquete: curl

Licencias: MIT

CURLOPT_TFTP_NO_OPTIONS(3) Manual de funciones de la biblioteca CURLOPT_TFTP_NO_OPTIONS(3)

NOMBRE

CURLOPT_TFTP_NO_OPTIONS - no enviar solicitudes de opciones TFTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TFTP_NO_OPTIONS, long onoff);

DESCRIPCIÓN

Establece onoff a 1L para excluir todas las opciones TFTP definidas en RFC 2347, RFC 2348 y RFC 2349 de las solicitudes de lectura y escritura.

Esta opción mejora la interoperabilidad con servidores heredados que no reconocen o implementan correctamente las opciones TFTP. Cuando se utiliza esta opción, CURLOPT_TFTP_BLKSIZE(3) se ignora.

POR OMISIÓN

0

PROTOCOLOS

Esta funcionalidad solo afecta a tftp

EJEMPLO

size_t write_callback(char *ptr, size_t size, size_t nmemb, void *fp)
{
  return fwrite(ptr, size, nmemb, (FILE *)fp);
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    FILE *fp = fopen("foo.bin", "wb");
    if(fp) {
      curl_easy_setopt(curl, CURLOPT_WRITEDATA, (void *)fp);
      curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, write_callback);
      curl_easy_setopt(curl, CURLOPT_URL, "tftp://example.com/foo.bin");
      /* no enviar solicitudes de opciones TFTP */
      curl_easy_setopt(curl, CURLOPT_TFTP_NO_OPTIONS, 1L);
      /* Realizar la solicitud */
      curl_easy_perform(curl);
      fclose(fp);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.48.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
