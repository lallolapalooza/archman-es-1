CURLOPT_TELNETOPTIONS(3)

Paquete: curl

Licencias: MIT

CURLOPT_TELNETOPTIONS(3) Manual de funciones de la biblioteca CURLOPT_TELNETOPTIONS(3)

NOMBRE

CURLOPT_TELNETOPTIONS - conjunto de opciones de telnet

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TELNETOPTIONS,
                          struct curl_slist *cmds);

DESCRIPCIÓN

Proporciona un puntero a una lista curl_slist con variables para pasar a las negociaciones de telnet. Las variables deben tener el formato <opción=valor>. libcurl admite las opciones TTYPE, XDISPLOC y NEW_ENV. Consulte el estándar TELNET para obtener más detalles.

El uso de esta opción varias veces hace que la última lista establecida anule las anteriores. Establézcala a NULL para deshabilitar su uso nuevamente.

libcurl no copia la lista, debe mantenerse hasta después de que la transferencia se haya completado.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a telnet

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_slist *options;
    options = curl_slist_append(NULL, "TTTYPE=vt100");
    options = curl_slist_append(options, "USER=foobar");
    curl_easy_setopt(curl, CURLOPT_URL, "telnet://example.com/");
    curl_easy_setopt(curl, CURLOPT_TELNETOPTIONS, options);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
    curl_slist_free_all(options);
  }
}

DISPONIBILIDAD

Añadido en curl 7.7

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un código CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).
