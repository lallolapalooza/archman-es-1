NOMBRE

snmp - backend snmp de cups (obsoleto)

SINOPSIS

/usr/lib/cups/backend/snmp direccion-ip-o-nombre-host
/usr/libexec/cups/backend/snmp direccion-ip-o-nombre-host
lpinfo -v --include-schemes snmp

DESCRIPCIÓN

El backend SNMP de CUPS, **OBSOLETO**, proporciona descubrimiento e identificación heredados de impresoras de red utilizando SNMPv1. Cuando se utiliza para el descubrimiento a través del planificador, el backend listará todas las impresoras que respondan a una consulta SNMPv1 de difusión con el nombre de comunidad "public". Luego se envían consultas adicionales a las impresoras que responden para determinar la URI del dispositivo correcta, la marca y modelo, y otra información necesaria para la impresión.

En la primera forma, el backend SNMP es ejecutado directamente por el usuario para buscar la URI del dispositivo y otra información cuando se tiene una dirección IP o un nombre de host. Esto se puede utilizar para programas que necesitan configurar colas de impresión donde el usuario ha proporcionado una dirección pero nada más.

En la segunda forma, el backend SNMP se ejecuta indirectamente utilizando el comando lpinfo(8). La salida proporciona todas las impresoras detectadas vía SNMP en las direcciones de difusión configuradas. *Nota: no hay direcciones de difusión configuradas por defecto.*

ENTORNO

El valor DebugLevel puede ser anulado usando la variable de entorno CUPS_DEBUG_LEVEL. El valor MaxRunTime puede ser anulado usando la variable de entorno CUPS_MAX_RUN_TIME.

ARCHIVOS

El backend SNMP lee el archivo de configuración /etc/cups/snmp.conf, si está presente, para establecer la dirección de difusión predeterminada, el nombre de comunidad y el nivel de registro.

NOTAS

El backend SNMP de CUPS está obsoleto y ya no será compatible en una futura versión de CUPS.

CONFORMIDAD

El backend SNMP de CUPS utiliza la información de los MIB de Host, Impresora y Monitor de Puerto junto con algunos MIB privados de vendedores y sondas de puerto inteligentes para determinar la URI del dispositivo correcta y la marca y modelo para cada impresora.

VER TAMBIÉN
