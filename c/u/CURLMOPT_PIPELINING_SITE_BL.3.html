CURLMOPT_PIPELINING_SITE_BL(3)

Paquete: curl

Licencias: MIT

CURLMOPT_PIPELINING_SITE_BL(3) Manual de funciones de la biblioteca CURLMOPT_PIPELINING_SITE_BL(3)

NOMBRE

CURLMOPT_PIPELINING_SITE_BL - lista de bloqueo de hosts para pipelining

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_PIPELINING_SITE_BL,
                            char **hosts);

DESCRIPCIÓN

Sin función desde que se eliminó el pipelining en 7.62.0.

Pase un array hosts de char *, terminado con una entrada NULL. Esta es una lista de sitios que están bloqueados para el pipelining, es decir, sitios que se sabe que no admiten pipelining HTTP. La matriz es copiada por libcurl.

Pase un puntero NULL para borrar la lista de bloqueo.

POR DEFECTO

NULL, lo que significa que no hay lista de bloqueo.

PROTOCOLOS

Esta funcionalidad solo afecta a http

EJEMPLO

static char *site_block_list[] =
{
  "www.haxx.se",
  "www.example.com:1234",
  NULL
};
int main(void)
{
  CURLM *m = curl_multi_init();
  curl_multi_setopt(m, CURLMOPT_PIPELINING_SITE_BL, site_block_list);
}

DISPONIBILIDAD

Añadido en curl 7.30.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
