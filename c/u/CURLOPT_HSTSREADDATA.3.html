CURLOPT_HSTSREADDATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_HSTSREADDATA(3) Manual de funciones de la biblioteca CURLOPT_HSTSREADDATA(3)

NOMBRE

CURLOPT_HSTSREADDATA - puntero pasado a la función de lectura HSTS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTSREADDATA, void *pointer);

DESCRIPCIÓN

Datos pointer para pasar a la función de lectura HSTS. Si usa la opción CURLOPT_HSTSREADFUNCTION(3), este es el puntero que obtiene como entrada en el 3er argumento de la función de devolución de llamada.

Esta opción no habilita HSTS, necesita usar CURLOPT_HSTS_CTRL(3) para hacerlo.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

struct MyData {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  struct MyData this;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "http://example.com");
    /* pasar el puntero que se pasa a la función de devolución de llamada
       CURLOPT_HSTSREADFUNCTION */
    curl_easy_setopt(curl, CURLOPT_HSTSREADDATA, &this);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.74.0

VALOR DE RETORNO

Esto devuelve CURLE_OK.

VER TAMBIÉN

CURLOPT_HSTS(3), CURLOPT_HSTSREADFUNCTION(3), CURLOPT_HSTSWRITEDATA(3), CURLOPT_HSTSWRITEFUNCTION(3)
