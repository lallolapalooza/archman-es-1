CURLOPT_STREAM_DEPENDS_E(3)

Paquete: curl

Licencias: MIT

CURLOPT_STREAM_DEPENDS_E(3) Manual de funciones de la biblioteca CURLOPT_STREAM_DEPENDS_E(3)

NOMBRE

CURLOPT_STREAM_DEPENDS_E - el flujo de esta transferencia depende exclusivamente

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_STREAM_DEPENDS_E,
                          CURL *dephandle);

DESCRIPCIÓN

Pase un puntero CURL en dephandle para identificar el flujo dentro de la misma conexión del cual este flujo depende exclusivamente. Eso significa que depende de él y establece el bit Exclusivo.

La especificación dice "Incluir una dependencia expresa la preferencia de asignar recursos al flujo identificado en lugar de al flujo dependiente".

Establecer una dependencia con el indicador exclusivo para un flujo repriorizado hace que todas las dependencias del nuevo flujo padre se conviertan en dependientes del flujo repriorizado.

Esta opción se puede establecer durante la transferencia.

dephandle no debe ser el mismo que handle, lo que hace que esta función devuelva un error. Debe ser un manejador fácil diferente, y también debe ser el manejador de una transferencia que se va a enviar a través de la misma conexión HTTP/2 para que esta opción tenga un efecto real.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init(); /* un segundo manejador */
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/one");
    /* el segundo depende del primero */
    curl_easy_setopt(curl2, CURLOPT_URL, "https://example.com/two");
    curl_easy_setopt(curl2, CURLOPT_STREAM_DEPENDS_E, curl);
    /* luego agrega ambos a un manejador múltiple y transfiérelos */
  }
}

DISPONIBILIDAD

Agregado en curl 7.46.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, vea libcurl-errors(3).
