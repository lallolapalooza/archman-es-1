NOMBRE

Curses::UI::Checkbox - Crea y manipula widgets de casilla de verificación

VERSIÓN

Versión 1.11

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Checkbox

SINÓPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $checkbox = $win->add(
    'mycheckbox', 'Checkbox',
    -label     => 'Decir hola al mundo',
    -checked   => 1,
);
$checkbox->focus();
my $checked = $checkbox->get();

DESCRIPCIÓN

Curses::UI::Checkbox proporciona un widget de casilla de verificación.

Una casilla de verificación es un control para un valor booleano (un interruptor de encendido/apagado). Consta de una caja que estará vacía (indicando apagado o falso) o contendrá una "X" (indicando encendido o verdadero). A esto le sigue una etiqueta de texto que describe el valor que se está controlando.

[X] Esta casilla está activada/verdadera/marcada/seleccionada
[ ] Esta casilla está desactivada/falsa/desmarcada/no seleccionada

Consulta exampes/demo-Curses::UI::Checkbox en la distribución para una demostración corta.

OPCIONES ESPECÍFICAS DEL WIDGET

-label

Establece la etiqueta inicial para el widget de casilla de verificación a la cadena o valor pasado.

-checked

Toma un argumento booleano. Determina si el estado inicial del widget está marcado o desmarcado. El valor predeterminado es falso (desmarcado).

-onchange

Espera un coderef y lo establece como una devolución de llamada para el widget. Cuando se cambie el estado de la casilla de verificación, se ejecutará el código dado.

MÉTODOS ESTÁNDAR

layout draw    intellidraw
focus  onFocus onBlur

Consulta Curses::UI::Widget para una explicación de estos.

MÉTODOS ESPECÍFICOS DEL WIDGET

get

Devuelve el estado actual de la casilla de verificación (0 == desmarcada, 1 == marcada).

check

Establece la casilla de verificación como "marcada".

uncheck

Establece la casilla de verificación como "desmarcada".

toggle

Cambia el estado de la casilla de verificación a su estado "opuesto". Si la casilla de verificación está desmarcada, se marcará, y viceversa.

onChange

Este método se puede utilizar para establecer el controlador de eventos "-onchange" (ver arriba) después de la inicialización de la casilla de verificación. Espera un coderef como argumento.

ASIGNACIONES PREDETERMINADAS

"[TAB]", "[ENTER}"
Llama a la rutina 'loose-focus', haciendo que el widget pierda el foco.
"[ESPACIO]"
Llama al método "toggle".
0, "n"
Llama al método "uncheck".
1, "y"
Llama al método "check".
