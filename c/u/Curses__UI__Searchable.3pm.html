DESCRIPCION

Usando Curses::UI::Searchable, puedes añadir capacidades de búsqueda tipo 'less' a tu widget.

Para hacer tu widget buscable usando esta clase, tu widget debe cumplir los siguientes requisitos:

  • Hazlo un descendiente de Curses::UI::Searchable

    Todos los métodos para buscar están en Curses::UI::Searchable. Al hacer tu clase descendiente de esta clase, estos métodos se heredan automáticamente.

  • Miembro de datos -ypos

    La posición vertical actual en el widget debe ser identificada por $this->{-ypos}. Esta posición y es el índice de la línea de contenido. Aquí hay un ejemplo para un widget Listbox.

    -ypos
  |
  v
      +------+
  0   |Uno   |
  1   |Dos   |
  2   |Tres  |
      +------+
  • método: number_of_lines ( )

    Tu clase de widget debe tener un método number_of_lines, que devuelve el número total de líneas en el contenido del widget. Así que en el ejemplo anterior, este método devolvería el valor 3.

  • método: getline_at_ypos ( YPOS )

    Tu clase de widget debe tener un método getline_at_ypos, que devuelve la línea de contenido en la posición YPOS del -ypos. Así que en el ejemplo anterior, este método devolvería el valor "Dos" para YPOS = 1.

  • método: layout_content ( )

    Las rutinas de búsqueda establecerán el -ypos de tu widget si se encuentra una coincidencia para la cadena de búsqueda dada. Tu rutina layout_content debe asegurarse de que la línea de contenido en -ypos sea visible si se llama al método draw.

  • método: draw ( )

    Si las rutinas de búsqueda encuentran una coincidencia, $this->{-search_highlight} se establecerá al -ypos de la línea en la que se encontró la coincidencia. Si no se encontró ninguna coincidencia, $this->{-search_highlight} no estará definido. Si quieres que una línea coincidente sea resaltada, en tu widget, puedes usar este miembro de datos para hacerlo (un ejemplo de un widget que usa esta opción es el widget Curses::UI::TextViewer).

  • enlaces para las rutinas de búsqueda

    Hay dos rutinas de búsqueda. Estas son search_forward y search_backward. Estas deben ser llamadas para mostrar el prompt de búsqueda. La mejor manera de hacerlo es creando enlaces para ellas. Aquí hay un ejemplo que hará que '/' sea una búsqueda hacia adelante y '?' una búsqueda hacia atrás:

    $this->set_routine('search-forward'  , \&search_forward);
$this->set_binding('search-forward'  , '/');
$this->set_routine('search-backward' , \&search_backward);
$this->set_binding('search-backward' , '?');
