NOMBRE

cupsaccept/cupsreject - aceptar/rechazar trabajos enviados a un destino

SINOPSIS

cupsaccept [ -E ] [ -U nombredeusuario ] [ -h nombredehost[:puerto] ] destino(s)
cupsreject [ -E ] [ -U nombredeusuario ] [ -h nombredehost[:puerto] ] [ -r razón ] destino(s)

DESCRIPCIÓN

El comando cupsaccept instruye al sistema de impresión para que acepte trabajos de impresión para los destinos especificados.

El comando cupsreject instruye al sistema de impresión para que rechace trabajos de impresión para los destinos especificados. La opción -r establece la razón por la cual se rechazan los trabajos de impresión. Si no se especifica, la razón por defecto es "Razón Desconocida".

OPCIONES

Las siguientes opciones son compatibles con cupsaccept y cupsreject:

-E
Fuerza el cifrado al conectarse al servidor.
-U nombredeusuario
Establece el nombre de usuario que se envía al conectarse al servidor.
-h nombredehost[:puerto]
Elige un servidor alternativo.
-r "razón"
Establece la cadena de razón que se muestra para una impresora que rechaza trabajos.

CONFORMIDAD

Los comandos cupsaccept y cupsreject corresponden a los comandos del sistema de impresión System V "accept" y "reject", respectivamente. A diferencia del sistema de impresión System V, CUPS permite que los nombres de las impresoras contengan cualquier carácter imprimible excepto ESPACIO, TAB, "/" o "#". Además, los nombres de impresoras y clases *no* distinguen entre mayúsculas y minúsculas.

Finalmente, las versiones de CUPS pueden solicitar al usuario una contraseña de acceso dependiendo de la configuración del sistema de impresión.
