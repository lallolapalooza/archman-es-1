CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE(3)

Paquete: curl

Licencias: MIT

CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE(3) Manual de funciones de la biblioteca CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE(3)

NOMBRE

CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE - tamaño umbral para la penalización de canalización

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE,
                            long size);

DESCRIPCIÓN

Sin función, ya que la canalización se eliminó en la versión 7.62.0.

Pase un `long` con un size en bytes. Si una transferencia en una canalización está actualmente procesando una solicitud con un Content-Length mayor que este CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE(3), esa canalización no se tiene en cuenta para solicitudes adicionales, incluso si es más corta que CURLMOPT_MAX_PIPELINE_LENGTH(3).

PREDETERMINADO

0, lo que significa que la penalización de tamaño está inactiva.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURLM *m = curl_multi_init();
  long maxlength = 10000;
  curl_multi_setopt(m, CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE, maxlength);
}

DISPONIBILIDAD

Añadido en curl 7.30.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un `CURLMcode` que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).

VER TAMBIÉN

CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE(3), CURLMOPT_PIPELINING(3)
