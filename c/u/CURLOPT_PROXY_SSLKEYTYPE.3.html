CURLOPT_PROXY_SSLKEYTYPE(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_SSLKEYTYPE(3) Manual de funciones de la biblioteca CURLOPT_PROXY_SSLKEYTYPE(3)

NOMBRE

CURLOPT_PROXY_SSLKEYTYPE - tipo de archivo de clave privada del proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_SSLKEYTYPE, char *type);

DESCRIPCIÓN

Esta opción es para conectarse a un proxy HTTPS, no a un servidor HTTPS.

Pase un puntero a una cadena terminada en nulo como parámetro. La cadena debe ser el formato de su clave privada. Los formatos admitidos son "PEM", "DER", "ENG" y "PROV" (este último añadido en curl 8.12.0).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Utilizar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para desactivar su uso nuevamente.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy");
    curl_easy_setopt(curl, CURLOPT_PROXY_SSLCERT, "client.pem");
    curl_easy_setopt(curl, CURLOPT_PROXY_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_PROXY_SSLKEYTYPE, "PEM");
    curl_easy_setopt(curl, CURLOPT_PROXY_KEYPASSWD, "s3cret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_PROXY_SSLCERT(3), CURLOPT_PROXY_SSLKEY(3), CURLOPT_SSLKEYTYPE(3)
