CURLOPT_PROXY_ISSUERCERT(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_ISSUERCERT(3) Manual de funciones de la biblioteca CURLOPT_PROXY_ISSUERCERT(3)

NOMBRE

CURLOPT_PROXY_ISSUERCERT - nombre de archivo del certificado SSL del emisor del proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_ISSUERCERT, char *file);

DESCRIPCIÓN

Pasa un puntero a `char` a una cadena terminada en nulo que nombra un archivo que contiene un certificado CA en formato PEM. Si la opción está establecida, se realiza una verificación adicional contra el certificado del par para verificar que el emisor del proxy HTTPS es de hecho el asociado con el certificado proporcionado por la opción. Esta verificación adicional es útil en PKI de varios niveles donde es necesario aplicar que el certificado del par sea de una rama específica del árbol.

Esta opción solo tiene sentido cuando se usa en combinación con la opción CURLOPT_PROXY_SSL_VERIFYPEER(3). De lo contrario, el resultado de la verificación no se considera un fallo.

Se define un código de error específico (CURLE_SSL_ISSUER_ERROR) con la opción, que se devuelve si la configuración de la sesión SSL/TLS ha fallado debido a una discrepancia con el emisor del certificado del par (se debe establecer CURLOPT_PROXY_SSL_VERIFYPEER(3) también para que la verificación falle).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para deshabilitar su uso nuevamente.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS y OpenSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* usando un proxy HTTPS */
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:443");
    curl_easy_setopt(curl, CURLOPT_PROXY_ISSUERCERT, "/etc/certs/cacert.pem");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.71.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un `CURLcode` que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
