curl_mime_type(3)

Paquete: curl

Licencias: MIT

curl_mime_type(3) Manual de funciones de la biblioteca curl_mime_type(3)

NOMBRE

curl_mime_type - establecer el tipo de contenido de una parte mime

SINOPSIS

#include <curl/curl.h>
CURLcode curl_mime_type(curl_mimepart *part, const char *mimetype);

DESCRIPCIÓN

curl_mime_type(3) establece el tipo de contenido de una parte mime.

part es el manejador de la parte al que se le asignará el tipo de contenido.

mimetype apunta a la cadena de tipo mime de archivo terminada en nulo; puede establecerse en NULL para eliminar un tipo mime previamente adjunto.

La cadena de tipo mime se copia en la parte, por lo tanto, el almacenamiento asociado puede liberarse o reutilizarse de forma segura después de la llamada. Establecer el tipo de una parte varias veces es válido: solo se conserva el valor establecido por la última llamada.

En ausencia de un tipo mime y si las especificaciones del protocolo lo requieren, se determina un tipo mime predeterminado según el contexto:

- Si se establece como una cabecera personalizada, use este valor.

- application/form-data para una publicación de formulario HTTP.

- Si se establece un nombre de archivo remoto, el tipo mime se toma de la extensión del nombre de archivo, o application/octet-stream por defecto.

- Para una parte multipart, multipart/mixed.

- text/plain en otros casos.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* crear un manejador mime */
    mime = curl_mime_init(curl);
    /* añadir una parte */
    part = curl_mime_addpart(mime);
    /* obtener datos de este archivo */
    curl_mime_filedata(part, "image.png");
    /* tipo de contenido para esta parte */
    curl_mime_type(part, "image/png");
    /* establecer nombre */
    curl_mime_name(part, "image");
}
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error; consulte libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el búfer de errores cuando se devuelve un valor distinto de cero.
