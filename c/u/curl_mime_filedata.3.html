NOMBRE

curl_mime_filedata - establece el cuerpo de una parte mime a partir del contenido de un archivo

SINOPSIS

#include <curl/curl.h>
CURLcode curl_mime_filedata(curl_mimepart *part,
                            const char *filename);

DESCRIPCIÓN

curl_mime_filedata(3) establece el contenido del cuerpo de una parte mime a partir del contenido del archivo nombrado. Esta es una alternativa a curl_mime_data(3) para establecer datos a una parte mime.

part es la parte a la que se asignarán los contenidos.

filename apunta al nombre del archivo terminado en nulo. El puntero puede ser NULL para desvincular la configuración previa de los contenidos de la parte. El almacenamiento del nombre de archivo puede ser reutilizado de forma segura después de esta llamada.

Como efecto secundario, el nombre de archivo remoto de la parte se establece al nombre base del filename dado si es un nombre de archivo válido. Esto puede ser deshecho o anulado por una llamada posterior a curl_mime_filename(3).

El contenido del archivo se lee durante la transferencia de archivos de manera continua para permitir la transferencia de archivos enormes sin usar mucha memoria. Por lo tanto, requiere que el archivo se mantenga intacto durante toda la solicitud.

Si el tamaño del archivo no se puede determinar antes de leerlo (como en un dispositivo de caracteres o una tubería con nombre), toda la estructura mime que contiene la parte se transfiere usando fragmentos por HTTP, pero es rechazada por IMAP.

Establecer los contenidos de una parte varias veces es válido: solo el valor establecido por la última llamada se conserva.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* crear un manejador mime */
    mime = curl_mime_init(curl);
    /* añadir una parte */
    part = curl_mime_addpart(mime);
    /* enviar datos de este archivo */
    curl_mime_filedata(part, "image.png");
    /* establecer el nombre */
    curl_mime_name(part, "data");
  }
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3) puede haber un mensaje de error almacenado en el búfer de error cuando se devuelve un valor distinto de cero.

CURLE_READ_ERROR es solo una indicación de que el archivo aún no es legible: se puede ignorar de forma segura en este momento, pero el archivo debe hacerse legible antes de que se realice el manejo de la parte correspondiente.
