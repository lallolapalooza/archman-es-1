CURLOPT_COPYPOSTFIELDS(3)

Paquete: curl

Licencias: MIT

CURLOPT_COPYPOSTFIELDS(3) Manual de funciones de la biblioteca CURLOPT_COPYPOSTFIELDS(3)

NOMBRE

CURLOPT_COPYPOSTFIELDS - hacer que libcurl copie los datos para POST

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_COPYPOSTFIELDS, char *data);

DESCRIPCIÓN

Pase un puntero a char como parámetro, que debe ser los datos completos para enviar en una operación POST HTTP. Se comporta como la opción CURLOPT_POSTFIELDS(3), pero la biblioteca copia los datos originales en su lugar, permitiendo a la aplicación sobrescribir los datos originales después de establecer esta opción.

Debido a que los datos se copian, se debe tener cuidado al usar esta opción junto con CURLOPT_POSTFIELDSIZE(3) o CURLOPT_POSTFIELDSIZE_LARGE(3). Si el tamaño no se ha establecido antes de CURLOPT_COPYPOSTFIELDS(3), se asume que los datos son una cadena terminada en nulo; de lo contrario, el tamaño almacenado informa a la biblioteca sobre el número de bytes a copiar. En cualquier caso, el tamaño no debe cambiarse después de CURLOPT_COPYPOSTFIELDS(3), a menos que se establezca otra opción CURLOPT_POSTFIELDS(3) o CURLOPT_COPYPOSTFIELDS(3).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida reemplace las anteriores. Establézcala a NULL para deshabilitar su uso de nuevo.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a http, mqtt y rtsp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    char local_buffer[1024]="data to send";
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* tamaño de los datos a copiar del búfer y enviar en la solicitud */
    curl_easy_setopt(curl, CURLOPT_POSTFIELDSIZE, 12L);
    /* enviar datos desde la pila local */
    curl_easy_setopt(curl, CURLOPT_COPYPOSTFIELDS, local_buffer);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.17.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
