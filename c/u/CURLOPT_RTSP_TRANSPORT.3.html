CURLOPT_RTSP_TRANSPORT(3)

Paquete: curl

Licencias: MIT

CURLOPT_RTSP_TRANSPORT(3) Manual de funciones de la biblioteca CURLOPT_RTSP_TRANSPORT(3)

NOMBRE

CURLOPT_RTSP_TRANSPORT(3) — Cabecera de transporte RTSP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RTSP_TRANSPORT,
                          char *transport);

DESCRIPCIÓN

Pasa un puntero a char para indicar a libcurl qué pasar para la cabecera Transport: para esta sesión RTSP. Este es principalmente un método de conveniencia para evitar la necesidad de establecer una cabecera Transport: personalizada para cada solicitud SETUP. La aplicación debe establecer una cabecera Transport: antes de emitir una solicitud SETUP.

La aplicación no tiene que mantener la cadena de caracteres disponible después de establecer esta opción.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a rtsp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "rtsp://example.com/");
    curl_easy_setopt(curl, CURLOPT_RTSP_REQUEST, CURL_RTSPREQ_SETUP);
    curl_easy_setopt(curl, CURLOPT_RTSP_TRANSPORT,
                     "RTP/AVP;unicast;client_port=4588-4589");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Los enums CURL_RTSPREQ_* se convirtieron en tipos long en la versión 8.13.0; antes de esta versión, era necesario un cast a long al pasarlos a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.20.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien; cualquier valor distinto de cero indica un error; ver libcurl-errors(3).

VER TAMBIÉN
