CURLINFO_EFFECTIVE_URL(3)

Paquete: curl

Licencias: MIT

CURLINFO_EFFECTIVE_URL(3) Manual de funciones de biblioteca CURLINFO_EFFECTIVE_URL(3)

NOMBRE

CURLINFO_EFFECTIVE_URL - obtener la última URL utilizada

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_EFFECTIVE_URL, char **urlp);

DESCRIPCIÓN

Pase un puntero a un puntero a char y obtenga la URL efectiva utilizada por última vez.

En los casos en que haya solicitado a libcurl que siga redirecciones, puede que no sea el mismo valor que estableció con CURLOPT_URL(3).

El puntero urlp es NULL o apunta a memoria privada. Usted no debe liberarlo. La memoria se libera automáticamente cuando llama a curl_easy_cleanup(3) en el manejador de curl correspondiente.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      char *url = NULL;
      curl_easy_getinfo(curl, CURLINFO_EFFECTIVE_URL, &url);
      if(url)
        printf("Redirect to: %s\n", url);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.4

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_FOLLOWLOCATION(3), curl_easy_getinfo(3), curl_easy_setopt(3)
