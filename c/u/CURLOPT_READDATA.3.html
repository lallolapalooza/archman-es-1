CURLOPT_READDATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_READDATA(3) Manual de funciones de biblioteca CURLOPT_READDATA(3)

NOMBRE

CURLOPT_READDATA - puntero pasado a la devolución de llamada de lectura

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_READDATA, void *pointer);

DESCRIPCIÓN

Datos pointer para pasar a la función de lectura de archivos. Si utiliza la opción CURLOPT_READFUNCTION(3), este es el puntero que recibe como entrada en el cuarto argumento de la función de devolución de llamada.

Si no especifica una función de devolución de llamada de lectura, sino que confía en la función de lectura interna predeterminada, estos datos deben ser un FILE * legible válido (convertido a 'void *').

Si está utilizando libcurl como una DLL en Windows, debe usar la función de devolución de llamada CURLOPT_READFUNCTION(3) si establece esta opción, de lo contrario, podría experimentar bloqueos.

PREDETERMINADO

stdin

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

struct MyData {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  struct MyData this;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* pasar el puntero que se pasa a la función de devolución
       de llamada CURLOPT_READFUNCTION */
    curl_easy_setopt(curl, CURLOPT_READDATA, &this);
    curl_easy_perform(curl);
  }
}

HISTORIA

Esta opción se conocía anteriormente por el nombre más antiguo CURLOPT_INFILE; el nombre CURLOPT_READDATA(3) se introdujo en la versión 7.9.7.

DISPONIBILIDAD

Añadido en curl 7.9.7

VALOR DE RETORNO

Esto devuelve CURLE_OK.

VER TAMBIÉN

CURLOPT_HEADERDATA(3), CURLOPT_READFUNCTION(3), CURLOPT_WRITEDATA(3), CURLOPT_WRITEFUNCTION(3)
