CURLINFO_SIZE_UPLOAD(3)

Paquete: curl

Licencias: MIT

CURLINFO_SIZE_UPLOAD(3) Manual de funciones de biblioteca CURLINFO_SIZE_UPLOAD(3)

NOMBRE

CURLINFO_SIZE_UPLOAD - obtener el número de bytes subidos

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_SIZE_UPLOAD,
                           double *uploadp);

DESCRIPCIÓN

Pase un puntero a un double para recibir la cantidad total de bytes que fueron subidos.

CURLINFO_SIZE_UPLOAD_T(3) es un reemplazo más nuevo que devuelve un tipo de variable más sensato.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Realizar la solicitud */
    res = curl_easy_perform(curl);
    if(!res) {
      double ul;
      res = curl_easy_getinfo(curl, CURLINFO_SIZE_UPLOAD, &ul);
      if(!res) {
        printf("Se subieron %.0f bytes\n", ul);
      }
    }
  }
}

OBSOLETO

Obsoleto desde la versión 7.55.0.

DISPONIBILIDAD

Añadido en curl 7.4.1

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLINFO_SIZE_DOWNLOAD_T(3), CURLINFO_SIZE_UPLOAD_T(3), curl_easy_getinfo(3), curl_easy_setopt(3)
