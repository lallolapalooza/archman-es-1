CURLINFO_LOCAL_PORT(3)

Paquete: curl

Licencias: MIT

CURLINFO_LOCAL_PORT(3) Manual de funciones de biblioteca CURLINFO_LOCAL_PORT(3)

NOMBRE

CURLINFO_LOCAL_PORT - obtener el último número de puerto local

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_LOCAL_PORT, long *portp);

DESCRIPCIÓN

Pase un puntero a un long para recibir el número de puerto local de la conexión más reciente realizada con este manejador de curl.

Si la conexión se realizó usando QUIC, el número de puerto es un número de puerto UDP; de lo contrario, es un número de puerto TCP.

PROTOCOLOS

Esta funcionalidad afecta a quic y tcp.

EJEMPLO

int main(void)
{
  CURL *curl;
  CURLcode res;
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      long port;
      res = curl_easy_getinfo(curl, CURLINFO_LOCAL_PORT, &port);
      if(CURLE_OK == res) {
        printf("Usamos el puerto local: %ld\n", port);
      }
    }
    curl_easy_cleanup(curl);
  }
  return 0;
}

DISPONIBILIDAD

Añadido en curl 7.21.0.

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien; un valor distinto de cero indica que ocurrió un error. Consulte libcurl-errors(3).

VER TAMBIÉN
