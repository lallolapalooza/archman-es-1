CURLMOPT_NOTIFYDATA(3)

Paquete: curl

Licencias: MIT

CURLMOPT_NOTIFYDATA(3) Manual de funciones de biblioteca CURLMOPT_NOTIFYDATA(3)

NOMBRE

CURLMOPT_NOTIFYDATA - puntero personalizado pasado a la función de notificación

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_NOTIFYDATA, void *pointer);

DESCRIPCIÓN

Un puntero de datos para pasar a la función de notificación establecida con la opción CURLMOPT_NOTIFYFUNCTION(3).

Este puntero no es modificado por libcurl, sino que solo se pasa como el argumento clientp de la función de notificación.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados.

EJEMPLO

struct priv {
  void *ours;
};
static void notify_cb(CURLM *multi, unsigned int notification,
                      CURL *easy, void *notifyp)
{
  struct priv *p = notifyp;
  printf("mi puntero: %p\n", p->ours);
  /* ... */
}
int main(void)
{
  struct priv setup;
  CURLM *multi = curl_multi_init();
  /* ... usar callback de socket y puntero personalizado */
  curl_multi_setopt(multi, CURLMOPT_NOTIFYFUNCTION, notify_cb);
  curl_multi_setopt(multi, CURLMOPT_NOTIFYDATA, &setup);
  curl_multi_notify_enable(multi, CURLMNOTIFY_INFO_READ);
}

DISPONIBILIDAD

Añadido en curl 8.17.0

VALOR DE RETORNO

Devuelve CURLM_OK.

VER TAMBIÉN

CURLMOPT_NOTIFYFUNCTION(3), curl_multi_notify_disable(3), curl_multi_notify_enable(3)
