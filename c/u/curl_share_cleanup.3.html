curl_share_cleanup(3)

Paquete: curl

Licencias: MIT

curl_share_cleanup(3) Manual de funciones de la biblioteca curl_share_cleanup(3)

NOMBRE

curl_share_cleanup - cerrar un objeto compartido

SINOPSIS

#include <curl/curl.h>
CURLSHcode curl_share_cleanup(CURLSH *share_handle);

DESCRIPCIÓN

Esta función elimina un objeto compartido. El manejador de uso compartido ya no se puede utilizar una vez que se haya llamado a esta función.

Pasar un puntero NULL en share_handle hace que esta función regrese inmediatamente sin ninguna acción.

Cualquier uso de share_handle después de que esta función haya sido llamada y haya regresado, es ilegal.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_SHARE, CURL_LOCK_DATA_CONNECT);
  /* usar el share, luego... */
  curl_share_cleanup(share);
}

DISPONIBILIDAD

Añadido en curl 7.10

VALOR DE RETORNO

CURLSHE_OK (cero) significa que la opción se estableció correctamente, un valor distinto de cero significa que ocurrió un error, según lo define <curl/curl.h>. Consulte la página del manual de libcurl-errors(3) para ver la lista completa con descripciones. Si ocurre un error, el objeto compartido no se elimina.

VER TAMBIÉN

curl_share_init(3), curl_share_setopt(3)
