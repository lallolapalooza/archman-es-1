CURLOPT_FTP_USE_EPRT(3)

Paquete: curl

Licencias: MIT

CURLOPT_FTP_USE_EPRT(3) Manual de funciones de biblioteca CURLOPT_FTP_USE_EPRT(3)

NOMBRE

CURLOPT_FTP_USE_EPRT - usar EPRT para FTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_USE_EPRT, long enabled);

DESCRIPCIÓN

Pasa un `long`. Si el valor es 1, le indica a curl que use el comando EPRT al realizar descargas FTP activas (lo cual está habilitado por CURLOPT_FTPPORT(3)). Usar EPRT significa que libcurl primero intenta usar EPRT antes de usar PORT, pero si pasas cero a esta opción, evita usar EPRT, solo usa PORT simple.

El comando EPRT es una adición un poco más reciente al protocolo FTP que PORT y es el comando preferido a usar ya que permite el uso de IPv6. Los servidores FTP antiguos podrían no soportarlo, razón por la cual libcurl tiene un mecanismo de respaldo. A veces ese respaldo no es suficiente y entonces esta opción puede ser útil.

Si el servidor es un host IPv6, esta opción no tiene efecto ya que EPRT es necesario entonces.

POR DEFECTO

PROTOCOLOS

Esta funcionalidad afecta solo a ftp.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/file.txt");
    /* contactar de vuelta, también conocido como FTP "activo" */
    curl_easy_setopt(curl, CURLOPT_FTPPORT, "-");
    /* FTP como lo hacían los neandertales */
    curl_easy_setopt(curl, CURLOPT_FTP_USE_EPRT, 0L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.10.5.

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un `CURLcode` que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
