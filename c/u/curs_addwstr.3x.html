curs_addwstr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_addwstr(3X) Llamadas a biblioteca curs_addwstr(3X)

NOMBRE

addwstr, addnwstr, waddwstr, waddnwstr, mvaddwstr, mvaddnwstr, mvwaddwstr, mvwaddnwstr - añadir una cadena de caracteres anchos a una ventana de curses y avanzar el cursor

SINOPSIS

#include <curses.h>
int addwstr(const wchar_t *wstr);
int mvaddwstr(int y, int x, const wchar_t *wstr);
int mvwaddwstr(WINDOW *win, int y, int x, const wchar_t *wstr);
int waddwstr(WINDOW *win, const wchar_t *wstr);
int addnwstr(const wchar_t *wstr, int n);
int mvaddnwstr(int y, int x, const wchar_t *wstr, int n);
int mvwaddnwstr(WINDOW *win, int y, int x, const wchar_t *wstr, int n);
int waddnwstr(WINDOW *win, const wchar_t *wstr, int n);

DESCRIPCIÓN

waddwstr escribe los caracteres de la cadena de caracteres anchos wstr (terminada en nulo ancho) en la ventana win. Su proceso es similar a la construcción de un cchar_t para cada wchar_t en wstr, luego llamar a wadd_wch(3X) con el cchar_t resultante.

  • Los caracteres de espaciado y no espaciado en la cadena se procesan uno a la vez, y
  • los caracteres de control se procesan como en wadd_wch(3X).

waddnwstr escribe como máximo n caracteres anchos, o hasta que ocurra un carácter nulo ancho terminador en wstr. Si n es -1, waddnwstr escribe la cadena ancha completa.

ncurses(3X) describe las variantes de estas funciones.

VALOR DE RETORNO

Estas funciones devuelven OK en caso de éxito y ERR en caso de fallo.

X/Open Curses no especifica ninguna condición de error. ncurses devuelve un error

  • si el puntero de la ventana es NULL,
  • si el puntero de la cadena es NULL, o
  • si una llamada interna a wadd_wch(3X) devuelve un error.

Las funciones prefijadas con “mv” primero realizan el movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Todas estas funciones excepto waddnwstr pueden implementarse como macros.

PORTABILIDAD

X/Open Curses, Issue 4 describe estas funciones.

VER TAMBIÉN

curs_addstr(3X) describe funciones comparables de la biblioteca ncurses en su configuración sin caracteres anchos.
