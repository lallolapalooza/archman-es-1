NOMBRE

cueconvert - convertir archivos entre formatos CUE y TOC

SINOPSIS

cueconvert [ -i formato | --input-format=formato ] [ -o formato | --output-format=formato ] [ archivo_entrada [ archivo_salida ] ]
cueconvert -h | --help
cueconvert -V | --version

DESCRIPCIÓN

cueconvert convierte archivos entre los formatos CUE y TOC, cada uno de los cuales es comúnmente utilizado por el software de ripeo de discos compactos para indicar puntos de quiebre de pista y otros datos.

Los operandos son opcionales; si no se especifica archivo_entrada, cueconvert lee de la entrada estándar, y si no se especifica archivo_salida, escribe en la salida estándar.

Si no se especifican nombres de archivo, se utiliza la entrada estándar y se debe especificar una opción de formato de entrada. Se utiliza el formato complementario para la salida.

Si se proporcionan nombres de archivo, pero no se especifican opciones de formato, los formatos de entrada y salida se adivinarán en base a la extensión de cada nombre de archivo (por ejemplo, .cue o .toc). Esta heurística no distingue entre mayúsculas y minúsculas.

OPCIONES

-h, --help
muestra un mensaje de uso y sale.
-i formato, --input-format=formato
establece el formato esperado del archivo de entrada a formato.
-o formato, --output-format=formato
establece el formato del archivo de salida generado a formato.
-V , --version
muestra la información de la versión y sale.

El argumento de opción formato debe ser cue o toc.

ESTADO DE SALIDA

cueconvert sale con el estado cero si convierte con éxito el archivo de entrada, y con un valor distinto de cero si hubo problemas.
