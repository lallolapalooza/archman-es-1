CURLINFO_FTP_ENTRY_PATH(3)

Paquete: curl

Licencias: MIT

CURLINFO_FTP_ENTRY_PATH(3) Manual de Funciones de Biblioteca CURLINFO_FTP_ENTRY_PATH(3)

NOMBRE

CURLINFO_FTP_ENTRY_PATH - obtener la ruta de entrada en el servidor FTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_FTP_ENTRY_PATH, char **path);

DESCRIPCIÓN

Pase un puntero a un puntero de carácter para recibir un puntero a una cadena que contiene la ruta de la ruta de entrada. Esta es la ruta inicial en la que libcurl terminó al iniciar sesión en el servidor FTP o SFTP remoto. Esto almacena un NULL como puntero si algo sale mal.

El puntero path es NULL o apunta a memoria privada. Usted no debe liberarlo. La memoria se libera automáticamente cuando llama a curl_easy_cleanup(3) en el descriptor de curl correspondiente.

PROTOCOLOS

Esta funcionalidad afecta a ftp y sftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com");
    res = curl_easy_perform(curl);
    if(!res) {
      /* extraer la ruta de entrada */
      char *ep = NULL;
      res = curl_easy_getinfo(curl, CURLINFO_FTP_ENTRY_PATH, &ep);
      if(!res && ep) {
        printf("La ruta de entrada fue: %s\n", ep);
      }
    }
    curl_easy_cleanup(curl);
  }
}

HISTORIA

Funciona para SFTP desde la versión 7.21.4

DISPONIBILIDAD

Agregado en curl 7.15.4

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

curl_easy_getinfo(3), curl_easy_setopt(3)
