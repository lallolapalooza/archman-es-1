CURLOPT_SERVICE_NAME(3)

Paquete: curl

Licencias: MIT

CURLOPT_SERVICE_NAME(3) Manual de funciones de la biblioteca CURLOPT_SERVICE_NAME(3)

NOMBRE

CURLOPT_SERVICE_NAME - nombre del servicio de autenticación

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SERVICE_NAME, char *nombre);

DESCRIPCIÓN

Pase un puntero a `char` como parámetro a una cadena que contenga el nombre del servicio para los mecanismos de autenticación DIGEST-MD5, SPNEGO y Kerberos 5. Los nombres de servicio predeterminados son "ftp", "HTTP", "imap", "ldap", "pop" y "smtp". Esta opción le permite cambiarlos.

La aplicación no tiene que mantener la cadena disponible después de configurar esta opción.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Configúrela a NULL para desactivar su uso de nuevo.

POR DEFECTO

Ver arriba

PROTOCOLOS

Esta funcionalidad afecta a ftp, http, imap, ldap, pop3 y smtp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SERVICE_NAME, "personalizado");
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.43.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
