CURLOPT_RESUME_FROM_LARGE(3)

Paquete: curl

Licencias: MIT

CURLOPT_RESUME_FROM_LARGE(3) Manual de funciones de la biblioteca CURLOPT_RESUME_FROM_LARGE(3)

NOMBRE

CURLOPT_RESUME_FROM_LARGE - desplazamiento para reanudar la transferencia

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RESUME_FROM_LARGE,
                          curl_off_t from);

DESCRIPCIÓN

Pase un curl_off_t como parámetro. Contiene el desplazamiento en número de bytes desde el cual desea que comience la transferencia. Establezca esta opción a 0 para que la transferencia comience desde el principio (desactivando efectivamente la reanudación). Para FTP, establezca esta opción a -1 para que la transferencia comience desde el final del archivo de destino (útil para continuar una carga interrumpida).

Al realizar cargas con FTP, la posición de reanudación es desde dónde en el archivo local/fuente libcurl intentará reanudar la carga y añadirá el archivo fuente al archivo de destino remoto.

PREDETERMINADO

0, no utilizado

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_off_t resume_position = 1234; /* obtenerlo de alguna manera */
    curl_off_t file_size = 9876; /* obtenerlo también de alguna manera */
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com");
    /* reanudar la carga en esta posición, posiblemente más allá de 2 GB */
    curl_easy_setopt(curl, CURLOPT_RESUME_FROM_LARGE, resume_position);
    /* solicitar carga */
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    /* establecer la cantidad total de datos a esperar */
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, file_size);
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.11.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
