DESCRIPCIÓ

N

"Curses" es la interfaz entre Perl y la biblioteca curses(3) de su sistema. Para descripciones sobre el uso de una función, variable o constante determinada, consulte la documentación de su sistema, ya que dicha información varía invariablemente (:-) entre diferentes bibliotecas curses(3) y sistemas operativos. Este documento describe la propia interfaz, y asume que ya sabe cómo funciona la biblioteca curses(3) de su

sistema.

Funciones

unificadas

Muchas funciones curses(3) tienen variantes que comienzan con los prefijos w-, mv- y/o wmv-. Estas variantes difieren solo en la adición explícita de una ventana, o por la adición de dos coordenadas que se usan para mover el cursor primero. Por ejemplo, addch() tiene otras tres variantes: waddch(), mvaddch() y mvwaddch(). Las variantes no son muy interesantes; de hecho, podríamos unir todas las variantes en la función original permitiendo un número variable de argumentos y analizando la lista de argumentos para saber qué variante quería llamar el

usuario.

Desafortunadamente, curses(3) es anterior a varargs(3), así que en C estábamos atados con todas las variantes. Sin embargo, "Curses" es una interfaz de Perl, así que somos libres de "unificar" estas variantes en una sola función. La sección "Funciones disponibles" a continuación lista todas las funciones curses(3) que "Curses" pone disponibles como equivalentes de Perl, junto con una columna que indica si está unificada. Si es así, toma un número variable de argumentos de la siguiente

manera:
"función( [win], [y, x], args );"

win es un argumento de ventana opcional, que por defecto es "stdscr" si no se

especifica.

y, x es un par de coordenadas opcional usado para mover el cursor, que por defecto no se mueve si no se

especifica.

args son los argumentos requeridos de la función. Estos son los argumentos que esp

ecificaría si estuviera llamando a la funció
n base y no a ninguna de las variantes.

Esto hace que las variantes queden obsoletas, ya que su funcionalidad ha sido fusionada en una sola función, así que "Curses" no las define por defecto. Aún puede obtenerlas si lo desea, estableciendo la variable $Curses::OldCurses a un valor distinto de cero antes de usar el paquete "Curses". Vea "Compatibilidad con "cursperl" de Perl 4.X" pa

ra un eje
mplo de esto.

Funciones conscientes de caracteres de ancho completo (Wide-Character-Awar

e)

Las siguientes son las funciones preferidas para trabajar con cadenas, aunque no siguen la convención de nomenclatura de funciones unificadas normal (basada en los nombres de la biblioteca Curses) descrita arriba. A pesar de la nomenclatura, cada una corresponde a una función de la biblioteca Curses. Por ejemplo, una llamada a "getchar" realiza una función de la biblioteca Curses en la familia "getch"

.

Además de estas funciones, el módulo "Curses" contiene funciones correspondientes con la nomenclatura convencional (por ejemplo, "getch"); la duplicación es por razones históricas. Las funciones preferidas eran nuevas en Curses 1.29 (abril de 2014). Usan las funciones de caracteres de ancho completo en la biblioteca Curses si están disponibles (recayendo en el uso de las versiones tradicionales no de ancho completo). También tienen una interfaz más parecida a Perl, atendiendo algunos detalles escabrosos bajo el capó de los que un programador de Perl no debería tener que

preocuparse.

La razón de tener dos conjuntos de funciones de manejo de cadenas es histórica. El módulo Perl Curses original es anterior a las bibliotecas Curses que entienden codificaciones de caracteres de múltiples bytes. Además, el módulo fue diseñado para tener una interfaz de Perl que se asemeja estrechamente a la interfaz de C y que pasa directamente la representación interna de bytes de las cadenas de Perl al código C. Esto probablemente estaba bien antes de que Perl tuviera funciones Unicode, pero hoy, Perl almacena cadenas internamente en Latin-1 o Unicode UTF-8 y el módulo original no era sensible a qué codificación se

usaba.

Aunque la mayoría de los problemas podían evitarse en el código Perl usando la interfaz tradicional, es difícil hacerlo bien y necesita una biblioteca curses consciente de caracteres de ancho completo (por ejemplo, ncursesw) de todos modos para que funcione correctamente. Debido a que los consumidores existentes del módulo Curses pueden estar confiando en el comportamiento tradicional, los diseñadores del módulo Curses no pudieron simplemente modificar las funciones existentes para que entendieran caracteres de ancho completo y convirtieran de y a cadenas de

Perl.

Ninguna de estas funciones existe si Perl es anterior a 5.

6.

"getchar"

Esto llama a wget_wch(). Devuelve un carácter -- más precisamente, una cadena de un carácter (¡no necesariamente de un byte!) que contiene el carácter -- para una tecla normal y una lista de dos elementos "(undef, número-de-tecla)" para una tecla de función. Devuelve "undef" en caso de

error.

Si no espera teclas de función (es decir, con "keypad(0))", simplemente puede

hacer 
my $ch = getchar;
die "getchar failed" unless defined
$ch;

Si sí espera teclas de función (es decir, con keypad(1)), aún puede asignar el resultado a una variable escalar como arriba. Debido a la forma en que funciona el operador coma, esa variable recibirá o bien "undef" o la cadena o el número, y puede decodificarlo usted

mismo. 
my $ch = getchar;
die "getchar failed" unless defined $ch;
if (<$ch looks like a number >= 0x100>) {
        <handle function key>
} else {
        <handle normal key>
}

o

hacer 
my ($ch, $key) = getchar;
if (defined $key) {
        <handle function key $key>
} else if (defined $ch) {
        <handle normal key $ch>
} else {
        die "getchar failed";
}

Si wget_wch() no está disponible (es decir, la biblioteca Curses no entiende caracteres de ancho completo), esto llama a wgetch(), pero devuelve los valores descritos arriba de todos modos. Esto puede ser un problema porque con una codificación de caracteres de múltiples bytes como UTF-8, recibirá dos cadenas de un carácter para un carácter de dos bytes (por ejemplo, "ï¿½ï¿½ï¿½ï¿½" y "â�½" para "â�½"). Si agrega estos caracteres a una cadena de Perl, esa cadena puede contener internamente una codificación UTF-8 válida de un carácter, pero Perl no lo interpretará de esa manera. Perl incluso puede intentar convertir lo que cree que son dos caracteres a UTF-8, dándole cuatro

bytes.

"getstring"

Esto llama a "wgetn_wstr" y devuelve una cadena o "undef". No puede devolver un valor de tecla de función; la biblioteca Curses interpretará por sí misma KEY_LEFT y

KEY_BACKSPACE.

Si wgett_wstr() no está disponible, esto llama a wgetstr

().

En ambos casos, la función asigna un búfer de tamaño fijo para contener el resultado de la llamada a la biblioteca

Curses. 
my $s = getstring();
die "getstring failed" unless defined
$s;

"addstring"/"insstring"

Esto agrega/inserta la cadena de Perl pasada como argumento a la ventana de Curses usando waddnwstr()/wins_nwstr() o, si no está disponible, waddnstr()/winsnstr(). Devuelve un valor verdadero en caso de éxito, falso en caso de

fallo. 
addstring("Hâ�½llâ�¡, Wâ�¡rld") || die "addstring
failed";

"instring"

Esto devuelve una cadena de Perl (o "undef" en caso de fallo) que contiene los caracteres desde la posición actual del cursor hasta el final de la línea. Utiliza winnwstr() si está disponible, y de lo contrario innstr

(). 
my $s = instring();
die "instring failed" unless defined
$s;

"ungetchar"

Esto empuja un carácter (pasado como una cadena de Perl de un carácter) de vuelta a la cola de entrada. Utiliza unget_wch() o ungetch(). Devuelve un valor verdadero en caso de éxito, falso en caso de fallo. No se puede empujar de vuelta una tecla de función; la biblioteca Curses no proporciona ninguna forma de empujar de vuelta teclas de función, solo

caracteres. 
ungetchar("X") or die "ungetchar
failed";

El módulo "Curses" no proporciona ninguna interfaz para las rutinas de caracteres complejos (wadd_wch(), wadd_wchnstr(), wecho_wchar(), win_wch(), win_wchnstr(), wins_wch()) porque no hay una forma razonable de convertir de Perl a un C "cchar_t" o

vice
versa.

COMPATIBILIDA

D

Compatibilidad con "cursperl" de Perl 4.

X

"Curses" fue escrito para aprovechar características de Perl 5 y posteriores. El autor pensó que era mejor proporcionar un entorno de programación curses mejorado que ser 100% compatible. Sin embargo, muchas aplicaciones antiguas "curseperl" probablemente seguirán funcionando iniciando el script

con: 
BEGIN { $Curses::OldCurses = 1; }
use
Curses;

Cualquier aplicación antigua que todavía no funcione debería imprimir un mensaje de error comprensible explicando el

problema.

Algunas funciones y variables no están disponibles a través de "Curses", incluso con la línea "BEGIN". Están listadas bajo "Elementos de Curses no disponibles a través de Perl

Curses".

Las variables $stdscr y $curscr también están disponibles como funciones "stdscr" y "curscr". Esto se debe a un error de Perl. V

éase la sección LIMITAC
IONES para más detalles.

Incompatibilidades con versiones anteriores de

"Curses"

En versiones anteriores de este software, algunas funciones de Perl tomaban un conjunto diferente de parámetros que sus homólogas en C. Esto no es cierto en la versión actual. Ahora debería usar getstr($str) y "getyx($y, $x)" en lugar de "$str = getstr()" y "($y, $x

) = g

LIMITACIONE

S

Si usa las variables $stdscr y $curscr en lugar de sus homólogas funcionales ("stdscr" y "curscr"), podría encontrarse con un error en Perl donde la "magia" no se llama lo suficientemente pronto. Esto se manifiesta por el paquete "Curses" diciéndole que $stdscr no es una ventana. Una solución es poner una línea como "$stdscr = $stdscr" cerca del

principio
de su programa.
