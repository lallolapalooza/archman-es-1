curs_ins_wstr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_ins_wstr(3X) Llamadas a la biblioteca curs_ins_wstr(3X)

NOMBRE

ins_wstr, ins_nwstr, wins_wstr, wins_nwstr, mvins_wstr, mvins_nwstr, mvwins_wstr, mvwins_nwstr - insertar una cadena de caracteres anchos en una ventana de curses

SINOPSIS

#include <curses.h>
int ins_wstr(const wchar_t *wstr);
int ins_nwstr(const wchar_t *wstr, int n);
int wins_wstr(WINDOW *win, const wchar_t *wstr);
int wins_nwstr(WINDOW *win, const wchar_t *wstr, int n);
int mvins_wstr(int y, int x, const wchar_t *wstr);
int mvins_nwstr(int y, int x, const wchar_t *wstr, int n);
int mvwins_wstr(WINDOW *win, int y, int x, const wchar_t *wstr);
int mvwins_nwstr(WINDOW *win, int y, int x, const wchar_t *wstr, int n);

DESCRIPCIÓN

Estas rutinas insertan una cadena de caracteres wchar_t (tantos caracteres como quepan en la línea) antes del carácter bajo el cursor, como si se llamara a wins_wch(3X). Todos los caracteres a la derecha del cursor se desplazan hacia la derecha, con la posibilidad de que los caracteres más a la derecha de la línea se pierdan. No se realiza ajuste de línea.

La posición del cursor no cambia (después de moverse a y, x, si se especifica).

Las funciones con n como argumento final insertan una subcadena inicial de como máximo n caracteres wchar_t. Si n es menor que cero, se inserta la cadena completa (deteniéndose en un carácter L'\0').

Los caracteres especiales se manejan como en wadd_wch(3X).

VALOR DE RETORNO

Todas las funciones devuelven el entero ERR en caso de fallo y OK en caso de éxito.

X/Open Curses no especifica ninguna condición de error. Esta implementación devuelve un error

  • si el parámetro win es nulo o
  • si el parámetro wstr es nulo o
  • si la función wins_wch devuelve un error.

Las funciones prefijadas con "mv" primero realizan el movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Todas excepto wins_nwstr pueden ser macros.

Si el primer carácter de la cadena es un carácter no espaciador, estas funciones fallarán. X/Open Curses no define qué sucederá si un carácter no espaciador sigue a un carácter de control.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4, que añade calificadores const a los argumentos.

X/Open afirma que se inserta la cadena completa si n es menor que 1. Esto es probablemente un error, porque es inconsistente con otras funciones y difiere de la implementación de X/Open en Solaris.

VER TAMBIÉN

curs_insstr(3X) describe funciones comparables de la biblioteca ncurses en su configuración sin caracteres anchos.
