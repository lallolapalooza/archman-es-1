CURLOPT_XFERINFOFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_XFERINFOFUNCTION(3) Manual de funciones de la biblioteca CURLOPT_XFERINFOFUNCTION(3)

NOMBRE

CURLOPT_XFERINFOFUNCTION - función de devolución de llamada de medidor de progreso

SINOPSIS

#include <curl/curl.h>
int progress_callback(void *clientp,
                      curl_off_t dltotal,
                      curl_off_t dlnow,
                      curl_off_t ultotal,
                      curl_off_t ulnow);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_XFERINFOFUNCTION,
                          progress_callback);

DESCRIPCIÓN

Pase un puntero a su función de devolución de llamada, que debe coincidir con el prototipo mostrado anteriormente.

Esta función es llamada por libcurl en lugar de su equivalente interno con una frecuencia alta. Mientras se transfieren datos, se llama con frecuencia, y durante períodos lentos, como cuando no se está transfiriendo nada, puede reducirse a aproximadamente una llamada por segundo.

clientp es el puntero establecido con CURLOPT_XFERINFODATA(3), no es utilizado por libcurl, sino que simplemente se pasa de la aplicación a la función de devolución de llamada.

La función de devolución de llamada recibe información sobre cuántos datos espera transferir libcurl y cuántos ya ha transferido, en número de bytes. dltotal es el número total de bytes que libcurl espera descargar en esta transferencia. dlnow es el número de bytes descargados hasta ahora. ultotal es el número total de bytes que libcurl espera cargar en esta transferencia. ulnow es el número de bytes cargados hasta ahora.

Los valores de argumentos desconocidos/no utilizados pasados a la función de devolución de llamada se establecen en cero (por ejemplo, si solo descarga datos, el tamaño de carga permanece en 0). Muchas veces, la función de devolución de llamada se llama una o más veces primero, antes de que conozca los tamaños de los datos, por lo que un programa debe estar preparado para manejar eso.

Devuelva cero desde la función de devolución de llamada si todo está bien.

Devuelva 1 desde esta función de devolución de llamada para hacer que libcurl aborte la transferencia y devuelva CURLE_ABORTED_BY_CALLBACK.

Si su función de devolución de llamada devuelve CURL_PROGRESSFUNC_CONTINUE, hace que libcurl continúe ejecutando la función de progreso predeterminada.

Si transfiere datos con la interfaz multi, esta función no se llama durante períodos de inactividad a menos que llame a la función apropiada de libcurl que realiza transferencias.

CURLOPT_NOPROGRESS(3) debe establecerse en 0 para que esta función se llame realmente.

PREDETERMINADO

NULL - usa el medidor de progreso interno. Esto rara vez es deseado por los usuarios.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

struct progress {
  char *private;
  size_t size;
};
static int xferinfo_callback(void *clientp,
                             curl_off_t dltotal,
                             curl_off_t dlnow,
                             curl_off_t ultotal,
                             curl_off_t ulnow)
{
  struct progress *memory = clientp;
  printf("mi puntero: %p\n", memory->private);
  /* usa los valores */
  return 0; /* todo está bien */
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct progress data;
    /* pasa la estructura a la función de devolución de llamada */
    curl_easy_setopt(curl, CURLOPT_XFERINFODATA, &data);
    /* habilita la llamada a la función de devolución de llamada de progreso */
    curl_easy_setopt(curl, CURLOPT_NOPROGRESS, 0L);
    curl_easy_setopt(curl, CURLOPT_XFERINFOFUNCTION, xferinfo_callback);
  }
}

DISPONIBILIDAD

Añadido en curl 7.32.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
