NOMBRE

cupsd - planificador de cups

SINOPSIS

cupsd [ -c cupsd.conf ] [ -f ] [ -F ] [ -h ] [ -l ] [ -s cups-files.conf ] [ -t ]

DESCRIPCIÓN

cupsd es el planificador para CUPS. Implementa un sistema de impresión basado en el protocolo de impresión por Internet, versión 2.1, y soporta la mayoría de los requisitos para IPP Everywhere. Si no se especifican opciones en la línea de comandos, se utilizará el archivo de configuración predeterminado /etc/cups/cupsd.conf.

OPCIONES

-c cupsd.conf
Utiliza el archivo de configuración cupsd.conf con el nombre especificado.
-f
Ejecuta cupsd en primer plano; el valor predeterminado es ejecutarlo en segundo plano como un "demonio".
-F
Ejecuta cupsd en primer plano pero desvincula el proceso del terminal controlador y del directorio actual. Esto es útil para ejecutar cupsd desde init(8).
-h
Muestra el uso del programa.
-l
Esta opción se pasa a cupsd cuando se ejecuta desde launchd(8) o systemd(8).
-s cups-files.conf
Utiliza el archivo de configuración cups-files.conf con el nombre especificado.
-t
Comprueba la sintaxis del archivo de configuración.

ARCHIVOS

CONFORMIDAD

cupsd implementa todos los atributos y operaciones requeridos de IPP/2.1. También implementa varias operaciones administrativas específicas de CUPS.

EJEMPLOS

Ejecutar cupsd en segundo plano con el archivo de configuración predeterminado:

    cupsd

Probar un archivo de configuración llamado test.conf:

    cupsd -t -c test.conf

Ejecutar cupsd en primer plano con un archivo de configuración de prueba llamado test.conf:

    cupsd -f -c test.conf
