DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine cunglq (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGLQ

Propósito:

!>
!> CUNGLQ genera una matriz compleja Q de M por N con filas ortonormales,
!> que se define como las primeras M filas de un producto de K reflectores
!> elementales de orden N
!>
!>       Q  =  H(k)**H . . . H(2)**H H(1)**H
!>
!> tal como devuelve CGELQF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q. N >= M.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>          A la entrada, la i-ésima fila debe contener el vector que define
!>          el reflector elemental H(i), para i = 1,2,...,k, tal como
!>          devuelve CGELQF en las primeras k filas de su argumento de array A.
!>          A la salida, la matriz Q de M por N.
!>

LDA

!>          LDA es ENTERO
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEJO, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve CGELQF.
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= M*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa;
!>          < 0:  si INFO = -i, el i-ésimo argumento tiene un valor ilegal
!>
