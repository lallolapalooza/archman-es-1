CURLOPT_SEEKFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_SEEKFUNCTION(3) Manual de Funciones de la Biblioteca CURLOPT_SEEKFUNCTION(3)

NOMBRE

CURLOPT_SEEKFUNCTION - callback de usuario para buscar en el flujo de entrada

SINOPSIS

#include <curl/curl.h>
/* Estos son los códigos de retorno para las callbacks de búsqueda */
#define CURL_SEEKFUNC_OK       0
#define CURL_SEEKFUNC_FAIL     1 /* fallar la transferencia completa */
#define CURL_SEEKFUNC_CANTSEEK 2 /* indicar a libcurl que la búsqueda no se puede realizar, por lo que
                                    libcurl puede intentar otros medios en su lugar */
int seek_callback(void *clientp, curl_off_t offset, int origin);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SEEKFUNCTION, seek_callback);

DESCRIPCIÓN

Pase un puntero a su función de callback, que debe coincidir con el prototipo mostrado arriba.

Esta función es llamada por libcurl para buscar una posición determinada en el flujo de entrada y puede usarse para avanzar rápidamente un archivo en una carga reanudada (en lugar de leer todos los bytes cargados con la función/callback de lectura normal). También se llama para rebobinar un flujo cuando los datos ya se han enviado al servidor y necesitan enviarse de nuevo. Esto puede suceder al realizar un PUT o POST HTTP con un método de autenticación de múltiples pasos, o cuando una conexión HTTP existente se reutiliza demasiado tarde y el servidor cierra la conexión. La función debe funcionar como fseek(3) o lseek(3) y recibe SEEK_SET, SEEK_CUR o SEEK_END como argumento para origin, aunque libcurl actualmente solo pasa SEEK_SET.

clientp es el puntero que estableció con CURLOPT_SEEKDATA(3).

La función de callback debe devolver CURL_SEEKFUNC_OK en caso de éxito, CURL_SEEKFUNC_FAIL para que la operación de carga falle, o CURL_SEEKFUNC_CANTSEEK para indicar que, aunque la búsqueda falló, libcurl puede intentar solucionar el problema si es posible. Esto último a veces se puede hacer leyendo desde la entrada o de manera similar.

Si pasa los argumentos de entrada directamente a fseek(3) o lseek(3), tenga en cuenta que el tipo de dato para offset no es el mismo que el definido para curl_off_t en muchos sistemas.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a ftp, http y sftp

EJEMPLO

#include <unistd.h> /* para lseek */
struct data {
  int our_fd;
};
static int seek_cb(void *clientp, curl_off_t offset, int origin)
{
  struct data *d = (struct data *)clientp;
  lseek(d->our_fd, offset, origin);
  return CURL_SEEKFUNC_OK;
}
int main(void)
{
  struct data seek_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_SEEKFUNCTION, seek_cb);
    curl_easy_setopt(curl, CURLOPT_SEEKDATA, &seek_data);
  }
}

DISPONIBILIDAD

Añadido en curl 7.18.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, distinto de cero significa que ocurrió un error, ver libcurl-errors(3).
