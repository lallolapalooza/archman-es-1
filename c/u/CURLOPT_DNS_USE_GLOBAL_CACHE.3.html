CURLOPT_DNS_USE_GLOBAL_CACHE(3)

Paquete: curl

Licencias: MIT

CURLOPT_DNS_USE_GLOBAL_CACHE(3) Manual de funciones de biblioteca CURLOPT_DNS_USE_GLOBAL_CACHE(3)

NOMBRE

CURLOPT_DNS_USE_GLOBAL_CACHE - caché DNS global

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DNS_USE_GLOBAL_CACHE,
                          long enable);

DESCRIPCIÓN

No tiene función desde la versión 7.62.0. No usar.

Pasa un long. Si el valor de enable es 1, le indica a curl que use una caché DNS global que sobrevive a la creación y eliminación de identificadores fáciles. Esto no es seguro para hilos y usa una variable global.

Consulte CURLOPT_SHARE(3) y curl_share_init(3) para la forma correcta de compartir la caché DNS entre transferencias.

POR OMISIÓN

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* desactiva el uso de una caché global no segura para hilos */
    curl_easy_setopt(curl, CURLOPT_DNS_USE_GLOBAL_CACHE, 0L);
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

OBSOLETO

Obsoleto desde la versión 7.11.1. Funcionalidad eliminada en la versión 7.62.0.

DISPONIBILIDAD

Añadido en curl 7.9.3

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
