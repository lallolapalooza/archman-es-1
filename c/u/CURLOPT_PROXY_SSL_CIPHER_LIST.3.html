CURLOPT_PROXY_SSL_CIPHER_LIST(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_SSL_CIPHER_LIST(3) Manual de funciones de biblioteca CURLOPT_PROXY_SSL_CIPHER_LIST(3)

NOMBRE

CURLOPT_PROXY_SSL_CIPHER_LIST - cifrados a usar para el proxy HTTPS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_SSL_CIPHER_LIST,
                          char *list);

DESCRIPCIÓN

Pasa un puntero a char, que apunta a una cadena terminada en nulo que contiene la lista de suites de cifrado a usar para la conexión TLS 1.2 (1.1, 1.0) al proxy HTTPS. La lista debe ser sintácticamente correcta, consiste en una o más cadenas de suite de cifrado separadas por dos puntos.

Para establecer cifrados TLS 1.3, consulta CURLOPT_PROXY_TLS13_CIPHERS(3).

Un ejemplo válido de lista de cifrados es:

"ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:"
"ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305"

Para Schannel, puedes usar esta opción para establecer algoritmos pero no suites de cifrado específicas. Consulta el documento de listas de cifrados para ver los algoritmos.

Encuentra más detalles sobre las listas de cifrados en esta URL:


https://curl.se/docs/ssl-ciphers.html

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción múltiples veces hace que la última cadena establecida anule las anteriores. Establécela a NULL para deshabilitar su uso nuevamente.

PREDETERMINADO

NULL, usa la lista interna incorporada.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL, Schannel, mbedTLS, rustls y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost");
    curl_easy_setopt(curl, CURLOPT_PROXY_SSL_CIPHER_LIST,
                     "ECDHE-ECDSA-CHACHA20-POLY1305:"
                     "ECDHE-RSA-CHACHA20-POLY1305");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIA

Soporte para OpenSSL añadido en 7.52.0. Soporte para wolfSSL, Schannel añadido en 7.87.0. Soporte para mbedTLS añadido en 8.8.0. Soporte para Rustls añadido en 8.10.0.

Desde curl 8.10.0 devuelve CURLE_NOT_BUILT_IN cuando no se soporta.

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulta libcurl-errors(3).

VER TAMBIÉN

CURLOPT_PROXY_SSLVERSION(3), CURLOPT_PROXY_TLS13_CIPHERS(3), CURLOPT_SSLVERSION(3), CURLOPT_SSL_CIPHER_LIST(3), CURLOPT_TLS13_CIPHERS(3)
