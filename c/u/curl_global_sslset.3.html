curl_global_sslset(3)

Paquete: curl

Licencias: MIT

curl_global_sslset(3) Manual de funciones de la biblioteca curl_global_sslset(3)

NOMBRE

curl_global_sslset - seleccionar el backend SSL a utilizar

SINOPSIS

#include <curl/curl.h>
CURLsslset curl_global_sslset(curl_sslbackend id,
                              const char *name,
                              const curl_ssl_backend ***avail);

DESCRIPCIÓN

Esta función configura en tiempo de ejecución qué backend SSL utilizar con libcurl. Esta función solo se puede usar para seleccionar un backend SSL una vez, y debe llamarse **antes** de curl_global_init(3).

El backend se puede identificar por su id (por ejemplo, **CURLSSLBACKEND_OPENSSL**). El backend también se puede especificar a través del parámetro name para una coincidencia insensible a mayúsculas y minúsculas (pasando **CURLSSLBACKEND_NONE** como id). Si se especifican tanto id como name, se ignora name.

Si no se especifican ni id ni name, la función falla con **CURLSSLSET_UNKNOWN_BACKEND** y establece el puntero avail a la lista terminada en NULL de backends disponibles. Los backends disponibles son aquellos que soporta esta compilación particular de libcurl.

Desde libcurl 7.60.0, el puntero avail siempre se establece en la lista de alternativas si no es NULL.

En caso de éxito, la función devuelve **CURLSSLSET_OK**.

Si el backend SSL especificado no está disponible, la función devuelve **CURLSSLSET_UNKNOWN_BACKEND** y establece el puntero avail a una lista terminada en NULL de backends SSL disponibles. En este caso, puede llamar a la función de nuevo para intentar seleccionar un backend diferente.

El backend SSL solo se puede configurar una vez. Si ya se ha configurado, un intento posterior de cambiarlo resulta en que se devuelva un **CURLSSLSET_TOO_LATE**.

Esta función es segura para hilos desde libcurl 7.84.0 si curl_version_info(3) tiene el bit de característica CURL_VERSION_THREADSAFE establecido (en la mayoría de las plataformas).

Si no es seguro para hilos, no debe llamar a esta función mientras ningún otro hilo del programa (es decir, un hilo que comparta la misma memoria) se esté ejecutando. Esto no significa solo que ningún otro hilo esté usando libcurl.

Nombres

Nombres de backends SSL (insensible a mayúsculas y minúsculas): GnuTLS, mbedTLS, OpenSSL, Rustls, Schannel, wolfSSL

El nombre "OpenSSL" se utiliza para todas las versiones de OpenSSL y sus bifurcaciones/variantes asociadas en esta función. OpenSSL, BoringSSL, LibreSSL, quictls y AmiSSL son compatibles con libcurl, pero para curl_global_sslset(3) todos son simplemente "OpenSSL". Todos proporcionan en su mayoría la misma API. curl_version_info(3) puede devolver información más específica sobre el sabor exacto de OpenSSL y el número de versión en uso.

struct

typedef struct {
  curl_sslbackend id;
  const char *name;
} curl_ssl_backend;
typedef enum {
  CURLSSLBACKEND_NONE = 0,
  CURLSSLBACKEND_OPENSSL = 1, /* o una de sus bifurcaciones */
  CURLSSLBACKEND_GNUTLS = 2,
  CURLSSLBACKEND_NSS = 3,
  CURLSSLBACKEND_GSKIT = 5, /* obsoleto */
  CURLSSLBACKEND_POLARSSL = 6, /* obsoleto */
  CURLSSLBACKEND_WOLFSSL = 7,
  CURLSSLBACKEND_SCHANNEL = 8,
  CURLSSLBACKEND_SECURETRANSPORT = 9, /* obsoleto */
  CURLSSLBACKEND_AXTLS = 10, /* obsoleto */
  CURLSSLBACKEND_MBEDTLS = 11,
  CURLSSLBACKEND_MESALINK = 12, /* obsoleto */
  CURLSSLBACKEND_BEARSSL = 13, /* obsoleto */
  CURLSSLBACKEND_RUSTLS = 14
} curl_sslbackend;

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  int i;
  /* elige un backend específico */
  curl_global_sslset(CURLSSLBACKEND_WOLFSSL, NULL, NULL);
  /* enumera los disponibles */
  const curl_ssl_backend **list;
  curl_global_sslset(CURLSSLBACKEND_NONE, NULL, &list);
  for(i = 0; list[i]; i++)
    printf("Backend SSL #%d: '%s' (ID: %d)\n",
           i, list[i]->name, list[i]->id);
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Si esta función devuelve CURLSSLSET_OK, el backend se seleccionó correctamente.

Si el backend elegido es desconocido (o el soporte para el backend elegido no se ha compilado en libcurl), la función devuelve CURLSSLSET_UNKNOWN_BACKEND.

Si el backend se había configurado previamente, o si curl_global_init(3) ya se ha llamado, la función devuelve CURLSSLSET_TOO_LATE.

Si esta libcurl se compiló completamente sin soporte SSL, sin ningún backend en absoluto, esta función devuelve CURLSSLSET_NO_BACKENDS.
