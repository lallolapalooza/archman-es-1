DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine cunghr (integer n, integer ilo, integer ihi, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGHR

Propósito:

!>
!> CUNGHR genera una matriz unitaria compleja Q que se define como el
!> producto de IHI-ILO reflectores elementales de orden N, tal como se devuelve en
!> CGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz Q. N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>
!>          ILO e IHI deben tener los mismos valores que en la llamada anterior
!>          de CGEHRD. Q es igual a la matriz unidad excepto en la
!>          submatriz Q(ilo+1:ihi,ilo+1:ihi).
!>          1 <= ILO <= IHI <= N, si N > 0; ILO=1 e IHI=0, si N=0.
!>

A

!>          A es array COMPLEJO, dimension (LDA,N)
!>          En la entrada, los vectores que definen los reflectores elementales,
!>          tal como se devuelve en CGEHRD.
!>          En la salida, la matriz unitaria Q de N por N.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

TAU

!>          TAU es array COMPLEJO, dimension (N-1)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como se devuelve en CGEHRD.
!>

WORK

!>          WORK es array COMPLEJO, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= IHI-ILO.
!>          Para un rendimiento óptimo LWORK >= (IHI-ILO)*NB, donde NB
!>          es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          sólo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
