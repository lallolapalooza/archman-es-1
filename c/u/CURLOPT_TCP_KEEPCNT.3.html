CURLOPT_TCP_KEEPCNT(3)

Paquete: curl

Licencias: MIT

CURLOPT_TCP_KEEPCNT(3) Manual de funciones de la biblioteca CURLOPT_TCP_KEEPCNT(3)

NOMBRE

CURLOPT_TCP_KEEPCNT - Número máximo de intentos de sondeo TCP keep-alive

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TCP_KEEPCNT, long cnt);

DESCRIPCIÓN

Pase un long. Establece el número de sondeos a enviar antes de descartar la conexión. No todos los sistemas operativos soportan esta opción. (Añadido en 8.9.0)

El valor máximo que acepta esta opción es INT_MAX o lo que sea que permita su sistema. Cualquier valor mayor se limita a esa cantidad.

POR OMISIÓN

9

PROTOCOLOS

Esta funcionalidad afecta solo a tcp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* habilitar TCP keep-alive para esta transferencia */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPALIVE, 1L);
    /* establecer tiempo inactivo de keep-alive a 120 segundos */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPIDLE, 120L);
    /* tiempo de intervalo entre sondeos de keep-alive: 60 segundos */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPINTVL, 60L);
    /* número máximo de sondeos de keep-alive: 3 */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPCNT, 3L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 8.9.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_TCP_KEEPALIVE(3), CURLOPT_TCP_KEEPIDLE(3), CURLOPT_TCP_KEEPINTVL(3)
