CURLOPT_LOW_SPEED_LIMIT(3)

Paquete: curl

Licencias: MIT

CURLOPT_LOW_SPEED_LIMIT(3) Manual de funciones de biblioteca CURLOPT_LOW_SPEED_LIMIT(3)

NOMBRE

CURLOPT_LOW_SPEED_LIMIT(3) - límite de baja velocidad en bytes por segundo

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_LOW_SPEED_LIMIT,
                          long speedlimit);

DESCRIPCIÓN

Pase un `long` como parámetro. Contiene la velocidad de transferencia promedio en bytes por segundo que debe ser inferior a la establecida durante CURLOPT_LOW_SPEED_TIME(3) segundos para que libcurl la considere demasiado lenta y la aborte.

POR OMISIÓN

0, deshabilitado

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* abortar si es más lento que 30 bytes/segundo durante 60 segundos */
    curl_easy_setopt(curl, CURLOPT_LOW_SPEED_TIME, 60L);
    curl_easy_setopt(curl, CURLOPT_LOW_SPEED_LIMIT, 30L);
    res = curl_easy_perform(curl);
    if(CURLE_OPERATION_TIMEDOUT == res) {
      printf("Se agotó el tiempo de espera.\n");
    }
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un `CURLcode` que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_LOW_SPEED_TIME(3), CURLOPT_MAX_RECV_SPEED_LARGE(3), CURLOPT_MAX_SEND_SPEED_LARGE(3), CURLOPT_TIMEOUT(3)
