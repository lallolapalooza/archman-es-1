CURLOPT_NOPROXY(3)

Paquete: curl

Licencias: MIT

CURLOPT_NOPROXY(3) Manual de funciones de biblioteca CURLOPT_NOPROXY(3)

NOMBRE

CURLOPT_NOPROXY - deshabilitar el uso de proxy para hosts específicos

SINAPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_NOPROXY, char *noproxy);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo. La cadena consta de una lista de nombres de host separados por comas que no requieren un proxy para ser alcanzados, incluso si se especifica uno. El único comodín disponible es un único carácter *, que coincide con todos los hosts y deshabilita efectivamente el proxy. Cada nombre en esta lista se compara como un dominio que contiene el nombre de host, o el nombre de host en sí. Por ejemplo, "ample.com" coincidiría con ample.com, ample.com:80 y www.ample.com, pero no con www.example.com o ample.com.org.

Establecer la cadena noproxy en "" (una cadena vacía) habilita explícitamente el proxy para todos los nombres de host, incluso si hay una variable de entorno establecida para ello.

Ingrese direcciones numéricas IPv6 en la lista de nombres de host sin encerrar corchetes:

"example.com,::1,localhost"

Desde la versión 7.86.0, las direcciones IP especificadas en esta opción se pueden proporcionar utilizando la notación CIDR: una barra adjunta y un número especifica el número de "bits de red" de la dirección a utilizar en la comparación. Por ejemplo, "192.168.0.0/16" coincidiría con todas las direcciones que comienzan con "192.168".

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala en NULL para deshabilitar su uso nuevamente.

Variables de entorno

Si existe una variable de entorno llamada no_proxy (o NO_PROXY), se utiliza si la opción CURLOPT_NOPROXY(3) no está establecida. Funciona exactamente de la misma manera.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* aceptar varias URL */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* usar este proxy */
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://proxy:80");
    /* ... pero asegurarse de que este nombre de host no sea proxificado */
    curl_easy_setopt(curl, CURLOPT_NOPROXY, "www.example.com");
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.19.4

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
