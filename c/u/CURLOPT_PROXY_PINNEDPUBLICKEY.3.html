CURLOPT_PROXY_PINNEDPUBLICKEY(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_PINNEDPUBLICKEY(3) Manual de funciones de biblioteca CURLOPT_PROXY_PINNEDPUBLICKEY(3)

NOMBRE

CURLOPT_PROXY_PINNEDPUBLICKEY - clave pública fijada para proxy https

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_PINNEDPUBLICKEY,
                          char *pinnedpubkey);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. La cadena puede ser el nombre de archivo de su clave pública fijada. El formato de archivo esperado es "PEM" o "DER". La cadena también puede ser cualquier número de hashes sha256 codificados en base64 precedidos por "sha256//" y separados por ";".

Al negociar una conexión TLS o SSL, el proxy https envía un certificado que indica su identidad. Una clave pública se extrae de este certificado y si no coincide exactamente con la clave pública proporcionada a esta opción, libcurl aborta la conexión antes de enviar o recibir ningún dato.

En caso de discrepancia, se devuelve CURLE_SSL_PINNEDPUBKEYNOTMATCH.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para volver a desactivar su uso.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL, mbedTLS y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy:443");
    curl_easy_setopt(curl, CURLOPT_PROXY_PINNEDPUBLICKEY,
                     "sha256//YhKJKSzoTt2b5FP18fvpHo7fJYqQCjA"
                     "a3HWY3tvRMwE=;sha256//t62CeU2tQiqkexU74"
                     "Gxa2eg7fRbEgoChTociMee9wno=");
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

EXTRACCIÓN DE CLAVE PÚBLICA

Si no tiene el archivo de clave pública del servidor proxy https, puede extraerlo del certificado del servidor proxy https.

# recuperar el certificado del servidor si aún no lo tiene
#
# asegúrese de examinar el certificado para ver si es lo que esperaba
#
# específico para Windows:
# - Use NUL en lugar de /dev/null.
# - OpenSSL puede esperar entrada en lugar de desconectarse. Presione Enter.
# - Si no tiene sed, simplemente copie el certificado en un archivo:
#   Líneas desde -----BEGIN CERTIFICATE----- hasta -----END CERTIFICATE-----.
#
openssl s_client -servername www.example.com -connect www.example.com:443 \
  < /dev/null | sed -n "/-----BEGIN/,/-----END/p" > www.example.com.pem
# extraer la clave pública en formato pem del certificado
openssl x509 -in www.example.com.pem -pubkey -noout > www.example.com.pubkey.pem
# convertir la clave pública de pem a der
openssl asn1parse -noout -inform pem -in www.example.com.pubkey.pem \
  -out www.example.com.pubkey.der
# hash sha256 y codificar en base64 la der a una cadena para su uso
openssl dgst -sha256 -binary www.example.com.pubkey.der | openssl base64

La clave pública en formato PEM contiene una cabecera, datos base64 y un pie de página:

-----BEGIN PUBLIC KEY-----
[DATOS BASE 64]
-----END PUBLIC KEY-----

HISTORIAL

Soporte PEM/DER:


7.52.0: GnuTLS, OpenSSL, mbedTLS, wolfSSL

Soporte sha256:


7.52.0: GnuTLS, OpenSSL, mbedTLS, wolfSSL

Otros backends SSL no soportados.

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
