curl_easy_header(3)

Paquete: curl

Licencias: MIT

curl_easy_header(3) Manual de Funciones de Biblioteca curl_easy_header(3)

NOMBRE

curl_easy_header - obtener una cabecera HTTP

SINOPSIS

#include <curl/curl.h>
CURLHcode curl_easy_header(CURL *easy,
                           const char *name,
                           size_t index,
                           unsigned int origin,
                           int request,
                           struct curl_header **hout);

DESCRIPCIÓN

curl_easy_header(3) devuelve un puntero a una estructura "curl_header" en hout con datos para la cabecera de respuesta HTTP name. El nombre de la cabecera, que no distingue entre mayúsculas y minúsculas y terminado en nulo, debe especificarse sin los dos puntos.

index 0 significa pedir la primera instancia de la cabecera. Si la estructura de cabecera devuelta tiene amount establecido en un valor mayor que 1, significa que hay más instancias del mismo nombre de cabecera disponibles para obtener. Pedir un índice demasiado grande hace que se devuelva CURLHE_BADINDEX .

El argumento origin sirve para especificar qué cabeceras recibir, ya que una única transferencia HTTP puede proporcionar cabeceras de varios lugares diferentes y pueden tener entonces una importancia diferente para el usuario, y pueden usarse cabeceras con el mismo nombre. El origin es una máscara de bits para las fuentes de cabeceras que desea. Vea las descripciones más abajo.

El argumento request le indica a libcurl de qué solicitud quiere las cabeceras. Una única transferencia puede consistir en una serie de solicitudes HTTP y este argumento le permite especificar de qué solicitud individual concreta quiere las cabeceras. 0 siendo la primera solicitud y luego el número aumenta para redirecciones posteriores o cuando se usa autenticación de múltiples estados. Pasar -1 es un atajo para "la última" solicitud de la serie, independientemente de la cantidad real de solicitudes usadas.

libcurl almacena y proporciona las cabeceras "correctas" realmente usadas. Si por ejemplo llegan dos cabeceras con el mismo nombre y la segunda anula a la primera, entonces solo se proporciona la segunda. Si la primera cabecera sobrevive a la segunda, entonces solo se proporciona la primera. Una aplicación que use esta API no tiene que preocuparse por múltiples cabeceras usadas incorrectamente.

La memoria para la estructura devuelta está asociada con el manejador fácil y las llamadas posteriores a curl_easy_header(3) sobrescriben la estructura usada en las llamadas anteriores para el mismo manejador fácil. La aplicación necesita copiar los datos si quiere conservarlos. La memoria usada para la estructura se libera al llamar a curl_easy_cleanup(3) del manejador fácil.

La primera línea en una respuesta HTTP se llama línea de estado. Esta función no la considera una cabecera. Las cabeceras son las líneas "nombre: valor" que siguen al estado.

Esta función puede usarse antes de que se hayan recibido (todas) las cabeceras y es correcto llamarla desde dentro de las funciones de retorno de libcurl. Devuelve el estado de las cabeceras en el momento en que se llama.

La estructura de cabecera

struct curl_header {
   char *name;
   char *value;
   size_t amount;
   size_t index;
   unsigned int origin;
   void *anchor;
};

Los datos a los que apunta el campo name son los mismos que el nombre solicitado, pero pueden tener un caso diferente.

Los datos a los que apunta el campo value provienen exactamente tal como se entregaron por la red pero con el espacio en blanco y los saltos de línea iniciales y finales eliminados. Los datos value están terminados en nulo. Para las "cabeceras plegadas" heredadas de HTTP/1, esta API proporciona el valor único completo de manera desplegada con un único espacio en blanco entre las líneas.

amount es cuántas cabeceras usando este nombre existen, dentro del ámbito de origen y solicitud pedido.

index es el número de entrada basado en cero de esta cabecera particular, que en caso de que esta cabecera se usara más de una vez en el ámbito solicitado puede ser mayor que 0 pero siempre es menor que amount.

El campo origin en la estructura "curl_header" tiene uno de los bits de origen establecido, indicando de dónde proviene la cabecera. En el momento de escribir esto, hay 5 bits con uso definido. Los 27 bits restantes no documentados están reservados para uso futuro y no se debe asumir que tengan algún valor particular.

anchor es un manejador privado usado por los internos de libcurl. No lo modifique.

ORÍGENES

CURLH_HEADER
La cabecera llegó como una cabecera del servidor.
CURLH_TRAILER
La cabecera llegó como un remite. Una cabecera que llega después del cuerpo.
CURLH_CONNECT
La cabecera llegó en una respuesta CONNECT. Se está realizando una solicitud CONNECT para configurar una transferencia "a través" de un proxy HTTP(S).
CURLH_1XX
La cabecera llegó en una respuesta HTTP 1xx. Una respuesta 1xx es una respuesta "intermedia" que puede ocurrir antes de la respuesta "real".
CURLH_PSEUDO
La cabecera es una cabecera pseudo de HTTP/2 o HTTP/3

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  struct curl_header *type;
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLHcode h;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_perform(curl);
    h = curl_easy_header(curl, "Content-Type", 0, CURLH_HEADER, -1, &type);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.83.0

VALOR DE RETORNO

Esta función devuelve un CURLHcode que indica éxito o error. CURLHE_OK (0) significa que todo estaba bien, un valor distinto de cero significa que ocurrió un error, vea libcurl-errors(3).
