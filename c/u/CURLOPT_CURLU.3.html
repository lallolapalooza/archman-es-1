CURLOPT_CURLU(3)

Paquete: curl

Licencias: MIT

CURLOPT_CURLU(3) Manual de funciones de la biblioteca CURLOPT_CURLU(3)

NOMBRE

CURLOPT_CURLU - manejador de URL en formato URL

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CURLU, CURLU *pointer);

DESCRIPCIÓN

Pasa un puntero al manejador URL con el que trabajar. El parámetro debe ser un puntero CURLU. Establecer CURLOPT_CURLU(3) anula explícitamente CURLOPT_URL(3).

CURLOPT_URL(3) o CURLOPT_CURLU(3) debe establecerse antes de que comience una transferencia.

libcurl utiliza este manejador y su contenido de solo lectura y no cambia su contenido. Una aplicación puede actualizar el contenido del manejador URL después de que una transferencia haya finalizado y, si se utiliza el mismo manejador en una solicitud posterior, se utilizará el contenido actualizado.

VALOR POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  CURLU *urlp = curl_url();
  if(curl) {
    CURLcode res;
    CURLUcode ret;
    ret = curl_url_set(urlp, CURLUPART_URL, "https://example.com", 0);
    curl_easy_setopt(curl, CURLOPT_CURLU, urlp);
    res = curl_easy_perform(curl);
    curl_url_cleanup(urlp);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.63.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, ver libcurl-errors(3).
