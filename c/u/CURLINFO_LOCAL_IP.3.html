CURLINFO_LOCAL_IP(3)

Paquete: curl

Licencias: MIT

CURLINFO_LOCAL_IP(3) Manual de Funciones de Biblioteca CURLINFO_LOCAL_IP(3)

NOMBRE

CURLINFO_LOCAL_IP - obtener la dirección IP local de la última conexión

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_LOCAL_IP, char **ip);

DESCRIPCIÓN

Pase un puntero a un puntero de caracter para recibir el puntero a una cadena terminada en nulo que contiene la dirección IP del extremo local de la conexión más reciente realizada con este manejador curl. Esta cadena puede ser IPv6 cuando está habilitada. Tenga en cuenta que obtiene un puntero a un área de memoria que se reutiliza en la próxima solicitud, por lo que debe copiar la cadena si desea conservar la información.

El puntero ip es NULL o apunta a memoria privada. Usted no debe liberarlo. La memoria se libera automáticamente cuando llama a curl_easy_cleanup(3) en el manejador de curl correspondiente.

PROTOCOLOS

Esta funcionalidad afecta a quic y tcp

EJEMPLO

int main(void)
{
  char *ip;
  CURLcode res;
  CURL *curl = curl_easy_init();
  curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
  /* Realizar la transferencia */
  res = curl_easy_perform(curl);
  /* Comprobar errores */
  if((res == CURLE_OK) &&
     !curl_easy_getinfo(curl, CURLINFO_LOCAL_IP, &ip) && ip) {
    printf("IP Local: %s\n", ip);
  }
  /* siempre limpiar */
  curl_easy_cleanup(curl);
}

DISPONIBILIDAD

Añadido en curl 7.21.0

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error; consulte libcurl-errors(3).
