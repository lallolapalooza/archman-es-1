NOMBRE

cupsdisable, cupsenable - detener/iniciar impresoras y clases

SINOPSIS

cupsdisable [ -E ] [ -U nombredeusuario ] [ -c ] [ -h servidor[:puerto] ] [ -r razón ] [ --hold ] destino(s)
cupsenable [ -E ] [ -U nombredeusuario ] [ -c ] [ -h servidor[:puerto] ] [ --release ] destino(s)

DESCRIPCIÓN

cupsenable inicia las impresoras o clases nombradas mientras que cupsdisable detiene las impresoras o clases nombradas.

OPCIONES

Se pueden usar las siguientes opciones:

-E
Fuerza el cifrado de la conexión al servidor.
-U nombredeusuario
Utiliza el nombre de usuario especificado al conectarse al servidor.
-c
Cancela todos los trabajos en el destino nombrado.
-h servidor[:puerto]
Utiliza el servidor y puerto especificados.
--hold
Retiene los trabajos restantes en la impresora nombrada. Útil para permitir que el trabajo actual finalice antes de realizar el mantenimiento.
-r "razón"
Establece el mensaje asociado con el estado detenido. Si no se especifica ninguna razón, el mensaje se establece en "Razón Desconocida".
--release
Libera los trabajos pendientes para impresión. Úselo después de ejecutar cupsdisable con la opción --hold para reanudar la impresión.

CONFORMIDAD

A diferencia del sistema de impresión System V, CUPS permite que los nombres de impresora contengan cualquier carácter imprimible excepto ESPACIO, TAB, "/" o "#". Además, los nombres de impresora y clase no distinguen entre mayúsculas y minúsculas.

Las versiones de System V de estos comandos son disable y enable, respectivamente. Se les ha cambiado el nombre para evitar conflictos con los comandos integrados de bash(1) del mismo nombre.

Las versiones de CUPS de disable y enable pueden solicitar al usuario una contraseña de acceso según la configuración del sistema de impresión. Esto difiere de las versiones de System V que requieren que el usuario root ejecute estos comandos.
