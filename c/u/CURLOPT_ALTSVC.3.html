CURLOPT_ALTSVC(3)

Paquete: curl

Licencias: MIT

CURLOPT_ALTSVC(3) Manual de funciones de la biblioteca CURLOPT_ALTSVC(3)

NOMBRE

CURLOPT_ALTSVC - nombre de archivo de caché alt-svc

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ALTSVC, char *filename);

DESCRIPCIÓN

Pase un puntero a un nombre de archivo para instruir a libcurl a usar ese archivo como caché de Alt-Svc para leer el contenido existente de la caché y posiblemente también escribirlo de vuelta después de una transferencia, a menos que CURLALTSVC_READONLYFILE esté establecido en CURLOPT_ALTSVC_CTRL(3).

Especifique un nombre de archivo en blanco ("") para que libcurl no cargue desde un archivo en absoluto.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para deshabilitar su uso nuevamente.

PREOCUPACIONES DE SEGURIDAD

libcurl no puede proteger completamente contra ataques donde un atacante tiene acceso de escritura al mismo directorio donde se le indica que guarde archivos. Esto es particularmente sensible si guarda archivos usando privilegios elevados.

POR DEFECTO

NULL. La caché alt-svc no se lee ni se escribe en archivo.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_ALTSVC_CTRL, CURLALTSVC_H1);
    curl_easy_setopt(curl, CURLOPT_ALTSVC, "altsvc-cache.txt");
    curl_easy_perform(curl);
  }
}

HISTORIAL

Las macros CURLALTSVC_* se convirtieron en tipos long en la versión 8.16.0, antes de esta versión era necesario un cast a long cuando se pasaban a curl_easy_setopt(3).

FORMATO DEL ARCHIVO

Un archivo basado en texto con una línea por cada entrada alt-svc y cada línea consta de nueve campos separados por espacios.

Una línea de ejemplo podría verse así:

h2 www.example.com 8443 h3 second.example.com 443 "20190808 06:18:37" 1 0

Los campos de esa línea son:

h2
ID de ALPN para el origen de origen
www.example.com
Nombre de host para el origen de origen
8443
Número de puerto para el origen de origen
h3
ID de ALPN para el host de destino
second.example.com
Nombre de host para el host de destino
443
Número de puerto para el host de destino
2019*
Fecha y hora de expiración de esta entrada entre comillas dobles. El formato de fecha es "AAAA MM DD HH:MM:SS" y la zona horaria es GMT.
1
Booleano (1 o 0) si se estableció "persist" para esta entrada
0
Valor de prioridad entero (no utilizado actualmente)

DISPONIBILIDAD

Añadido en curl 7.64.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero significa que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_ALTSVC_CTRL(3), CURLOPT_CONNECT_TO(3), CURLOPT_COOKIEFILE(3), CURLOPT_RESOLVE(3)
