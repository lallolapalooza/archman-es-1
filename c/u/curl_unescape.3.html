curl_unescape(3)

Paquete: curl

NOMBRE

curl_unescape - Decodifica una cadena URL

SINOPSIS

#include <curl/curl.h>
char *curl_unescape(const char *input, int length);

DESCRIPCIÓN

Obsoleto. Usa curl_easy_unescape(3) en su lugar.

Esta función convierte la cadena codificada en URL input a una cadena "plana" y la devuelve como una cadena recién asignada. Todos los caracteres de entrada que están codificados en URL (%XX donde XX es un número hexadecimal de dos dígitos) se convierten a sus versiones de texto plano.

Si el argumento length se establece en 0, curl_unescape(3) llama a strlen() en input para averiguar el tamaño.

Debes curl_free(3) la cadena devuelta cuando hayas terminado con ella.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    char *decoded = curl_unescape("%63%75%72%6c", 12);
    if(decoded) {
      /* no asumas que printf() funciona con los datos decodificados */
      printf("Decodificado: ");
      /* ... */
      curl_free(decoded);
    }
  }
}

OBSOLETO

Desde la versión 7.15.4, se debe usar curl_easy_unescape(3). Esta función puede ser eliminada en una futura versión.

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Un puntero a una cadena terminada en nulo o NULL si falló.

VER TAMBIÉN

RFC2396, curl_easy_escape(3), curl_easy_unescape(3), curl_free(3)
