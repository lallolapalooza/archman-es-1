CURLOPT_FNMATCH_FUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_FNMATCH_FUNCTION(3) Manual de funciones de la biblioteca CURLOPT_FNMATCH_FUNCTION(3)

NOMBRE

CURLOPT_FNMATCH_FUNCTION - función de devolución de llamada para coincidencia de comodines

SINOPSIS

#include <curl/curl.h>
int fnmatch_callback(void *ptr,
                     const char *pattern,
                     const char *string);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FNMATCH_FUNCTION,
                          fnmatch_callback);

DESCRIPCIÓN

Pase un puntero a su función de devolución de llamada, que debe coincidir con el prototipo mostrado anteriormente.

Esta función de devolución de llamada se utiliza para la coincidencia de comodines.

Devuelve CURL_FNMATCHFUNC_MATCH si el patrón coincide con la cadena, CURL_FNMATCHFUNC_NOMATCH si no coincide o CURL_FNMATCHFUNC_FAIL si ocurrió un error.

VALOR PREDETERMINADO

NULL == una función interna para coincidencia de comodines.

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

extern int string_match(const char *s1, const char *s2);
struct local_stuff {
  void *custom;
};
static int my_fnmatch(void *clientp,
                      const char *pattern, const char *string)
{
  struct local_stuff *data = clientp;
  printf("mi puntero: %p\n", data->custom);
  if(string_match(pattern, string))
    return CURL_FNMATCHFUNC_MATCH;
  else
    return CURL_FNMATCHFUNC_NOMATCH;
}
int main(void)
{
  struct local_stuff local_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://ftp.example.com/file*");
    curl_easy_setopt(curl, CURLOPT_WILDCARDMATCH, 1L);
    curl_easy_setopt(curl, CURLOPT_FNMATCH_FUNCTION, my_fnmatch);
    curl_easy_setopt(curl, CURLOPT_FNMATCH_DATA, &local_data);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.21.0

VALOR DE DEVOLUCIÓN

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, distinto de cero significa que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_DEBUGFUNCTION(3), CURLOPT_FNMATCH_DATA(3), CURLOPT_WILDCARDMATCH(3)
