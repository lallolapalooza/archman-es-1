curl_easy_setopt(3)

Paquete: curl

Licencias: curl

curl_easy_setopt(3) Library Functions Manual curl_easy_setopt(3)

NOMBRE

curl_easy_setopt - establece opciones para un handle easy de curl

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLoption option, parameter);

DESCRIPCIÓN

curl_easy_setopt(3) se utiliza para indicar a libcurl cómo debe comportarse. Al establecer las opciones adecuadas, la aplicación puede cambiar el comportamiento de libcurl. Todas las opciones se establecen con una opción seguida de un parámetro. Ese parámetro puede ser un long, un puntero a función, un puntero a objeto o un curl_off_t, dependiendo de lo que espere la opción específica. Lea este manual con atención, ya que valores de entrada incorrectos pueden hacer que libcurl se comporte mal. Solo puede establecer una opción en cada llamada a la función. Una aplicación típica utiliza muchas llamadas a curl_easy_setopt(3) en la fase de configuración.

El argumento handle es el código de retorno de una llamada a curl_easy_init(3) o curl_easy_duphandle(3).

Las opciones establecidas con esta llamada a la función son persistentes. Permanecen establecidas para todas las transferencias posteriores realizadas con este handle. Las opciones no se restablecen de ninguna manera entre transferencias, por lo que si desea transferencias posteriores con opciones diferentes, debe cambiarlas entre las transferencias. Opcionalmente, puede restablecer todas las opciones a los valores predeterminados internos con curl_easy_reset(3).

Cambiar opciones con curl_easy_setopt(3) mientras una transferencia aún está en curso puede causar un comportamiento indefinido e indeseado.

El orden en que se establecen las opciones no importa.

CADENAS

Las cadenas que se pasan a libcurl como argumentos 'char *' son copiadas por la biblioteca; el almacenamiento de la cadena asociado al argumento puntero puede descartarse o reutilizarse después de que curl_easy_setopt(3) retorne. La única excepción a esta regla es realmente CURLOPT_POSTFIELDS(3), pero la alternativa que copia la cadena CURLOPT_COPYPOSTFIELDS(3) tiene algunas características de uso sobre las que necesita informarse.

Esta función no acepta cadenas de entrada más largas que CURL_MAX_INPUT_LENGTH (8 MB).

libcurl hace poca o ninguna verificación del contenido de las cadenas proporcionadas. Pasar "octetos creativos" como saltos de línea donde no se esperan podría desencadenar resultados inesperados.

Antes de la versión 7.17.0, las cadenas no se copiaban. En su lugar, el usuario se veía obligado a mantenerlas disponibles hasta que libcurl ya no las necesitara.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode result;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    result = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue correcto, un valor distinto de cero significa que ocurrió un error, consulte libcurl-errors(3). Si se configuró CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el búfer de errores cuando se devuelve un valor distinto de cero.

Las cadenas que se pasan a libcurl deben tener menos de 8000000 bytes; de lo contrario, curl_easy_setopt(3) devuelve CURLE_BAD_FUNCTION_ARGUMENT (añadido en 7.65.0).

Se devuelve CURLE_BAD_FUNCTION_ARGUMENT cuando el argumento de una opción no es válido, como por ejemplo, fuera de rango.

Si intenta establecer una opción que libcurl no conoce, quizás porque la biblioteca es demasiado antigua para admitirla o porque la opción se eliminó en una versión reciente, esta función devuelve CURLE_UNKNOWN_OPTION. Si la compatibilidad con la opción se deshabilitó en tiempo de compilación, devuelve CURLE_NOT_BUILT_IN.
