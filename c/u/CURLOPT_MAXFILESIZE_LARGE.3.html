CURLOPT_MAXFILESIZE_LARGE(3)

Paquete: curl

Licencias: MIT

CURLOPT_MAXFILESIZE_LARGE(3) Manual de funciones de la biblioteca CURLOPT_MAXFILESIZE_LARGE(3)

NOMBRE

CURLOPT_MAXFILESIZE_LARGE - tamaño máximo de archivo permitido para descargar

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAXFILESIZE_LARGE,
                          curl_off_t size);

DESCRIPCIÓN

Pase un curl_off_t como parámetro. Este especifica el tamaño máximo aceptado (en bytes) de un archivo para descargar. Si el archivo solicitado se encuentra más grande que este valor, la transferencia se aborta y se devuelve CURLE_FILESIZE_EXCEEDED. Pasar un tamaño cero desactiva esta opción, y pasar un tamaño negativo resulta en CURLE_BAD_FUNCTION_ARGUMENT.

El tamaño del archivo no siempre se conoce antes del inicio de la descarga y, para tales transferencias, esta opción no tiene efecto, incluso si la transferencia de archivos eventualmente resulta ser más grande que el límite dado.

Desde la versión 8.4.0, esta opción también detiene las transferencias en curso si alcanzan este umbral.

VALOR POR OMISIÓN

0, lo que significa desactivado.

PROTOCOLOS

Esta funcionalidad afecta a ftp, http y mqtt

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_off_t ridiculo = (curl_off_t)1 << 48;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* rechazar la descarga si es mayor que ridiculo */
    curl_easy_setopt(curl, CURLOPT_MAXFILESIZE_LARGE, ridiculo);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.11.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
