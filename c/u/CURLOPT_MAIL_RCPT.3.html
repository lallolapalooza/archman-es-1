CURLOPT_MAIL_RCPT(3)

Paquete: curl

Licencias: MIT

CURLOPT_MAIL_RCPT(3) Manual de funciones de la biblioteca CURLOPT_MAIL_RCPT(3)

NOMBRE

CURLOPT_MAIL_RCPT - lista de destinatarios de correo SMTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAIL_RCPT,
                          struct curl_slist *rcpts);

DESCRIPCIÓN

Pasa un puntero a una lista enlazada de destinatarios para pasar al servidor en tu solicitud de correo SMTP. La lista enlazada debe ser una lista completamente válida de estructuras struct curl_slist correctamente completadas. Usa curl_slist_append(3) para crear la lista y curl_slist_free_all(3) para limpiar una lista completa.

libcurl no copia la lista, debe mantenerse hasta después de que la transferencia se haya completado.

Al realizar una transferencia de correo, cada destinatario debe especificarse entre corchetes angulares (<>), sin embargo, si no usas un corchete angular como primer carácter, libcurl asume que proporcionaste una única dirección de correo electrónico y encierra esa dirección entre corchetes por ti.

Para especificar parámetros DSN (según RFC 3461), la dirección debe escribirse entre corchetes angulares, seguida de los parámetros.

Al realizar una verificación de dirección (comando VRFY), cada destinatario debe especificarse como el nombre de usuario o el nombre de usuario más el dominio (según la Sección 3.5 de RFC 5321).

Al realizar una expansión de lista de correo (comando EXPN), cada destinatario debe especificarse utilizando el nombre de la lista de correo, como *Amigos* o *Oficina-Londres*.

Usar esta opción varias veces hace que la última lista establecida sobrescriba las anteriores. Establécela en NULL para deshabilitar su uso nuevamente.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a smtp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_slist *list;
    list = curl_slist_append(NULL, "root@localhost");
    list = curl_slist_append(list, "person@example.com");
    list = curl_slist_append(list, "<other@example.com> NOTIFY=SUCCESS");
    curl_easy_setopt(curl, CURLOPT_URL, "smtp://example.com/");
    curl_easy_setopt(curl, CURLOPT_MAIL_RCPT, list);
    res = curl_easy_perform(curl);
    curl_slist_free_all(list);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.20.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
