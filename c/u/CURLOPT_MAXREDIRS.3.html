CURLOPT_MAXREDIRS(3)

Paquete: curl

Licencias: MIT

CURLOPT_MAXREDIRS(3) Manual de funciones de la biblioteca CURLOPT_MAXREDIRS(3)

NOMBRE

CURLOPT_MAXREDIRS - número máximo de redirecciones permitidas

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAXREDIRS, long amount);

DESCRIPCIÓN

Pase un long. El número establecido es el límite de redirección amount. Si se han seguido tantas redirecciones, la siguiente redirección activa el error (CURLE_TOO_MANY_REDIRECTS). Esta opción solo tiene sentido si CURLOPT_FOLLOWLOCATION(3) se usa al mismo tiempo.

Establecer el límite en 0 hace que libcurl rechace cualquier redirección.

Establecerlo en -1 para un número infinito de redirecciones. Esto permite que su aplicación se quede atascada en bucles de redirección sin fin.

POR DEFECTO

30 (desde 8.3.0), anteriormente era ilimitado.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* habilitar seguimiento de redirecciones */
    curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
    /* permitir tres redirecciones */
    curl_easy_setopt(curl, CURLOPT_MAXREDIRS, 3L);
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.5

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLINFO_REDIRECT_COUNT(3), CURLINFO_REDIRECT_URL(3), CURLOPT_FOLLOWLOCATION(3)
