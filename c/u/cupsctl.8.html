NOMBRE

cupsctl - configurar opciones de cupsd.conf

SINOPSIS

cupsctl [ -h servidor[:puerto] ] [ -E ] [ -U nombredeusuario ] [ --[no-]debug-logging ] [ --[no-]remote-admin ] [ --[no-]remote-any ] [ --[no-]share-printers ] [ --[no-]user-cancel-any ] [ nombre=valor ]

DESCRIPCIÓN

cupsctl actualiza o consulta el archivo cupsd.conf de un servidor. Cuando no se solicitan cambios, los valores de configuración actuales se escriben en la salida estándar en el formato "nombre=valor", uno por línea.

OPCIONES

Se reconocen las siguientes opciones:

-E
Habilita el cifrado en la conexión con el planificador.
-U nombredeusuario
Especifica un nombre de usuario alternativo a usar al autenticarse con el planificador.
-h servidor[:puerto]
Especifica la dirección del servidor. Nota: Esta opción debe aparecer antes que todas las demás.
--[no-]debug-logging
Habilita (deshabilita) el registro de depuración en el archivo error_log.
--[no-]remote-admin
Habilita (deshabilita) la administración remota.
--[no-]remote-any
Habilita (deshabilita) la impresión desde cualquier dirección, por ejemplo, Internet.
--[no-]share-printers
Habilita (deshabilita) el uso compartido de impresoras locales con otros ordenadores.
--[no-]user-cancel-any
Permite (impide) a los usuarios cancelar trabajos de otros.

EJEMPLOS

Mostrar la configuración actual:

    cupsctl

Habilitar el registro de depuración:

    cupsctl --debug-logging

Obtener el estado actual del registro de depuración:

    cupsctl | grep '^_debug_logging' | awk -F= '{print $2}'

Deshabilitar el uso compartido de impresoras:

    cupsctl --no-share-printers

PROBLEMAS CONOCIDOS

No se pueden establecer las directivas Listen o Port usando cupsctl.
