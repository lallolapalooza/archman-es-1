CURLOPT_APPEND(3)

Paquete: curl

Licencias: MIT

CURLOPT_APPEND(3) Manual de funciones de la biblioteca CURLOPT_APPEND(3)

NOMBRE

CURLOPT_APPEND - añadir al archivo remoto

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_APPEND, long append);

DESCRIPCIÓN

Un parámetro long establecido en 1 indica a la biblioteca que añada al archivo remoto en lugar de sobrescribirlo. Esto solo es útil al cargar en un sitio FTP.

POR DEFECTO

0 (desactivado)

PROTOCOLOS

Esta funcionalidad afecta a ftp y sftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/dir/to/newfile");
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    curl_easy_setopt(curl, CURLOPT_APPEND, 1L);
    curl_easy_perform(curl);
  }
}

HISTORIAL

Esta opción se conocía como CURLOPT_FTPAPPEND hasta la versión 7.16.4

DISPONIBILIDAD

Añadido en curl 7.17.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_DIRLISTONLY(3), CURLOPT_RESUME_FROM(3), CURLOPT_UPLOAD(3)
