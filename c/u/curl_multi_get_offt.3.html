curl_multi_get_offt(3) Manual de funciones de la biblioteca curl_multi_get_offt(3)

NOMBRE

curl_multi_get_offt - extraer información de un manejador multi

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_get_offt(CURLM *multi_handle,
                              CURLMinfo_offt info,
                              curl_off_t *pvalue);

DESCRIPCIÓN

Obtiene la info mantenida en el manejador multi. Si la info no es aplicable, esta función devuelve CURLM_UNKNOWN_OPTION.

OPCIONES

La siguiente información puede ser extraída:

CURLMINFO_XFERS_CURRENT
Ver CURLMINFO_XFERS_CURRENT(3).
CURLMINFO_XFERS_RUNNING
Ver CURLMINFO_XFERS_RUNNING(3).
CURLMINFO_XFERS_PENDING
Ver CURLMINFO_XFERS_PENDING(3).
CURLMINFO_XFERS_DONE
Ver CURLMINFO_XFERS_DONE(3).
CURLMINFO_XFERS_ADDED
Ver CURLMINFO_XFERS_ADDED(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos.

EJEMPLO

int main(void)
{
  /* inicializar una pila multi */
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  curl_off_t n;
  if(curl) {
    /* añadir la transferencia */
    curl_multi_add_handle(multi, curl);
    curl_multi_get_offt(multi, CURLMINFO_XFERS_ADDED, &n);
    /* al añadir con éxito, n es 1 */
  }
}

DISPONIBILIDAD

Añadido en curl 8.16.0

VALOR DE RETORNO

Esta función devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo fue correcto, un valor distinto de cero significa que ocurrió un error, ver libcurl-errors(3).
