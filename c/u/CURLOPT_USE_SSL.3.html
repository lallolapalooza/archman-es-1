CURLOPT_USE_SSL(3)

Paquete: curl

Licencias: MIT

CURLOPT_USE_SSL(3) Manual de funciones de la biblioteca CURLOPT_USE_SSL(3)

NOMBRE

CURLOPT_USE_SSL - solicitar el uso de SSL / TLS para la transferencia

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_USE_SSL, long level);

DESCRIPCIÓN

Pase un `long` utilizando uno de los valores a continuación para que libcurl utilice el nivel de SSL deseado para la transferencia.

Estos son protocolos que comienzan como texto plano y se "actualizan" a SSL utilizando el comando STARTTLS.

Esto es para habilitar SSL/TLS cuando se utiliza FTP, SMTP, POP3, IMAP, etc.

CURLUSESSL_NONE
no intentar usar SSL.
CURLUSESSL_TRY
Intentar usar SSL, proceder normalmente de lo contrario. Tenga en cuenta que el servidor puede cerrar la conexión si la negociación no tiene éxito.
CURLUSESSL_CONTROL
Requerir SSL para la conexión de control o fallar con CURLE_USE_SSL_FAILED.
CURLUSESSL_ALL
Requerir SSL para toda la comunicación o fallar con CURLE_USE_SSL_FAILED.

PREDETERMINADO

CURLUSESSL_NONE

PROTOCOLOS

Esta funcionalidad afecta a ftp, imap, pop3 y smtp.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/dir/file.ext");
    /* requerir el uso de SSL para esto, o fallar */
    curl_easy_setopt(curl, CURLOPT_USE_SSL, CURLUSESSL_ALL);
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

HISTORIAL

Esta opción se conocía como CURLOPT_FTP_SSL hasta la versión 7.16.4. Compatible con LDAP desde la versión 7.81.0. Completamente compatible solo con el backend OpenLDAP.

Las enumeraciones CURLUSESSL_* se convirtieron en tipos `long` en la versión 8.13.0; antes de esta versión, era necesario un casting a `long` al pasarlos a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.17.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un `CURLcode` que indica éxito o error.

`CURLE_OK` (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).

VEA TAMBIÉN

CURLOPT_PROXY_SSLVERSION(3), CURLOPT_SSLVERSION(3), CURLOPT_SSL_OPTIONS(3)
