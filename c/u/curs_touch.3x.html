curs_touch(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_touch(3X) Llamadas a la biblioteca curs_touch(3X)

NOMBRE

touchwin, touchline, untouchwin, wtouchln, is_linetouched, is_wintouched - controlar la actualización de la salida de la terminal en una ventana de curses

SINOPSIS

#include <curses.h>
int touchline(WINDOW *win, int start, int count);
int touchwin(WINDOW *win);
int wtouchln(WINDOW *win, int y, int n, int changed);
int untouchwin(WINDOW *win);
bool is_linetouched(WINDOW *win, int line);
bool is_wintouched(WINDOW *win);

DESCRIPCIÓN

Las rutinas touchwin y touchline descartan toda la información de optimización sobre qué partes de la ventana han sido tocadas, fingiendo que toda la ventana ha sido dibujada. Esto a veces es necesario cuando se usan ventanas superpuestas, ya que un cambio en una ventana afecta a la otra ventana, pero los registros de qué líneas han sido cambiadas en la otra ventana no reflejan el cambio. La rutina touchline solo finge que se han cambiado count líneas, comenzando por la línea start.

La rutina untouchwin marca todas las líneas de la ventana como no modificadas desde la última llamada a wrefresh.

La rutina wtouchln hace que n líneas en la ventana, comenzando en la línea y, parezcan haber sido cambiadas (changed=1) o no (changed=0) desde la última llamada a wrefresh.

Las rutinas is_linetouched y is_wintouched devuelven TRUE si la línea/ventana especificada fue modificada desde la última llamada a wrefresh; de lo contrario, devuelven FALSE. Además, is_linetouched devuelve ERR si line no es válida para la ventana dada.

VALOR DE RETORNO

Todas las rutinas devuelven el entero ERR en caso de error y un valor entero distinto de ERR en caso de éxito, a menos que se indique lo contrario en las descripciones de rutina anteriores.

X/Open Curses no especifica condiciones de error. En esta implementación

is_linetouched
devuelve un error si el puntero de la ventana es nulo, o si el número de línea está fuera de los límites de la ventana.
La constante ERR es distinta de TRUE y FALSE, que son los valores de retorno normales de esta función. Debido a que la función devuelve un bool, devolver ERR (que no es ni TRUE ni FALSE) puede no ser compatible con el compilador.
Para proporcionar comprobación de errores y también para coincidir con el prototipo de función X/Open, ERR es proporcionado por una macro llamada is_linetouched. La función real devuelve FALSE cuando detecta un error.
wtouchln
devuelve un error si el puntero de la ventana es nulo, o si el número de línea está fuera de los límites de la ventana.

NOTAS

Todas estas rutinas, excepto wtouchln, pueden ser macros.

PORTABILIDAD

Estas funciones fueron introducidas por SVr4. El archivo de cabecera curses de Solaris, por ejemplo, define tanto una función real como una macro para cada una. Las macros dan el mismo resultado que las funciones reales. SVr4 curses no comprueba el parámetro de ventana win para asegurarse de que no sea NULL; de lo contrario, esta implementación se comporta igual que SVr4.

X/Open Curses, Issue 4 describe estas funciones, pero no define condiciones de error.
