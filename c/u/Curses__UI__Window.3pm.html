Curses::UI::Window(3) Documentación de Perl aportada por el usuario Curses::UI::Window(3)

NOMBRE

Curses::UI::Window - Crea y manipula widgets de ventana

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container   
           |
           +----Curses::UI::Window

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add(
    'window_id', 'Window',
    %options,
);

DESCRIPCIÓN

Curses::UI::Window es un widget de ventana. Se puede añadir a una instancia de Curses::UI. Después, la ventana se puede llenar con otros widgets para crear una ventana de aplicación. Para obtener información sobre cómo llenar la ventana con widgets, consulte Curses::UI::Container.

OPCIONES ESTÁNDAR

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

Para una explicación de estas opciones estándar, consulte Curses::UI::Widget.

OPCIONES ESPECÍFICAS DEL WIDGET

•
-centered < BOOLEAN >

Una ventana puede dibujarse automáticamente en el centro de la pantalla. Para habilitar esta opción, use un valor verdadero y para deshabilitarla, use un valor falso. El valor predeterminado es no centrar una ventana. Ejemplo:

$cui->add('mywindow', 'Window', -centered => 1);

MÉTODOS

  • new ( OPCIONES )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )
  • onFocus ( CODEREF )
  • onBlur ( CODEREF )
  • intellidraw ( )

    Estos son métodos estándar. Consulte Curses::UI::Widget para obtener una explicación de estos.

  • modalfocus ( )

    Si se llama a este método, la ventana obtendrá foco modal. Esto significa que todos los eventos se enviarán a esta ventana. Al llamar al método loose_focus, la ventana perderá su foco.

  • loose_focus ( )

    Este método hará que la ventana pierda su foco (usando este método también puede hacer que una ventana con foco modal pierda su foco).
