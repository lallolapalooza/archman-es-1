curl_multi_init(3)

Paquete: curl

Licencias: MIT

curl_multi_init(3) Manual de funciones de la biblioteca curl_multi_init(3)

NOMBRE

curl_multi_init - crear un manejador múltiple

SINOPSIS

#include <curl/curl.h>
CURLM *curl_multi_init();

DESCRIPCIÓN

Esta función devuelve un puntero a un manejador CURLM que se utilizará como entrada para todas las demás funciones múltiples, a veces denominado manejador múltiple en algunos lugares de la documentación. Esta llamada de inicialización DEBE tener una llamada correspondiente a curl_multi_cleanup(3) cuando la operación se complete.

Por defecto, varias cachés se almacenan y se mantienen en el manejador múltiple: caché DNS, pool de conexiones, caché de ID de sesión TLS y caché de certificados CA TLS. Todas las transferencias que utilizan el mismo manejador múltiple comparten estas cachés.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  /* inicializar una pila múltiple */
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init();
  /* añadir transferencias individuales */
  curl_multi_add_handle(multi, curl);
  curl_multi_add_handle(multi, curl2);
}

DISPONIBILIDAD

Añadido en curl 7.9.6

VALOR DE RETORNO

Si esta función devuelve NULL, algo salió mal y no puedes usar las otras funciones de curl.

VER TAMBIÉN

curl_easy_init(3), curl_global_init(3), curl_multi_add_handle(3), curl_multi_cleanup(3), curl_multi_get_handles(3)
