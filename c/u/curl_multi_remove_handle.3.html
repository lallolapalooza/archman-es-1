curl_multi_remove_handle(3)

Paquete: curl

Licencias: MIT

curl_multi_remove_handle(3) Manual de funciones de la biblioteca curl_multi_remove_handle(3)

NOMBRE

curl_multi_remove_handle - eliminar un manejador easy de una sesión multi

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_remove_handle(CURLM *multi_handle, CURL *easy_handle);

DESCRIPCIÓN

Elimina el easy_handle proporcionado del multi_handle. Esto hace que el manejador easy especificado se elimine del control de este manejador multi.

Cuando el manejador easy ha sido eliminado de una pila multi, es perfectamente legal invocar de nuevo curl_easy_perform(3) en este manejador easy.

Eliminar un manejador easy mientras está en uso es perfectamente legal y detiene efectivamente la transferencia en curso que involucra a ese manejador easy. Todos los demás manejadores easy y transferencias permanecen sin afectar.

Está bien eliminar un manejador en cualquier momento durante una transferencia, simplemente no desde dentro de ninguna función de devolución de llamada de libcurl.

Eliminar un manejador easy del manejador multi antes de que la transferencia correspondiente se complete podría hacer que libcurl cierre la conexión, si el estado de la misma y el controlador de protocolo interno lo consideran necesario. De lo contrario, libcurl mantiene la conexión activa en el grupo de conexiones asociado con el manejador multi, listo para ser reutilizado para una transferencia futura que utilice este manejador multi.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURLM *multi = curl_multi_init();
  int queued = 0;
  /* cuando un manejador easy ha completado, elimínalo */
  CURLMsg *msg = curl_multi_info_read(multi, &queued);
  if(msg) {
    if(msg->msg == CURLMSG_DONE) {
      /* una transferencia terminó */
      fprintf(stderr, "Transferencia completada\n");
      curl_multi_remove_handle(multi, msg->easy_handle);
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.6

VALOR DE RETORNO

Esta función devuelve un CURLMcode que indica el éxito o el error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
