NAME

cups - Sistema de impresión de Berkeley de código abierto

DESCRIPTION

CUPS es un sistema de impresión modular de código abierto que permite a un host actuar como un servidor de impresión. CUPS está diseñado para ser compatible con el sistema de impresión de Berkeley, pero también ha añadido muchas características nuevas. CUPS permite que varios hosts compartan una o más impresoras. Puede configurar impresoras locales, impresoras de red (incluyendo impresoras compartidas por otros sistemas CUPS) y una amplia variedad de impresoras remotas.

CUPS incluye el demonio de escucha de red cupsd, el front-end de línea de comandos lp, el back-end de línea de comandos lpadmin y muchas otras utilidades relacionadas con la impresión.

Los trabajos de impresión se envían a CUPS utilizando el comando lp o lpr y se procesan en cola y se envían a la impresora seleccionada por el demonio cupsd.

CUPS admite el protocolo IPP (Internet Printing Protocol). El protocolo utilizado para el reenvío de trabajos de impresión a servidores de impresión remotos puede ser IPP, IPPS, SMB o LPD.

CUPS incluye soporte para la mayoría de las impresoras PostScript y PCL, así como soporte para miles de impresoras no PostScript a través de formatos de archivo como PDF, PWG, HELLO y NCP.

CUPS proporciona una interfaz web para la administración del sistema de impresión. Puede acceder a esta interfaz web abriendo un navegador web y navegando a http://localhost:631/.

ENVIRONMENT

CUPS utiliza varias variables de entorno para controlar su comportamiento, incluyendo:

  • CUPS_SERVER: Especifica la dirección del servidor CUPS a utilizar.
  • CUPS_CONFIG_DIR: Especifica el directorio de configuración de CUPS.
  • CUPS_SPOOL_DIR: Especifica el directorio de trabajos de impresión en cola.
  • CUPS_LOG_DIR: Especifica el directorio de registro de CUPS.

FILES

  • /etc/cups/cupsd.conf: Archivo de configuración del demonio CUPS.
  • /etc/cups/printers.conf: Archivo de configuración de impresoras.
  • /var/spool/cups/: Directorio de trabajos de impresión en cola.
  • /var/log/cups/: Directorio de registro de CUPS.

CONFORMING TO

CUPS implementa el estándar Internet Printing Protocol (IPP). También es compatible con el sistema de impresión de Berkeley.

NOTES

Para obtener más información sobre CUPS, consulte la documentación oficial de CUPS en https://openprinting.github.io/cups/.
