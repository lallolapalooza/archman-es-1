curl_multi_assign(3)

Paquete: curl

Licencias: MIT

curl_multi_assign(3) Manual de funciones de la biblioteca curl_multi_assign(3)

NOMBRE

curl_multi_assign - asignar datos a un socket interno

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_assign(CURLM *multi_handle, curl_socket_t sockfd,
                            void *sockptr);

DESCRIPCIÓN

Esta función crea una asociación en el manejador múltiple entre el socket dado y un puntero privado de la aplicación. Esto está diseñado para usos de curl_multi_socket_action(3).

Cuando se establece, el puntero sockptr se pasa a todas las futuras llamadas de socket para el socket específico sockfd.

Si el sockfd dado no está siendo utilizado por libcurl, esta función devuelve un error.

libcurl solo mantiene un único puntero asociado a un socket, por lo que llamar a esta función varias veces para el mismo socket hace que se utilice el último puntero establecido.

La idea aquí es que esta asociación (socket a puntero privado) es algo que casi todas las aplicaciones que usan esta API necesitan y entonces libcurl puede hacerlo ya que tiene la funcionalidad necesaria.

Es aceptable llamar a esta función desde las funciones de callback múltiples.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

int main(void)
{
  CURLM *multi = curl_multi_init();
  int private = 123;
  curl_socket_t fd = 0; /* descriptor de archivo para asociar nuestros datos con */
  /* hacer que nuestro puntero struct se asocie con el socket fd */
  CURLMcode mc = curl_multi_assign(multi, fd, &private);
  if(mc)
    printf("error: %s\n", curl_multi_strerror(mc));
}

USO TÍPICO

En una aplicación típica, se asigna una estructura o al menos se utilizan datos semi-dinámicos para cada socket por el que debemos esperar una acción cuando se utiliza el enfoque de curl_multi_socket_action(3).

Cuando nuestro callback de socket es llamado por libcurl y nos informamos de otro socket al que esperar, podemos usar curl_multi_assign(3) para señalar los datos particulares para que cuando recibamos actualizaciones sobre este mismo socket nuevamente, no tengamos que encontrar la estructura asociada con este socket por nosotros mismos.

DISPONIBILIDAD

Añadido en curl 7.15.5

VALOR DE RETORNO

Esta función devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
