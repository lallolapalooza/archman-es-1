NOMBRE

curl_easy_upkeep - mantener vivas las conexiones existentes

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_upkeep(CURL *handle);

DESCRIPCIÓN

Algunos protocolos tienen mecanismos de "mantenimiento de conexión". Estos mecanismos suelen enviar algo de tráfico en las conexiones existentes para mantenerlas vivas; esto puede evitar que las conexiones se cierren debido a firewalls demasiado celosos, por ejemplo.

Para HTTP/2 tenemos un mecanismo de mantenimiento: cuando se supera el intervalo de mantenimiento de conexión y se llama a curl_easy_upkeep(3), se envía un paquete PING de HTTP/2 en la conexión.

Para MQTT, el intervalo de mantenimiento define cuándo enviar solicitudes de ping para evitar que el servidor desconecte.

Esta función debe llamarse explícitamente para realizar el trabajo de mantenimiento. El intervalo de mantenimiento de conexión se establece con CURLOPT_UPKEEP_INTERVAL_MS(3).

Si llama a esta función en un handle fácil que utiliza una caché de conexión compartida, el mantenimiento se realizará en las conexiones de esa caché, incluso si esas conexiones nunca fueron utilizadas por el handle fácil. (Añadido en 8.10.0)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* Establecer una conexión a un servidor HTTP/2. */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Establecer el intervalo en 30000ms / 30s */
    curl_easy_setopt(curl, CURLOPT_UPKEEP_INTERVAL_MS, 30000L);
    curl_easy_perform(curl);
    /* Realizar más trabajo aquí. */
    /* Mientras la conexión se mantiene abierta, se puede llamar a curl_easy_upkeep().
       Si se llama a curl_easy_upkeep() y el tiempo desde el último mantenimiento
       supera el intervalo, se enviará un PING de HTTP/2. */
    curl_easy_upkeep(curl);
    /* Realizar más trabajo aquí. */
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.62.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estaba bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el buffer de errores cuando se devuelve un valor distinto de cero.
