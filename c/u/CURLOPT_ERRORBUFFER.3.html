CURLOPT_ERRORBUFFER(3)

Paquete: curl

Licencias: MIT

CURLOPT_ERRORBUFFER(3) Manual de funciones de la biblioteca CURLOPT_ERRORBUFFER(3)

NOMBRE

CURLOPT_ERRORBUFFER - buffer de errores para mensajes de error

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ERRORBUFFER, char *buf);

DESCRIPCIÓN

Pase un puntero a char a un buffer que libcurl puede usar para almacenar mensajes de error legibles por humanos en caso de fallos o problemas. Esto puede ser más útil que solo el código de retorno de curl_easy_perform(3) y funciones relacionadas.

El buffer debe tener al menos CURL_ERROR_SIZE bytes de tamaño.

Debe mantener el buffer asociado disponible hasta que libcurl ya no lo necesite. No hacerlo podría causar un comportamiento extraño o incluso bloqueos. libcurl podría necesitarlo hasta que llame a curl_easy_cleanup(3) o establezca la misma opción nuevamente para usar un puntero diferente.

No confíe en el contenido del buffer a menos que se haya devuelto un código de error. Desde la versión 7.60.0, libcurl inicializa el contenido del buffer de errores a una cadena vacía antes de realizar la transferencia. En versiones anteriores, si se devolvió un código de error pero no había detalles del error, el buffer no se tocó.

No intente establecer el contenido del buffer usted mismo, incluso en las devoluciones de llamada que pueda escribir y que libcurl pueda llamar. La biblioteca puede sobrescribir el buffer después de que su devolución de llamada regrese.

Considere CURLOPT_VERBOSE(3) y CURLOPT_DEBUGFUNCTION(3) para depurar y rastrear mejor por qué ocurren los errores.

Usar esta opción varias veces hace que el último puntero establecido anule los anteriores. Establézcalo en NULL para deshabilitar su uso nuevamente.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

#include <string.h> /* para strlen() */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    char errbuf[CURL_ERROR_SIZE];
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* proporcionar un buffer para almacenar errores */
    curl_easy_setopt(curl, CURLOPT_ERRORBUFFER, errbuf);
    /* establecer el buffer de error como vacío antes de realizar una solicitud */
    errbuf[0] = 0;
    /* realizar la solicitud */
    res = curl_easy_perform(curl);
    /* si la solicitud no se completó correctamente, mostrar la información de
    error. si no se escribió información de error detallada en errbuf,
    mostrar la información más genérica de curl_easy_strerror en su lugar.
    */
    if(res != CURLE_OK) {
      size_t len = strlen(errbuf);
      fprintf(stderr, "\nlibcurl: (%d) ", res);
      if(len)
        fprintf(stderr, "%s%s", errbuf,
                ((errbuf[len - 1] != '\n') ? "\n" : ""));
      else
        fprintf(stderr, "%s\n", curl_easy_strerror(res));
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo OK, distinto de cero significa que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_DEBUGFUNCTION(3), CURLOPT_VERBOSE(3), curl_easy_strerror(3), curl_multi_strerror(3), curl_share_strerror(3), curl_url_strerror(3)
