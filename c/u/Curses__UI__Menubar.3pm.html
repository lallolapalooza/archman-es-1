Curses::UI::Menubar(3) Documentación aportada por el usuario de Perl Curses::UI::Menubar(3)

NOMBRE

Curses::UI::Menubar - Crea y manipula widgets de barra de menú

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Menubar

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
# Define la estructura de datos del menú.
my $menu_data = [....]; 
my $menu = $cui->add( 
    'menu', 'Menubar',
    -menu => $menu_data
);
$menu->focus();

DESCRIPCIÓN

Esta clase se puede utilizar para añadir una barra de menú a Curses::UI. Esta barra de menú puede contener una jerarquía completa de submenús. Se ve (remotamente :-) así:

-------------------------------------
menú1 | menú2 | menú3 | ....
-------------------------------------
      +-------------+ 
      |ítem de menú 1|
      |ítem de menú 2| +--------------+
      |ítem de menú 3 >>||submenú ítem 1|
      |ítem de menú 4| |submenú ítem 2|
      +-------------+|submenú ítem 3| 
                     |submenú ítem 4| 
                     |submenú ítem 5| 
                     +--------------+

Consulta el ejemplo demo-Curses::UI::Menubar en la distribución para una breve demostración.

OPCIONES ESTÁNDAR

Esta clase no utiliza ninguna de las opciones estándar que proporciona Curses::UI::Widget.

OPCIONES ESPECÍFICAS DEL WIDGET

Solo hay una opción: -menu. El valor de esta opción es un ARRAYREF. Este ARRAYREF se comporta exactamente igual que el descrito en Curses::UI::MenuListbox. La diferencia es que, para el menú principal, solo se usarán -submenu. Estructura de datos de ejemplo:

my $menu1 = [
    { -label => 'opción 1', -value => '1-1' },
    { -label => 'opción 2', -value => '1-2' },
    { -label => 'opción 3', -value => '1-3' },
];
my $menu2 = [
    { -label => 'opción 1', -value => \&sel1 },
    { -label => 'opción 2', -value => \&sel2 },
    { -label => 'opción 3', -value => \&sel3 },
];
my $submenu = [
    { -label => 'subopción 1', -value => '3-3-1' },
    { -label => 'subopción 2', -callback=> \&do_it },
];
my $menu3 = [
    { -label => 'opción 1', -value => \&sel2 },
    { -label => 'opción 2', -value => \&sel3 },
    { -label => 'submenú 1', -submenu => $submenu },
];
my $menu = [
    { -label => 'menú 1', -submenu => $menu1 },
    { -label => 'menú 2', -submenu => $menu2 }
    { -label => 'menú 3', -submenu => $menu3 }
];

ASIGNACIONES POR DEFECTO

  • <escape>

    Llama a la rutina 'escape'. Esto hará que la barra de menú pierda el foco y devuelva el valor 'ESCAPE' a la rutina que llama.

  • <tab>

    Llama a la rutina 'return'. Esto hará que la barra de menú pierda el foco y devuelva el valor 'LOOSE_FOCUS' a la rutina que llama.

  • <cursor-down>, <j>, <enter>

    Llama a la rutina 'pulldown'. Esto abrirá el menulistbox para el menú actual y le dará el foco a ese menulistbox. Lo que sucede después de que el menulistbox pierda el foco depende del valor de retorno del mismo:

    * el valor 'CURSOR_LEFT'

    Llama a la rutina 'cursor-left' y después llama
a la rutina 'pulldown'. Así se abrirá el
menulistbox para el menú anterior.

    * el valor 'CURSOR_RIGHT'

    Llama a la rutina 'cursor-right' y después llama
a la rutina 'pulldown'. Así se abrirá el
menulistbox para el siguiente menú.

    * el valor 'LOOSE_FOCUS'

    La barra de menú conservará el foco, pero no
se abrirá ningún menulistbox.

    * el valor 'ESCAPE'

    La barra de menú perderá el foco y devolverá el
valor 'ESCAPE' a la rutina que llama.

    * Una referencia de CÓDIGO

    Se ejecutará el código, la barra de menú perderá el
foco y el valor de retorno del CÓDIGO se
devolverá a la rutina que llama.

    * Cualquier otro valor

    La barra de menú perderá el foco y el valor se
devolverá a la rutina que llama.
  • <cursor-left>, <h>

    Llama a la rutina 'cursor-left'. Esto seleccionará el menú anterior. Si ya está seleccionado el primer menú, se seleccionará el último menú.

  • <cursor-right>, <l>

    Llama a la rutina 'cursor-right'. Esto seleccionará el siguiente menú. Si ya está seleccionado el último menú, se seleccionará el primer menú.
