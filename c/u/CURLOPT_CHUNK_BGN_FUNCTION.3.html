CURLOPT_CHUNK_BGN_FUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_CHUNK_BGN_FUNCTION(3) Manual de funciones de biblioteca CURLOPT_CHUNK_BGN_FUNCTION(3)

NOMBRE

CURLOPT_CHUNK_BGN_FUNCTION - función de retorno de llamada antes de una transferencia con coincidencia de comodín FTP

SINOPSIS

#include <curl/curl.h>
struct curl_fileinfo {
  char *filename;
  curlfiletype filetype;
  time_t time;   /* siempre cero */
  unsigned int perm;
  int uid;
  int gid;
  curl_off_t size;
  long int hardlinks;
  struct {
    /* Si alguno de estos campos no es NULL, apunta a b_data. */
    char *time;
    char *perm;
    char *user;
    char *group;
    char *target; /* apunta al nombre de archivo de destino de un enlace simbólico */
  } strings;
  unsigned int flags;
  /* utilizado internamente */
  char *b_data;
  size_t b_size;
  size_t b_used;
};
long chunk_bgn_callback(const void *transfer_info, void *ptr,
                        int remains);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CHUNK_BGN_FUNCTION,
                          chunk_bgn_callback);

DESCRIPCIÓN

Pase un puntero a su función de retorno de llamada, que debe coincidir con el prototipo mostrado arriba.

Esta función de retorno de llamada es llamada por libcurl antes de que se vaya a transferir una parte del flujo (si la transferencia admite fragmentos).

El puntero transfer_info apunta a una estructura curl_fileinfo con detalles sobre el archivo que está a punto de transferirse.

Esta función de retorno de llamada solo tiene sentido cuando se utiliza la opción CURLOPT_WILDCARDMATCH(3) por ahora.

El destino del parámetro transfer_info es una estructura "dependiente de la característica". Para la descarga de comodines FTP, el destino es la estructura curl_fileinfo (ver curl/curl.h). El parámetro ptr es un puntero proporcionado por CURLOPT_CHUNK_DATA(3). El parámetro remains contiene el número de fragmentos restantes por transferencia. Si la característica no está disponible, el parámetro tiene valor cero.

Devuelve CURL_CHUNK_BGN_FUNC_OK si todo está bien, CURL_CHUNK_BGN_FUNC_SKIP si desea omitir el fragmento concreto o CURL_CHUNK_BGN_FUNC_FAIL para indicar a libcurl que se detenga si ocurrió algún error.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

#include <stdio.h>
struct callback_data {
   FILE *output;
};
static long file_is_coming(struct curl_fileinfo *finfo,
                           void *ptr,
                           int remains)
{
  struct callback_data *data = ptr;
  printf("%3d %40s %10luB ", remains, finfo->filename,
         (unsigned long)finfo->size);
  switch(finfo->filetype) {
  case CURLFILETYPE_DIRECTORY:
    printf(" DIR\n");
    break;
  case CURLFILETYPE_FILE:
    printf("FILE ");
    break;
  default:
    printf("OTHER\n");
    break;
  }
  if(finfo->filetype == CURLFILETYPE_FILE) {
    /* no transferir archivos >= 50B */
    if(finfo->size > 50) {
      printf("SKIPPED\n");
      return CURL_CHUNK_BGN_FUNC_SKIP;
    }
    data->output = fopen(finfo->filename, "wb");
    if(!data->output) {
      return CURL_CHUNK_BGN_FUNC_FAIL;
    }
  }
  return CURL_CHUNK_BGN_FUNC_OK;
}
int main()
{
  /* datos para el callback */
  struct callback_data callback_info;
  CURL *curl = curl_easy_init();
  /* se llama al callback antes de que comience la descarga del archivo concreto */
  curl_easy_setopt(curl, CURLOPT_CHUNK_BGN_FUNCTION, file_is_coming);
  curl_easy_setopt(curl, CURLOPT_CHUNK_DATA, &callback_info);
}

DISPONIBILIDAD

Añadido en curl 7.21.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero significa que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
