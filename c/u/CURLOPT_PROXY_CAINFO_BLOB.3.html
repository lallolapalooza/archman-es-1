CURLOPT_PROXY_CAINFO_BLOB(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_CAINFO_BLOB(3) Manual de funciones de la biblioteca CURLOPT_PROXY_CAINFO_BLOB(3)

NOMBRE

CURLOPT_PROXY_CAINFO_BLOB - paquete de Autoridad de Certificación (CA) del proxy en formato PEM

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CAINFO_BLOB,
                          struct curl_blob *stblob);

DESCRIPCIÓN

Esta opción es para conectarse a un proxy HTTPS, no a un servidor HTTPS.

Pase un puntero a una estructura curl_blob, que contiene información (puntero y tamaño) sobre un bloque de memoria con datos binarios de contenido codificado en PEM que contiene uno o más certificados para verificar el proxy HTTPS.

Si el blob se inicializa con el miembro flags de la estructura curl_blob establecido en CURL_BLOB_COPY, la aplicación no tiene que mantener el buffer disponible después de configurarlo.

Si CURLOPT_PROXY_SSL_VERIFYPEER(3) es cero y se evita verificar el certificado del servidor, CURLOPT_PROXY_CAINFO_BLOB(3) no es necesario.

Esta opción anula CURLOPT_PROXY_CAINFO(3).

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL, Schannel y rustls

EJEMPLO

#include <string.h> /* para strlen */
extern char *strpem; /* strpem debe apuntar a una cadena PEM */
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* usando un proxy HTTPS */
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:443");
    blob.data = strpem;
    blob.len = strlen(strpem);
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_PROXY_CAINFO_BLOB, &blob);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.77.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
