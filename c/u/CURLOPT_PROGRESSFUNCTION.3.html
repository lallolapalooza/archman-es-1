CURLOPT_PROGRESSFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROGRESSFUNCTION(3) Manual de funciones de la biblioteca CURLOPT_PROGRESSFUNCTION(3)

NOMBRE

CURLOPT_PROGRESSFUNCTION - función de devolución de llamada del medidor de progreso

SINOPSIS

#include <curl/curl.h>
int progress_callback(void *clientp,
                      double dltotal,
                      double dlnow,
                      double ultotal,
                      double ulnow);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROGRESSFUNCTION,
                          progress_callback);

DESCRIPCIÓN

Pase un puntero a su función de devolución de llamada, que debe coincidir con el prototipo que se muestra arriba.

Esta opción está obsoleta y animamos a los usuarios a utilizar la nueva CURLOPT_XFERINFOFUNCTION(3) en su lugar, si pueden.

Esta función es llamada por libcurl en lugar de su equivalente interno con un intervalo frecuente. Mientras se transfieren datos, se invoca con frecuencia, y durante períodos lentos, como cuando no se está transfiriendo nada, puede reducirse a aproximadamente una llamada por segundo.

clientp es el puntero establecido con CURLOPT_PROGRESSDATA(3), no es utilizado por libcurl sino que solo se pasa de la aplicación a la función de devolución de llamada.

La función de devolución de llamada recibe información sobre cuántos datos espera transferir libcurl y ha transferido, en número de bytes. dltotal es el número total de bytes que libcurl espera descargar en esta transferencia. dlnow es el número de bytes descargados hasta ahora. ultotal es el número total de bytes que libcurl espera cargar en esta transferencia. ulnow es el número de bytes cargados hasta ahora.

Los valores de argumento desconocidos/no utilizados que se pasan a la función de devolución de llamada se establecen en cero (por ejemplo, si solo descarga datos, el tamaño de carga sigue siendo 0). Muchas veces, la función de devolución de llamada se llama una o más veces primero, antes de que conozca los tamaños de los datos, por lo que un programa debe estar hecho para manejar eso.

Devuelva cero de la función de devolución de llamada si todo está bien.

Si su función de devolución de llamada devuelve CURL_PROGRESSFUNC_CONTINUE, hace que libcurl continúe ejecutando la función de progreso predeterminada.

Devuelva 1 de esta función de devolución de llamada para hacer que libcurl abandone la transferencia y devuelva CURLE_ABORTED_BY_CALLBACK.

Si transfiere datos con la interfaz multi, esta función no se llama durante períodos de inactividad a menos que llame a la función de libcurl apropiada que realiza transferencias.

CURLOPT_NOPROGRESS(3) debe establecerse en 0 para que esta función sea realmente llamada.

PREDETERMINADO

NULL. libcurl tiene un medidor de progreso interno. Rara vez es querido por los usuarios.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

struct progress {
  char *private;
  size_t size;
};
static int progress_callback(void *clientp,
                             double dltotal,
                             double dlnow,
                             double ultotal,
                             double ulnow)
{
  struct progress *memory = clientp;
  printf("private: %p\n", memory->private);
  /* usar los valores */
  return 0; /* todo está bien */
}
int main(void)
{
  struct progress data;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* pasar struct a la función de devolución de llamada  */
    curl_easy_setopt(curl, CURLOPT_PROGRESSDATA, &data);
    curl_easy_setopt(curl, CURLOPT_PROGRESSFUNCTION, progress_callback);
    curl_easy_perform(curl);
  }
}

OBSOLETO

Obsoleto desde la versión 7.32.0.

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, véase libcurl-errors(3).

VER TAMBIÉN
