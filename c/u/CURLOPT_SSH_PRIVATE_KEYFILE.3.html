CURLOPT_SSH_PRIVATE_KEYFILE(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSH_PRIVATE_KEYFILE(3) Manual de funciones de la biblioteca CURLOPT_SSH_PRIVATE_KEYFILE(3)

NOMBRE

CURLOPT_SSH_PRIVATE_KEYFILE - archivo de clave privada para autenticación SSH

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_PRIVATE_KEYFILE,
                          char *filename);

DESCRIPCIÓN

Pase un puntero a un puntero de carácter que apunte a un nombre_de_archivo para su clave privada. Si no se utiliza, libcurl utiliza por defecto $HOME/.ssh/id_rsa o $HOME/.ssh/id_dsa si la variable de entorno HOME está configurada, y en el directorio actual si HOME no está configurada.

Si el archivo está protegido por contraseña, establezca la contraseña con CURLOPT_KEYPASSWD(3).

La biblioteca SSH deriva la clave pública de esta clave privada cuando es posible. Si la biblioteca SSH no puede derivar la clave pública de la privada y no se proporciona ninguna pública con CURLOPT_SSH_PUBLIC_KEYFILE(3), la transferencia falla.

La aplicación no tiene que mantener la cadena disponible después de configurar esta opción.

PREDETERMINADO

Como se explicó anteriormente

PROTOCOLOS

Esta funcionalidad afecta a scp y sftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/file");
    curl_easy_setopt(curl, CURLOPT_SSH_PRIVATE_KEYFILE,
                     "/home/clarkkent/.ssh/id_rsa");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "password");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.16.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo correcto, cualquier valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
