CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256(3) Manual de funciones de biblioteca CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256(3)

NOMBRE

CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256 - SHA256 hash de la clave pública del servidor SSH

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256,
                          char *sha256);

DESCRIPCIÓN

Pase un puntero a un carácter que apunte a una cadena que contenga un hash SHA256 codificado en Base64 de la clave pública del host remoto. La transferencia falla si el hash dado no coincide con el hash que proporciona el host remoto.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para volver a deshabilitar su uso.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a scp y sftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/file");
    curl_easy_setopt(curl, CURLOPT_SSH_HOST_PUBLIC_KEY_SHA256,
                     "NDVkMTQxMGQ1ODdmMjQ3MjczYjAyOTY5MmRkMjVmNDQ=");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

NOTAS

Requiere el backend libssh2.

DISPONIBILIDAD

Añadido en curl 7.80.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_SSH_AUTH_TYPES(3), CURLOPT_SSH_HOST_PUBLIC_KEY_MD5(3), CURLOPT_SSH_PUBLIC_KEYFILE(3)
