NOMBRE

cups-files.conf - archivo de configuración de archivos y directorios para cups

DESCRIPCIÓN

El archivo cups-files.conf configura los archivos y directorios utilizados por el planificador de CUPS, cupsd(8). Normalmente se encuentra en el directorio /etc/cups .

Cada línea del archivo puede ser una directiva de configuración, una línea en blanco o un comentario. Las directivas de configuración suelen constar de un nombre y uno o más valores separados por espacios en blanco. El nombre y los valores de la directiva de configuración no distinguen entre mayúsculas y minúsculas. Las líneas de comentario comienzan con el carácter #.

DIRECTIVAS

El planificador cupsd(8)entiende las siguientes directivas:

AccessLog
AccessLog nombre-de-archivo
AccessLog stderr
AccessLog syslog
Define el nombre de archivo del registro de acceso. Especificar un nombre de archivo en blanco desactiva la generación del registro de acceso. El valor "stderr" hace que las entradas del registro se envíen al archivo de error estándar cuando el planificador se ejecuta en primer plano, o al demonio de registro del sistema cuando se ejecuta en segundo plano. El valor "syslog" hace que las entradas del registro se envíen al demonio de registro del sistema. El nombre del servidor puede incluirse en los nombres de archivo utilizando la cadena "%s", por ejemplo: 
    AccessLog /var/log/cups/%s-access_log
El valor predeterminado es "/var/log/cups/access_log".
CacheDir directorio
Especifica el directorio a utilizar para los archivos temporales de larga duración (caché). El valor predeterminado es "/var/spool/cups/cache" o "/var/cache/cups" dependiendo de la plataforma.
ConfigFilePerm modo
Especifica los permisos para todos los archivos de configuración que escribe el planificador. El valor predeterminado es "0644" en macOS y "0640" en todos los demás sistemas operativos.

Nota: Los permisos del archivo printers.conf están actualmente enmascarados para permitir solo el acceso desde el usuario del planificador (normalmente root). Esto se hace porque las URI de los dispositivos de impresión a veces contienen información de autenticación sensible que no debería ser de conocimiento general en el sistema. No hay forma de desactivar esta función de seguridad.

CreateSelfSignedCerts yes
CreateSelfSignedCerts no
Especifica si el planificador crea automáticamente certificados autofirmados para las conexiones de clientes que utilizan TLS. El valor predeterminado es yes.
DataDir ruta
Especifica el directorio donde se pueden encontrar los archivos de datos. El valor predeterminado es normalmente "/usr/share/cups".
DocumentRoot directorio
Especifica el directorio raíz para el contenido de la interfaz web de CUPS. El valor predeterminado es normalmente "/usr/share/doc/cups".
ErrorLog
ErrorLog nombre-de-archivo
ErrorLog stderr
ErrorLog syslog
Define el nombre de archivo del registro de errores. Especificar un nombre de archivo en blanco desactiva la generación del registro de errores. El valor "stderr" hace que las entradas del registro se envíen al archivo de error estándar cuando el planificador se ejecuta en primer plano, o al demonio de registro del sistema cuando se ejecuta en segundo plano. El valor "syslog" hace que las entradas del registro se envíen al demonio de registro del sistema. El nombre del servidor puede incluirse en los nombres de archivo utilizando la cadena "%s", por ejemplo: 
    ErrorLog /var/log/cups/%s-error_log
El valor predeterminado es "/var/log/cups/error_log".
FatalErrors none
FatalErrors all -tipo [ ... -tipo ]
FatalErrors tipo [ ... tipo ]
Especifica qué errores son fatales, provocando la salida del planificador. El valor predeterminado es "config". Las cadenas tipo son:
none
Ningún error es fatal.
all
Todos los errores siguientes son fatales.
browse
Los errores de inicialización de la exploración son fatales, por ejemplo, fallos en las conexiones al demonio DNS-SD.
config
Los errores de sintaxis del archivo de configuración son fatales.
listen
Los errores de Listen o Port son fatales, excepto para fallos de IPv6 en las direcciones de bucle o "any".
log
Los errores de creación o escritura de archivos de registro son fatales.
permissions
Los permisos incorrectos de los archivos de inicio son fatales, por ejemplo, archivos de certificado y clave TLS compartidos con permisos de lectura para todos los usuarios.
Group nombre-o-número-de-grupo
Especifica el nombre o ID de grupo que se utilizará al ejecutar programas externos. El grupo predeterminado depende del sistema operativo, pero normalmente es "lp" o "nobody".

LogFileGroup nombre-o-número-de-grupo
Especifica el nombre o ID de grupo que se utilizará para los archivos de registro. El grupo predeterminado depende del sistema operativo, pero normalmente es "lp" o "nobody".
LogFilePerm modo
Especifica los permisos de todos los archivos de registro que escribe el planificador. El valor predeterminado es "0644".
PageLog [ nombre-de-archivo ]
PageLog stderr
PageLog syslog
Define el nombre de archivo del registro de páginas. El valor "stderr" hace que las entradas del registro se envíen al archivo de error estándar cuando el planificador se ejecuta en primer plano, o al demonio de registro del sistema cuando se ejecuta en segundo plano. El valor "syslog" hace que las entradas del registro se envíen al demonio de registro del sistema. Especificar un nombre de archivo en blanco desactiva la generación del registro de páginas. El nombre del servidor puede incluirse en los nombres de archivo utilizando la cadena "%s", por ejemplo: 
    PageLog /var/log/cups/%s-page_log
El valor predeterminado es "/var/log/cups/page_log".
PassEnv variable [ ... variable ]
Pasa la(s) variable(s) de entorno especificada(s) a los procesos secundarios. Nota: las variables de entorno estándar de los filtros y backends de CUPS no pueden ser anuladas utilizando esta directiva.
PeerCred off
PeerCred on
PeerCred root-only
Especifica si se utilizan las credenciales del par para la autorización al comunicarse a través del socket de dominio UNIX. Cuando es on, se aceptan las credenciales del par de cualquier usuario para la autorización. El valor off desactiva por completo el uso de las credenciales del par, mientras que el valor root-only permite las credenciales del par solo para el usuario root. Nota: por razones de seguridad, la configuración on se reduce a root-only para la autorización de las peticiones PUT.
RemoteRoot nombre-de-usuario
Especifica el nombre de usuario que se asocia con los accesos no autenticados de clientes que dicen ser el usuario root. El valor predeterminado es "remroot".
RequestRoot directorio
Especifica el directorio que contiene los trabajos de impresión y otros datos de solicitudes HTTP. El valor predeterminado es "/var/spool/cups".
Sandboxing relaxed
Sandboxing strict
Especifica el nivel de aislamiento de seguridad que se aplica a los filtros de impresión, backends y otros procesos secundarios del planificador. El valor predeterminado es "strict". Esta directiva actualmente solo se usa/soporta en macOS.
ServerBin directorio
Especifica el directorio que contiene los backends, programas CGI, filtros, programas de ayuda, notificadores y monitores de puerto. El valor predeterminado es "/usr/lib/cups" o "/usr/libexec/cups" dependiendo de la plataforma.
ServerKeychain ruta
Especifica la ubicación de los certificados TLS y las claves privadas. El valor predeterminado es "/Library/Keychains/System.keychain" en macOS y "/etc/cups/ssl" en todos los demás sistemas operativos. macOS utiliza su base de datos de llaveros para almacenar certificados y claves, mientras que otras plataformas utilizan archivos separados en el directorio especificado, *.crt para certificados codificados en PEM y *.key para claves privadas codificadas en PEM.
ServerRoot directorio
Especifica el directorio que contiene los archivos de configuración del servidor. El valor predeterminado es "/etc/cups".
SetEnv variable valor
Establece la variable de entorno especificada para que se pase a los procesos secundarios. Nota: las variables de entorno estándar de filtro y backend de CUPS no se pueden anular utilizando esta directiva.
StateDir directorio
Especifica el directorio que se utilizará para los archivos PID y de certificados locales. El valor predeterminado es "/var/run/cups" o "/etc/cups" dependiendo de la plataforma.
StripUserDomain Yes
StripUserDomain No
Especifica si se debe eliminar el dominio del nombre de usuario durante la autenticación de usuarios locales (por ejemplo, "usuario@ejemplo.com" –> "usuario"). Esta práctica puede ser beneficiosa para mantener la compatibilidad con versiones anteriores de Kerberos. Sin embargo, habilitar esta opción puede tener consecuencias negativas. Puede dar lugar a confusión entre usuarios de dominio y locales con nombres idénticos, lo que podría llevar a la asignación incorrecta de permisos de usuario y a una escalada de permisos no intencionada, creando así un riesgo de seguridad. Por lo tanto, se recomienda evitar el uso de esta opción en la mayoría de los casos.
SyncOnClose Yes
SyncOnClose No
Especifica si el planificador llama a fsync(2) después de escribir los archivos de configuración o estado.
SystemGroup nombre-grupo [ ... nombre-grupo ]
Especifica el(los) grupo(s) a utilizar para la autenticación del grupo @SYSTEM. El valor predeterminado contiene "admin", "lpadmin", "root", "sys" y/o "system".
TempDir directorio
Especifica el directorio donde se almacenan los archivos temporales de corto plazo. El valor predeterminado es "/var/spool/cups/tmp".
User nombre-usuario
Especifica el nombre de usuario o ID que se utiliza al ejecutar programas externos. El valor predeterminado es "lp".

DIRECTIVAS OBSOLETAS

Las siguientes directivas están obsoletas y se eliminarán en una futura versión de CUPS:

FileDevice Yes
FileDevice No
Especifica si se puede utilizar el pseudodispositivo de archivo para nuevas colas de impresión. La URI "file:///dev/null" siempre está permitida. Los dispositivos de archivo no se pueden usar con colas de impresión "raw"; se requiere un archivo PPD. El archivo especificado se sobrescribe con cada trabajo de impresión. La escritura en directorios no está soportada.
Printcap nombre-archivo
Especifica un archivo que se rellena con una lista de colas de impresión locales.
PrintcapFormat bsd
PrintcapFormat plist
PrintcapFormat solaris
Especifica el formato a utilizar para el archivo Printcap. "bsd" es el formato histórico del archivo LPD printcap. "plist" es el formato del archivo plist de Apple. "solaris" es el formato histórico del archivo LPD printcap de Solaris.

NOTAS

El planificador DEBE reiniciarse manualmente después de realizar cambios en el archivo cups-files.conf. En Linux, esto se hace típicamente usando el comando systemctl(8), mientras que en macOS se utiliza el comando launchctl(8) en su lugar.
