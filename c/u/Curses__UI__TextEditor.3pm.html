DESCRIPCIÓ

N

Curses::UI::TextEditor es un widget que se puede utilizar para crear varios tipos diferentes de editores de texto. Estos

son:
  • editor de texto multilínea

    Este es un editor de texto multilínea co

    n características como ajuste de palabr
    • as, longitud máxima de texto y deshacer.
  • editor de texto de una sola línea

    El editor de texto se puede crear como un editor de una sola línea. La mayoría de las características del editor de texto predeterminado permanecerán. Solo las opciones específicas de múltiples líneas no estarán disponibles (como moverse hacia arriba y hacia abajo en el

    texto)
    • .
  • editor de texto de solo lectura

    El editor de texto también se puede usar en mo

    do de solo lectura. En este modo, el editor de
    • texto funcionará como un visor de texto. El u
suario puede recorrer el texto y buscar en él.
