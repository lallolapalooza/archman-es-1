curl_ws_meta(3)

Paquete: curl

Licencias: MIT

curl_ws_meta(3) Manual de funciones de la biblioteca curl_ws_meta(3)

NOMBRE

curl_ws_meta - metadatos de información WebSocket

SINOPSIS

#include <curl/curl.h>
const struct curl_ws_frame *curl_ws_meta(CURL *curl);

DESCRIPCIÓN

Cuando la función de devolución de llamada de escritura (CURLOPT_WRITEFUNCTION(3)) se invoca sobre el tráfico WebSocket recibido, curl_ws_meta(3) puede ser llamada desde dentro de la función de devolución de llamada para proporcionar información adicional sobre el frame actual.

Esta función solo funciona desde dentro de la función de devolución de llamada, y solo al recibir datos WebSocket.

Esta función requiere un manejador `easy` como argumento de entrada para que libcurl sepa de qué transferencia es la consulta, pero como libcurl no proporciona ningún puntero de este tipo a la función de devolución de llamada, las aplicaciones que deseen utilizar curl_ws_meta(3) necesitan pasarlo a la función de devolución de llamada por su cuenta.

struct curl_ws_frame

struct curl_ws_frame {
  int age;
  int flags;
  curl_off_t offset;
  curl_off_t bytesleft;
  size_t len;
};
age
Este campo especifica la antigüedad de esta estructura. Por ahora es siempre cero.
flags
Esta es una máscara de bits con bits individuales establecidos que describen los datos de WebSocket. Ver la lista a continuación.
offset
Cuando este fragmento es una continuación de datos de frame ya entregados, este es el desplazamiento dentro de los datos del frame final donde pertenece esta parte.
bytesleft
Si este no es un fragmento completo, el campo bytesleft informa cuántos bytes adicionales se esperan antes de que este fragmento esté completo.
len
La longitud del fragmento de datos actual.

FLAGS

Los flags de tipo de mensaje (CURLWS_TEXT/BINARY/CLOSE/PING/PONG) son mutuamente excluyentes.

CURLWS_TEXT
Este es un mensaje con datos de texto. Tenga en cuenta que esto marca una diferencia para WebSocket, pero libcurl en sí no realiza ninguna verificación del contenido ni precauciones de que realmente reciba contenido UTF-8 válido.
CURLWS_BINARY
Este es un mensaje con datos binarios.
CURLWS_CLOSE
Este es un mensaje de cierre. No siguen más datos.

Puede contener un entero sin signo de 2 bytes en orden de bytes de red que indica la razón del cierre y puede contener adicionalmente hasta 123 bytes de carga útil textual adicional para un total de no más de 125 bytes. libcurl no verifica que la descripción textual sea UTF-8 válido.

CURLWS_PING
Este es un mensaje ping. Puede contener hasta 125 bytes de texto de carga útil. libcurl no verifica que la carga útil sea UTF-8 válido.

Al recibir un mensaje ping, libcurl responde automáticamente con un mensaje pong, a menos que se establezca el bit CURLWS_NOAUTOPONG o CURLWS_RAW_MODE de CURLOPT_WS_OPTIONS(3).

CURLWS_PONG
Este es un mensaje pong. Puede contener hasta 125 bytes de texto de carga útil. libcurl no verifica que la carga útil sea UTF-8 válido.
CURLWS_CONT
Solo puede ocurrir en conjunción con CURLWS_TEXT o CURLWS_BINARY.

Este no es el fragmento final del mensaje, implica que hay otro fragmento viniendo como parte del mismo mensaje. La aplicación debe reensamblar los fragmentos para recibir el mensaje completo.

Solo se puede transmitir un mensaje fragmentado a la vez, pero puede ser interrumpido por frames CURLWS_CLOSE, CURLWS_PING o CURLWS_PONG.

PROTOCOLOS

Esta funcionalidad solo afecta a ws

EJEMPLO

/* pasamos un puntero a esta estructura a la función de devolución de llamada */
struct customdata {
  CURL *easy;
  void *ptr;
};
static size_t writecb(char *buffer,
                      size_t size, size_t nitems, void *p)
{
  struct customdata *c = (struct customdata *)p;
  const struct curl_ws_frame *m = curl_ws_meta(c->easy);
  printf("flags: %x\n", m->flags);
  return 0;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct customdata custom;
    custom.easy = curl;
    custom.ptr = NULL;
    curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, writecb);
    curl_easy_setopt(curl, CURLOPT_WRITEDATA, &custom);
    curl_easy_perform(curl);
  }
  return 0;
}

DISPONIBILIDAD

Añadido en curl 7.86.0

VALOR DE RETORNO

Esta función devuelve un puntero a una estructura curl_ws_frame con información de solo lectura que es válida para esta invocación específica de la función de devolución de llamada. Si no puede devolver esta información, o si la función se llama en el contexto incorrecto, devuelve NULL.
