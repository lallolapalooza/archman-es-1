DESCRIPCIÓN

Estas funciones son las extensiones del puntero de pantalla de ncurses. Cada función es idéntica a su contraparte no terminada en _sp, excepto que toma un puntero SCREEN * como primer argumento, y opera en esa pantalla específica.

Por ejemplo, beep_sp(sp) hace lo mismo que beep(), pero opera en la pantalla sp. Las funciones no terminadas en _sp operan en la pantalla actual.

Las funciones terminadas en _sp están diseñadas para ser utilizadas en aplicaciones que necesitan manejar múltiples pantallas curses concurrentemente. Por ejemplo, en una aplicación que usa varias ventanas en un entorno gráfico, cada ventana puede tener su propia pantalla curses.

La función new_prescr se usa para crear una nueva pantalla curses vacía. El puntero a esta pantalla se puede pasar a las otras funciones _sp para operar en esa pantalla específica. Si pasa NULL como puntero SCREEN * a cualquiera de las funciones _sp, el comportamiento no está definido, pero podría actuar de manera similar a las funciones sin sufijo _sp (si se ha inicializado una pantalla actual).

VALOR DEVUELTO

Ninguna de estas funciones devuelve un valor significativo, excepto aquellas que se sabe que devuelven un valor en sus versiones sin sufijo _sp.

EJEMPLOS

Para ilustrar el uso de estas funciones, considere el siguiente ejemplo que muestra cómo inicializar y usar una pantalla curses:

#include <curses.h>
#include <stdio.h>

int main() {
    SCREEN *my_screen = new_prescr(); // Crear una nueva pantalla
    WINDOW *win;

    if (my_screen == NULL) {
        fprintf(stderr, "Error: No se pudo inicializar la pantalla.\n");
        return 1;
    }

    // Inicializar la pantalla
    if (newterm_sp(my_screen, NULL, stdout, stdin) == NULL) {
        fprintf(stderr, "Error: No se pudo inicializar newterm_sp.\n");
        // Asegurarse de liberar la pantalla si falla la inicialización
        // endwin_sp(my_screen); // ¡Precaución! endwin_sp limpia la pantalla.
        return 1;
    }

    // Crear una nueva ventana en la pantalla
    win = newwin_sp(my_screen, 10, 30, 0, 0);
    if (win == NULL) {
        fprintf(stderr, "Error: No se pudo crear la ventana.\n");
        endwin_sp(my_screen);
        return 1;
    }

    // Imprimir texto en la ventana
    wprintw(win, "¡Hola, mundo desde curses!\n");
    box(win, 0, 0); // Dibujar un borde alrededor de la ventana
    wrefresh(win); // Refrescar la ventana para mostrar los cambios

    // Esperar entrada del usuario
    napms_sp(my_screen, 2000); // Esperar 2 segundos

    // Limpiar y terminar
    delwin(win);
    endwin_sp(my_screen);

    return 0;
}

DESCRIPCIÓ

N

Esta implementación puede configurarse para proporcionar un conjunto de funciones que mejoran la capacidad de gestionar múltiples pantallas. Esta característica puede añadirse a cualquiera de las configuraciones soportadas por ncurses; añade nuevos símbolos sin cambiar el significado de ninguno de los

existentes.

Funciones

mejoradas

La mayoría de las funciones son nuevas versiones de funciones existentes. Se añade un parámetro al principio de la lista de parámetros. Es un puntero a

SCREEN.

Las funciones existentes usan todas la pantalla actual, que es una variable est

ática. Las funciones extendidas usan la pantalla especificada, reduciendo así el
número de variables que deben modificarse para actualizar múltiples pantallas.

Funciones

nuevas

Aquí están las funciones

nuevas:
ceiling_pan
el
devuelve un puntero al panel más alto en la pantalla
dada.
ground_pan
el
devuelve un puntero al panel más bajo en la pantalla
dada.
new_pres
cr
al crear una pantalla nueva, la biblioteca usa variables estáticas que han sido preestablecidas, p. ej., por use_env(3X), filter(3X), etc. Con la extensión de puntero a pantalla, hay situaciones en las que debe crear una pantalla actual antes de que lo haga la biblioteca sin extensión. La función new_prescr se usa internamente para manejar es
tos casos. También se proporci
ona para permitir a las a
plicaciones personalizar la in
icialización de la biblioteca.

NOTA

S

Esta extensión introduce algunos nombres

nuevos:
NCURSES_SP_FU
NCS
Se establece en el número de nivel de parche de la biblioteca. En la biblioteca sin extensión, esto es cero (0), para que sea útil para comprobar si la extensión está
proporcionada.
NCURSES_SP_N
AME
Las funciones nuevas se nombran usando la macro NCURSES_SP_NAME, que oculta la implementación actual. Actualmente esto añade un sufijo "_sp" al nombre de la función sin extensión. Esta página de manual indexa las extensiones mostrando el nombre completo. Sin embargo, el uso correcto de estas funciones usa la macro, para proporcionar la posibilidad de cambiar la convención de nombrado para configuraciones específicas de la
biblioteca.
NCURSES_SP_O
UTC
Este es un nuevo tipo de puntero a función para usar en las funciones de puntero a pantalla donde se usa un NCURSES_OUTC en la biblioteca sin
extensión.
NCURSES_OU
TC
Este es un tipo de puntero a función usado para los casos donde una función pasa caracteres al flujo de salida, p. ej., vidpu
ts
(3X
).

PORTABILIDA

D

Estas rutinas son específicas de ncurses. No fueron soportadas en las implementaciones de Versión 7, BSD ni System V. Se recomienda que cualquier código que dependa de extensiones de ncurses sea condicionado usando NCURSES_SP_FUNC
