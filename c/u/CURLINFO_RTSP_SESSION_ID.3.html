CURLINFO_RTSP_SESSION_ID(3)

Paquete: curl

Licencias: MIT

CURLINFO_RTSP_SESSION_ID(3) Manual de funciones de la biblioteca CURLINFO_RTSP_SESSION_ID(3)

NOMBRE

CURLINFO_RTSP_SESSION_ID - obtener el ID de sesión RTSP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_RTSP_SESSION_ID, char **id);

DESCRIPCIÓN

Pase un puntero a un puntero de caracter para recibir un puntero a una cadena que contiene el ID de sesión RTSP más reciente.

Las aplicaciones que deseen reanudar una sesión RTSP en otra conexión deben recuperar esta información antes de cerrar la conexión activa.

El puntero id es NULL o apunta a memoria privada. Usted **no debe** liberarlo. La memoria se libera automáticamente cuando llama a curl_easy_cleanup(3) en el manejador curl correspondiente.

PROTOCOLOS

Esta funcionalidad afecta solo a rtsp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "rtsp://rtsp.example.com");
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      char *id;
      curl_easy_getinfo(curl, CURLINFO_RTSP_SESSION_ID, &id);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.20.0

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLINFO_RTSP_CSEQ_RECV(3), curl_easy_getinfo(3), curl_easy_setopt(3)
