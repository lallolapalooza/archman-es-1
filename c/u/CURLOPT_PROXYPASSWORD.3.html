CURLOPT_PROXYPASSWORD(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXYPASSWORD(3) Manual de funciones de la biblioteca CURLOPT_PROXYPASSWORD(3)

NOMBRE

CURLOPT_PROXYPASSWORD - contraseña a utilizar con la autenticación del proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYPASSWORD, char *pwd);

DESCRIPCIÓN

Pase un puntero a char como parámetro, que debe apuntar a la contraseña terminada en nulo que se utilizará para la autenticación con el proxy.

La opción CURLOPT_PROXYPASSWORD(3) debe usarse junto con la opción CURLOPT_PROXYUSERNAME(3).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida reemplace a las anteriores. Establézcala a NULL para deshabilitar su uso nuevamente.

VALOR POR DEFECTO

en blanco

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://localhost:8080");
    curl_easy_setopt(curl, CURLOPT_PROXYUSERNAME, "mrsmith");
    curl_easy_setopt(curl, CURLOPT_PROXYPASSWORD, "qwerty");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.19.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_HTTPAUTH(3), CURLOPT_PASSWORD(3), CURLOPT_PROXYAUTH(3), CURLOPT_PROXYUSERNAME(3)
