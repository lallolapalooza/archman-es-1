NOMBRE

snmp.conf - archivo de configuración snmp para cups (obsoleto)

DESCRIPCIÓN

El archivo snmp.conf configura cómo los backends de red estándar de CUPS (http, https, ipp, ipps, lpd, snmp y socket) acceden a la información de la impresora usando SNMPv1 y normalmente se encuentra en el directorio /etc/cups. Cada línea en el archivo puede ser una directiva de configuración, una línea en blanco o un comentario. Las líneas de comentario comienzan con el carácter #.

Las directivas Community y DebugLevel son utilizadas por todos los backends. El resto se aplica solo al backend SNMP - cups-snmp(8).

DIRECTIVAS

Las siguientes directivas son entendidas por los backends de red de CUPS:

Address @IF(nombre)
Address @LOCAL
Address dirección
Envía consultas de difusión SNMP (para descubrimiento) a la(s) dirección(es) especificada(s). No hay una dirección de difusión predeterminada.
Community nombre
Especifica el nombre de la comunidad a utilizar. Solo se puede especificar un nombre de comunidad. El nombre de comunidad predeterminado es "public". Si no se especifica ningún nombre, todas las funciones SNMP se deshabilitan.
DebugLevel número
Especifica el nivel de registro de 0 (ninguno) a 3 (todo). Normalmente solo se usa para depuración (de ahí el nombre). El nivel de depuración predeterminado es 0.
DeviceURI"expresión regular" uri-dispositivo [... uri-dispositivo]
Especifica uno o más URIs de dispositivo que deben usarse para una cadena de marca y modelo dada. La expresión regular se utiliza para hacer coincidir la marca y el modelo detectados, y las cadenas de URI de dispositivo deben tener el formato "scheme://%s[:port]/[path]", donde "%s" representa la dirección o el nombre de host detectado. No hay reglas predeterminadas para la coincidencia de URIs de dispositivo.
HostNameLookups on
HostNameLookups off
Especifica si las direcciones de las impresoras deben convertirse a nombres de host o dejarse como direcciones IP numéricas. El valor predeterminado es "off".
MaxRunTime segundos
Especifica el número máximo de segundos que el backend SNMP escaneará la red en busca de impresoras. El valor predeterminado es 120 segundos (2 minutos).

NOTAS

Los backends de CUPS están obsoletos y ya no serán compatibles en una futura versión de características de CUPS. Las impresoras que no admiten IPP se pueden admitir utilizando aplicaciones como ippeveprinter(1).
