curl_easy_send(3)

Paquete: curl

Licencias: MIT

curl_easy_send(3) Manual de funciones de la biblioteca curl_easy_send(3)

NOMBRE

curl_easy_send - envía datos sin procesar a través de una conexión "easy"

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_send(CURL *curl, const void *buffer,
                        size_t buflen, size_t *n);

DESCRIPCIÓN

Esta función envía datos arbitrarios a través de la conexión establecida. Puedes usarla junto con curl_easy_recv(3) para implementar protocolos personalizados usando libcurl. Esta funcionalidad puede ser particularmente útil si usas proxies y/o cifrado SSL: libcurl se encarga de la negociación del proxy y la configuración de la conexión.

buffer es un puntero a los datos de longitud buflen que deseas enviar. La variable n apunta a recibe el número de bytes enviados.

Para establecer la conexión, configura la opción CURLOPT_CONNECT_ONLY(3) antes de llamar a curl_easy_perform(3) o curl_multi_perform(3). Ten en cuenta que curl_easy_send(3) no funciona en conexiones que no se crearon con esta opción.

La llamada devuelve CURLE_AGAIN si no es posible enviar datos en este momento - el socket se usa en modo no bloqueante internamente. Cuando se devuelve CURLE_AGAIN, utiliza las facilidades de tu sistema operativo como select(2) para esperar hasta que el socket sea escribible. El socket se puede obtener usando curl_easy_getinfo(3) con CURLINFO_ACTIVESOCKET(3).

Además, si esperas en el socket y este te indica que es escribible, curl_easy_send(3) puede devolver CURLE_AGAIN si los únicos datos que se enviaron fueron para el procesamiento interno de SSL, y no se pudieron enviar otros datos.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* No realizar la transferencia - solo conectar al host */
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      curl_socket_t sockfd;
      size_t sent;
      /* Extraer el socket del handle de curl - lo necesitamos para esperar. */
      res = curl_easy_getinfo(curl, CURLINFO_ACTIVESOCKET, &sockfd);
      /* enviar datos */
      res = curl_easy_send(curl, "hola", 5, &sent);
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.18.2

VALOR DE RETORNO

En caso de éxito, devuelve CURLE_OK y almacena el número de bytes realmente enviados en *n. Ten en cuenta que puede ser menor que la cantidad que querías enviar.

En caso de fallo, devuelve el código de error apropiado.

Esta función puede devolver CURLE_AGAIN. En este caso, utiliza las facilidades de tu sistema operativo para esperar hasta que el socket sea escribible y reintenta.

Si no hay un socket disponible para usar de la transferencia anterior, esta función devuelve CURLE_UNSUPPORTED_PROTOCOL.
