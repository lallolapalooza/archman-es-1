curs_outopts(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_outopts(3X) Llamadas a bibliotecas curs_outopts(3X)

NOMBRE

clearok, idlok, idcok, immedok, leaveok, setscrreg, wsetscrreg, scrollok - establecer opciones de salida de curses

SINOPSIS

#include <curses.h>
int clearok(WINDOW *win, bool bf);
int idlok(WINDOW *win, bool bf);
void idcok(WINDOW *win, bool bf);
void immedok(WINDOW *win, bool bf);
int leaveok(WINDOW *win, bool bf);
int scrollok(WINDOW *win, bool bf);
int setscrreg(int top, int bot);
int wsetscrreg(WINDOW *win, int top, int bot);

DESCRIPCIÓN

Estas rutinas establecen opciones que cambian el estilo de salida dentro de curses. Todas las opciones son inicialmente FALSE, a menos que se indique lo contrario. No es necesario desactivar estas opciones antes de llamar a endwin(3X).

clearok

Si clearok se llama con TRUE como argumento, la siguiente llamada a wrefresh con esta ventana borrará la pantalla por completo y redibujará toda la pantalla desde cero. Esto es útil cuando el contenido de la pantalla es incierto, o en algunos casos para un efecto visual más agradable. Si el argumento win de clearok es la variable global curscr, la siguiente llamada a wrefresh con cualquier ventana causará que la pantalla sea borrada y repintada desde cero.

idlok

Si idlok se llama con TRUE como segundo argumento, curses considerará usar la característica de hardware de inserción/borrado de líneas de los terminales equipados con ella. Llamar a idlok con FALSE como segundo argumento desactiva el uso de la inserción y borrado de líneas. Esta opción solo debería habilitarse si la aplicación necesita inserción/borrado de líneas, por ejemplo, para un editor de pantalla. Está deshabilitada por defecto porque la inserción/borrado de líneas tiende a ser visualmente molesto cuando se usa en aplicaciones donde no es realmente necesario. Si no se puede usar la inserción/borrado de líneas, curses redibujará las porciones cambiadas de todas las líneas.

idcok

Si idcok se llama con FALSE como segundo argumento, curses ya no considerará usar la característica de hardware de inserción/borrado de caracteres de los terminales equipados con ella. El uso de la inserción/borrado de caracteres está habilitado por defecto. Llamar a idcok con TRUE como segundo argumento vuelve a habilitar el uso de la inserción y borrado de caracteres.

immedok

Si immedok se llama con TRUE como segundo argumento, cualquier cambio en la imagen de la ventana, como los causados por waddch,wclrtobot, wscrl , etc., causará automáticamente una llamada awrefresh . Sin embargo, esto puede degradar el rendimiento considerablemente debido a las llamadas repetidas awrefresh . Llamar a immedok con FALSE

como segundo argumento restaura el comportamiento por defecto, es decir, diferir las actualizaciones de la pantalla hasta que se necesite una actualización.

leaveok Normalmente, el cursor de hardware se deja en la ubicación del cursor de la ventana que se está actualizando. La opción leaveok

permite que el cursor se deje dondequiera que la actualización lo haya dejado. Es útil para aplicaciones donde el cursor no se usa, ya que reduce la necesidad de movimientos del cursor.

scrollok La opción scrollokcontrola lo que sucede cuando el cursor de una ventana se mueve fuera del borde de la ventana o de la región de desplazamiento, ya sea como resultado de una acción de salto de línea en la línea inferior, o al escribir el último carácter de la última línea. Si está deshabilitada, ( bf esFALSE), el cursor se deja en la línea inferior. Si está habilitada, ( bf esTRUE ), la ventana se desplaza hacia arriba una línea (Nótese que para obtener el efecto de desplazamiento físico en el terminal, también es necesario llamar aidlok

).

setscrreg, wsetscrreg Las rutinas setscrreg y wsetscrreg permiten al programador de la aplicación establecer una región de desplazamiento por software en una ventana. Los parámetros top y bot son los números de línea del margen superior e inferior de la región de desplazamiento. (La línea 0 es la línea superior de la ventana.) Si esta opción y scrollok están habilitadas, un intento de moverse fuera de la línea del margen inferior hace que todas las líneas en la región de desplazamiento se desplacen una línea en la dirección de la primera línea. Solo se desplaza el texto de la ventana. (Nótese que esto no tiene nada que ver con el uso de una capacidad de región de desplazamiento física en el terminal, como la del VT100. Si idlok

está habilitada y el terminal tiene la capacidad de región de desplazamiento o de inserción/borrado de líneas, probablemente serán usadas por las rutinas de salida.)

VALOR DE RETORNO Las funciones setscrreg y wsetscrreg devuelven OK en caso de éxito y ERR en caso de fallo. Todas las demás rutinas que devuelven un entero siempre devuelvenOK

.

X/Open Curses no especifica ninguna condición de error.

  • En esta implementación, aquellas funciones que tienen un puntero a ventana devolverán un error si el puntero a ventana es nulo.
  • wsetscrreg devuelve un error si los límites de la región de desplazamiento se extienden fuera de los límites de la ventana.

NOTAS

Nótese que clearok, leaveok, scrollok, idcoky setscrreg pueden ser macros.

La rutina immedok es útil para ventanas que se usan como emuladores de terminal.

PORTABILIDAD

Estas funciones están descritas en X/Open Curses, Edición 4.

Algunas implementaciones históricas de curses tenían, como una característica no documentada, la capacidad de hacer el equivalente a clearok(..., 1) diciendo touchwin(stdscr) o clear(stdscr). Esto no funcionará bajo ncurses.

Implementaciones anteriores de curses de System V especificaban que con scrollok habilitada, cualquier modificación de la ventana que desencadenara un desplazamiento también forzaba una actualización física. X/Open Curses no requiere esto, y ncurses evita hacerlo para realizar una mejor optimización del movimiento vertical en el momento de wrefresh .

X/Open Curses no menciona que el cursor deba hacerse invisible como efecto secundario de leaveok. La documentación de SVr4 curses lo hace, pero el código no. Use curs_set para hacer el cursor invisible.

HISTORIA

ncurses trataba anteriormente nl(3X) y nonl(3X) como opciones tanto de entrada como de salida, pero ya no lo hace; véase curs_inopts(3X).
