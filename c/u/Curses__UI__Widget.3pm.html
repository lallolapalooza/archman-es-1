SINOPSI

S

Esta clase no es utilizada directamente por alguien que esté construyendo una aplicación usando Curses::UI. Es una clase base que es extendida por los widgets de Curses::UI. Vea la sección ESTRUCTURA DEL WIDGET más abajo para un esquema básico de

widget. 
use Curses::UI::Widget;
my $widget = new Curses::UI::Widget(
    -width  => 15,
    -height => 5,
    -border => 1,
)
;

cajas emergentes). Un borde de corchetes cuadrados solo puede ser habilitado si
-border es falso. El predeterminado es no usar un borde de corchetes cuadrados.

DESPLAZAMIENTO:

Nota

:

Dado que el usuario de un programa Curses::UI no tiene control real sobre las llamadas "barras de desplazamiento", no son realmente barras de desplazamiento. Un mejor nombre sería algo como "indicadores de ubicación del documento". Pero dado que se parecen tanto a las barras de desplazamiento decidí que podría salirme con la esta en cuanto a la convención de

nombres.
  • -vscrollbar < VALUE >

    VALUE puede ser 'left', 'right', otro valor verdadero o

    falso.

    Si -vscrollbar tiene un valor verdadero, el widget dibujará una barra de desplazamiento vertical. Si este valor verdadero resulta ser "left", la barra de desplazamiento será dibujada en el lado izquierdo del widget. En todos los demás casos será dibujada en el lado derecho. El predeterminado es no dibujar una barra de desplazamiento

    vertical.

    Para programadores de widgets: Para controlar la barra de desplazamiento, los datos del widget -vscrolll

    en (la longitud total del contenido del widget) y -vscrollpos (la posición actual en el documento) debe
    • rían ser establecidos. Si Curses::UI::Widget::draw es llamado, la barra de desplazamiento será dibujada.
  • -hscrollbar < VALUE >

    VALUE puede ser 'top', 'bottom', otro valor verdadero o

    falso.

    Si -hscrollbar tiene un valor verdadero, el widget dibujará una barra de desplazamiento horizontal. Si este valor verdadero resulta ser "top", la barra de desplazamiento será dibujada en la parte superior del widget. En todos los demás casos será dibujada en la parte inferior. El predeterminado es no dibujar una barra de desplazamiento

    horizontal.

    Para programadores de widgets: Para controlar la barra de desplazamien

    to, los datos del widget -hscrolllen (el ancho máximo del conte
    • nido del widget) y -hscrollpos (la posición horizontal actual
en el documento) deberían ser establecidos. Si Curses::UI::Widg
et::draw es llamado, la barra de desplazamiento será dibujada.

ESTRUCTURA DEL WIDGET Aquí hay un marco básico para crear un nuevo widget. No tienes que seguir este marco. Mientras tu widget tenga los métodos new(), layout() , draw() y focus(), puede ser usado en Curses:

: 
UI.
package Curses::UI::YourWidget
use Curses;
use Curses::UI::Widget;  
use Curses::UI::Common; # some common widget routines
use vars qw($VERSION @ISA);
$VERSION = '0.01';
@ISA = qw(Curses::UI::Widget Curses::UI::Common);
# For a widget that can get focus, you should define
# the routines that are used to control the widget.
# Each routine has a name. This name is used in 
# the definition of the bindings. 
# The value can be a string or a subroutine reference. 
# A string will make the widget return from focus.
#
my %routines = (
    'return'    => 'LOSE_FOCUS',
    'key-a'     => \&key_a,
    'key-other' => \&other_key
);
# Using the bindings, the routines can be binded to key-
# presses. If the keypress is an empty string, this means
# that this is the default binding. If the key is not 
# handled by any other binding, it's handled by this
# default binding.
#
my %bindings = (
    KEY_DOWN()  => 'return',   # down arrow will make the 
                               # widget lose it's focus
    'a'         => 'key-a',    # a-key will trigger key_a()
    ''          => 'key-other' # any other key will trigger other_key()
);
# The creation of the widget. Al hacerlo de esta manera,
# es fácil hacer posibles argumentos opcionales y forzados.
# Un argumento forzado podría ser, por ejemplo,
# -border => 1, lo que significaría que el widget
# siempre tiene un borde, que no puede ser deshabilitado por el
# programador. Los argumentos, por supuesto, pueden usarse
# para almacenar el estado actual del widget.
#
sub new () {
    my $class = shift;
    my %args = (
        -optional_argument_1 => "default value 1",
        -optional_argument_2 => "default value 2",
        ....etc....
        @_,
        -forced_argument_1   => "forced value 1", 
        -forced_argument_2   => "forced value 2", 
        ....etc....
        -bindings            => {%bindings},
        -routines            => {%routines},
    );
    # Crea el widget y hace su diseño.
    my $this = $class->SUPER::new( %args );
$this->layout;
return $this;
}
# Cada widget debería tener una rutina layout(). Aquí,
# el widget mismo y su contenido pueden ser diseñados.
# En el caso de un widget muy simple, esto solo significará
# que el Widget tiene que ser diseñado (en cuyo caso la
# rutina podría omitirse, ya que está en la clase base
# ya). En otros casos tendrás que añadir
# tu propio código de diseño. Esta rutina es muy importante,
# ya que habilitará la redimensionabilidad del widget!
#
sub layout () {
    my $this = shift;
    $this->SUPER::layout;
return $this if $Curses::UI::screen_too_small;
    ....tu propio diseño....
    # Si decides que el widget no cabe en la
    # pantalla, entonces establece $Curses::UI::screen_too_small
    # a un valor verdadero y regresa.    
    if ( ....el widget no cabe.... ) {
        $Curses::UI::screen_too_small++;
        return $this;
    }
    return $this;
}
# El widget es dibujado por la rutina draw(). La
# parte $no_update se usa para deshabilitar el parpadeo de la pantalla
# si muchos widgets tienen que ser dibujados a la vez (por
# ejemplo al redimensionar o redibujar). La ventana curses
# que puedes usar para dibujar el contenido del widget
# es $this->{-canvasscr}.
#
sub draw(;$) {
    my $this = shift;
    my $no_doupdate = shift || 0;
    return $this if $this->hidden;
    $this->SUPER::draw(1);
    ....tu propio código de dibujo....
    $this->{-canvasscr}->addstr(0, 0, "Fixed string");
    ....tu propio código de dibujo....
    $this->{-canvasscr}->noutrefresh;
    doupdate() unless $no_doupdate;
return $this;
}
# Enfoca el widget. Si no sobreescribes esta rutina
# de Curses::UI::Widget, el widget no será
# enfocable. Mayormente usarás el método generic_focus().
#
sub focus()
{
    my $this = shift;
    $this->show; # hace el widget visible si estaba invisible
    return $this->generic_focus(
        undef,             # delaytime, default = 2 (1/10 segundo).
        NO_CONTROLKEYS,    # deshabilita teclas de control como CTRL+C. Para habilitarlas
                           # usa CONTROLKEYS en su lugar.
        CURSOR_INVISIBLE,  # no muestra el cursor (si está soportado). Para
                           # mostrar el cursor usa CURSOR_VISIBLE.
        \&pre_key_routine, # rutina de callback opcional a ejecutar
                           # antes de leer una tecla. Mayormente no se usa.
    );
}
