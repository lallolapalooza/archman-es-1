CURLOPT_SSH_HOSTKEYFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSH_HOSTKEYFUNCTION(3) Manual de funciones de la biblioteca CURLOPT_SSH_HOSTKEYFUNCTION(3)

NOMBRE

CURLOPT_SSH_HOSTKEYFUNCTION - callback para verificar la clave del host

SINOPSIS

#include <curl/curl.h>
int keycallback(void *clientp,
                int keytype,
                const char *key,
                size_t keylen);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_HOSTKEYFUNCTION,
                          keycallback);

DESCRIPCIÓN

Pase un puntero a su función de callback, que debe coincidir con el prototipo mostrado arriba. Sobrescribe CURLOPT_SSH_KNOWNHOSTS(3).

Esta función de callback se llama cuando se necesita la verificación de la clave del host SSH.

key tiene keylen bytes de longitud y es la clave a verificar. keytype indica de qué tipo es, de la serie CURLKHTYPE_* en la enumeración curl_khtype.

clientp es un puntero personalizado establecido con CURLOPT_SSH_HOSTKEYDATA(3).

La función de callback debe devolver uno de los siguientes códigos de retorno para indicarle a libcurl cómo actuar:

CURLKHMATCH_OK
La clave del host es aceptada, la conexión debe continuar.
CURLKHMATCH_MISMATCH
La clave del host es rechazada, la conexión se cancela.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a scp y sftp

EJEMPLO

struct mine {
  void *custom;
};
int hostkeycb(void *clientp,    /* pasado con CURLOPT_SSH_HOSTKEYDATA */
              int keytype,      /* CURLKHTYPE */
              const char *key,  /* clave del host a verificar */
              size_t keylen)    /* longitud de la clave */
{
  /* 'clientp' apunta a la estructura callback_data */
  /* investigue la situación y devuelva el valor correcto */
  return CURLKHMATCH_OK;
}
int main(void)
{
  struct mine callback_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/thisfile.txt");
    curl_easy_setopt(curl, CURLOPT_SSH_HOSTKEYFUNCTION, hostkeycb);
    curl_easy_setopt(curl, CURLOPT_SSH_HOSTKEYDATA, &callback_data);
    curl_easy_perform(curl);
  }
}

NOTAS

Funciona solo con el backend libssh2.

DISPONIBILIDAD

Añadido en curl 7.84.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
