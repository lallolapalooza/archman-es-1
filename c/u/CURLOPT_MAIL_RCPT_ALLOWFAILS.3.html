CURLOPT_MAIL_RCPT_ALLOWFAILS(3)

Paquete: curl

Licencias: MIT

CURLOPT_MAIL_RCPT_ALLOWFAILS(3) Manual de funciones de la biblioteca CURLOPT_MAIL_RCPT_ALLOWFAILS(3)

NOMBRE

CURLOPT_MAIL_RCPT_ALLOWFAILS - permitir que el comando RCPT TO falle para algunos destinatarios

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAIL_RCPT_ALLOWFAILS,
                          long allow);

DESCRIPCIÓN

Si allow se establece en 1L, permite que el comando RCPT TO falle para algunos destinatarios.

Al enviar datos a múltiples destinatarios, por defecto curl aborta la conversación SMTP si alguno de los destinatarios provoca que el comando RCPT TO devuelva un error.

El comportamiento por defecto se puede cambiar estableciendo allow en 1L, lo que hace que libcurl ignore los errores para destinatarios individuales y continúe con los destinatarios restantes aceptados.

Si todos los destinatarios provocan fallos en RCPT TO y se especifica esta bandera, curl aborta la conversación SMTP y devuelve el error recibido del último comando RCPT TO.

POR DEFECTO

0

PROTOCOLOS

Esta funcionalidad afecta solo a smtp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_slist *list;
    CURLcode res;
    /* Añadiendo una dirección de correo electrónico válida y una inválida */
    list = curl_slist_append(NULL, "person@example.com");
    list = curl_slist_append(list, "invalidemailaddress");
    curl_easy_setopt(curl, CURLOPT_URL, "smtp://example.com/");
    curl_easy_setopt(curl, CURLOPT_MAIL_RCPT_ALLOWFAILS, 1L);
    res = curl_easy_perform(curl);
    curl_slist_free_all(list);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Esta opción se llamaba CURLOPT_MAIL_RCPT_ALLLOWFAILS (con tres en lugar de dos letras L) antes de la versión 8.2.0.

DISPONIBILIDAD

Añadido en curl 8.2.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error; consulte libcurl-errors(3).
