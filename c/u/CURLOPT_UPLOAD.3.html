CURLOPT_UPLOAD(3)

Paquete: curl

Licencias: MIT

CURLOPT_UPLOAD(3) Manual de funciones de la biblioteca CURLOPT_UPLOAD(3)

NOMBRE

CURLOPT_UPLOAD - carga de datos

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_UPLOAD, long upload);

DESCRIPCIÓN

El parámetro long upload establecido en 1 indica a la biblioteca que se prepare y realice una carga. Las opciones CURLOPT_READDATA(3) y CURLOPT_INFILESIZE(3) o CURLOPT_INFILESIZE_LARGE(3) también son interesantes para las cargas. Si el protocolo es HTTP, la carga implica el uso de la solicitud PUT a menos que le indique lo contrario a libcurl.

El uso de PUT con HTTP 1.1 implica el uso de una cabecera "Expect: 100-continue". Puede deshabilitar esta cabecera con CURLOPT_HTTPHEADER(3) como de costumbre.

Si utiliza PUT a un servidor HTTP 1.1, puede cargar datos sin conocer el tamaño antes de iniciar la transferencia. La biblioteca habilita esto añadiendo una cabecera "Transfer-Encoding: chunked". Con HTTP 1.0 o si prefiere no utilizar transferencia por fragmentos, debe especificar el tamaño de los datos con CURLOPT_INFILESIZE(3) o CURLOPT_INFILESIZE_LARGE(3).

PREDETERMINADO

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

static size_t read_cb(char *ptr, size_t size, size_t nmemb, void *userdata)
{
  FILE *src = userdata;
  /* copia tantos datos como sea posible en el búfer 'ptr', pero no más que
     'size' * 'nmemb' bytes */
  size_t retcode = fread(ptr, size, nmemb, src);
  return retcode;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    FILE *src = fopen("archivo-local", "r");
    curl_off_t fsize = 1234; /* establezca esto al tamaño del archivo de entrada */
    /* queremos usar nuestra propia función de lectura */
    curl_easy_setopt(curl, CURLOPT_READFUNCTION, read_cb);
    /* habilitar carga */
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    /* especificar destino */
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://ejemplo.com/directorio/a/nuevofichero");
    /* ahora especificar qué puntero pasar a nuestra devolución de llamada */
    curl_easy_setopt(curl, CURLOPT_READDATA, src);
    /* Establecer el tamaño del archivo a cargar */
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, (curl_off_t)fsize);
    /* ¡Ahora ejecuta y haz lo que te han dicho! */
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
