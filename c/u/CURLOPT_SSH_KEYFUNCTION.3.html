CURLOPT_SSH_KEYFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSH_KEYFUNCTION(3) Manual de funciones de la biblioteca CURLOPT_SSH_KEYFUNCTION(3)

NOMBRE

CURLOPT_SSH_KEYFUNCTION - callback para la lógica de coincidencia de hosts conocidos

SINOPSIS

#include <curl/curl.h>
enum curl_khstat {
  CURLKHSTAT_FINE_ADD_TO_FILE,
  CURLKHSTAT_FINE,
  CURLKHSTAT_REJECT, /* rechaza la conexión, devuelve un error */
  CURLKHSTAT_DEFER,  /* no la acepta, pero no podemos responder ahora. Causa un error CURLE_PEER_FAILED_VERIFICATION pero la conexión se mantiene intacta */
  CURLKHSTAT_FINE_REPLACE
};
enum curl_khmatch {
  CURLKHMATCH_OK,       /* coincidencia */
  CURLKHMATCH_MISMATCH, /* host encontrado, clave incorrecta */
  CURLKHMATCH_MISSING,  /* no se encontró host/clave coincidente */
};
struct curl_khkey {
  const char *key; /* apunta a una cadena terminada en nulo codificada en base64 si len es cero, de lo contrario, apunta a los datos "crudos" */
  size_t len;
  enum curl_khtype keytype;
};
int ssh_keycallback(CURL *easy,
                    const struct curl_khkey *knownkey,
                    const struct curl_khkey *foundkey,
                    enum curl_khmatch match,
                    void *clientp);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_KEYFUNCTION,
                          ssh_keycallback);

DESCRIPCIÓN

Pase un puntero a su función de callback, que debe coincidir con el prototipo que se muestra arriba.

Se llama cuando se ha realizado la coincidencia de known_host, para permitir que la aplicación actúe y decida para libcurl cómo proceder. El callback solo se llama si CURLOPT_SSH_KNOWNHOSTS(3) también está configurado.

Esta función de callback recibe el manejador de curl, la clave del archivo known_hosts knownkey, la clave del sitio remoto foundkey, información de libcurl sobre el estado de la coincidencia y un puntero personalizado (establecido con CURLOPT_SSH_KEYDATA(3)). Debe devolver uno de los siguientes códigos de retorno para indicar a libcurl cómo actuar:

CURLKHSTAT_FINE_REPLACE
El nuevo host+clave se acepta y libcurl reemplaza el host+clave antiguo en el archivo known_hosts antes de continuar con la conexión. Esto también agrega la nueva combinación host+clave al pool de known_host mantenido en memoria si no estaba presente allí anteriormente. La adición de datos al archivo se realiza reemplazando completamente el archivo con una nueva copia, por lo que los permisos del archivo deben permitirlo. (Agregado en 7.73.0)
CURLKHSTAT_FINE_ADD_TO_FILE
El host+clave se acepta y libcurl lo agrega al final del archivo known_hosts antes de continuar con la conexión. Esto también agrega la combinación host+clave al pool de known_host mantenido en memoria si no estaba presente allí anteriormente. La adición de datos al archivo se realiza reemplazando completamente el archivo con una nueva copia, por lo que los permisos del archivo deben permitirlo.
CURLKHSTAT_FINE
El host+clave se acepta y libcurl continúa con la conexión. Esto también agrega la combinación host+clave al pool de known_host mantenido en memoria si no estaba presente allí anteriormente.
CURLKHSTAT_REJECT
El host+clave es rechazado. libcurl niega que la conexión continúe y se cierra.
CURLKHSTAT_DEFER
El host+clave es rechazado, pero se solicita que la conexión SSH se mantenga activa. Esta característica podría usarse cuando la aplicación desea regresar y actuar sobre la situación del host+clave y luego reintentar sin necesitar la sobrecarga de configurarla desde cero nuevamente.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a scp y sftp

EJEMPLO

struct mine {
  void *custom;
};
static int keycb(CURL *easy,
                 const struct curl_khkey *knownkey,
                 const struct curl_khkey *foundkey,
                 enum curl_khmatch match,
                 void *clientp)
{
  /* 'clientp' apunta a la estructura callback_data */
  /* investiga la situación y devuelve el valor correcto */
  return CURLKHSTAT_FINE_ADD_TO_FILE;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct mine callback_data;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/thisfile.txt");
    curl_easy_setopt(curl, CURLOPT_SSH_KEYFUNCTION, keycb);
    curl_easy_setopt(curl, CURLOPT_SSH_KEYDATA, &callback_data);
    curl_easy_setopt(curl, CURLOPT_SSH_KNOWNHOSTS, "/home/user/known_hosts");
    curl_easy_perform(curl);
}
}

DISPONIBILIDAD

Agregado en curl 7.19.6

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, distinto de cero significa que ocurrió un error, consulte libcurl-errors(3).
