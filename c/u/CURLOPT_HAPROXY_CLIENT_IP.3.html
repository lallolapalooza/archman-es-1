CURLOPT_HAPROXY_CLIENT_IP(3)

Paquete: curl

Licencias: MIT

CURLOPT_HAPROXY_CLIENT_IP(3) Manual de funciones de la biblioteca CURLOPT_HAPROXY_CLIENT_IP(3)

NOMBRE

CURLOPT_HAPROXY_CLIENT_IP - establecer la IP del cliente HAProxy PROXY protocol

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HAPROXY_CLIENT_IP,
                          char *client_ip);

DESCRIPCIÓN

Cuando este parámetro se establece en una dirección numérica IPv4 o IPv6 válida, la biblioteca envía esta dirección como la dirección del cliente en la cabecera v1 del protocolo PROXY de HAProxy al inicio de la conexión.

Esta opción es una alternativa a CURLOPT_HAPROXYPROTOCOL(3) ya que esta última no puede usar una dirección especificada.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establécela a NULL para deshabilitar su uso nuevamente.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

POR DEFECTO

NULL, no se envía ninguna cabecera HAProxy

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_HAPROXY_CLIENT_IP, "1.1.1.1");
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 8.2.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue correcto, un valor distinto de cero indica que ocurrió un error, véase libcurl-errors(3).

VER TAMBIÉN
