CURLOPT_WRITEDATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_WRITEDATA(3) Manual de funciones de biblioteca CURLOPT_WRITEDATA(3)

NOMBRE

CURLOPT_WRITEDATA - puntero pasado a la función de retorno de escritura

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_WRITEDATA, void *pointer);

DESCRIPCIÓN

Un puntero de datos para pasar a la función de retorno de escritura. Si utiliza la opción CURLOPT_WRITEFUNCTION(3), este es el puntero que obtiene en el cuarto y último argumento de esa función de retorno. Si no utiliza una función de retorno de escritura, debe hacer que pointer sea un 'FILE *' (convertido a 'void *') ya que libcurl lo pasa a fwrite(3) al escribir datos.

La CURLOPT_WRITEFUNCTION(3) interna escribe los datos en el FILE * proporcionado con esta opción, o a la salida estándar si esta opción no ha sido establecida.

Si está utilizando libcurl como una DLL de Windows, también debe utilizar CURLOPT_WRITEFUNCTION(3) si establece esta opción o podría experimentar bloqueos.

POR OMISIÓN

stdout

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

Una técnica común es usar la función de retorno de escritura para almacenar los datos entrantes en un búfer asignado que crece dinámicamente, y luego este CURLOPT_WRITEDATA(3) se usa para apuntar a una estructura o al búfer donde almacenar los datos. Como en el ejemplo getinmemory: https://curl.se/libcurl/c/getinmemory.html

HISTORIA

Esta opción se conocía anteriormente como CURLOPT_FILE, el nombre CURLOPT_WRITEDATA(3) se añadió en la versión 7.9.7.

DISPONIBILIDAD

Añadido en curl 7.9.7

VALOR DE RETORNO

Retorna CURLE_OK.

VER TAMBIÉN

CURLOPT_HEADERDATA(3), CURLOPT_READDATA(3), CURLOPT_WRITEFUNCTION(3)
