CURLINFO_CONDITION_UNMET(3)

Paquete: curl

Licencias: MIT

CURLINFO_CONDITION_UNMET(3) Manual de funciones de biblioteca CURLINFO_CONDITION_UNMET(3)

NOMBRE

CURLINFO_CONDITION_UNMET - obtener información sobre una condición temporal no cumplida o una respuesta HTTP 304.

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONDITION_UNMET,
                           long *unmet);

DESCRIPCIÓN

Pase un puntero a un long para recibir el número 1 si la condición proporcionada en la solicitud anterior no coincidió (ver CURLOPT_TIMECONDITION(3)). Por lo tanto, si esto devuelve un 1, sabrá que la razón por la que no obtuvo datos en respuesta es porque no cumplió la condición. El long al que apunta este argumento se establece en cero si la condición se cumplió en su lugar. Esto también puede devolver 1 si el servidor respondió con un código de estado HTTP 304, por ejemplo, después de enviar una cabecera personalizada "If-Match-*".

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* 1 de enero de 2020 es 1577833200 */
    curl_easy_setopt(curl, CURLOPT_TIMEVALUE, 1577833200L);
    /* If-Modified-Since la marca de tiempo anterior */
    curl_easy_setopt(curl, CURLOPT_TIMECONDITION, CURL_TIMECOND_IFMODSINCE);
    /* Realizar la solicitud */
    res = curl_easy_perform(curl);
    if(!res) {
      /* comprobar la condición de tiempo */
      long unmet;
      res = curl_easy_getinfo(curl, CURLINFO_CONDITION_UNMET, &unmet);
      if(!res) {
        printf("La condición de tiempo fue %scumplida\n", unmet?"NO":"");
      }
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.19.4

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_TIMECONDITION(3), CURLOPT_TIMEVALUE(3), curl_easy_getinfo(3), curl_easy_setopt(3)
