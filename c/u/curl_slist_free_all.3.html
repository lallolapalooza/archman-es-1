NOMBRE

curl_slist_free_all - liberar una lista completa de curl_slist

SINOPSIS

#include <curl/curl.h>
void curl_slist_free_all(struct curl_slist *list);

DESCRIPCIÓN

curl_slist_free_all() elimina todos los rastros de una lista enlazada de curl_slist previamente construida.

Pasar un puntero NULL en list hace que esta función regrese inmediatamente sin realizar ninguna acción.

Cualquier uso de list después de que esta función haya sido llamada y haya regresado, es ilegal.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *handle = curl_easy_init();
  struct curl_slist *slist = NULL;
  slist = curl_slist_append(slist, "X-libcurl: coolness");
  if(!slist)
    return -1;
  curl_easy_setopt(handle, CURLOPT_HTTPHEADER, slist);
  curl_easy_perform(handle);
  curl_slist_free_all(slist); /* liberar la lista de nuevo */
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Nada.
