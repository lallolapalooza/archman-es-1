CURLOPT_PROXY_TRANSFER_MODE(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_TRANSFER_MODE(3) Manual de funciones de biblioteca CURLOPT_PROXY_TRANSFER_MODE(3)

NOMBRE

CURLOPT_PROXY_TRANSFER_MODE - añadir el modo de transferencia FTP a la URL para el proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_TRANSFER_MODE,
                          long enabled);

DESCRIPCIÓN

Pasa un long. Si el valor se establece a 1 (uno), le dice a libcurl que establezca el modo de transferencia (binario o ASCII) para transferencias FTP realizadas a través de un proxy HTTP, añadiendo ;type=a o ;type=i a la URL. Sin esta configuración, o si se establece a 0 (cero, el valor por defecto), CURLOPT_TRANSFERTEXT(3) no tiene efecto al realizar FTP a través de un proxy. Tenga en cuenta que no todos los proxies admiten esta característica.

PREDETERMINADO

0, deshabilitado

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/old-server/file.txt");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://localhost:80");
    curl_easy_setopt(curl, CURLOPT_PROXY_TRANSFER_MODE, 1L);
    curl_easy_setopt(curl, CURLOPT_TRANSFERTEXT, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.18.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
