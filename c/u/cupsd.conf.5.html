NOMBRE

cupsd.conf - archivo de configuración del servidor para cups

DESCRIPCIÓN

El archivo cupsd.conf configura el planificador de CUPS, cupsd(8). Normalmente se encuentra en el directorio /etc/cups. Cada línea del archivo puede ser una directiva de configuración, una línea en blanco o un comentario. Las directivas de configuración normalmente consisten en un nombre y cero o más valores separados por espacios en blanco. El nombre de la directiva de configuración y los valores no distinguen entre mayúsculas y minúsculas. Las líneas de comentario comienzan con el carácter #.

DIRECTIVAS DE NIVEL SUPERIOR

Las siguientes directivas de nivel superior son entendidas por cupsd(8):

AccessLogLevel config
AccessLogLevel acciones
AccessLogLevel todo
Especifica el nivel de registro para el archivo AccessLog. El nivel "config" registra cuándo se agregan, eliminan o modifican impresoras y clases, y cuándo se accede o actualizan los archivos de configuración. El nivel "acciones" registra cuándo se envían, retienen, liberan, modifican o cancelan trabajos de impresión, y cualquiera de las condiciones para "config". El nivel "todo" registra todas las solicitudes. El nivel de acceso predeterminado del registro es "acciones".
AutoPurgeJobs Sí
AutoPurgeJobs No

Especifica si se purgan automáticamente los datos del historial de trabajos cuando ya no son necesarios para las cuotas. El valor predeterminado es "No".
BrowseDNSSDSubTypes_subtipo[,...]
Especifica una lista de subtipos de Bonjour para anunciar cada impresora compartida. Por ejemplo, "BrowseDNSSDSubTypes _cups,_print" indicará a los clientes de red que se admiten tanto el uso compartido de CUPS como IPP Everywhere. El valor predeterminado es "_cups", que es necesario para que el uso compartido de impresoras funcione entre sistemas que utilizan CUPS.
BrowseLocalProtocols todo
BrowseLocalProtocols dnssd
BrowseLocalProtocols ninguno
Especifica qué protocolos se utilizan para compartir impresoras locales. El valor predeterminado es "dnssd" en sistemas que admiten Bonjour y "ninguno" en caso contrario.
BrowseWebIF Sí
BrowseWebIF No

Especifica si se anuncia la interfaz web de CUPS. El valor predeterminado es "No".
Browsing Sí
Browsing No

Especifica si se anuncian las impresoras compartidas. El valor predeterminado es "No".
DefaultAuthType Basic

Especifica el tipo de autenticación predeterminado que se utilizará. El valor predeterminado es "Basic".
DefaultEncryption Nunca
DefaultEncryption SiSeSolicita
DefaultEncryption Requerido
Especifica si se utilizará cifrado para las solicitudes autenticadas. El valor predeterminado es "Requerido".
DefaultLanguage locale
Especifica el idioma predeterminado a utilizar para texto y contenido web. El valor predeterminado es "en".
DefaultPaperSize Auto
DefaultPaperSize Ninguno
DefaultPaperSize nombre-tamaño
Especifica el tamaño de papel predeterminado para las colas de impresión nuevas. "Auto" utiliza un valor predeterminado específico de la configuración regional, mientras que "Ninguno" especifica que no hay tamaño de papel predeterminado. Los nombres de tamaño específicos suelen ser "Letter" o "A4". El valor predeterminado es "Auto". Nota: El tamaño de papel predeterminado debe utilizar un nombre de tamaño del archivo PPD y no un nombre de tamaño de medio de autodescripción PWG.
DefaultPolicy nombre-política
Especifica la política de acceso predeterminada que se utilizará. La política de acceso predeterminada es "default".
DefaultShared Sí
DefaultShared No
Especifica si las impresoras locales se comparten de forma predeterminada. El valor predeterminado es "Sí".
DirtyCleanInterval segundos
Especifica el retardo para la actualización de los archivos de configuración y estado. Un valor de 0 provoca que la actualización ocurra tan pronto como sea posible, normalmente en unos pocos milisegundos. El valor predeterminado es "30".
DNSSDHostNamehostname.example.com
Especifica el nombre de dominio completo del servidor que se utiliza para el uso compartido de Bonjour. El valor predeterminado suele ser el nombre de host ".local" del servidor.
ErrorPolicy abort-job
Especifica que un trabajo de impresión fallido debe ser abortado (descartado) a menos que se especifique lo contrario para la impresora.
ErrorPolicy retry-current-job
Especifica que un trabajo de impresión fallido debe ser reintentado inmediatamente a menos que se especifique lo contrario para la impresora.
ErrorPolicy retry-job
Especifica que un trabajo de impresión fallido debe ser reintentado más tarde a menos que se especifique lo contrario para la impresora.
ErrorPolicy stop-printer
Especifica que un trabajo de impresión fallido debe detener la impresora a menos que se especifique lo contrario para la impresora. La política de error 'stop-printer' es la predeterminada.
FilterLimit límite
Especifica el coste máximo de los filtros que se ejecutan simultáneamente, lo que puede utilizarse para minimizar problemas de recursos de disco, memoria y CPU. Un límite de 0 deshabilita la limitación de filtros. Una impresión promedio a una impresora no PostScript necesita un límite de filtro de aproximadamente 200. Una impresora PostScript necesita aproximadamente la mitad (100). Establecer el límite por debajo de estos umbrales limitará efectivamente el planificador a imprimir un solo trabajo en cualquier momento. El límite predeterminado es "0".
FilterNice valor-nice
Especifica la prioridad de planificación (valor de nice(8)) de los filtros que se ejecutan para imprimir un trabajo. El valor nice oscila entre 0, la prioridad más alta, y 19, la prioridad más baja. El valor predeterminado es 0.
HostNameLookups Activado
HostNameLookups Desactivado
HostNameLookups Doble
Especifica si se realizan búsquedas inversas en los clientes que se conectan. La configuración "Doble" hace que cupsd(8) verifique que el nombre de host resuelto a partir de la dirección coincida con una de las direcciones devueltas para ese nombre de host. Las búsquedas dobles también evitan que los clientes con direcciones no registradas se conecten a su servidor. El valor predeterminado es "Desactivado" para evitar los posibles problemas de rendimiento del servidor con la resolución de nombres de host

SSLOptions [AllowDH] [AllowRC4] [AllowSSL3] [DenyCBC] [DenyTLS1.0] [MaxTLS1.0] [MaxTLS1.1] [MaxTLS1.2] [MaxTLS1.3] [MinTLS1.0] [MinTLS1.1] [MinTLS1.2] [MinTLS1.3] [NoSystem]
SSLOptions None
Establece opciones de cifrado (solo en /etc/cups/client.conf). Por defecto, CUPS solo admite cifrado usando TLS v1.0 o superior utilizando suites de cifrado seguras conocidas. La seguridad se reduce cuando se utilizan las opciones Allow. La seguridad se mejora cuando se utilizan las opciones Deny. La opción AllowDH habilita suites de cifrado que usan negociación de claves Diffie-Hellman simple (no compatible con sistemas que usan GNU TLS). La opción AllowRC4 habilita las suites de cifrado RC4 de 128 bits, que son necesarias para algunos clientes antiguos. La opción AllowSSL3 habilita SSL v3.0, que es necesaria para algunos clientes antiguos que no admiten TLS v1.0. La opción DenyCBC deshabilita todas las suites de cifrado CBC. La opción DenyTLS1.0 deshabilita el soporte de TLS v1.0; esto establece la versión mínima del protocolo en TLS v1.1. Las opciones MinTLS establecen la versión mínima de TLS a admitir. Las opciones MaxTLS establecen la versión máxima de TLS a admitir. La opción NoSystem deshabilita la aplicación de la política criptográfica del sistema. No todos los sistemas operativos admiten TLS 1.3 en este momento.

NOMBRES DE MÉTODOS HTTP

Los siguientes métodos HTTP son compatibles con cupsd(8):

GET
Utilizado por un cliente para descargar iconos y otros recursos de la impresora y para acceder a la interfaz web de CUPS.
HEAD
Utilizado por un cliente para obtener el tipo, tamaño y fecha de modificación de recursos.
OPTIONS
Utilizado por un cliente para establecer una conexión segura (SSL/TLS).
POST
Utilizado por un cliente para enviar solicitudes IPP y formularios HTML desde la interfaz web de CUPS.
PUT
Utilizado por un cliente para cargar archivos de configuración.
