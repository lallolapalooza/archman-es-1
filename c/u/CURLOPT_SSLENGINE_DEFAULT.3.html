CURLOPT_SSLENGINE_DEFAULT(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSLENGINE_DEFAULT(3) Manual de funciones de la biblioteca CURLOPT_SSLENGINE_DEFAULT(3)

NOMBRE

CURLOPT_SSLENGINE_DEFAULT - establecer el motor SSL como predeterminado

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLENGINE_DEFAULT, long val);

DESCRIPCIÓN

Pase un `long` establecido a 1 para hacer que el motor criptográfico ya especificado sea el predeterminado para las operaciones criptográficas (asimétricas).

Esta opción no tiene ningún efecto a menos que se establezca después de CURLOPT_SSLENGINE(3).

PREDETERMINADO

Ninguno

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE, "dynamic");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE_DEFAULT, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.3

VALOR DE RETORNO

CURLE_OK - El motor se estableció como predeterminado.

CURLE_SSL_ENGINE_SETFAILED - No se pudo establecer el motor como predeterminado.

CURLE_NOT_BUILT_IN - La opción no está incorporada, OpenSSL no es el backend SSL.

CURLE_UNKNOWN_OPTION - Opción no reconocida.

CURLE_OUT_OF_MEMORY - Espacio insuficiente en el heap.

VER TAMBIÉN
