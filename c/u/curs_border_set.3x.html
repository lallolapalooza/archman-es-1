curs_border_set(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_border_set(3X) Llamadas a biblioteca curs_border_set(3X)

NOMBRE

border_set, wborder_set, box_set, hline_set, whline_set, mvhline_set, mvwhline_set, vline_set, wvline_set, mvvline_set, mvwvline_set - dibujar bordes y líneas en una ventana de curses con caracteres anchos

SINOPSIS

#include <curses.h>
int border_set(
   const cchar_t *ls, const cchar_t *rs,
   const cchar_t *ts, const cchar_t *bs,
   const cchar_t *tl, const cchar_t *tr,
   const cchar_t *bl, const cchar_t *br);
int wborder_set(
   WINDOW *win,
   const cchar_t *ls, const cchar_t *rs,
   const cchar_t *ts, const cchar_t *bs,
   const cchar_t *tl, const cchar_t *tr,
   const cchar_t *bl, const cchar_t *br);
int box_set(
   WINDOW *win,
   const cchar_t *verch,
   const cchar_t *horch);
int hline_set(
   const cchar_t *wch, int n);
int whline_set(
   WINDOW *win,
   const cchar_t *wch, int n);
int mvhline_set(
   int y, int x,
   const cchar_t *wch, int n);
int mvwhline_set(
   WINDOW *win,
   int y, int x,
   const cchar_t *wch, int n);
int vline_set(
   const cchar_t *wch, int n);
int wvline_set(
   WINDOW *win,
   const cchar_t *wch, int n);
int mvvline_set(
   int y, int x,
   const cchar_t *wch, int n);
int mvwvline_set(
   WINDOW *win,
   int y, int x,
   const cchar_t *wch, int n);

DESCRIPCIÓN

Las funciones border_set y wborder_set dibujan un borde alrededor de los bordes de la ventana actual o especificada. Estas funciones no cambian la posición del cursor y no envuelven.

Aparte de la ventana, cada argumento es un carácter complejo con atributos:

ls - lado izquierdo,
rs - lado derecho,
ts - lado superior,
bs - lado inferior,
tl - esquina superior izquierda,
tr - esquina superior derecha,
bl - esquina inferior izquierda, y
br - esquina inferior derecha.

Si alguno de estos argumentos es cero, entonces se utilizan en su lugar los valores predeterminados correspondientes (definidos en curses.h):

WACS_VLINE,
WACS_VLINE,
WACS_HLINE,
WACS_HLINE,
WACS_ULCORNER,
WACS_URCORNER,
WACS_LLCORNER, y
WACS_LRCORNER.

box_set(win, verch, horch); es una abreviatura de la siguiente llamada:

wborder_set(win, verch, verch,
horch, horch, NULL, NULL, NULL, NULL);

Las funciones *line_set utilizan wch para dibujar una línea que comienza en la posición actual del cursor en la ventana. La línea tiene como máximo n caracteres de longitud o tantos como quepan en la ventana. La posición actual del cursor no se modifica.

Las funciones hline_set, mvhline_set, mvwhline_set, y whline_set dibujan una línea que avanza hacia la última columna de la misma línea.

Las funciones vline_set, mvvline_set, mvwvline_set, y wvline_set dibujan una línea que avanza hacia la última línea de la ventana.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devuelven OK. En caso contrario, devuelven ERR.

Las funciones que utilizan un parámetro de ventana devuelven un error si es nulo.

Las funciones prefijadas con “mv” primero realizan un movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Tenga en cuenta que border_set, hline_set, mvhline_set, mvvline_set, mvwhline_set, mvwvline_set y vline_set pueden ser macros.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4.
