curl_formget(3)

Paquete: curl

Licencias: MIT

curl_formget(3) Manual de funciones de la biblioteca curl_formget(3)

NOMBRE

curl_formget - serializa una cadena de formulario multipart POST

SINOPSIS

#include <curl/curl.h>
int curl_formget(struct curl_httppost * form, void *userp,
                 curl_formget_callback append);

DESCRIPCIÓN

La API de formularios (incluida esta función) está obsoleta desde libcurl 7.56.0.

curl_formget() serializa datos construidos previamente con curl_formadd(3). Acepta un puntero void como segundo argumento llamado userp, que se pasa como primer argumento a la función curl_formget_callback.

 typedef size_t (*curl_formget_callback)(void *userp, const char *buf,
                                         size_t len);"

El callback curl_formget_callback se invoca para cada parte de la cadena POST de HTTP. El búfer de caracteres pasado al callback no debe ser liberado. El callback debe devolver la longitud del búfer que se le pasó en caso de éxito.

Si se utiliza la opción CURLFORM_STREAM en el formulario POST, impide que curl_formget(3) funcione hasta que hayas realizado la solicitud HTTP real. Esto se debe a que solo entonces libcurl sabrá qué callback de lectura usar.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

size_t print_httppost_callback(void *arg, const char *buf, size_t len)
{
  fwrite(buf, len, 1, stdout);
  (*(size_t *) arg) += len;
  return len;
}
size_t print_httppost(struct curl_httppost *post)
{
  size_t total_size = 0;
  if(curl_formget(post, &total_size, print_httppost_callback)) {
    return (size_t) -1;
  }
  return total_size;
}

DISPONIBILIDAD

Añadido en curl 7.15.5

VALOR DE RETORNO

0 significa que todo estuvo bien, cualquier valor distinto de cero indica un error.

VER TAMBIÉN

curl_formadd(3), curl_mime_init(3)
