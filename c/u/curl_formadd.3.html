Paquete: curl

curl_formadd(3) Manual de Funciones de Biblioteca curl_formadd(3)

NOMBRE

curl_formadd - añadir una sección a un formulario multipart POST

SINOPSIS

#include <curl/curl.h>
CURLFORMcode curl_formadd(struct curl_httppost **firstitem,
                          struct curl_httppost **lastitem, ...);

DESCRIPCIÓN

Esta función está obsoleta. Use en su lugar curl_mime_init(3).

curl_formadd() se utiliza para añadir secciones al construir un formulario multipart POST. Añada una sección a la vez hasta que haya añadido todas las secciones que desee incluir y luego pase el puntero firstitem como parámetro a CURLOPT_HTTPPOST(3). lastitem se establece después de cada llamada a curl_formadd(3) y en invocaciones repetidas, debe dejarse como está para permitir que las invocaciones repetidas encuentren el final de la lista más rápidamente.

Después del puntero lastitem siguen los argumentos reales.

Los punteros firstitem y lastitem deben apuntar ambos a NULL en la primera llamada a esta función. Todos los datos de la lista son asignados por la propia función. Debe llamar a curl_formfree(3) en el firstitem después de que se haya completado el formulario POST para liberar los recursos.

Usar POST con HTTP 1.1 implica el uso de una cabecera "Expect: 100-continue". Puede deshabilitar esta cabecera con CURLOPT_HTTPHEADER(3) como de costumbre.

Primero, hay algunos conceptos básicos que necesita comprender sobre los formularios multipart POST. Cada parte consta de al menos un NOMBRE y un CONTENIDO. Si la parte está hecha para subir archivos, también hay un TIPO DE CONTENIDO almacenado y un NOMBRE DE ARCHIVO. A continuación, discutimos qué opciones utiliza para establecer estas propiedades en las partes que desea añadir a su POST.

Las opciones listadas primero son para hacer partes normales. Las opciones de CURLFORM_FILE a CURLFORM_BUFFERLENGTH son para partes de carga de archivos.

OPCIONES

CURLFORM_COPYNAME
seguido de una cadena que proporciona el nombre de esta parte. libcurl copia la cadena para que su aplicación no necesite conservarla después de esta llamada a función. Si el nombre no termina en nulo, debe establecer su longitud con CURLFORM_NAMELENGTH. El nombre no tiene permitido contener bytes con valor cero. Los datos copiados son liberados por curl_formfree(3).
CURLFORM_PTRNAME
seguido de una cadena que proporciona el nombre de esta parte. libcurl utiliza el puntero y se refiere a los datos en su aplicación, por lo que debe asegurarse de que permanezcan hasta que curl ya no los necesite. Si el nombre no termina en nulo, debe establecer su longitud con CURLFORM_NAMELENGTH. El nombre no tiene permitido contener bytes con valor cero.
CURLFORM_COPYCONTENTS
seguido de un puntero a los contenidos de esta parte, los datos reales a enviar. libcurl copia los datos proporcionados, por lo que su aplicación no necesita conservarlos después de esta llamada a función. Si los datos no terminan en nulo, o si desea que contengan bytes nulos, debe establecer la longitud del nombre con CURLFORM_CONTENTSLENGTH. Los datos copiados son liberados por curl_formfree(3).
CURLFORM_PTRCONTENTS
seguido de un puntero a los contenidos de esta parte, los datos reales a enviar. libcurl utiliza el puntero y se refiere a los datos en su aplicación, por lo que debe asegurarse de que permanezcan hasta que curl ya no los necesite. Si los datos no terminan en nulo, o si desea que contengan bytes nulos, debe establecer su longitud con CURLFORM_CONTENTSLENGTH.
CURLFORM_CONTENTLEN
seguido de un valor curl_off_t que indica la longitud de los contenidos. Tenga en cuenta que para los contenidos de CURLFORM_STREAM, esta opción es obligatoria.

Si pasa un 0 (cero) para esta opción, libcurl llama a strlen() sobre los contenidos para determinar el tamaño. Si realmente desea enviar un contenido de cero bytes, debe asegurarse de que strlen() sobre el puntero de datos devuelva cero.

CURLFORM_CONTENTSLENGTH
(Esta opción está obsoleta. Use en su lugar CURLFORM_CONTENTLEN.)

seguido de un long que indica la longitud de los contenidos. Tenga en cuenta que para los contenidos de CURLFORM_STREAM, esta opción es obligatoria.

Si pasa un 0 (cero) para esta opción, libcurl llama a strlen() sobre los contenidos para determinar el tamaño. Si realmente desea enviar un contenido de cero bytes, debe asegurarse de que strlen() sobre el puntero de datos devuelva cero.

CURLFORM_FILECONTENT
seguido de un nombre de archivo, hace que ese archivo se lea y sus contenidos se utilicen como datos en esta parte. Esta parte no se convierte automáticamente en una parte de carga de archivos simplemente porque sus datos se leyeron de un archivo.

El archivo especificado debe mantenerse disponible hasta que la transferencia asociada se complete.

CURLFORM_FILE
seguido de un nombre de archivo, convierte esta parte en una parte de carga de archivos. Establece el campo filename con el nombre base del nombre de archivo proporcionado, lee los contenidos del archivo y los pasa como datos, y establece el tipo de contenido si el archivo dado coincide con una de las extensiones de archivo internas conocidas. Para CURLFORM_FILE, el usuario puede enviar uno o más archivos en una parte proporcionando múltiples argumentos CURLFORM_FILE, cada uno seguido del nombre de archivo (y cada CURLFORM_FILE puede tener un CURLFORM_CONTENTTYPE).

El archivo de carga proporcionado debe existir en su totalidad en el sistema de archivos ya cuando comience la carga, ya que libcurl necesita leer el tamaño correcto del archivo de antemano.

El archivo especificado debe mantenerse disponible hasta que la transferencia asociada se complete.

CURLFORM_CONTENTTYPE
se utiliza en combinación con CURLFORM_FILE. Seguido de un puntero a una cadena que proporciona el tipo de contenido para esta parte, posiblemente en lugar de uno elegido internamente.
CURLFORM_FILENAME
se utiliza en combinación con CURLFORM_FILE. Seguido de un puntero a una cadena, le dice a libcurl que use la cadena dada como el filename en la parte de carga de archivos en lugar del nombre de archivo real.
CURLFORM_BUFFER
se utiliza para partes de carga de archivos personalizadas sin usar CURLFORM_FILE. Le dice a libcurl que los contenidos del archivo ya están presentes en un búfer. El parámetro es una cadena que proporciona el campo filename en la cabecera de contenido.
CURLFORM_BUFFERPTR
se utiliza en combinación con CURLFORM_BUFFER. El parámetro es un puntero al búfer que se va a cargar. Este búfer no debe liberarse hasta después de que se haya llamado a curl_easy_cleanup(3). También debe usar CURLFORM_BUFFERLENGTH para establecer el número de bytes en el búfer.
CURLFORM_BUFFERLENGTH
se utiliza en combinación con CURLFORM_BUFFER. El parámetro es un long que indica la longitud del búfer.
CURLFORM_STREAM
Indica a libcurl que utilice la función de devolución de llamada CURLOPT_READFUNCTION(3) para obtener datos. El parámetro que pase a CURLFORM_STREAM es el puntero que se pasa al cuarto argumento de la función de devolución de llamada de lectura. Si desea que la parte parezca una parte de carga de archivos, establezca también el parámetro CURLFORM_FILENAME. Tenga en cuenta que al usar CURLFORM_STREAM, también se debe establecer CURLFORM_CONTENTSLENGTH con la longitud total esperada de la parte, a menos que el formulario POST se envíe codificado en fragmentos.
CURLFORM_ARRAY
Otra posibilidad para enviar opciones a curl_formadd() es la opción CURLFORM_ARRAY, que pasa un puntero a una matriz curl_forms struct

EJEMPL

O 
#include <string.h> /* para strlen */
static const char record[]="data in a buffer";
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_httppost *post = NULL;
    struct curl_httppost *last = NULL;
    char namebuffer[] = "name buffer";
    long namelength = strlen(namebuffer);
    char buffer[] = "test buffer";
    char htmlbuffer[] = "<HTML>test buffer</HTML>";
    long htmlbufferlength = strlen(htmlbuffer);
    struct curl_forms forms[3];
    char file1[] = "my-face.jpg";
    char file2[] = "your-face.jpg";
    /* añadir un carácter nulo en htmlbuffer, para demostrar que
       las transferencias de buffers que contienen caracteres nulos realmente funcionan
    */
    htmlbuffer[8] = '\0';
    /* Añadir sección simple de nombre/contenido */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "name",
                 CURLFORM_COPYCONTENTS, "content", CURLFORM_END);
    /* Añadir sección simple de nombre/contenido/tipo de contenido */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "htmlcode",
                 CURLFORM_COPYCONTENTS, "<HTML></HTML>",
                 CURLFORM_CONTENTTYPE, "text/html", CURLFORM_END);
    /* Añadir sección de nombre/puntero a contenido */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "name_for_ptrcontent",
                 CURLFORM_PTRCONTENTS, buffer, CURLFORM_END);
    /* Añadir sección de puntero a nombre/puntero a contenido */
    curl_formadd(&post, &last, CURLFORM_PTRNAME, namebuffer,
                 CURLFORM_PTRCONTENTS, buffer, CURLFORM_NAMELENGTH,
                 namelength, CURLFORM_END);
    /* Añadir sección de nombre/puntero a contenido/tipo de contenido */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "html_code_with_hole",
                 CURLFORM_PTRCONTENTS, htmlbuffer,
                 CURLFORM_CONTENTSLENGTH, htmlbufferlength,
                 CURLFORM_CONTENTTYPE, "text/html", CURLFORM_END);
    /* Añadir sección simple de archivo */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "picture",
                 CURLFORM_FILE, "my-face.jpg", CURLFORM_END);
    /* Añadir sección de archivo/tipo de contenido */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "picture",
                 CURLFORM_FILE, "my-face.jpg",
                 CURLFORM_CONTENTTYPE, "image/jpeg", CURLFORM_END);
    /* Añadir sección de dos archivos */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "pictures",
                 CURLFORM_FILE, "my-face.jpg",
                 CURLFORM_FILE, "your-face.jpg", CURLFORM_END);
    /* Añadir sección de dos archivos usando CURLFORM_ARRAY */
    forms[0].option = CURLFORM_FILE;
    forms[0].value  = file1;
    forms[1].option = CURLFORM_FILE;
    forms[1].value  = file2;
    forms[2].option  = CURLFORM_END;
    /* Añadir un buffer para subir */
    curl_formadd(&post, &last,
                 CURLFORM_COPYNAME, "name",
                 CURLFORM_BUFFER, "data",
                 CURLFORM_BUFFERPTR, record,
                 CURLFORM_BUFFERLENGTH, sizeof(record),
                 CURLFORM_END);
    /* no se necesita opción para el marcador de fin */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "pictures",
                 CURLFORM_ARRAY, forms, CURLFORM_END);
    /* Añadir el contenido de un archivo como un valor de texto de post normal */
    curl_formadd(&post, &last, CURLFORM_COPYNAME, "filecontent",
                 CURLFORM_FILECONTENT, ".bashrc", CURLFORM_END);
    /* Establecer la información del formulario */
    curl_easy_setopt(curl, CURLOPT_HTTPPOST, post);
    curl_easy_perform(curl);
    curl_easy_cleanup(curl);
    curl_formfree(post);
  }
}

O

Obsoleto en 7.56.0. Antes de esta versión, se permitía que los nombres de campo contuvieran bytes con valor cero. El pseudo-nombre de archivo "-" para leer stdin está desaconsejad

o aunque sigue siendo compatible, pero los datos no se leen antes de ser realmente enviados: el tamaño efectivo de los datos no puede entonces determinarse automáticamente, result
ando en una transferencia con codificación por trozos (chunked). Las barras invertidas y comillas dobles en los nombres de campo y de archivo se escapan ahora antes de la transmisión.
