curs_move(3X) Llamadas a la biblioteca curs_move(3X)

NOMBRE

move, wmove - mover el cursor en una ventana de curses

SINOPSIS

#include <curses.h>
int move(int y, int x);
int wmove(WINDOW *win, int y, int x);

DESCRIPCIÓN

wmove reubica el cursor asociado con la ventana de curses win a la línea y y columna x. El cursor del terminal no se moverá hasta que se llame a refresh(3X). La posición (y, x) es relativa a la esquina superior izquierda de la ventana, que tiene coordenadas (0, 0). ncurses(3X) describe la variante move de esta función.

VALOR DEVUELTO

Estas funciones devuelven OK en caso de éxito y ERR en caso de fallo.

Fallas si la posición (y, x) está fuera de los límites de la ventana.

wmove falla si su argumento puntero a WINDOW es NULL.

NOTAS

move puede implementarse como una macro.

PORTABILIDAD

X/Open Curses, Issue 4 describe estas funciones.

VER TAMBIÉN

curses(3X), curs_refresh(3X)
