Paquete: ncurses

curs_memleaks(3X) Llamadas a biblioteca curs_memleaks(3X)

NOMBRE

exit_curses, exit_terminfo - comprobar fugas de memoria en curses

SINOPSIS

#include <curses.h>
void exit_curses(int code);
#include <term.h>
void exit_terminfo(int code);
/* obsoleto (intencionalmente no declarado en curses.h o term.h) */
void _nc_freeall(void);
void _nc_free_and_exit(int code);
void _nc_free_tinfo(int code);

DESCRIPCIÓN

Estas funciones se utilizan para simplificar el análisis de fugas de memoria en la biblioteca ncurses.

Cualquier implementación de curses no debe liberar la memoria asociada con una pantalla, ya que (incluso después de llamar a endwin(3X)), debe estar disponible para su uso en la siguiente llamada a refresh(3X). También hay fragmentos de memoria reservados por motivos de rendimiento. Esto dificulta el análisis de aplicaciones de curses para detectar fugas de memoria. Al usar la versión de depuración especialmente configurada de la biblioteca ncurses, las aplicaciones pueden llamar a funciones que liberan esos fragmentos de memoria, simplificando el proceso de comprobación de fugas de memoria.

Algunas de las funciones tienen nombres con el prefijo “_nc_” porque no están destinadas a su uso en la biblioteca no depurable:

_nc_freeall
Esto libera (casi) toda la memoria asignada por ncurses.
_nc_free_and_exit
Esto libera la memoria asignada por ncurses (similar a _nc_freeall) y termina el programa. Es preferible a _nc_freeall ya que parte de esa memoria puede ser necesaria para que la aplicación siga en ejecución. Simplemente salir (con el código de salida dado) es más seguro.
_nc_free_tinfo
Use esta función si solo se utilizan las funciones de bajo nivel de terminfo (y la biblioteca correspondiente). Al igual que _nc_free_and_exit, sale del programa después de liberar la memoria.

Las funciones con prefijo “_nc” normalmente no están disponibles; deben incluirse en la biblioteca en tiempo de compilación usando la opción --disable-leaks. Eso compila código que libera memoria que normalmente no se liberaría.

Las funciones exit_curses y exit_terminfo llaman a _nc_free_and_exit y _nc_free_tinfo si la biblioteca está configurada para admitir la comprobación de fugas de memoria. Si la biblioteca no está configurada para admitir la comprobación de fugas de memoria, simplemente llaman a exit.

VALOR DE RETORNO

Estas funciones no devuelven un valor.

PORTABILIDAD

Estas funciones no forman parte de X/Open Curses; ni otras implementaciones de curses proporcionan una característica similar.

En cualquier implementación de X/Open Curses, una aplicación puede liberar parte de la memoria asignada por curses:

•
La parte portable de exit_curses se puede liberar usando delscreen, pasando el puntero SCREEN devuelto por newterm.
En algunas implementaciones, existe una variable global sp que se podría usar, por ejemplo, si la pantalla se inicializó solo con initscr.
•
La parte portable de exit_terminfo se puede liberar usando del_curterm.
En este caso, existe una variable global cur_term que se puede usar como parámetro.

VER TAMBIÉN

curses(3X), curs_initscr(3X), curs_terminfo(3X)
