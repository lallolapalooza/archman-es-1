DESCRIPCIÓ

N

curl_mime_data_cb(3) establece la fuente de datos del contenido del cuerpo de una parte mime a partir de una función de callback de lectura de

datos.

part es la parte a la que se le asignarán los

contenidos.

datasize es el número de bytes que se espera que proporcione la función de callback de

lectura.

readfunc es un puntero a una función de callback de lectura de datos, con una firma como la mostrada por el prototipo anterior. No se puede establecer en

NULL.

seekfunc es un puntero a una función de callback de búsqueda, con una firma como la mostrada por el prototipo anterior. Esta función se utiliza al reenviar datos (es decir: después de una redirección); este puntero puede establecerse en NULL, en cuyo caso un reenvío podría no ser

posible.

freefunc es un puntero a una función de callback de liberación de recursos del usuario, con una firma como la mostrada por el prototipo anterior. Si no hay ningún recurso que liberar, se puede establecer con seguridad en NULL. Esta función se llama al liberar la estructura

mime.

arg es un argumento definido por el usuario para las funciones de

callback.

La función de callback de lectura es llamada por libcurl tan pronto como necesita leer datos para enviarlos al par - como si le pidieras que suba o publique datos en el servidor. El área de datos a la que apunta el puntero buffer debe ser rellenada con un máximo de size multiplicado por nitems número de bytes por tu

función.

Tu función de lectura debe entonces devolver el número real de bytes que almacenó en esa área de memoria. Devolver 0 señala el fin de archivo a la biblioteca y hace que detenga la transferencia

actual.

Si detienes la transferencia actual devolviendo 0 "prematuramente" (es decir, antes de que el servidor lo esperara, como cuando has dicho que pretendes subir N bytes y sin embargo subes menos de N bytes), puedes experimentar que el servidor "se cuelga" esperando el resto de los datos que no

llegan.

La función de callback de lectura puede devolver CURL_READFUNC_ABORT para detener la operación actual inmediatamente, resultando en un código de error CURLE_ABORTED_BY_CALLBACK de la

transferencia.

La función de callback puede devolver CURL_READFUNC_PAUSE para hacer que la lectura de esta conexión se pause. Ver curl_easy_pause(3) para más

detalles.

La función de búsqueda es llamada por libcurl para rebobinar datos del flujo de entrada o para buscar una posición determinada. La función debe funcionar como fseek(3) o lseek(3) y recibe SEEK_SET, SEEK_CUR o SEEK_END como argumento para origin, aunque actualmente libcurl solo pasa

SEEK_SET.

La función de callback debe devolver CURL_SEEKFUNC_OK en caso de éxito, CURL_SEEKFUNC_FAIL para hacer que la operación de subida falle o CURL_SEEKFUNC_CANTSEEK para indicar que aunque la búsqueda falló, libcurl es libre de sortear el problema si es posible. Esto último a veces se puede hacer leyendo de la entrada o algo

similar.

Se debe tener cuidado si la parte está vinculada a un manejador fácil de curl que se duplica posteriormente: el argumento puntero arg también se duplica, resultando en que el elemento apuntado se comparta entre el manejador original y el copiado. En particular, se debe prestar especial atención al código del procedimiento freefunc ya que enton

ces se llama dos veces
con el mismo argumento.

EJEMPL

O

Enviar una cadena de datos enorme causa que se asigne la misma cantidad de memoria: para evitar el consumo de recursos por sobrecarga, se podría querer usar una fuente de callback para evitar la duplicación de datos. En este caso, los datos originales deben retenerse hasta después de que la transferencia

termine. 
#include <string.h> /* for memcpy */
char hugedata[512000];
struct ctl {
  char *buffer;
  curl_off_t size;
  curl_off_t position;
};
size_t read_callback(char *buffer, size_t size, size_t nitems, void *arg)
{
  struct ctl *p = (struct ctl *) arg;
  curl_off_t sz = p->size - p->position;
  nitems *= size;
  if(sz > nitems)
    sz = nitems;
  if(sz)
    memcpy(buffer, p->buffer + p->position, sz);
  p->position += sz;
  return sz;
}
int seek_callback(void *arg, curl_off_t offset, int origin)
{
  struct ctl *p = (struct ctl *) arg;
  switch(origin) {
  case SEEK_END:
    offset += p->size;
    break;
  case SEEK_CUR:
    offset += p->position;
    break;
  }
  if(offset < 0)
    return CURL_SEEKFUNC_FAIL;
  p->position = offset;
  return CURL_SEEKFUNC_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_mime *mime = curl_mime_init(curl);
    curl_mimepart *part = curl_mime_addpart(mime);
    struct ctl hugectl;
    hugectl.buffer = hugedata;
    hugectl.size = sizeof(hugedata);
    hugectl.position = 0;
    curl_mime_data_cb(part, hugectl.size, read_callback,
                      seek_callback, NULL, &hugectl);
  }
}
