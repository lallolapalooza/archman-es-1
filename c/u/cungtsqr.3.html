Documentación de la función/subrutina

subroutine cungtsqr (integer m, integer n, integer mb, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( * ) work, integer lwork, integer info)

CUNGTSQR

Propósito:

!>
!> CUNGTSQR genera una matriz compleja M por N, Q_out, con columnas ortonormales,
!> que son las primeras N columnas de un producto de matrices unitarias complejas
!> de orden M que son devueltas por CLATSQR
!>
!>      Q_out = primeras_N_columnas_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Ver la documentación de CLATSQR.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. M >= N >= 0.
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque de filas utilizado por CLATSQR para devolver
!>          los arrays A y T. MB > N.
!>          (Nota: si MB > M, entonces se usa M en lugar de MB
!>          como tamaño del bloque de filas).
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque de columnas utilizado por CLATSQR para devolver
!>          los arrays A y T. NB >= 1.
!>          (Nota: si NB > N, entonces se usa N en lugar de NB
!>          como tamaño del bloque de columnas).
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>
!>          En la entrada:
!>
!>             Los elementos en y por encima de la diagonal no se acceden.
!>             Los elementos por debajo de la diagonal representan la matriz
!>             trapezoidal inferior unitaria en bloques V calculada por CLATSQR
!>             que define las matrices de entrada Q_in(k) (los unos en la
!>             diagonal no se almacenan) (mismo formato que la salida A
!>             por debajo de la diagonal en CLATSQR).
!>
!>          En la salida:
!>
!>             El array A contiene una matriz ortonormal M por N, Q_out,
!>             es decir, las columnas de A son vectores unitarios ortogonales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

T

!>          T es un array COMPLEX,
!>          dimensión (LDT, N * NIRB)
!>          donde NIRB = Número_de_bloques_de_filas_de_entrada
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Sea NICB = Número_de_bloques_de_columnas_de_entrada
!>                   = CEIL(N/NB)
!>
!>          Losń reflectores de bloque triangulares superiores utilizados para definir las
!>          matrices de entrada Q_in(k), k=(1:NIRB*NICB). Los bloques
!>          reflectores se almacenan en forma compacta en NIRB bloques de
!>          secuencias de reflectores. Cada una de las NIRB secuencias de reflectores
!>          de bloque se almacena en un bloque de columna más grande de NB por N en T
!>          y consiste en NICB bloques de columna más pequeños de NB por NB triangulares superiores.
!>          (mismo formato que la salida T en CLATSQR).
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.
!>          LDT >= max(1,min(NB1,N)).
!>

WORK

!>          (espacio de trabajo) array COMPLEX, dimensión (MAX(2,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= (M+NB)*N.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo.
!>          La rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>
