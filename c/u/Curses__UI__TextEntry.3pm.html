Curses::UI::TextEntry(3) Documentación de Perl aportada por el usuario Curses::UI::TextEntry(3)

NOMBRE

Curses::UI::TextEntry - crear y manipular widgets de entrada de texto

JERARQUÍA DE CLASES

Curses::UI::Widget
Curses::UI::Searchable
   |
   +----Curses::UI::TextEditor
           |
           +----Curses::UI::TextEntry

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $textentry = $win->add(
    'mytextentry', 'TextEntry'
);
$textentry->focus();
my $text = $textentry->get();

DESCRIPCIÓN

Curses::UI::TextEntry es un widget que se puede usar para crear un widget de entrada de texto. Esta clase se deriva de Curses::UI::TextEditor. Lo único especial de esta clase es que la opción -singleline se fuerza a un valor verdadero. Así que para el uso de Curses::UI::TextEntry, consulte Curses::UI::TextEditor.

VER TAMBIÉN

Curses::UI, Curses::UI::TextEditor,
