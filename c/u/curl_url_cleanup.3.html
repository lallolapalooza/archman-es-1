curl_url_cleanup(3)

Paquete: curl

Licencias: MIT

curl_url_cleanup(3) Manual de funciones de biblioteca curl_url_cleanup(3)

NOMBRE

curl_url_cleanup - liberar el manejador de URL

SINOPSIS

#include <curl/curl.h>
void curl_url_cleanup(CURLU *handle);

DESCRIPCIÓN

Libera todos los recursos asociados con el manejador CURLU dado.

Pasar un puntero NULL en handle hace que esta función regrese inmediatamente sin realizar ninguna acción.

Cualquier uso del handle después de que esta función haya sido llamada y haya regresado, es ilegal.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURLU *url = curl_url();
  curl_url_set(url, CURLUPART_URL, "https://example.com", 0);
  curl_url_cleanup(url);
}

DISPONIBILIDAD

Añadido en curl 7.62.0

VALOR DE RETORNO

ninguno
