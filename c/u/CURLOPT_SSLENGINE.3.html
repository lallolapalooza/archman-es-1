CURLOPT_SSLENGINE(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSLENGINE(3) Manual de funciones de biblioteca CURLOPT_SSLENGINE(3)

NOMBRE

CURLOPT_SSLENGINE - Establecer motor o proveedor SSL

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLENGINE, char *id);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. Se utiliza como identificador del motor o proveedor que desea utilizar para su clave privada. OpenSSL 1 tenía motores, OpenSSL 3 tiene proveedores.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Al solicitar a libcurl que utilice un proveedor, la aplicación también puede proporcionar opcionalmente una propiedad, un conjunto de pares nombre-valor. Dicha propiedad se puede especificar separada del nombre con dos puntos (:).

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala en NULL para desactivar su uso nuevamente.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE, "dynamic");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.3

VALOR DE RETORNO

CURLE_OK - Motor encontrado.

CURLE_SSL_ENGINE_NOTFOUND - Motor no encontrado, o OpenSSL no fue compilado con soporte de motores.

CURLE_SSL_ENGINE_INITFAILED - Motor encontrado pero la inicialización falló.

CURLE_NOT_BUILT_IN - Opción no compilada, OpenSSL no es el backend SSL.

CURLE_UNKNOWN_OPTION - Opción no reconocida.

CURLE_OUT_OF_MEMORY - Espacio en el heap insuficiente.

VER TAMBIÉN

CURLINFO_SSL_ENGINES(3), CURLOPT_SSLENGINE_DEFAULT(3), CURLOPT_SSLKEY(3)
