curl_ws_start_frame(3)

Paquete: curl

Licencias: MIT

curl_ws_start_frame(3) Manual de funciones de la biblioteca curl_ws_start_frame(3)

NOMBRE

curl_ws_start_frame - iniciar un nuevo frame WebSocket

SINOPSIS

#include <curl/curl.h>
CURLcode curl_ws_start_frame(CURL *curl,
                             unsigned int flags,
                             curl_off_t frame_len);

DESCRIPCIÓN

Añade la cabecera del frame WebSocket para las flags y longitud dadas al búfer de envío de la transferencia para datos codificados en WebSocket. Previsto para su uso en una devolución de llamada CURLOPT_READFUNCTION(3).

Al usar una CURLOPT_READFUNCTION(3) en una transferencia WebSocket, cualquier dato devuelto por esa función se envía como un frame de tipo CURLWS_BINARY con la longitud igual a la cantidad de datos leídos.

Para enviar frames más grandes o frames de otro tipo, llame a curl_ws_start_frame() dentro de la función de lectura y luego devuelva los datos que pertenecen al frame.

La función falla si un frame anterior aún no se ha leído completamente. También falla en CURLWS_RAW_MODE.

La función de lectura en libcurl normalmente trata un valor de retorno de 0 como indicación de fin de archivo y detiene cualquier lectura posterior. Esto evitaría enviar frames WebSocket de longitud 0.

Sin embargo, si la función de lectura llama a curl_ws_start_frame(), un valor de retorno de 0 *no* se trata como fin de archivo y libcurl vuelve a llamar a la función de lectura.

FLAGS

Soporta todas las flags documentadas en curl_ws_meta(3).

PROTOCOLOS

Esta funcionalidad solo afecta a ws

EJEMPLO

#include <string.h> /* para strlen */
struct read_ctx {
  CURL *easy;
  char *message;
  size_t msg_len;
  size_t nsent;
};
static size_t readcb(char *buf, size_t nitems, size_t buflen, void *p)
{
  struct read_ctx *ctx = p;
  size_t len = nitems * buflen;
  size_t left = ctx->msg_len - ctx->nsent;
  CURLcode result;
  if(!ctx->nsent) {
    /* Queremos enviar un frame TEXT. */
    result = curl_ws_start_frame(ctx->easy, CURLWS_TEXT,
                                 (curl_off_t)ctx->msg_len);
    if(result) {
      fprintf(stderr, "error al iniciar frame: %d\n", result);
      return CURL_READFUNC_ABORT;
    }
  }
  if(left) {
    if(left < len)
      len = left;
    memcpy(buf, ctx->message + ctx->nsent, len);
    ctx->nsent += len;
    return len;
  }
  return 0;
}
int main(void)
{
  CURL *easy;
  struct read_ctx rctx;
  CURLcode res;
  easy = curl_easy_init();
  if(!easy)
    return 1;
  curl_easy_setopt(easy, CURLOPT_URL, "wss://example.com");
  curl_easy_setopt(easy, CURLOPT_READFUNCTION, readcb);
  /* decirle a curl que queremos enviar la carga útil */
  memset(&rctx, 0, sizeof(rctx));
  rctx.easy = easy;
  rctx.message = "¡Hola, amigo!";
  rctx.msg_len = strlen(rctx.message);
  curl_easy_setopt(easy, CURLOPT_READDATA, &rctx);
  curl_easy_setopt(easy, CURLOPT_UPLOAD, 1L);
  /* Realiza la solicitud, res obtiene el código de retorno */
  res = curl_easy_perform(easy);
  /* Comprobar errores */
  if(res != CURLE_OK)
    fprintf(stderr, "curl_easy_perform() falló: %s\n",
            curl_easy_strerror(res));
  /* siempre limpiar */
  curl_easy_cleanup(easy);
  return 0;
}

DISPONIBILIDAD

Añadido en curl 8.16.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error. Consulte libcurl-errors(3). Si se configuró CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el búfer de error cuando se devuelve un valor distinto de cero.

En lugar de bloquear, la función devuelve CURLE_AGAIN. El comportamiento correcto es esperar a que el socket señale que está listo para leer antes de llamar a esta función nuevamente.

Cualquier otro valor distinto de cero indica un error. Consulte la página del manual de libcurl-errors(3) para obtener la lista completa con descripciones.
