CURLOPT_MIME_OPTIONS(3)

Paquete: curl

Licencias: MIT

CURLOPT_MIME_OPTIONS(3) Manual de funciones de biblioteca CURLOPT_MIME_OPTIONS(3)

NOMBRE

CURLOPT_MIME_OPTIONS - establecer indicadores de opciones MIME

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MIME_OPTIONS, long options);

DESCRIPCIÓN

Pasa un long que contiene una máscara de bits de opciones. Cada bit es un indicador booleano utilizado al codificar un árbol MIME o datos de formulario multipartes.

Los bits disponibles son:

CURLMIMEOPT_FORMESCAPE
Indica a libcurl que escape los nombres de campo y de archivo de formulario multipartes utilizando el algoritmo de escape con barra invertida en lugar del cifrado de porcentaje (solo HTTP).

El escape con barra invertida consiste en preceder las barras invertidas y las comillas dobles con una barra invertida. El cifrado de porcentaje mapea todas las ocurrencias de comillas dobles, retorno de carro y salto de línea a %22, %0D y %0A respectivamente.

Antes de la versión 7.81.0, el cifrado de porcentaje nunca se aplicaba.

Los navegadores HTTP solían hacer el escape con barra invertida en el pasado, pero con el tiempo han pasado a utilizar el cifrado de porcentaje. Esta opción permite abordar aplicaciones del lado del servidor que aún no han sido convertidas.

Como ejemplo, considere el campo o nombre de archivo strangename"kind. Cuando se envía el formulario multipart que lo contiene, normalmente se transmite como strangename%22kind. Cuando se establece esta opción, se envía como strangename"kind.

PREDETERMINADO

0, lo que significa deshabilitado.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  curl_mime *form = NULL;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_MIME_OPTIONS, CURLMIMEOPT_FORMESCAPE);
    form = curl_mime_init(curl);
    if(form) {
      curl_mimepart *part = curl_mime_addpart(form);
      if(part) {
        curl_mime_filedata(part, "strange\\file\\name");
        curl_mime_name(part, "strange\"field\"name");
        curl_easy_setopt(curl, CURLOPT_MIMEPOST, form);
        /* Realizar la solicitud */
        curl_easy_perform(curl);
      }
    }
    curl_easy_cleanup(curl);
    curl_mime_free(form);
  }
}

HISTORIAL

El macro CURLMIMEOPT_FORMESCAPE se convirtió en tipo long en la versión 8.16.0; antes de esta versión, era necesario un cast de long al pasarlo a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.81.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).

VER TAMBIÉN
