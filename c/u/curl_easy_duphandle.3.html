curl_easy_duphandle(3)

Paquete: curl

Licencias: MIT

curl_easy_duphandle(3) Manual de funciones de biblioteca curl_easy_duphandle(3)

NOMBRE

curl_easy_duphandle - clonar un manejador easy

SINOPSIS

#include <curl/curl.h>
CURL *curl_easy_duphandle(CURL *handle);

DESCRIPCIÓN

Esta función devuelve un nuevo manejador curl, un duplicado, utilizando todas las opciones previamente establecidas en el handle de entrada de curl. Ambos manejadores pueden ser utilizados independientemente y deben ser liberados con curl_easy_cleanup(3).

Cualquier opción que se haya indicado al manejador de entrada para apuntar (en lugar de copiar) mediante llamadas anteriores a curl_easy_setopt(3), también será apuntada por el nuevo manejador. Por lo tanto, debe asegurarse de mantener los datos disponibles hasta que ambos manejadores hayan sido liberados.

El nuevo manejador no hereda ninguna información de estado, ninguna conexión, ninguna sesión SSL ni cookies. Tampoco hereda estados u opciones de objetos compartidos (creado como si CURLOPT_SHARE(3) se hubiera establecido a NULL).

Si el manejador de origen tiene HSTS o alt-svc habilitados, el duplicado obtiene datos leídos del archivo principal para poblar la caché.

En programas multihilo, esta función debe ser llamada de forma síncrona, el manejador de entrada no puede estar en uso cuando se clona.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    CURL *nother;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    nother = curl_easy_duphandle(curl);
    res = curl_easy_perform(nother);
    curl_easy_cleanup(nother);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9

VALOR DE RETORNO

Si esta función devuelve NULL, algo salió mal y no se devolvió ningún manejador válido.

VER TAMBIÉN
