curl_mime_data(3)

Paquete: curl

Licencias: MIT

curl_mime_data(3) Manual de funciones de la biblioteca curl_mime_data(3)

NOMBRE

curl_mime_data - establece los datos del cuerpo de una parte mime desde la memoria

SINOPSIS

#include <curl/curl.h>
CURLcode curl_mime_data(curl_mimepart *part, const char *data,
                        size_t datasize);

DESCRIPCIÓN

curl_mime_data(3) establece el contenido del cuerpo de una parte mime a partir de datos en memoria.

part es la parte mime a la que se asignan los contenidos, creada con curl_mime_addpart(3).

data apunta a los datos que esta función copia. El almacenamiento puede ser reutilizado de forma segura después de la llamada.

datasize es el número de bytes a los que apunta data. Puede establecerse en CURL_ZERO_TERMINATED para indicar que data es una cadena de caracteres terminada en nulo.

Establecer los contenidos de una parte varias veces es válido: solo se conserva el valor establecido por la última llamada. Es posible anular la asignación de los contenidos de una parte estableciendo data a NULL.

Establecer datos grandes consume memoria: se podría considerar usar curl_mime_data_cb(3) en tal caso.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* crear un manejador mime */
    mime = curl_mime_init(curl);
    /* añadir una parte */
    part = curl_mime_addpart(mime);
    /* añadir datos a la parte  */
    curl_mime_data(part, "contenido crudo para enviar", CURL_ZERO_TERMINATED);
  }
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el búfer de error cuando se devuelve un valor distinto de cero.
