CURLSHOPT_LOCKFUNC(3)

Paquete: curl

Licencias: MIT

CURLSHOPT_LOCKFUNC(3) Manual de Funciones de Librería CURLSHOPT_LOCKFUNC(3)

NOMBRE

CURLSHOPT_LOCKFUNC - callback de bloqueo mutex

SINOPSIS

#include <curl/curl.h>
void lockcb(CURL *handle, curl_lock_data data, curl_lock_access access,
            void *clientp);
CURLSHcode curl_share_setopt(CURLSH *share, CURLSHOPT_LOCKFUNC, lockcb);

DESCRIPCIÓN

Establece un callback de bloqueo mutex para el objeto de compartición, para permitir su uso por múltiples hilos concurrentemente. Hay un callback correspondiente CURLSHOPT_UNLOCKFUNC(3) que se llama cuando el mutex se libera de nuevo.

El argumento lockcb debe ser un puntero a una función que coincida con el prototipo mostrado arriba. Los argumentos de la función de callback son:

handle es el manejador easy actualmente activo en uso cuando se pretende utilizar el objeto de compartición.

El argumento data indica qué tipo de datos libcurl desea bloquear. Asegúrese de que la función de callback use un bloqueo diferente para cada tipo de dato.

access define qué tipo de acceso desea libcurl, compartido o individual.

clientp es el puntero privado que estableció con CURLSHOPT_USERDATA(3). Este puntero no es utilizado por libcurl en sí mismo.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

extern void mutex_lock(CURL *handle, curl_lock_data data,
                       curl_lock_access access, void *clientp);
int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_LOCKFUNC, mutex_lock);
  if(sh)
    printf("Error: %s\n", curl_share_strerror(sh));
}

DISPONIBILIDAD

Añadido en curl 7.10.3

VALOR DE RETORNO

CURLSHE_OK (cero) significa que la opción se estableció correctamente, un valor distinto de cero indica que ocurrió un error. Consulte libcurl-errors(3) para la lista completa con descripciones.

VER TAMBIÉN

CURLSHOPT_UNLOCKFUNC(3), curl_share_cleanup(3), curl_share_init(3), curl_share_setopt(3)
