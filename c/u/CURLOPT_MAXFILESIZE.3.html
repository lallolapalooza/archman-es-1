CURLOPT_MAXFILESIZE(3)

Paquete: curl

Licencias: MIT

CURLOPT_MAXFILESIZE(3) Manual de Funciones de Biblioteca CURLOPT_MAXFILESIZE(3)

NOMBRE

CURLOPT_MAXFILESIZE - tamaño máximo de archivo permitido para descargar

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAXFILESIZE, long size);

DESCRIPCIÓN

Pase un `long` como parámetro. Esto especifica el tamaño (en bytes) máximo aceptado de un archivo para descargar. Si el archivo solicitado se encuentra más grande que este valor, la transferencia se aborta y se devuelve CURLE_FILESIZE_EXCEEDED. Pasar un tamaño cero deshabilita esto, y pasar un tamaño negativo produce un CURLE_BAD_FUNCTION_ARGUMENT.

El tamaño del archivo no siempre se conoce antes del inicio de la descarga, y para tales transferencias esta opción no tiene ningún efecto, incluso si la transferencia de archivo finalmente resulta ser más grande que este límite dado.

Si desea un límite superior a 2 GB, utilice CURLOPT_MAXFILESIZE_LARGE(3).

Desde la versión 8.4.0, esta opción también detiene las transferencias en curso si alcanzan este umbral.

PREDETERMINADO

0, lo que significa deshabilitado.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* rechazar la descarga si es mayor que 1000 bytes */
    curl_easy_setopt(curl, CURLOPT_MAXFILESIZE, 1000L);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.10.8

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_MAXFILESIZE_LARGE(3), CURLOPT_MAX_RECV_SPEED_LARGE(3)
