CURLOPT_SSL_CIPHER_LIST(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSL_CIPHER_LIST(3) Manual de funciones de biblioteca CURLOPT_SSL_CIPHER_LIST(3)

NOMBRE

CURLOPT_SSL_CIPHER_LIST - cifradores a usar para TLS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_CIPHER_LIST, char *list);

DESCRIPCIÓN

Pasa un puntero a char, apuntando a una cadena terminada en nulo que contiene la lista de suites de cifrado a usar para la conexión TLS 1.2 (1.1, 1.0). La lista debe tener una sintaxis correcta, consta de una o más cadenas de suites de cifrado separadas por dos puntos.

Para configurar los cifradores TLS 1.3, consulte CURLOPT_TLS13_CIPHERS(3).

Un ejemplo válido de lista de cifradores con OpenSSL es:

"ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:"
"ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305"

Para Schannel, puede usar esta opción para configurar algoritmos pero no suites de cifrado específicas. Consulte la lista de cifradores para ver algoritmos.

GnuTLS tiene el concepto de una [cadena de prioridad](https://gnutls.org/manual/html_node/Priority-Strings.html) que tiene su propia sintaxis y palabras clave. La cadena establecida a través de CURLOPT_SSL_CIPHER_LIST(3) influye directamente en la configuración de prioridad.

Encuentre más detalles sobre las listas de cifradores en esta URL:


https://curl.se/docs/ssl-ciphers.html

La aplicación no tiene que mantener la cadena disponible después de configurar esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Configúrela a NULL para deshabilitar su uso nuevamente.

POR OMISIÓN

NULL, usa la lista integrada

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL, Schannel, mbedTLS, rustls y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSL_CIPHER_LIST,
                     "ECDHE-ECDSA-CHACHA20-POLY1305:"
                     "ECDHE-RSA-CHACHA20-POLY1305");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Soporte para OpenSSL añadido en 7.9. Soporte para wolfSSL añadido en 7.53.0. Soporte para Schannel añadido en 7.61.0. Soporte para mbedTLS añadido en 8.8.0. Soporte para Rustls añadido en 8.10.0.

Desde curl 8.10.0 devuelve CURLE_NOT_BUILT_IN cuando no es compatible.

DISPONIBILIDAD

Añadido en curl 7.9

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
