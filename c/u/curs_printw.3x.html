curs_printw(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_printw(3X) Llamadas a biblioteca curs_printw(3X)

NOMBRE

printw, wprintw, mvprintw, mvwprintw, vwprintw, vw_printw - escribir salida formateada en una ventana de curses

SINOPSIS

#include <curses.h>
int printw(const char *fmt, ...);
int wprintw(WINDOW *win, const char *fmt, ...);
int mvprintw(int y, int x, const char *fmt, ...);
int mvwprintw(WINDOW *win, int y, int x, const char *fmt, ...);
int vw_printw(WINDOW *win, const char *fmt, va_list varglist);
/* obsoleto */
int vwprintw(WINDOW *win, const char *fmt, va_list varglist);

DESCRIPCIÓN

printw, wprintw, mvprintw y mvwprintw son análogos a printf(3). En efecto, la cadena que sería generada por printf(3) se escribe en su lugar como si waddstr(3X) se utilizara con win (o stdscr) como su primer argumento.

vwprintw y vw_printw son análogos a vprintf(3) y realizan un wprintw usando una lista de argumentos variable. El tercer argumento es una va_list, un puntero a una lista de argumentos, como se define en stdarg.h.

VALOR DE RETORNO

Estas funciones devuelven ERR en caso de fallo y OK en caso de éxito.

En ncurses, el fallo ocurre si la biblioteca no puede asignar suficiente memoria para el búfer en el que se formatea la salida, o si el puntero de ventana win es nulo.

Las funciones prefijadas con “mv” primero mueven el cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

No se definen funciones análogas para caracteres anchos (wide character) ni en la configuración de ncurses “wide” ni en ningún estándar. Para formatear y escribir una cadena de caracteres anchos en una ventana de curses, considere usar swprintf(3) y waddwstr(3X) o similares.

PORTABILIDAD

X/Open Curses, Issue 4 describe estas funciones. No especifica condiciones de error para ellas.

ncurses define vw_printw y vwprintw idénticamente para soportar aplicaciones heredadas. Sin embargo, la última está obsoleta.

  • X/Open Curses, Issue 4 Version 2 (1996), marcó vwprintw como requiriendo varargs.h y “A SER RETIRADA”, y especificó vw_printw usando la interfaz stdarg.h.
  • X/Open Curses, Issue 5, Draft 2 (diciembre de 2007) marcó vwprintw (junto con vwscanw y la interfaz termcap) como retirada. Después de incorporar los comentarios de revisión, esto se convirtió en X/Open Curses, Issue 7 (2009).
  • ncurses proporciona vwprintw, pero la marca como obsoleta.

HISTORIA

Mientras que printw fue implementada en 4BSD (noviembre de 1980), no se utilizó hasta 4.2BSD (agosto de 1983), que la empleó para juegos. Esa versión temprana de curses precedió al estándar ANSI C de 1989. No utilizaba varargs.h, aunque este estaba disponible desde Seventh Edition Unix (1979). En 1991 (un par de años después de que SVr4 estuviera disponible en general, y después de que se publicara el estándar C), otros desarrolladores actualizaron la biblioteca, usando stdarg.h internamente en 4.4BSD curses. Incluso con esta mejora, BSD curses no utilizó prototipos de función (ni siquiera declaró funciones) en curses.h hasta 1992.

SVr2 (1984) documentó printw y wprintw de forma concisa como “printf en stdscr” y “printf en win”, respectivamente.

SVr3 (1987) añadió mvprintw y mvwprintw, con un resumen de tres líneas afirmando que eran análogos a printf(3), explicando que la cadena que printf(3) escribiría en el flujo de salida estándar se escribiría en su lugar usando waddstr en la ventana dada. SVr3 también implementó vwprintw, describiendo su tercer parámetro como una va_list, definida en varargs.h, y remitiendo al lector a las páginas del manual de varargs y vprintf para descripciones detalladas.

SVr4 (1989) no introdujo nuevas variaciones de printw, pero permitió usar varargs.h o stdarg.h para definir el tipo va_list.

X/Open Curses, Issue 4 (1995), definió vw_printw para reemplazar vwprintw, afirmando que su tipo va_list se define en stdarg.h.
