curs_in_wchstr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_in_wchstr(3X) Llamadas a la biblioteca curs_in_wchstr(3X)

NOMBRE

in_wchstr, in_wchnstr, win_wchstr, win_wchnstr, mvin_wchstr, mvin_wchnstr, mvwin_wchstr, mvwin_wchnstr - obtener una cadena de caracteres complejos de curses desde una ventana

SINOPSIS

#include <curses.h>
int in_wchstr(cchar_t *wchstr);
int win_wchstr(WINDOW *win, cchar_t *wchstr);
int mvin_wchstr(int y, int x, cchar_t *wchstr);
int mvwin_wchstr(WINDOW *win, int y, int x, cchar_t *wchstr);
int in_wchnstr(cchar_t *wchstr, int n);
int win_wchnstr(WINDOW *win, cchar_t *wchstr, int n);
int mvin_wchnstr(int y, int x, cchar_t *wchstr, int n);
int mvwin_wchnstr(WINDOW *win, int y, int x, cchar_t *wchstr, int n);

DESCRIPCIÓN

Estas funciones devuelven un array de caracteres complejos en wchstr, comenzando en la posición actual del cursor en la ventana indicada. Los atributos (rendimiento) se almacenan con los caracteres.

Las cuatro funciones con n como último argumento devuelven una subcadena inicial de como máximo n caracteres de longitud (excluyendo el carácter cchar_t final con valor cero). La transferencia se detiene al final de la línea actual, o cuando se han almacenado n caracteres en la ubicación referenciada por wchstr.

Las constantes definidas en <curses.h> se pueden usar con el operador & (AND lógico) para extraer el carácter o el atributo solo de cualquier posición en wchstr [ver getcchar(3X)].

VALOR DE RETORNO

Tras una ejecución satisfactoria, estas funciones devuelven OK. De lo contrario, devuelven ERR.

X/Open Curses no define condiciones de error. Esta implementación devuelve un error

  • si el parámetro win es nulo o
  • si el parámetro wchstr es nulo.

Las funciones prefijadas con “mv” primero mueven el cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Todas las rutinas excepto win_wchnstr pueden ser macros.

Leer una línea que desborda el array apuntado por wchstr con in_wchstr, mvin_wchstr, mvwin_wchstr o win_wchstr produce resultados indefinidos. Por lo tanto, se recomienda el uso de in_wchnstr, mvin_wchnstr, mvwin_wchnstr o win_wchnstr.

PORTABILIDAD

X/Open Curses no define condiciones de error. Esta implementación verifica punteros nulos, devolviendo ERR en ese caso.

VER TAMBIÉN

curs_inchstr(3X) describe funciones comparables de la biblioteca ncurses en su configuración de caracteres no anchos.
