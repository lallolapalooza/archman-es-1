curl_multi_socket(3)

Paquete: curl

Licencias: MIT

curl_multi_socket(3) Manual de Funciones de Biblioteca curl_multi_socket(3)

NOMBRE

curl_multi_socket - leer/escribir datos disponibles

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_socket(CURLM *multi_handle, curl_socket_t sockfd,
                            int *running_handles);

DESCRIPCIÓN

Esta función está obsoleta. Usa curl_multi_socket_action(3) en su lugar con ev_bitmask establecido en 0.

Al regresar, el entero running_handles apunta a la cantidad de manejadores 'easy' aún en ejecución dentro del manejador múltiple. Cuando este número llega a cero, todas las transferencias están completas/terminadas. Ten en cuenta que cuando llamas a curl_multi_socket(3) en un socket específico y el contador disminuye en uno, NO significa necesariamente que este socket/transferencia exacto es el que se completó. Usa curl_multi_info_read(3) para averiguar qué manejador 'easy' se completó.

Las funciones curl_multi_socket(3) informan a la aplicación sobre actualizaciones en el estado del socket (descriptor de archivo) realizando ninguna, una o varias llamadas a la función de devolución de llamada del socket establecida con la opción CURLMOPT_SOCKETFUNCTION(3) para curl_multi_setopt(3). Actualizan el estado con los cambios desde la última vez que se llamó a la devolución de llamada.

Obtén el tiempo de espera estableciendo la opción CURLMOPT_TIMERFUNCTION(3) con curl_multi_setopt(3). Luego, tu aplicación será llamada con información sobre cuánto tiempo esperar como máximo para las acciones del socket antes de realizar la acción de tiempo de espera: llama a la función curl_multi_socket_action(3) con el argumento sockfd establecido en CURL_SOCKET_TIMEOUT. También puedes usar la función curl_multi_timeout(3) para consultar el valor en cualquier momento, pero para un sistema basado en eventos, usar la devolución de llamada es mucho mejor que depender de la consulta del valor de tiempo de espera.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  /* la biblioteca de eventos se entera cuando hay actividad en el socket 'fd',
     lo que traducimos a una llamada a curl_multi_socket_action() */
  int running;
  int rc;
  int fd = 2;
  CURLM *multi = curl_multi_init();
  rc = curl_multi_socket(multi, fd, &running);
}

OBSOLETO

curl_multi_socket(3) está obsoleto, usa curl_multi_socket_action(3) en su lugar.

DISPONIBILIDAD

Añadido en curl 7.15.4

VALOR DE RETORNO

Esta función devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, consulta libcurl-errors(3).

El código de retorno es para toda la pila múltiple. Aún podrían haber ocurrido problemas en transferencias individuales incluso cuando una de estas funciones devuelve OK.
