curs_in_wch(3X) Llamadas a la biblioteca curs_in_wch(3X)

NOMBRE

in_wch, mvin_wch, mvwin_wch, win_wch - obtener un carácter complejo de curses de una ventana

SINOPSIS

#include <curses.h>
int in_wch(cchar_t *wch);
int win_wch(WINDOW *win, cchar_t *wch);
int mvin_wch(int y, int x, cchar_t *wch);
int mvwin_wch(WINDOW *win, int y, int x, cchar_t *wch);

DESCRIPCIÓN

Estas funciones extraen el carácter complejo y su representación del posición actual en la ventana nombrada al objeto cchar_t al que hace referencia wch.

VALOR DEVUELTO

No se definen errores en X/Open Curses. Esta implementación verifica si hay punteros nulos, devolviendo ERR en ese caso. Además, las rutinas de mv verifican errores al mover el cursor, devolviendo ERR en ese caso. De lo contrario, devuelven OK.

Las funciones prefijadas con “mv” primero realizan un movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Tenga en cuenta que todas estas rutinas pueden ser macros.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4.

VER TAMBIÉN

curs_inch(3X) describe funciones comparables de la biblioteca ncurses en su configuración de caracteres no anchos.
