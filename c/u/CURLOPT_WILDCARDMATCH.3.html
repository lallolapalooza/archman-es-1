Paquete: curl

CURLOPT_WILDCARDMATCH(3) Manual de Funciones de Biblioteca CURLOPT_WILDCARDMATCH(3)

NOMBRE

CURLOPT_WILDCARDMATCH - transferencias de comodines de directorios

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_WILDCARDMATCH, long onoff);

DESCRIPCIÓN

Establezca onoff a 1 si desea transferir múltiples archivos según un patrón de nombre de archivo. El patrón se puede especificar como parte de la opción CURLOPT_URL(3), utilizando un patrón similar a fnmatch (Coincidencia de Patrones de Shell) en la última parte de la URL (nombre de archivo).

Por defecto, libcurl utiliza su implementación interna de coincidencia de comodines. Puede proporcionar su propia función de coincidencia mediante la opción CURLOPT_FNMATCH_FUNCTION(3).

A continuación se presenta una breve introducción a su sintaxis:

* - ASTERISCO
ftp://example.com/some/path/*.txt

coincide con todos los archivos .txt en el directorio raíz. Solo se permiten dos asteriscos dentro de la misma cadena de patrón.

? - SIGNO DE INTERROGACIÓN
El signo de interrogación coincide con cualquier carácter (exactamente uno). 
ftp://example.com/some/path/photo?.jpg
[ - EXPRESIÓN ENTRE CORCHETES
El corchete izquierdo abre una expresión entre corchetes. El signo de interrogación y el asterisco no tienen un significado especial en una expresión entre corchetes. Cada expresión entre corchetes termina con el corchete derecho y coincide con exactamente un carácter. A continuación se presentan algunos ejemplos:

[a-zA-Z0-9] o [f-gF-G] - intervalo de caracteres

[abc] - enumeración de caracteres

[^abc] o [!abc] - negación

[[:name:]] expresión de clase. Las clases admitidas son alnum, lower, space, alpha, digit, print, upper, blank, graph, xdigit.

[][-!^] - caso especial - coincide solo con '-', ']', '[', '!' o '^'. Estos caracteres no tienen un propósito especial.

[[]] - sintaxis de escape. Coincide con '[', ']' o 'e'.

Usando las reglas anteriores, se puede construir un patrón de nombre de archivo:

ftp://example.com/some/path/[a-z[:upper:]\].jpg

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

extern long begin_cb(struct curl_fileinfo *, void *, int);
extern long end_cb(void *ptr);
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* activar la coincidencia de comodines */
    curl_easy_setopt(curl, CURLOPT_WILDCARDMATCH, 1L);
    /* la devolución de llamada se llama antes de que comience la descarga
       del archivo concreto */
    curl_easy_setopt(curl, CURLOPT_CHUNK_BGN_FUNCTION, begin_cb);
    /* la devolución de llamada se llama después de que se hayan transferido
       los datos del archivo */
    curl_easy_setopt(curl, CURLOPT_CHUNK_END_FUNCTION, end_cb);
    /* Ver más en https://curl.se/libcurl/c/ftp-wildcard.html */
  }
}

DISPONIBILIDAD

Añadido en curl 7.21.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
