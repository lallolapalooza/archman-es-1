NOMBRE

getch, wgetch, mvgetch, mvwgetch, ungetch, has_key - obtener (o devolver a la cola) caracteres del teclado del terminal curses

SINOPSIS

#include <curses.h>
int getch(void);
int wgetch(WINDOW *win);
int mvgetch(int y, int x);
int mvwgetch(WINDOW *win, int y, int x);
int ungetch(int c);
/* extensión */
int has_key(int c);

DESCRIPCIÓN

Lectura de Caracteres

wgetch recopila una pulsación de tecla del teclado del terminal asociada con una ventana curses win. ncurses(3X) describe las variantes de esta función.

Cuando hay entrada pendiente, wgetch devuelve un entero que identifica la pulsación de tecla; para teclas alfanuméricas y de puntuación, este valor corresponde a la codificación de caracteres utilizada por el terminal. El uso de la tecla de control como modificador a menudo da como resultado un código distinto. El comportamiento de otras teclas depende de si win está en modo de teclado; véase la subsección “Modo de Teclado” más abajo.

Si no hay entrada pendiente, entonces si la bandera de no demora está establecida en la ventana (ver nodelay(3X)), la función devuelve ERR; de lo contrario, curses espera hasta que el terminal tenga entrada. Si se ha llamado a cbreak(3X), esto ocurre después de leer un carácter. Si se ha llamado a nocbreak(3X), ocurre cuando se lee la siguiente nueva línea. Si se ha llamado a halfdelay(3X), curses espera hasta que se presione una tecla o transcurra el retraso especificado.

Si se ha llamado a echo(3X), y la ventana no es un relleno, curses escribe el carácter devuelto c en la ventana (en la posición del cursor) según las siguientes reglas.

  • Si c coincide con el carácter de borrado del terminal, el cursor se mueve una posición a la izquierda y la nueva posición se borra como si se hubieran llamado a wmove(3X) y luego a wdelch(3X). Cuando el modo de teclado de la ventana está habilitado (ver más abajo), KEY_LEFT y KEY_BACKSPACE se manejan de la misma manera.
  • curses escribe cualquier otro c en la ventana, como con wechochar(3X).
  • Si la ventana se ha movido o modificado desde la última llamada a wrefresh(3X), curses llama a wrefresh.

Si c es un retorno de carro y se ha llamado a nl(3X), wgetch devuelve el código de carácter de avance de línea en su lugar.

Modo de Teclado

Para curses, las pulsaciones de teclas que no provienen de la sección alfabética del teclado (las que corresponden al conjunto de caracteres ECMA-6 —ver ascii(7)— opcionalmente modificadas por las teclas de control o mayúsculas) se tratan como teclas de función. (En curses, el término “tecla de función” incluye, pero no se limita a, las teclas grabadas con “F1”, “PF1”, etc.). Si la ventana está en modo de teclado, estas producen un código numérico correspondiente a los símbolos KEY_ listados en la subsección “Códigos de Teclas Predefinidos” más abajo; de lo contrario, transmiten una secuencia de códigos que típicamente comienza con el carácter de escape, y que debe ser recopilada con múltiples llamadas a wgetch.

  • El archivo de cabecera curses.h declara muchas teclas de función predefinidas cuyos nombres comienzan con KEY_; estas macros tipo objeto tienen valores fuera del rango de los códigos de caracteres de ocho bits.
  • En ncurses, las teclas de función definidas por el usuario se configuran con define_key(3X); no tienen nombres, pero también se espera que tengan valores fuera del rango de los códigos de ocho bits.

Por lo tanto, una variable destinada a contener un código de tecla de función debe ser de tipo short o superior.

La mayoría de los terminales que se encuentran siguen el estándar ECMA-48 en cuanto a que sus teclas de función producen secuencias de caracteres precedidas por el carácter de escape ESC. Este hecho implica que curses no puede saber si el terminal ha enviado una pulsación de tecla ESC o el comienzo de la secuencia de caracteres de una tecla de función sin esperar a ver si, y con qué rapidez, llega más entrada. Cuando curses lee un carácter ambiguo, establece un temporizador. Si el resto de la secuencia no llega dentro del tiempo designado, wgetch devuelve el carácter prefijo; de lo contrario, devuelve el código de tecla de función correspondiente a la secuencia única definida por el terminal. En consecuencia, un usuario de una aplicación curses puede experimentar un retraso después de presionar ESC mientras curses desambigua la entrada; ver la sección “EXTENSIÓN” más abajo. Si la ventana está en modo “sin tiempo de espera”, el temporizador no expira; es un valor infinito (o muy grande). Ver notimeout(3X). Dado que las secuencias de teclas de función generalmente comienzan con un carácter de escape, el terminal puede parecer colgarse en modo sin tiempo de espera después de que el usuario haya presionado ESC. Generalmente, escribir más “despierta” a curses.

Devolver Caracteres a la Cola

ungetch coloca c en la cola de entrada para que sea devuelta por la próxima llamada a wgetch. Una única cola de entrada sirve a todas las ventanas.
