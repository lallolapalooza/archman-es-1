Paquete: curl

curl_version(3) Manual de funciones de biblioteca curl_version(3)

NOMBRE

curl_version - devuelve la cadena de versión de libcurl

SINOPSIS

#include <curl/curl.h>
char *curl_version();

DESCRIPCIÓN

Devuelve una cadena legible por humanos con el número de versión de libcurl y algunos de sus componentes importantes (como la versión de OpenSSL).

Para compilaciones MultiSSL, la cadena contiene todos los nombres de los backends SSL y los nombres de los backends inactivos están entre paréntesis. Por ejemplo "(OpenSSL/3.0.8) Schannel" o "OpenSSL/3.0.8 (Schannel)".

Recomendamos usar curl_version_info(3) en su lugar.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  printf("versión de libcurl %s\n", curl_version());
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Un puntero a una cadena terminada en nulo. La cadena reside en un búfer asignado estáticamente y el llamante no debe liberarla.
