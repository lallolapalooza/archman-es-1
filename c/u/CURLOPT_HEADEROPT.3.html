CURLOPT_HEADEROPT(3)

Paquete: curl

Licencias: MIT

CURLOPT_HEADEROPT(3) Manual de funciones de biblioteca CURLOPT_HEADEROPT(3)

NOMBRE

CURLOPT_HEADEROPT - enviar encabezados HTTP tanto al proxy como al host o por separado

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HEADEROPT, long mascara);

DESCRIPCIÓN

Pasa un valor long que es una máscara de bits de opciones sobre cómo tratar los encabezados. Las dos opciones mutuamente excluyentes son:

CURLHEADER_UNIFIED - los encabezados especificados en CURLOPT_HTTPHEADER(3) se utilizan en las solicitudes tanto a servidores como a proxies. Con esta opción habilitada, CURLOPT_PROXYHEADER(3) no tiene ningún efecto.

CURLHEADER_SEPARATE - hace que los encabezados de CURLOPT_HTTPHEADER(3) solo se envíen a un servidor y no a un proxy. Los encabezados del proxy deben configurarse con CURLOPT_PROXYHEADER(3) para que se utilicen. Tenga en cuenta que si se envía una solicitud que no sea CONNECT a un proxy, libcurl envía tanto los encabezados del servidor como los del proxy. Al realizar la conexión (CONNECT), libcurl envía solo los encabezados de CURLOPT_PROXYHEADER(3) al proxy y luego los encabezados de CURLOPT_HTTPHEADER(3) solo al servidor.

POR DEFECTO

CURLHEADER_SEPARATE (cambiado en 7.42.1, antes usaba CURLHEADER_UNIFIED)

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    struct curl_slist *list;
    list = curl_slist_append(NULL, "Shoesize: 10");
    list = curl_slist_append(list, "Accept:");
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://localhost:8080");
    curl_easy_setopt(curl, CURLOPT_HTTPHEADER, list);
    /* HTTPS sobre un proxy realiza una conexión CONNECT separada al proxy, así que díle
       a libcurl que no envíe los encabezados personalizados al proxy. Mantenlos
       separados. */
    curl_easy_setopt(curl, CURLOPT_HEADEROPT, CURLHEADER_SEPARATE);
    ret = curl_easy_perform(curl);
    curl_slist_free_all(list);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Las macros CURLHEADER_* se convirtieron en tipos long en 8.16.0. Antes de esta versión, era necesario un cast a long al pasarlas a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.37.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_HTTPHEADER(3), CURLOPT_PROXYHEADER(3)
