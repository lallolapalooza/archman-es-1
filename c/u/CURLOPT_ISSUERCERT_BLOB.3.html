Paquete: curl

Licencias: MIT

CURLOPT_ISSUERCERT_BLOB(3) Manual de Funciones de Biblioteca CURLOPT_ISSUERCERT_BLOB(3)

NOMBRE

CURLOPT_ISSUERCERT_BLOB - certificado SSL del emisor desde un blob de memoria

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ISSUERCERT_BLOB,
                          struct curl_blob *stblob);

DESCRIPCIÓN

Pasa un puntero a una estructura curl_blob, que contiene información (puntero y tamaño) sobre un bloque de memoria con datos binarios de un certificado CA en formato PEM. Si la opción se establece, se realiza una comprobación adicional contra el certificado del par para verificar que el emisor es realmente el asociado con el certificado proporcionado por la opción. Esta comprobación adicional es útil en PKI de varios niveles donde se necesita forzar que el certificado del par sea de una rama específica del árbol.

Esta opción debe usarse en combinación con la opción CURLOPT_SSL_VERIFYPEER(3). De lo contrario, el resultado de la comprobación no se considera un error.

Se define un código de error específico (CURLE_SSL_ISSUER_ERROR) con la opción, que se devuelve si la configuración de la sesión SSL/TLS ha fallado debido a una discrepancia con el emisor del certificado del par (también se debe establecer CURLOPT_SSL_VERIFYPEER(3) para que la comprobación falle).

Si el blob se inicializa con el miembro flags de la estructura curl_blob establecido en CURL_BLOB_COPY, la aplicación no tiene que mantener el buffer disponible después de establecer esta opción.

Esta opción es una alternativa a CURLOPT_ISSUERCERT(3) que en su lugar espera un nombre de archivo como entrada.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL

EJEMPLO

extern char *certificateData;
extern size_t filesize;
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    blob.data = certificateData;
    blob.len = filesize;
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_ISSUERCERT_BLOB, &blob);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.71.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue correcto, cualquier valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
