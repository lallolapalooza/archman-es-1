CURLOPT_IOCTLFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_IOCTLFUNCTION(3) Manual de funciones de biblioteca CURLOPT_IOCTLFUNCTION(3)

NOMBRE

CURLOPT_IOCTLFUNCTION - callback para operaciones de I/O

SINOPSIS

#include <curl/curl.h>
typedef enum {
  CURLIOE_OK,            /* Operación de I/O exitosa */
  CURLIOE_UNKNOWNCMD,    /* comando desconocido para el callback */
  CURLIOE_FAILRESTART,   /* fallo al reiniciar la lectura */
  CURLIOE_LAST           /* nunca usar */
} curlioerr;
typedef enum  {
  CURLIOCMD_NOP,         /* sin operación */
  CURLIOCMD_RESTARTREAD, /* reiniciar el flujo de lectura desde el principio */
  CURLIOCMD_LAST         /* nunca usar */
} curliocmd;
curlioerr ioctl_callback(CURL *handle, int cmd, void *clientp);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_IOCTLFUNCTION, ioctl_callback);

DESCRIPCIÓN

Pase un puntero a su función de callback, que debe coincidir con el prototipo mostrado arriba.

Esta función de callback es llamada por libcurl cuando algo especial relacionado con I/O necesita ser hecho que la biblioteca no puede hacer por sí misma. Por ahora, rebobinar el flujo de datos de lectura es la única acción que puede solicitar. El rebobinado del flujo de datos de lectura puede ser necesario al realizar un método de autenticación HTTP PUT o POST con múltiples pasos.

El callback **debe** devolver CURLIOE_UNKNOWNCMD si el parámetro cmd de entrada no es CURLIOCMD_RESTARTREAD.

El argumento clientp del callback se establece con la opción CURLOPT_IOCTLDATA(3).

**Esta opción está obsoleta**. No la use. Use CURLOPT_SEEKFUNCTION(3) en su lugar para proporcionar la búsqueda. Si CURLOPT_SEEKFUNCTION(3) está configurada, este parámetro se ignora al buscar.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

#include <unistd.h> /* para lseek */
struct data {
  int fd; /* nuestro descriptor de archivo */
};
static curlioerr ioctl_callback(CURL *handle, int cmd, void *clientp)
{
  struct data *io = (struct data *)clientp;
  if(cmd == CURLIOCMD_RESTARTREAD) {
    lseek(io->fd, 0, SEEK_SET);
    return CURLIOE_OK;
  }
  return CURLIOE_UNKNOWNCMD;
}
int main(void)
{
  struct data ioctl_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_IOCTLFUNCTION, ioctl_callback);
    curl_easy_setopt(curl, CURLOPT_IOCTLDATA, &ioctl_data);
  }
}

OBSOLETO

Obsoleto desde la versión 7.18.0.

DISPONIBILIDAD

Añadido en curl 7.12.3

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_IOCTLDATA(3), CURLOPT_SEEKFUNCTION(3)
