CURLOPT_UNRESTRICTED_AUTH(3)

Paquete: curl

Licencias: MIT

CURLOPT_UNRESTRICTED_AUTH(3) Manual de funciones de la biblioteca CURLOPT_UNRESTRICTED_AUTH(3)

NOMBRE

CURLOPT_UNRESTRICTED_AUTH - enviar credenciales a otros hosts también

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_UNRESTRICTED_AUTH,
                          long goahead);

DESCRIPCIÓN

Establezca el parámetro de tipo long goahead en 1L para que libcurl continúe enviando credenciales de autenticación (usuario+contraseña) o encabezados de cookies explícitamente establecidos al seguir ubicaciones, incluso cuando cambia el host. Esta opción solo es significativa cuando se establece CURLOPT_FOLLOWLOCATION(3).

Además, cuando esta opción no se usa o se establece en 0L, libcurl no envía encabezados Authentication: o Cookie: personalizados ni generados internamente en solicitudes a otros hosts que no sea el utilizado para la URL inicial. Otro host significa que uno o más de nombre de host, esquema de protocolo o número de puerto cambiaron.

Por defecto, libcurl solo envía encabezados Authentication: o Cookie: explícitamente establecidos al host inicial según lo indicado en la URL original, para evitar fugas de nombre de usuario + contraseña a otros sitios.

Esta opción debe usarse con precaución: cuando curl sigue redirecciones, recupera ciegamente la siguiente URL según lo instruido por el servidor. Establecer CURLOPT_UNRESTRICTED_AUTH(3) en 1L hace que curl confíe en el servidor y envíe credenciales posiblemente sensibles a cualquier host al que apunte el servidor, posiblemente una y otra vez, ya que los hosts siguientes pueden seguir redirigiendo a nuevos hosts.

Debido a la forma en que funciona HTTP, casi cualquier encabezado puede contener datos que un cliente podría no querer pasar a otros servidores que no sea el host inicialmente previsto, y para todos los demás encabezados que no sean los dos mencionados anteriormente, no hay protección contra que esto suceda cuando se le indica a libcurl que siga las redirecciones.

POR DEFECTO

0

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
    curl_easy_setopt(curl, CURLOPT_UNRESTRICTED_AUTH, 1L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.10.4

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
