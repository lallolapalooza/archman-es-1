CURLOPT_CLOSESOCKETDATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_CLOSESOCKETDATA(3) Manual de Funciones de Biblioteca CURLOPT_CLOSESOCKETDATA(3)

NOMBRE

CURLOPT_CLOSESOCKETDATA - puntero pasado a la devolución de llamada de cierre de socket

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CLOSESOCKETDATA,
                          void *pointer);

DESCRIPCIÓN

Pasa un puntero que libcurl no modificará y que se pasará como primer argumento en la devolución de llamada closesocket establecida con CURLOPT_CLOSESOCKETFUNCTION(3).

Tenga en cuenta que al usar manejadores multi/share, su devolución de llamada puede ser invocada incluso después de que el manejador easy haya sido limpiado. La devolución de llamada y los datos son heredados por una nueva conexión y esa conexión puede vivir más tiempo que la transferencia misma en la caché de conexiones del manejador multi/share.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

struct priv {
  void *custom;
};
static int closesocket(void *clientp, curl_socket_t item)
{
  struct priv *my = clientp;
  printf("our ptr: %p\n", my->custom);
  printf("libcurl wants to close %d now\n", (int)item);
  return 0;
}
int main(void)
{
  struct priv myown;
  CURL *curl = curl_easy_init();
  /* llamar a esta función para cerrar sockets */
  curl_easy_setopt(curl, CURLOPT_CLOSESOCKETFUNCTION, closesocket);
  curl_easy_setopt(curl, CURLOPT_CLOSESOCKETDATA, &myown);
  curl_easy_perform(curl);
  curl_easy_cleanup(curl);
}

DISPONIBILIDAD

Añadido en curl 7.21.7

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, véase libcurl-errors(3).
