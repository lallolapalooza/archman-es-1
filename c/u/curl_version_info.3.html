curl_version_info(3)

Paquete: curl

Licencias: MIT

curl_version_info(3) Manual de funciones de biblioteca curl_version_info(3)

NOMBRE

curl_version_info - devuelve información de la versión de libcurl en tiempo de ejecución

SINOPSIS

#include <curl/curl.h>
curl_version_info_data *curl_version_info(CURLversion age);

DESCRIPCIÓN

Devuelve un puntero a una estructura estática rellenada con información sobre varias características en la versión en ejecución de libcurl. age debe establecerse a la versión de esta funcionalidad cuando escriba su programa. De esta manera, libcurl siempre devuelve una estructura adecuada que su programa entienda, mientras que los programas en el futuro podrían obtener una estructura diferente. CURLVERSION_NOW es la más reciente para la biblioteca que tiene instalada:

  data = curl_version_info(CURLVERSION_NOW);

Las aplicaciones deben usar esta información para juzgar si es posible hacer algo o no, en lugar de usar verificaciones en tiempo de compilación, ya que las bibliotecas dinámicas/DLL pueden cambiarse independientemente de las aplicaciones.

Esta función puede alterar los datos estáticos devueltos siempre que curl_global_init(3) no haya sido llamado. Por lo tanto, no es seguro para hilos antes de que ocurra la inicialización de libcurl.

La estructura curl_version_info_data se ve así

typedef struct {
  CURLversion age;          /* ver descripción abajo */
  const char *version;      /* cadena legible para humanos */
  unsigned int version_num; /* representación numérica */
  const char *host;         /* cadena legible para humanos */
  int features;             /* máscara de bits, ver abajo */
  char *ssl_version;        /* cadena legible para humanos */
  long ssl_version_num;     /* no usado, siempre cero */
  const char *libz_version; /* cadena legible para humanos */
  const char *const *protocols; /* protocolos */
  /* cuando 'age' es CURLVERSION_SECOND o superior, los miembros de abajo existen */
  const char *ares;         /* cadena legible para humanos */
  int ares_num;             /* número */
  /* cuando 'age' es CURLVERSION_THIRD o superior, los miembros de abajo existen */
  const char *libidn;       /* cadena legible para humanos */
  /* cuando 'age' es CURLVERSION_FOURTH o superior (>= 7.16.1), los miembros
     de abajo existen */
  int iconv_ver_num;       /* '_libiconv_version' si el soporte iconv está habilitado */
  const char *libssh_version; /* cadena legible para humanos */
  /* cuando 'age' es CURLVERSION_FIFTH o superior (>= 7.57.0), los miembros
     de abajo existen */
  unsigned int brotli_ver_num; /* Versión numérica de Brotli
                                  (MAJOR << 24) | (MINOR << 12) | PATCH */
  const char *brotli_version; /* cadena legible para humanos. */
  /* cuando 'age' es CURLVERSION_SIXTH o superior (>= 7.66.0), los miembros
     de abajo existen */
  unsigned int nghttp2_ver_num; /* Versión numérica de nghttp2
                                   (MAJOR << 16) | (MINOR << 8) | PATCH */
  const char *nghttp2_version; /* cadena legible para humanos. */
  const char *quic_version;    /* biblioteca quic (+ HTTP/3) legible para humanos +
                                  versión o NULL */
  /* cuando 'age' es CURLVERSION_SEVENTH o superior (>= 7.70.0), los miembros
     de abajo existen */
  const char *cainfo;          /* el CURLOPT_CAINFO predeterminado integrado, podría
                                  ser NULL */
  const char *capath;          /* el CURLOPT_CAPATH predeterminado integrado, podría
                                  ser NULL */
  /* cuando 'age' es CURLVERSION_EIGHTH o superior (>= 7.71.0), los miembros
     de abajo existen */
  unsigned int zstd_ver_num; /* Versión numérica de Zstd
                                  (MAJOR << 24) | (MINOR << 12) | PATCH */
  const char *zstd_version; /* cadena legible para humanos. */
  /* cuando 'age' es CURLVERSION_NINTH o superior (>= 7.75.0), los miembros
     de abajo existen */
  const char *hyper_version; /* cadena legible para humanos. */
  /* cuando 'age' es CURLVERSION_TENTH o superior (>= 7.77.0), los miembros
     de abajo existen */
  const char *gsasl_version; /* cadena legible para humanos. */
  /* cuando 'age' es CURLVERSION_ELEVENTH o superior (>= 7.87.0), los miembros
     de abajo existen */
  const char *const *feature_names; /* Nombres de características. */
  /* cuando 'age' es CURLVERSION_TWELFTH o superior (>= 8.8.0), los miembros
     de abajo existen */
  const char *const *rtmp_version; /* cadena legible para humanos */
} curl_version_info_data;

age describe cuál es la antigüedad de esta estructura. El número depende de cuán nueva sea la libcurl que está usando. Sin embargo, se garantiza que obtendrá una estructura para la que tiene una estructura coincidente en el encabezado, ya que le dice a libcurl su "edad" con el argumento de entrada.

version es simplemente una cadena ASCII para la versión de libcurl.

version_num es un número de 24 bits creado así: <8 bits número mayor> | <8 bits número menor> | <8 bits número de parche>. La versión 7.9.8 se devuelve por lo tanto como 0x070908.

host es una cadena ASCII que muestra la información del host para el que esta libcurl fue construida. Como fue descubierta por un script de configure o establecida por el entorno de compilación.

features es una máscara de bits que representa las características disponibles. Puede tener ninguno, uno o más bits establecidos. El uso de este campo está obsoleto: use feature_names en su lugar. La descripción de los nombres de características de abajo lista los bits asociados.

feature_names es un puntero a un array de punteros a cadenas, que contiene los nombres de las características que libcurl soporta. El array es terminado por una entrada NULL. Vea la lista de nombres de características de abajo.

ssl_version es una cadena ASCII para el nombre de la biblioteca TLS + versión usada. Si libcurl no tiene soporte SSL, esto es NULL. Por ejemplo "Schannel", "Secure Transport" o "OpenSSL/1.1.0g". Para compilaciones MultiSSL la cadena contiene todos los nombres de backends SSL y los nombres de backends inactivos están entre paréntesis. Por ejemplo "(OpenSSL/3.0.8) Schannel" o "OpenSSL/3.0.8 (Schannel)".

ssl_version_num es siempre 0.

libz_version es una cadena ASCII (no hay versión numérica). Si libcurl no tiene soporte libz, esto es NULL.

protocols es un puntero a un array de punteros a char *, que contiene los nombres de los protocolos que libcurl soporta (usando letras minúsculas). Los nombres de los protocolos son los mismos que se usarían en URLs. El array es terminado por una entrada NULL.

CARACTERÍSTICAS

alt-svc
features bit de máscara: CURL_VERSION_ALTSVC

Análisis HTTP Alt-Svc y las opciones asociadas (Añadido en 7.64.1)

AppleSecTrust
features bit de máscara: no existente

libcurl fue construida con soporte para el servicio SecTrust de Apple para verificar certificados de servidor (Añadido en 8.17.0).

AsynchDNS
features bit de máscara: CURL_VERSION_ASYNCHDNS

libcurl fue construida con soporte para búsquedas de nombres asíncronas, lo que permite tiempos de espera más precisos (incluso en Windows) y menos bloqueo al usar la interfaz multi.

brotli
features bit de máscara: CURL_VERSION_BROTLI

soporta codificación de contenido HTTP Brotli usando libbrotlidec

asyn-rr
features bit de máscara: no existente

libcurl fue construida para usar c-ares para resoluciones de registros de recursos HTTPS EXPERIMENTALES, pero usa el resolvedor con hilos para resoluciones "normales" (Añadido en 8.12.0)

Debug
features bit de máscara: CURL_VERSION_DEBUG

libcurl fue construida con capacidades de depuración

ECH
features bit de máscara: no existente

libcurl fue construida con soporte ECH (experimental, añadido en 8.8.0)

gsasl
features bit de máscara: CURL_VERSION_GSASL

libcurl fue construida con libgsasl y por lo tanto con algunos métodos extra de autenticación SCRAM-SHA. (añadido en 7.76.0)

GSS-API
features bit de máscara: CURL_VERSION_GSSAPI

libcurl fue construida con soporte para GSS-API. Esto hace que libcurl use las funciones proporcionadas para autenticación Kerberos y SPNEGO. También permite a libcurl usar las credenciales del usuario actual sin que la aplicación tenga que pasarlas.

HSTS
features bit de máscara: CURL_VERSION_HSTS

libcurl fue construida con soporte para HSTS (HTTP Strict Transport Security) (Añadido en 7.74.0)

HTTP2
features bit de máscara: CURL_VERSION_HTTP2

libcurl fue construida con sopuerto para HTTP2.

HTTP3
características bit de máscara: CURL_VERSION_HTTP3

El soporte para HTTP/3 y QUIC está integrado (Añadido en 7.66.0)

Proxy HTTPS
características bit de máscara: CURL_VERSION_HTTPS_PROXY

libcurl fue compilado con soporte para proxy HTTPS.

HTTPSRR
características bit de máscara: no existente

libcurl fue compilado con soporte EXPERIMENTAL para registros de recursos HTTPS (Añadido en 8.12.0)

IDN
características bit de máscara: CURL_VERSION_IDN

libcurl fue compilado con soporte para IDNA, nombres de dominio con letras internacionales.

IPv6
características bit de máscara: CURL_VERSION_IPV6

soporta IPv6

Kerberos
características bit de máscara: CURL_VERSION_KERBEROS5

soporta autenticación Kerberos V5 para FTP, IMAP, LDAP, POP3, SMTP y proxy SOCKSv5.

Archivos grandes
características bit de máscara: CURL_VERSION_LARGEFILE

libcurl fue compilado con soporte para archivos grandes.

libz
características bit de máscara: CURL_VERSION_LIBZ

soporta HTTP deflate usando libz

MultiSSL
características bit de máscara: CURL_VERSION_MULTI_SSL

libcurl fue compilado con múltiples backends SSL. Para más detalles, ver curl_global_sslset(3).

NTLM
características bit de máscara: CURL_VERSION_NTLM

soporta HTTP NTLM

NTLM_WB
características bit de máscara: CURL_VERSION_NTLM_WB

libcurl fue compilado con soporte para la delegación de NTLM a un asistente winbind. Esta característica fue eliminada de curl en 8.8.0.

PSL
características bit de máscara: CURL_VERSION_PSL

libcurl fue compilado con soporte para la Lista de Sufijos Públicos de Mozilla. Esto hace que libcurl ignore cookies con un dominio que esté en la lista.

SPNEGO
características bit de máscara: CURL_VERSION_SPNEGO

libcurl fue compilado con soporte para autenticación SPNEGO (Mecanismo de Negociación GSS-API Simple y Protegido, definido en RFC 2478.)

SSL
características bit de máscara: CURL_VERSION_SSL

soporta SSL (HTTPS/FTPS)

SSLS-EXPORT
características bit de máscara: no existente

libcurl fue compilado con soporte para importación/exportación de sesiones SSL (experimental, añadido en 8.12.0)

SSPI
características bit de máscara: CURL_VERSION_SSPI

libcurl fue compilado con soporte para SSPI. Esto solo está disponible en Windows y hace que libcurl use funciones proporcionadas por Windows para autenticación Kerberos, NTLM, SPNEGO y Digest. También permite a libcurl usar las credenciales del usuario actual sin que la aplicación tenga que proporcionarlas.

seguro para hilos
características bit de máscara: CURL_VERSION_THREADSAFE

libcurl fue compilado con soporte de seguridad para hilos (Atomic o SRWLOCK) para proteger la inicialización de curl. (Añadido en 7.84.0) Ver libcurl-thread(3)

TLS-SRP
características bit de máscara: CURL_VERSION_TLSAUTH_SRP

libcurl fue compilado con soporte para TLS-SRP (en uno o más de los backends TLS integrados).

Rastreo de memoria
características bit de máscara: CURL_VERSION_CURLDEBUG

libcurl fue compilado con capacidades de depuración de rastreo de memoria. Esto es principalmente de interés para los desarrolladores de libcurl.

Unicode
características bit de máscara: CURL_VERSION_UNICODE

libcurl fue compilado con soporte Unicode en Windows. Esto hace que los caracteres no ASCII funcionen en nombres de archivos y opciones pasadas a libcurl. (Añadido en 7.72.0)

UnixSockets
características bit de máscara: CURL_VERSION_UNIX_SOCKETS

libcurl fue compilado con soporte para sockets de dominio Unix.

zstd
características bit de máscara: CURL_VERSION_ZSTD

soporta codificación de contenido HTTP zstd usando la biblioteca zstd (Añadido en 7.72.0)

sin nombre
características bit de máscara: CURL_VERSION_CONV

libcurl fue compilado con soporte para conversiones de caracteres proporcionadas por callbacks. Siempre 0 desde 7.82.0. Obsoleto.

sin nombre
características bit de máscara: CURL_VERSION_GSSNEGOTIATE

soporta HTTP GSS-Negotiate. Obsoleto.

sin nombre
características bit de máscara: CURL_VERSION_KERBEROS4

soporta Kerberos V4 (al usar FTP). Bit heredado. Obsoleto desde 7.33.0.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

int main(void)
{
  curl_version_info_data *ver = curl_version_info(CURLVERSION_NOW);
  printf("libcurl version %u.%u.%u\n",
         (ver->version_num >> 16) & 0xff,
         (ver->version_num >> 8) & 0xff,
         ver->version_num & 0xff);
}

Añadido en curl 7.10

VALOR DE RETORNO

Un puntero a una estructura curl_version_info_data.
