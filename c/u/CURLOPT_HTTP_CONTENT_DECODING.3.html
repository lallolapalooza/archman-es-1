CURLOPT_HTTP_CONTENT_DECODING(3)

Paquete: curl

Licencias: MIT

CURLOPT_HTTP_CONTENT_DECODING(3) Manual de funciones de la biblioteca CURLOPT_HTTP_CONTENT_DECODING(3)

NOMBRE

CURLOPT_HTTP_CONTENT_DECODING - control de decodificación de contenido HTTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HTTP_CONTENT_DECODING,
                          long enabled);

DESCRIPCIÓN

Pase un `long` para indicar a libcurl cómo actuar sobre la decodificación de contenido. Si se establece en cero, la decodificación de contenido se deshabilita. Si se establece en 1, se habilita. libcurl no tiene decodificación de contenido por defecto, pero requiere que usted utilice CURLOPT_ACCEPT_ENCODING(3) para ello.

POR OMISIÓN

1

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_HTTP_CONTENT_DECODING, 0L);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.16.2

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier otro valor indica un error; véase libcurl-errors(3).

VER TAMBIÉN

CURLOPT_ACCEPT_ENCODING(3), CURLOPT_DEBUGFUNCTION(3), CURLOPT_STDERR(3)
