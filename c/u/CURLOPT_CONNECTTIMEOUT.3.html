CURLOPT_CONNECTTIMEOUT(3)

Paquete: curl

Licencias: MIT

CURLOPT_CONNECTTIMEOUT(3) Manual de funciones de la biblioteca CURLOPT_CONNECTTIMEOUT(3)

NOMBRE

CURLOPT_CONNECTTIMEOUT - tiempo límite para la fase de conexión

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONNECTTIMEOUT, long timeout);

DESCRIPCIÓN

Pase un long. Establece el tiempo máximo en segundos que permite que la fase de conexión tome. Este tiempo límite solo restringe la fase de conexión, no tiene impacto una vez que libcurl se ha conectado. La fase de conexión incluye la resolución de nombres (DNS) y todos los protocolos de mano y negociaciones hasta que haya una conexión establecida con el lado remoto.

Establezca esta opción a cero para cambiar al tiempo límite de conexión incorporado predeterminado: 300 segundos. Consulte también la opción CURLOPT_TIMEOUT(3).

CURLOPT_CONNECTTIMEOUT_MS(3) es la misma función pero establecida en milisegundos.

Si se establecen tanto CURLOPT_CONNECTTIMEOUT(3) como CURLOPT_CONNECTTIMEOUT_MS(3), se utiliza el valor establecido por último.

El tiempo límite de conexión está incluido en el tiempo límite general que lo abarca todo CURLOPT_TIMEOUT(3):

Con CURLOPT_CONNECTTIMEOUT(3) establecido en 3 y CURLOPT_TIMEOUT(3) establecido en 5, la operación nunca podrá durar más de 5 segundos, y la fase de conexión no podrá durar más de 3 segundos.

Con CURLOPT_CONNECTTIMEOUT(3) establecido en 4 y CURLOPT_TIMEOUT(3) establecido en 2, la operación nunca podrá durar más de 2 segundos. Incluyendo la fase de conexión.

Esta opción puede hacer que libcurl utilice la señal SIGALRM para agotar el tiempo de espera de las llamadas al sistema en compilaciones que no utilizan DNS asíncrono. En sistemas similares a Unix, esto podría causar que se utilicen señales a menos que se establezca CURLOPT_NOSIGNAL(3).

PREDETERMINADO

300

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* completar la conexión en 10 segundos */
    curl_easy_setopt(curl, CURLOPT_CONNECTTIMEOUT, 10L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.7

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
