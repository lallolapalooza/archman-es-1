NOMBRE

Curses::UI::Popupmenu - Crear y manipular widgets de menú emergente

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Popupmenu

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $popupbox = $win->add(
    'mypopupbox', 'Popupmenu',
    -values    => [1, 2, 3],
    -labels    => { 1 => 'Uno', 
                    2 => 'Dos', 
                    3 => 'Tres' },
);
$popupbox->focus();
my $value = $popupbox->get();

DESCRIPCIÓN

Curses::UI::Popupmenu es un widget que se puede usar para crear algo muy similar a un Curses::UI::Listbox básico. La diferencia es que el widget mostrará solo el valor actualmente seleccionado (o "-------" si aún no hay ningún valor seleccionado). La lista de valores posibles se mostrará como una ventana emergente separada si se solicita.

Normalmente, el widget se verá algo así:

[Valor actual ]

Si se abre la ventana emergente, se verá algo así:

[Valor actual ]
+--------------+
|Otro valor    |
|Valor actual  | 
|Tercer valor  |
+--------------+

OPCIONES ESTÁNDAR

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

Para una explicación de estas opciones estándar, consulte Curses::UI::Widget.

OPCIONES ESPECÍFICAS DEL WIDGET

  • -values < LISTA >
  • -labels < HASHREF >
  • -selected < ÍNDICE >
  • -wraparound < BOOLEANO >

    Estas opciones son exactamente las mismas que las opciones del widget Listbox. Así que para una explicación de estas, eche un vistazo a Curses::UI::Listbox.

  • -onchange < CODEREF >

    Esto establece el manejador de eventos onChange para el widget popupmenu. Si se selecciona un nuevo elemento, se ejecutará el código en CODEREF. Recibirá la referencia del widget como argumento.

ASIGNACIONES POR DEFECTO

Hay asignaciones para el widget en sí y asignaciones para la lista emergente que se puede abrir con este widget.

El widget en sí

  • <tab>

    Llama a la rutina 'loose-focus'. Esto hará que el widget pierda el foco.

  • <enter>, <cursor-right, <l>, <space>

    Llama a la rutina 'open-popup'. Esto mostrará la lista emergente y dará el foco a esta lista. Consulte La lista emergente a continuación para obtener una descripción de las asignaciones para esta lista.

  • <cursor-down>, <j>

    Llama a la rutina 'select-next'. Esto seleccionará el elemento en la lista que está después del elemento actualmente seleccionado (a menos que el último elemento ya esté seleccionado). Si no hay ningún elemento seleccionado, se seleccionará el primer elemento de la lista.

  • <cursor-up>, <k>

    Llama a la rutina 'select-prev'. Esto seleccionará el elemento en la lista que está antes del elemento actualmente seleccionado (a menos que el primer elemento ya esté seleccionado). Si no hay ningún elemento seleccionado, se seleccionará el primer elemento de la lista.

La lista emergente

Las asignaciones para la lista emergente son las mismas que las asignaciones para el widget Listbox. Así que eche un vistazo a Curses::UI::Listbox para obtener una descripción de estas. La diferencia es que la rutina 'loose-focus' y 'option-select' harán que la lista emergente se cierre. Si se llama a la rutina 'option-select', se seleccionará el elemento activo.
