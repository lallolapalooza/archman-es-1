CURLOPT_SSL_CTX_DATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSL_CTX_DATA(3) Manual de funciones de biblioteca CURLOPT_SSL_CTX_DATA(3)

NOMBRE

CURLOPT_SSL_CTX_DATA - puntero pasado al callback del contexto SSL

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_CTX_DATA, void *pointer);

DESCRIPCIÓN

Puntero pointer para pasar al callback del contexto ssl establecido por la opción CURLOPT_SSL_CTX_FUNCTION(3), este es el puntero que obtienes como tercer parámetro.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL, mbedTLS y wolfSSL

EJEMPLO

/* Específico de OpenSSL */
#include <openssl/ssl.h>
#include <curl/curl.h>
#include <stdio.h>
static CURLcode sslctx_function(CURL *curl, void *sslctx, void *pointer)
{
  X509_STORE *store;
  X509 *cert = NULL;
  BIO *bio;
  char *mypem = pointer;
  /* obtener un BIO */
  bio = BIO_new_mem_buf(mypem, -1);
  /* usarlo para leer el certificado en formato PEM desde memoria en una
   * estructura X509 que SSL pueda usar
   */
  PEM_read_bio_X509(bio, &cert, 0, NULL);
  if(!cert)
    printf("PEM_read_bio_X509 falló...\n");
  /* obtener un puntero al almacén de certificados X509 (que puede estar vacío) */
  store = SSL_CTX_get_cert_store((SSL_CTX *)sslctx);
  /* añadir nuestro certificado a este almacén */
  if(X509_STORE_add_cert(store, cert) == 0)
    printf("error al añadir certificado\n");
  /* disminuir los recuentos de referencias */
  X509_free(cert);
  BIO_free(bio);
  /* todo listo para empezar */
  return CURLE_OK;
}
int main(void)
{
  CURL *ch;
  CURLcode rv;
  char *mypem = /* certificado CA en formato PEM, reemplaza las XXX */
    "-----BEGIN CERTIFICATE-----\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX\n"
    "-----END CERTIFICATE-----\n";
  curl_global_init(CURL_GLOBAL_ALL);
  ch = curl_easy_init();
  curl_easy_setopt(ch, CURLOPT_SSLCERTTYPE, "PEM");
  curl_easy_setopt(ch, CURLOPT_SSL_VERIFYPEER, 1L);
  curl_easy_setopt(ch, CURLOPT_URL, "https://www.example.com/");
  curl_easy_setopt(ch, CURLOPT_SSL_CTX_FUNCTION, *sslctx_function);
  curl_easy_setopt(ch, CURLOPT_SSL_CTX_DATA, mypem);
  rv = curl_easy_perform(ch);
  if(!rv)
    printf("*** transferencia exitosa ***\n");
  else
    printf("*** transferencia fallida ***\n");
  curl_easy_cleanup(ch);
  curl_global_cleanup();
  return rv;
}

HISTORIAL

Añadido en 7.11.0 para OpenSSL, en 7.42.0 para wolfSSL, en 7.54.0 para mbedTLS.

DISPONIBILIDAD

Añadido en curl 7.10.6

VALOR DE RETORNO

CURLE_OK si es compatible; o un error como:

CURLE_NOT_BUILT_IN - No soportado por el backend SSL

CURLE_UNKNOWN_OPTION
