CURLMOPT_PUSHFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLMOPT_PUSHFUNCTION(3) Manual de funciones de la biblioteca CURLMOPT_PUSHFUNCTION(3)

NOMBRE

CURLMOPT_PUSHFUNCTION - callback que aprueba o niega las inserciones (pushes) del servidor

SINOPSIS

#include <curl/curl.h>
int curl_push_callback(CURL *parent,
                       CURL *easy,
                       size_t num_headers,
                       struct curl_pushheaders *headers,
                       void *clientp);
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_PUSHFUNCTION,
                            curl_push_callback func);

DESCRIPCIÓN

Esta función de devolución de llamada se llama cuando se está insertando una nueva transmisión HTTP/2 desde el servidor (usando el marco PUSH_PROMISE). Si no se establece ninguna función de devolución de llamada de inserción, todas las inserciones ofrecidas se niegan automáticamente.

DESCRIPCIÓN DE LA FUNCIÓN DE DEVOLUCIÓN DE LLAMADA

La función de devolución de llamada recibe sus argumentos de la siguiente manera:

parent es el manejador de la transmisión en la que llega esta inserción. El nuevo manejador se ha duplicado del padre, lo que significa que ha heredado todas sus opciones. Corresponde a la aplicación modificar cualquier opción si se desea.

easy es un manejador recién creado que representa esta próxima transferencia.

num_headers es el número de pares nombre+valor que se recibieron y que se pueden acceder.

headers es un manejador utilizado para acceder a los encabezados de inserción utilizando las funciones accesoras descritas a continuación. Esto solo accede y proporciona los encabezados PUSH_PROMISE, los encabezados de respuesta normales se proporcionan en la función de devolución de llamada de encabezado como de costumbre.

clientp es el puntero establecido con CURLMOPT_PUSHDATA(3)

Si la función de devolución de llamada devuelve CURL_PUSH_OK, el nuevo manejador easy se agrega al manejador múltiple; la función de devolución de llamada no debe hacer eso por sí misma.

La función de devolución de llamada puede acceder a los encabezados PUSH_PROMISE con dos funciones accesoras. Estas funciones solo se pueden usar dentro de esta función de devolución de llamada y solo pueden acceder a los encabezados PUSH_PROMISE: curl_pushheader_byname(3) y curl_pushheader_bynum(3). Los encabezados de respuesta normales se pasan a la función de devolución de llamada de encabezado para las transmisiones insertadas, al igual que para las transmisiones normales.

Los campos de encabezado también se pueden acceder con curl_easy_header(3), introducido en versiones posteriores de libcurl.

VALOR DE RETORNO DE LA FUNCIÓN DE DEVOLUCIÓN DE LLAMADA

CURL_PUSH_OK (0)
La aplicación ha aceptado la transmisión y ahora puede comenzar a recibir datos; la propiedad del manejador curl ha sido asumida por la aplicación.
CURL_PUSH_DENY (1)
La función de devolución de llamada niega la transmisión y no llegan datos a la aplicación; libcurl destruye el manejador easy.
CURL_PUSH_ERROROUT (2)
Devolver este código rechaza la transmisión insertada y devuelve un error a la transmisión padre, lo que hace que se cierre con un error. (Añadido en 7.72.0)
*
Todos los demás códigos de retorno están reservados para uso futuro.

POR DEFECTO

NULL, sin función de devolución de llamada

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

#include <string.h>
/* solo permitir inserciones para nombres de archivo que comiencen con "push-" */
int push_callback(CURL *parent,
                  CURL *easy,
                  size_t num_headers,
                  struct curl_pushheaders *headers,
                  void *clientp)
{
  char *headp;
  int *transfers = (int *)clientp;
  FILE *out;
  headp = curl_pushheader_byname(headers, ":path");
  if(headp && !strncmp(headp, "/push-", 6)) {
    fprintf(stderr, "La RUTA es %s\n", headp);
    /* guardar la inserción aquí */
    out = fopen("pushed-stream", "wb");
    /* escribir en este archivo */
    curl_easy_setopt(easy, CURLOPT_WRITEDATA, out);
    (*transfers)++; /* uno más */
    return CURL_PUSH_OK;
  }
  return CURL_PUSH_DENY;
}
int main(void)
{
  int counter;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_PUSHFUNCTION, push_callback);
  curl_multi_setopt(multi, CURLMOPT_PUSHDATA, &counter);
}

DISPONIBILIDAD

Añadido en curl 7.44.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un código CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulta libcurl-errors(3).
