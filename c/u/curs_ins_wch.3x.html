curs_ins_wch(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_ins_wch(3X) Llamadas a biblioteca curs_ins_wch(3X)

NOMBRE

ins_wch, mvins_wch, mvwins_wch, wins_wch - insertar un carácter complejo de curses en una ventana

SINOPSIS

#include <curses.h>
int ins_wch(const cchar_t *wch);
int wins_wch(WINDOW *win, const cchar_t *wch);
int mvins_wch(int y, int x, const cchar_t *wch);
int mvwins_wch(WINDOW *win, int y, int x, const cchar_t *wch);

DESCRIPCIÓN

Estas funciones insertan el carácter complejo de curses wch en el cursor de la ventana especificada win (o stdscr). El carácter que estaba previamente en el cursor y cualquier carácter a su derecha se mueven una celda a la derecha; el carácter más a la derecha de la línea se descarta. El cursor no avanza.

VALOR DE RETORNO

Estas funciones devuelven OK en caso de éxito y ERR en caso de fallo.

Las funciones que toman un argumento de tipo puntero a WINDOW fallan si el puntero es NULL.

Las funciones prefijadas con “mv” primero realizan un movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

La capacidad insert_character (ich1) de un terminal no se utiliza necesariamente.

ins_wch, mvins_wch y mvwins_wch pueden estar implementadas como macros.

PORTABILIDAD

X/Open Curses, Issue 4 describe estas funciones.

SVr4 solo describe los valores de retorno exitosos como “un valor entero distinto de ERR”.

HISTORIAL

SVr4 (1989) implementó estas funciones bajo los nombres inswch, winswch, mvinswch y mvwinswch.

VER TAMBIÉN

curs_insch(3X) describe funciones comparables en la configuración curses sin caracteres anchos.
