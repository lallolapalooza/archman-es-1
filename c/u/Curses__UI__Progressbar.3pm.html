Curses::UI::Progressbar(3) Documentación de Perl contribuida por el usuario Curses::UI::Progressbar(3)

NOMBRE

Curses::UI::Progressbar - Crear y manipular widgets de barra de progreso

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Progressbar

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $progressbar = $win->add(
    'myprogressbar', 'Progressbar',
    -max       => 250,
    -pos       => 42,
);
$progressbar->draw;

DESCRIPCIÓN

Curses::UI::Progressbar es un widget que puede usarse para proporcionar algún tipo de información de progreso al usuario de su programa. La barra de progreso se ve así:

+------------------------------------------+
|||||||||---------- 14% ------------------ |
+------------------------------------------+

Consulte examples/demo-Curses::UI::Progressbar en la distribución para una demostración corta.

OPCIONES ESTÁNDAR

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse

Para una explicación de estas opciones estándar, consulte Curses::UI::Widget.

OPCIONES ESPECÍFICAS DEL WIDGET

  • -min < VALOR >

    Esta opción establece el valor mínimo para la barra de progreso. El valor predeterminado es 0.

  • -max < VALOR >

    Esta opción establece el valor máximo para la barra de progreso.

  • -pos < VALOR >

    Esta opción establece la posición de inicio para la barra de progreso.

  • -nopercentage < BOOLEAN >

    Esta opción controla si se debe dibujar un indicador de porcentaje en el widget. El valor predeterminado para el valor BOOLEANO es falso, por lo que se dibujará un indicador de porcentaje.

  • -showvalue < BOOLEAN >

    Si esta opción se establece en un valor verdadero, el valor de posición actual se dibujará en el widget.

  • -nocenterline < BOOLEAN >

    Esta opción controla si se debe dibujar una línea horizontal en el widget. El valor predeterminado para el valor BOOLEANO es falso, por lo que se dibujará una línea horizontal.

MÉTODOS

  • new ( OPCIONES )
  • layout ( )
  • draw ( BOOLEAN )
  • intellidraw ( )
  • focus ( )

    Estos son métodos estándar. Consulte Curses::UI::Widget para una explicación de estos.

  • get ( )

    Este método devolverá el valor actual de -pos del widget.

  • pos ( VALOR )

    Este método establecerá el valor de -pos del widget a SCALAR.

LIGADURAS PREDETERMINADAS

Dado que una barra de progreso es un widget no interactivo, no tiene ligaduras.
