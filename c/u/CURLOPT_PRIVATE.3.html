CURLOPT_PRIVATE(3)

Paquete: curl

Licencias: MIT

CURLOPT_PRIVATE(3) Manual de funciones de biblioteca CURLOPT_PRIVATE(3)

NOMBRE

CURLOPT_PRIVATE - almacenar un puntero privado

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PRIVATE, void *pointer);

DESCRIPCIÓN

Pasa un puntero void * como parámetro, apuntando a datos que deben asociarse con este manejador de curl. El puntero puede recuperarse posteriormente utilizando curl_easy_getinfo(3) con la opción CURLINFO_PRIVATE(3). libcurl en sí mismo nunca hace nada con estos datos.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

struct private {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  struct private secrets;
  if(curl) {
    struct private *extracted;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* almacenar un puntero a nuestra estructura privada */
    curl_easy_setopt(curl, CURLOPT_PRIVATE, &secrets);
    curl_easy_perform(curl);
    /* también podemos extraer el puntero privado de nuevo */
    curl_easy_getinfo(curl, CURLINFO_PRIVATE, &extracted);
  }
}

DISPONIBILIDAD

Añadido en curl 7.10.3

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un código CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLINFO_PRIVATE(3), CURLOPT_STDERR(3), CURLOPT_VERBOSE(3)
