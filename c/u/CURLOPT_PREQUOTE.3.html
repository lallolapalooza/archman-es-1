CURLOPT_PREQUOTE(3)

Paquete: curl

Licencias: MIT

CURLOPT_PREQUOTE(3) Manual de funciones de biblioteca CURLOPT_PREQUOTE(3)

NOMBRE

CURLOPT_PREQUOTE - comandos para ejecutar antes de una transferencia FTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PREQUOTE,
                          struct curl_slist *cmds);

DESCRIPCIÓN

Pase un puntero a una lista enlazada de comandos FTP para enviar al servidor después de que se haya establecido el tipo de transferencia. La lista enlazada debe ser una lista completamente válida de estructuras struct curl_slist llenas correctamente, tal como se describe para CURLOPT_QUOTE(3).

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para desactivar su uso nuevamente.

libcurl no copia la lista; debe mantenerse hasta después de que la transferencia haya completado.

Mientras que CURLOPT_QUOTE(3) y CURLOPT_POSTQUOTE(3) funcionan para SFTP, esta opción no.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

int main(void)
{
  struct curl_slist *cmdlist = NULL;
  cmdlist = curl_slist_append(cmdlist, "SYST");
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/foo.bin");
    /* pasar los comandos FTP a ejecutar */
    curl_easy_setopt(curl, CURLOPT_PREQUOTE, cmdlist);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
  curl_slist_free_all(cmdlist);
}

DISPONIBILIDAD

Añadido en curl 7.9.5

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
