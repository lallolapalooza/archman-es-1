CURLOPT_TIMEOUT(3)

Paquete: curl

Licencias: MIT

CURLOPT_TIMEOUT(3) Manual de funciones de biblioteca CURLOPT_TIMEOUT(3)

NOMBRE

CURLOPT_TIMEOUT - tiempo máximo permitido para la transferencia

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TIMEOUT, long timeout);

DESCRIPCIÓN

Pase un long como parámetro que contenga timeout, el tiempo máximo en segundos que permite que la operación de transferencia completa tenga lugar. El todo, desde el principio hasta el final. Normalmente, las búsquedas de nombres pueden llevar un tiempo considerable y limitar las operaciones corre el riesgo de abortar operaciones perfectamente normales.

CURLOPT_TIMEOUT_MS(3) es la misma función pero establecida en milisegundos.

Si se establecen tanto CURLOPT_TIMEOUT(3) como CURLOPT_TIMEOUT_MS(3), se usa el valor establecido en último lugar.

Dado que esta opción establece un límite estricto en cuánto tiempo se permite que una solicitud dure, tiene un uso limitado en casos de uso dinámicos con tiempos de transferencia variables. Esto es especialmente aparente cuando se utiliza la interfaz múltiple, que puede poner en cola la transferencia, y ese tiempo está incluido. Se aconseja explorar CURLOPT_LOW_SPEED_LIMIT(3), CURLOPT_LOW_SPEED_TIME(3) o utilizar CURLOPT_PROGRESSFUNCTION(3) para implementar su propia lógica de tiempo de espera.

El tiempo de espera de conexión establecido con CURLOPT_CONNECTTIMEOUT(3) se incluye en este tiempo de espera general que lo abarca todo.

Con CURLOPT_CONNECTTIMEOUT(3) establecido en 3 y CURLOPT_TIMEOUT(3) establecido en 5, la operación nunca puede durar más de 5 segundos.

Con CURLOPT_CONNECTTIMEOUT(3) establecido en 4 y CURLOPT_TIMEOUT(3) establecido en 2, la operación nunca puede durar más de 2 segundos.

Esta opción puede hacer que libcurl utilice la señal SIGALRM para realizar tiempo de espera en llamadas al sistema en compilaciones que no utilizan DNS asíncrono. En sistemas similares a Unix, esto podría causar el uso de señales a menos que se establezca CURLOPT_NOSIGNAL(3).

POR OMISIÓN

0 (cero), lo que significa que nunca se agota el tiempo de espera durante la transferencia.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* completar en 20 segundos */
    curl_easy_setopt(curl, CURLOPT_TIMEOUT, 20L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_CONNECTTIMEOUT(3), CURLOPT_LOW_SPEED_LIMIT(3), CURLOPT_TCP_KEEPALIVE(3), CURLOPT_TIMEOUT_MS(3)
