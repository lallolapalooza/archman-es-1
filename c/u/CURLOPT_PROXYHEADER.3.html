CURLOPT_PROXYHEADER(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXYHEADER(3) Manual de funciones de biblioteca CURLOPT_PROXYHEADER(3)

NOMBRE

CURLOPT_PROXYHEADER(3) — conjunto de cabeceras HTTP para pasar al proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYHEADER,
                          struct curl_slist *headers);

DESCRIPCIÓN

Pasa un puntero a una lista enlazada de cabeceras HTTP para enviar en tu solicitud HTTP enviada a un proxy. Las reglas para esta lista son idénticas a las de la opción CURLOPT_HTTPHEADER(3).

Las cabeceras establecidas con esta opción solo se utilizan en solicitudes enviadas a un proxy, cuando también hay una solicitud enviada a un host.

La primera línea de una solicitud (que contiene el método, generalmente GET o POST) NO es una cabecera y no puede ser reemplazada utilizando esta opción. Solo las líneas que siguen a la línea de solicitud son cabeceras. Añadir esta línea de método en esta lista de cabeceras provoca que tu solicitud envíe una cabecera inválida.

Usar esta opción múltiples veces hace que la última lista establecida anule las anteriores. Establécela a NULL para deshabilitar su uso nuevamente.

libcurl no copia la lista, debe mantenerse disponible hasta después de que la transferencia se haya completado.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  struct curl_slist *list;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://proxy.example.com:80");
    list = curl_slist_append(NULL, "Shoesize: 10");
    list = curl_slist_append(list, "Accept:");
    curl_easy_setopt(curl, CURLOPT_PROXYHEADER, list);
    curl_easy_perform(curl);
    curl_slist_free_all(list); /* liberar la lista de nuevo */
  }
}

DISPONIBILIDAD

Añadido en curl 7.37.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
