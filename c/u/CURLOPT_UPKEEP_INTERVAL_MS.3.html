CURLOPT_UPKEEP_INTERVAL_MS(3)

Paquete: curl

Licencias: MIT

CURLOPT_UPKEEP_INTERVAL_MS(3) Manual de funciones de la biblioteca CURLOPT_UPKEEP_INTERVAL_MS(3)

NOMBRE

CURLOPT_UPKEEP_INTERVAL_MS - intervalo de mantenimiento de la conexión

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_UPKEEP_INTERVAL_MS,
                          long upkeep_interval_ms);

DESCRIPCIÓN

Algunos protocolos tienen mecanismos de "mantenimiento de conexión". Estos mecanismos suelen enviar tráfico en las conexiones existentes para mantenerlas activas; esto puede evitar que las conexiones se cierren debido a firewalls demasiado celosos, por ejemplo.

El usuario debe llamar explícitamente a curl_easy_upkeep(3) para realizar el trabajo de mantenimiento.

Actualmente, el único protocolo con un mecanismo de mantenimiento de conexión es HTTP/2: cuando se supera el intervalo de mantenimiento de conexión y se llama a curl_easy_upkeep(3), se envía un frame PING de HTTP/2 en la conexión.

VALOR POR DEFECTO

CURL_UPKEEP_INTERVAL_DEFAULT (actualmente definido como 60000L, que son 60 segundos)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* Conectar a un servidor HTTP/2. */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Establecer el intervalo a 30000ms / 30s */
    curl_easy_setopt(curl, CURLOPT_UPKEEP_INTERVAL_MS, 30000L);
    curl_easy_perform(curl);
    /* Realizar más trabajo aquí. */
    /* Mientras la conexión se mantiene abierta, se puede llamar a curl_easy_upkeep().
       Si se llama a curl_easy_upkeep() y el tiempo transcurrido desde el último
       mantenimiento supera el intervalo, se envía un PING de HTTP/2. */
    curl_easy_upkeep(curl);
    /* Realizar más trabajo aquí. */
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.62.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
