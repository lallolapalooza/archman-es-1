CURLOPT_PUT(3)

Paquete: curl

Licencias: MIT

CURLOPT_PUT(3) Manual de funciones de la biblioteca CURLOPT_PUT(3)

NOMBRE

CURLOPT_PUT - realizar una solicitud HTTP PUT

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PUT, long put);

DESCRIPCIÓN

Un parámetro establecido a 1 indica a la biblioteca que utilice HTTP PUT para transferir datos. Los datos deben establecerse con CURLOPT_READDATA(3) y CURLOPT_INFILESIZE(3).

Esta opción está obsoleta desde la versión 7.12.1. Utilice CURLOPT_UPLOAD(3).

POR DEFECTO

0, deshabilitado

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

static size_t read_cb(char *ptr, size_t size, size_t nmemb, void *userdata)
{
  FILE *src = userdata;
  /* copia tantos datos como sea posible en el búfer 'ptr', pero no más que
     'size' * 'nmemb' bytes */
  size_t retcode = fread(ptr, size, nmemb, src);
  return retcode;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    FILE *src = fopen("archivo-local", "r");
    curl_off_t fsize = 123456; /* establécelo al tamaño del archivo de entrada */
    /* queremos usar nuestra propia función de lectura */
    curl_easy_setopt(curl, CURLOPT_READFUNCTION, read_cb);
    /* habilita PUT */
    curl_easy_setopt(curl, CURLOPT_PUT, 1L);
    /* especifica el destino */
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://ejemplo.com/dir/a/nuevoarchivo");
    /* ahora especifica qué puntero pasar a nuestra devolución de llamada */
    curl_easy_setopt(curl, CURLOPT_READDATA, src);
    /* Establece el tamaño del archivo a subir */
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, (curl_off_t)fsize);
    /* Ahora ejecuta y haz lo que te han dicho */
    curl_easy_perform(curl);
  }
}

OBSOLETO

Obsoleto desde la versión 7.12.1.

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo está bien, un valor distinto de cero indica que ocurrió un error, consulta libcurl-errors(3).

VER TAMBIÉN

CURLOPT_HTTPGET(3), CURLOPT_MIMEPOST(3), CURLOPT_POSTFIELDS(3), CURLOPT_UPLOAD(3)
