CURLOPT_DNS_LOCAL_IP6(3)

Paquete: curl

Licencias: MIT

CURLOPT_DNS_LOCAL_IP6(3) Manual de funciones de biblioteca CURLOPT_DNS_LOCAL_IP6(3)

NOMBRE

CURLOPT_DNS_LOCAL_IP6 - IPV6 a la que enlazará la resolución DNS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DNS_LOCAL_IP6, char *address);

DESCRIPCIÓN

Establece la dirección IPv6 local address a la que el resolutor debe enlazarse. El argumento debe ser de tipo char \* y contener una única dirección IPv6 como cadena. Establezca esta opción a NULL para usar la configuración predeterminada (no enlazar a una dirección IP específica).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción múltiples veces hace que la última cadena establecida reemplace a las anteriores. Establézcala a NULL para deshabilitar su uso de nuevo.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_DNS_LOCAL_IP6, "fe80::a9ff:fe46:b619");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

NOTAS

Esta opción requiere que libcurl se haya compilado con un backend resolutor que soporte esta operación. El backend c-ares es el único con esta capacidad.

DISPONIBILIDAD

Añadido en curl 7.33.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
