subrutina cuncsd2by1 (character jobu1, character jobu2, character jobv1t, integer m, integer p, integer q, complex, dimension(ldx11,*) x11, integer ldx11, complex, dimension(ldx21,*) x21, integer ldx21, real, dimension(*) theta, complex, dimension(ldu1,*) u1, integer ldu1, complex, dimension(ldu2,*) u2, integer ldu2, complex, dimension(ldv1t,*) v1t, integer ldv1t, complex, dimension(*) work, integer lwork, real, dimension(*) rwork, integer lrwork, integer, dimension(*) iwork, integer

CUNCSD2BY

1

Propósito

: 
!>
!> CUNCSD2BY1 calcula la descomposición CS de una matriz X de M por Q con
!> columnas ortonormales que ha sido particionada en una estructura de
!> bloques de 2 por 1:
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 es de P por Q. Las matrices unitarias U1, U2 y V1 son de P por P,
!> (M-P) por (M-P) y Q por Q, respectivamente. C y S son matrices
!> diagonales no negativas de R por R que satisfacen C^2 + S^2 = I, en
!> las que R = MIN(P,M-P,Q,M-Q). I1 es una matriz identidad de K1 por K1
!> y I2 es una matriz identidad de K2 por K2, donde K1 = MAX(Q+P-M,0),
!> K2 = MAX(Q-P,0).
!>
!
>

Parámetro

s
JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      se calcula U1;
!>          de lo contrario:  no se calcula U1.
!
>

JOBU

2 
!>          JOBU2 es CHARACTER
!>          = 'Y':      se calcula U2;
!>          de lo contrario:  no se calcula U2.
!
>

JOBV1

T 
!>          JOBV1T es CHARACTER
!>          = 'Y':      se calcula V1T;
!>          de lo contrario:  no se calcula V1T.
!
>

M 
!>          M es INTEGER
!>          El número de filas en X.
!
>

P 
!>          P es INTEGER
!>          El número de filas en X11. 0 <= P <= M.
!
>

Q 
!>          Q es INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <= M.
!
>

X1

1 
!>          X11 es un arreglo COMPLEX, dimensión (LDX11,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!
>

LDX1

1 
!>          LDX11 es INTEGER
!>          La dimensión principal de X11. LDX11 >= MAX(1,P).
!
>

X2

1 
!>          X21 es un arreglo COMPLEX, dimensión (LDX21,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!
>

LDX2

1 
!>          LDX21 es INTEGER
!>          La dimensión principal de X21. LDX21 >= MAX(1,M-P).
!
>

THET

A 
!>          THETA es un arreglo REAL, dimensión (R), en la que R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) y
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!
>

U

1 
!>          U1 es un arreglo COMPLEX, dimensión (P)
!>          Si JOBU1 = 'Y', U1 contiene la matriz unitaria U1 de P por P.
!
>

LDU

1 
!>          LDU1 es INTEGER
!>          La dimensión principal de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!
>

U

2 
!>          U2 es un arreglo COMPLEX, dimensión (M-P)
!>          Si JOBU2 = 'Y', U2 contiene la matriz unitaria U2 de (M-P) por (M-P).
!
>

LDU

2 
!>          LDU2 es INTEGER
!>          La dimensión principal de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!
>

V1

T 
!>          V1T es un arreglo COMPLEX, dimensión (Q)
!>          Si JOBV1T = 'Y', V1T contiene la matriz unitaria V1**T de Q por Q.
!
>

LDV1

T 
!>          LDV1T es INTEGER
!>          La dimensión principal de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo de los arreglos WORK y
!>          RWORK, devuelve este valor como la primera entrada de los
!>          arreglos WORK y RWORK, respectivamente, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK o LRWORK.
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>          Si INFO > 0 en la salida, RWORK(2:R) contiene los valores PHI(1),
!>          ..., PHI(R-1) que, junto con THETA(1), ..., THETA(R),
!>          definen la matriz en forma de bloques bidiagonal intermedio
!>          que permanece después de la no convergencia. INFO especifica
!>          el número de PHI no nulos.
!
>

LRWOR

K 
!>          LRWORK es INTEGER
!>          La dimensión del arreglo RWORK.
!>
!>          Si LRWORK=-1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo de los arreglos WORK y
!>          RWORK, devuelve este valor como la primera entrada de los
!>          arreglos WORK y RWORK, respectivamente, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK o LRWORK.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (M-MIN(P,M-P,Q,M-Q))
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  CBBCSD no convergió. Vea la descripción de WORK
!>                arriba para más detalles.
!
>
