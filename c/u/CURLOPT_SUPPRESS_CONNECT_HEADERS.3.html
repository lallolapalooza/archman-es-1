CURLOPT_SUPPRESS_CONNECT_HEADERS(3)

Paquete: curl

Licencias: MIT

CURLOPT_SUPPRESS_CONNECT_HEADERS(3) Manual de funciones de la biblioteca CURLOPT_SUPPRESS_CONNECT_HEADERS(3)

NOMBRE

CURLOPT_SUPPRESS_CONNECT_HEADERS - suprimir encabezados de respuesta de conexión de proxy

SINAPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SUPPRESS_CONNECT_HEADERS, long onoff);

DESCRIPCIÓN

Cuando se usa CURLOPT_HTTPPROXYTUNNEL(3) y se realiza una solicitud CONNECT, suprime los encabezados de respuesta CONNECT del proxy de las funciones de devolución de llamada del usuario CURLOPT_HEADERFUNCTION(3) y CURLOPT_WRITEFUNCTION(3).

Los encabezados de respuesta CONNECT del proxy pueden complicar el procesamiento de encabezados, ya que son esencialmente un conjunto separado de encabezados. Puede habilitar esta opción para suprimir esos encabezados.

Por ejemplo, supongamos que se va a recuperar una URL HTTPS a través de CONNECT. En caso de éxito, normalmente habría dos conjuntos de encabezados, y cada línea de encabezado enviada a la función de encabezado y/o a la función de escritura. Los datos dados a las funciones de devolución de llamada se verían así:

HTTP/1.1 200 Connection established
{headers}
...
HTTP/1.1 200 OK
Content-Type: application/json
{headers}
...
{body}
...

Sin embargo, al habilitar esta opción, se suprimen los encabezados de respuesta CONNECT, por lo que los datos dados a las funciones de devolución de llamada se verían así:

HTTP/1.1 200 OK
Content-Type: application/json
{headers}
...
{body}
...

PREDETERMINADO

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_HEADER, 1L);
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://foo:3128");
    curl_easy_setopt(curl, CURLOPT_HTTPPROXYTUNNEL, 1L);
    curl_easy_setopt(curl, CURLOPT_SUPPRESS_CONNECT_HEADERS, 1L);
    curl_easy_perform(curl);
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.54.0

VALOR DE RETORNO

CURLE_OK o un error como CURLE_UNKNOWN_OPTION.

VER TAMBIÉN

CURLOPT_HEADER(3), CURLOPT_HTTPPROXYTUNNEL(3), CURLOPT_PROXY(3)
