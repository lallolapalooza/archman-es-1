CURLOPT_FTP_FILEMETHOD(3)

Paquete: curl

Licencias: MIT

CURLOPT_FTP_FILEMETHOD(3) Manual de funciones de biblioteca CURLOPT_FTP_FILEMETHOD(3)

NOMBRE

CURLOPT_FTP_FILEMETHOD(3) - seleccionar el método de recorrido de directorios para FTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_FILEMETHOD,
                          long method);

DESCRIPCIÓN

Pasa un `long` indicando a libcurl qué *método* usar para acceder a un archivo en un servidor FTP(S).

Esta opción existe porque algunas implementaciones de servidor no cumplen con lo que los estándares dicen que debería funcionar.

El argumento debe ser una de las siguientes alternativas:

CURLFTPMETHOD_MULTICWD
libcurl realiza una única operación CWD por cada parte del directorio en la URL dada. Para jerarquías profundas, esto significa muchos comandos. Así es como RFC 1738 dice que debe hacerse. Este es el comportamiento predeterminado pero el más lento.
CURLFTPMETHOD_NOCWD
libcurl no realiza ningún CWD en absoluto. libcurl realiza SIZE, RETR, STOR, etc., y proporciona una ruta completa al servidor para todos estos comandos. Este es el comportamiento más rápido, ya que omite el cambio de directorios.
CURLFTPMETHOD_SINGLECWD
libcurl realiza un único CWD con el directorio de destino completo y luego opera en el archivo "normalmente" (como en el caso de multicwd). Esto es algo más compatible con los estándares que 'nocwd' pero sin la penalización completa de 'multicwd'.

PREDETERMINADO

CURLFTPMETHOD_MULTICWD

PROTOCOLOS

Esta funcionalidad afecta solo a ftp.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/1/2/3/4/new.txt");
    curl_easy_setopt(curl, CURLOPT_FTP_FILEMETHOD, CURLFTPMETHOD_SINGLECWD);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Las enumeraciones CURLFTPMETHOD_* se convirtieron en tipos `long` en la versión 8.16.0. Antes de esta versión, se requería una conversión a `long` al pasarlas a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.15.1.

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien. Un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_DIRLISTONLY(3), CURLOPT_FTP_SKIP_PASV_IP(3)
