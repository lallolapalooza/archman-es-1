NOMBRE

cupstestppd - prueba la conformidad de los archivos ppd (obsoleto)

SINOPSIS

cupstestppd [ -I categoría ] [ -R directorio_raiz ] [ -W categoría ] [ -q ] [ -r ] [ -v[v] ] nombre_archivo.ppd[.gz] [ ... nombre_archivo.ppd[.gz] ]
cupstestppd [ -R directorio_raiz ] [ -W categoría ] [ -q ] [ -r ] [ -v[v] ] -

DESCRIPCIÓN

cupstestppd prueba la conformidad de los archivos PPD con la especificación de formato de archivo Adobe PostScript Printer Description versión 4.3. También se puede utilizar para listar las opciones admitidas y las fuentes disponibles en un archivo PPD. Los resultados de la prueba y cualquier otra salida se envían a la salida estándar.

La primera forma de cupstestppd prueba uno o más archivos PPD en la línea de comandos. La segunda forma prueba el archivo PPD proporcionado en la entrada estándar.

OPCIONES

cupstestppd admite las siguientes opciones:

-I nombre_archivo
Ignora todas las advertencias de PCFileName.
-I filtros
Ignora todos los errores de filtro.
-I perfiles
Ignora todos los errores de perfil.
-R directorio_raiz
Especifica un directorio raíz alternativo para el filtro, el prefiltro y otras comprobaciones de archivos de soporte.
-W restricciones
Informa todos los errores de UIConstraint como advertencias.
-W predeterminados
Excepto para las opciones relacionadas con el tamaño, informa todos los errores de opción predeterminada como advertencias.
-W filtros
Informa todos los errores de filtro como advertencias.
-W perfiles
Informa todos los errores de perfil como advertencias.
-W tamaños
Informa todos los errores de tamaño de medios como advertencias.
-W traducciones
Informa todos los errores de traducción como advertencias.
-W todos
Informa todos los errores anteriores como advertencias.
-W ninguno
Informa todos los errores anteriores como errores.
-q
Especifica que no se debe mostrar ninguna información.
-r
Relaja los requisitos de conformidad de PPD para que los problemas comunes de espacios en blanco, caracteres de control y formato no se traten como errores graves.
-v
Especifica que se deben mostrar los resultados detallados de la prueba de conformidad en lugar del estado conciso PASS/FAIL/ERROR.
-vv
Especifica que se debe mostrar toda la información del archivo PPD, además de los resultados detallados de la prueba de conformidad.

Las opciones -q, -v y -vv son mutuamente excluyentes.

CÓDIGO DE SALIDA

cupstestppd devuelve cero si tiene éxito y un valor distinto de cero si hay un error. Los códigos de error son los siguientes:

1
Argumentos de línea de comandos incorrectos o nombre de archivo PPD faltante.
2
No se puede abrir o leer el archivo PPD.
3
El archivo PPD contiene errores de formato que no se pueden omitir.
4
El archivo PPD no se ajusta a la especificación PPD de Adobe.

EJEMPLOS

El siguiente comando probará todos los archivos PPD del directorio actual e imprimirá los nombres de cada archivo que no cumpla:

    find . -name \*.ppd \! -exec cupstestppd -q '{}' \; -print

El siguiente comando prueba todos los archivos PPD del directorio actual e imprime resultados detallados de la prueba de conformidad para los archivos que no cumplen:

    find . -name \*.ppd \! -exec cupstestppd -q '{}' \; \
        -exec cupstestppd -v '{}' \;

NOTAS

Los archivos PPD están obsoletos y dejarán de ser compatibles en una futura versión de características de CUPS. Las impresoras que no admiten IPP pueden ser compatibles utilizando aplicaciones como ippeveprinter(1).
