CURLOPT_EXPECT_100_TIMEOUT_MS(3)

Paquete: curl

Licencias: MIT

CURLOPT_EXPECT_100_TIMEOUT_MS(3) Manual de funciones de la biblioteca CURLOPT_EXPECT_100_TIMEOUT_MS(3)

NOMBRE

CURLOPT_EXPECT_100_TIMEOUT_MS - tiempo de espera para la respuesta Expect: 100-continue

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_EXPECT_100_TIMEOUT_MS,
                          long milliseconds);

DESCRIPCIÓN

Pase un valor `long` para indicar a libcurl el número de *milissegundos* a esperar por una respuesta del servidor con el código de estado HTTP 100 (Continue), 417 (Expectation Failed) o similar, después de enviar una solicitud HTTP que contenga una cabecera Expect: 100-continue. Si esto excede el tiempo de espera antes de recibir una respuesta, el cuerpo de la solicitud se envía de todos modos.

VALOR PREDETERMINADO

1000 milissegundos

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* esperar 3 segundos para 100-continue */
    curl_easy_setopt(curl, CURLOPT_EXPECT_100_TIMEOUT_MS, 3000L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.36.0

VALOR DE RETORNO

curl_easy_setopt(3) retorna un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error; ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_HTTPPOST(3), CURLOPT_POST(3)
