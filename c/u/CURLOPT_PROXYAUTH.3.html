CURLOPT_PROXYAUTH(3) Manual de funciones de biblioteca CURLOPT_PROXYAUTH(3)

NOMBRE

CURLOPT_PROXYAUTH(3) - métodos de autenticación de proxy HTTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYAUTH, long mascara_bits);

DESCRIPCIÓN

Pase un `long` como parámetro, que se establece a una máscara de bits, para indicar a libcurl qué método(s) de autenticación HTTP desea que utilice para la autenticación de su proxy. Si se establece más de un bit, libcurl primero consulta el sitio para ver qué métodos de autenticación admite y luego elige el mejor que usted le permite usar. Para algunos métodos, esto implica un viaje de ida y vuelta de red adicional. Establezca el nombre y la contraseña reales con la opción CURLOPT_PROXYUSERPWD(3).

La máscara de bits puede construirse a partir de los bits listados y descritos en la página del manual de CURLOPT_HTTPAUTH(3).

POR OMISIÓN

CURLAUTH_BASIC

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* usar este proxy */
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://local.example.com:1080");
    /* permitir cualquier autenticación que el proxy hable */
    curl_easy_setopt(curl, CURLOPT_PROXYAUTH, CURLAUTH_ANY);
    /* establecer las credenciales del proxy */
    curl_easy_setopt(curl, CURLOPT_PROXYUSERPWD, "james:007");
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Las macros CURLAUTH_* se convirtieron en tipos `long` en la versión 7.26.0; antes de esta versión, era necesario un `long` cast al pasarlas a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.10.7

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).
