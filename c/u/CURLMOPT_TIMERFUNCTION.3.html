CURLMOPT_TIMERFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLMOPT_TIMERFUNCTION(3) Manual de funciones de la biblioteca CURLMOPT_TIMERFUNCTION(3)

NOMBRE

CURLMOPT_TIMERFUNCTION - callback para recibir valores de tiempo de espera

SINOPSIS

#include <curl/curl.h>
int timer_callback(CURLM *multi,    /* manejador multi */
                   long timeout_ms, /* tiempo de espera en milisegundos */
                   void *clientp);  /* puntero privado del callback */
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_TIMERFUNCTION, timer_callback);

DESCRIPCIÓN

Pase un puntero a su función de callback, que debe coincidir con el prototipo mostrado arriba.

Ciertas características, como los tiempos de espera y los reintentos, requieren que usted llame a libcurl incluso cuando no hay actividad en los descriptores de archivo.

Su función de callback timer_callback debe instalar un único temporizador no repetitivo con un tiempo de expiración de timeout_ms milisegundos. Cuando ese temporizador se active, llame a curl_multi_socket_action(3) o curl_multi_perform(3), dependiendo de la interfaz que utilice.

Si se llama a este callback cuando ya hay un temporizador en ejecución, este nuevo tiempo de expiración *reemplaza* el tiempo de espera anterior. La aplicación debe cancelar efectivamente el temporizador antiguo y establecer uno nuevo utilizando este nuevo tiempo de expiración.

Un valor de timeout_ms de -1 pasado a este callback significa que debe eliminar el temporizador. Todos los demás valores son tiempos de expiración válidos en número de milisegundos, incluido cero milisegundos.

La función timer_callback se llama cuando se cambia el tiempo de expiración del temporizador.

El puntero clientp se establece con CURLMOPT_TIMERDATA(3).

La función de callback del temporizador debe devolver 0 en caso de éxito y -1 en caso de error. Si esta función de callback devuelve un error, *todas* las transferencias actualmente en curso en este manejador multi se abortan y fallan.

Este callback puede usarse en lugar de, o además de, curl_multi_timeout(3).

ADVERTENCIA: no llame a libcurl directamente desde dentro del propio callback cuando el valor timeout_ms sea cero, ya que existe el riesgo de desencadenar un comportamiento recursivo desagradable que llama inmediatamente a otra llamada al callback con un tiempo de espera cero...

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

struct priv {
  void *custom;
};
static int timerfunc(CURLM *multi, long timeout_ms, void *clientp)
{
  struct priv *mydata = clientp;
  printf("nuestro puntero: %p\n", mydata->custom);
  if(timeout_ms >= 0) {
    /* este es el nuevo tiempo de espera único a esperar, incluido el cero */
  }
  else {
    /* eliminar el tiempo de espera, no hay nada que esperar ahora */
  }
  return 0;
}
int main(void)
{
  struct priv mydata;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_TIMERFUNCTION, timerfunc);
  curl_multi_setopt(multi, CURLMOPT_TIMERDATA, &mydata);
}

DISPONIBILIDAD

Añadido en curl 7.16.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).
