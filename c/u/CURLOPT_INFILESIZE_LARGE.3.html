CURLOPT_INFILESIZE_LARGE(3)

Paquete: curl

Licencias: MIT

CURLOPT_INFILESIZE_LARGE(3) Manual de funciones de biblioteca CURLOPT_INFILESIZE_LARGE(3)

NOMBRE

CURLOPT_INFILESIZE_LARGE - tamaño del archivo de entrada para enviar

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INFILESIZE_LARGE,
                          curl_off_t filesize);

DESCRIPCIÓN

Al cargar un archivo en un sitio remoto, se debe usar filesize para indicar a libcurl cuál es el tamaño esperado del archivo de entrada. Este valor debe pasarse como un curl_off_t.

Para cargar usando SCP, esta opción o CURLOPT_INFILESIZE(3) es obligatoria.

Para cancelar este valor, establécelo en -1.

Al enviar correos electrónicos usando SMTP, este comando se puede utilizar para especificar el parámetro opcional SIZE para el comando MAIL FROM.

Esta opción no limita la cantidad de datos que libcurl realmente envía, ya que eso está completamente controlado por lo que devuelve la función de devolución de llamada de lectura, pero indicar un valor y enviar una cantidad diferente puede provocar errores.

POR OMISIÓN

No establecido

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

#define FILE_SIZE 123456
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_off_t uploadsize = FILE_SIZE;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/destination.tar.gz");
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, uploadsize);
    curl_easy_perform(curl);
  }
}

HISTORIAL

Soporte SMTP agregado en 7.23.0

DISPONIBILIDAD

Agregado en curl 7.11.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
