NOMBRE

cupsfilter - convierte un archivo a otro formato usando filtros CUPS (obsoleto)

SINOPSIS

cupsfilter [ --list-filters ] [ -D ] [ -U usuario ] [ -c archivo-config ] [ -d impresora ] [ -e ] [ -i tipo/mime ] [ -j id-trabajo[,N] ] [ -m tipo/mime ] [ -n copias ] [ -o nombre=valor ] [ -p archivo.ppd ] [ -t título ] [ -u ] archivo

DESCRIPCIÓN

cupsfilter es un frontend para el subsistema de filtros de CUPS que permite convertir un archivo a un formato específico, igual que si se hubiera impreso el archivo a través de CUPS. Por defecto, cupsfilter genera un archivo PDF. El archivo convertido se envía a la salida estándar.

OPCIONES

--list-filters
No ejecuta realmente los filtros, solo imprime los filtros utilizados en stdout.
-D
Elimina el archivo de entrada después de la conversión.
-U usuario
Especifica el nombre de usuario pasado a los filtros. El valor predeterminado es el nombre del usuario actual.
-c archivo-config
Utiliza el archivo de configuración cups-files.conf especificado.
-d impresora
Utiliza la información de la impresora especificada.
-e
Utiliza todos los filtros del archivo PPD.
-i tipo/mime
Especifica el tipo de archivo de origen. El tipo de archivo predeterminado se adivina usando el nombre de archivo y el contenido del archivo.
-j id-trabajo[,N]
Convierte el documento N del trabajo especificado. Si se omite N, se convierte el documento 1.
-m tipo/mime
Especifica el tipo de archivo de destino. El tipo de archivo predeterminado es application/pdf. Usa printer/foo para convertir al formato de impresora definido por los filtros en el archivo PPD.
-n copias
Especifica el número de copias a generar.
-o nombre=valor
Especifica las opciones a pasar a los filtros de CUPS.
-p archivo.ppd
Especifica el archivo PPD a utilizar.
-t título
Especifica el título del documento.
-u
Elimina el archivo PPD después de la conversión.

CÓDIGO DE SALIDA

cupsfilter devuelve un código de salida distinto de cero ante cualquier error.

ENTORNO

Todas las variables de entorno estándar de cups(1) afectan al funcionamiento de cupsfilter.

ARCHIVOS

/etc/cups/cups-files.conf
/etc/cups/*.convs
/etc/cups/*.types
/usr/share/cups/mime/*.convs
/usr/share/cups/mime/*.types

NOTAS

Los controladores de impresora, filtros y backends de CUPS están obsoletos y ya no serán compatibles en una futura versión de características de CUPS. Las impresoras que no soporten IPP pueden ser compatibles usando aplicaciones como ippeveprinter(1).

A diferencia de la impresión, los filtros ejecutados usando el comando cupsfilter utilizan el usuario y la sesión de seguridad actuales. Esto puede resultar en una salida diferente o un comportamiento inesperado.

EJEMPLO

El siguiente comando generará una vista previa en PDF del trabajo 42 para una impresora llamada "miimpresora" y la guardará en un archivo llamado "vista.pdf":

    cupsfilter -m application/pdf -d miimpresora -j 42 >vista.pdf
