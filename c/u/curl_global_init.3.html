Paquete: curl

curl_global_init(3) Manual de funciones de la biblioteca curl_global_init(3)

NOMBRE

curl_global_init - inicialización global de libcurl

SINOPSIS

#include <curl/curl.h>
CURLcode curl_global_init(long flags);

DESCRIPCIÓN

Esta función configura el entorno del programa que libcurl necesita. Piensa en ello como una extensión del cargador de bibliotecas.

Esta función debe llamarse al menos una vez dentro de un programa (un programa es todo el código que comparte un espacio de memoria) antes de que el programa llame a cualquier otra función en libcurl. El entorno que configura es constante durante la vida del programa y es el mismo para cada programa, por lo que las llamadas múltiples tienen el mismo efecto que una llamada.

La opción `flags` es un patrón de bits que le dice a libcurl exactamente qué características inicializar, como se describe a continuación. Establezca los bits deseados OReando los valores juntos. En operación normal, debe especificar CURL_GLOBAL_ALL. No use ningún otro valor a menos que esté familiarizado con él y desee controlar las operaciones internas de libcurl.

Esta función es segura para hilos en la mayoría de las plataformas. Entonces curl_version_info(3) tiene la característica threadsafe establecida (agregada en 7.84.0).

Si no es seguro para hilos (el bit mencionado anteriormente no está establecido), no debe llamar a esta función cuando cualquier otro hilo en el programa (es decir, un hilo que comparte la misma memoria) esté en ejecución. Esto no significa solo que ningún otro hilo esté usando libcurl. Debido a que curl_global_init(3) llama a funciones de otras bibliotecas que son igualmente inseguras para hilos, podría entrar en conflicto con cualquier otro hilo que use estas otras bibliotecas.

Si está inicializando libcurl desde una DLL de Windows, no debe inicializarla desde DllMain o un inicializador estático, ya que Windows mantiene el bloqueo del cargador durante ese tiempo y podría causar un interbloqueo.

Consulte la descripción en libcurl(3) de los requisitos del entorno global para obtener detalles sobre cómo usar esta función.

FLAGS

CURL_GLOBAL_ALL
Inicializa todo lo posible. Establece todos los bits conocidos excepto CURL_GLOBAL_ACK_EINTR.
CURL_GLOBAL_SSL
(La presencia o ausencia de esta bandera no tiene ningún significado desde 7.57.0. La descripción a continuación es para versiones anteriores de libcurl)

Inicializa SSL.

La implicación aquí es que si este bit no está establecido, la inicialización de la capa SSL debe ser realizada por la aplicación o, al menos, fuera de libcurl. El procedimiento exacto para realizar la inicialización SSL depende del backend TLS que utilice libcurl.

Realizar transferencias basadas en TLS sin tener la capa TLS inicializada puede llevar a comportamientos inesperados.

CURL_GLOBAL_WIN32
Inicializa las bibliotecas de sockets Win32.

La implicación aquí es que si este bit no está establecido, la inicialización de Winsock debe ser realizada por la aplicación o se corre el riesgo de comportamientos indefinidos. Esta opción existe para cuando la inicialización se maneja fuera de libcurl, por lo que no hay necesidad de que libcurl la realice de nuevo.

CURL_GLOBAL_NOTHING
No inicializa nada extra. No establece ningún bit.
CURL_GLOBAL_DEFAULT
Un valor predeterminado sensato. Inicializa tanto SSL como Win32. En este momento, equivale a la funcionalidad de la máscara CURL_GLOBAL_ALL.
CURL_GLOBAL_ACK_EINTR
Este bit no tiene sentido desde 7.69.0, sino que su comportamiento es el predeterminado.

Antes de 7.69.0: cuando esta bandera está establecida, curl reconoce la condición EINTR al conectarse o al esperar datos. De lo contrario, curl espera hasta que transcurra el tiempo de espera completo.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  curl_global_init(CURL_GLOBAL_DEFAULT);
  /* usar libcurl, luego antes de salir... */
  curl_global_cleanup();
}

DISPONIBILIDAD

Añadido en curl 7.8

VALOR DE RETORNO

Si esta función devuelve un valor distinto de cero, algo salió mal y no puedes usar las otras funciones de curl.
