NOMBRE

curl_multi_get_handles - devolver todos los identificadores fáciles añadidos

SINOPSIS

#include <curl/curl.h>
CURL **curl_multi_get_handles(CURLM *multi_handle);

DESCRIPCIÓN

Devuelve una matriz con punteros a todos los identificadores fáciles añadidos. El final de la lista se marca con un puntero NULL.

Incluso si no hay un solo identificador fácil añadido, esto sigue devolviendo una matriz pero con una única entrada NULL.

La matriz devuelta contiene todos los identificadores que están presentes en el momento de la llamada. Tan pronto como un identificador se haya eliminado o se haya añadido un identificador al identificador múltiple después de que se haya devuelto la matriz de identificadores, los dos puntos de datos estarán desincronizados.

El orden de los identificadores fáciles dentro de la matriz no está garantizado.

La matriz devuelta debe liberarse con una llamada a curl_free(3) después de su uso.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  /* inicializa una pila múltiple */
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  if(curl) {
    /* añade la transferencia */
    curl_multi_add_handle(multi, curl);
    /* extrae todos los identificadores añadidos */
    CURL **list = curl_multi_get_handles(multi);
    if(list) {
      int i;
      /* elimina todos los identificadores añadidos */
      for(i = 0; list[i]; i++) {
        curl_multi_remove_handle(multi, list[i]);
      }
      curl_free(list);
    }
  }
}

DISPONIBILIDAD

Añadido en curl 8.4.0

VALOR DE RETORNO

Devuelve NULL en caso de error. De lo contrario, devuelve un puntero a una matriz asignada.
