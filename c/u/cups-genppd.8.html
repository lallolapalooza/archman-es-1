NOMBRE

cups-genppd - generar archivos PPD de Gutenprint para usar con CUPS

SINOPSIS

cups-genppd [-c localedir] [-l locale] [-p prefijo] [-q] [-v] modelo1 [modelo2, ...modeln]
cups-genppd -L [-c localedir]
cups-genppd -M [-v]
cups-genppd -h
cups-genppd -V

DESCRIPCIÓN

cups-genppd genera archivos PPD de Gutenprint para usar con CUPS. El comportamiento predeterminado es generar archivos PPD para todos los modelos de impresora que soporta la biblioteca de controladores de impresora Gutenprint. Puede restringir los modelos listando los nombres de los controladores o los nombres completos de las impresoras para las que desea generar archivos PPD después de cualquier opción. Adicionalmente, los archivos PPD pueden ser localizados, es decir, traducidos, para usar su idioma nativo en lugar del inglés estadounidense. Existen comandos para averiguar qué modelos de impresora e idiomas son compatibles.

EJEMPLOS

cups-genppd -v bjc-6200 'Epson Stylus Photo 1280' 'HP DeskJet 850C'
genera verbosamente tres archivos PPD, listando el nombre del controlador en el primer caso y el nombre completo en el segundo.
LANG=de_DE genppd -p ppd -c /usr/share/locale
genera PPDs para todos los modelos disponibles, en el directorio ppd usando los datos de localización encontrados en /usr/share/locale. El idioma a usar se toma del entorno (de_DE).
cups-genppd -L -c /usr/local/share/locale
lista los idiomas disponibles usando los datos de localización encontrados en /usr/local/share/locale.
cups-genppd -M -v
lista los modelos de impresora disponibles, con descripciones detalladas del modelo

COMANDOS

-h
muestra un mensaje de ayuda
-L
lista las traducciones disponibles (catálogos de mensajes). Si se usa una localización para la que no hay una traducción correspondiente, se utilizará el inglés estadounidense.
-M
lista los modelos de impresora disponibles. Por defecto, solo se listan los nombres de los controladores; si se usa el modo detallado, también se imprimirá el nombre completo del modelo
-V
muestra información de la versión y valores predeterminados
El comportamiento predeterminado es generar PPDs si no se proporciona ningún comando.

OPCIONES

-c localedir
usa localedir como directorio base para los datos de localización
-l locale
genera PPDs traducidos con mensajes para locale. Ten en cuenta que locale **debe** ser una localización como muestra locale -a. Por ejemplo, la traducción de es utilizada por la localización de_DE; de solo no funcionará.
-p prefijo
genera PPDs en el directorio prefijo. Los directorios **no** se crean de forma recursiva.
-q
Modo silencioso.
-v
Modo detallado.
modelos
una lista de modelos de impresora, ya sea el nombre del controlador o el nombre completo entre comillas.
