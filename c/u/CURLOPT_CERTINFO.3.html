CURLOPT_CERTINFO(3)

Paquete: curl

Licencias: MIT

CURLOPT_CERTINFO(3) Manual de funciones de la biblioteca CURLOPT_CERTINFO(3)

NOMBRE

CURLOPT_CERTINFO - solicitar información del certificado SSL

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CERTINFO, long certinfo);

DESCRIPCIÓN

Pase un valor largo establecido en 1 para habilitar el recolector de información de la cadena de certificados de libcurl. Con esto habilitado, libcurl extrae mucha información y datos sobre los certificados en la cadena de certificados utilizada en la conexión SSL. Estos datos pueden recuperarse después de una transferencia utilizando curl_easy_getinfo(3) y su opción CURLINFO_CERTINFO(3).

POR OMISIÓN

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL, Schannel y rustls

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://www.example.com/");
    /* conectar a cualquier sitio HTTPS, confiable o no */
    curl_easy_setopt(curl, CURLOPT_SSL_VERIFYPEER, 0L);
    curl_easy_setopt(curl, CURLOPT_SSL_VERIFYHOST, 0L);
    curl_easy_setopt(curl, CURLOPT_CERTINFO, 1L);
    res = curl_easy_perform(curl);
    if(!res) {
      struct curl_certinfo *ci;
      res = curl_easy_getinfo(curl, CURLINFO_CERTINFO, &ci);
      if(!res) {
        int i;
        printf("%d certificados!\n", ci->num_of_certs);
        for(i = 0; i < ci->num_of_certs; i++) {
          struct curl_slist *slist;
          for(slist = ci->certinfo[i]; slist; slist = slist->next)
            printf("%s\n", slist->data);
        }
      }
    }
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Soporte de Schannel agregado en 7.50.0. Soporte de mbedTLS agregado en 8.9.0.

DISPONIBILIDAD

Agregado en curl 7.19.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
