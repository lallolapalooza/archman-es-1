CURLOPT_COOKIELIST(3)

Paquete: curl

Licencias: MIT

CURLOPT_COOKIELIST(3) Manual de funciones de la biblioteca CURLOPT_COOKIELIST(3)

NOMBRE

CURLOPT_COOKIELIST - añadir o manipular cookies almacenadas en memoria

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_COOKIELIST,
                          char *cookie);

DESCRIPCIÓN

Pasa un puntero a un carácter a una cadena de cookie.

Dicha cookie puede ser una línea única en formato Netscape / Mozilla o simplemente en formato de encabezado HTTP normal (formato Set-Cookie:). Esta opción también habilita el motor de cookies. Esto añade esa cookie individual al almacén de cookies interno.

Desaconsejamos firmemente cargar cookies desde un archivo de encabezados HTTP, ya que es un formato de intercambio de datos inferior.

Tenga cuidado si está utilizando esta opción y pueden ocurrir múltiples transferencias. Si utiliza el formato Set-Cookie y la cadena no especifica un dominio, la cookie se envía para cualquier dominio (incluso después de seguir las redirecciones) y no puede ser modificada por una cookie establecida por el servidor. Si un servidor establece una cookie con el mismo nombre (o quizás usted ha importado una), entonces ambas se envían en transferencias futuras a ese servidor, lo que probablemente no era lo que pretendía. Para abordar estos problemas, establezca un dominio en Set-Cookie (esto incluye subdominios) o, mucho mejor: utilice el formato de archivo Netscape.

Adicionalmente, hay comandos disponibles que realizan acciones si pasa estas cadenas exactas:

ALL
borra todas las cookies almacenadas en memoria
SESS
borra todas las cookies de sesión almacenadas en memoria
FLUSH
escribe todas las cookies conocidas en el archivo especificado por CURLOPT_COOKIEJAR(3)
RELOAD
carga todas las cookies desde los archivos especificados por CURLOPT_COOKIEFILE(3)

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

/* una importación en línea de una cookie en formato Netscape. */
#define SEP  "\t"  /* El tabulador separa los campos */
int main(void)
{
  const char *my_cookie =
    "example.com"    /* Nombre del host */
    SEP "FALSE"      /* Incluir subdominios */
    SEP "/"          /* Ruta */
    SEP "FALSE"      /* Seguro */
    SEP "0"          /* Caducidad en formato de tiempo epoch. 0 == Sesión */
    SEP "foo"        /* Nombre */
    SEP "bar";       /* Valor */
  CURL *curl = curl_easy_init();
  if(curl) {
    /* my_cookie se importa inmediatamente a través de CURLOPT_COOKIELIST. */
    curl_easy_setopt(curl, CURLOPT_COOKIELIST, my_cookie);
    /* La lista de cookies en cookies.txt no se importará hasta justo
       antes de que se realice una transferencia. Las cookies en la lista que
       tienen el mismo nombre de host, ruta y nombre que en my_cookie se omiten.
       Esto se debe a que libcurl ya ha importado my_cookie y se considera
       una cookie "viva". Una cookie viva no es reemplazada por una leída
       de un archivo.
    */
    curl_easy_setopt(curl, CURLOPT_COOKIEFILE, "cookies.txt");  /* importar */
    /* Las cookies se exportan después de que se llama a curl_easy_cleanup.
       El servidor puede haber añadido, eliminado o modificado cookies para
       entonces. Las cookies que se omitieron en la importación no se exportan.
    */
    curl_easy_setopt(curl, CURLOPT_COOKIEJAR, "cookies.txt");  /* exportar */
    curl_easy_perform(curl);  /* cookies importadas desde cookies.txt */
    curl_easy_cleanup(curl);  /* cookies exportadas a cookies.txt */
  }
}

Formato del archivo de cookies

El formato del archivo de cookies y los conceptos generales de cookies en curl se describen en línea aquí: https://curl.se/docs/http-cookies.html

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
