CURLOPT_ALTSVC_CTRL(3)

Paquete: curl

Licencias: MIT

CURLOPT_ALTSVC_CTRL(3) Manual de funciones de la biblioteca CURLOPT_ALTSVC_CTRL(3)

NOMBRE

CURLOPT_ALTSVC_CTRL - controla el comportamiento de alt-svc

SINOPSIS

#include <curl/curl.h>
#define CURLALTSVC_READONLYFILE (1L<<2)
#define CURLALTSVC_H1           (1L<<3)
#define CURLALTSVC_H2           (1L<<4)
#define CURLALTSVC_H3           (1L<<5)
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ALTSVC_CTRL, long bitmask);

DESCRIPCIÓN

Rellena el bitmask largo con el conjunto correcto de características para instruir a libcurl sobre cómo manejar Alt-Svc para las transferencias que utilizan este manejador.

libcurl solo acepta encabezados Alt-Svc sobre HTTPS. También solo completa una solicitud a un origen alternativo si dicho origen está alojado correctamente sobre HTTPS. Estos requisitos existen para asegurar que tanto el origen como el destino sean legítimos.

Los servicios alternativos solo se utilizan al configurar nuevas conexiones. Si existe una conexión existente al host en el grupo de conexiones, se prefiere esa.

Si se establece CURLOPT_ALTSVC(3), CURLOPT_ALTSVC_CTRL(3) recibe un valor predeterminado que corresponde a CURLALTSVC_H1 | CURLALTSVC_H2 | CURLALTSVC_H3; los bits de HTTP/2 y HTTP/3 solo se establecen si libcurl se compiló con soporte para esas versiones.

Establecer cualquier bit habilita el motor alt-svc.

CURLALTSVC_READONLYFILE
No escriba la caché de alt-svc de vuelta al archivo especificado con CURLOPT_ALTSVC(3), incluso si se actualiza. Por defecto, un archivo especificado con esa opción se lee y escribe según sea necesario.
CURLALTSVC_H1
Aceptar servicios alternativos ofrecidos sobre HTTP/1.1.
CURLALTSVC_H2
Aceptar servicios alternativos ofrecidos sobre HTTP/2. Esto solo se usa si libcurl también se compiló para admitir realmente HTTP/2; de lo contrario, este bit se ignora.
CURLALTSVC_H3
Aceptar servicios alternativos ofrecidos sobre HTTP/3. Esto solo se usa si libcurl también se compiló para admitir realmente HTTP/3; de lo contrario, este bit se ignora.

PREDETERMINADO

0 - El manejo de Alt-Svc está deshabilitado

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_ALTSVC_CTRL, CURLALTSVC_H1);
    curl_easy_setopt(curl, CURLOPT_ALTSVC, "altsvc-cache.txt");
    curl_easy_perform(curl);
  }
}

HISTORIA

Las macros CURLALTSVC_* se convirtieron en tipos long en la versión 8.16.0; antes de esta versión, era necesario un cast a long al pasarlas a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.64.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).

VER TAMBIÉN
