CUNCS

D

Propósito

: 
!>
!> CUNCSD calcula la descomposición CS de una matriz unitaria
!> particionada X de M por M:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**H
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 es de P por Q. Las matrices unitarias U1, U2, V1 y V2 son de P por P,
!> (M-P) por (M-P), Q por Q y (M-Q) por (M-Q), respectivamente. C y S son
!> matrices diagonales no negativas de R por R que satisfacen C^2 + S^2 = I, en
!> la que R = MIN(P,M-P,Q,M-Q).
!
>

Parámetro

s
JOBU1 
!>          JOBU1 es de tipo CHARACTER
!>          = 'Y':      se calcula U1;
!>          en otro caso:  no se calcula U1.
!
>

JOBU

2 
!>          JOBU2 es de tipo CHARACTER
!>          = 'Y':      se calcula U2;
!>          en otro caso:  no se calcula U2.
!
>

JOBV1

T 
!>          JOBV1T es de tipo CHARACTER
!>          = 'Y':      se calcula V1T;
!>          en otro caso:  no se calcula V1T.
!
>

JOBV2

T 
!>          JOBV2T es de tipo CHARACTER
!>          = 'Y':      se calcula V2T;
!>          en otro caso:  no se calcula V2T.
!
>

TRAN

S 
!>          TRANS es de tipo CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden
!>                      de filas;
!>          en otro caso:  X, U1, U2, V1T y V2T se almacenan en orden
!>                      de columnas.
!
>

SIGN

S 
!>          SIGNS es de tipo CHARACTER
!>          = 'O':      el bloque inferior izquierdo se hace no positivo (la
!>                       convención);
!>          en otro caso:  el bloque superior derecho se hace no positivo (la
!>                       convención).
!
>

M 
!>          M es de tipo INTEGER
!>          El número de filas y columnas en X.
!
>

P 
!>          P es de tipo INTEGER
!>          El número de filas en X11 y X12. 0 <= P <= M.
!
>

Q 
!>          Q es de tipo INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <= M.
!
>

X1

1 
!>          X11 es un arreglo COMPLEX, dimensión (LDX11,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!
>

LDX1

1 
!>          LDX11 es de tipo INTEGER
!>          La dimensión principal de X11. LDX11 >= MAX(1,P).
!
>

X1

2 
!>          X12 es un arreglo COMPLEX, dimensión (LDX12,M-Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!
>

LDX1

2 
!>          LDX12 es de tipo INTEGER
!>          La dimensión principal de X12. LDX12 >= MAX(1,P).
!
>

X2

1 
!>          X21 es un arreglo COMPLEX, dimensión (LDX21,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!
>

LDX2

1 
!>          LDX21 es de tipo INTEGER
!>          La dimensión principal de X11. LDX21 >= MAX(1,M-P).
!
>

X2

2 
!>          X22 es un arreglo COMPLEX, dimensión (LDX22,M-Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!
>

LDX2

2 
!>          LDX22 es de tipo INTEGER
!>          La dimensión principal de X11. LDX22 >= MAX(1,M-P).
!
>

THET

A 
!>          THETA es un arreglo REAL, dimensión (R), en la que R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) y
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!
>

U

1 
!>          U1 es un arreglo COMPLEX, dimensión (LDU1,P)
!>          Si JOBU1 = 'Y', U1 contiene la matriz unitaria U1 de P por P.
!
>

LDU

1 
!>          LDU1 es de tipo INTEGER
!>          La dimensión principal de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!
>

U

2 
!>          U2 es un arreglo COMPLEX, dimensión (LDU2,M-P)
!>          Si JOBU2 = 'Y', U2 contiene la matriz unitaria U2 de (M-P) por (M-P).
!
>

LDU

2 
!>          LDU2 es de tipo INTEGER
!>          La dimensión principal de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!
>

V1

T 
!>          V1T es un arreglo COMPLEX, dimensión (LDV1T,Q)
!>          Si JOBV1T = 'Y', V1T contiene la matriz unitaria V1**H de Q por Q.
!
>

LDV1

T 
!>          LDV1T es de tipo INTEGER
!>          La dimensión principal de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!
>

V2

T 
!>          V2T es un arreglo COMPLEX, dimensión (LDV2T,M-Q)
!>          Si JOBV2T = 'Y', V2T contiene la matriz unitaria V2**H de (M-Q) por (M-Q).
!
>

LDV2

T 
!>          LDV2T es de tipo INTEGER
!>          La dimensión principal de V2T. Si JOBV2T = 'Y', LDV2T >=
!>          MAX(1,M-Q).
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es de tipo INTEGER
!>          La dimensión del arreglo WORK.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo de trabajo, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión MAX(1,LRWORK)
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>          Si INFO > 0 en la salida, RWORK(2:R) contiene los valores PHI(1),
!>          ..., PHI(R)-1) que, junto con THETA(1), ..., THETA(R),
!>          definen la matriz en forma de bloques bidiagonales intermedios
!>          que queda después de la no convergencia. INFO especifica el número
!>          de PHI no nulos.
!
>

LRWOR

K 
!>          LRWORK es INTEGER
!>          La dimensión del arreglo RWORK.
!>
!>          Si LRWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo RWORK, devuelve
!>          este valor como la primera entrada del arreglo de trabajo, y no se emite
!>          ningún mensaje de error relacionado con LRWORK por parte de XERBLA.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (M-MIN(P,M-P,Q,M-Q))
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  CBBCSD no convergió. Véase la descripción de RWORK
!>                arriba para más detalles.
!
>
