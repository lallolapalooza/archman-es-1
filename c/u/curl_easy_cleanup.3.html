curl_easy_cleanup(3)

Paquete: curl

Licencias: MIT

curl_easy_cleanup(3) Manual de Funciones de Biblioteca curl_easy_cleanup(3)

NOMBRE

curl_easy_cleanup - liberar un manejador easy

SINOPSIS

#include <curl/curl.h>
void curl_easy_cleanup(CURL *handle);

DESCRIPCIÓN

Esta función es lo opuesto a curl_easy_init(3). Cierra y libera todos los recursos previamente asociados con este manejador easy.

Esta llamada cierra todas las conexiones que este manejador ha utilizado y posiblemente ha mantenido abiertas hasta ahora, a menos que el manejador easy se haya adjuntado a un manejador multi mientras realizaba las transferencias. No llame a esta función si tiene la intención de transferir más archivos; reutilizar manejadores es clave para un buen rendimiento con libcurl.

Ocasionalmente, su función de devolución de llamada de progreso o de cabecera puede ser llamada desde dentro de curl_easy_cleanup(3) (si se estableció previamente para el manejador usando curl_easy_setopt(3)). Por ejemplo, si libcurl decide cerrar la conexión y el protocolo es de un tipo que requiere una secuencia de comando/respuesta antes de la desconexión. Ejemplos de tales protocolos son FTP, POP3 e IMAP.

Cualquier uso del handle easy después de que esta función haya sido llamada y haya regresado, es ilegal.

Para cerrar un manejador easy que se ha utilizado con la interfaz multi, asegúrese de llamar primero a curl_multi_remove_handle(3) para eliminarlo del manejador multi antes de cerrarlo.

Pasar un puntero NULL en handle hace que esta función regrese inmediatamente sin ninguna acción.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(res)
      printf("error: %s\n", curl_easy_strerror(res));
    curl_easy_cleanup(curl);
  }
}

Añadido en curl 7.1
