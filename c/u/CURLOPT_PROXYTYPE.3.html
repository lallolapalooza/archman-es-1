CURLOPT_PROXYTYPE(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXYTYPE(3) Manual de Funciones de Librería CURLOPT_PROXYTYPE(3)

NOMBRE

CURLOPT_PROXYTYPE - tipo de protocolo del proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYTYPE, long type);

DESCRIPCIÓN

Pase uno de los siguientes valores para establecer el tipo de proxy.

CURLPROXY_HTTP
Proxy HTTP. Por defecto.
CURLPROXY_HTTPS
Proxy HTTPS usando HTTP/1. (Añadido en 7.52.0 para OpenSSL y GnuTLS. Desde 7.87.0, también funciona para mbedTLS, Rustls, Schannel y wolfSSL.)
CURLPROXY_HTTPS2
Proxy HTTPS e intento de hablar HTTP/2 sobre él. (Añadido en 8.1.0)
CURLPROXY_HTTP_1_0
Proxy HTTP 1.0. Esto es similar a CURLPROXY_HTTP excepto que utiliza HTTP/1.0 para cualquier conexión de tipo túnel (CONNECT). No cambia la versión HTTP de las peticiones HTTP reales, controlada por CURLOPT_HTTP_VERSION(3).
CURLPROXY_SOCKS4
Proxy SOCKS4.
CURLPROXY_SOCKS4A
Proxy SOCKS4a. El proxy resuelve el nombre de host de la URL.
CURLPROXY_SOCKS5
Proxy SOCKS5.
CURLPROXY_SOCKS5_HOSTNAME
Proxy SOCKS5. El proxy resuelve el nombre de host de la URL.

A menudo es más conveniente especificar el tipo de proxy con la parte del esquema de la cadena de CURLOPT_PROXY(3).

POR DEFECTO

CURLPROXY_HTTP

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "local.example.com:1080");
    /* establecer el tipo de proxy */
    curl_easy_setopt(curl, CURLOPT_PROXYTYPE, CURLPROXY_SOCKS5);
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Los enums CURLPROXY_* se convirtieron en tipos long en 8.16.0; antes de esta versión, era necesario hacer una conversión (cast) a long al pasarlos a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.10

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien; un valor distinto de cero indica que ocurrió un error; véase libcurl-errors(3).
