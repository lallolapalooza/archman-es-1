CURLOPT_STREAM_DEPENDS(3)

Paquete: curl

Licencias: MIT

CURLOPT_STREAM_DEPENDS(3) Manual de funciones de biblioteca CURLOPT_STREAM_DEPENDS(3)

NOMBRE

CURLOPT_STREAM_DEPENDS - el flujo en el que se basa esta transferencia

SINAPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_STREAM_DEPENDS,
                          CURL *dephandle);

DESCRIPCIÓN

Pase un puntero CURL en dephandle para identificar el flujo dentro de la misma conexión en la que se basa este flujo. Esta opción borra el bit exclusivo y es mutuamente excluyente con la opción CURLOPT_STREAM_DEPENDS_E(3).

La especificación dice: "Incluir una dependencia expresa una preferencia para asignar recursos al flujo identificado en lugar de al flujo dependiente".

Esta opción se puede configurar durante la transferencia.

dephandle no debe ser el mismo que handle, ya que esto hace que la función devuelva un error. Debe ser otro manejador fácil (easy handle) y también debe ser el manejador de una transferencia que se va a enviar a través de la misma conexión HTTP/2 para que esta opción tenga un efecto real.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad solo afecta a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init(); /* un segundo manejador */
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/one");
    /* el segundo depende del primero */
    curl_easy_setopt(curl2, CURLOPT_URL, "https://example.com/two");
    curl_easy_setopt(curl2, CURLOPT_STREAM_DEPENDS, curl);
    /* luego agregue ambos a un manejador múltiple y transfiéralos */
  }
}

DISPONIBILIDAD

Añadido en curl 7.46.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
