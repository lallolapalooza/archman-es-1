NOMBRE

cups-browsed - Un demonio para buscar transmisiones Bonjour de impresoras CUPS compartidas y remotas

SINOPSIS

cups-browsed [-v | -d | --debug] [-c archivo-config]
[-o opcion=valor] [-o 'línea-archivo-config'] ...
[--autoshutdown=modo] [--autoshutdown-timeout=tiempo]
[-h | --help | --version]

DESCRIPCIÓN

cups-browsed tiene dos funciones conmutables independientemente:

1.
Buscar transmisiones DNS-SD de impresoras remotas y crear/eliminar colas CUPS locales que apunten a estas impresoras.
2.
Encontrar impresoras compartidas en servidores CUPS dados y crear colas CUPS locales que apunten a ellas.

cups-browsed se puede ejecutar de forma permanente (desde el arranque del sistema hasta el apagado) o bajo demanda (por ejemplo, para ahorrar recursos en dispositivos móviles). Para ejecutarlo bajo demanda, se puede activar una función de apagado automático para que cups-browsed termine cuando ya no tenga colas que administrar.

OPCIONES

-v, -d, --debug
Modo de depuración, registro detallado en stderr
-l, --logfile
Registro de depuración en el archivo /var/log/cups/cups-browsed_log.
-c archivo-config
Utiliza el archivo de configuración alternativo archivo-config en lugar del estándar.
-o opcion=valor, -o 'línea-archivo-config'
Proporciona opciones de configuración a través de la línea de comandos. Puedes proporcionar cualquier línea que también podría incluirse en el archivo de configuración, pero ten en cuenta que debido a los espacios, la línea debe ir entre comillas, o para un simple par clave/valor, el espacio entre clave y valor puede ser reemplazado por '='. Si la configuración proporcionada en la línea de comandos contradice la del archivo de configuración, se utilizará la del archivo de configuración.
--autoshutdown=modo
Modo de apagado automático, modo es off para no apagar automáticamente, on para que el apagado automático esté activo, y avahi para control por el demonio avahi que se ejecuta bajo demanda, desactivando el apagado automático mientras el demonio avahi está presente y activándolo cuando el demonio avahi se apaga.
--autoshutdown-on=inactivity-type
Lo que cups-browsed considera inactividad para el apagado automático. inactivity-type configurado a no-queues (el predeterminado) significa que se inicia el apagado automático si ya no hay colas generadas por cups-browsed, no-jobs significa que el apagado automático se iniciará si todas las colas generadas por cups-browsed están sin trabajos.
--autoshutdown-timeout=tiempo
tiempo indica después de cuántos segundos cups-browsed se apagará si ya no tiene colas locales configuradas para ninguna impresora remota descubierta o trabajos en ellas. El valor predeterminado es 30 segundos. 0 significa apagado inmediato.
-h, --help, --version
Muestra la información de uso y versión y no inicia el demonio.

ARCHIVOS

/etc/cups/cups-browsed.conf

SEÑALES

SIGINT, SIGTERM: cups-browsed se apagará.

SIGUSR1: Cambia cups-browsed a modo permanente (sin apagado automático).

SIGUSR2: Cambia cups-browsed a modo de apagado automático.
