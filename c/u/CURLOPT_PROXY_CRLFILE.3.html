CURLOPT_PROXY_CRLFILE(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_CRLFILE(3) Manual de funciones de la biblioteca CURLOPT_PROXY_CRLFILE(3)

NOMBRE

CURLOPT_PROXY_CRLFILE - Archivo de Lista de Revocación de Certificados del proxy HTTPS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CRLFILE, char *file);

DESCRIPCIÓN

Esta opción es para conectarse a un proxy HTTPS, no a un servidor HTTPS.

Pase un puntero a char a una cadena terminada en nulo que nombre un archivo con la concatenación de CRL (en formato PEM) a utilizar en la validación del certificado que ocurre durante el intercambio SSL.

Cuando curl está compilado para usar GnuTLS, no hay forma de influir en el uso de CRL pasado para ayudar en el proceso de verificación. Cuando libcurl está compilado con soporte OpenSSL, se establecen tanto X509_V_FLAG_CRL_CHECK como X509_V_FLAG_CRL_CHECK_ALL, requiriendo la comprobación de CRL contra todos los elementos de la cadena de certificados si se pasa un archivo CRL.

Esta opción solo tiene sentido cuando se usa en combinación con la opción CURLOPT_PROXY_SSL_VERIFYPEER(3).

Se define un código de error específico (CURLE_SSL_CRL_BADFILE) con la opción. Se devuelve cuando el intercambio SSL falla porque el archivo CRL no se puede cargar. Un fallo en la verificación del certificado debido a información de revocación encontrada en el CRL no activa este error específico.

La aplicación no tiene que mantener la cadena en memoria después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida reemplace a las anteriores. Establézcala a NULL para deshabilitar su uso nuevamente.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL y mbedTLS

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:80");
    curl_easy_setopt(curl, CURLOPT_PROXY_CRLFILE, "/etc/certs/crl.pem");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_PROXY_SSL_VERIFYHOST(3), CURLOPT_PROXY_SSL_VERIFYPEER(3), CURLOPT_SSL_VERIFYHOST(3), CURLOPT_SSL_VERIFYPEER(3)
