curl_multi_add_handle(3)

Paquete: curl

Licencias: MIT

curl_multi_add_handle(3) Manual de funciones de biblioteca curl_multi_add_handle(3)

NOMBRE

curl_multi_add_handle - añadir un manejador easy a una sesión multi

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_add_handle(CURLM *multi_handle, CURL *easy_handle);

DESCRIPCIÓN

Añade el manejador easy al manejador multi.

Mientras un manejador easy esté añadido a una pila multi, no puedes y no debes usar curl_easy_perform(3) en ese manejador. Después de haber eliminado el manejador easy de la pila multi de nuevo, es perfectamente aceptable usarlo de nuevo con la interfaz easy.

Si el manejador easy no está configurado para usar una caché compartida (CURLOPT_SHARE(3)), se configura para usar una caché DNS que se comparte entre todos los manejadores easy dentro del manejador multi cuando se llama a curl_multi_add_handle(3).

Cuando una interfaz easy se añade a un manejador multi, se configura para usar una caché de conexión compartida propiedad del manejador multi. Eliminar y añadir nuevos manejadores easy no afecta al grupo de conexiones ni a la capacidad de reutilizar conexiones.

Si tienes CURLMOPT_TIMERFUNCTION(3) configurado en el manejador multi (como deberías si estás trabajando basado en eventos con curl_multi_socket_action(3) y similares), esa devolución de llamada se llama desde dentro de esta función para solicitar un temporizador actualizado para que tu bucle de eventos principal obtenga la actividad en este manejador para comenzar.

El manejador easy permanece añadido al manejador multi hasta que lo elimines de nuevo con curl_multi_remove_handle(3) - incluso cuando una transferencia con ese manejador easy específico ha completado.

Debes eliminar el manejador easy de la pila multi antes de terminar primero el manejador easy y luego el manejador multi:

1 - curl_multi_remove_handle(3)

2 - curl_easy_cleanup(3)

3 - curl_multi_cleanup(3)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

int main(void)
{
  /* inicializar una pila multi */
  CURLM *multi = curl_multi_init();
  /* crear dos manejadores easy */
  CURL *http_handle = curl_easy_init();
  CURL *http_handle2 = curl_easy_init();
  /* añadir transferencias individuales */
  curl_multi_add_handle(multi, http_handle);
  curl_multi_add_handle(multi, http_handle2);
}

DISPONIBILIDAD

Añadido en curl 7.9.6

VALOR DE RETORNO

Esta función devuelve un CURLMcode indicando éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
