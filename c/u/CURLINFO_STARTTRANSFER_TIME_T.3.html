CURLINFO_STARTTRANSFER_TIME_T(3)

Paquete: curl

Licencias: MIT

CURLINFO_STARTTRANSFER_TIME_T(3) Manual de funciones de biblioteca CURLINFO_STARTTRANSFER_TIME_T(3)

NOMBRE

CURLINFO_STARTTRANSFER_TIME_T - obtener el tiempo hasta que se recibe el primer byte

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_STARTTRANSFER_TIME_T,
                           curl_off_t *timep);

DESCRIPCIÓN

Pase un puntero a un curl_off_t para recibir el tiempo, en microsegundos, que tardó desde el inicio hasta que libcurl recibió el primer byte. Esto incluye CURLINFO_PRETRANSFER_TIME_T(3) y también el tiempo que necesita el servidor para calcular el resultado.

Cuando se sigue una redirección, se suman los tiempos de cada solicitud.

Consulte también la descripción general de TIMES en la página del manual de curl_easy_getinfo(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_off_t start;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_STARTTRANSFER_TIME_T, &start);
      if(CURLE_OK == res) {
        printf("Tiempo: %" CURL_FORMAT_CURL_OFF_T ".%06ld", start / 1000000,
               (long)(start % 1000000));
      }
    }
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.61.0

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue correcto; un valor distinto de cero indica que ocurrió un error. Consulte libcurl-errors(3).
