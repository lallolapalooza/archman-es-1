CURLMOPT_SOCKETFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLMOPT_SOCKETFUNCTION(3) Manual de funciones de biblioteca CURLMOPT_SOCKETFUNCTION(3)

NOMBRE

CURLMOPT_SOCKETFUNCTION - callback informado sobre qué esperar

SINOPSIS

#include <curl/curl.h>
int socket_callback(CURL *easy,      /* manejador fácil */
                    curl_socket_t s, /* socket */
                    int what,        /* describe el socket */
                    void *clientp,   /* puntero privado de callback */
                    void *socketp);  /* puntero privado de socket */
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_SOCKETFUNCTION, socket_callback);

DESCRIPCIÓN

Pase un puntero a su función de callback, que debe coincidir con el prototipo mostrado arriba.

Cuando se llama a la función curl_multi_socket_action(3), utiliza este callback para informar a la aplicación sobre las actualizaciones en el estado del socket (descriptor de archivo) realizando ninguna, una o múltiples llamadas a la función socket_callback. La función de callback recibe actualizaciones de estado con los cambios desde la última vez que se llamó al callback. Si el puntero de callback proporcionado se establece en NULL, no se llama a ningún callback.

libcurl espera entonces que la aplicación supervise los sockets para las actividades específicas y le indique a libcurl nuevamente cuándo ocurre algo en uno de ellos. Indique a libcurl llamando a curl_multi_socket_action(3).

Este callback puede ser invocado en cualquier momento al interactuar con libcurl. Incluso puede ocurrir después de que todas las transferencias hayan terminado y es *probable* que ocurra *durante* una llamada a curl_multi_cleanup(3) cuando se cierran las conexiones en caché.

ARGUMENTOS DE CALLBACK

easy identifica la transferencia específica a la que se refiere esta actualización. Dado que este callback gestiona un manejador múltiple completo, una aplicación no debe hacer suposiciones sobre qué manejador particular se pasa aquí. Incluso podría ser un manejador fácil interno que la aplicación no añadió por sí misma.

s es el socket específico al que se refiere esta invocación de función. Si el argumento what no es CURL_POLL_REMOVE, entonces contiene información sobre qué actividad en este socket se supone que debe supervisar la aplicación. Llamadas posteriores a este callback pueden actualizar los bits de what para un socket que ya está siendo supervisado.

El callback del socket debe devolver 0 en caso de éxito y -1 en caso de error. Si este callback devuelve un error, *todas* las transferencias en curso en este manejador múltiple se abortan y fallan.

clientp se establece con CURLMOPT_SOCKETDATA(3).

socketp se establece con curl_multi_assign(3) o NULL.

El parámetro what informa al callback sobre el estado del socket dado. Puede contener uno de los siguientes valores:

CURL_POLL_IN
Esperar datos entrantes. Para que el socket sea legible.
CURL_POLL_OUT
Esperar datos salientes. Para que el socket sea escribible.
CURL_POLL_INOUT
Esperar datos entrantes y salientes. Para que el socket sea legible o escribible.
CURL_POLL_REMOVE
El socket/descriptor de archivo especificado ya no es utilizado por libcurl para ninguna transferencia activa. Podría ser añadido de nuevo pronto.

PREDETERMINADO

NULL (sin callback)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

struct priv {
  void *ours;
};
static int sock_cb(CURL *e, curl_socket_t s, int what, void *cbp, void *sockp)
{
  struct priv *p = sockp;
  printf("our ptr: %p\n", p->ours);
  if(what == CURL_POLL_REMOVE) {
    /* eliminar el socket de nuestra colección */
  }
  if(what & CURL_POLL_IN) {
    /* esperar lectura en este socket */
  }
  if(what & CURL_POLL_OUT) {
    /* esperar escritura en este socket */
  }
  return 0;
}
int main(void)
{
  struct priv setup;
  CURLM *multi = curl_multi_init();
  /* ... usar callback de socket y puntero personalizado */
  curl_multi_setopt(multi, CURLMOPT_SOCKETFUNCTION, sock_cb);
  curl_multi_setopt(multi, CURLMOPT_SOCKETDATA, &setup);
}

DISPONIBILIDAD

Añadido en curl 7.15.4

VALOR DE RETORNO

Devuelve CURLM_OK.
