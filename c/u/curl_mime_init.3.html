curl_mime_init(3)

Paquete: curl

Licencias: MIT

curl_mime_init(3) Manual de funciones de la biblioteca curl_mime_init(3)

NOMBRE

curl_mime_init - crear un manejador mime

SINOPSIS

#include <curl/curl.h>
curl_mime *curl_mime_init(CURL *easy_handle);

DESCRIPCIÓN

curl_mime_init(3) crea un manejador para una nueva estructura mime vacía. Esta estructura mime puede ser rellenada posteriormente usando la API mime, luego adjuntada a algún manejador easy usando la opción CURLOPT_MIMEPOST(3) dentro de una llamada a curl_easy_setopt(3) o añadida como un multipart en la parte de otro manejador mime usando curl_mime_subparts(3).

easy_handle se usa para la aleatorización de separadores de partes y para la notificación de errores. Desde la versión 7.87.0, no necesita ser el manejador de destino final.

Usar un manejador mime es la forma recomendada para enviar un formulario HTTP, formatear y enviar un correo electrónico multipart con SMTP o subir dicho correo a un servidor IMAP.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  CURL *easy = curl_easy_init();
  curl_mime *mime;
  curl_mimepart *part;
  /* Construir un formulario HTTP con un único campo llamado "data", */
  mime = curl_mime_init(easy);
  part = curl_mime_addpart(mime);
  curl_mime_data(part, "Este es el dato del campo", CURL_ZERO_TERMINATED);
  curl_mime_name(part, "data");
  /* Enviar y publicar. */
  curl_easy_setopt(easy, CURLOPT_MIMEPOST, mime);
  curl_easy_setopt(easy, CURLOPT_URL, "https://example.com");
  curl_easy_perform(easy);
  /* Limpieza. */
  curl_easy_cleanup(easy);
  curl_mime_free(mime);
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Un manejador de estructura mime, o NULL en caso de fallo.

VER TAMBIÉN

CURLOPT_MIMEPOST(3), curl_mime_addpart(3), curl_mime_free(3), curl_mime_subparts(3)
