OPCIONES ESPECÍFICAS DEL WIDGET • -releasefocus Si esta opción está activada, los widgets dentro de este Contenedor serán parte del orden de enfoque del widget padre. Esto significa que cuando este Contenedor obtiene el enfoque, su primer widget será enfocado. Cuando el enfoque abandona el último widget dentro del Contenedor, devolverá el enfoque al padre en lugar de ciclar de vuelta al primer widget en este Contenedor. Esta opción es útil para crear una subclase empaquetada con widgets de uso común, facilitando la reutilización. MÉTODOS new ( ) Crea una nueva instancia de la clase Curses::UI::Container. add ( ID, CLASS, OPTIONS ) Este es el método principal para esta clase. Usando este método es fácil añadir widgets al contenedor. El ID es un identificador que desea usar para el widget añadido. Puede ser cualquier cadena que desee. Si no necesita un ID, también puede usar un valor indefinido. El contenedor creará automáticamente un ID para usted. La CLASE es la clase que desea añadir al contenedor. Si CLASE no contiene '::' o CLASE coincide con 'Dialog::...', se le antepondrá 'Curses::UI'. De esta manera no tiene que especificar el nombre completo de la clase para los widgets que están en la jerarquía de Curses::UI. No es necesario llamar a "use CLASE" usted mismo. El
