CURLOPT_DNS_CACHE_TIMEOUT(3)

Paquete: curl

Licencias: MIT

CURLOPT_DNS_CACHE_TIMEOUT(3) Manual de funciones de la biblioteca CURLOPT_DNS_CACHE_TIMEOUT(3)

NOMBRE

CURLOPT_DNS_CACHE_TIMEOUT - tiempo de vida de las entradas de la caché DNS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DNS_CACHE_TIMEOUT, long age);

DESCRIPCIÓN

Pase un long, esto establece el tiempo de espera en segundos. Los resultados de la resolución de nombres se mantienen en memoria y se utilizan durante este número de segundos. Establezca a cero para deshabilitar completamente la caché, o establezca a -1 para que las entradas de la caché permanezcan para siempre. Por defecto, libcurl almacena esta información durante 60 segundos.

Recomendamos a los usuarios que no manipulen esta opción a menos que sea estrictamente necesario. Si lo hace, tenga cuidado con el uso de valores grandes que pueden hacer que el tamaño de la caché crezca significativamente si se utilizan muchos nombres de host diferentes dentro de ese período de tiempo.

Las funciones de resolución de nombres de varias implementaciones de libc no releen la información del servidor de nombres a menos que se les indique explícitamente (por ejemplo, llamando a res_init(3)). Esto puede hacer que libcurl siga utilizando el servidor anterior incluso si DHCP ha actualizado la información del servidor, y esto puede parecer un problema de caché DNS para el usuario casual de la aplicación libcurl.

Las entradas DNS tienen una propiedad "TTL", pero libcurl no la utiliza. Este tiempo de espera de la caché DNS es puramente especulativo de que un nombre se resuelve a la misma dirección durante un corto período de tiempo en el futuro.

libcurl poda entradas de la caché DNS si excede las 30.000 entradas, sin importar el valor de tiempo de espera utilizado. (Añadido en la versión 8.1.0)

Desde curl 8.16.0, las resoluciones de nombres fallidas se almacenan en la caché DNS durante la mitad del período de tiempo de espera establecido.

POR DEFECTO

60

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    /* solo reutilizar direcciones durante un corto período de tiempo */
    curl_easy_setopt(curl, CURLOPT_DNS_CACHE_TIMEOUT, 2L);
    res = curl_easy_perform(curl);
    /* en esta segunda solicitud, la caché no se utilizará si han pasado más de
       dos segundos desde la resolución de nombres anterior */
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.3

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
