curl_multi_info_read(3)

Paquete: curl

Licencias: MIT

curl_multi_info_read(3) Manual de funciones de la biblioteca curl_multi_info_read(3)

NOMBRE

curl_multi_info_read - leer información de la pila múltiple

SINOPSIS

#include <curl/curl.h>
CURLMsg *curl_multi_info_read(CURLM *multi_handle, int *msgs_in_queue);

DESCRIPCIÓN

Pregunta al manejador múltiple si hay algún mensaje de las transferencias individuales. Los mensajes pueden incluir información como un código de error de la transferencia o simplemente el hecho de que una transferencia se ha completado. Se debe escribir más información sobre estos.

Las llamadas repetidas a esta función devuelven una nueva estructura cada vez, hasta que se devuelve NULL como señal de que no hay más que obtener en este momento. El entero al que apunta msgs_in_queue contiene el número de mensajes restantes después de que se llamó a esta función.

Cuando se obtiene un mensaje utilizando esta función, se elimina de la cola interna, por lo que llamar a esta función nuevamente no devuelve el mismo mensaje. En su lugar, devuelve nuevos mensajes en cada invocación hasta que la cola se vacía.

ADVERTENCIA: Los datos a los que apunta el puntero devuelto no sobreviven a la llamada a curl_multi_cleanup(3), curl_multi_remove_handle(3) o curl_easy_cleanup(3).

La estructura CURLMsg es simple y solo contiene información básica. Si se desea información más detallada, el manejador "easy" particular está presente en esa estructura y puede usarse en llamadas posteriores a curl_easy_getinfo(3) (o similares):

 struct CURLMsg {
   CURLMSG msg;       /* qué significa este mensaje */
   CURL *easy_handle; /* el manejador al que se refiere */
   union {
     void *whatever;    /* datos específicos del mensaje */
     CURLcode result;   /* código de retorno para la transferencia */
   } data;
 };

Cuando msg es CURLMSG_DONE, el mensaje identifica una transferencia que ha finalizado, y luego result contiene el código de retorno para el manejador "easy" que acaba de completarse.

En este punto, no hay otros tipos de msg definidos.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  if(curl) {
    struct CURLMsg *m;
    /* llama a curl_multi_perform o curl_multi_socket_action primero, luego itera
       y comprueba si hay alguna transferencia completada */
    do {
      int msgq = 0;
      m = curl_multi_info_read(multi, &msgq);
      if(m && (m->msg == CURLMSG_DONE)) {
        CURL *e = m->easy_handle;
        /* m->data.result contiene el código de error para la transferencia */
        curl_multi_remove_handle(multi, e);
        curl_easy_cleanup(e);
      }
    } while(m);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.6

VALOR DE RETORNO

Un puntero a una estructura rellena, o NULL si falló o se agotaron las estructuras. También escribe el número de mensajes restantes en la cola (después de esta lectura) en el entero al que apunta el segundo argumento.
