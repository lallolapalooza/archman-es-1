NOMBRE

deleteln, wdeleteln, insdelln, winsdelln, insertln, winsertln - eliminar o insertar líneas en una ventana de curses

SINOPSIS

#include <curses.h>
int deleteln(void);
int wdeleteln(WINDOW *win);
int insdelln(int n);
int winsdelln(WINDOW *win, int n);
int insertln(void);
int winsertln(WINDOW *win);

DESCRIPCIÓN

Las rutinas deleteln y wdeleteln eliminan la línea debajo del cursor en la ventana; todas las líneas debajo de la línea actual se mueven hacia arriba una posición. La línea inferior de la ventana se borra. La posición del cursor no cambia.

Las rutinas insdelln y winsdelln, para n positivos, insertan n líneas en la ventana especificada encima de la línea actual. Las n líneas inferiores se pierden. Para n negativos, eliminan n líneas (comenzando por la que está debajo del cursor) y las líneas restantes se mueven hacia arriba. Las n líneas inferiores se borran. La posición actual del cursor permanece igual.

Las rutinas insertln y winsertln insertan una línea en blanco encima de la línea actual y la línea inferior se pierde.

VALOR DE RETORNO

Estas rutinas devuelven el entero ERR en caso de fallo y OK (SVr4 especifica solo "un valor entero distinto de ERR") en caso de éxito.

X/Open no define condiciones de error. En esta implementación, si el parámetro de la ventana es nulo, se devuelve un error.

NOTAS

Tenga en cuenta que todas menos winsdelln pueden ser macros.

Estas rutinas no requieren una función de eliminación o inserción de líneas por hardware en el terminal. De hecho, no utilizarán la eliminación/inserción de líneas por hardware a menos que se haya establecido idlok(..., TRUE) en la ventana actual.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4. El estándar especifica que devuelven ERR en caso de fallo, pero no especifica condiciones de error.
