curl_mime_addpart(3)

Paquete: curl

Licencias: MIT

curl_mime_addpart(3) Manual de funciones de biblioteca curl_mime_addpart(3)

NOMBRE

curl_mime_addpart - añadir una nueva parte vacía a una estructura mime

SINOPSIS

#include <curl/curl.h>
curl_mimepart *curl_mime_addpart(curl_mime *mime);

DESCRIPCIÓN

curl_mime_addpart(3) crea y añade una nueva parte vacía a la estructura mime dada y devuelve un manejador para ella. El manejador de parte devuelto puede ser poblado posteriormente usando funciones de la API mime.

mime es el manejador de la estructura mime en la cual la nueva parte debe ser añadida.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* crear un manejador mime */
    mime = curl_mime_init(curl);
    /* añadir una parte */
    part = curl_mime_addpart(mime);
    /* continuar y establecer el nombre + datos a la parte */
    curl_mime_data(part, "This is the field data", CURL_ZERO_TERMINATED);
    curl_mime_name(part, "data");
  }
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Un manejador de estructura de parte mime, o NULL en caso de fallo.
