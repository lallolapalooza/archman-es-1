curl_mime_encoder(3)

Paquete: curl

Licencias: MIT

curl_mime_encoder(3) Manual de funciones de la biblioteca curl_mime_encoder(3)

NOMBRE

curl_mime_encoder - establece el codificador y la codificación de transferencia de contenido de una parte mime

SINOPSIS

#include <curl/curl.h>
CURLcode curl_mime_encoder(curl_mimepart *part, const char *encoding);

DESCRIPCIÓN

curl_mime_encoder() solicita que el contenido de una parte mime se codifique antes de ser transmitido.

part es el manejador de la parte al que asignar un codificador. encoding es un puntero a un esquema de codificación terminado en nulo. Puede establecerse a NULL para deshabilitar un codificador previamente adjunto a la parte. El almacenamiento del esquema de codificación puede ser reutilizado de forma segura después de que esta función retorne.

Establecer el codificador de una parte varias veces es válido: solo se retiene el valor establecido por la última llamada.

Al renderizar multiparte, el contenido de la parte se codifica según el esquema correspondiente y se añade una cabecera "Content-Transfer-Encoding" a la parte.

Los esquemas de codificación admitidos son:

"binary": los datos se dejan sin cambios, se añade la cabecera.

"8bit": se añade la cabecera, no hay cambio en los datos.

"7bit": los datos no se cambian, pero se comprueba que cada byte sea un valor de 7 bits; si no lo es, se produce un error de lectura.

"base64": Los datos se convierten a codificación base64, luego se dividen en líneas terminadas en CRLF de como máximo 76 caracteres.

"quoted-printable": los datos se codifican en líneas quoted-printable de como máximo 76 caracteres. Dado que el tamaño resultante de los datos finales no se puede determinar antes de leer los datos originales, se deja como desconocido, provocando transferencia fragmentada en HTTP. Por la misma razón, este codificador no puede usarse con IMAP. Este codificador está dirigido a datos de texto que son mayoritariamente ASCII y no debe usarse con otros tipos de datos.

Si los datos originales ya están codificados en dicho esquema, se debe añadir una cabecera Content-Transfer-Encoding personalizada con curl_mime_headers(3) en lugar de establecer un codificador de parte.

La codificación no debe aplicarse a multipartes, por lo tanto, se desaconseja encarecidamente el uso de esta función en una parte con contenido establecido con curl_mime_subparts(3).

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* crear un manejador mime */
    mime = curl_mime_init(curl);
    /* añadir una parte */
    part = curl_mime_addpart(mime);
    /* enviar un archivo */
    curl_mime_filedata(part, "image.png");
    /* codificar los datos del archivo en base64 para la transferencia */
    curl_mime_encoder(part, "base64");
  }
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo está bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el búfer de errores cuando se devuelve un valor distinto de cero.
