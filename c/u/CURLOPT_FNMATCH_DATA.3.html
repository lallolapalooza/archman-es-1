CURLOPT_FNMATCH_DATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_FNMATCH_DATA(3) Manual de funciones de biblioteca CURLOPT_FNMATCH_DATA(3)

NOMBRE

CURLOPT_FNMATCH_DATA - puntero pasado a la función de retorno de llamada fnmatch

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FNMATCH_DATA,
                          void *pointer);

DESCRIPCIÓN

Pasa un puntero que libcurl no modifica y que se pasa como argumento `ptr` a la función CURLOPT_FNMATCH_FUNCTION(3).

VALOR POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

extern int string_match(const char *s1, const char *s2);
struct local_stuff {
  void *custom;
};
static int my_fnmatch(void *clientp,
                      const char *pattern, const char *string)
{
  struct local_stuff *my = clientp;
  printf("my ptr: %p\n", my->custom);
  if(string_match(pattern, string))
    return CURL_FNMATCHFUNC_MATCH;
  else
    return CURL_FNMATCHFUNC_NOMATCH;
}
int main(void)
{
  struct local_stuff local_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://ftp.example.com/file*");
    curl_easy_setopt(curl, CURLOPT_WILDCARDMATCH, 1L);
    curl_easy_setopt(curl, CURLOPT_FNMATCH_FUNCTION, my_fnmatch);
    curl_easy_setopt(curl, CURLOPT_FNMATCH_DATA, &local_data);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.21.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue bien, un valor distinto de cero indica un error; ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_FNMATCH_FUNCTION(3), CURLOPT_WILDCARDMATCH(3)
