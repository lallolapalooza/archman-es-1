curl_pushheader_bynum(3)

Paquete: curl

Licencias: MIT

curl_pushheader_bynum(3) Manual de funciones de biblioteca curl_pushheader_bynum(3)

NOMBRE

curl_pushheader_bynum - obtener una cabecera push por índice

SINOPSIS

#include <curl/curl.h>
char *curl_pushheader_bynum(struct curl_pushheaders *h, size_t num);

DESCRIPCIÓN

Esta es una función que solo es funcional dentro de una devolución de llamada CURLMOPT_PUSHFUNCTION(3). No tiene sentido intentar usarla en otro lugar y no tiene función entonces.

Devuelve el valor para el campo de cabecera en el índice dado num, para la solicitud de server push entrante o NULL. Los datos a los que apunta son liberados por libcurl cuando esta devolución de llamada retorna. El puntero devuelto apunta a una cadena "nombre:valor" que se libera cuando esta devolución de llamada retorna.

PROTOCOLOS

Esta funcionalidad solo afecta a http

EJEMPLO

/* mostrar todas las cabeceras de la solicitud push entrante */
static int push_cb(CURL *parent,
                   CURL *easy,
                   size_t num_headers,
                   struct curl_pushheaders *headers,
                   void *clientp)
{
  int i = 0;
  char *field;
  do {
     field = curl_pushheader_bynum(headers, i);
     if(field)
       fprintf(stderr, "Cabecera Push: %s\n", field);
     i++;
  } while(field);
  return CURL_PUSH_OK; /* permiso concedido */
}
int main(void)
{
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_PUSHFUNCTION, push_cb);
}

DISPONIBILIDAD

Añadido en curl 7.44.0

VALOR DE RETORNO

Devuelve un puntero al contenido del campo de cabecera o NULL.
