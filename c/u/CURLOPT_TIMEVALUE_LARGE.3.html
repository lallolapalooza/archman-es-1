CURLOPT_TIMEVALUE_LARGE(3)

Paquete: curl

Licencias: MIT

CURLOPT_TIMEVALUE_LARGE(3) Manual de funciones de biblioteca CURLOPT_TIMEVALUE_LARGE(3)

NOMBRE

CURLOPT_TIMEVALUE_LARGE - valor de tiempo para condicional

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TIMEVALUE_LARGE,
                          curl_off_t val);

DESCRIPCIÓN

Pase un parámetro val de tipo curl_off_t. Este debe ser el tiempo contado en segundos desde el 1 de enero de 1970, y el tiempo se usa en una condición según lo especificado con CURLOPT_TIMECONDITION(3).

La diferencia entre esta opción y CURLOPT_TIMEVALUE(3) es el tipo del argumento. En sistemas donde 'long' solo tiene 32 bits de ancho, esta opción debe usarse para establecer fechas posteriores al año 2038.

POR DEFECTO

0

PROTOCOLOS

Esta funcionalidad solo afecta a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* El 1 de enero de 2020 es 1577833200 */
    curl_easy_setopt(curl, CURLOPT_TIMEVALUE_LARGE, (curl_off_t)1577833200);
    /* If-Modified-Since la marca de tiempo anterior */
    curl_easy_setopt(curl, CURLOPT_TIMECONDITION, CURL_TIMECOND_IFMODSINCE);
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

HISTORIAL

Las enumeraciones CURL_TIMECOND_* se convirtieron en tipos long en la versión 8.13.0; antes de esta versión, era necesario un casting a long al pasarlos a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.59.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien; un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).

VER TAMBIÉN

CURLINFO_FILETIME(3), CURLOPT_TIMECONDITION(3), CURLOPT_TIMEVALUE(3)
