curl_mime_headers(3)

Paquete: curl

Licencias: MIT

curl_mime_headers(3) Manual de funciones de la biblioteca curl_mime_headers(3)

NOMBRE

curl_mime_headers - establecer encabezados personalizados de una parte mime

SINOPSIS

#include <curl/curl.h>
CURLcode curl_mime_headers(curl_mimepart *part,
                           struct curl_slist *headers, int take_ownership);

DESCRIPCIÓN

curl_mime_headers(3) establece los encabezados personalizados de una parte mime.

part es el manejador de la parte al que se asignará la lista de encabezados personalizados.

headers es la cabeza de una lista de encabezados personalizados; puede establecerse a NULL para eliminar una lista de encabezados personalizados previamente adjunta.

take_ownership: cuando es distinto de cero, hace que la lista se libere al ser reemplazada o al eliminar la estructura mime; en este caso, la lista no debe liberarse explícitamente.

Establecer la lista de encabezados personalizados de una parte varias veces es válido: solo se conservará el valor establecido por la última llamada.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  struct curl_slist *headers = NULL;
  CURL *easy = curl_easy_init();
  curl_mime *mime;
  curl_mimepart *part;
  headers = curl_slist_append(headers, "Custom-Header: mooo");
  mime = curl_mime_init(easy);
  part = curl_mime_addpart(mime);
  /* usa estos encabezados en la parte, toma posesión */
  curl_mime_headers(part, headers, 1);
  /* pasa estos datos */
  curl_mime_data(part, "12345679", CURL_ZERO_TERMINATED);
  /* establece el nombre */
  curl_mime_name(part, "numbers");
  /* Publica y envíalo. */
  curl_easy_setopt(easy, CURLOPT_MIMEPOST, mime);
  curl_easy_setopt(easy, CURLOPT_URL, "https://example.com");
  curl_easy_perform(easy);
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el buffer de error cuando se devuelve un valor distinto de cero.

VER TAMBIÉN
