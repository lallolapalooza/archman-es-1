    DESCRIPTION

    These functions provide the curses interface for window and screen management.

    A window is a rectangle on the screen. A pad is like a window, but it is not restricted in size to the size of the physical screen. Pads are useful for creating windows larger than the screen, and then only a portion of the pad is displayed on the screen at any one time.

    A WINDOW structure represents a window. A PAD structure represents a pad.

    The functions are:

    • newwin: creates a new window with the given number of lines (h) and columns (w), whose upper-left corner is at position (y, x) on the screen. The window is initially blank.
    • delwin: delete the specified window, freeing all associated memory.
    • subwin: creates a new window that is a sub-window of the window orig. The sub-window has h lines and w columns, and its upper-left corner is at position (y, x) relative to the upper-left corner of the orig window.
    • dupwin: duplicate the specified window. The new window has the same dimensions, position, and contents as the original window.
    • wfresh: (Internal function, not intended for direct use by applications) Refresh the window.

    • wclrtobot: clear from the current cursor position to the end of the window.
    • wclrtoeol: clear from the current cursor position to the end of the line.
    • wcursyncup: synchronize the window's cursor position with its parent window's cursor position.
    • wsyncup: update the parent window to reflect changes in the window.
    • wsyncdown: update the window to reflect changes in its parent window.
    • derwin: create a derived window. This is similar to subwin, except that the window's top-left corner is relative to the parent window's top-left corner.
    • mvderwin: move a derived window from its current position to a new position (y, x) relative to its parent window.
    • subpad: create a new pad with the given number of lines (h) and columns (w).
    • prefresh: like refresh, but for pads. It refreshes a portion of the pad, corresponding to the screen region defined by the last four arguments.
    • pnoutrefresh: like noutrefresh, but for pads.
    • touchwin: touch all characters in the window.
    • touchline: touch a specified range of lines in the window.
    • untouchwin: mark all characters in the window as unmodified.
    • wrefresh: update the physical screen to match the contents of the specified window.
    • wnoutrefresh: mark the specified window for screen update, but don't actually update the screen. This allows multiple windows to be updated with a single call to doupdate.

    RETURN VALUE

    All functions that return a pointer to a WINDOW structure return NULL on failure. All other functions return OK on success and ERR on failure.

    NOTES

    When a window is deleted with delwin, all its subwindows are also deleted.

    The subwin and derwin functions create subwindows that share memory with the parent window. Changes to the parent window will affect the subwindow, and vice versa.

    The wrefresh, wclrtobot, wclrtoeol, wcursyncup, wsyncup, and wsyncdown functions are the primary interface for screen manipulation.

The subwin function creates a sub-window. The derwin function creates a sub-window that is not necessarily a subset of the parent window. It is a sub-window, but it can be located anywhere on the screen. The mvderwin function can be used to reposition derived windows.

The dupwin function creates a duplicate of an existing window. The new window has the same dimensions, position, and contents as the original window. This can be useful for creating temporary windows or for saving the state of a window.

wrefresh performs the update operation for the specified window. wnoutrefresh performs the update operation for the specified window but does not actually refresh the physical screen. This allows multiple windows to be updated efficiently with a single call to doupdate.

touchwin touches all characters in the specified window. This means that all characters in the window are marked as modified, and will be rewritten to the screen the next time the window is refreshed.

untouchwin marks all characters in the specified window as unmodified. This can be useful to prevent a window from being refreshed, even if it has been modified.

The wsyncup and wsyncdown functions synchronize the contents of a window with its parent window. wsyncup updates the parent window to reflect changes in the window. wsyncdown updates the window to reflect changes in its parent window.

wcursyncup synchronizes the cursor position of a window with its parent window.

The subpad function creates a new pad with the given number of lines (h) and columns (w). A pad is a window that is not restricted in size to the size of the physical screen.

prefresh refreshes a portion of the pad, corresponding to the screen region defined by the last four arguments. pnoutrefresh is similar to prefresh, but it does not update the physical screen.
