CURLOPT_FTP_SSL_CCC(3)

Paquete: curl

Licencias: MIT

CURLOPT_FTP_SSL_CCC(3) Manual de funciones de la biblioteca CURLOPT_FTP_SSL_CCC(3)

NOMBRE

CURLOPT_FTP_SSL_CCC - desactivar SSL nuevamente con FTP después de la autenticación

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_SSL_CCC,
                          long how);

DESCRIPCIÓN

Si está habilitado, esta opción hace que libcurl use CCC (Clear Command Channel). Desactiva la capa SSL/TLS después de la autenticación. El resto de la comunicación del canal de control permanece sin cifrar. Esto permite que los enrutadores NAT sigan la transacción FTP. Pase un long usando uno de los siguientes valores:

CURLFTPSSL_CCC_NONE
no intentar usar CCC.
CURLFTPSSL_CCC_PASSIVE
No iniciar la desactivación, sino esperar a que el servidor lo haga. No enviar una respuesta.
CURLFTPSSL_CCC_ACTIVE
Iniciar la desactivación y esperar una respuesta.

PREDETERMINADO

CURLFTPSSL_CCC_NONE

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/file.txt");
    curl_easy_setopt(curl, CURLOPT_USE_SSL, CURLUSESSL_CONTROL);
    /* volver a texto plano FTP después de autenticarse */
    curl_easy_setopt(curl, CURLOPT_FTP_SSL_CCC, CURLFTPSSL_CCC_ACTIVE);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIA

Los enums CURLFTPSSL_* se convirtieron en tipos long en la versión 8.16.0; antes de esta versión, era necesario hacer una conversión a long al pasarlos a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.16.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un código CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).
