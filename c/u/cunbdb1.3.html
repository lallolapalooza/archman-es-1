CUNBDB1

Documentación de función/subrutina

subrutina cunbdb1 (integer m, integer p, integer q, complex, dimension(ldx11,*) x11, integer ldx11, complex, dimension(ldx21,*) x21, integer ldx21, real, dimension(*) theta, real, dimension(*) phi, complex, dimension(*) taup1, complex, dimension(*) taup2, complex, dimension(*) tauq1, complex, dimension(*) work, integer lwork, integer info)

CUNBDB1

Propósito:

!>
!> CUNBDB1 bidiagonaliza simultáneamente los bloques de una matriz delgada y alta X con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 es P-por-Q, y X21 es (M-P)-por-Q. Q debe ser no mayor que P,
!> M-P, o M-Q. Las rutinas CUNBDB2, CUNBDB3 y CUNBDB4 manejan los casos en
!> los que Q no es la dimensión mínima.
!>
!> Las matrices unitarias P1, P2 y Q1 son P-por-P, (M-P)-por-(M-P),
!> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por
!> vectores de Householder.
!>
!> B11 y B12 son matrices bidiagonales Q-por-Q representadas implícitamente por
!> ángulos THETA, PHI.
!>
!>

Parámetros

M 
!>          M es ENTERO
!>           El número de filas de X11 más el número de filas de X21.
!>

P

!>          P es ENTERO
!>           El número de filas en X11. 0 <= P <= M.
!>

Q

!>          Q es ENTERO
!>           El número de columnas en X11 y X21. 0 <= Q <=
!>           MIN(P,M-P,M-Q).
!>

X11

!>          X11 es un array COMPLEJO, de dimensión (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X11) especifican los
!>           reflectores para P1 y las filas de triu(X11,1) especifican los
!>           reflectores para Q1.
!>

LDX11

!>          LDX11 es ENTERO
!>           La dimensión principal de X11. LDX11 >= P.
!>

X21

!>          X21 es un array COMPLEJO, de dimensión (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X21) especifican los
!>           reflectores para P2.
!>

LDX21

!>          LDX21 es ENTERO
!>           La dimensión principal de X21. LDX21 >= M-P.
!>

THETA

!>          THETA es un array REAL de dimensión (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es un array REAL de dimensión (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es un array COMPLEJO de dimensión (P)
!>           Los factores escalares de los reflectores elementales que
!>           definen P1.
!>

TAUP2

!>          TAUP2 es un array COMPLEJO de dimensión (M-P)
!>           Los factores escalares de los reflectores elementales que
!>           definen P2.
!>

TAUQ1

!>          TAUQ1 es un array COMPLEJO de dimensión (Q)
!>           Los factores escalares de los reflectores elementales que
!>           definen Q1.
!>

WORK

!>          WORK es un array COMPLEJO de dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>           solo calcula el tamaño óptimo del array WORK, devuelve
!>           este valor como la primera entrada del array WORK, y XERBLA no
!>           emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>           = 0:  salida exitosa.
!>           < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>

Detalles Adicionales:

!>
!>  Los bloques superior-bidiagonales B11, B21 se representan implícitamente
!>  por los ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada entrada
!>  en cada banda bidiagonal es un producto de un seno o coseno de un THETA
!>  con un seno o coseno de un PHI. Ver [1] o CUNCSD para detalles.
!>
!>  P1, P2 y Q1 se representan como productos de reflectores elementales.
!>  Ver CUNCSD2BY1 para detalles sobre la generación de P1, P2 y Q1 usando CUNGQR
!>  y CUNGLQ.
!>

Referencias:
