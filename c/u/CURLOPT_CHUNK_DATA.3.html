CURLOPT_CHUNK_DATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_CHUNK_DATA(3) Manual de funciones de la biblioteca CURLOPT_CHUNK_DATA(3)

NOMBRE

CURLOPT_CHUNK_DATA - puntero pasado a las funciones de retorno de llamada de fragmentos FTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CHUNK_DATA, void *pointer);

DESCRIPCIÓN

Pasa un puntero que libcurl no modifica y se pasa como argumento ptr a CURLOPT_CHUNK_BGN_FUNCTION(3) y CURLOPT_CHUNK_END_FUNCTION(3).

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

#include <stdio.h>
struct callback_data {
   FILE *output;
};
static long file_is_coming(struct curl_fileinfo *finfo,
                           void *ptr,
                           int remains)
{
  struct callback_data *data = ptr;
  printf("%3d %40s %10luB ", remains, finfo->filename,
         (unsigned long)finfo->size);
  switch(finfo->filetype) {
  case CURLFILETYPE_DIRECTORY:
    printf(" DIR\n");
    break;
  case CURLFILETYPE_FILE:
    printf("FILE ");
    break;
  default:
    printf("OTHER\n");
    break;
  }
  if(finfo->filetype == CURLFILETYPE_FILE) {
    /* no transferir archivos >= 50B */
    if(finfo->size > 50) {
      printf("SKIPPED\n");
      return CURL_CHUNK_BGN_FUNC_SKIP;
    }
    data->output = fopen(finfo->filename, "wb");
    if(!data->output) {
      return CURL_CHUNK_BGN_FUNC_FAIL;
    }
  }
  return CURL_CHUNK_BGN_FUNC_OK;
}
int main()
{
  /* datos para la devolución de llamada */
  struct callback_data callback_info;
  CURL *curl = curl_easy_init();
  /* se llama a la devolución de llamada antes de que comience la descarga del archivo concreto */
  curl_easy_setopt(curl, CURLOPT_CHUNK_BGN_FUNCTION, file_is_coming);
  curl_easy_setopt(curl, CURLOPT_CHUNK_DATA, &callback_info);
}

DISPONIBILIDAD

Añadido en curl 7.21.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un código CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, véase libcurl-errors(3).

VER TAMBIÉN

CURLOPT_CHUNK_BGN_FUNCTION(3), CURLOPT_WILDCARDMATCH(3)
