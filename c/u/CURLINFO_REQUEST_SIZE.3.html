CURLINFO_REQUEST_SIZE(3)

Paquete: curl

Licencias: MIT

CURLINFO_REQUEST_SIZE(3) Manual de funciones de la biblioteca CURLINFO_REQUEST_SIZE(3)

NOMBRE

CURLINFO_REQUEST_SIZE - obtener el tamaño de la solicitud enviada

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_REQUEST_SIZE, long *sizep);

DESCRIPCIÓN

Pasa un puntero a un long para recibir el tamaño total de las solicitudes emitidas. Esto es, hasta ahora, solo para solicitudes HTTP. Tenga en cuenta que puede ser más de una solicitud si CURLOPT_FOLLOWLOCATION(3) está activado.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      long req;
      res = curl_easy_getinfo(curl, CURLINFO_REQUEST_SIZE, &req);
      if(!res)
        printf("Tamaño de la solicitud: %ld bytes\n", req);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.4.1

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, véase libcurl-errors(3).

VER TAMBIÉN

CURLINFO_HEADER_SIZE(3), CURLINFO_SIZE_DOWNLOAD_T(3), curl_easy_getinfo(3), curl_easy_setopt(3)
