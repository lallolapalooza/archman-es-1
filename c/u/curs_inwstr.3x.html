curs_inwstr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_inwstr(3X) Llamadas a biblioteca curs_inwstr(3X)

NOMBRE

inwstr, innwstr, winwstr, winnwstr, mvinwstr, mvinnwstr, mvwinwstr, mvwinnwstr - obtener una cadena de caracteres anchos de una ventana de curses

SINOPSIS

#include <curses.h>
int inwstr(wchar_t *wstr);
int innwstr(wchar_t *wstr, int n);
int winwstr(WINDOW *win, wchar_t *wstr);
int winnwstr(WINDOW *win, wchar_t *wstr, int n);
int mvinwstr(int y, int x, wchar_t *wstr);
int mvinnwstr(int y, int x, wchar_t *wstr, int n);
int mvwinwstr(WINDOW *win, int y, int x, wchar_t *wstr);
int mvwinnwstr(WINDOW *win, int y, int x, wchar_t *wstr, int n);

DESCRIPCIÓN

Estas rutinas devuelven una cadena de caracteres anchos wchar_t en wstr, comenzando en la posición actual del cursor en la ventana nombrada.

Las cuatro funciones con n como último argumento devuelven una subcadena principal de como máximo n caracteres de longitud (excluyendo el NUL final). La transferencia se detiene al final de la línea actual, o cuando n caracteres han sido almacenados en la ubicación referenciada por wstr.

Si el tamaño n no es suficientemente grande para almacenar un carácter complejo completo, se genera un error.

VALOR DE RETORNO

Todas las rutinas devuelven ERR en caso de fallo. Al completarse con éxito, las rutinas *inwstr devuelven OK, y las rutinas *innwstr devuelven el número de caracteres leídos en la cadena.

X/Open no define condiciones de error. Esta implementación devuelve un error

  • si el parámetro win es nulo o
  • si el parámetro wstr es nulo, o
  • si no se pudieron leer caracteres.

Las funciones prefijadas con “mv” mueven primero el cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Todas las rutinas excepto winnwstr pueden ser macros.

Cada celda en la ventana contiene un carácter complejo (un carácter de espaciado y cero o más caracteres no espaciados) junto con atributos y color. Estas funciones almacenan solo los caracteres anchos, ignorando atributos y color. Use in_wchstr para obtener los caracteres complejos de una ventana.

Leer una línea que desborda el array apuntado por wstr con inwstr, mvinwstr, mvwinwstr o winwstr produce resultados indefinidos. Por lo tanto, se recomienda el uso de innwstr, mvinnwstr, mvwinnwstr o winnwstr.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4.

VER TAMBIÉN

curses(3X), curs_inch(3X), curs_inchstr(3X), curs_instr(3X), curs_in_wchstr(3X)
