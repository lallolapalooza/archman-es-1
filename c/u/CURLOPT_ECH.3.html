CURLOPT_ECH(3)

Paquete: curl

Licencias: MIT

CURLOPT_ECH(3) Manual de funciones de la biblioteca CURLOPT_ECH(3)

NOMBRE

CURLOPT_ECH - configuración para Encrypted Client Hello

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ECH, char *config);

DESCRIPCIÓN

ECH solo es compatible con TLSv1.3.

Esta función experimental requiere una compilación especial de OpenSSL, ya que ECH aún no es compatible en las versiones de OpenSSL. En cambio, ECH es compatible con las últimas versiones de BoringSSL, wolfSSL y rustls-ffi.

También existe un problema conocido con el uso de wolfSSL, que no admite ECH cuando se utiliza el mecanismo HelloRetryRequest.

Pase una cadena que especifique detalles de configuración para ECH. En todos los casos, si se intenta ECH, puede fallar por varias razones. Las palabras clave admitidas son:

false
Desactiva ECH.
grease
Instruye al cliente a emitir una extensión ECH GREASE. (La conexión falla si se intenta ECH pero falla).
true
Instruye al cliente a intentar ECH, si es posible, pero a no fallar si intentar ECH no es posible.
hard
Instruye al cliente a intentar ECH y fallar si intentar ECH no es posible.
ecl:<valor-base64>
Si la cadena comienza con ecl:, el resto de la cadena debe ser una lista ECHConfigList codificada en base64 que se utilizará para ECH en lugar de intentar descargar dicho valor de DNS.
pn:<nombre>
Si la cadena comienza con pn:, el resto de la cadena debe ser un nombre de host/DNS que se utilizará para anular el campo public_name de la ECHConfigList que se utiliza para ECH.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala en NULL o "false" para volver a deshabilitar su uso.

PREDETERMINADO

NULL, lo que significa que ECH está deshabilitado.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL, rustls y wolfSSL.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  const char *config = \
    "ecl:AED+DQA87wAgACB/RuzUCsW3uBbSFI7mzD63TUXpI8sGDTnFTbFCDpa+" \
    "CAAEAAEAAQANY292ZXIuZGVmby5pZQAA";
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_ECH, config);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 8.8.0.

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
