CURLINFO_SIZE_DOWNLOAD_T(3)

Paquete: curl

Licencias: MIT

CURLINFO_SIZE_DOWNLOAD_T(3) Manual de funciones de la biblioteca CURLINFO_SIZE_DOWNLOAD_T(3)

NOMBRE

CURLINFO_SIZE_DOWNLOAD_T - obtener el número de bytes descargados

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_SIZE_DOWNLOAD_T,
                           curl_off_t *dlp);

DESCRIPCIÓN

Pase un puntero a un curl_off_t para recibir la cantidad total de bytes que se descargaron. La cantidad es solo para la transferencia más reciente y se restablece nuevamente para cada transferencia nueva. Esto cuenta los datos de carga útil reales, lo que también se conoce comúnmente como cuerpo. Todos los metadatos y datos de encabezado están excluidos de esta cantidad.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Realizar la solicitud */
    res = curl_easy_perform(curl);
    if(!res) {
      /* comprobar el tamaño */
      curl_off_t dl;
      res = curl_easy_getinfo(curl, CURLINFO_SIZE_DOWNLOAD_T, &dl);
      if(!res) {
        printf("Descargados %" CURL_FORMAT_CURL_OFF_T " bytes\n", dl);
      }
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.55.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
