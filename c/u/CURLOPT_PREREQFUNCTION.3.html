CURLOPT_PREREQFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_PREREQFUNCTION(3) Manual de funciones de biblioteca CURLOPT_PREREQFUNCTION(3)

NOMBRE

CURLOPT_PREREQFUNCTION - función de devolución de llamada de usuario que se llama cuando se ha establecido una conexión, pero antes de que se haya realizado una solicitud.

SINOPSIS

#include <curl/curl.h>
/* Estos son los códigos de retorno para la función de devolución de llamada pre-solicitud. */
#define CURL_PREREQFUNC_OK 0
#define CURL_PREREQFUNC_ABORT 1 /* falla toda la transferencia */
int prereq_callback(void *clientp,
                    char *conn_primary_ip,
                    char *conn_local_ip,
                    int conn_primary_port,
                    int conn_local_port);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PREREQFUNCTION, prereq_callback);

DESCRIPCIÓN

Pase un puntero a su función de devolución de llamada, que debe coincidir con el prototipo mostrado arriba.

Esta función es llamada por libcurl después de que se ha establecido una conexión o se ha reutilizado una conexión (incluido cualquier handshake SSL), pero antes de que se realice realmente cualquier solicitud en la conexión. Por ejemplo, para HTTP, esta devolución de llamada se llama una vez que se ha establecido una conexión al servidor, pero antes de que se envíe una solicitud GET/HEAD/POST/etc.

Esta función puede ser llamada varias veces si se permiten redirecciones y se están siguiendo (ver CURLOPT_FOLLOWLOCATION(3)).

La función de devolución de llamada debe devolver CURL_PREREQFUNC_OK en caso de éxito, o CURL_PREREQFUNC_ABORT para que la transferencia falle con el resultado CURLE_ABORTED_BY_CALLBACK.

A esta función se le pasan los siguientes argumentos:

conn_primary_ip
Un puntero a una cadena C terminada en nulo que contiene la IP principal del servidor remoto establecida con esta conexión. Para FTP, esta es la IP para la conexión de control. Las direcciones IPv6 se representan sin corchetes circundantes.
conn_local_ip
Un puntero a una cadena C terminada en nulo que contiene la IP de origen para esta conexión. Las direcciones IPv6 se representan sin corchetes circundantes.
conn_primary_port
El número de puerto principal en el servidor remoto establecido con esta conexión. Para FTP, este es el puerto para la conexión de control. Este puede ser un número de puerto TCP o UDP dependiendo del protocolo.
conn_local_port
El número de puerto de origen para esta conexión. Este puede ser un número de puerto TCP o UDP dependiendo del protocolo.
clientp
El puntero que estableció con CURLOPT_PREREQDATA(3).

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

struct priv {
  void *custom;
};
static int prereq_callback(void *clientp,
                           char *conn_primary_ip,
                           char *conn_local_ip,
                           int conn_primary_port,
                           int conn_local_port)
{
  printf("Conexión realizada a %s:%d\n", conn_primary_ip, conn_primary_port);
  return CURL_PREREQFUNC_OK;
}
int main(void)
{
  struct priv prereq_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_PREREQFUNCTION, prereq_callback);
    curl_easy_setopt(curl, CURLOPT_PREREQDATA, &prereq_data);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.80.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, no cero significa que ocurrió un error, ver libcurl-errors(3).
