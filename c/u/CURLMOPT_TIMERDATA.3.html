CURLMOPT_TIMERDATA(3)

Paquete: curl

Licencias: MIT

CURLMOPT_TIMERDATA(3) Manual de funciones de biblioteca CURLMOPT_TIMERDATA(3)

NOMBRE

CURLMOPT_TIMERDATA - puntero personalizado para pasar a la función de devolución de llamada del temporizador

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_TIMERDATA, void *pointer);

DESCRIPCIÓN

Un puntero de datos para pasar a la función de devolución de llamada del temporizador establecida con la opción CURLMOPT_TIMERFUNCTION(3).

libcurl no modificará este puntero, solo lo pasará al argumento clientp de la función de devolución de llamada del temporizador.

VALOR POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

struct priv {
  void *custom;
};
static int timerfunc(CURLM *multi, long timeout_ms, void *clientp)
{
  struct priv *mydata = clientp;
  printf("nuestro ptr: %p\n", mydata->custom);
  if(timeout_ms >= 0) {
    /* este es el nuevo tiempo de espera único a esperar */
  }
  else {
    /* eliminar el tiempo de espera, no hay nada que esperar ahora */
  }
  return 0;
}
int main(void)
{
  struct priv mydata;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_TIMERFUNCTION, timerfunc);
  curl_multi_setopt(multi, CURLMOPT_TIMERDATA, &mydata);
}

DISPONIBILIDAD

Añadido en curl 7.16.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo correcto, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
