NOMBRE

curl_escape - Codifica una cadena para URL

SINOPSIS

#include <curl/curl.h>
char *curl_escape(const char *string, int length);

DESCRIPCIÓN

Función obsoleta. Utilice curl_easy_escape(3) en su lugar.

Esta función convierte la string de entrada dada en una cadena codificada para URL y la devuelve como una nueva cadena asignada. Todos los caracteres de entrada que no sean a-z, A-Z o 0-9 se convierten a su versión "escapada para URL" (%NN donde NN es un número hexadecimal de dos dígitos).

Si el argumento length se establece en 0, curl_escape(3) utiliza strlen() en string para determinar el tamaño.

Debe curl_free(3) la cadena devuelta cuando termine con ella.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  char *output = curl_escape("datos a convertir", 15);
  if(output) {
    printf("Codificado: %s\n", output);
    curl_free(output);
  }
}

HISTORIA

Desde la versión 7.15.4, se debe utilizar curl_easy_escape(3). Esta función podría eliminarse en una futura versión.

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Un puntero a una cadena terminada en nulo o NULL si falló.

VER TAMBIÉN

curl_free(3), curl_unescape(3)
