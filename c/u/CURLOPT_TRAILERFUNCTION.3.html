CURLOPT_TRAILERFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_TRAILERFUNCTION(3) Manual de funciones de biblioteca CURLOPT_TRAILERFUNCTION(3)

NOMBRE

CURLOPT_TRAILERFUNCTION - callback para enviar encabezados finales

SINOPSIS

#include <curl.h>
int curl_trailer_callback(struct curl_slist ** list, void *userdata);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TRAILERFUNCTION,
                          curl_trailer_callback *func);

DESCRIPCIÓN

Pasa un puntero a una función de callback.

Esta función de callback se llama una vez justo antes de enviar el CR LF final en una transferencia HTTP fragmentada para llenar una lista de encabezados finales que se enviarán antes de finalizar la transferencia HTTP.

Puede establecer el argumento userdata con la opción CURLOPT_TRAILERDATA(3).

Los encabezados finales incluidos en la lista enlazada no deben estar terminados en CRLF, ya que libcurl agrega los caracteres de terminación de línea apropiados después de cada elemento del encabezado.

Si usa curl_slist_append(3) para agregar encabezados finales a curl_slist, libcurl duplica las cadenas y libera curl_slist una vez que se han enviado los trailers.

Si un campo de encabezado final no tiene el formato correcto, se ignora y se emite un mensaje informativo.

El valor de retorno puede ser CURL_TRAILERFUNC_OK o CURL_TRAILERFUNC_ABORT, lo que instruirá a libcurl a continuar con el envío de los trailers o a abortar la solicitud.

Si establece esta opción en NULL, la transferencia procede como de costumbre sin interrupciones.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

extern size_t read_cb(char *ptr, size_t size,
                      size_t nmemb, void *userdata);
static int trailer_cb(struct curl_slist **tr, void *data)
{
  /* libcurl libera la lista */
  *tr = curl_slist_append(*tr, "Mi-super-genial-trailer: contenido-del-trailer");
  return CURL_TRAILERFUNC_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    /* Establecer la URL de la solicitud */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* Ahora establecerlo como put */
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    /* Suponiendo que tenemos una función que devuelve los datos a enviar
       Que esa función sea read_cb */
    curl_easy_setopt(curl, CURLOPT_READFUNCTION, read_cb);
    struct curl_slist *headers = NULL;
    headers = curl_slist_append(headers, "Trailer: Mi-super-genial-trailer");
    res = curl_easy_setopt(curl, CURLOPT_HTTPHEADER, headers);
    /* Establecer el callback para llenar los trailers */
    curl_easy_setopt(curl, CURLOPT_TRAILERFUNCTION, trailer_cb);
    /* Realizar la transferencia */
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
    curl_slist_free_all(headers);
  }
}

DISPONIBILIDAD

Agregado en curl 7.64.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier otro valor indica un error, ver libcurl-errors(3).
