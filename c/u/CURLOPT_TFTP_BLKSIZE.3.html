CURLOPT_TFTP_BLKSIZE(3)

Paquete: curl

Licencias: MIT

CURLOPT_TFTP_BLKSIZE(3) Manual de funciones de biblioteca CURLOPT_TFTP_BLKSIZE(3)

NOMBRE

CURLOPT_TFTP_BLKSIZE - Tamaño de bloque TFTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TFTP_BLKSIZE, long blocksize);

DESCRIPCIÓN

Especifica el tamaño de bloque a utilizar para la transmisión de datos TFTP. El rango válido según RFC 2348 es de 8 a 65464 bytes. El valor predeterminado de 512 bytes se utiliza si no se especifica esta opción. El tamaño de bloque especificado solo se utilizará si es compatible con el servidor remoto. Si el servidor no devuelve una confirmación de opción o devuelve una confirmación de opción sin tamaño de bloque, se utilizará el valor predeterminado de 512 bytes.

PREDETERMINADO

512

PROTOCOLOS

Esta funcionalidad afecta solo a tftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "tftp://example.com/bootimage");
    /* intentar usar bloques más grandes */
    curl_easy_setopt(curl, CURLOPT_TFTP_BLKSIZE, 2048L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.19.4

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier otro valor indica un error; consulte libcurl-errors(3).
