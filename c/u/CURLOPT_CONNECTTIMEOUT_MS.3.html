CURLOPT_CONNECTTIMEOUT_MS(3)

Paquete: curl

Licencias: MIT

CURLOPT_CONNECTTIMEOUT_MS(3) Manual de funciones de biblioteca CURLOPT_CONNECTTIMEOUT_MS(3)

NOMBRE

CURLOPT_CONNECTTIMEOUT_MS - tiempo de espera para la fase de conexión

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONNECTTIMEOUT_MS,
                          long timeout);

DESCRIPCIÓN

Pasa un long. Establece el tiempo máximo en milisegundos que permites que dure la fase de conexión. Este tiempo de espera solo limita la fase de conexión, no tiene impacto una vez que libcurl se ha conectado. La fase de conexión incluye la resolución de nombres (DNS) y todos los apretones de manos y negociaciones de protocolo hasta que haya una conexión establecida con el lado remoto.

Establece esta opción a cero para cambiar al tiempo de espera de conexión incorporado por defecto: 300 segundos. Ver también la opción CURLOPT_TIMEOUT_MS(3).

CURLOPT_CONNECTTIMEOUT(3) es la misma función pero establecida en segundos.

Si se establecen tanto CURLOPT_CONNECTTIMEOUT(3) como CURLOPT_CONNECTTIMEOUT_MS(3), se utiliza el valor establecido más recientemente.

El tiempo de espera de conexión está incluido en el tiempo de espera general que lo abarca todo, CURLOPT_TIMEOUT_MS(3):

Con CURLOPT_CONNECTTIMEOUT_MS(3) establecido a 3000 y CURLOPT_TIMEOUT_MS(3) establecido a 5000, la operación nunca puede durar más de 5000 milisegundos, y la fase de conexión no puede durar más de 3000 milisegundos.

Con CURLOPT_CONNECTTIMEOUT_MS(3) establecido a 4000 y CURLOPT_TIMEOUT_MS(3) establecido a 2000, la operación nunca puede durar más de 2000 milisegundos. Incluyendo la fase de conexión.

Esta opción puede hacer que libcurl use la señal SIGALRM para agotar el tiempo de espera de las llamadas al sistema en compilaciones que no utilizan DNS asíncrono. En sistemas similares a Unix, esto podría causar que se utilicen señales a menos que se establezca CURLOPT_NOSIGNAL(3).

PREDETERMINADO

300000

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* completar la conexión en 10000 milisegundos */
    curl_easy_setopt(curl, CURLOPT_CONNECTTIMEOUT_MS, 10000L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.16.2

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
