DESCRIPCIÓ

N

Esta función configura el comportamiento del registro para hacer que algunas partes de curl sean más verbosas o silenciosas que

otras.

Esta función puede llamarse durante la fase de inicialización de un programa. No es obligatorio. Puede llamarse varias veces, incluso sobrescribiendo posiblemente la configuración de llamadas

anteriores.

Llamar a esta función después de que se hayan iniciado las transferencias es indefinido. En algunas plataformas/arquitecturas podría surtir efecto, en otras

no.

Esta función es segura para hilos desde libcurl 8.3.0 si curl_version_info(3) tiene el bit de característica CURL_VERSION_THREADSAFE establecido (la mayoría de las plataformas)

.

Si no es segura para hilos, no debe llamar a esta función cuando cualquier otro hilo del programa (es decir, un hilo que comparta la misma memoria) esté en ejecución. Esto no significa solo ningún otro hilo que esté usando libcurl. Porque curl_global_init(3) puede llamar a funciones de otras bibliotecas que son igualmente inseguras para hilos, podría entrar en conflicto con cualquier otro hilo que use estas otras

bibliotecas.

Si está inicializando libcurl desde una DLL de Windows, no debe inicializarla desde DllMain o un inicializador estático, porque Windows retiene el bloqueo del cargador durante ese tiempo y podría causar un bloqueo

mutuo.

La cadena config es una lista de nombres de componentes separados por comas. Los nombres no distinguen entre mayúsculas y minúsculas y los nombres desconocidos se ignoran. El nombre especial "all" se aplica a todos los componentes. Los nombres pueden prefijarse con '+' o '-' para habilitar o deshabilitar el registro detallado de un

componente.

La lista de nombres de componentes no forma parte de la API pública de curl. Los nombres pueden añadirse o desaparecer en versiones futuras de libcurl. Dado que los nombres desconocidos se ignoran silenciosamente, las configuraciones de registro obsoletas no causan errores al actualizar libcurl. Dado esto, se puede esperar que algunos nombres sean bastante estables y se enumeran a continuación para fácil

referencia.

Tenga en cuenta que la configuración de registro solo se aplica a las transferencias donde el registro de depuración está habilitado. Vea CURLOPT_VERBOSE(3) o CURLOPT_DEBUGFUNCTION(3) par

a saber cómo
controlar eso.
