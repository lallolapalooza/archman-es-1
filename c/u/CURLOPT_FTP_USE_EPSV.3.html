CURLOPT_FTP_USE_EPSV(3)

Paquete: curl

Licencias: MIT

CURLOPT_FTP_USE_EPSV(3) Manual de funciones de biblioteca CURLOPT_FTP_USE_EPSV(3)

NOMBRE

CURLOPT_FTP_USE_EPSV - usar EPSV para FTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTP_USE_EPSV, long epsv);

DESCRIPCIÓN

Pase epsv como un long. Si el valor es 1, le indica a curl que use el comando EPSV al realizar descargas FTP pasivas (que es lo que hace por defecto). Usar EPSV significa que libcurl primero intenta usar el comando EPSV antes de usar PASV. Si pasa cero a esta opción, no usa EPSV, solo PASV simple.

El comando EPSV es una adición ligeramente más nueva al protocolo FTP que PASV y es el comando preferido para usar, ya que permite usar IPv6. Los servidores FTP antiguos podrían no admitirlo, razón por la cual libcurl tiene un mecanismo de respaldo. A veces, ese respaldo no es suficiente y entonces esta opción puede ser útil.

Si el servidor es un host IPv6, esta opción no tiene ningún efecto.

PREDETERMINADO

1

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/old-server/file.txt");
    /* apaguemos esta característica moderna */
    curl_easy_setopt(curl, CURLOPT_FTP_USE_EPSV, 0L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.2

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero significa que ocurrió un error, consulte libcurl-errors(3).
