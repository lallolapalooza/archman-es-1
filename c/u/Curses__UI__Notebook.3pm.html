NOMBRE

Curses::UI::Notebook - Crea y manipula widgets de cuaderno.

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Notebook

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add(undef, 'Window');
my $notebook = $win->add(undef, 'Notebook');
my $page1 = $notebook->add_page('page 1');
$page1->add(
    undef, 'Label',
    -x    => 15,
    -y    => 6,
    -text => "Page #1.",
);
my $page2 = $notebook->add_page('page 2');
$page2->add(
    undef, 'Label',
    -x    => 15,
    -y    => 6,
    -text => "Page #2.",
);
my $page3 = $notebook->add_page('page 3', -on_activate => \&sub );
$page3->add(
    undef, 'Label',
    -x    => 15,
    -y    => 6,
    -text => "Page #3.",
);
$notebook->focus;
$cui->mainloop;

DESCRIPCIÓN

Este paquete implementa un widget de cuaderno similar al que se encuentra en Motif. Un cuaderno contiene varias ventanas, o páginas, de las cuales solo una es visible a la vez; las pestañas en la parte superior del widget enumeran las páginas disponibles. De esta manera, se puede acomodar una gran cantidad de información en un área de pantalla relativamente pequeña. [Los usuarios de Windows podrían reconocer esto como un cuadro de diálogo con pestañas.]

OPCIONES ESTÁNDAR

-x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -border, -sbborder, -bg, -fg, -intellidraw, -onchange, -onblur.

Consulte Curses::UI::Widget para una discusión de cada una de estas opciones.

Tenga en cuenta que -border está habilitado y tanto -ipadleft como -ipadright están establecidos en 1 de forma predeterminada al crear objetos de cuaderno.

OPCIONES ESPECÍFICAS DEL WIDGET

  • -bindings < REFERENCIA A HASH >

    Las claves en esta referencia a hash son pulsaciones de teclas y los valores son rutinas a las que deben estar vinculadas. En el caso de que una tecla esté vacía, la rutina correspondiente se convertirá en la rutina predeterminada que process_bindings aplica a las pulsaciones de teclas no coincidentes que recibe.

    De forma predeterminada, se utilizan las siguientes asignaciones:

    TECLA                 RUTINA
------------------  ----------
KEY_HOME, Ctrl-A    first_page
KEY_END, Ctrl-E     last_page
KEY_NPAGE, Ctrl-N   next_page
KEY_PPAGE, Ctrl-P   prev_page
  • -routines < REFERENCIA A HASH >

    Las claves en esta referencia a hash son rutinas y los valores son valores escalares o referencias a código. process_bindings asigna pulsaciones de teclas a rutinas y luego a un valor escalar, que devuelve, o a una referencia a código, que ejecuta.

    De forma predeterminada, se utilizan las siguientes asignaciones:

    RUTINA         ACCIÓN
----------      -------------------------
first_page      hace que la primera página esté activa
last_page       hace que la última página esté activa
next_page       hace que la siguiente página esté activa
prev_page       hace que la página anterior esté activa
  • -wraparound < BOOLEANO >

    Si el BOOLEANO tiene un valor verdadero, se habilita el envolturamiento. Esto significa que avanzar a la siguiente página hará un ciclo desde la última de vuelta a la primera página y de manera similar, avanzar a la página anterior hará un ciclo desde la primera de vuelta a la última página.

    De forma predeterminada, es verdadero.

MÉTODOS

  • new ( OPCIONES )

    Construye un nuevo objeto de cuaderno usando opciones en el hash OPCIONES.

  • layout ( )

    Dispone el objeto de cuaderno, se asegura de que quepa en la pantalla disponible y crea las ventanas de curses para las etiquetas de borde / pestaña así como el área de dibujo efectiva.

  • draw ( BOOLEANO )

    Dibuja el objeto de cuaderno junto con la ventana de la página activa. Si el BOOLEANO es verdadero, la pantalla no se actualiza después de dibujar.

    De forma predeterminada, el BOOLEANO es verdadero, por lo que la pantalla se actualiza.

  • intellidraw ( )
  • focus ( )
  • onFocus ( REFERENCIA A CÓDIGO )
  • onBlur ( REFERENCIA A CÓDIGO )

    Consulte Curses::UI::Widget para explicaciones de estos métodos.

  • add_page ( PÁGINA [ , -on_activate => sub_ref ] [, -on_delete => ] )

    Añade la página especificada al objeto de cuaderno y crea un objeto de ventana asociado. Devuelve el objeto de ventana o undef en caso de fallo.

    Nota: la adición falla si la página haría que la ventana de pestañas desbordara o ya es parte del objeto de cuaderno.

    El parámetro "-on_activate" especifica una devolución de llamada opcional que se invocará cuando la página sea activada. Esta devolución de llamada se llamará con el widget de cuaderno y el nombre de la página como parámetros.

    De la misma manera para la devolución de llamada "-on_delete" . Esta se invoca cuando la página es eliminada.

  • delete_page ( PÁGINA )

    Elimina la página especificada del objeto de cuaderno y destruye su objeto de ventana asociado. Si la página estaba activa, la primera página se hace activa.

  • active_page ( )

    Devuelve la página actualmente activa en el objeto de cuaderno.

  • first_page ( )

    Devuelve la primera página en el objeto de cuaderno.

  • last_page ( )

    Devuelve la última página en el objeto de cuaderno.

  • prev_page ( )

    Devuelve la página anterior en el objeto de cuaderno.

  • next_page ( )

    Devuelve la siguiente página en el objeto de cuaderno.

  • activate_page ( PÁGINA )

    Hace que la página especificada en el objeto de cuaderno esté activa y la devuelve, redibujando el objeto de cuaderno en el proceso.

  • mouse_button1 ( )

    Procesa los clics del botón #1 del ratón. Si el usuario hace clic izquierdo en una de las pestañas, activate_page se llama con la página correspondiente para hacerla activa; de lo contrario, el clic se pasa a la ventana activa.
