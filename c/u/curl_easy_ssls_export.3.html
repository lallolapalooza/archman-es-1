DESCRIPCIÓ

N

Esta función itera sobre todos los tickets de sesión SSL que pertenecen al manejo fácil e invoca el callback export_fn en cada uno de ellos, siempre que el callback devuelva CURLE_OK

.

El callback puede entonces almacenar esta información y usar curl_easy_ssls_import(3) en otra instancia de libcurl para añadir tickets de sesión SSL nuevamente. La reutilización de tickets de sesión SSL puede resultar en acuerdos más rápidos y algunas conexiones podrían poder enviar datos de solicitud en los paquetes iniciales (0-RTT)

.

De todos los parámetros pasados al export_fn solo dos necesitan ser persistidos: ya sea session_key o shamc y siempre sdata. Todos los demás parámetros son informativos, p. ej. permiten que el callback actúe solo sobre tickets de sesión

específicos.

Tenga en cuenta que las sesiones SSL que invol

ucran un certificado de cliente o un nombr
e de usuario/contraseña SRP no son exportadas.

Sesión
Esta es una cadena imprimible, terminada con nulo, que comienza con hostname:port (nombre de host:puerto) del que proviene el ticket de sesión y también contiene todos los parámetros SSL relevantes usados en la conexión. La clave también lleva el nombre y el número de versión del backend TLS usado.

Se recomienda persistir solo session_key cuando pueda protegerse del acceso externo. Dado que el nombre de host aparece en texto plano, permitiría a cualquier tercero ver para qué se ha usado

curl.

Un blob binario de shmac_len bytes que contiene una sal aleatoria y un hash criptográfico de la sal y session_key. La sal es generada individualmente para cada sesión. Almacenar shmac es recomendado, por ejemplo, al colocar los tickets de sesión en un archivo.

PROTOCOLO

S

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS,

etc.

Esta opción funciona solo con lo

s siguientes backends TLS: GnuTLS
, OpenSSL, mbedTLS y wolfSSL

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  CURLcode rc;
  CURL *curl;
  sh = curl_share_setopt(share, CURLSHOPT_SHARE, CURL_LOCK_DATA_SSL_SESSION);
  if(sh)
    printf("Error: %s\n", curl_share_strerror(sh));
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_SHARE, share);
    /* ejecutar una transferencia, todas las sesiones TLS recibidas serán
     * añadidas al recurso compartido. */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_perform(curl);
    /* exportar las sesiones TLS recopiladas en el recurso compartido */
    rc = curl_easy_ssls_export(curl, my_export_cb, NULL);
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
  curl_share_cleanup(share);
}

el búfer de error cuando se de
vuelve un valor distinto de cero.
