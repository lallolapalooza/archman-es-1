Curses::UI::Color(3) Documentación de Perl contribuida por el usuario Curses::UI::Color(3)

NOMBRE

Curses::UI::Color - Módulo de soporte de color

ADVERTENCIA

Esta es una versión de desarrollo. Como no espero cambiar la interfaz durante este tiempo, puede ocurrir que el comportamiento del color (por ejemplo, hasta qué punto se dibuja el color en una ventana) pueda cambiar o incluso los colores mismos. Si desea algo estable, use -color_support => 0, ¡pero entonces no obtendrá esos colores elegantes :-)

DESCRIPCIÓN

Este módulo proporciona todas las funciones relacionadas con el soporte de color en Curses::UI. El soporte de color se implementó sin perturbar las aplicaciones antiguas; se verán como solían hacerlo. Solo si habilita el soporte de color explícitamente y está disponible en su terminal, las funciones de color tendrán efecto.

SINOPSIS

my $cui = new Curses::UI(-color_support => 1,
-clear_on_exit => 0);

my $mainw = $cui->add('screen', 'Window');

$mainw->add('l','Label', -bg => "white",
-fg => "blue",
-text => "Etiqueta coloreada");

MÉTODOS

  • new (-default-colors => BOOLEAN)

    Crea un nuevo objeto Curses::UI::Color; la opción default colors define si se utiliza la función use_default_colors de Curses. Consulte Curses para eso.

  • get_colors ( )

    Devuelve todos los colores definidos en este objeto como un array.

  • colors ( )

    Es verdadero si el soporte de color está habilitado.

  • define_color ( NOMBRE, R, G, B )

    Esta función define un nuevo color en el objeto Color. Los valores RGB pueden estar entre 0 y 1000. Los colores existentes se pueden redefinir.

USO

Curses::UI tiene 7 colores predefinidos:
black
red
green
yellow
blue
magenta
cyan
white

Curses::UI con soporte de color también define algunas opciones nuevas:

 -fg  -bg para color de primer plano y fondo general.
-tfg -tbg para color de primer plano y fondo del título del widget
-bfg -bbg para color de primer plano y fondo del borde del widget
-sfg -sbg para color de primer plano y fondo de la barra de desplazamiento

Cada widget tiene un configurador en tiempo de ejecución:
set_color_fg ( COLOR )
set_colof_bg ( COLOR )
set_color_tfg ( COLOR )
set_colof_tbg ( COLOR )
set_color_bfg ( COLOR )
set_colof_bbg ( COLOR )
set_color_sfg ( COLOR )
set_colof_sbg ( COLOR )

La mayoría de los widgets tienen una opción -fg y -bg para establecer el color de primer plano y fondo usando los nombres de color anteriores. Los colores propios se pueden definir usando el método define_color. Todos los widgets que soportan color ahora también tienen dos funciones set_color_fg y set_color_bg para establecer o cambiar el color en tiempo de ejecución. Los widgets con bordes y barras de desplazamiento pueden usar -bfg y -bbg para establecer el color de primer plano y fondo del borde o la opción -sfg y -sbg para establecer los colores de la barra de desplazamiento. Los widgets con títulos pueden establecer la opción -tfg y -tbg para definir el color de primer plano y fondo del título.

Consulte también el ejemplo examples/color_editor para ver lo que es posible en este momento.
