DESCRIPCIÓ

N

Obtener la información guardada en el manejador de curl. El tercer argumento DEBE apuntar al tipo específico de la opción utilizada que está documentada en cada página de manual de la opción info. Los datos se almacenan en consecuencia y solo se pueden confiar si esta función devuelve CURLE_OK. Utilice esta función después de una transferencia realizada si desea obtener datos relacionados con la

transferencia.

No debe liberar la memoria devuelta p

or esta función a menos que se me
ncione explícitamente a continuación.

EJEMPL

O 
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://www.example.com/");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      char *ct;
      /* solicitar el content-type */
      res = curl_easy_getinfo(curl, CURLINFO_CONTENT_TYPE, &ct);
      if((CURLE_OK == res) && ct)
        printf("Hemos recibido Content-Type: %s\n", ct);
    }
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
}
