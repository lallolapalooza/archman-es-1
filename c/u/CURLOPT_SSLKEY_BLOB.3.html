CURLOPT_SSLKEY_BLOB(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSLKEY_BLOB(3) Manual de funciones de biblioteca CURLOPT_SSLKEY_BLOB(3)

NOMBRE

CURLOPT_SSLKEY_BLOB - clave privada para el certificado de cliente desde un blob de memoria

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLKEY_BLOB,
                          struct curl_blob *blob);

DESCRIPCIÓN

Pase un puntero a una estructura curl_blob, que contiene información (puntero y tamaño) para una clave privada. Compatible con OpenSSL. El formato (como "PEM") debe especificarse con CURLOPT_SSLKEYTYPE(3).

Si el blob se inicializa con el miembro flags de la estructura struct curl_blob establecido en CURL_BLOB_COPY, la aplicación no tiene que mantener el búfer disponible después de establecer esto.

Esta opción es una alternativa a CURLOPT_SSLKEY(3), que en su lugar espera un nombre de archivo como entrada.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL y wolfSSL

EJEMPLO

extern char *certificateData; // apunta al certificado
extern size_t filesize; // tamaño del certificado
extern char *privateKeyData; // apunta a la clave
extern size_t privateKeySize; // tamaño de la clave
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    blob.data = certificateData;
    blob.len = filesize;
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_SSLCERT_BLOB, &blob);
    curl_easy_setopt(curl, CURLOPT_SSLCERTTYPE, "PEM");
    blob.data = privateKeyData;
    blob.len = privateKeySize;
    curl_easy_setopt(curl, CURLOPT_SSLKEY_BLOB, &blob);
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    curl_easy_setopt(curl, CURLOPT_SSLKEYTYPE, "PEM");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.71.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
