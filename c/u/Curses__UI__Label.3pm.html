Curses::UI::Label(3) Documentación de Perl aportada por el usuario Curses::UI::Label(3)

NOMBRE

Curses::UI::Label - Crear y manipular widgets de etiqueta

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Label

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $label = $win->add(
    'mylabel', 'Label',
    -text      => '¡Hola, mundo!',
    -bold      => 1,
);
$label->draw;

DESCRIPCIÓN

Curses::UI::Label es un widget que muestra una cadena de texto. Esta cadena de texto se puede mostrar utilizando estas características especiales: negrita, atenuado, inverso, subrayado y parpadeo.

Consulta los ejemplos/demo-Curses::UI::Label en la distribución para una demostración corta.

OPCIONES ESTÁNDAR

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

Para una explicación de estas opciones estándar, consulta Curses::UI::Widget.

OPCIONES ESPECÍFICAS DEL WIDGET

  • -height < VALOR >

    Si no defines -height, la etiqueta calculará la altura necesaria utilizando el -text inicial.

  • -text < TEXTO >

    Esto establecerá el texto de la etiqueta en TEXTO.

  • -textalignment < VALOR >

    Esta opción controla cómo se debe alinear el texto dentro de la etiqueta. VALOR puede ser 'left', 'middle' y 'right'. El valor por defecto para esta opción es 'left'.

  • -paddingspaces < BOOLEAN >

    Esta opción controla si se deben agregar espacios de relleno al texto si este no llena el ancho completo del widget. El valor por defecto para BOOLEAN es falso. Un ejemplo de uso de esta opción es:

    $win->add(
    'label', 'Label',
    -width         => -1,
    -paddingspaces => 1,
    -text          => 'Un poco de texto',
);

    Esto creará una etiqueta que llena el ancho completo de tu pantalla y que estará completamente en fuente inversa (incluso la parte que no tiene texto). Consulta la demostración en la distribución (examples/demo-Curses::UI::Label) para un ejemplo claro de esto)

  • -bold < BOOLEAN >

    Si BOOLEAN es verdadero, el texto de la etiqueta se mostrará en fuente negrita.

  • -dim < BOOLEAN >

    Si BOOLEAN es verdadero, el texto de la etiqueta se mostrará en fuente atenuada.

  • -reverse < BOOLEAN >

    Si BOOLEAN es verdadero, el texto de la etiqueta se mostrará en fuente inversa.

  • -underline < BOOLEAN >

    Si BOOLEAN es verdadero, el texto de la etiqueta se mostrará subrayado.

  • -blink < BOOLEAN >

    Si la opción BOOLEAN es verdadera, el texto de la etiqueta se mostrará en fuente parpadeante.

MÉTODOS

  • new ( OPCIONES )
  • layout ( )
  • draw ( BOOLEAN )
  • intellidraw ( )
  • focus ( )
  • onFocus ( CODEREF )
  • onBlur ( CODEREF )

    Estos son métodos estándar. Consulta Curses::UI::Widget para una explicación de estos.

  • bold ( BOOLEAN )
  • dim ( BOOLEAN )
  • reverse ( BOOLEAN )
  • underline ( BOOLEAN )
  • blink ( BOOLEAN )

    Estos métodos se pueden utilizar para controlar la fuente en la que se muestra el texto de la etiqueta, después de crear el widget. La opción de fuente se activará para un valor verdadero de BOOLEAN.

  • textalignment ( VALOR )

    Establece la alineación del texto. VALOR puede ser 'left', 'middle' o 'right'.

  • text ( [TEXTO] )

    Sin el argumento TEXTO, este método devolverá el texto actual del widget. Con un argumento TEXTO, el texto del widget se establecerá en TEXTO.

  • get ( )

    Esto llamará al método text sin ningún argumento y, por lo tanto, devolverá el texto actual de la etiqueta.

ASIGNACIONES POR DEFECTO

Dado que una etiqueta es un widget no interactivo, no tiene ninguna asignación.
