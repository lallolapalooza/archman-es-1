NOMBRE

getyx, getparyx, getbegyx, getmaxyx - obtener coordenadas de cursor y ventana de curses

SINOPSIS

#include <curses.h>
void getyx(WINDOW *win, int y, int x);
void getparyx(WINDOW *win, int y, int x);
void getbegyx(WINDOW *win, int y, int x);
void getmaxyx(WINDOW *win, int y, int x);

DESCRIPCIÓN

La macro getyx coloca la posición actual del cursor de la ventana dada en las dos variables enteras y y x.

Si win es una subventana, la macro getparyx coloca las coordenadas de inicio de la subventana relativas a la ventana padre en dos variables enteras y y x. De lo contrario, se coloca -1 en y y x.

Al igual que getyx, las macros getbegyx y getmaxyx almacenan las coordenadas de inicio actuales y el tamaño de la ventana especificada.

VALOR DE RETORNO

Los valores de retorno de estas macros no están definidos (es decir, no deben usarse como el lado derecho de las sentencias de asignación).

NOTAS

Todas estas interfaces son macros. No es necesario un “&” antes de las variables y y x.

PORTABILIDAD

Las macros getyx, getparyx, getbegyx y getmaxyx se describen en X/Open Curses, Issue 4.

Esta implementación también proporciona las funciones getbegx, getbegy, getcurx, getcury, getmaxx, getmaxy, getparx y getpary para la compatibilidad con versiones anteriores de curses; ver curs_legacy(3X).

Aunque X/Open Curses no aborda esto, muchas implementaciones proporcionan miembros de la estructura WINDOW que contienen valores correspondientes a estas macros. Para una mejor portabilidad, no confíe en el uso de los datos en WINDOW, ya que algunas implementaciones hacen que WINDOW sea opaco (no permiten el uso directo de sus miembros).

Además del problema de las estructuras opacas, los datos almacenados en miembros con nombres similares pueden no tener valores similares en diferentes implementaciones. Por ejemplo, los valores WINDOW._maxx y WINDOW._maxy en ncurses han diferido (al menos desde la versión 1.8.1) en uno respecto a algunas otras implementaciones. La diferencia se oculta mediante la macro getmaxyx.
