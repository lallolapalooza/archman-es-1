curl_global_init_mem(3)

Paquete: curl

Licencias: MIT

curl_global_init_mem(3) Manual de funciones de la biblioteca curl_global_init_mem(3)

NOMBRE

curl_global_init_mem - inicialización global de libcurl con devoluciones de llamada de memoria

SINOPSIS

#include <curl/curl.h>
CURLcode curl_global_init_mem(long flags,
                              curl_malloc_callback m,
                              curl_free_callback f,
                              curl_realloc_callback r,
                              curl_strdup_callback s,
                              curl_calloc_callback c);

DESCRIPCIÓN

Esta función funciona exactamente igual que curl_global_init(3) con una adición: permite a la aplicación establecer devoluciones de llamada para reemplazar las funciones de memoria internas utilizadas de otro modo.

Si estás usando libcurl desde múltiples hilos o libcurl fue compilado con la opción de resolución de nombres con subprocesos, entonces las funciones de devolución de llamada deben ser seguras para hilos. La resolución de nombres con subprocesos es una opción de compilación común para habilitar (y en algunos casos, el valor predeterminado), por lo que instamos encarecidamente a que tus funciones de devolución de llamada sean seguras para hilos.

Todos los argumentos de devolución de llamada deben establecerse en punteros de función válidos. Los prototipos para las devoluciones de llamada dadas deben coincidir con estos:

void *malloc_callback(size_t size);
Para reemplazar malloc()
void free_callback(void *ptr);
Para reemplazar free()
void *realloc_callback(void *ptr, size_t size);
Para reemplazar realloc()
char *strdup_callback(const char *str);
Para reemplazar strdup()
void *calloc_callback(size_t nmemb, size_t size);
Para reemplazar calloc()

Esta función es, de lo contrario, igual que curl_global_init(3), consulta esa página del manual para obtener documentación.

PRECAUCIÓN

Manipular esto otorga poderes considerables a la aplicación para meterla en graves problemas con libcurl. Ten cuidado.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

extern void *malloc_cb(size_t);
extern void free_cb(void *);
extern void *realloc_cb(void *, size_t);
extern char *strdup_cb(const char *);
extern void *calloc_cb(size_t, size_t);
int main(void)
{
  curl_global_init_mem(CURL_GLOBAL_DEFAULT, malloc_cb,
                       free_cb, realloc_cb,
                       strdup_cb, calloc_cb);
}

DISPONIBILIDAD

Añadido en curl 7.12.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error. Consulte libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el búfer de error cuando se devuelve un valor distinto de cero.
