CURLOPT_MIMEPOST(3)

Paquete: curl

Licencias: MIT

CURLOPT_MIMEPOST(3) Manual de funciones de biblioteca CURLOPT_MIMEPOST(3)

NOMBRE

CURLOPT_MIMEPOST - enviar datos desde la estructura mime

SINOPSIS

#include <curl/curl.h>
curl_mime *mime;
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MIMEPOST, mime);

DESCRIPCIÓN

Pase un manejador mime obtenido previamente de curl_mime_init(3).

Esta configuración es compatible con el protocolo HTTP para enviar formularios y con los protocolos SMTP e IMAP para proporcionar los datos del correo electrónico a enviar/cargar.

Esta opción es la forma preferida de enviar un formulario HTTP, reemplazando y extendiendo la opción CURLOPT_HTTPPOST(3).

Al establecer CURLOPT_MIMEPOST(3) a NULL, libcurl restablece el tipo de solicitud para HTTP a su valor predeterminado para deshabilitar el POST. Típicamente, esto significaría que se restablece a GET. En su lugar, debe establecer explícitamente el método de solicitud deseado.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_mime *multipart = curl_mime_init(curl);
    if(multipart) {
      curl_mimepart *part = curl_mime_addpart(multipart);
      curl_mime_name(part, "name");
      curl_mime_data(part, "daniel", CURL_ZERO_TERMINATED);
      part = curl_mime_addpart(multipart);
      curl_mime_name(part, "project");
      curl_mime_data(part, "curl", CURL_ZERO_TERMINATED);
      part = curl_mime_addpart(multipart);
      curl_mime_name(part, "logotype-image");
      curl_mime_filedata(part, "curl.png");
      /* Establecer la información del formulario */
      curl_easy_setopt(curl, CURLOPT_MIMEPOST, multipart);
      curl_easy_perform(curl); /* enviar */
      curl_mime_free(multipart); /* liberar los datos del post */
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Devuelve CURLE_OK.
