CURLOPT_POSTQUOTE(3)

Paquete: curl

Licencias: MIT

CURLOPT_POSTQUOTE(3) Manual de funciones de la biblioteca CURLOPT_POSTQUOTE(3)

NOMBRE

CURLOPT_POSTQUOTE - (S)FTP comandos a ejecutar después de la transferencia

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_POSTQUOTE,
                          struct curl_slist *cmds);

DESCRIPCIÓN

Pase un puntero a una lista enlazada de comandos FTP o SFTP que se enviarán al servidor después de su solicitud de transferencia FTP. Los comandos solo se ejecutan si no ocurren errores. La lista enlazada debe ser una lista completamente válida de estructuras struct curl_slist llenas correctamente, tal como se describe para CURLOPT_QUOTE(3).

El uso de esta opción varias veces hace que la última lista establecida anule las anteriores. Establézcala a NULL para deshabilitar su uso nuevamente.

libcurl no copia la lista, debe mantenerse hasta después de que la transferencia se haya completado.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a ftp y sftp

EJEMPLO

int main(void)
{
  struct curl_slist *cmdlist = NULL;
  cmdlist = curl_slist_append(cmdlist, "RNFR source-name");
  cmdlist = curl_slist_append(cmdlist, "RNTO new-name");
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/foo.bin");
    /* pasar los comandos FTP a ejecutar después de la transferencia */
    curl_easy_setopt(curl, CURLOPT_POSTQUOTE, cmdlist);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
  curl_slist_free_all(cmdlist);
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, distinto de cero significa que ocurrió un error, ver libcurl-errors(3).
