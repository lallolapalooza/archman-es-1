curl_multi_timeout(3)

Paquete: curl

Licencias: MIT

curl_multi_timeout(3) Manual de funciones de la biblioteca curl_multi_timeout(3)

NOMBRE

curl_multi_timeout - cuánto esperar por una acción antes de continuar

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_timeout(CURLM *multi_handle, long *timeout);

DESCRIPCIÓN

Una aplicación que utiliza la interfaz múltiple de libcurl debe llamar a curl_multi_timeout(3) para determinar cuánto tiempo debe esperar por acciones en sockets - como máximo - antes de continuar.

Continuar significa realizar la acción de tiempo de espera de sockets: llamar a la función curl_multi_socket_action(3) con el argumento sockfd establecido en CURL_SOCKET_TIMEOUT, o llamar a curl_multi_perform(3) si está utilizando el enfoque más simple y antiguo de la interfaz múltiple.

El valor de tiempo de espera devuelto en el puntero timeout está en milisegundos en este momento. Si es 0, significa que debe continuar inmediatamente sin esperar nada. Si devuelve -1, no hay ningún tiempo de espera establecido.

Una aplicación que utiliza la API multi_socket no debe utilizar esta función. En su lugar, debe utilizar la opción CURLMOPT_TIMERFUNCTION(3) para un comportamiento adecuado y deseado.

Nota: si libcurl devuelve un tiempo de espera de -1 aquí, solo significa que libcurl actualmente no tiene ningún valor de tiempo de espera almacenado. No debe esperar demasiado (más de unos pocos segundos, tal vez) antes de volver a llamar a curl_multi_perform(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  struct timeval timeout;
  long timeo;
  fd_set fdread;
  fd_set fdwrite;
  fd_set fdexcep;
  int maxfd = 2;
  CURLM *multi = curl_multi_init();
  curl_multi_timeout(multi, &timeo);
  if(timeo < 0)
    /* no hay tiempo de espera establecido, usar uno predeterminado */
    timeo = 980;
  timeout.tv_sec = timeo / 1000;
  timeout.tv_usec = (timeo % 1000) * 1000;
  /* esperar actividades no más de el tiempo de espera establecido */
  select(maxfd + 1, &fdread, &fdwrite, &fdexcep, &timeout);
}

USO TIPICO

Llame a curl_multi_timeout(3), luego espere una acción en los sockets. Determine qué sockets esperar llamando a curl_multi_fdset(3).

Cuando haya actividad o tiempo de espera agotado, llame a curl_multi_perform(3) y luego repita el ciclo, hasta que todas las transferencias se completen.

DISPONIBILIDAD

Añadido en curl 7.15.4

VALOR DE RETORNO

Esta función devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
