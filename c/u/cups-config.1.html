NOMBRE

cups-config - obtener información de la API, compilador, directorio y enlace de cups (obsoleto).

SINOPSIS

cups-config --api-version
cups-config --build
cups-config --cflags
cups-config --datadir
cups-config --help
cups-config --ldflags
cups-config [ --image ] [ --static ] --libs
cups-config --serverbin
cups-config --serverroot
cups-config --version

DESCRIPCIÓN

El comando cups-config permite a los desarrolladores de aplicaciones determinar las opciones de línea de comandos necesarias para el compilador y el enlazador, así como los directorios de instalación para filtros, archivos de configuración y controladores. Todos los valores se informan a la salida estándar. Nota: Este comando está obsoleto y se eliminará en una futura versión de CUPS. Se debe usar el comando pkg-config(1) en su lugar.

OPCIONES

El comando cups-config acepta las siguientes opciones de línea de comandos:

--api-version
Informa la versión actual de la API (mayor.menor).
--build
Informa un número de compilación específico del sistema.
--cflags
Informa las opciones necesarias del compilador.
--datadir
Informa el directorio de datos predeterminado de CUPS.
--help
Informa el mensaje de uso del programa.
--ldflags
Informa las opciones necesarias del enlazador.
--libs
Informa las bibliotecas necesarias para enlazar.
--serverbin
Informa el directorio de binarios predeterminado de CUPS, donde se almacenan los filtros y backends.
--serverroot
Informa el directorio de archivos de configuración predeterminado de CUPS.
--static
Cuando se usa con --libs, informa las bibliotecas estáticas en lugar de las bibliotecas predeterminadas (compartidas).
--version
Informa el número de versión completo de la instalación de CUPS (mayor.menor.parche).

EJEMPLOS

Mostrar la versión actualmente instalada de CUPS:

    cups-config --version

Compilar un filtro simple de CUPS de un solo archivo:

    cc `cups-config --cflags --ldflags` -o filter filter.c \
        `cups-config --libs`

OPCIONES OBSOLETAS

Las siguientes opciones están obsoletas pero siguen funcionando por compatibilidad hacia atrás:

--image
Anteriormente se usaba para agregar la biblioteca de imágenes de CUPS a la lista de bibliotecas.

VER TAMBIÉN
