curl_formfree(3)

Paquete: curl

Licencias: MIT

curl_formfree(3) Manual de funciones de la biblioteca curl_formfree(3)

NOMBRE

curl_formfree - libera una cadena de formulario POST multipart construida previamente

SINOPSIS

#include <curl/curl.h>
void curl_formfree(struct curl_httppost *form);

DESCRIPCIÓN

Esta función está obsoleta. No la use. Consulte curl_mime_init(3) en su lugar.

curl_formfree() se utiliza para limpiar los datos construidos/añadidos previamente con curl_formadd(3). Esto debe llamarse cuando los datos se han utilizado, lo que normalmente significa después de que se haya llamado a curl_easy_perform(3).

El puntero a liberar es el mismo puntero que pasó a la opción CURLOPT_HTTPPOST(3), que es el puntero firstitem de la(s) llamada(s) a curl_formadd(3).

form es el puntero devuelto por una llamada anterior a curl_formadd(3) y puede ser NULL.

Pasar un puntero NULL en form hace que esta función regrese inmediatamente sin realizar ninguna acción.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_httppost *formpost;
    struct curl_httppost *lastptr;
    /* Rellenar un campo de carga de archivo */
    curl_formadd(&formpost,
                 &lastptr,
                 CURLFORM_COPYNAME, "file",
                 CURLFORM_FILE, "nice-image.jpg",
                 CURLFORM_END);
    curl_easy_setopt(curl, CURLOPT_HTTPPOST, formpost);
    curl_easy_perform(curl);
    /* luego limpiar la cadena formpost */
    curl_formfree(formpost);
  }
}

OBSOLETO

Obsoleto en la versión 7.56.0.

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Ninguno
