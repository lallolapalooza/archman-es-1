CURLOPT_DOH_URL(3)

Paquete: curl

Licencias: MIT

CURLOPT_DOH_URL(3) Manual de Funciones de Biblioteca CURLOPT_DOH_URL(3)

NOMBRE

CURLOPT_DOH_URL - proporcionar la URL de DNS-sobre-HTTPS

SINAPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DOH_URL, char *URL);

DESCRIPCIÓN

Pase un puntero a una URL para el servidor DoH a utilizar para la resolución de nombres. El parámetro debe ser un puntero a char que apunte a una cadena terminada en null, que debe ser una URL HTTPS válida y correcta.

libcurl no valida la sintaxis ni utiliza esta variable hasta que se emite la transferencia. Incluso si establece un valor disparatado aquí, curl_easy_setopt(3) todavía devuelve CURLE_OK.

curl envía solicitudes POST a la URL de DNS-sobre-HTTPS dada.

Para encontrar el propio servidor DoH, que podría especificarse usando un nombre, libcurl utiliza la función de búsqueda de nombres por defecto. Puede iniciar eso proporcionando la dirección del servidor DoH con CURLOPT_RESOLVE(3).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida supere a las anteriores. Establécela a NULL para deshabilitar su uso de nuevo.

OPCIONES HEREDADAS

Las búsquedas DoH utilizan SSL y algunas configuraciones SSL de su transferencia se heredan, como CURLOPT_SSL_CTX_FUNCTION(3).

El nombre de host y la configuración de verificación de certificados del par no se heredan, pero se pueden controlar por separado a través de CURLOPT_DOH_SSL_VERIFYHOST(3) y CURLOPT_DOH_SSL_VERIFYPEER(3).

Una función de devolución de llamada CURLOPT_OPENSOCKETFUNCTION(3) establecida no se hereda.

ERRORES CONOCIDOS

Incluso cuando DoH está configurado para ser utilizado con esta opción, todavía hay algunas búsquedas de nombres que se realizan sin él, utilizando el mecanismo de resolución de nombres por defecto. Esto incluye búsquedas de nombres realizadas para CURLOPT_INTERFACE(3), CURLOPT_FTPPORT(3), un tipo de proxy establecido en CURLPROXY_SOCKS4 o CURLPROXY_SOCKS5 y probablemente algunos más.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_DOH_URL, "https://dns.example.com");
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.62.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).

Tenga en cuenta que curl_easy_setopt(3) analiza inmediatamente la cadena proporcionada, por lo que al recibir una URL DoH incorrecta, libcurl podría no detectar el problema hasta que más tarde intente resolver un nombre con ella.

VER TAMBIÉN
