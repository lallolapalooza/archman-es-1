Curses::UI::Tutorial

- Tutorial para el
framework Curses::UI

Introducció

n

La intención de este tutorial es ofrecer una visión general rápida

de Curses::UI y sus widgets. El objetivo de este ejemplo es esc
ribir un editor de texto simple usando el framework Curses::UI.

Primeros

requisitos

Para usar Curses::UI, comience su programa con "use Curses::UI;" y, como siempre es una buena idea,
agregue "use strict" y el interruptor -w también. Después de eso, se debe crear una instancia de Curses::UI. A partir de ahora, esta instancia se llamará "la UI". También querrá redirigir STDERR a un archivo (por ejemplo, perl myscript.pl 2> debug.out), para que la salida que no proviene de Curses::UI no arruine su pantalla. Quiere colores elegantes, así que la opción -color_support se establece en un valor

verdadero. 
#!/usr/bin/perl -w
use strict;
use Curses::UI;
my $cui = new Curses::UI( -color_support => 1
)
;

Crear un

menú 
my @menu = (
  { -label => 'File', 
    -submenu => [
   { -label => 'Exit      ^Q', -value => \&exit_dialog  }
                ]
   },
)
;

Para describir la estructura de un menú, Curses::UI usa una construcción bastante fea de hashrefs y arrayrefs. Vea Curses::UI:

:Menubar para detalles. Lo que hace en este punto es crear una barra de menús con una sola entrada y un submenú. La entra
da es 'File' y el submenú es 'Exit'. El valor de este elemento del menú es una referencia a una subrutina llamada exit_dialog.

Diálogo

s 
sub exit_dialog()
{
        my $return = $cui->dialog(
                -message   => "Do you really want to quit?",
                -title     => "Are you sure???", 
                -buttons   => ['yes', 'no'],
        );
exit(0) if $return;
}

El método dialog de Curses::UI nos da una forma fácil y conveniente de crear diálogos en la pantalla principal. Un diálogo es una forma de

interactuar con el usuario para hacerle una pregunta o darle información importante. Este diálogo es uno más complejo, que pregunta si
realmente quiere salir. Como el botón para "yes" nos devolvería un valor verdadero, puede salir fácilmente con este valor de retorno.

Agregar la barra de

menús 
my $menu = $cui->add(
        'menu','Menubar', 
        -menu => \@menu,
        -fg  => "blue",
)
;

Para finalmente agregar la barra de menús a nuestro objeto raíz, tiene que llamar al método add en el objeto Curses UI. Especifica el nombre interno del widget como prime

r argumento, el tipo de widget como segundo argumento (como Label, TextViewer, etc.) y la estructura del menú que creó al principio como una referencia a un array como t
ercer objeto. Como quiere que la barra de menús tenga un tema azul, le da la opción -fg "blue". Hay un par de colores que puede usar, vea Curses::UI::Color para detalles.

Agregar una

ventana 
my $win1 = $cui->add(
                     'win1', 'Window',
                     -border => 1,
                     -y    => 1,
                     -bfg  => 'red',
             )
;

Solo hay dos tipos de objetos que puede agregar al objeto raíz de Curses::UI: barras de menús y ventanas. Todos los demás widgets deben insertarse en una ventana. Por supuesto, puede agregar una barra de menús a una ventana, pero no viceversa ;-).

El método add siempre tiene los mismos dos primeros argumentos: el nombre interno y el tipo de widget. El nombre interno se puede usar para encontrar un objeto. El método getobj toma este nombre y nos devuelve el objeto correspondiente de
la jerarquía. Vea Curses::UI para detalles. De nuevo, quiere algunos colores elegantes, así que le dice a la ventana que tenga un borde, deja algo de espacio para la barra de menús (-y => 1) y establece el color de primer plano del borde en rojo.

Agregar un

widget 
my $texteditor = $win1->add("text", "TextEditor",
                         -text => "Here is some text\n"
                                . "And some more")
;

El siguiente paso es agregar un widget útil a nuestra pequeña aplicación Curses

::UI. Aquí toma un widget TextEditor que realiza tareas básicas como un editor
de texto. Agrega algo de texto inicial al widget para que no parezca tan vacío.

Hacer enlaces de

teclas 
$cui->set_binding(sub {$menu->focus()}, "\cX");
$cui->set_binding( \&exit_dialog , "\cQ")
;

Quiere poder enfocar la barra de menús cuando haya terminado de editar en el widget TextEditor. Por lo tanto, establece un enlace a la función fo

cus del menú y la secuencia de teclas Control (especificada por \c) combinada con X. Ahora puede volver fácilmente al menú después de editar.
Como es más fácil tener un atajo para cerrar la aplicación, agrega un enlace para la secuencia Control-Q a nuestro bonito método exit_dialog.

Los pasos

finales 
$texteditor->focus();
$cui->mainloop()
;

Quiere comenzar a editar directamente. Por lo tanto, establece el foco inicial en e

l TextEditor llamando directamente a su método focus. Lo último que tiene que hacer
es decirle a Curses que ahora controla el flujo del programa iniciando su MainLoop.

¡Ha

terminado!

¡Ha creado una aplicación Curses::UI genuina! No es que sea una muy útil, pero ¿a quién le importa? Ahora pruebe si funciona como cree que debería. El código fuente completo de esta aplicación se encuentra en el directorio examples de la distribución (examples/tutorial.pl)

.

Ahora puede mejorar esta aplicación

para convertirla en un editor con to
das las funciones como Emacs :-)
