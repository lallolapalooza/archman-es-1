CURLOPT_REDIR_PROTOCOLS(3)

Paquete: curl

Licencias: MIT

CURLOPT_REDIR_PROTOCOLS(3) Manual de funciones de la biblioteca CURLOPT_REDIR_PROTOCOLS(3)

NOMBRE

CURLOPT_REDIR_PROTOCOLS - protocolos permitidos para redirigir

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_REDIR_PROTOCOLS, long bitmask);

DESCRIPCIÓN

Esta opción está obsoleta. Recomendamos encarecidamente usar CURLOPT_REDIR_PROTOCOLS_STR(3) en su lugar, ya que esta opción no puede controlar todos los protocolos disponibles.

Pase un long que contenga una máscara de bits de protocolos. Si se utiliza, esta máscara de bits limita qué protocolos puede utilizar libcurl en una transferencia que sigue en una redirección cuando CURLOPT_FOLLOWLOCATION(3) está habilitado. Esto le permite limitar transferencias específicas para que solo puedan usar un subconjunto de protocolos en las redirecciones.

Los protocolos denegados por CURLOPT_PROTOCOLS(3) no se ven afectados por esta opción.

Por defecto, libcurl permite HTTP, HTTPS, FTP y FTPS en la redirección (7.65.2). CURLPROTO_ALL habilita todos los protocolos en la redirección, incluidos aquellos que de otro modo estarían deshabilitados por seguridad.

Estas son las definiciones de protocolo disponibles:

CURLPROTO_FILE
CURLPROTO_FTP
CURLPROTO_FTPS

CURLPROTO_HTTP

CURLPROTO_POP3
CURLPROTO_POP3S
CURLPROTO_RTMP
CURLPROTO_RTMPE

POR DEFECTO

HTTP, HTTPS, FTP y FTPS (Añadido en 7.65.2).

Versiones anteriores por defecto permitían todos los protocolos excepto FILE, SCP y, desde 7.40.0, SMB y SMBS.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(int argc, char **argv)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* pasar la URL desde una fuente externa */
    curl_easy_setopt(curl, CURLOPT_URL, argv[1]);
    /* solo permitir redirecciones a URLs HTTP y HTTPS */
    curl_easy_setopt(curl, CURLOPT_REDIR_PROTOCOLS,
                     CURLPROTO_HTTP | CURLPROTO_HTTPS);
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

HISTORIAL

Las macros CURLPROTO_* se convirtieron en tipos long en la versión 8.16.0; antes de esta versión, era necesario un cast a long al pasarlos a curl_easy_setopt(3).

OBSOLETO

Obsoleto desde la versión 7.85.0.

DISPONIBILIDAD

Añadido en curl 7.19.4

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un código CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue correcto, cualquier otro valor indica que ocurrió un error; véase libcurl-errors(3).
