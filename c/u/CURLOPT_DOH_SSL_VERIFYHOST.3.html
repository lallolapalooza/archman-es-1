CURLOPT_DOH_SSL_VERIFYHOST(3)

Paquete: curl

Licencias: MIT

CURLOPT_DOH_SSL_VERIFYHOST(3) Manual de funciones de la biblioteca CURLOPT_DOH_SSL_VERIFYHOST(3)

NOMBRE

CURLOPT_DOH_SSL_VERIFYHOST - verificar el nombre de host en el certificado SSL de DoH

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DOH_SSL_VERIFYHOST,
                          long verify);

DESCRIPCIÓN

Pase un valor numérico (long) establecido en 2L para pedirle a curl que *verifique* los campos del nombre del certificado del servidor DoH (DNS-over-HTTPS) frente al nombre de host.

Esta opción es el equivalente DoH de CURLOPT_SSL_VERIFYHOST(3) y solo afecta a las solicitudes al servidor DoH.

Cuando CURLOPT_DOH_SSL_VERIFYHOST(3) se establece en 2, el certificado SSL proporcionado por el servidor DoH debe indicar que el nombre del servidor es el mismo que el nombre del servidor al que se pretendía conectar, o la conexión fallará.

curl considera que el servidor DoH es el previsto cuando el campo Common Name o un campo Subject Alternate Name en el certificado coincide con el nombre de host en la URL de DoH a la que le dijo a curl que se conectara.

Cuando el valor de verify se establece en 1L, se trata de la misma manera que 2L. Sin embargo, para mantener la coherencia con las otras opciones VERIFYHOST, sugerimos usar 2 y no 1.

Cuando el valor de verify se establece en 0L, la conexión se realiza correctamente independientemente de los nombres utilizados en el certificado. Utilice esa capacidad con precaución.

Vea también CURLOPT_DOH_SSL_VERIFYPEER(3) para verificar la firma digital del certificado del servidor DoH.

PREDETERMINADO

2

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Todos los backends TLS soportan esta opción.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_DOH_URL,
                     "https://cloudflare-dns.com/dns-query");
    /* Desactivar la verificación del nombre de host del servidor DoH */
    curl_easy_setopt(curl, CURLOPT_DOH_SSL_VERIFYHOST, 0L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.76.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
