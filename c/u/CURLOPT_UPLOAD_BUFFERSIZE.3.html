CURLOPT_UPLOAD_BUFFERSIZE(3)

Paquete: curl

Licencias: MIT

CURLOPT_UPLOAD_BUFFERSIZE(3) Manual de funciones de biblioteca CURLOPT_UPLOAD_BUFFERSIZE(3)

NOMBRE

CURLOPT_UPLOAD_BUFFERSIZE - tamaño del búfer de carga

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_UPLOAD_BUFFERSIZE, long size);

DESCRIPCIÓN

Pase un `long` especificando su tamaño preferido (en bytes) para el búfer de carga en libcurl. Hace que libcurl utilice un búfer más grande que se pasa a la siguiente capa de la pila para ser enviado. En algunas configuraciones y para algunos protocolos, tener un búfer de carga más grande tiene un gran beneficio de rendimiento.

Esto se trata solo como una solicitud, no como una orden. No se le puede garantizar que reciba el tamaño dado.

El tamaño del búfer de carga es de 64 kilobytes por defecto. El tamaño máximo de búfer permitido para establecer es de 2 megabytes. El tamaño mínimo de búfer permitido para establecer es de 16 kilobytes.

El búfer de carga se asigna sobre la marcha, por lo que si el controlador no se utiliza para la carga, este búfer no se asigna en absoluto.

NO establezca esta opción en un controlador que se esté utilizando actualmente para una transferencia activa, ya que esto puede provocar consecuencias imprevistas.

POR OMISIÓN

65536 bytes

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/foo.bin");
    /* solicitar a libcurl que asigne un búfer de carga más grande */
    curl_easy_setopt(curl, CURLOPT_UPLOAD_BUFFERSIZE, 120000L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.62.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_BUFFERSIZE(3), CURLOPT_READFUNCTION(3), CURLOPT_TCP_NODELAY(3)
