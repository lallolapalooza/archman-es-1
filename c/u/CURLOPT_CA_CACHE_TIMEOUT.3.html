CURLOPT_CA_CACHE_TIMEOUT(3)

Paquete: curl

Licencias: MIT

CURLOPT_CA_CACHE_TIMEOUT(3) Manual de funciones de biblioteca CURLOPT_CA_CACHE_TIMEOUT(3)

NOMBRE

CURLOPT_CA_CACHE_TIMEOUT - tiempo de vida para tiendas de certificados en caché

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CA_CACHE_TIMEOUT, long age);

DESCRIPCIÓN

Pase un `long`, esto establece el tiempo de espera en segundos. Esto indica a libcurl el tiempo máximo que una tienda de certificados CA en caché que tenga en memoria puede ser mantenida y reutilizada para nuevas conexiones. Una vez que expire el tiempo de espera, una obtención posterior que requiera un certificado CA tendrá que recargarlo.

Construir una tienda de certificados CA a partir de un archivo de CURLOPT_CAINFO(3) es una operación lenta, por lo que curl puede almacenar en caché la tienda de certificados generada internamente para acelerar las conexiones futuras.

Establezca el tiempo de espera a cero para deshabilitar completamente el caché, o establézcalo a -1 para que la tienda en caché permanezca para siempre. Por defecto, libcurl almacena esta información en caché durante 24 horas.

PREDETERMINADO

86400 (24 horas)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL, Schannel y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    /* reutilizar tiendas de certificados solo por un corto tiempo */
    curl_easy_setopt(curl, CURLOPT_CA_CACHE_TIMEOUT, 60L);
    res = curl_easy_perform(curl);
    /* en esta segunda solicitud, la caché no se usará si han pasado más de
       sesenta segundos desde la conexión anterior */
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Esta opción es compatible con OpenSSL y sus bifurcaciones (desde 7.87.0), Schannel (desde 8.5.0), wolfSSL (desde 8.9.0) y GnuTLS (desde 8.9.0).

DISPONIBILIDAD

Añadido en curl 7.87.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error; consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_CAINFO(3), CURLOPT_CAINFO_BLOB(3), CURLOPT_CAPATH(3), CURLOPT_SSL_VERIFYHOST(3), CURLOPT_SSL_VERIFYPEER(3)
