Paquete: ncurses

curs_overlay(3X) Llamadas a bibliotecas curs_overlay(3X)

NOMBRE

overlay, overwrite, copywin - superponer ventanas de curses y manipularlas

SINOPSIS

#include <curses.h>
int overlay(const WINDOW *srcwin, WINDOW *dstwin);
int overwrite(const WINDOW *srcwin, WINDOW *dstwin);
int copywin(const WINDOW *srcwin, WINDOW *dstwin, int sminrow,
      int smincol, int dminrow, int dmincol, int dmaxrow,
      int dmaxcol, int overlay);

DESCRIPCIÓN

overlay, overwrite

Las rutinas overlay y overwrite superponen srcwin sobre dstwin. No se requiere que scrwin y dstwin tengan el mismo tamaño; solo se copia el texto donde las dos ventanas se superponen. La diferencia es que overlay no es destructiva (los espacios en blanco no se copian) mientras que overwrite es destructiva.

copywin

La rutina copywin proporciona una granularidad de control más fina sobre las rutinas overlay y overwrite. Al igual que en la rutina prefresh, se especifica un rectángulo en la ventana de destino, (dminrow, dmincol) y (dmaxrow, dmaxcol), y las coordenadas de la esquina superior izquierda de la ventana de origen, (sminrow, smincol). Si el argumento overlay es true, entonces la copia no es destructiva, como en overlay.

VALOR DE RETORNO

Estas rutinas devuelven el entero ERR en caso de fallo y un valor OK (SVr4 solo especifica "un valor entero distinto de ERR") en caso de éxito.

X/Open no define condiciones de error. En esta implementación, copywin, overlay y overwrite devuelven un error si alguno de los punteros de ventana son nulos, o si alguna parte de la ventana se colocaría fuera de la pantalla.

NOTAS

Tenga en cuenta que overlay y overwrite pueden ser macros.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4, que añade calificadores const a los argumentos. Además, especifica su comportamiento en presencia de caracteres con representaciones multibyte (aún no compatibles en esta implementación).

VER TAMBIÉN
