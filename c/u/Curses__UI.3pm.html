Curses::UI(3) Documentación de Perl aportada por el usuario Curses::UI(3)

NOMBRE

Curses::UI - Un marco de trabajo de interfaz de usuario orientada a objetos basado en curses

VERSIÓN

Versión 0.9609

SINOPSIS

use Curses::UI;
# crear un nuevo objeto C::UI
my $cui = Curses::UI->new( -clear_on_exit => 1,
                           -debug => $debug, );
# aquí es donde nos saltamos la configuración de todos los widgets y las
# estructuras de datos :)
# iniciar el bucle de eventos
$cui->mainloop;

DESCRIPCIÓN

Curses::UI es un marco de trabajo de interfaz de usuario orientada a objetos para Perl.

Contiene widgets básicos (como botones y áreas de texto), widgets más "avanzados" (como pestañas de interfaz de usuario y un editor de texto básico completamente funcional), y algunas clases de nivel más alto como diálogos de error preconstruidos.

Consulte Curses::UI::Tutorial y el directorio "examples" de la distribución fuente para más material introductorio.

CONSTRUCTOR

Crea un nuevo objeto Curses::UI:

my $cui = Curses::UI->new( OPCIONES );

donde "OPCIONES" es una o más de las siguientes.

-clear_on_exit

Si es verdadero, Curses::UI llamará a "clear" al salir. Por defecto es falso.

-color_support

Si es verdadero, Curses::UI intenta habilitar el color para la aplicación. Por defecto es falso.

-compat

Si es verdadero, Curses::UI se ejecutará en modo de compatibilidad, lo que significa que solo se usarán caracteres muy simples para crear los widgets. Por defecto es falso.

-keydelay

Si se establece en un entero positivo, Curses::UI rastreará los segundos transcurridos desde la última pulsación de tecla del usuario, evitando que ocurran eventos de temporizador durante el número de segundos especificado después. Por defecto esta opción está establecida en '0' (desactivado).

-mouse_support

Curses::UI intenta autodescubrir si el soporte de ratón debe estar habilitado o no. Esta opción permite una anulación forzada. Espera un valor booleano.

-userdata

Toma un escalar (frecuentemente una referencia a hash) como su argumento, y almacena ese escalar dentro del objeto Curses::UI donde puede recuperarse con el método #userdata. Útil dentro de callbacks y similares.

-default_colors

Indica a la biblioteca Curses subyacente que permita el uso de pares de colores predeterminados en las terminales. Está preestablecido en verdadero y casi con certeza no querrás modificarlo. Consulta "man use_default_colors" si crees que sí.

MÉTODOS DE MANEJO DE EVENTOS

mainloop

El bucle de manejo de eventos de Curses::UI. Llámalo una vez que la configuración haya terminado para "iniciar" un programa C::UI.

mainloopExit

Esto sale del bucle principal.

schedule_event

Empuja su argumento (una referencia a código) en la pila de eventos programados

MÉTODOS DE VENTANA/DISEÑO

layout

El método layout de Curses::UI intenta encontrar el tamaño de la pantalla y luego llama al método "layout" de cada objeto contenido (es decir, ventana o widget). Normalmente no es necesario llamar a este método directamente.

MÉTODOS DE DIÁLOGO DE CONVENIENCIA

dialog

Usa el método "dialog" para mostrar una ventana de diálogo. Si solo proporcionas un argumento, este argumento será usado como el mensaje a mostrar. Ejemplo:

$cui->dialog("¡Hola, mundo!");

Si quieres tener un poco más de control sobre la ventana de diálogo, tendrás que proporcionar más argumentos (para una explicación de los argumentos que se pueden usar, consulta Curses::UI::Dialog::Basic. Ejemplo:

my $yes = $cui->dialog(
    -message => "¿Hola, mundo?",
    -buttons =3D> ['sí','no'],
    -values  => [1,0],
    -title   => 'Pregunta',
);
if ($yes) {
    # lo que sea
}

error

El método "error" creará un diálogo de error. Esto es básicamente un Curses::UI::Dialog::Basic, pero tiene un signo de exclamación en arte ASCII dibujado a la izquierda del mensaje. Por lo demás, es igual que "dialog". Ejemplo:

$cui->error("Es el fin del\n"
           ."mundo tal como lo conocemos!");

filebrowser

Crea un diálogo de explorador de archivos. Para una explicación de los argumentos que se pueden usar, consulta Curses::UI::Dialog::Filebrowser. Ejemplo:

my $file = $cui->filebrowser(
    -path => "/tmp",
    -show_hidden => 1,
);
# Filebrowser devolverá undef
# si no se seleccionó ningún archivo.
if (defined $file) {
    unless (open F, ">$file") {
        print F "¡Hola, mundo!\n";
        close F;
} else {
    $cui->error(qq(Error al escribir en "$file":\n$!));
}

loadfilebrowser, savefilebrowser

Estos dos métodos también crearán diálogos de explorador de archivos. La diferencia es que estos tendrán los diálogos configurados correctamente para cargar y guardar archivos. Además, el diálogo de guardado comprobará si el archivo seleccionado existe o no. Si existe, mostrará una confirmación de sobrescritura para comprobar si el usuario realmente quiere sobrescribir el archivo seleccionado.

status, nostatus

Usando estos métodos es fácil proporcionar información de estado para el usuario de tu programa. El diálogo de estado es un diálogo con solo una etiqueta en él. El diálogo de estado no obtiene realmente el foco. Solo se usa para mostrar alguna información. Si necesitas más de un estado, puedes llamar a "status" consecutivamente. Cualquier diálogo de estado existente será eliminado y se creará uno nuevo.

Cuando hayas terminado, puedes eliminar el diálogo de estado llamando al método "nostatus". Ejemplo:

$cui->status("Diciendo hola al mundo...");
# código para decir "¡Hola, mundo!"
$cui->status("Diciendo adiós al mundo...");
# código para decir "¡Adiós, mundo!"
$cui->nostatus;

progress, setprogress, noprogress

Usando estos métodos es fácil proporcionar información de progreso al usuario. El diálogo de progreso es un diálogo con una etiqueta opcional y una barra de progreso. De manera similar al diálogo de estado, este diálogo no obtiene el foco.

Usando el método "progress", se puede crear un nuevo diálogo de progreso. Este método toma los mismos argumentos que la clase Curses::IU::Dialog::Progress.

Después, el progreso se puede establecer usando "setprogress". Este método toma uno o dos argumentos. El primer argumento es la posición actual de la barra de progreso. El segundo argumento es el mensaje para mostrar en la etiqueta. Si uno de estos argumentos está indefinido, se mantendrá el valor actual.

Cuando haya terminado, puede eliminar el diálogo de progreso llamando al "noprogress" método.

$cui->progress(
    -max => 10,
    -message => "Counting 10 seconds...",
);
for my $second (0..10) {
    $cui->setprogress($second)
    sleep 1;
}
$cui->noprogress;

OTROS MÉTODOS

leave_curses ( )
Sale temporalmente del modo curses y recupera el modo normal de la terminal.
reset_curses ( )
Vuelve al modo curses después de leave_curses().
add ( ID, CLASS, OPTIONS )
El add método de Curses::UI es casi el mismo que el add método de Curses::UI::Container. La diferencia es que Curses::UI solo aceptará clases que sean (descendientes de) la clase Curses::UI::Window. Para el resto de la información, consulte Curses::UI::Container.
add_callback ( ID, CODE)
Este método le permite añadir un callback al bucle principal de forma permanente. El código se ejecuta después de que se haya ejecutado el manejador de entrada.
delete_callback ( ID )
Este método elimina el CODE especificado por ID del bucle principal.
usemodule ( CLASSNAME )
Carga el módulo dado por CLASSNAME.
userdata ( [ SCALAR ] )
Este método devolverá los datos internos del usuario almacenados en el objeto UI. Si se especifica un parámetro SCALAR, también establecerá los datos actuales del usuario en él.
keydelay ( )
Este método se usa internamente para controlar los eventos del temporizador cuando el -keydelay opción está activada, pero se puede llamar directamente para saber si ha pasado la cantidad de tiempo requerida desde la última acción del usuario. keydelay() devolverá 0 si no ha pasado el tiempo suficiente, y devolverá el número de segundos transcurridos en caso contrario.
compat ( [BOOLEAN] )
El -compat opción se establecerá en el valor BOOLEAN, a menos que BOOLEAN se omita. El método devuelve el valor actual para -compat.
clear_on_exit ( [BOOLEAN] )
El -clear_on_exit opción se establecerá en el valor BOOLEAN, a menos que BOOLEAN se omita. El método devuelve el valor actual para -clear_on_exit.
color ( )
Devuelve el objeto Curses::UI::Color actualmente utilizado
set_color ( OBJECT )
Reemplaza el objeto Color actualmente utilizado con otro. Esto se puede usar para cambiar rápidamente todos los colores en una aplicación Curses::UI.
