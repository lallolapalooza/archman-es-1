CURLOPT_ABSTRACT_UNIX_SOCKET(3)

Paquete: curl

Licencias: MIT

CURLOPT_ABSTRACT_UNIX_SOCKET(3) Manual de Funciones de Biblioteca CURLOPT_ABSTRACT_UNIX_SOCKET(3)

NOMBRE

CURLOPT_ABSTRACT_UNIX_SOCKET - socket Unix abstracto

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ABSTRACT_UNIX_SOCKET,
                          char *path);

DESCRIPCIÓN

Habilita el uso de un socket Unix abstracto en lugar de establecer una conexión TCP a un host. El parámetro debe ser un puntero a un array de caracteres terminado en nulo que contenga la ruta del socket. La ruta se establece a path precedido por un byte NULO. Esta es la convención para sockets abstractos, sin embargo, cabe destacar que la ruta pasada a esta función no debe contener un byte NULO al principio.

En plataformas no compatibles, la dirección abstracta se interpreta como una cadena vacía y falla con elegancia, generando un error en tiempo de ejecución.

Esta opción comparte las mismas semánticas que CURLOPT_UNIX_SOCKET_PATH(3), en cuya documentación se puede encontrar más detalles. Internamente, estas dos opciones comparten el mismo almacenamiento y, por lo tanto, solo se puede establecer una de ellas por handle.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_ABSTRACT_UNIX_SOCKET, "/tmp/foo.sock");
    curl_easy_setopt(curl, CURLOPT_URL, "http://localhost/");
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.53.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, véase libcurl-errors(3).
