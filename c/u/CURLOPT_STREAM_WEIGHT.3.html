CURLOPT_STREAM_WEIGHT(3)

Paquete: curl

Licencias: MIT

CURLOPT_STREAM_WEIGHT(3) Manual de Funciones de Librería CURLOPT_STREAM_WEIGHT(3)

NOMBRE

CURLOPT_STREAM_WEIGHT - peso numérico de flujo

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_STREAM_WEIGHT, long weight);

DESCRIPCIÓN

Establece el entero largo weight a un número entre 1 y 256.

Cuando se usa HTTP/2, esta opción establece el peso individual para este flujo particular utilizado por el handle fácil. Establecer y usar pesos solo tiene sentido y solo es utilizable cuando se realizan múltiples flujos a través de las mismas conexiones, lo que implica que se usa CURLMOPT_PIPELINING(3).

Esta opción se puede establecer durante la transferencia y provoca que la información de peso actualizada se envíe al servidor la próxima vez que se envíe un frame HTTP/2 al servidor.

Consulte la sección 5.3 de RFC 7540 para obtener detalles del protocolo.

Los flujos con el mismo padre deben asignar recursos proporcionalmente en función de su peso. Si tiene dos flujos en curso, el flujo A con peso 16 y el flujo B con peso 32, el flujo B obtiene dos tercios (32/48) del ancho de banda disponible (suponiendo que el servidor puede enviar los datos de manera equitativa para ambos flujos).

VALOR POR DEFECTO

16

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init(); /* un segundo handle */
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/one");
    curl_easy_setopt(curl, CURLOPT_STREAM_WEIGHT, 10L);
    /* el segundo tiene el doble de peso */
    curl_easy_setopt(curl2, CURLOPT_URL, "https://example.com/two");
    curl_easy_setopt(curl2, CURLOPT_STREAM_WEIGHT, 20L);
    /* luego agregar ambos a un multi handle y transferirlos */
  }
}

DISPONIBILIDAD

Añadido en curl 7.46.0

VALOR DE RETORNO

curl_easy_setopt(3) retorna un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, ver libcurl-errors(3).
