CURLOPT_NETRC(3)

Paquete: curl

Licencias: MIT

CURLOPT_NETRC(3) Manual de funciones de la biblioteca CURLOPT_NETRC(3)

NOMBRE

CURLOPT_NETRC - habilita el uso de .netrc

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_NETRC, long level);

DESCRIPCIÓN

Este parámetro controla el nivel de preferencia level de libcurl entre usar nombres de usuario y contraseñas de tu archivo ~/.netrc , en relación con los nombres de usuario y contraseñas en la URL proporcionada con CURLOPT_URL(3). Si la variable de entorno NETRC está establecida, ese nombre de archivo se usa como el archivo netrc. (Añadido en 8.16.0)

En Windows, libcurl comprueba principalmente .netrc en %HOME%. Si %HOME% no está establecido en Windows, libcurl usa %USERPROFILE%como alternativa. Si el archivo no existe, recurre a comprobar si hay en su lugar un archivo llamado _netrc - usando un guion bajo en lugar de un punto.

También puedes indicar a libcurl un nombre de archivo diferente para usar con CURLOPT_NETRC_FILE(3).

libcurl usa un nombre de usuario (y una contraseña proporcionada o solicitada) proporcionado con CURLOPT_USERPWD(3) o CURLOPT_USERNAME(3) con preferencia sobre cualquiera de las opciones controladas por este parámetro.

Solo se tienen en cuenta el nombre de la máquina, el nombre de usuario y la contraseña (las macros de inicialización y cosas similares no son compatibles).

El archivo netrc proporciona credenciales para un nombre de host independientemente del protocolo y el número de puerto que se utilicen.

libcurl no verifica que el archivo tenga establecidas las propiedades correctas (como hace el cliente ftp estándar de Unix). Solo debería ser legible por el usuario.

level es un long que debería establecerse a uno de los valores descritos a continuación.

CURL_NETRC_IGNORED (0)
libcurl ignora el archivo .netrc . Este es el valor predeterminado.
CURL_NETRC_OPTIONAL (1)
El uso del archivo .netrc es opcional, y se debe preferir la información en la URL. El archivo se busca por el host y el nombre de usuario (para encontrar solo la contraseña) o solo por el host, para encontrar el primer nombre de usuario y contraseña después de esa machine, la información que no esté especificada.
CURL_NETRC_REQUIRED (2)
El uso del archivo .netrc es obligatorio, y se ignora cualquier información de credencial presente en la URL. El archivo se busca por el host y el nombre de usuario (para encontrar solo la contraseña) o solo por el host, para encontrar el primer nombre de usuario y contraseña después de esa machine, la información que no esté especificada.

FORMATO DEL ARCHIVO

El formato del archivo .netrc es simple: especificas líneas con un nombre de máquina y siguen el login y la contraseña que están asociados con esa máquina.

Cada campo se proporciona como una secuencia de letras que termina con un espacio o un salto de línea. A partir de la versión 7.84.0, libcurl también admite cadenas entrecomilladas. Comienzan y terminan con comillas dobles y admiten las letras especiales escapadas ", n, r y t. Las cadenas entrecomilladas son la única forma en que un espacio puede usarse en un nombre de usuario o una contraseña.

machine <name>
Proporciona credenciales para un host llamado name. libcurl busca en el archivo .netrc un token de máquina que coincida con el nombre de host especificado en la URL. Una vez que se hace una coincidencia, se procesan los tokens siguientes, deteniéndose cuando se alcanza el final del archivo o se encuentra otro "machine".
default
Esto es lo mismo que machine name excepto que default coincide con cualquier nombre. Solo puede haber un token default, y debe estar después de todos los tokens machine. Para proporcionar un login anónimo predeterminado para hosts que no coincidan de otra manera, añade una línea similar a esta al final: 
default login anonymous password user@domain
login <name>
La cadena de nombre de usuario para la máquina remota.
password <secret>
Proporciona una contraseña. Si este token está presente, curl proporciona la cadena especificada si el servidor remoto requiere una contraseña como parte del proceso de login. Ten en cuenta que si este token está presente en el archivo .netrc, realmente deberías asegurarte de que el archivo no sea legible por nadie además del usuario.
macdef <name>
Define una macro. Esta función no es compatible con libcurl. Para que el resto del .netrc siga funcionando bien, libcurl omite correctamente cada definición hecha con "macdef" que encuentra.

PREDETERMINADO

CURL_NETRC_IGNORED

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/");
    curl_easy_setopt(curl, CURLOPT_NETRC, CURL_NETRC_OPTIONAL);
    ret = curl_easy_perform(curl);
  }
}

HISTORIA

Los enums CURL_NETRC_se convirtieron en tipos long en 8.13.0, antes de esta versión era necesario hacer un cast a long al pasarlos a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estaba bien, un valor distinto de cero significa que ocurrió un error, ver libcurl-errors(3).
