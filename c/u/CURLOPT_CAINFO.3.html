CURLOPT_CAINFO(3)

Paquete: curl

Licencias: MIT

CURLOPT_CAINFO(3) Manual de funciones de la biblioteca CURLOPT_CAINFO(3)

NOMBRE

CURLOPT_CAINFO - ruta al paquete de Autoridad(es) de Certificación (CA)

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CAINFO, char *path);

DESCRIPCIÓN

Pase un puntero a char a una cadena terminada en nulo que nombre un archivo que contiene uno o más certificados para verificar al par.

Si CURLOPT_SSL_VERIFYPEER(3) es cero y evita verificar el certificado del servidor, CURLOPT_CAINFO(3) no necesita siquiera indicar un archivo accesible.

Esta opción está configurada por defecto en la ruta del sistema donde se asume que reside el paquete de certificados CA de libcurl, según lo establecido en el momento de la compilación.

(Schannel) Esta opción es compatible con Schannel en Windows 7 o posterior, pero recomendamos no usarla hasta Windows 8 ya que funciona mejor a partir de entonces. Si la opción no está configurada, curl utiliza los certificados en el almacén de certificados raíz de Windows (el valor predeterminado para Schannel).

La aplicación no tiene que conservar la cadena de caracteres después de configurar esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Configúrela a NULL para deshabilitar su uso nuevamente.

El valor predeterminado para esto se puede obtener con CURLINFO_CAINFO(3).

PREDETERMINADO

Específico del sistema integrado. Cuando curl se compila con Schannel, esta opción no se establece por defecto.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Todos los backends TLS soportan esta opción.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_CAINFO, "/etc/certs/cabundle.pem");
    curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Soporte Schannel añadido en libcurl 7.60.

DISPONIBILIDAD

Añadido en curl 7.4.2

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLINFO_CAINFO(3), CURLOPT_CAINFO_BLOB(3), CURLOPT_CAPATH(3), CURLOPT_CA_CACHE_TIMEOUT(3), CURLOPT_SSL_VERIFYHOST(3), CURLOPT_SSL_VERIFYPEER(3)
