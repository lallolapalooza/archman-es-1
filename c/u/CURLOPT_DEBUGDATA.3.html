CURLOPT_DEBUGDATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_DEBUGDATA(3) Manual de funciones de la biblioteca CURLOPT_DEBUGDATA(3)

NOMBRE

CURLOPT_DEBUGDATA - puntero pasado a la función de depuración

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DEBUGDATA, void *pointer);

DESCRIPCIÓN

Pase un puntero a lo que desee pasar a su CURLOPT_DEBUGFUNCTION(3) en el último argumento void *. Este puntero no es utilizado por libcurl, solo se pasa a la función de devolución de llamada.

VALOR PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

struct data {
  void *custom;
};
static int my_trace(CURL *handle, curl_infotype type,
                    char *data, size_t size,
                    void *clientp)
{
  struct data *mine = clientp;
  printf("our ptr: %p\n", mine->custom);
  /* output debug info */
  return 0;
}
int main(void)
{
  CURL *curl;
  CURLcode res;
  struct data my_tracedata;
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_DEBUGFUNCTION, my_trace);
    curl_easy_setopt(curl, CURLOPT_DEBUGDATA, &my_tracedata);
    /* the DEBUGFUNCTION has no effect until we enable VERBOSE */
    curl_easy_setopt(curl, CURLOPT_VERBOSE, 1L);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    res = curl_easy_perform(curl);
    /* always cleanup */
    curl_easy_cleanup(curl);
  }
  return 0;
}

DISPONIBILIDAD

Añadido en curl 7.9.6

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue correcto, un valor distinto de cero indica un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_DEBUGFUNCTION(3), CURLOPT_STDERR(3)
