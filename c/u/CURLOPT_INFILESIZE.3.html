CURLOPT_INFILESIZE(3)

Paquete: curl

Licencias: MIT

CURLOPT_INFILESIZE(3) Manual de funciones de la biblioteca CURLOPT_INFILESIZE(3)

NOMBRE

CURLOPT_INFILESIZE - tamaño del archivo de entrada a enviar

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INFILESIZE, long filesize);

DESCRIPCIÓN

Al subir un archivo a un sitio remoto, filesize se debe utilizar para indicar a libcurl cuál es el tamaño esperado del archivo de entrada. Este valor debe pasarse como un long. Consulte también CURLOPT_INFILESIZE_LARGE(3) para enviar archivos de más de 2 GB.

Para subir utilizando SCP, esta opción o CURLOPT_INFILESIZE_LARGE(3) es obligatoria.

Para restablecer este valor, configúrelo en -1.

Usar CURLOPT_UPLOAD(3) en un servidor HTTP/1.1 y con este valor establecido en -1, hace que libcurl realice una carga codificada mediante transferencia en fragmentos (chunked transfer encoding).

Al enviar correos electrónicos usando SMTP, este comando puede usarse para especificar el parámetro opcional SIZE para el comando MAIL FROM.

Esta opción no limita la cantidad de datos que libcurl realmente envía, ya que eso está controlado enteramente por lo que devuelve la función de devolución de lectura, pero indicar un valor y enviar una cantidad diferente puede llevar a errores.

PREDETERMINADO

No establecido

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

#define FILE_SIZE 12345L
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    long uploadsize = FILE_SIZE;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/destination.tar.gz");
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    curl_easy_setopt(curl, CURLOPT_INFILESIZE, uploadsize);
    curl_easy_perform(curl);
  }
}

HISTORIAL

Soporte SMTP añadido en 7.23.0

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
