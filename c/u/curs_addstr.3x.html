curs_addstr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_addstr(3X) Llamadas de biblioteca curs_addstr(3X)

NOMBRE

addstr, addnstr, waddstr, waddnstr, mvaddstr, mvaddnstr, mvwaddstr, mvwaddnstr - añadir una cadena a una ventana de curses y avanzar el cursor

SINOPSIS

#include <curses.h>
int addstr(const char *str);
int mvaddstr(int y, int x, const char *str);
int mvwaddstr(WINDOW *win, int y, int x, const char *str);
int waddstr(WINDOW *win, const char *str);
int addnstr(const char *str, int n);
int mvaddnstr(int y, int x, const char *str, int n);
int mvwaddnstr(WINDOW *win, int y, int x, const char *str, int n);
int waddnstr(WINDOW *win, const char *str, int n);

DESCRIPCIÓN

waddstr escribe los caracteres de la cadena (terminada en nulo) str en la ventana win. Su proceso es similar a llamar a waddch(3X) por cada char en str. Los caracteres de control se procesan como en waddch(3X).

waddnstr escribe como máximo n caracteres, o hasta que ocurra un carácter nulo terminador en str. Si n es -1, waddnstr escribe la cadena completa.

ncurses(3X) describe las variantes de estas funciones.

VALOR DE RETORNO

Estas funciones devuelven OK en caso de éxito y ERR en caso de fallo.

X/Open Curses no especifica ninguna condición de error. ncurses devuelve un error

  • si el puntero de la ventana es NULL,
  • si el puntero de la cadena es NULL, o
  • si una llamada interna a waddch(3X) devuelve un error.

Las funciones prefijadas con “mv” primero realizan el movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Todas estas funciones, excepto waddnstr, pueden ser macros.

PORTABILIDAD

X/Open Curses, Issue 4 describe estas funciones.

VER TAMBIÉN

curs_addwstr(3X) describe funciones comparables de la biblioteca ncurses en su configuración de caracteres anchos (ncursesw).
