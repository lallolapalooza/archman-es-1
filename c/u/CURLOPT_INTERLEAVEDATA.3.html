CURLOPT_INTERLEAVEDATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_INTERLEAVEDATA(3) Manual de funciones de la biblioteca CURLOPT_INTERLEAVEDATA(3)

NOMBRE

CURLOPT_INTERLEAVEDATA - puntero pasado al callback de interleave RTSP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INTERLEAVEDATA, void *pointer);

DESCRIPCIÓN

Este es el *puntero* de datos de usuario que se pasa a CURLOPT_INTERLEAVEFUNCTION(3) cuando se reciben datos RTP intercalados. Si la función de callback de interleave no está configurada, este puntero no se utiliza en ningún lugar.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a rtsp

EJEMPLO

struct local {
  void *custom;
};
static size_t rtp_write(void *ptr, size_t size, size_t nmemb, void *userp)
{
  struct local *l = userp;
  printf("mi puntero: %p\n", l->custom);
  /* encargarse del paquete en 'ptr', luego retornar... */
  return size * nmemb;
}
int main(void)
{
  struct local rtp_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_INTERLEAVEFUNCTION, rtp_write);
    curl_easy_setopt(curl, CURLOPT_INTERLEAVEDATA, &rtp_data);
    curl_easy_perform(curl);
 }
}

DISPONIBILIDAD

Añadido en curl 7.20.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_INTERLEAVEFUNCTION(3), CURLOPT_RTSP_REQUEST(3)
