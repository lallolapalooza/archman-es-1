Documentación de función/subrutina

subroutine cungtr (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGTR

Propósito:

!>
!> CUNGTR genera una matriz unitaria compleja Q que se define como el
!> producto de n-1 reflectores elementales de orden N, como los devueltos por
!> CHETRD:
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': El triángulo superior de A contiene los reflectores elementales
!>                 de CHETRD;
!>          = 'L': El triángulo inferior de A contiene los reflectores elementales
!>                 de CHETRD.
!>

N

!>          N es INTEGER
!>          El orden de la matriz Q. N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          A la entrada, los vectores que definen los reflectores elementales,
!>          como los devueltos por CHETRD.
!>          A la salida, la matriz unitaria N-por-N Q.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= N.
!>

TAU

!>          TAU es un array COMPLEX, de dimensión (N-1)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), como lo devuelve CHETRD.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= N-1.
!>          Para un rendimiento óptimo, LWORK >= (N-1)*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>
