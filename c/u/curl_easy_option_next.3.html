curl_easy_option_next(3)

Paquete: curl

Licencias: MIT

curl_easy_option_next(3) Manual de funciones de biblioteca curl_easy_option_next(3)

NOMBRE

curl_easy_option_next - itera sobre las opciones easy setopt

SINOPSIS

#include <curl/curl.h>
const struct curl_easyoption *
curl_easy_option_next(const struct curl_easyoption *prev);

DESCRIPCIÓN

Esta función devuelve un puntero a la estructura curl_easyoption primera o siguiente, proporcionando la capacidad de iterar sobre todas las opciones conocidas para curl_easy_setopt(3) en esta instancia de libcurl.

Pase un argumento NULL como prev para obtener la primera opción devuelta, o pase la opción actual para obtener la siguiente. Si no hay más opciones que devolver, curl_easy_option_next(3) devuelve NULL.

Las opciones devueltas por esta función son las conocidas por esta libcurl y la información sobre el tipo de argumento que desean.

Si el bit CURLOT_FLAG_ALIAS está establecido en el campo flags, significa que el nombre se proporciona por compatibilidad con versiones anteriores como un alias.

STRUCT

typedef enum {
  CURLOT_LONG,    /* long (un rango de valores) */
  CURLOT_VALUES,  /*      (un conjunto definido o máscara de bits) */
  CURLOT_OFF_T,   /* curl_off_t (un rango de valores) */
  CURLOT_OBJECT,  /* puntero (void *) */
  CURLOT_STRING,  /*         (char * a un búfer terminado en nulo) */
  CURLOT_SLIST,   /*         (struct curl_slist *) */
  CURLOT_CBPTR,   /*         (void * pasado tal cual a una devolución de llamada) */
  CURLOT_BLOB,    /* blob (struct curl_blob *) */
  CURLOT_FUNCTION /* puntero a función */
} curl_easytype;
/* Los rangos de ID de CURLOPTTYPE_* todavía se pueden usar para determinar qué tipo/tamaño
   usar para curl_easy_setopt() para el ID dado */
struct curl_easyoption {
  const char *name;
  CURLoption id;
  curl_easytype type;
  unsigned int flags;
};

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  /* itera sobre todas las opciones disponibles */
  const struct curl_easyoption *opt;
  opt = curl_easy_option_next(NULL);
  while(opt) {
    printf("Nombre: %s\n", opt->name);
    opt = curl_easy_option_next(opt);
  }
}

DISPONIBILIDAD

Añadido en curl 7.73.0

VALOR DE RETORNO

Un puntero a la estructura curl_easyoption para la siguiente opción o NULL si no hay más opciones.

VER TAMBIÉN
