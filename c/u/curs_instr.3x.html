curs_instr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_instr(3X) Llamadas a biblioteca curs_instr(3X)

NOMBRE

instr, innstr, winstr, winnstr, mvinstr, mvinnstr, mvwinstr, mvwinnstr - obtener una cadena de una ventana de curses

SINOPSIS

#include <curses.h>
int instr(char *str);
int innstr(char *str, int n);
int winstr(WINDOW *win, char *str);
int winnstr(WINDOW *win, char *str, int n);
int mvinstr(int y, int x, char *str);
int mvinnstr(int y, int x, char *str, int n);
int mvwinstr(WINDOW *win, int y, int x, char *str);
int mvwinnstr(WINDOW *win, int y, int x, char *str, int n);

DESCRIPCIÓN

Estas rutinas devuelven una cadena de caracteres en str, comenzando en la posición actual del cursor en la ventana nombrada. Los atributos se eliminan de los caracteres.

Las cuatro funciones con n como último argumento devuelven una subcadena inicial de como máximo n caracteres (excluyendo el NUL final). La transferencia se detiene al final de la línea actual o cuando se han almacenado n caracteres en la ubicación referenciada por str.

VALOR DE RETORNO

Todas las funciones devuelven ERR en caso de fallo, o el número de caracteres realmente leídos en la cadena.

X/Open Curses no define condiciones de error. Esta implementación devuelve un error

  • si el parámetro win es nulo o
  • si el parámetro chstr es nulo.

Las funciones prefijadas con “mv” primero realizan un movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Todas las rutinas excepto winnstr pueden ser macros.

Leer una línea que desborda el array apuntado por str con instr, mvinstr, mvwinstr o winstr causa resultados indefinidos. Por lo tanto, se recomienda el uso de innstr, mvinnstr, mvwinnstr o winnstr.

PORTABILIDAD

SVr4 no documenta si un límite de longitud incluye o excluye el NUL final.

La biblioteca ncurses extiende la descripción de X/Open Curses al permitir un valor negativo para n. En este caso, las funciones devuelven la cadena que termina en el margen derecho.

VER TAMBIÉN

curs_ins_wstr(3X) describe funciones comparables de la biblioteca ncurses en su configuración de caracteres anchos (ncursesw).
