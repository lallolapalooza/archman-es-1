CURLSHOPT_UNLOCKFUNC(3)

Paquete: curl

Licencias: MIT

CURLSHOPT_UNLOCKFUNC(3) Manual de Funciones de Biblioteca CURLSHOPT_UNLOCKFUNC(3)

NOMBRE

CURLSHOPT_UNLOCKFUNC - función de devolución de llamada para desbloquear mutex

SINOPSIS

#include <curl/curl.h>
void unlockcb(CURL *handle, curl_lock_data data, void *clientp);
CURLSHcode curl_share_setopt(CURLSH *share, CURLSHOPT_UNLOCKFUNC, unlockcb);

DESCRIPCIÓN

Establece una función de devolución de llamada para desbloquear mutex para el objeto compartido. Existe una función de devolución de llamada CURLSHOPT_LOCKFUNC(3) correspondiente que se llama cuando se bloquea el mutex por primera vez.

El argumento unlockcb debe ser un puntero a una función que coincida con el prototipo mostrado arriba. Los argumentos de la función de devolución de llamada son:

handle es el manejador easy actualmente activo en uso cuando se libera el objeto compartido.

El argumento data indica qué tipo de datos quiere desbloquear libcurl. Asegúrese de que la función de devolución de llamada utilice un mutex diferente para cada tipo de datos.

clientp es el puntero privado que estableció con CURLSHOPT_USERDATA(3). Este puntero no es utilizado por libcurl en sí.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

extern void mutex_unlock(CURL *, curl_lock_data, void *);
int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_UNLOCKFUNC, mutex_unlock);
  if(sh)
    printf("Error: %s\n", curl_share_strerror(sh));
}

DISPONIBILIDAD

Añadido en curl 7.10.3

VALOR DE RETORNO

CURLSHE_OK (cero) significa que la opción se estableció correctamente, un valor distinto de cero indica que ocurrió un error. Consulte libcurl-errors(3) para ver la lista completa con descripciones.

VER TAMBIÉN
