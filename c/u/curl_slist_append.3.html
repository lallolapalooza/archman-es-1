curl_slist_append(3)

Paquete: curl

Licencias: MIT

curl_slist_append(3) Manual de funciones de biblioteca curl_slist_append(3)

NOMBRE

curl_slist_append - agregar una cadena a una slist

SINOPSIS

#include <curl/curl.h>
struct curl_slist *curl_slist_append(struct curl_slist *list,
                                     const char *string);

DESCRIPCIÓN

curl_slist_append(3) agrega una cadena a una lista enlazada de cadenas. La list existente debe pasarse como primer argumento y la nueva lista se devuelve de esta función. Pase NULL en el argumento list para crear una nueva lista. La string especificada se ha agregado cuando esta función retorna. curl_slist_append(3) copia la cadena. El argumento string debe ser un puntero a cadena válido y no puede ser NULL.

La lista debe liberarse (después de su uso) con curl_slist_free_all(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *handle = curl_easy_init();
  struct curl_slist *slist = NULL;
  struct curl_slist *temp = NULL;
  slist = curl_slist_append(slist, "pragma:");
  if(!slist)
    return -1;
  temp = curl_slist_append(slist, "Accept:");
  if(!temp) {
    curl_slist_free_all(slist);
    return -1;
  }
  slist = temp;
  curl_easy_setopt(handle, CURLOPT_HTTPHEADER, slist);
  curl_easy_perform(handle);
  curl_slist_free_all(slist); /* libera la lista de nuevo */
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Se devuelve un puntero nulo si algo salió mal, de lo contrario se devuelve el nuevo puntero de lista. Para evitar sobrescribir una lista no vacía existente en caso de fallo, la nueva lista debe devolverse a una variable temporal que pueda probarse como NULL antes de actualizar el puntero de la lista original.
