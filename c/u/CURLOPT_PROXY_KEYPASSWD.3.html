CURLOPT_PROXY_KEYPASSWD(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_KEYPASSWD(3) Manual de Funciones de Librería CURLOPT_PROXY_KEYPASSWD(3)

NOMBRE

CURLOPT_PROXY_KEYPASSWD - contraseña para la clave privada del proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_KEYPASSWD, char *pwd);

DESCRIPCIÓN

Esta opción es para conectarse a un proxy HTTPS, no a un servidor HTTPS.

Pase un puntero a una cadena terminada en nulo como parámetro. Se utiliza como la contraseña requerida para usar la clave privada de CURLOPT_PROXY_SSLKEY(3). Nunca necesitas una contraseña para cargar un certificado, pero necesitas una para cargar tu clave privada.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establécela a NULL para deshabilitar su uso nuevamente.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL, Schannel, mbedTLS y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy:443");
    curl_easy_setopt(curl, CURLOPT_PROXY_KEYPASSWD, "superman");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_KEYPASSWD(3), CURLOPT_PROXY_SSLKEY(3), CURLOPT_SSH_PRIVATE_KEYFILE(3), CURLOPT_SSLKEY(3)
