CURLOPT_TLS13_CIPHERS(3)

Paquete: curl

Licencias: MIT

CURLOPT_TLS13_CIPHERS(3) Manual de funciones de la biblioteca CURLOPT_TLS13_CIPHERS(3)

NOMBRE

CURLOPT_TLS13_CIPHERS - cifrados a utilizar para TLS 1.3

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TLS13_CIPHERS, char *list);

DESCRIPCIÓN

Pase un puntero a char, que apunta a una cadena terminada en nulo que contiene la lista de suites de cifrado a utilizar para la conexión TLS 1.3. La lista debe tener una sintaxis correcta, consta de una o más cadenas de suites de cifrado separadas por dos puntos.

Para establecer cifrados TLS 1.2 (1.1, 1.0), consulte CURLOPT_SSL_CIPHER_LIST(3).

Un ejemplo válido de lista de cifrados es:

"TLS_AES_128_GCM_SHA256:TLS_CHACHA20_POLY1305_SHA256"

Encuentre más detalles sobre listas de cifrados en esta URL:


https://curl.se/docs/ssl-ciphers.html

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Utilizar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para restaurar los valores predeterminados internos.

PREDETERMINADO

NULL, usa los valores predeterminados internos

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL, mbedTLS, rustls y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_TLS13_CIPHERS,
                     "TLS_CHACHA20_POLY1305_SHA256");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Soporte para OpenSSL añadido en 7.61.0, disponible cuando se compila con OpenSSL >= 1.1.1. Soporte para LibreSSL añadido en 8.3.0, disponible cuando se compila con LibreSSL >= 3.4.1. Soporte para wolfSSL añadido en 8.10.0. Soporte para mbedTLS añadido en 8.10.0, disponible cuando se compila con mbedTLS >= 3.6.0. Soporte para Rustls añadido en 8.10.0.

Antes de curl 8.10.0 con mbedTLS o wolfSSL, las suites de cifrado TLS 1.3 se establecían utilizando la opción CURLOPT_SSL_CIPHER_LIST(3).

DISPONIBILIDAD

Añadido en curl 7.61.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
