curs_clear(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_clear(3X) Llamadas a biblioteca curs_clear(3X)

NOMBRE

erase, werase, clear, wclear, clrtobot, wclrtobot, clrtoeol, wclrtoeol - limpiar toda o parte de una ventana de curses

SINOPSIS

#include <curses.h>
int erase(void);
int werase(WINDOW *win);
int clear(void);
int wclear(WINDOW *win);
int clrtobot(void);
int wclrtobot(WINDOW *win);
int clrtoeol(void);
int wclrtoeol(WINDOW *win);

DESCRIPCIÓN

erase, werase

Las rutinas erase y werase copian espacios en blanco a cada posición de la ventana, limpiando la pantalla.

Los espacios en blanco creados por la erase tienen la representación de fondo actual (como se establece con wbkgdset(3X)) fusionada en ellos.

clear, wclear

Las rutinas clear y wclear son como erase y werase, pero también llaman a clearok(3X), por lo que la pantalla se limpiará completamente en la próxima llamada a wrefresh para esa ventana y se repintará desde cero.

clrtobot, wclrtobot

Las rutinas clrtobot y wclrtobot borran desde el cursor hasta el final de la pantalla. Es decir, borran todas las líneas debajo del cursor en la ventana. Además, la línea actual desde el cursor hacia la derecha, inclusive, se borra.

clrtoeol, wclrtoeol

Las rutinas clrtoeol y wclrtoeol borran la línea actual desde el cursor hacia la derecha, inclusive, hasta el final de la línea actual.

VALOR DE RETORNO

Todas las rutinas devuelven el entero OK en caso de éxito y ERR en caso de fallo.

X/Open no define condiciones de error. En esta implementación,

  • las funciones que usan un parámetro de puntero a ventana devuelven un error si es nulo
  • wclrtoeol devuelve un error si la posición del cursor está a punto de envolver.

NOTAS

Tenga en cuenta que erase, werase, clear, wclear, clrtobot y clrtoeol pueden ser macros.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4.

El manual de SVr4.0 dice que estas funciones podrían devolver “o un entero no negativo si immedok está establecido”, refiriéndose al valor de retorno de wrefresh. En esa implementación, wrefresh devolvería un recuento del número de caracteres escritos en el terminal.

Algunas implementaciones históricas de curses tenían, como característica no documentada, la capacidad de hacer el equivalente a clearok(..., 1) diciendo touchwin(stdscr) o clear(stdscr). Esto no funcionará bajo ncurses.

Esta implementación, y otras como Solaris, establecen la posición actual en 0,0 después de borrar mediante werase y wclear. Ese hecho no está documentado en otras implementaciones, y puede no ser cierto para implementaciones que no se derivaron del código fuente de SVr4.

No es obvio por la descripción, la mayoría de las implementaciones borran la pantalla después de wclear incluso para una subventana o una ventana derivada. Si no desea borrar la pantalla durante el próximo wrefresh, use werase en su lugar.
