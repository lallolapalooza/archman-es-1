CURLOPT_USERPWD(3)

Paquete: curl

Licencias: MIT

CURLOPT_USERPWD(3) Manual de funciones de biblioteca CURLOPT_USERPWD(3)

NOMBRE

CURLOPT_USERPWD - nombre de usuario y contraseña a usar en la autenticación

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_USERPWD, char *userpwd);

DESCRIPCIÓN

Pase un puntero de char como parámetro, apuntando a una cadena de detalles de inicio de sesión terminada en nulo para la conexión. El formato de la misma es: [nombre de usuario]:[contraseña].

Al usar autenticación Kerberos V5 con un servidor basado en Windows, debe especificar la parte del nombre de usuario con el nombre de dominio para que el servidor pueda obtener con éxito un Ticket Kerberos. Si no lo hace, la parte inicial del apretón de manos de autenticación puede fallar.

Al usar NTLM, el nombre de usuario puede especificarse simplemente como el nombre de usuario sin el nombre de dominio, si el servidor forma parte de un solo dominio y bosque.

Para especificar el nombre de dominio, utilice los formatos de inicio de sesión de nivel inferior o UPN (Nombre Principal de Usuario). Por ejemplo, EXAMPLEuser y user@example.com respectivamente.

Algunos servidores HTTP (en Windows) admiten la inclusión del dominio también para la autenticación Básica.

Al usar HTTP y CURLOPT_FOLLOWLOCATION(3), libcurl puede realizar varias solicitudes a hosts posiblemente diferentes. libcurl solo envía esta información de usuario y contraseña a los hosts que utilizan el nombre de host inicial (a menos que CURLOPT_UNRESTRICTED_AUTH(3) esté configurado), por lo que si libcurl sigue las redirecciones a otros hosts, no envía el usuario y la contraseña a esos.

Esto se aplica para evitar la fuga accidental de información.

Use CURLOPT_HTTPAUTH(3) para especificar el método de autenticación para conexiones basadas en HTTP o CURLOPT_LOGIN_OPTIONS(3) para controlar las opciones de IMAP, POP3 y SMTP.

Las cadenas de usuario y contraseña no se decodifican de URL, por lo que no hay forma de enviar un nombre de usuario que contenga dos puntos usando esta opción. Use CURLOPT_USERNAME(3) para eso, o inclúyalo en la URL.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establecerla a NULL para deshabilitar su uso nuevamente.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_USERPWD, "clark:kent");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
