CURLOPT_TCP_KEEPALIVE(3)

Paquete: curl

Licencias: MIT

CURLOPT_TCP_KEEPALIVE(3) Manual de funciones de biblioteca CURLOPT_TCP_KEEPALIVE(3)

NOMBRE

CURLOPT_TCP_KEEPALIVE - Sondas TCP keep-alive

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TCP_KEEPALIVE, long probe);

DESCRIPCIÓN

Pase un long. Si se establece en 1, se utilizan las sondas TCP keepalive. El retraso y la frecuencia de estas sondas se pueden controlar mediante las opciones CURLOPT_TCP_KEEPIDLE(3), CURLOPT_TCP_KEEPINTVL(3) y CURLOPT_TCP_KEEPCNT(3), siempre que el sistema operativo las admita. Establezca en 0 (comportamiento predeterminado) para deshabilitar las sondas keepalive.

PREDETERMINADO

0

PROTOCOLOS

Esta funcionalidad afecta solo a TCP.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* habilitar TCP keep-alive para esta transferencia */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPALIVE, 1L);
    /* tiempo de inactividad keep-alive a 120 segundos */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPIDLE, 120L);
    /* tiempo de intervalo entre sondas keep-alive: 60 segundos */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPINTVL, 60L);
    /* número máximo de sondas keep-alive: 3 */
    curl_easy_setopt(curl, CURLOPT_TCP_KEEPCNT, 3L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.25.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_LOW_SPEED_LIMIT(3), CURLOPT_MAX_RECV_SPEED_LARGE(3), CURLOPT_TCP_KEEPCNT(3), CURLOPT_TCP_KEEPIDLE(3), CURLOPT_TCP_KEEPINTVL(3)
