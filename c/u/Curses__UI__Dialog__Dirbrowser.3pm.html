NOMBRE

Curses::UI::Dialog::Dirbrowser - Crea y manipula diálogos de explorador de archivos

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Dirbrowser

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La forma difícil.
# ----------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Dirbrowser'
);
$dialog->focus;
my $file = $dialog->get();
$win->delete('mydialog');
# La forma fácil (ver la documentación de Curses::UI).
# --------------------------------------------------
$file = $cui->filebrowser();
$file = $cui->loadfilebrowser();
$file = $cui->savefilebrowser();

DESCRIPCIÓN

Curses::UI::Dialog::Dirbrowser es un diálogo explorador de directorios. Este tipo de diálogo se puede usar para seleccionar un directorio, en cualquier parte del sistema de archivos.

Ver examples/demo-Curses::UI::Dialog::Dirbrowser en la distribución para una breve demostración.

OPCIONES

  • -title < TEXTO >

    Establece el título de la ventana del diálogo a TEXTO.

  • -path < RUTA >

    Establece la ruta inicial a RUTA. Si esta ruta no existe, el explorador de archivos comenzará en el directorio raíz.

  • -show_hidden < BOOLEANO >

    Si BOOLEANO tiene un valor verdadero, también se mostrarán los archivos ocultos (el nombre de archivo comienza con un punto). Por defecto, esta opción está establecida a falso.

MÉTODOS

  • new ( OPCIONES )
  • layout ( )
  • draw ( BOOLEANO )
  • focus ( )

    Estos son métodos estándar. Ver Curses::UI::Container para una explicación de estos.

  • get ( )

    Este método devolverá la ruta completa al archivo que fue seleccionado usando el explorador de archivos. Si no se seleccionó ningún archivo, este método devolverá un valor indefinido.

LIGADURAS ESPECIALES

  • escape

    Esto invocará el botón de cancelar, por lo que el widget del explorador de archivos devolverá sin seleccionar ningún archivo.

  • ~

    Si la lista de directorios o archivos de la ventana del diálogo tiene el foco y se presiona la tecla tilde (~), el explorador de archivos cambiará el directorio al directorio de inicio del usuario actual.
