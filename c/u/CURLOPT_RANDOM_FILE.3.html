Paquete: curl

Licencias: MIT

CURLOPT_RANDOM_FILE(3) Manual de funciones de la biblioteca CURLOPT_RANDOM_FILE(3)

NOMBRE

CURLOPT_RANDOM_FILE - archivo para leer datos aleatorios

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RANDOM_FILE, char *path);

DESCRIPCIÓN

Opción obsoleta. Ya no tiene ningún propósito.

VALOR POR DEFECTO

NULL, no usado

OBSOLETO

Obsoleto desde la versión 7.84.0.

DISPONIBILIDAD

Añadido en curl 7.7

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un código CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error. Consulte libcurl-errors(3).
