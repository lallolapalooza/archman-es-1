CUT(1) Comandos de usuario CUT(1)

NOMBRE

cut - elimina secciones de cada línea de los archivos

SINOPSIS

cut OPCIÓN... [ARCHIVO]...

DESCRIPCIÓN

Imprime partes seleccionadas de líneas de cada ARCHIVO a la salida estándar.

Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas.

-b, --bytes=LISTA
selecciona solo estos bytes
-c, --characters=LISTA
selecciona solo estos caracteres
-d, --delimiter=DELIM
usa DELIM en lugar de TAB como delimitador de campo
-f, --fields=LISTA
selecciona solo estos campos; también imprime cualquier línea que no contenga el carácter delimitador, a menos que se especifique la opción -s
-n
(ignorado)
--complement
complementa el conjunto de bytes, caracteres o campos seleccionados
-s, --only-delimited
no imprime líneas que no contengan delimitadores
--output-delimiter=CADENA
usa CADENA como delimitador de salida. El valor predeterminado es usar el delimitador de entrada
-z, --zero-terminated
el delimitador de línea es NUL, no nueva línea
--help
muestra esta ayuda y sale
--version
muestra información de versión y sale

Usa una y solo una de las opciones -b, -c o -f. Cada LISTA se compone de un rango, o de varios rangos separados por comas. La entrada seleccionada se escribe en el mismo orden en que se lee, y se escribe exactamente una vez. Cada rango es uno de:

N
N-ésimo byte, carácter o campo, contado desde 1
N-
desde el N-ésimo byte, carácter o campo, hasta el final de la línea
N-M
desde el N-ésimo hasta el M-ésimo (incluido) byte, carácter o campo
-M
desde el primer hasta el M-ésimo (incluido) byte, carácter o campo
