CURLOPT_OPENSOCKETFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_OPENSOCKETFUNCTION(3) Manual de funciones de biblioteca CURLOPT_OPENSOCKETFUNCTION(3)

NOMBRE

CURLOPT_OPENSOCKETFUNCTION - callback para abrir socket

SINOPSIS

#include <curl/curl.h>
typedef enum  {
  CURLSOCKTYPE_IPCXN,  /* socket creado para una conexión IP específica */
} curlsocktype;
struct curl_sockaddr {
  int family;
  int socktype;
  int protocol;
  unsigned int addrlen;
  struct sockaddr addr;
};
curl_socket_t opensocket_callback(void *clientp,
                                  curlsocktype purpose,
                                  struct curl_sockaddr *address);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_OPENSOCKETFUNCTION, opensocket_callback);

DESCRIPCIÓN

Pase un puntero a su función de callback, que debe coincidir con el prototipo mostrado anteriormente.

Esta función de callback es llamada por libcurl en lugar de la llamada a socket(2). El argumento purpose de la callback identifica el propósito exacto de este socket en particular. CURLSOCKTYPE_IPCXN es para conexiones basadas en IP y es el único propósito utilizado actualmente en libcurl. Versiones futuras de libcurl pueden soportar más propósitos.

El puntero clientp contiene cualquier valor definido por el usuario establecido usando la función CURLOPT_OPENSOCKETDATA(3).

La callback recibe la dirección del par resuelta como argumento address y tiene permitido modificar la dirección o negarse a conectar completamente. La función de callback debe devolver el socket recién creado o CURL_SOCKET_BAD en caso de que no se haya podido establecer ninguna conexión o se haya detectado otro error. Cualquier llamada adicional a setsockopt(2) puede, por supuesto, hacerse sobre el socket a discreción del usuario.

Si la callback devuelve CURL_SOCKET_BAD, libcurl lo trata como una conexión fallida e intenta abrir un socket para conectarse a otra dirección IP asociada con la transferencia. Si no quedan más direcciones para intentar, libcurl falla la transferencia con el código de error CURLE_COULDNT_CONNECT.

Puede obtener la dirección IP para la que curl está abriendo el socket convirtiendo address->addr a sockaddr_in si address->family es AF_INET, o a sockaddr_in6 si address->family es AF_INET6. Para un ejemplo de cómo se pueden comparar esos datos, consulte docs/examples/block_ip.c.

Si desea pasar un socket con una conexión ya establecida, devuelva el socket con esta callback y luego use CURLOPT_SOCKOPTFUNCTION(3) para indicar que ya está conectado.

POR DEFECTO

El equivalente de esto:

   return socket(addr->family, addr->socktype, addr->protocol);

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

/* hacer que libcurl use el socket ya establecido 'sockfd' */
static curl_socket_t opensocket(void *clientp,
                                curlsocktype purpose,
                                struct curl_sockaddr *address)
{
  curl_socket_t sockfd;
  sockfd = *(curl_socket_t *)clientp;
  /* el socket externamente establecido se pasa a través de la opción
     OPENSOCKETDATA */
  return sockfd;
}
static int sockopt_callback(void *clientp, curl_socket_t curlfd,
                            curlsocktype purpose)
{
  return CURL_SOCKOPT_ALREADY_CONNECTED;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    extern int sockfd; /* el ya conectado */
    /* libcurl piensa que te conectas al host
     * y puerto que especificas en la opción URL. */
    curl_easy_setopt(curl, CURLOPT_URL, "http://99.99.99.99:9999");
    /* llamar a esta función para obtener un socket */
    curl_easy_setopt(curl, CURLOPT_OPENSOCKETFUNCTION, opensocket);
    curl_easy_setopt(curl, CURLOPT_OPENSOCKETDATA, &sockfd);
    /* llamar a esta función para establecer opciones en el socket */
    curl_easy_setopt(curl, CURLOPT_SOCKOPTFUNCTION, sockopt_callback);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.17.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
