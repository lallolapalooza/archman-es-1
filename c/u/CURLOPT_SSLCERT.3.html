CURLOPT_SSLCERT(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSLCERT(3) Manual de funciones de la biblioteca CURLOPT_SSLCERT(3)

NOMBRE

CURLOPT_SSLCERT - certificado de cliente SSL

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLCERT, char *cert);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. La cadena debe ser el nombre del archivo de su certificado de cliente. El formato predeterminado es PEM, pero se puede cambiar con CURLOPT_SSLCERTTYPE(3).

(Schannel) Los certificados de cliente se pueden especificar mediante una expresión de ruta a un almacén de certificados. (Puede importar PFX a un almacén primero). Puede usar "<ubicación del almacén>\<nombre del almacén>\<huella digital>" para referirse a un certificado en el almacén de certificados del sistema, por ejemplo, "CurrentUser\MY\934a7ac6f8a5d5". La huella digital suele ser una cadena hexadecimal SHA-1 que puede ver en los detalles del certificado. Las siguientes ubicaciones de almacén son compatibles: CurrentUser, LocalMachine, CurrentService, Services, CurrentUserGroupPolicy, LocalMachineGroupPolicy, LocalMachineEnterprise. Schannel también admite archivos de certificado P12, con la cadena P12 especificada con CURLOPT_SSLCERTTYPE(3).

Al usar un certificado de cliente, lo más probable es que también necesite proporcionar una clave privada con CURLOPT_SSLKEY(3).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para volver a deshabilitar su uso.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL, Schannel, mbedTLS y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLCERT, "client.pem");
    curl_easy_setopt(curl, CURLOPT_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_KEYPASSWD(3), CURLOPT_SSLCERTTYPE(3), CURLOPT_SSLKEY(3)
