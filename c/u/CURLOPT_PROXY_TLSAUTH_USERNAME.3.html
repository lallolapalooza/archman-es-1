CURLOPT_PROXY_TLSAUTH_USERNAME(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_TLSAUTH_USERNAME(3) Manual de funciones de la biblioteca CURLOPT_PROXY_TLSAUTH_USERNAME(3)

NOMBRE

CURLOPT_PROXY_TLSAUTH_USERNAME - nombre de usuario para usar en la autenticación TLS del proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_TLSAUTH_USERNAME,
                          char *user);

DESCRIPCIÓN

Pase un puntero a char como parámetro, que debe apuntar al nombre de usuario terminado en nulo para usar en el método de autenticación TLS del proxy HTTPS especificado con la opción CURLOPT_PROXY_TLSAUTH_TYPE(3). Requiere que la opción CURLOPT_PROXY_TLSAUTH_PASSWORD(3) también esté establecida.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para deshabilitar su uso nuevamente.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS y OpenSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_TYPE, "SRP");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_USERNAME, "user");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_PASSWORD, "secret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
