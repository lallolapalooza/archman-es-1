DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine cunbdb6 (integer m1, integer m2, integer n, complex, dimension(*) x1, integer incx1, complex, dimension(*) x2, integer incx2, complex, dimension(ldq1,*) q1, integer ldq1, complex, dimension(ldq2,*) q2, integer ldq2, complex, dimension(*) work, integer lwork, integer info)

CUNBDB6

Propósito:

!>
!> CUNBDB6 ortogonaliza el vector de columna
!>      X = [ X1 ]
!>          [ X2 ]
!> con respecto a las columnas de
!>      Q = [ Q1 ] .
!>          [ Q2 ]
!> Las columnas de Q deben ser ortonormales. El vector ortogonalizado será
!> cero si y solo si yace completamente en el rango de Q.
!>
!> La proyección se calcula con un máximo de dos iteraciones del
!> algoritmo clásico de Gram-Schmidt, ver
!> * L. Giraud, J. Langou, M. Rozložník. 
!>   2002. Informe Técnico de CERFACS No. TR/PA/02/33. URL:
!>   https://www.cerfacs.fr/algor/reports/2002/TR_PA_02_33.pdf
!>
!>

Parámetros

M1 
!>          M1 es INTEGER
!>           La dimensión de X1 y el número de filas de Q1. 0 <= M1.
!>

M2

!>          M2 es INTEGER
!>           La dimensión de X2 y el número de filas de Q2. 0 <= M2.
!>

N

!>          N es INTEGER
!>           El número de columnas de Q1 y Q2. 0 <= N.
!>

X1

!>          X1 es array COMPLEX, dimension (M1)
!>           En la entrada, la parte superior del vector a ortogonalizar.
!>           En la salida, la parte superior del vector proyectado.
!>

INCX1

!>          INCX1 es INTEGER
!>           Incremento para las entradas de X1.
!>

X2

!>          X2 es array COMPLEX, dimension (M2)
!>           En la entrada, la parte inferior del vector a
!>           ortogonalizar. En la salida, la parte inferior del vector
!>           proyectado.
!>

INCX2

!>          INCX2 es INTEGER
!>           Incremento para las entradas de X2.
!>

Q1

!>          Q1 es array COMPLEX, dimension (LDQ1, N)
!>           La parte superior de la matriz de base ortonormal.
!>

LDQ1

!>          LDQ1 es INTEGER
!>           La dimensión principal de Q1. LDQ1 >= M1.
!>

Q2

!>          Q2 es array COMPLEX, dimension (LDQ2, N)
!>           La parte inferior de la matriz de base ortonormal.
!>

LDQ2

!>          LDQ2 es INTEGER
!>           La dimensión principal de Q2. LDQ2 >= M2.
!>

WORK

!>          WORK es array COMPLEX, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= N.
!>

INFO

!>          INFO es INTEGER
!>           = 0:  salida exitosa.
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
