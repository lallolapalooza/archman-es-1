curl_multi_cleanup(3)

Paquete: curl

Licencias: MIT

curl_multi_cleanup(3) Manual de Funciones de Biblioteca curl_multi_cleanup(3)

NOMBRE

curl_multi_cleanup - cerrar una sesión múltiple

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_cleanup(CURLM *multi_handle);

DESCRIPCIÓN

Esta función es lo opuesto a curl_multi_init(3). Limpia y elimina toda la pila múltiple. No libera ni toca de ninguna manera los handles individuales (easy handles), estos aún deben cerrarse individualmente, usando la forma habitual de curl_easy_cleanup(3). El orden de limpieza debería ser:

1 - curl_multi_remove_handle(3) antes de que se limpien los handles individuales

2 - Ahora se puede llamar a curl_easy_cleanup(3) independientemente, ya que el handle individual ya no está conectado al handle múltiple.

3 - Se debe llamar a curl_multi_cleanup(3) cuando se han eliminado todos los handles individuales.

Cuando se llama a esta función, las entradas restantes en el pool de conexiones que mantiene el handle múltiple se cierran, lo que podría desencadenar llamadas a la función de devolución de llamada CURLMOPT_SOCKETFUNCTION(3).

Pasar un puntero NULL en multi_handle hace que esta función devuelva CURLM_BAD_HANDLE inmediatamente sin ninguna otra acción.

Cualquier uso de multi_handle después de que esta función haya sido llamada y haya retornado, es ilegal.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados.

EJEMPLO

int main(void)
{
  CURLM *multi = curl_multi_init();
  /* cuando la transferencia múltiple esté hecha ... */
  /* elimina todos los handles individuales, luego: */
  curl_multi_cleanup(multi);
}

DISPONIBILIDAD

Añadido en curl 7.9.6

VALOR DEVUELTO

Esta función devuelve un CURLMcode indicando éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
