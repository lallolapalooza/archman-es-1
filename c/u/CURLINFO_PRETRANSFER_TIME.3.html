CURLINFO_PRETRANSFER_TIME(3)

Paquete: curl

Licencias: MIT

CURLINFO_PRETRANSFER_TIME(3) Manual de funciones de la biblioteca CURLINFO_PRETRANSFER_TIME(3)

NOMBRE

CURLINFO_PRETRANSFER_TIME - obtener el tiempo hasta el inicio de la transferencia de archivos

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_PRETRANSFER_TIME,
                           double *timep);

DESCRIPCIÓN

Pase un puntero a un double para recibir el tiempo, en segundos, que tardó desde el inicio hasta que la transferencia de archivos está a punto de comenzar.

Este sello de tiempo incluye todos los comandos y negociaciones previos a la transferencia que son específicos de los protocolos involucrados. Incluye el envío de las instrucciones específicas del protocolo que activan una transferencia.

Cuando se sigue una redirección, se suman los tiempos de cada solicitud.

Consulte también la descripción general de TIEMPOS en la página del manual de curl_easy_getinfo(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    double pretransfer;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_PRETRANSFER_TIME, &pretransfer);
      if(CURLE_OK == res) {
        printf("Tiempo: %.1f", pretransfer);
      }
    }
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.4.1

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).

VER TAMBIÉN
