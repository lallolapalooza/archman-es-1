CURLOPT_PROXY_CAINFO(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_CAINFO(3) Manual de funciones de la biblioteca CURLOPT_PROXY_CAINFO(3)

NOMBRE

CURLOPT_PROXY_CAINFO - ruta al paquete de Autoridad de Certificación (CA) del proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CAINFO, char *path);

DESCRIPCIÓN

Esta opción es para conectarse a un proxy HTTPS, no a un servidor HTTPS.

Pase un puntero a `char` a una cadena terminada en nulo que nombre un archivo que contenga uno o más certificados para verificar el proxy HTTPS.

Si CURLOPT_PROXY_SSL_VERIFYPEER(3) es cero y usted evita verificar el certificado del servidor, CURLOPT_PROXY_CAINFO(3) no necesita indicar siquiera un archivo accesible.

Esta opción se establece por defecto en la ruta del sistema donde se asume que está almacenado el paquete de certificados CA de libcurl, tal como se estableció en el momento de la compilación.

La aplicación no tiene que conservar la cadena después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a `NULL` para deshabilitar su uso nuevamente y volver a la configuración predeterminada interna.

El valor predeterminado para esto se puede averiguar con CURLINFO_CAINFO(3).

POR DEFECTO

Específico del sistema incorporado

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Todos los backends TLS admiten esta opción.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* usando un proxy HTTPS */
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:443");
    curl_easy_setopt(curl, CURLOPT_PROXY_CAINFO, "/etc/certs/cabundle.pem");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

NOTAS

Para backends TLS que no admiten archivos de certificados, la opción CURLOPT_PROXY_CAINFO(3) se ignora. Consulte https://curl.se/docs/ssl-compared.html

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un `CURLcode` que indica éxito o error.

`CURLE_OK` (0) significa que todo estuvo bien, cualquier otro valor indica un error, consulte libcurl-errors(3).

VER TAMBIÉN
