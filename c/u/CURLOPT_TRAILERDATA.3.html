CURLOPT_TRAILERDATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_TRAILERDATA(3) Manual de funciones de biblioteca CURLOPT_TRAILERDATA(3)

NOMBRE

CURLOPT_TRAILERDATA - puntero pasado a la devolución de llamada de encabezados finales

SINOPSIS

#include <curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TRAILERDATA, void *userdata);

DESCRIPCIÓN

Puntero de datos que se pasará a la función de devolución de llamada de encabezados finales de HTTP.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad solo afecta a http

EJEMPLO

struct MyData {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct MyData data;
    curl_easy_setopt(curl, CURLOPT_TRAILERDATA, &data);
  }
}

DISPONIBILIDAD

Añadido en curl 7.64.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

CURLOPT_TRAILERFUNCTION(3), CURLOPT_WRITEFUNCTION(3)
