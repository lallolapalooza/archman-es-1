curl_easy_init(3)

Paquete: curl

Licencias: MIT

curl_easy_init(3) Manual de funciones de la biblioteca curl_easy_init(3)

NOMBRE

curl_easy_init - crear un identificador fácil

SINOPSIS

#include <curl/curl.h>
CURL *curl_easy_init();

DESCRIPCIÓN

Esta función asigna y devuelve un identificador fácil. Dicho identificador se utiliza como entrada para otras funciones de la interfaz fácil. Esta llamada debe tener una llamada correspondiente a curl_easy_cleanup(3) cuando la operación esté completa.

El identificador fácil se utiliza para mantener y controlar una única transferencia de red. Se recomienda reutilizar identificadores fáciles para transferencias repetidas.

Una forma alternativa de obtener un nuevo identificador fácil es duplicar uno ya existente con curl_easy_duphandle(3), que tiene la ventaja de que obtiene todas las opciones que se establecieron en el identificador de origen y las establece también en la nueva copia.

Si aún no ha llamado a curl_global_init(3) antes de llamar a esta función, curl_easy_init(3) lo hace automáticamente. Esto puede ser letal en casos multihilo para plataformas donde curl_global_init(3) no es seguro para hilos, y puede resultar en problemas de recursos porque no hay una limpieza correspondiente.

Se le recomienda encarecidamente que no permita este comportamiento automático, llamando a curl_global_init(3) usted mismo correctamente. Consulte la descripción en libcurl(3) sobre los requisitos del entorno global para obtener detalles sobre cómo usar esta función.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Si esta función devuelve NULL, algo salió mal y no podrá utilizar las otras funciones de curl.

VER TAMBIÉN

curl_easy_cleanup(3), curl_easy_duphandle(3), curl_easy_perform(3), curl_easy_reset(3), curl_global_init(3), curl_multi_init(3)
