NOMBRE

Curses::UI::Dialog::Progress - Crear y manipular diálogos de progreso

HIERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Progress

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La forma difícil.
# -------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Progress',
-max       => 100,
    -message   => 'Algún mensaje',
);
$dialog->pos(10);
$dialog->message('Otro mensaje');
$dialog->draw();
$win->delete('mydialog');
# La forma fácil (ver la documentación de Curses::UI).
# --------------------------------------------
$cui->progress(
-max       => 100,
    -message   => 'Algún mensaje',
);
$cui->setprogress(10, 'Otro mensaje');
$cui->noprogress;

DESCRIPCIÓN

Curses::UI::Dialog::Progress no es realmente un diálogo, ya que el usuario no tiene forma de interactuar con él. Es meramente una forma de presentar información de progreso al usuario de tu programa.

Ver exampes/demo-Curses::UI::Dialog::Progress en la distribución para una demostración corta.

OPCIONES

  • -title < TEXTO >

    Establece el título de la ventana de diálogo a TEXTO.

  • -message < TEXTO >

    Esta opción establece el mensaje inicial a mostrar a TEXTO. Este mensaje se muestra usando una Curses::UI::Label, así que no puede contener ningún carácter de nueva línea (\n).

  • -nomessage < BOOLEANO >

    Si BOOLEANO tiene un valor verdadero, la ventana de diálogo no contendrá una etiqueta de mensaje. Por defecto, -nomessage tiene un valor falso.

  • -min < VALOR >
  • -max < VALOR >
  • -pos < VALOR >
  • -nopercentage < BOOLEANO >
  • -nocenterline < BOOLEANO >

    Estas opciones controlan la barra de progreso del diálogo. Para una explicación de estas opciones, ver Curses::UI::Progressbar.

MÉTODOS

  • new ( OPCIONES )
  • layout ( )
  • draw ( BOOLEANO )

    Estos son métodos estándar. Ver Curses::UI::Container para una explicación de estos.

  • pos ( VALOR )

    Este método actualizará la posición de la barra de progreso a ESCALAR. Deberás llamar al método draw para ver los cambios.

  • message ( TEXTO )

    Este método actualizará el mensaje del diálogo de progreso a TEXTO. Deberás llamar al método draw para ver los cambios.

VER TAMBIÉN

Curses::UI, Curses::UI::Container, Curses::UI::Progressbar
