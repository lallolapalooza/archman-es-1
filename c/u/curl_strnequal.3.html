curl_strnequal(3)

Paquete: curl

Licencias: MIT

curl_strnequal(3) Manual de funciones de la biblioteca curl_strnequal(3)

NOMBRE

curl_strnequal - compara dos cadenas ignorando mayúsculas y minúsculas

SINOPSIS

#include <curl/curl.h>
int curl_strnequal(const char *str1, const char *str2, size_t length);

DESCRIPCIÓN

La función curl_strnequal(3) compara las dos cadenas str1 y str2, ignorando la mayúscula/minúscula de los caracteres. Devuelve un entero distinto de cero (VERDADERO) si las cadenas son idénticas.

Esta función compara como máximo los primeros length bytes de str1 y str2.

Esta función realiza comparaciones basadas únicamente en ASCII, ignorando completamente la configuración regional, a diferencia de cómo funcionan normalmente strcasecmp y otras comparaciones de cadenas del sistema que no distinguen entre mayúsculas y minúsculas.

Esta función es proporcionada por libcurl para permitir a las aplicaciones comparar cadenas de una manera verdaderamente portable. No existen funciones de comparación de cadenas que no distingan entre mayúsculas y minúsculas y sean portables de forma estándar. Esta función funciona en todas las plataformas.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(int argc, char **argv)
{
  const char *name = "comparar";
  if(curl_strnequal(name, argv[1], 5))
    printf("El nombre y la entrada coinciden en los 5 primeros bytes\n");
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Distinto de cero si las cadenas son idénticas. Cero si no lo son.

VER TAMBIÉN

curl_strequal(3), strcasecmp(3), strcmp(3)
