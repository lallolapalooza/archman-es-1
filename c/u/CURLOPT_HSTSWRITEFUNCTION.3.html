CURLOPT_HSTSWRITEFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_HSTSWRITEFUNCTION(3) Manual de funciones de biblioteca CURLOPT_HSTSWRITEFUNCTION(3)

NOMBRE

CURLOPT_HSTSWRITEFUNCTION - función de retorno de llamada de escritura para hosts HSTS

SINOPSIS

#include <curl/curl.h>
struct curl_hstsentry {
  char *name;
  size_t namelen;
  unsigned int includeSubDomains:1;
  char expire[18]; /* AAAA MM DD HH:MM:SS [terminado en nulo] */
};
struct curl_index {
  size_t index; /* el "índice" o recuento de la entrada proporcionada */
  size_t total; /* número total de entradas a guardar */
};
CURLSTScode hstswrite(CURL *easy, struct curl_hstsentry *sts,
                      struct curl_index *count, void *clientp);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTSWRITEFUNCTION, hstswrite);

DESCRIPCIÓN

Pase un puntero a su función de retorno de llamada, según el prototipo que se muestra arriba.

libcurl llama a esta función de retorno de llamada repetidamente para permitir que la aplicación almacene la caché HSTS en memoria cuando libcurl esté a punto de descartarla.

Establezca el argumento clientp con la opción CURLOPT_HSTSWRITEDATA(3) o será NULL. Cuando la función de retorno de llamada se invoca, el puntero sts apunta a una estructura poblada: lea el nombre de host en 'name' (tiene namelen bytes de longitud y está terminado en nulo. El campo includeSubDomains es distinto de cero si la entrada coincide con subdominios. La cadena expire es una cadena terminada en nulo con formato de fecha utilizando la sintaxis AAAA MM DD HH:MM:SS.

La función de retorno de llamada debe devolver CURLSTS_OK si tuvo éxito y está preparada para ser llamada de nuevo (para otro host) o CURLSTS_DONE si no hay nada más que hacer. También puede devolver CURLSTS_FAIL para indicar un error.

Esta opción no habilita HSTS; necesita usar CURLOPT_HSTS_CTRL(3) para hacerlo.

POR OMISIÓN

NULL - sin función de retorno de llamada.

PROTOCOLOS

Esta funcionalidad afecta solo a http.

EJEMPLO

struct priv {
  void *custom;
};
static CURLSTScode hswr_cb(CURL *easy, struct curl_hstsentry *sts,
                           struct curl_index *count, void *clientp)
{
  /* guardar los datos HSTS pasados en algún lugar */
  return CURLSTS_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct priv my_stuff;
    CURLcode res;
    /* establecer la función de retorno de llamada de lectura de HSTS */
    curl_easy_setopt(curl, CURLOPT_HSTSWRITEFUNCTION, hswr_cb);
    /* pasar un argumento adecuado a la función de retorno de llamada */
    curl_easy_setopt(curl, CURLOPT_HSTSWRITEDATA, &my_stuff);
    res = curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.74.0

VALOR DE RETORNO

Devuelve CURLE_OK.

VER TAMBIÉN
