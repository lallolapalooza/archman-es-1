DESCRIPCI

ÓN

Pasa un puntero a una lista enlazada de comandos FTP o SFTP para pasar al servidor antes de tu solicitud. Esto se hace antes de que se emitan cualquier otro comando (incluso antes del comando CWD para FTP). La lista enlazada debe ser una lista completamente válida de estructuras 'struct curl_slist' correctamente rellenadas con cadenas

de
texto. Usa

curl_slist_append(3) para añadir cadenas (comandos) a la lista, y limpia la lista completa después con

curl_slist_free_all(3) 
.




Usar esta opción varias veces hace que la última lista establecida
    reemplace a las anteriores. Establécela a NULL para deshabilitar su uso
    nuevamente. libcurl no copia la lista, debe mantenerse alrededor hasta
    después de que la transferencia 
se haya completado.

Al hablar con un servidor FTP, antepone el comando con un
    asterisco (*) para hacer que libcurl continúe incluso si el comando falla,
    ya que por defecto libcurl se detiene en el primer fallo. El conjunto de comandos FTP válidos depende del servidor (ver RFC 959
    para una lista de comandos obligatorios).
    libcurl no inspecciona, analiza ni "entiende" los
    comandos pasados al servidor usando esta opción. Si cambias el estado de
    la conexión, el directorio de trabajo o algo similar usando comandos
    quote, libcurl no 
se entera.

Los argumentos de ruta para FTP o SFTP deben usar comillas dobles para
    distinguir un espacio de ser el separador de parámetros o ser parte de la
    ruta. Por ejemplo, renombrar con sftp usando un comando quote 
así:

rename "test/_upload.txt" "test/Hello World.
txt"

Para SFTP, los nombres de archivo deben proporcionarse dentro de comillas dobles para incrustar
    espacios, barras invertidas, comillas o comillas dobles. Dentro de comillas dobles las
    siguientes secuencias de escape están disponibles para ese propósito:
 \,

int main(void)
{
  struct curl_slist *cmdlist = NULL;
  cmdlist = curl_slist_append(cmdlist, "RNFR source-name");
  cmdlist = curl_slist_append(cmdlist, "RNTO new-name");
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/foo.bin");
    /* pasa los comandos FTP a ejecutar antes de la transferencia */
    curl_easy_setopt(curl, CURLOPT_QUOTE, cmdlist);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
  curl_slist_free_all(cmdlist);


}
