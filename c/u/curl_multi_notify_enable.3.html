curl_multi_notify_enable(3)

Paquete: curl

Licencias: MIT

curl_multi_notify_enable(3) Manual de funciones de la biblioteca curl_multi_notify_enable(3)

NOMBRE

curl_multi_notify_enable - habilita un tipo de notificación

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_notify_enable(CURLM *multi_handle,
                                   unsigned int notification);

DESCRIPCIÓN

Habilita la recopilación del tipo de notificación dado en el manejador multi. Una función de devolución de llamada instalada a través de CURLMOPT_NOTIFYFUNCTION(3) se llama cuando ocurre esta notificación.

Solo cuando se instala una función de devolución de llamada de notificación y se habilita una notificación, estas se recopilan y se envían a la función de devolución de llamada.

Se pueden habilitar varios tipos de notificación al mismo tiempo. Habilitar una notificación que ya está habilitada no es un error.

Una notificación se puede deshabilitar de nuevo a través de curl_multi_notify_disable(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  int rc;
  CURLM *multi = curl_multi_init();
  rc = curl_multi_notify_enable(multi, CURLMNOTIFY_INFO_READ);
}

DISPONIBILIDAD

Añadido en curl 8.17.0

VALOR DE RETORNO

Esta función devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

El código de retorno es para toda la pila multi. Aún pueden haber ocurrido problemas en transferencias individuales incluso cuando una de estas funciones devuelve OK.

VER TAMBIÉN

CURLMOPT_NOTIFYDATA(3), CURLMOPT_NOTIFYFUNCTION(3), curl_multi_notify_disable(3)
