Documentación de la función/subrutina

subrutina cungbr (character vect, integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGBR

Propósito

!>
!> CUNGBR genera una de las matrices unitarias complejas Q o P**H
!> determinadas por CGEBRD al reducir una matriz compleja A a forma
!> bidiagonal: A = Q * B * P**H. Q y P**H se definen como productos de
!>   reflectores elementales H(i) o G(i) respectivamente.
!>
!> Si VECT = 'Q', se asume que A ha sido una matriz M-por-K, y Q
!> es de orden M:
!> si m >= k, Q = H(1) H(2) . . . H(k) y CUNGBR devuelve las primeras n
!> columnas de Q, donde m >= n >= k;
!> si m < k, Q = H(1) H(2) . . . H(m-1) y CUNGBR devuelve Q como una
!> matriz M-por-M.
!>
!> Si VECT = 'P', se asume que A ha sido una matriz K-por-N, y P**H
!> es de orden N:
!> si k < n, P**H = G(k) . . . G(2) G(1) y CUNGBR devuelve las primeras m
!> filas de P**H, donde n >= m >= k;
!> si k >= n, P**H = G(n-1) . . . G(2) G(1) y CUNGBR devuelve P**H como
!> una matriz N-por-N.
!>

Parámetros

VECT 
!>          VECT es CHARACTER*1
!>          Especifica si se requiere la matriz Q o la matriz P**H,
!>          como se define en la transformación aplicada por CGEBRD:
!>          = 'Q': generar Q;
!>          = 'P': generar P**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz Q o P**H a devolver.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q o P**H a devolver.
!>          N >= 0.
!>          Si VECT = 'Q', M >= N >= min(M,K);
!>          si VECT = 'P', N >= M >= min(N,K).
!>

K

!>          K es INTEGER
!>          Si VECT = 'Q', el número de columnas en la matriz original
!>          M-por-K reducida por CGEBRD.
!>          Si VECT = 'P', el número de filas en la matriz original
!>          K-por-N reducida por CGEBRD.
!>          K >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, los vectores que definen los reflectores
!>          elementales, como se devuelven por CGEBRD.
!>          En la salida, la matriz M-por-N Q o P**H.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= M.
!>

TAU

!>          TAU es un array COMPLEX, dimensión
!>                                (min(M,K)) si VECT = 'Q'
!>                                (min(N,K)) si VECT = 'P'
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i) o G(i), que determina Q o P**H, como
!>          se devuelve por CGEBRD en su array de argumentos TAUQ o TAUP.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,min(M,N)).
!>          Para un rendimiento óptimo LWORK >= min(M,N)*NB, donde NB
!>          es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array
!>          WORK, devuelve este valor como la primera entrada del array
!>          WORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
