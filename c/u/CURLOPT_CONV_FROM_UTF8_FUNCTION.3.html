CURLOPT_CONV_FROM_UTF8_FUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_CONV_FROM_UTF8_FUNCTION(3) Manual de funciones de biblioteca CURLOPT_CONV_FROM_UTF8_FUNCTION(3)

NOMBRE

CURLOPT_CONV_FROM_UTF8_FUNCTION - convierte datos de UTF8 a la codificación del host

SINOPSIS

#include <curl/curl.h>
CURLcode conv_callback(char *ptr, size_t length);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONV_FROM_UTF8_FUNCTION,
                          conv_callback);

DESCRIPCIÓN

Pase un puntero a su función de devolución de llamada, que debe coincidir con el prototipo mostrado anteriormente.

Se aplica a plataformas no ASCII. curl_version_info(3) devuelve el bit de función CURL_VERSION_CONV establecido si se proporciona esta opción.

Los datos a convertir se encuentran en un búfer apuntado por el parámetro ptr. La cantidad de datos a convertir se indica mediante el parámetro length. Los datos convertidos sobrescriben los datos de entrada en el búfer apuntado por el parámetro ptr. Se debe devolver CURLE_OK tras una conversión exitosa. Se debe devolver un valor de código CURL definido por curl.h, como CURLE_CONV_FAILED, si se encontró un error.

CURLOPT_CONV_FROM_UTF8_FUNCTION(3) convierte a la codificación del host desde la codificación UTF8. Solo es necesario para el procesamiento SSL.

Si establece un puntero de devolución de llamada a NULL, o no lo establece en absoluto, se utilizan las funciones iconv integradas de libcurl. Si HAVE_ICONV no se definió cuando se compiló libcurl, y no se ha establecido ninguna devolución de llamada, la conversión devuelve el código de error CURLE_CONV_REQD.

Si HAVE_ICONV está definido, CURL_ICONV_CODESET_OF_HOST también debe estar definido. Por ejemplo:

 #define CURL_ICONV_CODESET_OF_HOST "IBM-1047"

La función iconv en libcurl define por defecto los nombres de los conjuntos de códigos de red y UTF8 de la siguiente manera:

#define CURL_ICONV_CODESET_OF_NETWORK "ISO8859-1"
#define CURL_ICONV_CODESET_FOR_UTF8   "UTF-8"

Debe anular estas definiciones si son diferentes en su sistema.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

static CURLcode my_conv_from_utf8_to_ebcdic(char *buffer, size_t length)
{
  int rc = 0;
  /* convierte in-situ 'buffer' de UTF-8 a EBCDIC */
  if(rc == 0) {
    /* éxito */
    return CURLE_OK;
  }
  else {
    return CURLE_CONV_FAILED;
  }
}
int main(void)
{
  CURL *curl = curl_easy_init();
  curl_easy_setopt(curl, CURLOPT_CONV_FROM_UTF8_FUNCTION,
                   my_conv_from_utf8_to_ebcdic);
}

OBSOLETO

No disponible y obsoleto desde la versión 7.82.0.

Disponible solo si CURL_DOES_CONVERSIONS se definió al compilar libcurl.

DISPONIBILIDAD

Añadido en curl 7.15.4

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_CONV_FROM_NETWORK_FUNCTION(3), CURLOPT_CONV_TO_NETWORK_FUNCTION(3)
