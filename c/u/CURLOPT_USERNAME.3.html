CURLOPT_USERNAME(3)

Paquete: curl

Licencias: MIT

CURLOPT_USERNAME(3) Manual de funciones de biblioteca CURLOPT_USERNAME(3)

NOMBRE

CURLOPT_USERNAME - nombre de usuario a usar en la autenticación

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_USERNAME,
                          char *username);

DESCRIPCIÓN

Pase un puntero a un carácter como parámetro, que debe apuntar al nombre de usuario terminado en nulo que se utilizará para la transferencia.

CURLOPT_USERNAME(3) establece el nombre de usuario que se utilizará en la autenticación de protocolos. No debe usar esta opción junto con la opción (más antigua) CURLOPT_USERPWD(3).

Al usar autenticación Kerberos V5 con un servidor basado en Windows, debe incluir el nombre del dominio para que el servidor pueda obtener con éxito un Ticket Kerberos. Si no lo hace, la parte inicial del protocolo de enlace de autenticación puede fallar.

Al usar NTLM, el nombre de usuario se puede especificar simplemente como el nombre de usuario sin el nombre del dominio si el servidor forma parte de un único dominio y bosque.

Para incluir el nombre del dominio, use los formatos de nombre de inicio de sesión de nivel inferior (Down-Level Logon Name) o UPN (User Principal Name). Por ejemplo, EXAMPLEser y user@example.com respectivamente.

Algunos servidores HTTP (en Windows) también admiten la inclusión del dominio para la autenticación básica.

Para especificar la contraseña y las opciones de inicio de sesión, junto con el nombre de usuario, use las opciones CURLOPT_PASSWORD(3) y CURLOPT_LOGIN_OPTIONS(3).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

DEFECTO

en blanco

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_USERNAME, "clark");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.19.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
