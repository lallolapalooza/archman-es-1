CURLINFO_SSL_VERIFYRESULT(3)

Paquete: curl

Licencias: MIT

CURLINFO_SSL_VERIFYRESULT(3) Manual de funciones de la biblioteca CURLINFO_SSL_VERIFYRESULT(3)

NOMBRE

CURLINFO_SSL_VERIFYRESULT - obtener el resultado de la verificación del certificado

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_SSL_VERIFYRESULT,
                           long *result);

DESCRIPCIÓN

Pase un puntero a un long para recibir el resultado de la verificación del certificado SSL del servidor que se solicitó (utilizando la opción CURLOPT_SSL_VERIFYPEER(3)).

0 es un resultado positivo. Cualquier valor distinto de cero es un error.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS y OpenSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    long verifyresult;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(res) {
      printf("error: %s\n", curl_easy_strerror(res));
      curl_easy_cleanup(curl);
      return 1;
    }
    res = curl_easy_getinfo(curl, CURLINFO_SSL_VERIFYRESULT,
                            &verifyresult);
    if(!res) {
      printf("La verificación del par dijo %s\n",
             (verifyresult ? "mal" : "bien"));
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.5

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; véase libcurl-errors(3).

VER TAMBIÉN

CURLINFO_PROXY_SSL_VERIFYRESULT(3), curl_easy_getinfo(3), curl_easy_setopt(3)
