DESCRIPCIÓ

N

Pase un long con una máscara de bits para indicar a libcurl sobre comportamientos específicos de SSL. Bits

disponibles:
CURLSSLOPT_ALLOW_BE
AST
Indica a libcurl que no intente usar ninguna solución alternativa para una falla de seguridad en los protocolos SSL3 y TLS1.0. Si esta opción no se usa o este bit se establece a 0, la capa SSL que usa libcurl podría usar una solución alternativa para esta falla, aunque podría causar problemas de interoperabilidad con algunas implementaciones de SSL (más antiguas). ADVERTENCIA: evitar esta solución alternativa reduce la seguridad, y al establecer esta opción en 1 usted solicita exactamente eso. Esta opción solo es compatible con Secure Transport y
OpenSSL.
CURLSSLOPT_NO_REV
OKE
Indica a libcurl que desactive las comprobaciones de revocación de certificados para aquellos backends SSL donde tal comportamiento está presente. Esta opción solo es compatible con Schannel (la biblioteca SSL nativa de Windows), con una excepción en el caso de la lista de bloqueo de Editores No Confiables de Windows, la cual parece no poder ser
evadida.
CURLSSLOPT_NO_PARTIALCH
AIN
Indica a libcurl que no acepte cadenas de certificados "parciales", las cuales de otro modo acepta por defecto. Esta opción hace fallar la verificación del certificado si la cadena termina con un certificado intermedio y no con un certificado raíz.

Funciona con OpenSSL y sus derivados (LibreSSL, BoringSSL, etc). (Añadido en 7.

68.0)

Funciona con Schannel si el usuario especificó certificados para verificar al par. (Añadido en

8.15.
0)
CURLSSLOPT_REVOKE_BEST_EFF
ORT
Indica a libcurl que ignore las comprobaciones de revocación de certificados en caso de puntos de distribución faltantes u offline para aquellos backends SSL donde tal comportamiento está presente. Esta opción solo es compatible con Schannel (la biblioteca SSL nativa de Windows). Si se combina con CURLSSLOPT_NO_REVOKE, el último tiene prioridad. (Añadido en 7.70.
0)
CURLSSLOPT_NATIVE
_CA
Indica a libcurl que use el almacén de CA nativo del sistema operativo para la verificación de certificados. Esta opción es independiente de otras ubicaciones de certificados CA establecidas en tiempo de ejecución o de compilación. Esas ubicaciones se buscan además del almacén de CA nativo.

Funciona con wolfSSL en Windows, Linux (Debian, Ubuntu, Gentoo, Fedora, RHEL), macOS, Android y iOS (añadido en 8.3.0); con GnuTLS (añadido en 8.5.0) y con OpenSSL y sus derivados (LibreSSL, BoringSSL, etc) en Windows (Añadido en 7.

71.0).

Esto funciona con rustls en Windows, macOS, Android y iOS. En Linux es equivalente a usar el paquete de certificados CA de Mozilla. Cuando se usa con rustls _solo_ se consulta el almacén de CA nativo, no otras ubicaciones establecidas en tiempo de ejecución o de compilación. (Añadido en

8.13.
0)
CURLSSLOPT_AUTO_CLIENT_C
ERT
Indica a libcurl que localice y use automáticamente un certificado de cliente para la autenticación, cuando lo solicite el servidor. Esta opción solo es compatible con Schannel (la biblioteca SSL nativa de Windows). Antes de la versión 7.77.0 este era el comportamiento por defecto en libcurl con Schannel. Dado que el servidor puede solicitar cualquier certificado que soporte autenticación de cliente en el almacén de certificados del SO, esto podría ser una violación de privacidad e inesperado. (Añadido en 7.77.
0)
CURLSSLOPT_EARLYD
ATA
Indica a libcurl que intente enviar datos de aplicación como datos tempranos de TLS1.3. Esta opción es compatible con GnuTLS, wolfS
SL, quictls y OpenSSL (pero no con BoringSSL o AWS-LC). Funciona en conexiones TCP y QUIC usando ngtcp2. Esta opción funciona sobre
una base de mejor esfuerzo; en los casos en que no fue posible enviar datos tempranos, la solicitud se reenvía normalmente de
spués del handshake. Esta opción no funciona al usar QUIC. (Añadido en 8.11.0 para GnuTLS y 8.13.0 para wolfSSL, quictls y OpenSSL)

0

PROTOCOLO

S

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS

etc.

Todos los backe

nds TLS soport
an esta opción.

EJEMPL

O 
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* debilitar TLS solo para usar con servidores tontos */
    curl_easy_setopt(curl, CURLOPT_SSL_OPTIONS,
                     CURLSSLOPT_ALLOW_BEAST | CURLSSLOPT_NO_REVOKE);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}
