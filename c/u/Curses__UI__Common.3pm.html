NOMBRE

Curses::UI::Common - Métodos comunes para Curses::UI

JERARQUÍA DE CLASES

Curses::UI::Common - clase base

SINOPSIS

package MiPaquete;
use Curses::UI::Common;
use vars qw(@ISA);
@ISA = qw(Curses::UI::Common);

DESCRIPCIÓN

Curses::UI::Common es una colección de métodos que se comparten entre las clases de Curses::UI.

MÉTODOS

Varios métodos

  • parent ( )

    Devuelve el miembro de datos $this->{-parent}.

  • root ( )

    Devuelve el -parent superior (la instancia de Curses::UI).

  • delallwin ( )

    Este método recorrerá todos los miembros de datos de la instancia de la clase. Cada miembro de datos que sea un descendiente de Curses::Window será eliminado.

  • accessor ( NOMBRE, [VALOR] )

    Si se establece VALOR, se cambiará el valor del miembro de datos $this->{NOMBRE}. El método devolverá el valor actual del miembro de datos $this->{NOMBRE}.

  • keys_to_lowercase ( HASHREF )

    Todas las claves en el hash al que se refiere HASHREF se convertirán a minúsculas.

Procesamiento de texto

split_to_lines ( TEXTO )
Este método dividirá TEXTO en una lista de líneas separadas. Devuelve una referencia a esta lista.
scrlength ( LINEA )
Devuelve la longitud en pantalla de la cadena LINEA. La diferencia con la función de perl length() es que este método expandirá los caracteres TAB. Se exporta por esta clase y puede llamarse como una rutina independiente.
text_dimension ( TEXTO )
Este método devolverá un array que contiene el ancho (la longitud de la línea más larga) y la altura (el número de líneas) del TEXTO.
text_wrap ( LINEA, LONGITUD, AJUSTE_PALABRAS )
WORDWRAP ( )
NO_WORDWRAP ( )
Este método ajustará una línea de texto (LINEA) a una longitud dada (LONGITUD). Si el argumento AJUSTE_PALABRAS es verdadero, se habilitará el ajuste de palabras (este es el valor predeterminado para AJUSTE_PALABRAS). Devolverá una referencia a una lista de líneas ajustadas. Se exporta por esta clase y puede llamarse como una rutina independiente.

Las rutinas WORDWRAP y NO_WORDWRAP devolverán el valor correcto para el argumento AJUSTE_PALABRAS. Estas rutinas son exportadas por esta clase.

Ejemplo:

$this->text_wrap($line, 50, NO_WORDWRAP);

Lectura de entrada de teclado

CUI_ESCAPE ( )
CUI_TAB ( )
CUI_SPACE ( )
Estas son un par de rutinas que no están definidas por el módulo Curses, pero que pueden ser útiles de todos modos. Estas rutinas son exportadas por esta clase.
get_key ( TIEMPO_BLOQUEO, CURSOR )
Este método intentará leer una tecla del teclado. Devolverá la tecla presionada o -1 si no se presionó ninguna tecla. Se exporta por esta clase y puede llamarse como una rutina independiente.

El argumento TIEMPO_BLOQUEO se puede utilizar para establecer el medio retraso de curses (el tiempo a esperar antes de que la rutina decida que no se presionó ninguna tecla). TIEMPO_BLOQUEO se da en décimas de segundo. El valor predeterminado es 0 (lectura de teclas no bloqueante).

Ejemplo:

my $key = $this->get_key(5)
