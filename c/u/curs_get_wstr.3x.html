curs_get_wstr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_get_wstr(3X) Llamadas a biblioteca curs_get_wstr(3X)

NOMBRE

get_wstr, getn_wstr, wget_wstr, wgetn_wstr, mvget_wstr, mvgetn_wstr, mvwget_wstr, mvwgetn_wstr - obtener una cadena de caracteres anchos del teclado de una terminal curses

SINOPSIS

#include <curses.h>
int get_wstr(wint_t *wstr);
int getn_wstr(wint_t *wstr, int n);
int wget_wstr(WINDOW *win, wint_t *wstr);
int wgetn_wstr(WINDOW *win, wint_t *wstr, int n);
int mvget_wstr(int y, int x, wint_t *wstr);
int mvgetn_wstr(int y, int x, wint_t *wstr, int n);
int mvwget_wstr(WINDOW *win, int y, int x, wint_t *wstr);
int mvwgetn_wstr(WINDOW *win, int y, int x, wint_t *wstr, int n);

DESCRIPCIÓN

La función wgetn_wstr es equivalente a una serie de llamadas a wget_wch(3X) hasta que un salto de línea o un retorno de carro terminan la serie:

  • El carácter de terminación no se incluye en la cadena devuelta.
  • Una condición de fin de archivo se representa por WEOF, como se define en <wchar.h>.
  • En todos los casos, el final de la cadena se termina con un wchar_t nulo.
  • La función almacena el resultado en el área apuntada por el parámetro wstr.
  • La función lee como máximo n caracteres, evitando así un posible desbordamiento del búfer de entrada.
Cualquier intento de introducir más caracteres (aparte del salto de línea o retorno de carro de terminación) provocará un pitido.
Las teclas de función también provocarán un pitido y serán ignoradas.

Se interpretan los caracteres erase (borrar) y kill (matar) del usuario:

•
El carácter erase (por ejemplo, ^H) borra el carácter al final del búfer, moviendo el cursor hacia la izquierda.
Si el modo keypad está activado para la ventana, KEY_LEFT y KEY_BACKSPACE se consideran ambos equivalentes al carácter erase del usuario.
•
El carácter kill (por ejemplo, ^U) borra todo el búfer, dejando el cursor al principio del búfer.

Los caracteres introducidos se ecoan solo si echo está activado actualmente. En ese caso, el retroceso se ecoa como la eliminación del carácter anterior (típicamente un movimiento hacia la izquierda).

Las funciones getn_wstr, mvgetn_wstr, mvwgetn_wstr y wgetn_wstr son idénticas a las funciones get_wstr, mvget_wstr, mvwget_wstr y wget_wstr, respectivamente, excepto que las versiones *n_* leen como máximo n caracteres, permitiendo a la aplicación prevenir el desbordamiento del búfer de entrada.

VALOR DE RETORNO

Todas estas funciones devuelven el entero OK al completarse con éxito. Si no se completan con éxito, devuelven ERR.

X/Open no define condiciones de error.

En esta implementación, estas funciones devuelven un error

  • si el puntero de la ventana es nulo,
  • si su tiempo de espera expira sin tener datos, o
  • si la llamada asociada a wget_wch falló.

Las funciones prefijadas con "mv" primero realizan un movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Cualquiera de estas funciones, excepto wgetn_wstr, puede ser una macro.

Utilizar get_wstr, mvget_wstr, mvwget_wstr o wget_wstr para leer una línea que desborda el array apuntado por wstr produce resultados indefinidos. Se recomienda el uso de getn_wstr, mvgetn_wstr, mvwgetn_wstr o wgetn_wstr, respectivamente.

Estas funciones no pueden devolver valores KEY_ porque no hay forma de distinguir un valor KEY_ de un valor wchar_t válido.

PORTABILIDAD

Estas funciones se describen en The Single Unix Specification, Version 2. No se definen condiciones de error.

Esta implementación devuelve ERR si el puntero de la ventana es nulo, o si la llamada de nivel inferior wget_wch devuelve un ERR. En este último caso, un retorno ERR sin otros datos se trata como una condición de fin de archivo, y el array devuelto contiene un WEOF seguido de un wchar_t nulo.

X/Open curses documentó estas funciones para pasar un array de wchar_t en 1997, pero eso fue un error debido a esta parte de la descripción:

El efecto de get_wstr es como si se hiciera una serie de llamadas a get_wch, hasta que se procesara un carácter de salto de línea, un carácter de fin de línea o un carácter de fin de archivo.

La última función, get_wch, puede devolver un valor negativo, mientras que wchar_t es un tipo sin signo. Todos los proveedores implementan esto usando wint_t, siguiendo el estándar.

X/Open Curses, Issue 7 (2009) no es claro sobre si el terminador wchar_t nulo se cuenta en el parámetro de longitud n. X/Open Curses, Issue 7 revisó la descripción correspondiente de wgetnstr para abordar este problema. La descripción no revisada de wget_nwstr puede interpretarse de ambas maneras. Esta implementación cuenta el terminador en la longitud.

X/Open Curses no especifica qué sucede si la longitud n es negativa.

  • Por analogía con wgetnstr, ncurses 6.2 utiliza un límite (basado en LINE_MAX).
  • Otras implementaciones (como Solaris xcurses) hacen lo mismo, mientras que otras (PDCurses) no lo permiten.
  • NetBSD 7 curses imita a ncurses 6.1 en este aspecto, tratando un -1 como un número indefinido de caracteres.

VER TAMBIÉN

curs_getstr(3X) describe funciones comparables de la biblioteca ncurses en su configuración sin caracteres anchos.
