CURLINFO_LASTSOCKET(3)

Paquete: curl

Licencias: MIT

CURLINFO_LASTSOCKET(3) Manual de funciones de biblioteca CURLINFO_LASTSOCKET(3)

NOMBRE

CURLINFO_LASTSOCKET - obtener el último socket utilizado

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_LASTSOCKET, long *socket);

DESCRIPCIÓN

Obsoleto desde la versión 7.45.0. Utilice CURLINFO_ACTIVESOCKET(3) en su lugar.

Pase un puntero a un tipo long para recibir el último socket utilizado por esta sesión de curl. Si el socket ya no es válido, se devuelve -1. Cuando termine de trabajar con el socket, debe llamar a curl_easy_cleanup(3) como de costumbre y dejar que libcurl cierre el socket y libere otros recursos asociados con el manejador. Esto se usa típicamente en combinación con CURLOPT_CONNECT_ONLY(3).

NOTA: esta API está obsoleta ya que no funciona en win64 donde el tipo SOCKET es de 64 bits mientras que su 'long' es de 32 bits. Utilice CURLINFO_ACTIVESOCKET(3) en su lugar, si es posible.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    long sockfd; /* no funciona en win64 */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* No hacer la transferencia - solo conectarse al host */
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    res = curl_easy_perform(curl);
    if(res != CURLE_OK) {
      printf("Error: %s\n", curl_easy_strerror(res));
      curl_easy_cleanup(curl);
      return 1;
    }
    /* Extraer el socket del manejador de curl */
    res = curl_easy_getinfo(curl, CURLINFO_LASTSOCKET, &sockfd);
    if(!res && sockfd != -1) {
      /* operar en sockfd */
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.15.2

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error. Consulte libcurl-errors(3).

VER TAMBIÉN

CURLINFO_ACTIVESOCKET(3), CURLOPT_CONNECT_ONLY(3), curl_easy_getinfo(3), curl_easy_setopt(3)
