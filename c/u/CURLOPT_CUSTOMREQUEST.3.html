CURLOPT_CUSTOMREQUEST(3)

Paquete: curl

Licencias: MIT

CURLOPT_CUSTOMREQUEST(3) Manual de funciones de la biblioteca CURLOPT_CUSTOMREQUEST(3)

NOMBRE

CURLOPT_CUSTOMREQUEST - método de solicitud personalizado

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CUSTOMREQUEST, char *method);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro.

Al cambiar el método de solicitud estableciendo CURLOPT_CUSTOMREQUEST(3), en realidad no cambia cómo libcurl se comporta o actúa: solo cambia la cadena real enviada en la solicitud.

libcurl pasa la cadena literal en su solicitud sin ningún filtro u otra salvaguarda. Esto incluye espacios en blanco y caracteres de control.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida sobrescriba las anteriores. Restaure al valor predeterminado interno estableciendo esto en NULL.

Esta opción se puede usar para especificar la solicitud:

HTTP
En lugar de GET o HEAD al realizar solicitudes basadas en HTTP. Esto es particularmente útil, por ejemplo, para realizar una solicitud HTTP DELETE.

Por ejemplo:

Cuando le dice a libcurl que haga una solicitud HEAD, pero luego especifica un GET a través de una solicitud personalizada, libcurl aún actúa como si hubiera enviado un HEAD. Para cambiar a un HEAD adecuado, use CURLOPT_NOBODY(3), para cambiar a un POST adecuado use CURLOPT_POST(3) o CURLOPT_POSTFIELDS(3) y para cambiar a un GET adecuado use CURLOPT_HTTPGET(3).

Muchas personas han usado erróneamente esta opción para reemplazar toda la solicitud con la suya propia, incluyendo múltiples encabezados y contenido POST. Si bien eso podría funcionar en muchos casos, podría hacer que libcurl envíe solicitudes inválidas y podría confundir gravemente al servidor remoto. Use CURLOPT_POST(3) y CURLOPT_POSTFIELDS(3) para establecer datos POST. Use CURLOPT_HTTPHEADER(3) para reemplazar o extender el conjunto de encabezados enviados por libcurl. Use CURLOPT_HTTP_VERSION(3) para cambiar la versión HTTP.

Cuando esta opción se usa junto con CURLOPT_FOLLOWLOCATION(3), el método personalizado establecido anula el método al que libcurl podría cambiar para las solicitudes subsiguientes. Puede ajustar esa decisión usando el bit CURLFOLLOW_OBEYCODE para CURLOPT_FOLLOWLOCATION(3) para que las redirecciones cumplan con el código de respuesta de redirección según lo indica el protocolo.

FTP
En lugar de LIST y NLST al realizar listados de directorios FTP.
IMAP
En lugar de LIST al emitir solicitudes basadas en IMAP.
POP3
En lugar de LIST y RETR al emitir solicitudes basadas en POP3.

Por ejemplo:

Cuando le dice a libcurl que use una solicitud personalizada, se comporta como si se hubiera enviado un comando LIST o RETR donde espera que el servidor devuelva datos. Como tal, CURLOPT_NOBODY(3) debe usarse al especificar comandos como DELE y NOOP, por ejemplo.

SMTP
En lugar de HELP o VRFY al emitir solicitudes basadas en SMTP.

Por ejemplo:

Normalmente se devuelve una respuesta multilínea que se puede utilizar, junto con CURLOPT_MAIL_RCPT(3), para especificar una solicitud EXPN. Si se especifica la opción CURLOPT_NOBODY(3), entonces la solicitud se puede utilizar para emitir comandos NOOP y RSET.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a ftp, http, imap, pop3 y smtp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    /* DELETE la ruta dada */
    curl_easy_setopt(curl, CURLOPT_CUSTOMREQUEST, "DELETE");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VEA TAMBIÉN

CURLINFO_EFFECTIVE_METHOD(3), CURLOPT_HTTPHEADER(3), CURLOPT_NOBODY(3), CURLOPT_REQUEST_TARGET(3)
