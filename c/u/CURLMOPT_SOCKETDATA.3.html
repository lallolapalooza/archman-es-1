CURLMOPT_SOCKETDATA(3)

Paquete: curl

Licencias: MIT

CURLMOPT_SOCKETDATA(3) Manual de funciones de la biblioteca CURLMOPT_SOCKETDATA(3)

NOMBRE

CURLMOPT_SOCKETDATA - puntero personalizado pasado a la devolución de llamada de socket

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_SOCKETDATA, void *pointer);

DESCRIPCIÓN

Un puntero de datos para pasar a la devolución de llamada de socket establecida con la opción CURLMOPT_SOCKETFUNCTION(3).

libcurl no toca este puntero, sino que solo se pasa como el argumento clientp de la devolución de llamada del socket.

VALOR PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

struct priv {
  void *ours;
};
static int sock_cb(CURL *e, curl_socket_t s, int what, void *cbp, void *sockp)
{
  struct priv *p = sockp;
  printf("mi puntero: %p\n", p->ours);
  if(what == CURL_POLL_REMOVE) {
    /* elimina el socket de nuestra colección */
  }
  if(what & CURL_POLL_IN) {
    /* espera para leer en este socket */
  }
  if(what & CURL_POLL_OUT) {
    /* espera para escribir en este socket */
  }
  return 0;
}
int main(void)
{
  struct priv setup;
  CURLM *multi = curl_multi_init();
  /* ... usa la devolución de llamada de socket y el puntero personalizado */
  curl_multi_setopt(multi, CURLMOPT_SOCKETFUNCTION, sock_cb);
  curl_multi_setopt(multi, CURLMOPT_SOCKETDATA, &setup);
}

DISPONIBILIDAD

Añadido en curl 7.15.4

VALOR DE RETORNO

Devuelve CURLM_OK.

VER TAMBIÉN

CURLMOPT_SOCKETFUNCTION(3), CURLMOPT_TIMERFUNCTION(3), curl_multi_socket_action(3)
