CURLOPT_BUFFERSIZE(3)

Paquete: curl

Licencias: MIT

CURLOPT_BUFFERSIZE(3) Manual de funciones de biblioteca CURLOPT_BUFFERSIZE(3)

NOMBRE

CURLOPT_BUFFERSIZE - tamaño del búfer de recepción

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_BUFFERSIZE, long size);

DESCRIPCIÓN

Pase un `long` especificando su tamaño preferido (en bytes) para el búfer de recepción en libcurl. El principal punto de esto sería que la función de devolución de llamada de escritura se llame con más frecuencia y con trozos más pequeños. En segundo lugar, para algunos protocolos, existe el beneficio de tener un búfer más grande para el rendimiento.

Esto se trata solo como una solicitud, no como una orden. No se le puede garantizar que reciba el tamaño especificado.

El tamaño de este búfer es por defecto CURL_MAX_WRITE_SIZE (16 kB). El tamaño máximo de búfer permitido para establecer es CURL_MAX_READ_SIZE (10 MB). El tamaño mínimo de búfer permitido para establecer es 1024.

NO establezca esta opción en un manejador que se esté utilizando actualmente para una transferencia activa, ya que esto puede provocar consecuencias no deseadas.

El tamaño máximo era de 512 kB hasta la versión 7.88.0.

A partir de libcurl 8.7.0, solo hay un búfer de transferencia asignado por manejador `multi`. Este búfer es utilizado por todos los manejadores `easy` añadidos a un manejador `multi`, independientemente de la cantidad de transferencias paralelas. El búfer permanece asignado mientras haya transferencias activas.

POR DEFECTO

CURL_MAX_WRITE_SIZE (16 kB)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/foo.bin");
    /* pedir a libcurl que asigne un búfer de recepción más grande */
    curl_easy_setopt(curl, CURLOPT_BUFFERSIZE, 120000L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.10

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_MAXFILESIZE(3), CURLOPT_MAX_RECV_SPEED_LARGE(3), CURLOPT_UPLOAD_BUFFERSIZE(3), CURLOPT_WRITEFUNCTION(3)
