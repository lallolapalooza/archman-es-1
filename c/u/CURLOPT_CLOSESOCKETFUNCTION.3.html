CURLOPT_CLOSESOCKETFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_CLOSESOCKETFUNCTION(3) Manual de funciones de biblioteca CURLOPT_CLOSESOCKETFUNCTION(3)

NOMBRE

CURLOPT_CLOSESOCKETFUNCTION - reemplazo de devolución de llamada para el cierre de sockets

SINOPSIS

#include <curl/curl.h>
int closesocket_callback(void *clientp, curl_socket_t item);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CLOSESOCKETFUNCTION,
                          closesocket_callback);

DESCRIPCIÓN

Pase un puntero a su función de devolución de llamada, que debe coincidir con el prototipo que se muestra arriba.

Esta función de devolución de llamada es llamada por libcurl en lugar de la llamada close(3) o closesocket(3) cuando se cierran los sockets (no para ningún otro descriptor de archivo). Esto es prácticamente lo opuesto a la opción CURLOPT_OPENSOCKETFUNCTION(3). Devuelva 0 para indicar éxito y 1 si hubo un error.

El puntero clientp se establece con CURLOPT_CLOSESOCKETDATA(3). item es el socket que libcurl quiere que se cierre.

Tenga en cuenta que al usar manejadores multi/share, su devolución de llamada puede ser invocada incluso después de que el manejador easy haya sido liberado. La devolución de llamada y los datos son heredados por una nueva conexión y esa conexión puede vivir más que la transferencia en sí en la caché de conexiones del manejador multi/share.

POR OMISIÓN

Utilice la función de cierre de socket estándar.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

struct priv {
  void *custom;
};
static int closesocket(void *clientp, curl_socket_t item)
{
  struct priv *my = clientp;
  printf("our ptr: %p\n", my->custom);
  printf("libcurl wants to close %d now\n", (int)item);
  return 0;
}
int main(void)
{
  struct priv myown;
  CURL *curl = curl_easy_init();
  /* llamar a esta función para cerrar sockets */
  curl_easy_setopt(curl, CURLOPT_CLOSESOCKETFUNCTION, closesocket);
  curl_easy_setopt(curl, CURLOPT_CLOSESOCKETDATA, &myown);
  curl_easy_perform(curl);
  curl_easy_cleanup(curl);
}

DISPONIBILIDAD

Añadido en curl 7.21.7

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica el éxito o el error.

CURLE_OK (0) significa que todo estuvo bien, distinto de cero significa que ocurrió un error, consulte libcurl-errors(3).
