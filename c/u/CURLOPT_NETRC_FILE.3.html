CURLOPT_NETRC_FILE(3)

Paquete: curl

Licencias: MIT

CURLOPT_NETRC_FILE(3) Manual de funciones de biblioteca CURLOPT_NETRC_FILE(3)

NOMBRE

CURLOPT_NETRC_FILE - archivo desde el que leer información .netrc

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_NETRC_FILE, char *archivo);

DESCRIPCIÓN

Pase un puntero a char como parámetro, apuntando a una cadena terminada en nulo que contiene la ruta completa al archivo que desea que libcurl utilice como archivo .netrc. Si se omite esta opción y se establece CURLOPT_NETRC(3), libcurl busca un archivo .netrc en el directorio de inicio del usuario actual.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para deshabilitar su uso nuevamente.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/");
    curl_easy_setopt(curl, CURLOPT_NETRC, CURL_NETRC_OPTIONAL);
    curl_easy_setopt(curl, CURLOPT_NETRC_FILE, "/tmp/magic-netrc");
    ret = curl_easy_perform(curl);
  }
}

HISTORIAL

Los enumerados CURL_NETRC_* se convirtieron en tipos long en la versión 8.13.0; antes de esta versión, era necesario un casting a long al pasarlos a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.11.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien; un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
