CURLOPT_CAINFO_BLOB(3)

Paquete: curl

Licencias: MIT

CURLOPT_CAINFO_BLOB(3) Manual de funciones de biblioteca CURLOPT_CAINFO_BLOB(3)

NOMBRE

CURLOPT_CAINFO_BLOB - Paquete de Autoridad Certificadora (CA) en formato PEM

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CAINFO_BLOB,
                          struct curl_blob *stblob);

DESCRIPCIÓN

Pasa un puntero a una estructura curl_blob, que contiene información (puntero y tamaño) sobre un bloque de memoria con datos binarios de contenido codificado en PEM que contiene uno o más certificados para verificar el servidor HTTPS.

Si el blob se inicializa con el miembro flags de la estructura curl_blob establecido en CURL_BLOB_COPY, la aplicación no tiene que mantener el buffer disponible después de configurarlo.

Si CURLOPT_SSL_VERIFYPEER(3) es cero y evita verificar el certificado del servidor, CURLOPT_CAINFO_BLOB(3) no es necesario.

Esta opción anula a CURLOPT_CAINFO(3).

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL, Schannel, mbedTLS, rustls y wolfSSL

EJEMPLO

#include <string.h>
int main(void)
{
  char *strpem = "DATOS PEM"; /* strpem debe apuntar a una cadena PEM */
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    struct curl_blob blob;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    blob.data = strpem;
    blob.len = strlen(strpem);
    blob.flags = CURL_BLOB_COPY;
    curl_easy_setopt(curl, CURLOPT_CAINFO_BLOB, &blob);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Esta opción es compatible con los backends mbedTLS (desde 7.81.0), Rustls (desde 7.82.0), wolfSSL (desde 8.2.0), OpenSSL y Schannel.

DISPONIBILIDAD

Añadido en curl 7.77.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_CAINFO(3), CURLOPT_CAPATH(3), CURLOPT_SSL_VERIFYHOST(3), CURLOPT_SSL_VERIFYPEER(3)
