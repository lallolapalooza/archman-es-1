Documentación de Función/Subrutina

subrutina cunmrz (carácter side, carácter trans, entero m, entero n, entero k, entero l, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( * ) tau, complejo, dimensión( ldc, * ) c, entero ldc, complejo, dimensión( * ) work, entero lwork, entero info)

CUNMRZ

Propósito:

!>
!> CUNMRZ sobrescribe la matriz general compleja M por N C con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> donde Q es una matriz unitaria compleja definida como el producto de k
!> reflectores elementales
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tal como devuelve CTZRZF. Q es de orden M si SIDE = 'L' y de orden N
!> si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica Q o Q**H desde la Izquierda;
!>          = 'R': aplica Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplica Q;
!>          = 'C':  Transpuesta conjugada, aplica Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

L

!>          L es INTEGER
!>          El número de columnas de la matriz A que contienen
!>          la parte significativa de los reflectores de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

A

!>          A es array COMPLEX, dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como devuelve
!>          CTZRZF en las últimas k filas de su argumento de array A.
!>          A es modificado por la subrutina pero restaurado a la salida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

TAU

!>          TAU es array COMPLEX, dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve CTZRZF.
!>

C

!>          C es array COMPLEX, dimensión (LDC,N)
!>          A la entrada, la matriz C de M por N.
!>          A la salida, C es sobrescrita por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array COMPLEX, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la subrutina
!>          sólo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor en la primera entrada del array WORK y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
