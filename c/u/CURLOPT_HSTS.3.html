CURLOPT_HSTS(3)

Paquete: curl

Licencias: MIT

CURLOPT_HSTS(3) Manual de funciones de la biblioteca CURLOPT_HSTS(3)

NOMBRE

CURLOPT_HSTS - nombre de archivo de la caché HSTS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTS, char *filename);

DESCRIPCIÓN

Haga que filename apunte a un nombre de archivo para cargar una caché HSTS existente, y para almacenar la caché cuando se cierre el manejador easy. Establecer un nombre de archivo con esta opción también habilita HSTS para este manejador (el equivalente a establecer CURLHSTS_ENABLE con CURLOPT_HSTS_CTRL(3)).

Si el archivo dado no existe o no contiene entradas HSTS al inicio, la caché HSTS simplemente comienza vacía. Establecer el nombre de archivo a NULL permite HSTS sin leer ni escribir en ningún archivo. NULL también hace que libcurl borre la lista de archivos de los que leer datos HSTS, si se hubieran establecido previamente.

Si esta opción se establece varias veces, libcurl carga las entradas de la caché de cada archivo dado, pero solo almacena el último nombre utilizado para escritura posterior.

FORMATO DEL ARCHIVO

La caché HSTS se guarda y se carga desde un archivo de texto con una entrada por línea física. Cada línea en el archivo tiene el siguiente formato:

[host] [stamp]

[host] es el nombre de dominio de la entrada y el nombre está precedido por un punto si es una entrada válida para todos los subdominios del nombre o solo para el nombre exacto.

[stamp] es la hora (en UTC) en que expira la entrada y utiliza el formato "AAAA MM DD HH:MM:SS".

Las líneas que comienzan con "#" se tratan como comentarios y se ignoran. Actualmente no hay límite de longitud o tamaño.

POR DEFECTO

NULL, sin nombre de archivo

PREOCUPACIONES DE SEGURIDAD

libcurl no puede proteger completamente contra ataques en los que un atacante tiene acceso de escritura al mismo directorio donde se dirige a guardar archivos. Esto es particularmente sensible si guarda archivos con privilegios elevados.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_HSTS, "/home/user/.hsts-cache");
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.74.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error, consulte libcurl-errors(3).

VER TAMBIÉN
