CURLOPT_SSLKEYTYPE(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSLKEYTYPE(3) Manual de funciones de biblioteca CURLOPT_SSLKEYTYPE(3)

NOMBRE

CURLOPT_SSLKEYTYPE - tipo de archivo de clave privada

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLKEYTYPE, char *type);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. La cadena debe ser el formato de su clave privada. Los formatos compatibles son "PEM", "DER", "ENG" y "PROV".

El formato "ENG" le permite cargar la clave privada desde un motor criptográfico. En este caso, CURLOPT_SSLKEY(3) se utiliza como identificador pasado al motor. Debe configurar el motor criptográfico con CURLOPT_SSLENGINE(3).

El formato "PROV" le permite cargar la clave privada desde un proveedor criptográfico (Añadido en 8.12.0). En este caso, CURLOPT_SSLKEY(3) se utiliza como identificador pasado al proveedor.

El formato "DER" no funciona con OpenSSL.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establécela en NULL para restaurar el valor predeterminado interno.

PREDETERMINADO

"PEM"

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: OpenSSL y wolfSSL.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLCERT, "client.pem");
    curl_easy_setopt(curl, CURLOPT_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_SSLKEYTYPE, "PEM");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.3.

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_PROXY_SSLKEYTYPE(3), CURLOPT_SSLCERT(3), CURLOPT_SSLKEY(3).
