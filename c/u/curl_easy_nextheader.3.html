curl_easy_nextheader(3)

Paquete: curl

Licencias: MIT

curl_easy_nextheader(3) Manual de Funciones de Biblioteca curl_easy_nextheader(3)

NOMBRE

curl_easy_nextheader - obtener la siguiente cabecera HTTP

SINOPSIS

#include <curl/curl.h>
struct curl_header *curl_easy_nextheader(CURL *easy,
                                         unsigned int origin,
                                         int request,
                                         struct curl_header *prev);

DESCRIPCIÓN

Esta función permite a una aplicación iterar sobre todas las cabeceras HTTP recibidas previamente.

El argumento origin se usa para especificar qué cabeceras recibir, ya que una única transferencia HTTP puede proporcionar cabeceras de varios lugares diferentes y pueden tener una importancia distinta para el usuario, y las cabeceras con el mismo nombre pueden ser utilizadas. El origin es una máscara de bits para las fuentes de cabecera que desea. Consulte la página del manual de curl_easy_header(3) para las descripciones del origen.

El argumento request indica a libcurl de qué solicitud desea las cabeceras. Una única transferencia puede constar de una serie de solicitudes HTTP y este argumento le permite especificar de qué solicitud individual particular desea las cabeceras. 0 es la primera solicitud y luego el número aumenta para redirecciones posteriores o cuando se utiliza autenticación multiestado. Pasar -1 es un atajo para "la última" solicitud de la serie, independientemente de la cantidad real de solicitudes utilizadas.

Se sugiere que pase el mismo origin y request al iterar sobre un rango de cabeceras, ya que cambiar el valor a mitad del bucle podría darle resultados inesperados.

Si prev es NULL, esta función devuelve un puntero a la primera cabecera almacenada dentro del ámbito dado (origen + solicitud).

Si prev es un puntero a una estructura de cabecera devuelta previamente, curl_easy_nextheader(3) devuelve un puntero a la siguiente cabecera almacenada dentro del ámbito dado. De esta manera, una aplicación puede iterar sobre todas las cabeceras disponibles.

La memoria de la estructura a la que apunta es propiedad y está gestionada por libcurl y está asociada al manejador easy. Las aplicaciones deben copiar los datos si desean que sobrevivan a llamadas API posteriores o a la vida útil del manejador easy.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  struct curl_header *prev = NULL;
  struct curl_header *h;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_perform(curl);
    /* extraer las cabeceras normales de la primera solicitud */
    while((h = curl_easy_nextheader(curl, CURLH_HEADER, 0, prev))) {
      printf("%s: %s\n", h->name, h->value);
      prev = h;
    }
    /* extraer las cabeceras normales + 1xx + trailers de la última solicitud */
    unsigned int origin = CURLH_HEADER| CURLH_1XX | CURLH_TRAILER;
    while((h = curl_easy_nextheader(curl, origin, -1, prev))) {
      printf("%s: %s\n", h->name, h->value);
      prev = h;
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.83.0

VALOR DE RETORNO

Esta función devuelve la siguiente cabecera, o NULL cuando no hay más cabeceras (coincidentes) o ocurrió un error.

Si esta función devuelve NULL cuando prev se estableció a NULL, entonces no hay cabeceras disponibles dentro del ámbito para devolver.
