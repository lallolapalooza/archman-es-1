CURLMOPT_PIPELINING_SERVER_BL(3)

Paquete: curl

Licencias: MIT

CURLMOPT_PIPELINING_SERVER_BL(3) Manual de funciones de la biblioteca CURLMOPT_PIPELINING_SERVER_BL(3)

NOMBRE

CURLMOPT_PIPELINING_SERVER_BL - lista de bloqueo de servidores de pipelining

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_PIPELINING_SERVER_BL,
                            char **servers);

DESCRIPCIÓN

Sin función desde que se eliminó el pipelining en la versión 7.62.0.

Pase un array servers de punteros a char, terminado con una entrada NULL. Esta es una lista de prefijos de tipos de servidor (en la cabecera HTTP Server:) que están bloqueados para el pipelining, es decir, tipos de servidor que se sabe que no admiten pipelining HTTP. El array es copiado por libcurl.

Tenga en cuenta que la comparación coincide si la cabecera Server: comienza con la cadena en la lista de bloqueo, es decir, "Server: Ninja 1.2.3" y "Server: Ninja 1.4.0" pueden ser bloqueados teniendo "Ninja" en la lista.

Pase un puntero NULL para borrar la lista de bloqueo.

VALOR POR DEFECTO

NULL, lo que significa que no hay lista de bloqueo.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

static char *server_block_list[] =
{
  "Microsoft-IIS/6.0",
  "nginx/0.8.54",
  NULL
};
int main(void)
{
  CURLM *m = curl_multi_init();
  curl_multi_setopt(m, CURLMOPT_PIPELINING_SERVER_BL, server_block_list);
}

DISPONIBILIDAD

Añadido en curl 7.30.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un CURLMcode indicando éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
