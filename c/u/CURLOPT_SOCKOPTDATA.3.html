CURLOPT_SOCKOPTDATA(3)

Paquete: curl

Licencias: MIT

CURLOPT_SOCKOPTDATA(3) Manual de funciones de biblioteca CURLOPT_SOCKOPTDATA(3)

NOMBRE

CURLOPT_SOCKOPTDATA - puntero para pasar a la función de devolución de llamada sockopt

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SOCKOPTDATA, void *pointer);

DESCRIPCIÓN

Pasa un puntero que libcurl no modifica y que se pasa como primer argumento en la función de devolución de llamada sockopt establecida con CURLOPT_SOCKOPTFUNCTION(3).

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

static int sockopt_callback(void *clientp, curl_socket_t curlfd,
                            curlsocktype purpose)
{
  int val = *(int *)clientp;
  setsockopt((int)curlfd, SOL_SOCKET, SO_RCVBUF,
             (const char *)&val, sizeof(val));
  return CURL_SOCKOPT_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    int recvbuffersize = 256 * 1024;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* llamar a esta función para establecer opciones para el socket */
    curl_easy_setopt(curl, CURLOPT_SOCKOPTFUNCTION, sockopt_callback);
    curl_easy_setopt(curl, CURLOPT_SOCKOPTDATA, &recvbuffersize);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.16.0

VALOR DE RETORNO

Devuelve CURLE_OK si la opción es compatible, y CURLE_UNKNOWN_OPTION si no lo es.

VER TAMBIÉN

CURLOPT_OPENSOCKETFUNCTION(3), CURLOPT_SOCKOPTFUNCTION(3)
