NOMBRE

cups-calibrate - Herramienta de Calibración de Impresoras CUPS de ESP

SINOPSIS

cups-calibrate

DESCRIPCIÓN

Este programa permite calibrar la salida de color de las impresoras utilizando el controlador CUPS de Gutenprint. Tenga en cuenta que este programa solo funciona con el controlador CUPS de Gutenprint.

Estos controladores se identifican por el texto CUPS+Gutenprint en la descripción del modelo que se muestra en la interfaz web de CUPS.

Para crear un perfil de calibración para todos los usuarios, ejecute este programa como el usuario root. El programa muestra una serie de indicaciones que simplemente deben seguirse.
