Curses::UI::Listbox(3) Documentación de Perl aportada por el usuario Curses::UI::Listbox(3)

NOMBRE

Curses::UI::Listbox - Crear y manipular widgets de lista

JERARQUÍA DE CLASES

Curses::UI::Widget
Curses::UI::Searchable
   |
   +----Curses::UI::Listbox

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $listbox = $win->add(
    'mylistbox', 'Listbox',
    -values    => [1, 2, 3],
    -labels    => { 1 => 'One', 
                    2 => 'Two', 
                    3 => 'Three' },
    -radio     => 1,
);
$listbox->focus();
my $selected = $listbox->get();

DESCRIPCIÓN

Curses::UI::Listbox es un widget que se puede utilizar para crear varios tipos diferentes de listas. Estos son:

  • lista por defecto

    Una lista de valores a través de los cuales se puede navegar. Uno de estos valores puede ser seleccionado. El valor seleccionado se resaltará. Este tipo de lista se ve algo así:

    +------+
|One   |
|Two   |
|Three |
+------+
  • lista de selección múltiple

    Esta también es una lista de valores, pero ahora más de un valor puede ser seleccionado a la vez. Este tipo de lista se ve algo así:

    +----------+
|[X] One   |
|[ ] Two   |
|[X] Three |
+----------+
  • lista de botones de radio

    Esto se parece mucho a la lista por defecto (solo se puede seleccionar un valor), pero ahora hay una retroalimentación visual clara sobre qué valor está seleccionado. Antes de cada valor se imprime "< >". Si un valor está seleccionado, se imprime "<o>" en su lugar. Este tipo de lista se ve algo así:

    +----------+
|< > One   |
|<o> Two   |
|< > Three |
+----------+
  • Marcado de la lista

    La lista admite un lenguaje de marcado primitivo para enfatizar entradas:
    <reverse>texto invertido</reverse>
    <bold>texto en negrita</bold>
    <underline>texto subrayado</underline>
    <blink>texto parpadeante</blink>
    <dim>texto atenuado</dim> Usando estos tokens de marcado en el array de valores, puedes hacer que la lista dibuje el texto de la manera correspondiente. Para habilitar el analizador, tienes que crear la lista con la opción -htmltext.

OPCIONES ESTÁNDAR

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

Para una explicación de estas opciones estándar, ver Curses::UI::Widget.

OPCIONES ESPECÍFICAS DEL WIDGET

  • -values < ARRAYREF >

    Esta opción establece los valores a usar. A menos que se establezca una etiqueta para el valor (ver -labels), este valor se mostrará en la lista.

  • -labels < HASHREF >

    Las claves de esta referencia hash corresponden a los valores de la lista (ver -values). Los valores del hash son las etiquetas a mostrar en la lista. No es obligatorio tener una etiqueta definida para cada valor. Puedes incluso omitir -labels completamente.

  • -selected < INDEX >

    En caso de que la opción -multi no esté establecida, INDEX es el índice del valor que debe ser seleccionado.

    En caso de que la opción -multi esté establecida, INDEX es una referencia hash en la que las claves son los índices de los -values que están seleccionados y los valores son cualquier valor verdadero.

  • -multi < BOOLEAN >

    Si BOOLEAN tiene un valor verdadero, la lista será una lista de selección múltiple (ver DESCRIPCIÓN).

  • -radio < BOOLEAN >

    Si BOOLEAN tiene un valor verdadero, la lista será una lista de botones de radio (ver DESCRIPCIÓN).

  • -wraparound < BOOLEAN >

    Si BOOLEAN tiene un valor verdadero, se habilita el ajuste cíclico. Esto significa que si la lista está en su último valor y se presiona una tecla para ir al siguiente valor, se seleccionará el primer valor. También se seleccionará el último valor si este primer valor está seleccionado y se presiona "ir al valor anterior".

  • -onchange < CODEREF >

    Esto establece el manejador de eventos onChange para el widget de lista. Si se selecciona un nuevo elemento, se ejecutará el código en CODEREF. Recibirá la referencia del widget como su argumento.

  • -onselchange < CODEREF >

    Esto establece el manejador de eventos onSelectionChange para el widget de lista . Si se marca un nuevo elemento como activo, se ejecutará CODEREF. Recibirá la referencia del widget como su argumento.

  • -htmltext < BOOLEAN >

    Hace que la lista analice marcado primitivo para cambiar la apariencia de los elementos. Ver arriba.

MÉTODOS

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEAN )
  • intellidraw ( )
  • focus ( )
  • onFocus ( CODEREF )
  • onBlur ( CODEREF )

    Estos son métodos estándar. Ver Curses::UI::Widget para una explicación de estos.

  • get ( )

    Este método devolverá los valores de los elementos actualmente seleccionados en la lista. Si la lista no es una lista de selección múltiple, solo se devolverá un valor, por supuesto.

  • id ( )

    Este método devolverá el índice de los elementos actualmente seleccionados en la lista. Si la lista no es una lista de selección múltiple, solo devolverá un valor.

  • get_active_value ( )

    Este método devolverá el valor del elemento actualmente activo (es decir, la línea resaltada).

  • get_active_id ( )

    Este método devolverá el índice del elemento actualmente activo (es decir, la línea resaltada).

  • set_selection ( LIST )

    Este método marca los elementos en las posiciones especificadas en LIST como seleccionados. En una lista de selección múltiple puedes establecer varios elementos dando varios valores, en una lista de selección única solo el último elemento en LIST será seleccionado.

  • clear_selection ( )

    Este método limpia los objetos seleccionados de una lista de selección múltiple y de botones de radio.

  • values ( ARRAYREF )

    Este método establece los valores a usar.

  • insert_at < POS, ARRAYREF|SCALAR >

    Este método añade ARRAYREF o SCALAR a la lista de valores en la posición pos.

  • labels [ HASHREF ]

    Este método establece las etiquetas a usar.

  • add_labels [ HASHREF ]

    Este método añade las etiquetas dadas a las ya definidas.

  • onChange ( CODEREF )

    Este método se puede usar para establecer el -onchange manejador de eventos (ver arriba) después de la inicialización de la lista.

  • onSelectionChange ( CODEREF )

    Este método se puede usar para establecer el -onselchange manejador de eventos (ver arriba) después de la inicialización de la lista.

ENLACES POR DEFECTO

  • <cursor-left>, <h>, <tab>

    Llama a la rutina 'loose-focus'. Esto hará que el widget pierda su foco.

  • <cursor-right, <l>, <enter>, <space>

    Llama a la rutina 'option-select'. Esto seleccionará el elemento activo en la lista.

  • <1>, <y>

    Llama a la rutina 'option-check'. Si la lista es una lista de selección múltiple, el elemento activo se marcará como verificado y el siguiente elemento se volverá activo.

  • <0>, <n>

    Llama a la rutina 'option-uncheck'. Si la lista es una lista de selección múltiple, el elemento activo se desmarcará y el siguiente elemento se volverá activo.

  • <cursor-down>, <j>

    Llama a la rutina 'option-next'. Esto hará que el siguiente elemento de la lista esté activo.

  • <cursor-up>, <k>

    Llama a la rutina 'option-prev'. Esto hará que el elemento anterior de la lista esté activo.

  • <page-up>

    Llama a la rutina 'option-prevpage'. Esto hará que el elemento de la página anterior esté activo.

  • <page-down>

    Llama a la rutina 'option-nextpage'. Esto hará que el elemento de la página siguiente esté activo.

  • <home>, <CTRL+A>

    Llama a la rutina 'option-first'. Esto hará que el primer elemento de la lista esté activo.

  • <end>, <CTRL+E>

    Llama a la rutina 'option-last'. Esto hará que el último elemento de la lista esté activo.

  • </>

    Llama a la rutina 'search-forward'. Esto hará que aparezca en el listbox un sistema de búsqueda similar al de 'less'. Se puede introducir una cadena de búsqueda. Después de eso, el usuario puede buscar la siguiente coincidencia con la tecla 'n' o la coincidencia anterior con la tecla 'N'.

  • <?>

    Llama a la rutina 'search-backward'. Esto hará lo mismo que la rutina 'search-forward', solo que buscará en la dirección opuesta.
