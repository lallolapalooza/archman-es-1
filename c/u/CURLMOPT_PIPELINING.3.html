CURLMOPT_PIPELINING(3)

Paquete: curl

Licencias: MIT

CURLMOPT_PIPELINING(3) Manual de funciones de la biblioteca CURLMOPT_PIPELINING(3)

NOMBRE

CURLMOPT_PIPELINING - habilitar multiplexación HTTP

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_PIPELINING, long bitmask);

DESCRIPCIÓN

Pase el valor correcto en el parámetro bitmask para instruir a libcurl a habilitar la multiplexación para este manejador multi.

Con la multiplexación habilitada, libcurl intenta realizar múltiples transferencias a través de la misma conexión cuando realiza transferencias paralelas a los mismos hosts.

CURLPIPE_NOTHING (0)
No hacer intentos de multiplexación.
CURLPIPE_HTTP1 (1)
Este bit está obsoleto y no tiene ningún efecto desde la versión 7.62.0.
CURLPIPE_MULTIPLEX (2)
Si este bit está activado, libcurl intenta multiplexar la nueva transferencia a través de una conexión existente si es posible. Esto requiere HTTP/2 o HTTP/3.

POR DEFECTO

CURLPIPE_MULTIPLEX

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURLM *m = curl_multi_init();
  /* intentar multiplexación HTTP/2 */
  curl_multi_setopt(m, CURLMOPT_PIPELINING, CURLPIPE_MULTIPLEX);
}

HISTORIAL

El bit de soporte de multiplexación se añadió en 7.43.0. El soporte de Pipelining HTTP/1 se deshabilitó en 7.62.0.

Desde 7.62.0, CURLPIPE_MULTIPLEX está habilitado por defecto.

Antes de eso, el valor por defecto era CURLPIPE_NOTHING.

DISPONIBILIDAD

Añadido en curl 7.16.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
