CURLOPT_FAILONERROR(3)

Paquete: curl

Licencias: MIT

CURLOPT_FAILONERROR(3) Manual de funciones de la biblioteca CURLOPT_FAILONERROR(3)

NOMBRE

CURLOPT_FAILONERROR - solicitar fallo en respuestas HTTP >= 400

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FAILONERROR, long fail);

DESCRIPCIÓN

Un parámetro long establecido en 1 le indica a la biblioteca que haga fallar la solicitud si el código HTTP devuelto es igual o mayor que 400. La acción predeterminada sería devolver la página normalmente, ignorando dicho código.

Este método no es a prueba de fallos y hay ocasiones en las que se escapan códigos de respuesta no exitosos, especialmente cuando hay autenticación involucrada (códigos de respuesta 401 y 407).

Puede que se transfieran algunas cabeceras antes de que se detecte esta situación, como cuando se recibe un "100-continue" como respuesta a un POST/PUT y se recibe un 401 o 407 inmediatamente después.

Cuando se utiliza esta opción y se detecta un error, provoca que la conexión se cierre y se devuelva CURLE_HTTP_RETURNED_ERROR.

PREDETERMINADO

0, no fallar ante un error

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_FAILONERROR, 1L);
    ret = curl_easy_perform(curl);
    if(ret == CURLE_HTTP_RETURNED_ERROR) {
      /* un problema de error de respuesta HTTP */
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error, ver libcurl-errors(3).

VER TAMBIÉN
