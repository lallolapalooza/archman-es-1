CURLOPT_PROXY_SSL_VERIFYHOST(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_SSL_VERIFYHOST(3) Manual de funciones de la biblioteca CURLOPT_PROXY_SSL_VERIFYHOST(3)

NOMBRE

CURLOPT_PROXY_SSL_VERIFYHOST - verificar el nombre del certificado SSL del proxy frente al host

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_SSL_VERIFYHOST,
                          long verify);

DESCRIPCIÓN

Pase un long establecido en 2L para pedirle a curl que *verifique* los campos de nombre del certificado SSL del proxy frente al nombre del proxy.

Esta opción determina si libcurl verifica que el certificado del proxy contenga el nombre correcto para el nombre por el que se conoce.

Cuando CURLOPT_PROXY_SSL_VERIFYHOST(3) se establece en 2, el certificado del proxy debe indicar que el servidor es el proxy al que se pretendía conectar, o la conexión fallará.

curl considera que el proxy es el previsto cuando el campo Nombre Común o un campo de Nombre Alternativo del Sujeto en el certificado coincide con el nombre de host en la cadena del proxy que le indicó a curl que utilizara.

Si el valor de *verificar* se establece en 1:

En la versión 7.28.0 y anteriores: se trataba como una opción de depuración de algún tipo, ya no se admite debido a que con frecuencia conduce a errores de programación.

Desde la versión 7.28.1 hasta la 7.65.3: establecerlo en 1 hacía que curl_easy_setopt(3) devolviera un error y dejaba el indicador sin cambios.

Desde la versión 7.66.0: trata 1 y 2 de la misma manera.

Cuando el valor de *verificar* es 0L, la conexión tiene éxito independientemente de los nombres utilizados en el certificado. Utilice esa capacidad con precaución.

Consulte también CURLOPT_PROXY_SSL_VERIFYPEER(3) para verificar la firma digital del certificado del proxy.

POR DEFECTO

2

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Todos los backends TLS admiten esta opción.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* Establecer el valor predeterminado: ¡comprobación de nombre estricta, por favor! */
    curl_easy_setopt(curl, CURLOPT_PROXY_SSL_VERIFYHOST, 2L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DEVUELTO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).

VEA TAMBIÉN
