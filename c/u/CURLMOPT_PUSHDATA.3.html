CURLMOPT_PUSHDATA(3)

Paquete: curl

Licencias: MIT

CURLMOPT_PUSHDATA(3) Manual de funciones de biblioteca CURLMOPT_PUSHDATA(3)

NOMBRE

CURLMOPT_PUSHDATA - puntero para pasar a la función de llamada de push

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_PUSHDATA, void *pointer);

DESCRIPCIÓN

Establece un puntero para pasar como último argumento a la función de llamada CURLMOPT_PUSHFUNCTION(3). El puntero no es manipulado ni utilizado por libcurl en sí, solo se pasa a la función de llamada.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

#include <string.h>
/* solo permite push para nombres de archivo que comiencen con "push-" */
int push_callback(CURL *parent,
                  CURL *easy,
                  size_t num_headers,
                  struct curl_pushheaders *headers,
                  void *clientp)
{
  char *headp;
  int *transfers = (int *)clientp;
  FILE *out;
  headp = curl_pushheader_byname(headers, ":path");
  if(headp && !strncmp(headp, "/push-", 6)) {
    fprintf(stderr, "La RUTA es %s\n", headp);
    /* guarda el push aquí */
    out = fopen("pushed-stream", "wb");
    /* escribe en este archivo */
    curl_easy_setopt(easy, CURLOPT_WRITEDATA, out);
    (*transfers)++; /* uno más */
    return CURL_PUSH_OK;
  }
  return CURL_PUSH_DENY;
}
int main(void)
{
  int counter;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_PUSHFUNCTION, push_callback);
  curl_multi_setopt(multi, CURLMOPT_PUSHDATA, &counter);
}

DISPONIBILIDAD

Añadido en curl 7.44.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo OK, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
