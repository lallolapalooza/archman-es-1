CURLOPT_UNIX_SOCKET_PATH(3)

Paquete: curl

Licencias: MIT

CURLOPT_UNIX_SOCKET_PATH(3) Manual de funciones de la biblioteca CURLOPT_UNIX_SOCKET_PATH(3)

NOMBRE

CURLOPT_UNIX_SOCKET_PATH - Socket de dominio Unix

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_UNIX_SOCKET_PATH, char *path);

DESCRIPCIÓN

Habilita el uso de sockets de dominio Unix como punto final de conexión y establece la ruta a path. Si path es NULL, entonces los sockets de dominio Unix se deshabilitan.

Cuando se habilita, curl se conecta al socket de dominio Unix en lugar de establecer una conexión TCP con el host. Como no se crea ninguna conexión de red, curl no resuelve el nombre de host DNS en la URL.

La longitud máxima de la ruta en Cygwin, Linux y Solaris es 107. En otras plataformas podría ser incluso menor.

Las opciones de proxy y TCP como CURLOPT_TCP_NODELAY(3) no son compatibles. Las opciones de proxy como CURLOPT_PROXY(3) tampoco tienen efecto, ya que están orientadas a TCP, y pedirle a un servidor proxy que se conecte a un socket de dominio Unix específico no es posible.

La aplicación no tiene que mantener la cadena de caracteres disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida sobrescriba las anteriores. Establézcala a NULL para deshabilitar su uso de nuevo.

POR DEFECTO

NULL - no se utilizan sockets de dominio Unix.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_UNIX_SOCKET_PATH, "/tmp/httpd.sock");
    curl_easy_setopt(curl, CURLOPT_URL, "http://localhost/");
    curl_easy_perform(curl);
  }
}

Si está en Linux y de alguna manera necesita rutas de más de 107 bytes, puede usar el sistema de archivos proc para evitar la limitación:

  int dirfd = open(long_directory_path_to_socket, O_DIRECTORY | O_RDONLY);
  char path[108];
  snprintf(path, sizeof(path), "/proc/self/fd/%d/httpd.sock", dirfd);
  curl_easy_setopt(curl_handle, CURLOPT_UNIX_SOCKET_PATH, path);
  /* Asegúrese de mantener dirfd válido hasta que deseche el manejador */

DISPONIBILIDAD

Añadido en curl 7.40.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
