Las implementaciones existentes de Unix curses (AIX, HP-UX, Solaris) usan solo el mapeo de caracteres acsc para proporcionar esta característica. Como resultado, esas implementaciones solo pueden usar caracteres de dibujo de líneas de un solo byte. ncurses 5.3 (2002) proporcionó una tabla de valores Unicode para resolver estos problemas.
