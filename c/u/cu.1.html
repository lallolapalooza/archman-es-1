DESCRIPCIÓ

N

El comando cu se utiliza para llamar a otro sistema y actuar como un terminal de marcado. También puede realizar transferencias simples de archivos sin comprobación de

errores.

cu toma un único argumento, además de las opciones. Si el argumento es la cadena "dir", cu establecerá una conexión directa con el puerto. Esto solo puede ser utilizado por usuarios con acceso de escritura al puerto, ya que permite reprogramar el

módem.

De lo contrario, si el argumento comienza con un dígito, se considera que es un número de teléfono a llamar. De lo contrario, se considera que es el nombre de un sistema a llamar. La opción -z o --system puede utilizarse para nombrar un sistema que comience con un dígito, y la opción -c o --phone puede utilizarse para nombrar un número de teléfono que no comience con un

dígito.

cu localiza un puerto para usar en los archivos de configuración de UUCP. Si se proporciona un nombre de sistema simple, seleccionará un puerto apropiado para ese sistema. Las opciones -p, --port, -l, --line, -s y --speed pueden utilizarse para controlar la selección del

puerto.

Cuando se establece una conexión con el sistema remoto, cu se bifurca en dos procesos. Uno lee del puerto y escribe en la terminal, mientras que el otro lee de la terminal y escribe en el

puerto.

cu proporciona varios comandos que pueden utilizarse durante la conversación. Todos los comandos comienzan con un carácter de escape, inicialmente ~ (virgulilla). El carácter de escape solo se reconoce al comienzo de una línea. Para enviar un carácter de escape al sistema remoto al comienzo de una línea, debe introducirse dos veces. Todos los comandos son o bien un solo carácter o una palabra que comienza con % (signo de porcentaje)

.
