CURLOPT_SSLCERTTYPE(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSLCERTTYPE(3) Manual de Funciones de la Biblioteca CURLOPT_SSLCERTTYPE(3)

NOMBRE

CURLOPT_SSLCERTTYPE - tipo de certificado SSL del cliente

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLCERTTYPE, char *type);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. La cadena debe ser el formato de su certificado.

Los formatos admitidos son "PEM" y "DER", excepto con Schannel. OpenSSL y Schannel admiten "P12" para archivos codificados en PKCS#12. GnuTLS admite P12 a partir de curl 8.11.0.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida sobrescriba las anteriores. Establecerla a NULL restaura el valor predeterminado interno.

POR DEFECTO

"PEM"

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL, Schannel, mbedTLS y wolfSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLCERT, "client.pem");
    curl_easy_setopt(curl, CURLOPT_SSLCERTTYPE, "PEM");
    curl_easy_setopt(curl, CURLOPT_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "s3cret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.3

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier otro valor indica un error; consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_SSLCERT(3), CURLOPT_SSLKEY(3)
