CURLOPT_PROXY_CAPATH(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXY_CAPATH(3) Manual de Funciones de Biblioteca CURLOPT_PROXY_CAPATH(3)

NOMBRE

CURLOPT_PROXY_CAPATH - directorio que contiene certificados CA HTTPS del proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CAPATH, char *capath);

DESCRIPCIÓN

Pasa un puntero a un carácter a una cadena terminada en nulo que nombra un directorio que contiene múltiples certificados CA para verificar el proxy HTTPS con. Si libcurl se compila con OpenSSL, el directorio de certificados debe prepararse utilizando la utilidad c_rehash de OpenSSL. Esto solo tiene sentido cuando CURLOPT_PROXY_SSL_VERIFYPEER(3) está habilitado (lo cual está por defecto).

La aplicación no tiene que mantener la cadena disponible después de configurar esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Configúrela a NULL para deshabilitar su uso nuevamente y volver a la configuración predeterminada interna.

El valor predeterminado para esto se puede averiguar con CURLINFO_CAPATH(3).

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL y mbedTLS

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* usando un proxy HTTPS */
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:443");
    curl_easy_setopt(curl, CURLOPT_PROXY_CAPATH, "/etc/cert-dir");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.52.0

VALOR DE RETORNO

CURLE_OK si es compatible; o un error como:

CURLE_NOT_BUILT_IN - No es compatible con el backend SSL

CURLE_UNKNOWN_OPTION

CURLE_OUT_OF_MEMORY
