CURLINFO_CERTINFO(3)

Paquete: curl

Licencias: MIT

CURLINFO_CERTINFO(3) Manual de funciones de biblioteca CURLINFO_CERTINFO(3)

NOMBRE

CURLINFO_CERTINFO - obtener la cadena de certificados TLS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CERTINFO,
                           struct curl_certinfo **chainp);

DESCRIPCIÓN

Pase un puntero a un struct curl_certinfo * y se establecerá para que apunte a una estructura que contiene información sobre la cadena de certificados del servidor, asumiendo que usted habilitó CURLOPT_CERTINFO(3) cuando se realizó la solicitud.

struct curl_certinfo {
  int num_of_certs;
  struct curl_slist **certinfo;
};

El miembro de la estructura certinfo es una matriz de listas enlazadas de información de certificados. El miembro de la estructura num_of_certs es el número de certificados, que es el número de elementos en la matriz. La lista de cada certificado tiene elementos con información textual en el formato "nombre:contenido" como "Subject:Foo", "Issuer:Bar", etc. Los elementos de cada lista varían según el backend SSL y el certificado.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL, Schannel y rustls

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://www.example.com/");
    /* conectarse a cualquier sitio HTTPS, confiable o no */
    curl_easy_setopt(curl, CURLOPT_SSL_VERIFYPEER, 0L);
    curl_easy_setopt(curl, CURLOPT_SSL_VERIFYHOST, 0L);
    curl_easy_setopt(curl, CURLOPT_CERTINFO, 1L);
    res = curl_easy_perform(curl);
    if(!res) {
      int i;
      struct curl_certinfo *ci;
      res = curl_easy_getinfo(curl, CURLINFO_CERTINFO, &ci);
      if(!res) {
        printf("%d certificados!\n", ci->num_of_certs);
        for(i = 0; i < ci->num_of_certs; i++) {
          struct curl_slist *slist;
          for(slist = ci->certinfo[i]; slist; slist = slist->next)
            printf("%s\n", slist->data);
        }
      }
    }
    curl_easy_cleanup(curl);
  }
}

HISTORIA

Soporte GnuTLS añadido en 7.42.0. Soporte Schannel añadido en 7.50.0. Soporte mbedTLS añadido en 8.9.0.

DISPONIBILIDAD

Añadido en curl 7.19.1

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).
