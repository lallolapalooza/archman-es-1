El archivo

access_log

lista cada recurso HTTP al que accede un navegador web o un cliente. Cada línea está en una versión extendida del llamado "Formato de Registro Común" (Common Log Format) utilizado por muchos servidores web y herramientas de informes web: host group user fecha-hora " método recurso versión " estado b

ytes

operación-ipp

estado-ipp

Por ejemplo: 10.0.1.2 - - [01/Dec/2005:21:50:28 +0000] "POST / HTTP/1.1" 200 317 CUPS-Get-Printers successful-ok-ignored-or-substituted-attributes localhost - - [01/Dec/2005:21:50:32 +0000] "GET /admin HTTP/1.1" 200 0 - - localhost - - [01/Dec/2005:21:50:32 +0000] "POST / HTTP/1.1" 200 157 CUPS-Get-Printers successful-ok-ignored-or-substituted-attributes localhost - - [01/Dec/2005:21:50:32 +0000] "POST / HTTP/1.1" 200 1411 CUPS-Get-Devices - localhost - - [01/Dec/2005:21:50:32 +0000] "GET /admin HTTP/1.1" 200 6667

    El campo
user

es el nombre de usuario autenticado del usuario solicitante. Si no se proporciona un nombre de usuario y una contraseña para la solicitud, entonces este campo contiene "-". El campo fecha

-hora

es la fecha y hora de la solicitud en hora local y está en el formato "[DD/MON/AAAA:HH:MM:SS +ZZZZ]". El campo

método

es el método HTTP utilizado: "GET", "HEAD", "OPTIONS", "POST" o "PUT". Las solicitudes "GET" se utilizan para obtener archivos del servidor, tanto para la interfaz web como para obtener archivos de configuración y de registro. Las solicitudes "HEAD" se utilizan para obtener información sobre un recurso antes de un "GET". Las solicitudes "OPTIONS" se utilizan para mejorar las conexiones al cifrado TLS. Las solicitudes "POST" se utilizan para formularios de la interfaz web y solicitudes IPP. Las solicitudes "PUT" se utilizan para subir archivos de configuración. E

El archivo page_log lista el número total de páginas (hojas) que se imprimen. Por defecto, cada línea contiene la siguiente

información:

impresora usuario id-trabajo fecha-hora to

ta
l

num-hojas facturación-trabaj

o

nombre-host-origen-trabajo nombre-trabajo medio lados Por ejemplo, la entrada para un trabajo de dos páginas llamado "myjob" podría verse

así: 
    DeskJet root 1 [20/May/1999:19:21:06 +0000] total 2 acme-123
      localhost myjob na_letter_8.5x11in one-sided La directiva PageLogFormat en el archivo cupsd.conf(5)
      puede
    usarse para cambiar esta
información.

E

l 
    campo
impresora

contiene el nombre de la impresora que imprimió la página. Si envía un trabajo a una clase de impresora, este campo contendrá el nombre de la impresora a la que se le asignó el trabajo. E

l

campo usuario contiene el nombre del usuario (el atributo IPP requesting-user-name) que envió este archivo para

imprimir.

El campo id-tr

abajo

contiene el número de trabajo de la página que se está imprimiendo. E

l

campo fecha-hora contiene la fecha y hora de cuando la página comenzó a imprimirse. El formato de este campo es idéntico al campo fecha-hora en el archivo access_log [[165]]

.

El num-sheets proporciona el número total de páginas (hojas) que se han impreso en el trabajo.

El job-billing campo contiene una copia de los atributos job-billing o job-account-id proporcionados con las solicitudes IPP Create-Job o Print-Job o "-" si no se proporcionó ninguno.

El job-originating-host-name campo contiene el nombre de host o la dirección IP del cliente que imprimió el trabajo.

El job-name campo contiene una copia del atributo job-name proporcionado con las solicitudes IPP Create-Job o Print-Job o "-" si no se proporcionó ninguno.

El media campo contiene una copia del atributo media o media-col/media-size proporcionado con las solicitudes IPP Create-Job o Print-Job o "-" si no se proporcionó ninguno.

El sides campo contiene una copia del atributo sides proporcionado con las solicitudes IPP Create-Job o Print-Job o "-" si no se proporcionó ninguno.
