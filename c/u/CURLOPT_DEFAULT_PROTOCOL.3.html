CURLOPT_DEFAULT_PROTOCOL(3)

Paquete: curl

Licencias: MIT

CURLOPT_DEFAULT_PROTOCOL(3) Manual de funciones de la biblioteca CURLOPT_DEFAULT_PROTOCOL(3)

NOMBRE

CURLOPT_DEFAULT_PROTOCOL - protocolo predeterminado a usar si la URL carece de nombre de esquema

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DEFAULT_PROTOCOL,
                          char *protocol);

DESCRIPCIÓN

Esta opción le indica a libcurl que use protocol si la URL carece de nombre de esquema.

Utilice uno de estos nombres de protocolo (esquema):

dict, file, ftp, ftps, gopher, http, https, imap, imaps, ldap, ldaps, pop3, pop3s, rtsp, scp, sftp, smb, smbs, smtp, smtps, telnet, tftp

Un protocolo desconocido o no compatible provoca el error CURLE_UNSUPPORTED_PROTOCOL cuando libcurl analiza una URL sin esquema. El análisis se realiza cuando se llama a curl_easy_perform(3) o curl_multi_perform(3). El protocolo admitido por libcurl varía según cómo se compiló. Utilice curl_version_info(3) si necesita una lista de nombres de protocolo admitidos por la compilación de libcurl que está utilizando.

Esta opción no cambia el protocolo proxy predeterminado (http).

Sin esta opción, libcurl haría una suposición basada en el host, consulte CURLOPT_URL(3) para obtener más detalles.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala en NULL para volver a desactivar su uso.

PREDETERMINADO

NULL (hacer una suposición basada en el host)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* establecer una URL sin esquema */
    curl_easy_setopt(curl, CURLOPT_URL, "example.com");
    /* establecer el protocolo predeterminado (esquema) para URLs sin esquema */
    curl_easy_setopt(curl, CURLOPT_DEFAULT_PROTOCOL, "https");
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.45.0

VALOR DE RETORNO

CURLE_OK si la opción es compatible.

CURLE_OUT_OF_MEMORY si no había suficiente espacio en el heap.

CURLE_UNKNOWN_OPTION si la opción no es compatible.

VER TAMBIÉN

CURLINFO_PROTOCOL(3), CURLINFO_SCHEME(3), CURLOPT_URL(3)
