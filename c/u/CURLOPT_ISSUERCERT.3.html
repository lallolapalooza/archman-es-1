CURLOPT_ISSUERCERT(3)

Paquete: curl

Licencias: MIT

CURLOPT_ISSUERCERT(3) Manual de funciones de la biblioteca CURLOPT_ISSUERCERT(3)

NOMBRE

CURLOPT_ISSUERCERT - nombre de archivo del certificado SSL del emisor

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_ISSUERCERT, char *file);

DESCRIPCIÓN

Pase un puntero a char a una cadena terminada en nulo que nombre un archivo que contenga un certificado CA en formato PEM. Si la opción se establece, se realiza una verificación adicional contra el certificado del par para verificar que el emisor es realmente el asociado con el certificado proporcionado por la opción. Esta verificación adicional es útil en PKI multinivel donde es necesario garantizar que el certificado del par proviene de una rama específica del árbol.

Esta opción solo tiene sentido cuando se usa en combinación con la opción CURLOPT_SSL_VERIFYPEER(3). De lo contrario, el resultado de la verificación no se considera un fallo.

Se define un código de error específico (CURLE_SSL_ISSUER_ERROR) con la opción, que se devuelve si la configuración de la sesión SSL/TLS ha fallado debido a una discrepancia con el emisor del certificado del par (también se debe establecer CURLOPT_SSL_VERIFYPEER(3) para que la verificación falle).

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala en NULL para volver a deshabilitar su uso.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS y OpenSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_ISSUERCERT, "/etc/certs/cacert.pem");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.19.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_CRLFILE(3), CURLOPT_SSL_VERIFYHOST(3), CURLOPT_SSL_VERIFYPEER(3)
