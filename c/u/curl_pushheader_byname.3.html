curl_pushheader_byname(3)

Paquete: curl

Licencias: MIT

curl_pushheader_byname(3) Manual de funciones de la biblioteca curl_pushheader_byname(3)

NOMBRE

curl_pushheader_byname - obtener una cabecera de push por nombre

SINOPSIS

#include <curl/curl.h>
char *curl_pushheader_byname(struct curl_pushheaders *h, const char *name);

DESCRIPCIÓN

Esta es una función que solo es funcional dentro de una devolución de llamada de CURLMOPT_PUSHFUNCTION(3). No tiene sentido intentar usarla en otro lugar y no tiene ninguna función entonces.

Devuelve el valor para el nombre de campo de cabecera dado (o NULL) para la solicitud de push del servidor entrante. Esto es un atajo para que la aplicación no tenga que recorrer todas las cabeceras para encontrar la que le interesa. Los datos a los que apunta esta función se liberan cuando esta devolución de llamada finaliza. Si más de un campo de cabecera utiliza el mismo nombre, esta función devuelve solo el primero.

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

#include <string.h> /* para strncmp */
static int push_cb(CURL *parent,
                   CURL *easy,
                   size_t num_headers,
                   struct curl_pushheaders *headers,
                   void *clientp)
{
  char *headp;
  int *transfers = (int *)clientp;
  FILE *out;
  headp = curl_pushheader_byname(headers, ":path");
  if(headp && !strncmp(headp, "/push-", 6)) {
    fprintf(stderr, "La RUTA es %s\n", headp);
    /* guardar el push aquí */
    out = fopen("pushed-stream", "wb");
    /* escribir en este archivo */
    curl_easy_setopt(easy, CURLOPT_WRITEDATA, out);
    (*transfers)++; /* uno más */
    return CURL_PUSH_OK;
  }
  return CURL_PUSH_DENY;
}
int main(void)
{
  int counter;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_PUSHFUNCTION, push_cb);
  curl_multi_setopt(multi, CURLMOPT_PUSHDATA, &counter);
}

DISPONIBILIDAD

Añadido en curl 7.44.0

VALOR DE RETORNO

Devuelve un puntero al contenido del campo de cabecera o NULL.

VER TAMBIÉN
