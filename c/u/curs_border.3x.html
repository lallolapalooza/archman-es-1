curs_border(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_border(3X) Llamadas de biblioteca curs_border(3X)

NOMBRE

border, wborder, box, hline, whline, vline, wvline, mvhline, mvwhline, mvvline, mvwvline - dibujar bordes y líneas en una ventana de curses de caracteres

SINOPSIS

#include <curses.h>
int border(chtype ls, chtype rs, chtype ts, chtype bs,
           chtype tl, chtype tr, chtype bl, chtype br);
int wborder(WINDOW *win, chtype ls, chtype rs,
            chtype ts, chtype bs, chtype tl, chtype tr,
            chtype bl, chtype br);
int box(WINDOW *win, chtype verch, chtype horch);
int hline(chtype ch, int n);
int whline(WINDOW *win, chtype ch, int n);
int vline(chtype ch, int n);
int wvline(WINDOW *win, chtype ch, int n);
int mvhline(int y, int x, chtype ch, int n);
int mvwhline(WINDOW *win, int y, int x, chtype ch, int n);
int mvvline(int y, int x, chtype ch, int n);
int mvwvline(WINDOW *win, int y, int x, chtype ch, int n);

DESCRIPCIÓN

Las rutinas border, wborder y box dibujan un cuadro alrededor de los bordes de una ventana. Aparte de la ventana, cada argumento es un carácter con atributos:

ls - lado izquierdo,
rs - lado derecho,
ts - lado superior,
bs - lado inferior,
tl - esquina superior izquierda,
tr - esquina superior derecha,
bl - esquina inferior izquierda, y
br - esquina inferior derecha.

Si alguno de estos argumentos es cero, entonces los valores predeterminados correspondientes (definidos en curses.h) se usan en su lugar:

ACS_VLINE,
ACS_VLINE,
ACS_HLINE,
ACS_HLINE,
ACS_ULCORNER,
ACS_URCORNER,
ACS_LLCORNER,
ACS_LRCORNER.

box(win, verch, horch) es un atajo para la siguiente llamada: wborder(win, verch, verch, horch, horch, 0, 0, 0, 0).

Las funciones hline y whline dibujan una línea horizontal (de izquierda a derecha) usando ch a partir de la posición actual del cursor en la ventana. La posición actual del cursor no cambia. La línea tiene como máximo n caracteres de longitud, o tantos como quepan en la ventana.

Las funciones vline y wvline dibujan una línea vertical (de arriba a abajo) usando ch a partir de la posición actual del cursor en la ventana. La posición actual del cursor no cambia. La línea tiene como máximo n caracteres de longitud, o tantos como quepan en la ventana.

VALOR DE RETORNO

Todas las rutinas devuelven el entero OK. El manual de SVr4.0 dice “o un entero no negativo si immedok está activado”, pero esto parece ser un error.

X/Open Curses no especifica ninguna condición de error. Esta implementación devuelve un error si el puntero de la ventana es nulo.

Las funciones prefijadas con “mv” primero realizan el movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Los bordes generados por estas funciones son bordes *interiores* (esto también es cierto para curses SVr4, aunque el hecho no está documentado).

Tenga en cuenta que border y box pueden ser macros.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4.
