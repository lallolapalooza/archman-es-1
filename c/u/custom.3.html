int LIBMTP_Custom_Operation (LIBMTP_mtpdevice_t * device, uint16_t code, int n_param, ...)

Emite una operación personalizada (por ejemplo, específica del fabricante) (sin fase de datos).

Parámetros

device un puntero al dispositivo al que se enviará la operación personalizada.
code código de operación a enviar.
n_param número de parámetros pasados.
... parámetros específicos de la operación uint32_t.
