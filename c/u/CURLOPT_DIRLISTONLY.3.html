CURLOPT_DIRLISTONLY(3)

Paquete: curl

Licencias: MIT

CURLOPT_DIRLISTONLY(3) Manual de funciones de biblioteca CURLOPT_DIRLISTONLY(3)

NOMBRE

CURLOPT_DIRLISTONLY - solicitar solo nombres en una lista de directorios

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DIRLISTONLY, long listonly);

DESCRIPCIÓN

Para URLs basadas en FTP y SFTP, un parámetro establecido a 1 le indica a la biblioteca que liste los nombres de los archivos en un directorio, en lugar de realizar una lista completa del directorio que normalmente incluiría tamaños de archivo, fechas, etc.

Para POP3, un parámetro de 1 le indica a la biblioteca que liste los mensajes de correo electrónico en el servidor POP3. Esto se puede usar para cambiar el comportamiento predeterminado de libcurl, cuando se combina con una URL que contiene un ID de mensaje, para realizar una "lista de escaneo" que luego se puede usar para determinar el tamaño de un correo electrónico.

Para FILE, esta opción aún no tiene efecto, ya que los directorios siempre se listan en este modo.

Nota: Para FTP, esto provoca que se envíe un comando NLST al servidor FTP. Tenga cuidado, ya que algunos servidores FTP solo listan archivos en su respuesta a NLST; es posible que no incluyan subdirectorios y enlaces simbólicos.

Establecer esta opción en 1 también implica una lista de directorios, incluso si la URL no termina con una barra, lo cual es necesario de lo contrario.

No utilice esta opción si también usa CURLOPT_WILDCARDMATCH(3) ya que esto rompe efectivamente esa función.

PREDETERMINADO

0, deshabilitado

PROTOCOLOS

Esta funcionalidad afecta a ftp, pop3 y sftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/dir/");
    /* solo listar */
    curl_easy_setopt(curl, CURLOPT_DIRLISTONLY, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Esta opción se conocía como CURLOPT_FTPLISTONLY hasta la versión 7.16.4. POP3 es compatible desde la versión 7.21.5.

DISPONIBILIDAD

Añadido en curl 7.17.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un código CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero significa que ocurrió un error, consulte libcurl-errors(3).
