CURLOPT_GSSAPI_DELEGATION(3)

Paquete: curl

Licencias: MIT

CURLOPT_GSSAPI_DELEGATION(3) Manual de funciones de la biblioteca CURLOPT_GSSAPI_DELEGATION(3)

NOMBRE

CURLOPT_GSSAPI_DELEGATION - delegación GSS-API permitida

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_GSSAPI_DELEGATION, long nivel);

DESCRIPCIÓN

Establezca el parámetro de tipo long nivel en CURLGSSAPI_DELEGATION_FLAG para permitir la delegación incondicional de credenciales GSSAPI. La delegación está deshabilitada por defecto desde la versión 7.21.7. Establezca el parámetro en CURLGSSAPI_DELEGATION_POLICY_FLAG para delegar solo si la marca OK-AS-DELEGATE está establecida en el ticket de servicio, en caso de que esta característica sea compatible con la implementación de la GSS-API y la definición de GSS_C_DELEG_POLICY_FLAG estuviera disponible en tiempo de compilación.

POR OMISIÓN

CURLGSSAPI_DELEGATION_NONE

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* delegar si la política lo permite */
    curl_easy_setopt(curl, CURLOPT_GSSAPI_DELEGATION,
                     CURLGSSAPI_DELEGATION_POLICY_FLAG);
    ret = curl_easy_perform(curl);
  }
}

HISTORIAL

Las macros CURLGSSAPI_DELEGATION_* se convirtieron en tipos long en la versión 8.16.0; antes de esta versión, era necesario un casting a long al pasarlas a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.22.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue bien; un valor distinto de cero indica que ocurrió un error. Consulte libcurl-errors(3).
