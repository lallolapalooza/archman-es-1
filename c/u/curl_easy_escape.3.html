Paquete: curl

curl_easy_escape(3) Manual de funciones de la biblioteca curl_easy_escape(3)

NOMBRE

curl_easy_escape - Codifica una cadena para URL

SINOPSIS

#include <curl/curl.h>
char *curl_easy_escape(CURL *curl, const char *string, int length);

DESCRIPCIÓN

Esta función convierte la cadena de entrada dada en una cadena codificada para URL y la devuelve como una cadena recién asignada. Todos los caracteres de entrada que no sean a-z, A-Z, 0-9, '-', '.', '_' o '~' se convierten a su versión "codificada para URL" (%NN donde NN es un número hexadecimal de dos dígitos).

Si length se establece en 0 (cero), curl_easy_escape(3) usa strlen() en la cadena de entrada para determinar el tamaño. Esta función no acepta cadenas de entrada más largas que CURL_MAX_INPUT_LENGTH (8 MB).

Debes curl_free(3) la cadena devuelta cuando hayas terminado con ella.

CODIFICACIÓN

Normalmente, libcurl no conoce ni se preocupa por las codificaciones de caracteres. curl_easy_escape(3) codifica los datos byte a byte en la versión codificada para URL sin conocimiento ni preocupación por la codificación de caracteres particular que la aplicación o el servidor receptor puedan asumir que los datos utilizan.

El llamador de curl_easy_escape(3) debe asegurarse de que los datos pasados a la función estén codificados correctamente.

URLS

Las URL son, por definición, codificadas para URL. Para crear una URL adecuada a partir de un conjunto de componentes que pueden no estar ya codificados para URL, no puedes simplemente codificar toda la cadena de URL con curl_easy_escape(3), porque entonces también convierte dos puntos, barras y otros símbolos que probablemente quieras que permanezcan intactos.

Para crear una URL adecuada a partir de cadenas que no están ya codificadas para URL, recomendamos usar la API de URL de libcurl: establece las piezas con curl_url_set(3) y obtén la URL final correcta con curl_url_get(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    char *output = curl_easy_escape(curl, "datos a convertir", 15);
    if(output) {
      printf("Codificado: %s\n", output);
      curl_free(output);
    }
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Desde la versión 7.82.0, el parámetro curl se ignora. Antes de eso, había soporte de conversión de caracteres por identificador para algunos sistemas operativos antiguos como TPF, pero por lo demás se ignoraba.

DISPONIBILIDAD

Añadido en curl 7.15.4

VALOR DE RETORNO

Un puntero a una cadena terminada en nulo o NULL si falló.

VER TAMBIÉN
