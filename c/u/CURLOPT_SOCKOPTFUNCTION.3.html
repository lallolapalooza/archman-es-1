CURLOPT_SOCKOPTFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_SOCKOPTFUNCTION(3) Manual de Funciones de Biblioteca CURLOPT_SOCKOPTFUNCTION(3)

NOMBRE

CURLOPT_SOCKOPTFUNCTION - función de devolución de llamada para establecer opciones de socket

SINOPSIS

#include <curl/curl.h>
typedef enum  {
  CURLSOCKTYPE_IPCXN,  /* socket creado para una conexión IP específica */
  CURLSOCKTYPE_ACCEPT, /* socket creado por llamada a accept() */
  CURLSOCKTYPE_LAST    /* nunca usar */
} curlsocktype;
#define CURL_SOCKOPT_OK 0
#define CURL_SOCKOPT_ERROR 1 /* provoca que libcurl se aborte y devuelva
                               CURLE_ABORTED_BY_CALLBACK */
#define CURL_SOCKOPT_ALREADY_CONNECTED 2
int sockopt_callback(void *clientp,
                     curl_socket_t curlfd,
                     curlsocktype purpose);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SOCKOPTFUNCTION, sockopt_callback);

DESCRIPCIÓN

Pase un puntero a su función de devolución de llamada, que debe coincidir con el prototipo mostrado arriba.

Cuando se establece, libcurl llama a esta función de devolución de llamada cuando el socket ha sido creado, pero antes de la llamada de conexión, para permitir que las aplicaciones cambien opciones específicas del socket. El argumento purpose de la devolución de llamada identifica el propósito exacto de este socket en particular:

CURLSOCKTYPE_IPCXN para conexiones creadas activamente o desde la versión 7.28.0 CURLSOCKTYPE_ACCEPT para FTP cuando la conexión se estableció con PORT/EPSV (en versiones anteriores, estos sockets no se pasaban a esta devolución de llamada).

Versiones futuras de libcurl pueden admitir más propósitos. libcurl pasa el descriptor del socket recién creado a la devolución de llamada en el parámetro curlfd para que se puedan realizar llamadas setsockopt() adicionales a discreción del usuario.

El puntero clientp contiene cualquier valor definido por el usuario establecido con la función CURLOPT_SOCKOPTDATA(3).

Devuelva CURL_SOCKOPT_OK desde la devolución de llamada si tiene éxito. Devuelva CURL_SOCKOPT_ERROR desde la función de devolución de llamada para señalar un error irrecuperable a la biblioteca, y esta cerrará el socket y devolverá CURLE_COULDNT_CONNECT para CURLSOCKTYPE_IPCXN y CURLE_ABORTED_BY_CALLBACK para CURLSOCKTYPE_ACCEPT.

La función de devolución de llamada puede devolver CURL_SOCKOPT_ALREADY_CONNECTED para CURLSOCKTYPE_IPCXN, para indicar a libcurl que el socket ya está conectado, y entonces libcurl no intentará conectarse. Esto permite a una aplicación pasar un socket ya conectado con CURLOPT_OPENSOCKETFUNCTION(3) y luego hacer que esta función evite que libcurl intente conectarse (de nuevo).

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

/* hacer que libcurl utilice el socket ya establecido 'sockfd' */
static curl_socket_t opensocket(void *clientp,
                                curlsocktype purpose,
                                struct curl_sockaddr *address)
{
  curl_socket_t sockfd;
  sockfd = *(curl_socket_t *)clientp;
  /* el socket externo real se pasa a través de la opción OPENSOCKETDATA */
  return sockfd;
}
static int sockopt_callback(void *clientp, curl_socket_t curlfd,
                            curlsocktype purpose)
{
  return CURL_SOCKOPT_ALREADY_CONNECTED;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    int sockfd; /* nuestro descriptor de archivo personalizado */
    /* libcurl cree que te estás conectando al host
     * y puerto que especificas en la opción CURLOPT_URL. */
    curl_easy_setopt(curl, CURLOPT_URL, "http://99.99.99.99:9999");
    /* llamar a esta función para obtener un socket */
    curl_easy_setopt(curl, CURLOPT_OPENSOCKETFUNCTION, opensocket);
    curl_easy_setopt(curl, CURLOPT_OPENSOCKETDATA, &sockfd);
    /* llamar a esta función para establecer opciones para el socket */
    curl_easy_setopt(curl, CURLOPT_SOCKOPTFUNCTION, sockopt_callback);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.16.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error ocurrido, ver libcurl-errors(3).
