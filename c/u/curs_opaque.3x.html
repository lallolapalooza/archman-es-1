curs_opaque(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_opaque(3X) Llamadas a biblioteca curs_opaque(3X)

NOMBRE

is_cleared, is_idlok, is_idcok, is_immedok, is_keypad, is_leaveok, is_nodelay, is_notimeout, is_pad, is_scrollok, is_subwin, is_syncok, wgetdelay, wgetparent, wgetscrreg - obtener propiedades de la ventana de curses

SINOPSIS

#include <curses.h>
bool is_cleared(const WINDOW *win);
bool is_idcok(const WINDOW *win);
bool is_idlok(const WINDOW *win);
bool is_immedok(const WINDOW *win);
bool is_keypad(const WINDOW *win);
bool is_leaveok(const WINDOW *win);
bool is_nodelay(const WINDOW *win);
bool is_notimeout(const WINDOW *win);
bool is_pad(const WINDOW *win);
bool is_scrollok(const WINDOW *win);
bool is_subwin(const WINDOW *win);
bool is_syncok(const WINDOW *win);
WINDOW * wgetparent(const WINDOW *win);
int wgetdelay(const WINDOW *win);
int wgetscrreg(const WINDOW *win, int *top, int *bottom);

DESCRIPCIÓN

ncurses proporciona funciones que devuelven propiedades de una estructura WINDOW, permitiendo que sea “opaca” si la aplicación define el símbolo preprocesador NCURSES_OPAQUE. La opacidad en este sentido significa que los miembros de los tipos de datos de la struct no son directamente accesibles (por ejemplo, a través de operadores “.” o “->”), sino que deben consultarse y/o establecerse a través de funciones de la biblioteca. Las ventajas de la opacidad incluyen una mayor abstracción y una mejor gestión de accesos concurrentes a las estructuras de datos, manteniendo coherentes los estados de los objetos.

is_cleared
devuelve el valor establecido por clearok(3X).
is_idcok
devuelve el valor establecido por idcok(3X).
is_idlok
devuelve el valor establecido por idlok(3X).
is_immedok
devuelve el valor establecido por immedok(3X).
is_keypad
devuelve el valor establecido por keypad(3X).
is_leaveok
devuelve el valor establecido por leaveok(3X).
is_nodelay
devuelve el valor establecido por nodelay(3X).
is_notimeout
devuelve el valor establecido por notimeout(3X).
is_pad
devuelve TRUE si la ventana es un pad; es decir, fue creada por newpad(3X).
is_scrollok
devuelve el valor establecido por scrollok(3X).
is_subwin
devuelve TRUE si la ventana es una subventana, es decir, fue creada por subwin(3X) o derwin(3X).
is_syncok
devuelve el valor establecido por syncok(3X).
wgetdelay
devuelve el tiempo de espera establecido por wtimeout(3X).
wgetparent
devuelve el puntero de la WINDOW padre para subventanas, o NULL para ventanas sin padre.
wgetscrreg
almacena las filas superior e inferior del margen de desplazamiento establecido por wsetscrreg(3X) en los argumentos correspondientes, devolviendo ERR en caso de error y OK si se completa con éxito.

VALOR DE RETORNO

Estas funciones devuelven TRUE o FALSE excepto donde se indica.

NOTAS

ncurses proporciona tanto una función en C como una macro preprocesador para cada función descrita en esta página.

PORTABILIDAD

Estas rutinas son específicas de ncurses. No eran compatibles con las implementaciones de la Versión 7, BSD o System V. Se recomienda que cualquier código que dependa de extensiones de ncurses esté condicionado usando NCURSES_VERSION.
