NOMBRE

curl_multi_setopt - establecer opciones para un manejador multi de curl

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *multi, CURLMoption option, parameter);

DESCRIPCIÓN

curl_multi_setopt(3) se usa para indicar a un manejador multi de libcurl cómo comportarse. Usando las opciones apropiadas para curl_multi_setopt(3), puedes cambiar el comportamiento de libcurl al usar ese manejador multi. Todas las opciones se establecen con la opción seguida por el parámetro. Ese parámetro puede ser un tipo long, un puntero a función, un puntero a objeto o un tipo curl_off_t, dependiendo de lo que espere la opción específica. Lee este manual cuidadosamente ya que valores de entrada incorrectos pueden causar un mal comportamiento de libcurl. Solo puedes establecer una opción en cada llamada a la función.

OPCIONES

CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE
obsoleto Ver CURLMOPT_CHUNK_LENGTH_PENALTY_SIZE(3)
CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE
obsoleto Ver CURLMOPT_CONTENT_LENGTH_PENALTY_SIZE(3)
CURLMOPT_MAXCONNECTS
Tamaño de la caché de conexiones. Ver CURLMOPT_MAXCONNECTS(3)
CURLMOPT_MAX_CONCURRENT_STREAMS
Streams concurrentes máximos para http2. Ver CURLMOPT_MAX_CONCURRENT_STREAMS(3)
CURLMOPT_MAX_HOST_CONNECTIONS
Número máximo de conexiones a un host único. Ver CURLMOPT_MAX_HOST_CONNECTIONS(3)
CURLMOPT_MAX_PIPELINE_LENGTH
obsoleto. Ver CURLMOPT_MAX_PIPELINE_LENGTH(3)
CURLMOPT_MAX_TOTAL_CONNECTIONS
Conexiones simultáneas máximas. Ver CURLMOPT_MAX_TOTAL_CONNECTIONS(3)
CURLMOPT_NETWORK_CHANGED
Señalizar que la red ha cambiado. Ver CURLMOPT_NETWORK_CHANGED(3)
CURLMOPT_NOTIFYDATA
Puntero personalizado pasado a la función de notificación. Ver CURLMOPT_NOTIFYDATA(3)
CURLMOPT_NOTIFYFUNCTION
Función de devolución de llamada que recibe notificaciones. Ver CURLMOPT_NOTIFYFUNCTION(3)
CURLMOPT_PIPELINING
Habilitar multiplexación HTTP. Ver CURLMOPT_PIPELINING(3)
CURLMOPT_PIPELINING_SERVER_BL
obsoleto. Ver CURLMOPT_PIPELINING_SERVER_BL(3)
CURLMOPT_PIPELINING_SITE_BL
obsoleto. Ver CURLMOPT_PIPELINING_SITE_BL(3)
CURLMOPT_PUSHDATA
Puntero para pasar a la función de push. Ver CURLMOPT_PUSHDATA(3)
CURLMOPT_PUSHFUNCTION
Función de devolución de llamada que aprueba o deniega los push del servidor. Ver CURLMOPT_PUSHFUNCTION(3)
CURLMOPT_SOCKETDATA
Puntero personalizado pasado a la función de socket. Ver CURLMOPT_SOCKETDATA(3)
CURLMOPT_SOCKETFUNCTION
Función de devolución de llamada informada sobre qué esperar. Ver CURLMOPT_SOCKETFUNCTION(3)
CURLMOPT_TIMERDATA
Puntero personalizado para pasar a la función de temporizador. Ver CURLMOPT_TIMERDATA(3)
CURLMOPT_TIMERFUNCTION
Función de devolución de llamada para recibir valores de tiempo de espera. Ver CURLMOPT_TIMERFUNCTION(3)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

#define MAX_PARALLEL 45
int main(void)
{
  CURLM *multi = curl_multi_init();
  /* Limitar la cantidad de conexiones simultáneas que curl debería permitir: */
  curl_multi_setopt(multi, CURLMOPT_MAXCONNECTS, (long)MAX_PARALLEL);
}

DISPONIBILIDAD

Añadido en curl 7.15.4

VALOR DE RETORNO

Esta función devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo fue correcto, cualquier valor distinto de cero indica un error, ver libcurl-errors(3).

Ten en cuenta que devuelve un CURLM_UNKNOWN_OPTION si intentas establecer una opción que esta versión de libcurl no reconoce.
