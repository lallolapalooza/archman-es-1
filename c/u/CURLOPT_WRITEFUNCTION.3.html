CURLOPT_WRITEFUNCTION(3)

Paquete: curl

Licencias: MIT

CURLOPT_WRITEFUNCTION(3) Manual de funciones de la biblioteca CURLOPT_WRITEFUNCTION(3)

NOMBRE

CURLOPT_WRITEFUNCTION - callback para escribir los datos recibidos

SINOPSIS

#include <curl/curl.h>
size_t write_callback(char *ptr, size_t size, size_t nmemb, void *userdata);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_WRITEFUNCTION, write_callback);

DESCRIPCIÓN

Pase un puntero a su función de callback, la cual debe coincidir con el prototipo mostrado arriba.

Esta función de callback es llamada por libcurl tan pronto como hay datos recibidos que necesitan ser guardados. Para la mayoría de las transferencias, esta callback se llama muchas veces y cada invocación entrega un nuevo fragmento de datos. ptr apunta a los datos entregados, y el tamaño de esos datos es nmemb; size es siempre 1.

Los datos pasados a esta función no están terminados con null.

La función de callback recibe la mayor cantidad de datos posible en todas las invocaciones, pero no debe hacer suposiciones. Puede ser un byte, pueden ser miles. La cantidad máxima de datos del cuerpo que se pasa a la callback de escritura se define en el archivo de cabecera curl.h: CURL_MAX_WRITE_SIZE (el valor predeterminado habitual es 16K). Si CURLOPT_HEADER(3) está habilitado, lo que hace que los datos de encabezado se pasen a la callback de escritura, puede recibir hasta CURL_MAX_HTTP_HEADER bytes de datos de encabezado pasados a ella. Esto normalmente significa 100K.

Esta función puede ser llamada con cero bytes de datos si el archivo transferido está vacío.

Establezca el argumento userdata con la opción CURLOPT_WRITEDATA(3).

Su callback debe devolver el número de bytes que fueron realmente gestionados. Si esa cantidad difiere de la cantidad pasada a su función de callback, esto señala una condición de error a la biblioteca. Esto provoca que la transferencia se aborte y la función de libcurl utilizada devuelva CURLE_WRITE_ERROR.

También puede abortar la transferencia devolviendo CURL_WRITEFUNC_ERROR (añadido en 7.87.0), lo que hace que se devuelva CURLE_WRITE_ERROR.

Si la función de callback devuelve CURL_WRITEFUNC_PAUSE, pausa esta transferencia. Consulte curl_easy_pause(3) para más detalles.

Establezca esta opción a NULL para usar la función interna predeterminada en lugar de su callback. La función interna predeterminada escribe los datos en el FILE * dado con CURLOPT_WRITEDATA(3).

Esta opción no habilita HSTS, necesita usar CURLOPT_HSTS_CTRL(3) para hacerlo.

PREDETERMINADO

fwrite(3)

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

#include <stdlib.h> /* para realloc */
#include <string.h> /* para memcpy */
struct memory {
  char *response;
  size_t size;
};
static size_t cb(char *data, size_t size, size_t nmemb, void *clientp)
{
  size_t realsize = nmemb;
  struct memory *mem = (struct memory *)clientp;
  char *ptr = realloc(mem->response, mem->size + realsize + 1);
  if(!ptr)
    return 0;  /* sin memoria */
  mem->response = ptr;
  memcpy(&(mem->response[mem->size]), data, realsize);
  mem->size += realsize;
  mem->response[mem->size] = 0;
  return realsize;
}
int main(void)
{
  struct memory chunk = {0};
  CURLcode res;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* enviar todos los datos a esta función  */
    curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, cb);
    /* pasamos nuestra estructura 'chunk' a la función de callback */
    curl_easy_setopt(curl, CURLOPT_WRITEDATA, (void *)&chunk);
    /* enviar una solicitud */
    res = curl_easy_perform(curl);
    /* recuerda liberar el buffer */
    free(chunk.response);
    curl_easy_cleanup(curl);
  }
}

HISTORIA

El soporte para el código de retorno CURL_WRITEFUNC_PAUSE se añadió en la versión 7.18.0.

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

Devuelve CURLE_OK.

VER TAMBIÉN
