CURLOPT_HTTPPOST(3)

Paquete: curl

Licencias: MIT

CURLOPT_HTTPPOST(3) Manual de funciones de la biblioteca CURLOPT_HTTPPOST(3)

NOMBRE

CURLOPT_HTTPPOST - contenido de formpost multipart

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HTTPPOST,
                          struct curl_httppost *formpost);

DESCRIPCIÓN

Esta opción está obsoleta. Use CURLOPT_MIMEPOST(3) en su lugar.

Indica a libcurl que desea realizar un POST HTTP de tipo multipart/formdata y le indica qué datos pasar al servidor en el argumento formpost. Pase un puntero a una lista enlazada de estructuras curl_httppost como parámetro. La forma más sencilla de crear dicha lista es usar curl_formadd(3), como se documenta. Los datos de esta lista deben permanecer intactos mientras la transferencia de curl esté activa y la esté utilizando.

El uso de POST con HTTP 1.1 implica el uso de una cabecera "Expect: 100-continue". Puede deshabilitar esta cabecera con CURLOPT_HTTPHEADER(3).

Al establecer CURLOPT_HTTPPOST(3), libcurl establece automáticamente CURLOPT_NOBODY(3) a 0.

VALOR POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  struct curl_httppost *formpost;
  struct curl_httppost *lastptr;
  /* Rellenar el campo de carga de archivo. Esto hace que libcurl cargue datos
     del nombre de archivo dado cuando se llama a curl_easy_perform(). */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "sendfile",
               CURLFORM_FILE, "postit2.c",
               CURLFORM_END);
  /* Rellenar el campo de nombre de archivo */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "filename",
               CURLFORM_COPYCONTENTS, "postit2.c",
               CURLFORM_END);
  /* Rellenar también el campo submit, aunque rara vez sea necesario */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "submit",
               CURLFORM_COPYCONTENTS, "send",
               CURLFORM_END);
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_HTTPPOST, formpost);
    curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
  curl_formfree(formpost);
}

OBSOLETO

Obsoleto en la versión 7.56.0.

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error; consulte libcurl-errors(3).
