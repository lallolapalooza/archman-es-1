CURLMOPT_MAX_HOST_CONNECTIONS(3)

Paquete: curl

Licencias: MIT

CURLMOPT_MAX_HOST_CONNECTIONS(3) Manual de funciones de biblioteca CURLMOPT_MAX_HOST_CONNECTIONS(3)

NOMBRE

CURLMOPT_MAX_HOST_CONNECTIONS - número máximo de conexiones a un único host

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_MAX_HOST_CONNECTIONS,
                            long max);

DESCRIPCIÓN

Pase un `long` para indicar `max`, la cantidad máxima de conexiones abiertas simultáneamente que libcurl puede mantener para un único host (un host es lo mismo que un par de nombre de host y número de puerto). Por cada transferencia nueva al mismo host, libcurl puede abrir una nueva conexión hasta el límite establecido por CURLMOPT_MAX_HOST_CONNECTIONS(3). Cuando se alcanza el límite, las sesiones nuevas permanecen pendientes hasta que una conexión esté disponible.

El valor `max` predeterminado es 0, ilimitado. Este límite establecido también se usa para las conexiones proxy, y luego el proxy se considera el host para el cual este límite se cuenta.

Cuando se agregan más transferencias al manejador múltiple de las que se pueden realizar debido al límite establecido, se ponen en cola esperando su oportunidad.

Mientras una transferencia está en cola internamente esperando una conexión, el tiempo de espera de CURLOPT_TIMEOUT_MS(3) se cuenta incluyendo el tiempo de espera, lo que significa que si establece un tiempo de espera demasiado corto, la transferencia podría no iniciarse nunca antes de que expire. El tiempo de CURLOPT_CONNECTTIMEOUT_MS(3) también se trata de manera similar como un tiempo de espera por conexión y podría expirar incluso antes de que se permita establecer una nueva conexión.

Es posible cambiar este valor mientras hay transferencias en progreso. El nuevo valor se utilizará la próxima vez que se realicen las comprobaciones. Reducir el valor no cierra ninguna transferencia activa, simplemente no permite que se realicen nuevas.

PREDETERMINADO

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURLM *m = curl_multi_init();
  /* no más de 2 conexiones por host */
  curl_multi_setopt(m, CURLMOPT_MAX_HOST_CONNECTIONS, 2L);
}

DISPONIBILIDAD

Añadido en curl 7.30.0

VALOR DE RETORNO

curl_multi_setopt(3) devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; consulte libcurl-errors(3).
