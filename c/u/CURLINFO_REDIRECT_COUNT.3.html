CURLINFO_REDIRECT_COUNT(3)

Paquete: curl

Licencias: MIT

CURLINFO_REDIRECT_COUNT(3) Manual de funciones de la biblioteca CURLINFO_REDIRECT_COUNT(3)

NOMBRE

CURLINFO_REDIRECT_COUNT - obtener el número de redirecciones

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_REDIRECT_COUNT,
                           long *countp);

DESCRIPCIÓN

Pase un puntero a un `long` para recibir el número total de redirecciones que se siguieron realmente.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      long redirects;
      curl_easy_getinfo(curl, CURLINFO_REDIRECT_COUNT, &redirects);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.9.7

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un `CURLcode` indicando éxito o error.

CURLE_OK (0) significa que todo fue bien; un valor distinto de cero indica que ocurrió un error. Consulte libcurl-errors(3).

VER TAMBIÉN

CURLINFO_REDIRECT_URL(3), CURLOPT_FOLLOWLOCATION(3), curl_easy_getinfo(3), curl_easy_setopt(3)
