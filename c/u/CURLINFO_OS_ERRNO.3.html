CURLINFO_OS_ERRNO(3)

Paquete: curl

Licencias: MIT

CURLINFO_OS_ERRNO(3) Manual de funciones de biblioteca CURLINFO_OS_ERRNO(3)

NOMBRE

CURLINFO_OS_ERRNO - obtener el número errno del último fallo de conexión

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_OS_ERRNO, long *errnop);

DESCRIPCIÓN

Pasa un puntero a un long para recibir la variable errno de un fallo de conexión. Tenga en cuenta que el valor solo se establece en caso de fallo, no se restablece tras una operación exitosa. El número es específico del sistema operativo y del sistema.

Los errores relacionados con la red de libcurl que pueden tener un errno guardado son: CURLE_COULDNT_CONNECT, CURLE_FAILED_INIT, CURLE_INTERFACE_FAILED, CURLE_OPERATION_TIMEDOUT, CURLE_RECV_ERROR, CURLE_SEND_ERROR.

Desde la versión 8.8.0, libcurl borra el errno guardado del handle fácil antes de realizar la transferencia. Las versiones anteriores no borraron el errno guardado, lo que significa que si se recupera un errno guardado, podría ser de una transferencia anterior en el mismo handle.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos admitidos

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(res != CURLE_OK) {
      long error;
      res = curl_easy_getinfo(curl, CURLINFO_OS_ERRNO, &error);
      if(!res && error) {
        printf("Errno: %ld\n", error);
      }
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.12.2

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN

curl_easy_getinfo(3), curl_easy_setopt(3)
