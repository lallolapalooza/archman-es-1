curl_easy_recv(3)

Paquete: curl

Licencias: MIT

curl_easy_recv(3) Manual de Funciones de Librería curl_easy_recv(3)

NOMBRE

curl_easy_recv - recibe datos brutos en una conexión "easy"

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_recv(CURL *curl, void *buffer, size_t buflen, size_t *n);

DESCRIPCIÓN

Esta función recibe datos brutos de la conexión establecida. Puede utilizarla junto con curl_easy_send(3) para implementar protocolos personalizados utilizando libcurl. Esta funcionalidad puede ser particularmente útil si utiliza proxies y/o cifrado SSL: libcurl se encarga de la negociación del proxy y la configuración de la conexión.

buffer es un puntero a la memoria de su búfer que se llenará con los datos recibidos. buflen es la cantidad máxima de datos que puede obtener en ese búfer. La variable n apunta a la cantidad de bytes recibidos.

Para establecer la conexión, configure la opción CURLOPT_CONNECT_ONLY(3) antes de llamar a curl_easy_perform(3) o curl_multi_perform(3). Tenga en cuenta que curl_easy_recv(3) no funciona en conexiones que se crearon sin esta opción.

La llamada devuelve CURLE_AGAIN si no hay datos para leer; el socket se utiliza en modo no bloqueante internamente. Cuando se devuelve CURLE_AGAIN, utilice las facilidades de su sistema operativo como select(2) para esperar datos. El socket puede obtenerse utilizando curl_easy_getinfo(3) con CURLINFO_ACTIVESOCKET(3).

Espere en el socket solo si curl_easy_recv(3) devuelve CURLE_AGAIN. La razón de esto es que libcurl o la librería SSL pueden almacenar en caché algunos datos internamente, por lo tanto, debe llamar a curl_easy_recv(3) hasta que se lean todos los datos, lo que incluiría cualquier dato almacenado en caché.

Además, si espera en el socket y este le indica que hay datos para leer, curl_easy_recv(3) puede devolver CURLE_AGAIN si los únicos datos que se leyeron fueron para el procesamiento interno de SSL y no hay otros datos disponibles.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos soportados

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* No hacer la transferencia - solo conectar al host */
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      char buf[256];
      size_t nread;
      curl_socket_t sockfd;
      /* Extraer el socket del manejador curl - lo necesitamos para esperar. */
      res = curl_easy_getinfo(curl, CURLINFO_ACTIVESOCKET, &sockfd);
      /* leer datos */
      res = curl_easy_recv(curl, buf, sizeof(buf), &nread);
    }
  }
}

DISPONIBILIDAD

Añadido en curl 7.18.2

VALOR DE RETORNO

En caso de éxito, devuelve CURLE_OK, almacena los datos recibidos en buffer y el número de bytes que realmente leyó en *n.

En caso de error, devuelve el código de error apropiado.

La función puede devolver CURLE_AGAIN. En este caso, utilice las facilidades de su sistema operativo para esperar hasta que se puedan leer los datos y reintentar.

Leer exactamente 0 bytes indica una conexión cerrada.

Si no hay ningún socket disponible para usar de la transferencia anterior, esta función devuelve CURLE_UNSUPPORTED_PROTOCOL.
