curl_global_cleanup(3)

Paquete: curl

Licencias: MIT

curl_global_cleanup(3) Manual de funciones de biblioteca curl_global_cleanup(3)

NOMBRE

curl_global_cleanup - limpieza global de libcurl

SINOPSIS

#include <curl/curl.h>
void curl_global_cleanup(void);

DESCRIPCIÓN

Esta función libera los recursos adquiridos por curl_global_init(3).

Debe llamar a curl_global_cleanup(3) una vez por cada llamada que haga a curl_global_init(3), después de haber terminado de usar libcurl.

Esta función es segura para hilos desde libcurl 7.84.0 si curl_version_info(3) tiene el bit de característica CURL_VERSION_THREADSAFE establecido (en la mayoría de las plataformas).

Si no es segura para hilos, no debe llamar a esta función cuando ningún otro hilo del programa (es decir, un hilo que comparte la misma memoria) se esté ejecutando. Esto no significa solo ningún otro hilo que esté usando libcurl. Dado que curl_global_cleanup(3) llama a funciones de otras bibliotecas que no son seguras para hilos de manera similar, podría entrar en conflicto con cualquier otro hilo que utilice estas otras bibliotecas.

Consulte la descripción en libcurl(3) sobre los requisitos del entorno global para obtener detalles sobre cómo usar esta función.

PRECAUCIÓN

curl_global_cleanup(3) no bloquea esperando que los hilos creados por libcurl terminen (como los hilos utilizados para la resolución de nombres). Si un módulo que contiene libcurl se descarga dinámicamente mientras los hilos creados por libcurl todavía se están ejecutando, su programa podría fallar o podría ocurrir otra corrupción. Recomendamos que no ejecute libcurl desde ningún módulo que pueda ser descargado dinámicamente. Este comportamiento puede ser abordado en el futuro.

Es posible que libcurl no pueda limpiar completamente después de OpenSSL multihilo, dependiendo de cómo se compiló y cargó OpenSSL como biblioteca. Es posible en algunas circunstancias raras que ocurra una fuga de memoria a menos que implemente su propia limpieza de hilos de OpenSSL. Consulte libcurl-thread(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  curl_global_init(CURL_GLOBAL_DEFAULT);
  /* usa libcurl, luego antes de salir... */
  curl_global_cleanup();
}

DISPONIBILIDAD

Añadido en curl 7.8

VALOR DE RETORNO

Ninguno
