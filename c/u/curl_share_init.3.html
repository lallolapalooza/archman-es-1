curl_share_init(3)

Paquete: curl

Licencias: MIT

curl_share_init(3) Manual de funciones de biblioteca curl_share_init(3)

NOMBRE

curl_share_init - crear un objeto de compartición

SINOPSIS

#include <curl/curl.h>
CURLSH *curl_share_init();

DESCRIPCIÓN

Esta función devuelve un puntero a un manejador CURLSH que se utilizará como entrada para todas las demás funciones de compartición, a veces denominado manejador de compartición en algunos lugares de la documentación. Esta llamada de inicialización DEBE tener una llamada correspondiente a curl_share_cleanup(3) cuando todas las operaciones que utilizan la compartición hayan finalizado.

Este manejador de compartición es lo que se pasa a curl mediante la opción CURLOPT_SHARE(3) con curl_easy_setopt(3), para hacer que ese manejador de curl específico utilice los datos de esta compartición.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_SHARE, CURL_LOCK_DATA_CONNECT);
  if(sh)
    printf("Error: %s\n", curl_share_strerror(sh));
}

DISPONIBILIDAD

Añadido en curl 7.10

VALOR DE RETORNO

Si esta función devuelve NULL, algo salió mal (falta de memoria, etc.) y por lo tanto el objeto de compartición no se creó.

VER TAMBIÉN

curl_share_cleanup(3), curl_share_setopt(3)
