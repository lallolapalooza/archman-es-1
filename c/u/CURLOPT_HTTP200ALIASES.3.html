CURLOPT_HTTP200ALIASES(3)

Paquete: curl

Licencias: MIT

CURLOPT_HTTP200ALIASES(3) Manual de funciones de la biblioteca CURLOPT_HTTP200ALIASES(3)

NOMBRE

CURLOPT_HTTP200ALIASES - coincidencias alternativas para HTTP 200 OK

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HTTP200ALIASES,
                          struct curl_slist *aliases);

DESCRIPCIÓN

Pase un puntero a una lista enlazada de aliases para ser tratados como respuestas HTTP 200 válidas. Algunos servidores responden con una línea de respuesta de encabezado personalizada. Por ejemplo, los servidores SHOUTcast responden con "ICY 200 OK". También algunos servidores antiguos de Icecast 1.3.x responden de esa manera para ciertos encabezados de agente de usuario o en ausencia de ellos. Al incluir esta cadena en su lista de alias, la respuesta se trata como una línea de encabezado HTTP válida, como "HTTP/1.0 200 OK".

La lista enlazada debe ser una lista completamente válida de estructuras struct curl_slist, y estar correctamente completada. Use curl_slist_append(3) para crear la lista y curl_slist_free_all(3) para limpiar una lista completa.

El alias en sí no se analiza en busca de cadenas de versión. Se supone que el protocolo coincide con HTTP 1.0 cuando hay una coincidencia de alias.

El uso de esta opción varias veces hace que la última lista establecida reemplace a las anteriores. Establézcala a NULL para volver a deshabilitar su uso.

libcurl no copia la lista, debe mantenerse disponible hasta después de que la transferencia se haya completado.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_slist *list;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    list = curl_slist_append(NULL, "ICY 200 OK");
    list = curl_slist_append(list, "WEIRDO 99 FINE");
    curl_easy_setopt(curl, CURLOPT_HTTP200ALIASES, list);
    curl_easy_perform(curl);
    curl_slist_free_all(list); /* liberar la lista de nuevo */
  }
}

DISPONIBILIDAD

Añadido en curl 7.10.3

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, ver libcurl-errors(3).
