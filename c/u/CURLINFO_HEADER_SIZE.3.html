CURLINFO_HEADER_SIZE(3)

Paquete: curl

Licencias: MIT

CURLINFO_HEADER_SIZE(3) Manual de funciones de la biblioteca CURLINFO_HEADER_SIZE(3)

NOMBRE

CURLINFO_HEADER_SIZE - obtener el tamaño de las cabeceras recuperadas

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_HEADER_SIZE, long *sizep);

DESCRIPCIÓN

Pase un puntero a un long para recibir el tamaño total de todas las cabeceras recibidas. Medido en número de bytes.

El total incluye el tamaño de cualquier cabecera recibida suprimida por CURLOPT_SUPPRESS_CONNECT_HEADERS(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      long size;
      res = curl_easy_getinfo(curl, CURLINFO_HEADER_SIZE, &size);
      if(!res)
        printf("Tamaño de cabecera: %ld bytes\n", size);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.4.1

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error; véase libcurl-errors(3).

VER TAMBIÉN
