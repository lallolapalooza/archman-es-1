CURLOPT_TCP_NODELAY(3)

Paquete: curl

Licencias: MIT

CURLOPT_TCP_NODELAY(3) Manual de funciones de biblioteca CURLOPT_TCP_NODELAY(3)

NOMBRE

CURLOPT_TCP_NODELAY - la opción TCP_NODELAY

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TCP_NODELAY, long nodelay);

DESCRIPCIÓN

Pasa un valor long que especifica si la opción TCP_NODELAY se establece o se borra (1L = establecer, 0 = borrar). La opción se establece por defecto. Esto no tiene ningún efecto después de que la conexión se haya establecido.

Establecer esta opción a 1L deshabilita el algoritmo de Nagle en las conexiones creadas usando este manejador. El propósito de este algoritmo es minimizar el número de paquetes pequeños en la red (donde "paquetes pequeños" significa segmentos TCP de menos del Tamaño Máximo de Segmento para la red).

Maximizar la cantidad de datos enviados por segmento TCP es bueno porque amortiza el sobrecoste del envío. Sin embargo, en algunos casos, los segmentos pequeños pueden necesitar ser enviados sin demora. Esto es menos eficiente que enviar mayores cantidades de datos a la vez y puede contribuir a la congestión en la red si se abusa.

POR OMISIÓN

1

PROTOCOLOS

Esta funcionalidad afecta solo a tcp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* dejar el algoritmo de Nagle habilitado */
    curl_easy_setopt(curl, CURLOPT_TCP_NODELAY, 0L);
    curl_easy_perform(curl);
  }
}

HISTORIAL

El valor por defecto se cambió de 1 a 0 en la versión 7.50.2.

DISPONIBILIDAD

Añadido en curl 7.11.2

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
