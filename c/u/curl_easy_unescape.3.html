NOMBRE

curl_easy_unescape - Decodifica una cadena de URL

SINOPSIS

#include <curl/curl.h>
char *curl_easy_unescape(CURL *curl, const char *input,
                         int inlength, int *outlength);

DESCRIPCIÓN

Esta función convierte la cadena codificada en URL input a una "cadena normal" y la devuelve en un área de memoria asignada. Todos los caracteres de entrada que están codificados en URL (%XX donde XX es un número hexadecimal de dos dígitos) se convierten a sus versiones binarias.

Si el argumento length se establece en 0 (cero), curl_easy_unescape(3) utiliza strlen() en input para determinar el tamaño.

Si outlength no es NULL, la función escribe la longitud de la cadena devuelta en el entero al que apunta. Esto permite un manejo adecuado incluso para cadenas que contienen %00. Dado que es un puntero a un tipo int, solo puede devolver un valor hasta INT_MAX, por lo que no se puede devolver una cadena más larga en este parámetro.

Desde la versión 7.82.0, el parámetro curl se ignora. Antes de eso, había soporte de conversión de caracteres por identificador para algunos sistemas operativos antiguos como TPF, pero por lo demás se ignoraba.

Debes llamar a curl_free(3) con la cadena devuelta cuando hayas terminado con ella.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    int decodelen;
    char *decoded = curl_easy_unescape(curl, "%63%75%72%6c", 12, &decodelen);
    if(decoded) {
      /* no asumas que printf() funciona con los datos decodificados */
      printf("Decodificado: ");
      /* ... */
      curl_free(decoded);
    }
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.15.4

VALOR DE RETORNO

Un puntero a una cadena terminada en nulo o NULL si falló.
