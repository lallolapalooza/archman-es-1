CURLOPT_PIPEWAIT(3)

Paquete: curl

Licencias: MIT

CURLOPT_PIPEWAIT(3) Manual de funciones de biblioteca CURLOPT_PIPEWAIT(3)

NOMBRE

CURLOPT_PIPEWAIT - esperar la multiplexación

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PIPEWAIT, long wait);

DESCRIPCIÓN

Establece wait en 1L para indicar a libcurl que prefiera esperar a que una conexión confirme o niegue que puede hacer multiplexación antes de continuar.

Al realizar una nueva transferencia que permite la multiplexación, libcurl busca conexiones existentes para usar. Si no existe tal conexión, continúa inmediatamente y crea una conexión nueva para usar.

Al establecer esta opción en 1, y teniendo CURLMOPT_PIPELINING(3) habilitada para el manejador multi con el que se asocia esta transferencia, libcurl en su lugar espera a que la conexión revele si es posible multiplexar antes de continuar. Esto permite a libcurl mantener el número de conexiones al mínimo mucho mejor cuando se utilizan protocolos de multiplexación.

Con esta opción establecida, libcurl prefiere esperar y reutilizar una conexión existente para la multiplexación en lugar de lo contrario: preferir abrir una nueva conexión en lugar de esperar.

El tiempo de espera es el que tarda la conexión en establecerse y en que libcurl obtenga la respuesta necesaria que le informa sobre su nivel de protocolo y soporte.

POR DEFECTO

0 (apagado)

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PIPEWAIT, 1L);
    /* ahora agregue este manejador easy al manejador multi */
  }
}

DISPONIBILIDAD

Añadido en curl 7.43.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un código CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
