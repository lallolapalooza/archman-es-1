CURLOPT_CONNECT_ONLY(3)

Paquete: curl

Licencias: MIT

CURLOPT_CONNECT_ONLY(3) Manual de funciones de biblioteca CURLOPT_CONNECT_ONLY(3)

NOMBRE

CURLOPT_CONNECT_ONLY - detenerse al conectarse al servidor de destino

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONNECT_ONLY, long only);

DESCRIPCIÓN

Pase un long. Si el parámetro es igual a 1, le indica a la biblioteca que realice toda la autenticación de proxy requerida y la configuración de la conexión, pero sin transferencia de datos, y luego regrese.

La opción se puede utilizar para probar simplemente una conexión a un servidor, pero es más útil cuando se usa con la opción CURLINFO_ACTIVESOCKET(3) para curl_easy_getinfo(3), ya que la biblioteca puede configurar la conexión y luego la aplicación puede obtener el socket utilizado más recientemente para transferencias de datos especiales.

Desde la versión 7.86.0, esta opción se puede establecer en '2' y, si se utiliza WebSocket, libcurl realiza la solicitud y lee todas las cabeceras de respuesta antes de ceder el control a la aplicación. Para otros protocolos, el comportamiento de '2' no está definido.

Las transferencias marcadas como solo conexión no reutilizan ninguna conexión existente, y las conexiones marcadas como solo conexión no pueden ser reutilizadas.

Si la transferencia de solo conexión se realiza utilizando la interfaz múltiple, el manejador específico debe permanecer agregado al manejador múltiple mientras la aplicación desee utilizarlo. Una vez que se ha eliminado con curl_multi_remove_handle(3), curl_easy_send(3) y curl_easy_recv(3) no funcionan.

PREDETERMINADO

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    ret = curl_easy_perform(curl);
    if(ret == CURLE_OK) {
      /* solo conectado */
    }
  }
}

HISTORIA

Se agregó soporte para WS y WSS en la versión 7.86.0.

DISPONIBILIDAD

Añadido en curl 7.15.2

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
