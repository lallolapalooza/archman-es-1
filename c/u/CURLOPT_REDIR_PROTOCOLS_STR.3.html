CURLOPT_REDIR_PROTOCOLS_STR(3)

Paquete: curl

Licencias: MIT

CURLOPT_REDIR_PROTOCOLS_STR(3) Manual de funciones de biblioteca CURLOPT_REDIR_PROTOCOLS_STR(3)

NOMBRE

CURLOPT_REDIR_PROTOCOLS_STR - protocolos permitidos para redirigir

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_REDIR_PROTOCOLS_STR,
                          char *spec);

DESCRIPCIÓN

Pase un puntero a una cadena que contiene una lista separada por comas de nombres de protocolos (esquemas de URL) que no distinguen entre mayúsculas y minúsculas. Esa lista limita qué protocolos puede usar libcurl en una transferencia que sigue en una redirección cuando CURLOPT_FOLLOWLOCATION(3) está habilitado. Esta opción permite a las aplicaciones limitar transferencias específicas para que solo puedan usar un subconjunto de protocolos en las redirecciones.

Los protocolos denegados por CURLOPT_PROTOCOLS_STR(3) no son anulados por esta opción.

Por defecto, libcurl permite HTTP, HTTPS, FTP y FTPS en las redirecciones (desde la versión 7.65.2).

Estos son los protocolos disponibles:

DICT, FILE, FTP, FTPS, GOPHER, GOPHERS, HTTP, HTTPS, IMAP, IMAPS, LDAP, LDAPS, MQTT, POP3, POP3S, RTMP, RTMPE, RTMPS, RTMPT, RTMPTE, RTMPTS, RTSP, SCP, SFTP, SMB, SMBS, SMTP, SMTPS, TELNET, TFTP, WS, WSS

Puede establecer "ALL" como un atajo para habilitar todos los protocolos. Tenga en cuenta que al establecer todos, puede habilitar protocolos que no eran compatibles el día que escribe esto, pero que se introducen en una versión futura de libcurl.

Si intenta establecer un protocolo inexistente o si no se establece ningún protocolo coincidente, devuelve un error.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala en NULL para restaurarla al valor predeterminado interno.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

PREDETERMINADO

HTTP, HTTPS, FTP y FTPS (Añadido en 7.65.2).

Las versiones anteriores tenían como valor predeterminado todos los protocolos excepto FILE, SCP y, desde 7.40.0, SMB y SMBS.

PROTOCOLOS

Esta funcionalidad afecta solo a HTTP

EJEMPLO

int main(int argc, char **argv)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* pasar la URL desde una fuente externa */
    curl_easy_setopt(curl, CURLOPT_URL, argv[1]);
    /* solo permitir redirecciones a URL HTTP y HTTPS */
    curl_easy_setopt(curl, CURLOPT_REDIR_PROTOCOLS_STR, "http,https");
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.85.0

VALOR DE RETORNO

Devuelve CURLE_UNKNOWN_OPTION si la opción no está implementada, CURLE_UNSUPPORTED_PROTOCOL si un protocolo listado no es compatible o está deshabilitado, CURLE_BAD_FUNCTION_ARGUMENT si no se lista ningún protocolo, de lo contrario CURLE_OK.
