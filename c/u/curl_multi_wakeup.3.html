curl_multi_wakeup(3)

Paquete: curl

Licencias: MIT

curl_multi_wakeup(3) Manual de funciones de la biblioteca curl_multi_wakeup(3)

NOMBRE

curl_multi_wakeup - despierta una llamada curl_multi_poll(3) dormida

SINOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_wakeup(CURLM *multi_handle);

DESCRIPCIÓN

Esta función puede ser llamada desde cualquier hilo y despierta una llamada a curl_multi_poll(3) que esté actualmente (o a punto de) esperando actividad o un tiempo de espera.

Si la función se llama cuando no hay ninguna llamada a curl_multi_poll(3), hace que la próxima llamada devuelva inmediatamente.

Llamar a esta función solo garantiza despertar la llamada actual (o la próxima si no hay ninguna) a curl_multi_poll(3), lo que significa que es posible que múltiples llamadas a esta función despierten la misma operación en espera.

Esta función no tiene ningún efecto en las llamadas a curl_multi_wait(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

extern int time_to_die(void);
extern int set_something_to_signal_thread_1_to_exit(void);
extern int decide_to_stop_thread1();
int main(void)
{
  CURL *easy;
  CURLM *multi = curl_multi_init();
  int still_running;
  easy = curl_easy_init();
  /* añadir el manejador individual fácil */
  curl_multi_add_handle(multi, easy);
  /* este es el hilo 1 */
  do {
    CURLMcode mc;
    int numfds;
    mc = curl_multi_perform(multi, &still_running);
    if(mc == CURLM_OK) {
      /* esperar actividad, tiempo de espera o despertar */
      mc = curl_multi_poll(multi, NULL, 0, 10000, &numfds);
    }
    if(time_to_die())
      return 1;
  } while(still_running);
  curl_multi_remove_handle(multi, easy);
  /* este es el hilo 2 */
  if(decide_to_stop_thread1()) {
    set_something_to_signal_thread_1_to_exit();
    curl_multi_wakeup(multi);
  }
}

DISPONIBILIDAD

Añadido en curl 7.68.0

VALOR DE RETORNO

Esta función devuelve un CURLMcode que indica éxito o error.

CURLM_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
