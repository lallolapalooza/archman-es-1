CURLOPT_RESOLVE(3)

Paquete: curl

Licencias: MIT

CURLOPT_RESOLVE(3) Manual de funciones de biblioteca CURLOPT_RESOLVE(3)

NOMBRE

CURLOPT_RESOLVE - proporcionar resoluciones de host a IP personalizadas

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RESOLVE,
                          struct curl_slist *hosts);

DESCRIPCIÓN

Pasa un puntero a una lista enlazada de cadenas con información de resolución de host para usar en las solicitudes con este manejador. La lista enlazada debe ser una lista completamente válida de estructuras struct curl_slist llenas correctamente. Use curl_slist_append(3) para crear la lista y curl_slist_free_all(3) para limpiar una lista completa.

libcurl no copia la lista, debe mantenerse hasta después de que la transferencia haya completado.

Cada regla de resolución a agregar debe escribirse usando el formato

[+]HOST:PUERTO:DIRECCIÓN[,DIRECCIÓN]

HOST es el nombre que libcurl quiere resolver, PUERTO es el número de puerto del servicio al que libcurl quiere conectarse al HOST y DIRECCIÓN es una o más direcciones IP numéricas. Si especifica múltiples direcciones IP, estas deben estar separadas por comas. Si libcurl está compilado para admitir IPv6, cada una de las entradas DIRECCIÓN puede ser, por supuesto, de estilo IPv4 o IPv6.

Especifique el host como un único asterisco (*) para que coincida con todos los nombres. Este comodín se resuelve al final, por lo que cualquier resolución con un host y número de puerto específicos tiene prioridad.

Esta opción efectivamente puebla la caché DNS con entradas para el par host+puerto, de modo que las redirecciones y todo lo que las operaciones contra el HOST+PUERTO usen en su lugar la(s) DIRECCIÓN(es) que usted proporcionó.

El signo más (+) opcional al principio especifica que la nueva entrada debe caducar. Las entradas agregadas sin el carácter de signo más nunca caducan, mientras que las entradas agregadas con +HOST:... caducan al igual que las entradas DNS normales de la caché.

Si la caché DNS ya tiene una entrada para el par host+puerto dado, la nueva entrada anula la anterior.

Una DIRECCIÓN proporcionada por esta opción solo se usa si no está restringida por la configuración de CURLOPT_IPRESOLVE(3) a una versión IP diferente.

Para eliminar nombres de la caché DNS nuevamente, para dejar de proporcionar estas falsas resoluciones, incluya una cadena en la lista enlazada que use el formato

-HOST:PUERTO

La entrada a eliminar debe ir precedida de un guion, y el nombre de host y el número de puerto deben coincidir exactamente con lo que se agregó previamente.

Proporcione direcciones IPv6 dentro de corchetes [].

Usar esta opción varias veces hace que la última lista establecida anule las anteriores. Establézcala en NULL para deshabilitar su uso nuevamente.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl;
  struct curl_slist *host = NULL;
  host = curl_slist_append(NULL, "example.com:443:127.0.0.1");
  host = curl_slist_append(host, "example.com:443:[2001:db8::252f:efd6]");
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_RESOLVE, host);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_perform(curl);
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
  curl_slist_free_all(host);
}

HISTORIAL

Añadido en la versión 7.21.3. Soporte para eliminación añadido en la versión 7.42.0.

El soporte para proporcionar la DIRECCIÓN dentro de corchetes [] se añadió en la versión 7.57.0.

El soporte para proporcionar múltiples direcciones IP por entrada se añadió en la versión 7.59.0.

El soporte para añadir entradas no permanentes usando el prefijo "+" se añadió en la versión 7.75.0.

El soporte para especificar el componente del host como una dirección IPv6 se añadió en la versión 8.13.0.

DISPONIBILIDAD

Añadido en curl 7.21.3

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error, consulte libcurl-errors(3).
