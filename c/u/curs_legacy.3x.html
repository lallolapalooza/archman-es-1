curs_legacy(3X) Llamadas a biblioteca curs_legacy(3X)

NOMBRE

getattrs, getbegx, getbegy, getcurx, getcury, getmaxx, getmaxy, getparx, getpary - obtener coordenadas o atributos del cursor y ventana de curses (legado)

SINOPSIS

#include <curses.h>
int getattrs(const WINDOW *win);
int getbegx(const WINDOW *win);
int getbegy(const WINDOW *win);
int getcurx(const WINDOW *win);
int getcury(const WINDOW *win);
int getmaxx(const WINDOW *win);
int getmaxy(const WINDOW *win);
int getparx(const WINDOW *win);
int getpary(const WINDOW *win);

DESCRIPCIÓN

Estas funciones heredadas son más sencillas de usar que las funciones X/Open de curses:

•
La función getattrs devuelve los mismos datos de atributos que wattr_get.
Sin embargo, getattrs devuelve un entero (en realidad un chtype), mientras que wattr_get devuelve el par de colores actual en un parámetro separado. En la configuración de la biblioteca de caracteres anchos (wide-character), los pares de colores pueden no caber en un chtype, por lo que wattr_get es la única forma de obtener la información de color.
Dado que getattrs devuelve los atributos en un solo parámetro, no sería posible para una aplicación distinguirlo de ERR (un -1). Si el parámetro de ventana es nulo, getattrs devuelve A_NORMAL (cero).
  • Las funciones getbegy y getbegx devuelven los mismos datos que getbegyx.
  • Las funciones getcury y getcurx devuelven los mismos datos que getyx.
  • Las funciones getmaxy y getmaxx devuelven los mismos datos que getmaxyx.
  • Las funciones getpary y getparx devuelven los mismos datos que getparyx.

VALOR DE RETORNO

Excepto donde se indica, estas funciones devuelven un entero, o ERR si el parámetro de ventana es nulo.

NOTAS

Todas estas interfaces se implementan como macros y funciones. Las macros se suprimen (y solo se proporcionan las funciones) en una compilación de ncurses "opaca", que define el símbolo de preprocesador NCURSES_OPAQUE. Ver la sección "CONFIGURACIONES ALTERNATIVAS" en ncurses(3X).

Las formas estándar como getyx deben implementarse como macros y (en esta implementación) se definen en términos de las funciones descritas aquí, para evitar la dependencia de detalles internos de la estructura WINDOW.

PORTABILIDAD

Estas funciones fueron compatibles con las implementaciones de la Versión 7, BSD o System V. Ninguna de esas implementaciones comprobaba el parámetro de ventana.

La función y macro getattrs se definen para devolver un entero (con signo) para compatibilidad con esas implementaciones, aunque un tipo sin signo habría sido más apropiado.
