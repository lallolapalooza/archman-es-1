DESCRIPCIÓ

N

Curses::UI::Buttonbox es un widget que se

puede utilizar para crear una lista de
botones (o, por supuesto, solo un botón).

OPCIONES ESPECÍFICAS DEL

WIDGET
  • -buttons < ARRAYREF >

    Esta opción toma una referencia a una lista de botones. La lista puede contener tanto tipos de botones predefinidos como definiciones completas de botones

    propias.

    * Tu propia definición

    de botón 
    Una definición de botón es una referencia a un hash. Este
hash puede tener los siguientes pares clave-valor:
obligatorio:
-----------
-label      Esto determina qué texto debe dibujarse
            en el botón.
opcional:
---------
-value      Esto determina el valor de retorno para el
            método get(). Si el valor no está definido,
            el método get() devolverá el índice
            del botón.
-shortcut   El botón actuará como si se hubiera pulsado
            si se presiona la tecla definida por -shortcut
-onpress    Si el valor para -onpress es una referencia a
            CODE, este código se ejecutará si el botón
            se presiona, antes de que el widget de botones pierda
            el foco y
    retorne.

    * Tipo de botón

    predefinido 
    Este módulo tiene una lista predefinida de tipos de botones
frecuentemente utilizados. Usar estos en B<-buttons> hace las cosas mucho
más fáciles. Los tipos de botones predefinidos son:
ok          -label    => '< OK >'
            -shortcut => 'o'
            -value    => 1
            -onpress  => undef
cancel      -label    => '< Cancel >'
            -shortcut => 'c'
            -value    => 0
            -onpress  => undef
yes         -label    => '< Yes >'
            -shortcut => 'y'
            -value    => 1
            -onpress  => undef
no          -label    => '< No >'
            -shortcut => 'n'
            -value    => 0
            -onpress  =>
    undef

    Ejem

    plo: 
    ....
-buttons => [
    { -label => '< My own button >',
      -value => 'mine!',
      -shortcut => 'm' },
    'ok',
    'cancel',
    { -label => '< My second button >',
      -value => 'another one',
      -shortcut => 's',
      -onpress => sub { die "Do not press this button!\n" } }
    ] .
    • ...
  • -selected < INDEX >

    Por defecto, el primer botón (índice = 0) está activo. Si quieres

    que otro botón esté activo en el momento de la creación, añade esta
    • opción. El INDEX es el índice del botón que quieres hacer activo.
  • -buttonalignment < VALUE >

    Puedes especificar cómo deben alinearse los bot

    ones en el widget. Los valores disponi
    • bles para VALUE son 'left', 'middle' y 'right'.
  • -vertical < BOOLEAN >

    Cuando se establece en un v

    alor verdadero, hará que l
    • os botones se rende
ricen con alineación verti
cal en lugar de horizontal.

DEFECTO
  • <enter>, <space>

    llamando a:

    Llama a la rutina 'previous'. Esto hará que el botón
