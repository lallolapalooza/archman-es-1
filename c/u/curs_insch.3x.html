NOMBRE

insch, winsch, mvinsch, mvwinsch - insertar un carácter de curses en una ventana

SINOPSIS

#include <curses.h>
int insch(chtype ch);
int winsch(WINDOW *win, chtype ch);
int mvinsch(int y, int x, chtype ch);
int mvwinsch(WINDOW *win, int y, int x, chtype ch);

DESCRIPCIÓN

Estas funciones insertan el carácter de curses ch en el cursor de la ventana especificada win (o stdscr). El carácter previamente en el cursor y cualquier carácter a su derecha se mueven una celda hacia la derecha; el carácter más a la derecha en la línea se descarta. El cursor no avanza.

VALOR DE RETORNO

Estas funciones devuelven OK en caso de éxito y ERR en caso de fallo.

Las funciones que toman un argumento de puntero WINDOW fallan si el puntero es NULL.

Las funciones prefijadas con "mv" primero realizan un movimiento del cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

insch, mvinsch y mvwinsch pueden implementarse como macros.

La capacidad insert_character (ich1) de un terminal no se emplea necesariamente.

PORTABILIDAD

X/Open Curses, Issue 4 describe estas funciones.

SVr4 curses describe un valor de retorno exitoso solo como "un valor entero distinto de ERR".

VER TAMBIÉN

curs_ins_wch(3X) describe funciones comparables en la configuración de curses de caracteres anchos.
