NOMBRE

Curses::UI::Dialog::Question - Plantear una pregunta simple al usuario

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Question

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La forma difícil.
# -----------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Question',
    -question   => '¿Qué tan súper genial eres?'
);
$dialog->modalfocus;
$win->delete('mydialog');
# La forma fácil (ver documentación de Curses::UI).
# --------------------------------------------
my $value = $cui->question(-question => '¿Qué tan súper genial eres?');
# o incluso
my $awesomeness = $cui->question('¿Qué tan súper genial eres?');

DESCRIPCIÓN

Curses::UI::Dialog::Question es un cuadro de diálogo de pregunta básico. Este tipo de diálogo tiene un mensaje, un cuadro de entrada de texto para la respuesta y uno o más botones. Se puede usar para que un usuario ingrese una respuesta a una pregunta.

Ver examples/demo-widgets en la distribución para una breve demostración.

OPCIONES

  • -title < TEXTO >

    Establece el título de la ventana del diálogo a TEXTO.

  • -question < TEXTO >

    Esta opción establece la pregunta que se mostrará a TEXTO. El texto puede contener caracteres de nueva línea (\\n).

  • -buttons < ARRAYREF >
  • -selected < ÍNDICE >
  • -buttonalignment < VALOR >

    Estas opciones establecen los botones que se utilizarán. Para una explicación de estas opciones, ver la documentación de Curses::UI::Buttonbox.

MÉTODOS

  • new ( HASH )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )

    Estos son métodos estándar. Ver Curses::UI::Container para una explicación de estos.

  • get ( )

    Este método llamará a get en el objeto TextEntry del diálogo y devolverá su valor de retorno. Ver Curses::UI::TextEntry para más información al respecto. Si se presionó el botón de cancelar, el valor de retorno será indefinido.

VER TAMBIÉN

Curses::UI, Curses::UI::Container, Curses::UI::Buttonbox
