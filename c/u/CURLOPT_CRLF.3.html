CURLOPT_CRLF(3)

Paquete: curl

Licencias: MIT

CURLOPT_CRLF(3) Manual de funciones de la biblioteca CURLOPT_CRLF(3)

NOMBRE

CURLOPT_CRLF - Conversión de CRLF

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CRLF, long conv);

DESCRIPCIÓN

Pasa un long. Si el valor se establece en 1 (uno), libcurl convierte los saltos de línea de Unix a saltos de línea CRLF en las transferencias. Desactive esta opción nuevamente estableciendo el valor en 0 (cero).

Esta es una opción heredada de dudoso uso.

POR DEFECTO

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/");
    curl_easy_setopt(curl, CURLOPT_CRLF, 1L);
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VEASE TAMBIÉN

CURLOPT_CONV_FROM_NETWORK_FUNCTION(3), CURLOPT_CONV_TO_NETWORK_FUNCTION(3)
