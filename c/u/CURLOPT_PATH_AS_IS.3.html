CURLOPT_PATH_AS_IS(3)

Paquete: curl

Licencias: MIT

CURLOPT_PATH_AS_IS(3) Manual de funciones de biblioteca CURLOPT_PATH_AS_IS(3)

NOMBRE

CURLOPT_PATH_AS_IS - no manejar secuencias de puntos dobles

SINOPIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PATH_AS_IS, long leaveit);

DESCRIPCIÓN

Establece el entero largo leaveit a 1, para indicar explícitamente a libcurl que no altere la ruta dada antes de pasarla al servidor.

Esto instruye a libcurl a NO aplastar secuencias de "/../" o "/./" que puedan existir en la parte de ruta de la URL y que se supone que deben eliminarse según la RFC 3986 sección 5.2.4.

Algunas implementaciones de servidor son conocidas por (erróneamente) requerir que las secuencias de puntos dobles permanezcan en la ruta, y algunos clientes desean pasarlas para probar las implementaciones del servidor.

Por defecto, libcurl normaliza dichas secuencias antes de usar la ruta.

Esta es una solicitud para la *primera* solicitud que emite libcurl. Al seguir redirecciones, es posible que ya no se aplique.

La bandera correspondiente para la función curl_url_set(3) se llama CURLU_PATH_AS_IS.

POR DEFECTO

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL,
                     "https://example.com/../../etc/password");
    curl_easy_setopt(curl, CURLOPT_PATH_AS_IS, 1L);
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.42.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
