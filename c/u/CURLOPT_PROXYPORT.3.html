CURLOPT_PROXYPORT(3)

Paquete: curl

Licencias: MIT

CURLOPT_PROXYPORT(3) Manual de funciones de biblioteca CURLOPT_PROXYPORT(3)

NOMBRE

CURLOPT_PROXYPORT(3) - número de puerto en el que escucha el proxy

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYPORT, long port);

DESCRIPCIÓN

Desaconsejamos el uso de esta opción.

Pase un long con esta opción para establecer el puerto del proxy al que conectarse, a menos que se especifique en la cadena del proxy CURLOPT_PROXY(3) o use el puerto 443 para proxies https y el 1080 para todos los demás como predeterminado.

Desactivar esta opción, estableciéndola a cero, hace que no se especifique, lo que hace que libcurl utilice el número de puerto del proxy predeterminado o el número de puerto especificado en la cadena de URL del proxy.

Aunque esto acepta un 'long', el número de puerto es de 16 bits, por lo que no puede ser mayor que 65535.

PREDETERMINADO

0

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_PROXY, "localhost");
    curl_easy_setopt(curl, CURLOPT_PROXYPORT, 8080L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo fue bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
