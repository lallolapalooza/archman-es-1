curl_easy_ssls_import(3)

Paquete: curl

Licencias: MIT

curl_easy_ssls_import(3) Manual de funciones de biblioteca curl_easy_ssls_import(3)

NOMBRE

curl_easy_ssls_import - importar sesiones SSL

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_ssls_import(CURL *handle,
                               const char *session_key,
                               const unsigned char *shmac, size_t shmac_len,
                               const unsigned char *sdata, size_t sdata_len);

DESCRIPCIÓN

Esta función importa un ticket de sesión SSL previamente exportado. sdata y sdata_len deben proporcionarse siempre. Si session_key es NULL, entonces se deben proporcionar shmac y shmac_len tal como se recibieron durante la exportación. Consulte curl_easy_ssls_export(3) para una descripción de estos.

La importación de tickets de sesión de otras versiones de curl puede fallar debido a cambios en el manejo de shmac o sdata. Un ticket de sesión que ya ha expirado se descarta silenciosamente.

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS, OpenSSL, mbedTLS y wolfSSL

EJEMPLO

int main(void)
{
  CURLSHcode sh;
  CURLSH *share = curl_share_init();
  CURLcode rc;
  CURL *curl;
  sh = curl_share_setopt(share, CURLSHOPT_SHARE, CURL_LOCK_DATA_SSL_SESSION);
  if(sh)
    printf("Error: %s\n", curl_share_strerror(sh));
  curl = curl_easy_init();
  if(curl) {
    extern unsigned char *shmac, *sdata;
    size_t hlen = 4, slen = 5;
    curl_easy_setopt(curl, CURLOPT_SHARE, share);
    /* leer shmac y sdata del almacenamiento */
    rc = curl_easy_ssls_import(curl, NULL, shmac, hlen, sdata, slen);
    /* limpiar siempre */
    curl_easy_cleanup(curl);
  }
  curl_share_cleanup(share);
}

DISPONIBILIDAD

Añadido en curl 8.12.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error, consulte libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el buffer de error cuando se devuelve un valor distinto de cero.

VER TAMBIÉN

CURLOPT_SHARE(3), curl_easy_ssls_export(3), curl_share_setopt(3)
