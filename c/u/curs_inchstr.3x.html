curs_inchstr(3x)

Paquete: ncurses

Licencias: MIT-open-group

curs_inchstr(3X) Llamadas a la biblioteca curs_inchstr(3X)

NOMBRE

inchstr, inchnstr, winchstr, winchnstr, mvinchstr, mvinchnstr, mvwinchstr, mvwinchnstr - obtener una cadena de caracteres de curses de una ventana

SINOPSIS

#include <curses.h>
int inchstr(chtype *chstr);
int inchnstr(chtype *chstr, int n);
int winchstr(WINDOW *win, chtype *chstr);
int winchnstr(WINDOW *win, chtype *chstr, int n);
int mvinchstr(int y, int x, chtype *chstr);
int mvinchnstr(int y, int x, chtype *chstr, int n);
int mvwinchstr(WINDOW *win, int y, int x, chtype *chstr);
int mvwinchnstr(WINDOW *win, int y, int x, chtype *chstr, int n);

DESCRIPCIÓN

Estas rutinas devuelven un array terminado en NULL de cantidades chtype, comenzando en la posición actual del cursor en la ventana nombrada y terminando en el margen derecho de la ventana.

Las cuatro funciones con n como último argumento, devuelven una subcadena inicial de como máximo n caracteres de longitud (excluyendo el (chtype)0 final). La transferencia se detiene al final de la línea actual, o cuando se han almacenado n caracteres en la ubicación referenciada por chstr.

Las constantes definidas en <curses.h> pueden ser utilizadas con el operador & (AND lógico) para extraer el carácter o el atributo solo de cualquier posición en chstr [ver curs_inch(3X)].

VALOR DE RETORNO

Todas las rutinas devuelven el entero ERR en caso de fallo y un valor entero distinto de ERR en caso de éxito (el número de caracteres recuperados, excluyendo el 0 final).

X/Open Curses no define condiciones de error. Esta implementación devuelve un error

  • si el parámetro win es nulo o
  • si el parámetro chstr es nulo.

Las funciones prefijadas con “mv” mueven primero el cursor y fallan si la posición (y, x) está fuera de los límites de la ventana.

NOTAS

Todas las rutinas excepto winchnstr pueden ser macros.

SVr4 no documenta si la cadena resultante está terminada en cero; no documenta si un argumento de límite de longitud incluye algún cero final; y no documenta el significado del valor de retorno.

Leer una línea que desborda el array apuntado por chstr con inchstr, mvinchstr, mvwinchstr o winchstr causa resultados indefinidos. Por lo tanto, se recomienda el uso de inchnstr, mvinchnstr, mvwinchnstr o winchnstr.

PORTABILIDAD

Estas funciones se describen en X/Open Curses, Issue 4. No es más específica que la documentación de SVr4 sobre el cero final. Especifica que el retorno exitoso de las funciones es OK.

VER TAMBIÉN

curses(3X), curs_inch(3X), curs_inwstr(3X), curs_in_wchstr(3X)
