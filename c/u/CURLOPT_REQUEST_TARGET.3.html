CURLOPT_REQUEST_TARGET(3)

Paquete: curl

Licencias: MIT

CURLOPT_REQUEST_TARGET(3) Manual de funciones de biblioteca CURLOPT_REQUEST_TARGET(3)

NOMBRE

CURLOPT_REQUEST_TARGET - objetivo alternativo para esta solicitud

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_REQUEST_TARGET, cadena);

DESCRIPCIÓN

Pasa un puntero a `char` a `cadena` que libcurl utiliza en la próxima solicitud en lugar de la ruta extraída de la URL.

libcurl pasa la cadena literal en su solicitud sin ningún filtro u otras salvaguardias. Esto incluye espacios en blanco y caracteres de control.

Usar esta opción múltiples veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para deshabilitar su uso de nuevo.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad solo afecta a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/*");
    curl_easy_setopt(curl, CURLOPT_CUSTOMREQUEST, "OPTIONS");
    /* emite una solicitud OPTIONS * (sin barra inicial) */
    curl_easy_setopt(curl, CURLOPT_REQUEST_TARGET, "*");
    /* Realiza la solicitud */
    curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.55.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_CUSTOMREQUEST(3), CURLOPT_HTTPGET(3), CURLOPT_PATH_AS_IS(3), CURLOPT_URL(3)
