CURLOPT_SHARE(3)

Paquete: curl

Licencias: MIT

CURLOPT_SHARE(3) Manual de funciones de la biblioteca CURLOPT_SHARE(3)

NOMBRE

CURLOPT_SHARE - manejador de uso compartido

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SHARE, CURLSH *share);

DESCRIPCIÓN

Pase un manejador share como parámetro. El manejador de uso compartido debe haber sido creado por una llamada previa a curl_share_init(3). Establecer esta opción hace que este manejador curl use los datos del manejador compartido en lugar de conservarlos para sí mismo. Esto permite que varios manejadores curl compartan datos. Si los manejadores curl se utilizan simultáneamente en varios hilos, debe usar los métodos de bloqueo en el manejador de uso compartido. Consulte curl_share_setopt(3) para obtener más detalles.

Si agrega un uso compartido que está configurado para compartir cookies, su manejador easy utiliza esa caché de cookies y habilita el motor de cookies. Si deja de compartir un objeto que estaba utilizando cookies (o cambia a otro objeto que no comparte cookies), el motor de cookies del manejador easy se desactiva.

Los datos que el objeto de uso compartido no está configurado para compartir se manejan de la manera habitual, como si no se utilizara ningún objeto de uso compartido.

Establezca esta opción a NULL nuevamente para dejar de usar ese objeto de uso compartido.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init(); /* un segundo manejador */
  if(curl) {
    CURLcode res;
    CURLSH *shobject = curl_share_init();
    curl_share_setopt(shobject, CURLSHOPT_SHARE, CURL_LOCK_DATA_COOKIE);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_COOKIEFILE, "");
    curl_easy_setopt(curl, CURLOPT_SHARE, shobject);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
    /* el segundo manejador comparte las cookies del primero */
    curl_easy_setopt(curl2, CURLOPT_URL, "https://example.com/second");
    curl_easy_setopt(curl2, CURLOPT_COOKIEFILE, "");
    curl_easy_setopt(curl2, CURLOPT_SHARE, shobject);
    res = curl_easy_perform(curl2);
    curl_easy_cleanup(curl2);
    curl_share_cleanup(shobject);
  }
}

DISPONIBILIDAD

Añadido en curl 7.10

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, consulte libcurl-errors(3).
