CURLOPT_TLSAUTH_TYPE(3)

Paquete: curl

Licencias: MIT

CURLOPT_TLSAUTH_TYPE(3) Manual de funciones de la biblioteca CURLOPT_TLSAUTH_TYPE(3)

NOMBRE

CURLOPT_TLSAUTH_TYPE - Métodos de autenticación TLS

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TLSAUTH_TYPE, char *type);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. La cadena debe ser el método de autenticación TLS. El método admitido es "SRP".

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala a NULL para restaurar el valor predeterminado interno.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

SRP
Autenticación TLS-SRP. La autenticación Secure Remote Password para TLS se define en RFC 5054 y proporciona autenticación mutua si ambos lados tienen un secreto compartido. Para usar TLS-SRP, también debe establecer las opciones CURLOPT_TLSAUTH_USERNAME(3) y CURLOPT_TLSAUTH_PASSWORD(3).

TLS SRP no funciona con TLS 1.3.

PREDETERMINADO

vacío

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Esta opción solo funciona con los siguientes backends TLS: GnuTLS y OpenSSL

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_TYPE, "SRP");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_USERNAME, "user");
    curl_easy_setopt(curl, CURLOPT_TLSAUTH_PASSWORD, "secret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.21.4

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
