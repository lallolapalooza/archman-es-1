NOMBRE

Curses::UI::Dialog::Filebrowser - Crea y manipula diálogos de explorador de archivos

HIERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Filebrowser

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La forma difícil.
# ----------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Filebrowser'
);
$dialog->focus;
my $file = $dialog->get();
$win->delete('mydialog');
# La forma fácil (ver la documentación de Curses::UI).
# --------------------------------------------
$file = $cui->filebrowser();
$file = $cui->loadfilebrowser();
$file = $cui->savefilebrowser();

DESCRIPCIÓN

Curses::UI::Dialog::Filebrowser es un diálogo de explorador de archivos. Este tipo de diálogo se puede utilizar para seleccionar un archivo en cualquier lugar del sistema de archivos.

Ver los ejemplos/demo-Curses::UI::Dialog::Filebrowser en la distribución para una demostración corta.

OPCIONES

  • -title < TEXTO >

    Establece el título de la ventana del diálogo a TEXTO.

  • -path < RUTA >

    Establece la ruta inicial a RUTA. Si esta ruta no existe, el explorador de archivos comenzará en el directorio raíz.

  • -file < ARCHIVO >

    Establece el nombre de archivo inicial a ARCHIVO.

  • -editfilename < BOOLEAN >

    Si BOOLEANO tiene un valor verdadero, el usuario puede editar el nombre del archivo. Esto es útil, por ejemplo, para un explorador de archivos que se utiliza para seleccionar un nombre de archivo para guardar. Por defecto, esta opción está establecida a falso.

  • -show_hidden < BOOLEAN >

    Si BOOLEANO tiene un valor verdadero, los archivos ocultos (cuyo nombre de archivo comienza con un punto) también se mostrarán. Por defecto, esta opción está establecida a falso.

  • -mask < ARRAYREF >

    Si -mask está definido, se agregará una ventana emergente de máscara de archivo al diálogo del explorador de archivos. Esta ventana emergente filtrará la lista de archivos que se muestran, usando una expresión regular (sin distinción de mayúsculas y minúsculas). El ARRAYREF contiene una lista de referencias a arrays. Cada referencia a array tiene dos elementos: una expresión regular y una descripción. Aquí hay un ejemplo de -mask:

    my $mask = [
    [ '.',        'Todos los archivos (*)'       ],
    [ '\.txt$',   'Archivos de texto (*.txt)'  ]
    [ 'howto',    'Documentación HOWTO' ],
    [ 'core',     'Archivos core'          ],
];
  • -mask_selected < ÍNDICE >

    Normalmente, la primera máscara de la lista de máscaras se activará al crear el explorador de archivos. Si desea que otra máscara esté activa, utilice la opción -mask_selected. Establezca este valor al índice de la máscara que desea que esté activa. Por ejemplo: si deseara que la máscara "howto" del ejemplo anterior estuviera activa, utilizaría el valor 2 para -mask_selected.

MÉTODOS

  • new ( OPCIONES )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )

    Estos son métodos estándar. Ver Curses::UI::Container para una explicación de estos.

  • get ( )

    Este método devolverá la ruta completa al archivo que fue seleccionado utilizando el explorador de archivos. Si no se seleccionó ningún archivo, este método devolverá un valor indefinido.

ASIGNACIONES ESPECIALES

  • escape

    Esto invocará el botón de cancelar, por lo que el widget del explorador de archivos regresará sin seleccionar ningún archivo.

  • ~

    Si la lista de directorios o archivos del diálogo tiene el foco y se presiona la tecla tilde (~), el explorador de archivos cambiará al directorio personal del usuario actual.
