CURLOPT_MAIL_FROM(3)

Paquete: curl

Licencias: MIT

CURLOPT_MAIL_FROM(3) Manual de funciones de la biblioteca CURLOPT_MAIL_FROM(3)

NOMBRE

CURLOPT_MAIL_FROM - Dirección del remitente SMTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAIL_FROM, char *from);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. Esto debe usarse para especificar la dirección de correo electrónico del remitente al enviar correo SMTP con libcurl.

Se debe especificar una dirección de correo electrónico del originador entre corchetes angulares (<>), que si no se especifican se añaden automáticamente.

Para especificar parámetros DSN (según RFC 3461), la dirección debe escribirse entre corchetes angulares, seguidos de los parámetros.

Si no se especifica este parámetro, se envía una dirección vacía al servidor SMTP, lo que podría provocar el rechazo del correo.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Usar esta opción varias veces hace que la última cadena establecida anule las anteriores. Establézcala en NULL para desactivar su uso de nuevo.

POR OMISIÓN

vacío

PROTOCOLOS

Esta funcionalidad afecta solo a smtp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "smtp://example.com/");
    curl_easy_setopt(curl, CURLOPT_MAIL_FROM, "president@example.com");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.20.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
