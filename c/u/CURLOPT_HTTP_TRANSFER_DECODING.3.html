CURLOPT_HTTP_TRANSFER_DECODING(3)

Paquete: curl

Licencias: MIT

CURLOPT_HTTP_TRANSFER_DECODING(3) Manual de funciones de biblioteca CURLOPT_HTTP_TRANSFER_DECODING(3)

NOMBRE

CURLOPT_HTTP_TRANSFER_DECODING - control de decodificación de transferencia HTTP

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HTTP_TRANSFER_DECODING,
                         long enabled);

DESCRIPCIÓN

Pase un long para indicar a libcurl cómo actuar sobre la decodificación de transferencia. Si se establece en cero, la decodificación de transferencia se deshabilita; si se establece en 1, se habilita (predeterminado). libcurl realiza la decodificación de transferencia fragmentada por defecto a menos que esta opción se establezca en cero.

PREDETERMINADO

1

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_HTTP_TRANSFER_DECODING, 0L);
    ret = curl_easy_perform(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.16.2

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien; un valor distinto de cero indica que ocurrió un error. Consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_ACCEPT_ENCODING(3), CURLOPT_HTTP_CONTENT_DECODING(3)
