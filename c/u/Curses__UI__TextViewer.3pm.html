Curses::UI::TextViewer(3) Documentación de Perl aportada por el usuario Curses::UI::TextViewer(3)

NOMBRE

Curses::UI::TextViewer - Crear y manipular widgets de visor de texto

JERARQUÍA DE CLASES

Curses::UI::Widget
Curses::UI::Searchable
   |
   +----Curses::UI::TextEditor
           |
           +----Curses::UI::TextViewer

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $textviewer = $win->add( 
    'mytextviewer', 'TextViewer',
-text => "¡Hola, mundo!\n"
           . "Adiós, mundo"
);
$textviewer->focus();

DESCRIPCIÓN

Curses::UI::TextViewer es un widget que se puede utilizar para crear un widget de visor de texto. Esta clase se deriva de Curses::UI::TextEditor. Lo único especial de esta clase es que la opción -readonly se fuerza a un valor verdadero. Por lo tanto, para el uso de Curses::UI::TextViewer, consulte Curses::UI::TextEditor.

VER TAMBIÉN

Curses::UI, Curses::UI::TextEditor,
