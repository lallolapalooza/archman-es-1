Curses::UI::Dialog::Calendar(3) Documentación de Perl aportada por el usuario Curses::UI::Dialog::Calendar(3)

NOMBRE

Curses::UI::Dialog::Calendar - Crea y manipula diálogos de calendario

JERARQUÍA DE CLASES

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Calendar

SINOPSIS

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# La forma difícil.
# -------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Calendar'
);
$dialog->modalfocus;
$win->delete('mydialog');
my $date = $dialog->get();
# La forma fácil (ver la documentación de Curses::UI).
# --------------------------------------------
$date = $cui->calendardialog();

DESCRIPCIÓN

Curses::UI::Dialog::Calendar es un diálogo de calendario. Este tipo de diálogo puede usarse para seleccionar una fecha.

Ver examples/demo-widgets en la distribución para una breve demostración.

OPCIONES

  • -title < TEXTO >

    Establece el título de la ventana del diálogo a TEXTO.

  • -date < FECHA >

    Establece la fecha de inicio a FECHA. Si -date no está definido, se usará la fecha actual como fecha de inicio.

MÉTODOS

  • new ( OPCIONES )
  • layout ( )
  • draw ( BOOLEANO )
  • focus ( )
  • modalfocus ( )

    Estos son métodos estándar. Ver Curses::UI::Container para una explicación de estos.

  • get ( )

    Este método devolverá la fecha seleccionada o undef si no se seleccionó ninguna fecha.

LIGADURAS ESPECIALES

•
escape

Esto invocará el botón de cancelar, por lo que el diálogo de calendario devolverá sin seleccionar ninguna fecha.

VER TAMBIÉN

Curses::UI, Curses::UI::Container, Curses::UI::Buttonbox
