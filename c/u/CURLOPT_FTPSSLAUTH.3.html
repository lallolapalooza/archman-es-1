CURLOPT_FTPSSLAUTH(3)

Paquete: curl

Licencias: MIT

CURLOPT_FTPSSLAUTH(3) Manual de funciones de la biblioteca CURLOPT_FTPSSLAUTH(3)

NOMBRE

CURLOPT_FTPSSLAUTH - orden en el que intentar TLS frente a SSL

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTPSSLAUTH, long order);

DESCRIPCIÓN

Pase un long usando uno de los valores de abajo, para alterar cómo libcurl emite "AUTH TLS" o "AUTH SSL" cuando se activa FTP sobre SSL. Esto solo es interesante si CURLOPT_USE_SSL(3) también está configurado.

Posibles valores de order:

CURLFTPAUTH_DEFAULT
Permitir que libcurl decida.
CURLFTPAUTH_SSL
Intentar primero "AUTH SSL", y solo si falla, intentar "AUTH TLS".
CURLFTPAUTH_TLS
Intentar primero "AUTH TLS", y solo si falla, intentar "AUTH SSL".

POR OMISIÓN

CURLFTPAUTH_DEFAULT

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/file.txt");
    curl_easy_setopt(curl, CURLOPT_USE_SSL, CURLUSESSL_TRY);
    /* servidor extraño, pide SSL antes que TLS */
    curl_easy_setopt(curl, CURLOPT_FTPSSLAUTH, CURLFTPAUTH_SSL);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIA

Los enumerados CURLFTPAUTH_* se convirtieron en tipos long en la versión 8.16.0, antes de esta versión era necesario un cast a long al pasarlos a curl_easy_setopt(3).

DISPONIBILIDAD

Añadido en curl 7.12.2

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).
