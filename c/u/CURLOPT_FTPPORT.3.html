CURLOPT_FTPPORT(3)

Paquete: curl

Licencias: MIT

CURLOPT_FTPPORT(3) Manual de funciones de la biblioteca CURLOPT_FTPPORT(3)

NOMBRE

CURLOPT_FTPPORT(3) - hacer la transferencia FTP activa

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FTPPORT, char *spec);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. Especifica que la transferencia FTP debe ser activa y la cadena dada se usa para obtener la dirección IP a utilizar para la instrucción FTP PORT. Esta instrucción le dice al servidor remoto que establezca una conexión TCP a nuestra dirección IP especificada.

La cadena puede ser una dirección IP simple, un nombre de host, un nombre de interfaz de red (en Unix) o simplemente un símbolo '-' para permitir que la biblioteca use la dirección IP predeterminada de su sistema. Las operaciones FTP predeterminadas son pasivas y no utilizan el comando PORT.

La dirección puede ir seguida de ':' para especificar un puerto, opcionalmente seguido de '-' para especificar un rango de puertos. Si el puerto especificado es 0, el sistema operativo elige un puerto libre. Si se proporciona un rango y todos los puertos del rango no están disponibles, libcurl informa CURLE_FTP_PORT_FAILED para el manejador. La configuración inválida de puertos/rangos se ignora. Las direcciones IPv6 seguidas de un puerto o rango de puertos deben estar entre corchetes. Las direcciones IPv6 sin especificador de puerto/rango pueden estar entre corchetes.

Ejemplos con puertos especificados:

eth0:0
192.168.1.2:32000-33000
curl.se:32123
[::1]:1234-4567

Desaconsejamos encarecidamente especificar la dirección con un nombre, ya que hace que libcurl realice una llamada de resolución de nombres bloqueante para obtener la dirección IP. Esa operación de resolución de nombres no utiliza DNS-over-HTTPS, incluso si CURLOPT_DOH_URL(3) está configurado.

Usar cualquier cosa que no sea "-" para esta opción normalmente solo debería hacerse si tiene conocimiento especial y confirmación de que funciona.

La aplicación no tiene que mantener la cadena disponible después de configurar esta opción.

Usar esta opción varias veces hace que la última cadena configurada anule las anteriores. Vuelve a deshabilitar PORT y vuelve a usar la versión pasiva estableciendo esta opción en NULL.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a ftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/old-server/file.txt");
    curl_easy_setopt(curl, CURLOPT_FTPPORT, "-");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero significa que ocurrió un error, consulte libcurl-errors(3).
