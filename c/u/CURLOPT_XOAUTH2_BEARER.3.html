CURLOPT_XOAUTH2_BEARER(3)

Paquete: curl

Licencias: MIT

CURLOPT_XOAUTH2_BEARER(3) Manual de funciones de la biblioteca CURLOPT_XOAUTH2_BEARER(3)

NOMBRE

CURLOPT_XOAUTH2_BEARER - token de acceso OAuth 2.0

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_XOAUTH2_BEARER, char *token);

DESCRIPCIÓN

Pase un puntero a char como parámetro, el cual debe apuntar al token de acceso de portador OAuth 2.0 terminado en nulo para usarlo con servidores HTTP, IMAP, LDAP, POP3 y SMTP que soporten el Marco de Autorización OAuth 2.0.

Nota: Para IMAP, LDAP, POP3 y SMTP, el nombre de usuario utilizado para generar el token de portador debe proporcionarse a través de la opción CURLOPT_USERNAME(3).

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establécela en NULL para volver a deshabilitar su uso.

POR DEFECTO

NULL

PROTOCOLOS

Esta funcionalidad afecta a http, imap, ldap, pop3 y smtp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "pop3://example.com/");
    curl_easy_setopt(curl, CURLOPT_XOAUTH2_BEARER, "1ab9cb22bf269a7");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIAL

Se añadió soporte para OpenLDAP en 7.82.0.

DISPONIBILIDAD

Añadido en curl 7.33.0

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_MAIL_AUTH(3), CURLOPT_USERNAME(3)
