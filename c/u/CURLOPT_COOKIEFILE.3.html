CURLOPT_COOKIEFILE(3)

Paquete: curl

Licencias: MIT

CURLOPT_COOKIEFILE(3) Manual de funciones de la biblioteca CURLOPT_COOKIEFILE(3)

NOMBRE

CURLOPT_COOKIEFILE - archivo para leer cookies de

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_COOKIEFILE, char *filename);

DESCRIPCIÓN

Pase un puntero a una cadena terminada en nulo como parámetro. Debe apuntar al nombre del archivo que contiene los datos de cookies a leer. Los datos de las cookies pueden estar en el antiguo formato de datos de cookies Netscape / Mozilla o simplemente en cabeceras HTTP normales (estilo Set-Cookie) volcado a un archivo.

También activa el motor de cookies, haciendo que libcurl analice y envíe cookies en solicitudes posteriores con este manejador.

Al pasar una cadena vacía ("") a esta opción, activa el motor de cookies sin leer ninguna cookie inicial. Si le indica a libcurl que el nombre del archivo es "-" (solo un guion), libcurl lee desde la entrada estándar.

Esta opción solo lee cookies. Para hacer que libcurl escriba cookies en un archivo, consulte CURLOPT_COOKIEJAR(3).

Si lee cookies de un archivo de cabeceras HTTP simple y este no especifica un dominio en la línea Set-Cookie, la cookie no se envía ya que el dominio de la cookie no coincide con la URL de destino. Para abordar esto, establezca un dominio en la línea Set-Cookie (esto incluye subdominios) o, preferiblemente, use el formato Netscape.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

Si usa esta opción varias veces, agrega más archivos para leer cookies. Establecer esta opción en NULL desactiva el motor de cookies y borra la lista de archivos para leer cookies.

Las cookies se cargan desde el(los) archivo(s) especificado(s) cuando comienza la transferencia, no cuando se establece esta opción.

PREOCUPACIONES DE SEGURIDAD

Este documento mencionó anteriormente cómo especificar un archivo no existente también puede activar el motor de cookies. Si bien es cierto, desaconsejamos firmemente el uso de este método, ya que es demasiado difícil estar seguro de que los archivos permanezcan así a largo plazo.

POR OMISIÓN

NULL

PROTOCOLOS

Esta funcionalidad afecta solo a http

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    /* obtener cookies de un archivo existente */
    curl_easy_setopt(curl, CURLOPT_COOKIEFILE, "/tmp/cookies.txt");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

Formato de archivo de cookies

El formato del archivo de cookies y los conceptos generales de cookies en curl se describen en línea aquí: https://curl.se/docs/http-cookies.html

DISPONIBILIDAD

Agregado en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).
