CURLINFO_CONNECT_TIME(3)

Paquete: curl

Licencias: MIT

CURLINFO_CONNECT_TIME(3) Manual de funciones de biblioteca CURLINFO_CONNECT_TIME(3)

NOMBRE

CURLINFO_CONNECT_TIME - obtener el tiempo hasta la conexión

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONNECT_TIME, double *timep);

DESCRIPCIÓN

Pase un puntero a un double para recibir el tiempo total en segundos desde el inicio hasta que se completó la conexión con el host remoto (o proxy).

Cuando se sigue una redirección, se suman los tiempos de cada solicitud.

Consulte también la descripción general de TIEMPOS en la página del manual de curl_easy_getinfo(3).

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos compatibles

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    double connect;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_CONNECT_TIME, &connect);
      if(CURLE_OK == res) {
        printf("Tiempo: %.1f", connect);
      }
    }
    /* siempre limpiar */
    curl_easy_cleanup(curl);
  }
}

DISPONIBILIDAD

Añadido en curl 7.4.1

VALOR DE RETORNO

curl_easy_getinfo(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, consulte libcurl-errors(3).

VER TAMBIÉN
