CURLOPT_SSL_ENABLE_NPN(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSL_ENABLE_NPN(3) Manual de funciones de la biblioteca CURLOPT_SSL_ENABLE_NPN(3)

NOMBRE

CURLOPT_SSL_ENABLE_NPN - usar NPN

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_ENABLE_NPN, long npn);

DESCRIPCIÓN

Obsoleto desde la versión 7.86.0. El uso de esta opción no tiene función.

Pase un long como parámetro, 0 o 1, donde 1 es para habilitar y 0 para deshabilitar. Esta opción habilita/deshabilita NPN en el handshake SSL (si el backend SSL para el que está compilado libcurl lo soporta), lo cual puede ser usado para negociar http2.

PREDETERMINADO

1, habilitado

PROTOCOLOS

Esta funcionalidad afecta a todos los protocolos basados en TLS: HTTPS, FTPS, IMAPS, POP3S, SMTPS, etc.

Todos los backends TLS soportan esta opción.

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSL_ENABLE_NPN, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

OBSOLETO

Obsoleto desde la versión 7.86.0

DISPONIBILIDAD

Añadido en curl 7.36.0

VALOR DE RETORNO

curl_easy_setopt(3) retorna un CURLcode indicando éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica un error, ver libcurl-errors(3).

VER TAMBIÉN
