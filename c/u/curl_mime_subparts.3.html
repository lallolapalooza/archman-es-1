Paquete: curl

Licencias: MIT

curl_mime_subparts(3) Manual de funciones de la biblioteca curl_mime_subparts(3)

NOMBRE

curl_mime_subparts - establecer sub-partes de una parte mime multipart

SINOPSIS

#include <curl/curl.h>
CURLcode curl_mime_subparts(curl_mimepart *part, curl_mime *subparts);

DESCRIPCIÓN

curl_mime_subparts(3) establece el contenido de una parte mime multipart a partir de una estructura mime.

part es un manejador de la parte multipart.

subparts es un manejador de estructura mime que contiene las sub-partes. Después de que curl_mime_subparts(3) tenga éxito, el manejador de la estructura mime pertenece a la parte multipart y no debe liberarse explícitamente. Sin embargo, puede ser actualizado por llamadas posteriores a las funciones de la API mime.

Establecer el contenido de una parte varias veces es válido: solo se conservará el valor establecido por la última llamada. Es posible anular el contenido de partes anteriores estableciendo subparts a NULL.

PROTOCOLOS

Esta funcionalidad afecta a http, imap y smtp

EJEMPLO

static char *inline_html = "<title>example</title>";
static char *inline_text = "once upon the time";
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct curl_slist *slist;
    /* La parte inline es una alternativa que propone las versiones html y
       de texto del correo electrónico. */
    curl_mime *alt = curl_mime_init(curl);
    curl_mimepart *part;
    /* Mensaje HTML. */
    part = curl_mime_addpart(alt);
    curl_mime_data(part, inline_html, CURL_ZERO_TERMINATED);
    curl_mime_type(part, "text/html");
    /* Mensaje de texto. */
    part = curl_mime_addpart(alt);
    curl_mime_data(part, inline_text, CURL_ZERO_TERMINATED);
    /* Crear la parte inline. */
    part = curl_mime_addpart(alt);
    curl_mime_subparts(part, alt);
    curl_mime_type(part, "multipart/alternative");
    slist = curl_slist_append(NULL, "Content-Disposition: inline");
    curl_mime_headers(part, slist, 1);
  }
}

DISPONIBILIDAD

Añadido en curl 7.56.0

VALOR DE RETORNO

Esta función devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3). Si se estableció CURLOPT_ERRORBUFFER(3) con curl_easy_setopt(3), puede haber un mensaje de error almacenado en el búfer de error cuando se devuelve un valor distinto de cero.
