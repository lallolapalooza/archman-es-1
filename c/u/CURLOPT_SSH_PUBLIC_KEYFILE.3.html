CURLOPT_SSH_PUBLIC_KEYFILE(3)

Paquete: curl

Licencias: MIT

CURLOPT_SSH_PUBLIC_KEYFILE(3) Manual de funciones de la biblioteca CURLOPT_SSH_PUBLIC_KEYFILE(3)

NOMBRE

CURLOPT_SSH_PUBLIC_KEYFILE - archivo de clave pública para autenticación SSH

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSH_PUBLIC_KEYFILE,
                          char *filename);

DESCRIPCIÓN

Pasa un puntero a un caracter que apunta a un nombre de archivo para tu clave pública. Si no se usa, libcurl utiliza por defecto $HOME/.ssh/id_dsa.pub si la variable de entorno HOME está establecida, y solo "id_dsa.pub" en el directorio actual si HOME no está establecida.

Si se pasa NULL (o una cadena vacía) a esta opción, libcurl no pasa ninguna clave pública a la biblioteca SSH, la cual la deriva de la clave privada. Si la biblioteca SSH no puede derivar la clave pública de la privada y no se proporciona una pública, la transferencia falla.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a scp y sftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "sftp://example.com/file");
    curl_easy_setopt(curl, CURLOPT_SSH_PUBLIC_KEYFILE,
                     "/home/clarkkent/.ssh/id_rsa.pub");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

HISTORIA

El truco "" se añadió en la versión 7.26.0

DISPONIBILIDAD

Añadido en curl 7.16.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, un valor distinto de cero indica que ocurrió un error, ver libcurl-errors(3).

VER TAMBIÉN
