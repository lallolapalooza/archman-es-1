CURLOPT_RANGE(3)

Paquete: curl

Licencias: MIT

CURLOPT_RANGE(3) Manual de funciones de la biblioteca CURLOPT_RANGE(3)

NOMBRE

CURLOPT_RANGE - rango de bytes a solicitar

SINOPSIS

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RANGE, char *range);

DESCRIPCIÓN

Pase un puntero a char como parámetro, que debe contener el rango especificado que desea recuperar. Debe tener el formato "X-Y", donde se puede omitir X o Y, y X e Y son índices de bytes.

Las transferencias HTTP también admiten varios intervalos, separados por comas como en "X-Y,N-M". El uso de este tipo de intervalos múltiples hace que el servidor HTTP envíe el documento de respuesta en piezas (utilizando técnicas estándar de separación MIME) como una respuesta de múltiples partes que libcurl devuelve tal cual. Contiene metainformación además de los bytes solicitados. El análisis o cualquier otra transformación de esta respuesta es responsabilidad del llamador.

Desafortunadamente, el estándar HTTP (RFC 7233 sección 3.1) permite que los servidores ignoren las solicitudes de rango, por lo que incluso cuando configura CURLOPT_RANGE(3) para una solicitud, puede terminar recibiendo la respuesta completa.

Para RTSP, el formato de un rango debe seguir la RFC 2326 Sección 12.29. Para RTSP, los rangos de bytes no están permitidos. En su lugar, los rangos deben proporcionarse en formatos npt, utc o smpte.

Para cargas HTTP PUT, no se debe usar esta opción, ya que puede entrar en conflicto con otras opciones.

El uso de esta opción varias veces hace que la última cadena establecida anule las anteriores. Establécela en NULL para deshabilitar su uso nuevamente.

La aplicación no tiene que mantener la cadena disponible después de establecer esta opción.

PREDETERMINADO

NULL

PROTOCOLOS

Esta funcionalidad afecta a file, ftp, http, rtsp y sftp

EJEMPLO

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* obtener los primeros 200 bytes */
    curl_easy_setopt(curl, CURLOPT_RANGE, "0-199");
    /* Realizar la solicitud */
    curl_easy_perform(curl);
  }
}

HISTORIAL

FILE desde 7.18.0, RTSP desde 7.20.0

DISPONIBILIDAD

Agregado en curl 7.1

VALOR DE RETORNO

curl_easy_setopt(3) devuelve un CURLcode que indica éxito o error.

CURLE_OK (0) significa que todo estuvo bien, cualquier valor distinto de cero indica un error, consulte libcurl-errors(3).

VER TAMBIÉN

CURLOPT_LOW_SPEED_LIMIT(3), CURLOPT_MAXFILESIZE_LARGE(3), CURLOPT_MAX_RECV_SPEED_LARGE(3), CURLOPT_RESUME_FROM(3)
