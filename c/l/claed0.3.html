Documentación de Función/Subrutina

subrutina claed0 (integer qsiz, integer n, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( ldqs, * ) qstore, integer ldqs, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

CLAED0 utilizado por CSTEDC. Calcula todos los valores propios y los vectores propios correspondientes de una matriz tridiagonal simétrica no reducida utilizando el método de división y conquista.

Propósito:

!>
!> Utilizando el método de división y conquista, CLAED0 calcula todos los
!> valores propios de una matriz tridiagonal simétrica que es un bloque
!> diagonal de aquellos obtenidos al reducir una matriz hermitiana densa o
!> de banda y los vectores propios correspondientes de la matriz densa o de
!> banda.
!>

Parámetros

QSIZ 
!>          QSIZ es INTEGER
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz completa a forma tridiagonal. QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica. N >= 0.
!>

D

!>          D es un array REAL, de dimensión (N)
!>         En la entrada, los elementos diagonales de la matriz tridiagonal.
!>         En la salida, los valores propios en orden ascendente.
!>

E

!>          E es un array REAL, de dimensión (N-1)
!>         En la entrada, los elementos fuera de la diagonal de la matriz
!>         tridiagonal.
!>         En la salida, E ha sido destruido.
!>

Q

!>          Q es un array COMPLEX, de dimensión (LDQ,N)
!>         En la entrada, Q debe contener una matriz QSIZ x N cuyas
!>         columnas sean ortonormales unitariamente. Es parte de la matriz
!>         unitaria que reduce la matriz hermitiana completa densa a una
!>         matriz tridiagonal simétrica (reducible).
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q. LDQ >= max(1,N).
!>

IWORK

!>          IWORK es un array INTEGER,
!>         la dimensión de IWORK debe ser al menos
!>                      6 + 6*N + 5*N*lg N
!>                      ( lg( N ) = el entero más pequeño k
!>                                  tal que 2^k >= N )
!>

RWORK

!>          RWORK es un array REAL,
!>                               de dimensión (1 + 3*N + 2*N*lg N + 3*N**2)
!>                        ( lg( N ) = el entero más pequeño k
!>                                    tal que 2^k >= N )
!>

QSTORE

!>          QSTORE es un array COMPLEX, de dimensión (LDQS, N)
!>         Se utiliza para almacenar partes de la matriz de vectores
!>         propios cuando ocurren las multiplicaciones de la matriz de
!>         actualización.
!>

LDQS

!>          LDQS es INTEGER
!>         La dimensión principal del array QSTORE.
!>         LDQS >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: Salida exitosa.
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>
