subrutina claed0 (qsiz, n, d, e, q, ldq, qstore, ldqs, rwork, iwork, info)
CLAED0 utilizado por CSTEDC. Calcula todos los valores propios y los vectores propios correspondientes de una matriz tridiagonal simétrica no reducida utilizando el método de divide y vencerás.

Documentación de la función/subrutina

subrutina claed0 (integer qsiz, integer n, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( ldqs, * ) qstore, integer ldqs, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

CLAED0 utilizado por CSTEDC. Calcula todos los valores propios y los vectores propios correspondientes de una matriz tridiagonal simétrica no reducida utilizando el método de divide y vencerás.

Propósito:

!>
!> Usando el método de divide y vencerás, CLAED0 calcula todos los valores
!> propios de una matriz tridiagonal simétrica que es un bloque diagonal
!> de los que provienen de reducir una matriz hermítica densa o de banda y
!> los vectores propios correspondientes de la matriz densa o de banda.
!>

Parámetros

QSIZ 
!>          QSIZ es INTEGER
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz completa a forma tridiagonal.  QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es array REAL, dimension (N)
!>         En la entrada, los elementos diagonales de la matriz tridiagonal.
!>         En la salida, los valores propios en orden ascendente.
!>

E

!>          E es array REAL, dimension (N-1)
!>         En la entrada, los elementos fuera de la diagonal de la matriz
!>         tridiagonal.
!>         En la salida, E ha sido destruido.
!>

Q

!>          Q es array COMPLEX, dimension (LDQ,N)
!>         En la entrada, Q debe contener una matriz QSIZ x N cuyas columnas
!>         sean unitariamente ortonormales. Es parte de la matriz unitaria
!>         que reduce la matriz hermítica densa completa a una matriz
!>         tridiagonal simétrica (reducible).
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q.  LDQ >= max(1,N).
!>

IWORK

!>          IWORK es array INTEGER,
!>         la dimensión de IWORK debe ser al menos
!>                      6 + 6*N + 5*N*lg N
!>                      ( lg( N ) = entero más pequeño k
!>                                  tal que 2^k >= N )
!>

RWORK

!>          RWORK es array REAL,
!>                               dimension (1 + 3*N + 2*N*lg N + 3*N**2)
!>                        ( lg( N ) = entero más pequeño k
!>                                    tal que 2^k >= N )
!>

QSTORE

!>          QSTORE es array COMPLEX, dimension (LDQS, N)
!>         Se utiliza para almacenar partes de la matriz de vectores propios
!>         cuando ocurren las multiplicaciones de la matriz de actualización.
!>

LDQS

!>          LDQS es INTEGER
!>         La dimensión principal del array QSTORE.
!>         LDQS >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>
