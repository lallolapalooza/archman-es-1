NOMBRE

cleanup_digikamdb - Limpia las bases de datos de digiKam para reducir su tamaño y aumentar la velocidad de acceso

SINOPSIS


cleanup_digikamdb
[-t] [-T] [-p] [-h]

OPCIONES

-t
Incluir bases de datos de miniaturas.
-T
Solo limpiar bases de datos de miniaturas.
-p ruta
Especificar una ruta de base de datos diferente. Si esta opción no se establece o la ruta especificada no es válida, se utilizará la entrada del archivo de configuración.
-h
Mostrar opciones de línea de comandos.

DESCRIPCIÓN

cleanup_digikamdb limpiará y optimizará el archivo de base de datos de digiKam. Esto, en la mayoría de los casos, conducirá a un menor tamaño del archivo de base de datos y a una mayor velocidad de acceso, ya que se eliminan elementos innecesarios de la base de datos y se optimizan los datos.

El programa se asegurará de que no se esté ejecutando ninguna instancia de digiKam, ya que es más seguro no tener acceso a la base de datos durante el proceso de optimización. Luego leerá el archivo de configuración de digiKam y determinará la ubicación de la base de datos. En un paso final, la base de datos se optimizará invocando el comando sqlite 'VACUUM;' sobre ella. Si se encuentra más de una base de datos en esta ubicación, cleanup_digikamdb optimizará todas las bases de datos encontradas en esta ruta y por debajo.

Para obtener más explicaciones, consulte la siguiente descripción del comando VACUUM del sitio web de sqlite3:

Cuando un objeto (tabla, índice o desencadenador) se elimina de la base de datos, deja espacio libre. Este espacio libre se reutilizará la próxima vez que se agregue nueva información a la base de datos. Pero mientras tanto, el archivo de la base de datos puede ser más grande de lo estrictamente necesario. Además, las inserciones, actualizaciones y eliminaciones frecuentes pueden hacer que la información en la base de datos se fragmente, dispersándose por todo el archivo de la base de datos en lugar de agruparse en un solo lugar.

El comando VACUUM limpia la base de datos principal copiando su contenido a un archivo de base de datos temporal y recargando el archivo de base de datos original de la copia. Esto elimina las páginas libres, alinea los datos de la tabla para que sean contiguos y, de lo contrario, limpia la estructura del archivo de la base de datos.
