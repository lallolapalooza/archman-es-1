CLEVERCSV-CODE(1) Manual de Clevercsv CLEVERCSV-CODE(1)

NOMBRE

clevercsv-code - Genera código Python para importar un archivo CSV

SINOPSIS

clevercsv code [-e CODIFICACION | --encoding=CODIFICACION]
               [-n NUM_CARACTERES | --num-chars=NUM_CARACTERES] [-p | --pandas] <ruta>

DESCRIPCIÓN

Genera código Python para importar un archivo CSV dado. Esto es especialmente útil si no desea detectar repetidamente el dialecto del mismo archivo. Simplemente ejecute:

clevercsv code tu_archivo_csv.csv

y copie el código generado a un script de Python.

OPCIONES

-h, --help

muestra este mensaje de ayuda y sal

-e, --encoding

La codificación del archivo CSV se detecta automáticamente usando chardet. Aunque chardet es increíblemente preciso, no es perfecto. En los casos raros en que comete un error al detectar la codificación del archivo, puede anular la codificación proporcionándola a través de esta bandera. Además, cuando tenga una serie de archivos CSV con una codificación de archivo conocida, puede utilizar esta opción para acelerar el proceso de generación de código.

-n, --num-chars

En archivos CSV grandes, la detección de dialectos a veces puede ser un poco lenta debido a la gran cantidad de dialectos posibles a considerar. Para aliviar esto, puede limitar el número de caracteres a utilizar para la detección.

Un aspecto a tener en cuenta es que CleverCSV puede necesitar leer un número específico de caracteres para poder inferir correctamente el dialecto. Por ejemplo, en el archivo ``imdb.csv`` del repositorio de GitHub, el dialecto correcto solo se puede encontrar después de leer al menos 66 líneas del archivo. Por lo tanto, si hay disponibilidad para ejecutar CleverCSV en el archivo completo, generalmente se recomienda.

-p, --pandas

Por defecto, este comando escribe un pequeño script de Python para importar el archivo CSV como una lista de listas. Al habilitar esta opción, el script se escribirá de manera que el archivo se lea como un DataFrame de Pandas en su lugar.

<ruta>

Ruta al archivo CSV
