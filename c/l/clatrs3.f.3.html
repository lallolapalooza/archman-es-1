subrutina clatrs3 (uplo, trans, diag, normin, n, nrhs, a, lda, x, ldx, scale, cnorm, work, lwork, info)
CLATRS3 resuelve un sistema de ecuaciones triangulares con los factores de escala establecidos para evitar desbordamientos.

Documentación de la Función/Subrutina

subrutina clatrs3 (carácter uplo, carácter trans, carácter diag, carácter normin, entero n, entero nrhs, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldx, * ) x, entero ldx, real, dimensión( * ) scale, real, dimensión( * ) cnorm, real, dimensión( * ) work, entero lwork, entero info)

CLATRS3 resuelve un sistema de ecuaciones triangulares con los factores de escala establecidos para evitar desbordamientos.

Propósito:

!>
!> CLATRS3 resuelve uno de los sistemas triangulares
!>
!>    A * X = B * diag(scale),  A**T * X = B * diag(scale), o
!>    A**H * X = B * diag(scale)
!>
!> con escalado para prevenir desbordamientos. Aquí A es una matriz triangular
!> superior o inferior, A**T denota la transpuesta de A, A**H denota la
!> transpuesta conjugada de A. X y B son matrices n-por-nrhs y scale
!> es un vector de nrhs elementos de factores de escala. Un factor de escala scale(j)
!> es usualmente menor o igual a 1, elegido de tal manera que X(:,j) sea menor
!> que el umbral de desbordamiento. Si la matriz A es singular (A(j,j) = 0
!> para algún j), entonces se devuelve una solución no trivial a A*X = 0. Si
!> el sistema está tan mal escalado que la solución no puede ser representada
!> como (1/scale(k))*X(:,k), entonces x(:,k) = 0 y se devuelve scale(k).
!>
!> Esta es una versión BLAS-3 de LATRS para resolver varios lados derechos
!> simultáneamente.
!>
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b  (Sin transpuesta)
!>          = 'T':  Resolver A**T* x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**T* x = s*b  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM se ha establecido o no.
!>          = 'Y':  CNORM contiene las normas de las columnas en la entrada
!>          = 'N':  CNORM no se establece en la entrada. En la salida, las normas se
!>                  calcularán y se almacenarán en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de X.  NRHS >= 0.
!>

A

!>          A es array COMPLEJO, dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte superior triangular
!>          de n por n de la matriz A contiene la matriz triangular superior, y la
!>          parte estrictamente triangular inferior de A no se referencia. Si UPLO = 'L',
!>          la parte inferior triangular de n por n de la matriz A contiene la matriz
!>          triangular inferior, y la parte estrictamente triangular superior de A no se
!>          referencia. Si DIAG = 'U', los elementos diagonales de A tampoco se
!>          referencian y se asumen que son 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max (1,N).
!>

X

!>          X es array COMPLEJO, dimensión (LDX,NRHS)
!>          En la entrada, el lado derecho B del sistema triangular.
!>          En la salida, X se sobrescribe con la matriz de solución X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max (1,N).
!>

SCALE

!>          SCALE es array REAL, dimensión (NRHS)
!>          El factor de escala s(k) es para el sistema triangular
!>          A * x(:,k) = s(k)*b(:,k)  o  A**T* x(:,k) = s(k)*b(:,k).
!>          Si SCALE = 0, la matriz A es singular o está mal escalada.
!>          Si se encuentra A(j,j) = 0, se devuelve un vector no trivial x(:,k)
!>          que es una solución exacta o aproximada a A*x(:,k) = 0. Si el sistema
!>          está tan mal escalado que la solución no puede presentarse como x(:,k) * 1/s(k),
!>          entonces se devuelve x(:,k) = 0.
!>

CNORM

!>          CNORM es array REAL, dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte fuera de la diagonal de la j-ésima columna
!>          de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual a la norma del
!>          infinito, y si TRANS = 'T' o 'C', CNORM(j) debe ser mayor o igual a la
!>          norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte fuera de la diagonal de la j-ésima columna
!>          de A.
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el tamaño óptimo de
!>          WORK.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>
!>          Si MIN(N,NRHS) = 0, LWORK >= 1, de lo contrario
!>          LWORK >= MAX(1, 2*NBA * MAX(NBA, MIN(NRHS, 32)), donde
!>          NBA = (N + NB - 1)/NB y NB es el tamaño óptimo del bloque.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula las dimensiones óptimas del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>
