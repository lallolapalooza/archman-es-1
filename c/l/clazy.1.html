NOMBRE

clazy - un analizador estático de código fuente para C++ basado en Qt5.

SINOPSIS

clazy [opción] [opciones-de-clang++]

DESCRIPCIÓN

clazy escanea el código fuente C++/Qt buscando problemas relacionados con las buenas prácticas de codificación de Qt5. En el uso típico, durante la compilación del código con clazy verás estas advertencias impresas en la salida normalmente como encontrarías cualquier advertencia del compilador.

clazy tiene la capacidad de "arreglar" el código ofensivo en algunos casos. Consulta la CLAZY_FIXIT descripción de la variable de entorno a continuación para más información.

OPCIONES

--help
Imprime el mensaje de ayuda y sale.
--version
Imprime la información de la versión y sale.
--list
Imprime una lista de todos los verificadores disponibles, ordenados por nivel.
--explain
Imprime explicaciones para todos los verificadores.
--explain <expresión-regular>
Imprime explicaciones para los verificadores que coincidan con la expresión regular especificada.

Cualquiera de las opciones anteriores imprimirá la información solicitada y luego saldrá.

--qtdeveloper
Solo para desarrolladores de Qt. Esta opción es especial para ejecutar clazy en el propio Qt. Resultará en que se reporten menos falsos positivos en el código de Qt.

Esta es una opción de conveniencia que es idéntica a pasar directamente:
"-Xclang -plugin-arg-clazy -Xclang qt-developer"

Todas las demás opciones se pasan directamente a clang++ y se manejan desde allí.

Consulta el manual de clang para una lista del muy amplio conjunto de opciones disponibles, pero en la operación normal "compilas" tu código con clazy tal como lo harías con clang.

EJEMPLOS

Imprime una lista de todos los verificadores disponibles, ordenados por nivel de verificación:
% clazy --list
Lista de verificadores de clazy disponibles:
Verificaciones del nivel0. Verificaciones muy estables, 100% seguras, sin falsos positivos:
   connect-non-signal
   container-anti-pattern
   lambda-in-connect
   mutable-container-key
   qdatetime-utc
   qenums
   qfileinfo-exists
 ....
Compila tu proyecto CMake con los verificadores predeterminados de clazy:
% cmake -DCMAKE_CXX_COMPILER=clazy <otras_opciones_de_cmake>
luego ejecuta make como de costumbre
Compila tu proyecto CMake solo con las verificaciones del nivel2 (no-Windows):
% export CLAZY_CHECKS="level2"
% cmake -DCMAKE_CXX_COMPILER=clazy <otras_opciones_de_cmake>
luego ejecuta make como de costumbre
Compila tu proyecto qmake con los verificadores predeterminados de clazy:
% qmake -spec linux-clang QMAKE_CXX=clazy <otras_opciones_de_qmake>
luego ejecuta make como de costumbre

DIRECTIVAS EN EL CÓDIGO

clazy soporta la siguiente lista de directivas en el código:

clazy:skip
Exime un archivo completo de todas las verificaciones.
No se ejecutarán pruebas de clazy en el archivo.
clazy:excludeall=<nombre1[,nombre2,...,nombreN]>
Exime el archivo completo de las verificaciones especificadas.
Las verificaciones de clazy nombre1, etc. no se ejecutarán en este archivo.
clazy:exclude=<nombre1[,nombre2,...,nombreN]>
Excluye líneas individuales de verificaciones específicas.
Las pruebas de las verificaciones de clazy nombre1, etc. no se ejecutarán en la línea donde
se encuentre esta directiva.
clazy:exclude-next-line=<nombre1[,nombre2,...,nombreN]>
Excluye las verificaciones de clazy dadas de la siguiente línea.

No incluyas el prefijo 'clazy-'. Por ejemplo, para desactivar la verificación "qstring-allocations", escribirías:

// clazy:exclude=qstring-allocations

y no

// clazy:exclude=clazy-qstring-allocations

Ten en cuenta también que estas directivas deben ser comentarios de estilo C++; los comentarios de estilo C se ignoran.

ENTORNO

CLAZY_CHECKS - una lista separada por comas de verificadores o conjuntos de verificaciones a ejecutar. Por defecto, se ejecutarán todos los verificadores de los conjuntos de verificaciones "level0" y "level1".

Ejemplos:

1. Habilita solo los 2 verificadores "unneeded-cast" y "virtual-call-ctor":
% export CLAZY_CHECKS="unneeded-cast,virtual-call-ctor"
2. Habilita todas las verificaciones del conjunto de verificaciones "level0", excepto "qenums":
% export CLAZY_CHECKS="level0,no-qenums"
3. Habilita todas las verificaciones del conjunto de verificaciones "level0" junto con el verificador "detaching-temporary":
% export CLAZY_CHECKS="level0,detaching-temporary"

CLAZY_FIXIT - algunos verificadores pueden reescribir automáticamente tu código fuente siempre que encuentren código que puedan "arreglar". Habilita esta característica de "fixit" estableciendo esta variable en el nombre del verificador con la capacidad de "fixit".

Ejemplos:

1. Arregla las asignaciones de qlatin1string:
% export CLAZY_FIXIT="fix-qlatin1string-allocations"
2. Arregla las sentencias connect de estilo antiguo (casos simples):
% export CLAZY_FIXIT=fix-old-style-connect

Se proporciona más documentación al ejecutar clazy con la --explain opción de la línea de comandos.

Ten en cuenta también que solo se puede ejecutar 1 verificador de fixit a la vez.

CLAZY_EXTRA_OPTIONS - algunos verificadores pueden adaptar su comportamiento dependiendo del valor de esta variable de entorno. Se proporciona más documentación al ejecutar clazy con la --explain opción de la línea de comandos.

CLAZY_NO_WERROR - si esta variable está establecida, clazy no tratará las advertencias como errores, incluso si se especifica la opción del compilador -Werror. Esto es útil si quieres usar -Werror solo para las advertencias regulares de gcc/clang pero no para las advertencias de clazy.

CLAZY_CHECKS_AS_ERRORS - lista separada por comas de verificaciones que serán promovidas a errores del compilador. Ten en cuenta que esto no habilita las verificaciones especificadas aquí.

CLAZY_IGNORE_DIRS - Una expresión regular para rutas a excluir del procesamiento. Por ejemplo:

% export CLAZY_IGNORE_DIRS=".*my_qt_folder.*"
