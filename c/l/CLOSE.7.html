CLOSE(7) Documentación de PostgreSQL 18.1 CLOSE(7)

NOMBRE

CLOSE - cerrar un cursor

SINOPSIS

CLOSE { nombre | ALL }

DESCRIPCIÓN

CLOSE libera los recursos asociados con un cursor abierto. Después de que el cursor se cierra, no se permiten operaciones posteriores sobre él. Un cursor debe cerrarse cuando ya no sea necesario.

Todos los cursores abiertos no retenidos se cierran implícitamente cuando una transacción termina con COMMIT o ROLLBACK. Un cursor retenido se cierra implícitamente si la transacción que lo creó aborta mediante ROLLBACK. Si la transacción creadora confirma con éxito, el cursor retenido permanece abierto hasta que se ejecuta un CLOSE explícito, o el cliente se desconecta.

PARÁMETROS

nombre

El nombre de un cursor abierto a cerrar.

ALL

Cerrar todos los cursores abiertos.

NOTAS

PostgreSQL no tiene una declaración OPEN de cursor explícita; un cursor se considera abierto cuando se declara. Utilice la declaración DECLARE para declarar un cursor.

Puede ver todos los cursores disponibles consultando la vista del sistema pg_cursors.

Si un cursor se cierra después de un punto de guardado que luego se deshace, el CLOSE no se deshará; es decir, el cursor permanece cerrado.

EJEMPLOS

Cerrar el cursor liahona:

CLOSE liahona;

COMPATIBILIDAD

CLOSE cumple completamente con el estándar SQL. CLOSE ALL es una extensión de PostgreSQL.
