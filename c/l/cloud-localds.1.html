NOMBRE

cloud-localds - crea un disco para que cloud-init lo utilice nocloud

SINOPSIS

cloud-localds [opciones] salida datos-usuario [datos-meta]

DESCRIPCIÓN

cloud-localds crea una imagen de disco con datos-usuario y/o datos-meta para cloud-init(1). los datos-usuario pueden contener todo lo que es compatible con cloud-init(1)

OPCIONES

-d, --disk_format=FORMATO-DISCO
Formato de disco a generar. Consulte qemu-img(1) para ver los formatos de disco permitidos. El valor predeterminado es raw.
-f, --filesystem=FORMATO
Formato del sistema de archivos. Los formatos permitidos son vfat e iso. El valor predeterminado es iso9660.
-h, --help
Mostrar uso.
-i, --interfaces
Escribir el archivo de interfaces de red en los datos-meta.
-m, --dsmode=MODO
Añadir dsmode a los datos-meta. Los valores permitidos son local o net. El valor predeterminado en cloud-init(1) es net.

EJEMPLOS

Este ejemplo crea una imagen de disco con datos-usuario que se puede utilizar para iniciar una imagen en la nube que soporte cloud-init(1).

Crear algunos datos-usuario:
cat > my-user-data <<EOF
password: passw0rd
chpasswd: { expire: False }
ssh_pwauth: True
EOF
Crear la imagen de disco que contiene los datos-usuario:
cloud-localds my-seed.img my-user-data
Arrancar la imagen en la nube:
qemu -net nic -net user -hda cloud-image.img -hdb my-seed.img -m 512

cloud-image.img es una imagen que soporta cloud-init(1) durante el proceso de arranque.

VER TAMBIÉN

cloud-init(1), qemu-img(1), qemu(1)
