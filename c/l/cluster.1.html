NOMBRE

cluster - encuentra clústeres en un grafo y aumenta el grafo con esta información.

SINOPSIS

cluster [-v?] [ -Ck ] [ -ck ] [ -o archivo_salida ] [ archivos ]

DESCRIPCIÓN

cluster toma como entrada un grafo en formato DOT, encuentra clústeres de nodos y aumenta el grafo con esta información. Los clústeres se especifican mediante el atributo "cluster" adjunto a los nodos; los valores de clúster son enteros no negativos. cluster intenta maximizar la modularidad del agrupamiento. Si se define el atributo de arista "weight", se usará para calcular el agrupamiento.

OPCIONES

Se admiten las siguientes opciones:

-Ck
especifica un número objetivo de clústeres que deben generarse. El número especificado k es solo una sugerencia y puede que no sea realizable. Si k == 0, que es el valor predeterminado, se devuelve el número de clústeres que optimiza aproximadamente la modularidad.
-ck
especifica el método de agrupamiento. Si k == 0, el valor predeterminado, se utilizará el agrupamiento por modularidad. Si k == 1 se utilizará la calidad de modularidad.
-oarchivo_salida
Especifica que la salida debe ir al archivo archivo_salida. Por defecto, se utiliza stdout.
-v
Modo detallado.
-?
Imprime el uso y sale.

EJEMPLOS

Aplicar cluster al siguiente grafo,

   graph {
       1--2 [weight=10.]
       2--3 [weight=1]
       3--4 [weight=10.]
       4--5 [weight=10]
       5--6 [weight=10]
       3--6 [weight=0.1]
       4--6 [weight=10.]
      }

produce

   graph {
         node [cluster="-1"];
         1 [cluster=1];
         2 [cluster=1];
         3 [cluster=2];
         4 [cluster=2];
         5 [cluster=2];
         6 [cluster=2];
         1 -- 2 [weight="10."];
         2 -- 3 [weight=1];
         3 -- 4 [weight="10."];
         4 -- 5 [weight=10];
         5 -- 6 [weight=10];
         3 -- 6 [weight="0.1"];
         4 -- 6 [weight="10."];
   }
