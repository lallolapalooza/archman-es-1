subroutine clarz (character side, integer m, integer n, integer l, complex, dimension( * ) v, integer incv, complex tau, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work)

CLARZ aplica un reflector elemental (como el devuelto por stzrzf) a una matriz general.

Propósito:

!>
!> CLARZ aplica un reflector elemental complejo H a una matriz compleja
!> M por N, C, desde la izquierda o la derecha. H se representa
!> en la forma
!>
!>       H = I - tau * v * v**H
!>
!> donde tau es un escalar complejo y v es un vector complejo.
!>
!> Si tau = 0, entonces H se toma como la matriz unidad.
!>
!> Para aplicar H**H (la transpuesta conjugada de H), suminístrese conjg(tau) en lugar de
!> tau.
!>
!> H es un producto de k reflectores elementales según lo devuelto por CTZRZF.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': forma  H * C
!>          = 'R': forma  C * H
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

L

!>          L es INTEGER
!>          El número de entradas del vector V que contienen
!>          la parte significativa de los vectores de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

V

!>          V es un array COMPLEX, de dimensión (1+(L-1)*abs(INCV))
!>          El vector v en la representación de H según lo devuelto por
!>          CTZRZF. V no se utiliza si TAU = 0.
!>

INCV

!>          INCV es INTEGER
!>          El incremento entre elementos de v. INCV <> 0.
!>

TAU

!>          TAU es COMPLEX
!>          El valor tau en la representación de H.
!>

C

!>          C es un array COMPLEX, de dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
!>          o C * H si SIDE = 'R'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, de dimensión
!>                         (N) si SIDE = 'L'
!>                      o (M) si SIDE = 'R'
!>
