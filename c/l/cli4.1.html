CLI4(1) Manual de Comandos Generales CLI4(1)

NOMBRE

cli4 - Acceso por línea de comandos a la API v4 de Cloudflare

SINOPSIS

cli4 [-V|--version] [-h|--help] [-v|--verbose] [-q|--quiet] [-j|--json] [-y|--yaml] [-n|--ndjson] [-r|--raw] [-d|--dump] [-p perfil-nombre|--profile perfil-nombre] [item=valor ...] [item=@nombre-archivo ...] [-G|--get] [-P|--patch] [-O|--post] [-U|--put] [-D|--delete] /comando...

DESCRIPCIÓN

cli4 proporciona acceso por línea de comandos a la API v4 de Cloudflare

OPCIONES

[-V, --version]
Muestra el número de versión del programa y sale.
[-h, --help]
Esta información (en forma sucinta).
[-v, --verbose]
Proporciona información de depuración del protocolo.
[-q, --quiet]
No genera ninguna respuesta JSON/YAML.
[-j, --json]
Genera los datos de respuesta en formato JSON (el predeterminado).
[-y, --yaml]
Genera los datos de respuesta en formato YAML (si el paquete yaml está instalado).
[-n, --ndjson]
Genera los datos de respuesta en formato NDJSON (si el paquete jsonlines está instalado).
[-r, --raw]
Genera los resultados JSON en modo crudo sin separar los errores y los resultados.
[-d, --dump]
Genera una lista de todas las llamadas a la API incluidas en el código.
[-p nombre-perfil, --profile nombre-perfil]
Selecciona un nombre-perfil del archivo de configuración (por lo tanto, selecciona valores personalizados de correo electrónico/token).
--get
Envía la solicitud HTTP como un GET (el predeterminado).
--patch
Envía la solicitud HTTP como un PATCH.
--post
Envía la solicitud HTTP como un POST.
--put
Envía la solicitud HTTP como un PUT.
--delete
Envía la solicitud HTTP como un DELETE.
item=valor
Establece un parámetro o valor de datos para enviar con un comando GET, PATCH, POST, PUT o DELETE. El valor se envía como una cadena.
item:=valor
Establece un parámetro o valor de datos para enviar con un comando GET, PATCH, POST, PUT o DELETE. El valor se envía como un entero.
item=@nombre-archivo
Establece un parámetro o valor de datos para enviar con un comando POST o PUT. El valor se basa en el contenido del archivo.
/comando ...
El comando o comandos de la API a ejecutar.

COMANDO(S)

La cadena de comandos utiliza la barra (/) para separar los verbos de la misma manera que lo hace la documentación de la API v4 de Cloudflare. Cualquier verbo que comience con dos puntos (:) se convierte en zone_id, user_id, organtization_id o de otra manera. Cualquier verbo que comience con dos dos puntos (::) se pasa sin procesar.

RESULTADOS

La salida tiene formato JSON o YAML.

EJEMPLOS

cli4 /zones Lista información para todas las zonas.

cli4 /zones/:example.com Lista información específica de una zona.

cli4 /zones/:example.com/settings Lista la configuración de una zona específica.

cli4 --delete purge_everything=true /zones/:example.com/purge_cache Purgar la caché de una zona específica.

cli4 --delete files='[http://example.com/css/styles.css]' /zones/:example.com/purge_cache Purgar la caché de una zona específica.

cli4 --delete files='[http://example.com/css/styles.css,http://example.com/js/script.js]' /zones/:example.com/purge_cache Purgar la caché de una zona específica.

cli4 --delete tags='[tag1,tag2,tag3]' /zones/:example.com/purge_cache Purgar la caché de una zona específica.

cli4 /zones/:example.com/available_plans Lista los planes disponibles para una zona.

cli4 --patch status=active /zones/:example.com/dnssec Activar DNSSEC para una zona específica.

cli4 /zones/:example.com/dnssec Lista información y estado de DNSSEC para una zona específica.

VER TAMBIÉN

La API de Cloudflare se puede encontrar en https://api.cloudflare.com/. Cada llamada a la API se proporciona a través de una función con nombre similar dentro de la clase Cloudflare.
