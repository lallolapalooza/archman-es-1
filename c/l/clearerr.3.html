ferror(3) Manual de Funciones de Biblioteca ferror(3)

NOMBRE

clearerr, feof, ferror - comprobar y restablecer el estado del flujo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
void clearerr(FILE *stream);
int feof(FILE *stream);
int ferror(FILE *stream);

DESCRIPCIÓN

La función clearerr() borra los indicadores de fin de archivo y de error para el flujo apuntado por stream.

La función feof() comprueba el indicador de fin de archivo para el flujo apuntado por stream, devolviendo un valor distinto de cero si está activado. El indicador de fin de archivo solo puede borrarse mediante la función clearerr().

La función ferror() comprueba el indicador de error para el flujo apuntado por stream, devolviendo un valor distinto de cero si está activado. El indicador de error solo puede restablecerse mediante la función clearerr().

Para las contrapartes no bloqueantes, consulte unlocked_stdio(3).

VALOR DE RETORNO

La función feof() devuelve un valor distinto de cero si el indicador de fin de archivo está activado para stream; de lo contrario, devuelve cero.

La función ferror() devuelve un valor distinto de cero si el indicador de error está activado para stream; de lo contrario, devuelve cero.

ERRORES

Estas funciones no deberían fallar y no establecen errno.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
clearerr (), feof (), ferror () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C89, POSIX.1-2001.

NOTAS

POSIX.1-2008 especifica que estas funciones no cambiarán el valor de errno si stream es válido.

ADVERTENCIAS

Normalmente, los programas deberían leer el valor de retorno de una función de entrada, como fgetc(3), antes de utilizar las funciones de la familia de feof(3). Solo cuando la función devuelve el valor centinela EOF tiene sentido distinguir entre el fin de un archivo o un error con feof(3) o ferror(3).

VER TAMBIÉN

open(2), fdopen(3), fileno(3), stdio(3), unlocked_stdio(3)
