Funciones/Subrutinas


función real clangt (norm, n, dl, d, du)


CLANGT devuelve el valor de la 1-norma, norma de Frobenius, infinito-norma o el valor absoluto más grande de cualquier elemento de una matriz tridiagonal general.

Documentación de función/subrutina

función real clangt (carácter norm, entero n, complejo, dimensión( * ) dl, complejo, dimensión( * ) d, complejo, dimensión( * ) du)

CLANGT devuelve el valor de la 1-norma, norma de Frobenius, infinito-norma o el elemento de mayor valor absoluto de una matriz tridiagonal compleja.

Propósito:

!>
!> CLANGT  devuelve el valor de la uno-norma, o la norma de Frobenius, o
!> la  infinito-norma,  o el  elemento de  mayor valor absoluto  de una
!> matriz tridiagonal compleja A.
!>

Retorna

CLANGT 
!>
!>    CLANGT = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  uno-norma de una matriz (suma máxima de columna),
!> normI  denota la  infinito-norma  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a ser devuelto en CLANGT como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANGT se
!>          establece a cero.
!>

DL

!>          DL es array COMPLEX, dimensión (N-1)
!>          Los elementos sub-diagonales (n-1) de A.
!>

D

!>          D es array COMPLEX, dimensión (N)
!>          Los elementos diagonales de A.
!>

DU

!>          DU es array COMPLEX, dimensión (N-1)
!>          Los elementos super-diagonales (n-1) de A.
!>
