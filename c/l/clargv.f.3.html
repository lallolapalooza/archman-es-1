Documentación de función/subrutina

subrutina clargv (integer n, complex, dimension( * ) x, integer incx, complex, dimension( * ) y, integer incy, real, dimension( * ) c, integer incc)

CLARGV genera un vector de rotaciones de plano con cosenos reales y senos complejos.

Propósito:

!>
!> CLARGV genera un vector de rotaciones de plano complejas con cosenos
!> reales, determinados por los elementos de los vectores complejos x e y.
!> Para i = 1,2,...,n
!>
!>    (        c(i)   s(i) ) ( x(i) ) = ( r(i) )
!>    ( -conjg(s(i))  c(i) ) ( y(i) ) = (   0  )
!>
!>    donde c(i)**2 + ABS(s(i))**2 = 1
!>
!> Se utilizan las siguientes convenciones (estas son las mismas que en CLARTG,
!> pero difieren de la rutina BLAS1 CROTG):
!>    Si y(i)=0, entonces c(i)=1 y s(i)=0.
!>    Si x(i)=0, entonces c(i)=0 y s(i) se elige de modo que r(i) sea real.
!>

Parámetros

N 
!>          N es un ENTERO
!>          El número de rotaciones de plano a generar.
!>

X

!>          X es un array COMPLEJO, de dimensión (1+(N-1)*INCX)
!>          En la entrada, el vector x.
!>          En la salida, x(i) se sobrescribe con r(i), para i = 1,...,n.
!>

INCX

!>          INCX es un ENTERO
!>          El incremento entre los elementos de X. INCX > 0.
!>

Y

!>          Y es un array COMPLEJO, de dimensión (1+(N-1)*INCY)
!>          En la entrada, el vector y.
!>          En la salida, los senos de las rotaciones de plano.
!>

INCY

!>          INCY es un ENTERO
!>          El incremento entre los elementos de Y. INCY > 0.
!>

C

!>          C es un array REAL, de dimensión (1+(N-1)*INCC)
!>          Los cosenos de las rotaciones de plano.
!>

INCC

!>          INCC es un ENTERO
!>          El incremento entre los elementos de C. INCC > 0.
!>
