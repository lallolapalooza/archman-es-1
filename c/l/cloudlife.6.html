NOMBRE

cloudlife - un autómata celular basado en el Juego de la Vida de Conway

SINOPSIS

cloudlife [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--ncolors entero] [--cycle-delay microsegundos] [--cycle-colors entero][--cell-size entero] [--initial-density entero] [--max-age entero]

[--fps]

DESCRIPCIÓN

El programa cloudlife dibuja un autómata celular basado en el Juego de la Vida de Conway, excepto que las celdas tienen una edad máxima y solo se dibuja un píxel por celda en cada tick.

OPCIONES

cloudlife acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si se está en una pantalla a color, simula estar en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--cycle-delay entero
Tiempo en microsegundos para esperar entre ticks. Por defecto 25000.
--cycle-colors entero
Cuántos ticks deben transcurrir entre ciclos de colores. 0 para deshabilitar el ciclo de colores. Por defecto 2.
--ncolors entero
Cuántos colores se deben usar (si es posible). Por defecto 64. Los colores se eligen aleatoriamente.
--cell-size entero
Tamaño de cada celda, en potencias de 2. Por defecto 3 (celdas de 8 píxeles).
--initial-density entero
Porcentaje de celdas que están vivas al inicio y cuando el campo se repopula. Por defecto 30.
--max-age entero
Edad máxima para una celda. Por defecto 64.
--fps
Muestra la tasa de fotogramas actual y la carga de CPU.

AMBIENTE

DISPLAY
para obtener el host y número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
