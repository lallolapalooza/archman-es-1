NOMBRE

Class::Accessor::Chained::Fast - creador de accesores encadenados más rápido, pero menos expandible

SINOPSIS

package Foo;
use base qw(Class::Accessor::Chained::Fast);
 # El resto como Class::Accessor::Chained, excepto que no hay set() ni get().

DESCRIPCIÓN

Por analogía con Class::Accessor y Class::Accessor::Fast, este módulo proporciona un creador de accesores encadenados más rápido y menos flexible.
