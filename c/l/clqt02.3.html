Documentación de Función/Subrutina

subroutine clqt02 (integer m, integer n, integer k, complex, dimension( lda, * ) a, complex, dimension( lda, * ) af, complex, dimension( lda, * ) q, complex, dimension( lda, * ) l, integer lda, complex, dimension( * ) tau, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

CLQT02

Propósito:

!>
!> CLQT02 prueba CUNGLQ, que genera una matriz m-por-n Q con
!> filas ortonormales definida como el producto de k reflectores
!> elementales.
!>
!> Dada la factorización LQ de una matriz m-por-n A, CLQT02 genera
!> la matriz ortogonal Q definida por la factorización de las primeras k
!> filas de A; compara L(1:k,1:m) con A(1:k,1:n)*Q(1:m,1:n)', y
!> comprueba que las filas de Q son ortonormales.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q a generar.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q a generar.
!>          N >= M >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          La matriz m-por-n A que fue factorizada por CLQT01.
!>

AF

!>          AF es array COMPLEX, dimensión (LDA,N)
!>          Detalles de la factorización LQ de A, como devuelve CGELQF.
!>          Ver CGELQF para más detalles.
!>

Q

!>          Q es array COMPLEX, dimensión (LDA,N)
!>

L

!>          L es array COMPLEX, dimensión (LDA,M)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A, AF, Q y L. LDA >= N.
!>

TAU

!>          TAU es array COMPLEX, dimensión (M)
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización LQ en AF.
!>

WORK

!>          WORK es array COMPLEX, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es array REAL, dimensión (M)
!>

RESULT

!>          RESULT es array REAL, dimensión (2)
!>          Las razones de prueba:
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
