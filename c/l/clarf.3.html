SINOPSIS

Funciones/Subrutinas


subrutina clarf (side, m, n, v, incv, tau, c, ldc, work)
CLARF aplica un reflector elemental a una matriz rectangular general.

Documentación de función/subrutina

subrutina clarf (carácter side, entero m, entero n, complejo, dimensión( * ) v, entero incv, complejo tau, complejo, dimensión( ldc, * ) c, entero ldc, complejo, dimensión( * ) work)

CLARF aplica un reflector elemental complejo a una matriz compleja C de M por N, desde la izquierda o desde la derecha. H se representa en la forma

       H = I - tau * v * v**H

donde tau es un escalar complejo y v es un vector complejo.

Si tau = 0, entonces H se considera la matriz identidad.

Para aplicar H**H (la transpuesta conjugada de H), proporcione conjg(tau) en lugar de tau.

Parámetros

SIDE 
          SIDE es CHARACTER*1
          = 'L': forma  H * C
          = 'R': forma  C * H

M

          M es INTEGER
          El número de filas de la matriz C.

N

          N es INTEGER
          El número de columnas de la matriz C.

V

          V es un array COMPLEX, dimensión
                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
                  o (1 + (N-1)*abs(INCV)) si SIDE = 'R'
          El vector v en la representación de H. V no se utiliza si
          TAU = 0.

INCV

          INCV es INTEGER
          El incremento entre elementos de v. INCV <> 0.

TAU

          TAU es COMPLEX
          El valor tau en la representación de H.

C

          C es un array COMPLEX, dimensión (LDC,N)
          En la entrada, la matriz C de M por N.
          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
          o C * H si SIDE = 'R'.

LDC

          LDC es INTEGER
          La dimensión principal del array C. LDC >= max(1,M).

WORK

          WORK es un array COMPLEX, dimensión
                         (N) si SIDE = 'L'
                      o (M) si SIDE = 'R'
