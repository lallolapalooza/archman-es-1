Documentación de la función/subrutina

subroutine clatmt (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, real, dimension( * ) d, integer mode, real cond, real dmax, integer rank, integer kl, integer ku, character pack, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) work, integer info)

CLATMT

Propósito:

!>
!>    CLATMT genera matrices aleatorias con valores singulares especificados
!>    (o hermíticas con valores propios especificados)
!>    para probar programas LAPACK.
!>
!>    CLATMT opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establecer la diagonal a D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Generar una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Generar una matriz densa M x N multiplicando D a la izquierda
!>              y a la derecha por matrices unitarias aleatorias, luego:
!&>
!>          Reducir el ancho de banda según KL y KU, usando
!>              transformaciones de Householder.
!>
!>      Método B:
!>          Convertir la matriz de ancho de banda 0 (es decir, diagonal) a una
!>              matriz de ancho de banda 1 usando rotaciones de Givens,
!>              elementos fuera de banda hacia atrás, de manera similar a QR; luego convertir
!>              el ancho de banda 1 a una matriz de ancho de banda 2, etc. Tenga en cuenta
!>              que para anchos de banda razonablemente pequeños (en relación con M y
!>              N) esto requiere menos almacenamiento, ya que no se genera una matriz densa.
!>              Además, para matrices hermíticas o simétricas,
!>              solo se genera un triángulo.
!>
!>      Se elige el Método A si el ancho de banda es una fracción grande del
!>          orden de la matriz, y LDA es al menos M (por lo que se puede almacenar
!>          una matriz densa). Se elige el Método B si el ancho de banda
!>          es pequeño (< 1/2 N para hermíticas o simétricas, < .3 N+M para
!>          no simétricas), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es hermítica)
!>         poner a cero la mitad inferior (si es hermítica)
!>         almacenar la mitad superior columna por columna (si es hermítica o superior
!>               triangular)
!>         almacenar la mitad inferior columna por columna (si es hermítica o inferior
!>               triangular)
!>         almacenar el triángulo inferior en formato de banda (si es hermítica o
!>               triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es hermítica o
!>               triangular superior)
!>         almacenar toda la matriz en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en formato de banda, por lo que no será necesario volver a empaquetar.
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de A. No se modifica.
!>

N

!>          N es INTEGER
!>           El número de columnas de A. N debe ser igual a M si la matriz
!>           es simétrica o hermítica (es decir, si SYM no es 'N')
!>           No se modifica.
!>

DIST

!>          DIST es CHARACTER*1
!>           A la entrada, DIST especifica el tipo de distribución que se utilizará
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORME( 0, 1 )  ('U' para uniforme)
!>           'S' => UNIFORME( -1, 1 ) ('S' para simétrica)
!>           'N' => NORMAL( 0, 1 )   ('N' para normal)
!>           No se modifica.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión ( 4 )
!>           A la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros pequeños,
!>           por lo que debería producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se modifican al salir, y pueden usarse en la siguiente llamada
!>           a CLATMT para continuar la misma secuencia de números aleatorios.
!>           Modificado al salir.
!>

SYM

!>          SYM es CHARACTER*1
!>           Si SYM='H', la matriz generada es hermítica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es hermítica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada es no simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           Si SYM='S', la matriz generada es (compleja) simétrica,
!>             con valores singulares especificados por D, COND, MODE y
!>             DMAX; no serán negativos.
!>           No se modifica.
!>

D

!>          D es un array REAL, dimensión ( MIN( M, N ) )
!>           Este array se utiliza para especificar los valores singulares o
!>           valores propios de A (ver SYM, arriba). Si MODE=0, entonces D
!>           se asume que contiene los valores singulares/propios, de lo contrario
!>           se calcularán según MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es INTEGER
!>           A la entrada describe cómo se especificarán los valores singulares/propios:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:RANK)=1.0/COND
!>           MODE = 2 establece D(1:RANK-1)=1 y D(RANK)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(RANK-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           Si SYM='H', y MODE no es 0, 6 ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo aleatorio (es decir, +1 o -1).
!>           No se modifica.
!>

COND

!>          COND es REAL
!>           A la entrada, se utiliza como se describe en MODE arriba.
!>           Si se utiliza, debe ser >= 1. No se modifica.
!>

DMAX

!>          DMAX es REAL
!>           Si MODE no es -6, 0 ni 6, el contenido de D, según
!>           se calcula según MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))); por lo tanto, el valor propio o singular
!>           máximo absoluto (que es la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no tiene por qué ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No se modifica.
!>

RANK

!>          RANK es INTEGER
!>           El rango de la matriz a generar para los modos 1, 2, 3 solamente.
!>           D( RANK+1:N ) = 0.
!>           No se modifica.
!>

KL

!>          KL es INTEGER
!>           Esto especifica el ancho de banda inferior de la matriz. Por ejemplo, KL=0

KU

!>          KU es INTEGER
!>           Esto especifica el ancho de banda superior de la matriz. Por
!>           ejemplo, KU=0 implica triangular inferior, KU=1 implica Hessenberg
!>           inferior, y KU siendo al menos N-1 significa que la matriz
!>           tiene ancho de banda superior completo. KL debe ser igual a KU si la matriz
!>           es simétrica o hermitiana.
!>           No modificado.
!>

PACK

!>          PACK es CHARACTER*1
!>           Esto especifica el empaquetado de la matriz de la siguiente manera:
!>           'N' => sin empaquetar
!>           'U' => poner a cero todas las entradas subdiagonales (si es simétrica
!>                  o hermitiana)
!>           'L' => poner a cero todas las entradas superdiagonales (si es simétrica
!>                  o hermitiana)
!>           'C' => almacenar el triángulo superior por columnas (solo si la
!>                  matriz es simétrica, hermitiana o triangular superior)
!>           'R' => almacenar el triángulo inferior por columnas (solo si la
!>                  matriz es simétrica, hermitiana o triangular inferior)
!>           'B' => almacenar el triángulo inferior en el esquema de almacenamiento
!>                  de banda (solo si la matriz es simétrica, hermitiana o
!>                  triangular inferior)
!>           'Q' => almacenar el triángulo superior en el esquema de almacenamiento
!>                  de banda (solo si la matriz es simétrica, hermitiana o
!>                  triangular superior)
!>           'Z' => almacenar toda la matriz en el esquema de almacenamiento
!>                  de banda (el pivoteo puede ser proporcionado usando esta
!>                  opción para almacenar A en las filas finales del
!>                  almacenamiento asignado)
!>
!>           Usando estas opciones, se pueden obtener los diversos esquemas de
!>           almacenamiento empaquetado y de banda de LAPACK:
!>           GB                    - usar 'Z'
!>           PB, SB, HB, o TB     - usar 'B' o 'Q'
!>           PP, SP, HB, o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a CLATMT difieren solo en el parámetro PACK,
!>           generarán matrices matemáticamente equivalentes.
!>           No modificado.
!>

A

!>          A es un array COMPLEX, de dimensión ( LDA, N )
!>           Al salir, A es la matriz de prueba deseada. A se genera primero
!>           en forma completa (desempaquetada) y luego se empaqueta, si así
!>           lo especifica PACK. Por lo tanto, los primeros M elementos de las
!>           primeras N columnas siempre se modificarán. Si PACK especifica un
!>           esquema de almacenamiento empaquetado o de banda, todos los
!>           elementos LDA de las primeras N columnas se modificarán; los
!>           elementos del array que no corresponden a elementos de la matriz
!>           generada se establecerán a cero.
!>           Modificado.
!>

LDA

!>          LDA es INTEGER
!>           LDA especifica la primera dimensión de A tal como se declara en el
!>           programa llamador. Si PACK='N', 'U', 'L', 'C', o 'R', entonces
!>           LDA debe ser al menos M. Si PACK='B' o 'Q', entonces LDA debe
!>           ser al menos MIN( KL, M-1) (que es igual a MIN(KU,N-1)).
!>           Si PACK='Z', LDA debe ser lo suficientemente grande como para
!>           contener el array empaquetado: MIN( KU, N-1) + MIN( KL, M-1) + 1.
!>           No modificado.
!>

WORK

!>          WORK es un array COMPLEX de dimensión ( 3*MAX( N, M ) )
!>           Espacio de trabajo.
!>           Modificado.
!>

INFO

!>          INFO es INTEGER
!>           Código de error. Al salir, INFO se establecerá en uno de los
!>           siguientes valores:
!>             0 => retorno normal
!>            -1 => M negativo o desigual a N y SYM='S', 'H', o 'P'
!>            -2 => N negativo
!>            -3 => DIST cadena ilegal
!>            -5 => SYM cadena ilegal
!>            -7 => MODE no está en el rango -6 a 6
!>            -8 => COND menor que 1.0, y MODE ni -6, 0 ni 6
!>           -10 => KL negativo
!>           -11 => KU negativo, o SYM no es 'N' y KU no es igual a
!>                  KL
!>           -12 => PACK cadena ilegal, o PACK='U' o 'L', y SYM='N';
!>                  o PACK='C' o 'Q' y SYM='N' y KL es cero;
!>                  o PACK='R' o 'B' y SYM='N' y KU es cero;
!>                  o PACK='U', 'L', 'C', 'R', 'B', o 'Q', y M no es
!!>                 N.
!>           -14 => LDA es menor que M, o PACK='Z' y LDA es menor que
!>                  MIN(KU,N-1) + MIN(KL,M-1) + 1.
!>            1  => Retorno de error de SLATM7
!>            2  => No se puede escalar a DMAX (el valor singular máximo es 0)
!>            3  => Retorno de error de CLAGGE, CLAGHE o CLAGSY
!>
