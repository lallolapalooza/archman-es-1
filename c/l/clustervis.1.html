CLUSTERVIS(1) Manual de Comandos Generales CLUSTERVIS(1)

NOMBRE

clustervis - visualiza el rendimiento de CPU y red en un clúster

SINOPSIS

clustervis [-H archivo de nodos] [-h host[,host...]] [-a archivo de registro[,archivo de registro...]] [-m max] [opciones de pmview]

DESCRIPCIÓN

clustervis muestra gráficos de barras tridimensionales de la utilización de CPU y el tráfico de red para uno o la mayoría de los hosts en un clúster. Una herramienta alternativa de monitoreo de rendimiento de clúster bidimensional es pmgcluster(1). clustervis está diseñado para proporcionar una visión general escalable del rendimiento de clústeres grandes. Otras herramientas como pmchart(1) y pmgsys(1) proporcionan detalles de profundización a nivel de host. Estas herramientas pueden iniciarse haciendo clic en el plano base morado de un host particular y luego seleccionando una herramienta del menú lanzar en clustervis.

Los argumentos -H, -h y -a son mutuamente exclusivos y tienen las siguientes semánticas; si no se proporciona ninguno de -H, -h o -a, y existe el archivo /etc/nodes o /etc/ace/nodes, o la variable de entorno $PCP_CLUSTER_CONFIG está establecida, entonces se usa el archivo nombrado como el conjunto de hosts para monitoreo en vivo. Si el archivo de nodos predeterminado no existe, la variable de entorno no está establecida y ninguna de las tres banderas fue dada, se reporta un error. De lo contrario, si se proporciona -H, el conjunto de hosts se da en archivo de nodos.

La bandera -h especifica uno o más hosts (separados por comas sin espacios) para monitoreo en vivo y la bandera -a especifica uno o más archivos de registro para reproducción de archivo (separados por comas).

La altura de la pila de CPU es proporcional a la utilización de CPU en cada uno de los modos sys (rojo, ejecutando en el kernel) y user (azul, ejecutando código de usuario). La pila de tráfico de red se muestra para cada interfaz de red como la tasa de paquetes in (azul claro), out (naranja) y errors (rojo). La altura de la pila de red se modula por el argumento -m, con un valor predeterminado de 750 paquetes/segundo que representa tráfico de red saturado.

clustervis genera un archivo de configuración de pmview(1), y pasa la mayoría de las opciones de línea de comandos a pmview(1). Por lo tanto, las opciones de línea de comandos -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -Z y -z, y la interfaz de usuario se describen en la página del manual de pmview(1).

ARCHIVOS

$PCP_VAR_DIR/config/pmlogger/config.clustervis
Un archivo de configuración de pmlogger(1) para las métricas de clustervis.
/usr/pcp/lib/pmview-args
Procedimientos de shell para analizar las opciones de línea de comandos de pmview(1).
/etc/nodes
Conjunto predeterminado de hosts en el clúster.

ENTORNO PCP

La variable de entorno PCP_CLUSTER_CONFIG puede usarse para especificar el archivo de nodos predeterminado en lugar de usar la bandera -H. Cada línea en el archivo es un nombre de host (o un comentario que comienza con #). Otras variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(4).
