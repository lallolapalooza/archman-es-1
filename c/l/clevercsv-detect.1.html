NOMBRE

clevercsv-detect - Detecta el dialecto de un archivo CSV

SINOPSIS

clevercsv detect [-c | --consistency] [-e ENCODING | --encoding=ENCODING]
                 [-n NUM_CHARS | --num-chars=NUM_CHARS] [ -p | --plain |
                 -j | --json ] [--no-skip] [--add-runtime] <path>

DESCRIPCIÓN

Detecta el dialecto de un archivo CSV.

OPCIONES

-h, --help

muestra este mensaje de ayuda y sale

-c, --consistency

Por defecto, el dialecto de los archivos CSV se detecta utilizando un proceso de dos pasos. Primero, se utiliza un conjunto estricto de comprobaciones para ver si el archivo se adhiere a un formato muy básico (por ejemplo, cuando todas las celdas del archivo son enteros). Si ninguna de estas comprobaciones tiene éxito, se utiliza la medida de consistencia de datos de Van den Burg, et al. (2019) para detectar el dialecto. Con esta opción, puede forzar que la detección utilice siempre la medida de consistencia de datos. Esto puede ser útil para pruebas o investigación, por ejemplo.

-e, --encoding

La codificación del archivo CSV dado se detecta automáticamente utilizando chardet. Aunque chardet es increíblemente preciso, no es perfecto. En los casos raros en que comete un error al detectar la codificación del archivo, puede anular la codificación proporcionándola a través de esta bandera. Además, cuando tiene un número de archivos CSV con una codificación de archivo conocida, puede usar esta opción para acelerar el proceso de generación de código.

-n, --num-chars

En archivos CSV grandes, la detección de dialectos a veces puede ser un poco lenta debido al gran número de dialectos posibles a considerar. Para aliviar esto, puede limitar el número de caracteres a utilizar para la detección.

Un aspecto a tener en cuenta es que CleverCSV puede necesitar leer un número específico de caracteres para poder inferir correctamente el dialecto. Por ejemplo, en el archivo ``imdb.csv`` del repositorio de GitHub, el dialecto correcto solo se puede encontrar después de leer al menos 66 líneas del archivo. Por lo tanto, si hay disponibilidad para ejecutar CleverCSV en el archivo completo, generalmente se recomienda.

-p, --plain

Imprime los componentes del dialecto en líneas separadas

-j, --json

Imprime el dialecto en la salida estándar en forma de objeto JSON. Este objeto siempre tendrá las claves 'delimiter', 'quotechar', 'escapechar' y 'strict'. Si se especifica --add-runtime, también tendrá una clave 'runtime'.

--no-skip

La puntuación de consistencia de datos utilizada para la detección de dialectos consta de dos componentes: una puntuación de patrón y una puntuación de tipo. La puntuación de tipo está entre 0 y 1. Al calcular las medidas de consistencia de datos para diferentes dialectos, omitimos el cálculo de la puntuación de tipo si vemos que la puntuación de patrón es inferior a la mejor puntuación de consistencia de datos que hemos visto hasta ahora. Esta opción se puede usar para deshabilitar este comportamiento y calcular la puntuación de tipo para todos los dialectos. Esto es principalmente útil para depuración y pruebas.

--add-runtime

Agrega el tiempo de ejecución de la detección a la salida de la detección.

<path>

Ruta al archivo CSV
