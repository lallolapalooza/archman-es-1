NOMBRE

clevis-luks-edit - Editar un enlace de una ranura vinculada a clevis en un dispositivo LUKS

SINOPSIS

clevis luks edit [-f] -d DEV -s SLT [-c CONFIG]

DESCRIPCIÓN

El comando clevis luks edit edita los enlaces clevis de un dispositivo LUKS. Por ejemplo:

clevis luks edit -d /dev/sda1 -s 1

OPCIONES

•-d DEV : El dispositivo LUKS para editar los pines vinculados a clevis
•-s SLT : La ranura a usar al editar el enlace clevis
•-f : Proceder con la operación de edición incluso si la configuración no ha cambiado
•-c CONFIG : La configuración actualizada a usar

EJEMPLOS

clevis luks list -d /dev/sda1
1: tang '{"url":"addr"}'

Como podemos ver en el ejemplo anterior, /dev/sda1 tiene una ranura vinculada, en este caso, a un pin de tang.

Podemos editar este enlace emitiendo el siguiente comando:

clevis luks edit -d /dev/sda1 -s 1

Esto abrirá un editor de texto —el configurado en la variable de entorno $EDITOR, o vi, como respaldo— con la configuración actual de este enlace para ser editado. En este caso, deberíamos tener lo siguiente:

{
    "url": "addr"
}

Una vez en el editor, podemos editar la configuración del pin. Para tang, podríamos editar la url, por ejemplo. Después de completar el cambio, guarde el archivo y salga. La configuración actualizada se validará para JSON, y si no hay errores, se le mostrará la configuración actualizada y se le preguntará si desea proceder.

Al proceder, el enlace se actualizará. Es posible que se requiera proporcionar una contraseña LUKS válida para el dispositivo.

En el segundo ejemplo, actualizaremos el mismo dispositivo y ranura, pero también proporcionaremos la configuración actualizada:

clevis luks edit -d /dev/sda1 -s 1 -c '{"url":"new-addr-here"}'

En este caso, la actualización del enlace se realizará en modo no interactivo. Tenga en cuenta que también puede ser necesario proporcionar una contraseña LUKS para el dispositivo.
