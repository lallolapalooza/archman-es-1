CLARGE

Propósito:

!>
!> CLARGE pre y post-multiplica una matriz general compleja n por n A
!> con una matriz unitaria aleatoria: A = U*D*U'.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz original n por n A.
!>          En la salida, A es sobrescrita por U*A*U' para alguna
!>          matriz unitaria aleatoria U.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= N.
!>

ISEED

!>          ISEED es array INTEGER, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios; los elementos del array
!>          deben estar entre 0 y 4095, e ISEED(4) debe ser
!>          impar.
!>          En la salida, la semilla se actualiza.
!>

WORK

!>          WORK es array COMPLEX, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
