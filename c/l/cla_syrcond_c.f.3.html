función real cla_syrcond_c (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, real, dimension( * ) c, logical capply, integer info, complex, dimension( * ) work, real, dimension( * ) rwork)

CLA_SYRCOND_C calcula el número de condición de la norma infinita de op(A)*inv(diag(c)) para matrices simétricas indefinidas.

Propósito:

!>
!>    CLA_SYRCOND_C Calcula el número de condición de la norma infinita de
!>    op(A) * inv(diag(C)) donde C es un vector REAL.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>     En la entrada, la matriz A de N por N
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX, dimension (LDAF,N)
!>     La matriz diagonal de bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L según lo calculado por CSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por CSYTRF.
!>

C

!>          C es array REAL, dimension (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LOGICAL
!>     Si .TRUE. entonces accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array COMPLEX, dimension (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es array REAL, dimension (N).
!>     Espacio de trabajo.
!>
