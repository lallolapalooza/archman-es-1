NOMBRE

clockdiff - mide la diferencia de reloj entre hosts

SINOPSIS

clockdiff [-o] [-o1] [--time-format ctime iso] [-V] {destino}

DESCRIPCIÓN

clockdiff Mide la diferencia de reloj entre nosotros y el destino con una resolución de 1 ms utilizando paquetes ICMP TIMESTAMP [2] o, opcionalmente, la opción IP TIMESTAMP [3] añadida a ICMP ECHO. [1]

OPCIONES

-o

Utiliza IP TIMESTAMP con ICMP ECHO en lugar de mensajes ICMP TIMESTAMP. Es útil con algunos destinos que no admiten ICMP TIMESTAMP (por ejemplo, Solaris <2.4).

-o1

Una forma ligeramente diferente de -o, concretamente, utiliza IP TIMESTAMP de tres términos con direcciones de salto predefinidas en lugar de una de cuatro términos. Qué variante funciona mejor depende del host de destino. En particular, -o es mejor para Linux.

-T, --time-format ctime iso

Imprime la marca de tiempo en la salida en formato ISO-8601 o en formato ctime clásico. El formato ctime es el predeterminado. La marca de tiempo ISO incluye la zona horaria y es más fácil de analizar.

-I

Alias de la opción y argumento --time-format iso .

-h, --help

Imprime la ayuda y sale.

-V, --version

Imprime la versión y sale.

ADVERTENCIAS

• Algunos nodos (Cisco) utilizan marcas de tiempo no estándar, lo que está permitido por RFC, pero hace que las marcas de tiempo sean en gran medida inútiles.
• Algunos nodos generan marcas de tiempo incorrectas (Solaris>2.4) cuando ejecutan xntpd. Parece que su pila IP utiliza una fuente de reloj corrupta, que se sincroniza periódicamente con el reloj de hora del día y salta aleatoriamente, haciendo que las marcas de tiempo sean en gran medida inútiles. La buena noticia es que puedes usar NTP en este caso, que es incluso mejor.
• clockdiff muestra la diferencia de tiempo módulo 24 días.

VER TAMBIÉN

ping(8), arping(8), tracepath(8).

REFERENCIAS

[1] ICMP ECHO, RFC0792, página 14.

[2] ICMP TIMESTAMP, RFC0792, página 16.

[3] Opción IP TIMESTAMP, RFC0791, 3.1, página 16.

AUTOR

clockdiff fue compilado por Alexey Kuznetsov <kuznet@ms2.inr.ac.ru>. Se basó en código prestado del demonio timed de BSD.

SEGURIDAD

clockdiff requiere las capacidades CAP_NET_RAW y CAP_SYS_NICE para ser ejecutado. Es seguro usarlo como root con set-uid.

DISPONIBILIDAD

clockdiff es parte del paquete iputils.
