Class::Inspector(3) Documentación de Perl aportada por el usuario Class::Inspector(3)

NOMBRE

Class::Inspector - Obtener información sobre una clase y su estructura

VERSIÓN

versión 1.36

SINOPSIS

use Class::Inspector;

# ¿Está una clase instalada y/o cargada?
Class::Inspector->installed( 'Foo::Class' );
Class::Inspector->loaded( 'Foo::Class' );

# Información relacionada con el nombre de archivo
Class::Inspector->filename( 'Foo::Class' );
Class::Inspector->resolved_filename( 'Foo::Class' );

# Obtener información relacionada con subrutinas
Class::Inspector->functions( 'Foo::Class' );
Class::Inspector->function_refs( 'Foo::Class' );
Class::Inspector->function_exists( 'Foo::Class', 'bar' );
Class::Inspector->methods( 'Foo::Class', 'full', 'public' );

# Encontrar todas las subclases cargadas o algo así
Class::Inspector->subclasses( 'Foo::Class' );

DESCRIPCIÓN

Class::Inspector le permite obtener información sobre una clase cargada. La mayor parte o toda esta información se puede encontrar de otras maneras, pero no siempre son muy amigables, y generalmente implican un nivel relativamente alto de brujería de Perl, o código de aspecto extraño e inusual. Class::Inspector intenta proporcionar una interfaz más fácil y amigable para esta información.

MÉTODOS

installed

my $bool = Class::Inspector->installed($class);

El "installed" método estático intenta determinar si una clase está instalada en la máquina, o al menos disponible para Perl. Lo hace envolviendo a "resolved_filename".

Devuelve true si está instalada/disponible, false si la clase no está instalada, o "undef" si el nombre de la clase es inválido.

loaded

my $bool = Class::Inspector->loaded($class);

El "loaded" método estático intenta determinar si una clase está cargada buscando entradas en la tabla de símbolos.

Este método que usa para determinarlo funcionará incluso si la clase no tiene su propio archivo, sino que está contenida dentro de un único archivo con múltiples clases en él. Incluso en el caso de que se use algún tipo de clase de carga en tiempo de ejecución, estas típicamente dejan algún rastro en la tabla de símbolos, por lo que una clase basada en Autoload o Class::Autouse debería aparecer correctamente como cargada.

Devuelve true si la clase está cargada, false si no lo está, o "undef" si el nombre de la clase es inválido.

filename

my $filename = Class::Inspector->filename($class);

Para una clase dada, devuelve el nombre de archivo base para la clase. Este NO será un nombre de archivo completamente resuelto, solo la parte del nombre de archivo POR DEBAJO de la @INC entrada.

print Class->filename( 'Foo::Bar' );
> Foo/Bar.pm

Este nombre de archivo se devolverá con el separador correcto para la plataforma local, y debería funcionar en todas las plataformas.

Devuelve el nombre de archivo en caso de éxito o "undef" si el nombre de la clase es inválido.

resolved_filename

my $filename = Class::Inspector->resolved_filename($class);
my $filename = Class::Inspector->resolved_filename($class, @try_first);

Para una clase dada, el "resolved_filename" método estático devuelve el nombre de archivo completamente resuelto para una clase. Es decir, el archivo desde el cual la clase sería cargada.

Este no es necesariamente el archivo desde el cual la clase FUE cargada, ya que el valor devuelto se determina cada vez que se ejecuta, y el @INC ruta de inclusión puede cambiar.

Para obtener el archivo real de una clase cargada, vea el "loaded_filename" método.

Devuelve el nombre de archivo para la clase, o "undef" si el nombre de la clase es inválido.

loaded_filename

my $filename = Class::Inspector->loaded_filename($class);

Para una clase cargada dada, el "loaded_filename" método estático determina (a través del %INC hash) el nombre del archivo desde el cual fue originalmente cargada.

Devuelve una ruta de archivo resuelta, o false si la clase no tuvo su propio archivo.

functions

my $arrayref = Class::Inspector->functions($class);

Para una clase cargada, el "functions" método estático devuelve una lista de los nombres de todas las funciones en el espacio de nombres inmediato de las clases.

Tenga en cuenta que esto no son los MÉTODOS de la clase, solo las funciones.

Devuelve una referencia a un array de los nombres de las funciones en caso de éxito, o "undef" si el nombre de la clase es inválido o la clase no está cargada.

function_refs

my $arrayref = Class::Inspector->function_refs($class);

Para una clase cargada, el "function_refs" método estático devuelve referencias a todas las funciones en el espacio de nombres inmediato de las clases.

Tenga en cuenta que esto no son los MÉTODOS de la clase, solo las funciones.

Devuelve una referencia a un array de "CODE" refs de las funciones en caso de éxito, o "undef" si la clase no está cargada.

function_exists

my $bool = Class::Inspector->function_exists($class, $functon);

Dada una clase y un nombre de función, el "function_exists" método estático comprobará si la función existe en la clase.

Tenga en cuenta que esto es como una función, no como un método. Para ver si un método existe para una clase, use el "can" método de cualquier clase u objeto.

Devuelve true si la función existe, false si no, o "undef" si el nombre de la clase o la función son inválidos, o la clase no está cargada.

methods

my $arrayref = Class::Inspector->methods($class, @options);

Para un nombre de clase dado, el "methods" método estático devolverá TODOS los métodos disponibles para esa clase. Esto incluye todos los métodos disponibles de cada clase hacia arriba en el @ISA árbol de la clase.

Devuelve una referencia a un array de los nombres de todos los métodos disponibles en caso de éxito, o "undef" si el nombre de la clase es inválido o la clase no está cargada.

Hay varias opciones disponibles para el "methods" método que alterarán los resultados devueltos. Estas deberían listarse después del nombre de la clase, en cualquier orden.

# Solo obtener métodos públicos
my $method = Class::Inspector->methods( 'My::Class', 'public' );
public
La "public" opción devolverá solo los métodos 'públicos', tal como se definen por la convención de Perl de anteponer un guion bajo a cualquier método 'privado'. La "public" opción eliminará efectivamente cualquier método que comience con un guion bajo.
private
La "private" opción devolverá solo los métodos 'privados', tal como se definen por la convención de Perl de anteponer un guion bajo a los métodos privados. La "private" opción eliminará efectivamente cualquier método que no comience con un guion bajo.

Nota: Las "public" y "private" opciones son mutuamente excluyentes

full
"methods" normalmente devuelve solo el nombre del método. Al proporcionar el "full" opción hará que los métodos se devuelvan como los nombres completos. Es decir, en lugar de devolver "[ 'method1', 'method2', 'method3' ]", en su lugar obtendría "[ 'Class::method1', 'AnotherClass::method2', 'Class::method3' ]".
expanded
La "expanded" opción hará que se devuelva mucha más información sobre el método. En lugar de solo el nombre del método, obtendrá una referencia a un array que contiene el nombre del método como un nombre combinado único, al estilo de "full", la clase y el método por separado, y una referencia CODE a la función real ( si está disponible ). Tenga en cuenta que no se garantiza que la referencia a la función esté disponible. "Class::Inspector" está destinado en algún momento posterior a funcionar con módulos que tengan algún tipo de cargador de tiempo de ejecución común ( por ejemplo "Autoloader" o "Class::Autouse" por ejemplo).

La respuesta de "methods( 'Class', 'expanded' )" se parecería a lo siguiente.

[
  [ 'Class::method1',   'Class',   'method1', \&Class::method1   ],
  [ 'Another::method2', 'Another', 'method2', \&Another::method2 ],
  [ 'Foo::bar',         'Foo',     'bar',     \&Foo::bar         ],
]

subclasses

my $arrayref = Class::Inspector->subclasses($class);

El "subclasses" método estático buscará en todo el espacio de nombres (y por lo tanto todas las clases actualmente cargadas) para encontrar todas las clases que son subclases de la clase proporcionada como parámetro.

La prueba real se hará llamando a "isa" en la clase como un método estático. (es decir, "My::Class->isa($class)".

Devuelve una referencia a una lista de las clases cargadas que coinciden con la clase proporcionada, o falso si ninguna coincide, o "undef" si el nombre de clase proporcionado es inválido.
