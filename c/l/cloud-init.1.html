NOMBRE

cloud-init - Inicialización de instancias en la nube

SINOPSIS

cloud-init [-h] [-d] [--force] [-v] [SUBCOMANDO]

DESCRIPCIÓN

Cloud-init proporciona un mecanismo para la inicialización de instancias en la nube. Esto se hace identificando la plataforma en la nube que se está utilizando, leyendo metadatos, datos del proveedor y datos del usuario de la nube, y luego inicializando la instancia según lo solicitado.

OPCIONES

-h, --help
Mostrar mensaje de ayuda y salir.
-v, --version
Mostrar el número de versión del programa y salir.
--all-stages
INTERNO: Ejecutar las etapas de cloud-init bajo un único proceso utilizando un protocolo de sincronización. No está pensado para uso desde la línea de comandos.

SUBCOMANDOS

Por favor, consulta la salida de ayuda de cada subcomando para obtener detalles, flags y subcomandos adicionales.

analyze
Analizar los registros y datos de cloud-init.
collect-logs
Recopilar y empaquetar toda la información de depuración de cloud-init.
clean
Eliminar registros y artefactos para que cloud-init pueda volver a ejecutarse.
devel
Ejecutar herramientas de desarrollo. Consulta la salida de ayuda para ver los detalles del subcomando.
features
Listar las características definidas.
query
Consultar metadatos estandarizados de la instancia desde la línea de comandos.
schema
Validar archivos cloud-config utilizando jsonschema.
single
Ejecutar manualmente un único módulo. Útil para pruebas durante el desarrollo.
status
Informar del estado de cloud-init o esperar a que se complete.

OBSOLETOS

-d, --debug
Mostrar registros adicionales previos a la acción (por defecto: False).
--force
Forzar la ejecución incluso si no se encuentra ninguna fuente de datos (usar bajo tu propio riesgo).
init
Inicializar cloud-init y ejecutar los módulos iniciales.
modules
Activar módulos utilizando una clave de configuración dada.

ESTADO DE SALIDA

0 - Éxito
1 - Error - Cloud-init falló.
2 - Error recuperable - Cloud-init completó pero experimentó errores.
