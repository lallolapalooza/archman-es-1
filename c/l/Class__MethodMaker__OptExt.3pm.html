Class::MethodMaker::OptExt(3) Documentación aportada por el usuario de Perl Class::MethodMaker::OptExt(3)

NOMBRE

Class::MethodMaker::OptExt - Constantes para el mecanismo de extensión de opciones de C::MM

SINOPSIS

Esta clase es interna a Class::MethodMaker y no debe ser utilizada por ningún cliente. **No** forma parte de la API pública.

DESCRIPCIÓN

Esta clase contiene las constantes utilizadas por Class::MethodMaker para determinar los nombres de sus métodos dependientes de las opciones invocadas.

CONSTANTES DE CLASE

OPTEXT

OPTEXT es un mapeo de las opciones que se implementan como extensiones de métodos a los parámetros de la opción.

Las claves de los parámetros son:

codificación
Número de código (para permitir que la combinación de opciones se codifique manteniendo la longitud del nombre de la subrutina no más de 8 caracteres). La codificación es requerida para todas las opciones (para determinar la extensión del método) y debe ser una potencia de dos.
referencia
Código para referirse al almacenamiento (predeterminado: '$_[0]->{$name}').
declaración
Código para declarar el almacenamiento.
postac
Código a ejecutar inmediatamente después de cualquier verificación de asignación, por ejemplo, para inicializar el almacenamiento si es necesario.
asgnchk
Código para verificar asignaciones.
defchk
Código para la verificación predeterminada.
reset
Código a ejecutar al restablecer un elemento.
lectura
Código a ejecutar cada vez que se lee un valor.
almacenamiento
Código a ejecutar cada vez que se almacena un valor.

COMPONENTES DE CLASE

FUNCIONES DE NIVEL SUPERIOR DE CLASE

codificar

Toma un conjunto de opciones y devuelve un código de dos letras que es la extensión a añadir al método para incorporar las extensiones, y una lista (arrayref) de las extensiones representadas.

SINOPSIS
my ($ext, $opt) =
  Class::MethodMaker::OptExt->encode([qw( static type foobar )]);
ARGUMENTOS
opciones
Las opciones a codificar, como un arrayref de nombres de opciones.
RETORNA
ext
Un código (cadena) para añadir al nombre del método que representa las opciones utilizadas.
opts
Las opciones representadas por el código de extensión. Este es generalmente un subconjunto de las proporcionadas en opciones, ya que no todas las opciones generales son manejadas por un nombre de método codificado.
