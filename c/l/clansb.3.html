función real clansb (norm, uplo, n, k, ab, ldab, work)

CLANSB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz banda simétrica.

Documentación de función/subrutina

real función clansb (norm de carácter, uplo de carácter, n entero, k entero, complejo, dimensión( ldab, * ) ab, ldab entero, real, dimensión( * ) work)

CLANSB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz banda simétrica.

Propósito:

!>
!> CLANSB  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de mayor valor absoluto de una matriz
!> simétrica A de tamaño n x n, con k super-diagonales.
!>

Devuelve

CLANSB 
!>
!>    CLANSB = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma
!> de cuadrados).  Nótese que  max(abs(A(i,j)))  no es una norma de matriz
!> consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en CLANSB como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz banda A se proporciona.
!>          = 'U':  Se proporciona la parte triangular superior
!>          = 'L':  Se proporciona la parte triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANSB se
!>          establece a cero.
!>

K

!>          K es INTEGER
!>          El número de super-diagonales o sub-diagonales de la
!>          matriz banda A.  K >= 0.
!>

AB

!>          AB es un array COMPLEX, dimensión (LDAB,N)
!>          La parte superior o inferior de la matriz banda simétrica A,
!>          almacenada en las primeras K+1 filas de AB.  La j-ésima columna de A se
!>          almacena en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(k+1+i-j,j) = A(i,j) para max(1,j-k)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)   = A(i,j) para j<=i<=min(n,j+k).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= K+1.
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo contrario,
!>          WORK no se hace referencia.
!>
