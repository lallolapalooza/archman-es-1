NOMBRE

clevis-luks-list - Lista los pines enlazados a un dispositivo LUKS

SINOPSIS

clevis luks list -d DEV [-s SLT]

DESCRIPCIÓN

El comando clevis luks list lista los pines enlazados al dispositivo LUKS. Por ejemplo:

clevis luks list -d /dev/sda1

OPCIONES

•-d DEV : El dispositivo LUKS en el que listar los pines enlazados.
•-s SLT : La ranura a usar para listar el pin.

EJEMPLOS

clevis luks list -d /dev/sda1
1: sss '{"t":1,"pins":{"tang":[{"url":"addr1"},{"url":"addr2"}],"tpm2":[{"hash":"sha256","key":"ecc"}],"sss":{"t":1,"pins":{"tang":[{"url":"addr3"}]}}}}'
2: tang '{"url":"addr"}'
3: tpm2 '{"hash":"sha256","key":"ecc","pcr_bank":"sha1","pcr_ids":"7"}'

Como podemos ver en el ejemplo anterior, /dev/sda1 tiene tres ranuras enlazadas, cada una con un pin diferente.

•La ranura #1 está enlazada con el pin sss, y también utiliza pines tang y tpm2 en su política.
•La ranura #2 está enlazada usando el pin tang.
•La ranura #3 está enlazada con el pin tpm2.

Tenga en cuenta que la salida de clevis luks list puede utilizarse con el comando clevis luks bind, como por ejemplo:

clevis luks bind -d /dev/sda1 tpm2 '{"hash":"sha256","key":"ecc","pcr_bank":"sha1","pcr_ids":"7"}'

Y enlazaremos otra ranura con una política similar a la que tenemos en la ranura #3. Tenga en cuenta también que si le interesa una ranura particular, puede pasar el argumento -s SLT a clevis luks list:

clevis luks list -d /dev/sda1 -s 2
2: tang '{"url":"addr"}'

En el ejemplo anterior, listamos solo el pin enlazado a la ranura #2.

VER TAMBIÉN
