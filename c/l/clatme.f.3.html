CLATM

E

Propósito

: 
!>
!>    CLATME genera matrices cuadradas no simétricas aleatorias con
!>    eigenvalores especificados para probar los programas de LAPACK.
!>
!>    CLATME opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>    1. Establece la diagonal en D, donde D puede ser de entrada o
!>         calculado de acuerdo con MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>    2. Si UPPER='T', el triángulo superior de A se establece con valores aleatorios
!>         de la distribución DIST.
!>
!>    3. Si SIM='T', A se multiplica a la izquierda por una matriz aleatoria
!>         X, cuyos valores singulares son especificados por DS, MODES y
!>         CONDS, y a la derecha por la inversa de X.
!>
!>    4. Si KL < N-1, el ancho de banda inferior se reduce a KL usando
!>         transformaciones de Householder.  Si KU < N-1, el ancho de banda
!>         superior se reduce a KU.
!>
!>    5. Si ANORM no es negativo, la matriz se escala para tener
!>         una norma de elemento máximo ANORM.
!>
!>    (Nota: como la matriz no puede reducirse más allá de la forma de Hessenberg,
!>     no hay opciones de empaquetado disponibles.)
!
>

Parámetro

s
N 
!>          N es INTEGER
!>           El número de columnas (o filas) de A. No se modifica.
!
>

DIS

T 
!>          DIST es CHARACTER*1
!>           A la entrada, DIST especifica el tipo de distribución a usar
!>           para generar los eigen-/valores singulares aleatorios, y en el
!>           triángulo superior (ver UPPER).
!>           'U' => UNIFORM( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' para simétrico )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           'D' => uniforme en el disco complejo |z| < 1.
!>           No se modifica.
!
>

ISEE

D 
!>          ISEED es un array INTEGER, dimensión ( 4 )
!>           A la entrada ISEED especifica la semilla del generador de
!>           números aleatorios. Debería estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debería ser impar. El generador de números aleatorios
!>           usa una secuencia lineal congruencial limitada a pequeños
!>           enteros, y por lo tanto debería producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED cambian a la
!>           salida, y pueden usarse en la siguiente llamada a CLATME
!>           para continuar la misma secuencia de números aleatorios.
!>           Se cambia a la salida.
!
>

D 
!>          D es un array COMPLEX, dimensión ( N )
!>           Este array se usa para especificar los eigenvalores de A.  Si
!>           MODE=0, se asume que D contiene los eigenvalores,
!>           de lo contrario se calcularán de acuerdo con MODE, COND,
!>           DMAX y RSIGN y se colocarán en D.
!>           Se modifica si MODE es distinto de cero.
!
>

MOD

E 
!>          MODE es INTEGER
!>           A la entrada describe cómo se deben especificar los eigenvalores:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D con números aleatorios en el rango
!>                    ( 1/COND , 1 ) de modo que sus logaritmos
!>                    estén uniformemente distribuidos.
!>           MODE = 6 establece D con números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Así que si MODE está entre 1 y 4, D tiene entradas que van
!>              de 1 a 1/COND, si está entre -1 y -4, D tiene entradas
!>              que van de 1/COND a 1,
!>           No se modifica.
!
>

CON

D 
!>          COND es REAL
!>           A la entrada, se usa como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No se modifica.
!
>

DMA

X 
!>          DMAX es COMPLEX
!>           Si MODE no es -6, 0 ni 6, el contenido de D, tal como
!>           se calcula de acuerdo con MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))).  Note que DMAX no necesita ser
!>           positivo o real: si DMAX es negativo o complejo (o cero),
!>           D se escalará por un número negativo o complejo (o cero).
!>           Si RSIGN='F' entonces el eigenvalor (absoluto) más grande será
!>           igual a DMAX.
!>           No se modifica.
!
>

RSIG

N 
!>          RSIGN es CHARACTER*1
!>           Si MODE no es 0, 6, o -6, y RSIGN='T', entonces los
!>           elementos de D, tal como se calculan de acuerdo con MODE y COND, serán
!>           multiplicados por un número complejo aleatorio del círculo
!>           unitario |z| = 1.  Si RSIGN='F', no lo serán.  RSIGN puede
!>           tener solo los valores 'T' o 'F'.
!>           No se modifica.
!
>

UPPE

R 
!>          UPPER es CHARACTER*1
!>           Si UPPER='T', entonces los elementos de A sobre la diagonal
!>           se establecerán con números aleatorios de DIST.  Si UPPER='F',
!>           no lo serán.  UPPER puede tener solo los valores 'T' o 'F'.
!>           No se modificado.
!
>

SI

M 
!>          SIM es CHARACTER*1
!>           Si SIM='T', entonces A será operado por una , es decir, multiplicado a la izquierda por una matriz X y
!>           a la derecha por la inversa de X.  X = U S V, donde U y V son
!>           matrices unitarias aleatorias y S es una matriz (diagonal) de
!>           valores singulares especificados por DS, MODES y CONDS.  Si
!>           SIM='F', entonces A no será transformada.
!>           No se modifica.
!
>

D

S 
!>          DS es un array REAL, dimensión ( N )
!>           Este array se usa para especificar los valores singulares de X,
!>           de la misma manera que D especifica los eigenvalores de A.
!>           Si MODE=0, DS contiene los valores singulares, que
!>           no pueden ser cero.
!>           Se modifica si MODE es distinto de cero.
!
>

MODE

S 
!>          MODES es INTEGER
!
>

COND

S 
!>          CONDS es REAL
!>           Similar a MODE y COND, pero para especificar la diagonal
!>           de S.  MODES=-6 y +6 no están permitidos (ya que resultarían
!>           en eigenvalores aleatoriamente mal condicionados.)
!
>

K

L 
!>          KL es INTEGER
!>           Esto especifica el ancho de banda inferior de la  matriz.  KL=1
!>           especifica la forma de Hessenberg superior.  Si KL es al menos N-1,
!>           entonces A tendrá ancho de banda inferior completo.
!>           No se modifica.
!
>

K

U 
!>          KU es INTEGER
!>           Esto especifica el ancho de banda superior de la  matriz.  KU=1
!>           especifica la forma de Hessenberg inferior.  Si KU es al menos N-1,
!>           entonces A tendrá ancho de banda superior completo; si KU y KL
!>           son ambos al menos N-1, entonces A será densa.  Solo uno de
!>           KU y KL puede ser menor que N-1.
!>           No se modifica.
!
>

ANOR

M 
!>          ANORM es REAL
!>         


NAME


clatme - generates test matrices.







SYNOPSIS


  SUBROUTINE CLATME(
           M, N, DIST, DIAG, MODE,       NSETS,                  DIF,
           AMAX,                  AINF,                  K,       P,
           IL,                      JL,                      KL,      KU,
           ISEED,                   USER,                  A,       LDA,
           WORK,                    INFO )
      INTEGER M, N, NSETS, K, P, IL, JL, KL, KU, LDA, INFO
      CHARACTER*1 DIST, DIAG, MODE, DIF, AMAX, AINF
      REAL(8) AMAX, AINF

Function/Subroutine Documentation


This subroutine generates test matrices.




"M"




M is INTEGER
          The number of rows of the matrix A.


Not modified.




"N"




N is INTEGER
          The number of columns of the matrix A.


Not modified.




"DIST"




DIST is CHARACTER*1
          The distribution of the elements of A:
          = 'R': real random numbers
          = 'I': integers in the interval ( -2, 2 )
          = 'S': random integers in the interval ( -8, 8 )
          = 'N': normally distributed random numbers


Not modified.




"DIAG"




DIAG is CHARACTER*1
          The type of diagonal scaling:
          = 'N': no diagonal scaling
          = 'L': left diagonal scaling
          = 'R': right diagonal scaling
          = 'C': both left and right diagonal scaling


Not modified.




"MODE"




MODE is CHARACTER*1
          The type of matrix to generate:
          = 'N': none
          = 'Z': zero
          = 'K': Kahan matrix
          = 'D': diagonal matrix
          = 'S': symmetric matrix
          = 'H': skew-symmetric matrix
          = 'P': permutation matrix
          = 'L': lower triangular matrix
          = 'U': upper triangular matrix
          = 'B': bidiagonal matrix
          = 'O': orthogonal matrix
          = 'S': skew-symmetric
          = 'T': triangular matrix
          = 'P': permutation matrix


Not modified.




"NSETS"




NSETS is INTEGER
          Number of matrix sets to generate.


Not modified.




"DIF"




DIF is CHARACTER*1
          Controls the difficulty of the problem:
          = 'S': small problems
          = 'M': medium problems
          = 'L': large problems
          = 'U': unlikely to be singular


Not modified.




"AMAX"




AMAX is REAL(8)
          The maximum absolute value of the non-zero elements of A.


Not modified.




"AINF"




AINF is REAL(8)
          Specifies the norm of the inverse of A. Not used if MODE = 'N'.
          If AINF is negative, the norm is not scaled.
          If AINF is positive, A is scaled so that the appropriate norm
          of the inverse is AINF.


Not modified.




"K"




K is INTEGER
          Used with MODE = 'B' to indicate the number of super- or sub-
          diagonals.


Not modified.




"P"




P is INTEGER
          Used with MODE = 'P' to indicate the number of permutations.


Not modified.




"IL"




IL is INTEGER
          Offset of the first row of A to be used.
          Not modified.




"JL"




JL is INTEGER
          Offset of the first column of A to be used.
          Not modified.




"KL"




KL is INTEGER
          Used with MODE = 'K' to indicate the number of subdiagonals of
          A.


Not modified.




"KU"




KU is INTEGER
          Used with MODE = 'K' to indicate the number of superdiagonals
          of A.


Not modified.




"ISEED"




ISEED is INTEGER array, dimension ( 4 )
          Seed for the random number generator. Not modified.




"USER"




USER is COMPLEX array, dimension ( * )
          User workspace. Not modified.




"A"




A is COMPLEX array, dimension ( LDA, N )
          On exit A is the desired test matrix.


Modified.




"LDA"




LDA is INTEGER
          LDA specifies the first dimension of A as declared in the
          calling program. LDA must be at least M.


Not modified.




"WORK"




WORK is COMPLEX array, dimension ( 3*N )
          Workspace.


Modified.




"INFO"




INFO is INTEGER
          Error code. On exit, INFO will be set to one of the
          following values:
            0 => normal return
           -1 => N negative
           -2 => DIST illegal string
           -5 => MODE not in range -6 to 6
           -6 => COND less than 1.0, and MODE neither -6, 0 nor 6
           -9 => RSIGN is not 'T' or 'F'
          -10 => UPPER is not 'T' or 'F'
          -11 => SIM   is not 'T' or 'F'
          -12 => MODES=0 and DS has a zero singular value.
          -13 => MODES is not in the range -5 to 5.
          -14 => MODES is nonzero and CONDS is less than 1.
          -15 => KL is less than 1.
          -16 => KU is less than 1, or KL and KU are both less than
                 N-1.
          -19 => LDA is less than M.
            1  => Error return from CLATM1 (computing D)
            2  => Cannot scale to DMAX (max. eigenvalue is 0)
            3  => Error return from SLATM1 (computing DS)
            4  => Error return from CLARGE
            5  => Zero singular value from SLATM1.
