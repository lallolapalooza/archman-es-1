CLIENT *clntraw_create(unsigned long prognum, unsigned long versnum)
;
Esta rutina crea un cliente RPC de juguete para el programa remoto prognum, versión versnum. El transporte utilizado para pasar mensajes al servicio es en realidad un búfer dentro del espacio de direcciones del proceso, por lo que el servidor RPC correspondiente debe vivir en el mismo espacio de direcciones; véase svcraw_create(). Esto permite la simulación de RPC y la obtención de sobrecostos de RPC, como los
tiempos de ida y vuelta, sin ninguna interfere
ncia del núcleo. Esta rutina devuelve NULL si falla. 
CLIENT *clnttcp_create(struct sockaddr_in *addr,
                unsigned long prognum, unsigned long versnum,
                int *sockp, unsigned int sendsz, unsigned int recvsz)
;
Esta rutina crea un cliente RPC para el programa remoto prognum, versión versnum; el cliente usa TCP/IP como transporte. El programa remoto se encuentra en la dirección de Internet *addr. Si addr->sin_port es cero, entonces se establece al puerto real en el que el programa remoto está escuchando (se consulta al servicio portmap remoto para obtener esta información). El parámetro sockp es un socket; si es RPC_ANYSOCK, entonces esta rutina abre uno nuevo y establece sockp. Dado que el RPC basado en TCP usa E/S con búfer, el usuario puede especificar el tamaño de los búferes de envío y recepción con los parámetros sendsz y recvsz; los valores cero eligen valores predeterminado
s adecuados. Esta rutina
devuelve NULL si falla.
