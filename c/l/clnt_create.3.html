SINOPSIS Y

DESCRIPCIÓN

Estas rutinas permiten a los programas C realizar llamadas a procedimientos en otras máquinas a través de la red. Primero, el cliente llama a un procedimiento para enviar un paquete de datos al servidor. Al recibir el paquete, el servidor llama a una rutina de despacho para realizar el servicio solicitado, y luego envía una respuesta de vuelta. Finalmente, la llamada al procedimiento retorna al

cliente.

Para hacer uso de estas rutinas, incluya el archivo de cabecera <rpc/rpc.h>

.

Los prototipos a continuación hacen uso de los siguientes

tipos:
