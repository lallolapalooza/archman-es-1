CLOUD-INIT-PER(1) Manual de comandos generales CLOUD-INIT-PER(1)

NOMBRE

cloud-init-per - Ejecuta un comando con argumentos a una frecuencia específica

SINOPSIS

cloud-init-per <frecuencia> <nombre> <cmd> [ arg1 [ arg2 [...]]]

DESCRIPCIÓN

Ejecuta un comando con argumentos a una frecuencia específica.

Esta utilidad puede facilitar el uso de boothooks o bootcmd sobre una base "una vez" o "siempre". Por ejemplo:


- [ cloud-init-per, once, mymkfs, mkfs, /dev/vdb ]

El comando cloud-init-per reemplazó al comando cloud-init-run-module.

OPCIONES

frecuencia
Este puede ser uno de los siguientes valores:

once: ejecutar solo una vez y no volver a ejecutar para un nuevo instance-id

instance: ejecutar solo una vez para un instance-id dado y volver a ejecutar para un nuevo instance-id

always: ejecutar cada arranque

nombre
Un nombre para darle al comando a ejecutar para que aparezca en los registros.
cmd [ arg1 [ arg2 [...]]]
El comando real a ejecutar seguido de cualquier argumento adicional.
