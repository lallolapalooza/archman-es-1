subrutina clatrs (uplo, trans, diag, normin, n, a, lda, x, scale, cnorm, info)
CLATRS resuelve un sistema de ecuaciones triangular con el factor de escala establecido para prevenir el desbordamiento.

Documentación de Función/Subrutin

a

subrutina clatrs (character uplo, character trans, character diag, character normin, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer

info)

CLATRS resuelve un sistema de ecuaciones triangular con el factor de escala establecido para prevenir el

desbordamiento.

Propósito

: 
!>
!> CLATRS resuelve uno de los sistemas triangulares
!>
!>    A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b,
!>
!> con escala para prevenir el desbordamiento.  Aquí A es una matriz
!> triangular superior o inferior, A**T denota la transpuesta de A, A**H
!> denota la transpuesta conjugada de A, x y b son vectores de n
!> elementos, y s es un factor de escala, usualmente menor o igual a 1,
!> elegido de modo que los componentes de x serán menores que el umbral
!> de desbordamiento.  Si el problema sin escalar no causará
!> desbordamiento, se llama a la rutina de BLAS de Nivel 2 CTRSV.  Si la
!> matriz A es singular (A(j,j) = 0 para algún j), entonces s se
!> establece a 0 y se devuelve una solución no trivial a A*x = 0.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!
>

TRAN

S 
!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b     (Sin transponer)
!>          = 'T':  Resolver A**T * x = s*b  (Transponer)
!>          = 'C':  Resolver A**H * x = s*b  (Transponer conjugada)
!
>

DIA

G 
!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!
>

NORMI

N 
!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de columna a la entrada
!>          = 'N':  CNORM no está establecido a la entrada.  A la salida,
!>                  las normas serán calculadas y almacenadas en CNORM.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte triangular
!>          superior n por n principal del arreglo A contiene la matriz
!>          triangular superior, y la parte estrictamente triangular
!>          inferior de A no es referenciada.  Si UPLO = 'L', la parte
!>          triangular inferior n por n principal del arreglo A contiene
!>          la matriz triangular inferior, y la parte estrictamente
!>          triangular superior de A no es referenciada.  Si DIAG = 'U',
!>          los elementos diagonales de A tampoco son referenciados y se
!>          asume que son 1.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max (1,N).
!
>

X 
!>          X es un arreglo COMPLEX, dimensión (N)
!>          A la entrada, el lado derecho b del sistema triangular.
!>          A la salida, X es sobrescrito por el vector solución x.
!
>

SCAL

E 
!>          SCALE es REAL
!>          El factor de escala s para el sistema triangular
!>             A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b.
!>          Si SCALE = 0, la matriz A es singular o está mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.
!
>

CNOR

M 
!>          CNORM es un arreglo REAL, dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte fuera de la diagonal de la j-ésima
!>          columna de A.  Si TRANS = 'N', CNORM(j) debe ser mayor o igual
!>          a la norma infinita, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte fuera de la diagonal de la
!>          j-ésima columna de A.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!
>

Detalles

Adicionales: 
!>
!>  Se calcula una cota aproximada para x; si esa es menor que el
!>  desbordamiento, se llama a CTRSV, de lo contrario, se usa código
!>  específico que verifica posibles desbordamientos o divisiones por
!>  cero en cada operación.
!>
!>  Se usa un esquema por columnas para resolver A*x = b.  El algoritmo
!>  básico si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!>  Definir cotas sobre los componentes de x después de j iteraciones del
!>  bucle:
!>     M(j) = cota sobre x[1:j]
!>     G(j) = cota sobre x[j+1:n]
!>  Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!>  Entonces para la iteración j+1 tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  donde CNORM(j+1) es mayor o igual a la norma infinita de la columna
!>  j+1 de A, sin contar la diagonal.  Por lo tanto
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Dado que |x(j)| <= M(j), usamos la rutina de BLAS de Nivel 2 CTRSV
!>  si el recíproco del mayor M(j), j=1,..,n, es mayor que
!>  max(desbordamiento inferior, 1/desbordamiento superior).
!>
!>  La cota sobre x(j) también se usa para determinar cuándo un paso en
!>  el método por columnas puede realizarse sin temor a desbordamiento.
!>  Si la cota calculada es mayor que una constante grande, x se escala
!>  para prevenir el desbordamiento, pero si la cota desborda, x se
!>  establece a 0, x(j) a 1, y scale a 0, y se encuentra una solución
!>  no trivial a A*x = 0.
!>
!>  De manera similar, se usa un esquema por filas para resolver
!>  A**T *x = b  o  A**H *x = b.  El algoritmo básico para A triangular
!>  superior es
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       end
!>
!>  Calculamos simultáneamente dos cotas
!>       G(j) = cota sobre ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = cota sobre x(i), 1<=i<=j
!>
!>  Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y
!>  añadimos la restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!>  Entonces la cota sobre x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  y podemos llamar con seguridad a CTRSV si 1/M(n) y 1/G(n) son ambos
!>  mayores que max(desbordamiento inferior, 1/desbordamiento superior).
!
>
