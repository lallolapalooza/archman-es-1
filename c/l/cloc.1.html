cloc(1) Comandos de Usuario cloc(1)

NOMBRE

cloc - Contar, o computar diferencias de, líneas de código fuente y comentarios.

SINOPSIS

cloc [opciones] <ARCHIVO|DIRECTORIO> ...

DESCRIPCIÓN

Cuenta, o computa diferencias de, líneas físicas de código fuente en los archivos dados (pueden ser archivos como tarballs comprimidos o archivos zip, o hashes de commits de git o nombres de ramas) y/o recursivamente debajo de los directorios dados. Está escrito completamente en Perl, usando solo módulos de la distribución estándar.

OPCIONES

Opciones de entrada

Para contar la entrada estándar, use el nombre de archivo especial - y ya sea --stdin-name=ARCHIVO para decirle a cloc el nombre del archivo que se está canalizando, o --force-lang=IDIOMA para aplicar el contador IDIOMA a toda la entrada.

--extract-with=CMD
Esta opción solo es necesaria si cloc no puede determinar cómo extraer el contenido de los archivos de entrada por sí mismo. Use CMD para extraer archivos binarios (por ejemplo: .tar.gz, .zip, .Z). Use el literal '>ARCHIVO<' como un marcador de posición para los archivos reales que se van a extraer. Por ejemplo, para contar líneas de código en los archivos de entrada gcc-4.2.tar.gz perl-5.8.8.tar.gz en Unix use: 
--extract-with='gzip -dc >ARCHIVO< | tar xf -

o, si tiene GNU tar:

--extract-with='tar zxf >ARCHIVO<'

y en Windows, use, por ejemplo:

--extract-with="\"c:\Program Files\WinZip\WinZip32.exe\" -e -o >ARCHIVO<
--list-file=ARCHIVO
Tome la lista de nombres de archivos y/o directorios a procesar de ARCHIVO, que tiene un nombre de archivo/directorio por línea. Solo se cuentan las coincidencias exactas; los nombres de ruta relativos se resolverán comenzando desde el directorio donde se invoca cloc. Establezca ARCHIVO a - para leer nombres de archivo desde una tubería STDIN. Vea también --exclude-list-file, --config.
--diff-list-file=ARCHIVO
Tome los pares de nombres de archivo a comparar de ARCHIVO, cuyo formato coincide con la salida de --diff-alignment. (Ejecute con esa opción para ver un ejemplo.) El identificador de idioma al final de cada línea se ignora. Esto habilita el modo --diff y omite la lógica de alineación de pares de archivos. Vea también --config.
--vcs=VCS
Invoca una llamada al sistema a VCS para obtener una lista de archivos sobre los que trabajar. Si VCS es 'git', invocará 'git ls-files' para obtener una lista de archivos y 'git submodule status' para obtener una lista de submodules cuyos contenidos se ignorarán. Vea también --git que acepta hashes de commits de git y nombres de ramas. Si VCS es 'svn' entonces invocará 'svn list -R'. El beneficio principal es que cloc omitirá los archivos explícitamente excluidos por la herramienta de versionado en cuestión, es decir, aquellos en .gitignore o que tienen la propiedad svn:ignore. Alternativamente, VCS puede ser cualquier comando del sistema que genere una lista de archivos. Nota: cloc debe estar en un directorio que pueda leer los archivos tal como los devuelve VCS. cloc no descargará archivos de repositorios remotos. 'svn list -R' puede referirse a un repositorio remoto para obtener nombres de archivo (y por lo tanto puede requerir autenticación al repositorio remoto), pero los archivos en sí deben ser locales. Establecer VCS a 'auto' selecciona entre 'git' y 'svn' (o ninguno) dependiendo de la presencia de un subdirectorio .git o .svn debajo del directorio donde se invoca cloc.
--unicode
Comprueba si los archivos binarios contienen texto ASCII expandido Unicode. Esto causa una caída notable en el rendimiento.

Opciones de procesamiento

--autoconf
Cuenta archivos .in (como los procesados por GNU autoconf) de lenguajes reconocidos. Vea también --no-autogen.
--by-file
Informa resultados para cada archivo fuente encontrado.
--by-file-by-lang
Informa resultados para cada archivo fuente encontrado además de informar por idioma.
--config ARCHIVO
Lee los modificadores de línea de comandos de ARCHIVO en lugar de la ubicación predeterminada de ~/.config/cloc/options.txt. El archivo debe contener un modificador, junto con argumentos (si los hay), por línea. Las líneas en blanco y las líneas que comienzan con '#' se omiten. Las opciones dadas en la línea de comandos tienen prioridad sobre las entradas leídas del archivo. Si también se proporciona un directorio con alguno de estos modificadores: --list-file, --exclude-list-file, --read-lang-def, --force-lang-def, --diff-list-file y existe un archivo de configuración en ese directorio, tendrá prioridad sobre ~/.config/cloc/options.txt.
--count-and-diff SET1 SET2
Primero realiza recuentos de código directos de los archivos fuente de SET1 y SET2 por separado, luego realiza una diferencia de estos. Las entradas pueden ser pares de archivos, directorios o archivos. Si se dan --out o --report-file, se crearán tres archivos de salida, uno para cada uno de los dos recuentos y uno para la diferencia. Vea también --diff, --diff-alignment, --diff-timeout, --ignore-case, --ignore-whitespace.
--diff SET1 SET2
Calcula las diferencias en código y comentarios entre los archivos fuente de SET1 y SET2. Las entradas pueden ser pares de archivos, directorios o archivos. Use --diff-alignment para generar una lista que muestre qué pares de archivos se compararon. Vea también --count-and-diff, --diff-alignment, --diff-timeout, --ignore-case, --ignore-whitespace.
--diff-timeout N
Ignora los archivos que tardan más de N segundos en procesarse. El valor predeterminado es 10 segundos. Establecer N a 0 permite tiempo ilimitado. (Archivos grandes con muchas líneas repetidas pueden hacer que Algorithm::Diff::sdiff() tarde horas.)
--docstring-as-code
cloc considera que las cadenas de documentación (docstrings) son comentarios, pero esto no siempre es correcto, ya que las cadenas de documentación representan cadenas regulares cuando aparecen en el lado derecho de una asignación o como argumentos de función. Este modificador fuerza que las cadenas de documentación se cuenten como código.
--follow-links
[Solo Unix] Sigue enlaces simbólicos a directorios (los enlaces simbólicos a archivos siempre se siguen).
--force-lang=IDIOMA[,EXT]
Procesa todos los archivos que tienen una extensión EXT con el contador para el idioma IDIOMA. Por ejemplo, para contar todos los archivos .f con el contador de Fortran 90 (que espera que los archivos terminen en .f90) en lugar del contador predeterminado de Fortran 77, use: 
--force-lang="Fortran 90",f

Si EXT se omite, cada archivo se contará con el contador IDIOMA. Esta opción se puede especificar varias veces (pero eso solo es útil cuando se proporciona EXT en cada ocasión). Vea también --script-lang, --lang-no-ext.

--force-lang-def=ARCHIVO
Carga los filtros de procesamiento de idioma desde ARCHIVO, y luego usa esos filtros en lugar de los filtros integrados. Nota: los idiomas que se mapean a la misma extensión de archivo (por ejemplo: MATLAB/Objective-C/MUMPS; Pascal/PHP; Lisp/OpenCL; Lisp/Julia; Perl/Prolog) se omitirán ya que requieren procesamiento adicional que no se expresa en los archivos de definición de idioma. Use --read-lang-def para definir nuevos filtros de idioma sin reemplazar los filtros integrados (vea también --write-lang-def, --write-lang-def-incl-dup).
--git
Fuerza que las entradas se interpreten como objetivos de git (hashes de commit, nombres de rama, etc.) si no se identifican primero como nombres de archivo o directorio. Esta opción anula la lógica --vcs=git si se proporciona; en otras palabras, --git obtiene su lista de archivos para trabajar directamente de git usando el hash o el nombre de la rama en lugar de 'git ls-files'. Esta opción se puede usar con --diff para realizar diferencias de recuento de líneas entre commits de git, o entre un commit de git y un archivo, directorio o archivo. Use -v/--verbose para ver los comandos del sistema git que cloc emite.

Los valores negativos son iguales a los valores positivos pero retienen, en lugar de eliminar, el archivo JSON intermedio que se escribe. El nombre del archivo JSON se genera aleatoriamente a menos que se indique --out/--report-file. Los formatos son:
1: por lenguaje (igual que la salida predeterminada de cloc)
2: por lenguaje con una columna extra para el total de líneas
3: por archivo con lenguaje
4: por archivo con una columna de total de líneas
5: por archivo con lenguaje y una columna de total de
líneas
