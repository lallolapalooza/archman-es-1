Clamdtop(1) Clam AntiVirus Clamdtop(1)

NOMBRE

clamdtop - monitoriza el demonio de Clam AntiVirus

SINOPSIS

clamdtop [opciones] [clamdspec ...]

DESCRIPCIÓN

clamdtop es una herramienta para monitorizar uno o varios clamd(s). Tiene una interfaz ncurses (a color), que muestra los trabajos en la cola de clamd, el uso de memoria, e información sobre la base de datos de firmas cargada. Puede especificar en la línea de comandos a qué clamd(s) debe conectarse. Por defecto, intentará conectarse al clamd local tal como está definido en clamd.conf.

OPCIONES

-h, --help
Muestra información de ayuda y sale.
-V, --version
Imprime el número de versión y sale.
--config-file=ARCHIVO
Lee la configuración de clamd desde ARCHIVO, para determinar cómo conectarse a él.
clamdspec
Especifica el clamd al que conectarse: ya sea una ruta al socket local (de dominio unix) de clamd, o una dirección IP y un número de puerto (que por defecto es 3310) para conectarse a un clamd local o remoto usando TCP/IP.

DESCRIPCIÓN GENERAL

TECLAS:

H

Muestra una pantalla de ayuda breve, describiendo el significado de los diversos elementos en la pantalla.

Q

Sale de clamdtop

R

Restablece los valores máximos.

flecha arriba, flecha abajo

Si está monitorizando varios clamds, clamdtop mostrará una pantalla de resumen por defecto. Puede usar las teclas flecha arriba y flecha abajo para recorrer cada clamd individualmente, y la pantalla de resumen. Una barra azul resaltará el clamd que se está mostrando actualmente en detalle. En la pantalla de resumen, ninguno de los clamds está seleccionado (por lo tanto, no hay barra azul), y puede ver los elementos de la cola de todos los clamds.

La barra superior

Muestra la versión de clamdtop y la hora actual. Clamdtop actualiza la pantalla una vez cada 2 segundos.

La lista de clamds

Muestra los clamds a los que clamdtop está conectado, y estadísticas sobre ellos.

NO
Número único de clamd
CONNTIME
Cuánto tiempo lleva clamdtop conectado (se restablece al reconectar)
LIV
Número total de hilos activos
IDL
Número total de hilos inactivos
QUEUE
Número de elementos en la cola
MAXQ
Número máximo de elementos observados en la cola
MEM
Uso total de memoria (si está disponible)
HOST
Qué clamd, local significa socket unix
ENGINE
Versión del motor
DBVER
Versión de la base de datos
DBTIME
Hora de publicación de la base de datos

Vista detallada de Clamd

Hilos primarios activos
El número de hilos que están ejecutando comandos o escaneando.
Hilos primarios inactivos
El número de hilos que están inactivos, esperando comandos. Saldrán después de IdleTimeout (30 segundos).
Hilos primarios máx
El número máximo de hilos configurados.
Elementos de la cola
El número de elementos (trabajos de escaneo) en la cola de clamd que están esperando a un hilo libre para ser procesados.
Máximo de la cola
El número máximo de elementos observados en la cola de clamd.

La vista de uso de memoria

Si está disponible, mostrará detalles sobre el uso de memoria de clamd:

Mem heap
La cantidad de memoria usada por libc desde el heap en Megabytes.
Mem mmap
La cantidad de memoria usada por libc desde memoria asignada con mmap en Megabytes.
Mem unused
La cantidad de memoria que puede ser recuperada por libc.
Libc used
La cantidad de memoria útil asignada por libc.
Libc free
La cantidad de memoria asignada por libc, que no puede ser liberada debido a fragmentación.
Libc total
La cantidad de memoria asignada por libc del sistema en total.
Pool count
El número de regiones mmap asignadas por el asignador de pool de memoria de clamd (para la base de datos de firmas).
Pool used
La cantidad de memoria usada por el asignador de pool de memoria de clamd (para la base de datos de firmas).
Total
La cantidad total de memoria asignada por el asignador de pool de memoria de clamd.

La cola de trabajos de clamd

COMMAND
Tipo de comando que se está ejecutando, STATS es clamdtop, SCAN/CONTSCAN/FILDES/MULTISCAN es el escaneo de un archivo/directorio, MULTISCANFILE es el escaneo de un elemento por un trabajo MULTISCAN.
QUEUEDSINCE
El tiempo desde que el comando fue encolado, hasta ahora.
FILE
El nombre del archivo que se está procesando (si aplica).

EJEMPLOS

(1) Para conectarse al clamd configurado en el clamd.conf por defecto:

clamdtop

(2) Para conectarse al clamd configurado en otro clamd.conf:

clamdtop --config-file=/ruta/a/clamd.conf

(3) Para conectarse a un clamd ejecutándose en otra máquina (192.168.0.3) en la LAN:

clamdtop 192.168.0.3

(4) Para conectarse a un clamd ejecutándose en otra máquina (192.168.0.3) en un puerto no predeterminado (3410):

clamdtop 192.168.0.3:3410

(5) Para monitorizar el clamd local y 2 otros clamds remotos sobre TCP/IP:

clamdtop localhost 192.168.0.3 192.168.0.4

NOTAS

clamdtop usa colores si el terminal es capaz de mostrarlos. Si sabe que su terminal es capaz de mostrar colores, pero no ve ninguno, entonces compruebe que su TERM variable de entorno esté configurada correctamente. Por ejemplo, intente configurarla como TERM=xterm-color si está en un entorno similar a xterm. Se ha añadido soporte para IPv6. Si especifica una dirección IPv6, por favor use las reglas normales de direccionamiento IPv6. Si especifica tanto una dirección IPv6 como una combinación de puerto, encapsule la dirección IPv6 entre corchetes corchetes (por ejemplo, [::1]:3410).

CÓDIGOS DE RETORNO

0 : Terminación normal

>0: Ocurrió un error.
