Documentación de la función/subrutina

subroutine claghe (integer n, integer k, real, dimension( * ) d, complex, dimension( lda, * ) a, integer lda, integer, dimension( 4 ) iseed, complex, dimension( * ) work, integer info)

CLAGHE

Propósito:

!>
!> CLAGHE genera una matriz hermitiana compleja A, multiplicando previamente y
!> posteriormente con una matriz unitaria aleatoria:
!> A = U*D*U'. El semi-ancho de banda puede ser reducido entonces a k mediante
!> transformaciones unitarias adicionales.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

K

!>          K es INTEGER
!>          El número de subdiagonales no nulas dentro de la banda de A.
!>          0 <= K <= N-1.
!>

D

!>          D es array REAL, dimension (N)
!>          Los elementos de la diagonal de la matriz diagonal D.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          La matriz hermitiana compleja A generada de n por n (se almacena
!>          la matriz completa).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= N.
!>

ISEED

!>          ISEED es array INTEGER, dimension (4)
!>          En la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe
!>          ser impar.
!>          En la salida, la semilla se actualiza.
!>

WORK

!>          WORK es array COMPLEX, dimension (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
