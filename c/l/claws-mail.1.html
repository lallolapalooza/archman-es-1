DESCRIPCIÓ

N
Claws Mail es un cliente de correo electrónico (y lector de noticias) basado en GTK, que se ejecuta en el sistema de ventanas X, y cuyo objetivo
es:

• Respuesta rápida
• Interfaz elegante y sofisticada
• Fácil configuración, operación intuitiva
• Amplia gama de
funciones
Las funciones implementadas actualmente
incluyen:
• Soporte para POP3
• Soporte para IMAP4rev1
• Cliente de NetNews integrado
• Manejo ilimitado de múltiples cuentas
• Visualización de hilos de conversación
• Filtrado
• MIME (adjuntos)
• Visor de imágenes integrado
• Soporte para X-Face y Face (en color)
• Soporte para múltiples carpetas MH
• Importación / exportación de mbox
• Soporte para editor externo
• Cola de mensajes
• Comprobación automática de correo
• Función de mensajes de borrador
• Función de plantillas
• Ajuste de líneas
• URI clicables
• Libreta de direcciones basada en XML
• Soporte para LDAP, vCard y JPilot
• Gestión de mensajes nuevos y no leídos
• Asignación de teclas tipo Mew/Wanderlust
• Impresión
• Soporte para autenticación APOP
• Soporte para autenticación SMTP
• Soporte para SSL (POP3, SMTP, IMAP4rev1)
• Soporte para IPv6
• Arrastrar y soltar (parcialmente implementado)
• Soporte para GnuPG
• Soporte para automake + autoconf
• Internacionalización de los mensajes de la interfaz mediante gettext
• Soporte para muchos conjuntos de caracteres, incluido UTF-8 (Unicode)
• Soporte
para com
plementos

--compose "mailto:%t?subject=%s&cc=%c&body=%b

Esta sintaxis se puede usar en navegadores web y en la CLI para abrir una ventana de composición pre-rellenada. Los campos posibles después del destinatario son: subject (asunto), from (de), cc, bcc, in-reply-to, body (cuerpo), insert (inserta un archivo en la parte del cuerpo, requiere una ruta absoluta), attach (adjunta un archivo, requiere una ruta absoluta, véase también: --attach)

archivo.
