NOMBRE

clamsubmit - Utilidad de envío de archivos para ClamAV

SINOPSIS

clamsubmit [opciones]

DESCRIPCIÓN

clamsubmit envía archivos a Sourcefire para su posterior análisis.

OPCIONES

-h, -?
Muestra la ayuda en stderr y sale.
-e EMAIL
Opción requerida para establecer la dirección de correo electrónico para el envío.
-n ARCHIVO
Envía un archivo que se informa como falso negativo (ClamAV informa LIMPIO). ARCHIVO puede ser - para especificar stdin. Mutuamente exclusivo con -p.
-N NOMBRE
Opción requerida para establecer el nombre del remitente para el envío.
-p ARCHIVO
Envía un archivo que se informa como falso positivo (ClamAV marca el archivo como virus). ARCHIVO puede ser - para especificar stdin. Mutuamente exclusivo con -n.
-V VIRUS
El nombre del virus detectado como falso positivo. Esta opción es requerida para envíos de falsos positivos.

VARIABLES DE ENTORNO

clamsubmit utiliza las siguientes variables de entorno:

CURL_CA_BUNDLE
(Solo Linux/Unix, excluyendo macOS) Puede configurarse con la ruta a un archivo (paquete) que contenga uno o más certificados CA. Esto anulará la ruta de certificados predeterminada de openssl.
Tenga en cuenta que la variable de entorno CURL_CA_BUNDLE también es utilizada por la herramienta de línea de comandos curl para el mismo propósito.
