Class::Factory::Util(3pm) Documentación de Contribución del Usuario de Perl Class::Factory::Util(3pm)

NOMBRE

Class::Factory::Util - Proporciona métodos de utilidad para clases de fábrica

SINOPSIS

package My::Class;
use Class::Factory::Util;
My::Class->subclasses;

DESCRIPCIÓN

Este módulo exporta un método útil para clases de fábrica.

USO

Cuando este módulo se carga, crea un método en su llamante llamado subclasses(). Este método devuelve una lista de las subclases disponibles para el paquete. Lo hace buscando en @INC así como en el directorio que contiene al llamante, y encontrando cualquier módulo en los subdirectorios inmediatos del módulo llamante.

Así que si tienes los módulos "Foo::Base", "Foo::Base::Bar" y "Foo::Base::Baz", entonces el valor de retorno de "Foo::Base->subclasses()" sería "Bar" y "Baz".
