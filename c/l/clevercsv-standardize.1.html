CLEVERCSV-STANDARDIZE(1) Manual de Clevercsv CLEVERCSV-STANDARDIZE(1)

NOMBRE

clevercsv-standardize - Convierte un archivo CSV a uno que cumpla con RFC-4180

SINOPSIS

clevercsv standardize [-e CODIFICACION | --encoding=CODIFICACION]
                      [-E CODIFICACION_OBJETIVO | --target-encoding=CODIFICACION_OBJETIVO]
                      [-i | --in-place] [-n NUM_CARACTERES | --num-chars=NUM_CARACTERES]
                      [-o SALIDA | --output=SALIDA] [-t | --transpose]
                      <ruta [ruta ...]>

DESCRIPCIÓN

El comando standardize se puede utilizar para convertir un archivo CSV no estándar al formato estándar RFC-4180 [1]. Al usar la opción --in-place, el código de retorno de CleverCSV se puede usar para verificar si un archivo fue alterado o no. El código de retorno será 2 si el archivo fue alterado y 0 en caso contrario.

[1]: https://tools.ietf.org/html/rfc4180

OPCIONES

-h, --help

muestra este mensaje de ayuda y sale

-e, --encoding

La codificación del archivo CSV dado se detecta automáticamente usando chardet. Aunque chardet es increíblemente preciso, no es perfecto. En los raros casos en que comete un error al detectar la codificación del archivo, puede anular la codificación proporcionándola a través de esta bandera. Para este comando, la codificación proporcionada también se usará para los archivos de salida. Cuando solo se proporciona una codificación, se utilizará para todos los archivos dados en la línea de comandos. Cuando se proporcionan múltiples codificaciones, el número debe corresponder al número de archivos proporcionados como entrada.

-E, --target-encoding

Si se omite, la codificación del archivo de salida será la misma que la del archivo original.

-i, --in-place

Estandariza y sobrescribe los archivos de entrada

-n, --num-chars

En archivos CSV grandes, la detección de dialecto puede ser a veces un poco lenta debido a la gran cantidad de dialectos posibles a considerar. Para aliviar esto, puede limitar el número de caracteres a utilizar para la detección.

Un aspecto a tener en cuenta es que CleverCSV puede necesitar leer un número específico de caracteres para poder inferir correctamente el dialecto. Por ejemplo, en el archivo ``imdb.csv`` del repositorio de GitHub, el dialecto correcto solo se puede encontrar después de leer al menos 66 líneas del archivo. Por lo tanto, si hay disponibilidad para ejecutar CleverCSV en el archivo completo, generalmente se recomienda.

-o, --output

Los archivos de salida donde escribir los archivos de entrada estandarizados. El orden de los archivos de entrada y el orden de los archivos de salida deben coincidir si esta opción se usa con más de un archivo de entrada.

-t, --transpose

Transpone las columnas de los archivos de entrada antes de escribir

<ruta>

Ruta a uno o más archivos CSV
