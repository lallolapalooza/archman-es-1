NOMBRE

Class::Data::Inheritable - Datos de clase heredables y anulables

SINOPSIS

package Stuff;
use base qw(Class::Data::Inheritable);
# Configura DataFile como datos de clase heredables.
Stuff->mk_classdata('DataFile');
# Declara la ubicación del archivo de datos para esta clase.
Stuff->DataFile('/etc/stuff/data');
# O, todo de una vez:
Stuff->mk_classdata(DataFile => '/etc/stuff/data');

DESCRIPCIÓN

Class::Data::Inheritable se utiliza para crear accesores/mutadores para datos de clase. Es decir, si quieres almacenar algo sobre tu clase en general (en lugar de sobre un objeto individual). Estos datos se heredan luego por tus subclases y se pueden anular.

Por ejemplo:

Pere::Ubu->mk_classdata('Suitcase');

generará el método Suitcase() en la clase Pere::Ubu.

Este nuevo método puede usarse para obtener y establecer un dato de clase.

Pere::Ubu->Suitcase('Red');
$suitcase = Pere::Ubu->Suitcase;

La parte interesante ocurre cuando una clase hereda de Pere::Ubu:

package Raygun;
use base qw(Pere::Ubu);

# La maleta de Raygun es Roja.
$suitcase = Raygun->Suitcase;

Raygun hereda sus datos de clase Suitcase de Pere::Ubu.

La herencia de datos de clase funciona de forma análoga a la herencia de métodos. Mientras Raygun no "anule" sus datos de clase heredados (usando Suitcase() para establecer un nuevo valor) seguirá usando lo que esté establecido en Pere::Ubu y heredará cambios posteriores:

# Las maletas de Raygun y Pere::Ubu ahora son Azules
Pere::Ubu->Suitcase('Blue');

Sin embargo, si Raygun decide establecer su propio Suitcase(), ahora ha "anulado" Pere::Ubu y está por su cuenta, al igual que si hubiera anulado un método:

# Raygun tiene una maleta naranja, la de Pere::Ubu sigue siendo Azul.
Raygun->Suitcase('Orange');

Ahora que Raygun ha anulado Pere::Ubu, los cambios posteriores de Pere::Ubu ya no afectan a Raygun.

# Raygun todavía tiene una maleta naranja, pero Pere::Ubu usa Samsonite.
Pere::Ubu->Suitcase('Samsonite');

Métodos

mk_classdata

Class->mk_classdata($nombre_accessor_datos);
Class->mk_classdata($nombre_accessor_datos => $valor);

Este es un método de clase utilizado para declarar nuevos accesores de datos de clase. Se creará un nuevo accesor en la Clase usando el nombre de $nombre_accessor_datos, y opcionalmente se establecerá inicialmente con el valor dado.

Para facilitar la anulación, mk_classdata crea un alias para el accessor, _field_accessor(). Así, Suitcase() tendría un alias _Suitcase_accessor() que hace exactamente lo mismo que Suitcase(). Esto es útil si quieres alterar el comportamiento de un único accessor y aún así obtener los beneficios de los datos de clase heredables. Por ejemplo.

sub Suitcase {
    my($self) = shift;
    warn "Tragedia de moda" if @_ and $_[0] eq 'Plaid';
    $self->_Suitcase_accessor(@_);
}
