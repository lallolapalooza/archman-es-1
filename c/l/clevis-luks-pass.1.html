NOMBRE

clevis luks pass - Extrae la contraseña utilizada para vincular una ranura particular en un dispositivo LUKS

SINOPSIS

clevis luks pass -d DEV -s SLT

DESCRIPCIÓN

El comando clevis luks pass extrae la contraseña utilizada para vincular una ranura particular en un dispositivo LUKS. Por ejemplo:

clevis luks pass -d /dev/sda1 -s 1

OPCIONES

•-d DEV : El dispositivo LUKS sobre el cual extraer una contraseña.
•-s SLT : La ranura a utilizar para extraer la contraseña.

EJEMPLO

clevis luks pass -d /dev/sda1 -s 1
<contraseña aquí>

Tenga en cuenta que la salida de clevis luks pass puede no ser imprimible, en cuyo caso sería mejor redirigir su salida a un archivo y utilizarla como archivo de clave junto con cryptsetup. Por ejemplo:

clevis luks pass -d /dev/sda1 -s 1 > slot1-contraseña

Y el archivo slot1-contraseña contendrá la contraseña asociada con la ranura #1 en /dev/sda1.
