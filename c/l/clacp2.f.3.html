Funciones/Subrutinas


subrutina clacp2 (uplo, m, n, a, lda, b, ldb)

CLACP2 copia toda o parte de una matriz bidimensional real a una matriz compleja.

Documentación de función/subrutina

subrutina clacp2 (carácter uplo, entero m, entero n, real, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldb, * ) b, entero ldb)

CLACP2 copia toda o parte de una matriz bidimensional real a una matriz compleja.

Propósito:

!>
!> CLACP2 copia toda o parte de una matriz bidimensional real A a una
!> matriz compleja B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica la parte de la matriz A que se copiará a B.
!>          = 'U':      Parte triangular superior
!>          = 'L':      Parte triangular inferior
!>          En caso contrario: Toda la matriz A
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es una matriz REAL, dimensión (LDA,N)
!>          La matriz A de m por n.  Si UPLO = 'U', solo se accede al
!>          trapecio superior; si UPLO = 'L', solo se accede al trapecio
!>          inferior.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es una matriz COMPLEX, dimensión (LDB,N)
!>          Al salir, B = A en las ubicaciones especificadas por UPLO.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>
