DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine clacn2 (integer n, complex, dimension( * ) v, complex, dimension( * ) x, real est, integer kase, integer, dimension( 3 ) isave)

CLACN2 estima la norma 1 de una matriz cuadrada compleja, usando comunicación inversa para evaluar productos matriz-vector.

Propósito:

!>
!> CLACN2 estima la norma 1 de una matriz compleja cuadrada A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es ENTERO
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es un array COMPLEJO, dimensión (N)
!>         En el retorno final, V = A*W,  donde  EST = norm(V)/norm(W)
!>         (W no se devuelve).
!>

X

!>          X es un array COMPLEJO, dimensión (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         donde A**H es la transpuesta conjugada de A, y CLACN2 debe ser
!>         llamada de nuevo con todos los demás parámetros sin cambios.
!>

EST

!>          EST es REAL
!>         En la entrada con KASE = 1 o 2 y ISAVE(1) = 3, EST debe ser
!>         sin cambios desde la llamada anterior a CLACN2.
!>         En la salida, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es ENTERO
!>         En la llamada inicial a CLACN2, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**H * X.
!>         En el retorno final de CLACN2, KASE será nuevamente 0.
!>

ISAVE

!>          ISAVE es un array ENTERO, dimensión (3)
!>         ISAVE se utiliza para guardar variables entre llamadas a SLACN2.
!>
