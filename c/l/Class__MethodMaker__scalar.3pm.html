Class::MethodMaker::scalar(3) Documentación de Perl contribuida por el usuario Class::MethodMaker::scalar(3)

NOMBRE

Class::Method::scalar - Crear métodos para manejar un valor escalar.

SINOPSIS

package MyClass;
use Class::MethodMaker
  [ scalar => [qw/ a -static s /]];
sub new {
  my $class = shift;
  bless {}, $class;
}
package main;
my $m = MyClass->new;
my $a, $x;
$a = $m->a;       # *undef*
$x = $m->a_isset; # falso
$a = $m->a(1);    # 1
$m->a(3);
$x = $m->a_isset; # verdadero
$a = $m->a;       # 3
$a = $m->a(5);     # 5;
$m->a_reset;
$x = $m->a_isset; # falso

DESCRIPCIÓN

Crea métodos para manejar valores escalares en un objeto. Para un componente llamado "x", crea por defecto los métodos "x", "x_reset", "x_isset", "x_clear".

Los métodos disponibles son:

"*"

$m->a(3);
$a = $m->a;       # 3
$a = $m->a(5);     # 5;

Creado por defecto. Si se proporciona un argumento, el componente se establece a ese valor. El método devuelve el valor del componente (después de la asignación a un valor proporcionado, si es apropiado).

*_reset

$m->a_reset;

Creado por defecto. Restablece el componente a su valor predeterminado. Normalmente, esto significa que *_isset devolverá falso, y "*" devolverá undef. Si "-default" está en vigor, el componente se establecerá al valor predeterminado, y *_isset devolverá verdadero. Si "-default_ctor" está en vigor, se invocará la subrutina predeterminada, y su valor de retorno se usará para establecer el valor del componente, y *_isset devolverá verdadero.

Nota avanzada: en realidad, los valores predeterminados se asignan según sea necesario: normalmente, la próxima vez que se lea el valor de un componente.

*_isset

print $m->a_isset ? "verdadero" : "falso";

Creado por defecto. Si el componente está actualmente establecido. Esto es diferente de estar definido; inicialmente, el componente no está establecido (y si se lee, devolverá undef); puede establecerse a undef (que es un valor establecido, que también devuelve undef). Una vez establecido, la única forma de desestablecer el componente es con <*_reset>.

Si hay un valor predeterminado en vigor, entonces <*_isset> siempre devolverá verdadero.

*_clear

$m->a(5);
$a = $m->a;       # 5
$x = $m->a_isset; # verdadero
$m->a_clear;
$a = $m->a;       # *undef*
$x = $m->a_isset; # verdadero

Creado por defecto. Una abreviatura para establecer a undef. Tenga en cuenta que el componente se establecerá a undef, no se restablecerá, por lo que *_isset devolverá verdadero.

*_get

package MyClass;
use Class::MethodMaker
  [ scalar => [{'*_get' => '*_get'}, 'a'],
    new    => new, ];
package main;
my $m = MyClass->new;
$m->a(3);
$a = $m->a_get;     # 3
$a = $m->a_get(5);  # 3; ignora el argumento
$a = $m->a_get(5);  # 3; sin cambios por la llamada anterior

Creado bajo petición. Recupera el valor del componente sin establecerlo (ignora cualquier argumento pasado).

*_set

package MyClass;
use Class::MethodMaker
  [ scalar => [{'*_set' => '*_set'}, 'a'],
    new    => new, ];
package main;
my $m = MyClass->new;
$m->a(3);
$a = $m->a_set;     # *undef*
$a = $m->a_set(5);  # *undef*; el valor se establece pero no se devuelve
$a = $m->a;         # 5

Creado bajo petición. Establece el componente al primer argumento (o undef si no se proporciona ningún argumento). No devuelve ningún valor.
