CLATM

2

Propósito

: 
!>
!>    CLATM2 devuelve la entrada (I,J) de una matriz aleatoria de dimensión
!>    (M, N) descrita por los otros parámetros. Es llamada por la
!>    rutina CLATMR para construir matrices de prueba aleatorias. No se realiza
!>    verificación de errores en los parámetros, porque esta rutina es llamada en
!>    un bucle ajustado por CLATMR que ya ha verificado los parámetros.
!>
!>    El uso de CLATM2 difiere de CLATM3 en el orden en que el generador
!>    de números aleatorios es llamado para rellenar las entradas aleatorias de la matriz.
!>    Con CLATM2, el generador es llamado para rellenar la matriz
!>    pivoteada columna por columna. Con CLATM3, el generador es llamado para rellenar la
!>    matriz columna por columna, después de lo cual es pivoteada. Así, CLATM3 puede
!>    ser usada para construir matrices aleatorias que difieren solo en su
!>    orden de filas y/o columnas. CLATM2 es usada para construir matrices
!>    de banda mientras se evita llamar al generador de números aleatorios para
!>    entradas fuera de la banda (y por lo tanto generando números aleatorios
!>
!>    La matriz cuya entrada (I,J) es devuelta es construida como
!>    sigue (esta rutina solo calcula una entrada):
!>
!>      Si I está fuera de (1..M) o J está fuera de (1..N), devuelve cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Genera una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establece la diagonal a D.
!>
!>      Escala la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) como especificado por IGRADE.
!>
!>      Permuta, si se desea, las filas y/o columnas como especificado por
!>         IPVTNG e IWORK.
!>
!>      Convierte la matriz en banda para tener ancho de banda inferior KL y ancho de banda
!>         superior KU.
!>
!>      Establece entradas aleatorias a cero como especificado por SPARSE.
!
>

Parámetro

s
M 
!>          M es ENTERO
!>           Número de filas de la matriz. No modificado.
!
>

N 
!>          N es ENTERO
!>           Número de columnas de la matriz. No modificado.
!
>

I 
!>          I es ENTERO
!>           Fila de la entrada a ser devuelta. No modificado.
!
>

J 
!>          J es ENTERO
!>           Columna de la entrada a ser devuelta. No modificado.
!
>

K

L 
!>          KL es ENTERO
!>           Ancho de banda inferior. No modificado.
!
>

K

U 
!>          KU es ENTERO
!>           Ancho de banda superior. No modificado.
!
>

IDIS

T 
!>          IDIST es ENTERO
!>           A la entrada, IDIST especifica el tipo de distribución a ser
!>           usada para generar una matriz aleatoria.
!>           1 => partes real e imaginaria cada una UNIFORM( 0, 1 )
!>           2 => partes real e imaginaria cada una UNIFORM( -1, 1 )
!>           3 => partes real e imaginaria cada una NORMAL( 0, 1 )
!>           4 => número complejo uniforme en DISK( 0 , 1 )
!>           No modificado.
!
>

ISEE

D 
!>          ISEED es un arreglo ENTERO de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Cambiado en la salida.
!
>

D 
!>          D es un arreglo COMPLEJO de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificado.
!
>

IGRAD

E 
!>          IGRADE es ENTERO
!>           Especifica el escalado de la matriz como sigue:
!>           0  => sin escalado
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( CONJG(DL) )
!>           6  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!
>

D

L 
!>          DL es un arreglo COMPLEJO ( I o J, según corresponda )
!>           Factores de escala izquierdos para escalar la matriz.  No modificado.
!
>

D

R 
!>          DR es un arreglo COMPLEJO ( I o J, según corresponda )
!>           Factores de escala derechos para escalar la matriz.  No modificado.
!
>

IPVTN

G 
!>          IPVTNG es ENTERO
!>           A la entrada especifica las permutaciones de pivoteo como sigue:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!
>

IWOR

K 
!>          IWORK es un arreglo ENTERO ( I o J, según corresponda )
!>           Este arreglo especifica la permutación usada. La
!>           fila (o columna) en la posición K originalmente estaba en
!>           la posición IWORK( K ).
!>           Esto difiere de IWORK para CLATM3. No modificado.
!
>

SPARS

E 
!>          SPARSE es REAL
!>           Valor entre 0. y 1.
!>           A la entrada especifica la dispersión de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme ( 0, 1 ) x y se
!>           compara con SPARSE; si x es mayor la entrada de la matriz
!>           no cambia y si x es menor la entrada se establece
!>           a cero. Así, en promedio una fracción SPARSE de las
!>           entradas se establecerán a cero.
!>           No modificado.
!
>
