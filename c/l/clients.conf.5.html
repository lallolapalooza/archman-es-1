NOMBRE

clients.conf - Configuración del cliente FreeRADIUS

DESCRIPCIÓN

El archivo clients.conf contiene definiciones de clientes RADIUS.

La información de este archivo anula cualquier información proporcionada en los archivos obsoletos clients y naslist.

El formato del archivo es el mismo que el utilizado para radiusd.conf. Consulte radiusd.conf(5) para obtener más detalles.

Cada entrada de cliente RADIUS tiene la siguiente forma básica:

client <nombre-corto> {
       <atributo> = <valor>
 }

Los clientes tienen muchos parámetros de configuración. La mayoría están documentados en el propio archivo como comentarios. Esta página solo documenta el formato del archivo. Por favor, lea el propio archivo clients.conf para obtener más información.

El servidor acepta el formato antiguo de la versión 1.x, pero esa forma está obsoleta.

ARCHIVOS

/etc/raddb/clients.conf

/etc/raddb/radiusd.conf

VER TAMBIÉN

radiusd(8), radiusd.conf(5)

AUTOR

FreeRADIUS está escrito por el equipo de FreeRADIUS. http://freeradius.org/
