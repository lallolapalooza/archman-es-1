NOMBRE

clevis-luks-regen - Regenera una vinculación de clevis

SINOPSIS

clevis luks regen [-q] -d DEV -s SLT

DESCRIPCIÓN

El comando clevis luks regen regenera la vinculación de clevis para una ranura dada en un dispositivo LUKS, utilizando la misma configuración de la vinculación existente. Su operación se puede comparar con la ejecución de clevis luks unbind y clevis luks bind para volver a vincular dicha ranura y dispositivo. Esto es útil al rotar claves tang.

OPCIONES

•-d DEV : El dispositivo LUKS vinculado
•-s SLT : El número de ranura o ranura de clave para volver a vincular. Tenga en cuenta que requiere que dicha ranura esté actualmente vinculada por clevis.
•-q: No solicitar confirmación.

EJEMPLO

Comencemos usando clevis luks list para ver la configuración de vinculación actual en /dev/sda1:
# clevis luks list -d /dev/sda1
1: tang '{"url":"http://tang.server"}'
2: tpm2 '{"hash":"sha256","key":"ecc"}'
Vemos que la ranura 1 en /dev/sda1 tiene una vinculación tang con la siguiente configuración:
'{"url":"http://tang.server"}'
Ahora hagamos la re-vinculación de la ranura 1:
# clevis luks regen -d /dev/sda1 -s 1
Después de una operación exitosa, tendremos la nueva vinculación utilizando la misma configuración que ya estaba en vigor.
