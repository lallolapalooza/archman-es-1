CLAQZ2

Propósito:

!>
!> CLAQZ2 realiza AED
!>

Parámetros

ILSCHUR 
!>          ILSCHUR es LOGICAL
!>              Determina si se debe o no actualizar la forma completa de Schur
!>

ILQ

!>          ILQ es LOGICAL
!>              Determina si se debe o no actualizar la matriz Q
!>

ILZ

!>          ILZ es LOGICAL
!>              Determina si se debe o no actualizar la matriz Z
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, Q y Z.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI marcan las filas y columnas de (A,B) que
!>          deben ser normalizadas
!>

NW

!>          NW es INTEGER
!>          El tamaño deseado de la ventana de deflación.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA, N)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max( 1, N ).
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB, N)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max( 1, N ).
!>

Q

!>          Q es un arreglo COMPLEX, dimensión (LDQ, N)
!>

LDQ

!>          LDQ es INTEGER
!>

Z

!>          Z es un arreglo COMPLEX, dimensión (LDZ, N)
!>

LDZ

!>          LDZ es INTEGER
!>

NS

!>          NS es INTEGER
!>          El número de autovalores no convergidos disponibles para
!>          usar como desplazamientos.
!>

ND

!>          ND es INTEGER
!>          El número de autovalores convergidos encontrados.
!>

ALPHA

!>          ALPHA es un arreglo COMPLEX, dimensión (N)
!>          Cada escalar alpha que define un autovalor
!>          de GNEP.
!>

BETA

!>          BETA es un arreglo COMPLEX, dimensión (N)
!>          Los escalares beta que definen los autovalores de GNEP.
!>          Juntamente, las cantidades alpha = ALPHA(j) y
!>          beta = BETA(j) representan el j-ésimo autovalor del par de
!>          matrices (A,B), en una de las formas lambda = alpha/beta o
!>          mu = beta/alpha.  Dado que lambda o mu pueden desbordarse,
!>          en general no deberían ser calculados.
!>

QC

!>          QC es un arreglo COMPLEX, dimensión (LDQC, NW)
!>

LDQC

!>          LDQC es INTEGER
!>

ZC

!>          ZC es un arreglo COMPLEX, dimensión (LDZC, NW)
!>

LDZC

!>          LDZ es INTEGER
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO >= 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.  LWORK >= max(1,N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (N)
!>

REC

!>          REC es INTEGER
!>             REC indica el nivel de recursión actual. Debe establecerse
!>             a 0 en la primera llamada.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
