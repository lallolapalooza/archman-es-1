función real clanhs (norm, n, a, lda, work)
CLANHS devuelve el valor de la norma 1, norma de Frobenius, norma infinito, o el valor absoluto más grande de cualquier elemento de una matriz de Hessenberg superior.

Documentación de la función/subrutina

real función clanhs (carácter norm, entero n, complejo, dimensión( lda, * ) a, entero lda, real, dimensión( * ) work)

CLANHS devuelve el valor de la norma 1, norma de Frobenius, norma infinito, o el valor absoluto más grande de cualquier elemento de una matriz de Hessenberg superior.

Propósito:

!>
!> CLANHS  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz de Hessenberg A.
!>

Devuelve

CLANHS 
!>
!>    CLANHS = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma de matriz consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en CLANHS como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANHS se
!>          establece a cero.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          La matriz de Hessenberg superior n por n A; la parte de A debajo de la
!>          primera subdiagonal no se hace referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I'; de lo contrario, WORK no se
!>          hace referencia.
!>
