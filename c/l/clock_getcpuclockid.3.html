clock_getcpuclockid(3) Manual de Funciones de Biblioteca clock_getcpuclockid(3)

NOMBRE

clock_getcpuclockid - obtener la ID del reloj de tiempo de CPU de un proceso

BIBLIOTECA

Biblioteca C estándar (libc, -lc), desde glibc 2.17

Antes de glibc 2.17, Biblioteca de tiempo real (librt, -lrt)

SINOPSIS

#include <time.h>

int clock_getcpuclockid(pid_t pid, clockid_t *clockid);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

clock_getcpuclockid():

    _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

La función clock_getcpuclockid() obtiene la ID del reloj de tiempo de CPU del proceso cuyo ID es pid, y la devuelve en la ubicación apuntada por clockid. Si pid es cero, se devuelve la ID del reloj de tiempo de CPU del proceso que llama.

VALOR DE RETORNO

En caso de éxito, clock_getcpuclockid() devuelve 0; en caso de error, devuelve uno de los números de error positivos listados en ERRORES.

ERRORES

ENOSYS
El núcleo no admite la obtención del reloj de tiempo de CPU por proceso de otro proceso, y pid no especifica el proceso que llama.
EPERM
El llamador no tiene permiso para acceder al reloj de tiempo de CPU del proceso especificado por pid. (Especificado en POSIX.1-2001; no ocurre en Linux a menos que el núcleo no admita la obtención del reloj de tiempo de CPU por proceso de otro proceso).
ESRCH
No existe ningún proceso con el ID pid.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
clock_getcpuclockid () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

glibc 2.2. POSIX.1-2001.

NOTAS

Llamar a clock_gettime(2) con la ID del reloj obtenida mediante una llamada a clock_getcpuclockid() con un pid de 0, es lo mismo que usar la ID del reloj CLOCK_PROCESS_CPUTIME_ID.

EJEMPLOS

El siguiente programa de ejemplo obtiene la ID del reloj de tiempo de CPU del proceso cuyo ID se proporciona en la línea de comandos, y luego usa clock_gettime(2) para obtener el tiempo en ese reloj. Una ejecución de ejemplo es la siguiente:


$ ./a.out 1                 # Mostrar reloj de CPU del proceso init
El reloj de tiempo de CPU para PID 1 es 2.213466748 segundos

Código fuente del programa

#define _XOPEN_SOURCE 600
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    clockid_t clockid;
    struct timespec ts;
    if (argc != 2) {
        fprintf(stderr, "%s <ID-de-proceso>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (clock_getcpuclockid(atoi(argv[1]), &clockid) != 0) {
        perror("clock_getcpuclockid");
        exit(EXIT_FAILURE);
    }
    if (clock_gettime(clockid, &ts) == -1) {
        perror("clock_gettime");
        exit(EXIT_FAILURE);
    }
    printf("El reloj de tiempo de CPU para PID %s es %jd.%09ld segundos\n",
           argv[1], (intmax_t) ts.tv_sec, ts.tv_nsec);
    exit(EXIT_SUCCESS);
}
