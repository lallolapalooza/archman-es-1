DESCRIPCIÓ

N

Este es el módulo "Class::Singleton". Un Singleton describe una clase de objeto que solo puede tener una instancia en cualquier sistema. Un ejemplo de un Singleton podría ser un gestor de cola de impresión o el registro del sistema. Este módulo implementa una clase Singleton de la cual otras clases pueden derivarse. Por sí mismo, el módulo "Class::Singleton" hace muy poco más que gestionar la instanciación de un solo objeto. Al derivar una clase de "Class::Singleton", tu módulo heredará el método de instanciación Singleton y podrá implementar cualquier funcionalidad específica que se

requiera.

Para una descripción y discusión de la clase Singleton, consulta "Design Patterns", Gamma et al, Addison-Wesley, 1995, ISBN

0-201-63361-2.

Uso del módulo Class::

Singleton

Para importar y usar el módulo "Class::Singleton", la siguiente línea debe aparecer en tu programa

Perl: 
use Class::
Singleton;

El método instance() se utiliza para crear una nueva instancia de "Class::Singleton", o devolver una referencia a una instancia existente. Usando este método, solo es posible tener una única instancia de la clase en cualquier

sistema. 
my $highlander = Class::Singleton->instance()
;

Asumiendo que actualmente no existe ningún objeto "Class::Singleton", esta primera llamada a instance() creará un nuevo "Class::Singleton" y devolverá una referencia a él. Las futuras invocaciones de instance() devolverán la misma

referencia. 
my $macleod    = Class::Singleton->instance()
;

En el ejemplo anterior, tanto $highlander como $macleod contienen la misma referencia a una instancia de "Class::Single

ton". Solo pu
ede haber una.

Derivación de clases

Singleton

Una clase de módulo puede derivarse de "Class::Singleton" y heredará el método instance() que instancía correctamente solo un

objeto. 
package PrintSpooler;
use base 'Class::Singleton';

# código específico de la clase derivada
sub submit_job {
    ...
}

sub cancel_job {
    ...
}

La clase "PrintSpooler" definida arriba podría usarse de la siguiente

manera: 
use PrintSpooler;

my $spooler = PrintSpooler->instance();

$spooler->submit_job(...)
;

El método instance() llama al método constructor _new_instance() la primera y única vez que se crea una nueva instancia. Todos los parámetros pasados al método instance() se reenvían a _new_instance(). En la clase base, el método _new_instance() devuelve una referencia bendecida a un array hash que contiene cualquier argumento pasado ya sea como una referencia hash o como una lista de parámetros con

nombre. 
package MyConfig;
use base 'Class::Singleton';

sub foo {
    shift->{ foo };
}

sub bar {
    shift->{ bar };
}

package main;

# ya sea: referencia hash de parámetros con nombre
my $config = MyConfig->instance({ foo => 10, bar => 20 });

# o: lista de parámetros con nombre
my $config = MyConfig->instance( foo => 10, bar => 20 );

print $config->foo();   # 10
print $config->bar();   #
20

Las clases derivadas pueden redefinir el método _new_instance() para proporcionar una inicialización de objeto más específica o cambiar el tipo de objeto subyacente (a una referencia de lista, por ejemplo)

. 
package MyApp::Database;
use base 'Class::Singleton';
use DBI;

# esto solo se llama la primera vez que se llama a instance()
sub _new_instance {
    my $class = shift;
    my $self  = bless { }, $class;
    my $db    = shift || "myappdb";    
    my $host  = shift || "localhost";

    $self->{ DB } = DBI->connect("DBI:mSQL:$db:$host")
        || die "Cannot connect to database: $DBI::errstr";

    # cualquier otra inicialización...

    return $self;
}

El ejemplo anterior podría usarse de la siguiente

manera: 
use MyApp::Database;

# primer uso - la base de datos se inicializa
my $database = MyApp::Database->instance()
;

Algún tiempo después en un módulo muy, muy lejano..

. 
package MyApp::FooBar
use MyApp::Database;

# este objeto FooBar necesita acceso a la base de datos; el enfoque Singleton
# proporciona un buen envoltorio alrededor de las variables globales.

sub new {
    my $class = shift;
    bless {
        database => MyApp::Database->instance(),
    }, $class;
}

El método instance() de "Class::Singleton" utiliza un hash privado para almacenar una referencia a cualquier instancia existente del objeto, indexada por el nombre de paquete de la clase

derivada.

Esto permite que diferentes clases se deriven de "Class::Singleton" y puedan coexistir en el mismo sistema, mientras que aún permite que solo exista una instancia de cualquier clase. Por ejemplo, sería posible derivar tanto"PrintSpooler" como"MyApp::Database" de "Class::Singleton" y tener una sola instancia de cada una en un sistema, en lugar de una sola instancia de cualquiera de

ellas.

Puedes usar el método has_instance() para averiguar si una clase en particular ya tiene una instancia definida. Se devuelve una referencia a la instancia o "undef" si no hay ninguna definida

actualmente. 
my $instance = MyApp::Databas
e->has_instance() || warn
"No instance is defined yet";
