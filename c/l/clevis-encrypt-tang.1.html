NOMBRE

clevis-encrypt-tang - Cifra usando una política de servidor de enlace Tang

SINOPSIS

clevis encrypt tang CONFIG [-y] < PT > JWE

DESCRIPCIÓN

El comando clevis encrypt tang cifra usando una política de servidor de enlace Tang. Su único argumento es el objeto de configuración JSON.

Clevis proporciona soporte para el servidor de enlace de red Tang. Tang proporciona una alternativa sin estado y ligera a los depósitos. Cifrar datos usando el pin Tang funciona de la siguiente manera:

$ clevis encrypt tang '{"url":"http://tang.srv"}' < PT > JWE
El anuncio contiene las siguientes claves de firma:
_OsIk0T-E2l6qjfdDiwVmidoZjA
¿Desea confiar en estas claves? [ynYN] y

Para descifrar los datos, simplemente páselos al comando clevis decrypt:

$ clevis decrypt < JWE > PT

Como puede ver arriba, Tang utiliza un flujo de trabajo de confianza en el primer uso. Si ya conoce la huella digital de una clave de confianza, puede especificarla en la configuración en el momento del cifrado:

$ cfg='{"url":"http://tang.srv","thp":"_OsIk0T-E2l6qjfdDiwVmidoZjA"}'
$ clevis encrypt tang "$cfg" < PT > JWE

Obtener la huella digital de una clave de firma de confianza es fácil. Si tiene acceso al servidor Tang, simplemente ejecute:

$ tang-show-keys <PUERTO>

donde <PUERTO> es el puerto en el que está escuchando el servidor Tang.

Si tang-show-keys no está disponible, pero tiene acceso al directorio de la base de datos del servidor Tang, puede ejecutar esto en su lugar:

$ jose jwk thp -i $DBDIR/$SIG.jwk

Tang también puede realizar un cifrado completamente sin conexión si comparte previamente el anuncio del servidor. Puede obtener el anuncio con un comando simple (¡solo tenga cuidado de que su red no esté comprometida!).

$ curl -f $URL/adv > adv.jws

Una vez que tenga el archivo de anuncio, simplemente proporciónelo:

$ clevis encrypt tang '{"url":...,"adv":"adv.jws"}' < PT > JWE

CONFIG

Este comando utiliza las siguientes propiedades de configuración:

•url (cadena) : La URL base del servidor Tang (REQUERIDO)
•thp (cadena) : La huella digital de una clave de firma de confianza
•adv (cadena) : Un nombre de archivo que contiene un anuncio de confianza
•adv (objeto) : Un anuncio de confianza (JSON sin procesar)

OPCIONES

•-y : Responde automáticamente sí a todas las preguntas. Utilice esta opción para omitir la verificación de confianza del anuncio. Esto puede ser útil en implementaciones automatizadas: 
$ clevis encrypt tang '{"url":...}' -y < PT > JWE
