CLEVERCSV(1) Manual de Clevercsv CLEVERCSV(1)

NOMBRE

clevercsv - Herramienta de línea de comandos de CleverCSV

SINOPSIS

clevercsv [-h | --help] [-V | --version] [-v | --verbose] <comando ...>

DESCRIPCIÓN

CleverCSV es una biblioteca de Python y una herramienta de línea de comandos para tratar con archivos CSV desordenados. Consta de una serie de comandos que se pueden utilizar para analizar, explorar o estandarizar un archivo CSV desordenado.

Se puede encontrar más ayuda y documentación en línea en https://github.com/alan-turing-institute/CleverCSV o https://clevercsv.readthedocs.io

OPCIONES

-h, --help

muestra este mensaje de ayuda y sale

-V, --version

Muestra la versión y sale

-v, --verbose

Habilita el modo detallado

COMANDOS

Los siguientes comandos están disponibles en CleverCSV:

clevercsv-code(1)

Genera código Python para importar un archivo CSV dado

clevercsv-detect(1)

Detecta el dialecto de un archivo CSV

clevercsv-explore(1)

Infiere el dialecto y abre el archivo en una sesión interactiva de Python

clevercsv-standardize(1)

Convierte un archivo CSV desordenado a uno que sigue RFC-4180

clevercsv-view(1)

Detecta el dialecto y abre el archivo CSV usando TabView

AUTORES

El paquete CleverCSV fue escrito originalmente por Gerrit van den Burg y surgió de la investigación científica sobre el procesamiento de archivos CSV desordenados por Gerrit van den Burg, Alfredo Nazabal y Charles Sutton. Esta investigación se llevó a cabo y fue apoyada por The Alan Turing Institute. Desde entonces, CleverCSV se ha beneficiado de una serie de colaboradores de código abierto en GitHub.

REPORTE DE ERRORES

Si encuentra un problema en CleverCSV, abra un ticket o envíe una solicitud de extracción en https://github.com/alan-turing-institute/CleverCSV. ¡No dude en hacerlo, está ayudando a mejorar este proyecto para todos!
