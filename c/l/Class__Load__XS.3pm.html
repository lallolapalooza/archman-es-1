Class::Load::XS(3) Documentación de Perl Contribuida por el Usuario Class::Load::XS(3)

NOMBRE

Class::Load::XS - Implementación XS de partes de Class::Load

VERSIÓN

versión 0.10

SINOPSIS

use Class::Load;

DESCRIPCIÓN

Este módulo proporciona una implementación XS para porciones de Class::Load. Consulte Class::Load para obtener detalles de la API.
