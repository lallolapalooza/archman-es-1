CLAED8 utilizada por CSTEDC. Combina valores propios y descompone la ecuación secular. Se utiliza cuando la matriz original es densa.

subrutina claed8 (entero k, entero n, entero qsiz, complejo, dimensión( ldq, * ) q, entero ldq, real, dimensión( * ) d, real rho, entero cutpnt, real, dimensión( * ) z, real, dimensión( * ) dlambda, complejo, dimensión( ldq2, * ) q2, entero ldq2, real, dimensión( * ) w, entero, dimensión( * ) indxp, entero, dimensión( * ) indx, entero, dimensión( * ) indxq, entero, dimensión( * ) perm, entero givptr, entero, dimensión( 2, * ) givcol, real, dimensión( 2, * ) givnum, entero info)

CLAED8 utilizada por CSTEDC. Combina los dos conjuntos de valores propios en un único conjunto ordenado. Luego intenta descomponer el problema. Hay dos formas en que puede ocurrir la descomposición: cuando dos o más valores propios están muy juntos o si hay un elemento diminuto en el vector Z. Por cada ocurrencia de este tipo, el orden del problema de la ecuación secular relacionada se reduce en uno.

Propósito:

!>
!> CLAED8 combina los dos conjuntos de valores propios en un único
!> conjunto ordenado. Luego intenta descomponer el tamaño del problema.
!> Hay dos formas en que puede ocurrir la descomposición: cuando dos o
!> más valores propios están muy juntos o si hay un elemento diminuto en el
!> vector Z. Por cada ocurrencia de este tipo, el orden del problema de la
!> ecuación secular relacionada se reduce en uno.
!>

Parámetros

K 
!>          K es ENTERO
!>         Contiene el número de valores propios no descompuestos.
!>         Este es el orden de la ecuación secular relacionada.
!>

N

!>          N es ENTERO
!>         La dimensión de la matriz tridiagonal simétrica. N >= 0.
!>

QSIZ

!>          QSIZ es ENTERO
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz densa o de banda a forma tridiagonal.
!>         QSIZ >= N si ICOMPQ = 1.
!>

Q

!>          Q es un array COMPLEJO, dimensión (LDQ,N)
!>         En la entrada, Q contiene los vectores propios del sistema parcialmente
!>         resuelto que ha sido previamente actualizado en multiplicaciones matriciales
!>         con otros sistemas de valores propios parcialmente resueltos.
!>         En la salida, Q contiene los últimos N-K vectores propios actualizados
!>         (aquellos que fueron descompuestos) en sus últimas N-K columnas.
!>

LDQ

!>          LDQ es ENTERO
!>         La dimensión principal del array Q. LDQ >= max( 1, N ).
!>

D

!>          D es un array REAL, dimensión (N)
!>         En la entrada, D contiene los valores propios de las dos submatrices a
!>         combinar. En la salida, D contiene los últimos N-K valores propios
!>         actualizados (aquellos que fueron descompuestos) ordenados en orden
!>         creciente.
!>

RHO

!>          RHO es REAL
!>         Contiene el elemento fuera de la diagonal asociado con el corte de
!>         rango 1 que originalmente dividió las dos submatrices que ahora se
!>         están combinando. RHO se modifica durante el cálculo al valor
!>         requerido por SLAED3.
!>

CUTPNT

!>          CUTPNT es ENTERO
!>         Contiene la ubicación del último valor propio en la submatriz
!>         principal. MIN(1,N) <= CUTPNT <= N.
!>

Z

!>          Z es un array REAL, dimensión (N)
!>         En la entrada, este vector contiene el vector de actualización (la última
!>         fila de la primera matriz de vectores propios y la primera fila de
!>         la segunda matriz de vectores propios). El contenido de Z se destruye
!>         durante el proceso de actualización.
!>

DLAMBDA

!>          DLAMBDA es un array REAL, dimensión (N)
!>         Contiene una copia de los primeros K valores propios que se utilizarán
!>         en SLAED3 para formar la ecuación secular.
!>

Q2

!>          Q2 es un array COMPLEJO, dimensión (LDQ2,N)
!>         Si ICOMPQ = 0, Q2 no se referencia. De lo contrario,
!>         Contiene una copia de los primeros K vectores propios que se utilizarán
!>         en SLAED7 en una multiplicación matricial (SGEMM) para actualizar los nuevos
!>         vectores propios.
!>

LDQ2

!>          LDQ2 es ENTERO
!>         La dimensión principal del array Q2. LDQ2 >= max( 1, N ).
!>

W

!>          W es un array REAL, dimensión (N)
!>         Esto contendrá los primeros k valores del vector z final
!>         alterado por descomposición y se pasará a SLAED3.
!>

INDXP

!>          INDXP es un array ENTERO, dimensión (N)
!>         Esto contendrá la permutación utilizada para colocar los valores
!>         descompuestos de D al final del array. En la salida, INDXP(1:K)
!>         apunta a los valores D no descompuestos y INDXP(K+1:N)
!>         apunta a los valores propios descompuestos.
!>

INDX

!>          INDX es un array ENTERO, dimensión (N)
!>         Esto contendrá la permutación utilizada para ordenar el contenido de
!>         D en orden ascendente.
!>

INDXQ

!>          INDXQ es un array ENTERO, dimensión (N)
!>         Esto contiene la permutación que ordena por separado los dos
!>         subproblemas en D en orden ascendente. Tenga en cuenta que los elementos en
!>         la segunda mitad de esta permutación deben tener CUTPNT
!>         sumado a sus valores para ser precisos.
!>

PERM

!>          PERM es un array ENTERO, dimensión (N)
!>         Contiene las permutaciones (de descomposición y ordenación) que se
!>         aplicarán a cada bloque de valores propios.
!>

GIVPTR

!>          GIVPTR es ENTERO
!>         Contiene el número de rotaciones de Givens que tuvieron lugar en
!>         este subproblema.
!>

GIVCOL

!>          GIVCOL es un array ENTERO, dimensión (2, N)
!>         Cada par de números indica un par de columnas para realizar
!>         una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es un array REAL, dimensión (2, N)
!>         Cada número indica el valor S que se utilizará en la
!>         rotación de Givens correspondiente.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>
