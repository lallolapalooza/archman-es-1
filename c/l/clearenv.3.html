clearenv(3) Manual de funciones de biblioteca clearenv(3)

NOMBRE

clearenv - limpiar el entorno

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int clearenv(void);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

clearenv():

    /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

La función clearenv() limpia el entorno de todos los pares nombre-valor y establece el valor de la variable externa environ a NULL. Después de esta llamada, se pueden agregar nuevas variables al entorno usando putenv(3) y setenv(3).

VALOR DE RETORNO

La función clearenv() devuelve cero si tiene éxito, y un valor distinto de cero si falla.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor

ESTÁNDARES

putenv()
POSIX.1-2008.
clearenv()
Ninguno.

HISTORIA

putenv()
glibc 2.0. POSIX.1-2001.
clearenv()
glibc 2.0.

Varias variantes de UNIX (DG/UX, HP-UX, QNX, ...). POSIX.9 (enlances para FORTRAN77). POSIX.1-1996 no aceptó clearenv() y putenv(3), pero cambió de opinión y programó estas funciones para alguna edición posterior de este estándar (ver §B.4.6.1). Sin embargo, POSIX.1-2001 solo agrega putenv(3) y rechazó clearenv().

NOTAS

En sistemas donde clearenv() no está disponible, la asignación


environ = NULL;

probablemente funcionará.

La función clearenv() puede ser útil en aplicaciones sensibles a la seguridad que desean controlar con precisión el entorno que se pasa a los programas ejecutados con exec(3). La aplicación lo haría primero limpiando el entorno y luego agregando variables de entorno selectas.

Tenga en cuenta que el efecto principal de clearenv() es ajustar el valor del puntero environ(7); esta función no borra el contenido de los búferes que contienen las definiciones del entorno.

Las páginas del manual de DG/UX y Tru64 escriben: Si environ ha sido modificado por algo que no sean las funciones putenv(3), getenv(3) o clearenv(), entonces clearenv() devolverá un error y el entorno del proceso permanecerá sin cambios.

VÉASE TAMBIÉN

getenv(3), putenv(3), setenv(3), unsetenv(3), environ(7)
