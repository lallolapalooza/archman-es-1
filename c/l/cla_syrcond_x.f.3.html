función real cla_syrcond_x (uplo carácter, n entero, complejo, dimensión( lda, * ) a, lda entero, complejo, dimensión( ldaf, * ) af, ldaf entero, ipiv entero, dimensión( * ) x, info entero, work complejo, dimensión( * ) rwork real, dimensión( * ))

CLA_SYRCOND_X calcula el número de condición de la norma infinito de op(A)*diag(x) para matrices simétricas indefinidas.

Propósito:

!>
!>    CLA_SYRCOND_X Calcula el número de condición de la norma infinito de
!>    op(A) * diag(X) donde X es un vector COMPLEJO.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz COMPLEX, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L, tal como se calcula por CSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal de la matriz AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es una matriz INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por CSYTRF.
!>

X

!>          X es una matriz COMPLEX, dimensión (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es una matriz COMPLEX, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es una matriz REAL, dimensión (N).
!>     Espacio de trabajo.
!>
