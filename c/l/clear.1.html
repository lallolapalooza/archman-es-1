clear(1) Comandos de usuario clear(1)

NOMBRE

clear - limpiar la pantalla de la terminal

SINOPSIS

clear [-x] [-T tipo-de-terminal]

clear -V

DESCRIPCIÓN

clear limpia la pantalla de tu terminal y su búfer de desplazamiento, si existe. clear obtiene el tipo de terminal de la variable de entorno TERM, luego consulta la entrada de la base de datos de capacidades de terminal terminfo para ese tipo para determinar cómo realizar estas acciones.

Las capacidades para limpiar la pantalla y el búfer de desplazamiento se llaman “clear” y “E3”, respectivamente. Esta última es una capacidad definida por el usuario, que aplica un mecanismo de extensión introducido en ncurses 5.0 (1999).

OPCIONES

clear reconoce las siguientes opciones.

-T tipo
produce instrucciones adecuadas para el tipo de terminal. Normalmente, esta opción es innecesaria, ya que el tipo de terminal se infiere de la variable de entorno TERM. Si se especifica esta opción, clear también ignora las variables de entorno LINES y COLUMNS.
-V
informa la versión de ncurses asociada con este programa y sale con estado de éxito.
-x
evita que clear intente limpiar el búfer de desplazamiento.

PORTABILIDAD

Ni IEEE Std 1003.1/The Open Group Base Specifications Issue 7 (POSIX.1-2008) ni X/Open Curses Issue 7 documentan clear.

Este último documenta tput, que podría usarse para reemplazar esta utilidad ya sea a través de un script de shell o mediante un alias (como un enlace simbólico) para ejecutar tput como clear.

HISTORIA

Un comando clear que utiliza la base de datos y la biblioteca termcap apareció en 2BSD (1979). Eighth Edition Unix (1985) lo incluyó posteriormente.

El brazo comercial de Unix de AT&T adaptó un programa BSD diferente (tset) para crear un nuevo comando, tput, y reemplazó el programa clear con un script de shell que llamaba a “tput clear”.

/usr/bin/tput ${1:+-T$1} clear 2> /dev/null
exit

En 1989, cuando Keith Bostic revisó el comando BSD tput para que fuera similar al tput de AT&T, también agregó un script de shell clear.

exec tput clear

El resto del script en cada caso es un aviso de copyright.

En 1995, el clear de ncurses comenzó adaptando el comando original clear de BSD para usar terminfo. La extensión E3 llegó más tarde.

•
En junio de 1999, xterm proporcionó una extensión a la secuencia de control estándar para limpiar la pantalla. En lugar de limpiar solo la parte visible de la pantalla usando
printf '\033[2J'
uno podía limpiar también el búfer de desplazamiento usando
printf '\033[3J'
en su lugar. “XTerm Control Sequences” documenta esta característica como originada en xterm.
  • Algunos otros emuladores de terminal lo adoptaron, como PuTTY en 2006.
  • En abril de 2011, un desarrollador de Red Hat envió un parche al kernel de Linux, modificando su controlador de consola para hacer lo mismo. La documentación de este cambio, que apareció en Linux 3.0, no mencionó a xterm, aunque ese programa fue citado en el informe de error de Red Hat (#683733) que motivó la característica.
  • Posteriormente, más desarrolladores de terminales adoptaron la característica. El siguiente paso relevante fue cambiar el programa clear de ncurses en 2013 para incorporar esta extensión.
  • En 2013, la capacidad E3 no fue utilizada por “tput clear”. Esa omisión se abordó en 2016 reorganizando tput para compartir su lógica con clear y tset.

VER TAMBIÉN
