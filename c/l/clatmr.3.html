CLATMR

Documentación de Función/Subrutina

subrutina clatmr (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, complex, dimension( * ) d, integer mode, real cond, complex dmax, character rsign, character grade, complex, dimension( * ) dl, integer model, real condl, complex, dimension( * ) dr, integer moder, real condr, character pivtng, integer, dimension( * ) ipivot, integer kl, integer ku, real sparse, real anorm, character pack, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) iwork, integer info)

CLATMR

Propósito:

!>
!>    CLATMR genera matrices aleatorias de varios tipos para probar
!>    programas LAPACK.
!>
!>    CLATMR opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Genera una matriz A con entradas aleatorias de distribución DIST
!>         que es simétrica si SYM='S', Hermitiana si SYM='H', y
!>         no simétrica si SYM='N'.
!>
!>      Establece la diagonal en D, donde D puede ser de entrada o
!>         calculado de acuerdo con MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>      Escala la matriz, si se desea, desde la izquierda y/o derecha
!>         como se especifica por GRADE. Las entradas DL, MODEL, CONDL, DR,
!>         MODER y CONDR también determinan el escalado como se describe
!>         a continuación.
!>
!>      Permuta, si se desea, las filas y/o columnas como se especifica por
!>         PIVTNG e IPIVOT.
!>
!>      Establece entradas aleatorias a cero, si se desea, para obtener una matriz dispersa
!>         aleatoria como se especifica por SPARSE.
!>
!>      Hace que A sea una matriz banda, si se desea, poniendo a cero la matriz
!>         fuera de una banda de ancho inferior KL y ancho superior KU.
!>
!>      Escala A, si se desea, para tener una entrada máxima ANORM.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetado
!>         poner a cero la mitad superior (si es simétrica o Hermitiana)
!>         poner a cero la mitad inferior (si es simétrica o Hermitiana)
!>         almacenar la mitad superior por columnas (si es simétrica o Hermitiana
!>             o triangular superior cuadrada)
!>         almacenar la mitad inferior por columnas (si es simétrica o Hermitiana
!>             o triangular inferior cuadrada)
!>             igual que la mitad superior por filas si es simétrica
!>             igual que la mitad superior conjugada por filas si es Hermitiana
!>         almacenar el triángulo inferior en formato banda
!>             (si es simétrica o Hermitiana)
!>         almacenar el triángulo superior en formato banda
!>             (si es simétrica o Hermitiana)
!>         almacenar la matriz completa en formato banda
!>
!>    Nota: Si dos llamadas a CLATMR difieren solo en el parámetro PACK,
!>          generarán matrices matemáticamente equivalentes.
!>
!>          Si dos llamadas a CLATMR ambas tienen ancho de banda completo (KL = M-1
!>          y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>          entonces las matrices generadas diferirán solo
!>          en el orden de las filas y/o columnas, y de otro modo
!>          contendrán los mismos datos. Esta consistencia no puede ser y
!>          no se mantiene con menos de ancho de banda completo.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de A. No modificado.
!>

N

!>          N es INTEGER
!>           Número de columnas de A. No modificado.
!>

DIST

!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a ser usada
!>           para generar una matriz aleatoria.
!>           'U' => las partes real e imaginaria son independientes
!>                  UNIFORM( 0, 1 )  ( 'U' para uniforme )
!>           'S' => las partes real e imaginaria son independientes
!>                  UNIFORM( -1, 1 ) ( 'S' para simétrica )
!>           'N' => las partes real e imaginaria son independientes
!>                  NORMAL( 0, 1 )   ( 'N' para normal )
!>           'D' => uniforme en el interior del disco unitario ( 'D' para disco )
!>           No modificado.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>           En la entrada ISEED especifica la semilla del generador de números
!>           aleatorios. Deberían estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debería ser impar. El generador de números aleatorios
!>           usa una secuencia congruencial lineal limitada a pequeños
!>           enteros, y por lo tanto debería producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED son cambiados en
!>           la salida, y pueden ser usados en la siguiente llamada a CLATMR
!>           para continuar la misma secuencia de números aleatorios.
!>           Cambiado en la salida.
!>

SYM

!>          SYM es CHARACTER*1
!>           Si SYM='S', la matriz generada es simétrica.
!>           Si SYM='H', la matriz generada es Hermitiana.
!>           Si SYM='N', la matriz generada es no simétrica.
!>           No modificado.
!>

D

!>          D es un array COMPLEX, dimensión (min(M,N))
!>           En la entrada este array especifica las entradas diagonales
!>           de la diagonal de A. D puede ser especificado
!>           en la entrada, o establecido de acuerdo con MODE y COND como se describe
!>           a continuación. Si la matriz es Hermitiana, la parte real de D
!>           será tomada. Puede ser cambiado en la salida si MODE es distinto de cero.
!>

MODE

!>          MODE es INTEGER
!>           En la entrada describe cómo D debe ser usado:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) de modo que sus logaritmos
!>                    estén uniformemente distribuidos.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D está invertido.
!>           Así que si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           No modificado.
!>

COND

!>          COND es REAL
!>           En la entrada, usado como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es COMPLEX
!>           Si MODE no es ni -6, 0 ni 6, la diagonal es escalada por
!>           DMAX / max(abs(D(i))), de modo que la entrada máxima absoluta
!>           de la diagonal es abs(DMAX). Si DMAX es complejo (o cero),
!>           la diagonal será escalada por un número complejo (o cero).
!>

RSIGN

!>          RSIGN es CHARACTER*1
!>           Si MODE no es ni -6, 0 ni 6, especifica el signo de la diagonal
!>           como sigue:
!>           'T' => las entradas diagonales son multiplicadas por un número complejo aleatorio
!>                  uniformemente distribuido con valor absoluto 1
!>           'F' => la diagonal no cambia
!>           No modificado.
!>

GRADE

!>          GRADE es CHARACTER*1
!>           Especifica el escalado de la matriz como sigue:
!>           'N'  => sin escalado
!>           'L'  =>gt; matriz premultiplicada por diag( DL )
!>                   (solo si la matriz no es simétrica)
!>           'R'  => matriz postmultiplicada por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'B'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'H'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( CONJG(DL) )
!>                   (solo si la matriz es Hermitiana o no simétrica)
!>           'S'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>                   (solo si la matriz es simétrica o no simétrica)
!>           'E'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>                         ( 'S' para similitud )
!>                   (solo si la matriz no es simétrica)
!>                   Nota: si GRADE='S', entonces M debe ser igual a N.
!>           No modificado.
!>

DL

!>          DL es un arreglo COMPLEX, dimensión (M)
!>           Si MODEL=0, entonces en la entrada este arreglo especifica los
!>           elementos diagonales de una matriz diagonal utilizada como se
!>           describe bajo GRADE arriba. Si MODEL no es cero, entonces DL se
!>           establecerá de acuerdo con MODEL y CONDL, de manera análoga a
!>           como D se establece de acuerdo con MODE y COND (excepto que no
!>           hay parámetro DMAX para DL).
!>           Si GRADE='E', entonces DL no puede tener elementos cero.
!>           No se referencia si GRADE = 'N' o 'R'. Modificado en la salida.
!>

MODEL

!>          MODEL es INTEGER
!>           Esto especifica cómo debe calcularse el arreglo diagonal DL,
!>           igual que MODE especifica cómo debe calcularse D.
!>           No modificado.
!>

CONDL

!>          CONDL es REAL
!>           Cuando MODEL no es cero, esto especifica el número de condición
!>           del DL calculado.  No modificado.
!>

DR

!>          DR es un arreglo COMPLEX, dimensión (N)
!>           Si MODER=0, entonces en la entrada este arreglo especifica los
!>           elementos diagonales de una matriz diagonal utilizada como se
!>           describe bajo GRADE arriba. Si MODER no es cero, entonces DR se
!>           establecerá de acuerdo con MODER y CONDR, de manera análoga a
!>           como D se establece de acuerdo con MODE y COND (excepto que no
!>           hay parámetro DMAX para DR).
!>           No se referencia si GRADE = 'N', 'L', 'H' o 'S'.
!>           Modificado en la salida.
!>

MODER

!>          MODER es INTEGER
!>           Esto especifica cómo debe calcularse el arreglo diagonal DR,
!>           igual que MODE especifica cómo debe calcularse D.
!>           No modificado.
!>

CONDR

!>          CONDR es REAL
!>           Cuando MODER no es cero, esto especifica el número de condición
!>           del DR calculado.  No modificado.
!>

PIVTNG

!>          PIVTNG es CHARACTER*1
!>           En la entrada especifica las permutaciones de pivoteo como sigue:
!>           'N' o ' ' => ninguna.
!>           'L' => pivoteo izquierdo o por filas (la matriz debe ser no simétrica).
!>           'R' => pivoteo derecho o por columnas (la matriz debe ser
!>                  no simétrica).
!>           'B' o 'F' => ambos o pivoteo completo, es decir, en ambos lados.
!>                         En este caso, M debe ser igual a N
!>
!>           Si dos llamadas a CLATMR ambas tienen ancho de banda completo (KL = M-1
!>           y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>           entonces las matrices generadas diferirán solo en el orden de las
!>           filas y/o columnas, y de lo mismo contendrán los mismos datos.
!>           Esta consistencia no puede mantenerse con menos de ancho de banda completo.
!>

IPIVOT

!>          IPIVOT es un arreglo INTEGER, dimensión (N o M)
!>           Este arreglo especifica la permutación utilizada.  Después de
!>           que la matriz básica es generada, las filas, columnas, o ambas
!>           son permutadas.   Si, digamos, se selecciona pivoteo por filas, CLATMR
!>           comienza con la *última* fila e intercambia la M-ésima y la
!>           IPIVOT(M)-ésima filas, luego pasa a la penúltima fila,
!>           intercambiando la (M-1)-ésima y la IPIVOT(M-1)-ésima filas,
!>           y así sucesivamente.  En términos de , la permutación es
!>           (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
!>           donde el ciclo más a la derecha se aplica primero.  Este es el
!>           *inverso* del efecto del pivoteo en LINPACK.  La idea
!>           es que factorizar (con pivoteo) una matriz identidad
!>           que ha sido invertida-pivoteada de esta manera debería
!>           resultar en un vector de pivotes idéntico a IPIVOT.
!>           No se referencia si PIVTNG = 'N'. No modificado.
!>

KL

!>          KL es INTEGER
!>           En la entrada especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica
!>           Hessenberg superior, y KL al menos M-1 implica que la matriz no es
!>           de banda. Debe ser igual a KU si la matriz es simétrica o Hermitiana.
!>           No modificado.
!>

KU

!>          KU es INTEGER
!>           En la entrada especifica el ancho de banda superior de la matriz. Por
!>           ejemplo, KU=0 implica triangular inferior, KU=1 implica
!>           Hessenberg inferior, y KU al menos N-1 implica que la matriz no es
!>           de banda. Debe ser igual a KL si la matriz es simétrica o Hermitiana.
!>           No modificado.
!>

SPARSE

!>          SPARSE es REAL
!>           En la entrada especifica la dispersión de la matriz si se va a
!>           generar una matriz dispersa. SPARSE debe estar entre
!>           0 y 1. Para generar una matriz dispersa, para cada elemento de la matriz
!>           se genera un número aleatorio uniforme ( 0, 1 ) x y
!>           se compara con SPARSE; si x es mayor el elemento de la matriz
!>           no se modifica y si x es menor el elemento se establece
!>           a cero. Así en promedio una fracción SPARSE de los
!>           elementos se establecerán a cero.
!>           No modificado.
!>

ANORM

!>          ANORM es REAL
!>           En la entrada especifica el elemento máximo de la matriz de salida
!>           (la matriz de salida se multiplicará por una constante para que
!>           su elemento absoluto más grande sea igual a ANORM)
!>           si ANORM es no negativo. Si ANORM es negativo no se realiza
!>           escalado. No modificado.
!>

PACK

!>          PACK es CHARACTER*1
!>           En la entrada especifica el empaquetado de la matriz como sigue:
!>           'N' => sin empaquetado
!>           'U' => poner a cero todos los elementos por debajo de la diagonal
!>                  (si es simétrica o Hermitiana)
!>           'L' => poner a cero todos los elementos por encima de la diagonal
!>                  (si es simétrica o Hermitiana)
!>           'C' => almacenar el triángulo superior por columnas
!>                  (solo si la matriz es simétrica o Hermitiana o
!>                   triangular superior cuadrada)
!>           'R' => almacenar el triángulo inferior por columnas
!>                  (solo si la matriz es simétrica o Hermitiana o
!>                   triangular inferior cuadrada)
!>                  (igual que la mitad superior por filas si es simétrica)
!>                  (igual que la mitad superior conjugada por filas si es Hermitiana)
!>           'B' => almacenar el triángulo inferior en esquema de almacenamiento de banda
!>                  (solo si la matriz es simétrica o Hermitiana)
!>           'Q' => almacenar el triángulo superior en esquema de almacenamiento de banda
!>                  (solo si la matriz es simétrica o Hermitiana)
!>           'Z' => almacenar toda la matriz en esquema de almacenamiento de banda
!>                      (el pivoteo puede proporcionarse usando esta
!>                      opción para almacenar A en las filas finales del
!>                      almacenamiento asignado)
!>
!>           Usando estas opciones, se pueden obtener los diversos esquemas de
!>           almacenamiento empaquetado y de banda de LAPACK:
!>           GB               - usar 'Z'
!>           PB, HB o TB     - usar 'B' o 'Q'
!>           PP, HP o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a CLATMR difieren solo en el parámetro PACK,
!>           generarán matrices matemáticamente equivalentes.
!>           No modificado.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>           En la salida A es la matriz de prueba deseada. Solo aquellos
!>           elementos de A que son significativos en la salida
!>           serán referenciados (incluso si A está en formato de almacenamiento
!>           empaquetado o de banda). Los 'rincones no ocupados' de A en
!>           formato de banda serán puestos a cero.
!>

LDA

!>          LDA es INTEGER
!>           en la entrada LDA especifica la primera dimensión de A como
!>           se declara en el programa que llama.
!>           Si PACK='N', 'U' o 'L', LDA debe ser al menos max ( 1, M ).
!>           Si PACK='C' o 'R', LDA debe ser al menos 1.
!>           Si PACK='B', o 'Q', LDA debe ser MIN ( KU+1, N )
!>           Si PACK='Z', LDA debe ser al menos KUU+KLL+1, donde
!>           KUU = MIN ( KU, N-1 ) y KLL = MIN ( KL, M-1 )
!>           No modificado.
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (N o M)
!>           Espacio de trabajo. No se referencia si PIVTNG = 'N'. Modificado en la salida.
!>

INFO

!>          INFO es INTEGER
!>           Parámetro de error en la salida:
!>             0 => retorno normal
!>            -1 => M negativo o desigual a N y SYM='S' o 'H'
!>            -2 => N negativo
!>            -3 => DIST cadena ilegal
!>            -5 => SYM cadena ilegal
!>            -7 => MODE fuera del rango -6 a 6
!>            -8 => COND menor que 1.0, y MODE ni -6, 0 ni 6
!>           -10 => MODE ni -6, 0 ni 6 y RSIGN cadena ilegal
!>           -11 => GRADE cadena ilegal, o GRADE='E' y
!>                  M desigual a N, o GRADE='L', 'R', 'B', 'S' o 'E'
!>                  y SYM = 'H', o GRADE='L', 'R', 'B', 'H' o 'E'
!>                  y SYM = 'S'
!>           -12 => GRADE = 'E' y DL contiene cero
!>           -13 => MODEL fuera del rango -6 a 6 y GRADE= 'L', 'B', 'H',
!>                  'S' o 'E'
!>           -14 => CONDL menor que 1.0, GRADE='L', 'B', 'H', 'S' o 'E',
!>                  y MODEL ni -6, 0 ni 6
!>           -16 => MODER fuera del rango -6 a 6 y GRADE= 'R' o 'B'
!>           -17 => CONDR menor que 1.0, GRADE='R' o 'B', y
!>                  MODER ni -6, 0 ni 6
!>           -18 => PIVTNG cadena ilegal, o PIVTNG='B' o 'F' y
!>                  M desigual a N, o PIVTNG='L' o 'R' y SYM='S'
!>                  o 'H'
!>           -19 => IPIVOT contiene número fuera de rango y
!>                  PIVTNG desigual a 'N'
!>           -20 => KL negativo
!>           -21 => KU negativo, o SYM='S' o 'H' y KU desigual a KL
!>           -22 => SPARSE fuera del rango 0. a 1.
!>           -24 => PACK cadena ilegal, o PACK='U', 'L', 'B' o 'Q'
!>                  y SYM='N', o PACK='C' y SYM='N' y ya sea KL
!>                  desigual a 0 o N desigual a M, o PACK='R' y
!>                  SYM='N', y ya sea KU distinto de 0 o N distinto
!>                  de M
!>           -26 => LDA demasiado pequeño
!>             1 => Error al retornar de CLATM1 (computando D)
!>             2 => No se puede escalar la diagonal a DMAX (la entrada máxima es 0)
!>             3 => Error al retornar de CLATM1 (computando DL)
!>             4 => Error al retornar de CLATM1 (computando DR)
!>             5 => ANORM es positivo, pero la matriz construida antes de
!>                  intentar escalarla para tener norma ANORM es cero
!>
