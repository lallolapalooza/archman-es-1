Funciones/Subrutinas


subrutina clarfb (side, trans, direct, storev, m, n, k, v, ldv, t, ldt, c, ldc, work, ldwork)
CLARFB aplica un reflector de bloque o su transpuesta conjugada a una matriz rectangular general.

DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina clarfb (carácter side, carácter trans, carácter direct, carácter storev, entero m, entero n, entero k, complejo, dimensión( ldv, * ) v, entero ldv, complejo, dimensión( ldt, * ) t, entero ldt, complejo, dimensión( ldc, * ) c, entero ldc, complejo, dimensión( ldwork, * ) work, entero ldwork)

CLARFB aplica un reflector de bloque complejo H o su transpuesta conjugada H**H a una matriz compleja M por N, C, desde la izquierda o la derecha.

Propósito:

!>
!> CLARFB aplica un reflector de bloque complejo H o su transpuesta H**H a una
!> matriz compleja M por N, C, desde la izquierda o la derecha.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar H o H**H desde la Izquierda
!>          = 'R': aplicar H o H**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar H (Sin transpuesta)
!>          = 'C': aplicar H**H (Transpuesta conjugada)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de reflectores
!>          elementales.
!>          = 'F': H = H(1) H(2) . . . H(k) (Hacia adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Hacia atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los reflectores
!>          elementales:
!>          = 'C': Por columnas
!>          = 'R': Por filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T (= el número de reflectores elementales
!>          cuyo producto define el reflector de bloque).
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

V

!>          V es array COMPLEX, dimensión
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' y SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' y SIDE = 'R'
!>          La matriz V. Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C' y SIDE = 'L', LDV >= max(1,M);
!>          Si STOREV = 'C' y SIDE = 'R', LDV >= max(1,N);
!>          Si STOREV = 'R', LDV >= K.
!>

T

!>          T es array COMPLEX, dimensión (LDT,K)
!>          La matriz triangular K por K, T, en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

C

!>          C es array COMPLEX, dimensión (LDC,N)
!>          A la entrada, la matriz C de M por N.
!>          A la salida, C se sobrescribe con H*C o H**H*C o C*H o C*H**H.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array COMPLEX, dimensión (LDWORK,K)
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          Si SIDE = 'R', LDWORK >= max(1,M).
!>
