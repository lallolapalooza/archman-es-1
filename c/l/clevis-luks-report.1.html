NOMBRE

clevis-luks-report - Informa si una clavija vinculada a un volumen LUKS1 o LUKS2 ha sido rotada

SINOPSIS

clevis luks report -d DEV -s SLT

DESCRIPCIÓN

El comando clevis luks report comprueba una ranura dada de un dispositivo LUKS e informa si la clavija vinculada a ella — si existe — ha sido rotada.

OPCIONES

•-d DEV : El dispositivo LUKS enlazado
•-s SLT : El número de ranura o ranura de clave para verificar la clavija
•-q : Modo silencioso. Si se usa, no se preguntará si se debe regenerar el enlace con clevis luks regen
•-r : Regenera los metadatos de LUKS con clevis luks regen -q -d DEV -s SLT

EJEMPLO

Comprueba si la clavija enlazada a la ranura 1 en /dev/sda1 ha sido rotada:
# clevis luks report -d /dev/sda1 -s 1
