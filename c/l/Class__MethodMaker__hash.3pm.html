Class__MethodMaker__hash(3pm)

Paquete: perl-class-methodmaker

Licencias: GPL, PerlArtistic

Class::MethodMaker::hash(3) Documentación de Perl aportada por el usuario Class::MethodMaker::hash(3)

NOMBRE

Class::Method::hash - Crea métodos para manejar un valor hash.

SINOPSIS

use Class::MethodMaker
  [ hash => [qw/ x /] ];
$instance->x;                 # vacío
$instance->x(a => 1, b => 2, c => 3);
$instance->x_count == 3;      # verdadero
$instance->x = (b => 5, d => 8); # Nota: esto *reemplaza* el hash,
                                 # no le añade nada
$instance->x_index('b') == 5; # verdadero
$instance->x_exists('c');     # falso
$instance->x_exists('d');     # verdadero

DESCRIPCIÓN

Crea métodos para manejar valores hash en un objeto. Para un componente llamado "x", por defecto crea los métodos "x", "x_reset", "x_clear", "x_isset", "x_count", "x_index", "x_keys", "x_values", "x_each", "x_exists", "x_delete", "x_set", "x_get".

Los métodos disponibles son:

"*"

Creado por defecto. Este método devuelve la lista de claves y valores almacenados en el slot (se devuelven por pares, es decir, clave, valor, clave, valor; al igual que con los hashes de perl, no se garantiza ningún orden de las claves). Si se proporcionan argumentos a este método, estos reemplazan el contenido actual del hash. En un contexto de lista devuelve las claves y valores como una lista, y en un contexto escalar como una referencia a hash. Ten en cuenta que esta referencia ya no es una referencia directa al almacenamiento, a diferencia de Class::MethodMaker v1. Esto es para proteger el encapsulamiento. Consulta x_ref si necesitas esa funcionalidad (y estás preparado para asumir el riesgo asociado).

Si se proporciona un único argumento que es una referencia a array o a hash, se expande y se usan sus contenidos en lugar de los existentes. Este es un mecanismo de paso más eficiente para un gran número de valores.

*_reset

Creado por defecto. Llamado sin argumentos, restablece el componente en su totalidad; borrando cualquier almacenamiento asociado y devolviendo el componente a su estado por defecto. Normalmente, esto significa que *_isset devolverá falso, y * devolverá undef. Si "-default" está en vigor, entonces el componente se establecerá en el valor por defecto, y *_isset devolverá verdadero. Si "-default_ctor" está en vigor, entonces se invocará la subrutina por defecto, y su valor de retorno se usará para establecer el valor del componente, y *_isset devolverá verdadero.

Si se llama con argumentos, estos argumentos se tratan como índices dentro del componente, y los elementos individuales así referenciados se restablecen (su almacenamiento se borra, de modo que *_isset(n) devolverá falso para un napropiado, excepto cuando "-default" o "-default_ctor" estén en vigor, como se indicó anteriormente). Al igual que con los arrays de perl, restablecer el valor establecido más alto disminuye implícitamente el recuento (pero x_reset(n) nunca desestablece el agregado en sí, incluso si no todos los elementos están establecidos).

*_clear

Creado por defecto. Vacía el componente de todos sus elementos, pero sin borrar el almacenamiento en sí.

Si se le da una lista de claves, entonces los elementos que existen indexados por esas claves se establecen a undef (pero no se borran).

Nota la semántica muy diferente: "$x->a_clear('b')" establece el valor de "b" en el componente 'a' a undef (si "b"ya existe (de modo que "$x->a_isset('b'))" devuelve verdadero), pero "$x->a_clear()" borra el elemento "b" del componente 'a' (de modo que "$x->a_isset('b'))" devuelve falso).

*_isset

Creado por defecto. Si el componente está actualmente establecido. Esto es diferente de estar definido; inicialmente, el componente no está establecido (y si se lee, devolverá undef); se puede establecer a undef (lo cual es un valor establecido, que también devuelve undef). Una vez establecido, la única forma de desestablecer el componente es con *_reset.

Si un valor por defecto está en vigor, entonces *_isset siempre devolverá verdadero.

*_isset() prueba el componente en su totalidad. *_isset(a) prueba el elemento indexado por a. *_isset(a,b) prueba los elementos indexados por a, b, y devuelve la conjunción lógica (and) de las pruebas.

*_count

Creado por defecto. Devuelve el número de elementos en este componente. Esto no se ve afectado por la presencia (o ausencia) de un "default" (o "default_ctor"). Devuelve "undef" si el componente completo no está establecido (según *_isset).

*_index

Creado por defecto. Toma una lista de índices, devuelve una lista de los valores correspondientes.

Si un valor por defecto (o un ctor por defecto) está en vigor, entonces una búsqueda por índice vivificará y establecerá a los valores por defecto los elementos respectivos (y por lo tanto también la estructura de datos agregada, si aún no lo está).

*_keys

Creado por defecto. Las claves conocidas, como una lista en contexto de lista, como una referencia a array en contexto escalar.

Si esperas un recuento de las claves en contexto escalar, consulta *_count.

*_values

Creado por defecto. Los valores conocidos, como una lista en contexto de lista, como una referencia a array en contexto escalar.

*_each

Creado por defecto. El siguiente par de clave, valor (como una lista) del hash.

*_exists

Creado por defecto. Toma cualquier número de argumentos, considera cada uno como una clave, y determina si la clave existe en el hash. Devuelve la conjunción lógica (and).

*_delete

Creado por defecto. Esto funciona exactamente igual que *_reset, excepto que llamar a esto sin argumentos no hace nada. Esto se proporciona por ortogonalidad con el operador "delete" de Perl, mientras que *_reset se proporciona por ortogonalidad con otros tipos de componentes.

*_set

%n = $x->h; # (a=>1,b=>2,c=>3) (en algún orden)
$h->h_set(b=>4,d=>7);
%n = $h->a; # (a=>1,b=>4,c=>3,d=>7) (en algún orden)

Creado por defecto. Toma una lista, tratada como pares de índice => valor; cada índice dado se establece en el valor correspondiente. Sin retorno.

Si se dan dos argumentos, de los cuales el primero es una referencia a array, entonces se trata como una lista de índices de los cuales el segundo argumento (que también debe ser una referencia a array) son los valores correspondientes. Así que los siguientes dos comandos son equivalentes:

$x->a_set(b=>4,d=>7);
$x->a_set(['b','d'],[4,7]);

*_get

Creado por defecto. Recupera el valor del componente sin establecerlo (ignora cualquier argumento pasado).
