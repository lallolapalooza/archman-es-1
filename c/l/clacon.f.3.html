Documentación de función/subrutina

subrutina clacon (integer n, complex, dimension( n ) v, complex, dimension( n ) x, real est, integer kase)

CLACON estima la norma 1 de una matriz compleja cuadrada, utilizando comunicación inversa para evaluar productos matriz-vector.

Propósito:

!>
!> CLACON estima la norma 1 de una matriz compleja cuadrada A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es INTEGER
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es array COMPLEX, dimension (N)
!>         En el retorno final, V = A*W,  donde  EST = norm(V)/norm(W)
!>         (W no se retorna).
!>

X

!>          X es array COMPLEX, dimension (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         donde A**H es la traspuesta conjugada de A, y CLACON debe
!>         ser llamada de nuevo con todos los demás parámetros sin cambios.
!>

EST

!>          EST es REAL
!>         En la entrada con KASE = 1 o 2 y JUMP = 3, EST debe
!>         permanecer sin cambios desde la llamada anterior a CLACON.
!>         En la salida, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es INTEGER
!>         En la llamada inicial a CLACON, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**H * X.
!>         En el retorno final de CLACON, KASE volverá a ser 0.
!>
