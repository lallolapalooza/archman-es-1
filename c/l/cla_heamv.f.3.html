subrutina cla_heamv (uplo, n, alpha, a, lda, x, incx, beta, y, incy)

CLA_HEAMV calcula el producto de una matriz y un vector utilizando una matriz hermítica indefinida para calcular los límites de error.

Documentación de Función/Subrutina

subrutina cla_heamv (integer uplo, integer n, real alpha, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, integer incx, real beta, real, dimension( * ) y, integer incy)

CLA_HEAMV calcula el producto de una matriz y un vector utilizando una matriz hermítica indefinida para calcular los límites de error.

Propósito:

!>
!> CLA_SYAMV  realiza la operación de matriz-vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz simétrica de n por n.
!>
!> Esta función se utiliza principalmente para calcular los límites de
!> error. Para protegerse contra el subdesbordamiento durante la
!> evaluación, los componentes del vector resultante se perturban
!> lejos de cero en (N+1) veces el umbral de subdesbordamiento. Para
!> evitar errores innecesariamente grandes para la estructura de bloques
!> incrustada en matrices generales, los componentes cero no se perturban.
!> Una entrada cero se considera si todas las multiplicaciones involucradas
!> en el cálculo de esa entrada tienen al menos un multiplicando cero.
!>

Parámetros

UPLO 
!>          UPLO es INTEGER
!>           En la entrada, UPLO especifica si la parte triangular superior o
!>           inferior de la matriz A se va a referenciar de la siguiente
!>           manera:
!>
!>              UPLO = BLAS_UPPER   Sólo se referenciará la parte triangular
!>                                  superior de A.
!>
!>              UPLO = BLAS_LOWER   Sólo se referenciará la parte triangular
!>                                  inferior de A.
!>
!>           Sin cambios en la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios en la salida.
!>

ALPHA

!>          ALPHA es REAL.
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios en la salida.
!>

A

!>          A es un array COMPLEX, de dimensión ( LDA, n ).
!>           Antes de la entrada, la parte principal de m por n del array A debe
!>           contener la matriz de coeficientes.
!>           Sin cambios en la salida.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como se
!>           declara en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, n ).
!>           Sin cambios en la salida.
!>

X

!>          X es un array COMPLEX, de dimensión
!>           ( 1 + ( n - 1 )*abs( INCX ) )
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           Sin cambios en la salida.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios en la salida.
!>

BETA

!>          BETA es REAL.
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, Y no necesita estar configurado en la entrada.
!>           Sin cambios en la salida.
!>

Y

!>          Y es un array REAL, de dimensión
!>           ( 1 + ( n - 1 )*abs( INCY ) )
!>           Antes de la entrada con BETA distinto de cero, el array Y
!>           incrementado debe contener el vector y. En la salida, Y se
!>           sobrescribe con el vector y actualizado.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios en la salida.
!>
