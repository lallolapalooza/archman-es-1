CLA_PORFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices simétricas o hermitianas definidas positivas realizando un refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la

solución.

Propósito

: 
!>
!> CLA_PORFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión
!> extra y proporciona límites de error y estimaciones de error hacia atrás
!> para la solución.
!> Esta subrutina es llamada por CPORFSX para realizar refinamiento iterativo.
!> Además del límite de error en norma, el código proporciona el límite de
!> error componente a componente máximo si es posible. Véanse los comentarios
!> para ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de los límites de error.
!> Nótese que esta subrutina solo es responsable de establecer los segundos
!> campos de ERR_BNDS_NORM y ERR_BNDS_COMP.
!
>

Parámetro

s
PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a usar en el refinamiento.
!>     El valor está definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>     El número de miembros libres (right-hand-sides), es decir, el número de
!>     columnas de la matriz B.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!
>

LD

A 
!>          LDA es INTEGER
!>     La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

A

F 
!>          AF es un arreglo COMPLEX, dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como lo calcula CPOTRF.
!
>

LDA

F 
!>          LDAF es INTEGER
!>     La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!
>

COLEQ

U 
!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó un equilibrado de columnas en A antes de
!>     llamar a esta rutina. Esto es necesario para calcular la solución y los
!>     límites de error correctamente.
!
>

C 
!>          C es un arreglo REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si C es de entrada, cada elemento de C debería ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos
!>     que el resultado se desborde por abajo o por arriba. Los errores de
!>     redondeo durante el escalado llevan a refinar con una matriz que no es
!>     equivalente a la matriz de entrada, produciendo estimaciones de error que
!>     pueden no ser fiables.
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>     La matriz de miembros libres B.
!
>

LD

B 
!>          LDB es INTEGER
!>     La dimensión principal del arreglo B.  LDB >= max(1,N).
!
>

Y 
!>          Y es un arreglo COMPLEX, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como la calcula CPOTRS.
!>     En la salida, la matriz solución mejorada Y.
!
>

LD

Y 
!>          LDY es INTEGER
!>     La dimensión principal del arreglo Y.  LDY >= max(1,N).
!
>

BERR_OU

T 
!>          BERR_OUT es un arreglo REAL, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo hacia atrás
!>     componente a componente para el miembro libre j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto es calculado por CLA_LIN_BERR.
!
>

N_NORM

S 
!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (véanse ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve límites de error en norma.
!>     Si N_NORMS >= 2 devuelve límites de error componente a componente.
!
>

ERR_BNDS_NOR

M 
!>          ERR_BNDS_NORM es un arreglo REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada miembro libre, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El arreglo está indexado por el tipo de información de error como se
!>     describe abajo. Actualmente se devuelven hasta tres piezas de
!>     información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     miembro libre.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi seguramente dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debería confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco en norma estimado.  Comparado con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos recíprocos condition
!>              los números son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base para que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Este subrutina es responsable únicamente de establecer el segundo campo
!>     anterior.
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

ERR_BNDS_COM

P 
!>          ERR_BNDS_COMP es un arreglo REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El arreglo está indexado por el lado derecho i (del cual el
!>     error relativo componente a componente depende), y el tipo de información de
!>     error como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada lado derecho. Si
!>     la precisión componente a componente no se solicita (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi ciertamente dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición recíproco
!>              componente a componente estimado. Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la estimación de
!>              error es . Estos números de condición recíprocos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas absolutas de
!>              filas de Z sean aproximadamente 1.
!>
!>     Este subrutina es responsable únicamente de establecer el segundo campo
!>     anterior.
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

RE

S 
!>          RES es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para mantener el residuo intermedio.
!
>

AY

B 
!>          AYB es un arreglo REAL, dimensión (N)
!>     Espacio de trabajo.
!
>

D

Y 
!>          DY es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para mantener la solución intermedia.
!
>

Y_TAI

L 
!>          Y_TAIL es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para mantener los bits restantes de la solución intermedia.
!
>

RCON

D 
!>          RCOND es REAL
!>     Número de condición recíproco escalado. Esta es una estimación del
!>     número de condición recíproco de Skeel de la matriz A después de
!>     la equilibración (si se hizo). Si esto es menor que la precisión de la
!>     máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!
>

ITHRES

H 
!>          ITHRESH es INTEGER
!>     El número máximo de cálculos de residuo permitidos para
!>     el refinamiento. El valor predeterminado es 10. Para 'aggressive' establezca en 100 para
!>     permitir la convergencia usando factorizaciones aproximadas o
!>     factorizaciones distintas de LU. Si la factorización usa una
!>     técnica distinta de la eliminación de Gauss, las garantías en
!>     ERR_BNDS_NORM y ERR_BNDS_COMP pueden dejar de ser confiables.
!
>

RTHRES

H 
!>          RTHRESH es REAL
!>     Determina cuándo detener el refinamiento si la estimación de error deja de
!>     disminuir. El refinamiento se detendrá cuando la siguiente solución ya no
!>     satisfaga norm(dx_{i+1}) < RTHRESH * norm(dx_i) donde norm(Z) es
!>     la norma infinita de Z. RTHRESH satisface 0 < RTHRESH <= 1. El
!>     valor predeterminado es 0.5. Para 'aggressive' establezca en 0.9 para permitir
!>     la convergencia en matrices extremadamente mal condicionadas. Vea LAWN 165
!>     para más detalles.
!
>

DZ_U

B 
!>          DZ_UB es REAL
!>     Determina cuándo comenzar a considerar la convergencia componente a componente.
!>     La convergencia componente a componente solo se considera después de que cada componente
!>     de la solución Y sea estable, lo que definimos como el cambio
!>     relativo en cada componente sea menor que DZ_UB. El valor predeterminado
!>     es 0.25, requiriendo que el primer bit sea estable. Vea LAWN 165 para
!>     más detalles.
!
>

IGNORE_CWIS

E 
!>          IGNORE_CWISE es LOGICAL
!>     Si .TRUE. entonces ignorar la convergencia componente a componente. El valor predeterminado
!>     es .FALSE..
!
>

INF

O 
!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  si INFO = -i, el i-ésimo argumento de CPOTRS tenía un valor
!>             ilegal
!
>
