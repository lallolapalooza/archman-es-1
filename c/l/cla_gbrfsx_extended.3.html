subroutine cla_gbrfsx_extended (integer prec_type, integer trans_type, integer n, integer kl, integer ku, integer nrhs, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, logical colequ, real, dimension( * ) c, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldy, * ) y, integer ldy, real, dimension( * ) berr_out, integer n_norms, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, complex, dimension( * ) res, real, dimension(*) ayb, complex, dimension( * ) dy, complex, dimension( * ) y_tail, real rcond, integer ithresh, real rthresh, real dz_ub, logical ignore_cwise, integer info)

CLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices generales de banda realizando un refinamiento iterativo de precisión extra y proporciona cotas de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> CLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por CGBRFSX para realizar el refinamiento iterativo.
!> Además de la cota de error normwise, el código proporciona la cota de error
!> máxima por componente, si es posible. Consulte los comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para obtener detalles sobre las cotas de error. Tenga en cuenta
!> que esta subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición en A.
!>     El valor se define por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transposición
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

AB

!>          AB es array COMPLEX, dimensión (LDAB,N)
!>     En la entrada, la matriz AB de N por N.
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= max(1,N).
!>

AFB

!>          AFB es array COMPLEX, dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U calculada por CGBTRF.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     calculada por CGBTRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó una equilibrio de columna en A antes de llamar
!>     a esta subrutina. Esto es necesario para calcular correctamente la solución y
!>     las cotas de error.
!>

C

!>          C es array REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si C es de entrada, cada elemento de C debe ser una potencia
!>     de la base para garantizar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea subdesbordamiento o desbordamiento. Los errores de
!>     redondeo durante la escala conducen a un refinamiento con una matriz que no
!>     es equivalente a la matriz de entrada, produciendo estimaciones de error que
!>     pueden no ser fiables.
!>

B

!>          B es array COMPLEX, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es array COMPLEX, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, calculada por CGBTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es array REAL, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo hacia atrás por
!>     componente para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto por componente de la matriz
!>     o vector Z. Esto se calcula mediante CLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué cotas de error se devuelven (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 se devuelven cotas de error normwise.
!>     Si N_NORMS >= 2 se devuelven cotas de error por componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene la inf

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un arreglo REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El arreglo está indexado por el segundo miembro i (del cual
!>     depende el error relativo componente a componente), y el tipo de
!>     información de error descrito a continuación. Actualmente se
!>     devuelven hasta tres piezas de información para cada segundo
!>     miembro. Si no se solicita precisión componente a componente
!>     (PARAMS(3) = 0.0), entonces no se accede a ERR_BNDS_COMP. Si
!>     N_ERR_BNDS < 3, entonces se devuelven como máximo las primeras
!>     entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la entrada siguiente sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado componente a componente. Se compara
!>              con el umbral sqrt(n) * slamch('Epsilon') para determinar
!>              si la estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las
!>              sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Este subrutina es responsable únicamente de establecer el segundo
!>     campo anterior.
!>     Consulte la Nota de Trabajo de Lapack 165 para más detalles y
!>     precauciones adicionales.
!>

RES

!>          RES es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para contener el residual intermedio.
!>

AYB

!>          AYB es un arreglo REAL, dimensión (N)
!>     Espacio de trabajo.
!>

DY

!>          DY es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para contener la solución intermedia.
!>

Y_TAIL

!>          Y_TAIL es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para contener los bits finales de la solución
!>     intermedia.
!>

RCOND

!>          RCOND es REAL
!>     Número de condición recíproco escalado. Esta es una estimación del
!>     número de condición recíproco de Skeel de la matriz A después de
!>     la equilibración (si se realizó). Si es menor que la precisión de
!>     la máquina (en particular, si es cero), la matriz es singular en
!>     precisión de trabajo. Tenga en cuenta que el error puede seguir
!>     siendo pequeño incluso si este número es muy pequeño y la matriz
!>     parece mal condicionada.
!>

ITHRESH

!>          ITHRESH es INTEGER
!>     El número máximo de cálculos de residuo permitidos para el
!>     refinamiento. El valor predeterminado es 10. Para 'aggressive'
!>     establecer en 100 para permitir la convergencia usando
!>     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>     la factorización usa una técnica distinta de la eliminación
!>     gaussiana, las garantías en ERR_BNDS_NORM y ERR_BNDS_COMP pueden
!>     dejar de ser confiables.
!>

RTHRESH

!>          RTHRESH es REAL
!>     Determina cuándo detener el refinamiento si la estimación de
!>     error deja de disminuir. El refinamiento se detendrá cuando la
!>     siguiente solución ya no satisfaga norm(dx_{i+1}) < RTHRESH *
!>     norm(dx_i) donde norm(Z) es la norma infinita de Z. RTHRESH
!>     satisface 0 < RTHRESH <= 1. El valor predeterminado es 0.5. Para
!>     'aggressive' establecer en 0.9 para permitir la convergencia en
!>     matrices extremadamente mal condicionadas. Consulte LAWN 165 para
!>     más detalles.
!>

DZ_UB

!>          DZ_UB es REAL
!>     Determina cuándo comenzar a considerar la convergencia componente
!>     a componente. La convergencia componente a componente solo se
!>     considera después de que cada componente de la solución Y sea
!>     estable, lo cual definimos como el cambio relativo en cada
!>     componente siendo menor que DZ_UB. El valor predeterminado es
!>     0.25, requiriendo que el primer bit sea estable. Consulte LAWN 165
!>     para más detalles.
!>

IGNORE_CWISE

!>          IGNORE_CWISE es LOGICAL
!>     Si es .TRUE. entonces ignorar la convergencia componente a
!>     componente. El valor predeterminado es .FALSE..
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  si INFO = -i, el i-ésimo argumento a CGBTRS tenía un
!>             valor ilegal
!>
