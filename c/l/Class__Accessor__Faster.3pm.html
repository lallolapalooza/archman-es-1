NOMBRE

Class::Accessor::Faster - Accesor aún más rápido, pero menos expandible

SINOPSIS

package Foo;
use base qw(Class::Accessor::Faster);

DESCRIPCIÓN

Esta es una versión más rápida pero menos expandible de Class::Accessor::Fast.

Los accesores generados por Class::Accessor requieren dos llamadas a método para realizar su tarea (una para el accesor, otra para get() o set()).

Class::Accessor::Fast elimina la llamada a set()/get() y realiza el acceso por sí mismo, lo que resulta en un accesor algo más rápido.

Class::Accessor::Faster utiliza una referencia a un array internamente para ser más rápido.

Lea la documentación de Class::Accessor para más información.
