subrutina cla_gerfsx_extended (integer prec_type, integer trans_type, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, real, dimension( * ) c, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldy, * ) y, integer ldy, real, dimension( * ) berr_out, integer n_norms, real, dimension( nrhs, * ) errs_n, real, dimension( nrhs, * ) errs_c, complex, dimension( * ) res, real, dimension( * ) ayb, complex, dimension( * ) dy, complex, dimension( * ) y_tail, real rcond, integer ithresh, real rthresh, real dz_ub, logical ignore_cwise, integer info)

CLA_GERFSX_EXTENDED

Propósito:

!>
!>
!> CLA_GERFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales mediante el refinamiento iterativo de precisión
!> extra y proporciona cotas de error y estimaciones de error hacia atrás
!> para la solución.
!> Esta subrutina es llamada por CGERFSX para realizar refinamiento iterativo.
!> Además de la cota de error en norma, el código proporciona la cota
!> de error componente a componente si es posible. Véanse los comentarios
!> para ERRS_N y ERRS_C para detalles de las cotas de error. Nótese que
!> esta subrutina solo es responsable de establecer los segundos campos de
!> ERRS_N y ERRS_C.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a usar en el refinamiento.
!>     El valor está definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple (Single)
!>          = 'D':  Doble
!>          = 'I':  Indígena (Indigenous)
!>          = 'X' o 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición sobre A.
!>     El valor está definido por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transponer
!>          = 'T':  Transponer
!>          = 'C':  Transpuesta conjugada
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de miembros derechos (right-hand-sides), es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX, dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U tal como se calcula con CGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como se calcula con CGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó equilibrado de columnas a A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y las cotas
!>     de error correctamente.
!>

C

!>          C es un array REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si C es de entrada, cada elemento de C debería ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos que
!>     el resultado se desborde por abajo o por arriba. Los errores de redondeo durante el escalado
!>     conducen a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>     La matriz de miembros derechos B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es un array COMPLEX, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como se calcula con CGETRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un array REAL, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo hacia atrás
!>     componente a componente para el miembro derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto se calcula con CLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué cotas de error devolver (véanse ERRS_N
!>     y ERRS_C).
!>     Si N_NORMS >= 1 devuelve cotas de error en norma.
!>     Si N_NORMS >= 2 devuelve cotas de error componente a componente.
!>

ERRS_N

!>          ERRS_N es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada miembro derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error como se describe
!>     a continuación. Actualmente se devuelven hasta tres piezas de información.
!>
!>     El primer índice en ERRS_N(i,:) corresponde al i-ésimo
!>     miembro derecho.
!>
!>     El segundo índice en ERRS_N(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  cota de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Esta cota de error solo
!>              debería confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco en norma estimado.  Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz apropiadamente escaladaix Z.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              radix de modo que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Esta subrutina es responsable únicamente de establecer el segundo campo
!>     anterior.
!>     Consulte Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

ERRS_C

!>          ERRS_C es un arreglo REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro derecho, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El arreglo está indexado por el segundo miembro derecho i (del cual
!>     depende el error relativo componente a componente), y el tipo de
!>     información de error descrito a continuación. Actualmente se devuelven hasta tres
!>     piezas de información para cada segundo miembro derecho. Si
!>     no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
!>     no se accede a ERRS_C.  Si N_ERR_BNDS < 3, entonces se devuelven como máximo
!>     las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERRS_C(i,:) corresponde al i-ésimo
!>     segundo miembro derecho.
!>
!>     El segundo índice en ERRS_C(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco componente a componente estimado.  Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la radix de modo que todas las sumas absolutas de
!>              filas de Z sean aproximadamente 1.
!>
!>     Esta subrutina es responsable únicamente de establecer el segundo campo
!>     anterior.
!>     Consulte Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

RES

!>          RES es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para mantener el residuo intermedio.
!>

AYB

!>          AYB es un arreglo REAL, dimensión (N)
!>     Espacio de trabajo.
!>

DY

!>          DY es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para mantener la solución intermedia.
!>

Y_TAIL

!>          Y_TAIL es un arreglo COMPLEX, dimensión (N)
!>     Espacio de trabajo para mantener los bits finales de la solución intermedia.
!>

RCOND

!>          RCOND es REAL
!>     Número de condición recíproco escalado.  Esta es una estimación del
!>     número de condición recíproco de Skeel de la matriz A después de
!>     la equilibración (si se hizo).  Si esto es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo.  Tenga en cuenta que el error puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece estar mal
!>     condicionada.
!>

ITHRESH

!>          ITHRESH es INTEGER
!>     El número máximo de cálculos de residuo permitidos para
!>     el refinamiento. El valor predeterminado es 10. Para 'aggressive' establecer a 100 para
!>     permitir la convergencia usando factorizaciones aproximadas o
!>     factorizaciones distintas de LU. Si la factorización usa una
!>     técnica distinta de la eliminación gaussiana, las garantías en
!>     ERRS_N y ERRS_C pueden dejar de ser confiables.
!>

RTHRESH

!>          RTHRESH es REAL
!>     Determina cuándo detener el refinamiento si la estimación de error deja de
!>     disminuir. El refinamiento se detendrá cuando la siguiente solución ya no
!>     satisfaga norm(dx_{i+1}) < RTHRESH * norm(dx_i) donde norm(Z) es
!>     la norma infinita de Z. RTHRESH satisface 0 < RTHRESH <= 1. El
!>     valor predeterminado es 0.5. Para 'aggressive' establecer a 0.9 para permitir
!>     la convergencia en matrices extremadamente mal condicionadas. Consulte LAWN 165
!>     para más detalles.
!>

DZ_UB

!>          DZ_UB es REAL
!>     Determina cuándo comenzar a considerar la convergencia componente a componente.
!>     La convergencia componente a componente solo se considera después de que cada componente
!>     de la solución Y sea estable, lo cual definimos como el cambio
!>     relativo en cada componente sea menor que DZ_UB. El valor predeterminado
!>     es 0.25, requiriendo que el primer bit sea estable. Consulte LAWN 165 para
!>     más detalles.
!>

IGNORE_CWISE

!>          IGNORE_CWISE es LOGICAL
!>     Si es .TRUE. entonces ignorar la convergencia componente a componente. El valor predeterminado
!>     es .FALSE..
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  si INFO = -i, el i-ésimo argumento de CGETRS tenía un valor
!>             ilegal
!>
