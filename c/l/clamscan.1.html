--scan-mail[=yes(*)/no]
Analiza los archivos de correo electrónico. Si desactivas esta opción, los archivos originales se seguirán analizando, pero sin analizar mensajes/archivos adjuntos individuales.
--phishing-sigs[=yes(*)/no]
Habilita la detección de phishing basada en firmas de correo electrónico.
--phishing-scan-urls[=yes(*)/no]
Habilita la detección de phishing basada en firmas de URL (Heuristics.Phishing.Email.*)
--heuristic-alerts[=yes(*)/no]
En algunos casos (por ejemplo, malware complejo, exploits en archivos gráficos, y otros), ClamAV utiliza algoritmos especiales para proporcionar una detección precisa. Esta opción se puede utilizar para controlar la detección algorítmica.
--heuristic-scan-precedence[=yes/no(*)]
Permite que la coincidencia heurística tenga precedencia. Cuando está habilitado, si un escaneo heurístico (como phishingScan) detecta un posible virus/phishing, detendrá el escaneo inmediatamente. Recomendado, ahorra tiempo de escaneo de CPU. Cuando está deshabilitado, los virus/phishing detectados por escaneos heurísticos solo se informarán al final de un escaneo. Si un archivo comprimido contiene tanto un virus/phishing detectado heurísticamente como malware real, se informará el malware real. Mantenga esta opción deshabilitada si tiene la intención de manejar los virus "Heuristics.*" de manera diferente al malware "real". Si se encuentra primero un virus no detectado heurísticamente (basado en firmas), el escaneo se interrumpe inmediatamente, independientemente de esta opción de configuración.
--normalize[=yes(*)/no]
Normaliza (comprime espacios en blanco, convierte a minúsculas, etc.) archivos html, script y de texto. Usa normalize=no para compatibilidad con yara.
--scan-pe[=yes(*)/no]
PE significa Portable Executable (Ejecutable Portátil): es un formato de archivo ejecutable utilizado en todas las versiones de 32 bits de los sistemas operativos Windows. Por defecto, ClamAV realiza un análisis más profundo de los archivos ejecutables e intenta descomprimir empaquetadores de ejecutables populares como UPX, Petite y FSG. Si desactivas esta opción, los archivos originales se seguirán analizando pero sin procesamiento adicional.
--scan-elf[=yes(*)/no]
Executable and Linking Format (ELF) es un formato estándar para ejecutables UN*X. Esta opción controla el soporte ELF. Si la desactivas, los archivos originales se seguirán analizando pero sin procesamiento adicional.
--scan-ole2[=yes(*)/no]
Analiza documentos de Microsoft Office y archivos .msi. Si desactivas esta opción, los archivos originales se seguirán analizando pero sin procesamiento adicional.
--scan-pdf[=yes(*)/no]
Analiza dentro de archivos PDF. Si desactivas esta opción, los archivos originales se seguirán analizando, pero sin decodificación y procesamiento adicional.
--scan-swf[=yes(*)/no]
Analiza archivos SWF. Si desactivas esta opción, los archivos originales se seguirán analizando pero sin procesamiento adicional.
--scan-html[=yes(*)/no]
Detecta, normaliza/descifra y analiza archivos HTML y scripts incrustados. Si desactivas esta opción, los archivos originales se seguirán analizando, pero sin procesamiento adicional.
--scan-xmldocs[=yes(*)/no]
Analiza archivos de documentos basados en XML compatibles con libclamav. Si desactivas esta opción, los archivos originales se seguirán analizando, pero sin procesamiento adicional.
--scan-hwp3[=yes(*)/no]
Analiza archivos HWP3. Si desactivas esta opción, los archivos originales se seguirán analizando, pero sin procesamiento adicional.
--scan-archive[=yes(*)/no]
Analiza archivos compatibles con libclamav. Si desactivas esta opción, los archivos originales se seguirán analizando, pero sin desempaquetar y procesamiento adicional.
--scan-image[=yes(*)/no]
Esta opción habilita el análisis de imágenes (gráficos). Si desactivas esta opción, los archivos originales se seguirán analizando, pero sin procesamiento adicional.
--scan-image-fuzzy-hash[=yes(*)/no]
Esta opción habilita la detección calculando un hash difuso de archivos de imagen (gráficos). Las firmas que utilizan hashes difusos de imágenes suelen coincidir con archivos y documentos al identificar imágenes incrustadas o adjuntas a esos archivos. Si desactivas esta opción, es posible que algunos archivos ya no se detecten.
--alert-broken[=yes/no(*)]
Alerta sobre archivos ejecutables rotos (PE y ELF).
--alert-encrypted[=yes/no(*)]
Alerta sobre archivos y documentos cifrados (.zip, .7zip, .rar, .pdf cifrados).
--alert-encrypted-archive[=yes/no(*)]
Alerta sobre archivos cifrados (.zip, .7zip, .rar, .pdf cifrados).
--alert-encrypted-doc[=yes/no(*)]
Alerta sobre documentos cifrados (.zip, .7zip, .rar, .pdf cifrados).
--alert-macros[=yes/no(*)]

--alert-exceeds-max[=yes/no(*)]
Alerta sobre archivos que exceden el tamaño máximo de archivo, el tamaño máximo de escaneo o el límite máximo de recursión (Heuristics.Limits.Exceeded).
--alert-phishing-ssl[=yes/no(*)]

--alert-phishing-cloak[=yes/no(*)]
Alerta sobre correos electrónicos que contienen URL ofuscadas (puede generar algunos falsos positivos).
--alert-partition-intersection[=yes/no(*)]
Detecta intersecciones de particiones en imágenes de disco sin procesar utilizando heurísticas.
--nocerts
Deshabilita la verificación de la cadena de certificados de Authenticode en archivos PE.
--dumpcerts
Descarga la cadena de certificados de Authenticode en archivos PE.
--max-scantime=#n
El tiempo máximo de escaneo antes de rendirse. El valor está en milisegundos. El valor 0 deshabilita el límite. Esta opción protege su sistema contra ataques de DoS (por defecto: 120000 = 120s o 2min)
--max-filesize=#n
Extrae y analiza como máximo #n bytes de cada archivo. Puede introducir el valor en kilobytes en el formato xK o xk, o en megabytes en el formato xM o xm, donde x es un número. Esta opción protege su sistema contra ataques de DoS (por defecto: 100 MB, máximo: 2 GB)
--max-scansize=#n
Extrae y analiza como máximo #n bytes de cada archivo. El tamaño del archivo comprimido más la suma de los tamaños de todos los archivos dentro del archivo comprimido cuentan para el tamaño del escaneo. Por ejemplo, un archivo comprimido de 1 MB sin descomprimir que contiene un solo archivo interno de 1 MB cuenta como 2 MB para max-scansize. Puede introducir el valor en kilobytes en el formato xK o xk, o en megabytes en el formato xM o xm, donde x es un número. Esta opción protege su sistema contra ataques de DoS (por defecto: 400 MB)
--max-files=#n
Extrae como máximo #n archivos de cada archivo analizado (cuando este es un archivo comprimido, un documento u otro tipo de contenedor). Esta opción protege su sistema contra ataques de DoS (por defecto: 10000)
--max-recursion=#n
Establece el límite de nivel de recursión de archivos comprimidos. Esta opción protege su sistema contra ataques de DoS (por defecto: 17) (máximo: 100).
--max-dir-recursion=#n
Profundidad máxima a la que se analizan los directorios (por defecto: 15).
--max-embeddedpe=#n
Tamaño máximo de archivo para comprobar si contiene PE incrustado. Puede introducir el valor en kilobytes en el formato xK o xk, o en megabytes en el formato xM o xm, donde x es un número (por defecto: 40 MB).
--max-htmlnormalize=#n
Tamaño máximo de archivo HTML para normalizar. Puede introducir el valor en kilobytes en el formato xK o xk, o en megabytes en el formato xM o xm, donde x es un número (por defecto: 40 MB).
--max-htmlnotags=#n
Tamaño máximo de archivo HTML normalizado para analizar. Puede introducir el valor en kilobytes en el formato xK o xk, o en megabytes en el formato xM o xm, donde x es un número (por defecto: 8 MB).
--max-scriptnormalize=#n
Tamaño máximo de archivo de script para normalizar. Puede introducir el valor en kilobytes en el formato xK o xk, o en megabytes en el formato xM o xm, donde x es un número (por defecto: 20 MB).
--max-ziptypercg=#n
Tamaño máximo de zip para reanalizar tipo. Puede introducir el valor en kilobytes en el formato xK o xk, o en megabytes en el formato xM o xm, donde x es un número (por defecto: 1 MB).
--max-partitions=#n
Esta opción establece el número máximo de particiones de una imagen de disco sin procesar que se analizarán. Debe ser un entero positivo (por defecto: 50).
--max-iconspe=#n
Esta opción establece el número máximo de iconos dentro de un PE que se analizarán. Debe ser un entero positivo (por defecto: 100).
--max-rechwp3=#n
Esta opción establece el número máximo de llamadas recursivas a la función de análisis HWP3 (por defecto: 16).
--pcre-match-limit=#n
Máximo de llamadas a la función de coincidencia PCRE (por defecto: 100000).
--pcre-recmatch-limit=#n
Máximo de llamadas recursivas a la función de coincidencia PCRE (por defecto: 2000).
--pcre-max-filesize=#n
Tamaño máximo de archivo para realizar la coincidencia de subfirmas PCRE (por defecto: 100 MB).
--disable-cache

Enforce FIPS-like limits on using hash algorithms for cryptographic purposes. Will disable MD5 & SHA1 FP sigs and will require '.sign' files to verify CVD authenticity.

ENVIRONMENT VARIABLES

clamscan uses the following environment variables:

LD_LIBRARY_PATH
May be used on startup to find the libclamunrar_iface shared library module to enable RAR archive support.
CVD_CERTS_DIR
Specify a directory containing the root CA cert needed to verify detached CVD digital signatures. If not provided, then clamscan will look in the default directory.

EXAMPLES

(0) Scan a single file:

clamscan file

(1) Scan a current working directory:

clamscan

(2) Scan all files (and subdirectories) in /home:

clamscan -r /home

(3) Load database from a file:

clamscan -d /tmp/newclamdb -r /tmp

(4) Scan a data stream:

cat testfile | clamscan -

(5) Scan a mail spool directory:

clamscan -r /var/spool/mail

RETURN CODES

0 : No virus found.

1 : Virus(es) found.
2 : Some error(s) occurred.
