Documentación de la función/subrutina

subrutina clatme (integer n, character dist, integer, dimension( 4 ) iseed, complex, dimension( * ) d, integer mode, real cond, complex dmax, character rsign, character upper, character sim, real, dimension( * ) ds, integer modes, real conds, integer kl, integer ku, real anorm, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) work, integer info)

CLATME

Propósito:

!>
!>    CLATME genera matrices cuadradas no simétricas aleatorias con
!>    autovalores especificados para probar programas LAPACK.
!>
!>    CLATME opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>    1. Establece la diagonal a D, donde D puede ser de entrada o
!>         calculado según MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>    2. Si UPPER='T', el triángulo superior de A se establece a valores aleatorios
!>         fuera de la distribución DIST.
!>
!>    3. Si SIM='T', A se multiplica por la izquierda por una matriz aleatoria
!>         X, cuyos valores singulares son especificados por DS, MODES y
!>         CONDS, y por la derecha por la inversa de X.
!>
!>    4. Si KL < N-1, la banda inferior se reduce a KL usando
!>         transformaciones de Householder. Si KU < N-1, la banda superior
!>         se reduce a KU.
!>
!>    5. Si ANORM no es negativo, la matriz se escala para tener
!>         norma de elemento máximo ANORM.
!>
!>    (Nota: dado que la matriz no puede reducirse más allá de la forma de Hessenberg,
!>     no hay opciones de empaquetado disponibles.)
!>

Parámetros

N 
!>          N es ENTERO
!>           El número de columnas (o filas) de A. No modificado.
!>

DIST

!>          DIST es CARÁCTER*1
!>           A la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar los autovalores/valores singulares aleatorios, y en el
!>           triángulo superior (ver UPPER).
!>           'U' => UNIFORME( 0, 1 )  ( 'U' de uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' de simétrico )
!>           'N' => NORMAL( 0, 1 )   ( 'N' de normal )
!>           'D' => uniforme en el disco complejo |z| < 1.
!>           No modificado.
!>

ISEED

!>          ISEED es arreglo ENTERO, dimensión ( 4 )
!>           A la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Debe estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros
!>           pequeños, y por lo tanto debería producir números aleatorios independientes
!>           de la máquina. Los valores de ISEED se cambian a la
!>           salida, y pueden usarse en la siguiente llamada a CLATME
!>           para continuar la misma secuencia de números aleatorios.
!>           Modificado a la salida.
!>

D

!>          D es arreglo COMPLEJO, dimensión ( N )
!>           Este arreglo se utiliza para especificar los autovalores de A. Si
!>           MODE=0, entonces D contiene los autovalores;
!>           de lo contrario, se calcularán de acuerdo con MODE, COND,
!>           DMAX y RSIGN y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es ENTERO
!>           A la entrada, esto describe cómo se especificarán los autovalores:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE está entre 1 y 4, D tiene entradas que varían
!>              de 1 a 1/COND; si está entre -1 y -4, D tiene entradas
!>              que varían de 1/COND a 1.
!>           No modificado.
!>

COND

!>          COND es REAL
!>           A la entrada, se utiliza como se describe en MODE arriba.
!>           Si se utiliza, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es COMPLEJO
!>           Si MODE no es -6, 0 ni 6, el contenido de D, tal como se
!>           calcula según MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))). Tenga en cuenta que DMAX no necesita
!>           ser positivo o real: si DMAX es negativo o complejo (o cero),
!>           D se escalará por un número negativo o complejo (o cero).
!>           Si RSIGN='F', entonces el autovalor más grande (en valor absoluto) será
!>           igual a DMAX.
!>           No modificado.
!>

RSIGN

!>          RSIGN es CARÁCTER*1
!>           Si MODE no es 0, 6, ni -6, y RSIGN='T', entonces los
!>           elementos de D, tal como se calculan según MODE y COND, se
!>           multiplicarán por un número complejo aleatorio del círculo unitario
!>           |z| = 1. Si RSIGN='F', no se hará. RSIGN solo puede tener los
!>           valores 'T' o 'F'.
!>           No modificado.
!>

UPPER

!>          UPPER es CARÁCTER*1
!>           Si UPPER='T', entonces los elementos de A por encima de la diagonal
!>           se establecerán a números aleatorios de DIST. Si UPPER='F',
!>           no se hará. UPPER solo puede tener los valores 'T' o 'F'.
!>           No modificado.
!>

SIM

!>          SIM es CARÁCTER*1
!>           Si SIM='T', entonces A será operado por a , es decir, multiplicado por la izquierda por una matriz X y
!>           por la derecha por la inversa de X. X = U S V, donde U y V son
!>           matrices unitarias aleatorias y S es una matriz (diagonal) de
!>           valores singulares especificados por DS, MODES y CONDS. Si
!>           SIM='F', entonces A no será transformado.
!>           No modificado.
!>

DS

!>          DS es arreglo REAL, dimensión ( N )
!>           Este arreglo se utiliza para especificar los valores singulares de X,
!>           de la misma manera que D especifica los autovalores de A.
!>           Si MODE=0, DS contiene los valores singulares, que
!>           no pueden ser cero.
!>           Modificado si MODE es distinto de cero.
!>

MODES

!>          MODES es ENTERO
!>

CONDS

!>          CONDS es REAL
!>           Similar a MODE y COND, pero para especificar la diagonal
!>           de S. MODES=-6 y +6 no están permitidos (ya que resultarían
!>           en autovalores aleatoriamente mal condicionados.)
!>

KL

!>          KL es ENTERO
!>           Esto especifica el ancho de banda inferior de la matriz. KL=1
!>           especifica la forma de Hessenberg superior. Si KL es al menos N-1,
!>           entonces A tendrá ancho de banda inferior completo.
!>           No modificado.
!>

KU

!>          KU es ENTERO
!>           Esto especifica el ancho de banda superior de la matriz. KU=1
!>           especifica la forma de Hessenberg inferior. Si KU es al menos N-1,
!>           entonces A tendrá ancho de banda superior completo; si KU y KL
!>           son ambos al menos N-1, entonces A será densa. Solo uno de
!>           KU y KL puede ser menor que N-1.
!>           No modificado.
!>

ANORM

!>          ANORM es REAL
!>

Si ANORM no es negativo, entonces A será escalado por un número real no negativo para que la norma del elemento máximo de A sea igual a ANORM. !> No modificado. !>

A

!>          A es un arreglo COMPLEX, dimensión ( LDA, N )
!>          En la salida, A es la matriz de prueba deseada.
!>          Modificado.
!>

LDA

!>          LDA es INTEGER
!>          LDA especifica la primera dimensión de A tal como se declara en el
!>          programa que lo llama. LDA debe ser al menos M.
!>          No modificado.
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión ( 3*N )
!>          Espacio de trabajo.
!>          Modificado.
!>

INFO

!>          INFO es INTEGER
!>          Código de error. En la salida, INFO se establecerá en uno de los
!>          siguientes valores:
!>             0 => retorno normal
!>            -1 => N negativo
!>            -2 => DIST cadena ilegal
!>            -5 => MODE no está en el rango de -6 a 6
!>            -6 => COND menor que 1.0, y MODE no es ni -6, 0 ni 6
!>            -9 => RSIGN no es 'T' ni 'F'
!>           -10 => UPPER no es 'T' ni 'F'
!>           -11 => SIM   no es 'T' ni 'F'
!>           -12 => MODES=0 y DS tiene un valor singular cero.
!>           -13 => MODES no está en el rango de -5 a 5.
!>           -14 => MODES es distinto de cero y CONDS es menor que 1.
!>           -15 => KL es menor que 1.
!>           -16 => KU es menor que 1, o KL y KU son ambos menores que
!>                  N-1.
!>           -19 => LDA es menor que M.
!>            1  => Error en el retorno de CLATM1 (calculando D)
!>            2  => No se puede escalar a DMAX (el eigenvalor máximo es 0)
!>            3  => Error en el retorno de SLATM1 (calculando DS)
!>            4  => Error en el retorno de CLARGE
!>            5  => Valor singular cero de SLATM1.
!>
