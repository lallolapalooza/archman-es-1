close_range(2) Manual de Llamadas al Sistema close_range(2)

NOMBRE

close_range - cerrar todos los descriptores de archivo en un rango dado

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <unistd.h>
#include <linux/close_range.h> /* Definición de las constantes CLOSE_RANGE_* */
int close_range(unsigned int first, unsigned int last, int flags);

DESCRIPCIÓN

La llamada al sistema close_range() cierra todos los descriptores de archivo abiertos desde first hasta last (incluidos).

Actualmente, los errores al cerrar un descriptor de archivo dado se ignoran.

flags es una máscara de bits que contiene 0 o más de las siguientes opciones:

CLOSE_RANGE_CLOEXEC (desde Linux 5.11)
Establece el flag de cierre al ejecutar (close-on-exec) en los descriptores de archivo especificados, en lugar de cerrarlos inmediatamente.
CLOSE_RANGE_UNSHARE
Desvincula (unshare) los descriptores de archivo especificados de cualquier otro proceso antes de cerrarlos, evitando condiciones de carrera con otros hilos que comparten la tabla de descriptores de archivo.

VALOR DE RETORNO

En caso de éxito, close_range() devuelve 0. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
flags no es válido, o first es mayor que last.

Los siguientes errores pueden ocurrir con CLOSE_RANGE_UNSHARE (al construir la nueva tabla de descriptores):

EMFILE
El número de descriptores de archivo abiertos excede el límite especificado en /proc/sys/fs/nr_open (ver proc(5)). Este error puede ocurrir en situaciones donde ese límite se redujo antes de una llamada a close_range() donde se especifica el flag CLOSE_RANGE_UNSHARE.
ENOMEM
No había suficiente memoria del kernel disponible.

ESTANDARES

Ninguno.

HISTORIA

FreeBSD. Linux 5.9, glibc 2.34.

NOTAS

Cerrar todos los descriptores de archivo abiertos

Para evitar cerrar ciegamente descriptores de archivo en el rango de posibles descriptores de archivo, esto a veces se implementa (en Linux) listando los descriptores de archivo abiertos en /proc/self/fd/ y llamando a close(2) en cada uno. close_range() puede encargarse de esto sin requerir /proc y dentro de una única llamada al sistema, lo que proporciona importantes beneficios de rendimiento.

Cerrar descriptores de archivo antes de exec

Los descriptores de archivo pueden cerrarse de forma segura usando


/* no queremos nada después de stderr aquí */
close_range(3, ~0U, CLOSE_RANGE_UNSHARE);
execve(....);

CLOSE_RANGE_UNSHARE es conceptualmente equivalente a


unshare(CLONE_FILES);
close_range(first, last, 0);

pero puede ser más eficiente: si el rango desvinculado se extiende más allá del número máximo actual de descriptores de archivo asignados en la tabla de descriptores de archivo del llamante (el caso común cuando last es ~0U), el kernel desvinculará una nueva tabla de descriptores de archivo para el llamante hasta first, copiando tan pocos descriptores de archivo como sea posible. Esto evita por completo las llamadas posteriores a close(2); toda la operación se completa una vez que la tabla se desvincula.

Cerrar archivos en exec

Esto es particularmente útil en casos donde múltiples pasos de preparación pre-exec corren el riesgo de entrar en conflicto entre sí. Por ejemplo, configurar un perfil seccomp(2) puede entrar en conflicto con una llamada a close_range(): si los descriptores de archivo se cierran antes de que se configure el perfil seccomp(2), la configuración del perfil no puede usarlos ni controlar su cierre; si los descriptores de archivo se cierran después, el perfil seccomp no puede bloquear la llamada close_range() ni ninguna opción de respaldo. Usar CLOSE_RANGE_CLOEXEC evita esto: los descriptores pueden marcarse antes de que se configure el perfil seccomp(2), y el perfil puede controlar el acceso a close_range() sin afectar al proceso llamante.

EJEMPLOS

El programa que se muestra a continuación abre los archivos cuyos nombres se encuentran en los argumentos de la línea de comandos, muestra la lista de archivos que ha abierto (iterando a través de las entradas en /proc/PID/fd), usa close_range() para cerrar todos los descriptores de archivo mayores o iguales a 3, y luego, una vez más, muestra la lista de archivos abiertos del proceso. El siguiente ejemplo demuestra el uso del programa:


$ touch /tmp/a /tmp/b /tmp/c;
$ ./a.out /tmp/a /tmp/b /tmp/c;
/tmp/a abierto como FD 3
/tmp/b abierto como FD 4
/tmp/c abierto como FD 5
/proc/self/fd/0 ==> /dev/pts/1
/proc/self/fd/1 ==> /dev/pts/1
/proc/self/fd/2 ==> /dev/pts/1
/proc/self/fd/3 ==> /tmp/a
/proc/self/fd/4 ==> /tmp/b
/proc/self/fd/5 ==> /tmp/c
/proc/self/fd/6 ==> /proc/9005/fd
========= A punto de llamar a close_range() =======
/proc/self/fd/0 ==> /dev/pts/1
/proc/self/fd/1 ==> /dev/pts/1
/proc/self/fd/2 ==> /dev/pts/1
/proc/self/fd/3 ==> /proc/9005/fd

Tenga en cuenta que las líneas que muestran la ruta /proc/9005/fd son el resultado de las llamadas a opendir(3).

Código fuente del programa

#define _GNU_SOURCE
#include <dirent.h>
#include <fcntl.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
/* Muestra el contenido de los enlaces simbólicos en /proc/self/fd */
static void
show_fds(void)
{
    DIR            *dirp;
    char           path[PATH_MAX], target[PATH_MAX];
    ssize_t        len;
    struct dirent  *dp;
    dirp = opendir("/proc/self/fd");
    if (dirp  == NULL) {
        perror("opendir");
        exit(EXIT_FAILURE);
    }
    for (;;) {
        dp = readdir(dirp);
        if (dp == NULL)
            break;
        if (dp->d_type == DT_LNK) {
            snprintf(path, sizeof(path), "/proc/self/fd/%s",
                     dp->d_name);
            len = readlink(path, target, sizeof(target));
            printf("%s ==> %.*s\n", path, (int) len, target);
        }
    }
    closedir(dirp);
}
int
main(int argc, char *argv[])
{
    int  fd;
    for (size_t j = 1; j < argc; j++) {
        fd = open(argv[j], O_RDONLY);
        if (fd == -1) {
            perror(argv[j]);
            exit(EXIT_FAILURE);
        }
        printf("%s opened as FD %d\n", argv[j], fd);
    }
    show_fds();
    printf("========= About to call close_range() =======\n");
    if (close_range(3, ~0U, 0) == -1) {
        perror("close_range");
        exit(EXIT_FAILURE);
    }
    show_fds();
    exit(EXIT_FAILURE);
}
