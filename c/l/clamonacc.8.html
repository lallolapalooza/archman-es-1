NOMBRE

clamonacc - un demonio de escaneo antivirus sobre acceso y cliente de clamd

SINOPSIS

clamonacc [opciones]

DESCRIPCIÓN

El demonio clamonacc se registra para recibir notificaciones de acceso a archivos del kernel de Linux y, en respuesta, envía escaneos al demonio de escaneo clamd para obtener un veredicto. El acceso sobre la marcha solo está disponible en sistemas Linux. En Linux, el acceso sobre la marcha requiere una versión del kernel >= 3.8. Esto se debe a que utiliza una API del kernel llamada fanotify para bloquear procesos que intentan acceder a archivos maliciosos. Esta prevención ocurre en el espacio del kernel, y por lo tanto ofrece una protección más fuerte que una solución puramente en el espacio del usuario.

OPCIONES

-h, --help
Muestra la información de ayuda y sale.
-V, --version
Imprime el número de versión y sale.
-v, --verbose
Sé detallado.
-l ARCHIVO, --log=ARCHIVO
Guarda el informe de escaneo en ARCHIVO.
-F, --foreground
Ejecuta en primer plano; no te desvincules.
-W ARCHIVO, --watch-list=ARCHIVO
Observa directorios de ARCHIVO.
-e ARCHIVO, --exclude-list=ARCHIVO
Excluye directorios de ARCHIVO.
-p A[:I], --ping A[:I]
Haz ping a clamd hasta [A] veces en intervalos opcionales [I] hasta que responda.
-w, --wait
Espera hasta 30 segundos para que clamd se inicie. Opcionalmente úsalo junto con ping para establecer los intentos [A] y el intervalo [I] para comprobar clamd.
--remove
Elimina archivos infectados. Ten cuidado.
--move=DIRECTORIO
Mueve archivos infectados al DIRECTORIO.
--copy=DIRECTORIO
Copia archivos infectados al DIRECTORIO.
-c ARCHIVO, --config-file=ARCHIVO
Lee la configuración desde ARCHIVO.
--allmatch
Continúa escaneando dentro del archivo después de encontrar una coincidencia.
--fdpass
Pasa los permisos del descriptor de archivo a clamd. Esto es útil si clamd se está ejecutando como un usuario diferente, ya que es más rápido que transmitir el archivo a clamd. Solo disponible si se conecta a clamd a través de un socket local (unix).
--stream
Fuerza la transmisión del archivo a clamd. Esto generalmente no es necesario ya que clamdscan detecta automáticamente si la transmisión es necesaria. Esta opción solo existe para fines de depuración y prueba, en todos los demás casos se prefiere --fdpass.

SEÑALES

ClamOnAcc reconoce las siguientes señales:

SIGHUP
Reabre el archivo de registro.
SIGUSR2
Recarga las bases de datos de firmas.
SIGTERM
Realiza una salida limpia.
