Documentación de Función/Subrutina

real function cla_porcond_x (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, complex, dimension( * ) x, integer info, complex, dimension( * ) work, real, dimension( * ) rwork)

CLA_PORCOND_X calcula el número de condición de la norma infinito de op(A)*diag(x) para matrices hermíticas definidas positivas.

Propósito:

!>
!>    CLA_PORCOND_X Calcula el número de condición de la norma infinito de
!>    op(A) * diag(X) donde X es un vector COMPLEJO.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEJO, de dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**H*U o A = L*L**H, tal como fue calculada por CPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

X

!>          X es un array COMPLEJO, de dimensión (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N).
!>     Espacio de trabajo.
!>
