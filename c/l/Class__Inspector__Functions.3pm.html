Class::Inspector::Functions(3) Documentación de Perl contribuida por el usuario Class::Inspector::Functions(3)

NOMBRE

Class::Inspector::Functions - Obtener información sobre una clase y su estructura

VERSIÓN

versión 1.36

SINOPSIS

use Class::Inspector::Functions;
# ¡Class::Inspector proporciona una interfaz no contaminante basada en métodos!

# ¿Está una clase instalada y/o cargada?
installed( 'Foo::Class' );
loaded( 'Foo::Class' );

# Información relacionada con el archivo
filename( 'Foo::Class' );
resolved_filename( 'Foo::Class' );

# Obtener información relacionada con subrutinas
functions( 'Foo::Class' );
function_refs( 'Foo::Class' );
function_exists( 'Foo::Class', 'bar' );
methods( 'Foo::Class', 'full', 'public' );

# Encontrar todas las subclases cargadas o algo similar
subclasses( 'Foo::Class' );

DESCRIPCIÓN

Class::Inspector::Functions es una interfaz basada en funciones de Class::Inspector. Para una documentación exhaustiva de las funciones disponibles, por favor, consulta el manual del módulo principal.

Exportaciones

Las siguientes funciones se exportan por defecto.

installed
loaded
filename
functions
methods
subclasses

Las siguientes funciones se exportan solo a petición.

resolved_filename
loaded_filename
function_refs
function_exists

Todas las funciones pueden ser importadas usando la etiqueta ":ALL".
