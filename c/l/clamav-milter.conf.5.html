NOMBRE

clamav-milter.conf - Archivo de configuración de clamav-milter

DESCRIPCIÓN

clamav-milter.conf contiene las opciones de configuración para clamav-milter(8).

FORMATO DEL ARCHIVO

El archivo consta de comentarios y opciones con argumentos. Cada línea que comienza con el símbolo de almohadilla (#) es ignorada por el analizador. Las opciones y los argumentos distinguen entre mayúsculas y minúsculas y tienen la forma Opción Argumento. Los argumentos son de los siguientes tipos:

BOOL
Valor booleano (yes/no o true/false o 1/0).
STRING
Cadena de texto sin caracteres en blanco.
SIZE
Tamaño en bytes. Puede usar los modificadores 'M' o 'm' para megabytes y 'K' o 'k' para kilobytes.
NUMBER
Entero sin signo.

OPCIONES PRINCIPALES

Ejemplo
Si se establece esta opción, clamav-milter no se ejecutará.
MilterSocket STRING
Define la interfaz a través de la cual nos comunicamos con sendmail. Esta opción es obligatoria.
Los formatos posibles son:
[[unix|local]:]/ruta/al/archivo - para especificar un socket de dominio unix
inet:puerto@[nombre-de-host|dirección-ip] - para especificar un socket ipv4
inet6:puerto@[nombre-de-host|dirección-ip] - para especificar un socket ipv6
Predeterminado: sin establecer
MilterSocketGroup STRING
Define la propiedad de grupo para el socket del filtro (unix).
Predeterminado: deshabilitado (el grupo primario del usuario que ejecuta clamd)
MilterSocketMode STRING
Establece los permisos del socket del filtro (unix) al modo especificado.
Predeterminado: deshabilitado (obedece umask)
FixStaleSocket BOOL
Elimina el socket obsoleto después de un apagado anormal.
Predeterminado: sí
User STRING
Ejecutar como otro usuario (clamav-milter debe ser iniciado por root para que esta opción funcione)
Predeterminado: sin establecer (no descartar privilegios)
ReadTimeout NUMBER
La espera de datos de clamd expirará después de este tiempo (segundos).
Predeterminado: 120
Foreground BOOL
No bifurcar en segundo plano.
Predeterminado: no
Chroot STRING
Cambia al directorio raíz especificado. El cambio de raíz se realiza justo después de leer el archivo de configuración y antes de descartar privilegios.
Predeterminado: sin establecer (no cambiar de raíz)
PidFile STRING
Escribe el pid del demonio en el archivo especificado.
Predeterminado: deshabilitado
TemporaryDirectory STRING
Ruta opcional al directorio temporal global.
Predeterminado: específico del sistema (normalmente /tmp o /var/tmp).

OPCIONES DE CLAMD

ClamdSocket STRING
Define el socket de clamd al que conectarse para el análisis. Esta opción es obligatoria. Sintaxis:
ClamdSocket unix:ruta
ClamdSocket tcp:host:puerto
La primera sintaxis especifica un socket unix local (necesita una ruta absoluta) p. ej.:
ClamdSocket unix:/run/clamav/clamd.sock
La segunda sintaxis especifica un socket tcp local o remoto: el host puede ser un nombre de host o una dirección ip; el campo ":puerto" solo es necesario para direcciones IPv6, de lo contrario el valor predeterminado es 3310 p. ej.:
ClamdSocket tcp:192.168.0.1
Esta opción puede repetirse varias veces con diferentes sockets o incluso con el mismo socket: los servidores clamd se seleccionarán de forma round-robin.
Predeterminado: sin valor predeterminado

EXCLUSIONES

LocalNet STRING
Los mensajes que se originen en estos hosts/redes no serán analizados. Esta opción toma un par host(nombre)/máscara en notación CIDR y puede repetirse varias veces. Si se omite "/máscara", se asume un host. Para especificar un correo electrónico local, no smtp, use la palabra clave "local"
Predeterminado: sin establecer (analizar todo independientemente del origen)
AllowList STRING
Esta opción especifica un archivo que contiene una lista de expresiones regulares POSIX básicas. Las direcciones (enviadas a o desde - ver más abajo) que coincidan con estas expresiones regulares no serán analizadas. Opcionalmente, cada línea puede comenzar con la cadena "From:" o "To:" (nota: sin espacios en blanco después de los dos puntos) indicando si es, respectivamente, el remitente o el destinatario el que debe ser permitido. Si falta el campo, se asume "To:". Las líneas que comienzan con #, : o ! se ignoran.
Predeterminado: sin establecer (no se aplica ninguna exclusión)
SkipAuthenticated STRING
Los mensajes de usuarios SMTP autenticados que coincidan con esta expresión regular POSIX extendida (tipo egrep) no serán analizados. Como alternativa, se puede especificar un archivo que contiene una lista simple (no regex) de nombres (uno por línea) usando el prefijo "file:". p. ej. SkipAuthenticated file:/etc/good_guys. Nota: ¡este es el nombre de inicio de sesión AUTH!
Predeterminado: sin establecer (no se permite nada basado en la autenticación SMTP)
MaxFileSize SIZE
Los mensajes más grandes que este valor no serán analizados. Asegúrese de que este valor sea menor o igual que StreamMaxLength en clamd.conf
Predeterminado: 100M

ACCIONES

El siguiente grupo de opciones controla el proceso de entrega bajo diferentes circunstancias. Las siguientes acciones están disponibles:
- Aceptar: El mensaje es aceptado para su entrega
- Rechazar: Rechazar inmediatamente la entrega (se devuelve un error 5xx al par)
- Diferir: Devolver un mensaje de fallo temporal (4xx) al par
- Blackhole (no disponible para OnFail): Como Aceptar pero el mensaje se envía al olvido
- Poner en cuarentena (no disponible para OnFail): Como Aceptar pero el mensaje se pone en cuarentena en lugar de ser entregado. NOTA: En Sendmail la cola de cuarentena se puede examinar mediante mailq -qQ. Para Postfix esto hace que el mensaje se mantenga en espera.

OnClean STRING
Acción a realizar en mensajes limpios (mayormente útil para pruebas)
Predeterminado: Aceptar
OnInfected STRING
Acción a realizar en mensajes infectados
Predeterminado: Poner en cuarentena
OnFail STRING
Acción a realizar en condiciones de error (esto incluye fallos al asignar estructuras de datos, falta de analizadores disponibles, tiempos de espera de red, respuestas de analizador desconocidas y similares)
Predeterminado: Diferir
RejectMsg STRING
Esta opción le permite establecer una razón de rechazo específica para mensajes infectados y por lo tanto solo es útil junto con "OnInfected Reject". La cadena "%v", si está presente, será reemplazada por el nombre del virus.
Predeterminado: específico del MTA
AddHeader STRING
Si esta opción se establece en "Replace" (o "Yes"), se añadirá una cabecera "X-Virus-Scanned" y una "X-Virus-Status" a cada mensaje procesado, posiblemente reemplazando cabeceras existentes. Si se establece en Add, las cabeceras X-Virus se añaden posiblemente encima dede los existentes. Tenga en cuenta que, mientras que "Replace" puede romper potencialmente las firmas DKIM, "Add" puede confundir a procmail y filtros similares.
Por defecto: no
ReportHostname STRING
Cuando AddHeader está en uso, esta opción le permite establecer el hostname reportado. Esto puede ser deseable para evitar la fuga de nombres internos. Si no se establece, se usa el nombre real de la máquina.
Por defecto: deshabilitado
VirusAction STRING
Ejecuta un comando (posiblemente buscando en PATH) cuando se encuentra un mensaje infectado. Los siguientes parámetros se pasan al programa invocado en este orden: nombre del virus, id de la cola, remitente, destino, asunto, id del mensaje, fecha del mensaje. Nota 1: esto requiere que las macros de MTA estén disponibles (ver LogInfected más abajo). Nota 2: el proceso se invoca en el contexto de clamav-milter. Nota 3: clamav-milter esperará a que el proceso termine. Sea rápido o haga un fork para evitar retrasos innecesarios en la entrega de correo.
Por defecto: deshabilitado

OPCIONES DE REGISTRO

LogFile STRING
Habilita el registro en el archivo seleccionado.
Por defecto: no
LogFileUnlock BOOL
Deshabilita un bloqueo del sistema que protege contra la ejecución de clamd con el mismo archivo de configuración múltiples veces.
Por defecto: no
LogFileMaxSize SIZE
Limita el tamaño del archivo de registro. El logger se deshabilitará automáticamente si el archivo es mayor que SIZE. Un valor de 0 deshabilita el límite.
Por defecto: 1M
LogTime BOOL
Registra la hora para cada mensaje.
Por defecto: no
LogSyslog BOOL
Usa el logger del sistema (puede funcionar junto con LogFile).
Por defecto: no
LogFacility STRING
Especifica el tipo de mensajes de syslog - por favor consulte 'man syslog' para los nombres de las instalaciones.
Por defecto: LOG_LOCAL6
LogVerbose BOOL
Habilita el registro detallado.
Por defecto: no
LogInfected STRING
Esta opción le permite ajustar qué se registra cuando un mensaje está infectado. Los valores posibles son Off (por defecto - no se registra nada), Basic (se registra información mínima), Full (se registra información detallada)
Nota: Para que esto funcione correctamente en sendmail, asegúrese de que las macros msg_id, mail_addr, rcpt_addr e i estén disponibles en eom. En otras palabras, agregue una línea como: Milter.macros.eom={msg_id}, {mail_addr}, {rcpt_addr}, i a su archivo .cf. Alternativamente use la macro: define(`confMILTER_MACROS_EOM', `{msg_id}, {mail_addr}, {rcpt_addr}, i')
Postfix debería funcionar bien con la configuración predeterminada.
Por defecto: deshabilitado
LogClean STRING
Esta opción le permite ajustar qué se registra cuando no se encuentra ninguna amenaza en un mensaje escaneado.
Consulte LogInfected para los valores posibles y las advertencias.
Útil para depurar pero aumenta drásticamente el tamaño del registro.
Por defecto: deshabilitado
SupportMultipleRecipients BOOL
Esta opción afecta el comportamiento de LogInfected, LogClean y VirusAction cuando se escanea un mensaje con múltiples destinatarios:
Si SupportMultipleRecipients está desactivado (por defecto) se genera una sola entrada de registro para el mensaje y, en caso de que el mensaje se determine como malicioso, el comando indicado por VirusAction se ejecuta solo una vez. En ambos casos solo se reporta el último destinatario.
Si SupportMultipleRecipients está activado se registra una línea para cada destinatario y el comando indicado por VirusAction también se ejecuta una vez por cada destinatario.
Nota: aunque probablemente sea una buena idea habilitar esta opción, el valor por defecto está actualmente establecido en desactivado por razones de compatibilidad.
Por defecto: no

NOTAS

Todas las opciones que expresan un tamaño están limitadas a un máximo de 4GB. Los valores que lo excedan se restablecerán al máximo.
