NOMBRE

clamtk - Interfaz gráfica de usuario (gui) para Clam AntiVirus

SINOPSIS

clamtk
clamtk archivo
clamtk directorio

DESCRIPCIÓN

clamtk es un frontend para Clam AntiVirus. Está diseñado para ser un escáner de virus GUI ligero, fácil de usar y bajo demanda.

clamtk está escrito usando Perl, Python y las bibliotecas Gtk+.

OPCIONES

Actualmente no hay opciones de línea de comandos excepto las mencionadas en la sinopsis. No tiene sentido tener opciones de línea de comandos ya que se puede usar clamscan para eso. clamtk acepta un archivo o directorio como argumento para que uno pueda hacer clic derecho sobre él para escanear el objeto.

Existen plugins para agregar funcionalidad de menú contextual a administradores de archivos como Files, Dolphin, Thunar y otros.

DIAGNÓSTICOS

Es posible que necesite editar freshclam.conf y clamd.conf antes de intentar actualizar las firmas. Consulte la documentación de su distribución para más información.

VER TAMBIÉN

clamscan(1), freshclam(1), sigtool(1).
