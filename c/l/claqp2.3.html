DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine claqp2 (integer m, integer n, integer offset, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, complex, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, complex, dimension( * ) work)

CLAQP2 calcula una factorización QR con pivoteo de columnas del bloque de la matriz.

Propósito:

!>
!> CLAQP2 calcula una factorización QR con pivoteo de columnas del
!> bloque A(OFFSET+1:M,1:N).
!> El bloque A(1:OFFSET,1:N) se pivotea de forma adecuada, pero no se
!> factoriza.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

OFFSET

!>          OFFSET es INTEGER
!>          El número de filas de la matriz A que deben ser pivoteadas
!>          pero no factorizadas. OFFSET >= 0.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, el triángulo superior del bloque A(OFFSET+1:M,1:N) es
!>          el factor triangular obtenido; los elementos del bloque
!>          A(OFFSET+1:M,1:N) por debajo de la diagonal, junto con el
!>          array TAU, representan la matriz ortogonal Q como un producto de
!>          reflejos elementales. El bloque A(1:OFFSET,1:N) ha sido
!>          pivoteado de forma adecuada, pero no factorizado.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT es array INTEGER, dimension (N)
!>          En la entrada, si JPVT(i) .ne. 0, la i-ésima columna de A se permuta
!>          al frente de A*P (una columna líder); si JPVT(i) = 0,
!>          la i-ésima columna de A es una columna libre.
!>          En la salida, si JPVT(i) = k, entonces la i-ésima columna de A*P
!>          era la k-ésima columna de A.
!>

TAU

!>          TAU es array COMPLEX, dimension (min(M,N))
!>          Los factores escalares de los reflejos elementales.
!>

VN1

!>          VN1 es array REAL, dimension (N)
!>          El vector con las normas de columna parciales.
!>

VN2

!>          VN2 es array REAL, dimension (N)
!>          El vector con las normas de columna exactas.
!>

WORK

!>          WORK es array COMPLEX, dimension (N)
!>
