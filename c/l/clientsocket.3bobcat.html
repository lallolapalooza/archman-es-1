DESCRIPCIÓ

N

Un FBB::ClientSocket puede ser construido para conectarse a algún proceso servidor en internet. El socket proporcionado por el FBB:ClientSocket puede usarse para inicializar un std::istream y/o std::ostream. El std::istream se usa para leer información del proceso servidor al que el FBB::ClientSocket se conecta. El std::ostream se usa para enviar información al proceso servidor al que el FBB::ClientSocket se conecta. Dado que un socket puede considerarse un descriptor de archivo, las clases disponibles FBB::IFdStream, FBB::IFdStreamBuf, FBB::OFdStream, y FBB::OFdStreamBuf pueden usarse aquí con provecho. Nótese que tener un socket disponible no significa que esto defina el protocolo de comunicación. Es (sigue siendo) responsabilidad del programador cumplir con un protocolo existente o implementar un protocolo a medida. Esta última situación implica que la secuencia de operaciones de entrada y salida es definida por el

programador.

Un socket de cliente de Dominio Unix puede definirse usando FBB::LocalClientSocke

    #include <iostream>
    #include <string>
    #include <bobcat/clientsocket>
    #include <bobcat/ifdstream>
    #include <bobcat/ofdstream>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Proporcione el nombre del servidor y el número de puerto\n";
            return 1;
        }
        size_t     port = stoul(argv[2]);
        ClientSocket client(argv[1], port);
        int fd = client.connect();
        string line;
        cout << "Conectando al socket " << fd << endl <<
                "dirección = " << client.dottedDecimalAddress() << ", " <<
                                                                 endl <<
                "comunicación a través del puerto " << client.port() << endl;
        IFdStream in(fd);                 // flujo para leer
        OFdStream out(fd);                // flujo para escribir
        while (true)
        {
                                    // Pide una línea de texto, se detiene si
            cout << "? ";           // está vacía / no hay
            if (!getline(cin, line) || line.length() == 0)
                return 0;
            cout << "Línea leída: " << line << endl;
                                    // Devuelve la línea al servidor
            out << line.c_str() << endl;
            cout << "línea escrita\n";
            getline(in, line);      // Espera una respuesta del servidor
            cout << "Respuesta: " << line << endl;
        }
    }
    catch (Exception const &err)
    {
        cerr << err.what() << "\n" <<
                "No se puede conectar a " << argv[1] << ", puerto " <<
                argv[2] << endl;
        return 1;
}

    clientsocket(3bobcat)

    BOBCAT — Biblioteca de red del lado del cliente.

    SINOPSIS

    #include <bobcat/clientsocket> 

    class Bobcat::ClientSocket
   : public Bobcat::Socket
{
   public:
            ClientSocket();
            ClientSocket(int port, const std::string &host = "localhost");
            ClientSocket(int port, const char *host = "localhost");
            ClientSocket(const std::string &host, int port = 0);
            ClientSocket(const char *host, int port = 0);

            virtual ~ClientSocket() = default;

      bool connect(int port, const std::string &host = "localhost");
      bool connect(int port, const char *host = "localhost");
      bool connect(const std::string &host, int port = 0);
      bool connect(const char *host, int port = 0);

      bool reconnect();
   private:
      ClientSocket(const ClientSocket &other) = delete;
      ClientSocket &operator=(const ClientSocket &rhs) = delete;
};

    DESCRIPCIÓN

    Esta clase proporciona una interfaz de socket de cliente. Dado que un socket de cliente no es más que un socket de conexión, esta clase hereda de ella.

    HEREDA DE

    Socket

    CONSTRUCTOR

    ClientSocket() crea un objeto de socket de cliente nulo.

    ClientSocket(int port, const std::string &host = "localhost")

    ClientSocket(int port, const char *host = "localhost")

    ClientSocket(const std::string &host, int port = 0)

    ClientSocket(const char *host, int port = 0)

    Los constructores instancian un objeto de socket de cliente y ejecutan la función connect.

    FUNCIONES MIEMBRO

    bool connect(int port, const std::string &host = "localhost")

    bool connect(int port, const char *host = "localhost")

    bool connect(const std::string &host, int port = 0)

    bool connect(const char *host, int port = 0)

    Estas sobrecargas se utilizan para establecer una conexión de socket de cliente al host y puerto especificados. Devuelven true si la conexión se estableció correctamente, false de lo contrario. Si el puerto se establece en 0, entonces se intentará conectar a un servicio que se ejecuta en el puerto preferido para el tipo de servicio especificado.

    bool reconnect()

    Reconecta el socket de cliente si la conexión actual se perdió. Devuelve true si la reconexión fue exitosa, false en caso contrario.

    EJEMPLO

    El siguiente fragmento muestra cómo usar la clase ClientSocket. 

    #include <bobcat/clientsocket>
#include <iostream>

int main()
{
    Bobcat::ClientSocket clSock;

    // Conectar al host "localhost" en el puerto 80.
    if (clSock.connect(80, "localhost"))
    {
        std::cout << "¡Conexión establecida!" << std::endl;
        // ... enviar y recibir datos ...
    }
    else
    {
        std::cerr << "¡Error al conectar!" << std::endl;
        return 1;
    }

    return 0;
}
