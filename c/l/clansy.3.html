real function clansy (norm, uplo, n, a, lda, work)

CLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma del infinito, o el elemento de mayor valor absoluto de una matriz compleja simétrica.

Documentación de función/subrutina

real function clansy (character norm, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

CLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma del infinito, o el elemento de mayor valor absoluto de una matriz compleja simétrica.

Propósito:

!>
!> CLANSY  devuelve el valor de la norma uno, o la norma de Frobenius, o
!> la norma del infinito, o el elemento de mayor valor absoluto de una
!> matriz simétrica A.
!>

Devuelve

CLANSY 
!>
!>    CLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la norma 1 de una matriz (suma máxima de columna),
!> normI  denota la norma del infinito de una matriz (suma máxima de fila) y
!> normF  denota la norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma de matriz
!> consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en CLANSY como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se hará referencia a la parte triangular superior o
!>          inferior de la matriz simétrica A.
!>          = 'U':  Se hace referencia a la parte triangular superior de A
!>          = 'L':  Se hace referencia a la parte triangular inferior de A
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANSY se
!>          establece a cero.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>          principal de N por N de A contiene la parte triangular superior
!>          de la matriz A, y la parte triangular estrictamente inferior de A
!>          no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>          principal de N por N de A contiene la parte triangular inferior
!>          de la matriz A, y la parte triangular estrictamente superior de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' or '1' or 'O'; de lo contrario,
!>          WORK no se referencia.
!>
