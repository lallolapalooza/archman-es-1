Documentación de Función/Subrutina

subrutina clarhs (character*3 path, character xtype, character uplo, character trans, integer m, integer n, integer kl, integer ku, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldx, * ) x, integer ldx, complex, dimension( ldb, * ) b, integer ldb, integer, dimension( 4 ) iseed, integer info)

CLARHS

Propósito:

!>
!> CLARHS elige un conjunto de NRHS vectores de solución aleatorios y establece
!> los miembros independientes para el sistema lineal
!>    op(A) * X = B,
!> donde op(A) = A, A**T, o A**H, dependiendo de TRANS.
!>

Parámetros

PATH 
!>          PATH es CHARACTER*3
!>          El tipo de la matriz compleja A.  PATH puede darse en cualquier
!>          combinación de mayúsculas y minúsculas.  Las rutas válidas incluyen
!>             xGE:  Matriz general m x n
!>             xGB:  Matriz general bandada
!>             xPO:  Hermitiana definida positiva, almacenamiento 2-D
!>             xPP:  Hermitiana definida positiva empaquetada
!>             xPB:  Hermitiana definida positiva bandada
!>             xHE:  Hermitiana indefinida, almacenamiento 2-D
!>             xHP:  Hermitiana indefinida empaquetada
!>             xHB:  Hermitiana indefinida bandada
!>             xSY:  Simétrica indefinida, almacenamiento 2-D
!>             xSP:  Simétrica indefinida empaquetada
!>             xSB:  Simétrica indefinida bandada
!>             xTR:  Triangular
!>             xTP:  Triangular empaquetada
!>             xTB:  Triangular bandada
!>             xQR:  Matriz general m x n
!>             xLQ:  Matriz general m x n
!>             xQL:  Matriz general m x n
!>             xRQ:  Matriz general m x n
!>          donde el carácter inicial indica la precisión.
!>

XTYPE

!>          XTYPE es CHARACTER*1
!>          Especifica cómo se determinará la solución exacta X:
!>          = 'N':  Nueva solución; genera una X aleatoria.
!>          = 'C':  Calculada; usa el valor de X en la entrada.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Usado solo si A es simétrica o triangular; especifica si
!>          se almacena la parte triangular superior o inferior de la matriz A.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Usado solo si A es no simétrica; especifica la operación
!>          aplicada a la matriz A.
!>          = 'N':  B := A    * X  (Sin transponer)
!>          = 'T':  B := A**T * X  (Transponer)
!>          = 'C':  B := A**H * X  (Transponer conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          Usado solo si A es una matriz bandada; especifica el número de
!>          subdiagonales de A si A es una matriz bandada general o si A es
!>          simétrica o triangular y UPLO = 'L'; especifica el número
!>          de superdiagonales de A si A es simétrica o triangular y
!>          UPLO = 'U'.  0 <= KL <= M-1.
!>

KU

!>          KU es INTEGER
!>          Usado solo si A es una matriz bandada general o si A es
!>          triangular.
!>
!>          Si PATH = xGB, especifica el número de superdiagonales de A,
!>          y 0 <= KU <= N-1.
!>
!>          Si PATH = xTR, xTP, o xTB, especifica si la matriz
!>          tiene diagonal unitaria o no:
!>          = 1:  la matriz tiene diagonal no unitaria (por defecto)
!>          = 2:  la matriz tiene diagonal unitaria
!>

NRHS

!>          NRHS es INTEGER
!>          El número de vectores de miembros independientes en el sistema A*X = B.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          La matriz de prueba cuyo tipo se da por PATH.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.
!>          Si PATH = xGB, LDA >= KL+KU+1.
!>          Si PATH = xPB, xSB, xHB, o xTB, LDA >= KL+1.
!>          De lo contrario, LDA >= max(1,M).
!>

X

!>          X es un arreglo COMPLEX (o de salida), dimensión (LDX,NRHS)
!>          En la entrada, si XTYPE = 'C' (para 'Calculada'), entonces X contiene
!>          la solución exacta al sistema de ecuaciones lineales.
!>          En la salida, si XTYPE = 'N' (para 'Nueva'), entonces X se inicializa
!>          con valores aleatorios.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  Si TRANS = 'N',
!>          LDX >= max(1,N); si TRANS = 'T', LDX >= max(1,M).
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>          El(los) vector(es) de miembro(s) independiente(s) para el sistema de
!>          ecuaciones, calculado(s) a partir de B = op(A) * X, donde op(A) está
!>          determinado por TRANS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  Si TRANS = 'N',
!>          LDB >= max(1,M); si TRANS = 'T', LDB >= max(1,N).
!>

ISEED

!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado en
!>          CLATMS).  Modificado en la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
