clock(3) Manual de funciones de biblioteca clock(3)

NOMBRE

clock - determinar el tiempo del procesador

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <time.h>
clock_t clock(void);

DESCRIPCIÓN

La función clock() devuelve una aproximación del tiempo de CPU utilizado por el programa.

VALOR DE RETORNO

El valor devuelto es el tiempo de CPU utilizado hasta el momento como un clock_t; para obtener el número de segundos utilizados, divida por CLOCKS_PER_SEC. Si el tiempo de CPU utilizado no está disponible o su valor no se puede representar, la función devuelve el valor (clock_t) -1.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
clock () Seguridad de hilos MT-Safe

VERSIOnES

XSI requiere que CLOCKS_PER_SEC sea igual a 1000000, independientemente de la resolución real.

En varias otras implementaciones, el valor devuelto por clock() también incluye los tiempos de los hijos cuyo estado ha sido recopilado mediante wait(2) (o alguna otra llamada de tipo wait). Linux no incluye los tiempos de los hijos esperados en el valor devuelto por clock(). La función times(2), que devuelve explícitamente información (separada) sobre el llamador y sus hijos, puede ser preferible.

ESTáNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C89.

En glibc 2.17 y anteriores, clock() se implementó sobre times(2). Para mejorar la precisión, desde glibc 2.18, se implementa sobre clock_gettime(2) (utilizando el reloj CLOCK_PROCESS_CPUTIME_ID).

NOTAS

El estándar C permite valores arbitrarios al inicio del programa; reste el valor devuelto por una llamada a clock() al inicio del programa para obtener la máxima portabilidad.

Tenga en cuenta que el tiempo puede desbordarse. En un sistema de 32 bits donde CLOCKS_PER_SEC es igual a 1000000, esta función devolverá el mismo valor aproximadamente cada 72 minutos.

VéASE TAMBIÉN

clock_gettime(2), getrusage(2), times(2)
