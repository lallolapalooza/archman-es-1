Documentación de la función/subrutina

subroutine claed7 (integer n, integer cutpnt, integer qsiz, integer tlvls, integer curlvl, integer curpbm, real, dimension( * ) d, complex, dimension( ldq, * ) q, integer ldq, real rho, integer, dimension( * ) indxq, real, dimension( * ) qstore, integer, dimension( * ) qptr, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, real, dimension( 2, * ) givnum, complex, dimension( * ) work, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

CLAED7 utilizado por CSTEDC. Calcula el sistema de valores propios actualizado de una matriz diagonal después de la modificación por una matriz simétrica de rango uno. Se utiliza cuando la matriz original es densa.

Propósito:

!>
!> CLAED7 calcula el sistema de valores propios actualizado de una matriz
!> diagonal después de la modificación por una matriz simétrica de rango uno. Esta
!> subrutina se utiliza solo para el problema de valores propios que requiere todos
!> los valores propios y opcionalmente los vectores propios de una matriz Hermitiana
!> densa o de banda que se ha reducido a forma tridiagonal.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**H ) Q**H(in) = Q(out) * D(out) * Q**H(out)
!>
!>   donde Z = Q**Hu, u es un vector de longitud N con unos en los
!>   elementos CUTPNT y CUTPNT + 1 y ceros en otros lugares.
!>
!>    Los vectores propios de la matriz original se almacenan en Q, y los
!>    valores propios están en D. El algoritmo consta de tres etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay valores propios múltiples o si hay un cero en
!>       el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa
!>       es realizada por la subrutina SLAED2.
!>
!>       La segunda etapa consiste en calcular los valores propios
!>       actualizados. Esto se hace encontrando las raíces de la ecuación secular
!>       a través de la subrutina SLAED4 (llamada por SLAED3).
!>       Esta subrutina también calcula los vectores propios del
!>       problema actual.
!>
!>       La etapa final consiste en calcular los vectores propios
!>       actualizados directamente utilizando los valores propios actualizados.
!>       Los vectores propios del problema actual se multiplican con los vectores
!>       propios del problema general.
!>

Parámetros

N 
!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica. N >= 0.
!>

CUTPNT

!>          CUTPNT es INTEGER
!>         Contiene la ubicación del último valor propio en la submatriz
!>         principal. min(1,N) <= CUTPNT <= N.
!>

QSIZ

!>          QSIZ es INTEGER
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz completa a forma tridiagonal. QSIZ >= N.
!>

TLVLS

!>          TLVLS es INTEGER
!>         El número total de niveles de fusión en el árbol de dividir y
!>         conquistar general.
!>

CURLVL

!>          CURLVL es INTEGER
!>         El nivel actual en la subrutina de fusión general,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM es INTEGER
!>         El problema actual en el nivel actual de la subrutina de fusión
!>         general (contando de arriba a la izquierda a abajo a la derecha).
!>

D

!>          D es array REAL, dimension (N)
!>         En la entrada, los valores propios de la matriz perturbada de rango 1.
!>         En la salida, los valores propios de la matriz reparada.
!>

Q

!>          Q es array COMPLEX, dimension (LDQ,N)
!>         En la entrada, los vectores propios de la matriz perturbada de rango 1.
!>         En la salida, los vectores propios de la matriz tridiagonal reparada.
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q. LDQ >= max(1,N).
!>

RHO

!>          RHO es REAL
!>         Contiene el elemento subdiagonal utilizado para crear la modificación
!>         de rango 1.
!>

INDXQ

!>          INDXQ es array INTEGER, dimension (N)
!>         Contiene la permutación que reintegrará el subproblema recién resuelto
!>         en el orden correcto, es decir, D( INDXQ( I = 1, N ) ) estará en orden ascendente.
!>

IWORK

!>          IWORK es array INTEGER, dimension (4*N)
!>

RWORK

!>          RWORK es array REAL,
!>                                 dimension (3*N+2*QSIZ*N)
!>

WORK

!>          WORK es array COMPLEX, dimension (QSIZ*N)
!>

QSTORE

!>          QSTORE es array REAL, dimension (N**2+1)
!>         Almacena los vectores propios de las submatrices encontradas durante
!>         la división y conquista, empaquetados juntos. QPTR apunta al
!>         inicio de las submatrices.
!>

QPTR

!>          QPTR es array INTEGER, dimension (N+2)
!>         Lista de índices que apuntan al inicio de las submatrices almacenadas
!>         en QSTORE. Las submatrices se numeran comenzando desde la parte inferior
!>         izquierda del árbol de dividir y conquistar, de izquierda a
!>         derecha y de abajo hacia arriba.
!>

PRMPTR

!>          PRMPTR es array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM se almacena
!>         la permutación de un nivel. PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación y también el tamaño del
!>         problema completo, no desinflado.
!>

PERM

!>          PERM es array INTEGER, dimension (N lg N)
!>         Contiene las permutaciones (de la desinflación y ordenación) que se
!>         aplicarán a cada bloque de valores propios.
!>

GIVPTR

!>          GIVPTR es array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en GIVCOL se almacenan
!>         las rotaciones de Givens de un nivel. GIVPTR(i+1) - GIVPTR(i)
!>         indica el número de rotaciones de Givens.
!>

GIVCOL

!>          GIVCOL es array INTEGER, dimension (2, N lg N)
!>         Cada par de números indica un par de columnas en las que se realiza
!>         una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es array REAL, dimension (2, N lg N)
!>         Cada número indica el valor S que se utilizará en la rotación de Givens
!>         correspondiente.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si INFO = 1, un valor propio no convergió
!>
