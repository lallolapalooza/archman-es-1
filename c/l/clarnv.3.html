Documentación de la Función/Subrutina

subrutina clarnv (integer idist, integer, dimension( 4 ) iseed, integer n, complex, dimension( * ) x)

CLARNV devuelve un vector de números aleatorios de una distribución uniforme o normal.

Propósito:

!>
!> CLARNV devuelve un vector de n números complejos aleatorios de una distribución
!> uniforme o normal.
!>

Parámetros

IDIST 
!>          IDIST es INTEGER
!>          Especifica la distribución de los números aleatorios:
!>          = 1:  partes real e imaginaria uniformes (0,1) cada una
!>          = 2:  partes real e imaginaria uniformes (-1,1) cada una
!>          = 3:  partes real e imaginaria normales (0,1) cada una
!>          = 4:  distribuidos uniformemente en el disco abs(z) < 1
!>          = 5:  distribuidos uniformemente en el círculo abs(z) = 1
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe ser
!>          impar.
!>          En la salida, la semilla se actualiza.
!>

N

!>          N es INTEGER
!>          El número de números aleatorios a generar.
!>

X

!>          X es un array COMPLEX, dimensión (N)
!>          Los números aleatorios generados.
!>

Detalles Adicionales:

!>
!>  Esta rutina llama a la rutina auxiliar SLARUV para generar números
!>  reales de una distribución uniforme (0,1), en lotes de hasta
!>  128 utilizando código vectorizable. El método de Box-Muller se utiliza para
!>  transformar números de una distribución uniforme a una normal.
!>
