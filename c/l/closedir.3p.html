CLOSEDIR(3P) Manual del programador POSIX CLOSEDIR(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

closedir — cerrar un flujo de directorio

SINOPSIS

#include <dirent.h>
int closedir(DIR *dirp);

DESCRIPCION

La función closedir() cerrará el flujo de directorio al que hace referencia el argumento dirp. Al regresar, el valor de dirp ya no podrá apuntar a un objeto accesible del tipo DIR. Si se utiliza un descriptor de archivo para implementar el tipo DIR, se cerrará dicho descriptor de archivo.

VALOR DE RETORNO

Al completarse con éxito, closedir() devolverá 0; en caso contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función closedir() puede fallar si:

EBADF
El argumento dirp no se refiere a un flujo de directorio abierto.
EINTR
La función closedir() fue interrumpida por una señal.

EJEMPLOS

Cerrar un flujo de directorio

El siguiente fragmento de programa demuestra cómo se utiliza la función closedir().

...
    DIR *dir;
    struct dirent *dp;
...
    if ((dir = opendir (".")) == NULL) {
...
    }
    while ((dp = readdir (dir)) != NULL) {
...
    }
    closedir(dir);
...
