NOMBRE

Class::Accessor::Chained - crear accesores encadenados

SINOPSIS

package Foo;
use base qw( Class::Accessor::Chained );
__PACKAGE__->mk_accessors(qw( foo bar baz ));
my $foo = Foo->new->foo(1)->bar(2)->baz(4);
print $foo->bar; # imprime 2

DESCRIPCIÓN

Un accesor encadenado es aquel que siempre devuelve el objeto cuando se llama con parámetros (para establecer), y el valor del campo cuando se llama sin argumentos.

Este módulo es una subclase de Class::Accessor para proporcionar la misma interfaz mk_accessors.
