Documentación de Función/Subrutina

subrutina clacn2 (integer n, complex, dimension( * ) v, complex, dimension( * ) x, real est, integer kase, integer, dimension( 3 ) isave)

CLACN2 estima la 1-norma de una matriz compleja cuadrada, utilizando comunicación inversa para la evaluación de productos matriz-vector.

Propósito:

!>
!> CLACN2 estima la 1-norma de una matriz compleja cuadrada A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es INTEGER
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es array COMPLEXO, dimensión (N)
!>         En el retorno final, V = A*W,  donde  EST = norm(V)/norm(W)
!>         (W no se retorna).
!>

X

!>          X es array COMPLEXO, dimensión (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         donde A**H es la transpuesta conjugada de A, y CLACN2 debe ser
!>         llamada de nuevo con todos los demás parámetros sin cambios.
!>

EST

!>          EST es REAL
!>         Al ingresar con KASE = 1 o 2 y ISAVE(1) = 3, EST debe ser
!>         sin cambios desde la llamada anterior a CLACN2.
!>         Al salir, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es INTEGER
!>         En la llamada inicial a CLACN2, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**H * X.
!>         En el retorno final desde CLACN2, KASE volverá a ser 0.
!>

ISAVE

!>          ISAVE es array INTEGER, dimensión (3)
!>         ISAVE se usa para guardar variables entre llamadas a SLACN2
!>
