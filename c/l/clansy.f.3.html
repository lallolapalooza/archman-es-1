Funciones/Subrutinas


función real clansy (norm, uplo, n, a, lda, work)
CLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz compleja simétrica.

Documentación de Función/Subrutina

real función clansy (carácter norm, carácter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, real, dimensión( * ) work)

CLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz compleja simétrica.

Propósito:

!>
!> CLANSY  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de  mayor valor absoluto  de una
!> matriz compleja simétrica A.
!>

Devuelve

CLANSY 
!>
!>    CLANSY = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la norma uno de una matriz (suma máxima de columnas),
!> normI  denota la norma infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la norma  de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en CLANSY como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se debe hacer referencia a la parte triangular superior o inferior
!>          de la matriz simétrica A.
!>          = 'U':  Se hace referencia a la parte triangular superior de A
!>          = 'L':  Se hace referencia a la parte triangular inferior de A
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANSY se
!>          establece en cero.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>          de n por n de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior de A
!>          no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>          de n por n de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior de A no
!>          se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo contrario,
!>          WORK no se referencia.
!>
