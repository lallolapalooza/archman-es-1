subrutina clascl (type, kl, ku, cfrom, cto, m, n, a, lda, info)
CLASCL multiplica una matriz rectangular general por un escalar real definido como cto/cfrom.

Documentación de la función/subrutina

subrutina clascl (character type, integer kl, integer ku, real cfrom, real cto, integer m, integer n, complex, dimension( lda, * ) a, integer lda, integer info)

CLASCL multiplica la matriz compleja M por N, A, por el escalar real CTO/CFROM. Esto se hace sin desbordamiento superior/inferior mientras el resultado final CTO*A(I,J)/CFROM no lo haga. TYPE especifica si A puede ser completa, triangular superior, triangular inferior, upper Hessenberg o banda.

Propósito:

!>
!> CLASCL multiplica la matriz compleja M por N, A, por el escalar real
!> CTO/CFROM.  Esto se hace sin sobre/subdesbordamiento mientras el
!> resultado final CTO*A(I,J)/CFROM no se desborde. TYPE especifica que
!> A puede ser completa, triangular superior, triangular inferior,
!> upper Hessenberg o de banda.
!>

Parámetros

TYPE 
!>          TYPE es CHARACTER*1
!>          TYPE indexa el tipo de almacenamiento de la matriz de entrada.
!>          = 'G':  A es una matriz completa.
!>          = 'L':  A es una matriz triangular inferior.
!>          = 'U':  A es una matriz triangular superior.
!>          = 'H':  A es una matriz upper Hessenberg.
!>          = 'B':  A es una matriz banda simétrica con ancho de banda inferior KL
!>                  y ancho de banda superior KU y con solo la mitad inferior almacenada.
!>          = 'Q':  A es una matriz banda simétrica con ancho de banda inferior KL
!>                  y ancho de banda superior KU y con solo la mitad superior almacenada.
!>          = 'Z':  A es una matriz banda con ancho de banda inferior KL y ancho de banda superior KU.
!>                  Consultar CGBTRF para detalles de almacenamiento.
!>

KL

!>          KL es INTEGER
!>          El ancho de banda inferior de A.  Se hace referencia a él solo si TYPE = 'B',
!>          'Q' o 'Z'.
!>

KU

!>          KU es INTEGER
!>          El ancho de banda superior de A.  Se hace referencia a él solo si TYPE = 'B',
!>          'Q' o 'Z'.
!>

CFROM

!>          CFROM es REAL
!>

CTO

!>          CTO es REAL
!>
!>          La matriz A se multiplica por CTO/CFROM. A(I,J) se calcula
!>          sin sobre/subdesbordamiento si el resultado final CTO*A(I,J)/CFROM
!>          puede ser representado sin sobre/subdesbordamiento.  CFROM debe
!>          ser distinto de cero.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          La matriz a multiplicar por CTO/CFROM.  Ver TYPE para el
!>          tipo de almacenamiento.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si TYPE = 'G', 'L', 'U', 'H', LDA >= max(1,M);
!>             TYPE = 'B', LDA >= KL+1;
!>             TYPE = 'Q', LDA >= KU+1;
!>             TYPE = 'Z', LDA >= 2*KL+KU+1.
!>

INFO

!>          INFO es INTEGER
!>          0 - salida exitosa
!>          <0 - si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>
