función real cla_hercond_c (carácter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, real, dimensión ( * ) c, lógico capply, entero info, complejo, dimensión( * ) work, real, dimensión( * ) rwork)

CLA_HERCOND_C calcula el número de condición de la norma infinito de op(A)*inv(diag(c)) para matrices hermíticas indefinidas.

Propósito:

!>
!>    CLA_HERCOND_C calcula el número de condición de la norma infinito de
!>    op(A) * inv(diag(C)) donde C es un vector REAL.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U': el triángulo superior de A está almacenado;
!>       = 'L': el triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A. N >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A. LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L tal como lo calcula CHETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como los determina CHETRF.
!>

C

!>          C es array REAL, dimensión (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LOGICAL
!>     Si .TRUE. entonces accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es INTEGER
!>       = 0: Salida exitosa.
!>     i > 0: El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array COMPLEX, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es array REAL, dimensión (N).
!>     Espacio de trabajo.
!>
