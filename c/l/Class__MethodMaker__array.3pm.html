Class__MethodMaker__array(3pm)

Paquete: perl-class-methodmaker

Licencias: GPL, PerlArtistic

Class::MethodMaker::array(3) Documentación de Perl aportada por el usuario Class::MethodMaker::array(3)

NOMBRE

Class::Method::array - Crea métodos para manejar un valor de tipo array.

SINOPSIS

use Class::MethodMaker
  [ array => [qw/ x /] ];
$instance->x;                # vacío
$instance->x(1, 1, 2, 3, 5, 8);
$instance->x_count == 6;     # verdadero
$instance->x = (13, 21, 34);
$instance->x_index(1) == 21; # verdadero

DESCRIPCIÓN

Crea métodos para manejar valores de array en un objeto. Para un componente llamado "x", por defecto crea los métodos "x", "x_reset", "x_clear", "x_isset", "x_count", "x_index", "x_push", "x_pop", "x_unshift", "x_shift", "x_splice".

Los métodos disponibles son:

"*"

Creado por defecto. Este método devuelve la lista de valores almacenados en el slot. Si se proporcionan argumentos a este método, estos reemplazan el contenido actual de la lista. En un contexto de array devuelve los valores como un array y en un contexto escalar como una referencia a un array. Ten en cuenta que esta referencia ya no es una referencia directa al almacenamiento, en contraste con Class::MethodMaker v1. Esto es para proteger el encapsulamiento. Consulta x_ref si necesitas esa funcionalidad (y estás preparado para asumir el riesgo asociado). Esta función ya no expande automáticamente los arrayrefs de entrada como argumentos, ya que eso dificulta establecer valores individuales a arrayrefs. Consulta x_setref para esa funcionalidad.

Si hay un valor por defecto en vigor, entonces ese valor será auto-vivificado (y por lo tanto establecido) para cada valor sin establecer (no definido) hasta el máximo del array (por lo que no se añadirán nuevos elementos al final)

*_reset

Creado por defecto. Llamado sin argumentos, esto restablece el componente como un todo; borrando cualquier almacenamiento asociado y devolviendo el componente a su estado por defecto. Normalmente, esto significa que *_isset devolverá falso, y "*" devolverá undef. Si "-default" está en vigor, entonces el componente se establecerá al valor por defecto, y *_isset devolverá verdadero. Si "-default_ctor" está en vigor, entonces se invocará la subrutina por defecto, y su valor de retorno se usará para establecer el valor del componente, y *_isset devolverá verdadero.

Si se llama con argumentos, estos argumentos se tratan como índices dentro del componente, y los elementos individuales así referenciados se restablecen (su almacenamiento se borra, de modo que *_isset(n) devolverá falso para el napropiado, excepto donde "-default" o "-default_ctor" estén en vigor, como arriba). Al igual que con los arrays de perl, restablecer el valor establecido más alto disminuye implícitamente el recuento (pero x_reset(n) nunca desestablece el agregado en sí, incluso si no todos los elementos están establecidos).

*_clear

package MyClass;
use Class::MethodMaker
  [ scalar => [{'*_clear' => '*_clear'}, 'a'],
    new    => new, ];
package main;
my $m = MyClass->new;
$m->a(5);
$a = $m->a;       # 5
$x = $m->a_isset; # verdadero
$m->a_clear;
$a = $m->a;       # *undef*
$x = $m->a_isset; # verdadero

Creado bajo petición. Un alias para establecer a undef. Ten en cuenta que el componente se establecerá a undef, no se restablecerá, por lo que *_isset devolverá verdadero.

*_isset

Creado por defecto. Si el componente está actualmente establecido. Esto es diferente de estar definido; inicialmente, el componente no está establecido (y si se lee, devolverá undef); puede establecerse a undef (lo cual es un valor establecido, que también devuelve undef). Una vez establecido, la única forma de desestablecer el componente es con <*_reset>.

Si hay un valor por defecto en vigor, entonces <*_isset> siempre devolverá verdadero.

*_isset() prueba el componente como un todo. *_isset(a) prueba el elemento indexado por a. "*_isset(a,b)" prueba los elementos indexados por a, b, y devuelve la conjunción lógica (and) de las pruebas.

*_count

Creado por defecto. Devuelve el número de elementos en este componente. Esto no se ve afectado por la presencia (o ausencia) de un "default" (o "default_ctor"). Devuelve "undef" si el componente completo no está establecido (según *_isset).

*_index

Creado por defecto. Toma una lista de índices, devuelve una lista de los valores correspondientes.

Si hay un valor por defecto (o un ctor por defecto) en vigor, entonces una búsqueda por índice vivificará y establecerá al valor por defecto los elementos respectivos (y por lo tanto la estructura de datos agregada también, si aún no lo está).

Cuidado con un error en perl 5.6.1 que a veces inventa valores en slots previamente sin establecer de arrays que previamente contenían un valor. Así que, vivificar un valor (por ejemplo, mediante x_index(2)) donde x_index(1) estaba previamente sin establecer podría causar que x_index(1) se estableciera espuriamente. Esto está corregido en 5.8.0.

*_push

Creado por defecto. Añade elemento(s) al final de la lista. Sin valor de retorno.

*_pop

Creado por defecto. Dado un número, extrae esa cantidad de elementos del final de la lista, y los devuelve (como un ref en contexto escalar, como una lista en contexto de lista). Sin un argumento, siempre devuelve un solo elemento. Dado un número, los devuelve en orden de array (no en orden inverso como harían múltiples pops).

*_unshift

Creado por defecto. Añade elemento(s) al inicio de la lista. Sin valor de retorno.

*_shift

Creado por defecto. Dado un número, extrae esa cantidad de elementos del inicio de la lista, y los devuelve (como un ref en contexto escalar, como una lista en contexto de lista). Sin un argumento, siempre devuelve un solo elemento. Dado un número, los devuelve en orden de array.

*_splice

Creado por defecto. Argumentos como en perldoc perlfunc splice. Devuelve un arrayref en contexto escalar (incluso si se extrae un solo elemento), y una lista en contexto de lista.

*_get

Creado bajo petición. Recupera el valor del componente sin establecerlo (ignora cualquier argumento pasado).

*_set

@n = $x->a; # (1,2,3)
$x->a_set(1=>4,3=>7);
@n = $x->a; # (1,4,3,7)

Creado por defecto. Toma una lista, tratada como pares de índice => valor; cada índice dado se establece al valor correspondiente. Sin retorno.

Si se dan dos argumentos, de los cuales el primero es un arrayref, entonces se trata como una lista de índices de los cuales el segundo argumento (que también debe ser un arrayref) son los valores correspondientes. Así que los siguientes dos comandos son equivalentes:

$x->a_set(1=>4,3=>7);
$x->a_set([1,3],[4,7]);
