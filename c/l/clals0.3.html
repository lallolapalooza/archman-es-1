subrutina clals0 (integer icompq, integer nl, integer nr, integer sqre, integer nrhs, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldbx, * ) bx, integer ldbx, integer, dimension( * ) perm, integer givptr, integer, dimension( ldgcol, * ) givcol, integer ldgcol, real, dimension( ldgnum, * ) givnum, integer ldgnum, real, dimension( ldgnum, * ) poles, real, dimension( * ) difl, real, dimension( ldgnum, * ) difr, real, dimension( * ) z, integer k, real c, real s, real, dimension( * ) rwork, integer info)

CLALS0 aplica los factores multiplicativos de retroceso al resolver el problema de mínimos cuadrados utilizando el enfoque de SVD por división y conquista. Usado por sgelsd.

Propósito:

!>
!> CLALS0 aplica de vuelta los factores multiplicativos de la matriz de
!> vectores singulares izquierdos o de la matriz de vectores singulares
!> derechos de una matriz diagonal a la que se le ha añadido una fila, a la
!> matriz del segundo miembro B al resolver el problema de mínimos cuadrados
!> utilizando el enfoque de SVD por división y conquista.
!>
!> Para la matriz de vectores singulares izquierdos, se involucran tres
!> tipos de matrices ortogonales:
!>
!> (1L) Rotaciones de Givens: el número de tales rotaciones es GIVPTR; los
!>      pares de columnas/filas a las que se aplicaron se almacenan en
!>      GIVCOL; y los valores C y S de estas rotaciones se almacenan en
!>      GIVNUM.
!>
!> (2L) Permutación. La fila (NL+1)-ésima de B debe moverse a la primera
!>      fila, y para J=2:N, la fila PERM(J)-ésima de B debe moverse a la
!>      fila J-ésima.
!>
!> (3L) La matriz de vectores singulares izquierdos de la matriz restante.
!>
!> Para la matriz de vectores singulares derechos, se involucran cuatro
!> tipos de matrices ortogonales:
!>
!> (1R) La matriz de vectores singulares derechos de la matriz restante.
!>
!> (2R) Si SQRE = 1, una rotación de Givens extra para generar el espacio
!>      nulo derecho.
!>
!> (3R) La transformación inversa de (2L).
!>
!> (4R) La transformación inversa de (1L).
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si los vectores singulares deben calcularse en
!>         forma factorizada:
!>         = 0: Matriz de vectores singulares izquierdos.
!>         = 1: Matriz de vectores singulares derechos.
!>

NL

!>          NL es INTEGER
!>         La dimensión de filas del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de filas del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR-por-NR.
!>         = 1: el bloque inferior es una matriz rectangular NR-por-(NR+1).
!>
!>         La matriz bidiagonal tiene dimensión de filas N = NL + NR + 1,
!>         y dimensión de columnas M = N + SQRE.
!>

NRHS

!>          NRHS es INTEGER
!>         El número de columnas de B y BX. NRHS debe ser al menos 1.
!>

B

!>          B es un arreglo COMPLEX, dimensión ( LDB, NRHS )
!>         En la entrada, B contiene los segundos miembros del problema de
!>         mínimos cuadrados en las filas 1 a M. En la salida, B contiene
!>         la solución X en las filas 1 a N.
!>

LDB

!>          LDB es INTEGER
!>         La dimensión principal de B. LDB debe ser al menos
!>         max(1,MAX( M, N ) ).
!>

BX

!>          BX es un arreglo COMPLEX, dimensión ( LDBX, NRHS )
!>

LDBX

!>          LDBX es INTEGER
!>         La dimensión principal de BX.
!>

PERM

!>          PERM es un arreglo INTEGER, dimensión ( N )
!>         Las permutaciones (de la deflación y la ordenación) aplicadas
!>         a los dos bloques.
!>

GIVPTR

!>          GIVPTR es INTEGER
!>         El número de rotaciones de Givens que tuvieron lugar en este
!>         subproblema.
!>

GIVCOL

!>          GIVCOL es un arreglo INTEGER, dimensión ( LDGCOL, 2 )
!>         Cada par de números indica un par de filas/columnas
!>         involucradas en una rotación de Givens.
!>

LDGCOL

!>          LDGCOL es INTEGER
!>         La dimensión principal de GIVCOL, debe ser al menos N.
!>

GIVNUM

!>          GIVNUM es un arreglo REAL, dimensión ( LDGNUM, 2 )
!>         Cada número indica el valor C o S utilizado en la
!>         rotación de Givens correspondiente.
!>

LDGNUM

!>          LDGNUM es INTEGER
!>         La dimensión principal de los arreglos DIFR, POLES y
!>         GIVNUM, debe ser al menos K.
!>

POLES

!>          POLES es un arreglo REAL, dimensión ( LDGNUM, 2 )
!>         En la entrada, POLES(1:K, 1) contiene los nuevos valores
!>         singulares obtenidos de la resolución de la ecuación secular, y
!>         POLES(1:K, 2) es un arreglo que contiene los polos en la ecuación
!>         secular.
!>

DIFL

!>          DIFL es un arreglo REAL, dimensión ( K ).
!>         En la entrada, DIFL(I) es la distancia entre el I-ésimo valor
!>         singular actualizado (no deflado) y el I-ésimo valor singular
!>         antiguo (no deflado).
!>

DIFR

!>          DIFR es un arreglo REAL, dimensión ( LDGNUM, 2 ).
!>         En la entrada, DIFR(I, 1) contiene las distancias entre el
!>         I-ésimo valor singular actualizado (no deflado) y el (I+1)-ésimo
!>         valor singular antiguo (no deflado). Y DIFR(I, 2) es el
!>         factor de normalización para el I-ésimo vector singular derecho.
!>

Z

!>          Z es un arreglo REAL, dimensión ( K )
!>         Contiene los componentes del vector fila de actualización
!>         ajustado por deflación.
!>

K

!>          K es INTEGER
!>         Contiene la dimensión de la matriz no deflada,
!>         Este es el orden de la ecuación secular relacionada. 1 <= K <=N.
!>

C

!>          C es REAL
!>         C contiene basura si SQRE =0 y el valor C de una rotación de
!>         Givens relacionada con el espacio nulo derecho si SQRE = 1.
!>

S

!>          S es REAL
!>         S contiene basura si SQRE =0 y el valor S de una rotación de
!>         Givens relacionada con el espacio nulo derecho si SQRE = 1.
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión
!>         ( K*(1+NRHS) + 2*NRHS )
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
