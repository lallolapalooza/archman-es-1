NOMBRE

clamd.conf - Archivo de configuración para el Demonio Clam AntiVirus.

DESCRIPCIÓN

clamd.conf configura el demonio Clam AntiVirus, clamd(8).

FORMATO DEL ARCHIVO

El archivo consiste en comentarios y opciones con argumentos. Cada línea que empieza con un símbolo de almohadilla (#) es ignorada por el analizador. Las opciones y los argumentos distinguen entre mayúsculas y minúsculas y tienen el formato Opción Argumento. Los argumentos son de los siguientes tipos:

BOOL
Valor booleano (sí/no o verdadero/falso o 1/0).
STRING
Cadena sin espacios en blanco.
SIZE
Tamaño en bytes. Puedes usar modificadores 'M' o 'm' para megabytes y 'K' o 'k' para kilobytes. Para especificar el tamaño en bytes simplemente no uses modificadores.
NUMBER
Entero sin signo.

DIRECTIVAS

Cuando alguna opción no se usa (comentada o no incluida en el archivo de configuración en absoluto), clamd toma una acción predeterminada.

BOOL
Con esta opción puede excluir el UID de root (0). Los procesos ejecutados bajo root podrán acceder a todos los archivos sin desencadenar escaneos ni eventos de permiso denegado.
Tenga en cuenta que si clamd no puede verificar el uid del proceso que generó un evento de escaneo al acceder (por ejemplo, porque OnAccessPrevention no estaba habilitado, y el proceso ya terminó), clamd realizará un escaneo.
