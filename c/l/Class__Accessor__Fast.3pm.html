Class::Accessor::Fast(3) Documentación de Perl aportada por el usuario Class::Accessor::Fast(3)

NOMBRE

Class::Accessor::Fast - Accesor más rápido, pero menos expandible

SINOPSIS

package Foo;
use base qw(Class::Accessor::Fast);
# El resto es igual que Class::Accessor pero sin set() ni get().

DESCRIPCIÓN

Esta es una versión más rápida pero menos expandible de Class::Accessor. Los accesores generados por Class::Accessor requieren dos llamadas a métodos para llevar a cabo su tarea (una para el accesador, otra para get() o set()). Class::Accessor::Fast elimina la llamada a set()/get() y realiza el acceso por sí mismo, lo que resulta en un accesador algo más rápido.

La desventaja es que no se puede alterar fácilmente el comportamiento de los accesores, ni el de las subclases. Por supuesto, si necesita esto más tarde, siempre puede cambiar Class::Accessor::Fast por Class::Accessor.

Lea la documentación de Class::Accessor para más información.
