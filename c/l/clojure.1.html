CONFIGURACIÓ

N

Este script lee la configuración desde archivos deps.edn. Comprobará contra archivos deps.edn en la ubicación de la raíz del sistema, el directorio de configuración del usuario (usualmente ~/.clojure), y el directorio local. Los archivos en cada una de estas ubicaciones, si existen, se fusionan para formar un archivo de configuración combinado

. Las opciones del último archivo de configuración especificado sobrescriben
cualquier archivo anterior (ej. las configuraciones locales tienen prioridad).
