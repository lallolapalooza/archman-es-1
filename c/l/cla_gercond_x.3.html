real function cla_gercond_x (character trans, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex, dimension( * ) x, integer info, complex, dimension( * ) work, real, dimension( * ) rwork)

CLA_GERCOND_X calcula el número de condición de la norma infinito de op(A)*diag(x) para matrices generales.

Propósito:

!>
!>
!>    CLA_GERCOND_X calcula el número de condición de la norma infinito de
!>    op(A) * diag(X) donde X es un vector COMPLEJO.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEJO, dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U calculada por CGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     calculada por CGETRF; la fila i de la matriz se intercambió
!>     con la fila IPIV(i).
!>

X

!>          X es un array COMPLEJO, dimensión (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento no es válido.
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es un array REAL, dimensión (N).
!>     Espacio de trabajo.
!>
