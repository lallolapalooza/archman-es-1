NOMBRE

cleanarch - Limpia un archivo de claves de DNSSEC-Tools de claves antiguas

SINOPSIS

cleanarch [opciones] <archivo-keyrec | archivo-rollrec>

DESCRIPCIÓN

cleanarch elimina claves antiguas de un archivo de claves de DNSSEC-Tools. La "antigüedad" de las claves y los archivos se determinan mediante opciones y argumentos.

Las opciones y argumentos de la línea de comandos permiten la selección de archivos, las claves a eliminar y la cantidad de salida a proporcionar. Las opciones se dividen en tres grupos: selección de archivo, selección de clave y formato de salida. La información completa sobre las opciones se proporciona en la sección OPCIONES.

cleanarch toma un único argumento (distinto de una opción). Este argumento puede ser un archivo keyrec o un archivo rollrec. Si el archivo es un archivo keyrec, el directorio del archivo de sus claves keyrec se añade a la lista de archivos a limpiar. Si el archivo es un archivo rollrec, se buscan los archivos keyrec de sus zonas para el directorio del archivo de las zonas, y esos directorios se añaden a la lista de archivos a limpiar. Si una zona no tiene un directorio de archivo definido explícitamente, entonces se limpiará el predeterminado de DNSSEC-Tools. Los archivos especificados por este argumento pueden ser modificados por opciones de selección de archivo.

Las opciones de selección de archivo se combinan con el archivo keyrec o rollrec para seleccionar un conjunto de directorios de archivo a limpiar. (Algunas opciones pueden reemplazar al argumento de archivo).

Las opciones de selección de clave permiten que el conjunto de claves a eliminar contenga un archivo completo, las claves de una zona particular o todas las claves anteriores a una fecha determinada.

Las opciones de formato de salida establecen cuánta salida se proporcionará. Sin ninguna opción seleccionada, se imprimirán los nombres de las claves a medida que se eliminen. Si se proporciona la opción -verbose, se imprimirán los directorios seleccionados para la búsqueda y las claves seleccionadas para la eliminación. Si se proporciona la opción -dirlist, se imprimirán los directorios seleccionados para la búsqueda y no se realizará ninguna otra acción. Si se proporciona la opción -list, se imprimirán las claves seleccionadas para la eliminación y no se realizará ninguna otra acción.

cleanarch solo limpia los directorios de archivo; los archivos keyrec se dejan intactos. El comando cleankrf debe usarse junto con cleanarch para tener un entorno consistente.

OPCIONES

Opciones de selección de archivo

Las siguientes opciones permiten al usuario seleccionar los archivos a limpiar.

-archivo directorio
Esta opción especifica un directorio de archivo a limpiar.
-defarch
Esta opción indica que se debe limpiar el directorio de archivo predeterminado (nombrado en el archivo de configuración de DNSSEC-Tools).
-zona zona
Esta opción indica que zona es la única zona cuyo archivo se limpiará. Si el directorio de archivo es compartido por otras zonas, entonces sus claves también pueden ser eliminadas.

Opciones de selección de clave

Las siguientes opciones permiten al usuario seleccionar las claves a eliminar.

-all
Elimina todas las claves en los archivos seleccionados. Esta opción no puede usarse con ninguna otra opción de selección de clave.
-dias dias
Elimina todas las claves excepto aquellas cuya fecha de modificación esté dentro de los dias días completos anteriores al día actual.
-unazona zona
Solo se eliminan las claves que tienen zona en el nombre de archivo de la clave. Esto está destinado a usarse en la limpieza de un archivo de claves multizona.

Esto no valida que zona sea una zona real. Se puede usar **cualquier** cadena aquí. Por ejemplo, usar "private" seleccionará claves privadas antiguas para su eliminación y usar "com" seleccionará cualquier nombre de archivo que contenga "com".

Opciones de control de salida

Las siguientes opciones permiten al usuario controlar la salida de cleanarch.

-dirlist
Esta opción lista los directorios de archivo seleccionados. No se toma ninguna otra acción.
-list
Esta opción lista las claves seleccionadas. No se toma ninguna otra acción.
-quiet
No mostrar ninguna salida.
-verbose
Mostrar salida detallada.
-Version
Muestra la información de la versión de cleanarch y el paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso y sale.

ADVERTENCIAS

Se recomienda al usuario que invierta un poco de tiempo probando esta herramienta **antes** de ponerla en producción. Una vez que una clave es eliminada, **se ha ido**. A algunos esto les puede parecer perjudicial para la salud de su instalación de DNSSEC-Tools.
