CLUTTEX(1) Manual de Comandos Generales CLUTTEX(1)

NOMBRE

cluttex — una herramienta para procesar archivos TeX

SINOPSIS

cluttex -e ENGINE [opciones] [--] ARCHIVO.tex

DESCRIPCIÓN

Procesa archivos TeX sin llenar de basura tu directorio de trabajo.

Se aceptan las siguientes opciones:

-e, --engine=ENGINE
Especifica qué motor TeX usar. ENGINE es uno de los siguientes: pdflatex, pdftex, lualatex, luatex, luajittex, xelatex, xetex, latex, etex, tex, platex, eptex, ptex, uplatex, euptex, uptex,
--engine-executable=COMANDO+OPCIONES
El comando TeX real a usar. [por defecto: ENGINE]
-o, --output=ARCHIVO
El nombre del archivo de salida. [por defecto: NOMBRE_TRABAJO.pdf o NOMBRE_TRABAJO.dvi]
--fresh
Limpia los archivos intermedios antes de ejecutar TeX. No se puede usar con --output-directory.
--max-iterations=N
Número máximo de ejecuciones de TeX para resolver referencias cruzadas. [por defecto: 3]
--start-with-draft
Comienza con modo borrador.
--change-directory, --no-change-directory
Cambia de directorio antes de ejecutar TeX. [por defecto: no]
--watch[=ENGINE]
Observa los archivos de entrada para detectar cambios. Requiere que fswatch o inotifywait estén instalados. ENGINE es uno de "fswatch", "inotifywait" o "auto". [por defecto: auto]
--tex-option=OPCIÓN
Pasa OPCIÓN a TeX como una única opción.
--tex-options=OPCIONES
Pasa OPCIONES a TeX como opciones múltiples.
--dvipdfmx-option=OPCIÓN, --dvipdfmx-options=OPCIONES
Lo mismo para dvipdfmx.
--makeindex=COMANDO+OPCIONES
Comando para generar el índice, como "makeindex" o "mendex".
--bibtex=COMANDO+OPCIONES
Comando para BibTeX, como "bibtex" o "pbibtex".
--biber[=COMANDO+OPCIONES]
Comando para Biber.
--makeglossaries[=COMANDO+OPCIONES]
Comando para makeglossaries.
-h, --help
Imprime este mensaje y sale.
-v, --version
Imprime la información de la versión y sale.
-V, --verbose
Sea más verboso.
--color[=CUÁNDO]
Hace que los mensajes de ClutTeX sean más coloridos. CUÁNDO es uno de "siempre", "auto", o "nunca". [por defecto: "auto" si se omite -color, "siempre" si se omite CUÁNDO]
--includeonly=NOMBRES
Inserta "\includeonly{NOMBRES}".
--make-depends=ARCHIVO
Escribe las dependencias como una regla de Makefile.
--print-output-directory
Imprime el directorio de salida y sale.
--package-support=PKG1[,PKG2,...]
Habilita soporte especial para algunos paquetes de escape de shell. Actualmente soportados: minted, epstopdf.
--check-driver=DRIVER
Verifica que se cargue el archivo driver correcto. DRIVER es uno de "dvipdfmx", "dvips", "dvisvgm".
--shell-escape, --no-shell-escape
 
--shell-restricted
 
--synctex=NÚMERO
 
--fmt=NOMBRE_FMT
 
--file-line-error, --no-file-line-error
[por defecto: sí]
--halt-on-error, --no-halt-on-error
[por defecto: sí]
--interaction=CADENA
[por defecto: nonstopmode]
--jobname=CADENA
 
--output-directory=DIR
[por defecto: en algún lugar del directorio temporal]
--output-format=FORMATO
FORMATO es "pdf" o "dvi". [por defecto: pdf]

ESTADO DE SALIDA

La utilidad cluttex sale con 0 en caso de éxito, y >0 si ocurre un error.
