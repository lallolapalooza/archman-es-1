CLEVIS(1)   CLEVIS(1)

NOMBRE

clevis - Framework de política de descifrado automatizado

SINOPSIS

clevis COMANDO [OPCIONES]

DESCRIPCIÓN

Clevis es un framework para la política de descifrado automatizado. Permite definir una política en el momento del cifrado que debe cumplirse para que los datos se descifren. Una vez que esta política se cumple, los datos se descifran.

Clevis es enchufable. Nuestros plugins se llaman "pins". El trabajo de un pin es tomar una política como primer argumento y texto plano en la entrada estándar y cifrar los datos para que puedan descifrarse automáticamente si se cumple la política. Veamos un ejemplo.

ENLACE TANG

Clevis proporciona soporte para el servidor de enlace de red Tang. Tang ofrece una alternativa sin estado y ligera a los depósitos. Cifrar datos usando el pin Tang funciona de manera similar a nuestro pin HTTP anterior:

$ clevis encrypt tang '{"url":"http://tang.srv"}' < PT > JWE
El anuncio contiene las siguientes claves de firma:
_OsIk0T-E2l6qjfdDiwVmidoZjA
¿Desea confiar en estas claves? [ynYN] y

Como puede ver arriba, Tang utiliza un flujo de trabajo de confianza en el primer uso. Alternativamente, Tang puede realizar un cifrado completamente sin conexión si se comparte previamente el anuncio del servidor. El descifrado también funciona como nuestro primer ejemplo:

$ clevis decrypt < JWE > PT

Para más información, consulte clevis-encrypt-tang(1).

ENLACE TPM2

Clevis proporciona soporte para cifrar una clave en un chip Trusted Platform Module 2.0 (TPM2). La clave criptográficamente segura y aleatoria utilizada para el cifrado se cifra utilizando el chip TPM2, y luego, en el momento del descifrado, se descifra utilizando el TPM2 para permitir que clevis descifre el secreto almacenado en el JWE.

Cifrar datos utilizando el pin tpm2 funciona igual que con los pines mencionados anteriormente:

$ clevis encrypt tpm2 '{}' < PT > JWE

El pin tiene valores predeterminados razonables para su configuración, pero se puede elegir una jerarquía, hash y algoritmos de clave diferentes si los valores predeterminados utilizados no son adecuados.

El descifrado también funciona de manera similar a otros pines, solo se necesita proporcionar el JWE:

$ clevis decrypt < JWE > PT

Tenga en cuenta que, al igual que otros pines, no se utiliza ninguna configuración para el descifrado, esto se debe a que clevis almacena las claves pública y privada para revelar el objeto cifrado con TPM2 en el JWE para que clevis pueda obtener esa información desde allí.

Para más información, consulte clevis-encrypt-tpm2(1).

PARTICIÓN SECRETA DE SHAMIR

Clevis proporciona una forma de mezclar pines para crear políticas de desbloqueo sofisticadas y de alta disponibilidad. Esto se logra utilizando un algoritmo llamado Partición Secreta de Shamir (SSS).

SSS es un esquema de umbralización. Crea una clave y la divide en un número de partes. Cada parte se cifra utilizando otro pin (posiblemente incluso SSS recursivamente). Además, se define el umbral t. Si al menos t partes pueden descifrarse, entonces la clave de cifrado se puede recuperar y el descifrado puede tener éxito.

Por ejemplo, creemos una configuración de alta disponibilidad usando Tang:

$ cfg='{"t":1,"pins":{"tang":[{"url":...},{"url":...}]}}'
$ clevis encrypt sss "$cfg" < PT > JWE

En esta política, declaramos que tenemos un umbral de 1, pero que hay múltiples fragmentos de clave cifrados utilizando diferentes servidores Tang. Dado que nuestro umbral es 1, siempre que uno de los servidores Tang esté disponible, el descifrado tendrá éxito. Como siempre, el descifrado es simplemente:

$ clevis decrypt < JWE > PT

Para más información, consulte clevis-encrypt-tang(1).

ENLACE LUKS

Clevis se puede utilizar para vincular un volumen LUKS existente a su política de automatización. Esto se logra con un comando simple:

$ clevis luks bind -d /dev/sda tang '{"url":...}'

Este comando realiza cuatro pasos:

1.Crea una nueva clave con la misma entropía que la clave maestra LUKS — el número máximo de bits de entropía es 256.
2.Cifra la nueva clave con Clevis.
3.Almacena el JWE de Clevis en la cabecera LUKS.
4.Habilita la nueva clave para su uso con LUKS.

Este disco ahora se puede desbloquear con su contraseña existente, así como con la política de Clevis. Clevis proporciona dos desbloqueadores para volúmenes LUKS. Primero, proporcionamos integración con Dracut para desbloquear automáticamente su volumen raíz durante el arranque temprano. Segundo, proporcionamos integración con UDisks2 para desbloquear automáticamente sus medios extraíbles en su sesión de escritorio.

Para más información, consulte clevis-luks-bind(1).
