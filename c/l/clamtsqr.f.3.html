Documentación de Función/Subrutina

subrutina clamtsqr (character side, character trans, integer m, integer n, integer k, integer mb, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer lwork, integer info)

CLAMTSQR

Propósito:

!>
!>      CLAMTSQR sobrescribe la matriz compleja general M-por-N C con
!>
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>      donde Q es una matriz compleja unitaria definida como el producto
!>      de reflectores elementales bloqueados calculados por la
!>      factorización QR alta y delgada (CLATSQR)
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la izquierda;
!>          = 'R': aplicar Q o Q**H desde la derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'C':  Transpuesta conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >=0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q. M >= K >= 0;
!>
!>

MB

!>          MB es INTEGER
!>          El tamaño de bloque a utilizar en el QR bloqueado.
!>          MB > N. (debe ser el mismo que en CLATSQR)
!>

NB

!>          NB es INTEGER
!>          El tamaño de bloque de columnas a utilizar en el QR bloqueado.
!>          N >= NB >= 1.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental bloqueado H(i), para i = 1,2,...,k, tal
!>          como lo devuelve CLATSQR en las primeras k columnas de
!>          su argumento de arreglo A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T es un arreglo COMPLEX, dimensión
!>          ( N * Número de bloques(CEIL(M-K/MB-K)),
!>          Los reflectores de bloques triangulares superiores bloqueados almacenados en forma compacta
!>          como una secuencia de bloques triangulares superiores. Vea más abajo
!>          para más detalles.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del arreglo T.  LDT >= NB.
!>

C

!>          C es un arreglo COMPLEX, dimensión (LDC,N)
!>          En la entrada, la matriz C de M-por-N.
!>          En la salida, C es sobrescrita por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del arreglo C. LDC >= max(1,M).
!>

WORK

!>          (espacio de trabajo) Arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,N*NB).
!>          Si SIDE = 'R', LWORK >= max(1,MB*NB).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño mínimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!> El QR Alto-Delgado (TSQR) realiza QR mediante una secuencia de transformaciones unitarias,
!> representando Q como un producto de otras matrices unitarias
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> donde cada Q(i) anula las entradas subdiagonales de un bloque de MB filas de A:
!>   Q(1) anula las entradas subdiagonales de las filas 1:MB de A
!>   Q(2) anula las últimas MB-N filas de las filas [1:N,MB+1:2*MB-N] de A
!>   Q(3) anula las últimas MB-N filas de las filas [1:N,2*MB-N+1:3*MB-2*N] de A
!>   . . .
!>
!> Q(1) se calcula mediante GEQRT, que representa Q(1) mediante vectores de Householder
!> almacenados bajo la diagonal de las filas 1:MB de A, y mediante reflectores de bloques
!> triangulares superiores, almacenados en el arreglo T(1:LDT,1:N).
!> Para más información, vea Detalles adicionales en GEQRT.
!>
!> Q(i) para i>1 se calcula mediante TPQRT, que representa Q(i) mediante vectores de Householder
!> almacenados en las filas [(i-1)*(MB-N)+N+1:i*(MB-N)+N] de A, y mediante reflectores de bloques
!> triangulares superiores, almacenados en el arreglo T(1:LDT,(i-1)*N+1:i*N).
!> El último Q(k) puede usar menos filas.
!> Para más información, vea Detalles adicionales en TPQRT.
!>
!> Para más detalles del algoritmo general, vea la descripción del
!> TSQR Secuencial en la Sección 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>
