Documentación de Función/Subrutina

subrutina clamswlq (character side, character trans, integer m, integer n, integer k, integer mb, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer lwork, integer info)

CLAMSWLQ

Propósito:

!>
!>    CLAMSWLQ sobrescribe la matriz compleja general M-por-N C con
!>
!>
!>                    SIDE = 'L'     SIDE = 'R'
!>    TRANS = 'N':      Q * C          C * Q
!>    TRANS = 'T':      Q**H * C       C * Q**H
!>    donde Q es una matriz unitaria compleja definida como el producto de
!>    reflectores elementales bloqueados calculados por la factorización
!>    LQ ancha y corta (CLASWLQ)
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica Q o Q**H desde la Izquierda;
!>          = 'R': aplica Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transposición, aplica Q;
!>          = 'C':  Transposición conjugada, aplica Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.  M >=0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          M >= K >= 0;
!>
!>

MB

!>          MB es INTEGER
!>          El tamaño de bloque de filas a usar en el LQ bloqueado.
!>          M >= MB >= 1
!>

NB

!>          NB es INTEGER
!>          El tamaño de bloque de columnas a usar en el LQ bloqueado.
!>          NB > M.
!>

A

!>          A es un arreglo COMPLEX, dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el reflector
!>          elemental bloqueado H(i), para i = 1,2,...,k, tal como lo devuelve
!>          CLASWLQ en las primeras k filas de su argumento de arreglo A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA => max(1,K).
!>

T

!>          T es un arreglo COMPLEX, dimensión
!>          ( M * Número de bloques(CEIL(N-K/NB-K)),
!>          Los reflectores de bloques triangulares superiores bloqueados
!>          almacenados en forma compacta como una secuencia de bloques
!>          triangulares superiores.  Vea más abajo para más detalles.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del arreglo T.  LDT >= MB.
!>

C

!>          C es un arreglo COMPLEX, dimensión (LDC,N)
!>          A la entrada, la matriz C de M-por-N.
!>          A la salida, C es sobrescrita por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del arreglo C. LDC >= max(1,M).
!>

WORK

!>          (espacio de trabajo) Arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,NB*MB).
!>          Si SIDE = 'R', LWORK >= max(1,M*MB).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño mínimo del arreglo
!>          WORK, devuelve este valor como la primera entrada del arreglo
!>          WORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!> LQ Ancha y Corta (SWLQ) realiza LQ mediante una secuencia de transformaciones
!> unitarias, representando Q como un producto de otras matrices unitarias
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> donde cada Q(i) pone a cero las entradas de la diagonal superior de un bloque
!> de NB filas de A:
!>   Q(1) pone a cero las entradas de la diagonal superior de las filas 1:NB de A
!>   Q(2) pone a cero las filas inferiores MB-N de las filas [1:M,NB+1:2*NB-M] de A
!>   Q(3) pone a cero las filas inferiores MB-N de las filas [1:M,2*NB-M+1:3*NB-2*M] de A
!>   . . .
!>
!> Q(1) es calculado por GELQT, que representa Q(1) por vectores de Householder
!> almacenados bajo la diagonal de las filas 1:MB de A, y por reflectores de
!> bloques triangulares superiores, almacenados en el arreglo T(1:LDT,1:N).
!> Para más información vea Detalles Adicionales en GELQT.
!>
!> Q(i) para i>1 es calculado por TPLQT, que representa Q(i) por vectores de
!> Householder almacenados en las columnas [(i-1)*(NB-M)+M+1:i*(NB-M)+M] de A,
!> y por reflectores de bloques triangulares superiores, almacenados en el
!> arreglo T(1:LDT,(i-1)*M+1:i*M).
!> El último Q(k) puede usar menos filas.
!> Para más información vea Detalles Adicionales en TPLQT.
!>
!> Para más detalles del algoritmo general, vea la descripción de
!> TSQR Secuencial en la Sección 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>
