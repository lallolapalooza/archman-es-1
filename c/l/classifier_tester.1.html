CLASSIFIER_TESTER(1)   CLASSIFIER_TESTER(1)

NOMBRE

classifier_tester - para el motor *legacy tesseract*.

SINOPSIS

classifier_tester -U unicharset_file -F font_properties_file -X xheights_file -classifier x -lang lang [-output_trainer trainer] *.tr

DESCRIPCIÓN

classifier_tester(1) ejecuta Tesseract en un modo especial. Toma una lista de archivos .tr y prueba un clasificador de caracteres con datos formateados para entrenamiento, pero no tiene que ser igual a los datos de entrenamiento.

ARGUMENTOS DE ENTRADA/SALIDA

una lista de archivos .tr

OPCIONES

-l lang

(Entrada) código de idioma de tres caracteres; valor por defecto eng.

-classifier x

(Entrada) Uno de "pruner", "full".

-U unicharset

(Entrada) El conjunto de unichar para el idioma.

-F font_properties_file

(Entrada) archivo de propiedades de fuente, cada línea tiene el siguiente formato, donde cada campo aparte del nombre de la fuente es 0 o 1: 
*nombre_fuente* *cursiva* *negrita* *ancho_fijo* *serif* *frac*

-X xheights_file

(Entrada) archivo de alturas x, cada línea tiene el siguiente formato, donde la altura x se calcula como la altura x en píxeles de un carácter dibujado a 32pt con 300 dpi. [ Es decir, si la altura x base + ascendentes + descendentes = 133, ¿cuánto es la altura x? ] 
*nombre_fuente* *altura_x*

-output_trainer trainer

(Salida, Opcional) Nombre del archivo para el entrenador de salida.
