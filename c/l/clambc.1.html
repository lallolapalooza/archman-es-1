NOMBRE

clambc - Herramienta de análisis y prueba de bytecode

SINOPSIS

clambc <archivo> [función] [param1 ...]

DESCRIPCIÓN

Las firmas de bytecode son un formato de plugin ejecutable independiente de la plataforma que amplía las capacidades de detección de malware de ClamAV. Esta herramienta se proporciona para que los autores de firmas y los desarrolladores de ClamAV prueben las firmas de bytecode y el rendimiento en tiempo de ejecución del bytecode. **Precaución**: NUNCA debes ejecutar firmas de bytecode de fuentes no confiables. Hacerlo puede resultar en la ejecución de código arbitrario.

OPCIONES

--help -h
Mostrar ayuda.
--version -V
Mostrar versión
--debug
Mostrar depuración.
--force-interpreter -f
Forzar el uso del intérprete en lugar del JIT.
--trust-bytecode -t
Confiar en el bytecode cargado (por defecto sí).
--info -i
Imprimir información sobre el bytecode.
--printsrc -p
Imprimir el código fuente del bytecode.
--printbcir -c
Imprimir el IR de la firma de bytecode.
--input -r
Archivo de entrada sobre el cual ejecutar el bytecode.
--trace <nivel> -T
Establecer el nivel de rastreo del bytecode 0..7 (por defecto 7).
--no-trace-showsource
No mostrar la línea de código fuente durante el rastreo.
--statistics=bytecode
Recopilar e imprimir estadísticas de ejecución del bytecode.
archivo
Archivo a probar.
