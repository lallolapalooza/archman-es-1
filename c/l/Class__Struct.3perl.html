DESCRIPCIÓ

N

"Class::Struct" exporta una única función, "struct". Dada una lista de nombres y tipos de elementos, y opcionalmente un nombre de clase, "struct" crea una clase de Perl 5 que implementa una estructura de datos "similar a

struct".

A la nueva clase se le añade un método constructor, "new", para crear objetos

struct.

Cada elemento en la estructura de datos tiene un método accessor, que se usa para asignar al elemento y para obtener su valor. El accessor predeterminado puede ser sobrescrito declarando un "sub" con el mismo nombre en el paquete. (Ver Ejemplo 2.

)

El tipo de cada elemento puede ser escalar, array, hash o

clase.

La función

struct()

La función "struct" tiene tres formas de lista de

parámetros. 
struct( CLASS_NAME => [ ELEMENT_LIST ]);
struct( CLASS_NAME => { ELEMENT_LIST });
struct( ELEMENT_LIST )
;

La primera y segunda formas identifican explícitamente el nombre de la clase que se está creando. La tercera forma asume el nombre del paquete actual como nombre de la

clase.

Un objeto de una clase creada con la primera y la tercera formas se basa en un array, mientras que un objeto de una clase creada con la segunda forma se basa en un hash. Las formas basadas en array serán algo más rápidas y pequeñas; las formas basadas en hash son más

flexibles.

La clase creada por "struct" no debe ser una subclase de otra clase que no sea "UNIVERSAL"

.

Sin embargo, puede usarse como superclase para otras clases. Para facilitar esto, el método constructor generado usa una bendición de dos argumentos. Además, si la clase está basada en hash, la clave de cada elemento se le antepone el nombre de la clase (ver Perl Cookbook, Receta 13.12)

.

Una función llamada "new" no debe estar definida explícitamente en una clase creada por "struct"

.

La ELEMENT_LIST tiene la

forma 
NAME => TYPE, ..
.

Cada par nombre-tipo declara un elemento del struct. Cada nombre de elemento se definirá como un método accessor a menos que un método con ese nombre esté definido explícitamente; en este último caso, se emite una advertencia si el indicador de advertencia (-w) está

activ
ado.

Creación de clases en tiempo de

compilación

"Class::Struct" puede crear tu clase en tiempo de compilación. La razón principal para hacer esto es obvia, para que tu clase se comporte como cualquier otra clase en Perl. Crear tu clase en tiempo de compilación hará que el orden de los eventos sea similar al de usar cualquier otra clase ( o módulo de Perl )

.

No hay una ganancia de velocidad significativa entre la crea

ción de la clase en tiempo de compilación y en tiempo de
ejecución, solo hay un nuevo orden de eventos más estándar.

Tipos de elementos y métodos

accessor

Los cuatro tipos de elementos -- escalar, array, hash y clase -- se representan con cadenas -- '$', '@', '%', y un nombre de clase -- opcionalmente precedidos por un '*'

.

El método accessor proporcionado por "struct" para un elemento depende del tipo declarado del

elemento.
Escalar ('$' o
'*$')
El elemento es un escalar, y por defecto se inicializa a "undef" (pero ver "Inicialización con new").

El argumento del accessor, si lo hay, se asigna al

elemento.

Si el tipo de elemento es '$', se devuelve el valor del elemento (después de la asignación). Si el tipo de elemento es '*$', se devuelve una

referencia
al elemento.
Array ('@' o
'*@')
El elemento es un array, inicializado por defecto a "()".

Sin argumentos, el accessor devuelve una referencia al array completo del elemento (independientemente de si el elemento se especificó como '@' o '*@'

).

Con uno o dos argumentos, el primer argumento es un índice que especifica un elemento del array; el segundo argumento, si está presente, se asigna al elemento del array. Si el tipo de elemento es '@', el accessor devuelve el valor del elemento del array. Si el tipo de elemento es '*@', se devuelve una referencia al elemento del

array.

Como caso especial, cuando el accessor se llama con una r

eferencia a array como único argumento, esto provoca la asignación
del array completo. Se devuelve la referencia al objeto.
Hash ('%' o
'*%')
El elemento es un hash, inicializado por defecto a "()".

Sin argumentos, el accessor devuelve una referencia al hash completo del elemento (independientemente de si el elemento se especificó como '%' o '*%'

).

Con uno o dos argumentos, el primer argumento es una clave que especifica un elemento del hash; el segundo argumento, si está presente, se asigna al elemento del hash. Si el tipo de elemento es '%', el accessor devuelve el valor del elemento del hash. Si el tipo de elemento es '*%', se devuelve una referencia al elemento del

hash.

Como caso especial, cuando el accessor se llama con una r

eferencia a hash como único argumento, esto provoca la asignació
n del hash completo. Se devuelve la referencia al objeto.
Clase ('Class_Name' o
'*Class_Name')
El valor del elemento debe ser una referencia bendecida a la clase nombrada o a una de sus subclases. El elemento no se inicializa por defecto.

El argumento del accessor, si lo hay, se asigna al elemento. El accessor hará "croak" si no es una referencia a objeto

apropiada.

Si el tipo de elemento no comienza con un '*', el accessor devuelve el valor del elemento (después de la asignación). Si el tipo de elemento comienza con un '*', se devuelve un

a
referencia
al eleme
nto mismo. ">

Inicializando con

"new"

"struct" siempre crea un constructor llamado "new". Ese constructor puede recibir una lista de inicializadores para los distintos elementos de la nueva

estructura.

Cada inicializador es un par de valores: nombre del elemento" => "valor. El valor inicializador para un elemento escalar es simplemente un valor escalar. El inicializador para un elemento de arreglo es una referencia a un arreglo. El inicializador para un hash es una referencia a un

hash.

El inicializador para un elemento de clase es un objeto de la clase correspondiente, o de una de sus subclases, o una referencia a un hash que contenga argumentos con nombre que se pasarán al constructor del

elemento.

Vea el Ejemplo 3

más abajo para
ver un ejemplo de
inicialización.

EJEMPLO

S
Ejemplo
1
Dar a un elemento de la estructura un tipo de clase que también es una estructura es la forma en que las estructuras se anidan. Aquí, "Timeval" representa un tiempo (segundos y microsegundos), y "Rusage" tiene dos elementos, cada uno de los cuales es de tipo "Timeval". 
use Class::Struct;
struct( Rusage => {
    ru_utime => 'Timeval',  # tiempo de usuario usado
    ru_stime => 'Timeval',  # tiempo de sistema usado
});
struct( Timeval => [
    tv_secs  => '$',
# segundos tv_usecs => '$', # microsegundos ]); # crear un objeto: my $t = Rusage->new(ru_utime=>Timeval->new(), ru_stime=>Timeval->new()); # $t->ru_utime y $t->ru_stime son o
bjetos de tipo Timeval. # establecer $t->ru_utime a 100.0 seg y $t->ru_stime a 5.0 seg. $t->ru_utime->tv_secs(100); $t->ru_utime->tv_usecs(0); $t->ru_stime->tv_secs(5); $t->ru_stime->tv_usecs(0);
Ejemplo
2
Se puede redefinir una función de acceso para proporcionar comprobaciones adicionales de valores, etc. Aquí, queremos que el elemento "count" sea siempre no negativo, así que redefinimos el acceso "count" en consecuencia. 
package MyObj;
use Class::Struct;
# declarar la estructura
struct ( 'MyObj', { count => '$', stuff => '%' } );
# anular el método de acceso predeterminado para 'count'
sub count {
    my $self = shift;
    if ( @_ ) {
        die 'count must b
e nonnegative' if $_[0] < 0; $self->{'MyObj::count'} = shift; warn "Too many args to count" if @_; } return $self->{'MyObj::count'}; } package main; $x = new MyObj; print "\$x->count(5) = ", $x->count(5), "\n";
# imprime '$x->count(5) = 5' print "\$x->count = ", $x->count, "\n"; # imprime '$x->count = 5' print "\$x->count(-5) = ", $x->count(-5), "\n"; # muere debido al argumento negativo!
Ejemplo
3
Al constructor de una clase generada se le puede pasar una lista de pares elemento=>valor, con los cuales inicializar la estructura. Si no se especifica un inicializador para un elemento en particular, se realiza su inicialización predeterminada. Los inicializadores para elementos inexistentes se ignoran silenciosamente.

Tenga en cuenta que el inicializador para una clase anidada puede especificarse como un objeto de esa clase, o como una referencia a un hash de inicializadores que se pasan al constructor de la estructura

anidada. 
use Class::Struct;
struct Breed =>
{
    name  => '$',
    cross => '$',
};
struct Cat =>
[
    name     => '$',
    kitten
s => '@', markings => '%', breed => 'Breed', ]; my $cat = Cat->new( name => 'Socks', kittens => ['Mo
nica', 'Kenneth'], markings => { socks=>1, blaze=>"white" }, breed => Breed->new(name=>'short-hair
', cross=>1), o: breed => {name=>'short-hair', cross=>1}, ); print "Once a cat called ", $cat->n
ame, "\n"; print "(which was a ", $cat->breed->name, ")\n"; print "had 2 kittens: ", join(' and ', @{$cat->kittens}), "\n";

Modificaciones

Modificado por Damian Conway, 2001-09-10, v0.

62. 
Modificada la construcción implícita de objetos anidados.
Ahora también acepta una referencia a objeto en lugar de requerir una referencia a hash.
También inicializa por defecto los atributos de objetos anidados a undef, en lugar de
llamar al constructor del objeto sin argumentos
La sobreutilidad original estaba llena de problemas:
    * el constructor de la clase podría no llamarse 'new'
    * la clase podría no tener un constructor con argumentos tipo hash
    * la clase podría no tener un constructor sin argumentos
    * las estructuras de datos "recursivas" no funcionaban bien:
              package Person;
              struct { mother => 'Person', father => 'Person'}
;

59.

compilación.

58. 
Se añadió el manejo de listas de argumentos tipo hash para el constructor de la clase.
Se cambió a la bendición de dos argumentos en el constructor para soportar
la derivación de clases creadas.
Se añadieron prefijos de nombre de clase a las claves en clases basadas en hash

Se corrigió el comportamiento de los accesores para los elementos de estructura '*@' y '*%'.
