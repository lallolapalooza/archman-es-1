CLATM

R

Propósito

: 
!>
!>    CLATMR genera matrices aleatorias de varios tipos para probar
!>    programas LAPACK.
!>
!>    CLATMR opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Generar una matriz A con entradas aleatorias de distribución DIST
!>         que es simétrica si SYM='S', hermitiana si SYM='H', y
!>         no simétrica si SYM='N'.
!>
!>      Establecer la diagonal en D, donde D puede ser de entrada o
!>         calculado de acuerdo con MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>      Graduar la matriz, si se desea, desde la izquierda y/o derecha
!>         como se especifica con GRADE. Las entradas DL, MODEL, CONDL, DR,
!>         MODER y CONDR también determinan la graduación como se describe
!>         a continuación.
!>
!>      Permutar, si se desea, las filas y/o columnas como se especifica con
!>         PIVTNG e IPIVOT.
!>
!>      Establecer entradas aleatorias a cero, si se desea, para obtener una matriz dispersa aleatoria
!>         como se especifica con SPARSE.
!>
!>      Hacer que A sea una matriz de banda, si se desea, poniendo a cero la matriz
!>         fuera de una banda de ancho de banda inferior KL y ancho de banda superior KU.
!>
!>      Escalar A, si se desea, para tener una entrada máxima ANORM.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetado
!>         poner a cero la mitad superior (si es simétrica o hermitiana)
!>         poner a cero la mitad inferior (si es simétrica o hermitiana)
!>         almacenar la mitad superior por columnas (si es simétrica o hermitiana
!>             o triangular superior cuadrada)
!>         almacenar la mitad inferior por columnas (si es simétrica o hermitiana
!>             o triangular inferior cuadrada)
!>             igual que la mitad superior por filas si es simétrica
!>             igual que la mitad superior conjugada por filas si es hermitiana
!>         almacenar el triángulo inferior en formato de banda
!>             (si es simétrica o hermitiana)
!>         almacenar el triángulo superior en formato de banda
!>             (si es simétrica o hermitiana)
!>         almacenar la matriz completa en formato de banda
!>
!>    Nota: Si dos llamadas a CLATMR difieren solo en el parámetro PACK,
!>          generarán matrices matemáticamente equivalentes.
!>
!>          Si dos llamadas a CLATMR ambas tienen ancho de banda completo (KL = M-1
!>          y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>          entonces las matrices generadas diferirán solo
!>          en el orden de las filas y/o columnas, y de otro modo
!>          contendrán los mismos datos. Esta consistencia no puede ser y
!>          no se mantiene con menos que el ancho de banda completo.
!
>

Parámetro

s
M 
!>          M es INTEGER
!>           Número de filas de A. No modificado.
!
>

N 
!>          N es INTEGER
!>           Número de columnas de A. No modificado.
!
>

DIS

T 
!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a usar
!>           para generar una matriz aleatoria.
!>           'U' => partes real e imaginaria son independientes
!>                  UNIFORM( 0, 1 )  ( 'U' para uniforme )
!>           'S' => partes real e imaginaria son independientes
!>                  UNIFORM( -1, 1 ) ( 'S' para simétrica )
!>           'N' => partes real e imaginaria son independientes
!>                  NORMAL( 0, 1 )   ( 'N' para normal )
!>           'D' => uniforme en el interior del disco unidad ( 'D' para disco )
!>           No modificado.
!
>

ISEE

D 
!>          ISEED es un array INTEGER, dimensión (4)
!>           En la entrada ISEED especifica la semilla del generador de números
!>           aleatorios. Deberían estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debería ser impar. El generador de números aleatorios
!>           usa una secuencia congruencial lineal limitada a pequeños
!>           enteros, y por lo tanto debería producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED cambian en
!>           la salida, y pueden usarse en la siguiente llamada a CLATMR
!>           para continuar la misma secuencia de números aleatorios.
!>           Cambiado en la salida.
!
>

SY

M 
!>          SYM es CHARACTER*1
!>           Si SYM='S', la matriz generada es simétrica.
!>           Si SYM='H', la matriz generada es hermitiana.
!>           Si SYM='N', la matriz generada no es simétrica.
!>           No modificado.
!
>

D 
!>          D es un array COMPLEX, dimensión (min(M,N))
!>           En la entrada este array especifica las entradas diagonales
!>           de la diagonal de A.  D puede especificarse
!>           en la entrada, o establecerse de acuerdo con MODE y COND como se describe
!>           a continuación. Si la matriz es hermitiana, se tomará la parte real de D.
!>           Puede cambiar en la salida si MODE es distinto de cero.
!
>

MOD

E 
!>          MODE es INTEGER
!>           En la entrada describe cómo se debe usar D:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) de modo que sus logaritmos
!>                    estén uniformemente distribuidos.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D está invertido.
!>           Así que si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, de 1/COND a 1,
!>           No modificado.
!
>

CON

D 
!>          COND es REAL
!>           En la entrada, se usa como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!
>

DMA

X 
!>          DMAX es COMPLEX
!>           Si MODE no es ni -6, 0 ni 6, la diagonal se escala por
!>           DMAX / max(abs(D(i))), de modo que la entrada absoluta máxima
!>           de la diagonal sea abs(DMAX). Si DMAX es complejo (o cero),
!>           la diagonal se escalará por un número complejo (o cero).
!
>

RSIG

N 
!>          RSIGN es CHARACTER*1
!>           Si MODE no es ni -6, 0 ni 6, especifica el signo de la diagonal
!>           como sigue:
!>           'T' => las entradas diagonales se multiplican por un número complejo aleatorio
!>                  uniformemente distribuido con valor absoluto 1
!>           'F' => diagonal sin cambios
!>           No modificado.
!
>

GRAD

E 
!>          GRADE es CHARACTER*1
!>           Especifica la graduación de la matriz como sigue:
!>           'N'  => sin graduación
!>           'L'  => matriz premultiplicada por diag( DL )
!>                   (solo si la matriz no es simétrica)
!>           'R'  => matriz postmultiplicada por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'B'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'H'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( CONJG(DL) )
!>                   (solo si la matriz es Hermitiana o no simétrica)
!>           'S'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>                   (solo si la matriz es simétrica o no simétrica)
!>           'E'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>                         ( 'S' para similitud )
!>                   (solo si la matriz no es simétrica)
!>                   Nota: si GRADE='S', entonces M debe ser igual a N.
!>           No modificado.
!>


DL

!>          DL es un array COMPLEX, de dimensión (M)
!>           Si MODEL=0, entonces a la entrada este array especifica las
!>           entradas diagonales de una matriz diagonal utilizada como se
!>           describe en GRADE arriba. Si MODEL no es cero, entonces DL se
!>           establecerá de acuerdo con MODEL y CONDL, de forma análoga a
!>           como D se establece de acuerdo con MODE y COND (excepto que
!>           no hay parámetro DMAX para DL).
!>           Si GRADE='E', entonces DL no puede tener entradas cero.
!>           No referenciado si GRADE = 'N' o 'R'. Modificado a la salida.
!>




MODEL

!>          MODEL es INTEGER
!>           Este especifica cómo se va a calcular el array diagonal DL,
!>           así como MODE especifica cómo se va a calcular D.
!>           No modificado.
!>




CONDL

!>          CONDL es REAL
!>           Cuando MODEL no es cero, este especifica el número de
!>           condición de DL calculado. No modificado.
!>




DR

!>          DR es un array COMPLEX, de dimensión (N)
!>           Si MODER=0, entonces a la entrada este array especifica las
!>           entradas diagonales de una matriz diagonal utilizada como se
!>           describe en GRADE arriba. Si MODER no es cero, entonces DR se
!>           establecerá de acuerdo con MODER y CONDR, de forma análoga a
!>           como D se establece de acuerdo con MODE y COND (excepto que
!>           no hay parámetro DMAX para DR).
!>           No referenciado si GRADE = 'N', 'L', 'H' o 'S'.
!>           Modificado a la salida.
!>




MODER

!>          MODER es INTEGER
!>           Este especifica cómo se va a calcular el array diagonal DR,
!>           así como MODE especifica cómo se va a calcular D.
!>           No modificado.
!>




CONDR

!>          CONDR es REAL
!>           Cuando MODER no es cero, este especifica el número de
!>           condición de DR calculado. No modificado.
!>




PIVTNG

!>          PIVTNG es CHARACTER*1
!>           A la entrada especifica las permutaciones de pivote como sigue:
!>           'N' o ' ' => ninguna.
!>           'L' => pivoteo izquierdo o de fila (la matriz debe ser no simétrica).
!>           'R' => pivoteo derecho o de columna (la matriz debe ser
!>                  no simétrica).
!>           'B' o 'F' => ambos o pivoteo completo, es decir, en ambos lados.
!>                         En este caso, M debe ser igual a N.
!>
!>           Si dos llamadas a CLATMR tienen el mismo ancho de banda completo (KL = M-1
!>           y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>           entonces las matrices generadas diferirán solo en el orden de las
!>           filas y/o columnas, y de lo contrario contendrán los mismos datos.
!>           Esta consistencia no se puede mantener con un ancho de banda menor que
!>           el completo.
!>




IPIVOT

!>          IPIVOT es un array INTEGER, de dimensión (N o M)
!>           Este array especifica la permutación utilizada. Después de generar la
!>           matriz básica, se permutan las filas, columnas o ambas. Si, por ejemplo,
!>           se selecciona el pivoteo de filas, CLATMR comienza con la *última*
!>           fila e intercambia la M-ésima y la IPIVOT(M)-ésima fila, luego pasa a
!>           la penúltima fila, intercambiando la (M-1)-ésima y la IPIVOT(M-1)-ésima fila,
!>           y así sucesivamente. En términos de, la permutación es
!>           (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
!>           donde el ciclo más a la derecha se aplica primero. Este es el
!>           *inverso* del efecto del pivoteo en LINPACK. La idea es que la
!>           factorización (con pivoteo) de una matriz identidad que ha sido
!>           inversamente pivotada de esta manera debería resultar en un vector
!>           de pivote idéntico a IPIVOT.
!>           No referenciado si PIVTNG = 'N'. No modificado.
!>




KL

!>          KL es INTEGER
!>           A la entrada especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica Hessenberg
!>           superior, y KL al menos M-1 implica que la matriz no es de banda.
!>           Debe ser igual a KU si la matriz es simétrica o Hermitiana.
!>           No modificado.
!>




KU

!>          KU es INTEGER
!>           A la entrada especifica el ancho de banda superior de la matriz. Por
!>           ejemplo, KU=0 implica triangular inferior, KU=1 implica Hessenberg
!>           inferior, y KU al menos N-1 implica que la matriz no es de banda.
!>           Debe ser igual a KL si la matriz es simétrica o Hermitiana.
!>           No modificado.
!>




SPARSE

!>          SPARSE es REAL
!>           A la entrada especifica la dispersión de la matriz si se va a generar
!>           una matriz dispersa. SPARSE debe estar entre 0 y 1. Para generar una
!>           matriz dispersa, para cada entrada de la matriz se genera un número
!>           aleatorio uniforme (0, 1) x y se compara con SPARSE; si x es mayor,
!>           la entrada de la matriz no se modifica y si x es menor, la entrada se
!>           establece a cero. Por lo tanto, en promedio, una fracción SPARSE de las
!>           entradas se establecerá a cero.
!>           No modificado.
!>




ANORM

!>          ANORM es REAL
!>           A la entrada especifica la entrada máxima de la matriz de salida
!>           (la matriz de salida se multiplicará por una constante para que su
!>           entrada absoluta más grande sea ANORM) si ANORM es no negativo.
!>           Si ANORM es negativo, no se realiza ningún escalado. No modificado.
!>




PACK

!>          PACK es CHARACTER*1
!>           A la entrada especifica el empaquetado de la matriz como sigue:
!>           'N' => sin empaquetar
!>           'U' => poner a cero todas las entradas subdiagonales
!>                  (si es simétrica o Hermitiana)
!>           'L' => poner a cero todas las entradas superdiagonales
!>                  (si es simétrica o Hermitiana)
!>           'C' => almacenar el triángulo superior por columnas
!>                  (solo si la matriz es simétrica o Hermitiana o
!>                   triangular superior cuadrada)
!>           'R' => almacenar el triángulo inferior por columnas
!>                  (solo si la matriz es simétrica o Hermitiana o
!>                   triangular inferior cuadrada)
!>                  (igual que la mitad superior por filas si es simétrica)
!>                  (igual que la mitad superior conjugada por filas si es Hermitiana)
!>           'B' => almacenar el triángulo inferior en el esquema de almacenamiento
!>                  de banda (solo si la matriz es simétrica o Hermitiana)
!>           'Q' => almacenar el triángulo superior en el esquema de almacenamiento
!>                  de banda (solo si la matriz es simétrica o Hermitiana)
!>           'Z' => almacenar toda la matriz en el esquema de almacenamiento
!>                  de banda (se puede proporcionar pivoteo usando esta
!>                  opción para almacenar A en las filas finales del
!>                  almacenamiento asignado)
!>
!>           Usando estas opciones, se pueden obtener los diversos esquemas de
!>           almacenamiento empaquetado y de banda de LAPACK:
!>           GB               - usar 'Z'
!>           PB, HB o TB     - usar 'B' o 'Q'
!>           PP, HP o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a CLATMR difieren solo en el parámetro PACK,
!>           generarán matrices matemáticamente equivalentes.
!>           No modificado.
!>




A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>           A la salida, A es la matriz de prueba deseada. Solo las
!>           entradas de A que son significativas a la salida serán
!>           referenciadas (incluso si A está en formato de almacenamiento
!>           empaquetado o de banda). Las 'esquinas no ocupadas' de A en
!>           formato de banda se pondrán a cero.
!>




LDA

!>          LDA es INTEGER
!>           A la entrada LDA especifica la primera dimensión de A tal como
!>           está declarada en el programa llamador.
!>           Si PACK='N', 'U' o 'L', LDA debe ser al menos max( 1, M ).
!>           Si PACK='C' o 'R', LDA debe ser al menos 1.
!>           Si PACK='B' o 'Q', LDA debe ser MIN( KU+1, N ).
!>           Si PACK='Z', LDA debe ser al menos KUU+KLL+1, donde
!>           KUU = MIN( KU, N-1 ) y KLL = MIN( KL, M-1 ).
!>           No modificado.
!>




IWORK

!>          IWORK es un array INTEGER, de dimensión (N o M)
!>           Espacio de trabajo. No referenciado si PIVTNG = 'N'. Modificado a la salida.
!>




INFO

!>          INFO es INTEGER
!>           Parámetro de error a la salida:
!>             0 => retorno normal
!>            -1 => M negativo o desigual a N y SYM='S' o 'H'
!>            -2 => N negativo
!>            -3 => DIST cadena ilegal
!>            -5 => SYM cadena ilegal
!>            -7 => MODE no está en el rango -6 a 6
!>            -8 => COND menor que 1.0, y MODE ni -6, 0 ni 6
!>           -10 => MODE ni -6, 0 ni 6 y RSIGN cadena ilegal
!>           -11 => GRADE cadena ilegal, o GRADE='E' y
!>                  M no es igual a N, o GRADE='L', 'R', 'B', 'S' o 'E'
!>                  y SYM = 'H', o GRADE='L', 'R', 'B', 'H' o 'E'
!>                  y SYM = 'S'
!>           -12 => GRADE = 'E' y DL contiene cero
!>           -13 => MODEL no está en el rango -6 a 6 y GRADE= 'L', 'B', 'H',
!>                  'S' o 'E'
!>           -14 => CONDL menor que 1.0, GRADE='L', 'B', 'H', 'S' o 'E',
!>                  y MODEL ni -6, 0 ni 6
!>           -16 => MODER no está en el rango -6 a 6 y GRADE= 'R' o 'B'
!>           -17 => CONDR menor que 1.0, GRADE='R' o 'B', y
!>                  MODER ni -6, 0 ni 6
!>           -18 => PIVTNG cadena ilegal, o PIVTNG='B' o 'F' y
!>                  M no es igual a N, o PIVTNG='L' o 'R' y SYM='S'
!>                  o 'H'
!>           -19 => IPIVOT contiene un número fuera de rango y
!>                  PIVTNG no es igual a 'N'
!>           -20 => KL negativo
!>           -21 => KU negativo, o SYM='S' o 'H' y KU no es igual a KL
!>           -22 => SPARSE no está en el rango 0. a 1.
!>           -24 => PACK cadena ilegal, o PACK='U', 'L', 'B' o 'Q'
!>                  y SYM='N', o PACK='C' y SYM='N' y (KL
!>                  no es igual a 0 o N no es igual a M).


o PACK='R' y
!>                  SYM='N', y ya sea KU distinto de 0 o N distinto
!>                  de M
!>           -26 => LDA demasiado pequeño
!>             1 => Error devuelto por CLATM1 (calculando D)
!>             2 => No se puede escalar la diagonal a DMAX (la entrada máxima es 0)
!>             3 => Error devuelto por CLATM1 (calculando DL)
!>             4 => Error devuelto por CLATM1 (calculando DR)
!>             5 => ANORM es positivo, pero la matriz construida antes de
!>                  intentar escalarla para que tenga norma ANORM, es cero
!
