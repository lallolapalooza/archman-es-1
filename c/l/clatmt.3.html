Documentación de Función/Subrutina

subroutine clatmt (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, real, dimension( * ) d, integer mode, real cond, real dmax, integer rank, integer kl, integer ku, character pack, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) work, integer info)

CLATMT

Propósito:

!>
!>    CLATMT genera matrices aleatorias con valores singulares especificados
!>    (o hermíticas con valores propios especificados)
!>    para probar programas LAPACK.
!>
!>    CLATMT opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establecer la diagonal a D, donde D puede ser de entrada o
!>         calculada de acuerdo con MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Generar una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Generar una matriz densa M x N multiplicando D a la izquierda
!>              y a la derecha por matrices unitarias aleatorias, y luego:
!>
!>          Reducir el ancho de banda de acuerdo con KL y KU, usando
!>              transformaciones de Householder.
!>
!>      Método B:
!>          Convertir la matriz de ancho de banda 0 (es decir, diagonal) a una
!>              matriz de ancho de banda 1 usando rotaciones de Givens, 
!>              elementos fuera de banda hacia atrás, de manera similar a QR; luego convertir
!>              el ancho de banda 1 a una matriz de ancho de banda 2, etc. Tenga en cuenta
!>              que para anchos de banda razonablemente pequeños (en relación con M y
!>              N) esto requiere menos almacenamiento, ya que no se genera una matriz densa.
!>              Además, para matrices hermíticas o simétricas,
!>              solo se genera un triángulo.
!>
!>      Se elige el Método A si el ancho de banda es una fracción grande del
!>          orden de la matriz, y LDA es al menos M (para que se pueda almacenar
!>          una matriz densa). Se elige el Método B si el ancho de banda
!>          es pequeño (< 1/2 N para hermítica o simétrica, < .3 N+M para
!>          no simétrica), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es hermítica)
!>         poner a cero la mitad inferior (si es hermítica)
!>         almacenar la mitad superior columna a columna (si es hermítica o
!>               triangular superior)
!>         almacenar la mitad inferior columna a columna (si es hermítica o
!>               triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es hermítica o
!>               triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es hermítica o
!>               triangular superior)
!>         almacenar toda la matriz en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en formato de banda, por lo que no será necesario reempaquetar.
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de A. No se modifica.
!>

N

!>          N es INTEGER
!>           El número de columnas de A. N debe ser igual a M si la matriz
!>           es simétrica o hermítica (es decir, si SYM es 'N')
!>           No se modifica.
!>

DIST

!>          DIST es CHARACTER*1
!>           A la entrada, DIST especifica el tipo de distribución que se utilizará
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORME( 0, 1 )  ('U' para uniforme)
!>           'S' => UNIFORME( -1, 1 ) ('S' para simétrico)
!>           'N' => NORMAL( 0, 1 )   ('N' para normal)
!>           No se modifica.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión ( 4 )
!>           A la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Debe estar entre 0 y 4095, ambos inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros
!>           pequeños, y por lo tanto debería producir números aleatorios independientes
!>           de la máquina. Los valores de ISEED se cambian a la
!>           salida, y se pueden usar en la siguiente llamada a CLATMT
!>           para continuar la misma secuencia de números aleatorios.
!>           Modificado a la salida.
!>

SYM

!>          SYM es CHARACTER*1
!>           Si SYM='H', la matriz generada es hermítica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es hermítica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada no es simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           Si SYM='S', la matriz generada es simétrica (compleja),
!>             con valores singulares especificados por D, COND, MODE y
!>             DMAX; no serán negativos.
!>           No se modifica.
!>

D

!>          D es un array REAL, de dimensión ( MIN( M, N ) )
!>           Este array se utiliza para especificar los valores singulares o
!>           valores propios de A (ver SYM, arriba). Si MODE=0, entonces D se
!>           asume que contiene los valores singulares/propios, de lo contrario
!>           se calcularán de acuerdo con MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es INTEGER
!>           A la entrada, esto describe cómo se deben especificar los valores singulares/propios:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:RANK)=1.0/COND
!>           MODE = 2 establece D(1:RANK-1)=1 y D(RANK)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(RANK-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           Si SYM='H', y MODE no es 0, 6 ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo aleatorio
!>              (es decir, +1 o -1).
!>           No se modifica.
!>

COND

!>          COND es REAL
!>           A la entrada, se utiliza como se describe en MODE arriba.
!>           Si se utiliza, debe ser >= 1. No se modifica.
!>

DMAX

!>          DMAX es REAL
!>           Si MODE no es -6, 0 ni 6, el contenido de D, según
!>           calculado de acuerdo con MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))); por lo tanto, el valor propio o singular
!>           máximo absoluto (es decir, la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no tiene por qué ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No se modifica.
!>

RANK

!>          RANK es INTEGER
!>           El rango de la matriz a generar solo para los modos 1, 2, 3.
!>           D( RANK+1:N ) = 0.
!>           No se modifica.
!>

KL

!>          KL es INTEGER
!>           Esto especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 im
plies upper triangular, KL=1 implies upper !> Hessenberg, and KL being at least M-1 means that the matrix !> has full lower bandwidth. KL must equal KU if the matrix !> is symmetric or hermitian. !> Not modified. !>

K

U 
!>          KU is INTEGER
!>           This specifies the upper bandwidth of the  matrix. For
!>           example, KU=0 implies lower triangular, KU=1 implies lower
!>           Hessenberg, and KU being at least N-1 means that the matrix
!>           has full upper bandwidth.  KL must equal KU if the matrix
!>           is symmetric or hermitian.
!>           Not modified.
!
>

PAC

K 
!>          PACK is CHARACTER*1
!>           This specifies packing of matrix as follows:
!>           'N' => no packing
!>           'U' => zero out all subdiagonal entries (if symmetric
!>                  or hermitian)
!>           'L' => zero out all superdiagonal entries (if symmetric
!>                  or hermitian)
!>           'C' => store the upper triangle columnwise (only if the
!>                  matrix is symmetric, hermitian, or upper triangular)
!>           'R' => store the lower triangle columnwise (only if the
!>                  matrix is symmetric, hermitian, or lower triangular)
!>           'B' => store the lower triangle in band storage scheme
!>                  (only if the matrix is symmetric, hermitian, or
!>                  lower triangular)
!>           'Q' => store the upper triangle in band storage scheme
!>                  (only if the matrix is symmetric, hermitian, or
!>                  upper triangular)
!>           'Z' => store the entire matrix in band storage scheme
!>                      (pivoting can be provided for by using this
!>                      option to store A in the trailing rows of
!>                      the allocated storage)
!>
!>           Using these options, the various LAPACK packed and banded
!>           storage schemes can be obtained:
!>           GB                    - use 'Z'
!>           PB, SB, HB, or TB     - use 'B' or 'Q'
!>           PP, SP, HB, or TP     - use 'C' or 'R'
!>
!>           If two calls to CLATMT differ only in the PACK parameter,
!>           they will generate mathematically equivalent matrices.
!>           Not modified.
!
>

A 
!>          A is COMPLEX array, dimension ( LDA, N )
!>           On exit A is the desired test matrix.  A is first generated
!>           in full (unpacked) form, and then packed, if so specified
!>           by PACK.  Thus, the first M elements of the first N
!>           columns will always be modified.  If PACK specifies a
!>           packed or banded storage scheme, all LDA elements of the
!>           first N columns will be modified; the elements of the
!>           array which do not correspond to elements of the generated
!>           matrix are set to zero.
!>           Modified.
!
>

LD

A 
!>          LDA is INTEGER
!>           LDA specifies the first dimension of A as declared in the
!>           calling program.  If PACK='N', 'U', 'L', 'C', or 'R', then
!>           LDA must be at least M.  If PACK='B' or 'Q', then LDA must
!>           be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
!>           If PACK='Z', LDA must be large enough to hold the packed
!>           array: MIN( KU, N-1) + MIN( KL, M-1) + 1.
!>           Not modified.
!
>

WOR

K 
!>          WORK is COMPLEX array, dimension ( 3*MAX( N, M ) )
!>           Workspace.
!>           Modified.
!
>

INF

O 
!>          INFO is INTEGER
!>           Error code.  On exit, INFO will be set to one of the
!>           following values:
!>             0 => normal return
!>            -1 => M negative or unequal to N and SYM='S', 'H', or 'P'
!>            -2 => N negative
!>            -3 => DIST illegal string
!>            -5 => SYM illegal string
!>            -7 => MODE not in range -6 to 6
!>            -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
!>           -10 => KL negative
!>           -11 => KU negative, or SYM is not 'N' and KU is not equal to
!>                  KL
!>           -12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
!>                  or PACK='C' or 'Q' and SYM='N' and KL is not zero;
!>                  or PACK='R' or 'B' and SYM='N' and KU is not zero;
!>                  or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
!>                  N.
!>           -14 => LDA is less than M, or PACK='Z' and LDA is less than
!>                  MIN(KU,N-1) + MIN(KL,M-1) + 1.
!>            1  => Error return from SLATM7
!>            2  => Cannot scale to DMAX (max. sing. value is 0)
!>            3  => Error return from CLAGGE, CLAGHE or CLAGSY
!>
