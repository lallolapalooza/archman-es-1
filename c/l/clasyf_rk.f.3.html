subroutine clasyf_rk (character uplo, integer n, integer nb, integer kb, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) e, integer, dimension( * ) ipiv, complex, dimension( ldw, * ) w, integer ldw, integer info)

CLASYF_RK calcula una factorización parcial de una matriz simétrica indefinida compleja utilizando el método de pivoteo diagonal Bunch-Kaufman (rook) limitado.

Propósito:

!> CLASYF_RK calcula una factorización parcial de una matriz simétrica
!> compleja A utilizando el método de pivoteo diagonal Bunch-Kaufman
!> (rook) limitado. La factorización parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!>
!> CLASYF_RK es una subrutina auxiliar llamada por CSYTRF_RK. Utiliza
!> código bloqueado (llamando a BLAS de Nivel 3) para actualizar la
!> submatriz A11 (si UPLO = 'U') o A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es INTEGER
!>          El número máximo de columnas de la matriz A que deben ser
!>          factorizadas.  NB debe ser al menos 2 para permitir bloques
!>          de pivote de 2x2.
!>

KB

!>          KB es INTEGER
!>          El número de columnas de A que fueron realmente factorizadas.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte superior triangular N por N
!>            que la contiene la parte triangular superior de la matriz A,
!>            y la parte triangular estrictamente inferior de A no
!>            se referencia.
!>
!>            Si UPLO = 'L': la parte inferior triangular N por N
!>            que la contiene la parte triangular inferior de la matriz A,
!>            y la parte triangular estrictamente superior de A no
!>            se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz simétrica
!>               bloque diagonal D en la diagonal de A, es decir,
!>               D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array COMPLEX, dimension (N)
!>          En la salida, contiene los elementos superdiagonales (o
!>          subdiagonales) de la matriz simétrica bloque diagonal D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en el que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloque
!>          de la matriz simétrica bloque diagonal D con bloques diagonales
!>          de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización.
!>
!>          Si UPLO = 'U',
!>          ( en orden de factorización, k disminuye de N a 1 ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,N-KB+1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k e -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre se cumple ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en orden de factorización, k aumenta de 1 a N ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,1:KB).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k e -IPIV(k) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre se cumple ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>

W

!>          W es array COMPLEX, dimension (LDW,NB)
!>

LDW

!>          LDW es INTEGER
!>          La dimensión principal del array W.  LDW >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:

!>

NAME

clasyf_rk — Routine to compute the block LU factorization of a complex general band matrix using partial pivoting with rook interchanges.

SYNOPSIS

SUBROUTINE CLASYF_RK(UPLO, N, NB, KB, AB, LDAB, IPIV, WORK, LWORK, INFO)

Parameters:

UPLO
CHARACTER*1. On entry, UPLO specifies whether the

upper or lower triangular part of the matrix A is to be sequenced as follows:

UPLO = 'U' Only the upper triangle of A is to be sequenced.

UPLO = 'L' Only the lower triangle of A is to be sequenced.

N
INTEGER. On entry, N is the order of the matrix

A.

NB
INTEGER. On entry, NB is the block size to be used in

the

factorization.

KB
INTEGER. On entry, KB is the number of super- or

sub-diagonals in the band matrix A.

AB
COMPLEX*16 array, dimension (LDAB,N).

On entry, the coefficient matrix A.

On exit, AB is overwritten by details of the factorization.

The upper or lower triangular stored band matrix is in AB.

LDAB
INTEGER. On entry, LDAB is the leading dimension of

the array AB.

IPIV
INTEGER array, dimension (N).

Details of the row and column interchanges, and of the block factorization. More precisely, the rows/columns i and IPIV(i) are interchanged. The IPIV array must be dimensioned for at least size N. The meaning of IPIV(i) depends on the value of i.

If IPIV(i) > 0, then rows and columns i and IPIV(i) are interchanged. IPIV(i) is the pivot row, and i is the pivot column.

If IPIV(i) = 0, then row i is the pivot row and column i is the pivot column.

If IPIV(i) < 0, then row i and column i are interchanged, and IPIV(i) = -j means that the block pivot row is j.

WORK
COMPLEX*16 array, dimension (LWORK).

On exit, if INFO = 0, WORK(1) contains the optimal LWORK.

LWORK
INTEGER. On entry, LWORK is the dimension of the

array WORK.

INFO
INTEGER.

INFO is the exit status, and is the first entry in the array IPIV where a singularity is detected.

INFO = 0: successful exit.

INFO > 0: If INFO = k, then the factorization has been completed, but the block diagonal matrix D is exactly singular (a block of size NB), and division by zero will occur if D is used to solve a system of equations.

INFO < 0: If INFO = -k, the k-th argument had an invalid value.

Function/Subroutine Documentation

!> @brief Compute the block LU factorization of a complex general band
!>        matrix using partial pivoting with rook interchanges.
!>
!> This routine computes the block LU factorization of a general band matrix
!> A using the dynamic block size scheduling algorithm. It is a modified
!> version of the CLASYF routine.
!>
!> @param[in] UPLO Specifies whether the upper or lower triangular part of
!>                 the matrix A is stored.
!>                 UPLO = 'U' means upper triangular.
!>                 UPLO = 'L' means lower triangular.
!> @param[in] N The order of the matrix A.
!> @param[in] NB The block size to be used in the factorization.
!> @param[in] KB The number of super- or sub-diagonals in the band matrix A.
!> @param[in,out] AB The band matrix A, dimension (LDAB, N). On exit, AB
!>                   is overwritten by details of the factorization.
!> @param[in] LDAB The leading dimension of the array AB.
!> @param[out] IPIV Details of the row and column interchanges, and of the
!>                  block factorization. Dimension (N).
!>                  IPIV(i) > 0 indicates that rows and columns i and IPIV(i)
!>                  are interchanged.
!>                  IPIV(i) = 0 indicates that row i is the pivot row and
!>                  column i is the pivot column.
!>                  IPIV(i) < 0 indicates that row i and column i are
!>                  interchanged, and IPIV(i) = -j means that the block pivot
!>                  row is j.
!> @param[out] WORK Workspace array, dimension (LWORK). On exit, WORK(1)
!>                  contains the optimal LWORK.
!> @param[in] LWORK The dimension of the array WORK.
!> @param[out] INFO Information criterion:
!>                  INFO = 0: successful exit.
!>                  INFO > 0: the block diagonal matrix D is exactly singular.
!>                  INFO < 0: illegal value for the i-th argument.
!>
!> The factorization is performed as follows:
!>   A = P * D * U, if UPLO = 'U',
!>   A = P * D * L, if UPLO = 'L',
!> where P is a permutation matrix, D is a block diagonal matrix and U or L
!> is a unit upper or lower triangular band matrix, respectively.
!>
!> The block LU factorization is computed using partial pivoting with rook
!> interchanges. The block size NB is chosen dynamically by the routine.
!>
!> The routine completes the factorization even if the block diagonal matrix D
!> is singular. In case of singularity, INFO is set to the index of the first
!> block column that is singular. Division by zero will occur if the singular
!> block is used to solve a system of equations.
!>
!> NOTE: INFO only stores the first occurrence of a singularity, any subsequent
!>       occurrence of singularity is not stored in INFO even though the
!>       factorization always completes.
!>
