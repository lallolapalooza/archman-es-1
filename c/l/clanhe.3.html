función real clanhe (norm, uplo, n, a, lda, work)
CLANHE devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermitiana compleja.

Documentación de la función/subrutina

función real clanhe (caracter norm, caracter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, real, dimensión( * ) work)

CLANHE devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermitiana compleja.

Propósito:

!>
!> CLANHE  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma de infinito,  o el  elemento de  mayor valor absoluto de una
!> matriz hermitiana A.
!>

Devuelve

CLANHE 
!>
!>    CLANHE = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la
!> suma de cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma
!> de matriz consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en CLANHE como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se referenciará la parte triangular superior o
!>          inferior de la matriz hermitiana A.
!>          = 'U':  Se referencia la parte triangular superior de A
!>          = 'L':  Se referencia la parte triangular inferior de A
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANHE se
!>          establece a cero.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          La matriz hermitiana A.  Si UPLO = 'U', la parte triangular
!>          superior principal de n por n de A contiene la parte triangular
!>          superior de la matriz A, y la parte triangular inferior estricta
!>          de A no se referencia. Si UPLO = 'L', la parte triangular
!>          inferior principal de n por n de A contiene la parte triangular
!>          inferior de la matriz A, y la parte triangular superior estricta
!>          de A no se referencia. Tenga en cuenta que las partes imaginarias
!>          de los elementos diagonales no es necesario que se establezcan y
!>          se asumen que son cero.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo contrario,
!>          WORK no se referencia.
!>
