Clone(3pm)

Paquete: perl-clone

Licencias: GPL, PerlArtistic

Clone(3) Documentación contribuida por el usuario de Perl Clone(3)

NOMBRE

Clone - copia recursivamente tipos de datos de Perl

SINOPSIS

use Clone 'clone';
my $data = {
   set => [ 1 .. 50 ],
   foo => {
       answer => 42,
       object => SomeObject->new,
   },
};
my $cloned_data = clone($data);
$cloned_data->{foo}{answer} = 1;
print $cloned_data->{foo}{answer};  # '1'
print $data->{foo}{answer};         # '42'

También puedes añadirlo a tu clase:

package Foo;
use parent 'Clone';
sub new { bless {}, shift }
package main;
my $obj = Foo->new;
my $copy = $obj->clone;

DESCRIPCIÓN

Este módulo proporciona un método clone() que crea copias recursivas de hashes anidados, arrays, escalares y tipos de referencia, incluyendo variables enlazadas (tied) y objetos.

clone() toma un argumento escalar y lo duplica. Para duplicar listas, arrays o hashes, pásalos por referencia, ejemplo:

my $copy = clone (\@array);
# o
my %copy = %{ clone (\%hash) };

VER TAMBIÉN

El método dclone() de Storable es una solución flexible para clonar variables, aunque más lento para estructuras de datos de tamaño medio. Benchmarks simples y directos muestran que Clone es más rápido para estructuras de datos con 3 o menos niveles, mientras que dclone() puede ser más rápido para estructuras de 4 niveles o más.
