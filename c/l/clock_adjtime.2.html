adjtimex(2) Manual de Llamadas al Sistema adjtimex(2)

NOMBRE

adjtimex, clock_adjtime, ntp_adjtime - ajustar el reloj del kernel

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/timex.h>
int adjtimex(struct timex *buf);
int clock_adjtime(clockid_t clk_id, struct timex *buf);
int ntp_adjtime(struct timex *buf);

DESCRIPCIÓN

Linux utiliza el algoritmo de ajuste de reloj de David L. Mills (ver RFC 5905). La llamada al sistema adjtimex() lee y opcionalmente establece parámetros de ajuste para este algoritmo. Toma un puntero a una estructura timex, actualiza los parámetros del kernel desde los valores de los campos (seleccionados) y devuelve la misma estructura actualizada con los valores actuales del kernel. Esta estructura se declara como sigue:


struct timex {
    int  modes;      /* Selector de modo */
    long offset;     /* Desplazamiento de tiempo; nanosegundos, si la
                        bandera de estado STA_NANO está activada, de lo
                        contrario microsegundos */
    long freq;       /* Desplazamiento de frecuencia; ver NOTAS para
                        las unidades */
    long maxerror;   /* Error máximo (microsegundos) */
    long esterror;   /* Error estimado (microsegundos) */
    int  status;     /* Comando/estado del reloj */
    long constant;   /* Constante de tiempo de bucle
                        sincronizado en fase (PLL) */
    long precision;  /* Precisión del reloj
                        (microsegundos, solo lectura) */
    long tolerance;  /* Tolerancia de frecuencia del reloj (solo lectura);
                        ver NOTAS para las unidades */
    struct timeval time;
                     /* Tiempo actual (solo lectura, excepto para
                        ADJ_SETOFFSET); al regresar, time.tv_usec
                        contiene nanosegundos, de lo contrario
                        microsegundos */
    long tick;       /* Microsegundos entre ticks del reloj */
    long ppsfreq;    /* Frecuencia PPS (pulso por segundo)
                        (solo lectura); ver NOTAS para las unidades */
    long jitter;     /* Jitter PPS (solo lectura); nanosegundos, si la
                        bandera de estado STA_NANO está activada, de lo
                        contrario microsegundos */
    int  shift;      /* Duración del intervalo PPS
                        (segundos, solo lectura) */
    long stabil;     /* Estabilidad PPS (solo lectura);
                        ver NOTAS para las unidades */
    long jitcnt;     /* Contador de eventos de exceso del límite de
                        jitter PPS (solo lectura) */
    long calcnt;     /* Contador de intervalos de calibración PPS
                        (solo lectura) */
    long errcnt;     /* Contador de errores de calibración PPS
                        (solo lectura) */
    long stbcnt;     /* Contador de eventos de exceso del límite de
                        estabilidad PPS (solo lectura) */
    int  tai;        /* Desplazamiento TAI, establecido por una
                        operación ADJ_TAI anterior (segundos, solo
                        lectura, desde Linux 2.6.26) */
    /* Bytes de relleno adicionales para permitir futuras expansiones */
};

El campo modes determina qué parámetros, si los hay, se establecen. (Como se describe más adelante en esta página, las constantes utilizadas para ntp_adjtime() son equivalentes pero tienen nombres diferentes). Es una máscara de bits que contiene una combinación OR a nivel de bits de cero o más de los siguientes bits:

ADJ_OFFSET
Establece el desplazamiento de tiempo a partir de buf.offset. Desde Linux 2.6.26, el valor proporcionado se limita al rango (-0.5s, +0.5s). En kernels anteriores, ocurre un error EINVAL si el valor proporcionado está fuera de rango.
ADJ_FREQUENCY
Establece el desplazamiento de frecuencia a partir de buf.freq. Desde Linux 2.6.26, el valor proporcionado se limita al rango (-32768000, +32768000). En kernels anteriores, ocurre un error EINVAL si el valor proporcionado está fuera de rango.
ADJ_MAXERROR
Establece el error de tiempo máximo a partir de buf.maxerror.
ADJ_ESTERROR
Establece el error de tiempo estimado a partir de buf.esterror.
ADJ_STATUS
Establece bits de estado del reloj a partir de buf.status. Se proporciona una descripción de estos bits más abajo.
ADJ_TIMECONST
Establece la constante de tiempo del PLL a partir de buf.constant. Si la bandera de estado STA_NANO (ver más abajo) está desactivada, el kernel suma 4 a este valor.
ADJ_SETOFFSET (desde Linux 2.6.39)
Suma buf.time al tiempo actual. Si buf.status incluye la bandera ADJ_NANO, entonces buf.time.tv_usec se interpreta como un valor de nanosegundos; de lo contrario, se interpreta como microsegundos.
El valor de buf.time es la suma de sus dos campos, pero el campo buf.time.tv_usec siempre debe ser no negativo. El siguiente ejemplo muestra cómo normalizar un timeval con resolución de nanosegundos.

while (buf.time.tv_usec < 0) {
    buf.time.tv_sec  -= 1;
    buf.time.tv_usec += 1000000000;
}

ADJ_MICRO (desde Linux 2.6.26)
Selecciona resolución de microsegundos.
ADJ_NANO (desde Linux 2.6.26)
Selecciona resolución de nanosegundos. Solo se debe especificar una de ADJ_MICRO y ADJ_NANO.
ADJ_TAI (desde Linux 2.6.26)
Establece el desplazamiento TAI (Tiempo Internacional Atómico) a partir de buf.constant.
ADJ_TAI no debe usarse junto con ADJ_TIMECONST, ya que este último modo también utiliza el campo buf.constant.
Para una explicación completa de TAI y la diferencia entre TAI y UTC, ver BIPM
ADJ_TICK
Establece el valor del tick a partir de buf.tick.

Alternativamente, modes puede especificarse como uno de los siguientes valores (máscara multibit), en cuyo caso no se deben especificar otros bits en modes:

ADJ_OFFSET_SINGLESHOT
Forma antigua de adjtime(3): ajusta (gradualmente) el tiempo por el valor especificado en buf.offset, que especifica un ajuste en microsegundos.
ADJ_OFFSET_SS_READ (funcional desde Linux 2.6.28)
Devuelve (en buf.offset) la cantidad restante de tiempo a ajustar después de una operación anterior ADJ_OFFSET_SINGLESHOT. Esta característica se añadió en Linux 2.6.24, pero no funcionó correctamente hasta Linux 2.6.28.

Los usuarios ordinarios están limitados a un valor de 0 o ADJ_OFFSET_SS_READ para modes. Solo el superusuario puede establecer cualquier parámetro.

El campo buf.status es una máscara de bits que se utiliza para establecer y/o recuperar bits de estado asociados con la implementación NTP. Algunos bits en la máscara son legibles y escribibles, mientras que otros son de solo lectura.

STA_PLL (lectura/escritura)
Habilita actualizaciones del bucle sincronizado en fase (PLL) a través de ADJ_OFFSET.
STA_PPSFREQ (lectura/escritura)
Habilita la disciplina de frecuencia PPS (pulso por segundo).
STA_PPSTIME (lectura/escritura)
Habilita la disciplina de tiempo PPS.
STA_FLL (lectura/escritura)
Selecciona el modo de bucle sincronizado en frecuencia (FLL).
STA_INS (lectura/escritura)
Inserta un segundo intercalar después del último segundo del día UTC, extendiendo así el último minuto del día en un segundo. La inserción de segundos intercalares ocurrirá cada día, mientras esta bandera permanezca activada.
STA_DEL (lectura/escritura)
Elimina un segundo intercalar en el último segundo del día UTC. La eliminación de segundos intercalares ocurrirá cada día, mientras esta bandera permanezca activada.
STA_UNSYNC (lectura/escritura)
Reloj no sincronizado.

NOTA

S

En la estructura timex, freq, ppsfreq y stabil son ppm (partes por millón) con una parte fraccionaria de 16 bits, lo que significa que un valor de 1 en uno de esos campos realmente significa 2^-16 ppm, y 2^16=65536 es 1 ppm. Este es el caso tanto para los valores de entrada (en el caso de freq) como para los valores de

salida.

El procesamiento del segundo bisiesto desencadenado por STA_INS y STA_DEL lo realiza el núcleo en el contexto del temporizador. Por lo tanto, llevar

á un tick dentro del segundo para que
se inserte o elimine el segundo bisiesto.
