subrutina cla_syrfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, real, dimension( * ) c, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldy, * ) y, integer ldy, real, dimension( * ) berr_out, integer n_norms, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, complex, dimension( * ) res, real, dimension( * ) ayb, complex, dimension( * ) dy, complex, dimension( * ) y_tail, real rcond, integer ithresh, real rthresh, real dz_ub, logical ignore_cwise, integer info)

CLA_SYRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices simétricas indefinidas mediante la realización de refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> CLA_SYRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales mediante la realización de refinamiento iterativo
!> de precisión extra y proporciona límites de error y estimaciones de error
!> hacia atrás para la solución. Esta subrutina es llamada por CSYRFSX para
!> realizar refinamiento iterativo. Además del límite de error en norma,
!> el código proporciona el límite de error componente a componente máximo
!> si es posible. Vea los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP
!> para detalles de los límites de error. Note que esta subrutina solo es
!> responsable de establecer los segundos campos de ERR_BNDS_NORM y
!> ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a usar en el refinamiento.
!>     El valor está definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de miembros derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

AF

!>          AF es un arreglo COMPLEX, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores usados para
!>     obtener el factor U o L tal como fueron calculados por CSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura por bloques de D
!>     tal como fueron determinados por CSYTRF.
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó equilibrado de columnas a A antes de
!>     llamar a esta rutina. Esto es necesario para calcular la solución y los
!>     límites de error correctamente.
!>

C

!>          C es un arreglo REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no es accedido. Si C es de entrada, cada elemento de C debería ser una potencia
!>     de la base para asegurar una solución y estimaciones de error confiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos que
!>     el resultado desborde por arriba o por abajo. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     confiables.
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,NRHS)
!>     La matriz de miembros derechos B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

Y

!>          Y es un arreglo COMPLEX, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como fue calculada por CSYTRS.
!>     En la salida, la matriz solución Y mejorada.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del arreglo Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un arreglo REAL, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error hacia atrás relativo componente
!>     a componente para el miembro derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto es calculado por CLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (vea ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve límites de error en norma.
!>     Si N_NORMS >= 2 devuelve límites de error componente a componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un arreglo REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada miembro derecho, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que está definido de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El arreglo está indexado por el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     miembro derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi seguramente dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe ser confiado si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición recíproco normwise estimado.  Comparado con el umbral sqrt(n) * slamch('Epsilon') para determinar si la estimación del error es . Estos números de condición recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna matriz Z apropiadamente escalada.
              Sea Z = S*A, donde S escala cada fila por una potencia de la base para que todas las sumas absolutas de filas de Z sean aproximadamente 1.
              
     Esta subrutina solo es responsable de establecer el segundo campo anterior.
     Consulte la Nota de Trabajo 165 de Lapack para obtener más detalles y precauciones adicionales.
     



ERR_BNDS_COMP


              ERR_BNDS_COMP es un array REAL, de dimensión (NRHS, N_ERR_BNDS)
     Para cada mano derecha, este array contiene información sobre varios
     límites de error y números de condición correspondientes al error
     relativo componente a componente, que se define de la siguiente manera:
     
     Error relativo componente a componente en el i-ésimo vector solución:
                     abs(XTRUE(j,i) - X(j,i))
              max_j ----------------------
                          abs(X(j,i))
     
     El array está indexado por la mano derecha i (de la cual depende el error
     relativo componente a componente), y el tipo de información de error como se
     describe a continuación. Actualmente hay hasta tres piezas de
     información devueltas para cada mano derecha. Si no se solicita
     precisión componente a componente (PARAMS(3) = 0.0), entonces
     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo
     se devuelven las primeras (:,N_ERR_BNDS) entradas.
     
     El primer índice en ERR_BNDS_COMP(i,:) corresponde a la i-ésima
     mano derecha.
     
     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
     tres campos:
     err = 1 booleano. Confíe en la respuesta si el
              número de condición recíproco es menor que el umbral
              sqrt(n) * slamch('Epsilon').
     
     err = 2 límite de error: El error directo estimado,
              casi con toda seguridad dentro de un factor de 10 del error
              verdadero siempre que la siguiente entrada sea mayor que el umbral
              sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
              confiarse si el booleano anterior es verdadero.
     
     err = 3 Número de condición recíproco: Número de condición recíproco
              componente a componente estimado. Comparado con el umbral
              sqrt(n) * slamch('Epsilon') para determinar si la estimación del error
              es . Estos números de condición recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
              matriz Z apropiadamente escalada.
              Sea Z = S*(A*diag(x)), donde x es la solución para la
              mano derecha actual y S escala cada fila de
              A*diag(x) por una potencia de la base para que todas las sumas
              absolutas de filas de Z sean aproximadamente 1.
              
     Esta subrutina solo es responsable de establecer el segundo campo
     anterior.
     Consulte la Nota de Trabajo 165 de Lapack para obtener más detalles y precauciones adicionales.
     



RES


              RES es un array COMPLEX, de dimensión (N)
     Espacio de trabajo para contener el residuo intermedio.



AYB


              AYB es un array REAL, de dimensión (N)
     Espacio de trabajo.



DY


              DY es un array COMPLEX, de dimensión (N)
     Espacio de trabajo para contener la solución intermedia.



Y_TAIL


              Y_TAIL es un array COMPLEX, de dimensión (N)
     Espacio de trabajo para contener los bits finales de la solución intermedia.



RCOND


              RCOND es REAL
     Número de condición recíproco escalado. Esta es una estimación del
     número de condición de Skeel recíproco de la matriz A después de
     la   equilibración (si se realizó). Si esto es menor que la precisión
     de la máquina (en particular, si es cero), la matriz es singular
     para la precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño
     incluso si este número es muy pequeño y la matriz parece mal
     condicionada.



ITHRESH


              ITHRESH es INTEGER
     El número máximo de cómputos de residuo permitidos para el
     refinamiento. El valor predeterminado es 10. Para 'agresivo' establecer en 100 para
     permitir la convergencia utilizando factorizaciones aproximadas o
     factorizaciones distintas de LU. Si la factorización utiliza una
     técnica distinta de la eliminación gaussiana, las garantías en
     ERR_BNDS_NORM y ERR_BNDS_COMP pueden dejar de ser confiables.



RTHRESH


              RTHRESH es REAL
     Determina cuándo detener el refinamiento si la estimación del error deja de
     disminuir. El refinamiento se detendrá cuando la siguiente solución ya no
     satisfaga norm(dx_{i+1}) < RTHRESH * norm(dx_i) donde norm(Z) es
     la norma infinito de Z. RTHRESH satisface 0 < RTHRESH <= 1. El
     valor predeterminado es 0.5. Para 'agresivo' establecer en 0.9 para permitir
     la convergencia en matrices extremadamente mal condicionadas. Consulte LAWN 165
     para obtener más detalles.



DZ_UB


              DZ_UB es REAL
     Determina cuándo comenzar a considerar la convergencia componente a componente.
     La convergencia componente a componente solo se considera después de que cada componente
     de la solución Y sea estable, lo que definimos como el cambio relativo
     en cada componente sea menor que DZ_UB. El valor predeterminado
     es 0.25, que requiere que el primer bit sea estable. Consulte LAWN 165 para
     obtener más detalles.



IGNORE_CWISE


              IGNORE_CWISE es LOGICAL
     Si es .TRUE. entonces ignore la convergencia componente a componente. Valor predeterminado
     es .FALSE..



INFO


              INFO es INTEGER
       = 0: Salida exitosa.
       < 0: si INFO = -i, el i-ésimo argumento para CLA_SYRFSX_EXTENDED tuvo un valor ilegal
