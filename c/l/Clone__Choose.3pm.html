Clone::Choose(3) Documentación de Perl aportada por el usuario Clone::Choose(3)

NOMBRE

Clone::Choose - Elige la utilidad de clonación adecuada

SINOPSIS

use Clone::Choose;
my $data = {
    value => 42,
    href  => {
        set   => [ 'foo', 'bar' ],
        value => 'baz',
    },
};
my $cloned_data = clone $data;
# también es posible usar Clone::Choose y pasar una preferencia de clonación
use Clone::Choose qw(:Storable);

DESCRIPCIÓN

"Clone::Choose" comprueba varios módulos diferentes que proporcionan una función clone() y selecciona uno adecuado. La preferencia predeterminada es

Clone
Storable
Clone::PP

Esta lista puede evolucionar en el futuro. Consulte "EXPORTS" sobre cómo elegir uno en particular.

EXPORTS

"Clone::Choose" exporta clone() por defecto.

Se puede importar explícitamente "clone" usando

use Clone::Choose qw(clone);

o elegir una implementación de "clone" en particular

use Clone::Choose qw(:Storable clone);

La implementación exportada se resuelve dinámicamente, lo que significa que cualquier módulo que la use puede confiar en la preferencia de backend predeterminada o elegir una en particular.

También es posible seleccionar un backend de "clone" en particular estableciendo la variable de entorno CLONE_CHOOSE_PREFERRED_BACKEND a su backend preferido.

Esto también significa que una importación ya elegida no se puede modificar como

use Clone::Choose qw(clone :Storable);

Cuando realmente se necesitan diferentes implementaciones de clonación, nuestra forma *recomendada* de usarlas sería:

use Clone::Choose (); # no importar
my ($xs_clone, $st_clone);
{ local @Clone::Choose::BACKENDS = (Clone => "clone"); $xs_clone = Clone::Choose->can("clone"); }
{ local @Clone::Choose::BACKENDS = (Storable => "dclone"); $st_clone = Clone::Choose->can("clone"); }

No malinterprete *recomendado* - modificar @Clone::Choose::BACKENDS tiene muchos peligros y no es fiable más allá de ejemplos tan pequeños. No dude en abrir una solicitud con una propuesta adecuada para elegir implementaciones dinámicamente.

El uso de @Clone::Choose::BACKENDS está desaconsejado y será obsoleto tan pronto como alguien proporcione una idea mejor.

MÉTODOS DEL PAQUETE

backend

"backend" informa al llamador sobre el backend elegido dinámicamente:

use Clone::Choose;
say Clone::Choose->backend; # Clone

Este método actualmente existe solo para fines de depuración.

get_backends

"get_backends" devuelve una lista de los backends compatibles actualmente.
