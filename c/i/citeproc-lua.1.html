NOMBRE

citeproc-lua - genera citas y bibliografía CSL para LaTeX

SINOPSIS

citeproc-lua [<opciones>] nombreaux[.aux]

DESCRIPCIÓN

El motor citeproc es un procesador de Citation Style Language para LaTeX. Lee el archivo auxiliar (.aux) nombreaux y crea un archivo de bibliografía (.bbl)

OPCIONES

-h
Imprime el uso y sale.
-V
Imprime el número de versión y sale.
