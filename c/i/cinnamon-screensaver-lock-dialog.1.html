CINNAMON-SCREENSAVER-LOCK-DIALOG(1) Manual de cinnamon CINNAMON-SCREENSAVER-LOCK-DIALOG(1)

NOMBRE

cinnamon-screensaver-lock-dialog - mensaje de configuración para el salvapantallas de cinnamon

SINOPSIS

cinnamon-screensaver-lock-dialog

DESCRIPCIÓN

cinnamon-screensaver-lock-dialog ejecuta la interfaz gráfica para establecer un mensaje de ausencia al ejecutar cinnamon-screensaver.

NOTA

Este applet de diálogo solo funcionará si está instalado cinnamon-screensaver. Por lo tanto, el escritorio cinnamon llamará al diálogo solo si este último está efectivamente instalado.

AUTOR

cinnamon-screensaver-lock-dialog ha sido escrito por el proyecto Mint <root@linuxmint.com>.

Esta página del manual fue escrita por Nicolas Bourdaud <nicolas.bourdaud@gmail.com> para el proyecto Debian.
