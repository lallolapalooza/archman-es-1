CINNAMON(1) Manual de comandos generales CINNAMON(1)

NOMBRE

cinnamon - escritorio

SINOPSIS

cinnamon [opciones]

DESCRIPCIÓN

Cinnamon es un entorno de escritorio de Linux que proporciona características innovadoras avanzadas y una experiencia de usuario tradicional.

La disposición del escritorio es similar a Gnome 2. La tecnología subyacente es similar a la de Gnome Shell. El énfasis se pone en hacer que los usuarios se sientan como en casa y proporcionarles una experiencia de escritorio fácil de usar y cómoda.

OPCIONES

--replace
Reemplazar el gestor de ventanas en ejecución
--sm-disable
Desactivar la conexión con el gestor de sesiones
--sm-client-id=ID
Especificar el ID de gestión de sesiones
--sm-save-file=FILE
Inicializar la sesión desde el archivo guardado
--screen=SCREEN
Pantalla X a usar
-d, --display=DISPLAY
Pantalla X a usar
--sync
Hacer que las llamadas X sean síncronas
--version
Imprimir versión y salir
--help
Mostrar ayuda y salir

ERRORES

El rastreador de errores se puede encontrar visitando el sitio web https://github.com/linuxmint/Cinnamon/issues

Antes de enviar un informe de error, por favor, verifica que tienes la última versión de cinnamon. Muchos errores (mayores y menores) se corrigen en cada versión, y si la tuya está desactualizada, el problema ya puede haber sido resuelto.
