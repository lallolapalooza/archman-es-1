NOMBRE

cinnamon-session - Inicia el entorno de escritorio GNOME

SINOPSIS

cinnamon-session [-a|--autostart=DIR] [--session=SESSION] [--failsafe|-f] [--debug] [--whale]

DESCRIPCIÓN

El programa cinnamon-session inicia el entorno de escritorio GNOME. Este comando es típicamente ejecutado por tu gestor de inicio de sesión (ya sea mdm, xdm, o desde tus scripts de inicio de X). Cargará tu sesión guardada, o proporcionará una sesión por defecto para el usuario tal como la define el administrador del sistema (o la instalación por defecto de GNOME en tu sistema).

La sesión por defecto se define en gnome.session, un archivo similar a .desktop que se busca en $XDG_CONFIG_HOME/cinnamon-session/sessions, $XDG_CONFIG_DIRS/cinnamon-session/sessions y $XDG_DATA_DIRS/cinnamon-session/sessions.

Al guardar una sesión, cinnamon-session guarda las aplicaciones actualmente en ejecución en el directorio $XDG_CONFIG_HOME/cinnamon-session/saved-session.

cinnamon-session es un gestor de sesiones X11R6. Puede gestionar aplicaciones GNOME así como cualquier aplicación compatible con X11R6 SM.

OPCIONES

Se soportan las siguientes opciones:

--autostart=DIR
Inicia todas las aplicaciones definidas en DIR, en lugar de iniciar las aplicaciones definidas en gnome.session, o a través de la opción --session. Se pueden pasar múltiples opciones --autostart.
--session=SESSION
Utiliza las aplicaciones definidas en SESSION.session. Si no se especifica, se usará gnome.session.
--failsafe
Ejecuta en modo a prueba de fallos. Las aplicaciones especificadas por el usuario no se iniciarán.
--debug
Habilita el código de depuración.
--whale
Muestra la ballena de fallo en un diálogo para depurarla.

DEFINICIÓN DE SESIÓN

Las sesiones se definen en archivos .session, que utilizan un formato similar a .desktop, con las siguientes claves en el grupo GNOME Session:

Name
Nombre de la sesión. Esto puede ser localizado.
RequiredComponents
Lista de identificadores de componentes (archivos .desktop) que son requeridos por la sesión. Los componentes requeridos siempre se ejecutarán en la sesión.
RequiredProviders
Lista de proveedores de tareas que son requeridos por la sesión. Un proveedor por defecto para cada tarea debe definirse con una clave DefaultProvider-TASK; el proveedor puede ser reemplazado por componentes requeridos, la sesión guardada o aplicaciones de inicio automático. Los proveedores de tareas siempre se ejecutarán en la sesión.
DefaultProvider-TASK
Identificador (archivo .desktop) del proveedor por defecto para TASK. Si no se encuentra ningún proveedor para TASK en los componentes requeridos, la sesión guardada y en las aplicaciones de inicio automático, se iniciará el proveedor por defecto.

Aquí tienes un ejemplo de definición de sesión:


[GNOME Session]
Name=GNOME fallback
RequiredComponents=gnome-panel;metacity;gnome-settings-daemon;
RequiredProviders=notifications;
DefaultProvider-notifications=notification-daemon

Los archivos .session se buscan en $XDG_CONFIG_HOME/cinnamon-session/sessions, $XDG_CONFIG_DIRS/cinnamon-session/sessions y $XDG_DATA_DIRS/cinnamon-session/sessions.

ENTORNO

cinnamon-session establece varias variables de entorno para el uso de sus procesos hijos:

SESSION_MANAGER

Esta variable es utilizada por los clientes conscientes del gestor de sesiones para contactar con cinnamon-session.

DISPLAY

Esta variable se establece al X display que está siendo utilizado por cinnamon-session. Ten en cuenta que si se utiliza la opción --display, esto podría ser diferente de la configuración de la variable de entorno cuando se invoca cinnamon-session.

ARCHIVOS

$XDG_CONFIG_HOME/config/autostart $XDG_CONFIG_DIRS/config/autostart /usr/share/gnome/autostart

Las aplicaciones definidas en estos directorios se iniciarán al iniciar sesión. cinnamon-settings(1) puede ser utilizado para configurarlas fácilmente.

$XDG_CONFIG_HOME/cinnamon-session/sessions $XDG_CONFIG_DIRS/cinnamon-session/sessions $XDG_DATA_DIRS/cinnamon-session/sessions

Estos directorios contienen los archivos .session que pueden ser utilizados con la opción --session.

$XDG_CONFIG_HOME/cinnamon-session/saved-session

Este directorio contiene la lista de aplicaciones de la sesión guardada.
