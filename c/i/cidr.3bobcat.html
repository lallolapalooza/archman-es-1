DESCRIPCIÓ

N

Los objetos de la clase Cidr pueden usarse para probar si las direcciones de Internet IP4 pertenecen a rangos de direcciones definidos por especificaciones de bloques de direcciones de Enrutamiento entre Dominios Sin Clase (CIDR). Los bloques CIDR se especifican como a.b.c.d/m donde a.b.c.d son los cuatro octetos de una especificación de dirección IP4 en notación decimal con puntos (p. ej., 129.125.14.80) y m es un tamaño de máscara (que va de 0 a 32) que define el número de bits más significativos que deben permanecer sin cambios. La especificación CIDR 129.125.14.80/16 define una red de clase B, con direcciones que van desde 129.125.0.0 hasta 129.125.255.

255.

El tamaño de la máscara no tiene que ser múltiplo de 8. Por ejemplo, al especificar 129.125.14.80/5 solo se fijan los 5 bits más significativos del primer octeto, lo que resulta en un rango de direcciones que va desde 128.0.0.0 hasta 135.255.255.

255.

Las especificaciones CIDR pasadas a un objeto Cidr deben tener la forma a.b.c.d o a.b.c.d/m. Si no se especifica la máscara, se usa un tamaño de máscara de 32, definiendo efectivamente un rango de direcciones de una sola dirección. Los valores de máscara de 0 se ignoran. Los valores de máscara de 0 se ignoran por los objetos

Cidr.

Al especificar CIDRs en un flujo, se ignoran las líneas vacías y las líneas de comentario (que tienen un carácter de almohadilla (#) como primer carácter no en blanco). Las líneas no vacías deben comenzar con una especificación CIDR, y el objeto Cidr ignorará toda la información en

una línea que siga a un
a especificación CIDR.

EJEMPL

O 
#include <fstream>
#include <iostream>
#include <bobcat/exception>
#ifdef BOBCAT
    #include <bobcat/cidr>
#else
    #include "cidr"
#endif
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    enum Spec
    {
        NONE,
        FILE,
        CIN
    };
    Spec spec = CIN;
    ifstream in;
    if (argc > 1)
    {
        Exception::open(in, argv[1]);       // file containing cidr-specs
        spec = FILE;
    }
    while (true)
    {
        string cidrSpec;
        if (spec == CIN)
        {
            cout << "Specify cidr (empty to quit): ";
            if (!getline(cin, cidrSpec) || cidrSpec.empty())
                break;
        }
        try
        {
            Cidr cidr;
            switch (spec)
            {
                case NONE:
                return 0;
                case FILE:
                    cidr.setCidr(in);
                    spec = NONE;
                break;
                case CIN:
                    cidr.setCidr(cidrSpec);
            }
            while (true)
            {
                cout << "Specify address to test (empty to " <<
                    (spec == CIN ? "respec. CIDR" : "quit") << "): ";
                string address;
                if (!getline(cin, address) || address.empty())
                    break;
                if (!cidr.match(address))
                {
                    cout << "Address " << address << " not in ";
                    if (spec == CIN)
                        cout << cidrSpec << ’\n’;
                    else
                        cout << "specifications in " << argv[1] << ’\n’;
                }
                else
                    cout << "Address " << address << " in " << cidr.cidr() <<
                                                                        "\n&quot;
                        "Dirección más baja: " << cidr.first() << "\n"
                        "Dirección más alta: " << cidr.last() << "\n"
                        "Máscara CIDR: " << cidr.mask() << "\n"
                        "Dirección: " << cidr.address() << ’\n’;
            }
        }
        catch (exception const &err)
        {
            cout << "Vaya... " << err.what() << "\n"
                    "Inténtelo de nuevo...\n";
        }
    }
}
