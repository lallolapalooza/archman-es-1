NOMBRE

cinnamon-session-quit - Finaliza la sesión actual de GNOME

SINOPSIS

cinnamon-session-quit [--logout|--power-off|--reboot] [--force] [--no-prompt]

DESCRIPCIÓN

El programa cinnamon-session-quit se puede utilizar para finalizar una sesión de GNOME.

OPCIONES

Se soportan las siguientes opciones:

--logout
Pide al usuario que confirme el cierre de sesión. Este es el comportamiento predeterminado.
--power-off
Pide al usuario que confirme el apagado del sistema.
--reboot
Pide al usuario que confirme el reinicio del sistema.
--force
Ignora cualquier inhibidor.
--no-prompt
Finaliza la sesión sin interacción del usuario. Esto solo funciona con --logout.
