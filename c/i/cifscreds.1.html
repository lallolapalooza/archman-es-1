CIFSCREDS(1) Manual de comandos generales CIFSCREDS(1)

NOMBRE

cifscreds - administrar credenciales NTLM en el keyring del kernel

SINOPSIS

cifscreds add|clear|clearall|update [-u nombre_usuario] [-d] host|dominio [-t tiempo_espera]

DESCRIPCIÓN

El programa cifscreds es una herramienta para administrar credenciales (nombre de usuario y contraseña) con el fin de establecer sesiones en montajes multiusuario.

Cuando un sistema de archivos cifs se monta con la opción "multiuser" y no utiliza autenticación krb5, necesita poder obtener las credenciales para cada usuario desde algún lugar. El programa cifscreds es la herramienta utilizada para proporcionar estas credenciales al kernel.

El primer argumento que no es una opción para cifscreds es un comando (ver la sección COMANDOS más abajo). El segundo argumento que no es una opción es un nombre de host o dirección, o un nombre de dominio NT.

COMANDOS

add
Agrega credenciales al kernel para ser utilizadas para conectarse al servidor dado, o a los servidores en el dominio dado.
clear
Borra credenciales para un host o dominio específico del kernel.
clearall
Borra todas las credenciales cifs del kernel.
update
Actualiza las credenciales almacenadas en el kernel con un nuevo nombre de usuario y contraseña.

OPCIONES

-d, --domain
El argumento host/dominio proporcionado es un nombre de dominio NT.

Normalmente, el segundo argumento proporcionado a cifscreds se trata como un nombre de host o una dirección IP. Esta opción hace que el programa cifscreds trate ese argumento como un nombre de dominio NT en su lugar.

Si no hay credenciales específicas del host para el servidor montado, el kernel buscará un conjunto de credenciales de dominio equivalente a la opción domain= proporcionada en el momento del montaje.

-u, --username
Normalmente, el nombre de usuario se deriva del nombre de usuario de Unix del usuario que agrega las credenciales. Esta opción permite al usuario sustituir un nombre de usuario diferente.
-t, --timeout
Establece el tiempo de espera de la clave en segundos. Si no se establece, utilizará el tiempo de espera predeterminado del sistema para las claves de inicio de sesión.

NOTAS

La utilidad cifscreds requiere un kernel compilado con soporte para el tipo de clave login. Ese tipo de clave se agregó en la versión 3.3 en los kernels principales de Linux.

Dado que cifscreds agrega claves al keyring de sesión, se recomienda encarecidamente utilizar pam_keyinit para garantizar que se establezca un keyring de sesión al iniciar sesión.
