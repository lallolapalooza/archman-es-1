CIFSIOSTAT(1) Manual de Usuario de Linux CIFSIOSTAT(1)

NOMBRE

cifsiostat - Informar estadísticas de CIFS.

SINOPSIS

cifsiostat [ -h ] [ -k | -m ] [ -t ] [ -U ] [ -V ] [ -y ] [ --dec={ 0 | 1 | 2 } ] [ --human ] [ -o JSON ] [ --pretty ] [ intervalo [ conteo ] ]

DESCRIPCIÓN

El comando cifsiostat muestra estadísticas sobre las operaciones de lectura y escritura en sistemas de archivos CIFS.

El parámetro intervalo especifica la cantidad de tiempo en segundos entre cada informe. El primer informe contiene estadísticas del tiempo desde el arranque del sistema (boot), a menos que se use la opción -y (en cuyo caso, el primer informe se omite). Cada informe subsiguiente contiene estadísticas recopiladas durante el intervalo desde el informe anterior. Un informe consta de una fila de encabezado CIFS seguida de una línea de estadísticas para cada sistema de archivos CIFS que está montado. El parámetro conteo se puede especificar junto con el parámetro intervalo. Si se especifica el parámetro conteo, el valor de conteo determina el número de informes generados con una separación de intervalo segundos. Si se especifica el parámetro intervalo sin el parámetro conteo, el comando cifsiostat genera informes de forma continua.

INFORME

El informe CIFS proporciona estadísticas para cada sistema de archivos CIFS montado. El informe muestra los siguientes campos:

Sistema de archivos:
Esta columna muestra el punto de montaje del sistema de archivos CIFS.
rB/s (rkB/s, rMB/s)
Indica el número promedio de bytes (kibibytes, mebibytes) leídos por segundo.
wB/s (wkB/s, wMB/s)
Indica el número promedio de bytes (kibibytes, mebibytes) escritos por segundo.
rop/s
Indica el número de operaciones de 'lectura' que se emitieron al sistema de archivos por segundo.
wop/s
Indica el número de operaciones de 'escritura' que se emitieron al sistema de archivos por segundo.
fo/s
Indica el número de archivos abiertos por segundo.
fc/s
Indica el número de archivos cerrados por segundo.
fd/s
Indica el número de archivos eliminados por segundo.

OPCIONES

--dec={ 0 | 1 | 2
Especifica el número de decimales a utilizar (de 0 a 2, el valor predeterminado es 2).
-h
Esta opción es equivalente a especificar --human --pretty.
--human
Imprime los tamaños en formato legible por humanos (por ejemplo, 1.0k, 1.2M, etc.) Las unidades que se muestran con esta opción reemplazan cualquier otra unidad predeterminada (por ejemplo, kibibytes, sectores...) asociada a las métricas.
-k
Muestra estadísticas en kibibytes por segundo.
-m
Muestra estadísticas en mebibytes por segundo.
-o JSON
Muestra las estadísticas en formato JSON (JavaScript Object Notation). El orden de los campos de salida JSON no está definido y es posible que se agreguen nuevos campos en el futuro.
--pretty
Hace que el informe CIFS sea más fácil de leer para un humano.
-t
Imprime la hora de cada informe mostrado. El formato de la marca de tiempo puede depender del valor de la variable de entorno S_TIME_FORMAT (ver más abajo) y de si se ha utilizado la opción -U.
-U
Muestra la marca de tiempo (UTC - Tiempo Universal Coordinado) en segundos desde la época.
-V
Imprime el número de versión y luego sale.
-y
Omite el primer informe con estadísticas desde el arranque del sistema, si se muestran varios registros con el intervalo dado.

AMBIENTE

El comando cifsiostat tiene en cuenta las siguientes variables de entorno:

S_COLORS
Por defecto, las estadísticas se muestran en color cuando la salida está conectada a una terminal. Usa esta variable para cambiar la configuración. Los valores posibles para esta variable son never, always o auto (este último es equivalente a la configuración predeterminada).
Ten en cuenta que el color (ya sea rojo, amarillo o algún otro color) utilizado para mostrar un valor no indica ningún tipo de problema simplemente por el color. Solo indica diferentes rangos de valores.
S_COLORS_SGR
Especifica los colores y otros atributos utilizados para mostrar estadísticas en la terminal. Su valor es una lista separada por dos puntos de capacidades que por defecto es I=32;22:N=34;1:Z=34;22. Las capacidades admitidas son:
I=
Subcadena SGR para nombres de sistemas de archivos.
N=
Subcadena SGR para valores de estadísticas distintos de cero.
Z=
Subcadena SGR para valores cero.
S_TIME_FORMAT
Si esta variable existe y su valor es ISO, entonces la configuración regional actual se ignorará al imprimir la fecha en el encabezado del informe. El comando cifsiostat utilizará el formato ISO 8601 (AAAA-MM-DD) en su lugar. La marca de tiempo mostrada con la opción -t también cumplirá con el formato ISO 8601.

BUG

El sistema de archivos /proc debe estar montado para que cifsiostat funcione.

Aunque cifsiostat muestra unidades que corresponden a kilobytes (kB), megabytes (MB)..., en realidad utiliza kibibytes (kiB), mebibytes (MiB)... Un kibibyte es igual a 1024 bytes y un mebibyte es igual a 1024 kibibytes.

ARCHIVO

/proc/fs/cifs/Stats contiene estadísticas de CIFS.
