CIFS.IDMAP(8) Manual del Administrador del Sistema CIFS.IDMAP(8)

NOMBRE

cifs.idmap - Ayudante de espacio de usuario para mapear IDs para Common Internet File System (CIFS)

SINOPSIS

cifs.idmap [--ayuda|-h] [--tiempo-espera|-t] [--version|-v] {id_clave}

DESCRIPCIÓN

Esta herramienta forma parte del conjunto cifs-utils.

cifs.idmap es un programa auxiliar de espacio de usuario para el sistema de archivos cliente CIFS de Linux. Hay una serie de actividades que el kernel no puede realizar fácilmente por sí mismo. Este programa es un programa de llamada que realiza estas tareas para el kernel y luego devuelve el resultado.

cifs.idmap generalmente está destinado a ejecutarse cuando el kernel llama a request-key(8) para un tipo de clave particular. Aunque se puede ejecutar directamente desde la línea de comandos, generalmente no está diseñado para ejecutarse de esa manera.

Este programa solo se llama si se monta un recurso compartido con la opción de montaje cifsacl. El kernel solo realizará una llamada ascendente para realizar esta conversión si se especifica esa opción de montaje.

cifs.idmap depende de un plugin para manejar el mapeo de IDs. Si no puede encontrar el plugin, no funcionará correctamente. El plugin (o un enlace simbólico a él) debe estar en /etc/cifs-utils/idmap-plugin.

En caso de que cifs.idmap o el plugin no estén disponibles, los objetos de archivo en un recurso compartido montado se les asignarán uid y gid de las credenciales del proceso que montó el recurso compartido. Se recomienda encarecidamente utilizar las opciones de montaje uid y gid para especificar un uid y gid predeterminados para mapear SIDs de propietario y SIDs de grupo en esta situación.

OPCIONES

--ayuda|-h
Imprime el mensaje de uso y sale.
--tiempo-espera|-t
Establece el temporizador de expiración, en segundos, de la clave. El valor predeterminado es 600 segundos (10 minutos). Establecer esto en 0 hará que la clave nunca expire.
--version|-v
Imprime el número de versión y sale.

CONFIGURACIÓN PARA KEYCTL

cifs.idmap está diseñado para ser llamado desde el kernel a través del programa de llamada request-key. Esto requiere que request-key sepa dónde y cómo llamar a este programa. Actualmente cifs.idmap maneja un tipo de clave de:

cifs.idmap

Este tipo de clave es para mapear un SID a un uid o un gid.

Para que este programa sea útil para CIFS, deberá configurar una entrada para él en request-key.conf(5). Aquí hay un ejemplo de una entrada para este tipo de clave:

#OPERACIÓN  TIPO           D C PROGRAMA ARG1 ARG2...
#=========  =============  = = ================================
create      cifs.idmap     * * /usr/bin/cifs.idmap %k

Consulte request-key.conf(5) para obtener más información sobre cada campo.

NOTAS

El soporte para llamadas ascendentes a cifs.idmap se introdujo inicialmente en el kernel 3.0.

VER TAMBIÉN

request-key.conf(5), mount.cifs(8)
