DESCRIPCIÓ

N

Estas macros definen y operan sobre colas circulares doblemente

enlazadas.

En las definiciones de las macros, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo CIRCLEQ_ENTRY, llamado NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe ser declarada usando la macro CIRCLEQ_HE

AD().

Creació

n

Una cola circular está encabezada por una estructura definida por la macro CIRCLEQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están doblemente enlazados de modo que un elemento arbitrario puede ser eliminado sin recorrer la cola. Nuevos elementos pueden ser añadidos a la cola después de un elemento existente, antes de un elemento existente, en la cabeza de la cola, o en el final de la cola. Una estructura CIRCLEQ_HEAD se declara como

sigue: 


CIRCLEQ_HEAD(HEADNAME, TYPE)
head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos a enlazar en la cola. Un puntero a la cabeza de la cola puede ser declarado más tarde

como: 


struct HEADNAME
*headp;

(Los nombres head y headp son seleccionables por el usuario.

)

CIRCLEQ_ENTRY() declara una estructura que conecta los elementos en la

cola.

CIRCLEQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola head

.

CIRCLEQ_INIT() inicializa la cola referenciada por head

.

CIRCLEQ_EMPTY() evalúa a verdadero

si no hay element
os en la cola.

Inserció

n

CIRCLEQ_INSERT_HEAD() inserta el nuevo elemento elm en la cabeza de la

cola.

CIRCLEQ_INSERT_TAIL() inserta el nuevo elemento elm en el final de la

cola.

CIRCLEQ_INSERT_BEFORE() inserta el nuevo elemento elm antes del elemento listelm

.

CIRCLEQ_INSERT_AFTER() inserta el nuevo elemento elm después del elemento list

el
m.

Recorrid

o

CIRCLEQ_FIRST() devuelve el primer elemento de la

cola.

CIRCLEQ_LAST() devuelve el último elemento de la

cola.

CIRCLEQ_PREV() devuelve el elemento anterior de la cola, o &head si este elemento es el

primero.

CIRCLEQ_NEXT() devuelve el siguiente elemento de la cola, o &head si este elemento es el

último.

CIRCLEQ_LOOP_PREV() devuelve el elemento anterior de la cola. Si elm es el primer elemento de la cola, se devuelve el último

elemento.

CIRCLEQ_LOOP_NEXT() devuelve el siguiente elemento de la cola. Si elm es el último elemento de la cola, se devuelve el primer

elemento.

CIRCLEQ_FOREACH() recorre la cola referenciada por head en la dirección hacia adelante, asignando cada elemento por turno a var. var se establece a &head si el bucle se completa normalmente, o si no había

elementos.

CIRCLEQ_FOREACH_REVERSE() recorre la cola referenciada por head en la dirección inversa, asignando cada elemento por turno a va

r
.

Eliminació

n

CIRCLEQ_REMOVE() elimina el elemento elm de l

a
c
ola.

VALOR DE

RETORNO

CIRCLEQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una

entrada.

CIRCLEQ_FIRST(), CIRCLEQ_LAST(), CIRCLEQ_LOOP_PREV(), y CIRCLEQ_LOOP_NEXT() devuelven un puntero al primer, último, anterior o siguiente TYPE estructura, respectivamente

.

CIRCLEQ_PREV(), y CIRCLEQ_NEXT() son similares a sus contrapartes CIRCLEQ_LOOP_*(), excepto que si el argumento es el primer o último elemento, respectivamente, devuelven &head

.

CIRCLEQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola he

ad
.

ERRORE

S

CIRCLEQ_FOREACH() y CIRCLEQ_FOREACH_REVERSE() no permiten que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. CIRCLEQ_FOREACH_SAFE() y CIRCLEQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no están presentes en glibc, corrigen esta limitación al permitir que var sea eliminado de la lista y liberado de forma segura d

esde dentro del bucle sin
interferir con el recorrido.

EJEMPLO

S 
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    CIRCLEQ_ENTRY(entry) entries;           /* Cola */
};
CIRCLEQ_HEAD(circlehead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct circlehead head;                 /* Cabeza de la cola */
    int i;
    CIRCLEQ_INIT(&head);                    /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar en la cabeza */
    CIRCLEQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar en la cola */
    CIRCLEQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    CIRCLEQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    CIRCLEQ_INSERT_BEFORE(&head, n2, n3, entries);
    CIRCLEQ_REMOVE(&head, n2, entries);     /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    CIRCLEQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido hacia atrás */
    CIRCLEQ_FOREACH_REVERSE(np, &head, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de la cola */
    n1 = CIRCLEQ_FIRST(&head);
    while (n1 != (void *)&head) {
        n2 = CIRCLEQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    CIRCLEQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
