ciptool(1) Administración de sistemas Linux ciptool(1)

Nombre

ciptool - Perfil de acceso común a ISDN Bluetooth (CIP)

SINÓPSIS

ciptool [OPCIONES] COMANDOS

DESCRIPCIÓN

ciptool(1) se utiliza para configurar, mantener e inspeccionar la configuración CIP del subsistema Bluetooth en el kernel de Linux.

OPCIONES

-i <hciX|BDADDR>
El comando se aplica al dispositivo hciX, que debe ser el nombre o la dirección de un dispositivo Bluetooth instalado.

Si no se especifica, el comando utilizará el primer dispositivo Bluetooth disponible.

-h, --help
Mostrar opciones de ayuda

COMANDOS

show
Mostrar información sobre los dispositivos conectados.
search
Buscar dispositivos Bluetooth y conectarse al primero que ofrezca soporte CIP.
connect <BDADDR> [PSM]
Conectar el dispositivo local al dispositivo Bluetooth remoto en el número PSM especificado. Si no se especifica ningún PSM, utilizará SDP para recuperarlo del dispositivo remoto.
release [BDADDR]
Liberar una conexión al dispositivo específico. Si no se proporciona BDADDR y solo hay un dispositivo conectado, este será liberado.
loopback <BDADDR> [PSM]
Crear una conexión al dispositivo remoto para pruebas de Bluetooth. Este comando no proporcionará un controlador CAPI, ya que es solo para probar el Protocolo de Transporte de Mensajes CAPI.
