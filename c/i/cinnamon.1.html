CINNAMON(1) Manual de Comandos Generales CINNAMON(1)

NOMBRE

cinnamon - escritorio

SINOPSIS

cinnamon [opciones]

DESCRIPCIÓN

Cinnamon es un entorno de escritorio para Linux que proporciona funciones innovadoras avanzadas y una experiencia de usuario tradicional.

El diseño del escritorio es similar a Gnome 2. La tecnología subyacente es similar a la de Gnome Shell. Se pone énfasis en hacer que los usuarios se sientan como en casa y proporcionarles una experiencia de escritorio fácil de usar y cómoda.

OPCIONES

--replace
Reemplazar el gestor de ventanas en ejecución
--sm-disable
Deshabilitar la conexión con el gestor de sesiones
--sm-client-id=ID
Especificar ID de gestión de sesiones
--sm-save-file=FILE
Inicializar sesión desde archivo de guardado
--screen=SCREEN
Pantalla X a usar
-d, --display=DISPLAY
Pantalla X a usar
--sync
Hacer que las llamadas X sean síncronas
--version
Imprimir versión y salir
--help
Mostrar ayuda y salir

ERRORES

El rastreador de errores se puede encontrar visitando el sitio web https://github.com/linuxmint/Cinnamon/issues

Antes de enviar un informe de error, verifica que tienes la última versión de cinnamon. Muchos errores (importantes y menores) se corrigen en cada lanzamiento, y si tu versión está desactualizada, el problema puede que ya haya sido resuelto.

Para más información, visita el sitio web https://projects.linuxmint.com/cinnamon/
