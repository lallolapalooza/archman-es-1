DESCRIPCIÓ

N

cinnamon-settings ejecuta la interfaz gráfica de usuario que permite configurar

Cinnamon.

También se puede utilizar para ejecutar la interfaz gráfica de usuario que permite configurar un módulo específico, añadir applets a un panel y gestionar xle

t
s.

MÓDUL

O

Especificar un módulo permite configurarlo directamente.
Los siguientes módulos están disponibles. Puede usar el nombre o el sinónimo.
Los módulos con * tienen una interfaz de configuración con pestañas. Cada pestaña se puede abrir directamente (vea la sección PESTAÑA más abajo).
Los módulos con ** necesitan permisos de root para abrir su interfaz de configuración. Por lo tanto, la única pestaña que siempre se abrirá es la

primera.

PANE

L

PANEL es el panel en el que el usuario quiere instalar algunos applets. El escritorio del usuario puede tener hasta cuatro paneles.
panel1 es el primer panel (panel por defecto).
panel2, panel3 y panel4 existen solo si el

usuario los h
a creado.

UUID e

INSTANCIA

Los applets, desklets, extensiones y temas son los xlets

.

Cada xlet tiene un UUID (Identificador Único Universal). La estructura de un UUID es nombre_del_xlet@author, excepto para los

temas.

Hay dos tipos de xlets: Sistema y

Spices.

Los xlets de sistema están en /usr/share/cinnamon/applets/, /usr/share/cinnamon/desklets/ y /usr/share/themes/; su UUID termina con '@cinnamon.org' excepto para los temas. No hay extensiones de

sistema.

Los Spices son xlets ofrecidos por desarrolladores al equipo de Cinnamon, que los evalúa y valida. La descripción completa de estos Spices se puede encontrar en https://cinnamon-spices.linuxmint.com/.
Los Spices instalados por el usuario están en ~/.local/share/cinnamon (para applets, desklets y extensiones) y en ~/.them

es.

El argumento INSTANCIA está reservado para los desarrolladores. Cuando un applet o desklet tiene múltiples

instancias, la interfaz de configuración de cada una de ellas se puede abrir directamente con este argum
ento INSTANCIA. Los usuarios no tienen ni la posibilidad ni la necesidad de conocer el valor de INSTANCIA.
