Documentación de la función/subrutina

subrutina cbdt01 (integer m, integer n, integer kd, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldq, * ) q, integer ldq, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldpt, * ) pt, integer ldpt, complex, dimension( * ) work, real, dimension( * ) rwork, real resid)

CBDT01

Propósito:

!>
!> CBDT01 reconstruye una matriz general A a partir de su forma bidiagonal
!>    A = Q * B * P**H
!> donde Q (m por min(m,n)) y P**H (min(m,n) por n) son matrices unitarias
!> y B es bidiagonal.
!>
!> La relación de prueba para verificar la reducción es
!>    RESID = norm(A - Q * B * P**H) / ( n * norm(A) * EPS )
!> donde EPS es la precisión de la máquina.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de las matrices A y Q.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y P**H.
!>

KD

!>          KD es ENTERO
!>          Si KD = 0, B es diagonal y el array E no se referencia.
!>          Si KD = 1, la reducción fue realizada por xGEBRD; B es
!>          bidiagonal superior si M >= N, y bidiagonal inferior si M < N.
!>          Si KD = -1, la reducción fue realizada por xGBBRD; B es
!>          siempre bidiagonal superior.
!>

A

!>          A es un array COMPLEX, dimension (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

Q

!>          Q es un array COMPLEX, dimension (LDQ,N)
!>          La matriz unitaria Q de m por min(m,n) en la reducción
!>          A = Q * B * P**H.
!>

LDQ

!>          LDQ es ENTERO
!>          La dimensión principal del array Q.  LDQ >= max(1,M).
!>

D

!>          D es un array REAL, dimension (min(M,N))
!>          Los elementos diagonales de la matriz bidiagonal B.
!>

E

!>          E es un array REAL, dimension (min(M,N)-1)
!>          Los elementos superdiagonales de la matriz bidiagonal B si
!>          m >= n, o los elementos subdiagonales de B si m < n.
!>

PT

!>          PT es un array COMPLEX, dimension (LDPT,N)
!>          La matriz unitaria P**H de min(m,n) por n en la reducción
!>          A = Q * B * P**H.
!>

LDPT

!>          LDPT es ENTERO
!>          La dimensión principal del array PT.
!>          LDPT >= max(1,min(M,N)).
!>

WORK

!>          WORK es un array COMPLEX, dimension (M+N)
!>

RWORK

!>          RWORK es un array REAL, dimension (M)
!>

RESID

!>          RESID es REAL
!>          La relación de prueba:
!>          norm(A - Q * B * P**H) / ( n * norm(A) * EPS )
!>
