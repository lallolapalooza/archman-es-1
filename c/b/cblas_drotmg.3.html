Description

The CBLAS routines perform a number of vector and matrix operations, which are defined analitically and implement high performance linear algebra algorithms.

This page describes the CBLAS routines for the Z domain (complex double precision) that solve triangular band, packed, or general matrix equations.

CBLAS_LAYOUT
Specifies whether the matrix is stored in row-major (CblasRowMajor) or column-major (CblasColMajor) order.
CBLAS_UPLO
Specifies whether the matrix A is an upper triangular (CblasUpper) or lower triangular (CblasLower) matrix.
CBLAS_TRANSPOSE
Specifies whether to apply the transpose (CblasTrans), conjugate transpose (CblasConjTrans), or the original matrix (CblasNoTrans) to A.
CBLAS_DIAG
Specifies whether the matrix A has unit diagonals (CblasUnit) or non-unit diagonals (CblasNonUnit).
CBLAS_SIDE
Specifies whether to solve A*X = alpha*B (CblasLeft) or X*A = alpha*B (CblasRight).
CBLAS_INT
Integer type.
