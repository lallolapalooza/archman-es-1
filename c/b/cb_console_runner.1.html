NOMBRE

cb_console_runner - El lanzador de programas de consola del IDE Code::Blocks

SINOPSIS

cb_console_runner argumentos

DESCRIPCIÓN

cb_console_runner es parte del IDE Code::Blocks. Se usa para lanzar programas de consola y esperar a que terminen. Cuando el programa de consola finaliza, cb_console_runner muestra "Presiona ENTER para continuar".

Ese es su único propósito.

OPCIONES

Ninguna opción.

EJEMPLOS

cb_console_runner /home/usuario/programa_prueba --prog_arg1
