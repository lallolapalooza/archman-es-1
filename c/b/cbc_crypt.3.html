des_crypt(3) Manual de funciones de biblioteca des_crypt(3)

NOMBRE

des_crypt, ecb_crypt, cbc_crypt, des_setparity, DES_FAILED - cifrado DES rápido

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <rpc/des_crypt.h>
[[deprecated]] int ecb_crypt(unsigned int datalen;
                             char *key, char data[datalen],
                             unsigned int datalen, unsigned int mode);
[[deprecated]] int cbc_crypt(unsigned int datalen;
                             char *key, char data[datalen],
                             unsigned int datalen, unsigned int mode,
                             char *ivec);
[[deprecated]] void des_setparity(char *key);
[[deprecated]] int DES_FAILED(int status);

DESCRIPCIÓN

ecb_crypt() y cbc_crypt() implementan el NBS DES (Data Encryption Standard). Estas rutinas son más rápidas y de propósito más general que crypt(3). También pueden utilizar hardware DES si está disponible. ecb_crypt() cifra en modo ECB (Electronic Code Book), que cifra bloques de datos de forma independiente. cbc_crypt() cifra en modo CBC (Cipher Block Chaining), que encadena bloques sucesivos. El modo CBC protege contra inserciones, eliminaciones y sustituciones de bloques. Además, las regularidades en el texto plano no aparecerán en el texto cifrado.

Así es como se utilizan estas rutinas. El primer argumento, key, es la clave de cifrado de 8 bytes con paridad. Para establecer la paridad de la clave, que para DES está en el bit bajo de cada byte, utilice des_setparity(). El segundo argumento, data, contiene los datos a cifrar o descifrar. El tercer argumento, datalen, es la longitud en bytes de data, que debe ser un múltiplo de 8. El cuarto argumento, mode, se forma ORando juntas algunas cosas. Para la dirección de cifrado, OR con DES_ENCRYPT o DES_DECRYPT. Para cifrado por software o hardware, OR con DES_HW o DES_SW. Si se especifica DES_HW y no hay hardware, el cifrado se realiza por software y la rutina devuelve DESERR_NOHWDEVICE. Para cbc_crypt(), el argumento ivec es el vector de inicialización de 8 bytes para el encadenamiento. Se actualiza al siguiente vector de inicialización al regresar.

VALOR DE RETORNO

DESERR_NONE
Sin error.
DESERR_NOHWDEVICE
El cifrado tuvo éxito, pero se realizó por software en lugar del hardware solicitado.
DESERR_HWERROR
Ocurrió un error en el hardware o en el controlador.
DESERR_BADPARAM
Parámetro incorrecto para la rutina.

Dado un estado de resultado stat, la macro DES_FAILED(stat) es falsa solo para los dos primeros estados.

Interfaz Atributo Valor

ESTÁNDARES

Ninguno.

HISTORIA

4.3BSD. glibc 2.1. Eliminado en glibc 2.28.

Debido a que emplean el cifrado por bloques DES, que ya no se considera seguro, estas funciones fueron eliminadas. Las aplicaciones deberían cambiar a una biblioteca de criptografía moderna, como libgcrypt.
