DESCRIPCIÓN

Este archivo de cabecera, cblas_64.h, define las funciones de la interfaz BLAS de nivel 1, 2 y 3 de CBLAS (Basic Linear Algebra Subprograms) utilizando enteros de 64 bits para todos los argumentos de tamaño e índice. Esto se hace para admitir arrays de más de 2^31 elementos, que es el límite para los enteros de 32 bits.

El objetivo de estas rutinas es proporcionar una interfaz estándar y portátil a implementaciones de BLAS optimizadas para hardware específico.

Las funciones cubren una amplia gama de operaciones lineales algebraicas, incluyendo:

  • Operaciones de vector a escalar (p. ej., producto escalar, norma, suma absoluta).
  • Operaciones de vector a vector (p. ej., intercambio, copia, suma, escalado, rotación).
  • Operaciones de matriz a vector (p. ej., multiplicación de matriz por vector, multiplicación de matriz por vector dispersa, resolución de sistemas triangulares).
  • Operaciones de matriz a matriz (p. ej., multiplicación de matriz por matriz, multiplicación de matriz simétrica por vector, operaciones de rango 1 y 2, resolución de sistemas triangulares).

Cada función está prefijada con un carácter que indica el tipo de dato que maneja:

s
simple precisión (float)
d
doble precisión (double)
c
precisión simple compleja (struct complex float)
z
doble precisión compleja (struct complex double)

El sufijo '_64' indica el uso de enteros de 64 bits para índices y tamaños.

Los argumentos comunes de estas funciones incluyen:

layout
Especifica el orden de almacenamiento de la matriz (C o Fortran). Generalmente es CblasRowMajor o CblasColMajor.
TransA, TransB
Especifican si las matrices A y B deben ser transpuestas, conjugadas transpuestas o sin transponer. Las opciones típicas son CblasNoTrans, CblasTrans, CblasConjTrans.
Uplo
Indica si se utiliza la parte superior o inferior de una matriz simétrica o triangular. Las opciones son CblasUpper y CblasLower.
Diag
Indica si una matriz triangular es unitaria (diagonal es 1). Las opciones son CblasUnit y CblasNonUnit.
Side
Indica si las operaciones de matriz simétrica o hermitiana se aplican en el lado izquierdo o derecho. Las opciones son CblasLeft y CblasRight.
N, M, K
Dimensiones de las matrices y vectores involucrados en la operación.
alpha, beta
Escalares utilizados en las operaciones. Para tipos complejos, alpha y beta suelen ser punteros a los valores escalares.
A, B, C
Punteros a las matrices de entrada y salida.
X, Y
Punteros a los vectores de entrada y salida.
incX, incY
Factores de incremento para los elementos de los vectores X e Y.
lda, ldb, ldc
Número de filas (o columnas, dependiendo del layout) de la matriz en memoria. Se utiliza para calcular las direcciones de las columnas (o filas).

Las funciones de la familia _sub son usadas para calcular el producto escalar de dos vectores complejos.

Las funciones de la familia _dot son para productos escalares de vectores de precisión simple (sdot, dsdot) y doble precisión (ddot), así como para el producto escalar no conjugado (cdotu, zdotu) y conjugado (cdotc, zdotc) de vectores complejos.

Las funciones de la familia _nrm2 calculan la norma euclidiana de un vector, mientras que las funciones _asum calculan la suma de los valores absolutos de los elementos de un vector.

Las funciones _iamax, _damax, _icamax e _izamax devuelven el índice del elemento con la magnitud máxima en un vector.

Las funciones de rotación como _rotg y _rotmg generan los parámetros para una rotación de Givens, y _rot y _rotm aplican estas rotaciones a vectores.
