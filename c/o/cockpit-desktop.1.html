NOMBRE

cockpit-desktop - Integración de Cockpit Desktop

SINOPSIS

cockpit-desktop {URLPATH} [SSH_HOST]

DESCRIPCIÓN

El programa cockpit-desktop proporciona acceso seguro a las páginas de Cockpit en una sesión de escritorio ya en ejecución. Inicia un servidor web (cockpit-ws) y un navegador web en un espacio de nombres de red aislado, y un cockpit-bridge(8) en la sesión de usuario en ejecución.

Esto evita tener que iniciar sesión en Cockpit y tener que habilitar cockpit.socket a nivel de sistema. El aislamiento de red garantiza que ningún otro usuario, ni siquiera otros procesos en la sesión del usuario, puedan acceder a este servidor web local.

URLPATH es la página de Cockpit a abrir, es decir, el componente de ruta de las URLs de Cockpit. Se recomienda encarecidamente abrir solo un marco de página específico[1], no toda la navegación y el menú de Cockpit. Por ejemplo, la ruta /cockpit/@localhost/storage/index.html abrirá la página Almacenamiento. También es posible dar formas abreviadas de las urls, como "storage" o "network/firewall".

SSH_HOST es una especificación opcional de host remoto SSH (nombre de host o nombre de usuario@nombre de host). Si se proporciona, cockpit-bridge se iniciará en el host remoto a través de ssh(1) en su lugar, es decir, el navegador web de Cockpit mostrará ese host remoto. Tenga en cuenta que esta es más una característica experimental/de demostración.

AMBIENTE

La variable de entorno BROWSER especifica el comando del navegador (y posiblemente opciones) que se utilizará para abrir la página de Cockpit solicitada. Si no está configurado, cockpit-desktop intenta utilizar un navegador WebKit minimalista interno y, si falla, intentará detectar algunas alternativas razonables.
