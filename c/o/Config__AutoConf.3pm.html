DESCRIPCIÓ

N

Config::AutoConf está destinado a proporcionar las mismas oportunidades a los desarrolladores de Perl que GNU Autoconf http://www.gnu.org/software/autoconf/ hace para los desarrolladores de

Shell.

Dado que Perl es el segundo lenguaje más desplegado (ten en cuenta: cada Unix viene con Perl, varias minicomputadoras tienen Perl e incluso muchas máquinas Windows ejecutan software Perl - lo que requiere Perl desplegado allí también), esto ofrece un soporte más amplio que las pruebas basadas en

Shell.

La API está basada en GNU Autoconf, pero intentamos hacer la A

PI (especialmente los argumentos opcionales) más "perlera
" de lo que las capacidades de m4 permiten en el original.
