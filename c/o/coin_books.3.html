NOMBRE

coin_books - Libros relacionados con Open Inventor / Coin

Aquí hay una lista de algunos de los mejores libros para personas que invirtieron en desarrollo de software con Open Inventor. Si tienes sugerencias de libros adicionales que deberían incluirse en esta lista, no dudes en hacérnoslo saber.

El Mentor de Inventor

(subtítulo "Programación de gráficos 3D orientados a objetos con Open Inventor")

Este es un libro introductorio para Open Inventor, excelentemente escrito y detallado, estilo tutorial, que te guía a través de todos los principios de diseño fundamentales aplicados en la API de Open Inventor, ricamente ilustrado y con numerosos ejemplos de código bien documentados.

The Inventor Mentor está un poco anticuado, pero no dejes que eso te desanime. Es tan válido hoy como lo fue el día en que se escribió, y recomendamos encarecidamente este libro para cualquiera que esté aprendiendo a usar Open Inventor.

ISBN 0-201-62495-8. También es posible que encuentres este libro en formato pdf en línea, pero recomendamos tenerlo impreso.

El Fabricante de Herramientas de Inventor

Este libro explica cómo Open Inventor fue diseñado para ser extendido por los usuarios y te guía a través de cómo desarrollar tus propios componentes que funcionen con todos los aspectos de Coin.

ISBN 0-201-62493-1. También es posible que encuentres este libro en formato pdf en línea, pero recomendamos tenerlo impreso.

El Manual de Referencia de VRML2.0 Anotado

Este libro cubre el estándar VRML97 (también conocido como VRML 2.0), que Coin ha implementado con sus clases Inventor/VRMLnodes/, lo que es una extensión realizada más allá de la API de Open Inventor V2.1.

El formato VRML97 tiene algunas diferencias significativas con los formatos Inventor y VRML1, por lo que es un libro útil si deseas utilizar esa parte de Coin.

ISBN 0-201-41974-2. Encontrarás los documentos de especificación para VRML97 en línea en http://www.web3d.org/.

El Manual de Programación de Open GL

Esta es la biblia cuando se trata de programación OpenGL y es relevante para los extensores de Open Inventor que desarrollan nuevos nodos que implementan o afectan la renderización OpenGL de Open Inventor. Hay muchas ediciones de este libro, ya que se actualiza cada vez que se estandarizan y lanzan nuevas versiones de OpenGL, así que asegúrate de haber identificado la última edición si pides una.

El Manual de Referencia de Open Inventor C++

Aunque este libro es directamente relevante para Open Inventor, solo cubre la API de Open Inventor 2.1. Esta información está más o menos cubierta en la documentación doxygen en línea para Coin, donde está hipervinculada y también se puede generar sin conexión a partir de las fuentes de Coin para tenerla localmente, por lo que no creemos que este libro sea muy útil tenerlo impreso. Lo mencionamos de todos modos ya que es un libro de documentación oficial para Open Inventor.

ISBN 0-201-62491-5.
