containers-storage-set-metadata 1 Agosto 2016

NOMBRE

containers-storage set-metadata - Establecer metadatos para una capa, imagen o contenedor

SINOPSIS

containers-storage set-metadata [opciones [...]] nombreOIdentificadorDeCapaOImagenOContenedor

DESCRIPCIÓN

Actualiza los metadatos asociados a una capa, imagen o contenedor. Los metadatos están pensados para ser pequeños y se espera que se almacenen en caché en memoria.

OPCIONES

-f | --metadata-file nombrearchivo

Utilizar el contenido del archivo especificado como metadatos.

-m | --metadata valor

Utilizar el valor especificado como metadatos.

EJEMPLO

containers-storage set-metadata -m "compression: gzip" mi-capa
