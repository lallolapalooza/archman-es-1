COQTOP(1) Manual de Comandos Generales COQTOP(1)

NOMBRE

coqtop - sistema Coq de nivel superior

SINOPSIS

coqtop [ opciones ]

DESCRIPCIÓN

coqtop es el sistema de nivel superior de Coq, para uso interactivo. Lee frases de la entrada estándar y muestra resultados en la salida estándar. Para el uso de Coq orientado a lotes, consulta coqc(1).

OPCIONES

-h, --help
Ayuda. Te dará la lista completa de opciones aceptadas por coqtop.
-I dir, --include dir
Añade el directorio dir a la ruta de inclusión.
-R dir coqdir
Mapea recursivamente el directorio físico dir al directorio lógico coqdir.
-top coqdir
Establece el nombre de nivel superior a coqdir en lugar de Top.
-nois
Inicia con un estado inicial vacío.
-load-ml-source nombre_archivo
Carga el archivo ML nombre_archivo.
-load-ml-object nombre_archivo
Carga el archivo objeto ML nombre_archivo.
-load-vernac-source nombre_archivo, -l nombre_archivo
Carga el archivo Coq nombre_archivo.v. (Cargar nombre_archivo.)
-load-vernac-source-verbose nombre_archivo, -lv nombre_archivo
Carga el archivo Coq nombre_archivo.v de forma detallada. (Cargar Detallado nombre_archivo.)
-require lib
Carga la librería Coq lib. (Requerir lib.)
-require-import lib, -ri lib
Carga la librería Coq lib y la importa. (Requerir Importar lib.)
-require-export lib, -re lib
Carga la librería Coq lib y la importa transitivamente. (Requerir Exportar lib.)
-require-from raiz lib, -rfrom raiz lib
Carga la librería Coq lib. (Desde raiz Requerir lib.)
-require-import-from raiz lib, -rifrom raiz lib
Carga la librería Coq lib y la importa. (Desde raiz Requerir Importar lib.)
-require-export-from raiz lib, -refrom raiz lib
Carga la librería Coq lib y la importa transitivamente. (Desde raiz Requerir Exportar lib.)
-load-vernac-object lib
Sinónimo obsoleto de -require.
-where
Imprime la ubicación de la biblioteca estándar de Coq y sale.
-v
Imprime la versión de Coq y sale.
-q
Omite la carga del archivo rc (archivo de recursos), si lo hay.
-init-file nombre_archivo
Establece el archivo rc a nombre_archivo.
-batch
Modo por lotes (sale justo después de analizar los argumentos).
-emacs
Indica a Coq que se está ejecutando bajo Emacs.
-dump-glob nombre_archivo
Vuelca las globalizaciones en el archivo nombre_archivo (para ser utilizado por coqdoc(1)).
-impredicative-set
Establece la clase Set impredicativa.
-dont-load-proofs
No carga pruebas opacas en memoria.

VER TAMBIÉN
