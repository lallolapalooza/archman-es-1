NOMBRE

cockpit-bridge - Puente de Host de Cockpit

SINOPSIS

cockpit-bridge [--help] [--packages]

DESCRIPCIÓN

El programa cockpit-bridge es utilizado por Cockpit para transmitir mensajes y comandos desde la interfaz web al servidor. Entre otras cosas, transmite DBus y lanza procesos en nombre de la interfaz web.

Este programa no es ejecutado habitualmente por usuarios o administradores. Está en el $PATH para que Cockpit pueda encontrarlo al conectar entre hosts. Sin embargo, hay algunos diagnósticos disponibles al ejecutarlo desde la línea de comandos.

OPCIONES

--help

Muestra las opciones de ayuda.

--interact=boundary

Interactúa con el protocolo crudo cockpit1. Útil para depuración y pruebas. Especifica un boundary que debe estar en una línea vacía entre mensajes.

--packages

Lista todos los paquetes de Cockpit disponibles y sale. Tenga en cuenta que esto incluye los paquetes disponibles para el usuario que ejecuta este comando.

--version

Muestra información de la versión de Cockpit.
