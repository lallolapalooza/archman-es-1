coin401 - Nuevas características en Coin v4.0.1

Esta es una versión de corrección de errores.

Este es un breve resumen de las nuevas características en Coin v4.0.1:

  • El sistema de control de versiones ha sido cambiado de Mercurial a Git.
  • El hogar de la organización Coin3d ha sido cambiado de https://bitbucket.org/Coin3D a https://github.com/coin3d debido a que Bitbucket finaliza el soporte de Mercurial.
  • Se agregaron CI para macOS, Windows y Ubuntu por GitHub actions al repositorio
  • Se agregó la generación de checksum a AppVeyor CI
  • Se agregaron imágenes de macOS a AppVeyor CI
  • Las fuentes de expat en coin/src/xml/expat se actualizaron a la versión 2.2.10.
  • Se introdujo la nueva opción COIN_DEBUG_CHECK_THREAD.
  • Se introdujo la variable de entorno COIN_GLX_PIXMAP_DIRECT_RENDERING para forzar la renderización directa de contextos fuera de pantalla.

Correcciones de errores:

  • Se optimizó la depuración de mutex.
  • Se corrigió el problema de división entera.
  • Se corrigió el manejo de materiales y normales para conjuntos de líneas indexadas.
  • Se corrigió la búsqueda de recursos cuando HAVE_MULTIPLE_VERSION está habilitado en el script de compilación de CMake.
  • Se corrigió un problema de transparencia para conjuntos de líneas indexadas.
  • Se movieron los datos constantes al segmento de datos de solo lectura para reducir el tamaño de la biblioteca de objetos compartidos (ver https://randomascii.wordpress.com/2017/01/08/add-a-const-here-delete-a-const-there)
  • Se corrigieron numerosos problemas detectados por el análisis estático de código.
  • Se corrigió el enlace con la instalación del sistema de expat.
  • Se corrigió la versión de ABI rota en el enlace .so.
  • No se ejecutan programas para determinar el hash quoting para admitir la compilación cruzada.
  • Se corrigió la prueba del tamaño máximo de textura.
  • Se eliminó la comprobación obsoleta del problema del controlador ATI. No se comprueban problemas del controlador ATI corregidos hace mucho tiempo (ver problema #412). Agregamos la variable de entorno COIN_GLGLUE_DISABLE_VBO_IN_DISPLAYLIST para compatibilidad con el comportamiento anterior.
  • Se corrigió el subenlazamiento contra X11 en los scripts de compilación de CMake.
  • Se estableció la versión del shader GLSL en 120 para evitar problemas de renderización con la niebla.
  • Se habilitaron las texturas que no son potencias de dos para ATi e Intel por defecto. Para aquellos que necesiten el comportamiento anterior, se agregó una variable de entorno COIN_GLGLUE_DISABLE_NON_POWER_OF_TWO_TEXTURES.
  • No se deshabilita la renderización VBO para los controladores de gráficos Intel. Se sabe que el hardware gráfico Intel reciente admite la renderización VBO correctamente. Por lo tanto, eliminamos el código que lo deshabilita por defecto.
  • Se corrigió el pegamento GLX que intentaba usar una pantalla NULL, es decir, cuando una plataforma Unix tiene un contexto no GLX: generalmente Wayland, pero también puede ser fuera de pantalla o quizás EGL-X11.
  • Se corrigieron los argumentos del operador en algunos tipos base para usar referencias constantes en lugar de copias.
  • Se corrigió la renderización incorrecta de SoFaceSet. Las condiciones para renderizar como VertexArrayObject no se verificaron correctamente.
  • Se corrigió el manejo incorrecto de saltos de línea para CR/LF de Windows.
  • Se corrigió el cálculo incorrecto del punto más cercano para los cuadros delimitadores.
  • Se aplicaron algunos parches de distribución de Fedora, Rosa y Gentoo.
  • Se agregó documentación de algunas clases y se corrigieron numerosos problemas de documentación.
  • cpack.d se hizo opcional y se deshabilitó por defecto (agregue -DCOIN_USE_CPACK=ON al comando de cmake para habilitarlo).
  • La línea de referencia para el texto renderizado con la fuente predeterminada incorporada se cambió (antes: línea descendente, ahora: línea base). Por lo tanto, el texto renderizado con la fuente predeterminada aparecerá unos píxeles más abajo que antes, pero ahora es consistente con el texto que utiliza fuentes no predeterminadas. (ver https://github.com/coin3d/coin/pull/368)
  • Se corrigió el bloqueo al fallar la llamada a cc_flww32_get_bitmap().
