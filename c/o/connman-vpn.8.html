CONNMAN-VPN(8) Manual del Administrador del Sistema CONNMAN-VPN(8)

NOMBRE

ConnMan-VPN - Demonio de gestión de VPN

SINOPSIS

connman-vpnd [--version|--help]

connman-vpnd [-c archivo] [-d [archivo[,...]]] [-p plugin[,...]] [-P plugin[,...]] [-n]

DESCRIPCIÓN

El ConnMan-VPN proporciona un demonio para gestionar conexiones vpn junto con connmand(8). El Gestor de Conexiones está diseñado para ser ligero y usar la menor cantidad de recursos posible. El demonio VPN soporta openconnect(8), openvpn(8), vpnc(8) y L2TP/PPTP (xl2tpd.conf(5), pptp(8), pppd(8)).

OPCIONES

Se soportan las siguientes opciones:

-v, --version
Imprime la versión del software ConnMan-VPN y sale.
-h, --help
Imprime las opciones disponibles de ConnMan-VPN y sale.
-c archivo, --config=archivo
Especifica el archivo de configuración para configurar varios ajustes para ConnMan. Si no se especifica, se utiliza el valor predeterminado de /etc/connman/connman-vpn.conf. Consulte connman-vpn.conf(5) para obtener más información sobre el archivo de configuración. El uso del archivo de configuración es opcional y se utilizan valores predeterminados sensatos si el archivo de configuración falta.
-d [archivo[,...]], --debug[=archivo[,...]]
Establece cuánta información envía ConnMan-VPN al destino del registro (generalmente la instalación "daemon" de syslog). Si se omiten las opciones de archivo, se imprimen las informaciones de depuración de todos los archivos fuente. Si están presentes las opciones de archivo, entonces solo se imprimen las depuraciones de ese archivo fuente. Ejemplo:


connman-vpnd --debug=vpn/vpn-provider.c,vpn/vpn-config.c

-n, --nodaemon
No crear un demonio. Esto es útil para la depuración y dirige la salida del registro a la terminal controladora además de syslog.

VER TAMBIÉN

connmanctl(1), connman-vpn.conf(5), connman-vpn-provider.config(5), connmand(8)
