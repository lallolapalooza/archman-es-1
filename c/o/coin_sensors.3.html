NOMBRE

coin_sensors - Clases de Sensores


- Los sensores son objetos que monitorizan otros objetos en busca de cambios e invocan callbacks cuando ocurren cambios.

SINOPSIS

Clases


class SoAlarmSensor
La clase SoAlarmSensor es un sensor que se activará una vez en un momento específico. class SoDataSensor
La clase SoDataSensor es la clase base abstracta para sensores que monitorizan cambios en un grafo de escena. class SoDelayQueueSensor
La clase SoDelayQueueSensor es la clase base abstracta para sensores con planificación de prioridad. class SoFieldSensor
La clase SoFieldSensor detecta cambios en un campo. class SoIdleSensor
La clase SoIdleSensor es un sensor que se activará tan pronto como la aplicación esté inactiva. class SoNodeSensor
La clase SoNodeSensor detecta cambios en nodos. class SoOneShotSensor
La clase SoOneShotSensor es un sensor que se activará una vez. class SoPathSensor
La clase SoPathSensor detecta cambios en rutas. class SoSensor
La clase SoSensor es la clase base abstracta para todos los sensores. class SoSensorManager
La clase SoSensorManager maneja las colas de sensores. class SoTimerQueueSensor
La clase SoTimerQueueSensor es la clase base abstracta para sensores que se activan en ciertos eventos de temporizador. class SoTimerSensor
La clase SoTimerSensor es un sensor que se activará en intervalos dados.

Descripción Detallada

Los sensores son objetos que monitorizan otros objetos en busca de cambios e invocan callbacks cuando ocurren cambios.
