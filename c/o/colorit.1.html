NOMBRE

colorit - un script para marcar la entrada de texto

SINOPSIS

colorit [OPCIONES] [archivos...]

DESCRIPCION

colorit es un script para marcar la entrada de texto y enviar un resultado al paginador ( less -r por defecto) o a la salida estándar. Las reglas de marcado se describen en un archivo de configuración que es filtrado por un preprocesador (el valor por defecto es m4 ). La definición HOME igual a tu directorio principal se establece para el preprocesador usando la opción -D compatible tanto con m4 como con cpp. Este script se puede utilizar para colorear texto mediante secuencias de escape ANSI, o para realizar conversiones de texto sencillas y puede ser utilizado como paginador en lugar de less por dict u otros programas. En particular, los archivos de registro, la salida de dict, cc, make, o diff se pueden colorear y ver fácilmente.

OPCIONES

-V o --version
Muestra la información de la versión.
-h o --help
Muestra la información de ayuda.
-c archivo o --config archivo
Especifica el archivo de configuración. El valor por defecto es ~/.coloritrc o /etc/dict/colorit.conf
-P paginador o --pager paginador
Especifica un paginador (- para ninguno). El valor por defecto es less -r
--pp preprocesador
Especifica un preprocesador (- para ninguno).

ARCHIVOS

~/.coloritrc
Archivo de configuración del usuario para colorit
/etc/dict/colorit.conf
Archivo de configuración del sistema para colorit

ARCHIVO DE CONFIGURACION

Las líneas vacías o las líneas que comienzan con el signo de almohadilla (`#') se ignoran. Todas las demás líneas tienen esta estructura: comando arg1 arg2 ... argN. Todos los comandos se procesan uno por uno para cada línea de entrada.
Las cadenas de argumentos pueden ir entre comillas dobles.
Actualmente, solo el comando mark está disponible, con los siguientes argumentos: expresion_regular cadena_pre_cadena_post
La cadena_pre y la cadena_post se insertan al principio y al final de la subcadena que coincide con la expresion_regular

ERRORES

La única secuencia de escape admitida en las cadenas entrecomilladas es \033.

VER TAMBIEN

less(1), m4(1), cpp(1), dict(1)
