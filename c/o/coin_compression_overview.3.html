coin_compression_overview - Compresión de archivos

Coin puede admitir la lectura y escritura de archivos Inventor y VRML comprimidos con gzip o bzip2 (hasta ahora, puede haber más formatos en el futuro). Esta funcionalidad, por supuesto, solo se habilita cuando Coin puede enlazarse con las bibliotecas de compresión correspondientes.

La lectura de archivos comprimidos se realiza de forma transparente; el desarrollador no tiene que hacer nada para admitirlo.

La escritura de archivos comprimidos se controla a través del método SoOutput::setCompression.

La lista de métodos de compresión disponibles se puede obtener con el método SoOutput::getAvailableCompressionMethods.

No puede utilizar la compresión de archivos junto con E/S a búferes de memoria, excepto para leer desde búferes de memoria que contengan archivos comprimidos con gzip.

Para compatibilidad con versiones anteriores de Coin 2.0 y Coin 1.0, no se deben utilizar archivos comprimidos. Los archivos comprimidos solo funcionan desde Coin 2.1 en adelante.
