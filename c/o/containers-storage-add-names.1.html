containers-storage-add-names 1 de agosto de 2016

NOMBRE

containers-storage add-names - Añadir nombres a una capa/imagen/contenedor

SINOPSIS

containers-storage add-names [opciones [...]] nombreOrIDDeCapaOImagenOContenedor

DESCRIPCIÓN

Además de las IDs, las capas, imágenes y contenedores pueden tener nombres legibles asignados en containers-storage. El comando add-names se puede usar para añadirles uno o más nombres.

OPCIONES

-n | --name nombre

Especifica un nombre para añadir a la capa, imagen o contenedor. Si un nombre especificado ya está en uso por otra capa, imagen o contenedor, se elimina de esa otra capa, imagen o contenedor.

EJEMPLO

containers-storage add-names -n mi-contenedor-genial -n mi-contenedor-realmente-genial f3be6c6134d0d980936b4c894f1613b69a62b79588fdeda744d0be3693bde8ec
