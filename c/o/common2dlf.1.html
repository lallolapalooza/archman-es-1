NOMBRE

common2dlf - convierte archivos de registro de servidor web en formato Common Log a www DLF

SINOPSIS

common2dlf archivo

DESCRIPCIÓN

common2dlf convierte archivos de registro de servidor web en formato Common Log a www DLF. El formato Common Log es un formato de registro estándar que se implementó originalmente en el servidor web CERN httpd pero que hoy en día es compatible con la mayoría de los servidores web. Apache, IIS, Boa y PureFTPD pueden configurarse para registrar en ese formato.

Si falta el argumento archivo, se analizará STDIN. DLF se imprimirá en STDOUT.

FORMATO COMMON LOG

El formato Common Log tiene el siguiente formato:

hostremoto rfc931 usuarioautenticado [fecha] "solicitud" estado bytes

donde los campos tienen el siguiente significado:

hostremoto
El host que realizó la solicitud. Puede ser una IP o un nombre de host.
rfc931
El resultado de una búsqueda ident en el host. Esto generalmente nunca se usa.
usuarioautenticado
El nombre de usuario autenticado.
fecha
La marca de tiempo de la solicitud.
solicitud
La primera línea de la solicitud. Generalmente en el formato "método uri-solicitud versión-http".

Ver también RFC 2616, sección 5.1.

estado
El estado del resultado de la solicitud. es decir, 200, 301, 404, 500.
bytes
El tamaño de la solicitud enviada al cliente.

Ejemplo de registro:

127.0.01 - - [11/03/2001 12:12:01 -0400] "GET / HTTP/1.0" 200 513
dsl1.myprovider.com - francis [11/03/2001 12:14:01 -0400] "GET /secret/ HTTP/1.0" 200 1256

EJEMPLOS

Para procesar un registro como el producido en el formato Common Log:

$ lr_run common2dlf < common.log

common2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report common < /var/log/httpd/common.log
