columns(1) Comandos de usuario columns(1)

NOMBRE

columns - Columnizar texto de entrada

SINOPSIS

columns [-flags] [-flag [valor]] [--nombre-opcion[[=| ]valor]]

Todos los argumentos deben ser opciones.

DESCRIPCIÓN

No hay descripción para este comando.

OPCIONES

Especificar las dimensiones de salida

-W num, --ancho=num

Ancho máximo de línea. Esta opción toma un número entero como argumento. El valor de num está restringido a estar: 
en el rango  16 a 4095

El num predeterminado para esta opción es:
79

Esta opción especifica el ancho completo de la línea de salida, incluida cualquier indentación al principio de la línea. La salida llenará cada línea lo más posible, a menos que el ancho de columna se haya especificado explícitamente. Si el ancho máximo es menor que la longitud de la entrada más ancha, obtendrá una sola columna de salida.

-c cuenta, --columnas=cuenta

Número deseado de columnas. Esta opción toma un número entero como argumento. El valor de cuenta está restringido a estar: 
en el rango  1 a 2048

El cuenta predeterminado para esta opción es:
0

Use esta opción para especificar exactamente cuántas columnas producir. Si ese número de columnas no cabe dentro de ancho_linea, entonces la cuenta se reducirá al número que quepa.

-w num, --ancho-col=num

Establecer el ancho de cada columna. Esta opción toma un número entero como argumento. El valor de num está restringido a estar: 
en el rango  1 a 2048

El num predeterminado para esta opción es:
0

Use esta opción para especificar exactamente cuántos caracteres se asignarán a cada columna. Si es más estrecho que la entrada más ancha, se anulará con el ancho requerido.

--ancho-tab=num

Ancho de tabulación. Esta opción toma un número entero como argumento. El num predeterminado para esta opción es:
8

Si una cadena de indentación contiene tabulaciones, este valor se utiliza para calcular la columna final de la cadena de prefijo.

Especificar cómo diseñar el texto

--spread=num

propagación máxima añadida al ancho de columna. Esta opción toma un número entero como argumento. El valor de num está restringido a estar: 
en el rango  1 a 1024

El num predeterminado para esta opción es:
0

Use esta opción para especificar exactamente cuántos caracteres se pueden agregar a cada columna. Permite evitar que las columnas se separen demasiado. Sin esta opción, columns intentará ampliar las columnas para llenar el ancho completo.

--fill

Rellenar líneas con entrada. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: spread, ancho_col, por_columnas.

En lugar de poner en columnas el texto de entrada, rellena las líneas de salida con las líneas de entrada. Las líneas en blanco en la entrada causarán una línea en blanco en la salida, a menos que la salida esté ordenada. Con salida ordenada, se ignoran las líneas en blanco.

-I prefijo-lin, --indentar=prefijo-lin

Prefijo de línea o indentación.

Si es un número, se insertará ese número de espacios al principio de cada línea. De lo contrario, es un prefijo de línea que se insertará al principio de cada línea.

--indent-primero=prefijo-lin

Prefijo de la primera línea. Esta opción debe aparecer en combinación con la opción indentar.

Si es un número, se insertará ese número de espacios al principio de la primera línea. De lo contrario, es un prefijo de línea que se insertará al principio de esa línea. Si su longitud excede "indentar", se emitirá en una línea separada, seguida de cualquier cadena de separación de línea. Por ejemplo:

    $ columns --indent-primero='#define TABLE' -c 2 -I4 --separacion-linea=' ´ <<_EOF_
    one
    two
    three
    four
    _EOF_
    #define TABLE         one   two         three four
-f cadena-formato, --formato=cadena-formato

Cadena de formato para cada entrada.

Si necesita reformatear cada texto de entrada, el argumento de esta opción se interpreta como un formato sprintf(3) que se utiliza para producir cada entrada de salida.

-S cadena-sep, --separacion=cadena-sep

Cadena de separación - sigue a todas excepto la última.

Use esta opción si, por ejemplo, desea que aparezca una coma después de cada entrada excepto la última.

--separacion-linea=cadena-sep

Cadena al final de todas las líneas excepto la última.

Use esta opción si, por ejemplo, desea que aparezca una barra inclinada al final de cada línea, excepto la última.

--final=cadena-final

Cadena al final de la última línea.

Esta opción coloca la cadena especificada al final de la salida.

Especificar el orden de las entradas

--por-columnas

Imprimir entradas en orden de columnas.

Normalmente, las entradas se imprimen en orden por filas y luego por columnas. Esta opción hará que las entradas se ordenen dentro de las columnas. La columna final, en lugar de la fila final, puede ser más corta que las otras.

-s patron-clave, --ordenar [patron-clave]

Ordenar texto de entrada.

Hace que el texto de entrada se ordene. Si se proporciona un argumento, se presume que es un patrón y el orden se basa en el texto coincidente. Si el patrón comienza con un asterisco (*) o consiste en él, la ordenación no distingue entre mayúsculas y minúsculas.

Redirigir stdin a un archivo alternativo

-i archivo, --entrada=archivo

Archivo de entrada (si no es stdin).

Este programa normalmente se ejecuta como un filtro, leyendo desde la entrada estándar, colocando en columnas y escribiendo en la salida estándar. Esta opción redirige la entrada a un archivo.

-?, --ayuda

Mostrar información de uso y salir.
-!, --mas-ayuda

Pasar la información de uso extendida a través de un paginador.
-> [archivo-cfg], --guardar-opts [=archivo-cfg]

Guardar el estado de las opciones en archivo-cfg. El valor predeterminado es el último archivo de configuración listado en la sección PREAJUSTES DE OPCIONES, más abajo. El comando saldrá después de actualizar el archivo de configuración.
-< archivo-cfg, --cargar-opts=archivo-cfg, --sin-cargar-opts

Cargar opciones desde archivo-cfg. La forma sin-cargar-opts deshabilitará la carga de archivos config/rc/ini anteriores. --sin-cargar-opts se maneja temprano, fuera de orden.
-v [{v|c|n --version [{v|c|n}]}]

Mostrar la versión del programa y salir. El modo predeterminado es `v', una simple v
