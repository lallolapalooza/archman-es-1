CONFIG_DATA(1p) Documentación de Perl aportada por el usuario CONFIG_DATA(1p)

NOMBRE

config_data - Consultar o cambiar la configuración de módulos Perl

SINOPSIS

# Obtener valores de configuración/características
config_data --module Foo::Bar --feature bazzable
config_data --module Foo::Bar --config magic_number
# Establecer valores de configuración/características
config_data --module Foo::Bar --set_feature bazzable=1
config_data --module Foo::Bar --set_config magic_number=42
# Imprimir un mensaje de ayuda
config_data --help

DESCRIPCIÓN

La herramienta "config_data" proporciona una interfaz de línea de comandos para la configuración de módulos Perl. Por "configuración", nos referimos a algo similar a las "preferencias del usuario" o "ajustes locales". Esta es una formalización y abstracción de los sistemas que personas como Andreas Koenig ("CPAN::Config"), Jon Swartz ("HTML::Mason::Config"), Andy Wardley ("Template::Config") y Larry Wall (el propio Config.pm de Perl) han desarrollado de forma independiente.

El sistema de configuración empleado aquí se desarrolló en el contexto de "Module::Build". Bajo este sistema, la información de configuración para un módulo "Foo", por ejemplo, se almacena en un módulo llamado "Foo::ConfigData") (lo habría llamado "Foo::Config", pero ese nombre estaba ocupado por todos los demás sistemas mencionados en el párrafo anterior...). Estos módulos "...::ConfigData" contienen los datos de configuración, así como métodos accesibles públicamente para consultar y establecer (sí, realmente reescribir) los datos de configuración. El script "config_data" (cuyos documentos está leyendo actualmente) es meramente una interfaz para esos métodos. Si lo desea, puede crear interfaces alternativas.

Los dos tipos de datos que se pueden almacenar se denominan valores de "config" y valores de "feature". Un valor de "config" puede ser cualquier escalar de perl, incluyendo referencias a estructuras de datos complejas. Sin embargo, debe ser serializable utilizando "Data::Dumper". Una "feature" es un valor booleano (1 o 0).

USO

Este script funciona como un envoltorio básico de obtentor/establecedor para la configuración de un solo módulo. En la línea de comandos, especifique qué módulo desea configurar y pase opciones para obtener o establecer valores de "config" o "feature". Las siguientes opciones son compatibles:

module
Especifica el nombre del módulo a configurar (requerido).
feature
Cuando se le pasa el nombre de una "feature", muestra su valor. El valor será 1 si la característica está habilitada, 0 si la característica no está habilitada, o vacío si la característica es desconocida. Cuando no se proporciona un nombre de característica, se mostrarán los nombres y valores de todas las características conocidas.
config
Cuando se le pasa el nombre de una entrada de "config", muestra su valor. El valor se mostrará utilizando "Data::Dumper" (o similar) como código de perl. Cuando no se proporciona un nombre de configuración, se mostrarán los nombres y valores de todas las entradas de configuración conocidas.
set_feature
Establece la "feature" dada al valor booleano dado. Especifique el valor como 1 o 0.
set_config
Establece la entrada de "config" dada al valor dado.
eval
Si se utiliza la opción "--eval", los valores en "set_config" se evaluarán como código perl antes de ser almacenados. Esto permite almacenar estructuras de datos moderadamente complicadas. Para estructuras realmente complicadas, probablemente no debería usar esta interfaz de línea de comandos, solo use la API de Perl en su lugar.
help
Imprime un mensaje de ayuda, incluyendo algunos ejemplos, y sale.
