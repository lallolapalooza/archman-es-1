coin_foreign_file_support - Soporte para formatos de archivo externos

Esta es una página que describe el soporte para formatos de archivo externos en Coin.

Formatos soportados hasta ahora:

•
Archivos STL / Estereolitografía (.stl)

El servidor SoSTLFileKit es un primer ejemplo de cómo se puede implementar el soporte para formatos de archivo externos a través del nodo de interfaz SoForeignFileKit. Para STL, el formato de archivo es tan trivial que se mapea directamente en unos pocos nodos de Open Inventor. Para otros formatos de archivo, el mapeo directo podría no ser posible o deseable (quizás se perdería información importante en dicha conversión), y el implementador podría optar por implementar un conjunto de nodos personalizados internos para realizar el renderizado (y aplicar las otras acciones), y elegir organizar primero puramente Open Inventor cuando se le pide al kit de nodos que escriba su contenido como un grafo de escena.
