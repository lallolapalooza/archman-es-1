DESCRIPCIÓ

N

Conky es un monitor de sistema para X originalmente basado en torsmo. Desde su creación, Conky ha cambiado significativamente respecto a su predecesor, manteniendo la simplicidad y la configurabilidad. Conky puede mostrar casi cualquier cosa, ya sea en su escritorio raíz o en su propia ventana. No solo Conky tiene muchos objetos integrados, sino que también puede mostrar casi cualquier pieza de información usando scripts y otros programas

externos.

Conky tiene más de 250 objetos integrados, incluyendo soporte para una gran cantidad de estadísticas del SO (uname, tiempo de actividad, uso de CPU, uso de memoria, uso de disco, estadísticas de procesos similares a "top" y monitoreo de red, por nombrar algunos), soporte integrado de IMAP y POP3, soporte integrado para muchos reproductores de música populares (MPD, XMMS2, Audacious), y mucho más. Conky puede mostrar esta información ya sea como texto, o usando barras de progreso simples y widgets de gráficos, con diferentes fuentes y

colores.

Siempre estamos buscando ayuda, ya sea reportando errores, escribiendo parches o escribiendo documentación. Por favor, use las herramientas en GitHub para hacer reportes de errores, solicitudes de características y enviar

parches.

COMPILACIÓ

N

Para usuarios que compilan desde el código fuente en una distribución binaria, asegúrese de tener las bibliotecas de desarrollo de X instaladas (a menos que configure su compilación sin X11). Este debería ser un paquete como "libx11-dev" o "xorg-x11-dev" para las bibliotecas de X11, y un formato "-dev" similar para las otras bibliotecas requeridas (dependiendo de sus opciones de compilación). Debería poder ver qué paquetes adicionales necesita instalar leyendo los errores que obtiene al ejecutar `cmake`. La forma más fácil de ver las opciones de compilación disponibles es ejecutar `ccmake` o `cmake-gui` desde el árbol de código fuente, pero tenga cuidado al desactivar ciertas características, ya que podría perder funcionalidad deseada. Por ejemplo, con BUILD_MATH desactivado no obtendrá errores, pero los gráficos logarítmicos serán gráficos normales y los medidores carecerán de su

línea.

Conky ha estado disponible (por algún tiempo) en los repositorios de la mayoría de las distribuciones populares. Aquí hay algunas instrucciones de instalación para algunas de

ellas:

Usuarios de Gentoo -- Conky está en el Portage de Gentoo... simplemente use "emerge app-admin/conky" para la

instalación.

Usuarios de Debian, etc. -- Conky debería estar en sus repositorios, y puede instalarse haciendo "aptitude install

conky".

Ejemplo para compilar y ejecutar Conky con los componentes predeterminados (note que algunas opciones de compilación pueden diferir en su sistema)
