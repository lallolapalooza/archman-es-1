NOMBRE

containers-storage list-container-data - Listar datos externos para un contenedor

SINOPSIS

containers-storage list-container-data nombreOIdContenedor

DESCRIPCIÓN

Lista las piezas de datos con nombre que están asociadas con un contenedor.

EJEMPLO

containers-storage list-container-data mi-contenedor
