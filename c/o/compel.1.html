NOMBRE
compel - Ejecutar código parásito dentro de otro proceso.



SINOPSIS

compel hgen [opción ...]

compel plugins [NOMBRE_PLUGIN ...]

compel [--compat] includes | cflags | ldflags

compel [--compat] [--static] libs



DESCRIPCIÓN

compel es una utilidad para ejecutar código arbitrario, también llamado código parásito, en el contexto de un proceso ajeno. El código parásito, una vez compilado con las opciones de compel y empaquetado, puede ser ejecutado en el contexto de otras tareas. Actualmente solo hay una forma de cargar el blob parásito en la tarea víctima usando libcompel.a, llamada c-header.



ARGUMENTOS



Argumentos Posicionales

hgen

crea una cabecera a partir del archivo .po, que es el binario parásito.

plugins

imprime los plugins disponibles.

ldflags

imprime las ldflags disponibles para compel durante el enlazado del código parásito.

cflags

imprime las cflags de compel que se deben usar durante la compilación del código parásito.

includes

imprime la lista de directorios de inclusión estándar.

libs

imprime la lista de bibliotecas estáticas o dinámicas con las que compel puede enlazarse.



OPCIONES

-f, --file FICHERO

Ruta al archivo binario, FICHERO, que compel debe convertir en una cabecera

-o, --output FICHERO

Ruta al archivo de cabecera, FICHERO, donde compel debe escribir la cabecera resultante.

-p, --prefix NOMBRE

Especifica el prefijo para los nombres de variables

-l, --log-level NÚMERO

Nivel de registro predeterminado de compel.

-h, --help

Imprime el uso y sale.

-V, --version

Imprime el número de versión de compel.



EJEMPLOS DE CÓDIGO FUENTE



Código Parásito

#include <compel/plugins/std.h>

int parasite_trap_cmd(int cmd, void *args); // es llamado por compel_run_in_thread()

int parasite_daemon_cmd(int cmd, void *arg); // es llamado por compel_rpc_call() y compel_rpc_call_sync()

void parasite_cleanup(void); // es llamado al descargar el parásito por compel_cure()



Código de Infección

El código parásito se compila y se convierte en una cabecera usando compel, y se incluye aquí.

#include <compel/infect.h>

#include "parasite.h"

Los siguientes pasos se realizan para infectar el proceso víctima:

•detener la tarea: int compel_stop_task(int pid);
•preparar el manejador de infección: struct parasite_ctl *compel_prepare(int pid);
•ejecutar llamada al sistema: int compel_syscall(ctl, int syscall_nr, long *ret, int arg ...);
•infectar víctima: int compel_infect(ctl, nr_thread, size_of_args_area);
•curar la víctima: int compel_cure(ctl); //el puntero ctl es liberado por esta llamada
•Reanudar víctima: int compel_resume_task(pid, orig_state, state) o int compel_resume_task_sig(pid, orig_state, state, stop_signo). //se puede usar compel_resume_task_sig() en caso de que la víctima esté en estado detenido. stop_signo se puede leer llamando a compel_parse_stop_signo().

ctl debe ser configurado con la información del blob llamando a PREFIX_setup_c_header(), con ctl como argumento. PREFIX es el argumento dado a -p al llamar a hgen, de lo contrario se deduce del nombre del archivo.



EJEMPLOS

Para generar un archivo de cabecera (.h) a partir de un archivo binario parásito (.po), usa:

    compel hgen -f parasite.po -o parasite.h

El archivo parasite.po se obtiene compilando el código fuente parásito con las opciones de compel y enlazándolo con los plugins de compel.
