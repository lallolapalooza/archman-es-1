COQDOC(1) Manual de comandos generales COQDOC(1))

NOMBRE

coqdoc - herramienta de documentación para el asistente de demostración Coq

SINOPSIS

coqdoc [ opciones ] archivos

DESCRIPCIÓN

coqdoc es una herramienta de documentación para el asistente de demostración Coq. Crea documentos LaTeX o HTML a partir de un conjunto de archivos Coq. Consulte el manual de referencia de Coq para la documentación (URL más abajo).

OPCIONES

Opciones generales

-h
Ayuda. Le dará la lista completa de opciones aceptadas por coqdoc.
--html
Selecciona una salida HTML.
--latex
Selecciona una salida LaTeX.
--dvi
Selecciona una salida DVI.
--ps
Selecciona una salida PostScript.
--texmacs
Selecciona una salida TeXmacs.
--stdout
Redirige la salida a stdout
-oarchivo,--outputarchivo
Redirige la salida al archivo archivo.
-ddir,--directorydir
Escribe los archivos de salida en el directorio dir en lugar del directorio actual (la opción -d no cambia el nombre de archivo especificado con la opción -o, si lo hay).
-s,--short
No inserta títulos para los archivos. El comportamiento por defecto es insertar un título como ``Library Foo'' para cada archivo.
-tcadena,--titlecadena
Establece el título del documento.
--body-only
Suprime el encabezado y el pie del documento final. Así, puede insertar el documento resultante en uno más grande.
-pcadena,--preamblecadena
Inserta algún material en el preámbulo LaTeX, justo antes de \begin{document} (sin sentido con -html).
--vernac-filearchivo,--tex-filearchivo
Considera el archivo archivo respectivamente como un archivo .v (o .g) o un archivo .tex .
--files-fromarchivo
Lee los nombres de archivo a procesar en el archivo archivo como si se hubieran dado en la línea de comandos. Útil para fuentes de programas divididas en varios directorios.
-q,--quiet
Ser silencioso. No imprimir nada excepto errores.
-h,--help
Da un resumen breve de las opciones y sale.
-v,--version
Imprime la versión y sale.

Opciones de índice

El comportamiento por defecto es construir un índice, solo para la salida HTML, en index.html.

--no-index
No genera el índice.
--multi-index
Genera una página para cada categoría y cada letra en el índice, junto con una página superior index.html.

Opción de tabla de contenidos

-toc,--table-of-contents
Inserta una tabla de contenidos. Para una salida LaTeX, inserta un \tableofcontents al principio del documento. Para una salida HTML, construye una tabla de contenidos en toc.html.

Opciones de hipervínculos

--glob-fromarchivo
Hace referencias usando las globalizaciones de Coq del archivo archivo. (Tales globalizaciones se obtienen con la opción de Coq -dump-glob).
--no-externals
No inserta enlaces a la biblioteca estándar de Coq.
--externalurl libroot
Establece la URL base para la biblioteca externa cuyo prefijo raíz es libroot.
--coqlib_urlurl
Establece la URL base para la biblioteca estándar de Coq (por defecto es http://coq.inria.fr/library/).
--coqlibdir
Establece la ruta base donde están instalados los archivos de Coq, especialmente los archivos de estilo coqdoc.sty y coqdoc.css.
-Rdir coqdir
Mapea el directorio físico dir al directorio lógico de Coq coqdir (de manera similar a la opción de Coq -R). Nota: la opción -R solo tiene efecto sobre los archivos que la siguen en la línea de comandos, por lo que probablemente necesitará poner esta opción primero.

Opciones de contenido

-g,--gallina
No imprime las demostraciones.
-l,--light
Modo ligero. Suprime las demostraciones (como con -g) y los siguientes comandos:
  • [Recursive] Tactic Definition
  • Hint / Hints
  • Require
  • Transparent / Opaque
  • Implicit Argument / Implicits
  • Section / Variable / Hypothesis / End

El comportamiento de las opciones -g y -l puede ser anulado localmente usando el entorno (* begin show *) ... (* end show *) (ver arriba).

Opciones de idioma

El comportamiento por defecto es asumir archivos de entrada ASCII de 7 bits.

-latin1,--latin1
Selecciona archivos de entrada ISO-8859-1. Es equivalente a --inputenc latin1 --charset iso-8859-1.
-utf8,--utf8
Selecciona archivos de entrada UTF-8 (Unicode). Es equivalente a --inputenc utf8 --charset utf-8. El soporte UTF-8 de LaTeX se puede encontrar en http://www.ctan.org/tex-archive/macros/latex/contrib/supported/unicode/.
--inputenccadena
Da una codificación de entrada LaTeX, como una opción para el paquete LaTeX inputenc.
--charsetcadena
Especifica el juego de caracteres HTML, para ser insertado en el encabezado HTML.
