NOMBRE

coqwc - imprime el número de líneas de especificación, prueba y comentario en archivos Coq

SINOPSIS

coqwc [ -p ] [ -s ] [ -r ] [ -e ] archivos ...

DESCRIPCIÓN

coqwc calcula el número de líneas de especificación, líneas de prueba y líneas de comentario en archivos Coq.

OPCIONES

-p
Imprime el porcentaje de comentarios.
-s
Imprime solo el número de líneas de especificación.
-r
Imprime solo el número de líneas de prueba.
-e
No omitir encabezados.

BUGS

Por favor, informa cualquier error en https://github.com/coq/coq/issues.
