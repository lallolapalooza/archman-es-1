NOMBRE

containers-mounts.conf - archivo de configuración para montajes predeterminados en contenedores

DESCRIPCIÓN

El archivo mounts.conf especifica directorios de montaje de volumen que se montan automáticamente dentro de los contenedores. Los procesos del contenedor pueden entonces usar este contenido. Por lo general, estos directorios se utilizan para pasar secretos o credenciales requeridos por el software del paquete para acceder a repositorios de paquetes remotos. Tenga en cuenta que, por razones de seguridad, las herramientas que se adhieren a mounts.conf se espera que copien el contenido en lugar de montar enlazados las rutas del host.

FORMATO

El formato de mounts.conf es el formato de volumen /SRC:/DEST, un montaje por línea. Por ejemplo, un mounts.conf con la línea /usr/share/secrets:/run/secrets haría que el contenido del directorio /usr/share/secrets en el host se montara en el directorio /run/secrets dentro del contenedor. Establecer puntos de montaje permite a los contenedores usar los archivos del host, por ejemplo, para usar la suscripción del host a alguna distribución Linux empresarial.

ARCHIVOS

Algunas distribuciones pueden proporcionar un archivo /usr/share/containers/mounts.conf para proporcionar montajes predeterminados, pero los usuarios pueden crear un /etc/containers/mounts.conf para especificar sus propios volúmenes especiales a montar en el contenedor. Cuando Podman se ejecuta en modo sin raíz (rootless), el archivo $HOME/.config/containers/mounts.conf reemplazará al predeterminado si existe.
