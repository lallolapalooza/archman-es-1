Documentación de Typedef

typedef struct cc_xml_doc cc_xml_doc

tipo de objeto contenedor opaco para documentos XML Este tipo es un objeto contenedor opaco para una estructura de documento XML, y también la interfaz para configurar el código de análisis y escritura.

Documentación de Funciones

Crea un nuevo objeto cc_xml_doc que está totalmente en blanco.

void cc_xml_doc_delete_x (cc_xml_doc * doc) [relacionado]

Libera un objeto cc_xml_doc y todos sus recursos.

void cc_xml_doc_set_filter_cb_x (cc_xml_doc * doc, cc_xml_filter_cb * cb, void * userdata) [relacionado]

Establece la función de devolución de llamada de filtro para el análisis del documento. Esto hace posible utilizar el analizador como un analizador en streaming, haciendo que el analizador descarte todos los elementos que ha leído.

Los elementos solo pueden descartarse cuando se sacan de la pila; al introducirlos, se mantendrán independientemente de lo que devuelva la función de devolución de llamada del filtro.

void cc_xml_doc_get_filter_cb (const cc_xml_doc * doc, cc_xml_filter_cb *& cb, void *& userdata) [relacionado]

Devuelve la función de devolución de llamada de filtro establecida en los argumentos cb y userdata.
