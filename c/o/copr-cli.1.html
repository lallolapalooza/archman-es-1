NOMBRE

copr-cli - interfaz de línea de comandos para el servicio Copr

SINOPSIS

copr-cli [-h] [--version] [--config CONFIG] {list,create,build} ...

DESCRIPCIÓN

Este comando le permite interactuar con el servicio Copr desde la línea de comandos.

Necesita configurar primero la autenticación (vea la sección AUTENTICACIÓN más abajo).

OPCIONES

-h, --help

muestra este mensaje de ayuda y sale

--version

muestra el número de versión del programa y sale

--config

ruta a un archivo de configuración alternativo (por defecto es ~/.config/copr).

ACCIÓN LISTA

list [username|@groupname]

Lista todos los proyectos del nombre de usuario proporcionado. Si no se proporciona ningún nombre de usuario, se listan sus proyectos.

create

Crea un nuevo proyecto.

delete

Elimina un proyecto completo.

build

Compila paquetes para un proyecto especificado.

status

Obtiene el estado de la compilación.

cancel

Cancela una compilación con el id dado.

download-build

Descarga una compilación a un directorio local.

modify

Modifica un copr existente

regenerate-repos

Regenera los metadatos del repositorio de un proyecto

add-package-*

Añade un nuevo paquete del tipo de origen especificado (por ejemplo, add-package-tito)

edit-package-*

Edita la definición y el tipo de origen de un paquete existente (por ejemplo, edit-package-tito)

list-packages

Lista todos los paquetes de un copr en formato json

list-package-names

Muestra solo los nombres de los paquetes del copr dado

get-package

Muestra los detalles de un solo paquete en formato json

delete-package

Elimina un paquete de un copr y todas sus compilaciones también

reset-package

Borra la definición de origen de un paquete y su tipo de origen

build-package

Compila un paquete a partir de su definición de origen

mock-config

Obtiene el perfil de mock (similar a koji mock-config)

ACCIONES DE COMPILACIÓN

copr-cli build [opciones]

uso: copr-cli build [-h] [-r, --chroot CHROOTS] [--memory MEMORY] [--timeout TIMEOUT] [--nowait] [--background] [--isolation {default, nspawn, simple}] [--enable-net {on,off}] copr_repo PKG [PKG ...]

-r, --chroot

Si no necesita esta compilación para todos los chroots del proyecto. Puede usarlo varias veces para cada chroot que necesite.

--exclude-chroot

Si no necesita esta compilación para todos los chroots del proyecto. Puede usarlo varias veces para cada chroot que no necesite.

--memory

Anula la memoria para esta compilación. En realidad no se usa y no tiene efecto.

--timeout

Especifica el tiempo de espera de la compilación (segundos); si la compilación tarda más que eso, se termina y falla. Por defecto, generalmente se establece en 5 horas en el Frontend de Copr.

--nowait

No espera a que se complete la compilación.

--background

Ejecuta la compilación con una prioridad más baja.

--isolation ISOLATION

Elige el método de aislamiento para ejecutar comandos en el buildroot.

--enable-net

Si la red debe estar habilitada para esta compilación.

copr_repo

El repositorio copr en el que compilar el paquete. Este puede ser un nombre simple de alguno de sus proyectos o puede especificarse completamente como username/project o @groupname/project. De esta manera puede compilar en el proyecto de otro usuario o grupo, siempre que tenga permisos para hacerlo. Finalmente, en lugar de solo el nombre del proyecto, también puede pasar project:tag. En ese caso, la compilación aterrizará en el repositorio lateral del proyecto en lugar del repositorio principal. El repositorio lateral con el nombre project:tag se creará automáticamente si no existest aún. Puede, por ejemplo, usar esta función para lanzar compilaciones de prueba mientras el repositorio principal orientado al usuario permanece intacto. Puede especificar cualquier etiqueta que sea apropiada para la(s) compilación(es) dada(s)
.

PK

G
Esto puede ser un archivo en su estación de trabajo local o la URL del paquete a compilar. Cuando se usa una URL, el paquete debe estar
colocado en un servidor web o ftp público. Tenga en cuenta que no puede combinar rutas de archivo locales y URLs en una sola línea de
comando y que las compilaciones con archivos locales se limitan al primer PKG especificado. Esta limitación proviene de la API de COPR.

ESTADO DE

SALIDA

Normalmente, el código de salida es 0 cuando todo va bien. Pero si no, podríamos

obtener:

1 - Solicitud incorrecta como nombre de proyecto erróneo, derechos insuficientes, etc. También puede ocurrir cuando el usuario interrumpe la operación cuando no

debería.

2 - Argumentos incorrectos

proporcionados.

3 - Configuración incorrecta o

ausente.

4 - La compilación falló o fue

cancelada.

5 - Error de comunicación entre el Cli y el servidor. Este problema probablemente significa un error y debería ser

reportado.

6 - Error de

configuración.

7 - La autentica

ción con el serv
idor Copr falló.

AUTENTICACIÓ

N

El cliente Copr soporta autenticación basada en tokens y

GSSAPI.

Visite la página https://copr.fedorainfracloud.org/api/ para obtener un token de API. Este token debe guardarse en el archivo de configuración ~/.config/copr en el siguiente

formato: 
[copr-cli]
username = msuchy
login = Y57wcg==##fkfaxbkjhuoiebf
afadl token = vbfseelqdebzedukgombekmuvbkqwo copr_url = https
://copr.fedorainfracloud.org # fecha de expiración: 2023-01-01

¡Tenga en cuenta que los tokens de API tienen una fecha de

expiración!

Para habilitar GSSAPI necesita obtener un ticket de Kerberos. Si quiere trabajar con Fedora Copr, simplemente puede

hacer: 
$ fkinit
Introduzca su contraseña y OTP concatena
das. (Ignore que el prompt es solo para el token)
Valor del Token OTP: <su contraseña + token OTP>

Para trabajar con una instancia diferente (no Fedora Copr), obtendrá el ticket de manera diferente y aún necesita tener un archivo de configuración que referencie el copr_url

apropiado: 
$ kinit username@EXAMPLE.COM
$ c
at ~/.config/copr [copr-cli] copr
_url = https://copr.example.com/

El cliente Copr usa la API de Python internamente, para más información eche un vistazo a la página https://python-copr.readthedocs.io/en/latest/ClientV3.html#example-usa
