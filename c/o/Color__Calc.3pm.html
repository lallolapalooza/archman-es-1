DESCRIPCIÓ

N

El módulo "Color::Calc" implementa cálculos simples con colores RGB. Esto puede usarse para crear un esquema de colores completo a partir de unos pocos

colores.

Los métodos de cálculo también están disponibles como funciones. El formato de salida se selecciona a través del nombre de la

función.
