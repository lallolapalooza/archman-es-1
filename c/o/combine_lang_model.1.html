NOMBRE

combine_lang_model - genera un archivo traineddata de inicio

SINOPSIS

combine_lang_model --input_unicharset archivo --script_dir directorio --output_dir directorio_raiz --lang idioma [--lang_is_rtl] [pass_through_recoder] [--words archivo --puncs archivo --numbers archivo]

DESCRIPCIÓN

combine_lang_model(1) genera un archivo traineddata de inicio que puede ser utilizado para entrenar un modelo de red neuronal basado en LSTM. Toma como entrada un conjunto de caracteres (unicharset) y un conjunto opcional de listas de palabras. Elimina la necesidad de ejecutar set_unicharset_properties(1), wordlist2dawg(1), un binario no existente para generar el codificador (compresor unicode) y, finalmente, combine_tessdata(1).

OPCIONES

--lang idioma

El idioma a utilizar. Tesseract usa códigos de idioma ISO 639-2 de 3 caracteres. (Ver IDIOMAS)

--script_dir RUTA

Nombre del directorio para los unicharsets de script de entrada. Debería apuntar a la ubicación del directorio langdata (repositorio de GitHub). (tipo:cadena valor por defecto:)

--input_unicharset ARCHIVO

El unicharset a completar y utilizar en la codificación. Puede ser un archivo creado manualmente con campos incompletos. Sus propiedades básicas y de script serán establecidas antes de ser utilizadas. (tipo:cadena valor por defecto:)

--lang_is_rtl BOOLEANO

Verdadero si el idioma que se está procesando se escribe de derecha a izquierda (ej. árabe/hebreo). (tipo:booleano valor por defecto:falso)

--pass_through_recoder BOOLEANO

Si es verdadero, el codificador es una simple pasada del unicharset. De lo contrario, potencialmente una compresión del mismo codificando Hangul en Jamos, descomponiendo símbolos multi-unicode en secuencias de unicodes y codificando Han usando los datos en radical_table_data, que debe ser el contenido del archivo: langdata/radical-stroke.txt. (tipo:booleano valor por defecto:falso)

--version_str CADENA

Una etiqueta de versión arbitraria para añadir al archivo traineddata (tipo:cadena valor por defecto:)

--words ARCHIVO

(Opcional) Archivo que lista las palabras a utilizar para el diccionario del sistema (tipo:cadena valor por defecto:)

--numbers ARCHIVO

(Opcional) Archivo que lista los patrones de números (tipo:cadena valor por defecto:)

--puncs ARCHIVO

(Opcional) Archivo que lista los patrones de puntuación. Las listas de palabras/puntuación/números pueden estar todas vacías. Si alguna no está vacía, entonces puncs debe ser no vacío. (tipo:cadena valor por defecto:)

--output_dir RUTA

Directorio raíz para los archivos de salida. Los archivos de salida se escribirán en <output_dir>/<idioma>/<idioma>.* (tipo:cadena valor por defecto:)

HISTORIA

combine_lang_model(1) se puso a disposición por primera vez para tesseract4.00.00alpha.
