NOMBRE

coin_navigation - Clases de navegación


- Estas contienen la implementación real del sistema de navegación basado en ScXML.

SINOPSIS

Clases


clase SoScXMLNavigation
Clase estática para algunas funciones estáticas de inicialización/limpieza/sincronización. clase SoScXMLNavigationTarget
clase base para los servicios de destino de eventos SCXML del sistema de navegación clase SoScXMLPanTarget
Destino de eventos del sistema de navegación para operaciones de paneo. clase SoScXMLRotateTarget
Destino de eventos del sistema de navegación para operaciones de rotación. clase SoScXMLSeekTarget
Destino de eventos del sistema de navegación para operaciones de búsqueda. clase SoScXMLSpinTarget
Destino de eventos del sistema de navegación para operaciones de giro. clase SoScXMLZoomTarget
Servicio de destino de eventos SCXML para el comportamiento de zoom. clase SoScXMLDollyTarget
Servicio de destino de eventos SCXML para el comportamiento de zoom. clase SoScXMLMiscTarget
Funciones de utilidad de navegación misceláneas. clase SoScXMLFlightControlTarget
Servicio de navegación SCXML para movimientos de vuelo típicos. clase SoScXMLMotionTarget
para ser usado en paralelo con otros destinos no móviles cuando se implementan estados paralelos.
