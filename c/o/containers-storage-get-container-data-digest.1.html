containers-storage-get-container-data-digest 1 de agosto de 2017

NOMBRE

containers-storage get-container-data-digest - Recupera el resumen de un elemento de datos externo

SINOPSIS

containers-storage get-container-data-digest nombre_o_ID_contenedor nombre_datos

DESCRIPCIÓN

Imprime el resumen del elemento de datos con nombre que está asociado con el contenedor especificado.

EJEMPLO

containers-storage get-container-data-digest mi-contenedor manifest.json
