La función confstr() devolverá valores de cadena definidos por la configuración. Su uso y propósito son similares a los de sysconf(), pero se utiliza donde se devuelven valores de cadena en lugar de valores

numéricos.

Si len no es 0, y si name tiene un valor definido por la configuración, confstr() copiará ese valor en el búfer de len bytes apuntado por buf. Si la cadena a devolver es más larga que len bytes, incluyendo el nulo final, entonces confstr() truncará la cadena a len-1 bytes y terminará el resultado con un nulo. La aplicación puede detectar que la cadena fue truncada comparando el valor devuelto por confstr() con len

.

Si len es 0 y buf es un puntero nulo, entonces confstr() aún devolverá el valor entero definido a continuación, pero no devolverá una cadena. Si len es 0 pero buf no es un puntero nulo, el resultado es

indeterminado.

APLICACIONES

Una aplicación puede distinguir entre un valor de parámetro name inválido y uno que corresponde a una variable configurable que no tiene un valor definido por la configuración, verificando si errno es modificado. Esto refleja el comportamiento de sysconf

().

La necesidad original de esta función era proporcionar una forma de encontrar el valor por defecto definido por la configuración para la variable de entorno PATH. Dado que PATH puede ser modificada por el usuario para incluir directorios que podrían contener utilidades que reemplacen a las utilidades estándar en el volumen de Shell y Utilidades de POSIX.1‐2017, las aplicaciones necesitan una forma de determinar el valor de la variable de entorno PATH proporcionado por el sistema que contiene la ruta de búsqueda correcta para las utilidades

estándar.

Una aplicación podría

usar: 
confstr(name,
(char *)NUL
L, (size_t)0)

para averiguar qué tan grande debe ser el búfer para el valor de la cadena; usar malloc() para asignar un búfer que contenga la cadena; y llamar a confstr() de nuevo para obtener la cadena. Alternativamente, podría asignar un búfer estático fijo lo suficientemente grande para contener la mayoría de las respuestas (quizás 512 o 1024 bytes), pero luego usar malloc() para asignar un búfer más grande si

encuentra que este
es demasiado pequeño.

A

Los desarrolladores de aplicaciones normalmente pueden determinar cualquier variable de configuración mediante la lectura del flujo abierto por una llamada

a:

La función confstr() con un argumento name de _CS_PATH devuelve una cadena que puede usarse como una configuración de la variable de entorno PATH que referenciará el shell y las utilidades estándar como se describe en el volumen de Shell y Utilidades de POSIX.

1‐2017.

La función confstr() copia la cadena devuelta en un búfer proporcionado por la aplicación en lugar de devolver un puntero a una cadena. Esto permite una funci

ón más limpia en algunas implementaciones (como aquellas con hilos ligeros) y
resuelve preguntas sobre cuándo la aplicación debe copiar la cadena devuelta.
