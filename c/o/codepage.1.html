NOMBRE

codepage - extraer una página de códigos de un archivo de página de códigos de MSDOS

SINOPSIS

codepage [ -c | -l | -L | -a | nnn ] archivo.cpi

DESCRIPCIÓN

El comando codepage extrae páginas de códigos de un archivo de página de códigos de MSDOS.

OPCIONES

-c
El archivo de entrada es una única página de códigos.
-L
Imprimir información de cabecera (no querrás ver esto).
-l
Listar todas las páginas de códigos contenidas en el archivo.
-a
Extraer todas las páginas de códigos del archivo.
nnn
(3 dígitos): extraer la página de códigos nnn del archivo.

EJEMPLO

Para crear un archivo 850.cp, con la página de códigos 850 de un archivo ega.cpi, ejecuta:

codepage ega.cpi 850
