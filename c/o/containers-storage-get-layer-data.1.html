containers-storage-get-layer-data 1 Diciembre 2020

NOMBRE

containers-storage get-layer-data - Recuperar datos externos para una capa

SINOPSIS

containers-storage get-layer-data [opciones [...]] IDdeCapa NombreDatos

DESCRIPCIÓN

Recupera una pieza de datos con nombre que está asociada con una capa.

OPCIONES

-f | --file archivo

Escribe los datos en un archivo en lugar de stdout.

EJEMPLO

containers-storage get-layer-data -f config.json 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824 configuration
