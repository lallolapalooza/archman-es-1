NOMBRE

cockpit - Cockpit

DESCRIPCIÓN

Cockpit es una interfaz de administración interactiva accesible por web para máquinas Linux. Cockpit suele ser accesible en el puerto 9090 de la máquina en la que está instalado. Cockpit se inicia bajo demanda. Utiliza tus credenciales del sistema para iniciar sesión.

COMPONENTES

El servicio web cockpit-ws escucha en el puerto 9090 y es iniciado bajo demanda por systemd. El servicio web Cockpit autentica al usuario, carga Cockpit en el navegador e inicia cockpit-bridge en una sesión de usuario de Linux.

El cockpit-bridge proporciona acceso a las APIs del sistema a Cockpit en el navegador web. Lo hace a través de sus entradas y salidas estándar. El puente se inicia como un shell una vez por sesión de usuario de Linux.
