NOMBRE

collateindex.pl - genera archivos de índice DocBook

SINOPSIS

collateindex.pl [-f] [-g] [-i id] [-I ámbito] [-N]
[-o archivo] [-p] [-P archivo] [-q] [-s nombre]
[-S ámbito] [-t nombre] [-x] archivo

DESCRIPCIÓN

collateindex.pl crea datos de índice para archivos DocBook XML o SGML.

OPCIONES

-f
Forzar la escritura del archivo de salida, incluso si parece haber sido editado manualmente.
-g
Agrupar términos con IndexDiv basándose en la primera letra del término (o su atributo SortAs). (Esto podría no manejar todos los entornos lingüísticos).
-i id
El ID a usar para la etiqueta <index>.
-I ámbito
El ámbito implícito, debe ser "all", "local", o "global". Los IndexTerms que no especifiquen un ámbito tendrán el ámbito implícito. Si no se especifica, se asume "all".
-N
Índice nuevo (genera un archivo de índice vacío).
-o archivo
Salida a archivo. Por defecto es stdout.
-p
Enlazar a puntos en el documento. La opción por defecto es enlazar a la sección contenedora más cercana.
-P archivo
Leer un preámbulo del archivo archivo. El contenido de archivo se insertará antes de la etiqueta <index>.
-q
Ejecutar en modo silencioso.
-s nombre
Nombrar el IndexDiv que contiene símbolos. El valor por defecto es "Symbols". Sin sentido si no se usa -g.
-S ámbito
Ámbito del índice, debe ser "all", "local", o "global". Si no se especifica, se asume "all".
-t nombre
Título para el índice.
-x
Crear un SetIndex.
-V
Mostrar el número de versión y salir.
archivo
El archivo que contiene los datos del índice generados con la hoja de estilos HTML DocBook DSSSL (normalmente llamado HTML.index).

EJEMPLO

collateindex.pl -o index.sgml HTML.index
