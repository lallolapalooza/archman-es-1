DESCRIPCIÓN Los objetos Config pr

estilo unix. El espacio en blanco inicial (espacios y tabuladores) se elimina de las líneas procesadas. Si una línea termina en una barra invertida (\), entonces la barra invertida se elimina y la siguiente línea (con el espacio en blanco inicial eliminado) se

añade a la línea actual.

Si la bandera rmComment está establecida

en

true, se eliminan las líneas en blanco y la información de las líneas desde el primer #. Si una barra invertida precede al carácter de comentario (es decir, \#), entonces esto no se considera comentario, sino que se reemplaza por un solo carácter #. De manera similar, si la bandera rmComment estaba establecida, dos caracteres de barra invertida consecutivos se reemplazan por un solo carácter de barra invertida. Todas las líneas del archivo de configuración (posiblemente sin comentarios) se almacenan en

el

objeto Config. Sus números de línea también pueden ser recuperados. En el momento de la construcción, el manejo de comentarios (mantener comentario / eliminar comentario) y el tipo de búsqueda (sensible a mayúsculas/minúsculas / insensible) pueden ser

especificados.

Además de uno de los constructores,

el

miembro load puede ser usado para procesar un archivo de configuración, reemplazando el contenido actual del objeto por el contenido de otro archivo de configuración. El miembro load no puede ser usado para alterar los parámetros de procesamiento del archivo de configuración, pero la asignación sobrecargada es soportada y el manejo de comentarios y de mayúsculas/minúsculas puede ser modificado por miembros set. A menudo las líneas en la configuración muestran la siguiente

estructura:

id: valor contenido restante

Si 
    id es
un identificador C++ se le llama un ID en esta página del manual. Al buscar IDs, todos los caracteres no blancos que siguen inmediatamente al ID son ignorados (en el ejemplo el ID es id). Una Clave está definida como la primera entrada delimitada por espacios en blanco en las líneas. En el ejemplo la clave es id:. La primera entrada delimitada por espacios que sigue a la clave se llama el valor de la línea, mientras que todo el contenido de la línea que comienza en valor se llama la cola de la línea. Los objetos Config ofrecen varios miembros para procesar líneas de archivos de configuración que están estructuradas de esta manera. Sin embargo, las líneas no tienen que estar estructuradas de esta manera. Todas las líneas de un archivo de configuración son puestas a disposición por los

objetos Config y pueden ser procesadas de varias otras maneras también. ESPACIO D

#include <iostream>

int main(int argc, char **argv)

    Config cf(argv[1]);
    cout << *cf.find("this one") << ’\n’; // find text within a line
