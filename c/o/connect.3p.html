CONNECT(3P) Manual de Programador POSIX CONNECT(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

connect — conectar un socket

SINOPSIS

#include <sys/socket.h>
int connect(int socket, const struct sockaddr *address,
    socklen_t address_len);

DESCRIPCIÓN

La función connect() intentará establecer una conexión en un socket de modo de conexión o establecer o restablecer la dirección del par en un socket de modo sin conexión. La función toma los siguientes argumentos:

socket
Especifica el descriptor de archivo asociado con el socket.
address
Punta a una estructura sockaddr que contiene la dirección del par. La longitud y el formato de la dirección dependen de la familia de direcciones del socket.
address_len
Especifica la longitud de la estructura sockaddr a la que apunta el argumento address.

Si el socket aún no se ha vinculado a una dirección local, connect() lo vinculará a una dirección que, a menos que la familia de direcciones del socket sea AF_UNIX, sea una dirección local no utilizada.

Si el socket que inicia la conexión no es de modo de conexión, entonces connect() establecerá la dirección del par del socket y no se establecerá ninguna conexión. Para los sockets SOCK_DGRAM, la dirección del par identifica dónde se enviarán todos los datagramas en las posteriores llamadas a send(), y limita el remitente remoto para las posteriores llamadas a recv(). Si el miembro sa_family de address es AF_UNSPEC, la dirección del par del socket se restablecerá. Tenga en cuenta que a pesar de no establecerse ninguna conexión, el término "conectado" se utiliza para describir un socket sin conexión para el cual se ha establecido una dirección de par.

Si el socket que inicia la conexión es de modo de conexión, entonces connect() intentará establecer una conexión a la dirección especificada por el argumento address. Si la conexión no se puede establecer inmediatamente y O_NONBLOCK no está establecido para el descriptor de archivo del socket, connect() se bloqueará hasta un intervalo de tiempo de espera no especificado hasta que se establezca la conexión. Si el intervalo de tiempo de espera expira antes de que se establezca la conexión, connect() fallará y el intento de conexión se abortará. Si connect() es interrumpido por una señal que se captura mientras está bloqueado esperando establecer una conexión, connect() fallará y establecerá errno en [EINTR], pero la solicitud de conexión no se abortará y la conexión se establecerá de forma asíncrona.

Si la conexión no se puede establecer inmediatamente y O_NONBLOCK está establecido para el descriptor de archivo del socket, connect() fallará y establecerá errno en [EINPROGRESS], pero la solicitud de conexión no se abortará y la conexión se establecerá de forma asíncrona. Las llamadas posteriores a connect() para el mismo socket, antes de que se establezca la conexión, fallarán y establecerán errno en [EALREADY].

Cuando la conexión se ha establecido de forma asíncrona, pselect(), select() y poll() indicarán que el descriptor de archivo del socket está listo para escritura.

El socket utilizado puede requerir que el proceso tenga los privilegios apropiados para usar la función connect().

VALOR DE RETORNO

Tras una finalización exitosa, connect() devolverá 0; de lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función connect() fallará si:

EADDRNOTAVAIL

La dirección especificada no está disponible desde la máquina local.
EAFNOSUPPORT

La dirección especificada no es una dirección válida para la familia de direcciones del socket especificado.
EALREADY
Ya hay una solicitud de conexión en curso para el socket especificado.
EBADF
El argumento socket no es un descriptor de archivo válido.
ECONNREFUSED

La dirección de destino no estaba escuchando conexiones o rechazó la solicitud de conexión.
EINPROGRESS
O_NONBLOCK está establecido para el descriptor de archivo del socket y la conexión no se puede establecer inmediatamente; la conexión se establecerá de forma asíncrona.
EINTR
El intento de establecer una conexión fue interrumpido por la entrega de una señal que fue capturada; la conexión se establecerá de forma asíncrona.
EISCONN
El socket especificado es de modo de conexión y ya está conectado.
ENETUNREACH

No existe ruta hacia la red.
ENOTSOCK
El argumento socket no se refiere a un socket.
EPROTOTYPE
La dirección especificada tiene un tipo diferente al del socket vinculado a la dirección del par especificada.
ETIMEDOUT
El intento de conexión expiró antes de que se realizara la conexión.

Si la familia de direcciones del socket es AF_UNIX, entonces connect() fallará si:

EIO
Ocurrió un error de E/S al leer o escribir en el sistema de archivos.
ELOOP
Existe un bucle en los enlaces simbólicos encontrados durante la resolución de la ruta en address.
ENAMETOOLONG

La longitud de un componente de una ruta es mayor que {NAME_MAX}.
ENOENT
Un componente de la ruta no nombra un archivo existente o la ruta es una cadena vacía.
ENOTDIR
Un componente del prefijo de ruta de la ruta en address nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio, o la ruta en address contiene al menos un carácter que no es <barra> y termina con una o más barras finales <barra> y el último componente de ruta nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio.

La función connect() puede fallar si:

EACCES
Se niega el permiso de búsqueda para un componente del prefijo de ruta; o se niega el acceso de escritura al socket con nombre.
EADDRINUSE
Intento de establecer una conexión que utiliza direcciones que ya están en uso.
ECONNRESET
El host remoto reinició la solicitud de conexión.
EHOSTUNREACH

No se puede alcanzar el host de destino (probablemente porque el host está apagado o un enrutador remoto no puede alcanzarlo).
EINVAL
El argumento address_len no es una longitud válida para la familia de direcciones; o familia de direcciones inválida en la estructura sockaddr.
ELOOP
Se encontraron más de {SYMLOOP_MAX} enlaces simbólicos durante la resolución de la ruta en address.
ENAMETOOLONG

La longitud de una ruta es mayor que {NAME_MAX}.

La longitud de una ruta de acceso excede {PATH_MAX}, o la resolución de la ruta de acceso de un enlace simbólico produjo un resultado intermedio con una longitud que excede {PATH_MAX}.
