Config::Grammar::Dynamic(3) Documentación de Perl contribuida por el usuario Config::Grammar::Dynamic(3)

NOMBRE

Config::Grammar::Dynamic - un analizador de configuración basado en gramática y fácil de usar

DESCRIPCIÓN

Config::Grammar::Dynamic es similar a Config::Grammar pero con algunas características adicionales útiles para construir gramáticas de configuración que son dinámicas, es decir, donde la sintaxis cambia según las entradas de configuración en el mismo archivo.

Las siguientes claves se pueden especificar adicionalmente en la gramática al usar este módulo:

Claves Especiales de Sección

_dyn
Una referencia a una subrutina (puntero de función) que se llamará cuando se encuentre una nueva sección de esta sintaxis. La subrutina recibirá tres argumentos: la sintaxis del nombre de la sección (cadena o regexp), el nombre real encontrado (este será el mismo que el primer argumento para secciones no regexp) y una referencia al árbol de gramática de la sección. Esta subrutina puede modificar el árbol de gramática dinámicamente.
_dyndoc
Una referencia a un hash que enumera nombres interesantes para la sección que deben documentarse. Las claves del hash son los nombres y los valores del hash son cadenas que pueden contener una explicación del nombre. Luego, la subrutina _dyn() se llama para cada uno de estos nombres y se documentan las diferencias de la gramática resultante y la original. Actualmente, este módulo puede documentar diferencias en la lista _vars, enumerando las variables nuevas y eliminadas, y diferencias en la lista _sections, enumerando las secciones nuevas y eliminadas.
_recursive
Array que contiene la lista de aquellas subsecciones que son *recursivas*, es decir, que pueden contener una nueva subsección con la misma sintaxis que ellas mismas.

El mismo efecto se puede lograr con referencias circulares en el árbol de gramática o una subrutina de sección _dyn adecuada (ver más abajo), por lo que esta funcionalidad se incluye solo por conveniencia.

Claves Especiales de Variables

_dyn
Una referencia a una subrutina (puntero de función) que se llamará cuando la variable se asigne algún valor en el archivo de configuración. La subrutina recibirá tres argumentos: el nombre de la variable, el valor asignado y una referencia al árbol de gramática de esta sección. Esta subrutina puede modificar el árbol de gramática dinámicamente.

Tenga en cuenta que no se realiza ninguna llamada _dyn() para los valores predeterminados y heredados de la variable.

_dyndoc
Una referencia a un hash que enumera valores interesantes para la variable que deben documentarse. Las claves del hash son los valores y los valores del hash son cadenas que pueden contener una explicación del valor. Luego, la subrutina _dyn() se llama para cada uno de estos valores y se documentan las diferencias de la gramática resultante y la original. Actualmente, este módulo puede documentar diferencias en la lista _vars, enumerando las variables nuevas y eliminadas, y diferencias en la lista _sections, enumerando las secciones nuevas y eliminadas.
