Config::Extensions(3perl) Guía del programador de Perl Config::Extensions(3perl)

NOMBRE

Config::Extensions - búsqueda en hash de las extensiones principales compiladas.

SINOPSIS

use Config::Extensions '%Extensions';
if ($Extensions{PerlIO::via}) {
    # Este perl tiene PerlIO::via compilado
}

DESCRIPCIÓN

El módulo Config::Extensions proporciona un hash %Extensions que contiene todas las extensiones principales que se habilitaron para este perl. El hash se indexa por el nombre de la extensión, y cada entrada tiene uno de los 3 valores posibles:

dinamica
La extensión está enlazada dinámicamente.
no_xs
La extensión es perl puro, por lo que no necesita enlazarse al ejecutable de perl.
estatica
La extensión está enlazada estáticamente a la binaria de perl.

Como todos los valores son verdaderos, una simple prueba "if" es suficiente para determinar si una extensión está presente.

Todos los datos utilizados para generar el hash %Extensions ya están presentes en el módulo "Config", pero no en un formato tan conveniente para una referencia rápida.
