containerd(8) Manual del Administrador del Sistema containerd(8)

NOMBRE

containerd

SINOPSIS

containerd

[--direccion|-a]=[valor]
[--config|-c]=[valor]
[--nivel-log|-l]=[valor]
[--root]=[valor]
[--state]=[valor]

DESCRIPCIÓN

containerd es un tiempo de ejecución de contenedores de alto rendimiento cuyo demonio puede iniciarse utilizando este comando. Si no se especifican los comandos config, publish, oci-hook o help, la acción predeterminada del comando containerd es iniciar el demonio containerd en primer plano.

Se utiliza una configuración predeterminada si no se especifica una configuración TOML o si no se encuentra en la ubicación de archivo predeterminada. El comando containerd config se puede utilizar para generar la configuración predeterminada para containerd. La salida de ese comando se puede utilizar y modificar según sea necesario como una configuración personalizada.

Uso:

containerd [OPCIONES GLOBALES] comando [OPCIONES DEL COMANDO] [ARGUMENTOS...]

OPCIONES GLOBALES

--address, -a="": Dirección del servidor GRPC de containerd

--config, -c="": Ruta al archivo de configuración (predeterminado: "/etc/containerd/config.toml")

--log-level, -l="": Establecer el nivel de registro [trace, debug, info, warn, error, fatal, panic]

--root="": Directorio raíz de containerd

--state="": Directorio de estado de containerd

COMANDOS

config

Información sobre la configuración de containerd

default

Ver la salida de la configuración predeterminada

dump

Ver la salida de la configuración principal final con subconfiguraciones importadas en los archivos

migrate

Migrar el archivo de configuración actual a la última versión (no migra los archivos de subconfiguración)

publish

Binario para publicar eventos en containerd

--namespace="": Espacio de nombres al que publicar

--topic="": Tema del evento

oci-hook

Proporciona una base para los ganchos de tiempo de ejecución de OCI para permitir la inyección de argumentos.
