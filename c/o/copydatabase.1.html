COPYDATABASE(1) Comandos de usuario COPYDATABASE(1)

NOMBRE

copydatabase - Realiza una copia documento por documento de una o más bases de datos Xapian

SINOPSIS

copydatabase BASE_DE_DATOS_ORIGEN... BASE_DE_DATOS_DESTINO

DESCRIPCIÓN

copydatabase - Realiza una copia documento por documento de una o más bases de datos Xapian

OPCIONES

--no-renumber
Preserva la numeración de los IDs de documentos (útil si tienes referencias externas a ellos, o si los has establecido para que coincidan con IDs únicos de una fuente externa). Si se especifican múltiples bases de datos de origen y el mismo ID de documento se encuentra en más de una, la última ocurrencia será la que termine en la base de datos de destino.
