COS(3P) Manual del programador POSIX COS(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

cos, cosf, cosl — función coseno

SINOPSIS

#include <math.h>
double cos(double x);
float cosf(float x);
long double cosl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones calcularán el coseno de su argumento x, medido en radianes.

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, se ha producido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el coseno de x.

Si x es NaN, se devolverá un NaN.

Si x es ±0, se devolverá el valor 1.0.

Si x es ±Inf, se producirá un error de dominio y se devolverá un NaN.

ERRORES

Estas funciones fallarán si:

Error de Dominio
El argumento x es ±Inf.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se generará la excepción de punto flotante inválida.

Las siguientes secciones son informativas.

EJEMPLOS

Tomando el Coseno de un Ángulo de 45 Grados

#include <math.h>
...
double radianes = 45 * M_PI / 180;
double resultado;
...
resultado = cos(radianes);

USO DE LA APLICACIÓN

Estas funciones pueden perder precisión cuando su argumento está cerca de un múltiplo impar de π/2 o está lejos de 0.

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.

FUNDAMENTACIÓN

Ninguna.

DIRECCIONES FUTURAS

Ninguna.
