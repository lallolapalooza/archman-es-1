NOMBRE

COMMIT PREPARED - confirma una transacción que fue preparada anteriormente para confirmación en dos fases

SINOPSIS

COMMIT PREPARED id_transaccion

DESCRIPCIÓN

COMMIT PREPARED confirma una transacción que se encuentra en estado preparado.

PARÁMETROS

id_transaccion

El identificador de la transacción que se va a confirmar.

NOTAS

Para confirmar una transacción preparada, debe ser el mismo usuario que ejecutó la transacción originalmente, o un superusuario. Pero no es necesario estar en la misma sesión que ejecutó la transacción.

Este comando no se puede ejecutar dentro de un bloque de transacción. La transacción preparada se confirma inmediatamente.

Todas las transacciones preparadas disponibles actualmente se enumeran en la vista del sistema pg_prepared_xacts.

EJEMPLOS

Confirmar la transacción identificada por el identificador de transacción foobar:

COMMIT PREPARED 'foobar';

COMPATIBILIDAD

COMMIT PREPARED es una extensión de PostgreSQL. Está destinado a ser utilizado por sistemas externos de gestión de transacciones, algunos de los cuales están cubiertos por estándares (como X/Open XA), pero el lado SQL de esos sistemas no está estandarizado.

VER TAMBIÉN

PREPARE TRANSACTION (PREPARE_TRANSACTION(7)), ROLLBACK PREPARED (ROLLBACK_PREPARED(7))
