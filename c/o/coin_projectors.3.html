NOMBRE

coin_projectors - Clases de proyectores


- Las clases de proyectores se utilizan para convertir entre ubicaciones en el espacio de pantalla (2D) y ubicaciones en el espacio del mundo (3D).

SINOPSIS

Clases


class SbCylinderPlaneProjector
La clase SbCylinderPlaneProjector proyecta puntos 2D a un semicilindro y un plano. class SbCylinderProjector
La clase SbCylinderProjector es la clase base abstracta para mapear a superficies cilíndricas. class SbCylinderSectionProjector
La clase SbCylinderSectionProjector proyecta puntos 2D a una sección cilíndrica. class SbCylinderSheetProjector
La clase SbCylinderSheetProjector proyecta puntos 2D a puntos 3D en una lámina que cubre una forma cilíndrica. class SbLineProjector
La clase SbLineProjector proyecta puntos 2D a puntos 3D a lo largo de una línea. class SbPlaneProjector
La clase SbPlaneProjector proyecta puntos 2D a puntos 3D en un plano. class SbProjector
La clase SbProjector es la clase base abstracta del proyector. class SbSpherePlaneProjector
La clase SbSpherePlaneProjector proyecta puntos 2D a una semiesfera y un plano. class SbSphereProjector
La clase SbSphereProjector es la clase base abstracta para mapear a superficies esféricas. class SbSphereSectionProjector
La clase SbSphereSectionProjector proyecta puntos 2D a una esfera cortada. class SbSphereSheetProjector
La clase SbSphereSheetProjector proyecta puntos 2D a puntos 3D en una lámina que cubre una forma esférica.

DESCRIPCIÓN DETALLADA

Las clases de proyectores se utilizan para convertir entre ubicaciones en el espacio de pantalla (2D) y ubicaciones en el espacio del mundo (3D).

Se utilizan principalmente en relación con la interacción del usuario con el ratón en la ventana de visualización.
