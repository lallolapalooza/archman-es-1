coin310 - Nuevas características en Coin v3.1.0

Este es un breve resumen de las nuevas características en Coin v3.1.0:

  • El tipo de transparencia predeterminado para SoGLRenderAction cambió de SCREEN_DOOR a BLEND.
  • SoBase ya no mantendrá una lista de nodos sin nombre/con nombre vacío. Esto es tanto una optimización como una mejora de la conformidad con SGI / TGS Inventor.
  • SbTesselator funciona mejor cuando se le entregan ciertos polígonos, debido a una mejor precisión en los cálculos internos.
  • La presión de uso de recursos es significativamente menor para gráficos de escenas de uso común con respecto a las asignaciones de mutex. Un problema no del todo infrecuente en sistemas MS Windows para gráficos de escenas enormes era que el sistema en tiempo de ejecución se quedaba sin mutexes disponibles; esto ahora es muy poco probable que ocurra.
  • Las compilaciones con G++ y MSVC tendrán el soporte de excepciones C++ habilitado por defecto.
  • La llamada de retorno de renderizado de SoSceneManager se puede establecer en NULL para deshabilitarla.
  • Las texturas no potencias de dos se soportan automáticamente si el controlador de OpenGL tiene esa característica.
  • No hay otras diferencias intencionales en semántica, aparte de los errores corregidos.
