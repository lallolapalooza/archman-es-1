Opciones Comunes al Convertir desde MODS

Tenga en cuenta que --output-encoding se refiere al archivo de entrada

-h --help muestra la ayuda
-v --version muestra la versión
-o --output-encoding interpreta el archivo de entrada como usando el conjunto de caracteres solicitado (usar sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-s --single-refperfile coloca una referencia por nombre de archivo según el número de referencia
-nb --no-bom no escribe Byte Order Mark si escribe UTF8

xml2bib

xml2bib convierte la bibliografía MODS XML en un archivo de referencia con formato bibtex. El uso de xml2bib es como para otras herramientas

xml2bib xml_file.xml > output_file.bib

Dado que el formato de referencia BibTeX es bastante flexible y parece tener el mayor número de preferencias personales, también ha acumulado una serie de opciones específicas que no están disponibles para otros formatos.

A partir de la versión 3.24, la salida de xml2bib utiliza etiquetas en minúsculas y tipos de referencia en mayúsculas y minúsculas mixtas para una mejor interacción con otro software. El comportamiento anterior con etiquetas/tipos de referencia completamente en mayúsculas todavía se puede generar usando el modificador de línea de comandos -U/--uppercase.

Opciones específicas de xml2bib:

-fc --finalcomma agrega una coma final en la salida bibtex para aquellos que la deseen
-sd --singledash usa un guion en lugar de dos (guion más largo en latex) entre números en la salida de páginas
-b --brackets usa corchetes en lugar de comillas alrededor de los datos del campo
-w --whitespace agrega espacios en blanco embellecedores a la salida
-U --uppercase usa mayúsculas completas para etiquetas (nombres de campo) y tipos de referencia (comportamiento anterior a la versión 3.24)
-sk --strictkey usa solo caracteres alfanuméricos para las claves de cita bibtex

xml2ads

xml2ads convierte la bibliografía MODS XML al formato de referencia del Astrophysics Data System (ADS) de la Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) (que es muy similar al estilo Endnote etiquetado). El uso de xml2ads es como para otras herramientas

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convierte la bibliografía MODS XML en un archivo de bibliografía con formato RIS. El uso de xml2ris es como para otras herramientas

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convierte la bibliografía MODS XML en un archivo de bibliografía Endnote etiquetado (formato refer). El uso de xml2end es como para otras herramientas

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib convierte la bibliografía MODS XML en un archivo de bibliografía XML con formato Word 2007. El uso de xml2wordbib es como para otras herramientas

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib se llamaba xml2word en versiones de bibutils anteriores a la 3.40. Se le cambió el nombre para evitar confusiones con otras herramientas. Esperemos que esto no rompa demasiados scripts ya en uso.
