DESCRIPCIÓ

N 
TNEF significa Transport Neutral Encapsulation Format (Formato de encapsulación neutral de transporte), y si alguna vez has tenido la desgracia de recibir uno de estos archivos como adjunto de correo electrónico, es posible que desees usar este módulo.
read() toma como primer argumento cualquier manejador de archivo abierto para lectura. El segundo argumento opcional es una referencia a un hash que contiene una o más de las siguientes
claves: 

output_dir - Ruta para almacenar los datos de atributos TNEF que se guardan en archivos (por defecto: directorio actual).
output_prefix - Prefijo de archivo para los datos de atributos TNEF que se guardan en archivos (por defecto: 'tnef').
output_to_core - Los datos de atributos TNEF se guardarán en la memoria principal a menos que superen este número de bytes (por defecto: 4096). También se puede establecer en 'NONE' para mantener todos los datos en archivos, o en 'ALL' para mantener todos los datos en la memoria principal.
buffer_size - Tamaño del búfer para leer el archivo TNEF (por defecto: 1024).
debug - Si es verdadero, muestra todo tipo de información sobre lo que la función read() está leyendo, incluyendo los datos ASCII en bruto junto con los datos convertidos a hexadecimal (por defecto: falso).
display_after_err - Si debug es verdadero y se encuentra un error, lee y muestra este número de bytes de datos que sigu
en al error (por defecto: 32). debug_max_display - Si debug es verdadero, entonces se leerán y mostrarán como máximo este número de bytes de datos para cada atributo TNEF (por defecto: 1024). debug_max_line_size - Si debug es verdadero, entonces se mostrarán como máximo este número de bytes de datos en cada línea para cada atributo TNEF (por defecto: 64). ignore_checksum - Si es verdadero, ignorará los errores de suma de verificación al analizar los datos (por defecto: falso). read() devuelve un objeto que contiene los 'atributos' TNEF leídos del archivo y los datos de esos atributos. Si todo lo que quieres son los adjuntos, entonces esto es en su mayor parte basura, pero si te interesa, puedes ver toda la basura activando la depuración. Si la basura te resulta útil, entonces házmelo saber para ver si puedo hacerla más útil. Si se encuentra un error, se devuelve un valor indefinido y la variable de paquete $errstr se esta
blece en algún mensaje útil. read_in() es una conveniente interfaz frontal para read() que toma un nombre de archivo en lugar de un manejador. read_ent() es otra conveniente interfaz frontal para read() que puede tomar un objeto MIME::Entity (o cualquier objeto con métodos similares, específicamente open("r"), read($buff,$num_bytes), y close). purge() elimina cualquier dato en disco que pueda estar en los adjuntos del objeto TNEF. message() devuelve la parte del mensaje del objeto tnef, si existe. Lo que devuelve es como un adjunto, pero no es un adjunto. Por ejemplo, muy probablemente no tiene un nombre ni ningún dato de adjunto. attachments() devuelve una lista de los adjuntos que contiene el objeto TNEF dado. Devuelve una referencia a lista si no se llama en contexto de arreglo. data() toma un nombre de atributo TNEF y devuelve un valor de cadena para ese atributo de ese adjunto. Es tu propio problema si la cadena es
demasiado grande para la memoria. Si no se da ningún argumento, se asume el atributo 'AttachData', que probablemente es el dato de adjunto que estás buscando. name() es lo mismo que data(), excepto que el atributo 'AttachTitle' es el predeterminado, que devuelve el nombre del adjunto de 8 caracteres + extensión de 3 caracteres. longname() devuelve el nombre de archivo largo y la extensión de un adjunto. Esto está incrustado dentro de una propiedad MAPI de los datos del atributo 'Attachment', por lo que intentamos extraer el nombre de ahí. size() toma un nombre de atributo TNEF y devuelve el tamaño en bytes de los datos para ese atributo de adjunto. datahandle() es un método para adjuntos que toma un nombre de atributo TNEF y devuelve los datos de ese atributo como un manejador que es igual a un manejador MIME::Body. Consulta MIME::Body para todos los métodos aplicables. Si no se da ningún argumento, se asume 'AttachData'.

EJEMPLO

S 
# Aquí hay un ejemplo bastante largo donde el correo se recupera
# de un servidor POP3 basado en la información de los encabezados, luego
# se analiza como MIME, y luego se extraen y convierten
# los contenidos TNEF.
use strict;
use Net::POP3;
use MIME::Parser;
use Convert::TNEF;
my $mail_dir = "mailout";
my $mail_prefix = "mail";
my $pop = new Net::POP3 ( "pop3server_name" );
my $num_msgs = $pop->login("user_name","password");
die "Can't login: $!" unless defined $num_msgs;
# Get mail by sender and subject
my $mail_out_idx = 0;
MESSAGE: for ( my $i=1; $i<= $num_msgs;  $i++ ) {
 my $header = join "", @{$pop->top($i)};
 for ($header) {
  next MESSAGE unless
   /^from:.*someone\@somewhere.net/im &&
   /^subject:\s*important stuff/im
 }
 my $fname = $mail_prefix."-".$$.++$mail_out_idx.".doc";
 open (MAILOUT, ">$mail_dir/$fname")
  or die "Can't open $mail_dir/$fname: $!";
 # If the get() complains, you need the new libnet bundle
 $pop->get($i, \*MAILOUT) or die "Can't read mail";
 close MAILOUT or die "Error closing $mail_dir/$fname";
 # If you want to delete the mail on the server
 # $pop->delete($i);
}
close MAILOUT;
$pop->quit();
# Parse the mail message into separate mime entities
my $parser=new MIME::Parser;
$parser->output_dir("mimemail");
opendir(DIR, $mail_dir) or die "Can't open directory $mail_dir: $!";
my @files = map { $mail_dir."/".$_ } sort
 grep { -f "$mail_dir/$_" and /$mail_prefix-$$-/o } readdir DIR;
closedir DIR;
for my $file ( @files ) {
 my $entity=$parser->parse_in($file) or die "Couldn't parse mail";
 print_tnef_parts($entity);
 # If you want to delete the working files
 # $entity->purge;
}
sub print_tnef_parts {
 my $ent = shift;
 if ( $ent->parts ) {
  for my $sub_ent ( $ent->parts ) {
   print_tnef_parts($sub_ent);
  }
 } elsif ( $ent->mime_type =~ /ms-tnef/i ) {
  # Create a tnef object
  my $tnef = Convert::TNEF->read_ent($ent,{output_dir=>"tnefmail"})
   or die $Convert::TNEF::errstr;
  for ($tnef->attachments) {
   print "Title:",$_->name,"\n";
   print "Data:\n",$_->data,"\n";
  }
  # If you want to delete the working files
  # $tnef->purge;
 }
}
