containers-storage-import-layer 1 abril 2019

NOMBRE

containers-storage import-layer - Importar archivos a una nueva capa

SINOPSIS

containers-storage import-layer [opciones [...]] [nombreOIDeCapadePadre]

DESCRIPCIÓN

Este subcomando es una combinación de containers-storage create-layer y containers-storage apply-diff.

Cuando una capa se crea por primera vez con containers-storage create-layer, no contiene ningún cambio en relación con su capa padre. La capa puede montarse en modo lectura-escritura y su contenido modificarse directamente, o se puede añadir (o eliminar) contenido aplicando una diferencia de capa ejecutando containers-storage apply-diff.

OPCIONES

-n nombre

Establece un nombre opcional para la capa. Si ya existe un nombre, se devuelve un error.

-i | --id ID

Establece el ID para la capa. Si no se especifica ninguno, se genera uno.

-f | --file nombrearchivo

Especifica el nombre de un archivo del cual se leerá la diferencia. Si no se utiliza esta opción, la diferencia se lee de la entrada estándar.

-l | --label etiqueta-montaje

Establece la etiqueta que se asignará como contexto SELinux al montar la capa.

-r | --readonly

Marca la capa como de solo lectura.

-j | --json

Prefiere salida en formato JSON.

--uidmap

Mapa de UID especificado en el formato esperado por subuid. No se puede especificar simultáneamente con --hostuidmap.

--gidmap

Mapa de GID especificado en el formato esperado por subgid. No se puede especificar simultáneamente con --hostuidmap.

--hostuidmap

Fuerza el mapa de UID del host. No se puede especificar simultáneamente ni con --uidmap ni con --subuidmap.

--hostgidmap

Fuerza el mapa de GID del host. No se puede especificar simultáneamente ni con --gidmap ni con --subgidmap.

--subuidmap nombredeusuario

Crea un mapa de UID para el nombre de usuario utilizando los datos de /etc/subuid. No se puede especificar simultáneamente con --hostuidmap.

--subgidmap nombrede grupo

Crea un mapa de GID para el nombre de grupo utilizando los datos de /etc/subgid. No se puede especificar simultáneamente con --hostuidmap.

EJEMPLO

containers-storage import-layer -f 71841c97e320d6cde.tar.gz -n nueva-capa capa-anterior
