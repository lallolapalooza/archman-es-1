com_err(3)

Paquete: e2fsprogs

Licencias: GPL, LGPL, MIT

COM_ERR(3) Manual de funciones de biblioteca COM_ERR(3)

NOMBRE

com_err - rutina de visualización de errores común

SINOPSIS

 #include <et/com_err.h>
void (*proc) (const char *, long, const char *, va_list);
void com_err (const char *whoami, long code, const char *format, ...);
proc = set_com_err_hook (proc);
proc = reset_com_err_hook ();
void initialize_XXXX_error_table ();

DESCRIPCIÓN

Com_err muestra un mensaje de error en el flujo de error estándar stderr (ver stdio(3S)) compuesto por la cadena whoami, que debe especificar el nombre del programa o alguna subsección de un programa, seguido de un mensaje de error generado a partir del valor code (derivado de compile_et(1)), y una cadena producida usando la cadena format y cualquier argumento siguiente, en el mismo estilo que fprintf(3).

El comportamiento de com_err se puede modificar usando set_com_err_hook; esto define un procedimiento que se llama con los argumentos pasados a com_err, en lugar del procedimiento interno por defecto que envía el texto formateado a la salida de error. Por lo tanto, los mensajes de error de un programa se pueden desviar fácilmente a otra forma de registro de diagnóstico, como syslog(3). Reset_com_err_hook se puede utilizar para restaurar el comportamiento de com_err a su forma por defecto. Ambos procedimientos devuelven el valor anterior del "hook". Estos procedimientos "hook" deben tener la declaración dada para proc anteriormente en la sinopsis.

La rutina initialize_XXXX_error_table es generada mecánicamente por compile_et(1) a partir de un archivo fuente que contiene nombres y cadenas asociadas. Cada tabla tiene un nombre de hasta cuatro caracteres, que se utiliza en lugar de XXXX en el nombre de la rutina. Estas rutinas deben ser llamadas antes de que se utilicen los códigos de error correspondientes, para que la biblioteca com_err reconozca los códigos de error de estas tablas cuando se utilicen.

El archivo de cabecera com_err.h debe incluirse en cualquier archivo fuente que utilice rutinas de la biblioteca com_err; los archivos ejecutables deben enlazarse usando ``-lcom_err'' para incluir la biblioteca com_err.

VER TAMBIÉN

compile_et (1), syslog (3).

Ken Raeburn, "A Common Error Description Library for UNIX".
