complex(7) Manual de Información Miscelánea complex(7)

NOMBRE

complex - conceptos básicos de las matemáticas complejas

BIBLIOTECA

Biblioteca de matemáticas (libm, -lm)

SINOPSIS

#include <complex.h>

DESCRIPCIÓN

Los números complejos son números de la forma z = a+b*i, donde a y b son números reales e i = sqrt(-1), de modo que i*i = -1.

Existen otras formas de representar ese número. El par (a,b) de números reales puede ser visto como un punto en el plano, dado por coordenadas X e Y. Este mismo punto puede también describirse dando el par de números reales (r,phi), donde r es la distancia al origen O, y phi el ángulo entre el eje X y la línea Oz. Ahora z = r*exp(i*phi) = r*(cos(phi)+i*sin(phi)).

Las operaciones básicas se definen sobre z = a+b*i y w = c+d*i como:

suma: z+w = (a+c) + (b+d)*i
multiplicación: z*w = (a*c - b*d) + (a*d + b*c)*i
división: z/w = ((a*c + b*d)/(c*c + d*d)) + ((b*c - a*d)/(c*c + d*d))*i

Casi todas las funciones matemáticas tienen una contraparte compleja pero existen algunas funciones exclusivas para números complejos.

EJEMPLOS

Tu compilador C puede trabajar con números complejos si soporta el estándar C99. La unidad imaginaria se representa con I.

/* comprobar que exp(i * pi) == -1 */
#include <math.h>        /* para atan */
#include <stdio.h>
#include <complex.h>
int
main(void)
{
    double pi = 4 * atan(1.0);
    double complex z = cexp(I * pi);
    printf("%f + %f * i\n", creal(z), cimag(z));
}
