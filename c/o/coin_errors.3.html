coin_errors - Clases de manejo de errores


- Las clases de error son clases estáticas que contienen un puntero de callback para manejar errores del tipo dado.

Descripción detallada

Las clases de error son clases estáticas que contienen un puntero de callback para manejar errores del tipo dado.

Coin tiene manejadores predeterminados para mostrar todos los tipos, pero pueden ser sobrescritos por las aplicaciones estableciendo otros callbacks.
