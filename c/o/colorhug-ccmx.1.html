NOMBRE

colorhug-ccmx - Cargador CCMX para el colorímetro ColorHug

SINOPSIS

colorhug-ccmx [ --verbose ] [ --repair ]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando colorhug-ccmx.

colorhug-ccmx te permite cargar CCMX en tu colorímetro Hughski ColorHug.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

--help
Muestra un resumen de las opciones.
--verbose
Muestra información de depuración adicional.
--repair
Repara la matriz de calibración de fábrica predeterminada.

ENTORNO

Establecer COLORHUG_EMULATE te permitirá ejecutar esta herramienta sin ningún hardware real conectado.
