NOMBRE

Convert::ASN1 - Biblioteca de codificación/descodificación ASN.1

VERSIÓN

versión 0.34

SINOPSIS

use Convert::ASN1;
$asn = Convert::ASN1->new;
$asn->prepare(q<
  [APPLICATION 7] SEQUENCE {
    int INTEGER,
    str OCTET STRING
  }
>);
$pdu = $asn->encode( int => 7, str => "string");
$out = $asn->decode($pdu);
print $out->{int}," ",$out->{str},"\n";
use Convert::ASN1 qw(:io);
$peer   = asn_recv($sock,$buffer,0);
$nbytes = asn_read($fh, $buffer);
$nbytes = asn_send($sock, $buffer, $peer);
$nbytes = asn_send($sock, $buffer);
$nbytes = asn_write($fh, $buffer);
$buffer = asn_get($fh);
$yes    = asn_ready($fh)

DESCRIPCIÓN

Convert::ASN1 codifica y descodifica estructuras de datos ASN.1 usando las reglas BER/DER.

MÉTODOS

new ( [OPCIONES] )

Constructor, crea un nuevo objeto.

Si se proporcionan, OPCIONES son las mismas que para "configure ( OPCIONES )" más abajo.

error ()

Devuelve el último error.

configure ( OPCIONES )

Configura opciones para controlar cómo Convert::ASN1 realizará varias tareas. Las opciones se pasan como pares nombre-valor.

encode
Referencia a un hash que contiene varias opciones de codificación.
decode
Referencia a un hash que contiene varias opciones de descodificación.
encoding
Uno de 'BER' o 'DER'. El valor predeterminado es 'BER'
tagdefault
Uno de 'EXPLICIT' o 'IMPLICIT'. Las convenciones de etiquetado predeterminadas normalmente se indican en la definición del módulo ASN.1 (no soportado por el analizador). La especificación ASN.1 establece que el etiquetado EXPLICIT es el predeterminado, pero esta opción tiene el etiquetado IMPLICIT predeterminado por razones de compatibilidad con versiones anteriores.

Opciones de codificación

real
Qué codificación usar para los números reales. Una de 'binary', 'nr1', 'nr2', 'nr3'
time
Esto controla cómo se codifican los elementos UTCTime y GeneralizedTime. El valor predeterminado es "withzone".
utctime
El valor pasado se codificará sin una zona, es decir, un valor UTC.
withzone
El valor se codificará con una zona. Por defecto se codificará usando el desfase de la hora local. El desfase puede establecerse usando la "timezone" opción de configuración.
raw
El valor pasado ya debe estar en el formato correcto y se copiará en el PDU tal cual.
timezone
Por defecto, UTCTime y GeneralizedTime se codificarán usando el desfase de la hora local respecto a UTC. Esto lo anulará. Es un desfase respecto a UTC en segundos. Esta opción puede anularse pasando una referencia a una lista de dos valores como el valor de tiempo. La lista debe contener el valor de tiempo y el desfase respecto a UTC en segundos.
bigint
Si durante la codificación se descubre un valor mayor de 32 bits y no es ya un objeto de entero grande, el valor se convertirá primero en un objeto de entero grande. Esta opción controla la clase de entero grande en la que se bendecirán los objetos. El valor predeterminado es usar Math::BigInt

Opciones de descodificación

time
Esto controla cómo se descodificará un elemento UTCTime o GeneralizedTime. El valor predeterminado es "utctime".
utctime
El valor devuelto será un valor de tiempo como el devuelto por la "time" función.
withzone
El valor devuelto será una referencia a un array de dos valores. El primero es el mismo que con "utctime", el segundo es el desfase de la zona horaria, en segundos, que se usó en la codificación.
raw
El valor devuelto será la codificación sin procesar extraída del PDU.
bigint
Si durante la descodificación se descubren enteros grandes (enteros mayores de 32 bits), se descodificarán en objetos de entero grande. Esta opción controla la clase de entero grande en la que se bendecirán los objetos. El valor predeterminado es usar Math::BigInt.
null
El valor en el que descodificar los tipos ASN.1 NULL. Si no se establece, el valor predeterminado es 1.

prepare ( ASN )

Compila la descripción ASN.1 dada, que puede pasarse como cadena o como un identificador de archivo. La sintaxis usada es muy similar a ASN.1, pero tiene algunas diferencias. Si ASN describe solo una macro, se puede llamar a encode/decode en este objeto. Si ASN describe más de una macro ASN.1, entonces "find" debe ser llamado. El método devuelve undef en caso de error.

prepare_file ( RUTA_ASN )

Compila la descripción ASN.1 que se leerá de la ruta de archivo especificada.

find ( MACRO )

Encuentra una macro en una descripción ASN.1 preparada. Devuelve un objeto que puede usarse para encode/decode.

encode ( VARIABLES )

Codifica un PDU. Las variables de nivel superior se pasan como pares nombre-valor, o como una referencia a un hash que los contiene. Devuelve el PDU codificado, o undef en caso de error.

decode ( PDU )

Descodifica el PDU, devuelve una referencia a un hash que contiene los valores para el PDU. Devuelve undef si hubo un error.

registeroid ( OID, MANEJADOR )

Registra un manejador para todos los elementos ASN.1 que son "DEFINED BY" el OID dado.

MANEJADOR debe ser un objeto Convert::ASN1, p. ej. como el devuelto por "find ( MACRO )".

registertype ( NOMBRE, OID, MANEJADOR )

Registra un manejador para todos los elementos ASN.1 llamados "NOMBRE", que son "DEFINED BY" el OID dado.

MANEJADOR debe ser un objeto Convert::ASN1, p. ej. como el devuelto por "find ( MACRO )".

MAPEO DE ASN.1 A
PERL
Cada elemento en la definición ASN.1 tiene un nombre; en perl se utiliza un hash con estos
nombres como índice y el valor del elemento como valor del hash.
# ASN.1 int INTEGE
R, str OCTET STRIN
G # Perl { int =>
5, str => "text" }

En el caso de un SEQUENCE, SET o CHOICE, el valor en el espacio de nombres será una referencia a un hash que será el espacio de nombres para los elementos de ese

elemento.

# ASN.1 int INTEGER, seq SEQUENCE { str OCTET STRING, bool BOOLEAN } # Perl { int => 5, seq => { str => "text", bool => 1}

} 
Si el elemento es un SEQUENCE OF, o SET OF, entonces el valor en el
    espacio de nombres será una referencia a un arreglo. Los elementos del
    arreglo serán del tipo esperado por el tipo que sigue a OF. Por ejemplo,
    con "SEQUENCE OF STRING" el arreglo contendría cadenas. Con
    "SEQUENCE OF SEQUENCE { ... }" el arreglo contendrá referencias a hashes
    que se usarán como espacios de
nombres

# ASN.1 int INTEGER, str SEQUENCE OF OCTET STRING # Perl { int => 5, str => [ "text1", "text2"]} # ASN.1 int INTEGER, str SEQUENCE OF SEQUENCE { type OCTET STRING, value INTEGER } # Perl { int => 5, str => [ { type => "abc", value => 4 }, { type => "def", value => -1 },

]} 
Finalmente, si deseas pre-analizar ASN.1 y retenerlo para incluirlo
    en línea en tu PDU, puedes forzarlo en la especificación ASN.1 definiendo
    el valor como ANY en el esquema, y luego pasar el valor pre-codificado en
línea.

# ASN.1 int INTEGER, str OCTET STRING, pre ANY # Perl { int => 5, str => "text", pre=>"\x03\x03\x00\x0a\x05"

}
