DESCRIPCIÓ

N

El comando coroutine crea un nuevo contexto de corutina (con un comando asociado) llamado nombre y ejecuta ese contexto llamando a comando, pasando los demás argumentos restantes sin interpretación adicional. Una vez que comando retorna normalmente o con una excepción (por ejemplo, un error), el contexto de la corutina nombre es

eliminado.

Dentro del contexto, los valores pueden generarse como resultados usando el comando yield; si no se proporciona ningún valor, se utiliza la cadena vacía . Cuando se llama a esto, el contexto suspenderá la ejecución y el comando coroutine retornará el argumento a yield. La ejecución del contexto puede ser reanudada llamando al comando del contexto, pasando opcionalmente el valor único a usar como resultado de la llamada a yield que causó que el contexto fuera suspendido. Si la corutina contexto nunca cede y en su lugar retorna convencionalmente, el resultado del comando coroutine será el resultado de la evaluación del

contexto.

La corutina también puede suspender su ejecución mediante el uso del comando yieldto, que en lugar de retornar, cede la ejecución a algún comando llamado comando (resuelto en el contexto de la corutina) y al cual cualquier número de argumentos puede ser pasado. Dado que cada corutina tiene un comando de contexto, yieldto puede usarse para transferir el control directamente de una corutina a otra (esto solo es aconsejable si las dos corutinas esperan que esto suceda), pero cualquier comando puede ser el objetivo. Si una corutina es suspendida por este mecanismo, el procesamiento de la corutina puede ser reanudado llamando al comando del contexto pasando opcionalmente un número arbitrario de argumentos. El valor de retorno de la llamada a yieldto será la lista de argumentos pasados al comando del contexto; le corresponde al llamador decidir qué hacer con esos

valores.

La forma recomendada de escribir una versión de yield que permite la reanudación con múltiples argumentos es usando yieldto y el comando return,

así: 
proc yieldm {valor} {
    yieldto return -
level 0
$valor }

La corutina también puede ser eliminada destruyendo el comando nombre, y el nombre de la corutina actual puede ser recuperado usando info coroutine. Si hay rastros de eliminación en variables en la implementación de la corutina, se activarán en el punto en que la corutina sea eliminada explícitamente (o, naturalmente, si el comando retorna convencionalmente)

.

En el punto en que se llama al comando, el espacio de nombres actual será el espacio de nombres global y no habrá marcos de pila por encima de él (en el sentido de upvar y uplevel). Sin embargo, qué comando llamar será determinado en el espacio de nombres desde el que se llamó al comando

coro
utine.

Este ejemplo muestra una corutina que producirá una secuencia infinita de valores pares, y un bucle que consume los primeros diez de

ellos. 
proc allNumbers {} {
    yield
    set i 0
    while 1 {
        yield $i
        incr i 2
    }
}
coroutine nextNumber allNumbers
for {set i 0} {$i < 10} {incr i} {
    puts "recibido [nextNumber]"
}

Este ejemplo demuestra el uso de corutinas para implementar el clásico algoritmo Criba de Eratóstenes para encontrar números primos. Note la creación de corutinas dentro de una

corutina. 
proc filterByFactor {fuente n} {
    yield [info coroutine]
    while 1 {
        set x [$fuente]
        if {$x % $n} {
            yield $x
        }
    }
}
coroutine allNumbers apply {{} {while 1 {yield [incr x]}}}
coroutine eratosthenes apply {c {
    yield
    while 1 {
        set n [$c]
        yield $n
        set c [coroutine prime$n filterByFactor $c $n]
    }
}} allNumbers

Este ejemplo muestra cómo un valor puede ser pasado alrededor de un grupo de tres corutinas que ceden una a

otra: 
proc malabarista {nombre objetivo {valor ""}} {
    if {$valor eq ""} {
        set valor [yield [info coroutine]]
    }
    while {$valor ne ""} {
        puts "$nombre : $valor"
        set valor [string range $valor 0 end-1]
        lassign [yieldto $objetivo $valor] valor
    }
}
