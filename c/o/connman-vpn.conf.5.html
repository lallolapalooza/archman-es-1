NOMBRE

connman-vpn.conf - Archivo de configuración de ConnMan-VPN

SINOPSIS

/etc/connman/connman-vpn.conf

DESCRIPCIÓN

connman-vpn.conf es un archivo de configuración para ConnMan-VPN. El archivo de configuración es opcional, pero se puede usar para configurar varios aspectos del comportamiento de ConnMan-VPN. La ubicación del archivo puede modificarse mediante el argumento --config= para connman-vpn(8).

Los privilegios DAC (usuario, grupo y grupos suplementarios) de un binario de VPN ejecutado por connman-vpn(8) pueden ser controlados por esta configuración. La configuración en connman-vpn.conf es para todos los tipos de VPN y puede ser reemplazada definiendo configuraciones separadas en /etc/connman/vpn-plugin/ usando el nombre del plugin + sufijo .conf con la misma sintaxis. Por ejemplo, para OpenVPN la ruta a la configuración es /etc/connman/vpn-plugin/openvpn.conf que reemplazará cualquier valor en la configuración principal.

FORMATO DEL ARCHIVO

El archivo de configuración consta de secciones (grupos) de pares clave-valor. Las líneas que comienzan con '#' y las líneas en blanco se consideran comentarios. Las secciones se inician con una línea de encabezado que contiene la sección encerrada entre '[' y ']', y terminan implícitamente con el inicio de la siguiente sección o el final del archivo. Cada par clave-valor debe estar contenido en una sección.

Se describen las secciones y las claves disponibles a continuación:

[General]

Esta sección es la única sección obligatoria del archivo de configuración.

InputRequestTimeout=secs
Establece el tiempo de espera de la solicitud de entrada. El valor predeterminado es 300 segundos. La solicitud de entradas como la frase de contraseña expirará después de una cierta cantidad de tiempo. Utilice esta configuración para aumentar el valor en caso de diferentes diseños de interfaz de usuario.

[DACPrivileges]

Esta sección controla los privilegios DAC a utilizar para un binario de VPN utilizado por un plugin de VPN. Los privilegios DAC que se pueden establecer son usuario, grupo y grupos suplementarios.

User=nombre_de_usuario/uid
Usuario del sistema a utilizar para ejecutar el binario de VPN. Se puede usar el nombre de usuario o el uid.
Group=nombre_de_grupo/gid
El grupo principal a utilizar para ejecutar el binario de VPN. Se puede usar el nombre del grupo o el gid.
SupplementaryGroups=nombres_de_grupo/gids
Lista separada por comas de grupos suplementarios a establecer para el binario de VPN. Los grupos se pueden definir con sus nombres o gids.

EJEMPLOS

El siguiente ejemplo de configuración establece InputRequestTimeout a 10 minutos, ejecuta VPNs como el usuario "vpn_user" del grupo "vpn" con grupos suplementarios adicionales "inet" y "net_admin".

[General]
InputRequestTimeout = 600
[DACPrivileges]
User = vpn_user
Group = vpn
SupplementaryGroups = inet, net_admin
