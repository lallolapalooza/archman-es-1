COLORDIFF(1) Comandos de usuario COLORDIFF(1)

NOMBRE

colordiff - una herramienta para colorear la salida de diff

SINOPSIS

colordiff [opciones de diff] [opciones de colordiff] {archivo1} {archivo2}

DESCRIPCIÓN

colordiff es un envoltorio para diff y produce la misma salida que diff pero con resaltado de sintaxis en color en la línea de comandos para mejorar la legibilidad. La salida es similar a cómo podría aparecer un parche generado por diff en Vim o Emacs con las opciones de resaltado de sintaxis apropiadas habilitadas. Los esquemas de color se pueden leer de un archivo de configuración central o de un archivo local del usuario ~/.colordiffrc.

colordiff utiliza colores ANSI y, como tal, solo funcionará cuando se puedan usar colores ANSI; ejemplos típicos son xterms y Eterms, así como sesiones de consola.

colordiff ha sido probado en varias distribuciones de Linux y bajo OpenBSD, pero debería ser ampliamente portable a otros sistemas.

USO

Use colordiff donde normalmente usaría diff, o en su lugar envíe la salida a colordiff:

Por ejemplo:

$ colordiff archivo1 archivo2
$ diff -u archivo1 archivo2 | colordiff

Puede enviar la salida a 'less', usando la opción '-R' (algunos sistemas o tipos de terminal pueden obtener mejores resultados usando '-r' en su lugar), que mantiene las secuencias de escape de color, de lo contrario, mostradas incorrectamente o descartadas por 'less':

$ diff -u archivo1 archivo2 | colordiff | less -R

Si desea forzar la deshabilitación de las secuencias de escape de color (por ejemplo, enviar la salida a patch), puede usar la opción '--color=no' para hacerlo:

$ diff -u archivo1 archivo2 | colordiff --color=no | patch -p0 -d otro-directorio-de-trabajo

Si tiene wdiff instalado, colordiff coloreará correctamente el texto agregado y eliminado, siempre que se proporcione la opción '-n' a wdiff:

$ wdiff -n archivo1 archivo2 | colordiff

Puede resultarle útil hacer que diff llame automáticamente a colordiff. Agregue la siguiente línea a ~/.bashrc (o equivalente):

alias diff=colordiff

Cualquier opción pasada a colordiff se pasa a diff, excepto la opción específica de colordiff 'difftype', por ejemplo:

colordiff --difftype=debdiff archivo1 archivo2

Los valores válidos para 'difftype' son: diff, diffc, diffu, diffy, wdiff, debdiff; estos corresponden a diffs planos, diffs de contexto, diffs unificados, diffs lado a lado, salida wdiff y salida debdiff, respectivamente. Use estas anulaciones cuando colordiff no pueda determinar el tipo de diff automáticamente.

Alternativamente, una construcción como 'cvs diff ALGO | colordiff' se puede incluir en ~/.bashrc de la siguiente manera:

function cvsdiff () { cvs diff $@ | colordiff; }

O, combinando la idea anterior usando 'less':

function cvsdiff () { cvs diff $@ | colordiff |less -R; }

Tenga en cuenta que el nombre de la función, cvsdiff, se puede personalizar.

Por defecto, colordiff devuelve el código de salida de la invocación subyacente de diff (si la hay), pero hay algunas circunstancias en las que es útil forzar el código de salida de colordiff a cero: para hacer esto, use la opción '--fakeexitcode':

colordiff --fakeexitcode ...

OPCIONES

colordiff enviará la mayoría de las opciones a diff, pero hay varias opciones específicas de colordiff que se pueden usar:

--help

Mostrar estas opciones específicas de colordiff

--color=(yes|no)

Forzar (o suprimir) la visualización de colores en la salida

--color=patches=(yes|no)

Forzar (o suprimir) la inclusión de códigos de color en la salida de parches

--color-term-output-only

Forzar que el color solo aparezca en la salida de la terminal

--difftype=DIFFTYPE

Forzar la detección del tipo de diff al formato especificado. DIFFTYPE puede ser: diff, diffc, diffu, diffy, debdiff, wdiff

--(no)banner

Mostrar (o suprimir) el banner de colordiff

ARCHIVOS

/etc/colordiffrc

Archivo de configuración central. Las configuraciones específicas del usuario se pueden habilitar copiando este archivo a ~/.colordiffrc y realizando los cambios apropiados.

colordiffrc-lightbg

Plantilla de configuración alternativa para usar con terminales que tienen fondos claros. Copie esto a /etc/colordiffrc o ~/.colordiffrc y personalícelo.

colordiffrc-gitdiff

Plantilla de configuración alternativa para usar con terminales que tienen fondos oscuros, con valores predeterminados de color configurados para que coincidan con la salida de 'git diff'. Copie esto a /etc/colordiffrc o ~/.colordiffrc y personalícelo.
