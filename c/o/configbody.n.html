configbody(n)

Paquete: tcl

Licencias: TCL

configbody(n) [incr Tcl] configbody(n)

NOMBRE

itcl::configbody - cambiar el código de "config" para una variable pública

SINOPSIS

itcl::configbody NombreClase::NombreVariable cuerpo

DESCRIPCIÓN

El comando configbody se utiliza fuera de una definición de clase [incr Tcl] para definir o redefinir el código de configuración asociado con una variable pública. Las variables públicas actúan como opciones de configuración para un objeto. Se pueden modificar fuera del ámbito de la clase utilizando el método incorporado configure. Cada variable puede tener un pequeño bloque de código de "config" asociado que se ejecuta automáticamente cuando la variable se configura. El comando configbody se puede utilizar para definir o redefinir este bloque de código.

Al igual que el comando body, esta característica permite que una definición de clase tenga partes separadas de "interfaz" e "implementación". La parte de la "interfaz" es un comando class con declaraciones para métodos, procedimientos, variables de instancia y variables comunes. La parte de la "implementación" es una serie de comandos body y configbody. Si la parte de la "implementación" se mantiene en un archivo separado, se puede incluir una y otra vez a medida que se corrigen los errores, para admitir el desarrollo interactivo. Al usar el modo "tcl" en el editor emacs, las partes de la "interfaz" y la "implementación" se pueden mantener en el mismo archivo; a medida que se corrigen los errores, los cuerpos individuales se pueden resaltar y enviar a la aplicación de prueba.

El nombre "NombreClase::NombreVariable" identifica la variable pública que se está actualizando. Si la cadena cuerpo comienza con "@", se trata como el nombre simbólico de un procedimiento C. De lo contrario, se trata como un script de comandos Tcl.

Los nombres simbólicos para los procedimientos C se establecen registrando procedimientos a través de Itcl_RegisterC(). Esto generalmente se hace en el procedimiento Tcl_AppInit(), que se llama automáticamente cuando el intérprete se inicia. En el siguiente ejemplo, el procedimiento My_FooCmd() se registra con el nombre simbólico "foo". Este procedimiento se puede referenciar en el comando configbody como "@foo".

int
Tcl_AppInit(interp)
    Tcl_Interp *interp;     /* Intérprete de la aplicación. */
{
    if (Itcl_Init(interp) == TCL_ERROR) {
        return TCL_ERROR;
    }
    if (Itcl_RegisterC(interp, "foo", My_FooCmd) != TCL_OK) {
        return TCL_ERROR;
    }
}

EJEMPLO

En el siguiente ejemplo, se define una clase "File" para representar archivos abiertos. Cada vez que se configura la opción "-name", se cierra el archivo existente y se abre uno nuevo. Tenga en cuenta que el código de "config" para una variable pública es opcional. La opción "-access", por ejemplo, no lo tiene.

itcl::class File {
    private variable fid ""
    public variable name ""
    public variable access "r"
    constructor {args} {
        eval configure $args
    }
    destructor {
        if {$fid != ""} {
            close $fid
        }
    }
    method get {}
    method put {line}
    method eof {}
}
itcl::body File::get {} {
    return [gets $fid]
}
itcl::body File::put {line} {
    puts $fid $line
}
itcl::body File::eof {} {
    return [::eof $fid]
}
itcl::configbody File::name {
    if {$fid != ""} {
        close $fid
    }
    set fid [open $name $access]
}
#
# Vea la clase File en acción:
#
File x
x configure -name /etc/passwd
while {![x eof]} {
    puts "=> [x get]"
}
itcl::delete object x
