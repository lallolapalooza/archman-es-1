NOMBRE

cog-verify - Verifica un único mensaje de commit

SINOPSIS

cog-verify [-f|--file] [-i|--ignore-merge-commits] [--ignore-fixup-commits] [-h|--help] [MENSAJE]

DESCRIPCIÓN

Verifica un único mensaje de commit

OPCIONES

-f, --file <ARCHIVO>
Lee el mensaje del archivo especificado
-i, --ignore-merge-commits
Ignora mensajes de commit de fusión
--ignore-fixup-commits
Ignora mensajes de commit fixup!, squash! y amend!
-h, --help
Imprime la ayuda
[MENSAJE]
El mensaje de commit
