NOMBRE

connection_name.config - Archivo de aprovisionamiento de conexiones VPN de ConnMan

SINOPSIS

/var/lib/connman-vpn/connection-name.config

DESCRIPCIÓN

Las conexiones VPN deConnMan se configuran con los llamados "archivos de aprovisionamiento" que residen en /var/lib/connman-vpn/. Los archivos pueden tener cualquier nombre, siempre que contengan solo caracteres ASCII imprimibles, por ejemplo letras, números y guiones bajos. El archivo debe terminar con .config. Cada conexión VPN requiere un archivo de aprovisionamiento, pero se pueden especificar varias conexiones en el mismo archivo.

FORMATO DEL ARCHIVO

El archivo de configuración consta de secciones (grupos) de pares clave-valor. Las líneas que comienzan con '#' y las líneas en blanco se consideran comentarios. Las secciones comienzan con una línea de encabezado que contiene la sección entre '[' y ']', y terminan implícitamente con el inicio de la siguiente sección o con el final del archivo. Cada par clave-valor debe estar contenido en una sección.

A continuación se describe las secciones y las claves disponibles:

[global]

Esta sección es opcional y puede usarse para describir el archivo. Los dos campos permitidos para esta sección son:

Name=nombre
Nombre de la red.
Description=descripción
Descripción de la red.

[provider_*]

Cada conexión aprovisionada debe comenzar con una etiqueta [provider_*], con * reemplazado por un nombre único dentro del archivo. Los siguientes campos son obligatorios:

Type=OpenConnect | OpenVPN | VPNC | L2TP | PPTP
Especifica el tipo de VPN.
Host=IP
Dirección IP del servidor VPN.
Domain=dominio
Nombre de dominio para el servicio VPN.
El siguiente campo es opcional:
Networks=red/máscara de red/puerta de enlace[,...]
Redes detrás de la VPN. Si todo el tráfico debe pasar por la VPN, este campo puede omitirse. La puerta de enlace puede omitirse. Para direcciones IPv6, solo se acepta la longitud del prefijo como máscara de red.

OpenConnect

Las siguientes claves pueden usarse para redes openconnect(8) :

OpenConnect.ServerCert=certificado
Huella digital SHA1 del certificado del servidor VPN.
OpenConnect.CACert=certificado
Archivo que contiene certificados de CA adicionales además de las autoridades de certificación de confianza del sistema.
OpenConnect.ClientCert=certificado
Certificado del cliente, si es necesario para la autenticación web.
OpenConnect.MTU=mtu
Solicitar mtu al servidor como el MTU del túnel.
OpenConnect.Cookie=cookie
La cookie resultante del proceso de autenticación. Como la vida útil de la cookie puede ser muy limitada, normalmente no tiene sentido añadirla al archivo de configuración.
OpenConnect.VPNHost=host
El servidor VPN final a usar después de completar la autenticación web. Solo es utilizable para configuraciones VPN extremadamente simples y normalmente solo debe establecerse a través de la API del agente VPN.

Si OpenConnect.Cookie, OpenConnect.VPNHost o OpenConnect.ServerCert faltan, se contactará al agente VPN para proporcionar la información.

OpenVPN

Las siguientes claves son obligatorias para redes openvpn(8) :

OpenVPN.CACert=certificado
Archivo de autoridad de certificación.
OpenVPN.Cert=certificado
Certificado firmado del par local.
OpenVPN.Cert=certificado
Certificado firmado del par local.
OpenVPN.Key=clave
Clave privada del par local.
Las siguientes claves son opcionales para redes openvpn(8) :
OpenVPN.MTU=mtu
MTU del túnel.
OpenVPN.NSCertType=client | server
Tipo de certificado del par, ya sea client o server.
OpenVPN.Proto=protocolo
Usar protocolo.
OpenVPN.Port=puerto
Número de puerto TCP/UDP.
OpenVPN.AuthUserPass=true | false
Autenticar en el servidor usando nombre de usuario/contraseña.
OpenVPN.AskPass=archivo
Obtener la contraseña del certificado de archivo.
OpenVPN.AuthNoCache=true | false
No almacenar en caché el valor de AskPass o AuthUserPass.
OpenVPN.TLSRemote=nombre
Aceptar conexiones solo de un host con nombre X509 o nombre común igual a nombre.
OpenVPN.TLSAuth=archivo
Usar archivo para la autenticación HMAC.
OpenVPN.TLSAuthDir=dirección
Usar dirección para la dirección de autenticación HMAC.
OpenVPN.Cipher=cifrado
Usar cifrado como el cifrado.
OpenVPN.Auth=true | false
Usar autenticación HMAC.
OpenVPN.CompLZO=yes | no | adaptive
Usar compresión LZO rápida.
OpenVPN.RemoteCertTls=client | server
Requerir que el certificado remoto esté firmado basándose en las reglas TLS de RFC3280.
OpenVPN.ConfigFile=archivo
Archivo de configuración de OpenVPN para opciones adicionales no soportadas por el plugin de OpenVPN.
OpenVPN.DeviceType=tun|tap
Si la VPN debe usar un dispositivo tun (capa OSI 3) o tap (capa OSI 2). Por defecto es tun si se omite.

VPNC

La siguiente clave es obligatoria para redes vpnc(8) :

VPNC.IPSec.ID=id
Nombre de usuario del grupo.
Las siguienteslas teclas de grupo son opcionales para vpnc(8) redes:
VPNC.IPSec.Secret=secreto
Contraseña de grupo.
VPNC.XAuth.Username=nombre de usuario
Nombre de usuario.
VPNC.XAuth.Password=contraseña
Contraseña.
VPNC.IKE.Authmode=modo
Modo de autenticación IKE.
VPNC.IKE.DHGroup=grupo
Nombre del grupo DH de IKE.
VPNC.PFS=grupo
Grupo Diffie-Hellman para secreto hacia adelante perfecto.
VPNC.Domain=dominio
Nombre de dominio para la autenticación.
VPNC.Vendor=proveedor
Proveedor del puerta de enlace IPSec.
VPNC.LocalPort=puerto
Número de puerto ISAKMP local a utilizar.
VPNC.CiscoPort=puerto
Puerto de encapsulación UDP de Cisco.
VPNC.AppVersion=versión
Versión de la aplicación a informar.
VPNC.NATTMode=modo
Método de NAT-Traversal a utilizar.
VPNC.DPDTimeout=tiempo de espera
Tiempo de espera de inactividad DPD.
VPNC.SingleDES=true | false
Habilitar cifrado DES simple.
VPNC.NoEncryption=true | false
Habilitar el uso de sin cifrado para el tráfico de datos.
VPNC.DeviceType=tun|tap
Si la VPN debe usar un dispositivo tun (capa OSI 3) o tap (capa OSI 2). Por defecto es tun si se omite.

EJEMPLO

Este es un archivo de configuración para una VPN que proporciona servicios L2TP, OpenVPN y OpenConnect. Podría estar, por ejemplo, en el archivo /var/lib/connman-vpn/example.config.

[global]
Name = Example
Description = Example VPN configuration
[provider_l2tp]
Type = L2TP
Name = Connection to corporate network
Host = 1.2.3.4
Domain = corporate.com
Networks = 10.10.30.0/24
L2TP.User = username
[provider_openconnect]
Type = OpenConnect
Name = Connection to corporate network using Cisco VPN
Host = 7.6.5.4
Domain = corporate.com
Networks = 10.10.20.0/255.255.255.0/10.20.1.5,192.168.99.1/24,2001:db8::1/64
OpenConnect.ServerCert = 263AFAB4CB2E6621D12E90182008AEF44AEFA031
OpenConnect.CACert = /etc/certs/certificate.p12
[provider_openvpn]
Type = OpenVPN
Name = Connection to corporate network using OpenVPN
Host = 3.2.5.6
Domain = my.home.network
OpenVPN.CACert = /etc/certs/cacert.pem
OpenVPN.Cert = /etc/certs/cert.pem
OpenVPN.Key = /etc/certs/cert.key
