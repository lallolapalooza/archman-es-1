cog-bump(1) Manual de comandos generales cog-bump(1)

NOMBRE

cog-bump - Confirma el registro de cambios desde la última etiqueta hasta HEAD y crea una nueva etiqueta

SINOPSIS

cog-bump [--version] [-a|--auto] [-M|--major] [-m|--minor] [-p|--patch] [--pre] [--build] [-H|--hook-profile] [--package] [-A|--annotated] [-d|--dry-run] [--skip-ci] [--skip-ci-override] [--skip-untracked] [--disable-bump-commit] [--include-packages] [-h|--help]

DESCRIPCIÓN

Confirma el registro de cambios desde la última etiqueta hasta HEAD y crea una nueva etiqueta

OPCIONES

--version <VERSIÓN>
Establece manualmente la versión de destino
-a, --auto
Sugiere automáticamente la versión de destino
-M, --major
Incrementa la versión principal
-m, --minor
Incrementa la versión menor
-p, --patch
Incrementa la versión de parche
--pre <PRE>
Establece la versión de pre-lanzamiento
--build <BUILD>
Establece el sufijo de compilación
-H, --hook-profile <HOOK_PROFILE>
Especifica los hooks de perfil de aumento a ejecutar
--package <PAQUETE>
Especifica qué paquete aumentar para monorepos
-A, --annotated <ANNOTATED>
Anota la etiqueta con el mensaje dado
-d, --dry-run
Simulación: imprime la versión de destino. No se realiza ninguna acción
--skip-ci
Añade la cadena skip-ci definida en cog.toml (o por defecto [skip ci]) al commit de aumento
--skip-ci-override <SKIP_CI_OVERRIDE>
Anula y añade la cadena skip-ci con el valor proporcionado al commit de aumento
--skip-untracked
No fallar si hay archivos sin seguimiento o sin confirmar
--disable-bump-commit
Deshabilita la creación del commit de aumento
--include-packages
También aumenta los paquetes en el aumento manual

Anula el comportamiento predeterminado para --patch, --minor, --major y --version para aumentar solo la versión global para monorepos. Útil para aumentar a la versión 1.0.0.

-h, --help
Imprime la ayuda (ver un resumen con '-h')
