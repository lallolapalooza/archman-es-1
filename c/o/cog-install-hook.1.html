NOMBRE

cog-install-hook - Añade hooks de git al repositorio

SINOPSIS

cog-install-hook [-a|--all] [-o|--overwrite] [-h|--help] [TIPO_HOOK]

DESCRIPCIÓN

Añade hooks de git al repositorio

OPCIONES

-a, --all
Instalar todos los git-hooks
-o, --overwrite
Sobrescribir los git-hooks existentes
-h, --help
Imprimir ayuda
[TIPO_HOOK]
Tipo de hook a instalar
cog-install-hook
