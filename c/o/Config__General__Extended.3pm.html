is_hash('key') is_array('key')

Como se vio anteriormente, puede acceder a partes de su configuración actual usando métodos hash, array o escalar. Pero tiene razón si adivina que esto podría volverse problemático, si por ejemplo llama a hash() en una clave que en realidad no es un hash sino un escalar. En circunstancias normales perl se negaría a hacerlo y moriría.

Para evitar tal comportamiento puede usar uno de los métodos is_hash() is_array() is_scalar() para verificar si el valor de "key" es realmente lo que usted espera que

sea.

Un ejemplo (basado en el ejemplo de configuración

anterior):

   $individual = $conf->obj("individual");
}
else {
   die "You need to configure a "individual" block!
\n";
}

MÉTODOS

AUTOLOAD

Otra característica útil está implementada en esta clase usando la función AUTOLOAD de perl. Si conoce los nombres de las claves de un bloque dentro de su configuración, puede acceder a los valores de cada clave individual usando la notación de método. Vea el siguiente ejemplo y lo

entenderá:

Asumimos la siguiente

configuración: 
<person>
   name    = Moser
   prename = Peter
   birth   = 12.10.1972
</person>

Ahora la leemos y la

procesamos: 
my $conf = Config::General::Extended->new("configfile");
my $person = $conf->obj("person");
print $person->prename . " " . $person->name . " is " . $person->age . " years
old\n";

¡Esta notación solo soporta valores escalares! Debe asegurarse de que el bloque <person> no contenga ningún subbloque ni opciones idénticas múltiples (lo que ¡se convertirá en un array tras el análisis)

!

Si accedes a una clave que no existe de esta manera, Config::General generará un error fatal. Puedes desactivar este comportamiento estableciendo -StrictObjects a 0 o "no". En este caso se devolverá

undef.

Por supuesto, puedes usar este tipo de métodos para escribir datos

también: 
$person->name("Neustein")
;

Esto cambia el valor de la clave "name" a "Neustein". Esta característica se comporta exactamente igual que value(), lo que significa que también puedes asignar referencias a hashes o

arrays y que los valores existente
s bajo la clave dada serán sobrescritos.
