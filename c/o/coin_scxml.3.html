Descripción Detallada

Este conjunto de clases es una implementación básica de State Chart XML.

No está completo, ni es necesariamente conforme a las partes que implementa.

Actualmente Coin usa SCXML para gestionar la interacción del usuario del visor 3D (la parte que no es de interacción con el modelo) - el modo de navegación del examinador, en términos sencillos.

La Especificación Provisional de SCXML se encuentra en http://www.w3.org/TR/scxml/.

Desde

Coin 3.0

State Chart XML

La parte ScXML de Coin es una implementación parcial, básica y no conforme de State Chart XML, basada en el Borrador de Trabajo de W3C del 16 de mayo de 2008 de SCXML http://www.w3.org/TR/2008/WD-scxml-20080516/. La última versión debería estar en http://www.w3.org/TR/scxml/. Lea ese documento para una comprensión básica de cómo se deben construir los documentos SCXML.

Coin utiliza SCXML para configurar sus sistemas de navegación, para poder eliminar la lógica codificada de la navegación del usuario y externalizarla en archivos XML. Esto facilita a los usuarios la personalización del sistema de navegación para sus propios fines.

Elementos no soportados:

  • El elemento <parallel> no se soporta como se pretende con estados paralelos. Coin simplemente lo tratará como un elemento <state> ordinario por ahora. Los estados paralelos no están en la lista de prioridades altas, por lo que se espera que se manejen después de que mucha otra funcionalidad esté en marcha.
  • La parte relacionada con <datamodel> de la especificación no está completamente soportada.
  • El atributo 'target' en el elemento <transition> actualmente solo puede identificar un único estado, no múltiples como sería necesario cuando se soporten elementos <parallel> (lo cual no tenemos).
  • Los elementos de estado virtual como <history> y <anchor> solo se implementan como estados ficticios por ahora y no hacen nada en relación con lo que realmente deberían hacer.

Para aprender más sobre cómo se implementa y utiliza ScXML en Coin, eche un vistazo a $COINDIR/scxml/navigation/examiner.xml (o en el directorio fuente de Coin, data/scxml/navigation/examiner.xml) para un ejemplo de cómo se ve un sistema SCXML para la navegación de la cámara, y mire los archivos fuente en src/navigation/ para las contrapartes C++ del mismo sistema de navegación SCXML.
