El

El contenido de estos archivos se fusiona junto; para tener un comportamiento bien definido y fácil de entender, solo puede haber una sección de configuración que describa un espacio de nombres individual dentro de un registro (en particular solo puede haber como máximo una sección default-docker en todos los archivos, y solo puede haber como máximo una instancia de cualquier clave bajo la sección docker;

estas

secciones se documentan más adelante). Por lo tanto, está prohibido tener dos configuracione

s en conflicto para un registro o ámbito individual, y también está prohibido dividir un
a configuración para un registro o ámbito individual en más de un archivo (incluso si no

están en conflicto semántico).
