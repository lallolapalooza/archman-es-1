coin403 - Nuevas características en Coin v4.0.3

Esta es una versión de corrección de errores.

Este es un breve resumen de las nuevas características en Coin v4.0.3:

  • Se agregó soporte para compilar documentación de estilo moderno.
  • Se estableció el estándar C++ mínimo necesario para compilar Coin a C++11.

Correcciones de errores:

  • Se corrigió el error ODR de compilación LTO.
  • Se corrigió un incremento sospechoso en SbProfilingData.cpp.
  • Se corrigió el cálculo de intersección de SbTri3f.
  • Mejorado el recorte automático.
  • Se corrigió el recorte automático ortográfico al permitir `negative farDistance`.
  • Se corrigió la rotación de un nodo VRMLBackground con las rotaciones de sus ancestros.
