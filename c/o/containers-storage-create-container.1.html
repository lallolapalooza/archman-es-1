NOMBRE

containers-storage create-container - Crear un contenedor

SINOPSIS

containers-storage create-container [opciones...] nombreOIdImagen

DESCRIPCIÓN

Crea un contenedor, utilizando la imagen especificada como punto de partida para su sistema de archivos raíz.

OPCIONES

-n | --name nombre

Establece un nombre opcional para el contenedor. Si ya existe un nombre en uso, se devuelve un error.

-i | --id ID

Establece la ID para el contenedor. Si no se especifica ninguna, se genera una.

-m | --metadata valor-metadatos

Establece los metadatos del contenedor al valor especificado.

-f | --metadata-file archivo-metadatos

Establece los metadatos del contenedor al contenido del archivo especificado.

EJEMPLO

containers-storage create-container -f manifest.json -n contenedor-nuevo imagen-buena

VEASE TAMBIÉN
