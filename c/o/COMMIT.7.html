Paquete: postgresql

COMMIT(7) Documentación de PostgreSQL 18.1 COMMIT(7)

NOMBRE

COMMIT - confirma la transacción actual

SINOPSIS

COMMIT [ WORK | TRANSACTION ] [ AND [ NO ] CHAIN ]

DESCRIPCIÓN

COMMIT confirma la transacción actual. Todos los cambios realizados por la transacción se vuelven visibles para otros y se garantiza que serán duraderos en caso de que ocurra un fallo.

PARÁMETROS

WORK
TRANSACTION

Palabras clave opcionales. No tienen ningún efecto.

AND CHAIN

Si se especifica AND CHAIN, se inicia inmediatamente una nueva transacción con las mismas características de transacción (ver SET TRANSACTION (SET_TRANSACTION(7))) que la recién terminada. De lo contrario, no se inicia ninguna transacción nueva.

NOTAS

Utilice ROLLBACK(7) para abortar una transacción.

Emitir COMMIT cuando no se está dentro de una transacción no causa daño, pero provocará un mensaje de advertencia. COMMIT AND CHAIN cuando no se está dentro de una transacción es un error.

EJEMPLOS

Para confirmar la transacción actual y hacer permanentes todos los cambios:

COMMIT;

COMPATIBILIDAD

El comando COMMIT cumple con el estándar SQL. La forma COMMIT TRANSACTION es una extensión de PostgreSQL.

VER TAMBIÉN

BEGIN(7), ROLLBACK(7)
