mtx-context(1) Gestión de procesos de ConTeXt mtx-context(1)

NOMBRE


mtx-context - Gestión de procesos de ConTeXt

SINOPSIS

mtxrun --script context [ OPCIONES ... ] [ NOMBRESDEARCHIVO ]

DESCRIPCIÓN

Gestión de procesos de ConTeXt

OPCIONES: BÁSICAS

--run
procesar (uno o más) archivos (acción por defecto)
--make
crear formatos de context
--ctx=nombre
usar archivo ctx (especificación de gestión de procesos)
--noctx
ignorar directivas y banderas ctx
--interface
usar la interfaz de usuario especificada (por defecto: en)
--autopdf
cerrar el archivo pdf en el visor y lanzar el visor de pdf después
--purge
purgar archivos después de una ejecución o no (--pattern=...)
--purgeall
purgar todos los archivos después de una ejecución o no (--pattern=...)
--usemodule=lista
cargar el módulo o estilo dado, normalmente parte de la distribución
--environment=lista
cargar primero el archivo de entorno dado (estilos de documento)
--mode=lista
habilitar los modos dados (procesamiento condicional en estilos)
--path=lista
consultar también las rutas dadas al buscar archivos
--arguments=lista
establecer variables que pueden consultarse durante una ejecución (pares clave/valor)
--randomseed=número
establecer la semilla aleatoria
--result=nombre
renombrar la salida resultante al nombre dado
--trackers=lista
establecer variables de rastreo (mostrar lista con --showtrackers)
--directives=lista
establecer variables de directiva (mostrar lista con --showdirectives)
--silent=lista
deshabilitar categorías de registro (mostrar lista con --showlogcategories)
--strip
eliminar el código Lua (solo destinado a producción donde no se esperan errores)
--errors=lista
mostrar errores al final de una ejecución, salir si están en la lista (también con --silent)
--htmlerrorpage
generar página de errores html en su lugar (opcional: =scite)
--noconsole
deshabilitar el registro en la consola (solo archivo de registro)
--nodummy
no crear un archivo ficticio (puede confundir a los visores de pdf que mantienen el archivo en vista)
--purgeresult
purgar el archivo de resultado antes de la ejecución
--find=cadena
buscar el patrón dado en las fuentes de documentación
--forcexml
forzar stub xml
--forcecld
forzar stub cld (context lua document)
--forcelua
forzar stub lua (como texlua)
--forcemp
forzar stub mp
--arrange
ejecutar una pasada extra de imposición, dado que el estilo configura la imposición
--noarrange
ignorar las especificaciones de imposición en el estilo
--pages
informar números de página de páginas con nombres y listar referencias (--page=... o --page=...)
--jit
usar luajittex con jit desactivado (usar solo la máquina virtual más rápida)
--jiton
usar luajittex con jit activado (en la mayoría de los casos no es más rápido, incluso más lento)
--once
ejecutar solo una vez (no se produce archivo de datos de multipasada)
--runs
procesar como máximo esta cantidad de veces
--forcedruns
procesar esta cantidad de veces (permite ejecuciones de prueba de optimización)
--batchmode
ejecutar sin detenerse y no mostrar mensajes en la consola
--nonstopmode
ejecutar sin detenerse
--nocompactfonts
volver al escalado de fuentes menos eficiente (tradicional)
--nosynctex
nunca inicializar synctex (para ejecuciones de producción)
--synctex
ejecutar con synctex habilitado (mejor usar tupsynctex[state=start])
--nodates
omitir fechas de ejecución en el archivo pdf (valor opcional: un número (desplazamiento 1970) o cadena "AAAA-MM-DD HH:MM")
--nocompression
desactivar forzosamente la compresión en el backend
--trailerid
id de trailer alternativo (o constante)
--generate
generar base de datos de archivos etc. (como hace luatools)
--paranoid
no descender a .. y ../..
--version
informar la versión de context instalada
--global
asumir que el archivo dado está presente en otro lugar
--nofile
usar archivo ficticio como nombre de trabajo
--forceinput
usar este archivo como archivo de entrada en lugar del dado
--expert
mostrar algunas opciones más

OPCIONES: EXPERTO

--touch
actualizar número de versión de context (proporcionar también --expert, opcionalmente proporcionar --basepath)
--nostatistics
omitir estadísticas de ejecución al final de la ejecución
--profile
perfilar trabajo (usar: mtxrun --script profile --analyze)
--timing
generar resumen de tiempos y estadísticas
--keeptuc
conservar archivos tuc anteriores (nombretrabajo-tuc-[ejecución].tmp)
--keeppdf
conservar archivos pdf anteriores (nombretrabajo-pdf-keep.tmp)
--keeplog
conservar archivos de registro anteriores (nombretrabajo-log-[ejecución].tmp)
--notuc
no escribir archivo tuc
--lmtx
forzar modo lmtx (cuando esté disponible)

OPTIONS: EXPERT

--overloadmode=error|warning|0--6|255
habilitar la comprobación de sobrecarga de csname
--extra=name
procesar extras (mtx-context-... en distribución)
--extras
mostrar extras
--ownerpassword
cifrar el archivo (pdf) usando esta contraseña maestra
--userpassword
usar una contraseña adicional para abrir el documento
--permissions
lista de: imprimir, modificar, extraer, añadir, rellenar, ensamblar, calidad
--wtpdf
añadir un blob de conformidad wtpdf pero es mejor comprobar primero si aplica

OPTIONS: ESPECIAL

--pdftex
procesar archivo con texexec usando pdftex
--xetex
procesar archivo con texexec usando xetex
--mkii
procesar archivo con texexec
--pipe
no comprobar archivo y entrar en modo de desplazamiento (--dummyfile=whatever.tmp)
--parallel
procesar múltiples archivos al mismo tiempo (se puede especificar un número de procesos, por defecto: 8)
--parallellist
procesar comandos en este archivo (líneas que empiezan con 'context')
--sandbox
procesar archivo en un entorno limitado
--addbinarypath
añadir el binarypath (encontrado) al principio de los ejecutores
