Descripción detallada

Funciones de utilidad estáticas para administrar recursos de datos a nivel de búfer básico.

Esta clase es solo un alcance estático para algunas funciones de administración de recursos. Con esto, Coin puede registrar recursos predeterminados integrados que luego pueden recuperarse a través del mismo localizador de recursos, ya sea desde el disco (si está presente) y como respaldo, el búfer integrado (compilado).

Los localizadores de recursos tienen la forma de una URL con 'coin' como su esquema y un host vacío, por ejemplo, "coin://ruta/al/recurso.ext".

El prefijo "coin:" es para que Coin diferencie un localizador de recurso de un nombre de archivo (para uso de funciones multipropósito).

La ruta/al/recurso.ext es, para la mayoría de las plataformas, la ruta bajo la variable de entorno $COINDIR donde debe estar presente el archivo. Para Mac OS X, la ruta está bajo el directorio Resources/ del framework Inventor, si Coin se instaló como un framework.

El archivo en disco puede ser una versión actualizada, en comparación con el búfer compilado, por lo que los archivos externalizados tienen prioridad sobre los búferes integrados.

Un recurso no necesita tener un archivo externo correspondiente. Esto se configura en el parámetro de flags cuando se establece el recurso. En otras palabras, también puedes registrar recursos solo integrados.

Documentación de funciones

SbByteBuffer CoinResources::get (const char * resloc)

Devuelve un recurso si existe. Si la instalación de Coin lo permite, el recurso se cargará desde el archivo, pero si el archivo no se puede localizar o cargar, se devolverán versiones integradas en su lugar.

Retorna

TRUE si tiene éxito y FALSE si no existe dicho recurso.

SbBool CoinResources::set (const char * resloc, const SbByteBuffer & buffer, ResourceFlags flags = NONE)

Esta función registra un nuevo recurso. El localizador de recurso (resloc) debe tener el formato "coin:" seguido de una ruta de archivo relativa que debería conducir a la representación del archivo del recurso desde donde apunta la variable de entorno COINDIR. La ruta relativa debe usar / para la separación de directorios, y no \ si está en Microsoft Windows.

Si coloca COIN_RESOURCE_NOT_A_FILE en el argumento flags, no se realizará la búsqueda automática de archivos.

Retorna

TRUE si el recurso se estableció y FALSE si algo salió mal. Lo más probable es que se devuelva FALSE porque el recurso ya existe.

void CoinResources::freeLoadedExternals (void )

Esta función desasigna todos los búferes que se han cargado desde el disco. Los búferes internos no se liberarán, ya que se espera que estén compilados en la sección de datos de la biblioteca Coin.
