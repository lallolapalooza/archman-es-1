NOMBRE

coqnative - compilador nativo de Coq

SINOPSIS

coqnative [ opciones ] nombre_archivo

DESCRIPCIÓN

coqnative compila archivos vo a archivos binarios utilizados por el mecanismo de cómputo nativo del Asistente de Pruebas Coq. Consulte el Manual de Referencia para obtener más información. Devuelve el código de salida 0 si todas las tareas solicitadas tuvieron éxito. Un código de retorno distinto de cero significa que algo salió mal.

nombre_archivo es un archivo objeto de Coq (un .vo) para compilar a un binario nativo.

OPCIONES

-Q dir coqdir
Mapea el dir físico a coqdir lógico.
-R dir coqdir
Sinónimo de -Q.
-I dir
Ignorado, por compatibilidad.
-noinit
Ignorado, por compatibilidad.
-boot
Modo de arranque.
-coqlib dir
Anula la ubicación predeterminada de la biblioteca estándar.
-nI dir
Añade dir al conjunto de rutas para los archivos nativos de las dependencias.
-native-output-dir dir
Genera los archivos resultantes en dir.
-h, --help
Imprime la lista de opciones.
