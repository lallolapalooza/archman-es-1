countof(3) Manual de Funciones de Biblioteca countof(3)

NOMBRE

countof, _Countof - contar el número de elementos en un arreglo

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <stdcountof.h>
size_t countof(array);

DESCRIPCIÓN

Este operador cuenta el número de elementos en un arreglo.

Si el operando no es un arreglo, produce un error de compilación.

Existe una palabra clave, _Countof(), que se comporta de manera idéntica y puede usarse sin incluir <stdcountof.h>.

VALOR DE RETORNO

El número de elementos en el arreglo.

ESTÁNDARES

C2y.

HISTORIA

gcc 16, clang 21.

VER TAMBIÉN

operator(7)
