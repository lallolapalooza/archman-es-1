NOMBRE

cog-commit - Crear un nuevo commit convencional

SINOPSIS

cog-commit [-B|--breaking-change] [-e|--edit] [-s|--sign] [--skip-ci] [--skip-ci-override] [-a|--add] [-u|--update] [-h|--help] <TIPO> <MENSAJE> [ALCANCE]

DESCRIPCIÓN

Crear un nuevo commit convencional

OPCIONES

-B, --breaking-change
Crear un commit BREAKING CHANGE
-e, --edit
Abrir el mensaje del commit en un editor
-s, --sign
Firmar este commit
--skip-ci
Añadir la cadena skip-ci definida en cog.toml (o por defecto [skip ci]) al commit
--skip-ci-override <SKIP_CI_OVERRIDE>
Anular y añadir la cadena <SKIP_CI_OVERRIDE> al commit
-a, --add
Añadir archivos al commit (similar a git add .)
-u, --update
Actualizar pero no añadir archivos al commit (similar a git add -u .)
-h, --help
Imprimir ayuda
<TIPO>
Tipo de commit convencional

[valores posibles: build, chore, ci, docs, feat, fix, perf, refactor, revert, style, test]

<MENSAJE>
Descripción del commit
[ALCANCE]
Alcance del commit convencional
