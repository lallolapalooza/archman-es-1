coin240 - Nuevas características en Coin v2.4.0

La razón principal del lanzamiento de la versión 2.4.0 fue la opción de finalmente compilar Coin desde el código fuente en MS Windows sin tener que pasar por el proceso de Cygwin.

También se realizaron varios trabajos de optimización en el código de recorrido de renderizado, E/S de archivos y otras cosas.

Para la v2.4.1, las selecciones SoExtSelection LASSO y RECTANGLE podían ser abortadas por el usuario final al presionar la tecla 'END'. Por supuesto, no se necesitaron cambios en la API para esto.

Para la v2.4.2, añadimos soporte para texturas comprimidas a través de un campo invisible para la API/ABI en SoTexture2, llamado "enableCompressedTexture". Este campo permanecerá "invisible" hasta el lanzamiento de Coin v3.0.0, y solo se podrá acceder a él desde la entrada de archivos .iv o a través de la API SoFieldContainer.

Para la v2.4.6, se implementó SbViewVolume::getAlignRotation(), y SoToVRML2Action obtuvo soporte para SoUnits en relación con los nodos SoVRMLTransform.
