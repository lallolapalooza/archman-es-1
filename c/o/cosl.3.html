cos(3) Manual de funciones de la biblioteca cos(3)

NOMBRE

cos, cosf, cosl - función coseno

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double cos(double x);
float cosf(float x);
long double cosl(long double x);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

cosf(), cosl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven el coseno de x, donde x se da en radianes.

VALOR DEVUELTO

En caso de éxito, estas funciones devuelven el coseno de x.

Si x es un NaN, se devuelve un NaN.

Si x es infinito positivo o infinito negativo, ocurre un error de dominio y se devuelve un NaN.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un infinito
errno se establece en EDOM (pero ver BUGS). Se genera una excepción de punto flotante inválida (FE_INVALID).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
cos (), cosf (), cosl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C89, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD.

BUGS

Antes de glibc 2.10, la implementación de glibc no establecía errno en EDOM cuando ocurría un error de dominio.

VER TAMBIÉN

acos(3), asin(3), atan(3), atan2(3), ccos(3), sin(3), sincos(3), tan(3)
