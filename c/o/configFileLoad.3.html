NOMBRE

configFileLoad - analizar un archivo de configuración

SINOPSIS

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

const tOptionValue * configFileLoad(char const * fname);

DESCRIPCIÓN

Esta rutina cargará un archivo de configuración con nombre y analizará el texto como una opción de valor jerárquico. El descriptor de opción creado a partir de un archivo de definición de opción no se utiliza a través de esta interfaz. El valor devuelto se "denomina" con el nombre del archivo de entrada y es del tipo "OPARG_TYPE_HIERARCHY". Puede ser utilizado en llamadas a optionGetValue(), optionNextValue() y optionUnloadNested().

fname
el archivo a cargar

VALOR DE RETORNO

Una estructura de valor compuesto asignada.

ERRORES

Si el archivo no puede ser cargado o procesado, se devuelve NULL y se establece errno. Puede ser establecido por una llamada a open(2) mmap(2) u otras llamadas al sistema de archivos, o puede ser:

ENOENT - no se encontró el archivo.

ENOMSG - el archivo estaba vacío.

EINVAL - el contenido del archivo es inválido - no está bien formado.

ENOMEM - no hay suficiente memoria para asignar las estructuras necesarias. @end itemize
