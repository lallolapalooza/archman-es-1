NOMBRE

colorhug-backlight - Utilidad de retroiluminación para el colorímetro ColorHug

SINOPSIS

colorhug-backlight [ --verbose ] [ --repair ]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando colorhug-backlight.

colorhug-backlight utiliza el dispositivo ColorHug para alterar el nivel de retroiluminación y compensar el nivel cambiante de la luz ambiental.
