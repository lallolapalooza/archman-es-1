NOMBRE

coq-tex - procesa frases Coq incrustadas en archivos LaTeX

SINOPSIS

coq-tex [ -o archivo-salida ] [ -n ancho-linea ] [ -image imagen-coq ] [ -w ] [ -v ] [ -sl ] [ -hrule ] [ -small ] archivo-entrada ...

DESCRIPCIÓN

El filtro coq-tex extrae frases Coq incrustadas en archivos LaTeX, las evalúa e inserta el resultado de la evaluación después de cada frase.

Se proporcionan tres entornos LaTeX para incluir código Coq en los archivos de entrada:

coq_example
Las frases entre \begin{coq_example} y \end{coq_example} se evalúan y se copian al archivo de salida. Cada frase va seguida de la respuesta del bucle principal.
coq_example*
Las frases entre \begin{coq_example*} y \end{coq_example*} se evalúan y se copian al archivo de salida. Las respuestas del bucle principal se descartan.
coq_eval
Las frases entre \begin{coq_eval} y \end{coq_eval} se evalúan en silencio. No se copian al archivo de salida y las respuestas del bucle principal se descartan.

El código LaTeX resultante se almacena en el archivo archivo.v.tex si el archivo de entrada tiene un nombre de la forma archivo.tex, de lo contrario, el nombre del archivo de salida es el nombre del archivo de entrada con `.v.tex' añadido.

Los archivos producidos por coq-tex pueden ser procesados directamente por LaTeX. Tanto las frases Coq como la salida del bucle se tipografían en fuente de máquina de escribir.

OPCIONES

-o archivo-salida
Especifica el nombre de un archivo donde se almacenará la salida LaTeX. Un guion `-' hace que la salida LaTeX se imprima en la salida estándar.
-n ancho-linea
Establece el ancho de línea. El valor predeterminado es 72 caracteres. Las respuestas del bucle principal se ajustan si son más largas que el ancho de línea. No se realiza ajuste en el texto de entrada de Coq.
-image imagen-coq
Hace que el archivo imagen-coq se ejecute para evaluar las frases Coq. Por defecto, se utiliza el comando coqtop sin especificar ninguna ruta para evaluar las frases Coq.
-w
Hace que las líneas se ajusten en un espacio en blanco siempre que sea posible, evitando cortes de palabras en la salida. Por defecto, el ajuste se produce en el ancho de línea, independientemente de los cortes de palabras.
-v
Modo detallado. Imprime las respuestas de Coq en la salida estándar. Útil para detectar errores en frases Coq.
-sl
Modo cursiva. Las respuestas de Coq se escriben en una fuente cursiva.
-hrule
Modo de línea horizontal. Las partes de Coq se escriben entre dos líneas horizontales.
-small
Modo de fuente pequeña. Las partes de Coq se escriben en una fuente más pequeña.

ADVERTENCIAS

Las frases \begin... y \end... deben estar en una línea propia, sin caracteres antes de la barra invertida o después de la llave de cierre. Cada frase Coq debe terminar con `.' al final de una línea. Se acepta espacio en blanco entre `.' y el salto de línea, pero cualquier otro carácter provocará que coq-tex ignore el final de la frase, lo que resultará en una mezcla incorrecta de las respuestas en las frases. (Las respuestas ``se quedan atrás''.)
