NOMBRE

containers-sigstore-signing-params.yaml - sintaxis para el archivo de parámetros de firma sigstore

DESCRIPCIÓN

Los archivos de parámetros de firma sigstore se utilizan para almacenar opciones que pueden ser necesarias para crear firmas sigstore. No hay una ubicación predeterminada para estos archivos; son administrados por el usuario y se utilizan como entradas para una operación de firma de imagen de contenedor, por ejemplo, skopeo copy --sign-by-sigstore=archivo-parámetros.yaml o podman push --sign-by-sigstore=archivo-parámetros.yaml.

FORMATO

Los archivos de parámetros de firma sigstore utilizan YAML.

Muchos parámetros son opcionales, pero el archivo debe especificar lo suficiente para crear una firma; en particular, una clave privada o Fulcio.

Firma con Claves Privadas

•
privateKeyFile: ruta

Crea una firma utilizando una clave privada en ruta.
La existencia de este campo activa el uso de una clave privada.

•
privateKeyPassphraseFile: ruta-contraseña

Lee la contraseña requerida para usar privateKeyFile desde ruta-contraseña.
Opcional: si esto no está configurado, el usuario debe proporcionar la contraseña interactivamente.

Firma con Certificados generados por Fulcio

En lugar de una clave privada estática, el proceso de firma genera un par de claves de corta duración y solicita a un servidor Fulcio que emita un certificado para ese par de claves, basándose en la autenticación del usuario a un proveedor OpenID Connect.

Para especificar Fulcio, incluya un sub-objeto fulcio con una o más de las siguientes claves. Además, también se debe especificar un servidor Rekor.

•
fulcioURL: URL

Requerido. URL del servidor Fulcio a usar.

•
oidcMode: interactive | deviceGrant | staticToken

Requerido. Especifica cómo obtener la credencial OpenID Connect necesaria.

interactive abre un navegador web en la misma máquina o, si no es posible,
pide al usuario que abra un navegador manualmente y escriba el código proporcionado.
Requiere que el usuario pueda interactuar directamente con el proceso de firma.

deviceGrant utiliza un flujo de concesión de autorización de dispositivo (RFC 8628).
Requiere que el usuario pueda leer el texto impreso por el proceso de firma y actuar sobre él con relativa prontitud.

staticToken proporciona un "ID token" de OpenID Connect preexistente, que debe haber sido obtenido por separado.

•
oidcIssuerURL: URL

Requerido para oidcMode: interactive o deviceGrant. URL de un servidor emisor de OpenID Connect con el que autenticarse.

•
oidcClientID: ID de cliente

Se utiliza para oidcMode: interactive o deviceGrant para identificar al cliente al contactar al emisor.
Opcional, pero probablemente necesario en esos casos.

•
oidcClientSecret: secreto de cliente

Se utiliza para oidcMode: interactive o deviceGrant para autenticar al cliente al contactar al emisor.
Opcional.

•
oidcIDToken: token

Requerido para oidcMode: staticToken.
Un token ID de OpenID Connect que identifica al usuario (y autoriza la emisión del certificado).

Grabación de la Firma en un Servidor de Transparencia Rekor

Esto se puede combinar con una clave privada o Fulcio. Es, en la práctica, requerido para Fulcio; es opcional cuando se usa una clave privada estática, pero necesario para la interoperabilidad con la configuración predeterminada de cosign.

•
rekorURL: URL

URL del servidor Rekor a usar.

EJEMPLOS

Firmar Usando una Clave Privada Preexistente

Utiliza el servidor Rekor de la "infraestructura comunitaria".

privateKeyFile: "/home/usuario/sigstore/clave-privada.key"
privateKeyPassphraseFile: "/mnt/usuario/contraseña-clave-privada-sigstore"
rekorURL: "https://rekor.sigstore.dev"

Firmar Usando un Certificado emitido por Fulcio

Utiliza los servidores Fulcio y Rekor de la "infraestructura comunitaria", y el emisor OIDC Dex que delega a otros emisores importantes como Google y GitHub.

Otras configuraciones muy probablemente necesitarán también proporcionar un secreto de cliente OIDC.

fulcio:
  fulcioURL: "https://fulcio.sigstore.dev"
  oidcMode: "interactive"
  oidcIssuerURL: "https://oauth2.sigstore.dev/auth"
  oidcClientID: "sigstore"
rekorURL: "https://rekor.sigstore.dev"
