confstr(3) Manual de Funciones de Biblioteca confstr(3)

NOMBRE

confstr - obtener variables de cadena dependientes de la configuración

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
size_t confstr(size_t size;
               int name, char buf[size], size_t size);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

confstr():

    _POSIX_C_SOURCE >= 2 || _XOPEN_SOURCE

DESCRIPCIÓN

confstr() obtiene el valor de variables de cadena dependientes de la configuración.

El argumento name es la variable del sistema que se va a consultar. Las siguientes variables son compatibles:

_CS_GNU_LIBC_VERSION (solo biblioteca C de GNU; desde glibc 2.3.2)
Una cadena que identifica la versión de la biblioteca C de GNU en este sistema (por ejemplo, "glibc 2.3.4").
_CS_GNU_LIBPTHREAD_VERSION (solo biblioteca C de GNU; desde glibc 2.3.2)
Una cadena que identifica la implementación POSIX proporcionada por esta biblioteca C (por ejemplo, "NPTL 2.3.4" o "linuxthreads-0.10").
_CS_PATH
Un valor para la variable PATH que indica dónde se pueden encontrar todas las utilidades estándar de POSIX.2.

Si buf no es NULL y size no es cero, confstr() copia el valor de la cadena a buf truncado a size - 1 bytes si es necesario, con un byte nulo ('\0') como terminador. Esto se puede detectar comparando el valor de retorno de confstr() con size.

Si size es cero y buf es NULL, confstr() simplemente devuelve el valor según se define a continuación.

VALOR DE RETORNO

Si name es una variable de configuración válida, confstr() devuelve el número de bytes (incluido el byte nulo terminador) que se requerirían para contener todo el valor de esa variable. Este valor puede ser mayor que size, lo que significa que el valor en buf está truncado.

Si name es una variable de configuración válida, pero esa variable no tiene valor, entonces confstr() devuelve 0. Si name no corresponde a una variable de configuración válida, confstr() devuelve 0 y se establece errno a EINVAL.

ERRORES

EINVAL
El valor de name es inválido.

ATRIBUTOS

Interfaz Atributo Valor

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

EJEMPLOS

El siguiente fragmento de código determina la ruta donde encontrar las utilidades del sistema POSIX.2:


char *pathbuf;
size_t n;
n = confstr(_CS_PATH, NULL, (size_t) 0);
pathbuf = malloc(n);
if (pathbuf == NULL)
    abort();
confstr(_CS_PATH, pathbuf, n);
