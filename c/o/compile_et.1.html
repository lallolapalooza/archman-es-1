COMPILE_ET(1) Manual de Comandos Generales COMPILE_ET(1)

NOMBRE

compile_et - compilador de tablas de errores

SINOPSIS

compile_et archivo

DESCRIPCIÓN

Compile_et convierte una tabla que enumera nombres de códigos de error y sus mensajes asociados en un archivo fuente C adecuado para su uso con la biblioteca com_err(3).

El nombre del archivo fuente debe terminar con el sufijo ``.et''; el archivo consiste en una declaración que proporciona el nombre (de hasta cuatro caracteres de longitud) de la tabla de códigos de error:

error_table nombre

seguido de hasta 256 entradas de la forma:

error_code nombre, " cadena "

y un final

end

para indicar el final de la tabla.

El nombre de la tabla se utiliza para construir el nombre de una subrutina initialize_XXXX_error_table que debe ser llamada para que la biblioteca com_err reconozca la tabla de errores.

Los diversos códigos de error definidos se les asignan números secuencialmente crecientes (comenzando con un número grande calculado como una función hash del nombre de la tabla); por lo tanto, para compatibilidad, se sugiere que los nuevos códigos se agreguen solo al final de una tabla existente, y que no se eliminen códigos de las tablas.

Los nombres definidos en la tabla se colocan en un archivo de cabecera C con directivas de preprocesador que los definen como constantes enteras de hasta 32 bits de magnitud.

También se genera un archivo fuente C que debe compilarse y vincularse con los archivos objeto que hacen referencia a estos códigos de error; contiene el texto de los mensajes y la subrutina de inicialización. Ambos archivos C tienen nombres derivados del archivo fuente original, con el sufijo ``.et'' reemplazado por ``.c'' y ``.h''.

Un ``#'' en el archivo fuente se trata como un carácter de comentario, y todo el texto restante hasta el final de la línea fuente se ignorará.

ERRORES

Dado que el compile_et original utiliza un analizador muy simple basado en yacc(1), y esta versión actual de compile_et utiliza una combinación de scripts awk/sed, su recuperación de errores deja mucho que desear.

VER TAMBIÉN

com_err (3).

Ken Raeburn, "A Common Error Description Library for UNIX".
