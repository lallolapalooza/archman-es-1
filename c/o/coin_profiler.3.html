Descripción Detallada

Coin incluye funcionalidad de perfilado del grafo de escena.

Esta funcionalidad está destinada a ser utilizada durante el desarrollo de aplicaciones para identificar cuellos de botella de rendimiento en aplicaciones basadas en Coin con respecto a cómo se utiliza Coin y con respecto a problemas en la implementación de Coin.

El código de perfilado se puede habilitar en aplicaciones Coin existentes sin necesidad de añadir código, habilitándolo mediante el uso de algunas variables de entorno. Para necesidades de perfilado particulares, el comportamiento predeterminado que se puede activar a través de variables de entorno podría no funcionar bien (podría tener un pipeline de renderizado especializado que provoque que la salida esté corrupta) o centrarse en la información que necesita (la aplicación completa podría añadir ruido al sistema que Coin no separaría). En tales casos, será necesario el acceso programático al subsistema de perfilado para obtener mejores resultados.
