containers-storage-list-layer-data 1 Diciembre 2020

NOMBRE

containers-storage list-layer-data - Listar datos lookaside para una capa

SINOPSIS

containers-storage list-layer-data ID_de_capa

DESCRIPCIÓN

Lista las piezas de datos con nombre que están asociadas con una capa.

EJEMPLO

containers-storage list-layer-data 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
