cog(1) Manual de Comandos Generales cog(1)

NOMBRE

cog - Una herramienta de línea de comandos para las especificaciones de commits convencionales y semver

SINOPSIS

cog [-v|--verbose]... [-q|--quiet] [--config] [-h|--help] [-V|--version] <subcomandos>

DESCRIPCIÓN

Una herramienta de línea de comandos para las especificaciones de commits convencionales y semver

OPCIONES

-v, --verbose
El nivel de verbosidad: -v para ERROR, -vv para WARNING, -vvv para INFO
-q, --quiet
Silenciar toda la salida, independientemente del valor de verbosidad
--config <CONFIG> [por defecto: cog.toml]
Ruta al archivo de configuración
-h, --help
Imprimir ayuda
-V, --version
Imprimir versión

SUBCOMANDOS

cog-check(1)
Verificar todos los mensajes de commit contra la especificación de commit convencional
cog-commit(1)
Crear un nuevo commit convencional
cog-edit(1)
Renombrar interactivamente mensajes de commit inválidos
cog-log(1)
Como git log pero para commits convencionales
cog-verify(1)
Verificar un único mensaje de commit
cog-changelog(1)
Mostrar un registro de cambios para el rango de oid de commit dado
cog-get-version(1)
Obtener la versión actual
cog-bump(1)
Confirmar el registro de cambios desde la última etiqueta hasta HEAD y crear una nueva etiqueta
cog-init(1)
Instalar archivos de configuración de cog
cog-install-hook(1)
Añadir ganchos de git al repositorio
cog-generate-completions(1)
Generar completaciones de shell
cog-help(1)
Imprimir este mensaje o la ayuda de los subcomandos dados
