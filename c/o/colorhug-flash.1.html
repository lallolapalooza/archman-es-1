NOMBRE

colorhug-flash - Actualizador de firmware para el colorímetro ColorHug

SINOPSIS

colorhug-flash [ --verbose ] [ --filename ]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando colorhug-flash.

colorhug-flash te permite actualizar el firmware de tu colorímetro ColorHug de Hughski.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

--help
Muestra un resumen de las opciones.
--verbose
Muestra información de depuración adicional.
--filename
Actualiza un archivo de firmware específico.

Normalmente colorhug-flash contacta con Internet y descarga metadatos de actualización para determinar el archivo de firmware a utilizar. Esta opción permite al usuario utilizar una imagen personalizada.

ENTORNO

Establecer COLORHUG_EMULATE te permitirá ejecutar esta herramienta sin ningún hardware real conectado, aunque el programa fallará cuando se verifique la escritura del flash.

AUTOR
