coin_xml_parsing - Análisis XML con Coin

Para Coin 3.0, añadimos un analizador XML a Coin. Este documento describe cómo se puede utilizar para propósitos genéricos.

¿Por qué otro analizador XML, te preguntarás? En primer lugar, el analizador XML es en realidad un analizador de terceros, Expat. Coin lo necesitaba, y muchos proyectos dependientes de Coin también lo necesitaban. Por lo tanto, necesitábamos exponer una API para él. Sin embargo, al integrar un analizador de terceros en Coin, no podemos exponer su API directamente, o otros proyectos que también usan Expat tendrían conflictos. Por lo tanto, necesitamos exponer la API XML con una API única, de ahí la API que ves aquí. Se basa en una API DOM XML que usamos (o usábamos) en un par de otros proyectos, pero se ha modificado para encajar en Coin y para envolver a Expat (la implementación original simplemente usaba flex).

El analizador XML es tanto un analizador de flujo como un analizador DOM. Ser un analizador de flujo significa que los documentos se pueden leer sin tener que estar completamente contenidos en memoria. Cuando se usa como analizador DOM, todo el documento se analiza completamente primero, y luego se inspecciona por el código cliente recorriendo el DOM. Los dos modos en realidad se pueden mezclar arbitrariamente si terminar con un DOM parcial resulta útil.

El analizador XML tiene una API de C y una API de C++. La API de C++ es solo una envoltura alrededor de la API de C y solo sirve como conveniencia si prefieres leer/escribir código C++ (que es más conciso) sobre código C más verboso.

La convención de nombres de la API de C puede parecer un poco extraña, a menos que hayas escrito bibliotecas para ser envueltas para lenguajes tipo scheme/lisp antes. Entonces podrías estar familiarizado con la convención de sufijar tus funciones basándose en su comportamiento/significado de uso. Las funciones mutantes se sufijan con "!" o "_x" (signo de exclamación), y los predicados se sufijan con "?" o "_p" en C.

La forma más sencilla de usar el analizador XML es simplemente llamar a cc_xml_read_file(filename) y luego recorrer el modelo DOM utilizando cc_xml_doc_get_root(), cc_xml_elt_get_child() y cc_xml_elt_get_attr().
