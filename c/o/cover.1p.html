COVER(1p) Documentación de Perl aportada por el usuario COVER(1p)

NOMBRE

cover - informar estadísticas de cobertura

VERSIÓN

versión 1.51

SINOPSIS

cover -test
cover -report html_basic

DESCRIPCIÓN

Informar estadísticas de cobertura en una variedad de formatos.

La opción de resumen produce un resumen textual corto. Otros informes están disponibles usando la opción de informe.

Los siguientes informes están disponibles actualmente:

html        - informes detallados en HTML  (por defecto)
html_basic  - informes detallados en HTML con resaltado de sintaxis
text        - resumen detallado en texto
compilation - salida en un formato similar a los errores de Perl
json        - salida en formato JSON
vim         - mostrar información de cobertura en la canaleta de vim

OPCIONES

Se admiten las siguientes opciones de línea de comandos:

-h -help              - mostrar ayuda
-i -info              - mostrar documentación
-v -version           - mostrar versión
-silent               - no imprimir mensajes informativos (por defecto desactivado)
-summary              - dar informe de resumen                (por defecto activado)
-report formato_informe - formato del informe                      (por defecto html)
-outputdir dir        - directorio para la salida               (base de datos db dada por defecto)
-launch               - lanzar informe en visor (si está disponible) (por defecto desactivado)
-select archivo       - informar solo sobre el archivo             (por defecto todos)
-ignore archivo       - no informar sobre el archivo              (por defecto ninguno)
-select_re RE         - añadir a los RE de los archivos a seleccionar (por defecto ninguno)
-ignore_re RE         - añadir a los RE de los archivos a ignorar   (por defecto ninguno)
-relative_only        - para XS, ignorar rutas absolutas          (por defecto desactivado)
-gcov_chdir           - para XS, ejecutar gcov en subdirectorios    (por defecto desactivado)
-write [db]           - escribir la base de datos fusionada         (por defecto desactivado)
-delete               - eliminar bases de datos                   (por defecto desactivado)
-dump_db              - volcar bases de datos (para depuración)    (por defecto desactivado)
-coverage criterio    - informar sobre criterio  (por defecto todo lo disponible)
-test                 - eliminar bases de datos y ejecutar make test (por defecto desactivado)
-gcov                 - ejecutar gcov para cubrir código XS      (por defecto activado si se usa gcc)
-make make_prog       - usar el programa 'make' dado para 'make test'
-prefer_lib           - preferir archivos en lib                  (por defecto desactivado)
-ignore_covered_err   - permitir cubrir código no cubrible        (por defecto desactivado)
-add_uncoverable_point    cadena
-delete_uncoverable_point cadena
-clean_uncoverable_points
-uncoverable_file         archivo
otras opciones específicas del formato de informe
coverage_database [coverage_database ...]

Las opciones "-report", "-select", "-ignore", "-select_re", "-ignore_re" y "-coverage" pueden especificarse varias veces.

FORMATOS DE INFORME

Las siguientes opciones de "-report" están disponibles en el módulo principal. Otros informes pueden estar disponibles si se han instalado desde paquetes externos.

html|html_minimal (por defecto)
Informes en HTML. Los umbrales de porcentaje se codifican por colores y son configurables mediante -report_c0 <entero>, -report_c1 <entero> y -report_c2 <entero>.: 
0%      75%      90%      100%
|   ..   |   ..   |   ..   |
   <c0      <c1      <c2   c3
   rojo    amarillo naranja verde
html_basic
Informes en HTML con resaltado de sintaxis si se detecta el módulo PPI::HTML o Perl::Tidy. Al igual que en los informes html|html_minimal, los umbrales de porcentaje se codifican por colores y son configurables.
text
Informes en texto plano.
compilation
Un informe textual en un formato similar al que genera el propio Perl, de modo que el informe pueda ser utilizado por tu editor u otras herramientas de informes para mostrar dónde falta cobertura.
json
Un informe en formato JSON.
vim
Un informe adecuado para usar con el editor vim para mostrar datos de cobertura en la columna de signos.

DETALLES

Se puede especificar cualquier número de bases de datos de cobertura en la línea de comandos. Estas bases de datos se fusionarán y los informes se basarán en la información fusionada. Si no se especifican bases de datos, se utilizará la base de datos por defecto (cover_db).

La opción "-write" escribirá la base de datos fusionada. Si no se da nombre a la nueva base de datos, se sobrescribirá la primera base de datos leída. Cuando se utiliza esta opción, no se generan informes por defecto.

Especifique las opciones "-select", "-select_re", "-ignore" y "-ignore_re" para informar sobre archivos específicos. "-select" e "-ignore" se interpretan como patrones de shell; "-select_re" y "-ignore_re" se interpretan como expresiones regulares.

Especifique las opciones "-coverage" para informar sobre criterios específicos. Por defecto, se informará toda la información disponible sobre todos los criterios en todos los archivos. Las opciones de cobertura disponibles son statement, branch, condition, subroutine, pod y default (que equivale a todas las opciones disponibles). Sin embargo, si sabes que solo quieres información de cobertura para ciertos criterios, es mejor recopilar datos solo para esos criterios en primer lugar, especificándolos en ese momento. Esto hará que los procesos de recopilación de datos y de informes sean más rápidos y menos intensivos en memoria. Ver la documentación de Devel::Cover para más información.

Si quieres todo *excepto* algunos criterios, puedes decir algo como "-coverage default,-pod".

Si especifica múltiples opciones de "-report", asegúrese de que no entren en conflicto. Por ejemplo, los diferentes informes HTML se sobrescribirán entre sí.

La opción "-test" eliminará las bases de datos y ejecutará tus pruebas para generar nuevos datos de cobertura antes de informar sobre ellos. Devel::Cover sabe cómo trabajar con los Makefiles estándar de Perl, así como con las distribuciones basadas en Module::Build. Para instrucciones detalladas, consulta la documentación de ExtUtils::MakeMaker en https://metacpan.org/module/ExtUtils::MakeMaker o para Module::Build en https://metacpan.org/module/Module::Build, ambos vienen de serie en las distribuciones recientes de Perl.

La opción "-gcov" intentará ejecutar gcov en cualquier código XS. Esto requiere que estés usando gcc, por supuesto. Si estás usando la opción "-test", se activará por defecto. Si tienes código XS en subdirectorios, probablemente necesitarás añadir la opción "-gcov_chdir" ya que gcov parece funcionar mejor con eso.

La opción "-prefer_lib" indica a Devel::Cover que informe sobre archivos en el directorio lib aunque se hayan utilizado desde el directorio blib.

La opción "-ignore_covered_err" no marcará un error si se cubre código no cubrible.

ESTADO DE SALIDA

Se devuelven los siguientes valores de salida:

0 Todas las operaciones se completaron con éxito.

>0 Ocurrió un error.

Con la opción -test se devuelve el estado de salida de la ejecución de pruebas subyacente.
