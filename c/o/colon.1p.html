COLON(1P) Manual del Programador POSIX COLON(1P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

colon — utilidad nula

SINOPSIS

: [argumento...]

DESCRIPCIÓN

Esta utilidad solo expandirá los argumentos del comando. Se utiliza cuando se necesita un comando, como en la condición then de un comando if, pero no se va a hacer nada con el comando.

OPCIONES

Ninguna.

OPERANDOS

Véase la DESCRIPCIÓN.

ENTRADA ESTÁNDAR

No utilizada.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Ninguna.

EVENTOS ASÍNCRONOS

Predeterminado.

SALIDA ESTÁNDAR

No utilizada.

ERROR ESTÁNDAR

El error estándar se utilizará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

DESCRIPCIÓN EXTENDIDA

Ninguna.

ESTADO DE SALIDA

Cero.

CONSECUENCIAS DE LOS ERRORES

Predeterminado.

Las siguientes secciones son informativas.

USO DE LA APLICACIÓN

Ninguno.

EJEMPLOS

: ${X=abc}
if     false
then   :
else   echo $X
fi
abc

Al igual que con cualquiera de los comandos internos especiales, la utilidad nula también puede tener asignaciones de variables y redirecciones asociadas, como:

x=y : > z

lo que establece la variable x al valor y (para que persista después de que la utilidad nula complete) y crea o trunca el archivo z.
