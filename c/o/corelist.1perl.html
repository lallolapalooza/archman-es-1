CORELIST(1perl) Guía de referencia para programadores de Perl CORELIST(1perl)

NOMBRE

corelist - una interfaz de línea de comandos para Module::CoreList

DESCRIPCIÓN

Ver Module::CoreList para más detalles.

SINOPSIS

corelist -v
corelist [-a|-d] <NombreModulo> | /<RegexModulo>/ [<VersionModulo>] ...
corelist [-v <VersionPerl>] [ <NombreModulo> | /<RegexModulo>/ ] ...
corelist [-r <VersionPerl>] ...
corelist --utils [-d] <NombreUtilidad> [<NombreUtilidad>] ...
corelist --utils -v <VersionPerl>
corelist --feature <NombreCaracteristica> [<NombreCaracteristica>] ...
corelist --diff VersionPerl VersionPerl
corelist --upstream <NombreModulo>

-d
encuentra la primera versión de perl donde se lanzó un módulo por fecha, y no por número de versión (como es el predeterminado).
--diff
Dadas dos versiones de perl, esto imprime una tabla legible por humanos de todos los cambios de módulos entre las dos. El formato de salida puede cambiar en el futuro y está destinado a *humanos*, no a programas. Para programas, use la API de Module::CoreList.
-? or -help
¡ayuda! ¡ayuda! ¡ayuda! para ver más ayuda, prueba --man.
-man
toda la ayuda
-v
enumera todas las versiones de lanzamiento de perl para las que tenemos CoreList.

Si pasas un argumento de versión (valor de $], como 5.00503 o 5.008008), obtienes una lista de todos los módulos y sus respectivas versiones. (Si tienes el módulo "version", también puedes usar números de versión de estilo nuevo, como 5.8.8.)

En el contexto de filtrado de módulos, se puede usar como filtro de versión de Perl.

-r
enumera todos los lanzamientos de perl y cuándo se lanzaron

Si pasas una versión de perl, obtienes la fecha de lanzamiento solo para esa versión.

--utils
enumera la primera versión de perl con la que se lanzó cada programa utilitario llamado

Puede usarse con -d para modificar los criterios del primer lanzamiento.

Si se usa con -v <version>, se enumeran todos los utilitarios lanzados con esa versión de perl, y se ignoran los programas utilitarios llamados en la línea de comandos.

--feature, -f
enumera el primer paquete de versiones de cada característica nombrada dada
--upstream, -u
Muestra si el módulo dado se mantiene principalmente en el núcleo de perl o en CPAN y la URL del rastreador de errores.

Como caso especial, si especificas el nombre del módulo "Unicode", obtendrás el número de versión de la Base de Datos de Caracteres Unicode incluida con las versiones de perl solicitadas.

EJEMPLOS

$ corelist File::Spec
File::Spec se lanzó por primera vez con perl 5.005
$ corelist File::Spec 0.83
File::Spec 0.83 se lanzó con perl 5.007003
$ corelist File::Spec 0.89
File::Spec 0.89 no estaba en CORE (o eso creo)
$ corelist File::Spec::Aliens
File::Spec::Aliens  no estaba en CORE (o eso creo)
