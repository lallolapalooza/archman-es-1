CORE(3perl) Guía de Referencia del Programador de Perl CORE(3perl)

NOMBRE

CORE - Espacio de nombres para las rutinas principales de Perl

SINOPSIS

BEGIN {
    *CORE::GLOBAL::hex = sub { 1; };
}
print hex("0x50"),"\n";                     # imprime 1
print CORE::hex("0x50"),"\n";               # imprime 80
CORE::say "yes";                            # imprime yes
BEGIN { *shove = \&CORE::push; }
shove @array, 1,2,3;                        # empuja en @array

DESCRIPCIÓN

El espacio de nombres "CORE" da acceso a las funciones integradas originales de Perl. El paquete "CORE" está integrado en Perl y, por lo tanto, no necesita usar o requerir un módulo hipotético "CORE" antes de acceder a las rutinas de este espacio de nombres.

Una lista de las funciones integradas en Perl se puede encontrar en perlfunc.

Para todas las palabras clave de Perl, un prefijo "CORE::" forzará el uso de la función integrada, incluso si ha sido sobrescrita o normalmente requeriría el pragma feature. A pesar de las apariencias, esto no tiene nada que ver con el paquete CORE, sino que es parte de la sintaxis de Perl.

Para muchas funciones de Perl, el paquete CORE contiene subrutinas reales. Esta característica es nueva en Perl 5.16. Puede tomar referencias a estas y crear alias. Sin embargo, algunas solo se pueden llamar como barewords; es decir, no puede usar la sintaxis de ampersand (&foo) ni llamarlas a través de referencias. Vea el ejemplo "shove" anterior. Estas subrutinas existen para todas las palabras clave, excepto las siguientes:

"__DATA__", "__END__", "and", "cmp", "default", "do", "dump", "else", "elsif", "eq", "eval", "for", "foreach", "format", "ge", "given", "goto", "grep", "gt", "if", "last", "le", "local", "lt", "m", "map", "my", "ne", "next", "no", "or", "our", "package", "print", "printf", "q", "qq", "qr", "qw", "qx", "redo", "require", "return", "s", "say", "sort", "state", "sub", "tr", "unless", "until", "use", "when", "while", "x", "xor", "y"

La llamada con sintaxis de ampersand y a través de referencias no funciona para las siguientes funciones, ya que tienen sintaxis especial que no siempre se puede traducir a una lista simple (por ejemplo, "eof" vs eof()):

"chomp", "chop", "defined", "delete", "eof", "exec", "exists", "lstat", "split", "stat", "system", "truncate", "unlink"

SOBRESCRITURA DE FUNCIONES CORE

Para sobrescribir una rutina integrada de Perl con su propia versión, necesita importarla en tiempo de compilación. Esto se puede lograr convenientemente con el pragma "subs". Esto afectará solo al paquete en el que haya importado dicha subrutina:

use subs 'chdir';
sub chdir { ... }
chdir $somewhere;

Para sobrescribir una función integrada globalmente (es decir, en todos los espacios de nombres), necesita importar su función al pseudo-espacio de nombres "CORE::GLOBAL" en tiempo de compilación:

BEGIN {
    *CORE::GLOBAL::hex = sub {
        # ... su código aquí
    };
}

La nueva rutina se llamará cada vez que se llame a una función integrada sin un paquete calificador:

print hex("0x50"),"\n";                     # imprime 1

En ambos casos, si desea acceder a la rutina original sin modificar, use el prefijo "CORE::":

print CORE::hex("0x50"),"\n";               # imprime 80
