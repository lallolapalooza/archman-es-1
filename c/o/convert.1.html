convert(1) Manual de Comandos Generales convert(1)

NOMBRE

convert - convierte entre formatos de imagen, así como redimensionar una imagen, desenfocar, recortar, quitar motas, difuminar, dibujar sobre, voltear, unir, re-muestrear y mucho más.

SINOPSIS

magick convert [opciones-de-entrada] archivo-de-entrada [opciones-de-salida] archivo-de-salida

DESCRIPCIÓN GENERAL

El programa convert es un miembro del conjunto de herramientas ImageMagick(1). Úselo para convertir entre formatos de imagen, así como redimensionar una imagen, desenfocar, recortar, quitar motas, difuminar, dibujar sobre, voltear, unir, re-muestrear y mucho más.

Para más información sobre el comando convert, abra en su navegador el archivo file:///usr/share/doc/ImageMagick-7/www/convert.html o https://imagemagick.org/script/convert.php.

Usar cualquier configuración u operador como una opción de salida. Solo un número limitado de configuraciones son opciones de entrada. Incluyen: -antialias, -caption, -density, -define, -encoding, -font, -pointsize, -size y -texture, así como cualquiera de las opciones varias.

Por defecto, el formato de imagen de `file' se determina por su número mágico. Para especificar un formato de imagen particular, preceder el nombre del archivo con un nombre de formato de imagen y dos puntos (es decir ps:image) o especificar el tipo de imagen como el sufijo del nombre de archivo (es decir image.ps). Especificar 'file' como '-' para entrada o salida estándar.
