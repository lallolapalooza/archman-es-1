COLORMGR(1) Comandos de usuario COLORMGR(1)

NOMBRE

colormgr - Herramienta de prueba del gestor de color

SINOPSIS

colormgr [--verbose] [--version]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando colormgr.

colormgr permite a un administrador ver y cambiar las correspondencias de perfiles de color a dispositivos.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que empiezan con dos guiones (‘-’). A continuación se incluye un resumen de las opciones.

--help

Muestra un resumen de las opciones.

COMANDOS

Este programa toma comandos con un número variable de argumentos.

create-device id_dispositivo alcance

Crea un dispositivo

create-profile id_perfil alcance

Crea un perfil

delete-device dispositivo

Elimina un dispositivo

delete-profile perfil

Elimina un perfil

device-add-profile dispositivo perfil

Añade un perfil a un dispositivo que ya existe

device-get-default-profile dispositivo

Obtiene el perfil predeterminado para un dispositivo

device-get-profile-for-qualifier dispositivo calificador

Devuelve todos los perfiles que coinciden con un calificador

device-inhibit dispositivo tiempo_de_espera

Inhabilita perfiles de color para este dispositivo

device-make-profile-default dispositivo perfil

Establece un perfil como predeterminado para un dispositivo

device-set-enabled

Habilita o deshabilita el dispositivo

device-set-kind dispositivo tipo

Establece el tipo de dispositivo

device-set-model dispositivo modelo

Establece el modelo del dispositivo

device-set-serial dispositivo serie

Establece el número de serie del dispositivo

device-set-vendor dispositivo vendedor

Establece el vendedor del dispositivo

find-device id_dispositivo

Busca un dispositivo por su ID

find-device-by-property clave valor

Busca un dispositivo con un valor de propiedad dado

find-profile id_perfil

Busca un perfil por su ID

find-profile-by-filename nombre_archivo

Busca un perfil por su nombre de archivo

get-devices

Obtiene todos los dispositivos gestionados por color

get-devices-by-kind tipo

Obtiene todos los dispositivos gestionados por color de un tipo específico

get-profiles

Obtiene todos los perfiles de color disponibles

get-sensor-reading tipo_pantalla

Obtiene una lectura de un sensor

get-sensors

Obtiene todos los sensores de color disponibles

get-standard-space espacio_estandar

Obtiene un espacio de color estándar

import-profile nombre_archivo

Copia un archivo .icc al directorio correcto por usuario y muestra información sobre el perfil importado.

profile-set-property perfil nombre valor

Establece propiedades adicionales en el perfil

sensor-lock

Bloquea el sensor de color

sensor-set-options nombre valor

Establece una o más opciones del sensor
