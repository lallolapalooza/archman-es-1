containers-storage-create-layer 1 August 2016

NOMBRE

containers-storage create-layer - Crear una capa

SINOPSIS

containers-storage create-layer [opciones [...]] [nombreOIdDeCapaPadre]

DESCRIPCIÓN

Crea una nueva capa que tiene como padre una capa especificada o, si no se especifica ningún padre, está vacía.

OPCIONES

-n nombre

Establece un nombre opcional para la capa. Si el nombre ya está en uso, se devuelve un error.

-i | --id ID

Establece el ID para la capa. Si no se especifica ninguno, se genera uno.

-l | --label etiqueta-de-montaje

Establece la etiqueta que se asignará como contexto SELinux al montar la capa.

EJEMPLO

containers-storage create-layer -f manifest.json -n nueva-capa capa-anterior
