coin_vbo_rendering - Renderizado de arrays de vértices y VBO en Coin

Coin 2.5 añadió soporte mejorado para el renderizado de arrays de vértices y VBO de OpenGL. Esto puede resultar en importantes mejoras de rendimiento de renderizado en comparación con el antiguo código de renderizado. El nuevo código de renderizado se ha añadido para los nodos SoIndexedFaceSet, SoVRMLIndexedFaceSet, SoIndexedLineSet, SoVRMLIndexedLineSet, SoPointSet, SoFaceSet y SoVRMLPointSet.

Para aprovechar las mejoras de rendimiento que ofrecen los arrays de vértices y el renderizado VBO, necesitarás organizar tus datos de vértices de manera que sea posible renderizarlos con arrays de vértices de OpenGL. El renderizado de arrays de vértices de OpenGL no soporta múltiples arrays de índices, por lo que todos tus datos de vértices (coordenadas, normales, colores y coordenadas de textura) deben usar el mismo array de índices; o usar vinculación GENERAL. Para los nodos indexados, esto significa que PER_VERTEX_INDEXED y GENERAL son las únicas vinculaciones soportadas para materiales, normales y coordenadas de textura. Cuando se utiliza la vinculación PER_VERTEX_INDEXED, el campo de índice correspondiente debe estar vacío. Esto indicará a la forma que use el campo coordIndex para los índices. A continuación se muestra un ejemplo de grafo de escena que se renderizará usando arrays de vértices:

NormalBinding { value PER_VERTEX_INDEXED }
Coordinate3 {
  point [
    0 0 0, # 0
    1 0 0, # 1
    2 0 0, # 2
    0 1 0, # 3
    1 1 0, # 4
    2 1 0, # 5
    0 2 0, # 6
    1 2 0, # 7
    2 2 0, # 8
    2 0  0, # 9
    2 0 -1, # 10
    2 1  0, # 11
    2 1 -1, # 12
    2 2  0, # 13
    2 2 -1  # 14
  ]
}
Normal {
  vector [
    0 0 1, # 0
    0 0 1, # 1
    0 0 1, # 2
    0 0 1, # 3
    0 0 1, # 4
    0 0 1, # 5
    0 0 1, # 6
    0 0 1, # 7
    0 0 1, # 8
    1 0 0,  # 9
    1 0 0,  # 10
    1 0 0,  # 11
    1 0 0,  # 12
    1 0 0,  # 13
    1 0 0   # 14
  ]
}
IndexedFaceSet {
  coordIndex [
    0, 1, 4, 3, -1,
    1, 2, 5, 4, -1,
    3, 4, 7, 6, -1,
    4, 5, 8, 7, -1,
    9, 10, 12, 11, -1,
    11, 12, 14, 13, -1
  ]
  normalIndex [ ] # = usa coordIndex
}

Ten en cuenta que, dado que solo se puede usar un array de índices, puede ser necesario proporcionar normales y coordenadas duplicadas para cumplir este requisito.

Además, si se necesitan normales, debes proporcionarlas. Una forma con normales autogeneradas no se puede renderizar usando arrays de vértices (ya que una sola coordenada podría tener múltiples normales).

Los nodos PointSet siempre se pueden renderizar usando arrays de vértices ya que estos nodos no tienen arrays de índices, y las únicas vinculaciones soportadas son PER_VERTEX y GENERAL.

Si es inconveniente crear grafos de escena listos para arrays de vértices directamente desde tu aplicación, también es posible usar SoReorganizeAction para reorganizar la geometría antes de renderizar.
