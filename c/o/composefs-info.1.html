NOMBRE

composefs-info - imprime información sobre una imagen composefs

SINOPSIS

composefs-info [ls|objects|missing-objects|dump] IMAGEN [IMAGEN2 IMAGEN3 ...]

DESCRIPCIÓN

El comando composefs-info te permite inspeccionar una imagen composefs. Tiene varios subcomandos:

ls
Imprime una lista simple de los archivos y directorios en las imágenes, así como su archivo de respaldo o destino del enlace simbólico.
objects
Imprime una lista de todos los archivos de respaldo referenciados por las imágenes, en orden ordenado.
missing-objects
Imprime una lista de todos los archivos de respaldo faltantes referenciados por las imágenes, en orden ordenado, dado un almacén de archivos de respaldo pasado usando la opción --basedir.
dump
Imprime un volcado completo de las imágenes en un formato textual basado en líneas. Consulte composefs-dump(5) para más detalles. Este formato también se acepta como entrada para mkcomposefs si se utiliza la opción --from-file.
measure-file
Interpreta las rutas proporcionadas como archivos genéricos e imprime su hash fsverity.

OPCIONES

El argumento IMAGEN proporcionado debe ser un archivo composefs. Se pueden especificar varias imágenes.

compoosefs-info acepta las siguientes opciones:

--basedir=RUTA
Debe apuntar a un directorio de archivos de respaldo y será utilizado por el comando missing-objects para saber qué archivos están disponibles.
--filter=NOMBRE
Solo imprime entradas cuyo nombre coincida con uno de estos. Se puede especificar varias veces. No puede ser una ruta completa (por ejemplo, no puede contener /). Esto está destinado a ser utilizado por herramientas para buscar eficientemente archivos de metadatos incrustados en la imagen sin cargar e imprimir la imagen completa.

VER TAMBIÉN
