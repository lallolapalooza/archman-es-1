CONF_modules_free(3ssl)

Paquete: openssl

Licencias: Apache-2.0

CONF_MODULES_FREE(3ssl) OpenSSL CONF_MODULES_FREE(3ssl)

NOMBRE

CONF_modules_free, CONF_modules_finish, CONF_modules_unload - Funciones de limpieza de configuración de OpenSSL

SINOPSIS

#include <openssl/conf.h>
void CONF_modules_finish(void);
void CONF_modules_unload(int all);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 1.1.0, y pueden ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

void CONF_modules_free(void);

DESCRIPCIÓN

CONF_modules_free() cierra y libera toda la memoria asignada por todos los módulos de configuración. Normalmente, en versiones de OpenSSL anteriores a la 1.1.0, las aplicaciones llamaban a CONF_modules_free() al salir para organizar cualquier configuración realizada.

CONF_modules_finish() llama al manejador de finish de cada módulo de configuración para liberar cualquier configuración que dicho módulo pueda haber realizado.

CONF_modules_unload() finaliza y descarga los módulos de configuración. Si all se establece en 0, solo se descargarán los módulos cargados desde DSO. Si all es 1, se descargarán todos los módulos, incluidos los módulos integrados.

VALORES DE RETORNO

Ninguna de las funciones devuelve un valor.

VER TAMBIÉN

config(5), OPENSSL_config(3), CONF_modules_load_file_ex(3)

HISTORIA

CONF_modules_free() fue marcada como obsoleta en OpenSSL 1.1.0; no la uses. Para más información véase OPENSSL_init_crypto(3).
