SINOPSIS

Clases


clase SoBoundingBoxCache
La clase SoBoundingBoxCache se utiliza para almacenar en caché cuadros delimitadores. clase SoCache
La clase SoCache es la superclase de todas las clases de caché internas. clase SoConvexDataCache
La clase SoConvexDataCache se utiliza para almacenar en caché polígonos convexificados. clase SoGLCacheList
La clase SoGLCacheList se utiliza para almacenar y gestionar cachés de OpenGL. clase SoGLRenderCache
La clase SoGLRenderCache se utiliza para almacenar en caché llamadas a OpenGL. clase SoNormalCache
La clase SoNormalCache se utiliza para mantener normales almacenados en caché. clase SoTextureCoordinateCache
La clase SoTextureCoordinateCache se utiliza para almacenar en caché coordenadas de textura generadas. clase SoPrimitiveVertexCache
Esta caché contiene una versión organizada de la geometría en forma de array de vértices.
