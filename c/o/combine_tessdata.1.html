COMBINE_TESSDATA(1)   COMBINE_TESSDATA(1)

NOMBRE

combine_tessdata - combina/extrae/sobrescribe/lista/compacta datos de Tesseract

SINOPSIS

combine_tessdata [OPCIÓN] ARCHIVO...

DESCRIPCIÓN

combine_tessdata(1) es el programa principal para combinar/extraer/sobrescribir/listar/compactar componentes de tessdata en archivos [lang].traineddata.

Para combinar todos los componentes individuales de tessdata (unicharset, DAWGs, plantillas de clasificador, ambigüedades, configuraciones de idioma) ubicados, por ejemplo, en /home/$USER/temp/eng.* ejecuta:

combine_tessdata /home/$USER/temp/eng.

El resultado será un archivo tessdata combinado /home/$USER/temp/eng.traineddata

Especifica la opción -e si deseas extraer componentes individuales de un archivo traineddata combinado. Por ejemplo, para extraer el archivo de configuración de idioma y el unicharset del tessdata/eng.traineddata ejecuta:

combine_tessdata -e tessdata/eng.traineddata \
  /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharset

El archivo de configuración y el unicharset deseados se escribirán en /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharset

Especifica la opción -o para sobrescribir componentes individuales del archivo [lang].traineddata dado. Por ejemplo, para sobrescribir los archivos de configuración de idioma y ambigüedades de unichar en tessdata/eng.traineddata usa:

combine_tessdata -o tessdata/eng.traineddata \
  /home/$USER/temp/eng.config /home/$USER/temp/eng.unicharambigs

Como resultado, tessdata/eng.traineddata contendrá la nueva configuración de idioma y ambigüedades de unichar, además de todos los DAWGs originales, plantillas de clasificador, etc.

Nota: los nombres de archivo de los archivos a extraer y para sobrescribir deben tener los sufijos (extensiones) apropiados que indiquen su tipo de componente de tessdata (.unicharset para el unicharset, .unicharambigs para ambigüedades de unichar, etc.). Ver la variable k*FileSuffix en ccutil/tessdatamanager.h.

Especifica la opción -u para desempaquetar todos los componentes en la ruta especificada:

combine_tessdata -u tessdata/eng.traineddata /home/$USER/temp/eng.

Esto creará los archivos /home/$USER/temp/eng.* con componentes de tessdata individuales de tessdata/eng.traineddata.

OPCIONES

-c .traineddata ARCHIVO...: Compacta el componente LSTM en el archivo .traineddata a int.

-d .traineddata ARCHIVO...: Lista el directorio de componentes del archivo .traineddata.

-e .traineddata ARCHIVO...: Extrae los componentes especificados del archivo .traineddata

-l .traineddata ARCHIVO...: Lista la información de la red.

-o .traineddata ARCHIVO...: Sobrescribe los componentes especificados del archivo .traineddata con los proporcionados en la línea de comandos.

-u .traineddata PREFIJO Desempaqueta el .traineddata usando el prefijo proporcionado.

ADVERTENCIAS

Prefijo se refiere al prefijo de archivo completo, incluido el punto (.)

COMPONENTES

Los componentes de un archivo lang.traineddata de Tesseract a partir de la versión 4.0 se describen brevemente a continuación; Para obtener más información sobre muchos de estos archivos, consulte https://tesseract-ocr.github.io/tessdoc/Training-Tesseract.html y https://tesseract-ocr.github.io/tessdoc/TrainingTesseract-4.00.html

lang.config

(Opcional) Sobrescrituras específicas del idioma para las variables de configuración predeterminadas. Para los archivos traineddata de la versión 4.0, lang.config proporciona parámetros de control que pueden afectar el análisis de diseño y los sub-idiomas.

lang.unicharset

(Requerido - tesseract legado 3.0x) La lista de símbolos que Tesseract reconoce, con propiedades. Ver unicharset(5).

lang.unicharambigs

(Opcional - tesseract legado 3.0x) Este archivo contiene información sobre pares de símbolos reconocidos que a menudo se confunden. Por ejemplo, rn y m.

lang.inttemp

(Requerido - tesseract legado 3.0x) Plantillas de forma de caracteres para cada unichar. Producido por mftraining(1).

lang.pffmtable

(Requerido - tesseract legado 3.0x) El número de características esperadas para cada unichar. Producido por mftraining(1) a partir de archivos .tr.

lang.normproto

(Requerido - tesseract legado 3.0x) Prototipos de normalización de caracteres generados por cntraining(1) a partir de archivos .tr.

lang.punc-dawg

(Opcional - tesseract legado 3.0x) Un dawg hecho de patrones de puntuación que se encuentran alrededor de las palabras. La parte de "palabra" se reemplaza por un solo espacio.

lang.word-dawg

(Opcional - tesseract legado 3.0x) Un dawg hecho de palabras de diccionario del idioma.

lang.number-dawg

(Opcional - tesseract legado 3.0x) Un dawg hecho de tokens que originalmente contenían dígitos. Cada dígito se reemplaza por un carácter de espacio.

lang.freq-dawg

(Opcional - tesseract legado 3.0x) Un dawg hecho de las palabras más frecuentes que habrían ido a word-dawg.

lang.fixed-length-dawgs

(Opcional - tesseract legado 3.0x) Varios dawgs de diferentes longitudes fijas — útiles para idiomas como el chino.

lang.shapetable

(Opcional - tesseract legado 3.0x) Cuando está presente, shapetable es una capa adicional entre el clasificador de caracteres y el reconocedor de palabras que permite al clasificador de caracteres devolver una colección de ids de unichar y fuentes en lugar de un solo id de unichar y fuente.

lang.bigram-dawg

(Opcional - tesseract legado 3.0x) Un dawg de bigramas de palabras donde las palabras están separadas por un espacio y cada dígito se reemplaza por un ?.

lang.unambig-dawg

(Opcional - tesseract legado 3.0x) .

lang.params-model

(Opcional - tesseract legado 3.0x) .

lang.lstm

(Requerido - LSTM 4.0) Modelo de reconocimiento de red neuronal entrenada generado por lstmtraining.

lang.lstm-punc-dawg

(Opcional - LSTM 4.0) Un dawg hecho de patrones de puntuación que se encuentran alrededor de las palabras. La parte de "palabra" se reemplaza por un solo espacio. Utiliza lang.lstm-unicharset.

lang.lstm-word-dawg

(Opcional - LSTM 4.0) Un dawg hecho de palabras de diccionario del idioma. Utiliza lang.lstm-unicharset.

lang.lstm-number-dawg

(Opcional - LSTM 4.0) Un dawg hecho de tokens que originalmente contenían dígitos. Cada dígito se reemplaza por un carácter de espacio. Utiliza lang.lstm-unicharset.

lang.lstm-unicharset

(Requerido - LSTM 4.0) El conjunto de caracteres unicode que Tesseract reconoce, con propiedades. Se debe usar el mismo unicharset para entrenar el LSTM y construir los archivos lstm-*-dawgs.

lang.lstm-recoder

(Requerido - LSTM 4.0) Unicharcompress, también conocido como el codificador, que mapea el unicharset a los códigos utilizados por el reconocedor de red neuronal. Esto se crea como parte del traineddata inicial mediante combine_lang_model.

lang.version

(Opcional) Cadena de versión para el archivo traineddata. Apareció por primera vez en la versión 4.0 de Tesseract. Las versiones antiguas de los archivos traineddata informarán Version:Pre-4.0.0. Las versiones de la versión 4.0 de los archivos traineddata pueden incluir la especificación de la red utilizada para el entrenamiento LSTM como parte de la cadena de versión.

HISTORIA

combine_tessdata(1) apareció por primera vez en la versión 3.00 de Tesseract
