Esta clase está obsoleta: debería usarse la

clase

FBB::Config (cf. config(3bobcat)) en su lugar. Los objetos ConfigFile leen archivos de

configuración

estándar tipo unix. Las líneas se almacenan con el espacio en blanco inicial (espacios y tabuladores) eliminado. Si una línea termina en \, entonces la siguiente línea (con el espacio en blanco inicial eliminado) se añade a la línea actual. Si

la

bandera rmComment está establecida en true, se eliminan las líneas en blanco y la información de las líneas desde el primer #. Si el carácter de comentario ( #) está precedido por una barra invertida (es decir,\#), no se considera comentario, sino que se reemplaza por un solo carácter #. Del mismo modo, si la bandera rmComment estaba establecida, dos caracteres de barra invertida consecutivos se reemplazan por un solo carácter de barra invertida. En la información de configuración recuperada, aparece como un solo carácter #. Si el archivo de configuración debe contener \#, escriba \\#, esto resulta en reemplazar \# por #, dejando \#. Todas las líneas no vacías del archivo de configuración (cuando se ignora el comentario, el comentario no se considera

contenido de línea) se almacenan en el

objeto ConfigFile. Cuando se deben almacenar los índices de línea, los índices de línea (basados en 0) de las líneas también están disponibles. En el momento de la construcción se puede especificar el manejo de comentarios (mantener comentario / eliminar comentario), la búsqueda sensible a mayúsculas y minúsculas (sensible / insensible) y el almacenamiento de índices (almacenar / no almacenar)

.

No se puede modificar usando

el

miembro open, pero se admite la asignación sobrecargada y el manejo de comentarios y de mayúsculas y minúsculas puede modificarse mediante miembros set. ESPACIO D

Se devuelve un par de const_RE_iterators. El primer campo del par es un iterador const al primer elemento (es decir, línea) del objeto ConfigFile en el que se encuentra la expresión regular target

El segundo campo es un iterador const que marca el final de la serie de líneas que comienza en la primera línea que coincide con la expresión regular especificada por targe

o
std::string findKey(std::string const &keyPattern, size_t count = 1) const:
Este miembro se puede utilizar para recuperar información de líneas que tienen el patrón general `keyPattern value’. El espacio en blanco inicial y final de las líneas se ignora. keyPattern en sí mismo no debe contener espacio en blanco inicial o final. Debe aparecer al menos un carácter de espacio en blanco entre keyPattern y value. Si se encontraron al menos count líneas que coinciden con keyPattern value, entonces este miembro devuelve la primera secuencia de caracteres que no son espacio en blanco que sigue a keyPattern después de que coincidan count líneas que coinciden con keyPattern value (es decir, se devuelve `value’). Si value está vacío o si menos de count líneas coinciden con keyPattern, se devuelve una cadena vacía. Se lanza una excepción FBB::Exception si count es igual
a 0.

std::string findKeyTail(std::string const &keyPattern, size_t count = 1) const:
Este miembro se puede utilizar para recuperar información de líneas que tienen el patrón general `keyPattern value’, seguido únicamente de espacio en blanco. Debe aparecer al menos un carácter de espacio en blanco entre keyPattern y value. Supongamos que el archivo de configuración se llama config.rc y contiene las siguientes

líneas: 
# esto se ignora
noline: esta también
line: esta se encuentra
esta no es una línea que contenga line: al principio de la línea
line: esta es
    line: ¿qué pasa con esta? se extiende a lo largo de varias líneas
y por supuesto puede haber más líneas en este
archivo

El siguiente programa se puede compilar y ejecutar como a.out con

fig.rc: 
#include <iostream>
#include <iterator>
#include <algorithm>
#include <string>
#include <bobcat/configfile>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    ConfigFile cf(argv[1]);
    cout << *cf.find("this one") << ’\n’; // find text within a line
                                         // find all lines matching
    auto [begin, end] = cv.beginEndRE("^line:"); // `^line:’
    copy(begin, end, ostream_iterator<string>(cout, "\n"));
}
