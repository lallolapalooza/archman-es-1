Especifica una tabla de traducciones que está vinculada con sus acciones en el contexto de un widget en particular. La tabla de aceleradores puede ser instalada después en algún widget de destino. Tenga en cuenta que los aceleradores predeterminados de cualquier widget siempre se instalarán, independientemente de si este recurso se especifica o
no.
XmNancestorSensit
ive
Especifica si el padre inmediato del widget recibe eventos de entrada. Utilice la función XtSetSensitive para cambiar el argumento y preservar la integridad de los datos (véase XmNsensitive). Para los shells, el valor predeterminado se copia del recurso XmNancestorSensitive del padre si existe un padre; de lo contrario, es True. Para otros widgets, el valor predeterminado es el AND bit a bit de los recursos XmNsensitive y XmNancestorSensitive del
padre.

XmNborderPix
map
Especifica un mapa de píxeles para usar en mosaico del borde. El primer mosaico se coloca en la esquina superior izquierda del
borde.
XmNborderWid
th
Especifica el ancho del borde que rodea la ventana del widget en los cuatro lados. El ancho se especifica en píxeles. Un ancho de 0 (cero) significa que no se muestra ningún borde. Tenga en cuenta que debe usar recursos como XmNshadowThickness y XmNhighlightThickness en lugar de XmNborderWidth para especificar anchos de
borde.
XmNcolorm
ap
Especifica el mapa de colores que se usa para las conversiones al tipo Pixel para esta instancia de widget. Cuando se cambia este recurso, los valores de píxel generados previamente no se ven afectados, pero los valores generados nuevos están en el nuevo mapa de colores. Para los shells sin padres, el valor predeterminado es el mapa de colores predeterminado de la pantalla del widget. De lo contrario, el valor predeterminado se copia del
padre.
XmNdep
th
Especifica el número de bits que se pueden usar para cada píxel en la ventana del widget. Las aplicaciones no deben cambiar ni establecer el valor de este recurso, ya que lo establecen las Xt Intrinsics cuando se crea el widget. Para los shells sin padres, el valor predeterminado es la profundidad predeterminada de la pantalla del widget. De lo contrario, el valor predeterminado se copia del
padre.
XmNdestroyCallb
ack
Especifica una lista de devoluciones de llamada que se invoca cuando el widget es
destruido.
XmNheig

Especifica la altura interior (excluyendo el borde) de la ventana del

XmNinitialResourcesPersist
ent
Especifica si los recursos se cuentan como referencias o no. Si el valor es True cuando se crea el widget, los recursos a los que hace referencia el widget no se cuentan como referencias, independientemente de cómo se registre el convertidor de tipo de recurso. Una aplicación que espera destruir el widget y quiere que se liberen los recursos debe especificar un valor de False. El valor predeterminado es True, lo que implica la suposición de que el widget no será destruido durante la vida de la
aplicación.
XmNmappedWhenMana
ged
Si este recurso se establece en True, se asigna el widget (se hace visible) tan pronto como esté tanto realizado como gestionado. Si este recurso se establece en False, el cliente es responsable de asignar y desasignar el widget. Si el valor se cambia de True a False después de que el widget haya sido realizado y gestionado, el widget se
desasigna.
XmNscre
en
Especifica la pantalla en la que reside una instancia de widget. Es de solo lectura. Cuando se inicializa el Toolkit, el widget de nivel superior obtiene su valor predeterminado de la pantalla predeterminada de la visualización. De lo contrario, el valor predeterminado se copia del
padre.
XmNsensiti
ve
Determina si un widget recibe eventos de entrada. Si un widget es sensible, el Gestor de Eventos de las Xt Intrinsics despacha al widget todos los eventos de teclado, botón del ratón, movimiento, entrada/salida de ventana y foco. Los widgets insensibles no reciben estos eventos. Utilice la función XtSetSensitive para cambiar el argumento de sensibilidad. El uso de XtSetSensitive garantiza que si un widget padre tiene XmNsensitive establecido en False, la bandera de sensibilidad del ancestro de todos sus hijos se establece
adecuadamente.
XmNtranslati
ons
Apunta a una lista de traducciones. Una lista de traducciones es una lista de eventos y acciones que deben realizarse cuando ocurran los eventos. Tenga en cuenta que las traducciones predeterminadas de cualquier widget siempre se instalarán, independientemente de si este recurso se especifica o
no.
