NOMBRE

Color::Calc::WWW - Cálculos sencillos con colores para la WWW.

SINOPSIS

use Color::Calc::WWW;
my $background = 'green';
print 'background: ', color($background),';';
print 'border-top: solid 1px ', color_light($background),';';
print 'border-bottom: solid 1px ', color_dark($background),';';
print 'color: ', color_contrast_bw($background),';';

DESCRIPCIÓN

El módulo "Color::Calc::WWW" implementa cálculos sencillos con colores RGB para la World Wide Web. Esto puede usarse para crear un esquema de colores completo a partir de unos pocos colores.

Este módulo es casi idéntico a usar lo siguiente:

use Color::Calc('ColorScheme' => 'WWW', 'OutputFormat' => 'html');

Sin embargo, este módulo también hace que las funciones estén disponibles cuando no se importan:

use Color::Calc::WWW();               # no importar
Color::Calc::WWW::color('F00');

USO

Por defecto, todas las funciones se importan.

Todas las funciones reconocen todas las palabras clave de color HTML (a través de Graphics::ColorNames::WWW) y devuelven los resultados en formatos compatibles con la WWW, es decir, como una de las 16 palabras clave HTML básicas (ver Graphics::ColorNames::WWW) o como #RRGGBB.

color, color_mix, ...
Ver L<Color::Calc> para una lista de funciones de cálculo disponibles.
