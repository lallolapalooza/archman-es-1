NOMBRE

cog-changelog - Muestra un registro de cambios para el rango de OID de commit dado

SINOPSIS

cog-changelog [-a|--at] [-t|--template] [-r|--remote] [-o|--owner] [--repository] [-u|--unified] [-h|--help] [PATRÓN]

DESCRIPCIÓN

Muestra un registro de cambios para el rango de OID de commit dado

OPCIONES

-a, --at <AT>
Genera el registro de cambios para una etiqueta git específica
-t, --template <PLANTILLA>
Genera el registro de cambios con la plantilla dada.

Los valores posibles son 'remote', 'full_hash', 'default' o la ruta a tu plantilla. Si no se especifica, cog usará la configuración de plantilla de cog.toml o recurrirá a 'default'.

-r, --remote <REMOTO>
URL a usar durante la generación de la plantilla
-o, --owner <PROPIETARIO>
Propietario del repositorio a usar durante la generación de la plantilla
--repository <REPOSITORIO>
Nombre del repositorio a usar durante la generación de la plantilla
-u, --unified
Combina los cambios del paquete y los cambios globales en un solo registro de cambios
-h, --help
Imprime la ayuda (ver un resumen con '-h')
[PATRÓN]
Genera el registro de cambios en el rango de especificación dado
