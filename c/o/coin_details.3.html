coin_details - Clases de detalle


- Las clases de detalle son objetos que entregan información adicional dondequiera que se utilice la clase SoPrimitiveVertex.

class SoDetail
La clase SoDetail es la superclase para todas las clases que almacenan información detallada sobre formas particulares. class SoConeDetail
La clase SoConeDetail contiene información sobre las partes de una forma SoCone. class SoCubeDetail
La clase SoCubeDetail contiene información sobre las partes de una forma SoCube. class SoCylinderDetail

La clase SoDetailList es un contenedor para punteros a objetos SoDetail.

Descripción detallada

Las clases de detalle son objetos que entregan información adicional dondequiera que se utilice la clase SoPrimitiveVertex.

Esto se aplica a los resultados de la selección por rayos, y también a la generación de primitivas por las clases SoShape para la clase SoCallbackAction y la renderización de formas de respaldo a través de la generación de primitivas (un truco útil de depuración al depurar, por ejemplo, la selección por rayos).
