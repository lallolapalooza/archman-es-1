NOMBRE

combined2dlf - convierte un archivo de registro combinado a DLF

SINOPSIS

combined2dlf archivo

DESCRIPCIÓN

combined2dlf convierte archivos de registro de servidores web en el formato de registro combinado al formato DLF de www. El formato de registro combinado (también conocido como formato de registro común extendido) fue implementado por primera vez en el servidor web httpd de NSCA, pero ahora es compatible con muchos servidores web. Apache puede configurarse para usar ese formato de registro.

FORMATO DE REGISTRO COMBINADO

El formato de registro combinado es una extensión del formato de registro común; consulte common2dlf(1). Añade dos campos al final de la línea:

"referer" "useragent"
referer
El contenido del encabezado de la solicitud Referer. Esto generalmente refleja la página donde el usuario estaba antes de esa solicitud.
useragent
El contenido del encabezado User-Agent de la solicitud. Esto generalmente refleja el navegador que está utilizando el usuario.

Ejemplo de registro:

127.0.01 - - [11/03/2001 12:12:01 -0400] "GET / HTTP/1.0" 200 513 "-" "Mozilla/5.0"
dsl1.myprovider.com - francis [11/03/2001 12:14:01 -0400] "GET /secret/ HTTP/1.0" 200 1256 "http://www.example.com/index.html" "Mozilla/5.0"

EJEMPLOS

Para procesar un registro como el producido en el formato de registro combinado:

$ combined2dlf < combined.log

combined2dlf rara vez se usará solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report combined < /var/log/httpd/combined.log
