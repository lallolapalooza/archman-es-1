NOMBRE

coin_draggers - Clases Dragger


- Los Draggers son componentes interactivos en el grafo de escena que responden a, y son controlados por, eventos del ratón y del teclado.

SINOPSIS

Clases


clase SoDragger
La clase SoDragger es la clase base para todos los draggers. clase SoCenterballDragger
La clase SoCenterballDragger es un dragger que puedes rotar y trasladar. clase SoDirectionalLightDragger
La clase SoDirectionalLightDragger proporciona geometría interactiva para manipular una fuente de luz direccional. clase SoDragPointDragger
La clase SoDragPointDragger proporciona mecanismos para mover un punto en 3D. clase SoHandleBoxDragger
La clase SoHandleBoxDragger proporciona soporte para escalado y traslación interactivos. clase SoJackDragger
La clase SoJackDragger es un dragger que puedes trasladar, rotar y escalar. clase SoPointLightDragger
La clase SoPointLightDragger proporciona geometría interactiva para manipular una fuente de luz puntual. clase SoRotateCylindricalDragger
La clase SoRotateCylindricalDragger es para rotar geometría alrededor de un único eje. clase SoRotateDiscDragger
La clase SoRotateDiscDragger es para rotar geometría alrededor de un único eje. clase SoRotateSphericalDragger
La clase SoRotateSphericalDragger es para rotar geometría en cualquier dirección. clase SoScale1Dragger
La clase SoScale1Dragger proporciona un mecanismo para que el usuario final escale en una dimensión. clase SoScale2Dragger
La clase SoScale2Dragger proporciona un mecanismo para que el usuario final escale en dos dimensiones. clase SoScale2UniformDragger
La clase SoScale2UniformDragger proporciona un mecanismo para que el usuario final escale en dos dimensiones. clase SoScaleUniformDragger
La clase SoScaleUniformDragger proporciona un mecanismo para que el usuario final escale en tres dimensiones. clase SoSpotLightDragger
La clase SoSpotLightDragger proporciona geometría interactiva para manipular un foco. clase SoTabBoxDragger
La clase SoTabBoxDragger envuelve una caja alrededor de la geometría que luego puedes trasladar y escalar. clase SoTabPlaneDragger
La clase SoTabPlaneDragger es un dragger que puedes trasladar y escalar dentro de un plano. clase SoTrackballDragger
La clase SoTrackballDragger proporciona al usuario final posibilidades de interacción de rotación y escalado. clase SoTransformBoxDragger
La clase SoTransformBoxDragger proporciona una caja que puede ser trasladada, escalada y rotada. clase SoTransformerDragger
La clase SoTransformerDragger proporciona geometría para traslaciones, escalados y rotaciones. clase SoTranslate1Dragger
La clase SoTranslate1Dragger proporciona un mecanismo para que el usuario final traslade a lo largo de un eje. clase SoTranslate2Dragger
La clase SoTranslate2Dragger proporciona un mecanismo para que el usuario final traslade en un plano.

DESCRIPCIÓN DETALLADA

Los Draggers son componentes interactivos en el grafo de escena que responden a, y son controlados por, eventos del ratón y del teclado.

Se utilizan en manipuladores como interfaz de usuario para la acción de manipulación, a menudo muchos draggers combinados al mismo tiempo.
