COLLECTL2PCP(1) Manual de Comandos Generales COLLECTL2PCP(1)

NOMBRE

collectl2pcp - importar datos de collectl a un archivo PCP

SINOPSIS

collectl2pcp [-fv?] [-D debug] archivo [archivo ...] archivo_pcp

DESCRIPCIÓN

collectl2pcp lee datos crudos de collectl(1) de cada archivo y crea un nuevo archivo PCP con el nombre base archivo_pcp. Cada archivo de entrada puede estar comprimido con gzip (con sufijo .gz). El argumento archivo_pcp y al menos un archivo de entrada son obligatorios.

OPCIONES

Las opciones de línea de comandos disponibles son:

-f, --force
Sobrescribe archivo_pcp (y los archivos de índice y meta) si ya existe.
-v, --verbose
Informa el progreso y los errores de forma detallada. Esto también informa un recuento de métricas no soportadas en los archivos de entrada de collectl(1), que normalmente se omiten silenciosamente.
-?, --help
Muestra el mensaje de uso y sale.
archivo [archivo ...]
Estos son los archivos de entrada de collectl(1). Si se proporcionan varios, deben contener datos del mismo host y deben aparecer en orden cronológico de marca de tiempo en la línea de comandos. Tenga en cuenta que cuando collectl(1) se ejecuta como servicio, normalmente crea archivos con nombres basados en la fecha que se ordenarán cronológicamente (por ejemplo, /var/log/collectl/*.gz se ordenará correctamente).

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para ver las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información es a veces críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; utilice pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

collectl(1), PCPIntro(1), LOGIMPORT(3), pcp.conf(5), pcp.env(5) y PMNS(5).
