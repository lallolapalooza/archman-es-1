NOMBRE

Config::General::Interpolated - Analiza variables dentro de archivos de configuración

SINOPSIS

use Config::General;
$conf = Config::General->new(
   -ConfigFile      => 'archivo_configuracion',
   -InterPolateVars => 1
);

DESCRIPCIÓN

Este es un módulo interno que hace posible interpolar variables al estilo Perl en su archivo de configuración (es decir, $variable o "${variable}").

Normalmente no se llama directamente.

VARIABLES

Las variables se pueden definir en cualquier lugar del archivo de configuración y se pueden usar posteriormente como valor de una opción. Las variables no se pueden usar como claves ni como parte de las claves.

Si define una variable dentro de un bloque o un bloque con nombre, solo será visible dentro de ese bloque o dentro de los bloques que se definan dentro de ese bloque. Bueno, veamos un ejemplo:

# configuración de ejemplo que usa variables
basedir   = /opt/ora
user      = t_space
sys       = unix
<table intern>
    instance  = INTERN
    owner     = $user                 # "t_space"
    logdir    = $basedir/log          # "/opt/ora/log"
    sys       = macos
    <procs>
        misc1   = ${sys}_${instance}  # macos_INTERN
        misc2   = $user               # "t_space"
    </procs>
</table>

Esto dará como resultado la siguiente estructura:

{
    'basedir' => '/opt/ora',
    'user'    => 't_space'
    'sys'     => 'unix',
    'table'   => {
         'intern' => {
               'sys'      => 'macos',
               'logdir'   => '/opt/ora/log',
               'instance' => 'INTERN',
               'owner' => 't_space',
               'procs' => {
                    'misc1' => 'macos_INTERN',
                    'misc2' => 't_space'
           }
        }
    }

Como puede ver, la variable sys se ha definido dos veces. Dentro del bloque <procs>, se utilizó una variable ${sys}, que luego se interpoló en el valor de sys definido dentro del bloque <table>, no la variable sys un nivel por encima. Si sys no se hubiera definido dentro del bloque <table>, se habría utilizado la variable "global" sys en su lugar, con el valor de "unix".

Las variables dentro de comillas dobles se interpolarán, pero las variables dentro de comillas simples no se interpolarán. Este es el mismo comportamiento que conoce de la propia Perl.

Además, puede rodear los nombres de las variables con llaves para evitar interpretaciones erróneas por parte del analizador.

CONVENCIONES DE NOMBRADO

Los nombres de las variables deben:

  • comenzar con una letra US-ASCII (a-z o A-Z) o un dígito (0-9).
  • contener solo letras US-ASCII (a-z o A-Z), dígitos (0-9), los caracteres guion (-), dos puntos (:), punto (.), guion bajo (_) y signo más (+).

Para mayor claridad, los nombres de las variables pueden ir rodeados de llaves.
