COMP_ERR(1) Sistema de base de datos MySQL COMP_ERR(1)

NOMBRE

comp_err - compilar archivo de mensajes de error de MySQL

SINOPSIS

comp_err [opciones]

DESCRIPCIÓN

comp_err crea el archivo errmsg.sys que es utilizado por mysqld para determinar los mensajes de error a mostrar para diferentes códigos de error. comp_err normalmente se ejecuta automáticamente cuando se compila MySQL. Compila el archivo errmsg.sys a partir de información de errores en formato de texto en las distribuciones fuente de MySQL:

La información de errores proviene de los archivos messages_to_error_log.txt y messages_to_clients.txt en el directorio share.

Para más información sobre la definición de mensajes de error, consulte los comentarios dentro de esos archivos, junto con el archivo errmsg_readme.txt.

comp_err también genera los archivos de cabecera mysqld_error.h, mysqld_ername.h y mysqld_errmsg.h.

Ejecute comp_err de esta forma:

comp_err [opciones]

comp_err soporta las siguientes opciones.

•--help, -?
Formato de línea de comandos --help
Tipo Booleano
Valor por defecto false

Muestra un mensaje de ayuda y sale.

•--charset=nombre_dir, -C nombre_dir
Formato de línea de comandos --charset
Tipo Cadena
Valor por defecto

El directorio de juegos de caracteres. El valor por defecto es ../sql/share/charsets.

•--debug=opciones_debug, -# opciones_debug
Formato de línea de comandos --debug=opciones
Tipo Cadena
Valor por defecto d:t:O,/tmp/comp_err.trace

Escribe un registro de depuración. Una cadena típica de opciones_debug es d:t:O,nombre_archivo. El valor por defecto es d:t:O,/tmp/comp_err.trace.

•--debug-info, -T
Formato de línea de comandos --debug-info
Tipo Booleano
Valor por defecto false

Imprime información de depuración al salir del programa.

•--errmsg-file=nombre_archivo, -H nombre_archivo
Formato de línea de comandos --errmsg-file=nombre
Tipo Nombre de archivo
Valor por defecto mysqld_errmsg.h

El nombre del archivo de mensajes de error. El valor por defecto es mysqld_errmsg.h.

•--header-file=nombre_archivo, -H nombre_archivo
Formato de línea de comandos --header-file=nombre
Tipo Nombre de archivo
Valor por defecto mysqld_error.h

El nombre del archivo de cabecera de errores. El valor por defecto es mysqld_error.h.

•--in-file-errlog=nombre_archivo, -e nombre_archivo
Formato de línea de comandos --in-file-errlog
Tipo Nombre de archivo
Valor por defecto

El nombre del archivo de entrada que define los mensajes de error destinados a ser escritos en el registro de errores. El valor por defecto es ../share/messages_to_error_log.txt.

•--in-file-toclient=nombre_archivo, -c nombre_archivo
Formato de línea de comandos --in-file-toclient=ruta
Tipo Nombre de archivo
Valor por defecto

El nombre del archivo de entrada que define los mensajes de error destinados a ser escritos a los clientes. El valor por defecto es ../share/messages_to_clients.txt.

•--name-file=nombre_archivo, -N nombre_archivo
Formato de línea de comandos --name-file=nombre
Tipo Nombre de archivo
Valor por defecto mysqld_ername.h

El nombre del archivo de nombres de error. El valor por defecto es mysqld_ername.h.

•--out-dir=nombre_dir, -D nombre_dir
Formato de línea de comandos --out-dir=ruta
Tipo Cadena
Valor por defecto

El nombre del directorio base de salida. El valor por defecto es ../sql/share/.

•--out-file=nombre_archivo, -O nombre_archivo
Formato de línea de comandos --out-file=nombre
Tipo Nombre de archivo
Valor por defecto errmsg.sys

El nombre del archivo de salida. El valor por defecto es errmsg.sys.

•--version, -V
Formato de línea de comandos --version
Tipo Booleano
Valor por defecto false

Muestra información de versión y sale.
