coin404 - Nuevas características en Coin v4.0.4

Esta es una versión de corrección de errores.

Este es un resumen de las nuevas características en Coin v4.0.4:

  • Se añadió soporte EGL.
  • Se añadió soporte para construir Coin como subdirectorio.
  • Se añadió el estilo visual de líneas ocultas sombreadas.

Correcciones de errores:

  • Se corrigió la llamada a deleteAll en punteros inválidos en SoCallbackAction.
  • Se actualizó el comando cmake_minimum_required para soportar CMake >= 3.30.
  • Se corrigió el bloqueo en SoVRMLBackground::GLRender debido a un puntero sin verificar.
  • Se corrigió una regresión debido a la inicialización eliminada de cc_glglue.
  • Se transfirieron archivos codificados en ANSI a UTF-8.
  • Se corrigió el acceso inválido al eliminar una llamada de retorno.
  • Se corrigió el manejo de macros para evitar conflictos con los encabezados de la API de Win32 de Microsoft.
  • Se corrigieron errores tipográficos y salidas de cadenas extrañas.
  • Se corrigieron vulnerabilidades de cadenas de formato.
  • Pequeña optimización para evitar el cálculo repetido de la rotación identidad.
  • Pequeña optimización para evitar multiplicaciones de matrices innecesarias.
