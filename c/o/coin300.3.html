coin300 - Nuevas características en Coin v3.0.0

Este es un breve resumen de las nuevas características de Coin v3.0:

  • Nuevo subsistema de perfilado de recorrido del grafo de escena.
  • Nuevo nodo SoVertexAttribute que proporciona soporte para atributos de vértice para shaders.
  • Nuevo nodo SoDepthBuffer para controlar la configuración del búfer de profundidad.
  • Nuevo nodo SoShadowSpotLight en el subsistema de generación de sombras.
  • Nuevo motor SoHeightMapToNormalMap para convertir imágenes de mapa de profundidad a mapas normales de tres componentes.
  • SoPickStyle tiene tres nuevas configuraciones de estilo: SHAPE_ON_TOP, BOUNDING_BOX_ON_TOP y SHAPE_FRONTFACES.
  • Analizador XML integrado utilizado para diversos propósitos.
  • Control de características GL a través de un nuevo subsistema GLDriverDatabase que es configurable a través de archivos XML.
  • Motor de Statechart XML, que se ha utilizado para implementar la navegación del visor en modo examinador a nivel de Coin (anteriormente esta funcionalidad se implementó una y otra vez en las diversas bibliotecas GUI).
  • Soporte de formatos de archivo extranjeros a través de SoForeignFileKit, con una implementación de ejemplo SoSTLFileKit para la importación STL.
  • Existe un framework de suite de pruebas basado en Boost.Test
  • Los controladores de traslación (1D/2D) ahora están equipados con nuevos campos minTranslation y maxTranslation para agregar la capacidad de restringir el rango en el que los controladores pueden operar. Cuando se utiliza esta función y los controladores se guardan en un archivo, tiene consecuencias para el formato del archivo y se pierde la capacidad de cargar esos archivos con versiones anteriores de Coin.
  • Ligero cambio en la representación antialiasing con SoGLRenderAction::setNumPasses(). La representación antialiasing ya no se desplaza 1/2 píxel hacia la izquierda en comparación con la representación sin antialiasing de un solo paso.
  • Se ha modificado la carga dinámica de bibliotecas de soporte para Mac OS X, lo que tiene consecuencias para las posibilidades disponibles para agrupar dichas bibliotecas al crear los paquetes de su aplicación.
