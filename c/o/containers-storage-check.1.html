NOMBRE

containers-storage check - Comprobar y eliminar capas/imágenes/contenedores dañados

SINOPSIS

containers-storage check [-q] [-r [-f]]

DESCRIPCIÓN

Comprueba capas, imágenes y contenedores en busca de daños identificables.

OPCIONES

-f

Al reparar daños, también elimina los contenedores dañados. No tiene efecto a menos que se utilice -r.

-r

Intenta reparar los daños eliminando imágenes y capas dañadas. Si no se especifica, se informan los daños pero no se actúa sobre ellos.

-q

Realiza solo comprobaciones que no se espera que consuman mucho tiempo. Actualmente omite la verificación de que una capa que fue inicializada usando una diferencia puede reproducir esa diferencia si se le pide.

EJEMPLO

**containers-storage check -r -f
