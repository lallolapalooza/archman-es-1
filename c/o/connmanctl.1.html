síncrona simple y un intérprete de comandos interactivo asíncrono. Para ejecutar un comando específico, el usuario puede introducir connmanctl command [ options ] o simplemente connmanctl; en el último caso, se iniciará unintérpretedecomandos interactivo. Connmanctl puede gestionar la mayoría de las conexiones de red.

Se

puede utilizar para habilitar/deshabilitar cualquier tecnología que exista en el sistema, mostrar una lista de servicios disponibles, conectar/desconectar redes, mostrar propiedades del sistema, de las tecnologías y de cualquier servicio individual, y configurar todas las propiedades. También es capaz de monitorizar cambios en las propiedades de los servicios, las tecnologías y el sistema. En el intérprete de comandos interactivo,

se

pueden utilizar todos los mismos comandos. Proporciona un uso más rápido cuando es necesar

io usar connmanctl de forma más extensa. Además, la primera vez que se conecta a puntos de
acceso inalámbricos protegidos se requiere el intérprete de comandos interactivo. COMANDOS
