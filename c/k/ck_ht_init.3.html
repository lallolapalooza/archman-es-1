DESCRIPCIÓ

N

La función ck_ht_init() inicializa la tabla hash a la que apunta el puntero

ht.

El argumento mode especifica el tipo de pares clave-valor que se almacenarán en la tabla hash. El valor de mode puede ser uno de los

siguientes:
CK_HT_MODE_BYTESTR
ING
La tabla hash está destinada a almacenar punteros clave-valor donde la clave es una región de memoria de hasta 65536 bytes de longitud. Este puntero será desreferenciado durante las operaciones de la tabla hash para la comparación de claves. Se espera que las entradas de esta tabla hash se manipulen utilizando las funciones ck_ht_entry_empty(3), ck_ht_entry_key(3), ck_ht_entry_key_length(3), ck_ht_entry_value(3), y ck_ht_entry_set(3). Intentar una operación de tabla hash con una clave de valor NULL o (void *)UINTPTR_MAX resultará en un comportamiento
indefinido.
CK_HT_MODE_DIR
ECT
La tabla hash está destinada a almacenar punteros clave-valor donde la clave es de ancho fijo compatible con el tipo uintptr_t. La clave se comparará directamente con otras claves para la igualdad. Se espera que las entradas de esta tabla hash se manipulen utilizando las funciones ck_ht_entry_empty(3), ck_ht_entry_key_direct(3), ck_ht_entry_value_direct(3) y ck_ht_entry_set_direct(3). Intentar una operación de tabla hash con una
clave de valor 0 o UINTPTR_MAX res
ultará en un comportamiento indefinido.

Además de esto, el usuario puede hacer un OR bit a bit de la bandera mode con CK_HT_WORKLOAD_DELETE para indicar que la tabla hash tendrá que manejar una carga de trabajo con muchas eliminaciones, en cuyo caso se pueden proporcionar límites más estrictos de latencia a costa de aproximadamente un 13% más de uso de memoria. El argumento hash_function es un puntero a una función de hash especificada por el usuario. Es opcional, si se especifica NULL, entonces se utilizará la implementación de la función de hash predeterminada ( ck_ht_hash(3) ). Una función de hash especificada por el usuario toma cuatro argumentos. El argumento h es un puntero a un objeto de valor hash. Se espera que la función de hash actualice el objeto valor de tipo uint64_t contenido dentro del objeto al que apunta h. El argumento key es un puntero a una clave, el argumento key_length es la longitud de la clave y el argumento seed es la semilla inicial asociada con la tabla hash. Esta semilla inicial es especificada por el usuario en ck_ht_ini

t(3).

El argumento allocator es un puntero a una estructura que contiene punteros a las funciones malloc y free que definen respectivamente las funciones de asignación y destrucción de memoria que se utilizarán en la tabla hash que se está

inicializando.

El argumento capacity representa el número inicial de pares clave-valor que se espera que contenga la tabla hash. Este argumento es simplemente una pista y la implementación subyacente es libre de asignar más o menos memoria de la necesaria para contener el número de entradas especificado por

capacity.

El argumento seed especifica la semilla inicial utilizada por la función de hash subyacente. El usuario es libre de elegir un valor de su

elección.

La tabla hash es segura de acceder por múltiples lectores en l

a presencia de un escritor concurrente. El comportamiento
es indefinido en la presencia de escritores concurrentes.
