DESCRIPCIÓN

Este es un bloqueo de lectura-escritura centralizado, sesgado hacia la escritura y de un solo escritor. Requiere la mitad del espacio que ck_rwlock y tiene una vía rápida de baja latencia. El bloqueo admite operaciones de latched (bloqueo temporal) y unlatched (desbloqueo temporal) que permiten usarlo de manera segura contra copias (los bits de lectura pueden ser sobrescritos de forma segura).

EJEMPLO

#include <ck_swlock.h>

static ck_swlock_t lock = CK_SWLOCK_INITIALIZER;

static void
reader(void)
{

	for (;;) {
		ck_swlock_read_lock(&lock);
		/* Sección crítica del lado de lectura. */
		ck_swlock_read_unlock(&lock);

		if (ck_swlock_read_trylock(&lock) == true) {
			/* Sección crítica del lado de lectura. */
			ck_swlock_read_unlock(&lock);
		}
	}

	return;
}

static void
writer(void)
{
	ck_swlock_t contrived;

	for (;;) {
		ck_swlock_write_lock(&lock);
		/* Sección crítica del lado de escritura. */
		ck_swlock_write_unlock(&lock);

		if (ck_swlock_write_trylock(&lock) == true) {
			/* Sección crítica del lado de escritura. */
			ck_swlock_write_unlock(&lock);
		}

		ck_swlock_write_latch(&lock);
		/* Sección crítica del lado de escritura. */

		/* Esto es seguro hacerlo dentro de un latch. */
		contrived = lock;
		lock = contrived;
		ck_swlock_write_unlatch(&lock);
	}

	return;
}
