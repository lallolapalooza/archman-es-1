NOMBRE

ck_ht_reset_size_spmc — elimina todas las entradas de una tabla hash y restablece el tamaño

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ht.h>

bool
ck_ht_reset_size_spmc(ck_ht_t *ht, uint64_t capacity);

DESCRIPCIÓN

La función ck_ht_reset_size_spmc() eliminará todos los pares clave-valor almacenados en la tabla hash apuntada por el argumento ht y creará una nueva generación de la tabla hash que estará preasignada para capacity entradas.

VALORES DE RETORNO

Si tiene éxito, ck_ht_reset_size_spmc() devolverá true y en caso contrario devolverá false. Esta función solo fallará si no se pudo asignar internamente una tabla hash de reemplazo.
