ck_ht_hash(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_HT_HASH(3) Manual de funciones de la biblioteca CK_HT_HASH(3)

NOMBRE

ck_ht_hash — genera un valor hash para una tabla hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ht.h>

void
ck_ht_hash(ck_ht_hash_t *h, ck_ht_t *ht, const void *key, uint16_t key_length);

DESCRIPCIÓN

La función ck_ht_hash() generará un valor hash en el objeto apuntado por el argumento h. El valor hash será válido para su uso en la tabla hash apuntada por el argumento ht para la clave (de tipo cadena de bytes) especificada por el argumento key. La longitud de la clave se especifica por el argumento key_length.

VALORES DE RETORNO

ck_ht_hash() no tiene valor de retorno.

ERRORES

El comportamiento no está definido si key es NULL o si ht no está inicializado.
