CK_RWCOHORT_PROTOTYPE(3) Manual de Funciones de Librería CK_RWCOHORT_PROTOTYPE(3)

NOMBRE

CK_RWCOHORT_PROTOTYPE — define un bloqueo de cohorte basado en lectores-escritores utilizando el tipo de cohorte especificado

LIBRERÍA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_rwcohort.h>

CK_RWCOHORT_NEUTRAL_PROTOTYPE(COHORT_NAME nombre_cohorte);

CK_RWCOHORT_RP_PROTOTYPE(COHORT_NAME nombre_cohorte);

CK_RWCOHORT_WP_PROTOTYPE(COHORT_NAME nombre_cohorte);

DESCRIPCIÓN

El archivo de cabecera ck_rwcohort.h no define ningún tipo de cohorte. En su lugar, el usuario debe usar la macro CK_RWCOHORT_PROTOTYPE para definir cualquier tipo que desee utilizar. Esta macro toma un único argumento que corresponde al tipo del bloqueo de cohorte que debe utilizar el bloqueo de lectores-escritores. Un tipo de cohorte debe haber sido definido previamente con ese nombre utilizando las macros CK_COHORT_PROTOTYPE(3) o CK_COHORT_TRYLOCK_PROTOTYPE(3).

Se pueden declarar instancias del tipo de bloqueo definido como:
CK_RWCOHORT_INSTANCE(nombre_cohorte) bloqueo;
