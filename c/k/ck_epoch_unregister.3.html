NOMBRE

ck_epoch_unregister — desregistrar un hilo para la recuperación de épocas

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_epoch.h>

void
ck_epoch_unregister(ck_epoch_record_t *record);

DESCRIPCIÓN

La función ck_epoch_unregister(3) permite que el registro apuntado por el puntero record sea utilizado como valor de retorno por la función ck_epoch_recycle(3). Este registro ahora puede ser utilizado por otro hilo de ejecución. El comportamiento no está definido si el objeto al que apunta record se modifica de alguna manera, incluso después de realizar una llamada a la función ck_epoch_unregister(3).

VALORES DE RETORNO

Esta función no tiene valor de retorno.
