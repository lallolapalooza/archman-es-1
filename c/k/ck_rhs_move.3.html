ck_rhs_move(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_RHS_MOVE(3) Manual de Funciones de Biblioteca CK_RHS_MOVE(3)

NOMBRE

ck_rhs_move — mover uno de un conjunto hash a otro

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_rhs.h>

bool
ck_rhs_move(ck_rhs_t *destino, ck_rhs_t *fuente, ck_rhs_hash_cb_t *hash_cb, ck_rhs_compare_cb_t *compare_cb, struct ck_malloc *m);

DESCRIPCIÓN

La función ck_rhs_move(3) inicializará fuente desde destino. La función hash se establecerá en hash_cb, la función de comparación en compare_cb y las callbacks del asignador en m. Modificaciones posteriores a fuente resultarán en un comportamiento indefinido. Las operaciones concurrentes de ck_rhs_get(3) y ck_rhs_fas(3) a fuente son legales hasta la siguiente operación de escritura a destino.

Esta operación mueve la propiedad de un objeto de conjunto hash a otro y reasigna las funciones de callback a valores especificados por el desarrollador. Esto permite la configuración dinámica de las callbacks de asignación y es necesario para casos de uso que involucran código ejecutable que puede ser desmapeado debajo del conjunto hash.

VALORES DE RETORNO

Al completarse con éxito, ck_rhs_move(3) devuelve true y de lo contrario devuelve false para indicar un error.
