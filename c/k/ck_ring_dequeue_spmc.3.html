ck_ring_dequeue_spmc(3)

CK_RING_DEQUEUE_SPMC(3) Manual de funciones de biblioteca CK_RING_DEQUEUE_SPMC(3)

NOMBRE

ck_ring_dequeue_spmc — elimina un puntero de una FIFO acotada

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ring.h>

bool
ck_ring_dequeue_spmc(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *result);

DESCRIPCIÓN

La función ck_ring_dequeue_spmc(3) elimina un puntero del buffer acotado apuntado por ring en orden FIFO. El puntero se almacena en el puntero apuntado por result. El buffer apuntado por buffer debe ser único para ring. La desacoplación del anillo del buffer sirve para abordar casos de uso que involucran múltiples espacios de direcciones y DMA, entre otros. Si te encuentras en plataformas no POSIX o deseas un cumplimiento estricto de C, se recomienda pasar un puntero de tipo void ** para result. Esta función es segura para ser llamada sin bloqueo para UINT_MAX invocaciones concurrentes de ck_ring_dequeue_spmc(3) o ck_ring_trydequeue_spmc(3) y hasta una invocación concurrente de ck_ring_enqueue_spmc(3) o ck_ring_tryenqueue_spmc(3). Esta función proporciona garantías de progreso sin bloqueo.

EJEMPLO

#include <ck_ring.h>

/* Este anillo fue inicializado previamente con ck_ring_init. */
ck_ring_t ring;

/* El anillo fue inicializado para 1023 elementos. */
ck_ring_buffer_t buffer[1024];

void
dequeue(void)
{
	void *result;

	/* Eliminar del anillo hasta que esté vacío. */
	while (ck_ring_dequeue_spmc(&ring, &buffer, &result) == true) {
		/*
		 * Results contiene el puntero más antiguo en ring
		 * ya que la operación de dequeue devolvió true.
		 */
		operation(result);
	}

	/* Se encontró un anillo vacío, salir. */
	return;
}

VALORES DE RETORNO

La función devuelve true si el buffer no estaba vacío. El resultado de la operación de eliminación se almacena en el valor apuntado por result. La función devolverá false si el buffer estaba vacío y el valor en result será indefinido.
