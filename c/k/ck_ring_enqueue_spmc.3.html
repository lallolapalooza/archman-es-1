CK_RING_ENQUEUE_SPMC(3) Manual de funciones de biblioteca CK_RING_ENQUEUE_SPMC(3)

NOMBRE

ck_ring_enqueue_spmc — poner en cola un puntero en FIFO acotado

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ring.h>

bool
ck_ring_enqueue_spmc(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *entry);

DESCRIPCIÓN

La función ck_ring_enqueue_spmc(3) pone en cola el puntero entry en el búfer acotado apuntado por ring en orden FIFO. El búfer apuntado por buffer debe ser único para ring y apuntar a una matriz de ck_ring_buffer_t de longitud suficiente (según los elementos de potencia de 2 en el búfer). La desacoplación del anillo del búfer sirve para abordar casos de uso que involucran múltiples espacios de direcciones y DMA, entre otros. Si se encuentra en plataformas no POSIX o desea un cumplimiento estricto de C, se recomienda pasar un puntero de tipo void ** para entry. Esta función se puede llamar sin bloqueo para UINT_MAX invocaciones concurrentes de ck_ring_dequeue_spmc(3) o ck_ring_trydequeue_spmc(3). Esta función proporciona garantías de progreso sin espera para una invocación activa.

EJEMPLO

#include <ck_ring.h>

/* Este anillo se inicializó previamente con ck_ring_init. */
ck_ring_t ring;

/* El anillo se inicializó para 1023 elementos. */
ck_ring_buffer_t buffer[1024];

void
enqueue(void)
{
	void *entry = some_object;

	/* Intenta poner en cola el puntero a some_object en el buffer. */
	if (ck_ring_enqueue_spmc(&ring, &buffer, &entry) == false) {
		/*
		 * El búfer estaba lleno y la operación de puesta en cola
		 * ha fallado.
		 */
		return;
	}

	/* La operación de puesta en cola se completó con éxito. */
	return;
}

VALORES DE RETORNO

La función devuelve true si el valor de entry se puso en cola correctamente en ring. La función devolverá false si el valor de entry no se pudo poner en cola, lo que solo ocurre si ring estaba lleno.
