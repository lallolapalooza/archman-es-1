ck_ht_stat(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_HT_STAT(3) Manual de funciones de biblioteca CK_HT_STAT(3)

NOMBRE

ck_ht_stat — obtener estado de la tabla hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ht.h>

void
ck_ht_stat(ck_ht_t *ht, struct ck_ht_stat *st);

DESCRIPCIÓN

La función ck_ht_stat(3) almacenará diversas estadísticas del conjunto hash en el objeto apuntado por st. La estructura ck_ht_stat se define como sigue:

struct ck_ht_stat {
	uint64_t probe_maximum; /* Secuencia de sondeo de lectura más larga. */
	uint64_t n_entries;     /* Número actual de claves en el conjunto hash. */
};

VALORES DE RETORNO

ck_ht_stat(3) no tiene valor de retorno.

ERRORES

El comportamiento es indefinido si ht no se ha inicializado.
