ck_rhs_destroy(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_RHS_DESTROY(3) Manual de Funciones de Librería CK_RHS_DESTROY(3)

NOMBRE

ck_rhs_destroy — destruir conjunto de hash

LIBRERÍA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_rhs.h>

void
ck_rhs_destroy(ck_rhs_t *hs);

DESCRIPCIÓN

La función ck_rhs_destroy(3) solicitará que el asignador subyacente, tal como se especifica en la función ck_rhs_init(3), destruya inmediatamente el objeto al que apunta el argumento hs. El usuario debe garantizar que ningún hilo esté accediendo al objeto al que apunta hs cuando se llame a ck_rhs_destroy(3).

VALORES DE RETORNO

ck_rhs_destroy(3) no tiene valor de retorno.

ERRORES

Se garantiza que esta función no fallará.
