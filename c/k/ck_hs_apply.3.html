NOMBRE

ck_hs_apply — aplica una función al valor del conjunto hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_hs.h>

void *
ck_hs_apply_fn_t(void *key, void *closure);

bool
ck_hs_apply(ck_hs_t *hs, unsigned long hash, const void *key, ck_hs_apply_fn_t *function, void *argument);

DESCRIPCIÓN

La función ck_hs_apply(3) buscará la ranura del conjunto hash asociada con key y la pasará a la función apuntada por function para una acción posterior. Esta devolución de llamada puede eliminar o reemplazar el valor devolviendo respectivamente NULL o un puntero a otro objeto con una clave idéntica. El primer argumento pasado a function es un puntero al objeto encontrado en el conjunto hash y el segundo argumento es el puntero argument pasado a ck_hs_apply(3). Si el puntero devuelto por function es equivalente al primer argumento, no se realiza ninguna modificación en el conjunto hash.

VALORES DE RETORNO

Al completarse con éxito, ck_hs_apply(3) devuelve verdadero y, de lo contrario, devuelve falso en caso de error.
