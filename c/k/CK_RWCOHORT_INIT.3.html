CK_RWCOHORT_INIT(3) Manual de funciones de la biblioteca CK_RWCOHORT_INIT(3)

NOMBRE

CK_RWCOHORT_INIT — inicializa la instancia de un tipo de bloqueo de lectura-escritura basado en cohortes

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_rwcohort.h>

CK_RWCOHORT_NEUTRAL_INIT(COHORT_NAME nombre_cohorte, LOCK *bloqueo);

CK_RWCOHORT_RP_INIT(COHORT_NAME nombre_cohorte, LOCK *bloqueo, unsigned int limite_espera);

CK_RWCOHORT_WP_INIT(COHORT_NAME nombre_cohorte, LOCK *bloqueo, unsigned int limite_espera);

DESCRIPCIÓN

Esta macro inicializa la instancia de bloqueo apuntada por el argumento bloqueo. Hasta que una instancia de bloqueo no se inicialice usando la macro CK_RWCOHORT_INIT, cualquier operación que la involucre tendrá un comportamiento indefinido. Tenga en cuenta que el argumento limite_espera solo debe usarse con bloqueos de preferencia de lectura o de preferencia de escritura. Para bloqueos neutrales, este argumento debe excluirse. Si no está seguro de qué valor usar para el argumento limite_espera, debería usar CK_RWCOHORT_STRATEGY_DEFAULT_LOCAL_WAIT_LIMIT.
