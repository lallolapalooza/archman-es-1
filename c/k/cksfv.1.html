CKSFV(1) Manual de comandos generales CKSFV(1)

NOMBRE

cksfv - prueba y crea listados de verificación simple de archivos (SFV)

SINOPSIS

cksfv [-bciqrLR] [-C dir] [-f file] [-g path] [file ...]

DESCRIPCIÓN

cksfv es una herramienta para verificar sumas de verificación CRC32 de archivos. Las sumas de verificación CRC32 se utilizan para verificar que los archivos no estén corruptos. El algoritmo está criptográficamente limitado, por lo que no se puede utilizar para fines de seguridad. md5sum(1) o sha1sum(1) son herramientas mucho mejores para calcular sumas de verificación de archivos. cksfv solo debe usarse para compatibilidad con otros sistemas.

cksfv tiene dos modos de operación: creación de sumas de verificación y verificación de sumas de verificación.

En el **modo de creación de sumas de verificación**, cksfv genera sumas de verificación CRC32 de archivos en la salida estándar, normalmente redirigida a un archivo .sfv.

En el **modo de verificación de sumas de verificación**, cksfv lee nombres de archivo de un archivo sfv y compara los valores de suma de verificación registrados con las sumas de verificación de archivos recalculadas.

OPCIONES

Estas opciones están disponibles:

-b
Elimina los nombres de directorio de los nombres de archivo que se verifican. Carga los archivos desde sus posiciones originales, pero imprime solo los nombres base en el catálogo del archivo sfv.
-c
Utiliza la salida estándar para imprimir el progreso y la resolución final (archivos OK o se detectaron algunos errores). Esto es útil para programas externos que analizan la salida de cksfv. Esto también fuerza las escrituras en la salida cuando es necesario.
-C dir
Cambia el directorio actual antes de proceder con una operación de verificación. Esta opción está en gran medida obsoleta con la opción -g. Anteriormente se usaba para verificar sumas de verificación en un directorio diferente: cksfv -C foo -f foo/bar.sfv
-f file
Verifica las sumas de verificación en el archivo sfv.
-g path
Ve al directorio de ruta y verifica las sumas de verificación en el archivo sfv.
-i
Ignora mayúsculas y minúsculas en los nombres de archivo. Esto se usa en el modo de verificación de sumas de verificación.
-L
Sigue los enlaces simbólicos al recorrer subdirectorios. Esta opción se puede usar con las opciones -r y -R.
-q
Habilita el modo SILENCIOSO (en lugar del modo detallado), solo se imprimen los mensajes de error.
-v
Habilita el modo DETALLADO, este es el modo predeterminado.
-r
Recorre directorios y verifica los archivos .sfv en cada uno. Los enlaces simbólicos no se siguen de forma predeterminada. Esta opción no se puede usar con las opciones -f y -g.
-R
Recorre directorios y lee la suma de verificación de cada archivo. Los enlaces simbólicos no se siguen de forma predeterminada.

EJEMPLOS

Verifica las sumas de verificación de los archivos listados en 'foo/files.sfv':
cksfv -g foo/files.sfv
Crea sumas de verificación para un conjunto de archivos:
cksfv *.gz > files.sfv
Verifica las sumas de verificación de nombres de archivo que no distinguen
entre mayúsculas y minúsculas listados en 'files.sfv'. Esto a veces es útil
con archivos creados por sistemas operativos que tienen nombres de sistema
de archivos que no distinguen entre mayúsculas y minúsculas.
cksfv -i -g files.sfv
Comprueba las sumas de verificación de los archivos 'foo' y 'bar' listados
en 'files.sfv':
cksfv -g files.sfv foo bar
Crea sumas de verificación de archivos que coinciden con /foo/bar/* y
elimina los nombres de directorio:
cksfv -b /foo/bar/* > files.sfv
Escanea recursivamente /foo/bar y verifica cada archivo .sfv:
cksfv -C /foo/bar -r
Igual que el anterior, pero comenzando desde el directorio de trabajo actual
y también siguiendo enlaces simbólicos durante la recursión:
cksfv -r -L
