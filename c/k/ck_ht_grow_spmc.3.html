NOMBRE

ck_ht_grow_spmc — redimensiona una tabla hash si es necesario

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ht.h>

bool
ck_ht_grow_spmc(ck_ht_t *ht, uint64_t capacity);

DESCRIPCIÓN

La función ck_ht_grow_spmc() redimensionará la tabla hash para poder almacenar al menos el número de entradas especificadas por capacity con un factor de carga de uno. El factor de carga por defecto de la tabla hash es 0.5. Si desea minimizar la probabilidad de asignaciones de memoria para una tabla hash destinada a almacenar n entradas, especifique una capacidad de 2n. El comportamiento por defecto de ck_ht es redondear capacity a la siguiente potencia de dos disponible si no es ya una potencia de dos.

Esta función es segura para ser llamada en presencia de operaciones concurrentes de ck_ht_get_spmc(3).

VALORES DE RETORNO

Tras una ejecución exitosa, ck_ht_grow_spmc() devuelve true, de lo contrario, devuelve un valor false.

ERRORES

El comportamiento no está definido si ht no está inicializado. La función solo devolverá false si hay fallos internos de asignación de memoria.
