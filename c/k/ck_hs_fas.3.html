CK_HS_FAS(3) Manual de funciones de la biblioteca CK_HS_FAS(3)

NOMBRE

ck_hs_fas — recuperar y almacenar clave en un conjunto hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_hs.h>

bool
ck_hs_fas(ck_hs_t *hs, unsigned long hash, const void *key, void **previous);

DESCRIPCIÓN

La función ck_hs_fas(3) recuperará y almacenará la clave especificada por el argumento key en el conjunto hash al que apunta el argumento hs. Se espera que la clave especificada por key tenga el valor hash especificado por el argumento hash (que se generó previamente usando la macro CK_HS_HASH(3)).

Si la llamada a ck_hs_fas(3) fue exitosa, entonces la clave especificada por key se almacenó con éxito en el conjunto hash al que apunta hs. La clave debe existir previamente en el conjunto hash y se reemplaza por key, y el valor anterior se almacena en el puntero void apuntado por el argumento previous. Si la clave no existe en el conjunto hash, la función devolverá falso y el conjunto hash permanecerá sin cambios. Se garantiza que esta función es estable con respecto al uso de memoria.

VALORES DE RETORNO

Al completarse con éxito, ck_hs_fas(3) devuelve verdadero y de lo contrario devuelve falso en caso de error.

ERRORES

El comportamiento no está definido si key o hs no están inicializados.
