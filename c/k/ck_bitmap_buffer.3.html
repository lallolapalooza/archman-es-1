CK_BITMAP_BUFFER(3) Manual de funciones de biblioteca CK_BITMAP_BUFFER(3)

NOMBRE

ck_bitmap_buffer — devuelve un puntero al array de bits

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_bitmap.h>

void *
ck_bitmap_buffer(ck_bitmap_t *bitmap);

DESCRIPCIÓN

Las funciones ck_bitmap_buffer() devuelven un puntero al array de bits real. Para los punteros ck_bitmap, el array de bits es de tipo CK_BITMAP_WORD[] y consta de ck_bitmap_base(bitmap) / sizeof(CK_BITMAP_WORD) elementos. En las plataformas de 64 bits actualmente admitidas, CK_BITMAP_WORD es uint64_t. En las plataformas de 32 bits actualmente admitidas, CK_BITMAP_WORD es uint32_t.

VALORES DE RETORNO

Esta función devuelve un valor distinto de NULL.
