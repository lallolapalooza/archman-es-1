CK_COHORT_INSTANCE(3) Manual de funciones de la biblioteca CK_COHORT_INSTANCE(3)

NOMBRE

CK_COHORT_INSTANCE — declara una instancia de un tipo de cohorte

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_cohort.h>

CK_COHORT_INSTANCE(NOMBRE_COHORTE nombre_cohorte);

DESCRIPCIÓN

El usuario debe usar esta macro para declarar instancias de tipos de cohorte que hayan definido. Por ejemplo, si han utilizado la macro CK_COHORT_PROTOTYPE para definir un tipo de cohorte con el nombre foo, crearían una instancia de este tipo de la siguiente manera:
CK_COHORT_INSTANCE(foo) cohorte;

Esta macro también debe usarse al asignar memoria para cohortes. Por ejemplo, para asignar un bloque de 4 cohortes:
CK_COHORT_INSTANCE(foo) *cohortes = malloc(4 * sizeof(CK_COHORT_INSTANCE(foo)));
