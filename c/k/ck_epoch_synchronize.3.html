ck_epoch_synchronize(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_EPOCH_SYNCHRONIZE(3) Manual de funciones de biblioteca CK_EPOCH_SYNCHRONIZE(3)

NOMBRE

ck_epoch_synchronize — bloquea hasta que se detecta un período de gracia

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_epoch.h>

void
ck_epoch_synchronize(ck_epoch_record_t *record);

DESCRIPCIÓN

La función ck_epoch_synchronize(3) bloqueará al llamador hasta que se detecte un período de gracia, de acuerdo con la semántica de la recuperación de épocas. No es seguro llamar a esta función en un registro que se encuentra en una sección activa. Cualquier objeto que requiera recuperación segura de memoria que se haya eliminado lógicamente es seguro para la eliminación física tras una llamada a ck_epoch_synchronize(3). Si requiere que se despachen todas las devoluciones de llamada, entonces se sugiere que utilice ck_epoch_barrier(3) en su lugar o que siga una llamada a ck_epoch_synchronize(3) con ck_epoch_reclaim(3).

EJEMPLO

#include <ck_epoch.h>
#include <ck_stack.h>
#include <stdlib.h>

/*
 * epoch se inicializó previamente con ck_epoch_init.
 * stack se inicializó previamente con ck_stack_init.
 */
ck_epoch_t *epoch;
ck_stack_t *stack;

void
function(void)
{
	ck_epoch_record_t *record;
	ck_stack_entry_t *s;

	record = malloc(sizeof *record);
	ck_epoch_register(&epoch, record, NULL);

	/*
	 * Estamos usando una sección de época aquí para garantizar que
	 * ningún nodo en la pila se elimine mientras los referenciamos.
	 * Esto es necesario aquí porque hay múltiples escritores.
	 * Si solo hubiera un hilo extrayendo de esta pila,
	 * entonces no hay necesidad de ck_epoch_begin/ck_epoch_end.
	 */
	ck_epoch_begin(record);

	/* Eliminar lógicamente un objeto. */
	s = ck_stack_pop_upmc(stack);

	ck_epoch_end(record);

	/*
	 * Espera hasta que ningún hilo pueda tener una referencia al
	 * objeto que acabamos de extraer (asumiendo que todos los hilos están simplemente ejecutando
	 * ck_stack_pop_upmc).
	 */
	ck_epoch_synchronize(record);

	/* Ahora es seguro eliminar físicamente el objeto. */
	free(s);
	return;
}

VALORES DE RETORNO

Esta función no tiene valor de retorno.

ERRORES

El objeto al que apunta .Fa record debe haber sido registrado previamente a través de ck_epoch_register(3).
