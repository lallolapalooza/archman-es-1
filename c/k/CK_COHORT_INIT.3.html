CK_COHORT_INIT(3) Manual de funciones de biblioteca CK_COHORT_INIT(3)

NOMBRE

CK_COHORT_INIT — inicializa una instancia de un tipo de cohorte

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_cohort.h>

CK_COHORT_INIT(COHORT_NAME nombre_cohorte, COHORT *cohorte, void *bloqueo_global, void *bloqueo_local, unsigned int limite_pasadas);

DESCRIPCIÓN

Hasta que una instancia de cohorte se inicialice usando la macro CK_COHORT_INIT, cualquier operación que la involucre tendrá un comportamiento indefinido. Después de que esta macro haya sido llamada, la cohorte apuntada por el argumento cohorte usará el bloqueo apuntado por bloqueo_global como su bloqueo global y el bloqueo apuntado por bloqueo_local como su bloqueo local.

La cohorte liberará su bloqueo global después de limite_pasadas adquisiciones consecutivas de su bloqueo local, incluso si hay otros hilos esperando. Si no estás seguro de un valor para usar en el argumento limite_pasadas, deberías usar CK_COHORT_DEFAULT_LOCAL_PASS_LIMIT.
