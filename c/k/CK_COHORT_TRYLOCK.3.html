CK_COHORT_TRYLOCK(3) Manual de funciones de biblioteca CK_COHORT_TRYLOCK(3)

NOMBRE

CK_COHORT_TRYLOCK — intenta adquirir el bloqueo de cohort

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_cohort.h>

CK_COHORT_TRYLOCK(NOMBRE_COHORTE nombre_cohorte, COHORTE *cohorte, void *contexto_bloqueo_global_intento, void *contexto_bloqueo_local_intento, void *contexto_desbloqueo_bloqueo);

DESCRIPCIÓN

Esta llamada intenta adquirir los bloqueos local y global (si es necesario) de cohorte. Solo se puede usar con tipos de cohorte que se definieron usando la macro CK_COHORT_TRYLOCK_PROTOTYPE(3). La llamada no se bloqueará y devolverá un booleano que será verdadero si el cohorte se adquirió correctamente. contexto_bloqueo_global_intento se pasará como segundo argumento a la función que se proporcionó como argumento metodo_bloqueo_global_intento a CK_COHORT_TRYLOCK_PROTOTYPE si se llama a ese método, y contexto_bloqueo_local_intento se pasará a la función especificada por metodo_bloqueo_local_intento. Si la adquisición del bloqueo global falla, el cohorte liberará inmediatamente su bloqueo local también, y contexto_desbloqueo_bloqueo se pasará a la función especificada por metodo_desbloqueo_local cuando se realice esta llamada.
