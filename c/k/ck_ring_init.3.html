CK_RING_INIT(3) Manual de funciones de biblioteca CK_RING_INIT(3)

NOMBRE

ck_ring_init — inicializar FIFO delimitado

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ring.h>

void
ck_ring_init(ck_ring_t *ring, unsigned int size);

DESCRIPCIÓN

La función ck_ring_init() inicializa un búfer FIFO delimitado apuntado por ring para el almacenamiento de hasta size punteros. El argumento size debe ser una potencia de dos mayor o igual a 4.

VALORES DE RETORNO

Esta función no tiene valor de retorno.
