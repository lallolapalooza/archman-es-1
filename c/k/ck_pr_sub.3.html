ck_pr_sub(3) Manual de funciones de biblioteca ck_pr_sub(3)

NOMBRE

ck_pr_sub_ptr, ck_pr_sub_double, ck_pr_sub_char, ck_pr_sub_uint, ck_pr_sub_int, ck_pr_sub_64, ck_pr_sub_32, ck_pr_sub_16, ck_pr_sub_8 — operaciones de resta atómica

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_sub_ptr(void *target, uintptr_t delta);

void
ck_pr_sub_double(double *target, double delta);

void
ck_pr_sub_char(char *target, char delta);

void
ck_pr_sub_uint(unsigned int *target, unsigned int delta);

void
ck_pr_sub_int(int *target, int delta);

void
ck_pr_sub_64(uint64_t *target, uint64_t delta);

void
ck_pr_sub_32(uint32_t *target, uint32_t delta);

void
ck_pr_sub_16(uint16_t *target, uint16_t delta);

void
ck_pr_sub_8(uint8_t *target, uint8_t delta);

DESCRIPCIÓN

Las funciones de la familia ck_pr_sub(3) restan atómicamente el valor especificado por delta del valor apuntado por target.

VALORES DE RETORNO

Esta familia de funciones no tiene valor de retorno.
