CK_RWCOHORT_READ_LOCK(3) Manual de funciones de biblioteca CK_RWCOHORT_READ_LOCK(3)

NOMBRE

CK_RWCOHORT_READ_LOCK — adquirir permiso de solo lectura para un bloqueo de lector-escritor basado en cohortes

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_cohort.h>

CK_RWCOHORT_NEUTRAL_READ_LOCK(COHORT_NAME nombre_cohorte, LOCK *bloqueo, COHORT *cohorte"void *contexto_global, void *contexto_local);

CK_RWCOHORT_RP_READ_LOCK(COHORT_NAME nombre_cohorte, LOCK *bloqueo, COHORT *cohorte"void *contexto_global, void *contexto_local);

CK_RWCOHORT_WP_READ_LOCK(COHORT_NAME nombre_cohorte, LOCK *bloqueo, COHORT *cohorte"void *contexto_global, void *contexto_local);

DESCRIPCIÓN

Esta llamada adquirirá permiso de solo lectura de bloqueo. La llamada se bloqueará hasta que se adquiera este permiso. cohorte debe apuntar a una cohorte cuyo bloqueo global sea el mismo que el de todas las demás cohortes utilizadas con bloqueo. Los argumentos contexto_global y contexto_local se pasarán como argumentos de contexto a cualquier llamada a cohorte.
