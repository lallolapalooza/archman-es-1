ck_rhs_put_unique(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_RHS_PUT_UNIQUE(3) Manual de funciones de la biblioteca CK_RHS_PUT_UNIQUE(3)

NOMBRE

ck_rhs_put_unique — almacena incondicionalmente una clave única en un conjunto de hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_rhs.h>

bool
ck_rhs_put_unique(ck_rhs_t *hs, unsigned long hash, const void *key);

DESCRIPCIÓN

La función ck_rhs_put_unique(3) almacenará la clave especificada por el argumento key en el conjunto de hash apuntado por el argumento hs. Se espera que la clave especificada por key tenga el valor hash especificado por el argumento hash (que se generó previamente usando la macro CK_RHS_HASH(3)).

Si la llamada a ck_rhs_put(3) fue exitosa, entonces la clave especificada por key se almacenó con éxito en el conjunto de hash apuntado por hs. La función causará un comportamiento indefinido si una clave con un valor equivalente ya está presente en el conjunto de hash. Para obtener semántica de reemplazo, consulte la función ck_rhs_set(3).

VALORES DE RETORNO

Al completarse con éxito, ck_rhs_put_unique(3) devuelve true y, de lo contrario, devuelve false en caso de fallo.

ERRORES

El comportamiento es indefinido si key o hs no están inicializados. La función también devolverá false si el conjunto de hash no pudo ser ampliado para acomodar la inserción de la clave. La función resultará en un comportamiento indefinido si se llama para un valor de clave ya insertado.
