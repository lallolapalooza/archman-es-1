Paquete: libck

CK_RHS_PUT(3) Manual de funciones de biblioteca CK_RHS_PUT(3)

NOMBRE

ck_rhs_put — almacenar una clave única en un conjunto hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_rhs.h>

bool
ck_rhs_put(ck_rhs_t *hs, unsigned long hash, const void *key);

DESCRIPCIÓN

La función ck_rhs_put(3) almacenará la clave especificada por el argumento key en el conjunto hash apuntado por el argumento hs. Se espera que la clave especificada por key tenga el valor hash especificado por el argumento hash (que se generó previamente usando la macro CK_RHS_HASH(3)).

Si la llamada a ck_rhs_put(3) fue exitosa, entonces la clave especificada por key se almacenó con éxito en el conjunto hash apuntado por hs. La función fallará si una clave con un valor equivalente a key ya está presente en el conjunto hash. Para obtener semánticas de reemplazo, consulte la función ck_rhs_set(3).

VALORES DE RETORNO

Tras una finalización exitosa, ck_rhs_put(3) devuelve verdadero y, de lo contrario, devuelve falso en caso de fallo.

ERRORES

El comportamiento no está definido si key o hs no están inicializados. La función también devolverá falso si el conjunto hash no pudo ser ampliado para acomodar la inserción de la clave.
