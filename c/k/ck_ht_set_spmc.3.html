CK_HT_SET_SPMC(3) Manual de funciones de biblioteca CK_HT_SET_SPMC(3)

NOMBRE

ck_ht_set_spmc — almacena un par clave-valor en la tabla hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ht.h>

bool
ck_ht_set_spmc(ck_ht_t *ht, ck_ht_hash_t h, ck_ht_entry_t *entry);

DESCRIPCIÓN

La función ck_ht_set_spmc() almacenará el par clave-valor especificado en el argumento entry en la tabla hash apuntada por el argumento ht. Se espera que la clave especificada en entry tenga el valor hash especificado por el argumento h.

Si ht se creó con CK_HT_MODE_BYTESTRING, entonces entry debe haber sido inicializado con la función ck_ht_entry_set(3). Si ht se creó con CK_HT_MODE_DIRECT, entonces entry debe haber sido inicializado con la función ck_ht_entry_set_direct(3).

Se espera que h haya sido inicializado con ck_ht_hash(3) si ht se creó con CK_HT_MODE_BYTESTRING. Si ht se inicializó con CK_HT_MODE_DIRECT, entonces se espera que h haya sido inicializado con la función ck_ht_hash_direct(3).

Si la llamada a ck_ht_set_spmc() fue exitosa, el par clave-valor en entry contendrá el par clave-valor anterior asociado con la clave originalmente contenida en el argumento entry. Si la operación no tuvo éxito, entry no se modifica.

Esta función es segura para ser llamada en presencia de operaciones concurrentes de ck_ht_get_spmc.

VALORES DE RETORNO

Al completarse con éxito, ck_ht_set_spmc() devuelve true, de lo contrario, devuelve false en caso de fallo.

ERRORES

El comportamiento no está definido si entry o ht no están inicializados. La función devolverá false si la tabla hash necesitó crecer pero falló al intentar hacerlo.
