NOMBRE

ck_bitmap_init — inicializar un mapa de bits

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_bitmap.h>

void
ck_bitmap_init(ck_bitmap_t *bitmap, unsigned int n_bits, bool set);

DESCRIPCIÓN

La función ck_bitmap_init() inicializa el mapa de bits al que apunta el puntero bitmap. El argumento n_bits especifica el número de bits que se almacenarán en el mapa de bits. El argumento set determina si los valores de los bits en bitmap se inicializarán a 1 o 0.

Se espera que bitmap apunte a una región contigua de memoria que contenga al menos el número de bytes especificado por ck_bitmap_size(3).

VALORES DE RETORNO

Esta función no tiene valor de retorno.

ERRORES

El comportamiento de ck_bitmap_init() es indefinido si bitmap no es un puntero a una región de bytes de al menos ck_bitmap_size(3) de longitud.
