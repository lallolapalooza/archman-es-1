CK_COHORT_PROTOTYPE(3) Manual de funciones de biblioteca CK_COHORT_PROTOTYPE(3)

NOMBRE

CK_COHORT_PROTOTYPE — define el tipo de cohorte con tipos de bloqueo especificados

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_cohort.h>

CK_COHORT_PROTOTYPE(NOMBRE_COHORTE cohort_name, TIPO global_lock_method, LOCK_FXN global_unlock_method, LOCK_FXN local_lock_method, LOCK_FXN local_unlock_method);

DESCRIPCIÓN

El archivo de cabecera ck_cohort.h no define ningún tipo de cohorte. En su lugar, el usuario debe usar las macros CK_COHORT_PROTOTYPE o CK_COHORT_TRYLOCK_PROTOTYPE(3) para definir los tipos que desea utilizar. Deben usar CK_COHORT_TRYLOCK_PROTOTYPE si desean que su tipo de cohorte admita operaciones de trylock. La macro CK_COHORT_PROTOTYPE toma los siguientes argumentos:

cohort_name : Un identificador utilizado para este tipo de cohorte. Tendrá que pasarse a cada una de las otras macros CK_COHORT.
global_lock_method : El método que se llamará para adquirir el bloqueo global.
global_unlock_method : El método que se llamará para liberar el bloqueo global.
local_lock_method : El método que se llamará para adquirir el bloqueo local.
local_unlock_method : El método que se llamará para liberar el bloqueo local.

Las instancias del tipo de cohorte definido se pueden declarar como:
CK_COHORT_INSTANCE(cohort_name) cohort;
