NOMBRE

ck_ring_trydequeue_spmc — extraer de FIFO acotado y permitir fallo espurio

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ring.h>

bool
ck_ring_trydequeue_spmc(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *result);

DESCRIPCIÓN

La función ck_ring_trydequeue_spmc(3) intenta extraer un puntero del buffer acotado apuntado por ring en modo FIFO. El puntero se almacena en el puntero apuntado por result. El buffer apuntado por buffer debe ser único para ring y apuntar a un array de ck_ring_buffer_t de longitud suficiente (según los elementos potencia de 2 en el buffer). La desacoplamiento del anillo del buffer sirve para abordar casos de uso que involucran múltiples espacios de direcciones y DMA, entre otros. Si está en plataformas no POSIX o desea un cumplimiento estricto de C, entonces se recomienda pasar un puntero de tipo void ** para result. Esta función es segura para llamar sin bloqueo para UINT_MAX invocaciones concurrentes de ck_ring_dequeue_spmc(3) o ck_ring_trydequeue_spmc(3) y hasta una invocación concurrente de ck_ring_enqueue_spmc(3) o ck_ring_tryenqueue_spmc(3). Esta operación siempre se completará en un número finito de pasos. Es posible que la función devuelva false incluso si ring no está vacío. Esto

EJEMPLO

#include <ck_ring.h>

/* Este anillo se inicializó previamente con ck_ring_init. */
ck_ring_t ring;

/* El anillo se inicializó para 1023 elementos. */
ck_ring_buffer_t buffer[1024];

void
dequeue(void)
{
	void *result;

	/* Extraer del anillo hasta que se observe contención activa. */
	while (ck_ring_trydequeue_spmc(&ring, &buffer, &result) == true) {
		/*
		 * result contiene el puntero más antiguo en ring
		 * ya que la operación de extracción devolvió true.
		 */
		operation(result);
	}

	/* Se encontró un anillo vacío, salir. */
	return;
}

VALORES DE RETORNO

La función devuelve true si la operación de extracción se completó con éxito en un número finito de pasos. El resultado de la operación de extracción se almacena en el valor apuntado por result. De lo contrario, la función devolverá false si el buffer estaba vacío o si la operación no pudo completarse en un número finito de pasos. Si la función devuelve false, entonces el contenido de result no está definido.
