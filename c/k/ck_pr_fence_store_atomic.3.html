CK_PR_FENCE_STORE_ATOMIC(3) Manual de funciones de biblioteca CK_PR_FENCE_STORE_ATOMIC(3)

NOMBRE

ck_pr_fence_store_atomic — garantiza el orden de las operaciones de escritura respecto a las operaciones de lectura

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_fence_store_atomic(void);

void
ck_pr_fence_strict_store_atomic(void);

DESCRIPCIÓN

La función ck_pr_fence_store_atomic() garantiza el orden de cualquier escritura de memoria, ck_pr_store() y operaciones atómicas de lectura-modificación-escritura, con respecto a las operaciones atómicas de lectura-modificación-escritura posteriores a la invocación de la función. Esta función siempre actúa como una barrera implícita para el compilador. Estas funciones emitirán una valla para los destinos PSO y RMO. Para forzar la emisión de una valla, use la función ck_pr_fence_strict_store_atomic().

EJEMPLO

#include <ck_pr.h>

static int a = 0;
static int b = 0;

void
function(void)
{

	ck_pr_store_int(&a, 1);

	/*
	 * Garantiza que la escritura en a se complete
	 * con respecto a la actualización de b.
	 */
	ck_pr_fence_store_atomic();
	ck_pr_add_int(&b, 2);
	return;
}

VALORES DE RETORNO

Esta función no tiene valor de retorno.
