NOMBRE

CK_ARRAY_FOREACH — iterar a través de un array

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_array.h>

bool
CK_ARRAY_FOREACH(ck_array_t *array, ck_array_iterator_t *iterator, void **b);

DESCRIPCIÓN

La macro CK_ARRAY_FOREACH(3) itera a través del array apuntado por array. Se debe especificar un puntero a un objeto iterador mediante iterator y b debe apuntar a un puntero void.

EJEMPLO

#include <ck_array.h>

/* Asume que esto ya fue inicializado previamente. */
ck_array_t array;

void
example(void)
{
	ck_array_iterator_t iterator;
	void *pointer;

	CK_ARRAY_FOREACH(&array, &iterator, &pointer) {
		do_something(pointer);
	}
}

VALORES DE RETORNO

Esta macro no tiene valor de retorno.
