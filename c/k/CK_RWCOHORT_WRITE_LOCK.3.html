NOMBRE

CK_RWCOHORT_WRITE_LOCK — adquiere acceso de escritura para un bloqueo de lector-escritor basado en cohortes

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_cohort.h>

CK_RWCOHORT_NEUTRAL_WRITE_LOCK(COHORT_NAME nombre_cohorte, LOCK *bloqueo, COHORT *cohorte"void *contexto_global, void *contexto_local);

CK_RWCOHORT_RP_WRITE_LOCK(COHORT_NAME nombre_cohorte, LOCK *bloqueo, COHORT *cohorte"void *contexto_global, void *contexto_local);

CK_RWCOHORT_WP_WRITE_LOCK(COHORT_NAME nombre_cohorte, LOCK *bloqueo, COHORT *cohorte"void *contexto_global, void *contexto_local);

DESCRIPCIÓN

Esta llamada adquirirá permiso de escritura para bloqueo. La llamada se bloqueará hasta que se haya adquirido este permiso. cohorte debe apuntar a una cohorte cuyo bloqueo global sea el mismo que el de todas las demás cohortes utilizadas con bloqueo. Los argumentos contexto_global y contexto_local se pasarán como argumentos de contexto a cualquier llamada a cohorte.
