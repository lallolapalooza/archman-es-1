ck_rhs_apply(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_RHS_APPLY(3) Manual de funciones de la biblioteca CK_RHS_APPLY(3)

NOMBRE

ck_rhs_apply — aplica una función a un valor de conjunto hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_rhs.h>

void *
ck_rhs_apply_fn_t(void *clave, void *cierre);

bool
ck_rhs_apply(ck_rhs_t *hs, unsigned long hash, const void *clave, ck_rhs_apply_fn_t *funcion, void *argumento);

DESCRIPCIÓN

La función ck_rhs_apply(3) buscará la ranura del conjunto hash asociada con clave y la pasará a la función apuntada por función para una acción adicional. Esta devolución de llamada puede eliminar o reemplazar el valor devolviendo respectivamente NULL o un puntero a otro objeto con una clave idéntica. El primer argumento pasado a función es un puntero al objeto encontrado en el conjunto hash y el segundo argumento es el puntero argumento pasado a ck_rhs_apply(3). Si el puntero devuelto por función es equivalente al primer argumento, no se realiza ninguna modificación en el conjunto hash.

VALORES DE RETORNO

Al completarse con éxito, ck_rhs_apply(3) devuelve true y, de lo contrario, devuelve false en caso de error.
