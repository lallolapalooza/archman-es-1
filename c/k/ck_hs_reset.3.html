CK_HS_RESET(3) Manual de funciones de biblioteca CK_HS_RESET(3)

NOMBRE

ck_hs_reset — elimina todas las claves de un conjunto hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_hs.h>

bool
ck_hs_reset(ck_hs_t *hs);

DESCRIPCIÓN

La función ck_hs_reset(3) eliminará todas las claves almacenadas en el conjunto hash apuntado por el argumento hs.

VALORES DE RETORNO

Si tiene éxito, ck_hs_reset(3) devolverá true y, de lo contrario, devolverá false en caso de error. Esta función solo fallará si no se pudo asignar internamente un conjunto hash de reemplazo.

ERRORES

El comportamiento no está definido si hs no está inicializado. El comportamiento no está definido si esta función es llamada por un hilo que no sea de escritura.
