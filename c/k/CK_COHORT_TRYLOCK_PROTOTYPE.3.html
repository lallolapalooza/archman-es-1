NOMBRE

CK_COHORT_TRYLOCK_PROTOTYPE — define tipo de cohorte con tipos de bloqueo especificados

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_cohort.h>

CK_COHORT_TRYLOCK_PROTOTYPE(NOMBRE_COHORTE cohort_name, METODO_BLOQUEO global_lock_method, METODO_BLOQUEO global_unlock_method, METODO_BLOQUEO_BOOL global_locked_method, METODO_BLOQUEO_BOOL global_trylock_method, METODO_BLOQUEO local_lock_method, METODO_BLOQUEO local_unlock_method, METODO_BLOQUEO_BOOL local_locked_method, METODO_BLOQUEO_BOOL local_trylock_method);

DESCRIPCIÓN

El archivo de cabecera ck_cohort.h no define ningún tipo de cohorte. En su lugar, el usuario debe usar las macros CK_COHORT_PROTOTYPE o CK_COHORT_TRYLOCK_PROTOTYPE para definir los tipos que desea utilizar. Deben usar CK_COHORT_TRYLOCK_PROTOTYPE si desean que su tipo de cohorte tenga soporte para operaciones de trylock. La macro CK_COHORT_TRYLOCK_PROTOTYPE toma los siguientes argumentos:

cohort_name : Un identificador utilizado para este tipo de cohorte. Tendrá que pasarse a cada una de las otras macros CK_COHORT.
global_lock_method : El método que se debe llamar para adquirir el bloqueo global.
global_unlock_method : El método que se debe llamar para liberar el bloqueo global.
global_locked_method : Este método debe devolver true si el bloqueo global está adquirido por un hilo.
global_trylock_method : El método que se debe llamar para intentar adquirir el bloqueo global. No debe bloquear y debe devolver true si el bloqueo se adquirió con éxito.
local_lock_method : El método que se debe llamar para adquirir el bloqueo local.
local_unlock_method : El método que se debe llamar para liberar el bloqueo local.
global_locked_method : Este método debe devolver true si el bloqueo global está adquirido por un hilo.
local_trylock_method : El método que se debe llamar para intentar adquirir el bloqueo local. No debe bloquear y debe devolver true si el bloqueo se adquirió con éxito.

Las instancias del tipo de cohorte definido se pueden declarar como:
CK_COHORT_INSTANCE(nombre_cohorte) cohorte;
