NOMBRE

ck_pr_fence_load_depends — barrera de dependencia de datos

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_fence_load_depends(void);

DESCRIPCIÓN

La función ck_pr_fence_load_depends(3) genera las barreras necesarias para cargas de datos puramente dependientes. Actualmente, solo sirve como barrera del compilador para las plataformas compatibles con Concurrency Kit. A menos que te encuentres en una arquitectura que reordena las cargas de datos dependientes (como la extinta Alpha), esta función es innecesaria.

VALORES DEVUELTOS

Esta función no tiene valor de retorno.
