Paquete: libck

Licencias: BSD, Apache, Custom

CK_RHS_STAT(3) Manual de funciones de biblioteca CK_RHS_STAT(3)

NOMBRE

ck_rhs_stat — obtener el estado del conjunto hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_rhs.h>

void
ck_rhs_stat(ck_rhs_t *hs, struct ck_rhs_stat *st);

DESCRIPCIÓN

La función ck_rhs_stat(3) almacenará diversas estadísticas del conjunto hash en el objeto al que apunta st. La estructura ck_rhs_stat se define de la siguiente manera:

struct ck_rhs_stat {
	unsigned long n_entries;    /* Número actual de claves en el conjunto hash. */
	unsigned int probe_maximum; /* La secuencia de sondeo más larga del lado de lectura. */
};

VALORES DE RETORNO

ck_rhs_stat(3) no tiene valor de retorno.

ERRORES

El comportamiento no está definido si hs no está inicializado. El comportamiento no está definido si esta función es llamada por un hilo que no sea de escritura.
