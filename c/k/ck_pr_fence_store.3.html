NOMBRE

ck_pr_fence_store — impone el orden parcial de las operaciones de almacenamiento

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_fence_store(void);

void
ck_pr_fence_strict_store(void);

DESCRIPCIÓN

La función ck_pr_fence_store() impone el orden de cualquier operación de almacenamiento de memoria, ck_pr_store() y operaciones atómicas de lectura-modificación-escritura con respecto a la invocación de la función. Esta función siempre sirve como una barrera de compilador implícita. En arquitecturas que implementan CK_MD_TSO, esta operación solo sirve como una barrera de compilador y no se emiten vallas. En arquitecturas que implementan CK_MD_PSO y CK_MD_RMO, se emite una valla de almacenamiento. Para forzar la emisión incondicional de una valla de almacenamiento, utilice ck_pr_fence_strict_store().

EJEMPLO

#include <ck_pr.h>

static int a = 0;
static int b = 0;
static int c = 0;

void
function(void)
{

	ck_pr_store_int(&a, 1);

	/*
	 * Garantizar que el almacenamiento en a se completa
	 * con respecto a los almacenamientos de b y c.
	 */
	ck_pr_fence_store();
	ck_pr_store_int(&b, 2);
	ck_pr_store_int(&c, 2);

	return;
}

VALORES DE RETORNO

Esta función no tiene valor de retorno.
