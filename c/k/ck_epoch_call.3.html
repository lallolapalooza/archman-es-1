ck_epoch_call(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_EPOCH_CALL(3) Manual de funciones de la biblioteca CK_EPOCH_CALL(3)

NOMBRE

ck_epoch_call — difiere la ejecución de la función hasta un período de gracia

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_epoch.h> typedef struct ck_epoch_entry ck_epoch_entry_t;
typedef void ck_epoch_cb_t(ck_epoch_entry_t *);
void
ck_epoch_call(ck_epoch_record_t *record, ck_epoch_entry_t *entry, ck_epoch_cb_t *function);

DESCRIPCIÓN

La función ck_epoch_call(3) diferirá la ejecución de la función apuntada por function hasta que se detecte un período de gracia en epoch. La función recibirá el puntero especificado por entry. La función se ejecutará en algún momento futuro a través de llamadas a ck_epoch_reclaim(3), ck_epoch_barrier(3) o ck_epoch_poll(3).

EJEMPLO

#include <ck_epoch.h>
#include <ck_stack.h>
#include <stdlib.h>

/*
 * epoch fue inicializado previamente con ck_epoch_init.
 */
ck_epoch_t *epoch;

struct object {
	int value;
	ck_epoch_entry_t epoch_entry;
};
static struct object *global;

CK_EPOCH_CONTAINER(struct object, epoch_entry, object_container)

void
destroy_object(ck_epoch_entry_t *e)
{
	struct object *o = object_container(e);

	free(o);
	return;
}

void
function(void)
{
	ck_epoch_record_t *record;
	struct object *n;

	record = malloc(sizeof *record);
	ck_epoch_register(&epoch, record, NULL);

	n = malloc(sizeof *n);
	if (n == NULL)
		return;

	n->value = 1;

	/*
	 * Estamos utilizando una sección de época aquí porque hay múltiples
	 * escritores. También es una opción utilizar otras formas de bloqueo
	 * de sincronización del lado de escritura, como mutexes.
	 */
	ck_epoch_begin(record);
	n = ck_pr_fas_ptr(&global, n);
	ck_epoch_end(record);

	/* Diferir la destrucción del objeto anterior. */
	ck_epoch_call(record, &n->epoch_entry, destroy_object);

	/* Sondea el subsistema de época de forma no bloqueante. */
	ck_epoch_poll(record);
	return;
}

VALORES DE RETORNO

Esta función no tiene valor de retorno.

ERRORES

El objeto apuntado por record debe haber sido registrado previamente a través de ck_epoch_register(3).
