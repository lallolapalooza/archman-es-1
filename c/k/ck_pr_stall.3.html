NOMBRE

ck_pr_stall — primitiva de espera activa

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_stall(void);

DESCRIPCIÓN

La función ck_pr_stall(3) debe usarse dentro de las rutas de reintento de los bucles de espera activa. No solo sirve como barrera del compilador, sino que en algunas arquitecturas emite instrucciones que ahorran ciclos.

EJEMPLO

#include <ck_pr.h>

static int ready = 0;

void
function(void)
{

	/* Espera activa hasta que ready no sea cero. */
	while (ck_pr_load_int(&ready) == 0)
		ck_pr_stall();

	return;
}
