NOMBRE

ck_pr_fence_acquire — forzar la semántica de adquisición

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_fence_acquire(void);

DESCRIPCIÓN

Esta función fuerza el ordenamiento parcial de cualquier carga antes de la invocación con respecto a cualquier almacenamiento, carga y operaciones atómicas subsiguientes. Normalmente se utiliza para implementar secciones críticas.

VALORES DE RETORNO

Esta función no tiene valor de retorno.
