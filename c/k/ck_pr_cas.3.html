NAME

ck_pr_cas, ck_pr_cas_value - compare-and-swap memory operation

LIBRARY

Descriptive standard C library

SYNOPSIS

In ck_pr_cas.h:

bool
ck_pr_cas(uint64_t *target, uint64_t old_value, uint64_t new_value);
bool
ck_pr_cas_value(uint64_t *target, uint64_t old_value, uint64_t new_value,
    uint64_t *original_value);

DESCRIPTION

The ck_pr_cas and ck_pr_cas_value functions implement a compare-and-swap operation on a 64-bit integer pointed to by target. These operations are atomic.

If the value pointed to by target is equal to the value specified by old_value, then the value pointed to by target is replaced with the value specified by new_value. Otherwise, no modifications occur to the value in target.

The ck_pr_cas_value function is identical to ck_pr_cas, except that it also stores the original value pointed to by target into the memory location pointed to by original_value prior to any potential modification. The ck_pr_cas_value function unconditionally updates original_value.

These functions are implemented using the processor’s compare-and-swap primitive. This primitive is the fundamental building block of most lock-free data structures. It allows for a thread to perform an atomic read-modify-write operation on a memory location, conditional on the value read from that location.

The use of these primitives can be tricky and complex. It is recommended that users should consult Lock-free data structures and Memory Barriers for a more complete explanation.

The *_value form of these functions unconditionally update original_value.

RETURN VALUES

These functions return true if the value in target was modified as a result of the operation. Otherwise, they return false.
