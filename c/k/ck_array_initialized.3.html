CK_ARRAY_INITIALIZED(3) Manual de funciones de biblioteca CK_ARRAY_INITIALIZED(3)

NOMBRE

ck_array_initialized — indica si una matriz fue inicializada o desinicializada recientemente

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_array.h>

bool
ck_array_initialized(ck_array_t *array);

DESCRIPCIÓN

La función ck_array_initialized(3) se puede utilizar para determinar si una matriz fue inicializada recientemente con ck_array_init(3) o desinicializada con ck_array_deinit(3). El comportamiento no está definido si un usuario asigna datos del asignador interno a través de otros medios.

VALORES DE RETORNO

Esta función devuelve verdadero si la matriz está inicializada y falso en caso contrario.
