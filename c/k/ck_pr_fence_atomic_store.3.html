NOMBRE

ck_pr_fence_atomic_store — garantiza el ordenamiento de operaciones atómicas de lectura-modificación-escritura en operaciones de escritura

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_fence_atomic_store(void);

void
ck_pr_fence_strict_atomic_store(void);

DESCRIPCIÓN

La función ck_pr_fence_atomic_store() garantiza el ordenamiento de cualquier operación atómica de lectura-modificación-escritura con respecto a cualquier operación de escritura posterior a la invocación de la función. Esta función siempre sirve como una barrera implícita del compilador. En arquitecturas que implementan CK_MD_TSO, esta operación solo sirve como barrera del compilador y no se emiten cercas. Para forzar la emisión incondicional de una cerca, use ck_pr_fence_strict_atomic_store().

EJEMPLO

#include <ck_pr.h>

static int a = 0;
static int b = 0;

void
function(void)
{
	int c;

	ck_pr_fas_int(&a, 1);

	/*
	 * Garantiza que la actualización de a se complete
	 * con respecto a la escritura en el valor apuntado
	 * por b.
	 */
	ck_pr_fence_atomic_store();
	c = ck_pr_store_int(&b, 2);

	return;
}

VALORES DE RETORNO

Esta función no tiene valor de retorno.
