CK_HT_GC(3) Manual de funciones de biblioteca CK_HT_GC(3)

NOMBRE

ck_ht_gc — realiza mantenimiento en una tabla hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ht.h>

bool
ck_ht_gc(ck_ht_t *ht, unsigned long cycles, unsigned long seed);

DESCRIPCIÓN

La función ck_ht_gc() realizará varias rutinas de mantenimiento en la tabla hash apuntada por ht, incluyendo la desfragmentación de secuencias de sondeo con respecto a las tumba y, en el caso de que se haya pasado la pista de carga de eliminación, el recálculo de los límites de la secuencia de sondeo. El argumento cycles se utiliza para indicar cuántas entradas de la tabla hash deben someterse a mantenimiento. Si cycles es 0, el mantenimiento se realiza en la tabla hash completa. El argumento seed determina la ubicación de inicio del proceso de mantenimiento. Si cycles no es cero, se recomienda que seed sea algún valor aleatorio. Si se ha pasado la pista de eliminación, la función requerirá un 12% de memoria adicional (con respecto al uso de memoria existente del conjunto), hasta la finalización de la operación.

VALORES DE RETORNO

Tras una finalización exitosa, ck_ht_gc(3) devuelve true y de lo contrario devuelve false en caso de fallo debido a un error de asignación de memoria.

ERRORES

Esta función solo devolverá false si hay fallos internos de asignación de memoria.
