NOMBRE

ck_ring_enqueue_spsc_size — encola un puntero en una FIFO acotada y devuelve el tamaño del búfer

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ring.h>

bool
ck_ring_enqueue_spsc_size(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *entry, unsigned int *size);

DESCRIPCIÓN

La función ck_ring_enqueue_spsc_size(3) encola el puntero entry en el búfer acotado al que apunta ring de forma FIFO (primero en entrar, primero en salir). El búfer al que apunta buffer debe ser único para ring y apuntar a un array de ck_ring_buffer_t de longitud suficiente (según los elementos de potencia de 2 en el búfer). La desacoplación del anillo del búfer sirve para abordar casos de uso que involucran múltiples espacios de direcciones y DMA, entre otros. Si está en plataformas no POSIX o desea un cumplimiento estricto con C, se recomienda pasar un puntero de tipo void ** para entry. Esta función es segura de llamar sin bloqueo para hasta una invocación concurrente de ck_ring_dequeue_spsc(3). Esta función proporciona garantías de progreso sin espera (wait-free).

EJEMPLO

#include <ck_ring.h>

/* Este anillo se inicializó previamente con ck_ring_init. */
ck_ring_t ring;

/* El anillo se inicializó para 1023 elementos. */
ck_ring_buffer_t buffer[1024];

void
enqueue(void)
{
	void *entry = some_object;
	unsigned int length;

	/* Intentar encolar el puntero a some_object en el búfer. */
	if (ck_ring_enqueue_spsc(&ring, &buffer, &entry, &length) == false) {
		/*
		 * El búfer estaba lleno y la operación de encolamiento
		 * ha fallado.
		 */
		return;
	}

	/*
	 * Si la longitud del búfer era de 100 elementos o más en el momento
	 * en que se encoló entry, haz algo.
	 */
	if (length > 100) {
		do_something;
	}

	return;
}

VALORES DE RETORNO

La función devuelve true si el valor de entry se encoló con éxito en ring. Esta función devolverá el número de elementos en ring con respecto al punto de linealización (el punto en el elemento en el que se encola entry). La función devolverá false si el valor de entry no se pudo encolar, lo que solo ocurre si ring estaba lleno.
