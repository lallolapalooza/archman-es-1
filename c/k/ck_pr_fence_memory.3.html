ck_pr_fence_memory(3) Manual de funciones de biblioteca ck_pr_fence_memory(3)

NOMBRE

ck_pr_fence_memory — garantiza un ordenamiento parcial de todas las operaciones de memoria

LIBRERÍA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_fence_memory();

void
ck_pr_fence_strict_memory();

DESCRIPCIÓN

La función ck_pr_fence_memory(3) garantiza el ordenamiento de cualquier operación de memoria con respecto a la invocación de la función. Esta función siempre sirve como una barrera implícita del compilador. Las arquitecturas que implementan CK_MD_TSO no emiten una barrera, pero las semánticas de barrera del compilador permanecen. Las arquitecturas que implementan CK_MD_PSO y CK_MD_RMO siempre emiten instrucciones que proporcionan las garantías de ordenamiento especificadas. Para forzar la emisión incondicional de una barrera de memoria, utilice ck_pr_fence_strict_memory().

EJEMPLO

#include <ck_pr.h>

static int a = 0;
static int b;
static int c;
static int d;

void
function(void)
{
	int snapshot_a;

	ck_pr_store_int(&b, 1);
	snapshot_a = ck_pr_load_int(&a);

	/*
	 * Asegúrate de que las operaciones de memoria anteriores estén
	 * ordenadas con respecto a las operaciones de memoria
	 * posteriores a ck_pr_fence_memory.
	 */
	ck_pr_fence_memory();

	ck_pr_store_int(&d, 3);
	ck_pr_store_int(&c, 2);

	return;
}

VALORES DEVUELTOS

Esta función no tiene valor de retorno.
