CK_HS_ITERATOR_INIT(3) Manual de Funciones de Biblioteca CK_HS_ITERATOR_INIT(3)

NOMBRE

ck_hs_iterator_init — inicializar el iterador de conjunto hash

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_hs.h>

ck_hs_iterator_t iterator = CK_HS_ITERATOR_INITIALIZER


void
ck_hs_iterator_init(ck_hs_iterator_t *iterator);

DESCRIPCIÓN

La función ck_hs_iterator_init(3) inicializará el objeto al que apunta el argumento iterator. Alternativamente, un iterador puede ser inicializado estáticamente asignándole el valor CK_HS_ITERATOR_INITIALIZER.

Se utiliza un iterador para recorrer las entradas del conjunto hash con la función ck_hs_next(3).

VALORES DE RETORNO

ck_hs_iterator_init(3) no tiene valor de retorno.

ERRORES

Esta función no fallará.
