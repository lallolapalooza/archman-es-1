NOMBRE

ck_pr_fence_store_load — garantiza el orden de las operaciones de escritura respecto a las operaciones de lectura

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_fence_store_load(void);

void
ck_pr_fence_strict_store_load(void);

DESCRIPCIÓN

La función ck_pr_fence_store_load() garantiza el orden de cualquier operación de escritura en memoria, ck_pr_store() y operaciones atómicas de lectura-modificación-escritura respecto a las operaciones de lectura que invocan a la función. Esta función siempre servirá como una barrera implícita del compilador. Actualmente, siempre se emitirá una valla para esta operación, incluso para destinos con modelo de memoria TSO.

EJEMPLO

#include <ck_pr.h>

static int a = 0;
static int b = 0;

void
funcion(void)
{
	unsigned int snapshot_b;

	ck_pr_store_int(&a, 1);

	/*
	 * Garantiza que la escritura en 'a' se complete
	 * con respecto a la lectura de 'b'.
	 */
	ck_pr_fence_store_load();
	snapshot_b = ck_pr_load_int(&b, 2);
	return;
}

VALORES DE RETORNO

Esta función no tiene valor de retorno.
