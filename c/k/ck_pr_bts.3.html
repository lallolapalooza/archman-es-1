ck_pr_bts(3) Manual de funciones de biblioteca ck_pr_bts(3)

NOMBRE

ck_pr_bts_ptr, ck_pr_bts_uint, ck_pr_bts_int, ck_pr_bts_64, ck_pr_bts_32, ck_pr_bts_16 — operaciones atómicas de prueba y establecimiento de bits

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

bool
ck_pr_bts_ptr(void *objetivo, unsigned int indice_bit);

bool
ck_pr_bts_uint(uint *objetivo, unsigned int indice_bit);

bool
ck_pr_bts_int(int *objetivo, unsigned int indice_bit);

bool
ck_pr_bts_64(uint64_t *objetivo, unsigned int indice_bit);

bool
ck_pr_bts_32(uint32_t *objetivo, unsigned int indice_bit);

bool
ck_pr_bts_16(uint16_t *objetivo, unsigned int indice_bit);

DESCRIPCIÓN

La familia de funciones ck_pr_bts(3) obtiene atómicamente el valor del bit en objetivo en el índice indice_bit y establece ese bit a 1.

VALORES DE RETORNO

Esta familia de funciones devuelve el valor original del bit en el desplazamiento indice_bit que se encuentra en el valor apuntado por objetivo.
