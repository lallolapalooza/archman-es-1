CK_BITMAP_BITS(3) Manual de funciones de biblioteca CK_BITMAP_BITS(3)

NOMBRE

ck_bitmap_bits — devuelve el número de bits direccionables en el mapa de bits

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_bitmap.h>

unsigned int
ck_bitmap_bits(ck_bitmap_t *bitmap);

DESCRIPCIÓN

La función ck_bitmap_bits() devuelve el número máximo de bits direccionables en el objeto apuntado por bitmap.

VALORES DE RETORNO

Esta función devuelve un valor distinto de cero.

VER TAMBIÉN
