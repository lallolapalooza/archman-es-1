ck_ring_size(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_RING_SIZE(3) Manual de funciones de biblioteca CK_RING_SIZE(3)

NOMBRE

ck_ring_size — devuelve el número de punteros encolados en FIFO delimitado.

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ring.h>

unsigned int
ck_ring_size(ck_ring_t *ring);

DESCRIPCIÓN

La función ck_ring_size(3) devuelve el número de punteros actualmente encolados en el búfer apuntado por ring.

VER TAMBIÉN

ck_ring_init(3), ck_ring_enqueue_spmc(3), ck_ring_dequeue_spmc(3), ck_ring_trydequeue_spmc(3), ck_ring_enqueue_spmc_size(3), ck_ring_dequeue_spsc(3), ck_ring_enqueue_spsc(3), ck_ring_enqueue_spsc_size(3), ck_ring_capacity(3)
