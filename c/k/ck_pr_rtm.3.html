ck_pr_rtm(3) Manual de funciones de biblioteca ck_pr_rtm(3)

NOMBRE

ck_pr_rtm_begin, ck_pr_rtm_end, ck_pr_rtm_abort, ck_pr_rtm_test — memoria transaccional restringida

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

unsigned int
ck_pr_rtm_begin(void);

void
ck_pr_rtm_end(void);

void
ck_pr_rtm_abort(const unsigned int status);

bool
ck_pr_rtm_test(void);

DESCRIPCIÓN

Estas funciones implementan el soporte para memoria transaccional restringida, si está disponible en la plataforma subyacente. Actualmente, el soporte solo se proporciona para arquitecturas x86 Intel Haswell y más nuevas que tienen la característica TSX-NI.

La función ck_pr_rtm_begin() devuelve CK_PR_RTM_STARTED si una transacción se inició correctamente. En caso de aborto, ya sea interno (a través de un ck_pr_rtm_abort) o externo, el flujo del programa regresará al punto desde donde se llamó a la función, excepto que el valor de retorno consistirá en un mapa de bits con uno o más de los siguientes bits establecidos:

CK_PR_RTM_EXPLICIT
Establecido si la transacción fue abortada explícitamente a través de ck_pr_rtm_abort().
CK_PR_RTM_RETRY
Establecido si la transacción falló pero aún puede tener éxito si se reintenta.
CK_PR_RTM_CONFLICT
La transacción falló debido a un conflicto en una de las direcciones de memoria que forman parte del conjunto de trabajo de la transacción.
CK_PR_RTM_CAPACITY
Establecido si se excedió el límite de tamaño de transacción definido por la arquitectura.
CK_PR_RTM_DEBUG
Establecido si se activó un punto de interrupción de hardware.
CK_PR_RTM_NESTED
Establecido si una transacción anidada falló.

El usuario también puede especificar un byte de estado de aborto de un byte llamando a ck_pr_rtm_abort(). Este byte de estado se puede extraer llamando a la función CK_PR_RTM_CODE() con el valor de retorno de ck_pr_rtm_begin() como argumento. El valor de retorno de CK_PR_RTM_CODE() será el valor de este byte de estado. Para obtener información adicional, consulte los manuales de conjunto de instrucciones de Intel.
