ck_epoch_reclaim(3)

Paquete: libck

Licencias: BSD, Apache, Custom

CK_EPOCH_RECLAIM(3) Manual de funciones de biblioteca CK_EPOCH_RECLAIM(3)

NOMBRE

ck_epoch_reclaim — ejecuta inmediatamente todas las devoluciones de llamada diferidas

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_epoch.h>

void
ck_epoch_reclaim(ck_epoch_record_t *record);

DESCRIPCIÓN

La función ck_epoch_reclaim(3) ejecutará incondicionalmente todas las devoluciones de llamada que se hayan diferido con ck_epoch_call(3).

EJEMPLO

#include <ck_epoch.h>
#include <ck_stack.h>
#include <stdlib.h>

/*
 * epoch se inicializó previamente con ck_epoch_init.
 */
ck_epoch_t *epoch;

void
function(void)
{
	ck_epoch_record_t *record;

	logically_delete(object);
	ck_epoch_call(epoch, record, &object->epoch_entry, destructor);

	/*
	 * Esperar hasta que ningún hilo pueda tener una referencia al
	 * objeto que acabamos de eliminar.
	 */
	ck_epoch_synchronize(epoch, record);

	/*
	 * Ejecutar todas las devoluciones de llamada diferidas.
	 */
	ck_epoch_reclaim(record);

	return;
}

VALORES DE RETORNO

Esta función no tiene valor de retorno.
