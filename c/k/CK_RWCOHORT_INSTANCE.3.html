CK_RWCOHORT_INSTANCE(3) Manual de funciones de la biblioteca CK_RWCOHORT_INSTANCE(3)

NOMBRE

CK_RWCOHORT_INSTANCE — declara una instancia de un tipo de bloqueo de lector-escritor basado en cohortes

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_cohort.h>

CK_RWCOHORT_NEUTRAL_INSTANCE(NOMBRE_COHORTE nombre_cohorte);

CK_RWCOHORT_RP_INSTANCE(NOMBRE_COHORTE nombre_cohorte);

CK_RWCOHORT_WP_INSTANCE(NOMBRE_COHORTE nombre_cohorte);

DESCRIPCIÓN

El usuario debe usar esta macro para declarar instancias de tipos de bloqueo que haya definido usando la macro CK_RWCOHORT_PROTOTYPE(3). El nombre_cohorte debe ser el mismo que el utilizado en la macro de prototipo. Por ejemplo, si se llamó a CK_RWCOHORT_PROTOTYPE con el nombre "foo", la macro CK_RWCOHORT_INSTANCE debe llamarse como
CK_RWCOHORT_INSTANCE(foo) cohorte;

Esta macro también debe usarse al asignar memoria para cohortes. Por ejemplo, para asignar un bloque de 4 cohortes:
CK_RWCOHORT_WP_INSTANCE(foo) *cohortes = malloc(4 * sizeof(CK_RWCOHORT_WP_INSTANCE(foo)));
