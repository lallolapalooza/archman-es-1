NOMBRE

ck_ring_enqueue_spsc — poner en cola puntero en FIFO acotado

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_ring.h>

bool
ck_ring_enqueue_spsc(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *entry);

DESCRIPCIÓN

La función ck_ring_enqueue_spsc(3) pone en cola el puntero entry en el búfer acotado apuntado por ring en modo FIFO. El búfer apuntado por buffer debe ser único para ring y apuntar a una matriz de ck_ring_buffer_t de longitud suficiente (de acuerdo con los elementos de potencia de 2 en el búfer). La desacoplación del anillo del búfer sirve para abordar casos de uso que involucran múltiples espacios de direcciones y DMA, entre otros. Si se encuentra en plataformas no POSIX o desea un estricto cumplimiento con C, se recomienda pasar un puntero de tipo void ** para entry. Esta función se puede llamar de forma segura sin bloqueo para hasta una invocación concurrente de ck_ring_dequeue_spsc(3). Esta función proporciona garantías de progreso sin espera.

EJEMPLO

#include <ck_ring.h>

/* Este anillo fue inicializado previamente con ck_ring_init. */
ck_ring_t ring;

/* El anillo fue inicializado para 1023 elementos. */
ck_ring_buffer_t buffer[1024];

void
enqueue(void)
{
	void *entry = some_object;

	/* Intentar poner en cola el puntero a some_object en el búfer. */
	if (ck_ring_enqueue_spsc(&ring, &buffer, &entry) == false) {
		/*
		 * El búfer estaba lleno y la operación de puesta en cola
		 * ha fallado.
		 */
		return;
	}

	/* Operación de puesta en cola completada con éxito. */
	return;
}

VALORES DE RETORNO

La función devuelve true si el valor de entry se puso en cola con éxito en ring. La función devolverá false si el valor de entry no se pudo poner en cola, lo que solo ocurre si ring estaba lleno.
