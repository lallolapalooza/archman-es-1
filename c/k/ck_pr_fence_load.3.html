NOMBRE

ck_pr_fence_load — impone el orden parcial de las operaciones de carga

BIBLIOTECA

Concurrency Kit (libck, -lck)

SINOPSIS

#include <ck_pr.h>

void
ck_pr_fence_load(void);

void
ck_pr_fence_strict_load(void);

DESCRIPCIÓN

Esta función impone el orden de cualquier carga de memoria y ck_pr_load(3) operaciones relativas a la invocación de la función. Cualquier operación de escritura que se haya confirmado en procesadores remotos y recibido por el procesador que llama antes de la invocación de ck_pr_fence_load() también se hará visible solo después de una llamada a ck_pr_fence_load(). Esta función siempre sirve como una barrera implícita del compilador. En arquitecturas con CK_MD_TSO o CK_MD_PSO especificados (orden total de escrituras y orden parcial de escrituras, respectivamente), esta operación solo sirve como una barrera del compilador y no se emitirán instrucciones de valla. Para forzar la emisión incondicional de una valla de carga, use ck_pr_fence_strict_load(). Las arquitecturas que implementan CK_MD_RMO siempre emiten una valla de carga.

EJEMPLO

#include <ck_pr.h>

static unsigned int a;
static unsigned int b;

void
function(void)
{
	unsigned int snapshot_a, snapshot_b;

	snapshot_a = ck_pr_load_uint(&a);

	/*
	 * Garantizar que la carga de "a" se complete
	 * antes de la carga de "b".
	 */
	ck_pr_fence_load();
	snapshot_b = ck_pr_load_uint(&b);

	return;
}

VALORES DE RETORNO

Esta función no tiene valor de retorno.
