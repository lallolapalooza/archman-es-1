Documentación de la función/subrutina

subrutina cqrt15 (entero scale, entero rksel, entero m, entero n, entero nrhs, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldb, * ) b, entero ldb, real, dimensión( * ) s, entero rank, real norma, real normb, entero, dimensión( 4 ) iseed, complejo, dimensión( lwork ) work, entero lwork)

CQRT15

Propósito:

!>
!> CQRT15 genera una matriz con rango completo o deficiente y de varias
!> normas.
!>

Parámetros

SCALE 
!>          SCALE es ENTERO
!>          SCALE = 1: matriz normalmente escalada
!>          SCALE = 2: matriz escalada hacia arriba
!>          SCALE = 3: matriz escalada hacia abajo
!>

RKSEL

!>          RKSEL es ENTERO
!>          RKSEL = 1: matriz de rango completo
!>          RKSEL = 2: matriz de rango deficiente
!>

M

!>          M es ENTERO
!>          El número de filas de la matriz A.
!>

N

!>          N es ENTERO
!>          El número de columnas de A.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de columnas de B.
!>

A

!>          A es array COMPLEJO, dimensión (LDA,N)
!>          La matriz A de M por N.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.
!>

B

!>          B es array COMPLEJO, dimensión (LDB, NRHS)
!>          Una matriz que está en el espacio de rango de la matriz A.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.
!>

S

!>          S es array REAL, dimensión MIN(M,N)
!>          Valores singulares de A.
!>

RANK

!>          RANK es ENTERO
!>          número de valores singulares distintos de cero de A.
!>

NORMA

!>          NORMA es REAL
!>          norma uno de A.
!>

NORMB

!>          NORMB es REAL
!>          norma uno de B.
!>

ISEED

!>          ISEED es array entero, dimensión (4)
!>          semilla para el generador de números aleatorios.
!>

WORK

!>          WORK es array COMPLEJO, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          longitud del espacio de trabajo requerido.
!>          LWORK >= MAX(M+MIN(M,N),NRHS*MIN(M,N),2*N+M)
!>
