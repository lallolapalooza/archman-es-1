función real cqrt12 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork)

CQRT12

Propósito:

!>
!> CQRT12 calcula los valores singulares `svlues' de la región trapezoidal superior
!> de A(1:M,1:N) y devuelve la relación
!>
!>      || svlues -s ||/( ||s||*eps*max(M,N) )
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.
!>

A

!>          A es un array COMPLEJO, de dimensiones (LDA,N)
!>          La matriz A de M por N. Solo se referencia la región trapezoidal superior.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.
!>

S

!>          S es un array REAL, de dimensiones (min(M,N))
!>          Los valores singulares de la matriz A.
!>

WORK

!>          WORK es un array COMPLEJO, de dimensiones (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud del array WORK. LWORK >= M*N + 2*min(M,N) +
!>          max(M,N).
!>

RWORK

!>          RWORK es un array REAL, de dimensiones (4*min(M,N))
!>
