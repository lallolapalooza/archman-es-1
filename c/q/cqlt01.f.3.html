CQLT01

Propósito:

!>
!> CQLT01 prueba CGEQLF, que calcula la factorización QL de una matriz m-por-n
!> A, y prueba parcialmente CUNGQL que forma la matriz ortogonal m-por-m
!> Q.
!>
!> CQLT01 compara L con Q'*A, y comprueba que Q es ortogonal.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          La matriz m-por-n A.
!>

AF

!>          AF es un array COMPLEX, dimensión (LDA,N)
!>          Detalles de la factorización QL de A, devueltos por CGEQLF.
!>          Ver CGEQLF para más detalles.
!>

Q

!>          Q es un array COMPLEX, dimensión (LDA,M)
!>          La matriz ortogonal m-por-m Q.
!>

L

!>          L es un array COMPLEX, dimensión (LDA,max(M,N))
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A, AF, Q y R.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU es un array COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales, como se
!>          devuelven por CGEQLF.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es un array REAL, dimensión (M)
!>

RESULT

!>          RESULT es un array REAL, dimensión (2)
!>          Las razones de prueba:
!>          RESULT(1) = norm( L - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
