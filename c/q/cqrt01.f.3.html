CQRT01

Propósito:

!>
!> CQRT01 prueba CGEQRF, que calcula la factorización QR de una matriz m-por-n
!> A, y prueba parcialmente CUNGQR que forma la matriz ortogonal m-por-m
!> Q.
!>
!> CQRT01 compara R con Q'*A, y verifica que Q es ortogonal.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          La matriz A de m-por-n.
!>

AF

!>          AF es un array COMPLEJO, dimensión (LDA,N)
!>          Detalles de la factorización QR de A, como la devuelve CGEQRF.
!>          Ver CGEQRF para más detalles.
!>

Q

!>          Q es un array COMPLEJO, dimensión (LDA,M)
!>          La matriz ortogonal Q de m-por-m.
!>

R

!>          R es un array COMPLEJO, dimensión (LDA,max(M,N))
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, Q y R.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU es un array COMPLEJO, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales, como los
!>          devuelve CGEQRF.
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es un array REAL, dimensión (M)
!>

RESULT

!>          RESULT es un array REAL, dimensión (2)
!>          Los ratios de prueba:
!>          RESULT(1) = norm( R - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
