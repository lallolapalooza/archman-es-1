Documentación de función/subrutina

subroutine cqrt03 (integer m, integer n, integer k, complex, dimension( lda, * ) af, complex, dimension( lda, * ) c, complex, dimension( lda, * ) cc, complex, dimension( lda, * ) q, integer lda, complex, dimension( * ) tau, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

CQRT03

Propósito:

!>
!> CQRT03 prueba CUNMQR, que calcula Q*C, Q'*C, C*Q o C*Q'.
!>
!> CQRT03 compara los resultados de una llamada a CUNMQR con los resultados de
!> formar Q explícitamente mediante una llamada a CUNGQR y luego realizar la
!> multiplicación de matrices mediante una llamada a CGEMM.
!>

Parámetros

M 
!>          M is INTEGER
!>          El orden de la matriz ortogonal Q.  M >= 0.
!>

N

!>          N is INTEGER
!>          El número de filas o columnas de la matriz C; C es m-por-n si
!>          Q se aplica desde la izquierda, o n-por-m si Q se aplica desde
!>          la derecha.  N >= 0.
!>

K

!>          K is INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz ortogonal Q.  M >= K >= 0.
!>

AF

!>          AF is COMPLEX array, dimension (LDA,N)
!>          Detalles de la factorización QR de una matriz m-por-n, como
!>          devuelve CGEQRF. Ver CGEQRF para más detalles.
!>

C

!>          C is COMPLEX array, dimension (LDA,N)
!>

CC

!>          CC is COMPLEX array, dimension (LDA,N)
!>

Q

!>          Q is COMPLEX array, dimension (LDA,M)
!>

LDA

!>          LDA is INTEGER
!>          La dimensión principal de los arrays AF, C, CC y Q.
!>

TAU

!>          TAU is COMPLEX array, dimension (min(M,N))
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización QR en AF.
!>

WORK

!>          WORK is COMPLEX array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          La longitud de WORK.  LWORK debe ser al menos M, y debería ser
!>          M*NB, donde NB es el tamaño del bloque para este entorno.
!>

RWORK

!>          RWORK is REAL array, dimension (M)
!>

RESULT

!>          RESULT is REAL array, dimension (4)
!>          Las razones de prueba comparan dos técnicas para multiplicar una
!>          matriz aleatoria C por una matriz ortogonal m-por-m Q.
!>          RESULT(1) = norm( Q*C - Q*C )  / ( M * norm(C) * EPS )
!>          RESULT(2) = norm( C*Q - C*Q )  / ( M * norm(C) * EPS )
!>          RESULT(3) = norm( Q'*C - Q'*C )/ ( M * norm(C) * EPS )
!>          RESULT(4) = norm( C*Q' - C*Q' )/ ( M * norm(C) * EPS )
!>
