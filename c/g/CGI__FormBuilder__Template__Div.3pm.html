NOMBRE

CGI::FormBuilder::Template::Div - Renderizado HTML de Div

SINOPSIS

my $form = CGI::FormBuilder->new;
$form->render;

DESCRIPCIÓN

Este módulo proporciona renderizado por defecto para FormBuilder. Es llamado automáticamente por el método render() de FormBuilder si no se especifica una plantilla externa. Ver la documentación en CGI::FormBuilder para más detalles.

VER TAMBIÉN

CGI::FormBuilder, CGI::FormBuilder::Template::HTML, CGI::FormBuilder::Template::Text, CGI::FormBuilder::Template::TT2, CGI::FormBuilder::Template::Fast, CGI::FormBuilder::Template::CGI_SSI
