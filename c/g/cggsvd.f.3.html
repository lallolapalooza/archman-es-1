CGGSVD calcula la descomposición en valores singulares (SVD) para matrices

OTHER

Propósito

: 
!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina CGGSVD3.
!>
!> CGGSVD calcula la descomposición generalizada en valores singulares (GSVD)
!> de una matriz compleja A de M por N y una matriz compleja B de P por N:
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices unitarias.
!> Sea K+L = el rango numérico efectivo de la
!> matriz (A**H,B**H)**H, entonces R es una matriz triangular superior
!> no singular de (K+L) por (K+L), D1 y D2 son matrices de M por (K+L) y P por (K+L)
!> y de las siguientes estructuras, respectivamente:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) en la salida.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) en la salida.
!>
!> La rutina calcula C, S, R, y opcionalmente las matrices de
!> transformación unitarias U, V y Q.
!>
!> En particular, si B es una matriz no singular de N por N, entonces la GSVD de
!> A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H tiene columnas ortonormales, entonces la GSVD de A y B es también
!> igual a la descomposición CS de A y B. Además, la GSVD puede
!> usarse para derivar la solución del problema de valores propios:
!>                      A**H*A x = lambda* B**H*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, y D1 y D2 son
!> ``diagonales''.  La forma anterior de la GSVD puede convertirse a la forma
!> posterior tomando la matriz no singular X como
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!
>

Q 
!>          JOBQ es CHARACTER*1

!>          = 'N':  No se calcula Q.

>

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.

>

P

!>          El número de filas de la matriz B.  P >= 0.
!
>

K 
!>          K es INTEGER
!
>

L 
!>          L es INTEGER
!>
!>          En la salida, K y L especifican la dimensión de los subbloques

!>          K + L = rango numérico efectivo de (A**H,B**H)**H.
!
>

A 
!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, A contiene la matriz triangular R, o parte de R.
!>          Vea Propósito para más detalles.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!
>

B 
!>          B es un arreglo COMPLEX, dimensión (LDB,N)
!>          En la entrada, la matriz B de P por N.
!>          En la salida, B contiene parte de la matriz triangular R si
!>          M-K-L < 0.  Vea Propósito para más detalles.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1,P).
!
>

ALPH

A 
!>          ALPHA es un arreglo REAL, dimensión (N)
!
>

BET

A 
!>          BETA es un arreglo REAL, dimensión (N)
!>
!>          En la salida, ALPHA y BETA contienen los pares de valores
!>          singulares generalizados de A y B;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          y si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = C,
!>            BETA(K+1:K+L)  = S,
!>          o si M-K-L < 0,
!>            ALPHA(K+1:M)=C, ALPHA(M+1:K+L)=0
!>            BETA(K+1:M) =S, BETA(M+1:K+L) =1
!>          y
!>            ALPHA(K+L+1:N) = 0
!>            BETA(K+L+1:N)  = 0
!
>

U 
!>          U es un arreglo COMPLEX, dimensión (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz unitaria U de M por M.
!>          Si JOBU = 'N', U no se referencia.
!
>

LD

U 
!>          LDU es INTEGER
!>          La dimensión principal del arreglo U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en otro caso.
!
>

V 
!>          V es un arreglo COMPLEX, dimensión (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz unitaria V de P por P.
!>          Si JOBV = 'N', V no se referencia.
!
>

LD

V 
!>          LDV es INTEGER
!>          La dimensión principal del arreglo V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en otro caso.
!
>

Q 
!>          Q es un arreglo COMPLEX, dimensión (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz unitaria Q de N por N.
!>          Si JOBQ = 'N', Q no se referencia.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del arreglo Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en otro caso.
!
>

WORK> 

!>          WORK es un arreglo COMPLEJO, dimensión (max(3*N,M,P)+N)
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (2*N)
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (N)
!>          Al salir, IWORK almacena la información de ordenación. Más
!>          precisamente, el siguiente bucle ordenará ALPHA
!>             for I = K+1, min(M,K+L)

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.

!>                converger. Para más detalles, ver el subrutina CTGSJA.
!
>

Parámetros

internos: 
!>  TOLA    REAL
!>  TOLB    REAL
!>          TOLA y TOLB son los umbrales para determinar el rango efectivo
!>          de (A**H,B**H)**H. Generalmente, se establecen como
!>                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El tamaño de TOLA y TOLB puede afectar el tamaño de los errores
!>          hacia atrás de la descomposición.
!
