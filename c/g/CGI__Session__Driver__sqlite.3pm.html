NOMBRE

CGI::Session::Driver::sqlite - Driver de CGI::Session para SQLite

SINOPSIS

$s = CGI::Session->new("driver:sqlite", $sid, {DataSource=>'/mi/carpeta/sessions.sqlt'});
$s = CGI::Session->new("driver:sqlite", $sid, {Handle=>$dbh});

o

$s = CGI::Session->new('driver:sqlite', undef,
{
    TableName=>'sesion',
    IdColName=>'mi_id',
    DataColName=>'mis_datos',
    Handle=>$dbh,
});

DESCRIPCIÓN

El driver sqlite almacena datos de sesión en archivos SQLite utilizando el driver DBI de DBD::SQLite. Para más detalles, consulta CGI::Session::Driver::DBI, su clase padre.

ARGUMENTOS DEL DRIVER

Los argumentos del driver soportados son DataSource y Handle. **Como máximo**, solo uno de estos argumentos puede ser establecido al crear el objeto de sesión.

DataSource debe tener el formato "dbi:SQLite:dbname=/ruta/a/db.sqlt". Si "dbi:SQLite:" falta, se añadirá por ti. Si Handle está presente, debe ser un manejador de base de datos ($dbh) devuelto por DBI::connect().

A partir de la versión 1.7 de este driver, el tercer argumento **NO** es opcional. Usar una base de datos predeterminada en el directorio temporal es un riesgo de seguridad, ya que cualquier persona en la máquina puede crear y/o leer tus datos de sesión. Si entiendes estos riesgos y aún quieres el comportamiento anterior, puedes establecer la opción "DataSource" a '/tmp/sessions.sqlt'.

ERRORES Y LIMITACIONES

Ninguno conocido.

LICENCIA

Para soporte y licencias, consulta CGI::Session
