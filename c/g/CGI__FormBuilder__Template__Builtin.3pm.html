NOMBRE

CGI::FormBuilder::Template::Builtin - Renderizado HTML incorporado

SINOPSIS

my $form = CGI::FormBuilder->new;
$form->render;

DESCRIPCIÓN

Este módulo proporciona renderizado por defecto para FormBuilder. Se llama automáticamente desde el método render() de FormBuilder si no se especifica una plantilla externa. Consulte la documentación en CGI::FormBuilder para más detalles.

VER TAMBIÉN

CGI::FormBuilder, CGI::FormBuilder::Template::HTML, CGI::FormBuilder::Template::Text, CGI::FormBuilder::Template::TT2, CGI::FormBuilder::Template::Fast, CGI::FormBuilder::Template::CGI_SSI
