CGI::FormBuilder::Template(3) Documentación de Perl aportada por el usuario CGI::FormBuilder::Template(3)

NOMBRE

CGI::FormBuilder::Template - Adaptadores de plantilla para FormBuilder

SINOPSIS

# Define a template engine
package CGI::FormBuilder::Template::Whatever;
use base 'Whatever::Template::Module';
sub new {
    my $self  = shift;
    my $class = ref($self) || $self;
    my %opt   = @_;
    # override some options
    $opt{some_setting} = 0;
    $opt{another_var}  = 'Some Value';
    # instantiate the template engine
    $opt{engine} = Whatever::Template::Module->new(%opt);
    return bless \%opt, $class;
}
sub render {
    my $self = shift;
    my $form = shift;   # only arg is form object
    # grab any manually-set template params
    my %tmplvar = $form->tmpl_param;
    # example template manipulation
    my $html = $self->{engine}->do_template(%tmplvar);
    return $html;       # scalar HTML is returned
}

DESCRIPCIÓN

Esta documentación describe el uso de las plantillas de FormBuilder , así como cómo escribir su propio adaptador de plantilla.

Los motores de plantilla sirven como adaptadores entre los módulos de plantilla de CPAN y FormBuilder. Un motor de plantilla se invoca utilizando la opción "template" en el método de nivel superior new() :

my $form = CGI::FormBuilder->new(
                template => 'filename.tmpl'
           );

Este ejemplo apunta a un nombre de archivo que contiene una plantilla compatible con "HTML::Template" para usar al maquetar el HTML. También puede especificar la opción "template" como una referencia a un hash, lo que le permite personalizar aún más las opciones de procesamiento de plantillas o usar otros motores de plantilla.

Por ejemplo, podría activar el almacenamiento en caché en "HTML::Template" con algo como lo siguiente:

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                template => {
                    filename => 'form.tmpl',
                    shared_cache => 1
                }
           );

Como se mencionó, especificar una referencia a un hash le permite usar un sistema de procesamiento de plantillas alternativo como "Template Toolkit". Una configuración mínima se vería así:

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                template => {
                    type => 'TT2',      # use Template Toolkit
                    template => 'form.tmpl',
                },
           );

La opción "type" especifica el nombre del motor. Los tipos aceptados actualmente son:

Builtin -  Incluido, representación predeterminada si no se especifica una plantilla
Div     -  Representar el formulario usando <div> (sin tablas)
HTML    -  HTML::Template
Text    -  Text::Template
TT2     -  Template Toolkit
Fast    -  CGI::FastTemplate
CGI_SSI -  CGI::SSI

Además de uno de estos tipos, también puede especificar un nombre de paquete completo, en cuyo caso ese módulo se cargará automáticamente y se usarán sus rutinas new() y render() . Por ejemplo:

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                template => {
                    type => 'My::Template::Module',
                    template => 'form.tmpl',
                },
           );

Todas las demás opciones además de "type" se pasan al constructor de ese sistema de plantillas de forma literal, por lo que deberá consultar esa documentación para ver qué hacen todas las diferentes opciones. Vaya directamente a "VER TAMBIÉN".

HERENCIA DE ADAPTADORES DE PLANTILLA

Además de los motores de plantilla incluidos anteriormente, también es posible escribir su propio módulo de representación. Si se le ocurre algo genial, ¡por favor, avíselo a la lista de correo!

Para hacerlo, necesita escribir un módulo que tenga una subrutina llamada render(). Esta subrutina será llamada por FormBuilder cuando se llame a "$form->render" . Esta subrutina puede hacer básicamente lo que quiera, lo único que tiene que hacer es devolver una cadena escalar que sea el HTML a imprimir.

En realidad, esto no es difícil. Aquí hay un adaptador simple que manipularía una plantilla al estilo de "HTML::Template" :

# This file is My/HTML/Template.pm
package My::HTML::Template;
use CGI::FormBuilder::Template::HTML;
use base 'CGI::FormBuilder::Template::HTML';
sub render {
    my $self = shift;    # class object
    my $form = shift;    # $form as only argument
    # the template object (engine) lives here
    my $tmpl = $self->engine;
    # setup vars for our fields (objects)
    for ($form->field) {
        $tmpl->param($_ => $_->value);
    }
    # render output
    my $html = $tmpl->output;
    # return scalar;
    return $html;
}
1;  # close module

Luego en FormBuilder:

use CGI::FormBuilder;
use My::HTML::Template;   # your module
my $tmpl = My::HTML::Template->new;
my $form = CGI::FormBuilder->new(
                fields   => [qw(name email)],
                header   => 1,
                template => $tmpl   # pass template object
           );
# set our company from an extra CGI param
my $co = $form->cgi_param('company');
$tmpl->engine->param(company => $co);
# and render like normal
print $form->render;

¡Eso es todo! Para más detalles, lo mejor es que mire a través de las entrañas de uno de los motores de plantilla existentes y parta de ahí.
