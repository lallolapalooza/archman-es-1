subrutina cgerfs (carácter trans, entero n, entero nrhs, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, complejo, dimensión( ldb, * ) b, entero ldb, complejo, dimensión( ldx, * ) x, entero ldx, real, dimensión( * ) ferr, real, dimensión( * ) berr, complejo, dimensión( * ) work, real, dimensión( * ) rwork, entero info)

CGERFS

Propósito:

!>
!> CGERFS mejora la solución calculada de un sistema de ecuaciones lineales
!> y proporciona cotas de error y estimaciones de error residual para
!> la solución.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          La matriz original A de N por N.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX, dimensión (LDAF,N)
!>          Los factores L y U de la factorización A = P*L*U
!>          calculada por CGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote de CGETRF; para 1<=i<=N, la fila i de la
!>          matriz fue intercambiada con la fila IPIV(i).
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, calculada por CGETRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array REAL, dimensión (NRHS)
!>          La cota de error residual estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada de la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividida por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación de RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>          El error residual relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
