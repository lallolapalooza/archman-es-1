NOMBRE

CGI::Session::Test::Default - Ejecutar un conjunto de pruebas para un controlador CGI::Session dado

new()

my $t = CGI::Session::Test::Default->new(
    # Estos son opcionales, con los siguientes valores por defecto
    dsn   => "driver:file",
    args  => undef,
    tests => 77,
);

Crea un nuevo objeto de prueba, posiblemente anulando algunas opciones por defecto.

number_of_tests()

my $new_num = $t->number_of_tests($new_num);

Un método modificador/accesor para afectar al número de pruebas a ejecutar, después de haber llamado a new() y antes de llamar a run().

run()

$t->run();

Ejecuta el conjunto de pruebas. Ver new() para configurar opciones relacionadas.
