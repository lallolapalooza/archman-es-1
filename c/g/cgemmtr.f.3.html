Documentación de Función/Subrutina

subrutina cgemmtr (character uplo, character transa, character transb, integer n, integer k, complex alpha, complex, dimension(lda,*) a, integer lda, complex, dimension(ldb,*) b, integer ldb, complex beta, complex, dimension(ldc,*) c, integer ldc)

CGEMMTR

Propósito:

!>
!> CGEMMTR  realiza una de las operaciones de matriz-matriz
!>
!>    C := alpha*op( A )*op( B ) + beta*C,
!>
!> donde  op( X ) es una de:
!>
!>    op( X ) = X   o   op( X ) = X**T,
!>
!> alpha y beta son escalares, y A, B y C son matrices, con op( A )
!> siendo una matriz n por k,  op( B )  una matriz  k por n y  C una matriz n por n.
!> Por lo tanto, la rutina solo accede y actualiza la parte triangular superior o inferior
!> de la matriz resultante C. Este comportamiento puede usarse si
!> se sabe que la matriz resultante C es hermitiana o simétrica.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si se accede y actualiza la parte
!>           triangular inferior o superior de C.
!>
!>              UPLO = 'L' o 'l', se utiliza la parte triangular inferior de C.
!>
!>              UPLO = 'U' o 'u', se utiliza la parte triangular superior de C.
!>

TRANSA

!>          TRANSA es CHARACTER*1
!>           En la entrada, TRANSA especifica la forma de op( A ) a utilizar en
!>           la multiplicación de matrices de la siguiente manera:
!>
!>              TRANSA = 'N' o 'n',  op( A ) = A.
!>
!>              TRANSA = 'T' o 't',  op( A ) = A**T.
!>
!>              TRANSA = 'C' o 'c',  op( A ) = A**H.
!>

TRANSB

!>          TRANSB es CHARACTER*1
!>           En la entrada, TRANSB especifica la forma de op( B ) a utilizar en
!>           la multiplicación de matrices de la siguiente manera:
!>
!>              TRANSB = 'N' o 'n',  op( B ) = B.
!>
!>              TRANSB = 'T' o 't',  op( B ) = B**T.
!>
!>              TRANSB = 'C' o 'c',  op( B ) = B**H.
!>

N

!>          N es INTEGER
!>           En la entrada,  N especifica el número de filas y columnas de
!>           la matriz C, el número de columnas de op(B) y el número
!>           de filas de op(A).  N debe ser al menos cero.
!>

K

!>          K es INTEGER
!>           En la entrada,  K  especifica  el número de columnas de la matriz
!>           op( A ) y el número de filas de la matriz op( B ). K debe
!>           ser al menos  cero.
!>

ALPHA

!>          ALPHA es COMPLEX.
!>           En la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX, de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANSA = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con  TRANSA = 'N' o 'n',  la parte principal n por k
!>           del array  A  debe contener la matriz  A,  en caso contrario
!>           la parte principal  k por m  del array  A  debe contener  la
!>           matriz A.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como se declaró
!>           en el programa (sub)llamador. Cuando  TRANSA = 'N' o 'n' entonces
!>           LDA debe ser al menos  max( 1, n ), en caso contrario  LDA debe ser
!>           al menos  max( 1, k ).
!>

B

!>          B es un array COMPLEX, de dimensión ( LDB, kb ), donde kb es
!>           n  cuando  TRANSB = 'N' o 'n',  y es  k  en caso contrario.
!>           Antes de la entrada con  TRANSB = 'N' o 'n',  la parte principal k por n
!>           del array  B  debe contener la matriz  B,  en caso contrario
!>           la parte principal  n por k  del array  B  debe contener  la
!>           matriz B.
!>

LDB

!>          LDB es INTEGER
!>           En la entrada, LDB especifica la primera dimensión de B tal como se declaró
!>           en el programa (sub)llamador. Cuando  TRANSB = 'N' o 'n' entonces
!>           LDB debe ser al menos  max( 1, k ), en caso contrario  LDB debe ser
!>           al menos  max( 1, n ).
!>

BETA

!>          BETA es COMPLEX.
!>           En la entrada,  BETA  especifica el escalar  beta.  Cuando  BETA  se
!>           proporciona como cero, C no necesita estar configurado en la entrada.
!>

C

!>          C es un array COMPLEX, de dimensión ( LDC, N )
!>           Antes de la entrada, la parte principal n por n de la matriz
!>           C  debe contener la matriz  C,  excepto cuando  beta  es cero, en cuyo
!>           caso C no necesita estar configurado en la entrada.
!>           En la salida, la parte triangular superior o inferior de la matriz
!>           C  se sobrescribe con la matriz n por n
!>           ( alpha*op( A )*op( B ) + beta*C ).
!>

LDC

!>          LDC es INTEGER
!>           En la entrada, LDC especifica la primera dimensión de C tal como se declaró
!>           en el programa (sub)llamador.   LDC  debe ser  al menos
!>           max( 1, n ).
!>
