CGI::Session::Serialize::storable(3) Documentación de Perl contribuida por el usuario CGI::Session::Serialize::storable(3)

NOMBRE

CGI::Session::Serialize::storable - Serializador para CGI::Session

DESCRIPCIÓN

Esta biblioteca puede ser utilizada por CGI::Session para serializar datos de sesión. Utiliza Storable.

MÉTODOS

freeze($clase, \%hash)
Recibe dos argumentos. El primero es el nombre de la clase, el segundo son los datos a serializar. Debería devolver una cadena serializada en caso de éxito, undef en caso de fallo. El mensaje de error debe establecerse usando "set_error()|CGI::Session::ErrorHandler/"set_error()""
thaw($clase, $cadena)
Recibe dos argumentos. El primero es el nombre de la clase, el segundo es la cadena de datos congelados. Debería devolver la estructura de datos descongelada en caso de éxito, undef en caso de fallo. El mensaje de error debe establecerse usando "set_error()|CGI::Session::ErrorHandler/"set_error()""

LICENCIA
