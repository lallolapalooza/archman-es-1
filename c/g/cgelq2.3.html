Documentación de función/subrutina

subrutina cgelq2 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CGELQ2 calcula la factorización LQ de una matriz rectangular general utilizando un algoritmo sin bloques.

Propósito:

!>
!> CGELQ2 calcula una factorización LQ de una matriz A m-por-n compleja:
!>
!>    A = ( L 0 ) *  Q
!>
!> donde:
!>
!>    Q es una matriz unitaria n-por-n;
!>    L es una matriz triangular inferior m-por-m;
!>    0 es una matriz cero m-por-(n-m), si m < n.
!>
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>          En la entrada, la matriz A m por n.
!>          En la salida, los elementos en y por debajo de la diagonal del
!>          array contienen la matriz trapezoidal inferior L m-por-min(m,n)
!>          (L es triangular inferior si m <= n); los elementos por
!>          encima de la diagonal, junto con el array TAU, representan la
!>          matriz unitaria Q como producto de reflectores elementales (ver
!>          Más detalles).
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEJO, de dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales (ver Más
!>          detalles).
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (M)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Autor

Univ. de Tennessee

Univ. de California Berkeley

Univ. de Colorado Denver

NAG Ltd.

Más detalles:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(k)**H . . . H(2)**H H(1)**H, donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i-1) = 0 y v(i) = 1; conjg(v(i+1:n)) se almacena en la salida en
!>  A(i,i+1:n), y tau en TAU(i).
!>
