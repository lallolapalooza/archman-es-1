subrutina cget38 (real, dimension( 3 ) rmax, integer, dimension( 3 ) lmax, integer, dimension( 3 ) ninfo, integer knt, integer nin)

CGET38

Propósito:

!>
!> CGET38 prueba CTRSEN, una rutina para estimar números de condición de un
!> clúster de valores propios y/o su subespacio invariante derecho asociado
!>
!> Las matrices de prueba se leen de un archivo con el número de unidad lógica NIN.
!>

Parámetros

RMAX 
!>          RMAX es un array REAL, de dimensión (3)
!>          Valores de los ratios de prueba más grandes.
!>          RMAX(1) = residuos más grandes de CHST01 o comparando
!>                    llamadas diferentes a CTRSEN
!>          RMAX(2) = error más grande en la condición recíproca
!>                    de los números teniendo en cuenta su condición
!>          RMAX(3) = error más grande en la condición recíproca
!>                    de los números sin tener en cuenta su condición
!>                    (puede ser mayor que RMAX(2))
!>

LMAX

!>          LMAX es un array INTEGER, de dimensión (3)
!>          LMAX(i) es el número de ejemplo donde se logra el ratio de prueba más grande
!>          RMAX(i). También:
!>          Si CGEHRD devuelve INFO no nulo en el ejemplo i, LMAX(1)=i
!>          Si CHSEQR devuelve INFO no nulo en el ejemplo i, LMAX(2)=i
!>          Si CTRSEN devuelve INFO no nulo en el ejemplo i, LMAX(3)=i
!>

NINFO

!>          NINFO es un array INTEGER, de dimensión (3)
!>          NINFO(1) = Nº de veces que CGEHRD devolvió INFO no nulo
!>          NINFO(2) = Nº de veces que CHSEQR devolvió INFO no nulo
!>          NINFO(3) = Nº de veces que CTRSEN devolvió INFO no nulo
!>

KNT

!>          KNT es INTEGER
!>          Número total de ejemplos probados.
!>

NIN

!>          NIN es INTEGER
!>          Número de unidad lógica de entrada.
!>
