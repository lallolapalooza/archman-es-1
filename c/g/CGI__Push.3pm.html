DESCRIPCIÓ

N

CGI::Push es una subclase del objeto CGI creado por CGI.pm. Está especializada en operaciones de servidor push, que le permiten crear páginas animadas cuyo contenido cambia a intervalos

regulares.

Usted proporciona a CGI::Push un puntero a una subrutina que dibujará una página. Cada vez que se llama a su subrutina, genera una nueva página. El contenido de la página se transmitirá al navegador de tal manera que reemplazará lo que había allí previamente. La técnica funcionará con páginas HTML así como con archivos gráficos, permitiéndole crear GIFs

animados.

Solo Netscape Navigator soport

a el servidor push. Los navegad
ores Internet Explorer no.

USANDO CGI::

Push

CGI::Push añade un nuevo método al conjunto estándar de CGI, do_push(). Cuando llama a este método, le pasa una referencia a una subrutina que es responsable de dibujar cada nueva página, un retardo de intervalo, y una subrutina opcional para dibujar la última página. Otros parámetros opcionales incluyen la mayoría de los reconocidos por el método header() de

CGI.

Puede llamar a do_push() de manera orientada a objetos o no, como

prefiera: 
use CGI::Push;
$q = CGI::Push->new;
$q->do_push(-next_page=>\&draw_a_page);
    -o-
use CGI::Push qw(:standard);
do_push(-next_page=>\&draw_a_page)
;

Este parámetro requerido apunta a una referencia a una subrutina responsable de dibujar cada nueva página. La subrutina debe esperar dos parámetros que consisten en el objeto CGI y un contador que indica el número de veces que la subrutina ha sido llamada. Debe devolver el contenido de la página como un array de uno o más elementos a imprimir. Puede devolver un valor falso (o un array vacío) para abortar el bucle de redibujado e imprimir la página final

(si la hay)

Páginas

Heterogéneas

Ordinariamente, todas las páginas mostradas por CGI::Push comparten un tipo MIME común. Sin embargo, proporcionando un valor de "heterogeneous" o "dynamic" en el parámetro -type de do_push(), puede especificar el tipo MIME de cada página caso por

caso.

Si usa esta opción, usted será responsable de producir el encabezado HTTP para cada página. Simplemente modifique su rutina de dibujo para que se vea

así: 
sub my_draw_routine {
    my($q,$counter) = @_;
    return header('text/html'),   # note we're producing the header here
    ....
}

Puede añadir cualquier campo de encabezado que desee, pero algunos (cookies y campos de estado incluidos) pueden no ser interpretados por el navegador. Un efecto interesante es mostrar una serie de páginas, luego, después de la última página, redirigir el navegador a una nueva URL. Debido a que redirect() no funciona, la forma más fácil es con un campo de encabezado -refresh, como se muestra

abajo: 
sub my_draw_routine {
    my($q,$counter) = @_;
    return undef if $counter > 10;
    return header('text/html'),   # note we're producing the header here
    ...
}
sub my_last_page {
    return header(-refresh=>'5; URL=http://somewhere.else/finished.html',
                  -type=>'text/html'),
    ...
}

Cambiando el Retardo de Página sobre la

Marcha

Si le gustaría controlar el retardo entre páginas página por página, llame a push_delay() desde dentro de su rutina de dibujo. push_delay() toma un único argumento numérico que representa el número de segundos que desea retrasar después de que la página actual se muestre y antes de mostrar la siguiente. El retardo puede ser fraccional. Sin parámetros, push_delay() simpleme

INSTALANDO GUIONES CGI::

Push

Los guiones de servidor push deben instalarse como guiones de encabezado sin análisis (NPH) para funcionar correctamente en muchos servidores. En sistemas Unix, esto se logra más a menudo prefijando el nombre del guión con "nph-". El reconocimiento de guiones NPH ocurre automáticamente con WebSTAR y Microsoft IIS. Los usuarios de otros servidores deben ver su documentación para

ayuda.

El servidor web Apache desde la versión 1.3b2 en adelante no necesita que los guiones de servidor push se instalen como guiones NPH: el parámetro -nph para do_push() puede establecerse a un valor falso para deshab

ilitar los encabezados extra ne
cesarios por un guión NPH.
