CGESDD

Documentación de Función/Subrutin

a

subrutina cgesdd (character jobz, integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( ldvt, * ) vt, integer ldvt, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer

info)

CGESD

D

Propósito

: 
!>
!> CGESDD calcula la descomposición en valores singulares (SVD) de una matriz compleja A de M por N, calculando opcionalmente los vectores singulares izquierdo y/o derecho, mediante el método de divide y vencerás. La SVD se escribe
!>
!>      A = U * SIGMA * conjugado-transpuesta(V)
!>
!> donde SIGMA es una matriz de M por N que es cero excepto por sus min(m,n) elementos diagonales, U es una matriz unitaria de M por M, y V es una matriz unitaria de N por N. Los elementos diagonales de SIGMA son los valores singulares de A; son reales y no negativos, y se devuelven en orden descendente. Las primeras min(m,n) columnas de U y V son los vectores singulares izquierdo y derecho de A.
!>
!> Tenga en cuenta que la rutina devuelve VT = V**H, no V.
!>
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          Especifica opciones para calcular toda o parte de la matriz U:
!>          = 'A':  se devuelven en los arrays U y VT todas las M columnas de U y todas las N filas de V**H;
!>          = 'S':  se devuelven en los arrays U y VT las primeras min(M,N) columnas de U y las primeras min(M,N) filas de V**H;
!>          = 'O':  Si M >= N, las primeras N columnas de U se sobrescriben en el array A y todas las filas de V**H se devuelven en el array VT;
!>                  de lo contrario, todas las columnas de U se devuelven en el array U y las primeras M filas de V**H se sobrescriben en el array A;
!>          = 'N':  no se calculan columnas de U ni filas de V**H.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida,
!>          si JOBZ = 'O',  A se sobrescribe con las primeras N columnas
!>                          de U (los vectores singulares izquierdos, almacenados
!>                          por columnas) si M >= N;
!>                          A se sobrescribe con las primeras M filas
!>                          de V**H (los vectores singulares derechos, almacenados
!>                          por filas) en caso contrario.
!>          si JOBZ .ne. 'O', el contenido de A se destruye.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!
>

S 
!>          S es un array REAL, dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!
>

U 
!>          U es un array COMPLEX, dimensión (LDU,UCOL)
!>          UCOL = M si JOBZ = 'A' o JOBZ = 'O' y M < N;
!>          UCOL = min(M,N) si JOBZ = 'S'.
!>          Si JOBZ = 'A' o JOBZ = 'O' y M < N, U contiene la matriz unitaria U de M por M;
!>          si JOBZ = 'S', U contiene las primeras min(M,N) columnas de U
!>          (los vectores singulares izquierdos, almacenados por columnas);
!>          si JOBZ = 'O' y M >= N, o JOBZ = 'N', U no se referencia.
!
>

LD

U 
!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1;
!>          si JOBZ = 'S' o 'A' o JOBZ = 'O' y M < N, LDU >= M.
!
>

V

T 
!>          VT es un array COMPLEX, dimensión (LDVT,N)
!>          Si JOBZ = 'A' o JOBZ = 'O' y M >= N, VT contiene la matriz unitaria V**H de N por N;
!>          si JOBZ = 'S', VT contiene las primeras min(M,N) filas de
!>          V**H (los vectores singulares derechos, almacenados por filas);
!>          si JOBZ = 'O' y M < N, o JOBZ = 'N', VT no se referencia.
!
>

LDV

T 
!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1;
!>          si JOBZ = 'A' o JOBZ = 'O' y M >= N, LDVT >= N;
!>          si JOBZ = 'S', LDVT >= min(M,N).
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo. El tamaño óptimo para el array WORK se calcula y se almacena en WORK(1), y no se realiza ningún otro trabajo excepto la comprobación de argumentos.
!>
!>          Sea mx = max(M,N) y mn = min(M,N).
!>          Si JOBZ = 'N', LWORK >= 2*mn + mx.
!>          Si JOBZ = 'O', LWORK >= 2*mn*mn + 2*mn + mx.
!>          Si JOBZ = 'S', LWORK >=   mn*mn + 3*mn.
!>          Si JOBZ = 'A', LWORK >=   mn*mn + 2*mn + mx.
!>          Estos no son mínimos ajustados en todos los casos; consulte los comentarios dentro del código.
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor; se recomienda una consulta.
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (MAX(1,LRWORK))
!>          Sea mx = max(M,N) y mn = min(M,N).
!>          Si JOBZ = 'N',    LRWORK >= 5*mn (LAPACK <= 3.6 necesita 7*mn);
!>          de lo contrario si mx >> mn, LRWORK >= 5*mn*mn + 5*mn;
!>          de lo contrario              LRWORK >= max( 5*mn*mn + 5*mn,
!>                                           2*mx*mn + 2*mn*mn + mn ).
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (8*min(M,N))
!
>

INF

O 
!>          INFO es INTEGER
!>          <  0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = -4:  si A tenía una entrada NAN.
!>          >  0:  El proceso de actualización de SBDSDC no convergió.
!>          =  0:  salida exitosa.
!
>
