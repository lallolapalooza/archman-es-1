subrutina cgeevx (character balanc, character jobvl, character jobvr, character sense, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) w, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, integer ilo, integer ihi, real, dimension( * ) scale, real abnrm, real, dimension( * ) rconde, real, dimension( * ) rcondv, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CGEEVX calcula los valores propios, y opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> CGEEVX calcula para una matriz compleja no simétrica N por N, A, los
!> valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos.
!>
!> Opcionalmente también, calcula una transformación de balanceo para mejorar
!> el condicionamiento de los valores y vectores propios (ILO, IHI,
!> SCALE y ABNRM), los recíprocos de los números de condición de los
!> valores propios (RCONDE) y los recíprocos de los números de condición de los
!> vectores propios derechos (RCONDV).
!>
!> El vector propio derecho v(j) de A satisface
!>                  A * v(j) = lambda(j) * v(j)
!> donde lambda(j) es su valor propio.
!> El vector propio izquierdo u(j) de A satisface
!>               u(j)**H * A = lambda(j) * u(j)**H
!> donde u(j)**H denota la transpuesta conjugada de u(j).
!>
!> Los vectores propios calculados se normalizan para tener norma Euclidiana
!> igual a 1 y el componente real más grande.
!>
!> El balanceo de una matriz significa permutar las filas y columnas para hacerla
!> más cercana a ser triangular superior, y aplicar una transformación de
!> similitud diagonal D * A * D**(-1), donde D es una matriz diagonal, para
!> hacer que sus filas y columnas tengan normas más cercanas y los números de
!> condición de sus valores y vectores propios sean menores. Los recíprocos
!> de los números de condición calculados corresponden a la matriz balanceada.
!> Las permutaciones de filas y columnas no cambiarán los números de condición
!> (en aritmética exacta), pero el escalado diagonal sí. Para una explicación
!> adicional del balanceo, véase la sección 4.10.2 de la Guía del Usuario de LAPACK.
!>

Parámetros

BALANC 
!>          BALANC es CHARACTER*1
!>          Indica cómo la matriz de entrada debe ser escalada diagonalmente
!>          y/o permutada para mejorar el condicionamiento de sus
!>          valores propios.
!>          = 'N': No escalar ni permutar diagonalmente;
!>          = 'P': Realizar permutaciones para hacer la matriz más cercana a
!>                 ser triangular superior. No escalar diagonalmente;
!>          = 'S': Escalar diagonalmente la matriz, es decir, reemplazar A por
!>                 D*A*D**(-1), donde D es una matriz diagonal elegida
!>                 para hacer que las filas y columnas de A tengan normas más
!>                 iguales. No permutar;
!>          = 'B': Escalar diagonalmente y permutar A.
!>
!>          Los recíprocos de los números de condición calculados serán para la matriz
!>          después del balanceo y/o permutación. Las permutaciones no cambian
!>          los números de condición (en aritmética exacta), pero el balanceo sí.
!>

JOBVL

!>          JOBVL es CHARACTER*1
!>          = 'N': los vectores propios izquierdos de A no se calculan;
!>          = 'V': los vectores propios izquierdos de A se calculan.
!>          Si SENSE = 'E' o 'B', JOBVL debe ser = 'V'.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N': los vectores propios derechos de A no se calculan;
!>          = 'V': los vectores propios derechos de A se calculan.
!>          Si SENSE = 'E' o 'B', JOBVR debe ser = 'V'.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué recíprocos de números de condición se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Se calculan solo para valores propios;
!>          = 'V': Se calculan solo para vectores propios derechos;
!>          = 'B': Se calculan para valores propios y vectores propios derechos.
!>
!>          Si SENSE = 'E' o 'B', también deben calcularse los vectores propios
!>          izquierdos y derechos (JOBVL = 'V' y JOBVR = 'V').
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la matriz N por N, A.
!>          En la salida, A ha sido sobrescrita. Si JOBVL = 'V' o
!>          JOBVR = 'V', A contiene la forma de Schur de la versión
!>          balanceada de la matriz A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

W

!>          W es un array COMPLEX, de dimensión (N)
!>          W contiene los valores propios calculados.
!>

VL

!>          VL es un array COMPLEX, de dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios izquierdos u(j) se almacenan uno
!>          tras otro en las columnas de VL, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVL = 'N', VL no se utiliza.
!>          u(j) = VL(:,j), la j-ésima columna de VL.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX, de dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios derechos v(j) se almacenan uno
!>          tras otro en las columnas de VR, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVR = 'N', VR no se utiliza.
!>          v(j) = VR(:,j), la j-ésima columna de VR.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1; si
!>          JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI son valores enteros determinados cuando A fue
!>          balanceada. La A(i,j) balanceada = 0 si I > J y
!>          J = 1,...,ILO-1 o I = IHI+1,...,N.
!>

SCALE

!>          SCALE es un array REAL, de dimensión (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al balancear A. Si P(j) es el índice de la fila y columna
!>          intercambiada con la fila y columna j, y D(j) es el factor de
!>          escala aplicado a la fila y columna j, entonces
!>          SCALE(J) = P(J),    para J = 1,...,ILO-1
!>                   = D(J),    para J = ILO,...,IHI
!>                   = P(J)     para J = IHI+1,...,N.
!>          El orden en que se realizan los intercambios es de N a IHI+1,
!>          luego de 1 a ILO-1.
!>

ABNRM

!>          ABNRM es REAL
!>          La norma uno de la matriz balanceada (el máximo
!>          de la suma de los valores absolutos de los elementos de cualquier columna).
!>

RCONDE

!>          RCONDE es un array REAL, de dimensión (N)
!>          RCONDE(j) es el recíproco del número de condición del j-ésimo
!>          valor propio.
!>

RCONDV

!>          RCONDV es un array REAL, de dimensión (N)
!>          RCONDV(j) es el recíproco del número de condición del j-ésimo
!>          vector propio derecho.
!>

WORK

!>          WORK es COMPLEX
array, dimension (MAX(1,LWORK)) !> Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo. !>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.  Si SENSE = 'N' o 'E',
!>          LWORK >= max(1,2*N), y si SENSE = 'V' o 'B',
!>          LWORK >= N*N+2*N.
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (2*N)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo QR no pudo calcular todos los
!>                eigenvalores, y no se han calculado autovectores ni números de
!>                condición; los elementos 1:ILO-1 y i+1:N de W
!>                contienen eigenvalores que han convergido.
!>
