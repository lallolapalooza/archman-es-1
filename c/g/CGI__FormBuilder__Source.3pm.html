NOMBRE

CGI::FormBuilder::Source - Adaptadores de fuente para FormBuilder

SINOPSIS

# Definir un adaptador de fuente
package CGI::FormBuilder::Source::Whatever;
sub new {
    my $self  = shift;
    my $class = ref($self) || $self;
    my %opt   = @_;
    return bless \%opt, $class;
}
sub parse {
    my $self = shift;
    my $file = shift || $self->{source};
    # abrir el archivo y analizarlo, o lo que sea
    my %formopt;
    open(F, "<$file") || die "No se puede leer $file: $!";
    while (<F>) {
        # ... hacer algo con la línea ...
        $formopt{$fb_option} = $fb_value;
    }
    # devolver hash de opciones de $form
    return wantarray ? %formopt : \%formopt;
}

DESCRIPCIÓN

Esta documentación describe el uso de las fuentes de FormBuilder, así como cómo escribir su propio adaptador de fuente.

Una fuente externa se invoca utilizando la opción "source" para el método de nivel superior new():

my $form = CGI::FormBuilder->new(
                source => 'archivo_fuente.conf'
           );

Este ejemplo apunta a un nombre de archivo que contiene un archivo siguiendo el diseño de "CGI::FormBuilder::Source::File". Al igual que con la opción "template", también puede especificar "source" como una referencia a un hash, lo que le permite utilizar otros adaptadores de fuente:

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                source => {
                    type => 'File',
                    source => '/ruta/a/fuente.conf',
                }
           );

La opción "type" especifica el nombre del adaptador de fuente. Actualmente, los tipos aceptados son:

File  -  CGI::FormBuilder::Source::File

Además de uno de estos tipos, también puede especificar un nombre de paquete completo, en cuyo caso ese módulo se cargará automáticamente y se utilizarán sus rutinas new() y parse(). Por ejemplo:

my $form = CGI::FormBuilder->new(
                fields => \@fields,
                source => {
                    type => 'Mi::Modulo::Fuente',
                    archivo => '/ruta/a/fuente.conf',
                }
           );

Todas las demás opciones además de "type" se pasan al constructor para ese módulo fuente literalmente, por lo que depende de usted y/o del módulo fuente cómo se deben manejar estas opciones adicionales.
