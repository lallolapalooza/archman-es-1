subrutina cgeesx (character jobvs, character sort, external select, character sense, integer n, complex, dimension( lda, * ) a, integer lda, integer sdim, complex, dimension( * ) w, complex, dimension( ldvs, * ) vs, integer ldvs, real rconde, real rcondv, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, logical, dimension( * ) bwork,

CGEESX calcula los eigenvalores, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices

GE

Propósito

:

!> !> CGEESX calcula para una matriz compleja no simétrica A de N por N, los !> eigenvalores, la forma de Schur T y, opcionalmente, la matriz de vectores !> de Schur Z. Esto proporciona la factorización de Schur A = Z*T*(Z**H). !> !> Opcionalmente, también ordena los eigenvalores en la diagonal de la !> forma de Schur de modo que los eigenvalores seleccionados estén en la !> esquina superior izquierda; calcula un número de condición recíproco !> para el promedio de los eigenvalores seleccionados (RCONDE); y calcula !> un número de condición recíproco para el subespacio invariante derecho !> correspondiente a los eigenvalores seleccionados (RCONDV). Las columnas !> principales de Z forman una base ortonormal para este subespacio !> invariante. !> !> Para una explicación más detallada de los números de condición !> recíprocos RCONDE y RCONDV, consulte la Sección 4.10 de la Guía de !> Usuarios de LAPACK (donde estas cantidades se

denominan s y sep !> respectivamente). !> !> Una matriz compleja está en forma de Schur si es triangular superior. !>
