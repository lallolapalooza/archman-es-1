CGI::Session::ID::incr(3) Documentación de Perl aportada por el usuario CGI::Session::ID::incr(3)

NOMBRE

CGI::Session::ID::incr - Controlador de ID para CGI::Session

SINOPSIS

use CGI::Session;
$session = CGI::Session->new("id:Incr", undef, {
                            Directory   => '/tmp',
                            IDFile      => '/tmp/cgisession.id',
                            IDInit      => 1000,
                            IDIncr      => 2 });

DESCRIPCIÓN

CGI::Session::ID::incr se utiliza para generar IDs de sesión que se incrementan automáticamente. Compárelo con CGI::Session::ID::md5, donde los IDs de sesión son cadenas de 32 caracteres verdaderamente aleatorias. CGI::Session::ID::incr espera los siguientes argumentos pasados a CGI::Session->new() como el tercer argumento.

IDFile
Ubicación donde se almacenan los IDs autoincrementales. Este atributo es obligatorio.
IDInit
Valor inicial del ID si es el primer ID que se va a generar. Por ejemplo, si desea que los números de ID comiencen con 1000 en lugar de 0, aquí es donde debe establecer su valor. El valor predeterminado es 0.
IDIncr
En cuántos dígitos debe incrementarse cada número. Por ejemplo, si desea que el primer ID generado comience con 1000, y cada ID subsiguiente se incremente en 10, establezca IDIncr en 10 y IDInit en 1000. El valor predeterminado es 1.
