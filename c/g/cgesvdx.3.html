CGESVDX calcula la descomposición en valores singulares (SVD) para matrices GE

Propósito:

!>
!>  CGESVDX calcula la descomposición en valores singulares (SVD) de una matriz compleja
!>  A de M por N, calculando opcionalmente los vectores singulares izquierdos y/o derechos.
!>  La SVD se escribe
!>
!>      A = U * SIGMA * transpuesta(V)
!>
!>  donde SIGMA es una matriz de M por N que es cero excepto por sus
!>  min(m,n) elementos diagonales, U es una matriz unitaria de M por M, y
!>  V es una matriz unitaria de N por N.  Los elementos diagonales de SIGMA
!>  son los valores singulares de A; son reales y no negativos, y
!>  se devuelven en orden descendente.  Las primeras min(m,n) columnas de
!>  U y V son los vectores singulares izquierdos y derechos de A.
!>
!>  CGESVDX usa un problema de valores propios para obtener la SVD, lo que
!>  permite el cálculo de un subconjunto de valores y vectores
!>  singulares. Consulte SBDSVDX para más detalles.
!>
!>  Tenga en cuenta que la rutina devuelve V**T, no V.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          Especifica opciones para calcular toda o parte de la matriz U:
!>          = 'V':  se devuelven en el array U las primeras min(m,n) columnas de U (los vectores
!>                  singulares izquierdos) o las especificadas por RANGE;
!>          = 'N':  no se calculan columnas de U (ningún vector
!>                  singular izquierdo).
!>

JOBVT

!>          JOBVT es CHARACTER*1
!>           Especifica opciones para calcular toda o parte de la matriz
!>           V**T:
!>           = 'V':  se devuelven en el array VT las primeras min(m,n) filas de V**T (los vectores
!>                   singulares derechos) o las especificadas por RANGE;
!>           = 'N':  no se calculan filas de V**T (ningún vector
!>                   singular derecho).
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores singulares.
!>          = 'V': se encontrarán todos los valores singulares en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los valores singulares del i-ésimo al IU-ésimo.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, el contenido de A se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

VL

!>          VL es REAL
!>          Si RANGE='V', el límite inferior del intervalo en el que
!>          se buscarán los valores singulares. VU > VL.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es REAL
!>          Si RANGE='V', el límite superior del intervalo en el que
!>          se buscarán los valores singulares. VU > VL.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor singular más pequeño a devolver.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor singular más grande a devolver.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

NS

!>          NS es INTEGER
!>          El número total de valores singulares encontrados,
!>          0 <= NS <= min(M,N).
!>          Si RANGE = 'A', NS = min(M,N); si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S es un array REAL, dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!>

U

!>          U es un array COMPLEX, dimensión (LDU,UCOL)
!>          Si JOBU = 'V', U contiene las columnas de U (los vectores
!>          singulares izquierdos, almacenados por columnas) según lo especificado por RANGE; si
!>          JOBU = 'N', U no se referencia.
!>          Nota: El usuario debe asegurarse de que UCOL >= NS; si RANGE = 'V',
!>          el valor exacto de NS no se conoce de antemano y se debe usar una
!>          cota superior.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1; si
!>          JOBU = 'V', LDU >= M.
!>

VT

!>          VT es un array COMPLEX, dimensión (LDVT,N)
!>          Si JOBVT = 'V', VT contiene las filas de V**T (los vectores
!>          singulares derechos, almacenados por filas) según lo especificado por RANGE; si JOBVT = 'N',
!>          VT no se referencia.
!>          Nota: El usuario debe asegurarse de que LDVT >= NS; si RANGE = 'V',
!>          el valor exacto de NS no se conoce de antemano y se debe usar una
!>          cota superior.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1; si
!>          JOBVT = 'V', LDVT >= NS (ver arriba).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= MAX(1,MIN(M,N)*(MIN(M,N)+4)) para las rutas (ver
!>          comentarios dentro del código):
!>             - RUTA 1  (M mucho mayor que N)
!>             - RUTA 1t (N mucho mayor que M)
!>          LWORK >= MAX(1,MIN(M,N)*2+MAX(M,N)) para las otras rutas.
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un array REAL, dimensión (MAX(1,LRWORK))
!>          LRWORK >= MIN(M,N)*(MIN(M,N)*2+15*MIN(M,N)).
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (12*MIN(M,N))
!>          Si INFO = 0, los primeros NS elementos de IWORK son cero. Si INFO > 0,
!>          entonces IWORK contiene los índices de los autovectores que no
!>          convergieron en SBDSVDX/SSTEVX.
!>

INFO

!>     INFO es INTEGER
!>           = 0:  salida exitosa
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>           > 0:  si INFO = i, entonces i autovectores no convergieron
!>                 en SBDSVDX/SSTEVX.
!>                 si INFO = N*2 + 1, ocurrió un error interno en
!>                 SBDSVDX
!>
