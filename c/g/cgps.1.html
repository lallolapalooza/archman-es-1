CGPS(1) Documentación de gpsd CGPS(1)

NOMBRE

cgps - cliente de terminal ncurses para gpsd

SINOPSIS

cgps [OPCIONES] [servidor[:puerto[:dispositivo]]]

cgps -h

cgps -V

DESCRIPCIÓN

cgps es un cliente de gpsd basado en ncurses. Es capaz de ejecutarse en una terminal serie o un emulador de terminal. Se parece a xgps(1), pero sin la pantalla gráfica de satélites y no requiere X ni otro sistema de ventanas.

cgps no requiere privilegios de root. También funcionará bien como root. Ejecutarlo con sudo causará pérdida de funcionalidad.

Ninguna de las estimaciones de error proporcionadas por gpsd, y mostradas por cgps, debe tomarse como algo más que niveles de "bondad". Los fabricantes de receptores GNSS a menudo no documentan la base de sus estimaciones. Aquellos que sí documentan sus estimaciones son inconsistentes sobre lo que significan.

OPCIONES

-?, -h, --help

Imprime un resumen de las opciones y luego sale.

-D LVL, --debug LVL

Establece el nivel de depuración; es principalmente para uso de los desarrolladores de GPSD. Habilita varios mensajes de progreso a la salida de error estándar.

-i, --imu

Muestra datos IMU en lugar de datos de corrección y satélite.

-l FMT, --llfmt FMT

Establece el formato de los informes de latitud y longitud. El valor 'd' produce grados decimales y es el predeterminado. El valor 'm' produce grados y minutos decimales. El valor 's' produce grados, minutos y segundos decimales.

-m, --magtrack

Muestra las trayectorias como magnéticas, no verdaderas.

-m, --magtrack

Muestra tu trayectoria magnética (en contraposición a tu trayectoria verdadera). Este es un valor calculado, no un valor medido. La variación magnética siempre es potencialmente susceptible a grandes errores, pero suele ser mejor que dos grados.

-s, --silent

Evita que cgps muestre los datos brutos que provienen del demonio. Esta visualización también se puede activar con el comando s.

-u UNITS, --units UNITS

Establece las unidades del sistema para la visualización; sigue la palabra clave con 'i' para 'imperial' para unidades americanas (Pies Internacionales en altitud y estimaciones de error, millas por hora en velocidades), 'n' para 'náutico' (pies en altitud y estimaciones de error, nudos en velocidad) o 'm' para 'métrico' (metros en altitud y estimaciones de error, kilómetros por hora en velocidades).

Nota: El Pie de Topografía de EE. UU. no es compatible.

-V, --version

Imprime la versión del paquete y sale.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio gpsd local que se ejecuta en localhost, utilizando el puerto predeterminado de GPSD 2947. El argumento opcional a cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para más explicaciones y ejemplos, consulta la sección ARGUMENTOS en la página del manual de gps(1)

COMANDOS

cgps termina cuando le envías una SIGHUP o SIGINT; dadas las configuraciones de terminal predeterminadas, esto ocurrirá cuando escribas Ctrl-C en él.

cgps aceptará unos pocos comandos de una sola letra mientras se ejecuta:

c

Borra la ventana inferior.

d

Muestra lat/lon dd.dddddddd, dd mm.mmmmmm y dd mm ss.ssss

h

Abre una ventana de ayuda.

i

Usa unidades imperiales.

m

Usa unidades métricas.

n

Usa unidades náuticas.

q

Borra la pantalla y sale

s

Activa/desactiva la visualización de datos JSON brutos en la ventana inferior.

t

Activa/desactiva la trayectoria verdadera/magnética.

ENTORNO

La variable de entorno GPSD_UNITS se verifica si no se especifica ningún sistema de unidades en la línea de comandos. Puede establecerse en 'i'. 'imperial', 'm', 'metric', o 'n', 'nautical'.

Se verifica LC_MEASUREMENT y luego LANG si no se ha especificado ningún sistema de unidades en la línea de comandos o en GPSD_UNITS. Si el valor es 'C', 'POSIX', o comienza con 'en_US', el sistema de unidades se establece en imperial. El valor predeterminado si no se ha seleccionado ningún sistema es métrico.

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo

2

fallo: terminal demasiado pequeña
