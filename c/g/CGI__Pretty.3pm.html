CGI::Pretty(3) Documentación de Perl aportada por el usuario CGI::Pretty(3)

NOMBRE

CGI::Pretty - módulo para producir código HTML bien formateado

CGI::Pretty ESTÁ OBSOLETO

Se eliminará de la distribución CGI en una futura versión, por lo que ya no debe usarse y debe eliminarse de cualquier código que lo utilice actualmente.

Por ahora, se ha reducido a un envoltorio para evitar que su código falle, pero las funciones "pretty" ya no generarán HTML "pretty".

Alternativas

HTML::HTML5::Parser + HTML::HTML5::Writer + XML::LibXML::PrettyPrint:

print HTML::HTML5::Writer->new(
    start_tags => 'force',
    end_tags   => 'force',
)->document(
    XML::LibXML::PrettyPrint->new_for_html( indent_string => "\t" )
    ->pretty_print(
        HTML::HTML5::Parser->new->parse_string( $html_string )
    )
);

Marpa::R2::HTML (ver el script html_fmt para ejemplos)

HTML::Tidy

HTML::Parser
