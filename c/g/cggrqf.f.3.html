Documentación de Función/Subrutina

subrutina cggrqf (integer m, integer p, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) taua, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) taub, complex, dimension( * ) work, integer lwork, integer info)

CGGRQF

Propósito:

!>
!> CGGRQF calcula una factorización RQ generalizada de una matriz A de M por N
!> y una matriz B de P por N:
!>
!>             A = R*Q,        B = Z*T*Q,
!>
!> donde Q es una matriz unitaria de N por N, Z es una matriz unitaria
!> de P por P, y R y T asumen una de las formas:
!>
!> si M <= N,  R = ( 0  R12 ) M,   o si M > N,  R = ( R11 ) M-N,
!>                  N-M  M                           ( R21 ) N
!>                                                      N
!>
!> donde R12 o R21 es triangular superior, y
!>
!> si P >= N,  T = ( T11 ) N  ,   o si P < N,  T = ( T11  T12 ) P,
!>                 (  0  ) P-N                         P   N-P
!>                    N
!>
!> donde T11 es triangular superior.
!>
!> En particular, si B es cuadrada y no singular, la factorización GRQ
!> de A y B da implícitamente la factorización RQ de A*inv(B):
!>
!>              A*inv(B) = (R*inv(T))*Z**H
!>
!> donde inv(B) denota el inverso de la matriz B, y Z**H denota la
!> transpuesta conjugada de la matriz Z.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B. N >= 0.
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, si M <= N, el triángulo superior del subarreglo
!>          A(1:M,N-M+1:N) contiene la matriz triangular superior R de M por M;
!>          si M > N, los elementos en y por encima de la subdiagonal
!>          (M-N)-ésima contienen la matriz trapezoidal superior R de M por N;
!>          los elementos restantes, junto con el arreglo TAUA, representan la
!>          matriz unitaria Q como un producto de reflectores elementales (ver
!>          Detalles Adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>

TAUA

!>          TAUA es un arreglo COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Q (ver Detalles Adicionales).
!>

B

!>          B es un arreglo COMPLEX, dimensión (LDB,N)
!>          En la entrada, la matriz B de P por N.
!>          En la salida, los elementos en y por encima de la diagonal del
!>          arreglo contienen la matriz trapezoidal superior T de min(P,N) por N
!>          (T es triangular superior si P >= N); los elementos por debajo de la
!>          diagonal, junto con el arreglo TAUB, representan la matriz unitaria
!>          Z como un producto de reflectores elementales (ver Detalles
!>          Adicionales).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1,P).
!>

TAUB

!>          TAUB es un arreglo COMPLEX, dimensión (min(P,N))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Z (ver Detalles Adicionales).
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= max(1,N,M,P).
!>          Para un rendimiento óptimo LWORK >= max(N,M,P)*max(NB1,NB2,NB3),
!>          donde NB1 es el tamaño de bloque óptimo para la factorización RQ
!>          de una matriz de M por N, NB2 es el tamaño de bloque óptimo para
!>          la factorización QR de una matriz de P por N, y NB3 es el tamaño
!>          de bloque óptimo para una llamada de CUNMRQ.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO=-i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taua * v * v**H
!>
!>  donde taua es un escalar complejo, y v es un vector complejo con
!>  v(n-k+i+1:n) = 0 y v(n-k+i) = 1; v(1:n-k+i-1) se almacena en la salida en
!>  A(m-k+i,1:n-k+i-1), y taua en TAUA(i).
!>  Para formar Q explícitamente, use la subrutina de LAPACK CUNGRQ.
!>  Para usar Q para actualizar otra matriz, use la subrutina de LAPACK CUNMRQ.
!>
!>  La matriz Z se representa como un producto de reflectores elementales
!>
!>     Z = H(1) H(2) . . . H(k), donde k = min(p,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taub * v * v**H
!>
!>  donde taub es un escalar complejo, y v es un vector complejo con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:p) se almacena en la salida en B(i+1:p,i),
!>  y taub en TAUB(i).
!>  Para formar Z explícitamente, use la subrutina de LAPACK CUNGQR.
!>  Para usar Z para actualizar otra matriz, use la subrutina de LAPACK CUNMQR.
!>
