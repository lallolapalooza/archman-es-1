NOMBRE

CGI::FormBuilder::Template::Fast - Interfaz de FormBuilder para CGI::FastTemplate

SINOPSIS

 my $form = CGI::FormBuilder->new(
     fields   => \@whatever,
     template => {
         type => 'Fast',
         root => '/path/to/templates',
         # usar archivos externos
         define => {
             form           => 'form.txt',
             field          => 'field.txt',
             invalid_field  => 'invalid_field.txt',
         },
         # o definir en línea
         define_nofile => {
             form => '<html><head></head><body>$START_FORM
                      <table>$FIELDS</table>$SUBMIT $END_FORM</body></html>',
             # etc.
         },
     },
);

DESCRIPCIÓN

Este motor adapta FormBuilder para usar "CGI::FastTemplate". Por favor, lea estas documentaciones cuidadosamente, ya que el uso difiere de otros adaptadores de plantilla en varias formas importantes.

Necesitará definir tres plantillas: "form", "field", y "invalid_field". Puede usar "define" para apuntar a archivos externos (que es el estilo recomendado de "CGI::FastTemplate"), o "define_nofile"/ "define_raw" para definirlas en línea. Las plantillas en "define_nofile" tienen precedencia sobre "define_raw", y ambas tienen precedencia sobre "define".

my $form = CGI::FormBuilder->new(
    # ...
    template => {
        type => 'FastTemplate',
        root => '/path/to/templates',
        define => {
            form           => 'form.txt',
            field          => 'field.txt',
            invalid_field  => 'invalid_field.txt',
        },
        # o, puede definir plantillas directamente
        define_nofile => {
            form => '<html><head></head><body>$START_FORM<table>'
                    '$FIELDS</table>$SUBMIT $END_FORM</body></html>',
            # etc.
        },
    },
    # ...
);

Si usa "define" con plantillas externas, probablemente también querrá definir su directorio raíz de plantillas con el parámetro "root".

Dentro de cada una de las plantillas de campo, las siguientes variables están disponibles:

$NAME         # $field->name
$FIELD        # $field->tag   (etiqueta de entrada HTML)
$VALUE        # $field->value (¡primer valor solamente!)
$LABEL        # $field->label
$COMMENT      # $field->comment
$ERROR        # $field->error
$REQUIRED     # $field->required ? 'required' : 'optional'

Todos los campos se procesan en secuencia; los campos válidos usan la plantilla "field", y los campos inválidos la plantilla "invalid_field". El resultado de cada uno de estos se añade a la variable $FIELDS, que debe usar en su plantilla "form". En la plantilla "form", también tiene acceso a estas variables:

$TITLE        # título del formulario
$START_FORM   # etiqueta de apertura del formulario
$SUBMIT       # el botón de envío
$RESET        # el botón de reinicio
$END_FORM     # etiqueta de cierre del formulario
$JS_HEAD      # JavaScript de validación

Tenga en cuenta que, dado que "CGI::FastTemplate" no usa nada más que variables escalares simples, no hay variables que correspondan a las listas que tienen otros motores (por ejemplo, listas de "fields" u "options" en "TT2" o "Text::Template").
