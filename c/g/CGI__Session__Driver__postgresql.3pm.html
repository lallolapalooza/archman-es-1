NOMBRE

CGI::Session::Driver::postgresql - Controlador de PostgreSQL para CGI::Session

SINOPSIS

use CGI::Session;
$session = CGI::Session->new("driver:PostgreSQL", undef, {Handle=>$dbh});

DESCRIPCIÓN

CGI::Session::PostgreSQL es un controlador de CGI::Session para almacenar datos de sesión en una tabla de PostgreSQL.

ALMACENAMIENTO

Antes de poder usar cualquier controlador de base de datos basado en DBI, debes asegurarte de que se ha creado una tabla de base de datos compatible para que CGI::Session funcione. El siguiente comando producirá los requisitos mínimos en la mayoría de las bases de datos SQL:

CREATE TABLE sessions (
    id CHAR(32) NOT NULL PRIMARY KEY,
    a_session BYTEA NOT NULL
);

y dentro de tu código usa:

use CGI::Session;
$session = CGI::Session->new("driver:PostgreSQL", undef, {Handle=>$dbh, ColumnType=>"binary"});

Ten en cuenta el argumento *ColumnType*. El tipo de texto de PostgreSQL tiene problemas al intentar contener un carácter nulo. (Conocido como "\0" en Perl, no confundir con el *NULL* de SQL). Si sabes que no hay posibilidad de que aparezca un carácter nulo en los datos serializados, puedes omitir el atributo *ColumnType*. Se recomienda usar un tipo de columna *BYTEA* y "ColumnType => 'binary'" cuando se usa Storable como serializador o si existe alguna posibilidad de que aparezca un valor nulo en cualquiera de los datos serializados.

Para usar nombres de columna diferentes, cambia la declaración 'create table', y luego simplemente haz esto:

$s = CGI::Session->new('driver:pg', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    DataSource=>'dbi:pg:dbname=project',
});

o

$s = CGI::Session->new('driver:pg', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    Handle=>$dbh,
});

Para más detalles, consulta CGI::Session::Driver::DBI, la clase padre.

Consulta también el controlador sqlite, que ejerce un método diferente para tratar con datos binarios.
