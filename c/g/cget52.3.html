CGET52

Documentación de función/subrutina

subrutina cget52 (logical left, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( lde, * ) e, integer lde, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( * ) work, real, dimension( * ) rwork, real, dimension( 2 ) result)

CGET52

Propósito:

!>
!> CGET52  realiza una comprobación de vectores propios para el problema
!> de valores propios generalizado.
!>
!> La prueba básica para vectores propios derechos es:
!>
!>                           | b(i) A E(i) -  a(i) B E(i) |
!>         RESULT(1) = max   -------------------------------
!>                      i    n ulp max( |b(i) A|, |a(i) B| )
!>
!> usando la norma 1.  Aquí, a(i)/b(i) = w es el i-ésimo valor propio
!> generalizado de A - w B, o, equivalentemente, b(i)/a(i) = m es el
!> i-ésimo valor propio generalizado de m A - B.
!>
!>                         H   H  _      _
!> Para vectores propios izquierdos, se usan A , B , a, y b.
!>
!> CGET52 también prueba la normalización de E. Se supone que cada
!> vector propio está normalizado de tal manera que el máximo
!> de sus elementos sea 1, donde en este caso,
!> de un valor complejo x es |Re(x)| + |Im(x)|; llamemos a esto
!> norma máxima de un vector v  M(v).
!> si a(i)=b(i)=0, entonces el vector propio se establece como el
!> vector de coordenadas j-ésimo. La prueba de normalización es:
!>
!>         RESULT(2) =      max       | M(v(i)) - 1 | / ( n ulp )
!>                    eigenvectors v(i)
!>

Parámetros

LEFT 
!>          LEFT es LOGICAL
!>          =.TRUE.:  Se asume que los vectores propios en las columnas
!>                    de E son vectores propios *izquierdos*.
!>          =.FALSE.: Se asume que los vectores propios en las columnas
!>                    de E son vectores propios *derechos*.
!>

N

!>          N es INTEGER
!>          El tamaño de las matrices. Si es cero, CGET52 no hace
!>          nada. Debe ser al menos cero.
!>

A

!>          A es un array COMPLEX, dimension (LDA, N)
!>          La matriz A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 1
!>          y al menos N.
!>

B

!>          B es un array COMPLEX, dimension (LDB, N)
!>          La matriz B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. Debe ser al menos 1
!>          y al menos N.
!>

E

!>          E es un array COMPLEX, dimension (LDE, N)
!>          La matriz de vectores propios. Debe ser O( 1 ).
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal de E. Debe ser al menos 1 y al
!>          menos N.
!>

ALPHA

!>          ALPHA es un array COMPLEX, dimension (N)
!>          Los valores a(i) como se describe arriba, que, junto con b(i),
!>          definen los valores propios generalizados.
!>

BETA

!>          BETA es un array COMPLEX, dimension (N)
!>          Los valores b(i) como se describe arriba, que, junto con a(i),
!>          definen los valores propios generalizados.
!>

WORK

!>          WORK es un array COMPLEX, dimension (N**2)
!>

RWORK

!>          RWORK es un array REAL, dimension (N)
!>

RESULT

!>          RESULT es un array REAL, dimension (2)
!>          Los valores calculados por la prueba descrita arriba. Si A E o
!>          B E es probable que cause desbordamiento, entonces RESULT(1:2)
!>          se establece en 10 / ulp.
!>
