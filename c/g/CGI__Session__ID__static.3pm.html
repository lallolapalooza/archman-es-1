NOMBRE

CGI::Session::ID::static - Controlador de ID de CGI::Session para generar IDs estáticos

SINOPSIS

use CGI::Session;
$session = CGI::Session->new( 'driver:mysql;id:static', $ENV{REMOTE_ADDR}, { Handle => $dbh } );

DESCRIPCIÓN

CGI::Session::ID::static se utiliza para generar IDs de sesión estáticos y consistentes. En otras palabras, le dices a CGI::Session el ID que quieres usar y lo respetará.

A diferencia de los otros controladores de ID, este requiere que proporciones un ID al crear el objeto de sesión; si le pasas un valor indefinido, fallará.
