NOMBRE

CGI::FormBuilder::Multi - Crear formularios FormBuilder de varias páginas

SINOPSIS

use CGI::FormBuilder::Multi;
use CGI::Session;   # o algo similar
# "Meta-formulario" de nivel superior
my $multi = CGI::FormBuilder::Multi->new(
    # opciones del formulario 1
    { fields   => [qw(name email daytime_phone evening_phone)],
      title    => 'Basic Info',
      template => 'page1.tmpl',
      validate => { name => 'NAME', email => 'EMAIL' },
      required => [qw(name email daytime_phone)],
    },
    # opciones del formulario 2
    { fields   => [qw(billing_name billing_card billing_exp
                      billing_address billing_city billing_state
                      billing_zip billing_phone)],
      title    => 'Billing',
      template => 'page2.tmpl',
      required => 'ALL',
    },
    # opciones del formulario 3
    { fields   => [qw(same_as_billing shipping_address
                      shipping_city shipping_state shipping_zip)],
      title    => 'Shipping',
      template => 'page3.tmpl',
      required => 'ALL',
    },
    # un par de opciones específicas de este módulo
    navbar => 1,
    # opciones restantes (no en hashrefs) se aplican a todos los formularios
    header => 1,
    method => 'POST',
    submit => 'Continue',
    values => $dbi_hashref_query,
);
# Obtener el formulario de la página actual
my $form = $multi->form;
if ($form->submitted && $form->validate) {
    # Recuperar el id de sesión
    my $sid = $form->sessionid;
    # Inicializar sesión
    my $session = CGI::Session->new("driver:File", $sid, {Directory=>'/tmp'});
    # Almacenar automáticamente los datos actualizados en la sesión
    $session->save_param($form);
    # ¿última página?
    if ($multi->page == $multi->pages) {
        print $form->confirm;
        exit;
    }
    # Todavía aquí, ir a la siguiente página
    $multi->page++;
    # Y volver a obtener el formulario (¡sin "my" en $form!)
    $form = $multi->form;
    # Asegurarse de que tiene el sessionid correcto
    $form->sessionid($session->id);
    # en la página 3 tenemos manejo especial de campos
    if ($multi->page == 3) {
        $form->field(name    => 'same_as_billing',
                     type    => 'checkbox',
                     options => 'Yes',
                     jsclick => 'this.form.submit()');
    }
}
# Continuar e imprimir el formulario de la siguiente página
print $form->render;

DESCRIPCIÓN

Este módulo trabaja con "CGI::FormBuilder" para crear formularios de varias páginas. Cada formulario se especifica usando las mismas opciones que pasarías directamente a FormBuilder. Ver CGI::FormBuilder para una lista de estas opciones.

El "meta-formulario" de varias páginas es un compuesto de los formularios individuales que especificas, unidos a través del parámetro CGI especial "_page" . El formulario actual está disponible a través del método form() , y la página actual está disponible a través de page(). Depende de ti navegar apropiadamente:

my $multi = CGI::FormBuilder::Multi->new(...);
# formulario actual
my $form  = $multi->form;
$multi->page++;         # página siguiente
$multi->page--;         # y anterior
$multi->page = $multi->pages;   # ir a la última página
# formulario actual
$form = $multi->form;

Para que todo sea lo más fluido posible, deberías ponerle título a cada uno de tus formularios, incluso si estás usando una plantilla. Esto permitirá "::Multi" crear enlaces cruzados por nombre en lugar de solo "Página 2".

MÉTODOS

Se proporcionan los siguientes métodos:

new(\%form1, \%form2, opt => val)

Esto crea un nuevo objeto "CGI::FormBuilder::Multi" . Los formularios se especifican como hashrefs de opciones, en orden secuencial, similar a cómo se especifican los campos. El orden de los formularios es el orden en que las páginas se recorrerán.

Además de un hashref, los formularios pueden especificarse directamente como un $form objeto que ya ha sido creado. Para objetos existentes, lo siguiente no aplica.

Cuando se ve el primer argumento que no es una referencia, todos los argumentos restantes se toman como opciones comunes que se aplican a todos los formularios. De esta manera, puedes especificar configuraciones globales para cosas como "method" o "header" (que probablemente serán las mismas), y luego anular configuraciones individuales como "fields" y "validate" a nivel de cada formulario.

Si no deseas especificar ninguna opción para tus formularios, puedes en su lugar especificar solo la opción "pages" , por ejemplo:

my $multi = CGI::FormBuilder::Multi->new(pages => 3);

Con este enfoque, tendrás que ensamblar dinámicamente cada página a medida que llegues a ellas. La lista de correo puede ayudar.

La "SINOPSIS" anterior es muy representativa del uso típico.

form()

Esto devuelve el formulario de la página actual, como un objeto creado directamente por "CGI::FormBuilder->new". Todos los métodos y opciones válidos de FormBuilder funcionan en el formulario. Para cambiar qué formulario se devuelve, usa page().

page($num)

Esto establece y devuelve la página actual. Puede aceptar un número de página ya sea como argumento o directamente como una asignación:

$multi->page(1);    # página 1
$multi->page = 1;   # lo mismo
$multi->page++;     # página siguiente
$multi->page--;     # una hacia atrás
if ($multi->page == $multi->pages) {
    # última página
}

Consejo: Generalmente, solo deberías cambiar de página una vez que hayas validado apropiadamente el formulario de la página actual.

pages()

Esto devuelve el número total de páginas. En realidad, lo que devuelve es un array de todos los formularios (y por lo tanto tiene el alias forms()), que simplemente resulta ser la longitud en un contexto escalar, igual que en cualquier otro lugar en Perl.

navbar($onoff)

Esto devuelve una barra de navegación que permite al usuario saltar entre páginas del formulario. Esto es útil si quieres permitir que una persona llene diferentes páginas fuera de orden. En la mayoría de los casos, no quieres esto, así que está desactivado por defecto.

Para usarlo, la mejor manera es configurar "navbar => 1" en new(). Sin embargo, también puedes obtenerlo tú mismo para renderizar tu propio HTML:

my $html = $multi->navbar;      # HTML escalar
my @link = $multi->navbar;      # array de enlaces

Esto es útil en algo como esto:

my $nav = $multi->navbar;
$form = $multi->form;
$form->tmpl_param(navbar => $navbar);

La barra de navegación tendrá dos clases de estilo: "fb_multi_page" para el enlace de la página actual, y "fb_multi_link" para los demás.
