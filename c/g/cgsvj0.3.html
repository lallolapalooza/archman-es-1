Documentación de Función/Subrutina

subrutina cgsvj0 (character*1 jobv, integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( n ) d, real, dimension( n ) sva, integer mv, complex, dimension( ldv, * ) v, integer ldv, real eps, real sfmin, real tol, integer nsweep, complex, dimension( lwork ) work, integer lwork, integer info)

CGSVJ0 preprocesador para la rutina cgesvj.

Propósito:

!>
!> CGSVJ0 es llamado desde CGESVJ como un preprocesador y ese es su principal
!> propósito. Aplica rotaciones de Jacobi de la misma manera que lo hace CGESVJ, pero
!> no comprueba la convergencia (criterio de parada). Hay disponibles algunos
!> parámetros de ajuste (marcados con [TP]) para el implementador.
!>

Parámetros

JOBV 
!>          JOBV es CHARACTER*1
!>          Especifica si la salida de este procedimiento se utiliza
!>          para calcular la matriz V:
!>          = 'V': el producto de las rotaciones de Jacobi se acumula
!>                 postmultiplicando el array V de N por N.
!>                (Véase la descripción de V.)
!>          = 'A': el producto de las rotaciones de Jacobi se acumula
!>                 postmultiplicando el array V de MV por N.
!>                (Véanse las descripciones de MV y V.)
!>          = 'N': las rotaciones de Jacobi no se acumulan.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.
!>          M >= N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          A la entrada, la matriz A de M por N, tal que A*diag(D) representa
!>          la matriz de entrada.
!>          A la salida,
!>          A_onexit * diag(D_onexit) representa la matriz de entrada A*diag(D)
!>          post-multiplicada por una secuencia de rotaciones de Jacobi, donde el
!>          umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Véanse las descripciones de D, TOL y NSWEEP.)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

D

!>          D es un array COMPLEX, dimensión (N)
!>          El array D acumula los factores de escala de las rotaciones
!>          de Jacobi complejas escaladas.
!>          A la entrada, A*diag(D) representa la matriz de entrada.
!>          A la salida, A_onexit*diag(D_onexit) representa la matriz de entrada
!>          post-multiplicada por una secuencia de rotaciones de Jacobi, donde el
!>          umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Véanse las descripciones de A, TOL y NSWEEP.)
!>

SVA

!>          SVA es un array REAL, dimensión (N)
!>          A la entrada, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A*diag(D).
!>          A la salida, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A_onexit*diag(D_onexit).
!>

MV

!>          MV es INTEGER
!>          Si JOBV = 'A', entonces las filas de V son post-multiplicadas por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces MV no se referencia.
!>

V

!>          V es un array COMPLEX, dimensión (LDV,N)
!>          Si JOBV = 'V' entonces las filas de V son post-multiplicadas por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'A' entonces las filas de V son post-multiplicadas por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!>

EPS

!>          EPS es REAL
!>          EPS = SLAMCH('Epsilon')
!>

SFMIN

!>          SFMIN es REAL
!>          SFMIN = SLAMCH('Safe Minimum')
!>

TOL

!>          TOL es REAL
!>          TOL es el umbral para las rotaciones de Jacobi. Para un par
!>          A(:,p), A(:,q) de columnas pivote, la rotación de Jacobi se
!>          aplica solo si ABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>

NSWEEP

!>          NSWEEP es INTEGER
!>          NSWEEP es el número de barridos de rotaciones de Jacobi a
!>          realizar.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          LWORK es la dimensión de WORK. LWORK >= M.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

CGSVJ0 se usa solo para permitir que CGESVJ llame a una versión simplificada de sí mismo para trabajar en una submatriz de la matriz original.
