Documentación de Función/Subrutina

subrutina cgehd2 (integer n, integer ilo, integer ihi, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CGEHD2 reduce una matriz general cuadrada compleja a forma de Hessenberg superior utilizando un algoritmo no bloqueado.

Propósito:

!>
!> CGEHD2 reduce una matriz general compleja A a la forma de Hessenberg superior H
!> por una transformación unitaria de semejanza:  Q**H * A * Q = H .
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>
!>          Se asume que A ya es triangular superior en las filas
!>          y columnas 1:ILO-1 e IHI+1:N. ILO e IHI normalmente son
!>          establecidos por una llamada previa a CGEBAL; de lo contrario,
!>          deberían ser establecidos a 1 y N respectivamente. Ver Detalles
!>          Adicionales.
!>          1 <= ILO <= IHI <= max(1,N).
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz general de n por n a ser reducida.
!>          En la salida, el triángulo superior y la primera subdiagonal de A
!>          se sobrescriben con la matriz de Hessenberg superior H, y los
!>          elementos debajo de la primera subdiagonal, con el array TAU,
!>          representan la matriz unitaria Q como un producto de
!>          reflejos elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

TAU

!>          TAU es array COMPLEX, dimension (N-1)
!>          Los factores escalares de los reflejos elementales (ver Detalles
!>          Adicionales).
!>

WORK

!>          WORK es array COMPLEX, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales:

!>
!>  La matriz Q se representa como un producto de (ihi-ilo) reflejos
!>  elementales
!>
!>     Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i) = 0, v(i+1) = 1 y v(ihi+1:n) = 0; v(i+2:ihi) se almacena en la
!>  salida en A(i+2:ihi,i), y tau en TAU(i).
!>
!>  El contenido de A se ilustra con el siguiente ejemplo, con
!>  n = 7, ilo = 2 e ihi = 6:
!>
!>  en entrada,                        en salida,
!>
!>  ( a   a   a   a   a   a   a )    (  a   a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      h   h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  v4  h   h   h )
!>  (                         a )    (                          a )
!>
!>  donde a denota un elemento de la matriz original A, h denota un
!>  elemento modificado de la matriz de Hessenberg superior H, y vi denota un
!>  elemento del vector que define H(i).
!>
