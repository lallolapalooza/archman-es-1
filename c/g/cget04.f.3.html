Documentación de la Función/Subrutina

subroutine cget04 (integer n, integer nrhs, complex, dimension( ldx, * ) x, integer ldx, complex, dimension( ldxact, * ) xact, integer ldxact, real rcond, real resid)

CGET04

Propósito:

!>
!> CGET04 calcula la diferencia entre una solución calculada y la
!> solución verdadera de un sistema de ecuaciones lineales.
!>
!> RESID =  ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> donde RCOND es la inversa del número de condición y EPS es la
!> epsilon de la máquina.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices X y XACT.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X y XACT.  NRHS >= 0.
!>

X

!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!>          Los vectores solución calculados. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es un array COMPLEX, dimensión (LDXACT,NRHS)
!>          Los vectores solución exactos. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La inversa del número de condición de la matriz de coeficientes
!>          en el sistema de ecuaciones.
!>

RESID

!>          RESID es REAL
!>          El máximo sobre los NRHS vectores solución de
!>          ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS )
!>
