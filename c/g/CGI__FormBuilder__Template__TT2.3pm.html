SINOPSI

S 
my $form = CGI::FormBuilder->new(
                fields   => \@fields,
                template => {
                    type => 'TT2',
                    template => 'form.tmpl',
                    variable => 'form',
                }

;

DESCRIPCIÓ

N

Este motor adapta FormBuilder para usar "Template Toolkit". Para ello, especifique la opción "template" como una referencia a un hash que incluya la opción "type" establecida en "TT2" y la opción "template" establecida en el nombre de la plantilla que desea procesar. También puede añadir "variable" como una opción (entre otras) para indicar el nombre de la variable con el que desea que se referencien los datos del

formulario: 
my $form = CGI::FormBuilder->new(
                fields => \@fields,
                template => {
                    type => 'TT2',
                    template => 'userinfo.tmpl',
                    variable => 'form',
                }
           )
;

Se proporcionan los siguientes métodos (normalmente solo se usan internamente)

e

ate"

e

Devuelve un hash con t

para ser renderizados.

o y expande la plant

PLANTILLA

S

La plantilla podría parecerse a

esto: 
<html>
<head>
  <title>[% form.title %]</title>
  [% form.jshead %]
</head>
<body>
  [% form.start %]
  <table>
    [% FOREACH field = form.fields %]
    <tr valign="top">
      <td>
        [% field.required
              ? "<b>$field.label</b>"
              : field.label
        %]
      </td>
      <td>
        [% IF field.invalid %]
        Entrada faltante o no válida, por favor inténtelo de nuevo.
    <br/>
    [% END %]
    [% field.field %]
  </td>
</tr>
    [% END %]
    <tr>
      <td colspan="2" align="center">
        [% form.submit %] [% form.reset %]
      </td>
    </tr>
  </table>
  [% form.end %]
</body>
</html>

Por defecto, Template Toolkit hace que toda la información del formulario y de los campos sea accesible a través de variables

simples. 
[% jshead %]  -  JavaScript para insertar en <head>
[% title  %]  -  El <title> del formulario HTML
[% start  %]  -  Etiqueta <form> de apertura y campos internos
[% submit %]  -  El botón(es) de envío
[% reset  %]  -  El botón de reinicio
[% end    %]  -  Etiqueta </form> de cierre
[% fields %]  -  Lista de campos
[% field  %]  -  Hash de campos (para búsqueda por
nombre)

Puede especificar la opción "variable" para que todas estas variables sean accesibles bajo un espacio de nombres determinado. Por

ejemplo: 
my $form = CGI::FormBuilder->new(
    fields => \@fields,
    template => {
         type => 'TT2',
         template => 'form.tmpl',
         variable => 'form'
    },
)
;

Con "variable" establecida en "form", las variables son accesibles

como: 
[% form.jshead %]
[% form.start  %]
etc.

Puede acceder a campos individuales a través de la variable "f

ield". 
Para un campo llamado...  Los datos del campo están en...
--------------------  -----------------------
job                   [% form.field.job   %]
size                  [% form.field.size  %]
email                 [% form.field.email
%]

Cada campo contiene varios elementos. Por

ejemplo: 
[% myfield = form.field.email %]
[% myfield.label    %]  # etiqueta de texto
[% myfield.field    %]  # etiqueta de entrada del campo
[% myfield.value    %]  # primer valor
[% myfield.values   %]  # lista de todos los valores
[% myfield.option   %]  # primer valor
[% myfield.options  %]  # lista de todos los valores
[% myfield.required %]  # indicador de obligatorio
[% myfield.invalid  %]  # indicador de no
válido

La variable "fields" contiene una lista de todos los campos del formulario. Para iterar a través de todos los campos en orden, podría hacer algo como

esto: 
[% FOREACH field = form.fields %]
<tr>
 <td>[% field.label %]</td> <td>[% field.field %]</td>
</tr>
[% END
%]

Si desea personalizar alguna de las opciones de Template Toolkit, puede establecer la opción "engine" para que contenga una referencia a un objeto "Template" existente o una referencia a un hash de opciones que se pasan al constructor "Template". También puede establecer el elemento "data" para definir cualquier variable adicional que desee que sea accesible cuando se procese la

plantilla. 
my $form = CGI::FormBuilder->new(
    fields => \@fields,
    template => {
         type => 'TT2',
         template => 'form.tmpl',
         variable => 'form',
         engine   => {
              INCLUDE_PATH => '/usr/local/tt2/templates',
         },
         data => {
              version => 1.23,
              author  => 'Fred Smith',
         },
    },
)
;
