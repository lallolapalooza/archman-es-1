CGTTRS

Propósito:

!>
!> CGTTRS resuelve uno de los sistemas de ecuaciones
!>    A * X = B,  A**T * X = B,  o  A**H * X = B,
!> con una matriz tridiagonal A usando la factorización LU calculada
!> por CGTTRF.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es array COMPLEJO, dimensión (N-1)
!>          Los (n-1) multiplicadores que definen la matriz L de la
!>          factorización LU de A.
!>

D

!>          D es array COMPLEJO, dimensión (N)
!>          Los n elementos diagonales de la matriz triangular superior U de
!>          la factorización LU de A.
!>

DU

!>          DU es array COMPLEJO, dimensión (N-1)
!>          Los (n-1) elementos de la primera superdiagonal de U.
!>

DU2

!>          DU2 es array COMPLEJO, dimensión (N-2)
!>          Los (n-2) elementos de la segunda superdiagonal de U.
!>

IPIV

!>          IPIV es array ENTERO, dimensión (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).  IPIV(i) siempre será
!>          i o i+1; IPIV(i) = i indica que no se requirió un intercambio de fila.
!>

B

!>          B es array COMPLEJO, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de vectores del lado derecho B.
!>          En la salida, B es sobrescrita por los vectores solución X.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>
