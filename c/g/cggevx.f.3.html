subroutine cggevx (character balanc, character jobvl, character jobvr, character sense, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, integer ilo, integer ihi, real, dimension( * ) lscale, real, dimension( * ) rscale, real abnrm, real bbnrm, real, dimension( * ) rconde, real, dimension( * ) rcondv, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, logical, dimension( * ) bwork, integer info)

CGGEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE complejas

Propósito:

!>
!> CGGEVX calcula para un par de matrices complejas no simétricas de NxN
!> (A,B) los valores propios generalizados, y opcionalmente, los vectores
!> propios generalizados izquierdos y/o derechos.
!>
!> Opcionalmente, también calcula una transformación de balanceo para mejorar
!> el condicionamiento de los valores propios y los vectores propios (ILO, IHI,
!> LSCALE, RSCALE, ABNRM, y BBNRM), los recíprocos de los números de condición
!> para los valores propios (RCONDE), y los recíprocos de los números de condición
!> para los vectores propios derechos (RCONDV).
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar
!> lambda o una relación alpha/beta = lambda, tal que A - lambda*B es
!> singular. Usualmente se representa como el par (alpha,beta), ya que
!> existe una interpretación razonable para beta=0, e incluso para ambos
!> siendo cero.
!>
!> El vector propio derecho v(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>                  A * v(j) = lambda(j) * B * v(j) .
!> El vector propio izquierdo u(j) correspondiente al valor propio lambda(j)
!> de (A,B) satisface
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B.
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>
!>

Parámetros

BALANC 
!>          BALANC es CHARACTER*1
!>          Especifica la opción de balanceo a realizar:
!>          = 'N':  no escalar ni permutar diagonalmente;
!>          = 'P':  solo permutar;
!>          = 'S':  solo escalar;
!>          = 'B':  permutar y escalar.
!>          Los recíprocos de los números de condición calculados serán para las
!>          matrices después de permutar y/o balancear. La permutación no
!>          cambia los números de condición (en aritmética exacta), pero el
!>          balanceo sí lo hace.
!>

JOBVL

!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados izquierdos;
!>          = 'V':  calcular los vectores propios generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los vectores propios generalizados derechos;
!>          = 'V':  calcular los vectores propios generalizados derechos.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué recíprocos de números de condición se calculan.
!>          = 'N': ninguno se calcula;
!>          = 'E': se calcula solo para los valores propios;
!>          = 'V': se calcula solo para los vectores propios;
!>          = 'B': se calcula para valores propios y vectores propios.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL, y VR.  N >= 0.
!>

A

!>          A es array COMPLEX, dimension (LDA, N)
!>          En la entrada, la matriz A del par (A,B).
!>          En la salida, A ha sido sobrescrita. Si JOBVL='V' o JOBVR='V'
!>          o ambas, entonces A contiene la primera parte de la forma de Schur
!>          compleja de las versiones de entrada de A y B.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es array COMPLEX, dimension (LDB, N)
!>          En la entrada, la matriz B del par (A,B).
!>          En la salida, B ha sido sobrescrita. Si JOBVL='V' o JOBVR='V'
!>          o ambas, entonces B contiene la segunda parte de la forma de Schur
!>          compleja de las versiones de entrada de A y B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es array COMPLEX, dimension (N)
!>

BETA

!>          BETA es array COMPLEX, dimension (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los valores propios
!>          generalizados.
!>
!>          Nota: el cociente ALPHA(j)/BETA(j) puede fácilmente desbordar o
!>          subdesbordar, y BETA(j) puede incluso ser cero. Por lo tanto, el
!>          usuario debe evitar calcular ingenuamente el cociente ALPHA/BETA.
!>          Sin embargo, ALPHA siempre será menor y usualmente comparable con
!>          norm(A) en magnitud, y BETA siempre menor y usualmente comparable
!>          con norm(B).
!>

VL

!>          VL es array COMPLEX, dimension (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios generalizados izquierdos u(j) se
!>          almacenan uno tras otro en las columnas de VL, en el mismo orden
!>          que sus valores propios.
!>          Cada vector propio se escalará de manera que el componente más grande
!>          tenga abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es array COMPLEX, dimension (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios generalizados derechos v(j) se
!>          almacenan uno tras otro en las columnas de VR, en el mismo orden
!>          que sus valores propios.
!>          Cada vector propio se escalará de manera que el componente más grande
!>          tenga abs(parte real) + abs(parte imaginaria) = 1.
!>          No referenciado si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI son valores enteros tales que en la salida
!>          A(i,j) = 0 y B(i,j) = 0 si i > j y
!>          j = 1,...,ILO-1 o i = IHI+1,...,N.
!>          Si BALANC = 'N' o 'S', ILO = 1 e IHI = N.
!>

LSCALE

!>          LSCALE es array REAL, dimension (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al lado izquierdo de A y B. Si PL(j) es el índice de la
!>          fila intercambiada con la fila j, y DL(j) es el factor de
!>          escala aplicado a la fila j, entonces
!>            LSCALE(j) =
PL(j) para j = 1,...,ILO-1 !> = DL(j) para j = ILO,...,IHI !> = PL(j) para j = IHI+1,...,N. !> El orden en que se realizan los intercambios es de N a IHI+1, !> luego de 1 a ILO-1. !>

RSCAL

E 
!>          RSCALE es un arreglo REAL, dimensión (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          al lado derecho de A y B. Si PR(j) es el índice de la
!>          columna intercambiada con la columna j, y DR(j) es el factor
!>          de escala aplicado a la columna j, entonces
!>            RSCALE(j) = PR(j)  para j = 1,...,ILO-1
!>                      = DR(j)  para j = ILO,...,IHI
!>                      = PR(j)  para j = IHI+1,...,N
!>          El orden en que se realizan los intercambios es de N a IHI+1,
!>          luego de 1 a ILO-1.
!
>

ABNR

M 
!>          ABNRM es REAL
!>          La norma uno de la matriz balanceada A.
!
>

BBNR

M 
!>          BBNRM es REAL
!>          La norma uno de la matriz balanceada B.
!
>

RCOND

E 
!>          RCONDE es un arreglo REAL, dimensión (N)
!>          Si SENSE = 'E' o 'B', los números de condición recíprocos de
!>          los eigenvalores, almacenados en elementos consecutivos del arreglo.
!>          Si SENSE = 'N' o 'V', RCONDE no se referencia.
!
>

RCOND

V 
!>          RCONDV es un arreglo REAL, dimensión (N)
!>          Si SENSE = 'V' o 'B', los números de condición recíprocos estimados de
!>          los autovectores, almacenados en elementos consecutivos
!>          del arreglo. Si los eigenvalores no pueden reordenarse para
!>          calcular RCONDV(j), RCONDV(j) se establece a 0; esto solo puede ocurrir
!>          cuando el valor real sería muy pequeño de todos modos.
!>          Si SENSE = 'N' o 'E', RCONDV no se referencia.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= max(1,2*N).
!>          Si SENSE = 'E', LWORK >= max(1,4*N).
!>          Si SENSE = 'V' o 'B', LWORK >= max(1,2*N*N+2*N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por parte de XERBLA.
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (lrwork)
!>          lrwork debe ser al menos max(1,6*N) si BALANC = 'S' o 'B',
!>          y al menos max(1,2*N) en caso contrario.
!>          Espacio de trabajo real.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (N+2)
!>          Si SENSE = 'E', IWORK no se referencia.
!
>

BWOR

K 
!>          BWORK es un arreglo LOGICAL, dimensión (N)
!>          Si SENSE = 'N', BWORK no se referencia.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló. No se han calculado autovectores,
!>                pero ALPHA(j) y BETA(j) deberían ser correctos
!>                para j=INFO+1,...,N.
!>          > N:  =N+1: fallo en CHGEQZ distinto a la iteración QZ.
!>                =N+2: retorno de error desde CTGEVC.
!>

Detalles

adicionales: 
!>
!>  Balancear un par de matrices (A,B) incluye, primero, permutar filas y
!>  columnas para aislar eigenvalores, segundo, aplicar una transformación de similitud diagonal
!>  a las filas y columnas para hacer que las filas y columnas
!>  estén lo más cerca posible en norma. Los números de condición recíprocos calculados
!>  corresponden a la matriz balanceada. Permutar filas y columnas
!>  no cambiará los números de condición (en aritmética exacta) pero
!>  el escalamiento diagonal sí lo hará. Para una explicación más detallada del balanceo, véase
!>  la sección 4.11.1.2 de la Guía de Usuarios de LAPACK.
!>
!>  Una cota de error aproximada sobre la distancia cordal entre el i-ésimo
!>  eigenvalor generalizado calculado w y el eigenvalor exacto
!>  correspondiente lambda es
!>
!>       chord(w, lambda) <= EPS * norm(ABNRM, BBNRM) / RCONDE(I)
!>
!>  Una cota de error aproximada para el ángulo entre el i-ésimo
!>  autovector calculado VL(i) o VR(i) viene dada por
!>
!>       EPS * norm(ABNRM, BBNRM) / DIF(i).
!>
!>  Para una explicación más detallada de los números de condición recíprocos RCONDE
!>  y RCONDV, véase la sección 4.11 de la Guía de Usuarios de LAPACK.
!
>
