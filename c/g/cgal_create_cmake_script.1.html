NOMBRE

cgal_create_cmake_script - crea un script de cmake para aplicaciones que usan CGAL

SINOPSIS

cgal_create_cmake_script [ejemplo|demo|test]

DESCRIPCIÓN

El script cgal_create_cmake_script permite la creación sencilla de scripts de cmake para aplicaciones que utilizan la biblioteca CGAL. El parámetro selecciona uno de los tres tipos de script, el tipo predeterminado es ejemplo.

OPCIONES

ejemplo
Crea un script de cmake para varias aplicaciones sencillas. Cada archivo C y cpp en el directorio actual que contenga una función main() se compila y enlaza como un ejecutable separado.
demo
Crea un script de cmake para una única aplicación. Todos los archivos C y cpp en el directorio actual se compilan y enlazan en un ejecutable.
test
Crea un script de cmake que se adapta al conjunto de pruebas utilizado por los desarrolladores de CGAL.

AUTOR

El proyecto CGAL (https://www.cgal.org/).

REPORTE DE ERRORES

Reporte errores a <cgal-discuss@inria.fr> (ver https://www.cgal.org/ para más instrucciones).

VER TAMBIÉN

La documentación completa para CGAL está disponible en https://www.cgal.org/ en formato PDF y HTML.
