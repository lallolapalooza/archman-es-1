CGBSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Documentación de Función/Subrutina

subrutina cgbsvxx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, real, dimension( * ) r, real, dimension( * ) c, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx , * ) x, integer ldx, real rcond, real rpvgrw, real, dimension( * ) berr, integer n_err_bnds, real, dimension( nrhs, * ) err_bnds_norm, real, dimension( nrhs, * ) err_bnds_comp, integer nparams, real, dimension( * ) params, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CGBSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!>    CGBSVXX usa la factorización LU para calcular la solución a un
!>    sistema complejo de ecuaciones lineales A * X = B, donde A es una
!>    matriz N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven tanto límites de error en norma como
!>    límites de error máximos por componente. CGBSVXX devolverá una
!>    solución con un error garantizado minúsculo (O(eps) donde eps es
!>    la precisión de trabajo de la máquina) a menos que la matriz esté
!>    muy mal condicionada, en cuyo caso se devuelve una advertencia.
!>    También se calculan y devuelven los números de condición
!>    relevantes.
!>
!>    CGBSVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; consulte las definiciones de las
!>    opciones FACT y EQUED. Resolver con refinamiento y usando una
!>    factorización de una llamada anterior a CGBSVXX también producirá
!>    una solución con errores O(eps) o advertencias, pero no podemos
!>    hacer esa afirmación para factorizaciones y factores de
!>    equilibrado proporcionados por el usuario si difieren de lo que
!>    CGBSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para
!>    equilibrar el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibra o no depende de la escala de la matriz
!>    A, pero si se usa el equilibrado, A se sobrescribe por
!>    diag(R)*A*diag(C) y B por diag(R)*B (si TRANS='N') o diag(C)*B
!>    (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular
!>    inferior unitaria y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, la
!>    rutina retorna con INFO = i. De lo contrario, la forma factorizada
!>    de A se usa para estimar el número de condición de la matriz A (vea
!>    el argumento RCOND). Si el recíproco del número de condición es
!>    menor que la precisión de la máquina, la rutina continúa igualmente
!>    para resolver X y calcular los límites de error como se describe
!>    a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X usando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca
!>    en cero), la rutina usará refinamiento iterativo para intentar
!>    obtener un error pequeño y límites de error. El refinamiento
!>    calcula el residual con al menos el doble de la precisión de
!>    trabajo.
!>
!>    6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores por defecto son aceptables. Si los
!>     valores por defecto son aceptables, los usuarios pueden pasar
!>     NPARAMS = 0, lo que evita que el código fuente acceda al argumento
!>     PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona a la entrada y, si no, si la matriz A debe
!>     equilibrarse antes de ser factorizada.
!>       = 'F':  A la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transponer)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de miembros independientes, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es un array COMPLEX, dimensión (LDAB,N)
!>     A la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna del
!>     array AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>     Si FACT = 'F' y EQUED no es 'N', entonces AB debe haber sido
!>     equilibrado por los factores de escala en R y/o C. AB no se
!>     modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>     EQUED = 'N' a la salida.
!>
!>     A la salida, si EQUED .ne. 'N', A se escala como sigue:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es un array COMPLEX, dimensión (LDAFB,N)
!>     Si FACT = 'F', entonces AFB es un argumento de entrada y a la entrada
!>     contiene detalles de la factorización LU de la matriz de banda
!>     A, tal como la calcula CGBTRF. U se almacena como una matriz de
!>     banda triangular superior con KL+KU superdiagonales en las filas 1
!>     a KL+KU+1, y los multiplicadores usados durante la factorización
!>     se almacenan en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N, entonces AFB es
!>     la forma factorizada de la matriz equilibrada A.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y al salir
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y al salir
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz equilibrada A (véase la descripción de A para
!>     la forma de la matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y a la entrada
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     tal como los calcula CGETRF; la fila i de la matriz se intercambió
!>     con la fila IPIV(i).
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y al salir
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces IPIV es un argumento de salida y al salir
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz equilibrada A.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre cierto si FACT = 'N').
!>       = 'R':  Equilibrado de filas, es decir, A se ha premultiplicado por
!>               diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A se ha postmultiplicado
!>               por diag(C).
!>       = 'B':  Tanto equilibrado de filas como de columnas, es decir, A ha sido
!>               reemplazada por diag(R) * A * diag(C).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

R

!>          R es un array REAL, dimensión (N)
!>     Los factores de escala de fila para A.  Si EQUED = 'R' o 'B', A se
!>     multiplica por la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede.  R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida.  Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es de salida, cada elemento de R es una potencia de la base.
!>     Si R es de entrada, cada elemento de R debería ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado se desborde por abajo o por arriba. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

C

!>          C es un array REAL, dimensión (N)
!>     Los factores de escala de columna para A.  Si EQUED = 'C' o 'B', A se
!>     multiplica por la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede.  C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida.  Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es de salida, cada elemento de C es una potencia de la base.
!>     Si C es de entrada, cada elemento de C debería ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado se desborde por abajo o por arriba. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>     A la entrada, la matriz del segundo miembro B de dimensiones N-por-NRHS.
!>     A la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe con
!>        diag(R)*B;
!>     si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B se
!>        sobrescribe con diag(C)*B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz solución X de dimensiones N-por-NRHS al sistema
!>     original de ecuaciones.  Tenga en cuenta que A y B se modifican a la salida
!>     si EQUED .ne. 'N', y la solución al sistema equilibrado es
!>     inv(diag(C))*X si TRANS = 'N' y EQUED = 'C' o 'B', o
!>     inv(diag(R))*X si TRANS = 'T' o 'C' y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Número de condición recíproco escalado.  Esta es una estimación del
!>     recíproco del número de condición de Skeel de la matriz A después
!>     del equilibrado (si se hizo).  Si esto es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo.  Tenga en cuenta que el error puede seguir siendo pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

RPVGRW

!>          RPVGRW es REAL
!>     Crecimiento recíproco del pivote.  A la salida, esto contiene el factor
!>     de crecimiento recíproco del pivote norm(A)/norm(U). Se utiliza la
!>     norma infinita.  Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (equilibrada) podría ser deficiente.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y los límites de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento recíproco del pivote
!>     para las primeras INFO columnas de A.  En CGESVX, esta cantidad se
!>     devuelve en RWORK(1).
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>     Error hacia atrás relativo componente a componente.  Este es el
!>     error hacia atrás relativo componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace de X(j) una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada segundo miembro
!>     y cada tipo (en norma o componente a componente).  Véase ERR_BNDS_NORM y
!>     ERR_BNDS_COMP más abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente se devuelven hasta tres piezas de información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la entrada siguiente sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco estimado
!>              del número de condición en norma.  Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación del error es fiable. Estos recíprocos de los números de
!>              condición son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada adecuadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de modo que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Véase la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por el segundo miembro i (del que depende el
!>     error relativo componente a componente), y el tipo de información de
!>     error como se describe a continuación. Actualmente se devuelven hasta tres
!>     piezas de información para cada segundo miembro. Si
!>     no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
!>     no se accede a ERR_BNDS_COMP.  Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la entrada siguiente sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco estimado
!>              del número de condición componente a componente.  Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación del error es fiable. Estos recíprocos de los números de
!>              condición son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas las sumas absolutas
!>              de filas de Z sean aproximadamente 1.
!>
!>     Véase la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS.  Si <= 0, el
!>     array PARAMS nunca se referencia y se utilizan valores predeterminados.
!>

PARAMS

!>          PARAMS es un array REAL, dimensión NPARAMS
!>     Especifica los parámetros del algoritmo.  Si una entrada es < 0.0, entonces
!>     esa entrada será se rellenará con el valor predeterminado utilizado para ese
!>     parámetro.  Solo se accede a las posiciones hasta NPARAMS; se usan
!>     valores predeterminados para los parámetros numerados más altamente.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar refinamiento
!>            iterativo o no.
!>         Predeterminado: 1.0
!>            = 0.0:  No se realiza refinamiento, y no se calculan cotas
!>                    de error.
!>            = 1.0:  Usar el algoritmo de refinamiento de doble
!>                    precisión, posiblemente con cálculos de doble
!>                    simple si el entorno de compilación no soporta
!>                    DOUBLE PRECISION.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de cálculos de
!>            residuo permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecer a 100 para permitir la convergencia usando
!>                     factorizaciones aproximadas o factorizaciones
!>                     distintas de LU. Si la factorización usa una
!>                     técnica distinta de la eliminación gaussiana, las
!>                     garantías en err_bnds_norm y err_bnds_comp pueden
!>                     dejar de ser fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Bandera que determina si el
!>            código intentará encontrar una solución con pequeño error
!>            relativo componente a componente en el algoritmo de doble
!>            precisión.  Positivo es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia componente a
!>         componente)
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (2*N)
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa. La solución para cada segundo miembro
!>         está garantizada.
!>       < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero.  La factorización
!>         ha sido completada, pero el factor U es exactamente singular,
!>         por lo que la solución y las cotas de error no pudieron ser
!>         calculadas. Se devuelve RCOND = 0.
!>       = N+J: La solución correspondiente al J-ésimo segundo miembro no
!>         está garantizada. Las soluciones correspondientes a otros
!>         segundos miembros K con K > J pueden no estar garantizadas
!>         también, pero solo se reporta el primer segundo miembro de
!>         este tipo. Si no se solicita un pequeño error componente a
