subrutina cgbrfs (carácter trans, entero n, entero kl, entero ku, entero nrhs, complejo, dimensión( ldab, * ) ab, entero ldab, complejo, dimensión( ldafb, * ) afb, entero ldafb, entero, dimensión( * ) ipiv, complejo, dimensión( ldb, * ) b, entero ldb, complejo, dimensión( ldx, * ) x, entero ldx, real, dimensión( * ) ferr, real, dimensión( * ) berr, complejo, dimensión( * ) work, real, dimensión( * ) rwork, entero info)

CGBRFS

Propósito:

!>
!> CGBRFS mejora la solución calculada para un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es una matriz banda, y
!> proporciona cotas de error y estimaciones de error hacia atrás
!> para la solución.
!>

Parámetros

TRANS 
!>          TRANS es CARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

KL

!>          KL es ENTERO
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es ENTERO
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es una matriz COMPLEJA, dimensión (LDAB,N)
!>          La matriz de banda original A, almacenada en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna de
!>          la matriz AB de la siguiente manera:
!>          AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku) <= i <= min(n,j+kl).
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal de la matriz AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es una matriz COMPLEJA, dimensión (LDAFB,N)
!>          Detalles de la factorización LU de la matriz de banda A, tal
!>          como se calcula por CGBTRF.  U se almacena como una matriz de
!>          banda triangular superior con KL+KU superdiagonales en las
!>          filas 1 a KL+KU+1, y los multiplicadores utilizados durante
!>          la factorización se almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es ENTERO
!>          La dimensión principal de la matriz AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV es una matriz ENTERA, dimensión (N)
!>          Los índices de pivote de CGBTRF; para 1 <= i <= N, la fila i de la
!>          matriz se intercambió con la fila IPIV(i).
!>

B

!>          B es una matriz COMPLEJA, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

X

!>          X es una matriz COMPLEJA, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como se calculó por CGBTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal de la matriz X.  LDX >= max(1,N).
!>

FERR

!>          FERR es una matriz REAL, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento
!>          más grande en X(j). La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es una matriz REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución
!>          exacta).
!>

WORK

!>          WORK es una matriz COMPLEJA, dimensión (2*N)
!>

RWORK

!>          RWORK es una matriz REAL, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
