SINOPSIS

Funciones/Subrutinas


subrutina cgeqp3rk (m, n, nrhs, kmax, abstol, reltol, a, lda, k, maxc2nrmk, relmaxc2nrmk, jpiv, tau, work, lwork, rwork, iwork, info)
CGEQP3RK calcula una factorización QR truncada de Householder con pivoteo de columnas de una matriz compleja m por n A utilizando BLAS de Nivel 3 y sobrescribe la matriz compleja m por nrhs B con Q**H * B.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina cgeqp3rk (entero m, entero n, entero nrhs, entero kmax, real abstol, real reltol, complejo, dimensión( lda, * ) a, entero lda, entero k, real maxc2nrmk, real relmaxc2nrmk, entero, dimensión( * ) jpiv, complejo, dimensión( * ) tau, complejo, dimensión( * ) work, entero lwork, real, dimensión( * ) rwork, entero, dimensión( * ) iwork, entero info)

CGEQP3RK calcula una factorización QR truncada de Householder con pivoteo de columnas de una matriz compleja m por n A utilizando BLAS de Nivel 3 y sobrescribe la matriz compleja m por nrhs B con Q**H * B.

Propósito:

!>
!> CGEQP3RK realiza dos tareas simultáneamente:
!>
!> Tarea 1: La rutina calcula una factorización QR truncada (de rango K) o de rango completo
!> de Householder con pivoteo de columnas de una matriz compleja
!> M por N A utilizando BLAS de Nivel 3. K es el número de columnas
!> que fueron factorizadas, es decir, el rango de factorización de la
!> factor R, K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_aproximación    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residuo ),
!>
!> donde:
!>
!>  P(K)            es una matriz de permutación N por N;
!>  Q(K)            es una matriz unitaria M por M;
!>  R(K)_aproximación = ( R11(K), R12(K) ) es una aproximación de rango K de la
!>                    factor completa R con R11(K) triangular superior K por K
!>                    y R12(K) rectangular K por N. Las entradas diagonales
!>                    de R11(K) aparecen en orden no creciente de valor absoluto, y los
!>                    valores absolutos de todas ellas superan la norma 2 máxima de columna de R22(K)
!>                    hasta el error de redondeo.
!>  R(K)_residuo = R22(K) es el residuo de una aproximación de rango K
!>                    de la factor completa R. Es una
!>                    matriz rectangular (M-K) por (N-K);
!>  0               es una matriz cero (M-K) por K.
!>
!> Tarea 2: Al mismo tiempo, la rutina sobrescribe una matriz B compleja M por NRHS
!> con Q(K)**H * B utilizando BLAS de Nivel 3.
!>
!> =====================================================================
!>
!> Las matrices A y B se almacenan en la entrada en el array A como
!> los bloques izquierdo y derecho A(1:M,1:N) y A(1:M, N+1:N+NRHS)
!> respectivamente.
!>
!>                                  N     NRHS
!>             array_A   =   M  [ mat_A, mat_B ]
!>
!> Los criterios de truncamiento (es decir, cuándo detener la factorización)
!> pueden ser cualquiera de los siguientes:
!>
!>   1) El parámetro de entrada KMAX, el número máximo de columnas
!>      KMAX a factorizar, es decir, el rango de factorización se limita
!>      a KMAX. Si KMAX >= min(M,N), el criterio no se utiliza.
!>
!>   2) El parámetro de entrada ABSTOL, la tolerancia absoluta para
!>      la norma 2 máxima de columna de la matriz residual R22(K). Esto
!>      significa que la factorización se detiene si esta norma es menor o
!>      igual a ABSTOL. Si ABSTOL < 0.0, el criterio no se utiliza.
!>
!>   3) El parámetro de entrada RELTOL, la tolerancia para la norma 2 máxima de
!>      columna de la matriz residual R22(K) dividida por la norma 2 máxima de
!>      columna de la matriz original A, que
!>      es igual a abs(R(1,1)). Esto significa que la factorización se detiene
!>      cuando la relación de la norma 2 máxima de columna de R22(K) a
!>      la norma 2 máxima de columna de A es menor o igual a RELTOL.
!>      Si RELTOL < 0.0, el criterio no se utiliza.
!>
!>   4) En caso de que los criterios de parada ABSTOL o RELTOL no se utilicen,
!>      y cuando la matriz residual R22(K) es una matriz cero en algún
!>      paso de factorización K. (Este criterio de parada es implícito.)
!>
!>  El algoritmo se detiene cuando se satisface cualquiera de estas condiciones
!>  por primera vez, de lo contrario, se factoriza la matriz A completa.
!>
!>  Para factorizar la matriz A completa, utilice los valores
!>  KMAX >= min(M,N), ABSTOL < 0.0 y RELTOL < 0.0.
!>
!>  La rutina devuelve:
!>     a) Q(K), R(K)_aproximación = ( R11(K), R12(K) ),
!>        R(K)_residuo = R22(K), P(K), es decir, las matrices resultantes
!>        de la factorización; P(K) se representa por JPIV,
!>        ( si K = min(M,N), R(K)_aproximación es la factor completa R,
!>        y no hay matriz residual R(K)_residuo);
!>     b) K, el número de columnas que fueron factorizadas,
!>        es decir, rango de factorización;
!>     c) MAXC2NRMK, la norma 2 máxima de columna del residual
!>        matriz R(K)_residuo = R22(K),
!>        ( si K = min(M,N), MAXC2NRMK = 0.0 );
!>     d) RELMAXC2NRMK igual a MAXC2NRMK dividido por MAXC2NRM, la norma 2 máxima de
!>        columna de la matriz original A, que es igual
!>        a abs(R(1,1)), ( si K = min(M,N), RELMAXC2NRMK = 0.0 );
!>     e) Q(K)**H * B, la matriz B con la transformación unitaria
!>        Q(K)**H aplicada a la izquierda.
!>
!> La matriz de permutación N por N P(K) se almacena en forma compacta en
!> el array de enteros JPIV. Para 1 <= j <= N, la columna j
!> de la matriz A se intercambió con la columna JPIV(j).
!>
!> La matriz unitaria M por M Q se representa como un producto
!> de reflectores elementales de Householder
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K),
!>
!> donde K es el número de columnas que fueron factorizadas.
!>
!> Cada H(j) tiene la forma
!>
!>     H(j) = I - tau * v * v**H,
!>
!> donde 1 <= j <= K y
!>   I    es una matriz identidad M por M,
!>   tau  es un escalar complejo,
!>   v    es un vector complejo con v(1:j-1) = 0 y v(j) = 1.
!>
!> v(j+1:M) se almacena en la salida en A(j+1:M,j) y tau en TAU(j).
!>
!> Ver la sección Detalles Adicionales para más información.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

KMAX

!>          KMAX es ENTERO
!>
!>          El primer criterio de parada de la factorización. KMAX >= 0.
!>
!>          El número máximo de columnas de la matriz A a factorizar,
!>          es decir, el rango máximo de factorización.
!>
!>          a) Si KMAX >= min(M,N), entonces este criterio de parada
!>                no se utiliza, la rutina factoriza columnas
!>                dependiendo de ABSTOL y RELTOL.
!>
!>          b) Si KMAX = 0, entonces este criterio de parada se
!>                satisface en la entrada y la rutina sale inmediatamente.
!>                Esto significa que la factorización no se realiza,
!>                las matrices A y B no se modifican, y
!>                la matriz A es en sí misma el residuo.

!>
!>          b) Si ABSTOL < 0.0, entonces este criterio de parada no se

RELTOL

!>          RELTOL es REAL
!>
!>          El tercer criterio de parada de la factorización, no puede ser NaN.
!>
!>          La tolerancia (umbral de parada) para la relación
!>          abs(R(K+1,K+1))/abs(R(1,1)) de la norma 2 máxima de columna de
!>          la matriz residuo R22(K) a la norma 2 máxima de columna de
!>          la matriz original A. El algoritmo converge (detiene la
!>          factorización), cuando abs(R(K+1,K+1))/abs(R(1,1)) A es menor
!>          o igual que RELTOL. Sea EPS = DLAMCH('E').
!>
!>          a) Si RELTOL es NaN, entonces no se realiza ningún cálculo
!>                y se emite un mensaje de error ( INFO = -6 )
!>                por XERBLA.
!>
!>          b) Si RELTOL < 0.0, entonces este criterio de parada no se
!>                usa, la rutina factoriza columnas dependiendo
!>                de KMAX y ABSTOL.
!>                Esto incluye el caso RELTOL = -Inf.
!>
!>          c) Si 0.0 <= RELTOL < EPS, entonces se usa RELTOL = EPS.
!>                Esto incluye el caso RELTOL = -0.0.
!>
!>          d) Si EPS <= RELTOL, entonces se usa el valor de entrada de RELTOL.
!>
!>          Sea MAXC2NRM la norma 2 máxima de columna de
!>          toda la matriz original A.
!>          Si el RELTOL elegido anteriormente es >= 1.0, entonces este
!>          criterio de parada se satisface en la entrada y la rutina sale
!>          inmediatamente después de que se calcula MAXC2NRM.
!>          La rutina devuelve MAXC2NRM en MAXC2NORMK,
!>          y 1.0 en RELMAXC2NORMK.
!>          Esto incluye el caso RELTOL = +Inf. Esto significa que la
!>          factorización no se realiza, las matrices A y B no se
!>          modifican, y la matriz A es en sí misma el residuo.
!>
!>          NOTA: Recomendamos que RELTOL satisfaga
!>                min( 10*max(M,N)*EPS, sqrt(EPS) ) <= RELTOL
!>

A

!>          A es un arreglo COMPLEX, dimensión (LDA,N+NRHS)
!>
!>          En la entrada:
!>
!>          a) El subarreglo A(1:M,1:N) contiene la matriz A de M-por-N.
!>          b) El subarreglo A(1:M,N+1:N+NRHS) contiene la matriz B
!>             de M-por-NRHS.
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          En la salida:
!>
!>          a) El subarreglo A(1:M,1:N) contiene partes de los factores
!>             de la matriz A:
!>
!>            1) Si K = 0, A(1:M,1:N) contiene la matriz original A.
!>            2) Si K > 0, A(1:M,1:N) contiene partes de los
!>            factores:
!>
!>              1. Los elementos por debajo de la diagonal del subarreglo
!>                 A(1:M,1:K) junto con TAU(1:K) representan la
!>                 matriz unitaria Q(K) como un producto de K reflectores
!>                 elementales de Householder.
!>
!>              2. Los elementos en y por encima de la diagonal de
!>                 el subarreglo A(1:K,1:N) contienen la matriz
!>                 trapecio superior K-por-N
!>                 R(K)_aprox = ( R11(K), R12(K) ).
!>                 NOTA: Si K=min(M,N), es decir, factorización de rango completo,
!>                       entonces R_aprox(K) es el factor completo R que
!>                       es trapecio superior. Si, además, M>=N,
!>                       entonces R es triangular superior.
!>
!>              3. El subarreglo A(K+1:M,K+1:N) contiene la matriz
!>                 rectangular (M-K)-por-(N-K)
!>                 R(K)_residuo = R22(K).
!>
!>          b) Si NRHS > 0, el subarreglo A(1:M,N+1:N+NRHS) contiene
!>             el producto M-por-NRHS Q(K)**H * B.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,M).
!>          Esta es la dimensión principal para ambas matrices, A y B.
!>

K

!>          K es INTEGER
!>          Rango de factorización de la matriz A, es decir, el rango de
!>          el factor R, que es el mismo que el número de filas no nulas
!>          del factor R. 0 <= K <= min(M,KMAX,N).
!>
!>          K también representa el número de vectores de Householder
!>          no nulos.
!>
!>          NOTA: Si K = 0, a) los arreglos A y B no se modifican;
!>                          b) el arreglo TAU(1:min(M,N)) se establece en CERO,
!>                             si la matriz A no contiene NaN,
!>                             de lo contrario los elementos TAU(1:min(M,N))
!>                             son indefinidos;
!>                          c) los elementos del arreglo JPIV se establecen
!>                             de la siguiente manera: para j = 1:N, JPIV(j) = j.
!>

MAXC2NRMK

!>          MAXC2NRMK es REAL
!>          La norma 2 máxima de columna de la matriz residuo R22(K),
!>          cuando la factorización se detuvo en el rango K. MAXC2NRMK >= 0.
!>
!>          a) Si K = 0, es decir, la factorización no se realizó,
!>             la matriz A no se modificó y es en sí misma una matriz
!>             residuo, entonces MAXC2NRMK es igual a la norma 2 máxima
!>             de columna de la matriz original A.
!>
!>          b) Si 0 < K < min(M,N), entonces se devuelve MAXC2NRMK.
!>
!>          c) Si K = min(M,N), es decir, toda la matriz A fue
!>             factorizada y no hay matriz residuo,
!>             entonces MAXC2NRMK = 0.0.
!>
!>          NOTA: MAXC2NRMK en el paso de factorización K sería igual
!>                a R(K+1,K+1) en el siguiente paso de factorización K+1.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK es REAL
!>          La relación MAXC2NRMK / MAXC2NRM de la norma 2 máxima
!>          de columna de la matriz residuo R22(K) (cuando la factorización
!>          se detuvo en el rango K) a la norma 2 máxima de columna de
!>          toda la matriz original A. RELMAXC2NRMK >= 0.
!>
!>          a) Si K = 0, es decir, la factorización no se realizó,
!>             la matriz A no se modificó y es en sí misma una matriz
!>             residuo, entonces RELMAXC2NRMK = 1.0.
!>
!>          b) Si 0 < K < min(M,N), entonces
!>                se devuelve RELMAXC2NRMK = MAXC2NRMK / MAXC2NRM.
!>
!>          c) Si K = min(M,N), es decir, toda la matriz A fue
!>             factorizada y no hay matriz residuo,
!>             entonces RELMAXC2NRMK = 0.0.
!>
!>         NOTA: RELMAXC2NRMK en el paso de factorización K sería igual
!>               a abs(R(K+1,K+1))/abs(R(1,1)) en el siguiente paso de
!>               factorización K+1.
!>

JPIV

!>          JPIV es un arreglo INTEGER, dimensión (N)
!>          Índices de pivote de columna. Para 1 <= j <= N, la columna j
!>          de la matriz A se intercambió con la columna JPIV(j).
!>
!>          Los elementos del arreglo JPIV(1:N) siempre son establecidos
!>          por la rutina, por ejemplo, incluso cuando no se factorizaron
!>          columnas, es decir, cuando K = 0, los elementos se
!>          establecen como JPIV(j) = j para j = 1:N.
!>

TAU

!>          TAU es un arreglo COMPLEX, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales.
!>
!>          Si 0 < K <= min(M,N), solo los elementos TAU(1:K) del
!>          arreglo TAU son modificados por la factorización.
!>          Después de calcular la factorización, si no se encontró
!>          ningún NaN durante la factorización, los elementos restantes
!>          TAU(K+1:min(M,N)) se establecen en cero, de lo contrario los
!>          elementos TAU(K+1:min(M,N)) no se establecen y por lo tanto
!>          son indefinidos.
!>          ( Si K = 0, todos los elementos de TAU se establecen en cero, si
!>          la matriz A no contiene NaN. )
!>

WORK

!>          WORK es un arreglo COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y
!>          LWORK >= N+NRHS-1, en caso contrario.
!>          Para un rendimiento óptimo LWORK >= NB*( N+NRHS+1 ),
!>          donde NB es el tamaño de bloque óptimo para CGEQP3RK
!>          devuelto por ILAENV. Tamaño de bloque mínimo MINNB=2.
!>
!>          NOTA: La decisión de si usar código BLAS 2 sin bloquear
!>          o código BLAS 3 con bloquear se basa no solo en la dimensión
!>          LWORK del espacio de trabajo disponible WORK, sino también en la
!>          dimensión N de la matriz A a través del punto de cruce NX devuelto
!>          por ILAENV. (Para N menor que NX, se debe usar el código sin bloquear.)
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del arreglo
!>          WORK, devuelve este valor como la primera entrada del arreglo
!>          WORK, y no se emite ningún mensaje de error relacionado con LWORK
!>          por XERBLA.
!>

RWORK

!>          RWORK es un arreglo REAL, dimensión (2*N)
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (N-1).
!>          Es un arreglo de trabajo. ( IWORK se usa para almacenar índices
!>          de columnas para la actualización descendente de normas en la
!>          matriz residuo en el subrutina auxiliar del paso con bloquear CLAQP3RK ).
!>

INFO

!>          INFO es INTEGER
!>          1) INFO = 0: salida exitosa.
!>          2) INFO < 0: si INFO = -i, el i-ésimo argumento tenía un
!>                       valor ilegal.
!>          3) Si INFO = j_1, donde 1 <= j_1 <= N, entonces se detectó
!>             NaN y la rutina detiene el cálculo.
!>             La j_1-ésima columna de la matriz A o el j_1-ésimo
!>             elemento del arreglo TAU contiene la primera aparición
!>             de NaN en el paso de factorización K+1 (cuando K columnas
!>             han sido factorizadas).
!>
!>             En la salida:
!>             K                  se establece al número de
!>                                   columnas factorizadas sin
!>                                   excepción.
!>             MAXC2NRMK          se establece en NaN.
!>             RELMAXC2NRMK       se establece en NaN.
!>             TAU(K+1:min(M,N))  no se establece y contiene elementos
!>                                   indefinidos. Si j_1=K+1, TAU(K+1)
!>                                   puede contener NaN.
!>          4) Si INFO = j_2, donde N+1 <= j_2 <= 2*N, entonces no se detectó
!>             NaN, pero se detectó +Inf (o -Inf) y             la rutina continúa el cálculo hasta su finalización.
!>             La columna (j_2-N) de la matriz A contiene la primera
!>             aparición de +Inf (o -Inf) en el paso de factorización
!>             K+1 (cuando se han factorizado K columnas).
!>

Detalles adicionales:

!> CGEQP3RK se basa en el mismo algoritmo de factorización QR de Householder BLAS3
!> con pivoteo de columnas que en la rutina CGEQP3, la cual utiliza
!> la rutina CLARFG para generar reflectores de Householder
!> para la factorización QR.
!>
!> También podemos escribir:
!>
!>   A = A_approx(K) + A_residual(K)
!>
!> La matriz de aproximación de bajo rango A(K)_approx de
!> la factorización QR truncada de rango K de la matriz A es:
!>
!>   A(K)_approx = Q(K) * ( R(K)_approx ) * P(K)**T
!>                        (     0     0 )
!>
!>               = Q(K) * ( R11(K) R12(K) ) * P(K)**T
!>                        (      0      0 )
!>
!> El residuo A_residual(K) de la matriz A es:
!>
!>   A_residual(K) = Q(K) * ( 0              0 ) * P(K)**T =
!>                          ( 0  R(K)_residual )
!>
!>                 = Q(K) * ( 0        0 ) * P(K)**T
!>                          ( 0   R22(K) )
!>
!> La factorización truncada (de rango K) garantiza que
!> la norma 2 máxima de columna de A_residual(K) es menor que
!> o igual a MAXC2NRMK hasta el error de redondeo.
!>
!> NOTA: Una aproximación de los vectores nulos
!>       de A puede calcularse fácilmente a partir de R11(K)
!>       y R12(K):
!>
!>       Null( A(K) )_approx = P * ( inv(R11(K)) * R12(K) )
!>                                 (         -I           )
!>
