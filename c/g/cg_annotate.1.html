NOMBRE

cg_annotate - herramienta de post-procesamiento para Cachegrind

SINOPSIS

cg_annotate [opciones] archivo-de-salida-cachegrind [archivos-fuente...]

DESCRIPCIÓN

cg_annotate toma uno o más archivos de salida de Cachegrind e imprime datos sobre el programa perfilado en un formato fácil de leer.

OPCIONES

-h --help

Muestra el mensaje de ayuda.

--version

Muestra el número de versión.

--diff

Compara dos archivos de salida de Cachegrind.

--mod-filename <regex> [predeterminado: ninguno]

Especifica una expresión de búsqueda y reemplazo s/viejo/nuevo/ que se aplica a todos los nombres de archivo. Útil al comparar, para eliminar diferencias menores en las rutas entre dos versiones diferentes de un programa que se encuentran en directorios distintos. Un sufijo i hace que la expresión regular no distinga entre mayúsculas y minúsculas, y un sufijo g hace que coincida varias veces.

--mod-funcname <regex> [predeterminado: ninguno]

Similar a --mod-filename, pero para nombres de archivo. Útil para eliminar diferencias menores en los nombres aleatorios de funciones autogeneradas por algunos compiladores.

--show=A,B,C [predeterminado: todas, usando el orden en el archivo de salida de Cachegrind]

Especifica qué eventos mostrar (y el orden de las columnas). El valor predeterminado es usar todos los presentes en el archivo de salida de Cachegrind (y usar el orden en el archivo). Mejor usar en combinación con --sort.

--sort=A,B,C [predeterminado: orden en el archivo de salida de Cachegrind]

Especifica los eventos sobre los cuales se basará la ordenación de las entradas archivo:función y función:archivo.

--threshold=X [predeterminado: 0.1%]

Establece el umbral de significancia para las secciones archivo:función y función:archivos. Un archivo o función se muestra si representa más del X% de los recuentos para el evento de ordenación principal. Si se anotan archivos fuente, esto también afecta qué archivos se anotan.

--show-percs, --no-show-percs, --show-percs=<no|yes> [predeterminado: yes]

Cuando está habilitado, se imprime un porcentaje junto a todos los recuentos de eventos. Esto ayuda a evaluar la importancia relativa de cada función y línea.

--annotate, --no-annotate, --auto=<no|yes> [predeterminado: yes]

Habilita o deshabilita la anotación del archivo fuente.

--context=N [predeterminado: 8]

El número de líneas de contexto a mostrar antes y después de cada línea anotada. Use un número grande (por ejemplo, 100000) para mostrar todas las líneas de código fuente.

VER TAMBIÉN

valgrind(1), $INSTALL/share/doc/valgrind/html/index.html o http://www.valgrind.org/docs/manual/index.html.
