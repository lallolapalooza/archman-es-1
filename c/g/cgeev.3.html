CGEEV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Documentación de la Función/Subrutina

subrutina cgeev (caracter jobvl, caracter jobvr, entero n, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( * ) w, complejo, dimensión( ldvl, * ) vl, entero ldvl, complejo, dimensión( ldvr, * ) vr, entero ldvr, complejo, dimensión( * ) work, entero lwork, real, dimensión( * ) rwork, entero info)

CGEEV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices GE

Propósito:

!>
!> CGEEV calcula para una matriz compleja no simétrica N por N, A, los
!> valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos.
!>
!> El vector propio derecho v(j) de A satisface
!>                  A * v(j) = lambda(j) * v(j)
!> donde lambda(j) es su valor propio.
!> El vector propio izquierdo u(j) de A satisface
!>               u(j)**H * A = lambda(j) * u(j)**H
!> donde u(j)**H denota la transpuesta conjugada de u(j).
!>
!> Los vectores propios calculados se normalizan para tener una norma Euclidiana
!> igual a 1 y el componente más grande real.
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N': los vectores propios izquierdos de A no se calculan;
!>          = 'V': los vectores propios izquierdos de A se calculan.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N': los vectores propios derechos de A no se calculan;
!>          = 'V': los vectores propios derechos de A se calculan.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>          En la entrada, la matriz N por N A.
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

W

!>          W es un array COMPLEJO, de dimensión (N)
!>          W contiene los valores propios calculados.
!>

VL

!>          VL es un array COMPLEJO, de dimensión (LDVL,N)
!>          Si JOBVL = 'V', los vectores propios izquierdos u(j) se almacenan uno
!>          después de otro en las columnas de VL, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVL = 'N', VL no se referencia.
!>          u(j) = VL(:,j), la j-ésima columna de VL.
!>

LDVL

!>          LDVL es ENTERO
!>          La dimensión principal del array VL.  LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEJO, de dimensión (LDVR,N)
!>          Si JOBVR = 'V', los vectores propios derechos v(j) se almacenan uno
!>          después de otro en las columnas de VR, en el mismo orden
!>          que sus valores propios.
!>          Si JOBVR = 'N', VR no se referencia.
!>          v(j) = VR(:,j), la j-ésima columna de VR.
!>

LDVR

!>          LDVR es ENTERO
!>          La dimensión principal del array VR.  LDVR >= 1; si
!>          JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.  LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          sólo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (2*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo QR no pudo calcular todos los
!>                valores propios, y no se han calculado vectores propios;
!>                los elementos i+1:N de W contienen valores propios que han
!>                convergido.
!>
