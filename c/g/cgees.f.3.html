Documentación de Función/Subrutin

subrutina cgees (character jobvs, character sort, external select, integer n, complex, dimension( lda, * ) a, integer lda, integer sdim, complex, dimension( * ) w, complex, dimension( ldvs, * ) vs, integer ldvs, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, logical, dimension( * ) bwork, integer

info)

CGEES calcula los eigenvalores, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices

GE

Propósito

: 
!>
!> CGEES calcula para una matriz compleja no simétrica A de N por N, los
!> eigenvalores, la forma de Schur T y, opcionalmente, la matriz de vectores
!> de Schur Z. Esto proporciona la factorización de Schur A = Z*T*(Z**H).
!>
!> Opcionalmente, también ordena los eigenvalores en la diagonal de la
!> forma de Schur de modo que los eigenvalores seleccionados estén en la
!> parte superior izquierda. Las columnas principales de Z forman entonces
!> una base ortonormal para el subespacio invariante correspondiente a los
!> eigenvalores seleccionados.
!>
!> Una matriz compleja está en forma de Schur si es triangular superior.
!
>

Parámetro

s
JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': no se calculan los vectores de Schur;
!>          = 'V': se calculan los vectores de Schur.
!
>

SOR

T 
!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los eigenvalores en la
!>          diagonal de la forma de Schur.
!>          = 'N': no se ordenan los eigenvalores:
!>          = 'S': se ordenan los eigenvalores (véase SELECT).
!
>

SELEC

T 
!>          SELECT es una FUNCIÓN LÓGICA de un argumento COMPLEJO
!>          SELECT debe declararse EXTERNAL en la subrutina que la llama.
!>          Si SORT = 'S', SELECT se utiliza para seleccionar los eigenvalores
!>          a ordenar en la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', no se hace referencia a SELECT.
!>          El eigenvalor W(j) se selecciona si SELECT(W(j)) es verdadero.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!
>

A 
!>          A es un arreglo COMPLEJO, dimensión (LDA,N)
!>          A la entrada, la matriz A de N por N.
!>          A la salida, A ha sido sobrescrita por su forma de Schur T.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!
>

SDI

M 
!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de eigenvalores para los cuales
!>                         SELECT es verdadero.
!
>

W 
!>          W es un arreglo COMPLEJO, dimensión (N)
!>          W contiene los eigenvalores calculados, en el mismo orden en que
!>          aparecen en la diagonal de la forma de Schur de salida T.
!
>

V

S 
!>          VS es un arreglo COMPLEJO, dimensión (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz unitaria Z de vectores
!>          de Schur.
!>          Si JOBVS = 'N', no se hace referencia a VS.
!
>

LDV

S 
!>          LDVS es INTEGER
!>          La dimensión principal del arreglo VS.  LDVS >= 1; si
!>          JOBVS = 'V', LDVS >= N.
!
>

WOR

K 
!>          WORK es un arreglo COMPLEJO, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.  LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!
>

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (N)
!
>

BWOR

K 
!>          BWORK es un arreglo LÓGICO, dimensión (N)
!>          No se hace referencia si SORT = 'N'.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si INFO = i, y i es
!>               <= N:  el algoritmo QR falló al calcular todos los
!>                      eigenvalores; los elementos 1:ILO-1 y i+1:N de W
!>                      contienen aquellos eigenvalores que han convergido;
!>                      si JOBVS = 'V', VS contiene la matriz que
!>                      reduce A a su forma de Schur parcialmente convergida.
!>               = N+1: los eigenvalores no pudieron reordenarse porque
!>                      algunos eigenvalores estaban demasiado cerca para
!>                      separarse (el problema está muy mal condicionado);
!>               = N+2: después de reordenar, el redondeo cambió valores de
!>                      algunos eigenvalores complejos de modo que los
!>                      eigenvalores principales en la forma de Schur ya no
!>                      satisfacen SELECT = .TRUE.. Esto también podría ser
!>                      causado por desbordamiento inferior debido al
!>                      escalado.
!
>
