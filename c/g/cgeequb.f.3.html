Documentación de Función/Subrutina

subrutina cgeequb (integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) r, real, dimension( * ) c, real rowcnd, real colcnd, real amax, integer info)

CGEEQUB

Propósito:

!>
!> CGEEQUB calcula los factores de escala de filas y columnas destinados a
!> equilibrar una matriz M por N, A, y reducir su número de condición. R devuelve
!> los factores de escala de filas y C los factores de escala de columnas, elegidos
!> para intentar que el elemento más grande en cada fila y columna de la matriz B,
!> con elementos B(i,j)=R(i)*A(i,j)*C(j), tenga un valor absoluto de como máximo
!> la base (radix).
!>
!> R(i) y C(j) están restringidos a ser una potencia de la base entre
!> SMLNUM = número seguro más pequeño y BIGNUM = número seguro más grande. El uso
!> de estos factores de escala no garantiza la reducción del número de condición
!> de A, pero funciona bien en la práctica.
!>
!> Esta rutina difiere de CGEEQU al restringir los factores de escala
!> a una potencia de la base. Salvo desbordamiento superior e inferior,
!> el escalado por estos factores no introduce errores de redondeo adicionales.
!> Sin embargo, las magnitudes de las entradas escaladas ya no son aproximadamente 1,
!> sino que se encuentran entre sqrt(base) y 1/sqrt(base).
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX, dimension (LDA,N)
!>          La matriz M por N cuyos factores de equilibrado se
!>          van a calcular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

R

!>          R es un array REAL, dimension (M)
!>          Si INFO = 0 o INFO > M, R contiene los factores de escala de
!>          fila para A.
!>

C

!>          C es un array REAL, dimension (N)
!>          Si INFO = 0, C contiene los factores de escala de columna para A.
!>

ROWCND

!>          ROWCND es REAL
!>          Si INFO = 0 o INFO > M, ROWCND contiene la relación entre el
!>          R(i) más pequeño y el R(i) más grande. Si ROWCND >= 0.1 y
!>          AMAX no es ni demasiado grande ni demasiado pequeño, no merece la
!>          pena escalar con R.
!>

COLCND

!>          COLCND es REAL
!>          Si INFO = 0, COLCND contiene la relación entre el
!>          C(i) más pequeño y el C(i) más grande. Si COLCND >= 0.1, no merece la
!>          pena escalar con C.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento matricial más grande. Si AMAX está muy
!>          cerca del desbordamiento o muy cerca del subdesbordamiento, la matriz
!>          debería escalarse.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= M:  la i-ésima fila de A es exactamente cero
!>                >  M:  la (i-M)-ésima columna de A es exactamente cero
!>
