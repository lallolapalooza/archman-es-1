El -lang argumento se utiliza para incorporar un atributo de idioma en la etiqueta <html>. Por ejemplo:

El único propósito de esta declaración es declarar la codificación del juego de caracteres. El valor predeterminado para -declare_xml es falso.

JAVASCRIPTING: Los -script, -noScript, -onLoad, -onMouseOver, -onMouseOut y -onUnload parámetros se utilizan para agregar llamadas de JavaScript a sus páginas. -script debe apuntar a un bloque de texto que contenga definiciones de funciones JavaScript. Este bloque se colocará dentro de un bloque <script> dentro de la cabecera HTML (no HTTP). El bloque se coloca en la cabecera para dar a su página una oportunidad de tener todas sus funciones JavaScript en su lugar incluso si el usuario presiona el botón de detener antes de que la página se haya cargado completamente. CGI.pm intenta formatear el script de tal manera que los navegadores que no conocen JavaScript no se ahoguen con el código: desafortunadamente hay algunos navegadores que se confunden con él de todos modos.

Los -onLoad y -onUnload parámetros apuntan a fragmentos de código JavaScript para ejecutar cuando la página es abierta y cerrada respectivamente por el navegador. Usualmente estos parámetros son llamadas a funciones definidas en el -script campo:

$q = CGI->new;
print header;
$JSCRIPT = <<END;
    // Ask a silly question
    function riddle_me_this() {
        var r = prompt(
            "What walks on four legs in the morning, " +
            "two legs in the afternoon, " +
            "and three legs in the evening?"
        );
        response(r);
    }
    // Get a silly answer
    function response(answer) {
        if (answer == "man")
            alert("Right you are!");
        else
            alert("Wrong!  Guess again.");
    }
END
print start_html(
    -title  => 'The Riddle of the Sphinx',
    -script => $JSCRIPT
);

Use el -noScript parámetro para pasar algo de texto HTML que se mostrará en los navegadores que no tienen JavaScript (o en los navegadores donde JavaScript está desactivado).

La etiqueta <script> tiene varios atributos, incluyendo "type", "charset" y "src". "src" le permite mantener el código JavaScript en un archivo externo. Para usar estos atributos, pase una referencia HASH en el -script parámetro que contenga uno o más de -type, -src o -code:

print $q->start_html(
    -title  => 'The Riddle of the Sphinx',
    -script => {
        -type => 'JAVASCRIPT',
        -src  => '/javascript/sphinx.js'}
    );
print $q->(
    -title  => 'The Riddle of the Sphinx',
    -script => {
        -type => 'PERLSCRIPT',
        -code => 'print "hello world!\n;"'
    }
);

Una característica final le permite incorporar múltiples secciones <script> en la cabecera. Simplemente pase la lista de secciones de script como una referencia a un array. Esto le permite especificar archivos fuente diferentes para diferentes dialectos de JavaScript. Ejemplo:

print $q->start_html(
    -title  => 'The Riddle of the Sphinx',
    -script => [
        {
            -type => 'text/javascript',
            -src  => '/javascript/utilities10.js'
        },
        {
            -type => 'text/javascript',
            -src  => '/javascript/utilities11.js'
        },
        {
            -type => 'text/jscript',
            -src  => '/javascript/utilities12.js'
        },
        {
            -type => 'text/ecmascript',
            -src  => '/javascript/utilities219.js'
        }
    ]
);

CREANDO ELEMENTOS HTML ESTÁNDAR:

CGI.pm define métodos de atajo HTML generales para muchas etiquetas HTML. Los atajos HTML se nombran después de un solo elemento HTML y devuelven un fragmento de texto HTML. Ejemplo:

print $q->blockquote(
                  "Many years ago on the island of",
                  $q->a({href=>"http://crete.org/"},"Crete"),
                  "there lived a Minotaur named",
                  $q->strong("Fred."),
                 ),
    $q->hr;

Esto resulta en el siguiente código HTML (se han agregado saltos de línea extra para mejorar la legibilidad):

<blockquote>
Many years ago on the island of
<a href="http://crete.org/">Crete</a> there lived
a minotaur named <strong>Fred.</strong> 
</blockquote>
<hr>

Si encuentra que la sintaxis para llamar a los atajos HTML es incómoda, puede importarlos a su espacio de nombres y prescindir por completo de la sintaxis de objetos (consulte la siguiente sección para obtener más detalles):

use CGI ':standard';
print blockquote(
   "Many years ago on the island of",
   a({href=>"http://crete.org/"},"Crete"),
   "there lived a minotaur named",
   strong("Fred."),
   ),
   hr;

Proporcionando argumentos a los atajos HTML

Los métodos HTML aceptarán cero, uno o múltiples argumentos. Si no proporciona argumentos, obtiene una sola etiqueta:

print hr;    #  <hr>

Si proporciona uno o más argumentos de cadena, se concatenan juntos con espacios y se colocan entre las etiquetas de apertura y cierre:

print h1("Chapter","1"); # <h1>Chapter 1</h1>"

Si el primer argumento es una referencia a un hash, entonces las claves y los valores del hash se convierten en los atributos de la etiqueta HTML:

print a({-href=>'fred.html',-target=>'_new'},
   "Open a new frame");
         <a href="fred.html",target="_new">Open a new frame</a>

Puede prescindir de los guiones delante de los nombres de los atributos si lo prefiere:

print img {src=>'fred.gif',align=>'LEFT'};
        <img align="LEFT" src="fred.gif">

A veces un atributo de etiqueta HTML no tiene argumento. Por ejemplo, las listas ordenadas pueden marcarse como COMPACT. La sintaxis para esto es un argumento que apunta a una cadena undef:

print ol({compact=>undef},li('one'),li('two'),li('three'));

Antes de la versión 2.41 de CGI.pm, proporcionar una cadena vacía ('') como argumento de atributo era lo mismo que proporcionar undef. Sin embargo, esto ha cambiado para acomodar a aquellos que quieren crear etiquetas de la forma <img alt="">. La diferencia se muestra en estos dos fragmentos de código:

CODE                   RESULT
img({alt=>undef})      <img alt>
img({alt=>''})         <img alt="">

La propiedad distributiva de los atajos HTML

Una de las características geniales de los atajos HTML es que son distributivos. Si les da un argumento que consiste en una referencia a una lista, la etiqueta se distribuirá a través de cada elemento de la lista. Por ejemplo, aquí hay una forma de hacer una lista ordenada:

print ul(
          li({-type=>'disc'},['Sneezy','Doc','Sleepy','Happy'])
        );

Este ejemplo producirá una salida HTML que se verá así:

<ul>
  <li type="disc">Sneezy</li>
  <li type="disc">Doc</li>
  <li type="disc">Sleepy</li>
  <li type="disc">Happy</li>
</ul>

Esto es extremadamente útil para crear tablas. Por ejemplo:

print table({-border=>undef},
        caption('When Should You Eat Your Vegetables?'),
        Tr({-align=>'CENTER',-valign=>'TOP'},
        [
           th(['Vegetable', 'Breakfast','Lunch','Dinner']),
           td(['Tomatoes' , 'no', 'yes', 'yes']),
           td(['Broccoli' , 'no', 'no',  'yes']),
           td(['Onions'   , 'yes','yes', 'yes'])
        ]
        )
     );

Atajos de HTML e interpolación de listas

Considere este fragmento de código:

print blockquote(em('Hi'),'mom!'));

Normalmente devolverá la cadena que probablemente espera, a saber:

<blockquote><em>Hi</em> mom!</blockquote>

Note el espacio entre el elemento "Hi" y el elemento "mom!". CGI.pm coloca el espacio adicional allí usando la interpolación de arreglos, la cual está controlada por la mágica variable $". A veces este espacio adicional no es lo que desea, por ejemplo, cuando está intentando alinear una serie de imágenes. En este caso, simplemente puede cambiar el valor de $" a una cadena vacía.

{
   local($") = '';
   print blockquote(em('Hi'),'mom!'));
 }

Le sugiero que ponga el código en un bloque como se muestra aquí. De lo contrario, el cambio en $" afectará a todo el código posterior hasta que usted lo restablezca explícitamente.

comment() genera un comentario HTML (<!-- comment -->). Llámelo así:

print comment('here is my comment');

Debido a conflictos con funciones incorporadas de Perl, las siguientes funciones comienzan con mayúscula inicial:

Select

Además, start_html(), end_html(), start_form(), end_form(), start_multipart_form() y todas las etiquetas de formularios de relleno son especiales. Vea sus respectivas secciones.

Auto-escapeo de HTML

Por defecto, todo el HTML que es emitido por las funciones de generación de formularios se pasa a través de una función llamada escapeHTML():

$escaped_string = escapeHTML("unescaped string");
Escapa los caracteres de formato HTML en una cadena. Internamente esto llama a HTML::Entities (encode_entities), así que realmente debería usar eso en su lugar; la lista por defecto de caracteres que serán codificados (pasada al método encode_entities de HTML::Entities) es: 
& < > " \x8b \x9b '

puede controlar esta lista estableciendo el valor de $CGI::ENCODE_ENTITIES:

# only encode < >
$CGI::ENCODE_ENTITIES = q{<>}

si desea codificar todas las entidades, entonces undef $CGI::ENCODE_ENTITIES:

# encode all entities
$CGI::ENCODE_ENTITIES = undef;

El escapeo automático no se aplica a otros atajos, tales como h1(). Debería llamar a escapeHTML() usted mismo sobre datos no confiables para proteger sus páginas contra trucos maliciosos que la gente pueda introducir en los libros de visitas, etc. Para cambiar el juego de caracteres, use charset(). Para desactivar completamente el auto-escapeo, use autoEscape(0):

$charset = charset([$charset]);
Obtiene o establece el juego de caracteres actual.
$flag = autoEscape([$flag]);
Obtiene o establece el valor del indicador de auto-escapeo.

CREANDO FORMULARIOS DE RELLENO:

Nota general Los diversos métodos de creación de formularios devuelven cadenas al llamador, que contienen la etiqueta o etiquetas que crearán el elemento de formulario solicitado. Usted es responsable de imprimir realmente estas cadenas. Está configurado de esta manera para que usted pueda colocar etiquetas de formato alrededor de los elementos del formulario.

Otra nota Los valores por defecto que usted especifica para los formularios se usan solo la primera vez que se invoca el script (cuando no hay cadena de consulta). En las invocaciones posteriores del script (cuando hay una cadena de consulta), se usan los valores anteriores incluso si están en blanco.

Si desea cambiar el valor de un campo desde su valor anterior, tiene dos opciones:

(1) llame al método param() para establecerlo.

(2) use el parámetro -override (alias -force) (una nueva característica en la versión 2.15). Esto fuerza el uso del valor por defecto, sin importar el valor anterior:

print textfield(-name=>'field_name',
                        -default=>'starting value',
                        -override=>1,
                        -size=>50,
                        -maxlength=>80);

Y todavía otra nota Por defecto, el texto y las etiquetas de los elementos del formulario se escapan de acuerdo con las reglas de HTML. Esto significa que puede usar de forma segura "<CLICK ME>" como la etiqueta de un botón. Sin embargo, también interfiere con su capacidad para incorporar secuencias de caracteres HTML especiales, tales como &, en sus campos. Si desea desactivar el escapeo automático, llame al método autoEscape() con un valor falso inmediatamente después de crear el objeto CGI:

$q = CGI->new;
$q->autoEscape(0);

Note que autoEscape() se usa exclusivamente para afectar el comportamiento de cómo algunas funciones de generación de HTML de CGI.pm manejan el escapeo. Llamar a escapeHTML() explícitamente siempre escapará el HTML.

¡Una trampa oculta! Algunos de los métodos generadores de elementos de formulario devuelven múltiples etiquetas. En un contexto escalar, las etiquetas se concatenarán con espacios, o con lo que sea el valor actual del $" global. En un contexto de lista, los métodos devolverán una lista de elementos, permitiéndole modificarlos si lo desea. Usualmente no notará este comportamiento, pero tenga cuidado con esto:

printf("%s\n",end_form())

end_form() produce varias etiquetas, y solo la primera de ellas se imprimirá porque el formato solo espera un valor.

enctype: application/x-www-form-urlencoded for non-XHTML
         multipart/form-data for XHTML, see multipart/form-data below.

end_form() devuelve la etiqueta de cierre </form>.

start_form()'s el argumento enctype le dice al navegador cómo empaquetar los diversos campos del formulario antes de enviar el formulario al servidor. Dos valores son posibles:

application/x-www-form-urlencoded
Este es el tipo de codificación más antiguo. Es compatible con muchos scripts CGI y es adecuado para campos cortos que contienen datos de texto. Para su comodidad, CGI.pm almacena el nombre de este tipo de codificación en &CGI::URL_ENCODED.
multipart/form-data
Este es el tipo de codificación más nuevo. Es adecuado para formularios que contienen campos muy grandes o que están destinados a transferir datos binarios. Lo más importante, habilita la característica de "subida de archivos". Para su comodidad, CGI.pm almacena el nombre de este tipo de codificación en &CGI::MULTIPART

Los formularios que usan este tipo de codificación no son fácilmente interpretados por scripts CGI a menos que usen CGI.pm u otra biblioteca diseñada para manejarlos.

Si XHTML está activado (el valor por defecto), entonces los formularios se crearán automáticamente usando este tipo de codificación.

El start_form() método usa la forma más antigua de codificación por defecto a menos que se solicite XHTML. Si desea usar la forma más nueva de codificación por defecto, puede llamar a start_multipart_form() en lugar de start_form(). El método end_multipart_form() es un alias de end_form().

JAVASCRIPTING: Los parámetros -name y -onSubmit se proporcionan para su uso con JavaScript. El parámetro -name le da al formulario un nombre para que pueda ser identificado y manipulado por funciones de JavaScript. -onSubmit debe apuntar a una función de JavaScript que se ejecutará justo antes de que el formulario sea enviado a su servidor. Puede usar esta oportunidad para verificar el contenido del formulario en cuanto a consistencia y completitud. Si encuentra algo incorrecto, puede mostrar una caja de alerta o tal vez arreglar las cosas usted mismo. Puede abortar el envío devolviendo false desde esta función.

Usualmente, la mayor parte de las funciones de JavaScript se definen en un bloque <script> en el encabezado HTML y -onSubmit apunta a una de estas llamadas a funciones. Vea start_html() para detalles.

Elementos del formulario

Después de iniciar un formulario, normalmente creará uno o más campos de texto, menús emergentes, grupos de radio y otros elementos de formulario. Cada uno de estos elementos toma un conjunto estándar de argumentos con nombre. Algunos elementos también tienen argumentos opcionales. Los argumentos estándar son los siguientes:

-name
El nombre del campo. Después del envío, este nombre se puede usar para recuperar el valor del campo usando el método param() .
-value, -values
<dd>El valor inicial del campo que se devolverá al script después de el envío del formulario. Algunos elementos de formulario, como los campos de texto, toman un único argumento de valor escalar. Otros, como los menús emergentes, toman una referencia a un array de valores. Los dos argumentos son sinónimos.
-tabindex
Un valor numérico que establece el orden en el que el elemento del formulario recibe el foco cuando el usuario presiona la tecla tabulador. Los elementos con valores más bajos reciben el foco primero.
-id
Un identificador de cadena que se puede usar para identificar este elemento en JavaScript y DHTML.
-override
Un booleano, que, si es verdadero, fuerza al elemento a adoptar el valor especificado por -value, anulando el comportamiento "pegajoso" descrito anteriormente para la -nosticky directiva.
-onChange, -onFocus, -onBlur, -onMouseOver, -onMouseOut, -onSelect
Estos se utilizan para asignar manejadores de eventos de JavaScript. Consulte la sección de JavaScript para más detalles.

Otros argumentos comunes se describen en la siguiente sección. En adición a estos, todos los atributos descritos en las especificaciones HTML son soportados.

Creando un campo de texto

print textfield(-name=>'field_name',
                -value=>'starting value',
                -size=>50,
                -maxlength=>80);
    -o-
print textfield('field_name','starting value',50,80);

textfield() devolverá un campo de entrada de texto.

Parámetros

1.
El primer parámetro es el nombre requerido para el campo (-name).
2.
El segundo parámetro opcional es el valor inicial predeterminado para el contenido del campo (-value, anteriormente conocido como -default).
3.
El tercer parámetro opcional es el tamaño del campo en
caracteres (-size).
4.
El cuarto parámetro opcional es el número máximo de caracteres que el
campo aceptará (-maxlength).

Como con todos estos métodos, el campo se inicializará con su contenido anterior de invocaciones anteriores del script. Cuando el formulario es procesado, el valor del campo de texto se puede recuperar con:

$value = param('foo');

Si desea restablecerlo a su valor inicial después de que el script haya sido llamado una vez, puede hacerlo así:

param('foo',"I'm taking over this value!");

Creando un campo de texto grande

print textarea(-name=>'foo',
                       -default=>'starting value',
                       -rows=>10,
                       -columns=>50);
     -o
print textarea('foo','starting value',10,50);

textarea() es igual a textfield, pero le permite especificar filas y columnas para una caja de entrada de texto de varias líneas. Puede proporcionar un valor inicial para el campo, que puede ser largo y contener múltiples líneas.

Creando un campo de contraseña

print password_field(-name=>'secret',
                             -value=>'starting value',
                             -size=>50,
                             -maxlength=>80);
     -o-
print password_field('secret','starting value',50,80);

password_field() es idéntico a textfield(), excepto que su contenido se mostrará con asteriscos en la página web.

Creando un campo de carga de archivos

print filefield(-name=>'uploaded_file',
                        -default=>'starting value',
                        -size=>50,
                        -maxlength=>80);
    -o-
print filefield('uploaded_file','starting value',50,80);

filefield() devolverá un campo de carga de archivos. Para aprovechar al máximo esto debe usar el nuevo esquema de codificación multipart para el formulario. Puede hacer esto llamando a start_form() con un tipo de codificación de &CGI::MULTIPART, o llamando al nuevo método start_multipart_form() en lugar del start_form() normal.

Parámetros

1.
El primer parámetro es el nombre requerido para el campo (-name).
2.
El segundo parámetro opcional es el valor inicial para el contenido del campo a usar como nombre de archivo predeterminado (-default).

Por razones de seguridad, los navegadores no prestan ninguna atención a este campo, y por lo tanto el valor inicial siempre estará en blanco. Peor aún, el campo pierde su comportamiento "pegajoso" y olvida su contenido anterior. El campo de valor inicial es requerido en la especificación HTML, sin embargo, y posiblemente algún navegador finalmente proporcione soporte para él.

3.
El tercer parámetro opcional es el tamaño del campo en caracteres (-size).
4.
El cuarto parámetro opcional es el número máximo de caracteres que el campo aceptará (-maxlength).

JAVASCRIPT: Los -onChange, -onFocus, -onBlur, -onMouseOver, -onMouseOut y -onSelect parámetros son reconocidos. Consulte textfield() para detalles.

Creando un menú emergente

print popup_menu('menu_name',
                         ['eenie','meenie','minie'],
                         'meenie');
   -o-
%labels = ('eenie'=>'your first choice',
           'meenie'=>'your second choice',
           'minie'=>'your third choice');
%attributes = ('eenie'=>{'class'=>'class of first choice'});
print popup_menu('menu_name',
                         ['eenie','meenie','minie'],
       'meenie',\%labels,\%attributes);
     -o (estilo de parámetro con nombre)-
print popup_menu(-name=>'menu_name',
                         -values=>['eenie','meenie','minie'],
                         -default=>['meenie','minie'],
       -labels=>\%labels,
       -attributes=>\%attributes);

popup_menu() crea un menú. Tenga en cuenta que la opción -multiple será ignorada si se pasa - use scrolling_list() si desea crear un menú que soporte selecciones múltiples

1.
El primer argumento requerido es el nombre del menú (-name).
2.
El segundo argumento requerido (-values) es una referencia a un array que contiene la lista de elementos del menú. Puede pasar al método un array anónimo, como se muestra en el ejemplo, o una referencia a un array con nombre, como "\@foo".
3.
El tercer parámetro opcional (-default) es el nombre de la opción predeterminada del menú. Si no se especifica, el primer elemento será el predeterminado. Los valores de la elección anterior se mantendrán entre consultas. Pase una referencia a un array para seleccionar múltiples valores predeterminados.
4.
El cuarto parámetro opcional (-labels) se proporciona para las personas que quieren usar valores diferentes para la etiqueta visible por el usuario dentro del menú emergente y el valor devuelto a su script. Es un puntero a un hash que relaciona los valores del menú con las etiquetas visibles por el usuario. Si deja este parámetro en blanco, los valores del menú se mostrarán por defecto. (También puede dejar una etiqueta sin definir si lo desea).
5.
El quinto parámetro opcional (-attributes) se proporciona para asignar cualquiera de los atributos HTML comunes a un elemento individual del menú. Es un puntero a un hash que relaciona los valores del menú con otro hash con el nombre del atributo como la clave y el valor del atributo como el valor.

Cuando el formulario es procesado, el valor seleccionado del menú emergente se puede recuperar usando:

$popup_menu_value = param('menu_name');

Creando un grupo de opciones

Estilo de parámetro con nombre

print popup_menu(-name=>'menu_name',
                -values=>[qw/eenie meenie minie/,
                          optgroup(-name=>'optgroup_name',
                                           -values => ['moe','catch'],
                                           -attributes=>{'catch'=>{'class'=>'red'}})],
                -labels=>{'eenie'=>'one',
                          'meenie'=>'two',
                          'minie'=>'three'},
                -default=>'meenie');
Estilo antiguo
print popup_menu('menu_name',
                ['eenie','meenie','minie',
                 optgroup('optgroup_name', ['moe', 'catch'],
                                 {'catch'=>{'class'=>'red'}})],'meenie',
                {'eenie'=>'one','meenie'=>'two','minie'=>'three'});

optgroup() crea un grupo de opciones dentro de un menú emergente.

1.
El primer argumento requerido (-name) es el atributo label del optgroup y no se inserta en la lista de parámetros de la consulta.
2.
El segundo argumento requerido (-values) es una referencia a un array que contiene la lista de elementos del menú. Puede pasar al método un array anónimo, como se muestra en el ejemplo, o una referencia a un array con nombre, como \@foo. Si pasa una referencia a un HASH, las claves se usarán para los valores del menú, y los valores se usarán para las etiquetas del menú (ver -labels más abajo).
3.
El tercer parámetro opcional (-labels) le permite pasar una referencia a un hash que contiene etiquetas visibles por el usuario para uno o más de los elementos del menú. Puede usar esto cuando quiera que el usuario vea una cadena del menú, pero que el navegador devuelva a su programa una diferente. Si no especifica esto, se usará la cadena de valor ("eenie", "meenie" y "minie" en este ejemplo). Esto es equivalente a usar una referencia a un hash para el parámetro -values.
4.
Un cuarto parámetro opcional (-labeled) se puede establecer a un valor verdadero e indica que los valores deben usarse como el atributo label para cada elemento option dentro del optgroup.
5.
Un quinto parámetro opcional (-novals) se puede establecer a un valor verdadero e indica suprimir el atributo val en cada elemento option dentro del optgroup.

Consulte la discusión sobre optgroup en W3C (http://www.w3.org/TR/REC-html40/interact/forms.html#edef-OPTGROUP) para detalles.

6.
Un sexto parámetro opcional (-attributes) se proporciona para asignar cualquiera de los atributos HTML comunes a un elemento individual del menú. Es un puntero a un hash que relaciona los valores del menú con otro hash con elnombre del atributo como clave y el valor del atributo como valor.

scrolling_list() crea una lista desplazable.

Parámetros:

1.
El primer y segundo argumentos son el nombre de la lista (-name) y los valores (-values). Como en el menú emergente, el segundo argumento debe ser una referencia a un arreglo.
2.
El tercer argumento opcional (-default) puede ser una referencia a una lista que contenga los valores que se seleccionarán por defecto, o puede ser un único valor a seleccionar. Si este argumento falta o es indefinido, entonces no se selecciona nada cuando la lista aparece por primera vez. En la versión con parámetros con nombre, puede usar el sinónimo "-defaults" para este parámetro.
3.
El cuarto argumento opcional es el tamaño de la lista (-size).
4.
El quinto argumento opcional puede establecerse en verdadero para permitir selecciones múltiples simultáneas (-multiple). De lo contrario, solo se permitirá una selección a la vez.
5.
El sexto argumento opcional es un puntero a un hash que contiene etiquetas largas visibles para el usuario de los elementos de la lista (-labels). Si no se proporciona, se mostrarán los valores.
6.
El sexto parámetro opcional (-attributes) se proporciona para asignar cualquiera de los atributos HTML comunes a un elemento individual del menú. Es un puntero a un hash que relaciona los valores del menú con otro hash con el nombre del atributo como clave y el valor del atributo como valor.

Cuando se procesa esta forma, todos los elementos de la lista seleccionados serán devueltos como una lista bajo el nombre de parámetro 'list_name'. Los valores de los elementos seleccionados se pueden recuperar con:

@selected = param('list_name');

checkbox_group() crea una lista de casillas de verificación que están relacionadas por el mismo nombre.

Parámetros:

1.
El primer y segundo argumentos son el nombre de la casilla de verificación y los valores, respectivamente (-name y -values). Como en el menú emergente, el segundo argumento debe ser una referencia a un arreglo. Estos valores se usan para las etiquetas legibles por el usuario impresas junto a las casillas de verificación, así como para los valores pasados a su script en la cadena de consulta.
2.
El tercer argumento opcional (-default) puede ser una referencia a una lista que contenga los valores que se marcarán por defecto, o puede ser un único valor a marcar. Si este argumento falta o es indefinido, entonces no se selecciona nada cuando la lista aparece por primera vez.
3.
El cuarto argumento opcional (-linebreak) puede establecerse en verdadero para colocar saltos de línea entre las casillas de verificación de modo que aparezcan como una lista vertical. De lo contrario, se encadenarán en una línea horizontal.

El argumento opcional -labels es un puntero a un hash que relaciona los valores de las casillas de verificación con las etiquetas visibles para el usuario que se imprimirán junto a ellas. Si no se proporciona, se usarán los valores por defecto.

Los parámetros opcionales -rows, y -columns hacen que checkbox_group() devuelva una tabla compatible con HTML3 que contiene el grupo de casillas de verificación formateado con el número especificado de filas y columnas. Puede proporcionar solo el parámetro -columns si lo desea; checkbox_group calculará el número correcto de filas por usted.

La opción -disabled toma un arreglo de valores de casillas de verificación y los deshabilita atenuándolos (esto puede no ser compatible con todos los navegadores).

El argumento opcional -attributes se proporciona para asignar cualquiera de los atributos HTML comunes a un elemento individual del menú. Es un puntero a un hash que relaciona los valores del menú con otro hash con el nombre del atributo como clave y el valor del atributo como valor.

El argumento opcional -tabindex se puede usar para controlar el orden en el que los botones de radio reciben el foco cuando el usuario presiona el botón de tabulación. Si se le pasa un valor numérico escalar, el primer elemento del grupo recibirá este índice de tabulación y los elementos posteriores se incrementarán en uno. Si se le da una referencia a un arreglo de valores de botones de radio, entonces los índices se ajustarán de modo que el orden especificado en el arreglo corresponda al orden de tabulación. También puede pasar una referencia a un hash en el que las claves del hash sean los valores de los botones de radio y los valores sean los índices de tabulación de cada botón. Ejemplos:

-tabindex => 100    #  este grupo comienza en el índice 100 y cuenta hacia arriba
-tabindex => ['moe','minie','eenie','meenie']  # tabular en este orden
-tabindex => {meenie=>100,moe=>101,minie=>102,eenie=>200} # tabular en este orden

El argumento opcional -labelattributes contendrá atributos adjuntos al elemento <label> que rodea cada botón.

Cuando se procesa el formulario, todas las casillas marcadas serán devueltas como una lista bajo el nombre de parámetro 'group_name'. Los valores de las casillas "on" se pueden recuperar con:

@turned_on = param('group_name');

El valor devuelto por checkbox_group() es en realidad un arreglo de elementos de botón. Puede capturarlos y usarlos dentro de tablas, listas, o de otras maneras creativas:

@h = checkbox_group(-name=>'group_name',-values=>\@values);
&use_in_creative_way(@h);

Para registrar un manejador de eventos JavaScript con un elemento HTML, simplemente use el nombre del evento como parámetro cuando llame al método CGI correspondiente. Por ejemplo, para que su validateAge() código JavaScript se ejecute cada vez que el campo de texto llamado "age" cambie, genere el campo así:

print textfield(-name=>'age',-onChange=>"validateAge(this)");

Este ejemplo asume que ya ha declarado la validateAge() función incorporándola en un bloque <SCRIPT>. El método CGI.pm start_html() proporciona una manera conveniente de crear esta sección.

De manera similar, puede crear un formulario que se verifique a sí mismo en busca de inconsistencias y alerte al usuario si falta algún valor esencial creándolo de esta manera:
print start_form(-onSubmit=>"validateMe(this)");

SOPORTE LIMITADO PARA HOJAS DE ESTILO EN CASCADA

CGI.pm tiene soporte limitado para las hojas de estilo en cascada (css) de HTML3. Para incorporar una hoja de estilos en su documento, pase al método start_html() un parámetro -style . El valor de este parámetro puede ser un escalar, en cuyo caso se trata como la URL de origen de la hoja de estilos, o puede ser una referencia a un hash. En el último caso, debe proporcionar al hash uno o más de -src o -code. -src apunta a una URL donde se puede encontrar una hoja de estilos definida externamente. -code apunta a un valor escalar que se incorporará en una sección <style>. Las definiciones de estilo en -code anulan las de nombre similar en -src, de ahí el nombre "en cascada".

También puede especificar el tipo de la hoja de estilos añadiendo el parámetro opcional -type al hash al que apunta -style. Si no se especifica, el estilo por defecto es 'text/css'.

Para referirse a un estilo dentro del cuerpo de su documento, añada el parámetro -class a cualquier elemento HTML:

print h1({-class=>'Fancy'},'Welcome to the Party');

O defina estilos sobre la marcha con el parámetro -style :

print h1({-style=>'Color: red;'},'Welcome to Hell');

También puede usar el nuevo elemento span() para aplicar un estilo a una sección de texto:

print span({-style=>'Color: red;'},
           h1('Welcome to Hell'),
           "Where did that handbasket get to?"
           );

Tenga en cuenta que debe importar las definiciones ":html3" para tener el método span() disponible. Aquí hay un ejemplo rápido y sucio de uso de CSS. Consulte la especificación CSS en http://www.w3.org/Style/CSS/ para más información.

use CGI qw/:standard :html3/;
#aquí hay una hoja de estilos incorporada directamente en la página
$newStyle=<<END;
<!-- 
P.Tip {
    margin-right: 50pt;
    margin-left: 50pt;
    color: red;
}
P.Alert {
    font-size: 30pt;
    font-family: sans-serif;
  color: red;
}
-->
END
print header();
print start_html( -title=>'CGI with Style',
                  -style=>{-src=>'http://www.capricorn.com/style/st1.css',
                           -code=>$newStyle}
                 );
print h1('CGI with Style'),
      p({-class=>'Tip'},
        "Better read the cascading style sheet spec before playing with this!"),
      span({-style=>'color: magenta'},
           "Look Mom, no hands!",
           p(),
           "Whooo wee!"
           );
print end_html;

Pase una referencia a un array a -code o -src para incorporar múltiples hojas de estilos en su documento.

Si desea incorporar una hoja de estilos literal que incluya un formato arbitrario en la cabecera, puede pasar una etiqueta -verbatim al hash -style, como sigue:

print start_html (-style => {-verbatim => '@import url("/server-common/css/'.$cssFile.'");',
-src => '/server-common/css/core.css'});

Esto generará una cabecera HTML que contiene esto:

<link rel="stylesheet" type="text/css"  href="/server-common/css/core.css">
  <style type="text/css">
  @import url("/server-common/css/main.css");
  </style>

Cualquier argumento adicional pasado en el valor de -style se incorporará a la etiqueta <link>. Por ejemplo:

start_html(-style=>{-src=>['/styles/print.css','/styles/layout.css'],
                         -media => 'all'});

Esto dará:

<link rel="stylesheet" type="text/css" href="/styles/print.css" media="all"/>
<link rel="stylesheet" type="text/css" href="/styles/layout.css" media="all"/>

<p>

Para hacer etiquetas <link> más complicadas, use la función Link() y pásela a start_html() en el argumento -head, como en:

@h = (Link({-rel=>'stylesheet',-type=>'text/css',-src=>'/ss/ss.css',-media=>'all'}),
      Link({-rel=>'stylesheet',-type=>'text/css',-src=>'/ss/fred.css',-media=>'paper'}));
print start_html({-head=>\@h})

Para crear una hoja de estilos principal y una "alternativa", use la opción -alternate :

start_html(-style=>{-src=>[
                          {-src=>'/styles/print.css'},
                          {-src=>'/styles/alt.css',-alternate=>1}
                          ]
                   });

Volcado de todos los pares nombre/valor

El método Dump() produce una cadena que consiste en todos los pares nombre/valor de la consulta formateados de manera agradable como una lista anidada. Esto es útil para propósitos de depuración:

print Dump

Produce algo que se parece a:

    <ul>
    <li>value1
    <li>value2
    </ul>
<li>name2
    <ul>
    <li>value1
    </ul>
</ul>

Como un atajo, puede interpolar el objeto CGI completo en una cadena y será reemplazado por el volcado HTML agradable mostrado arriba:

$q=CGI->new;
print "<h2>Current Values</h2> $q\n";
