CGET10

Propósito:

!>
!> CGET10 compara dos matrices A y B y calcula la razón
!> RESULT = norm( A - B ) / ( norm(A) * M * EPS )
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de las matrices A y B.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y B.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>          La matriz m por n A.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es un array COMPLEJO, de dimensión (LDB,N)
!>          La matriz m por n B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (M)
!>

RWORK

!>          RWORK es un array REAL, de dimensión (M)
!>

RESULT

!>          RESULT es REAL
!>          RESULT = norm( A - B ) / ( norm(A) * M * EPS )
!>
