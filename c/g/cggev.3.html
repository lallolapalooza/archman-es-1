subrutina cggev (character jobvl, character jobvr, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( ldvl, * ) vl, integer ldvl, complex, dimension( ldvr, * ) vr, integer ldvr, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CGGEV calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdo y/o derecho para matrices GE

Propósito:

!>
!> CGGEV calcula para un par de matrices complejas no simétricas N-por-N
!> (A,B), los eigenvalores generalizados, y opcionalmente, los eigenvectores generalizados
!> izquierdo y/o derecho.
!>
!> Un eigenvalor generalizado para un par de matrices (A,B) es un escalar
!> lambda o una razón alpha/beta = lambda, tal que A - lambda*B es
!> singular. Generalmente se representa como el par (alpha,beta), ya que
!> hay una interpretación razonable para beta=0, e incluso para ambos
!> siendo cero.
!>
!> El eigenvector generalizado derecho v(j) correspondiente al
!> eigenvalor generalizado lambda(j) de (A,B) satisface
!>
!>              A * v(j) = lambda(j) * B * v(j).
!>
!> El eigenvector generalizado izquierdo u(j) correspondiente a los
!> eigenvalores generalizados lambda(j) de (A,B) satisface
!>
!>              u(j)**H * A = lambda(j) * u(j)**H * B
!>
!> donde u(j)**H es la transpuesta conjugada de u(j).
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los eigenvectores generalizados izquierdos;
!>          = 'V':  calcular los eigenvectores generalizados izquierdos.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los eigenvectores generalizados derechos;
!>          = 'V':  calcular los eigenvectores generalizados derechos.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VL y VR.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA, N)
!>          En la entrada, la matriz A del par (A,B).
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX, dimensión (LDB, N)
!>          En la entrada, la matriz B del par (A,B).
!>          En la salida, B ha sido sobrescrita.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX, dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX, dimensión (N)
!>          En la salida, ALPHA(j)/BETA(j), j=1,...,N, serán los
!>          eigenvalores generalizados.
!>
!>          Nota: los cocientes ALPHA(j)/BETA(j) pueden fácilmente desbordar o
!>          quedarse sin rango, y BETA(j) puede incluso ser cero.  Por lo tanto, el usuario
!>          debe evitar calcular ingenuamente la razón alpha/beta.
!>          Sin embargo, ALPHA siempre será menor y generalmente
!>          comparable con norm(A) en magnitud, y BETA siempre menor
!>          y generalmente comparable con norm(B).
!>

VL

!>          VL es un array COMPLEX, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los eigenvectores generalizados izquierdos u(j) son
!>          almacenados uno tras otro en las columnas de VL, en el mismo
!>          orden que sus eigenvalores.
!>          Cada eigenvector se escala de modo que el componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1.
!>          No se referencia si JOBVL = 'N'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los eigenvectores generalizados derechos v(j) son
!>          almacenados uno tras otro en las columnas de VR, en el mismo
!>          orden que sus eigenvalores.
!>          Cada eigenvector se escala de modo que el componente más grande tenga
!>          abs(parte real) + abs(parte imaginaria) = 1.
!>          No se referencia si JOBVR = 'N'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por XERBLA.
!>

RWORK

!>          RWORK es un array REAL, dimensión (8*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          =1,...,N:
!>                La iteración QZ falló.  No se han calculado eigenvectores,
!>                pero ALPHA(j) y BETA(j) deberían ser
!>                correctos para j=INFO+1,...,N.
!>          > N:  =N+1: otro fallo de iteración QZ en CHGEQZ,
!>                =N+2: retorno de error de CTGEVC.
!>

    cggev(3)

    CGGEV Computes the eigenvalues and eigenvectors of a complex general matrix pair (A,B).

    SYNOPSIS

    SUBROUTINE CGGEV(
  JOBVL, JOBVR, N, A, LDA, B, LDB, ALPHAR, ALPHAI, BETA, VL, LDVL, VR, LDVR,
  WORK, LWORK, RWORK, INFO
)
  CHARACTER (*) JOBVL, JOBVR
  INTEGER N, LDA, LDB, LDVL, LDVR, LWORK, INFO
  COMPLEX A( LDA, * ), B( LDB, * ), VL( LDVL, * ), VR( LDVR, * ),
     WORK( * )
  REAL ALPHAR( * ), ALPHAI( * ), RWORK( * )
  COMPLEX BETA( * )

    DESCRIPTION

    This routine is in the INTEGER 1 array, so it can be called from Fortran, C, and other languages.

    The routine computes the eigenvalues and, if requested, the left and right eigenvectors of a complex general matrix pair (A,B).

    The eigenvalues are computed in the form α and β, such that A*v = λ*B*v, where λ is the eigenvalue. The equation A*v = λ*B*v is equivalent to the generalized eigenvalue problem A*x = λ*B*x.

    The pair of eigenvalues is returned as the pair of numbers (ALPHAR(I), ALPHAI(I)) and BETA(I), and the eigenvalues λ are such that ALPHAR(I) + i*ALPHAI(I) = BETA(I)*λ.

    Parameters

    • JOBVL: CHARACTER*1.
      • If JOBVL = 'N', the left eigenvectors are not computed.
      • If JOBVL = 'V', the left eigenvectors are computed.
    • JOBVR: CHARACTER*1.
      • If JOBVR = 'N', the right eigenvectors are not computed.
      • If JOBVR = 'V', the right eigenvectors are computed.
    • N: INTEGER. The order of the matrices A and B. N ≥ 0.
    • A: COMPLEX array, dimension (LDA, N). On entry, the first N rows and N columns of matrix A.
    • LDA: INTEGER. The leading dimension of A. LDA ≥ max(1, N).
    • B: COMPLEX array, dimension (LDB, N). On entry, the first N rows and N columns of matrix B.
    • LDB: INTEGER. The leading dimension of B. LDB ≥ max(1, N).
    • ALPHAR: REAL array, dimension (N). See DESCRIPTION for the return value.
    • ALPHAI: REAL array, dimension (N). See DESCRIPTION for the return value.
    • BETA: COMPLEX array, dimension (N). See DESCRIPTION for the return value.
    • VL: COMPLEX array, dimension (LDVL, N). If JOBVL = 'V', VL contains the left eigenvectors of the pair (A,B), with the i-th eigenvector column VL(*,i) normalized so that the largest magnitude element is 1.
    • LDVL: INTEGER. The leading dimension of VL. LDVL ≥ max(1, N).
    • VR: COMPLEX array, dimension (LDVR, N). If JOBVR = 'V', VR contains the right eigenvectors of the pair (A,B), with the i-th eigenvector column VR(*,i) normalized so that the largest magnitude element is 1.
    • LDVR: INTEGER. The leading dimension of VR. LDVR ≥ max(1, N).
    • WORK: COMPLEX array, dimension (LWORK). On exit, WORK(1) contains the optimal LWORK.
    • LWORK: INTEGER. The dimension of the array WORK. LWORK ≥ max(1, 2*N). For optimum performance, LWORK ≥ max(1, 2*N + 2*N*N).
    • RWORK: REAL array, dimension (8*N). Workspace array.
    • INFO: INTEGER. = 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if INFO = i > 0, the algorithm QR iteration failed to converge; i eigenvalues are stillRangeException.

    Examples

    None.

    Reference

    LAPACK Working Note 169.
