Documentación de Función/Subrutina

subrutina cgeqp3rk (integer m, integer n, integer nrhs, integer kmax, real abstol, real reltol, complex, dimension( lda, * ) a, integer lda, integer k, real maxc2nrmk, real relmaxc2nrmk, integer, dimension( * ) jpiv, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

CGEQP3RK calcula una factorización QR de Householder truncada con pivoteo de columnas de una matriz compleja m-por-n A utilizando BLAS de Nivel 3 y sobrescribe la matriz m-por-nrhs B con Q**H * B.

Propósito:

!>
!> CGEQP3RK realiza dos tareas simultáneamente:
!>
!> Tarea 1: La rutina calcula una factorización QR de Householder truncada (rango K) o de
!> rango completo con pivoteo de columnas de una matriz compleja
!> M-por-N A utilizando BLAS de Nivel 3. K es el número de columnas
!> que fueron factorizadas, es decir, el rango de la factorización
!> del factor R, K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_aprox    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residuo ),
!>
!> donde:
!>
!>  P(K)            es una matriz de permutación N-por-N;
!>  Q(K)            es una matriz unitaria M-por-M;
!>  R(K)_aprox   = ( R11(K), R12(K) ) es una aproximación de rango K del
!>                    factor R de rango completo con R11(K) triangular superior
!>                    K-por-K y R12(K) rectangular K-por-N. Las entradas
!>                    diagonales de R11(K) aparecen en orden no creciente
!>                    de valor absoluto, y los valores absolutos de todas
!>                    ellas exceden la norma 2 máxima de columna de R22(K)
!>                    hasta el error de redondeo.
!>  R(K)_residuo = R22(K) es el residuo de una aproximación de rango K
!>                    del factor R de rango completo. Es una
!>                    matriz rectangular (M-K)-por-(N-K);
!>  0               es una matriz cero (M-K)-por-K.
!>
!> Tarea 2: Al mismo tiempo, la rutina sobrescribe una matriz compleja M-por-NRHS
!> B con  Q(K)**H * B  utilizando BLAS de Nivel 3.
!>
!> =====================================================================
!>
!> Las matrices A y B se almacenan en la entrada en el array A como
!> los bloques izquierdo y derecho A(1:M,1:N) y A(1:M, N+1:N+NRHS)
!> respectivamente.
!>
!>                                  N     NRHS
!>             array_A   =   M  [ mat_A, mat_B ]
!>
!> Los criterios de truncamiento (es decir, cuándo detener la factorización)
!> pueden ser cualquiera de los siguientes:
!>
!>   1) El parámetro de entrada KMAX, el número máximo de columnas
!>      KMAX a factorizar, es decir, el rango de la factorización está limitado
!>      a KMAX. Si KMAX >= min(M,N), el criterio no se utiliza.
!>
!>   2) El parámetro de entrada ABSTOL, la tolerancia absoluta para
!>      la norma 2 máxima de columna de la matriz residuo R22(K). Esto
!>      significa que la factorización se detiene si esta norma es menor o
!>      igual a ABSTOL. Si ABSTOL < 0.0, el criterio no se utiliza.
!>
!>   3) El parámetro de entrada RELTOL, la tolerancia para la norma 2
!>      máxima de columna de la matriz residuo R22(K) dividida
!>      por la norma 2 máxima de columna de la matriz original A, la cual
!>      es igual a abs(R(1,1)). Esto significa que la factorización se detiene
!>      cuando el cociente de la norma 2 máxima de columna de R22(K) a
!>      la norma 2 máxima de columna de A es menor o igual a RELTOL.
!>      Si RELTOL < 0.0, el criterio no se utiliza.
!>
!>   4) En caso de que ninguno de los criterios de parada ABSTOL o RELTOL se utilicen,
!>      y cuando la matriz residuo R22(K) sea una matriz cero en algún
!>      paso de factorización K. ( Este criterio de parada es implícito. )
!>
!>  El algoritmo se detiene cuando cualquiera de estas condiciones se satisface
!>  primero, de lo contrario se factoriza toda la matriz A.
!>
!>  Para factorizar toda la matriz A, utilice los valores
!>  KMAX >= min(M,N), ABSTOL < 0.0 y RELTOL < 0.0.
!>
!>  La rutina devuelve:
!>     a) Q(K), R(K)_aprox = ( R11(K), R12(K) ),
!>        R(K)_residuo = R22(K), P(K), es decir, las matrices resultantes
!>        de la factorización; P(K) está representada por JPIV,
!>        ( si K = min(M,N), R(K)_aprox es el factor R completo,
!>        y no hay matriz residuo R(K)_residuo);
!>     b) K, el número de columnas que fueron factorizadas,
!>        es decir, el rango de la factorización;
!>     c) MAXC2NRMK, la norma 2 máxima de columna de la matriz
!>        residuo R(K)_residuo = R22(K),
!>        ( si K = min(M,N), MAXC2NRMK = 0.0 );
!>     d) RELMAXC2NRMK es igual a MAXC2NRMK dividido por MAXC2NRM, la norma 2
!>        máxima de columna de la matriz original A, la cual es igual
!>        a abs(R(1,1)), ( si K = min(M,N), RELMAXC2NRMK = 0.0 );
!>     e) Q(K)**H * B, la matriz B con la transformación
!>        unitaria Q(K)**H aplicada a la izquierda.
!>
!> La matriz de permutación N-por-N P(K) se almacena en una forma compacta en
!> el array entero JPIV. Para 1 <= j <= N, la columna j
!> de la matriz A se intercambió con la columna JPIV(j).
!>
!> La matriz unitaria M-por-M Q está representada como un producto
!> de reflectores elementales de Householder
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K),
!>
!> donde K es el número de columnas que fueron factorizadas.
!>
!> Cada H(j) tiene la forma
!>
!>     H(j) = I - tau * v * v**H,
!>
!> donde 1 <= j <= K y
!>   I    es una matriz identidad M-por-M,
!>   tau  es un escalar complejo,
!>   v    es un vector complejo con v(1:j-1) = 0 y v(j) = 1.
!>
!> v(j+1:M) se almacena en la salida en A(j+1:M,j) y tau en TAU(j).
!>
!> Vea la sección Detalles Adicionales para más información.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros libres, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

KMAX

!>          KMAX es INTEGER
!>
!>          El primer criterio de parada de la factorización. KMAX >= 0.
!>
!>          El número máximo de columnas de la matriz A a factorizar,
!>          es decir, el rango máximo de la factorización.
!>
!>          a) Si KMAX >= min(M,N), entonces este criterio de parada
!>                no se utiliza, la rutina factoriza columnas
!>                dependiendo de ABSTOL y RELTOL.
!>
!>          b) Si KMAX = 0, entonces este criterio de parada se
!>                satisface en la entrada y la rutina sale inmediatamente.
!>                Esto significa que la factorización no se realiza,
!>                las matrices A y B no se modifican, y
!>                la matriz A es en sí misma el residuo.
!>

ABSTOL

!>          ABSTOL es REAL
!>
!>          El segundo criterio de parada de la factorización, no puede ser NaN.
!>
!>          La tolerancia absoluta (umbral de parada) para
!>          la norma 2 máxima de columna de la matriz residuo R22(K).
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 máxima de columna de la matriz residuo R22(K)
!>          es menor o igual a ABSTOL. Sea SAFMIN = DLAMCH('S').
!>
!>          a) Si ABSTOL es NaN, entonces no se realiza ningún cálculo
!>                y se emite un mensaje de error ( INFO = -5 )
!>                por XERBLA.
!>
!>          b) Si ABSTOL < 0.0, entonces este criterio de parada no se
!>                utiliza, la rutina factoriza columnas
!>          depending
!>                on KMAX and RELTOL.
!>                This includes the case ABSTOL = -Inf.
!>
!>          c) If 0.0 <= ABSTOL < 2*SAFMIN, then ABSTOL = 2*SAFMIN
!>                is used. This includes the case ABSTOL = -0.0.
!>
!>          d) If 2*SAFMIN <= ABSTOL then the input value
!>                of ABSTOL is used.
!>
!>          Let MAXC2NRM be the maximum column 2-norm of the
!>          whole original matrix A.
!>          If ABSTOL chosen above is >= MAXC2NRM, then this
!>          stopping criterion is satisfied on input and routine exits
!>          immediately after MAXC2NRM is computed. The routine
!>          returns MAXC2NRM in MAXC2NORMK,
!>          and 1.0 in RELMAXC2NORMK.
!>          This includes the case ABSTOL = +Inf. This means that the
!>          factorization is not performed, the matrices A and B are not
!>          modified, and the matrix A is itself the residual.
!> 


RELTOL


!>          RELTOL is REAL
!>
!>          The third factorization stopping criterion, cannot be NaN.
!>
!>          The tolerance (stopping threshold) for the ratio
!>          abs(R(K+1,K+1))/abs(R(1,1)) of the maximum column 2-norm of
!>          the residual matrix R22(K) to the maximum column 2-norm of
!>          the original matrix A. The algorithm converges (stops the
!>          factorization), when abs(R(K+1,K+1))/abs(R(1,1)) A is less
!>          than or equal to RELTOL. Let EPS = DLAMCH('E').
!>
!>          a) If RELTOL is NaN, then no computation is performed
!>                and an error message ( INFO = -6 ) is issued
!>                by XERBLA.
!>
!>          b) If RELTOL < 0.0, then this stopping criterion is not
!>                used, the routine factorizes columns depending
!>                on KMAX and ABSTOL.
!>                This includes the case RELTOL = -Inf.
!>
!>          c) If 0.0 <= RELTOL < EPS, then RELTOL = EPS is used.
!>                This includes the case RELTOL = -0.0.
!>
!>          d) If EPS <= RELTOL then the input value of RELTOL
!>                is used.
!>
!>          Let MAXC2NRM be the maximum column 2-norm of the
!>          whole original matrix A.
!>          If RELTOL chosen above is >= 1.0, then this stopping
!>          criterion is satisfied on input and routine exits
!>          immediately after MAXC2NRM is computed.
!>          The routine returns MAXC2NRM in MAXC2NORMK,
!>          and 1.0 in RELMAXC2NORMK.
!>          This includes the case RELTOL = +Inf. This means that the
!>          factorization is not performed, the matrices A and B are not
!>          modified, and the matrix A is itself the residual.
!>
!>          NOTE: We recommend that RELTOL satisfy
!>                min( 10*max(M,N)*EPS, sqrt(EPS) ) <= RELTOL
!> 


A


!>          A is COMPLEX array, dimension (LDA,N+NRHS)
!>
!>          On entry:
!>
!>          a) The subarray A(1:M,1:N) contains the M-by-N matrix A.
!>          b) The subarray A(1:M,N+1:N+NRHS) contains the M-by-NRHS
!>             matrix B.
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          On exit:
!>
!>          a) The subarray A(1:M,1:N) contains parts of the factors
!>             of the matrix A:
!>
!>            1) If K = 0, A(1:M,1:N) contains the original matrix A.
!>            2) If K > 0, A(1:M,1:N) contains parts of the
!>            factors:
!>
!>              1. The elements below the diagonal of the subarray
!>                 A(1:M,1:K) together with TAU(1:K) represent the
!>                 unitary matrix Q(K) as a product of K Householder
!>                 elementary reflectors.
!>
!>              2. The elements on and above the diagonal of
!>                 the subarray A(1:K,1:N) contain K-by-N
!>                 upper-trapezoidal matrix
!>                 R(K)_approx = ( R11(K), R12(K) ).
!>                 NOTE: If K=min(M,N), i.e. full rank factorization,
!>                       then R_approx(K) is the full factor R which
!>                       is upper-trapezoidal. If, in addition, M>=N,
!>                       then R is upper-triangular.
!>
!>              3. The subarray A(K+1:M,K+1:N) contains (M-K)-by-(N-K)
!>                 rectangular matrix R(K)_residual = R22(K).
!>
!>          b) If NRHS > 0, the subarray A(1:M,N+1:N+NRHS) contains
!>             the M-by-NRHS product Q(K)**H * B.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>          This is the leading dimension for both matrices, A and B.
!> 


K


!>          K is INTEGER
!>          Factorization rank of the matrix A, i.e. the rank of
!>          the factor R, which is the same as the number of non-zero
!>          rows of the factor R. 0 <= K <= min(M,KMAX,N).
!>
!>          K also represents the number of non-zero Householder
!>          vectors.
!>
!>          NOTE: If K = 0, a) the arrays A and B are not modified;
!>                          b) the array TAU(1:min(M,N)) is set to ZERO,
!>                             if the matrix A does not contain NaN,
!>                             otherwise the elements TAU(1:min(M,N))
!>                             are undefined;
!>                          c) the elements of the array JPIV are set
!>                             as follows: for j = 1:N, JPIV(j) = j.
!> 


MAXC2NRMK


!>          MAXC2NRMK is REAL
!>          The maximum column 2-norm of the residual matrix R22(K),
!>          when the factorization stopped at rank K. MAXC2NRMK >= 0.
!>
!>          a) If K = 0, i.e. the factorization was not performed,
!>             the matrix A was not modified and is itself a residual
!>             matrix, then MAXC2NRMK equals the maximum column 2-norm
!>             of the original matrix A.
!>
!>          b) If 0 < K < min(M,N), then MAXC2NRMK is returned.
!>
!>          c) If K = min(M,N), i.e. the whole matrix A was
!>             factorized and there is no residual matrix,
!>             then MAXC2NRMK = 0.0.
!>
!>          NOTE: MAXC2NRMK in the factorization step K would equal
!>                R(K+1,K+1) in the next factorization step K+1.
!> 


RELMAXC2NRMK


!>          RELMAXC2NRMK is REAL
!>          The ratio MAXC2NRMK / MAXC2NRM of the maximum column
!>          2-norm of the residual matrix R22(K) (when the factorization
!>          stopped at rank K) to the maximum column 2-norm of the
!>          whole original matrix A. RELMAXC2NRMK >= 0.
!>
!>          a) If K = 0, i.e. the factorization was not performed,
!>             the matrix A was not modified and is itself a residual
!>             matrix, then RELMAXC2NRMK = 1.0.
!>
!>          b) If 0 < K < min(M,N), then
!>                RELMAXC2NRMK = MAXC2NRMK / MAXC2NRM is returned.
!>
!>          c) If K = min(M,N), i.e. the whole matrix A was
!>             factorized and there is no residual matrix,
!>             then RELMAXC2NRMK = 0.0.
!>
!>         NOTE: RELMAXC2NRMK in the factorization step K would equal
!>               abs(R(K+1,K+1))/abs(R(1,1)) in the next factorization
!>               step K+1.
!> 


JPIV


!>          JPIV is INTEGER array, dimension (N)
!>          Column pivot indices. For 1 <= j <= N, column j
!>          of the matrix A was interchanged with column JPIV(j).
!>
!>          The elements of the array JPIV(1:N) are always set
!>          by the routine, for example, even  when no columns
!>          were factorized, i.e. when K = 0, the elements are
!>          set as JPIV(j) = j for j = 1:N.
!> 


TAU


!>          TAU is COMPLEX array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors.
!>
!>          If 0 < K <= min(M,N), only the elements TAU(1:K) of
!>          the array TAU are modified by the factorization.
!>          After the factorization computed, if no NaN was found
!>          during the factorization, the remaining elements
!>          TAU(K+1:min(M,N)) are set to zero, otherwise the
!>          elements TAU(K+1:min(M,N)) are not set and therefore
!>          undefined.
!>          ( If K = 0, all elements of TAU are set to zero, if
!>          the matrix A does not contain NaN. )
!> 


WORK


!>          WORK is COMPLEX array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          LWORK >= 1, if MIN(M,N) = 0, and
!>          LWORK >= N+NRHS-1, otherwise.
!>          For optimal performance LWORK >= NB*( N+NRHS+1 ),
!>          where NB is the optimal block size for CGEQP3RK returned
!>          by ILAENV. Minimal block size MINNB=2.
!>
!>          NOTE: The decision, whether to use unblocked BLAS 2
!>          or blocked BLAS 3 code is based not only on the dimension
!>          LWORK of the availbale workspace WORK, but also also on the
!>          matrix A dimension N via crossover point NX returned
!>          by ILAENV. (For N less than NX, unblocked code should be
!>          used.)
!>
!>          If LWORK = -1, then a workspace query is assumed;
!>          the routine only calculates the optimal size of the WORK
!>          array, returns this value as the first entry of the WORK
!>          array, and no error message related to LWORK is issued
!>          by XERBLA.
!> 


RWORK


!>          RWORK is REAL array, dimension (2*N)
!> 


IWORK


!>          IWORK is INTEGER array, dimension (N-1).
!>          Is a work array. ( IWORK is used to store indices
!>          of  columns for norm downdating in the residual
!>          matrix in the blocked step auxiliary subroutine CLAQP3RK ).
!> 


INFO


!>          INFO is INTEGER
!>          1) INFO = 0: successful exit.
!>          2) INFO < 0: if INFO = -i, the i-th argument had an
!>                       illegal value.
!>          3) If INFO = j_1, where 1 <= j_1 <= N, then NaN was
!>             detected and the routine stops the computation.
!>             The j_1-th column of the matrix A or the j_1-th
!>             element of array TAU contains the first occurrence
!>             of NaN in the factorization step K+1 ( when K columns
!>             have been factorized ).
!>
!>             On exit:
!>             K                  is set to the number of
!>                                   factorized columns without
!>                                   exception.
!>             MAXC2NRMK          is set to NaN.
!>             RELMAXC2NRMK       is set to NaN.
!>             TAU(K+1:min(M,N))  is not set and contains undefined
!>                                   elements. If j_1=K+1, TAU(K+1)
!!>             may contain NaN.
!>          4) If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN
!>             was detected, but +Inf (or -Inf) was detected and
!> 

la rutina continúa el cálculo hasta su finalización.
!> La columna (j_2-N) de la matriz A contiene la primera
!> aparición de +Inf (o -Inf) en el paso de factorización
!> K+1 (cuando K columnas han sido factorizadas).

Detalles Adicionales:

!> CGEQP3RK se basa en el mismo algoritmo de factorización QR de Householder
!> con pivoteo de columnas BLAS3 que la rutina CGEQP3, la cual utiliza
!> la rutina CLARFG para generar los reflectores de Householder
!> para la factorización QR.
!>
!> También podemos escribir:
!>
!>   A = A_approx(K) + A_residual(K)
!>
!> La matriz de aproximación de bajo rango A(K)_approx de
!> la factorización QR truncada de rango K de la matriz A es:
!>
!>   A(K)_approx = Q(K) * ( R(K)_approx ) * P(K)**T
!>                        (     0     0 )
!>
!>               = Q(K) * ( R11(K) R12(K) ) * P(K)**T
!>                        (      0      0 )
!>
!> El residuo A_residual(K) de la matriz A es:
!>
!>   A_residual(K) = Q(K) * ( 0              0 ) * P(K)**T =
!>                          ( 0  R(K)_residual )
!>
!>                 = Q(K) * ( 0        0 ) * P(K)**T
!>                          ( 0   R22(K) )
!>
!> La factorización truncada (rango K) garantiza que
!> la norma 2 máxima de columna de A_residual(K) es menor que
!> o igual a MAXC2NRMK hasta el error de redondeo.
!>
!> NOTA: Una aproximación de los vectores nulos
!>       de A se puede calcular fácilmente a partir de R11(K)
!>       y R12(K):
!>
!>       Null( A(K) )_approx = P * ( inv(R11(K)) * R12(K) )
!>                                 (         -I           )
!>
!>
