Documentación de la Función/Subrutina

subroutine cgbsvx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, real, dimension( * ) r, real, dimension( * ) c, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CGBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!> CGBSVX utiliza la factorización LU para calcular la solución de un sistema
!> complejo de ecuaciones lineales A * X = B, A**T * X = B, o A**H * X = B,
!> donde A es una matriz de banda de orden N con KL subdiagonales y KU
!> superdiagonales, y X e B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación de
!> la condición.
!>

Descripción:

!>
!> Los siguientes pasos son realizados por esta subrutina:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se va a equilibrar o no depende de la
!>    escala de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>       A = L * U,
!>    donde L es un producto de matrices de permutación y triangulares inferiores unitarias
!>    con KL subdiagonales, y U es triangular superior con
!>    KL+KU superdiagonales.
!>
!> 3. Si algún U(i,i)=0, de modo que U es exactamente singular, la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se usa
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando las cotas de error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X usando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular las cotas de error y las estimaciones de error residual
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AFB e IPIV contienen la forma factorizada de
!>                  A.  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  AB, AFB e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AFB y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFB y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array COMPLEX, dimension (LDAB,N)
!>          En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna del
!>          array AB como sigue:
!>          AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' y EQUED no es 'N', entonces A debe haber sido
!>          equilibrada con los factores de escala en R y/o C. AB no
!>          se modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>          EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array COMPLEX, dimension (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y en la entrada
!>          contiene detalles de la factorización LU de la matriz de banda
!>          A, tal como fue calculada por CGBTRF. U se almacena como una matriz
!>          triangular superior de banda con KL+KU superdiagonales en las filas
!>          1 a KL+KU+1, y los multiplicadores usados durante la factorización se almacenan
!>          en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N', entonces AFB
!>          es la forma factorizada de la matriz equilibrada A.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y en la salida
!>          contiene detalles de la factorización LU de A.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y en la salida
!>          contiene detalles de la factorización LU de la matriz equilibrada
!>          A (ver la descripción de AB para la forma de la matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización A = L*U
!>          tal como fue calculada por CGBTRF; la fila i de la matriz fue intercambiada
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>          de la matriz equilibrada A.
!>

EQUED

/i>

!>          EQUED es CHARACTER*1
!>          Especifica la forma de ecualización que se realizó.
!>          = 'N':  Sin ecualización (siempre cierto si FACT = 'N').
!>          = 'R':  Ecualización de filas, es decir, A ha sido premultiplicada por
!>                  diag(R).
!>          = 'C':  Ecualización de columnas, es decir, A ha sido postmultiplicada
!>                  por diag(C).
!>          = 'B':  Tanto ecualización de filas como de columnas, es decir, A ha sido
!>                  reemplazada por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

R

!>          R es un array REAL, dimensión (N)
!>          Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A es
!>          multiplicada a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>          no se accede. R es un argumento de entrada si FACT = 'F';
!>          de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>

C

!>          C es un array REAL, dimensión (N)
!>          Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A es
!>          multiplicada a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>          no se accede. C es un argumento de entrada si FACT = 'F';
!>          de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del segundo miembro B.
!>          En la salida,
!>          si EQUED = 'N', B no se modifica;
!>          si TRANS = 'N' y EQUED = 'R' o 'B', B es sobrescrita por
!>          diag(R)*B;
!>          si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B es
!>          sobrescrita por diag(C)*B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS
!>          del sistema original de ecuaciones. Tenga en cuenta que A y B son
!>          modificados en la salida si EQUED .ne. 'N', y la solución al
!>          sistema ecualizado es inv(diag(C))*X si TRANS = 'N' y
!>          EQUED = 'C' o 'B', o inv(diag(R))*X si TRANS = 'T' o 'C'
!>          y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          La estimación del número de condición recíproco de la matriz
!>          A después de la ecualización (si se hizo). Si RCOND es menor que la
!>          precisión de la máquina (en particular, si RCOND = 0), la matriz
!>          es singular a la precisión de trabajo. Esta condición es
!>          indicada por un código de retorno de INFO > 0.
!>

FERR

!>          FERR es un array REAL, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del mayor
!>          elemento en (X(j) - XTRUE) dividida por la magnitud del
!>          mayor elemento en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector
!>          solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL, dimensión (MAX(1,N))
!>          En la salida, RWORK(1) contiene el factor de crecimiento del pivote
!>          recíproco norm(A)/norm(U). Se usa la norma
!>          infinito. Si RWORK(1) es mucho menor que 1, entonces la estabilidad
!>          de la factorización LU de la matriz A (ecualizada) podría ser
!>          deficiente. Esto también significa que la solución X, el estimador de
!>          condición RCOND y la cota de error hacia adelante FERR podrían ser
!>          poco fiables. Si la factorización falla con 0<INFO<=N, entonces
!>          RWORK(1) contiene el factor de crecimiento del pivote recíproco para las
!>          primeras INFO columnas de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  U(i,i) es exactamente cero. La factorización
!>                       se ha completado, pero el factor U es exactamente
!>                       singular, por lo que la solución y las cotas de error
!>                       no se pudieron calcular. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión de
!>                       la máquina, lo que significa que la matriz es singular
!>                       a la precisión de trabajo. Sin embargo, la
!>                       solución y las cotas de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.
!>
