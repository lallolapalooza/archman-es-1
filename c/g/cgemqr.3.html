subrutina cgemqr (character side, character trans, integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) t, integer tsize, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer lwork, integer info)

CGEMQR

Propósito:

!>
!> CGEMQR sobrescribe la matriz real general M por N, C, con
!>
!>                      SIDE = 'L'     SIDE = 'R'
!>      TRANS = 'N':      Q * C          C * Q
!>      TRANS = 'T':      Q**H * C       C * Q**H
!>
!> donde Q es una matriz unitaria compleja definida como el producto
!> de reflectores elementales en bloque calculados por la factorización
!> QR delgada y alta (CGEQR)
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica Q o Q**H desde la Izquierda;
!>          = 'R': aplica Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': Sin transponer, aplica Q;
!>          = 'C': Transpuesta conjugada, aplica Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >=0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,K)
!>          Parte de la estructura de datos para representar Q como devuelto por CGEQR.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T es un array COMPLEX, de dimensión (MAX(5,TSIZE)).
!>          Parte de la estructura de datos para representar Q como devuelto por CGEQR.
!>

TSIZE

!>          TSIZE es INTEGER
!>          La dimensión del array T. TSIZE >= 5.
!>

C

!>          C es un array COMPLEX, de dimensión (LDC,N)
!>          En la entrada, la matriz M por N, C.
!>          En la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          (espacio de trabajo) array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo. La rutina
!>          solo calcula el tamaño del array WORK, devuelve este
!>          valor como WORK(1), y XERBLA no emite ningún mensaje de error relacionado con WORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

!>  o CGEQRT para calcular la factorización QR.
!>  Esta versión de CGEMQR utilizará CLAMTSQR o CGEMQRT para
!>  multiplicar la matriz Q por otra matriz.
