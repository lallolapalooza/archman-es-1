subrutina cgsvts3 (integer m, integer p, integer n, complex, dimension( lda, * ) a, complex, dimension( lda, * ) af, integer lda, complex, dimension( ldb, * ) b, complex, dimension( ldb, * ) bf, integer ldb, complex, dimension( ldu, * ) u, integer ldu, complex, dimension( ldv, * ) v, integer ldv, complex, dimension( ldq, * ) q, integer ldq, real, dimension( * ) alpha, real, dimension( * ) beta, complex, dimension( ldr, * ) r, integer ldr, integer, dimension( * ) iwork, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( 6 ) result)

CGSVTS3

Propósito:

!>
!> CGSVTS3 prueba CGGSVD3, que calcula la GSVD de una matriz M por N A
!> y una matriz P por N B:
!>              U'*A*Q = D1*R y V'*B*Q = D2*R.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es ENTERO
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,M)
!>          La matriz M por N A.
!>

AF

!>          AF es un array COMPLEJO, de dimensión (LDA,N)
!>          Detalles de la GSVD de A y B, tal como la devuelve CGGSVD3,
!>          ver CGGSVD3 para más detalles.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A y AF.
!>          LDA >= max( 1,M ).
!>

B

!>          B es un array COMPLEJO, de dimensión (LDB,P)
!>          En la entrada, la matriz P por N B.
!>

BF

!>          BF es un array COMPLEJO, de dimensión (LDB,N)
!>          Detalles de la GSVD de A y B, tal como la devuelve CGGSVD3,
!>          ver CGGSVD3 para más detalles.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de los arrays B y BF.
!>          LDB >= max(1,P).
!>

U

!>          U es un array COMPLEJO, de dimensión(LDU,M)
!>          La matriz unitaria M por M U.
!>

LDU

!>          LDU es ENTERO
!>          La dimensión principal del array U. LDU >= max(1,M).
!>

V

!>          V es un array COMPLEJO, de dimensión(LDV,M)
!>          La matriz unitaria P por P V.
!>

LDV

!>          LDV es ENTERO
!>          La dimensión principal del array V. LDV >= max(1,P).
!>

Q

!>          Q es un array COMPLEJO, de dimensión(LDQ,N)
!>          La matriz unitaria N por N Q.
!>

LDQ

!>          LDQ es ENTERO
!>          La dimensión principal del array Q. LDQ >= max(1,N).
!>

ALPHA

!>          ALPHA es un array REAL, de dimensión (N)
!>

BETA

!>          BETA es un array REAL, de dimensión (N)
!>
!>          Los pares de valores singulares generalizados de A y B, las
!>          matrices "diagonales" D1 y D2 se construyen a partir de
!>          ALPHA y BETA, ver la subrutina CGGSVD3 para detalles.
!>

R

!>          R es un array COMPLEJO, de dimensión(LDQ,N)
!>          La matriz triangular superior R.
!>

LDR

!>          LDR es ENTERO
!>          La dimensión principal del array R. LDR >= max(1,N).
!>

IWORK

!>          IWORK es un array ENTERO, de dimensión (N)
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK,
!>          LWORK >= max(M,P,N)*max(M,P,N).
!>

RWORK

!>          RWORK es un array REAL, de dimensión (max(M,P,N))
!>

RESULT

!>          RESULT es un array REAL, de dimensión (6)
!>          Las relaciones de prueba:
!>          RESULT(1) = norm( U'*A*Q - D1*R ) / ( MAX(M,N)*norm(A)*ULP)
!>          RESULT(2) = norm( V'*B*Q - D2*R ) / ( MAX(P,N)*norm(B)*ULP)
!>          RESULT(3) = norm( I - U'*U ) / ( M*ULP )
!>          RESULT(4) = norm( I - V'*V ) / ( P*ULP )
!>          RESULT(5) = norm( I - Q'*Q ) / ( N*ULP )
!>          RESULT(6) = 0        si ALPHA está en orden decreciente;
!>                    = ULPINV   en caso contrario.
!>
