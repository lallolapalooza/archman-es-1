NOMBRE

CGI::Session::Driver::db_file - Driver de CGI::Session para BerkeleyDB usando DB_File

SINOPSIS

$s = CGI::Session->new("driver:db_file", $sid);
$s = CGI::Session->new("driver:db_file", $sid, {FileName=>'/tmp/cgisessions.db'});

DESCRIPCIÓN

db_file almacena los datos de sesión en un archivo BerkelyDB usando DB_File - módulo Perl. Todas las sesiones se almacenarán en un único archivo, especificado en el argumento del driver FileName como en el ejemplo anterior. Si FileName no se proporciona, se usará por defecto /tmp/cgisess.db, o su equivalente en un sistema no UNIX.

Si la jerarquía de directorios que conduce al archivo no existe, se creará para usted.

Este módulo toma una opción UMask que se usará si DB_File tiene que crear el archivo de base de datos para usted. Por defecto, la umask es 0660.
