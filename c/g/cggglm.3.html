DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina cggglm (integer n, integer m, integer p, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) d, complex, dimension( * ) x, complex, dimension( * ) y, complex, dimension( * ) work, integer lwork, integer info)

CGGGLM

Propósito:

!>
!> CGGGLM resuelve un problema de modelo lineal Gauss-Markov (GLM) general:
!>
!>         minimizar || y ||_2   sujeto a   d = A*x + B*y
!>             x
!>
!> donde A es una matriz N por M, B es una matriz N por P, y d es un
!> vector N dado. Se asume que M <= N <= M+P, y
!>
!>            rango(A) = M    y    rango( A B ) = N.
!>
!> Bajo estas suposiciones, la ecuación restringida es siempre
!> consistente, y existe una solución única x y una solución de norma 2 mínima
!> y, que se obtiene utilizando una factorización QR generalizada
!> de las matrices (A, B) dada por
!>
!>    A = Q*(R),   B = Q*T*Z.
!>          (0)
!>
!> En particular, si la matriz B es cuadrada y no singular, entonces el problema
!> GLM es equivalente al siguiente problema de mínimos cuadrados lineales ponderados
!>
!>              minimizar || inv(B)*(d-A*x) ||_2
!>                  x
!>
!> donde inv(B) denota la inversa de B.
!>
!> Los llamadores de esta subrutina deben tener en cuenta que las comprobaciones
!> de singularidad/deficiencia de rango implementadas en esta subrutina son rudimentarias.
!> La subrutina CTRTRS llamada por esta subrutina solo señala un error debido a
!> singularidad si el problema es exactamente singular.
!>
!> Es concebible que uno (o más) de los factores involucrados en la factorización QR
!> generalizada del par (A, B) esté anormalmente cerca de ser singular sin que esta
!> subrutina señale un error. Las soluciones calculadas para tales problemas
!> casi de rango deficiente pueden ser menos precisas debido a una pérdida de precisión numérica.
!>
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices A y B.  N >= 0.
!>

M

!>          M es INTEGER
!>          El número de columnas de la matriz A.  0 <= M <= N.
!>

P

!>          P es INTEGER
!>          El número de columnas de la matriz B.  P >= N-M.
!>

A

!>          A es array COMPLEX, dimensión (LDA,M)
!>          En la entrada, la matriz A de N por M.
!>          En la salida, la parte triangular superior del array A contiene
!>          la matriz triangular superior R de M por M.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es array COMPLEX, dimensión (LDB,P)
!>          En la entrada, la matriz B de N por P.
!>          En la salida, si N <= P, el triángulo superior de la submatriz
!>          B(1:N,P-N+1:P) contiene la matriz triangular superior T de N por N;
!>          si N > P, los elementos en y por encima de la (N-P)-ésima subdiagonal
!>          contienen la matriz trapezoidal superior T de N por P.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

D

!>          D es array COMPLEX, dimensión (N)
!>          En la entrada, D es el lado izquierdo de la ecuación GLM.
!>          En la salida, D se destruye.
!>

X

!>          X es array COMPLEX, dimensión (M)
!>

Y

!>          Y es array COMPLEX, dimensión (P)
!>
!>          En la salida, X e Y son las soluciones del problema GLM.
!>

WORK

!>          WORK es array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N+M+P).
!>          Para un rendimiento óptimo, LWORK >= M+min(N,P)+max(N,P)*NB,
!>          donde NB es un límite superior para los tamaños de bloque óptimos para
!>          CGEQRF, CGERQF, CUNMQR y CUNMRQ.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1:  el factor triangular superior R asociado con A en la
!>                factorización QR generalizada del par (A, B) es exactamente
!>                singular, de modo que rango(A) < M; la solución de mínimos cuadrados
!>                no pudo calcularse.
!>          = 2:  la parte inferior de (N-M) por (N-M) del factor trapezoidal superior
!>                T asociado con B en la factorización QR generalizada
!>                del par (A, B) es exactamente singular, de modo que
!>                rango( A B ) < N; la solución de mínimos cuadrados no pudo
!>                calcularse.
!>
