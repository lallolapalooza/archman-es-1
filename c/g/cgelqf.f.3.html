Documentación de la función/subrutina

subroutine cgelqf (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CGELQF

Propósito:

!>
!> CGELQF calcula una factorización LQ de una matriz compleja M por N, A:
!>
!>    A = ( L 0 ) *  Q
!>
!> donde:
!>
!>    Q es una matriz ortogonal N por N;
!>    L es una matriz triangular inferior M por M;
!>    0 es una matriz cero M por (N-M), si M < N.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz M por N, A.
!>          En la salida, los elementos en y por debajo de la diagonal del array
!>          contienen la matriz trapezoidal inferior m por min(m,n), L (L es
!>          triangular inferior si m <= n); los elementos por encima de la diagonal,
!>          con el array TAU, representan la matriz unitaria Q como un producto
!>          de reflectores elementales (ver Detalles adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es array COMPLEX, dimension (min(M,N))
!>          Los factores escalares de los reflectores elementales (ver Detalles
!>          adicionales).
!>

WORK

!>          WORK es array COMPLEX, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) contiene el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y LWORK >= M en caso contrario.
!>          Para un rendimiento óptimo LWORK >= M*NB, donde NB es el
!>          tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(k)**H . . . H(2)**H H(1)**H, donde k = min(m,n).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i-1) = 0 y v(i) = 1; conjg(v(i+1:n)) se almacena en la salida en
!>  A(i,i+1:n), y tau en TAU(i).
!>
