Documentación de Función/Subrutina

subrutina cgqrts (integer n, integer m, integer p, complex, dimension( lda, * ) a, complex, dimension( lda, * ) af, complex, dimension( lda, * ) q, complex, dimension( lda, * ) r, integer lda, complex, dimension( * ) taua, complex, dimension( ldb, * ) b, complex, dimension( ldb, * ) bf, complex, dimension( ldb, * ) z, complex, dimension( ldb, * ) t, complex, dimension( ldb, * )bwk, integer ldb, complex, dimension( * ) taub, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( 4 ) result)

CGQRTS

Propósito:

!>
!> CGQRTS prueba CGGQRF, que calcula la factorización GQR de una
!> matriz N-por-M A y una matriz N-por-P B: A = Q*R y B = Q*T*Z.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices A y B.  N >= 0.
!>

M

!>          M es INTEGER
!>          El número de columnas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de columnas de la matriz B.  P >= 0.
!>

A

!>          A es array COMPLEX, dimension (LDA,M)
!>          La matriz N-por-M A.
!>

AF

!>          AF es array COMPLEX, dimension (LDA,N)
!>          Detalles de la factorización GQR de A y B, como es devuelto
!>          por CGGQRF, ver CGGQRF para más detalles.
!>

Q

!>          Q es array COMPLEX, dimension (LDA,N)
!>          La matriz unitaria M-por-M Q.
!>

R

!>          R es array COMPLEX, dimension (LDA,MAX(M,N))
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder de los arrays A, AF, R y Q.
!>          LDA >= max(M,N).
!>

TAUA

!>          TAUA es array COMPLEX, dimension (min(M,N))
!>          Los factores escalares de los reflectores elementales, como son
!>          devueltos por CGGQRF.
!>

B

!>          B es array COMPLEX, dimension (LDB,P)
!>          En la entrada, la matriz N-por-P A.
!>

BF

!>          BF es array COMPLEX, dimension (LDB,N)
!>          Detalles de la factorización GQR de A y B, como es devuelto
!>          por CGGQRF, ver CGGQRF para más detalles.
!>

Z

!>          Z es array COMPLEX, dimension (LDB,P)
!>          La matriz unitaria P-por-P Z.
!>

T

!>          T es array COMPLEX, dimension (LDB,max(P,N))
!>

BWK

!>          BWK es array COMPLEX, dimension (LDB,N)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder de los arrays B, BF, Z y T.
!>          LDB >= max(P,N).
!>

TAUB

!>          TAUB es array COMPLEX, dimension (min(P,N))
!>          Los factores escalares de los reflectores elementales, como son
!>          devueltos por SGGRQF.
!>

WORK

!>          WORK es array COMPLEX, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK, LWORK >= max(N,M,P)**2.
!>

RWORK

!>          RWORK es array REAL, dimension (max(N,M,P))
!>

RESULT

!>          RESULT es array REAL, dimension (4)
!>          Las ratios de prueba:
!>            RESULT(1) = norm( R - Q'*A ) / ( MAX(M,N)*norm(A)*ULP)
!>            RESULT(2) = norm( T*Z - Q'*B ) / (MAX(P,N)*norm(B)*ULP)
!>            RESULT(3) = norm( I - Q'*Q ) / ( M*ULP )
!>            RESULT(4) = norm( I - Z'*Z ) / ( P*ULP )
!>
