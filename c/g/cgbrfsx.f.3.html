CGBRFSX

Propósito:

!>
!>    CGBRFSX mejora la solución computada de un sistema de ecuaciones
!>    lineales y proporciona cotas de error y estimaciones de error hacia atrás
!>    para la solución. Además de la cota de error normwise, el código
!>    proporciona una cota de error máxima por componentes si es posible. Véase
!>    los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP para los detalles de las
!>    cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe en los
!>    argumentos EQUED, R y C a continuación. En este caso, la solución y las
!>    cotas de error devueltas son para el sistema original no equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en la matriz PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables. Si los valores predeterminados son
!>     aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que el
!>     código fuente acceda al argumento PARAMS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'R':  Equilibrado de filas, es decir, A se ha multiplicado previamente por
!>               diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A se ha multiplicado posteriormente por
!>               diag(C).
!>       = 'B':  Equilibrado tanto de filas como de columnas, es decir, A ha sido
!>               reemplazado por diag(R) * A * diag(C).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array COMPLEX, dimensión (LDAB,N)
!>     La matriz de banda original A, almacenada en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna de la
!>     matriz AB de la siguiente manera:
!>     AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal de la matriz AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array COMPLEX, dimensión (LDAFB,N)
!>     Detalles de la factorización LU de la matriz de banda A, tal como
!>     la calculó CGBTRF. U se almacena como una matriz de banda triangular superior
!>     con KL+KU superdiagonales en las filas 1 a KL+KU+1, y
!>     los multiplicadores utilizados durante la factorización se almacenan en
!>     las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal de la matriz AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Los índices de pivote de CGETRF; para 1<=i<=N, la fila i de la
!>     matriz se intercambió con la fila IPIV(i).
!>

R

!>          R es array REAL, dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>     multiplica a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede. R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es de salida, cada elemento de R es una potencia de la base.
!>     Si R es de entrada, cada elemento de R debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea subdesbordado o sobrebordado. Los errores de redondeo durante el escalado
!>     conducen al refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

C

!>          C es array REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>     multiplica a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede. C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es de salida, cada elemento de C es una potencia de la base.
!>     Si C es de entrada, cada elemento de C debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El escalado por
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea subdesbordado o sobrebordado. Los errores de redondeo durante el escalado
!>     conducen al refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es array COMPLEX, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

X

!>          X es array COMPLEX, dimensión (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como la calculó CGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal de la matriz X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>     Condición recíproca escalada. Esta es una estimación de la
!>     condición de Skeel recíproca de la matriz A después del
!>     equilibrado (si se realizó). Si esto es menor que la precisión de la máquina
