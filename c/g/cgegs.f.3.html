Documentación de Función/Subrutina

subrutina cgegs (character jobvsl, character jobvsr, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) alpha, complex, dimension( * ) beta, complex, dimension( ldvsl, * ) vsl, integer ldvsl, complex, dimension( ldvsr, * ) vsr, integer ldvsr, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, integer info)

CGEGS calcula los eigenvalores, la forma de Schur y, opcionalmente, los vectores de Schur izquierdos y/o derechos de un par de matrices complejas (A,B)

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina CGGES.
!>
!> CGEGS calcula los eigenvalores, la forma de Schur y, opcionalmente,
!> los vectores de Schur izquierdos y/o derechos de un par de matrices complejas (A,B).
!> Dadas dos matrices cuadradas A y B, la factorización de Schur
!> generalizada tiene la forma
!>
!>    A = Q*S*Z**H,  B = Q*T*Z**H
!>
!> donde Q y Z son matrices unitarias y S y T son triangulares superiores.
!> Las columnas de Q son los vectores de Schur izquierdos
!> y las columnas de Z son los vectores de Schur derechos.
!>
!> Si solo se necesitan los eigenvalores de (A,B), se debe usar la rutina
!> controladora CGEGV en su lugar. Vea CGEGV para una descripción de los
!> eigenvalores del problema de eigenvalores no simétrico generalizado
!> (GNEP).
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos (devueltos en VSL).
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos (devueltos en VSR).
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR. N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA, N)
!>          En la entrada, la matriz A.
!>          En la salida, la matriz triangular superior S de la factorización
!>          de Schur generalizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX, dimensión (LDB, N)
!>          En la entrada, la matriz B.
!>          En la salida, la matriz triangular superior T de la factorización
!>          de Schur generalizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX, dimensión (N)
!>          Los escalares complejos alpha que definen los eigenvalores de
!>          GNEP. ALPHA(j) = S(j,j), el elemento diagonal de la forma de Schur
!>          de A.
!>

BETA

!>          BETA es un array COMPLEX, dimensión (N)
!>          Los escalares reales no negativos beta que definen los
!>          eigenvalores de GNEP. BETA(j) = T(j,j), el elemento diagonal
!>          del factor triangular T.
!>
!>          En conjunto, las cantidades alpha = ALPHA(j) y beta = BETA(j)
!>          representan el j-ésimo eigenvalor del par de matrices (A,B), en
!>          una de las formas lambda = alpha/beta o mu = beta/alpha.
!>          Dado que cualquiera de los dos, lambda o mu, puede desbordarse, en
!>          general no deberían calcularse.
!>

VSL

!>          VSL es un array COMPLEX, dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', la matriz de vectores de Schur izquierdos Q.
!>          No se referencia si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >= 1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es un array COMPLEX, dimensión (LDVSR,N)
!>          Si JOBVSR = 'V', la matriz de vectores de Schur derechos Z.
!>          No se referencia si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,2*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>          Para calcular el valor óptimo de LWORK, llame a ILAENV para obtener
!>          los tamaños de bloque (para CGEQRF, CUNMQR y CUNGQR). Luego calcule:
!>          NB -- el MÁXIMO de los tamaños de bloque para CGEQRF, CUNMQR y CUNGQR;
!>          el LWORK óptimo es N*(NB+1).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un array REAL, dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          =1,...,N:
!>                La iteración QZ falló. (A,B) no están en forma de Schur,
!>                pero ALPHA(j) y BETA(j) deberían ser correctos para
!>                j=INFO+1,...,N.
!>          > N:  errores que usualmente indican problemas de LAPACK:
!>                =N+1: retorno de error de CGGBAL
!>                =N+2: retorno de error de CGEQRF
!>                =N+3: retorno de error de CUNMQR
!>                =N+4: retorno de error de CUNGQR
!>                =N+5: retorno de error de CGGHRD
!>                =N+6: retorno de error de CHGEQZ (distinto de iteración
!>                                               fallida)
!>                =N+7: retorno de error de CGGBAK (calculando VSL)
!>                =N+8: retorno de error de CGGBAK (calculando VSR)
!>                =N+9: retorno de error de CLASCL (varios lugares)
!>
