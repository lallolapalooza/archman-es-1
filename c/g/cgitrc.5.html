NOMBRE

cgitrc - configuración en tiempo de ejecución para cgit

SINOPSIS

Cgitrc contiene todos los ajustes en tiempo de ejecución de cgit, incluida la lista de repositorios de git, formateada como una lista de pares NOMBRE=VALOR separados por saltos de línea. Las líneas en blanco y las líneas que comienzan con # se ignoran.

UBICACIÓN

La ubicación predeterminada de cgitrc, definida en tiempo de compilación, es /etc/cgitrc. En tiempo de ejecución, cgit consultará la variable de entorno CGIT_CONFIG y, si está definida, usará su valor en su lugar.

AJUSTES GLOBALES

about-filter

Especifica un comando que se invocará para dar formato al contenido de las páginas "about" (tanto de nivel superior como para cada repositorio). El comando recibirá el contenido del archivo "about" en su STDIN, el nombre del archivo como primer argumento, y la salida estándar del comando se incluirá literalmente en la página "about". Valor predeterminado: ninguno. Ver también: "FILTER API".

agefile

Especifica una ruta, relativa a la ruta de cada repositorio, que se puede utilizar para especificar la fecha y hora del commit más reciente en el repositorio. La primera línea del archivo se utiliza como entrada para la función "parse_date" en libgit. El formato de marca de tiempo recomendado es "aaaa-mm-dd hh:mm:ss". Es posible que desee generar este archivo a partir de un hook post-receive. Valor predeterminado: "info/web/last-modified".

auth-filter

Especifica un comando que se invocará para autenticar el acceso al repositorio. Recibe bastantes argumentos y datos tanto en stdin como en stdout para el procesamiento de autenticación. Los detalles se presentan más adelante en este documento. Si no se especifica ningún filtro de autenticación, no se realiza ninguna autenticación. Valor predeterminado: ninguno. Ver también: "FILTER API".

branch-sort

Indicador que, cuando se establece en "age", habilita la ordenación por fecha en la lista de referencias de ramas, y cuando se establece en "name" habilita la ordenación por nombre de rama. Valor predeterminado: "name".

cache-about-ttl

Número que especifica el tiempo de vida, en minutos, de la versión en caché de la página "about" del repositorio. Ver también: "CACHE". Valor predeterminado: "15".

cache-dynamic-ttl

Número que especifica el tiempo de vida, en minutos, de la versión en caché de las páginas de repositorio a las que se accede sin un SHA1 fijo. Ver también: "CACHE". Valor predeterminado: "5".

cache-repo-ttl

Número que especifica el tiempo de vida, en minutos, de la versión en caché de la página de resumen del repositorio. Ver también: "CACHE". Valor predeterminado: "5".

cache-root

Ruta utilizada para almacenar las entradas de caché de cgit. Valor predeterminado: "/var/cache/cgit". Ver también: "MACRO EXPANSION".

cache-root-ttl

Número que especifica el tiempo de vida, en minutos, de la versión en caché de la página de índice del repositorio. Ver también: "CACHE". Valor predeterminado: "5".

cache-scanrc-ttl

Número que especifica el tiempo de vida, en minutos, del resultado del escaneo de una ruta en busca de repositorios git. Ver también: "CACHE". Valor predeterminado: "15".

case-sensitive-sort

Ordena los elementos en la lista de repositorios de forma sensible a mayúsculas y minúsculas. Valor predeterminado: "1". Ver también: repository-sort, section-sort.

cache-size

El número máximo de entradas en la caché de cgit. Cuando se establece en "0", la caché se deshabilita. Ver también: "CACHE". Valor predeterminado: "0"

cache-snapshot-ttl

Número que especifica el tiempo de vida, en minutos, de la versión en caché de las instantáneas. Ver también: "CACHE". Valor predeterminado: "5".

cache-static-ttl

Número que especifica el tiempo de vida, en minutos, de la versión en caché de las páginas de repositorio a las que se accede con un SHA1 fijo. Ver también: "CACHE". Valor predeterminado: -1".

clone-prefix

Lista de prefijos comunes separados por espacios que, cuando se combinan con una URL de repositorio, generan URLs de clonación válidas para el repositorio. Esta configuración solo se utiliza si repo.clone-url no está especificado. Valor predeterminado: ninguno.

clone-url

Lista de plantillas de URL de clonación separadas por espacios. Esta configuración solo se utiliza si repo.clone-url no está especificado. Valor predeterminado: ninguno. Ver también: "MACRO EXPANSION", "FILTER API".

commit-filter

Especifica un comando que se invocará para formatear mensajes de commit. El comando recibirá el mensaje en su STDIN, y la salida estándar del comando se incluirá literalmente como mensaje de commit, es decir, esto se puede usar para implementar la integración con el rastreador de errores. Valor predeterminado: ninguno. Ver también: "FILTER API".

commit-sort

Indicador que, cuando se establece en "date", habilita la ordenación estricta por fecha en el registro de commits, y cuando se establece en "topo" habilita la ordenación topológica estricta. Si no está establecido, se utiliza la ordenación predeterminada de "git log". Valor predeterminado: no establecido.

css

URL que especifica el documento css a incluir en todas las páginas de cgit. Valor predeterminado: "/cgit.css". Se puede dar varias veces, cada ruta de URL css se agrega en la sección head del documento en orden.

email-filter

Especifica un comando que se invocará para formatear los nombres y direcciones de correo electrónico de los contribuidores, autores y etiquetadores, tal como se representan en varios lugares de la interfaz de cgit. Este comando recibirá una dirección de correo electrónico y una cadena de página de origen como argumentos de línea de comandos, y el texto en STDIN. Debe escribir el texto formateado de nuevo en STDOUT. Valor predeterminado: ninguno. Ver también: "FILTER API".

embedded

Indicador que, cuando se establece en "1", hará que cgit genere un fragmento html adecuado para ser incrustado en otras páginas html. Valor predeterminado: ninguno. Ver también: "noheader".

enable-blame

Indicador que, cuando se establece en "1", permitirá a cgit proporcionar una página de "blame" para los archivos, y generará enlaces a esa página en los lugares apropiados. Valor predeterminado: "0".

enable-commit-graph

Indicador que, cuando se establece en "1", hará que cgit imprima un gráfico de historial de commits en arte ASCII a la izquierda de los mensajes de commit en la página de registro de commits. Valor predeterminado: "0".

enable-filter-overrides

Indicador que, cuando se establece en "1", permite que todas las configuraciones de filtro se invaliden en archivos cgitrc específicos del repositorio. Valor predeterminado: ninguno.

enable-follow-links

Indicador que, cuando se establece en "1", permite a los usuarios seguir un archivo en la vista de registro. Valor predeterminado: "0".

enable-git-config

Indicador que, cuando se establece en "1", permitirá a cgit utilizar la configuración de git para establecer cualquier configuración específica del repositorio. Esta opción se utiliza junto con "scan-path" y debe definirse previamente para aumentar la configuración específica del repositorio. Las claves gitweb.owner, gitweb.category, gitweb.description y gitweb.homepage se mapearán a las claves cgit repo.owner, repo.section, repo.desc y repo.homepage respectivamente. Todas las claves de configuración de git que comiencen con "cgit." se mapearán a la clave "repo." correspondiente en cgit. Valor predeterminado: "0". Ver también: scan-path, section-from-path.

enable-http-clone

Si se establece en "1", cgit actuará como un endpoint HTTP "dumb" para clones de git. Puede agregar "http://$HTTP_HOST$SCRIPT_NAME/$CGIT_REPO_URL" a clone-url para exponer esta función. Si utiliza una forma alternativa de servir repositorios git, es posible que desee deshabilitar esto. Valor predeterminado: "1".

enable-html-serving

Indicador que, cuando se establece en "1", permitirá que el manejador /plain sirva encabezados de tipo MIME que resulten en que el archivo se trate como HTML por el navegador. Cuando se establece en "0", dichos tipos de archivo se devuelven en su lugar como text/plain o application/octet-stream. Valor predeterminado: "0". Ver también: "repo.enable-html-serving".

enable-index-links

Indicador que, cuando se establece en "1", hará que cgit genere enlaces adicionales para cada repo en el índice de repositorios (específicamente, a las páginas "summary", "commit" y "tree"). Valor predeterminado: "0".

enable-index-owner

Indicador que, cuando se establece en "1", hará que cgit muestre el propietario de cada repo en el índice de repositorios. Valor predeterminado: "1"
.

enable-log-filecoun

t

"0".

enable-log-linecoun

t
Bandera que, cuando se establece en "1", hará que cgit imprima el número de líneas añadidas y eliminadas para cada commit en la página de registro del repositorio. Valor predeterminado:
"0".

enable-remote-branche

s
Bandera que, cuando se establece en "1", hará que cgit muestre ramas remotas en las vistas de resumen y referencias. Valor predeterminado: "0". Ver también: "repo.enable-remote-branches"
.

enable-subject-link

s
Bandera que, cuando se establece en "1", hará que cgit use el asunto del commit padre como texto de enlace al generar enlaces a commits padres en la vista de commit. Valor predeterminado: "0". Ver también: "repo.enable-subject-links"
.

enable-tree-linenumber

s
Bandera que, cuando se establece en "1", hará que cgit genere enlaces de números de línea para blobs de texto plano impresos en la vista de árbol. Valor predeterminado:
"1".

favico

n
URL utilizada como enlace a un icono de acceso directo para cgit. Se sugiere usar el valor "/favicon.ico" ya que ciertos navegadores ignorarán otros valores. Valor predeterminado: "/favicon.
ico".

t
La forma en que se ordenan los repositorios en cada sección. Los valores válidos son "name" para ordenar por el nombre del repositorio o "age" para ordenar por el repositorio actualizado más recientemente. Valor predeterminado: "name". Ver también: section, case-sensitive-sort,

Texto utilizado como contenido para la meta-etiqueta "robots". Valor predeterminado: "index,

Texto impreso debajo del encabezado en la página de índice del repositorio. Valor predeterminado: "a fast webinterface for the git

e
El contenido del archivo especificado con esta opción será incluido literalmente debajo del enlace "about" en la página de índice del repositorio. Valor predeterminado:

Texto impreso como encabezado en la página de índice del repositorio. Valor predeterminado: "Git Repository

scan-hidden-pat

h
Si se establece en "1" y scan-path está habilitado, scan-path recursará en directorios cuyo nombre comienza con un punto (.). De lo contrario, scan-path evitará tales directorios (considerados como "ocultos"). Tenga en cuenta que esto no se aplica al directorio ".git" en repositorios no bare. Esto debe definirse antes de scan-path. Valor predeterminado: 0. Ver también:
scan-path.

scan-pat

h
Una ruta que será escaneada en busca de repositorios. Si la caché está habilitada, el resultado se almacenará en caché como un archivo de inclusión cgitrc en el directorio de caché. Si project-list se ha definido antes de scan-path, scan-path carga solo los directorios listados en el archivo al que apunta project-list. Tenga en cuenta que solo se aplicarán a cada repositorio los ajustes globales tomados antes de la directiva scan-path. Valor predeterminado: ninguno. Ver también: cache-scanrc-ttl, project-list, "EXPANSIÓN DE
MACROS".

sectio

n
El nombre de la sección del repositorio actual: todos los repositorios definidos después de esta opción heredarán el nombre de la sección actual. Valor predeterminado:
ninguno.

section-sor

t
Bandera que, cuando se establece en "1", ordenará las secciones en el listado de repositorios por nombre. Establezca esta bandera en "0" si se debe preservar el orden en el archivo cgitrc. Valor predeterminado: "1". Ver también: section, case-sensitive-sort, repository-sort
.

section-from-pat

h
Un número que, si se define antes de scan-path, especifica cuántos elementos de la ruta de cada repositorio usar como nombre de sección predeterminado. Si es negativo, cgit descartará el número especificado de elementos de la ruta por encima del directorio del repositorio. Valor predeterminado:
"0".

side-by-side-diff

s
Si se establece en "1", muestra diffs lado a lado en lugar de unidiffs por defecto. Valor predeterminado:
"0".

snapshot

s
Texto que especifica el conjunto predeterminado de formatos de instantánea para los cuales cgit genera enlaces. El valor es una lista separada por espacios de cero o más de los valores "tar", "tar.gz", "tar.bz2", "tar.lz", "tar.xz", "tar.zst" y "zip". El valor especial "all" habilita todos los formatos de instantánea. Valor predeterminado: ninguno. Todos los compresores usan la configuración predeterminada. Algunos ajustes pueden influirse con variables de entorno, por ejemplo, establezca ZSTD_CLEVEL=10 en el entorno del servidor web para una compresión zstd más alta (pero más lenta)
.

source-filte

r
Especifica un comando que será invocado para formatear blobs de texto plano en la vista de árbol. El comando recibirá el contenido del blob en su STDIN y el nombre del blob como su único argumento de línea de comandos. El STDOUT del comando será incluido literalmente como elblob contents, es decir, esto puede utilizarse para implementar, por ejemplo, resaltado de sintaxis. Valor por defecto: none. Ver también: "FILTER API".

summary-branches

Especifica el número de ramas a mostrar en la vista "summary" del repositorio. Valor por defecto: "10".

summary-log

Especifica el número de entradas de registro a mostrar en la vista "summary" del repositorio. Valor por defecto: "10".

summary-tags

Especifica el número de etiquetas a mostrar en la vista "summary" del repositorio. Valor por defecto: "10".

strict-export

Nombre de archivo que, si se especifica, debe estar presente dentro del repositorio para que cgit permita el acceso a ese repositorio. Esto se puede utilizar para emular la funcionalidad EXPORT_OK y STRICT_EXPORT de gitweb y limitar los repositorios de cgit para que coincidan con los exportados por git-daemon. Esta opción debe definirse antes de scan-path.

virtual-root

URL que, si se especifica, se utilizará como raíz para todos los enlaces de cgit. También hará que cgit genere URLs virtuales, es decir, URLs como /cgit/tree/README en lugar de ?r=cgit&p=tree&path=README. Valor por defecto: none. NOTA: cgit ha aprendido recientemente a utilizar PATH_INFO para lograr el mismo tipo de URLs virtuales, por lo que es probable que esta opción se desapruebe.

AJUSTES DEL REPOSITORIO

repo.about-filter

Anula el filtro about-filter predeterminado. Valor por defecto: none. Ver también: "enable-filter-overrides". Ver también: "FILTER API".

repo.branch-sort

Indicador que, cuando se establece en "age", habilita la ordenación por fecha en la lista de referencias de ramas, y cuando se establece en "name" habilita la ordenación por nombre de rama. Valor por defecto: "name".

repo.clone-url

Una lista de URLs separadas por espacios que se pueden utilizar para clonar este repositorio. Valor por defecto: none. Ver también: "MACRO EXPANSION".

repo.commit-filter

Anula el filtro commit-filter predeterminado. Valor por defecto: none. Ver también: "enable-filter-overrides". Ver también: "FILTER API".

repo.commit-sort

Indicador que, cuando se establece en "date", habilita la ordenación estricta por fecha en el registro de commits, y cuando se establece en "topo" habilita la ordenación topológica estricta. Si no se establece, se utiliza la ordenación predeterminada de "git log". Valor por defecto: no establecido.

repo.defbranch

El nombre de la rama predeterminada para este repositorio. Si no existe dicha rama en el repositorio, se utilizará el primer nombre de rama (al ordenar) como predeterminado. Valor por defecto: la rama a la que apunta HEAD, o "master" si no hay un HEAD adecuado.

repo.desc

El valor que se mostrará como descripción del repositorio. Valor por defecto: none.

repo.email-filter

Anula el filtro email-filter predeterminado. Valor por defecto: none. Ver también: "enable-filter-overrides". Ver también: "FILTER API".

repo.enable-blame

Un indicador que se puede utilizar para deshabilitar la configuración global ‘enable-blame’. Valor por defecto: none.

repo.enable-commit-graph

Un indicador que se puede utilizar para deshabilitar la configuración global ‘enable-commit-graph’. Valor por defecto: none.

repo.enable-html-serving

Un indicador que se puede utilizar para anular la configuración global enable-html-serving. Valor por defecto: none.

repo.enable-log-filecount

Un indicador que se puede utilizar para deshabilitar la configuración global ‘enable-log-filecount’. Valor por defecto: none.

repo.enable-log-linecount

Un indicador que se puede utilizar para deshabilitar la configuración global ‘enable-log-linecount’. Valor por defecto: none.

repo.enable-remote-branches

Indicador que, cuando se establece en "1", hará que cgit muestre las ramas remotas en las vistas de resumen y referencias. Valor por defecto: <enable-remote-branches>.

repo.enable-subject-links

Un indicador que se puede utilizar para anular la configuración global ‘enable-subject-links’. Valor por defecto: none.

repo.extra-head-content

Este valor se añadirá literalmente a la sección head de cada página mostrada para este repositorio. Valor por defecto: none.

repo.hide

Indicador que, cuando se establece en "1", oculta el repositorio del índice de repositorios. El repositorio aún se puede acceder proporcionando una ruta directa. Valor por defecto: "0". Ver también: "repo.ignore".

repo.homepage

El valor que se mostrará como página principal del repositorio. Valor por defecto: none.

repo.ignore

Indicador que, cuando se establece en "1", ignora el repositorio. El repositorio no se muestra en el índice y no se puede acceder a él proporcionando una ruta directa. Valor por defecto: "0". Ver también: "repo.hide".

repo.logo

URL que especifica la fuente de una imagen que se utilizará como logotipo en las páginas de este repositorio. Valor por defecto: logotipo global.

repo.logo-link

URL que se carga al hacer clic en la imagen del logotipo de cgit. Si no se especifica, se utilizará la URL calculada de la página del índice de repositorios. Valor por defecto: logotipo global-link.

repo.module-link

Texto que se utilizará como cadena de formato para un hipervínculo cuando se imprima un subódulo en una lista de directorios. Los argumentos para la cadena de formato son la ruta y el SHA1 del commit del submódulo. Valor por defecto: <module-link>

repo.module-link.<path>

Texto que se utilizará como cadena de formato para un hipervínculo cuando se imprima un subódulo con la ruta de subdirectorio especificada en una lista de directorios. El único argumento para la cadena de formato es el SHA1 del commit del submódulo. Valor por defecto: none.

repo.max-stats

Anula el período máximo de estadísticas predeterminado. Los valores válidos son iguales a los especificados para la configuración global "max-stats". Valor por defecto: none.

repo.name

El valor que se mostrará como nombre del repositorio. Valor por defecto: <repo.url>.

repo.owner

Un valor utilizado para identificar al propietario del repositorio. Valor por defecto: none.

repo.owner-filter

Anula el filtro owner-filter predeterminado. Valor por defecto: none. Ver también: "enable-filter-overrides". Ver también: "FILTER API".

repo.path

Una ruta absoluta al directorio del repositorio. Para repositorios no bare, este es el directorio .git. Valor por defecto: none.

repo.readme

Una ruta (relativa a <repo.path>) que especifica un archivo para incluir literalmente como página "Acerca de" para este repositorio. También puede especificar una referencia de git por cabeza o por hash anteponiendo la referencia seguida de dos puntos. Por ejemplo, "master:docs/readme.mkd". Si el valor comienza con dos puntos, es decir, ":docs/readme.rst", se utilizará la cabeza dada en la consulta o la rama predeterminada del repositorio. Compartir cualquier archivo expondrá todo el árbol de directorios a los endpoints "/about/PATH", así que asegúrese de que no haya archivos no públicos ubicados en el mismo directorio que el archivo readme. Valor por defecto: <readme>.

repo.section

Anula el nombre de sección actual para este repositorio. Valor por defecto: none.

repo.snapshots

Una máscara de formatos de instantánea para este repositorio para los que cgit genera enlaces, restringida por la configuración global "snapshots". Valor por defecto: <snapshots>.

repo.snapshot-prefix

Prefijo a utilizar para los enlaces de instantáneas en lugar del nombre base del repositorio. Por ejemplo, el repositorio "linux-stable" puede desear establecer esto en "linux" para que las instantáneas tengan el formato "linux-3.15.4" en lugar de "linux-stable-3.15.4". Valor por defecto: <vacío>, lo que significa usar el nombre base del repositorio.

repo.source-filter

Anula el filtro source-filter predeterminado. Valor por defecto: none. Ver también: "enable-filter-overrides". Ver también: "FILTER API".

repo.url

La URL relativa utilizada para acceder al repositorio. Esta debe ser la primera opción especificada para cada repositorio. Valor por defecto: none.

ARCHIVO CGITRC ESPECIFICO DEL REPOSITORIO

Cuando se utiliza la opción "scan-path" para descubrir automáticamente repositorios git, cgit intentará analizar el archivo "cgitrc" dentro de cualquier repositorio encontrado. Dicho archivo de configuración específico del repositorio puede contener cualquiera de las opciones específicas del repositorio descritas anteriormente, excepto "repo.url" y "repo.path". Además, las opciones "filter" solo se reconocen en archivos de configuración específicos del repositorio cuando "enable-filter-overrides" se establece en "1".

Nota: el prefijo "repo." se elimina de los nombres de las opciones en los archivos de configuración específicos del repositorio, por ejemplo, "repo.desc" se convierte en "desc".

API DE FILTROS

Por defecto, los filtros son procesos separados que se ejecutan cada vez que son necesarios. Se pueden utilizar tecnologías alternativas anteponiendo la especificación del filtro con la cadena relevante; los valores disponibles son:

exec:

El modo predeterminado de "un proceso por filtro".

lua:

Ejecuta el script utilizando un intérprete Lua incorporado. El script se carga una vez por ejecución de cgit y puede ser llamado varias veces durante la vida útil de cgit, lo que lo convierte en una buena opción para filtros repetidos como el filtro de correo electrónico. Se llama al activar el filtro para un conjunto particular de datos.

Se llama cada vez que cgit escribe datos en la página web.

filter_close()

Se llama cuando se completa la operación de filtrado actual. Debe devolver un valor entero. Normalmente, 0 indica éxito.

CACH

É

Todos los valores de ttl de la caché están en minutos. Los valores de ttl negativos indican que un tipo de página nunca expirará, y por lo tanto la p

rimera vez que se accede a una URL, el resultado se almacenará en caché indefinidamente, incluso si el repositorio git subyacente cambia. A la invers
a, cuando el valor de ttl es cero, la caché está deshabilitada para ese tipo de página en particular, y el tipo de página nunca se almacena en caché.

FIRMA

S

Cgit puede alojar firmas .asc correspondientes a varios formatos de instantánea, mediante el uso de git notes. Por ejemplo, el siguiente comando puede usarse para añadir una firma a un archivo .tar.

xz: 
git notes --ref=refs/notes/signatures/tar.xz add -C
"$( gpg --output - --armor --detach-sign cgit-
1.1.tar.xz | git hash-object -w --stdin )" v1.1

Si en cambio es deseable adjuntar una firma del .tar subyacente, este será enlazado, como caso especial, junto a un enlace .tar.* que no tenga su propia firma. Por ejemplo, una firma del tarball de la etiqueta más reciente podría añadirse con un comando

similar: 
tag="$(git describe --abbrev=0)"
git notes --ref=refs/notes/signatures/tar add
-C "$( git archive --format tar --prefix "cgit-${tag#v}/" "$tag" | g
pg --output - --armor --detach-sign | git hash-object -w --stdin )" "$tag"

Dado que se espera que git-archive(1) produzca una sal

ida estable entre versiones, esto permite generar una f
irma a largo plazo del contenido de una etiqueta dada.
