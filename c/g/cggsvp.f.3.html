CGGSVP

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina CGGSVP3.
!>
!> CGGSVP calcula matrices unitarias U, V y Q tales que
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz A12 de dimensión K-por-K y la matriz B13 de dimensión
!> L-por-L son triangulares superiores no singulares; A23 es triangular
!> superior de dimensión L-por-L si M-K-L >= 0, de lo contrario A23 es
!> trapezoidal superior de dimensión (M-K)-por-L. K+L = el rango numérico
!> efectivo de la matriz (A**H,B**H)**H de dimensión (M+P)-por-N.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición de Valor Singular Generalizada (GSVD), ver la subrutina
!> CGGSVD.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  se calcula la matriz unitaria U;
!>          = 'N':  no se calcula U.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  se calcula la matriz unitaria V;
!>          = 'N':  no se calcula V.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  se calcula la matriz unitaria Q;
!>          = 'N':  no se calcula Q.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B. P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B. N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          A la entrada, la matriz A de dimensión M-por-N.
!>          A la salida, A contiene la matriz triangular (o trapezoidal)
!>          descrita en la sección Propósito.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX, dimensión (LDB,N)
!>          A la entrada, la matriz B de dimensión P-por-N.
!>          A la salida, B contiene la matriz triangular descrita en
!>          la sección Propósito.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es REAL
!>

TOLB

!>          TOLB es REAL
!>
!>          TOLA y TOLB son los umbrales para determinar el rango numérico
!>          efectivo de la matriz B y de un subbloque de A. Generalmente,
!>          se establecen en
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El tamaño de TOLA y TOLB puede afectar el tamaño de los errores
!>          hacia atrás de la descomposición.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          A la salida, K y L especifican la dimensión de los subbloques
!>          descritos en la sección Propósito.
!>          K + L = rango numérico efectivo de (A**H,B**H)**H.
!>

U

!>          U es un array COMPLEX, dimensión (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz unitaria U.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!>

V

!>          V es un array COMPLEX, dimensión (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz unitaria V.
!>          Si JOBV = 'N', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es un array COMPLEX, dimensión (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz unitaria Q.
!>          Si JOBQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N)
!>

RWORK

!>          RWORK es un array REAL, dimensión (2*N)
!>

TAU

!>          TAU es un array COMPLEX, dimensión (N)
!>

WORK

!>          WORK es un array COMPLEX, dimensión (max(3*N,M,P))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles adicionales:

La subrutina utiliza la subrutina de LAPACK CGEQPF para la factorización QR con pivoteo de columnas para detectar el rango numérico efectivo de la matriz A. Puede ser reemplazada por una mejor estrategia de determinación del rango.
