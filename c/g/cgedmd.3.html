CGEDMD calcula la Descomposición en Modos Dinámicos (DMD) para un par de matrices de instantáneas de

datos.

Propósito

: 
!>    CGEDMD calcula la Descomposición en Modos Dinámicos (DMD) para
!>    un par de matrices de instantáneas de datos. Para las matrices de
!>    entrada X e Y tales que Y = A*X con una matriz A inaccesible,
!>    CGEDMD calcula un cierto número de pares de Ritz de A usando
!>    la extracción estándar de Rayleigh-Ritz de un subespacio de
!>    range(X) que se determina usando los vectores singulares izquierdos
!>    principales de X. Opcionalmente, CGEDMD devuelve los residuos
!>    de los pares de Ritz calculados, la información necesaria para
!>    un refinamiento de los vectores de Ritz, o los autovectores de
!>    la DMD Exacta.
!>    Para más detalles, ver las referencias listadas
!>    abajo. Para más detalles de la implementación, ver [3].
!
>

!>        decompositions: analysis and enhancements,

Parámetro

s
JOBS 
!>    JOBS (entrada) CHARACTER*1
!>    Determina si las instantáneas de datos iniciales se escalan
!>    por una matriz diagonal.
!>    'S' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           con una matriz diagonal D de modo que X*D tiene columnas
!>           no nulas unitarias (en la norma euclidiana 2)
!>    'C' :: Las instantáneas se escalan como con la opción 'S'.
!>           Si se encuentra que la i-ésima columna de X es un vector
!>           cero y la i-ésima columna correspondiente de Y es
!>           no nula, entonces la i-ésima columna de Y se establece en
!>           cero y se eleva una bandera de advertencia.
!>    'Y' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           por una matriz diagonal D de modo que Y*D tiene columnas
!>           no nulas unitarias (en la norma euclidiana 2)
!>    'N' :: Sin escalado de datos.
!
>

JOB

Z 
!>    JOBZ (entrada) CHARACTER*1
!>    Determina si los autovectores (modos de Koopman) serán
!>    calculados.
!>    'V' :: Los autovectores (modos de Koopman) serán calculados
!>           y devueltos en la matriz Z.
!>           Ver la descripción de Z.
!>    'F' :: Los autovectores (modos de Koopman) serán devueltos
!>           en forma factorizada como el producto X(:,1:K)*W, donde X
!>           contiene una base POD (vectores singulares izquierdos
!>           principales de la matriz de datos X) y W contiene los autovectores
!>           del cociente de Rayleigh correspondiente.
!>           Ver las descripciones de K, X, W, Z.
!>    'N' :: Los autovectores no se calculan.
!
>

JOB

R 
!>    JOBR (entrada) CHARACTER*1
!>    Determina si calcular los residuos.
!>    'R' :: Los residuos para los auto-pares calculados serán
!>           calculados y almacenados en el arreglo RES.
!>           Ver la descripción de RES.
!>           Para que esta opción sea legal, JOBZ debe ser 'V'.
!>    'N' :: Los residuos no se calculan.
!
>

JOB

F 
!>    JOBF (entrada) CHARACTER*1
!>    Especifica si almacenar información necesaria para el post-
!>    procesamiento (p. ej., calcular vectores de Ritz refinados)
!>    'R' :: La matriz necesaria para el refinamiento de los vectores
!>           de Ritz se calcula y almacena en el arreglo B.
!>           Ver la descripción de B.
!>    'E' :: Los autovectores sin escalar de la DMD Exacta son
!>           calculados y devueltos en el arreglo B. Ver la
!>           descripción de B.
!>    'N' :: No se calculan datos de refinamiento de autovectores.
!
>

WHTSV

D 
!>    WHTSVD (entrada) INTEGER, WHSTVD en { 1, 2, 3, 4 }
!>    Permite una selección del algoritmo SVD de la
!>    biblioteca LAPACK.

JOBR


    JOBR (input) CHARACTER*1
    Specifies whether to compute the residual vectors.
    = 'R' : Compute the residual vectors.
    = 'N' : Do not compute the residual vectors.



JOBS


    JOBS (input) CHARACTER*1
    Specifies the form of the output.
    = 'N' : Do not normalize the columns of X.
    = 'S' : Normalize the columns of X. This option
            is recommended if the columns of X vary
            considerably in norm.
    = 'C' : Normalize the columns of X and Y.
            This option requires that Y is not
            referenced.



WHTSVD


    WHTSVD (input) INTEGER
    Specifies the SVD method to be used.
    1 :: CGESVD (el algoritmo QR SVD)
    2 :: CGESDD (el algoritmo Divide and Conquer; si hay
         suficiente espacio de trabajo disponible, esta es la opción más rápida)
    3 :: CGESVDQ (el SVD QR precondicionado; este y el 4
         son las opciones más precisas)
    4 :: CGEJSV (el SVD de Jacobi precondicionado; este y el 3
         son las opciones más precisas)
    Para los cuatro métodos anteriores, es posible una diferencia significativa en
    la precisión de los valores singulares pequeños si
    las instantáneas varían en norma de modo que X está severamente
    mal condicionada. Si los valores singulares pequeños (menores que EPS*||X||)
    son de interés y JOBS=='N', entonces
    las opciones (3, 4) dan los resultados más precisos, donde
    la opción 4 es ligeramente mejor y con un trasfondo teórico más sólido.
    Si JOBS=='S', es decir, las columnas de X se normalizarán,
    entonces todos los métodos dan resultados casi igualmente precisos.



M


    M (entrada) INTEGER, M>= 0
    La dimensión del espacio de estados (la dimensión de fila de X, Y).



N


    N (entrada) INTEGER, 0 <= N <= M
    El número de pares de instantáneas de datos
    (el número de columnas de X e Y).



X


    X (entrada/salida) COMPLEX(KIND=WP) array M-por-N
    > Al entrar, X contiene la matriz de instantáneas de datos X. Se
    asume que las normas de las columnas de X están en el rango de
    los números de punto flotante normalizados.
    < Al salir, las K columnas principales de X contienen una base POD,
    es decir, los K vectores singulares izquierdos principales de la matriz de datos de entrada
    X, U(:,1:K). Todas las N columnas de X contienen todos los
    vectores singulares izquierdos de la matriz de entrada X.
    Ver las descripciones de K, Z y W.



LDX


    LDX (entrada) INTEGER, LDX >= M
    La dimensión principal del array X.



Y


    Y (entrada/espacio de trabajo/salida) COMPLEX(KIND=WP) array M-por-N
    > Al entrar, Y contiene la matriz de instantáneas de datos Y
    < Al salir,
    Si JOBR == 'R', las K columnas principales de Y contienen
    los vectores residuales para los pares de Ritz calculados.
    Ver la descripción de RES.
    Si JOBR == 'N', Y contiene los datos de entrada originales,
                    escalados según el valor de JOBS.



LDY


    LDY (entrada) INTEGER , LDY >= M
    La dimensión principal del array Y.



NRNK


    NRNK (entrada) INTEGER
    Determina el modo de cómo calcular el rango numérico,
    es decir, cómo truncar los valores singulares pequeños de la matriz de entrada
    X. Al entrar, si
    NRNK = -1 :: el i-ésimo valor singular sigma(i) se trunca
                 si sigma(i) <= TOL*sigma(1)
                 Se recomienda esta opción.
    NRNK = -2 :: el i-ésimo valor singular sigma(i) se trunca
                 si sigma(i) <= TOL*sigma(i-1)
                 Esta opción se incluye con fines de I+D.
                 Requiere un SVD de alta precisión, que
                 puede no ser factible.
    El rango numérico se puede forzar utilizando un valor positivo
    de NRNK de la siguiente manera:
    0 < NRNK <= N :: se utilizarán como máximo NRNK valores singulares más grandes.
    Si el número de valores singulares calculados distintos de cero
    es menor que NRNK, entonces solo se utilizarán esos
    valores distintos de cero y la dimensión realmente utilizada
    es menor que NRNK. El número real de
    los valores singulares distintos de cero se devuelve en la variable
    K. Ver las descripciones de TOL y K.



TOL


    TOL (entrada) REAL(KIND=WP), 0 <= TOL < 1
    La tolerancia para truncar valores singulares pequeños.
    Ver la descripción de NRNK.



K


    K (salida) INTEGER,  0 <= K <= N
    La dimensión de la base POD para la matriz de instantáneas de datos
    X y el número de pares de Ritz calculados.
    El valor de K se determina según la regla establecida
    por los parámetros NRNK y TOL.
    Ver las descripciones de NRNK y TOL.



EIGS


    EIGS (salida) COMPLEX(KIND=WP) array N-por-1
    Las K entradas principales (K<=N) de EIGS contienen
    los valores propios calculados (valores de Ritz).
    Ver las descripciones de K y Z.



Z


    Z (espacio de trabajo/salida) array COMPLEX(KIND=WP) M-por-N
    Si JOBZ =='V' entonces Z contiene los vectores de Ritz. Z(:,i)
    es un vector propio del i-ésimo valor de Ritz; ||Z(:,i)||_2=1.
    Si JOBZ == 'F', entonces los Z(:,i) se dan implícitamente como
    las columnas de X(:,1:K)*W(1:K,1:K), es decir, X(:,1:K)*W(:,i)
    es un vector propio correspondiente a EIGS(i). Las columnas
    de W(1:k,1:K) son los vectores propios calculados del
    cociente de Rayleigh de K-por-K.
    Ver las descripciones de EIGS, X y W.



LDZ


    LDZ (entrada) INTEGER , LDZ >= M
    La dimensión principal del array Z.



RES


    RES (salida) array REAL(KIND=WP) N-por-1
    RES(1:K) contiene los residuos para los K pares de Ritz calculados,
    RES(i) = || A * Z(:,i) - EIGS(i)*Z(:,i))||_2.
    Ver la descripción de EIGS y Z.



B


    B (salida) array COMPLEX(KIND=WP) M-por-N.
    SI JOBF =='R', B(1:M,1:K) contiene A*U(:,1:K), y puede
    ser utilizado para calcular los vectores refinados; ver más
    detalles en las referencias proporcionadas.
    Si JOBF == 'E', B(1:M,1:K) contiene
    A*U(:,1:K)*W(1:K,1:K), que son los vectores de
    DMD exacto, hasta el escalado por los valores propios inversos.
    Si JOBF =='N', entonces B no se referencia.
    Ver las descripciones de X, W, K.



LDB


    LDB (entrada) INTEGER, LDB >= M
    La dimensión principal del array B.



W


    W (espacio de trabajo/salida) array COMPLEX(KIND=WP) N-por-N
    Al salir, W(1:K,1:K) contiene los K
    vectores propios calculados del cociente de Rayleigh de la matriz.
    Los vectores de Ritz (devueltos en Z) son el
    producto de X (que contiene una base POD para la matriz de entrada
    X) y W. Ver las descripciones de K, S, X y Z.
    W también se utiliza como espacio de trabajo para almacenar temporalmente
    los vectores singulares derechos de X.



LDW


    LDW (entrada) INTEGER, LDW >= N
    La dimensión principal del array W.



S


    S (espacio de trabajo/salida) array COMPLEX(KIND=WP) N-por-N
    El array S(1:K,1:K) se utiliza para el cociente de Rayleigh de la matriz.
    Este contenido se sobrescribe durante
    la descomposición de valores propios por CGEEV.
    Ver la descripción de K.



LDS


    LDS (entrada) INTEGER, LDS >= N
    La dimensión principal del array S.



ZWORK


    ZWORK (espacio de trabajo/salida) array COMPLEX(KIND=WP) LZWORK-por-1
    ZWORK se utiliza como espacio de trabajo complejo en el SVD complejo, según
    lo especificado por WHTSVD (1, 2, 3 o 4) y para CGEEV para calcular
    los valores propios de un cociente de Rayleigh.
    Si la llamada a CGEDMD es solo una consulta de espacio de trabajo, entonces
    ZWORK(1) contiene la longitud mínima del espacio de trabajo complejo y
    ZWORK(2) es la longitud óptima del espacio de trabajo complejo.
    Por lo tanto, la longitud de work es al menos 2.
    Ver la descripción de LZWORK.



LZWORK


    LZWORK (entrada) INTEGER
    La longitud mínima del vector de espacio de trabajo ZWORK.
    LZWORK se calcula como MAX(LZWORK_SVD, LZWORK_CGEEV),
    donde LZWORK_CGEEV = MAX( 1, 2*N ) y el LZWORK_SVD mínimo
    se calcula de la siguiente manera
    Si WHTSVD == 1 :: CGESVD ::
       LZWORK_SVD = MAX(1,2*MIN(M,N)+MAX(M,N))
    Si WHTSVD == 2 :: CGESDD ::
       LZWORK_SVD = 2*MIN(M,N)*MIN(M,N)+2*MIN(M,N)+MAX(M,N)
    Si WHTSVD == 3 :: CGESVDQ ::
       LZWORK_SVD = obtenible mediante una consulta
    Si WHTSVD == 4 :: CGEJSV ::
       LZWORK_SVD = obtenible mediante una consulta
    Si en la entrada LZWORK = -1, entonces se asume una consulta de espacio de trabajo
    y el procedimiento solo calcula las longitudes mínima
    y óptima del espacio de trabajo y las devuelve en
    LZWORK(1) y LZWORK(2), respectivamente.



RWORK


    RWORK (espacio de trabajo/salida) array REAL(KIND=WP) LRWORK-por-1
    Al salir, RWORK(1:N) contiene los valores singulares de
    X (para JOBS=='N') o X escalado por columna (JOBS=='S', 'C').
    Si WHTSVD==4, entonces RWORK(N+1) y RWORK(N+2) contienen
    el factor de escalado RWORK(N+2)/RWORK(N+1) utilizado para escalar X
    e Y para evitar desbordamiento en el SVD de X.
    Esto puede ser de interés si la opción de escalado está desactivada
    y se desean tantos de los valores propios más pequeños como sea posible
    con la máxima precisión factible.
    Si la llamada a CGEDMD es solo una consulta de espacio de trabajo, entonces
    RWORK(1) contiene la longitud mínima del espacio de trabajo.
    Ver la descripción de LRWORK.



LRWORK


    LRWORK (entrada) INTEGER
    La longitud mínima del vector de espacio de trabajo RWORK.
    LRWORK se calcula de la siguiente manera:
    LRWORK = MAX(1, N+LRWORK_SVD,N+LRWORK_CGEEV), donde
    LRWORK_CGEEV = MAX(1,2*N) y RWORK_SVD es el espacio de trabajo real
    para la subrutina SVD determinada por el parámetro de entrada
    WHTSVD.
    Si WHTSVD == 1 :: CGESVD ::
       LRWORK_SVD = 5*MIN(M,N)
    Si WHTSVD == 2 :: CGESDD ::
       LRWORK_SVD =  MAX(5*MIN(M,N)*MIN(M,N)+7*MIN(M,N),
       2*MAX(M,N)*MIN(M,N)+2*MIN(M,N)*MIN(M,N)+MIN(M,N) ) )
    Si WHTSVD == 3 :: CGESVDQ ::
       LRWORK_SVD = obtenible mediante una consulta
    Si WHTSVD == 4 :: CGEJSV ::
       LRWORK_SVD = obtenible mediante una consulta
    Si en la entrada LRWORK = -1, entonces se asume una consulta de espacio de trabajo
    y el procedimiento solo calcula la longitud mínima
    del espacio de trabajo real y la devuelve en RWORK(1).



IWORK


    IWORK (espacio de trabajo/salida) array INTEGER LIWORK-por-1
    Espacio de trabajo que solo se requiere si WHTSVD es igual a
    2, 3 o 4. (Ver la descripción de WHTSVD).
    Si en la entrada LWORK =-1 o LIWORK=-1, entonces la
    longitud mínima de IWORK se calcula y se devuelve en
    IWORK(1). Ver la descripción de LIWORK.



LIWORK


    LIWORK (entrada) INTEGER
    La longitud mínima del vector de espacio de trabajo IWORK.
    Si WHTSVD == 1, entonces solo se usa IWORK(1); LIWORK >=1
    Si WHTSVD == 2, entonces LIWORK >= MAX(1,8*MIN(M,N))
    Si WHTSVD == 3, entonces LIWORK >= MAX(1,M+N-1)
    Si WHTSVD == 4, entonces LIWORK >= MAX(3,M+3*N)
    Si en la entrada LIWORK = -1, entonces se asume una consulta de espacio de trabajo
    y el procedimiento solo calcula las longitudes mínima
    y óptima del espacio de trabajo para ZWORK, RWORK e
    IWORK. Ver las descripciones de ZWORK, RWORK e IWORK.



INFO


    INFO (salida) INTEGER
    -i < 0 :: Al entrar, el i-ésimo argumento tenía un
              valor ilegal
       = 0 :: Retorno exitoso.
       = 1 :: Entrada vacía. Salida rápida (M=0 o N=0).
       = 2 :: El cálculo SVD de X no convergió.


              Sugerencia: Verifique los datos de entrada y/o
!>              repita con un WHTSVD diferente.
!>       = 3 :: El cálculo de los autovalores no
!>              convergió.
!>       = 4 :: Si se solicitó el escalado de datos en la entrada y
!>              el procedimiento encontró inconsistencia en los datos
!>              de modo que para algún índice de columna i,
!>              X(:,i) = 0 pero Y(:,i) /= 0, entonces Y(:,i) se establece
!>              a cero si JOBS=='C'. El cálculo continúa
!>              con los datos originales o modificados y la
!>              bandera de advertencia se establece con INFO=4.
!
