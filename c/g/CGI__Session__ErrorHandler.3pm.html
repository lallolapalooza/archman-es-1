CGI::Session::ErrorHandler(3) Documentación de Perl aportada por el usuario CGI::Session::ErrorHandler(3)

NOMBRE

CGI::Session::ErrorHandler - rutinas de manejo de errores para CGI::Session

SINOPSIS

require CGI::Session::ErrorHandler;
@ISA = qw( CGI::Session::ErrorHandler );
sub some_method {
    my $self = shift;
    unless (  $some_condition ) {
        return $self->set_error("some_method(): \$some_condition isn't met");
    }
}

DESCRIPCIÓN

CGI::Session::ErrorHandler proporciona los métodos set_error() y errstr() para establecer y acceder a mensajes de error dentro de los componentes de CGI::Session. Este método debe ser utilizado por los desarrolladores de controladores para proporcionar rutinas de manejo de errores estándar de CGI::Session para su código.

MÉTODOS

set_error($message)
Define implícitamente $pkg_name::errstr y establece su valor a $message. El valor de retorno es **siempre** undef.
errstr()
Devuelve cualquier valor que haya sido establecido por la llamada más reciente a set_error(). Si aún no se ha establecido ningún mensaje, se devuelve la cadena vacía para que el mensaje pueda concatenarse sin advertencia.
