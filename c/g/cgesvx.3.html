Documentación de Función/Subrutina

subrutina cgesvx (character fact, character trans, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, real, dimension( * ) r, real, dimension( * ) c, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CGESVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!> CGESVX utiliza la factorización LU para calcular la solución de un sistema complejo
!> de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación de la
!> condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibrará o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con
!>    diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>       A = P * L * U,
!>    donde P es una matriz de permutación, L es una matriz triangular inferior
!>    unitaria y U es triangular superior.
!>
!> 3. Si algún U(i,i)=0, de modo que U sea exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, se utiliza la forma factorizada de A
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina aún continúa
!>    resolviendo X y calculando las cotas de error como se describe a continuación.
!>
!> 4. Se resuelve el sistema de ecuaciones para X utilizando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para que
!>    resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra en la entrada, y si no, si la matriz A debe
!>          equilibrarse antes de factorizarse.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>                  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  A, AF e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz N por N A. Si FACT = 'F' y EQUED
!>          no es 'N', entonces A ha sido equilibrada por los factores
!>          de escala en R y/o C. A no se modifica si FACT = 'F' o
!>          'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene los factores L y U de la factorización
!>          A = P*L*U calculada por CGETRF. Si EQUED .ne. 'N', entonces
!>          AF es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>          devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz A original.
!>
!>          Si FACT = 'E', entonces AF es un argumento de salida y en la salida
!>          devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz A equilibrada (ver la descripción de A para
!>          la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          calculada por CGETRF; la fila i de la matriz se intercambió
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz A original.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz A equilibrada.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicada por
!>                  diag(R).
!>          = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicada
!>                  por diag(C).
!>          = 'B':  Equilibrado de filas y columnas, es decir, A ha sido
!>                  reemplazada por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; en caso contrario, es un
!>          argumento de salida.
!>

R

!>          R es un array REAL, dimensión (N)
!>          Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>          multiplica a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>          no se accede. R es un argumento de entrada si FACT = 'F';
!>          en caso contrario, es un argumento de salida.
!>

C

!>          C es un array REAL, dimensión (N)
!>          Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>          multiplica a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>          no se accede. C es un argumento de entrada si FACT = 'F';
!>          en caso contrario, es un argumento de salida.
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, el array N por NRHS de los lados derechos.
!>          En la salida, si EQUED = 'N', B no se modifica. Si EQUED = 'R' o 'B',
!>          B se premultiplica por diag(R). Si EQUED = 'C', B no se
!>          modifica.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX, dimensión (LDX,NRHS)
!>          En la salida, la solución N por NRHS de los sistemas de ecuaciones.
!>          En la salida, si EQUED = 'N', la solución X no se modifica. Si
!>          EQUED = 'R' o 'B', la solución X se premultiplica por diag(C).
!>          Si EQUED = 'C', la solución X no se modifica.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es un array REAL
!>          En la salida, el recíproco del número de condición de la matriz
!>          (después del equilibrado, si se hizo). Los valores de RCOND son
!>          aproximados, pero el valor absoluto es una cota inferior.
!>          RCOND está definido si y solo si INFO = 0.
!>

FERR

!>          FERR es un array REAL, dimensión (NRHS)
!>          En la salida, el error estimado hacia adelante para cada columna
!>          de X, y para cada sistema de ecuaciones. La estimación del error
!>          hacia adelante se proporciona como un número moderado tal que
!>          si E es una matriz de matrices de error, entonces ||E|| / ||X||
!>          está acotado por FERR(j).
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>          En la salida, el error estimado hacia atrás para cada columna
!>          de X, y para cada sistema de ecuaciones. La estimación del error
!>          hacia atrás se proporciona como un número moderado tal que
!>          || B - A*X || / || B || está acotado por BERR(j).
!>

WORK

!>          WORK es un array COMPLEX, dimensión (*). Para la correcta
!>          ejecución, el tamaño de WORK debe ser al menos max( 2*N, N*NB ),
!>          donde NB es el tamaño del bloque óptimo de la subrutina
!>          CGESVX.
!>

RWORK

!>          RWORK es un array REAL, dimensión (*). El tamaño del array RWORK debe
!>          ser al menos max( N, 2*NRHS ).
!>

INFO

!>          INFO es INTEGER
!>          = 0:   Ejecución correcta.
!>          < 0:   Si INFO = -i, la i-ésima argumento de entrada tenía un
!>                 valor ilegal. Se puede encontrar más información sobre
!>                 los códigos de error en la documentación de cada función.
!>          > 0:   Si INFO = i y i <= N, entonces U(i,i) es cero. La factorización
!>                 ha sido completada, pero la matriz está singular.
!>                 El valor de RCOND es 0.
!>                 Si INFO = N+1, entonces la matriz está casi singular.
!>                 RCOND es muy pequeño, pero positivo. La solución se ha
!>                 calculado, pero puede no ser precisa.
!>

!>          FERR es un arreglo REAL, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución real correspondiente a X(j), FERR(j)

!>          elemento en (X(j) - XTRUE) dividida por la magnitud del
!>          mayor elemento en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error real.

BER

R 
!>          BERR es un arreglo REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector

!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!

WOR

K 
!>          WORK es un arreglo COMPLEX, dimensión (2*N)

RWOR

K 
!>          RWORK es un arreglo REAL, dimensión (MAX(1,2*N))
!>          En la salida, RWORK(1) contiene el factor de crecimiento de pivote
!>          recíproco norm(A)/norm(U). Se usa la norma
!>          . Si RWORK(1) es mucho menor que 1, entonces la estabilidad
!>          de la factorización LU de la matriz A (equilibrada) podría ser
!>          deficiente. Esto también significa que la solución X, el estimador de
!>          condición RCOND y la cota de error hacia adelante FERR podrían ser
!>          poco fiables. Si la factorización falla con 0<INFO<=N, entonces
!>          RWORK(1) contiene el factor de crecimiento de pivote recíproco para las
!>          primeras INFO columnas de A.

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  U(i,i) es exactamente cero. La factorización se
!>                       ha completado, pero el factor U es exactamente
!>                       singular, por lo que la solución y las cotas de error
!>                       no se pudieron calcular. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       a la precisión de trabajo. Sin embargo, la
!>                       solución y las cotas de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.
!>
