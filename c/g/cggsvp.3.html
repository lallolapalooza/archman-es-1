CGGSV

P

Propósito

: 
!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina CGGSVP3.
!>
!> CGGSVP calcula matrices unitarias U, V y Q tales que
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz A12 de tamaño K-por-K y la matriz B13 de tamaño L-por-L son
!> triangulares superiores no singulares; A23 es triangular superior de tamaño
!> L-por-L si M-K-L >= 0, de lo contrario A23 es trapezoidal superior de tamaño
!> (M-K)-por-L.  K+L = el rango numérico efectivo de la matriz (A**H,B**H)**H de
!> tamaño (M+P)-por-N.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición de Valor Singular Generalizada (GSVD), ver la subrutina
!> CGGSVD.
!
>
