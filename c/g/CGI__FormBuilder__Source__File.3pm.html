CGI::FormBuilder::Source::File(3) Documentación de Perl aportada por el usuario CGI::FormBuilder::Source::File(3)

NOMBRE

CGI::FormBuilder::Source::File - Inicializar FormBuilder desde un archivo externo

SINOPSIS

# use the main module
use CGI::FormBuilder;
my $form = CGI::FormBuilder->new(source => 'form.conf');
my $lname = $form->field('lname');  # like normal

DESCRIPCIÓN

Esto analiza un archivo que contiene opciones de configuración de FormBuilder y devuelve un hash adecuado para crear un nuevo objeto $form . Normalmente, no debería usar esto directamente, sino en su lugar pasar un $filename a "CGI::FormBuilder", el cual llama a este módulo.

El formato de configuración se inspira en Python (¡ack!) el cual es sensible a la indentación y a los saltos de línea. Esto le ahorra trabajo a largo plazo. Aquí hay un formulario completo:

    # form basics
    method: POST
    header: 1
    title:  Account Information
    # define fields
    fields:
        fname:
            label:   First Name
            size:    40
        minit:
            label:   Middle Initial
            size:    1
        lname:
            label:   Last Name
            size:    60
        email:
            size:    80
        phone:
            label:    Home Phone
            comment:  (optional)
            required: 0
        sex:
            label:   Gender
            options: M=Male, F=Female
            jsclick: javascript:alert('Change your mind??')
        # custom options and sorting sub
        state:
            options:  \&getstates
            sortopts: \&sortstates
        datafile:
            label:   Upload Survey Data
            type:    file
            growable:   1
    # validate our above fields
    validate:
        email:  EMAIL
        phone:  /^1?-?\d{3}-?\d{3}-?\d{4}$/
    required: ALL
    # create two submit buttons, and skip validation on "Cancel"
    submit:  Update, Cancel
    jsfunc:  <<EOJS
  // skip validation
  if (this._submit.value == 'Cancel') return true;
EOJS
    # CSS
    styleclass: acctInfoForm
    stylesheet: /style/acct.css

Cualquier opción que FormBuilder acepte es soportada por este archivo de configuración. Básicamente, cada vez que colocaría un nuevo corchete para crear una estructura de datos anidada en FormBuilder, coloca un salto de línea e indentación en su lugar.

Las opciones múltiples DEBEN separarse por comas. Todo el espacio en blanco se conserva intacto, así que no se confunda y haga algo como esto:

fields:
    send_me_emails:
        options: Yes No

Lo cual resultará en una única opción "Yes No". Usted quiere:

fields:
    send_me_emails:
        options: Yes, No

O aún mejor:

fields:
    send_me_emails:
        options: 1=Yes, 0=No

O quizás lo mejor de todo:

fields:
    send_me_emails:
        options: 1=Yes Please, 0=No Thanks

Si está confundido, por favor únase a la lista de correo:

fbusers-subscribe@formbuilder.org

Podremos ayudarle.

MÉTODOS

new()

Esto crea un nuevo objeto "CGI::FormBuilder::Source::File" .

my $source = CGI::FormBuilder::Source::File->new;

Cualquier argumento especificado se toma como valor predeterminado, el cual el archivo luego sobreescribe. Por ejemplo, para desactivar siempre "javascript" (para que no tenga que hacerlo en todos sus archivos de configuración), use:

my $source = CGI::FormBuilder::Source::File->new(
                  javascript => 0
             );

Luego, cada archivo analizado por $source tendrá "javascript => 0" en él, a menos que ese archivo tenga una configuración "javascript:" por sí mismo.

parse($source)

Esto analiza la fuente especificada, la cual es un $file, "\$string", o "\@array", y devuelve un hash que puede pasarse directamente a "CGI::FormBuilder":

my %conf = $source->parse('myform.conf');
my $form = CGI::FormBuilder->new(%conf);

write_module($modname)

Esto realmente escribirá un módulo en el directorio actual el cual puede luego usar en scripts subsecuentes para obtener el mismo formulario:

$source->parse('myform.conf');
$source->write_module('MyForm');    # write MyForm.pm
# then in your Perl code
use MyForm;
my $form = MyForm->new;

También puede sobreescribir configuraciones desde "MyForm" de la misma manera que lo haría en FormBuilder":

my $form = MyForm->new(
                header => 1,
                submit => ['Save Changes', 'Abort']
           );

Esto acelerará las cosas, ya que no tendrá que re-analizar el archivo cada vez. Buena idea Peter.

NOTAS

Este módulo fue completamente inspirado por "Text::FormBuilder" de Peter Eichman, aunque la sintaxis es diferente.

Recuerde que para obtener un nuevo nivel en un hashref, necesita agregar un salto de línea e indentación. Así que para obtener algo como esto:

table => {cellpadding => 1, cellspacing => 4},
td    => {align => 'center', bgcolor => 'gray'},
font  => {face => 'arial,helvetica', size => '+1'},

Necesita decir:

table:
    cellpadding: 1
    cellspacing: 4
td:
    align: center
    bgcolor: gray
font:
    face: arial,helvetica
    size: +1

Ya se hace la idea...
