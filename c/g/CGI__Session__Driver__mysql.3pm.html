CGI::Session::Driver::mysql(3) Documentación de Perl aportada por el usuario CGI::Session::Driver::mysql(3)

NOMBRE

CGI::Session::Driver::mysql - Driver de CGI::Session para base de datos MySQL

SINOPSIS

$s = CGI::Session->new( 'driver:mysql', $sid);
$s = CGI::Session->new( 'driver:mysql', $sid, {DataSource  => 'dbi:mysql:test',
                                               User        => 'sherzodr',
                                               Password    => 'hello' });
$s = CGI::Session->new( 'driver:mysql', $sid, { Handle => $dbh } );

DESCRIPCIÓN

mysql almacena los registros de sesión en una tabla MySQL. Para más detalles, consulta CGI::Session::Driver::DBI, su clase padre.

Es especialmente importante para el driver de MySQL que la columna del ID de sesión se defina como clave primaria, o al menos como "única", de esta manera:

CREATE TABLE sessions (
    id CHAR(32) NOT NULL PRIMARY KEY,
    a_session TEXT NOT NULL
 );

Para usar nombres de columna diferentes, cambia la sentencia 'create table', y luego haz simplemente esto:

$s = CGI::Session->new('driver:mysql', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    DataSource=>'dbi:mysql:project',
});

o

$s = CGI::Session->new('driver:mysql', undef,
{
    TableName=>'session',
    IdColName=>'my_id',
    DataColName=>'my_data',
    Handle=>$dbh,
});

ARGUMENTOS DEL DRIVER

El driver mysql soporta todos los argumentos documentados en CGI::Session::Driver::DBI. Además, el argumento DataSource puede opcionalmente omitir la cadena inicial "dbi:mysql:":

$s = CGI::Session->new( 'driver:mysql', $sid, {DataSource=>'shopping_cart'});
# es lo mismo que:
$s = CGI::Session->new( 'driver:mysql', $sid, {DataSource=>'dbi:mysql:shopping_cart'});

COMPATIBILIDAD HACIA ATRÁS

A partir de la V 4.30, la variable global $CGI::Session::MySQL::TABLE_NAME no se puede usar para establecer el nombre de la tabla de sesión.

Esto se debe a cambios en el método new() de CGI::Session::Driver, que ahora permite cambiar el nombre de la tabla (así como permitir cambiar el nombre de la columna 'id' y el nombre de la columna 'a_session').

Consulta la documentación de CGI::Session::Driver::DBI para ver los detalles.

En particular, la nueva sintaxis para new() se aplica a todos los drivers de base de datos, mientras que el método anterior - y malo - de variable global solo se aplicaba a MySQL.

Alternativamente, llama a $session -> table_name('new_name') justo después de crear el objeto de sesión si deseas cambiar el nombre de la tabla de sesión.
