Documentación de Función/Subrutina

subroutine cget22 (character transa, character transe, character transw, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( lde, * ) e, integer lde, complex, dimension( * ) w, complex, dimension( * ) work, real, dimension( * ) rwork, real, dimension( 2 ) result)

CGET22

Propósito:

!>
!> CGET22 realiza una comprobación de autovectores.
!>
!> La prueba básica es:
!>
!>    RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>
!> usando la norma 1. También prueba la normalización de E:
!>
!>    RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                 j
!>
!> donde E(j) es el j-ésimo autovector, y m-norm es la norma máxima de un
!> vector. La norma máxima de un vector complejo n en este caso es el
!> máximo de |re(x(i)| + |im(x(i)| para i = 1, ..., n.
!>

Parámetros

TRANSA 
!>          TRANSA es CHARACTER*1
!>          Especifica si A se transpone o no.
!>          = 'N':  Sin transponer
!>          = 'T':  Transponer
!>          = 'C':  Transpuesta conjugada
!>

TRANSE

!>          TRANSE es CHARACTER*1
!>          Especifica si E se transpone o no.
!>          = 'N':  Sin transponer, los autovectores están en las columnas de E
!>          = 'T':  Transponer, los autovectores están en las filas de E
!>          = 'C':  Transpuesta conjugada, los autovectores están en las filas de E
!>

TRANSW

!>          TRANSW es CHARACTER*1
!>          Especifica si W se transpone o no.
!>          = 'N':  Sin transponer
!>          = 'T':  Transponer, igual que TRANSW = 'N'
!>          = 'C':  Transpuesta conjugada, usa -WI(j) en lugar de WI(j)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          La matriz cuyos autovectores están en E.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es array COMPLEX, dimension (LDE,N)
!>          La matriz de autovectores. Si TRANSE = 'N', los autovectores
!>          se almacenan en las columnas de E, si TRANSE = 'T' o 'C', los
!>          autovectores se almacenan en las filas de E.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal del array E.  LDE >= max(1,N).
!>

W

!>          W es array COMPLEX, dimension (N)
!>          Los autovalores de A.
!>

WORK

!>          WORK es array COMPLEX, dimension (N*N)
!>

RWORK

!>          RWORK es array REAL, dimension (N)
!>

RESULT

!>          RESULT es array REAL, dimension (2)
!>          RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>          RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                       j
!>
