CGGSVD3 calcula la descomposición en valores singulares generalizada (GSVD) de una matriz compleja M por N, A, y una matriz compleja P por N, B:

Propósito:

!>
!> CGGSVD3 calcula la descomposición en valores singulares generalizada (GSVD)
!> de una matriz compleja M por N, A, y una matriz compleja P por N, B:
!>
!>       U**H*A*Q = D1*( 0 R ),    V**H*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices unitarias.
!> Sea K+L = el rango numérico efectivo de
!> la matriz (A**H,B**H)**H, entonces R es una matriz triangular superior no singular (K+L)-por-(K+L),
!> D1 y D2 son matrices M-por-(K+L) y P-por-(K+L) respectivamente y de las siguientes estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) a la salida.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) a la salida.
!>
!> La rutina calcula C, S, R, y opcionalmente las matrices de transformación
!> unitarias U, V y Q.
!>
!> En particular, si B es una matriz no singular N-por-N, entonces la GSVD de
!> A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**H.
!> Si ( A**H,B**H)**H tiene columnas ortonormales, entonces la GSVD de A y B es también
!> igual a la descomposición CS de A y B. Además, la GSVD puede
!> usarse para derivar la solución del problema de valores propios:
!>                      A**H*A x = lambda* B**H*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**H*A*X = ( 0 D1 ),   V**H*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, y D1 y D2 son
!> "diagonales". La forma de GSVD anterior se puede convertir a la última
!> forma tomando la matriz no singular X como
!>
!>                       X = Q*(  I   0    )
!>                             (  0 inv(R) )
!>

NAME

cggsvd3 - the subroutine cggsvd3 computes the generalized singular value decomposition (GSVD) of two conjugated matrices.

 CGGSVD3 -> CTGSJA

Function/Subroutine Documentation

JOBU
CHARACTER*1.

Specifies whether to compute the matrices U and the upper triangular Cholesky factor of I - V*V**H.

JOBU = 'Y': U is computed.

JOBU = 'N': U is not computed.

JOBV
CHARACTER*1.

Specifies whether to compute the upper triangular matrix V.

JOBV = 'Y': V is computed.

JOBV = 'N': V is not computed.

JOBQ
CHARACTER*1.

Specifies whether to compute the upper triangular matrix Q.

JOBQ = 'Y': Q is computed.

JOBQ = 'N': Q is not computed.

M
INTEGER.

The number of rows of matrix A.

N
INTEGER.

The number of columns of matrices A and B.

P
INTEGER.

The number of rows of matrix B.

A
COMPLEX*16 array, dimension (LDA, N).

On entry, the M-by-N matrix A.

On exit, A is overwritten by the results.
LDA
INTEGER.

The leading dimension of A.

B
COMPLEX*16 array, dimension (LDB, N).

On entry, the P-by-N matrix B.

On exit, B is overwritten by the results.
LDB
INTEGER.

The leading dimension of B.

TOL
DOUBLE PRECISION.

Tolerance used to determine the effective rank of A and B.

Singular values S(I) are treated as zero if they are less than or equal to TOL.
K
INTEGER.

The number of diagonal blocks in the matrix S.

L
INTEGER.

The number of diagonal blocks in the matrix T.

ALPHA
DOUBLE PRECISION array, dimension (N).

See below.

BETA
DOUBLE PRECISION array, dimension (N).

See below.

Q
COMPLEX*16 array, dimension (LDQ, N).

On exit, if JOBQ = 'Y', Q is an N-by-N orthogonal matrix such that.

If JOBQ = 'N', Q is not computed.

LDQ
INTEGER.

The leading dimension of Q.

U
COMPLEX*16 array, dimension (LDU, M).

On exit, if JOBU = 'Y', U is an M-by-M orthogonal matrix. See below.

If JOBU = 'N', U is not computed.

LDU
INTEGER.

The leading dimension of U.

V
COMPLEX*16 array, dimension (LDV, N).

On exit, if JOBV = 'Y', V is an N-by-N orthogonal matrix.

If JOBV = 'N', V is not computed.

LDV
INTEGER.

The leading dimension of V.

WORK
COMPLEX*16 array, dimension (MAX(1,LWORK)).

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK
INTEGER.

The dimension of the array WORK. LWORK >= 1.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

RWORK
REAL array, dimension (2*N)
IWORK
INTEGER array, dimension (N).

On exit, IWORK stores the sorting information. More precisely, the following loop will sort ALPHA

for I = K+1, min(M,K+L)

swap ALPHA(I) and ALPHA(IWORK(I))

endfor

such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).

INFO
INTEGER.

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = 1, the Jacobi-type procedure failed to converge. For further details, see subroutine CTGSJA.

Internal Parameters:

TOLA    REAL
TOLB    REAL
        TOLA and TOLB are the thresholds to determine the effective
        rank of (A**H,B**H)**H. Generally, they are set to
                 TOLA = MAX(M,N)*norm(A)*MACHEPS,
                 TOLB = MAX(P,N)*norm(B)*MACHEPS.
        The size of TOLA and TOLB may affect the size of backward
        errors of the decomposition.
