CGSVTS

3

Propósito

: 
!>
!> CGSVTS3 prueba CGGSVD3, que calcula la GSVD de una matriz A de M por N
!> y una matriz B de P por N:
!>              U'*A*Q = D1*R y V'*B*Q = D2*R.
!
>

Parámetro

s
M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!
>

P 
!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!
>

A 
!>          A es un array COMPLEX, dimensión (LDA,M)
!>          La matriz A de M por N.
!
>

A

F 
!>          AF es un array COMPLEX, dimensión (LDA,N)
!>          Detalles de la GSVD de A y B, tal como los devuelve CGGSVD3,
!>          ver CGGSVD3 para más detalles.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal de los arrays A y AF.
!>          LDA >= max( 1,M ).
!
>

B 
!>          B es un array COMPLEX, dimensión (LDB,P)
!>          En la entrada, la matriz B de P por N.
!
>

B

F 
!>          BF es un array COMPLEX, dimensión (LDB,N)
!>          Detalles de la GSVD de A y B, tal como los devuelve CGGSVD3,
!>          ver CGGSVD3 para más detalles.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal de los arrays B y BF.
!>          LDB >= max(1,P).
!
>

U 
!>          U es un array COMPLEX, dimensión(LDU,M)
!>          La matriz unitaria U de M por M.
!
>

LD

U 
!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M).
!
>

V 
!>          V es un array COMPLEX, dimensión(LDV,M)
!>          La matriz unitaria V de P por P.
!
>

LD

V 
!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P).
!
>

Q 
!>          Q es un array COMPLEX, dimensión(LDQ,N)
!>          La matriz unitaria Q de N por N.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N).
!
>

ALPH

A 
!>          ALPHA es un array REAL, dimensión (N)
!
>

BET

A 
!>          BETA es un array REAL, dimensión (N)
!>
!>          Los pares de valores singulares generalizados de A y B, las
!>          matrices ``diagonales'' D1 y D2 se construyen a partir de
!>          ALPHA y BETA, ver la subrutina CGGSVD3 para detalles.
!
>

R 
!>          R es un array COMPLEX, dimensión(LDQ,N)
!>          La matriz triangular superior R.
!
>

LD

R 
!>          LDR es INTEGER
!>          La dimensión principal del array R. LDR >= max(1,N).
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (N)
!
>

WOR

K 
!>          WORK es un array COMPLEX, dimensión (LWORK)
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK,
!>          LWORK >= max(M,P,N)*max(M,P,N).
!
>

RWOR

K 
!>          RWORK es un array REAL, dimensión (max(M,P,N))
!
>

RESUL

T 
!>          RESULT es un array REAL, dimensión (6)
!>          Los cocientes de prueba:
!>          RESULT(1) = norm( U'*A*Q - D1*R ) / ( MAX(M,N)*norm(A)*ULP)
!>          RESULT(2) = norm( V'*B*Q - D2*R ) / ( MAX(P,N)*norm(B)*ULP)
!>          RESULT(3) = norm( I - U'*U ) / ( M*ULP )
!>          RESULT(4) = norm( I - V'*V ) / ( P*ULP )
!>          RESULT(5) = norm( I - Q'*Q ) / ( N*ULP )
!>          RESULT(6) = 0        si ALPHA está en orden decreciente;
!>                    = ULPINV   en caso contrario.
!
