NOMBRE

cg_diff - (obsoleto) compara dos archivos de salida de Cachegrind

SINOPSIS

cg_diff [opciones] archivo-salida-cachegrind1 archivo-salida-cachegrind2

DESCRIPCIÓN

cg_diff compara dos archivos de salida de Cachegrind y genera un único archivo de salida de Cachegrind. Está obsoleto porque cg_annotate puede hacer ahora algo similar, pero mejor.

OPCIONES

-h --help

Muestra el mensaje de ayuda.

--version

Muestra el número de versión.

--mod-filename=<expr> [por defecto: none]

Especifica una expresión de búsqueda y reemplazo s/viejo/nuevo/ que se aplica a todos los nombres de archivo.

--mod-funcname=<expr> [por defecto: none]

Similar a --mod-filename, pero para nombres de función.

VER TAMBIÉN

cg_annotate(1), valgrind(1), $INSTALL/share/doc/valgrind/html/index.html o http://www.valgrind.org/docs/manual/index.html.
