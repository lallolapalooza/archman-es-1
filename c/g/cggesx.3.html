CGGESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices

GE

Propósito

: 
!>
!> CGGESX calcula para un par de matrices complejas no simétricas N-por-N
!> (A,B), los valores propios generalizados, la forma de Schur compleja (S,T),
!> y, opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL
!> y VSR). Esto proporciona la factorización generalizada de Schur
!>
!>      (A,B) = ( (VSL) S (VSR)**H, (VSL) T (VSR)**H )
!>
!> donde (VSR)**H es la transpuesta conjugada de VSR.
!>
!> Opcionalmente, también ordena los valores propios de modo que un
!> grupo seleccionado de valores propios aparece en los bloques diagonales
!> principales de la matriz triangular superior S y la matriz triangular
!> superior T; calcula un número de condición recíproco para el promedio
!> de los valores propios seleccionados (RCONDE); y calcula un número de
!> condición recíproco para los subespacios deflactantes derecha e izquierda
!> correspondientes a los valores propios seleccionados (RCONDV). Las
!> columnas principales de VSL y VSR entonces forman una base ortonormal
!> para los autoespacios izquierdo y derecho correspondientes (subespacios
!> deflactantes).
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Generalmente se
!> representa como el par (alpha,beta), ya que existe una interpretación
!> razonable para beta=0 o para ambos siendo cero.
!>
!> Un par de matrices (S,T) está en forma de Schur compleja generalizada si T es
!> triangular superior con diagonal no negativa y S es triangular
!> superior.
!
>

!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos.
!
>

     NAME
    

    
cggesx — generalized eigenvalue problem for complex matrices

   

   

    

     SYNOPSIS
    

    
subroutine cggesx(JOBVSL, JOBVSR, SENSE, N, A, LDA, B, LDB, ALPHA, BETA, VSL, LDVSL, VSR, LDVSR, RCONDE, RCONDV, WORK, LWORK, IWORK, LIWORK, BWORK, INFO)
    character(len=1) JOBVSL, JOBVSR, SENSE
    integer N, LDA, LDB, LDVSL, LDVSR, LWORK, LIWORK, INFO
    complex*16 A(LDA, *)
    complex*16 B(LDB, *)
    complex*16 ALPHA(*)
    complex*16 BETA(*)
    complex*16 VSL(LDVSL, *)
    complex*16 VSR(LDVSR, *)
    real*8 RCONDE(*)
    real*8 RCONDV(*)
    complex*16 WORK(LWORK)
    integer IWORK(LIWORK)
    logical BWORK(N)


   

   

    

     Function/Subroutine Documentation
    

    
CGGESX computes for the generalized eigenvalue problem
        A*x = lambda*B*x the eigenvalues, and optionally the left and right
        eigenvectors of a pair of matrices (A, B).

    
The eigenvalues are lambda = ALPHA(i)/BETA(i).

    
A pair (A, B) is reduced to upper triangular form (A, R)
        (Z, T) = (Q'*A*Z, Q'*B*Z) where T is upper triangular.

    
The generalized eigenvalues are the ratios ALPHA(i)/BETA(i),
        where ALPHA is the diagonal of the complex upper triangular matrix A,
        and BETA is the diagonal of the complex upper triangular matrix B.

    
The eigenvectors are Z and Q.

    
Arguments

    
JOBVSL character*1

    

     
If JOBVSL = 'V', compute the left eigenvectors of the
         generalized eigenvalue problem.

     
If JOBVSL = 'N', do not compute the left eigenvectors.

    

    
JOBVSR character*1

    

     
If JOBVSR = 'V', compute the right eigenvectors of the
         generalized eigenvalue problem.

     
If JOBVSR = 'N', do not compute the right eigenvectors.

    

    
SENSE character*1

    

     
Determines which reciprocal condition numbers are requested.

     
Possible values for CHARACTER*1 SENSE are:

     
 'N': None are computed.

     
 'E': Computed for the Schur values only.

     
 'V': Computed for the right eigenvectors only.

     
 'B': Computed for both left and right eigenvectors.

    

    
N integer

    

     
The order of the matrices A and B. 0 <= N <= max(A,B).

    

    
A complex*16 array, dimension (LDA, N)

    

     
On entry, the first N rows and N columns of matrix A.

     
On exit, A is overwritten by its upper triangular factor.

    

    
LDA integer

    

     
The leading dimension of the array A. LDA >= max(1, N).

    

    
B complex*16 array, dimension (LDB, N)

    

     
On entry, the first N rows and N columns of matrix B.

     
On exit, B is overwritten by its upper triangular factor.

    

    
LDB integer

    

     
The leading dimension of the array B. LDB >= max(1, N).

    

    
ALPHA complex*16 array, dimension (N)

    

     
On exit, the complex numerators of the generalized eigenvalues.

    

    
BETA complex*16 array, dimension (N)

    

     
On exit, the complex denominators of the generalized eigenvalues.

    

    
VSL complex*16 array, dimension (LDVSL, N)

    

     
If JOBVSL = 'V', VSL is an input/output array containing the
         left eigenvectors of the generalized eigenvalue problem A*x = lambda*B*x.
         On entry, VSL is a matrix of dimension LDVSL*N.

     
If JOBVSL = 'N', VSL is not referenced.

     
On exit, the normalized left eigenvectors, with the i-th
         column vsl(i) satisfying A*vsl(i) = ALPHA(i)*B*vsl(i).

    

    
LDVSL integer

    

     
The leading dimension of the array VSL. LDVSL >= max(1, N).

     
If JOBVSL = 'N', LDVSL is not referenced.

    

    
VSR complex*16 array, dimension (LDVSR, N)

    

     
If JOBVSR = 'V', VSR is an input/output array containing the
         right eigenvectors of the generalized eigenvalue problem A*x = lambda*B*x.
         On entry, VSR is a matrix of dimension LDVSR*N.

     
If JOBVSR = 'N', VSR is not referenced.

     
On exit, the normalized right eigenvectors, with the i-th
         column vsr(i) satisfying A*vsr(i) = ALPHA(i)*B*vsr(i).

    

    
LDVSR integer

    

     
The leading dimension of the array VSR. LDVSR >= max(1, N).

     
If JOBVSR = 'N', LDVSR is not referenced.

    

    
RCONDE real*8 array, dimension (N)

    

     
If SENSE = 'E' or 'B', RCONDE(i) is an estimate of the
         reciprocal condition number of the i-th eigenvalue. The i-th
         eigenvalue is computed from the pair of eigenvalues of (A, B).

     
Not referenced if SENSE = 'N' or 'V'.

    

    
RCONDV real*8 array, dimension (2)

    

     
If SENSE = 'V' or 'B', RCONDV(1) and RCONDV(2) contain the
         reciprocal condition number for the selected deflating
         subspaces.
         Not referenced if SENSE = 'N' or 'E'.

    

    
WORK complex*16 array, dimension (MAX(1,LWORK))

    

     
On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

    

    
LWORK integer

    

     
The dimension of the array WORK.

     
If N = 0, LWORK >= 1, else if SENSE = 'E', 'V', or 'B',
         LWORK >= MAX(1,2*N,2*SDIM*(N-SDIM)), else
         LWORK >= MAX(1,2*N). Note that 2*SDIM*(N-SDIM) <= N*N/2.
         Note also that an error is only returned if
         LWORK < MAX(1,2*N), but if SENSE = 'E' or 'V' or 'B' this may
         not be large enough.

     
If LWORK = -1, then a workspace query is assumed; the routine
         only calculates the bound on the optimal size of the WORK
         array and the minimum size of the IWORK array, returns these
         values as the first entries of the WORK and IWORK arrays, and
         no error message related to LWORK or LIWORK is issued by
         XERBLA.

    

    
RWORK real*8 array, dimension ( 8*N )

    

     
Real workspace.

    

    
IWORK integer array, dimension (MAX(1,LIWORK))

    

     
On exit, if INFO = 0, IWORK(1) returns the minimum LIWORK.

    

    
LIWORK integer

    

     
The dimension of the array WORK.
         If SENSE = 'N' or N = 0, LIWORK >= 1, otherwise
         LIWORK >= N+2.
         If LIWORK = -1, then a workspace query is assumed; the
         routine only calculates the bound on the optimal size of the
         WORK array and the minimum size of the IWORK array, returns
         these values as the first entries of the WORK and IWORK
         arrays, and no error message related to LWORK or LIWORK is
         issued by XERBLA.

    

    
BWORK logical array, dimension (N)

    

     
Not referenced if SORT = 'N'.

    

    
INFO integer

    

     
 = 0: successful exit
         < 0: if INFO = -i, the i-th argument had an illegal value.
         = 1,...,N:
         The QZ iteration failed. (A,B) are not in Schur
         form, but ALPHA(j) and BETA(j) should be correct for
         j=INFO+1,...,N.
         > N: =N+1: other than QZ iteration failed in CHGEQZ
         =N+2: after reordering, roundoff changed values of
         some complex eigenvalues so that leading
         eigenvalues in the Generalized Schur form no
         longer satisfy SELCTG=.TRUE. This could also
         be caused due to scaling.
         =N+3: reordering failed in CTGSEN.
