Veamos un último ejemplo. Aquí queremos un grupo de radio que
    permita a una persona quitarse de una lista de correo. Aquí está nuestra
  
plantilla:

¿Quiere estar en nuestra lista de correo?
<p&gt;<table>
<tmpl_loop loop-mailopt>
<td bgcolor="silver">
  <input type="radio" name="mailopt" value="<tmpl_var value>">
</td>
<td bgcolor="white"><tmpl_var label></td>
</tmpl_loop>
</table>


Entonces, manipularíamos el
    "mailopt" campo mediante
    field():


$form->field(
          name => 'mailopt',
          options => [
             [ 1 => 'Sí, por favor, manténgame en ella!' ],
             [ 0 => 'No, elimíname inmediatamente.' ]
          ]
       );


Cuando se renderiza la plantilla, el resultado sería algo como
    esto:


¿Quiere estar en nuestra lista de correo?
<p><table>
<td bgcolor="silver">
  <input type="radio" name="mailopt" value="1">
</td>
<td bgcolor="white">Sí, por favor, manténgame en ella!</td>
<td bgcolor="silver">
  <input type="radio" name="mailopt" value="0">
</td>
<td bgcolor="white">No, elimíname inmediatamente</td>
</table>


Cuando se enviara el formulario, accedería a los valores igual
    que a cualquier otro campo:


if ($form->field('mailopt')) {
    # es 1, así que añádelos
} else {
    # es 0, elimínalos
}


Finalmente, también puede recorrer cada uno de los campos
    utilizando el bucle de nivel superior "fields" en su plantilla.
    Esto le permite reutilizar la misma plantilla incluso si sus parámetros cambian.
    El siguiente código de plantilla recorrería cada campo, creando una fila de
    tabla para cada uno:


<table>
<tmpl_loop fields>
<tr>
<td class="small"><tmpl_if required><b><tmpl_var label></b><tmpl_else><tmpl_var label></tmpl_if></td>
<td><tmpl_var field></td>
</tr>
</tmpl_loop>
</table>


Cada bucle tendrá un "label",
    "field",
    "value", etc, igual que arriba.
