ExtUtils::Typemaps::Type(3perl) Guía del programador de Perl ExtUtils::Typemaps::Type(3perl)

NOMBRE

ExtUtils::Typemaps::Type - Entrada en la sección TYPEMAP de un typemap

SINOPSIS

use ExtUtils::Typemaps;
...
my $type = $typemap->get_type_map('char*');
my $input = $typemap->get_input_map($type->xstype);

DESCRIPCIÓN

Consulte ExtUtils::Typemaps para obtener detalles. El objeto asocia "ctype" con "xstype", que es el índice en las tablas de mapeo de entrada y salida.

MÉTODOS

new

Requiere parámetros "xstype" y "ctype".

Opcionalmente, toma el parámetro "prototype". Sin embargo, tenga en cuenta que el método para obtener/establecer el valor se llama "proto" en lugar de <prototype>.

proto

Devuelve o establece el prototipo.

xstype

Devuelve el nombre del tipo XS al que está asociado este tipo C.

ctype

Devuelve el nombre del tipo C tal como se estableció en la construcción.

tidy_ctype

Devuelve el nombre canonizado del tipo C.

VER TAMBIÉN
