NOMBRE

ExtUtils::Mksymlists - escribe archivos de opciones del enlazador para extensiones dinámicas

SINOPSIS

use ExtUtils::Mksymlists;
Mksymlists(  NAME     => $nombre ,
             DL_VARS  => [ $var1, $var2, $var3 ],
             DL_FUNCS => { $pkg1 => [ $func1, $func2 ],
                           $pkg2 => [ $func3 ] });

DESCRIPCIÓN

"ExtUtils::Mksymlists" produce archivos utilizados por el enlazador bajo algunos sistemas operativos durante la creación de bibliotecas compartidas para extensiones dinámicas. Normalmente se llama desde un Makefile generado por MakeMaker cuando se construye la extensión. El archivo de opciones del enlazador se genera llamando a la función "Mksymlists", que se exporta por defecto desde "ExtUtils::Mksymlists". Toma un argumento, una lista de pares clave-valor, en la que se reconocen las siguientes claves:

DLBASE
Este elemento especifica el nombre por el que el enlazador conoce la extensión, que puede ser diferente del nombre de la extensión en sí (por ejemplo, algunos enlazadores añaden un '_' al nombre de la extensión). Si no se especifica, se deriva del atributo NAME. Actualmente solo se utiliza en OS2 y Win32.
DL_FUNCS
Es idéntico al atributo DL_FUNCS disponible a través de MakeMaker, del cual generalmente se toma. Su valor es una referencia a una matriz asociativa, en la que cada clave es el nombre de un paquete y cada valor es una referencia a una matriz de nombres de funciones que la extensión debe exportar. Por ejemplo, se podría decir "DL_FUNCS => { Homer::Iliad => [ qw(trojans greeks) ], Homer::Odyssey => [ qw(travellers family suitors) ] }". Los nombres de las funciones deben ser idénticos a los del código XSUB; "Mksymlists" alterará los nombres escritos en el archivo de opciones del enlazador para que coincidan con los cambios realizados por xsubpp. Además, si ninguna de las funciones de una lista comienza con la cadena boot_, "Mksymlists" añadirá una función de arranque para ese paquete, al igual que lo hace xsubpp. (Si una función boot_<pkg> está presente en la lista, se pasa sin cambios). Si no se especifica DL_FUNCS, se utiliza por defecto la función de arranque para la extensión especificada en NAME.
DL_VARS
Es idéntico al atributo DL_VARS disponible a través de MakeMaker y, al igual que DL_FUNCS, generalmente se especifica a través de MakeMaker. Su valor es una referencia a una matriz de nombres de variables que la extensión debe exportar.
FILE
Esta clave se puede utilizar para especificar el nombre del archivo de opciones del enlazador (sin la extensión específica del sistema operativo), si por alguna razón no se desea utilizar el valor predeterminado, que es la última palabra del atributo NAME (por ejemplo, para "Tk::Canvas", FILE por defecto es "Canvas").
FUNCLIST
Proporciona un medio alternativo para especificar nombres de funciones que se exportarán desde la extensión. Su valor es una referencia a una matriz de nombres de funciones que la extensión exportará. Estos nombres se pasan sin alteraciones al archivo de opciones del enlazador. Especificar un valor para el atributo FUNCLIST suprime la generación automática de la función de arranque para el paquete. Para crear aún el nombre de arranque, debe especificar el nombre del paquete en el hash DL_FUNCS: 
Mksymlists(  NAME     => $nombre ,
             FUNCLIST => [ $func1, $func2 ],
             DL_FUNCS => { $pkg => [] } );
IMPORTS
Este atributo se utiliza para especificar los nombres que se importarán en la extensión. Actualmente solo lo utilizan OS/2 y Win32.
NAME
Indica el nombre de la extensión (por ejemplo, "Tk::Canvas") para la que se producirá el archivo de opciones del enlazador.

Al llamar a "Mksymlists", siempre se debe especificar el atributo NAME. En la mayoría de los casos, esto es todo lo necesario. Sin embargo, en el caso de extensiones inusuales, los otros atributos se pueden usar para proporcionar información adicional al enlazador.
