NOMBRE

exit - Finalizar la aplicación

SINOPSIS

exit ?código_retorno?

DESCRIPCIÓN

Termina el proceso, devolviendo código_retorno al sistema como estado de salida. Si no se especifica código_retorno, por defecto será 0.

EJEMPLO

Dado que los códigos de salida distintos de cero suelen ser interpretados como casos de error por el proceso que llama, el comando exit es una parte importante para señalar que ha ocurrido un problema fatal. Este fragmento de código es útil en scripts para actuar como una trampa general de problemas:

proc main {} {
    # ... pon el código principal real aquí ...
}
if {[catch {main} msg options]} {
    puts stderr "error inesperado en el script: $msg"
    if {[info exists env(DEBUG)]} {
        puts stderr "---- INICIO DE TRAZA ----"
        puts stderr [dict get $options -errorinfo]
        puts stderr "---- FIN DE TRAZA ----"
    }
    # Reserva el código 2 para salidas de error "inesperadas"...
    exit 2
}
