ExtUtils::MM_Cygwin(3perl) Guía de Programación de Perl ExtUtils::MM_Cygwin(3perl)

NOMBRE

ExtUtils::MM_Cygwin - métodos para anular el comportamiento UN*X en ExtUtils::MakeMaker

SINOPSIS

use ExtUtils::MM_Cygwin; # Realizado internamente por ExtUtils::MakeMaker si es necesario

DESCRIPCIÓN

Ver ExtUtils::MM_Unix para una documentación de los métodos proporcionados allí.

os_flavor
Somos Unix y Cygwin.
cflags
si está configurado para carga dinámica, activa #define EXT en EXTERN.h
replace_manpage_separator
reemplaza las cadenas '::' por '.' en los nombres de páginas man de MAN*POD
init_linker
apunta a libperl.a
maybe_command
Determina si un archivo es nativo de Cygwin comprobando si reside dentro de la instalación de Cygwin (usando rutas de Windows). Si es así, utiliza ExtUtils::MM_Unix para determinar si puede ser un comando. De lo contrario, utiliza las pruebas de ExtUtils::MM_Win32.
dynamic_lib
Usa el valor predeterminado para producir los *.dll. Pero para las nuevas dll de archdir, usa la misma dirección de rebase si la antigua existe.
install
Rebasa las dll con la base de datos de rebase global después de la instalación.
