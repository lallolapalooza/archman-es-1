NOMBRE

ExtUtils::PkgConfig - interfaz simplista a pkg-config

SINOPSIS

use ExtUtils::PkgConfig;
$paquete = 'gtk+-2.0';
%info_paquete = ExtUtils::PkgConfig->find ($paquete);
print "modversion:  $info_paquete{modversion}\n";
print "cflags:      $info_paquete{cflags}\n";
print "libs:        $info_paquete{libs}\n";
$existe = ExtUtils::PkgConfig->exists($paquete);
$version_mod = ExtUtils::PkgConfig->modversion($paquete);
$libs = ExtUtils::PkgConfig->libs($paquete);
$cflags = ExtUtils::PkgConfig->cflags($paquete);
$solo_cflags_I = ExtUtils::PkgConfig->cflags_only_I($paquete);
$otros_cflags = ExtUtils::PkgConfig->cflags_only_other($paquete);
$solo_libs_L = ExtUtils::PkgConfig->libs_only_L($paquete);
$solo_libs_l = ExtUtils::PkgConfig->libs_only_l($paquete);
$otras_libs = ExtUtils::PkgConfig->libs_only_other($paquete);
$libs_estaticas = ExtUtils::PkgConfig->static_libs($paquete);
$valor_variable = ExtUtils::PkgConfig->variable($paquete, $variable);
if (ExtUtils::PkgConfig->atleast_version($paquete,$version)) {
   ...
}
if (ExtUtils::PkgConfig->exact_version($paquete,$version)) {
   ...
}
if (ExtUtils::PkgConfig->max_version($paquete,$version)) {
   ...
}

DESCRIPCIÓN

El programa pkg-config recupera información sobre bibliotecas instaladas, generalmente con el propósito de compilar y enlazar con ellas.

ExtUtils::PkgConfig es una interfaz muy simplista para esta utilidad, destinada a ser utilizada en el Makefile.PL de extensiones de Perl que enlazan bibliotecas que pkg-config conoce. En realidad, es solo código repetitivo que habrías escrito tú mismo.

USO

HASH = ExtUtils::PkgConfig->find (CADENA, [CADENA, ...])
Llama a pkg-config sobre la biblioteca especificada por CADENA (tendrás que saber qué usar aquí). El HASH devuelto contiene los valores modversion, cflags y libs bajo claves con esos nombres. Si se pasan múltiples CADENAS, se intentan en el orden en que se dan hasta que se encuentra un paquete que funcione.

Si pkg-config no encuentra una CADENA que funcione, esta función falla con un mensaje destinado a ser útil para quien esté intentando compilar tu paquete.

Por ejemplo:

*** no se puede encontrar el paquete bad1
*** comprueba que esté correctamente instalado y disponible
*** en PKG_CONFIG_PATH

o

*** no se pueden encontrar los cflags para gtk+-2.0
*** ¿está correctamente instalado y disponible en PKG_CONFIG_PATH?
CADENA = ExtUtils::PkgConfig->create_version_macros (PAQUETE, SUFIJO)
Crea un conjunto de macros de versión con el prefijo SUFIJO para la biblioteca especificada por PAQUETE. El resultado se devuelve.

La entrada de ejemplo sería "gtk+-2.0" para PAQUETE y "GTK" para SUFIJO.

ExtUtils::PkgConfig->write_version_macros (ARCHIVO, PAQUETE, SUFIJO, [PAQUETE, SUFIJO, ...])
Crea uno o más conjuntos de macros de versión para las bibliotecas y prefijos especificados por los pares PAQUETE y SUFIJO y los escribe en el archivo ARCHIVO. Si no existe, ARCHIVO será creado. Si ya existe, será sobrescrito.

VER TAMBIÉN

ExtUtils::PkgConfig fue diseñado para funcionar con ExtUtils::Depends para compilar los diversos módulos del proyecto gtk2-perl.

L<ExtUtils::Depends>
L<http://gtk2-perl.sourceforge.net/>

Este módulo es realmente solo una interfaz al programa de utilidad pkg-config. http://www.freedesktop.org/Software/pkgconfig
