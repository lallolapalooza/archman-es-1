EXEC(1P) Manual del programador de POSIX EXEC(1P)

PROLOG

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

exec — ejecutar comandos y abrir, cerrar o copiar descriptores de archivo

SINOPSIS

exec [comando [argumento...]]

DESCRIPCIÓN

La utilidad exec abrirá, cerrará y/o copiará descriptores de archivo según lo especificado por cualquier redirección como parte del comando.

Si exec se especifica sin comando o argumentos, y se abren descriptores de archivo con números mayores que 2 con sentencias de redirección asociadas, no está especificado si esos descriptores de archivo permanecen abiertos cuando el shell invoca otra utilidad. Los scripts preocupados de que los shells hijos puedan hacer un uso indebido de los descriptores de archivo abiertos siempre pueden cerrarlos explícitamente, como se muestra en uno de los siguientes ejemplos.

Si exec se especifica con comando, reemplazará el shell con comando sin crear un nuevo proceso. Si se especifican argumentos, serán argumentos para comando. La redirección afecta el entorno de ejecución del shell actual.

ESTADO DE SALIDA

Si se especifica comando, exec no devolverá el control al shell; en cambio, el estado de salida del proceso será el estado de salida del programa que implementa comando, que ha reemplazado al shell. Si no se encuentra comando, el estado de salida será 127. Si se encuentra comando, pero no es una utilidad ejecutable, el estado de salida será 126. Si ocurre un error de redirección (ver Sección 2.8.1, Consecuencias de los errores del shell), el shell saldrá con un valor en el rango de 1 a 125. De lo contrario, exec devolverá un estado de salida cero.

USO DE APLICACIONES

Ninguno.

EJEMPLOS

Abrir readfile como descriptor de archivo 3 para lectura:

exec 3< readfile

Abrir writefile como descriptor de archivo 4 para escritura:

exec 4> writefile

Hacer que el descriptor de archivo 5 sea una copia del descriptor de archivo 0:

exec 5<&0

Cerrar el descriptor de archivo 3:

exec 3<&-

Mostrar el archivo maggie reemplazando el shell actual con la utilidad cat:

exec cat maggie

FUNDAMENTO

La mayoría de las implementaciones históricas no cumplían con la norma en el sentido de que:

foo=bar exec cmd

no pasaba foo a cmd.
