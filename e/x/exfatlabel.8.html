EXFATLABEL(8) Manual del Administrador del Sistema EXFATLABEL(8)

NOMBRE

exfatlabel - obtener o establecer una etiqueta de sistema de archivos exFAT

SINOPSIS

exfatlabel [ -V ] dispositivo [ etiqueta ]

DESCRIPCIÓN

exfatlabel lee o cambia una etiqueta de sistema de archivos exFAT (nombre de volumen).

Si el argumento etiqueta está presente, exfatlabel establece el nuevo nombre de volumen. Una etiqueta vacía ('') elimina el nombre de volumen. La etiqueta puede tener hasta 15 caracteres. Este límite es menor si se utilizan caracteres más allá del BMP de Unicode, ya que internamente la etiqueta se almacena en UTF-16.

Si se omite el argumento etiqueta, exfatlabel simplemente imprime el nombre de volumen actual.

OPCIONES DE LÍNEA DE COMANDOS

Opciones de línea de comandos disponibles:

-V
Imprime la versión y los derechos de autor.

CÓDIGOS DE SALIDA

Se devuelve cero si la operación se realiza correctamente. Cualquier otro código indica un error.
