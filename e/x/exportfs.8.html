DESCRIPCIÓ

N

Un servidor NFS mantiene una tabla de sistemas de archivos físicos locales que son accesibles para los clientes NFS. Cada sistema de archivos en esta tabla se denomina sistema de archivos exportado, o exportación, para

abreviar.

El comando exportfs mantiene la tabla actual de exportaciones para el servidor NFS. La tabla maestra de exportaciones se guarda en un archivo llamado /var/lib/nfs/etab. Este archivo es leído por rpc.mountd cuando un cliente envía una solicitud NFS

MOUNT.

Normalmente, la tabla maestra de exportaciones se inicializa con el contenido de /etc/exports y los archivos bajo /etc/exports.d invocando exportfs -a. Sin embargo, un administrador del sistema puede optar por añadir o eliminar exportaciones sin modificar /etc/exports o los archivos bajo /etc/exports.d utilizando el comando exp

ortfs.

exportfs y su programa asociado rpc.mountd trabajan en uno de dos modos: un modo legado que aplica a versiones 2.4 y anteriores del núcleo de Linux, y un nuevo modo que aplica a versiones 2.6 y posteriores, siempre que el sistema de archivos virtual nfsd haya sido montado en /proc/fs/nfsd o /proc/fs/nfs. En núcleos 2.6, si este sistema de archivos no está montado, se usa el modo

legado.

En el nuevo modo, exportfs no da ninguna información al núcleo, sino que la proporciona solo a rpc.mountd a través del archivo /var/lib/nfs/etab. rpc.mountd luego gestiona las solicitudes del núcleo para información sobre exportaciones, según sea

necesario.

En el modo legado, las exportaciones que identifican un host específico, en lugar de una subred o un grupo de red, se introducen directamente en la tabla de exportaciones del núcleo, además de escribirse en /var/lib/nfs/etab. Además, las exportaciones listadas en /var/lib/nfs/rmtab que coincidan con una solicitud de exportación no específica de host causarán que se añada una entrada de exportación apropiada para el host dado en rmtab a la tabla de ex

portaciones
del núcleo.

La sección [exportfs] del archivo de configuración /etc/nfs.conf puede contener un valor debug, que puede ser uno o más de la lista general, call, auth, parse, all. Cuando se da una lista, los miembros deben estar separados por

comas.

exportfs también reconocerá el valor state-directory-path tanto de la sección [mountd] como de la sección

[expo
rtd]

DISCUSIÓ

N

Exportar

Directorios

La primera sinopsis muestra cómo invocar exportfs al añadir nuevas entradas a la tabla de exportaciones. Al usar exportfs -a, todas las exportaciones listadas en /etc/exports y los archivos bajo /etc/exports.d se añaden a /var/lib/nfs/etab. La tabla de exportaciones del núcleo también se actualiza según sea

necesario.

El argumento host:/ruta especifica un directorio local a exportar, junto con el cliente o clientes a los que se les permite acceder. Véase exports(5) para una descripción de las opciones soportadas y los formatos de listas de

acceso.

Las direcciones de presentación IPv6 contienen dos puntos, que ya se usan para separar los argumentos de la línea de comandos "host" y "ruta". Al especificar un cliente usando una dirección IPv6 en bruto, encierre la dirección entre corchetes. Para direcciones de red IPv6, coloque el prefijo justo después del corchete de

cierre.

Para exportar un directorio al mundo, simplemente especifique :/rut

a.

Las opciones de exportación para un par host/directorio particular derivan de varias fuentes. Las opciones de exportación predeterminadas son sync,ro,root_squash,wdelay. Estas pueden ser sobrescritas por entradas en /etc/exports o en los archivos bajo /etc/expor

ts.d.

Un administrador del sistema puede sobrescribir opciones de estas fuentes usando la opción -o de la línea de comandos en exportfs. Esta opción toma una lista de opciones separadas por comas de la misma manera en que uno las especificaría en /etc/exports. De esta manera exportfs se puede usar para modificar las opci

ones de exportación de un
directorio ya exportado.

Dejar de Exportar

Directorios

La tercera sinopsis muestra cómo dejar de exportar un directorio actualmente exportado. Al usar exportfs -ua, todas las entradas listadas en /var/lib/nfs/etab se eliminan de las tablas de exportación del núcleo, y el archivo se vacía. Esto cierra efectivamente toda la actividad

NFS.

Para eliminar una exportación, especifique un par host:/ruta. Esto borra la entrada especificada de /var/lib/nfs/etab y elimina la entrad

a correspondiente del
núcleo (si existe).

Volcado de la Tabla de

Exportaciones

Invocar exportfs sin opciones muestra la lista actual de sistemas de archivos exportados. Añadir la opción -v hace que exportfs muestre las opc

iones de export
ación para cad
a exportación.

NOTAS DE USO

Exportar a redes IP o dominios DNS y NIS no habilita inmediatamente a los clientes de estos grupos a acceder a NFS. Más bien, este tipo de exportaciones son pistas para rpc.mountd(8) para conceder cualquier solicitud de montaje de estos clientes. Esto generalmente no es un problema, ya que cualquier montaje existente se conserva en rmtab a través de reinicios.

Al desexportar una entrada de red o dominio, se comprobarán las exportaciones actuales a los miembros de este grupo contra las exportaciones válidas restantes y, si dejan de ser válidas, se eliminarán.
