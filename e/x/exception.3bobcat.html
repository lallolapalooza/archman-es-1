FBB::Exception(3bobcat) clase de excepción insertable FBB::Exception(3bobcat)

NOMBRE

FBB::Exception - inserciones de stream para objetos std::exception

SINOPSIS

#include <bobcat/exception>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos FBB::Exception se derivan de std::exception, pero aceptan inserciones de stream. Su uso previsto consiste en lanzar un objeto anónimo, en el cual se ha insertado el texto del mensaje de std::exception::what.

Las excepciones Exception son lanzadas por varias clases de Bobcat. Estas clases son Arg, ArgConfig, BigInt, Cgi, Cidr, ClientSocket, CmdFinderBase, ConfigFile, DateTime, DecryptBuf, DigestBuf, EncryptBuf, Fork, GetHostent, Glob, HMacBuf, Hostname, LocalClientSocket, LocalServerSocket, LocalSocketBase, Log, MailHeaders, Mbuf, Milter, Mstream, OFoldBuf, OneKey, Pattern, Pipe, Process, Redirector, Selector, ServerSocket, Signal, SocketBase, Stat, TempStream, User, Xpointer

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::exception

ENUMERACIÓN

La enumeración Protection es utilizada por el miembro protection descrito a continuación. La enumeración tiene dos valores:

o
ANY: un archivo existente puede tener cualquier conjunto de bits de protección;
o
EQUAL: un archivo existente debe tener exactamente el conjunto de bits de protección especificado al llamar a Exception::protection.

CONSTRUCTORES

o
Exception():
El constructor por defecto (asigna 0 a FBB::g_errno, ver el siguiente constructor).
o
Exception(int errnoValue):
Este constructor almacena el valor proporcionado errnoValue en una variable local de hilo int FBB::g_errno. Antes de Bobcat 4.04.00, errnoValue solo se almacenaba en la variable global ::errno (todavía lo está), pero como esta variable también es utilizada por muchas otras funciones, el valor de errno puede haber cambiado para cuando la excepción sea capturada. La variable thread_local int FBB::g_errno no tiene ese inconveniente.
Cuando g_errno debe ser declarado sin incluir bobcat/exception, haz 
    namespace FBB
    {
        extern thread_local int g_errno;
    }

Los constructores y operadores de copia/movimiento están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::exception están disponibles, ya que FBB::Exception hereda de esta clase.

o
char const *what() const noexcept(true) override:
Devuelve el texto que se insertó en el objeto FBB::Exception.

OPERADORES SOBRECARGADOS

o
Exception &&operator<<(Exception &&in, Type const &t):
Una plantilla de función que implementa el operador de inserción sobrecargado. Puede usarse para insertar valores de cualquier tipo que también pueda insertarse en un objeto ostringstream.

MIEMBROS ESTÁTICOS

Las siguientes funciones de conveniencia se pueden usar para la apertura controlada de objetos de tipo stream, como los objetos std::ofstream y std::ifstream. Estos objetos de tipo stream deben soportar miembros open y close, como los proporcionados por std::ifstream y std::ofstream.

Si el stream ya estaba abierto, primero se cierra.

Si la apertura falla, se lanza una excepción FBB::Exception que contiene un mensaje corto indicando que el stream con nombre no pudo ser abierto.

o
static StreamType factory<StreamType>(std::string const &name):
Devuelve un objeto stream StreamType> abierto que puede ser usado para construir por movimiento un objeto StreamType. Por ejemplo, 
    auto out{ Exception::factory<ofstream>("/tmp/out") };
o
static StreamType factory<StreamType>(int errnoValue, std::string const &name):
Devuelve un objeto stream StreamType> abierto que puede ser usado para construir por movimiento un objeto StreamType. Si la construcción del objeto stream falla, entonces la excepción lanzada FBB::Exception asigna errnoValue a FBB::g_errno.
o
static StreamType factory<StreamType>(std::string const &name, std::ios::openmode mode):
Devuelve un objeto stream StreamType> abierto, creado usando las banderas de openmode mode, que puede ser usado para construir por movimiento un objeto StreamType.
o
static StreamType factory<StreamType>(int errnoValue, std::string const &name, std::ios::openmode mode):
Devuelve un objeto stream StreamType> abierto, creado usando las banderas de openmode mode, que puede ser usado para construir por movimiento un objeto StreamType. Si la construcción del objeto stream falla, entonces la excepción lanzada FBB::Exception asigna errnoValue a FBB::g_errno.
o
static StreamType factory<StreamType>(std::string const &name, std::ios::openmode mode1, std::ios::openmode mode2):
Devuelve un objeto stream StreamType> abierto. El stream se abre inicialmente usando mode1. Si eso falla, se usa mode2. Si ambas formas de abrir el stream fallan, entonces se lanza una Exception. El stream devuelto puede usarse para construir por movimiento un objeto StreamType. Este miembro puede usarse para abrir un std::fstream que puede o no existir todavía para lectura y escritura. Por ejemplo, 
    auto out{ Exception::factory<fstream>("/tmp/out",
                ios::in | ios::out,
                ios::in | ios::out | ios::trunc) };
Si /tmp/out ya existe, entonces ios::in | ios::out debería tener éxito. Si no, se crea vacío para lectura y escritura, usando ios::in | ios::out | ios::trunc.
o
static StreamType factory<StreamType>(int errnoValue, std::string const &name, std::ios::openmode mode1, std::ios::openmode mode2):
Devuelve un objeto stream StreamType> abierto. El stream se abre inicialmente usando mode1. Si eso falla, se usa mode2. Si ambas formas de abrir el stream fallan, entonces se lanza una Exception, asignando errnoValue a FBB::g_errno.
o

Abre el objeto stream, usando su miembro open, pasando mode a open. Si la apertura del stream falla, entonces la excepción lanzada FBB::Exception asigna errnoValue a FBB::g_errno.
