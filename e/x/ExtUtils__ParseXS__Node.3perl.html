XXX Sept 2024: Esto está en progreso. Esta API es actualmente privada y sujeta a cambios. La mayor parte de ParseXS no utiliza un AST, y en su lugar mantiene solo el estado suficiente para emitir código a medida que analiza. Este módulo representa el inicio de un esfuerzo para que utilice un AST en su lugar.

Una clase "ExtUtils::ParseXS::Node", y sus diversas subclases, contienen el estado de los nodos de un Árbol de Sintaxis Abstracta (AST), que representa el estado analizado de un archivo XS.

Cada nodo es básicamente un hash de campos. Qué nombres de campo son legales varía según el tipo de nodo. Las claves y los valores del hash se pueden acceder directamente: no hay métodos getter/setter.
