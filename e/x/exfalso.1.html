NOMBRE

exfalso - editor de etiquetas de audio

SINOPSIS

exfalso [ directorio ]

DESCRIPCIÓN

Ex Falso muestra y edita metadatos de audio. Los formatos compatibles incluyen MP3, Ogg Vorbis, FLAC, Musepack (MPC), WavPack y MOD/XM/IT.

Esta página del manual es solo una referencia breve para Ex Falso. La documentación completa está disponible en https://quodlibet.readthedocs.io/en/latest/guide/.

OPCIONES

Se puede proporcionar un directorio a Ex Falso en la línea de comandos.

ETIQUETAS VINCULADAS

En muchos lugares de Ex Falso se permite usar "etiquetas vinculadas". Las etiquetas vinculadas son dos nombres de etiqueta unidos por un "~" como "title~version" o "album~part". Las etiquetas vinculadas resultan en visualizaciones "agradables" incluso cuando una de las etiquetas falta; por ejemplo, "title~version" resultará en Título - Versión cuando la etiqueta de versión está presente, pero solo Título cuando no lo está. Puedes vincular cualquier número de etiquetas.

RENOMBRADO DE ARCHIVOS

Ex Falso permite renombrar archivos basándose en sus etiquetas. En algunos casos, es posible que desees modificar el nombre del archivo dependiendo de si algunas etiquetas están presentes o ausentes, además de sus valores. Un patrón común podría ser

<tracknumber>. <title~version>

Puedes usar un '|' para poner texto solo cuando una etiqueta está presente:

<tracknumber|<tracknumber>. ><title~version>

También puedes especificar texto literal para usar si la etiqueta falta añadiendo otro '|':

<album|<album>|No Album> - <title>

Ver https://quodlibet.readthedocs.io/en/latest/guide/renaming_files.html.

ERRORES
