EXP2(3P) Manual del Programador POSIX EXP2(3P)

PRÓLOGO

Esta página de manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página de manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

exp2, exp2f, exp2l — funciones exponenciales de base 2

SINOPSIS

#include <math.h>
double exp2(double x);
float exp2f(float x);
long double exp2l(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C no es intencional. Este volumen de POSIX.1‐2017 se subordina al estándar ISO C.

Estas funciones deben calcular el exponencial de base 2 de x.

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DE RETORNO

Tras una finalización exitosa, estas funciones deben devolver 2x.

Si el valor correcto causara desbordamiento, debe ocurrir un error de rango y exp2(), exp2f(), y exp2l() deben devolver el valor de la macro HUGE_VAL, HUGE_VALF y HUGE_VALL, respectivamente.

Si el valor correcto causara desbordamiento inferior, y no es representable, puede ocurrir un error de rango, y exp2(), exp2f(), y exp2l() deben devolver 0.0, o (si la opción de Punto Flotante IEC 60559 no está soportada) un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN y LDBL_MIN, respectivamente.

Si x es NaN, se debe devolver un NaN.

Si x es ±0, se debe devolver 1.

Si x es -Inf, se debe devolver +0.

Si x es +Inf, x debe ser devuelto.

Si el valor correcto causara desbordamiento inferior, y es representable, puede ocurrir un error de rango y se debe devolver el valor correcto.

ERRORES

Estas funciones fallarán si:

Error de rango
El resultado se desborda.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno debe establecerse a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces debe generarse la excepción de punto flotante de desbordamiento.

Estas funciones pueden fallar si:

Error de rango
El resultado se desborda inferiormente.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno debe establecerse a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces debe generarse la excepción de punto flotante de desbordamiento inferior.

USO EN APLICACIONES

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.
