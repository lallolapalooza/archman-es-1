DESCRIPCIÓ

N

ExtUtils::Constant facilita generar código envoltorio de C y XS para permitir que los módulos de perl hagan AUTOLOAD de constantes definidas en archivos de cabecera de bibliotecas C. Es utilizado principalmente por la utilidad "h2xs", en la cual se basa este código. No contiene las ruti

nas para escanear archivos de cab
ecera para extraer estas constantes.

XS_constant PAQUETE, TIPOS, XS_SUBNAME,
C_SUBNAME
Una función para generar el código XS que implementa el subrutina de perl PAQUETE::constant usada por PAQUETE::AUTOLOAD para cargar constantes. Este código XS es un envoltorio alrededor de una subrutina C usualmente generada por "C_constant", y usualmente nombrada "constant".

TIPOS debe darse ya sea como una lista separada por comas de tipos que la subrutina C "constant" generará o como una referencia a un hash. Debe ser la misma lista de tipos que se le dio a "C_constant". [De lo contrario "XS_constant" y "C_constant" pueden tener ideas diferentes sobre el número de parámetros pasados a la función C "constan

t"]

Puedes llamar a la subrutina visible en perl algo diferente a "constant" si das el parámetro XS_SUBNAME. La subrutina C a la que llama tiene como nombre por defecto el de la subrutina visible en perl, a menos que des el parámetro C_SUB
