XSBuilder::ParseSource(3) Documentación de Perl aportada por el usuario XSBuilder::ParseSource(3)

NOMBRE

ExtUtils::XSBuilder::ParseSource - analizar archivos fuente C

DESCRIPCIÓN

Para más información, véase ExtUtils::XSBuilder

extent_parser (o)

Permite al usuario llamar al método Extent o Replace del analizador para añadir nuevas reglas de sintaxis. Esto es útil principalmente para incluir expansiones de macros del preprocesador.

preprocess (o)

Permite al usuario preprocesar la fuente antes de que se le entregue al analizador. Puede modificar la fuente, que se pasa en su lugar como primer argumento.

include_dirs (o)

Devuelve una referencia a la lista de directorios que deben ser buscados para archivos de inclusión que contengan las funciones, estructuras, etc. a extraer.

Por defecto: '.'

include_paths (o)

Devuelve una referencia a una lista de directorios que se pasan como directorios de inclusión al compilador C. Esto se utiliza principalmente para eliminar estos directorios de los nombres de archivo y convertir rutas absolutas en relativas.

Por defecto: lista vacía ("[]")

unwanted_includes (o)

Devuelve una referencia a una lista de archivos de inclusión que no deben ser procesados.

Por defecto: lista vacía ("[]")

sort_includes (o, include_list)

Recibe una referencia a un array de archivos de inclusión, permite al usuario definir el orden de clasificación, para que las inclusiones se procesen correctamente.

Por defecto: devuelve la referencia al array pasado.

find_includes (o)

Devuelve una lista de archivos de inclusión a procesar.

Por defecto: busca en los directorios dados por "include_dirs" todos los archivos y construye una lista de archivos de inclusión. Todos los archivos que comiencen con una palabra que coincida con "unwanted_includes" no se incluirán en la lista.

handle_define (o)

Recibe una referencia a un hash con la definición de un `define`, puede modificarlo. Devuelve falso para descartarlo, devuelve verdadero para conservarlo.

Por defecto: 1

handle_enum (o)

Recibe una referencia a un hash con la definición de un valor `enum`, puede modificarlo. Devuelve falso para descartarlo, devuelve verdadero para conservarlo.

Por defecto: 1

handle_struct (o)

Recibe una referencia a un hash con la definición de una `struct`, puede modificarlo. Devuelve falso para descartarlo, devuelve verdadero para conservarlo.

Por defecto: 1

handle_function (o)

Recibe una referencia a un hash con la definición de una función, puede modificarlo. Devuelve falso para descartarlo, devuelve verdadero para conservarlo.

Por defecto: 1

handle_callback (o)

Recibe una referencia a un hash con la definición de un callback, puede modificarlo. Devuelve falso para descartarlo, devuelve verdadero para conservarlo.

Por defecto: 1

package (o)

Devuelve el nombre del paquete para las tablas

Por defecto: 'MY'

targetdir (o)

Devuelve el nombre del directorio de destino donde escribir las tablas

Por defecto: './xsbuilder/tables'

run

Llama a este método de clase para analizar tu código fuente. Antes de poder hacerlo, debes proporcionar una clase que anule los valores por defecto en ExtUtils::XSBuilder::ParseSource. Después de eso, escanea los archivos fuente con

MyClass -> run ;
