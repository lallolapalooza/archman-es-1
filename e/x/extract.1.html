NOMBRE

extract - determinar metadatos sobre un archivo

SINOPSIS

extract [ -bgihLmnvV ] [ -l biblioteca ] [ -p tipo ] [ -x tipo ] archivo ...

DESCRIPCIÓN

Esta página del manual documenta la versión 1.0.0 del comando extract.

extract prueba cada archivo especificado en la lista de argumentos en un intento de inferir metadatos del mismo. Cada archivo se somete a las bibliotecas de extracción de metadatos de libextractor.

libextractor clasifica los metadatos (también referidos como palabras clave) en tipos. Se puede obtener una lista de todos los tipos con la opción -L.

OPCIONES

-b
Mostrar la salida en formato BiBTeX.
-g
Usar salida compatible con grep (todas las palabras clave en una sola línea para cada archivo). Use la opción detallada para imprimir primero el nombre del archivo, seguido de las palabras clave. Use la opción detallada dos veces para también mostrar los tipos de palabras clave. Esta opción no imprimirá tipos de palabras clave ni metadatos no textuales.
-h
Imprimir un breve resumen de las opciones.
-i
Ejecutar plugins en proceso (para depuración). Por defecto, cada plugin se ejecuta en su propio proceso.
-l bibliotecas
Usar las bibliotecas especificadas para extraer palabras clave. El formato general de las bibliotecas es .I [[-]NOMBRE_BIBLIOTECA[:[-]NOMBRE_BIBLIOTECA]*] donde NOMBRE_BIBLIOTECA es una biblioteca compatible con libextractor y típicamente tiene la forma .Ijpeg. El guion antes del nombre de la biblioteca indica que esta biblioteca debe eliminarse de la lista existente. Para ejecutar solo unos pocos plugins seleccionados, use -l en combinación con -n.
-L
Imprimir una lista de todos los tipos de palabras clave conocidos.
-m
Cargar el archivo en memoria y realizar la extracción desde la memoria (para depuración).
-n
No usar el conjunto predeterminado de extractores (típicamente todos los extractores estándar, actualmente mp3, ogg, jpg, gif, png, tiff, real, html, pdf y tipos mime), usar solo los extractores especificados con la opción .B -l.
-p tipo
Imprimir solo las palabras clave que coincidan con el tipo especificado. Por defecto, se imprimen todas las palabras clave que se encuentran y no se eliminan como duplicadas.
-v
Imprimir el número de versión y salir.
-V
Ser detallado. Esta opción se puede especificar varias veces para aumentar aún más el nivel de detalle.
-x tipo
Excluir palabras clave del tipo especificado de la salida. Por defecto, se imprimen todas las palabras clave que se encuentran y no se eliminan como duplicadas.

VER TAMBIÉN

EJEMPLOS

$ extract test/test.jpg
comment - (C) 2001 by Christian Grothoff, using gimp 1.2 1
mimetype - image/jpeg
$ extract -V -x comment test/test.jpg
Keywords for file test/test.jpg:
mimetype - image/jpeg
$ extract -p comment test/test.jpg
comment - (C) 2001 by Christian Grothoff, using gimp 1.2 1
$ extract -nV -l png.so -p comment test/test.jpg test/test.png
Keywords for file test/test.jpg:
Keywords for file test/test.png:
comment - Testing keyword extraction
