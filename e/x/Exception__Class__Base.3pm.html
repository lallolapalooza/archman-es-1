EXCEPCIONES

LIGERAS

Una excepción ligera es aquella que no registra información sobre su contexto cuando es creada. Esto se puede lograr configurando "$class->NoContextInfo" a un valor

verdadero.

Puedes hacer esto el valor por defecto para una clase de excepciones configurándolo después de crear la

clase: 
use Exception::Class (
    'LightWeight',
    'HeavyWeight',
);
LightWeight->NoContextInfo(1)
;

Una excepción ligera no tiene un objeto de stac

k trace, ni tampoco registra el tiempo, pid
, uid, euid, gid o egid. Solo tiene un mensaje.

SOBRECARG

A

Los objetos "Exception::Class::Base" están sobrecargados para que la conversión a cadena produzca un mensaje de error normal. Esto simplemente llama al "$exception->as_string" method descrito arriba. Esto significa que puedes simplemente "print $@" después de un "eval" y no preocuparte de si es un objeto real o no. También significa que una aplicación o módulo podría hacer

esto: 
$SIG{__DIE__} = sub { Exception::Class::Base->throw( error => join '', @_ ); }
;

y esto probablemente no rompería nada (a menos que alguien esperara un tipo diferente de objeto de excepción de "die

"
).

SOBRESCRIBIENDO EL MÉTODO

as_string

Por defecto, el "as_string" method simplemente devuelve el valor "message" o "error" param más un stack trace, si el método "Trace" de la clase devuelve un valor verdadero o "show_trace" fue configurado al crear la

excepción.

Sin embargo, una vez que agregues nuevos campos a una subclase, podrías querer incluir esos campos en el error convertido a

cadena.

Dentro del "as_string" method, la porción del mensaje (sin stack trace) del error es generada llamando al "full_message" method. Este puede ser fácilmente sobreescrito. Por

ejemplo: 
sub full_message {
    my $self = shift;
    my $msg = $self->message;
    $msg .= " and foo was " . $self->foo;
    return $msg;
}
