experimental(3perl) Guía de referencia para programadores de Perl experimental(3perl)

NOMBRE

experimental - Facilita las características experimentales

VERSIÓN

versión 0.035

SINOPSIS

use experimental 'lexical_subs', 'signatures';
my sub plus_one($value) { $value + 1 }

DESCRIPCIÓN

Este pragma proporciona una forma fácil y conveniente de habilitar o deshabilitar características experimentales.

Cada versión de perl tiene un número de características presentes pero consideradas "experimentales". Durante gran parte de la vida de Perl 5, esta era solo una designación que se encontraba en la documentación. A partir de Perl v5.10.0, y de manera más agresiva en v5.18.0, las características experimentales se colocaron detrás de pragmas utilizados para habilitar la característica y deshabilitar las advertencias asociadas.

El pragma "experimental" existe para combinar las invocaciones requeridas en una única interfaz estable entre versiones de perl. Para cada característica experimental, esto debería habilitar la característica y silenciar las advertencias para el ámbito léxico que la contiene:

use experimental 'feature-name';

Para deshabilitar la característica y, si es aplicable, volver a habilitar cualquier advertencia, use:

no experimental 'feature-name';

Las características compatibles, documentadas más abajo, son:

  • "args_array_with_signatures" - permite usar @_ en subs con firmas.

    Esto es compatible con perl 5.20.0 y superior, pero es probable que se elimine en el futuro.

  • "array_base" - permite el uso de $[ para cambiar el índice de inicio de @array.

    Esto se eliminó en perl 5.30.0.

  • "autoderef" - permite push, each, keys, y otros incorporados en referencias.

    Esto se añadió en perl 5.14.0 y se eliminó en perl 5.24.0.

  • "bitwise" - permite los nuevos operadores de bits a nivel de cadena.

    Esto se añadió en perl 5.22.0.

  • "builtin" - permite el uso de las funciones del espacio de nombres builtin::

    Esto se añadió en perl 5.36.0.

  • "const_attr" - permite el atributo :const en subs.

    Esto se añadió en perl 5.22.0.

  • "declared_refs" - habilita la creación de alias mediante asignación a referencias.

    Esto se añadió en perl 5.26.0.

  • "defer" - habilita el uso de bloques defer.

    Esto se añadió en perl 5.36.0.

  • "extra_paired_delimiters" - habilita el uso de más delimitadores de cadena emparejados que los cuatro tradicionales: "<  >", "( )", "{ }" y "[ ]".

    Esto se añadió en perl 5.36.

  • "for_list" - permite iterar sobre múltiples valores a la vez con "for".

    Esto se añadió en perl 5.36.0.

  • "isa" - permite el uso del operador in-line "isa".

    Esto se añadió en perl 5.32.0.

  • "lexical_topic" - permite el uso del tópico léxico $_ mediante "my $_".

    Esto se añadió en perl 5.10.0 y se eliminó en perl 5.24.0.

  • "lexical_subs" - permite el uso de subrutinas léxicas.

    Esto se añadió en 5.18.0 y se volvió no experimental (y siempre habilitado) en 5.26.0.

  • "postderef" - permite el uso de expresiones de desreferenciación postfija.

    Esto se añadió en perl 5.20.0 y se volvió no experimental (y siempre habilitado) en 5.24.0.

  • "postderef_qq" - permite el uso de expresiones de desreferenciación postfija dentro de cadenas de interpolación.

    Esto se añadió en perl 5.20.0 y se volvió no experimental (y siempre habilitado) en 5.24.0.

  • "re_strict" - habilita el modo estricto en expresiones regulares.

    Esto se añadió en perl 5.22.0.

  • "refaliasing" - permite la creación de alias mediante "\$x = \$y".

    Esto se añadió en perl 5.22.0.

  • "regex_sets" - permite clases de caracteres entre corchetes extendidas en expresiones regulares.

    Esto se añadió en perl 5.18.0 y se volvió no experimental (y siempre habilitado) en 5.36.0.

    Esto se documenta en "Clases de caracteres entre corchetes extendidas" en perlrecharclass.

  • "signatures" - permite firmas de subrutinas (para argumentos nombrados).

    Esto se añadió en perl 5.20.0.

  • "smartmatch" - permite el uso de "~~".

    Esto se añadió en perl 5.10.0, pero cabe señalar que existen incompatibilidades significativas entre 5.10.0 y 5.10.1.

    La característica se marcó como obsoleta en perl 5.38.0 y se volvió a habilitar en 5.42.0.

  • "switch" - permite el uso de "~~", given, y when.

    Esto se añadió en perl 5.10.0.

    La característica se marcó como obsoleta en perl 5.38.0 y se volvió a habilitar en 5.42.0.

  • "try" - permite el uso de "try" y "catch".

    Esto se añadió en perl 5.34.0.

  • "win32_perlio" - permite el uso de la capa IO :win32.

    Esto se añadió en perl 5.22.0.

El orden importa

Usar este pragma para 'habilitar una característica experimental' es otra forma de decir que este pragma deshabilitará las advertencias que resultarían del uso de esa característica. Por lo tanto, el orden en el que se aplican los pragmas es importante. En particular, probablemente querrá habilitar las características experimentales *después* de habilitar las advertencias:

use warnings;
use experimental 'smartmatch';

También debe tener cuidado con los módulos que habilitan advertencias por usted. Un ejemplo común es Moose. En este ejemplo, las advertencias para la característica 'smartmatch' se activan primero con el pragma warnings, se desactivan con el pragma experimental y se vuelven a activar con el módulo Moose (la solución es intercambiar las dos últimas líneas):

use warnings;
use experimental 'smartmatch';
use Moose;

Descargo de responsabilidad

Debido a la naturaleza de las características que habilita, la compatibilidad futura no se puede garantizar de ninguna manera.
