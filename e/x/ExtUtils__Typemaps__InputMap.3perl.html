ExtUtils::Typemaps::InputMap(3perl) Guía de referencia para programadores de Perl ExtUtils::Typemaps::InputMap(3perl)

NOMBRE

ExtUtils::Typemaps::InputMap - Entrada en la sección INPUT de un typemap

SINOPSIS

use ExtUtils::Typemaps;
...
my $input = $typemap->get_input_map('T_NV');
my $code = $input->code();
$input->code("...");

DESCRIPCIÓN

Consulte ExtUtils::Typemaps para obtener detalles.

MÉTODOS

new

Requiere los parámetros "xstype" y "code".

code

Devuelve o establece el código de mapeo de entrada para esta entrada.

xstype

Devuelve el nombre del tipo XS del mapa de entrada.

cleaned_code

Devuelve una copia limpia del código al que se han aplicado ciertas transformaciones para hacerlo más compatible con ANSI.

VEA TAMBIÉN

ExtUtils::Typemaps
