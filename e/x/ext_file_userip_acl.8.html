NOMBRE

ext_file_userip_acl - Restringe a los usuarios a ciertas direcciones IP, utilizando un backend de archivo de texto.

Versión 1.0

SINOPSIS

ext_file_userip_acl [-dh] [-f nombre_archivo ]

DESCRIPCIÓN

ext_file_userip_acl es un binario instalado. Un helper externo para el esquema de ACL externo de Squid.

Funciona leyendo un par compuesto por una dirección IP y un nombre de usuario en STDIN y comparándolo con un archivo de configuración.

OPCIONES

-d
Escribe información de depuración en stderr.
-f archivo
Archivo de configuración archivo para cargar.
-h
Muestra la ayuda del binario y la información de la sintaxis de la línea de comandos en stderr.

CONFIGURACIÓN

La configuración de squid.conf para la ACL externa debería ser:

external_acl_type nombre-tipo %SRC %LOGIN /ruta/a/ext_file_userip_acl -f /ruta/a/archivo.config

Si el programa helper encuentra un nombre de usuario/IP coincidente en el archivo de configuración, devuelve OK, de lo contrario devuelve ERR.

El formato del archivo de configuración es el siguiente:

ip_addr[/netmask] username|@group|ALL|NONE

Donde ip_addr es una dirección IP en formato de cuádruple punto, y la netmask también debe estar en formato de cuádruple punto.

Cuando el segundo parámetro está prefijado con un @, el programa buscará la entrada del archivo /etc/group para el nombre de usuario especificado.

Hay otras dos directivas, ALL y NONE, que significan "cualquier usuario en esta dirección IP puede autenticarse" o "ningún usuario en esta dirección IP puede autenticarse".
