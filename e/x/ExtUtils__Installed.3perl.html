DESCRIPCIÓ

N

ExtUtils::Installed proporciona una forma estándar de averiguar qué archivos del núcleo y de módulos se han instalado. Utiliza

la información almacenada en los archivos .packlist creados durante la instalación para proporcionar esta información. Además,
ofrece funciones para clasificar los archivos instalados y para extraer información de directorios de los archivos .packlist.

US

O

La función new() busca todos los .packlists instalados en el sistema y almacena su contenido. Los .packlists se pueden consultar con las funciones descritas más abajo. Dónde busca por defecto lo determinan las configuraciones encontradas en %Config::Config, y el valor de l

a variable de e
ntorno PERL5LIB.

A menos que se especifique lo contrario, todos los métodos se pueden llamar como métodos de clase o como métodos de objeto. Si se llaman como métodos de clase, se utilizará el objeto "predeterminado", y si es necesario, se creará usando el %Config y el @INC del proceso actual. Consulte la opción 'default' de new() para más

detalles.
new
()
Acepta parámetros con nombre opcionales. Sin parámetros, busca todos los .packlists instalados en el sistema utilizando información de %Config::Config y las rutas de búsqueda de módulos por defecto @INC. Los packlists se leen utilizando el módulo

ExtUtils::Packlist. Si el parámetro con nombre "skip_cwd" es verdadero, el directorio actual "." se eliminará de @INC antes de buscar .packlists. Esto evita

que

ExtUtils::Installed encuentre módulos instalados en otros perls que resulten estar ubicados debajo del directorio actual. Si se especifica el parámetro con nombre "config_override", debe ser una referencia a un hash que contenga toda la información que normalmente se encuentra en %Config::Config. Por ejemplo, puede obtener la información de configuración de una instalación de perl separada y

pasarla. 
my $yoda_cfg  = get_fake_config('yoda');
my $yoda_inst =
           ExtUtils::Installed->new(config_override=>$yoda_cfg);
De manera similar, el
parámetro

"inc_override" puede ser una referencia a un array que se utiliza en lugar de las rutas de búsqueda de módulos por defecto de @I

NC. 
use Config;
my @dirs = split(/\Q$Config{path_sep}\E/, $ENV{PERL5LIB});
my $p5libs = ExtUtils::Installed->new(inc_override=>\@dirs);

modules(
)
Devuelve una lista con los nombres de todos los módulos instalados. Al 'núcleo' de perl
se le da el nombre especial 'Perl'.
files(
)
Acepta un parámetro obligatorio, el nombre de un módulo. Devuelve una lista de todos los nombres de archivo del paquete. Para obtener una lista de los archivos del núcleo de perl, use el nombre de módulo 'Perl'. Se permiten parámetros adicionales. El primero es una de las cadenas "prog", "doc" o "all", para seleccionar solo archivos de programa, solo archivos de manual o todos los archivos. Los parámetros restantes son una lista de
directorios. Los nombres de archivo devueltos se restringirán a aquellos bajo los directorios especificados.
directories(
)
Acepta un parámetro obligatorio, el nombre de un módulo. Devuelve una lista de todos los directorios del paquete. Se permiten parámetros adicionales. El primero es una de las cadenas "prog", "doc" o "all", para seleccionar solo directorios de programa, solo directorios de manual o todos los directorios. Los parámetros restantes son una lista de directorios. Los directorios devueltos se restringirán a aquellos bajo los directorios especificados. Este
método devuelve solo los directorios hoja que contienen archivos del módulo especificado.
