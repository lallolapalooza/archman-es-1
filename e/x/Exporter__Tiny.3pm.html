Exporter::Tiny(3) Documentación de Perl aportada por el usuario Exporter::Tiny(3)

NOMBRE

Exporter::Tiny - un exportador con las características de Sub::Exporter pero solo dependencias principales

SINOPSIS

package MyUtils;
use base "Exporter::Tiny";
our @EXPORT = qw(frobnicate);
sub frobnicate { ... }
1;
package MyScript;
use MyUtils "frobnicate" => { -as => "frob" };
print frob(42);
exit;

DESCRIPCIÓN

Exporter::Tiny soporta muchas de las características externas de Sub::Exporter, incluyendo el renombrado de funciones importadas con las opciones "-as", "-prefix" y "-suffix"; destinos explícitos con la opción "into"; y instaladores alternativos con la opción "installer". Pero está escrito en solo aproximadamente el 40% de las líneas de código y con cero dependencias no principales.

Su interfaz interna se acerca más a Exporter.pm, con la configuración realizada a través de las variables de paquete @EXPORT, @EXPORT_OK y %EXPORT_TAGS.

Si está intentando **escribir** un módulo que hereda de Exporter::Tiny, entonces mire:

  • Exporter::Tiny::Manual::QuickStart
  • Exporter::Tiny::Manual::Exporting

Si está intentando **usar** un módulo que hereda de Exporter::Tiny, entonces mire:

•
Exporter::Tiny::Manual::Importing
