exp10(3) Manual de funciones de la biblioteca exp10(3)

NOMBRE

exp10, exp10f, exp10l - función exponencial de base 10

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <math.h>
double exp10(double x);
float exp10f(float x);
long double exp10l(long double x);

DESCRIPCIÓN

Estas funciones devuelven el valor de 10 elevado a la potencia de x.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor exponencial de base 10 de x.

Para varios casos especiales, incluido el manejo de infinito y NaN, así como desbordamientos y subdesbordamientos, consulte exp(3).

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si se ha producido un error al llamar a estas funciones.

Para una discusión de los errores que pueden ocurrir con estas funciones, consulte exp(3).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
exp10 (), exp10f (), exp10l () Seguridad en hilos MT-Safe

ESTÁNDARES

GNU.

HISTORIAL

glibc 2.1.

ERRORES CONOCIDOS

Antes de glibc 2.19, la implementación de glibc de estas funciones no establecía errno en ERANGE cuando ocurría un error de subdesbordamiento.

VER TAMBIÉN

cbrt(3), exp(3), exp2(3), log10(3), sqrt(3)
