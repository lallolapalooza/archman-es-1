EXFATATTRIB(8) Manual del Administrador del Sistema EXFATATTRIB(8)

NOMBRE

exfatattrib - Establecer o mostrar atributos de archivos exFAT

SINOPSIS

exfatattrib [ -r | -R | -i | -I | -s | -S | -a | -A ] -d dispositivo archivo

DESCRIPCIÓN

exfatattrib establece o muestra los atributos de un archivo en un sistema de archivos exFAT.

dispositivo es la ruta a una partición de disco desmontada o archivo de imagen de disco que contiene un sistema de archivos exFAT.

archivo es la ruta de un archivo dentro de ese sistema de archivos.

Si se ejecuta sin opciones de línea de comandos, se mostrarán los atributos actuales de archivo; de lo contrario, se establecerán o limpiarán los atributos especificados. Es un error establecer y limpiar la misma bandera.

OPCIONES DE LÍNEA DE COMANDOS

Opciones de línea de comandos disponibles:

-d dispositivo
La ruta a una partición de disco desmontada o archivo de imagen de disco que contiene un sistema de archivos exFAT. Esta opción es obligatoria.
-r
Establecer bandera de solo lectura
-R
Limpiar bandera de solo lectura
-i
Establecer bandera oculta (mnemotécnico: invisible)
-I
Limpiar bandera oculta
-s
Establecer bandera de sistema
-S
Limpiar bandera de sistema
-a
Establecer bandera de archivo
-A
Limpiar bandera de archivo
-h
Mostrar este mensaje de ayuda
-V
Imprimir versión y derechos de autor.

CÓDIGOS DE SALIDA

Se devuelve cero si no se encontraron errores. Cualquier otro código significa un error.
