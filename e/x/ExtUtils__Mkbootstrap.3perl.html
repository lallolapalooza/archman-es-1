NOMBRE

ExtUtils::Mkbootstrap - crea un archivo de arranque para ser utilizado por DynaLoader

SINOPSIS

Mkbootstrap

DESCRIPCIÓN

Mkbootstrap normalmente se llama desde un Makefile de extensión.

No se proporciona ningún archivo "*.bs" con la extensión. En su lugar, puede haber un archivo *_BS que contenga código para casos especiales, como posix para berkeley db en NeXT.

Este archivo se analizará y producirá un array quizás vacío @DynaLoader::dl_resolve_using para la arquitectura actual. Este será extendido por $BSLOADLIBS, que fue calculado por ExtUtils::Liblist::ext(). Si este array todavía está vacío, no hacemos nada, de lo contrario, escribimos un archivo .bs con un array @DynaLoader::dl_resolve_using.

El archivo *_BS puede insertar código en el archivo "*.bs" generado colocándolo en $bscode. Este es un mecanismo de 'escape' útil que puede resultar útil en situaciones complejas.

Si @DynaLoader::dl_resolve_using contiene entradas "-L*" o "-l*", entonces Mkbootstrap agregará automáticamente una llamada a dl_findfile() al archivo "*.bs" generado.
