Sobrescribiendo la subrutina existente '%s::%s' con la subrutina '%s' exportada por %
s
  
Una advertencia emitida si se le pide a Exporter::Tiny que exporte un símbolo que resultará en la sobrescritura de una subrutina existente. Esta advertencia puede suprimirse usando cualquiera de las siguientes:
        
use MyUtils { replace => 1 }, "frobnicate";
use MyUtils "frobnicate" => { -replace =>
 1 };
    
O puede convertirse en un error 
fatal:
        
use MyUtils { replace => "die" }, "frobnicate";
use MyUtils "frobnicate" => { -replace => 
"die" 
};
  
Rehusándose a sobrescribir la subrutina existente '%s::%s' con la subrutina '%s' exportada por
    %
s
  
La versión fatal de la advertencia 
anterior.
  
No se pudo encontrar la subrutina '%s' exportada por %
s
  
Solicitaste importar una subrutina que el paquete no proporciona.

  
No se puede proporcionar una opción -as
    para etiquetas

  
Dado que una etiqueta puede proporcionar más de una función, no tiene sentido
      solicitar un único nombre para ella. En su lugar, utilice
      "-prefix" o
      "-suffix".

  
Pasar opciones a
    unimport '%s' no tiene sentido

  
Cuando se importa un sub, ocasionalmente tiene sentido pasar algunas opciones
      para él. Sin embargo, al desimportar, las opciones no hacen nada, por lo que se emite
      esta advertencia.
