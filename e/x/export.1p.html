EXPORT(1P) Manual del programador POSIX EXPORT(1P)

PROLOGO

Esta página de manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página de manual correspondiente de Linux para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

export — establecer el atributo de exportación para variables

SÍNTAXIS

export name[=word]...
export -p

DESCRIPCIÓN

La shell debe otorgar el atributo export a las variables correspondientes a los name especificados, lo que hará que estén en el entorno de los comandos ejecutados posteriormente. Si el nombre de una variable está seguido por =word, entonces el valor de esa variable se establecerá en word.

El constructo especial export debe soportar el volumen de Definiciones Básicas de POSIX.1‐2017, Sección 12.2, Directrices de sintaxis de utilidad.

Cuando se especifica -p, export debe escribir en la salida estándar los nombres y valores de todas las variables exportadas, en el siguiente formato:

"export %s=%s\n", <name>, <value>

si name está establecido, y:

"export %s\n", <name>

si name no está establecido.

La shell debe formatear la salida, incluyendo el uso correcto de comillas, de modo que sea apta para reintroducirse a la shell como comandos que logren los mismos resultados de exportación, excepto:

1.
Las variables de solo lectura con valores no pueden reiniciarse.
2.
Las variables que no estaban establecidas en el momento en que se generó la salida no necesitan reiniciarse al estado no establecido si se asigna un valor a la variable entre el momento en que se guardó el estado y el momento en que la salida guardada se reintroduce a la shell.

Cuando no se proporcionan argumentos, los resultados son indeterminados.

ESTADO DE SALIDA

USO DE LA APLICACIÓN

Tenga en cuenta que, a menos que X haya sido previamente marcado como solo lectura, el valor de "$?" después de:

export X=$(false)

será 0 (porque export estableció con éxito X en la cadena vacía) y que la ejecución continúa, incluso si set -e está en vigor. Para detectar fallos en la sustitución de comandos, el usuario debe separar la asignación de la exportación, como en:

X=$(false)
export X

EJEMPLOS

Exportar las variables PWD y HOME:

export PWD HOME

Establecer y exportar la variable PATH:

export PATH=/local/bin:$PATH

Guardar y restaurar todas las variables exportadas:

export -p > temp-file
unset a lot of variables
... processing
. temp-file

RACIONAL

Algunas shells históricas utilizan el caso sin argumentos como el equivalente funcional de lo que se requiere aquí con -p. Esta función se dejó sin especificar porque no es la práctica histórica en todas las shells, y algunos scripts pueden depender de los resultados ahora no especificados en sus implementaciones. Los intentos de especificar la salida -p como el caso por defecto fueron infructuosos para lograr consenso. Se añadió la opción -p para permitir el acceso portátil a los valores que se pueden guardar y luego restaurar posteriormente utilizando, por ejemplo, un script dot.
