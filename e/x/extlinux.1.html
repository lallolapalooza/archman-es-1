extlinux(1) Manual General de Comandos extlinux(1)

NOMBRE

extlinux - instala el cargador de arranque SYSLINUX en un sistema de archivos ext2/ext3/ext4/btrfs/xfs

SINOPSIS

extlinux [opciones] directorio

DESCRIPCIÓN

EXTLINUX es un nuevo derivado de syslinux, que arranca desde un sistema de archivos Linux ext2/ext3/ext4/btrfs o xfs. Funciona de la misma manera que SYSLINUX, con algunas modificaciones menores. Está diseñado para simplificar la instalación inicial de Linux y para la creación de discos de rescate y otros propósitos especiales.

El instalador está diseñado para ejecutarse en un directorio montado. Por ejemplo, si tienes una unidad USB ext2, ext3, ext4 o btrfs montada en /mnt, puedes ejecutar el siguiente comando:

extlinux --install /mnt

OPCIONES

-H, --heads=#
Fuerza el número de cabezales.
-i, --install
Instala sobre el sector de arranque actual.
-O, --clear-once
Borra el comando de arranque único.
-o, --once=comando
Ejecuta un comando una vez al arrancar.
-M, --menu-save=etiqueta
Establece la etiqueta a seleccionar como predeterminada en el próximo arranque.
-r, --raid
Retrocede al siguiente dispositivo en caso de fallo de arranque.
--reset-adv
Restablece los datos auxiliares.
-S, --sectors=#
Fuerza el número de sectores por pista.
-U, --update
Actualiza una instalación previa de EXTLINUX.
-z, --zip
Fuerza la geometría de unidad zip (-H 64 -S 32).
--device=nombre_dispositivo
Anula la detección automática de nombres de dispositivos. Esta opción está pensada solo para entornos especiales y no debe ser utilizada por usuarios normales. El uso incorrecto de esta opción puede causar corrupción del disco y pérdida de datos.

ARCHIVOS

El archivo de configuración de extlinux debe llamarse syslinux.cfg o extlinux.conf y debe almacenarse en el directorio de instalación de extlinux. Para más información sobre el contenido de extlinux.conf, consulta la página del manual de syslinux(1), sección archivos.

LIMITACIONES

Arrancar desde XFS solo funciona cuando se utiliza una tabla de particiones MBR (no en tablas de particiones GPT).

BUGS

Agradecería recibir noticias sobre cualquier problema que tengas con SYSLINUX. También me gustaría tener noticias tuyas si has utilizado SYSLINUX con éxito, especialmente si lo estás utilizando para una distribución.

Si estás informando de problemas, por favor incluye toda la información posible sobre tu sistema y tu BIOS; la gran mayoría de todos los problemas informados resultan ser errores de BIOS o de hardware, y necesito la mayor cantidad de información posible para diagnosticar los problemas.

Hay una lista de correo para la discusión entre usuarios de SYSLINUX y para anuncios de versiones nuevas y de prueba. Puedes suscribirte a esta lista de correo.
