NOMBRE

ExtUtils::Manifest - Utilidades para escribir y verificar un archivo MANIFEST

VERSIÓN

versión 1.75

SINOPSIS

use ExtUtils::Manifest qw(...funcs to import...);
mkmanifest();
my @missing_files    = manicheck;
my @skipped          = skipcheck;
my @extra_files      = filecheck;
my($missing, $extra) = fullcheck;
my $found    = manifind();
my $manifest = maniread();
manicopy($read,$target);
maniadd({$file => $comment, ...});

FUNCIONES

ExtUtils::Manifest no exporta ninguna función de forma predeterminada. Las siguientes se exportan bajo petición:

mkmanifest

mkmanifest();

Escribe todos los archivos en y por debajo del directorio actual en tu MANIFEST. Funciona de manera similar al resultado del comando de Unix

find . > MANIFEST

Todos los archivos que coincidan con cualquier expresión regular en un archivo MANIFEST.SKIP (si existe) se ignoran.

Cualquier archivo MANIFEST existente se guardará como MANIFEST.bak.

manifind

my $found = manifind();

devuelve una referencia a un hash. Las claves del hash son los archivos encontrados por debajo del directorio actual.

manicheck

my @missing_files = manicheck();

comprueba si todos los archivos dentro de un "MANIFEST" en el directorio actual realmente existen. Si "MANIFEST" y el árbol por debajo del directorio actual están sincronizados, devuelve silenciosamente una lista vacía. De lo contrario, devuelve una lista de archivos que están listados en el "MANIFEST" pero faltan en el directorio, y de forma predeterminada también imprime estos nombres en STDERR.

filecheck

my @extra_files = filecheck();

encuentra archivos por debajo del directorio actual que no están mencionados en el archivo "MANIFEST" . Se consultará un archivo opcional "MANIFEST.SKIP" . Cualquier archivo que coincida con una expresión regular en dicho archivo no se informará como faltante en el archivo "MANIFEST" . Se devuelve la lista de cualquier archivo extraño encontrado, y de forma predeterminada también se informa a STDERR.

fullcheck

my($missing, $extra) = fullcheck();

realiza tanto una manicheck() como una filecheck(), devolviéndolas luego como dos referencias a arreglos.

skipcheck

my @skipped = skipcheck();

lista todos los archivos que se omiten debido a tu archivo "MANIFEST.SKIP" .

maniread

my $manifest = maniread();
my $manifest = maniread($manifest_file);

lee un archivo "MANIFEST" con nombre (por defecto "MANIFEST" en el directorio actual) y devuelve una referencia a un HASH con los archivos como claves y los comentarios como valores del HASH. Las líneas en blanco y las líneas que comienzan con "#" en el archivo "MANIFEST" se descartan.

maniskip

my $skipchk = maniskip();
my $skipchk = maniskip($manifest_skip_file);
if ($skipchk->($file)) { .. }

lee un archivo "MANIFEST.SKIP" con nombre (por defecto "MANIFEST.SKIP" en el directorio actual) y devuelve una referencia a un CÓDIGO que prueba si un nombre de archivo dado debe omitirse.

manicopy

manicopy(\%src, $dest_dir);
manicopy(\%src, $dest_dir, $how);

Copia los archivos que son las claves en %src al $dest_dir. %src es típicamente devuelto por la función maniread() .

manicopy( maniread(), $dest_dir );

Esta función es útil para producir un árbol de directorios idéntico al árbol de distribución previsto.

$how puede usarse para especificar un método diferente de "copia". Los valores válidos son "cp", que realmente copia los archivos, "ln" que crea enlaces duros, y "best" que enlaza principalmente los archivos pero copia cualquier enlace simbólico para hacer un árbol sin ningún enlace simbólico. "cp" es el valor predeterminado.

maniadd

maniadd({ $file => $comment, ...});

Añade una entrada a un MANIFEST existente a menos que ya esté ahí.

$file se normalizará (es decir, se convertirá a estilo Unix). NO IMPLEMENTADO

MANIFEST

Una lista de archivos en la distribución, un archivo por línea. El MANIFEST siempre usa las convenciones de rutas de archivo de Unix incluso si no estás en Unix. Esto significa el estilo foo/bar y no foo\bar.

Cualquier cosa entre espacio en blanco y un fin de línea dentro de un archivo "MANIFEST" se considera un comentario. Cualquier línea que comience con # también es un comentario. A partir de ExtUtils::Manifest 1.52, un nombre de archivo puede contener caracteres de espacio en blanco si está encerrado entre comillas simples; las comillas simples o las barras invertidas en ese nombre de archivo deben escaparse con una barra invertida.

# this a comment
some/file
some/other/file            comment about some/file
'some/third file'          comment

MANIFEST.SKIP

El archivo MANIFEST.SKIP puede contener expresiones regulares de archivos que deben ser ignorados por mkmanifest() y filecheck(). Las expresiones regulares deben aparecer una en cada línea. Las líneas en blanco y las líneas que comienzan con "#" se omiten. Usa "\#" si necesitas que una expresión regular comience con un "#".

Por ejemplo:

# Version control files and dirs.
\bRCS\b
\bCVS\b
,v$
\B\.svn\b
# Makemaker generated files and dirs.
^MANIFEST\.
^Makefile$
^blib/
^MakeMaker-\d
# Temp, old and emacs backup files.
~$
\.old$
^#.*#$
^\.#

Si no se encuentra ningún archivo MANIFEST.SKIP, se usará un conjunto predeterminado de omisiones, similar al ejemplo de arriba. Si no quieres que se omita nada, simplemente crea un archivo MANIFEST.SKIP vacío.

En el propio archivo MANIFEST.SKIP de uno, se pueden usar ciertas directivas para incluir el contenido de otros archivos MANIFEST.SKIP. Actualmente se reconocen dos de tales directivas.

#!include_default
Esto le dice a ExtUtils::Manifest que lea el archivo MANIFEST.SKIP predeterminado y omita los archivos en consecuencia, pero no para incluirlo en el MANIFEST.SKIPlocal. Esto está destinado a omitir archivos de acuerdo con un valor predeterminado del sistema, que puede cambiar con el tiempo sin requerir más cambios en el MANIFEST.SKIPde la distribución.
#!include /Path/to/another/manifest.skip
Esto inserta el contenido del archivo externo especificado en el MANIFEST.SKIPlocal. Esto está destinado a que los autores tengan un archivo MANIFEST.SKIP central, y lo incluyan con sus diversas distribuciones.

El contenido incluido se insertará en el archivo MANIFEST.SKIP entre los marcadores #!start included /path/to/manifest.skip y #!end included /path/to/manifest.skip . El archivo MANIFEST.SKIP original se guarda como MANIFEST.SKIP.bak.

EXPORT_OK

&mkmanifest, &manicheck, &filecheck, &fullcheck, &manileer, y &manicopy son exportables.

VARIABLES GLOBALES

$ExtUtils::Manifest::MANIFEST tiene como valor por defecto "MANIFEST". Cambiarlo resulta tanto en un "MANIFEST" diferente como en un archivo "MANIFEST.SKIP" diferente. Esto es útil si quieres mantener distribuciones diferentes para diferentes audiencias (por ejemplo, una versión para usuarios y una versión para desarrolladores que incluya RCS).

$ExtUtils::Manifest::Quiet tiene como valor por defecto 0. Si se le asigna un valor verdadero, todas las funciones actúan en silencio.

$ExtUtils::Manifest::Debug tiene como valor por defecto 0. Si se le asigna un valor verdadero, o si PERL_MM_MANIFEST_DEBUG es verdadero, se producirá una salida de depuración.

DIAGNÓSTICOS

Toda la salida de diagnóstico se envía a "STDERR".

"Not in MANIFEST:" archivo
se informa si se encuentra un archivo que no está en "MANIFEST".
"Skipping" archivo
se informa si un archivo se omite debido a una entrada en "MANIFEST.SKIP".
"No such file:" archivo
se informa si un archivo mencionado en un "MANIFEST" no existe.
"MANIFEST:" $!
se informa si "MANIFEST" no se pudo abrir.
"Added to MANIFEST:" archivo
se informa por mkmanifest() si $Verbose está activado y se añade un archivo a MANIFEST. $Verbose está activado por defecto con el valor 1.

ENTORNO

PERL_MM_MANIFEST_DEBUG
