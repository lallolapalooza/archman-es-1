EXFATFSCK(8) Manual del administrador del sistema EXFATFSCK(8)

NOMBRE

exfatfsck - comprobar un sistema de archivos exFAT

SINOPSIS

exfatfsck [ -a | -n | -p | -y ] dispositivo
exfatfsck [ -V ]

DESCRIPCIÓN

exfatfsck comprueba un sistema de archivos exFAT en busca de errores. Puede reparar algunos de ellos.

OPCIONES DE LÍNEA DE COMANDOS

Opciones de línea de comandos disponibles:

-a
Reparar automáticamente el sistema de archivos. No se requiere intervención del usuario.
-n
Modo de no operación: comprobar los errores de forma no interactiva, pero sin escribir nada en el sistema de archivos.
-p
Igual que -a para compatibilidad con otros *fsck.
-V
Imprimir versión y copyright.
-y
Igual que -a para compatibilidad con otros *fsck.

CÓDIGOS DE SALIDA

Se devuelve cero si no se encontraron errores. Cualquier otro código significa un error.
