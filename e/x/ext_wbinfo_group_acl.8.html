NOMBRE

ext_wbinfo_group_acl - helper externo de ACL para Squid para verificar la membresía de grupo de un dominio NT usando wbinfo.

SINOPSIS

ext_wbinfo_group_acl [-dhK]

DESCRIPCIÓN

ext_wbinfo_group_acl es un script ejecutable instalado. Utiliza wbinfo de Samba para buscar la membresía de grupo de los usuarios conectados.

Este helper debe usarse con un esquema de autenticación (típicamente Básico o NTLM) basado en usuarios de dominio de Windows NT/2000.

Lee desde la entrada estándar el nombre de usuario del dominio y una lista de grupos, y trata de hacer coincidir cada uno con la membresía de grupo del nombre de usuario especificado.

OPCIONES

-d
Escribe información de depuración en stderr.
-h
Imprime la ayuda.
-K
Degrada las credenciales de Kerberos a NTLM.

CONFIGURACIÓN

external_acl_type wbinfo_check %LOGIN /ruta/a/ext_wbinfo_group_acl
acl allowed_group external wbinfo_check Grupo1 Grupo2
http_access allow allowed_group

Si el intérprete de Perl local se encuentra en una ubicación inusual, puede ser necesario añadirlo:

external_acl_type wbinfo_check %LOGIN /ruta/a/perl /ruta/a/ext_wbinfo_group_acl
