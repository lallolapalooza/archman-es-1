NOMBRE

ext_sql_session_acl - Ayudante de búsqueda de sesiones de base de datos SQL para Squid

SINOPSIS

ext_sql_session_acl [opciones]

DESCRIPCIÓN

Valida la autorización de acceso de una solicitud HTTP con una base de datos de sesiones.

Tomando un token de identidad para validar (tal como lo determina el formato external_acl_type), devuelve un nombre de usuario o etiqueta asociado con el token de identidad proporcionado.

Las formas comunes de identificadores son direcciones IP, direcciones EUI (MAC), contraseñas o tokens UUID.

Este programa utiliza el soporte de concurrencia de Squid.

OPCIONES

--dsn
DSN de la base de datos. Por defecto "DBI:mysql:database=squid"
--user
Usuario de la base de datos
--password
Contraseña de la base de datos
--table
Tabla de la base de datos. Por defecto "passwd".
--uidcol
Columna del Identificador de Sesión Único. Por defecto "id".
--usercol
Columna de resultado user= del ACL externo.
--tagcol
Columna de resultado tag= del ACL externo.
--cond
Condición, por defecto enabled=1. Especificar 1 o "" para ninguna condición
--persist
Mantener una conexión de base de datos persistente abierta entre consultas.
--debug
Escribir información de depuración en stderr.
