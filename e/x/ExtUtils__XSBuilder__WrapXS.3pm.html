Paquete: perl-extutils-xsbuilder

XSBuilder::WrapXS(3) Documentación aportada por el usuario de Perl XSBuilder::WrapXS(3)

NOMBRE

ExtUtils::XSBuilder::WrapXS - crear envoltorios XS de Perl para funciones C

DESCRIPCIÓN

Para más información, ver ExtUtils::XSBuilder

new_parsesource (o)

Devuelve una referencia a un array de objetos ParseSource nuevos para todos los archivos fuente que se deben utilizar para generar archivos XS

new_typemap (o)

Devuelve un nuevo objeto typemap

new_podtemplate (o)

Devuelve un nuevo objeto podtemplate

xs_includes (o)

Devuelve una lista de archivos de inclusión XS.

Por defecto: usa todos los archivos de inclusión que "ParseSource::find_includes" devuelve, pero elimina la información de ruta

xs_glue_dirs (o)

Devuelve una lista de directorios adicionales de pegamento XS donde buscar mapas.

xs_base_dir (o)

Devuelve un directorio que sirve como base para otros directorios.

Por defecto: '.'

xs_map_dir (o)

Devuelve el directorio donde buscar archivos map

Por defecto: "<xs_base_dir"/xsbuilder/maps>

xs_incsrc_dir (o)

Devuelve el directorio donde buscar archivos para incluir en el código fuente. Por ejemplo, "<xs_incsrc_dir"/Apache/DAV/Resource/Resource_pm> se incluirá en el módulo "Apache::DAV::Resource".

Por defecto: "<xs_base_dir"/xsbuilder>

xs_include_dir (o)

Devuelve un directorio donde buscar archivos de inclusión para pm y XS

Por defecto: "<xs_base_dir"/xsinclude>

xs_target_dir (o)

Devuelve el directorio donde escribir los archivos XS y de cabecera generados.

Por defecto: "<xs_base_dir"/xs>

makefilepl_text (o)

Devuelve el texto para Makefile.PL

h_filename_prefix (o)

Define un prefijo para los archivos de cabecera generados

Por defecto: 'xs_'

my_xs_prefix (o)

Define un prefijo utilizado para todas las funciones XS

Por defecto: 'xs_'

my_cnv_prefix (o)

Define un prefijo utilizado para todas las funciones/macros de conversión.

Por defecto: "my_xs_prefix"

needs_prefix (o, name)

Devuelve verdadero si el nombre pasado debe tener prefijo

pm_text (o, module, isa, code)

Devuelve el texto de un archivo ".pm", o undef si no se debe escribir ningún archivo ".pm".

Por defecto: Crea un archivo ".pm" que inicializa el código XS

mapline_elem (o, elem)

Se llama para cada elemento de estructura que se escribe en el archivo map por checkmaps. Permite al usuario cambiar el nombre del elemento, por ejemplo añadiendo un nombre de Perl diferente.

Por defecto: devuelve el elemento sin modificar

mapline_func (o)

Se llama para cada función que se escribe en el archivo map por checkmaps. Permite al usuario cambiar el nombre de la función, por ejemplo añadiendo un nombre de Perl diferente.

Por defecto: devuelve el elemento sin modificar
