ExtUtils::Helpers(3) Documentación de Perl aportada por el usuario ExtUtils::Helpers(3)

NOMBRE

ExtUtils::Helpers - Utilidades de portabilidad varias para constructores de módulos

VERSIÓN

versión 0.028

SINOPSIS

use ExtUtils::Helpers qw/make_executable split_like_shell/;
unshift @ARGV, split_like_shell($ENV{PROGRAM_OPTS});
write_script_to('Build');
make_executable('Build');

DESCRIPCIÓN

Este módulo proporciona varias funciones de ayuda portátiles para la construcción de módulos.

FUNCIONES

make_executable($filename)

Esto hace que un script de perl sea ejecutable.

split_like_shell($string)

Esta función divide una cadena de la misma manera que lo hace la plataforma local.

detildefy($path)

Esta función sustituye una tilde al principio de una ruta con el directorio de inicio del usuario de manera apropiada.

man1_pagename($filename, $ext = $Config{man1ext})

Devuelve el nombre del archivo de página de manual para un script.

man3_pagename($filename, $basedir = 'lib', $ext = $Config{man3ext})

Devuelve el nombre del archivo de página de manual para una biblioteca de Perl.

AGRADECIMIENTOS

Olivier Mengué y Christian Walde hicieron que "make_executable" funcionara en Windows.
