NOMBRE

Exporter::Shiny - atajo para Exporter::Tiny

SINOPSIS

use Exporter::Shiny qw( foo bar );

Es un atajo para:

use base "Exporter::Tiny";
push our(@EXPORT_OK), qw( foo bar );

Para compatibilidad con Sub::Exporter, también se soporta la siguiente sintaxis más larga:

use Exporter::Shiny -setup => {
   exports => [qw( foo bar )],
};

DESCRIPCIÓN

Este es un pequeño wrapper para simplificar el uso de Exporter::Tiny.

Hace lo siguiente:

  • Marca tu paquete como cargado en %INC;
  • Empuja cualquier nombre de función en la lista de importación a tu @EXPORT_OK; y
  • Empuja "Exporter::Tiny" a tu @ISA.

No configura %EXPORT_TAGS ni @EXPORT, pero nada te impide hacerlo tú mismo.

ERRORES

Por favor, informa de cualquier error en https://github.com/tobyink/p5-exporter-tiny/issues.

VER TAMBIÉN

https://exportertiny.github.io/.

Este módulo es solo un wrapper alrededor de Exporter::Tiny, así que échale un vistazo a Exporter::Tiny::Manual::QuickStart y Exporter::Tiny::Manual::Exporting para más información sobre las características disponibles.

Otros exportadores interesantes: Sub::Exporter, Exporter.
