NOMBRE

execsnoop.bt - Rastrea nuevos procesos a través de llamadas syscall exec(). Utiliza bpftrace/eBPF.

SINOPSIS

execsnoop.bt

DESCRIPCIÓN

Esto rastrea cuándo los procesos llaman a exec() (execve()). Es útil para identificar nuevos procesos creados a través de la secuencia habitual fork()->exec(). Tenga en cuenta que el valor de retorno no se rastrea actualmente, por lo que el exec() puede haber fallado.

Esta herramienta es útil para depurar scripts de shell, incluida la inicialización de aplicaciones. También es útil para identificar un tipo de problema de rendimiento: una avalancha de procesos de corta duración, que terminan rápidamente y no son fácilmente visibles en top(1).

Dado que esto utiliza BPF, solo el usuario root puede utilizar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Rastrear todos los nuevos procesos que llaman a execve():
# execsnoop.bt

CAMPOS

TIEMPO
Hora de la llamada a exec(), en milisegundos desde el inicio del programa.
PID
ID del Proceso
PPID
ID del Proceso Padre
ARGS
Nombre y argumentos del proceso (máximo 16 palabras).

SOBRECARGA

Esto rastrea el punto de rastreo execve() e imprime la salida para cada evento. Dado que la tasa de esto generalmente se espera que sea baja (< 100/s), la sobrecarga también se espera que sea insignificante. Si tiene una aplicación que está generando una alta tasa de nuevos procesos por alguna razón (proceso de compilación grande), esto podría causar una pequeña sobrecarga: pruebe y comprenda la sobrecarga antes de usarla.
