NOMBRE

exempi - herramienta de línea de comandos para manipular metadatos XMP

SINTAXIS

exempi { -h | [ -R ] [ -X ] [ -x [ -p ] ] [ { -w | -o <archivo> } ] [ { -g <nombre_prop> | -s <nombre_prop> -v <valor> } ] } <archivos>

OPCIONES

-h: mostrar esta ayuda
-R: no reconciliar
-x: volcar XML
-p: envolver el paquete XML. Solo para -x.
-X: el/los archivo(s) es XMP
-w: escribir in situ. Solo para -s. No compatible con -o.
-o <archivo>: archivo donde escribir la salida.
-n <ns> <prefijo>: establecer el prefijo para un namespace.
-g <nombre_prop>: recuperar el valor con nombre_prop.
-s <nombre_prop> -v <valor>: recuperar u obtener el valor.
<archivos> los archivos de donde leer.

SEGURIDAD

El código fuente no ha sido auditado en busca de vulnerabilidades de seguridad. La herramienta de línea de comandos no tiene una verificación de entrada robusta, lo que la hace más fácil.

Tenga cuidado de no ejecutar la herramienta como superusuario. Tenga cuidado si decide utilizarla en una aplicación en línea (web).

Se aceptan parches y sugerencias.
