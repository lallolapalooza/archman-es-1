NOMBRE

ext_kerberos_sid_group_acl - ayudante de ACL externo para Squid para verificar la pertenencia a grupos del dominio AD usando sid.

SINOPSIS

ext_kerberos_sid_group_acl [-d] [-h] -p Nombre del Principal -D Controlador de Dominio -b DN Base -G Grupo1:Grupo2

DESCRIPCIÓN

ext_kerberos_sid_group_acl es un script ejecutable instalado. Utiliza ldapsearch de Openldap para buscar el nombre de un sid de grupo AD.

Este ayudante debe usarse con el ayudante negotiate_kerberos_auth en un entorno Microsoft AD o Samba.

Lee desde la entrada estándar el nombre de usuario del dominio y una lista de sids de grupo e intenta hacer coincidir los SIDs de grupo con los sids de grupo AD.

OPCIONES

-d
Escribe información de depuración en stderr.
-h
Imprime la ayuda.
-p nombre del principal
Nombre del principal en el archivo keytab de squid para usar en la autenticación ldap a AD
-D controlador de dominio
Controlador de dominio a contactar para buscar el SID del grupo
-b DN base
DN base para la búsqueda ldap
-G nombre del grupo AD
Nombre del grupo AD a usar para la búsqueda de SID. Separado por dos puntos (:)

CONFIGURACIÓN

auth_param negotiate program /ruta/a/negotiate_wrapper_auth -d \
     --ntlm /ruta/a/ntlm_auth --helper-protocol=squid-2.5-ntlmssp --domain ejemplo.com \
     --kerberos /ruta/a/negotiate_kerberos_auth -d -s GSS_C_NO_NAME -k /ruta/a/squid.keytab -t none
external_acl_type sid_check %LOGIN %note{group} /ruta/a/kerberos_sid_group_acl -p principal -D dc1.ejemplo.com -b "DC=ejemplo,DC=com" -G Grupo1:Grupo2
acl squid_allow external sid_check
acl allowed_group external sid_check
http_access allow allowed_group

Si el intérprete de perl local se encuentra en una ubicación inusual, puede ser necesario añadirlo:

external_acl_type sid_check %LOGIN %note{group} /ruta/a/perl /ruta/a/kerberos_sid_group_acl -p principal -D dc1.ejemplo.com -b "DC=ejemplo,DC=com" -G Grupo1:Grupo2
