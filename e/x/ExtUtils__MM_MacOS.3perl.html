NOMBRE

ExtUtils::MM_MacOS - una vez produjo Makefiles para MacOS Classic

SINOPSIS

# MM_MacOS ya no contiene código. Esto es solo un marcador de posición.

DESCRIPCIÓN

Érase una vez, MakeMaker podía producir una aproximación de un Makefile correcto en MacOS Classic (MacPerl). Debido a la falta de mantenedores, esto se desfasó con el resto de MakeMaker y no había funcionado en años. Dado que hay pocas posibilidades de que se repare, MacOS Classic está desapareciendo y el código era sucio desde el principio, se ha eliminado el código para facilitar el mantenimiento.

Cualquier persona interesada en resucitar este archivo debe obtener la versión antigua del repositorio CVS de MakeMaker y contactar a makemaker@perl.org.
