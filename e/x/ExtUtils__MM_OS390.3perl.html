ExtUtils::MM_OS390(3perl) Guía de Referencia del Programador de Perl ExtUtils::MM_OS390(3perl)

NOMBRE

ExtUtils::MM_OS390 - Subclase específica de OS390 de ExtUtils::MM_Unix

SINOPSIS

No uses este módulo directamente.
Usa ExtUtils::MM y deja que elija.

DESCRIPCIÓN

Esta es una subclase de ExtUtils::MM_Unix que contiene funcionalidad para OS390.

A menos que se indique lo contrario, funciona igual que ExtUtils::MM_Unix.

Métodos sobrescritos

xs_make_dynamic_lib
Define las recetas para la sección "dynamic_lib".
