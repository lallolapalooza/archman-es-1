NOMBRE

ExtUtils::Packlist - gestionar archivos .packlist

SINOPSIS

use ExtUtils::Packlist;
my ($pl) = ExtUtils::Packlist->new('.packlist');
$pl->read('/un/antiguo/.packlist');
my @archivos_faltantes = $pl->validate();
$pl->write('/un/nuevo/.packlist');
$pl->{'/algún/nombre/de/archivo'}++;
   o
$pl->{'/otro/nombre/de/archivo'} = { type => 'file',
                                   from => '/algún/archivo' };

DESCRIPCIÓN

ExtUtils::Packlist proporciona una forma estándar de gestionar archivos .packlist. Se proporcionan funciones para leer y escribir archivos .packlist. El formato original de .packlist es una lista simple de rutas absolutas, una por línea. Además, este paquete soporta un formato extendido, donde además de un nombre de archivo, cada línea puede contener una lista de atributos en forma de pares clave=valor separados por espacios. Esto es utilizado por el script installperl para diferenciar entre archivos y enlaces, por ejemplo.

USO

La referencia de hash devuelta por la función new() puede utilizarse para examinar y modificar el contenido del .packlist. Se pueden añadir/eliminar elementos del .packlist modificando el hash. Si el valor asociado a una clave de hash es un escalar, la entrada escrita en el .packlist por cualquier write() posterior será un simple nombre de archivo. Si el valor es un hash, la entrada escrita será el nombre de archivo seguido de los pares clave=valor del hash. La lectura del .packlist recreará las entradas originales.

FUNCIONES

new()
Toma un parámetro opcional, el nombre de un .packlist. Si el archivo existe, se abrirá y se leerá el contenido del archivo. El método new() devuelve una referencia a un hash. Este hash contiene una entrada por cada línea del .packlist. En el caso de los .packlists de estilo antiguo, el valor asociado a cada clave es undef. En el caso de los .packlists de estilo nuevo, el valor asociado a cada clave es un hash que contiene los pares clave=valor que siguen al nombre de archivo en el .packlist.
read()
Toma un parámetro opcional, el nombre del .packlist a leer. Si no se especifica archivo, se leerá el .packlist especificado a new(). Si el .packlist no existe, se llamará a Carp::croak.
write()
Toma un parámetro opcional, el nombre del .packlist a escribir. Si no se especifica archivo, se sobrescribirá el .packlist especificado a new().
validate()
Comprueba que cada archivo listado en el .packlist realmente exista. Si se proporciona un argumento que se evalúa como verdadero, los archivos faltantes se eliminarán del hash interno. El valor de retorno es una lista de los archivos faltantes, que estará vacía si todos existen.
packlist_file()
Devuelve el nombre del archivo .packlist asociado.

EJEMPLO

Aquí está "modrm", una pequeña utilidad para eliminar limpiamente un módulo instalado.

#!/usr/local/bin/perl -w
use strict;
use IO::Dir;
use ExtUtils::Packlist;
use ExtUtils::Installed;
sub vaciar_directorio($) {
    my ($dir) = @_;
    my $dh = IO::Dir->new($dir) || return(0);
    my @count = $dh->read();
    $dh->close();
    return(@count == 2 ? 1 : 0);
}
# Encontrar todos los paquetes instalados
print("Buscando todos los módulos instalados...\n");
my $instalado = ExtUtils::Installed->new();
foreach my $modulo (grep(!/^Perl$/, $instalado->modules())) {
   my $version = $instalado->version($modulo) || "???";
   print("Módulo encontrado $modulo Versión $version\n");
   print("¿Desea eliminar $modulo? [n] ");
   my $r = <STDIN>; chomp($r);
   if ($r && $r =~ /^y/i) {
      # Eliminar todos los archivos
      foreach my $archivo (sort($instalado->files($modulo))) {
         print("rm $archivo\n");
         unlink($archivo);
      }
      my $pf = $instalado->packlist($modulo)->packlist_file();
      print("rm $pf\n");
      unlink($pf);
      foreach my $dir (sort($instalado->directory_tree($modulo))) {
         if (vaciar_directorio($dir)) {
            print("rmdir $dir\n");
            rmdir($dir);
         }
      }
   }
}
