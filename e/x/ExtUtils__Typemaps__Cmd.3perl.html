ExtUtils::Typemaps::Cmd(3perl) Guía del programador de Perl ExtUtils::Typemaps::Cmd(3perl)

NOMBRE

ExtUtils::Typemaps::Cmd - Comandos rápidos para manejar typemaps

SINOPSIS

Desde XS:

COMANDO_INCLUSION: $^X -MExtUtils::Typemaps::Cmd \
                 -e "print typemap_incrustable(q{Excommunicated})"

Carga "ExtUtils::Typemaps::Excommunicated", instancia un objeto y lo vuelca como un typemap incrustable para su uso directo en tu archivo XS.

DESCRIPCIÓN

Este es un módulo auxiliar para ExtUtils::Typemaps para comandos rápidos de una línea, específicamente para la inclusión de typemaps compartidos que residen en CPAN en un archivo XS (ver SINOPSIS).

Por esta razón, las siguientes funciones se exportan por defecto:

FUNCIONES EXPORTADAS

typemap_incrustable

Dada una lista de identificadores, "typemap_incrustable" intenta cargar typemaps de un archivo con los nombres dados, o de un módulo que sea una subclase de "ExtUtils::Typemaps".

Devuelve una representación en cadena de los typemaps combinados que se pueden incluir literalmente en XS. Ejemplo:

print typemap_incrustable(
  "Excommunicated", "ExtUtils::Typemaps::Basic", "./typemap"
);

Esto intentará cargar el módulo "ExtUtils::Typemaps::Excommunicated" y utilizarlo como una subclase de "ExtUtils::Typemaps". Si eso falla, intentará cargar "Excommunicated" como módulo; si eso falla, intentará leer un archivo llamado Excommunicated. Funcionará de manera similar para el segundo argumento, pero el tercero se cargará primero como archivo.

Después de cargar todos los archivos o módulos de typemap, los combinará en el orden especificado y volcará el resultado como un typemap incrustable.
