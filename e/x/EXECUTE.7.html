NOMBRE

EXECUTE - ejecuta una sentencia preparada

SINOPSIS

EXECUTE nombre [ ( parametro [, ...] ) ]

DESCRIPCIÓN

EXECUTE se utiliza para ejecutar una sentencia preparada previamente. Dado que las sentencias preparadas solo existen durante la duración de una sesión, la sentencia preparada debe haber sido creada por una sentencia PREPARE ejecutada anteriormente en la sesión actual.

Si la sentencia PREPARE que creó la sentencia especificó algunos parámetros, se debe pasar un conjunto compatible de parámetros a la sentencia EXECUTE, o se generará un error. Tenga en cuenta que (a diferencia de las funciones) las sentencias preparadas no se sobrecargan basándose en el tipo o número de sus parámetros; el nombre de una sentencia preparada debe ser único dentro de una sesión de base de datos.

Para más información sobre la creación y el uso de sentencias preparadas, consulte PREPARE(7).

PARÁMETROS

nombre

El nombre de la sentencia preparada a ejecutar.

parametro

El valor real de un parámetro para la sentencia preparada. Debe ser una expresión que produzca un valor compatible con el tipo de datos de este parámetro, según se determinó cuando se creó la sentencia preparada.

SALIDAS

La etiqueta de comando devuelta por EXECUTE es la de la sentencia preparada, y no la de EXECUTE.

EJEMPLOS

Los ejemplos se dan en Ejemplos en la documentación de PREPARE(7).

COMPATIBILIDAD

El estándar SQL incluye una sentencia EXECUTE, pero es solo para uso en SQL incrustado. Esta versión de la sentencia EXECUTE también utiliza una sintaxis algo diferente.

VER TAMBIÉN

DEALLOCATE(7), PREPARE(7)
