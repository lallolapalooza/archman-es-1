EXPAC(1) Manual de expac EXPAC(1)

NOMBRE

expac - utilidad de extracción de datos de alpm

SINOPSIS

Uso: expac [opciones] <formato> objetivos...

DESCRIPCIÓN

expac es una herramienta de extracción de datos para bases de datos alpm. Presenta una flexibilidad similar a printf y tiene como objetivo ser una herramienta simple para otras utilidades basadas en pacman que no enlazan con la biblioteca. Utiliza pacman.conf como archivo de configuración para localizar y cargar tus bases de datos locales y de sincronización.

Invocar expac consiste en proporcionar una cadena de formato, que generalmente se describe mediante uno o más tokens de formato (ver la sección FORMATO), las opciones relevantes y cero o más objetivos. La cadena de formato **debe** ser el primer argumento que no sea una opción. Los objetivos pueden ser un simple nombre de paquete, una cadena de consulta (en el caso de una búsqueda) o en sintaxis de repo/paquete cuando se proporciona la opción -sync.

OPCIONES

-Q, --query
Busca en la base de datos local los objetivos proporcionados. Este es el comportamiento predeterminado.
-S, --sync
Busca en las bases de datos de sincronización los objetivos proporcionados.
-s, --search
Busca paquetes que coincidan con las cadenas especificadas por los objetivos. Esta es una consulta booleana AND y se permiten expresiones regulares.
-g, --group
Devuelve paquetes que coincidan con los objetivos especificados como grupos de paquetes.
--config <archivo>
Lee de archivo para la inicialización de alpm en lugar de /etc/pacman.conf.
-H, --humansize <tamaño>
Formatea los tamaños de los paquetes en unidades SI según tamaño. Las opciones válidas son: 
B, K, M, G, T, P, E, Z, Y
-1, --readone
Deja de buscar después del primer resultado. Esto solo tiene efecto en las operaciones -S sin -s.
-d, --delim <cadena>
Separa cada paquete con la cadena especificada. El valor predeterminado es un carácter de nueva línea.
-l, --listdelim <cadena>
Separa cada elemento de la lista con la cadena especificada. Las listas son cualquier secuencia interpretada especificada con una letra mayúscula. El valor predeterminado son dos espacios.
-p, --file
Interpreta los objetivos como rutas a archivos locales.
-t, --timefmt <formato>
Muestra la hora descrita por el formato especificado. Esta cadena se pasa directamente a strftime(3). El formato predeterminado es %c.
-v, --verbose
Muestra más información. Se mostrarán los errores de `Paquete no encontrado` y los valores de campo vacíos se mostrarán como `None`.
-V, --version
Muestra la información de la versión y sale.
-h, --help
Muestra el mensaje de ayuda y sale.

FORMATO

El argumento de formato permite las siguientes secuencias interpretadas:

%a    arquitectura
%B    archivos de copia de seguridad
%b    fecha de compilación
%C    conflictos con (sin cadenas de versión)
%D    dependencias
%d    descripción
%E    dependencias (sin cadenas de versión)
%e    paquete base
%f    nombre de archivo (solo con -S)
%F    archivos (solo con -Q)
%g    firma PGP codificada en base64 (solo con -S)
%G    grupos
%H    conflictos con
%h    sha256sum
%i    tiene script de instalación (solo con -Q)
%k    tamaño de descarga (solo con -S)
%l    fecha de instalación (solo con -Q)
%L    licencias
%m    tamaño de instalación
%M    archivos de copia de seguridad modificados (solo con -Q)
%n    nombre del paquete
%N    requerido por
%O    dependencias opcionales
%o    dependencias opcionales (sin descripciones)
%p    nombre del empaquetador
%P    provee
%R    reemplaza (sin cadenas de versión)
%r    repo
%s    md5sum
%S    provee (sin cadenas de versión)
%T    reemplaza
%u    URL del proyecto
%V    método de validación del paquete
%v    versión
%w    motivo de la instalación (solo con -Q)
%!    número de resultado (contador auto-incrementado, empieza en 0)
%%    % literal

Tenga en cuenta que para cualquier token en minúscula aparte de %m y %k, se permite el soporte completo de printf, por ejemplo, %-20n. Esto no se aplica a ninguna salida basada en listas, fechas o números.

Se admiten secuencias de escape de barra invertida estándar, según printf(1).

EJEMPLOS

Emular la función de búsqueda de pacman:

$ expac -Ss '%r/%n %v\n    %d' <términos de búsqueda>

Listar los 10 paquetes instalados más antiguos (por fecha de compilación):

$ expac --timefmt=%s '%b\t%n' | sort -n | head -10
