ExtUtils::Command::MM(3perl) Guía de Referencia del Programador de Perl ExtUtils::Command::MM(3perl)

NOMBRE

ExtUtils::Command::MM - Comandos para que los MM los usen en Makefiles

SINOPSIS

perl "-MExtUtils::Command::MM" -e "función" "--" argumentos...

DESCRIPCIÓN

¡SOLO PARA USO INTERNO! La interfaz no es estable.

ExtUtils::Command::MM encapsula código que de otro modo tendría que hacerse con grandes líneas de comandos ("one-liners").

Cualquier $(FOO) usado en los ejemplos son variables de make, no de Perl.

test_harness
test_harness($verbose, @test_libs);

Ejecuta las pruebas en @ARGV a través de Test::Harness pasando el flag $verbose. Cualquier @test_libs se antepondrá al @INC de la prueba.

@test_libs se ejecutan en orden alfabético.

pod2man
pod2man( '--option=valor',
         $podfile1 => $manpage1,
         $podfile2 => $manpage2,
         ...
       );
# o argumentos en @ARGV

pod2man() es una función que realiza la mayoría de las tareas del programa pod2man. Sus argumentos son exactamente los mismos que pod2man a partir de la versión 5.8.0 con la adición de:

--perm_rw   permiso octal para establecer la página de manual resultante

Y la eliminación de:

--verbose/-v
--help/-h

Si no se dan argumentos a pod2man, leerá de @ARGV.

Si Pod::Man no está disponible, esta función advertirá y devolverá undef.

warn_if_old_packlist
perl "-MExtUtils::Command::MM" -e warn_if_old_packlist <algunarchivo>

Muestra una advertencia de que se encontró un archivo de lista de paquetes antiguo. Lee el nombre del archivo desde @ARGV.

perllocal_install
perl "-MExtUtils::Command::MM" -e perllocal_install
    <tipo> <nombre del módulo> <clave> <valor> ...
# solo VMS, pares clave|valor vienen por STDIN
perl "-MExtUtils::Command::MM" -e perllocal_install
    <tipo> <nombre del módulo> < <clave>|<valor> ...

Imprime un fragmento de POD adecuado para añadir a perllocal.pod. Los argumentos se leen de @ARGV.

<tipo> es el tipo de lo que estás instalando. Generalmente 'Module'.

<nombre del módulo> es simplemente el nombre de tu módulo. (Foo::Bar)

Los pares clave/valor son información adicional sobre el módulo. Los campos incluyen:

installed into      en qué directorio se instaló tu módulo
LINKTYPE            enlazado dinámico o estático
VERSION             número de versión del módulo
EXE_FILES           cualquier ejecutable instalado en una lista separada por espacios
uninstall
perl "-MExtUtils::Command::MM" -e uninstall <packlist>

Un envoltorio para ExtUtils::Install::uninstall(). Advierte que la desinstalación está obsoleta y no realiza la desinstalación realmente.

test_s
perl "-MExtUtils::Command::MM" -e test_s <archivo>

Comprueba si un archivo existe y no está vacío (tamaño > 0). *Sale* con 0 si lo está, 1 si no lo está.

cp_nonempty
perl "-MExtUtils::Command::MM" -e cp_nonempty <archivo_origen> <archivo_destino> <permiso>

Comprueba si el archivo de origen existe y no está vacío (tamaño > 0). Si no está vacío, lo copia al destino dado con el permiso dado.
