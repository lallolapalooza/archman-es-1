DESCRIPCIÓ

N

ext_edirectory_userip_acl es un binario

instalado.

Este programa ha sido escrito para resolver los problemas asociados con la ejecución del script Perl squid_ip_lookup.pl como un asistente externo de

Squid.

Las limitaciones del script Perl involucraban la util

ización de memoria/CPU, la velocidad, la falta de
soporte para eDirectory 8.8 y el soporte para IPv6.

CONFIGURACIÓ

N
external_acl_type IPUser %SRC /usr/sbin/ext_edirectory_userip_acl
acl edirectory_users_allowed external IPUser cn=Internet_Allowed,ou=ORG,o=BASE acl edirectory_users_denied external IPUser cn=Internet_Denied,ou=ORG,o=BASE
http_access deny edirectory_users_denied http_access allow edirectory_users_allowed http_access deny
all

En este ejemplo, los grupos Internet_Allowed y Internet_Denied son Grupos que los usuarios pueden usar para controlar el acceso a Internet, y que también pueden combinarse con otras ACL. El uso de los grupos

es opcional, a menos que se haya pasado la opción '-G'. Tenga en cuenta que n
ecesita especificar el objeto LDAP completo para esto, como se muestra arriba.

PROBLEMAS

CONOCIDOS

El soporte para IPv6 aún no ha sido probado en un entorno IPv6 real, pero el código está en su lugar para leer los campos networkAddress de IPv6, por favor intente esto primero en un entorno de PRUEBAS. Por favor, contacte al autor con respecto al desarrollo del soporte para

IPv6.

Existe un problema conocido con el Cliente de Novell para Windows, que se solventa en su mayoría usando la versión 4.91 SP3+, con la función 'Auto-Reconnect' que no vuelve a poblar el campo networkAddress en

eDirectory.

También he experimentado un problema relacionado con el uso de NetWare 6.5 (SP6 y anteriores?) y la licencia de conexiones. Parece que siempre que un servidor se queda bajo de licencias de conexión, a veces no puebla los campos networkAddress

correctamente.

La mayoría de los problemas de autenticación de proxy se pueden resolver haciendo que los usuarios se reinicien si su networkAddress no es correcto, o usando basic_ldap_auth como alternativa. Revise ConsoleOne, etc. para v

erificar sus campos networkAd
dress para solucionar problemas.
