Excepciones incontrolables

Internamente, el "caught" método llamará a "isa" en el objeto de excepción. Podrías hacer que una excepción fuera "incontrolable" sobrescribiendo "isa" en esa clase de esta manera:

package Exception::Uncatchable;
sub isa { shift->rethrow }

Por supuesto, esto solo funciona si siempre llamas a "Exception::Class->caught" después de un "eval".

RECOMENDACIÓN DE USO

Si estás creando un sistema complejo que lanza muchos tipos diferentes de excepciones, considera poner todas las declaraciones de excepciones en un solo lugar. Para una aplicación llamada Foo podrías crear un "Foo::Exceptions" módulo y usarlo en todo tu código. Este módulo podría contener solo el código para hacer que "Exception::Class" realice su creación automática de clases. Hacer esto te permite ver más fácilmente qué excepciones tienes, y facilita el seguimiento de las mismas.

Esto podría verse algo así:

package Foo::Bar::Exceptions;
use Exception::Class (
    Foo::Bar::Exception::Senses =>
        { description => 'sense-related exception' },
    Foo::Bar::Exception::Smell => {
        isa         => 'Foo::Bar::Exception::Senses',
        fields      => 'odor',
        description => 'stinky!'
    },
    Foo::Bar::Exception::Taste => {
        isa         => 'Foo::Bar::Exception::Senses',
        fields      => [ 'taste', 'bitterness' ],
        description => 'like, gag me with a spoon!'
    },
    ...
);

Es posible que desees crear un módulo real para subclasear Exception::Class::Base también, particularmente si quieres que tus excepciones tengan más métodos.

Subclaseando Exception::Class::Base

Como parte de tu uso de "Exception::Class", es posible que desees crear tu propia clase base de excepción que subclasee Exception::Class::Base. Deberías sentirte libre de subclasear cualquiera de los métodos documentados arriba. Por ejemplo, es posible que desees subclasear "new" para agregar información adicional a tus objetos de excepción.

Exception::Class FUNCIONES

El "Exception::Class" método ofrece una función, "Classes", que no se exporta. Este método devuelve una lista de las clases que han sido creadas al llamar al "Exception::Class" "import" método. Ten en cuenta que esto es todo las subclases que han sido creadas, por lo que puede incluir subclases creadas por cosas como módulos de CPAN, etc. Ten en cuenta también que si simplemente defines una subclase a través del método normal de Perl de establecer @ISA o "use base", entonces tu subclase no será incluida.
