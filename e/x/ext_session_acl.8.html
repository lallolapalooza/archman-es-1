NOMBRE

ext_session_acl - Ayudante de ACL de sesión externa de Squid.

Versión 1.2

SINOPSIS

ext_session_acl [-t tiempo_espera ] [-b base_de_datos ] [-a]

DESCRIPCIÓN

ext_session_acl mantiene un concepto de sesiones monitorizando las peticiones y agotando las sesiones. El tiempo de espera se basa bien en el uso inactivo ( -t ) o en un período fijo de tiempo ( -T ). El primero es adecuado para mostrar términos y condiciones a un usuario; el segundo es adecuado para la visualización de anuncios u otras notificaciones (tanto como página de bienvenida - ver ejemplos de configuración en la wiki en línea). El ayudante de sesión también puede ser utilizado para forzar a los usuarios a re-autenticarse si %LOGIN y -a se usan ambos.

OPCIONES

-t tiempo_espera
Tiempo de espera inactivo para cualquier sesión. El valor predeterminado si no se especifica es 3600 segundos.
-T tiempo_espera
Tiempo de espera fijo para cualquier sesión. Esto finalizará la sesión después del tiempo de espera independientemente de la actividad de un usuario. Si se usa con el modo active, esto terminará la sesión del usuario después de tiempo_espera, después de lo cual se requerirá otro LOGIN. LOGOUT reiniciará la sesión y el tiempo de espera.
-b ruta
Ruta a la base de datos persistente. Si se especifica un archivo, ese archivo único se utiliza como base de datos. Si se especifica una ruta, se crea un entorno de base de datos Berkeley DB dentro del directorio. La ventaja de esto último es un mejor soporte de base de datos entre múltiples instancias del ayudante de sesión. Usar múltiples instancias del ayudante de sesión con un único archivo de base de datos causará problemas de sincronización entre procesos. Si esta opción no se especifica, los detalles de la sesión se mantendrán solo en memoria y todas las sesiones se reiniciarán cada vez que Squid reinicie sus ayudantes (reinicio de Squid o rotación de logs).
-a
Modo activo. En este modo, las sesiones se inician evaluando una acl con el argumento LOGIN, o se terminan con el argumento LOGOUT. Sin esta bandera, el ayudante inicia automáticamente la sesión después de la primera petición.

CONFIGURACIÓN

El ayudante ext_session_acl es un ayudante concurrente; por lo tanto, la opción concurrency= debe especificarse en la configuración.

Ejemplo de configuración de sesión pasiva usando el modo automático predeterminado

external_acl_type session ttl=300 negative_ttl=0 children=1 concurrency=200 %LOGIN /usr/local/squid/libexec/ext_session_acl
acl session external session
http_access deny !session
deny_info http://tu.servidor.ejemplo.com/bannerpage?url=%s session

Luego, configure http://tu.servidor.ejemplo.com/bannerpage para mostrar una página de inicio de sesión y luego redirija al usuario a la URL solicitada dada en el parámetro de consulta url.
