NOMBRE

extcheck - Detecta conflictos de versión entre un archivo Java Archive (JAR) de destino y los archivos JAR de extensión instalados actualmente.

SINOPSIS

extcheck [opciones] archivo_destino.jar
opciones
Las opciones de la línea de comandos. Véase Opciones.
archivo_destino.jar
El archivo JAR de destino contra el cual se comparan los archivos JAR de extensión instalados actualmente para detectar conflictos de versión.

DESCRIPCIÓN

El comando extcheck comprueba un archivo JAR especificado en busca de conflictos de título y versión con cualquier extensión instalada en el SDK de Java SE. Antes de instalar una extensión, puedes usar esta utilidad para ver si ya está instalada la misma versión o una más reciente de la extensión.

El comando extcheck compara las cabeceras Specification-title y Specification-version en el manifiesto del archivo archivo_destino.jar contra las cabeceras correspondientes en todos los archivos JAR instalados actualmente en el directorio de extensiones. Por defecto, el directorio de extensiones es jre/lib/ext en Oracle Solaris y \jre\lib\ext en Windows. El comando extcheck compara los números de versión de la misma manera que el método java.lang.Package.isCompatibleWith.

Si no se detecta ningún conflicto, el código de retorno es 0.

Si el manifiesto de cualquier archivo JAR en el directorio de extensiones tiene el mismo Specification-title y el mismo o un número mayor de Specification-version, se devuelve un código de error distinto de cero. También se devuelve un código de error distinto de cero cuando archivo_destino.jar no tiene los atributos Specification-title o Specification-version en su archivo de manifiesto.

OPCIONES

-verbose

Enumera los archivos JAR en el directorio de extensiones a medida que se comprueban. Además, también se informan los atributos del manifiesto del archivo JAR de destino y de cualquier archivo JAR conflictivo.
-Jopción

Pasa opción a la Máquina Virtual Java (JVM), donde opción es una de las opciones descritas en la página de referencia del lanzador de Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB. Véase java(1).
