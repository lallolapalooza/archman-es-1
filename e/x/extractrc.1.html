NOMBRE

extractrc - Extrae cadenas de mensajes de archivos UI y GUI-RC

SINOPSIS

extractrc [nombre_archivo]

DESCRIPCIÓN

extractrc encuentra todas las etiquetas de texto y otras cadenas de mensajes en los archivos dados y escribe las llamadas i18n() correspondientes en la salida estándar para que xgettext pueda analizarlas.

Entiende tanto los archivos UI de (Qt(TM)/KDE) designer como los archivos XML GUI-RC.

Esta utilidad forma parte del Kit de Desarrollo de Software de KDE.
