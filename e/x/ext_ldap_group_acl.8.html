NOMBRE

ext_ldap_group_acl - Ayudante externo de ACL de grupo LDAP de Squid

Versión 2.18

SINOPSIS

ext_ldap_group_acl -b base-DN -f filtro [ opciones ] [ servidor [ ':' puerto ] | URI ] ...

DESCRIPCIÓN

ext_ldap_group_acl permite a Squid conectarse a un directorio LDAP para autorizar usuarios a través de grupos LDAP. Las opciones LDAP se especifican como parámetros en la línea de comandos, mientras que el/los nombre/s de usuario y el/los grupo/s a verificar contra el directorio LDAP se especifican en líneas posteriores de entrada al ayudante, un par de nombre de usuario/grupo por línea separado por un espacio.

Como se espera de la construcción external_acl_type de Squid, después de especificar un nombre de usuario y un grupo seguido de una nueva línea, este ayudante producirá OK o ERR en la línea siguiente para indicar si el usuario pertenece al grupo especificado.

El programa opera buscando con un filtro de búsqueda basado en el nombre de usuario de los usuarios y el grupo solicitado, y si se encuentra una coincidencia, se determina que el usuario pertenece al grupo.

OPCIONES

-a nunca|siempre|buscar|encontrar
Cuándo desreferenciar alias. Por defecto es 'nunca'
nunca desreferenciar alias (por defecto), siempre desreferenciar alias, solo durante una búsqueda o solo para encontrar el objeto base
-b basedn
REQUERIDO. Especifica el DN base bajo el cual se encuentran los grupos.
-B basedn
Especifica el DN base bajo el cual se encuentran los usuarios (si es diferente)
-c tiempo_espera_conexion
Especifica el tiempo de espera utilizado al conectarse a servidores LDAP (requiere bibliotecas API de Netscape LDAP)
-d
Modo de depuración donde cada paso dado se informará en detalle. Útil para comprender qué sale mal si el resultado no es el esperado.
-D binddn -w contraseña
El DN y la contraseña para vincularse al realizar búsquedas. Requerido si el directorio LDAP no permite búsquedas anónimas.
Dado que la contraseña debe imprimirse en texto plano en su configuración de Squid y se enviará en la línea de comandos al ayudante, se recomienda encarecidamente utilizar una cuenta con privilegios mínimos asociados. Esto para limitar el daño en caso de que alguien obtenga una copia de su archivo de configuración de Squid o extraiga la contraseña utilizada de una lista de procesos.
-D binddn -W archivo_secreto
El DN y el nombre de un archivo que contiene la contraseña para vincularse al realizar búsquedas.
Versión menos insegura del par de parámetros anterior con dos ventajas: La contraseña no aparece en la lista de procesos, y la contraseña no se ve comprometida si alguien obtiene el archivo de configuración de squid sin obtener el archivo secreto.
-E ruta_cert
Habilitar LDAP sobre SSL (requiere bibliotecas API de Netscape LDAP)
-f filtro
Filtro de búsqueda LDAP utilizado para buscar en el directorio LDAP cualquier membresía de grupo coincidente. En el filtro %u será reemplazado por el nombre de usuario (o DN si se usan las opciones -F o -u) y %g por el nombre del grupo solicitado.
-F filtro
Filtro de búsqueda LDAP utilizado para buscar en el directorio LDAP cualquier usuario coincidente. En el filtro %s será reemplazado por el nombre de usuario. Si % se incluirá literalmente en el filtro, use %%
-g
Especifica que el primer argumento de consulta enviado al ayudante por Squid es una extensión del basedn y se agregará temporalmente delante del basedn global para esta consulta.
-h servidor_ldap
Especificar el servidor LDAP al que conectarse
-H uri_ldap
Especificar el servidor LDAP al que conectarse mediante una URI LDAP (requiere bibliotecas de OpenLDAP)
-K
Eliminar el componente del reino Kerberos de los nombres de usuario (separado por @)
-p puerto_ldap
Especificar un puerto TCP alternativo donde el servidor LDAP está escuchando si es diferente del puerto LDAP predeterminado 389.
-P
Utilizar una conexión LDAP persistente. Normalmente, la conexión LDAP solo está abierta mientras se verifica la membresía del grupo de un usuario para preservar recursos en el servidor LDAP. Esta opción hace que la conexión LDAP permanezca abierta, permitiendo que se reutilice para validaciones de usuarios posteriores. Recomendado para instalaciones más grandes.
-R
No seguir referencias
-s base|uno|sub
ámbito de búsqueda. Por defecto es sub
solo objeto base,
un nivel por debajo del objeto base o
subárbol debajo del objeto base
-S
Eliminar el componente del nombre de dominio NT de los nombres de usuario (separado por / o \)
-t tiempo_espera_busqueda
Especificar límite de tiempo en las operaciones de búsqueda LDAP
-u attr
Atributo LDAP utilizado para construir el DN del usuario a partir del nombre de usuario y el base dn sin necesidad de buscar al usuario. Se admite un máximo de 16 ocurrencias de %s.
-v 2|3
Versión del protocolo LDAP. Por defecto es 3 si no se especifica.
-Z
Usar cifrado TLS

CONFIGURACIÓN

Este ayudante está destinado a ser utilizado como un ayudante external_acl_type en squid.conf.

external_acl_type ldap_group %LOGIN /ruta/a/ext_ldap_group_acl ...
acl group1 external ldap_group Grupo1
acl group2 external ldap_group Grupo2

NOTA: Al construir filtros de búsqueda, se recomienda probar primero el filtro usando ldapsearch para verificar que el filtro coincida con lo que espera antes de intentar usar ext_ldap_group_acl
