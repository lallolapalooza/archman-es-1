DESCRIPCIÓ

N

"ExtUtils::CppGuess" intenta adivinar el compilador de C++ del sistema que es compatible con el compilador de C con el que se compiló su

perl.

Puede generar las opciones necesarias para el constructor de Module::Build o para la función "WriteMakefile" de E

xtUtils::
MakeMaker.

ENTORN

O

A partir de la versión 0.24, la variable de entorno "CXX" define el valor obvio y se usará en lugar de cualquier detecció

n. Los argumentos proporcionados a "n
ew" seguirán teniendo prioridad.

cpp_flavor_def

s

Devuelve el texto para un encabezado que "#define"s "__INLINE_CPP_STANDARD_HEADERS" y "__INLINE_CPP_NAMESPACE_STD" si los encabezados estándar y el espacio de nombres están disponibles. Esto se determina intentando compilar C++ con "#define <iostream>" - si tiene éxito, los símbolos se definirán, de lo contrario, se
