ExtUtils__LibBuilder(3pm)

Paquete: perl-extutils-libbuilder

ExtUtils::LibBuilder(3pm) Documentación Perl aportada por el usuario ExtUtils::LibBuilder(3pm)

NOMBRE

ExtUtils::LibBuilder - Una herramienta para construir bibliotecas C.

SINOPSIS

use ExtUtils::LibBuilder;
my $libbuilder = ExtUtils::LibBuilder->new( %options );

MÉTODOS

Soporta todos los métodos de ExtUtils::CBuilder. Los siguientes tres métodos fueron adaptados para ser usados en bibliotecas C independientes.

new

Este método crea un nuevo objeto ExtUtils::LibBuilder. Aunque soporta todos los métodos de "ExtUtils::CBuilder", algunos pueden funcionar de manera ligeramente diferente (en particular, los dos siguientes).

Puede proporcionar al constructor cualquier opción reconocida por el constructor de "ExtUtils::CBuilder". Ninguna de ellas será utilizada por "LibBuilder".

enlazar

$libbuilder -> enlazar( objetos     => [ "foo.o", "bar.o" ],
                     nombre_modulo => "foobar",
                     archivo_lib   => "libfoobar$libbuilder->{libext}");

Las opciones para el método "enlazar" son las mismas que las de su contraparte en "CBuilder". Tenga en cuenta que el resultado es una biblioteca C independiente y no un paquete para ser cargado por Perl.

Además, tenga en cuenta que puede usar la clave "libext" para recuperar del objeto la extensión común de biblioteca en el sistema en ejecución (incluido el punto).

enlazar_ejecutable

$libbuilder->enlazar_ejecutable( objetos => ["main.o"],
                              banderas_enlazador_extra => "-L. -lfoobar",
                              archivo_exe => "foobarcmd$libbuilder->{exeext}");

El método "enlazar_ejecutable" necesita, como opciones de "banderas_enlazador_extra", el nombre de la biblioteca y la ruta de búsqueda. Las versiones futuras podrían incluir un mejor manejo de los archivos de biblioteca.

Además, tenga en cuenta que puede usar la clave "exeext" para recuperar del objeto la extensión común de ejecutable en el sistema en ejecución (incluido el punto).
