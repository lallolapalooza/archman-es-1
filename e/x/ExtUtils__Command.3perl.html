ExtUtils::Command(3perl) Guía de referencia del programador de Perl ExtUtils::Command(3perl)

NOMBRE

ExtUtils::Command - utilidades para reemplazar comandos comunes de UNIX en Makefiles, etc.

SINOPSIS

perl -MExtUtils::Command -e cat archivos... > destino
perl -MExtUtils::Command -e mv origen... destino
perl -MExtUtils::Command -e cp origen... destino
perl -MExtUtils::Command -e touch archivos...
perl -MExtUtils::Command -e rm_f archivos...
perl -MExtUtils::Command -e rm_rf directorios...
perl -MExtUtils::Command -e mkpath directorios...
perl -MExtUtils::Command -e eqtime origen destino
perl -MExtUtils::Command -e test_f archivo
perl -MExtUtils::Command -e test_d directorio
perl -MExtUtils::Command -e chmod modo archivos...
...

DESCRIPCIÓN

El módulo se utiliza para reemplazar comandos comunes de UNIX. En todos los casos, las funciones trabajan a partir de @ARGV en lugar de tomar argumentos. Esto facilita su manejo en los Makefiles. Llámales así:

perl -MExtUtils::Command -e comando_alguno algunos archivos para trabajar

y *NO* así:

perl -MExtUtils::Command -e 'comando_alguno qw(algunos archivos para trabajar)'

Para eso usa Shell::Command.

Los nombres de archivo con * y ? serán expandidos por globbing.

FUNCIONES

cat
cat archivo ...

Concatena todos los archivos mencionados en la línea de comandos a STDOUT.

eqtime
eqtime origen destino

Establece la hora de modificación del destino a la del origen.

rm_rf
rm_rf archivos o directorios ...

Elimina archivos y directorios, recursivamente (incluso si son de solo lectura).

rm_f
rm_f archivo ...

Elimina archivos (incluso si son de solo lectura).

touch
touch archivo ...

Hace que los archivos existan, con la marca de tiempo actual.

mv
mv archivo_origen archivo_destino
mv archivo_origen archivo_origen directorio_destino

Mueve el origen al destino. Se permiten múltiples orígenes si el destino es un directorio existente.

Devuelve verdadero si todos los movimientos tuvieron éxito, falso en caso contrario.

cp
cp archivo_origen archivo_destino
cp archivo_origen archivo_origen directorio_destino

Copia los orígenes al destino. Se permiten múltiples orígenes si el destino es un directorio existente.

Devuelve verdadero si todas las copias tuvieron éxito, falso en caso contrario.

chmod
chmod modo archivos ...

Establece el modo de permisos tipo UNIX en todos los archivos. Por ejemplo, 0666.

mkpath
mkpath directorio ...

Crea directorios, incluyendo cualquier directorio padre.

test_f
test_f archivo

Prueba si un archivo existe. *Sale* con 0 si existe, 1 si no existe (es decir, la idea del shell de verdadero y falso).

test_d
test_d directorio

Prueba si un directorio existe. *Sale* con 0 si existe, 1 si no existe (es decir, la idea del shell de verdadero y falso).

dos2unix
dos2unix archivos o dirs ...

Convierte saltos de línea de DOS y OS/2 a estilo Unix de forma recursiva.

VER TAMBIÉN

Shell::Command, que son estas mismas funciones pero toman argumentos normalmente.
