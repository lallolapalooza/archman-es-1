ExtUtils::MM_Win32(3perl) Guía del programador de Perl ExtUtils::MM_Win32(3perl)

NOMBRE

ExtUtils::MM_Win32 - métodos para anular el comportamiento UN*X en ExtUtils::MakeMaker

SINOPSIS

use ExtUtils::MM_Win32; # Hecho internamente por ExtUtils::MakeMaker si es necesario

DESCRIPCIÓN

Ver ExtUtils::MM_Unix para obtener documentación sobre los métodos proporcionados allí. Este paquete anula la implementación de estos métodos, no la semántica.

Métodos anulados

dlsyms
xs_dlsyms_ext
En Win32, es ".def".
replace_manpage_separator
Cambia el separador de ruta con .
maybe_command
Dado que Windows no tiene nada tan simple como un bit ejecutable, verificamos la extensión del archivo.

La variable de entorno PATHEXT se usará para obtener una lista de extensiones que puedan indicar un comando, de lo contrario, se usarán por defecto .com, .exe, .bat y .cmd.

init_DIRFILESEP
Usando \ para Windows, excepto para "gmake" donde es /.
init_tools
Anula algunos de los comandos portátiles más lentos con otros específicos de Windows.
init_others
Anula las herramientas de enlace y compilación por defecto.

El valor predeterminado de LDLOADLIBS se cambia a $Config{libs}.

Se realizan ajustes para las peculiaridades de Borland que necesitan que -L venga primero.

init_platform
Añade MM_Win32_VERSION.
platform_constants
specify_shell
Establece SHELL a $ENV{COMSPEC} solo si make es de tipo 'gmake'.
constants
Añade MAXLINELENGTH para dmake antes de que se generen todas las constantes.
dep_constants
Crea dependencias que funcionan para nmake.
special_targets
Añade el objetivo .USESHELL para dmake.
static_lib_pure_cmd
Define cómo ejecutar la utilidad de archivo
dynamic_lib
Los métodos se anulan aquí: no dynamic_lib en sí, sino las utilidades que realizan el trabajo específico del sistema operativo.
extra_clean_files
Limpia archivos dll.{base,exp} adicionales que podrían ser generados por gcc. De lo contrario, elimina todos los archivos *.pdb.
init_linker
perl_script
Busca el programa perl bajo varias extensiones comunes de perl.
quote_dep
xs_obj_opt
Anula para corregir las opciones -o para MSVC.
pasthru
Todo lo que enviamos es -nologo a nmake para evitar que imprima su maldito banner.
arch_check (anulación)
Normaliza todos los argumentos para la consistencia de la comparación.
oneliner
Estos se basan en lo que hace command.com en Win98. Puede que sean incorrectos para otros shells de Windows, no lo sé.
cd
dmake puede manejar cambios de directorio al estilo Unix, pero nmake (al menos 1.5) no puede. Quiere: 
cd dir1\dir2
command
another_command
cd ..\..
max_exec_len
nmake 1.50 limita la longitud del comando a 2048 caracteres.
os_flavor
Windows es Win32.
dbgoutflag
Devuelve una bandera de CC que le indica a la CC que emita un archivo de símbolos de depuración separado al compilar un archivo objeto.
cflags
Define el símbolo PERLDLL si estamos configurados para la compilación estática, ya que todo el código destinado a perl5xx.dll debe compilarse con el símbolo PERLDLL definido.
make_type
Devuelve una cadena adecuada que describe el tipo de makefile que se está escribiendo.
