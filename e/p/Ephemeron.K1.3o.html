Módulo K1
: sig final

Efímeros con una clave.

tipo ('k, 'd) t

un efímero con una clave

val make : 'k -> 'd -> ('k, 'd) t

Ephemeron.K1.make k d crea un efímero con clave k y datos d.

val query : ('k, 'd) t -> 'k -> 'd option

Ephemeron.K1.query eph key devuelve Some x (donde x son los datos del efímero) si key es físicamente igual a la clave de eph, y None si eph está vacío o key no es igual a la clave de eph.
