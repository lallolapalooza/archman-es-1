Nombre

epiphany - una vista simple, limpia y hermosa de la web

SINOPSIS

epiphany [OPCIÓN...] [URL...]

DESCRIPCIÓN

epiphany es el nombre en clave de GNOME Web, el navegador web diseñado para el escritorio GNOME. Ofrece integración de primera clase con GNOME, utilizando WebKitGTK para la renderización web.

OPCIONES

--new-window

Abrir una nueva ventana del navegador en lugar de una nueva pestaña

-l, --load-session=ARCHIVO

Cargar el archivo de estado de sesión dado

-i, --incognito-mode

Iniciar una instancia con datos de usuario de solo lectura, para navegar sin almacenar historial en su computadora

-p, --private-instance

Iniciar una instancia temporal sin datos de usuario, para pruebas

-a, --application-mode=NOMBRE_BASE

Iniciar una instancia privada en modo aplicación web (requiere pasar el nombre base del archivo de escritorio o --profile)

--automation-mode

Iniciar una instancia privada para control de WebDriver

--profile=ARCHIVO

Iniciar usando un directorio de perfil personalizado para datos de usuario

--search=TÉRMINO

Iniciar búsqueda con el término de búsqueda dado

-?, --help

Mostrar opciones de ayuda

--version

Mostrar versión

Epiphany tiene un sistema de ayuda completo. Ejecute el navegador y seleccione Ayuda en el menú.
