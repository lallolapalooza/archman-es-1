DESCRIPCIÓ

N

El programa ircII/EPIC es un agente de usuario orientado a caracteres ('cliente') basado en unix para Internet Relay Chat. Es un cliente ircII com

pletamente funcional con muchas extensiones útiles. Esta versión funcio
na con todas las clases de servidores irc modernos a principios de 1999.

OPCIONE

S
-
a
Añade la lista de descripciones de servidores a la lista de servidores predeterminada. El comportamiento predeterminado es que la lista de descripciones de servidores reemplace a la lista de servidores
predeterminada.
-
b
Opera en el llamado “modo bot”. Esto implica la opción [-d]. EPIC hará fork(2) inmediatamente y el proceso padre saldrá, devolviéndote a tu shell. A algunos administradores de sistemas no les gusta que sus usuarios ejecuten bots, y han deshabilitado esta opción. Aunque tu administrador no la haya deshabilitado, no debes asumir que esto te da permiso automático para ejecutar un bot. Si ejecutas un bot sin permiso, tu administrador puede enfadarse mucho contigo, y posiblemente revocar tu cuenta. Además, la mayoría de los operadores de irc en redes públicas de irc tienen muy poca tolerancia para las personas que ejecutan bots. Así que solo una palabra de precaución, asegúrate de que tu administrador de sistemas y tu administrador de irc te hayan dado permiso antes de ejecutar un
bot.
-
B
Fuerza que el archivo de inicio se cargue inmediatamente en lugar de esperar hasta que se establezca una conexión con un
servidor.
-c can
al
Únete al canal especificado la primera vez que te conectes con éxito a un
servidor.
-
d
Opera en “modo tonto”. El cliente no mostrará una pantalla completa, y leerá de la entrada estándar y escribirá en la salida estándar. Esto es útil si la salida normalmente se ve horrible (porque estás usando una configuración incorrecta de TERM, o tu descripción de terminal está espectacularmente rota), o simplemente no quieres usar la interfaz bonita. Esta opción se activará automáticamente si tu configuración actual de TERM no es capaz de una pantalla
completa.
-
f
Fuerza el uso del control de flujo por hardware. Con esta opción, las teclas control-S y control-Q probablemente no estarán disponibles para ser vinculadas a algo
más.
-
F
Deshabilita el uso del control de flujo por hardware. Con esta opción, las teclas control-S y control-Q están disponibles para ser vinculadas a algo más. Sin embargo, no tendrás control de flujo por
hardware.
-
h
Muestra un mensaje de ayuda moderadamente conciso y sale
inmediatamente.
-H nombre-de-
host
Usa la dirección IP del nombre de host especificado como tu dirección IP predeterminada. Esto se puede usar si tienes múltiples direcciones IP en la misma máquina y quieres usar una dirección diferente a la dirección predeterminada. Podrías necesitar usar esta opción cuando gethostname(3) no devuelve un nombre de host (en algunos entornos de NIS mal configurados). El uso de múltiples direcciones IP en una sola máquina se conoce comúnmente como "alojamiento virtual", y cada dirección IP es un "host virtual". Por favor, entiende que un cliente de irc puede no decirle al servidor de irc cuál debería ser tu nombre de host: solo el servidor determina eso. Los servidores típicamente usan el nombre de host canónico para una dirección IP como tu nombre de host. Debido a esto, esta opción no te permitirá usar un CNAME (nombre de host secundario para una dirección IP), porque el servidor usará el nombre de host canónico en su lugar. Esta opción anula la variable de entorno IRCHOST
.
-l nombre-de-archivo,
[nombre-de-archivo]
Usa el/los nombre(s) de archivo especificado(s) como el archivo de inicio. El archivo de inicio se carga la primera vez que te conectes con éxito a un servidor, a menos que especifiques la opción [-B]. Esto anula la variable de entorno IRCRC. Si esta opción no se especifica, y la variable de entorno IRCRC no está establecida, entonces ~/.ircrc es el archivo de inicio
predeterminado.
-n apod
o
Usa el apodo especificado como el apodo predeterminado siempre que te conectes a un servidor de irc. Esta opción anula la variable de entorno IRCNICK. Esta opción puede ser anulada si especificas el argumento apodo en la línea de comandos (ver más abajo)
.
-
o
Fuerza el uso de caracteres termios IEXTEN. Los sistemas POSIX están permitidos para reservar caracteres de control adicionales para realizar acciones especiales cuando IEXTEN está activado. En 4.4BSD, las teclas control-V y control-O son usadas por IEXTEN y por lo tanto no pueden ser usadas en enlaces de teclas dentro de EPIC ya que el terminal nunca las envía a
EPIC.
-
O
Deshabilita el uso de caracteres termios IEXTEN. Esto hace que todas las teclas reservadas por la opción termios IEXTEN de tu sistema estén disponibles para ser usadas en enlaces de teclas. En 4.4BSD, esta opción es necesaria si quieres usar control-V y control-O en tus enlaces de
teclas.
-p pue
rto
Usa el puerto especificado como el puerto predeterminado para nuevas conexiones de servidor. El puerto predeterminado es usualmente 6667. Asegúrate de que los servidores a los que quieres conectarte estén escuchando en este puerto antes de intentar conectarte
allí.
-
q
Suprime la carga de cualquier archivo cuando estableces una conexión por primera vez con un servidor de
irc.
-
v
Emite la información de identificación de versión (VID) y
sale.
-
x
Esta característica no documentada activa todas las banderas XDEBUG. Consulta los archivos de ayuda para XDEBUG si quieres saber qué sucede si usas
esto.
-z nombre-de-us
uario
Usa el nombre de usuario especificado al negociar una conexión con un nuevo servidor de irc. Esto anula la variable de entorno IRCUSER. Si esta opción no se especifica, entonces se usa el nombre de usuario especificado en /etc/passwd para tu usuario. Esta característica antes estaba sin documentar, pero con el aumento de la popularidad y el uso de identd(8) esta opción es mucho menos útil de lo que solía ser. Las solicitudes para tener esta opción eliminada probablemente serán ignoradas. Si no quieres que tus usuarios suplanten sus nombres de usuario, instala identd, y haz un favor a todos en
IRC.
apod
o
La primera palabra simple encontrada se toma como el apodo predeterminado a usar. Esto anula todas las demás opciones, incluyendo la opción -n y la variable de entorno IRCNICK. Si todo lo demás falla, entonces el cliente usa tu nombre de inicio de sesión como el apodo
predeterminado.

DESCRIPCIÓN

DETALLADA

La

Pantalla:

La pantalla está dividida en dos partes, separadas por una línea de estado en vídeo inverso (si se admite). La parte superior (más grande) de la pantalla muestra las respuestas del servidor ircd(8). La parte inferior de la pantalla (una sola línea) acepta la entrada del

teclado.

Algunas terminales no admiten ciertas características requeridas por epic, en cuyo caso recibirás un mensaje que lo indica. Si esto ocurre, intenta cambiar el tipo de terminal o ejecuta epic con la

opci
ón -d.

Comandos de

Irc:

Cualquier línea que comience con el carácter “/” se considera un comando de epic (el carácter de comando puede cambiarse). Cualquier línea que no comience con este carácter se trata como un mensaje a enviar al canal actual. El cliente tiene un si

stema de ayuda integrado. Instala los archivos de ayuda (deberían estar disponibles en el mis
mo lugar donde obtuviste el cliente) y luego escribe “/help” para abrir el sistema de ayuda.

El archivo .

ircrc:

Cuando epic se ejecuta, comprueba el directorio de inicio del usuario en busca de un archivo ~/.ircrc, ejecutando los comandos del archivo. Los comandos en este archivo

no necesitan tener un carácter de barra d
iagonal inicial “/”. Esto permite la predefi
nición de alias y otras características.

LOS ARCHIVOS DE

AYUDA

Iniciar el cliente es la parte fácil. Una vez que te conectes, probablemente descubrirás que no tienes idea de lo que estás haciendo. Ahí es donde entran los archivos de ayuda. Si la persona que mantiene irc en tu sitio no instaló l

os archivos de ayuda, molesta a esa persona hasta que lo haga. Una vez que los archivos de ayuda estén disponibles, usa el comando “/help” para empezar. Hay una cantidad inmensa de comandos y una multitud de matices que te llevarán unos
meses para dominar. Pero una vez que lo hagas, estarás tan firmemente enganchado a irc que tu esposa se divorciará de ti, tus hijos te abandonarán, tu perro se escapará, y suspenderás todas tus clases, y te quedarás cantando blues.

ERRORE

S

Cualquier pieza de software no trivial tiene errores. ircII/EPIC no es la excepción. Puedes referirte al archivo KNOWNBUGS que se distribuye con el código fuente del cliente para obtener una lista de problemas que se sabe que existen y que pueden o no corregirse algún día. Si encuentras un error que no está listado allí, puedes referirte al archivo BUG_FORM que también se distribuye con el código fuente. Te

dará instrucciones sobre cómo rel
lenar el informe y a dónde enviarlo.
