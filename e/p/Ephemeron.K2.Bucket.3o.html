Módulo Bucket
: sig end

type ('k1, 'k2, 'd) t

Un cubo es una "lista" mutable de efímeros.

val make : unit -> ('k1, 'k2, 'd) t

Crea un nuevo cubo.

val add : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> 'd -> unit

Añade un efímero al cubo.

val remove : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> unit

remove b k1 k2 elimina del cubo b el efímero agregado más recientemente con las claves k1 y k2, o no hace nada si no existe tal efímero.

val find : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> 'd option

Devuelve los datos del efímero agregado más recientemente con las claves dadas, o None si no existe tal efímero.

val length : ('k1, 'k2, 'd) t -> int

Devuelve un límite superior para la longitud del cubo.

val clear : ('k1, 'k2, 'd) t -> unit

Elimina todos los efímeros del cubo.
