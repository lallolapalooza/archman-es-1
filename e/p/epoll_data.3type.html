epoll_event(3type) epoll_event(3type)

NOMBRE

epoll_event, epoll_data, epoll_data_t - evento epoll

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <sys/epoll.h>
struct epoll_event {
    uint32_t      events;  /* Eventos Epoll */
    epoll_data_t  data;    /* Variable de datos de usuario */
};
union epoll_data {
    void     *ptr;
    int       fd;
    uint32_t  u32;
    uint64_t  u64;
};
typedef union epoll_data  epoll_data_t;

DESCRIPCIÓN

La estructura epoll_event especifica datos que el kernel debe guardar y devolver cuando el descriptor de archivo correspondiente esté listo.

VERSIONES

Diferencias biblioteca C/kernel

Las cabeceras del kernel de Linux también proporcionan este tipo, con una definición ligeramente diferente:


#include <linux/eventpoll.h>
struct epoll_event {
    __poll_t  events;
    __u64     data;
};

ESTÁNDARES

Linux.

VER TAMBIÉN

epoll_wait(2), epoll_ctl(2)
