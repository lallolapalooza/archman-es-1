ether_aton(3) Manual de funciones de biblioteca ether_aton(3)

NOMBRE

ether_aton, ether_ntoa, ether_ntohost, ether_hostton, ether_line, ether_ntoa_r, ether_aton_r - Rutinas de manipulación de direcciones Ethernet

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <netinet/ether.h>
char *ether_ntoa(const struct ether_addr *addr);
struct ether_addr *ether_aton(const char *asc);
int ether_ntohost(char *hostname, const struct ether_addr *addr);
int ether_hostton(const char *hostname, struct ether_addr *addr);
int ether_line(const char *line, struct ether_addr *addr,
               char *hostname);
/* Extensiones GNU */
char *ether_ntoa_r(const struct ether_addr *addr, char *buf);
struct ether_addr *ether_aton_r(const char *asc,
                                struct ether_addr *addr);

DESCRIPCIÓN

ether_aton() convierte la dirección Ethernet de 48 bits del host asc de la notación estándar de dígitos hexadecimales y dos puntos a datos binarios en orden de bytes de red y devuelve un puntero a ella en un búfer asignado estáticamente, que las llamadas posteriores sobrescribirán. ether_aton() devuelve NULL si la dirección no es válida.

La función ether_ntoa() convierte la dirección del host Ethernet addr dada en orden de bytes de red a una cadena en notación estándar de dígitos hexadecimales y dos puntos, omitiendo ceros iniciales. La cadena se devuelve en un búfer asignado estáticamente, que las llamadas posteriores sobrescribirán.

La función ether_ntohost() mapea una dirección Ethernet al nombre de host correspondiente en /etc/ethers y devuelve un valor distinto de cero si no se puede encontrar.

La función ether_hostton() mapea un nombre de host a la dirección Ethernet correspondiente en /etc/ethers y devuelve un valor distinto de cero si no se puede encontrar.

La función ether_line() analiza una línea en formato /etc/ethers (dirección Ethernet seguida de espacios en blanco seguida de nombre de host; '#' introduce un comentario) y devuelve un par de dirección y nombre de host, o un valor distinto de cero si no se puede analizar. El búfer al que apunta hostname debe ser lo suficientemente largo; por ejemplo, tener la misma longitud que line.

Las funciones ether_ntoa_r() y ether_aton_r() son versiones reentrantes y seguras para hilos de ether_ntoa() y ether_aton() respectivamente, y no utilizan búferes estáticos.

La estructura ether_addr se define en <net/ethernet.h> como:


struct ether_addr {
    uint8_t ether_addr_octet[6];
}

ESTÁNDARES

Ninguno.

HISTORIA

4.3BSD, SunOS.

ERRORES

En glibc 2.2.5 y anteriores, la implementación de ether_line() está rota.
