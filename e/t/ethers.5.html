NOMBRE

ethers - base de datos de direcciones Ethernet a números IP

DESCRIPCIÓN

/etc/ethers contiene direcciones Ethernet de 48 bits y sus números IP correspondientes, una línea por cada número IP:

Dirección-Ethernet Número-IP

Los dos elementos están separados por cualquier número de caracteres ESPACIO y/o TAB. Un # al principio de una línea inicia un comentario que se extiende hasta el final de la línea. La Dirección-Ethernet se escribe como x:x:x:x:x:x, donde x es un número hexadecimal entre 0 y ff que representa un byte de la dirección, que está en orden de bytes de red (big-endian). El Número-IP puede ser un nombre de host que puede ser resuelto por DNS o un número separado por puntos.

EJEMPLOS

08:00:20:00:61:CA pal
