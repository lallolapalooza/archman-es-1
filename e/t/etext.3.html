etext(3) Manual de funciones de biblioteca etext(3)

NOMBRE

etext, edata, end - fin de los segmentos del programa

SINOPSIS

extern etext;
extern edata;
extern end;

DESCRIPCIÓN

Las direcciones de estos símbolos indican el final de varios segmentos del programa:

etext
Esta es la primera dirección después del final del segmento de texto (el código del programa).
edata
Esta es la primera dirección después del final del segmento de datos inicializado.
end
Esta es la primera dirección después del final del segmento de datos no inicializado (también conocido como segmento BSS).

ESTÁNDARES

Ninguno.

HISTORIA

Aunque estos símbolos se han proporcionado durante mucho tiempo en la mayoría de los sistemas UNIX, no están estandarizados; úselos con precaución.

NOTAS

El programa debe declarar explícitamente estos símbolos; no están definidos en ningún archivo de encabezado.

En algunos sistemas, los nombres de estos símbolos van precedidos de guiones bajos, así: _etext, _edata y _end. Estos símbolos también están definidos para programas compilados en Linux.

Al inicio de la ejecución del programa, el límite del programa estará cerca de &end (quizás al principio de la página siguiente). Sin embargo, el límite cambiará a medida que se asigna memoria a través de brk(2) o malloc(3). Use sbrk(2) con un argumento de cero para encontrar el valor actual del límite del programa.

EJEMPLOS

Al ejecutarse, el siguiente programa produce una salida similar a la siguiente:


$ ./a.out
Primera dirección después de:
    texto del programa (etext)       0x8048568
    datos inicializados (edata)   0x804a01c
    datos no inicializados (end)   0x804a024

Código fuente del programa

#include <stdio.h>
#include <stdlib.h>
extern char etext, edata, end;  /* Los símbolos deben tener algún tipo,
                                   o "gcc -Wall" se quejará */
int
main(void)
{
    printf("Primera dirección después de:\n");
    printf("    texto del programa (etext)      %10p\n", &etext);
    printf("    datos inicializados (edata)  %10p\n", &edata);
    printf("    datos no inicializados (end)  %10p\n", &end);
    exit(EXIT_SUCCESS);
}
