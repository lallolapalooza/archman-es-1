NOMBRE

etc-update - gestionar actualizaciones de archivos de configuración

SINOPSIS

etc-update [opciones] [--automode <modo>] [rutas a escanear]

DESCRIPCIÓN

etc-update se supone que se ejecutará después de fusionar un nuevo paquete para ver si hay actualizaciones de los archivos de configuración. Si un nuevo archivo de configuración va a sobrescribir uno antiguo, etc-update le pedirá al usuario una decisión.

etc-update verificará todos los directorios especificados en la línea de comandos. Si no se proporcionan rutas, se utilizará la variable CONFIG_PROTECT. Todos los archivos de configuración encontrados en CONFIG_PROTECT_MASK serán actualizados automáticamente por etc-update. Consulte make.conf(5) para más información.

etc-update respeta las variables normales PORTAGE_CONFIGROOT y EROOT para encontrar las variables de protección de configuración mencionadas anteriormente.

OPCIONES

-d, --debug
Ejecutar con el rastreo del shell habilitado.
-h, --help
Sorprendentemente, muestra la salida de ayuda.
-p, --preen
Fusiona automáticamente solo los cambios triviales y sale.
-v, --verbose
Muestra la configuración y la información de decisiones importantes mientras se ejecuta.
--automode <modo>
Selecciona uno de los modos de fusión automática. Los modos válidos son: -3 -5 -7 -9. Consulte el texto de --help para más detalles.
