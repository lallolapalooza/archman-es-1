DESCRIPTION

ethtool se utiliza para consultar y controlar la configuración del controlador de red y del hardware, especialmente para dispositivos Ethernet cableados.

devname es el nombre del dispositivo de red en el que operará ethtool.

OPTIONS

ethtool con un único argumento que especifica el nombre del dispositivo imprime la configuración actual del dispositivo especificado.

-h --help
Muestra un mensaje de ayuda breve.
--version
Muestra el número de versión de ethtool.
--debug N
Activa los mensajes de depuración. El argumento se interpreta como una máscara:
0x01 Información del analizador
0x02 Resumen de mensajes netlink
0x04 Volcado hexadecimal de mensajes netlink enviados
0x08 Volcado hexadecimal de mensajes netlink recibidos
0x10 Estructura de mensajes netlink
--disable-netlink
No utiliza netlink y recurre a la interfaz ioctl si es posible.
--json
Muestra los resultados en JavaScript Object Notation (JSON). Solo un subconjunto de opciones admite esto. Aquellas que no lo hagan continuarán mostrando texto sin formato en presencia de esta opción.
-I --include-statistics
Incluye estadísticas relacionadas con el comando en la salida. Esta opción permite mostrar estadísticas relevantes del dispositivo para comandos get seleccionados.
--phy N
Apuntar a un PHY dentro de la interfaz. El índice del PHY se puede obtener con --show-phys. El índice de PHY 0 apunta al dispositivo PHY conectado directamente a la MAC Ethernet, si lo hay. Los siguientes comandos pueden aceptar un índice de PHY:
--cable-test
--cable-test-tdr
--get-plca-cfg
--set-plca-cfg
--get-plca-status
--show-pse
--set-pse
-a --show-pause
Consulta al dispositivo Ethernet especificado para obtener información sobre los parámetros de pausa.
--src aggregate|emac|pmac
Si se admite la capa de fusión de MAC (MAC Merge), solicita una fuente específica de estadísticas del dispositivo (eMAC o pMAC, o su agregado). Solo es válido si ethtool se invocó con el argumento -I --include-statistics.
-A --pause
Cambia los parámetros de pausa del dispositivo Ethernet especificado.
autoneg on|off
Especifica si la autonegociación de pausa debe estar habilitada.
rx on|off
Especifica si la pausa RX debe estar habilitada.
tx on|off
Especifica si la pausa TX debe estar habilitada.
-c --show-coalesce
Consulta al dispositivo de red especificado para obtener información de coalescencia.
-C --coalesce
Cambia la configuración de coalescencia del dispositivo de red especificado.
-g --show-ring
Consulta al dispositivo de red especificado para obtener información sobre los parámetros del anillo rx/tx.
-G --set-ring
Cambia los parámetros del anillo rx/tx del dispositivo de red especificado.
rx N
Cambia el número de entradas del anillo para el anillo Rx.
rx-mini N
Cambia el número de entradas del anillo para el anillo Mini Rx.
rx-jumbo N
Cambia el número de entradas del anillo para el anillo Jumbo Rx.
tx N
Cambia el número de entradas del anillo para el anillo Tx.
rx-buf-len N
Cambia el tamaño de un búfer en el anillo Rx.
tcp-data-split auto|on|off
Especifica el estado de la división de datos TCP.
hds-thresh N
Especifica el valor umbral de la división de datos TCP.
cqe-size N
Cambia el tamaño del evento de la cola de finalización.
tx-push on|off
Especifica si la función push TX debe estar habilitada.
rx-push on|off
Especifica si la función push RX debe estar habilitada.
tx-push-buf-len N
Especifica el número máximo de bytes de un paquete transmitido que un controlador puede enviar directamente al dispositivo subyacente.
-i --driver
Consulta al dispositivo de red especificado para obtener información del controlador asociado.
-d --register-dump
Recupera e imprime un volcado de registros para el dispositivo de red especificado. El formato de registro para algunos dispositivos es conocido y decodificado, otros se imprimen en hexadecimal. Cuando raw está habilitado, ethtool vuelca los datos brutos del registro a la salida estándar. Si se especifica file, usa el contenido del volcado de registro bruto anterior, en lugar de leer desde el dispositivo.
-e --eeprom-dump
Recupera e imprime un volcado de la EEPROM para el dispositivo de red especificado. Cuando raw está habilitado, vuelca los datos brutos de la EEPROM a la salida estándar. Los parámetros de longitud y desplazamiento permiten volcar porciones específicas de la EEPROM. El valor predeterminado es volcar toda la EEPROM.
raw on|off
offset N
length N
-E --change-eeprom
Si se especifica value, cambia un byte de la EEPROM para el dispositivo de red especificado. offset y value especifican qué byte y su nuevo valor. Si value no se especifica, se lee la entrada estándar y se escribe en la EE
PROM. Los parámetros de longitud y desplazamiento permiten escribir en ciertas porciones de la EEPROM. Debido a la naturaleza persistente de la escritura en la EEPROM, se debe especificar una clave mágica específica del dispositivo para evitar la escritura accidental en la EEPROM.
-k --show-features --show-offload
Consulta el dispositivo de red especificado para conocer el estado de la descarga de protocolos y otras características.
-K --features --offload
Cambia los parámetros de descarga y otras características del dispositivo de red especificado. Los siguientes nombres de características son integrados y otros pueden ser definidos por el kernel.
rx on|off
Especifica si la suma de verificación RX debe estar habilitada.
tx on|off
Especifica si la suma de verificación TX debe estar habilitada.
sg on|off
Especifica si la dispersión-agregación (scatter-gather) debe estar habilitada.
tso on|off
Especifica si la descarga de segmentación TCP (TCP segmentation offload) debe estar habilitada.
ufo on|off
Especifica si la descarga de fragmentación UDP (UDP fragmentation offload) debe estar habilitada.
gso on|off
Especifica si la descarga de segmentación genérica (generic segmentation offload) debe estar habilitada.
gro on|off
Especifica si la descarga de recepción genérica (generic receive offload) debe estar habilitada.
lro on|off
Especifica si la descarga de recepción grande (large receive offload) debe estar habilitada.
rxvlan on|off
Especifica si la aceleración VLAN RX debe estar habilitada.
txvlan on|off
Especifica si la aceleración VLAN TX debe estar habilitada.
ntuple on|off
Especifica si los filtros y acciones ntuple RX deben estar habilitados.
rxhash on|off
Especifica si la descarga de hash de recepción debe estar habilitada.
-p --identify
Inicia una acción específica del adaptador destinada a permitir que un operador identifique fácilmente el adaptador a la vista. Típicamente, esto implica el parpadeo de uno o más LEDs en el puerto de red específico.
[ N]
Duración de la ejecución de phys-id, en segundos.
-P --show-permaddr
Consulta el dispositivo de red especificado para obtener la dirección hardware permanente.
-r --negotiate
Reinicia la negociación automática en el dispositivo Ethernet especificado, si la negociación automática está habilitada.
-S --statistics
Consulta el dispositivo de red especificado para obtener estadísticas estándar (IEEE, IETF, etc.) o estadísticas específicas de la NIC y del driver. Las estadísticas específicas de la NIC y del driver se solicitan cuando no se especifica ningún grupo de estadísticas.

Las estadísticas específicas de la NIC y del driver y las estadísticas estándar son independientes; los dispositivos pueden implementar una, ambas o ninguna. Hay poca coincidencia en la denominación de las estadísticas específicas de la NIC y del driver entre los proveedores.

--all-groups
--groups [eth-phy] [eth-mac] [eth-ctrl] [rmon]
Solicita grupos de estadísticas de dispositivo estándar.
--src aggregate|emac|pmac
Si la capa MAC Merge es compatible, solicita una fuente particular de estadísticas del dispositivo (eMAC o pMAC, o su agregado).
--phy-statistics
Consulta el dispositivo de red especificado para obtener estadísticas específicas de PHY.
-t --test
Ejecuta la autocomprobación del adaptador en el dispositivo de red especificado. Los modos de prueba posibles son:
offline
Realiza el conjunto completo de pruebas, posiblemente interrumpiendo la operación normal durante las pruebas.
online
Realiza un conjunto limitado de pruebas, sin interrumpir la operación normal.
external_lb
Realiza el conjunto completo de pruebas, como para offline, y adicionalmente una prueba de bucle externo (external-loopback).
-s --change
Permite cambiar todas o algunas de las configuraciones del dispositivo de red especificado. Todas las siguientes opciones solo se aplican si se especificó -s.
speed N
Establece la velocidad en Mb/s. ethtool solo con el nombre del dispositivo como argumento le mostrará las velocidades admitidas por el dispositivo.
lanes N
Establece el número de carriles.
duplex half|full
Establece el modo dúplex completo o semidúplex.
port tp|aui|bnc|mii
Selecciona el puerto del dispositivo.
master-slave preferred-master|preferred-slave|forced-master|forced-slave
Configura el rol MAESTRO/ESCLAVO del PHY. Cuando el PHY está configurado como MAESTRO, la función de transmisión PMA obtendrá TX_TCLK de una fuente de reloj local. Cuando está configurado como ESCLAVO, la función de transmisión PMA obtendrá TX_TCLK del reloj recuperado del flujo de datos proporcionado por el MAESTRO. No todos los dispositivos admiten esto.
preferred-master Prefiere el rol MAESTRO en la negociación automática.
preferred-slave Prefiere el rol ESCLAVO en la negociación automática.
forced-master Fuerza el PHY en el rol MAESTRO. Se puede usar sin negociación automática.
forced-slave Fuerza el PHY en el rol ESCLAVO. Se puede usar sin negociación automática.
mdix auto|on|off
Selecciona el modo MDI-X para el puerto. Puede usarse para anular la función de detección automática de la mayoría de los adaptadores. Un argumento de auto significa detección automática del estado MDI, on fuerza el modo MDI-X (cruzado), mientras que off significa modo MDI (directo). El driver debe garantizar que este comando tenga efecto inmediatamente y, si es necesario, puede restablecer el enlace para que el cambio tenga efecto.
autoneg on|off
Especifica si la negociación automática debe estar habilitada. La negociación automática está habilitada por defecto, pero algunos dispositivos de red pueden tener problemas con ella, por lo que puede deshabilitarla si es realmente necesario.

El identificador de nodo único en el rango [0 .. 255]. El ID de nodo 0 está reservado para el nodo coordinador, el que genera la señal BEACON. Debe haber exactamente un coordinador en una red PLCA. node-cnt N
El parámetro node-cnt es el número total de nodos en el enlace. Solo el nodo coordinador (nod-id = 0) puede configurar este parámetro. Configurar este parámetro en un nodo seguidor no tiene ningún efecto. El parámetro node-cnt se corresponde con la cláusula 30.16.1.1.3 (aPLCANodeCount) de IEEE 802.3cg-2019.
to-tmr N
El parámetro del temporizador TO (Transmit Opportunity) establece el valor del temporizador de oportunidad de transmisión en tiempos de bit y debe ser igual en todos los nodos que comparten el mismo medio para que PLCA funcione. El valor predeterminado de 32 es suficiente para cubrir un enlace de aproximadamente 50 metros. Este parámetro se corresponde con la cláusula 30.16.1.1.5 (aPLCATransmitOpportunityTimer) de IEEE 802.3cg-2019.
burst-cnt N
El parámetro burst-cnt [0 .. 255] indica el número adicional de paquetes que se permite enviar al nodo durante una única oportunidad de transmisión. Por defecto, este atributo es 0, lo que significa que el nodo puede enviar un solo trama por TO. Cuando es mayor que 0, el RS de PLCA mantiene el TO después de cualquier transmisión, esperando que la MAC envíe una nueva trama hasta burst-tmr BTs. Esto solo puede ocurrir un número de veces por ciclo de PLCA hasta el valor de este parámetro. Después de eso, el ráfaga termina y se reanuda el conteo normal de TOs. Este parámetro se corresponde con la cláusula 30.16.1.1.6 (aPLCAMaxBurstCount) de IEEE 802.3cg-2019.
burst-tmr N
El parámetro burst-tmr [0 .. 255] establece cuántos tiempos de bit espera el RS de PLCA a que la MAC inicie una nueva transmisión cuando burst-cnt es mayor que 0. Si la MAC no logra enviar una nueva trama dentro de este tiempo, la ráfaga termina y se reanuda el conteo de TOs. De lo contrario, la nueva trama se envía como parte de la ráfaga actual. Este parámetro se corresponde con la cláusula 30.16.1.1.7 (aPLCABurstTimer) de IEEE 802.3cg-2019. El valor de burst-tmr debe ser mayor que el tiempo de Inter-Frame-Gap (IFG) de la MAC (más un margen) para que el modo de ráfaga de PLCA funcione según lo previsto.
