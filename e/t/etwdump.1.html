NOMBRE

etwdump - Proporciona una interfaz para leer Event Tracing for Windows (ETW)

SINOPSIS

etwdump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --capture ] [ --fifo=<ruta a archivo o pipe> ] [ --iue=<¿Se deben incluir eventos no decidibles?> ] [ --etlfile=<archivo etl> ] [ --params=<parámetros de filtro> ]

DESCRIPCIÓN

etwdump es una herramienta extcap que proporciona acceso a un archivo de registro de traza de eventos o a una sesión en vivo de traza de eventos. Solo se utiliza para mostrar trazas de eventos en Windows que incluyen mensajes de texto legibles y diferentes protocolos (como MBIM y paquetes IP).

OPCIONES

--help

Imprime los argumentos del programa.

--version

Imprime la versión del programa.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Utiliza las interfaces especificadas.

--extcap-dlts

Lista los DLT de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--capture

Inicia la captura desde la interfaz especificada y la guarda en la ubicación especificada por --fifo.

--fifo=<ruta a archivo o pipe>

Guarda el paquete capturado en un archivo o lo envía a través de un pipe.

--iue=<¿Se deben incluir eventos no decidibles?>

Elige si se incluyen los eventos no decidibles.

--etlfile=<archivo Etl>

Selecciona el archivo etl para mostrar en Wireshark.

--params=<parámetros de filtro>

Proveedores de entrada, filtros de palabras clave y nivel para el archivo etl y la sesión en vivo.

EJEMPLOS

Para ver los argumentos del programa:

etwdump --help

Para ver la versión del programa:

etwdump --version

Para ver las interfaces:

etwdump --extcap-interfaces

Salida de ejemplo

interface {value=etwdump}{display=Lector ETW}

Para ver los DLT de la interfaz:

etwdump --extcap-interface=etwdump --extcap-dlts

Salida de ejemplo

dlt {number=1}{name=etwdump}{display=DLT_ETW}

Para ver las opciones de configuración de la interfaz:

etwdump --extcap-interface=etwdump --extcap-config

Salida de ejemplo

arg {number=0}{call=--etlfile}{display=archivo etl}{type=fileselect}{tooltip=Selecciona el archivo etl para mostrar en Wireshark}{group=Captura}
arg {number=1}{call=--params}{display=parámetros de filtro}{type=string}{tooltip=Proveedores de entrada, filtros de palabras clave y nivel para el archivo etl y la sesión en vivo}{group=Captura}
arg {number=2}{call=--iue}{display=¿Se deben incluir eventos no decidibles?}{type=boolflag}{default=false}{tooltip=Elige si se incluyen los eventos no decidibles}{group=Captura}

Para capturar:

etwdump --extcap-interface etwdump --fifo=/tmp/etw.pcapng --capture --params "--p=Microsoft-Windows-Wmbclass-Opn --p=Microsoft-Windows-wmbclass --k=0xff --l=4"
etwdump --extcap-interface etwdump --fifo=/tmp/etw.pcapng --capture --params "--p=Microsoft-Windows-Wmbclass-Opn --p=Microsoft-Windows-NDIS-PacketCapture"

Nota

Para detener la captura, presiona CTRL+C o termina la aplicación.
