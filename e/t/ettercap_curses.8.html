ETTERCAP-CURSES(8) Manual del Administrador del Sistema ETTERCAP-CURSES(8)

NOMBRE

ettercap - Página del manual de la GUI de Ncurses.

DESCRIPCIÓN GENERAL

La GUI de curses es bastante simple e intuitiva.
Se basa en menús. Cada bandera o función se puede modificar/llamar a través del menú superior. Todos los mensajes del usuario se imprimen en la ventana inferior. Si desea ver los mensajes anteriores, puede desplazarse por el búfer de la ventana presionando las teclas ARRIBA, ABAJO, PPAGE, NPAGE. La parte central se utiliza para mostrar información o diálogos para el usuario.

Los menús se pueden abrir presionando la tecla de acceso rápido relativa. Para los menús, la tecla de acceso rápido se representa con la letra inicial mayúscula del título (por ejemplo, 'S' para Sniffing, 'T' para Targets). Las funciones dentro de un menú se pueden llamar presionando la tecla de acceso rápido que se muestra cerca del nombre de la función a la derecha. Las teclas de acceso rápido que comienzan con 'C-' se deben usar junto con la tecla CTRL (por ejemplo, 'C-f' significa CTRL + f).

Puede cambiar el enfoque entre los objetos en la pantalla presionando la tecla TAB o haciendo clic sobre ellos con el ratón (si está ejecutando ettercap dentro de un xterm). Los eventos del ratón solo son compatibles a través de xterm. Puede usar el ratón para seleccionar objetos, abrir un menú, elegir una función, desplazarse por las barras de desplazamiento de las ventanas, etc.

Cuando abre varias ventanas en la parte central, estas se superpondrán. Use la tecla TAB para cambiar entre ellas. Use CTRL + Q para cerrar la ventana enfocada.
También puede usar CTRL + Q para cerrar el cuadro de diálogo de entrada si desea cancelar la entrada solicitada. (es decir, ha seleccionado la función incorrecta y desea volver).

Para obtener ayuda rápida sobre los atajos que puede usar contra una ventana particular, presione la tecla ESPACIO. Se mostrará una ventana de ayuda con una lista de atajos que se pueden usar. Si la ventana no aparece, no hay atajos disponibles.

CÓMO SELECCIONARLO

Para usar la GUI de ncurses, debe:

- compilar ettercap con soporte ncurses (obviamente)
- ejecutarlo con la bandera -C

Pasar la bandera -C es suficiente, pero si lo desea, puede pasar otras banderas que se configurarán automáticamente para la GUI de ncurses. Podrá anularlas utilizando el menú para cambiar las opciones.

UNA VEZ INICIADO

Tan pronto como se inicie ettercap con la GUI de Ncurses, se le presentarán múltiples opciones. La primera pantalla le permite seleccionar si desea abrir un archivo pcap o volcar el tráfico capturado a un archivo, si desea captura unificada o en puente, le permite establecer un archivo pcap en el tráfico capturado y le permite registrar todos los datos capturados.

Una vez que haya seleccionado un método de captura (desde archivo, unificado o en puente), esta pantalla ya no será accesible. La única forma es reiniciar ettercap.

Analicemos cada menú en la pantalla de inicio:

Archivo
Abrir...
Abre un archivo pcap y lo analiza. Todas las funcionalidades disponibles para la captura en vivo están presentes, excepto aquellas que envían o reenvían paquetes (ataques mitm y similares...).
Volcar a archivo...
Todo el tráfico capturado por la captura en vivo se volcará a ese archivo. Los filtros, no los objetivos, tienen efectos en este archivo, ya que se volcarán todos los paquetes recibidos por pcap. La única forma de no volcar un paquete determinado es establecer un filtro pcap adecuado (ver más abajo).
Salir

Sale de ettercap y regresa al prompt de comandos.
Captura
Captura unificada...
Al elegir esta función, se le pedirá que seleccione la interfaz de red que se utilizará para la captura. La primera interfaz en funcionamiento se sugiere en el cuadro de entrada. Para obtener una explicación de lo que es la captura unificada, consulte ettercap(8).
CONSEJO: Si usa la tecla de acceso rápido 'u', este paso se omitirá y la interfaz predeterminada se seleccionará automáticamente.
Captura en puente...
Después de seleccionar las dos interfaces que se utilizarán, entrará en el modo de captura en puente. Para obtener una explicación de lo que es la captura en puente, consulte ettercap(8).
Establecer filtro pcap...
Aquí puede insertar un filtro tipo tcpdump para el proceso de captura.
IMPORTANTE: Si logra utilizar un ataque mitm, recuerde que si ettercap no ve un paquete, no se reenviará. Así que asegúrese de lo que está haciendo al establecer un filtro pcap.
Opciones
No ofensivo
Esto habilita/deshabilita la bandera no ofensiva. El asterisco '*' significa "la opción está habilitada". De lo contrario, la opción no está habilitada.
Modo promiscuo
Habilita/deshabilita el modo promiscuo para la captura en vivo en una interfaz de red. Esta es una "opción de asterisco" como la no ofensiva.
Establecer máscara de red
Utiliza la máscara de red especificada en lugar de la asociada con la interfaz actual. Esta opción es útil si tiene la NIC con una máscara de red de clase B asociada y desea escanear (con el escaneo arp) solo una clase C.

LA PARTE INTERESANTE

Una vez que haya seleccionado una captura en vivo o desde archivo, el menú superior se modifica y puede comenzar a hacer las cosas interesantes...
Algunos de los siguientes menús solo están disponibles en captura en vivo.

Iniciar
Iniciar captura
Inicia el proceso de captura dependiendo de lo que haya seleccionado al inicio (en vivo o desde archivo)
Detener captura
Detiene el hilo de captura.
Salir

Regresa a su shell favorito ;)
Objetivos
Objetivos Actuales
Muestra una lista de hosts en cada OBJETIVO. Puede eliminar selectivamente un host seleccionándolo y presionando 'd' o agregar un nuevo host presionando 'a'. Para cambiar entre las dos listas, use las teclas de FLECHA.
Seleccionar OBJETIVO(s)
Le permite seleccionar el(los) OBJETIVO(s) como se explica en ettercap(8). La sintaxis es la misma que para la especificación de línea de comandos.
Protocolo...
Puede elegir capturar solo TCP, solo UDP o ambos (TODOS).
Invertir coincidencia
Invierte la coincidencia de un paquete. Es equivalente a un NOT antes de la especificación del objetivo.
Borrar Objetivos
Restaura ambos OBJETIVOS a CUALQUIERA/CUALQUIERA/CUALQUIERA
Hosts
Lista de hosts
Muestra la lista de hosts detectados mediante un escaneo ARP o convertidos de los perfiles pasivos. Esta lista es utilizada por los ataques MITM cuando se selecciona el objetivo CUALQUIERA, por lo que si desea excluir un host del ataque, simplemente elimínelo de la lista.
Puede eliminar un host de la lista presionando 'd', agregarlo a OBJETIVO1 presionando '1' o agregarlo a OBJETIVO2 presionando '2'.
Escanear hosts
Realiza el escaneo ARP de la máscara de red si no se seleccionan OBJETIVOS. Si se especificó OBJETIVOS, solo escanea esos hosts.
Cargar desde archivo...
Carga la lista de hosts desde un archivo previamente

Muestra la lista de conexiones. Para ver información detallada sobre una conexión, presiona 'd', o presiona 'k' para terminarla. Para ver el tráfico de una conexión específica, selecciónala y presiona enter. Una vez que se muestra la interfaz de dos paneles, puedes mover el foco con las teclas de flecha.
