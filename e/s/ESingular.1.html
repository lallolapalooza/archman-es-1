NOMBRE

ESingular - página del manual para ESingular 4.0.0

DESCRIPCIÓN

ESingular: Un programa que inicia Singular dentro de emacs, para la versión 4.0.0 de Singular -- un CAS para cálculos polinomiales. Uso:

ESingular [opciones] [archivo]

OPCIONES

- --emacs=EMACS
Usa EMACS como programa de emacs para ejecutar Singular
- --emacs-dir=DIR
Usa DIR como directorio para buscar archivos lisp de emacs
- --emacs-load=FILE
Carga FILE al iniciar emacs, en lugar del predeterminado
- --singular=PROG
Inicia PROG como programa de Singular dentro de emacs
- --no-call
No inicia el programa. Imprime la llamada a la salida estándar
todas las demás opciones se pasan a Singular.

Para más información, escribe `help;' desde dentro de Singular o visita https://www.singular.uni-kl.de o consulta el manual de Singular (disponible como información en línea o manual html).

VER TAMBIÉN

La documentación completa de Singular se mantiene como un manual Texinfo. Si los programas info y Singular están correctamente instalados en tu sitio, el comando

info Singular

debería darte acceso al manual completo.
