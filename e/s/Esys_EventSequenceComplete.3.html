Función de una sola llamada para TPM2_EventSequenceComplet

e

Esta función invoca el comando TPM2_EventSequenceComplete en una variante de una sola llamada. Esto significa que la función se bloqueará hasta que la respuesta del TPM esté disponible. Todos los parámetros de entrada son const. La memoria para los parámetros de salida no simples es asignada por la implementación de la

función.

Parámetro

s
esysContext El ESYS_CONTEXT.
pcrHandle PCR a extender con los datos del Evento.
sequenceHandle Autorización para la secuencia.
shandle1 Manipulador de sesión para la autorización de pcrHandle
shandle2 Manipulador de sesión para la autorización de sequenceHandle
shandle3 Tercer manipulador de sesión.
buffer Datos a añadir al Evento.
results Lista de resúmenes calculados para el PCR. (asignado por el
receptor)

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_ESYS_RC_BAD_REFERENCE si el esysContext o los punteros de entrada requeridos o las referencias de manipuladores de salida requeridos son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en el esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de la respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_RSP_AUTH_FAILED si el HMAC de respuesta del TPM no se verificó.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si alguno de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.
TSS2_ESYS_RC_NO_ENCRYPT_PARAM si una de las sesiones tiene el atributo 'encrypt' establecido y el comando no soporta el cifrado del primer parámetro de respuesta.
Los TSS2_RC producidos por capas inferiores del stack de software pueden ser
devueltos al llamador sin alterar a
menos que sean manejados internamente.

Función asíncrona para TPM2_EventSequenceComplet

e

Esta función invoca el comando TPM2_EventSequenceComplete en una variante asíncrona. Esto significa que la función retornará tan pronto como el comando haya sido enviado hacia abajo por el stack al TPM. Todos los parámetros de entrada son const. Para obtener la respuesta del TPM, llame a Esys_EventSequenceComplete_Finish

.

shandle2 Manipulador de sesión para la autorización de sequenceHandle
shandle3 Tercer manipulador de sesión.
buffer Datos a añadir al
Evento.

TSS2_ESYS_RC_BAD_REFERENCE si el esysContext o los punteros de entrada requeridos o las referencias de manipuladores de salida requeridos son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en el esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
Los TSS2_RC producidos por capas inferiores del stack de software pueden ser devueltos al llamador sin alterar a menos que sean manejados internamente.

TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en el esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
