TSS2_RC Esys_PCR_Reset (ESYS_CONTEXT * esysContext, ESYS_TR pcrHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR

shandle3)

Función de una sola llamada para

TPM2_PCR_Reset

Esta función invoca el comando TPM2_PCR_Reset en una variante de una sola llamada. Esto significa que la función se bloqueará hasta que la respuesta del TPM esté disponible. Todos los parámetros de entrada son const. La memoria para los parámetros de salida no simples es asignada por la implementación de la

función.

Parámetro

s
esysContext El ESYS_CONTEXT.
pcrHandle El PCR a reiniciar.
shandle1 Manejo de sesión para la autorización de pcrHandle
shandle2 Segundo manejo de sesión.
shandle3 Tercer manejo de
sesión.

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_ESYS_RC_BAD_REFERENCE si el esysContext o los punteros de entrada requeridos o las referencias de manejo de salida requeridas son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de la respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_RSP_AUTH_FAILED si el HMAC de respuesta del TPM no se verificó.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si cualquiera de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si una de las sesiones tiene el atributo 'decrypt' establecido y el comando no soporta el cifrado del primer parámetro de comando.
TSS2_ESYS_RC_NO_ENCRYPT_PARAM si una de las sesiones tiene el atributo 'encrypt' establecido y el comando no soporta el cifrado del primer parámetro de respuesta.
Los TSS2_RC producidos por capas inferiores de la pila de software pueden s
er devueltos al llamador sin altera
r a menos que se manejen internamente.

TSS2_RC Esys_PCR_Reset_Async (ESYS_CONTEXT * esysContext, ESYS_TR pcrHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR

shandle3)

Función asíncrona para

TPM2_PCR_Reset

Esta función invoca el comando TPM2_PCR_Reset en una variante asíncrona. Esto significa que la función retornará tan pronto como el comando haya sido enviado hacia abajo por la pila al TPM. Todos los parámetros de entrada son const. En orden para recuperar la respuesta del TPM, llame a Esys_PCR_Reset_Finish

.

Parámetro

s
esysContext El ESYS_CONTEXT.
pcrHandle El PCR a reiniciar.
shandle1 Manejo de sesión para la autorización de pcrHandle
shandle2 Segundo manejo de sesión.
shandle3 Tercer manejo de
sesión.

Valores de

retorno
ESYS_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_ESYS_RC_BAD_REFERENCE si el esysContext o los punteros de entrada requeridos o las referencias de manejo de salida requeridas son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
Los TSS2_RC producidos por capas inferiores de la pila de software pueden ser devueltos al llamador sin alterar a menos que se manejen internamente.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si cualquiera de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si una de las sesiones tiene el atributo 'decrypt' establecido y el comando no soporta el cifrado del primer parámetro de comando.
TSS2_ESYS_RC_NO_ENCRYPT_PARAM si una de las sesiones tiene el atributo 'encrypt'
