es256_pk_new(3)

Paquete: libfido2

Licencias: BSD-2-Clause

ES256_PK_NEW(3) Manual de funciones de biblioteca ES256_PK_NEW(3)

NOMBRE

es256_pk_new, es256_pk_free, es256_pk_from_EC_KEY, es256_pk_from_EVP_PKEY, es256_pk_from_ptr, es256_pk_to_EVP_PKEY — API COSE ES256 de FIDO2

SINOPSIS

#include <openssl/ec.h>
#include <fido/es256.h>

es256_pk_t *
es256_pk_new(void);

void
es256_pk_free(es256_pk_t **pkp);

int
es256_pk_from_EC_KEY(es256_pk_t *pk, const EC_KEY *ec);

int
es256_pk_from_EVP_PKEY(es256_pk_t *pk, const EVP_PKEY *pkey);

int
es256_pk_from_ptr(es256_pk_t *pk, const void *ptr, size_t len);

EVP_PKEY *
es256_pk_to_EVP_PKEY(const es256_pk_t *pk);

DESCRIPCIÓN

ES256 es el nombre dado en el RFC CBOR Object Signing and Encryption (COSE) a ECDSA sobre P-256 con SHA-256. La API COSE ES256 de libfido2 es una API auxiliar con rutinas para convertir entre los diferentes tipos de clave pública ECDSA utilizados en libfido2 y OpenSSL.

En libfido2, las claves públicas ES256 se abstraen mediante el tipo es256_pk_t.

La función es256_pk_new() devuelve un puntero a un tipo es256_pk_t recién asignado y vacío. Si no se puede asignar memoria, se devuelve NULL.

La función es256_pk_free() libera la memoria que respalda *pkp, donde *pkp debe haber sido asignado previamente por es256_pk_new(). Al regresar, *pkp se establece en NULL. Ya sea pkp o *pkp pueden ser NULL, en cuyo caso es256_pk_free() no hace nada.

La función es256_pk_from_EC_KEY() rellena pk con el contenido de ec. No se conservan referencias a ec.

La función es256_pk_from_EVP_PKEY() rellena pk con el contenido de pkey. No se conservan referencias a pkey.

La función es256_pk_from_ptr() rellena pk con el contenido de ptr, donde ptr apunta a len bytes. El puntero ptr puede apuntar a un punto no comprimido, o a la concatenación de las coordenadas x e y. No se conservan referencias a ptr.

La función es256_pk_to_EVP_PKEY() convierte pk a un tipo EVP_PKEY recién asignado con un recuento de referencias de 1. No se conservan referencias internas al puntero devuelto. Si ocurre un error, es256_pk_to_EVP_PKEY() devuelve NULL.

VALORES DE RETORNO

Las funciones es256_pk_from_EC_KEY(), es256_pk_from_EVP_PKEY() y es256_pk_from_ptr() devuelven FIDO_OK si la operación tiene éxito. En caso de error, se devuelve un código de error diferente definido en <fido/err.h>.
