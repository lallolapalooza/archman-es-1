Descripción Detallada

Función ESAPI para invocar el comando TPM2_Clear, ya sea como una llamada única o de forma asíncrona.

Documentación de la Función

TSS2_RC Esys_Clear_Async (ESYS_CONTEXT * esysContext, ESYS_TR authHandle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3)

Función asíncrona para TPM2_Clear

Esta función invoca el comando TPM2_Clear en una variante asíncrona. Esto significa que la función retornará tan pronto como el comando haya sido enviado por la pila al TPM. Todos los parámetros de entrada son constantes. Para recuperar la respuesta del TPM, llame a Esys_Clear_Finish.

Parámetros

esysContext El ESYS_CONTEXT.
authHandle TPM2_RH_LOCKOUT o TPM2_RH_PLATFORM+{PP}.
shandle1 Manejador de sesión para la autorización de authHandle
shandle2 Segundo manejador de sesión.
shandle3 Tercer manejador de sesión.

Valores de retorno

ESYS_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext o punteros de entrada requeridos o referencias de manejadores de salida requeridos son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_RCs producidos por capas inferiores de la pila de software pueden ser devueltos al llamador sin alterar, a menos que se manejen internamente.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si alguno de los objetos ESYS_TR son desconocidos para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si una de las sesiones tiene el atributo 'decrypt' establecido y el comando no soporta encriptación del primer parámetro del comando.
TSS2_ESYS_RC_NO_ENCRYPT_PARAM si una de las sesiones tiene el atributo 'encrypt' establecido y el comando no soporta encriptación del primer parámetro de respuesta.
