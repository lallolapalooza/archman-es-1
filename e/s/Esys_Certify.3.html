Función de Llamada Única para

TPM2_Certify

Esta función invoca el comando TPM2_Certify en una variante de llamada única. Esto significa que la función se bloqueará hasta que la respuesta del TPM esté disponible. Todos los parámetros de entrada son const. La memoria para los parámetros de salida no simples es asignada por la implementación de la

función.

Parámetro

s
esysContext El ESYS_CONTEXT.
objectHandle Manejo del objeto a ser certificado.
signHandle Manejo de la clave usada para firmar la estructura de atestación.
shandle1 Manejo de sesión para la autorización de objectHandle
shandle2 Manejo de sesión para la autorización de signHandle
shandle3 Tercer manejo de sesión.
qualifyingData Datos de calificación proporcionados por el usuario.
inScheme Esquema de firma TPM2_Signing a usar si el esquema para signHandle es TPM2_ALG_NULL.
certifyInfo La estructura que fue firmada. (asignada por el receptor)
signature La firma asimétrica sobre certifyInfo usando la clave referenciada por signHandle. (asignada por el
receptor)

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_ESYS_RC_BAD_REFERENCE si el esysContext o los punteros de entrada requeridos o las referencias de manejo de salida requeridas son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_RSP_AUTH_FAILED si el HMAC de respuesta del TPM no se verificó.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si alguno de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.

inScheme Esquema de firma TPM2_Signing a usar si el esquema para signHandle es
TPM2_ALG_NULL.
