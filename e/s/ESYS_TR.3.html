Descripción

detallada

Objetos virtuales con metadatos para recursos TPM. Los recursos TPM de Esys son los objetos virtuales dentro de ESYS_CONTEXT que contienen los metadatos de los recursos TPM correspondientes

.

Existe un conjunto de objetos ESYS_TR globales, como ES

YS_TR_NON o para los distintos PCRs y jerarquías. ESYS_T
R_MIN_OBJECT denota el primer objeto ESYS_TR no global.

TSS2_RC Esys_TR_FromTPMPublic (ESYS_CONTEXT * esys_context, TPM2_HANDLE tpm_handle, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3, ESYS_TR *

object)

Creación de un objeto ESYS_TR a partir de metadatos del

TPM.

Esta función puede usarse para crear un objeto ESYS_TR para recursos TPM que no fueron creados o cargados (por ejemplo, usando ESys_CreatePrimary o ESys_Load) pero que ya existen dentro del TPM. Ejemplos son los índices NV u objetos

persistentos.

Nota: Para PCRs y jerarquías, por favor use los identificadores ESYS_TR globales. Nota: Si se proporciona una sesión, se consulta al TPM dos veces por los metadatos. Primero sin una sesión para recuperar algunos metadatos, luego con la sesión donde estos metadatos se usan en el cálculo del HMAC de la sesión y así se

verifican.

Dado que los ataques man-in-the-middle deben prevenirse en la medida de lo posible, se recomienda pasar una

sesión.

Parámetro

s
esys_context [entrada,salida] El ESYS_CONTEXT
tpm_handle [entrada] El manejador del objeto TPM a representar como ESYS_TR.
shandle1 [entrada,salida] Una sesión para asegurar el comando TPM (opcional).
shandle2 [entrada,salida] Una sesión para asegurar el comando TPM (opcional).
shandle3 [entrada,salida] Una sesión para asegurar el comando TPM (opcional).
object [salida] El nuevo objeto de metadatos ESYS_TR
creado.

Valores de

retorno
TSS2_RC_SUCCESS en caso de éxito
ESYS_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext o los punteros de entrada requeridos o las referencias de manejador de salida requeridas son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de la respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si una de las sesiones tiene el atributo 'decrypt' establecido y el comando no soporta el cifrado del primer parámetro del comando.
