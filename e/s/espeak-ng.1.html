OPCIONE

S
-h, --he
lp
Muestra un resumen de las
opciones.
--versi
on
Imprime la versión de la biblioteca espeak y la ubicación de los datos de voz de
espeak.
-f <archivo de
texto>
Archivo de texto para
hablar.
--std
in
Lee la entrada de texto de
sde stdin hasta el final de
un flujo de una sola vez.

Si no se proporciona ni -f ni --stdin, entonces se hablan las <palabras> del parámetro, o se habla el texto desde stdin, leyéndolo por separado una línea a la

vez.
-d
<dispositivo>
Usa el dispositivo especificado para reproducir el audio. Si no se especifica, se usa el dispositivo de audio
predeterminado.
-
q
Silencioso, no produce ningún habla (puede ser útil con
-x).
-a
<entero>
Amplitud, de 0 a 200, el valor predeterminado es
100.
-g
<entero>
Separación entre palabras. Pausa entre palabras, en unidades de 10 ms a la velocidad
predeterminada.
-k
<entero>
Indica letras mayúsculas con: 1=sonido, 2=la palabra "capitales", valores más altos = un aumento de tono (prueba -k20)
.
-l
<entero>
Longitud de línea. Si no es cero (que es el valor predeterminado), considera las líneas con una longitud menor que esta como fin de
cláusula.
-p
<entero>
Ajuste de tono, de 0 a 99, el valor predeterminado es
50.
-s
<entero>
Velocidad en palabras por minuto, el valor predeterminado es
175.
-v <nombre de
voz>
Usa el archivo de voz con este nombre de espeak-ng-data/voices. Se puede especificar una variante usando voz+variante, como
af+m3.
-w <nombre de archivo de
onda>
Escribe la salida en este archivo WAV, en lugar de hablarlo
directamente.
--split=<minut
os>
Se usa con -w para dividir la salida de audio en fragmentos grabados de <minutos>
.
-
b
Codificación del texto de entrada, 1=UTF8, 2=8 bits, 4=16
bits.
-
m
Indica que el texto contiene etiquetas SSML (Speech Synthesis Markup Language) u otras etiquetas XML. Aquellas etiquetas SSML que son compatibles se interpretan. Otras etiquetas, incluyendo HTML, se ignoran, excepto que algunas etiquetas HTML
como
-
x
Escribe las mnemotecnias de fonemas en
stdout.
-
X
Escribe las mnemotecnias de fonemas y la traza de traducción en stdout. Si los archivos de reglas se han compilado con --compile=debug, también se mostrarán los números de
línea.
-
z
No hay pausa de frase final al final del
texto.
--stdo
ut
Escribe la salida de voz en
stdout.
--compile=voicen
ame
Compila las reglas de pronunciación y el diccionario en el directorio actual. =<voicename< es opcional y especifica qué idioma se
compila.
--compile-debug=voicen
ame
Compila las reglas de pronunciación y el diccionario en el directorio actual como arriba, pero incluye los números de línea, que se muestran cuando se usa
-X.
--i
pa
Escribe los fonemas en stdout usando el Alfabeto Fonético Internacional. --ipa=1 Usa ligaduras, --ipa=2 Usa ZWJ, --ipa=3 Separa con
_.
--tie=<carácte
r>
El carácter a usar para unir fonemas de múltiples letras en la salida de -x y
--ipa.
--path=<rut
a>
Especifica el directorio que contiene el directorio
espeak-ng-data.
--p
ho
Escribe los datos de fonemas de mbrola (.pho) en stdout o en el archivo en
--phonout.
--phonout=<nombre de
archivo>
Escribe la salida de los comandos -x -X y los datos de fonemas de mbrola en este
archivo.
--punct="<caracteres>
"
Habla los nombres de los caracteres de puntuación durante la locución. Si se omite =<caracteres>, se habla toda la
puntuación.
--sep=<carácte
r>
El carácter para separar los fonemas de la salida de -x y
--ipa.
--voices[=<código de idioma>
]
Lista las voces disponibles. Si está presente =<código de idioma>, solo se listan las voces adecuadas para ese idioma. Si se pasa código de idioma xx-yy, entonces las voces con yy de variantes de idioma xx se muestran con mayor prioridad que solo xx. Si se pasa variante, entonces se muestran todas las variantes de voz. Si se pasa mb o mbrola, entonces se muestran todas las voces que usan el sintetizador de voz MBROLA. Si se pasa all, entonces se muestran todas las voces, variantes de voz y voces MBROLA de eSpeak
NG.
--voices=<director
io>
Lista las vo
ces en el su
bdirectorio e
specificado.

EJEMPLO

S
espeak-ng "This is a
test"
Habla la frase "This is a test" usando la voz de inglés
predeterminada.
espeak-ng -f hello.
txt
Habla el contenido de hello.txt usando la voz de inglés
predeterminada.
cat hello.txt |
espeak-ng
Habla el contenido de hello.txt usando la voz de inglés
predeterminada.
espeak-ng -x
hello
Habla la palabra "hello" usando la voz de inglés predeterminada e imprime los fonemas que se
hablaron.
espeak-ng -ven-us "[[h@'loU]
]"
Habla los fonemas "h@'loU" usando la voz de inglés
estadounidense.
espeak-ng
--voices
Lista todas las voces soportadas por
eSpeak.
espeak-ng
--voices=en
Lista todas las voces que hablan inglés (en)
.
espeak-ng
--voices=mb
Lista todas las
voces que usan
el sintetizador
de voz MBROLA.
