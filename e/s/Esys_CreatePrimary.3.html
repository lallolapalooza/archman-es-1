Función de Llamada Única para TPM2_CreatePrimar

y

Esta función invoca el comando TPM2_CreatePrimary en una variante de llamada única. Esto significa que la función se bloqueará hasta que la respuesta del TPM esté disponible. Todos los parámetros de entrada son const. La memoria para los parámetros de salida no simples es asignada por la implementación de la

función.

Parámetro

s
esysContext El ESYS_CONTEXT.
primaryHandle TPM2_RH_ENDORSEMENT, TPM2_RH_OWNER, TPM2_RH_PLATFORM+{PP}, o TPM2_RH_NULL.
shandle1 Manipulador de sesión para la autorización de primaryHandle
shandle2 Segundo manipulador de sesión.
shandle3 Tercer manipulador de sesión.
inSensitive Los datos sensibles, véase TPM 2.0 Parte 1 Valores Sensibles.
inPublic La plantilla pública.
outsideInfo Datos que serán incluidos en los datos de creación para este objeto para proporcionar un enlace permanente y verificable entre este objeto y algunos datos del propietario del objeto.
creationPCR PCR que será usada en los datos de creación.
outPublic La porción pública del objeto creado. (asignado por el receptor)
creationData Contiene un TPMT_CREATION_DATA. (asignado por el receptor)
creationHash Resumen de creationData usando el nameAlg de outPublic. (asignado por el receptor)
creationTicket Boleto usado por TPM2_CertifyCreation() para validar que los datos de creación fueron producidos por el TPM. (asignado por el receptor)
objectHandle Manipulador ESYS_TR del recurso ESYS para
TPM2_HANDLE.

Valores de

Retorno
TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_ESYS_RC_BAD_REFERENCE si el esysContext o los punteros de entrada requeridos o las referencias de manipuladores de salida requeridos son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_RSP_AUTH_FAILED si el HMAC de respuesta del TPM no verificó.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si cualquiera de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.

Función Asíncrona para TPM2_CreatePrimar

y

Esta función invoca el comando TPM2_CreatePrimary en una variante asíncrona. Esto significa que la función retornará tan pronto como el comando haya sido enviado hacia abajo por la pila al TPM. Todos los parámetros de entrada son const. Para obtener la respuesta del TPM, llame a Esys_CreatePrimary_Finish

.

shandle2 Segundo manipulador de sesión.

creación.
