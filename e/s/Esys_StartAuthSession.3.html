Función de una sola llamada para TPM2_StartAuthSessio

n

Esta función invoca el comando TPM2_StartAuthSession en una variante de una sola llamada. Esto significa que la función se bloqueará hasta que la respuesta del TPM esté disponible. Todos los parámetros de entrada son const. La memoria para los parámetros de salida no simples es asignada por la implementación de la

función.

Parámetro

s
esysContext El ESYS_CONTEXT.
tpmKey Manija de una clave de descifrado cargada utilizada para cifrar la sal.
bind Entidad que proporciona el authValue.
shandle1 Primera manija de sesión.
shandle2 Segunda manija de sesión.
shandle3 Tercera manija de sesión.
nonceCaller nonceCaller inicial, establece el tamaño de nonceTPM para la sesión.
sessionType Indica el tipo de la sesión; HMAC simple o política (incluyendo una política de prueba).
symmetric El algoritmo y el tamaño de clave para el cifrado de parámetros.
authHash Algoritmo hash a utilizar para la sesión.
sessionHandle Manija ESYS_TR del recurso ESYS para TPMI_SH_AUTH_SESSION
.

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_ESYS_RC_BAD_REFERENCE si el esysContext o los punteros de entrada requeridos o las referencias de manija de salida requeridas son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en el esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_RSP_AUTH_FAILED si el HMAC de respuesta del TPM no se verificó.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si alguno de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.
