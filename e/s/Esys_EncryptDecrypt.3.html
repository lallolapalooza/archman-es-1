Función de una sola llamada para TPM2_EncryptDecryp

t

Esta función invoca el comando TPM2_EncryptDecrypt en una variante de una sola llamada. Esto significa que la función se bloqueará hasta que la respuesta del TPM esté disponible. Todos los parámetros de entrada son const. La memoria para los parámetros de salida no simples es asignada por la implementación de la

función.

Parámetro

s
esysContext El ESYS_CONTEXT.
keyHandle La clave simétrica utilizada para la operación.
shandle1 Manejo de sesión para la autorización de keyHandle
shandle2 Segundo manejo de sesión.
shandle3 Tercer manejo de sesión.
decrypt Si es YES, entonces la operación es descifrado; si es NO, la operación es cifrado.
mode Modo simétrico.
ivIn Un valor inicial como lo requiere el algoritmo.
inData Los datos a ser cifrados/descifrados.
outData Salida cifrada o descifrada. (asignada por el llamante)
ivOut Valor de encadenamiento a usar para el IV en la siguiente ronda. (asignada por el
llamante)

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext o los punteros de entrada requeridos o las referencias de manejo de salida requeridas son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de la respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_RSP_AUTH_FAILED si el HMAC de respuesta del TPM no se verificó.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si alguno de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si una de las sesiones tiene el atributo 'decrypt' establecido y el comando no soporta el cifrado del primer parámetro del comando.
