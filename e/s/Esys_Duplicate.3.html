Función de una sola llamada para

TPM2_Duplicate

Esta función invoca el comando TPM2_Duplicate en una variante de una sola llamada. Esto significa que la función se bloqueará hasta que la respuesta del TPM esté disponible. Todos los parámetros de entrada son const. La memoria para los parámetros de salida no simples es asignada por la implementación de la

función.

Parámetro

s
esysContext El ESYS_CONTEXT.
objectHandle Objeto cargado para duplicar.
newParentHandle Debe referenciar el área pública de una clave asimétrica.
shandle1 Manejo de sesión para la autorización de objectHandle
shandle2 Segundo manejo de sesión.
shandle3 Tercer manejo de sesión.
encryptionKeyIn Clave de cifrado simétrico opcional.
symmetricAlg Definición del algoritmo simétrico a utilizar para el envoltorio interno.
encryptionKeyOut TPM2_Si el llamador proporcionó una clave de cifrado o si symmetricAlg fue TPM2_ALG_NULL, entonces este será el TPM2_Empty TPM2_Buffer; de lo contrario, debe contener la clave de cifrado simétrico generada por el TPM2_TPM para el envoltorio interno.. (asignado por el receptor)
duplicate Área privada que puede ser cifrada por encryptionKeyIn; y puede ser cifrada doblemente. (asignado por el receptor)
outSymSeed Semilla protegida por los algoritmos asimétricos del nuevo padre (NP). (asignado por el
receptor)

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext o los punteros de entrada requeridos o las referencias de manejo de salida requeridas son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de la respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_RSP_AUTH_FAILED si el HMAC de respuesta del TPM no se verificó.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si alguno de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.

Función asíncrona para

TPM2_Duplicate

Esta función invoca el comando TPM2_Duplicate en una variante asíncrona. Esto significa que la función retornará tan pronto como el comando haya sido enviado hacia abajo por la pila al TPM. Todos los parámetros de entrada son const. Para recuperar la respuesta del TPM, llame a Esys_Duplicate_Finish

shandle3 Tercer manejo de sesión.
encryptionKeyIn Clave de cifrado simétrico opcional.
symmetricAlg Definición del algoritmo simétrico a utilizar para el envoltorio
interno.
