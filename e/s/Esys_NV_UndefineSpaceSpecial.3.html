Descripción detallada

Función ESAPI para invocar el comando TPM2_NV_UndefineSpaceSpecial ya sea como una sola llamada o de manera asíncrona.

Documentación de la función

TSS2_RC Esys_NV_UndefineSpaceSpecial (ESYS_CONTEXT * esysContext, ESYS_TR nvIndex, ESYS_TR platform, ESYS_TR shandle1, ESYS_TR shandle2, ESYS_TR shandle3)

Función de una sola llamada para TPM2_NV_UndefineSpaceSpecial

Esta función invoca el comando TPM2_NV_UndefineSpaceSpecial en una variante de una sola llamada. Esto significa que la función se bloqueará hasta que la respuesta del TPM esté disponible. Todos los parámetros de entrada son const. La memoria para los parámetros de salida no simples es asignada por la implementación de la función.

Parámetros

esysContext El ESYS_CONTEXT.
nvIndex Índice a ser eliminado.
platform TPM2_RH_PLATFORM + {PP}.
shandle1 Manejador de sesión para la autorización de nvIndex
shandle2 Manejador de sesión para la autorización de platform
shandle3 Tercer manejador de sesión.

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_ESYS_RC_BAD_REFERENCE si esysContext o los punteros de entrada requeridos o las referencias de manejador de salida requeridas son NULL.
TSS2_ESYS_RC_BAD_CONTEXT si se detecta corrupción en esysContext.
TSS2_ESYS_RC_MEMORY si la ESAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_ESYS_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_ESYS_RC_INSUFFICIENT_RESPONSE si la respuesta del TPM no contiene al menos la etiqueta, la longitud de respuesta y el código de respuesta.
TSS2_ESYS_RC_MALFORMED_RESPONSE si la respuesta del TPM está corrupta.
TSS2_ESYS_RC_RSP_AUTH_FAILED si el HMAC de respuesta del TPM no se verificó correctamente.
TSS2_ESYS_RC_MULTIPLE_DECRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'decrypt' establecido.
TSS2_ESYS_RC_MULTIPLE_ENCRYPT_SESSIONS si más de una sesión tiene el bit de atributo 'encrypt' establecido.
TSS2_ESYS_RC_BAD_TR si alguno de los objetos ESYS_TR es desconocido para el ESYS_CONTEXT o son del tipo incorrecto o si los objetos ESYS_TR requeridos son ESYS_TR_NONE.
TSS2_ESYS_RC_NO_DECRYPT_PARAM si una de las sesiones tiene el atributo 'decrypt' establecido y el comando no soporta el cifrado del primer parámetro del comando.
TSS2_ESYS_RC_NO_ENCRYPT_PARAM si una de las sesiones tiene el atributo 'encrypt' establecido y el comando no soporta el cifrado del primer parámetro de respuesta.
TSS2_RCs producidos por capas inferiores de la pila de software pueden ser devueltos al llamador sin alterar a menos que se manejen internamente.
