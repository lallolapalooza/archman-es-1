DESCRIPCIÓ

N

esh (embedded shell) es un motor de plantillas para evaluar comandos de shell incrustados en plantillas arbitrarias. Es como ERB (Embedded RuBy) para shell, destinado a ser utilizado para la creación de plantillas de archivos de configuración. A diferencia de ERB, proporciona soporte para incluir una plantilla ESH en otra (desde la versión 0.2.0)

.

esh convierte el archivo de plantilla, o stdin si archivo es “-”, en una secuencia de comandos de shell. Los comandos entre <% y %> etiquetas se pasan tal cual, todo lo demás se escapa y se le antepone el comando printf. Estos comandos se evalúan finalmente usando shell (a menos que -d se es

pecif
ique).

SINTAXIS DE

PLANTILLA

ESH tiene dos etiquetas para código de shell, una etiqueta para inclusión, comentarios y una forma de escapar los delimitadores de

etiqueta.

<% comandos

%>
Ejecuta los comandos y reemplaza esta etiqueta con su salida en stdout
.

<%= valores

%>
Ejecuta printf '%s ' con los valores como argumentos y reemplaza esta etiqueta con la salida (sin espacio en blanco final). Los valores no se entrecomillan ni se escapan, por lo que se aplican todas las sustituciones de
shell.

<%+ nombre_archivo

%>
Lee y convierte la plantilla ESH desde el nombre_archivo y la coloca en lugar de esta etiqueta. Las inclusiones se procesan recursivamente, pero la profundidad está limitada por ESH_MAX_DEPTH.

Si el nombre_archivo es relativo, se resuelve contra el directorio del archivo de plantilla en el que se encuentra esta etiqueta. Si la plantilla se lee desde stdin, las inclusiones de primer nivel se resuelven contra el directorio de trabajo actual. Tenga en cuenta que las inclusiones se procesan durante la conversión, no en la fase de evaluación, por lo que el nombre_archivo no puede ser una expresión ni una

variable.

A diferencia de las demás, esta etiquet

a debe cerrarse en la misma línea, d
e lo contrario es un error de sintaxis.

<%# comentario

%>
Se elimina de la salida
final.

-%

>
Puede usarse en lugar de %>. Elimina el salto de línea siguiente si se usa al final de la línea, de lo contrario no tiene efecto de
eliminación.

<%

%
Un <% literal cuando se usa fuera de las etiquetas
anteriores.

%%

>
Un %> literal cuando se usa dentro de las etiquetas
anteriores.

La etiqueta de apertura y cierre no puede estar en la misma

línea.

El texto fuera de una etiqueta se convierte en texto literal, pero está sujeto a cualquier código de shell etiquetado que lo rodee. Por ejemplo, el texto rodeado por una declaración if etiquetada solo aparece en la salida si

la condición
es verdadera.

EJEMPLO

S

nginx.conf.

esh 
http {
    access_log <%= $logs_dir/access.log %> main;
    resolver <%= $(sed -En 's/^nameserver ([^#]+)/\1/p' /etc/resolv.conf) %>;
    <% if nginx -V 2>&1 | grep -q lua-nginx-module; then -%>
    lua_package_path '<%= $(pkg-config --variable=INSTALL_LMOD lua) %>/?.lua';
    <% fi -%>
    <%+ ./http-common.esh %>
    <%# El resto de la configuración se omite %>
}

ejecute: 
esh -o nginx.conf nginx.conf.esh logs_dir=/var/log/ng
