EOM(1) Manual de comandos generales EOM(1)

NOMBRE

eom - El Ojo de MATE Visor de Imágenes

SINOPSIS

eom [--fullscreen] [--disable-image-collection] [--slide-show] [--new instance] [ARCHIVOS...]

DESCRIPCIÓN

eom o El Ojo de MATE es el visor de imágenes oficial del Entorno de Escritorio MATE. Su objetivo es ser simplista, ligero y fácil de usar. El Ojo de MATE también puede ser utilizado para realizar tareas básicas como voltear y rotar imágenes.

El Ojo de MATE presenta un sistema de plugins flexible que puede ser utilizado para añadir dinámicamente nuevas características avanzadas al propio eom. eom utiliza la biblioteca gdk-pixbuf, puede manejar imágenes grandes, hacer zoom y desplazarse con bajo uso de memoria.

Esta página del manual documenta brevemente el comando eom.

OPCIONES

nombre de archivo(s)...
Especifica la imagen a abrir cuando se inicia eom. Si esto no se especifica, eom se iniciará con una ventana en blanco y podrá abrir un archivo desde el menú o usando el atajo CTRL+O. eom también soporta el manejo de archivos remotos.
--display=PANTALLA
Pantalla X a usar.
-f, --fullscreen
Inicia eom en modo de pantalla completa.
-c, --disable-image-collection
Deshabilita el visor de colección de imágenes.
-s, --slide-show
Abre en modo presentación.
-n, --new-instance
Inicia una nueva instancia en lugar de reutilizar una ventana existente.
--version
Muestra la información de la versión y sale.
-h, --help
Imprime las opciones estándar de la línea de comandos.
--help-all
Imprime todas las opciones de la línea de comandos.

Este programa también acepta las opciones estándar de GTK.

EJEMPLOS

eom -f http://mate-desktop.org/assets/img/icons/mate.png

Abre el archivo referenciado en modo de pantalla completa.

eom -s /usr/share/eom/icons/hicolor/scalable/actions

Abre las imágenes en el directorio referenciado en modo presentación.
