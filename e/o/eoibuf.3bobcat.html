FBB::EoiBuf(3bobcat) Clase base de fin de información FBB::EoiBuf(3bobcat)

NOMBRE

FBB::EoiBuf - clase std::streambuf que ofrece un manipulador eoi

SINOPSIS

#include <bobcat/eoibuf>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

La clase EoiBuf hereda de Eoi y por lo tanto puede usarse como clase base de clases que especializan std::streambuf. También proporciona un búfer de caracteres configurable para almacenar caracteres recibidos de sus dispositivos. A menudo, al derivar clases de std::streambuf las clases derivadas deben implementar el almacenamiento en y la recuperación de un búfer de caracteres. Al derivar de EoiBuf el manejo del búfer se proporciona automáticamente: contiene un búfer de caracteres (redimensionable) y ofrece un miembro setp así como un miembro setg que pueden usarse para especificar el rango de índices del búfer del cual las extracciones reciben caracteres. Además, al sobreescribir su miembro de clase base eoi_ puede usarse para señalar el final de la entrada insertada en clases std::ostream usando objetos EoiBuf como objetos std::streambuf .

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual se definen en el espacio de nombres FBB.

HEREDA DE

FBB::Eoi (y por lo tanto de: std::streambuf)

CONSTRUCTOR PROTEGIDO

Análogamente a std::streambuf solo están disponibles constructores protegidos.

o
EoiBuf():
El constructor por defecto inicializa un búfer vacío.
o
EoiBuf(size_t size):
Esto inicializa un búfer vacío de un tamaño predefinido de size caracteres.

Nótese que no hay un límite inherente al tamaño del búfer interno: su tamaño siempre puede ampliarse o reducirse.

No están disponibles constructores de copia y de movimiento (ni operadores de asignación).

FUNCIONES DE MIEMBRO PROTEGIDAS

Todos los miembros de std:streambuf y de Eoi están disponibles, ya que FBB::EoiBuf hereda de estas clases.

o
std::string &buffer():
Se devuelve una referencia al búfer interno;
o
size_t bufSize() const:
Se devuelve la longitud (tamaño) del búfer interno;
o
void resize(size_t size):
El tamaño del búfer interno se cambia a size caracteres;
o
void setg(unsigned next, unsigned beyond):
El miembro streambuf::eback devuelve la dirección del primer carácter del búfer interno, streambuf::gptr devuelve la dirección del carácter next del búfer interno, streambuf::egptr devuelve la dirección del carácter beyond del búfer interno;
o
void setp():
Los miembros streambuf::pbase y pptr devuelven la dirección del primer carácter del búfer interno, streambuf::epptr devuelve la dirección inmediatamente más allá del último carácter del búfer interno;
o
unsigned char *ucharPtr():
Se devuelve la dirección del primer carácter del búfer interno como un puntero a un carácter sin signo;
o
unsigned char const *ucharPtr() const:
Igual que el miembro anterior, pero en este caso la dirección del primer carácter del búfer interno se devuelve como un puntero a un carácter sin signo inmutable.

FUNCIONES ESTÁTICAS DE MIEMBRO PROTEGIDAS

Los siguientes dos miembros estáticos se proporcionan como funciones convenientes para que las clases derivadas conviertan la dirección del primer carácter de objetos std::string a punteros a caracteres sin signo:

o
unsigned char *ucharPtr(std::string &str):
La dirección del primer carácter de str se devuelve como un puntero a un carácter sin signo;
o
unsigned char const *ucharPtr(std::string const &str) const:
Igual que el miembro anterior, pero en este caso la dirección del primer carácter de str se devuelve como un puntero a un carácter sin signo inmutable.

EJEMPLO

Las siguientes dos funciones se definen en la clase (usada internamente solamente) FBB::OSymCryptBase, que es la clase base de osymcryptstreambuf(3bobcat).

o
evpUpdate actualiza el cifrado o descifrado en curso, p. ej., usando la función de openssl EVP_EncryptUpdate, usando ucharPtr para acceder a los caracteres actualmente en el búfer de EoiBuf :
#include "osymcryptbase.ih"
void OSymCryptBase::evpUpdate()
{
    size_t inBufRead = pptr() - pbase();    // # read chars
    checkOutBufSize(inBufRead);
    int nOutputChars;
    if (not ((*d_evpUpdate)(                // en/decrypt the bytes in d_inBuf
            ctx(),
            uOutBuf(), &nOutputChars,
            ucharPtr(), inBufRead
        ))
    )
        throw Exception{} << "EVP_{En,De}cryptUpdate failed";
    d_outStream.write(outBuf(), nOutputChars);      // write the processed
                                                    // chars to d_outSteam
    setp();
}
o
eoi_ sobreescribe la función FBB::Eoi::eoi_() , impidiendo que nueva información sea insertada en el objeto FBB::OSymCryptBase (y por lo tanto en su clase derivada FBB::OSymCryptStreambuf ):
#include "osymcryptbase.ih"
void OSymCryptBase::eoi_()
{
    if (d_eoi)
        return;
    evpUpdate();                // process available chars in the input
    d_eoi = true;
    resize(0);                  // clear the input buffer
    evpUpdate();                // update an empty buffer
}
