eof(n) Comandos integrados de Tcl eof(n)

NOMBRE

eof - Comprueba la condición de fin de archivo en el canal

SINOPSIS

eof idCanal

DESCRIPCIÓN

Devuelve 1 si se produjo una condición de fin de archivo durante la operación de entrada más reciente en idCanal (como por ejemplo gets), y 0 en caso contrario.

IdCanal debe ser un identificador de un canal abierto, como un canal estándar de Tcl (stdin, stdout o stderr), el valor de retorno de una invocación de open o socket, o el resultado de un comando de creación de canal proporcionado por una extensión de Tcl.

EJEMPLOS

Leer e imprimir el contenido de un archivo línea por línea:

set f [open somefile.txt]
while {1} {
    set line [gets $f]
    if {[eof $f]} {
        close $f
        break
    }
    puts "Leída línea: $line"
}

Leer e imprimir el contenido de un archivo por registros de tamaño fijo:

set f [open somefile.dat]
fconfigure $f -translation binary
set recordSize 40
while {1} {
    set record [read $f $recordSize]
    if {[eof $f]} {
        close $f
        break
    }
    puts "Registro leído: $record"
}

VER TAMBIÉN

file(n), open(n), close(n), fblocked(n), Tcl_StandardChannels(3)

PALABRAS CLAVE

canal, fin de archivo
