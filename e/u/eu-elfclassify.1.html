EU-ELFCLASSIFY(1) Manual de Comandos Generales EU-ELFCLASSIFY(1)

NOMBRE

eu-elfclassify - Determina el tipo de un archivo ELF.

SINOPSIS

eu-elfclassify [--core]
[--debug-only]
[--elf]
[--elf-archive]
[--elf-file]
[--executable]
[--library]
[--linux-kernel-module]
[--loadable]
[--program]
[--shared]
[--unstripped]
[-f| --file]
[--no-stdin]
[--stdin]
[--stdin0]
[-z| --compressed]
[--matching]
[--no-print]
[--not-matching]
[--print]
[--print0]
[-q| --quiet]
[-v| --verbose]
[-?| --help]
[--usage]
[-V| --version] archivo_elf...

DESCRIPCIÓN

eu-elfclassify identifica el propósito principal de un tipo particular de
archivo ELF o archivos.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes. Todas las opciones de clasificación deben aplicarse al mismo tiempo a un archivo en particular. Las opciones de clasificación se pueden negar usando un prefijo --not-.

Opciones de clasificación

--core
El archivo es un archivo de volcado de núcleo ELF.
--debug-only
El archivo es solo para depuración ELF (múltiples archivos .debug, .dwo o dwz separados).
--elf
El archivo parece un objeto ELF o un archivo/biblioteca estática (predeterminado).
--elf-archive
El archivo es un archivo ELF o una biblioteca estática.
--elf-file
El archivo es un objeto ELF regular (no un archivo/biblioteca estática).
--executable
El archivo es (principalmente) un ejecutable de programa ELF (no es principalmente un DSO).
--library
El archivo es un objeto compartido ELF (DSO) (podría ser también un ejecutable).
--linux-kernel-module
El archivo es un módulo del kernel de Linux.
--loadable
El archivo es un objeto ELF cargable (programa u objeto compartido).
--program
El archivo es un ejecutable de programa ELF (podría ser también un DSO).
--shared
El archivo es (principalmente) un objeto compartido ELF (DSO) (no es principalmente un ejecutable).
--unstripped
El archivo es un archivo ELF con tabla de símbolos o secciones .debug_* y puede ser despojado adicionalmente.

Indicadores de entrada

-f
--file
Solo clasifica archivos regulares (no enlaces simbólicos ni dispositivos especiales).
--no-stdin
No lee archivos de la entrada estándar (predeterminado).
--stdin
También lee nombres de archivo para procesar de la entrada estándar, separados por saltos de línea.
--stdin0
También lee nombres de archivo para procesar de la entrada estándar, separados por bytes NUL ASCII.
-z
--compressed
Intenta abrir archivos comprimidos o imágenes ELF incrustadas (del kernel).

Indicadores de salida

--matching
Si se imprimen nombres de archivo, imprime los archivos coincidentes (predeterminado).
--no-print
No emite nombres de archivo.
--not-matching
Si se imprimen nombres de archivo, imprime los archivos que no coinciden.
--print
Nombres de salida de archivos, separados por saltos de línea.
--print0
Nombres de salida de archivos, separados por NUL ASCII.

Indicadores adicionales

-q
--quiet
Suprime parte de la salida de error (contraparte de --verbose).
-v
--verbose
Emite información adicional (se puede especificar varias veces).
-?
--help
Proporciona esta lista de ayuda.
--usage
Proporciona un mensaje de uso corto.
-V
--version
Imprime la versión del programa.
