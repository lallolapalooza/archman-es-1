euidaccess(3) Manual de Funciones de Biblioteca euidaccess(3)

NOMBRE

euidaccess, eaccess - comprobar los permisos del usuario efectivo para un archivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE             /* Véase feature_test_macros(7) */
#include <unistd.h>
int euidaccess(const char *path, int mode);
int eaccess(const char *path, int mode);

DESCRIPCIÓN

Al igual que access(2), euidaccess() comprueba los permisos y la existencia del archivo identificado por su argumento path. Sin embargo, mientras que access(2) realiza comprobaciones utilizando los identificadores reales de usuario y grupo del proceso, euidaccess() utiliza los identificadores efectivos.

mode es una máscara que consiste en uno o más de R_OK, W_OK, X_OK y F_OK, con los mismos significados que para access(2).

eaccess() es un sinónimo de euidaccess(), proporcionado para compatibilidad con otros sistemas.

VALOR DE RETORNO

En caso de éxito (se conceden todos los permisos solicitados), se devuelve cero. En caso de error (al menos un bit en mode solicitó un permiso que se deniega, o ocurrió algún otro error), se devuelve -1, y errno se establece para indicar el error.

ERRORES

Como en access(2).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
euidaccess (), eaccess () Seguridad en hilos MT-Safe

VERSIONES

Otros sistemas tienen una función eaccess().

ESTANDARES

Ninguno.

HISTORIA

eaccess()
glibc 2.4.

NOTAS

Advertencia: Usar esta función para comprobar los permisos de un proceso sobre un archivo antes de realizar alguna operación basada en esa información conduce a condiciones de carrera: los permisos del archivo pueden cambiar entre los dos pasos. Generalmente, es más seguro simplemente intentar la operación deseada y manejar cualquier error de permiso que ocurra.

Esta función siempre desreferencia los enlaces simbólicos. Si necesita comprobar los permisos de un enlace simbólico, use faccessat(2) con las banderas AT_EACCESS y AT_SYMLINK_NOFOLLOW.

VER TAMBIÉN
