NOMBRE

enscript - convierte archivos de texto a PostScript, HTML, RTF, ANSI y sobrescrituras

SINOPSIS

enscript [-123456789BcgGhjkKlmOqrRvVzZ] [-# copias] [-a páginas] [-A alineación] [-b encabezado] [-C[línea_inicio]] [-d impresora] [-D clave[:valor]] [-e[carácter]] [-E[idioma]] [-f fuente] [-F fuente_encabezado] [-H[num]] [-i sangría] [-I filtro] [-J título] [-L líneas_por_página] [-M medio] [-n copias] [-N nueva_línea] [-o archivo_salida] [-o -] [-p archivo_salida] [-p -] [-P impresora] [-s espaciado_líneas] [-S clave[:valor]] [-t título] [-T tamaño_tab] [-u[texto]] [-U num] [-w idioma] [-X codificación] [nombre_archivo ...]

DESCRIPCIÓN

Enscript convierte archivos de texto a PostScript u otros lenguajes de salida. Enscript puede enviar la salida generada directamente a una impresora especificada o dejarla en un archivo. Si no se proporcionan archivos de entrada, enscript procesa la entrada estándar stdin. Enscript puede extenderse para manejar diferentes medios de salida y tiene muchas opciones que se pueden usar para personalizar las impresiones.

OPCIONES

-# num
Imprime num copias de cada página.
-1, -2, -3, -4, -5, -6, -7, -8, -9, --columnas=num
Especifica cuántas columnas tendrá cada página. Con la opción larga --columnas=num puedes especificar más de 9 columnas por página.
-a páginas, --paginas=páginas
Especifica qué páginas se imprimen. La especificación de página páginas puede darse en los siguientes formatos:
inicio-fin
imprime páginas desde inicio hasta fin
-fin
imprime páginas desde 0 hasta fin
inicio-
imprime páginas desde inicio hasta el final
página
imprime la página página
impar
imprime páginas impares
par
imprime páginas pares
-A alineación, --alineacion-archivo=alineación
Alinea archivos de entrada separados a un recuento par de páginas de alineación. Esta opción es útil en impresiones a doble cara y 2-up (--alineacion-archivo=2).
-b encabezado, --encabezado=encabezado
Usa el texto encabezado como encabezado de página. El encabezado de página predeterminado se construye a partir del nombre del archivo y de su última fecha de modificación.

La cadena de encabezado encabezado puede contener las mismas secuencias de formato que se pueden especificar para las directivas %Format en los encabezados elegantes definidos por el usuario. Por ejemplo, la siguiente opción imprime el nombre del archivo, la fecha actual y los números de página:

enscript --encabezado='$n %W Página $% de $=' *.c

La cadena de encabezado también puede contener campos justificados a la izquierda, al centro y a la derecha. Los campos están separados por el carácter '|':

enscript --encabezado='$n|%W|Página $% de $=' *.c

Ahora el nombre del archivo se imprime justificado a la izquierda, la fecha está centrada en el encabezado y los números de página se imprimen justificados a la derecha.

-B, --sin-encabezado
No imprimir encabezados de página.
-c, --cortar-lineas
Cortar líneas que son demasiado largas para la página. Por defecto, enscript envuelve las líneas largas a la siguiente línea para que no se pierda información.

También puedes usar la opción --rebanar que divide las líneas largas en páginas separadas.

-C[línea_inicio], --numeros-linea[=línea_inicio]
Anteponer a cada línea su número de línea. El argumento opcional línea_inicio especifica el número de la primera línea en la entrada. El número de la primera línea es 1 por defecto.
-d nombre
Enviar la salida a la impresora nombre.
-D clave[:valor], --setpagedevice=clave[:valor]
Pasar una definición de dispositivo de página a la salida PostScript generada. Si no se proporciona ningún valor, la clave clave se elimina de las definiciones.

Por ejemplo, el comando

enscript -DDuplex:true foo.txt

imprime el archivo foo.txt en modo dúplex (doble cara).

Los operadores del dispositivo de página dependen de la implementación, pero están estandarizados. Consulte la sección OPCIONES DE DISPOSITIVO DE PÁGINA para ver los detalles.

-e[carácter], --escapes[=carácter]
Habilitar la interpretación de escapes especiales (ver sección ESCAPES ESPECIALES). Si se proporciona el argumento carácter, cambia el carácter de escape a carácter. El carácter de escape predeterminado es 0.
-E[idioma], --resaltar[=idioma]
Resaltar el código fuente creando un filtro de entrada especial con el programa states. El argumento opcional idioma especifica el idioma a resaltar. Por defecto, states hace una suposición informada.

Puedes imprimir una breve descripción de los idiomas de resaltado y formatos de archivo compatibles con el comando:

enscript --help-highlight

Las reglas de resaltado se definen en los archivos `/usr/share/enscript/hl/*.st' que pueden editarse para crear definiciones de resaltado para nuevos idiomas.

¡Nota! No puedes usar tus propios filtros de entrada con esta opción.

-f nombre, --fuente=nombre
Selecciona una fuente que se utiliza para el texto del cuerpo. La fuente predeterminada para el cuerpo es Courier10, a menos que se seleccione el modo de impresión en paisaje multicanal, en cuyo caso la fuente predeterminada es Courier7.

La especificación de fuente nombre contiene dos partes: el nombre de la fuente y su tamaño en puntos PostScript. Por ejemplo, "Times-Roman12" selecciona la fuente "Times-Roman" con tamaño 12pt.

La especificación de fuente nombre también se puede dar en el formato `nombre@tamaño_pt', donde el nombre de la fuente y su tamaño en puntos están separados por un carácter '@'. Esto permite a enscript usar fuentes que contienen caracteres numéricos en sus nombres.

El tamaño de la fuente en puntos también se puede dar en el formato ancho/alto donde ancho y alto especifican el tamaño de la fuente en las direcciones x e y. Por ejemplo, "Times-Roman@10/12" selecciona una fuente "Times-Roman" de 10 puntos de ancho y 12 puntos de alto.

También puedes dar los tamaños de fuente como números decimales. Por ejemplo, "Times-Roman10.2" selecciona una fuente "Times-Roman" de 10.2pt.

-F nombre, --fuente-encabezado=nombre
Selecciona una fuente para los textos del encabezado.
-g, --imprimir-de-todas-formas
Imprimir un archivo incluso si contiene datos binarios. La opción solo se implementa con fines de compatibilidad. Enscript imprime archivos binarios de todos modos, independientemente de la opción.
-G, --encabezado-elegante[=nombre]
Imprime un encabezado de página elegante nombre en la parte superior de cada página. La opción -G especifica el encabezado elegante predeterminado. Consulte la sección ARCHIVOS DE CONFIGURACIÓN para ver cómo se puede cambiar el encabezado elegante predeterminado.
-h, --sin-encabezado-trabajo
Suprimir la impresión de la página de encabezado del trabajo.
-H[num], --barras-resaltadas[=num]
Especifica qué tan altas son las barras de resaltado en líneas. Si el num no se proporciona, se usa el valor predeterminado de 2. Por defecto, no se imprimen barras de resaltado.
-i num, --indentar=num
Indenta cada línea num caracteres. La indentación también se puede especificar en otras unidades añadiendo un especificador de unidad después del número. Los especificadores de unidad posibles y las unidades correspondientes son:
c
centímetros
i
pulgadas
l
caracteres (predeterminado)
p
puntos PostScript
-I filtro, --filtro=filtro
Lee todos los archivos de entrada a través de un filtro de entrada filtro. El filtro de entrada puede ser un comando único o una tubería de comandos. El filtro puede hacer referencia al nombre del archivo de entrada con el escape `%s'. El nombre de la entrada estándar se puede cambiar con la opción `--filtro-stdin'.

Por ejemplo, el siguiente comando imprime el archivo `foo.c' utilizando únicamente caracteres en mayúsculas:

enscript --filtro="cat %s | tr 'a-z' 'A-Z'" foo.c

El siguiente comando resalta los cambios realizados en los archivos desde el último checkout:

enscript --filtro="rcsdiff %s | diffpp %s" -e *.c

Para incluir la cadena "%s" en el comando de filtro, debe escribirla como "%%s".

-j, --bordes
Imprime bordes alrededor de las columnas.
-J título
Un alias para la opción -t, --título.
-k, --pre-alimentacion-pagina
Habilita la pre-alimentación de página.
-K, --sin-pre-alimentacion-pagina
Deshabilita la pre-alimentación de página (predeterminado).
-l, --impresora-lineas
Emula una impresora de líneas. Esta opción es un atajo para las opciones --lineas-por-pagina=66 y --sin-encabezado.
-L num, --lineas-por-pagina=num
Imprime solo num líneas por página. Por defecto, el número de líneas por página se calcula a partir de la altura de la página y del tamaño de la fuente.
-m, --correo
Envía una notificación por correo al usuario después de que el trabajo de impresión se haya completado.
-M nombre, --medio=nombre
Selecciona un medio de salida nombre. El medio de salida predeterminado de Enscript es A4.
-n num, --copias=num
Imprime num copias de cada página.
-N nl, --nueva-linea=nl
Selecciona el carácter de nueva línea. Los valores posibles para nl son: n (nueva línea de Unix, 0xa hexadecimal) y r (nueva línea de Mac, 0xd hexadecimal).
-o archivo
Un alias para la opción -p, --salida.
-O, --caracteres-faltantes
Imprime una lista de códigos de caracteres que no se pudieron imprimir.
-p archivo, --salida=archivo
Deja la salida en el archivo archivo. Si el archivo es `-', enscript envía la salida a la salida estándar stdout.
-P nombre, --impresora=nombre
Envía la salida a la impresora nombre.
-q, --silencioso, --callado
Hace que enscript sea realmente silencioso. Solo se imprimen mensajes de error fatales en stderr.
-r, --horizontal
Imprime en modo horizontal; rota la página 90 grados.
-R, --vertical
Imprime en modo vertical (predeterminado).
-s num, --espacio-linea-base=num
Especifica el espacio de línea base en puntos PostScript. El número num puede darse como un número decimal. Cuando enscript se mueve de una línea a otra, la coordenada y del punto actual se mueve (tamaño de fuente en puntos + espacio de línea base) puntos hacia abajo. El espacio de línea base predeterminado es 1.
-S clave[:valor], --diccionario-estado=clave[:valor]
Pasa una definición de diccionario de estado a la salida PostScript generada. Si no se proporciona valor, se elimina la clave clave de las definiciones.

Los operadores del diccionario de estado dependen de la implementación; consulte la documentación de la impresora para obtener detalles.

Por ejemplo, el comando

enscript -Ssetpapertray:1 foo.txt

imprime el archivo foo.txt utilizando papel de la bandeja 1 (suponiendo que la impresora admita la selección de bandejas de papel).

-t título, --título=título
Establece el título del trabajo de la página de banner a título. La opción también establece el nombre del archivo de entrada stdin.
-T num, --tamaño-tab=num
Establece el tamaño del tabulador a num caracteres. El predeterminado es 8.
-u[texto], --subrayado[=texto]
Imprime la cadena texto debajo de cada página. Las propiedades del texto pueden modificarse con las opciones --angulo-sub, --fuente-sub, --gris-sub, --posicion-sub y --estilo-sub.

Si no se proporciona texto, el subrayado no se imprime. Esto puede usarse para eliminar un texto de subrayado que se especificó con la opción de archivo de configuración `Underlay'.

-U num, --nup=num
Imprime num páginas lógicas en cada página de salida (impresión N-up). El valor num debe ser una potencia de 2.
-v, --detallado[=nivel]
Indica qué está haciendo enscript.
-V, --version
Imprime la información de la versión de enscript y sale.

NAME

enscript - convert text files to PostScript, HTML or RTF

SYNOPSIS

DESCRIPTION

Enscript is a text-to-PostScript converter. It can be used to print text files. It supports features like:

  • Multiple columns per page.
  • Fancy headers and footers.
  • Page numbering.
  • Text highlighting.
  • Automatic code highlighting.
  • Outputting to a file or directly to a printer.
  • And many more.

It also supports generating the output in three different formats:

  • PostScript (level 1 or 2).
  • HTML.
  • RTF.

All features are configurable and can be turned off.

CONFIGURATION FILES

The configuration files are searched in the following order:

  • /etc/enscript.cfg
  • ~/.enscriptrc
  • ~/.enscript/

The last configuration file found is used. Options specified on the command line override options in the configuration files.

FANCY HEADERS

Fancy headers are specified using a special syntax. The header is divided into three parts: left-aligned, centered, and right-aligned. The syntax is:

lefttext
centertext
righttext

The text can contain PostScript code, character strings, or PostScript operators. The following PostScript variables are available:

Date
Current date.
Time
Current time.
User
Login name of the user.
Host
Name of the host machine.
File
Name of the file being printed.
Pages
Total number of pages.
Page
Current page number.
Lines
Total number of lines in the file.
Line
Current line number.

Example:

left\Date 0,\320,\320 center\Page Page\320of\320 Pages right\File

lnum
set image length to num
rnum
set image width to num
sxnum
scale image in x direction with factor num
synum
scale image in y direction with factor num

lines or characters (default)
p
PostScript points

For example to print an image one inch high, you can specify height by following options: h1i (1 inch), h2.54c (2.54 cm), h72p (72 points).

font
select current font. The syntax of the escape is:

^@font{fontname[:encoding]}

where fontname is a standard font specification. Special font specification default can be used to select the default body font (enscript's default or the one specified by the command line option -f, --font).

The optional argument encoding specifies the encoding that should be used for the new font. Currently the encoding can only be the enscript's global input encoding or ps.

ps
include raw PostScript code to the output. The syntax of the escape is:

^@ps{code}

shade
highlight regions of text by changing the text background color. Escape's syntax is:

^@shade{gray}

where gray is the new text background gray value. The default value is 1.0 (white) which disables highlighting.

PAGE DEVICE OPTIONS

Page device is a PostScript level 2 feature that offers an uniform interface to control printer's output device. Enscript protects all page device options inside an if block so they have no effect in level 1 interpreters. Although all level 2 interpreters support page device, they do not have to support all page device options. For example some printers can print in duplex mode and some can not. Refer to the documentation of your printer for supported options.

Here are some usable page device options which can be selected with the -D, --setpagedevice option. For a complete listing, see PostScript Language Reference Manual: section 4.11 Device Setup.

Collate boolean
how output is organized when printing multiple copies
Duplex boolean
duplex (two side) printing
ManualFeed boolean
manual feed paper tray
OutputFaceUp boolean
print output `face up' or `face down'
Tumble boolean
how opposite sides are positioned in duplex printing

PRINTING EXAMPLES

Following printing examples assume that enscript uses the default configuration. If default actions have been changed from the configuration files, some examples will behave differently.

enscript foo.txt
Print file foo.txt to the default printer.
enscript -Possu foo.txt
Print file foo.txt to printer ossu.
enscript -pfoo.ps foo.txt
Print file foo.txt, but leave PostScript output to file foo.ps.
enscript -2 foo.txt
Print file foo.txt to two columns.
enscript -2r foo.txt
Print file to two columns and rotate output 90 degrees (landscape).
enscript -DDuplex:true foo.txt
Print file in duplex (two side) mode (printer dependent).
enscript -G2rE -U2 foo.c
My default code printing command: gaudy header, two columns, landscape, code highlighting, 2-up printing.
enscript -E --color -whtml --toc -pfoo.html *.h *.c
A nice HTML report of your project's C source files.

ENVIRONMENT VARIABLES

The environment variable ENSCRIPT can be used to pass default options for enscript. For example, to select the default body font to be Times-Roman 7pt, set the following value to the ENSCRIPT environment variable:

-fTimes-Roman7

The value of the ENSCRIPT variable is processed before the command line options, so command line options can be used to overwrite these defaults.

Variable ENSCRIPT_LIBRARY specifies the enscript's library directory. It can be used to overwrite the build-in default `/usr/share/enscript'.

RETURN VALUE

Enscript returns value 1 to the shell if any errors were encountered or 0 otherwise. If the option --extended-return-values was specified, the return value is constructed from the following flags:

0
no errors or warnings
2
some lines were truncated or wrapped
4
some characters were missing from the used fonts
8
some characters were unprintable
