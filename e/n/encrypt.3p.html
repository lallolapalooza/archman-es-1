ENCRYPT(3P) Manual del programador POSIX ENCRYPT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación en Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

encrypt — función de codificación (CRYPT)

SINOPSIS

#include <unistd.h>
void encrypt(char block[64], int edflag);

DESCRIPCIÓN

La función encrypt() proporcionará acceso a un algoritmo de codificación definido por la implementación. La clave generada por setkey() se utiliza para cifrar la cadena block con encrypt().

El argumento block de encrypt() será un array de longitud 64 bytes que contenga solo los bytes con valores 0 y 1. El array se modifica in situ a un array similar utilizando la clave establecida por setkey(). Si edflag es 0, el argumento se codifica. Si edflag es 1, el argumento puede decodificarse (véase la sección USO POR APLICACIONES); si el argumento no se decodifica, se establecerá errno a [ENOSYS].

La función encrypt() no modificará el valor de errno si tiene éxito. Una aplicación que desee comprobar situaciones de error debe establecer errno a 0 antes de llamar a encrypt(). Si errno es distinto de cero al regresar, ha ocurrido un error.

La función encrypt() puede no ser segura para hilos.

VALOR DE RETORNO

La función encrypt() no devolverá ningún valor.

ERRORES

La función encrypt() fallará si:

ENOSYS
La funcionalidad no es compatible con esta implementación.

USO POR APLICACIONES

Las implementaciones históricas de la función encrypt() utilizaban un algoritmo de codificación bastante primitivo.

En algunos entornos, la decodificación podría no estar implementada. Esto está relacionado con algunas restricciones gubernamentales sobre rutinas de cifrado y descifrado. La práctica histórica ha sido distribuir una versión diferente de la biblioteca de cifrado sin la característica de decodificación en las rutinas suministradas. Por lo tanto, la versión exportada de encrypt() realiza codificación pero no decodificación.
