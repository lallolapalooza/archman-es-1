ENCFSCTL(1) Sistema de archivos cifrado ENCFSCTL(1)

NOMBRE

encfsctl - herramienta administrativa para trabajar con sistemas de archivos EncFS

SINOPSIS

encfsctl [comando argumentos_comando]

encfsctl [info] directorio_raiz

encfsctl passwd directorio_raiz

encfsctl showcruft directorio_raiz

encfsctl decode [--extpass=prog] directorio_raiz [nombre_cifrado ...]

encfsctl encode [--extpass=prog] directorio_raiz [nombre_texto_plano ...]

encfsctl cat [--extpass=prog] [--reverse] directorio_raiz <(cifrado|plano) nombre_archivo>

DESCRIPCIÓN

encfsctl es una herramienta administrativa para trabajar con sistemas de archivos EncFS. Es capaz de cambiar la contraseña proporcionada por el usuario, mostrar información básica sobre un volumen cifrado y otras operaciones relacionadas.

COMANDOS

info
Muestra información básica sobre el sistema de archivos. Toma un único argumento, directorio_raiz, que es el directorio raíz del sistema de archivos cifrado. El sistema de archivos no necesita estar montado. Info es también el comando predeterminado si solo se proporciona un directorio raíz en la línea de comandos.
passwd
Permite cambiar la contraseña del sistema de archivos cifrado. Se le pedirá al usuario la contraseña actual y la nueva contraseña.
showcruft
Busca recursivamente en todo el volumen y muestra todos los archivos que no se pueden decodificar (solo comprueba la codificación del nombre de archivo, no las cabeceras MAC de los bloques). Esto puede ser útil para la limpieza en caso de que hayas utilizado funciones que crean archivos que no son decodificables bajo la clave principal.
decode
Te permite especificar un nombre codificado en la línea de comandos y muestra la versión decodificada. Esto es principalmente útil para la depuración, ya que los mensajes de depuración siempre muestran nombres de archivo cifrados (para evitar fugas de datos sensibles a través de los canales de depuración). Por lo tanto, este comando proporciona una forma de decodificar los nombres de archivo.

La opción --extpass se puede usar para especificar el programa que devuelve la contraseña, al igual que con encfs.

Si no se especifican nombres en la línea de comandos, se leerá una lista de nombres de archivo desde stdin y se decodificarán.

encode
Te permite especificar un nombre de archivo en la línea de comandos y muestra su versión codificada. Esto es útil si, por ejemplo, estás haciendo una copia de seguridad de un directorio cifrado y deseas excluir algunos archivos.

La opción --extpass se puede usar para especificar el programa que devuelve la contraseña, al igual que con encfs.

Si no se especifican nombres en la línea de comandos, se leerá una lista de nombres de archivo desde stdin y se codificarán.

cat
Decodifica y muestra el contenido de un archivo cifrado. El nombre del archivo se puede dar en forma plana o cifrada. Con --reverse, el contenido del archivo se cifrará en su lugar.

EJEMPLOS

Mostrar información sobre un sistema de archivos cifrado:

% encfsctl info ~/.crypt
Configuración de versión 5; creado por EncFS 1.1 (revisión 20040504)
Cifrado del sistema de archivos: "ssl/aes" , versión 2:1:1
Codificación de nombres de archivo: "nameio/block" , versión 3:0:1
Tamaño de clave: 192 bits
Tamaño de bloque: 512 bytes
Cada archivo contiene una cabecera de 8 bytes con datos IV únicos.
Nombre de archivo codificado usando modo de encadenamiento IV.
