encoding(n) Comandos integrados de Tcl encoding(n)

NOMBRE

encoding - Manipular codificaciones

SINOPSIS

encoding opción ?arg arg ...?

INTRODUCCIÓN

Las cadenas en Tcl son lógicamente una secuencia de caracteres Unicode de 16 bits. Estas cadenas se representan en memoria como una secuencia de bytes que pueden estar en una de varias codificaciones: UTF-8 modificado (que usa de 1 a 3 bytes por carácter), "Unicode" de 16 bits (que usa 2 bytes por carácter, con una distribución de bytes que depende de la arquitectura del host) y binario (que usa un solo byte por carácter pero solo maneja un rango restringido de caracteres). Tcl no garantiza que siempre use la misma codificación para la misma cadena.

Las diferentes interfaces del sistema operativo o aplicaciones pueden generar cadenas en otras codificaciones como Shift-JIS. El comando encoding ayuda a tender un puente entre Unicode y estos otros formatos.

DESCRIPCIÓN

Realiza una de varias operaciones relacionadas con codificaciones, dependiendo de la opción. Las opciónes legales son:

encoding convertfrom ?codificación? datos
Convierte datos a Unicode desde la codificación especificada. Los caracteres en datos se tratan como datos binarios donde se toma el byte de menor peso de 8 bits de cada carácter. La secuencia resultante de bytes se trata como una cadena en la codificación especificada. Si no se especifica codificación, se utiliza la codificación del sistema actual.
encoding convertto ?codificación? cadena
Convierte cadena de Unicode a la codificación especificada. El resultado es una secuencia de bytes que representa la cadena convertida. Cada byte se almacena en los 8 bits de menor peso de un carácter Unicode (de hecho, la cadena resultante es una cadena binaria en lo que respecta a Tcl, al menos inicialmente). Si no se especifica codificación, se utiliza la codificación del sistema actual.
encoding dirs ?listaDirectorios?
Tcl puede cargar archivos de datos de codificación desde el sistema de archivos que describen codificaciones adicionales para que pueda trabajar con ellas. Este comando establece la ruta de búsqueda de archivos de datos de codificación *.enc a la lista de directorios listaDirectorios. Si se omite listaDirectorios, el comando devuelve la lista actual de directorios que componen la ruta de búsqueda. Es un error que listaDirectorios no sea una lista válida. Si, cuando ocurre una búsqueda de un archivo de datos de codificación, un elemento en listaDirectorios no se refiere a un directorio legible y buscable, ese elemento se ignora.
encoding names
Devuelve una lista que contiene los nombres de todas las codificaciones que están actualmente disponibles. Se garantiza que las codificaciones “utf-8” y “iso8859-1” estarán presentes en la lista.
encoding system ?codificación?
Establece la codificación del sistema a codificación. Si se omite codificación, el comando devuelve la codificación del sistema actual. La codificación del sistema se utiliza siempre que Tcl pasa cadenas a las llamadas del sistema.

EJEMPLO

El siguiente ejemplo convierte una secuencia de bytes en codificación japonesa euc-jp a una cadena TCL:

set s [encoding convertfrom euc-jp "\xA4\xCF"]

El resultado es el punto de código unicode: “\u306F”, que es la letra Hiragana HA.

Tcl_GetEncoding(3), fconfigure(n)
