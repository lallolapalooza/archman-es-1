NOMBRE

Env::ShellWords - Variables de entorno para argumentos como array

VERSIÓN

versión 0.02

SINOPSIS

# Interfaz Tie
use Env::ShellWords;
tie my @CFLAGS,  'Env::ShellWords', 'CFLAGS';
tie my @LDFLAGS, 'Env::ShellWords', 'LDFLAGS';
# lo mismo con la interfaz de importación:
use Env::ShellWords qw( @CFLAGS @LDFLAGS );
# uso:
$ENV{CFLAGS} = '-DBAR=1';
unshift @CFLAGS, '-I/foo/include';
push @CFLAGS, '-DFOO=Define With Spaces';

# ahora:
# $ENV{CFLAGS} = '-I/foo/include -DBAR=1 -DFOO=Define\\ With\\ Spaces';

unshift @LDFLAGS, '-L/foo/lib';
push @LDFLAGS, '-lfoo';

DESCRIPCIÓN

Este módulo proporciona una interfaz similar a un array para variables de entorno que contienen flags. Por ejemplo, Autoconf puede usar variables de entorno como "CFLAGS" o "LDFLAGS", y esto te permite manipular esas variables sin tener que hacer comillas espaciadas y otras cosas engorrosas.

La intención es usar esto desde alienfile para tratar con prerrequisitos jerárquicos.

Puedes proporcionar callbacks de división y unión al hacer `tie`:

use Env::ShellWords;
# dividir en cualquier espacio, ignorar comillas
tie my @FOO, 'Env::ShellWords',
  sub { split /\s+/, $_[0] },
  sub { join ' ', @_ };

Lo cual puede ser útil si tienes que dividir en palabras en un sistema operativo con una especificación diferente.

ADVERTENCIAS

No es especialmente rápido. "undef" se mapea a la cadena vacía '' ya que "undef" no tiene significado como argumento en una cadena.

Escribir en una variable de entorno usando esta interfaz es inherentemente con pérdida.
