ENDHOSTENT(3P) Manual del programador POSIX ENDHOSTENT(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

endhostent, gethostent, sethostent — funciones de la base de datos de hosts de red

SINOPSIS

#include <netdb.h>
void endhostent(void);
struct hostent *gethostent(void);
void sethostent(int stayopen);

DESCRIPCIÓN

Estas funciones recuperarán información sobre hosts. Esta información se considera almacenada en una base de datos a la que se puede acceder secuencialmente o aleatoriamente. La implementación de esta base de datos no está especificada.

Nota:
En muchos casos, esta base de datos se implementa mediante el Sistema de Nombres de Dominio (DNS), como se documenta en las RFC 1034, RFC 1035 y RFC 1886.

La función sethostent() abrirá una conexión a la base de datos y establecerá la siguiente entrada para su recuperación en la primera entrada de la base de datos. Si el argumento stayopen es distinto de cero, la conexión no se cerrará con una llamada a gethostent(), y la implementación podrá mantener un descriptor de archivo abierto.

La función gethostent() leerá la siguiente entrada de la base de datos, abriendo y cerrando una conexión a la base de datos según sea necesario.

Las entradas se devolverán en estructuras hostent.

La función endhostent() cerrará la conexión a la base de datos, liberando cualquier descriptor de archivo abierto.

Estas funciones no son necesariamente seguras para hilos.

VALOR DE RETORNO

Al completarse con éxito, la función gethostent() devolverá un puntero a una estructura hostent si se encontró la entrada solicitada y un puntero nulo si se llegó al final de la base de datos o no se encontró la entrada solicitada.

La aplicación no deberá modificar la estructura a la que apunta el valor de retorno, ni las áreas de almacenamiento a las que apuntan los punteros dentro de la estructura. El puntero devuelto, y los punteros dentro de la estructura, pueden quedar invalidados o la estructura o las áreas de almacenamiento pueden ser sobrescritas por una llamada posterior a gethostent(). El puntero devuelto, y los punteros dentro de la estructura, también pueden quedar invalidados si se termina el hilo que realiza la llamada.

ERRORES

No se definen errores para endhostent(), gethostent() y sethostent().
