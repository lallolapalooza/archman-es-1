NOMBRE

Encode::Byte - Codificaciones de un solo byte

SINOPSIS

use Encode qw/encode decode/; 
$griego = encode("iso-8859-7", $utf8);  # Carga Encode::Byte implícitamente
$utf8  = decode("iso-8859-7", $griego); # Idem

RESUMEN

Este módulo implementa varias codificaciones de un solo byte. Para la mayoría de los casos, utiliza \x80-\xff (la mitad superior) para mapear caracteres no ASCII. Las codificaciones soportadas son las siguientes.
