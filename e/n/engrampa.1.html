ENGRAMPA(1) Manual de Comandos Generales ENGRAMPA(1)

NOMBRE

Engrampa - Gestor de Archivos para MATE

SINOPSIS

engrampa [OPCIONES...] [ARCHIVOS...]

DESCRIPCIÓN

Engrampa es el gestor de archivos oficial del Entorno de Escritorio MATE, es una interfaz gráfica para utilidades de archivado como tar y zip. Es un fork de File Roller.

Engrampa soporta la mayoría de las operaciones comunes como crear, modificar y extraer archivos de un archivo. También puedes ver el contenido de un archivo y abrir archivos contenidos dentro del archivo.
Esta página del manual documenta brevemente el comando engrampa.

OPCIONES

nombre-de-archivo(s)...
Especifica el archivo de archivo a abrir cuando se inicia engrampa. Si no se especifica, engrampa se iniciará con una ventana en blanco y podrás abrir un archivo desde el menú o usando el atajo CTRL+O.
-a, --agregar-a=ARCHIVO
Añadir archivos al archivo especificado y salir del programa
-d, --agregar ARCHIVO
Añadir archivos solicitando el nombre del archivo y salir del programa
-e, --extraer-en=CARPETA
Extraer archivos a la carpeta especificada y salir del programa
-f, --extraer
Extraer archivos solicitando la carpeta de destino y salir del programa
-h, --extraer-aqui
Extraer archivos usando el nombre del archivo como carpeta de destino y salir del programa
--directorio-predeterminado=CARPETA
Carpeta predeterminada a usar para los comandos '--agregar' y '--extraer'
--forzar
Crear la carpeta de destino sin pedir confirmación
--mostrar=MOSTRAR
Pantalla X a usar.
-?, --ayuda
Imprimir opciones estándar de línea de comandos.
--ayuda-completa
Imprimir todas las opciones de línea de comandos.
--version
Mostrar la versión de la aplicación.

Este programa también acepta las opciones estándar de GTK.

EJEMPLOS

engrampa -h matelivecd.iso

Extrae matelivecd.iso en ./matelivecd en el directorio de trabajo actual.

engrampa ./matelivecd/* -a matelivecd.tar.gz

Crea un nuevo archivo comprimido tar.gz llamado matelivecd.tar.gz, que contiene todos los archivos ubicados en el directorio ./matelivecd.

engrampa matelivecd.tar.gz

Abre matelivecd.tar.gz para ver y manipular su contenido.
