English(3perl) Guía de Referencia del Programador de Perl English(3perl)

NOMBRE

English - usa nombres amigables en inglés (o awk) para variables de puntuación feas

SINOPSIS

use English;
use English qw( -no_match_vars ) ;  # Evita la penalización de rendimiento de expresiones regulares
                                    # en perl 5.18 y anteriores
...
if ($ERRNO =~ /denied/) { ... }

DESCRIPCIÓN

Este módulo proporciona alias para las variables incorporadas cuyos nombres a nadie parece gustarle leer. Las variables con efectos secundarios que se activan simplemente al acceder a ellas (como $0) seguirán estando afectadas.

Para aquellas variables que tienen una versión de awk, se proporcionan alternativas en inglés, tanto cortas como largas. Por ejemplo, la variable $/ puede ser referida como $RS o $INPUT_RECORD_SEPARATOR si estás usando el módulo English.

Consulta perlvar para una lista completa de estas.

RENDIMIENTO

NOTA: Esto se corrigió en perl 5.20. Mencionar estas tres variables ya no supone una diferencia de velocidad. Esta sección todavía se aplica si tu código se va a ejecutar en perl 5.18 o anteriores.

Este módulo puede provocar ineficiencias considerables para las expresiones regulares, debido a detalles de implementación desafortunados. Si el rendimiento importa en tu aplicación y no necesitas $PREMATCH, $MATCH, o $POSTMATCH, intenta hacer

use English qw( -no_match_vars ) ;

. Es especialmente importante hacer esto en módulos para evitar penalizar todas las aplicaciones que los usan.
