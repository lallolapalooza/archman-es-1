entry(n) Comandos integrados de Tk entry(n)

NOMBRE

entry - Crear y manipular widgets de entrada de texto de una línea 'entry'

SINOPSIS

entry nombreDeRuta ?opciones?

OPCIONES ESTÁNDAR

-background	-highlightthickness	-selectbackground
-borderwidth	-insertbackground	-selectborderwidth
-cursor	-insertborderwidth	-selectforeground
-exportselection	-insertofftime	-takefocus
-font	-insertontime	-textvariable
-foreground	-insertwidth	-xscrollcommand
-highlightbackground	-justify
-highlightcolor	-relief

Ver la entrada del manual de options para detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-disabledbackground
Nombre de base de datos:	disabledBackground
Clase de base de datos:	DisabledBackground
Especifica el color de fondo a usar cuando la entrada está deshabilitada. Si esta opción es una cadena vacía, se usa el color de fondo normal.
Nombre de línea de comandos:	-disabledforeground
Nombre de base de datos:	disabledForeground
Clase de base de datos:	DisabledForeground
Especifica el color de primer plano a usar cuando la entrada está deshabilitada. Si esta opción es una cadena vacía, se usa el color de primer plano normal.
Nombre de línea de comandos:	-invalidcommand o -invcmd
Nombre de base de datos:	invalidCommand
Clase de base de datos:	InvalidCommand
Especifica un script para evaluar cuando -validatecommand retorna 0. Establecerlo a {} deshabilita esta función (por defecto). El mejor uso de esta opción es establecerla a bell. Ver VALIDACIÓN más abajo para más información.
Nombre de línea de comandos:	-readonlybackground
Nombre de base de datos:	readonlyBackground
Clase de base de datos:	ReadonlyBackground
Especifica el color de fondo a usar cuando la entrada es de solo lectura. Si esta opción es una cadena vacía, se usa el color de fondo normal.
Nombre de línea de comandos:	-show
Nombre de base de datos:	show
Clase de base de datos:	Show
Si se especifica esta opción, entonces el contenido real de la entrada no se muestra en la ventana. En su lugar, cada carácter del valor de la entrada se mostrará como el primer carácter del valor de esta opción, como por ejemplo “*”. Esto es útil, por ejemplo, si la entrada se va a usar para ingresar una contraseña. Si se seleccionan y copian caracteres de la entrada en otro lugar, la información copiada será lo que se muestra, no el contenido real de la entrada.
Nombre de línea de comandos:	-state
Nombre de base de datos:	state
Clase de base de datos:	State
Especifica uno de los tres estados para la entrada: normal, disabled, o readonly. Si la entrada es de solo lectura, entonces el valor no puede ser modificado usando comandos del widget y no se mostrará ningún cursor de inserción, incluso si el foco de entrada está en el widget; el contenido del widget aún puede ser seleccionado. Si la entrada está deshabilitada, el valor no puede ser modificado, no se mostrará ningún cursor de inserción, el contenido no será seleccionable y la entrada puede mostrarse en un color diferente, dependiendo de los valores de las opciones -disabledforeground y -disabledbackground.
Nombre de línea de comandos:	-validate
Nombre de base de datos:	validate
Clase de base de datos:	Validate
Especifica el modo en que debe operar la validación: none, focus, focusin, focusout, key, o all. Por defecto es none. Cuando quieras validación, debes indicar explícitamente qué modo deseas usar. Ver VALIDACIÓN más abajo para más información.
Nombre de línea de comandos:	-validatecommand o -vcmd
Nombre de base de datos:	validateCommand
Clase de base de datos:	ValidateCommand
Especifica un script para evaluar cuando quieras validar la entrada en el widget de entrada. Establecerlo a {} deshabilita esta función (por defecto). Este comando debe retornar un valor booleano válido de Tcl. Si retorna 0 (o su equivalente booleano válido de Tcl), significa que rechazas la nueva edición y no ocurrirá, y se evaluará -invalidcommand si está establecido. Si retorna 1, entonces la nueva edición ocurre. Ver VALIDACIÓN más abajo para más información.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Especifica un valor entero que indica el ancho deseado de la ventana de entrada, en caracteres de tamaño promedio de la fuente del widget. Si el valor es menor o igual a cero, el widget elige un tamaño justo lo suficientemente grande como para contener su texto actual.

DESCRIPCIÓN

El comando entry crea una nueva ventana (dada por el argumento nombreDeRuta) y la convierte en un widget de entrada. Opciones adicionales, descritas arriba, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos de la entrada como sus colores, fuente y relieve. El comando entry retorna su argumento nombreDeRuta. En el momento en que se invoca este comando, no debe existir una ventana llamada nombreDeRuta, pero el padre de nombreDeRuta debe existir.

Una entrada es un widget que muestra una cadena de texto de una línea y permite que esa cadena sea editada usando los comandos del widget descritos a continuación, que normalmente están vinculados a pulsaciones de teclas y acciones del ratón. Al crearse, la cadena de una entrada está vacía. Una porción de la entrada puede ser seleccionada como se describe a continuación. Si una entrada está exportando su selección (ver la opción -exportselection), entonces observará los protocolos estándar de X11 para manejar la selección; las selecciones de entrada están disponibles como tipo STRING. Las entradas también observan las reglas estándar de Tk para tratar con el foco de entrada. Cuando una entrada tiene el foco de entrada, muestra un cursor de inserción para indicar dónde se insertarán los nuevos caracteres.

Las entradas son capaces de mostrar cadenas que son demasiado largas para caber completamente dentro de la ventana del widget. En este caso, solo se mostrará una porción de la cadena; los comandos descritos a continuación pueden usarse para cambiar la vista en la ventana. Las entradas usan el mecanismo estándar -xscrollcommand para interactuar con las barras de desplazamiento (ver la descripción de la opción -xscrollcommand para detalles). También soportan escaneo, como se describe a continuación.

VALIDACIÓN

La validación funciona estableciendo la opción -validatecommand a un script (validateCommand) que será evaluado de acuerdo con la opción -validate como sigue:

none
Por defecto. Esto significa que no ocurrirá ninguna validación.
focus
validateCommand será llamado cuando la entrada reciba o pierda el foco.
focusin
validateCommand será llamado cuando la entrada reciba el foco.
focusout
validateCommand será llamado cuando la entrada pierda el foco.
key
validateCommand será llamado cuando la entrada sea editada.
all
validateCommand será llamado para todas las condiciones anteriores.

Es posible realizar sustituciones de porcentaje en el valor de las opciones -validatecommand y -invalidcommand, tal como lo harías en un script de bind. Se reconocen las siguientes sustituciones:

%d
Tipo de acción: 1 para insert, 0 para delete, o -1 para validación de foco, forzada o por textvariable.
%i
Índice del carácter de la cadena a insertar/eliminar, si lo hay, de lo contrario -1.
%P
El valor de la entrada si se permite la edición. Si estás configurando el widget de entrada para que tenga un nuevo textvariable, este será el valor de ese textvariable.
%s
El valor actual de la entrada antes de la edición.
%S
La cadena de texto que se está insertando/eliminando, si la hay, de lo contrario {}.
%v
El tipo de validación actualmente establecido.
%V
El tipo de validación que desencadenó la llamada (key, focusin, focusout, forced).
%W

El nombre del widget de entrada.

En general, las opciones -textvariable y -validatecommand pueden ser peligrosas de mezclar. Se han superado todos los problemas para que el uso de -validatecommand no interfiera con el comportamiento tradicional del widget de entrada. El uso de -textvariable para fines de solo lectura nunca causará problemas. El peligro surge cuando se intenta establecer -textvariable a algo que -validatecommand no aceptaría, lo que provoca que -validate se establezca en none (el -invalidcommand no se activará). Lo mismo ocurre cuando ocurre un error al evaluar -validatecommand.

Principalmente, ocurrirá un error cuando -validatecommand o -invalidcommand encuentren un error en su script mientras lo evalúan o cuando -validatecommand no devuelva un valor booleano Tcl válido. La opción -validate también se establecerá en none cuando edite el widget de entrada dentro de -validatecommand o -invalidcommand. Dichas ediciones anularán la que se estaba validando. Si desea editar el widget de entrada (por ejemplo, establecerlo en {}) durante la validación y aún así mantener la opción -validate establecida, debe incluir el comando

after idle {%W config -validate %v}
en -validatecommand o -invalidcommand (desde cualquiera de ellos estaba editando el widget de entrada). También se recomienda no establecer una -textvariable asociada durante la validación, ya que eso puede hacer que el widget de entrada se desincronice con la -textvariable.

COMANDO DEL WIDGET

El comando entry crea un nuevo comando Tcl cuyo nombre es pathName. Este comando puede usarse para invocar varias operaciones en el widget. Tiene la siguiente forma general:

pathName subcomando ?arg arg ...?
El subcomando y los arg determinan el comportamiento exacto del comando.

ÍNDICES

Muchos de los comandos del widget para entradas toman uno o más índices como argumentos. Un índice especifica un carácter particular en la cadena de la entrada, de cualquiera de las siguientes maneras:

número
Especifica el carácter como un índice numérico, donde 0 corresponde al primer carácter de la cadena.
anchor
Indica el punto de anclaje para la selección, que se establece con los comandos del widget select from y select adjust.
end
Indica el carácter justo después del último en la cadena de la entrada. Esto equivale a especificar un índice numérico igual a la longitud de la cadena de la entrada.
insert
Indica el carácter adyacente e inmediatamente posterior al cursor de inserción.
sel.first
Indica el primer carácter de la selección. Es un error usar esta forma si la selección no está en la ventana de entrada.
sel.last
Indica el carácter justo después del último de la selección. Es un error usar esta forma si la selección no está en la ventana de entrada.
@número
En esta forma, número se trata como una coordenada x en la ventana de la entrada; se utiliza el carácter que abarca esa coordenada x. Por ejemplo, “@0” indica el carácter más a la izquierda de la ventana.

Se pueden usar abreviaturas para cualquiera de las formas anteriores, por ejemplo, “e” o “sel.f”. En general, los índices fuera de rango se redondean automáticamente al valor legal más cercano.

SUBCOMANDOS

Los siguientes comandos son posibles para los widgets de entrada:

pathName bbox índice
Devuelve una lista de cuatro números que describen el cuadro delimitador del carácter dado por índice. Los dos primeros elementos de la lista dan las coordenadas x e y de la esquina superior izquierda del área de la pantalla cubierta por el carácter (en píxeles en relación con el widget) y los dos últimos elementos dan el ancho y la altura del carácter, en píxeles. El cuadro delimitador puede referirse a un área fuera del área visible de la ventana.
pathName cget opción
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando entry.
pathName configure ?opción? ?valor opción valor ...?
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para pathName (consulte Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica opción sin ningún valor, el comando devuelve una lista que describe la opción con nombre (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna opción). Si se especifican uno o más pares opción-valor, el comando modifica las opciones del widget dadas para que tengan los valores dados; en este caso, el comando devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el comando entry.
pathName delete primero ?último?
Elimina uno o más elementos de la entrada. Primero es el índice del primer carácter a eliminar, y último es el índice del carácter justo después del último a eliminar. Si último no se especifica, predetermina primero+1, es decir, se elimina un solo carácter. Este comando devuelve una cadena vacía.
pathName get
Devuelve la cadena de la entrada.
pathName icursor índice
Organiza la visualización del cursor de inserción justo antes del carácter dado por índice. Devuelve una cadena vacía.
pathName index índice
Devuelve el índice numérico correspondiente a índice.
pathName insert índice cadena
Inserta los caracteres de cadena justo antes del carácter indicado por índice. Devuelve una cadena vacía.
pathName scan opción args
Este comando se utiliza para implementar el escaneo en las entradas. Tiene dos formas, dependiendo de opción:
pathName scan mark x
Graba x y la vista actual en la ventana de entrada; se utiliza en conjunción con comandos posteriores de scan dragto. Típicamente, este comando se asocia con la pulsación de un botón del ratón en el widget. Devuelve una cadena vacía.
pathName scan dragto x
Este comando calcula la diferencia entre su argumento x y el argumento x del último comando scan mark para el widget. Luego, ajusta la vista hacia la izquierda o hacia la derecha en 10 veces la diferencia en coordenadas x. Este comando se asocia típicamente con eventos de movimiento del ratón en el widget, para producir el efecto de arrastrar la entrada a alta velocidad por la ventana. El valor de retorno es una cadena vacía.
pathName selection opción arg
Este comando se utiliza para ajustar la selección dentro de una entrada. Tiene varias formas, dependiendo de opción:
pathName selection adjust índice
Localiza el extremo de la selección más cercano al carácter dado por índice, y ajusta ese extremo de la selección a índice (es decir, incluyendo pero sin ir más allá de índice). El otro extremo de la selección se convierte en el punto de anclaje para futuros comandos select to. Si la selección no está actualmente en la entrada, se crea una nueva selección para incluir los caracteres entre índice y el punto de anclaje de selección más reciente, inclusive. Devuelve una cadena vacía.
pathName selection clear
Borra la selección si está actualmente en este widget. Si la selección no está en este widget, el comando no tiene ningún efecto. Devuelve una cadena vacía.
pathName selection from índice
Establece el punto de anclaje de la selección justo antes del carácter dado por índice. No cambia la selección. Devuelve una cadena vacía.
pathName selection present
Devuelve 1 si hay caracteres seleccionados en la entrada, 0 si no hay nada seleccionado.
pathName selection range inicio fin
Establece la selección para incluir los caracteres que comienzan con el indexado por inicio y terminan con el anterior a fin. Si fin se refiere al mismo carácter que inicio o a uno anterior, la selección de la entrada se borra.
pathName selection to índice
Si índice está antes del punto de anclaje, establece la selección a los caracteres desde índice hasta, pero sin incluir, el punto de anclaje. Si índice es igual al punto de anclaje, no hace nada. Si índice está después del punto de anclaje, establece la selección a los caracteres desde el punto de anclaje hasta, pero sin incluir, índice. El punto de anclaje se determina por el comando select from o select adjust más reciente en este widget. Si la selección no está en este widget, se crea una nueva selección utilizando el punto de anclaje más reciente especificado para el widget. R
devuelve una cadena vacía.
pathName valida
te
Este comando se utiliza para forzar una evaluación de la -validatecommand independientemente de las condiciones especificadas por la -validate option. Esto se hace estableciendo temporalmente la -validate option a all. Devuelve 0 o
1.
pathName xview ar
gs

Por ejemplo, si el primer elemento es .2 y el segundo elemento es .6, el 20% del texto de la entrada está fuera de la pantalla a la izquierda, el 40% del medio está visible en la ventana, y el 40% del texto está fuera de la pantalla a la derecha. Ajusta la vista en la ventana de modo que el carácter dado por index se muestre en el borde izquierdo de la
