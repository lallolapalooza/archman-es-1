ENDUTXENT(3P) Manual del Programador POSIX ENDUTXENT(3P)

PRÓLOGO

Esta página manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

endutxent, getutxent, getutxid, getutxline, pututxline, setutxent — funciones de la base de datos de contabilidad de usuarios

SINOPSIS

#include <utmpx.h>
void endutxent(void);
struct utmpx *getutxent(void);
struct utmpx *getutxid(const struct utmpx *id);
struct utmpx *getutxline(const struct utmpx *line);
struct utmpx *pututxline(const struct utmpx *utmpx);
void setutxent(void);

DESCRIPCIÓN

Estas funciones proporcionan acceso a la base de datos de contabilidad de usuarios.

La getutxent() leerá la siguiente entrada de la base de datos de contabilidad de usuarios. Si la base de datos no está ya abierta, la abrirá. Si alcanza el final de la base de datos, fallará.

La getutxid() buscará hacia adelante desde el punto actual en la base de datos. Si el valor de ut_type de la estructura utmpx a la que apunta id es BOOT_TIME, OLD_TIME o NEW_TIME, se detendrá cuando encuentre una entrada con un valor coincidente de ut_type . Si el valor de ut_type es INIT_PROCESS, LOGIN_PROCESS, USER_PROCESS o DEAD_PROCESS, se detendrá cuando encuentre una entrada cuyo tipo sea uno de estos cuatro y cuyo miembro ut_id coincida con el miembro ut_id de la estructura utmpx a la que apunta id. Si se alcanza el final de la base de datos sin encontrar una coincidencia, getutxid() fallará.

La getutxline() buscará hacia adelante desde el punto actual en la base de datos hasta que encuentre una entrada de tipo LOGIN_PROCESS o USER_PROCESS que también tenga un valor de ut_line que coincida con el de la estructura utmpx a la que apunta line. Si se alcanza el final de la base de datos sin encontrar una coincidencia, getutxline() fallará.

La getutxid() o la getutxline() pueden almacenar datos en caché. Por esta razón, para usar getutxline() y buscar múltiples ocurrencias, la aplicación debe poner a cero los datos estáticos después de cada éxito, o getutxline() puede devolver un puntero a la misma estructura utmpx .

Hay una excepción a la regla sobre limpiar la estructura antes de realizar más lecturas. La lectura implícita realizada por pututxline() (si encuentra que no está ya en el lugar correcto en la base de datos de contabilidad de usuarios) no modificará la estructura estática devuelta por getutxent(), getutxid() o getutxline(), si la aplicación ha modificado esta estructura y ha pasado el puntero de vuelta a pututxline() .

Para todas las entradas que coincidan con una solicitud, el miembro ut_type indica el tipo de la entrada. Otros miembros de la entrada contendrán datos significativos basados en el valor del miembro ut_type de la siguiente manera:

Miembro ut_type Otros miembros con datos significativos
EMPTY Ninguno
BOOT_TIME ut_tv
OLD_TIME ut_tv
NEW_TIME ut_tv
USER_PROCESS ut_id, ut_user (nombre de inicio de sesión del usuario), ut_line, ut_pid, ut_tv
INIT_PROCESS ut_id, ut_pid, ut_tv
LOGIN_PROCESS ut_id , ut_user (nombre del proceso de inicio de sesión definido por la implementación), ut_line , ut_pid , ut_tv
DEAD_PROCESS ut_id, ut_pid, ut_tv

Una implementación que proporcione controles de seguridad extendidos puede imponer restricciones definidas por la implementación para acceder a la base de datos de contabilidad de usuarios. En particular, el sistema puede negar la existencia de algunas o todas las entradas de la base de datos de contabilidad de usuarios asociadas con usuarios distintos del llamador.

Si el proceso tiene los privilegios adecuados, la función pututxline() escribirá la estructura en la base de datos de contabilidad de usuarios. Buscará un registro como si fuera con getutxid() que satisfaga la solicitud. Si esta búsqueda tiene éxito, la entrada será reemplazada. De lo contrario, se creará una nueva entrada al final de la base de datos de contabilidad de usuarios.

La endutxent() cerrará la base de datos de contabilidad de usuarios.

La setutxent() restablecerá la entrada al principio de la base de datos. Esto debe hacerse antes de cada búsqueda de una nueva entrada si se desea examinar toda la base de datos.

Estas funciones no necesitan ser seguras para subprocesos.

VALOR DE RETORNO

Tras una finalización exitosa, getutxent(), getutxid() y getutxline() devolverán un puntero a una estructura utmpx que contiene una copia de la entrada solicitada en la base de datos de contabilidad de usuarios. De lo contrario, se devolverá un puntero nulo.

El valor de retorno puede apuntar a un área estática que es sobrescrita por una llamada posterior a getutxid() o getutxline() .

Tras una finalización exitosa, pututxline() devolverá un puntero a una estructura utmpx que contiene una copia de la entrada añadida a la base de datos de contabilidad de usuarios. De lo contrario, se devolverá un puntero nulo.

Las funciones endutxent() y setutxent() no devolverán ningún valor.

ERRORES
