NOMBRE

Encode::Symbol - Codificaciones de Símbolos

SINOPSIS

use Encode qw/encode decode/; 
$simbolo  = encode("symbol", $utf8); # carga Encode::Symbol implícitamente
$utf8 = decode("", $simbolo);        # ídem

RESUMEN

Este módulo implementa codificaciones de símbolos y dingbats. Las codificaciones soportadas son las siguientes.

Canónica   Alias             Descripción
--------------------------------------------------------------------
symbol
dingbats
AdobeZDingbat
AdobeSymbol
MacDingbats

DESCRIPCIÓN

Para saber cómo usar este módulo en detalle, consulta Encode.
