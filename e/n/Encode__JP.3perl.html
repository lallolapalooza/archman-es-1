NOMBRE

Encode::JP — Codificaciones japonesas

SINOPSIS

use Encode qw/encode decode/; 
$euc_jp = encode("euc-jp", $utf8);   # Carga Encode::JP implícitamente
$utf8   = decode("euc-jp", $euc_jp); # ídem

RESUMEN

Este módulo implementa codificaciones de juegos de caracteres japoneses. Las codificaciones soportadas son las siguientes.

Canónica     Alias           Descripción
--------------------------------------------------------------------
euc-jp      /\beuc.*jp$/i     EUC (Extended Unix Character)
            /\bjp.*euc/i   
        /\bujis$/i
shiftjis    /\bshift.*jis$/i  Shift JIS (también conocido como MS Kanji)
        /\bsjis$/i
7bit-jis    /\bjis$/i         JIS de 7 bits
iso-2022-jp                   ISO-2022-JP                  [RFC1468]
              = JIS de 7 bits con Kana de ancho reducido convertido a ancho completo
iso-2022-jp-1                 ISO-2022-JP-1                [RFC2237]
                              = ISO-2022-JP con soporte para JIS X 0212-1990
                . Ver abajo
MacJapanese                   Shift JIS + asignaciones de proveedor de Apple
cp932       /\bwindows-31j$/i Code Page 932
                              = Shift JIS + asignaciones de MS/IBM
jis0201-raw                   JIS0201, formato crudo
jis0208-raw                   JIS0208, formato crudo
jis0212-raw                   JIS0212, formato crudo
--------------------------------------------------------------------

DESCRIPCIÓN

Para saber cómo usar este módulo en detalle, consulte Encode.

Nota sobre ISO-2022-JP(-1)?

ISO-2022-JP-1 (RFC2237) es un superconjunto de ISO-2022-JP (RFC1468) que añade soporte para JIS X 0212-1990. Esto significa que puede usar el mismo código para decodificar a utf8, pero no viceversa.

$utf8 = decode('iso-2022-jp-1', $stream);

y

$utf8 = decode('iso-2022-jp',   $stream);

producen el mismo resultado, pero

$with_0212 = encode('iso-2022-jp-1', $utf8);

es ahora diferente de

$without_0212 = encode('iso-2022-jp', $utf8 );

En este último caso, los caracteres que se mapean a 0212 se convierten primero a U+3013 (0xA2AE en EUC-JP; un cuadrado blanco también conocido como 'Tofu' o 'marca geta') y luego se introducen en el motor de decodificación. U+FFFD no se utiliza, para preservar el diseño del texto tanto como sea posible.

ERRORES

La región ASCII (0x00-0x7f) se conserva para todas las codificaciones, aunque esto entra en conflicto con las asignaciones del Consorcio Unicode.
