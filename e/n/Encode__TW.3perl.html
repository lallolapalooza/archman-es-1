NOMBRE

Encode::TW - Codificaciones Chinas basadas en Taiwán

SINOPSIS

use Encode qw/encode decode/; 
$big5 = encode("big5", $utf8); # carga Encode::TW implícitamente
$utf8 = decode("big5", $big5); # ídem

DESCRIPCIÓN

Este módulo implementa codificaciones de juegos de caracteres chinos tradicionales tal como se usan en Taiwán y Hong Kong. Las codificaciones soportadas son las siguientes.

Canónico     Alias             Descripción
--------------------------------------------------------------------
big5-eten   /\bbig-?5$/i      Codificación Big5 (con extensiones ETen)
        /\bbig5-?et(en)?$/i
        /\btca-?big5$/i
big5-hkscs  /\bbig5-?hk(scs)?$/i
            /\bhk(scs)?-?big5$/i
                              Big5 + caracteres cantoneses en Hong Kong
MacChineseTrad                Big5 + Mapeos de Proveedor de Apple
cp950                         Página de Código 950 
                              = Big5 + Mapeos de Proveedor de Microsoft
--------------------------------------------------------------------

Para saber cómo usar este módulo en detalle, consulte Encode.

NOTAS

Debido a problemas de tamaño, "EUC-TW" (Extended Unix Character), "CCCII" (Chinese Character Code for Information Interchange), "BIG5PLUS" (Big5+ de CMEX) y "BIG5EXT" (Big5e de CMEX) se distribuyen por separado en CPAN, bajo el nombre Encode::HanExtra. Ese módulo también contiene codificaciones adicionales basadas en China.

ERRORES

Dado que la codificación original "big5" (1984) no se soporta en ningún lugar (glibc y sistemas basados en DOS usan "big5" para significar "big5-eten"; Microsoft usa "big5" para significar "cp950"), se tomó la decisión consciente de crear un alias para "big5" a "big5-eten", que es el superconjunto de facto del big5 original.

Los archivos de codificación "CNS11643" no están completos. Para la manipulación común de "CNS11643", por favor use "EUC-TW" en Encode::HanExtra, que contiene los planos 1-7.

La región ASCII (0x00-0x7f) se conserva para todas las codificaciones, incluso aunque esto entre en conflicto con los mapeos del Unicode Consortium.
