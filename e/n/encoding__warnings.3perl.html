encoding::warnings(3perl) Guía de referencia del programador de Perl encoding::warnings(3perl)

NOMBRE

encoding::warnings - Advertir sobre conversiones de codificación implícitas

VERSIÓN

Este documento describe la versión 0.13 de encoding::warnings, publicada el 20 de junio de 2016.

AVISO

A partir de Perl 5.26.0, este módulo no tiene ningún efecto. La característica interna de Perl que se utilizaba para implementar este módulo ha sido eliminada. En los últimos años, se ha trabajado mucho en el núcleo de Perl para eliminar las discrepancias en el tratamiento de las cadenas actualizadas frente a las degradadas. Además, la pragmática `encoding`, que causaba muchos de los problemas, ya no es compatible. Por lo tanto, las advertencias que producía este módulo ya no son necesarias.

Por lo tanto, si cargas este módulo en Perl 5.26.0, recibirás una advertencia de que el módulo ya no es compatible; y el módulo no hará nada después.

SINOPSIS

use encoding::warnings; # o 'FATAL' para lanzar excepciones fatales
utf8::encode($a = chr(20000));  # una cadena de bytes (bytes crudos)
$b = chr(20000);                # una cadena unicode (caracteres anchos)
# "Bytes implícitamente convertidos a caracteres anchos como iso-8859-1"
$c = $a . $b;

DESCRIPCIÓN

Resumen del problema

Por defecto, existe una asimetría fundamental en el modelo unicode de Perl: la conversión implícita de cadenas de bytes a cadenas unicode asume que estaban codificadas en ISO 8859-1 (Latin-1), pero las cadenas unicode se degradan con la codificación UTF-8. Esto ocurre porque los primeros 256 puntos de código en Unicode coinciden con Latin-1.

Sin embargo, esta conversión silenciosa puede causar fácilmente problemas si se mezclan cadenas unicode con datos que no son Latin-1, es decir, cadenas de bytes codificadas en UTF-8 u otras codificaciones. El error no se manifestará hasta que la cadena combinada se escriba en la salida, momento en el que sería imposible saber dónde ocurrió la conversión silenciosa.

Detección del problema

Este módulo simplifica el proceso de diagnóstico de dichos problemas. Simplemente añade esta línea al principio de tu programa principal:

use encoding::warnings;

Después, la conversión implícita de bytes de alto bit generará una advertencia. Por ejemplo: "Bytes implícitamente convertidos a caracteres anchos como iso-8859-1 en - línea 7".

Sin embargo, las cadenas compuestas puramente por puntos de código ASCII (0x00..0x7F) *no* activarán esta advertencia.

También puedes hacer que las advertencias sean fatales importando este módulo como:

use encoding::warnings 'FATAL';

Solución del problema

La mayoría de las veces, esta advertencia ocurre cuando una cadena de bytes se concatena con una cadena unicode. Hay varias maneras de resolverlo:

  • Convertir ambos lados a cadenas unicode

    Si tu programa no necesita compatibilidad con Perl 5.6 y anteriores, el enfoque recomendado es aplicar las disciplinas de IO adecuadas, para que todos los datos de tu programa se conviertan en cadenas unicode. Consulta `encoding`, `open` y "binmode" en perlfunc para saber cómo hacerlo.

  • Degradar ambos lados a cadenas de bytes

    La otra forma también funciona, especialmente si estás seguro de que todos tus datos están bajo la misma codificación, o si se desea compatibilidad con versiones anteriores de Perl.

    Puedes degradar cadenas con "Encode::encode" y "utf8::encode". Consulta Encode y utf8 para obtener más detalles.

  • Especificar la codificación para la conversión implícita de cadenas de bytes

    Si estás seguro de que todas las cadenas de bytes estarán en una codificación específica como UTF-8, *y* no necesitas soportar versiones anteriores de Perl, usa la pragmática `encoding`:

    use encoding 'utf8';

    Del mismo modo, esto silenciará las advertencias de este módulo y preservará el comportamiento predeterminado:

    use encoding 'iso-8859-1';

    Sin embargo, ten en cuenta que `use encoding` en realidad tenía tres efectos distintos:

  • Capas PerlIO para STDIN y STDOUT

    Esto es similar a lo que hace la pragmática `open`.

  • Conversiones literales

    Esto convierte *todas* las cadenas literales de tu programa en cadenas unicode (equivalente a `use utf8`), decodificándolas usando la codificación especificada.

  • Conversión implícita de cadenas de bytes

    Esto silenciará las advertencias de este módulo, como se mostró anteriormente.

Debido a que las conversiones literales también funcionan en cadenas vacías, puede sorprender a algunas personas:

use encoding 'big5';
my $byte_string = pack("C*", 0xA4, 0x40);
print length $a;    # 2 aquí.
$a .= "";           # concatenando con una cadena unicode...
print length $a;    # ¡1 aquí!

En otras palabras, no uses `use encoding` a menos que estés seguro de que el programa no tratará con ningún dato binario crudo de 8 bits.

Sin embargo, la variante `Filter => 1` de `use encoding` *no* afectará a la conversión implícita de cadenas de bytes y, por lo tanto, es incapaz de silenciar las advertencias de este módulo. Consulta `encoding` para más detalles.

CONTRAS

Para Perl 5.9.4 o posterior, el efecto de este módulo es léxico.

Para versiones de Perl anteriores a 5.9.4, este módulo afecta a todo el script, en lugar de estar dentro de su bloque léxico.
