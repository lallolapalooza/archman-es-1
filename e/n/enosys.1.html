ENOSYS(1) Comandos de Usuario ENOSYS(1)

NOMBRE

enosys - utilidad para hacer que las llamadas al sistema fallen con ENOSYS

SINOPSIS

enosys [--syscall|-s syscall] comando

DESCRIPCIÓN

enosys es un comando simple para ejecutar un proceso hijo para el cual ciertas llamadas al sistema fallan con errno ENOSYS.

Se puede utilizar para probar el comportamiento de las aplicaciones ante llamadas al sistema faltantes, como podría ocurrir al ejecutarse en kernels antiguos.

OPCIONES

-s, --syscall

Llamada al sistema a bloquear con ENOSYS. Se puede especificar varias veces. Se puede especificar un número de error o nombre alternativo con dos puntos.

-i, --ioctl

Ioctl a bloquear con ENOTTY. Se puede especificar varias veces. Se puede especificar un número de error o nombre alternativo con dos puntos.

-l, --list

Listar llamadas al sistema conocidas por enosys.

-m, --list-ioctl

Listar ioctls conocidos por enosys.

-d, --dump[=archivo]

Volcar el filtro de bytecode seccomp a la salida estándar.

El volcado puede ser utilizado, por ejemplo, por setpriv --seccomp-filter.

-h, --help

Mostrar el texto de ayuda y salir.

-V, --version

Mostrar la versión y salir.

EJEMPLOS

# hacer fallar la llamada al sistema "fallocate" con ENOSYS
enosys -s fallocate ...
# hacer fallar la llamada al sistema "fallocate" con ENOMEM
enosys -s fallocate:ENOMEM ...
# hacer fallar la llamada al sistema "fallocate" con el valor 12/ENOMEM
enosys -s fallocate:12 ...
# hacer fallar el ioctl FIOCLEX con ENOTTY
enosys -i FIOCLEX ...
# hacer fallar el ioctl FIOCLEX con ENOMEM
enosys -i FIOCLEX:ENOMEM ...
# hacer fallar el ioctl FIOCLEX con el valor 12/ENOMEM
enosys -i FIOCLEX:12 ...

ESTADO DE SALIDA

enosys sale con el código de estado del proceso ejecutado. Los siguientes valores tienen significados especiales:

1

error interno

2

el sistema no proporciona la funcionalidad necesaria
