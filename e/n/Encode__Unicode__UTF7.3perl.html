Encode::Unicode::UTF7(3perl) Guía del programador de Perl Encode::Unicode::UTF7(3perl)

NOMBRE

Encode::Unicode::UTF7 -- Codificación UTF-7

SINOPSIS

use Encode qw/encode decode/; 
$utf7 = encode("UTF-7", $utf8);
$utf8 = decode("UTF-7", $ucs2);

RESUMEN

Este módulo implementa la codificación UTF-7 documentada en RFC 2152. UTF-7, como su nombre indica, es una versión recodificada en 7 bits de UTF-16BE. Está diseñada para ser compatible con MTA (Mail Transfer Agent) y se espera que sea una forma estándar de intercambiar correos electrónicos Unicode a través del correo. Pero con la llegada de UTF-8 y los MTA compatibles con 8 bits, UTF-7 apenas se usa.

UTF-7 no era compatible con Encode hasta la versión 1.95 debido a eso. Pero Unicode::String, un módulo de Gisle Aas que añade soporte Unicode a perl no compatible con utf8, sí soportaba UTF-7; el soporte para UTF-7 se añadió para que Encode pudiera reemplazar completamente Unicode::String.

En Práctica

Sin embargo, cuando quiera codificar Unicode para correos electrónicos y páginas web, no utilice UTF-7 a menos que esté seguro de que sus destinatarios y lectores pueden manejarlo. Muy pocos MUA (Mail User Agent) y navegadores web lo soportan hoy en día (solo Mozilla parece soportar una variante). Para casos generales, use UTF-8 para el cuerpo del mensaje y MIME-Header para la cabecera.
