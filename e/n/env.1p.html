Las

utilidades

command, env, nice, nohup, time y xargs se han especificado para usar el código de salida 127 si ocurre un error, para que las aplicaciones puedan distinguir «fallo al encontrar una utilidad» de «la utilidad invocada salió con una indicación de error». Se eligió el valor 127 porque no se usa comúnmente para otros significados; la mayoría de las utilidades usan valores pequeños para «condiciones de error normales» y los valores superiores a 128 pueden confundirse con la terminación debido a la recepción de una señal. El valor 126 se eligió de manera similar para indicar que la utilidad pudo ser encontrada, pero no invocada. Algunos scripts producen mensajes de error significativos que diferencian los casos 126 y 127. La distinción entre los códigos de salida 126 y 127 se basa en la práctica de KornShell que usa 127 cuando todos los intentos de ejecutar la utilidad fallan con [ENOENT], y usa 126 cuando cualquier intento de ejecutar la utilidad falla por cualquier otra razón. Las implementaciones históricas de la

utilidad

env usan las funciones execvp() o execlp() definidas en el volumen de Interfaces del Sistema de POSIX.1‐2017 para invocar la utilidad especificada; esto proporciona un mejor rendimiento y evita que los usuarios tengan que escapar caracteres con un significado especial para el shell. Por lo tanto, las funciones de shell, las incorporadas especiales y las incorporadas que solo proporciona el shell no se encuentran. EJEM
