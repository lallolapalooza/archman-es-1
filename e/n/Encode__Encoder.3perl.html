NOMBRE

Encode::Encoder -- Codificador Orientado a Objetos

SINOPSIS

use Encode::Encoder;
# Encode::encode("ISO-8859-1", $data); 
Encode::Encoder->new($data)->iso_8859_1; # Forma OOP
# acceso directo
use Encode::Encoder qw(encoder);
encoder($data)->iso_8859_1;
# ¡puedes encadenarlos!
encoder($data)->iso_8859_1->base64;  # siempre que base64() esté definido
# puedes usarlo como decodificador también
encoder($base64)->bytes('base64')->latin1;
# convertido a cadena
print encoder($data)->utf8->latin1;  # imprime la cadena en latin1
# convertido a número
encoder("\x{abcd}\x{ef}g")->utf8 == 6; # verdadero. bytes::length($data)

RESUMEN

Encode::Encoder te permite usar Encode de forma orientada a objetos. Esto no solo es más intuitivo que un enfoque funcional, sino que también es más práctico cuando deseas apilar codificaciones. Supón que quieres que tu cadena UTF-8 se convierta a Latin1 y luego a Base64: puedes decir simplemente

my $base64 = encoder($utf8)->latin1->base64;

en lugar de

my $latin1 = encode("latin1", $utf8);
my $base64 = encode_base64($utf8);

o el más perezoso y complicado

my $base64 = encode_base64(encode("latin1", $utf8));

Descripción

Aquí se explica cómo usar este módulo.

  • Hay al menos dos variables de instancia almacenadas en una referencia de hash, {data} y {encoding}.
  • Cuando no hay un método, toma el nombre del método como el nombre de la codificación y codifica los datos de la instancia con la codificación. Si tiene éxito, la codificación de la instancia se establece correspondientemente.
  • Puedes recuperar el resultado a través de ->data pero normalmente no tendrás que hacerlo porque el operador de conversión a cadena ("") está sobrescrito para hacer exactamente eso.

Métodos predefinidos

Este módulo predefine los siguientes métodos:

$e = Encode::Encoder->new([$data, $encoding]);
devuelve un objeto codificador. Sus datos se inicializan con $data si está presente, y su codificación se establece en $encoding si está presente.

Cuando $encoding se omite, por defecto es utf8 si $data ya está en utf8 o "" (cadena vacía) en caso contrario.

encoder()
es un alias de Encode::Encoder->new(). Este se exporta bajo demanda.
$e->data([$data])
Cuando $data está presente, establece los datos de la instancia a $data y devuelve el objeto mismo. De lo contrario, se devuelven los datos de la instancia actual.
$e->encoding([$encoding])
Cuando $encoding está presente, establece la codificación de la instancia a $encoding y devuelve el objeto mismo. De lo contrario, se devuelve la codificación de la instancia actual.
$e->bytes([$encoding])
decodifica los datos de la instancia desde $encoding, o la codificación de la instancia si se omite. Si la conversión tiene éxito, la codificación de la instancia se establecerá en "".

El nombre de bytes fue elegido deliberadamente para evitar el envenenamiento del espacio de nombres: este módulo puede usarse como clase base, por lo que se evitan los nombres de métodos que aparecen en Encode::Encoding.

Ejemplo: Transcodificador base64

Este módulo está diseñado para funcionar con Encode::Encoding. Para que el ejemplo del transcodificador Base64 anterior funcione realmente, podrías escribir un módulo como este:

package Encode::Base64;
use parent 'Encode::Encoding';
__PACKAGE__->Define('base64');
use MIME::Base64;
sub encode{ 
    my ($obj, $data) = @_; 
    return encode_base64($data);
}
sub decode{
    my ($obj, $data) = @_; 
    return decode_base64($data);
}
1;
__END__

Y tu módulo de llamada sería algo como esto:

use Encode::Encoder;
use Encode::Base64;
# ahora realmente puedes hacer lo siguiente
encoder($data)->iso_8859_1->base64;
encoder($base64)->bytes('base64')->latin1;

Sobrecarga de operadores

Este módulo sobrecarga dos operadores, el de conversión a cadena ("") y el de conversión a número (0+).

La conversión a cadena vuelca los datos dentro del objeto.

La conversión a número devuelve el número de bytes en los datos de la instancia.

Son muy útiles cuando quieres imprimir o conocer el tamaño de los datos.
