Env(3perl) Guía de referencia del programador de Perl Env(3perl)

NOMBRE

Env - módulo de Perl que importa variables de entorno como escalares o arrays

SINOPSIS

use Env;
use Env qw(PATH HOME TERM);
use Env qw($SHELL @LD_LIBRARY_PATH);

DESCRIPCIÓN

Perl mantiene las variables de entorno en un hash especial llamado %ENV. Para cuando este método de acceso es inconveniente, el módulo de Perl "Env" permite que las variables de entorno se traten como variables escalares o de array.

La función Env::import() enlaza las variables de entorno con nombres adecuados a variables globales de Perl con los mismos nombres. Por defecto, enlaza todas las variables de entorno existentes ("keys %ENV") a escalares. Si la función "import" recibe argumentos, los toma como una lista de variables a enlazar; no pasa nada si aún no existen. El prefijo de tipo escalar '$' se infiere para cualquier elemento de esta lista que no esté precedido por '$' o '@'. Los arrays se implementan mediante "split" y "join", utilizando $Config::Config{path_sep} como delimitador.

Después de enlazar una variable de entorno, simplemente úsala como una variable normal. Puedes acceder a su valor

@path = split(/:/, $PATH);
print join("\n", @LD_LIBRARY_PATH), "\n";

o modificarla

$PATH .= ":/any/path";
push @LD_LIBRARY_PATH, $dir;

como quieras. Ten en cuenta, sin embargo, que cada acceso a una variable de array enlazada requiere dividir la cadena de la variable de entorno de nuevo.

El código:

use Env qw(@PATH);
push @PATH, '/any/path';

es casi equivalente a:

use Env qw(PATH);
$PATH .= ":/any/path";

excepto que si $ENV{PATH} estaba inicialmente vacío, el segundo enfoque lo deja con el valor (impar) "":/any/path"", pero el primer enfoque lo deja con ""/any/path"".

Para eliminar una variable de entorno enlazada del entorno, asígnale el valor indefinido

undef $PATH;
undef @LD_LIBRARY_PATH;

LIMITACIONES

En sistemas VMS, los arrays enlazados a variables de entorno son de solo lectura. Intentar cambiar algo provocará una advertencia.
