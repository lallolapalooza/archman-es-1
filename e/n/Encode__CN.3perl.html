NOMBRE

Encode::CN - Codificaciones chinas basadas en China

SINOPSIS

use Encode qw/encode decode/; 
$euc_cn = encode("euc-cn", $utf8);   # Carga Encode::CN implícitamente
$utf8   = decode("euc-cn", $euc_cn); # lo mismo

DESCRIPCIÓN

Este módulo implementa codificaciones de juegos de caracteres chinos basadas en China. Las codificaciones admitidas son las siguientes.

Canónico   Alias             Descripción
--------------------------------------------------------------------
euc-cn      /\beuc.*cn$/i     EUC (Extended Unix Character)
        /\bcn.*euc$/i
            /\bGB[-_ ]?2312(?:\D.*$|$)/i (ver abajo)
gb2312-raw                    Mapa de caracteres GB2312 crudo (bit bajo)
gb12345-raw                   Contraparte china tradicional de 
              GB2312 (crudo)
iso-ir-165                    GB2312 + GB6345 + GB8565 + adiciones
MacChineseSimp                GB2312 + Adiciones de Apple
cp936                         Code Page 936, también conocida como GBK 
              (Extended GuoBiao)
hz                            Codificación GB2312 escapada de 7 bits
--------------------------------------------------------------------

Para saber cómo usar este módulo en detalle, consulte Encode.

NOTAS

Debido a problemas de tamaño, "GB 18030" (una extensión de "GBK") se distribuye por separado en CPAN, bajo el nombre Encode::HanExtra. Ese módulo también contiene codificaciones adicionales basadas en Taiwán.

ERRORES

Cuando ve "charset=gb2312" en correos y páginas web, en realidad significan codificaciones "euc-cn". Para solucionarlo, "gb2312" es un alias de "euc-cn". Use "gb2312-raw" cuando realmente quiera decir eso.

La región ASCII (0x00-0x7f) se conserva para todas las codificaciones, aunque esto entre en conflicto con los mapeos del Consorcio Unicode.
