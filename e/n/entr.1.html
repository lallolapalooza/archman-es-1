ENTR(1) Manual de Comandos Generales ENTR(1)

NOMBRE

entr — ejecuta comandos arbitrarios cuando los archivos cambian

SINOPSIS

entr [-acdnprsxz] utilidad [argumento /_ ...]

DESCRIPCIÓN

Se proporciona una lista de archivos a través de la entrada estándar, y la utilidad se ejecuta con los argumentos proporcionados si alguno de ellos cambia. entr espera a que el proceso hijo termine antes de responder a los siguientes eventos del sistema de archivos. También se abre un TTY antes de entrar en el bucle de vigilancia para admitir utilidades interactivas.

Los argumentos son los siguientes:

-a
Responder a todos los eventos que ocurran mientras la utilidad se está ejecutando. Sin esta opción, entr consolida los eventos para evitar bucles. Esta opción no tiene efecto cuando se combina con el indicador -r .
-c
Borrar la pantalla antes de invocar la utilidad especificada en la línea de comandos. Especifíquelo dos veces para borrar el búfer de desplazamiento.
-d
Rastrear los directorios de los archivos regulares proporcionados como entrada y salir si se añade un archivo nuevo. Esta opción también permite especificar directorios explícitamente. Si se especifica dos veces, se reconocen todas las entradas nuevas de un directorio; de lo contrario, se ignoran los archivos cuyos nombres comienzan con ‘.’.
-n
Ejecutar en modo no interactivo. En este modo, entr no intenta leer del TTY ni cambiar sus propiedades.
-p
Posponer la primera ejecución de la utilidad hasta que se modifique un archivo.
-r
Recargar un proceso hijo persistente. Como en el modo de operación estándar, una utilidad que termina no se vuelve a ejecutar hasta que se procesa un evento del sistema de archivos o del teclado. SIGTERM se utiliza para terminar la utilidad antes de reiniciarla. Se crea un grupo de procesos para evitar que los scripts de shell enmascaren las señales. entr espera a que la utilidad salga para asegurarse de que recursos como los sockets se han cerrado. El control del TTY no se transfiere al proceso hijo.
-s
Evaluar el primer argumento usando el intérprete especificado por la variable de entorno SHELL .
-x
Formatear mensajes de estado de salida personalizados usando un proceso persistente de awk(1) . La ruta al script de estado se define por la variable de entorno ENTR_STATUS_SCRIPT. Si el script de estado no existe, entr creará un ejemplo. Por defecto no se permiten comandos de shell ni redirección de archivos, pero se pueden habilitar especificando -x dos veces.
-z
Salir después de que la utilidad termine. Cuando se combina con -r , la utilidad se reiniciará solo en respuesta a comandos o eventos del sistema de archivos.

El primer argumento llamado /_ se reemplaza con la ruta absoluta del primer archivo que desencadena un evento. El primer archivo vigilado se utiliza como valor predeterminado. Si se usa la opción -s , el nombre del primer archivo que desencadena un evento se puede leer desde $0.

COMANDOS

entr escucha la entrada del teclado y responde a los siguientes comandos:

⟨espacio⟩
Ejecutar la utilidad inmediatamente. Si la opción -r está activada, esto terminará y reiniciará el proceso hijo como si hubiera ocurrido un evento de cambio de archivo.
q
Salir; equivalente a presionarcontrol-C.

ENTORNO

ENTR_STATUS_SCRIPT
La ruta al script de estado de salida habilitado por la opción -x . Por defecto se evalúa $HOME/.entr/status.awk .
PAGER
Establecido por defecto en /bin/cat para evitar que las utilidades interactivas esperen entrada del teclado si la salida no cabe en la pantalla.
SHELL
Especificar el shell a usar con el indicador -s . El valor predeterminado es /bin/sh.
EV_TRACE
Imprimir mensajes de eventos del sistema de archivos.

ESTADO DE SALIDA

Si el indicador -z está activado y la utilidad se ejecuta correctamente, se devuelve el estado del proceso hijo. Si el proceso hijo fue terminado por una señal, el estado de salida es el número de señal más 128.

entr normalmente devuelve uno de los siguientes valores:

0
Terminación normal después de recibir SIGINT
1
No se proporcionaron archivos regulares como entrada o se produjo un error
2
Se añadió un archivo a un directorio y se especificó la opción de vigilancia de directorios

EJEMPLOS

Reconstruir un proyecto si los archivos fuente cambian, limitando la salida a las primeras 20 líneas:

$ find src/ | entr -s 'make | head -n 20'

Lanzar y recargar automáticamente un servidor node.js:

$ ls *.js | entr -r node app.js

Borrar la pantalla y ejecutar una consulta después de que el script SQL se actualice:

$ echo my.sql | entr -cp psql -f /_

Reconstruir el proyecto si se modifica un archivo fuente o se añade al directorio src/:

$ while sleep 0.1; do ls src/*.rb | entr -d make; done

Recargar automáticamente un servidor web, o terminar si el servidor sale

$ ls * | entr -rz ./httpd
