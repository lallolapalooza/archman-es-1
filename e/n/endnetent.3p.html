ENDNETENT(3P) Manual del programador POSIX ENDNETENT(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

endnetent, getnetbyaddr, getnetbyname, getnetent, setnetent — funciones de la base de datos de redes

SINOPSIS

#include <netdb.h>
void endnetent(void);
struct netent *getnetbyaddr(uint32_t net, int type);
struct netent *getnetbyname(const char *name);
struct netent *getnetent(void);
void setnetent(int stayopen);

DESCRIPCIÓN

Estas funciones recuperan información sobre redes. Se considera que esta información está almacenada en una base de datos a la que se puede acceder secuencialmente o de forma aleatoria. La implementación de esta base de datos no se especifica.

La función setnetent() abre y rebobina la base de datos. Si el argumento stayopen es distinto de cero, la conexión a la base de datos de net no se cerrará después de cada llamada a getnetent() (ya sea directamente o indirectamente a través de una de las otras funciones getnet*()), y la implementación puede mantener un descriptor de archivo abierto a la base de datos.

La función getnetent() lee la siguiente entrada de la base de datos, abriendo y cerrando una conexión a la base de datos según sea necesario.

La función getnetbyaddr() busca en la base de datos desde el principio y encuentra la primera entrada para la que la familia de direcciones especificada por type coincide con el miembro n_addrtype y el número de red net coincide con el miembro n_net, abriendo y cerrando una conexión a la base de datos según sea necesario. El argumento net será el número de red en orden de bytes del host.

La función getnetbyname() busca en la base de datos desde el principio y encuentra la primera entrada para la que el nombre de red especificado por name coincide con el miembro n_name, abriendo y cerrando una conexión a la base de datos según sea necesario.

Las funciones getnetbyaddr(), getnetbyname() y getnetent() devolverán cada una un puntero a una estructura netent, cuyos miembros contendrán los campos de una entrada en la base de datos de redes.

La función endnetent() cierra la base de datos, liberando cualquier descriptor de archivo abierto.

Estas funciones no necesitan ser seguras para hilos.

VALOR DE RETORNO

Tras una finalización exitosa, getnetbyaddr(), getnetbyname() y getnetent() devolverán un puntero a una estructura netent si se encontró la entrada solicitada, y un puntero nulo si se alcanzó el final de la base de datos o no se encontró la entrada solicitada. En caso contrario, se devolverá un puntero nulo.

La aplicación no debe modificar la estructura a la que apunta el valor de retorno, ni las áreas de almacenamiento a las que apuntan los punteros dentro de la estructura. El puntero devuelto, y los punteros dentro de la estructura, pueden invalidarse o la estructura o las áreas de almacenamiento pueden ser sobrescritas por una llamada posterior a getnetbyaddr(), getnetbyname() o getnetent(). El puntero devuelto, y los punteros dentro de la estructura, también pueden invalidarse si se termina el hilo que llama.

ERRORES

No se definen errores.
