    NAME

    env_parallel - run commands in parallel, setting environment variables

    SYNOPSIS

    env_parallel [OPTIONS] COMMAND [ARG...]

    env_parallel [OPTIONS] [&lt;TEMPLATE]...

    DESCRIPTION

    The env_parallel utility runs COMMAND multiple times in parallel. It is a wrapper around parallel(1) which sets environment variables. For most use cases, parallel(1) is a better choice.

    The first argument is the command to be run. If it starts with a template, then env_parallel will read the input from stdin and run the command for each line of input, replacing the template string with the line. The template string must be enclosed in quotes or apostrophes.

    By default, env_parallel runs one job per CPU core. The number of jobs can be controlled with the --jobs option.

    The environment variables that are set are:

    • PARALLEL_SEQ: The sequence number of the job (starting from 1).
    • PARALLEL_SLAVE: The number of the job (starting from 1).
    • PARALLEL_JOB: The job number (starting from 0).
    • PARALLEL_PID: The PID of the job.
    • PARALLEL_TIMESTAMP: The timestamp of the job.
    • PARALLEL_HOST: The hostname of the job.
    • PARALLEL_RETRY: The number of retries for the job (starting from 0).
    • PARALLEL_SUCCESS: Whether the job succeeded (1) or failed (0).

    OPTIONS

    --jobs N
    Run at most N jobs in parallel. The default is the number of CPU cores.
    --results DIR
    Store the results (stdout and stderr) in the specified directory.
    --timeout SEC
    Kill jobs that run longer than SEC seconds.
    --verbose
    Print verbose output.
    --dry-run
    Print the commands to be executed, but do not execute them.
    --help
    Print a help message and exit.
    --version
    Print version information and exit.

    SUPPORTED SHELLS

    env_parallel supports the following shells:

    • bash
    • sh
    • zsh
    • csh
    • ksh

    EXIT STATUS

    env_parallel returns the exit status of the last executed command.
