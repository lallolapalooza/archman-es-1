NOMBRE

Encode::PerlIO -- un documento detallado sobre Encode y PerlIO

Descripción general

Es muy común querer realizar transformaciones de codificación al leer o escribir archivos, conexiones de red, tuberías, etc. Si Perl está configurado para usar el nuevo sistema de E/S 'perlio', entonces "Encode" proporciona una "capa" (ver PerlIO) que puede transformar los datos a medida que se leen o se escriben.

Así es como el poeta ciego modernizaría la codificación:

use Encode;
open(my $iliad,'<:encoding(iso-8859-7)','iliad.greek');
open(my $utf8,'>:utf8','iliad.utf8');
my @epic = <$iliad>;
print $utf8 @epic;
close($utf8);
close($illiad);

Además, el nuevo sistema de E/S también se puede configurar para leer/escribir caracteres codificados en UTF-8 (como se mencionó anteriormente, esto es eficiente):

open(my $fh,'>:utf8','anything');
print $fh "Any \x{0021} string \N{SMILEY FACE}\n";

Cualquiera de las formas de especificación de "capa" anteriores puede convertirse en el valor predeterminado para un ámbito léxico con la "use open ..." directiva. Ver open.

Una vez que un manejador está abierto, sus capas se pueden alterar usando "binmode".

Sin ninguna configuración de este tipo, o si el propio Perl está compilado usando el E/S propio del sistema, entonces las operaciones de escritura asumen que el manejador de archivo acepta solo bytes y hará un "die" si se escribe en el manejador un carácter mayor que 255. Al leer, cada octeto del manejador se convierte en un byte-en-un-carácter. Tenga en cuenta que este comportamiento predeterminado es el mismo que el que tendrían los lenguajes de solo bytes (incluido Perl antes de la v5.6) y es suficiente para manejar codificaciones nativas de 8 bits, p. ej. iso-8859-1, EBCDIC, etc., y cualquier mecanismo heredado para manejar otras codificaciones y datos binarios.

En otros casos, es responsabilidad del programa transformar caracteres en bytes usando la API anterior antes de realizar escrituras, y transformar los bytes leídos de un manejador en caracteres antes de realizar "operaciones sobre caracteres" (p. ej. "lc", "/\W+/", ...).

También puede usar PerlIO para convertir grandes cantidades de datos que no desea cargar en la memoria. Por ejemplo, para convertir entre ISO-8859-1 (Latin 1) y UTF-8 (o UTF-EBCDIC en máquinas EBCDIC):

open(F, "<:encoding(iso-8859-1)", "data.txt") or die $!;
open(G, ">:utf8",                 "data.utf") or die $!;
while (<F>) { print G }
# También se podría hacer "print G <F>", pero eso cargaría
# el archivo completo en la memoria solo para escribirlo de nuevo.

Más ejemplos:

open(my $f, "<:encoding(cp1252)")
open(my $g, ">:encoding(iso-8859-2)")
open(my $h, ">:encoding(latin9)")       # iso-8859-15

Ver también encoding para saber cómo cambiar la codificación predeterminada de los datos en su script.

¿Cómo funciona?

Aquí hay un diagrama crudo de cómo interactúan el manejador de archivo, PerlIO y Encode.

filehandle <-> PerlIO        PerlIO <-> scalar (read/printed)
                     \      /
                      Encode

Cuando PerlIO recibe datos de cualquiera de las direcciones, llena un búfer (actualmente con 1024 bytes) y pasa el búfer a Encode. Encode intenta convertir la parte válida y la devuelve a PerlIO, dejando las partes inválidas (generalmente un carácter parcial) en el búfer. PerlIO luego agrega más datos al búfer, llama a Encode de nuevo, y así sucesivamente hasta que el flujo de datos termina.

Para hacer esto, PerlIO siempre llama a los métodos (de|en)code con CHECK establecido en 1. Esto asegura que el método se detenga en el lugar correcto cuando encuentre un carácter parcial. Lo siguiente es lo que sucede cuando PerlIO y Encode intentan codificar (desde utf8) más de 1024 bytes y el límite del búfer ocurre en medio de un carácter.

 A   B   C   ....   ~     \x{3000}    ....
41  42  43   ....  7E   e3   80   80  ....
<- buffer --------------->
<< encoded >>>>>>>>>>
                     <- next buffer ------

Encode convierte desde el principio hasta \x7E, dejando \xe3 en el búfer porque es inválido (carácter parcial).

Desafortunadamente, este esquema no funciona bien con codificaciones basadas en secuencias de escape como ISO-2022-JP.

Búfer por líneas

Ahora veamos qué sucede cuando intenta decodificar desde ISO-2022-JP y el búfer termina en medio de un carácter.

            JIS208-ESC   \x{5f3e}
 A   B   C   ....   ~   \e   $   B  |DAN | ....
41  42  43   ....  7E   1b  24  41  43  46 ....
<- buffer --------------------------->
<< encoded >>>>>>>>>>>>>>>>>>>>>>>

Como puede ver, el siguiente búfer comienza con \x43. Pero \x43 es 'C' en ASCII, lo cual es incorrecto en este caso porque ahora estamos en el área JISX 0208, así que tiene que convertir \x43\x46, no \x43. A diferencia de utf8 y EUC, en codificaciones basadas en secuencias de escape no se puede saber si un octeto dado es un carácter completo o solo una parte de él.

Afortunadamente, PerlIO también admite búfer por línea si le indica a PerlIO que use uno en lugar de un búfer de tamaño fijo. Dado que se garantiza que ISO-2022-JP vuelve a ASCII al final de la línea, un carácter parcial nunca ocurrirá cuando se use el búfer por línea.

Para indicarle a PerlIO que use búfer por línea, implemente el método ->needs_lines para su objeto de codificación. Ver Encode::Encoding para más detalles.

Gracias a estos esfuerzos, la mayoría de las codificaciones que vienen con Encode admiten PerlIO, pero aún quedan las siguientes codificaciones.

iso-2022-kr
MIME-B
MIME-Header
MIME-Q

Afortunadamente, iso-2022-kr rara vez se usa (según Jungshik) y es muy poco probable que MIME-* se pasen a PerlIO porque son para encabezados de correo electrónico. Ver Encode::MIME::Header para más detalles.

¿Cómo puedo saber si mi codificación admite completamente PerlIO?

Al momento de escribir esto, cualquier codificación cuya clase pertenezca a Encode::XS y Encode::Unicode funciona. El módulo Encode tiene un "perlio_ok" método que puede usar antes de aplicar la codificación PerlIO al manejador de archivo. Aquí hay un ejemplo:

my $use_perlio = perlio_ok($enc);
my $layer = $use_perlio ? "<:raw" : "<:encoding($enc)";
open my $fh, $layer, $file or die "$file : $!";
while(<$fh>){
  $_ = decode($enc, $_) unless $use_perlio;
  # .... 
}
