NOMBRE

encguess - adivinar codificaciones de caracteres de archivos

VERSIÓN

$Id: encguess,v 0.4 2023/11/10 01:10:50 dankogai Exp $

SINOPSIS

encguess [opciones] nombre_archivo...

OPCIONES

-h
mostrar este mensaje y salir.
-s
especificar una lista de "tipos de codificación sospechosos" para probar, separados por ":" o ","
-S
mostrar una lista de todos los tipos de codificación aceptables que se pueden usar con el parámetro -s
-u
suprimir la visualización de tipos no identificados

EJEMPLOS:

  • Adivinar la codificación de un archivo llamado "test.txt", usando solo los tipos sospechosos por defecto. 
    encguess test.txt
  • Adivinar el tipo de codificación de un archivo llamado "test.txt", usando los tipos sospechosos "euc-jp,shiftjis,7bit-jis". 
    encguess -s euc-jp,shiftjis,7bit-jis test.txt
encguess -s euc-jp:shiftjis:7bit-jis test.txt
  • Adivinar el tipo de codificación de varios archivos, no mostrar resultados para archivos no identificados. 
    encguess -us euc-jp,shiftjis,7bit-jis test*.txt

DESCRIPCIÓN

La identificación de la codificación se realiza comprobando un tipo de codificación a la vez hasta que se eliminan todos excepto el correcto. El conjunto de tipos de codificación a probar se define mediante el parámetro -s y, por defecto, es ascii, utf8 y UTF-16/32 con BOM. Esto se puede anular pasando uno o más tipos de codificación a través del parámetro -s. Si necesita pasar múltiples tipos de codificación sospechosos, use una cadena entre comillas con un espacio separando cada valor.

VER TAMBIÉN

Encode::Guess, Encode::Detect
