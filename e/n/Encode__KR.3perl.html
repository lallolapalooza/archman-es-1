Encode::KR(3perl) Guía de referencia para programadores de Perl Encode::KR(3perl)

NOMBRE

Encode::KR - Codificaciones coreanas

SINOPSIS

use Encode qw/encode decode/; 
$euc_kr = encode("euc-kr", $utf8);   # carga Encode::KR implícitamente
$utf8   = decode("euc-kr", $euc_kr); # lo mismo

DESCRIPCIÓN

Este módulo implementa codificaciones de juegos de caracteres coreanos. Las codificaciones soportadas son las siguientes.

Canónica    Alias             Descripción
--------------------------------------------------------------------
euc-kr      /\beuc.*kr$/i     EUC (Extended Unix Character)
        /\bkr.*euc$/i
ksc5601-raw                   Conjunto de códigos estándar coreano (tal cual)
cp949       /(?:x-)?uhc$/i
            /(?:x-)?windows-949$/i
            /\bks_c_5601-1987$/i
                              Página de códigos 949 (EUC-KR + 8.822 sílabas Hangul adicionales)
MacKorean                     EUC-KR + Mapeos del proveedor de Apple
johab       JOHAB             Una codificación suplementaria definida en 
                                           el Anexo 3 de KS X 1001:1998
iso-2022-kr                   iso-2022-kr                  [RFC1557]
--------------------------------------------------------------------

Para saber cómo usar este módulo en detalle, consulte Encode.

ERRORES

Cuando ve "charset=ks_c_5601-1987" en correos y páginas web, en realidad significan codificaciones "cp949". Para solucionarlo, se establecen los siguientes alias:

qr/(?:x-)?uhc$/i         => '"cp949"'
qr/(?:x-)?windows-949$/i => '"cp949"'
qr/ks_c_5601-1987$/i     => '"cp949"'

La región ASCII (0x00-0x7f) se conserva para todas las codificaciones, aunque esto entre en conflicto con los mapeos del Consorcio Unicode.
