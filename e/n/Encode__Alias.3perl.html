Encode::Alias(3perl) Guía de referencia para programadores de Perl Encode::Alias(3perl)

NOMBRE

Encode::Alias - alias para codificaciones

SINOPSIS

use Encode;
use Encode::Alias;
define_alias( "nuevoNombre" => CODIFICACION);
define_alias( qr/.../ => CODIFICACION);
define_alias( sub { return CODIFICACION if ...; } );

DESCRIPCIÓN

Permite que nuevoNombre sea usado como un alias para CODIFICACION. CODIFICACION puede ser el nombre de una codificación o un objeto de codificación (como se describe en Encode).

Actualmente, el primer argumento de define_alias() puede ser especificado de las siguientes maneras:

Como una cadena simple.
Como una expresión regular compilada qr//, por ejemplo:
define_alias( qr/^iso8859-(\d+)$/i => '"iso-8859-$1"' );

En este caso, si CODIFICACION no es una referencia, se le aplica "eval" para permitir que $1 etc. sean sustituidos. El ejemplo es una forma de alias para nombres como los usados en fuentes X11 a nombres MIME para la familia iso-8859-*. Nótese las comillas dobles dentro de las comillas simples.

(o, no tiene que hacer esto usted mismo porque este ejemplo ya está predefinido)

Si está usando una expresión regular aquí, debe usar las comillas como se muestra o no funcionará. También tenga en cuenta que el manejo de expresiones regulares es complicado incluso para los experimentados. Use esta característica con precaución.

Como una referencia de código, por ejemplo:
define_alias( sub {shift =~ /^iso8859-(\d+)$/i ? "iso-8859-$1" : undef } );

El mismo efecto que el ejemplo anterior de una manera diferente. La referencia de código toma el nombre del alias como argumento y devuelve un nombre canónico en caso de éxito o undef si no. Tenga en cuenta que el segundo argumento se ignora si se proporciona. Úselo con aún más precaución que la versión con expresión regular.

Cambios en el aliasing de referencias de código

A partir de Encode 1.87, la forma antigua

define_alias( sub { return  /^iso8859-(\d+)$/i ? "iso-8859-$1" : undef } );

ya no funciona.

Encode hasta la versión 1.86 usaba internamente "local $_" para implementar esta forma antigua. Pero considere el siguiente código:

use Encode;
$_ = "eeeee" ;
while (/(e)/g) {
  my $utf = decode('aliased-encoding-name', $1);
  print "position:",pos,"\n";
}

Antes de Encode 1.86 esto falla debido a "local $_".

Sobrecarga de alias

Puede sobrescribir alias predefinidos simplemente aplicando define_alias(). El nuevo alias siempre se evalúa primero y, cuando es necesario, define_alias() vacía la caché interna para hacer que la nueva definición esté disponible.

# redirige SHIFT_JIS a MS/IBM Code Page 932, que es un
# superconjunto de SHIFT_JIS
define_alias( qr/shift.*jis$/i  => '"cp932"' );
define_alias( qr/sjis$/i        => '"cp932"' );

Si desea eliminar todos los alias predefinidos, puede usar

Encode::Alias->undef_aliases;

para hacerlo. Y

Encode::Alias->init_aliases;

restaura la configuración de fábrica.

Tenga en cuenta que define_alias() no podrá sobrescribir el nombre canónico de las codificaciones. Las codificaciones se buscan primero por su nombre canónico antes de que se intenten los alias potenciales.
