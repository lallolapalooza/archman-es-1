NOMBRE

Encode::EBCDIC - Codificaciones EBCDIC

SINOPSIS

use Encode qw/encode decode/; 
$posix_bc  = encode("posix-bc", $utf8); # carga Encode::EBCDIC implícitamente
$utf8 = decode("", $posix_bc);          # ídem

RESUMEN

Este módulo implementa varias codificaciones basadas en EBCDIC. Las codificaciones soportadas son las siguientes.

Canónica    Alias           Descripción
--------------------------------------------------------------------
cp37  
cp500  
cp875  
cp1026  
cp1047  
posix-bc

DESCRIPCIÓN

Para saber cómo usar este módulo en detalle, véase Encode.
