ENFUSE(1) Comandos de usuario ENFUSE(1)

NOMBRE

enfuse - página del manual de enfuse 4.2.1-0bcfaaf743e7

SINOPSIS

enfuse [opciones] [--output=IMAGEN] ENTRADA...

DESCRIPCIÓN

Fusiona las imágenes ENTRADA en una sola IMAGEN.

ENTRADA... son nombres de archivo de imagen o nombres de archivo de respuesta. Los nombres de archivo de respuesta comienzan con el carácter "@".

OPCIONES

Opciones comunes:

-l, --levels=NIVELES
limita el número de NIVELES de fusión a utilizar (1 a 29); un número negativo de NIVELES reduce el máximo; "auto" restaura la maximización automática predeterminada
-o, --output=ARCHIVO
escribe la salida en ARCHIVO; predeterminado: "a.tif"
-v, --verbose[=NIVEL]
informa del progreso de forma detallada; repita para aumentar el nivel de detalle o establezca directamente el NIVEL
--compression=COMPRESSION
establece la compresión de la imagen de salida a COMPRESSION, donde COMPRESSION es: "deflate", "jpeg", "lzw", "none", "packbits" para archivos TIFF y de 0 a 100, o "jpeg", "jpeg-arith" para archivos JPEG, donde "jpeg" y "jpeg-arith" aceptan un nivel de compresión

Opciones avanzadas:

--blend-colorspace=ESPACIO-DE-COLOR
fuerza el ESPACIO-DE-COLOR para las operaciones de fusión; Enfuse usa "CIELUV" para imágenes con perfil ICC y "IDENTITY" para las que no lo tienen, y también para todas las imágenes de punto flotante; otros espacios de color de fusión disponibles son "CIELAB" y "CIECAM"
-c, --ciecam
usa CIECAM02 para fusionar colores; desactive con "--no-ciecam"; tenga en cuenta que esta opción se retirará en favor de "--blend-colorspace"
-d, --depth=PROFUNDIDAD
establece el número de bits por canal de la imagen de salida, donde PROFUNDIDAD es "8", "16", "32", "r32" o "r64"
-f ANCHOxALTO[+xXOFFSET+yYOFFSET]
establece manualmente el tamaño y la posición de la imagen de salida; útil para imágenes TIFF de entrada recortadas y desplazadas, como las producidas por Nona
-g
truco de alfa asociado para Gimp (antes de la versión 2) y Cinepaint
-w, --wrap[=MODO]
envuelve alrededor del límite de la imagen, donde MODO es "none", "horizontal", "vertical" o "both"; predeterminado: none; sin argumento, la opción selecciona el envoltorio horizontal

Opciones de fusión:

--exposure-weight=PESO
peso dado a los píxeles bien expuestos (0 <= PESO <= 1); predeterminado: 1
--saturation-weight=PESO
peso dado a los píxeles altamente saturados (0 <= PESO <= 1); predeterminado: 0.2
--contrast-weight=PESO
peso dado a los píxeles en vecindarios de alto contraste (0 <= PESO <= 1); predeterminado: 0
--entropy-weight=PESO
peso dado a los píxeles en vecindarios de alta entropía (0 <= PESO <= 1); predeterminado: 0
--exposure-optimum=ÓPTIMO
valor de exposición óptimo, generalmente el máximo de la función de ponderación (0 <= ÓPTIMO <= 1); predeterminado: 0.5
--exposure-width=ANCHO
ancho característico de la función de ponderación (ANCHO > 0); predeterminado: 0.2
--soft-mask
promedia sobre todas las máscaras; esto es lo predeterminado
--hard-mask
fuerza máscaras de fusión duras y sin promediado en la escala más fina; esto es especialmente útil para pilas de enfoque con características finas y de alto contraste, pero conduce a un aumento del ruido

Opciones de experto:

--save-masks[=PLANTILLA-SUAVE[:PLANTILLA-DURA]]
guarda las máscaras de peso en PLANTILLA-SUAVE y PLANTILLA-DURA; caracteres de conversión: "%i": índice de la máscara, "%n": número de la máscara, "%p": ruta completa, "%d": nombre del directorio, "%b": nombre base, "%f": nombre del archivo, "%e": extensión; los caracteres en minúscula se refieren a las imágenes de entrada y en mayúscula a la imagen de salida predeterminado: "softmask-%n.tif":"hardmask-%n.tif"
--load-masks[=PLANTILLA-SUAVE[:PLANTILLA-DURA]]
omite el cálculo de los mapas de peso y usa los que se encuentran en los archivos que coinciden con las plantillas. Estos pueden ser máscaras duras o suaves. Para la sintaxis de las plantillas, consulte "--save-masks"; predeterminado: "softmask-%n.tif":"hardmask-%n.tif"
--fallback-profile=ARCHIVO-DE-PERFIL
usa el perfil ICC de ARCHIVO-DE-PERFIL en lugar de sRGB
--layer-selector=ALGORITMO
establece el ALGORITMO del selector de capas; predeterminado: "all-layers"; los algoritmos disponibles son: "all-layers": selecciona todas las capas en cualquier imagen; "first-layer": selecciona solo la primera capa en cada imagen (multi)capa; "last-layer": selecciona solo la última capa en cada imagen (multi)capa; "largest-layer": selecciona la capa más grande en cada imagen (multi)capa; "no-layer": no selecciona ninguna capa de ninguna imagen;
--parameter=CLAVE1[=VALOR1][:CLAVE2[=VALOR2][:...]]
establece uno o más pares CLAVE-VALOR

Opciones de fusión de experto:

--exposure-weight-function=FUNCIÓN-DE-PESO
(1ª forma) selecciona una de las FUNCIONES-DE-PESO de exposición integradas: "gaussian", "lorentzian", "half-sine", "full-sine" o "bi-square"; predeterminado: "gaussian"
--exposure-weight-function=OBJETO-COMPARTIDO:SÍMBOLO[:ARGUMENTO[:...]]
(2ª forma) carga la función de peso de exposición definida por el usuario SÍMBOLO desde OBJETO-COMPARTIDO y opcionalmente pasa ARGUMENTOs
--exposure-cutoff=CORTE-INFERIOR[:CORTE-SUPERIOR[:PROYECTOR-INFERIOR[:PROYECTOR-SUPERIOR]]]
CORTE-INFERIOR y CORTE-SUPERIOR son los valores por debajo o por encima de los cuales los píxeles se ponderan con peso cero en la ponderación de exposición; añada símbolos "%" para valores relativos; predeterminado: 0%:100%:anti-valor:valor
--contrast-window-size=TAMAÑO
establece el TAMAÑO de la ventana para el análisis de contraste local (TAMAÑO >= 3); predeterminado: 5
--contrast-edge-scale=ESCALA-DE-BORDE[:ESCALA-LCE[:FACTOR-LCE]]
establece la escala en la que buscar bordes; una ESCALA-LCE positiva activa la mejora de contraste local por FACTOR-LCE (ESCALA-DE-BORDE, ESCALA-LCE, FACTOR-LCE >= 0); añada "%" a ESCALA-LCE para valores relativos a ESCALA-DE-BORDE; añada "%" a FACTOR-LCE para un valor relativo; predeterminado: 0:0:0
--contrast-min-curvature=CURVATURA
CURVATURA mínima para que un borde califique; añada "%" para valores relativos; predeterminado: 0

NAME

enfuse - blend exposures to high dynamic range images

SYNOPSIS

enfuse [OPTIONS] INPUTFILES...

DESCRIPTION

Enfuse is a command-line tool that blends multiple images of the same scene with different exposures into a single high dynamic range (HDR) image. It can also be used to create images with higher resolution or to reduce noise.

Enfuse can be used for:

  • Generating HDR images from bracketed exposures.
  • Reducing noise by averaging multiple exposures of the same scene.
  • Increasing resolution by combining multiple images of the same scene.
  • Creating images with better focus by selecting the sharpest parts of multiple images.

Enfuse uses a weighted average approach, where each pixel in the output image is a weighted average of the corresponding pixels in the input images. The weights are determined by various factors, such as exposure, contrast, and saturation.

OPTIONS

The following options are available:

Exposure and contrast weighting options:

--gray-projector=PROJECTOR
apply gray-scale PROJECTOR in exposure or contrast weighing, where PROJECTOR is one of "anti-value", "average", "l-star", "lightness", "luminance", "pl-star", "value", or "channel-mixer:RED-WEIGHT:GREEN-WEIGHT:BLUE-WEIGHT"; default: "average"
--entropy-window-size=SIZE
set window SIZE for local entropy analysis (SIZE >= 3); default: 3
--entropy-cutoff=LOWERCUTOFF[:UPPERCUTOFF]
LOWERCUTOFF is the value below of which pixels are treated as black and UPPERCUTOFF is the value above of which pixels are treated as white in the entropy weighting; append "%" signs for relative values; default: 0%:100%

Information options:

-h, --help
print this help message and exit
-V, --version
output version information and exit
--show-globbing-algorithms
show all globbing algorithms
--show-image-formats
show all recognized image formats and their filename extensions
--show-signature
show who compiled the binary when and on which machine
--show-software-components
show the software components with which Enfuse was compiled

Enfuse accepts arguments to any option in uppercase as well as in lowercase letters.

ENVIRONMENT

OMP_NUM_THREADS
The OMP_NUM_THREADS environment variable sets the number of threads to use in OpenMP parallel regions. If unset Enfuse uses as many threads as there are CPUs.
OMP_DYNAMIC
The OMP_DYNAMIC environment variable controls dynamic adjustment of the number of threads to use in executing OpenMP parallel regions.
