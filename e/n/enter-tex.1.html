ENTER-TEX(1) Comandos de usuario ENTER-TEX(1)

NOMBRE

enter-tex - Editor de texto TeX/LaTeX

SINOPSIS

enter-tex [OPCIONES] [ARCHIVOS]

enter-tex {-h | --help | --help-all | --help-gtk}

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando enter-tex.

Enter TeX es un editor de texto TeX/LaTeX.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que empiezan con dos guiones. A continuación se incluye un resumen de las opciones. Para una descripción completa de las opciones, utilice enter-tex --help.

-n, --new-document

Crea un nuevo documento.

--new-window

Crea una nueva ventana de nivel superior en una instancia existente de Enter TeX

--display=DISPLAY

Pantalla X a utilizar

-h, --help

Muestra un resumen de las opciones comunes.

--help-all

Muestra un resumen de todas las opciones.

--help-gtk

Muestra un resumen de las opciones GTK+.

-V, --version

Muestra información de la versión.

NOTAS

Por defecto, cuando Enter TeX se inicia, reabre los archivos que estaban abiertos la última vez que se utilizó. Este comportamiento se puede desactivar en las preferencias del programa.
