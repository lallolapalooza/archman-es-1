NOMBRE

eapol_test - Pruebas de cliente EAP peer y RADIUS

SINOPSIS

eapol_test [ -nWS ] [ -carchivo de configuración ] [ -adirección IP del servidor ] [ -Adirección IP del cliente ] [ -ppuerto UDP ] [ -ssecreto compartido ] [ -rreautenticaciones ] [ -ttiempo de espera ] [ -CInformación de conexión ] [ -Mdirección MAC ] [ -oarchivo ] [ -Nespecificación de atributo ]

eapol_test scard

eapol_test sim [ PIN ] [ número de tríos ]

DESCRIPCIÓN GENERAL

eapol_test es un programa que une la misma implementación de peer EAP que utiliza wpa_supplicant y el código del cliente de autenticación RADIUS de hostapd. Además, tiene un código de enlace mínimo para combinar estos dos componentes de maneras similares a las máquinas de estado del Autenticador IEEE 802.1X/EAPOL. En otras palabras, integra el Autenticador IEEE 802.1X (normalmente, un punto de acceso) y el Cliente IEEE 802.1X (normalmente, un cliente inalámbrico) para generar un único programa que se puede usar para probar métodos EAP sin tener que configurar un punto de acceso y un cliente inalámbrico.

Los principales usos de eapol_test son las pruebas de interoperabilidad de los métodos EAP contra servidores RADIUS y las pruebas de desarrollo para nuevos métodos EAP. Se puede utilizar fácilmente para automatizar las pruebas EAP para interoperabilidad y regresión, ya que el programa se puede ejecutar desde scripts de shell sin requerir componentes de prueba adicionales aparte de un servidor RADIUS. Por ejemplo, las pruebas EAP automatizadas descritas en eap_testing.txt se implementan con eapol_test. De manera similar, eapol_test podría usarse para implementar un conjunto de pruebas de regresión automatizadas para un servidor de autenticación RADIUS.

Como ejemplo:

eapol_test -ctest.conf -a127.0.0.1 -p1812 -ssecret -r1

intenta completar la autenticación EAP basándose en la configuración de red de test.conf contra el servidor RADIUS que se ejecuta en el host local. Se activa una reautenticación para probar la reautenticación rápida. El archivo de configuración utiliza el mismo formato para los bloques de red que wpa_supplicant.

ARGUMENTOS DEL COMANDO

-c ruta del archivo de configuración
Una configuración a utilizar. La configuración debe usar el mismo formato para los bloques de red que wpa_supplicant.
-a dirección del servidor de autenticación (AS)
Dirección IP del servidor de autenticación. El valor predeterminado es '127.0.0.1'.
-A dirección del cliente
Dirección IP del cliente. El valor predeterminado es seleccionar una dirección automáticamente.
-p puerto del servidor de autenticación (AS)
Puerto UDP del servidor de autenticación. El valor predeterminado es '1812'.
-s secreto del servidor de autenticación (AS)
Secreto compartido con el servidor de autenticación. El valor predeterminado es 'radius'.
-r recuento
Número de reautenticaciones.
-t tiempo de espera
Tiempo de espera en segundos. El valor predeterminado es 30.
-C información
Información de conexión RADIUS. El valor predeterminado es
-M dirección mac
Dirección MAC del cliente (Calling-Station-Id). El valor predeterminado es '02:00:00:00:00:01'.
-o archivo
Ubicación donde escribir el certificado del servidor.
-N especificación de atributo
Enviar atributo arbitrario especificado por id_atributo:sintaxis:valor, o solo id_atributo. id_atributo debe ser el ID numérico del atributo y sintaxis debe ser uno de 's' (cadena), para enviar. Cuando se proporciona solo id_atributo, se usa NULL como valor del atributo. Se pueden especificar múltiples atributos usando la opción varias veces.
-n
Indica que no se esperan claves MPPE.
-W
Espera a un monitor de interfaz de control antes de comenzar.
-S
Guarda la configuración después de la autenticación.
