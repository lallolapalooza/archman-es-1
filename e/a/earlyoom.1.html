Cualquier retraso de este tipo, y los recursos adicionales tomados por el proceso generado, siempre tienen un costo y estresan aún más el sistema ya estresado. Use

NAME

earlyoom - A low memory monitor

SYNOPSIS

earlyoom [ options ]

DESCRIPTION

earlyoom is a small daemon that monitors memory usage and kills processes when the system is running out of memory. It aims to prevent the kernel's OOM killer from being invoked, which can lead to unpredictable process termination.

OPTIONS

--memrestrict MEMORY
Set the memory threshold. If the system memory usage (excluding swap) exceeds this value, earlyoom will start killing processes. MEMORY can be specified in MiB (e.g., 1000) or as a percentage of total RAM (e.g., 50%). Default is 50%.
--swaprestrict SWAP
Set the swap threshold. If the swap usage exceeds this value, earlyoom will start killing processes. SWAP can be specified in MiB (e.g., 1000) or as a percentage of total swap space (e.g., 50%). Default is 50%.
--mempercent PERCENT
Set the memory threshold as a percentage of total RAM. Same as --memrestrict with a percentage value.
--swappercen PERCENT
Set the swap threshold as a percentage of total swap space. Same as --swaprestrict with a percentage value.
--io interval
Set the interval in seconds at which earlyoom checks memory usage. Default is 1 second.
--pkill process_name
Kill processes matching process_name when memory threshold is reached. This option can be used multiple times.
--kmem KILLED_MEM
Amount of memory to kill. Default is 100 MiB.
--kswap KILLED_SWAP
Amount of swap to kill. Default is 100 MiB.
--killoom oom_score_adj
Set the oom_score_adj for processes to be killed. Default is 500. This value is added to the process's current oom_score_adj. The kernel will then use this new value to decide which process to kill. A higher value means the process is more likely to be killed.
--prefer REGEX
Prefer killing processes whose comm name matches REGEX (adds 300 to oom_score).
--avoid REGEX
Avoid killing processes whose comm name matches REGEX (subtracts 300 from oom_score).
--ignore REGEX
Ignore processes whose comm name matches REGEX. These processes will never be killed by earlyoom.
--sort-by-rss
Sort processes by Resident Set Size (RSS) instead of oom_score when deciding which one to kill.
--dryrun
Do not kill any processes, just log what would be killed.
--syslog
Log messages to syslog instead of stdout/stderr.
-h, --help
Show help message and exit.

--pgrep REGEX

Kill processes whose comm name matches REGEX.

The comm name is the string in /proc/pid/comm. It is the first 15 bytes of the process name. Longer names are truncated to 15 bytes.

The comm name is also what top, pstree, ps -e show. Use any of these tools to find the proper comm name.

Example: Kill all processes with "bash" in their name:

earlyoom --pgrep bash

--pgrep-all REGEX

Kill processes whose comm name matches REGEX, even if they are otherwise protected by --avoid or --ignore options.

Example: Forcefully kill all processes with "firefox" in their name:

earlyoom --pgrep-all firefox

--target PID

Target a specific PID to kill. This option can be used multiple times.

earlyoom --target 1234 --target 5678

--target-all PID

Target a specific PID to kill, even if it is protected by --avoid or --ignore options.

earlyoom --target-all 1234

--group REGEX

Kill processes whose PGID matches REGEX.

Use `pstree -gT` to show all processes with the PGID in brackets.
