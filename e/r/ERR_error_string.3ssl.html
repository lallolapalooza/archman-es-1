ERR_error_string(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ERR_ERROR_STRING(3ssl) OpenSSL ERR_ERROR_STRING(3ssl)

NOMBRE

ERR_error_string, ERR_error_string_n, ERR_lib_error_string, ERR_func_error_string, ERR_reason_error_string - obtener mensaje de error legible por humanos

SINOPSIS

#include <openssl/err.h>
char *ERR_error_string(unsigned long e, char *buf);
void ERR_error_string_n(unsigned long e, char *buf, size_t len);
const char *ERR_lib_error_string(unsigned long e);
const char *ERR_reason_error_string(unsigned long e);

Obsoleto en OpenSSL 3.0:

const char *ERR_func_error_string(unsigned long e);

DESCRIPCIÓN

ERR_error_string() genera una cadena legible por humanos que representa el código de error e, y la coloca en buf. buf debe tener al menos 256 bytes de longitud. Si buf es NULL, la cadena de error se coloca en un buffer estático. Tenga en cuenta que esta función no es segura para hilos y no realiza comprobaciones sobre el tamaño del buffer; utilice ERR_error_string_n() en su lugar.

ERR_error_string_n() es una variante de ERR_error_string() que escribe como máximo len caracteres (incluyendo el terminador 0) y trunca la cadena si es necesario. Para ERR_error_string_n(), buf NO DEBE ser NULL.

La cadena tendrá el siguiente formato:

error:[código de error]:[nombre de la biblioteca]::[cadena de razón]

código de error es un número hexadecimal de 8 dígitos, nombre de la biblioteca y cadena de razón son texto ASCII.

ERR_lib_error_string() y ERR_reason_error_string() devuelven el nombre de la biblioteca y la cadena de razón respectivamente.

Si no hay una cadena de texto registrada para el código de error dado, la cadena de error contendrá el código numérico.

ERR_print_errors(3) puede usarse para imprimir todos los códigos de error actualmente en la cola.

VALORES DE RETORNO

ERR_error_string() devuelve un puntero a un buffer estático que contiene la cadena si buf == NULL, o buf en caso contrario.

ERR_lib_error_string() y ERR_reason_error_string() devuelven las cadenas, y NULL si no hay ninguna registrada para el código de error.

ERR_func_error_string() devuelve NULL.

VER TAMBIÉN

ERR_get_error(3), ERR_print_errors(3)

HISTORIAL

ERR_func_error_string() quedó obsoleto en OpenSSL 3.0.
