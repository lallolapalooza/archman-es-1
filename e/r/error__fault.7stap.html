NOMBRE

error::fault - fallos de acceso a memoria

DESCRIPCIÓN

Los fallos de lectura o escritura pueden ocurrir durante la operación de un script de systemtap, si el script causa la desreferenciación de un puntero que resulta ser inválido. Esto puede ser causado por el uso de variables de contexto que no tienen valores válidos, o quizás referencias a memoria que no está disponible en ese momento debido a paginación.

Estas condiciones de fallo son benignas porque son capturadas por el tiempo de ejecución de systemtap, que termina limpiamente el script. Si no se desea una terminación rápida, considere usar las opciones de stap --skip-badvars o --suppress-handler-errors o -DMAXERRORS=NN, o envolver las partes relevantes de los manejadores de sondas en un bloque try/catch.

Puede ser posible ajustar el programa de destino para que sea más probable que las variables de contexto necesarias se paginen cuando systemtap las busque. Considere agregar algún procesamiento ligero a las variables clave, como un strlen(foo) para una cadena, o iterar sobre los elementos de una matriz o lista enlazada, o acceder a algunos bytes de un bloque asignado en el heap. La idea es activar cualquier fallo de página en el programa de destino, antes de que systemtap necesite hacerlo (pero no puede).

VER TAMBIÉN

stap(1),
error::reporting(7stap)
