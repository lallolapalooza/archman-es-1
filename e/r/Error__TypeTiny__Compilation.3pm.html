NOMBRE

Error::TypeTiny::Compilation - excepción para Eval::TypeTiny

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Lanzada cuando la compilación de una clausura falla. Causas comunes son problemas con restricciones de tipo insertadas, y errores de sintaxis cuando las coerciones se dan como cadenas de código Perl.

Este paquete hereda de Error::TypeTiny; consulta ese para la mayor parte de la documentación. Las principales diferencias se enumeran a continuación:

Atributos

"code"
El código fuente de Perl que se está compilando.
"environment"
Hashref de variables que se cierran.
"errstr"
Mensaje de error del compilador de Perl.

ERRORES

Por favor, informa de cualquier error en https://github.com/tobyink/p5-type-tiny/issues.
