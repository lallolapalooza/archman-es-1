error(3) Manual de funciones de biblioteca error(3)

NOMBRE

error, error_at_line, error_message_count, error_one_per_line, error_print_progname - funciones de reporte de errores de glibc

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <error.h>
void error(int status, int errnum, const char *format, ...);
void error_at_line(int status, int errnum, const char *file,
                   unsigned int line, const char *format, ...);
extern unsigned int error_message_count;
extern int error_one_per_line;
extern typeof(void (void))  *error_print_progname;

DESCRIPCIÓN

error() es una función general de reporte de errores. Vacía stdout y luego envía a stderr el nombre del programa, dos puntos y un espacio, el mensaje especificado por la cadena de formato tipo printf(3), format y, si errnum no es cero, dos puntos y un espacio seguidos por la cadena dada por strerror(errnum). Cualquier argumento requerido para format debe seguir a format en la lista de argumentos. La salida se termina con un carácter de nueva línea.

El nombre del programa impreso por error() es el valor de la variable global program_invocation_name(3). program_invocation_name tiene inicialmente el mismo valor que argv[0] de main(). El valor de esta variable puede modificarse para cambiar la salida de error().

Si status tiene un valor distinto de cero, entonces error() llama a exit(3) para terminar el programa usando el valor dado como estado de salida; de lo contrario, retorna después de imprimir el mensaje de error.

La función error_at_line() es exactamente igual a error(), excepto por la adición de los argumentos file y line. La salida producida es como para error(), excepto que después del nombre del programa se escribe: dos puntos, el valor de file, dos puntos y el valor de line. Los valores preprocesados __LINE__ y __FILE__ pueden ser útiles al llamar a error_at_line(), pero también se pueden usar otros valores. Por ejemplo, estos argumentos podrían referirse a una ubicación en un archivo de entrada.

Si la variable global error_one_per_line se establece a un valor distinto de cero, una secuencia de llamadas a error_at_line() con el mismo valor de file y line resultará en una sola salida de mensaje (la primera).

La variable global error_message_count cuenta el número de mensajes que han sido emitidos por error() y error_at_line().

Si la variable global error_print_progname se asigna la dirección de una función (es decir, no es NULL), entonces esa función se llama en lugar de anteponer el nombre del programa y dos puntos al mensaje. La función debe imprimir una cadena adecuada en stderr.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
error () Seguridad de hilos MT-Safe locale
error_at_line () Seguridad de hilos MT-Unsafe race: error_at_line/error_one_per_line locale

La variable interna error_one_per_line se accede (sin ninguna forma de sincronización, pero como es un int usado una vez, debería ser suficientemente seguro), y si error_one_per_line se establece a un valor distinto de cero, las variables estáticas internas (no expuestas a los usuarios) utilizadas para mantener el último nombre de archivo y número de línea impresos se acceden y modifican sin sincronización; la actualización no es atómica y ocurre antes de deshabilitar la cancelación, por lo que solo puede ser interrumpida después de que una de las dos variables se modifique. Después de eso, error_at_line() es muy similar a error().
