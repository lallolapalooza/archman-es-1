ERR_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ERR_NEW(3ssl) OpenSSL ERR_NEW(3ssl)

NOMBRE

ERR_new, ERR_set_debug, ERR_set_error, ERR_vset_error - Bloques de construcción para el registro de errores

SINOPSIS

#include <openssl/err.h>
void ERR_new(void);
void ERR_set_debug(const char *file, int line, const char *func);
void ERR_set_error(int lib, int reason, const char *fmt, ...);
void ERR_vset_error(int lib, int reason, const char *fmt, va_list args);

DESCRIPCIÓN

Las funciones descritas aquí generalmente no se usan directamente, sino a través de macros como ERR_raise(3). Aún pueden ser útiles para cualquiera que quiera crear sus propias macros.

ERR_new() asigna un nuevo espacio en la cola de errores del hilo.

ERR_set_debug() establece la información de depuración relacionada con el error actual en la cola de errores del hilo. Los valores que se pueden proporcionar son el nombre del archivo file, la línea en el archivo line y el nombre de la función func donde ocurrió el error. Los nombres deben ser constantes, esta función solo guardará los punteros, no copiará las cadenas.

ERR_set_error() establece la información del error, que son el número de biblioteca lib y el código de razón reason, y datos adicionales como una cadena de formato fmt y un número arbitrario de argumentos. Los datos adicionales se procesan con BIO_snprintf(3) para formar la cadena de datos adicionales, que se asigna y se almacena en el registro de errores.

ERR_vset_error() funciona como ERR_set_error(), pero toma un argumento va_list en lugar de un número variable de argumentos.

VALORES DE RETORNO

ERR_new, ERR_set_debug, ERR_set_error y ERR_vset_error no devuelven ningún valor.

NOTAS

El número de biblioteca es único para cada unidad que registra errores. OpenSSL tiene varios preasignados para sus propios usos, pero otros pueden asignar su propio número de biblioteca dinámicamente con ERR_get_next_error_library(3).

Los códigos de razón son únicos dentro de cada biblioteca, y pueden tener un conjunto asociado de cadenas como una breve descripción de la razón. Para números de biblioteca asignados dinámicamente, las cadenas de razón se registran con ERR_load_strings(3).

A los autores de proveedores se les proporcionan versiones básicas de estas funciones, consulte provider-base(7).

VER TAMBIÉN

ERR_raise(3), ERR_get_next_error_library(3), ERR_load_strings(3), BIO_snprintf(3), provider-base(7)
