error(n) Comandos integrados de Tcl error(n)

NOMBRE

error - Generar un error

SINOPSIS

error mensaje ?info? ?código?

DESCRIPCIÓN

Devuelve un código TCL_ERROR, que provoca el desenrollado de la interpretación del comando. Mensaje es una cadena que se devuelve a la aplicación para indicar qué salió mal.

La opción de retorno -errorinfo de un intérprete se utiliza para acumular un rastreo de la pila de lo que estaba en progreso cuando ocurrió un error; a medida que los comandos anidados se desenrollan, el intérprete Tcl agrega información a la opción de retorno -errorinfo. Si el argumento info está presente, se utiliza para inicializar las opciones de retorno -errorinfo y el primer incremento de información de desenrollado no será agregado por el intérprete Tcl. En otras palabras, el comando que contiene el comando error no aparecerá en el rastreo de la pila; en su lugar estará info. Históricamente, esta característica ha sido más útil en conjunción con el comando catch: si un error capturado no puede manejarse exitosamente, info puede usarse para devolver un rastreo de pila que refleje el punto original de ocurrencia del error:

catch {...} errMsg
set savedInfo $::errorInfo
...
error $errMsg $savedInfo

Al trabajar con Tcl 8.5 o posterior, se debe usar el siguiente código en su lugar:

catch {...} errMsg options
...
return -options $options $errMsg

Si el argumento código está presente, su valor se almacena en la opción de retorno -errorcode. La opción de retorno -errorcode está destinada a contener una descripción legible por máquina del error en casos donde dicha información está disponible; consulte la página del manual de return para obtener información sobre el formato adecuado para el valor de esta opción.

EJEMPLO

Generar un error si falla una operación matemática básica:

if {1+2 != 3} {
    error "algo va muy mal con la suma"
}
