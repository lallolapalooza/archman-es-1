NOMBRE

Error::TypeTiny::Assertion - excepción cuando un valor falla una restricción de tipo

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Esta excepción se lanza cuando un valor falla una aserción de restricción de tipo.

Este paquete hereda de Error::TypeTiny; véase este último para la mayor parte de la documentación. Las diferencias principales se enumeran a continuación:

Atributos

"type"
La restricción de tipo que se verificó. Se involucran enlaces debilitados, por lo que esto puede terminar siendo "undef".
"value"
El valor que se probó.
"varname"
El nombre de la variable que se verificó, si se conoce. Por defecto es '$_'.
"attribute_name"
Si esta excepción se lanzó como resultado de una comprobación `isa` o una coerción fallida para un atributo de Moo, esto le indicará qué atributo (si su Moo es lo suficientemente nuevo).

(Con suerte, algún día esto admitirá otros frameworks OO.)

"attribute_step"
Si esta excepción se lanzó como resultado de una comprobación `isa` o una coerción fallida para un atributo de Moo, esto contendrá "isa check" o "coercion" para indicar qué salió mal (si su Moo es lo suficientemente nuevo).

(Con suerte, algún día esto admitirá otros frameworks OO.)

Métodos

"has_type", "has_attribute_name", "has_attribute_step"
Métodos predicado.
"message"
Sobrescrito para añadir "varname" al mensaje si está definido.
"explain"
Intenta explicar por qué el valor no pasó la restricción de tipo. Devuelve un arrayref de cadenas que proporcionan un razonamiento paso a paso; o devuelve undef si no es posible ninguna explicación.
