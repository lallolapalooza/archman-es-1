ERR_put_error(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ERR_PUT_ERROR(3ssl) OpenSSL ERR_PUT_ERROR(3ssl)

NOMBRE

ERR_raise, ERR_raise_data, ERR_put_error, ERR_add_error_data, ERR_add_error_vdata, ERR_add_error_txt, ERR_add_error_mem_bio - registrar un error

SINOPSIS

#include <openssl/err.h>
void ERR_raise(int lib, int reason);
void ERR_raise_data(int lib, int reason, const char *fmt, ...);
void ERR_add_error_data(int num, ...);
void ERR_add_error_vdata(int num, va_list arg);
void ERR_add_error_txt(const char *sep, const char *txt);
void ERR_add_error_mem_bio(const char *sep, BIO *bio);

La siguiente función ha quedado obsoleta desde OpenSSL 3.0 y puede ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

void ERR_put_error(int lib, int func, int reason, const char *file, int line);

DESCRIPCIÓN

ERR_raise() añade un nuevo error a la cola de errores del hilo. El error ocurrió en la biblioteca lib por la razón indicada por el código reason . Además, el nombre del archivo, la línea y el nombre de la función donde ocurrió el error se guardan junto con el registro del error.

ERR_raise_data() hace lo mismo que ERR_raise(), pero también permite al llamador especificar información adicional como una cadena de formato fmt y un número arbitrario de valores, que se procesan con BIO_snprintf(3).

ERR_put_error() añade un código de error a la cola de errores del hilo. Señala que el error con código de razón reason ocurrió en la función func de la biblioteca lib, en el número de línea line del archivo. Esta función normalmente la llama una macro.

ERR_add_error_data() asocia la concatenación de sus num argumentos de cadena como datos adicionales con el código de error añadido por última vez. ERR_add_error_vdata() es similar, excepto que el argumento es un va_list. Múltiples llamadas a estas funciones se añaden a la parte superior actual de la cola de errores. La longitud total de los datos de cadena por error está limitada a 4096 caracteres.

ERR_add_error_txt() añade la cadena de texto dada como datos adicionales a la última entrada de la cola de errores, después de insertar la cadena de separador opcional si no es NULL y la entrada de error superior todavía no tiene datos adicionales. En caso de que el separador esté al final del texto, no se añade a los datos. El sep argumento puede ser, por ejemplo, "\n" para insertar un salto de línea cuando sea necesario. Si los datos asociados se volvieran más largos de 4096 caracteres (que es el límite indicado anteriormente), se divide entre suficientes copias nuevas de la última entrada de la cola de errores.

ERR_add_error_mem_bio() es lo mismo que ERR_add_error_txt() excepto que la cadena de texto se toma del BIO de memoria dado. Añade '\0' al contenido del BIO si no está terminado en NUL.

ERR_load_strings(3) puede usarse para registrar cadenas de error para que la aplicación pueda generar mensajes de error legibles para el código de error.

Informe de errores

Informes de la biblioteca OpenSSL

Cada subbiblioteca de OpenSSL tiene un código de biblioteca ERR_LIB_XXX y tiene su propio conjunto de códigos de razón XXX_R_.... Ambos se pasan en combinación a ERR_raise() y ERR_raise_data(), y la combinación produce finalmente el texto de error correcto para el error informado.

Todas estas macros y los números que tienen como valores son específicos de las bibliotecas de OpenSSL. Los códigos de razón de OpenSSL normalmente consisten en descripciones textuales de errores. Por ejemplo, la función ssl3_read_bytes() informa un "fallo de handshake" de la siguiente manera:

ERR_raise(ERR_LIB_SSL, SSL_R_SSL_HANDSHAKE_FAILURE);

Hay dos excepciones:

ERR_LIB_SYS
Este "código de biblioteca" indica que se está informando un error del sistema. En este caso, el código de razón dado a ERR_raise() y ERR_raise_data() debe ser errno(3). 
ERR_raise(ERR_LIB_SYS, errno);
ERR_R_XXX
Este conjunto de códigos de error se considera global y puede usarse en combinación con cualquier código de subbiblioteca. 
ERR_raise(ERR_LIB_RSA, ERR_R_PASSED_INVALID_ARGUMENT);

Otro software

Otro software que pueda querer usar el sistema de informe de errores de OpenSSL, como motores o aplicaciones, normalmente debe obtener sus propios números.

  • Para obtener un código de "biblioteca", llame a ERR_get_next_error_library(3); esto da al código que llama un número dinámico, utilizable durante la duración del proceso.
  • Los códigos de razón para cada una de estas "bibliotecas" son determinados o generados por los autores de ese código. Deben ser números en el rango de 1 a 524287 (en otras palabras, deben ser enteros sin signo de 18 bits distintos de cero).

Las excepciones mencionadas en "Informes de la biblioteca OpenSSL" anteriores son válidas para otro software, es decir, pueden usar ERR_LIB_SYS para informar errores del sistema:

ERR_raise(ERR_LIB_SYS, errno);

... y pueden usar las macros ERR_R_XXX junto con su propio código de "biblioteca".

int app_lib_code = ERR_get_next_error_library();
/* ... */
ERR_raise(app_lib_code, ERR_R_PASSED_INVALID_ARGUMENT);

VALORES DE RETORNO

ERR_raise(), ERR_raise_data(), ERR_put_error(), ERR_add_error_data(), ERR_add_error_vdata() ERR_add_error_txt(), y ERR_add_error_mem_bio() no devuelven valores.

NOTAS

ERR_raise(), ERR_raise() y ERR_put_error() están implementadas como macros.

VÉASE TAMBIÉN

ERR_load_strings(3), ERR_get_next_error_library(3)

HISTORIA

ERR_raise, ERR_raise_data, ERR_add_error_txt() y ERR_add_error_mem_bio() se añadieron en OpenSSL 3.0.
