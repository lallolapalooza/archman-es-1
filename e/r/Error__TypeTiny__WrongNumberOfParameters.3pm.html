Error::TypeTiny::WrongNumberOfParameters(3) Documentación de Perl aportada por el usuario Error::TypeTiny::WrongNumberOfParameters(3)

NOMBRE

Error::TypeTiny::WrongNumberOfParameters - excepción para Type::Params

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Se lanza cuando una comprobación compilada de Type::Params se llama con el número incorrecto de parámetros.

También se lanza por varias restricciones de tipo parametrizables en circunstancias similares. Por ejemplo, "HashRef[Int]" tiene sentido, pero "HashRef[Int, {}]" no.

Este paquete hereda de Error::TypeTiny; consulta esa documentación para la mayoría de la información. Las principales diferencias se enumeran a continuación:

Atributos

"minimum"
El número mínimo esperado de parámetros.
"maximum"
El número máximo esperado de parámetros.
"got"
El número de parámetros realmente pasados a la comprobación compilada.
"target"
Una cadena corta que describe para qué había un número incorrecto de parámetros.

Métodos

"has_minimum", "has_maximum", "has_target"
Métodos predicado.

ERRORES
