PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

errno.h — números de error del sistema

SINOPSIS

#include <errno.h>

DESCRIPCIÓN

Parte de la funcionalidad descrita en esta página de referencia extiende el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C no es intencional. Este volumen de POSIX.1‐2017 se subordina al estándar ISO C.

El estándar ISO C solo requiere que los símbolos [EDOM], [EILSEQ]y [ERANGE] estén definidos.

La <errno.h> cabecera debe proporcionar una declaración o definición para errno. El símbolo errno debe expandirse a un valor lvalue modificable de tipo int. No se especifica si errno es una macro o un identificador declarado con enlace externo. Si se suprime una definición de macro para acceder a un objeto real, o si un programa define un identificador con el nombre errno, el comportamiento es indefinido.

La <errno.h> cabecera debe definir las siguientes macros que deben expandirse a expresiones constantes enteras de tipo int, valores positivos distintos (excepto como se indica a continuación), y que deben ser adecuadas para su uso en #if directivas de preprocesamiento:
