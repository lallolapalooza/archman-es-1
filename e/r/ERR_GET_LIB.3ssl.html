ERR_GET_LIB(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ERR_GET_LIB(3ssl) OpenSSL ERR_GET_LIB(3ssl)

NOMBRE

ERR_GET_LIB, ERR_GET_REASON, ERR_FATAL_ERROR - obtener información de los códigos de error

SINOPSIS

#include <openssl/err.h>
int ERR_GET_LIB(unsigned long e);
int ERR_GET_REASON(unsigned long e);
int ERR_FATAL_ERROR(unsigned long e);

DESCRIPCIÓN

El código de error devuelto por ERR_get_error() consiste en un número de biblioteca y un código de razón. ERR_GET_LIB() y ERR_GET_REASON() se pueden usar para extraerlos.

ERR_FATAL_ERROR() indica si un código de error dado es un error fatal.

El número de biblioteca describe dónde ocurrió el error, el código de razón es la información sobre qué salió mal.

Cada sub-biblioteca de OpenSSL tiene un número de biblioteca único; el código de razón es único dentro de cada sub-biblioteca. Tenga en cuenta que diferentes bibliotecas pueden usar el mismo valor para señalar diferentes razones.

Los códigos de razón ERR_R_..., como ERR_R_MALLOC_FAILURE, son globalmente únicos. Sin embargo, al buscar códigos de razón específicos de la sub-biblioteca, asegúrese de comparar también el número de biblioteca.

ERR_GET_LIB(), ERR_GET_REASON() y ERR_FATAL_ERROR() son macros.

VALORES DE RETORNO

El número de biblioteca, el código de razón y si el error es fatal, respectivamente. A partir de OpenSSL 3.0.0, el código de función siempre se establece en cero.

NOTAS

Las aplicaciones no deben tomar decisiones de flujo de control basadas en códigos de error específicos. Los códigos de error están sujetos a cambios en cualquier momento (incluso en versiones de parche de OpenSSL). Un código de error particular solo puede considerarse significativo para las decisiones de flujo de control si está documentado explícitamente como tal. Pueden aparecer nuevos códigos de fallo en cualquier momento.

VER TAMBIÉN

ERR_get_error(3)

HISTORIA

ERR_GET_LIB() y ERR_GET_REASON() están disponibles en todas las versiones de OpenSSL.

ERR_GET_FUNC() fue eliminado en OpenSSL 3.0.
