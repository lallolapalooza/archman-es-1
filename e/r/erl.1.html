Los identificadores pasados como identificadores reales pueden ser utilizados por el sistema de tiempo de ejecución al intentar acceder a hardware específico; si son incorrectos, el comportamiento es indefinido. No se aceptan identificadores de CPU lógicos falsos, ya que no hay punto en definir la topología de la CPU sin identificadores de CPU lógicos reales. Los identificadores de hilo, núcleo, procesador y nodo pueden omitirse. Si se omiten, el ID del hilo por defecto es t0, el ID del núcleo por defecto es c0, el ID del procesador por defecto es p0, y el ID del nodo queda sin definir. NUMA.

decrecientes.

núcleo.

•<LogicalIds><ThreadIds><CoreIds><ProcessorIds><NodeIds>, es decir, el hilo es parte de un núcleo que es parte de un procesador, que es parte de un nodo
NUMA.
•<LogicalIds><ThreadIds><CoreIds><NodeIds><ProcessorIds>, es decir, el hilo es parte de un núcleo que es parte de un nodo NUMA, que es parte de un
procesador.

procesador.
