ERR_get_error(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ERR_GET_ERROR(3ssl) OpenSSL ERR_GET_ERROR(3ssl)

NOMBRE

ERR_get_error, ERR_peek_error, ERR_peek_last_error, ERR_get_error_line, ERR_peek_error_line, ERR_peek_last_error_line, ERR_peek_error_func, ERR_peek_last_error_func, ERR_peek_error_data, ERR_peek_last_error_data, ERR_get_error_all, ERR_peek_error_all, ERR_peek_last_error_all, ERR_get_error_line_data, ERR_peek_error_line_data, ERR_peek_last_error_line_data - obtener código de error y datos

SINOPSIS

#include <openssl/err.h>
unsigned long ERR_get_error(void);
unsigned long ERR_peek_error(void);
unsigned long ERR_peek_last_error(void);
unsigned long ERR_peek_error_line(const char **file, int *line);
unsigned long ERR_peek_last_error_line(const char **file, int *line);
unsigned long ERR_peek_error_func(const char **func);
unsigned long ERR_peek_last_error_func(const char **func);
unsigned long ERR_peek_error_data(const char **data, int *flags);
unsigned long ERR_peek_last_error_data(const char **data, int *flags);
unsigned long ERR_get_error_all(const char **file, int *line,
                                const char **func,
                                const char **data, int *flags);
unsigned long ERR_peek_error_all(const char **file, int *line,
                                 const char **func,
                                 const char **data, int *flags);
unsigned long ERR_peek_last_error_all(const char **file, int *line,
                                      const char *func,
                                      const char **data, int *flags);

Las siguientes funciones han quedado obsoletas desde OpenSSL 3.0, y pueden ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

unsigned long ERR_get_error_line(const char **file, int *line);
unsigned long ERR_get_error_line_data(const char **file, int *line,
                                      const char **data, int *flags);
unsigned long ERR_peek_error_line_data(const char **file, int *line,
                                       const char **data, int *flags);
unsigned long ERR_peek_last_error_line_data(const char **file, int *line,
                                            const char **data, int *flags);

DESCRIPCIÓN

ERR_get_error() devuelve el código de error más antiguo de la cola de errores del hilo y elimina la entrada. Esta función puede llamarse repetidamente hasta que no queden más códigos de error por devolver.

ERR_peek_error() devuelve el código de error más antiguo de la cola de errores del hilo sin modificarla.

ERR_peek_last_error() devuelve el código de error más reciente de la cola de errores del hilo sin modificarla.

Ver ERR_GET_LIB(3) para obtener información más específica como el motivo del error, y ERR_error_string(3) para mensajes de error legibles para humanos.

ERR_get_error_all() es lo mismo que ERR_get_error(), pero en caso de éxito además almacena el nombre de archivo, el número de línea y la función donde ocurrió el error en *file, *line y *func, y también texto adicional y banderas en *data, *flags. Si alguno de esos parámetros es NULL, no se modificará. Un nombre de archivo no establecido se indica como "", es decir, una cadena vacía. Un número de línea no establecido se indica como 0. Un nombre de función no establecido se indica como "", es decir, una cadena vacía.

Un puntero devuelto de esta manera por estas funciones y las siguientes es válido hasta que la entrada correspondiente se sobrescriba en la cola de errores.

ERR_peek_error_line() y ERR_peek_last_error_line() son lo mismo que ERR_peek_error() y ERR_peek_last_error(), pero en caso de éxito además almacenan el nombre de archivo y el número de línea donde ocurrió el error en *file y *line, siempre que no sean NULL. Un nombre de archivo no establecido se indica como "", es decir, una cadena vacía. Un número de línea no establecido se indica como 0.

ERR_peek_error_func() y ERR_peek_last_error_func() son lo mismo que ERR_peek_error() y ERR_peek_last_error(), pero en caso de éxito además almacenan el nombre de la función donde ocurrió el error en *func, a menos que sea NULL. Un nombre de función no establecido se indica como "".

ERR_peek_error_data() y ERR_peek_last_error_data() son lo mismo que ERR_peek_error() y ERR_peek_last_error(), pero en caso de éxito además almacenan datos adicionales y banderas asociados con el código de error en *data y *flags, siempre que no sean NULL. Los datos no establecidos se indican como "". En este caso el valor dado para la bandera es irrelevante (e igual a 0). *data contiene una cadena si *flags&ERR_TXT_STRING es verdadero.

ERR_peek_error_all() y ERR_peek_last_error_all() son combinaciones de todo lo anterior.

ERR_get_error_line(), ERR_get_error_line_data(), ERR_peek_error_line_data() y ERR_peek_last_error_line_data() son variantes antiguas de ERR_get_error_all(), ERR_peek_error_all() y ERR_peek_last_error_all(), y pueden dar resultados confusos. Ya no deberían usarse y por lo tanto están obsoletas.

Una aplicación NO DEBE liberar el puntero *data (o cualquier otro puntero devuelto por estas funciones) con OPENSSL_free() ya que la liberación se gestiona automáticamente por la biblioteca de errores.

VALORES DE RETORNO

El código de error, o 0 si no hay error en la cola.

VER TAMBIÉN

ERR_error_string(3), ERR_GET_LIB(3)

HISTORIAL

ERR_peek_error_func(), ERR_peek_last_error_func(), ERR_peek_error_data(), ERR_peek_last_error_data(), ERR_peek_error_all() y ERR_peek_last_error_all() se añadieron en OpenSSL 3.0.

ERR_get_error_line(), ERR_get_error_line_data(), ERR_peek_error_line_data() y ERR_peek_last_error_line_data() quedaron obsoletas en OpenSSL 3.0.
