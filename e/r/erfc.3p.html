ERFC(3P) Manual del Programador POSIX ERFC(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

erfc, erfcf, erfcl — funciones de error complementarias

SINOPSIS

#include <math.h>
double erfc(double x);
float erfcf(float x);
long double erfcl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones calcularán la función de error complementaria 1.0 - erf(x).

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el valor de la función de error complementaria.

Si el valor correcto causara un desbordamiento inferior (underflow) y no es representable, puede ocurrir un error de rango, y erfc(), erfcf(), y erfcl() devolverán 0.0, o (si la opción de punto flotante IEC 60559 no es compatible) un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN y LDBL_MIN, respectivamente.

Si x es NaN, se devolverá un NaN.

Si x es ±0, se devolverá +1.

Si x es -Inf, se devolverá +2.

Si x es +Inf, se devolverá +0.

Si el valor correcto causara un desbordamiento inferior y es representable, puede ocurrir un error de rango y se devolverá el valor correcto.

ERRORES

Estas funciones pueden fallar si:

Error de rango
El resultado sufre un desbordamiento inferior.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante de desbordamiento inferior.

Ninguno.

USO EN APLICACIONES

La función erfc() se proporciona debido a la extrema pérdida de precisión relativa si se llama a erf(x) para valores grandes de x y el resultado se resta de 1.0.

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.
