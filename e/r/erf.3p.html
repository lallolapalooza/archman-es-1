ERF(3P) Manual del Programador POSIX ERF(3P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

erf, erff, erfl — funciones de error

SINOPSIS

#include <math.h>
double erf(double x);
float erff(float x);
long double erfl(long double x);

DESCRIPCION

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones calcularán la función de error de su argumento x, definida como:

2π∫0xe^ −t^2 dt

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DE RETORNO

Tras la finalización exitosa, estas funciones devolverán el valor de la función de error.

Si x es NaN, se devolverá un NaN.

Si x es ±0, se devolverá ±0.

Si x es ±Inf, se devolverá ±1.

Si el valor correcto causara un subdesbordamiento, puede ocurrir un error de rango, y erf(), erff(), y erfl() devolverán un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN y LDBL_MIN, respectivamente.

Si la opción de punto flotante IEC 60559 es compatible, se devolverá 2 * x/sqrt(π).

ERRORES

Estas funciones pueden fallar si:

Error de Rango
El resultado sufre un subdesbordamiento.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se generará la excepción de punto flotante de subdesbordamiento.

Las siguientes secciones son informativas.

EJEMPLOS

Calcular la Probabilidad para una Variable Normal

Este ejemplo muestra cómo usar erf() para calcular la probabilidad de que una variable normal asuma un valor en el rango [x1,x2] con x1≤x2.

Este ejemplo utiliza la constante M_SQRT1_2 que forma parte de la opción XSI.

#include <math.h>
double
Phi(const double x1, const double x2)
{
    return ( erf(x2*M_SQRT1_2) - erf(x1*M_SQRT1_2) ) / 2;
}

USO DE APLICACIONES

El subdesbordamiento ocurre cuando |x| < DBL_MIN * (sqrt(π)/2).

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.
