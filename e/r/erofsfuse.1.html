EROFSFUSE(1) Manual de Comandos Generales EROFSFUSE(1)

NOMBRE

erofsfuse - Cliente del sistema de archivos FUSE para el sistema de archivos erofs

SINOPSIS

erofsfuse [OPCIONES] DISPOSITIVO PUNTOMONTAJE

DESCRIPCIÓN

erofsfuse es un cliente del sistema de archivos FUSE que soporta la lectura de dispositivos o archivos de imagen que contienen el sistema de archivos erofs.

OPCIONES

opciones generales:

-o opción,[opción...]
opciones de montaje
-h --help
mostrar ayuda y salir

opciones de erofsfuse:

--dbglevel=#
Especificar el nivel de mensajes de depuración. El valor predeterminado es 2, que muestra mensajes de advertencia básicos.
--device=ruta
Especificar un dispositivo adicional que se utilizará conjuntamente. Puede proporcionar múltiples opciones `--device' en el orden correcto.
--offset=#
Especificar `--offset' bytes para omitir al leer el archivo de imagen. El valor predeterminado es 0.

opciones de FUSE:

-d -o debug
habilitar salida de depuración (implica -f)
-f
operación en primer plano
-s
deshabilitar operación multihilo

Para otras opciones de FUSE, consulte mount.fuse(8) o vea la salida de erofsfuse --help

DISPONIBILIDAD

erofsfuse forma parte del paquete erofs-utils y está disponible en git://git.kernel.org/pub/scm/linux/kernel/git/xiang/erofs-utils.git.

VER TAMBIÉN
