Error::TypeTiny(3) Documentación de Perl contribuida por el usuario Error::TypeTiny(3)

NOMBRE

Error::TypeTiny - excepciones para Type::Tiny y sus derivados

SINOPSIS

use feature 'try';
use Data::Dumper;
use Types::Standard qw( Str );

try {
   Str->assert_valid( undef );
}
catch ( $exception ) {
   warn "Encontré un Error: $exception";
   warn Dumper( $exception->explain )
      if $exception->isa( "Error::TypeTiny::Assertion" );
}

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Cuando Type::Tiny y sus módulos relacionados encuentran un error, generan un objeto de excepción. Estos objetos de excepción heredan de Error::TypeTiny.

Constructores

new(%atributos)
Función constructora estilo Moose.
throw(%atributos)
Construye una excepción y la pasa a "die".

Rellena automáticamente "context" y "stack_trace" si es apropiado.

"throw_cb($callback, %atributos)"
Construye una excepción y la pasa a $callback que debe ser un coderef; si es undef, usa "die".

Rellena automáticamente "context" y "stack_trace" si es apropiado.

Atributos

"message"
El mensaje de error.
"context"
Hashref que contiene el paquete, archivo y línea que generó el error.
"stack_trace"
Un rastreo de pila más completo. Esta característica requiere Devel::StackTrace; usa la variable de paquete $StackTrace para activarla.

Métodos

"to_string"
Devuelve el mensaje, seguido del contexto si está establecido.

Funciones

"Error::TypeTiny::croak($format, @args)"
Atajo de estilo funcional para el método "throw". Toma una cadena de formato estilo "sprintf" y argumentos opcionales para construir el "message".

Sobrecarga

•
La stringificación está sobrecargada para llamar a "to_string".

Variables de paquete

%Carp::CarpInternal
Error::TypeTiny respeta esta variable de paquete de Carp. ( %Error::TypeTiny::CarpInternal es un alias para ella.)
$Error::TypeTiny::StackTrace
Booleano para alternar la generación del rastreo de pila.
$Error::TypeTiny::LastError
Una referencia al último objeto de excepción lanzado.

ADVERTENCIAS

Aunque se lanzan objetos Error::TypeTiny para errores producidos por Type::Tiny, eso no significa que cada vez que uses Type::Tiny obtendrás Error::TypeTinys cuando quieras.

Por ejemplo, si usas una restricción de tipo Type::Tiny en un atributo de Moose, Moose no llamará al método "assert_valid" de la restricción (que lanza una excepción). En su lugar, llamará a "check" y "get_message" (que no lo hacen), y hará "confess" un mensaje de error propio. (La variable de paquete $LastError puede salvarte.)

ERRORES

Por favor, informa de cualquier error en https://github.com/tobyink/p5-type-tiny/issues.

VER TAMBIÉN
