ERR_print_errors(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ERR_PRINT_ERRORS(3ssl) OpenSSL ERR_PRINT_ERRORS(3ssl)

NOMBRE

ERR_print_errors, ERR_print_errors_fp, ERR_print_errors_cb - imprimir mensajes de error

SINOPSIS

#include <openssl/err.h>
void ERR_print_errors(BIO *bp);
void ERR_print_errors_fp(FILE *fp);
void ERR_print_errors_cb(int (*cb)(const char *str, size_t len, void *u),
                         void *u);

DESCRIPCIÓN

ERR_print_errors() es una función de conveniencia que imprime las cadenas de error para todos los errores que OpenSSL ha registrado en bp, vacíando así la cola de errores.

ERR_print_errors_fp() es lo mismo, excepto que la salida va a un FILE.

ERR_print_errors_cb() es lo mismo, excepto que la función de callback, cb, se llama para cada línea de error con la cadena, longitud y datos de usuario u como parámetros de callback.

Las cadenas de error tendrán el siguiente formato:

[pid]:error:[código de error]:[nombre de la biblioteca]:[nombre de la función]:[cadena de razón]:[nombre de archivo]:[línea]:[mensaje de texto opcional]

código de error es un número hexadecimal de 8 dígitos. nombre de la biblioteca, nombre de la función y cadena de razón son texto ASCII, al igual que el mensaje de texto opcional si se estableció para el código de error respectivo.

Si no hay una cadena de texto registrada para el código de error dado, la cadena de error contendrá el código numérico.

VALORES DE RETORNO

ERR_print_errors() y ERR_print_errors_fp() no devuelven valores.

VER TAMBIÉN

ERR_error_string(3), ERR_get_error(3)
