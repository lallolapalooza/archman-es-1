NOMBRE

warning::process-tracking - las instalaciones de seguimiento de procesos no están disponibles

DESCRIPCIÓN

Estos errores y advertencias ocurren cuando el kernel systemtap en el que se está ejecutando carece de soporte para las instalaciones de seguimiento de procesos del espacio de usuario.

ERROR DE COMPILACIÓN

El error

ERROR: user-space process-tracking facilities not available

ocurre cuando el script contiene un punto de sonda uprobes que el kernel actual no soporta.

ADVERTENCIAS EN TIEMPO DE EJECUCIÓN

La advertencia,

WARNING: process-tracking facilities are not available in this kernel

y el mensaje relacionado,

WARNING: cannot track target in process '...'

ocurren en tiempo de ejecución cuando se ejecuta en un kernel (generalmente una versión anterior) que no tiene funcionalidad utrace ni un sustituto aceptable.

El script aún debería cargarse y ejecutarse. Sin embargo, las sondas que dependen de la disponibilidad de las instalaciones de seguimiento de procesos fallarán silenciosamente al activarse.

RESOLVIENDO EL PROBLEMA

Si la funcionalidad de seguimiento de procesos es absolutamente necesaria, se necesita una versión del kernel posterior a la 3.5, o una versión anterior debe compilarse con los parches utrace apropiados.

VER TAMBIÉN

stap(1),
error::reporting(7stap)
