NOMBRE

Error::Simple - la subclase de error simple de Error

VERSIÓN

versión 0.17030

SINOPSIS

use base 'Error::Simple';

DESCRIPCIÓN

El único propósito de este módulo es permitir a uno decir:

use base 'Error::Simple';

y lo único que hace es "usar" Error.pm. Consulte la documentación de Error para obtener más información sobre Error::Simple.

MÉTODOS

Error::Simple->new($texto [, $valor])

Construye un Error::Simple con el texto $texto y el valor opcional $valor.

$err->stringify()

Error::Simple sobrecarga este método.
