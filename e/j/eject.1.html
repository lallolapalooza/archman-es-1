EJECT(1) Comandos de usuario EJECT(1)

NOMBRE

eject - expulsa medios extraíbles

eject [opciones] dispositivo|punto de montaje

DESCRIPCIÓN

eject permite expulsar medios extraíbles (típicamente un CD-ROM, disquete, cinta, JAZ, ZIP o disco USB) bajo control de software. El comando también puede controlar algunos cambiadores de CD-ROM de múltiples discos, la función de auto-expulsión soportada por algunos dispositivos, y cerrar la bandeja de discos de algunas unidades de CD-ROM.

El dispositivo correspondiente a dispositivo o punto de montaje es expulsado. Si no se especifica ningún nombre, se usa el nombre por defecto /dev/cdrom . El dispositivo puede ser referenciado por nombre de dispositivo (por ejemplo, 'sda'), ruta de dispositivo (por ejemplo, '/dev/sda'), UUID=uuid o etiquetas LABEL=etiqueta .

Hay cuatro métodos diferentes de expulsión, dependiendo de si el dispositivo es un CD-ROM, un dispositivo SCSI, un disquete extraíble o una cinta. Por defecto eject prueba los cuatro métodos en orden hasta que tiene éxito.

Si se especifica una partición del dispositivo, se usa el dispositivo de disco completo.

Si el dispositivo o una partición del dispositivo está actualmente montado, se desmonta antes de expulsar. La expulsión se procesa en el descriptor de archivo de dispositivo de bloque abierto de forma exclusiva si --no-unmount o --force no están especificados.

OPCIONES

-a, --auto on|off

Esta opción controla el modo de auto-expulsión, soportado por algunos dispositivos. Cuando está habilitado, la unidad expulsa automáticamente el dispositivo cuando se cierra.

-c, --changerslot ranura

Con esta opción se puede seleccionar una ranura de CD de un cambiador de CD-ROM ATAPI/IDE. La unidad de CD-ROM no puede estar en uso (CD de datos montado o reproduciendo un CD de música) para que una solicitud de cambio funcione. Tenga en cuenta también que la primera ranura del cambiador se denomina 0, no 1.

-d, --default

Lista el nombre de dispositivo por defecto.

-F, --force

Fuerza la expulsión, no verifica el tipo de dispositivo, no abre el dispositivo con bloqueo exclusivo. El resultado exitoso puede ser un falso positivo en dispositivos no extraíbles en caliente.

-f, --floppy

Esta opción especifica que la unidad debe ser expulsada usando un comando de expulsión de disquete extraíble.

-i, --manualeject on|off

Esta opción controla el bloqueo del botón de expulsión manual. Cuando está habilitado, la unidad no será expulsada cuando se presione el botón. Esto es útil cuando transporta un portátil en una bolsa o maletín y no quiere que se expulse si el botón se presiona accidentalmente.

-M, --no-partitions-unmount

La opción le indica a eject que no intente desmontar otras particiones en dispositivos particionados. Si otra partición sigue montada, el programa no intentará expulsar el medio. Solo intentará desmontar el dispositivo o punto de montaje dado en la línea de comandos.

-m, --no-unmount

La opción le indica a eject que no intente desmontar en absoluto. Si esta opción no se especifica, entonces eject abre el dispositivo con el indicador O_EXCL para asegurarse de que el dispositivo no está en uso (desde v2.35).

-n, --noop

Con esta opción se muestra el dispositivo seleccionado pero no se realiza ninguna acción.

-p, --proc

Esta opción permite usar /proc/mounts en lugar de /etc/mtab. También pasa la opción -n a umount(8).

-q, --tape

Esta opción especifica que la unidad debe ser expulsada usando un comando de desconexión de unidad de cinta.

-r, --cdrom

Esta opción especifica que la unidad debe ser expulsada usando un comando de expulsión de CDROM.

-s, --scsi

Esta opción especifica que la unidad debe ser expulsada usando comandos SCSI.

-T, --traytoggle

Con esta opción se envía a la unidad un comando de cierre de bandeja de CD-ROM si está abierta, y un comando de expulsión de bandeja de CD-ROM si está cerrada. No todos los dispositivos soportan este comando, porque usa el comando de cierre de bandeja de CD-ROM mencionado anteriormente.

-t, --trayclose

Con esta opción se envía a la unidad un comando de cierre de bandeja de CD-ROM. No todos los dispositivos soportan este comando.

-v, --verbose

Ejecuta en modo verboso; se muestra más información sobre lo que está haciendo el comando.

-X, --listspeed

Con esta opción se sondeará la unidad de CD-ROM para detectar las velocidades disponibles. La salida es una lista de velocidades que pueden usarse como argumento de la opción -x . Esto solo funciona con Linux 2.6.13 o superior, en versiones anteriores solo se informará la velocidad máxima. Tenga en cuenta también que algunas unidades pueden no informar correctamente la velocidad y por lo tanto esta opción no funciona con ellas.

-x, --cdspeed velocidad

Con esta opción se envía a la unidad un comando de selección de velocidad de CD-ROM. El argumento velocidad es un número que indica la velocidad deseada (por ejemplo, 8 para velocidad 8X), o 0 para la tasa de datos máxima. No todos los dispositivos soportan este comando y solo puede especificar velocidades de las que la unidad es capaz. Cada vez que se cambia el medio, esta opción se restablece. Esta opción puede usarse sola, o con las opciones -t y -c .

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ESTADO DE SALIDA

Devuelve 0 si la operación fue exitosa, 1 si la operación falló o la sintaxis del comando no era válida.

NOTAS

eject solo funciona con dispositivos que soporten uno o más de los cuatro métodos de expulsión. Esto incluye la mayoría de las unidades de CD-ROM (IDE, SCSI y propietarias), algunas unidades de cinta SCSI, unidades JAZ, unidades ZIP (versiones de puerto paralelo, SCSI e IDE) y disquetes extraíbles LS120. Los usuarios también han informado éxito con unidades de disquete en sistemas Sun SPARC y Apple Macintosh. Si eject no funciona, es más probable que sea una limitación del controlador del kernel para el dispositivo y no el programa eject en sí mismo.

Las opciones -r, -s, -fy -q permiten controlar qué métodos se usan para expulsar. Se puede especificar más de un método. Si no se especifica ninguna de estas opciones, se prueban las cuatro (esto funciona bien en la mayoría de los casos).

eject puede no siempre ser capaz de determinar si el dispositivo está montado (por ejemplo, si tiene varios nombres). Si el nombre del dispositivo es un enlace simbólico, eject seguirá el enlace y usará el dispositivo al que apunta.

Si eject determina que el dispositivo puede tener múltiples particiones, intentará desmontar todas las particiones montadas del dispositivo antes de expulsar (véase también --no-partitions-unmount). Si un desmontaje falla, el programa no intentará expulsar el medio.

Puede expulsar un CD de audio. Algunas unidades de CD-ROM se negarán a abrir la bandeja si la unidad está vacía. Algunos dispositivos no soportan el comando de cierre de bandeja.

Si la función de auto-expulsión está habilitada, entonces la unidad siempre será expulsada después de ejecutar este comando. No todos los controladores de CD-ROM del kernel de Linux soportan el modo de auto-expulsión. No hay forma de averiguar el estado del modo de auto-expulsión.

Necesita los privilegios apropiados para acceder a los archivos de dispositivo. Se requiere ejecutar como root para expulsar algunos dispositivos (por ejemplo, dispositivos SCSI).
