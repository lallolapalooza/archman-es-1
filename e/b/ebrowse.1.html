EBROWSE(1) GNU EBROWSE(1)

NOMBRE

ebrowse - crear una base de datos de jerarquía de clases

SINOPSIS

ebrowse [opciones] [ARCHIVOS...]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando ebrowse. La documentación completa está disponible en formato GNU Info.

ebrowse se utiliza para crear la base de datos utilizada por el explorador de clases en Emacs.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones ("-").

-a, --append
añadir salida al archivo existente
-f, --files=ARCHIVOS
leer nombres de archivos de entrada de ARCHIVO
-I, --search-path=LISTA
establecer la ruta de búsqueda de archivos de entrada
-m, --min-regexp-length=N
establecer la longitud mínima de la expresión regular a N
-M, --max-regexp-length=N
establecer la longitud máxima de la expresión regular a N
-n, --no-nested-classes
excluir clases anidadas
-o, --output-file=ARCHIVO
establecer el nombre del archivo de salida a ARCHIVO
-p, --position-info
imprimir información sobre la posición en el archivo
-s, --no-structs-or-unions
no registrar estructuras ni uniones
-v, --verbose
ser verboso
-V, --very-verbose
ser muy verboso
-x, --no-regexps
no registrar expresiones regulares
--help
mostrar esta ayuda
--version
mostrar información de la versión

VER TAMBIÉN

emacs(1), etags(1), y la documentación completa de ebrowse que se mantiene como un manual Texinfo. Si los programas info y ebrowse están debidamente instalados en su sitio, el comando

info ebrowse

debería darle acceso al manual completo.
