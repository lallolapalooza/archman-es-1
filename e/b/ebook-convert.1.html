NOMBRE

ebook-convert - ebook-convert

ebook-convert archivo_entrada archivo_salida [opciones]

Convierte un libro electrónico de un formato a otro.

archivo_entrada es la entrada y archivo_salida es la salida. Ambos deben especificarse como los dos primeros argumentos del comando.

El formato del libro electrónico de salida se deduce de la extensión del archivo archivo_salida. archivo_salida también puede tener el formato especial .EXT donde EXT es la extensión del archivo de salida. En este caso, el nombre del archivo de salida se deriva del nombre del archivo de entrada. Tenga en cuenta que los nombres de archivo no deben empezar con un guion. Finalmente, si archivo_salida no tiene extensión, se trata como una carpeta y se escribe un "libro electrónico abierto" (OEB) que consta de archivos HTML en esa carpeta. Estos archivos son los que normalmente se habrían pasado al complemento de salida.

Después de especificar el archivo de entrada y salida, puede personalizar la conversión especificando varias opciones. Las opciones disponibles dependen de los tipos de archivo de entrada y salida. Para obtener ayuda sobre ellas, especifique el archivo de entrada y salida y luego use la opción -h.

Para obtener documentación completa sobre el sistema de conversión, consulte Conversión de libros electrónicos

Siempre que pase argumentos a ebook-convert que contengan espacios, encierre los argumentos entre comillas. Por ejemplo: "/alguna ruta/con espacios"

Las opciones y sus valores predeterminados cambian según los formatos de entrada y salida, por lo que siempre debe comprobar con:

ebook-convert mi_archivo.formato_entrada mi_archivo.formato_salida -h

DESCRIPCIÓN

La utilidad ebook-convert es un programa versátil para convertir libros electrónicos de un formato a otro. Admite una amplia gama de formatos de entrada y salida, lo que lo convierte en una herramienta indispensable para los usuarios de libros electrónicos.

La sintaxis básica del comando es:

ebook-convert archivo_entrada archivo_salida [opciones]

El programa determina el formato de salida del libro electrónico basándose en la extensión del archivo proporcionado para `archivo_salida`. Si `archivo_salida` termina con `.EXT`, donde `EXT` es una extensión de formato conocida, el nombre del archivo de salida se deriva automáticamente del nombre del archivo de entrada. Por ejemplo, si la entrada es `mi_libro.epub` y la salida se especifica como `.mobi`, el archivo de salida se llamará `mi_libro.mobi`.

Si `archivo_salida` no tiene una extensión, se tratará como un directorio, y el contenido del libro electrónico se guardará como una colección de archivos HTML dentro de ese directorio, representando el formato "open e-book" (OEB).

Además de la conversión básica, ebook-convert permite una personalización exhaustiva a través de una multitud de opciones. Estas opciones se pueden agrupar en varias categorías, incluidas las relacionadas con el aspecto y el diseño, el procesamiento heurístico, la búsqueda y el reemplazo, la detección de la estructura, la tabla de contenidos, los metadatos y la depuración. También hay opciones específicas para cada formato de entrada y salida.

Para obtener una lista detallada de las opciones disponibles para un par específico de formatos de entrada y salida, y sus valores predeterminados, ejecute el comando con la opción `-h` después de especificar los archivos de entrada y salida:

ebook-convert mi_libro.epub mi_libro.mobi -h

Esto mostrará la ayuda específica para la conversión de EPUB a MOBI, incluidas todas las opciones relevantes y sus valores predeterminados.

Para garantizar la correcta interpretación de las rutas de archivo o los nombres de archivo que contienen espacios, siempre deben incluirse entre comillas dobles.

EJEMPLOS

1. Convertir un archivo EPUB a MOBI:

ebook-convert entrada.epub salida.mobi

2. Convertir un archivo PDF a EPUB, optimizado para un Kindle:

ebook-convert entrada.pdf salida.epub --output-profile kindle

3. Convertir un archivo HTML a EPUB, especificando el título y el autor:

ebook-convert entrada.html salida.epub --title "Mi Gran Libro" --authors "Yo Mismo"

4. Convertir un archivo MOBI a TXT, extrayendo solo el texto:

ebook-convert entrada.mobi salida.txt --no-images --no-chapters

5. Convertir una carpeta de archivos HTML a un archivo EPUB, utilizando una receta personalizada:

ebook-convert "Mi Receta Personalizada.recipe" salida.epub
