NOMBRE

e2freefrag - informar sobre la fragmentación del espacio libre

SINOPSIS

e2freefrag [ -c chunk_kb ] [ -h ] sistema_archivos

DESCRIPCIÓN

e2freefrag se utiliza para informar sobre la fragmentación del espacio libre en los sistemas de archivos ext2/3/4. sistema_archivos es el nombre del dispositivo del sistema de archivos (por ejemplo, /dev/hdc1, /dev/md0). El programa e2freefrag escaneará la información del mapa de bits de bloques para verificar cuántos bloques libres están presentes como espacio libre contiguo y alineado. Se informa el porcentaje de bloques libres contiguos de tamaño y alineación chunk_kb. También muestra el tamaño mínimo/máximo/promedio de los fragmentos libres en el sistema de archivos, junto con un histograma de todos los fragmentos libres. Esta información se puede utilizar para evaluar el nivel de fragmentación del espacio libre en el sistema de archivos.

OPCIONES

-c chunk_kb
Si se especifica un tamaño de fragmento, entonces e2freefrag imprimirá cuántos fragmentos libres de tamaño chunk_kb están disponibles en unidades de kilobytes (Kb). El tamaño del fragmento debe ser una potencia de dos y ser mayor que el tamaño de bloque del sistema de archivos.
-h
Imprime el uso del programa.

EJEMPLO

# e2freefrag /dev/vgroot/lvhome
Dispositivo: /dev/vgroot/lvhome
Tamaño de bloque: 4096 bytes
Bloques totales: 1504085
Bloques libres: 292995 (19.5%)

Mín. extensión libre: 4 KB
Máx. extensión libre: 24008 KB
Extensión libre promedio: 252 KB
