E2SCRUB(8) Manual del Administrador del Sistema E2SCRUB(8)

NOMBRE

e2scrub_all - comprueba todos los sistemas de archivos ext[234] montados en busca de errores.

SINOPSIS

e2scrub_all [OPCIÓN]

DESCRIPCIÓN

Busca en el sistema todos los volúmenes lógicos de LVM que contienen un sistema de archivos ext2, ext3 o ext4, y los comprueba en busca de problemas. La comprobación se realiza invocando la herramienta e2scrub, que buscará corrupciones. Los sistemas de archivos corruptos se marcarán con errores para que se invoque fsck antes del próximo montaje. Si no se encuentran errores, se llamará a fstrim en el sistema de archivos si está montado. Consulte la página del manual de e2scrub para obtener más información sobre cómo se realiza la comprobación.

OPCIONES

-n
Imprime qué comandos ejecutaría e2scrub_all para iniciar las operaciones de e2scrub. (Nota: estos comandos no se ejecutarán realmente; sin embargo, dado que e2scrub_all necesita ejecutar algunos comandos adicionales, privilegiados, para consultar el sistema y determinar qué comandos de e2scrub se ejecutarían, todavía necesita ejecutarse como root.)
-r
Elimina las instantáneas de e2scrub pero no comprueba nada.
-A
Comprueba todos los sistemas de archivos ext[234] aunque no estén montados.
-V
Imprime información de la versión y sale.

VER TAMBIÉN

e2scrub(8)
