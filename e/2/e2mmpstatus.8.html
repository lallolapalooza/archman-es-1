E2MMPSTATUS(8) Manual del Administrador del Sistema E2MMPSTATUS(8)

NOMBRE

e2mmpstatus - Comprobar el estado MMP de un sistema de archivos ext4

SINOPSIS

e2mmpstatus [-i] <sistemadearchivos>

OPCIONES

-i
imprime la información de MMP en lugar de comprobarla.

DESCRIPCIÓN

e2mmpstatus se utiliza para comprobar el estado de Protección contra Múltiples Montajes (MMP) de un sistema de archivos ext4 con la característica mmp habilitada. El sistema de archivos especificado puede ser un nombre de dispositivo (por ejemplo, /dev/hdc1, /dev/sdb2), o una etiqueta o UUID de sistema de archivos ext4, por ejemplo UUID=8868abf6-88c5-4a83-98b8-bfc24057f7bd o LABEL=root. Por defecto, el programa e2mmpstatus comprueba si es seguro montar el sistema de archivos sin correr el riesgo de montarlo más de una vez.

MMP (protección contra múltiples montajes) es una característica que añade protección contra la modificación simultánea del sistema de archivos por más de un nodo. NO es seguro montar un sistema de archivos cuando una de las siguientes condiciones es verdadera:
1. e2fsck se está ejecutando en el sistema de archivos.
2. el sistema de archivos está en uso por otro nodo.
3. El bloque MMP está corrupto o no se puede leer por alguna razón.
El programa e2mmpstatus puede esperar un tiempo para ver si el bloque MMP está siendo actualizado por algún nodo durante este período. El tiempo tomado depende de la frecuencia con la que el bloque MMP está siendo escrito por el otro nodo.

CÓDIGO DE SALIDA

El código de salida devuelto por e2mmpstatus es 0 cuando es seguro montar el sistema de archivos, 1 cuando el bloque MMP indica que el sistema de archivos está en uso en otro nodo y NO es seguro montar el sistema de archivos, y 2 si ocurrió algún otro fallo que impida que la comprobación detecte correctamente el estado MMP actual.
