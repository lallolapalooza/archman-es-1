E2UNDO(8) Manual del Administrador del Sistema E2UNDO(8)

NOMBRE

e2undo - Reinterpreta un registro de deshacer para un sistema de archivos ext2/ext3/ext4

SINOPSIS

e2undo [ -f ] [ -h ] [ -n ] [ -o offset ] [ -v ] [ -z archivo_deshacer ] registro_deshacer dispositivo

DESCRIPCIÓN

e2undo reinterpretará el registro de deshacer registro_deshacer para un sistema de archivos ext2/ext3/ext4 que se encuentra en dispositivo. Esto se puede usar para deshacer una operación fallida de un programa de e2fsprogs.

OPCIONES

-f
Normalmente, e2undo comprobará el superbloque del sistema de archivos para asegurarse de que el registro de deshacer coincide con el sistema de archivos en el dispositivo. Si no coinciden, e2undo se negará a aplicar el registro de deshacer como un mecanismo de seguridad. La opción -f deshabilita este mecanismo de seguridad.
-h
Muestra un mensaje de uso.
-n
Simulación; no escribir bloques reales de vuelta al sistema de archivos.
-o offset
Especifica el offset (en bytes) del sistema de archivos desde el principio del dispositivo o archivo.
-v
Informa sobre el bloque que se está reinterpretando actualmente.
-z archivo_deshacer
Antes de sobrescribir un bloque del sistema de archivos, escribe el contenido antiguo del bloque en un archivo de deshacer. Este archivo de deshacer se puede usar con e2undo(8) para restaurar el contenido antiguo del sistema de archivos en caso de que algo salga mal. Si se pasa una cadena vacía como argumento de archivo_deshacer, el archivo de deshacer se escribirá en un archivo llamado e2undo-dispositivo.e2undo en el directorio especificado a través de la variable de entorno E2FSPROGS_UNDO_DIR.

ADVERTENCIA: El archivo de deshacer no se puede usar para recuperarse de un corte de energía o un fallo del sistema.
