E2SCRUB(8) Manual del administrador del sistema E2SCRUB(8)

NOMBRE

e2scrub - comprobar el contenido de un sistema de archivos ext[234] montado

SINOPSIS

e2scrub [OPCIÓN] PUNTO_MONTAJE | DISPOSITIVO

DESCRIPCIÓN

e2scrub intenta comprobar (pero no reparar) todos los metadatos de un sistema de archivos ext[234] montado si el sistema de archivos reside en un volumen lógico de LVM. También se puede pasar el dispositivo de bloques del volumen lógico de LVM.

Este programa crea una instantánea (snapshot) del volumen y ejecuta una comprobación del sistema de archivos en la instantánea para buscar errores de corrupción. El grupo de volúmenes LVM debe tener al menos 256MiB de espacio sin asignar para dedicarlos a la instantánea, de lo contrario, el volumen lógico se omitirá. La instantánea se llamará nombre_lv.e2scrub y udev no creará enlaces simbólicos a ella bajo /dev/disk. Se hará todo lo posible por eliminar las instantáneas antes de ejecutar e2scrub, pero en una situación crítica puede ser necesario eliminar la instantánea manualmente.

Si no se encuentran errores, se puede llamar a fstrim en el sistema de archivos si está montado. Si se encuentran errores, el sistema de archivos se marcará como con errores. El sistema de archivos debe ser desmontado y ejecutar e2fsck lo antes posible, ya que e2scrub no repara las corrupciones. Si el sistema de archivos no se repara, se ejecutará e2fsck antes del próximo montaje.

OPCIONES

-n
Imprime qué comandos ejecutaría e2scrub para comprobar el sistema de archivos. (Nota: los comandos no se ejecutarán realmente; sin embargo, dado que e2scrub necesita ejecutar algunos comandos para consultar el sistema y determinar qué comandos se ejecutarían, todavía necesita ser ejecutado como root).
-r
Elimina la instantánea de e2scrub y sale sin comprobar nada.
-t
Ejecuta fstrim(1) en el sistema de archivos montado si no se encuentran errores.
-V
Imprime la información de la versión y sale.

CÓDIGO DE SALIDA

Los códigos de salida son los mismos que en e2fsck(8)
