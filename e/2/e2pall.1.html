e2pall(1) Manual de Comandos Generales e2pall(1)

NOMBRE

e2pall - convierte todos los archivos EPS de un documento LaTeX a PDF

SINOPSIS

e2pall FICHEROTEX

DESCRIPCIÓN

e2pall busca en FICHEROTEX comandos \includegraphics para encontrar los nombres base de los archivos de imagen. Cuando encuentra uno, e2pall ejecuta epstopdf(1) para crear un archivo PDF a partir del archivo EPS.

e2pall comprobará que un archivo PDF existente esté actualizado con el archivo EPS, y no ejecutará epstopdf(1) si el archivo PDF es más reciente que el archivo EPS.

ERRORES

Envía informes de errores por correo electrónico a https://lists.tug.org/tex-k (lista de correo pública).

Parece estar roto
No puede manejar \input{nombre_archivo} o \includegraphics{nombre_archivo} divididos en más de una línea
Debe ejecutarse desde el mismo directorio que el archivo LaTeX
No busca en $TEXINPUTS
No puede manejar documentos que usan comandos \include
Asume que todos los archivos incluidos con \includegraphics son archivos EPS

VER TAMBIÉN

epstopdf(1)
