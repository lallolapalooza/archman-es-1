DESCRIPCIÓ

N

Esta es una extensión del módulo Email::Simple, para manejar mensajes codificados con MIME.

Toma un mensaje como una cadena de texto, lo divide en sus partes constituyentes y te permit
e acceder a varias partes del mensaje. Las cabeceras se decodifican de la codificación MIME.

PERL

Esta biblioteca debería ejecutarse en versiones de Perl lanzadas hace mucho tiempo. Debería funcionar en cualquier versión de Perl lanzada en los últimos cinco

años.

Este método crea una nueva parte MIME. El parámetro "header_str" es una lista de pares de cabeceras a incluir en el mensaje. Se espera que el valor de cada par sea una cadena de texto que se codificará con MIME según sea necesario. Alternativamente, puede ser un objeto con el método "as_mime_string" que implementa la conversión de ese objeto a una cadena codificada con MIME. Ese método del objeto se llama con dos parámetros de entrada con nombre: "charset" y "header_name_length". Debería devolver la representación codificada con MIME del objeto. A partir del 2017-07-25, el código de cabecera-como-objeto es muy nuevo y aún puede

cambiar.

En caso de que el nombre de la cabecera esté registrado en el hash %Email::MIME::Header::header_to_class_map, la clase registrada se utiliza para la conversión de una cadena Unicode a codificación MIME de 8 bits. El valor puede ser una cadena o una referencia a un array de cadenas. El objeto se construye mediante el método "from_string" con el valor de cadena (o valores en caso de referencia a array) y se convierte a una cadena codificada con MIME mediante el método "as_mime_string"

.

Un parámetro similar "header" puede proporcionarse además de o en lugar de "header_str". Sus valores se usarán

literalmente.

"attributes" es un hash de atributos MIME a asignar a la parte, y puede anular partes de la cabecera establecida en el parámetro "header". Las claves del hash corresponden directamente a métodos para modificar un mensaje. Las claves permitidas son: content_type, charset, name, format, boundary, encoding, disposition y filename. Se mapearán a "$attr\_set" para la modificación del

mensaje.

El parámetro "parts" es una referencia a una lista que contiene objetos "Email::MIME". Los elementos de la lista "parts" también pueden ser una cadena de datos sin referencia. En ese caso, se creará un objeto "Email::MIME" por ti. Comprobaciones simples determinarán si la parte es binaria o no, y todas las partes creadas de esta manera se codifican con "base64", por si

acaso.

Si se proporciona "body" en lugar de "parts", especifica el cuerpo a usar para un mensaje MIME plano (sin subpartes). Se asume que es una secuencia de

octetos.

Si se proporciona "body_str" en lugar de "body" o "parts", se asume que es una cadena de caracteres a usar como cuerpo. Si proporcionas un parámetro "body_str", debes proporcionar los atributos "charset" y "encod

CONFIGURACIÓ

N

La variable i">$Email::MIME::MAX_DEPTH es la profundidad máxima de partes que serán procesadas. Por defecto es 10, ya más alta de lo que un correo legítimo probablemente alcanzará. Este valor puede subir con el tiempo a medida que el analizador sintáctico se

mejore.

La variable $Email::MIME::MAX_PARTS es el número máximo de partes que serán procesadas. Por defecto es 100, ya más alto de lo que un correo legítimo probablemente alcanzará. Este valor puede subir con el tiempo a medida que el analizador sintáctico se mejore o a medida que la investigación sugiera que nuestra posición inicial era

incorrecta.

Aumentar cualquiera de estas variables conllev
