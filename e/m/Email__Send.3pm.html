Escribir sistemas de

package Email::Send::Example;
sub is_available {
    eval { use Net::Example }
}
sub send {
    my ($class, $message, @args) = @_;
    use Net::Example;
    Net::Example->do_it($message) or return;
}
1;

Escribir nuevos sistemas de correo es muy simple. Si quiere usar un nombre corto al llamar a "send", nombre su sistema de correo bajo el espacio de nombres "Email::Send". Si no lo hace, se tendrá que usar el nombre completo. Un sistema de correo solo necesita implementar una única función, "send". Será llamado desde "Email::Send" exactamente

así. 
Your::Sending::Package->send($message, @args)
;

$message es un objeto Email::Simple, @args son los argumentos extra pasados a "Email::Send:

:send".

Aquí hay un ejemplo de un sistema de correo que envía correo electrónico a una

URL. 
package Email::Send::HTTP::Post;
use strict;
use vars qw[$AGENT $URL $FIELD];
use Return::Value;
sub is_available {
    eval { use LWP::UserAgent }
}
sub send {
    my ($class, $message, @args);
    require LWP::UserAgent;
    if ( @args ) {
        my ($URL, $FIELD) = @args;
        $AGENT = LWP::UserAgent->new;
    }
    return failure "No se puede enviar a la URL si no se nombran la URL y el campo"
        unless $URL && $FIELD;
    $AGENT->post($URL => { $FIELD => $message->as_string });
    return success;
}
1;
