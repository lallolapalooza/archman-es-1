my $reply   = reply to       => $message,
                    from     => '"Casey West" <casey@geeknest.com>',
                    all      => 1;
                    self     => 0,
                    attach   => 1,
                    quote    => 1,
                    top_post => 0,
                    keep_sig => 1,
                    prefix   => ': ',
                    attrib   => sprintf("De %s, escribidor de muchas palabras:",
                                        $from->name),
                    body     => <<__RESPONSE__;
Gracias por el mensaje, me alegrará explicar la imagen...
__RESPONSE__

Esta función acepta varios parámetros con nombre y devuelve un objeto de mensaje de correo electrónico de tipo "Email::MIME" o "Email::Simple", dependiendo de los parámetros pasados. Revisemos esos parámetros

ahora.
"t
o"
Este parámetro requerido es el mensaje de correo electrónico al que estás respondiendo. Puede representar varios tipos de objetos, o una cadena que contenga el mensaje. Este valor se pasa directamente a "Email::Abstract" sin pasar por Go ni cobrar los $200, así que por favor, lee sobre sus complementos disponibles para saber qué se permite
aquí.
"fro
m"
Este parámetro opcional especifica una dirección de correo electrónico a usar que indica al remitente del mensaje de respuesta. Puede ser una cadena o un objeto "Email::Address". En ausencia de este parámetro, se usa la primera dirección encontrada en el encabezado "To" del mensaje original. Esto puede no ser siempre lo que quieras, por lo que este parámetro es altamente
recomendado.
"al
l"
Este parámetro opcional indica si deseas "Responder a todos". Si es verdadero, el encabezado "Cc" de la respuesta se rellenará con todas las direcciones de los encabezados "To" y "Cc" del original. Por defecto, el parámetro es falso, indicando "Responder al
remitente".
"sel
f"
Este parámetro opcional decide si una dirección que coincida con la dirección "from" será incluida en la lista de direcciones "all". Si es verdadero, tu dirección se preservará en esa lista si se encuentra. Si es falso, como lo es por defecto, tu dirección será eliminada de la lista. Como podrías esperar, este parámetro solo es útil si "all" es
verdadero.
"attac
h"
Este parámetro opcional permite que el mensaje original, en su totalidad, sea encapsulado en una parte MIME de tipo "message/rfc822". Si es verdadero, el objeto devuelto por "reply" será un objeto "Email::MIME" cuya segunda parte es el mensaje encapsulado. Si es falso, nada de esto ocurre. Por defecto, nada de esto
ocurre.
"quot
e"
Este parámetro opcional, que es verdadero por defecto, citará el mensaje original para tu respuesta. Si el mensaje original es un mensaje MIME, se citará la primera parte de tipo "text/plain". Si es un mensaje Simple, se citará el cuerpo. Bueno, eso solo si mantienes el parámetro verdadero. Si no lo haces, nada de esto
ocurre.
"top_pos
t"
Este parámetro opcional, cuyo uso generalmente se desaconseja, permitirá el envío de mensajes en la parte superior (top posting) si es verdadero. Establecerá implícitamente "quote" a verdadero, y pondrá tu "body" antes del texto citado. Es falso por defecto, y deberías hacer lo posible por mantenerlo
así.
"keep_si
g"
Este parámetro opcional alterna el mecanismo de eliminación de firmas. Verdadero por defecto, la firma se eliminará del cuerpo citado original. Cuando es falso, la firma se deja intacta y se citará correspondientemente. Esto solo es útil cuando "quote" es
verdadero.
"prefi
x"
Este parámetro opcional especifica el prefijo de citación. Por defecto, es ">", pero puedes cambiarlo estableciendo este parámetro. Nuevamente, solo útil cuando "quote" es
verdadero.
"attri
b"
Este parámetro opcional especifica la línea de atribución a añadir al comienzo del texto citado. Por defecto, se usa el nombre o la dirección de correo electrónico del remitente original para reemplazar %s en la cadena, "%s escribió:". Puedes cambiar eso con este parámetro. No se proporcionan formatos especiales, sprintf() ni de otro tipo, para tu comodidad. Lo siento, tendrás que arreglártelas. Como "prefix" y "keep_sig", esto solo es bueno cuando "quote" es
verdadero.
"bod
y"
Este parámetro requeri
do contiene tu prosa,
tu manifiesto, tu
respuesta. ¡Recuerda
revisar la ortografía!
