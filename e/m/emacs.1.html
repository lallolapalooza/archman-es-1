DESCRIPCIÓN GNU Emacs es una versión de Emacs

, esc
rita

por

el

autor del Emacs original (PDP-10), Richard Stallman. La funcionalidad para el usuario de GNU Emacs abarca todo lo que hacen otros editores, y es fácilmente extensible ya que sus comandos de edición están escritos en Lisp. La documentación principal de GNU Emacs está en el Manual

de

GNU Emacs, que puede leer usando Info, ya sea desde Emacs o como un programa independiente. Por favor, busque allí la documentación completa y actualizada. Esta página man solo se actualiza cuando alguien se ofrece voluntario para hacerlo. Emacs tiene una extensa instalación de ayuda

interactiva,

pero la instalación asume que sabe cómo manipular ventanas y búferes de Emacs. CTRL-h o F1 entra en la instalación de Ayuda. Tutorial de Ayuda (CTRL-h t) inicia un tutorial interactivo para enseñar rápidamente a los principiantes los fundamentos de Emacs. Ayuda Apropos (CTRL-h a) le ayuda a encontrar un comando con un nombre que coincida con un patrón dado, Ayuda Tecla (CTRL-h k) describe una secuencia de teclas dada, y Ayuda Función (CTRL-h f) describe una función Lisp dada. Los muchos paquetes especiales de GNU Emacs

manejan

la lectura de correo (RMail) y el envío (Mail), la edición de esquemas (Outline), la compilación (Compile), la ejecución de subshells dentro de ventanas de Emacs (Shell), la ejecución de un bucle leer-evaluar-imprimir de Lisp (Lisp-Interaction-Mode), la psicoterapia automatizada (Doctor), y mucho más.
