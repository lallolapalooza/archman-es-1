Aide Apropos (CTRL-h a) vous aide à trouver une commande correspondant à un motif donné, Aide Touche (CTRL-h k) décrit une séquence de touches donnée, et Aide Fonction (CTRL-h f) décrit une fonction Lisp donnée. Les nombreux paquets spéciaux de GNU Emacs gèrent

la

lecture du courrier (RMail) et l'envoi (Mail), l'édition de plans (Outline), la compilation (Compile), l'exécution de sous-shells dans les fenêtres de Emacs (Shell), l'exécution d'une boucle lire-évaluer-afficher Lisp (Lisp-Interaction-Mode), la psychothérapie automatisée (Doctor), et bien plus encore. MANUALES

Puede pedir copias impresas del Manual de GNU Emacs a la Free Software Foundation, que desarrolla software GNU. Consulte la tienda en línea en https://shop.fsf.org/.
Su administrador local también podría tener copias disponibles. Al igual que con todo software y publicaciones de la FSF, se permite a todos hacer y distribuir copias del manual de Emacs. El código fuente Texinfo del manual también se incluye en la distribución fuente de Emacs.

ARCHIVOS

/usr/local/share/info — archivos para el navegador de documentación Info. El texto completo del manual de referencia de Emacs se incluye en un formato estructurado en árbol conveniente. Esto incluye el Manual de Referencia de Emacs Lisp, útil para cualquiera que desee escribir programas en el lenguaje de extensión Emacs Lisp, y la Introducción a la Programación en Emacs Lisp.

/usr/local/share/emacs/$VERSION/lisp — archivos fuente Lisp y archivos compilados que definen la mayoría de los comandos de edición. Algunos se precargan; otros se cargan automáticamente desde este directorio cuando se usan.

/usr/local/libexec/emacs/$VERSION/$ARCH — varios programas que se utilizan con GNU Emacs.

/usr/local/share/emacs/$VERSION/etc — varios archivos de información.

/usr/local/share/emacs/$VERSION/etc/DOC.* — contiene las cadenas de documentación para las primitivas Lisp y las funciones Lisp precargadas de GNU Emacs. Se almacenan aquí para reducir el tamaño de Emacs propiamente dicho.

ERRORES

Existe una lista de correo, bug-gnu-emacs@gnu.org, para informar sobre errores y correcciones de Emacs. Pero antes de informar algo como un error, por favor intente asegurarse de que realmente es un error, no una malinterpretación o una característica deliberada. Le pedimos que lea la sección "Reportar Errores" del manual de Emacs para obtener indicaciones sobre cómo y cuándo informar errores. Además, incluya el número de versión de Emacs que está ejecutando en *cada* informe de error que envíe. Los errores tienden a ser corregidos si se pueden aislar, por lo que le conviene informarlos de manera que se puedan reproducir fácilmente.

No espere una respuesta personal a un informe de error. El propósito de informar errores es que se corrijan para todos en la próxima versión, si es posible. Para asistencia personal, consulte el directorio de servicios en https://www.fsf.org/resources/service/ para obtener una lista de personas que la ofrecen.

Por favor, no envíe nada más que informes de errores a esta lista de correo. Para otras listas de Emacs, consulte https://savannah.gnu.org/mail/?group=emacs.
