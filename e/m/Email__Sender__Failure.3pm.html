Email::Sender::Failure(3) Documentación de Perl aportada por el usuario Email::Sender::Failure(3)

NOMBRE

Email::Sender::Failure - un informe de fallo de un transporte de envío de correo

VERSIÓN

versión 2.601

VERSIÓN DE PERL

Esta biblioteca debería ejecutarse en versiones de Perl incluso antiguas. Debería funcionar en cualquier versión de Perl lanzada en los últimos cinco años.

Aunque puede funcionar en versiones más antiguas de Perl, no se garantiza que la versión mínima requerida no aumente. La versión puede aumentar por cualquier motivo, y no hay promesa de que se acepten parches para reducir la versión mínima requerida de Perl.

ATRIBUTOS

mensaje

Este método devuelve el mensaje de fallo, que debe describir el fallo. Los fallos se convierten a cadenas con este mensaje.

código

Esto devuelve el código numérico del fallo, si lo hay. Esto es principalmente útil para transportes de protocolos de red como SMTP. Esto puede no estar definido.

destinatarios

Esto devuelve una lista de direcciones a las que no se pudo enviar el correo electrónico.

MÉTODOS

lanzar

Este método puede usarse para instanciar y lanzar un objeto Email::Sender::Failure a la vez.

Email::Sender::Failure->throw(\%arg);

En lugar de un hashref de argumentos, puedes pasar un solo argumento de cadena que se usará como el "mensaje" del nuevo fallo.

VER TAMBIÉN

  • Email::Sender::Permanent
  • Email::Sender::Temporary
  • Email::Sender::Multi
