NOMBRE

Email::Sender::Transport::Test - entrega correo en memoria para pruebas

VERSIÓN

versión 2.601

DESCRIPCIÓN

Este transporte está diseñado para probar entregas de correo en memoria. Almacenará un registro de cualquier entrega realizada para que puedan inspeccionarse posteriormente.

VERSIÓN DE PERL

Esta biblioteca debería ejecutarse incluso en versiones antiguas de Perl. Debería funcionar en cualquier versión de Perl lanzada en los últimos cinco años.

ATRIBUTOS

entregas

Por defecto, el transporte de Prueba no permitirá el éxito parcial y siempre tendrá éxito. Sin embargo, se puede hacer que falle predeciblemente si se extiende y sus métodos "recipient_failure" o "delivery_failure" se anulan. Estos métodos se llaman de la siguiente manera:

$self->delivery_failure($email, $envelope);
$self->recipient_failure($to);

Si devuelven verdadero, el envío fallará. Si el transporte se creó con un atributo "allow_partial_success" verdadero, los fallos de destinatario pueden hacer que se devuelva un éxito parcial.

Para modos de fallo más flexibles, puedes anular de forma más agresiva o puedes usar Email::Sender::Transport::Failable.

Este atributo almacena una referencia a un array de todas las entregas realizadas a través del transporte. El método "clear_deliveries" devuelve una lista de ellas.

Cada entrega es una referencia a un hash, en el siguiente formato:

{
  email     => $email,
  envelope  => $envelope,
  successes => \@ok_rcpts,
  failures  => \@failures,
}

Se almacenan tanto las entregas exitosas como las fallidas.

Se proporcionan varios métodos relacionados con este atributo:

  • delivery_count
  • clear_deliveries
  • shift_deliveries
