NOMBRE

Email::Send::SMTP - Enviar Mensajes usando SMTP

SINOPSIS

use Email::Send;
my $mailer = Email::Send->new({mailer => 'SMTP'});
$mailer->mailer_args([Host => 'smtp.example.com:465', ssl => 1])
  if $USE_SSL;
$mailer->send($message);

DESCRIPCIÓN

Este empaquetador para "Email::Send" usa "Net::SMTP" para enviar un mensaje con un servidor SMTP. La primera invocación de "send" requiere argumentos del servidor SMTP. Las llamadas subsiguientes recordarán la primera configuración hasta que se restablezca.

Cualquier argumento pasado a "send" será pasado a "Net::SMTP->new()", con algunas excepciones. "username" y "password", si se pasan, se usan para invocar "Net::SMTP->auth()" para soporte de autenticación SASL. "ssl", si se establece a verdadero, activa el soporte SSL usando "Net::SMTP::SSL".

SMTP puede fallar por varias razones. Todos los valores de retorno de este paquete son verdaderos o falsos. Si es falso, el envío ha fallado. Si es verdadero, el envío ha tenido éxito. Los valores de retorno son objetos "Return::Value", sin embargo, y contienen más información sobre lo que salió mal.

Aquí hay un ejemplo de cómo lidiar con el fracaso.

my $return = send SMTP => $message, 'localhost';
die "$return" if ! $return;

La versión en cadena del valor de retorno tendrá el texto del error. En una condición, un fallo se evaluará como falso.

Aquí tienes un ejemplo de cómo lidiar con el éxito. Se da el caso de que algunas direcciones de correo electrónico pueden no tener éxito, pero otras sí. En este caso, la propiedad "bad" del valor de retorno se establece en una lista de direcciones erróneas.

my $return = send SMTP => $message, 'localhost';
if ( $return ) {
    my @bad = @{ $return->prop('bad') };
    warn "Failed to send to: " . join ', ', @bad
      if @bad;
}

Para más información sobre estos valores de retorno, ver Return::Value.

GENERACIÓN DEL SOBRE

El remitente y los destinatarios del sobre se generan, por defecto, buscando en las cabeceras From, To, Cc y Bcc. Este comportamiento se puede modificar reemplazando los métodos "get_env_sender" y "get_env_recipients", ambos reciben el objeto Email::Simple y su único parámetro, y devuelven direcciones de correo electrónico.
