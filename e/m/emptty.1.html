NOMBRE

emptty - Gestor de pantalla CLI simple en TTY

SINOPSIS

emptty [-v] [--version] [-d] [--daemon] [-c RUTA] [--config RUTA] [-i] [--ignore-config] [-t TTY] [--tty TTY] [-u usuarioPredeterminado] [--default-user usuarioPredeterminado] [-a [sesión]] [--autologin [sesión]]

DESCRIPCIÓN

emptty Gestor de pantalla CLI simple, que permite seleccionar el entorno de escritorio/gestor de ventanas después de iniciar sesión, usar configuración predefinida o permitir el inicio de sesión automático, si el usuario seleccionado pertenece al grupo nopasswdlogin.

OPCIONES

-v, --version
Muestra la versión del programa.
-d, --daemon
Inicia emptty como demonio, que no requiere agetty.
-c, --config RUTA
Carga la configuración desde la ruta especificada.
-C, --print-config
Solo imprime la configuración cargada y sale.
-i, --ignore-config
Omite la carga de configuración desde el archivo, solo carga la configuración de los argumentos.
-t, --tty TTY
Anula la configuración cargada estableciendo la TTY definida. Puede especificarse como un número (p. ej., "7") o un nombre de TTY (p. ej., "tty7").
-u, --default-user usuarioPredeterminado
Anula la configuración cargada estableciendo el usuario predeterminado definido.
-a, --autologin [sesión]
Anula la configuración cargada habilitando el inicio de sesión automático. Si se define una sesión, anula la sesión de inicio de sesión automático.

CONFIGURACIÓN

/etc/emptty/conf

NUMERO_TTY
TTY en la que se iniciará emptty.
CAMBIAR_TTY
Habilita el cambio a un número de TTY definido. Predeterminado: true.
IMPRIMIR_ISSUE
Habilita la impresión de /etc/issue en modo demonio.
IMPRIMIR_MOTD
Habilita la impresión de motd predeterminado, motd estático o motd dinámico.
ENTORNO_PREDETERMINADO
Define el entorno predeterminado utilizado para iniciar sesiones no definidas (p. ej., desde el archivo `emptty`). Los valores posibles son "xorg" y "wayland". El valor predeterminado es xorg.
USUARIO_PREDETERMINADO
Usuario preseleccionado; si AUTOLOGIN está habilitado, se iniciará sesión con este usuario.
SESIÓN_PREDETERMINADA
Sesión de escritorio preseleccionada; si el usuario no utiliza el archivo `emptty`. Tiene menor prioridad que SESIÓN_AUTOLOGIN.
ENTORNO_SESIÓN_PREDETERMINADA
Entorno opcional de la sesión de escritorio preseleccionada; si el usuario no utiliza el archivo `emptty`. Los valores posibles son "xorg" y "wayland".
AUTOLOGIN
Habilita el inicio de sesión automático, si se define USUARIO_PREDETERMINADO. Los valores posibles son "true" o "false". Valor predeterminado: false.

NOTA: para habilitar el inicio de sesión automático, USUARIO_PREDETERMINADO debe pertenecer al grupo nopasswdlogin, de lo contrario, el usuario NO será autorizado.

SESIÓN_AUTOLOGIN
La sesión predeterminada utilizada si el inicio de sesión automático está habilitado. Si la sesión no se encuentra en la lista de sesiones, procede a la selección manual.
ENTORNO_SESIÓN_AUTOLOGIN
Entorno opcional de la sesión de escritorio de inicio de sesión automático. Los valores posibles son "xorg" y "wayland".
AUTOLOGIN_MAX_RETRY
Si la sesión no se inicia correctamente en el período especificado, se mantiene el número de reintentos en un corto período para detener eventualmente el bucle infinito de reinicios. -1 significa reintentos infinitos, 0 significa sin reintentos. El valor predeterminado es 2.
AUTOLOGIN_RETRY_PERIOD
Período de tiempo en segundos, que se utiliza para comprobar los reintentos de inicio de sesión de la sesión. El valor predeterminado es 2.
LANG
Define la configuración regional para todos los usuarios. El valor predeterminado es "en_US.UTF-8"
DBUS_LAUNCH
Inicia "dbus-launch" antes del comando de sesión. Después del final de la sesión, se interrumpe "dbus-daemon". El valor predeterminado es true. Si la configuración del usuario se maneja como un script (no contiene la opción Exec), esta configuración se anula a false.
ALWAYS_DBUS_LAUNCH
Inicia "dbus-launch" antes del comando de sesión en cualquier caso, se ignora el valor de DBUS_LAUNCH. También se inicia incluso si XINITRC_LAUNCH está establecido en `true`. Después del final de la sesión, se interrumpe "dbus-daemon". El valor predeterminado es false.
XINITRC_LAUNCH
Inicia la sesión Xorg llamando al script ~/.xinitrc con la ejecución de la sesión como argumento; si es true, el archivo existe y el WM/DE seleccionado es una sesión Xorg, anula DBUS_LAUNCH. Si la configuración del usuario se maneja como un script (no contiene la opción Exec), esta configuración se anula a false.
SELECCIÓN_VERTICAL
Imprime el WM/DE disponible cada uno en una nueva línea en lugar de imprimir en una sola línea.
INDENTACIÓN_SELECCIÓN
Desplazamiento horizontal para la selección vertical, útil para centrar el menú en la pantalla.
LOGGING
Define cómo se maneja el registro. Los valores posibles son "rotate", "appending" o "disabled". El valor predeterminado es "rotate".
ARCHIVO_LOGGING
Anula la ruta del archivo de registro. El valor predeterminado es /var/log/emptty/[NUMERO_TTY].log

NOTA: espera la existencia de directorios para el archivo de registro definido.

XORG_ARGS
Argumentos pasados al servidor Xorg.
MOTD_DINÁMICO
Permite usar un script motd dinámico para generar un MOTD personalizado. Los valores posibles son "true" o "false". El valor predeterminado es false.

NOTA: asegúrate de que el motd dinámico tenga el contenido y los permisos correctos (p. ej., 744); el script se inicia como el usuario predeterminado; en modo demonio, esto significa root

RUTA_MOTD_DINÁMICO
Permite anular la ruta predeterminada al motd dinámico. El valor predeterminado es "/etc/emptty/motd-gen.sh".
RUTA_MOTD
Permite anular la ruta predeterminada al motd estático. El valor predeterminado es "/etc/emptty/motd".
COLOR_FUENTE
Color de fuente, disponible solo en modo demonio. La lista de colores se muestra a continuación.
COLOR_FONDO
Color de fondo, disponible solo en modo demonio. La lista de colores se muestra a continuación.
SCRIPT_INICIO_PANTALLA
Script iniciado antes de que comience la pantalla (Xorg/Wayland).

NOTA: el script se inicia como el usuario predeterminado; en modo demonio, esto significa root

SCRIPT_FIN_PANTALLA
Script iniciado después de que la pantalla (Xorg/Wayland) se detiene.

NOTA: el script se inicia como el usuario predeterminado; en modo demonio, esto significa root

ACTIVAR_NUMLOCK
Habilita numlock en modo demonio. Los valores posibles son "true" o "false".

COMMAND

S

Si se permiten comandos y no se ha definido un usuario predeterminado, se pueden usar comandos en la entrada de inicio de sesión. Todos estos comandos deben empezar con dos puntos ":". Los caracteres de escape se ignoran para evitar problemas con la memoria muscular de VI.
- :help, :? - imprime los comandos disponibles
- :poweroff, :shutdown - procesa el comando de apagado
- :reboot - procesa el comando de reinicio
- :suspend, :zzz
