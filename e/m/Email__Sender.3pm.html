Email::Sender(3) Documentación de Perl aportada por el usuario Email::Sender(3)

NOMBRE

Email::Sender - una biblioteca para enviar correo electrónico

VERSIÓN

versión 2.601

SINOPSIS

my $message = Email::MIME->create( ... );
# produce un objeto de mensaje compatible con Email::Abstract,
# p. ej. producido por Email::Simple, Email::MIME, Email::Stuff
use Email::Sender::Simple qw(sendmail);
use Email::Sender::Transport::SMTP qw();
use Try::Tiny;
try {
  sendmail(
    $message,
    {
      from => $SMTP_ENVELOPE_FROM_ADDRESS,
      transport => Email::Sender::Transport::SMTP->new({
          host => $SMTP_HOSTNAME,
          port => $SMTP_PORT,
      })
    }
  );
} catch {
    warn "el envío falló: $_";
};

DESCRIPCIÓN GENERAL

Email::Sender reemplaza a la antigua y a veces problemática biblioteca Email::Send, que hacía un trabajo decente al manejar tareas de envío de correo electrónico muy simples, pero no era adecuada para un uso serio, por una variedad de razones.

La mayoría de los usuarios podrán usar Email::Sender::Simple para enviar correo. Los usuarios con necesidades más específicas deberían consultar las clases disponibles de Email::Sender::Transport.

La documentación se puede encontrar en Email::Sender::Manual, y los usuarios nuevos deberían comenzar con Email::Sender::Manual::QuickStart.

VERSIÓN DE PERL

Esta biblioteca debería funcionar en versiones de Perl lanzadas incluso hace mucho tiempo. Debería funcionar en cualquier versión de Perl lanzada en los últimos cinco años.

IMPLEMENTACIÓN

Email::Sender en sí es un rol de Moo. Cualquier clase que implemente Email::Sender debe proporcionar un método llamado "send". Este método debe aceptar cualquier entrada que pueda ser entendida por Email::Abstract, seguida de un hashref que contenga los argumentos "to" y "from" para ser utilizados como el sobre. El método debe devolver un objeto Email::Sender::Success en caso de éxito o lanzar una Email::Sender::Failure en caso de fallo.
