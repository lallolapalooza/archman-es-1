Email::MIME::Encodings(3) Documentación de Perl aportada por el usuario Email::MIME::Encodings(3)

NOMBRE

Email::MIME::Encodings - Una interfaz unificada para codificar y decodificar MIME

VERSIÓN

versión 1.317

SINOPSIS

use Email::MIME::Encodings;
my $codificado = Email::MIME::Encodings::encode(base64 => $cuerpo);
my $decodificado = Email::MIME::Encodings::decode(base64 => $codificado);

Si se proporciona un tercer argumento, este es la codificación a la que recurrir. Si no se encuentra ningún códec válido (considerando tanto el primer como el tercer argumento), se genera una excepción.

DESCRIPCIÓN

Este módulo simplemente envuelve "MIME::Base64" y "MIME::QuotedPrint" para que puedas pasar el contenido de una cabecera "Content-Transfer-Encoding" a algún texto y que ocurra lo correcto.

"MIME::Base64", "MIME::QuotedPrint", "Email::MIME".
