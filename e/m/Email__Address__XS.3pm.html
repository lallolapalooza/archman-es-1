DESC
RIP
CIÓN

Este módulo implementa el analizador y formateador de direcciones de correo electrónico y grupos

RFC 5322

https://tools.ietf.org/html/rfc5322. Analiza una cadena de entrada de encabezados de correo electrónico que contienen una lista de direcciones de correo electrónico o grupos de direcciones de correo electrónico (como From, To, Cc, Bcc, Reply-To, Sender, ...). También puede generar un valor de cadena para esos encabezados a partir de una lista de objetos de direcciones de correo electrónico. El módulo es compatible hacia atrás con RFC 2822 https://tools.ietf.org/html/rfc2822 y RFC 822 https://tools.ietf.org/html/rfc822. La funcionalidad del analizador y formateador está implementada en XS y utiliza cód

igo compartido del servidor IMAP Dovecot.

Es un reemplazo directo para el módulo Email::Address, el cual tiene varios problemas de seguridad. Por ejemplo, el problema CVE-2015-7686 (Vulnerabilidad de complejidad

algorítmica)

https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2015-7686, que permite a atacantes remotos causar denegación de servicio, todavía está presente en la versión 1.908 de Email::Address. El módulo Email::Address::XS fue creado para finalmente corregir

CVE-2015-7686.

Las aplicaciones existentes que usan el módulo Email::Address podrían cambiar fácilmente al módulo Email::Address::XS. En la mayoría de los casos, solo

cambiar

"use Email::Address" a "use Email::Address::XS" y reemplazar cada aparición de "Email::Address" por "Email::Address::XS" es

suficiente.

Así que a diferencia de Email::Address, este módulo no usa expresiones regulares para el análisis, sino que en su lugar una implementación XS nativa analiza la cadena de entrada secuencialmente de acuerdo con la gramática RFC

5322.

Además, también tiene soporte para grupos con nombre y por lo tanto puede usarse en lugar del módulo Email::Address::

List.

Si estás buscando el módulo que proporciona una representación de objetos para la lista de direcciones de correo electrónico adecuada para los encabezados de correo electrónico MIME, consulta Email::MIME::Header::

AddressList.
