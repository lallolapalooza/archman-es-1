NOMBRE

Email::Send::Test - Captura correos electrónicos enviados a través de Email::Send para pruebas

SINOPSIS

# Cargar como de costumbre
use Email::Send;
use Email::Send::Test;
# Siempre limpiar la trampa de correos antes de cada prueba para evitar
# resultados inesperados, y por lo tanto, resultados de prueba espurios.
Email::Send::Test->clear;
### EMPIEZA TU CÓDIGO A PROBAR (ejemplo a continuación)
my $sender = Email::Send->new({ mailer => 'Test' });
$sender->send( $message );
### TERMINA TU CÓDIGO A PROBAR
# Comprueba que el número y tipo (y contenido) de los correos
# coinciden con lo que esperas.
my @emails = Email::Send::Test->emails;
is( scalar(@emails), 1, 'Enviado 1 correo' );
isa_ok( $emails[0], 'Email::MIME' ); # Las subclases de Email::Simple pasan directamente

DESCRIPCIÓN

Email::Send::Test es un controlador para usar en la prueba de aplicaciones que utilizan Email::Send para enviar correos electrónicos.

Para poder usarlo en pruebas, necesitarás algún tipo de mecanismo de configuración para especificar el método de entrega a usar, o alguna otra forma para que en tus scripts de prueba puedas convencer a tu código de usar "Test" como remitente, en lugar de "Sendmail" u otro remitente real.

¿Cómo Funciona?

Email::Send::Test es una trampa para correos electrónicos. Cuando se envía un correo electrónico, lo añade a un array interno sin hacer nada con él, y devuelve éxito al llamador.

Si tu aplicación envía un correo electrónico, habrá uno en la trampa. Si envías 20, habrá 20, y así sucesivamente.

Una prueba típica implicará ejecutar algún código que **debería** resultar en el envío de un correo electrónico, y luego verificar en la trampa para ver si el código realmente envió el correo electrónico.

Si lo deseas, puedes sacar los correos de la trampa y examinarlos. Si solo te importa que algo se envió, simplemente puedes limpiar la trampa y pasar a tu próxima prueba.

La Trampa de Correos

La trampa de correos es un simple array que se llena con lo que se envía.

Cuando envías un correo electrónico, se añade al final del array. Puedes acceder al array directamente si lo deseas, o usar los métodos proporcionados.

MÉTODOS

send $mensaje

Al igual que con cualquier otro remitente de Email::Send, "send" toma el mensaje a enviar.

Sin embargo, en nuestro caso, no hay argumentos de ningún valor para nosotros, y por lo tanto, se ignoran.

Cabe destacar que NO HACEMOS NADA para comprobar o alterar el correo electrónico. Por ejemplo, si se nos pasa "undef", se almacena tal cual en la trampa. De esta manera, puedes ver **exactamente** lo que se envió sin ninguna posible manipulación por parte del remitente de prueba.

Por supuesto, esto no evita ninguna manipulación por parte del propio Email::Send :)

Siempre devuelve verdadero.

emails

El método "emails" es el método preferido y recomendado para acceder a la trampa de correos electrónicos.

En contexto de lista, devuelve el contenido del array de la trampa como una lista.

En contexto escalar, devuelve el número de elementos en la trampa.

clear

El método "clear" reinicia la trampa, vaciándola.

Se recomienda que siempre limpies la trampa antes de cada prueba para asegurar que se eliminen los correos existentes y no creen un resultado de prueba espurio.

Siempre devuelve verdadero.

deliveries

Este método devuelve una lista de arrayrefs, uno por cada llamada a "send" que se haya realizado. Cada arrayref tiene el formato:

[ $mailer, $email, \@rest ]

El primer elemento es el invocante sobre el cual se llamó a "send". El segundo es el correo electrónico que se le dio a "send". El tercero es el resto de los argumentos dados a "send".
