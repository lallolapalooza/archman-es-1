NOMBRE

Email::Sender::Transport::Wrapper - un remitente para envolver un remitente para enviar correos

VERSIÓN

versión 2.601

DESCRIPCIÓN

Email::Sender::Transport::Wrapper envuelve un transporte, proporcionado como el argumento "transport" al constructor. Se proporciona como una forma sencilla de usar modificadores de método para crear clases de envoltura.
