NOMBRE

Email::Abstract::Plugin - una clase base para plugins de Email::Abstract

VERSIÓN

versión 3.010

VERSIÓN DE PERL

Esta biblioteca debería ejecutarse incluso en perls liberados hace mucho tiempo. Debería funcionar en cualquier versión de perl liberada en los últimos cinco años.

Aunque puede funcionar en versiones anteriores de perl, no se garantiza que la versión mínima requerida no aumente. La versión puede aumentar por cualquier motivo, y no hay promesa de que se acepten parches para reducir la versión mínima requerida de perl.

MÉTODOS

está_disponible

Este método devuelve verdadero si el plugin debe considerarse disponible para registro. Los plugins que devuelven falso de este método no se registrarán cuando se cargue Email::Abstract.
