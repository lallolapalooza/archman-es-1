Email::MessageID(3) Documentación de Perl aportada por el usuario Email::MessageID(3)

NOMBRE

Email::MessageID - Genera IDs de mensaje únicos a nivel mundial.

VERSIÓN

versión 1.408

SINOPSIS

use Email::MessageID;
my $mid = Email::MessageID->new->in_brackets;
print "Message-ID: $mid\x0D\x0A";

DESCRIPCIÓN

Los IDs de mensaje son cabeceras opcionales, pero altamente recomendadas, que identifican un mensaje de forma única. Este software genera un ID de mensaje único.

VERSIÓN DE PERL

MÉTODOS

new

my $mid = Email::MessageID->new;
my $new_mid = Email::MessageID->new( host => $myhost );

Este método de clase construye un objeto Email::MessageID que contiene un ID de mensaje único. Puede especificar parámetros personalizados de "host" y "user".

Por defecto, el "host" se genera a partir de "Sys::Hostname::hostname".

Por defecto, el "user" se genera utilizando "Time::HiRes"'s "gettimeofday" y el ID del proceso.

Usando estos valores tenemos la capacidad de garantizar la unicidad mundial hasta un proceso específico que se ejecuta en un host específico, y la hora exacta hasta seis dígitos de precisión de microsegundos.

create_host

my $domain_part = Email::MessageID->create_host;

Este método devuelve la parte del dominio del ID del mensaje.

create_user

my $local_part = Email::MessageID->create_user;

Este método devuelve una parte local única para el ID del mensaje. Incluye datos aleatorios y datos predecibles.

in_brackets

Al usar Email::MessageID directamente para poblar el campo "Message-ID", asegúrese de usar "in_brackets" para obtener la cadena dentro de los corchetes angulares:

header => [
  ...
  'Message-Id' => Email::MessageID->new->in_brackets,
],

No cometa este error común:

header => [
  ...
  'Message-Id' => Email::MessageID->new->as_string, # ¡MAL!
],
