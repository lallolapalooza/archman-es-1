Email::Sender::Transport::SMTP(3) Documentación de Perl aportada por el usuario Email::Sender::Transport::SMTP(3)

NOMBRE

Email::Sender::Transport::SMTP - enviar correo electrónico a través de SMTP

VERSIÓN

versión 2.601

DESCRIPCIÓN

Este transporte se utiliza para enviar correo electrónico a través de SMTP, con o sin sockets seguros (SSL/TLS). Es uno de los transportes más complejos disponibles, capaz de éxito parcial.

Para una versión potencialmente más eficiente de este transporte, consulte Email::Sender::Transport::SMTP::Persistent.

VERSIÓN PERL

Esta biblioteca debería funcionar en versiones de perl lanzadas hace mucho tiempo. Debería funcionar en cualquier versión de perl lanzada en los últimos cinco años.

Aunque puede funcionar en versiones anteriores de perl, no se garantiza que la versión mínima requerida no se incremente. La versión puede incrementarse por cualquier motivo, y no hay promesa de que se acepten parches para reducir la versión mínima de perl requerida.

ATRIBUTOS

Los siguientes atributos pueden pasarse al constructor:

"hosts": un arrayref de nombres de host a intentar, en orden; por defecto es un array de un solo elemento que contiene "localhost"
Se puede proporcionar el atributo "host", en su lugar, que contiene un solo nombre de host.
"ssl": si es 'starttls', usa STARTTLS; si es 'ssl' (o 1), conecta de forma segura; si es 'maybestarttls', usa STARTTLS si está disponible; de lo contrario, no hay seguridad
"ssl_options": se pasa al constructor de Net::SMTP para conexiones 'ssl' o a starttls para conexiones 'starttls' o 'maybestarttls'; debe contener opciones adicionales para IO::Socket::SSL
"port": puerto al que conectar; por defecto es 25 para no SSL, 465 para 'ssl', 587 para 'starttls'
"timeout": tiempo máximo en segundos para esperar al servidor; el valor por defecto es 120
"sasl_username": el nombre de usuario a utilizar para la autenticación; opcional
"sasl_password": la contraseña a utilizar para la autenticación; requerida si se proporciona "sasl_username"
"sasl_authenticator": una instancia de "Authen::SASL" para usar en la autenticación; opcional
Los atributos "sasl_authenticator" y "sasl_username" son mutuamente excluyentes.
"allow_partial_success": si es verdadero, enviará datos incluso si algunos destinatarios fueron rechazados; por defecto es falso
"helo": qué decir al decir HELO; sin valor por defecto
"localaddr": dirección local desde la que conectarse
"localport": puerto local desde el que conectarse
"debug": si es verdadero, pon el objeto Net::SMTP en modo de depuración

ÉXITO PARCIAL

Si se estableció "allow_partial_success" al crear el transporte, el transporte puede devolver objetos Email::Sender::Success::Partial. Consulte la documentación de ese módulo.
