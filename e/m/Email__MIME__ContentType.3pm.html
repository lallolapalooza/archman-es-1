Email__MIME__ContentType(3pm)

Paquete: perl-email-mime-contenttype

Licencias: GPL, PerlArtistic

Email::MIME::ContentType(3) Documentación de Perl aportada por el usuario Email::MIME::ContentType(3)

NOMBRE

Email::MIME::ContentType - Analiza y construye una cabecera MIME Content-Type o Content-Disposition

VERSIÓN

versión 1.028

SINOPSIS

use Email::MIME::ContentType;
# Content-Type: text/plain; charset="us-ascii"; format=flowed
my $ct = 'text/plain; charset="us-ascii"; format=flowed';
my $data = parse_content_type($ct);
$data = {
  type       => "text",
  subtype    => "plain",
  attributes => {
    charset => "us-ascii",
    format  => "flowed"
  }
};
my $ct_new = build_content_type($data);
# text/plain; charset=us-ascii; format=flowed
# Content-Type: application/x-stuff;
#  title*0*=us-ascii'en'This%20is%20even%20more%20;
#  title*1*=%2A%2A%2Afun%2A%2A%2A%20;
#  title*2="isn't it!"
my $ct = q(application/x-stuff;
 title*0*=us-ascii'en'This%20is%20even%20more%20;
 title*1*=%2A%2A%2Afun%2A%2A%2A%20;
 title*2="isn't it!");
my $data = parse_content_type($ct);
$data = {
  type       => "application",
  subtype    => "x-stuff",
  attributes => {
    title => "This is even more ***fun*** isn't it!"
  }
};
# Content-Disposition: attachment; filename=genome.jpeg;
#   modification-date="Wed, 12 Feb 1997 16:29:51 -0500"
my $cd = q(attachment; filename=genome.jpeg;
  modification-date="Wed, 12 Feb 1997 16:29:51 -0500");
my $data = parse_content_disposition($cd);
$data = {
  type       => "attachment",
  attributes => {
    filename            => "genome.jpeg",
    "modification-date" => "Wed, 12 Feb 1997 16:29:51 -0500"
  }
};
my $cd_new = build_content_disposition($data);
# attachment; filename=genome.jpeg; modification-date="Wed, 12 Feb 1997 16:29:51 -0500"

FUNCIONES

parse_content_type

Esta rutina se exporta por defecto.

Esta rutina analiza las cabeceras de tipo de contenido del correo electrónico según la sección 5.1 de RFC 2045 y también RFC 2231 (Conjuntos de caracteres y continuaciones de parámetros). Devuelve un hash como el anterior, con entradas para "type", el "subtype", y un hash de "attributes".

Por compatibilidad con un malentendido realmente desafortunado de RFC 2045 por parte de los primeros implementadores de este módulo, "discrete" y "composite" también están presentes en el hashref devuelto, con los valores de "type" y "subtype" respectivamente.

parse_content_disposition

Esta rutina se exporta por defecto.

Esta rutina analiza las cabeceras Content-Disposition del correo electrónico según RFC 2183 y RFC 2231. Devuelve un hash como el anterior, con entradas para "type", y un hash de "attributes".

build_content_type

Esta rutina se exporta por defecto.

Esta rutina construye la cabecera Content-Type del correo electrónico según RFC 2045 y RFC 2231. Toma un hash como el anterior, con entradas para "type", el "subtype", y opcionalmente también un hash de "attributes". Devuelve una cadena que representa la cabecera Content-Type. Los atributos no ASCII se codifican a UTF-8 según la sección de Conjunto de caracteres de RFC 2231. Un atributo que tenga más de 78 caracteres ASCII se divide en más atributos según las Continuaciones de parámetros de RFC 2231.

Por razones de compatibilidad con clientes que no soportan RFC 2231, la cadena de salida también contiene una versión ASCII truncada de cualquier atributo demasiado largo o no ASCII. La codificación a ASCII se realiza mediante el módulo Text::Unidecode. Este comportamiento puede causar confusión en implementaciones MIME compatibles con 2231, y puede deshabilitarse estableciendo $Email::MIME::ContentType::STRICT a un valor verdadero.

build_content_disposition

Esta rutina se exporta por defecto.

Esta rutina construye la cabecera Content-Disposition del correo electrónico según RFC 2182 y RFC 2231. Toma un hash como el anterior, con entradas para "type", y opcionalmente también un hash de "attributes". Devuelve una cadena que representa la cabecera Content-Disposition. Los atributos no ASCII o demasiado largos se manejan de la misma manera que en la función build_content_type.

ADVERTENCIAS

Esta no es una cabecera content-type válida, según RFC 1521 y RFC 2045:

Content-Type: type/subtype;

Si aparece un punto y coma, debe haber un parámetro. "parse_content_type" emitirá un aviso si encuentra una cabecera de este tipo, pero puede suprimirlo estableciendo $Email::MIME::ContentType::STRICT_PARAMS a un valor falso. ¡Por favor, considere localizar esta asignación!

Lo mismo se aplica a "parse_content_disposition".
