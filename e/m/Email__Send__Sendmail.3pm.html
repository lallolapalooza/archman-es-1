NOMBRE

Email::Send::Sendmail - Enviar mensajes usando sendmail

SINOPSIS

use Email::Send;
Email::Send->new({mailer => 'Sendmail'})->send($message);

DESCRIPCIÓN

Este remitente para "Email::Send" usa "sendmail" para enviar un mensaje. *No* intenta encontrar el ejecutable de forma exhaustiva. Simplemente llama a "sendmail" y espera que esté en tu ruta. Si no es así, o si quieres definir explícitamente la ubicación de tu ejecutable, modifica la variable de paquete $Email::Send::Sendmail::SENDMAIL.

$Email::Send::Sendmail::SENDMAIL = '/usr/sbin/sendmail';
