emacsclient(1)

Paquete: emacs

Licencias: GPL3

EMACSCLIENT(1) GNU EMACSCLIENT(1)

NOMBRE

emacsclient - indica a un Emacs en ejecución que visite un archivo

SINOPSIS

emacsclient [opciones] archivos ...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando emacsclient. La documentación completa está disponible en formato GNU Info; véase más abajo.

emacsclient funciona en conjunción con el servidor Emacs incorporado.

Puedes llamar a emacsclient directamente o permitir que otros programas lo ejecuten cuando sea necesario. En sistemas GNU y Unix, muchos programas consultan la variable de entorno EDITOR (a veces también VISUAL) para obtener el comando utilizado para editar. Por lo tanto, configurar esta variable de entorno a 'emacsclient' permitirá que estos programas utilicen un Emacs ya en ejecución para editar. Otros sistemas operativos pueden tener sus propios métodos para definir el editor predeterminado.

Para que emacsclient funcione, necesitas un Emacs ya en ejecución con un servidor. Dentro de Emacs, llama a las funciones "server-start" o "server-mode". (Tu archivo ".emacs" puede hacer esto automáticamente si le añades "(server-start)" o "(server-mode 1)".)

Cuando hayas terminado de editar el búfer, escribe "C-x #" ("server-edit"). Esto guarda el archivo y envía un mensaje de vuelta al programa emacsclient indicándole que salga. Los programas que usan EDITOR esperan a que el "editor" (en realidad, emacsclient) salga. "C-x #" también comprueba otras solicitudes externas pendientes para editar diversos archivos y selecciona el siguiente archivo.

Si configuras la variable "server-window" a una ventana o un frame, "C-x #" muestra el búfer del servidor en esa ventana o en ese frame.

OPCIONES

La mayoría de las opciones siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones ("-").

+línea[:columna]
Ve a la línea y columna especificadas. Una columna faltante se trata como columna 1. Esta opción solo se aplica al siguiente archivo especificado.
-a, --alternate-editor=COMANDO
Si el servidor Emacs no está en ejecución, ejecuta el comando shell especificado en su lugar. Si se especifica una cadena vacía, ejecuta "emacs --daemon" para iniciar Emacs en modo demonio e intentar conectarse a él.

Consulta también la variable de entorno ALTERNATE_EDITOR, sobre la cual esta opción tiene precedencia.

-c, --create-frame
Crea un nuevo frame en lugar de intentar usar el frame Emacs actual.
-r --reuse-frame
Reutiliza un frame existente si hay uno, de lo contrario crea un nuevo frame.
-F, --frame-parameters=ALIST
Establece los parámetros de un frame recién creado.
-d, --display=PANTALLA
Indica al servidor que muestre los archivos en la pantalla dada.
-e, --eval
No visite archivos, sino que evalúe los argumentos como expresiones Emacs Lisp.
-f, --server-file=NOMBRE_ARCHIVO
Usa el archivo de configuración TCP NOMBRE_ARCHIVO para la comunicación. Los nombres de archivo relativos son relativos a "~/.emacs.d/server/" o "$XDG_CONFIG_HOME/emacs/server/", y el predeterminado es "server".

Consulta también la variable de entorno EMACS_SERVER_FILE, sobre la cual esta opción tiene precedencia.

-n, --no-wait
Regresa inmediatamente sin esperar a que "termines" el búfer en Emacs. Si se combina con --eval, esta opción se ignora.
-w, --timeout=N
Cuánto tiempo esperar, en segundos, a que Emacs responda antes de darse por vencido. El valor predeterminado es 0, lo que significa esperar eternamente.
--parent-id=ID
Abre un frame de emacsclient como un frame cliente en la ventana X padre con id ID.
-q, --quiet
No permitas que emacsclient muestre mensajes sobre la espera de Emacs o la conexión a sockets de servidor remotos.
-u, --suppress-output
No permitas que emacsclient muestre los resultados devueltos desde el servidor. Útil principalmente en combinación con --eval cuando la evaluación realizada es para efectos secundarios en lugar de resultados.
-s, --socket-name=NOMBRE_ARCHIVO
Usa el socket llamado NOMBRE_ARCHIVO para la comunicación. Los nombres de archivo relativos son relativos a "$XDG_RUNTIME_DIR/emacs/" o "$TMPDIR/".

Consulta también la variable de entorno EMACS_SOCKET_NAME, sobre la cual esta opción tiene precedencia.

-nw, -t, --tty, --no-window-system
Abre un nuevo frame Emacs en el terminal actual.
-T, --tramp=PREFIJO
Establece PREFIJO para añadir a los nombres de archivo para que Emacs localice archivos en máquinas remotas usando TRAMP. Esto es útil principalmente en combinación con el uso del servidor Emacs en un host remoto (ya sea usando TCP con --server-file, o un socket reenviado a través de SSH).

Consulta también la variable de entorno EMACSCLIENT_TRAMP, sobre la cual esta opción tiene precedencia.

-V, --version
Imprime la información de la versión y sale.
-H, --help
Imprime este mensaje de información de uso y sale.

ESTADO DE SALIDA

Normalmente, el estado de salida es 0. Si emacsclient se apaga debido a que Emacs señala un error, el estado de salida es 1.

ENTORNO

ALTERNATE_EDITOR
Si el servidor Emacs no está en ejecución, ejecuta el comando shell en esta variable de entorno en su lugar. Si se establece en una cadena vacía, ejecuta "emacs --daemon" para iniciar Emacs en modo demonio y tratar de conectarse a él. Será anulado por la opción --alternate-editor, si está presente.
EMACSCLIENT_TRAMP
Un prefijo para añadir a los nombres de archivo, destinado a permitir que Emacs localice archivos en máquinas remotas usando TRAMP. Será anulado por la opción --tramp, si está presente.
EMACS_SERVER_FILE
Busca en este archivo para descubrir dónde encontrar un servidor Emacs TCP. Los nombres de archivo relativos son relativos a "~/.emacs.d/server/" o "$XDG_CONFIG_HOME/emacs/server/", y el predeterminado es "server". Será anulado por la opción --server-file, si está presente.
EMACS_SOCKET_NAME
El nombre del archivo del socket a usar para la comunicación con el servidor Emacs. Los nombres de archivo relativos son relativos a "$XDG_RUNTIME_DIR/emacs/" o "$TMPDIR/". Será anulado por la opción --socket-name, si está presente.

VER TAMBIÉN

Las variables de entorno XDG se describen en detalle en la Especificación de Directorios Base XDG.
