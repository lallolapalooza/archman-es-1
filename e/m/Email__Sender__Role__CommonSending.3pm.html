NOMBRE

Email::Sender::Role::CommonSending - las tareas comunes de envío que la mayoría de las clases de Email::Sender necesitarán

VERSIÓN

versión 2.601

DESCRIPCIÓN

Email::Sender::Role::CommonSending proporciona una serie de características que facilitarán la escritura de nuevas clases que realicen el rol de Email::Sender. En lugar de escribir un método "send", los implementadores deberán escribir un método más pequeño "send_email", al que se le pasará un objeto Email::Abstract y un sobre que contenga entradas de "from" y "to". Se garantizará que la entrada "to" sea un array.

También se proporcionará un método "success" como atajo para llamar a:

Email::Sender::Success->new(...);

Algunos otros detalles menores son manejados por CommonSending; para más información, consulte el código fuente.

Los métodos documentados aquí pueden ser sobrescritos para alterar el comportamiento del rol de CommonSending.

MÉTODOS

prepare_email

A este método se le pasa un escalar y se espera que devuelva un objeto Email::Abstract. Probablemente no deberías sobrescribirlo en la mayoría de los casos.

prepare_envelope

A este método se le pasa un hashref y devuelve un nuevo hashref que debería usarse como el sobre pasado al método "send_email". Este método es responsable de asegurar que la entrada *to* sea un array.

success

...
return $self->success;

Este método devuelve un nuevo objeto Email::Sender::Success. Los argumentos pasados a este método se pasan al constructor de Success. Esto se proporciona como una conveniencia para devolver éxito desde los métodos "send_email" de las subclases.
