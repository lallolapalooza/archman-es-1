Email::Date::Format(3) Documentación Perl contribuida por el usuario Email::Date::Format(3)

NOMBRE

Email::Date::Format - produce cadenas de fecha RFC 2822

VERSIÓN

versión 1.008

SINOPSIS

use Email::Date::Format qw(email_date);
my $header = email_date($date->epoch);
Email::Simple->create(
  header => [
    Date => $header,
  ],
  body => '...',
);

DESCRIPCIÓN

Este módulo proporciona un medio sencillo para generar una cadena de fecha y hora compatible con RFC 2822. (Por si te importa, no son fechas RFC 822, ya que usan un año de cuatro dígitos, lo cual no está permitido en RFC 822).

VERSIÓN DE PERL

Esta biblioteca debería funcionar en versiones de Perl publicadas incluso hace mucho tiempo. Debería funcionar en cualquier versión de Perl publicada en los últimos cinco años.

FUNCIONES

email_date

my $date = email_date; # ahora
my $date = email_date( time - 60*60 ); # hace una hora

"email_date" acepta un valor de época, como el devuelto por "time". Devuelve una cadena que representa la fecha y hora de la entrada, según lo especificado en RFC 2822. Si no se proporciona ningún valor de entrada, se utiliza el valor actual de "time".

"email_date" solo se exporta si se solicita.

email_gmdate

my $date = email_gmdate;

"email_gmdate" es idéntico a "email_date", pero devolverá una cadena que indica la hora en Tiempo Medio de Greenwich (GMT), en lugar de la hora local.

"email_gmdate" solo se exporta si se solicita.
