EVP_KEYEXCH_free(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_KEYEXCH_FREE(3ssl) OpenSSL EVP_KEYEXCH_FREE(3ssl)

NOMBRE

EVP_KEYEXCH_fetch, EVP_KEYEXCH_free, EVP_KEYEXCH_up_ref, EVP_KEYEXCH_get0_provider, EVP_KEYEXCH_is_a, EVP_KEYEXCH_do_all_provided, EVP_KEYEXCH_names_do_all, EVP_KEYEXCH_get0_name, EVP_KEYEXCH_get0_description, EVP_KEYEXCH_gettable_ctx_params, EVP_KEYEXCH_settable_ctx_params - Funciones para gestionar objetos de algoritmo EVP_KEYEXCH

SINOPSIS

#include <openssl/evp.h>
EVP_KEYEXCH *EVP_KEYEXCH_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                               const char *properties);
void EVP_KEYEXCH_free(EVP_KEYEXCH *exchange);
int EVP_KEYEXCH_up_ref(EVP_KEYEXCH *exchange);
OSSL_PROVIDER *EVP_KEYEXCH_get0_provider(const EVP_KEYEXCH *exchange);
int EVP_KEYEXCH_is_a(const EVP_KEYEXCH *exchange, const char *name);
const char *EVP_KEYEXCH_get0_name(const EVP_KEYEXCH *exchange);
void EVP_KEYEXCH_do_all_provided(OSSL_LIB_CTX *libctx,
                                 void (*fn)(EVP_KEYEXCH *exchange, void *arg),
                                 void *arg);
int EVP_KEYEXCH_names_do_all(const EVP_KEYEXCH *exchange,
                             void (*fn)(const char *name, void *data),
                             void *data);
const char *EVP_KEYEXCH_get0_description(const EVP_KEYEXCH *keyexch);
const OSSL_PARAM *EVP_KEYEXCH_gettable_ctx_params(const EVP_KEYEXCH *keyexch);
const OSSL_PARAM *EVP_KEYEXCH_settable_ctx_params(const EVP_KEYEXCH *keyexch);

DESCRIPCIÓN

EVP_KEYEXCH_fetch() obtiene la implementación de intercambio de claves para el algorithm dado de cualquier proveedor que lo ofrezca, dentro de los criterios dados por las properties. Vea "ALGORITHM FETCHING" en crypto(7) para más información.

El valor devuelto debe ser liberado eventualmente con EVP_KEYEXCH_free().

EVP_KEYEXCH_free() decrementa el contador de referencias para la estructura EVP_KEYEXCH. Típicamente esta estructura habrá sido obtenida de una llamada anterior a EVP_KEYEXCH_fetch(). Si el contador de referencias cae a 0, la estructura es liberada. Si el argumento es NULL, no se hace nada.

EVP_KEYEXCH_up_ref() incrementa el contador de referencias para una estructura EVP_KEYEXCH.

EVP_KEYEXCH_get0_provider() devuelve el proveedor desde el que se obtuvo exchange.

EVP_KEYEXCH_is_a() comprueba si exchange es una implementación de un algoritmo identificable con name.

EVP_KEYEXCH_get0_name() devuelve el nombre del algoritmo de la implementación proporcionada para el exchange dado. Tenga en cuenta que el exchange puede tener varios sinónimos asociados. En este caso, se devuelve el primer nombre de la definición del algoritmo. La propiedad del cadena devuelta la conserva el objeto exchange y no debe ser liberada por el llamador.

EVP_KEYEXCH_names_do_all() recorre todos los nombres del exchange, y llama a fn con cada nombre y data.

EVP_KEYEXCH_get0_description() devuelve una descripción del keyexch, destinada a ser mostrada y para consumo humano. La descripción queda a discreción de la implementación del keyexch.

EVP_KEYEXCH_do_all_provided() recorre todas las implementaciones de intercambio de claves de todos los proveedores activados en el contexto de biblioteca libctx, y para cada una de las implementaciones, llama a fn con el método de implementación y data como argumentos.

EVP_KEYEXCH_gettable_ctx_params() y EVP_KEYEXCH_settable_ctx_params() devuelven una matriz constante de OSSL_PARAM(3) que describe los nombres y tipos de parámetros clave que se pueden obtener o establecer mediante un algoritmo de intercambio de claves utilizando EVP_PKEY_CTX_get_params(3) y EVP_PKEY_CTX_set_params(3).

VALORES DEVUELTOS

EVP_KEYEXCH_fetch() devuelve un puntero a un EVP_KEYEXCH en caso de éxito o NULL en caso de fallo.

EVP_KEYEXCH_up_ref() devuelve 1 en caso de éxito o 0 en caso contrario.

EVP_KEYEXCH_names_do_all() devuelve 1 si la función de retrollamada se llamó para todos los nombres. Un valor de retorno de 0 significa que la función de retrollamada no se llamó para ningún nombre.

EVP_KEYEXCH_is_a() devuelve 1 si exchange era identificable, de lo contrario 0.

EVP_KEYEXCH_gettable_ctx_params() y EVP_KEYEXCH_settable_ctx_params() devuelven una matriz constante de OSSL_PARAM(3) o NULL en caso de error.

VER TAMBIÉN

"ALGORITHM FETCHING" en crypto(7), OSSL_PROVIDER(3)
