NOMBRE

EVP_KDF-PBKDF1 - La implementación EVP_KDF de PBKDF1

DESCRIPCIÓN

Soporte para calcular la función de derivación de claves basada en contraseñas PBKDF1 a través de la API EVP_KDF.

El algoritmo EVP_KDF-PBKDF1 implementa la función de derivación de claves basada en contraseñas PBKDF1, según se describe en RFC 8018; deriva una clave de una contraseña usando una sal y un recuento de iteraciones.

Identidad

"PBKDF1" es el nombre de esta implementación; puede usarse con la función EVP_KDF_fetch().

Parámetros admitidos

Los parámetros admitidos son:

"pass" (OSSL_KDF_PARAM_PASSWORD) <cadena de octetos>
"salt" (OSSL_KDF_PARAM_SALT) <cadena de octetos>
"iter" (OSSL_KDF_PARAM_ITER) <entero sin signo>
Este parámetro tiene un valor predeterminado de 0 y debe establecerse.
"properties" (OSSL_KDF_PARAM_PROPERTIES) <cadena UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <cadena UTF8>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_KDF(3).

NOTAS

Una aplicación típica de este algoritmo es derivar material de clave para un algoritmo de cifrado a partir de una contraseña en "pass", una sal en "salt", y un recuento de iteraciones.

Aumentar el parámetro "iter" ralentiza el algoritmo, lo que dificulta que un atacante realice un ataque de fuerza bruta utilizando un gran número de contraseñas candidatas.

No se hace ninguna suposición con respecto a la contraseña proporcionada; simplemente se trata como una secuencia de bytes.

El proveedor heredado debe estar disponible para poder acceder a este algoritmo.

CONFORME A
