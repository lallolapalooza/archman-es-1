DESCRIPCIÓ

N

A veces la generación de claves es sencilla: basta con generar los números de la clave y listo. Sin embargo, hay ciertos tipos de clave que necesitan parámetros de clave, a menudo llamados parámetros de dominio pero no necesariamente limitados a eso, que también deben ser generados. Además de esto, el llamante puede querer establecer parámetros de generación proporcionados por el usuario que afecten aún más a la generación de parámetros de clave o de clave, como el tamaño de clave

deseado.

Para permitir flexiblemente todo lo que se ha descrito, la generación de parámetros de clave y de clave se divide en una inicialización de un contexto de algoritmo de clave, funciones para establecer parámetros proporcionados por el usuario, y finalmente la función de generación de parámetros de clave o de clave en

sí.

El contexto del algoritmo de clave debe ser creado usando EVP_PKEY_CTX_new(3) o variantes de la misma, vea ese manual para

detalles.

EVP_PKEY_keygen_init() inicializa un contexto de algoritmo de clave pública ctx para una operación de generación de

clave.

EVP_PKEY_paramgen_init() es similar a EVP_PKEY_keygen_init() excepto que se generan parámetros de

clave.

Después de la inicialización, los parámetros de generación pueden proporcionarse con EVP_PKEY_CTX_ctrl(3) o EVP_PKEY_CTX_set_params(3), o cualquier otra función descrita en esos

manuales.

EVP_PKEY_generate() realiza la operación de generación, los parámetros de clave resultantes o la clave se escriben en *ppkey. Si *ppkey es NULL cuando se llama a esta función, se asignará, y debe ser liberada por el llamante cuando ya no sea útil, usando EVP_PKEY_fr

ee(3).

EVP_PKEY_paramgen() y EVP_PKEY_keygen() hacen exactamente lo mismo que EVP_PKEY_generate(), después de comprobar que la correspondiente EVP_PKEY_paramgen_init() o EVP_PKEY_keygen_init() se usó para inicializar ctx. Estas son funciones más antiguas que se mantienen por compatibilidad con versiones anteriores. Es seguro usar EVP_PKEY_generate() en su

lugar.

La función EVP_PKEY_set_cb() establece el callback de generación de clave o de parámetro a cb. La función EVP_PKEY_CTX_get_cb() devuelve el callback de generación de clave o de

parámetro.

La función EVP_PKEY_CTX_get_keygen_info() devuelve parámetros asociados con la operación de generación. Si idx es -1, se devuelve el número total de parámetros disponibles. Cualquier valor no negativo devuelve el valor de ese parámetro. EVP_PKEY_CTX_gen_keygen_info() con un valor no negativo para idx solo debe llamarse dentro del callback de

generación.

Si el callback devuelve 0, la operación de generación de clave se aborta y se produce un error. Esto puede ocurrir durante una operación que consume tiempo donde un usuario hace clic en un botón de

"cancelar".

Las funciones EVP_PKEY_CTX_set_app_data() y EVP_PKEY_CTX_get_app_data() establecen y recuperan un puntero opaco. Esto se puede usar para establecer algún valor definido por la aplicación que se puede recuperar en el callback: por ejemplo, un manejador que se usa para actualizar un "diálogo de

progreso".

EVP_PKEY_Q_keygen() abstrae del uso explícito de EVP_PKEY_CTX mientras proporciona una forma 'rápida' pero limitada de generar un nuevo par de claves asimétricas. Proporciona atajos para casos simples y comunes de generación de claves. Como es habitual, el contexto de la biblioteca libctx y la consulta de propiedades propq pueden darse para obtener algoritmos de proveedores. Si type es "RSA", se debe dar un parámetro size_t para especificar el tamaño de la clave RSA. Si type es "EC", se debe dar un parámetro de cadena para especificar el nombre de la curva EC. Si type es: "ED25519", "ED448", "SM2", "X25519", "X448", "ML-DSA-44", "ML-DSA-65", "ML-DSA-87", "ML-KEM-512", "ML-KEM-768", o "ML-KEM-1024" no se necesitan más parámetros. Otros tipos de clave pueden ser posibles si son proporcionados por los proveedores cargados. EVP_PKEY_Q_keygen() puede ser utilizable con tales ti

pos de clave siempre que no
requieran más parámetros.

VALORES DE

RETORNO

EVP_PKEY_keygen_init(), EVP_PKEY_paramgen_init(), EVP_PKEY_keygen() y EVP_PKEY_paramgen() devuelven 1 para éxito y 0 o un valor negativo para fallo. En particular, un valor de retorno de -2 indica que la operación no es soportada por el algoritmo de clave

pública.

EVP_PKEY_Q_keygen() devuelve un EVP_PKEY, o NULL en

caso de
fallo.

NOTA

S

Después de la llamada a EVP_PKEY_keygen_init() o EVP_PKEY_paramgen_init() se pueden realizar operaciones de control específicas del algoritmo para establecer cualquier parámetro apropiado para la

operación.

Las funciones EVP_PKEY_keygen() y EVP_PKEY_paramgen() pueden llamarse más de una vez en el mismo contexto si se realizan varias operaciones usando los mismos

parámetros.

El significado de los parámetros pasados al callback dependerá del algoritmo y la implementación específica del algoritmo. Algunos podrían no dar ninguna información útil durante la generación de clave o de parámetro. Otros podrían ni siquiera llamar al

callback.

La operación realizada por la generación de clave o de parámetro depende del algoritmo usado. En algunos casos (p. ej. EC con una curva nombrada proporcionada) la opción "generación" simplemente establece los campos apropiados en una estructura

EVP_PKEY.

En OpenSSL una estructura EVP_PKEY que contiene una clave privada también contiene los componentes y parámetros de l

a clave pública (si los hay). Una clave privada de OpenSSL es equivalente a lo que algunas bibliotecas llaman un "par
de claves". Una clave privada puede usarse en funciones que requieren el uso de una clave pública o parámetros.

EJEMPLO

S

Generar una clave RSA de 2048

bits: 
#include <openssl/evp.h>
#include <openssl/rsa.h>
EVP_PKEY_CTX *ctx;
EVP_PKEY *pkey = NULL;
ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_RSA, NULL);
if (!ctx)
    /* Error occurred */
if (EVP_PKEY_keygen_init(ctx) <= 0)
    /* Error */
if (EVP_PKEY_CTX_set_rsa_keygen_bits(ctx, 2048) <= 0)
    /* Error */
/* Generate key */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
    /* Error
*/

Generar una clave a partir de un conjunto de

parámetros: 
#include <openssl/evp.h>
#include <openssl/rsa.h>
EVP_PKEY_CTX *ctx;
ENGINE *eng;
EVP_PKEY *pkey = NULL, *param;
/* Assumed param, eng are set up already */
ctx = EVP_PKEY_CTX_new(param, eng);
if (!ctx)
    /* Error occurred */
if (EVP_PKEY_keygen_init(ctx) <= 0)
    /* Error */
/* Generate key */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
    /* Error
*/

Ejemplo de callback de generación para implementaciones de clave pública de

OpenSSL: 
/* Application data is a BIO to output status to */
EVP_PKEY_CTX_set_app_data(ctx, status_bio);
static int genpkey_cb(EVP_PKEY_CTX *ctx)
{
    char c = '*';
    BIO *b = EVP_PKEY_CTX_get_app_data(ctx);
    int p = EVP_PKEY_CTX_get_keygen_info(ctx, 0);
    if (p == 0)
        c = '.';
    if (p == 1)
        c = '+';
    if (p == 2)
        c = '*';
    if (p == 3)
        c = '\n';
    BIO_write(b, &c, 1);
    (void)BIO_flush(b);
    return 1;
}
