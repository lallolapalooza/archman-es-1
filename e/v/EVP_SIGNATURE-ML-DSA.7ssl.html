EVP_SIGNATURE-ML-DSA(7ssl) OpenSSL EVP_SIGNATURE-ML-DSA(7ssl)

NOMBRE

EVP_SIGNATURE-ML-DSA, EVP_SIGNATURE-ML-DSA-44, EVP_SIGNATURE-ML-DSA-65, EVP_SIGNATURE-ML-DSA-87, - Soporte de EVP_SIGNATURE ML-DSA

DESCRIPCIÓN

Las ML-DSA-44, ML-DSA-65 y ML-DSA-87 implementaciones EVP_PKEY admiten la generación de claves, y la firma y verificación de un solo paso (one-shot) utilizando los esquemas de firma ML-DSA descritos en FIPS 204 https://csrc.nist.gov/pubs/fips/204/final.

Los diferentes nombres de algoritmo corresponden a los conjuntos de parámetros definidos en FIPS 204 https://csrc.nist.gov/pubs/fips/204/final Sección 4 Tabla 1. (Las firmas varían en tamaño desde ~2.5K hasta ~4.5K dependiendo del tipo elegido). Hay 3 categorías de seguridad diferentes también dependiendo del tipo.

EVP_SIGNATURE_fetch(3) puede usarse para obtener explícitamente uno de los 3 algoritmos, que luego puede usarse con EVP_PKEY_sign_message_init(3), EVP_PKEY_sign(3), EVP_PKEY_verify_message_init(3), y EVP_PKEY_verify(3) para realizar la firma de un mensaje de un solo paso o la verificación de la firma.

El proceso de firma normal (llamado Generación de Firma ML-DSA Pura) codifica el mensaje internamente como 0x00 || len(ctx) || ctx || mensaje. donde ctx es algún valor opcional de tamaño 0x00..0xFF. Este proceso está definido en FIPS 204 https://csrc.nist.gov/pubs/fips/204/final Algoritmo 2 paso 10 y Algoritmo 3 paso 5. OpenSSL también permite que el mensaje no sea codificado, lo cual es necesario para las pruebas. OpenSSL no soporta la Generación de Firma ML-DSA Pre-Hash, pero esto puede ser hecho por el usuario realizando la codificación Pre-Hash externamente y luego eligiendo la opción de no codificar el mensaje.

Parámetros de Firma ML-DSA

El siguiente parámetro puede usarse tanto para la firma como para la verificación. Puede establecerse pasando un array OSSL_PARAM a EVP_PKEY_sign_message_init(3) o EVP_PKEY_verify_message_init(3)

"context-string" (OSSL_SIGNATURE_PARAM_CONTEXT_STRING) <cadena de octetos>
Una cadena de octetos con longitud máxima de 255. Por defecto es la cadena vacía.

Los siguientes parámetros pueden usarse al firmar: Pueden establecerse pasando un array OSSL_PARAM a EVP_PKEY_sign_init_ex2(3).

"message-encoding" (OSSL_SIGNATURE_PARAM_MESSAGE_ENCODING) <entero>
El valor por defecto de 1 usa 'Generación de Firma ML-DSA Pura' como se describió anteriormente. Establecerlo en 0 no codifica el mensaje, lo cual se usa para las pruebas. Los pasos de codificación del mensaje están definidos en FIPS 204 https://csrc.nist.gov/pubs/fips/204/final Algoritmo 2 paso 10 y Algoritmo 3 paso 5.
"test-entropy" (OSSL_SIGNATURE_PARAM_TEST_ENTROPY) <cadena de octetos>
Usado para pruebas para pasar un valor aleatorio determinista opcional por mensaje. Si se establece, el tamaño debe ser de 32 bytes.
"deterministic" (OSSL_SIGNATURE_PARAM_DETERMINISTIC) <entero>
El valor por defecto de 0 hace que la aleatoriedad por mensaje sea generada aleatoriamente usando un DRBG. Establecerlo en 1 hace que la aleatoriedad por mensaje sea establecida en 32 bytes de ceros. Este valor se ignora si "test-entropy" está establecido.
"mu" (OSSL_SIGNATURE_PARAM_MU) <entero>
El valor por defecto de 0 hace que las operaciones de firma y verificación procesen un mensaje en bruto. Establecerlo en 1 hace que esas operaciones asuman que la entrada es el valor "mu" de FIPS 204 https://csrc.nist.gov/pubs/fips/204/final Algoritmo 7 paso 6 y Algoritmo 8 paso 7.

Tenga en cuenta que los pasos de codificación del mensaje de FIPS 204 https://csrc.nist.gov/pubs/fips/204/final Algoritmo 2 paso 10 y Algoritmo 3 paso 5 se omiten cuando esta configuración es 1.

Vea EVP_PKEY-ML-DSA(7) para información relacionada con las claves ML-DSA .

NOTAS

Por razones de compatibilidad hacia atrás, EVP_DigestSignInit_ex(), EVP_DigestSign(), EVP_DigestVerifyInit_ex() y EVP_DigestVerify() también pueden usarse, pero el resumen (digest) pasado en mdname debe ser NULL.

EJEMPLOS

Para firmar un mensaje usando una estructura EVP_PKEY ML-DSA:

void do_sign(EVP_PKEY *key, unsigned char *msg, size_t msg_len)
{
    size_t sig_len;
    unsigned char *sig = NULL;
    const OSSL_PARAM params[] = {
        OSSL_PARAM_octet_string("context-string", (unsigned char *)"A context string", 16),
        OSSL_PARAM_END
    };
    EVP_PKEY_CTX *sctx = EVP_PKEY_CTX_new_from_pkey(NULL, pkey, NULL);
    EVP_SIGNATURE *sig_alg = EVP_SIGNATURE_fetch(NULL, "ML-DSA-65", NULL);
    EVP_PKEY_sign_message_init(sctx, sig_alg, params);
    /* Calcular el tamaño requerido para la firma pasando un buffer NULL. */
    EVP_PKEY_sign(sctx, NULL, &sig_len, msg, msg_len);
    sig = OPENSSL_zalloc(sig_len);
    EVP_PKEY_sign(sctx, sig, &sig_len, msg, msg_len);
    ...
    OPENSSL_free(sig);
    EVP_SIGNATURE_free(sig_alg);
    EVP_PKEY_CTX_free(sctx);
}
