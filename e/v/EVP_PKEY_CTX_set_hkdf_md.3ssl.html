DESCRIPCIÓ

N

El algoritmo EVP_PKEY_HKDF implementa la función de derivación de claves HKDF. HKDF sigue el paradigma "extraer-luego-expandir", donde la KDF lógicamente consta de dos módulos. La primera etapa toma el material de clave de entrada y "extrae" de él una clave pseudoaleatoria de longitud fija K. La segunda etapa "expande" la clave K en varias claves pseudoaleatorias adicionales (la salida de la KDF)

.

EVP_PKEY_CTX_set_hkdf_mode() establece el modo para la operación HKDF. Hay tres modos definidos

actualmente:
EVP_PKEY_HKDEF_MODE_EXTRACT_AND_EXP
AND
Este es el modo predeterminado. Llamar a EVP_PKEY_derive(3) en un EVP_PKEY_CTX configurado para HKDF realizará una operación de extracción seguida de expansión de una sola vez. La clave derivada devuelta será el resultado después de la operación de expansión. La clave pseudoaleatoria intermedia de longitud fija K no se devuelve.

En este modo, los valores de resumen, clave,

sal y info deben establecerse antes
de derivar una clave o se producirá un error.
EVP_PKEY_HKDEF_MODE_EXTRACT_O
NLY
En este modo, llamar a EVP_PKEY_derive(3) solo realizará la operación de extracción. El valor devuelto será la clave pseudoaleatoria intermedia de longitud fija K.

Los valores de resumen, clave y sal de

ben establecerse antes de deri
var una clave o se producirá un error.
EVP_PKEY_HKDEF_MODE_EXPAND_O
NLY
En este modo, llamar a EVP_PKEY_derive(3) solo realizará la operación de expansión. La clave de entrada debe establecerse como la clave pseudoaleatoria intermedia de longitud fija K devuelta por una operación de extracción anterior.

Los valores de resumen, clave

e info deben establecerse an
tes de derivar una c
lave o se producirá un error.

EVP_PKEY_CTX_set_hkdf_md() establece el resumen de mensaje asociado con

HKDF.

EVP_PKEY_CTX_set1_hkdf_salt() establece la sal a saltlen bytes del búfer salt. Cualquier valor existente es

reemplazado.

EVP_PKEY_CTX_set1_hkdf_key() establece la clave a keylen bytes del búfer key. Cualquier valor existente es

reemplazado.

EVP_PKEY_CTX_add1_hkdf_info() establece el valor de info a infolen bytes del búfer info. Si ya hay un valor establecid

o, se añade a

CONTROLES DE

CADENA

HKDF también soporta operaciones de control basadas en cadenas a través de EVP_PKEY_CTX_ctrl_str(3). El parámetro de tipo "md" usa el valor proporcionado como el nombre del algoritmo de resumen a usar. El parámetro de tipo "mode" usa los valores "EXTRACT_AND_EXPAND", "EXTRACT_ONLY" y "EXPAND_ONLY" para determinar el modo a usar. Los parámetros de tipo "salt", "key" y "info" usan el parámetro valor proporcionado como un valor de semilla, clave o info. Los nombres "hexsalt", "hexkey" y "hexinfo" son similares

excepto que toman una cadena hexadeci
mal que es convertida a binario.

NOTA

S

Se puede obtener un contexto para HKDF llamando

a: 
EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_HKDF, NULL)
;

La longitud total del búfer de info no puede exceder 2048 bytes: esto debería ser más que suficiente para cualquier uso normal de

HKDF.

La longitud de salida de una operación de expansión HKDF se especifica a través del parámetro length de la función EVP_PKEY_derive(3). Dado que la longitud de salida de HKDF es variable, pasar un búfer NULL como medio para obtener la longitud requerida no es significativo con HKDF en ningún modo que realice una operación de expansión. En su lugar, el llamador debe asignar un búfer de la longitud deseada y pasar ese búfer a EVP_PKEY_derive(3) junto con (un puntero inicializado a) la longitud deseada. Se permite pasar un búfer NULL para obtener la longitud cuando se usa EVP_PKEY_HKDEF_MODE_EXTRACT_ONLY

.

Se pueden implementar

versiones optimizadas
de HKDF en un ENGINE.

VALORES DE

RETORNO

Todas estas funciones devuelven 1 en caso de éxito y 0 o un valor ne

gativo en caso de fallo. En particular, un valor de retorno de -2 in
dica que la operación no es soportada por el algoritmo de clave pública.

S

Este ejemplo deriva 10 bytes usando SHA-256 con la clave secreta "secret", el valor de sal "salt" y el valor de info

"label":

unsigned char out[10];
size_t outlen = sizeof(out);
pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_HKDF, NULL);
if (EVP_PKEY_derive_init(pctx) <= 0)
    /* Error */
if (EVP_PKEY_CTX_set_hkdf_md(pctx, EVP_sha256()) <= 0) /* Error */ if (EVP_PKEY_CTX_set1_hkdf_salt(pctx, "salt", 4) <= 0) /* Error */ if (EVP_PKEY_CTX_set1_hkdf_key(
pctx, "secret", 6) <= 0) /* Error */ if (EVP_PKEY_CTX_add1_hkdf_info(pctx, "label", 5) <= 0) /* Error */ if (EVP_PKEY_derive(pctx, out, &outlen) <= 0) /* Error */
