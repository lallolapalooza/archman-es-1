EVP_SIGNATURE(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_SIGNATURE(3ssl) OpenSSL EVP_SIGNATURE(3ssl)

NOMBRE

EVP_SIGNATURE, EVP_SIGNATURE_fetch, EVP_SIGNATURE_free, EVP_SIGNATURE_up_ref, EVP_SIGNATURE_is_a, EVP_SIGNATURE_get0_provider, EVP_SIGNATURE_do_all_provided, EVP_SIGNATURE_names_do_all, EVP_SIGNATURE_get0_name, EVP_SIGNATURE_get0_description, EVP_SIGNATURE_gettable_ctx_params, EVP_SIGNATURE_settable_ctx_params - Funciones para gestionar objetos de algoritmo EVP_SIGNATURE

SINOPSIS

#include <openssl/evp.h>
typedef struct evp_signature_st EVP_SIGNATURE;
EVP_SIGNATURE *EVP_SIGNATURE_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                                   const char *properties);
void EVP_SIGNATURE_free(EVP_SIGNATURE *signature);
int EVP_SIGNATURE_up_ref(EVP_SIGNATURE *signature);
const char *EVP_SIGNATURE_get0_name(const EVP_SIGNATURE *signature);
int EVP_SIGNATURE_is_a(const EVP_SIGNATURE *signature, const char *name);
OSSL_PROVIDER *EVP_SIGNATURE_get0_provider(const EVP_SIGNATURE *signature);
void EVP_SIGNATURE_do_all_provided(OSSL_LIB_CTX *libctx,
                                   void (*fn)(EVP_SIGNATURE *signature,
                                              void *arg),
                                   void *arg);
int EVP_SIGNATURE_names_do_all(const EVP_SIGNATURE *signature,
                               void (*fn)(const char *name, void *data),
                               void *data);
const char *EVP_SIGNATURE_get0_name(const EVP_SIGNATURE *signature);
const char *EVP_SIGNATURE_get0_description(const EVP_SIGNATURE *signature);
const OSSL_PARAM *EVP_SIGNATURE_gettable_ctx_params(const EVP_SIGNATURE *sig);
const OSSL_PARAM *EVP_SIGNATURE_settable_ctx_params(const EVP_SIGNATURE *sig);

DESCRIPCIÓN

EVP_SIGNATURE_fetch() obtiene la implementación para el algorithm dado de cualquier proveedor que lo ofrezca, dentro de los criterios dados por las properties. El algoritmo será uno que ofrezca funciones para realizar tareas relacionadas con la firma, como firmar y verificar. Ver "ALGORITHM FETCHING" en crypto(7) para más información.

El valor devuelto debe liberarse eventualmente con EVP_SIGNATURE_free().

EVP_SIGNATURE_free() decrementa el contador de referencias para la estructura EVP_SIGNATURE. Típicamente esta estructura habrá sido obtenida de una llamada anterior a EVP_SIGNATURE_fetch(). Si el contador de referencias llega a 0, la estructura se libera. Si el argumento es NULL, no se hace nada.

EVP_SIGNATURE_up_ref() incrementa el contador de referencias para una estructura EVP_SIGNATURE.

EVP_SIGNATURE_is_a() devuelve 1 si signature es una implementación de un algoritmo que se puede identificar con name, de lo contrario 0.

EVP_SIGNATURE_get0_provider() devuelve el proveedor desde el que se obtuvo signature.

EVP_SIGNATURE_do_all_provided() recorre todas las SIGNATURE implementadas por todos los proveedores activados en el contexto de librería dado libctx, y para cada una de las implementaciones, llama a la función dada fn con el método de implementación y el arg dado como argumento.

EVP_SIGNATURE_get0_name() devuelve el nombre del algoritmo de la implementación proporcionada para la signature dada. Tenga en cuenta que la signature puede tener varios sinónimos asociados. En este caso, se devuelve el primer nombre de la definición del algoritmo. La propiedad del cadena devuelta la retiene el objeto signature y no debe ser liberada por el llamador.

EVP_SIGNATURE_names_do_all() recorre todos los nombres para signature, y llama a fn con cada nombre y data.

EVP_SIGNATURE_get0_description() devuelve una descripción de la signature, destinada a ser mostrada y para consumo humano. La descripción queda a discreción de la implementación de la signature.

EVP_SIGNATURE_gettable_ctx_params() y EVP_SIGNATURE_settable_ctx_params() devuelven una matriz constante OSSL_PARAM(3) que describe los nombres y tipos de parámetros clave que pueden ser recuperados o establecidos por un algoritmo de firma usando EVP_PKEY_CTX_get_params(3) y EVP_PKEY_CTX_set_params(3).

VALORES DE RETORNO

EVP_SIGNATURE_fetch() devuelve un puntero a una EVP_SIGNATURE en caso de éxito o NULL en caso de fallo.

EVP_SIGNATURE_up_ref() devuelve 1 en caso de éxito o 0 en caso contrario.

EVP_SIGNATURE_names_do_all() devuelve 1 si la función de callback se llamó para todos los nombres. Un valor de retorno de 0 significa que la función de callback no se llamó para ningún nombre.

EVP_SIGNATURE_gettable_ctx_params() y EVP_SIGNATURE_settable_ctx_params() devuelven una matriz constante OSSL_PARAM(3) o NULL en caso de error.

VER TAMBIÉN

"ALGORITHM FETCHING" en crypto(7), OSSL_PROVIDER(3)
