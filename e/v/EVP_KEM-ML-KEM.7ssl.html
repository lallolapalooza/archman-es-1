NOMBRE

EVP_KEM-ML-KEM-512, EVP_KEM-ML-KEM-768, EVP_KEM-ML-KEM-1024, EVP_KEM-ML-KEM - Soporte de tipo de clave y algoritmo EVP_KEM ML-KEM

DESCRIPCIÓN

Los tipos de clave y parámetros de ML-KEM se describen en EVP_PKEY-ML-KEM(7). Consulte EVP_PKEY_encapsulate(3) y EVP_PKEY_decapsulate(3) para obtener más detalles sobre las operaciones básicas de KEM.

PARÁMETROS KEM ML-KEM

"ikme" (OSSL_KEM_PARAM_IKME) <cadena de octetos>
El mecanismo de encapsulación ML-KEM de OpenSSL solo puede modificarse estableciendo aleatoriedad durante la encapsulación, esto permite la prueba, según FIPS 203, sección 6.2, algoritmo 17.

Este parámetro no debe utilizarse para fines distintos de las pruebas.

Cuando este parámetro no está establecido, la encapsulación procede según FIPS 203, sección 7.2.

Este parámetro solo se puede establecer.

Esto se puede establecer al usar EVP_PKEY_encapsulate_init().
