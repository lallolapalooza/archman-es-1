EVP_MAC-BLAKE2(7ssl) OpenSSL EVP_MAC-BLAKE2(7ssl)

NOMBRE

EVP_MAC-BLAKE2, EVP_MAC-BLAKE2BMAC, EVP_MAC-BLAKE2SMAC - Las implementaciones de EVP_MAC de BLAKE2

DESCRIPCIÓN

Soporte para calcular MACs BLAKE2 a través de la API EVP_MAC.

Identidad

Estas implementaciones se identifican con uno de estos nombres y propiedades, para ser utilizados con EVP_MAC_fetch():

"BLAKE2BMAC", "provider=default"
"BLAKE2SMAC", "provider=default"

Parámetros soportados

La descripción general de estos parámetros se puede encontrar en "PARAMETERS" en EVP_MAC(3).

Todos estos parámetros (excepto "block-size") se pueden configurar con EVP_MAC_CTX_set_params(). Además, el parámetro "size" se puede obtener con EVP_MAC_CTX_get_params(), o con EVP_MAC_CTX_get_mac_size(). La longitud del parámetro "size" no debe exceder la de un size_t. Del mismo modo, el parámetro "block-size" se puede obtener con EVP_MAC_CTX_get_params(), o con EVP_MAC_CTX_get_block_size().

"key" (OSSL_MAC_PARAM_KEY) <cadena de octetos>
Establece la clave MAC. Puede tener como máximo 64 bytes para BLAKE2BMAC o 32 para BLAKE2SMAC y al menos 1 byte en ambos casos. Establecer este parámetro es idéntico a pasar una key a EVP_MAC_init(3).
"custom" (OSSL_MAC_PARAM_CUSTOM) <cadena de octetos>
Establece la cadena de personalización/customización. Es un valor opcional de como máximo 16 bytes para BLAKE2BMAC o 8 para BLAKE2SMAC, y está vacío por defecto.
"salt" (OSSL_MAC_PARAM_SALT) <cadena de octetos>
Establece la sal. Es un valor opcional de como máximo 16 bytes para BLAKE2BMAC o 8 para BLAKE2SMAC, y está vacío por defecto.
"size" (OSSL_MAC_PARAM_SIZE) <entero sin signo>
Establece el tamaño del MAC. Puede ser cualquier número entre 1 y 32 para EVP_MAC_BLAKE2S o entre 1 y 64 para EVP_MAC_BLAKE2B. Por defecto es 32 y 64 respectivamente.
"block-size" (OSSL_MAC_PARAM_BLOCK_SIZE) <entero sin signo>
Obtiene el tamaño del bloque MAC. Es 64 para EVP_MAC_BLAKE2S y 128 para EVP_MAC_BLAKE2B.
