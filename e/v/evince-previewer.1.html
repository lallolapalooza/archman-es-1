NOMBRE

evince-previewer - muestra una vista previa de impresión de documentos PostScript y PDF

SINOPSIS

evince-previewer [opciones] entrada

DESCRIPCIÓN

evince-previewer es un programa GNOME para mostrar una vista previa de impresión de archivos PostScript (PS), Portable Document Format (PDF), DjVu y DVI.

Este programa no está diseñado para ser llamado por usuarios finales.

OPCIONES

evince-previewer obedece todas las opciones de línea de comandos normales de GNOME y GTK+. Las opciones de la aplicación son:

-u, --eliminar-archivo-temporal
Elimina el archivo temporal
-p, --configuración-de-impresión=ARCHIVO
Archivo de configuración de impresión
