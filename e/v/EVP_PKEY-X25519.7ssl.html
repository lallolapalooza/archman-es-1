EVP_PKEY-X25519(7ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY-X25519(7ssl) OpenSSL EVP_PKEY-X25519(7ssl)

NOMBRE

EVP_PKEY-X25519, EVP_PKEY-X448, EVP_PKEY-ED25519, EVP_PKEY-ED448, EVP_KEYMGMT-X25519, EVP_KEYMGMT-X448, EVP_KEYMGMT-ED25519, EVP_KEYMGMT-ED448 - Soporte de tipo de clave y algoritmo EVP_PKEY X25519, X448, ED25519 y ED448

DESCRIPCIÓN

Los tipos de clave X25519, X448, ED25519 y ED448 se implementan en los proveedores predeterminados y FIPS de OpenSSL. Estas implementaciones soportan la clave asociada, que contiene la clave pública pub y la clave privada priv.

Parámetros comunes de generación de claves para X25519, X448, ED25519 y ED448

Los siguientes parámetros se pueden utilizar durante la generación de claves llamando a EVP_PKEY_CTX_set_params() después de llamar a EVP_PKEY_keygen_init().

"properties" (OSSL_PKEY_PARAM_PROPERTIES) <cadena de octetos>
La consulta de propiedades a utilizar al obtener algoritmos durante la operación de generación de claves.

Parámetros de generación de claves para X25519 y X448

"dhkem-ikm" (OSSL_PKEY_PARAM_DHKEM_IKM) <cadena de octetos>
DHKEM requiere la generación de un par de claves utilizando un material de clave de entrada (semilla). Use esto para especificar el material de clave utilizado para la generación de la clave privada. Este valor no debe reutilizarse para otros fines. Debe tener una longitud de al menos 32 para X25519 y 56 para X448.
"group" (OSSL_PKEY_PARAM_GROUP_NAME) <cadena UTF8>
El nombre del grupo debe ser "x25519" o "x448" respectivamente para esos algoritmos. Esto solo está presente por consistencia con otros algoritmos de intercambio de claves y normalmente no es necesario.

Parámetros comunes para X25519, X448, ED25519 y ED448

Además de los parámetros comunes que todos los tipos de clave deben soportar (ver "Parámetros comunes" en provider-keymgmt(7)), la implementación de estos tipos de clave soporta lo siguiente.

"pub" (OSSL_PKEY_PARAM_PUB_KEY) <cadena de octetos>
El valor de la clave pública.
"priv" (OSSL_PKEY_PARAM_PRIV_KEY) <cadena de octetos>
El valor de la clave privada.

Parámetros para X25519 y X448

"encoded-pub-key" (OSSL_PKEY_PARAM_ENCODED_PUBLIC_KEY) <cadena de octetos>
Se utiliza para obtener y establecer la codificación de una clave pública para los tipos de clave X25519 y X448. Se espera que las claves públicas estén codificadas en un formato definido por RFC7748.
"fips-indicator" (OSSL_PKEY_PARAM_FIPS_APPROVED_INDICATOR) <entero>
Este descriptor solo es compatible con el proveedor FIPS de X25519 y X448 de OpenSSL. Dado que X25519 y X448 no están aprobados en FIPS 140-3, este descriptor devuelve 0.

Parámetros para ED25519 y ED448

"mandatory-digest" (OSSL_PKEY_PARAM_MANDATORY_DIGEST) <cadena UTF8>
La cadena vacía, lo que significa que no se puede especificar ningún resumen.

CONFORME A

RFC 8032
RFC 8410

EJEMPLOS

Se puede obtener un contexto EVP_PKEY llamando a:

EVP_PKEY_CTX *pctx =
    EVP_PKEY_CTX_new_from_name(NULL, "X25519", NULL);
EVP_PKEY_CTX *pctx =
    EVP_PKEY_CTX_new_from_name(NULL, "X448", NULL);
EVP_PKEY_CTX *pctx =
    EVP_PKEY_CTX_new_from_name(NULL, "ED25519", NULL);
EVP_PKEY_CTX *pctx =
    EVP_PKEY_CTX_new_from_name(NULL, "ED448", NULL);

Una clave X25519 se puede generar de esta manera:

pkey = EVP_PKEY_Q_keygen(NULL, NULL, "X25519");

Una clave X448, ED25519 o ED448 se puede generar de forma similar.
