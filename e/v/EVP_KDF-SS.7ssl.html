EVP_KDF-SS(7ssl) OpenSSL EVP_KDF-SS(7ssl)

NOMBRE

EVP_KDF-SS - La implementación EVP_KDF de Un Solo Paso / Un Paso

DESCRIPCIÓN

El algoritmo EVP_KDF-SS implementa la función de derivación de claves de Un Solo Paso (SSKDF). SSKDF deriva una clave utilizando entradas como una clave secreta compartida (que fue generada durante la ejecución de un esquema de establecimiento de claves) y fixedinfo. SSKDF también se conoce informalmente como 'Concat KDF'.

La salida se considera material de clave.

Función auxiliar

La implementación utiliza una función auxiliar H seleccionable, que puede ser una de las siguientes:

H(x) = hash(x, digest=md)
H(x) = HMAC_hash(x, key=salt, digest=md)
H(x) = KMACxxx(x, key=salt, custom="KDF", outlen=mac_size)

Tanto las implementaciones HMAC como KMAC establecen la clave utilizando el valor 'salt'. El hash y el HMAC también requieren que se establezca el resumen (digest).

Identidad

"SSKDF" es el nombre de esta implementación; puede usarse con la función EVP_KDF_fetch()

Parámetros soportados

Los parámetros soportados son:

"properties" (OSSL_KDF_PARAM_PROPERTIES) <cadena UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <cadena UTF8>
Este parámetro se ignora para KMAC.
"mac" (OSSL_KDF_PARAM_MAC) <cadena UTF8>
"maclen" (OSSL_KDF_PARAM_MAC_SIZE) <entero sin signo>
"salt" (OSSL_KDF_PARAM_SALT) <cadena de octetos>
Estos parámetros funcionan como se describe en "PARAMETERS" en EVP_KDF(3).
"key" (OSSL_KDF_PARAM_SECRET) <cadena de octetos>
Este parámetro establece el secreto compartido que se utiliza para la derivación de claves.
"info" (OSSL_KDF_PARAM_INFO) <cadena de octetos>
Este parámetro establece un valor opcional para fixedinfo, también conocido como otherinfo.

El proveedor FIPS de OpenSSL también soporta los siguientes parámetros:

"fips-indicator" (OSSL_KDF_PARAM_FIPS_APPROVED_INDICATOR) <entero>
Un getter que devuelve 1 si la operación está aprobada por FIPS, o 0 en caso contrario. Esto puede usarse después de llamar a EVP_KDF_derive. Devuelve 0 si "key-check" está establecido a 0 y la verificación falla.
"key-check" (OSSL_KDF_PARAM_FIPS_KEY_CHECK) <entero>
El valor predeterminado de 1 provoca un error durante EVP_KDF_CTX_set_params() si la longitud de la clave de derivación de claves utilizada (OSSL_KDF_PARAM_KEY) es más corta que 112 bits. Establecer esto en cero ignorará el error y establecerá el "fips-indicator" aprobado en 0. Esta opción rompe el cumplimiento de FIPS si provoca que el "fips-indicator" aprobado devuelva 0.

NOTAS

Se puede obtener un contexto para SSKDF llamando a:

EVP_KDF *kdf = EVP_KDF_fetch(NULL, "SSKDF", NULL);
EVP_KDF_CTX *kctx = EVP_KDF_CTX_new(kdf);

La longitud de salida de un SSKDF se especifica a través del parámetro keylen de la función EVP_KDF_derive(3)

EJEMPLOS

Este ejemplo deriva 10 bytes usando H(x) = SHA-256, con la clave secreta "secret" y el valor fixedinfo "label":

EVP_KDF *kdf;
EVP_KDF_CTX *kctx;
unsigned char out[10];
OSSL_PARAM params[4], *p = params;
kdf = EVP_KDF_fetch(NULL, "SSKDF", NULL);
kctx = EVP_KDF_CTX_new(kdf);
EVP_KDF_free(kdf);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_KDF_PARAM_DIGEST,
                                        SN_sha256, strlen(SN_sha256));
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_KEY,
                                         "secret", (size_t)6);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_INFO,
                                         "label", (size_t)5);
*p = OSSL_PARAM_construct_end();
if (EVP_KDF_derive(kctx, out, sizeof(out), params) <= 0) {
    error("EVP_KDF_derive");
}
EVP_KDF_CTX_free(kctx);

Este ejemplo deriva 10 bytes usando H(x) = HMAC(SHA-256), con la clave secreta "secret", el valor fixedinfo "label" y el salt "salt":

EVP_KDF *kdf;
EVP_KDF_CTX *kctx;
unsigned char out[10];
OSSL_PARAM params[6], *p = params;
kdf = EVP_KDF_fetch(NULL, "SSKDF", NULL);
kctx = EVP_KDF_CTX_new(kdf);
EVP_KDF_free(kdf);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_KDF_PARAM_MAC,
                                        SN_hmac, strlen(SN_hmac));
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_KDF_PARAM_DIGEST,
                                        SN_sha256, strlen(SN_sha256));
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_SECRET,
                                         "secret", (size_t)6);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_INFO,
                                         "label", (size_t)5);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_SALT,
                                         "salt", (size_t)4);
*p = OSSL_PARAM_construct_end();
if (EVP_KDF_derive(kctx, out, sizeof(out), params) <= 0) {
    error("EVP_KDF_derive");
}
EVP_KDF_CTX_free(kctx);

Este ejemplo deriva 10 bytes usando H(x) = KMAC128(x,salt,outlen), con la clave secreta "secret", el valor fixedinfo "label", el salt "salt" y un outlen de KMAC de 20:

EVP_KDF *kdf;
EVP_KDF_CTX *kctx;
unsigned char out[10];
OSSL_PARAM params[6], *p = params;
kdf = EVP_KDF_fetch(NULL, "SSKDF", NULL);
kctx = EVP_KDF_CTX_new(kdf);
EVP_KDF_free(kdf);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_KDF_PARAM_MAC,
                                        SN_kmac128, strlen(SN_kmac128));
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_SECRET,
                                         "secret", (size_t)6);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_INFO,
                                         "label", (size_t)5);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_SALT,
                                         "salt", (size_t)4);
*p++ = OSSL_PARAM_construct_size_t(OSSL_KDF_PARAM_MAC_SIZE, (size_t)20);
*p = OSSL_PARAM_construct_end();
if (EVP_KDF_derive(kctx, out, sizeof(out), params) <= 0) {
    error("EVP_KDF_derive");
}
EVP_KDF_CTX_free(kctx);
