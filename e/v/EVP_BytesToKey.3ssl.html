EVP_BytesToKey(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_BYTESTOKEY(3ssl) OpenSSL EVP_BYTESTOKEY(3ssl)

NOMBRE

EVP_BytesToKey - rutina de cifrado basada en contraseña

SINOPSIS

#include <openssl/evp.h>
int EVP_BytesToKey(const EVP_CIPHER *type, const EVP_MD *md,
                   const unsigned char *salt,
                   const unsigned char *data, int datal, int count,
                   unsigned char *key, unsigned char *iv);

DESCRIPCIÓN

EVP_BytesToKey() deriva una clave y un IV a partir de varios parámetros. type es el cifrador para el que se derivan la clave y el IV. md es el resumen del mensaje a usar. El parámetro salt se usa como sal en la derivación: debe apuntar a un buffer de 8 bytes o ser NULL si no se usa sal. data es un buffer que contiene datal bytes que se usan para derivar los datos de clave. count es el número de iteraciones a usar. La clave y el IV derivados se escribirán en key e iv respectivamente.

NOTAS

Una aplicación típica de esta función es derivar material de clave para un algoritmo de cifrado a partir de una contraseña en el parámetro data.

Aumentar el parámetro count ralentiza el algoritmo, lo que dificulta que un atacante realice un ataque de fuerza bruta utilizando un gran número de contraseñas candidatas.

Si la longitud total de la clave y el IV es menor que la longitud del resumen y se usa MD5, entonces el algoritmo de derivación es compatible con PKCS#5 v1.5, de lo contrario se utiliza una extensión no estándar para derivar los datos adicionales.

Las aplicaciones más nuevas deben usar un algoritmo más moderno, como PBKDF2, según se define en PKCS#5v2.1 y proporcionado por PKCS5_PBKDF2_HMAC.

ALGORITMO DE DERIVACIÓN DE CLAVE

La clave y el IV se derivan concatenando D_1, D_2, etc., hasta que haya suficientes datos disponibles para la clave y el IV. D_i se define como:

D_i = HASH^count(D_(i-1) || data || salt)

donde || denota concatenación, D_0 está vacío, HASH es el algoritmo de resumen en uso, HASH^1(data) es simplemente HASH(data), HASH^2(data) es HASH(HASH(data)) y así sucesivamente.

Los bytes iniciales se utilizan para la clave y los bytes subsiguientes para el IV.

VALORES DE RETORNO

Si data es NULL, entonces EVP_BytesToKey() devuelve el número de bytes necesarios para almacenar la clave derivada. De lo contrario, EVP_BytesToKey() devuelve el tamaño de la clave derivada en bytes, o 0 en caso de error.

VER TAMBIÉN
