NOMBRE

EVP_KDF-TLS1_PRF - La implementación de EVP_KDF TLS1 PRF

DESCRIPCIÓN

Soporte para calcular el PRF TLS1 a través de la API EVP_KDF.

El algoritmo EVP_KDF-TLS1_PRF implementa el PRF utilizado por las versiones de TLS hasta TLS 1.2 inclusive.

La salida se considera material de clave.

Identidad

"TLS1-PRF" es el nombre de esta implementación; puede ser utilizado con la función EVP_KDF_fetch().

Parámetros soportados

Los parámetros soportados son:

"properties" (OSSL_KDF_PARAM_PROPERTIES) <cadena UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <cadena UTF8>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_KDF(3).

El parámetro OSSL_KDF_PARAM_DIGEST se utiliza para establecer el resumen de mensajes asociado con el PRF TLS. EVP_md5_sha1() se trata como un caso especial que utiliza el algoritmo PRF usando tanto MD5 como SHA1 como se usó en TLS 1.0 y 1.1.

"secret" (OSSL_KDF_PARAM_SECRET) <cadena de octetos>
Este parámetro establece el valor secreto del PRF TLS. Cualquier valor secreto existente es reemplazado.
"seed" (OSSL_KDF_PARAM_SEED) <cadena de octetos>
Este parámetro establece la semilla de contexto. La longitud de la semilla de contexto no puede exceder los 1024 bytes; esto debería ser más que suficiente para cualquier uso normal del PRF TLS.

El proveedor FIPS de OpenSSL también soporta los siguientes parámetros:

"fips-indicator" (OSSL_KDF_PARAM_FIPS_APPROVED_INDICATOR) <entero>
Un getter que devuelve 1 si la operación está aprobada por FIPS, o 0 de lo contrario. Esto puede usarse después de llamar a EVP_KDF_derive. Devuelve 0 si algún parámetro relacionado con "***-check" se establece en 0 y la verificación falla.
"ems-check" (OSSL_KDF_PARAM_FIPS_EMS_CHECK) <entero>
El valor predeterminado de 1 causa un error durante EVP_KDF_derive() si se utiliza "master secret" en lugar de "extended master secret". Establecer esto en cero ignorará el error y establecerá el indicador FIPS aprobado en 0. Esta opción rompe el cumplimiento de FIPS si hace que el indicador FIPS aprobado devuelva 0.
"digest-check" (OSSL_KDF_PARAM_FIPS_DIGEST_CHECK) <entero>
El valor predeterminado de 1 causa un error durante EVP_KDF_CTX_set_params() si el resumen utilizado no está aprobado. Establecer esto en cero ignorará el error y establecerá el indicador FIPS aprobado en 0. Esta opción rompe el cumplimiento de FIPS si hace que el indicador FIPS aprobado devuelva 0.

Según SP 800-135r1, los siguientes son algoritmos de resumen aprobados: SHA2-256, SHA2-384, SHA2-512.

"key-check" (OSSL_KDF_PARAM_FIPS_KEY_CHECK) <entero>
El valor predeterminado de 1 causa un error durante EVP_KDF_CTX_set_params() si la longitud de la clave de derivación utilizada (OSSL_KDF_PARAM_SECRET) es inferior a 112 bits. Establecer esto en cero ignorará el error y establecerá el indicador FIPS aprobado en 0. Esta opción rompe el cumplimiento de FIPS si hace que el indicador FIPS aprobado devuelva 0.

NOTAS

Se puede obtener un contexto para el PRF TLS llamando a:

EVP_KDF *kdf = EVP_KDF_fetch(NULL, "TLS1-PRF", NULL);
EVP_KDF_CTX *kctx = EVP_KDF_CTX_new(kdf);

El resumen, el valor secreto y la semilla deben establecerse antes de derivar una clave, de lo contrario se producirá un error.

La longitud de salida del PRF se especifica mediante el parámetro keylen de la función EVP_KDF_derive().

EJEMPLOS

Este ejemplo deriva 10 bytes usando SHA-256 con la clave secreta "secret" y el valor de semilla "seed":

EVP_KDF *kdf;
EVP_KDF_CTX *kctx;
unsigned char out[10];
OSSL_PARAM params[4], *p = params;
kdf = EVP_KDF_fetch(NULL, "TLS1-PRF", NULL);
kctx = EVP_KDF_CTX_new(kdf);
EVP_KDF_free(kdf);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_KDF_PARAM_DIGEST,
                                        SN_sha256, strlen(SN_sha256));
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_SECRET,
                                         "secret", (size_t)6);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_SEED,
                                         "seed", (size_t)4);
*p = OSSL_PARAM_construct_end();
if (EVP_KDF_derive(kctx, out, sizeof(out), params) <= 0) {
    error("EVP_KDF_derive");
}
EVP_KDF_CTX_free(kctx);
