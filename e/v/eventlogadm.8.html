EVENTLOGADM(8) Herramientas de administración del sistema EVENTLOGADM(8)

NOMBRE

eventlogadm - introduce registros en el almacén de registros de eventos de Samba

SINOPSIS

eventlogadm [-s] [-d] [-h] -o addsource EVENTLOG SOURCENAME MSGFILE

eventlogadm [-s] [-d] [-h] -o write EVENTLOG

eventlogadm [-s] [-d] [-h] -o dump EVENTLOG RECORD_NUMBER

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de utilidades de samba(1).

eventlogadm es un filtro que acepta registros de eventos formateados en la entrada estándar y los escribe en el almacén de registros de eventos de Samba. Los clientes de Windows pueden entonces manipular estos registros utilizando las herramientas de administración habituales.

OPCIONES

-s NOMBRE_ARCHIVO

La opción -s hace que eventlogadm cargue el archivo de configuración dado como NOMBRE_ARCHIVO en lugar del predeterminado utilizado por Samba.

-d

La opción -d hace que eventlogadm emita información de depuración.

-o addsource EVENTLOG NOMBRE_FUENTE ARCHIVO_MENSAJES

La opción -o addsource crea una nueva fuente de registro de eventos.

-o write EVENTLOG

La opción -o write lee registros de eventos de la entrada estándar y los escribe en el almacén de registros de eventos de Samba identificado por EVENTLOG.

-o dump EVENTLOG NÚMERO_REGISTRO

La opción -o dump lee registros de eventos de una tdb de EVENTLOG y los vuelca en la salida estándar en pantalla.

-h

Imprime la información de uso.

FORMATO DEL REGISTRO DE EVENTOS

Para la operación de escritura, eventlogadm espera poder leer registros estructurados de la entrada estándar. Estos registros son una secuencia de líneas, con la clave del registro y los datos separados por dos puntos. Los registros están separados por una o más líneas en blanco.

Los campos del registro de eventos son:

•LEN - Este campo debe ser 0, ya que eventlogadm calculará este valor.
•RS1 - Este debe ser el valor 1699505740.
•RCN - Este campo debe ser 0.
•TMG - La hora en que se generó el registro del evento; el formato es el número de segundos desde las 00:00:00 del 1 de enero de 1970, UTC.
•TMW - La hora en que se escribió el registro del evento; el formato es el número de segundos desde las 00:00:00 del 1 de enero de 1970, UTC.
•EID - El ID del registro de eventos.
•ETP - El tipo de evento: uno de "INFO", "ERROR", "WARNING", "AUDIT SUCCESS" o "AUDIT FAILURE".
•ECT - La categoría del evento; esto depende del archivo de mensajes. Se utiliza principalmente como medio de filtrado en el visor de registros de eventos.
•RS2 - Este campo debe ser 0.
•CRN - Este campo debe ser 0.
•USL - Este campo debe ser 0.
•SRC - Este campo contiene el nombre de la fuente asociado con el registro de eventos. Si se utiliza un archivo de mensajes con un registro de eventos, habrá una entrada en el registro para asociar este nombre de fuente con un DLL de archivo de mensajes.
•SRN - El nombre de la máquina en la que se generó el registro de eventos. Típicamente, es el nombre del host.
•STR - El texto asociado con el registro de eventos. Puede haber más de una cadena en un registro.
•DAT - Este campo debe dejarse sin establecer.

EJEMPLOS

Un ejemplo del formato de registro aceptado por eventlogadm:

LEN: 0
RS1: 1699505740
RCN: 0
TMG: 1128631322
TMW: 1128631322
EID: 1000
ETP: INFO
ECT: 0
RS2: 0
CRN: 0
USL: 0
SRC: cron
SRN: dmlinux
STR: (root) CMD ( rm -f /var/spool/cron/lastrun/cron.hourly)
DAT:

Configurar una fuente de registro de eventos, especificando un archivo de mensajes DLL:

eventlogadm -o addsource Application MyApplication | \\
    	%SystemRoot%/system32/MyApplication.dll

Filtrar mensajes del registro del sistema en un registro de eventos:

tail -f /var/log/messages | \\
	my_program_to_parse_into_eventlog_records | \\
      	eventlogadm SystemLogEvents
