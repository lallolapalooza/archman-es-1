EVP_PKEY_is_a(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_IS_A(3ssl) OpenSSL EVP_PKEY_IS_A(3ssl)

NOMBRE

EVP_PKEY_is_a, EVP_PKEY_can_sign, EVP_PKEY_type_names_do_all, EVP_PKEY_get0_type_name, EVP_PKEY_get0_description, EVP_PKEY_get0_provider - funciones de tipo y capacidades de clave

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_is_a(const EVP_PKEY *pkey, const char *name);
int EVP_PKEY_can_sign(const EVP_PKEY *pkey);
int EVP_PKEY_type_names_do_all(const EVP_PKEY *pkey,
                               void (*fn)(const char *name, void *data),
                               void *data);
const char *EVP_PKEY_get0_type_name(const EVP_PKEY *key);
const char *EVP_PKEY_get0_description(const EVP_PKEY *key);
const OSSL_PROVIDER *EVP_PKEY_get0_provider(const EVP_PKEY *key);

DESCRIPCIÓN

EVP_PKEY_is_a() comprueba si el tipo de clave de pkey es name.

EVP_PKEY_can_sign() comprueba si la funcionalidad del tipo de clave de pkey admite la firma. No se realiza ninguna otra comprobación, como si pkey contiene una clave privada.

EVP_PKEY_type_names_do_all() recorre todos los nombres del tipo de clave de pkey y llama a fn con cada nombre y data. Por ejemplo, una EVP_PKEY de RSA puede denominarse tanto "RSA" como "rsaEncryption". El orden de los nombres depende de la implementación del proveedor que posea la clave.

EVP_PKEY_get0_type_name() devuelve el primer nombre de tipo de clave que se encuentra para el pkey dado. Tenga en cuenta que el pkey puede tener varios sinónimos asociados. En este caso, depende de la implementación del proveedor que posea la clave cuál se devolverá. La propiedad de la cadena devuelta la conserva el objeto pkey y no debe ser liberada por el llamador.

EVP_PKEY_get0_description() devuelve una descripción del tipo de EVP_PKEY, destinada a su visualización y consumo humano. La descripción queda a discreción de la implementación del tipo de clave.

EVP_PKEY_get0_provider() devuelve el proveedor de EVP_KEYMGMT(3) del EVP_PKEY.

VALORES DE RETORNO

EVP_PKEY_is_a() devuelve 1 si pkey tiene el tipo de clave name, de lo contrario 0.

EVP_PKEY_can_sign() devuelve 1 si la funcionalidad del tipo de clave pkey admite la firma, de lo contrario 0.

EVP_PKEY_get0_type_name() devuelve el nombre encontrado o NULL en caso de error.

EVP_PKEY_get0_description() devuelve la descripción si se encuentra o NULL si no.

EVP_PKEY_get0_provider() devuelve el proveedor si se encuentra o NULL si no.

EVP_PKEY_type_names_do_all() devuelve 1 si se llamó a la función de devolución de llamada para todos los nombres. Un valor de retorno de 0 significa que la función de devolución de llamada no se llamó para ningún nombre.

EJEMPLOS

EVP_PKEY_is_a()

Los proveedores cargados y los tipos de clave que admiten determinarán en última instancia qué name se puede utilizar con EVP_PKEY_is_a(). Sabemos que el proveedor predeterminado admite claves RSA, DH, DSA y EC, por lo que podemos usar esto como un ejemplo rudimentario:

#include <openssl/evp.h>
...
    /* |pkey| es un EVP_PKEY* */
    if (EVP_PKEY_is_a(pkey, "RSA")) {
        BIGNUM *modulus = NULL;
        if (EVP_PKEY_get_bn_param(pkey, "n", &modulus))
            /* hacer lo que sea con el módulo */
        BN_free(modulus);
    }

EVP_PKEY_can_sign()

#include <openssl/evp.h>
...
    /* |pkey| es un EVP_PKEY* */
    if (!EVP_PKEY_can_sign(pkey)) {
        fprintf(stderr, "¡No es una clave de firma!");
        exit(1);
    }
    /* Firmar algo... */
