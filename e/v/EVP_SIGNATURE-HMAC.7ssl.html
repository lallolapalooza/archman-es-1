NOMBRE

EVP_SIGNATURE-HMAC, EVP_SIGNATURE-Siphash, EVP_SIGNATURE-Poly1305, EVP_SIGNATURE-CMAC - Las implementaciones de firmas MAC EVP_PKEY heredadas

DESCRIPCIÓN

Los algoritmos descritos aquí tienen soporte heredado para crear MACs usando EVP_DigestSignInit(3) y funciones relacionadas. Esta no es la forma preferida de crear MACs. En su lugar, deberías usar las funciones más nuevas EVP_MAC_init(3). Este mecanismo se proporciona para compatibilidad con versiones anteriores de OpenSSL.

Los mismos parámetros de firma se pueden establecer usando EVP_PKEY_CTX_set_params() que se pueden establecer a través de EVP_MAC_CTX_set_params() para el EVP_MAC subyacente. Véase EVP_MAC-HMAC(7), EVP_MAC-Siphash(7), EVP_MAC-Poly1305(7) y EVP_MAC-CMAC(7) para más detalles.

Ver L<EVP_PKEY-HMAC(7)>, L<EVP_PKEY-Siphash(7)>, L<EVP_PKEY-Poly1305(7)> o
L<EVP_PKEY-CMAC(7)> para detalles sobre los parámetros que son compatibles durante la
creación de un EVP_PKEY.
