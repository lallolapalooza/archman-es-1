EVP_PKEY_meth_get_count(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_METH_GET_COUNT(3ssl) OpenSSL EVP_PKEY_METH_GET_COUNT(3ssl)

NOMBRE

EVP_PKEY_meth_get_count, EVP_PKEY_meth_get0, EVP_PKEY_meth_get0_info - enumerar métodos de clave pública

SINOPSIS

#include <openssl/evp.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

size_t EVP_PKEY_meth_get_count(void);
const EVP_PKEY_METHOD *EVP_PKEY_meth_get0(size_t idx);
void EVP_PKEY_meth_get0_info(int *ppkey_id, int *pflags,
                             const EVP_PKEY_METHOD *meth);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar las APIs de OSSL_PROVIDER en su lugar.

EVP_PKEY_meth_count() devuelve un recuento del número de métodos de clave pública disponibles: incluye métodos estándar y cualquier método añadido por la aplicación.

EVP_PKEY_meth_get0() devuelve el método de clave pública idx. El valor de idx debe estar entre cero y EVP_PKEY_meth_get_count() - 1.

EVP_PKEY_meth_get0_info() devuelve el ID de clave pública (un NID) y cualquier flag asociado con el método de clave pública *meth.

VALORES DE RETORNO

EVP_PKEY_meth_count() devuelve el número de métodos de clave pública disponibles.

EVP_PKEY_meth_get0() devuelve un método de clave pública o NULL si idx está fuera de rango.

EVP_PKEY_meth_get0_info() no devuelve un valor.

VER TAMBIÉN

EVP_PKEY_new(3)

HISTORIAL

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
