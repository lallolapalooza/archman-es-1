EVP_PKEY_asn1_get_count(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_asn1_get_count(3ssl) OpenSSL EVP_PKEY_asn1_get_count(3ssl)

NOMBRE

EVP_PKEY_asn1_find, EVP_PKEY_asn1_find_str, EVP_PKEY_asn1_get_count, EVP_PKEY_asn1_get0, EVP_PKEY_asn1_get0_info - enumerar métodos ASN.1 de claves públicas

SINOPSIS

Las siguientes funciones han sido obsoletas desde OpenSSL 3.6, y pueden ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7); utilice la API del proveedor en su lugar.

#include <openssl/evp.h>
int EVP_PKEY_asn1_get_count(void);
const EVP_PKEY_ASN1_METHOD *EVP_PKEY_asn1_get0(int idx);
const EVP_PKEY_ASN1_METHOD *EVP_PKEY_asn1_find(ENGINE **pe, int type);
const EVP_PKEY_ASN1_METHOD *EVP_PKEY_asn1_find_str(ENGINE **pe,
                                                   const char *str, int len);
int EVP_PKEY_asn1_get0_info(int *ppkey_id, int *pkey_base_id,
                            int *ppkey_flags, const char **pinfo,
                            const char **ppem_str,
                            const EVP_PKEY_ASN1_METHOD *ameth);

DESCRIPCIÓN

EVP_PKEY_asn1_count() devuelve un recuento del número de métodos ASN.1 de claves públicas disponibles: incluye métodos estándar y cualquier método añadido por la aplicación.

EVP_PKEY_asn1_get0() devuelve el método ASN.1 de clave pública idx. El valor de idx debe estar entre cero y EVP_PKEY_asn1_get_count() - 1.

EVP_PKEY_asn1_find() busca el EVP_PKEY_ASN1_METHOD con NID type. Si pe no es NULL, entonces buscará un motor que implemente un EVP_PKEY_ASN1_METHOD para el NID type y devolverá ese en su lugar, y también establecerá *pe para que apunte al motor que lo implementa.

EVP_PKEY_asn1_find_str() busca el EVP_PKEY_ASN1_METHOD con la cadena de tipo PEM str. Al igual que EVP_PKEY_asn1_find(), si pe no es NULL, entonces buscará un motor que implemente un EVP_PKEY_ASN1_METHOD para el NID type y devolverá ese en su lugar, y también establecerá *pe para que apunte al motor que lo implementa.

EVP_PKEY_asn1_get0_info() devuelve el ID de la clave pública, el ID base de la clave pública (ambos NIDs), cualquier bandera, la descripción del método y la cadena de tipo PEM asociados con el método ASN.1 de clave pública *ameth.

EVP_PKEY_asn1_count(), EVP_PKEY_asn1_get0(), EVP_PKEY_asn1_find() y EVP_PKEY_asn1_find_str() no son seguros para subprocesos, pero mientras todos los objetos EVP_PKEY_ASN1_METHOD se añadan antes de que la aplicación obtenga subprocesos, su uso es seguro. Véase EVP_PKEY_asn1_add0(3).

VALORES DEVUELTOS

EVP_PKEY_asn1_count() devuelve el número de métodos de clave pública disponibles.

EVP_PKEY_asn1_get0() devuelve un método de clave pública o NULL si idx está fuera de rango.

EVP_PKEY_asn1_get0_info() devuelve 0 en caso de fallo, 1 en caso de éxito.

VER TAMBIÉN

EVP_PKEY_asn1_new(3), EVP_PKEY_asn1_add0(3)

HISTORIAL

Estas funciones fueron obsoletas en OpenSSL 3.6.
