EV::MakeMaker(3) Documentación de Perl aportada por el usuario EV::MakeMaker(3)

NOMBRE

EV::MakeMaker - Pegamento de MakeMaker para la API C de EV

SINOPSIS

Esto le permite acceder a parte de la funcionalidad de libevent desde otros módulos de Perl.

DESCRIPCIÓN

Para un rendimiento óptimo, conéctese a EV a nivel de C. Necesitará hacer cambios en su "Makefile.PL", cargar "EV" en su archivo "pm" y agregar código a sus archivos "xs" / "c".

CÓMO

Makefile.PL

use EV::MakeMaker qw(ev_args);
# ... configura %args ...
WriteMakefile (ev_args (%args));

extension.pm

use EV (); # importa opcionalmente

extension.xs

#include "EVAPI.h"
[...]
BOOT:
  I_EV_API (HvNAME (GvSTASH (CvGV (cv))));

API

Consulte el encabezado EVAPI.h en http://cvs.schmorp.de/EV/EV/EVAPI.h, que debe incluir en lugar de ev.h.

En resumen, todas las funciones y macros de ev.h deberían funcionar, excepto que las macros con guion bajo al final ("EV_A_", "EV_DEFAULT_") no están disponibles (excepto "EV_P_" :).

La multiplicidad está habilitada.

El miembro "data" en cada observador es de tipo "SV *" y no "void *" (esto podría cambiar en algún momento).

EJEMPLO

Los módulos EV::Glib, EV::ADNS y Glib::EV dan buenos ejemplos sobre cómo usar este módulo.

Aquí hay algunos fragmentos de .xs tomados de EV::ADNS que deberían servirle:

#include "EVAPI.h"
static ev_prepare pw;
static ev_idle iw;
static void
idle_cb (EV_P_ ev_idle *w, int revents)
{
  ev_idle_stop (EV_A, w);
}
MODULE = ...
BOOT:
{
  I_EV_API ("EV::ADNS");
  ev_prepare_init (&pw, prepare_cb);
  ev_init (&iw, idle_cb); ev_set_priority (&iw, EV_MINPRI);
  ev_idle_start (EV_DEFAULT, &iw);
}
