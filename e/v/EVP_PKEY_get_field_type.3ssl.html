EVP_PKEY_get_field_type(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_GET_FIELD_TYPE(3ssl) OpenSSL EVP_PKEY_GET_FIELD_TYPE(3ssl)

NOMBRE

EVP_PKEY_get_field_type, EVP_PKEY_get_ec_point_conv_form - obtener el tipo de campo o la forma de conversión de punto de una clave

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_get_field_type(const EVP_PKEY *pkey);
int EVP_PKEY_get_ec_point_conv_form(const EVP_PKEY *pkey);

DESCRIPCIÓN

EVP_PKEY_get_field_type() devuelve el NID del tipo de campo de pkey, si el tipo de clave de pkey lo soporta. Los tipos actualmente soportados por los proveedores incorporados de OpenSSL son NID_X9_62_prime_field para curvas primas o NID_X9_62_characteristic_two_field para curvas binarias; estos valores se definen en el archivo de cabecera <openssl/obj_mac.h>.

EVP_PKEY_get_ec_point_conv_form() devuelve el formato de conversión de punto de pkey, si el tipo de clave de pkey lo soporta.

NOTAS

Entre los tipos de clave estándar de OpenSSL, esto solo se soporta para claves EC y SM2. Otros proveedores pueden soportarlo para tipos de clave adicionales.

VALORES DE RETORNO

EVP_PKEY_get_field_type() devuelve el NID del tipo de campo o 0 en caso de error.

EVP_PKEY_get_ec_point_conv_form() devuelve el número del formato de conversión de punto (ver EC_GROUP_copy(3)) o 0 en caso de error.

VER TAMBIÉN

EC_GROUP_copy(3)

HISTORIAL

Estas funciones se añadieron en OpenSSL 3.0.
