EVP_KEM_free(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_KEM_FREE(3ssl) OpenSSL EVP_KEM_FREE(3ssl)

NOMBRE

EVP_KEM_fetch, EVP_KEM_free, EVP_KEM_up_ref, EVP_KEM_get0_name, EVP_KEM_is_a, EVP_KEM_get0_provider, EVP_KEM_do_all_provided, EVP_KEM_names_do_all, EVP_KEM_get0_description, EVP_KEM_gettable_ctx_params, EVP_KEM_settable_ctx_params - Funciones para gestionar objetos de algoritmos EVP_KEM

SINOPSIS

#include <openssl/evp.h>
EVP_KEM *EVP_KEM_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                       const char *properties);
void EVP_KEM_free(EVP_KEM *kem);
int EVP_KEM_up_ref(EVP_KEM *kem);
const char *EVP_KEM_get0_name(const EVP_KEM *kem);
int EVP_KEM_is_a(const EVP_KEM *kem, const char *name);
OSSL_PROVIDER *EVP_KEM_get0_provider(const EVP_KEM *kem);
void EVP_KEM_do_all_provided(OSSL_LIB_CTX *libctx,
                             void (*fn)(EVP_KEM *kem, void *arg), void *arg);
int EVP_KEM_names_do_all(const EVP_KEM *kem,
                         void (*fn)(const char *name, void *data), void *data);
const char *EVP_KEM_get0_description(const EVP_KEM *kem);
const OSSL_PARAM *EVP_KEM_gettable_ctx_params(const EVP_KEM *kem);
const OSSL_PARAM *EVP_KEM_settable_ctx_params(const EVP_KEM *kem);

DESCRIPCIÓN

EVP_KEM_fetch() obtiene la implementación para el algorithm dado de cualquier proveedor que lo ofrezca, dentro de los criterios dados por las properties y en el ámbito del contexto de biblioteca dado ctx (ver OSSL_LIB_CTX(3)). El algoritmo ofrecerá funciones para realizar tareas relacionadas con KEM asimétricas, como la encapsulación y decapsulación de claves. Ver "ALGORITHM FETCHING" en crypto(7) para más información.

El valor devuelto debe liberarse eventualmente con EVP_KEM_free().

EVP_KEM_free() decrementa el contador de referencias para la estructura EVP_KEM. Típicamente, esta estructura se habrá obtenido de una llamada anterior a EVP_KEM_fetch(). Si el contador de referencias llega a 0, la estructura se libera. Si el argumento es NULL, no se hace nada.

EVP_KEM_up_ref() incrementa el contador de referencias de una estructura EVP_KEM.

EVP_KEM_is_a() devuelve 1 si kem es una implementación de un algoritmo que se puede identificar con name, de lo contrario devuelve 0.

EVP_KEM_get0_provider() devuelve el proveedor del que se obtuvo kem.

EVP_KEM_do_all_provided() recorre todos los EVP_KEM implementados por todos los proveedores activados en el contexto de biblioteca dado libctx, y para cada una de las implementaciones, llama a la función dada fn con el método de implementación y el arg dado como argumento.

EVP_KEM_get0_name() devuelve el nombre del algoritmo de la implementación proporcionada para el kem dado. Tenga en cuenta que el kem puede tener varios sinónimos asociados. En este caso, se devuelve el primer nombre de la definición del algoritmo. La propiedad de la cadena devuelta la conserva el objeto kem y no debe ser liberada por el llamador.

EVP_KEM_names_do_all() recorre todos los nombres para kem, y llama a fn con cada nombre y data.

EVP_KEM_get0_description() devuelve una descripción de kem, destinada a visualización y consumo humano. La descripción queda a discreción de la implementación de kem.

EVP_KEM_gettable_ctx_params() y EVP_KEM_settable_ctx_params() devuelven una matriz constante de OSSL_PARAM(3) que describe los nombres y tipos de los parámetros de clave que se pueden recuperar o establecer mediante un algoritmo de encapsulación de claves utilizando EVP_PKEY_CTX_get_params(3) y EVP_PKEY_CTX_set_params(3).

VALORES DE RETORNO

EVP_KEM_fetch() devuelve un puntero a un EVP_KEM en caso de éxito o NULL en caso de fallo.

EVP_KEM_up_ref() devuelve 1 en caso de éxito o 0 en caso contrario.

EVP_KEM_names_do_all() devuelve 1 si la función de llamada fue llamada para todos los nombres. Un valor de retorno de 0 significa que la función de llamada no fue llamada para ningún nombre.

EVP_KEM_gettable_ctx_params() y EVP_KEM_settable_ctx_params() devuelven una matriz constante de OSSL_PARAM(3) o NULL en caso de error.

VER TAMBIÉN

"ALGORITHM FETCHING" en crypto(7), OSSL_PROVIDER(3)
