DESCRIPCIÓ

N

Estos tipos y funciones ayudan a la aplicación a calcular MACs de diferentes tipos y con diferentes algoritmos subyacentes si los

hay.

Los MACs son un poco complejos en la medida en que algunos de ellos utilizan otros algoritmos para el cálculo real. HMAC utiliza un resumen (digest), y CMAC utiliza un cifrado. Por lo tanto, a veces hay que llevar dos contextos, uno para el algoritmo MAC en sí y otro para el algoritmo de cálculo subyacente si

existe.

Para hacer las cosas menos ambiguas, este manual habla de un "contexto" o "contexto MAC", que denota el contexto a nivel de MAC, y de un "contexto subyacente", o "contexto de cálculo", que denota el contexto para el algoritmo de cálculo subyacente si

existe.

Tipo

s

EVP_MAC es un tipo que contiene la implementación de un

MAC.

EVP_MAC_CTX es un tipo de contexto que contiene información MAC interna, así como una referencia

a un contexto de cálculo, para aquellos MACs q
ue dependen de un algoritmo de cálculo subyacente.

Obtención de la implementación del

algoritmo

EVP_MAC_fetch() obtiene una implementación de un algoritmo MAC, dado un contexto de biblioteca libctx y un conjunto de propiedades. Véase "ALGORITHM FETCHING" en crypto(7) para más

información.

Véase "Message Authentication Code (MAC)" en OSSL_PROVIDER-default(7) para la lista de algoritmos soportados por el proveedor por

defecto.

El valor devuelto debe ser finalmente liberado con EVP_MAC_fre

e(3).

EVP_MAC_up_ref() incrementa el contador de referencias de un MAC ya

obtenido.

EVP_MAC_free() libera un algoritmo obtenido. NULL es un pa

rámetro válido, para el cu
al esta función no hace nada.

Funciones de manipulación del

contexto

EVP_MAC_CTX_new() crea un nuevo contexto para el tipo de MAC mac. El contexto creado puede entonces usarse con la mayoría de las otras funciones descritas

aquí.

EVP_MAC_CTX_free() libera el contenido del contexto, incluyendo un contexto subyacente si existe, así como el contexto en sí. NULL es un parámetro válido, para el cual esta función no hace

nada.

EVP_MAC_CTX_dup() duplica el contexto src y devuelve un contexto recién

asignado.

EVP_MAC_CTX_get0_mac() devuelve el EVP_MAC asociado con el contexto ct

x
.

Funciones de

cálculo

EVP_Q_mac() calcula el código de autenticación de mensajes de data con longitud datalen utilizando el algoritmo MAC name y la clave key con longitud keylen. El algoritmo MAC se obtiene utilizando cualquier libctx y cadena de consulta de propiedades propq proporcionados. Toma los parámetros subalg y otros params, ambos de los cuales pueden ser NULL si no son necesarios. Si out no es NULL, coloca el resultado en la memoria apuntada por out, pero solo si outsize es suficiente (de lo contrario no se realiza ningún cálculo). Si out es NULL, asigna y utiliza un búfer de longitud adecuada, que se devolverá en caso de éxito y debe ser liberado por el llamante. En cualquier caso, también en caso de error, asigna el número de bytes escritos a *outlen a menos que outlen sea

NULL.

EVP_MAC_init() configura el contexto subyacente ctx con la información proporcionada a través de los argumentos key y params. La clave MAC tiene una longitud de keylen y los parámetros en params se procesan antes de establecer la clave. Si key es NULL, la clave debe establecerse a través de params ya sea como parte de esta llamada o por separado utilizando EVP_MAC_CTX_set_params(). Proporcionar params no nulos a esta función es equivalente a llamar a EVP_MAC_CTX_set_params() con esos params para el mismo ctx de antemano. Nota: Hay requisitos adicionales para algunos algoritmos MAC durante la reinicialización (es decir, llamar a EVP_MAC_init() en un EVP_MAC después de que se haya llamado a EVP_MAC_final() en el mismo objeto). Véase la sección NOTAS más

abajo.

Debe llamarse a EVP_MAC_init() antes de EVP_MAC_update() y EVP_MAC_fin

al().

EVP_MAC_init_SKEY() es similar a EVP_MAC_init() pero acepta un objeto EVP_SKEY opaco como

clave.

EVP_MAC_update() añade datalen bytes de data a la entrada del

MAC.

EVP_MAC_final() realiza el cálculo final y almacena el resultado en la memoria apuntada por out de tamaño outsize, y establece el número de bytes escritos en *outl. Si out es NULL o outsize es demasiado pequeño, no se realiza ningún cálculo. Para averiguar cuál será la longitud de la salida y asignar espacio para ella dinámicamente, simplemente llame con out siendo NULL y outl apuntando a una ubicación válida, luego asigne espacio y haga una segunda llamada con out apuntando al espacio

asignado.

EVP_MAC_finalXOF() realiza el cálculo final para un MAC basado en XOF y almacena el resultado en la memoria apuntada por out de tamaño outsize

.

EVP_MAC_get_params() recupera detalles sobre la implementación mac. El conjunto de parámetros proporcionado con params determina exactamente qué parámetros deben recuperarse. Tenga en cuenta que un parámetro qui est inconnu dans le contexte sous-jacent est simplement

ignorée.

EVP_MAC_CTX_get_params() récupère les paramètres choisis, étant donné le contexte ctx et son contexte sous-jacent. L'ensemble des paramètres donnés avec params détermine exactement quels paramètres doivent être récupérés. Notez qu'un paramètre qui est inconnu dans le contexte sous-jacent est simplement

ignoré.

EVP_MAC_CTX_set_params() transmet les paramètres choisis au contexte sous-jacent, étant donné un contexte ctx. L'ensemble des paramètres donnés avec params détermine exactement quels paramètres sont transmis. Si params vaut NULL, le contexte sous-jacent ne doit rien faire et doit retourner 1. Notez qu'un paramètre qui est inconnu dans le contexte sous-jacent est simplement ignoré. De plus, ce qui se passe lorsqu'un paramètre nécessaire n'est pas transmis est défini par l'implémentation

.

EVP_MAC_gettable_params() retourne un tableau OSSL_PARAM(3) qui décrit les paramètres récupérables et définissables. EVP_MAC_gettable_params() retourne les paramètres qui peuvent être utilisés avec EVP_MAC_get_pa

rams().

EVP_MAC_gettable_ctx_params() et EVP_MAC_CTX_gettable_params() retournent des tableaux constants OSSL_PARAM(3) qui décrivent les paramètres récupérables qui peuvent être utilisés avec EVP_MAC_CTX_get_params() . EVP_MAC_gettable_ctx_params() retourne les paramètres qui peuvent être récupérés depuis l'algorithme, alors que EVP_MAC_CTX_gettable_params() retourne les paramètres qui peuvent être récupérés dans l'état actuel du contexte. EVP_MAC_settable_ctx_params(

)

et EVP_MAC_CTX_settable_params() retournent des tableaux constants OSSL_PARAM(3) qui décrivent les paramètres définissables qui peuvent être utilisés avec EVP_MAC_CTX_set_params(). EVP_MAC_settable_ctx_params() retourne les paramètres qui peuvent être récupérés depuis l'algorithme, alors que EVP_MAC_CTX_settable_params() retourne les paramètres qui peuvent être récupérés dans l'état actuel du contexte. EXEMPLES
#include <stdlib.h>
#include <stdio.h>
#include <string.h>
#include <stdarg.h>
#include <unistd.h>
#include <openssl/evp.h>
#include <openssl/err.h>
#include <openssl/params.h>
int main() {
    EVP_MAC *mac = EVP_MAC_fetch(NULL, getenv("MY_MAC"), NULL);
    const char *cipher = getenv("MY_MAC_CIPHER");
    const char *digest = getenv("MY_MAC_DIGEST");
    const char *key = getenv("MY_KEY");
    EVP_MAC_CTX *ctx = NULL;
    unsigned char buf[4096];
    size_t read_l;
    size_t final_l;
    size_t i;
    OSSL_PARAM params[3];
    size_t params_n = 0;
    if (cipher != NULL)
        params[params_n++] =
            OSSL_PARAM_construct_utf8_string("cipher", (char*)cipher, 0);
    if (digest != NULL)
        params[params_n++] =
            OSSL_PARAM_construct_utf8_string("digest", (char*)digest, 0);
    params[params_n] = OSSL_PARAM_construct_end();
    if (mac == NULL
        || key == NULL
        || (ctx = EVP_MAC_CTX_new(mac)) == NULL
        || !EVP_MAC_init(ctx, (const unsigned char *)key, strlen(key),
                         params))
        goto err;
    while ( (read_l = read(STDIN_FILENO, buf, sizeof(buf))) > 0) {
        if (!EVP_MAC_update(ctx, buf, read_l))
            goto err;
    }
    if (!EVP_MAC_final(ctx, buf, &final_l, sizeof(buf)))
        goto err;
    printf("Result: ");
    for (i = 0; i < final_l; i++)
        printf("%02X", buf[i]);
    printf("\n");
    EVP_MAC_CTX_free(ctx);
    EVP_MAC_free(mac);
    exit(0);
 err:
    EVP_MAC_CTX_free(ctx);
    EVP_MAC_free(mac);
    fprintf(stderr, "Something went wrong\n");
    ERR_print_errors_fp(stderr);
    exit (1);
}
