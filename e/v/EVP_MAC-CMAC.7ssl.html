NOMBRE

EVP_MAC-CMAC - La implementación de EVP_MAC de CMAC

DESCRIPCIÓN

Soporte para calcular MACs CMAC a través de la API de EVP_MAC.

Esta implementación utiliza funciones de cifrado EVP para acceder al cifrado subyacente.

Identidad

Esta implementación se identifica con este nombre y propiedades, para ser utilizada con EVP_MAC_fetch():

"CMAC", "provider=default" o "provider=fips"

Parámetros soportados

La descripción general de estos parámetros se puede encontrar en "PARÁMETROS" en EVP_MAC(3).

El siguiente parámetro se puede establecer con EVP_MAC_CTX_set_params():

"key" (OSSL_MAC_PARAM_KEY) <cadena de octetos>
Establece la clave MAC. Establecer este parámetro es idéntico a pasar una key a EVP_MAC_init(3).
"cipher" (OSSL_MAC_PARAM_CIPHER) <cadena UTF8>
Establece el nombre del cifrado subyacente a utilizar. El modo del cifrado debe ser CBC.
"properties" (OSSL_MAC_PARAM_PROPERTIES) <cadena UTF8>
Establece las propiedades a consultar al intentar obtener el cifrado subyacente. Esto debe proporcionarse junto con el parámetro de nombre del cifrado para ser considerado válido.
"encrypt-check" (OSSL_CIPHER_PARAM_FIPS_ENCRYPT_CHECK) <entero>
Esta opción es utilizada por el proveedor FIPS de OpenSSL. Si se requiere, este parámetro debe establecerse antes de EVP_MAC_init()

El valor predeterminado de 1 provoca un error cuando se activa una operación de cifrado Triple-DES no aprobada. Establecer esto en 0 ignorará el error y establecerá el "fips-indicator" aprobado en 0. Esta opción rompe la conformidad FIPS si hace que el "fips-indicator" aprobado devuelva 0.

Los siguientes parámetros se pueden recuperar con EVP_MAC_CTX_get_params():

"size" (OSSL_MAC_PARAM_SIZE) <entero sin signo>
El parámetro "size" también se puede recuperar con EVP_MAC_CTX_get_mac_size(). La longitud del parámetro "size" es igual a la de un unsigned int.
"block-size" (OSSL_MAC_PARAM_BLOCK_SIZE) <entero sin signo>
Obtiene el tamaño del bloque MAC. El parámetro "block-size" también se puede recuperar con EVP_MAC_CTX_get_block_size().
"fips-indicator" (OSSL_CIPHER_PARAM_FIPS_APPROVED_INDICATOR) <entero>
Esta opción es utilizada por el proveedor FIPS de OpenSSL.

Un getter que devuelve 1 si la operación está aprobada por FIPS, o 0 en caso contrario. Esto puede usarse después de llamar a EVP_MAC_final(). Puede devolver 0 si la opción "encrypt-check" está establecida en 0.

VER TAMBIÉN
