EVP_PKEY-LMS(7ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY-LMS(7ssl) OpenSSL EVP_PKEY-LMS(7ssl)

NOMBRE

EVP_PKEY-LMS, EVP_KEYMGMT-LMS, LMS - Soporte de clave y algoritmo LMS (Leighton-Micali Signature) de EVP_PKEY

DESCRIPCIÓN

El tipo de clave LMS está implementado en los proveedores predeterminados y FIPS de OpenSSL. Los proveedores de OpenSSL solo admiten la verificación de firmas LMS, ya que este es un requisito de [SP 800-208](https://csrc.nist.gov/pubs/sp/800/208/final) para módulos de software FIPS.

Parámetros comunes LMS

Las claves públicas LMS se codifican en formato XDR (es decir, no en formato ASN1). Los siguientes parámetros son utilizados por EVP_PKEY_fromdata() y por el gestor de claves LMS para importación y exportación.

"pub" (OSSL_PKEY_PARAM_PUB_KEY) <cadena de octetos>
Se utiliza para obtener y establecer la codificación de una clave pública LMS. Se espera que la clave pública esté en formato XDR.

CONFORME A

NOTAS

El soporte de LMS está deshabilitado por defecto en el momento de la compilación. Para habilitarlo, especifique la opción de configuración de compilación enable-lms.

EJEMPLOS

NOTA: La comprobación de errores se ha omitido en estos ejemplos

Se puede obtener un contexto EVP_PKEY llamando a:

EVP_PKEY_CTX *ctx = EVP_PKEY_CTX_new_from_name(libctx, "LMS", propq);

Se puede cargar una clave pública LMS simplemente así:

EVP_PKEY *pkey = NULL;
OSSL_DECODER_CTX *dctx = NULL;
int selection = OSSL_KEYMGMT_SELECT_PUBLIC_KEY;
dctx = OSSL_DECODER_CTX_new_for_pkey(&pkey, "XDR", NULL,
                                     "LMS", selection, libctx, propq);
ret = OSSL_DECODER_from_bio(dctx, bio);
OSSL_DECODER_CTX_free(dctx);

Para cargar una clave LMS de datos XDR codificados "data" de tamaño "datalen":

EVP_PKEY *key = NULL;
OSSL_PARAM params[2];
params[0] =
    OSSL_PARAM_construct_octet_string(OSSL_PKEY_PARAM_ENCODED_PUBLIC_KEY,
                                      (unsigned char *)data, datalen);
params[1] = OSSL_PARAM_construct_end();
ret = EVP_PKEY_fromdata_init(ctx)
ret = EVP_PKEY_fromdata(ctx, &key, EVP_PKEY_PUBLIC_KEY, params);
