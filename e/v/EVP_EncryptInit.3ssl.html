NOTA

S

Siempre que sea posible, la interfaz EVP para cifrados simétricos debe usarse en lugar de las interfaces de bajo nivel. Esto se debe a que el código se vuelve transparente al cifrado utilizado y mucho más flexible. Además, la interfaz EVP garantizará el uso de la aceleración criptográfica específica de la plataforma como AES-NI (las interfaces de bajo nivel no proporcionan esta garantía)

.

El relleno PKCS funciona añadiendo n bytes de relleno de valor n para que la longitud total de los datos cifrados sea un múltiplo del tamaño del bloque. El relleno se añade siempre, por lo que si los datos ya son un múltiplo de el tamaño del bloque n será igual al tamaño del bloque. Por ejemplo, si el tamaño del bloque es 8 y se van a cifrar 11 bytes, se añadirán 5 bytes de relleno de valor

5.

Al descifrar, se comprueba el bloque final para ver si tiene la forma

correcta.

Aunque la operación de descifrado puede producir un error si el relleno está habilitado, no es una prueba sólida de que los datos de entrada o la clave sean correctos. Un bloque aleatorio tiene más de 1 entre 256 posibilidades de tener el formato correcto y los problemas con los datos de entrada anteriores no producirán un error de descifrado

final.

Si el relleno está deshabilitado, entonces la descLa operación de descifrado siempre tendrá éxito si la cantidad total de datos descifrados es un múltiplo del tamaño del

bloque.

int do_crypt(FILE *in, FILE *out, int do_encrypt)
{
    /* Permitir suficiente espacio en el buffer de salida para un bloque adicional */
    unsigned char inbuf[1024], outbuf[1024 + EVP_MAX_BLOCK_LENGTH];
    int inlen, outlen;
    EVP_CIPHER_CTX *ctx;
    /*
     * Clave e IV falsos: normalmente los estableceríamos desde
     * otra fuente.
     */
    unsigned char key[] = "0123456789abcdeF";
    unsigned char iv[] = "1234567887654321";
    /* No establecer la clave o el IV de inmediato; queremos verificar las longitudes */
    ctx = EVP_CIPHER_CTX_new();
    if (!EVP_CipherInit_ex2(ctx, EVP_aes_128_cbc(), NULL, NULL,
                            do_encrypt, NULL)) {
        /* Error */
        EVP_CIPHER_CTX_free(ctx);
        return 0;
    }
    OPENSSL_assert(EVP_CIPHER_CTX_get_key_length(ctx) == 16);
    OPENSSL_assert(EVP_CIPHER_CTX_get_iv_length(ctx) == 16);
    /* Ahora podemos establecer la clave y el IV */
    if (!EVP_CipherInit_ex2(ctx, NULL, key, iv, do_encrypt, NULL)) {
        /* Error */
        EVP_CIPHER_CTX_free(ctx);
        return 0;
    }
    for (;;) {
        inlen = fread(inbuf, 1, 1024, in);
        if (inlen <= 0)
            break;
        if (!EVP_CipherUpdate(ctx, outbuf, &outlen, inbuf, inlen)) {
            /* Error */
            EVP_CIPHER_CTX_free(ctx);
            return 0;
        }
        fwrite(outbuf, 1, outlen, out);
    }
    if (!EVP_CipherFinal_ex(ctx, outbuf, &outlen)) {
        /* Error */
        EVP_CIPHER_CTX_free(ctx);
        return 0;
    }
    fwrite(outbuf, 1, outlen, out);
    EVP_CIPHER_CTX_free(ctx);
    return 1;
}
