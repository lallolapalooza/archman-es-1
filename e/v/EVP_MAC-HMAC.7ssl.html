NOMBRE

EVP_MAC-HMAC - La implementación de EVP_MAC para HMAC

DESCRIPCIÓN

Soporte para calcular MACs HMAC a través de la API EVP_MAC.

Esta implementación utiliza funciones EVP_MD para acceder al digest subyacente.

Identidad

Esta implementación se identifica con este nombre y propiedades, para ser utilizada con EVP_MAC_fetch():

"HMAC", "provider=default" o "provider=fips"

Parámetros soportados

La descripción general de estos parámetros se puede encontrar en "PARÁMETROS" en EVP_MAC(3).

Los siguientes parámetros se pueden establecer con EVP_MAC_CTX_set_params():

"key" (OSSL_MAC_PARAM_KEY) <cadena de octetos>
Establece la clave MAC. Establecer este parámetro es idéntico a pasar una key a EVP_MAC_init(3).
"digest" (OSSL_MAC_PARAM_DIGEST) <cadena UTF8>
Establece el nombre del digest subyacente a ser utilizado.
"properties" (OSSL_MAC_PARAM_PROPERTIES) <cadena UTF8>
Establece las propiedades a consultar al intentar obtener el digest subyacente. Esto debe darse junto con el parámetro de nombre de digest ("digest", o OSSL_MAC_PARAM_DIGEST) para ser considerado válido.
"digest-noinit" (OSSL_MAC_PARAM_DIGEST_NOINIT) <entero>
Un indicador para establecer que el digest MAC no inicialice los datos específicos de la implementación. Se espera el valor 0 o 1. Esta opción está obsoleta y se eliminará en una futura versión. Puede ser establecida pero actualmente se ignora.
"digest-oneshot" (OSSL_MAC_PARAM_DIGEST_ONESHOT) <entero>
Un indicador para establecer que el digest MAC sea una operación de un solo disparo. Se espera el valor 0 o 1. Esta opción está obsoleta y se eliminará en una futura versión. Puede ser establecida pero actualmente se ignora.
"tls-data-size" (OSSL_MAC_PARAM_TLS_DATA_SIZE) <entero sin signo>
"key-check" (OSSL_MAC_PARAM_FIPS_KEY_CHECK) <entero>
Ver "Parámetros Mac" en provider-mac(7).

Los siguientes parámetros se pueden recuperar con EVP_MAC_CTX_get_params():

"size" (OSSL_MAC_PARAM_SIZE) <entero sin signo>
El parámetro "size" también se puede recuperar con EVP_MAC_CTX_get_mac_size(). La longitud del parámetro "size" es igual a la de un unsigned int.
"block-size" (OSSL_MAC_PARAM_BLOCK_SIZE) <entero sin signo>
Obtiene el tamaño del bloque MAC. El parámetro "block-size" también se puede recuperar con EVP_MAC_CTX_get_block_size().
"fips-indicator" (OSSL_KDF_PARAM_FIPS_APPROVED_INDICATOR) <entero>
Ver "Parámetros Mac" en provider-mac(7).

VER TAMBIÉN

EVP_MAC_CTX_get_params(3), EVP_MAC_CTX_set_params(3), "PARÁMETROS" en EVP_MAC(3), OSSL_PARAM(3), HMAC(3)
