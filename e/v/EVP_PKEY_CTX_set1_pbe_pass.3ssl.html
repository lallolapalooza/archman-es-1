NOMBRE

EVP_PKEY_CTX_set1_pbe_pass - funciones de soporte genéricas de KDF

SINÓPSIS

#include <openssl/kdf.h>
int EVP_PKEY_CTX_set1_pbe_pass(EVP_PKEY_CTX *pctx, unsigned char *pass,
                               int passlen);

DESCRIPCIÓN

Estas funciones son funciones de soporte genéricas para todos los algoritmos KDF.

EVP_PKEY_CTX_set1_pbe_pass() establece la contraseña en los passlen primeros bytes de pass.

CONTROLES DE CADENA

También hay soporte para operaciones de control basadas en cadenas a través de EVP_PKEY_CTX_ctrl_str(3). La contraseña se puede especificar directamente usando el parámetro "pass" de type o se puede proporcionar en codificación hexadecimal usando el parámetro "hexpass".

VALORES DE RETORNO

Todas estas funciones devuelven 1 para éxito y 0 o un valor negativo para fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

VER TAMBIÉN

EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_ctrl_str(3), EVP_PKEY_derive(3)

HISTORIAL

EVP_PKEY_CTX_set1_pbe_pass() fue convertida de una macro a una función en OpenSSL 3.0.
