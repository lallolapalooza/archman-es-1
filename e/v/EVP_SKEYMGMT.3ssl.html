EVP_SKEYMGMT(3ssl)

EVP_SKEYMGMT(3ssl) OpenSSL EVP_SKEYMGMT(3ssl)

NOMBRE

EVP_SKEYMGMT, EVP_SKEYMGMT_fetch, EVP_SKEYMGMT_up_ref, EVP_SKEYMGMT_free, EVP_SKEYMGMT_get0_provider, EVP_SKEYMGMT_is_a, EVP_SKEYMGMT_get0_description, EVP_SKEYMGMT_get0_name, EVP_SKEYMGMT_do_all_provided, EVP_SKEYMGMT_names_do_all, EVP_SKEYMGMT_get0_gen_settable_params, EVP_SKEYMGMT_get0_imp_settable_params - Rutinas de gestión de claves EVP para claves simétricas opacas

SINOPSIS

#include <openssl/evp.h>
typedef struct evp_sskeymgmt_st EVP_SKEYMGMT;
EVP_SKEYMGMT *EVP_SKEYMGMT_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                                 const char *properties);
int EVP_SKEYMGMT_up_ref(EVP_SKEYMGMT *skeymgmt);
void EVP_SKEYMGMT_free(EVP_SKEYMGMT *skeymgmt);
const OSSL_PROVIDER *EVP_SKEYMGMT_get0_provider(const EVP_SKEYMGMT *skeymgmt);
int EVP_SKEYMGMT_is_a(const EVP_SKEYMGMT *skeymgmt, const char *name);
const char *EVP_SKEYMGMT_get0_name(const EVP_SKEYMGMT *skeymgmt);
const char *EVP_SKEYMGMT_get0_description(const EVP_SKEYMGMT *skeymgmt);
void EVP_SKEYMGMT_do_all_provided(OSSL_LIB_CTX *libctx,
                                  void (*fn)(EVP_SKEYMGMT *skeymgmt, void *arg),
                                  void *arg);
int EVP_SKEYMGMT_names_do_all(const EVP_SKEYMGMT *skeymgmt,
                              void (*fn)(const char *name, void *data),
                              void *data);
const OSSL_PARAM *EVP_SKEYMGMT_get0_gen_settable_params(const EVP_SKEYMGMT *skeymgmt);
const OSSL_PARAM *EVP_SKEYMGMT_get0_imp_settable_params(const EVP_SKEYMGMT *skeymgmt);

DESCRIPCIÓN

EVP_SKEYMGMT es un objeto método que representa implementaciones de gestión de claves simétricas para diferentes algoritmos criptográficos. Este objeto método proporciona funcionalidad para permitir a los proveedores importar material de claves desde el exterior, así como exportar material de claves hacia el exterior.

La mayor parte de la funcionalidad solo puede usarse internamente y no tiene interfaz pública; este objeto opaco simplemente se pasa a otras funciones cuando es necesario.

EVP_SKEYMGMT_fetch() busca un algoritmo dentro de un proveedor que haya sido cargado en el OSSL_LIB_CTX dado por ctx, teniendo el nombre dado por algorithm y las propiedades dadas por properties.

EVP_SKEYMGMT_up_ref() incrementa el recuento de referencias para el EVP_SKEYMGMT skeymgmtdado.

EVP_SKEYMGMT_free() decrementa el recuento de referencias para el EVP_SKEYMGMT skeymgmtdado, y cuando el recuento llega a cero, lo libera. Si el argumento es NULL, no se hace nada.

EVP_SKEYMGMT_get0_provider() devuelve el proveedor que tiene esta implementación en particular.

EVP_SKEYMGMT_is_a() comprueba si skeymgmt es una implementación de un algoritmo que es identificado por name.

EVP_SKEYMGMT_get0_name() devuelve el nombre del algoritmo de la implementación proporcionada para el skeymgmtdado. Tenga en cuenta que el skeymgmt puede tener múltiples sinónimos asociados con él. En este caso, se devuelve el primer nombre de la definición del algoritmo. La propiedad de la cadena devuelta es retenida por el skeymgmt objeto y no debe ser liberada por el llamador.

EVP_SKEYMGMT_names_do_all() recorre todos los nombres para el skeymgmt, y llama a fn con cada nombre y data.

EVP_SKEYMGMT_get0_description() devuelve una descripción del skeymgmt, destinada a la visualización y consumo humano. La descripción queda a discreción de la implementación del skeymgmt .

EVP_SKEYMGMT_do_all_provided() recorre todas las implementaciones de gestión de claves skeymgmt de todos los proveedores activados en el contexto de la biblioteca libctx, y para cada una de las implementaciones, llama a fn con el método de implementación y data como argumentos.

EVP_SKEYMGMT_get0_gen_settable_params() y EVP_SKEYMGMT_get0_imp_settable_params() obtienen una constante OSSL_PARAM(3) array que describe los parámetros configurables que pueden usarse con EVP_SKEY_generate() y EVP_SKEY_import() correspondientemente.

NOTAS

EVP_SKEYMGMT_fetch() puede ser llamado implícitamente por otras funciones de obtención, usando el mismo contexto de biblioteca y propiedades. Cualquier otra API que use claves simétricas típicamente hará esto.

VALORES DE RETORNO

EVP_SKEYMGMT_fetch() devuelve un puntero a la implementación de gestión de claves representada por un objeto EVP_SKEYMGMT, o NULL en caso de error.

EVP_SKEYMGMT_up_ref() devuelve 1 en caso de éxito, o 0 en caso de error.

EVP_SKEYMGMT_names_do_all() devuelve 1 si la función de retorno de llamada fue llamada para todos los nombres. Un valor de retorno de 0 significa que la función de retorno de llamada no fue llamada para ningún nombre.

EVP_SKEYMGMT_free() no devuelve ningún valor.

EVP_SKEYMGMT_get0_provider() devuelve un puntero a un objeto proveedor, o NULL en caso de error.

EVP_SKEYMGMT_is_a() devuelve 1 si skeymgmt fue identificable, de lo contrario 0.

EVP_SKEYMGMT_get0_name() devuelve el nombre del algoritmo, o NULL en caso de error.

EVP_SKEYMGMT_get0_description() devuelve un puntero a una descripción, o NULL si no hay una.
