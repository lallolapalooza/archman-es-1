DESCRIPCIÓN

EVP_PKEY_ASN1_METHOD es una estructura que contiene un conjunto de métodos de conversión, impresión e información ASN.1 para un algoritmo de clave pública específico.

Hay dos lugares donde se almacenan los objetos EVP_PKEY_ASN1_METHOD : uno es un array incorporado que representa los métodos estándar para diferentes algoritmos, y el otro es una pila de métodos específicos de la aplicación definidos por el usuario, que pueden manipularse utilizando EVP_PKEY_asn1_add0(3).

Métodos

Los métodos son las implementaciones subyacentes de un algoritmo de clave pública en particular presentado por el objeto EVP_PKEY .

int (*pub_decode) (EVP_PKEY *pk, const X509_PUBKEY *pub);
int (*pub_encode) (X509_PUBKEY *pub, const EVP_PKEY *pk);
int (*pub_cmp) (const EVP_PKEY *a, const EVP_PKEY *b);
int (*pub_print) (BIO *out, const EVP_PKEY *pkey, int indent,
                  ASN1_PCTX *pctx);

Los métodos pub_decode() y pub_encode() se llaman para decodificar / codificar los parámetros ASN.1 de X509_PUBKEY a / desde pk. DEBEN devolver 0 en caso de error y 1 en caso de éxito. Son llamados por X509_PUBKEY_get0(3) y X509_PUBKEY_set(3).

El método pub_cmp() se llama cuando se van a comparar dos claves públicas. DEBE devolver 1 cuando las claves son iguales, y 0 en caso contrario. Es llamado por EVP_PKEY_eq(3).

El método pub_print() se llama para imprimir una clave pública en texto legible para humanos en out, con una sangría de indent espacios. DEBE devolver 0 en caso de error y 1 en caso de éxito. Es llamado por EVP_PKEY_print_public(3).
