EVP_PKEY_CTX_set_scrypt_N(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_CTX_SET_SCRYPT_N(3ssl) OpenSSL EVP_PKEY_CTX_SET_SCRYPT_N(3ssl)

NOMBRE

EVP_PKEY_CTX_set1_scrypt_salt, EVP_PKEY_CTX_set_scrypt_N, EVP_PKEY_CTX_set_scrypt_r, EVP_PKEY_CTX_set_scrypt_p, EVP_PKEY_CTX_set_scrypt_maxmem_bytes - Funciones de soporte de scrypt KDF EVP_PKEY

SINOPSIS

#include <openssl/kdf.h>
int EVP_PKEY_CTX_set1_scrypt_salt(EVP_PKEY_CTX *pctx, unsigned char *salt,
                                  int saltlen);
int EVP_PKEY_CTX_set_scrypt_N(EVP_PKEY_CTX *pctx, uint64_t N);
int EVP_PKEY_CTX_set_scrypt_r(EVP_PKEY_CTX *pctx, uint64_t r);
int EVP_PKEY_CTX_set_scrypt_p(EVP_PKEY_CTX *pctx, uint64_t p);
int EVP_PKEY_CTX_set_scrypt_maxmem_bytes(EVP_PKEY_CTX *pctx,
                                         uint64_t maxmem);

DESCRIPCIÓN

Estas funciones se utilizan para configurar los datos necesarios para utilizar el KDF scrypt. Para más información sobre scrypt, véase EVP_KDF-SCRYPT(7).

EVP_PKEY_CTX_set1_scrypt_salt() establece el valor de salt de longitud saltlen.

EVP_PKEY_CTX_set_scrypt_N(), EVP_PKEY_CTX_set_scrypt_r() y EVP_PKEY_CTX_set_scrypt_p() configuran los factores de trabajo N, r y p.

EVP_PKEY_CTX_set_scrypt_maxmem_bytes() establece la cantidad máxima de RAM que la derivación de clave puede utilizar, en bytes. Si se supera la RAM debido a que los factores de carga se eligen demasiado altos, la derivación de clave fallará.

CONTROLES DE CADENA

scrypt también soporta operaciones de control basadas en cadenas a través de EVP_PKEY_CTX_ctrl_str(3). Del mismo modo, el salt puede especificarse utilizando el parámetro type "salt" o en codificación hexadecimal utilizando el parámetro "hexsalt". Los factores de trabajo N, r y p, así como maxmem_bytes, se pueden establecer utilizando los parámetros "N", "r", "p" y "maxmem_bytes", respectivamente.

NOTAS

Existe una API genérica más nueva para KDFs, EVP_KDF(3), que es preferible al método EVP_PKEY.

El KDF scrypt también utiliza EVP_PKEY_CTX_set1_pbe_pass(), así como el valor de los controles de cadena "pass" y "hexpass". Véase EVP_PKEY_CTX_set1_pbe_pass(3).

VALORES DE RETORNO

Todas estas funciones devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

VER TAMBIÉN

EVP_KDF(3) EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_ctrl_str(3), EVP_PKEY_derive(3)
