EVP_PKEY_CTX_set_rsa_pss_keygen_md(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_CTX_SET_RSA_PSS_KEYGEN_MD(3ssl) OpenSSL EVP_PKEY_CTX_SET_RSA_PSS_KEYGEN_MD(3ssl)

NOMBRE

EVP_PKEY_CTX_set_rsa_pss_keygen_md, EVP_PKEY_CTX_set_rsa_pss_keygen_md_name, EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md, EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md_name, EVP_PKEY_CTX_set_rsa_pss_keygen_saltlen - Funciones de soporte del algoritmo RSA-PSS de EVP_PKEY

SINOPSIS

#include <openssl/rsa.h>
int EVP_PKEY_CTX_set_rsa_pss_keygen_md(EVP_PKEY_CTX *pctx,
                                       const EVP_MD *md);
int EVP_PKEY_CTX_set_rsa_pss_keygen_md_name(EVP_PKEY_CTX *ctx,
                                            const char *mdname,
                                            const char *mdprops);
int EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md(EVP_PKEY_CTX *pctx,
                                            const EVP_MD *md);
int EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md_name(EVP_PKEY_CTX *pctx,
                                                 const char *mdname);
int EVP_PKEY_CTX_set_rsa_pss_keygen_saltlen(EVP_PKEY_CTX *pctx,
                                            int saltlen);

DESCRIPCIÓN

Estas son las funciones que implementan RSA-PSS(7).

Firma y Verificación

Se admite la macro EVP_PKEY_CTX_set_rsa_padding(), pero se devuelve un error si se intenta establecer el modo de relleno en algo distinto de PSS. Por lo demás, es similar a la versión de RSA.

La macro EVP_PKEY_CTX_set_rsa_pss_saltlen() se utiliza para establecer la longitud de la sal. Si la clave tiene restricciones de uso, se devuelve un error si se intenta establecer la longitud de la sal por debajo del valor mínimo. Por lo demás, es similar a la operación de RSA, excepto que la detección de la longitud de la sal (usando RSA_PSS_SALTLEN_AUTO) no se admite para la verificación si la clave tiene restricciones de uso.

Las funciones EVP_PKEY_CTX_set_signature_md(3) y EVP_PKEY_CTX_set_rsa_mgf1_md(3) se utilizan para establecer los algoritmos de resumen y MGF1 respectivamente. Si la clave tiene restricciones de uso, se devuelve un error si se intenta establecer el resumen en algo distinto del valor restringido. De lo contrario, son similares a las versiones de RSA.

Generación de Claves

Al igual que con la generación de claves RSA, las macros EVP_PKEY_CTX_set_rsa_keygen_bits() y EVP_PKEY_CTX_set_rsa_keygen_pubexp() son compatibles con RSA-PSS: tienen exactamente el mismo significado que para el algoritmo RSA.

Se pueden especificar restricciones de parámetros opcionales al generar una clave PSS. Si se establecen restricciones (utilizando las macros descritas a continuación), entonces todos los parámetros están restringidos. Por ejemplo, establecer una longitud mínima de sal también restringe los algoritmos de resumen y MGF1. Si existen restricciones, estas se reflejan en los parámetros correspondientes de la clave pública cuando (por ejemplo) se firma una solicitud de certificado.

EVP_PKEY_CTX_set_rsa_pss_keygen_md() restringe el algoritmo de resumen que puede utilizar la clave generada a md. EVP_PKEY_CTX_set_rsa_pss_keygen_md_name() hace lo mismo, pero pasa el algoritmo por nombre en lugar de por EVP_MD.

EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md() restringe el algoritmo MGF1 que puede utilizar la clave generada a md. EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md_name() hace lo mismo, pero pasa el algoritmo por nombre en lugar de por EVP_MD.

EVP_PKEY_CTX_set_rsa_pss_keygen_saltlen() restringe la longitud mínima de la sal a saltlen.

NOTAS

Se puede obtener un contexto para el algoritmo RSA-PSS llamando a:

EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_RSA_PSS, NULL);

VALORES DEVUELTOS

Todas estas funciones devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.
