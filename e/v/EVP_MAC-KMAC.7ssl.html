EVP_MAC-KMAC(7ssl)

Paquete: openssl

EVP_MAC-KMAC(7ssl) OpenSSL EVP_MAC-KMAC(7ssl)

NOMBRE

EVP_MAC-KMAC, EVP_MAC-KMAC128, EVP_MAC-KMAC256 - Las implementaciones de KMAC EVP_MAC

DESCRIPCIÓN

Soporte para el cálculo de MACs KMAC a través de la API EVP_MAC.

Identidad

Estas implementaciones se identifican con uno de estos nombres y propiedades, para ser utilizados con EVP_MAC_fetch():

"KMAC-128", "provider=default" o "provider=fips"
"KMAC-256", "provider=default" o "provider=fips"

Parámetros soportados

La descripción general de estos parámetros se puede encontrar en "PARÁMETROS" en EVP_MAC(3).

Todos estos parámetros (excepto "block-size") se pueden establecer con EVP_MAC_CTX_set_params(). Además, el parámetro "size" se puede recuperar con EVP_MAC_CTX_get_params() o con EVP_MAC_CTX_get_mac_size(). La longitud del parámetro "size" no debe exceder la de un size_t. De manera similar, el parámetro "block-size" se puede recuperar con EVP_MAC_CTX_get_params() o con EVP_MAC_CTX_get_block_size().

"key" (OSSL_MAC_PARAM_KEY) <cadena de octetos>
Establece la clave MAC. Establecer este parámetro es idéntico a pasar una key a EVP_MAC_init(3). La longitud de la clave (en bytes) debe estar en el rango 4...512.
"custom" (OSSL_MAC_PARAM_CUSTOM) <cadena de octetos>
Establece la cadena de personalización. Es un valor opcional con una longitud máxima de 512 bytes, y está vacío por defecto.
"size" (OSSL_MAC_PARAM_SIZE) <entero sin signo>
Establece el tamaño del MAC. Por defecto, es 32 para "KMAC-128" y 64 para "KMAC-256".
"block-size" (OSSL_MAC_PARAM_BLOCK_SIZE) <entero sin signo>
Obtiene el tamaño del bloque MAC. Es 168 para "KMAC-128" y 136 para "KMAC-256".
"xof" (OSSL_MAC_PARAM_XOF) <entero>
Se espera que el valor del parámetro "xof" sea 1 o 0. Use 1 para habilitar el modo XOF. El valor por defecto es 0.
"fips-indicator" (OSSL_MAC_PARAM_FIPS_APPROVED_INDICATOR) <int>
Este parámetro configurable se describe en provider-mac(7).
"no-short-mac" (OSSL_MAC_PARAM_FIPS_NO_SHORT_MAC) <entero>
Este parámetro configurable se describe en provider-mac(7). Lo utiliza el proveedor FIPS de OpenSSL y la longitud mínima de salida para KMAC está definida por SP 800-185 8.4.2 de NIST.
"key-check" (OSSL_MAC_PARAM_FIPS_KEY_CHECK) <entero>
Este parámetro configurable se describe en provider-mac(7).

Los parámetros "custom" y "no-short-mac" deben establecerse como parte de o antes de la llamada a EVP_MAC_init(). Los parámetros "xof" y "size" se pueden establecer en cualquier momento antes de EVP_MAC_final(). El parámetro "key" se establece como parte de la llamada a EVP_MAC_init(), pero puede establecerse antes de él en su lugar.

EJEMPLOS

#include <openssl/evp.h>
#include <openssl/params.h>
static int do_kmac(const unsigned char *in, size_t in_len,
                   const unsigned char *key, size_t key_len,
                   const unsigned char *custom, size_t custom_len,
                   int xof_enabled, unsigned char *out, int out_len)
{
    EVP_MAC_CTX *ctx = NULL;
    EVP_MAC *mac = NULL;
    OSSL_PARAM params[4], *p;
    int ret = 0;
    size_t l = 0;
    mac = EVP_MAC_fetch(NULL, "KMAC-128", NULL);
    if (mac == NULL)
        goto err;
    ctx = EVP_MAC_CTX_new(mac);
    /* El mac se puede liberar después de ser utilizado por EVP_MAC_CTX_new */
    EVP_MAC_free(mac);
    if (ctx == NULL)
        goto err;
    /*
     * Configurar parámetros requeridos antes de llamar a EVP_MAC_init()
     * Los parámetros OSSL_MAC_PARAM_XOF y OSSL_MAC_PARAM_SIZE también se pueden
     * usar en este punto.
     */
    p = params;
    *p++ = OSSL_PARAM_construct_octet_string(OSSL_MAC_PARAM_KEY,
                                             (void *)key, key_len);
    if (custom != NULL && custom_len != 0)
      *p++ = OSSL_PARAM_construct_octet_string(OSSL_MAC_PARAM_CUSTOM,
                                               (void *)custom, custom_len);
    *p = OSSL_PARAM_construct_end();
    if (!EVP_MAC_CTX_set_params(ctx, params))
        goto err;
    if (!EVP_MAC_init(ctx))
        goto err;
    /*
     * Nota: los siguientes parámetros opcionales se pueden establecer en cualquier momento
     * antes de EVP_MAC_final().
     */
    p = params;
    *p++ = OSSL_PARAM_construct_int(OSSL_MAC_PARAM_XOF, &xof_enabled);
    *p++ = OSSL_PARAM_construct_int(OSSL_MAC_PARAM_SIZE, &out_len);
    *p = OSSL_PARAM_construct_end();
    if (!EVP_MAC_CTX_set_params(ctx, params))
        goto err;
    /* La actualización puede llamarse varias veces aquí para entrada en streaming */
    if (!EVP_MAC_update(ctx, in, in_len))
        goto err;
    if (!EVP_MAC_final(ctx, out, &l, out_len))
        goto err;
    ret = 1;
err:
    EVP_MAC_CTX_free(ctx);
    return ret;
}
