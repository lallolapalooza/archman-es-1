NOMBRE

Event::ExecFlow::Job::Command - Comando externo para ejecución asíncrona

SINOPSIS

Event::ExecFlow::Job::Command->new (
  command              => Comando de shell a ejecutar,
  fetch_output         => Booleano si se debe obtener la salida,
  progress_parser      => Una clausura o expresión regular para el análisis del progreso,
  configure_callback   => Una clausura para configurar el comando
                          antes de la ejecución,
  ...
  atributos de Event::ExecFlow::Job
);

DESCRIPCIÓN

Use este módulo para la ejecución asíncrona de un comando externo con Event::ExecFlow.
