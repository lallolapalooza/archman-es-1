EVP_sha3_224(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_SHA3_224(3ssl) OpenSSL EVP_SHA3_224(3ssl)

NOMBRE

EVP_sha3_224, EVP_sha3_256, EVP_sha3_384, EVP_sha3_512, EVP_shake128, EVP_shake256 - SHA-3 para EVP

SINOPSIS

#include <openssl/evp.h>
const EVP_MD *EVP_sha3_224(void);
const EVP_MD *EVP_sha3_256(void);
const EVP_MD *EVP_sha3_384(void);
const EVP_MD *EVP_sha3_512(void);
const EVP_MD *EVP_shake128(void);
const EVP_MD *EVP_shake256(void);

DESCRIPCIÓN

SHA-3 (Secure Hash Algorithm 3) es una familia de funciones de hash criptográficas estandarizadas en NIST FIPS 202, publicadas por primera vez en 2015. Se basa en el algoritmo Keccak.

EVP_sha3_224(), EVP_sha3_256(), EVP_sha3_384(), EVP_sha3_512()
Los algoritmos SHA-3 SHA-3-224, SHA-3-256, SHA-3-384 y SHA-3-512 respectivamente. Producen 224, 256, 384 y 512 bits de salida a partir de una entrada dada.
EVP_shake128(), EVP_shake256()
Las Funciones de Salida Extensible (XOF) SHAKE-128 y SHAKE-256 que pueden generar una longitud de hash variable.

Específicamente, EVP_shake128 proporciona una seguridad general de 128 bits, mientras que EVP_shake256 proporciona una de 256 bits.

NOTAS

Los desarrolladores deben tener en cuenta las implicaciones negativas de rendimiento al llamar a estas funciones varias veces y deberían considerar usar EVP_MD_fetch(3) con EVP_MD-SHA3(7) o EVP_MD-SHAKE(7) en su lugar. Ver "Rendimiento" en crypto(7) para más información.

VALORES DEVUELTOS

Estas funciones devuelven una estructura EVP_MD que contiene la implementación del resumen del mensaje. Ver EVP_MD_meth_new(3) para detalles de la estructura EVP_MD.

CONFORMIDAD

NIST FIPS 202.

VER TAMBIÉN

evp(7), EVP_DigestInit(3)
