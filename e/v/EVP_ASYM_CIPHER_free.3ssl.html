EVP_ASYM_CIPHER_free(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_ASYM_CIPHER_FREE(3ssl) OpenSSL EVP_ASYM_CIPHER_FREE(3ssl)

NOMBRE

EVP_ASYM_CIPHER_fetch, EVP_ASYM_CIPHER_free, EVP_ASYM_CIPHER_up_ref, EVP_ASYM_CIPHER_is_a, EVP_ASYM_CIPHER_get0_provider, EVP_ASYM_CIPHER_do_all_provided, EVP_ASYM_CIPHER_names_do_all, EVP_ASYM_CIPHER_get0_name, EVP_ASYM_CIPHER_get0_description, EVP_ASYM_CIPHER_gettable_ctx_params, EVP_ASYM_CIPHER_settable_ctx_params - Funciones para gestionar objetos de algoritmos EVP_ASYM_CIPHER

SINOPSIS

#include <openssl/evp.h>
EVP_ASYM_CIPHER *EVP_ASYM_CIPHER_fetch(OSSL_LIB_CTX *ctx, const char *algorithm,
                                       const char *properties);
void EVP_ASYM_CIPHER_free(EVP_ASYM_CIPHER *cipher);
int EVP_ASYM_CIPHER_up_ref(EVP_ASYM_CIPHER *cipher);
const char *EVP_ASYM_CIPHER_get0_name(const EVP_ASYM_CIPHER *cipher);
int EVP_ASYM_CIPHER_is_a(const EVP_ASYM_CIPHER *cipher, const char *name);
OSSL_PROVIDER *EVP_ASYM_CIPHER_get0_provider(const EVP_ASYM_CIPHER *cipher);
void EVP_ASYM_CIPHER_do_all_provided(OSSL_LIB_CTX *libctx,
                                     void (*fn)(EVP_ASYM_CIPHER *cipher,
                                                void *arg),
                                     void *arg);
int EVP_ASYM_CIPHER_names_do_all(const EVP_ASYM_CIPHER *cipher,
                                 void (*fn)(const char *name, void *data),
                                 void *data);
const char *EVP_ASYM_CIPHER_get0_description(const EVP_ASYM_CIPHER *cipher);
const OSSL_PARAM *EVP_ASYM_CIPHER_gettable_ctx_params(const EVP_ASYM_CIPHER *cip);
const OSSL_PARAM *EVP_ASYM_CIPHER_settable_ctx_params(const EVP_ASYM_CIPHER *cip);

DESCRIPCIÓN

EVP_ASYM_CIPHER_fetch() obtiene la implementación para el algoritmo dado de cualquier proveedor que lo ofrezca, dentro de los criterios dados por las properties y en el ámbito del contexto de biblioteca dado ctx (ver OSSL_LIB_CTX(3)). El algoritmo ofrecerá funciones para realizar tareas relacionadas con cifrados asimétricos, como cifrado y descifrado asimétrico. Ver "FETCHING DE ALGORITMOS" en crypto(7) para más información.

El valor devuelto debe liberarse eventualmente con EVP_ASYM_CIPHER_free().

EVP_ASYM_CIPHER_free() decrementa el contador de referencias para la estructura EVP_ASYM_CIPHER. Típicamente, esta estructura se habrá obtenido de una llamada anterior a EVP_ASYM_CIPHER_fetch(). Si el contador de referencias cae a 0, se libera la estructura. Si el argumento es NULL, no se hace nada.

EVP_ASYM_CIPHER_up_ref() incrementa el contador de referencias para una estructura EVP_ASYM_CIPHER.

EVP_ASYM_CIPHER_is_a() devuelve 1 si cipher es una implementación de un algoritmo que se puede identificar con name, de lo contrario devuelve 0.

EVP_ASYM_CIPHER_get0_provider() devuelve el proveedor desde el que se obtuvo cipher.

EVP_ASYM_CIPHER_do_all_provided() recorre todos los EVP_ASYM_CIPHER implementados por todos los proveedores activados en el contexto de biblioteca dado libctx, y para cada una de las implementaciones, llama a la función dada fn con el método de implementación y el arg dado como argumento.

EVP_ASYM_CIPHER_get0_name() devuelve el nombre del algoritmo de la implementación proporcionada para el cipher dado. Tenga en cuenta que el cipher puede tener varios sinónimos asociados. En este caso, se devuelve el primer nombre de la definición del algoritmo. La propiedad de la cadena devuelta la conserva el objeto cipher y el llamador no debe liberarla.

EVP_ASYM_CIPHER_names_do_all() recorre todos los nombres para cipher y llama a fn con cada nombre y data.

EVP_ASYM_CIPHER_get0_description() devuelve una descripción del cipher, destinada a ser mostrada y consumida por humanos. La descripción queda a discreción de la implementación del cipher.

EVP_ASYM_CIPHER_gettable_ctx_params() y EVP_ASYM_CIPHER_settable_ctx_params() devuelven un array constante de OSSL_PARAM(3) que describe los nombres y tipos de parámetros clave que se pueden recuperar o establecer mediante un algoritmo de cifrado de clave usando EVP_PKEY_CTX_get_params(3) y EVP_PKEY_CTX_set_params(3).

VALORES DE RETORNO

EVP_ASYM_CIPHER_fetch() devuelve un puntero a un EVP_ASYM_CIPHER en caso de éxito o NULL en caso de error.

EVP_ASYM_CIPHER_up_ref() devuelve 1 en caso de éxito o 0 en caso contrario.

EVP_ASYM_CIPHER_names_do_all() devuelve 1 si la función de llamada se ejecutó para todos los nombres. Un valor de retorno de 0 significa que la función de llamada no se ejecutó para ningún nombre.

EVP_ASYM_CIPHER_gettable_ctx_params() y EVP_ASYM_CIPHER_settable_ctx_params() devuelven un array constante de OSSL_PARAM(3) o NULL en caso de error.

VER TAMBIÉN

"FETCHING DE ALGORITMOS" en crypto(7), OSSL_PROVIDER(3)

HISTORIA
