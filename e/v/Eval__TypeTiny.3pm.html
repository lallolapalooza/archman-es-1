Este módulo es utilizado por Type::Tiny para compilar referencias a subrutinas a partir de cadenas de código Perl, y hashes de variables para cerrar sobre

ellas.

Funcione

s

Por defecto este módulo exporta una función, que funciona de manera muy similar a la función del mismo nombre de Eval::

Closure:
"eval_closure(source => $source, environment => \%env, %opt)
"

Otras funciones pueden ser importadas bajo

petición:
"set_subname( $fully_qualified_name, $coderef
)"
Funciona como la función del mismo nombre de Sub::Util, pero recurrirá a no hacer nada si ni Sub::Util ni Sub::Name están disponibles. También se negará cobardemente a establecer el nombre de una referencia a subrutina por segunda vez si ya tiene un
nombre.
"type_to_coderef( $type, %options
)"
Convierte un objeto Type::Tiny en una referencia a subrutina, adecuada para instalar en una tabla de símbolos para crear una función como "ArrayRef" o "Int". (En realidad debería funcionar para cualquier objeto que proporcione los métodos "is_parameterizable", "parameterize", y

"qualified_name", como Type::Coercion.) $options{post_method} puede ser una cadena de Perl que indica un método a llamar en la restricción de tipo

antes de devolverla. Por ejemplo

'->moose_t

$options{description} puede ser una descripción de la referencia a subrutina que puede mostrarse en trazas de pila, etc. La referencia a subrutina será nombrada usando "set_subname" a menos

que

$options{anonymous} sea verdadero. Si $type es undef, entonces se asume que la restricción de tipo no ha sido definida todavía pero lo será más adelante, sin embargo aún se desea una función ahora. $options

ENTORNO DE

EVALUACIÓN

La evaluación se realiza en presencia de strict, pero en ausencia de warnings. (Esto es diferente a Eval::Closure, que habilita warnings para los closures compilados.

)

El pragma feature no está activo en el entorno de evaluación, así que lo siguiente no

funcionará: 
use feature qw(say);
use Eval::TypeTiny qw(eval_closure);

my $say_all = eval_closure(
   source => 'sub { say for @_ }',
);
$say_all->("Hello", "World")
;

El pragma feature no se "transfiere" al eval de cadena. Por supuesto, es posible importar pragmas en la cadena evaluada como parte de la propia

cadena: 
use Eval::TypeTiny qw(eval_closure);

my $say_all =
eval_closure( source => 'sub { use feature qw(sa
y); say for @_ }', ); $say_all->("Hello", "World");
