EVP_PKEY_set_type(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_SET_TYPE(3ssl) OpenSSL EVP_PKEY_SET_TYPE(3ssl)

NOMBRE

EVP_PKEY_set_type, EVP_PKEY_set_type_str, EVP_PKEY_set_type_by_keymgmt - funciones para cambiar el tipo de EVP_PKEY

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_set_type(EVP_PKEY *pkey, int type);
int EVP_PKEY_set_type_str(EVP_PKEY *pkey, const char *str, int len);
int EVP_PKEY_set_type_by_keymgmt(EVP_PKEY *pkey, EVP_KEYMGMT *keymgmt);

DESCRIPCIÓN

Todas las funciones descritas aquí se comportan de la misma manera en el sentido de que borran todos los datos y métodos de clave previos de pkey, y lo reinician para que sea del tipo de clave dado por los diferentes argumentos. Si pkey es NULL, estas funciones aún devolverán los mismos valores de retorno que si no lo fuera.

EVP_PKEY_set_type() inicializa pkey para contener una clave interna heredada. Al hacer esto, encuentra un EVP_PKEY_ASN1_METHOD(3) correspondiente a type y asocia pkey con los hallazgos. Es un error si no se pudo encontrar un EVP_PKEY_ASN1_METHOD(3) para type.

EVP_PKEY_set_type_str() inicializa pkey para contener una clave interna heredada. Al hacer esto, encuentra un EVP_PKEY_ASN1_METHOD(3) correspondiente a str que tiene la longitud len, y asocia pkey con los hallazgos. Es un error si no se pudo encontrar un EVP_PKEY_ASN1_METHOD(3) para type.

Tanto para EVP_PKEY_set_type() como para EVP_PKEY_set_type_str(), pkey obtiene un tipo numérico, que puede ser recuperado con EVP_PKEY_get_id(3). Este tipo numérico se toma del EVP_PKEY_ASN1_METHOD(3) que se encontró, y es igual o está estrechamente relacionado con type en el caso de EVP_PKEY_set_type(), o relacionado con str en el caso de EVP_PKEY_set_type_str().

EVP_PKEY_set_type_by_keymgmt() inicializa pkey para contener una clave interna del lado del proveedor. Al hacer esto, asocia pkey con keymgmt. Para las claves inicializadas de esta manera, el tipo numérico recuperado con EVP_PKEY_get_id(3) siempre será EVP_PKEY_NONE.

VALORES DE RETORNO

Todas las funciones descritas devuelven 1 si tienen éxito, o 0 en caso de error.

VER TAMBIÉN
