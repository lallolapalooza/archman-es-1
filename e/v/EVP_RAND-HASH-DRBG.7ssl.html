NOMBRE

EVP_RAND-HASH-DRBG - La implementación EVP_RAND de HASH-DRBG

DESCRIPCIÓN

Soporte para el generador de bits aleatorios determinista de hash a través de la API EVP_RAND.

Identidad

"HASH-DRBG" es el nombre de esta implementación; se puede usar con la función EVP_RAND_fetch().

Parámetros soportados

Los parámetros soportados son:

"state" (OSSL_RAND_PARAM_STATE) <entero>
"strength" (OSSL_RAND_PARAM_STRENGTH) <entero sin signo>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <entero sin signo>
"reseed_requests" (OSSL_DRBG_PARAM_RESEED_REQUESTS) <entero sin signo>
"reseed_time_interval" (OSSL_DRBG_PARAM_RESEED_TIME_INTERVAL) <entero>
"min_entropylen" (OSSL_DRBG_PARAM_MIN_ENTROPYLEN) <entero sin signo>
"max_entropylen" (OSSL_DRBG_PARAM_MAX_ENTROPYLEN) <entero sin signo>
"min_noncelen" (OSSL_DRBG_PARAM_MIN_NONCELEN) <entero sin signo>
"max_noncelen" (OSSL_DRBG_PARAM_MAX_NONCELEN) <entero sin signo>
"max_perslen" (OSSL_DRBG_PARAM_MAX_PERSLEN) <entero sin signo>
"max_adinlen" (OSSL_DRBG_PARAM_MAX_ADINLEN) <entero sin signo>
"reseed_counter" (OSSL_DRBG_PARAM_RESEED_COUNTER) <entero sin signo>
"properties" (OSSL_DRBG_PARAM_PROPERTIES) <cadena UTF8>
"digest" (OSSL_DRBG_PARAM_DIGEST) <cadena UTF8>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_RAND(3).
"fips-indicator" (OSSL_DRBG_PARAM_FIPS_APPROVED_INDICATOR) <entero>
"digest-check" (OSSL_DRBG_PARAM_FIPS_DIGEST_CHECK) <entero>
Estos parámetros funcionan como se describe en "PARÁMETROS" en provider-rand(7).

NOTAS

Cuando el proveedor FIPS se instala utilizando la opción -no_drbg_truncated_digests para fipsinstall, solo se permiten estos digests (según FIPS 140-3 IG D.R https://csrc.nist.gov/CSRC/media/Projects/cryptographic-module-validation-program/documents/fips%20140-3/FIPS%20140-3%20IG.pdf):

La implementación predeterminada de HASH-DRBG intenta obtener los algoritmos internos requeridos del proveedor en el que están integrados (por ejemplo, el proveedor predeterminado), independientemente de las propiedades proporcionadas. Si el proveedor no implementa los algoritmos requeridos, se usarán propiedades para encontrar una implementación diferente.

SHA-1
SHA2-256
SHA2-512
SHA3-256
SHA3-512

Se puede obtener un contexto para HASH DRBG llamando a:

EVP_RAND *rand = EVP_RAND_fetch(NULL, "HASH-DRBG", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

EJEMPLOS

EVP_RAND *rand;
EVP_RAND_CTX *rctx;
unsigned char bytes[100];
OSSL_PARAM params[2], *p = params;
unsigned int strength = 128;
rand = EVP_RAND_fetch(NULL, "HASH-DRBG", NULL);
rctx = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_free(rand);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_DRBG_PARAM_DIGEST, SN_sha512, 0);
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);

Para obtener detalles, consulte FIPS 140-3 IG D.R https://csrc.nist.gov/CSRC/media/Projects/cryptographic-module-validation-program/documents/fips%20140-3/FIPS%20140-3%20IG.pdf.
