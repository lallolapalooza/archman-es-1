Eval::TypeTiny::CodeAccumulator(3) Documentación de Perl contribuida por el usuario Eval::TypeTiny::CodeAccumulator(3)

NOMBRE

Eval::TypeTiny::CodeAccumulator - API alternativa para Eval::TypeTiny

SINOPSIS

my $make_adder = 'Eval::TypeTiny::CodeAccumulator'->new(
  description => 'adder',
);

my $n = 40;
my $varname = $make_adder->add_variable( '$addend' => \$n );

$make_adder->add_line( 'sub {' );
$make_adder->increase_indent;
$make_adder->add_line( 'my $other_addend = shift;' );
$make_adder->add_gap;
$make_adder->add_line( 'return ' . $varname . ' + $other_addend;' );
$make_adder->decrease_indent;
$make_adder->add_line( '}' );

my $adder = $make_adder->compile;

say $adder->( 2 );  ## ==> 42

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCION

Constructor

new( %attrs )
El único atributo actualmente soportado es "description".

Métodos

env()
Devuelve el entorno de compilación actual, un hashref de variables a cerrar.
code()
Devuelve el código fuente hasta el momento.
description()
Devuelve la misma descripción dada al constructor, si la hay.
add_line( @lineas_de_codigo )
Añade la siguiente línea de código.
"addf( $fmt, @args )"
Atajo para "add_line( sprintf $fmt, @args )".
add_gap()
Añade una línea en blanco de código.
increase_indent()
Aumenta el nivel de indentación para las siguientes líneas de código.
decrease_indent()
Disminuye el nivel de indentación para las siguientes líneas de código.
"add_variable( $varname, $referencia_a_valor )"
Añade una variable al entorno de compilación para que el coderef que se está generando pueda cerrarla.

Si una variable ya existe en el entorno con ese nombre, se añadirá una variable con un nombre diferente y se devolverá ese nombre. Siempre debes seguir refiriéndote a la variable con ese nombre devuelto, por si acaso.

add_placeholder( $nombre_marcador )
Añade una línea de código que es solo un comentario, pero recuerda su número de línea.
"fill_placeholder( $nombre_marcador, @lineas_de_codigo )"
Retrocede a un marcador previamente insertado y lo reemplaza con código.

Como alternativa, "add_placeholder" devuelve un coderef, que puedes llamar como $callback->( @lineas_de_codigo ).

compile( %opts )
Compila el código y lo devuelve como un coderef.

Las opciones se pasan a "eval_closure" de Eval::TypeTiny, pero no pueden incluir "code" o "environment". "alias => 1" es probablemente la opción más útil, pero en general no necesitarás proporcionar ninguna opción.

finalize()
Este método es llamado por "compile" justo antes de compilar el código. Todo lo que hace es eliminar los comentarios de marcadores no rellenados. No está destinado a ser llamado por usuarios finales, pero se documenta ya que puede ser un hook útil si estás creando una subclase de esta clase.
