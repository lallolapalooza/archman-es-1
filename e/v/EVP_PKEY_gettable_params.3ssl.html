CIÓN

Consult

e

OSSL_PARAM(3) para obtener información sobre los parámetros. EVP_PKEY_get_params() recupera parámetros de la

clave

pkey, de acuerdo con el contenido de params. EVP_PKEY_gettable_params() devuelve una

lista constante de

params que indica los nombres y tipos de los parámetros de la clave que se pueden recuperar. U

n

OSSL_PARAM(3) de tipo OSSL_PARAM_INTEGER u OSSL_PARAM_UNSIGNED_INTEGER es de longitud arbitraria. Dicho parámetro se puede obtener usando cualquiera de las funciones EVP_PKEY_get_int_param(), EVP_PKEY_get_size_t_param() o EVP_PKEY_get_bn_param(). Intentar obtener un valor entero que no quepa en un tipo nativo de C int hará que EVP_PKEY_get_int_param() falle. De manera similar, intentar obtener un valor entero que sea negativo o que no quepa en un tipo nativo de C size_t usando EVP_PKEY_get_size_t_param() también fallará. EVP_PKEY_get_int_param() recupera un valor

entero

*out de la clave pkey asociado con un nombre de key_name si cabe en el tipo "int". Para parámetros que no caben en "int", use EVP_PKEY_get_bn_param(). EVP_PKEY_get_size_t_param() recuper

a un valor size_t

*out de la clave pkey asociado con un nombre de key_name si cabe en el tipo "size_t". Para parámetros que no caben en "size_t", use EVP_PKEY_get_bn_param(). EVP_PKEY_get_bn_param() recupera

un valor BIGNUM

**bn de la clave pkey asociado con un nombre de key_name. Si *bn es NULL, el BIGNUM es asignado por el método. EVP_PKEY_get_utf8_string_param() obtiene un valor de cadena

UTF8

de la clave pkey en un búfer str de tamaño máximo max_buf_sz asociado con un nombre de key_name. El tamaño máximo debe ser lo suficientemente grande para acomodar el valor de la cadena, incluyendo un byte NUL terminante, o esta función fallará. Si out_len no es NULL, *out_len se establece en la longitud de la cadena sin incluir el byte NUL terminante. El tamaño de búfer requerido sin incluir el byte NUL terminante se puede obtener a partir de *out_len llamando a la función con str establecido en

NULL.

EVP_PKEY_get_octet_string_param() obtiene el valor de cadena de octetos de la clave pkey en un búfer buf de tamaño máximo max_buf_sz asociado con un nombre de key_name. Si out_len no es NULL, *out_len se establece en la longitud del contenido. El tamaño de búfer requerido se puede obtener a partir de *out_len llamando

a la fun
ción con

buf establecido en

NULL.

NOTAS Estas funciones so

lo funci
onan para

EVP_PKEY que contienen una clave del lado del proveedor. VALORES DE

RETORNO

EVP_PKEY_gettable_params() devuelve NULL en caso de error o si no está

soportado.

Todos los demás métodos devuelven 1 si se devolvió con éxito un valor asociado con el key_name de la clave, o 0 si hubo un error. Un error puede ser devuelto por los métodos EVP_PKEY_get_utf8_string_param() y EVP_PKEY_get_octet_string_param() si max_buf_sz no es lo suficientemente grande para contener el valor. Si out_len no es NULL, *out_len se asignará al tamaño de

búfer requerido para
contener el valor.
