NOTA

S

De acuerdo con la convención de nomenclatura de OpenSSL, la clave obtenida de o asignada a pkey usando las funciones 1 debe ser liberada así como pkey

EVP_PKEY_assign_RSA(), EVP_PKEY_assign_DSA(), EVP_PKEY_assign_DH(), EVP_PKEY_assign_EC_KEY(), EVP_PKEY_assign_POLY1305() y EVP_PKEY_assign_SIPHASH() están implementadas como

EVP_PKEY_assign_EC_KEY() examina el id del nombre de la curva para determinar si el EC_KEY pasado es una clave SM2(7), y establecerá el tipo EVP_PKEY a EVP_PKEY_SM2 en ese caso, en lugar de EVP_PKEY_EC

La mayoría de las aplicaciones que deseen conocer el tipo de una clave simplemente llamarán a EVP_PKEY_get_base_id() y no les importará el tipo real: el cual será idéntico en casi todos los

casos.

Versiones anteriores de este documento sugerían usar EVP_PKEY_type(pkey->type) para determinar el tipo de una clave. Dado que EVP_PKEY es ahora opaco, esto ya no es posible: el equivalente es EVP_PKEY_get_base_id(pkey)

EVP_PKEY_set1_engine() es típicamente usada por un ENGINE que devuel
