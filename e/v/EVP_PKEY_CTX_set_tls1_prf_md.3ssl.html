EVP_PKEY_CTX_set_tls1_prf_md(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_PKEY_CTX_set_tls1_prf_md(3ssl) OpenSSL EVP_PKEY_PKEY_CTX_set_tls1_prf_md(3ssl)

NOMBRE

EVP_PKEY_PKEY_CTX_set_tls1_prf_md, EVP_PKEY_PKEY_CTX_set1_tls1_prf_secret, EVP_PKEY_PKEY_CTX_add1_tls1_prf_seed - algoritmo de derivación de claves PRF de TLS

SINOPSIS

#include <openssl/kdf.h>
int EVP_PKEY_PKEY_CTX_set_tls1_prf_md(EVP_PKEY_CTX *pctx, const EVP_MD *md);
int EVP_PKEY_PKEY_CTX_set1_tls1_prf_secret(EVP_PKEY_CTX *pctx,
                                      unsigned char *sec, int seclen);
int EVP_PKEY_PKEY_CTX_add1_tls1_prf_seed(EVP_PKEY_CTX *pctx,
                                    unsigned char *seed, int seedlen);

DESCRIPCIÓN

El algoritmo EVP_PKEY_TLS_PRF implementa la función de derivación de claves PRF para TLS. No tiene clave privada asociada y solo implementa la derivación de claves usando EVP_PKEY_derive(3).

EVP_PKEY_set_tls1_prf_md() establece el resumen de mensaje asociado con el PRF de TLS. EVP_md5_sha1() se trata como un caso especial que utiliza el algoritmo PRF usando tanto MD5 como SHA1 como se usa en TLS 1.0 y 1.1.

EVP_PKEY_PKEY_CTX_set1_tls1_prf_secret() establece el valor secreto del PRF de TLS a seclen bytes del búfer sec. Cualquier valor secreto existente se reemplaza y cualquier semilla se reinicia.

EVP_PKEY_PKEY_CTX_add1_tls1_prf_seed() establece la semilla a seedlen bytes de seed. Si ya hay una semilla establecida, se añade al valor existente.

CTRLS DE CADENA

El PRF de TLS también admite operaciones de control basadas en cadenas usando EVP_PKEY_CTX_ctrl_str(3). El parámetro type "md" utiliza el parámetro value suministrado como el nombre del algoritmo de resumen a utilizar. Los parámetros type "secret" y "seed" utilizan el parámetro value suministrado como un valor secreto o semilla. Los nombres "hexsecret" y "hexseed" son similares, excepto que toman una cadena hexadecimal que se convierte a binario.

NOTAS

Se puede obtener un contexto para el PRF de TLS llamando a:

EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_TLS_PRF, NULL);

El resumen, el valor secreto y la semilla deben establecerse antes de derivar una clave o se producirá un error.

La longitud total de todas las semillas no puede exceder los 1024 bytes: esto debería ser más que suficiente para cualquier uso normal del PRF de TLS.

La longitud de salida del PRF se especifica por el parámetro de longitud en la función EVP_PKEY_derive(). Dado que la longitud de salida es variable, establecer el búfer a NULL no tiene sentido para el PRF de TLS.

Se pueden implementar versiones optimizadas del PRF de TLS en un ENGINE.

VALORES DE RETORNO

Todas estas funciones devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

EJEMPLOS

Este ejemplo deriva 10 bytes usando SHA-256 con la clave secreta "secret" y el valor semilla "seed":

EVP_PKEY_CTX *pctx;
unsigned char out[10];
size_t outlen = sizeof(out);
pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_TLS_PRF, NULL);
if (EVP_PKEY_derive_init(pctx) <= 0)
    /* Error */
if (EVP_PKEY_PKEY_CTX_set_tls1_prf_md(pctx, EVP_sha256()) <= 0)
    /* Error */
if (EVP_PKEY_PKEY_CTX_set1_tls1_prf_secret(pctx, "secret", 6) <= 0)
    /* Error */
if (EVP_PKEY_PKEY_CTX_add1_tls1_prf_seed(pctx, "seed", 4) <= 0)
    /* Error */
if (EVP_PKEY_derive(pctx, out, &outlen) <= 0)
    /* Error */
