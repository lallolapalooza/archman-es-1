EVP_PKEY_get_attr(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_GET_ATTR(3ssl) OpenSSL EVP_PKEY_GET_ATTR(3ssl)

NOMBRE

EVP_PKEY_get_attr, EVP_PKEY_get_attr_count, EVP_PKEY_get_attr_by_NID, EVP_PKEY_get_attr_by_OBJ, EVP_PKEY_delete_attr, EVP_PKEY_add1_attr, EVP_PKEY_add1_attr_by_OBJ, EVP_PKEY_add1_attr_by_NID, EVP_PKEY_add1_attr_by_txt - Funciones X509_ATTRIBUTE de EVP_PKEY

SINOPSIS

#include <openssl/x509.h>
int EVP_PKEY_get_attr_count(const EVP_PKEY *key);
int EVP_PKEY_get_attr_by_NID(const EVP_PKEY *key, int nid, int lastpos);
int EVP_PKEY_get_attr_by_OBJ(const EVP_PKEY *key, const ASN1_OBJECT *obj,
                             int lastpos);
X509_ATTRIBUTE *EVP_PKEY_get_attr(const EVP_PKEY *key, int loc);
X509_ATTRIBUTE *EVP_PKEY_delete_attr(EVP_PKEY *key, int loc);
int EVP_PKEY_add1_attr(EVP_PKEY *key, X509_ATTRIBUTE *attr);
int EVP_PKEY_add1_attr_by_OBJ(EVP_PKEY *key,
                              const ASN1_OBJECT *obj, int type,
                              const unsigned char *bytes, int len);
int EVP_PKEY_add1_attr_by_NID(EVP_PKEY *key,
                              int nid, int type,
                              const unsigned char *bytes, int len);
int EVP_PKEY_add1_attr_by_txt(EVP_PKEY *key,
                              const char *attrname, int type,
                              const unsigned char *bytes, int len);

DESCRIPCIÓN

Estas funciones son utilizadas por PKCS12.

EVP_PKEY_get_attr_by_OBJ() encuentra la ubicación del primer objeto coincidente obj en la lista de atributos de key. La búsqueda comienza en la posición después de lastpos. Si el valor devuelto es positivo, entonces puede ser utilizado en la siguiente llamada a EVP_PKEY_get_attr_by_OBJ() como el valor de lastpos para iterar a través de los atributos restantes. lastpos puede ser establecido a cualquier valor negativo en la primera llamada, para comenzar la búsqueda desde el inicio de la lista de atributos.

EVP_PKEY_get_attr_by_NID() es similar a EVP_PKEY_get_attr_by_OBJ() excepto que pasa el identificador numérico (NID) nid asociado con el objeto. Véase <openssl/obj_mac.h> para una lista de NID_*.

EVP_PKEY_get_attr() devuelve el objeto X509_ATTRIBUTE en el índice loc en la lista de atributos de key. loc debe estar en el rango de 0 a EVP_PKEY_get_attr_count() - 1.

EVP_PKEY_delete_attr() elimina el objeto X509_ATTRIBUTE en el índice loc en la lista de atributos de key.

EVP_PKEY_add1_attr() agrega una copia del objeto X509_ATTRIBUTE proporcionado a la lista de atributos de key. Se crea una nueva lista de atributos de key si es necesario. Ocurre un error si attr es NULL, o si el atributo ya existe.

EVP_PKEY_add1_attr_by_OBJ() crea un nuevo X509_ATTRIBUTE usando X509_ATTRIBUTE_set1_object() y X509_ATTRIBUTE_set1_data() para asignar un nuevo obj con el tipo type y los datos bytes de longitud len y luego lo agrega a la lista de atributos del objeto key. Si obj ya existe en la lista de atributos, ocurre un error.

EVP_PKEY_add1_attr_by_NID() es similar a EVP_PKEY_add1_attr_by_OBJ() excepto que pasa el identificador numérico (NID) nid asociado con el objeto. Véase <openssl/obj_mac.h> para una lista de NID_*.

EVP_PKEY_add1_attr_by_txt() es similar a EVP_PKEY_add1_attr_by_OBJ() excepto que pasa un nombre attrname asociado con el objeto. Véase <openssl/obj_mac.h> para una lista de nombres SN_*.

VALORES DE RETORNO

EVP_PKEY_get_attr_count() devuelve el número de atributos en la lista de atributos del objeto key o -1 si la lista de atributos es NULL.

EVP_PKEY_get_attr_by_OBJ() devuelve -1 si la lista está vacía O el objeto no se encuentra; de lo contrario, devuelve la ubicación del objeto en la lista.

EVP_PKEY_get_attr_by_NID() es similar a EVP_PKEY_get_attr_by_OBJ(), excepto que devuelve -2 si el nid no es conocido por OpenSSL.

EVP_PKEY_get_attr() devuelve un X509_ATTRIBUTE o NULL si hay un error.

EVP_PKEY_delete_attr() devuelve el X509_ATTRIBUTE eliminado o NULL si hay un error.

EVP_PKEY_add1_attr(), EVP_PKEY_add1_attr_by_OBJ(), EVP_PKEY_add1_attr_by_NID() y EVP_PKEY_add1_attr_by_txt() devuelven 1 en caso de éxito o 0 en caso contrario.

NOTAS

La lista de atributos de un objeto EVP_PKEY es inicialmente NULL. Todas las funciones anteriores listadas devolverán un error a menos que se llame a EVP_PKEY_add1_attr(). Todas las funciones listadas asumen que key no es NULL.
