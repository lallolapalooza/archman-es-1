NOMBRE

EVP_rc2_cbc, EVP_rc2_cfb, EVP_rc2_cfb64, EVP_rc2_ecb, EVP_rc2_ofb, EVP_rc2_40_cbc, EVP_rc2_64_cbc - cifrado RC2 de EVP

SINOPSIS

#include <openssl/evp.h>
const EVP_CIPHER *EVP_rc2_cbc(void);
const EVP_CIPHER *EVP_rc2_cfb(void);
const EVP_CIPHER *EVP_rc2_cfb64(void);
const EVP_CIPHER *EVP_rc2_ecb(void);
const EVP_CIPHER *EVP_rc2_ofb(void);
const EVP_CIPHER *EVP_rc2_40_cbc(void);
const EVP_CIPHER *EVP_rc2_64_cbc(void);

DESCRIPCIÓN

El algoritmo de cifrado RC2 para EVP.

EVP_rc2_cbc(), EVP_rc2_cfb(), EVP_rc2_cfb64(), EVP_rc2_ecb(), EVP_rc2_ofb()
Algoritmo de cifrado RC2 en modos CBC, CFB, ECB y OFB respectivamente. Este es un cifrado de longitud de clave variable con un parámetro adicional llamado "bits de clave efectivos" o "longitud de clave efectiva". Por defecto, ambos se establecen en 128 bits.
EVP_rc2_40_cbc(), EVP_rc2_64_cbc()
Algoritmo RC2 en modo CBC con una longitud de clave por defecto y una longitud de clave efectiva de 40 y 64 bits.

ADVERTENCIA: estas funciones están obsoletas. Su uso debe reemplazarse con las funciones EVP_rc2_cbc(), EVP_CIPHER_CTX_set_key_length() y EVP_CIPHER_CTX_ctrl() para establecer la longitud de clave y la longitud de clave efectiva.

NOTAS

Los desarrolladores deben ser conscientes de las implicaciones negativas de rendimiento de llamar a estas funciones varias veces y deberían considerar usar EVP_CIPHER_fetch(3) con EVP_CIPHER-RC2(7) en su lugar. Consulte "Rendimiento" en crypto(7) para más información.

VALORES DEVUELTOS

Estas funciones devuelven una estructura EVP_CIPHER que contiene la implementación del cifrado simétrico. Consulte EVP_CIPHER_meth_new(3) para ver los detalles de la estructura EVP_CIPHER.

VER TAMBIÉN
