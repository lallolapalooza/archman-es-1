EVP_CIPHER_CTX_get_original_iv(3ssl)

Licencias: Apache-2.0

EVP_CIPHER_CTX_GET_ORIGINAL_IV(3ssl) OpenSSL EVP_CIPHER_CTX_GET_ORIGINAL_IV(3ssl)

NOMBRE

EVP_CIPHER_CTX_get_original_iv, EVP_CIPHER_CTX_get_updated_iv, EVP_CIPHER_CTX_iv, EVP_CIPHER_CTX_original_iv, EVP_CIPHER_CTX_iv_noconst - Rutinas para inspeccionar datos IV del EVP_CIPHER_CTX

SINOPSIS

#include <openssl/evp.h>
int EVP_CIPHER_CTX_get_original_iv(EVP_CIPHER_CTX *ctx, void *buf, size_t len);
int EVP_CIPHER_CTX_get_updated_iv(EVP_CIPHER_CTX *ctx, void *buf, size_t len);

Las siguientes funciones han sido deprecadas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

const unsigned char *EVP_CIPHER_CTX_iv(const EVP_CIPHER_CTX *ctx);
const unsigned char *EVP_CIPHER_CTX_original_iv(const EVP_CIPHER_CTX *ctx);
unsigned char *EVP_CIPHER_CTX_iv_noconst(EVP_CIPHER_CTX *ctx);

DESCRIPCIÓN

EVP_CIPHER_CTX_get_original_iv() y EVP_CIPHER_CTX_get_updated_iv() copian información del vector de inicialización (IV) desde el EVP_CIPHER_CTX al buffer proporcionado por el llamante. EVP_CIPHER_CTX_get_iv_length(3) puede ser usado para determinar un tamaño de buffer apropiado, y si el buffer proporcionado es demasiado pequeño, se devolverá un error (y no se copiarán datos). EVP_CIPHER_CTX_get_original_iv() accede al IV ("original") que fue proporcionado cuando el EVP_CIPHER_CTX fue inicializado, y EVP_CIPHER_CTX_get_updated_iv() accede al "estado del IV" actual del cifrado, el cual se actualiza durante la operación de cifrado para ciertos modos de cifrado (ej. CBC y OFB).

Las funciones EVP_CIPHER_CTX_iv(), EVP_CIPHER_CTX_original_iv(), y EVP_CIPHER_CTX_iv_noconst() son funciones deprecadas que proporcionan funcionalidad similar (a nivel conceptual). EVP_CIPHER_CTX_iv() devuelve un puntero al inicio del "estado del IV" tal como se mantiene internamente en el EVP_CIPHER_CTX; EVP_CIPHER_CTX_original_iv() devuelve un puntero al inicio del IV ("original"), tal como se mantiene por el EVP_CIPHER_CTX, que fue proporcionado cuando el EVP_CIPHER_CTX fue inicializado; y EVP_CIPHER_CTX_get_iv_noconst() es lo mismo que EVP_CIPHER_CTX_iv() pero tiene un tipo de retorno diferente para el puntero.

VALORES DE RETORNO

EVP_CIPHER_CTX_get_original_iv() y EVP_CIPHER_CTX_get_updated_iv() devuelven 1 en caso de éxito y 0 en caso de fallo.

Las funciones EVP_CIPHER_CTX_iv(), EVP_CIPHER_CTX_original_iv(), y EVP_CIPHER_CTX_iv_noconst() devuelven un puntero a un IV como un array de bytes en caso de éxito, y NULL en caso de fallo.

HISTORIA

EVP_CIPHER_CTX_get_original_iv() y EVP_CIPHER_CTX_get_updated_iv() fueron añadidas en OpenSSL 3.0.0.

EVP_CIPHER_CTX_iv(), EVP_CIPHER_CTX_original_iv(), y EVP_CIPHER_CTX_iv_noconst() fueron añadidas en OpenSSL 1.1.0, y fueron deprecadas en OpenSSL 3.0.0.
