NOMBRE

EVP_RAND-CTR-DRBG - La implementación de EVP_RAND para el generador de bits determinista de contador (CTR DRBG)

DESCRIPCIÓN

Soporte para el generador de bits determinista de contador a través de la API EVP_RAND.

Identidad

"CTR-DRBG" es el nombre de esta implementación; se puede utilizar con la función EVP_RAND_fetch().

Parámetros admitidos

Los parámetros admitidos son:

"state" (OSSL_RAND_PARAM_STATE) <entero>
"strength" (OSSL_RAND_PARAM_STRENGTH) <entero sin signo>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <entero sin signo>
"reseed_requests" (OSSL_DRBG_PARAM_RESEED_REQUESTS) <entero sin signo>
"reseed_time_interval" (OSSL_DRBG_PARAM_RESEED_TIME_INTERVAL) <entero>
"min_entropylen" (OSSL_DRBG_PARAM_MIN_ENTROPYLEN) <entero sin signo>
"max_entropylen" (OSSL_DRBG_PARAM_MAX_ENTROPYLEN) <entero sin signo>
"min_noncelen" (OSSL_DRBG_PARAM_MIN_NONCELEN) <entero sin signo>
"max_noncelen" (OSSL_DRBG_PARAM_MAX_NONCELEN) <entero sin signo>
"max_perslen" (OSSL_DRBG_PARAM_MAX_PERSLEN) <entero sin signo>
"max_adinlen" (OSSL_DRBG_PARAM_MAX_ADINLEN) <entero sin signo>
"reseed_counter" (OSSL_DRBG_PARAM_RESEED_COUNTER) <entero sin signo>
"properties" (OSSL_DRBG_PARAM_PROPERTIES) <cadena UTF8>
"cipher" (OSSL_DRBG_PARAM_CIPHER) <cadena UTF8>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_RAND(3).
"use_derivation_function" (OSSL_DRBG_PARAM_USE_DF) <entero>
Este booleano indica si se debe usar o no una función de derivación. Un valor distinto de cero (el valor predeterminado) usa la función de derivación. Un valor cero no.

NOTAS

Se puede obtener un contexto para CTR DRBG llamando a:

EVP_RAND *rand = EVP_RAND_fetch(NULL, "CTR-DRBG", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

La implementación predeterminada de CTR-DRBG intenta obtener los algoritmos internos requeridos del proveedor con el que están integrados (por ejemplo, el proveedor predeterminado) independientemente de las propiedades proporcionadas. Si el proveedor no implementa los algoritmos requeridos, se utilizarán las propiedades para encontrar una implementación diferente.

EJEMPLOS

EVP_RAND *rand;
EVP_RAND_CTX *rctx;
unsigned char bytes[100];
OSSL_PARAM params[2], *p = params;
unsigned int strength = 128;
rand = EVP_RAND_fetch(NULL, "CTR-DRBG", NULL);
rctx = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_free(rand);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_DRBG_PARAM_CIPHER,
                                        SN_aes_256_ctr, 0);
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);
