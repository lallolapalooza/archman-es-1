NOMBRE

EVP_SIGNATURE-SLH-DSA, EVP_SIGNATURE-SLH-DSA-SHA2-128s, EVP_SIGNATURE-SLH-DSA-SHA2-128f, EVP_SIGNATURE-SLH-DSA-SHA2-192s, EVP_SIGNATURE-SLH-DSA-SHA2-192f, EVP_SIGNATURE-SLH-DSA-SHA2-256s, EVP_SIGNATURE-SLH-DSA-SHA2-256f, EVP_SIGNATURE-SLH-DSA-SHAKE-128s, EVP_SIGNATURE-SLH-DSA-SHAKE-128f, EVP_SIGNATURE-SLH-DSA-SHAKE-192s, EVP_SIGNATURE-SLH-DSA-SHAKE-192f, EVP_SIGNATURE-SLH-DSA-SHAKE-256s, EVP_SIGNATURE-SLH-DSA-SHAKE-256f - Soporte EVP_PKEY SLH-DSA

DESCRIPCIÓN

Las implementaciones SLH-DSA-SHA2-128s, EVP_PKEY-SLH-DSA-SHA2-128f, SLH-DSA-SHA2-192s, EVP_PKEY-SLH-DSA-SHA2-192f, SLH-DSA-SHA2-256s, EVP_PKEY-SLH-DSA-SHA2-256f, SLH-DSA-SHAKE-128s, EVP_PKEY-SLH-DSA-SHAKE-128f, SLH-DSA-SHAKE-192s, EVP_PKEY-SLH-DSA-SHAKE-192f, SLH-DSA-SHAKE-256s y EVP_PKEY-SLH-DSA-SHAKE-256f EVP_PKEY soportan la generación de claves, firma y verificación en un solo paso utilizando los esquemas de firma SLH-DSA descritos en FIPS 205.

Los diferentes nombres de algoritmos corresponden a los conjuntos de parámetros definidos en la Tabla 2 de la Sección 11 de FIPS 205. Los tipos "s" tienen tamaños de firma más pequeños, y las variantes "f" son más rápidas (las firmas varían de ~8K a ~50K dependiendo del tipo elegido). Hay 3 categorías de seguridad diferentes también, dependiendo del tipo.

EVP_SIGNATURE_fetch(3) puede usarse para obtener explícitamente uno de los 12 algoritmos que luego pueden ser utilizados con EVP_PKEY_sign_message_init(3), EVP_PKEY_sign(3), EVP_PKEY_verify_message_init(3) y EVP_PKEY_verify(3) para realizar firmas o verificaciones de mensajes en un solo paso.

El proceso de firma normal (llamado Generación de Firma Pura SLH-DSA) codifica el mensaje internamente como 0x00 || len(ctx) || ctx || mensaje. donde ctx es algún valor opcional de tamaño 0x00..0xFF. OpenSSL también permite que el mensaje no sea codificado, lo cual es requerido para pruebas. OpenSSL no soporta la Generación de Firma SLH-DSA Pre Hash, pero esto puede ser hecho por el usuario realizando la codificación Pre Hash externamente y luego eligiendo la opción de no codificar el mensaje.

PARÁMETROS DE FIRMA SLH-DSA

El parámetro "cadena-de-contexto", descrito a continuación, puede ser usado tanto para firmar como para verificar. Puede ser configurado pasando un array OSSL_PARAM a EVP_PKEY_sign_init_ex2(3) o EVP_PKEY_verify_init_ex2(3)

"cadena-de-contexto" (OSSL_SIGNATURE_PARAM_CONTEXT_STRING) <cadena de octetos>
Una cadena de octetos con una longitud máxima de 255. Por defecto es la cadena vacía.

Los siguientes parámetros pueden ser usados al firmar: Pueden ser configurados pasando un array OSSL_PARAM a EVP_PKEY_sign_init_ex2(3).

"codificación-mensaje" (OSSL_SIGNATURE_PARAM_MESSAGE_ENCODING) <entero>
El valor por defecto de 1 usa la 'Generación de Firma Pura SLH-DSA' como se describe arriba. Configurar a 0 no codifica el mensaje, lo cual se usa para pruebas, pero también puede ser usado para 'Generación de Firma SLH-DSA Pre Hash'.
"entropía-de-prueba" (OSSL_SIGNATURE_PARAM_TEST_ENTROPY <cadena de octetos
Usado para pruebas para pasar un valor aleatorio opcional.
"determinista" (OSSL_SIGNATURE_PARAM_DETERMINISTIC) <entero>
El valor por defecto de 0 genera un valor aleatorio (usando un DRBG) que se usa al procesar el mensaje. Configurar esto a 1 causa que se use la semilla de la clave privada en su lugar. Este valor es ignorado si se establece "entropía-de-prueba".

Ver EVP_PKEY-SLH-DSA(7) para información relacionada con las claves SLH-DSA.

NOTAS

Por razones de compatibilidad hacia atrás EVP_DigestSignInit_ex(), EVP_DigestSign(), EVP_DigestVerifyInit_ex() y EVP_DigestVerify() también pueden ser usadas, pero el digest pasado en mdname debe ser NULL.

EJEMPLOS

Para firmar un mensaje usando una estructura EVP_PKEY SLH-DSA:

void do_sign(EVP_PKEY *key, unsigned char *msg, size_t msg_len)
{
    size_t sig_len;
    unsigned char *sig = NULL;
    const OSSL_PARAM params[] = {
        OSSL_PARAM_octet_string("context-string", (unsigned char *)"Una cadena de contexto", 33),
        OSSL_PARAM_END
    };
    EVP_PKEY_CTX *sctx = EVP_PKEY_CTX_new_from_pkey(NULL, pkey, NULL);
    EVP_SIGNATURE *sig_alg = EVP_SIGNATURE_fetch(NULL, "SLH-DSA-SHA2-128s", NULL);
    EVP_PKEY_sign_message_init(sctx, sig_alg, params);
    /* Calcular el tamaño requerido para la firma pasando un buffer NULL. */
    EVP_PKEY_sign(sctx, NULL, &sig_len, msg, msg_len);
    sig = OPENSSL_zalloc(sig_len);
    EVP_PKEY_sign(sctx, sig, &sig_len, msg, msg_len);
    ...
    OPENSSL_free(sig);
    EVP_SIGNATURE_free(sig_alg);
    EVP_PKEY_CTX_free(sctx);
}
