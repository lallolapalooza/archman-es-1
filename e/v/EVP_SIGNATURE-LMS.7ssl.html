NOMBRE

EVP_SIGNATURE-LMS - La implementación de firma EVP_PKEY Leighton-Micali (LMS)

DESCRIPCIÓN

La implementación LMS de EVP_PKEY soporta las Firmas Leighton-Micali (LMS) descritas en [RFC 8554](https://datatracker.ietf.org/doc/html/rfc8554) y [SP 800-208](https://csrc.nist.gov/pubs/sp/800/208/final). Los proveedores de OpenSSL solo soportan la verificación de firmas LMS, ya que este es un requisito de [SP 800-208](https://csrc.nist.gov/pubs/sp/800/208/final) para los módulos de software FIPS.

EVP_PKEY_verify_message_init() y EVP_PKEY_verify() son las únicas funciones soportadas utilizadas para firmas LMS. La transmisión no está soportada actualmente, y dado que los datos de la firma contienen datos relacionados con el resumen utilizado, las funciones que especifican el nombre del resumen no son necesarias.

NOTAS

El soporte para LMS está deshabilitado por defecto en tiempo de compilación. Para habilitarlo, especifique la opción de configuración de compilación enable-lms.

LMS solo debe usarse para implementaciones antiguas. Las nuevas implementaciones deben usar EVP_SIGNATURE-ML-DSA(7) o <L/EVP_SIGNATURE-SLH-DSA(7)>.

EJEMPLOS

La comprobación de errores se ha omitido en los siguientes ejemplos

Verificación de firma LMS

/* Ver L<EVP_PKEY-LMS(7)/EXAMPLES para un ejemplo de carga de una clave |pub| LMS */
ctx = EVP_PKEY_CTX_new_from_pkey(libctx, pub, propq);
sig = EVP_SIGNATURE_fetch(libctx, "LMS", propq);
EVP_PKEY_verify_message_init(ctx, sig, NULL);
/*
 * EVP_PKEY_verify_message_update() y EVP_PKEY_verify_message_final()
 * no están soportados
 */
ret = EVP_PKEY_verify(ctx, sigdata, sigdata_len, msg, msglen);
/*
 * ret == 1 indica éxito, 0 fallo de verificación y < 0 para algún
 * otro error.
 */
