NOMBRE

EVP_aria_128_cbc, EVP_aria_192_cbc, EVP_aria_256_cbc, EVP_aria_128_cfb, EVP_aria_192_cfb, EVP_aria_256_cfb, EVP_aria_128_cfb1, EVP_aria_192_cfb1, EVP_aria_256_cfb1, EVP_aria_128_cfb8, EVP_aria_192_cfb8, EVP_aria_256_cfb8, EVP_aria_128_cfb128, EVP_aria_192_cfb128, EVP_aria_256_cfb128, EVP_aria_128_ctr, EVP_aria_192_ctr, EVP_aria_256_ctr, EVP_aria_128_ecb, EVP_aria_192_ecb, EVP_aria_256_ecb, EVP_aria_128_ofb, EVP_aria_192_ofb, EVP_aria_256_ofb, EVP_aria_128_ccm, EVP_aria_192_ccm, EVP_aria_256_ccm, EVP_aria_128_gcm, EVP_aria_192_gcm, EVP_aria_256_gcm, - Cifrado ARIA EVP

SINOPSIS

#include <openssl/evp.h>
const EVP_CIPHER *EVP_ciphername(void)

EVP_ciphername se utiliza como marcador de posición para cualquiera de las funciones de cifrado descritas, como EVP_aria_128_cbc.

DESCRIPCIÓN

El algoritmo de cifrado ARIA para EVP.

EVP_aria_128_cbc(), EVP_aria_192_cbc(), EVP_aria_256_cbc(), EVP_aria_128_cfb(), EVP_aria_192_cfb(), EVP_aria_256_cfb(), EVP_aria_128_cfb1(), EVP_aria_192_cfb1(), EVP_aria_256_cfb1(), EVP_aria_128_cfb8(), EVP_aria_192_cfb8(), EVP_aria_256_cfb8(), EVP_aria_128_cfb128(), EVP_aria_192_cfb128(), EVP_aria_256_cfb128(), EVP_aria_128_ctr(), EVP_aria_192_ctr(), EVP_aria_256_ctr(), EVP_aria_128_ecb(), EVP_aria_192_ecb(), EVP_aria_256_ecb(), EVP_aria_128_ofb(), EVP_aria_192_ofb(), EVP_aria_256_ofb()
ARIA para claves de 128, 192 y 256 bits en los siguientes modos: CBC, CFB con desplazamiento de 128 bits, CFB con desplazamiento de 1 bit, CFB con desplazamiento de 8 bits, CTR, ECB y OFB.
EVP_aria_128_ccm(), EVP_aria_192_ccm(), EVP_aria_256_ccm(), EVP_aria_128_gcm(), EVP_aria_192_gcm(), EVP_aria_256_gcm(),
ARIA para claves de 128, 192 y 256 bits en modo CBC-MAC (CCM) y modo contador de Galois (GCM). Estos cifrados requieren operaciones de control adicionales para funcionar correctamente, consulte la sección "INTERFAZ AEAD" en EVP_EncryptInit(3) para obtener más detalles.

NOTAS

Los desarrolladores deben ser conscientes de las implicaciones negativas de rendimiento de llamar a estas funciones repetidamente y deben considerar usar EVP_CIPHER_fetch(3) con EVP_CIPHER-ARIA(7) en su lugar. Consulte "Rendimiento" en crypto(7) para obtener más información.

VALORES DEVUELTOS

Estas funciones devuelven una estructura EVP_CIPHER que contiene la implementación del cifrado simétrico. Consulte EVP_CIPHER_meth_new(3) para obtener detalles sobre la estructura EVP_CIPHER.

VER TAMBIÉN
