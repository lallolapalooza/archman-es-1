NOMBRE

EVP_KDF-PBKDF2 - La implementación de EVP_KDF de PBKDF2

DESCRIPCIÓN

Soporte para calcular la función de derivación de clave basada en contraseñas PBKDF2 a través de la API EVP_KDF.

El algoritmo EVP_KDF-PBKDF2 implementa la función de derivación de clave basada en contraseñas PBKDF2, tal como se describe en SP800-132; deriva una clave de una contraseña utilizando una sal y un número de iteraciones.

La salida se considera una clave criptográfica.

Identidad

"PBKDF2" es el nombre de esta implementación; puede ser utilizado con la función EVP_KDF_fetch().

Parámetros soportados

Los parámetros soportados son:

"pass" (OSSL_KDF_PARAM_PASSWORD) <cadena de octetos>
"salt" (OSSL_KDF_PARAM_SALT) <cadena de octetos>
"iter" (OSSL_KDF_PARAM_ITER) <entero sin signo>
Este parámetro tiene un valor predeterminado de 2048.
"properties" (OSSL_KDF_PARAM_PROPERTIES) <cadena UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <cadena UTF8>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_KDF(3).
"pkcs5" (OSSL_KDF_PARAM_PKCS5) <entero>
Este parámetro se puede utilizar para habilitar o deshabilitar las verificaciones de cumplimiento de SP800-132. Establecer el modo a 0 habilita las verificaciones de cumplimiento.

Las verificaciones realizadas son:

- el número de iteraciones es de al menos 1000.
- la longitud de la sal es de al menos 128 bits.
- la longitud de la clave derivada es de al menos 112 bits.

El proveedor predeterminado utiliza un modo predeterminado de 1 para compatibilidad con versiones anteriores, y el proveedor FIPS utiliza un modo predeterminado de 0. Esta opción rompe la conformidad FIPS si provoca que el "indicador-fips" aprobado devuelva 0.

"fips-indicator" (OSSL_KDF_PARAM_FIPS_APPROVED_INDICATOR) <entero>
Esta opción es utilizada por el proveedor FIPS de OpenSSL.

Un obtentor que devuelve 1 si la operación está aprobada por FIPS, o 0 en caso contrario. Esto puede usarse después de llamar a EVP_KDF_derive. Devuelve 0 si se establece "pkcs5" en 1 y falla la prueba de longitud de clave derivada, longitud de sal o número de iteraciones.

NOTAS

Una aplicación típica de este algoritmo es derivar material de clave para un algoritmo de cifrado a partir de una contraseña en "pass", una sal en "salt" y un número de iteraciones.

Aumentar el parámetro "iter" ralentiza el algoritmo, lo que dificulta que un atacante realice un ataque de fuerza bruta utilizando un gran número de contraseñas candidatas.

No se hace ninguna suposición sobre la contraseña dada; simplemente se trata como una secuencia de bytes.

CONFORMIDAD CON

SP800-132
