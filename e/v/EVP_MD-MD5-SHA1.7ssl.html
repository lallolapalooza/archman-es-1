NOMBRE

EVP_MD-MD5-SHA1 - La implementación de EVP_MD MD5-SHA1

DESCRIPCIÓN

Soporte para calcular resúmenes MD5-SHA1 a través de la API EVP_MD.

MD5-SHA1 es un resumen bastante especial que se utiliza con SSLv3.

Identidad

Esta implementación solo está disponible con el proveedor predeterminado y se identifica con el nombre "MD5-SHA1".

Parámetros obtenibles

Esta implementación admite los parámetros comunes obtenibles descritos en EVP_MD-common(7).

Parámetros de contexto configurables

Esta implementación admite las siguientes entradas de OSSL_PARAM(3), que se pueden configurar para un EVP_MD_CTX con EVP_MD_CTX_set_params(3):

"ssl3-ms" (OSSL_DIGEST_PARAM_SSL3_MS) <cadena de octetos>
Este parámetro lo establece libssl para calcular un hash de firma para un mensaje CertificateVerify de SSLv3 según RFC6101. Solo se establece después de que todos los mensajes de handshake ya hayan sido resumidos mediante llamadas OP_digest_update(). El parámetro proporciona el valor del secreto maestro que se añadirá al resumen. La implementación del resumen debe calcular el resumen completo según la sección 5.6.8 de RFC6101. La siguiente llamada después de establecer este parámetro debe ser OP_digest_final().

VER TAMBIÉN

EVP_MD_CTX_set_params(3), provider-digest(7), OSSL_PROVIDER-default(7)
