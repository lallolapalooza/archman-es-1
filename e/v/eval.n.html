eval(n) Comandos integrados de Tcl eval(n)

NOMBRE

eval - Evaluar un script de Tcl

SINOPSIS

eval arg ?arg ...?

DESCRIPCIÓN

Eval toma uno o más argumentos, que juntos comprenden un script de Tcl que contiene uno o más comandos. Eval concatena todos sus argumentos de la misma manera que el comando concat, pasa la cadena concatenada al intérprete de Tcl recursivamente y devuelve el resultado de esa evaluación (o cualquier error generado por ella). Tenga en cuenta que el comando list cita secuencias de palabras de tal manera que no son expandidas adicionalmente por el comando eval.

EJEMPLOS

A menudo, es útil almacenar un fragmento de script en una variable y ejecutarlo más tarde con valores adicionales añadidos. Esta técnica se utiliza en varios lugares de Tcl core (por ejemplo, en los callbacks de los comandos fcopy, lsort y trace). Este ejemplo muestra cómo hacer esto utilizando comandos básicos de Tcl:

set script {
    puts "logging now"
    lappend $myCurrentLogVar
}
set myCurrentLogVar log1
# ¡Configurar un cambio de variable de registro a mitad de camino!
after 20000 set myCurrentLogVar log2
for {set i 0} {$i<10} {incr i} {
    # Introducir un retardo aleatorio
    after [expr {int(5000 * rand())}]
    update    ;# Comprobar el cambio de registro asíncrono
    eval $script $i [clock clicks]
}

Tenga en cuenta que en el caso más común (donde el fragmento de script es en realidad solo una lista de palabras que forman un prefijo de comando), es mejor usar {*}$script al hacer este tipo de patrón de invocación. Es menos general que el comando eval, y por lo tanto más fácil de hacer robusto en la práctica. El siguiente procedimiento actúa de manera análoga al comando lappend, excepto que inserta los valores de los argumentos al principio de la lista en la variable:

proc lprepend {varName args} {
    upvar 1 $varName var
    # Asegurarse de que la variable exista y contenga una lista
    lappend var
    # Ahora insertamos todos los argumentos de una vez
    set var [eval [list linsert $var 0] $args]
}

Sin embargo, la última línea ahora se escribiría normalmente sin eval, así:

set var [linsert $var 0 {*}$args]
