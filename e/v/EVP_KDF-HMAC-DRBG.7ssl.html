NOMBRE

EVP_KDF-HMAC-DRBG - La implementación determinista de EVP_KDF HMAC DRBG

DESCRIPCIÓN

Soporte para un HMAC DRBG determinista utilizando la API EVP_KDF. Esto es similar a EVP_RAND-HMAC-DRBG(7), pero utiliza valores fijos para sus valores de entropía y nonce. Esto se utiliza para generar el valor determinista de nonce requerido por ECDSA y DSA (según se define en RFC 6979).

Identidad

"HMAC-DRBG-KDF" es el nombre de esta implementación; se puede utilizar con la función EVP_KDF_fetch().

Parámetros soportados

Los parámetros soportados son:

"digest" (OSSL_DRBG_PARAM_DIGEST) <cadena UTF8>
"properties" (OSSL_DRBG_PARAM_PROPERTIES) <cadena UTF8>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_KDF(3).
"entropy" (OSSL_KDF_PARAM_HMACDRBG_ENTROPY) <cadena de octetos>
Establece los bytes de entropía suministrados al HMAC-DRBG.
"nonce" (OSSL_KDF_PARAM_HMACDRBG_NONCE) <cadena de octetos>
Establece los bytes de nonce suministrados al HMAC-DRBG.

NOTAS

Se puede obtener un contexto para KDF HMAC DRBG llamando a:

EVP_KDF *kdf = EVP_KDF_fetch(NULL, "HMAC-DRBG-KDF", NULL);
EVP_KDF_CTX *kdf_ctx = EVP_KDF_CTX_new(kdf, NULL);

CONFORME A

RFC 6979

VER TAMBIÉN

EVP_KDF(3), "PARÁMETROS" en EVP_KDF(3)

HISTORIA
