EVP_PKEY_get_group_name(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_GET_GROUP_NAME(3ssl) OpenSSL EVP_PKEY_GET_GROUP_NAME(3ssl)

NOMBRE

EVP_PKEY_get_group_name - obtener el nombre del grupo de una clave

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_get_group_name(EVP_PKEY *pkey, char *gname, size_t gname_sz,
                            size_t *gname_len);

DESCRIPCIÓN

EVP_PKEY_get_group_name() rellena el nombre del grupo de pkey en gname, hasta un máximo de gname_sz bytes, incluido el byte NUL final, y asigna *gname_len la longitud real del nombre sin incluir el byte NUL, si el tipo de clave de pkey lo admite. gname así como gname_len pueden ser NULL individualmente, y no se rellenarán ni asignarán en ese caso.

NOTAS

Entre los tipos de clave estándar de OpenSSL, esto solo se admite para claves DH, EC y SM2. Otros proveedores pueden admitir esto para tipos de clave adicionales.

VALORES DE RETORNO

EVP_PKEY_get_group_name() devuelve 1 si el nombre del grupo pudo ser rellenado, de lo contrario, devuelve 0.

HISTORIA

Esta función se añadió en OpenSSL 3.0.
