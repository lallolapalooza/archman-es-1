EVP_PKEY-DSA(7ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY-DSA(7ssl) OpenSSL EVP_PKEY-DSA(7ssl)

NOMBRE

EVP_PKEY-DSA, EVP_KEY MGMT-DSA - Soporte de tipo de clave y algoritmo DSA de EVP_PKEY

DESCRIPCIÓN

Para DSA, el estándar FIPS 186-4 especifica que los valores utilizados para la generación de parámetros FFC también se requieren para la validación de parámetros. Esto significa que los valores de parámetros de dominio FFC opcionales para seed, pcounter y gindex pueden necesitar almacenarse con fines de validación. Para DSA, estos campos no se almacenan en los datos ASN1, por lo que deben almacenarse externamente si se requiere validación.

Como parte de FIPS 140-3, DSA ya no está aprobado por FIPS para la generación de claves y la validación de firmas, pero todavía se permite para la verificación de firmas.

PARÁMETROS DSA

El tipo de clave DSA admite los parámetros FFC (consulte "Parámetros FFC" en EVP_PKEY-FFC(7)).

También admite los siguientes parámetros:

"sign-check" (OSSL_PKEY_PARAM_FIPS_SIGN_CHECK) <entero>
"fips-indicator" (OSSL_PKEY_PARAM_FIPS_APPROVED_INDICATOR) <entero>
Consulte "Parámetros de información comunes" en provider-keymgmt(7) para obtener más información.

PARÁMETROS DE GENERACIÓN DE CLAVES DSA

El tipo de clave DSA admite los parámetros de generación de claves FFC (consulte "Parámetros de generación de claves FFC" en EVP_PKEY-FFC(7)

Las siguientes restricciones se aplican al campo "pbits":

Para "fips186_4", esto debe ser 2048 o 3072. Para "fips186_2", esto debe ser 1024. Para "group", puede ser cualquiera de 2048, 3072, 4096, 6144 u 8192.

VALIDACIÓN DE CLAVES DSA

Para las claves DSA, EVP_PKEY_param_check(3) se comporta de la siguiente manera: El proveedor FIPS de OpenSSL cumple con las reglas del estándar FIPS186-4 para la validación de parámetros FFC. Para compatibilidad con versiones anteriores, el proveedor predeterminado de OpenSSL utiliza una comprobación mucho más simple (ver abajo) para la validación de parámetros, a menos que se establezca el parámetro seed.

Para las claves DSA, EVP_PKEY_param_check_quick(3) se comporta de la siguiente manera: Se realiza una comprobación simple de L y N y g parcial. El proveedor predeterminado también admite la validación de claves heredadas "fips186_2".

Para las claves DSA, EVP_PKEY_public_check(3), EVP_PKEY_private_check(3) y EVP_PKEY_pairwise_check(3), los proveedores predeterminado y FIPS de OpenSSL cumplen con las reglas de SP800-56Ar3 para pruebas públicas, privadas y por pares, respectivamente.

EJEMPLOS

Se puede obtener un contexto EVP_PKEY llamando a:

EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_from_name(NULL, "DSA", NULL);

Los parámetros de dominio DSA se pueden generar llamando a:

unsigned int pbits = 2048;
unsigned int qbits = 256;
int gindex = 1;
OSSL_PARAM params[5];
EVP_PKEY *param_key = NULL;
EVP_PKEY_CTX *pctx = NULL;
pctx = EVP_PKEY_CTX_new_from_name(NULL, "DSA", NULL);
EVP_PKEY_paramgen_init(pctx);
params[0] = OSSL_PARAM_construct_uint("pbits", &pbits);
params[1] = OSSL_PARAM_construct_uint("qbits", &qbits);
params[2] = OSSL_PARAM_construct_int("gindex", &gindex);
params[3] = OSSL_PARAM_construct_utf8_string("digest", "SHA384", 0);
params[4] = OSSL_PARAM_construct_end();
EVP_PKEY_CTX_set_params(pctx, params);
EVP_PKEY_generate(pctx, &param_key);
EVP_PKEY_CTX_free(pctx);
EVP_PKEY_print_params(bio_out, param_key, 0, NULL);

Una clave DSA se puede generar utilizando parámetros de dominio llamando a:

EVP_PKEY *key = NULL;
EVP_PKEY_CTX *gctx = NULL;
gctx = EVP_PKEY_CTX_new_from_pkey(NULL, param_key, NULL);
EVP_PKEY_keygen_init(gctx);
EVP_PKEY_generate(gctx, &key);
EVP_PKEY_CTX_free(gctx);
EVP_PKEY_print_private(bio_out, key, 0, NULL);

CONFORMA A

Las siguientes secciones de FIPS186-4:

A.1.1.2 Generación de primos probables p y q utilizando una función hash aprobada.
A.2.3 Generación del generador canónico g.
A.2.1 Generación no verificable del generador g.

HISTORIA

La generación de claves y la generación de firmas DSA ya no están aprobadas por FIPS en OpenSSL 3.4. Consulte "Indicadores FIPS" en fips_module(7) para obtener más información.
