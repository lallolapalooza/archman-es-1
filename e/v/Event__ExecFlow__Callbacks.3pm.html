NOMBRE

Event::ExecFlow::Callbacks - Callbacks adjuntos a trabajos

SINOPSIS

#-- Crear un nuevo objeto Callbacks
my $callbacks = Event::ExecFlow::Callbacks->new (
  sub { print "sub llamada\n" },
  sub { print "otra sub de este llamado\n" },
);
#-- Adjuntar callbacks a un trabajo
$job->set_pre_callbacks($callbacks);

#-- Añadir más subs
$callbacks->add(sub { print "una sub añadida más tarde\n" });
$callbacks->prepend(sub { print "una sub antepuesta a la lista de subs } );
#-- los métodos execute() se ejecutan más tarde por Event::ExecFlow
$callbacks->execute($job);

DESCRIPCIÓN

Esta clase representa una o más clausuras que pueden adjuntarse como callbacks a un Event::ExecFlow::Job.
