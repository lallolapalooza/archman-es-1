NOMBRE

EVP_KEM-X25519, EVP_KEM-X448 - Soporte de tipo de clave y algoritmo EVP_KEM X25519 y EVP_KEM X448

DESCRIPCIÓN

El tipo de clave X25519 y <X448> y sus parámetros se describen en EVP_PKEY-X25519(7). Consulte EVP_PKEY_encapsulate(3) y EVP_PKEY_decapsulate(3) para obtener más información.

Parámetros KEM X25519 y X448

"operation" (OSSL_KEM_PARAM_OPERATION)<cadena UTF8>
Los Mecanismos de Encapsulación de Claves X25519 y X448 de OpenSSL solo admiten la siguiente operación predeterminada (modo de operación):
"DHKEM" (OSSL_KEM_PARAM_OPERATION_DHKEM)
La función de encapsulación genera un par de claves efímero. Produce material de clave realizando un intercambio de claves X25519 o X448 utilizando la clave privada efímera y una clave pública del destinatario proporcionada. Una operación HKDF que utiliza el material de clave y un contexto KEM produce entonces un secreto compartido. Se devuelven el secreto compartido y la clave pública efímera. La función de desencapsulación utiliza la clave privada del destinatario y la clave pública efímera para producir el mismo material de clave, que puede ser utilizado para producir el mismo secreto compartido. Consulte https://www.rfc-editor.org/rfc/rfc9180.html#name-dh-based-kem-dhkem

Esto se puede configurar usando EVP_PKEY_CTX_set_kem_op() o EVP_PKEY_CTX_set_params().

"ikme" (OSSL_KEM_PARAM_IKME) <cadena de octetos>
Se utiliza para especificar el material de clave utilizado para la generación de la clave efímera. Este valor no debe reutilizarse para otros fines. Debe tener una longitud de al menos 32 para X25519 y 56 para X448. Si no se establece este valor, se utiliza un ikm aleatorio.

CONFORME A

RFC9180

VER TAMBIÉN

EVP_PKEY_CTX_set_kem_op(3), EVP_PKEY_encapsulate(3), EVP_PKEY_decapsulate(3) EVP_KEY MGMT(3), EVP_PKEY(3), provider-keymgmt(7)

HISTORIA

Esta funcionalidad se añadió en OpenSSL 3.2.

El parámetro "operation" (modo de operación) era obligatorio antes de OpenSSL 3.5. A partir de OpenSSL 3.5, "DHKEM" es el modo de operación predeterminado, y no es necesario especificar un valor explícito.
