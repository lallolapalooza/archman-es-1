DESCRIPCIÓ

N

EVP_PKEY_set1_encoded_public_key() puede usarse para establecer el valor de la clave pública dentro de un objeto EVP_PKEY existente, que aún no tiene asignada una clave pública o privada. Para los algoritmos integrados de OpenSSL esto actualmente solo funciona para aquellos que admiten intercambio de claves o encapsulamiento de claves. Los parámetros no se establecen como parte de esta operación, por lo que normalmente una aplicación creará primero un EVP_PKEY, establecerá los parámetros en él, y luego llamará a esta función. Por ejemplo, establecer los parámetros podría hacerse usando EVP_PKEY_copy_param

eters(3).

El formato de la clave pública codificada dependerá del algoritmo en uso. Para DH debe codificarse como un entero positivo en forma big-endian. Para EC debe ser un punto que cumpla con la Sec. 2.3.4 del estándar SECG SEC 1 ("Elliptic Curve Cryptography"). Para X25519 y X448 debe codificarse en el formato definido por RFC7748. Para ML-KEM-512, ML-KEM-768 y ML-KEM-1024, este es el formato de clave pública definido en FIPS 203 (la clave pública codificada con 12 bits por coeficiente t vector y la semilla de matriz de 32 bytes rho

).

La clave a actualizar se proporciona en pkey. El búfer que contiene la clave codificada es apuntado por pub. La longitud del búfer se proporciona en publen

.

EVP_PKEY_get1_encoded_public_key() realiza la operación equivalente excepto que la clave pública codificada se devuelve a la aplicación. La clave que contiene los datos de la clave pública se proporciona en pkey. Un búfer que contiene la clave codificada será asignado y almacenado en *ppub. La longitud de la clave pública codificada es devuelta por la función. La aplicación es responsable de liberar el búfer

asignado.

La macro EVP_PKEY_set1_tls_encodedpoint() está obsoleta y simplemente llama a EVP_PKEY_set1_encoded_public_key() con todos los mismos argumentos. Las nuevas aplicaciones deberían usar EVP_PKEY_set1_encoded_public_key() en su

lugar.

La macro EVP_PKEY_get1_tls_encodedpoint() está obsoleta y simplemente llama a EVP_PKEY_get1_encoded_public_key() con todos los mismos argumentos. Las nuevas aplicaciones deberían usar EVP_PKEY_get1_encoded_pu

blic_key()
en su lugar.

#include <openssl/evp.h>
int exchange(EVP_PKEY *ourkey, unsigned char *peer_pub, size_t peer_pub_len)
{
    EVP_PKEY *peerkey = EVP_PKEY_new();
    if (peerkey == NULL || EVP_PKEY_copy_parameters(peerkey, ourkey) <= 0)
        return 0;
    if (EVP_PKEY_set1_encoded_public_key(peerkey, peer_pub,
                                         peer_pub_len) <= 0)
        return 0;
    /* Realizar el intercambio de claves aquí */
    EVP_PKEY_free(peerkey);
    return 1;
}
