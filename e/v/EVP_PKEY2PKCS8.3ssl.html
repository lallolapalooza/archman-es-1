EVP_PKEY2PKCS8(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY2PKCS8(3ssl) OpenSSL EVP_PKEY2PKCS8(3ssl)

NOMBRE

EVP_PKEY2PKCS8, EVP_PKCS82PKEY_ex, EVP_PKCS82PKEY - Convertir una clave privada a/desde PKCS8

SINOPSIS

#include <openssl/x509.h>
PKCS8_PRIV_KEY_INFO *EVP_PKEY2PKCS8(const EVP_PKEY *pkey);
EVP_PKEY *EVP_PKCS82PKEY(const PKCS8_PRIV_KEY_INFO *p8);
EVP_PKEY *EVP_PKCS82PKEY_ex(const PKCS8_PRIV_KEY_INFO *p8, OSSL_LIB_CTX *libctx,
                            const char *propq);

DESCRIPCIÓN

EVP_PKEY2PKCS8() convierte una clave privada pkey en un objeto PKCS8 devuelto.

EVP_PKCS82PKEY_ex() convierte un objeto PKCS8 p8 en una clave privada devuelta. Utiliza libctx y propq al obtener algoritmos.

EVP_PKCS82PKEY() es similar a EVP_PKCS82PKEY_ex() pero utiliza valores predeterminados NULL para libctx y propq.

VALORES DE RETORNO

EVP_PKEY2PKCS8() devuelve un objeto PKCS8 en caso de éxito. EVP_PKCS82PKEY() y EVP_PKCS82PKEY_ex() devuelven una clave privada en caso de éxito.

Todas las funciones devuelven NULL si la operación falla.
