EVP_PKEY_derive(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_DERIVE(3ssl) OpenSSL EVP_PKEY_DERIVE(3ssl)

NOMBRE

EVP_PKEY_derive_init, EVP_PKEY_derive_init_ex, EVP_PKEY_derive_set_peer_ex, EVP_PKEY_derive_set_peer, EVP_PKEY_derive, EVP_PKEY_derive_SKEY - derivar secreto compartido de algoritmo de clave pública

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_derive_init(EVP_PKEY_CTX *ctx);
int EVP_PKEY_derive_init_ex(EVP_PKEY_CTX *ctx, const OSSL_PARAM params[]);
int EVP_PKEY_derive_set_peer_ex(EVP_PKEY_CTX *ctx, EVP_PKEY *peer,
                                int validate_peer);
int EVP_PKEY_derive_set_peer(EVP_PKEY_CTX *ctx, EVP_PKEY *peer);
int EVP_PKEY_derive(EVP_PKEY_CTX *ctx, unsigned char *key, size_t *keylen);
EVP_SKEY *EVP_PKEY_derive_SKEY(EVP_PKEY_CTX *ctx, EVP_SKEYMGMT *mgmt,
                               const char *key_type, const char *propquery,
                               size_t keylen, const OSSL_PARAM params[]);

DESCRIPCIÓN

EVP_PKEY_derive_init() inicializa un contexto de algoritmo de clave pública ctx para la derivación de un secreto compartido usando el algoritmo dado cuando se creó el contexto usando EVP_PKEY_CTX_new(3) o sus variantes. El algoritmo se usa para obtener un método EVP_KEYEXCH implícitamente, véase "Obtención implícita" en provider(7) para más información sobre obtenciones implícitas.

EVP_PKEY_derive_init_ex() es lo mismo que EVP_PKEY_derive_init() pero además establece los parámetros proporcionados params en el contexto antes de retornar.

EVP_PKEY_derive_set_peer_ex() establece la clave del oponente: normalmente será una clave pública. El parámetro validate_peer validará la clave pública si este valor no es cero.

EVP_PKEY_derive_set_peer() es similar a EVP_PKEY_derive_set_peer_ex() con validate_peer establecido a 1.

EVP_PKEY_derive() deriva un secreto compartido usando ctx. Si key es NULL, entonces el tamaño máximo del buffer de salida se escribe en el parámetro keylen. Si key no es NULL, entonces antes de la llamada, el parámetro keylen debe contener la longitud del buffer key; si la llamada tiene éxito, el secreto compartido se escribe en key y la cantidad de datos escritos en keylen.

EVP_PKEY_derive_SKEY() es similar a EVP_PKEY_derive() pero devuelve un objeto EVP_SKEY que almacena los datos opacos para la clave derivada. Si se proporciona un argumento EVP_SKEYMGMT, se usaría explícitamente para la creación de EVP_SKEY. De lo contrario, el objeto EVP_SKEYMGMT utilizado para EVP_SKEY se obtendría de acuerdo con skeymgmtname y propquery. Si skeymgmtname es NULL, se asume el nombre que coincide con el nombre del método de intercambio de claves.

NOTAS

Después de la llamada a EVP_PKEY_derive_init(), se pueden realizar operaciones de control específicas del algoritmo para establecer los parámetros apropiados para la operación.

La función EVP_PKEY_derive() se puede llamar más de una vez en el mismo contexto si se realizan varias operaciones utilizando los mismos parámetros.

VALORES DE RETORNO

EVP_PKEY_derive_init() y EVP_PKEY_derive() devuelven 1 para éxito y 0 o un valor negativo para fallo. En particular, un valor de retorno de -2 indica que la operación no es soportada por el algoritmo de clave pública.

EVP_PKEY_derive_SKEY() devuelve un objeto EVP_SKEY recién creado en caso de éxito o NULL en caso de fallo.

EJEMPLOS

Derivar un secreto compartido (por ejemplo, claves DH o EC):

#include <openssl/evp.h>
#include <openssl/rsa.h>
EVP_PKEY_CTX *ctx;
ENGINE *eng;
unsigned char *skey;
size_t skeylen;
EVP_PKEY *pkey, *peerkey;
/* NOTA: Se asume que pkey, eng, peerkey ya han sido configurados */
ctx = EVP_PKEY_CTX_new(pkey, eng);
if (!ctx)
    /* Ocurrió un error */
if (EVP_PKEY_derive_init(ctx) <= 0)
    /* Error */
if (EVP_PKEY_derive_set_peer(ctx, peerkey) <= 0)
    /* Error */
/* Determinar la longitud del buffer */
if (EVP_PKEY_derive(ctx, NULL, &skeylen) <= 0)
    /* Error */
skey = OPENSSL_malloc(skeylen);
if (!skey)
    /* Fallo de malloc */
if (EVP_PKEY_derive(ctx, skey, &skeylen) <= 0)
    /* Error */
/* El secreto compartido está en skey con skeylen bytes escritos en el buffer */

VER TAMBIÉN

EVP_PKEY_CTX_new(3), EVP_PKEY_encrypt(3), EVP_PKEY_decrypt(3), EVP_PKEY_sign(3), EVP_PKEY_verify(3), EVP_PKEY_verify_recover(3), EVP_KEYEXCH_fetch(3)

HISTORIA

Las funciones EVP_PKEY_derive_init(), EVP_PKEY_derive_set_peer() y EVP_PKEY_derive() se añadieron originalmente en OpenSSL 1.0.0.

Las funciones EVP_PKEY_derive_init_ex() y EVP_PKEY_derive_set_peer_ex() se añadieron en OpenSSL 3.0.

La función EVP_PKEY_derive_SKEY() se añadió en OpenSSL 3.6.
