NOMBRE

evp - funciones criptográficas de alto nivel

SINOPSIS

#include <openssl/evp.h>

DESCRIPCIÓN

La biblioteca EVP proporciona una interfaz de alto nivel a las funciones criptográficas.

Las funciones EVP_SealXXX y EVP_OpenXXX proporcionan cifrado y descifrado de clave pública para implementar "envelopes" digitales.

Las funciones EVP_DigestSignXXX y EVP_DigestVerifyXXX implementan firmas digitales y Códigos de Autenticación de Mensajes (MACs). Consulte también las funciones más antiguas EVP_SignXXX y EVP_VerifyXXX.

El cifrado simétrico está disponible con las funciones EVP_EncryptXXX. Las funciones EVP_DigestXXX proporcionan resúmenes de mensajes.

Las funciones EVP_PKEYXXX proporcionan una interfaz de alto nivel a los algoritmos asimétricos. Para crear una nueva EVP_PKEY, consulte EVP_PKEY_new(3). Las EVP_PKEYs pueden asociarse con una clave privada de un algoritmo particular utilizando las funciones descritas en la página EVP_PKEY_fromdata(3), o se pueden generar nuevas claves usando EVP_PKEY_keygen(3). Las EVP_PKEYs se pueden comparar usando EVP_PKEY_eq(3), o imprimir usando EVP_PKEY_print_private(3). EVP_PKEY_todata(3) se puede usar para convertir una clave de nuevo en un array de OSSL_PARAM(3).

Las funciones EVP_PKEY admiten toda la gama de operaciones de algoritmos asimétricos:

Para acuerdo de claves, consulte EVP_PKEY_derive(3)
Para firmar y verificar, consulte EVP_PKEY_sign(3), EVP_PKEY_verify(3) y EVP_PKEY_verify_recover(3). Sin embargo, tenga en cuenta que estas funciones no realizan un resumen de los datos a firmar. Por lo tanto, normalmente utilizaría las funciones EVP_DigestSignInit(3) para este propósito.
Para cifrar y descifrar, consulte EVP_PKEY_encrypt(3) y EVP_PKEY_decrypt(3) respectivamente. Sin embargo, tenga en cuenta que estas funciones solo realizan el cifrado y descifrado. Dado que el cifrado de clave pública es una operación costosa, normalmente encapsularía un mensaje cifrado en una "envelope" digital utilizando las funciones EVP_SealInit(3) y EVP_OpenInit(3).

La función EVP_BytesToKey(3) proporciona cierto soporte limitado para el cifrado basado en contraseña. La selección cuidadosa de los parámetros proporcionará una implementación compatible con PKCS#5 PBKDF1. Sin embargo, las nuevas aplicaciones normalmente no deberían usar esto (prefiriendo, por ejemplo, PBKDF2 de PKCS#5).

Las funciones EVP_EncodeXXX y EVP_DecodeXXX implementan la codificación y decodificación base64.

Todos los algoritmos simétricos (cifrados), resúmenes y algoritmos asimétricos (algoritmos de clave pública) pueden ser reemplazados por módulos ENGINE que proporcionen implementaciones alternativas. Si las implementaciones ENGINE de cifrados o resúmenes se registran como predeterminadas, las diversas funciones EVP utilizarán automáticamente esas implementaciones en lugar de las implementaciones de software integradas. Para obtener más información, consulte la página del manual de engine(3).

Aunque existen funciones de bajo nivel específicas de algoritmos para muchos de ellos, se desaconseja su uso. No se pueden usar con un ENGINE y las versiones de ENGINE de nuevos algoritmos no se pueden acceder mediante las funciones de bajo nivel. También hace que el código sea más difícil de adaptar a nuevos algoritmos y algunas opciones no se admiten limpiamente a bajo nivel, y algunas operaciones son más eficientes utilizando la interfaz de alto nivel.
