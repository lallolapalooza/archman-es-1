evince(1) Manual de Comandos Generales evince(1)

NOMBRE

evince - visor de documentos de GNOME

La aplicación Visor de Documentos Evince para el entorno de escritorio GNOME

SINTAXIS

evince [--ayuda] [--etiqueta-pagina=PAGINA | --indice-pagina=NUMERO | --destino-nombrado=DESTINO] [--pantalla-completa] [--presentacion] [--vista-previa] [--buscar=CADENA] [archivo(s)... O uri(s)...]

DESCRIPCIÓN

evince

Evince es un visor de documentos capaz de mostrar formatos de documentos de múltiples y una sola página como PDF y Postscript. Para información más general sobre Evince, visite nuestro sitio web en https://apps.gnome.org/Evince/

OPCIONES

-?, -h, --ayuda
Imprime las opciones de la línea de comandos.
-p, --etiqueta-pagina=PAGINA
Abre el documento en la página con la etiqueta de página (o número de página) especificada.
-i, --indice-pagina=NUMERO
Abre el documento en la página con el índice de página especificado (este es el número exacto de página, no una etiqueta de página).
-n, --destino-nombrado=DEST
Abre el documento en el destino nombrado especificado.
-f, --pantalla-completa
Ejecuta evince en modo de pantalla completa.
-s, --presentacion
Ejecuta evince en modo de presentación.
-l, --buscar=cadena
Puedes pasar una palabra o frase aquí. Si existe, evince mostrará el documento y la primera coincidencia.
archivo(s)... O uri(s)...
Especifica el archivo a abrir cuando se inicia Evince. Si no se especifica, Evince se abrirá con la vista de Archivos Recientes. Se pueden cargar múltiples archivos si están separados por espacios. Evince también soporta el manejo de archivos remotos. Por ejemplo, puedes pasar la ubicación en la web o cargar un archivo desde un servidor FTP, como "ftp://adobe.com/sample.pdf". También se permiten URIs de archivos, por ejemplo, "file:///home/usuario/Documentos/sample.pdf"

Soportamos parcialmente los parámetros de apertura de Adobe PDF, específicamente los parámetros "page" y "nameddest", que son similares a nuestras opciones --destino-nombrado y --etiqueta-pagina respectivamente. Algunos ejemplos a continuación:
- file:///home/usuario/Documentos/sample.pdf#pagina=12
- https://arxiv.org/pdf/2310.01425#nameddest=section.3
- sample.pdf#Page=5
- sample.pdf#NamedDest=Chapter4


Consejo: puedes obtener la lista de todos los destinos nombrados en un archivo pdf
con el comando "pdfinfo -dests" del paquete poppler-utils.

Evince también trata un parámetro numérico únicamente como el número de "página", por ejemplo:
- sample.pdf#5
- https://arxiv.org/pdf/2310.01425#7

Opciones de vista previa de impresión

Estas opciones están diseñadas principalmente para su uso con la función de vista previa de impresión de GTK+. Para más información sobre estas opciones, consulte https://docs.gtk.org/gtk3/property.Settings.gtk-print-preview-command.html

-w, --vista-previa
Ejecuta evince como un visor de vista previa.
--desenlazar-archivo-temporal
Si evince se ejecuta en modo de vista previa, esto desenlazará el archivo temporal creado por GTK+.
--configuracion-impresion %s %f
Esto envía la ruta completa del archivo PDF, f, y la configuración del diálogo de impresión, s, a evince.

ERRORES

Si encuentras un error, por favor repórtalo en https://gitlab.gnome.org/GNOME/evince/issues.
