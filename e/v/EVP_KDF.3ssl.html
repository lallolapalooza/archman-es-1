RETORNO

EVP_KDF_fetch() devuelve un puntero a una KDF recién obtenida EVP_KDF, o NULL si la asignación

falló.

EVP_KDF_get0_provider() devuelve un puntero al proveedor de la KDF, o NULL en caso de

error.

EVP_KDF_up_ref() devuelve 1 en caso de éxito, 0 en caso de

error.

EVP_KDF_CTX_new() devuelve la estructura EVP_KDF_CTX recién asignada o NULL si se produjo un

error.

EVP_KDF_CTX_free() y EVP_KDF_CTX_reset() no devuelven un

valor.

EVP_KDF_CTX_get_kdf_size() devuelve el tamaño de salida. Se devuelve SIZE_MAX para indicar que el algoritmo produce una cantidad variable de salida; 0 para indicar

fallo.

EVP_KDF_get0_name() devuelve el nombre de la KDF, o NULL en caso de

error.

EVP_KDF_names_do_all() devuelve 1 si se llamó a la función de retorno de llamada para todos los nombres. Un valor de retorno de 0 significa que la función de retorno de llamada no se llamó para ningún

nombre.

EVP_KDF_derive_SKEY() devuelve el objeto EVP_SKEY en caso de éxito o NULL en caso de

fallo.

Las funciones restant

es devuelven 1 para éx
ito y 0 para fallo.
