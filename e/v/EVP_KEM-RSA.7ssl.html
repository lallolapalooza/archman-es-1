EVP_KEM-RSA(7ssl)

Paquete: openssl

EVP_KEM-RSA(7ssl) OpenSSL EVP_KEM-RSA(7ssl)

NOMBRE

EVP_KEM-RSA - Soporte para el tipo de clave y algoritmo EVP_KEM RSA

DESCRIPCIÓN

El tipo de clave RSA y sus parámetros se describen en EVP_PKEY-RSA(7). Vea EVP_PKEY_encapsulate(3) y EVP_PKEY_decapsulate(3) para más información.

Parámetros RSA KEM

"operation" (OSSL_KEM_PARAM_OPERATION) <cadena UTF8>
El Mecanismo de Encapsulación de Clave RSA de OpenSSL solo admite actualmente la siguiente operación predeterminada (modo de operación):
"RSASVE"
La función de encapsulación simplemente genera un secreto usando bytes aleatorios y luego cifra el secreto usando la clave pública RSA (sin relleno). La función de decapsulación recupera el secreto usando la clave privada RSA.

Esto se puede configurar usando EVP_PKEY_CTX_set_kem_op().

"fips-indicator" (OSSL_KEM_PARAM_FIPS_APPROVED_INDICATOR) <entero>
"key-check" (OSSL_KEM_PARAM_FIPS_KEY_CHECK) <entero>
Estos parámetros se describen en provider-kem(7).

CONFORME A

SP800-56Br2
Sección 7.2.1.2 Operación de Generación RSASVE (RSASVE.GENERATE). Sección 7.2.1.3 Operación de Recuperación RSASVE (RSASVE.RECOVER).

VER TAMBIÉN

EVP_PKEY_CTX_set_kem_op(3), EVP_PKEY_encapsulate(3), EVP_PKEY_decapsulate(3) EVP_KEYMGMT(3), EVP_PKEY(3), provider-keymgmt(7)

HISTORIA

Esta funcionalidad se añadió en OpenSSL 3.0.

El "operation" (modo de operación) era un parámetro obligatorio antes de OpenSSL 3.5. A partir de OpenSSL 3.5, "RSASVE" es el modo de operación predeterminado, y no es necesario especificar un valor explícito.
