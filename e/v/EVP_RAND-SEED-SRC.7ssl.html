NOMBRE

EVP_RAND-SEED-SRC - La implementación de EVP_RAND de fuente de semilla de aleatoriedad

DESCRIPCIÓN

Soporte para la siembra de generadores de números pseudoaleatorios deterministas a través de la API EVP_RAND.

Las fuentes de semilla utilizadas se especifican en el momento en que OpenSSL se configura para la compilación usando la opción --with-rand-seed=. Por defecto, se utilizan fuentes de aleatoriedad del sistema operativo.

Identidad

"SEED-SRC" es el nombre de esta implementación; se puede usar con la función EVP_RAND_fetch().

Parámetros soportados

Los parámetros soportados son:

"state" (OSSL_RAND_PARAM_STATE) <entero>
"strength" (OSSL_RAND_PARAM_STRENGTH) <entero sin signo>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <entero sin signo>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_RAND(3).

NOTAS

Se puede obtener un contexto para la fuente de semilla llamando a:

EVP_RAND *rand = EVP_RAND_fetch(NULL, "SEED-SRC", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

EJEMPLOS

EVP_RAND *rand;
EVP_RAND_CTX *seed, *rctx;
unsigned char bytes[100];
OSSL_PARAM params[2], *p = params;
unsigned int strength = 128;
/* Crear e instanciar una fuente de semilla */
rand = EVP_RAND_fetch(NULL, "SEED-SRC", NULL);
seed = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_instantiate(seed, strength, 0, NULL, 0, NULL);
EVP_RAND_free(rand);
/* Introducir esto en un DRBG */
rand = EVP_RAND_fetch(NULL, "CTR-DRBG", NULL);
rctx = EVP_RAND_CTX_new(rand, seed);
EVP_RAND_free(rand);
/* Configurar el DRBG */
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_DRBG_PARAM_CIPHER,
                                        SN_aes_256_ctr, 0);
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);
EVP_RAND_CTX_free(seed);
