EVP_PKEY_CTX_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_CTX_NEW(3ssl) OpenSSL EVP_PKEY_CTX_NEW(3ssl)

NOMBRE

EVP_PKEY_CTX_new, EVP_PKEY_CTX_new_id, EVP_PKEY_CTX_new_from_name, EVP_PKEY_CTX_new_from_pkey, EVP_PKEY_CTX_dup, EVP_PKEY_CTX_free, EVP_PKEY_CTX_is_a - funciones de contexto de algoritmo de clave pública

SINOPSIS

#include <openssl/evp.h>
EVP_PKEY_CTX *EVP_PKEY_CTX_new(EVP_PKEY *pkey, ENGINE *e);
EVP_PKEY_CTX *EVP_PKEY_CTX_new_id(int id, ENGINE *e);
EVP_PKEY_CTX *EVP_PKEY_CTX_new_from_name(OSSL_LIB_CTX *libctx,
                                         const char *name,
                                         const char *propquery);
EVP_PKEY_CTX *EVP_PKEY_CTX_new_from_pkey(OSSL_LIB_CTX *libctx,
                                         EVP_PKEY *pkey,
                                         const char *propquery);
EVP_PKEY_CTX *EVP_PKEY_CTX_dup(const EVP_PKEY_CTX *ctx);
void EVP_PKEY_CTX_free(EVP_PKEY_CTX *ctx);
int EVP_PKEY_CTX_is_a(EVP_PKEY_CTX *ctx, const char *keytype);

DESCRIPCIÓN

La función EVP_PKEY_CTX_new() asigna un contexto de algoritmo de clave pública usando el tipo de clave pkey y el ENGINE e.

La función EVP_PKEY_CTX_new_id() asigna un contexto de algoritmo de clave pública usando el tipo de clave especificado por id y el ENGINE e.

La función EVP_PKEY_CTX_new_from_name() asigna un contexto de algoritmo de clave pública usando el contexto de biblioteca libctx (véase OSSL_LIB_CTX(3)), el tipo de clave especificado por name y la consulta de propiedades propquery. Ninguno de los argumentos se duplica, por lo que deben permanecer sin cambios durante la vida útil del EVP_PKEY_CTX devuelto o de cualquiera de sus duplicados. Lea más sobre los nombres posibles en "NOTAS" más abajo.

La función EVP_PKEY_CTX_new_from_pkey() asigna un contexto de algoritmo de clave pública usando el contexto de biblioteca libctx (véase OSSL_LIB_CTX(3)) y el algoritmo especificado por pkey y la consulta de propiedades propquery. Ninguno de los argumentos se duplica, por lo que deben permanecer sin cambios durante la vida útil del EVP_PKEY_CTX devuelto o de cualquiera de sus duplicados.

EVP_PKEY_CTX_new_id() y EVP_PKEY_CTX_new_from_name() se usan normalmente cuando no hay una estructura EVP_PKEY asociada con las operaciones, por ejemplo durante la generación de parámetros o la generación de claves para algunos algoritmos.

EVP_PKEY_CTX_dup() duplica el contexto ctx. No está soportado para una operación de generación de claves. Sin embargo, es posible duplicar un contexto recién creado mediante cualquiera de las funciones "new" anteriores, siempre que EVP_PKEY_keygen_init(3) aún no se haya llamado en el contexto de origen, y luego usar la copia para la generación de claves.

EVP_PKEY_CTX_free() libera el contexto ctx. Si ctx es NULL, no se hace nada.

EVP_PKEY_is_a() comprueba si el tipo de clave asociado con ctx es keytype.

NOTAS

Sobre EVP_PKEY_CTX

La estructura EVP_PKEY_CTX es un contexto opaco de algoritmo de clave pública usado por la API de clave pública de alto nivel de OpenSSL. Los contextos NO DEBEN compartirse entre hilos: es decir, no se permite usar el mismo contexto simultáneamente en dos hilos.

Sobre los tipos de clave

En este manual mencionamos "tipo de clave", que es lo mismo que "algoritmo" en la mayoría de los casos, permitiendo usar cualquiera de los términos de forma intercambiable. Hay algoritmos en los que el tipo de clave y el algoritmo de las operaciones que usan las claves no son el mismo, como las claves EC usadas para operaciones ECDSA y ECDH.

Los tipos de clave se dan de dos maneras diferentes:

NID legado o tipo EVP_PKEY
Este es el id usado con EVP_PKEY_CTX_new_id().

Estos son EVP_PKEY_RSA, EVP_PKEY_RSA_PSS, EVP_PKEY_DSA, EVP_PKEY_DH, EVP_PKEY_EC, EVP_PKEY_SM2, EVP_PKEY_X25519, EVP_PKEY_X448, y son usados por métodos legados.

Cadenas de nombre
Este es el name usado con EVP_PKEY_CTX_new_from_name().

Estos son nombres como "RSA", "DSA", y lo que está disponible depende de qué proveedores estén actualmente accesibles.

Los proveedores de OpenSSL ofrecen un conjunto de tipos de clave disponibles de esta manera, consulte OSSL_PROVIDER-FIPS(7) y OSSL_PROVIDER-default(7) y la documentación relacionada para más información.

VALORES DE RETORNO

EVP_PKEY_CTX_new(), EVP_PKEY_CTX_new_id() y EVP_PKEY_CTX_dup() devuelven la estructura EVP_PKEY_CTX recién asignada o NULL si ocurrió un error.

EVP_PKEY_CTX_free() no devuelve un valor.

EVP_PKEY_CTX_is_a() devuelve 1 para verdadero y 0 para falso.

VÉASE TAMBIÉN

EVP_PKEY_new(3)

HISTORIA

Las funciones EVP_PKEY_CTX_new(), EVP_PKEY_CTX_new_id(), EVP_PKEY_CTX_dup() y EVP_PKEY_CTX_free() se añadieron en OpenSSL 1.0.0.

Las funciones EVP_PKEY_CTX_new_from_name() y EVP_PKEY_CTX_new_from_pkey() se añadieron en OpenSSL 3.0.
