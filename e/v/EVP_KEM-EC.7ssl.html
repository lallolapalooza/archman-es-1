NOMBRE

EVP_KEM-EC - Soporte para el tipo de clave EVP_KEM y algoritmo EC

DESCRIPCIÓN

El tipo de clave EC y sus parámetros se describen en EVP_PKEY-EC(7). Consulte EVP_PKEY_encapsulate(3) y EVP_PKEY_decapsulate(3) para obtener más información.

PARÁMETROS EC KEM

"operation" (OSSL_KEM_PARAM_OPERATION)<cadena UTF8>
Los Mecanismos de Encapsulación de Clave EC de OpenSSL solo admiten la siguiente operación predeterminada (modo de operación):
"DHKEM" (OSSL_KEM_PARAM_OPERATION_DHKEM)
La función de encapsulación genera un par de claves efímero. Produce material clave realizando un intercambio de claves ECDH utilizando la clave privada efímera y una clave pública del destinatario proporcionada. Una operación HKDF utilizando el material clave y un contexto KEM produce un secreto compartido. Se devuelven el secreto compartido y la clave pública efímera. La función de descapsulación utiliza la clave privada del destinatario y la clave pública efímera para producir el mismo material clave, que luego se puede usar para producir el mismo secreto compartido. Consulte https://www.rfc-editor.org/rfc/rfc9180.html#name-dh-based-kem-dhkem

Esto se puede establecer usando EVP_PKEY_CTX_set_kem_op(3) o EVP_PKEY_CTX_set_params(3).

"ikme" (OSSL_KEM_PARAM_IKME) <cadena de octetos>
Se utiliza para especificar el material clave utilizado para la generación de la clave efímera. Este valor no debe reutilizarse para otros fines. Solo se puede utilizar para las curvas "P-256", "P-384" y "P-521" y debe tener una longitud de al menos el tamaño de la clave privada codificada (es decir, 32, 48 y 66 para las curvas listadas). Si este valor no está establecido, se utiliza un ikm aleatorio.

CONFORME A

RFC9180

VER TAMBIÉN

EVP_PKEY_CTX_set_kem_op(3), EVP_PKEY_encapsulate(3), EVP_PKEY_decapsulate(3) EVP_KEYMGMT(3), EVP_PKEY(3), provider-keymgmt(7)

HISTORIAL

Esta funcionalidad se añadió en OpenSSL 3.2.

El "operation" (modo de operación) era un parámetro obligatorio antes de OpenSSL 3.5. A partir de OpenSSL 3.5, "DHKEM" es el modo de operación predeterminado, y no es necesario especificar ningún valor explícito.
