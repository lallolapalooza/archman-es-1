EVP_PKEY_encrypt(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_ENCRYPT(3ssl) OpenSSL EVP_PKEY_ENCRYPT(3ssl)

NOMBRE

EVP_PKEY_encrypt_init_ex, EVP_PKEY_encrypt_init, EVP_PKEY_encrypt - cifrar usando un algoritmo de clave pública

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_encrypt_init(EVP_PKEY_CTX *ctx);
int EVP_PKEY_encrypt_init_ex(EVP_PKEY_CTX *ctx, const OSSL_PARAM params[]);
int EVP_PKEY_encrypt(EVP_PKEY_CTX *ctx,
                     unsigned char *out, size_t *outlen,
                     const unsigned char *in, size_t inlen);

DESCRIPCIÓN

La función EVP_PKEY_encrypt_init() inicializa un contexto de algoritmo de clave pública usando la clave pkey para una operación de cifrado.

La función EVP_PKEY_encrypt_init_ex() inicializa un contexto de algoritmo de clave pública usando la clave pkey para una operación de cifrado y establece los params específicos del algoritmo.

La función EVP_PKEY_encrypt() realiza una operación de cifrado de clave pública usando ctx. Los datos a cifrar se especifican usando los parámetros in e inlen. Si out es NULL, entonces el tamaño máximo del buffer de salida se escribe en el parámetro outlen. Si out no es NULL, entonces antes de la llamada, el parámetro outlen debe contener la longitud del buffer out; si la llamada es exitosa, los datos cifrados se escriben en out y la cantidad de datos escritos se almacena en outlen.

NOTAS

Después de la llamada a EVP_PKEY_encrypt_init() se pueden realizar operaciones de control específicas del algoritmo para establecer cualquier parámetro apropiado para la operación. Estas operaciones pueden incluirse en la llamada EVP_PKEY_encrypt_init_ex().

La función EVP_PKEY_encrypt() se puede llamar más de una vez en el mismo contexto si se realizan varias operaciones usando los mismos parámetros.

VALORES DE RETORNO

EVP_PKEY_encrypt_init(), EVP_PKEY_encrypt_init_ex() y EVP_PKEY_encrypt() devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

EJEMPLOS

Cifrar datos usando OAEP (para claves RSA). Ver también PEM_read_PUBKEY(3) o d2i_X509(3) para medios de cargar una clave pública. También puede simplemente establecer 'eng = NULL;' para comenzar con la implementación RSA predeterminada de OpenSSL:

#include <openssl/evp.h>
#include <openssl/rsa.h>
#include <openssl/engine.h>
EVP_PKEY_CTX *ctx;
ENGINE *eng;
unsigned char *out, *in;
size_t outlen, inlen;
EVP_PKEY *key;
/*
 * NOTA: asume que eng, key, in, inlen ya están configurados,
 * y que key es una clave pública RSA
 */
ctx = EVP_PKEY_CTX_new(key, eng);
if (!ctx)
    /* Ocurrió un error */
if (EVP_PKEY_encrypt_init(ctx) <= 0)
    /* Error */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING) <= 0)
    /* Error */
/* Determinar la longitud del buffer */
if (EVP_PKEY_encrypt(ctx, NULL, &outlen, in, inlen) <= 0)
    /* Error */
out = OPENSSL_malloc(outlen);
if (!out)
    /* Fallo de malloc */
if (EVP_PKEY_encrypt(ctx, out, &outlen, in, inlen) <= 0)
    /* Error */
/* Los datos cifrados son outlen bytes escritos en el buffer out */
