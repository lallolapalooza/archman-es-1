EVP_PKEY_settable_params(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_SETTABLE_PARAMS(3ssl) OpenSSL EVP_PKEY_SETTABLE_PARAMS(3ssl)

NOMBRE

EVP_PKEY_SETTABLE_PARAMS, EVP_PKEY_set_params, EVP_PKEY_set_int_param, EVP_PKEY_set_size_t_param, EVP_PKEY_set_bn_param, EVP_PKEY_set_utf8_string_param, EVP_PKEY_set_octet_string_param - establecer parámetros de clave en una clave

SINOPSIS

#include <openssl/evp.h>
const OSSL_PARAM *EVP_PKEY_settable_params(const EVP_PKEY *pkey);
int EVP_PKEY_set_params(EVP_PKEY *pkey, OSSL_PARAM params[]);
int EVP_PKEY_set_int_param(EVP_PKEY *pkey, const char *key_name, int in);
int EVP_PKEY_set_size_t_param(EVP_PKEY *pkey, const char *key_name, size_t in);
int EVP_PKEY_set_bn_param(EVP_PKEY *pkey, const char *key_name,
                          const BIGNUM *bn);
int EVP_PKEY_set_utf8_string_param(EVP_PKEY *pkey, const char *key_name,
                                   const char *str);
int EVP_PKEY_set_octet_string_param(EVP_PKEY *pkey, const char *key_name,
                                    const unsigned char *buf, size_t bsize);

DESCRIPCIÓN

Estas funciones se pueden usar para establecer parámetros adicionales en una EVP_PKEY existente.

EVP_PKEY_set_params() establece uno o más params en un pkey. Consulte OSSL_PARAM(3) para obtener información sobre los parámetros.

EVP_PKEY_settable_params() devuelve una lista constante de params que indica los nombres y tipos de los parámetros de clave que se pueden establecer. Consulte OSSL_PARAM(3) para obtener información sobre los parámetros.

EVP_PKEY_set_int_param() establece un valor entero in en una clave pkey para el campo asociado key_name.

EVP_PKEY_set_size_t_param() establece un valor size_t in en una clave pkey para el campo asociado key_name.

EVP_PKEY_set_bn_param() establece el valor BIGNUM bn en una clave pkey para el campo asociado key_name.

EVP_PKEY_set_utf8_string_param() establece la cadena UTF8 str en una clave pkey para el campo asociado key_name.

EVP_PKEY_set_octet_string_param() establece el valor de cadena de octetos buf con un tamaño bsize en una clave pkey para el campo asociado key_name.

NOTAS

Estas funciones solo funcionan para EVP_PKEYs que contienen una clave del lado del proveedor.

VALORES DE RETORNO

EVP_PKEY_settable_params() devuelve NULL en caso de error o si no se admite.

Todos los demás métodos devuelven 1 si se estableció un valor correctamente, o 0 si hubo un error.

VER TAMBIÉN

EVP_PKEY_gettable_params(3), EVP_PKEY_CTX_new(3), provider-keymgmt(7), OSSL_PARAM(3),

HISTORIA

Estas funciones se agregaron en OpenSSL 3.0.
