EVP_OPENINIT(3ssl) OpenSSL EVP_OPENINIT(3ssl)

NOMBRE

EVP_OpenInit, EVP_OpenUpdate, EVP_OpenFinal - Descifrado de sobre EVP

SINOPSIS

#include <openssl/evp.h>
int EVP_OpenInit(EVP_CIPHER_CTX *ctx, EVP_CIPHER *type, unsigned char *ek,
                 int ekl, unsigned char *iv, EVP_PKEY *priv);
int EVP_OpenUpdate(EVP_CIPHER_CTX *ctx, unsigned char *out,
                   int *outl, unsigned char *in, int inl);
int EVP_OpenFinal(EVP_CIPHER_CTX *ctx, unsigned char *out, int *outl);

DESCRIPCIÓN

Las rutinas de sobre EVP son una interfaz de alto nivel para el descifrado de sobres. Descifran una clave simétrica cifrada con clave pública y luego descifran datos usando ella.

EVP_OpenInit() inicializa un contexto de cifrado ctx para descifrar con el cifrador type. Descifra la clave simétrica cifrada de longitud ekl bytes pasada en el parámetro ek usando la clave privada priv. El IV se proporciona en el parámetro iv.

EVP_OpenUpdate() y EVP_OpenFinal() tienen exactamente las mismas propiedades que las rutinas EVP_DecryptUpdate() y EVP_DecryptFinal(), como se documenta en la página del manual de EVP_EncryptInit(3).

NOTAS

Es posible llamar a EVP_OpenInit() dos veces de la misma manera que EVP_DecryptInit(). La primera llamada debe tener priv establecido en NULL y (después de establecer cualquier parámetro de cifrado) debe ser llamada de nuevo con type establecido en NULL.

Si el cifrador pasado en el parámetro type es un cifrador de longitud variable, la longitud de la clave se establecerá en el valor de la longitud de la clave recuperada. Si el cifrador es un cifrador de longitud fija, la longitud de la clave recuperada debe coincidir con la longitud fija del cifrador.

VALORES DE RETORNO

EVP_OpenInit() devuelve 0 en caso de error o un entero no nulo (en realidad, el tamaño de la clave secreta recuperada) si tiene éxito.

EVP_OpenUpdate() devuelve 1 para éxito o 0 para fallo.

EVP_OpenFinal() devuelve 0 si el descifrado falló o 1 para éxito.
