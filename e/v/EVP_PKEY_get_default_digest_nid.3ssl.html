EVP_PKEY_get_default_digest_nid(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_GET_DEFAULT_DIGEST_NID(3ssl) OpenSSL EVP_PKEY_GET_DEFAULT_DIGEST_NID(3ssl)

NOMBRE

EVP_PKEY_get_default_digest_name, EVP_PKEY_get_default_digest_nid - obtener digest por defecto para firma

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_get_default_digest_name(EVP_PKEY *pkey,
                                     char *mdname, size_t mdname_sz);
int EVP_PKEY_get_default_digest_nid(EVP_PKEY *pkey, int *pnid);

DESCRIPCIÓN

EVP_PKEY_get_default_digest_name() rellena el nombre del digest de mensaje por defecto para las operaciones de firma de clave pública asociadas con la clave pkey en mdname, hasta un máximo de mdname_sz bytes, incluyendo el byte NUL final. El nombre podría ser "UNDEF", lo que significa que un digest debe (para valor de retorno 2) o puede (para valor de retorno 1) dejarse sin especificar.

EVP_PKEY_get_default_digest_nid() establece pnid al NID del digest de mensaje por defecto para las operaciones de firma de clave pública asociadas con la clave pkey. Tenga en cuenta que algunos algoritmos de firma (es decir, Ed25519 y Ed448) no utilizan un digest durante la firma. En este caso, pnid se establecerá en NID_undef. Esta función solo es fiable para claves heredadas, que son claves con un EVP_PKEY_ASN1_METHOD; estas claves normalmente se han cargado desde motores, o se han creado con EVP_PKEY_assign_RSA(3) o similar.

NOTAS

Para todos los algoritmos de clave pública estándar actuales de OpenSSL, se devuelve SHA256.

VALORES DE RETORNO

EVP_PKEY_get_default_digest_name() y EVP_PKEY_get_default_digest_nid() devuelven 1 si el digest de mensaje es informativo (es decir, se pueden usar otros digests) y 2 si es obligatorio (no se pueden usar otros digests). Devuelven 0 o un valor negativo en caso de error. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

VER TAMBIÉN

EVP_PKEY_CTX_new(3), EVP_PKEY_sign(3), EVP_PKEY_digestsign_supports_digest(3), EVP_PKEY_verify(3), EVP_PKEY_verify_recover(3),

HISTORIA

Esta función se añadió en OpenSSL 1.0.0.
