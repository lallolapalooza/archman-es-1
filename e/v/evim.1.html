EVIM(1) Manual de Comandos Generales EVIM(1)

NOMBRE

evim - Vim fácil, edita un archivo con Vim y configuración para edición sin modo

SINOPSIS

evim [opciones] [archivo ..]
eview

DESCRIPCIÓN

eVim inicia Vim y establece opciones para que se comporte como un editor sin modo. Sigue siendo Vim pero se usa como un editor de apuntar y hacer clic. Se siente muy parecido a usar el Bloc de notas en MS-Windows. eVim siempre se ejecutará en la GUI, para permitir el uso de menús y la barra de herramientas.

Solo debe ser utilizado por personas que realmente no pueden trabajar con Vim de la manera normal. La edición será mucho menos eficiente.

eview es lo mismo, pero se inicia en modo de solo lectura. Funciona igual que evim -R.

Consulte vim(1) para obtener detalles sobre Vim, opciones, etc.

La opción 'insertmode' está configurada para poder escribir texto directamente.
Se configuran asignaciones para que Copiar y Pegar funcionen con las teclas de MS-Windows. CTRL-X corta texto, CTRL-C copia texto y CTRL-V pega texto. Use CTRL-Q para obtener el significado original de CTRL-V.

OPCIONES

Consulte vim(1).

ARCHIVOS

/usr/local/share/vim/vim??/evim.vim
El script cargado para inicializar eVim.
vim?? es el número de versión corto, como vim91 para Vim 9.1

APODO

También conocido como "Vim para gumbies". Cuando use evim se espera que tome un pañuelo, haga un nudo en cada esquina y lo use en la cabeza.
