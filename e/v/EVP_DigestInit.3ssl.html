DESCRIPCIÓ

N

Las rutinas de resumen de EVP son una interfaz de alto nivel para los resúmenes de mensajes y las Funciones de Salida Extensible (XOF)

.

El tipo EVP_MD es una estructura para la implementación del método de

resumen.

Cada algoritmo de resumen de mensajes (como SHA256) produce una longitud de salida de tamaño fijo que se devuelve cuando se llama a EVP_DigestFinal_ex(). Las Funciones de Salida Extensible (XOF) como SHAKE256 tienen una longitud de salida de tamaño variable outlen que puede usarse con EVP_DigestFinalXOF() o EVP_DigestSqueeze(). EVP_DigestFinal_ex() también puede usarse para un XOF, pero "xoflen" debe establecerse previamente (Ver "PARÁMETROS"). Nótese que EVP_MD_get_size() y EVP_MD_CTX_get_size_ex() se comportan de manera diferente para un

XOF.

NOTA

S

La interfaz EVP para resúmenes de mensajes casi siempre debe usarse en lugar de las interfaces de bajo nivel. Esto se debe a que el código se vuelve transparente al resumen utilizado y mucho más

flexible.

Las nuevas aplicaciones deben usar los algoritmos de resumen SHA-2 (como EVP_sha256(3)) o SHA-3 (como EVP_sha3_512(3)). Los otros algoritmos de resumen todavía se usan

comúnmente.

Para la mayoría de las aplicaciones, el parámetro impl de EVP_DigestInit_ex() se establecerá en NULL para usar la implementación de resumen

predeterminada.

Ignorar los retornos de fallo de EVP_DigestInit_ex(), EVP_DigestInit_ex2() o EVP_DigestInit() puede llevar a un comportamiento no definido en llamadas posteriores que actualicen o finalicen el EVP_MD_CTX, como las funciones EVP_DigestUpdate() o EVP_DigestFinal(). Las únicas llamadas válidas en el EVP_MD_CTX cuando la inicialización falla son las que intentan otra inicialización del contexto o liberan el

contexto.

Las funciones EVP_DigestInit(), EVP_DigestFinal() y EVP_MD_CTX_copy() están obsoletas pero se conservan para mantener la compatibilidad con el código existente. Las nuevas aplicaciones deben usar EVP_DigestInit_ex(), EVP_DigestFinal_ex() y EVP_MD_CTX_copy_ex() porque pueden reutilizar eficientemente un contexto de resumen en lugar de inicializarlo y limpiarlo en cada llamada, y permiten especificar implementaciones de resumen no predeterminadas

.

Si los contextos de resumen no se limpian después de su uso, ocurrirán fugas de

memoria.

EVP_MD_CTX_get0_name(), EVP_MD_CTX_get_size(), EVP_MD_CTX_get_block_size(), EVP_MD_CTX_get_type(), EVP_get_digestbynid() y EVP_get_digestbyobj() están definidas como

macros.

EVP_MD_CTX_ctrl() envía comandos a los resúmenes de

mensajes para configur
ación o control adicional.

EJEMPLO

S

Este ejemplo genera el resumen de los datos "Test Message\n" y "Hello World\n", usando el nombre del resumen pasado en la línea de

comandos. 
#include <stdio.h>
#include <string.h>
#include <openssl/evp.h>
int main(int argc, char *argv[])
{
    EVP_MD_CTX *mdctx;
    const EVP_MD *md;
    char mess1[] = "Test Message\n";
    char mess2[] = "Hello World\n";
    unsigned char md_value[EVP_MAX_MD_SIZE];
    unsigned int md_len, i;
    if (argv[1] == NULL) {
        printf("Usage: mdtest digestname\n");
        exit(1);
    }
    md = EVP_get_digestbyname(argv[1]);
    if (md == NULL) {
        printf("Unknown message digest %s\n", argv[1]);
        exit(1);
    }
    mdctx = EVP_MD_CTX_new();
    if (mdctx == NULL) {
       printf("Message digest create failed.\n");
       exit(1);
    }
    if (!EVP_DigestInit_ex2(mdctx, md, NULL)) {
        printf("Message digest initialization failed.\n");
        EVP_MD_CTX_free(mdctx);
        exit(1);
    }
    if (!EVP_DigestUpdate(mdctx, mess1, strlen(mess1))) {
        printf("Message digest update failed.\n");
        EVP_MD_CTX_free(mdctx);
        exit(1);
    }
    if (!EVP_DigestUpdate(mdctx, mess2, strlen(mess2))) {
        printf("Message digest update failed.\n");
        EVP_MD_CTX_free(mdctx);
        exit(1);
    }
    if (!EVP_DigestFinal_ex(mdctx, md_value, &md_len)) {
        printf("Message digest finalization failed.\n");
        EVP_MD_CTX_free(mdctx);
        exit(1);
    }
    EVP_MD_CTX_free(mdctx);
    printf("Digest is: ");
    for (i = 0; i < md_len; i++)
        printf("%02x", md_value[i]);
    printf("\n");
    exit(0);
}
