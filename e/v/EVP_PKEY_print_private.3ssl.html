EVP_PKEY_print_private(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_PRINT_PRIVATE(3ssl) OpenSSL EVP_PKEY_PRINT_PRIVATE(3ssl)

NOMBRE

EVP_PKEY_print_public, EVP_PKEY_print_private, EVP_PKEY_print_params, EVP_PKEY_print_public_fp, EVP_PKEY_print_private_fp, EVP_PKEY_print_params_fp - rutinas de impresión de algoritmos de clave pública

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_print_public(BIO *out, const EVP_PKEY *pkey,
                          int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_public_fp(FILE *fp, const EVP_PKEY *pkey,
                             int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_private(BIO *out, const EVP_PKEY *pkey,
                           int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_private_fp(FILE *fp, const EVP_PKEY *pkey,
                              int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_params(BIO *out, const EVP_PKEY *pkey,
                          int indent, ASN1_PCTX *pctx);
int EVP_PKEY_print_params_fp(FILE *fp, const EVP_PKEY *pkey,
                             int indent, ASN1_PCTX *pctx);

DESCRIPCIÓN

Las funciones EVP_PKEY_print_public(), EVP_PKEY_print_private() y EVP_PKEY_print_params() imprimen los componentes públicos, privados o de parámetros de la clave pkey respectivamente. La clave se envía a BIO out en formato legible. El parámetro indent indica el nivel de sangría de la impresión.

El parámetro pctx permite ajustar finamente la salida de la impresión utilizando opciones de impresión ASN1. Si pctx se establece en NULL, se utilizarán los valores predeterminados.

Las funciones EVP_PKEY_print_public_fp(), EVP_PKEY_print_private_fp() y EVP_PKEY_print_params_fp() hacen lo mismo que las funciones basadas en BIO, pero utilizan FILE fp en su lugar.

NOTAS

Actualmente, ningún algoritmo de clave pública incluye opciones en el parámetro pctx.

Si la clave no incluye todos los componentes indicados por la función, solo se imprimirán aquellos contenidos en la clave. Por ejemplo, pasar una clave pública a EVP_PKEY_print_private() solo imprimirá los componentes públicos.

VALORES DEVUELTOS

Estas funciones devuelven 1 en caso de éxito y 0 o un valor negativo en caso de error. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

VER TAMBIÉN

EVP_PKEY_CTX_new(3), EVP_PKEY_keygen(3)

HISTORIAL

Las funciones EVP_PKEY_print_public(), EVP_PKEY_print_private() y EVP_PKEY_print_params() se añadieron en OpenSSL 1.0.0.

Las funciones EVP_PKEY_print_public_fp(), EVP_PKEY_print_private_fp() y EVP_PKEY_print_params_fp() se añadieron en OpenSSL 3.0.
