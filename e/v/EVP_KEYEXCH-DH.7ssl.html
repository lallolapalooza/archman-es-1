NOMBRE

EVP_KEYEXCH-DH - Soporte para el algoritmo de intercambio de claves DH

DESCRIPCIÓN

Soporte para intercambio de claves para los tipos de clave DH y DHX.

Tenga en cuenta que aunque ambos tipos de clave soportan las mismas operaciones de intercambio de claves, no pueden usarse juntos en un único intercambio de claves. No es posible usar una clave privada del tipo DH en un intercambio de claves con la clave pública del tipo DHX y viceversa.

Parámetros de intercambio de claves DH y DHX

"pad" (OSSL_EXCHANGE_PARAM_PAD) <entero sin signo>
Establece el modo de relleno para el contexto de intercambio de claves asociado. Establecer un valor de 1 activará el relleno. Establecer un valor de 0 desactivará el relleno. Si el relleno está desactivado, el secreto compartido derivado puede ser menor que el tamaño máximo posible del secreto. Si el relleno está activado, los primeros bytes del secreto compartido derivado se rellenarán con ceros donde sea necesario para que el secreto compartido tenga el mismo tamaño que el tamaño máximo posible del secreto. El parámetro de modo de relleno se ignora (y el relleno se activa implícitamente) cuando el tipo de KDF se establece en "X942KDF-ASN1" (OSSL_KDF_NAME_X942KDF_ASN1).
"kdf-type" (OSSL_EXCHANGE_PARAM_KDF_TYPE) <cadena UTF8>
"kdf-digest" (OSSL_EXCHANGE_PARAM_KDF_DIGEST) <cadena UTF8>
"kdf-digest-props" (OSSL_EXCHANGE_PARAM_KDF_DIGEST_PROPS) <cadena UTF8>
"kdf-outlen" (OSSL_EXCHANGE_PARAM_KDF_OUTLEN) <entero sin signo>
"kdf-ukm" (OSSL_EXCHANGE_PARAM_KDF_UKM) <cadena de octetos>
"fips-indicator" (OSSL_EXCHANGE_PARAM_FIPS_APPROVED_INDICATOR) <entero>
"key-check" (OSSL_EXCHANGE_PARAM_FIPS_KEY_CHECK) <entero>
"digest-check" (OSSL_EXCHANGE_PARAM_FIPS_DIGEST_CHECK) <entero>
Ver "Parámetros comunes de intercambio de claves" en provider-keyexch(7).
"cekalg" (OSSL_KDF_PARAM_CEK_ALG) <puntero a cadena de octetos>
Ver "Parámetros KDF" en provider-kdf(7).

EJEMPLOS

Los ejemplos asumen que tanto el host como el peer generan claves utilizando el mismo grupo nombrado (o parámetros de dominio). Ver "Ejemplos" en EVP_PKEY-DH(7). Tanto el host como el peer se transfieren mutuamente sus claves públicas.

Para convertir el par de claves generado por el peer a formato DER de clave pública para transferirlo al host:

EVP_PKEY *peer_key; /* Se asume que esto contiene la clave generada por el peer */
unsigned char *peer_pub_der = NULL;
int peer_pub_der_len;
peer_pub_der_len = i2d_PUBKEY(peer_key, &peer_pub_der);
...
OPENSSL_free(peer_pub_der);

Para convertir la clave pública del peer recibida del formato DER en el host:

const unsigned char *pd = peer_pub_der;
EVP_PKEY *peer_pub_key = d2i_PUBKEY(NULL, &pd, peer_pub_der_len);
...
EVP_PKEY_free(peer_pub_key);

Para derivar un secreto compartido en el host utilizando la clave del host y la clave pública del peer:

/* Se asume que host_key y peer_pub_key están configurados */
void derive_secret(EVP_KEY *host_key, EVP_PKEY *peer_pub_key)
{
    unsigned int pad = 1;
    OSSL_PARAM params[2];
    unsigned char *secret = NULL;
    size_t secret_len = 0;
    EVP_PKEY_CTX *dctx = EVP_PKEY_CTX_new_from_pkey(NULL, host_key, NULL);
    EVP_PKEY_derive_init(dctx);
    /* Opcionalmente, establezca el relleno */
    params[0] = OSSL_PARAM_construct_uint(OSSL_EXCHANGE_PARAM_PAD, &pad);
    params[1] = OSSL_PARAM_construct_end();
    EVP_PKEY_CTX_set_params(dctx, params);
    EVP_PKEY_derive_set_peer(dctx, peer_pub_key);
    /* Obtenga el tamaño pasando NULL como buffer */
    EVP_PKEY_derive(dctx, NULL, &secret_len);
    secret = OPENSSL_zalloc(secret_len);
    EVP_PKEY_derive(dctx, secret, &secret_len);
    ...
    OPENSSL_clear_free(secret, secret_len);
    EVP_PKEY_CTX_free(dctx);
}

Se puede usar un código muy similar para que el peer derive el mismo secreto compartido utilizando la clave pública del host y el par de claves generado por el peer.
