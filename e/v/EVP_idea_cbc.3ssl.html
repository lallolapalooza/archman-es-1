EVP_idea_cbc(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_IDEA_CBC(3ssl) OpenSSL EVP_IDEA_CBC(3ssl)

NOMBRE

EVP_idea_cbc, EVP_idea_cfb, EVP_idea_cfb64, EVP_idea_ecb, EVP_idea_ofb - Cifrado IDEA de EVP

SINOPSIS

#include <openssl/evp.h>
const EVP_CIPHER *EVP_idea_cbc(void);
const EVP_CIPHER *EVP_idea_cfb(void);
const EVP_CIPHER *EVP_idea_cfb64(void);
const EVP_CIPHER *EVP_idea_ecb(void);
const EVP_CIPHER *EVP_idea_ofb(void);

DESCRIPCIÓN

Algoritmo de cifrado IDEA para EVP.

EVP_idea_cbc(), EVP_idea_cfb(), EVP_idea_cfb64(), EVP_idea_ecb(), EVP_idea_ofb()
El algoritmo de cifrado IDEA en modos CBC, CFB, ECB y OFB respectivamente.

NOTAS

Los desarrolladores deben ser conscientes de las implicaciones negativas de rendimiento al llamar a estas funciones múltiples veces y deben considerar usar EVP_CIPHER_fetch(3) con EVP_CIPHER-IDEA(7) en su lugar. Vea "Rendimiento" en crypto(7) para más información.

VALORES DE RETORNO

Estas funciones devuelven una estructura EVP_CIPHER que contiene la implementación del cifrado simétrico. Vea EVP_CIPHER_meth_new(3) para detalles de la estructura EVP_CIPHER.

VER TAMBIÉN

evp(7), EVP_EncryptInit(3), EVP_CIPHER_meth_new(3)
