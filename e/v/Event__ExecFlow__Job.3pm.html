NOMBRE

Event::ExecFlow::Job - Clase base abstracta para todas las clases de trabajos

SINOPSIS

Event::ExecFlow::Job->new (
  title                => Título descriptivo,
  name                 => Nombre interno corto,
  depends_on           => Nombres de trabajos de los que depende este trabajo,
  progress_max         => Valor máximo esperado de progreso,
  progress_ips         => Cadena a mostrar como "elementos por segundo",
  no_progress          => El trabajo no tiene estado de progreso en absoluto,
  pre_callbacks        => Callbacks ejecutados antes de que comience el trabajo,
  post_callbacks       => Callbacks ejecutados después de que el trabajo finalice,
  error_callbacks      => Callbacks ejecutados si el trabajo tuvo errores,
  warning_callbacks    => Callbacks ejecutados si el trabajo tuvo advertencias,
  stash                => Un hash de datos personalizado almacenado con el trabajo,
);

DESCRIPCIÓN

Esta es una clase base abstracta y generalmente no se usa directamente desde la aplicación. Para la programación diaria, los atributos definidos en esta clase son los más importantes, ya que son comunes a todos los trabajos del framework Event::ExecFlow.
