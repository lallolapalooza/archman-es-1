El tipo de clave EC está implementado en el proveedor por defecto de

OpenSSL.

Parámetros comunes de

EC

La forma normal de especificar los parámetros de dominio para una curva EC es a través del nombre de curva "group". Para curvas sin nombre de curva, se pueden usar parámetros explícitos que especifiquen "field-type", "p", "a", "b", "generator" y "order". Los parámetros explícitos se admiten por razones de compatibilidad con versiones anteriores, pero no cumplen con múltiples estándares (incluido RFC5915) que solo permiten curvas con

nombre.

Los siguientes tipos de generación de claves/obtenibles/importación/exportación están disponibles para el algoritmo EC

incorporado:
"group" (OSSL_PKEY_PARAM_GROUP_NAME) <cadena
UTF8>
El nombre de la
curva.
"field-type" (OSSL_PKEY_PARAM_EC_FIELD_TYPE) <cadena
UTF8>
El valor debe ser "prime-field" o "characteristic-two-field", que corresponden al campo primo Fp y al campo binario
F2^m.
"p" (OSSL_PKEY_PARAM_EC_P) <entero sin
signo>
Para una curva sobre Fp p es el primo del campo. Para una curva sobre F2^m p representa el polinomio irreducible: cada bit representa un término en el polinomio. Por lo tanto, habrá tres o cinco bits establecidos dependiendo de si el polinomio es un trinomio o un
pentanomio.
"a" (OSSL_PKEY_PARAM_EC_A) <entero sin
signo>
"b" (OSSL_PKEY_PARAM_EC_B) <entero sin
signo>
"seed" (OSSL_PKEY_PARAM_EC_SEED) <cadena de
octetos>
a y b representan los coeficientes de la curva. Para Fp: y^2 mod p = x^3 +ax + b mod p O Para F2^m: y^2 + xy = x^3 + ax^2 + b

seed es un valor opcional que es solo para fines informativos. Representa la semilla de número aleatorio utilizada para generar el coeficiente b a partir de un

número al
eatorio.
"generator" (OSSL_PKEY_PARAM_EC_GENERATOR) <cadena de
octetos>
"order" (OSSL_PKEY_PARAM_EC_ORDER) <entero sin
signo>
"cofactor" (OSSL_PKEY_PARAM_EC_COFACTOR) <entero sin
signo>
El generador es un punto bien definido en la curva elegido para operaciones criptográficas. La codificación se conforma con la Sección 2.3.3 del estándar SECG SEC 1 ("Elliptic Curve Cryptography"). Ver EC_POINT_oct2point(). Los enteros utilizados para multiplicaciones de puntos estarán entre 0 y order - 1. cofactor es un valor opcional. order multiplicado por el cofactor da el número de puntos en la
curva.
"decoded-from-explicit" (OSSL_PKEY_PARAM_EC_DECODED_FROM_EXPLICIT_PARAMS)
<entero>
Obtiene un indicador que indica si la clave o los parámetros se decodificaron a partir de parámetros de curva explícitos. Se establece en 1 si es así o en 0 si se usó una curva con
nombre.
"use-cofactor-flag" (OSSL_PKEY_PARAM_USE_COFACTOR_ECDH)
<entero>
Habilita Cofactor DH (ECC CDH) si este valor es 1, de lo contrario usa EC DH normal si el valor es cero. La variante de cofactor multiplica el secreto compartido por el cofactor de la curva EC (ten en cuenta que para algunas curvas el cofactor es 1).

Ver también EVP_KEYEXCH-ECDH(7) para el parámetro relacionado OSSL_EXCHANGE_PARAM_EC_ECDH_COFACTOR_MOD

E que se puede estab
lecer por operación.
"encoding" (OSSL_PKEY_PARAM_EC_ENCODING) <cadena
UTF8>
Establece el formato utilizado para serializar los parámetros del grupo EC. Los valores válidos son "explicit" o "named_curve". El valor predeterminado es
"named_curve".
"point-format" (OSSL_PKEY_PARAM_EC_POINT_CONVERSION_FORMAT) <cadena
UTF8>
Establece u obtiene el point_conversion_form para la clave. Para una descripción de los point_conversion_forms, consulta EC_POINT_new(3). Los valores válidos son "uncompressed" o "compressed". El valor predeterminado es
"uncompressed".
"group-check" (OSSL_PKEY_PARAM_EC_GROUP_CHECK_TYPE) <cadena
UTF8>
Establece u obtiene el tipo de verificación de grupo realizada cuando se llama a EVP_PKEY_param_check(). Los valores válidos son "default", "named" y "named-nist". El tipo "named" verifica que los parámetros de dominio coincidan con los parámetros de curva incorporados, "named-nist" es similar pero también verifica que la curva con nombre sea una curva nist. El tipo "default" realiza la validación de parámetros de dominio para el proveedor por defecto de OpenSSL, pero es equivalente a "named-nist" para el proveedor FIPS de
OpenSSL.
"include-public" (OSSL_PKEY_PARAM_EC_INCLUDE_PUBLIC)
<entero>
Establecer este valor en 0 indica que la clave pública no debe incluirse al codificar la clave privada. El valor predeterminado de 1 incluirá la clave
pública.
"pub" (OSSL_PKEY_PARAM_PUB_KEY) <cadena de
octetos>
El valor de la clave pública en formato de punto EC codificado conforme a las Secciones 2.3.3 y 2.3.4 del estándar SECG SEC 1 ("Elliptic Curve Cryptography"). Este parámetro se usa al importar o exportar el valor de la clave pública con las funciones EVP_PKEY_fromdata() y EVP_PKEY_todata().

Ten en cuenta, en particular, que la elección del formato de compresión de puntos utilizado para codificar el valor exportado a través de EVP_PKEY_todata() depende de la implementación del proveedor subyacente. Antes de OpenSSL 3.0.8, la implementación de los proveedores incluidos con OpenSSL siempre optaba por una codificación en formato comprimido, incondicionalmente. Desde OpenSSL 3.0.8, la implementación se ha cambiado para respetar el parámetro OSSL_PKEY_PARAM_EC_POINT_CONVERSION_FORMAT, si está estab

lecido, o para usar por defec
to el formato sin comprimir.
"priv" (OSSL_PKEY_PARAM_PRIV_KEY) <entero sin
signo>
El valor de la clave
privada.
"encoded-pub-key" (OSSL_PKEY_PARAM_ENCODED_PUBLIC_KEY) <cadena de
octetos>
Se usa para obtener y establecer la codificación de una clave pública EC. Se espera que la clave pública sea un punto conforme a la Sección 2.3.4 del estándar SECG SEC 1 ("Elliptic Curve Cryptography")
.
"qx" (OSSL_PKEY_PARAM_EC_PUB_X) <entero sin
signo>
Se usa para obtener el componente X de la clave pública
EC.
"qy" (OSSL_PKEY_PARAM_EC_PUB_Y) <entero sin
signo>
Se usa para obtener el componente Y de la clave pública
EC.
"default-digest" (OSSL_PKEY_PARAM_DEFAULT_DIGEST) <cadena
UTF8>
Obtener que devuelve el nombre del resumen predeterminado. (Actualmente devuelve "SHA256" a partir de OpenSSL 3.
0).
"dhkem-ikm" (OSSL_PKEY_PARAM_DHKEM_IKM) <cadena de
octetos>
DHKEM requiere la generación de un par de claves utilizando un material de clave de entrada (semilla). Usa esto para especificar el material de clave
utilizado para la generación de la clave privada. Este valor no debe reutilizarse para otros propósitos. Solo se puede usar para las curvas "P-256",
"P-384" y "P-521" y debe tener una longitud de al menos el tamaño de la clave privada codificada (es decir, 32, 48 y 66 para las curvas enumeradas).

incorporado:

UTF8>
Admite los valores "tpBasis" para un trinomio o "ppBasis" para un pentanomio. Este campo solo se usa para un campo binario
F2^m.
"m" (OSSL_PKEY_PARAM_EC_CHAR2_M)
<entero>
"tp" (OSSL_PKEY_PARAM_EC_CHAR2_TP_BASIS)
<entero>
"k1" (OSSL_PKEY_PARAM_EC_CHAR2_PP_K1)
<entero>
"k2" (OSSL_PKEY_PARAM_EC_CHAR2_PP_K2)
<entero>
"k3" (OSSL_PKEY_PARAM_EC_CHAR2_PP_K3)
<entero>
Estos campos solo se usan para un campo binario F2^m. m es el grado del campo binario.

tp es el bit medio de un trinomio, por lo que su valor debe estar en el rango m > tp

k1, k2 y k3 se usan para obtener los bits medios de un pentanomio de modo que m > k3 > k2 >

k1 >
