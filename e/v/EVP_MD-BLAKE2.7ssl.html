EVP_MD-BLAKE2(7ssl)

EVP_MD-BLAKE2(7ssl) OpenSSL EVP_MD-BLAKE2(7ssl)

NOMBRE

EVP_MD-BLAKE2 - La implementación de BLAKE2 EVP_MD

DESCRIPCIÓN

Soporte para calcular resúmenes BLAKE2 a través de la API EVP_MD.

Identidades

Esta implementación solo está disponible con el proveedor por defecto, e incluye las siguientes variedades:

BLAKE2S-256
Los nombres conocidos son "BLAKE2S-256" y "BLAKE2s256".
BLAKE2B-512
Los nombres conocidos son "BLAKE2B-512" y "BLAKE2b512".

Parámetros Configurables

"BLAKE2B-512" soporta la siguiente clave EVP_MD_CTX_set_params() descrita en "PARÁMETROS" en EVP_DigestInit(3).

"size" (OSSL_DIGEST_PARAM_SIZE) <entero sin signo>

Parámetros Obtenibles

Esta implementación soporta los parámetros obtenibles comunes descritos en EVP_MD-common(7).

Parámetros de Contexto Configurables

La implementación soporta las siguientes entradas OSSL_PARAM(3) que son configurables para un EVP_MD_CTX con EVP_DigestInit_ex2(3) o EVP_MD_CTX_set_params(3):

"size" (OSSL_DIGEST_PARAM_SIZE) <entero sin signo>
Establece una longitud de resumen diferente para la salida de EVP_DigestFinal(3). El valor del parámetro "size" no debe exceder la longitud de resumen por defecto de las variantes del algoritmo BLAKE2 respectivas, 64 para BLAKE2B-512 y 32 para BLAKE2S-256. El parámetro debe establecerse con la llamada EVP_DigestInit_ex2(3) para tener un efecto inmediato. Cuando se establece con EVP_MD_CTX_set_params(3) solo tendrá efecto si el contexto EVP_MD_CTX se reinicializa.

VER TAMBIÉN

provider-digest(7), OSSL_PROVIDER-default(7)

HISTORIA

Esta funcionalidad se añadió en OpenSSL 3.0.

El soporte de tamaño variable se añadió en OpenSSL 3.2 para BLAKE2B-512 y en OpenSSL 3.3 para BLAKE2S-256.
