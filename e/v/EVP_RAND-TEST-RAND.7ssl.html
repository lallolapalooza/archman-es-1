EVP_RAND-TEST-RAND(7ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_RAND-TEST-RAND(7ssl) OpenSSL EVP_RAND-TEST-RAND(7ssl)

NOMBRE

EVP_RAND-TEST-RAND - La implementación de prueba de EVP_RAND

DESCRIPCIÓN

Soporte para un generador de prueba a través de la API EVP_RAND. Este generador es solo para fines de prueba, no genera números aleatorios.

Identidad

"TEST-RAND" es el nombre de esta implementación; puede ser utilizado con la función EVP_RAND_fetch().

Parámetros soportados

Los parámetros soportados son:

"state" (OSSL_RAND_PARAM_STATE) <entero>
"fips-indicator" (OSSL_RAND_PARAM_FIPS_APPROVED_INDICATOR) <entero>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_RAND(3).
"strength" (OSSL_RAND_PARAM_STRENGTH) <entero sin signo>
"reseed_requests" (OSSL_DRBG_PARAM_RESEED_REQUESTS) <entero sin signo>
"reseed_time_interval" (OSSL_DRBG_PARAM_RESEED_TIME_INTERVAL) <entero>
"max_request" (OSSL_DRBG_PARAM_RESEED_REQUESTS) <entero sin signo>
"min_entropylen" (OSSL_DRBG_PARAM_MIN_ENTROPYLEN) <entero sin signo>
"max_entropylen" (OSSL_DRBG_PARAM_MAX_ENTROPYLEN) <entero sin signo>
"min_noncelen" (OSSL_DRBG_PARAM_MIN_NONCELEN) <entero sin signo>
"max_noncelen" (OSSL_DRBG_PARAM_MAX_NONCELEN) <entero sin signo>
"max_perslen" (OSSL_DRBG_PARAM_MAX_PERSLEN) <entero sin signo>
"max_adinlen" (OSSL_DRBG_PARAM_MAX_ADINLEN) <entero sin signo>
"reseed_counter" (OSSL_DRBG_PARAM_RESEED_COUNTER) <entero sin signo>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_RAND(3), excepto que todos pueden ser establecidos y leídos.
"test_entropy" (OSSL_RAND_PARAM_TEST_ENTROPY) <cadena de octetos>
Establece los bytes devueltos cuando al generador de prueba se le solicita entropía. La posición actual se recuerda entre llamadas a generar. Si no hay datos suficientes para satisfacer una llamada, se devuelve un error.
"test_nonce" (OSSL_RAND_PARAM_TEST_NONCE) <cadena de octetos>
Establece los bytes devueltos cuando al generador de prueba se le solicita un nonce. Cada solicitud de nonce devolverá todos los bytes.
"generate" (OSSL_RAND_PARAM_GENERATE) <entero>
Si este parámetro es cero, solo emitirá los datos de nonce y entropía suministrados a través de los parámetros anteriores. De lo contrario, se producirá una salida seudorandom de baja calidad no criptográfica. Este parámetro por defecto es cero.

NOTAS

Se puede obtener un contexto para un generador de prueba llamando a:

EVP_RAND *rand = EVP_RAND_fetch(NULL, "TEST-RAND", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

EJEMPLOS

EVP_RAND *rand;
EVP_RAND_CTX *rctx;
unsigned char bytes[100];
OSSL_PARAM params[4], *p = params;
unsigned char entropy[1000] = { ... };
unsigned char nonce[20] = { ... };
unsigned int strength = 48;
rand = EVP_RAND_fetch(NULL, "TEST-RAND", NULL);
rctx = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_free(rand);
*p++ = OSSL_PARAM_construct_uint(OSSL_RAND_PARAM_STRENGTH, &strength);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_RAND_PARAM_TEST_ENTROPY,
                                         entropy, sizeof(entropy));
*p++ = OSSL_PARAM_construct_octet_string(OSSL_RAND_PARAM_TEST_NONCE,
                                         nonce, sizeof(nonce));
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);
