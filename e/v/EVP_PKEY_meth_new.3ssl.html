DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar las API de OSSL_PROVIDER.

EVP_PKEY_METHOD es una estructura que contiene un conjunto de métodos para un algoritmo criptográfico de clave pública específico. Esos métodos suelen usarse para realizar diferentes tareas, como generar una clave, firmar o verificar, cifrar o descifrar, etc.

Hay dos lugares donde los objetos EVP_PKEY_METHOD se almacenan: uno es un array estático integrado que representa los métodos estándar para diferentes algoritmos, y el otro es una pila de métodos específicos de la aplicación definidos por el usuario, que pueden manipularse usando EVP_PKEY_meth_add0(3).

Los objetos EVP_PKEY_METHOD suelen ser referenciados por objetos EVP_PKEY_CTX .

Métodos

Los métodos son las implementaciones subyacentes de un algoritmo de clave pública particular presentado por el objeto EVP_PKEY_CTX .

int (*init) (EVP_PKEY_CTX *ctx);
int (*copy) (EVP_PKEY_CTX *dst, const EVP_PKEY_CTX *src);
void (*cleanup) (EVP_PKEY_CTX *ctx);

El método init() se llama para inicializar datos específicos del algoritmo cuando se crea un nuevo EVP_PKEY_CTX . A diferencia de init(), el método cleanup() se llama cuando un EVP_PKEY_CTX se libera. El método copy() se llama cuando un EVP_PKEY_CTX se está duplicando. Consulte EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_new_id(3), EVP_PKEY_CTX_free(3) y EVP_PKEY_CTX_dup(3).

int (*paramgen_init) (EVP_PKEY_CTX *ctx);
int (*paramgen) (EVP_PKEY_CTX *ctx, EVP_PKEY *pkey);

Los métodos paramgen_init() y paramgen() tratan la generación de parámetros de clave. Son llamados por EVP_PKEY_paramgen_init(3) y EVP_PKEY_paramgen(3) para manejar el proceso de generación de parámetros.

int (*keygen_init) (EVP_PKEY_CTX *ctx);
int (*keygen) (EVP_PKEY_CTX *ctx, EVP_PKEY *pkey);

Los métodos keygen_init() y keygen() se usan para generar la clave real para el algoritmo especificado. Son llamados por EVP_PKEY_keygen_init(3) y EVP_PKEY_keygen(3).

int (*sign_init) (EVP_PKEY_CTX *ctx);
int (*sign) (EVP_PKEY_CTX *ctx, unsigned char *sig, size_t *siglen,
             const unsigned char *tbs, size_t tbslen);

Los métodos sign_init() y sign() se usan para generar la firma de un trozo de datos usando una clave privada. Son llamados por EVP_PKEY_sign_init(3) y EVP_PKEY_sign(3).

int (*verify_init) (EVP_PKEY_CTX *ctx);
int (*verify) (EVP_PKEY_CTX *ctx,
               const unsigned char *sig, size_t siglen,
               const unsigned char *tbs, size_t tbslen);

Los métodos verify_init() y verify() se usan para verificar si una firma es válida. Son llamados por EVP_PKEY_verify_init(3) y EVP_PKEY_verify(3).

int (*verify_recover_init) (EVP_PKEY_CTX *ctx);
int (*verify_recover) (EVP_PKEY_CTX *ctx,
                       unsigned char *rout, size_t *routlen,
                       const unsigned char *sig, size_t siglen);

Los métodos verify_recover_init() y verify_recover() se usan para verificar una firma y luego recuperar el resumen de la firma (por ejemplo, una firma que fue generada por el algoritmo de firma RSA). Son llamados por EVP_PKEY_verify_recover_init(3) y EVP_PKEY_verify_recover(3).

int (*signctx_init) (EVP_PKEY_CTX *ctx, EVP_MD_CTX *mctx);
int (*signctx) (EVP_PKEY_CTX *ctx, unsigned char *sig, size_t *siglen,
                EVP_MD_CTX *mctx);

Los métodos signctx_init() y signctx() se usan para firmar un resumen presentado por un objeto EVP_MD_CTX . Son llamados por las funciones EVP_DigestSign. Vea EVP_DigestSignInit(3) para más detalles.

int (*verifyctx_init) (EVP_PKEY_CTX *ctx, EVP_MD_CTX *mctx);
int (*verifyctx) (EVP_PKEY_CTX *ctx, const unsigned char *sig, int siglen,
                  EVP_MD_CTX *mctx);

Los métodos verifyctx_init() y verifyctx() se usan para verificar una firma contra los datos en un objeto EVP_MD_CTX . Son llamados por las diversas funciones EVP_DigestVerify. Vea EVP_DigestVerifyInit(3) para más detalles.

int (*encrypt_init) (EVP_PKEY_CTX *ctx);
int (*encrypt) (EVP_PKEY_CTX *ctx, unsigned char *out, size_t *outlen,
                const unsigned char *in, size_t inlen);

Los métodos encrypt_init() y encrypt() se usan para cifrar un trozo de datos. Son llamados por EVP_PKEY_encrypt_init(3) y EVP_PKEY_encrypt(3).

int (*decrypt_init) (EVP_PKEY_CTX *ctx);
int (*decrypt) (EVP_PKEY_CTX *ctx, unsigned char *out, size_t *outlen,
                const unsigned char *in, size_t inlen);

Los métodos decrypt_init() y decrypt() se usan para descifrar un trozo de datos. Son llamados por EVP_PKEY_decrypt_init(3) y man/EVP_PKEY_decrypt.3.en'>EVP_PKEY_decrypt(3)
