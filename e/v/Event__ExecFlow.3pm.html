NOMBRE

Event::ExecFlow - API de alto nivel para el control de flujo de ejecución basado en eventos.

NOTA

Este lanzamiento casi no tiene documentación todavía. Si está interesado en los detalles, póngase en contacto con el autor.

RESUMEN

Event::ExecFlow proporciona una API de alto nivel para definir controles de flujo complejos con ejecución asíncrona de programas externos.

SINOPSIS

use Event::ExecFlow;
my $job = Event::ExecFlow::Job::Group->new (
  jobs => [
    Event::ExecFlow::Job::Command->new (
      name            => "transcode",
      title           => "Transcodificando título de DVD a OGG",
      command         => "transcode -i /dev/dvd ...",
      fetch_output    => 1,
      progress_max    => 4711, # número de fotogramas
      progress_parser => sub {
        my ($job, $buffer) = @_;
        $job->set_progress_cnt($1) if $buffer =~ /\[\d+-(\d+)\]/;
        #-- o simplemente escriba esto:
        #--   progress_parser => qr/\[\d+-(\d+)\]/,
      },
    ),
    Event::ExecFlow::Job::Code->new (
      name          => "checks",
      title         => "Realizar algunas comprobaciones",
      depends_on    => [ "transcode" ],
      code          => sub {
        my ($job) = @_;
        my $transcode = $job->get_group->get_job_by_name("transcode");
        if ( $transcode->get_output !~ /.../ ) {
          $job->set_error_message("La comprobación XY falló");
        }
        #-- esto podría hacerse más fácil como una callback post añadida a
        #-- el trabajo "transcode" de arriba, pero es, no obstante, un buen
        #-- ejemplo para el tipo de trabajo 'Code' y muestra cómo los trabajos pueden
        #-- interferir entre sí.
      },
    ),
    Event::ExecFlow::Job::Command->new (
      title         => "Multiplexando archivo OGG",
      depends_on    => [ "checks" ],
      command       => "ogmmerge ...",
      no_progress   => 1,
    ),
  ],
);
#-- esto hereda de Event::ExecFlow::Frontend
my $frontend = Video::DVDRip::GUI::ExecFlow->new(...);
$frontend->start_job($job);

DESCRIPCIÓN

Event::ExecFlow ofrece una API de alto nivel para declarar trabajos, que principalmente ejecutan comandos externos, analizan su salida para obtener información de progreso u otro estado, activan acciones cuando el comando ha finalizado, etc. Dichos trabajos se pueden encadenar de forma recursiva para cumplir tareas bastante complejas que constan de muchos trabajos.

Además, define una API extensible para la comunicación con la aplicación frontend, que puede estar escrita usando Gtk2, Tk o Qt o ser un simple programa de consola de texto.

En el caso de Gtk2, se incluye un widget personalizado para mostrar un plan de trabajo de Event::ExecFlow, incluidas las actualizaciones de progreso, con el paquete Gtk2::Ex::FormFactory.

REQUISITOS

Event::ExecFlow requiere los siguientes módulos de Perl:

AnyEvent           >= 0.04
Locale::TextDomain
Test::More
