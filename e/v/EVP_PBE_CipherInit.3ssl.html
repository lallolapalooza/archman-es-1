EVP_PBE_CipherInit(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PBE_CIPHERINIT(3ssl) OpenSSL EVP_PBE_CIPHERINIT(3ssl)

NOMBRE

EVP_PBE_CipherInit, EVP_PBE_CipherInit_ex, EVP_PBE_find, EVP_PBE_find_ex, EVP_PBE_alg_add_type, EVP_PBE_alg_add - Rutinas de cifrado basado en contraseña

SINOPSIS

#include <openssl/evp.h>
int EVP_PBE_CipherInit(ASN1_OBJECT *pbe_obj, const char *pass, int passlen,
                       ASN1_TYPE *param, EVP_CIPHER_CTX *ctx, int en_de);
int EVP_PBE_CipherInit_ex(ASN1_OBJECT *pbe_obj, const char *pass, int passlen,
                          ASN1_TYPE *param, EVP_CIPHER_CTX *ctx, int en_de,
                          OSSL_LIB_CTX *libctx, const char *propq);
int EVP_PBE_find(int type, int pbe_nid, int *pcnid, int *pmnid,
                 EVP_PBE_KEYGEN **pkeygen);
int EVP_PBE_find_ex(int type, int pbe_nid, int *pcnid, int *pmnid,
                    EVP_PBE_KEYGEN **pkeygen, EVP_PBE_KEYGEN_EX **keygen_ex);
int EVP_PBE_alg_add_type(int pbe_type, int pbe_nid, int cipher_nid,
                         int md_nid, EVP_PBE_KEYGEN *keygen);
int EVP_PBE_alg_add(int nid, const EVP_CIPHER *cipher, const EVP_MD *md,
                    EVP_PBE_KEYGEN *keygen);

DESCRIPCIÓN

Operaciones PBE

EVP_PBE_CipherInit() y EVP_PBE_CipherInit_ex() inicializan un EVP_CIPHER_CTX ctx para cifrado (en_de=1) o descifrado (en_de=0) usando la contraseña pass de longitud passlen. El tipo de algoritmo PBE y los parámetros se extraen de un OID pbe_obj y los parámetros param.

EVP_PBE_CipherInit_ex() también permite a la aplicación especificar un contexto de biblioteca libctx y una consulta de propiedades propq para seleccionar implementaciones de algoritmos apropiadas.

Búsqueda de algoritmos PBE

EVP_PBE_find() y EVP_PBE_find_ex() buscan un algoritmo coincidente utilizando dos parámetros:

1. Un tipo de algoritmo type que puede ser:

  • EVP_PBE_TYPE_OUTER - Un algoritmo PBE
  • EVP_PBE_TYPE_PRF - Una función pseudoaleatoria
  • EVP_PBE_TYPE_KDF - Una función de derivación de clave

2. Un pbe_nid que puede representar el identificador del algoritmo con parámetros, por ejemplo, NID_pbeWithSHA1AndRC2_CBC o una clase de algoritmo, por ejemplo, NID_pbes2.

Devuelven el ID del cifrador del algoritmo pcnid, el ID del digest pmnid y una función de generación de claves para el algoritmo pkeygen. EVP_PBE_CipherInit_ex() también devuelve una función de generación de claves extendida keygen_ex que toma un contexto de biblioteca y una consulta de propiedades.

Si se proporciona NULL para alguno de pcnid, pmnid, pkeygen o keygen_ex, ese parámetro no se devuelve.

Adición de algoritmos PBE

EVP_PBE_alg_add_type() y EVP_PBE_alg_add() añaden un algoritmo a la lista de algoritmos conocidos. Sus parámetros tienen el mismo significado que para las funciones EVP_PBE_find() y EVP_PBE_find_ex().

NOTAS

Los argumentos pbe_obj y param para EVP_PBE_CipherInit() y EVP_PBE_CipherInit_ex() juntos forman un X509_ALGOR y a menudo se pueden extraer directamente de esta estructura.

VALORES DE RETORNO

El valor de retorno es 1 para éxito y 0 si ocurrió un error.

VER TAMBIÉN

HISTORIA
