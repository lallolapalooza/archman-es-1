EVP_PKEY_todata(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_todata(3ssl) OpenSSL EVP_PKEY_todata(3ssl)

NOMBRE

EVP_PKEY_todata, EVP_PKEY_export - funciones para devolver claves como un array de parámetros de clave

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_todata(const EVP_PKEY *pkey, int selection, OSSL_PARAM **params);
int EVP_PKEY_export(const EVP_PKEY *pkey, int selection,
                    OSSL_CALLBACK *export_cb, void *export_cbarg);

DESCRIPCIÓN

Las funciones descritas aquí se utilizan para extraer valores de clave EVP_PKEY como un array de OSSL_PARAM(3).

EVP_PKEY_todata() extrae valores de una clave pkey utilizando la selection. La selection se describe en "Selections" en EVP_PKEY_fromdata(3). Se debe usar OSSL_PARAM_free(3) para liberar los parámetros devueltos en *params.

EVP_PKEY_export() es similar a EVP_PKEY_todata() pero utiliza una función de devolución de llamada export_cb que recibe el valor de export_cbarg. Consulte openssl-core.h(7) para más información sobre la función de devolución de llamada. Tenga en cuenta que el array OSSL_PARAM(3) que se pasa a la función de devolución de llamada no es persistente después de que la función de devolución de llamada retorna. El usuario debe conservar los elementos de interés, o usar EVP_PKEY_todata() si se requiere persistencia.

NOTAS

Estas funciones solo funcionan con métodos de gestión de claves provenientes de un proveedor. Esta es la función espejo de EVP_PKEY_fromdata(3).

El soporte para LMS está deshabilitado por defecto en el momento de la compilación. Para habilitarlo, especifique la opción de configuración de compilación enable-lms.

VALORES DE RETORNO

EVP_PKEY_todata() y EVP_PKEY_export() devuelven 1 en caso de éxito y 0 en caso de error.

VER TAMBIÉN

OSSL_PARAM(3), openssl-core.h(7), EVP_PKEY_fromdata(3), EVP_PKEY-RSA(7), EVP_PKEY-EC(7), EVP_PKEY-DSA(7), EVP_PKEY-ED25519(7) EVP_PKEY-ED448(7), EVP_PKEY-DH(7), EVP_PKEY-X25519(7), EVP_PKEY-X448(7), EVP_PKEY-LMS(7), EVP_PKEY-ML-DSA(7), EVP_PKEY-ML-KEM(7), EVP_PKEY-SLH-DSA(7).

HISTORIA

Estas funciones se agregaron en OpenSSL 3.0.

El soporte para ML-DSA, ML-KEM y SLH-DSA se agregó en OpenSSL 3.5.

El soporte para LMS se agregó en OpenSSL 3.6.
