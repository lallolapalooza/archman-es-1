NOMBRE

Event::ExecFlow::Job::Code - Ejecutar un cierre

SINOPSIS

Event::ExecFlow::Job::Code->new (
  code     => Cierre a ejecutar,
  ...
  atributos de Event::ExecFlow::Job
);

DESCRIPCIÓN

Utilice este módulo para la ejecución de código Perl arbitrario (pasado como cierre) dentro de un Event::ExecFlow.

JERARQUÍA DE OBJETOS

Event::ExecFlow
Event::ExecFlow::Job
+--- Event::ExecFlow::Job::Code
Event::ExecFlow::Frontend
Event::ExecFlow::Callbacks
