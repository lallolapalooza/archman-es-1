NOMBRE

EVP_KDF-PVKKDF - La implementación de PVKKDF de EVP_KDF

DESCRIPCIÓN

Soporte para calcular la función de derivación de claves (KDF) basada en PIN de PVK a través de la API de EVP_KDF.

El algoritmo EVP_KDF-PVKKDF implementa una función de derivación de claves basada en PIN de PVK; deriva una clave de una contraseña usando una sal.

Identidad

"PVKKDF" es el nombre de esta implementación; puede ser utilizado con la función EVP_KDF_fetch().

Parámetros soportados

Los parámetros soportados son:

"pass" (OSSL_KDF_PARAM_PASSWORD) <cadena de octetos>
"salt" (OSSL_KDF_PARAM_SALT) <cadena de octetos>
"properties" (OSSL_KDF_PARAM_PROPERTIES) <cadena UTF8>
"digest" (OSSL_KDF_PARAM_DIGEST) <cadena UTF8>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_KDF(3).

NOTAS

Una aplicación típica de este algoritmo es derivar material de clave para un algoritmo de cifrado a partir de una contraseña en el campo "pass" y una sal en el campo "salt".

No se hace ninguna suposición sobre la contraseña dada; simplemente se trata como una secuencia de bytes.

El proveedor heredado debe estar disponible para poder acceder a este algoritmo.

VER TAMBIÉN

EVP_KDF(3), EVP_KDF_CTX_new(3), EVP_KDF_CTX_free(3), EVP_KDF_CTX_set_params(3), EVP_KDF_derive(3), "PARÁMETROS" en EVP_KDF(3), OSSL_PROVIDER-legacy(7)

HISTORIA
