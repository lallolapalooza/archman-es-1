Módulo Event
: sig end

Comunicación síncrona de primera clase.

Este módulo implementa comunicaciones síncronas entre hilos a través de canales. Como en el sistema Concurrent ML de John Reppy, los eventos de comunicación son valores de primera clase: pueden construirse y combinarse independientemente antes de ofrecerse para la comunicación.

type 'a channel

El tipo de canales de comunicación que transportan valores de tipo 'a .

val new_channel : unit -> 'a channel

Devuelve un nuevo canal.

type +'a event

El tipo de eventos de comunicación que devuelven un resultado de tipo 'a .

val send : 'a channel -> 'a -> unit event

send ch v devuelve el evento que consiste en enviar el valor v a través del canal ch . El valor resultante de este evento es () .

val receive : 'a channel -> 'a event

receive ch devuelve el evento que consiste en recibir un valor del canal ch . El valor resultante de este evento es el valor recibido.

val always : 'a -> 'a event

always v devuelve un evento que está siempre listo para la sincronización. El valor resultante de este evento es v .

val choose : 'a event list -> 'a event

choose evl devuelve el evento que es la alternativa de todos los eventos de la lista evl .

val wrap : 'a event -> ('a -> 'b) -> 'b event

wrap ev fn devuelve el evento que realiza las mismas comunicaciones que ev , y luego aplica la función de post-procesamiento fn al valor de retorno.

val wrap_abort : 'a event -> (unit -> unit) -> 'a event

wrap_abort ev fn devuelve el evento que realiza las mismas comunicaciones que ev , pero si no se selecciona, la función fn se llama después de la sincronización.

val guard : (unit -> 'a event) -> 'a event

guard fn devuelve el evento que, al sincronizarse, calcula fn() y se comporta como el evento resultante. Esto permite calcular eventos con efectos secundarios en el momento de la operación de sincronización.

val sync : 'a event -> 'a

Sincroniza con un evento: ofrece todas las posibilidades de comunicación especificadas en el evento al mundo exterior, y se bloquea hasta que una de las comunicaciones tenga éxito. Se devuelve el valor resultante de esa comunicación.

val select : 'a event list -> 'a

Sincroniza con una alternativa de eventos. select evl es una abreviatura de sync(choose evl) .

val poll : 'a event -> 'a option

Versión no bloqueante de Event.sync : ofrece todas las posibilidades de comunicación especificadas en el evento al mundo exterior, y si una puede realizarse inmediatamente, la realiza y devuelve Some r donde r es el valor resultante de esa comunicación. De lo contrario, devuelve None sin bloquear.
