DESCRIPCIÓ

N

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar las API de

OSSL_PROVIDER.

El tipo EVP_MD es una estructura para la implementación de métodos de resumen. También puede tener rutinas asociadas de firma y verificación de claves pública/privada

.

EVP_MD_meth_new() crea una nueva estructura EVP_MD. Estas estructuras EVP_MD tienen conteo de

referencias.

EVP_MD_meth_dup() crea una copia de md

.

EVP_MD_meth_free() decrementa el conteo de referencias de la estructura EVP_MD. Si el conteo de referencias baja a 0, entonces la estructura se libera. Si el argumento es NULL, no se hace

nada.

EVP_MD_meth_set_input_blocksize() establece el tamaño del bloque de entrada interno para el método md a blocksize b

ytes.

EVP_MD_meth_set_result_size() establece el tamaño del resultado que se espera que produzca el método de resumen en md a resultsize

bytes.

El método de resumen puede tener sus propios datos privados, que OpenSSL asignará para él. EVP_MD_meth_set_app_datasize() debe usarse para establecer su tamaño a datasize

.

EVP_MD_meth_set_flags() establece los indicadores que describen comportamientos opcionales en el md particular. Varios indicadores pueden combinarse con OR. Los indicadores disponibles

son:
EVP_MD_FLAG_ONES
HOT
Este método de resumen solo puede manejar un bloque de
entrada.
EVP_MD_FLAG_
XOF
Este método de resumen es una función de salida extensible (XOF) y soporta el control EVP_MD_CTRL_XOF_L
EN.
EVP_MD_FLAG_DIGALGID_N
ULL
Al configurar un DigestAlgorithmIdentifier, este indicador hará que el parámetro se establezca en NULL por defecto. Úselo para PKCS#1. Nota: si se combina con EVP_MD_FLAG_DIGALGID_ABSENT, este último
prevalecerá.
EVP_MD_FLAG_DIGALGID_ABS
ENT
Al configurar un DigestAlgorithmIdentifier, este indicador hará que el parámetro quede ausente por defecto. Nota: si se combina con EVP_MD_FLAG_DIGALGID_NULL, este último será
anulado.
EVP_MD_FLAG_DIGALGID_CUS
TOM
Manejo personalizado de DigestAlgorithmIdentifier a través de ctrl, con EVP_MD_FLAG_DIGALGID_ABSENT como valor por defecto. Nota: si se combina con EVP_MD_FLAG_DIGALGID_NULL, este último será anulado. Actualmente sin
uso.
EVP_MD_FLAG_F
IPS
Este método de resumen es ad
ecuado para su uso en modo FI
PS. Actualmente sin uso.

EVP_MD_meth_set_init() establece la función de inicialización del resumen para md. La función de inicialización del resumen es llamada por EVP_Digest(), EVP_DigestInit(), EVP_DigestInit_ex(), EVP_SignInit, EVP_SignInit_ex(), EVP_VerifyInit() y EVP_VerifyIni

t_ex().

EVP_MD_meth_set_update() establece la función de actualización del resumen para md. La función de actualización del resumen es llamada por EVP_Digest(), EVP_DigestUpdate() y EVP_SignUpd

ate().

EVP_MD_meth_set_final() establece la función final del resumen para md. La función final del resumen es llamada por EVP_Digest(), EVP_DigestFinal(), EVP_DigestFinal_ex(), EVP_SignFinal() y EVP_VerifyFi

nal().

EVP_MD_meth_set_copy() establece la función para md para realizar cálculos adicionales después de que la estructura de datos privada del método haya sido copiada de un EVP_MD_CTX a otro. Si todo lo que se necesita es copiar los datos, no hay necesidad de esta función de copia. Tenga en cuenta que la función de copia recibe dos EVP_MD_CTX *, la estructura de datos privada está entonces disponible con EVP_MD_CTX_get0_md_data(). Esta función de copia es llamada por EVP_MD_CTX_copy() y EVP_MD_CTX_cop

y_ex().

EVP_MD_meth_set_cleanup() establece la función para md para realizar una limpieza adicional antes de que la estructura de datos privada del método sea limpiada y liberada. Tenga en cuenta que la función de limpieza recibe un EVP_MD_CTX *, la estructura de datos privada está entonces disponible con EVP_MD_CTX_get0_md_data(). Esta función de limpieza es llamada por EVP_MD_CTX_reset() y EVP_MD_CTX_f

ree().

EVP_MD_meth_set_ctrl() establece la función de control para md. Ver EVP_MD_CTX_ctrl(3) para los controles

disponibles.

EVP_MD_meth_get_input_blocksize(), EVP_MD_meth_get_result_size(), EVP_MD_meth_get_app_datasize(), EVP_MD_meth_get_flags(), EVP_MD_meth_get_init(), EVP_MD_meth_get_update(), EVP_MD_meth_get_final(), EVP_MD_meth_get_copy(), EVP_MD_meth_get_cleanup() y EVP_MD_meth_get_ctrl() se usan todas para recuperar los datos del

método dados con las funcione
s EVP_MD_meth_set_*() anteriores.

VALORES DE

RETORNO

EVP_MD_meth_new() y EVP_MD_meth_dup() devuelven un puntero a un EVP_MD recién creado, o NULL en caso de fallo. Todas las funciones EVP_MD_meth_set_*() devuelven 1. EVP_MD_get_input_blocksize(), EVP_MD_meth_get_result_size(), EVP_MD_meth_get_app_datasize() y EVP_MD_meth_get_flags() devuelven los tamaños o indicadores indicados. Todas las demás funciones EVP_CIPHER_meth_get_*() devuelven punteros a su respectiva funció

n
md.
