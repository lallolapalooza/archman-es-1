EVP_PKEY_CTX_get_algor(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_CTX_GET_ALGOR(3ssl) OpenSSL EVP_PKEY_CTX_GET_ALGOR(3ssl)

NOMBRE

EVP_CIPHER_CTX_get_algor, EVP_CIPHER_CTX_get_algor_params, EVP_CIPHER_CTX_set_algor_params, EVP_PKEY_CTX_get_algor, EVP_PKEY_CTX_get_algor_params, EVP_PKEY_CTX_set_algor_params - pasar AlgorithmIdentifier y sus parámetros hacia/desde implementaciones de algoritmo

SINOPSIS

int EVP_TYPE_CTX_get_algor(EVP_TYPE_CTX *ctx, X509_ALGOR **alg);
int EVP_TYPE_CTX_get_algor_params(EVP_TYPE_CTX *ctx, X509_ALGOR *alg);
int EVP_TYPE_CTX_set_algor_params(EVP_TYPE_CTX *ctx, const X509_ALGOR *alg);

DESCRIPCIÓN

En la descripción aquí y en la "SINOPSIS" anterior, TYPE se usa como marcador de posición para cualquier tipo de operación EVP.

EVP_TYPE_CTX_get_algor() intenta recuperar un AlgorithmIdentifier completo de la implementación de EVP_TYPE y lo pobla en *alg. Si alg es NULL, llamar a esta función servirá para ver si la llamada a esta función es soportada en absoluto por la implementación de EVP_TYPE. Si *alg es NULL, el espacio se asignará automáticamente y se asignará a *alg.

EVP_TYPE_CTX_get_algor_params() intenta recuperar la parte de parámetros de un AlgorithmIdentifier de la implementación de EVP_TYPE y lo pobla en alg-parameters>. Si alg es NULL, llamar a esta función servirá para ver si la llamada a esta función es soportada en absoluto por la implementación de EVP_TYPE. Si alg->parameters es NULL, el espacio se asignará automáticamente y se asignará a alg->parameters. Si alg->parameters no es NULL, su contenido anterior se sobrescribirá con los parámetros del AlgorithmIdentifier recuperados. ¡Cuidado!

EVP_TYPE_CTX_set_algor_params() intenta pasar alg->parameters a la implementación de EVP_TYPE. Si alg es NULL, llamar a esta función servirá para ver si la llamada a esta función es soportada en absoluto por la implementación de EVP_TYPE.

VALORES DE RETORNO

Todas las funciones devuelven 1 para éxito, y 0 o un número negativo si ocurre un error. En particular, se devuelve -2 cuando la función no es soportada por la implementación de EVP_TYPE.

HISTORIA

Estas funciones se añadieron en OpenSSL 3.4.
