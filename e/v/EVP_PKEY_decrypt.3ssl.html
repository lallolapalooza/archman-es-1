EVP_PKEY_decrypt(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EVP_PKEY_DECRYPT(3ssl) OpenSSL EVP_PKEY_DECRYPT(3ssl)

NOMBRE

EVP_PKEY_decrypt_init, EVP_PKEY_decrypt_init_ex, EVP_PKEY_decrypt - descifrar usando un algoritmo de clave pública

SINOPSIS

#include <openssl/evp.h>
int EVP_PKEY_decrypt_init(EVP_PKEY_CTX *ctx);
int EVP_PKEY_decrypt_init_ex(EVP_PKEY_CTX *ctx, const OSSL_PARAM params[]);
int EVP_PKEY_decrypt(EVP_PKEY_CTX *ctx,
                     unsigned char *out, size_t *outlen,
                     const unsigned char *in, size_t inlen);

DESCRIPCIÓN

La función EVP_PKEY_decrypt_init() inicializa un contexto de algoritmo de clave pública usando la clave pkey para una operación de descifrado.

La función EVP_PKEY_decrypt_init_ex() inicializa un contexto de algoritmo de clave pública usando la clave pkey para una operación de descifrado y establece los params específicos del algoritmo.

La función EVP_PKEY_decrypt() realiza una operación de descifrado de clave pública usando ctx. Los datos a descifrar se especifican usando los parámetros in y inlen. Si out es NULL, entonces el tamaño mínimo requerido del búfer de salida se escribe en el parámetro *outlen.

Si out no es NULL, antes de la llamada, el parámetro *outlen debe contener la longitud del búfer out. Si la llamada es exitosa, los datos descifrados se escriben en out y la cantidad de datos descifrados se escribe en *outlen; de lo contrario, se devuelve un error.

NOTAS

Después de la llamada a EVP_PKEY_decrypt_init(), se pueden realizar operaciones de control específicas del algoritmo para establecer los parámetros apropiados para la operación. Estas operaciones se pueden incluir en la llamada EVP_PKEY_decrypt_init_ex().

La función EVP_PKEY_decrypt() se puede llamar más de una vez en el mismo contexto si se realizan varias operaciones usando los mismos parámetros.

VALORES DE RETORNO

EVP_PKEY_decrypt_init(), EVP_PKEY_decrypt_init_ex() y EVP_PKEY_decrypt() devuelven 1 para éxito y 0 o un valor negativo para fallo. En particular, un valor de retorno de -2 indica que la operación no es soportada por el algoritmo de clave pública.

ADVERTENCIAS

En versiones de OpenSSL anteriores a la 3.2.0, cuando se usaba en relleno PKCS#1 v1.5, tanto el valor de retorno de EVP_PKEY_decrypt() como la información proporcionada por outlen eran útiles para montar un ataque de Bleichenbacher contra la clave privada utilizada. Tenían que ser procesados de manera segura contra canales laterales.

Desde la versión 3.2.0, el método EVP_PKEY_decrypt() cuando se usa con relleno PKCS#1 v1.5, tal como se implementa en el proveedor **default**, implementa el mecanismo de rechazo implícito (ver OSSL_ASYM_CIPHER_PARAM_IMPLICIT_REJECTION en provider-asym_cipher(7)). Esto significa que no devuelve un error cuando detecta un error en el relleno, sino que devuelve un mensaje generado pseudoaleatoriamente, eliminando la necesidad de código seguro contra canales laterales para las aplicaciones que usan OpenSSL. Si OpenSSL está configurado para usar un proveedor que no implementa el rechazo implícito, el código aún necesita manejar los valores devueltos usando código seguro contra canales laterales. El manejo seguro contra canales laterales de la pila de errores se puede realizar usando un par de llamadas incondicionales a ERR_set_mark(3) y ERR_pop_to_mark(3) o usando la llamada a ERR_clear_error(3).

EJEMPLOS

Descifrar datos usando OAEP (para claves RSA):

#include <openssl/evp.h>
#include <openssl/rsa.h>
EVP_PKEY_CTX *ctx;
ENGINE *eng;
unsigned char *out, *in;
size_t outlen, inlen;
EVP_PKEY *key;
/*
 * NOTA: asume que key, eng, in, inlen ya están configurados
 * y que key es una clave privada RSA
 */
ctx = EVP_PKEY_CTX_new(key, eng);
if (!ctx)
    /* Ocurrió un error */
if (EVP_PKEY_decrypt_init(ctx) <= 0)
    /* Error */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING) <= 0)
    /* Error */
/* Determinar la longitud del búfer */
if (EVP_PKEY_decrypt(ctx, NULL, &outlen, in, inlen) <= 0)
    /* Error */
out = OPENSSL_malloc(outlen);
if (!out)
    /* Fallo de malloc */
if (EVP_PKEY_decrypt(ctx, out, &outlen, in, inlen) <= 0)
    /* Error */
/* Los datos descifrados son outlen bytes escritos en el búfer out */
