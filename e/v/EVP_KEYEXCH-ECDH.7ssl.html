NOMBRE

EVP_KEYEXCH-ECDH - Soporte para el algoritmo de intercambio de claves ECDH

DESCRIPCIÓN

Soporte para el intercambio de claves del tipo de clave ECDH.

Parámetros de intercambio de claves ECDH

"ecdh-cofactor-mode" (OSSL_EXCHANGE_PARAM_EC_ECDH_COFACTOR_MODE) <entero>
Establece u obtiene el modo de operación ECDH para el ctx de intercambio de claves asociado.

En el contexto de un intercambio de claves Diffie-Hellman de Curva Elíptica, este parámetro se puede usar para seleccionar entre las variantes de difusión Diffie-Hellman (DH) o Diffie-Hellman de Cofactor (CDH) del algoritmo de intercambio de claves.

Al establecer, el valor debe ser 1, 0 o -1, forzando respectivamente el modo cofactor activado, desactivado, o reiniciándolo al predeterminado para la clave privada asociada con el ctx de intercambio de claves dado.

Al obtener, el valor debe ser 1 o 0, indicando respectivamente si el modo cofactor está activado o desactivado.

Ver también provider-keymgmt(7) para el parámetro relacionado OSSL_PKEY_PARAM_USE_COFACTOR_ECDH que se puede establecer por clave.

"kdf-type" (OSSL_EXCHANGE_PARAM_KDF_TYPE) <cadena UTF8>
"kdf-digest" (OSSL_EXCHANGE_PARAM_KDF_DIGEST) <cadena UTF8>
"kdf-digest-props" (OSSL_EXCHANGE_PARAM_KDF_DIGEST_PROPS) <cadena UTF8>
"kdf-outlen" (OSSL_EXCHANGE_PARAM_KDF_OUTLEN) <entero sin signo>
"kdf-ukm" (OSSL_EXCHANGE_PARAM_KDF_UKM) <cadena de octetos>

El proveedor FIPS de OpenSSL también soporta los siguientes parámetros:

"fips-indicator" (OSSL_EXCHANGE_PARAM_FIPS_APPROVED_INDICATOR) <entero>
"key-check" (OSSL_EXCHANGE_PARAM_FIPS_KEY_CHECK) <entero>
"digest-check" (OSSL_EXCHANGE_PARAM_FIPS_DIGEST_CHECK) <entero>
Ver "Parámetros comunes de intercambio de claves" en provider-keyexch(7).
"ecdh-cofactor-check" (OSSL_EXCHANGE_PARAM_FIPS_ECDH_COFACTOR_CHECK) <entero>
Si se requiere, este parámetro debe ser antes de OSSL_FUNC_keyexch_derive(). El valor predeterminado de 1 causa un error durante OSSL_FUNC_keyexch_derive si la curva EC tiene un cofactor que no es 1, y el cofactor no se usa. Establecer esto a 0 ignorará el error y establecerá el "fips-indicator" aprobado a 0. Esta opción rompe la conformidad con FIPS si provoca que el "fips-indicator" aprobado devuelva 0.

EJEMPLOS

Los ejemplos de acuerdo de claves se pueden encontrar en demos/keyexch.

Las claves para el host y el par deben ser generadas como se muestra en "Ejemplos" en EVP_PKEY-EC(7) usando el mismo nombre de curva.

El código para generar un secreto compartido para el caso normal es idéntico a "Ejemplos" en EVP_KEYEXCH-DH(7).

Para derivar un secreto compartido en el host usando la clave del host y la clave pública del par, pero también usando X963KDF con material de clave de usuario:

/* Se asume que host_key, peer_pub_key y ukm están configurados */
void derive_secret(EVP_PKEY *host_key, EVP_PKEY *peer_key,
                   unsigned char *ukm, size_t ukm_len)
{
    unsigned char secret[64];
    size_t out_len = sizeof(secret);
    size_t secret_len = out_len;
    unsigned int pad = 1;
    OSSL_PARAM params[6];
    EVP_PKEY_CTX *dctx = EVP_PKEY_CTX_new_from_pkey(NULL, host_key, NULL);
    EVP_PKEY_derive_init(dctx);
    params[0] = OSSL_PARAM_construct_uint(OSSL_EXCHANGE_PARAM_PAD, &pad);
    params[1] = OSSL_PARAM_construct_utf8_string(OSSL_EXCHANGE_PARAM_KDF_TYPE,
                                                 "X963KDF", 0);
    params[2] = OSSL_PARAM_construct_utf8_string(OSSL_EXCHANGE_PARAM_KDF_DIGEST,
                                                 "SHA1", 0);
    params[3] = OSSL_PARAM_construct_size_t(OSSL_EXCHANGE_PARAM_KDF_OUTLEN,
                                            &out_len);
    params[4] = OSSL_PARAM_construct_octet_string(OSSL_EXCHANGE_PARAM_KDF_UKM,
                                                  ukm, ukm_len);
    params[5] = OSSL_PARAM_construct_end();
    EVP_PKEY_CTX_set_params(dctx, params);
    EVP_PKEY_derive_set_peer(dctx, peer_pub_key);
    EVP_PKEY_derive(dctx, secret, &secret_len);
    ...
    OPENSSL_clear_free(secret, secret_len);
    EVP_PKEY_CTX_free(dctx);
}
