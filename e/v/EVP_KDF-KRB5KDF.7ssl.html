NOMBRE

EVP_KDF-KRB5KDF - La implementación KRB5KDF RFC3961 de EVP_KDF

DESCRIPCIÓN

Soporte para calcular el KDF KRB5KDF a través de la API EVP_KDF.

El algoritmo EVP_KDF-KRB5KDF implementa la función de derivación de clave definida en RFC 3961, sección 5.1 y es utilizada por Krb5 para derivar claves de sesión. Se requieren tres entradas para realizar la derivación de clave: un cifrador (por ejemplo, AES-128-CBC), la clave inicial y una constante.

Identidad

"KRB5KDF" es el nombre de esta implementación; se puede utilizar con la función EVP_KDF_fetch().

Parámetros soportados

Los parámetros soportados son:

"properties" (OSSL_KDF_PARAM_PROPERTIES) <cadena UTF8>
"cipher" (OSSL_KDF_PARAM_CIPHER) <cadena UTF8>
"key" (OSSL_KDF_PARAM_KEY) <cadena de octetos>
Estos parámetros funcionan como se describe en "PARÁMETROS" en EVP_KDF(3).
"constant" (OSSL_KDF_PARAM_CONSTANT) <cadena de octetos>
Este parámetro establece el valor de la constante para el KDF. Si ya hay un valor establecido, su contenido se reemplaza.

NOTAS

Se puede obtener un contexto para KRB5KDF llamando a:

EVP_KDF *kdf = EVP_KDF_fetch(NULL, "KRB5KDF", NULL);
EVP_KDF_CTX *kctx = EVP_KDF_CTX_new(kdf);

La longitud de salida de la derivación KRB5KDF se especifica a través del parámetro keylen en la función EVP_KDF_derive(3), y DEBE coincidir con la longitud de clave para el cifrador elegido o se devolverá un error. Además, la longitud de la constante no debe exceder el tamaño del bloque del cifrador. Dado que la longitud de salida de KRB5KDF depende del cifrador elegido, la llamada a EVP_KDF_CTX_get_kdf_size(3) para obtener la longitud requerida solo devuelve la longitud correcta después de que se haya establecido el cifrador. Antes de eso, se devuelve EVP_MAX_KEY_LENGTH. El llamador debe asignar un búfer de la longitud correcta para el cifrador elegido y pasar ese búfer a la función EVP_KDF_derive(3) junto con esa longitud.

EJEMPLOS

Este ejemplo deriva una clave utilizando el cifrador AES-128-CBC:

EVP_KDF *kdf;
EVP_KDF_CTX *kctx;
unsigned char key[16] = "01234...";
unsigned char constant[] = "Soy una constante";
unsigned char out[16];
size_t outlen = sizeof(out);
OSSL_PARAM params[4], *p = params;
kdf = EVP_KDF_fetch(NULL, "KRB5KDF", NULL);
kctx = EVP_KDF_CTX_new(kdf);
EVP_KDF_free(kdf);
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_KDF_PARAM_CIPHER,
                                        SN_aes_128_cbc,
                                        strlen(SN_aes_128_cbc));
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_KEY,
                                         key, (size_t)16);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_KDF_PARAM_CONSTANT,
                                         constant, strlen(constant));
*p = OSSL_PARAM_construct_end();
if (EVP_KDF_derive(kctx, out, outlen, params) <= 0)
    /* Error */
EVP_KDF_CTX_free(kctx);
