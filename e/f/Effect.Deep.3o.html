Manejadores profundos

type ('a, 'b) continuation = ('a, 'b) continuation

('a,'b) continuation es una continuación delimitada que espera un valor 'a y devuelve un valor 'b.

val continue : ('a, 'b) continuation -> 'a -> 'b

continue k x reanuda la continuación k pasando x a k.

Lanza Continuation_already_resumed si la continuación ya ha sido reanudada.

val discontinue : ('a, 'b) continuation -> exn -> 'b

discontinue k e reanuda la continuación k lanzando la excepción e en k.

Lanza Continuation_already_resumed si la continuación ya ha sido reanudada.

val discontinue_with_backtrace : ('a, 'b) continuation -> exn -> Printexc.raw_backtrace -> 'b

discontinue_with_backtrace k e bt reanuda la continuación k lanzando la excepción e en k utilizando bt como origen de la excepción.

Lanza Continuation_already_resumed si la continuación ya ha sido reanudada.

type ('a, 'b) handler = {
retc : 'a -> 'b ;
exnc : exn -> 'b ;
effc : 'c. 'c Effect.t -> (('c, 'b) continuation -> 'b) option ;
}

('a,'b) handler es un registro de manejador con tres campos: retc es el manejador de valores, exnc maneja excepciones y effc maneja los efectos realizados por la computación incluida en el manejador.

val match_with : ('c -> 'a) -> 'c -> ('a, 'b) handler -> 'b

match_with f v h ejecuta la computación f v en el manejador h.

type 'a effect_handler = {
effc : 'b. 'b Effect.t -> (('b, 'a) continuation -> 'a) option ;
}

'a effect_handler es un manejador profundo con un manejador de valor identidad fun x -> x y un manejador de excepciones que lanza cualquier excepción fun e -> raise e.

val try_with : ('b -> 'a) -> 'b -> 'a effect_handler -> 'a

try_with f v h ejecuta la computación f v bajo el manejador h.

val get_callstack : ('a, 'b) continuation -> int -> Printexc.raw_backtrace

get_callstack c n devuelve una descripción de la parte superior de la pila de llamadas en la continuación c, con como máximo n entradas.
