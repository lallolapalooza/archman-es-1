EFADV_CREATE_QP_EX(3) Manual de Verbos Directos EFA EFADV_CREATE_QP_EX(3)

NOMBRE

efadv_create_qp_ex - Crear Cola de Pares extendida específica de EFA

SINOPSIS

#include <infiniband/efadv.h>
struct ibv_qp *efadv_create_qp_ex(struct ibv_context *ibvctx,
                  struct ibv_qp_init_attr_ex *attr_ex,
                  struct efadv_qp_init_attr *efa_attr,
                  uint32_t inlen);

DESCRIPCIÓN

efadv_create_qp_ex() crea una Cola de Pares (Queue Pair) extendida específica del dispositivo.

El argumento attr_ex es una estructura ibv_qp_init_attr_ex, tal como se define en <infiniband/verbs.h>.

Utilice ibv_qp_to_qp_ex() para obtener el ibv_qp_ex para acceder a la interfaz del iterador de operaciones de envío, cuando se utiliza el atributo de creación de QP IBV_QP_INIT_ATTR_SEND_OPS_FLAGS.

El transporte Scalable Reliable Datagram (SRD) proporciona entrega fiable fuera de orden, utilizando de forma transparente múltiples rutas de red para reducir la latencia de cola de red. Su interfaz es similar a UD, en particular, soporta tamaños de mensaje de hasta MTU, con manejo de errores extendido para soportar comunicaciones fiables.

La compatibilidad se maneja utilizando los campos comp_mask e inlen.

struct efadv_qp_init_attr {
    uint64_t comp_mask;
    uint32_t driver_qp_type;
    uint16_t flags;
    uint8_t sl;
    uint8_t reserved[1];
};
inlen
Entrada: Tamaño de la estructura efadv_qp_init_attr.
comp_mask
Máscara de compatibilidad.
driver_qp_type
El tipo de QP a crear:

EFADV_QP_DRIVER_TYPE_SRD: Crear un QP SRD.

flags
Una combinación OR a nivel de bits de los valores descritos a continuación.

EFADV_QP_FLAGS_UNSOLICITED_WRITE_RECV: Las WR de recepción no se consumirán para escritura RDMA con inmediatez (imm).

sl
Nivel de Servicio - el valor 0 implica el nivel predeterminado.

VALOR DEVUELTO

efadv_create_qp_ex() devuelve un puntero al QP creado, o NULL si la solicitud falla.

VER TAMBIÉN

efadv(7), ibv_create_qp_ex(3)
