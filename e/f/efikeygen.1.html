DESCRIPCIÓ

N

efikeygen es una herramienta de línea de comandos para generar claves y certificados para ser usados con pesign. Estos son certificados X.509 estándar, y potencialmente pueden ser generados con cualquier herramienta de creación de certificados. efikeygen genera certificados con opciones sensatas configuradas para una

clave a ser usada para la firma de imá
genes PE para arranque seguro UEFI.

efikeygen(1) — Arch Linux manual pages
























NAME


efikeygen - generates a key, certificate and loads it on a smart
card.






SYNOPSIS


efikeygen [-h]
    [-V] [-k] [-C]
    [-n name] [-S
    subject] [-u uri]
    [-p password]






DESCRIPTION


This tool generates a private key and a self-signed certificate and
    loads them on a smart card. It can also be used to generate a key and
    certificate signed by another key already present on the card. It requires
    that the opensc-pkcs11.so library be installed.


This is intended to be used with UEFI Secure Boot, which requires
    keys to be loaded on a smart card.


It is possible to generate a CA key and certificate, and then use
    that to sign other keys/certificates.


The keys and certificates are generated using RSA, and are stored
    as PKCS#11 objects.


This tool interacts with the smart card via the PKCS#11 interface.






OPTIONS




-h">-h


Prints a usage message and exits.


-V


Prints the version of efikeygen and exits.


-k


This flag indicates that the key being generated is a signing key. It will
    be used to sign other keys and certificates.


-C


This flag indicates that the key being generated is a Certificate Authority
    (CA) key. It will be used to sign other keys and certificates.


-n name


The name to give the key and certificate. This is the label that will be
    used by PKCS#11.


-S subject


The subject name for the certificate. This should be in the format
    required by OpenSSL, e.g.
    CN=My Certificate Name,O=My Organization.


-u uri


The URI for the certificate authority. This is typically a URL where the
    CA's certificate can be found.


-p password


The password to use for the private key. If this is not supplied, the user
    will be prompted for a password.


--signer name


Specifies the name of the key on the smart card that should be used to sign
    the new key and certificate. This is only used when generating a signing key
    or CA key.








EXAMPLES


Initialize the smart card:




# Set environment variables for PINs
# Note: In a real scenario, you would want to use a more secure method
# for handling PINs, rather than environment variables.
host:~$ export SOPIN=$(openssl rand -hex 16)
host:~$ export SOPUK=$(openssl rand -hex 16)
host:~$ export PIN=$(openssl rand -hex 16)
host:~$ export PUK=$(openssl rand -hex 16)

# Initialize the card's PKCS15 data, set the Security Officer PIN and unlock
# code.
host:~$ pkcs15-init -CT --so-pin $SOPIN --so-puk $SOPUK
Using reader with a card: Generic Smart Card Reader Interface [Smart Card Reader Interface] (20070818000000000) 00 00

# Initialize the user PIN and unlock code, and label the token
host:~$ pkcs15-init -P -a 1 --pin $PIN --puk $PUK \
        --so-pin $SOPIN --so-puk $SOPUK \
        --label "myorg-sb-ca"
Using reader with a card: Generic Smart Card Reader Interface [Smart Card Reader Interface] (20070818000000000) 00 00




Generate keys and certificates:




# Create a new CA key and certificate
host:~$ efikeygen -C -n my-ca -S \
        -c "CN=My Org's Secure Boot CA,OU=My Org's CA,O=My Org" \
        -u https://myorg.example.com/ca/

# Create a kernel signing key and cert
host:~$ efikeygen -n my-signer --signer my-ca -k \
        -c "CN=My Org's SB Signer,OU=My Org's CA,O=My Org"\
        -u https://myorg.example.com/ca/




Get them onto the Smart Card




# Save the CA key and certificate in a PKCS-12 bundle
host:~$ pk12util -d /etc/pki/pesign -o my-ca.p12 -n my-ca
Enter password for PKCS12 file: <enter a password here>
Re-enter password: <type it again here>
pk12util: PKCS12 EXPORT SUCCESSFUL

# Import the PKCS-12 bundle onto the card
host:~$ pkcs15-init --store-private-key my-ca.p12 \
        --format pkcs12 --auth-id 01 \
        --pin $PIN --so-pin $SOPIN --so-puk $SOPUK
