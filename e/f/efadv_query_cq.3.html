EFADV_QUERY_CQ(3) Manual de Verbos Directos EFA EFADV_QUERY_CQ(3)

NOMBRE

efadv_query_cq - Consultar atributos específicos del dispositivo de la Cola de Completado

SINOPSIS

#include <infiniband/efadv.h>
int efadv_query_cq(struct ibv_cq *ibvcq, struct efadv_cq_attr *attr,
                   uint32_t inlen);

DESCRIPCIÓN

efadv_query_cq() consulta los atributos específicos del dispositivo de la Cola de Completado.

La compatibilidad se maneja usando los campos comp_mask e inlen.

struct efadv_cq_attr {
    uint64_t comp_mask;
    uint8_t *buffer;
    uint32_t entry_size;
    uint32_t num_entries;
    uint32_t *doorbell;
};
inlen
Entrada: Tamaño de struct efadv_cq_attr.
comp_mask
Máscara de compatibilidad.
buffer
Búfer de la cola de completado.
entry_size
Tamaño de cada entrada de la cola de completado.
num_entries
Número máximo de entradas en la cola de completado.
doorbell
Timbre de llamada inverso utilizado para actualizar el dispositivo de las entradas sondeos y para solicitar notificaciones. NULL cuando no se usa para esta Cola de Completado.

VALOR DE RETORNO

efadv_query_cq() devuelve 0 si tiene éxito, o el valor de errno en caso de error (que indica la razón del fallo).

VER TAMBIÉN

efadv(7)

NOTAS

•
La máscara de compatibilidad (comp_mask) es un campo de salida y actualmente no tiene valores.
