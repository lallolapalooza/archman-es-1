efi_variable_get_attributes(3)

Paquete: efivar

Licencias: LGPL-2.1-or-later

EFI_VARIABLE_T(3) Manual de Funciones de Biblioteca EFI_VARIABLE_T(3)

NOMBRE

efi_variable_import, efi_variable_export, efi_variable_alloc, efi_variable_free, efi_variable_set_name, efi_variable_get_name, efi_variable_set_guid, efi_variable_get_guid, efi_variable_set_data, efi_variable_get_data, efi_variable_set_attributes, efi_variable_get_attributes, efi_variable_realize - funciones de utilidad para importar y exportar variables UEFI a archivos.

SINOPSIS

#include <efivar.h>

typedef struct efi_variable efi_variable_t;
ssize_t efi_variable_import(uint8_t *data, size_t size, efi_variable_t **var);
ssize_t efi_variable_export(efi_variable_t *var, uint8_t **data, size_t *size);
efi_variable_t *efi_variable_alloc(void);
void efi_variable_free(efi_variable_t *var, int free_data);
int efi_variable_set_name(efi_variable_t *var, char *name);
char *efi_variable_get_name(efi_variable_t *var);
int efi_variable_set_guid(efi_variable_t *var, efi_guid_t *guid);
int efi_variable_get_guid(efi_variable_t *var, efi_guid_t **guid);
int efi_variable_set_data(efi_variable_t *var, uint8_t *data, size_t size);
int efi_variable_get_data(efi_variable_t *var, uint8_t **data, size_t *size);
#define EFI_VARIABLE_NON_VOLATILE 0x0000000000000001
#define EFI_VARIABLE_BOOTSERVICE_ACCESS 0x0000000000000002
#define EFI_VARIABLE_RUNTIME_ACCESS 0x0000000000000004
#define EFI_VARIABLE_HARDWARE_ERROR_RECORD 0x0000000000000008
#define EFI_VARIABLE_AUTHENTICATED_WRITE_ACCESS 0x0000000000000010
#define EFI_VARIABLE_TIME_BASED_AUTHENTICATED_WRITE_ACCESS 0x0000000000000020
#define EFI_VARIABLE_APPEND_WRITE 0x0000000000000040
#define EFI_VARIABLE_HAS_AUTH_HEADER 0x0000000100000000
#define EFI_VARIABLE_HAS_SIGNATURE 0x0000000200000000
int efi_variable_set_attributes(efi_variable_t *var, uint64_t attrs);
int efi_variable_get_attributes(efi_variable_t *var, uint64_t *attrs);
int efi_variable_realize(efi_variable_t *var);

DESCRIPCIÓN

efi_variable_t es un tipo de datos opaco utilizado para almacenar variables en memoria para su uso con esta API.

efi_variable_import() se utiliza para importar datos crudos leídos de un archivo. Esta función devuelve la cantidad de datos consumidos con esta variable y puede usarse sucesivamente, utilizando su código de retorno como desplazamiento, para analizar una lista de variables. Tenga en cuenta que la guía interna, el nombre y los valores de los datos se asignan por separado y deben liberarse individualmente o utilizando el parámetro free_data de efi_variable_free(). Los accesores _get() para esos valores devuelven datos adecuados para liberarlos individualmente, excepto en casos en que un accesorio _set() haya recibido un objeto que ya no sea adecuado para ello.

efi_variable_export() se utiliza para organizar objetos efi_variable_t en datos lineales que pueden escribirse en un archivo. Si no se proporcionan los parámetros data o size, esta función devolverá cuánta memoria debe asignar el llamador. De lo contrario, efi_variable_export() utilizará el almacenamiento al que hace referencia como su búfer; si size es menor que la cantidad de almacenamiento necesario, el búfer no se modificará y se devolverá la diferencia entre el espacio necesario y size.

efi_variable_alloc() se utiliza para asignar un objeto efi_variable_t no poblado, adecuado para ser utilizado en toda esta API. efi_variable_free() se utiliza para liberar un objeto efi_variable_t y, si free_data no es cero, para liberar sus datos constituyentes.

Cada par de accesorios _set() y _get() tienen esencialmente la misma semántica. Ninguna operación realiza ninguna gestión de memoria, incluida la liberación de valores previamente establecidos o valores establecidos por efi_variable_import(), y por lo tanto, en algunos casos puede ser necesario utilizar un accesorio _get() para recuperar un objeto que deba liberarse. En casos donde no se ha establecido ningún valor, los accesorios _get() establecerán errno en ENOENT y devolverán un valor negativo o NULL.

efi_variable_set_name() y efi_variable_get_name() se utilizan para establecer y recuperar el nombre de la variable al que se refiere el objeto efi_variable_t.

efi_variable_set_guid() y efi_variable_get_guid() se utilizan para establecer y recuperar el valor GUID del proveedor de la variable a la que se refiere el objeto efi_variable_t.

efi_variable_set_data() y efi_variable_get_data() se utilizan para establecer y recuperar los datos de la variable de un objeto efi_variable_t.

efi_variable_set_attributes() y efi_variable_get_attributes se utilizan para establecer y recuperar los atributos de un objeto efi_variable_t. Todos los bits excepto EFI_VARIABLE_HAS_AUTH_HEADER y EFI_VARIABLE_HAS_SIGNATURE están definidos en la especificación UEFI y deben usarse en consecuencia. EFI_VARIABLE_HAS_AUTH_HEADER debe ser utilizado por las aplicaciones para rastrear si el contenido de los datos de la variable incluye una cabecera de autenticación. EFI_VARIABLE_HAS_SIGNATURE debe ser utilizado por las aplicaciones para rastrear si el contenido de los datos de la variable incluye una firma, y no debe establecerse a menos que también se establezca EFI_VARIABLE_HAS_AUTH_HEADER. Estos atributos se utilizan para rastrear si una variable exportada está en un estado de construcción parcial, por ejemplo, si se ha creado una variable autenticada pero está destinada a ser firmada en una fecha posterior.

efi_variable_realize() es una función de conveniencia para establecer o agregar una variable UEFI en el sistema en ejecución desde un objeto efi_variable_t. sus códigos de retorno son los mismos que los de efi_append_variable(3) si se establece EFI_VARIABLE_APPEND_WRITE, y efi_set_variable() si no se establece ese bit. Además, en el caso de que se establezcan cualquiera de los bits de autenticación, efi_variable_realize() devolverá un error y establecerá errno en EPERM a menos que se hayan establecido ambos bits de atributo EFI_VARIABLE_HAS_AUTH_HEADER y EFI_VARIABLE_HAS_SIGNATURE.

VALOR DE RETORNO

efi_variable_import() devuelve 0 en caso de éxito y -1 en caso de error. En casos donde no puede analizar los datos, errno se establecerá en EINVAL. En casos donde la memoria se ha agotado, errno se establecerá en ENOMEM.

efi_variable_export() devuelve el tamaño de los datos del búfer en caso de éxito, o un valor negativo en caso de error. Si no se proporcionan los parámetros data o size, esta función devolverá cuánta memoria debe asignar el llamador. De lo contrario, esta función utilizará el almacenamiento proporcionado en data; si size es menor que el espacio necesario, el búfer no se modificará y el valor de retorno será la deficiencia de tamaño.

efi_variable_alloc() devuelve un objeto efi_variable_t recién asignado, pero no realiza ninguna asignación para el nombre, guid o data de ese objeto. En caso de agotamiento de memoria, se devolverá NULL y errno se establecerá en ENOMEM.

efi_variable_get_name() devuelve un puntero a la cadena terminada en NUL que contiene la información del nombre del objeto efi_variable_t.

efi_variable_set_name(), efi_variable_set_guid(), efi_variable_get_guid(), efi_variable_set_data(), efi_variable_get_data(), efi_variable_set_attributes(), efi_variable_get_attributes() y efi_variable_realize() devuelven 0 en caso de éxito y -1 en caso de error.
