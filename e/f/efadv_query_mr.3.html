EFADV_QUERY_MR(3) Manual de EFA Direct Verbs EFADV_QUERY_MR(3)

NOMBRE

efadv_query_mr - Consultar los atributos específicos de EFA de la Región de Memoria

SINOPSIS

#include <infiniband/efadv.h>
int efadv_query_mr(struct ibv_mr *ibvmr, struct efadv_mr_attr *attr, uint32_t inlen);

DESCRIPCIÓN

efadv_query_mr() consulta los atributos de la Región de Memoria específicos del dispositivo.

La compatibilidad se maneja utilizando los campos comp_mask e inlen.

struct efadv_mr_attr {
    uint64_t comp_mask;
    uint16_t ic_id_validity;
    uint16_t recv_ic_id;
    uint16_t rdma_read_ic_id;
    uint16_t rdma_recv_ic_id;
};
inlen
Entrada: Tamaño de struct efadv_mr_attr.
comp_mask
Máscara de compatibilidad.
ic_id_validity
Máscara de validez de los campos de ID de interconexión:

EFADV_MR_ATTR_VALIDITY_RECV_IC_ID: recv_ic_id tiene un valor válido.

EFADV_MR_ATTR_VALIDITY_RDMA_READ_IC_ID: rdma_read_ic_id tiene un valor válido.

EFADV_MR_ATTR_VALIDITY_RDMA_RECV_IC_ID: rdma_recv_ic_id tiene un valor válido.

recv_ic_id
Interconexión física utilizada por el dispositivo para acceder a la MR para la operación de recepción.
rdma_read_ic_id
Interconexión física utilizada por el dispositivo para acceder a la MR para la operación de lectura RDMA.
rdma_recv_ic_id
Interconexión física utilizada por el dispositivo para acceder a la MR para la recepción de escritura RDMA.

VALOR DE RETORNO

efadv_query_mr() devuelve 0 si tiene éxito, o el valor de errno si falla (lo que indica el motivo del fallo).

VER TAMBIÉN

efadv(7)

NOTAS

•
La máscara de compatibilidad (comp_mask) es un campo de salida y actualmente no tiene valores.
