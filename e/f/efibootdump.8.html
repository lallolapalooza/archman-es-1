NOMBRE

efibootdump - volcar entradas de arranque de una variable o un archivo

SINOPSIS

efibootdump [-?|--ayuda] [--uso]
[-f <archivo1> [... -f <archivoN>]]
[[-g {guid}] <nombre0> [... [<nombreN>]]]

DESCRIPCIÓN

efibootdump es una aplicación de espacio de usuario utilizada para mostrar opciones de arranque individuales de UEFI, desde un archivo o una variable UEFI. Esto permite mostrar, por ejemplo, archivos guardados de efivarfs, así como variables en la máquina en ejecución.

OPCIONES

La siguiente es una lista de opciones aceptadas por efibootmgr:

-g | --guid {guid}
Cualquier variable especificada por nombre tiene el GUID especificado.
-f | --file <archivo>
Lee una única variable de arranque del archivo especificado.
<nombreN>
Muestra la variable especificada en la máquina local. Si no se especifica ningún GUID, el predeterminado es Variable Global EFI.

ERRORES

Por favor, dirija cualquier error, característica, parche, etc. al equipo de arranque de Red Hat en https://github.com/rhboot/efibootmgr .
