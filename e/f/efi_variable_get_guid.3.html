Tenga en cuenta que los valores internos de guid, nombre y datos se asignan por separado, y deben liberarse individualmente o utilizando el parámetro free_data de efi_variable_free(). Los accesores _get() para esos valores devuelven datos adecuados para liberar individualmente, excepto en aquellos casos en los que un accesador _set() ha recibido un objeto que ya no es adecuado para eso. efi_variable_export() se utiliza para serializar objetos efi_variable_t en datos lineales que pueden

escribirse

en un archivo. Si los parámetros data o size no se proporcionan, esta función devolverá cuánto almacenamiento debe asignar un llamador. De lo contrario, efi_variable_export() usará el almacenamiento referido como su búfer; si size es menor que la cantidad de almacenamiento necesaria, el búfer no se modificará, y se devolverá la diferencia entre el espacio necesario y size. efi_variable_alloc() se utiliza para asignar un objeto efi_variable_t no poblado adecuado para ser utilizado en toda esta

API.

efi_variable_free() se utiliza para liberar un objeto efi_variable_t, y si free_data es distinto de cero, para liberar sus datos constituyentes. Cada par de accesadores _set() y _get() tienen esencialmente la misma semántica. Ninguna operación realiza ninguna gestión

de

memoria, incluida la liberación de valores establecidos previamente o valores establecidos por efi_variable_import(), y por lo tanto en algunos casos puede ser necesario usar un accesador _get() para recuperar un objeto a ser liberado. En los casos en los que no se ha establecido ningún valor, los accesadores _get() establecerán errno a ENOENT y devolverán un valor negativo o NULL. efi_variable_set_name() y efi_variable_get_name() se utilizan para establecer

utilizan

para establecer y recuperar los atributos de un objeto efi_variable_t. Todos los bits excepto EFI_VARIABLE_HAS_AUTH_HEADER y EFI_VARIABLE_HAS_SIGNATURE están definidos en la especificación UEFI y deben usarse en consecuencia. EFI_VARIABLE_HAS_AUTH_HEADER debe ser usada por las aplicaciones para rastrear si el contenido de los datos de la variable incluye un encabezado de autenticación. EFI_VARIABLE_HAS_SIGNATURE debe ser usada por las aplicaciones para rastrear si el contenido de los datos de la variable incluye una firma, y no debe establecerse a menos que EFI_VARIABLE_HAS_AUTH_HEADER también esté establecido. Estos atributos se utilizan para rastrear si una variable exportada está en un estado de construcción parcial, por ejemplo, si una variable autenticada ha sido creada pero está destinada a ser firmada en una fecha posterior. efi_variable_realize() es una función

de

conveniencia para establecer o agregar una variable UEFI en el sistema en ejecución a partir de un objeto efi_variable_t. sus códigos de retorno son los mismos que efi_append_variable(3) si EFI_VARIABLE_APPEND_WRITE está establecido, y efi_set_variable() si ese bit no está establecido. Adicionalmente, en el caso de que cualquiera de los bits de autenticación estén establecidos, efi_variable_realize() devolverá un error y establecerá errno a EPERM a menos que tanto EFI_VARIABLE_HAS_AUTH_HEADER como EFI_VARIABLE_HAS_SIGN
