EFADV_QUERY_DEVICE(3) Manual de Verbos Directos EFA EFADV_QUERY_DEVICE(3)

NOMBRE

efadv_query_device - Consultar capacidades del dispositivo

SINOPSIS

#include <infiniband/efadv.h>
int efadv_query_device(struct ibv_context *ibvctx,
               struct efadv_device_attr *attr,
               uint32_t inlen);

DESCRIPCIÓN

efadv_query_device() consulta los atributos específicos del dispositivo EFA.

La compatibilidad se maneja utilizando los campos comp_mask e inlen.

struct efadv_device_attr {
    uint64_t comp_mask;
    uint32_t max_sq_wr;
    uint32_t max_rq_wr;
    uint16_t max_sq_sge;
    uint16_t max_rq_sge;
    uint16_t inline_buf_size;
    uint8_t reserved[2];
    uint32_t device_caps;
    uint32_t max_rdma_size;
};
inlen
Entrada: Tamaño de struct efadv_device_attr.
comp_mask
Máscara de compatibilidad.
max_sq_wr
Solicitudes de trabajo (WRs) máximas de la cola de envío (SQ).
max_rq_wr
Solicitudes de trabajo (WRs) máximas de la cola de recepción (RQ).
max_sq_sge
Elementos de dispersión-recopilación (SGEs) máximos de la cola de envío (SQ).
max_rq_sge
Elementos de dispersión-recopilación (SGEs) máximos de la cola de recepción (RQ).
inline_buf_size
Tamaño máximo del búfer en línea.
device_caps
Máscara de bits de capacidades del dispositivo:

EFADV_DEVICE_ATTR_CAPS_RDMA_READ: Se admite RDMA read.

EFADV_DEVICE_ATTR_CAPS_RNR_RETRY: Se admite reintento RNR para QPs SRD.

EFADV_DEVICE_ATTR_CAPS_CQ_WITH_SGID: Se admite la lectura de la dirección de origen (SGID) de los descriptores de finalización de recepción. Solo es válido para AH desconocidos.

EFADV_DEVICE_ATTR_CAPS_RDMA_WRITE: Se admite RDMA write

EFADV_DEVICE_ATTR_CAPS_UNSOLICITED_WRITE_RECV: Indica que el dispositivo tiene soporte para crear QPs que pueden recibir RDMA write con inmediato no solicitado. Las RQ con esta característica habilitada no consumirán ninguna solicitud de trabajo para recibir RDMA write con inmediato y una WC generada para dicha recepción se marcará como no solicitada.

EFADV_DEVICE_ATTR_CAPS_CQ_WITH_EXT_MEM_DMABUF: Indica que se admite la creación de CQs con búferes de memoria externos pasando dmabuf.

max_rdma_size
Tamaño máximo de transferencia RDMA en bytes.

VALOR DE RETORNO

efadv_query_device() devuelve 0 si tiene éxito, o el valor de errno en caso de fallo (que indica el motivo del fallo).

VER TAMBIÉN

efadv(7)

NOTAS

•
La máscara de compatibilidad (comp_mask) es un campo de salida y actualmente no tiene valores.
