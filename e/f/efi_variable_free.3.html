NOMBRE

efi_variable_import, efi_variable_export, efi_variable_alloc, efi_variable_free, efi_variable_set_name, efi_variable_get_name, efi_variable_set_guid, efi_variable_get_guid, efi_variable_set_data, efi_variable_get_data, efi_variable_set_attributes, efi_variable_get_attributes, efi_variable_realize - funciones de utilidad para importar y exportar variables UEFI a archivos.

SINOPSIS

#include <efivar.h>

typedef struct efi_variable efi_variable_t;
ssize_t efi_variable_import(uint8_t *data, size_t size, efi_variable_t **var);
ssize_t efi_variable_export(efi_variable_t *var, uint8_t **data, size_t *size);
efi_variable_t *efi_variable_alloc(void);
void efi_variable_free(efi_variable_t *var, int free_data);
int efi_variable_set_name(efi_variable_t *var, char *name);
char *efi_variable_get_name(efi_variable_t *var);
int efi_variable_set_guid(efi_variable_t *var, efi_guid_t *guid);
int efi_variable_get_guid(efi_variable_t *var, efi_guid_t **guid);
int efi_variable_set_data(efi_variable_t *var, uint8_t *data, size_t size);
int efi_variable_get_data(efi_variable_t *var, uint8_t **data, size_t *size);
#define EFI_VARIABLE_NON_VOLATILE 0x0000000000000001
#define EFI_VARIABLE_BOOTSERVICE_ACCESS 0x0000000000000002
#define EFI_VARIABLE_RUNTIME_ACCESS 0x0000000000000004
#define EFI_VARIABLE_HARDWARE_ERROR_RECORD 0x0000000000000008
#define EFI_VARIABLE_AUTHENTICATED_WRITE_ACCESS 0x0000000000000010
#define EFI_VARIABLE_TIME_BASED_AUTHENTICATED_WRITE_ACCESS 0x0000000000000020
#define EFI_VARIABLE_APPEND_WRITE 0x0000000000000040
#define EFI_VARIABLE_HAS_AUTH_HEADER 0x0000000100000000
#define EFI_VARIABLE_HAS_SIGNATURE 0x0000000200000000
int efi_variable_set_attributes(efi_variable_t *var, uint64_t attrs);
int efi_variable_get_attributes(efi_variable_t *var, uint64_t *attrs);
int efi_variable_realize(efi_variable_t *var);

DESCRIPCIÓN

efi_variable_t es un tipo de datos opaco utilizado para almacenar variables en memoria para su uso con esta API.

efi_variable_import() se utiliza para importar datos sin procesar leídos de un archivo. Esta función devuelve la cantidad de datos consumidos con esta variable, y puede usarse sucesivamente, usando su código de retorno como desplazamiento, para analizar una lista de variables. Tenga en cuenta que los valores internos de guid, nombre y datos se asignan por separado, y deben liberarse ya sea individualmente o usando el free_data parámetro de efi_variable_free(). _get() los accesores para esos valores devuelven datos adecuados para ser liberados individualmente, excepto en aquellos casos en los que un _set() accesor se le ha pasado un objeto que ya no es adecuado para eso.

efi_variable_export() se utiliza para serializar efi_variable_t objetos en datos lineales que pueden escribirse en un archivo. Si data o size los parámetros no se proporcionan, esta función devolverá cuánto almacenamiento debe asignar un llamador. De lo contrario, efi_variable_export() usará el almacenamiento referido como su búfer; si size es más pequeño que la cantidad de almacenamiento necesaria, el búfer no se modificará, y la diferencia entre el espacio necesario y size será devuelta.

efi_variable_alloc() se utiliza para asignar un objeto efi_variable_t sin poblar adecuado para ser utilizado en toda esta API. efi_variable_free() se utiliza para liberar un efi_variable_t objeto, y si free_data es distinto de cero, para liberar sus datos constituyentes.

Cada par de _set() y _get() los accesores tienen esencialmente la misma semántica. Ninguna operación realiza ninguna gestión de memoria, incluida la liberación de valores establecidos previamente o valores establecidos por efi_variable_import(), y por lo tanto en algunos casos puede ser necesario usar un _get() accesor para recuperar un objeto a ser liberado. En los casos donde no se ha establecido ningún valor, _get() los accesores establecerán errno a ENOENT y devolverán un valor negativo o NULL.

efi_variable_set_name() y efi_variable_get_name() se utilizan para establecer y recuperar el nombre de la variable referida por el efi_variable_t objeto.

efi_variable_set_guid() y efi_variable_get_guid() se utilizan para establecer y recuperar el valor del GUID del proveedor de la variable referida por el efi_variable_t objeto.

efi_variable_set_data() y efi_variable_get_data() se utilizan para establecer y recuperar los datos de la variable de un efi_variable_t objeto.

efi_variable_set_attributes() y efi_variable_get_attributes se utilizan para establecer y recuperar los atributos de un efi_variable_t objeto. Todos los bits excepto EFI_VARIABLE_HAS_AUTH_HEADER y EFI_VARIABLE_HAS_SIGNATURE están definidos en la especificación UEFI y deben usarse en consecuencia. EFI_VARIABLE_HAS_AUTH_HEADER debe ser usado por las aplicaciones para rastrear si los contenidos de los datos de la variable incluyen un encabezado de autenticación. EFI_VARIABLE_HAS_SIGNATURE debe ser usado por las aplicaciones para rastrear si los contenidos de los datos de la variable incluyen una firma, y no debe establecerse a menos que EFI_VARIABLE_HAS_AUTH_HEADER también esté establecido. Estos atributos se usan para rastrear si una variable exportada está en un estado de construcción parcial, por ejemplo, si una variable autenticada ha sido creada pero está destinada a ser firmada en una fecha posterior.

efi_variable_realize() es una función de conveniencia para establecer o agregar una variable UEFI en el sistema en ejecución desde un efi_variable_t objeto. sus códigos de retorno son los mismos que efi_append_variable(3) si EFI_VARIABLE_APPEND_WRITE está establecido, y efi_variable_set_variable() si ese bit no está establecido. Adicionalmente, en el caso de que cualquiera de los bits de autenticación estén establecidos, efi_variable_realize() devolverá un error y establecerá errno a EPERM a menos que ambos EFI_VARIABLE_HAS_AUTH_HEADER y EFI_VARIABLE_HAS_SIGNATURE bits de atributo estén establecidos.

VALOR DE RETORNO

efi_variable_import() devuelve 0 en caso de éxito, y -1 en caso de fallo. En los casos en que no puede analizar los datos, errno será establecido a EINVAL. En los casos en que la memoria se ha agotado, errno será establecido a ENOMEM.

efi_variable_export() devuelve el tamaño del búfer de datos en caso de éxito, o un valor negativo en caso de error. Si data o size los parámetros no se proporcionan, esta función devolverá cuánto almacenamiento debe asignar un llamador. De lo contrario, esta función usará el almacenamiento proporcionado en data; si size es menor que el espacio necesario, el búfer no se modificará, y el valor de retorno será la deficiencia en el tamaño.

efi_variable_alloc() devuelve un objeto efi_variable_t recién asignado, pero no realiza ninguna asignación para ese objeto name, guid, o data. En el caso de que la memoria se agote, NULL será devuelto, y errno será establecido a ENOMEM.

efi_variable_get_name() devuelve un puntero a la cadena terminada en NUL que contiene la efi_variable_t información del nombre del objeto.

efi_variable_set_name(), efi_variable_set_guid(), efi_variable_get_guid(), efi_variable_set_data(), efi_variable_get_data(), efi_variable_set_attributes(), efi_variable_get_attributes(), y efi_variable_realize() devuelven 0 en caso de éxito y -1 en caso de error.
