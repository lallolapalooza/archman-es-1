EFI-READVAR(1) Comandos de usuario EFI-READVAR(1)

NOMBRE

efi-readvar - herramienta para mostrar variables seguras

SINOPSIS

efi-readvar: [-v <var>] [-s <lista>[-<entrada>]] [-o <archivo>]

DESCRIPCIÓN

sin argumentos, imprime toda la base de datos de variables seguras y expande el contenido de hashes y certificados X509. Puede ser restringido a variables específicas y firmas específicas dentro de las variables. Tenga en cuenta que las listas de firmas EFI se numeran a partir de cero y pueden contener una o más entradas (también numeradas a partir de cero), por lo que 0-0 representa la primera entrada de la lista de firmas cero.

Lista el contenido de las bases de datos de firmas UEFI

OPCIONES

-v <var>
lista solo el contenido de <var>
-s <lista>[-<entrada>]
lista solo una lista de firmas dada (y opcionalmente
solo una entrada dada en esa lista
-o <archivo>
genera las listas de firmas solicitadas en <archivo>

EJEMPLOS

Para ver todas las variables, escribe

efi-readvars

Para ver la segunda entrada de la lista de firmas 1 para la variable db, haz

efi-readvars -v db -s 1-1

Para ver todas las entradas de la lista de firmas 0 para KEK

efi-readvars -v KEK -s 0
