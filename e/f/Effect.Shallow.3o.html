type ('a, 'b) continuation

('a,'b) continuation es una continuación delimitada que espera un valor de tipo 'a y devuelve un valor de tipo 'b.

val fiber : ('a -> 'b) -> ('a, 'b) continuation

fiber f construye una continuación que ejecuta el cálculo f.

type ('a, 'b) handler = {
retc : 'a -> 'b ;
exnc : exn -> 'b ;
effc : 'c. 'c Effect.t -> (('c, 'a) continuation -> 'b) option ;
}

('a,'b) handler es un registro de manejador con tres campos: retc es el manejador de valor, exnc maneja las excepciones y effc maneja los efectos realizados por el cálculo encerrado en el manejador.

val continue_with : ('c, 'a) continuation -> 'c -> ('a, 'b) handler -> 'b

continue_with k v h reanuda la continuación k con el valor v y el manejador h.

Raises Continuation_already_resumed si la continuación ya ha sido reanudada.

val discontinue_with : ('c, 'a) continuation -> exn -> ('a, 'b) handler -> 'b

discontinue_with k e h reanuda la continuación k lanzando la excepción e con el manejador h.

Raises Continuation_already_resumed si la continuación ya ha sido reanudada.

val discontinue_with_backtrace : ('a, 'b) continuation -> exn -> Printexc.raw_backtrace -> ('b, 'c) handler -> 'c

discontinue_with k e bt h reanuda la continuación k lanzando la excepción e con el manejador h utilizando el rastreo bruto bt como origen de la excepción.

Raises Continuation_already_resumed si la continuación ya ha sido reanudada.

val get_callstack : ('a, 'b) continuation -> int -> Printexc.raw_backtrace

get_callstack c n devuelve una descripción de la parte superior de la pila de llamadas en la continuación c, con como máximo n entradas.
