efi_variable_get_attributes se utilizan para establecer y recuperar los atributos de un objeto efi_variable_t. Todos los bits excepto EFI_VARIABLE_HAS_AUTH_HEADER y EFI_VARIABLE_HAS_SIGNATURE están definidos en la especificación UEFI y deben usarse en consecuencia. EFI_VARIABLE_HAS_AUTH_HEADER debe ser usada por las aplicaciones para rastrear si los contenidos de los datos de la variable incluyen un encabezado de autenticación. EFI_VARIABLE_HAS_SIGNATURE debe ser usada por las aplicaciones para rastrear si los contenidos de los datos de la variable incluyen una firma, y no debe establecerse a menos que EFI_VARIABLE_HAS_AUTH_HEADER también esté establecido. Estos atributos se utilizan para rastrear si una variable exportada está en un estado de construcción parcial, por ejemplo, si una variable autenticada ha sido creada pero está destinada a ser firmada en una fecha

posterior.

efi_variable_realize() es una función de conveniencia para establecer o agregar una variable UEFI en el sistema en ejecución a partir de un objeto efi_variable_t. Sus códigos de retorno son los mismos que efi_append_variable(3) si EFI_VARIABLE_APPEND_WRITE está establecido, y efi_set_variable() si ese bit no está establecido.
