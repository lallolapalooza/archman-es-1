EFADV_QUERY_AH(3) Manual de Verbos Directos de EFA EFADV_QUERY_AH(3)

NOMBRE

efadv_query_ah - Consulta los atributos específicos del dispositivo del Address Handle de EFA

SINOPSIS

#include <infiniband/efadv.h>
int efadv_query_ah(struct ibv_ah *ibvah, struct efadv_ah_attr *attr,
           uint32_t inlen);

DESCRIPCIÓN

efadv_query_ah() consulta los atributos específicos del dispositivo del Address Handle.

La compatibilidad se maneja utilizando los campos comp_mask e inlen.

struct efadv_ah_attr {
    uint64_t comp_mask;
    uint16_t ahn;
    uint8_t reserved[6];
};
inlen
Entrada: Tamaño de struct efadv_ah_attr.
comp_mask
Máscara de compatibilidad.
ahn
Número de Address Handle del dispositivo.

VALOR DE RETORNO

efadv_query_ah() devuelve 0 si tiene éxito, o el valor de errno en caso de error (que indica el motivo del fallo).

VER TAMBIÉN

efadv(7)

NOTAS

•
La máscara de compatibilidad (comp_mask) es un campo de salida y actualmente no tiene valores.
