EFI-UPDATEVAR(1) Comandos de usuario EFI-UPDATEVAR(1)

NOMBRE

efi-updatevar - herramienta para actualizar variables seguras

SINOPSIS

efi-updatevar: [-a] [-e] [-d <lista>[-<entrada>]] [-k <clave>] [-g <guid>] [-b <archivo>|-f <archivo>|-c archivo] <var>

DESCRIPCIÓN

Toma una variedad de archivos de entrada y los añade a una de las bases de datos de claves o firmas seguras de arranque de UEFI.

Tenga en cuenta que el sistema de archivos efivarfs debe estar montado en algún lugar del sistema y efi-updatevars debe tener la capacidad de escribir en los archivos (esto generalmente significa que debe ejecutarse como root).

Manipula la base de datos de claves UEFI a través del sistema de archivos efivarfs

OPCIONES

-a
añadir un valor a la variable en lugar de reemplazarlo
-e
usar la lista de firmas EFI en lugar de la actualización firmada (solo funciona en Modo de Configuración)
-b <archivo_binario>
Añadir el hash de <archivo_binario> a la lista de firmas
-f <archivo>
Añadir o Reemplazar el archivo de clave (.esl o .auth) en la variable <var>
-c <archivo>
Añadir o Reemplazar el certificado x509 en la variable <var> (con <guid> si se proporciona)
-g <guid>
Opcional <guid> para el Certificado X509
-k <clave>
Archivo de clave secreta para autorizar actualizaciones en Modo Usuario
-d <lista>[-<entrada>]
Eliminar la lista de firmas <lista> (o solo una única <entrada> dentro de la lista)
--engine <eng>
Usar el motor <eng> para la clave privada

EJEMPLOS

Suponiendo que usted posee su propia clave de plataforma y tiene los archivos PK.auth y noPK.auth que van con ella, puede sacar el sistema del Modo Usuario programáticamente haciendo

efi-updatevar -f noPK.auth PK

y volver a ponerlo con

efi-updatevar -f PK.auth PK

Para añadir el hash de un binario EFI bin.efi a db en Modo de Configuración haga

efi-updatevar -b bin.efi db

Y para añadir una lista de firmas EFI append.esl a db en Modo de Configuración haga

efi-updatevar -a -e append.esl db

Para añadir su clave (KEK.crt) a la Clave de Intercambio de Claves en Modo Usuario, suponiendo que la parte privada de la clave de plataforma está en PK.key, haga

efi-updatevar -a -c KEK.crt -k PK.key KEK

Para añadir el certificado DB.crt a db en Modo Usuario, suponiendo que la parte privada de la Clave de Intercambio de Claves (KEK) está en KEK.key, haga

efi-updatevar -a -c DB.crt -k KEK.key db

Para reemplazar la clave de plataforma antigua (PK) con una nueva en newPK.crt en Modo Usuario, suponiendo que la parte privada de la clave de plataforma antigua está en PK.key, haga

efi-updatevar -c newPK.crt -k PK.key db

Para eliminar la clave privada, pasando la plataforma de Modo Usuario a Modo de Configuración, haga

efi-updatevar -d 0 -k PK.key PK

Y para volver a poner la clave privada (en Modo de Configuración) haga

efi-updatevar -c PK.crt -k PK.key PK
