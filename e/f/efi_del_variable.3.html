efi_del_variable(3)

Paquete: efivar

Licencias: LGPL-2.1-or-later

EFI_DEL_VARIABLE(3) Manual de funciones de biblioteca EFI_DEL_VARIABLE(3)

NOMBRE

efi_variables_supported, efi_del_variable, efi_get_variable, efi_get_variable_attributes, efi_get_variable_size, efi_set_variable - manipular variables UEFI

SINOPSIS

#include <efivar.h>

int efi_variables_supported(void);
int efi_del_variable(efi_guid_t guid, const char *name);
int efi_get_variable(efi_guid_t guid, const char *name,
				 void **data, ssize_t *data_size,
				 uint32_t *attributes);
int efi_get_variable_attributes(efi_guid_t guid, const char *name,
						  uint32_t *attributes);
int efi_get_variable_exists(efi_guid_t guid, const char *name);
int efi_get_variable_size(efi_guid_t guid, const char *name,
					 size_t *size);
int efi_append_variable(efi_guid_t guid, const char *name,
				 void *data, size_t data_size,
				 uint32_t attributes);
int efi_set_variable(efi_guid_t guid, const char *name,
				 void *data, size_t data_size,
				 uint32_t attributes, mode_t mode);
int efi_get_next_variable_name(efi_guid_t **guid, char **name);
int efi_str_to_guid(const char *s, efi_guid_t *guid);
int efi_guid_to_str(const efi_guid_t *guid, char **sp);
int efi_name_to_guid(const char *name, efi_guid_t *guid);
int efi_id_guid_to_guid(const char *id_guid, efi_guid_t *guid);
int efi_guid_to_name(efi_guid_t *guid, char **name);
int efi_guid_to_id_guid(efi_guid_t *guid, char **id_guid);
int efi_guid_to_symbol(efi_guid_t *guid, char **symbol);
int efi_symbol_to_guid(const char *symbol, efi_guid_t *guid);

DESCRIPCIÓN

efi_variables_supported() comprueba si la instalación de variables UEFI es compatible en la máquina actual.

efi_del_variable() elimina la variable especificada por guid y name.

efi_get_variable() obtiene la variable especificada por guid y name. El valor se almacena en data, su tamaño en data_size, y sus atributos se almacenan en attributes.

efi_get_variable_attributes() obtiene atributos para la variable especificada por guid y name.

efi_get_variable_exists() obtiene si la variable especificada por guid y name existe.

efi_get_variable_size() obtiene el tamaño de los datos para la variable especificada por guid y name.

efi_append_variable() añade data de tamaño size a la variable especificada por guid y name.

efi_set_variable() establece la variable especificada por guid y name, y establece el modo de archivo a mode, sujeto a umask. Tenga en cuenta que el modo no persistirá después de un reinicio, y que los permisos solo se aplican si se está en sistemas que utilizan efivarfs.

efi_get_next_variable_name() itera sobre las variables actualmente existentes, devolviendo una guid y un nombre.

efi_str_to_guid() analiza una GUID de UEFI desde formato de cadena a una efi_guid_t que proporciona el llamador

efi_guid_to_str() Crea una representación de cadena de una GUID de UEFI. Si sp es NULL, devuelve qué tan grande sería la cadena. Si sp no es NULL pero *sp es NULL, asigna una cadena y la devuelve. Es responsabilidad del llamador liberar esta cadena. Si sp no es NULL y *sp no es NULL, efi_guid_to_str() asume que hay una asignación de tamaño adecuado y la utiliza.

efi_name_to_guid() se traduce de un nombre conocido a una efi_guid_t que proporciona el llamador.

efi_guid_to_name() se traduce de una efi_guid_t a un nombre conocido. Si la GUID proporcionada no tiene un nombre conocido, esta función es equivalente a efi_guid_to_str().

efi_guid_to_id_guid() se traduce de una efi_guid_t a una GUID de {ID}. Si la GUID proporcionada tiene un nombre conocido, la GUID de {ID} será de la forma "{name_here}". Si no, será de la forma "{66b2af1c-6211-4082-95cb-9f73a4795a7e}".

efi_id_guid_to_guid() se traduce de una GUID de {ID} a una efi_guid_t que proporciona el llamador.

efi_guid_to_symbol() se traduce de una efi_guid_t a un nombre de símbolo de estilo C único (dentro de libefivar). Estos nombres de símbolo son útiles para imprimirlos como un identificador único y fácil de analizar, y también son proporcionados por la biblioteca y sus archivos de encabezado.

efi_symbol_to_guid() se traduce de un nombre de símbolo efi_guid_$FOO de libefivar a una efi_guid_t que proporciona el llamador.

VALOR DE RETORNO

efi_variables_supported() devuelve verdadero si las variables son compatibles en el hardware en ejecución, y falso si no lo son.

efi_get_next_variable_name() devuelve 0 cuando la iteración ha completado, 1 cuando la iteración no ha completado, y -1 en caso de error. En caso de error, errno(3) se configura apropiadamente.

efi_del_variable(), efi_get_variable(), efi_get_variable_attributes(), efi_get_variable_exists(), efi_get_variable_size(), efi_append_variable(), efi_set_variable(), efi_str_to_guid(), efi_guid_to_str(), efi_name_to_guid() y efi_guid_to_name() devuelven negativo en caso de error y cero en caso de éxito.
