para descartar o aceptar transmisión de paquetes específicos sobre la interfaz de red edge. -R regla_str se puede usar múltvarias veces para añadir múltiples reglas. Cada regla -R rule_str añade una regla.

rule_str formato:"src_ip/len:[b_port,e_port],dst_ip/len:[s_port,e_port],TCP+/-,UDP+/-,

ICMP+/-".

ip/len indica un bloque cidr, len puede ignorarse, lo que significa que se usará una ip única (no un bloque cidr) en la regla de

filtro.

+,- después del tipo de protocolo TCP,UDP,ICMP indica permitir o descartar paquetes de ese protocolo. Si falta cualquiera de los tres protocolos anteriores, la regla no tendrá efecto para ese

protocolo.

El rango de puertos [s_port,e_port] puede ser sustituido por un número de puerto único. Si no se especifica, se usará [0,65535]. El rango de puertos incluye start_port y end_port. Si múltiples reglas coinciden con los ips y puertos del paquete, se seleccionará la regla con el bloque cidr más pequeño (espacio de direcciones más pequeño). Esto significa que las reglas con un valor de len más grande tienen mayor

prioridad.

Los paquetes que no coincidan con ninguna regla serán aceptados por defecto. Los usuarios pueden añadir reglas para bloquear tráficos. Este comportamiento puede cambiar añadiendo la regla : `0.0.0.0/0:[0,65535],0.0.0.0/0: [0,65535],TCP-,UDP-,ICMP-`. Luego todo el tráfico será descartado, los usuarios necesitan añadir reglas para permitir

tráficos.

por ejemplo : `-R 0.0.0.0/0,0.0.0.0

MODO DE TEXTO

PLANO

Si -k no se especifica entonces edge usa el modo de texto plano. En el modo de texto plano no hay transformación de los datos del paquete, simplemente se cifra. Esto es útil para depurar n2n ya que el contenido de los paquetes puede verse

claramente.

Para prevenir la exposición accidental de datos, edge solo entra en el modo de texto plano cuando no se especifican parámetros de clave

ado. En el caso de que se especifiquen parámetros de claveado pero no se puedan determinar claves válidas, edge sale con un error al
inicio. Si todas las claves se vuelven inválidas mientras se ejecuta, edge continúa codificando usando la última clave que era válida.
