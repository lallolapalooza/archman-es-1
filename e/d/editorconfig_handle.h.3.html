Set the version fields of an editorconfig_handle object.

Function Documentation

void editorconfig_handle_set_version (editorconfig_handle_t * h, int major, int minor, int patch)

Set the version fields of an editorconfig_handle object.

Parameters

h El objeto editorconfig_handle cuyos campos de versión necesitan ser establecidos.
major Si no es menor que 0, el campo de versión principal se establecerá en major. Si este parámetro es menor que 0, el campo de versión principal del objeto editorconfig_handle permanecerá sin cambios.
minor Si no es menor que 0, el campo de versión secundaria se establecerá en minor. Si este parámetro es menor que 0, el campo de versión secundaria del objeto editorconfig_handle permanecerá sin cambios.
patch Si no es menor que 0, el campo de versión de parche se establecerá en patch. Si este parámetro es menor que 0, el campo de versión de parche del objeto editorconfig_handle permanecerá sin cambios.

Returns

Nada.
