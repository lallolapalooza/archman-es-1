edoc(1) Comandos de usuario edoc(1)

NOMBRE

edoc - Genera documentación como HTML o fragmentos de documentación EEP-48

DESCRIPCIÓN

Este programa es un punto de entrada de línea de comandos para las funciones edoc:application/2 y edoc:files/2. También permite generar solo los fragmentos de documentación EEP-48 (usando la opción -chunks) en lugar de la documentación HTML completa.

edoc -app <app> [-chunks]

EDoc se invoca a través de edoc:application/2, con el conjunto de opciones predeterminado. Si se proporciona -chunks, entonces solo se generarán fragmentos de documentación, no la documentación HTML completa.

Ejecute el script sin argumentos para obtener la lista completa de opciones.

edoc -files <erl_file>... [-chunks]

EDoc se invoca a través de edoc:files/2, con el conjunto de opciones predeterminado. Si se proporciona -chunks, entonces solo se generarán fragmentos de documentación, no la documentación HTML completa.

Ejecute el script sin argumentos para obtener la lista completa de opciones.
