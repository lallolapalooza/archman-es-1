Controla qué modos de tty editrc no permitirá que el usuario cambie. -d , -q o -x indica setty que actúe sobre el conjunto de modos de tty ‘edit’, ‘quote’ o ‘execute’ respectivamente; por defecto -x.

Sin otros argumentos, setty lista los modos del conjunto elegido que están fijados en activado (+mode) o desactivado (-mode). -a lista todos los modos de tty del conjunto elegido independientemente de su configuración. Con +mode, -mode o mode, fija mode como activado o desactivado o elimina el control de mode en el conjunto elegido.

Setty también se puede usar para establecer caracteres de tty a valores particulares usando char=value. Si value está vacío, entonces el carácter se establece a _POSIX_VDISABLE.

ENTORNO

EDITRC
Nombra el archivo de configuración por defecto para la editline(3) biblioteca.

ARCHIVOS

~/.editrc
Archivo de configuración de último recurso para el usuario de la editline(3) biblioteca si no se especifica ningún otro archivo.
