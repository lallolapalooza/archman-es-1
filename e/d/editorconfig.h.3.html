Documentación de la Definición de Macros

#define EDITORCONFIG_PARSE_MEMORY_ERROR (-3)

editorconfig_parse() valor de retorno: se produce un error de memoria.

#define EDITORCONFIG_PARSE_NOT_FULL_PATH (-2)

editorconfig_parse() valor de retorno: el parámetro full_filename de editorconfig_parse() no es una ruta de nombre completa

#define EDITORCONFIG_PARSE_VERSION_TOO_NEW (-4)

editorconfig_parse() valor de retorno: la versión requerida especificada en editorconfig_handle es mayor que la versión actual.

Documentación de Funciones

const char * editorconfig_get_error_msg (int err_num)

Obtiene el mensaje de error a partir del número de error devuelto por editorconfig_parse(). Un ejemplo está disponible en src/bin/main.c en el código fuente de EditorConfig C Core.

Parámetros

err_num El número de error que se utiliza para obtener el mensaje de error.

Devuelve

El mensaje de error correspondiente a err_num.

void editorconfig_get_version (int * major, int * minor, int * patch)

Obtiene el número de versión de EditorConfig. Un ejemplo está disponible en src/bin/main.c en el código fuente de EditorConfig C Core.

Parámetros

major Si no es nulo, el entero al que apunta major se rellenará con la versión principal de EditorConfig.
minor Si no es nulo, el entero al que apunta minor se rellenará con la versión secundaria de EditorConfig.
patch Si no es nulo, el entero al que apunta patch se rellenará con la versión de parche de EditorConfig.

Devuelve

Nada.

const char * editorconfig_get_version_suffix (void )

Obtiene el sufijo de versión.

Devuelve

El sufijo de versión, por ejemplo "-development" para una versión de desarrollo, cadena vacía para una versión estable.

int editorconfig_parse (const char * full_filename, editorconfig_handle h)

Analiza los archivos editorconfig correspondientes a la ruta de archivo dada por full_filename, y la información relacionada se introduce y se devuelve en h. Un ejemplo está disponible en src/bin/main.c en el código fuente de EditorConfig C Core.

Parámetros

full_filename La ruta completa de un archivo que es editado por el editor para el cual es el resultado del análisis.
h El editorconfig_handle que se utilizará y se devolverá desde esta función (incluyendo el resultado del análisis). El editorconfig_handle debe ser creado por editorconfig_handle_init().

Valores de retorno

0 Todo está bien.
Entero positivo Se produce un error de análisis. El valor de retorno será el número de línea del error de análisis. err_file obtenido de h llamando a editorconfig_handle_get_err_file() también se rellenará con la ruta del archivo que causó el error de análisis.
Entero negativo Ocurrió algún error. Vea abajo la razón del error para cada valor de retorno.
EDITORCONFIG_PARSE_NOT_FULL_PATH full_filename no es una ruta de nombre completa.
EDITORCONFIG_PARSE_MEMORY_ERROR Se produce un error de memoria.
EDITORCONFIG_PARSE_VERSION_TOO_NEW La versión requerida especificada en editorconfig_handle es mayor que la versión actual.
