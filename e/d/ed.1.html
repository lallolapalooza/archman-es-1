ED(1) Comandos de usuario ED(1)

NOMBRE

ed - editor de texto orientado a líneas

SINOPSIS

ed [opciones] [[+línea] archivo]

DESCRIPCIÓN

GNU ed es un editor de texto orientado a líneas. Se utiliza para crear, mostrar, modificar y manipular archivos de texto, tanto de forma interactiva como a través de scripts de shell. Una versión restringida de ed, red, solo puede editar archivos en el directorio actual y no puede ejecutar comandos del shell. Ed es el editor de texto 'estándar' en el sentido de que es el editor original de Unix y, por lo tanto, está ampliamente disponible. Para la mayoría de los propósitos, sin embargo, está superado por editores de pantalla completa.

El nombre del archivo puede ir precedido por '+línea', '+/RE', o '+?RE' para establecer la línea actual al número de línea especificado o a la primera o última línea que coincida con la expresión regular 'RE'.

Inicia la edición leyendo 'archivo' si se proporciona. Si 'archivo' comienza con un '!', lee la salida del comando del shell.

La variable de entorno LINES se puede usar para establecer el tamaño inicial de la ventana.

OPCIONES

-h, --help
muestra esta ayuda y sale
-V, --version
muestra información de la versión y sale
-E, --extended-regexp
usa expresiones regulares extendidas
-G, --traditional
ejecuta en modo de compatibilidad
-l, --loose-exit-status
sale con estado 0 incluso si un comando falla
-p, --prompt=CADENA
usa CADENA como un prompt interactivo
-q, --quiet, --silent
suprime los diagnósticos escritos en stderr
-r, --restricted
ejecuta en modo restringido
-s, --script
suprime recuentos de bytes y el prompt '!'
-v, --verbose
sea verboso; equivalente al comando 'H'
--strip-trailing-cr
elimina los retornos de carro al final de las líneas de texto
--unsafe-names
permite caracteres de control en nombres de archivo

ESTADO DE SALIDA

0 para una salida normal, 1 para problemas ambientales (opciones de línea de comandos inválidas, memoria agotada, comando fallido, etc.), 2 para problemas con el archivo de entrada (archivo no encontrado, búfer modificado, errores de E/S), 3 para un error de consistencia interna (por ejemplo, un error) que hizo que ed entrara en pánico.
