NOMBRE

ewfmount — montar datos almacenados en archivos EWF

SINOPSIS

ewfmount [-f formato] [-X opciones_extendidas] [-hvV] archivos_ewf

DESCRIPCIÓN

ewfmount es una utilidad para montar datos almacenados en archivos EWF.

ewfmount forma parte del paquete libewf. libewf es una biblioteca para acceder al Formato de Compresión Expert Witness (EWF).

archivos_ewf el primer archivo o el conjunto completo de archivos de segmento EWF punto_de_montaje el directorio que servirá como punto de montaje

Las opciones son las siguientes:

-f formato
especificar el formato de entrada, opciones: raw (por defecto), files (restringido a archivos de volumen lógico)
-h
muestra esta ayuda
-v
salida detallada a stderr
-V
imprime la versión
-X opciones_extendidas
opciones extendidas para pasar al subsistema

ENTORNO

Ninguno

FICHEROS

Ninguno

EJEMPLOS

# ewfmount floppy.E01 floppy/
ewfmount 20110918

DIAGNÓSTICO

Los errores, la salida detallada y de depuración se imprimen en stderr cuando se habilita la salida detallada -v. La salida detallada y de depuración solo se imprimen cuando están habilitadas en la compilación.

ERRORES

Por favor, informe de errores de cualquier tipo en el rastreador de problemas del proyecto: https://github.com/libyal/libewf-legacy/issues
