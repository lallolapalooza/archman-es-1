NOMBRE

ewfinfo — muestra metadatos almacenados en archivos EWF

SINOPSIS

ewfinfo [-A codepage] [-d date_format] [-f format] [-ehimvV] archivos_ewf

DESCRIPCIÓN

ewfinfo es una utilidad para mostrar metadatos almacenados en archivos EWF.

ewfinfo es parte del paquete libewf. libewf es una biblioteca para acceder al Formato de Compresión de Expert Witness (EWF).

archivos_ewf el primer o el conjunto completo de archivos de segmento EWF.

Las opciones son las siguientes:

-A codepage
la página de códigos de la sección de encabezado, opciones: ascii (por defecto), windows-874, windows-932, windows-936, windows-949, windows-950, windows-1250, windows-1251, windows-1252, windows-1253, windows-1254, windows-1255, windows-1256, windows-1257 o windows-1258
-d date_format
el formato de fecha, opciones: ctime (por defecto), dm (día/mes), md (mes/día), iso8601
-e
mostrar solo información de error de lectura EWF
-f format
especificar el formato de salida, opciones: text (por defecto), dfxml
-h
muestra esta ayuda
-i
mostrar solo información de adquisición EWF
-m
mostrar solo información de medios EWF
-v
salida detallada a stderr
-V
imprimir versión

AMBIENTE

Ninguno

ARCHIVOS

Ninguno

DIAGNÓSTICO

Los errores, la salida detallada y de depuración se imprimen en stderr cuando se habilita la salida detallada -v. La salida detallada y de depuración solo se imprimen cuando se habilitan en la compilación.
