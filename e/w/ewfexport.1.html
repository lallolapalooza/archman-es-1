DESCRIPCIÓ

N

ewfexport es una utilidad para exportar datos de medios almacenados en archivos

EWF.

ewfexport forma parte del paquete libewf. libewf es una biblioteca para acceder al Expert Witness Compression Format (EWF)

.

ewf_files el primer archivo de segmento EWF o el conjunto completo de archivos de segmento

EWF

Las opciones son las

siguientes:
-A codepa
ge
la página de códigos de la sección de cabecera, opciones: ascii (por defecto), windows-874, windows-932, windows-936, windows-949, windows-950, windows-1250, windows-1251, windows-1252, windows-1253, windows-1254, windows-1255, windows-1256, windows-1257 o
windows-1258
-b number_of_sect
ors
el número de sectores a leer de una vez (por trozo), opciones: 16, 32, 64 (por defecto), 128, 256, 512, 1024, 2048, 4096, 8192, 16384 o
32768
-B number_of_by
tes
el número de bytes a
exportar
-c compression_val

especifica los valores de compresión como: nivel o método:nivel opciones de método de compresión: deflate (por defecto) opciones de nivel de compresión: none (por defecto), empty-block, fast o
best
-d digest_ty
pe
calcula tipos de digest (hash) adicionales además de md5, opciones: sha1 (no se usa para los formatos raw y
files)
-f form
at
el formato de salida al que escribir, opciones: raw (por defecto), files (restringido a archivos de volumen lógico), ewf, smart, ftk, encase1, encase2, encase3, encase4, encase5, encase6, encase7, encase7-v2, linen5, linen6, linen7,
ewfx.
