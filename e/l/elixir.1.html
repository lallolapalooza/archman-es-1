DESCRIPCIÓ

N

El programa inicia el sistema de ejecución, típicamente para la ejecución de uno o más scripts. Es similar a iex(1), pero elixir termina cuando el

script ejecut
ado termina.

--hidd
en
Inicia un nodo oculto.

Las conexiones entre nodos son transitivas. Por ejemplo, si el nodo A está conectado al nodo B, y el nodo B está conectado al nodo C, entonces el nodo A está conectado al nodo C. La opción --hidden permite crear un nodo que puede conectarse a otro nodo, evitando conexiones

redundantes.

La función Node.list/0 permite obtener la lista de nodos conectados al nodo objetivo; sin embargo, la lista no incluirá los nodos ocultos. Dependiendo del parámetro de entrada, la función Node.list/1 permite obtener la lista que contiene solo nodos ocultos (el parámetro :hidden) o tanto nodos ocultos como no ocultos (el parámetro :conne

cte
d).

--sname nom
bre
Da a un nodo un nombre corto e inicia. Los nombres cortos toman la forma de nombre@host, donde host es el nombre del host objetivo (hostname(1)) que ejecuta el nodo. Los nodos con nombres cortos solo pueden interactuar entre sí en la misma red
local.
--name nom
bre
Da a un nodo un nombre largo e inicia. Los nombres largos toman la forma de nombre@host, donde host es la dirección IP del host que ejecuta el nodo. A diferencia de los nodos con nombres cortos, los nodos con nombres largos no están limitados por los límites de una red local (véase arriba)
.

--no-halt

--

NOTAS

Las siguientes opciones se pueden dar más de una vez: --boot-var, --erl-config, --eval, --rpc-eval.

ENTORNO

ELIXIR_ERL_OPTIONS
Permite pasar parámetros al runtime de Erlang.

ARCHIVOS

~/.erlang.cookie
Almacena el valor de la cookie mágica que solo se utiliza cuando no se especificó a través de la opción --cookie (ver arriba). Si el archivo no existe cuando se inicia un nodo, se creará.
