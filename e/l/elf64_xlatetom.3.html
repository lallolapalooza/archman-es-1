ELF32_XLATETOM(3) Manual del programador de Libelf ELF32_XLATETOM(3)

NOMBRE

elf32_xlatetom, elf64_xlatetom - traduce datos ELF de 32 o 64 bits de la
representación de archivo a la representación de memoria
elf32_xlatetof, elf64_xlatetof - traduce datos ELF de 32 o 64 bits de la
representación de memoria a la representación de archivo

SINOPSIS

#include <libelf.h>
int elf32_xlatetom(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf64_xlatetom(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf32_xlatetof(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf64_xlatetof(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);

DESCRIPCIÓN

Traduce datos ELF de la representación de archivo a la representación de memoria o viceversa. Las representaciones de archivo y de memoria de los datos ELF pueden diferir en términos de endianness. Los datos en representación de archivo normalmente provienen de elf_rawdata, mientras que los datos en representación de memoria normalmente provienen de elf_getdata. Cuando no hay diferencia entre las representaciones de archivo y de memoria, estas funciones simplemente copian los datos ELF de src a dst. De lo contrario, la codificación cambiará entre ELFDATA2LSB (complemento a dos, little-endian) y ELFDATA2MSB (complemento a dos, big-endian). La codificación de un archivo ELF se especifica en el miembro Elf32_Ehdr o Elf64_Ehdr e_ident[EI_DATA]. Para conocer la codificación en memoria de un programa, puedes incluir <endian.h> y comprobar BYTE_ORDER == LITTLE_ENDIAN (correspondiente a ELFDATA2LSB) o BYTE_ORDER == BIG_ENDIAN (correspondiente a ELFDATA2MSB).

PARÁMETROS

dst
Destino donde se almacenarán los datos traducidos. El campo d_size de dst debe ser al menos tan grande como el campo d_size de src.
src
Datos de origen. Para las funciones xlatetom, los datos de origen deben estar en representación de archivo. Para las funciones xlatetof, los datos de origen deben estar en representación de memoria.
encoding
Especifica una codificación. Puede ser ELFDATA2LSB (complemento a dos, little-endian) o ELFDATA2MSB (complemento a dos, big-endian). Para las funciones xlatetom, esto especifica la codificación de src. Para las funciones xlatetof, esto especifica la codificación de dst.

VALOR DE RETORNO

En caso de éxito, devuelve dst, que contendrá los datos traducidos. Si no hay diferencia entre las representaciones de archivo y de memoria, dst contendrá una copia de los datos de origen. Los campos d_type y d_size de dst se establecerán en los mismos valores que los de src.


Si ocurre un error, devuelve NULL y establece un código de error de libelf.
