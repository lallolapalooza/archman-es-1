ELF_NEXTSCN(3) Manual del programador de Libelf ELF_NEXTSCN(3)

NOMBRE

elf_nextscn - Devolver la siguiente sección en un descriptor ELF.

SINOPSIS

#include <libelf.h>
Elf_Scn *elf_nextscn(Elf *elf, Elf_Scn *scn);

DESCRIPCIÓN

La función elf_nextscn() devuelve un identificador a la siguiente sección en el descriptor de objeto ELF elf. Si scn es NULL, se devuelve la primera sección (con índice 1). El índice de sección 0 está reservado y se omite.

Si scn no es NULL, se devuelve la sección inmediatamente posterior a ella. Si no hay más secciones, se devuelve NULL.

PARÁMETROS

elf
Un puntero a un descriptor ELF.
scn
Un identificador de sección devuelto por elf_getscn(3), o NULL para comenzar la iteración.

VALOR DE RETORNO

Devuelve un puntero a la siguiente estructura Elf_Scn en la lista de secciones, o NULL si no hay más secciones o si elf es NULL.

VER TAMBIÉN

elf_getscn(3), elf_newscn(3), libelf(3), elf(5)

ATRIBUTOS

Interfaz Atributo Valor
elf_nextscn () Seguridad de hilos MT-Safe
