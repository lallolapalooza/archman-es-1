elf32_getphdr(3)

Paquete: libelf

ELF32_GETPHDR(3) Manual del programador de Libelf ELF32_GETPHDR(3)

NOMBRE

elf32_getphdr, elf64_getphdr - recuperar la tabla de encabezados de programa para un archivo objeto ELF de 32 o 64 bits

SINOPSIS

#include <libelf.h>
Elf32_Phdr *elf32_getphdr(Elf *elf);
Elf64_Phdr *elf64_getphdr(Elf *elf);

DESCRIPCIÓN

Recupera la tabla de encabezados de programa para el descriptor ELF dado elf. El número de elementos en la tabla de encabezados de programa se puede recuperar con elf32_getphdrnum y elf64_getphdrnum. elf32_newphdr y elf64_newphdr cambian el tamaño de la tabla de encabezados de programa o la eliminan. Si se cambia un elemento de la tabla de encabezados de programa, debe llamar a elf_flagphdr con ELF_C_SET y ELF_F_DIRTY para escribir los nuevos datos en el disco.

PARÁMETROS

elf
Descriptor ELF del cual recuperar la tabla de encabezados de programa.

VALOR DE RETORNO

En caso de éxito, devuelve un puntero a la tabla de encabezados de programa. Devuelve NULL si no hay un encabezado de programa. En caso de error, devuelve NULL y establece un código de error de libelf.

VER TAMBIÉN

elf32_newphdr(3), elf_errno(3), elf_getphdrnum(3), libelf(3), elf(5)

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
