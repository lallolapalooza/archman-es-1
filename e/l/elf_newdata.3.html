NOMBRE

elf_newdata - Añadir un nuevo descriptor Elf_Data a una sección

SINOPSIS

#include <libelf.h>
Elf_Data * elf_newdata(Elf_Scn *scn);

DESCRIPCIÓN

La función elf_newdata() crea un nuevo descriptor Elf_Data y lo asocia con la sección a la que se refiere scn. Este descriptor puede utilizarse para describir nuevos contenidos de sección para un objeto ELF que se está construyendo o modificando.

La sección no debe ser la sección nula (índice 0). Si la sección aún no tiene datos asociados o fue creada usando elf_newscn(), esta función crea el primer descriptor Elf_Data para la sección.

Las llamadas posteriores a elf_newdata() añadirán nuevos descriptores de datos a la sección.

El descriptor devuelto se marca como sucio para que sea incluido durante elf_update(). El descriptor devuelto también se inicializa para representar ningún dato con d_buf establecido a NULL, d_type establecido a ELF_T_BYTE, d_version establecido a EV_CURRENT, y d_size, d_off y d_align establecidos a cero.

PARÁMETROS

scn
Un descriptor de sección al que se debe adjuntar el nuevo descriptor de datos. No debe ser la sección cero, la sección nula. Si scn es NULL, esta función devuelve NULL.

VALOR DE RETORNO

En caso de éxito, se devuelve un puntero a un descriptor Elf_Data nuevo y escribible. En caso de fallo, se devuelve NULL y se establece un elf_errno. Si scn es NULL, se devuelve NULL y no se establece elf_errno.

El llamante es responsable de configurar el valor de retorno (ver DESCRIPCIÓN para los valores de campo predeterminados).

VER TAMBIÉN
