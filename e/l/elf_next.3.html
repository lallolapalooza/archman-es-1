NOMBRE

elf_next - avanza un descriptor ELF al siguiente miembro del archivo

SINOPSIS

#include <libelf.h>
Elf_Cmd elf_next(Elf *elf);

DESCRIPCIÓN

Avanza un descriptor ELF asociado con un archivo de archivo al siguiente miembro del archivo disponible.

Los descriptores ELF inicializados desde un archivo de archivo se pueden usar para recuperar descriptores ELF para los miembros del archivo uno a la vez usando elf_begin(3). elf_next(3) actualiza el descriptor del archivo para que elf_begin(3) devuelva el descriptor ELF del siguiente miembro del archivo. Ver la sección EJEMPLOS a continuación.

VALOR DE RETORNO

Si elf se refiere a un miembro del archivo, actualiza el estado del descriptor ELF del archivo padre asociado con elf para que el siguiente miembro del archivo pueda ser recuperado con elf_begin(3). Devuelve el Elf_Cmd que se usó con elf_begin(3) para inicializar elf.

Si elf no fue inicializado desde un archivo de archivo o no hay más miembros del archivo, elf_next(3) devuelve ELF_C_NULL.

EJEMPLOS

  /* Abrir el archivo.  */
  fd = open (archive_name, O_RDONLY);
  if (fd == -1)
    {
      printf ("no se puede abrir el archivo de archivo `%s'", fname);
      exit (1);
    }
  /* Establecer la versión ELF.  */
  elf_version (EV_CURRENT);
  /* Crear un descriptor ELF para el archivo.  */
  cmd = ELF_C_READ;
  elf = elf_begin (fd, cmd, NULL);
  if (elf == NULL)
    {
      printf ("no se puede crear el descriptor ELF: %s\n", elf_errmsg (-1));
      exit (1);
    }
  /* Verificar que este es un descriptor para un archivo.  */
  if (elf_kind (elf) != ELF_K_AR)
    {
      printf ("`%s' no es un archivo\n", fname);
      exit (1);
    }
  /* Obtener los miembros del archivo uno tras otro.  */
  while ((subelf = elf_begin (fd, cmd, elf)) != NULL)
    {
      /* Procesar subelf aquí */
      [...]
      /* elf_next actualiza elf, el archivo padre, para que la siguiente llamada
         a elf_begin devuelva el siguiente miembro del archivo.  */
      cmd = elf_next (subelf);
      if (elf_end (subelf) != 0)
        {
          printf ("error al liberar el descriptor sub-ELF: %s\n",
                  elf_errmsg (-1));
          exit (1);
        }
    }
  elf_end (elf);
  close (fd);
