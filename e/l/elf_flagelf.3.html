ELF_FLAGELF(3) Manual del programador de Libelf ELF_FLAGELF(3)

NOMBRE

elf_flagelf, elf_flagdata, elf_flagehdr, elf_flagphdr, elf_flagscn, elf_flagshdr - establecer o borrar banderas en descriptores y componentes ELF

SINOPSIS

#include <libelf.h>
unsigned int elf_flagelf(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagehdr(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagphdr(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagscn(Elf_Scn * scn, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagshdr(Elf_Scn * scn, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagdata(Elf_Data * data, Elf_Cmd cmd, unsigned int flags);

DESCRIPCIÓN

Estas funciones permiten al llamante establecer o borrar banderas en varios componentes ELF gestionados por libelf. Se suelen usar para indicar que un componente ha sido modificado (sucio), o para controlar el comportamiento de la disposición durante la salida.

elf_flagelf() modifica las banderas en el descriptor principal Elf.

elf_flagdata() modifica las banderas en un descriptor Elf_Data, típicamente recuperado usando elf_getdata(3) o creado con elf_newdata(3).

elf_flagehdr() modifica las banderas en la cabecera ELF para un descriptor ELF (por ejemplo, el resultado de gelf_getehdr(3)).

elf_flagphdr() modifica las banderas en la tabla de cabeceras de programa de un descriptor ELF.

elf_flagscn() modifica las banderas en un descriptor Elf_Scn (sección).

elf_flagshdr() modifica las banderas en la cabecera de sección de un Elf_Scn dado.

El argumento cmd determina si las banderas dadas deben ser establecidas (ELF_C_SET) o borradas (ELF_C_CLR).

Los siguientes valores de bandera pueden ser pasados a través del parámetro flags:

ELF_F_DIRTY
Marca el objeto como modificado. Esto asegura que los cambios en el componente se escriban durante elf_update(3).
ELF_F_LAYOUT
Indica que la disposición del componente ELF se gestiona manualmente. Las posiciones y tamaños se conservarán tal como se proporcionaron. Esta bandera solo se usa con elf_flagelf() y se ignora cuando se usa con otras funciones. Si esta bandera está establecida, el usuario debe establecer Ehdr e_phoff, e_shoff, así como Elf_Data d_off y Shdr sh_offset. Si no está establecida, estas posiciones se recalcularán cuando se llame a elf_update. Si ELF_F_LAYOUT está establecido, los cambios en las posiciones de phdr impedirán que elf_update ajuste automáticamente las posiciones de shdr.
ELF_F_PERMISSIVE
Habilita una validación relajada de la estructura del objeto. Esta bandera permite disposiciones no estándar sin verificaciones estrictas. Específicamente, elimina una verificación en elf_update() de que el tamaño de la sección sh_size es un múltiplo del tamaño de la entrada de la sección sh_entsize (si no es cero). Esta bandera solo se usa con elf_flagelf() y se ignora cuando se usa con otras funciones. ELF_F_PERMISSIVE es una extensión de libelf de elfutils y puede no estar disponible en otras implementaciones de libelf.

PARÁMETROS

obj
El objeto a modificar: Para elf_flagelf, elf_flagehdr, elf_flagphdr, es un descriptor Elf *. Para elf_flagscn y elf_flagshdr, es un descriptor Elf_Scn *. Para elf_flagdata, un buffer Elf_Data *.
cmd
Debe ser una de las siguientes: ELF_C_SET para establecer las banderas dadas, o ELF_C_CLR para borrarlas.
flags
Máscara de bits de las banderas a modificar. Puede incluir cualquier combinación de ELF_F_DIRTY, ELF_F_LAYOUT y ELF_F_PERMISSIVE.

Tenga en cuenta que ELF_F_LAYOUT y ELF_F_PERMISSIVE solo se usan con elf_flagelf() y se ignoran para otras funciones.

VALOR DE RETORNO

Devuelve el nuevo valor de las banderas después de la operación de establecer/borrar.

Devuelve 0 en caso de error y establece un código de error que se puede recuperar mediante elf_errmsg(3). Si el primer argumento es NULL, se devuelve 0 y no se establece ningún código de error.

Si la última bandera se borra, se devolverá 0 como el nuevo valor de la bandera. En este caso, 0 no es un indicador de error y no se establece ningún código de error.
