ELF_GETDATA(3) Manual del programador de Libelf ELF_GETDATA(3)

NOMBRE

elf_getdata - Obtener datos procesados de una sección

SINOPSIS

#include <libelf.h>

Elf_Data * elf_getdata (Elf_Scn *scn, Elf_Data *data);

DESCRIPCIÓN

La función elf_getdata() permite al usuario obtener los buffers de datos de la sección scn
. Puede haber más de un buffer si el usuario los ha añadido explícitamente. Cuando se lee un archivo, la biblioteca libelf crea exactamente un buffer de datos.

El primer buffer de la lista se puede obtener pasando un puntero nulo en el parámetro data. Para obtener el siguiente buffer de datos, se debe pasar el valor devuelto previamente en el parámetro data. Si no quedan más buffers en la lista, se devuelve un puntero nulo.

Si el parámetro data no es un puntero nulo, debe ser un descriptor para un buffer asociado con la sección scn . Si no es así, se devuelve un puntero nulo. Para facilitar el manejo de errores, elf_getdata también devuelve un puntero nulo si el parámetro scn es un puntero nulo.
