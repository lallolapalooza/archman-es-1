ELF_FLAGELF(3) Manual del programador de Libelf ELF_FLAGELF(3)

NOMBRE

elf_flagelf, elf_flagdata, elf_flagehdr, elf_flagphdr, elf_flagscn, elf_flagshdr - establecer o borrar banderas en descriptores y componentes ELF

SINOPSIS

#include <libelf.h>
unsigned int elf_flagelf(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagehdr(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagphdr(Elf * elf, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagscn(Elf_Scn * scn, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagshdr(Elf_Scn * scn, Elf_Cmd cmd, unsigned int flags);
unsigned int elf_flagdata(Elf_Data * data, Elf_Cmd cmd, unsigned int flags);

DESCRIPCIÓN

Estas funciones permiten al llamador establecer o borrar banderas en varios componentes ELF gestionados por libelf . Se utilizan típicamente para indicar que un componente ha sido modificado (sucio), o para controlar el diseño durante la salida.

elf_flagelf() modifica las banderas en el descriptor Elf de nivel superior.

elf_flagdata() modifica las banderas en un descriptor Elf_Data, recuperado típicamente usando elf_getdata(3) o creado con elf_newdata(3).

elf_flagehdr() modifica las banderas en la cabecera ELF para un descriptor ELF (por ejemplo, el resultado de gelf_getehdr(3)).

elf_flagphdr() modifica las banderas en la tabla de cabeceras de programa de un descriptor ELF.

elf_flagscn() modifica las banderas en un descriptor Elf_Scn (sección).

elf_flagshdr() modifica las banderas en la cabecera de sección de un Elf_Scn dado.

El argumento cmd determina si las banderas dadas deben ser establecidas ( ELF_C_SET ) o borradas ( ELF_C_CLR ).

Los siguientes valores de bandera pueden pasarse a través del parámetro flags:

ELF_F_DIRTY
Marca el objeto como modificado. Esto asegura que los cambios en el componente se escriban durante elf_update(3).
ELF_F_LAYOUT
Indica que el diseño del componente ELF se gestiona manualmente. Los desplazamientos y tamaños se conservarán como se proporcionaron. Esta bandera solo se usa con elf_flagelf() y se ignora cuando se usa con otras funciones. Si esta bandera está establecida, el usuario debe establecer el desplazamiento de cabecera de programa e_phoff, e_shoff, así como el desplazamiento d_off de Elf_Data y el desplazamiento sh_offset de Shdr. Si no está establecido, estos desplazamientos se recalcularán cuando se llame a elf_update. Si se establece ELF_F_LAYOUT, los cambios en los desplazamientos de phdr impedirán que elf_update ajuste automáticamente los desplazamientos de shdr.
ELF_F_PERMISSIVE
Habilita la validación laxa de la estructura del objeto. Esta bandera permite diseños no estándar sin comprobaciones estrictas. Específicamente, elimina una comprobación en elf_update() de que el tamaño de sección sh_size es un múltiplo del tamaño de entrada de sección sh_entsize (si no es cero). Esta bandera solo se usa con elf_flagelf() y se ignora cuando se usa con otras funciones. ELF_F_PERMISSIVE es una extensión de libelf de elfutils y puede no estar disponible en otras implementaciones de libelf.

PARÁMETROS

obj
El objeto a modificar: Para elf_flagelf, elf_flagehdr, elf_flagphdr, este es un descriptor Elf *. Para elf_flagscn y elf_flagshdr, este es un descriptor Elf_Scn *. Para elf_flagdata, un buffer Elf_Data *.
cmd
Debe ser uno de los siguientes: ELF_C_SET para establecer las banderas dadas, o ELF_C_CLR para borrarlas.
flags
Máscara de bits de banderas a modificar. Puede incluir cualquier combinación de ELF_F_DIRTY, ELF_F_LAYOUT y ELF_F_PERMISSIVE.

Tenga en cuenta que ELF_F_LAYOUT y ELF_F_PERMISSIVE solo se usan con elf_flagelf() y se ignoran para otras funciones.

VALOR DE RETORNO

Devuelve el nuevo valor de las banderas después de la operación de establecimiento/borrado.

Devuelve 0 en caso de error, y establece un código de error que se puede recuperar mediante elf_errmsg(3). Si el primer argumento es NULL entonces se devuelve 0 y no se establece ningún código de error.

Si se borra la última bandera, se devolverá 0 como nuevo valor de la bandera. En este caso, 0 no es un indicador de error y no se establece ningún código de error.
