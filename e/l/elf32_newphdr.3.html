ELF32_NEWPHDR(3) Manual del programador de Libelf ELF32_NEWPHDR(3)

NOMBRE

elf32_newphdr, elf64_newphdr - crear una nueva tabla de cabeceras de programa para un archivo objeto ELF de 32 bits o 64 bits

SINOPSIS

#include <libelf.h>
Elf32_Phdr *elf32_newphdr(Elf *elf, size_t count);
Elf64_Phdr *elf64_newphdr(Elf *elf, size_t count);

DESCRIPCIÓN

Crea una nueva tabla de cabeceras de programa para el archivo objeto ELF al que se refiere elf. El número de entradas en la nueva tabla de cabeceras de programa se especifica mediante count. Un valor de count de cero elimina la tabla de cabeceras de programa existente.

La función asigna un nuevo array de Elf32_Phdr y lo convierte en la tabla de cabeceras de programa para elf. El contenido de la nueva cabecera del programa se establece a cero y cualquier tabla de cabeceras de programa anterior se descarta. Debe existir una cabecera ELF antes de crear una tabla de cabeceras de programa.

PARÁMETROS

elf
Puntero al objeto ELF para el cual se va a crear una nueva tabla de cabeceras de programa.
count
El número de entradas en la nueva tabla de cabeceras de programa. Un recuento de cero elimina la tabla de cabeceras de programa existente.

VALOR DE RETORNO

En caso de éxito, devuelve un puntero a la primera Elf32_Phdr de la tabla de cabeceras de programa recién creada. Si elf es NULL, devuelve NULL. Si ocurre un error, devuelve NULL y establece un código de error de libelf.

VER TAMBIÉN
