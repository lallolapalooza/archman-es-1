ELF_NEWSCN(3) Manual del programador de Libelf ELF_NEWSCN(3)

NOMBRE

elf_newscn - crea una nueva sección para un descriptor ELF

SINOPSIS

#include <libelf.h>
Elf_Scn *elf_newscn(Elf * elf");"

DESCRIPCIÓN

La función elf_newscn() crea un nuevo descriptor de sección para el descriptor ELF elf.

Cada llamada a elf_newscn() añade una nueva sección a la lista interna de secciones del descriptor ELF. También crea una cabecera de sección vacía correspondiente, que se inicializa a cero y se marca como modificada. Si elf no tiene aún secciones, elf_newscn() creará también la sección nula con sh_type SHT_NULL en el índice de sección 0.

Una sección recién creada no tiene nombre ni tipo y debe inicializarse correctamente antes de llamar a elf_update(). Use elf32_getshdr() o elf64_getshdr() para obtener la estructura de cabecera de sección, luego rellene los campos requeridos. Use elf_newdata() para asociar uno o más buffers de datos con la nueva sección.

La sección con índice 0 (la sección nula) está reservada y no puede tener datos añadidos. elf_newscn() nunca devolverá esta sección.

PARÁMETROS

elf
Un descriptor ELF que debe tener al menos un Elf32_Ehdr o Elf64_Ehdr asociado.

VALOR DE RETORNO

En caso de éxito, elf_newscn() devuelve un puntero a un nuevo descriptor de sección. En caso de fallo, devuelve NULL y establece elf_errno. Si elf es NULL, entonces se devuelve NULL sin establecer elf_errno.

VER TAMBIÉN

elf32_getshdr(3), elf64_getshdr(3), elf_getdata(3), elf_newdata(3), elf_update(3), libelf(3), elf(5)
