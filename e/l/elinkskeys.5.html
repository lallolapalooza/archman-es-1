NOMBRE

elinkskeys - atajos de teclado para ELinks

SINOPIS

Información sobre cómo configurar los atajos de teclado y resumen de los atajos de teclado predeterminados.

DESCRIPCIÓN

Las combinaciones de teclas para elinks deben colocarse en el archivo ~/.config/elinks/elinks.conf. Tenga en cuenta que cualquier información relacionada con su formato/estructura puede no estar actualizada. Si descubre que es así, por favor, envíenos un parche.

Las sentencias de combinación de teclas tienen la forma:

bind <mapa_teclas> <secuencia_teclas> = <accion>

donde:

<mapa_teclas>

es main, edit, o menu. El mapa de teclas principal se usa para la navegación general. El mapa de teclas de edición se usa para editar campos de texto. El mapa de teclas de menú se usa para navegar por los menús.

<secuencia_teclas>

es una tecla sensible a mayúsculas/minúsculas, que puede prefijar con Ctrl-, Alt-, o ambos. Ctrl- debe ir seguido de una tecla mayúscula. Consulte a continuación una lista de teclas válidas.

<accion>

es lo que la tecla debe hacer. Las acciones disponibles dependen del mapa de teclas y se enumeran por separado a continuación.

Todas las palabras/cadenas pueden ir entre comillas "como esta". Las barras invertidas son caracteres de escape, incluso si no están entre comillas. Las líneas que comienzan con un carácter de almohadilla (#) son comentarios.

Las combinaciones de teclas pueden ser desvinculadas simplemente vinculándolas a la acción especial none. Esto puede ser útil si accidentalmente pulsa una tecla con frecuencia.

EJEMPLOS DE COMBINACIONES

Algunas combinaciones de teclas de ejemplo:

bind "main" "v" = "view-image"
bind "main" "l" = "jump-to-link"
bind "main" "L" = "link-menu"
bind "main" "F10" = "file-menu"
bind "main" "F9" = "menu"
bind "main" "Escape" = "menu"
bind "edit" "Ctrl-R" = "auto-complete-unambiguous"
bind "edit" "Ctrl-W" = "auto-complete"
bind "edit" "Ctrl-K" = "kill-to-eol"
bind "menu" "Ctrl-B" = "page-up"
bind "menu" "PageUp" = "page-up"
bind "menu" "Ctrl-F" = "page-down"
bind "menu" "PageDown" = "page-down"
# ELinks con soporte Lua
bind "main" "," = "lua-console"

TECLAS

Las teclas válidas son: caracteres alfanuméricos, signos de puntuación, Enter, Backspace, Tab, Escape, Left, Right, Up, Down, Insert, Delete, Home, End, PageUp, PageDown, F1 a F12.

Algunas teclas necesitarán ser puestas entre comillas o escapadas. Por ejemplo, el espacio se puede escribir como " " (comilla espacio comilla), y la comilla misma como \" (barra invertida comilla). La barra invertida se puede escribir como \\ (doble barra invertida).
