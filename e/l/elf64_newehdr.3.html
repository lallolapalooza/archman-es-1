NOMBRE

elf32_newehdr, elf64_newehdr - crear una nueva cabecera ELF para un archivo objeto ELF de 32 o 64 bits

SINOPSIS

#include <libelf.h>
Elf32_Ehdr *elf32_newehdr(Elf *elf);
Elf64_Ehdr *elf64_newehdr(Elf *elf);

DESCRIPCIÓN

Esta función inicializa una nueva cabecera ELF y la asocia con elf. Si elf ya tiene una cabecera ELF asociada, no se creará ninguna cabecera nueva y se devolverá la cabecera existente. Debe haber una cabecera ELF presente antes de llamar a elf_newscn o elf_newphdr.

PARÁMETROS

elf
Descriptor ELF para el cual se va a crear una nueva cabecera ELF.

VALOR DE RETORNO

En caso de éxito, devuelve un puntero a la cabecera ELF recién creada. Si elf ya tiene una cabecera ELF asociada, se devuelve esta cabecera preexistente y no se crea ninguna cabecera nueva. En caso de error, devuelve NULL y establece un código de error de libelf.

VER TAMBIÉN

elf_errno(3), libelf(3), elf(5)
