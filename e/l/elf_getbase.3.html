NOMBRE

elf_getbase - Recuperar el desplazamiento base para un archivo objeto ELF.

SINOPSIS

#include <libelf.h>

int64_t elf_getbase(Elf *elf);

DESCRIPCIÓN

elf_getbase devuelve el desplazamiento de archivo del primer byte del descriptor ELF elf. Si elf es un miembro de un archivo y tiene el tipo ELF ELF_K_AR, el desplazamiento base es el desplazamiento del objeto ELF dentro del archivo. Para otros tipos de objetos ELF, el desplazamiento base es 0.

PARÁMETROS

elf
El descriptor ELF.

VALOR DEVUELTO

Devuelve el desplazamiento base de elf si su tipo ELF es ELF_K_AR, de lo contrario, devuelve 0. Si elf es NULL, devuelve -1.

VER TAMBIÉN
