ELF_ERRNO(3) Manual del programador de Libelf ELF_ERRNO(3)

NOMBRE

elf_errno - recupera el código de error de la última llamada fallida a una función de libelf.

SINOPSIS

#include <libelf.h>

int elf_errno(void);

DESCRIPCIÓN

La función elf_errno recupera el código de error de la última función de la biblioteca libelf que falló. Este código de error indica el tipo de error que ocurrió durante la llamada a la función fallida. Cada hilo mantiene su propio código de error separado.

PARÁMETROS

Esta función no toma ningún parámetro.

VALOR DE RETORNO

La función elf_errno devuelve un entero que representa el código de error más reciente para el hilo actual. Si no ha ocurrido ningún error, devuelve 0. Si ocurrió un error, la función devuelve un código de error distinto de cero que corresponde al error específico. Los códigos de error se pueden pasar a elf_errmsg para crear una cadena que describa el error.

VER TAMBIÉN

elf_errmsg(3)

REPORTAR ERRORES

Reporte errores a <elfutils-devel@sourceware.org> o https://sourceware.org/bugzilla/.
