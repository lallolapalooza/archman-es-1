PROGRAMA
La salida del programa, para cada archivo ELF dado en la línea de
comandos, es la siguiente:
nomb
re de
l arc

La primera línea de la salida muestra el nombre del archivo y la arquitectura para la que fue creado. El nombre del archivo irá seguido de un asterisco
*
si el archivo es un ejecutable binario, de un ampersand
&
si el archivo es una biblioteca compartida, o de un signo de

dólar

$ si el archivo es un archivo core. De lo contrario, el archivo es un archivo objeto. (Esta es la única línea que se garantiza que se mostrará. La otra información no se muestra si los datos no son aplicables, no están presentes en el archivo o se suprimen mediante las opciones de la línea de comandos.) Después del nombre del archivo se muestra la lista de las bibliotecas de objetos compartidos con las que el archivo está enlazado dinámicamente, si las hay. A continuación se muestra la lista de los archivos fuente que se usaron para construir el archivo, suponiendo que esta información esté

disponible.

A continuación aparece la lista de las entradas de la tabla de cabeceras de programa. Véase más abajo para una descripción detallada de la salida. Los ejecutables binarios y las bibliotecas compartidas siempre contienen una tabla de cabeceras de

programa.

Finalmente, se muestran las entradas de la tabla de cabeceras de sección. Véase más abajo para una descripción detallada de la salida. Los archivos ELF casi siempre contienen una tabla de cabeceras de sección, aunque solo son requeridos para los archivos

objeto.

El nombre de esta sección. Si la sección es una lista de entradas de reubicaciónes, entonces el nombre se sufijará con dos puntos y un número, el número indicando el índice de la sección a la que se aplica la información de reubicación. Además, varios tipos de sección contienen información que se refiere a cadenas y/o símbolos, que están contenidos en una sección de tabla de cadenas y/o una sección de tabla hash de símbolos. Dichas secciones tendrán un número entre corchetes después del nombre, indicando el índice de esta sección. Una S entre corchetes que aparezca después del nombre de una sección de tabla de cadenas indica la tabla de cadenas que contiene los nombres de las secciones.

Tenga en cuenta que, a menos que se especifique --nostr, las entradas del intérprete, comentario y nota en la tabla de cabeceras del programa se muestran simplemente como una cadena que indica su contenido.
