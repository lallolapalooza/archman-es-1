ELF_MEMORY(3) Manual del programador de Libelf ELF_MEMORY(3)

NOMBRE

elf_memory - crea un descriptor ELF a partir de un búfer de memoria

SINOPSIS

#include <libelf.h>
Elf * elf_memory(char *" image , size_t size );

DESCRIPCIÓN

La función elf_memory() crea un nuevo descriptor ELF a partir de una región de memoria que contiene un objeto ELF. Esta función se utiliza cuando los datos ELF ya están presentes en la memoria en lugar de leerse desde un descriptor de archivo.

La memoria apuntada por image debe contener un archivo o archivo ELF completo. El contenido debe permanecer válido y sin modificar durante la vida útil del descriptor ELF resultante.

El descriptor ELF devuelto por elf_memory() se abre en modo de solo lectura utilizando ELF_C_READ_MMAP_PRIVATE (consulte elf_begin). La imagen de memoria subyacente no debe ser modificada directamente por la aplicación mientras su descriptor ELF esté abierto. Algunas funciones de libelf, como elf_compress() y gelf_update_*(), pueden modificar internamente la imagen subyacente y, por lo tanto, requieren que la imagen subyacente sea escribible. El uso de una imagen de solo lectura (por ejemplo, mapeada en memoria solo con PROT_READ) puede provocar fallos o bloqueos.

PARÁMETROS

image
Un puntero a un búfer de memoria que contiene el contenido completo de un archivo o archivo ELF. Si es NULL, esta función falla y devuelve NULL.
size
El tamaño en bytes de la región de memoria apuntada por image. Debe ser al menos tan grande como una cabecera ELF completa y debe cubrir todo el objeto ELF.

VALOR DE RETORNO

En caso de éxito, elf_memory() devuelve un puntero a un descriptor Elf que representa el archivo o archivo ELF contenido en image.

En caso de fallo, devuelve NULL y establece un código de error que se puede recuperar con elf_errmsg(3).
