ELF_VERSION(3) Manual del programador de Libelf ELF_VERSION(3)

NOMBRE

elf_version - establece la versión ELF para libelf.

SINOPSIS

#include <libelf.h>

unsigned int elf_version(unsigned int version);

DESCRIPCIÓN

La función elf_version establece la versión ELF de libelf al valor especificado. Esta función debe llamarse antes de que se utilicen otras funciones de libelf.

PARÁMETROS

version
Un valor de tipo unsigned int que especifica la versión ELF deseada para la biblioteca. Debe establecerse en EV_CURRENT para indicar la versión ELF actual. En este momento, la única versión ELF compatible es EV_CURRENT.

VALOR DE RETORNO

La función elf_version devuelve EV_CURRENT si version es compatible y establece la versión ELF de la biblioteca a este valor. Si la versión dada es EV_NONE, entonces esta función devuelve EV_CURRENT y no establece la versión ELF de la biblioteca. Si la versión especificada no es compatible, esta función devuelve EV_NONE.

REPORTE DE ERRORES

Reporte errores a <elfutils-devel@sourceware.org> o https://sourceware.org/bugzilla/.
