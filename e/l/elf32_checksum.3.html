ELF32_CHECKSUM(3) Manual del Programador de Libelf ELF32_CHECKSUM(3)

NOMBRE

elf32_checksum, elf64_checksum - calcular la suma de verificación para un archivo objeto ELF de 32 o 64 bits

SINOPSIS

#include <libelf.h>
long int elf32_checksum(Elf *elf);
long int elf64_checksum(Elf *elf);

DESCRIPCIÓN

Calcula una suma de verificación para el archivo objeto ELF al que se refiere elf. La suma de verificación se calcula a partir de partes permanentes del archivo ELF y el resultado es repetible. Para ser repetible, las secciones que se pueden eliminar (strippable) no se incluyen en el cálculo de la suma de verificación. Las secciones SHT_NOBITS tampoco se incluyen al calcular la suma de verificación. La suma de verificación se puede utilizar como valor para DT_CHECKSUM.

PARÁMETROS

elf
El archivo objeto ELF para el cual se va a calcular la suma de verificación.

VALOR DE RETORNO

En caso de éxito, devuelve la suma de verificación calculada. Si ocurre un error, devuelve -1 y establece un código de error de libelf. La suma de verificación siempre se calcula como un valor de 4 bytes. Si long int es mayor que 4 bytes, la suma de verificación se extenderá rellenando con ceros.

VER TAMBIÉN

elf_errno(3), libelf(3), elf(5)

ATRIBUTOS
