ELINKS.CONF(5) Archivo de configuración de ELinks ELINKS.CONF(5)

NOMBRE

elinks.conf - Archivo de configuración de ELinks

SINOPSIS

set        <opción> = <valor>
set_domain <dominio> <opción> = <valor>
unset      <opción>
bind       "<mapa_teclas>" "<tecla>" = "<acción>"
include    "<archivo>"

DESCRIPCIÓN

El archivo elinks.conf contiene información de configuración para ELinks. Puede ser utilizado para configurar el comportamiento de ELinks de una amplia variedad de maneras: comportamiento de protocolos, atajos de teclado, colores usados para la representación y para la interfaz de usuario.

Se lee al inicio y solo se guarda cuando se solicita. Todas las opciones descritas en este documento pueden ser configuradas desde dentro de ELinks. La edición de elinks.conf solo es necesaria si desea anular los valores de algunas opciones en dominios individuales (set_domain).

Tenga en cuenta que las opciones relacionadas con MIME utilizadas para especificar manejadores de varios tipos MIME no se describen completamente en este documento. La documentación para estas opciones se puede encontrar en el capítulo MIME del manual de ELinks. Los atajos de teclado también se pueden especificar en elinks.conf. Esto se describe en elinkskeys(5).

SINTAXIS

La sintaxis del archivo de configuración es muy simple. El archivo elinks.conf es un archivo de texto ASCII de formato libre. El archivo puede contener tabulaciones y saltos de línea adicionales para propósitos de formato. Las palabras clave en el archivo distinguen entre mayúsculas y minúsculas. Los comentarios se pueden colocar en cualquier lugar dentro del archivo (excepto dentro de comillas). Los comentarios comienzan con el carácter # y terminan al final de la línea.

EJEMPLOS

Algunos ajustes de ejemplo:

# ¿Usar resolvedor DNS asíncrono?
set connection.async_dns = 1
# Margen horizontal de texto.
set document.browse.margin_width = 3
# Página de códigos de documento predeterminada.
set document.codepage.assume = "ISO-8859-1"
# Manejadores de protocolos definidos por el usuario
set protocol.user.mailto.unix = "mutt %h -s \"%s\""

marcadores (Bookmarks)

Opciones de marcadores.

bookmarks.file_format <num> (predeterminado: 0)

Formato de archivo para marcadores (afecta tanto la lectura como el guardado):
•0 es el formato nativo predeterminado de ELinks
•1 es el formato universal de marcadores XML XBEL

bookmarks.folder_state [0|1] (predeterminado: 1)

Al guardar marcadores, también se almacena si las carpetas están expandidas o no, para que la apariencia del diálogo de marcadores se mantenga entre sesiones de ELinks. Si está deshabilitado, todas las carpetas aparecerán sin expandir la próxima vez que se ejecute ELinks.

config (Sistema de configuración)

Opciones de manejo de configuración.

config.comments <num> (predeterminado: 3)

Cantidad de comentarios escritos automáticamente en el archivo de configuración:
•0 no se escriben comentarios
•1 solo se escribe la "descripción breve" (nombre+tipo)
•2 solo se escribe la descripción
•3 se escriben comentarios completos

config.indentation <num> (predeterminado: 2)

Ancho de desplazamiento de un nivel de indentación en el archivo de configuración. Cero significa que no se realiza ninguna indentación al guardar la configuración.

config.saving_style <num> (predeterminado: 3)

Determina qué sucede cuando le indica a ELinks que guarde opciones:
•0 solo se alteran los valores de las opciones actuales
•1 se alteran los valores de las opciones actuales y se agregan las opciones faltantes al final del archivo
•2 el archivo de configuración se reescribe desde cero
•3 se alteran los valores de las opciones actuales y se agregan al final del archivo las opciones faltantes CAMBIADAS durante esta sesión de ELinks

config.i18n [0|1] (predeterminado: 0)

Si se establece en 1, los comentarios en el archivo de configuración se traducirán al idioma utilizado por la UI. Tenga en cuenta que si tiene un idioma diferente configurado en diferentes terminales, el idioma utilizado en el archivo de configuración PUEDE ser el mismo que en la terminal donde guardó el archivo, pero en general se debe considerar impredecible.

config.saving_style_w [0|1] (predeterminado: 0)

Esta es una opción interna utilizada al mostrar una advertencia sobre config.saving_style obsoleto. No debería tocarla.

config.show_template [0|1] (predeterminado: 0)

Mostrar opciones de plantilla en árboles autocreados en el administrador de opciones y guardarlas en el archivo de configuración.

document.cache.cache_redirects [0|1] (predeterminado:

0)
Cachear incluso las redirecciones enviadas por el servidor (usualmente a través de HTTP con un código HTTP 302 y una cabecera Location). Este era el comportamiento original durante bastante tiempo, pero causa problemas en una situación muy común en varios sistemas de inicio de sesión web – frecuentemente, al acceder a una ubicación determinada, te redirigirán a una página de inicio de sesión si no reciben una cookie de autenticación, la página de inicio de sesión te da la cookie y te redirige de vuelta a la página original, ¡pero allí ya has cacheado la redirección de vuelta a la página de inicio de sesión! Si esta opción tiene el valor 0, este mal funcionamiento se corrige, pero ocasionalmente podrías obtener peticiones superfluas (depende de cómo lo veas ;-) al servidor. Si esta opción tiene el valor 1, los usuarios experimentados aún pueden sortearlo mediante una combinión inteligente del uso de recargar, saltar por el historial de sesión y presionar ctrl+enter.

Ten en cuenta que esta opción se comprueba al recuperar la información de la c

aché, no al guardarla en la caché – así que si la habilitas, incluso las redi
recciones anteriores se tomarán de la caché en lugar de preguntar al servidor.

Las opciones de color controlan los colores de la interfaz de usuario.

Cada opción de color se define como un par de colores: un color de primer plano (primer plano) y un color de fondo (fondo). Los colores se especifican como un valor hexadecimal de 24 bits en el formato #rrggbb, donde r, g y b son dígitos hexadecimales para los componentes rojo, verde y azul del color, respectivamente.

Las opciones de color se agrupan en temas. El tema predeterminado es el tema monocromático.
