NOMBRE

elf_hash, elf_gnu_hash - Calcula el hash ELF estándar o el hash GNU de una cadena.

SINOPSIS

#include <libelf.h>
unsigned long int elf_hash(const char *cadena);
unsigned long int elf_gnu_hash(const char *cadena);

DESCRIPCIÓN

La función elf_hash calcula el valor de hash ELF estándar para una cadena terminada en nulo. Los valores de hash se utilizan típicamente en archivos objeto ELF para el hashing de tablas de símbolos. La función de hash se utiliza en secciones SHT_HASH, ya que evita la generación de valores dependientes de la arquitectura y es adecuada para su uso en diferentes arquitecturas.

La función elf_gnu_hash calcula el valor de hash estilo GNU de una cadena terminada en nulo, utilizado en la sección SHT_GNU_HASH.

PARÁMETROS

cadena
Cadena terminada en nulo que se va a hashear.

VALOR DE RETORNO

Estas funciones devuelven un valor hash para cadena. Solo se utilizan los 32 bits inferiores del valor de retorno.

VER TAMBIÉN

libelf(3), elf(5)
