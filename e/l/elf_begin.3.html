ELF_BEGIN(3) Manual del programador de Libelf ELF_BEGIN(3)

NOMBRE

elf_begin - inicializa un descriptor ELF

SINOPSIS

#include <libelf.h>
Elf *elf_begin(int fildes, Elf_Cmd cmd, Elf *ref);

DESCRIPCIÓN

Inicializa y devuelve un manejador para un archivo ELF para su uso con la biblioteca libelf de elfutils y bibliotecas relacionadas de elfutils como libdw.

El descriptor Elf devuelto debe liberarse usando elf_end(3).

elf_version(3) debe llamarse antes de usar cualquier biblioteca de libelf, incluida elf_begin(3).

PARÁMETROS

fildes
Un descriptor de archivo que se refiere a un objeto ELF. El descriptor debe estar abierto para lectura y, opcionalmente, para escritura, dependiendo de la operación prevista. Si ref no es NULL, entonces fildes debe ser -1 o establecerse al mismo descriptor de archivo que el asociado a ref.
cmd
Especifica la acción a realizar. Los valores comunes incluyen:
ELF_C_NULL
Devuelve un puntero NULL en lugar de inicializar un descriptor ELF. Ignora ref.
ELF_C_READ
Abre un descriptor ELF para lectura.
ELF_C_WRITE
Abre un descriptor ELF para escritura. El descriptor se refiere inicialmente a un archivo vacío.
ELF_C_RDWR
Abre un descriptor ELF para lectura y escritura.
ELF_C_READ_MMAP
Abre un descriptor ELF para lectura usando mmap, si está disponible. Los comandos ELF_C_*_MMAP son una extensión de libelf de elfutils y pueden no estar disponibles en otras implementaciones de libelf. Una vez que se establece el tamaño de mmap, los intentos de extender el tamaño pueden fallar. Por lo tanto, los comandos ELF_C_*_MMAP tienden a ser más útiles para modificaciones in situ o eliminación de datos de un descriptor ELF.
ELF_C_WRITE_MMAP
Abre un descriptor ELF para escritura usando mmap, si está disponible. El descriptor se refiere inicialmente a un archivo vacío.
ELF_C_RDWR_MMAP
Abre un descriptor ELF para lectura y escritura usando mmap, si está disponible.
ELF_C_READ_MMAP_PRIVATE
Abre un descriptor ELF para lectura usando mmap, si está disponible. Este comando invoca mmap con MAP_PRIVATE mientras que los otros comandos ELF_C_*_MMAP invocan mmap con MAP_SHARED. Consulte mmap(2) para más información.
ref
Una referencia a un descriptor Elf existente. Si ref se refiere a un binario ELF regular (no a un archivo AR), entonces elf_begin duplicará ref. El contador de referencias asociado a ref se incrementará y se deberá llamar a elf_end(3) una vez más para desasignar ref. ref debe haber sido abierto con permisos de lectura/escritura consistentes con cmd.

Si ref se refiere a un archivo AR, entonces el descriptor ELF devuelto será el primer miembro del objeto disponible en el archivo (consulte elf_next(3) para más información).

ref puede ser NULL, en cuyo caso este argumento se ignora.

VALOR DE RETORNO

En caso de éxito, elf_begin() devuelve un puntero a un nuevo descriptor Elf. Si cmd es ELF_C_NULL, se devuelve NULL. Si ref no es NULL y no es un archivo AR, se devuelve una copia de ref. En caso de error, elf_begin() devuelve NULL y establece un estado de error interno que puede recuperarse con elf_errmsg(3).

VER TAMBIÉN
