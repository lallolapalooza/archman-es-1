ELF_ERRMSG(3) Manual del programador de Libelf ELF_ERRMSG(3)

NOMBRE

elf_errmsg - devuelve la cadena del mensaje de error para un código de error dado de libelf.

SINOPSIS

#include <libelf.h>

const char *elf_errmsg(int err);

DESCRIPCIÓN

La función elf_errmsg recupera una cadena legible por humanos correspondiente al código de error más reciente establecido por una función de la biblioteca libelf. Si err es 0, la función devuelve el mensaje de error para el código de error más reciente. Si err no es cero, la función devuelve el mensaje de error para el código de error especificado.

PARÁMETROS

err
Un valor int que especifica el código de error. Si este valor es 0, la función devuelve el mensaje de error para el error más reciente o NULL si no ocurrió ninguno. Si este valor es -1, el comportamiento es similar al caso anterior excepto que se devolverá una cadena válida en lugar de NULL.

VALOR DE RETORNO

La función elf_errmsg devuelve una cadena que contiene el mensaje de error. Si no hay un mensaje de error correspondiente, devuelve NULL.

VER TAMBIÉN

elf_errno(3)

REPORTAR ERRORES
