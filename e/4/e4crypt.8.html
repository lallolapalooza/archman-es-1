E4CRYPT(8) Manual del Administrador del Sistema E4CRYPT(8)

NOMBRE

e4crypt - utilidad de cifrado de sistemas de archivos ext4

SINOPSIS

e4crypt add_key -S [ -k keyring ] [-v] [-q] [ -p pad ] [ ruta ... ]
e4crypt new_session
e4crypt get_policy ruta ...
e4crypt set_policy [ -p pad ] política ruta ...

DESCRIPCIÓN

e4crypt realiza la gestión del cifrado para sistemas de archivos ext4.

COMANDOS

e4crypt add_key [-vq] [-S sal ] [-k keyring ] [ -p relleno ] [ ruta ... ]
Solicita al usuario una frase de contraseña y la inserta en el keyring especificado. Si no se especifica ningún keyring, e4crypt utilizará el keyring de la sesión si existe o el keyring de la sesión del usuario si no existe.
El argumento sal se interpreta de varias maneras, dependiendo de su prefijo. Si los dos primeros caracteres son "s:", el resto del argumento se utilizará como una cadena de texto y servirá como valor de sal. Si los dos primeros caracteres son "0x", el resto del argumento se interpretará como una cadena hexadecimal y se utilizará como sal. Si los primeros caracteres son "f:", el resto del argumento se interpretará como un nombre de archivo del que se leerá el valor de sal. Si la cadena comienza con un carácter '/', se tratará de forma similar como un nombre de archivo. Finalmente, si el argumento sal puede interpretarse como un UUID válido, se utilizará el valor del UUID como valor de sal.
El argumento keyring especifica el keyring al que se debe añadir la clave.
El valor relleno especifica el número de bytes de relleno que se añadirán a los nombres de los directorios con fines de ofuscación. Los valores válidos de relleno son 4, 8, 16 y 32.
Si se especifican una o más rutas de directorio, e4crypt intentará establecer la política de esos directorios para usar la clave recién añadida por el comando add_key. Si se especificó explícitamente una sal, se utilizará para derivar la clave de cifrado de esos directorios. De lo contrario, se utilizará una sal predeterminada específica del directorio.
e4crypt get_policy ruta ...
Imprime la política para los directorios especificados en la línea de comandos.
e4crypt new_session
Proporciona al proceso invocador (normalmente un shell) un nuevo keyring de sesión, descartando su antiguo keyring de sesión.
e4crypt set_policy [ -p relleno ] política ruta ...
Establece la política para los directorios especificados en la línea de comandos. Todos los directorios deben estar vacíos para establecer la política; si el directorio ya tiene una política establecida, e4crypt validará que la política coincide con lo especificado. Una política es un identificador de clave de cifrado que consta de 16 caracteres hexadecimales.
