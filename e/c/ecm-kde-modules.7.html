KDEFrameworkCompilerSetting

s

Establece banderas de compilación y enlace más estrictas para los módulos de KDE

Frameworks.

Advertencia

:
No use este módulo para software que no sea parte de
KDE-Frameworks. No hay garantía de compatibilidad c
on versiones anteriores en versiones más recientes.

Se incluye el módulo KDECompilerSettings <#kde-module:KDECompilerSettings> y, además, se establecen varias definiciones que afectan a las bibliotecas de Qt para hacer cumplir ciertas

convenciones.

Por ejemplo, construcciones como QString("foo") están prohibidas, forzando en su lugar el uso de QLatin1String o QStringLiteral, y algunas palabras clave definidas por Qt como signals y slots no estarán

definidas.

Nota

:
Se recomienda incluir este módulo con la bandera
NO_POLICY_SCOPE, de lo contrario puede obtener adve
rtencias espurias con algunas versiones de CMake.

Además, para cada variable KDE_INSTALL_*, se define una variable CMAKE_INSTALL_* equivalente. Si KDE_INSTALL_DIRS_NO_CMAKE_VARIABLES se establece en TRUE, este módulo no definirá ninguna variable con el prefijo CMAKE_ (aparte de CMAKE_INSTALL_DEFAULT_COMPONENT_NAME - ver abajo)

Las variables KDE_INSTALL_<dir> (o sus equivalentes CMAKE_INSTALL_<dir> u obsoletas) pueden pasarse a las opciones DESTINATION de los comandos install() para el tipo de archivo correspondiente. Se establecen en la caché de CMake, y por lo tanto los valores predeterminados anteriores pueden ser sobrescritos por los

usuarios.

Tenga en cuenta que si la forma KDE_INSTALL_<dir>, CMAKE_INSTALL_<dir> u obsoleta de la variable se establece antes de include(KDEInstallDirs), no serán sobrescritas por KDEInstallDirs. Esto es útil si, por ejemplo, desea usar definiciones de variables de la línea de comandos de CMake para establecer valores personalizados. Sin embargo, hay algunas otras implicaciones de las que debe ser consciente: GNUInstallDirs define variables CMAKE_INSTALL_<dir>, por lo tanto KDEInstallDirs no las sobrescribirá si se incluye más tarde. En la mayoría de los casos esto no es intencionado y si necesita incluir GNUInstallDirs, siempre debe hacerlo después de haber incluido KDEInstallDirs

.

Si establece valores personalizados en KDE_INSTALL_<dir> o CMAKE_INSTALL_<dir> como se describe arriba, siempre ambas formas de la variable se verán afectadas. evitarse.
