BÚSQUEDA

Una buena plantilla para la documentación de un módulo de búsqueda es: #[=======================================================================[.rst: FindFoo ------- Encuentra la biblioteca Foo. Esto definirá las siguientes variables: ``Foo_FOUND`` Verdadero si (la versión solicitada de) Foo está disponible ``Foo_VERSION`` La versión de Foo, si se encuentra ``Foo_LIBRARIES`` Esto puede pasarse a target_link_libraries() en lugar del objetivo ``Foo::Foo`` ``Foo_INCLUDE_DIRS`` Esto debería pasarse a target_include_directories() si el objetivo no se usa para enlazar ``Foo_DEFINITIONS`` Esto debería pasarse a target_compile_options() si el objetivo no se usa para enlazar Si ``Foo_FOUND`` es VERDADERO, también definirá el siguiente objetivo importado: ``Foo::Foo`` La biblioteca Foo En general recomendamos usar el objetivo importado, ya que es más fácil de usar. Ten en cuenta, sin embargo, que si el objetivo está en la interfaz de enlace de una biblioteca exportada, debe ser proporcionado por el archivo de configuración del paquete. #]====================================================================

ENVÍO DE MÓDULOS

Los nuevos módulos propuestos deben enviarse utilizando la instancia de KDE Review Board https://git.reviewboard.kde.org/, y asignarse a los grupos buildsystem y extracmakemodules. Deberías poder señalar dos proyectos separados que harán uso del módulo.

La lista de correo se puede encontrar en https://mail.kde.org/mailman/listinfo/kde-buildsystem.
