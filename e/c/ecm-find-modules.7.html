FindPoppler

Este es un módulo de búsqueda basado en componentes, que utiliza los argumentos COMPONENTS y OPTIONAL_COMPONENTS para find_module. Los siguientes componentes están disponibles:

Core  Cpp  Qt5  Qt4  Glib

Si no se especifican componentes, este módulo actuará como si todos los componentes se hubieran pasado a OPTIONAL_COMPONENTS.

Este módulo definirá las siguientes variables, independientemente de los componentes buscados o encontrados:

Poppler_FOUND
VERDADERO si (la versión solicitada de) Poppler está disponible
Poppler_VERSION
Versión de Poppler encontrada
Poppler_TARGETS
Una lista de todos los destinos importados por este módulo (tenga en cuenta que puede haber más que los componentes solicitados)
Poppler_LIBRARIES
Esto se puede pasar a target_link_libraries() en lugar de los destinos importados
Poppler_INCLUDE_DIRS
Esto debe pasarse a target_include_directories() si los destinos no se utilizan para enlazar
Poppler_DEFINITIONS
Esto debe pasarse a target_compile_options() si los destinos no se utilizan para enlazar

En general, recomendamos usar los destinos importados, ya que son más fáciles de usar y ofrecen más control. Tenga en cuenta, sin embargo, que si algún destino está en la interfaz de enlace de una biblioteca exportada, debe estar disponible a través del archivo de configuración del paquete.

NAME

ecm-find-modules - ECM modules for finding external libraries

INTRODUCTION

This document describes the find modules provided by ECM (Extra CMake Modules). These modules are intended to help CMake find external libraries and tools required by KDE/Qt related projects.

ALL FIND MODULES

FindEpoxy

Try to find the Epoxy library.

This module defines:

epoxy_FOUND
TRUE if epoxy is available
epoxy_INCLUDE_DIRS
The include directories for epoxy
epoxy_LIBRARIES
The epoxy libraries to link against
epoxy_DEFINITIONS
Compiler definitions for epoxy
epoxy_VERSION
The version of epoxy found
epoxy_HAS_GLX
TRUE if GLX support is available

If epoxy_FOUND is TRUE, it will also define the following imported target:

epoxy::epoxy
The epoxy library

In general we recommend using the imported target, as it is easier to use. Bear in mind, however, that if the target is in the link interface of an exported library, it must be made available by the package config file.

Findgzip

Try to find gzip.

If the gzip executable is not in your PATH, you can provide an alternative name or full path location with the gzip_EXECUTABLE variable.

This will define the following variables:

gzip_FOUND
TRUE if gzip is available
gzip_EXECUTABLE
Path to gzip executable

If gzip_FOUND is TRUE, it will also define the following imported target:

gzip::gzip
Path to gzip executable

Since 5.85.0.
