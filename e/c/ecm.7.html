ECM(7) Módulos Extra de CMake ECM(7)

NOMBRE

ecm - Módulos Extra de CMake

INTRODUCCIÓN

El paquete Extra CMake Modules, o ECM, se añade a los módulos proporcionados por CMake, incluyendo los utilizados por find_package() para encontrar software común, los que se pueden usar directamente en archivos CMakeLists.txt para realizar tareas comunes y archivos de toolchain que deben ser especificados en la línea de comandos por el usuario.

Además, proporciona configuraciones de compilación comunes utilizadas en software producido por la comunidad KDE.

Aunque la fuerza impulsora de este módulo es reducir la duplicación en scripts de CMake en todo el software de KDE, está destinado a ser útil para cualquier software que utilice el sistema de compilación CMake.

USO

Para usar ECM, añade lo siguiente a tu CMakeLists.txt:

find_package(ECM REQUIRED NO_MODULE)
set(CMAKE_MODULE_PATH ${ECM_MODULE_PATH})

(ten en cuenta que podrías querer añadir ${ECM_MODULE_PATH} a CMAKE_MODULE_PATH en lugar de descartar el valor existente). Puedes entonces simplemente incluir los módulos que necesites, o usar find_package() según sea necesario. Por ejemplo:

include(ECMInstallIcons)

Los desarrolladores de software de KDE a menudo querrán usar las configuraciones estándar de KDE proporcionadas por ECM; pueden hacer lo siguiente:

find_package(ECM REQUIRED NO_MODULE)
set(CMAKE_MODULE_PATH ${ECM_MODULE_PATH})
include(KDEInstallDirs)
include(KDECompilerSettings)
include(KDECMakeSettings)

Ten en cuenta que se puede usar cualquier combinación de las inclusiones anteriores si solo deseas algunas de las configuraciones. Parte de la funcionalidad de KDECMakeSettings <#kde-module:KDECMakeSettings> también puede ser deshabilitada selectivamente.

Organización

ECM proporciona cuatro tipos diferentes de módulos.

  • Los módulos principales proporcionan macros útiles para su uso en scripts CMake de proyectos. Consulte ecm-modules(7) <#manual:ecm-modules(7)> para más información.
  • Los módulos de búsqueda extienden la funcionalidad del comando find_package() de CMake. Consulte ecm-find-modules(7) <#manual:ecm-find-modules(7)> para más información.
  • Los módulos de KDE proporcionan configuraciones comunes para el software producido por KDE; gran parte de esto puede ser útil también para otros proyectos. Consulte ecm-kde-modules(7) <#manual:ecm-kde-modules(7)> para más información.
  • Los archivos de toolchain cambian las herramientas y objetivos de compilación utilizados por CMake. Consulte ecm-toolchains(7) <#manual:ecm-toolchains(7)> para más información.

Las variables ${ECM_MODULE_DIR}, ${ECM_FIND_MODULE_DIR} y ${ECM_KDE_MODULE_DIR} se pueden usar en lugar de ${ECM_MODULE_PATH} si solo necesitas parte de esta funcionalidad.

DESARROLLO

El manual ecm-developer(7) <#manual:ecm-developer(7)> contiene más información sobre el desarrollo para Extra CMake Modules.
