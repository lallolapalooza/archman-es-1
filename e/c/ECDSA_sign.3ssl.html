ECDSA_sign(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ECDSA_SIGN(3ssl) OpenSSL ECDSA_SIGN(3ssl)

NOMBRE

ECDSA_size, ECDSA_sign, ECDSA_do_sign, ECDSA_verify, ECDSA_do_verify, ECDSA_sign_setup, ECDSA_sign_ex, ECDSA_do_sign_ex - funciones obsoletas de bajo nivel del algoritmo de firma digital de curva elíptica (ECDSA)

SINOPSIS

#include <openssl/ecdsa.h>

Las siguientes funciones han quedado obsoletas desde OpenSSL 3.0, y pueden ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int ECDSA_size(const EC_KEY *eckey);
int ECDSA_sign(int type, const unsigned char *dgst, int dgstlen,
               unsigned char *sig, unsigned int *siglen, EC_KEY *eckey);
ECDSA_SIG *ECDSA_do_sign(const unsigned char *dgst, int dgst_len,
                         EC_KEY *eckey);
int ECDSA_verify(int type, const unsigned char *dgst, int dgstlen,
                 const unsigned char *sig, int siglen, EC_KEY *eckey);
int ECDSA_do_verify(const unsigned char *dgst, int dgst_len,
                    const ECDSA_SIG *sig, EC_KEY* eckey);
ECDSA_SIG *ECDSA_do_sign_ex(const unsigned char *dgst, int dgstlen,
                            const BIGNUM *kinv, const BIGNUM *rp,
                            EC_KEY *eckey);
int ECDSA_sign_setup(EC_KEY *eckey, BN_CTX *ctx, BIGNUM **kinv, BIGNUM **rp);
int ECDSA_sign_ex(int type, const unsigned char *dgst, int dgstlen,
                  unsigned char *sig, unsigned int *siglen,
                  const BIGNUM *kinv, const BIGNUM *rp, EC_KEY *eckey);

DESCRIPCIÓN

Véase ECDSA_SIG_new(3) para una descripción del objeto ECDSA_SIG .

Véase i2d_ECDSA_SIG(3) y d2i_ECDSA_SIG(3) para información sobre la codificación y decodificación de firmas ECDSA a/desde DER.

Todas las funciones descritas a continuación están obsoletas. Las aplicaciones deberían usar la interfaz de más alto nivel EVP como EVP_DigestSignInit(3) o EVP_DigestVerifyInit(3) en su lugar.

ECDSA_size() devuelve la longitud máxima de una firma ECDSA codificada en DER creada con la clave EC privada eckey. Para obtener el tamaño real de la firma, use EVP_PKEY_sign(3) con un parámetro sig NULL.

ECDSA_sign() calcula una firma digital del valor hash de dgstlen bytes dgst usando la clave EC privada eckey. La firma codificada en DER se almacena en sig y su longitud se devuelve en siglen. Nota: sig debe apuntar a ECDSA_size(eckey) bytes de memoria. El parámetro type actualmente se ignora. ECDSA_sign() es una función envoltorio de ECDSA_sign_ex() con kinv y rp establecidos a NULL.

ECDSA_do_sign() es similar a ECDSA_sign() excepto que la firma se devuelve como una estructura ECDSA_SIG recién asignada (o NULL en caso de error). ECDSA_do_sign() es una función envoltorio de ECDSA_do_sign_ex() con kinv y rp establecidos a NULL.

ECDSA_verify() verifica que la firma en sig de tamaño siglen es una firma ECDSA válida del valor hash dgst de tamaño dgstlen usando la clave pública eckey. El parámetro type se ignora.

ECDSA_do_verify() es similar a ECDSA_verify() excepto que la firma se presenta en forma de un puntero a una estructura ECDSA_SIG .

Las funciones restantes utilizan los valores internos kinv y r usados durante el cálculo de la firma. La mayoría de las aplicaciones nunca necesitarán llamar a estas y algunas implementaciones externas de ENGINE para ECDSA podrían no soportarlas en absoluto si cualquiera de kinv o r no es NULL.

ECDSA_sign_setup() puede usarse para precalcular partes de la operación de firma. eckey es la clave EC privada y ctx es un puntero a una estructura BN_CTX (o NULL). Los valores precalculados se devuelven en kinv y rp y pueden usarse en una llamada posterior a ECDSA_sign_ex() o ECDSA_do_sign_ex().

ECDSA_sign_ex() calcula una firma digital del valor hash de dgstlen bytes dgst usando la clave EC privada eckey y los valores opcionales precalculados kinv y rp. La firma codificada en DER se almacena en sig y su longitud se devuelve en siglen. Nota: sig debe apuntar a ECDSA_size(eckey) bytes de memoria. El parámetro type se ignora.

ECDSA_do_sign_ex() es similar a ECDSA_sign_ex() excepto que la firma se devuelve como una estructura ECDSA_SIG recién asignada (o NULL en caso de error).

VALORES DEVUELTOS

ECDSA_size() devuelve la longitud máxima de la firma o 0 en caso de error.

ECDSA_sign(), ECDSA_sign_ex() y ECDSA_sign_setup() devuelven 1 si es exitoso o 0 en caso de error.

ECDSA_do_sign() y ECDSA_do_sign_ex() devuelven un puntero a una estructura ECDSA_SIG asignada o NULL en caso de error.

ECDSA_verify() y ECDSA_do_verify() devuelven 1 para una firma válida, 0 para una firma inválida y -1 en caso de error. Los códigos de error pueden obtenerse mediante ERR_get_error(3).

EJEMPLOS

Crear una firma ECDSA de un valor hash SHA-256 dado usando la curva nombrada prime256v1 (también conocida como P-256). Este ejemplo usa funcionalidad obsoleta. Véase "DESCRIPCIÓN".

Primer paso: crear un objeto EC_KEY (nota: esta parte es no específica de ECDSA)

int ret;
ECDSA_SIG *sig;
EC_KEY *eckey;
eckey = EC_KEY_new_by_curve_name(NID_X9_62_prime256v1);
if (eckey == NULL)
    /* error */
if (EC_KEY_generate_key(eckey) == 0)
    /* error */

Segundo paso: calcular la firma ECDSA de un valor hash SHA-256 usando ECDSA_do_sign():

sig = ECDSA_do_sign(digest, 32, eckey);
if (sig == NULL)
    /* error */

o usando ECDSA_sign():

unsigned char *buffer, *pp;
int buf_len;
buf_len = ECDSA_size(eckey);
buffer = OPENSSL_malloc(buf_len);
pp = buffer;
if (ECDSA_sign(0, dgst, dgstlen, pp, &buf_len, eckey) == 0)
    /* error */

Tercer paso: verificar la firma ECDSA creada usando ECDSA_do_verify():

ret = ECDSA_do_verify(digest, 32, sig, eckey);

o usando ECDSA_verify():

ret = ECDSA_verify(0, digest, 32, buffer, buf_len, eckey);

y finalmente evaluar el valor devuelto:

if (ret == 1)
    /* signature ok */
else if (ret == 0)
    /* incorrect signature */
else
    /* error */
