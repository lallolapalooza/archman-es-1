ecryptfs-generate-tpm-key(1) eCryptfs ecryptfs-generate-tpm-key(1)

NOMBRE

ecryptfs-generate-tpm-key - genera una clave eCryptfs para hardware TPM.

SINOPSIS

ecryptfs-generate-tpm-key -p PCR [-p PCR]...

DESCRIPCIÓN

ecryptfs-generate-tpm-key es una utilidad para generar una clave de sellado (almacenamiento) vinculada a un conjunto especificado de valores PCR en los PCR del TPM actual.

EJEMPLO

ecryptfs-generate-tpm-key -p 0 -p 2 -p 3
