DESCRIPCIÓN

Ecatools son sencillas utilidades de línea de comandos para el procesamiento de archivos de audio. Cada herramienta está diseñada para realizar una operación específica. La mayoría de las herramientas también admiten procesamiento por

lotes.

ECAMONITO

R

Ecamonitor es un programa de utilidad que puede usarse para monitorizar una sesión activa de ecasound. Ecamonitor es capaz de mostrar información sobre la configuración de cadena (chainsetup) actual, como la lista de entradas, salidas, posición actual, efectos, el estado del

motor y numerosas otras cosas.

Por defecto, ecamonitor intentará conectarse a la dirección IP4 "localhost", en el puerto "2868". Se puede especificar una dirección diferente al iniciar ecamonitor, por ejemplo "ecamonitor foo.mynetwork.com" o "ecamonitor foo.mynetwork.com:4500". Para habilitar conexiones entrantes, ecasound debe

iniciarse con la

--daemo

n

opción. Ecamonitor está implementado en Python usando la API

NetECI.

ECANORMALIZ

E

Ecanormalize es una herramienta de línea de comandos para normalizar archivos de audio y así utilizar toda la resolución de muestreo disponible. Ecanormalize primero determina cuánto se puede amplificar el archivo de entrada sin saturar y, si hay margen de aumento, se aplicará una ganancia estática al

archivo.

ECAPLA

Y

Ecaplay es una herramienta de línea de comandos para reproducir archivos de audio. Ecaplay usa el motor libecasound y por lo tanto puede manejar todos los formatos de audio admitidos por la

biblioteca.

Los archivos pueden seleccionarse para la reproducción especificando los nombres de archivo en la línea de comandos, o usando el mecanismo de listas de reproducción. En el modo lista de reproducción, los archivos pueden añadirse a la lista usando la -q opción.

La

-p opción puede usarse entonces para reproducir todas las pistas de la lista de reproducción. Ecaplay repetirá las pistas de la lista hasta que se detenga explícitamente (con doble Ctrl-C). La lista de reproducción puede vaciarse

con

comandos

-o:output_device . La reproducción puede detenerse en cualquier momento con Ctrl-C. Si se reproducen varios archivos, el primer Ctrl-C detendrá el archivo actual y pasará a reproducir el siguiente. Emitir Ctrl-C dos veces (dentro de un segundo) hará que ecaplay salga. -d:nivel_
