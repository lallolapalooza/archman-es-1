DESCRIPCIÓ

N

EVP_EC_gen() genera un nuevo par de claves EC en la curva d

ada.

Todas las funciones descritas a continuación están obsoletas. Las aplicaciones deben usar en su lugar EVP_EC_gen(), EVP_PKEY_Q_keygen(3), o EVP_PKEY_keygen_init(3) y EVP_PKEY_keyg

en(3).

Un EC_KEY representa una clave pública y, opcionalmente, la clave privada asociada. Se puede construir un nuevo EC_KEY sin curva asociada llamando a EC_KEY_new_ex() y especificando el contexto de biblioteca asociado en ctx (ver OSSL_LIB_CTX(3)) y la cadena de consulta de propiedades propq. El parámetro ctx puede ser NULL, en cuyo caso se usa el contexto de biblioteca predeterminado. El recuento de referencias del EC_KEY recién creado se establece inicialmente en 1. Se puede asociar una curva con el EC_KEY llamando a EC_KEY_set_gr

oup().

EC_KEY_new() es lo mismo que EC_KEY_new_ex() excepto que siempre se usa el contexto de biblioteca

predeterminado.

Alternativamente, se puede construir un nuevo EC_KEY llamando a EC_KEY_new_by_curve_name_ex() y proporcionando el nid de la curva asociada, el contexto de biblioteca a usar ctx (ver OSSL_LIB_CTX(3)) y cualquier cadena de consulta de propiedades propq. El parámetro ctx puede ser NULL, en cuyo caso se usa el contexto de biblioteca predeterminado. El valor propq también puede ser NULL. Ver EC_GROUP_new(3) para una descripción de los nombres de curva. Esta función simplemente envuelve las llamadas a EC_KEY_new_ex() y EC_GROUP_new_by_curve

_name_ex().

EC_KEY_new_by_curve_name() es lo mismo que EC_KEY_new_by_curve_name_ex() excepto que siempre se usa el contexto de biblioteca predeterminado y una cadena de consulta de propiedades

NULL.

Llamar a EC_KEY_free() decrementa el recuento de referencias del objeto EC_KEY y, si ha llegado a cero, libera la memoria asociada a él. Si key es NULL, no se hace

nada.

EC_KEY_copy() copia el contenido del EC_KEY en src en dest

.

EC_KEY_dup() crea un nuevo objeto EC_KEY y copia ec_key en

él.

EC_KEY_up_ref() incrementa el recuento de referencias asociado con el objeto

EC_KEY.

EC_KEY_get0_engine() devuelve un manejador del ENGINE que ha sido establecido para este objeto

EC_KEY.

EC_KEY_generate_key() genera una nueva clave pública y privada para el objeto eckey proporcionado. eckey debe tener un objeto EC_GROUP asociado antes de llamar a esta función. La clave privada es un entero aleatorio (0 < priv_key < orden, donde orden es el orden del objeto EC_GROUP). La clave pública es un EC_POINT en la curva calculado multiplicando el generador de la curva por la clave

privada.

EC_KEY_check_key() realiza varias comprobaciones de coherencia en el objeto EC_KEY para confirmar que es

válido.

EC_KEY_set_public_key_affine_coordinates() establece la clave pública para key basándose en sus coordenadas afines; es decir, construye un objeto EC_POINT basándose en los valores proporcionados x y y y establece la clave pública para que sea este EC_POINT. También realiza ciertas comprobaciones de coherencia en la clave para confirmar que es

válida.

Las funciones EC_KEY_get0_group(), EC_KEY_set_group(), EC_KEY_get0_private_key(), EC_KEY_set_private_key(), EC_KEY_get0_public_key() y EC_KEY_set_public_key() obtienen y establecen el objeto EC_GROUP, la clave privada y la clave pública EC_POINT para la key respectivamente. La función EC_KEY_set_private_key() acepta NULL como el argumento priv_key para borrar de forma segura el componente de clave privada del

EC_KEY.

Las funciones EC_KEY_get_conv_form() y EC_KEY_set_conv_form() obtienen y establecen el point_conversion_form para la key. Para una descripción de los point_conversion_forms, ver EC_POINT_ne

w(3).

EC_KEY_set_flags() establece los indicadores en el parámetro flags en el objeto EC_KEY. Los indicadores que ya están establecidos permanecen establecidos. Los indicadores definidos actualmente son EC_FLAG_NON_FIPS_ALLOW y EC_FLAG_FIPS_CHECKED. Además, existe el indicador EC_FLAG_COFACTOR_ECDH que es específico de ECDH. EC_KEY_get_flags() devuelve los indicadores actuales establecidos para este EC_KEY. EC_KEY_clear_flags() borra los indicadores indicados por el parámetro flags; todos los demás indicadores permanecen en su estado

existente.

EC_KEY_set_asn1_flag() establece el asn1_flag en el objeto EC_GROUP subyacente (si está establecido). Referirse a EC_GROUP_copy(3) para más información sobre el

asn1_flag.

EC_KEY_decoded_from_explicit_params() devuelve 1 si el grupo de la key fue decodificado a partir de datos con parámetros de grupo codificados explícitamente, -1 si la key es NULL o los parámetros del grupo faltan, y 0 en caso

contrario.

EC_KEY_precompute_mult() almacena múltiplos del generador EC_GROUP subyacente para una multiplicación de puntos más rápida. Ver también EC_POINT_add(3). Las versiones modernas deberían en su lugar cambiar a curvas nombradas para las que OpenSSL tiene tablas de búsqueda

codificadas.

EC_KEY_oct2key() y EC_KEY_key2buf() son idénticas a las funciones EC_POINT_oct2point() y EC_POINT_point2buf() excepto que usan el EC_POINT de clave pública en eckey

.

EC_KEY_oct2priv() y EC_KEY_priv2oct() convierten entre el componente de clave privada de eckey y su forma de octeto. La forma de octeto consiste en los octetos de contenido del privateKey OCTET STRING en una estructura ECPrivateKey ASN.

1.

La función EC_KEY_priv2oct() debe proporcionarse con un búfer lo suficientemente largo para almacenar el formato octeto. El valor de retorno proporciona el número de octetos almacenados. Llamar a la función con un búfer NULL no realizará la conversión, sino que simplemente devolverá la longitud de búfer

requerida.

La función EC_KEY_priv2buf() asigna un búfer de longitud adecuada y escribe un EC_KEY en él en formato octeto. El búfer asignado se escribe en *pbuf y se devuelve su longitud. El llamador debe liberar el búfer asignado con una llamada a OPENSSL_free(). Dado que el valor del búfer asignado se escribe en *pbuf, el parámetro pbuf NO DEBE ser NULL

.

EC_KEY_priv2buf() convierte una clave p

rivada EC_KEY en un
búfer asignado.

RETORNO

EC_KEY_new_ex(), EC_KEY_new(), EC_KEY_new_by_curve_name_ex(), EC_KEY_new_by_curve_name() y EC_KEY_dup() devuelven un puntero al objeto EC_KEY recién creado, o NULL en caso de

error.

EC_KEY_get_flags() devuelve los indicadores asociados con el objeto EC_KEY como un

entero.

EC_KEY_copy() devuelve un puntero a la clave de destino, o NULL en caso de

error.

EC_KEY_get0_engine() devuelve un puntero a un ENGINE, o NULL si no se

estableció.

EC_KEY_up_ref(), EC_KEY_set_group(), EC_KEY_set_public_key(), EC_KEY_precompute_mult(), EC_KEY_generate_key(), EC_KEY_check_key(), EC_KEY_set_public_key_affine_coordinates(), EC_KEY_oct2key() y EC_KEY_oct2priv() devuelven 1 en caso de éxito o 0 en caso de

error.

EC_KEY_set_private_key() devuelve 1 en caso de éxito o 0 en caso de error, excepto cuando el argumento priv_key es NULL; en ese caso devuelve 0, por compatibilidad con versiones anteriores, y no debe tratarse como un

error.

EC_KEY_get0_group() devuelve el EC_GROUP asociado con el

EC_KEY.

EC_KEY_get0_private_key() devuelve la clave privada asociada con el

EC_KEY.

EC_KEY_get_conv_form() devuelve el point_conversion_form para el

EC_KEY.

EC_KEY_key2buf(), EC_KEY_priv2oct() y EC_KEY_priv2buf() devuelven la longi

tud del búfer o 0
en caso de error.
