ecm es un programa de factorización de enteros que utiliza el Método de la Curva Elíptica (ECM), el método P-1 o el método P+1. Las siguientes secciones describen los parámetros relevantes para

estos algoritmos.

B1 es el límite del paso 1. Es un parámetro obligatorio. Se puede dar tanto en formato entero (por ejemplo 3000000) como en formato

de punto flotante (3000000.0 o 3e6). El valor más grande posible de

ARCHIVOS

Las siguientes opciones permiten realizar el paso 1 y el paso 2 por separado, ya sea en diferentes máquinas, en diferentes momentos, o usando diferentes software (en particular, el programa Prime95/mprime de George Woltman puede producir una salida del paso 1 adecuada para reanudar con GMP-ECM). También puede ser útil dividir el paso 2 en varias ejecuciones, usando la opción B2min-
B2max.

MODO_DE_BUCLE


El "modo de bucle" (opción -c n)
    permite ejecutar varias curvas en cada número de entrada. Las siguientes
    opciones controlan su comportamiento.


-c n


Realiza n ejecuciones en cada número de entrada (el valor predeterminado es una). Esta opción es útil principalmente para P+1 (por ejemplo, con n=3) o para ECM, donde n podría establecerse en el número esperado de curvas para encontrar un factor de d dígitos con un límite de paso 1 dado. Esta opción es incompatible con -resume, -sigma, -x0. Dar -c 0 produce un bucle infinito hasta que se encuentre un factor.


-one


En modo de bucle, detente cuando se encuentre un factor; el valor predeterminado es continuar hasta que el cofactor sea primo o se realicen el número especificado de ejecuciones.


-b


Procesamiento en anchura primero: en modo de bucle, ejecuta una curva por cada número de entrada, luego una segunda curva para cada uno, y así sucesivamente. Este es el modo predeterminado con -inp.


-d


Procesamiento en profundidad primero: en modo de bucle, ejecuta n curvas para el primer número, luego n curvas para el segundo, y así sucesivamente. Este es el modo predeterminado con la entrada estándar.


-ve n


En modo de bucle, en la segunda ejecución y posteriores, muestra solo expresiones que tengan como máximo n caracteres. El valor predeterminado es -ve 0.


-i n


En modo de bucle, incrementa B1 en n después de cada curva.


-I n


En modo de bucle, multiplica B1 por un factor que depende de n después de cada curva. El valor predeterminado es uno, que debería ser óptimo en una máquina, mientras que -I 10 podría usarse al intentar factorizar el mismo número simultáneamente en 10 máquinas idénticas.






EJECUCION_DE_COMANDOS_DE_SHELL


Estas opciones permiten la ejecución de comandos de shell para complementar la funcionalidad de GMP-ECM.


-prpcmd cmd


Ejecuta el comando cmd para probar la primalidad si los factores y cofactores en lugar de las propias funciones de GMP-ECM. El número a probar se pasa a través de stdin. Un código de salida de 0 se interpreta como "probablemente primo", un código de salida distinto de cero como "compuesto".


-faccmd cmd


Ejecuta el comando cmd cada vez que se encuentra un factor mediante P-1, P+1 o ECM. El número de entrada, el factor y el cofactor se pasan a través de stdin, cada uno en una línea. Esto podría usarse, por ejemplo, para enviar automáticamente nuevos factores por correo:



ecm -faccmd 'mail -s “$HOSTNAME encontró un factor”
                me@myaddress.com' 11e6 < cunningham.in






-idlecmd cmd


Ejecuta el comando cmd antes de que comience cada intento de curva ECM, P-1 o P+1 en un número. Si el estado de salida de cmd no es cero, GMP-ECM termina inmediatamente, de lo contrario continúa normalmente. GMP-ECM se detiene mientras se ejecuta cmd, ofreciendo una forma de permitir que GMP-ECM duerma, por ejemplo, mientras el sistema está ocupado.






VARIOS


-n


Ejecuta el programa en modo "nice" (prioridad por debajo de la normal).


-nn


Ejecuta el programa en modo "very nice" (prioridad inactiva).


-B2scale f


Multiplica el límite de paso 2 predeterminado B2 por el valor de punto flotante f. Ejemplo: -B2scale 0.5 divide el B2 predeterminado por 2.


-stage1time n


Agrega n segundos al tiempo de la etapa 1. Esto es útil para obtener el tiempo esperado correcto con -v si parte de la etapa 1 se realizó en otra ejecución.


-cofdec


Fuerza la salida del cofactor en decimal (incluso si se utilizan expresiones).


-h, --help


Muestra una breve descripción del uso de ecm, parámetros y opciones de línea de comandos.


-printconfig


Imprime los parámetros de configuración utilizados para la compilación y sale.






SINTAXIS_DE_ENTRADA


Los números de entrada pueden tener varios formatos:


Números decimales crudos como 123456789.


Los comentarios se pueden colocar en el archivo: todo lo que esté después de "//" se ignora hasta el final de la línea.


Continuación de línea. Si una línea termina con un carácter de barra invertida "\", se considera que continúa en la siguiente línea.


Se pueden usar expresiones aritméticas comunes. Ejemplo: 3*5+(2+7)^10.


Factorial: ejemplo 53!.


Multi-factorial: ejemplo 15!3 significa 15*12*9*6*3.


Primorial: ejemplo 11# significa 2*3*5*7*11.


Primorial reducido: ejemplo 17#5 significa 5*7*11*13*17.


Funciones:


GCD(a,b): Máximo común divisor


ejemplo GCD(120,28) = 4


Phi(n,x): Polinomio ciclotómico n-ésimo evaluado en x


ejemplo Phi(3,5) = 1 + x + x^2 = 31






ESTADO_DE_SALIDA


El estado de salida refleja el resultado de la última curva ECM o intento P-1/P+1 que realizó el programa. Los bits individuales significan eventos particulares, específicamente:


Bit 0


0 si la terminación normal del programa, 1 si ocurrió un error


Bit 1


0 si no se encontró un factor adecuado, 1 en caso contrario


Bit 2


0 si el factor es compuesto, 1 si el factor es un primo probable


Bit 3


0 si el cofactor es compuesto, 1 si el cofactor es un primo probable


Por lo tanto, pueden ocurrir los siguientes valores de estado de salida:


0


Terminación normal del programa, no se encontró factor


1


Error


2


Se encontró un factor compuesto, el cofactor es compuesto


6


Se encontró un factor de primo probable, el cofactor es compuesto


8


Se encontró el número de entrada


10


Se encontró un factor compuesto, el cofactor es un primo probable


14


Se encontró un factor de primo probable, el cofactor es un primo probable
