DESCRIPCIÓ

N

Ecatools son utilidades simples de línea de comandos para el procesamiento de archivos de audio. Cada herramienta está diseñada para realizar una operación específica. La mayoría de las herramientas también admiten procesamiento por

lotes.

ECACONVER

T

Una herramienta para convertir un conjunto de archivos a un formato de destino común. Este formato de destino se indica como el primer argumento de la línea de comandos, y su sintaxis es .ex

t.

ECAFIXD

C

Una herramienta simple de línea de comandos para corregir el desplazamiento

DC.

ECALENGT

H

Consulte la página man independiente de ecalength(1)

.

ECAMONITO

R

Ecamonitor es un programa utilitario que se puede usar para monitorear una sesión activa de ecasound. Ecamonitor es capaz de mostrar información sobre la configuración de cadena actual, como la lista de entradas, salidas, posición actual, efectos, el estado del motor y numerosas otras

cosas.

Por defecto, ecamonitor intentará conectarse a la dirección IP4 "localhost", al puerto "2868". Se puede especificar una dirección diferente al iniciar ecamonitor, por ejemplo "ecamonitor foo.mynetwork.com" o "ecamonitor foo.mynetwork.com:

4500".

Para habilitar conexiones entrantes, ecasound debe iniciarse con la opción --daemon. Ecamonitor está implementado en Python utilizando la API

NetECI.

ECANORMALIZ

E

Ecanormalize es una herramienta de línea de comandos para normalizar archivos de audio y utilizar toda la resolución de muestreo disponible. Ecanormalize primero determina cuánto se puede amplificar el archivo de entrada sin recorte y si hay espacio para aumentar, se aplicará una ganancia estática al

archivo.

ECAPLA

Y

Ecaplay es una herramienta de línea de comandos para reproducir archivos de audio. Ecaplay usa el motor libecasound y por lo tanto es capaz de manejar todos los formatos de audio admitidos por la

biblioteca.

Los archivos se pueden seleccionar para la reproducción ya sea especificando los nombres de archivo en la línea de comandos, o usando el mecanismo de lista de reproducción. En el modo de lista de reproducción, se pueden agregar archivos a la lista de reproducción usando la opción -q. La opción -p se puede usar luego para reproducir todas las pistas de la lista de reproducción. Ecaplay repetirá las pistas de la lista de reproducción hasta que se detenga explícitamente (con doble Ctrl-C). La lista de reproducción se puede vaciar con -f y su contenido se puede listar con la opción

-l.

Si no se especifica de otra manera, ecaplay usará el dispositivo de salida de audio especificado en ~/.ecasound/ecasoundrc para la reproducción. Se puede seleccionar un dispositivo de salida diferente con la variable de entorno del shell ECAPLAY_OUTPUT_DEVICE o con la opción de línea de comandos -o:

output_device.

La reproducción se puede detener en cualquier momento con Ctrl-C. Si se reproducen varios archivos, el primer Ctrl-C detendrá el archivo actual y pasará a reproducir el siguiente. Emitir Ctrl-C dos veces (dentro de un segundo) hará que ecaplay

salga.

ECASIGNALVI
E
W

Ecasignalview está destinado a monitorear la amplitud de la señal y las estadísticas de pico. Acepta las siguientes

opciones:
entr
ada
La primera opción que no comienza con ’-’ se interpreta como una cadena de entrada. Esta puede ser un dispositivo o un nombre de archivo. Se aceptan todos los formatos admitidos por libecasound. Por defecto es
’/dev/dsp’.
sali
da
De manera similar a la entrada, la segunda opción que no comienza con ’-’ se interpreta como salida. Por defecto es
’null’.
-b:
tamaño_buffer
Tamaño del búfer en tramas de muestreo. Por defecto es
128.
-
c
Habilita el modo acumulativo. Los contadores no se restablecen después de la actualización. *obsolet
o*
-
d
Habilita el modo de
depuración.
-f:
cadena_formato
Especifica el formato de audio predeterminado. Consulte ecasound(1) para más
detalles.
-r:
rate_msec
Especifica la tasa de actualización de la pantalla en
milisegundos.
-
I
Usa escala lineal para mostrar la amplitud de la muestra de

-

Usa escala logarítmica para mostrar la amplitud de la muestra de
audio.
-G, -B, -M*, -r,
-z

detalles.
