La clase aplicando claves elípticas al algoritmo de Diffie-Hellman (1976). El algoritmo de Diffie-Hellman utiliza información pública y privada, proporcionando una infraestructura de clave pública (PKI). La información pública consiste en una especificación de curva elíptica y una clave pública, que puede compartirse a través de medios inseguros. El algoritmo de Diffie-Hellman se

utiliza

comúnmente para calcular una clave compartida que luego se usa para cifrar información enviada entre dos partes. Una parte, que en esta

página

man se llama el iniciador, especifica en el momento de la construcción una curva elíptica, construye una clave pública y privada, y escribe la clave pública en forma hexadecimal big-endian, seguida del nombre de la curva elíptica utilizada en un archivo. La clave privada del iniciador se escribe por separado en un archivo, ya que la clave privada es necesaria para calcular la clave compartida. Puede utilizarse cifrado al escribir la clave privada en el archivo. A

continuación,

el iniciador pasa el archivo que contiene la clave pública del iniciador y el nombre de la curva elíptica utilizada a la otra parte, que en esta página man se llama el par. El pa

r,

habiendo recibido el archivo de la clave pública del iniciador, construye un objeto FBB::ECDH. El constructor ECDH del par calcula la clave pública y privada del par, escribe la clave pública del par en un archivo y construye la clave compartida. Una vez que el objeto ECDH del par ha sido construido, el par puede escribir la clave compartida en un archivo. La clave privada del par puede opcionalmente escribirse también en un archivo, pero eso es opcional, ya que la clave privada del par no es necesaria para cálculos posteriores. También puede utilizarse cifrado al escribir

la

clave privada del par en el archivo. El archivo que contiene la clave pública del par es entonces enviado a el iniciador. El iniciador construye un objeto ECDH especificando los nombres de la curva elíptica utilizada, del archivo que contiene la clave privada del iniciador, y el nombre del archivo que contiene la clave pública del par. Una vez que este objeto ECDH ha sido

construido

el par puede escribir la clave compartida en un archivo. Las claves compartidas del iniciador y del par son idénticas y pueden usarse para el cifrado simétrico de

#include "main.ih"
int main(int argc, char **argv)
try
{
    if (argc == 1)
    {
        usage(path{ argv[0] }.filename().string());
        return 0;
    }
    if ("curves"s == argv[1])           // show supported ECDH curves.
        cout << ECDH{};
    else if ("init"s == argv[1])        // initiator key construction
    {
                                        // write the file containing
                                        // the curve + public key
        ECDH ecdh{ ECDH::Initiator, "secp384r1", "init.pub" };
                                        // save the initiator’s 
                                       // private key
        ecdh.privKey("init.sec", "use your passphrase");
            // not using encryption:
            // auto initSec = Exception::factory<ofstream>("init.sec");
            // initSec << ecdh.privKey() << ’\n’;
    }
    else if ("priv"s == argv[1])        // initiator key construction
    {
                                        // write the file containing
                                        // the curve + public key
        ECDH ecdh{ ECDH::Initiator, "secp384r1", "init.pub" };
        cout << "wait for the peer’s public key. "
                "Press Enter to continue... ";
        cin.ignore(100, ’\n’);
                                                    // written to file
        auto initShared = Exception::factory<ofstream>("init.shared");
        initShared << ecdh.sharedKey("peer.pub") << ’\n’;  
    }
    else if ("peer"s == argv[1])        // peer’s key construction
    {                                   
                                        // write the peer’s public key
        ECDH ecdh{ ECDH::Peer, "init.pub", "peer.pub" }; 
                                        // save the peer’s private
                                        // key (although not needed)
        auto out = Exception::factory<ofstream>("peer.sec");
        out << ecdh.privKey() << ’\n’;
        out = Exception::factory<ofstream>("peer.shared");
        out << ecdh.sharedKey() << ’\n’;
    }
    else if ("shared"s == argv[1])      // the initiator’s shared key
    {                                   // construction
        ECDH ecdh{ "secp384r1", "peer.pub", "init.sec", 
                                            "use your passphrase" };
        auto initShared = Exception::factory<ofstream>("init.shared");
        initShared << ecdh.sharedKey() << ’\n’;     // written to file
    }
    else 
    {
        usage(path{ argv[0] }.filename().string());
        return 1;
    }
}
catch (exception const &exc)
{
    cerr << "Error: " << exc.what() << ’\n’;
    return 1;
}
catch (...)                     // and handle an unexpected exception
{
    cerr << "unexpected exception\n";
    return 1;
}
