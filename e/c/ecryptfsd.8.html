NOMBRE

ecryptfsd - demonio de eCryptfs en espacio de usuario.

DESCRIPCIÓN

ecryptfsd es un demonio en espacio de usuario que se ejecuta como el usuario que realiza operaciones de archivo bajo el punto de montaje de eCryptfs. Atiende las solicitudes de claves públicas del módulo del kernel de eCryptfs; estas solicitudes se envían a través de /dev/ecryptfs en eventos de apertura de archivos. ecryptfsd solo necesita ejecutarse cuando se realiza un montaje con un módulo de clave pública.

El demonio puede iniciarse simplemente ejecutando ecryptfsd. ecryptfsd se registrará con el kernel como el demonio que debe atender todas las solicitudes del sistema de archivos eCryptfs realizadas bajo el contexto del usuario que ejecuta el demonio.
