NOMBRE

ecpg - preprocesador C de SQL embebido

SINOPSIS

ecpg [opción...] archivo...

DESCRIPCIÓN

ecpg es el preprocesador de SQL embebido para programas C. Convierte programas C con sentencias SQL embebidas a código C normal reemplazando las invocaciones SQL por llamadas a funciones especiales. Los archivos de salida pueden ser procesados posteriormente con cualquier cadena de herramientas de compilador C.

ecpg convertirá cada archivo de entrada dado en la línea de comandos al archivo de salida C correspondiente. Si el nombre de un archivo de entrada no tiene ninguna extensión, se asume .pgc. La extensión del archivo se reemplazará por .c para construir el nombre del archivo de salida. Sin embargo, el nombre del archivo de salida puede ser anulado usando la opción -o.

Si el nombre de un archivo de entrada es solo -, ecpg lee el programa de la entrada estándar (y escribe a la salida estándar, a menos que esto se anule con -o).

Esta página de referencia no describe el lenguaje SQL embebido. Consulte el Capítulo 34 para obtener más información sobre este tema.

OPCIONES

ecpg acepta los siguientes argumentos de línea de comandos:

-c

Genera automáticamente cierto código C a partir de código SQL. Actualmente, esto funciona para EXEC SQL TYPE.

-C modo

Establece un modo de compatibilidad. modo puede ser INFORMIX, INFORMIX_SE, o ORACLE.

-D símbolo[=valor]

Define un símbolo del preprocesador, de forma equivalente a la directiva EXEC SQL DEFINE. Si no se especifica ningún valor, el símbolo se define con el valor 1.

-h

Procesa archivos de cabecera. Cuando se especifica esta opción, la extensión del archivo de salida se convierte en .h, no en .c, y la extensión por defecto del archivo de entrada es .pgh, no .pgc. Además, la opción -c se fuerza a activarse.

-i

Analiza también los archivos de inclusión del sistema.

-I directorio

Especifica una ruta de inclusión adicional, utilizada para encontrar archivos incluidos a través de EXEC SQL INCLUDE. Los valores por defecto son . (directorio actual), /usr/local/include, el directorio de inclusión de PostgreSQL que se define en el momento de la compilación (por defecto: /usr/local/pgsql/include), y /usr/include, en ese orden.

-o nombrearchivo

Especifica que ecpg debe escribir toda su salida en el nombrearchivo dado. Escriba -o - para enviar toda la salida a la salida estándar.

-r opción

Selecciona el comportamiento en tiempo de ejecución. opción puede ser una de las siguientes:

no_indicator

No usa indicadores, sino que utiliza valores especiales para representar valores nulos. Históricamente ha habido bases de datos que utilizaban este enfoque.

prepare

Prepara todas las sentencias antes de usarlas. Libecpg mantendrá una caché de sentencias preparadas y reutilizará una sentencia si se ejecuta de nuevo. Si la caché se llena, libecpg liberará la sentencia menos utilizada.

questionmarks

Permite el signo de interrogación como marcador de posición por motivos de compatibilidad. Este solía ser el valor por defecto hace mucho tiempo.

-t

Activa el autocommit de las transacciones. En este modo, cada comando SQL se confirma automáticamente a menos que esté dentro de un bloque de transacción explícito. En el modo por defecto, los comandos solo se confirman cuando se emite EXEC SQL COMMIT.

-v

Imprime información adicional, incluida la versión y la ruta de "inclusión".

--version

Imprime la versión de ecpg y sale.

-?
--help

Muestra ayuda sobre los argumentos de la línea de comandos de ecpg y sale.

NOTAS

Al compilar los archivos de código C preprocesados, el compilador necesitará poder encontrar los archivos de cabecera ECPG en el directorio de inclusión de PostgreSQL. Por lo tanto, es posible que deba usar la opción -I al invocar el compilador (por ejemplo, -I/usr/local/pgsql/include).

Los programas que utilizan código C con SQL embebido deben ser enlazados contra la biblioteca libecpg, por ejemplo, usando las opciones del enlazador -L/usr/local/pgsql/lib -lecpg.

El valor de cualquiera de estos directorios que sea apropiado para la instalación se puede averiguar utilizando pg_config(1).

EJEMPLOS

Si tiene un archivo fuente C de SQL embebido llamado prog1.pgc, puede crear un programa ejecutable usando la siguiente secuencia de comandos:

ecpg prog1.pgc
cc -I/usr/local/pgsql/include -c prog1.c
cc -o prog1 prog1.o -L/usr/local/pgsql/lib -lecpg
