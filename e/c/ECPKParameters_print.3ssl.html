ECPKParameters_print(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ECPKPARAMETERS_PRINT(3ssl) OpenSSL ECPKPARAMETERS_PRINT(3ssl)

NOMBRE

ECPKParameters_print, ECPKParameters_print_fp - Funciones para decodificar y codificar representaciones ASN1 de entidades de curva elíptica

SINOPSIS

#include <openssl/ec.h>

Las siguientes funciones están obsoletas desde OpenSSL 3.0 y pueden ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int ECPKParameters_print(BIO *bp, const EC_GROUP *x, int off);
int ECPKParameters_print_fp(FILE *fp, const EC_GROUP *x, int off);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_print_params(3)

ECPKParameters representa los parámetros públicos de un estructura EC_GROUP, que representa una curva.

Las funciones ECPKParameters_print() y ECPKParameters_print_fp() imprimen una salida legible por humanos de los parámetros públicos del EC_GROUP a bp o fp. Las líneas de salida están indentadas por off espacios.

VALORES DE RETORNO

ECPKParameters_print() y ECPKParameters_print_fp() devuelven 1 si tiene éxito y 0 si ocurre un error.

VER TAMBIÉN

crypto(7), EC_GROUP_new(3), EC_GROUP_copy(3), EC_POINT_new(3), EC_POINT_add(3), EC_KEY_new(3), EC_GFp_simple_method(3),

HISTORIA

Todas estas funciones quedaron obsoletas en OpenSSL 3.0.
