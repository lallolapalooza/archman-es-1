NOMBRE

ecryptfs-migrate-home - migrar el directorio personal de un usuario a una configuración de directorio personal cifrado

SINOPSIS

ecryptfs-migrate-home [-u|--user USUARIO]

OPCIONES

-u, --user USUARIO
Migrar el directorio personal de USUARIO a un directorio personal cifrado

DESCRIPCIÓN

ADVERTENCIA: Haga una copia de seguridad completa de los datos no cifrados en otro sistema o en medios externos. ¡Este script es peligroso y, en caso de error, podría resultar en pérdida de datos o en que USUARIO quede bloqueado fuera del sistema!

Este programa debe ser ejecutado por root.

Este programa intentará migrar el directorio personal de un usuario a un directorio personal cifrado.

Este programa requiere espacio libre en disco 2.5 veces el tamaño actual del directorio personal a migrar. Una vez completado con éxito, puede recuperar la mayor parte de este espacio eliminando el directorio de texto plano.

USUARIO debe haber cerrado sesión en todas las sesiones para poder realizar la migración, y no tener ningún archivo abierto según lsof(1).

Una vez que la migración haya completado, USUARIO debe iniciar sesión inmediatamente, ANTES DEL PRÓXIMO REINICIO para completar la migración.

Después de iniciar sesión, si USUARIO puede leer y escribir archivos en su directorio personal con éxito, entonces la migración se ha completado con éxito y puede eliminar la copia de seguridad de texto plano en /home/.

Después de una migración exitosa, USUARIO realmente debe ejecutar ecryptfs-unwrap-passphrase(1) o zescrow(1) y registrar su frase de paso de montaje generada aleatoriamente.

Si el swap no está ya cifrado, se recomienda encarecidamente que su administrador configure el swap cifrado usando ecryptfs-setup-swap(1).

VER TAMBIÉN

ecryptfs-unwrap-passphrase(1), ecryptfs-setup-private(1), ecryptfs-setup-swap(1), lsof(1), rsync(1), zescrow(1)
