NOMBRE

EC_GFp_simple_method, EC_GFp_mont_method, EC_GFp_nist_method, EC_GFp_nistp224_method, EC_GFp_nistp256_method, EC_GFp_nistp521_method, EC_GF2m_simple_method, EC_METHOD_get_field_type - Funciones para obtener objetos EC_METHOD

SINOPSIS

#include <openssl/ec.h>

Las siguientes funciones han sido obsoletas desde OpenSSL 3.0, y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

const EC_METHOD *EC_GFp_simple_method(void);
const EC_METHOD *EC_GFp_mont_method(void);
const EC_METHOD *EC_GFp_nist_method(void);
const EC_METHOD *EC_GFp_nistp224_method(void);
const EC_METHOD *EC_GFp_nistp256_method(void);
const EC_METHOD *EC_GFp_nistp521_method(void);
const EC_METHOD *EC_GF2m_simple_method(void);
int EC_METHOD_get_field_type(const EC_METHOD *meth);

DESCRIPCIÓN

Todas las funciones const EC_METHOD *EC_GF* fueron obsoletas en OpenSSL 3.0, ya que EC_METHOD ya no es un concepto público.

La biblioteca de Curvas Elípticas proporciona una serie de implementaciones diferentes a través de una única interfaz común. Al construir una curva usando EC_GROUP_new (véase EC_GROUP_new(3)) se debe proporcionar un método de implementación. Las funciones descritas aquí devuelven todas un puntero constante a una estructura EC_METHOD que puede ser pasada a EC_GROUP_NEW. Es importante utilizar el tipo de implementación correcto para la forma de curva seleccionada.

Para curvas F2^m solo hay una opción de implementación, es decir, EC_GF2_simple_method.

Para curvas Fp, la implementación de menor denominador común es la implementación EC_GFp_simple_method. Todas las demás implementaciones se basan en esta. EC_GFp_mont_method se basa en EC_GFp_simple_method pero añade el uso de multiplicación de Montgomery (véase BN_mod_mul_montgomery(3)). EC_GFp_nist_method ofrece una implementación optimizada para su uso con las curvas recomendadas por NIST (las curvas NIST están disponibles a través de EC_GROUP_new_by_curve_name como se describe en EC_GROUP_new(3)).

Las funciones EC_GFp_nistp224_method, EC_GFp_nistp256_method y EC_GFp_nistp521_method ofrecen implementaciones optimizadas a 64 bits para las curvas NIST P224, P256 y P521 respectivamente. Tenga en cuenta, sin embargo, que estas implementaciones no están disponibles en todas las plataformas.

EC_METHOD_get_field_type() fue obsoleta en OpenSSL 3.0. Las aplicaciones deben usar EC_GROUP_get_field_type() como reemplazo (véase EC_GROUP_copy(3)).

VALORES DE RETORNO

Todas las funciones EC_GFp* y EC_GF2m_simple_method siempre devuelven un puntero constante a una estructura EC_METHOD.

EC_METHOD_get_field_type devuelve un entero que identifica el tipo de campo que soporta la estructura EC_METHOD.
