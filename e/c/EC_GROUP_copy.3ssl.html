La siguiente función ha quedado obsoleta desde OpenSSL 3.0, y puede ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

const EC_METHOD *EC_GROUP_method_of(const EC_GROUP *group);

DESCRIPCIÓN

EC_GROUP_copy() copia la curva src en dst. Tanto src como dst deben usar el mismo EC_METHOD.

EC_GROUP_dup() crea un nuevo objeto EC_GROUP y copia el contenido de src al objeto EC_GROUP recién creado.

EC_GROUP_method_of() obtiene el EC_METHOD de group. Esta función quedó obsoleta en OpenSSL 3.0, ya que EC_METHOD ya no es un concepto público.

EC_GROUP_set_generator() establece los parámetros de la curva que deben acordarse por todos los participantes que usan la curva. Estos parámetros incluyen el generador, la orden y el cofactor. El generador es un punto bien definido en la curva elegido para operaciones criptográficas. Los enteros usados para las multiplicaciones de puntos estarán entre 0 y n-1, donde n es la orden. La orden multiplicada por el cofactor da el número de puntos en la curva.

EC_GROUP_get0_generator() devuelve el generador para el grupo identificado group.

EC_GROUP_get_order() recupera la orden de group y copia su valor en order. Falla en caso de que group no esté completamente inicializado (es decir, su orden no está establecida o está establecida a cero).

EC_GROUP_get_cofactor() recupera el cofactor de group y copia su valor en cofactor. Falla en caso de que group no esté completamente inicializado o si el cofactor no está establecido (o está establecido a cero).

Las funciones EC_GROUP_set_curve_name() y EC_GROUP_get_curve_name(), establecen y obtienen el NID para la curva respectivamente (véase EC_GROUP_new(3)). Si una curva no tiene un NID asociado, entonces EC_GROUP_get_curve_name devolverá NID_undef.

El valor asn1_flag se usa para determinar si la codificación de la curva usa parámetros explícitos o una curva con nombre usando un OID ASN1: muchas aplicaciones solo soportan la última forma. Si asn1_flag es OPENSSL_EC_NAMED_CURVE entonces se usa la forma de curva con nombre y los parámetros deben tener un NID de curva con nombre correspondiente establecido. Si asn1_flags es OPENSSL_EC_EXPLICIT_CURVE los parámetros se codifican explícitamente. Las funciones EC_GROUP_get_asn1_flag() y EC_GROUP_set_asn1_flag() obtienen y establecen el estado del asn1_flag para la curva. Nota: OPENSSL_EC_EXPLICIT_CURVE se añadió en OpenSSL 1.1.0, para versiones anteriores de OpenSSL debe usarse el valor 0 en su lugar. Antes de OpenSSL 1.1.0 la forma por defecto era usar parámetros explícitos (lo que significa que las aplicaciones tendrían que establecer explícitamente la forma de curva con nombre) en OpenSSL 1.1.0 y posteriores la forma de curva con nombre es la predeterminada.

El point_conversion_form para una curva controla cómo se codifican los datos EC_POINT como ASN1 según lo definido en X9.62 (ECDSA). point_conversion_form_t es un enum definido como sigue:

typedef enum {
       /** el punto se codifica como z||x, donde el octeto z especifica
        *   qué solución de la cuadrática y es  */
       POINT_CONVERSION_COMPRESSED = 2,
       /** el punto se codifica como z||x||y, donde z es el octeto 0x04  */
       POINT_CONVERSION_UNCOMPRESSED = 4,
       /** el punto se codifica como z||x||y, donde el octeto z especifica
        *  qué solución de la cuadrática y es  */
       POINT_CONVERSION_HYBRID = 6
} point_conversion_form_t;

Para POINT_CONVERSION_UNCOMPRESSED el punto se codifica como un octeto que indica que se ha usado la forma SIN COMPRIMIR seguido de los octetos para x, seguido de los octetos para y.

Para cualquier coordenada x dada de un punto en una curva es posible derivar dos valores posibles de y. Para POINT_CONVERSION_COMPRESSED el punto se codifica como un octeto que indica que se ha usado la forma COMPRIMIDA Y cuál de las dos soluciones posibles para y se ha usado, seguido de los octetos para x.

Para POINT_CONVERSION_HYBRID el punto se codifica como un octeto que indica que se ha usado la forma HÍBRIDA Y cuál de las dos soluciones posibles para y se ha usado, seguido de los octetos para x, seguido de los octetos para y.

Las funciones EC_GROUP_set_point_conversion_form() y EC_GROUP_get_point_conversion_form(), establecen y obtienen el point_conversion_form para la curva respectivamente.

ANSI X9.62 (estándar ECDSA) define un método para generar el parámetro de curva b a partir de un número aleatorio. Esto proporciona ventajas en el sentido de que un parámetro obtenido de esta manera es muy poco probable que sea susceptible a ataques de propósito especial, o que tenga alguna trampa en él. Si la semilla está presente para una curva entonces el parámetro b se generó de una manera verificable usando esa semilla. La biblioteca EC de OpenSSL no usa este valor de semilla pero sí le permite inspeccionarlo usando EC_GROUP_get0_seed(). Esto devuelve un puntero a un bloque de memoria que contiene la semilla que se usó. La longitud del bloque de memoria se puede obtener usando EC_GROUP_get_seed_len(). Un número de las curvas incorporadas en la biblioteca proporcionan valores de semilla que se pueden obtener. También es posible establecer una semilla personalizada usando EC_GROUP_set_seed() y pasando un puntero a un bloque de memoria, junto con la longitud de la semilla. De nuevo, la biblioteca EC no usará este valor de semilla, aunque se preservará en cualquier comunicación basada en ASN1.

EC_GROUP_get_degree() obtiene el grado del campo. Para campos Fp este será el número de bits en p. Para campos F2^m este será el valor m.

EC_GROUP_get_field_type() identifica qué tipo de campo soporta la estructura EC_GROUP, que será F2^m o Fp.

La función EC_GROUP_check_discriminant() calcula el discriminante para la curva y verifica que es válido. Para una curva definida sobre Fp el discriminante está dado por la fórmula 4*a^3 + 27*b^2 mientras que para curvas F2^m el discriminante es simplemente b. En cualquier caso para que la curva sea válida el discriminante debe ser distinto de cero.

La función EC_GROUP_check() se comporta de la siguiente manera: Para el prproveedor realiza una serie de comprobaciones en una curva para verificar que es válida. Las comprobaciones realizadas incluyen verificar que el discriminante no es cero; que se ha definido un generador; que el generador está en la curva y tiene el orden correcto. Para el proveedor FIPS de OpenSSL, utiliza EC_GROUP_check_named_curve() para cumplir con SP800-56Ar3.

La función EC_GROUP_check_named_curve() determina si los parámetros de dominio del grupo coinciden con una de las curvas integradas admitidas por la biblioteca. El nombre de la curva se devuelve como un NID si coincide. Si los parámetros de dominio del grupo han sido modificados, no se encontrará ninguna coincidencia. Si el nombre de la curva del grupo dado es NID_undef (por ejemplo, se ha creado utilizando parámetros explícitos sin nombre de curva), entonces este método se puede utilizar para buscar el nombre de la curva que coincide con los parámetros de dominio del grupo. Las curvas integradas contienen alias, de modo que múltiples NID's pueden mapear a los mismos parámetros de dominio. Para tales curvas, no se especifica cuál de los alias se devolverá si el nombre de la curva del grupo dado es NID_undef. Si nist_only es 1, solo buscará curvas aprobadas por NIST, de lo contrario, buscará todas las curvas integradas. Esta función puede recibir un objeto BN_CTX en el ctx parámetro. El ctx parámetro puede ser NULL.

EC_GROUP_cmp() compara a y b para determinar si representan la misma curva o no.

Las funciones EC_GROUP_get_basis_type(), EC_GROUP_get_trinomial_basis() y EC_GROUP_get_pentanomial_basis() solo deben llamarse para curvas definidas sobre un campo F2^m. Las operaciones de suma y multiplicación dentro de un campo F2^m se realizan utilizando una función de polinomio irreducible f(x). Esta función es o bien un trinomio de la forma:

f(x) = x^m + x^k + 1 con m > k >= 1

o un pentanomio de la forma:

f(x) = x^m + x^k3 + x^k2 + x^k1 + 1 con m > k3 > k2 > k1 >= 1

La función EC_GROUP_get_basis_type() devuelve un NID que identifica si se está utilizando un trinomio o un pentanomio para el campo. La función EC_GROUP_get_trinomial_basis() solo debe llamarse donde f(x) sea de la forma de trinomio, y devuelve el valor de k. De manera similar la función EC_GROUP_get_pentanomial_basis() solo debe llamarse donde f(x) sea de la forma de pentanomio, y devuelve los valores de k1, k2 y k3 respectivamente.

VALORES DE RETORNO

Las siguientes funciones devuelven 1 en caso de éxito o 0 en caso de error: EC_GROUP_copy(), EC_GROUP_set_generator(), EC_GROUP_check(), EC_GROUP_check_discriminant(), EC_GROUP_get_trinomial_basis() y EC_GROUP_get_pentanomial_basis().

EC_GROUP_dup() devuelve un puntero a la curva duplicada, o NULL en caso de error.

EC_GROUP_method_of() devuelve la implementación EC_METHOD en uso para la curva dada o NULL en caso de error.

EC_GROUP_get0_generator() devuelve el generador para la curva dada o NULL en caso de error.

EC_GROUP_get_order() devuelve 0 si el orden no está establecido (o establecido a cero) para group o si la copia en order falla, 1 en caso contrario.

EC_GROUP_get_cofactor() devuelve 0 si el cofactor no está establecido (o está establecido a cero) para group o si la copia en cofactor falla, 1 en caso contrario.

EC_GROUP_get_curve_name() devuelve el nombre de la curva (NID) para group o devolverá NID_undef si no hay un nombre de curva asociado.

EC_GROUP_get_asn1_flag() devuelve el flag ASN1 para el grupo group especificado.

EC_GROUP_get_point_conversion_form() devuelve el point_conversion_form para group.

EC_GROUP_get_degree() devuelve el grado para group o 0 si la operación no es admitida por la implementación subyacente del grupo.

EC_GROUP_get_field_type() devuelve o bien NID_X9_62_prime_field para curvas primas o NID_X9_62_characteristic_two_field para curvas binarias; estos valores están definidos en el archivo de cabecera <openssl/obj_mac.h> .

EC_GROUP_check_named_curve() devuelve el nid de la curva con nombre que coincide, de lo contrario devuelve 0 si no hay coincidencia, o -1 en caso de error.

EC_GROUP_get0_order() devuelve un puntero interno al orden del grupo. EC_GROUP_order_bits() devuelve el número de bits en el orden del grupo. EC_GROUP_get0_cofactor() devuelve un puntero interno al cofactor del grupo. EC_GROUP_get0_field() devuelve un puntero interno al campo del grupo. Para curvas sobre GF(p), este es el módulo; para curvas sobre GF(2^m), este es el polinomio irreducible que define el campo.

EC_GROUP_get0_seed() devuelve un puntero a la semilla que fue utilizada para generar el parámetro b, o NULL si la semilla no está especificada. EC_GROUP_get_seed_len() devuelve la longitud de la semilla o 0 si la semilla no está especificada.

EC_GROUP_set_seed() devuelve la longitud de la semilla que ha sido establecida. Si la semilla proporcionada es NULL, o la longitud de la semilla proporcionada es 0, el valor de retorno será 1. En caso de error se devuelve 0.

EC_GROUP_cmp() devuelve 0 si las curvas son iguales, 1 si no lo son, o -1 en caso de error.

EC_GROUP_get_basis_type() devuelve los valores NID_X9_62_tpBasis o NID_X9_62_ppBasis (como se define en <openssl/obj_mac.h>) para un trinomio o pentanomio respectivamente. Alternativamente, en caso de error se devuelve un 0.
