NOMBRE

ecryptfs-setup-private - configurar un directorio privado de eCryptfs.

SINOPSIS

ecryptfs-setup-private [-f|--force] [-w|--wrapping] [-b|--bootstrap] [-n|--no-fnek] [--nopwcheck] [-u|--username USUARIO] [-l|--loginpass CONTRASENA_LOGIN] [-m|--mountpass CONTRASENA_MONTAJE]

OPCIONES

Opciones disponibles para el comando ecryptfs-setup-private:

-f, --force
Forzar la sobrescritura de una configuración existente
-w, --wrapping
Usar una contraseña de envoltura independiente, diferente de la contraseña de inicio de sesión
-u, --username USUARIO
Usuario para configurar, por defecto es el usuario actual si se omite
-l, --loginpass CONTRASENA_LOGIN
Contraseña del sistema para USUARIO, se usa para envolver CONTRASENA_MONTAJE, solicitará interactivamente si se omite
-m, --mountpass CONTRASENA_MONTAJE
Contraseña para montar el directorio ecryptfs, por defecto son 16 bytes de /dev/random si se omite
-b, --bootstrap
Arrancar el directorio completo del hogar de un nuevo usuario
--undo
Mostrar instrucciones sobre cómo deshacer una configuración de privado cifrado
-n, --no-fnek
No cifrar nombres de archivo; de lo contrario, los nombres de archivo se cifrarán en sistemas que admitan el cifrado de nombres de archivo
--nopwcheck
No comprobar la validez de la contraseña de inicio de sesión especificada (útil para cuentas de usuario LDAP)
--noautomount
Configurar este usuario de manera que el directorio privado cifrado no se monte automáticamente al iniciar sesión
--noautoumount
Configurar este usuario de manera que el directorio privado cifrado no se desmonte automáticamente al cerrar sesión

DESCRIPCIÓN

ecryptfs-setup-private es un programa que configura un punto de montaje criptográfico privado para un usuario que no es root.

Asegúrate de escapar correctamente tus parámetros según las peculiaridades de los caracteres especiales de tu shell, y también de rodear los parámetros con comillas dobles, si es necesario. Cualquiera de los parámetros puede ser:


1) exportado como variables de entorno
2) especificado en la línea de comandos
3) dejado vacío y solicitado interactivamente

El usuario DEBE ABSOLUTAMENTE GRABAR LA CONTRASEÑA DE MONTAJE Y GUARDARLA EN UN LUGAR SEGURO. Si se pierde el archivo de la contraseña de montaje, o se olvida la contraseña de montaje, NO HAY FORMA DE RECUPERAR LOS DATOS CIFRADOS.

Utilizando los valores de USUARIO, CONTRASENA_MONTAJE y CONTRASENA_LOGIN, ecryptfs-setup-private:


- Creará ~/.Private (permiso 700)
- Creará ~/Private (permiso 500)
- Hará una copia de seguridad de las contraseñas envueltas existentes
- Usará CONTRASENA_LOGIN para envolver y cifrar CONTRASENA_MONTAJE
- Escribirá en ~/.ecryptfs/wrapped-passphrase
- Añadirá la contraseña al keyring actual
- Escribirá la firma de la contraseña en ~/.ecryptfs/Private.sig
- Probará el montaje criptográfico con algunas lecturas y escrituras

El administrador del sistema puede añadir el módulo pam_ecryptfs.so a la pila PAM, que utilizará automáticamente la contraseña de inicio de sesión para desenvolver la contraseña de montaje, añadir la contraseña al keyring del kernel del usuario y realizar el montaje automáticamente. Véase pam_ecryptfs(8).

ARCHIVOS

~/.ecryptfs/auto-mount

~/.Private - directorio subyacente que contiene datos cifrados

~/Private - punto de montaje que contiene datos descifrados (cuando está montado)

~/.ecryptfs/Private.sig - archivo que contiene la firma de la contraseña del punto de montaje

~/.ecryptfs/Private.mnt - archivo que contiene la ruta del punto de montaje del directorio privado

~/.ecryptfs/wrapped-passphrase - archivo que contiene la contraseña de montaje, envuelta con la contraseña de inicio de sesión

~/.ecryptfs/wrapping-independent - este archivo existe si la contraseña de envoltura es independiente de la contraseña de inicio de sesión
