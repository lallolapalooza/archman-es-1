ecatools(1) Software multimedia ecatools(1)

NOMBRE

ecatools - utilidades de procesamiento de audio basadas en ecasound

SINOPSIS

ecaconvert .extension archivo1 [ archivo2 ... archivoN ]

ecafixdc archivo1 [ archivo2 ... archivoN ]

ecalength archivo1 [ archivo2 ... archivoN ]

ecamonitor [host][:puerto]

ecanormalize archivo1 [ archivo2 ... archivoN ]

ecaplay [-dfhklopq] [ archivo1 archivo2 ... archivoN ]

ecasignalview [ opciones ] [ entrada ] [ salida ]

DESCRIPCIÓN

Ecatools son utilidades simples de línea de comandos para el procesamiento de archivos de audio. Cada herramienta está diseñada para realizar una operación específica. La mayoría de las herramientas también admiten procesamiento por lotes.

ECACONVERT

Una herramienta para convertir un conjunto de archivos a un formato de destino común. Este formato de destino se proporciona como el primer argumento de la línea de comandos y su sintaxis es .ext.

ECAFIXDC

Una herramienta simple de línea de comandos para corregir la compensación de CC (DC-offset).

ECALENGTH

Consulte la página del manual separada ecalength(1).

ECAMONITOR

Ecamonitor es un programa de utilidad que se puede utilizar para monitorizar una sesión activa de ecasound. Ecamonitor es capaz de mostrar información sobre la configuración de cadena actual, como la lista de entradas, salidas, posición actual, efectos, el estado del motor y numerosas cosas más.

Por defecto, ecamonitor intentará conectarse a la dirección IP4 "localhost", al puerto "2868". Se puede especificar una dirección diferente al iniciar ecamonitor, por ejemplo, "ecamonitor foo.mynetwork.com" o "ecamonitor foo.mynetwork.com:4500".

Para habilitar las conexiones entrantes, ecasound debe iniciarse con la opción --daemon. Ecamonitor está implementado en Python utilizando la API NetECI.

ECANORMALIZE

Ecanormalize es una herramienta de línea de comandos para normalizar archivos de audio y utilizar la resolución de muestra completa disponible. Ecanormalize primero determina cuánto se puede amplificar el archivo de entrada sin saturación y, si hay margen de aumento, se aplicará una ganancia estática al archivo.

ECAPLAY

Ecaplay es una herramienta de línea de comandos para reproducir archivos de audio. Ecaplay utiliza el motor libecasound y, por lo tanto, es capaz de manejar todos los formatos de audio compatibles con la biblioteca.

Los archivos se pueden seleccionar para su reproducción especificando los nombres de archivo en la línea de comandos o utilizando el mecanismo de lista de reproducción. En el modo de lista de reproducción, los archivos se pueden agregar a la lista de reproducción utilizando la opción -q. La opción -p se puede utilizar para reproducir todas las pistas de la lista de reproducción. Ecaplay repetirá las pistas de la lista de reproducción hasta que se detenga explícitamente (con doble Ctrl-C). La lista de reproducción se puede vaciar con -f y su contenido se puede listar con la opción -l.

Si no se especifica lo contrario, ecaplay utilizará el dispositivo de salida de audio especificado en ~/.ecasound/ecasoundrc para la reproducción. Se puede seleccionar un dispositivo de salida diferente con la variable de entorno shell ECAPLAY_OUTPUT_DEVICE o con la opción de línea de comandos -o:dispositivo_salida.

La reproducción se puede detener en cualquier momento con Ctrl-C. Si se reproducen varios archivos, la primera pulsación de Ctrl-C detendrá el archivo actual y pasará al siguiente. Al pulsar Ctrl-C dos veces (en un segundo), ecaplay saldrá.

-d:nivel_depuracion
Establece el nivel de depuración de libecasound. Consulte ecasound(1).
-f
Vacía el contenido de la lista de reproducción. Consulte también las opciones -l, -p y -q.
-h
Imprime información de uso y sale.
-k:numero
Omite ’número’ de archivos.
-l
Lista el contenido actual de la lista de reproducción en la salida estándar. Consulte también las opciones -f, -p y -q.
-o:dispositivo_salida
Utiliza ’dispositivo_salida’ en lugar del dispositivo de salida predeterminado (según lo especificado en ~/.ecasound/ecasoundrc). La sintaxis es la misma que la utilizada por la opción "-o" de ecasound (consulte la página del manual de ecasound(1)). Esta opción anula la variable de entorno ECAPLAY_OUTPUT_DEVICE (más información a continuación).
-p
Reproduce pistas de la lista de reproducción (en modo bucle). Consulte también las opciones -f, -l y -q.
-q
Añade nuevas pistas a la cola de la lista de reproducción. Todos los nombres de archivo proporcionados en la línea de comandos se añadirán a la lista de reproducción. Es posible añadir nuevas pistas a la cola mientras otra instancia de ecaplay está utilizando la lista de reproducción. Consulte también las opciones -f, -l y -p.
ECASIGNALVIEW

Ecasignalview está diseñado para monitorizar la amplitud de la señal y las estadísticas de picos. Acepta las siguientes opciones:

entrada
La primera opción que no empiece por un ’-’ se interpreta como una cadena de entrada. Puede ser un dispositivo o un nombre de archivo. Se aceptan todos los formatos compatibles con libecasound. El valor predeterminado es ’/dev/dsp’.
salida
De manera similar a la entrada, la segunda opción que no empiece por un ’-’ se interpreta como salida. El valor predeterminado es ’null’.
-b:tamaño_buffer
Tamaño del buffer en fotogramas de muestra. El valor predeterminado es 128.
-c
Habilita el modo acumulativo. Los contadores no se restablecen después de la actualización. *obsoleto*
-d
Habilita el modo de depuración.
-f:cadena_formato
Especifica el formato de audio predeterminado. Consulte ecasound(1) para obtener detalles.
-r:tasa_milisegundos
Especifica la tasa de actualización de la pantalla en milisegundos.
-I
Utiliza escala lineal para mostrar la amplitud de la muestra de audio.
-L
Utiliza escala logarítmica para mostrar la amplitud de la muestra de audio.
-G, -B, -M*, -r, -z
Las opciones de Ecasound se utilizan para modificar el comportamiento del motor, consulte la página del manual de ecasound(1) para obtener detalles.
Cuando ecasignalview se está ejecutando, los siguientes comandos del teclado se pueden utilizar para controlar la operación (requiere soporte del sistema para el control de la interfaz de terminal UNIX):
barra_espaciadora
Restablece las estadísticas (pico máximo, amplitud media y recuento de muestras saturadas).
q o Q o Esc
Sale de ecasignalview.
También es posible restablecer los contadores de pico máximo y de muestras saturadas enviando una señal SIGHUP al proceso (por ejemplo, desde otra consola: "killall -v -HUP ecasignalview").

Se puede encontrar documentación más completa para ecasignalview en la "Guía del usuario de Ecasound" (consulte ’’http://nosignal.fi/ecasound -> Documentación’’).

AMBIENTE

ECASOUND Ruta al ejecutable de ecasound. Utilizado por muchas herramientas de ecatools.

ECAPLAY_OUTPUT_DEVICE Dispositivo que ecaplay debe utilizar para la salida de audio. Misma sintaxis que para la opción "-o" de ecaplay/ecasound.

ARCHIVOS

~/.ecasound/ecasoundrc El archivo de recursos predeterminado de ecasound. Consulte ecasoundrc(5) para obtener detalles.

~/.ecasound/ecaplay_queue Archivo utilizado para almacenar la lista de reproducción de ecaplay (una pista por línea con ruta completa).
