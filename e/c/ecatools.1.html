Ecatools son utilidades simples de línea de comandos para el procesamiento de archivos de audio. Cada herramienta está diseñada para realizar una operación específica. La mayoría de las herramientas también admiten procesamiento por

ECAMONITO

R

Ecamonitor es un programa utilitario que se puede usar para monitorear una sesión activa de ecasound. Ecamonitor puede mostrar información sobre la configuración de cadena actual, como la lista de entradas, salidas, posición actual, efectos, el estado del motor y numerosas otras

cosas.

De forma predeterminada, ecamonitor intentará conectarse a la dirección IP4 "localhost", en el puerto "2868". Se puede especificar una dirección diferente al iniciar ecamonitor, por ejemplo "ecamonitor foo.mynetwork.com" o "ecamonitor

foo.mynetwork.com:4500".

Para habilitar conexiones entrantes, ecasound debe iniciarse con la --daemo

n

opción. Ecamonitor está implementado en Python utilizando la API

NetECI.

ECANORMALIZ

E

Ecanormalize es una herramienta de línea de comandos para normalizar archivos de audio y utilizar toda la resolución de muestreo disponible. Ecanormalize primero determina cuánto se puede amplificar el archivo de entrada sin saturar y, si hay margen para el aumento, se aplicará

una ganancia estática al archivo.

ECATOOLS(1)

NOMBRE

ecatools - una colección de herramientas de línea de comandos para ecasound.

SINOPSIS

ecatools [--help | --version | --list-plugins]

ecatools [--realtime-priority <prio>] [--realtime-group <group>] [--log-level <level>] [--no-color] [--disable-irqs] [--irq-handler-prio <prio>] [--disable-recursion] [--enable-recursion] [--no-shared-memory] [--shared-memory-size <size>] [--no-sound-server] [--sound-server <server>] [--no-rt-audio] [--rt-audio <audio>] [--no-scheduler-realtime] [--scheduler-realtime <sched>] [--no-thread-realtime] [--thread-realtime <thread>] [--set-thread-priority <prio>] [--irq-thread-priority <prio>] [--max-concurrent-processes <num>] [--max-concurrent-threads <num>] [--no-init-plugins] [--init-plugins] [--plugin-path <path>] [--no-auto-load-plugins] [--auto-load-plugins] [--config-file <file>] [--log-file <file>] [--debug-file <file>]

ecatools <command> [<args>]

DESCRIPCIÓN

ecatools es una utilidad que se utiliza para ejecutar las diversas utilidades y herramientas que forman parte del paquete ecasound. Permite realizar diversas tareas, como gestionar cadenas de audio, manipular archivos de audio y controlar el comportamiento del servidor de audio ecasound.

Las siguientes subcomandos están disponibles:

add-chain
Añade una nueva cadena al servidor ecasound.
list-chains
Lista todas las cadenas actuales en el servidor ecasound.
remove-chain
Elimina una cadena del servidor ecasound.
start-chain
Inicia una cadena en el servidor ecasound.
stop-chain
Detiene una cadena en el servidor ecasound.
add-object
Añade un objeto (por ejemplo, un archivo de audio, un efecto) a una cadena.
remove-object
Elimina un objeto de una cadena.
list-objects
Lista todos los objetos en una cadena.
set-object-param
Establece un parámetro para un objeto en una cadena.
get-object-param
Obtiene el valor de un parámetro para un objeto en una cadena.
load-config
Carga una configuración desde un archivo.
save-config
Guarda la configuración actual en un archivo.
play
Reproduce un archivo de audio.
record
Graba audio en un archivo.
convert
Convierte un archivo de audio a otro formato.

Además de estos comandos, hay varias opciones de línea de comandos que se pueden utilizar para configurar el comportamiento del servidor ecasound y de las herramientas. Estas opciones incluyen:

  • --realtime-priority: Establece la prioridad en tiempo real para los procesos de ecasound.
  • --log-level: Establece el nivel de registro para los mensajes de ecasound.
  • --no-color: Deshabilita la salida con color.
  • --plugin-path: Especifica una ruta de búsqueda de plugins adicional.
  • --config-file: Especifica un archivo de configuración para cargar.
  • --log-file: Especifica un archivo para registrar mensajes.

ENTORNO

Las siguientes variables de entorno pueden afectar a la ejecución de ecatools:

  • ECASOUND_CONFIG_DIR: Directorio donde buscar archivos de configuración.
  • ECASOUND_PLUGIN_DIR: Directorio donde buscar plugins.

ARCHIVOS

  • ~/.ecasound/config: Archivo de configuración del usuario.
  • /etc/ecasound/config: Archivo de configuración del sistema.
