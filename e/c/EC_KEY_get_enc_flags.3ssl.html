EC_KEY_get_enc_flags(3ssl)

Paquete: openssl

Licencias: Apache-2.0

EC_KEY_GET_ENC_FLAGS(3ssl) OpenSSL EC_KEY_GET_ENC_FLAGS(3ssl)

NOMBRE

EC_KEY_get_enc_flags, EC_KEY_set_enc_flags - Obtener y establecer indicadores para la codificación de estructuras EC_KEY

SINOPSIS

#include <openssl/ec.h>
unsigned int EC_KEY_get_enc_flags(const EC_KEY *key);
void EC_KEY_set_enc_flags(EC_KEY *eckey, unsigned int flags);

DESCRIPCIÓN

El formato de la representación externa de la clave pública escrita por i2d_ECPrivateKey() (por ejemplo, si está almacenada en forma comprimida o no) se describe mediante el punto_conversion_form. Consulte EC_GROUP_copy(3) para una descripción de punto_conversion_form.

Al leer una clave privada codificada sin una clave pública asociada (por ejemplo, si se ha utilizado EC_PKEY_NO_PUBKEY - ver más abajo), d2i_ECPrivateKey() genera la clave pública que falta automáticamente. Las claves privadas codificadas sin parámetros (por ejemplo, si se ha utilizado EC_PKEY_NO_PARAMETERS - ver más abajo) no pueden cargarse con d2i_ECPrivateKey().

Las funciones EC_KEY_get_enc_flags() y EC_KEY_set_enc_flags() obtienen y establecen el valor de los indicadores de codificación para la key. Actualmente hay dos indicadores de codificación definidos: EC_PKEY_NO_PARAMETERS y EC_PKEY_NO_PUBKEY. Estos indicadores definen el comportamiento de cómo la key se convierte a ASN1 en una llamada a i2d_ECPrivateKey(). Si se establece EC_PKEY_NO_PARAMETERS, los parámetros públicos de la curva no se codifican junto con la clave privada. Si se establece EC_PKEY_NO_PUBKEY, la clave pública no se codifica junto con la clave privada.

VALORES DE RETORNO

EC_KEY_get_enc_flags() devuelve el valor de los indicadores de codificación actuales para el EC_KEY.
