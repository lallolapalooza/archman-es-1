NOMBRE

ecl-config - Consulta de configuración de Common Lisp incrustable

SINOPSIS

ecl-config [-cflags] [-libs] [-ldflags] [ LIBS]

DESCRIPCIÓN

ecl-config devolverá a través de la salida estándar el conjunto de banderas del compilador o enlazador necesarias para construir aplicaciones que incrustan ecl.

OPCIONES

-cflags
Devuelve las banderas necesarias para compilar un archivo C/C++.
-libs
-ldflags
Devuelve las banderas del enlazador necesarias para construir una aplicación C/C++ o una biblioteca compartida.
LIBS
Cuando también se usa -ldflags, también se agrega la biblioteca cmp (compilador).

BUGS

Probablemente algunos. ¡Repórtalos!
