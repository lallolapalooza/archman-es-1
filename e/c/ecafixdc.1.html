DESCRIPCIÓN

Ecatools son sencillas utilidades de línea de comandos para el procesamiento de archivos de audio. Cada herramienta está diseñada para realizar una operación específica. La mayoría de las herramientas también admiten procesamiento por

lotes.

T

sintaxis es

ECAMONITO

R

Ecamonitor es un programa utilitario que se puede usar para monitorizar una sesión activa de ecasound. Ecamonitor es capaz de mostrar información sobre la configuración de cadena actual, como la lista de entradas, salidas, posición actual, efectos, el estado del

motor y numerosas otras cosas.

Por defecto, ecamonitor intentará conectarse a la dirección IP4 "localhost", en el puerto "2868". Se puede especificar una dirección diferente al iniciar ecamonitor, por ejemplo "ecamonitor foo.mynetwork.com" o "ecamonitor foo.mynetwork.com:4500". Para habilitar conexiones entrantes, ecasound debe

iniciarse con la

opción

--daemon

. Ecamonitor está implementado en Python utilizando la API

NetECI.

ECANORMALIZ

E

Ecanormalize es una herramienta de línea de comandos para normalizar archivos de audio para utilizar toda la resolución de muestreo disponible. Ecanormalize primero averigua cuánto se puede amplificar el archivo de entrada sin que haya recorte y si hay margen de aumento, se aplicará una ganancia estática al

archivo.

ECAPLA

Y

Ecaplay es una herramienta de línea de comandos para reproducir archivos de audio. Ecaplay utiliza el motor libecasound y por lo tanto es capaz de manejar todos los formatos de audio admitidos por la

biblioteca.

Los archivos pueden seleccionarse para la reproducción ya sea especificando los nombres de archivo en la línea de comandos, o utilizando el mecanismo de lista de reproducción. En el modo de lista de reproducción, se pueden añadir archivos a la lista de reproducción utilizando

la

opción -q . La opción

-p

se puede usar entonces para reproducir todas las pistas de la lista de reproducción. Ecaplay repetirá las pistas de la lista de reproducción hasta que se detenga explícitamente (con doble Ctrl-C). La lista de reproducción

se puede vaciar con

-

f

y su contenido se puede listar

con la

opción

-l

. Si no se especifica lo contrario, ecaplay utilizará el dispositivo de salida de audio especificado en ~/.ecasound/ecasoundrc para la reproducción. Se puede seleccionar un dispositivo de salida diferente con la variable de entorno del shell ECAPLAY_OUTPUT_DEVICE o con la opción -o:

output_device

de la línea de comandos. La reproducción se puede detener en cualquier momento con Ctrl-C. Si se reproducen varios archivos, el primer Ctrl-C detendrá el archivo actual y pasará a reproducir el siguiente. Emitir Ctrl-C dos veces (dentro de un segundo), hará que ecaplay salga. -d:nivel_de_depuración Establece el nivel de depuración de libecasound. Consulte ecasound(1).
