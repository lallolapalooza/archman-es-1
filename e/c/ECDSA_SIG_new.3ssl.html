ECDSA_SIG_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ECDSA_SIG_NEW(3ssl) OpenSSL ECDSA_SIG_NEW(3ssl)

NOMBRE

ECDSA_SIG_new, ECDSA_SIG_free, ECDSA_SIG_get0, ECDSA_SIG_get0_r, ECDSA_SIG_get0_s, ECDSA_SIG_set0 - Funciones para crear, destruir y manipular objetos ECDSA_SIG

SINOPSIS

#include <openssl/ecdsa.h>
ECDSA_SIG *ECDSA_SIG_new(void);
void ECDSA_SIG_free(ECDSA_SIG *sig);
void ECDSA_SIG_get0(const ECDSA_SIG *sig, const BIGNUM **pr, const BIGNUM **ps);
const BIGNUM *ECDSA_SIG_get0_r(const ECDSA_SIG *sig);
const BIGNUM *ECDSA_SIG_get0_s(const ECDSA_SIG *sig);
int ECDSA_SIG_set0(ECDSA_SIG *sig, BIGNUM *r, BIGNUM *s);

DESCRIPCIÓN

ECDSA_SIG es una estructura opaca que consta de dos BIGNUMs para los valores r y s de una firma del Algoritmo de Firma Digital de Curva Elíptica (ECDSA) (ver FIPS186-4 o X9.62). El objeto ECDSA_SIG fue utilizado principalmente por las funciones de bajo nivel obsoletas descritas en ECDSA_sign(3), todavía se requiere para poder establecer o obtener los valores de r y s dentro o desde una firma. Esto se utiliza principalmente con fines de prueba, como se muestra en "EJEMPLOS".

ECDSA_SIG_new() asigna una estructura ECDSA_SIG vacía. Nota: antes de OpenSSL 1.1.0, los componentes r y s se inicializaban.

ECDSA_SIG_free() libera la estructura ECDSA_SIG sig. Si el argumento es NULL, no se hace nada.

ECDSA_SIG_get0() devuelve punteros internos a los valores r y s contenidos en sig y los almacena en *pr y *ps, respectivamente. El puntero pr o ps puede ser NULL, en cuyo caso el valor correspondiente no se devuelve.

Los valores r, s también se pueden recuperar por separado mediante las funciones correspondientes ECDSA_SIG_get0_r() y ECDSA_SIG_get0_s(), respectivamente.

Se pueden establecer valores r y s no NULL en sig llamando a ECDSA_SIG_set0(). Llamar a esta función transfiere la gestión de memoria de los valores al objeto ECDSA_SIG y, por lo tanto, los valores pasados no deben ser liberados por el llamador.

Ver i2d_ECDSA_SIG(3) y d2i_ECDSA_SIG(3) para información sobre la codificación y decodificación de firmas ECDSA a/desde DER.

VALORES DE RETORNO

ECDSA_SIG_new() devuelve NULL si la asignación falla.

ECDSA_SIG_set0() devuelve 1 en caso de éxito o 0 en caso de fallo.

ECDSA_SIG_get0_r() y ECDSA_SIG_get0_s() devuelven el valor correspondiente, o NULL si no está establecido.

EJEMPLOS

Extraer los valores r y s de la firma de una firma ECDSA de tamaño signaturelen:

ECDSA_SIG *obj;
const BIGNUM *r, *s;
/* Cargar una firma en el objeto ECDSA_SIG */
obj = d2i_ECDSA_SIG(NULL, &signature, signaturelen);
if (obj == NULL)
    /* error */
r = ECDSA_SIG_get0_r(obj);
s = ECDSA_SIG_get0_s(obj);
if (r == NULL || s == NULL)
    /* error */
/* Usar BN_bn2binpad() aquí para convertir en arrays de bytes r y s */
/*
 * No intente acceder a I<r> o I<s> después de llamar a ECDSA_SIG_free(),
 * ya que ambos son liberados por esta llamada.
 */
ECDSA_SIG_free(obj);

Convertir arrays de bytes r y s en una firma ECDSA de tamaño signaturelen:

ECDSA_SIG *obj = NULL;
unsigned char *signature = NULL;
size_t signaturelen;
BIGNUM *rbn = NULL, *sbn = NULL;
obj = ECDSA_SIG_new();
if (obj == NULL)
    /* error */
rbn = BN_bin2bn(r, rlen, NULL);
sbn = BN_bin2bn(s, slen, NULL);
if (rbn == NULL || sbn == NULL)
    /* error */
if (!ECDSA_SIG_set0(obj, rbn, sbn))
    /* error */
/* Establecer estos a NULL ya que ahora son propiedad de obj */
rbn = sbn = NULL;
signaturelen = i2d_ECDSA_SIG(obj, &signature);
if (signaturelen <= 0)
    /* error */
/*
 * Esta firma podría ahora pasarse a L<EVP_DigestVerify(3)>
 * o L<EVP_DigestVerifyFinal(3)>
 */
BN_free(rbn);
BN_free(sbn);
OPENSSL_free(signature);
ECDSA_SIG_free(obj);
