echo(1)

Paquete: coreutils

Licencias: GPL-3.0-or-later, GFDL-1.3-or-later

ECHO(1) Comandos de usuario ECHO(1)

NOMBRE

echo - mostrar una línea de texto

SINOPSIS

echo [OPCIÓN-CORTA]... [CADENA]...
echo OPCIÓN-LARGA

DESCRIPCIÓN

Muestra la(s) CADENA(S) en la salida estándar.

-n
no mostrar la nueva línea final
-e
habilitar la interpretación de secuencias de escape con barra invertida
-E
deshabilitar la interpretación de secuencias de escape con barra invertida (por defecto)
--help
mostrar esta ayuda y salir
--version
mostrar información de versión y salir

Si -e está activo, se reconocen las siguientes secuencias:

\\
barra invertida
\a
alerta (BEL)
\b
retroceso (backspace)
\c
no producir más salida
\e
escape
\f
salto de página (form feed)
\n
nueva línea
\r
retorno de carro (carriage return)
\t
tabulación horizontal
\v
tabulación vertical
\0NNN
byte con valor octal NNN (1 a 3 dígitos)
\xHH
byte con valor hexadecimal HH (1 a 2 dígitos)

Es posible que tu shell tenga su propia versión de echo, que generalmente reemplaza a la versión descrita aquí. Por favor, consulta la documentación de tu shell para obtener detalles sobre las opciones que soporta.

Considera usar el comando printf(1) en su lugar, ya que evita problemas al mostrar cadenas que parecen opciones.
