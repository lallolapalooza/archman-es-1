NOMBRE

ecryptfs-recover-private - encontrar y montar directorios privados cifrados

SINOPSIS

ecryptfs-recover-private [--rw] [directorio privado cifrado]

DESCRIPCIÓN

Esta utilidad está diseñada para ayudar a eCryptfs a recuperar datos de sus directorios privados cifrados o particiones cifradas. Es útil ejecutar esto desde un LiveISO o una imagen de recuperación. Debe ejecutarse bajo sudo(8) o con permisos de root, para poder buscar en el sistema de archivos y realizar los montajes.

El programa puede tomar un directorio cifrado como objetivo en la línea de comandos. Si no se especifica, la utilidad buscará en todo el sistema directorios privados cifrados, según la configuración de ecryptfs-setup-private(1).

Si se encuentran un directorio cifrado y un archivo wrapped-passphrase, se le pedirá al usuario la contraseña de inicio de sesión (envoltorio), las claves se insertarán en el keyring y los datos se descifrarán y montarán.

Si no se encuentra el archivo wrapped-passphrase, se le pedirá al usuario su contraseña de montaje. Esta contraseña suele ser de 32 caracteres [0-9a-f]. Se pide a todos los usuarios que anoten urgentemente esta contraseña generada aleatoriamente cuando configuran por primera vez su directorio privado cifrado.

El punto de montaje de los datos descifrados es un directorio temporal, con la forma /tmp/ecryptfs.XXXXXXXX.

Por defecto, el montaje será de solo lectura. Para montar con permisos de lectura y escritura, añada el parámetro --rw.
