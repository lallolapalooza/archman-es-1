NOMBRE

ecatools - utilidades de procesamiento de audio basadas en ecasound

SINOPSIS

ecaconvert .extensión archivo1 [ archivo2 ... archivoN ]

ecafixdc archivo1 [ archivo2 ... archivoN ]

ecalength archivo1 [ archivo2 ... archivoN ]

ecamonitor [host][:puerto]

ecanormalize archivo1 [ archivo2 ... archivoN ]

ecaplay [-dfhklopq] [ archivo1 archivo2 ... archivoN ]

ecasignalview [ opciones ] [ entrada ] [ salida ]

DESCRIPCIÓN

Ecatools son utilidades sencillas de línea de comandos para el procesamiento de archivos de audio. Cada herramienta está diseñada para realizar una operación específica. La mayoría de las herramientas también admiten el procesamiento por lotes.

ECACONVERT

Una herramienta para convertir un conjunto de archivos a un formato destino común. Este formato de destino se proporciona como el primer argumento de línea de comandos, y su sintaxis es .ext.

ECAFIXDC

Una herramienta sencilla de línea de comandos para corregir la compensación de CC.

ECALENGTH

Ver la página del manual separada de ecalength(1).

ECAMONITOR

Ecamonitor es un programa de utilidad que se puede utilizar para monitorear una sesión activa de ecasound. Ecamonitor puede mostrar información sobre la configuración de la cadena actual, como la lista de entradas, salidas, posición actual, efectos, el estado del motor y numerosas cosas más.

Por defecto, ecamonitor intentará conectarse a la dirección IP4 "localhost", al puerto "2868". Se puede especificar una dirección diferente al iniciar ecamonitor, por ejemplo, "ecamonitor foo.mynetwork.com" o "ecamonitor foo.mynetwork.com:4500".

Para habilitar las conexiones entrantes, ecasound debe iniciarse con la opción --daemon. Ecamonitor está implementado en Python utilizando la API NetECI.

ECANORMALIZE

Ecanormalize es una herramienta de línea de comandos para normalizar archivos de audio y utilizar toda la resolución de muestra disponible. Ecanormalize primero determina cuánto se puede amplificar el archivo de entrada sin distorsión y, si hay margen para aumentar, se aplicará una ganancia estática al archivo.

ECAPLAY

Ecaplay es una herramienta de línea de comandos para reproducir archivos de audio. Ecaplay utiliza el motor libecasound y, por lo tanto, puede manejar todos los formatos de audio compatibles con la biblioteca.

Los archivos se pueden seleccionar para su reproducción especificando los nombres de archivo en la línea de comandos o utilizando el mecanismo de lista de reproducción. En el modo de lista de reproducción, los archivos se pueden agregar a la lista de reproducción con la opción -q. La opción -p se puede usar para reproducir todas las pistas de la lista de reproducción. Ecaplay repetirá las pistas de la lista de reproducción hasta que se detenga explícitamente (con doble Ctrl-C). La lista de reproducción se puede vaciar con -f y su contenido se puede listar con la opción -l.

Si no se especifica lo contrario, ecaplay utilizará el dispositivo de salida de audio especificado en ~/.ecasound/ecasoundrc para la reproducción. Se puede seleccionar un dispositivo de salida diferente con la variable de entorno de shell ECAPLAY_OUTPUT_DEVICE o con la opción de línea de comandos -o:dispositivo_salida.

La reproducción se puede detener en cualquier momento con Ctrl-C. Si se reproducen varios archivos, el primer Ctrl-C detendrá el archivo actual y pasará al siguiente. Al pulsar Ctrl-C dos veces (en un segundo), ecaplay saldrá.

-d:nivel_depuracion
Establece el nivel de depuración de libecasound. Ver ecasound(1).
-f
Vacía el contenido de la lista de reproducción. Ver también las opciones -l, -p y -q.
-h
Imprime información de uso y sale.
-k:numero
Omite ’numero’ de archivos.
-l
Lista el contenido actual de la lista de reproducción en la salida estándar. Ver también las opciones -f, -p y -q.
-o:dispositivo_salida
Utiliza ’dispositivo_salida’ en lugar del dispositivo de salida predeterminado (como se especifica en ~/.ecasound/ecasoundrc). La sintaxis es la misma que la utilizada por la opción "-o" de ecasound (ver la página del manual de ecasound(1)). Esta opción anula la variable de entorno ECAPLAY_OUTPUT_DEVICE (más información a continuación).
-p
Reproduce pistas en la lista de reproducción (en modo de bucle). Ver también las opciones -f, -l y -q.
-q
Añade nuevas pistas a la cola de la lista de reproducción. Todos los nombres de archivo proporcionados en la línea de comandos se añadirán a la lista de reproducción. Es posible añadir nuevas pistas mientras otra instancia de ecaplay está utilizando la lista de reproducción. Ver también las opciones -f, -l y -p.
ECASIGNALVIEW

Ecasignalview está diseñado para monitorizar la amplitud de la señal y las estadísticas de los picos. Acepta las siguientes opciones:

entrada
La primera opción que no comienza con un ’-’ se interpreta como una cadena de entrada. Puede ser un dispositivo o un nombre de archivo. Se aceptan todos los formatos compatibles con libecasound. El valor predeterminado es ’/dev/dsp’.
salida
De manera similar a la entrada, la segunda opción que no comienza con un ’-’ se interpreta como salida. El valor predeterminado es ’null’.
-b:tamano_buffer
Tamaño del búfer en fotogramas de muestra. El valor predeterminado es 128.
-c
Habilita el modo acumulativo. Los contadores no se reinician después de la actualización. *obsoleto*
-d
Habilita el modo de depuración.
-f:cadena_formato
Especifica el formato de audio predeterminado. Ver ecasound(1) para más detalles.
-r:tasa_milisegundos
Especifica la tasa de actualización de la pantalla en milisegundos.
-I
Utiliza escala lineal para mostrar la amplitud de la muestra de audio.
-L
Utiliza escala logarítmica para mostrar la amplitud de la muestra de audio.
-G, -B, -M*, -r, -z
Las opciones de Ecasound se utilizan para modificar el comportamiento del motor, ver la página del manual de ecasound(1) para más detalles.
Cuando ecasignalview se está ejecutando, los siguientes comandos del teclado se pueden utilizar para controlar la operación (requiere soporte del sistema para el control de la interfaz de terminal UNIX):
barra_espaciadora
Reinicia las estadísticas (pico máximo, amplitud media y recuento de muestras recortadas).
q o Q o Esc
Sale de ecasignalview.
También es posible reiniciar los contadores de pico máximo y muestras recortadas enviando una señal SIGHUP al proceso (es decir, desde otra consola: "killall -v -HUP ecasignalview").

La documentación más completa para ecasignalview se puede encontrar en la "Guía del usuario de Ecasound" (ver ’’http://nosignal.fi/ecasound -> Documentación’’).

AMBIENTE

ECASOUND Ruta al ejecutable de ecasound. Utilizado por muchas herramientas de ecatools.

ECAPLAY_OUTPUT_DEVICE Dispositivo que ecaplay debe usar para la salida de audio. Misma sintaxis que para la opción "-o" de ecaplay/ecasound.

ARCHIVOS

~/.ecasound/ecasoundrc El archivo de recursos predeterminado de ecasound. Ver ecasoundrc(5) para más detalles.

~/.ecasound/ecaplay_queue Archivo utilizado para almacenar la lista de reproducción de ecaplay (una pista por línea con ruta completa).
