Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; consulte VERSIONS.

DESCRIPCIÓN

Estas macros definen y operan sobre colas de lista enlazada simple con cola.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola de lista enlazada simple con cola está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simple para minimizar el consumo de espacio y la manipulación de punteros, a expensas de una eliminación de O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola. Un puntero a la cabecera de la cola se puede declarar posteriormente como:


struct NOMBRE_CABECERA *puntero_cabecera;

(Los nombres cabecera y puntero_cabecera son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

STAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola cabecera.

STAILQ_INIT() inicializa la cola referenciada por cabecera.

STAILQ_EMPTY() evalúa a verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por cabecera en dirección hacia adelante, asignando cada elemento en turno a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elem de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola cabecera.

VERSIONES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se llamaron de manera diferente en distintos BSD. STAILQ se originó en FreeBSD, y SIMPLEQ en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticas excepto por una falta de equivalente SIMPLEQ a STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, corrige esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* Cola de lista enlazada simple */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Cabecera de cola de lista enlazada simple */
    STAILQ_INIT(&head);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Eliminación del principio */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
 
    /* Recorrer la cola */
    STAILQ_FOREACH(np, &head, entries) {
        printf("%d ", np->data);
    }
    printf("\n");
    /* Eliminar todos los elementos */
    while (!STAILQ_EMPTY(&head)) {
        STAILQ_REMOVE_HEAD(&head, entries);
    }
    return 0;
}

DESCRIPCIÓN

Estas macros definen e implementan una cola doblemente enlazada de forma segura para hilos. Una cola doblemente enlazada es una lista enlazada en la que cada elemento contiene un puntero al siguiente elemento y un puntero al elemento anterior. Los punteros `next' y `prev' son utilizados para permitir la inserción y eliminación eficientes en cualquier parte de la lista.

Las listas doblemente enlazadas no se pueden recorrer en orden inverso de forma eficiente. Para obtener un recorrido en orden inverso, se deben usar listas de cola doblemente enlazadas.

Antes de que se pueda usar una lista, se debe inicializar utilizando la macro SIMPLEQ_INIT. La macro SIMPLEQ_INIT toma un puntero a la cabeza de la cola como argumento, y la inicializa para que esté vacía.

El siguiente ejemplo muestra cómo inicializar una lista y agregar un elemento al final de la lista:

    struct my_list {
        int data;
        SIMPLEQ_ENTRY(my_list) entries;
    } my_list;
    struct my_list *np;
    SIMPLEQ_HEAD(my_list_head, my_list) head;
    SIMPLEQ_INIT(&head);
    np = malloc(sizeof(struct my_list));
    np->data = 1;
    SIMPLEQ_INSERT_TAIL(&head, np, entries);

La macro SIMPLEQ_INSERT_TAIL agrega el elemento elm al final de la cola especificada por head. El miembro de enlace de elm se especifica por el parámetro entries.

La macro SIMPLEQ_INSERT_HEAD agrega el elemento elm al principio de la cola especificada por head.

La macro SIMPLEQ_INSERT_AFTER inserta el elemento elm después del elemento elm_prev en la cola especificada por head.

La macro SIMPLEQ_INSERT_BEFORE inserta el elemento elm antes del elemento elm_prev en la cola especificada por head.

La macro SIMPLEQ_REMHead elimina y devuelve el primer elemento de la cola especificada por head. Si la cola está vacía, devuelve NULL.

La macro SIMPLEQ_REMTAIL elimina y devuelve el último elemento de la cola especificada por head. Si la cola está vacía, devuelve NULL.

La macro SIMPLEQ_CONCAT anexa la cola head2 al final de la cola head1. Después de la operación, head2 estará vacía.

Las siguientes macros se pueden usar para recorrer una cola:

SIMPLEQ_FIRST(head): Devuelve un puntero al primer elemento de la cola, o NULL si la cola está vacía.

SIMPLEQ_NEXT(elm, field): Devuelve un puntero al siguiente elemento después de elm en la cola, o NULL si elm es el último elemento.

SIMPLEQ_FOREACH(var, head): Itera sobre cada elemento var en la cola head.

SIMPLEQ_EMPTY(head): Devuelve verdadero si la cola está vacía, falso en caso contrario.

VALOR DE RETORNO

SIMPLEQ_REMHead y SIMPLEQ_REMTAIL devuelven un puntero al elemento eliminado, o NULL si la cola estaba vacía.

VERSIONES

Las macros SIMPLEQ_* aparecieron por primera vez en FreeBSD 3.0.

ERRORES

No se conocen errores.

EJEMPLOS

El siguiente código de ejemplo muestra cómo usar las macros SIMPLEQ_INSERT_TAIL, SIMPLEQ_FOREACH, SIMPLEQ_REMHead y SIMPLEQ_INIT.

                                            /* Recorrido forward */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                             /* Eliminación de TailQ */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
