Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TIPO);
STAILQ_HEAD(NOMBRE_DE_CABECERA, TIPO);

                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *cabeza, struct TIPO *elemento_lista,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
struct TIPO *STAILQ_FIRST(STAILQ_HEAD *cabeza);
struct TIPO *STAILQ_NEXT(struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
STAILQ_FOREACH(struct TIPO *variable, STAILQ_HEAD *cabeza, STAILQ_ENTRY NOMBRE);

                         STAILQ_ENTRY NOMBRE);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; consulte VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas enlazadas simples con cola.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_DE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola enlazada simple con cola está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y el otro al último elemento de la cola. Los elementos están enlazados de forma simple para una mínima sobrecarga de manipulación de punteros y espacio, a costa de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden agregar a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_DE_CABECERA, TIPO) cabeza;

donde struct NOMBRE_DE_CABECERA es la estructura que se va a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:


struct NOMBRE_DE_CABECERA *puntero_a_cabeza;

(Los nombres cabeza y puntero_a_cabeza son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

STAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabeza.

STAILQ_INIT() inicializa la cola referenciada por cabeza.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elemento al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elemento al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elemento después del elemento elemento_lista.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por cabeza en la dirección hacia adelante, asignando cada elemento en turno a variable.

Eliminación

STAILQ_REMOVE() elimina el elemento elemento de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cola cabeza.

VERSIONES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se llamaron de manera diferente en diferentes BSD. STAILQ se originó en FreeBSD, y SIMPLEQ se originó en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por una equivalente a STAILQ_CONCAT() faltante para SIMPLEQ.

ERRORES

STAILQ_FOREACH() no permite que variable sea eliminada o liberada dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que variable se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* Cola enlazada simple con cola */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Cabeza de cola enlazada simple
                                               con cola */
    STAILQ_INIT(&head);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Eliminación del principio */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

DESCRIPTION

These macros provide an implementation of simple singly linked lists. A simple singly linked list is one in which each element contains a pointer to the next element in the list. The end of the list is indicated by a NULL pointer.

A singly linked list is declared using the SIMPLEQ_HEAD macro. This macro declares a structure named headname which will serve as the head of the list. The second argument, type, is the name of the structure that represents the list elements. Each list element structure must contain an instance of the SIMPLEQ_ENTRY macro (or SLIST_ENTRY, see below). The SIMPLEQ_ENTRY macro takes two arguments: the name of the head structure and the name of the entry member within the element structure.

For example:

struct my_list_element {
    int data;
    SIMPLEQ_ENTRY(my_list_element) next;
};
SIMPLEQ_HEAD(my_list_head, my_list_element);

This declares a list head structure named struct my_list_head and a list element structure named struct my_list_element. The list element structure contains a member named next which is used by the list macros to link elements together.

The SIMPLEQ_HEAD_INITIALIZER macro can be used to initialize a list head variable. Alternatively, the SIMPLEQ_INIT macro can be used to initialize an empty list.

The macros SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_BEFORE, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, and SIMPLEQ_REMOVE_TAIL manipulate the list.

SIMPLEQ_INSERT_AFTER inserts the element elm after the element listelm.

SIMPLEQ_INSERT_BEFORE inserts the element elm before the element listelm.

SIMPLEQ_INSERT_HEAD inserts the element elm at the head of the list.

SIMPLEQ_INSERT_TAIL inserts the element elm at the tail of the list.

SIMPLEQ_REMOVE removes the element elm from the list.

SIMPLEQ_REMOVE_HEAD removes and returns the head element of the list.

SIMPLEQ_REMOVE_TAIL removes and returns the tail element of the list.

SIMPLEQ_CONCAT concatenates two lists, appending list head2 to the end of list head1. List head2 will be empty after the operation.

The macros SIMPLEQ_FIRST, SIMPLEQ_LAST, SIMPLEQ_NEXT, SIMPLEQ_PREV, SIMPLEQ_END, and SIMPLEQ_EMPTY are used to traverse the list.

SIMPLEQ_FIRST returns the first element in the list.

SIMPLEQ_LAST returns the last element in the list.

SIMPLEQ_NEXT returns the next element in the list.

SIMPLEQ_PREV returns the previous element in the list. Note that this is only valid if the list is implemented as a doubly linked list.

SIMPLEQ_END returns the end of the list, which is a sentinel value that is not a valid list element.

SIMPLEQ_EMPTY returns true if the list is empty, false otherwise.

The macros SIMPLEQ_FOREACH, SIMPLEQ_FOREACH_SAFE, SIMPLEQ_FOREACH_REVERSE, and SIMPLEQ_FOREACH_REVERSE_SAFE provide convenient ways to iterate over the list. The _SAFE variants are designed to allow safe removal of elements during iteration.

The macros SIMPLEQ_PEEK_HEAD and SIMPLEQ_PEEK_TAIL return the head and tail elements respectively, without removing them from the list.

The sys/queue.h header also defines SLIST_HEAD, SLIST_ENTRY, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_BEFORE, SLIST_INSERT_HEAD, SLIST_INSERT_TAIL, SLIST_REMOVE, SLIST_REMOVE_HEAD, SLIST_REMOVE_TAIL, SLIST_CONCAT, SLIST_FIRST, SLIST_NEXT, SLIST_END, SLIST_EMPTY, SLIST_FOREACH, SLIST_FOREACH_SAFE, SLIST_PEEK_HEAD, and SLIST_PEEK_TAIL macros, which implement the same functionality as their SIMPLEQ_ counterparts. The SLIST_ macros are the preferred interface.

RETURN VALUE

The insertion and removal macros do not return values. The traversal macros return pointers to list elements or the end-of-list sentinel.

VERSIONS

These macros have been available since FreeBSD 2.0.

BUGS

The SIMPLEQ_PREV macro is not provided for singly linked lists. The SIMPLEQ_FOREACH_REVERSE and SIMPLEQ_FOREACH_REVERSE_SAFE macros are inefficient as they require traversing the list from the beginning on each step.

STANDARDS

These macros are not part of any standard.

HISTORY

The list macros first appeared in 4.4BSD-Lite.

EXAMPLES

The following example demonstrates how to use the SIMPLEQ_ macros to create, populate, and traverse a simple singly linked list:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    SIMPLEQ_ENTRY(node) entries;
};

SIMPLEQ_HEAD(my_list_head, node);

int
main() {
    struct my_list_head head;
    struct node *np, *n1, *n2;

    /* Initialize the list */
    SIMPLEQ_INIT(&head);

    /* Create and insert nodes */
    np = malloc(sizeof(struct node));
    np->data = 10;
    SIMPLEQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct node));
    np->data = 20;
    SIMPLEQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct node));
    np->data = 30;
    SIMPLEQ_INSERT_TAIL(&head, np, entries);

                                    /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
