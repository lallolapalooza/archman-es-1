                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);

                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; véase VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas enlazadas simples con cola.

En las definiciones de macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABEZA es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola enlazada simple con cola está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden agregar a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_CABEZA, TIPO) cabeza;

donde struct NOMBRE_CABEZA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:


struct NOMBRE_CABEZA *cabezap;

(Los nombres cabeza y cabezap son seleccionables por el usuario).

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

STAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabeza.

STAILQ_INIT() inicializa la cola a la que hace referencia cabeza.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento listelm.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por cabeza en dirección hacia adelante, asignando cada elemento en turno a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elm de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cola cabeza.

VERSIONES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se nombraron de manera diferente en diferentes BSD. STAILQ se originó en FreeBSD, y SIMPLEQ se originó en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por la falta de un equivalente SIMPLEQ para STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

ESTNDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* Cola enlazada simple con cola */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Cabeza de cola enlazada simple con cola */
    STAILQ_INIT(&head);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Eliminación del principio */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

DESCRIPTION

These macros and functions implement a simple singly linked queue data structure.

SIMPLEQ_HEAD is a macro that declares a queue head.

SIMPLEQ_INIT initializes the queue pointed to by head.

SIMPLEQ_ADD_HEAD inserts entry at the head of the queue.

SIMPLEQ_ADD_TAIL inserts entry at the tail of the queue.

SIMPLEQ_FOREACH iterates over the elements in the queue.

SIMPLEQ_FIRST returns the first element in the queue.

SIMPLEQ_NEXT returns the next element in the queue.

SIMPLEQ_LAST returns the last element in the queue.

SIMPLEQ_PREV returns the element before entry in the queue.

SIMPLEQ_REMOVE removes entry from the queue.

SIMPLEQ_CONCAT concatenates head2 to the end of head1.

RETURN VALUE

simpleq_add_head and simpleq_add_tail return the added entry.

simpleq_first, simpleq_next, simpleq_last, simpleq_prev, and simpleq_remove return pointers to struct simpleq_entry or NULL.

VERSIONS

These functions first appeared in NetBSD 1.3.

BUGS

There are no known bugs.

STANDARDS

These macros and functions are not part of any standard.

HISTORY

The SIMPLEQ_* macros were implemented in NetBSD.

EXAMPLES

The following example demonstrates how to use the SIMPLEQ_* macros to implement a simple stack.

#include <stdio.h>
#include <stdlib.h>
#include <simpleq.h>

struct node {
    int data;
    struct simpleq_entry entries;
};

int
main(void)
{
    struct simpleq_head head;
    struct simpleq_entry *np;
    struct node *n1, *n2;

    /* Initialize the queue */
    simpleq_init(&head);

    /* Add elements to the queue */
    n1 = malloc(sizeof(struct node));
    n1->data = 1;
    simpleq_add_tail(&head, &n1->entries);

    n1 = malloc(sizeof(struct node));
    n1->data = 2;
    simpleq_add_tail(&head, &n1->entries);

    n1 = malloc(sizeof(struct node));
    n1->data = 3;
    simpleq_add_tail(&head, &n1->entries);

    /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
