STAILQ(3) Manual de funciones de biblioteca STAILQ(3)

NOMBRE

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implementación de una cola de cola enlazada simple

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TIPO);
STAILQ_HEAD(NOMBRE_DE_CABECERA, TIPO);
STAILQ_HEAD NOMBRE_DE_CABECERA STAILQ_HEAD_INITIALIZER(STAILQ_HEAD cabecera);
void STAILQ_INIT(STAILQ_HEAD *cabecera);
int STAILQ_EMPTY(STAILQ_HEAD *cabecera);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *cabecera,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *cabecera,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *cabecera, struct TIPO *elemento_lista,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
struct TIPO *STAILQ_FIRST(STAILQ_HEAD *cabecera);
struct TIPO *STAILQ_NEXT(struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
STAILQ_FOREACH(struct TIPO *variable, STAILQ_HEAD *cabecera, STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE(STAILQ_HEAD *cabecera, struct TIPO *elemento, TIPO,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *cabecera,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_CONCAT(STAILQ_HEAD *cabecera1, STAILQ_HEAD *cabecera2);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; véase VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas de cola enlazadas simples.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_DE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola de cola enlazada simple está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola de cola y otro al último elemento de la cola de cola. Los elementos están enlazados de forma simple para un mínimo de espacio y sobrecarga de manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden agregar nuevos elementos a la cola de cola después de un elemento existente, al principio de la cola de cola o al final de la cola de cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_DE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_DE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola de cola. Un puntero a la cabecera de la cola de cola puede declararse más tarde como:


struct NOMBRE_DE_CABECERA *puntero_a_cabecera;

(Los nombres cabecera y puntero_a_cabecera son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos de la cola de cola.

STAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola de cola cabecera.

STAILQ_INIT() inicializa la cola de cola a la que apunta cabecera.

STAILQ_EMPTY() evalúa a verdadero si no hay elementos en la cola de cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elemento al principio de la cola de cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elemento al final de la cola de cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elemento después del elemento elemento_lista.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola de cola o NULL si la cola de cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola de cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola de cola referenciada por cabecera en la dirección hacia adelante, asignando cada elemento en turno a variable.

Eliminación

STAILQ_REMOVE() elimina el elemento elemento de la cola de cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola de cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola de cola deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola de cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cola cabecera.

VERSIONES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se nombraron de manera diferente en diferentes BSD. STAILQ se originó en FreeBSD, y SIMPLEQ se originó en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por una falta de equivalente SIMPLEQ a STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que variable se elimine o libere dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que variable se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    STAILQ_ENTRY(entrada) entradas;        /* Cola de cola enlazada simple */
};
STAILQ_HEAD(cabecera_simple, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabecera_simple cabecera;                  /* Cabecera de cola de cola
                                               enlazada simple */
    STAILQ_INIT(&cabecera);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&cabecera, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&cabecera, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    STAILQ_INSERT_AFTER(&cabecera, n1, n2, entradas);
    STAILQ_REMOVE(&cabecera, n2, entrada, entradas); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&cabecera);
    STAILQ_REMOVE_HEAD(&cabecera, entradas);     /* Eliminación del principio */
    free(n3);
    n1 = STAILQ_FIRST(&cabecera);
    n1->datos = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        STAILQ_INSERT_HEAD(&cabecera, n1, entradas);
        n1->datos = i;
    }
SIMPLEQ_NEXT(3) - Linux man pages

NAME

SIMPLEQ_FOREACH, STAILQ_FOREACH, TAILQ_FOREACH, SLIST_FOREACH, LIST_FOREACH - traverser une liste chaînée

LIBRARY

libbsd

SYNOPSIS

#include <sys/queue.h>

simpleq.h:

#define SIMPLEQ_FOREACH(var, head) \
    for ((var) = SIMPLEQ_FIRST((head)); \
        (var) != NULL; \
        (var) = SIMPLEQ_NEXT((var), next))

stailq.h:

#define STAILQ_FOREACH(var, head) \
    for ((var) = STAILQ_FIRST((head)); \
        (var) != NULL; \
        (var) = STAILQ_NEXT((var), next))

tailq.h:

#define TAILQ_FOREACH(var, head) \
    for ((var) = TAILQ_FIRST((head)); \
        (var) != NULL; \
        (var) = TAILQ_NEXT((var), next))

slist.h:

#define SLIST_FOREACH(var, head) \
    for ((var) = SLIST_FIRST((head)); \
        (var) != NULL; \
        (var) = SLIST_NEXT((var), next))

list.h:

#define LIST_FOREACH(var, head) \
    for ((var) = LIST_FIRST((head)); \
        (var) != NULL; \
        (var) = LIST_NEXT((var), next))

DESCRIPTION

Ces macros fournissent un moyen simple de parcourir une liste chaînée. La macro `SIMPLEQ_FOREACH` parcourt la liste chaînée définie par `head`, en assignant le pointeur vers chaque élément à `var`. La macro `STAILQ_FOREACH` fait de même pour une liste chaînée simple en queue. La macro `TAILQ_FOREACH` parcourt une liste chaînée doublement chaînée. La macro `SLIST_FOREACH` parcourt une liste chaînée simple. La macro `LIST_FOREACH` parcourt une liste chaînée doublement chaînée.

Les pointeurs vers les éléments de la liste sont assignés à la variable `var` dans chaque itération. Le pointeur vers l'élément suivant est obtenu en utilisant `SIMPLEQ_NEXT`, `STAILQ_NEXT`, `TAILQ_NEXT`, `SLIST_NEXT` ou `LIST_NEXT`, respectivement, en utilisant le membre de lien spécifié lors de la définition de la liste.

RETURN VALUE

Aucune valeur de retour.

VERSIONS

Les macros `SIMPLEQ_FOREACH`, `STAILQ_FOREACH`, `TAILQ_FOREACH`, `SLIST_FOREACH` et `LIST_FOREACH` sont disponibles dans la bibliothèque `libbsd` et sont compatibles avec les implémentations BSD standard.

BUGS

Aucun bug connu.

STANDARDS

Ces macros sont basées sur les primitives de liste chaînée fournies par BSD Unix.

HISTORY

Ces macros existent depuis les premières versions de BSD Unix.

EXAMPLES

Voici un exemple d'utilisation de `STAILQ_FOREACH` pour parcourir une liste et en supprimer tous les éléments :

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    STAILQ_ENTRY(node) entries;
};

int
main() {
    STAILQ_HEAD(listhead, node) head = STAILQ_HEAD_INITIALIZER(head);
    struct node *np, *n1, *n2;

    /* Ajout de quelques éléments à la liste */
    np = malloc(sizeof(struct node));
    np->data = 10;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct node));
    np->data = 20;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct node));
    np->data = 30;
    STAILQ_INSERT_TAIL(&head, np, entries);

    /* Parcours avant */
    printf("Parcours avant :\n");
    STAILQ_FOREACH(np, &head)
        printf("%i\n", np->data);

    /* Suppression de la liste */
    printf("\nSuppression de la liste :\n");
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);

    printf("Liste vidée.\n");

    return EXIT_SUCCESS;
}
