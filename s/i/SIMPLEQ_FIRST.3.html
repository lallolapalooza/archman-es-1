STAILQ(3) Manual de Funciones de Librería STAILQ(3)

NOMBRE

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implementación de una cola de listas enlazadas simples con cola

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TIPO);
STAILQ_HEAD(NOMBRE_CABECERA, TIPO);
STAILQ_HEAD NOMBRE_CABECERA STAILQ_HEAD_INITIALIZER(STAILQ_HEAD cabeza);
void STAILQ_INIT(STAILQ_HEAD *cabeza);
int STAILQ_EMPTY(STAILQ_HEAD *cabeza);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *cabeza,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *cabeza,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *cabeza, struct TIPO *listelm,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
struct TIPO *STAILQ_FIRST(STAILQ_HEAD *cabeza);
struct TIPO *STAILQ_NEXT(struct TIPO *elm, STAILQ_ENTRY NOMBRE);
STAILQ_FOREACH(struct TIPO *var, STAILQ_HEAD *cabeza, STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE(STAILQ_HEAD *cabeza, struct TIPO *elm, TIPO,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *cabeza,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_CONCAT(STAILQ_HEAD *cabeza1, STAILQ_HEAD *cabeza2);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; ver VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas de listas enlazadas simples con cola.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, nombrado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro STAILQ_HEAD().

Creación

Una cola de listas enlazadas simples con cola está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simple para un mínimo espacio y sobrecarga de manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola después de un elemento existente, al principio de la cola, o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabeza;

donde struct NOMBRE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:


struct NOMBRE_CABECERA *puntero_cabeza;

(Los nombres cabeza y puntero_cabeza son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

STAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabeza.

STAILQ_INIT() inicializa la cola referenciada por cabeza.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento listelm.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por cabeza en dirección hacia adelante, asignando cada elemento por vez a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elm de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola cabeza.

VERSIONES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se denominaron de manera diferente en distintos BSDs. STAILQ se originó en FreeBSD, y SIMPLEQ en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por una falta de un equivalente SIMPLEQ a STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    STAILQ_ENTRY(entrada) entradas;        /* Cola de lista enlazada simple */
};
STAILQ_HEAD(cabecera_cola_simple, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabecera_cola_simple cabeza;                  /* Cabeza de cola de
                                                           lista enlazada simple */
    STAILQ_INIT(&cabeza);                     /* Inicializa la cola */
    n1 = malloc(sizeof(struct entrada));      /* Inserta al principio */
    STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Inserta al final */
    STAILQ_INSERT_TAIL(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Inserta después */
    STAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);
    STAILQ_REMOVE(&cabeza, n2, entrada, entradas); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&cabeza);
    STAILQ_REMOVE_HEAD(&cabeza, entradas);     /* Eliminación del principio */
    free(n3);
    n1 = STAILQ_FIRST(&cabeza);
    n1->datos = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
        n1->datos = i;
    }

SIMPLEQ_FIRST(3) - Linux manual pages

NAME

SIMPLEQ_FIRST, SIMPLEQ_NEXT, SIMPLEQ_PREPEND, SIMPLEQ_ENQUEUE, SIMPLEQ_DEQUEUE, SIMPLEQ_INIT, SIMPLEQ_EMPTY, SIMPLEQ_END - simple queue macros

LIBRARY

Standard C Library (libc, -lc)

SYNOPSIS

#include <sys/queue.h>

Simple Queue Operations:

   SIMPLEQ_FIRST(struct simpleq *head);
   SIMPLEQ_NEXT(struct simpleq_entry *elm);
   SIMPLEQ_PREPEND(struct simpleq *head, struct simpleq_entry *elm);
   SIMPLEQ_ENQUEUE(struct simpleq *head, struct simpleq_entry *elm);
   SIMPLEQ_DEQUEUE(struct simpleq *head);
   SIMPLEQ_INIT(struct simpleq *head);
   SIMPLEQ_EMPTY(struct simpleq *head);
   SIMPLEQ_END(struct simpleq *head);

DESCRIPTION

These macros provide an implementation of a simple, singly linked queue. A singly linked queue is a queue where insertion and deletion operations only occur at one end of the queue. The queue implementation uses the standard queue macros defined in <sys/queue.h>.

A queue is defined by a structure of type struct simpleq. The elements to be stored in the queue are defined by structures of type struct simpleq_entry. The struct simpleq_entry must contain a field of type struct simpleq_entry * (a pointer to struct simpleq_entry) which will be used by the queue macros to link the elements together.

The following macros are available:

SIMPLEQ_EMPTY(struct simpleq *head);
Returns true if the queue pointed to by head is empty, false otherwise.
SIMPLEQ_END(struct simpleq *head);
Returns a pointer to the last element in the queue pointed to by head.
SIMPLEQ_ENQUEUE(struct simpleq *head, struct simpleq_entry *elm);
Adds the element elm to the end of the queue pointed to by head.
SIMPLEQ_FIRST(struct simpleq *head);
Returns a pointer to the first element in the queue pointed to by head. If the queue is empty, it returns NULL.
SIMPLEQ_INIT(struct simpleq *head);
Initializes the queue pointed to by head to be an empty queue.
SIMPLEQ_NEXT(struct simpleq_entry *elm);
Returns a pointer to the next element in the queue after the element pointed to by elm. If elm is the last element in the queue, it returns NULL.
SIMPLEQ_PREPEND(struct simpleq *head, struct simpleq_entry *elm);
Adds the element elm to the beginning of the queue pointed to by head.
SIMPLEQ_DEQUEUE(struct simpleq *head);
Removes and returns the first element from the queue pointed to by head. If the queue is empty, it returns NULL.

RETURN VALUE

SIMPLEQ_FIRST, SIMPLEQ_NEXT, and SIMPLEQ_END return a pointer to a struct simpleq_entry or NULL if the queue is empty or the end of the queue is reached.

SIMPLEQ_DEQUEUE returns a pointer to the dequeued struct simpleq_entry or NULL if the queue is empty.

SIMPLEQ_EMPTY returns a non-zero value if the queue is empty, and zero otherwise.

VERSIONS

The simple queue macros first appeared in FreeBSD 2.1.

BUGS

The macros are not reentrant. If they are used in a multithreaded environment, appropriate locking mechanisms must be used.

STANDARDS

The simple queue macros are not part of any standard.

HISTORY

The simple queue macros were inspired by the list queue macros in BSD. They were first introduced in FreeBSD 2.1.

EXAMPLES

The following example demonstrates the usage of the simple queue macros to create, populate, traverse, and empty a queue.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct simpleq my_queue;
struct simpleq_entry *np, *np2;

struct node {
    int data;
    struct simpleq_entry entries;
};

int
main(void)
{
    /* Initialize the queue */
    SIMPLEQ_INIT(&my_queue);

    /* Create and enqueue elements */
    for (int i = 0; i < 5; i++) {
        np = malloc(sizeof(struct node));
        if (np == NULL) {
            perror("malloc failed");
            exit(EXIT_FAILURE);
        }
        np->data = i;
        SIMPLEQ_ENQUEUE(&my_queue, np);
    }

                                     /* Forward traversal */
    SIMPLEQ_FOREACH(np, &my_queue, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    while (!SIMPLEQ_EMPTY(&my_queue)) {
        np = SIMPLEQ_DEQUEUE(&my_queue);
        free(np);
    }

    exit(EXIT_SUCCESS);
}
