SINGULAR(1) Comandos de usuario SINGULAR(1)

NOMBRE

Singular - página del manual para Singular para la versión 4.x.x

DESCRIPCIÓN

Singular -- un Sistema Algebraico Computacional (CAS) para cálculos polinomiales.

ESingular: inicia Singular dentro de emacs.

TSingular: inicia Singular dentro de una nueva terminal

SINOPSIS

Singular [opciones] [archivo1 [archivo2 ...]]

ESingular [opciones] [archivo1 [archivo2 ...]]

TSingular [opciones] [archivo1 [archivo2 ...]]

OPCIONES

-b --batch
Ejecutar en modo batch (requiere --link/--MPhost/--MPport)
-c --execute=CADENA
Ejecutar CADENA al inicio
-d --sdb
Habilitar depurador de código fuente (experimental)
-e --echo[=VAL]
Establecer el valor de la variable `echo' a (entero) VAL
-h --help
Imprimir mensaje de ayuda y salir
-p --profile
Recopilar datos de perfil en smon.out
-q --quiet
No imprimir el banner de inicio ni los mensajes de carga de la biblioteca
-r --random=SEMILLA
Inicializar el generador aleatorio con (entero) SEMILLA
-t --no-tty
No redefinir las características de la terminal
-u --user-option=CADENA
Devolver CADENA en `system("--user-option")'
-v --version
Imprimir información extendida de versión y configuración
--allow-net
Permitir obtener páginas de ayuda (html) de la red
--browser=NAVEGADOR
Mostrar ayuda en NAVEGADOR (ver help.cnf)
--cntrlc[=CARACTER]
Respuesta automática para el aviso de CTRL-C
--emacs
Establecer valores predeterminados para ejecutar dentro de emacs
--log=ARCHIVO_DE_LOG
Registrar toda la entrada en ARCHIVO_DE_LOG.*
--no-stdlib
No cargar `standard.lib' al inicio
--no-rc
No ejecutar el/los archivo(s) `.singularrc' al inicio
--no-warn
No mostrar mensajes de advertencia
--no-out
Suprimir toda la salida
--no-shell
Modo restringido: prohibir comandos de escape de shell y enlaces
--min-time=SEGS
No mostrar tiempos menores que SEGS (en segundos)
--cpus=#CPUS
número máximo de CPUs a usar
--threads=#hilos
número máximo de CPUs a usar para hilos

--flint-threads=#hilos_flint número máximo de hilos a usar en la biblioteca flint

--MPport=PUERTO
Usar número de PUERTO para conexiones
--MPhost=HOST
Usar HOST para conexiones
--link=ENLACE
Usar ENLACE para conexiones
--ticks-per-sec=TICKS
Establece la unidad del temporizador a TICKS por segundo
--dump-versiontuple
Mostrar la tupla de versión y salir

Para más información, escribe `help;' dentro de Singular o visita https://www.singular.uni-kl.de o consulta el manual de Singular (disponible como información en línea o manual html).

VER TAMBIÉN

La documentación completa de Singular se mantiene como un manual Texinfo.
