SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; ver VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas de listas enlazadas simples con cola.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, con el nombre NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola de listas enlazadas simples con cola está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y el otro al último elemento de la cola. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos a enlazar en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:


struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

STAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola head.

STAILQ_INIT() inicializa la cola referenciada por head.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elm al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elm al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elm después del elemento listelm.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento en su momento a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elm de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TYPE primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola head.

VERSIONES

Algunos BSDs proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se les dio nombres diferentes en diferentes BSDs. STAILQ se originó en FreeBSD y SIMPLEQ se originó en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por una falta de equivalente SIMPLEQ para STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSDs pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado dentro del bucle sin interferir con el recorrido.

ESTANDARES

BSD.

HISTORIA

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* Cola de lista enlazada simple */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Cabeza de cola de lista enlazada simple
                                               */
    STAILQ_INIT(&head);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Eliminación desde el principio */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
