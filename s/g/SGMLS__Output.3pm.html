SGMLS::Output(3) Documentación de Perl aportada por el usuario SGMLS::Output(3)

NOMBRE

SGMLS::Output - Procedimientos de salida basados en pila

SINOPSIS

use SGMLS::Output;

Para imprimir una cadena en el destino de salida actual:

output($data);

Para agregar un nuevo nivel de salida al manejador DATA:

push_output('handle',DATA);

Para agregar un nuevo nivel de salida al archivo "foo.data" (que se abrirá y cerrará automáticamente):

push_output('file','foo.data');

Para agregar un nuevo nivel de salida a una tubería para el comando de shell "sort":

push_output('pipe','sort');

Para agregar un nuevo nivel de salida *adjuntando* al archivo "foo.data":

push_output('append','foo.data');

Para agregar un nuevo nivel de salida a una cadena vacía:

push_output('string');

Para agregar un nuevo nivel de salida adjuntando a la cadena "David es ":

push_output('string',"David es ");

Para agregar un nuevo nivel de salida al Gran Más Allá:

push_output('nul');

Para volver al nivel de salida anterior:

pop_output();

Para volver al nivel de salida anterior, devolviendo el contenido de una cadena de salida:

$data = pop_output();

DESCRIPCIÓN

Esta biblioteca permite la salida redirigible y basada en pila a archivos, tuberías, manejadores, cadenas o nul. Es especialmente útil para paquetes como SGMLS, ya que los manejadores para elementos SGML individuales pueden cambiar temporalmente y restaurar el destino de salida predeterminado. También es particularmente útil para capturar el contenido de un elemento (y sus subelementos) en una cadena.

Ejemplo:

sgmls('<title>', sub{ push_output('string'); });
sgmls('</title>', sub{ $title = pop_output(); });

En el medio, cualquier cosa enviada a output (como CDATA) se acumulará en la cadena devuelta por pop_output().

Ejemplo:

sgmls('<tei.header>', sub { push_output('nul'); });
sgmls('</tei.header>', sub { pop_output(); });

Toda la salida será ignorada hasta que finalice la cabecera.
