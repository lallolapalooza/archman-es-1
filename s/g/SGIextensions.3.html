Descripción Detallada

Dado que libstdc++ basó su implementación de las subsecciones STL de la biblioteca en la implementación SGI 3.3, también heredamos sus extensiones.

Se documentan adicionalmente en la documentación en línea, una copia de la cual también se envía con el código fuente de la biblioteca (en .../docs/html/documentation.html). También puede leer la documentación en el sitio de SGI, que todavía está activo aunque el código no se mantiene.

NOTA que las siguientes notas se extraen de varios comentarios en todas partes, por lo que pueden parecer poco fluidas.

Las funciones identity_element no forman parte del estándar C++; SGI las proporcionó como una extensión. Su argumento es una operación, y su valor de retorno es el elemento de identidad para esa operación. Está sobrecargada para suma y multiplicación, y puede sobrecargarla para sus propias operaciones nefastas.

Como extensión a los vinculadores, SGI proporcionó funtores de composición y funciones envoltorio para ayudar en su creación. El funtor unary_compose se construye a partir de dos funciones/funtores, f y g. Al llamar a operator() con un único argumento x, se devuelve f(g(x)). La función compose1 toma las dos funciones y construye una variable unary_compose para usted.

binary_compose se construye a partir de tres funtores, f, g1 y g2. Su operator() devuelve f(g1(x),g2(x)). La función compose2 toma f, g1 y g2, y construye la instancia binary_compose para usted. Por ejemplo, si f devuelve un int, entonces

int answer = (compose2(f,g1,g2))(x);


es equivalente a

int temp1 = g1(x);
int temp2 = g2(x);
int answer = f(temp1,temp2);


Pero la primera forma es más compacta y se puede pasar como un funtor a otros algoritmos.

Como extensión, SGI proporcionó un funtor llamado identity. Cuando se requiere un funtor pero no se desean operaciones, este se puede utilizar como un paso directo. Su operator() devuelve su argumento sin cambios.

Functors

select1st y select2nd son extensiones proporcionadas por SGI. Sus operator() toman un std::pair como argumento y devuelven el primer o el segundo miembro, respectivamente. Pueden usarse (especialmente con los functors de composición) para eliminar datos de una secuencia antes de realizar el resto de un algoritmo.

El operator() del functor project1st toma dos argumentos arbitrarios y devuelve el primero, mientras que project2nd devuelve el segundo. Son extensiones proporcionadas por SGI.

Estos tres functors se construyen cada uno a partir de una única variable/valor arbitrario. Más tarde, sus operator() ignoran completamente cualquier argumento pasado y devuelven el valor almacenado.

  • constant_void_fun's operator() no toma argumentos
  • constant_unary_fun's operator() toma un argumento (ignorado)
  • constant_binary_fun's operator() toma dos argumentos (ignorados)

Las funciones auxiliares creadoras constant0, constant1 y constant2 toman cada una un argumento resultado y construyen variables del tipo de functor apropiado.

Encuentra la mediana de tres valores.

Parámetros

__a Un valor.
__b Un valor.
__c Un valor.

Devuelve

Uno de a, b o c.

Si {l,m,n} es alguna convolución de {a,b,c} tal que l<=m<=n, entonces el valor devuelto será m. Esta es una extensión de SGI.

template<typename _InputIterator, typename _Size, typename _OutputIterator> std::pair< _InputIterator, _OutputIterator > __gnu_cxx::copy_n (_InputIterator __first, _Size __count, _OutputIterator __result) [inline]

Copia el rango [first,first+count) en [result,result+count).

Parámetros

__first Un iterador de entrada.
__count El número de elementos a copiar.
__result Un iterador de salida.

Devuelve

Un std::pair compuesto por first+count y result+count.

Esta es una extensión de SGI. Esta función en línea se reducirá a una llamada a memmove siempre que sea posible. De lo contrario, si se pasan iteradores de acceso aleatorio, el recuento del bucle será conocido (y, por lo tanto, será un candidato para optimizaciones del compilador, como el desenrollado).

template<typename _InputIterator1, typename _InputIterator2> int __gnu_cxx::lexicographical_compare_3way (_InputIterator1 __first1, _InputIterator1 __last1, _InputIterator2 __first2, _InputIterator2 __last2)

memcmp con esteroides.

Parámetros

__first1 Un iterador de entrada.
__last1 Un iterador de entrada.
__first2 Un iterador de entrada.
__last2 Un iterador de entrada.

Devuelve

Un int, como con memcmp.

El valor de retorno será menor que cero si el primer rango es *lexicográficamente menor que* el segundo, mayor que cero si el segundo rango es *lexicográficamente menor que* el primero, y cero en caso contrario. Esta es una extensión de SGI.
