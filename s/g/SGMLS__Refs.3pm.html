Paquete: perl-sgmls

SGMLS::Refs(3) Documentación de Perl contribuida por el usuario SGMLS::Refs(3)

NOMBRE

SGMLS::Refs - Manejo de referencias cruzadas

SINOPSIS

use SGMLS::Refs;

Para crear un nuevo objeto de gestión de referencias utilizando el archivo "foo.refs":

my $refs = new SGMLS::Refs("foo.refs");

Para crear un nuevo objeto de gestión de referencias utilizando el archivo "foo.refs" y registrando los cambios en el archivo "foo.log":

my $refs = new SGMLS::Refs("foo.refs","foo.log");

Para registrar una referencia:

$refs->put("título del documento",$title);

Para recuperar una referencia:

$title = $refs->get("título del documento");

Para devolver el número de referencias modificadas desde la última ejecución:

$num = $refs->changed;

Para imprimir una advertencia similar a LaTeX si alguna referencia ha cambiado:

$refs->warn;

DESCRIPCIÓN

Esta biblioteca puede ser utilizada junto con el paquete SGMLS para mantener un registro de referencias cruzadas de una ejecución a otra, similar a los archivos ".aux" de LaTeX. Cada gestor de referencias es un objeto que lee y luego reescribe un archivo de código fuente de Perl, con el nombre de archivo proporcionado por el llamador.

Ejemplo:

# Inicia el gestor de referencias antes del análisis.
sgml('start', sub { $refs = new SGMLS::Refs("foo.refs"); });
# Advierte sobre cualquier referencia cambiada al final.
sgml('end', sub { $refs->warn; });
# Busca el título del análisis anterior, si está disponible.
sgml('<div>', sub { 
  my $element = shift;
  my $id = $element->attribute(ID)->value;
  my $title = $refs->get("title:$id") || "[no hay título disponible]";
  $current_div_id = $id;
  output "\\section{$title}\n\n";
});
# Guarda el título para el próximo análisis.
sgml('<head>', sub { push_output('string'); });
sgml('</head>', sub {
  my $title = pop_output();
  my $id = $current_div_id;
  $refs->put("title:$id",$title);
});
