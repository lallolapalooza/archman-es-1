Descripción Detallada

La clase SbName almacena cadenas de texto por referencia.

La clase es utilizada por Coin para almacenar palabras clave, nombres y otras cadenas de texto. Se almacenan de tal manera que las cadenas idénticas garantizan que se mapean a la misma dirección de memoria (según lo devuelto por el método SbName::getString()).

La principal ventaja de almacenar cadenas idénticas en la misma dirección de memoria es que simplifica las operaciones de comparación, y particularmente cuando se trabaja con datos de cadenas como claves en otras estructuras de datos, como por ejemplo en tablas hash (diccionario).

Además de eso, mapear cadenas idénticas a la misma dirección de memoria también puede ahorrar recursos de memoria y proporcionar optimizaciones en tiempo de ejecución. Las comparaciones de cadenas para objetos SbName son muy eficientes, por ejemplo.

Hay un aspecto del uso de instancias de SbName que es importante tener en cuenta: dado que las cadenas se almacenan permanentemente, usar instancias de SbName en código donde hay cadenas en constante cambio o la adición continua de nuevas cadenas únicas acabará saturando los recursos de memoria. Por lo tanto, cuando sea posible, utilice instancias de SbString en su lugar.

El puntero de memoria devuelto para la cadena de caracteres está garantizado que será válido durante el resto de la vida del proceso, incluso después de que todas las instancias de SbName que referencien la cadena hayan sido destruidas.

SbBool SbName::isBaseNameStartChar (const char c) [static]

Devuelve TRUE si el carácter dado es válido para usar como primer carácter de un nombre para un objeto derivado de una clase que hereda SoBase.

Los objetos derivados de SoBase necesitan ser nombrados de una manera que no entre en conflicto con los caracteres especiales reservados como tokens en las reglas de sintaxis de los archivos Open Inventor y VRML.

Los caracteres legales para el primer carácter del nombre de un objeto SoBase son el guion bajo ("_") y cualquier carácter alfabético mayúsculo y minúsculo del conjunto de caracteres ASCII (es decir, A-Z y a-z).

Este método no forma parte de la API original de Open Inventor.

SbBool SbName::isBaseNameChar (const char c) [static]

Devuelve TRUE si el carácter dado es válido para usar en el nombramiento de instancias de objetos de clases derivadas de SoBase.

Los objetos derivados de SoBase necesitan ser nombrados de una manera que no entre en conflicto con los caracteres especiales reservados como tokens en las reglas de sintaxis de los archivos Open Inventor y VRML.

Los caracteres legales para usar en el nombre de un objeto SoBase son cualquier carácter del conjunto de caracteres ASCII desde el carácter 33 (hex 0x21) hasta el 126 (hex 0x7e), excepto las comillas simples y dobles, el signo más y los signos de puntuación, la barra invertida y las llaves.

Este método no forma parte de la API original de Open Inventor.
