Descripción detallada

La clase SbSpherePlaneProjector proyecta puntos 2D a una semiesfera y un plano.

Este proyector utiliza un plano junto con la semiesfera de SbSphereSectionProjector para las proyecciones. Si el mapeo del punto 2D "falla" la sección de la esfera, el punto 3D se proyectará en el plano.

Inherits SbProjector.

Inherited class members: getMatrix, getProjection, getTransformation, project, rotate, scale, translate

Detailed Description

This projector defines a projection onto a sphere. The projection is performed by finding the intersection of a line from the camera's viewpoint through the point onto the sphere.
