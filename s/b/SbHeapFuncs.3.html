Descripción Detallada

La estructura SbHeapFuncs se utiliza para especificar funciones en elementos de montón.

Documentación de Datos Miembro

float(* SbHeapFuncs::eval_func) (void *)

El miembro eval_func es un puntero a una función que debería devolver un valor de peso para un elemento del montón. Los elementos más pequeños se extraen primero del montón.

int(* SbHeapFuncs::get_index_func) (void *)

get_index_func es un puntero a una función que debería devolver el índice del elemento en el montón. Si desea eliminar un elemento del montón (que no sea el primer elemento) o cambiar el peso de un elemento del montón, debe proporcionar las dos funciones de índice. Cada elemento debe almacenar su índice en el montón en sus propias estructuras de datos.

void(* SbHeapFuncs::set_index_func) (void *, int)

set_index_func se utiliza para establecer este valor de índice y se llamará cada vez que el elemento se mueva en el montón.
