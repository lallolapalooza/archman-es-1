Descripción detallada

La clase SbBox2d es una caja bidimensional con coordenadas de esquina de precisión doble.

Esta clase de caja es utilizada por muchas otras clases en Coin para intercambio y almacenamiento de datos. Proporciona dos esquinas de caja con coordenadas de precisión doble, lo cual es útil, entre otras cosas, para representar dimensiones de pantalla o lienzo en coordenadas normalizadas.

Esta clase es una extensión de Coin.

Ver también

SbBox2s, SbBox2f, SbBox3s, SbBox3f, SbBox3d, SbXfBox3f.

Description

The SbBox2d class defines a 2D bounding box.

A 2D bounding box is defined by its minimum (lower-left) and maximum (upper-right) corner points.

Note that a 2D bounding box is considered "empty" if its minimum point is greater than its maximum point. An empty box has zero dimensions, and may be initialized using the makeEmpty() method.

The methods getMin() and getMax() return the corner points. The getOrigin() method returns the lower-left corner, and getSize() returns the width and height of the box.

The hasArea() method can be used to check if a box has positive dimensions (i.e. is not empty).
