Descripción Detallada

La clase SbString es una clase de cadena con funciones de conveniencia para operaciones de cadena.

Esta es la clase utilizada para almacenar y trabajar con cadenas de caracteres. Se encarga automáticamente de soportar todas las tareas de "contabilidad" usualmente asociadas con el trabajo con cadenas de caracteres, como la asignación y desasignación de memoria, etc.

Esta clase también debería ser adecuada para el uso por el programador de aplicaciones en toda la aplicación que utiliza la biblioteca Coin.

SbString SbString::getSubString (int startidx, int endidx = -1) const [inline]

Este método devuelve una nueva cadena que contiene una subcadena definida por los índices dados startidx y endidx (inclusive).

Si endidx es -1, se utiliza la subcadena desde startidx hasta el final de la cadena.

Esto devolverá una cadena que es (endidx - startidx + 1) caracteres de longitud, es decir, si esta cadena es "foo/bar" y llamamos a SbString::getSubString(0, 3), la cadena devuelta será "foo/".

Este método elimina la subcadena definida por startidx y endidx (inclusive). Si endidx es -1, se elimina la subcadena desde startidx hasta el final de la cadena.

Detailed Description

String class.

This class is used for strings. It is similar to the C++ std::string class.

It has methods to handle concatenation, comparison and searching. The main difference to the C++ standard string is that the SbString class is part of the Open Inventor API.

The Open Inventor string class SbString is used to manage character strings. It implements concatenation, substring extraction, comparison, searching, and other common string manipulations.

The SbString class supports the following operations:

  • Concatenation: Strings can be concatenated using the + and += operators.

  • Comparison: Strings can be compared using the ==, !=, <, >, <=, and >= operators.

  • Access: Individual characters can be accessed using the [] operator.

  • Substring extraction: The getSubString() method can be used to extract substrings.

  • Searching: The find() and findAll() methods can be used to search for substrings.

  • Formatting: The sprintf() and vsprintf() methods can be used to format strings similar to the C standard library functions.

void SbString::apply (char(* func )(char input)) [inline]

Apply the conversion function func to every character of the current string. func is a pointer to a function that takes a character as input and returns a (probably converted) character.

Note that this function is not part of the original Open Inventor API.

int SbString::compareSubString (const char * text, int offset = 0) const [inline]

Uses text as a substring to be compared to the string, starting at offset offset. Return value is 0 upon success, and the failing character comparison difference upon failure.
