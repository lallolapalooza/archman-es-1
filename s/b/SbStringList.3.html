Descripción Detallada

La clase SbStringList es un contenedor para punteros a objetos SbString.

Tenga en cuenta que al usar los operadores de igualdad y desigualdad, las cadenas en sí no se comparan, solo los valores de los punteros.

Esta clase no asigna ni libera cadenas. Es responsabilidad del llamador asignar/liberar las instancias de SbString.

NOMBRE

SbStringList - Gestiona una lista de cadenas.

SINOPSIS

#include <SbStringList.h>

Funciones para crear, destruir, añadir, eliminar, buscar y manipular elementos en una lista de cadenas.

DESCRIPCIÓN

La estructura SbStringList proporciona una forma eficiente de gestionar colecciones dinámicas de cadenas de caracteres. Permite operaciones comunes como la adición, eliminación, búsqueda y acceso a elementos individuales. Internamente, se implementa como un array dinámico que se redimensiona según sea necesario.

Las principales funciones son:

  • SbStringList_create(): Crea una nueva lista de cadenas vacía.
  • SbStringList_destroy(): Libera la memoria ocupada por la lista y sus elementos.
  • SbStringList_add(): Añade una cadena al final de la lista.
  • SbStringList_remove(): Elimina la primera aparición de una cadena dada de la lista.
  • SbStringList_find(): Busca una cadena en la lista y devuelve su índice si se encuentra.
  • SbStringList_get(): Devuelve la cadena en un índice específico.
  • SbStringList_size(): Devuelve el número de elementos en la lista.

VALOR DE RETORNO

Las funciones devuelven valores apropiados como punteros a SbStringList, enteros (para índices o tamaños) o booleanos (para indicar éxito o fracaso).

EJEMPLOS

#include <stdio.h>
#include <SbStringList.h>

int main() {
    SbStringList* list = SbStringList_create();
    if (!list) {
        fprintf(stderr, "Error al crear la lista.\\n");
        return 1;
    }

    SbStringList_add(list, "hola");
    SbStringList_add(list, "mundo");
    SbStringList_add(list, "arch");

    printf("Tamaño de la lista: %d\\n", SbStringList_size(list));

    for (int i = 0; i < SbStringList_size(list); ++i) {
        printf("Elemento %d: %s\\n", i, SbStringList_get(list, i));
    }

    if (SbStringList_find(list, "mundo") != -1) {
        printf("'mundo' encontrado en la lista.\\n");
    }

    SbStringList_remove(list, "hola");
    printf("Después de eliminar 'hola', tamaño: %d\\n", SbStringList_size(list));

    SbStringList_destroy(list);
    return 0;
}
