Descripción Detallada

La SbSphereSectionProjector proyecta puntos 2D a un esfera cortada.

La esfera de proyección para esta clase se corta por un plano de corte. Las proyecciones se mapan a la parte restante de la esfera.

Detailed Description

This class manages a projection surface which is defined by the intersection of a sphere and a plane. It is used for implementing trackball-like rotation mechanisms.

The projection surface is a section of a sphere. By default it is a hemisphere, but the section can be adjusted using `setTolerance()`.

The members `radialFactor` and `tolerance` control how the projection surface is defined and how calculations are performed.

The `radialFactor` member controls how rotations are performed when the mouse is outside the sphere. If `radialFactor` is 0.0, rotations are performed as if the user were dragging the sphere directly. If `radialFactor` is 1.0, rotations are performed around the axis from the viewpoint to the sphere.

The `tolerance` member defines how much of the sphere is used for projections. A `tolerance` of 1.0 means the entire hemisphere is used. Values less than 1.0 define a smaller section of the sphere.

The class also stores information about the plane that defines the section of the sphere, including its normal vector (`planeDir`), a point on the plane (`planePoint`), and the distance from the origin to the plane (`planeDist`).
