Descripción detallada

La clase SbBox2s es una caja bidimensional con coordenadas de enteros cortos.

Esta clase de caja es utilizada por otras clases en Coin para el intercambio de datos. Proporciona almacenamiento para dos esquinas de la caja con coordenadas de enteros cortos, lo cual es útil, entre otras cosas, para representar áreas de pantalla o lienzo en coordenadas absolutas de ventana.

DESCRIPTION

This class defines a 2D bounding box using two points. The points are stored as 16-bit signed integers (shorts).

A bounding box is defined by its minimum and maximum points. The minimum point is the corner with the smallest coordinates, and the maximum point is the corner with the largest coordinates. For a 2D box, the minimum point is typically the lower-left corner, and the maximum point is the upper-right corner.

The class provides methods to get and set these points, as well as to perform common operations like checking for emptiness, intersection, and expansion.
