Descripción Detallada

La clase SbDPViewVolume representa un volumen de visión en 3D espacio de precisión doble.

Esta clase contiene la información necesaria para almacenar un volumen de visión. Tiene métodos para proyectar los primitivos desde o hacia el volumen de 3D, realizando transformaciones de cámara, transformaciones de volumen de visión, etc.

Debes tener en cuenta que esta clase es una extensión para Coin, y no está disponible en el API original de SGI Open Inventor v2.1.

Ver también

SbViewportRegion

Desde

Coin 2.0

SbDPMatrix SbDPViewVolume::getCameraSpaceMatrix (void ) const

Devuelve una matriz que traslada el volumen de visión de la cámara de vuelta a origen, y gira la cámara para que apunte hacia el eje negativo del eje Z.

Nota: La matriz no incluye la rotación necesaria para que el vector de up de la cámara apunte hacia el eje positivo Y (es decir, el giro de la cámara no se considera).

void SbDPViewVolume::projectPointToLine (const SbVec2d & pt, SbDPLine & line) const

Proyecta el punto dado en 2D del plano de proyección a una línea en 3D.

Las coordenadas pt deben normalizarse para estar dentro del rango [0, 1].

void SbDPViewVolume::projectPointToLine (const SbVec2d & pt, SbVec3d & line0, SbVec3d & line1) const

Proyecta el punto dado en 2D del plano de proyección a dos puntos que definen una línea en 3D. El punto line0 corresponde al punto de proyección en el plano cercano, mientras que line1 es el punto final de la línea, que está en el plano lejano.

void SbDPViewVolume::projectToScreen (const SbVec3d & src, SbVec3d & dst) const

Proyecta el punto src a coordenadas normales de coordenadas de pantalla en el plano de proyección y coloca el resultado en dst.

Es seguro que src y dst puedan ser la misma instancia de SbVec3d.

El valor de la coordenada z de dst está normalizado para el rango [0, 1].

Returns a rotation that aligns an object so that its positive x-axis is to the right and its positive y-axis is up in the view volume.

If rightangleonly is TRUE, it will create a rotation that aligns the x and y axes with the closest orthogonal axes to the right and up.

SbDPViewVolume SbDPViewVolume::narrow (double left, double bottom, double right, double top) const

Returns a narrowed view volume that is contained within the normalized coordinate range [0, 1]. The coordinates are taken as the corner points of a "normalized view window" on the near clipping plane. Thus, one could say:

SbDPViewVolume view;
view.ortho(0, 100, 0, 100, 0.1, 1000);
view = view.narrow(0.25, 0.5, 0.75, 1.0);

..will result in a view volume with corner points <25, 75> and <50, 100>.

See also

scale(), scaleWidth(), scaleHeight()

SbDPViewVolume SbDPViewVolume::narrow (const SbBox3f & box) const

Returns a narrowed view volume that is contained within the normalized coordinate range [0, 1]. The x and y coordinates of the box are taken as the corner points of a "normalized view window" on the near clipping plane. The z coordinates of the box are used to adjust the near and far clipping planes, and must be relative to the current clipping planes. A value of 1.0 is at the current near clipping plane. A value of 0.0 is at the current far clipping plane.

void SbDPViewVolume::ortho (double left, double right, double bottom, double top, double nearval, double farval)

Sets the view volume to be a rectangular cuboid for parallel, orthographic projections. The sight line will be along the negative Z axis, passing through the center of the plane defined by the point <(right+left)/2, (top+bottom)/2, 0>.

Sets the view volume for perspective projections. The sight line will be through the origin, along the negative Z axis.

void SbDPViewVolume::frustum (double left, double right, double bottom, double top, double nearval, double farval)

Sets the frustum for perspective projections. This is an alternative to perspective() that allows you to specify any kind of view volume (e.g. offset volumes). It has the same arguments and functionality as the corresponding OpenGL function glFrustum().

This class is a viewing frustum in double precision. It is used to represent the volume visible to a camera.
