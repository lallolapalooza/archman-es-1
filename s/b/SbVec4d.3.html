Descripción Detallada

La clase SbVec4d es un vector de 4 dimensiones con coordenadas de punto flotante de doble precisión.

Esta clase de vector no es utilizada por muchas otras clases en Coin. Proporciona almacenamiento para un vector homogéneo de 3 dimensiones (con los 4 componentes usualmente referidos como <x, y, z, w>) así como operaciones aritméticas simples de punto flotante de doble precisión.

Ver también

SbVec2s, SbVec2f, SbVec2d, SbVec3s, SbVec3f, SbVec3d, SbVec4f.

Detailed Description

4-component vector of doubles.

This class implements a 4-component vector for homogenous coordinates. The vector components are x, y, z and w.

SbVec4d::SbVec4d ()

Default constructor. Initializes the vector components to zero.

Constructor. Initializes the vector with the given component values.

SbVec4d::SbVec4d (const SbVec3d & v, double v4)

Constructor. Initializes the vector from a 3D vector and a w component.

Copy constructor.

void SbVec4d::getValue (double * v) const

Copies the vector components into the array pointed to by v. The array must have at least 4 elements.

void SbVec4d::getValue (SbVec3d & v) const

Returns the vector as a Cartesian 3D vector in v. This means that the 3 first components x, y and z will be divided by the fourth, w.

Calculates and returns the result of taking the dot product of this vector and v.

SbBool SbVec4d::equals (const SbVec4d & v, double tolerance) const

Compares the vector with v and returns TRUE if the distance between the vectors is smaller or equal to the square root of tolerance.

The comparison is done in 4D-space, i.e. the w component of the vector is not used to make x, y and z into Cartesian coordinates first.

void SbVec4d::getReal (SbVec3d & v) const

Returns the vector as a Cartesian 3D vector in v. This means that the 3 first components x, y and z will be divided by the fourth, w.
