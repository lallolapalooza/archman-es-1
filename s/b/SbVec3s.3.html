Descripción Detallada

La clase SbVec3s es un vector tridimensional con coordenadas de enteros cortos.

Esta clase de vector proporciona almacenamiento para un vector tridimensional, así como operaciones aritméticas simples con enteros.

Tenga en cuenta que esta clase es una extensión para Coin, y no está disponible en la API original de SGI Open Inventor v2.1.
