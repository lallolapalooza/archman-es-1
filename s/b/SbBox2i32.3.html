Descripción Detallada

La clase SbBox2i32 es un cuadrado de 2 dimensiones con coordenadas de 32 bits enteros.

Esta clase de cuadrado se utiliza por otras clases en Coin para intercambiar datos. Proporciona almacenamiento para dos vértices de un cuadrado con coordenadas de 32 bits enteros, lo cual es útil, por ejemplo, para representar áreas de ventana absolutas en coordenadas de pantalla.

Detailed Description

This class defines a 2D bounding box with integer coordinates. It stores the minimum and maximum corner points of the box.

The bounding box is defined by two points: its minimum point (lower left corner) and its maximum point (upper right corner).

The coordinate system used is a standard Cartesian coordinate system, where the X-axis increases to the right and the Y-axis increases upwards.

An SbBox2i32 object can be empty. An empty box is created using the makeEmpty() method. An empty box has no volume, and operations like intersect() will return false if performed on an empty box.

The bounding box can be extended to include a given point or another bounding box using the extendBy() methods.

The hasArea() method checks if the box has a valid area (i.e., if the minimum coordinates are less than or equal to the maximum coordinates).

The intersect() methods check for intersection with a point or another bounding box.

The getCenter(), getSize(), getOrigin(), and getAspectRatio() methods provide information about the dimensions and position of the box.

The operator== and operator!= allow for comparison of two bounding boxes.
