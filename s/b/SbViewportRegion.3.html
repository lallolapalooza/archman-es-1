Descripción detallada

La clase SbViewportRegion es una región de vista dentro de una ventana completa.

La clase SbViewportRegion contiene información para representar una subvista dentro de una ventana. Almacena información sobre el origen y el tamaño de la subvista, así como el tamaño de la ventana "completa" subyacente.

Los métodos disponibles incluyen consultas y manipulación tanto en coordenadas normalizadas como en coordenadas de píxeles.

A continuación, se muestra un pequeño ejemplo que muestra cómo se puede modificar la región de vista de una clase de visor, dentro de un contexto adecuado de Coin y sistema de ventanas. Presione 'D' o 'U' para mover la región de vista 40 píxeles hacia abajo o hacia arriba, respectivamente. Haga clic en 'Esc' y acerque con los botones izquierdo + central del ratón, para ver cómo se define la región, donde no se verá ninguna geometría 3D fuera de ella. Haga clic de nuevo en 'Esc' para usar 'U' y 'D'.

// Copyright (C) by Kongsberg Oil & Gas Technologies. All rights reserved.
#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/nodes/SoEventCallback.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoCone.h>
#include <Inventor/events/SoKeyboardEvent.h>
// ************************************************************
static void
keypresscbfunc(void * userdata, SoEventCallback * keyboardcb)
{
  SoQtExaminerViewer * viewer = (SoQtExaminerViewer *)userdata;
  const SoEvent * event = keyboardcb->getEvent();
  int shift = 0;
  if (SO_KEY_PRESS_EVENT(event, U)) {
    shift = 40;
    keyboardcb->setHandled();
  }
  else if (SO_KEY_PRESS_EVENT(event, D)) {
    shift = -40;
    keyboardcb->setHandled();
  }
  if (keyboardcb->isHandled()) {
    SbViewportRegion vpr = viewer->getViewportRegion();
    SbVec2s size = vpr.getViewportSizePixels();
    SbVec2s origin = vpr.getViewportOriginPixels();
    origin[1] -= shift;
    vpr.setViewportPixels(origin, size);
    viewer->setViewportRegion(vpr);
  }
}
// ************************************************************
int
main(int argc, char ** argv)
{
  QWidget * window = SoQt::init(argv[0]);
  SoSeparator * root = new SoSeparator;
  root->ref();
  root->addChild(new SoCone);
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  SoEventCallback * eventcb = new SoEventCallback;
  eventcb->addEventCallback(SoKeyboardEvent::getClassTypeId(),
                            keypresscbfunc, viewer);
  root->insertChild(eventcb, 0);
  viewer->setViewing(FALSE);
  viewer->setDecoration(FALSE);
  viewer->setSceneGraph(root);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  root->unref();
  return 0;
}

Detailed Description

Specify a viewport region in screen coordinates.

A viewport region defines a rectangular sub-window onto which the 3D scene is rendered. The coordinates are given in pixels.

The default viewport region is the entire window.

The coordinates are defined such that (0,0) is the lower-left corner of the window, and the positive x and y axes point to the right and up, respectively.

scaleWidth (float ratio)

Scale the width of the viewport region.

The scale factor should not make the viewport larger than the window. If this happens, the viewport will be clamped.

The scaling will be done around the viewport region center point, but if this causes the viewport origin to be moved below (0,0), the origin coordinates will be clamped.

See also scaleHeight().

scaleHeight (float ratio)

Scale the height of the viewport region.

The scale factor should not make the viewport larger than the window. If this happens, the viewport will be clamped.

The scaling will be done around the viewport region center point, but if this causes the viewport origin to be moved below (0,0), the origin coordinates will be clamped.

See also scaleWidth().
