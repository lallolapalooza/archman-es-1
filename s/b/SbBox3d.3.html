Descripción Detallada

La clase SbBox3d es una abstracción para una caja tridimensional alineada con los ejes.

Esta clase de abstracción de caja es utilizada por otras entidades en la biblioteca Coin para el intercambio y almacenamiento de datos. Proporciona una representación de las esquinas definitorias de una caja en el espacio 3D, con los lados alineados con los 3 ejes principales.

Detailed Description

This class defines a 3D bounding box. It's defined by two points: the minimum coordinates (lower-left-front corner) and the maximum coordinates (upper-right-back corner).

The class provides methods to manipulate the box (i.e. extend, transform, intersect) and query its properties (i.e. center, size, volume).

A box can also be marked as empty (using makeEmpty()), which is checked by isEmpty(). An empty box has no volume and is never considered to contain any points or other boxes.

SbBool SbBox3d::outside (const SbDPMatrix & mvp, int & cullbits) const

Check if the box is outside the view volume defined by the mvp matrix. Sets cullbits according to which planes we're inside or outside. Bit 0 (0x1) is cleared when box is completely inside left and right clipping planes. Bit 1 (0x2) is cleared when box is inside top and bottom clipping planes. Bit 2 (0x4) is cleared when box is inside near and far clipping planes.

Returns TRUE if box is completely outside one of the clipping planes. FALSE otherwise.

void SbBox3d::getSpan (const SbVec3d & dir, double & dmin, double & dmax) const

Find the span of the box in the given direction (i.e. how much room in the given direction the box needs). The distance is returned as the minimum and maximum distance from origo to the closest and furthest plane defined by the direction vector and each of the box' corners. The difference between these values gives the span.
