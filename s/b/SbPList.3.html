void SbPList::fit (void )

Ajusta el array asignado exactamente al tamaño de la lista, descartando memoria gastada en celdas de array preasignadas no utilizadas.

Normalmente no deberías necesitar ni querer llamar a este método, y solo está disponible para tener la opción de optimizar el uso de memoria para el improbable caso de que debas manejar objetos SbList enormes dentro de tu aplicación.

void SbPList::append (void * item) [inline]

Añade item al final de la lista.

Asigna automáticamente más elementos internamente si es necesario.

int SbPList::find (const void * item) const

Devuelve el índice de la primera ocurrencia de item en la lista, o -1 si item no está presente.

void SbPList::insert (void * item, const int insertbefore)

Inserta item en el índice insertbefore.

insertbefore no debe ser mayor que el número actual de elementos en la lista.

void SbPList::removeItem (void * item)

Elimina un item de la lista. Si hay varios elementos con el mismo valor, elimina el item con el índice más bajo.

void SbPList::remove (const int index)

Elimina el elemento en index, moviendo todos los elementos subsiguientes un lugar hacia abajo en la lista.

void SbPList::removeFast (const int index) [inline]

Elimina el elemento en index, moviendo el último elemento a su lugar y truncando la lista.

int SbPList::getLength (void ) const [inline]

Devuelve el número de elementos en la lista.

void SbPList::truncate (const int length, const int fit = 0) [inline]

Acorta la lista para que contenga length elementos, eliminando los elementos desde el índice length en adelante.

Si fit es distinto de cero, también reducirá el tamaño interno del array asignado. Nótese que esto es mucho menos eficiente que no volver a ajustar el tamaño del array.

void ** SbPList::getArrayPtr (const int start = 0) const [inline]

Devuelve un puntero a un array no modificable de los elementos de la lista. start especifica un índice en el array.

El llamador no es responsable de liberar el array, ya que es solo un puntero al array interno utilizado por la lista.

void *& SbPList::operator[] (const int index) const [inline]

Devuelve el elemento en index.

Expandirá automáticamente el tamaño del array interno si index está fuera de los límites actuales de la lista. Los valores de los punteros adicionales se establecerán a NULL.

int SbPList::operator== (const SbPList & l) const

Operador de igualdad. Devuelve TRUE si esta lista y l son idénticas, conteniendo exactamente el mismo conjunto ordenado de elementos.

int SbPList::operator!= (const SbPList & l) const [inline]

Operador de desigualdad. Devuelve TRUE si esta lista y l no son idénticas.

void * SbPList::get (const int index) const [inline]

Devuelve el elemento en index.

void SbPList::set (const int index, void * item) [inline]

Establece el elemento en index a item.

Si index está fuera de los límites actuales de la lista, se reclamará el tamaño del array interno.
