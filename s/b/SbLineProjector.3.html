Descripción Detallada

La clase SbLineProjector proyecta puntos 2D a puntos 3D a lo largo de una línea.

La proyección 3D de las coordenadas 2D está restringida para esta clase de proyector a estar a lo largo de una línea predefinida.

Entre otros lugares, esto es útil dentro de los manejadores de traslación, como por ejemplo SoTranslate1Dragger, donde queremos mover "piezas" a lo largo de uno o más ejes.

Construye y devuelve una copia de este proyector. El llamador es responsable de destruir la nueva instancia.

SbBool SbLineProjector::tryProject (const SbVec2f & point, const float epsilon, SbVec3f & result) [virtual]

Intenta proyectar el punto 2D desde coordenadas de vista normalizadas a un punto 3D. El mapeo se realizará de acuerdo con el tipo del proyector.

Si la proyección no se puede realizar de forma segura (por ejemplo, cuando el plano o la línea de proyección son paralelos a la proyección del volumen de vista), esta función debería devolver FALSE.

La implementación predeterminada llamará a project() y siempre devolverá TRUE, pero las subclases pueden anular este comportamiento para admitir proyecciones seguras.
