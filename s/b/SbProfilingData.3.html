NAME

SbProfilingData - Profiling data accumulator class

SYNOPSIS

#include <Inventor/SbProfiling.h>

Inheritance diagram for SbProfilingData:

+-- SbProfilingData

Detailed Description

This class is used to accumulate profiling data. It is intended to be used to collect timing information about parts of the scenegraph traversal, or other computations.

The data is organized hierarchically, mirroring the scenegraph structure. Each node in the scenegraph can have associated profiling data, which is accessed via the SoPath object.
