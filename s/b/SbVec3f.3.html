Descripción detallada

La clase SbVec3f es un vector tridimensional con coordenadas de punto flotante.

Esta clase de vector es utilizada por muchas otras clases en Coin. Proporciona almacenamiento para un vector tridimensional, así como operaciones simples de aritmética de punto flotante.

float SbVec3f::normalize (void )

Normaliza el vector a longitud unitaria. El valor devuelto es la longitud original del vector antes de la normalización.

Si el vector es el vector nulo, no se intentará la normalización. Si la biblioteca Coin se compiló en una versión de depuración y la variable de entorno COIN_DEBUG_NORMALIZE está establecida, se mostrará el siguiente mensaje de error:

  Coin warning in SbVec3f::normalize(): The length of the vector
  should be > 0.0f to be able to normalize.

Hemos hecho posible que Coin muestre una advertencia cuando se intenta normalizar un vector nulo, ya que esto a veces parece ser un síntoma causado por un error más grave en otro lugar: ya sea un error interno en el código de Coin, un error de programación en el código de la aplicación o un error en un archivo de entrada (como, por ejemplo, especificaciones de polígonos inválidas).

Si encuentra errores/problemas con su aplicación o con Coin, podría ser una buena idea establecer COIN_DEBUG_NORMALIZE=1 y luego reiniciar la aplicación para ver si recibe alguna advertencia de normalize().

Si esto sucede, debería ejecutar la aplicación en un depurador y ver cómo se ve la traza de la pila de llamadas cuando se detiene. Una forma fácil de obtener una interrupción del depurador en el punto de advertencia es establecer la siguiente variable de entorno de depuración, que hará que el código genere una aserción:

  COIN_DEBUG_BREAK="SbVec3f::normalize"

Si a partir del análisis de la traza de la pila sospecha firmemente de un error interno de Coin, por favor, infórmenos de la pila de llamadas en coin-support@coin3d.org y lo investigaremos. El código de ejemplo que desencadena el error también sería muy útil.

Una nota para los desarrolladores que portan código de SGI o TGS Inventor a Coin: esas implementaciones de Inventor son más permisivas a la hora de detectar y emitir advertencias sobre el mal uso de la API, y es posible que ahora reciba esta advertencia con Coin sin haber visto ninguna indicación de error con SGI/TGS Inventor. Esto no significa necesariamente que sea un error en Coin; es mucho más probable que reciba una advertencia como indicación de mal uso de la API o errores en archivos de importación que simplemente no fueron detectados y/o reportados con esas implementaciones de Inventor.
