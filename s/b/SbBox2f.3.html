Descripción detallada

La clase SbBox2f es una caja 2 dimensional con coordenadas de esquina de punto flotante.

Esta clase de caja es utilizada por muchas otras clases en Coin para intercambio y almacenamiento de datos. Proporciona dos esquinas de caja con coordenadas de punto flotante, lo cual es útil, entre otras cosas, para representar dimensiones de pantalla o lienzo en coordenadas normalizadas.

Detailed Description

The SbBox2f class defines an axis-aligned rectangular box in 2D space. The box is defined by its minimum and maximum corner points.
