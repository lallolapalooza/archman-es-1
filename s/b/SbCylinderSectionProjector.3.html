Descripción Detallada

El SbCylinderSectionProjector proyecta puntos 2D a un cilindro seccionado.

El cilindro de proyección para esta clase está seccionado por un plano de corte paralelo a su eje de altura. Las proyecciones se mapearán a la parte restante del cilindro.

SbCylinderSectionProjector::SbCylinderSectionProjector (const float edgetol = 0.9f, const SbBool orienttoeye = TRUE)

Constructor por defecto. Ver SbCylinderProjector::SbCylinderProjector().

El valor edgetol debe estar entre <0, 1], y especifica cuánto del cilindro se usa como superficie de proyección. 1.0 significa que se usa la mitad frontal completa.
