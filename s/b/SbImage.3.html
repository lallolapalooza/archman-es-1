Descripción detallada

La clase SbImage es un tipo de datos abstracto para imágenes 2D y 3D.

Deberías estar consciente de que esta clase es una extensión de Coin y no está disponible en el API original de SGI Open Inventor v2.1.

void SbImage::setValue (const SbVec3s & size, const int bytesperpixel, const unsigned char * bytes)

Establece la imagen con tamaño size y bytesperpixel. Si bytes != NULL, los datos se copian de bytes a esta clase. Si bytes == NULL, los datos se dejan sin inicializar.

Los datos de imagen siempre se almacenan en múltiplos de 4. Esto significa que si estableces una imagen con size == (1,1,1) y bytesperpixel == 1, se asignarán 4 bytes para almacenar los datos. Esto se hace principalmente para simplificar el código de exportación en SoSFImage, y normalmente no tendrás que preocuparte por esta función.

Si la profundidad de la imagen (size[2]) es 0, se considera una imagen 2D.

SbBool SbImage::readFile (const SbString & filename, const SbString *const * searchdirectories = NULL, const int numdirectories = 0)

Lee los datos de imagen desde el archivo filename. En Coin, simage se usa para cargar archivos de imagen, y varios formatos comunes son compatibles. simage puede descargarse desde nuestras páginas web. Si falla al cargar por alguna razón, este método devuelve FALSE, y la instancia se establece a una imagen vacía. Si el archivo se carga correctamente, los datos de imagen del archivo se copian en esta clase.

Si numdirectories > 0, este método buscará filename en todos los directorios en searchdirectories.

void SbImage::addReadImageCB (SbImageReadImageCB * cb, void * closure) [static]

Agrega una función de devolución de llamada que se llamará cada vez que Coin quiera leer un archivo de imagen. La función de devolución de llamada debe devolver TRUE si pudo leer y establecer correctamente los datos de la imagen, y FALSE en caso contrario.

Se llamará a las funciones de devolución de llamada antes de intentar usar simage para cargar imágenes.

SbString SbImage::searchForFile (const SbString & basename, const SbString *const * dirlist, const int numdirs) [static]

Dado un basename para un archivo y una matriz de directorios para buscar (en dirlist, de longitud numdirs), devuelve el nombre completo del archivo encontrado.

Además de buscar en la raíz de cada directorio en dirlist, también buscamos en los subdirectorios texture/, textures/, images/, pics/ y pictures/ de cada directorio de dirlist.

Si no se encuentra ningún archivo que coincida con basename, devuelve una cadena vacía.

Devuelve TRUE si la imagen no está vacía. Esto puede ser útil, ya que getValue() comenzará a cargar la imagen si se ha utilizado scheduleReadFile() para establecer los datos de la imagen.

void SbImage::readLock (void ) const

Aplica un bloqueo de lectura en esta imagen. Esto hará imposible que otros hilos cambien la imagen mientras este bloqueo esté activo. Otros hilos pueden realizar operaciones de solo lectura en esta imagen, por supuesto.

Para la versión de un solo hilo de Coin, este método no hace nada.
