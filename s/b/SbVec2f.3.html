Descripción detallada

La clase SbVec2f es un vector de 2 dimensiones con coordenadas de punto flotante.

Esta clase de vector es utilizada por muchas otras clases en Coin. Proporciona almacenamiento para un vector en 2 dimensiones, así como operaciones aritméticas simples de punto flotante sobre este vector.

Ver también

SbVec2s, SbVec2d, SbVec3s, SbVec3f, SbVec3d, SbVec4f, SbVec4d.

Detailed Description

This is a 2D vector class with float components. It supports standard vector operations like addition, subtraction, scaling, dot product, normalization, etc. The class is derived from SbVec2d, which is the base class for 2D vectors with double precision components.
