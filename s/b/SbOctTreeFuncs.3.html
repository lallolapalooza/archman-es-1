Descripción Detallada

La estructura SbOctTreeFuncs se utiliza para especificar funciones de devolución de llamada para trabajar con elementos en un SbOctTree.

El único puntero a función que *debe* configurarse es insideboxfunc. Las otras funciones deben configurarse si tiene la intención de utilizar los métodos de búsqueda correspondientes en SbOctTree.

SbBool(* SbOctTreeFuncs::insideplanesfunc) (void *const item, const SbPlane *const planes, const int numplanes)

Debe devolver si el elemento está completamente o parcialmente dentro de un conjunto de planos.
