Descripción detallada

La clase SbProjector es la clase base abstracta de proyector.

Los proyectores se utilizan en la biblioteca Coin para mapear coordenadas 2D (típicamente de la posición del cursor del ratón en la ventana de renderizado) a coordenadas 3D del "mundo".

Mapear coordenadas 2D a coordenadas 3D es algo que se hace ampliamente en las clases dragger, para proporcionar al usuario una forma conveniente y natural de interactuar con la geometría 3D de las escenas.

Para un ejemplo de uso, consulte la documentación de la clase SbSphereSheetProjector.

El programador de aplicaciones normalmente no necesita preocuparse por las clases de proyector, a menos que haya necesidades especiales en la aplicación.

virtual SbProjector * SbProjector::copy (void ) const [pure virtual]

Construye y devuelve una copia de este proyector. El llamador es responsable de destruir la nueva instancia.

Tenga en cuenta que si la biblioteca Coin se ha compilado como DLL en Microsoft Windows y utiliza este método desde el código de la aplicación, debe asegurarse de que tanto la DLL de Coin como el ejecutable de la aplicación estén utilizando la misma instancia de una biblioteca C Run-Time (CRT). De lo contrario, obtendrá corrupción del montón de memoria al liberar las instancias devueltas, lo que provocará fallos misteriosos.

Implementado en SbCylinderPlaneProjector, SbCylinderSectionProjector, SbCylinderSheetProjector, SbLineProjector, SbPlaneProjector, SbSpherePlaneProjector, SbSphereSectionProjector y SbSphereSheetProjector.

SbBool SbProjector::tryProject (const SbVec2f & point, const float epsilon, SbVec3f & result) [virtual]

Intenta proyectar el point 2D de coordenadas de ventana normalizadas a un punto 3D. El mapeo se realizará de acuerdo con el tipo de proyector.

Si la proyección no se puede realizar de forma segura (por ejemplo, cuando el plano o la línea de proyección son paralelos a la proyección del volumen de vista), esta función debería devolver FALSE.

La implementación predeterminada llamará a project() y siempre devolverá TRUE, pero las subclases pueden anular este comportamiento para admitir proyecciones seguras.

Reimplementado en SbLineProjector y SbPlaneProjector.

float SbProjector::findVanishingDistance (void ) const [protected]

Encuentra la distancia de punto de fuga del cubo unitario para el volumen de vista del proyector actual. El volumen de vista debe ser un volumen de vista en perspectiva.

Este método no formaba parte de la API de Inventor v2.1 y es una extensión específica de Coin.

SbBool SbProjector::verifyProjection (const SbVec3f & projpt) const [protected]

Verifica que projpt sea una proyección válida para el volumen de vista actual. Para volúmenes de vista de perspectiva, lo hace verificando que el punto de proyección esté delante del plano del ojo. Para proyecciones ortográficas, este método siempre devuelve TRUE.
