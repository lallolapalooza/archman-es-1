Descripción Detallada

La clase SbCylinderSheetProjector proyecta puntos 2D a puntos 3D en una lámina que cubre una forma cilíndrica.

Documentación de Constructor y Destructor

SbCylinderSheetProjector::SbCylinderSheetProjector (const SbBool orienttoeye = TRUE)

Constructor. Utiliza la definición de cilindro por defecto, véase SbCylinderProjector::SbCylinderProjector().

orienttoeye decide si el cilindro y la lámina deben estar orientados hacia el espectador o no.

SbProjector * SbCylinderSheetProjector::copy (void ) const [virtual]

Construye y devuelve una copia de este proyector. El llamador es responsable de destruir la nueva instancia.

Tenga en cuenta que si la biblioteca Coin se ha compilado como una DLL en Microsoft Windows y utiliza este método desde código de aplicación, debe asegurarse de que tanto la DLL de Coin como el ejecutable de la aplicación utilicen la misma instancia de una biblioteca C en tiempo de ejecución (CRT). De lo contrario, obtendrá corrupción del montón de memoria al liberar las instancias devueltas, lo que eventualmente provocará fallos misteriosos.
