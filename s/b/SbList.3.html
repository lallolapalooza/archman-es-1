Descripción detallada

template<typename Tipo>

class SbList< Tipo >"La clase SbList es una clase contenedora de plantilla para listas.

SbList es una extensión de la biblioteca Coin frente a la API original de Open Inventor. Open Inventor maneja la mayoría de las clases de listas heredando de la clase SbPList, que contiene un array de punteros void* genéricos. Al usar esta clase basada en plantillas en su lugar, podemos compartir más código y hacer que el código de manejo de listas sea más seguro en cuanto a tipos.

Se ha tenido cuidado para asegurarse de que las clases de lista que forman parte de la API de Open Inventor sigan siendo compatibles con sus interfaces originales, ya que se derivan de la clase base SbPList. Pero si aún encuentra algún problema al migrar sus aplicaciones de Open Inventor, háganoslo saber y haremos todo lo posible para solucionarlos.

Una característica de esta clase es que los arrays de objetos de lista crecen dinámicamente a medida que append() más elementos a la lista. La técnica de crecimiento real utilizada es duplicar el tamaño de la lista cuando se vuelve demasiado pequeña.

También hay otros métodos de conveniencia relacionados con arrays; por ejemplo, encontrar índices de elementos, insertar elementos en cualquier posición, eliminar elementos (y reducir el array), copiar arrays, etc.

Documentación del constructor y destructor

template<typename Tipo> SbList< Tipo >::SbList (const int sizehint = DEFAULTSIZE) [inline]

Constructor predeterminado.

El argumento sizehint da una pista sobre cuántos elementos contendrá la lista, para que la asignación de memoria se pueda realizar de manera eficiente.

Nota importante: especificar explícitamente un valor de sizehint no significa que la lista contendrá inicialmente este número de valores. Después de la construcción, la lista contendrá cero elementos, al igual que para el constructor predeterminado. Aquí tienes un buen ejemplo de cómo darte errores difíciles de encontrar:

SbList<SbBool> flags(2); // Supongamos que solo necesitamos 2 elementos. Ten en cuenta
                         // que la lista sigue teniendo 0 elementos.
flags[0] = TRUE;         // Ay. La lista todavía tiene 0 elementos.

Dado que este malentendido conceptual es tan fácil de cometer, probablemente sea mejor (o al menos más seguro) dejar el argumento sizehint en su valor predeterminado sin especificarlo explícitamente.

Mejora el rendimiento si conoces el tamaño total aproximado de la lista de antemano antes de agregar elementos a la lista, ya que el número de reasignaciones se minimizará.

Detailed Description

This class is an instantiation of a generic list class template. It is implemented as a dynamic array of items.

The list supports adding and removing items at the end, and accessing elements by index.

The list can be used to implement a stack (using append() and pop()) or a queue (using insert() and remove() at index 0).

SbList is intended to be the base class for other list classes, and therefore has a few protected methods that are not available to the user of the class.
