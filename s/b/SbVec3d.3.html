Descripción detallada

La clase SbVec3d es un vector de 3 dimensiones con coordenadas de punto flotante de doble precisión.

Esta clase de vector proporciona almacenamiento para un vector de 3 dimensiones de doble precisión de punto flotante, así como operaciones aritméticas simples de punto flotante.

DESCRIPTION

This class provides functionality for 3D vectors with double precision floating-point components. It is part of the Coin 3D library.
