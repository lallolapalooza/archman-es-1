Los proyectores esféricos mapean puntos 2D a varios tipos de superficies basados en formas esféricas.

Detailed Description

This class defines a spherical projection mapping. It is used for example in SbSphereDragger.

The spherical projection maps 3D points onto the surface of a sphere. This is done by finding the intersection of a line from the camera's eye through the 3D point with the sphere. The result is then transformed from the projector's coordinate system to the world coordinate system.

Reimplemented from SbProjector.

SbBool SbSphereProjector::project (const SbVec3f & point3d, SbVec3f & point2d) [virtual]

Maps the given 3D point onto the sphere surface and returns the corresponding 2D screen coordinate. This function translates the projection from the projector's coordinate system to the world coordinate system.

Returns TRUE if the point was successfully projected onto the sphere, FALSE otherwise.
