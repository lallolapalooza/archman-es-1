Descripción detallada

La clase SbRotation representa una rotación en el espacio 3D.

SbRotation se utiliza ampliamente en toda la biblioteca Coin.

Una SbRotation se almacena internamente como un cuaternión por razones de velocidad y almacenamiento, pero se pueden realizar consultas para obtener y establecer valores de eje y ángulo para mayor comodidad.

Tenga en cuenta que hay un error muy común que es fácil de cometer al establecer el valor de una SbRotation, y es usar inadvertidamente el constructor SbRotation incorrecto. Este ejemplo debería aclarar el problema:

SbRotation rotacion(0, 0, 1, 1.5707963f);

El programador claramente intenta establecer una rotación de PI/2 alrededor del eje Z, pero esto fallará, ya que el constructor SbRotation invocado anteriormente es el que toma como argumentos los 4 flotantes de un cuaternión. Lo que el programador casi con certeza quería hacer era utilizar el constructor SbRotation que toma un vector de rotación y un ángulo de rotación, que se invoca de la siguiente manera:

SbRotation rotacion(SbVec3f(0, 0, 1), 1.5707963f);

Otro problema común es establecer el valor de rotación a 0.0 exactamente, mientras se desea almacenar solo la información sobre un ángulo de rotación: las rotaciones se manejan internamente como cuaterniones, y al convertir de un ángulo y un valor de rotación a una representación de cuaternión, la información sobre el ángulo se "pierde" si no hay una rotación real.

SbRotation::SbRotation (const float q[4])

Construye un nuevo objeto SbRotation inicializado con los componentes de cuaternión dados.

El array debe estar ordenado de la siguiente manera:

q[0] = x, q[1] = y, q[2] = z y q[3] = w, donde el cuaternión se especifica como q = w + xi + yj + zk.

Ejemplo:

#include <Inventor/SbRotation.h>
#include <Inventor/SbVec3f.h>
#include <cstdio>
int
main(void)
{
  SbVec3f desde(10, 0, 0);
  SbVec3f hasta(0, 10, 0);
  SbRotation rot(desde, hasta);
  SbVec3f eje;
  float angulo;
  rot.getValue(eje, angulo);
  eje.print(stdout);
  printf("  angulo==%f\n", angulo);
  return 0;
}

DESCRIPTION

The SbRotation class stores a rotation using a quaternion.

Quaternions are four-dimensional vectors of the form (x, y, z, w), where x, y, and z represent a rotation vector and w represents the amount of rotation. Note that the internal representation is normalized so that x*x + y*y + z*z + w*w = 1.

Rotations can be combined by quaternion multiplication. The order of operations is important: if you have two rotations, q1 and q2, applying q1 then q2 is equivalent to calculating q2*q1. If you have a rotation q and a vector v, applying q to v is equivalent to calculating q*v*q^-1.

The SbRotation class supports operations such as rotation combination, inversion, and conversion to/from other rotation representations.
