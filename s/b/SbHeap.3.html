Documentación del Constructor y Destructor

SbHeap::SbHeap (const SbHeapFuncs & hFuncs, const int initsize = 1024)

Constructor. hFuncs especifica las funciones para modificar y devolver información sobre el objeto del montículo, initsize especifica el número inicial de elementos asignados. Esta matriz crecerá automáticamente cuando sea necesario, pero si sabes aproximadamente cuántos elementos contendrá el montículo, deberías proporcionarlo para evitar algunas reasignaciones.
