Descripción detallada

La clase SbPlaneProjector proyecta puntos 2D a puntos 3D en un plano.

La proyección 3D de las coordenadas 2D está restringida para esta clase de proyector a permanecer dentro de un plano 3D predefinido.

SbBool SbPlaneProjector::tryProject (const SbVec2f & point, const float epsilon, SbVec3f & result) [virtual]

Intenta proyectar el punto 2D desde coordenadas normalizadas de volumen de visualización a un punto 3D. El mapeo se realizará de acuerdo con el tipo del proyector.

Si la proyección no se puede realizar de forma segura (por ejemplo, cuando el plano o la línea de proyección son paralelos a la proyección del volumen de visualización), esta función debería devolver FALSE.

La implementación predeterminada llamará a project() y siempre devolverá TRUE, pero las subclases pueden anular este comportamiento para admitir proyecciones seguras.

Detailed Description

This class provides projection onto a plane. The plane is defined by an origin, a normal vector, an up-vector and a direction-vector. All these vectors must be orthogonal. The up-vector is used to orient the plane relative to the screen coordinate system.

The orientToEye flag influences how the plane is oriented. If TRUE (the default), the plane will be oriented so that the camera's viewpoint is kept within the plane. If FALSE, the plane will be kept fixed relative to the viewing frustum.

This projector is especially useful when you want to define a projection plane from a 3D object, e.g. you want to drag an object along the surface of another.

The projector uses the OpenGL viewport and projection matrices to calculate the 3D point corresponding to a 2D screen coordinate.
