Descripción detallada

La clase SbColor4f contiene los componentes rojo, verde, azul y alfa que componen un valor de color.

Esta clase se utiliza internamente dentro de otras clases en Coin. Contiene un vector de 4 componentes como posición en el cubo RGB con un valor de transparencia adicional.

Los valores rojo, verde y azul deben estar entre 0.0 y 1.0, donde 0.0 se interpreta como intensidad mínima y 1.0 como intensidad máxima. El valor de transparencia también está entre 0.0 y 1.0.

SbColor4f contiene métodos para el manejo conveniente de la configuración y obtención de valores de color como valores empaquetados de 32 bits o como valores HSV.

Nota: esta clase no es parte de Open Inventor, sino una extensión de la API. No la uses si deseas que tu código sea compatible con Open Inventor.

Detailed Description

This class is used to store a color with 4 components (red, green, blue, and alpha), each of which is represented as a floating-point value between 0.0 and 1.0.
