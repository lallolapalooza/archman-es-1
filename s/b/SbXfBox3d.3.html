Descripción Detallada

La clase SbXfBox3d es una caja 3 dimensional con coordenadas de precisión doble y una transformación adjunta.

Proporciona almacenamiento para dos esquinas de caja con coordenadas de punto flotante de precisión doble, y para una matriz de transformación de precisión doble 4x4.

Ver también

SbBox3d, SbDPMatrix, SbXfBox3f

void SbXfBox3d::extendBy (const SbBox3d & bb)

Extiende los límites de la caja por el parámetro bb dado. Se asume que la caja dada está en el espacio transformado.

Las dos cajas dadas se combinarán de tal manera que la caja delimitadora resultante siempre tenga el volumen más pequeño posible. Para lograr esto, la transformación en esta SbXfBox3f a veces se aplanará antes de combinarse con bb.

Extiende los límites de la caja por el parámetro bb dado.

Nota: no se garantiza que proporcione un resultado óptimo si se utiliza para el cálculo de la caja delimitadora, ya que la matriz de transformación podría cambiar. Consulte la documentación en SoGetBoundingBoxAction para más detalles.

Description

This class is a subclass of SbBox3d that includes a transformation matrix.

The transformation matrix is applied to the box only when needed.

void SbXfBox3d::getSpan (const SbVec3d & direction, double & dMin, double & dMax) const

Find the span of the box in the given direction (i.e. how much room in the given direction the box needs). The distance is returned as the minimum and maximum distance from origo to the closest and furthest plane defined by the direction vector and each of the box' corners. The difference between these values gives the span.
