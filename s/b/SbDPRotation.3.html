Descripción detallada

La clase SbDPRotation representa una rotación en el espacio 3D utilizando datos de doble precisión.

SbDPRotation se utiliza ampliamente en toda la biblioteca Coin.

Una SbDPRotation se almacena internamente como un cuaternión por razones de velocidad y almacenamiento, pero se pueden realizar consultas para obtener y establecer valores de eje y ángulo para mayor comodidad.

SbDPRotation::SbDPRotation (const double q[4])

Construye un nuevo objeto SbDPRotation inicializado con los componentes de cuaternión dados.

El array debe estar ordenado de la siguiente manera:

q[0] = x, q[1] = y, q[2] = z y q[3] = w, donde el cuaternión se especifica como q = w + xi + yj + zk.

Detailed Description

This class is used to represent rotations using quaternions. Quaternions are a four-dimensional number system that can be used to represent rotations in three-dimensional space. They have several advantages over other methods of representing rotations, such as Euler angles or rotation matrices, including avoiding gimbal lock and allowing for efficient interpolation.

The SbDPRotation class stores the rotation as a quaternion (q0, q1, q2, q3), where q0 is the scalar part and (q1, q2, q3) is the vector part.

Spherical linear interpolation between two rotations.

Returns the SbDPRotation which will rotate rot0 the given part t of the spherical distance towards rot1, where t=0 will yield rot0 and t=1 will yield rot1.

t should be in the interval [0, 1].

See also getValue().
