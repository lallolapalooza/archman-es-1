Descripción detallada

La clase SbMatrix es una representación de dimensión 4x4 de una matriz.

SbMatrix es utilizada por muchas otras clases en Coin. Proporciona almacenamiento para una matriz de 4x4 de valores de punto flotante de precisión simple.

Por definición, las matrices en Coin deben configurarse en modo de orden de columnas. Este es el mismo orden que utiliza, por ejemplo, OpenGL, pero ten en cuenta que los libros de geometría a menudo usan el modo opuesto de orden de filas, lo que puede confundir a los recién llegados a la API.

Otra forma de pensar en matrices de orden de columnas es que utilizan multiplicaciones en orden postfijo: es decir, para concatenar una transformación de una segunda matriz con tu matriz actual, debe multiplicarse en el lado derecho, es decir, con el método SbMatrix::multRight().

Si tienes una matriz en orden de filas de alguna otra fuente, se puede "convertir" a orden de columnas transponiéndola con SbMatrix::transpose(). Un ejemplo simple ayudará a explicar esto.

Con matrices de orden de filas, una matriz de transformación con posición, rotación y escala se ve así:

M = T * R * S

Donde T es traslación, R es rotación y S es la escala. Lo que esto significa es que la escala se aplica primero. La matriz escalada se rota luego, y finalmente la matriz escalada y rotada se traslada. Al usar matrices de orden de columnas, como se hace en Coin, las matrices se representan ligeramente diferente; el orden de multiplicación se invierte:

M = S * R * T

La transformación es la misma que la matriz de orden de filas. La única diferencia es el orden de multiplicación. Para entender por qué esto es así, considera la transformación de muestra:

M = T * R * S

Convertir M de una matriz de orden de filas a una matriz de orden de columnas se hace de la siguiente manera:

M^t = (T * R * S)^t
M^t = ((T * R) * S)^t
M^t = S^t * (T * R)^t
M^t = S^t * R^t * T^t

Todo lo que queda por hacer es eliminar los símbolos de transpuesta, y las matrices se han convertido a matrices de orden de columnas:

M = S * R * T

Esto se hizo utilizando el hecho de que:

A^t = (B * C)^t = C^t * B^t

La conversión de orden de columnas a orden de filas se hace usando el mismo principio.

Class Documentation

SbMatrix

Matrix class.

This class encapsulates a 4x4 matrix. For efficiency, it is implemented as a standard C++ class. The matrix elements are stored as a standard 16-element array of floats.

The matrix elements are stored in column-major order. That is, the elements of the first column are stored first, then the elements of the second column, and so on.

The matrix is defined as:

      col 0      col 1      col 2      col 3
(      0,0        1,0        2,0        3,0       )  row 0
(      0,1        1,1        2,1        3,1       )  row 1
(      0,2        1,2        2,2        3,2       )  row 2
(      0,3        1,3        2,3        3,3       )  row 3

The elements are stored in the array as:

elements[0] = 0,0    elements[4] = 1,0    elements[8]  = 2,0    elements[12] = 3,0
elements[1] = 0,1    elements[5] = 1,1    elements[9]  = 2,1    elements[13] = 3,1
elements[2] = 0,2    elements[6] = 1,2    elements[10] = 2,2    elements[14] = 3,2
elements[3] = 0,3    elements[7] = 1,3    elements[11] = 2,3    elements[15] = 3,3

Where the index of the element is calculated as: column * 4 + row.

The matrix class is used for storing and manipulating 4x4 transformation matrices in 3D graphics. It supports operations such as multiplication, inversion, and decomposition into translation, rotation, and scaling components.

Note that this class is implemented using the Microsoft Visual C++ compiler.

SbBool SbMatrix::LUDecomposition (int index[4], float & d)

This function produces a permuted LU decomposition of the matrix. It uses the common single-row-pivoting strategy.

FALSE is returned if the matrix is singular, which it never is, because of small adjustment values inserted if a singularity is found (as Open Inventor does too).

The parity argument is always set to 1.0 or -1.0. Don't really know what it's for, so it's not checked for correctness.

The index[] argument returns the permutation that was done on the matrix to LU-decompose it. index[i] is the row that row i was swapped with at step i in the decomposition, so index[] is not the actual permutation of the row indexes!

BUGS: The function does not produce results that are numerically identical with those produced by Open Inventor for the same matrices, because the pivoting strategy in OI was never fully understood.

See also

SbMatrix::Solve

Detailed Description

A 4x4 matrix used for 3D transformations. SbMatrix is the standard transformation matrix class for Open Inventor. It uses column-major ordering.

void SbMatrix::LUBackSubstitution (int index[4], float b[4]) const

This function does a solve on the "Ax = b" system, given that the matrix is LU-decomposed in advance. First, a forward substitution is done on the lower system (Ly = b), and then a backwards substitution is done on the upper triangular system (Ux = y).

The index[] argument is the one returned from SbMatrix::LUDecomposition(), so see that function for an explanation.

The b[] argument must contain the b vector in "Ax = b" when calling the function. After the function has solved the system, the b[] vector contains the x vector.

BUGS: As is done by Open Inventor, unsolvable x values will not return NaN but 0.

void SbMatrix::multMatrixVec (const SbVec3f & src, SbVec3f & dst) const

Multiply src vector with this matrix and return the result in dst. Multiplication is done with the vector on the right side of the expression, i.e. dst = M * src.

(Be aware that it is more common to use the SbMatrix::multVecMatrix() operation, when doing vector transformations, as SbMatrix instances are by definition in column-order, and uses post-multiplication for common geometry operations.)

See also

multVecMatrix(), multDirMatrix() and multLineMatrix().

void SbMatrix::multVecMatrix (const SbVec3f & src, SbVec3f & dst) const

Multiply src vector with this matrix and return the result in dst. Multiplication is done with the vector on the left side of the expression, i.e. dst = src * M.

It is safe to let src and dst be the same SbVec3f instance.

This method can be used (using the current model matrix) to transform a point from an object coordinate systems to the world coordinate system.

This operation is what you would usually do when transforming vectors, as SbMatrix instances are, by definition, column-order matrices.

See also

multMatrixVec(), multDirMatrix() and multLineMatrix().

void SbMatrix::multDirMatrix (const SbVec3f & src, SbVec3f & dst) const

Multiplies src by the matrix. src is assumed to be a direction vector, and the translation components of the matrix are therefore ignored.

Multiplication is done with the vector on the left side of the expression, i.e. dst = src * M.
