Descripción detallada

La clase SbDict organiza un diccionario de claves y valores.

Utiliza hashing para insertar y buscar entradas en el diccionario rápidamente. Una entrada consiste en una clave única y un puntero genérico.

void SbDict::clear (void )

Borra todas las entradas del diccionario.

SbBool SbDict::enter (const Key key, void *const value)

Inserta una nueva entrada en el diccionario. key debe ser un número único y value son los datos genéricos del usuario.

Si key no existe en el diccionario, se crea una nueva entrada y se devuelve TRUE. De lo contrario, los datos genéricos del usuario se cambian a value y se devuelve FALSE.

SbBool SbDict::find (const Key key, void *& value) const

Busca key en el diccionario. Si existe una entrada con esta clave, se devuelve TRUE y el valor de la entrada se devuelve en value. De lo contrario, se devuelve FALSE.

void SbDict::makePList (SbPList & keys, SbPList & values)

Crea listas con todas las entradas del diccionario.

SbBool SbDict::remove (const Key key)

Elimina la entrada con la clave key. Se devuelve TRUE si una entrada con esta clave estaba presente, FALSE en caso contrario.

void SbDict::setHashingFunction (SbDictHashingFunc * func)

Establece una nueva función de hashing para este diccionario. La función de hashing por defecto simplemente devuelve la clave.

Si encuentra que los elementos introducidos en el diccionario parecen formar clústeres en solo unas pocas cubetas, debería intentar establecer una función de hashing. Si, por ejemplo, está utilizando cadenas, podría usar la función estática SbString::hash() (necesitaría crear una función estática que convierta de SbDict::Key a char * , por supuesto).

Esta función no forma parte de la API de OIV.
