Descripción detallada

La clase SbOctTree define un árbol octal general para búsquedas de geometría rápidas.

Tenga en cuenta que esta clase es una extensión de Coin y no está disponible en el API original de SGI Open Inventor v2.1.

void SbOctTree::addItem (void *const item)

Añade un elemento a este árbol octal.

void SbOctTree::removeItem (void *const item)

Elimina el elemento del árbol octal. El árbol no se modificará ni se simplificará incluso si se eliminan todos los elementos.

void SbOctTree::findItems (const SbVec3f & pos, SbList< void * > & destarray, const SbBool removeduplicates = TRUE) const

Encuentra todos los elementos que contienen la posición pos. Los elementos se devuelven en destarray.

Si removeduplicates es TRUE (por defecto), destarray no contendrá elementos duplicados. Este proceso no está optimizado, así que si buscas velocidad, deberías establecer este valor a FALSE y realizar tu propio procesamiento de la lista de elementos devueltos.

Nota: si la biblioteca Coin ha sido compilada como DLL bajo Windows y utilizas este método desde código de aplicación, deberás asegurarte de que tanto la DLL de Coin como el ejecutable de la aplicación estén usando la misma instancia de la biblioteca de tiempo de ejecución (CRT). De lo contrario, podrías obtener corrupción de memoria durante la liberación de los objetos devueltos, lo que finalmente causará colisiones de pila misteriosas.
