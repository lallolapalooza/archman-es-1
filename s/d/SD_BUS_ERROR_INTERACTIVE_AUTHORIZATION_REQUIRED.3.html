DESCRIPCIÓN

Además de los nombres de error que definen los programas de usuario, D-Bus conoce una serie de nombres de error genéricos y estandarizados que se enumeran a continuación.

Además de esta lista, en sd-bus, el espacio de nombres de error especial "System.Error." se utiliza para mapear errores genéricos del sistema Linux (según se definen en errno(3)) a errores D-Bus y viceversa. Por ejemplo, el error EUCLEAN se mapea a "System.Error.EUCLEAN" y viceversa.

SD_BUS_ERROR_FAILED

Una indicación de error genérica. Consulte el mensaje de error para obtener más detalles. Este nombre de error debe evitarse, en favor de un nombre de error más expresivo.

Añadido en la versión 223.

DESCRIPCIÓN

Los valores enumerados definidos aquí representan todos los errores que se pueden devolver de una llamada de método de sd-bus o una operación relacionada con el bus.

La enumeración sd_bus_error_codes_t incluye un gran número de códigos de error específicos que se corresponden con los códigos de error definidos por la especificación D-Bus, así como algunos adicionales definidos por systemd.

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

No se permite el acceso a la operación solicitada. Sin embargo, podría estar disponible después de una autenticación interactiva. Esto generalmente se devuelve en llamadas a métodos que admiten un marco para autorización interactiva adicional, cuando la autorización interactiva no se habilitó con sd_bus_message_set_allow_interactive_authorization(3) para el mensaje de llamada al método.

Añadido en la versión 223.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar contra y enlazar con el archivo pkg-config(1) de libsystemd.

El código descrito aquí utiliza getenv(3), que está declarado como no seguro para hilos. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
