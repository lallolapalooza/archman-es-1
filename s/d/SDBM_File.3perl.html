NOMBRE

SDBM_File - Acceso enlazado a archivos sdbm

SINOPSIS

use Fcntl;   # Para O_RDWR, O_CREAT, etc.
use SDBM_File;
tie(%h, 'SDBM_File', 'nombre_archivo', O_RDWR|O_CREAT, 0666)
  or die "No se pudo enlazar el archivo SDBM 'nombre_archivo': $!; abortando";
# Ahora lee y modifica el hash
$h{nuevaclave} = nuevovalor;
print $h{clavevieja}; 
...
untie %h;

DESCRIPCIÓN

"SDBM_File" establece una conexión entre una variable hash de Perl y un archivo en formato SDBM_File. Puedes manipular los datos del archivo como si estuvieran en un hash de Perl, pero cuando tu programa termine, los datos permanecerán en el archivo, para ser utilizados la próxima vez que tu programa se ejecute.

Enlace (Tie)

Usa "SDBM_File" con la función incorporada de Perl "tie" para establecer la conexión entre la variable y el archivo.

tie %hash, 'SDBM_File', $basename, $modeflags, $perms;
tie %hash, 'SDBM_File', $dirfile,  $modeflags, $perms, $pagfilename;

$basename es el nombre base del archivo para la base de datos. La base de datos consta de dos archivos con extensiones ".dir" y ".pag" añadidas a $basename,

$basename.dir     (o .sdbm_dir en VMS, según la constante DIRFEXT)
$basename.pag

Los dos nombres de archivo también se pueden dar por separado de forma completa como $dirfile y $pagfilename. Esto es adecuado para dos archivos sin extensiones ".dir" y ".pag", quizás, por ejemplo, dos archivos de File::Temp.

$modeflags puede ser las siguientes constantes del módulo "Fcntl" (al estilo de la llamada al sistema open(2)),

O_RDONLY          acceso de solo lectura
O_WRONLY          acceso de solo escritura
O_RDWR            acceso de lectura y escritura

Si deseas crear el archivo si no existe, utiliza el OR a nivel de bits ("|") con "O_CREAT". Si omites "O_CREAT" y la base de datos no existe, la llamada "tie" fallará.

O_CREAT           crear la base de datos si no existe

$perms son los bits de permisos de archivo que se usarán si se crean nuevos archivos de base de datos. Este parámetro es obligatorio incluso cuando no se crea una nueva base de datos. Los permisos se reducirán por la umask del usuario, por lo que un valor habitual aquí sería 0666, o si son datos muy privados, entonces 0600. (Véase "umask" en perlfunc.)

EXPORTACIONES

SDBM_File exporta opcionalmente las siguientes constantes:

  • "PAGFEXT" - la extensión utilizada para el archivo de página, normalmente ".pag".
  • "DIRFEXT" - la extensión utilizada para el archivo de directorio, ".dir" en todas partes excepto en VMS, donde es ".sdbm_dir".
  • "PAIRMAX" - el tamaño máximo de una entrada de hash almacenada, incluyendo la longitud tanto de la clave como del valor.

Estas constantes también se pueden usar con nombres completamente cualificados, por ejemplo, "SDBM_File::PAGFEXT".

DIAGNÓSTICOS

En caso de fallo, la llamada "tie" devuelve un valor indefinido y probablemente establece $! para contener el motivo por el cual el archivo no pudo ser enlazado.

"sdbm store devolvió -1, errno 22, clave "..." en ..."

Esta advertencia se emite cuando intentas almacenar una clave o un valor que es demasiado largo. Significa que el cambio no se registró en la base de datos. Véase ERRORES Y ADVERTENCIAS a continuación.

ADVERTENCIA DE SEGURIDAD

¡No aceptes archivos SDBM de fuentes no confiables!

El formato de archivo sdbm fue diseñado para la velocidad y la comodidad, no para la portabilidad o la seguridad. Un archivo elaborado maliciosamente podría hacer que perl se bloquee o incluso exponer una vulnerabilidad de seguridad.

ERRORES Y ADVERTENCIAS

Existen una serie de límites en el tamaño de los datos que puedes almacenar en el archivo SDBM. El más importante es que la longitud de una clave, más la longitud de su valor asociado, no puede superar los 1008 bytes.

Véase "tie" en perlfunc, perldbmfilter, Fcntl
