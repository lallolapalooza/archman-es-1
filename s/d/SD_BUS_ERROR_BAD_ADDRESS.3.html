DESCRIPCIÓN

Además de los nombres de error definidos por los programas en uso, D-Bus conoce varios nombres de error estándar y generales que se listan a continuación.

Además de esta lista, en sd-bus, se utiliza el espacio de nombres especial "System.Error" para mapear errores del sistema operativo (como se definen por errno(3)) a errores de D-Bus y viceversa. Por ejemplo, el error EUCLEAN se mapea a "System.Error.EUCLEAN" y viceversa.

SD_BUS_ERROR_FAILED

Un indicador general de error. Consulte el mensaje de error para detalles adicionales. Este nombre de error debería evitarse, en favor de un nombre de error más expresivo.

Añadido en la versión 223.

SD_BUS_ERROR_NO_MEMORY

Un error de asignación de memoria, y la operación solicitada no pudo completarse.

Añadido en la versión 223.

SD_BUS_ERROR_SERVICE_UNKNOWN

El servicio de bus que se contactó no está definido y no puede activarse.

Añadido en la versión 223.

SD_BUS_ERROR_NAME_HAS_NO_OWNER

El nombre del servicio de bus especificado actualmente no tiene propietario.

Añadido en la versión 223.

SD_BUS_ERROR_NO_REPLY

No se recibió una respuesta a un mensaje. Este error suele generarse después de un tiempo de espera agotado.

Añadido en la versión 223.

SD_BUS_ERROR_IO_ERROR

Error de entrada/salida general, por ejemplo al acceder a un socket o contexto de E/S.

Añadido en la versión 223.

SD_BUS_ERROR_BAD_ADDRESS

El string de dirección de bus especificado está mal formado.

SD_BUS_ERROR_NOT_SUPPORTED

SD_BUS_ERROR_NO_SERVER

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para subprocesos múltiples. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
