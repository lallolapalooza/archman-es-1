DESCRIPCIÓN

Además de los nombres de error que definen los programas de usuario, D-Bus conoce una serie de nombres de error genéricos y estandarizados que se enumeran a continuación.

Además de esta lista, en sd-bus, el espacio de nombres de error especial "System.Error." se utiliza para mapear errores genéricos del sistema Linux (tal como se definen en errno(3)) a y desde errores de D-Bus. Por ejemplo, el error EUCLEAN se mapea a "System.Error.EUCLEAN" y viceversa.

SD_BUS_ERROR_FAILED

Una indicación de error genérica. Ver el mensaje de error para más detalles. Se debe evitar este nombre de error, en favor de un nombre de error más expresivo.

DESCRIPTION

The sd_bus_error structure is used to report errors that occur during operations with the D-Bus message bus system. It holds an error name and a human-readable error message.

The functions sd_bus_error_set*() are used to initialize or modify an sd_bus_error structure.

If the error argument is NULL, these functions do nothing and return 0. Otherwise, they fill in the error structure.

The error name is a string, following the D-Bus error name specification. The error message is a free-form string, intended to explain the error in more detail.

If error->name is not NULL when one of these functions is called, the existing string is freed before the new one is set. If error->message is not NULL, it is also freed.

sd_bus_error_set() sets the error name and message from the passed strings. The strings are copied.

sd_bus_error_set_const() is similar to sd_bus_error_set(), but it stores pointers to the passed strings instead of copying them. The strings must remain valid for the lifetime of the sd_bus_error structure. This function should only be used when the strings are static or guaranteed to outlive the error structure.

sd_bus_error_set_errno() sets the error name to "errno" and the message to the string representation of the specified POSIX error code errnum, obtained via strerror_r(3). Note that errnum might be 0 or negative, in which case no error message is set.

sd_bus_error_set_from_error() copies the name and message from another sd_bus_error structure. This is useful for propagating errors.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
