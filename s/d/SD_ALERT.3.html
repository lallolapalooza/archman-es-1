SD_DAEMON(3) sd-daemon SD_DAEMON(3)

NOMBRE

sd-daemon, SD_EMERG, SD_ALERT, SD_CRIT, SD_ERR, SD_WARNING, SD_NOTICE, SD_INFO, SD_DEBUG - APIs para demonios de nuevo estilo

SINOPSIS

#include <systemd/sd-daemon.h>

pkg-config --cflags --libs libsystemd

DESCRIPCIÓN

sd-daemon.h es parte de libsystemd(3) y proporciona APIs para demonios de nuevo estilo, como los implementados por el gestor de servicios systemd(1).

Consulte sd_listen_fds(3), sd_notify(3), sd_booted(3), sd_is_fifo(3), sd_watchdog_enabled(3), y sd_pidfd_get_inode_id(3) para obtener más información sobre las funciones implementadas. Además de estas funciones, se definen un par de prefijos de registro como macros:

#define SD_EMERG   "<0>"  /* el sistema es inutilizable */
#define SD_ALERT   "<1>"  /* la acción debe tomarse inmediatamente */
#define SD_CRIT    "<2>"  /* condiciones críticas */
#define SD_ERR     "<3>"  /* condiciones de error */
#define SD_WARNING "<4>"  /* condiciones de advertencia */
#define SD_NOTICE  "<5>"  /* condición normal pero significativa */
#define SD_INFO    "<6>"  /* informativa */
#define SD_DEBUG   "<7>"  /* mensajes a nivel de depuración */

Estos prefijos están destinados a ser utilizados en conjunción con el registro basado en stderr (o registro basado en stdout) como lo implementa systemd. Si un archivo de definición de servicio de systemd está configurado con StandardError=journal o StandardError=kmsg (y similar con StandardOutput=), estos prefijos se pueden usar para codificar un nivel de registro en las líneas impresas. Esto es similar al registro estilo printk() del kernel. Consulte klogctl(2) para obtener más información.

Los niveles de registro son idénticos al sistema de niveles de registro de syslog(3). Para usar estos prefijos simplemente anteponga cada línea con una de estas cadenas. Una línea que no tenga prefijo se registrará en el nivel de registro predeterminado SD_INFO.

Ejemplo 1. Hola Mundo

Un demonio puede registrarse con el nivel de registro NOTICE emitiendo esta llamada:

fprintf(stderr, SD_NOTICE "¡Hola Mundo!\n");

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara como no seguro para hilos (no multi-thread-safe). Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda hacer llamadas a setenv() solo desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
