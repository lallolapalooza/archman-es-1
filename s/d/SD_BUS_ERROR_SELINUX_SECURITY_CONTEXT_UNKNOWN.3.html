DESCRIPCION

Además de los nombres de error definidos por los programas usuarios, D-Bus conoce un número de nombres de error estándar y genéricos que se listan a continuación.

Además de este listado, en sd-bus, el espacio de errores especial "System.Error" se utiliza para mapear errores de sistema del Linux (como los definidos por errno(3)) a errores de D-Bus y viceversa. Por ejemplo, el error EUCLEAN se mapea a "System.Error.EUCLEAN" y viceversa.

SD_BUS_ERROR_FAILED

Un indicador general de error. Para más detalles, vea el mensaje de error. Este nombre de error debería evitarse, en favor de un nombre de error más expresivo.

Añadido en la versión 223.
