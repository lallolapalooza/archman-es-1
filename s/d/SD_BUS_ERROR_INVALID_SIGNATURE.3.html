DESCRIPCIÓN

Además de los nombres de error que definen los programas de usuario, D-Bus conoce una serie de nombres de error genéricos y estandarizados que se enumeran a continuación.

Además de esta lista, en sd-bus, el espacio de nombres especial de errores "System.Error." se utiliza para mapear errores genéricos del sistema Linux (como se definen en errno(3)) a errores de D-Bus y viceversa. Por ejemplo, el error EUCLEAN se mapea a "System.Error.EUCLEAN" y viceversa.

SD_BUS_ERROR_FAILED

Una indicación genérica de error. Consulte el mensaje de error para obtener más detalles. Este nombre de error debe evitarse, en favor de un nombre de error más expresivo.

Añadido en la versión 223.
