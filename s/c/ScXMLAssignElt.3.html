Descripción Detallada

el elemento SCXML <assign>.

El elemento <assign> solo es funcional bajo un perfil que tenga una implementación del Módulo de Datos. El perfil "mínimo" no implementa uno, pero el perfil "x-coin" sí.

Se aceptan los siguientes atributos:

  • location
  • dataID
  • expr

Se puede especificar location o dataID a la vez.

Si se especifica dataID, el objetivo de la asignación es el elemento <data> que tiene el atributo ID establecido al mismo valor.

Si se especifica location, se utiliza un direccionamiento de variables dependiente del perfil. El perfil "mínimo" no define ninguno, y el perfil "x-coin" define los siguientes esquemas de dirección para variables escribibles:

  • _data.{id} significa dirigirse a una variable <data> existente.
  • coin:temp.{id} significa dirigirse a una variable temporal, creándola si es necesario.

Las variables temporales en el perfil "x-coin" tienen la vida útil de un evento SCXML. Para tener datos persistentes, usa variables <data>. Permanecen vivas durante la misma duración que existe el objeto ScXMLStateMachine.

Las variables temporales son particularmente útiles para el elemento <send>, porque el atributo namelist puede dirigirse a ellas con un prefijo implícito, lo que significa que los objetivos del evento pueden leerlas basándose en nombres lógicos en lugar de direcciones del modelo de datos SCXML.

Detailed Description

The Coin SCXML engine implements the SCXML specification (<a href="http://www.w3.org/TR/2011/REC-scxml-20110607/">http://www.w3.org/TR/2011/REC-scxml-20110607/</a>) by mapping SCXML elements to COIN classes.

This class implements the SCXML <assign> element.

An assign element can have the following attributes:

  • expr: The value to assign. This can be an expression that will be evaluated by the SCXML engine.
  • location: The data variable to assign the value to. This must be an XPath expression.
  • event: The name of the event to be thrown.
  • type: The type of the element. Can be “assign”, “send”, “log”, etc.

See the SCXML specification for more details.
