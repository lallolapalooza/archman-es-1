Descripción Detallada

implementa el elemento SCXML <scxml>.

Un objeto de este tipo representa el elemento raíz <scxml> SCXML en un documento. Tiene los siguientes atributos:

  • initial
  • name
  • xmlns
  • version [REQUERIDO] debe contener "1.0"
  • profile
  • exmode - "lax" o "strict"

El elemento <scxml> puede tener elementos hijos de los siguientes tipos:

  • initial - cero o un elemento de este tipo, dependiendo de si el atributo "initial" está establecido o no (uno de ellos debe estar establecido, y solo uno), pero solo cuando el elemento <scxml> es el elemento raíz y no una referencia externa de otro documento.
  • state - cero o más elementos
  • parallel - cero o más elementos
  • final - cero o más elementos
  • datamodel - cero o uno si el módulo del modelo de datos está habilitado

Desde

Coin 3.0
