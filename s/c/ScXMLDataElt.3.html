Descripción Detallada

el elemento SCXML <data>.

El elemento SCXML <data> se utiliza para almacenar variables. Necesitan estar contenidos dentro de un elemento <datamodel>. Los elementos <data> solo son funcionales en máquinas de estados con un perfil que tenga una implementación del Módulo de Datos. El perfil "mínimo" no lo tiene, pero el perfil "x-coin" sí.

Se aceptan los siguientes atributos:

  • ID
  • src - no soportado
  • expr

El atributo ID es obligatorio y especifica el nombre de la variable. El nombre de la variable debe ser único para toda la especificación de la máquina de estados SCXML.

El atributo src no está soportado.

El atributo expr especifica el valor de la variable. El atributo se evalúa según el perfil que esté utilizando la máquina de estados.

El valor de la variable <data> puede ser modificado mediante el uso de elementos <assign>, y sus valores pueden ser pasados a otros sistemas mediante el uso del elemento <send> en el Módulo de Comunicaciones Externas.

SbBool ScXMLDataElt::handleXMLAttributes (void ) [virtual]

Este método se llama cuando el lector de archivos ha establecido todos los atributos XML en el objeto, y quiere que el objeto los maneje y reporte si los valores estaban bien o si se debe producir un error de lectura.

Devuelve

TRUE si los atributos están bien, y FALSE en caso de error.

La implementación de la clase base no hace nada y solo devuelve TRUE.
