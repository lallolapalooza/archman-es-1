Scope::Guard(3pm) Documentación de Perl contribuida por el usuario Scope::Guard(3pm)

NOMBRE

Scope::Guard - gestión de recursos con ámbito léxico

SINOPSIS

mi $guard = guard { ... };
  # o
mi $guard = scope_guard \&handler;
  # o
mi $guard = Scope::Guard->new(sub { ... });
$guard->dismiss(); # deshabilita el manejador

DESCRIPCIÓN

Este módulo proporciona una forma conveniente de realizar limpieza u otras formas de gestión de recursos al final de un ámbito. Es particularmente útil cuando se trata de excepciones: el constructor "Scope::Guard" toma una referencia a una subrutina que se garantiza que se llamará incluso si el hilo de ejecución se interrumpe prematuramente. Esto permite efectivamente hacer "promesas" con ámbito léxico que son honradas automáticamente por el recolector de basura de perl.

Para más información, ver: http://www.drdobbs.com/cpp/184403758

MÉTODOS

new

mi $guard = Scope::Guard->new(sub { ... });
  # o
mi $guard = Scope::Guard->new(\&handler);

El método "new" crea un nuevo objeto "Scope::Guard" que llama al manejador suministrado cuando se llama a su método "DESTROY", típicamente al final del ámbito.

dismiss

$guard->dismiss();
  # o
$guard->dismiss(1);

"dismiss" desvincula el manejador del objeto "Scope::Guard". Esto revoca la "promesa" de llamar al manejador cuando se destruye el objeto.

El manejador puede ser reactivado llamando a:

$guard->dismiss(0);

EXPORTACIONES

guard

"guard" toma un bloque y devuelve un nuevo objeto "Scope::Guard". Se puede usar como atajo para:

Scope::Guard->new(...)

p. ej.

mi $guard = guard { ... };

Nota: llamar a "guard" anónimamente, es decir, en contexto nulo, generará una excepción. Esto se debe a que los guardias anónimos se destruyen **inmediatamente** (en lugar de al final del ámbito), lo cual es poco probable que sea el comportamiento deseado.

scope_guard

"scope_guard" es lo mismo que "guard", pero toma una referencia de código en lugar de un bloque. p. ej.

mi $guard = scope_guard \&handler;

o:

mi $guard = scope_guard sub { ... };

o:

mi $guard = scope_guard $handler;

Al igual que con "guard", llamar a "scope_guard" en contexto nulo generará una excepción.
