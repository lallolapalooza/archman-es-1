Descripción detallada

clase base para objetivos de eventos para la comunicación de eventos entre sistemas

Esta clase gestiona la inter-comunicación entre sistemas SCXML y sistemas destinados a la comunicación con dichos sistemas. También gestiona la cola de eventos externa para dichos sistemas (los sistemas también pueden tener colas de eventos internas).

Desde

Coin 3.1

virtual const ScXMLEvent * ScXMLEventTarget::getCurrentEvent (void ) const [inline], [virtual]

Este método devuelve el evento actual durante el procesamiento de eventos, y NULL cuando no se están procesando eventos.

El procesamiento de eventos se realiza en casos especiales con NULL como evento actual, como por ejemplo durante la inicialización de la máquina de estados.

void ScXMLEventTarget::queueEvent (const ScXMLEvent * event) [virtual]

Pone en cola un evento ScXMLEvent. El evento se copia y se puede eliminar tan pronto como la función devuelva.

void ScXMLEventTarget::queueEvent (const SbName & eventid) [virtual]

Pone en cola un evento ScXMLEvent que tiene el eventid dado como nombre del evento.

void ScXMLEventTarget::setCurrentEvent (const ScXMLEvent * event) [protected], [virtual]

Establece un puntero para el evento que es 'actual' durante el procesamiento de eventos. Este es un método interno, y la actualización del evento actual debe manejarse automáticamente.

SbBool ScXMLEventTarget::processOneEvent (const ScXMLEvent * event) [protected], [virtual]

Esta función procesa un evento. La implementación de la clase base no hace nada.
