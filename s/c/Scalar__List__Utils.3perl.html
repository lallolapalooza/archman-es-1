Scalar::List::Utils(3perl) Guía de referencia para programadores de Perl Scalar::List::Utils(3perl)

NOMBRE

Scalar::List::Utils - Una distribución de subrutinas de utilidad general

SINOPSIS

use Scalar::Util qw(blessed);
use List::Util qw(any);

DESCRIPCIÓN

"Scalar::List::Utils" no hace nada por sí solo. Se empaqueta con varios módulos útiles.

MÓDULOS

List::Util

List::Util contiene una selección de subrutinas útiles para operar con listas de valores.

Scalar::Util

Scalar::Util contiene una selección de subrutinas útiles para interrogar o manipular valores escalares.

Sub::Util

Sub::Util contiene una selección de subrutinas útiles para interrogar o manipular referencias a subrutinas.
