Descripción Detallada

implementa el elemento SCXML <invoke>.

Nota importante para usuarios de SCXML en la implementación de Coin 3.0 del elemento <invoke>: La primera implementación de SCXML de Coin se basó en un borrador de febrero de 2007, y la interpretación realizada del elemento <invoke> fue incorrecta en ciertos aspectos que se han aclarado en revisiones posteriores del borrador del estándar. La implementación de SCXML se realizó apresuradamente por diversas razones, con un plazo en el que no sería posible tener listas las capacidades de scripting, y el código del sistema de navegación (el propósito principal de implementar el sistema SCXML) tuvo que ser insertado en algún lugar. En ese momento, esto se hizo en el elemento <invoke>.

Para la implementación actual, el código de navegación se ha movido de basarse en <invoke> a ser un servicio comunicado a través del elemento <send> para ser más conforme al estándar. Y para hacer la situación aún más ridícula, ese enfoque probablemente será obsoleto en un futuro no muy lejano, para ser reemplazado por un enfoque puro, en línea y basado en scripting. Sin embargo, ambos enfoques deberían ser completamente posibles de mantener activos uno al lado del otro durante un tiempo, por lo que seguir la corriente actual en la implementación de sus propios sistemas de navegación personalizados debería ser mucho más seguro que hacerlo a través del enfoque equivocado de <invoke>.

ScXMLInvokeElt — clase para un elemento <invoke> de SCXML

SYNOPSIS

class ScXMLInvokeElt

Inherits from ScXMLElt.

Detailed Description

Representa un elemento <invoke> dentro de un documento SCXML.

Este elemento se utiliza para invocar un documento o una aplicación externa. Contiene atributos como href, type, targetexpr y srcexpr para especificar qué invocar y cómo.

Este elemento es crucial para la interoperabilidad de SCXML con sistemas externos.
