SCT_validate(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SCT_VALIDATE(3ssl) OpenSSL SCT_VALIDATE(3ssl)

NOMBRE

SCT_validate, SCT_LIST_validate, SCT_get_validation_status - comprueba que los Certificados Firmados de Fecha (SCTs) son válidos

SINOPSIS

#include <openssl/ct.h>
typedef enum {
    SCT_VALIDATION_STATUS_NOT_SET,
    SCT_VALIDATION_STATUS_UNKNOWN_LOG,
    SCT_VALIDATION_STATUS_VALID,
    SCT_VALIDATION_STATUS_INVALID,
    SCT_VALIDATION_STATUS_UNVERIFIED,
    SCT_VALIDATION_STATUS_UNKNOWN_VERSION
} sct_validation_status_t;
int SCT_validate(SCT *sct, const CT_POLICY_EVAL_CTX *ctx);
int SCT_LIST_validate(const STACK_OF(SCT) *scts, CT_POLICY_EVAL_CTX *ctx);
sct_validation_status_t SCT_get_validation_status(const SCT *sct);

DESCRIPCIÓN

SCT_validate() comprobará que un SCT es válido y verificará su firma. SCT_LIST_validate() realiza las mismas comprobaciones en una pila completa de SCTs. El resultado de las comprobaciones de validación se puede obtener pasando el SCT a SCT_get_validation_status().

Se debe proporcionar un CT_POLICY_EVAL_CTX que especifique:

  • El certificado para el que se emitió el SCT.

    Si no se proporciona el certificado, el estado de validación será SCT_VALIDATION_STATUS_UNVERIFIED.

  • El emisor de ese certificado.

    Esto solo es necesario si el SCT se emitió para un pre-certificado (ver RFC 6962). Si es necesario pero no se proporciona, el estado de validación será SCT_VALIDATION_STATUS_UNVERIFIED.

  • Un CTLOG_STORE que contenga el registro de CT que emitió este SCT.

    Si el SCT fue emitido por un registro que no se encuentra en este CTLOG_STORE, el estado de validación será SCT_VALIDATION_STATUS_UNKNOWN_LOG.

Si el SCT es de una versión no soportada (actualmente solo se soporta v1), el estado de validación será SCT_VALIDATION_STATUS_UNKNOWN_VERSION.

Si la firma del SCT es incorrecta, su marca de tiempo está en el futuro (en relación con la hora en CT_POLICY_EVAL_CTX), o si es inválido por cualquier otro motivo, el estado de validación será SCT_VALIDATION_STATUS_INVALID.

Si todas las comprobaciones pasan, el estado de validación será SCT_VALIDATION_STATUS_VALID.

NOTAS

Un valor de retorno de 0 de SCT_LIST_validate() no debe interpretarse como un fallo. Como mínimo, un solo SCT válido puede proporcionar suficiente confianza de que un certificado ha sido registrado públicamente.

VALORES DE RETORNO

SCT_validate() devuelve un entero negativo si ocurre un error interno, 0 si el SCT falla la validación, o 1 si el SCT pasa la validación.

SCT_LIST_validate() devuelve un entero negativo si ocurre un error interno, 0 si alguno de los SCTs falla la validación, o 1 si todos pasan la validación.

SCT_get_validation_status() devuelve el estado de validación del SCT. Si SCT_validate() o SCT_LIST_validate() no se han pasado a ese SCT, el valor devuelto será SCT_VALIDATION_STATUS_NOT_SET.
