SbBool ScXMLStateElt::handleXMLAttributes (void )

Esta función se llama después de que se hayan procesado todos los atributos XML y antes de que se procesen los elementos hijo.

Si el atributo initial se ha definido (es decir, no es NULL), esta función intentará encontrar el estado hijo cuyo id coincide con el valor de este atributo y hará que este sea el estado inicial.

void ScXMLStateElt::setInitialAttribute (const char * initialstr) [virtual]

Establece el atributo XML 'initial' para el elemento SCXML <state>. Si se establece este valor, el estado no debe contener un elemento <initial>, y viceversa.

Al establecerse, este valor debe ser el valor de un identificador descendiente para un estado hijo.

SbBool ScXMLStateElt::handleXMLAttributes (void ) [virtual]

Este método se llama cuando el lector de archivos ha establecido todos los atributos XML en el objeto, y quiere que el objeto los maneje e informe si los valores estaban bien o si se debe producir un error de lectura.

Retorna

TRUE si los atributos están bien, y FALSE en caso de error.

Esta implementación de la clase base no hace nada y simplemente devuelve TRUE.
