ScXMLObject(3)

ScXMLObject - Representation of an SCXML document

Name

ScXMLObject - Representation of an SCXML document

Description

The ScXMLObject structure represents an SCXML (State Chart XML) document. It provides an interface for parsing SCXML files, manipulating their content, and retrieving information about them.
