SbBool ScXMLEventElt::handleXMLAttributes (void ) [virtual]

Este método se llama cuando el lector de archivos ha establecido todos los atributos XML en el objeto, y quiere que el objeto los maneje y reporte si los valores estuvieron OK o si se debería producir un error de lectura.

Devuelve

TRUE si los atributos están OK, y FALSE en caso de error.

Esta implementación de clase base no hace nada y solo devuelve TRUE.
