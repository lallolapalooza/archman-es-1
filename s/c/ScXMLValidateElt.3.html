SbBool ScXMLValidateElt::handleXMLAttributes (void ) [virtual]

Este método se llama cuando el lector de archivos ha establecido todos los atributos XML en el objeto, y quiere que el objeto los maneje y reporte si los valores eran correctos o si debería producirse un error de lectura.

Retorna

TRUE si los atributos son correctos, y FALSE en caso de error.

Esta implementación de clase base hace lo mismo y devuelve TRUE.
