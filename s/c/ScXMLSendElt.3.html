Descripción Detallada

el elemento SCXML <send>.

El elemento <send> solo es útil en perfiles que tienen una implementación del Módulo de Comunicación Externa. Tanto el perfil "minimum" como el perfil "x-coin" tienen implementaciones, pero el perfil "minimum" no implementa El Módulo de Datos, por lo que solo se pueden enviar eventos simples sin datos asociados.

El elemento <send> puede tomar los siguientes atributos:

  • event
  • target
  • targettype
  • sendid - no soportado
  • delay
  • namelist
  • hints - no soportado

El elemento <send> envía eventos externos. Las máquinas de estados tienen típicamente dos colas de eventos: una interna y una externa. La cola de eventos interna tiene prioridad total sobre la cola de eventos externa. Las máquinas de estados *pueden* enviarse eventos externos a sí mismas, pero es más probable que los eventos internos sean lo que deseas. Para enviar eventos internos, consulta el elemento <event> implementado en ScXMLEventElt. Para enviar un evento externo a la máquina de estados contenedora, no especifiques el atributo target.

El atributo event especifica el nombre del evento para el evento que se está enviando. Los nombres de eventos son nombres separados por puntos como "error.InvalidExpr" o "x-coin-navigation.Rotate.BEGIN", y los nombres de eventos se tratan como sensibles a mayúsculas y minúsculas en la implementación actual de Coin SCXML. El atributo event es obligatorio.

El atributo targettype especifica el tipo del sistema de destino. Otras máquinas de estados SCXML tienen el tipo "scxml". Los servicios relacionados con los sistemas de navegación de Coin tienen el targettype "x-coin-navigation". Al enviarse eventos externos a uno mismo, targettype puede omitirse.

El atributo target es el nombre del sistema de eventos de destino. Si no se especifica, significa que el evento se enviará a la máquina de estados contenedora. Los servicios de navegación de Coin suelen llamarse "Rotate", pero para otras máquinas de estados SCXML, el atributo name del <scxml> decide esto. Sin embargo, ese nombre no es único si se han creado varios nombres de este tipo, por lo que target también puede ser el identificador _sessionid de la máquina de estados. (FIXME: verificar si esto está implementado)

El atributo sendid no está soportado.

Si se especifica delay, debe tener el formato "{número}s" o "{número}ms", lo que te da la opción de especificar el retraso en número de segundos o milisegundos antes de que se envíe el evento. Para que se envíen eventos retrasados, se debe realizar el procesamiento de la cola de retraso de Coin. La mayoría de los usuarios de Coin lo hacen, ya sea que lo sepan o no. Si no se especifica delay, el evento se pasa al destino inmediatamente. Si se elimina una máquina de estados, cualquier evento programado para enviarse de forma retrasada desaparecerá. La cola de retraso es una característica de la máquina de estados que envía, no de la que recibe.

El atributo namelist especifica qué variables de datos incluir con el evento para el destino del evento. Este atributo solo es útil en perfiles que implementan el Módulo de Datos. El perfil "minimum" no lo hace, pero el perfil "x-coin" sí. Para el perfil "x-coin", puedes especificar variables <data> dirigiéndote a ellas con el esquema _data.{ID}, o puedes especificar variables temporales, ya sea usando el esquema coin:temp.{ID} o teniendo el prefijo implícito simplemente

NAME

ScXMLSendElt — ScXML element for sending events.

SYNOPSIS

#include <Coin/scxml/ScXMLSendElt.h>

Detailed Description

This element is used to send an event. It has the following attributes:

event
The name of the event to send. If not specified, the event must be specified using the name attribute of the <data> element.
target
The document (URL) of the target SCXML document. If omitted, the event is sent to the current document.
targetexpr
A SCXML expression that evaluates to the target document (URL). This attribute and the target attribute are mutually exclusive.
type
The MIME type of the event. If omitted, it is assumed to be application/scxml+xml.
typeexpr
A SCXML expression that evaluates to the MIME type of the event. This attribute and the type attribute are mutually exclusive.
content
The content of the event. If omitted, the event has no content.
contentexpr
A SCXML expression that evaluates to the content of the event. This attribute and the content attribute are mutually exclusive.
expr
A SCXML expression that evaluates to the content of the event. This attribute and the content and contentexpr attributes are mutually exclusive.
params
An optional list of parameters to be sent with the event. Each parameter is specified as a <param> element.
name
Used by the <param> element to specify the name of a parameter. This is only relevant when the param.location attribute is specified.
location
Used by the <param> element to specify the location of a data variable within the SCXML data model. The location is specified as an XPath expression.

If the event is sent to a remote SCXML document, the SCXML processor may perform a conversion of the event to an appropriate format for the target. This includes converting the event name, content, and parameters to the target's expected format. If the target is not an SCXML document, the event is sent as a MIME message.

The event attribute is optional if the event name is specified via the <data> element.

If the target attribute is omitted, the event is sent to the current SCXML document.

The type attribute specifies the MIME type of the event. If omitted, it defaults to application/scxml+xml.

The content attribute specifies the event content. If omitted, the event has no content.

The expr attribute can be used to specify the event content as a SCXML expression.

The params attribute is a list of <param> elements. Each <param> element can specify a parameter name and value. The value can be specified directly or by referencing a data variable using the location attribute.

When using temporary variables, the values can get names that are intended for the event target instead of the name used at the source.

The hints attribute is not supported.
