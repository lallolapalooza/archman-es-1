Scalar::Util(3perl) Guía de referencia para programadores de Perl Scalar::Util(3perl)

NOMBRE

Scalar::Util - Una selección de subrutinas de utilidad general escalar

SINOPSIS

use Scalar::Util qw(blessed dualvar isdual readonly refaddr reftype
                    tainted weaken isweak isvstring looks_like_number
                    set_prototype);
                    # y otras utilidades útiles que aparecen a continuación

DESCRIPCIÓN

"Scalar::Util" contiene una selección de subrutinas que la gente ha expresado que le gustaría tener en el núcleo de Perl, pero cuyo uso no sería lo suficientemente alto como para justificar el uso de una palabra clave, y el tamaño sería tan pequeño que ser extensiones individuales sería un desperdicio.

Por defecto, "Scalar::Util" no exporta ninguna subrutina.

Funciones "incorporadas" de Perl

Muchas funciones de este módulo han servido de inspiración para una nueva instalación experimental en versiones recientes de Perl. A partir de varias versiones de desarrollo, comenzando con la 5.35.7, funciones equivalentes a muchas de estas utilidades están disponibles en el paquete "builtin::".

use Scalar::Util qw(blessed);
$class = blessed $obj;
$class = builtin::blessed $obj;  # equivalente

Para más información, consulte la documentación sobre builtin.

FUNCIONES PARA REFERENCIAS

Las siguientes funciones realizan alguna actividad útil sobre valores de referencia.

blessed

my $pkg = blessed( $ref );

Si $ref es una referencia bendecida, se devuelve el nombre del paquete en el que está bendecida. De lo contrario, se devuelve "undef".

$scalar = "foo";
$class  = blessed $scalar;           # undef
$ref    = [];
$class  = blessed $ref;              # undef
$obj    = bless [], "Foo";
$class  = blessed $obj;              # "Foo"

Tenga cuidado al usar esta función simplemente como una prueba de verdad (como en "if(blessed $ref)...") porque el nombre del paquete "0" está definido pero es falso.

Desde la versión 5.35.7 de Perl, una función equivalente está disponible como "builtin::blessed".

refaddr

my $addr = refaddr( $ref );

Si $ref es una referencia, se devuelve la dirección de memoria interna del valor referenciado como un entero simple. De lo contrario, se devuelve "undef".

$addr = refaddr "string";           # undef
$addr = refaddr \$var;              # p.ej. 12345678
$addr = refaddr [];                 # p.ej. 23456784
$obj  = bless {}, "Foo";
$addr = refaddr $obj;               # p.ej. 88123488

Desde la versión 5.35.7 de Perl, una función equivalente está disponible como "builtin::refaddr".

reftype

my $type = reftype( $ref );

Si $ref es una referencia, se devuelve el tipo básico de Perl de la variable referenciada como una cadena simple (como "ARRAY" o "HASH"). De lo contrario, se devuelve "undef".

$type = reftype "string";           # undef
$type = reftype \$var;              # SCALAR
$type = reftype [];                 # ARRAY
$obj  = bless {}, "Foo";
$type = reftype $obj;               # HASH

Tenga en cuenta que, por razones internas, todas las expresiones regulares precompiladas ("qr/.../") son referencias bendecidas; por lo tanto, ref() devuelve la cadena del nombre del paquete "Regexp" en ellas, pero reftype() devolverá el tipo de estructura C subyacente de "REGEXP" en mayúsculas.

Desde la versión 5.35.7 de Perl, una función equivalente está disponible como "builtin::reftype".

weaken

weaken( $ref );

El lvalor $ref se convertirá en una referencia débil. Esto significa que no mantendrá un contador de referencias sobre el objeto que referencia. Además, cuando el contador de referencias de ese objeto llegue a cero, la referencia se establecerá a undef. Esta función modifica el lvalor pasado como argumento y no devuelve ningún valor.

Esto es útil para mantener copias de referencias, pero no desea impedir que el objeto sea DESTROY-ado en su momento habitual.

{
  my $var;
  $ref = \$var;
  weaken($ref);                     # Hacer de $ref una referencia débil
}
# $ref es ahora undef

Tenga en cuenta que si toma una copia de un escalar con una referencia debilitada, la copia será una referencia fuerte.

my $var;
my $foo = \$var;
weaken($foo);                       # Hacer de $foo una referencia débil
my $bar = $foo;                     # $bar es ahora una referencia fuerte

Esto puede ser menos obvio en otras situaciones, como grep(), por ejemplo, al buscar en una lista de referencias debilitadas a objetos que pueden haber sido destruidos previamente:

@object = grep { defined } @object;

Esto eliminará efectivamente todas las referencias a objetos destruidos, pero las referencias restantes a objetos serán fuertes, lo que provocará que los objetos restantes nunca se destruyan porque ahora siempre hay una referencia fuerte a ellos en la matriz @object.

Desde la versión 5.35.7 de Perl, una función equivalente está disponible como "builtin::weaken".

unweaken

unweaken( $ref );

Desde la versión 1.36.

El lvalor "REF" se convertirá de una referencia débil de nuevo en una referencia normal (fuerte). Esta función modifica el lvalor pasado como argumento y no devuelve ningún valor. Esto deshace la acción realizada por "weaken".

Esta función es un poco más limpia y conveniente que el código equivalente:

my $tmp = $REF;
undef $REF;
$REF = $tmp;

(porque, en particular, simplemente asignar una referencia débil a sí misma no funciona para debilitarla; "$REF = $REF" no funciona).

Desde la versión 5.35.7 de Perl, una función equivalente está disponible como "builtin::unweaken".

isweak

my $weak = isweak( $ref );

Devuelve verdadero si $ref es una referencia débil.

$ref  = \$foo;
$weak = isweak($ref);               # falso
weaken($ref);
$weak = isweak($ref);               # verdadero

NOTA: Copiar una referencia débil crea una referencia normal y fuerte.

$copy = $ref;
$weak = isweak($copy);              # falso

Desde la versión 5.35.7 de Perl, una función equivalente está disponible como "builtin::is_weak".

OTRAS FUNCIONES

dualvar

my $var = dualvar( $num, $string );

Devuelve un escalar que tiene el valor $num en un contexto numérico y el valor $string en un contexto de cadena.

$foo = dualvar 10, "Hello";
$num = $foo + 2;                    # 12
$str = $foo . " world";             # Hello world

isdual

my $dual = isdual( $var );

Desde la versión 1.26.

Si $var es un escalar que tiene valores numéricos y de cadena, el resultado es verdadero.

$foo = dualvar 86, "Nix";
$dual = isdual($foo);               # verdadero

Tenga en cuenta que un escalar puede tener contenido de cadena y numérico a través de operaciones estándar:

$foo = "10";
$dual = isdual($foo
