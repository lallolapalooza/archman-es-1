Introducción

Entrada funcional con cadenas de formato

El módulo Scanf proporciona funciones de entrada formateada o escáneres.

Las funciones de entrada formateada pueden leer desde cualquier tipo de entrada, incluyendo cadenas de texto, archivos o cualquier cosa que pueda devolver caracteres. La fuente de caracteres más general se denomina canal de entrada formateada (o buffer de escaneo) y tiene el tipo Scanf.Scanning.in_channel. La función de entrada formateada más general lee desde cualquier buffer de escaneo y se llama bscanf.

En general, las funciones de entrada formateada tienen 3 argumentos:

-el primer argumento es una fuente de caracteres para la entrada,

-el segundo argumento es una cadena de formato que especifica los valores a leer,

-el tercer argumento es una función receptora que se aplica a los valores leídos.

Por lo tanto, una llamada típica a la función de entrada formateada Scanf.bscanf es bscanf ic fmt f, donde:

- ic es una fuente de caracteres (típicamente un canal de entrada formateada con tipo Scanf.Scanning.in_channel),

- fmt es una cadena de formato (las mismas cadenas de formato que se utilizan para imprimir material con el módulo Printf o Format),

- f es una función que tiene tantos argumentos como el número de valores a leer en la entrada según fmt.

Un ejemplo sencillo

Como se sugirió anteriormente, la expresión bscanf ic "%d" f lee un entero decimal n de la fuente de caracteres ic y devuelve f n.

Por ejemplo,

-si usamos stdin como fuente de caracteres ( Scanf.Scanning.stdin es el canal de entrada formateada predefinido que lee de la entrada estándar),

-si definimos el receptor f como let f x = x + 1 ,

entonces bscanf Scanning.stdin "%d" f lee un entero n de la entrada estándar y devuelve f n (es decir, n + 1). Por lo tanto, si evaluamos bscanf stdin "%d" f y luego introducimos 41 en el teclado, el resultado que obtenemos es 42.

Entrada formateada como característica funcional

La facilidad de escaneo de OCaml recuerda a la característica correspondiente en C. Sin embargo, también es muy diferente, más simple y, sin embargo, más potente: las funciones de entrada formateada son funciones de orden superior y el mecanismo de paso de parámetros es simplemente la aplicación regular de funciones, no el mecanismo basado en la asignación de variables que es típico para la entrada formateada en lenguajes imperativos; las cadenas de formato de OCaml también presentan adiciones útiles para definir fácilmente tokens complejos; como se espera dentro de un lenguaje de programación funcional, las funciones de entrada formateada también admiten polimorfismo, en particular, una interacción arbitraria con escáneres polimórficos definidos por el usuario. Además, la facilidad de entrada formateada de OCaml se verifica completamente mediante tipos en tiempo de compilación.

Accesos no sincronizados

Los accesos no sincronizados a un Scanf.Scanning.in_channel pueden llevar a un estado inválido de Scanf.Scanning.in_channel. Por lo tanto, los accesos concurrentes a Scanf.Scanning.in_channel deben sincronizarse (por ejemplo, con un Mutex.t).

Tipo de funciones de entrada formateada

type ('a, 'b, 'c, 'd) scanner = ('a, Scanning.in_channel, 'b, 'c, 'a -> 'd, 'd) format6 -> 'c

El tipo de escáneres de entrada formateada: ('a, 'b, 'c, 'd) scanner es el tipo de una función de entrada formateada que lee desde algún canal de entrada formateada según alguna cadena de formato; más precisamente, si scan es alguna función de entrada formateada, entonces scan
ic fmt f aplica f a todos los argumentos especificados por la cadena de formato fmt, cuando scan ha leído esos argumentos del canal de entrada formateada Scanf.Scanning.in_channel ic.

Por ejemplo, la función Scanf.scanf a continuación tiene el tipo ('a, 'b, 'c, 'd) scanner, ya que es una función de entrada formateada que lee de Scanf.Scanning.stdin: scanf fmt f aplica f a los argumentos especificados por fmt, leyendo esos argumentos de stdin como se espera.

Si el formato fmt tiene algunas indicaciones %r, las funciones de entrada correspondientes deben proporcionarse antes de la función receptora f. Por ejemplo, si read_elem es una función de entrada para valores de tipo t, entonces bscanf ic "%r;" read_elem f lee un valor v de tipo t seguido de un carácter ';', y devuelve f v.

type ('a, 'b, 'c, 'd) scanner_opt = ('a, Scanning.in_channel, 'b, 'c, 'a -> 'd option, 'd) format6 -> 'c

exception Scan_failure of string

Cuando la entrada no se puede leer según la especificación de la cadena de formato, las funciones de entrada formateada suelen lanzar la excepción Scan_failure.

La función general de entrada formateada

val bscanf : Scanning.in_channel -> ('a, 'b, 'c, 'd) scanner

bscanf ic fmt r1 ... rN f lee caracteres del canal de entrada formateada Scanf.Scanning.in_channel ic y los convierte a valores según la cadena de formato fmt. Como paso final, la función receptora f se aplica a los valores leídos y da el resultado de la llamada a bscanf.

Por ejemplo, si f es la función fun s i -> i + 1, entonces Scanf.sscanf "x = 1" "%s = %i" f devuelve 2.

Los argumentos r1 a rN son funciones de entrada definidas por el usuario que leen el argumento correspondiente a las conversiones %r especificadas en la cadena de formato.

val bscanf_opt : Scanning.in_channel -> ('a, 'b, 'c, 'd) scanner_opt

Igual que Scanf.bscanf, pero devuelve None en caso de fallo en el escaneo.

Desde 5.0

Descripción de la cadena de formato

La cadena de formato es una cadena de caracteres que contiene tres tipos de objetos:

-caracteres literales, que simplemente se comparan con los caracteres de la entrada (con un caso especial para espacio y salto de línea, véase Scanf.space),

-especificaciones de conversión, cada una de las cuales provoca la lectura y conversión de un argumento para la función f (véase Scanf.conversion),

-indicaciones de escaneo para especificar límites de tokens (véase escaneo Scanf.indication).

El caracter espacio en las cadenas de formato

Como se mencionó anteriormente, un carácter literal en la cadena de formato simplemente se compara con el siguiente carácter de la entrada; sin embargo, dos caracteres son excepciones especiales a esta regla: el carácter espacio ( ' ' o código ASCII 32) y el carácter de salto de línea ( '\n' o código ASCII 10). Un espacio no coincide con un único carácter de espacio, sino con cualquier cantidad de 'espacios en blanco' en la entrada. Más precisamente, un espacio dentro de la cadena de formato coincide con cualquier número de caracteres de tabulación, espacio, salto de línea y retorno de carro. De manera similar, un carácter de salto de línea en la cadena de formato coincide con un único salto de línea o un retorno de carro.

Según la estructura del archivo, se sigue el siguiente formato:

El carácter % se encuentra seguido de un flag opcional, un ancho de campo opcional y un carácter de conversión opcional.

Los caracteres de conversión y sus significados son:

- d : lee un entero decimal opcionalmente con signo ( 0-9 +).

- i : lee un entero decimal opcionalmente con signo (se entienden las convenciones de entrada estándar para decimales ( 0-9 +), hexadecimal ( 0x[0-9a-f]+ ) y octal ( 0o[0-7]+ ) y binario ( 0b[0-1]+ )).

- u : lee un entero decimal sin signo.

- x o X : lee un entero hexadecimal sin signo ( [0-9a-fA-F]+ ).

- o : lee un entero octal sin signo ( [0-7]+ ).

- s : lee un argumento de cadena que se extiende tanto como sea necesario hasta que se cumpla una de las siguientes condiciones:

- Se encuentra un carácter de espacio en blanco (ver Scanf.space ),

- Se ha encontrado un indicador de escaneo (ver Scanf.indication ),

- Se ha alcanzado el fin de la entrada.

Por lo tanto, esta conversión siempre tiene éxito: devuelve una cadena vacía si la condición de contorno se cumple al inicio de la lectura.

- S : lee un argumento de cadena delimitada (los delimitadores y caracteres especiales siguen las convenciones léxicas de OCaml).

- c : lee un único carácter. Para probar el carácter actual sin leerlo, especifique un ancho de campo nulo, es decir, use la especificación %0c . Lanza Invalid_argument si el ancho de campo especificado es mayor que 1.

- C : lee un único carácter delimitado (los delimitadores y caracteres especiales siguen las convenciones léxicas de OCaml).

- f , e , E , g , G : lee un número de punto flotante opcionalmente con signo en notación decimal, en el estilo dddd.ddd y/o e/E+-dd ..

- h , H : lee un número de punto flotante opcionalmente con signo en notación hexadecimal.

- F : lee un número de punto flotante según las convenciones léxicas de OCaml (por lo tanto, la coma decimal es obligatoria si la parte del exponente no se menciona).

- B : lee un argumento booleano ( true o false ).

- b : lee un argumento booleano (para compatibilidad retroactiva; no se debe usar en programas nuevos).

- ld , li , lu , lx , lX , lo : lee un argumento int32 según la segunda letra de la especificación de formato.

- nd , ni , nu , nx , nX , no : lee un argumento nativeint según la segunda letra de la especificación de formato.

- Ld , Li , Lu , Lx , LX , Lo : lee un argumento int64 según la segunda letra de la especificación de formato.

- [ range ] : lee caracteres que coinciden con uno de los caracteres mencionados en el rango de caracteres range (o no mencionados en él, si el rango comienza con ^ ). Lee una cadena que puede ser vacía si el siguiente carácter de entrada no coincide con el rango. El conjunto de caracteres de c1 a c2 (inclusivamente) se denota como c1-c2 . Por lo tanto, %[0-9] devuelve una cadena que representa un número decimal o una cadena vacía si no se encuentra un dígito decimal; de manera similar, %[0-9a-f] devuelve una cadena de dígitos hexadecimales. Si un corchete de cierre aparece en un rango, debe aparecer como el primer carácter del rango (o simplemente después del ^ en caso de negación de rango); por lo tanto, []] coincide con un carácter ] y [^]] coincide con cualquier carácter que no sea ] . Use %% y %@ para incluir un % o un @ en un rango.

- r : lector personalizado. Al leer el siguiente ri de entrada formateada, aplica esta función al buffer de lectura ib para leer el siguiente argumento. La función de lectura ri debe tener el tipo Scanning.in_channel -> 'a y el argumento leído tiene el tipo 'a .

- { fmt %} : lee un argumento de cadena de formato. El formato de cadena leído debe tener el mismo tipo que la especificación de formato fmt . Por ejemplo, "%{ %i %}" lee cualquier cadena de formato que pueda leer un valor de tipo int ; por lo tanto, si s es la cadena "fmt:\"number is %u\"" , entonces Scanf.sscanf s "fmt: %{%i%}" tiene éxito y devuelve la cadena de formato "number is %u" .

- ( fmt %) : sustitución de subformato de lectura. Lee la cadena de formato rf de la entrada, y luego se leerá con rf en lugar de con fmt . La cadena de formato rf debe tener el mismo tipo que la especificación de formato fmt que reemplaza. Por ejemplo, "%( %i %)" lee cualquier cadena de formato que pueda leer un valor de tipo int . La conversión devuelve la cadena de formato leída rf y luego un valor leído con rf . Por lo tanto, si s es la cadena "\"%4d\"1234.00" , entonces Scanf.sscanf s "%(%i%)" (fun fmt i -> fmt, i) evalúa a ("%4d", 1234) . Este comportamiento no es simplemente un reemplazo de formato, ya que la conversión devuelve la cadena de formato leída como argumento adicional. Si necesitas un reemplazo puro, usa el flag especial _ para descartar el argumento extra: la conversión %_( fmt %) lee una cadena de formato rf y luego se comporta igual que la cadena de formato rf . Por lo tanto, si s es la cadena "\"%4d\"1234.00" , entonces Scanf.sscanf s "%_(%i%)" es equivalente simplemente a Scanf.sscanf "1234.00" "%4d" .

- l : devuelve el número de líneas leídas hasta ahora.

- n : devuelve el número de caracteres leídos hasta ahora.

- N o L : devuelve el número de tokens leídos hasta ahora.

- ! : coincide con la condición de fin de entrada.

- % : coincide con un carácter % en la entrada.

- @ : coincide con un carácter @ en la entrada.

- , : no hace nada.

Después del carácter % que introduce una conversión, puede haber el flag especial _ : la conversión que sigue ocurre normalmente, pero el valor resultante se descarta. Por ejemplo, si f es la función fun i -> i + 1 y s es la cadena "x = 1" , entonces Scanf.sscanf s "%_s = %i" f devuelve 2 .

El ancho de campo se compone de un literal entero opcional que indica el ancho máximo del token a leer. Por ejemplo, %6d lee un entero con un máximo de 6 dígitos decimales; %4f lee un número de punto flotante con un máximo de 4 caracteres; y %8[\000-\255] devuelve los siguientes 8 caracteres (o todos los caracteres aún disponibles, si hay menos de 8 en la entrada).

Notas:

- Como se mencionó anteriormente, una conversión de %s siempre tiene éxito, incluso si no hay nada que leer en la entrada: en este caso, simplemente devuelve "" .

- Además de los dígitos relevantes, pueden aparecer caracteres '_' dentro de los números (esto recuerda a las convenciones léxicas estándar de OCaml). Si se desea un análisis más estricto, use la función de conversión de rango en lugar de las conversiones numéricas.

- El indicador de escaneo scanf no está destinado para el análisis léxico y el parseo intensivo. Si no es suficiente para sus necesidades, existen varias alternativas: expresiones regulares (módulo Str ), analizadores de flujo, lexers generados por ocamllex, parsers generados por ocamlyacc.

Indicadores de escaneo en cadenas de formato

Los indicadores de escaneo aparecen justo después de las conversiones de cadena %s y %[ range ] para delimitar el final del token. Un indicador de escaneo se introduce por un carácter @ seguido de algún carácter común c . Significa que el token de cadena debe terminar justo antes del siguiente carácter que coincida con c (que se omitirá). Si no se encuentra ningún carácter c , el token de cadena se extiende lo más posible. Por ejemplo, "%s@\t" lee una cadena hasta el siguiente carácter de tabulación o hasta el fin de la entrada. Si un carácter @ aparece en cualquier lugar de la cadena de formato, se trata como un carácter común.

Nota:

- Como en las cadenas de formato estándar, los caracteres % y @ deben escaparse usando %% y %@ ; esta regla también se aplica dentro de las especificaciones de rango y los indicadores de escaneo. Por ejemplo, el formato "%s@%%" lee una cadena hasta el siguiente % , y el formato "%s@%@" lee una cadena hasta el siguiente @ .

- Los indicadores de escaneo introducen diferencias mínimas en la sintaxis de las cadenas de formato de Scanf comparadas con las utilizadas en el módulo Printf. Sin embargo, los indicadores de escaneo son similares a los utilizados en el módulo Format ; por lo tanto, al producir texto formateado que se va a leer por Scanf.bscanf , es aconsejable usar funciones de impresión del módulo Format (o, si deseas usar funciones del módulo Printf , evita o revisa cuidadosamente las cadenas de formato que contienen caracteres '@' ).

Excepciones durante el escaneo

Los lectores pueden lanzar las siguientes excepciones cuando la entrada no se puede leer según la cadena de formato:

- Lanza Scanf.Scan_failure si la entrada no coincide con el formato.

- Lanza Failure si no es posible convertir a un número.

- Lanza End_of_file si se alcanza el fin de la entrada mientras se necesitan leer más caracteres para la especificación de conversión actual.

- Lanza Invalid_argument si la cadena de formato es inválida.

Nota:

- Como consecuencia, la lectura de una conversión de %s nunca lanza la excepción End_of_file : si se alcanza el fin de la entrada, la conversión tiene éxito y simplemente devuelve los caracteres leídos hasta ese momento.

NAME

Scanf, Scanf_format - formatted input functions

Module

Scanf

This module provides functions for reading formatted input, inspired by the C standard library function scanf. These functions can read from an input channel or a string, using a format string that specifies the structure of the input and the types of the values to be read.

The formatting functions are polymorphic and rely on a type inference mechanism to determine the types of the arguments and the return value. For example, the format string "%d %s" expects an integer and a string, and the function will return a pair of an integer and a string.

The module also provides functions for reading format strings themselves from input, allowing for dynamic format specification.

For more advanced usage and customization, refer to the Scanning module, which provides lower-level access to the scanning process.

Documentation

Basic scanning functions

val bscanf : Scanning.in_channel -> ('a, 'b, 'c, 'd) scanner -> 'd

Scans a formatted input from the given channel ic, according to the given format string. The format string is a function that takes the input channel as its first argument and returns the desired formatted input result.

The type of the format string, ('a, 'b, 'c, 'd) scanner, indicates the structure of the format and the resulting type. Typically, `'a` is the type of the arguments to be read, `'b` represents the continuation for the next argument, `'c` is the state of the scanner, and `'d` is the final result type.

The function raises Scan_failure if the input does not match the format string.

val fscanf : in_channel -> ('a, 'b, 'c, 'd) scanner -> 'd

Same as Scanf.bscanf, but reads from the predefined formatted input channel Scanf.Scanning.stdin that is connected to standard input.

val sscanf : string -> ('a, 'b, 'c, 'd) scanner -> 'd

Same as Scanf.bscanf, but reads from the given string.

val from_string : string -> ('a, 'b, 'c, 'd) scanner

Returns a scanner that reads from the given string. This is useful for creating scanners that can be passed to other functions like bscanf.

val from_channel : Scanning.in_channel -> ('a, 'b, 'c, 'd) scanner

Returns a scanner that reads from the given input channel.

val memoize : ('a, 'b, 'c, 'd) scanner -> ('a, 'b, 'c, 'd) scanner

Returns a memoized version of the given scanner. This can improve performance if the same format string is used multiple times.

If the input is empty, the scanner returns (). If the format string is empty, it returns (). If none were ever read.

Specialised formatted input functions

val sscanf : string -> ('a, 'b, 'c, 'd) scanner

Same as Scanf.bscanf , but reads from the given string.

val sscanf_opt : string -> ('a, 'b, 'c, 'd) scanner_opt

Same as Scanf.sscanf , but returns None in case of scanning failure.

Since 5.0

val scanf : ('a, 'b, 'c, 'd) scanner

Same as Scanf.bscanf , but reads from the predefined formatted input channel Scanf.Scanning.stdin that is connected to stdin .

val scanf_opt : ('a, 'b, 'c, 'd) scanner_opt

Same as Scanf.scanf , but returns None in case of scanning failure.

Since 5.0

val kscanf : Scanning.in_channel -> (Scanning.in_channel -> exn -> 'd) -> ('a, 'b, 'c, 'd) scanner

Same as Scanf.bscanf , but takes an additional function argument ef that is called in case of error: if the scanning process or some conversion fails, the scanning function aborts and calls the error handling function ef with the formatted input channel and the exception that aborted the scanning process as arguments.

val ksscanf : string -> (Scanning.in_channel -> exn -> 'd) -> ('a, 'b, 'c, 'd) scanner

Same as Scanf.kscanf but reads from the given string.

Since 4.02

Reading format strings from input

val bscanf_format : Scanning.in_channel -> ('a, 'b, 'c, 'd, 'e, 'f) format6 -> (('a, 'b, 'c, 'd, 'e, 'f) format6 -> 'g) -> 'g

bscanf_format ic fmt f reads a format string token from the formatted input channel ic , according to the given format string fmt , and applies f to the resulting format string value.

Since 3.09

Raises Scan_failure if the format string value read does not have the same type as fmt .

val sscanf_format : string -> ('a, 'b, 'c, 'd, 'e, 'f) format6 -> (('a, 'b, 'c, 'd, 'e, 'f) format6 -> 'g) -> 'g

Same as Scanf.bscanf_format , but reads from the given string.

Since 3.09

val format_from_string : string -> ('a, 'b, 'c, 'd, 'e, 'f) format6 -> ('a, 'b, 'c, 'd, 'e, 'f) format6

format_from_string s fmt converts a string argument to a format string, according to the given format string fmt .

Since 3.10

Raises Scan_failure if s , considered as a format string, does not have the same type as fmt .

val unescaped : string -> string

unescaped s return a copy of s with escape sequences (according to the lexical conventions of OCaml) replaced by their corresponding special characters. More precisely, Scanf.unescaped has the following property: for all string s , Scanf.unescaped (String.escaped s) = s .

Always return a copy of the argument, even if there is no escape sequence in the argument.

Since 4.00

Raises Scan_failure if s is not properly escaped (i.e. s has invalid escape sequences or special characters that are not properly escaped). For instance, Scanf.unescaped "\"" will fail.
