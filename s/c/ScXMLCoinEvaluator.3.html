Descripción detallada

implementa el evaluador para el perfil personalizado denominado "x-coin".

El perfil x-coin se extiende sobre el perfil mínimo con interpretación de datos, operadores lógicos, expresiones aritméticas y algunas características de modelo de datos convenientes como el acceso al grafo de escena y el almacenamiento temporal de variables.
