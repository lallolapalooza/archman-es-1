Descripción detallada

clase base para todos los elementos SCXML.

Esta es una clase base común para todas las clases de elementos SCXML. Gana atributos XML a nivel general, tiene utilidades para verificar la contención de documentos y proporciona algunos hooks de infraestructura.

Desde

Coin 3.1
