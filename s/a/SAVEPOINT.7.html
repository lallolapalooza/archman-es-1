NOMBRE

SAVEPOINT - define un nuevo punto de guardado dentro de la transacción actual

SINOPSIS

SAVEPOINT nombre_punto_guardado

DESCRIPCIÓN

SAVEPOINT establece un nuevo punto de guardado dentro de la transacción actual.

Un punto de guardado es una marca especial dentro de una transacción que permite que todos los comandos que se ejecutan después de que se estableció sean deshechos, restaurando el estado de la transacción a como estaba en el momento del punto de guardado.

PARÁMETROS

nombre_punto_guardado

El nombre que se le da al nuevo punto de guardado. Si ya existen puntos de guardado con el mismo nombre, no serán accesibles hasta que se liberen los puntos de guardado más nuevos con el mismo nombre.

NOTAS

Utilice ROLLBACK TO para deshacer hasta un punto de guardado. Utilice RELEASE SAVEPOINT para destruir un punto de guardado, conservando los efectos de los comandos ejecutados después de que se estableció.

Los puntos de guardado solo se pueden establecer dentro de un bloque de transacción. Puede haber varios puntos de guardado definidos dentro de una transacción.

EJEMPLOS

Para establecer un punto de guardado y luego deshacer los efectos de todos los comandos ejecutados después de que se estableció:

BEGIN;
    INSERT INTO tabla1 VALUES (1);
    SAVEPOINT mi_punto_guardado;
    INSERT INTO tabla1 VALUES (2);
    ROLLBACK TO SAVEPOINT mi_punto_guardado;
    INSERT INTO tabla1 VALUES (3);
COMMIT;

La transacción anterior insertará los valores 1 y 3, pero no el 2.

Para establecer y luego destruir un punto de guardado:

BEGIN;
    INSERT INTO tabla1 VALUES (3);
    SAVEPOINT mi_punto_guardado;
    INSERT INTO tabla1 VALUES (4);
    RELEASE SAVEPOINT mi_punto_guardado;
COMMIT;

La transacción anterior insertará tanto el 3 como el 4.

Para usar un nombre de punto de guardado único:

BEGIN;
    INSERT INTO tabla1 VALUES (1);
    SAVEPOINT mi_punto_guardado;
    INSERT INTO tabla1 VALUES (2);
    SAVEPOINT mi_punto_guardado;
    INSERT INTO tabla1 VALUES (3);
    -- deshacer hasta el segundo punto de guardado
    ROLLBACK TO SAVEPOINT mi_punto_guardado;
    SELECT * FROM tabla1;               -- muestra las filas 1 y 2
    -- liberar el segundo punto de guardado
    RELEASE SAVEPOINT mi_punto_guardado;
    -- deshacer hasta el primer punto de guardado
    ROLLBACK TO SAVEPOINT mi_punto_guardado;
    SELECT * FROM tabla1;               -- muestra solo la fila 1
COMMIT;

La transacción anterior muestra que la fila 3 se deshace primero, luego la fila 2.

COMPATIBILIDAD

SQL requiere que un punto de guardado se destruya automáticamente cuando se establece otro punto de guardado con el mismo nombre. En PostgreSQL, el punto de guardado antiguo se conserva, aunque solo se utilizará el más reciente al deshacer o liberar. (Liberar el punto de guardado más nuevo con RELEASE SAVEPOINT hará que el antiguo vuelva a ser accesible para ROLLBACK TO SAVEPOINT y RELEASE SAVEPOINT.) De lo contrario, SAVEPOINT cumple totalmente con SQL.
