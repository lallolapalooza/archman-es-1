Safe::Isa(3) Documentación de Perl aportada por el usuario Safe::Isa(3)

NOMBRE

Safe::Isa - Llamar a isa, can, does y DOES de forma segura en cosas que puede que no sean objetos

SINOPSIS

use strict;
use warnings;

{ package Foo; sub new { bless({}, $_[0]) } }
{ package Bar; our @ISA = qw(Foo); sub bar { 1 } }

my $foo = Foo->new;
my $bar = Bar->new;
my $blam = [ 42 ];

# uso básico de isa -

$foo->isa('Foo');  # verdadero
$bar->isa('Foo');  # verdadero
$blam->isa('Foo'); # BOOM

$foo->can('bar');  # falso
$bar->can('bar');  # verdadero
$blam->can('bar'); # BOOM

# Uso de Safe::Isa -

use Safe::Isa;

$foo->$_isa('Foo');  # verdadero
$bar->$_isa('Foo');  # verdadero
$blam->$_isa('Foo'); # falso, sin boom hoy

$foo->$_can('bar');  # falso
$bar->$_can('bar');  # verdadero
$blam->$_can('bar'); # falso, sin boom hoy

De forma similar:

$maybe_an_object->$_does('RoleName'); # verdadero o falso, sin boom hoy
$maybe_an_object->$_DOES('RoleName'); # verdadero o falso, sin boom hoy

Y por si acaso nos perdimos algún método o dos:

$maybe_an_object->$_call_if_object(name => @args);
$maybe_an_object->$_call_if_can(name => @args);

O para reutilizar un ejemplo anterior con fines de explicación:

$foo->$_call_if_object(isa => 'Foo');  # verdadero
$bar->$_call_if_object(isa => 'Foo');  # verdadero
$blam->$_call_if_object(isa => 'Foo'); # falso, sin boom hoy

DESCRIPCIÓN

¿Cuántas veces te has encontrado escribiendo:

if ($obj->isa('Something')) {

y poco después maldiciendo y cambiándolo a:

if (Scalar::Util::blessed($obj) and $obj->isa('Something')) {

¿Correcto? Por eso existe este módulo.

Dado que Perl nos permite proporcionar una referencia de subrutina o un nombre de método al operador -> cuando se usa como una llamada a método, y una subrutina no requiere que el invocante sea realmente un objeto, podemos crear versiones seguras de isa, can y similares usando una referencia de subrutina que solo intenta llamar al método si se usa en un objeto. Así:

my $isa_Foo = $maybe_an_object->$_call_if_object(isa => 'Foo');

es equivalente a

my $isa_Foo = do {
  if (Scalar::Util::blessed($maybe_an_object)) {
    $maybe_an_object->isa('Foo');
  } else {
    undef;
  }
};

Tenga en cuenta que no manejamos la prueba de nombres de clase, porque muchas cosas son nombres de clase válidos que quizás no quiera tratar como tales (como decir "Matt") - la función "is_module_name" de Module::Runtime es una buena manera de comprobar algo en lo que podría ser capaz de llamar métodos si quiere hacer eso.

Nos aseguramos de que el contexto escalar/lista se preserve para el método que finalmente se llama.

EXPORTA

$_isa

$maybe_an_object->$_isa('Foo');

Si se llama en un objeto, llama a "isa" en él y devuelve el resultado, de lo contrario, no devuelve nada.

$_can

$maybe_an_object->$_can('Foo');

Si se llama en un objeto, llama a "can" en él y devuelve el resultado, de lo contrario, no devuelve nada.

$_does

$maybe_an_object->$_does('Foo');

Si se llama en un objeto, llama a "does" en él y devuelve el resultado, de lo contrario, no devuelve nada. Si el método "does" no existe, no devuelve nada en lugar de fallar.

$_DOES

$maybe_an_object->$_DOES('Foo');

Si se llama en un objeto, llama a "DOES" en él y devuelve el resultado, de lo contrario, no devuelve nada. En versiones de Perl anteriores a 5.10.0, el método incorporado "DOES" no existe. Si el método no existe, esto recurrirá a llamar a "isa" al igual que el método "DOES" incorporado.

$_call_if_object

$maybe_an_object->$_call_if_object(method_name => @args);

Si se llama en un objeto, llama a "method_name" en él y devuelve el resultado, de lo contrario, no devuelve nada.

$_call_if_can

$maybe_an_object->$_call_if_can(name => @args);

Si se llama en un objeto, llama a "can" en él; si eso devuelve verdadero, entonces llama a "method_name" en él y devuelve el resultado; si alguna condición es falsa, no devuelve nada.
