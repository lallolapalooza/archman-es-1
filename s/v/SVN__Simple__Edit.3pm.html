NOMBRE

SVN::Simple::Edit - Una interfaz simple para manejar editores delta de svn

SINOPSIS

my $edit = SVN::Simple::Edit->new
   (_editor => [SVN::Repos::get_commit_editor($repos, "file://$repospath",
                                     '/', 'root', 'FOO', \&committed)],
   );
$edit->open_root($fs->youngest_rev);
$edit->add_directory ('trunk');
$edit->add_file ('trunk/filea');
$edit->modify_file ("trunk/fileb", "content", $checksum);
$edit->delete_entry ("trunk/filec");
$edit->close_edit ();
...
$edit->copy_directory ('branches/a, trunk, 0);

DESCRIPCIÓN

SVN::Simple::Edit envuelve el editor delta de subversion con una interfaz amigable para Perl y así puedes manejarlo fácilmente para describir cambios en un árbol. Un uso común es envolver el editor de commits, para que puedas hacer commits a un repositorio de subversion fácilmente.

Esto también significa que no puedes proporcionar el objeto $edit como un delta_editor a otra API, y es por eso que este módulo se llama ::Edit en lugar de ::Editor.

Ver SVN::Simple::Editor para una interfaz simple que implementa un editor delta.

PARÁMETROS

para el constructor

_editor
El editor que recibirá las llamadas al editor delta.
missing_handler
Se llama cuando los directorios padre aún no están abiertos, podría ser:
\&SVN::Simple::Edit::build_missing
Siempre construye los padres si no los abres explícitamente.
\&SVN::Simple::Edit::open_missing
Siempre abre los padres si no los creas explícitamente.
SVN::Simple::Edit::check_missing ([$root])
Comprueba si la ruta existe en $root. Ábrela si es así, de lo contrario créala.
root
La raíz por defecto a usar por SVN::Simple::Edit::check_missing.
base_path
La ruta base para la que se crea el objeto de edición para enviar llamadas al editor delta.
noclose
No cerrar archivos o directorios. Esto podría permitir operaciones no ordenadas en directorios/archivos.

MÉTODOS

Nota: No esperes que todos los editores funcionen con operaciones no ordenadas en orden DFS.

open_root ($base_rev)
add_directory ($path)
open_directory ($path)
copy_directory ($path, $from, $fromrev)
add_file ($path)
open_file ($path)
copy_file ($path, $from, $fromrev)
delete_entry ($path)
change_dir_prop ($path, $propname, $propvalue)
change_file_prop ($path, $propname, $propvalue)
close_edit ()
