NOMBRE

SVN::Repos - Funciones del repositorio Subversion

SINOPSIS

use SVN::Core;
use SVN::Repos;
use SVN::Fs;
my $repos = SVN::Repos::open('/ruta/al/repos');
print $repos->fs()->youngest_rev;

DESCRIPCIÓN

SVN::Repos envuelve las funciones orientadas a objetos "svn_repos_t", proporcionando acceso a un repositorio Subversion en el sistema de archivos local.

CONSTRUCTORES

SVN::Repos::open($ruta)
Esta función abre un repositorio existente y devuelve un objeto "SVN::Repos".
create($ruta, undef, undef, $config, $fs_config)
Esta función crea un nuevo repositorio y devuelve un objeto "SVN::Repos".

MÉTODOS

$repos->dump_fs($dump_fh, $feedback_fh, $start_rev, $end_rev, $incremental, $cancel_callback)
$repos->dump_fs2($dump_fh, $feedback_fh, $start_rev, $end_rev, $incremental, $deltify, $cancel_callback)
Crea un archivo de volcado del repositorio desde la revisión $start_rev hasta $end_rev, lo almacena en el manejador de archivo $dump_fh y escribe retroalimentación sobre el progreso de la operación en el manejador de archivo $feedback_fh.

Si $incremental es TRUE, la primera revisión volcada será una diferencia contra la revisión anterior (generalmente parece un volcado completo del árbol).

Si $use_deltas es TRUE, solo se volcarán las propiedades de los nodos que hayan cambiado en relación con el contenido anterior, y se volcarán los contenidos de texto como datos svndiff contra el contenido anterior. Independientemente de cómo se establezca este indicador, la primera revisión de un volcado no incremental se realizará con texto plano completo. Un volcado con @a use_deltas configurado no puede ser cargado por Subversion 1.0.x.

Si $cancel_callback no es "undef", debe ser una referencia de código que se llama periódicamente para determinar si el cliente desea cancelar el volcado. Consulte "CANCELLATION CALLBACK" en SVN::Client para más detalles.

Ejemplo:

use SVN::Core;
use SVN::Repos;
my $repos = SVN::Repos::open('/repo/sandbox');
open my $fh, ">/tmp/tmp.dump" or die "No se puede abrir el archivo: $!\n";
my $start_rev   = 10;
my $end_rev     = 20;
my $incremental = 1;
my $deltify     = 1;
$repos->dump_fs2($fh, \*STDOUT,          # Archivo de volcado => $fh, Retroalimentación => STDOUT
                 $start_rev, $end_rev,   # Rango de revisiones
                 $incremental, $deltify, # Opciones
                 undef);                 # Callback de cancelación
close $fh;
$repos->load_fs($dumpfile_fh, $feedback_fh, $uuid_action, $parent_dir, $cancel_callback);
$repos->load_fs2($dumpfile_fh, $feedback_fh, $uuid_action, $parent_dir, $use_pre_commit_hook, $use_post_commit_hook, $cancel_callback);
Carga un archivo de volcado especificado por el manejador de archivo $dumpfile_fh en el repositorio. Si el flujo de volcado contiene historial de copias que no está disponible en el repositorio, se generará un error.

El UUID del repositorio se actualizará SÓLO si el flujo de volcado contiene un UUID y $uuid_action no es igual a $SVN::Repos::load_uuid_ignore y el repositorio no contiene revisiones o $uuid_action es igual a $SVN::Repos::load_uuid_force.

Si el flujo de volcado no contiene UUID, entonces $uuid_action se ignora y el UUID del repositorio no se modifica.

Si $parent_dir no es nulo, entonces el analizador re-parentará todos los nodos cargados, desde la raíz hasta @a parent_dir. El directorio $parent_dir debe ser un directorio existente en el repositorio.

Si se establece $use_pre_commit_hook, se llamará al hook pre-commit del repositorio antes de confirmar cada revisión cargada.

Si se establece $use_post_commit_hook, se llamará al hook post-commit del repositorio después de confirmar cada revisión cargada.

Si $cancel_callback no es "undef", debe ser una referencia de código que se llama periódicamente para determinar si el cliente desea cancelar la carga. Consulte "CANCELLATION CALLBACK" en SVN::Client para más detalles.

Debe proporcionar al menos "undef" para estos parámetros para que la llamada al método funcione.

Ejemplo:
use SVN::Core;
use SVN::Repos;

my $repos = SVN::Repos::open('/repo/test_repo');
open my $fh, "/repo/sandbox.dump" or die "No se puede abrir el archivo: $!\n";
my $parent_dir = '/';
my $use_pre_commit_hook  = 0;
my $use_post_commit_hook = 0;
$repos->load_fs2($fh, \*STDOUT,
                 $SVN::Repos::load_uuid_ignore, # Ignorar uuid
                 $parent_dir,
                 $use_pre_commit_hook,  # ¿Usar hook pre-commit?
                 $use_post_commit_hook, # ¿Usar hook post-commit?
                 undef, undef);
close $fh;
$repos->fs()
Devuelve el objeto "SVN::Fs" para este repositorio.
$repos->get_logs([$ruta, ...], $inicio, $fin, $discover_changed_paths, $strict_node_history, $receiver)
Itera sobre todas las revisiones que afectan a la lista de rutas pasadas como primer parámetro, comenzando en $inicio y terminando en $fin.

$receiver es llamado por cada cambio. Los argumentos para $receiver son:

$self
El objeto "SVN::Repos".
$paths
"undef" si $discover_changed_paths es falso. De lo contrario, contiene un hash de rutas que han cambiado en esta revisión.
$rev
La revisión en la que ocurrió este cambio.
$date
La fecha y hora en que ocurrió la revisión.
$msg
El mensaje de registro asociado con esta revisión.
$pool
Un objeto "SVN::Pool" que puede ser usado en la función.

Si $strict_node_history es verdadero, entonces las copias no serán recorridas.

SVN::Repos Perl API

NAME

SVN::Repos — Manipulate Subversion repositories

SYNOPSIS

use SVN::Repos;

my $repos = SVN::Repos::repos_open($path);
my $fs = $repos->fs();
my $root = $fs->youngest_rev();
# ...

DESCRIPTION

This module provides Perl bindings for the Subversion repository-access library. It allows you to inspect and manipulate Subversion repositories from Perl.

For the most part, the API mirrors the C API provided by libsvn_repos.
