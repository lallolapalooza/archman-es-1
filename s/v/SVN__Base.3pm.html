NOMBRE

SVN::Base - Clase base para importar símbolos para módulos svn

SINOPSIS

# Cargar las funciones svn_ra_* en el espacio de nombres SVN::Ra.
package SVN::Ra;
use SVN::Base qw(Ra svn_ra_);
# Cargar los accesores de la estructura svn_config_t en el espacio de nombres mágico
# proporcionado por swig, para que podamos usarlo devuelto por otras funciones
package _p_svn_config_t;
use SVN::Base qw(Core svn_config_);

DESCRIPCIÓN

SVN::Base es un módulo que importa los símbolos crudos de las uniones perl de subversion creados por swig, en un espacio de nombres adecuado y los hace más fáciles de usar.

También encontrará los accesores para los miembros de una estructura C, creará una función accesora más simple como "$data->field()" y "$data->field($new_value)".

Una vez que entienda la convención de las funciones de subversión en las uniones perl, podrá buscar en la API de subversión y escribirla en perl. La API está disponible en los archivos de cabecera de origen o en línea en https://subversion.apache.org/docs/api/latest/.

INTERNOS

Las uniones perl de swig envuelven las funciones crudas en diferentes módulos perl, por ejemplo, SVN::_Core, SVN::_Repos. Al importar, SVN::Base inicializa el módulo solicitado si aún no se ha cargado, e itera sobre los símbolos proporcionados en ese módulo, luego coloca la función con el prefijo recortado en el espacio de nombres del llamador para esta importación.

El tercer parámetro hasta el último es una lista de sufijos de símbolos que desea que SVN::Base no importe en su espacio de nombres. Esto es útil para casos en los que puede desear importar ciertos símbolos de manera diferente a lo normal.

ADVERTENCIAS

SVN::Base considera que una función es un accesorio de miembro de estructura si tiene el sufijo ``_get'' o ``_set''. Las funciones reales con estos sufijos necesitarán un manejo adicional.
