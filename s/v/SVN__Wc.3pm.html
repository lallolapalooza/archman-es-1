FUNCIONES

SVN::Wc::parse_externals_description3($parent_directory, $desc, $canonicalize_url, $pool);
Analiza la cadena $desc como un valor "svn:externals" y devuelve una referencia a una matriz de objetos _p_svn_wc_external_item2_t. Si $canonicalize_url es verdadero, canoniza el miembro "url" de esos objetos. $parent_directory solo se utiliza para construir cadenas de error.

NAME

SVN::Wc - Subversion Working Copy Access

SYNOPSIS

  use SVN::Wc;
  
  my $wc = SVN::Wc::Wc->new('/path/to/working/copy');
  
  # Notification callbacks
  sub notify_handler {
      my ($notification, $message) = @_;
      # ... handle notification ...
      return $SVN::Wc::Notify::Continue;
  }
  
  $wc->notify_handler(\¬ify_handler);
  
  # Get status
  my @entries = $wc->status(
      {
          show_hidden => 1,
          recurse     => 1,
      }
  );
  
  for my $entry (@entries) {
      # ... process $entry ...
  }
  
  # Update
  $wc->update(
      {
          revision => 'HEAD',
      }
  );
  
  # Commit
  $wc->commit(
      {
          message => "My commit message",
      }
  );
  
  # ... and so on ...

FUNCTIONS

This module provides a high-level interface to the Subversion working copy library. It wraps the low-level SVN::Client and SVN::Pool APIs with a more object-oriented interface, and provides notification callbacks for operations.

The primary object is SVN::Wc::Wc, which represents a working copy. You create an instance by passing the path to the working copy's root directory to the constructor:

  my $wc = SVN::Wc::Wc->new('/path/to/working/copy');

Methods on the $wc object include:

add
Add files/directories to the working copy.

Example:

  $wc->add(['file1.txt', 'dir2']);
blame
Get blame information for a file.
cat
Retrieve the content of a file.

Example:

  my $content = $wc->cat('file.txt');
checkout
Checkout a Subversion repository URL into a new working copy.
commit
Commit changes in the working copy to the repository.
copy
Copy files/directories within the working copy or to the repository.
delete
Delete files/directories from the working copy.
diff
Generate differences between revisions or between the working copy and the repository.
export
Export a clean directory from the repository.
get_commit_info
Get commit information for a revision.
get_url
Get the repository URL for a path in the working copy.
import
Import a directory into the repository.
info
Get information about a file or directory in the working copy.
list
List the contents of a directory in the repository.
log
Retrieve commit logs for a path.
mkdir
Create a new directory in the working copy.
move
Move/rename files/directories in the working copy.
notify_handler
Set a callback handler for notifications during operations.
propset
Set a property on a file or directory.
propget
Get a property from a file or directory.
proplist
List properties of a file or directory.
rebase
Rebase changes.
resolve
Resolve conflicts.
revert
Revert changes in the working copy.
status
Get the status of files and directories in the working copy.
switch
Switch the working copy to a different branch or tag.
unlock
Unlock a file or directory.
update
Update the working copy to the latest revision.

OBJECTS

The SVN::Wc::Wc object represents a Subversion working copy.

The status method returns an array of SVN::Wc::Status objects, each representing the status of a file or directory.

The SVN::Wc::Notify module provides constants for notification types and states.

The SVN::Wc::Schedule module provides constants for scheduling actions.

The SVN::Wc::Status module provides constants for status codes.
