NOMBRE

SVN::Delta - Funciones de delta de Subversion

SINOPSIS

require SVN::Core;
require SVN::Repos;
require SVN::Delta;
# dirigiendo un editor
my $editor = SVN::Delta::Editor->
    new(SVN::Repos::get_commit_editor($repos, "file://$repospath",
                                      '/', 'root', 'FOO', \&committed));
my $rootbaton = $editor->open_root(0);
my $fbaton = $editor->add_file('filea', $rootbaton,
                               undef, -1);
my $ret = $editor->apply_textdelta($fbaton, undef);
SVN::TxDelta::send_string("CONTENIDO DEL ARCHIVO A", @$ret);
# implementando un editor en perl
SVN::Repos::dir_delta($root1, $path, undef,
                      $root2, $path,
                      SVN::Delta::Editor->new(_debug=>1),
                      1, 1, 0, 1

DESCRIPCIÓN

SVN::Delta envuelve las funciones relacionadas con delta en subversion. La más importante es SVN::Delta::Editor, la interfaz para describir deltas de árbol. Por defecto, SVN::Delta::Editor reenvía las llamadas a métodos a su miembro interno "_editor", que podría ser un editor en C (como el que se obtiene de get_commit_editor), u otro objeto SVN::Delta::Editor.

SVN::Delta::Editor

Dirigiendo Editores

Si deseas dirigir un editor nativo (como el commit_editor obtenido por SVN::Repos::get_commit_editor), crea un objeto SVN::Delta::Editor con el par editor/baton nativo. El objeto estará listo para usar y sus llamadas a métodos serán reenviadas al editor nativo.

Implementando Editores

Si deseas implementar un editor, crea una subclase de SVN::Delta::Editor e implementa las callbacks del editor. Consulta la sección MÉTODOS a continuación.

CONSTRUCTOR - new(...)

new($editor, $editor_baton)
Enlace al editor nativo

También puedes pasar un array asociativo a new:

_debug
Activar depuración.
_editor
Un arrayref del par editor/baton u otro objeto SVN::Delta::Editor con el que enlazar.

MÉTODOS

Por favor, consulta la sección svn_delta.h en la API de Subversion. Las funciones miembro de svn_delta_editor_t se pueden llamar como métodos de los objetos SVN::Delta::Editor, omitiendo el edit_baton. El pool también es opcional.

Si estás creando una subclase, los métodos toman exactamente los mismos argumentos que las funciones miembro (ten en cuenta que los void ** son datos devueltos, aunque como en el resto de los enlaces de perl), con el edit_baton omitido.

ERRORES

Las funciones que devuelven un par editor/baton deberían ser mapeadas de tipo a un objeto SVN::Delta::Editor.
