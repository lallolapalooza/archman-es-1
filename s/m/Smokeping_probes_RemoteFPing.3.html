NOMBRE

Smokeping::probes::RemoteFPing - Sonda FPing Remota para SmokePing

SINOPSIS

*** Probes ***
+RemoteFPing
binary = /usr/bin/ssh # obligatorio
blazemode = true
hostinterval = 1.5
interface = eth0
mininterval = 0.001
offset = 50%
packetsize = 5000
pings = 20
protocol = 4
rbinary = /usr/bin/fping # obligatorio
rhost = mi.host.pinger # obligatorio
rport = 22
ruser = foo
sourceaddress = 192.168.0.1
step = 300
timeout = 1.5
tos = 0x20
usestdout = true
# Las siguientes variables pueden ser anuladas en cada sección de objetivo
/^influx_.+/ = influx_location = En el sótano
# [...]
*** Targets ***
probe = RemoteFPing # si esta debe ser la sonda predeterminada
# [...]
+ mi_objetivo
# probe = RemoteFPing # si la sonda predeterminada es otra
host = mi.host
/^influx_.+/ = influx_location = En el sótano

DESCRIPCIÓN

Integra la ejecución remota de FPing vía ssh/rsh en smokeping. La variable binary debe apuntar a su copia del programa ssh/rsh. La variable rbinary debe apuntar a su copia del programa fping en el extremo remoto.

VARIABLES

Variables específicas de la sonda soportadas:

binary
Esta variable especifica la ruta del programa de shell remoto (normalmente ssh, rsh o remsh). Cualquier otro script o binario que pueda ser llamado como

binary [ -l ruser ] [ -p rport ] rhost rbinary

puede ser utilizado.

Valor de ejemplo: /usr/bin/ssh

Este ajuste es obligatorio.

blazemode
Envía un ping adicional y luego descarta la primera respuesta ya que la primera está destinada a ser un valor atípico.

Valor de ejemplo: true

hostinterval
El parámetro "-p" de fping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping. De fping(1):

Este parámetro establece el tiempo que fping espera entre paquetes sucesivos a un objetivo individual.

Valor de ejemplo: 1.5

interface
El nombre de la interfaz de red para realizar el ping.

Valor de ejemplo: eth0

mininterval
El parámetro "-i" de fping, pero en segundos (probablemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping. De fping(1):

La cantidad mínima de tiempo entre el envío de un paquete ping a cualquier objetivo.

Valor de ejemplo: 0.001

Valor predeterminado: 0.01

offset
Si ejecuta muchas sondas concurrentemente, puede que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro offset específico de la sonda puede cambiar el punto en el tiempo cuando cada sonda se ejecutará. El offset se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el offset de la sección 'General' si nada se especifica aquí. Tenga en cuenta que esto NO influye en los rrds en sí, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 50%

packetsize
El tamaño del paquete ping (en el rango de 12-64000 bytes).

Valor de ejemplo: 5000

pings
Cuántos pings se deben enviar a cada objetivo, si es diferente del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD se fija cuando se generan originalmente, y si cambia este parámetro posteriormente, deberá eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 20

protocol
Elija si el ping debe usar IPv4 o IPv6.

Valor de ejemplo: 4

rbinary
La ubicación de su binario fping.

Valor de ejemplo: /usr/bin/fping

Este ajuste es obligatorio.

rhost
La opción rhost especifica el dispositivo remoto desde donde se lanzará fping.

Valor de ejemplo: mi.host.pinger

Este ajuste es obligatorio.

rport
La opción (opcional) rport le permite especificar el puerto del host remoto.

Valor de ejemplo: 22

ruser
La opción (opcional) ruser le permite especificar el usuario remoto, si es diferente del que ejecuta el demonio smokeping.

Valor de ejemplo: foo

sourceaddress
El parámetro "-S" de fping. De fping(1):

Establecer la dirección de origen.

Valor de ejemplo: 192.168.0.1

step
Duración del intervalo base que esta sonda debe utilizar, si es diferente del especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD se fija cuando se generan originalmente, y si cambia el parámetro de paso posteriormente, deberá eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 300

timeout
El parámetro "-t" de fping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping. Tenga en cuenta que como Smokeping utiliza el modo de 'conteo' de fping (-C), esto aparentemente solo afecta al último ping.

Valor de ejemplo: 1.5

tos
Establece el tipo de servicio (TOS) de los paquetes ICMP salientes. Necesitas al menos fping-2.4b2_to3-ipv6 para que esto funcione. Encuentra una copia en www.smokeping.org/pub.

Valor de ejemplo: 0x20

usestdout
Escucha la salida de FPing en stdout en lugar de stderr ... (la versión 3.3+ envía sus estadísticas en stdout).

Valor de ejemplo: true

NOTAS

Es importante asegurarse de que puede acceder a la máquina remota sin que se le solicite contraseña, de lo contrario, esta sonda no funcionará correctamente. Para probar, simplemente intente algo como esto:

$ ssh foo@HostA.foobar.com fping HostB.barfoo.com

Lo siguiente que debe ver es la salida de fping.

Las variables rhost, ruser, rport y rbinary se configuraban anteriormente en la sección Targets del primer objetivo o sus padres. Fueron movidas a la sección Probes, porque las variables no son realmente específicas del objetivo (todos los objetivos se miden con los mismos parámetros). Las secciones Targets ya no son reconocidas.

ERRORES

Esta funcionalidad debería estar en un módulo genérico de 'ejecución remota' para que pudiera ser utilizado también para las otras sondas.
