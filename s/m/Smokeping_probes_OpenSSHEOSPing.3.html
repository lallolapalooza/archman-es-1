NOMBRE

Smokeping::probes::OpenSSHEOSPing - Sonda SSH de Arista EOS para SmokePing

SINOPSIS

*** Sondas ***
+OpenSSHEOSPing
forks = 5
offset = 50%
packetsize = 100
step = 300
timeout = 15
# Las siguientes variables se pueden anular en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
eospass = contraseña # obligatorio
eosuser = usuario # obligatorio
pings = 5
psource = 192.168.2.129
source = 192.168.2.1 # obligatorio
 unpriv = 1
# [...]
*** Destinos ***
probe = OpenSSHEOSPing # si esta debe ser la sonda predeterminada
# [...]
+ mi_destino
# probe = OpenSSHEOSPing # si la sonda predeterminada es otra cosa
host = mi.servidor
/^influx_.+/ = influx_location = En el sótano
eospass = contraseña # obligatorio
eosuser = usuario # obligatorio
pings = 5
psource = 192.168.2.129
source = 192.168.2.1 # obligatorio
 unpriv = 1

DESCRIPCIÓN

Se conecta a Arista EOS a través de OpenSSH para ejecutar comandos ping. Esta sonda utiliza el CLI "ping" del Arista EOS. Tiene la opción de especificar desde qué interfaz se originan los pings.

VARIABLES

Variables específicas de la sonda admitidas:

forks
Ejecuta este número de procesos concurrentes como máximo

Valor de ejemplo: 5

Valor predeterminado: 5

offset
Si ejecuta muchas sondas concurrentemente, es posible que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puede cambiar el punto en el tiempo en que se ejecutará cada sonda. El desplazamiento se especifica en el % del intervalo total, o alternativamente como 'aleatorio', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Tenga en cuenta que esto NO influye en los propios RRD, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 50%

packetsize
La opción (opcional) packetsize le permite configurar el tamaño del paquete para los pings enviados.

Valor predeterminado: 100

step
Duración del intervalo base que esta sonda debe usar, si es diferente del especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD es fijo cuando se generan originalmente, y si cambia el parámetro step después, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 300

timeout
Cuánto tiempo tarda un 'ping' individual como máximo

Valor de ejemplo: 15

Valor predeterminado: 5

Variables específicas del destino admitidas:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará con "tag_". Las etiquetas se pueden usar para filtrar.

Valor de ejemplo: influx_location = En el sótano

eospass
La opción eospass le permite especificar la contraseña para el nombre de usuario especificado con la opción eosuser.

Valor de ejemplo: contraseña

Esta configuración es obligatoria.

eosuser
La opción eosuser le permite especificar un nombre de usuario que tenga capacidad de ping en el Dispositivo EOS.

Valor de ejemplo: usuario

Esta configuración es obligatoria.

pings
Cuántos pings se deben enviar a cada destino, si es diferente del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD es fijo cuando se generan originalmente, y si cambia este parámetro después, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 5

psource
La opción (opcional) psource especifica una dirección IP o interfaz alternativa desde la cual desea originar sus pings. Los routers pueden tener muchas direcciones IP e interfaces. Cuando haces ping desde un router, tienes la capacidad de elegir desde qué interfaz y/o qué dirección IP se origina el ping. Especificar una IP/interfaz no especifica necesariamente la interfaz desde la cual saldrá el ping, pero especificará de qué dirección parecerán provenir los paquetes. Si se omite esta opción, el Dispositivo EOS originará el paquete automáticamente según el enrutamiento y/o las métricas. Si esto no tiene sentido para usted, simplemente déjelo fuera.

Valor de ejemplo: 192.168.2.129

source
La opción source especifica el dispositivo EOS que ejecutará los comandos ping. Esta dirección se utilizará para la conexión SSH.

Valor de ejemplo: 192.168.2.1

Esta configuración es obligatoria.

unpriv
Si la cuenta no tiene privilegios, especifique la opción ' unpriv'. También debe configurar "pings = 5", ya que es el único valor admitido, y los valores especificados para packetsize o psource se ignoran.

Valor de ejemplo: 1

NOTAS

Configuración EOS

El dispositivo EOS debe tener configurado un nombre de usuario/contraseña, y el servidor SSH no debe estar deshabilitado.

Asegúrese de conectarse al host remoto una vez desde la línea de comandos como el usuario que ejecuta smokeping. En la primera conexión, SSH preguntará si desea agregar el nuevo host a su archivo known_hosts. Esto no sucederá automáticamente, por lo que el script fallará al iniciar sesión hasta que la clave SSH de su cuadro EOS esté en el archivo known_hosts.

Requisitos

Este módulo requiere los módulos Perl Net::OpenSSH y IO::Pty.
