NOMBRE

SMIME_write_PKCS7 - convierte una estructura PKCS#7 a formato S/MIME

SINOPSIS

#include <openssl/pkcs7.h>
int SMIME_write_PKCS7(BIO *out, PKCS7 *p7, BIO *data, int flags);

DESCRIPCIÓN

SMIME_write_PKCS7() añade las cabeceras MIME apropiadas a una estructura PKCS#7 para producir un mensaje S/MIME.

out es el BIO al que se escribirán los datos. p7 es la estructura PKCS7 apropiada. Si la transmisión está habilitada, el contenido debe proporcionarse en el argumento data. flags es un conjunto opcional de indicadores.

NOTAS

Los siguientes indicadores se pueden pasar en el parámetro flags.

Si se establece PKCS7_DETACHED, se utilizará la firma de texto plano; esta opción solo tiene sentido para datos firmados donde también se establece PKCS7_DETACHED cuando también se llama a PKCS7_sign().

Si se establece el indicador PKCS7_TEXT, se añadirán cabeceras MIME para el tipo text/plain al contenido; esto solo tiene sentido si también se establece PKCS7_DETACHED.

Si se establece el indicador PKCS7_STREAM, se realiza la transmisión. Este indicador solo debe establecerse si PKCS7_STREAM también se estableció en la llamada anterior a PKCS7_sign() o PKCS7_encrypt().

Si se está utilizando la firma de texto plano y PKCS7_STREAM no está establecido, los datos deben leerse dos veces: una para calcular la firma en PKCS7_sign() y otra para generar el mensaje S/MIME.

Si se realiza la transmisión, el contenido se genera en formato BER utilizando codificación construida de longitud indefinida, excepto en el caso de datos firmados con contenido separado, donde el contenido está ausente y se utiliza formato DER.

ERRORES

SMIME_write_PKCS7() siempre codifica en base64 las estructuras PKCS#7; debería haber una opción para deshabilitar esto.

VALORES DE RETORNO

SMIME_write_PKCS7() devuelve 1 en caso de éxito o 0 en caso de fallo.

VER TAMBIÉN

ERR_get_error(3), PKCS7_sign(3), PKCS7_verify(3), PKCS7_encrypt(3) PKCS7_decrypt(3)
