NOMBRE

Smokeping::probes::FPing6 - Sonda FPing6 para SmokePing

SINOPSIS

*** Sondas ***
+FPing6
binary = /usr/bin/fping6 # obligatorio
blazemode = true
hostinterval = 1.5
interface = eth0
mininterval = 0.001
offset = 50%
packetsize = 5000
pings = 20
protocol = 6
sourceaddress = ::1
step = 300
timeout = 1.5
tos = 0x20
usestdout = true
# Las siguientes variables se pueden anular en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
# [...]
*** Destinos ***
probe = FPing6 # si esta debe ser la sonda predeterminada
# [...]
+ mi_destino
# probe = FPing6 # si la sonda predeterminada es otra cosa
host = mi.host
/^influx_.+/ = influx_location = En el sótano

DESCRIPCIÓN

Integra FPing6 como una sonda en smokeping. Esta sonda se deriva de FPing; la única diferencia es que el host de destino utilizado para comprobar la salida del comando fping es ::1 en lugar de localhost.

VARIABLES

Variables específicas de la sonda admitidas:

binary
La ubicación de tu ejecutable fping.

Valor de ejemplo: /usr/bin/fping6

Este ajuste es obligatorio.

blazemode
Envía un ping adicional y luego descarta la primera respuesta, ya que la primera está destinada a ser un valor atípico.

Valor de ejemplo: true

hostinterval
El parámetro "-p" de fping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping. De fping(1):

Este parámetro establece el tiempo que fping espera entre paquetes sucesivos a un objetivo individual.

Valor de ejemplo: 1.5

interface
El nombre de la interfaz de red en la que realizar el ping.

Valor de ejemplo: eth0

mininterval
El parámetro "-i" de fping, pero en segundos (probablemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping. De fping(1):

La cantidad mínima de tiempo entre el envío de un paquete ping a cualquier objetivo.

Valor de ejemplo: 0.001

Valor predeterminado: 0.01

offset
Si ejecutas muchas sondas concurrentemente, puede que quieras evitar que golpeen tu red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puedes cambiar el momento en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se usa el desplazamiento de la sección 'General' si no se especifica nada aquí. Ten en cuenta que esto NO influye en los rrds en sí, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 50%

packetsize
El tamaño del paquete ping (en el rango de 12-64000 bytes).

Valor de ejemplo: 5000

pings
Cuántos pings se deben enviar a cada objetivo, si son diferentes del valor global especificado en la sección Database. Ten en cuenta que el número de pings en los archivos RRD se fija cuando se generan originalmente, y si cambias este parámetro después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 20

protocol
Elige si el ping debe usar IPv4 o IPv6.

Valor de ejemplo: 6

Valor predeterminado: 6

sourceaddress
El parámetro "-S" de fping. De fping(1):

Establece la dirección de origen.

Valor de ejemplo: ::1

step
Duración del intervalo base que esta sonda debe usar, si es diferente del especificado en la sección 'Database'. Ten en cuenta que el paso en los archivos RRD se fija cuando se generan originalmente, y si cambias el parámetro de paso después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 300

timeout
El parámetro "-t" de fping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping. Ten en cuenta que como Smokeping usa el modo 'contador' (-C) de fping, esto aparentemente solo afecta al último ping.

Valor de ejemplo: 1.5

tos
Establece el tipo de servicio (TOS) de los paquetes ICMP salientes. Necesitas al menos fping-2.4b2_to3-ipv6 para que esto funcione. Encuentra una copia en www.smokeping.org/pub.

Valor de ejemplo: 0x20

usestdout
Escucha la salida de FPing en stdout en lugar de stderr... (la versión 3.3+ envía sus estadísticas en stdout).

Valor de ejemplo: true
