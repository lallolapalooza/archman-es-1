NOMBRE

Smokeping::probes::EchoPingHttp - una sonda echoping(1) para SmokePing

DESCRIPCIÓN GENERAL

Mide los tiempos de ida y vuelta HTTP (servidores web y cachés) para SmokePing.

SINOPSIS

*** Sondas ***
+EchoPingHttp
binary = /usr/bin/echoping
forks = 5
offset = 50%
step = 300
# Las siguientes variables se pueden anular en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
accept_redirects = yes
extraopts = -alguna-letra-en-la-que-el-autor-no-habia-pensado
ignore_cache = yes
ipversion = 4
pings = 5
port = 80
priority = 6
revalidate_data = no
timeout = 20
tos = 0xa0
url = /
waittime = 1
# [...]
*** Destinos ***
probe = EchoPingHttp # si esta debe ser la sonda predeterminada
# [...]
+ mi_destino
# probe = EchoPingHttp # si la sonda predeterminada es otra
host = mi.host
/^influx_.+/ = influx_location = En el sótano
accept_redirects = yes
extraopts = -alguna-letra-en-la-que-el-autor-no-habia-pensado
ignore_cache = yes
ipversion = 4
pings = 5
port = 80
priority = 6
revalidate_data = no
timeout = 20
tos = 0xa0
url = /
waittime = 1

VARIABLES

Variables específicas de la sonda admitidas:

binary
La ubicación de tu binario echoping.

Valor predeterminado: /usr/bin/echoping

forks
Ejecutar este número de procesos concurrentes como máximo

Valor de ejemplo: 5

Valor predeterminado: 5

offset
Si ejecutas muchas sondas concurrentemente, puedes querer evitar que golpeen tu red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puedes cambiar el punto en el tiempo en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Ten en cuenta que esto NO influye en los RRD en sí, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 50%

step
Duración del intervalo base que esta sonda debe usar, si es diferente del especificado en la sección 'Database'. Ten en cuenta que el paso en los archivos RRD es fijo cuando se generan originalmente, y si cambias el parámetro de paso después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 300

Variables específicas del destino admitidas:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará con "tag_" en su lugar. Las etiquetas se pueden usar para filtrar.

Valor de ejemplo: influx_location = En el sótano

accept_redirects
La opción echoping(1) "-R": Aceptar códigos de estado HTTP 3xx (redirecciones) como respuestas normales en lugar de tratarlos como errores. Ten en cuenta que esta opción solo está disponible a partir de Echoping 6.

Habilitado si el valor es cualquier cosa que no sea 'no' o '0'.

Valor de ejemplo: yes

extraopts
Cualquier opción adicional especificada aquí se pasará sin modificaciones a echoping(1).

Valor de ejemplo: -alguna-letra-en-la-que-el-autor-no-habia-pensado

ignore_cache
La opción echoping(1) "-A": forzar al proxy a ignorar la caché. Habilitado si el valor es cualquier cosa que no sea 'no' o '0'.

Valor de ejemplo: yes

ipversion
El protocolo IP utilizado. Los valores posibles son "4" y "6". Se pasa a echoping(1) como las opciones "-4" o "-6".

Valor de ejemplo: 4

pings
Cuántos pings se deben enviar a cada destino, si es diferente del valor global especificado en la sección Database. Ten en cuenta que el número de pings en los archivos RRD es fijo cuando se generan originalmente, y si cambias este parámetro después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 5

port
El puerto TCP a usar.

Valor de ejemplo: 80

priority
La opción "-p" de echoping(1).

Valor de ejemplo: 6

revalidate_data
La opción echoping(1) "-a": forzar al proxy a revalidar los datos con el servidor original. Habilitado si el valor es cualquier cosa que no sea 'no' o '0'.

Valor de ejemplo: no

timeout
La opción "-t" de echoping(1).

Valor de ejemplo: 20

Valor predeterminado: 10

tos
La opción "-P" de echoping(1).

Valor de ejemplo: 0xa0

url
La URL que se solicitará al servidor web o caché. Puede ser relativa (/...) para servidores web o absoluta (http://...) para cachés.

Valor predeterminado: /

waittime
La opción "-w" de echoping(1).

Valor de ejemplo: 1

AUTORES

Niko Tyni <ntyni@iki.fi>

NOTAS

Deberías considerar establecer un valor más bajo para la variable "pings" que el valor predeterminado de 20, ya que la obtención repetitiva de URL puede ser bastante pesada para el servidor.

Las variables fill, size y udp de EchoPing no son válidas para EchoPingHttp.
