SMIME_WRITE_CMS(3ssl) OpenSSL SMIME_WRITE_CMS(3ssl)

NOMBRE

SMIME_write_CMS - convertir la estructura CMS al formato S/MIME

SINOPSIS

#include <openssl/cms.h>
int SMIME_write_CMS(BIO *out, CMS_ContentInfo *cms, BIO *data, int flags);

DESCRIPCIÓN

SMIME_write_CMS() añade las cabeceras MIME apropiadas a una estructura CMS para producir un mensaje S/MIME.

out es el BIO al que se escribirán los datos. cms es la estructura CMS_ContentInfo apropiada. Si se habilita el streaming, el contenido debe suministrarse en el argumento data. flags es un conjunto opcional de indicadores.

NOTAS

Los siguientes indicadores se pueden pasar en el parámetro flags.

Si se establece CMS_DETACHED, se utilizará la firma de texto claro; esta opción solo tiene sentido para SignedData donde CMS_DETACHED también se establece al llamar a CMS_sign().

Si se establece el indicador CMS_TEXT, se añaden cabeceras MIME para el tipo text/plain al contenido; esto solo tiene sentido si CMS_DETACHED también se establece.

Si se establece el indicador CMS_STREAM, se realiza el streaming. Este indicador solo debe establecerse si CMS_STREAM también se estableció en la llamada anterior a una función de creación de CMS_ContentInfo.

Si se utiliza la firma de texto claro y no se establece CMS_STREAM, los datos deben leerse dos veces: una para calcular la firma en CMS_sign() y otra para generar el mensaje S/MIME.

Si se realiza streaming, el contenido se genera en formato BER utilizando codificación construida de longitud indefinida, excepto en el caso de datos firmados con contenido separado, donde el contenido está ausente y se utiliza formato DER.

ERRORES

SMIME_write_CMS() siempre codifica en base64 las estructuras CMS; debería haber una opción para deshabilitar esto.

VALORES DE RETORNO

SMIME_write_CMS() devuelve 1 en caso de éxito o 0 en caso de fallo.

VER TAMBIÉN
