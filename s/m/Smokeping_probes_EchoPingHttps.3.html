NAME

Smokeping::probes::EchoPingHttps - un probe de echoping(1) para SmokePing

OVERVIEW

Medicion de los tiempos de redirección HTTP (HTTP sobre SSL) (servidores web y cachés) para SmokePing.

SYNOPSIS

*** Probes ***
+EchoPingHttps
binary = /usr/bin/echoping
forks = 5
offset = 50%
step = 300
# El siguiente variables pueden ser sobrescritas en cada sección de objetivo
/^influx_.+/ = influx_location = En el basement
accept_redirects = yes
extraopts = -some-letter-the-author-did-not-think-of
ignore_cache = yes
ipversion = 4
pings = 5
port = 80
priority = 6
prot = 3443
revalidate_data = no
timeout = 20
tos = 0xa0
url = /
waittime = 1
# [...]
*** Objetivos ***
probe = EchoPingHttps # si este debe ser el probe por defecto
# [...]
+ mytarget
# probe = EchoPingHttps # si el probe por defecto es algo distinto
host = my.host
/^influx_.+/ = influx_location = En el basement
accept_redirects = yes
extraopts = -some-letter-the-author-did-not-think-of
ignore_cache = yes
ipversion = 4
pings = 5
port = 80
priority = 6
prot = 3443
revalidate_data = no
timeout = 20
tos = 0xa0
url = /
waittime = 1

DESCRIPTION

Como EchoPingHttp(3pm), pero con soporte SSL.

VARIABLES

Variables específicas del probe:

binary
La ubicación de tu binario de echoping.

Valor por defecto: /usr/bin/echoping

forks
Se ejecutan tantos procesos concurrentes como máximo

Ejemplo de valor: 5

Valor por defecto: 5

offset
Si ejecutas muchos probes concurrentes, puedes evitar que todos acaben golpeando tu red a la vez. Usando el parámetro de la sección específica de probe, puedes cambiar el momento en que se ejecute cada probe. El offset se especifica en % del intervalo total, o alternativamente como 'random', y el offset del apartado 'General' se usa si nada se especifica aquí. Debe recordar que esto no influye en los rrds, es solo un cuestión de cuando se inicia la recolección de datos. (Esta variable es solo aplicable si la variable 'concurrentprobes' está definida en la sección 'General'.)

Ejemplo de valor: 50%

step
El intervalo base que debería usar este probe, si distinto del especificado en la sección 'Database'. Debe recordar que el paso en los archivos rrds es fijo cuando se generan originalmente, y si cambias este parámetro después, tendrás que eliminar los archivos rrds antiguos o convertirlos. (Esta variable es solo aplicable si la variable 'concurrentprobes' está definida en la sección 'General'.)

Ejemplo de valor: 300

Variables específicas de objetivo:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición del probe. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará con "tag_". Las etiquetas pueden usarse para filtrado.

Ejemplo de valor: influx_location = En el basement

accept_redirects
El opción "-R" de echooping(1): aceptar códigos HTTP 3xx (redirecciones) como respuestas normales en lugar de tratarlos como errores. Debe tener en cuenta que esta opción solo está disponible desde Echoping 6.

Activado si el valor es cualquier cosa excepto 'no' o '0'.

Ejemplo de valor: yes

extraopts
Todo lo especificado aquí será pasado al echooping(1) sin modificaciones.

Ejemplo de valor: -some-letter-the-author-did-not-think-of

ignore_cache
La opción "-A" de echooping(1): forzar que el proxy ignore el cache. Activado si el valor es cualquier cosa excepto 'no' o '0'.

Ejemplo de valor: yes

ipversion
El protocolo de IP usado. Valores posibles: "4" y "6". Pasado a echooping(1) como "-4" o "-6".

Ejemplo de valor: 4

pings
¿Cuántos pings se deben enviar a cada objetivo, si distinto del valor global especificado en la sección 'Database'. Debe recordar que el número de pings en los archivos rrds es fijo cuando se generan originalmente, y si cambias este parámetro después, tendrás que eliminar los archivos rrds antiguos o convertirlos.

Ejemplo de valor: 5

port
El puerto TCP a usar.

Ejemplo de valor: 80

priority
La opción "-p" de echooping(1).

Ejemplo de valor: 6

prot
Ejemplo de valor: 3443

Valor por defecto: 443

revalidate_data
La opción "-a" de echooping(1): forzar que el proxy revalidate los datos con el servidor original. Activado si el valor es cualquier cosa excepto 'no' o '0'.

Ejemplo de valor: no

timeout
La opción "-t" de echooping(1).

Ejemplo de valor: 20

Valor por defecto: 10

tos
La opción "-P" de echooping(1).

Ejemplo de valor: 0xa0

url
La URL a solicitar desde el servidor web o el caché. Puede ser relativa (/...) para los servidores web o absoluta (http://...) para los cachés.

Valor por defecto: /

waittime
La opción "-w" de echooping(1).

Ejemplo de valor: 1

AUTORES

Niko Tyni <ntyni@iki.fi>

NOTAS

Debes considerar un valor más bajo para el parámetro "pings" que el valor por defecto 20, ya que la repetición de la extracción de URLs puede ser bastante pesada en el servidor.

NAME

Smokeping::probes::EchoPingHttps - Probe for Smokeping using HTTPS Echo

SYNOPSIS

This probe is part of the smokeping(8) package.

In your smokeping_config(5) you can specify the following:

    template = EchoPingHttps

DESCRIPTION

This probe uses the HTTPS Echo mechanism to measure the round trip time to a web server.

It works by sending an HTTPS request to a specified URL and measuring the time it takes to receive a response. This can be used to monitor the availability and performance of web services.

CONFIGURATION

The probe can be configured with the following options:

  • url: The URL to send the HTTPS request to. This is a mandatory parameter.
  • cert: Path to a client certificate file (PEM format). Optional.
  • key: Path to the private key file for the client certificate. Optional.
  • cafile: Path to a CA certificate bundle file. Optional.
  • method: The HTTP method to use (e.g., GET, POST). Defaults to GET.
  • post_data: Data to send with a POST request.
  • timeout: Connection timeout in seconds. Defaults to 10.

EXAMPLE

    + webserver
      menu = Web Servers
      host = www.example.com
      template = EchoPingHttps
      url = https://www.example.com/
      # Optional:
      # cert = /etc/ssl/certs/mycert.pem
      # key = /etc/ssl/private/mykey.pem
      # cafile = /etc/ssl/certs/ca-bundle.crt
      # method = POST
      # post_data = user=test&password=test
      # timeout = 5

DIAGNOSTICS

The probe will report the round trip time in milliseconds. If the request times out or fails, it will report a loss.

AUTHOR

This probe was written by the Smokeping community.

BUGS

Please report bugs to the Smokeping mailing list or issue tracker.

NOTES

This probe requires the Net::SSLeay Perl module to be installed.
