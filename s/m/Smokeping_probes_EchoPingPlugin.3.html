NOMBRE

Smokeping::probes::EchoPingPlugin - una base para usar plugins de echoping(1) como sondas para SmokePing

VISIÓN GENERAL

Mide los tiempos de ida y vuelta para SmokePing con un plugin de echoping(1). Los plugins actualmente distribuidos con echoping se implementan como sondas separadas basadas en esta clase, pero la clase también se puede usar directamente.

SINOPSIS

*** Sondas ***
+EchoPingPlugin
binary = /usr/bin/echoping
forks = 5
offset = 50%
step = 300
# Las siguientes variables se pueden sobrescribir en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
extraopts = -alguna-letra-en-la-que-el-autor-no-pensó
ipversion = 4
pings = 5
plugin = random # obligatorio
pluginargs = -p argumento_específico_del_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1
# [...]
*** Destinos ***
probe = EchoPingPlugin # si esta debe ser la sonda predeterminada
# [...]
+ mi_destino
# probe = EchoPingPlugin # si la sonda predeterminada es otra cosa
host = mi.host
/^influx_.+/ = influx_location = En el sótano
extraopts = -alguna-letra-en-la-que-el-autor-no-pensó
ipversion = 4
pings = 5
plugin = random # obligatorio
pluginargs = -p argumento_específico_del_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1

VARIABLES

Variables admitidas específicas de la sonda:

binary
La ubicación de su binario echoping.

Valor predeterminado: /usr/bin/echoping

forks
Ejecutar este número de procesos concurrentes como máximo

Valor de ejemplo: 5

Valor predeterminado: 5

offset
Si ejecuta muchas sondas concurrentemente, puede que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puede cambiar el momento en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Tenga en cuenta que esto NO influye en los RRD, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 50%

step
Duración del intervalo base que esta sonda debe usar, si es diferente del especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD es fijo cuando se generan originalmente, y si cambia el parámetro de paso después, deberá eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 300

Variables admitidas específicas del destino:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará con "tag_" en su lugar. Las etiquetas se pueden usar para filtrar.

Valor de ejemplo: influx_location = En el sótano

extraopts
Cualquier opción adicional especificada aquí se pasará sin modificaciones a echoping(1).

Valor de ejemplo: -alguna-letra-en-la-que-el-autor-no-pensó

ipversion
El protocolo IP utilizado. Los valores posibles son "4" y "6". Se pasa a echoping(1) como las opciones "-4" o "-6".

Valor de ejemplo: 4

pings
Cuántos pings se deben enviar a cada destino, si es diferente del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD es fijo cuando se generan originalmente, y si cambia este parámetro después, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 5

plugin
El plugin de echoping que se utilizará. Ver echoping(1) para más detalles. Puede ser el nombre del plugin o una ruta completa al objeto compartido del plugin.

Valor de ejemplo: random

Esta configuración es obligatoria.

pluginargs
Cualquier argumento adicional necesario para el plugin de echoping especificado con la variable pluginname. Estos son generalmente proporcionados por la subclase de sonda.

Valor de ejemplo: -p argumento_específico_del_plugin

priority
La opción "-p" de echoping(1).

Valor de ejemplo: 6

timeout
La opción "-t" de echoping(1).

Valor de ejemplo: 1

Valor predeterminado: 5

tos
La opción "-P" de echoping(1).

Valor de ejemplo: 0xa0

waittime
La opción "-w" de echoping(1).

Valor de ejemplo: 1

AUTORES

NOTAS

Las variables fill, size y udp de EchoPing no son válidas por defecto para las sondas derivadas de EchoPingPlugin.

Los plugins están disponibles a partir de la versión 6 de echoping.
