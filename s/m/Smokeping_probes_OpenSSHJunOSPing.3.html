NOMBRE

Smokeping::probes::OpenSSHJunOSPing - Sonda SSH de Juniper JunOS para SmokePing

SINOPSIS

*** Sondas ***
+OpenSSHJunOSPing
forks = 5
offset = 50%
packetsize = 100
step = 300
timeout = 15
tos = 
# Las siguientes variables se pueden anular en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
junospass = contraseña # obligatorio
junosuser = usuario # obligatorio
pings = 5
psource = 192.168.2.129
source = 192.168.2.1 # obligatorio
# [...]
*** Destinos ***
probe = OpenSSHJunOSPing # si esta debe ser la sonda predeterminada
# [...]
+ mi_destino
# probe = OpenSSHJunOSPing # si la sonda predeterminada es otra
host = mi.host
/^influx_.+/ = influx_location = En el sótano
junospass = contraseña # obligatorio
junosuser = usuario # obligatorio
pings = 5
psource = 192.168.2.129
source = 192.168.2.1 # obligatorio

DESCRIPCIÓN

Se conecta a Juniper JunOS a través de OpenSSH para ejecutar comandos de ping. Esta sonda utiliza el "ping extendido" de Juniper JunOS. Tiene la opción de especificar desde qué interfaz se originan los pings.

VARIABLES

Variables específicas de la sonda admitidas:

forks
Ejecutar este número de procesos concurrentes como máximo

Valor de ejemplo: 5

Valor predeterminado: 5

offset
Si ejecuta muchas sondas concurrentemente, es posible que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puede cambiar el punto en el tiempo en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Tenga en cuenta que esto NO influye en los RRD en sí, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 50%

packetsize
La opción (opcional) packetsize le permite configurar el tamaño del paquete para los pings enviados.

Valor predeterminado: 100

step
Duración del intervalo base que esta sonda debe usar, si es diferente del especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD se fija cuando se generan originalmente, y si cambia el parámetro de paso después, deberá eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 300

timeout
Cuánto tarda un 'ping' individual como máximo

Valor de ejemplo: 15

Valor predeterminado: 5

tos
La opción (opcional) de tipo de servicio para los pings enviados.

Variables específicas de destino admitidas:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará por "tag_". Las etiquetas se pueden usar para filtrar.

Valor de ejemplo: influx_location = En el sótano

junospass
La opción junospass le permite especificar la contraseña para el nombre de usuario especificado con la opción junosuser.

Valor de ejemplo: contraseña

Esta configuración es obligatoria.

junosuser
La opción junosuser le permite especificar un nombre de usuario que tenga capacidad de ping en el Dispositivo JunOS.

Valor de ejemplo: usuario

Esta configuración es obligatoria.

pings
Cuántos pings se enviarán a cada destino, si es diferente del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD se fija cuando se generan originalmente, y si cambia este parámetro después, deberá eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 5

psource
La opción (opcional) psource especifica una dirección IP o interfaz alternativa desde la cual desea originar sus pings. Los enrutadores pueden tener muchas direcciones IP e interfaces. Cuando haces ping desde un enrutador, tienes la capacidad de elegir desde qué interfaz y/o qué dirección IP se originan los pings. Especificar una IP/interfaz no especifica necesariamente la interfaz desde la cual saldrán los pings, sino que especifica de qué dirección parecerán provenir los paquetes. Si se omite esta opción, el Dispositivo JunOS originará el paquete automáticamente según el enrutamiento y/o las métricas. Si esto no tiene sentido para usted, simplemente omítalo.

Valor de ejemplo: 192.168.2.129

source
La opción source especifica el dispositivo JunOS que ejecutará los comandos de ping. Esta dirección se utilizará para la conexión ssh.

Valor de ejemplo: 192.168.2.1

Esta configuración es obligatoria.

NOTAS

Configuración de JunOS

El dispositivo JunOS debe tener un nombre de usuario/contraseña configurado, así como la capacidad de conectarse a los VTY.

Asegúrese de conectarse al host remoto una vez desde la línea de comandos como el usuario que está ejecutando smokeping. En la primera conexión, ssh le pedirá que agregue el nuevo host a su archivo known_hosts. Esto no sucederá automáticamente, por lo que el script fallará al iniciar sesión hasta que la clave ssh de su caja Juniper esté en el archivo known_hosts.

Algunos dispositivos JunOS tienen un máximo de 5 VTY disponibles, así que tenga cuidado de no alcanzar un límite con la variable 'forks'.

Requisitos

Este módulo requiere Net::OpenSSH y IO::Pty.
