NOMBRE

Smokeping::probes::skel - un esqueleto para las sondas de Smokeping

SINOPSIS

*** Probes ***
+skel
forks = 5
offset = 50%
step = 300
timeout = 15
# Las siguientes variables se pueden sobrescribir en cada sección de destino
/^influx_.+/ = influx_location = In the basement
pings = 5
# [...]
*** Targets ***
probe = skel # si esta debe ser la sonda predeterminada
# [...]
+ mytarget
# probe = skel # si la sonda predeterminada es otra
host = my.host
/^influx_.+/ = influx_location = In the basement
pings = 5

DESCRIPCIÓN

Este es un módulo no funcional que pretende servir de base para la creación de nuevas sondas. Consulte el documento smokeping_extend para obtener más información.

VARIABLES

Variables específicas de la sonda admitidas:

forks
Ejecutar este número de procesos concurrentes como máximo

Valor de ejemplo: 5

Valor predeterminado: 5

offset
Si ejecuta muchas sondas concurrentemente, es posible que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puede cambiar el momento en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Tenga en cuenta que esto NO influye en los archivos RRD, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 50%

step
Duración del intervalo base que esta sonda debe usar, si es diferente al especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD es fijo cuando se generan originalmente, y si cambia el parámetro de paso después, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 300

timeout
Cuánto tarda un solo 'ping' como máximo

Valor de ejemplo: 15

Valor predeterminado: 5

Variables específicas de destino admitidas:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará con "tag_" en su lugar. Las etiquetas se pueden usar para filtrar.

Valor de ejemplo: influx_location = In the basement

pings
Cuántos pings se deben enviar a cada destino, si es diferente del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD es fijo cuando se generan originalmente, y si cambia este parámetro después, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 5
