NOMBRE

Smokeping::probes::EchoPingLDAP - una sonda echoping(1) para SmokePing

DESCRIPCIÓN GENERAL

Mide los tiempos de ida y vuelta de LDAP para SmokePing con el plugin echoping_ldap.

SINOPSIS

*** Probes ***
+EchoPingLDAP
binary = /usr/bin/echoping
forks = 5
offset = 50%
step = 300
# Las siguientes variables pueden ser anuladas en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
extraopts = -alguna-letra-que-al-autor-no-se-le-ocurrio
ipversion = 4
ldap_base = dc=current,dc=bugs,dc=debian,dc=org
ldap_request = (objectclass=*)
ldap_scope = one
pings = 5
plugin = /ruta/a/ldap.so
pluginargs = -p argumento_especifico_del_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1
# [...]
*** Targets ***
probe = EchoPingLDAP # si esta debe ser la sonda predeterminada
# [...]
+ mi_objetivo
# probe = EchoPingLDAP # si la sonda predeterminada es otra
host = mi.host
/^influx_.+/ = influx_location = En el sótano
extraopts = -alguna-letra-que-al-autor-no-se-le-ocurrio
ipversion = 4
ldap_base = dc=current,dc=bugs,dc=debian,dc=org
ldap_request = (objectclass=*)
ldap_scope = one
pings = 5
plugin = /ruta/a/ldap.so
pluginargs = -p argumento_especifico_del_plugin
priority = 6
timeout = 1
tos = 0xa0
waittime = 1

VARIABLES

Variables específicas de la sonda admitidas:

binary
La ubicación de su ejecutable echoping.

Valor predeterminado: /usr/bin/echoping

forks
Ejecutar este número de procesos concurrentes como máximo

Valor de ejemplo: 5

Valor predeterminado: 5

offset
Si ejecuta muchas sondas concurrentemente, puede que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puede cambiar el punto en el tiempo en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Tenga en cuenta que esto NO influye en los archivos RRD, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 50%

step
Duración del intervalo base que esta sonda debe usar, si es diferente del especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD es fijo cuando se generan originalmente, y si cambia el parámetro de paso después, deberá eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 300

Variables específicas del destino admitidas:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que será reemplazado por "tag_" en su lugar. Las etiquetas se pueden usar para filtrar.

Valor de ejemplo: influx_location = En el sótano

extraopts
Cualquier opción adicional especificada aquí se pasará sin modificar a echoping(1).

Valor de ejemplo: -alguna-letra-que-al-autor-no-se-le-ocurrio

ipversion
El protocolo IP utilizado. Los valores posibles son "4" y "6". Se pasa a echoping(1) como las opciones "-4" o "-6".

Valor de ejemplo: 4

ldap_base
La opción '-b' de echoping_ldap: base de la búsqueda.

Valor de ejemplo: dc=current,dc=bugs,dc=debian,dc=org

ldap_request
La opción '-r' de echoping_ldap: la solicitud al servidor LDAP, en lenguaje de filtro LDAP.

Valor de ejemplo: (objectclass=*)

ldap_scope
La opción '-s' de echoping_ldap: alcance de la búsqueda, "sub", "one" o "base".

Valor de ejemplo: one

pings
Cuántos pings se deben enviar a cada destino, si es diferente del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD es fijo cuando se generan originalmente, y si cambia este parámetro después, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 5

plugin
El plugin de echoping que se utilizará. Consulte echoping(1) para obtener más detalles. Este puede ser el nombre del plugin o una ruta completa al objeto compartido del plugin.

Valor de ejemplo: /ruta/a/ldap.so

Valor predeterminado: ldap

pluginargs
Cualquier argumento adicional necesario para el plugin de echoping especificado con la variable pluginname. Estos son generalmente proporcionados por la sonda de clase derivada.

Valor de ejemplo: -p argumento_especifico_del_plugin

priority
La opción "-p" de echoping(1).

Valor de ejemplo: 6

timeout
La opción "-t" de echoping(1).

Valor de ejemplo: 1

Valor predeterminado: 5

tos
La opción "-P" de echoping(1).

Valor de ejemplo: 0xa0

waittime
La opción "-w" de echoping(1).

Valor de ejemplo: 1

AUTORES

Niko Tyni <ntyni@iki.fi>

NOTAS

Las variables fill, size y udp de EchoPing no son válidas.

Los plugins, incluido echoping_ldap, están disponibles a partir de la versión 6 de echoping.
