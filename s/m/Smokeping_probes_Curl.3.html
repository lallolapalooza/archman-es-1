NOMBRE

Smokeping::probes::Curl - una sonda curl(1) para SmokePing

DESCRIPCIÓN GENERAL

Obtiene una URL HTTP o HTTPS usando curl(1).

SINOPSIS

*** Sondas ***
+Curl
binary = /usr/bin/curl
forks = 5
offset = 50%
step = 300
# Las siguientes variables pueden ser anuladas en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
agent = User-Agent: Lynx/2.8.4rel.1 libwww-FM/2.14 SSL-MM/1.4.1 OpenSSL/0.9.6c
expect = Status: green
extraargs = -6 --head --user user:password
extrare = / /
follow_redirects = yes
include_redirects = yes
insecure_ssl = 1
interface = eth0
pings = 5
require_zero_status = yes
ssl2 = 1
timeout = 20
urlformat = http://%host%/ # obligatorio
# [...]
*** Destinos ***
probe = Curl # si esta debe ser la sonda predeterminada
# [...]
+ mi_destino
# probe = Curl # si la sonda predeterminada es otra
host = mi.host
/^influx_.+/ = influx_location = En el sótano
agent = User-Agent: Lynx/2.8.4rel.1 libwww-FM/2.14 SSL-MM/1.4.1 OpenSSL/0.9.6c
expect = Status: green
extraargs = -6 --head --user user:password
extrare = / /
follow_redirects = yes
include_redirects = yes
insecure_ssl = 1
interface = eth0
pings = 5
require_zero_status = yes
ssl2 = 1
timeout = 20
urlformat = http://%host%/ # obligatorio

DESCRIPCIÓN

(ver curl(1) para detalles de las opciones a continuación)

VARIABLES

Variables específicas de la sonda compatibles:

binary
La ubicación de tu binario de curl.

Valor predeterminado: /usr/bin/curl

forks
Ejecuta este número de procesos concurrentes como máximo.

Ejemplo de valor: 5

Valor predeterminado: 5

offset
Si ejecutas muchas sondas concurrentemente, puede que desees evitar que golpeen tu red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puedes cambiar el punto en el tiempo en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se usa el desplazamiento de la sección 'General' si no se especifica nada aquí. Ten en cuenta que esto NO influye en los rrds en sí, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Ejemplo de valor: 50%

step
Duración del intervalo base que esta sonda debería usar, si es diferente del especificado en la sección 'Database'. Ten en cuenta que el paso en los archivos RRD es fijo cuando se generan originalmente, y si cambias el parámetro de paso después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Ejemplo de valor: 300

Variables específicas del destino compatibles:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará con "tag_" en su lugar. Las etiquetas se pueden usar para filtrar.

Ejemplo de valor: influx_location = En el sótano

agent
La opción "-A" de curl(1). Esta es una cabecera completa de HTTP User-Agent que incluye las palabras "User-Agent:". Ten en cuenta que no necesita comillas alrededor.

Ejemplo de valor: User-Agent: Lynx/2.8.4rel.1 libwww-FM/2.14 SSL-MM/1.4.1 OpenSSL/0.9.6c

expect
Requiere que el texto dado aparezca en algún lugar de la respuesta, de lo contrario la sonda se tratará como un fallo.

Ejemplo de valor: Status: green

Valor predeterminado:

extraargs
Cualquier argumento adicional que quieras pasar a curl(1). Los argumentos deben estar separados por la expresión regular especificada en "extrare", que contiene solo el espacio en blanco (" ") por defecto.

Ten en cuenta que curl será llamado con la lista resultante de argumentos sin ninguna expansión de shell. Si necesitas especificar algún argumento que contenga espacios, deberías configurar "extrare" a algo diferente.

Como ejemplo complicado, para establecer explícitamente la cabecera "Host:" en las solicitudes de Curl, necesitas configurar "extrare" a algo diferente, por ejemplo, "/;/ ", y luego especificar "extraargs = --header;Host: www.example.com".

Ejemplo de valor: -6 --head --user user:password

extrare
La expresión regular utilizada para dividir la cadena extraargs en una lista de argumentos, en la notación "/regexp/". Por defecto, contiene solo el carácter de espacio (" "), pero si necesitas especificar algún argumento que contenga espacios, puedes establecer esta variable a un valor diferente.

Ejemplo de valor: / /

Valor predeterminado: / /

follow_redirects
Si esta variable se establece en 'yes', curl seguirá cualquier paso de redirección HTTP (la opción '-L'). Si se establece en 'no', las cabeceras HTTP Location: no se seguirán. Ver también 'include_redirects'.

Ejemplo de valor: yes

Valor predeterminado: no

include_redirects
Si esta variable se establece en 'yes', el resultado de la medición incluirá el tiempo dedicado a seguir cualquier paso de redirección HTTP. Si se establece en 'no', solo se medirá el último paso. Ver también 'follow_redirects'.

Ejemplo de valor: yes

Valor predeterminado: no

insecure_ssl
La opción "-k" de curl(1). Acepta conexiones SSL que no tienen una cadena de certificado segura a una CA de confianza. Ten en cuenta que si vas a monitorizar destinos https, probablemente tendrás que habilitar esta opción o especificar la ruta de la CA a curl a través de extraargs a continuación. Para más información, consulta la página del manual de curl(1).

Ejemplo de valor: 1

interface
La opción "--interface" de curl(1). Vincula a una interfaz, dirección IP o nombre de host específico.

Ejemplo de valor: eth0

pings
Cuántos pings se enviarán a cada destino, si es diferente del valor global especificado en la sección Database. Ten en cuenta que el número de pings en los archivos RRD es fijo cuando se generan originalmente, y si cambias este parámetro después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Ejemplo de valor: 5

require_zero_status
Si esta variable se establece en 'yes', las respuestas solo se contarán si el estado de salida de Curl es '0'. Esto es útil para reportar tiempos de espera como pérdidas en lugar de respuestas retrasadas.

Ejemplo de valor: yes

Valor predeterminado: no

ssl2
La opción "-2" de curl(1). Fuerza SSL2.

Ejemplo de valor: 1

timeout
La opción "-m" de curl(1). Tiempo máximo de espera en segundos.

Ejemplo de valor: 20

Valor predeterminado: 10

urlformat
La plantilla de la URL a obtener. Puede ser cualquiera que curl soporte. Cualquier ocurrencia de la cadena '%host%' será reemplazada con el host a sondear.

Ejemplo de valor: http://%host%/

Esta configuración es obligatoria.

NOTAS

Debería considerar establecer un valor más bajo para la variable "pings" que el valor predeterminado de 20, ya que la obtención repetitiva de URL puede ser bastante pesada para el servidor.

La URL a probar solía especificarse mediante la variable 'url' en versiones anteriores de Smokeping, y la configuración 'host' no la influía de ninguna manera. El nombre de la variable ahora ha cambiado a 'urlformat', y puede (y en la mayoría de los casos debería) contener un marcador de posición para la variable 'host'.
