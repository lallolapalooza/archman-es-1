NOMBRE

Smokeping::probes::FPingContinuous - Sonda FPingContinuous para SmokePing

SINOPSIS

*** Sondas ***
+FPingContinuous
binary = /usr/bin/fping # obligatorio
hostinterval = 1.5
offset = 50%
packetsize = 5000
pings = 20
sourceaddress = 192.168.0.1
step = 300
timeout = 1.5
tos = 0x20
usestdout = false
# Las siguientes variables se pueden anular en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
# [...]
*** Destinos ***
probe = FPingContinuous # si esta debe ser la sonda predeterminada
# [...]
+ mi_destino
# probe = FPingContinuous # si la sonda predeterminada es otra cosa
host = mi.host
/^influx_.+/ = influx_location = En el sótano

DESCRIPCIÓN

Integra FPingContinuous como una sonda en smokeping. La variable binary debe apuntar a su copia del programa FPing. Si aún no está instalado en su sistema, puede obtener una versión ligeramente mejorada de "pub" en www.smokeping.org.

La opción (opcional) packetsize le permite configurar el tamaño del paquete para los pings enviados.

La salida continua se envía normalmente a stdout, pero puede establecer usestdout en 'false' para que smokeping lea stderr en lugar de stdout.

El manual de FPing dice lo siguiente sobre este tema:

Número de bytes de datos de ping para enviar. El tamaño mínimo (normalmente 12) permite espacio para los datos que fping necesita para realizar su trabajo (número de secuencia, marca de tiempo). El tamaño de los datos recibidos informados incluye la cabecera IP (normalmente 20 bytes) y la cabecera ICMP (8 bytes), por lo que el tamaño total mínimo es de 40 bytes. El valor predeterminado es 56, como en ping. El máximo es el tamaño máximo teórico del datagrama IP (64K), aunque la mayoría de los sistemas lo limitan a un número más pequeño y dependiente del sistema.

VARIABLES

Variables específicas de la sonda admitidas:

binary
La ubicación de su binario fping.

Valor de ejemplo: /usr/bin/fping

Este ajuste es obligatorio.

hostinterval
El parámetro "-p" de fping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para coherencia con otras sondas de Smokeping. De fping(1):

Este parámetro establece el tiempo que fping espera entre paquetes sucesivos a un destino individual.

Valor de ejemplo: 1.5

offset
Si ejecuta muchas sondas concurrentemente, es posible que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda puede cambiar el punto en el tiempo en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Tenga en cuenta que esto NO influye en los propios RRD, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 50%

packetsize
El tamaño del paquete de ping (en el rango de 12-64000 bytes).

Valor de ejemplo: 5000

pings
Cuántos pings se deben enviar a cada destino, si es diferente del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD se fija cuando se generan originalmente y, si cambia este parámetro posteriormente, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 20

sourceaddress
El parámetro "-S" de fping. De fping(1):

Establecer dirección de origen.

Valor de ejemplo: 192.168.0.1

step
Duración del intervalo base que esta sonda debe usar, si es diferente del especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD se fija cuando se generan originalmente y, si cambia el parámetro de paso posteriormente, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 300

timeout
El parámetro "-t" de fping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para coherencia con otras sondas de Smokeping. Tenga en cuenta que, dado que Smokeping utiliza el modo de conteo de fping (-C), esto aparentemente solo afecta al último ping.

Valor de ejemplo: 1.5

tos
Establecer el tipo de servicio (TOS) de los paquetes ICMP salientes. Necesita al menos fping-2.4b2_to3-ipv6 para que esto funcione. Encuentre una copia en www.smokeping.org/pub.

Valor de ejemplo: 0x20

usestdout
Escuchar la salida de FPing en stdout en lugar de stderr... (la salida continua se envía normalmente a stdout).

Valor de ejemplo: false
