SMIME_WRITE_ASN1(3ssl) OpenSSL SMIME_WRITE_ASN1(3ssl)

NOMBRE

SMIME_write_ASN1_ex, SMIME_write_ASN1 - convertir estructura a formato S/MIME

SINOPSIS

#include <openssl/asn1.h>
int SMIME_write_ASN1_ex(BIO *out, ASN1_VALUE *val, BIO *data, int flags,
                        int ctype_nid, int econt_nid,
                        STACK_OF(X509_ALGOR) *mdalgs, const ASN1_ITEM *it,
                        OSSL_LIB_CTX *libctx, const char *propq);
int SMIME_write_ASN1(BIO *out,
    ASN1_VALUE *val, BIO *data, int flags, int ctype_nid, int econt_nid,
    STACK_OF(X509_ALGOR) *mdalgs, const ASN1_ITEM *it);

DESCRIPCIÓN

SMIME_write_ASN1_ex() añade las cabeceras MIME apropiadas a una estructura de objeto para producir un mensaje S/MIME.

out es el BIO al que se escribirán los datos. value es la estructura ASN1_VALUE apropiada (ya sea CMS_ContentInfo o PKCS7). Si se habilita el streaming, el contenido debe ser proporcionado a través de data. flags es un conjunto opcional de banderas. ctype_nid es el NID del tipo de contenido, econt_nid es el NID del tipo de contenido incrustado y mdalgs es una lista de digestAlgorithms de datos firmados. Los valores válidos que pueden ser utilizados por la estructura ASN.1 it son ASN1_ITEM_rptr(PKCS7) o ASN1_ITEM_rptr(CMS_ContentInfo). El contexto de biblioteca libctx y la consulta de propiedad propq se utilizan al recuperar algoritmos de los proveedores.

NOTAS

Las funciones de nivel superior SMIME_write_CMS(3) y SMIME_write_PKCS7(3) deben ser usadas en lugar de SMIME_write_ASN1().

Las siguientes banderas pueden ser pasadas en el parámetro flags.

Si se establece CMS_DETACHED, se utilizará la firma cleatexto, esta opción solo tiene sentido para SignedData donde CMS_DETACHED también se establece cuando se llama al método sign().

Si se establece la bandera CMS_TEXT, se añaden cabeceras MIME para el tipo text/plain al contenido, esto solo tiene sentido si CMS_DETACHED también está establecido.

Si se establece la bandera CMS_STREAM, se realiza el streaming. Esta bandera solo debe establecerse si CMS_STREAM también se estableció en la llamada anterior a una función de creación de CMS_ContentInfo o PKCS7.

Si se está utilizando la firma cleartexto y no se ha establecido CMS_STREAM, los datos deben leerse dos veces: una para calcular la firma en el método de firma y otra para generar el mensaje S/MIME.

Si se realiza streaming, el contenido se genera en formato BER utilizando codificación construida de longitud indefinida, excepto en el caso de datos firmados con contenido separado, donde el contenido está ausente y se utiliza el formato DER.

VALORES DE RETORNO

SMIME_write_ASN1_ex() y SMIME_write_ASN1() retornan 1 para éxito o 0 para fallo.

VER TAMBIÉN

ERR_get_error(3), SMIME_write_CMS(3), SMIME_write_PKCS7(3)
