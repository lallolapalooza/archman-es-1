NOMBRE

Smokeping::probes::FTPtransfer - sonda intrusiva de ancho de banda

DESCRIPCIÓN GENERAL

Esta sonda envía y recupera archivos hacia o desde un servidor ftp. Trazará el ancho de banda que pudo utilizar.

SINOPSIS

*** Sondas ***
+FTPtransfer
destfile = ruta/al/archivo_destino.xxx
forks = 5
min_interval = 1
mode = get # obligatorio
offset = 50%
passwordfile = /algún/lugar/secreto
srcfile = src/ruta/miarchivo_grande.pdf # obligatorio
step = 300
timeout = 15 # obligatorio
# Las siguientes variables pueden ser anuladas en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
localaddr = mi-host-interfaz-nat
passive = yes
password = clave-prueba
pings = 5
port = 3255
timeout = 10
username = usuario-prueba
# [...]
*** Destinos ***
probe = FTPtransfer # si esta debe ser la sonda por defecto
# [...]
+ mi_destino
# probe = FTPtransfer # si la sonda por defecto es otra
host = mi.servidor
/^influx_.+/ = influx_location = En el sótano
localaddr = mi-host-interfaz-nat
passive = yes
password = clave-prueba
pings = 5
port = 3255
timeout = 10
username = usuario-prueba

DESCRIPCIÓN

La sonda utiliza el cliente Perl Net::FTP para ejecutar pruebas de rendimiento utilizando un servidor FTP como objetivo. Esta sonda es intrusiva ya que transfiere datos reales. Al usar datos reales, obtenemos una buena oportunidad para determinar de qué es capaz un enlace en cuanto a la transferencia de archivos reales.

La contraseña se puede especificar ya sea (en orden de precedencia, con la última anulando la anterior) en la variable específica de la sonda `password', en un archivo externo o en la variable específica del destino `password'. La ubicación de este archivo externo se indica en la variable específica de la sonda `passwordfile'. Consulte Smokeping::probes::passwordchecker(3pm) para conocer el formato de este archivo (resumen: tríos separados por dos puntos de la forma `<host>:<username>:<password>')

La sonda intenta ser amable con el servidor y espera al menos X segundos entre el inicio de las transferencias de archivos, donde X es el valor de la variable específica de la sonda `min_interval' (1 por defecto).

Muchas variables se pueden especificar en la sonda o en la definición del destino; la variable específica del destino anulará la variable específica de la sonda.

Si su transferencia tarda mucho tiempo, es posible que desee asegurarse de configurar correctamente timeout y max_rtt para que smokeping no cancele las transferencias ni limite el tamaño del gráfico.

VARIABLES

Variables específicas de la sonda admitidas:

destfile
Normalmente, el nombre del archivo de destino es el mismo que el nombre del archivo de origen (sin la ruta). Si desea mantener archivos en diferentes directorios, esto puede no funcionar y tendrá que especificar `destfile' también.

Valor de ejemplo: ruta/al/archivo_destino.xxx

forks
Ejecutar este número de procesos concurrentes como máximo.

Valor de ejemplo: 5

Valor predeterminado: 5

min_interval
El intervalo mínimo entre cada sesión ftp iniciada en segundos.

Valor predeterminado: 1

mode
La sonda ftp puede estar en modo put o get. Si está en modo put, enviará un archivo al servidor ftp. En modo get, recuperará un archivo del servidor ftp.

Valor de ejemplo: get

Esta configuración es obligatoria.

offset
Si ejecuta muchas sondas concurrentemente, es posible que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puede cambiar el punto en el tiempo en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Tenga en cuenta que esto NO influye en los propios RRD, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 50%

passwordfile
Ubicación del archivo que contiene nombres de usuario y contraseñas.

Valor de ejemplo: /algún/lugar/secreto

srcfile
El nombre del archivo de origen. Si la sonda está en modo put, este archivo debe estar en la máquina local; si la sonda está en modo get, este archivo debe residir en la cuenta ftp remota.

Valor de ejemplo: src/ruta/miarchivo_grande.pdf

Esta configuración es obligatoria.

step
Duración del intervalo base que esta sonda debe utilizar, si es diferente del especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD se fija cuando se generan originalmente, y si cambia el parámetro `step' posteriormente, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Valor de ejemplo: 300

timeout
El tiempo de espera es la cantidad máxima de tiempo que permitirá que la sonda transfiera el archivo. Si la sonda no logra transferir en el tiempo especificado, se cancelará y se registrará una 'pérdida'.

Dado que FTPtransfer es una sonda invasiva, debe asegurarse de no cargar el enlace durante más de unos pocos segundos de todos modos. Smokeping actualmente tiene un límite estricto de 180 segundos para cualquier RTT.

Valor de ejemplo: 15

Esta configuración es obligatoria.

Variables específicas del destino admitidas:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará con "tag_". Las etiquetas se pueden utilizar para filtrar.

Valor de ejemplo: influx_location = En el sótano

localaddr
La dirección local que se utilizará al establecer conexiones.

Valor de ejemplo: mi-host-interfaz-nat

passive
Utilizar protocolo FTP pasivo.

Valor de ejemplo: yes

password
La contraseña del usuario, si no está presente en el archivo de contraseñas.

Valor de ejemplo: clave-prueba

pings
Cuántos pings se deben enviar a cada destino, si es diferente del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD se fija cuando se generan originalmente, y si cambia este parámetro posteriormente, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 5

port
Un puerto FTP no estándar que se utilizará.

Valor de ejemplo: 3255

timeout
Tiempo de espera en segundos para que se complete la transferencia FTP.

Valor de ejemplo: 10

username
El nombre de usuario que se probará.

Valor de ejemplo: usuario-prueba

ERRORES

Esta sonda tiene la capacidad de saturar sus enlaces, así que no la use a menos que sepa lo que está haciendo.

La sonda FTPtransfer mide el ancho de banda, pero informamos el número de segundos que tardó en transferir el archivo 'de referencia'. Esto es porque actualmente la noción de *tiempo de ida y vuelta* está en el núcleo de la aplicación. Se necesitaría una reingeniería para dividir esto en complementos y así hacerlo configurable ...
