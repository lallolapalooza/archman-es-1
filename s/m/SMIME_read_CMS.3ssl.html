SMIME_read_CMS(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SMIME_READ_CMS(3ssl) OpenSSL SMIME_READ_CMS(3ssl)

NOMBRE

SMIME_read_CMS_ex, SMIME_read_CMS - analizar mensaje S/MIME

SINOPSIS

#include <openssl/cms.h>
CMS_ContentInfo *SMIME_read_CMS_ex(BIO *bio, int flags, BIO **bcont,
                                   CMS_ContentInfo **cms);
CMS_ContentInfo *SMIME_read_CMS(BIO *in, BIO **bcont);

DESCRIPCIÓN

SMIME_read_CMS() analiza un mensaje en formato S/MIME.

in es un BIO para leer el mensaje.

Si se utiliza firma de texto plano (cleartext signing), el contenido se guarda en un bio de memoria que se escribe en *bcont, de lo contrario *bcont se establece a NULL.

Se devuelve la estructura CMS_ContentInfo analizada o NULL si ocurrió un error.

SMIME_read_CMS_ex() es similar a SMIME_read_CMS() pero opcionalmente se puede suministrar un objeto CMS_ContentInfo cms previamente creado, así como algunos flags. Para crear un objeto cms use CMS_ContentInfo_new_ex(3). Si el argumento flags contiene CMS_BINARY entonces se asume que la entrada está en formato binario y no se traduce a forma canónica. Si además se establece SMIME_ASCIICRLF entonces se asume que la entrada binaria va seguida de los caracteres CR y LF, de lo contrario solo por un carácter LF. Si flags es 0 y cms es NULL entonces es idéntico a SMIME_read_CMS().

NOTAS

Si *bcont no es NULL, entonces el mensaje está firmado con texto plano. *bcont puede entonces pasarse a CMS_verify() con la bandera CMS_DETACHED establecida.

De lo contrario, el tipo de la estructura devuelta se puede determinar usando CMS_get0_type().

Para soportar funcionalidad futura, si bcont no es NULL, *bcont debe inicializarse a NULL. Por ejemplo:

BIO *cont = NULL;
CMS_ContentInfo *cms;
cms = SMIME_read_CMS(in, &cont);

ERRORES

El analizador MIME utilizado por SMIME_read_CMS() es algo primitivo. Si bien manejará la mayoría de los mensajes S/MIME, los formatos compuestos más complejos pueden no funcionar.

El analizador asume que la estructura CMS_ContentInfo siempre está codificada en base64 y no manejará el caso en que esté en formato binario o utilice formato quoted-printable.

El uso de un bio de memoria para mantener el contenido firmado limita el tamaño del mensaje que se puede procesar debido a restricciones de memoria: debería haber disponible una opción de flujo de una sola pasada.

VALORES DE RETORNO

SMIME_read_CMS_ex() y SMIME_read_CMS() devuelven una estructura CMS_ContentInfo válida o NULL si ocurrió un error. El error se puede obtener de ERR_get_error(3).

VER TAMBIÉN

ERR_get_error(3), CMS_sign(3), CMS_verify(3), CMS_encrypt(3), CMS_decrypt(3)

HISTORIA

La función SMIME_read_CMS_ex() se añadió en OpenSSL 3.0.
