NOMBRE

Smokeping::probes::NFSping - Sonda NFSping para SmokePing

SINOPSIS

*** Sondas ***
+NFSping
binary = /usr/local/bin/nfsping # obligatorio
blazemode = true
hostinterval = 1.5
mininterval = 0.001
offset = 50%
pings = 20
step = 300
tcp = true
timeout = 1.5
# Las siguientes variables se pueden anular en cada sección de destino
/^influx_.+/ = influx_location = En el sótano
# [...]
*** Destinos ***
probe = NFSping # si esta debe ser la sonda por defecto
# [...]
+ mi_destino
# probe = NFSping # si la sonda por defecto es otra
host = mi.host
/^influx_.+/ = influx_location = En el sótano

DESCRIPCIÓN

Integra NFSping como una sonda en smokeping. La variable binary debe apuntar a tu copia del programa NFSping.

NFSping se puede descargar desde:

https://github.com/mprovost/NFSping

En el modo blazemode, NFSping envía un ping adicional al solicitado y descarta el primer valor RTT devuelto, ya que es probable que sea un valor atípico.

VARIABLES

Variables específicas de la sonda admitidas:

binary
La ubicación de tu binario de nfsping.

Valor de ejemplo: /usr/local/bin/nfsping

Esta configuración es obligatoria.

blazemode
Envía un ping adicional y luego descarta la primera respuesta, ya que la primera está obligada a ser un valor atípico.

Valor de ejemplo: true

hostinterval
El parámetro "-p" de nfsping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping. Este parámetro establece el tiempo que nfsping espera entre paquetes sucesivos a un objetivo individual.

Valor de ejemplo: 1.5

mininterval
El parámetro "-i" de nfsping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping. Este es el intervalo entre pings a objetivos sucesivos.

Valor de ejemplo: 0.001

Valor por defecto: 0.01

offset
Si ejecutas muchas sondas concurrentemente, es posible que desees evitar que golpeen tu red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda puedes cambiar el momento en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Ten en cuenta que esto NO influye en los rrds mismos, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 50%

pings
Cuántos pings se deben enviar a cada destino, si es diferente del valor global especificado en la sección Database. Ten en cuenta que el número de pings en los archivos RRD se fija cuando se generan originalmente, y si cambias este parámetro después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 20

step
Duración del intervalo base que esta sonda debe utilizar, si es diferente del especificado en la sección 'Database'. Ten en cuenta que el paso en los archivos RRD se fija cuando se generan originalmente, y si cambias el parámetro de paso después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 300

tcp
Usar TCP en lugar de UDP.

Valor de ejemplo: true

timeout
El parámetro "-t" de nfsping, pero en segundos (posiblemente fraccionarios) en lugar de milisegundos, para consistencia con otras sondas de Smokeping.

Valor de ejemplo: 1.5
