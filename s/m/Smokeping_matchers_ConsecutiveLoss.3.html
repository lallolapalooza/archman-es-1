NOMBRE

Smokeping::matchers::ConsecutiveLoss - Genera/cierra alertas según tu elección de umbral y valores consecutivos

DESCRIPCIÓN

Usa este comparador para generar y cerrar alertas según tu elección de umbral y valores consecutivos. Por ejemplo, puedes generar una alerta ante la primera ocurrencia de un 50% de pérdida de paquetes, pero optar por mantener la alerta activa hasta que la pérdida de paquetes se mantenga por debajo del 10% durante 5 mediciones consecutivas.

Añade el comparador a tu archivo de configuración usando la siguiente sintaxis:

type = matcher
edgetrigger = yes
pattern =  ConsecutiveLoss(pctlossraise=>##,stepsraise=>##,pctlossclear=>##,stepsclear=>##)

Reemplaza los ## con enteros de tu elección, ver abajo para referencia:

pctlossraise - Los valores de pérdida iguales o superiores a este porcentaje generarán una alerta cuando... stepsraise - ... se hayan recogido el número de valores consecutivos

pctlossclear - Los valores de pérdida inferiores a este porcentaje borrarán una alerta cuando... stepsclear - ... se hayan recogido el número de valores consecutivos

En mi entorno, defino cuatro alertas para niveles como:

+packetloss_significant_instantalert
type = matcher
pattern = ConsecutiveLoss(pctlossraise=>10,stepsraise=>1,pctlossclear=>3,stepsclear=>3)
comment = Alerta instantánea: se detectó pérdida de paquetes significativa (Al menos 10% en 1 ciclo). La alerta se borrará cuando la pérdida se mantenga en un máximo del 2% durante 3 ciclos.
priority = 30
+packetloss_major_instantalert
type = matcher
pattern = ConsecutiveLoss(pctlossraise=>25,stepsraise=>1,pctlossclear=>3,stepsclear=>3)
comment = Alerta instantánea: se detectó pérdida de paquetes importante (Al menos 25% en 1 ciclo). La alerta se borrará cuando la pérdida se mantenga en un máximo del 2% durante 3 ciclos.
priority = 20
+packetloss_significant_consecutivealert
type = matcher
pattern = ConsecutiveLoss(pctlossraise=>10,stepsraise=>3,pctlossclear=>3,stepsclear=>5)
comment = Se detectó ocurrencia consecutiva de pérdida de paquetes significativa (Al menos 10% en 3 ciclos). La alerta se borrará cuando la pérdida se mantenga en un máximo del 2% durante 5 ciclos.
priority = 10
+packetloss_major_consecutivealert
type = matcher
pattern = ConsecutiveLoss(pctlossraise=>25,stepsraise=>3,pctlossclear=>3,stepsclear=>5)
comment = Se detectó ocurrencia consecutiva de pérdida de paquetes importante (Al menos 25% en 3 ciclos). La alerta se borrará cuando la pérdida se mantenga en un máximo del 2% durante 5 ciclos.
priority = 5
