Paquete: openssl

SMIME_READ_PKCS7(3ssl) OpenSSL SMIME_READ_PKCS7(3ssl)

NOMBRE

SMIME_read_PKCS7_ex, SMIME_read_PKCS7 - analizar mensaje S/MIME

SINOPSIS

#include <openssl/pkcs7.h>
PKCS7 *SMIME_read_PKCS7_ex(BIO *bio, BIO **bcont, PKCS7 **p7);
PKCS7 *SMIME_read_PKCS7(BIO *in, BIO **bcont);

DESCRIPCIÓN

SMIME_read_PKCS7() analiza un mensaje en formato S/MIME.

in es un BIO para leer el mensaje desde.

Si se utiliza firma de texto plano, el contenido se guarda en un BIO de memoria que se escribe en *bcont; de lo contrario, *bcont se establece a NULL.

Se devuelve la estructura PKCS#7 analizada o NULL si ocurrió un error.

SMIME_read_PKCS7_ex() es similar a SMIME_read_PKCS7() pero puede proporcionar opcionalmente un objeto PKCS7 p7 creado previamente. Si p7 es NULL, es idéntico a SMIME_read_PKCS7(). Para crear un objeto p7, use PKCS7_new_ex(3).

NOTAS

Si *bcont no es NULL, el mensaje está firmado con texto plano. *bcont puede pasarse a PKCS7_verify() con la bandera PKCS7_DETACHED establecida.

De lo contrario, el tipo de la estructura devuelta se puede determinar usando PKCS7_type_is_enveloped(), etc.

Para admitir funcionalidades futuras, si bcont no es NULL, *bcont debe inicializarse a NULL. Por ejemplo:

BIO *cont = NULL;
PKCS7 *p7;
p7 = SMIME_read_PKCS7(in, &cont);

ERRORES

El analizador MIME utilizado por SMIME_read_PKCS7() es algo primitivo. Aunque manejará la mayoría de los mensajes S/MIME, es posible que formatos compuestos más complejos no funcionen.

El analizador asume que la estructura PKCS7 siempre está codificada en base64 y no manejará el caso en que esté en formato binario o use formato quoted printable.

El uso de un BIO de memoria para contener el contenido firmado limita el tamaño del mensaje que se puede procesar debido a restricciones de memoria: debería haber una opción de transmisión de una sola pasada disponible.

VALORES DE RETORNO

SMIME_read_PKCS7_ex() y SMIME_read_PKCS7() devuelven una estructura PKCS7 válida o NULL si ocurrió un error. El error se puede obtener de ERR_get_error(3).

VER TAMBIÉN

ERR_get_error(3), SMIME_read_PKCS7(3), PKCS7_sign(3), PKCS7_verify(3), PKCS7_encrypt(3) PKCS7_decrypt(3)

HISTORIA

La función SMIME_read_PKCS7_ex() se agregó en OpenSSL 3.0.
