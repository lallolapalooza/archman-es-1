NOMBRE

Smokeping::probes::basevars - Otra clase base para implementar sondas de SmokePing

RESUMEN

*** Probes ***
+basevars
offset = 50%
pings = 20
step = 300
# Las siguientes variables se pueden sobrescribir en cada sección de destino
/^influx_.+/ = influx_location = In the basement
# [...]
*** Targets ***
probe = basevars # si esta debe ser la sonda predeterminada
# [...]
+ mytarget
# probe = basevars # si la sonda predeterminada es otra
host = my.host
/^influx_.+/ = influx_location = In the basement

DESCRIPCIÓN

Proporciona el método `targets' que devuelve una lista de hashes. Los hashes contienen las entradas:

addr
La dirección del objetivo.
vars
Un hash que contiene las variables definidas en la sección de configuración correspondiente.
tree
El índice único que `probe::base' utiliza para los objetivos.

También existe el método 'vars' que devuelve el hash mencionado anteriormente correspondiente al parámetro de índice 'tree'.

VARIABLES

Variables específicas de sonda admitidas:

offset
Si ejecuta muchas sondas simultáneamente, es posible que desee evitar que golpeen su red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda, puede cambiar el punto en el tiempo en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'aleatorio', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Tenga en cuenta que esto NO influye en los rrds en sí, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Ejemplo de valor: 50%

pings
Cuántos pings se enviarán a cada objetivo, si son diferentes del valor global especificado en la sección Database. Tenga en cuenta que el número de pings en los archivos RRD se fija cuando se generan originalmente, y si cambia este parámetro después, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Ejemplo de valor: 20

step
Duración del intervalo base que debe usar esta sonda, si es diferente al especificado en la sección 'Database'. Tenga en cuenta que el paso en los archivos RRD se fija cuando se generan originalmente, y si cambia el parámetro de paso después, tendrá que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está configurada en la sección 'General'.)

Ejemplo de valor: 300
