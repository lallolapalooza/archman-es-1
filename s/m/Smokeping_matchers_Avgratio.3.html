NOMBRE

Smokeping::matchers::Avgratio - detectar cambios en la latencia media

DESCRIPCIÓN GENERAL

El comparador Avgratio establece una latencia media histórica durante varias rondas de medición. Compara esta media con un segundo valor de latencia media, también construido a lo largo de varias rondas de medición.

DESCRIPCIÓN

Llame al comparador con la siguiente secuencia:

type = matcher
pattern =  Avgratio(historic=>a,current=>b,comparator=>o,percentage=>p)
historic
El número de valores de media a utilizar para construir el promedio 'histórico'.
current
El número de valores de media a utilizar para construir el promedio 'actual'.
comparator
Qué operador de comparación se debe utilizar para comparar el valor actual/histórico con el porcentaje.
percentage
Lado derecho de la comparación.
antiguo <--- histórico ---><--- actual ---> ahora

EJEMPLO

Construir el promedio de la latencia media durante 10 muestras, usar esto para dividir la latencia media actual construida sobre 2 muestras y comprobar si es mayor que el 150%.

Avgratio(historic=>10,current=>2,comparator=>'>',percentage=>150);
avg(current)/avg(historic) > 150/100

Esto significa que el comparador se activará cuando el promedio de latencia actual sea más de 1,5 veces el promedio de latencia histórico establecido durante las últimas 10 rondas de medición.
