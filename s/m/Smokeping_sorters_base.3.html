NOMBRE

Smokeping::sorters::base - Clase base para implementar Sorters de SmokePing

DESCRIPCIÓN GENERAL

Los Sorters (clasificadores) están en el núcleo de la función de Gráficos de SmokePing, donde se presentan los gráficos más interesantes en una sola página. El Sorter decide qué gráficos se consideran interesantes.

Cada sorter debe heredar de la clase base y proporcionar sus propios métodos para la lógica de 'negocio'.

Para mantener un rendimiento decente, la actividad de los sorters se divide en dos partes.

La primera parte está activa mientras el demonio smokeping recopila sus datos. Cada vez que se reciben datos, se llama al sorter para calcular un 'valor' para los datos presentes. En cada 'ronda de consulta', esta información se almacena en el directorio de almacenamiento del sorter. Cada proceso de smokeping almacena su propia información. Dado que smokeping puede ejecutarse en múltiples instancias al mismo tiempo, los datos pueden dividirse en varios archivos.

La segunda parte del sorter es llamada desde smokeping.cgi. Carga toda la información del almacenamiento del sorter y la integra en un único 'árbol'. Luego llama a cada sorter con los datos precalculados para que se ordenen y se seleccione la información interesante.

DESCRIPCIÓN

Cada sorter debe proporcionar los siguientes métodos:

new

El método new espera elementos hash como argumento, por ejemplo new({x=>'\d+',y=>'\d+'},x=>1,y=>2). La primera parte es una regla de sintaxis para los argumentos que debe esperar y la segunda parte son los argumentos en sí. La primera parte será proporcionada por la clase hija al llamar al método padre.

Desc

Simplemente devuelve la descripción de la función. Este método debe ser sobrescrito por las clases hijas de la clase base.

SortTree

Devuelve una matriz de 'objetivos' (targets). Depende del sorter decidir cuántas entradas debe contener la lista. Si la lista está vacía, la entrada completa se suprimirá en la interfaz web.

El método obtiene acceso a todos los objetivos del sistema, junto con el último conjunto de datos adquirido para cada objetivo.

CalcValues

Calcula el valor de ordenación actual utilizando la siguiente entrada.

$info = { uptime => w,
          loss   => x,
          median => y,
          alert  => z, # (0/1)
          pings  => [qw(a b c d)] }

La salida puede tener cualquier estructura que desees. Se devolverá al método sorter para su posterior procesamiento.
