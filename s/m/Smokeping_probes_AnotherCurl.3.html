NOMBRE

Smokeping::probes::AnotherCurl - una sonda curl(1) para SmokePing

DESCRIPCIÓN GENERAL

Obtiene una URL HTTP o HTTPS usando curl(1).

SINOPSIS

*** Sondas ***
+AnotherCurl
binary = /usr/bin/curl
forks = 5
offset = 50%
step = 300
# Las siguientes variables se pueden anular en cada sección de objetivo
/^influx_.+/ = influx_location = En el sótano
agent = User-Agent: Lynx/2.8.4rel.1 libwww-FM/2.14 SSL-MM/1.4.1 OpenSSL/0.9.6c
extraargs = -6 --head --user user:password
extrare = / /
follow_redirects = yes
include_redirects = yes
insecure_ssl = 1
interface = eth0
pings = 5
ssl2 = 1
timeout = 20
urlformat = http://%host%/ # obligatorio
write_out = 
# [...]
*** Objetivos ***
probe = AnotherCurl # si esta debe ser la sonda por defecto
# [...]
+ mytarget
# probe = AnotherCurl # si la sonda por defecto es otra
host = my.host
/^influx_.+/ = influx_location = En el sótano
agent = User-Agent: Lynx/2.8.4rel.1 libwww-FM/2.14 SSL-MM/1.4.1 OpenSSL/0.9.6c
extraargs = -6 --head --user user:password
extrare = / /
follow_redirects = yes
include_redirects = yes
insecure_ssl = 1
interface = eth0
pings = 5
ssl2 = 1
timeout = 20
urlformat = http://%host%/ # obligatorio
write_out =

DESCRIPCIÓN

(ver curl(1) para detalles de las opciones a continuación)

VARIABLES

Variables específicas de sonda soportadas:

binary
La ubicación de tu binario curl.

Valor por defecto: /usr/bin/curl

forks
Ejecutar este número de procesos concurrentes como máximo

Valor de ejemplo: 5

Valor por defecto: 5

offset
Si ejecutas muchas sondas concurrentemente, es posible que quieras evitar que golpeen tu red al mismo tiempo. Usando el parámetro de desplazamiento específico de la sonda puedes cambiar el momento en que se ejecutará cada sonda. El desplazamiento se especifica en % del intervalo total, o alternativamente como 'random', y se utiliza el desplazamiento de la sección 'General' si no se especifica nada aquí. Ten en cuenta que esto NO influye en los propios rrds, es solo una cuestión de cuándo se inicia la adquisición de datos. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 50%

step
Duración del intervalo base que esta sonda debe usar, si es diferente del especificado en la sección 'Database'. Ten en cuenta que el paso en los archivos RRD se fija cuando se generan originalmente, y si cambias el parámetro step después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera. (Esta variable solo es aplicable si la variable 'concurrentprobes' está establecida en la sección 'General'.)

Valor de ejemplo: 300

Variables específicas de objetivo soportadas:

/^influx_.+/
Esta es una etiqueta que se enviará a influxdb y no tiene impacto en la medición de la sonda. El nombre de la etiqueta se enviará sin el prefijo "influx_", que se reemplazará con "tag_" en su lugar. Las etiquetas se pueden usar para filtrar.

Valor de ejemplo: influx_location = En el sótano

agent
La opción "-A" de curl(1). Esta es una cabecera HTTP User-Agent completa que incluye las palabras "User-Agent:". Ten en cuenta que no necesita comillas alrededor.

Valor de ejemplo: User-Agent: Lynx/2.8.4rel.1 libwww-FM/2.14 SSL-MM/1.4.1 OpenSSL/0.9.6c

extraargs
Cualquier argumento adicional que quieras pasar a curl(1). Los argumentos deben estar separados por la expresión regular especificada en "extrare", que por defecto solo contiene el carácter de espacio (" ").

Ten en cuenta que curl se llamará con la lista de argumentos resultante sin ninguna expansión de shell. Si necesitas especificar algún argumento que contenga espacios, deberías establecer "extrare" a algo diferente.

Como ejemplo complicado, para establecer explícitamente la cabecera "Host:" en las solicitudes de Curl, necesitas establecer "extrare" a algo diferente, por ejemplo, "/;/ ", y luego especificar "extraargs = --header;Host: www.example.com".

Valor de ejemplo: -6 --head --user user:password

extrare
La expresión regular utilizada para dividir la cadena extraargs en una lista de argumentos, en la notación "/regexp/". Por defecto, contiene solo el carácter de espacio (" "), pero si necesitas especificar algún argumento que contenga espacios, puedes establecer esta variable a un valor diferente.

Valor de ejemplo: / /

Valor por defecto: / /

follow_redirects
Si esta variable se establece en 'yes', curl seguirá cualquier paso de redirección HTTP (la opción '-L'). Si se establece en 'no', las cabeceras HTTP Location: no se seguirán. Ver también 'include_redirects'.

Valor de ejemplo: yes

Valor por defecto: no

include_redirects
Si esta variable se establece en 'yes', el resultado de la medición incluirá el tiempo dedicado a seguir cualquier paso de redirección HTTP. Si se establece en 'no', solo se medirá el último paso. Ver también 'follow_redirects'.

Valor de ejemplo: yes

Valor por defecto: no

insecure_ssl
La opción "-k" de curl(1). Acepta conexiones SSL que no tengan una cadena de certificado segura a una CA de confianza. Ten en cuenta que si vas a monitorizar objetivos https, probablemente tendrás que habilitar esta opción o especificar la ruta de la CA a curl a través de extraargs a continuación. Para más información, consulta la página del manual de curl(1).

Valor de ejemplo: 1

interface
La opción "--interface" de curl(1). Vincula a una interfaz, dirección IP o nombre de host específico.

Valor de ejemplo: eth0

pings
Cuántos pings se enviarán a cada objetivo, si es diferente del valor global especificado en la sección Database. Ten en cuenta que el número de pings en los archivos RRD se fija cuando se generan originalmente, y si cambias este parámetro después, tendrás que eliminar los archivos RRD antiguos o convertirlos de alguna manera.

Valor de ejemplo: 5

ssl2
La opción "-2" de curl(1). Fuerza SSL2.

Valor de ejemplo: 1

timeout
La opción "-m" de curl(1). Tiempo máximo de espera en segundos.

Valor de ejemplo: 20

Valor por defecto: 10

urlformat
La plantilla de la URL a obtener. Puede ser cualquiera que curl soporte. Cualquier ocurrencia de la cadena '%host%' será reemplazada con el host a sondear.

Valor de ejemplo: http://%host%/

Esta configuración es obligatoria.

write_out
Elige qué valor de salida quieres enviar a Smokeping. El valor puede ser uno de: 'time_appconnect', 'time_connect', 'time_namelookup', 'time_pretransfer', 'time_redirect', 'time_starttransfer', 'time_total'.

El comportamiento por defecto es el mismo que el de la sonda Curl heredada.

Smokeping::probes::AnotherCurl(3pm)

NAME

Smokeping::probes::AnotherCurl - A probe that uses curl to fetch a web page

OVERVIEW

This probe uses the curl(1) program to fetch a web page. It is useful for checking the availability and response time of web servers.

SYNOPSIS

This is a Smokeping probe. See Smokeping_config(5) for configuration details.

    @target = (
        {
            #
            # Probe using a real URL:
            #
            'url' => 'http://example.com/',
            'title' => 'Example.com',
        },
        {
            #
            # Probe using a URL format:
            #
            'urlformat' => 'http://%s/',
            'title' => 'Example.com (via format)',
        },
    );

DESCRIPTION

The AnotherCurl probe uses the external curl(1) program to access a given URL. It measures the time it takes to establish a connection, to send the request, and to receive the first byte of the response.

The probe is configured using the url or urlformat parameters. If url is used, it specifies the exact URL to fetch. If urlformat is used, it specifies a URL pattern that will be filled in using the host variable from the target configuration.

For example, if urlformat is set to http://%s/ and the host is www.example.com, the probe will fetch http://www.example.com/.

VARIABLES

In addition to the standard probe variables, AnotherCurl supports the following:

url
The URL to be fetched. This is mutually exclusive with urlformat.
urlformat
A format string for the URL. This string can contain placeholders for variables such as %s (for the host) or %H (for the full host name including port).
curl_options
A string containing additional options to pass to the curl(1) program. This can be used to specify things like proxy settings, user agent, etc. For example:

curl_options = "-A 'MyProbe/1.0' --proxy http://proxy.example.com/"

write_out
Specifies which value to return from curl(1). Defaults to time_total. Other options include time_connect, time_starttransfer, size_download, etc. Refer to curl(1) for a full list of options.

The url variable has been deprecated in favor of urlformat. In earlier versions of Smokeping, url was used directly, and the host setting had no influence. The urlformat variable allows the host variable to be incorporated into the URL, which is the preferred method.

The legacy Curl probe only returned the page load time. With AnotherCurl, you can specify which 'write-out' value you want to retrieve (refer to curl(1) for more details about the write_out option).

AUTHORS

Philip St. George and T. G. Schutt.

NOTES

This probe can be quite resource-intensive on the server.

The URL to be tested used to be specified by the variable 'url' in earlier versions of Smokeping, and the 'host' setting did not influence it in any way. The variable name has now been changed to 'urlformat', and it can (and in most cases should) contain a placeholder for the 'host' variable.

Legacy Curl probe only returns page load time. With AnotherCurl, you can specify which 'write-out' value you want to get (please refer to curl(1) for more details about write_out option.

SEE ALSO

curl(1), http://curl.haxx.se/
