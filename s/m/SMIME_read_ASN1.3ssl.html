NOMBRE

SMIME_read_ASN1_ex, SMIME_read_ASN1 - analizar mensaje S/MIME

SINOPSIS

#include <openssl/asn1.h>
ASN1_VALUE *SMIME_read_ASN1_ex(BIO *in, int flags, BIO **bcont,
                               const ASN1_ITEM *it, ASN1_VALUE **x,
                               OSSL_LIB_CTX *libctx, const char *propq);
ASN1_VALUE *SMIME_read_ASN1(BIO *in, BIO **bcont, const ASN1_ITEM *it);

DESCRIPCIÓN

SMIME_read_ASN1_ex() analiza un mensaje en formato S/MIME.

in es un BIO para leer el mensaje. Si el argumento flags contiene CMS_BINARY, entonces la entrada se asume en formato binario y no se traduce a forma canónica. Si además se establece SMIME_ASCIICRLF, entonces se asume que la entrada binaria está seguida por los caracteres CR y LF, de lo contrario, solo por un carácter LF. x se puede usar para suministrar opcionalmente un objeto ASN1_VALUE it creado previamente (como CMS_ContentInfo o PKCS7), puede ser NULL. Los valores válidos que se pueden usar por la estructura ASN.1 it son ASN1_ITEM_rptr(PKCS7) o ASN1_ITEM_rptr(CMS_ContentInfo). Cualquier búsqueda de algoritmo que ocurra durante la operación utilizará el **OSSL_LIB_CTX** suministrado en el parámetro libctx, y usará la cadena de consulta de propiedad propq. Consulte "Búsqueda de algoritmos" en crypto(7) para más detalles sobre la búsqueda de algoritmos.

Si se utiliza firma de texto plano, el contenido se guarda en un bio de memoria que se escribe en *bcont, de lo contrario, *bcont se establece en NULL.

La estructura ASN1_VALUE analizada se devuelve o NULL si ocurrió un error.

SMIME_read_ASN1() es similar a SMIME_read_ASN1_ex() pero establece el valor de x a NULL y el valor de flags a 0.

NOTAS

Las funciones de nivel superior SMIME_read_CMS_ex(3) y SMIME_read_PKCS7_ex(3) deberían usarse en lugar de SMIME_read_ASN1_ex().

Para admitir funcionalidad futura si bcont no es NULL, *bcont debe inicializarse a NULL.

ERRORES

El analizador MIME utilizado por SMIME_read_ASN1_ex() es algo primitivo. Si bien manejará la mayoría de los mensajes S/MIME, los formatos compuestos más complejos pueden no funcionar.

El uso de un bio de memoria para mantener el contenido firmado limita el tamaño del mensaje que se puede procesar debido a restricciones de memoria: debería estar disponible una opción de transmisión de una sola pasada.

VALORES DE RETORNO

SMIME_read_ASN1_ex() y SMIME_read_ASN1() devuelven una estructura ASN1_VALUE válida o NULL si ocurrió un error. El error se puede obtener de ERR_get_error(3).

VER TAMBIÉN

ERR_get_error(3), SMIME_read_CMS_ex(3), SMIME_read_PKCS7_ex(3), SMIME_write_ASN1(3), SMIME_write_ASN1_ex(3)

HISTORIA

La función SMIME_read_ASN1_ex() se añadió en OpenSSL 3.0.
