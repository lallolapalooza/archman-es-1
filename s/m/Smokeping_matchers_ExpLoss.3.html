NOMBRE

Smokeping::matchers::ExpLoss - un comparador de ponderación exponencial para la pérdida de paquetes con umbrales similares a RMON

DESCRIPCIÓN

Compara con el promedio ponderado exponencialmente de las últimas muestras, de modo que los valores nuevos son más valiosos que los antiguos. Dos umbrales, uno ascendente y otro descendente, producen un bucle de histéresis como en el subsistema de alertas RMON. Si el promedio alcanza el umbral "ascendente", el comparador pasa al estado "coincide" y lo mantiene hasta que el promedio cae por debajo del umbral "descendente".

Llama al comparador con la siguiente secuencia:

type = matcher
pattern = ExpLoss(hist => <hist>, rising=><rising> \
                 [,falling => <falling>] [,skip=><stat>] [,fast=><fast>])

Argumentos:
hist - número de muestras para ponderar; el peso se disminuirá
exponencialmente desde el más nuevo al más antiguo, de modo que la
muestra más antigua tenga un 1% de significancia;
rising - umbral ascendente para la pérdida de paquetes, 0-100%
falling - umbral descendente para la pérdida de paquetes, por defecto es <rising>
skip - omite <skip> número de muestras después del inicio antes de disparar alertas.
fast - usa <fast> muestras para una transición rápida: si los valores de las últimas
<fast> muestras son mayores que <rising>, toma el estado "coincide", si son menores que
<falling>, toma el estado "no coincide".

Nota:
Si el historial real es menor que el valor <hist>, entonces este valor se toma
como el historial real.
