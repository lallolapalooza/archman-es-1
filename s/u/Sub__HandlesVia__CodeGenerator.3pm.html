Sub::HandlesVia::CodeGenerator(3) Documentación de Perl contribuida por el usuario Sub::HandlesVia::CodeGenerator(3)

NOMBRE

Sub::HandlesVia::CodeGenerator - examina un Handler y genera una cadena de código Perl para él

DESCRIPCIÓN

Este módulo es parte de la API interna de Sub::HandlesVia. Interesa principalmente a las personas que extienden Sub::HandlesVia.

Los toolkits de Sub::HandlesVia crean un generador de código para cada atributo con el que están tratando, y usan el generador de código para generar código Perl para uno o más métodos delegados.

CONSTRUCTORES

new( %attributes )

Constructor estándar similar a Moose.

ATRIBUTOS

"toolkit" Objeto

El toolkit que creó este generador de código.

"target" NombreClase|NombreRol

El paquete de destino para los métodos generados.

"sandboxing_package" NombreClase|NombreRol|Undef

Nombre del paquete a utilizar como sandbox; el valor predeterminado suele estar bien.

"attribute" Str|ArrayRef

El atributo delegado.

"attribute_spec" HashRef

Solo informativo.

"is_method" Bool

Indica si el código generado debe ser métodos en lugar de funciones. Esto tiene un valor predeterminado de verdadero, y falso no está realmente probado ni bien definido.

"env" HashRef

Variables que necesitan ser cerradas al compilar coderefs.

"isa" Quizás[TypeTiny]

La restricción de tipo para el atributo.

"coerce" Bool

¿Debería el atributo hacer coerciones?

"method_installer" CodeRef

Un coderef que puede ser llamado con $nombre_metodo y $coderef, e instalará el método. Nótese que no se le pasa el paquete en el que instalar (que se puede encontrar en "target"), por lo que eso tendría que ser cerrado.

"generator_for_self" CodeRef

Un coderef que, si se llama, genera una cadena como '$_[0]'.

Tiene un valor predeterminado razonable.

Todos los métodos "generator_for_XXX" se llaman como métodos, por lo que tienen el objeto generador de código como invocante.

"generator_for_slot" CodeRef

Un coderef que, si se llama, genera una cadena como '$_[0]{nombre_attr}'.

"generator_for_get" CodeRef

Un coderef que, si se llama, genera una cadena como '$_[0]->nombre_attr'.

"generator_for_set" CodeRef

Un coderef que, si se llama con un parámetro, genera una cadena como "\$_[0]->_set_nombre_attr( $parametro )".

"generator_for_simple_default" CodeRef

Un coderef que, si se llama con un parámetro, genera una cadena como 'undef' o 'q[]' o '{}'.

El parámetro es un objeto handler, que ofrece un atributo "default_for_reset" que podría proporcionar un respaldo útil.

"generator_for_args" CodeRef

Un coderef que, si se llama, genera una cadena como '@_[1..$#_]'.

Tiene un valor predeterminado razonable.

"generator_for_argc" CodeRef

Un coderef que, si se llama, genera una cadena como '$#_'.

Tiene un valor predeterminado razonable.

"generator_for_argc" CodeRef

Un coderef que, si se llama con un parámetro, genera una cadena como "\$_[$parametro + 1]".

Tiene un valor predeterminado razonable.

"generator_for_currying" CodeRef

Un coderef que, si se llama con un parámetro, genera una cadena como "splice(\@_,1,0,$parametro);".

Tiene un valor predeterminado razonable.

"generator_for_usage_string" CodeRef

El valor predeterminado es este coderef:

sub {
  @_==3 or die;
  shift;
  my $nombre_metodo = shift;
  my $guts = shift;
  return "\$instancia->$nombre_metodo($guts)";
}

"generator_for_type_assertion" CodeRef

Se llama como un método y se le pasa un entorno de compilación hashref, una restricción de tipo y un nombre de variable. Genera código para asegurar que el valor de la variable cumple la restricción de tipo, con coerción si es apropiado.

"generator_for_error"

NOMBRE

Sub::HandlesVia::CodeGenerator - Genera métodos para Sub::HandlesVia.

SINOPSIS

  use Sub::HandlesVia::CodeGenerator;

  my $generator = Sub::HandlesVia::CodeGenerator->new(
    target_package => 'My::Class',
    attribute_name => 'foo',
  );

  # Generar un método 'foo' que almacena su valor en '$self->{_foo}'
  $generator->generate_and_install_method(
    'foo',
    Sub::HandlesVia::CodeGenerator::generate_for_hash_element(
      hash_element => '{_foo}',
    ),
  );

  # Generar un método 'bar' que llama a otro método
  $generator->generate_and_install_method(
    'bar',
    Sub::HandlesVia::CodeGenerator::generate_for_method_call(
      method_name => 'baz',
    ),
  );

DESCRIPCIÓN

Sub::HandlesVia::CodeGenerator es una clase que ayuda a generar métodos para la distribución Sub::HandlesVia.

Se utiliza para generar el código de los métodos "getter" y "setter" que Sub::HandlesVia necesita para implementar accesorios de atributos.

CONSTRUCTORES

new( %args )
Crea y devuelve un nuevo objeto Sub::HandlesVia::CodeGenerator.

Los argumentos aceptados son:

target_package
El nombre del paquete al que se instalarán los métodos generados.
attribute_name
El nombre del atributo para el que se están generando los métodos.
code_ref_for_error
Un CodeRef que se llama cuando se produce un error. Debe devolver una cadena que sea una expresión Perl válida para lanzar el error.
generator_for_prelude
Un CodeRef que se llama para generar código adicional que se insertará al principio del método generado. Por defecto, devuelve una cadena vacía.

ATRIBUTOS

Los siguientes atributos se pueden establecer en el constructor:

code_ref_for_error
Se llama como un método y se le pasa una cadena Perl que es una expresión que se evalúa como un mensaje de error. Genera código para lanzar el error.
generator_for_prelude
Por defecto es un coderef que devuelve la cadena vacía. Se puede usar para generar sentencias adicionales que se insertarán cerca de la parte superior del método que se está generando. (Típicamente después de las comprobaciones de parámetros pero antes de hacer cualquier cosa seria.) Esto se puede usar para desbloquear un atributo de solo lectura, por ejemplo.
get_is_lvalue
Indica si el código generado por "generator_for_get" será adecuado para ser usado como un lvalue.
set_checks_isa
Indica si el código generado por "generator_for_set" realizará comprobaciones de tipo.
set_strictly
Indica si queremos asegurarnos de que el setter siempre se llama y que no deberíamos intentar omitirlo, incluso si tenemos un getter lvalue.

MÉTODOS

Para cada atributo "generator_for_XXX", hay un método correspondiente "generate_XXX" para llamar realmente al coderef, posiblemente incluyendo procesamiento adicional.

generate_and_install_method( $method_name, $handler )
Dado un manejador y un nombre de método, generará un coderef para el manejador y lo instalará en el paquete de destino.
generate_coderef_for_handler( $method_name, $handler )
Lo mismo que lo anterior, pero solo devuelve el coderef en lugar de instalarlo.
install_method( $method_name, $coderef )
Instala un coderef en el paquete de destino con el nombre dado.
