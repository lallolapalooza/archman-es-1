Sub::Defer(3) Documentación de Perl contribuida por el usuario Sub::Defer(3)

NOMBRE

Sub::Defer - Retrasar la generación de subrutinas hasta que se llamen por primera vez

SINOPSIS

use Sub::Defer;
my $deferred = defer_sub 'Logger::time_since_first_log' => sub {
   my $t = time;
   sub { time - $t };
};
 Logger->time_since_first_log; # devuelve 0 y se reemplaza a sí mismo
 Logger->time_since_first_log; # devuelve time - $t

DESCRIPCIÓN

Estas subrutinas proporcionan al usuario una forma conveniente de retrasar la creación de subrutinas y métodos hasta que se llamen por primera vez.

SUBRUTINAS

defer_sub

my $coderef = defer_sub $name => sub { ... }, \%options;

Esta subrutina devuelve una referencia de código que encapsula la subrutina proporcionada. Cuando se llama por primera vez, se llama a la subrutina proporcionada y se espera que -ella misma- devuelva una subrutina a la que se saltará en las llamadas posteriores.

Si se proporciona un nombre, esto también instala la subrutina con ese nombre y, cuando la subrutina se "desdeferirá", reinstalará la versión final para mayor velocidad.

Exportada por defecto.

Opciones

Opcionalmente, se puede especificar un hashref de opciones.

package
El paquete en el que generar la subrutina. Se anulará por la opción $name completamente cualificada. Si no se especifica, se utilizará por defecto el paquete del llamador.
attributes
Los "Atributos de subrutina" en perlsub que se aplicarán a la subrutina generada. Debe especificarse como una referencia de matriz.

undefer_sub

my $coderef = undefer_sub \&Foo::name;

Si la referencia de código pasada ha sido "deferida", esto la "desdeferirá". Si la referencia de código pasada no ha sido "deferida", simplemente la devolverá.

Si esto es confuso, echa un vistazo al ejemplo en la sección "SINOPSIS".

Exportada por defecto.

defer_info

my $data = defer_info $sub;
my ($name, $generator, $options, $undeferred_sub) = @$data;

Devuelve los argumentos originales de defer_sub, más la versión "desdeferida" si esta subrutina ya ha sido "desdeferida".

Tenga en cuenta que $sub puede ser tanto la versión "deferida" original como la versión "desdeferida" para mayor comodidad.

No exportada por defecto.

undefer_all

undefer_all();

Esto "desdeferirá" todas las subrutinas "deferidas" de una sola vez. Esto puede ser muy útil en un entorno de bifurcación donde cada proceso hijo tendría que "desdeferir" las mismas subrutinas. Al llamar a esto justo antes de empezar a bifurcar procesos hijos, puedes "desdeferir" todas las subrutinas "deferidas" actualmente en el proceso padre para que los hijos no tengan que hacerlo. Ten en cuenta que esto puede "hornear" el comportamiento de algunas subrutinas que estaban destinadas a calcular su comportamiento más tarde, por lo que no debe usarse a mitad de la carga de un módulo o definición de clase.

Exportada por defecto.

undefer_package

undefer_package($package);

Esto "desdeferirá" todas las subrutinas "deferidas" en un paquete.

No exportada por defecto.
