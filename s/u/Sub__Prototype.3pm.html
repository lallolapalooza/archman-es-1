Sub::Prototype(3) Documentación de Perl contribuida por el usuario Sub::Prototype(3)

NOMBRE

Sub::Prototype - Establece el prototipo de una subrutina

VERSIÓN

versión 0.03

SINOPSIS

use Sub::Prototype;
BEGIN {
    my $code = sub { ... };
    set_prototype($code, '&@');
    *main::my_func = $code;
}
my_func { ... } @list;

FUNCIONES

Este módulo solo tiene una función, que también se exporta por defecto:

set_prototype(\&coderef, $prototipo)

set_prototype(\&some_function, '$$');

Establece el prototipo para "coderef" a $prototipo.
