Sub::HandlesVia::Manual::Comparison(3pm)

NAME

Sub::HandlesVia::Manual::Comparison — comp with other modules

MANUAL

This document compares Sub::HandlesVia with other modules that provide similar functionality.

Sub::ObjectMethod

Sub::HandlesVia can do everything that Sub::ObjectMethod can do, and more.

Sub::ObjectMethod provides a way to create method wrappers, using one of the following syntaxes:

    use Sub::ObjectMethod qw(method_wrapper);
    sub hello : method_wrapper;
    sub hello : method_wrapper( 'hello' );
    sub hello : method_wrapper( \$object, 'hello' );
    sub hello : method_wrapper( \$object, \$method_name );

Sub::HandlesVia provides similar functionality using the following syntaxes:

    use Sub::HandlesVia;
    sub hello : HandlesVia;
    sub hello : HandlesVia( 'hello' );
    sub hello : HandlesVia( \$object, 'hello' );
    sub hello : HandlesVia( \$object, \$method_name );

However, Sub::HandlesVia also supports delegating to code references:

    use Sub::HandlesVia;
    sub hello : HandlesVia( \&some_code );
    sub hello : HandlesVia( \$object, \&some_code );

And it supports storing the delegated method or code reference in an object's attribute:

    package MyObject;
    use Moose;
    use Sub::HandlesVia;

    has has_method => (
        isa => 'Maybe[Str]',
        handles_via => 'get_method',
    );

    sub get_method { ... }

    sub hello : HandlesVia( 'has_method' );
    sub hello : HandlesVia( \$self, 'has_method' );

    __PACKAGE__->meta->make_immutable;
    # ...

Mouse

MooseX::HandlesVia provides syntax for the same functionality as Sub::HandlesVia, but it requires the use of Moose.

    package MyObject;
    use Moose;
    use MooseX::HandlesVia;

    has has_method => (
        isa => 'Maybe[Str]',
        handles_via => 'get_method',
    );

    sub get_method { ... }

    sub hello : HandlesVia( 'has_method' );
    sub hello : HandlesVia( \$self, 'has_method' );

    __PACKAGE__->meta->make_immutable;
    # ...

If you are not using Moose, you should use Sub::HandlesVia instead.

DataP

DataP::Handle::via has similar syntax to Sub::HandlesVia, but it is designed for delegating to accessors.

    package MyObject;
    use DataP;
    use DataP::Handle::via;

    has 'x' => (is => 'rw');
    has 'y' => (is => 'rw');

    sub x : via('x');
    sub y : via('y');
    # ...

Sub::HandlesVia is more general-purpose, and can delegate to methods, coderefs, or arbitrary object attributes.

SubHV

This module is very similar to Sub::HandlesVia. It is perhaps slightly older, and may not support all the same features (e.g. delegation to coderefs).

    sub trim : SubHV;
    sub trim : SubHV( 'trim' );
    sub trim : SubHV( \$object, 'trim' );

    sub uc : SubHV;
    sub uc : SubHV( 'uc' );
    sub uc : SubHV( \$object, 'uc' );

It is recommended to use Sub::HandlesVia in new projects.

Sub::HandlesVia is intended to be a drop-in replacement for SubHV. You can replace:

    use SubHV;

with

    use Sub::HandlesVia qw( HandlesVia );

and it should just work. Note that the subroutine attribute name has changed from SubHV to HandlesVia.

The following example shows how to replace:

    package My::Class;
    use strict;
    use warnings;
    use Moose;
    use SubHV;

    has 'attr' => (is => 'rw');

    sub trim : SubHV( 'attr' );
    sub trim : SubHV( \$self, 'attr' );
    sub uc : SubHV( 'attr' );
    sub uc : SubHV( \$self, 'attr' );

    __PACKAGE__->meta->make_immutable;

with:

    package My::Class;
    use strict;
    use warnings;
    use Moose;
    use Sub::HandlesVia qw( HandlesVia );

    has 'attr' => (is => 'rw');

    sub trim : HandlesVia( 'attr' );
    sub trim : HandlesVia( \$self, 'attr' );
    sub uc : HandlesVia( 'attr' );
    sub uc : HandlesVia( \$self, 'attr' );

    __PACKAGE__->meta->make_immutable;

Sub::HandlesVia also supports delegation to coderefs:

    package My::Class;
    use strict;
    use warnings;
    use Moose;
    use Sub::HandlesVia;

    sub multiply : HandlesVia( \&{sub { $_[0] * $_[1] }} );
    sub multiply : HandlesVia( \$self, \&{sub { $_[0] * $_[1] }} );
