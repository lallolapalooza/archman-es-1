Sub::HandlesVia::HandlerLibrary::Number(3) Documentación de Contribución de Usuarios de Perl Sub::HandlesVia::HandlerLibrary::Number(3)

NOMBRE

Sub::HandlesVia::HandlerLibrary::Number - biblioteca de métodos relacionados con números

SINOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Num';
  has attr => (
    is => 'rwp',
    isa => Num,
    handles_via => 'Number',
    handles => {
      'my_abs' => 'abs',
      'my_add' => 'add',
      'my_ceil' => 'ceil',
      'my_cmp' => 'cmp',
      'my_div' => 'div',
      'my_eq' => 'eq',
      'my_floor' => 'floor',
      'my_ge' => 'ge',
      'my_get' => 'get',
      'my_gt' => 'gt',
      'my_le' => 'le',
      'my_lt' => 'lt',
      'my_mod' => 'mod',
      'my_mul' => 'mul',
      'my_ne' => 'ne',
      'my_set' => 'set',
      'my_sub' => 'sub',
    },
  );
}

DESCRIPCIÓN

Esta es una biblioteca de métodos para Sub::HandlesVia.

MÉTODOS DELEGABLES

abs()

Encuentra el valor absoluto del número actual, actualizando el atributo.

my $object = My::Class->new( attr => -5 );
$object->my_abs;
say $object->attr; ## ==> 5

add( $addend )

Argumentos: Num.

Suma un número al número existente, actualizando el atributo.

my $object = My::Class->new( attr => 4 );
$object->my_add( 5 );
say $object->attr; ## ==> 9

ceil()

Encuentra el techo (ceil) del número actual, actualizando el atributo. Similar a "ceil" de las funciones integradas, pero en su lugar.

cmp( $num )

Argumentos: Num.

Devuelve "$object->attr <=> $num".

div( $divisor )

Argumentos: Num.

Divide el número existente por un número, actualizando el atributo.

my $object = My::Class->new( attr => 6 );
$object->my_div( 2 );
say $object->attr; ## ==> 3

eq( $num )

Argumentos: Num.

Devuelve "$object->attr == $num".

floor()

Encuentra el suelo (floor) del número actual, actualizando el atributo. Similar a "floor" de las funciones integradas, pero en su lugar.

ge( $num )

Argumentos: Num.

Devuelve "$object->attr >= $num".

get()

Devuelve el valor actual del número.

my $object = My::Class->new( attr => 4 );
say $object->my_get; ## ==> 4

gt( $num )

Argumentos: Num.

Devuelve "$object->attr > $num".

le( $num )

Argumentos: Num.

Devuelve "$object->attr <= $num".

lt( $num )

Argumentos: Num.

Devuelve "$object->attr < $num".

mod( $divisor )

Argumentos: Num.

Encuentra el número actual módulo un divisor, actualizando el atributo.

my $object = My::Class->new( attr => 5 );
$object->my_mod( 2 );
say $object->attr; ## ==> 1

mul( $factor )

Argumentos: Num.

Multiplica el número existente por un número, actualizando el atributo.

my $object = My::Class->new( attr => 2 );
$object->my_mul( 5 );
say $object->attr; ## ==> 10

ne( $num )

Argumentos: Num.

Devuelve "$object->attr != $num".

set( $value )

Argumentos: Num.

Establece el número a un nuevo valor.

my $object = My::Class->new( attr => 4 );
$object->my_set( 5 );
say $object->attr; ## ==> 5

sub( $subtrahend )

Argumentos: Num.

Resta un número del número existente, actualizando el atributo.

my $object = My::Class->new( attr => 9 );
$object->my_sub( 6 );
say $object->attr; ## ==> 3
