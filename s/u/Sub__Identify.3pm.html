NOMBRE

Sub::Identify - Recuperar nombres de referencias de código

SINOPSIS

use Sub::Identify ':all';
my $subname = sub_name( $some_coderef );
my $packagename = stash_name( $some_coderef );
# o, para obtener todo a la vez...
my $fully_qualified_name = sub_fullname( $some_coderef );
defined $subname
    and say "esta referencia de código apunta a la subrutina $subname en el paquete $packagename";
my ($file, $line) = get_code_location( $some_coderef );
$file
    and say "esta referencia de código está definida en la línea $line del archivo $file";
is_sub_constant( $some_coderef )
    and say "esta referencia de código apunta a una subrutina constante";

DESCRIPCIÓN

"Sub::Identify" te permite recuperar el nombre real de las referencias de código.

Proporciona seis funciones, todas ellas tomando una referencia de código.

"sub_name" devuelve el nombre de la referencia de código pasada como argumento (o "__ANON__" si es una referencia de código anónima), "stash_name" devuelve su paquete, y "sub_fullname" devuelve la concatenación de ambos.

"get_code_info" devuelve una lista de dos elementos, el paquete y el nombre de la subrutina (en caso de que quieras ambos y te preocupe la velocidad).

En caso de alias de subrutinas, estas funciones siempre devuelven el nombre original.

"get_code_location" devuelve una lista de dos elementos que contiene el nombre del archivo y el número de línea donde se definió la subrutina.

"is_sub_constant" devuelve un valor booleano que indica si la subrutina es o no una constante.

Versión Pure-Perl

Por defecto, "Sub::Identify" intenta cargar una implementación XS de las funciones "get_code_info", "get_code_location" y (en versiones de perl 5.16.0 y posteriores) "is_sub_constant", para mayor velocidad; si falla, o si la variable de entorno "PERL_SUB_IDENTIFY_PP" está definida como verdadera, recurrirá a una implementación pura de perl, que utiliza el mecanismo de introspección de perl, proporcionado por el módulo "B".
