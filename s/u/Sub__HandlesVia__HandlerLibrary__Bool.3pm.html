Sub__HandlesVia__HandlerLibrary__Bool(3pm)

Paquete: perl-sub-handlesvia

Licencias: PerlArtistic, GPL

Sub::HandlesVia::HandlerLibrary::Bool(3) Documentación de Perl contribuida por el usuario Sub::HandlesVia::HandlerLibrary::Bool(3)

NOMBRE

Sub::HandlesVia::HandlerLibrary::Bool - biblioteca de métodos relacionados con booleanos

SINOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Bool';
  has attr => (
    is => 'rwp',
    isa => Bool,
    handles_via => 'Bool',
    handles => {
      'my_not' => 'not',
      'my_reset' => 'reset',
      'my_set' => 'set',
      'my_toggle' => 'toggle',
      'my_unset' => 'unset',
    },
  );
}

DESCRIPCIÓN

Esta es una biblioteca de métodos para Sub::HandlesVia.

MÉTODOS DELEGABLES

not()

Devuelve el valor opuesto del booleano.

my $object = My::Class->new( attr => 1 );
say $object->my_not(); ## ==> falso

reset()

Establece el booleano a su valor predeterminado, o falso si no tiene predeterminado.

set()

Establece el valor del booleano a verdadero.

my $object = My::Class->new();
$object->my_set();
say $object->attr; ## ==> verdadero

toggle()

Alterna el valor de verdad del booleano.

my $object = My::Class->new();
$object->my_toggle();
say $object->attr; ## ==> verdadero
$object->my_toggle();
say $object->attr; ## ==> falso

unset()

Establece el valor del booleano a falso.

my $object = My::Class->new();
$object->my_unset();
say $object->attr; ## ==> falso
