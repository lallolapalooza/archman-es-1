NOMBRE

Sub::Install - instala subrutinas en paquetes fácilmente

VERSIÓN

versión 0.929

SINOPSIS

use Sub::Install;
Sub::Install::install_sub({
  code => sub { ... },
  into => $paquete,
  as   => $nombre_subrutina
});

DESCRIPCIÓN

Este módulo facilita la instalación de subrutinas en paquetes sin el desorden antiestético de "no strict" o los typeglobs a la vista de cualquiera.

VERSIÓN DE PERL

Esta biblioteca debería funcionar en versiones de perl publicadas incluso hace mucho tiempo. Debería funcionar en cualquier versión de perl publicada en los últimos diez años.

Aunque puede funcionar en versiones anteriores de perl, no se garantiza que la versión mínima requerida no aumente. La versión puede aumentar por cualquier motivo, y no hay promesa de que se acepten parches para reducir la versión mínima requerida de perl.

FUNCIONES

install_sub

Sub::Install::install_sub({
 code => \&subrutina,
 into => "Finance::Shady",
 as   => 'launder',
});

Esta rutina instala una referencia de código dada en un paquete como una subrutina normal. Lo anterior es equivalente a:

no strict 'refs';
*{"Finance::Shady" . '::' . "launder"} = \&subrutina;

Si no se proporciona "into", la subrutina se instala en el paquete que llama.

Si "code" no es una referencia de código, se busca como una sub existente en el paquete nombrado en el parámetro "from". Si no se proporciona "from", buscará en el paquete que llama.

Si no se proporciona "as", y si "code" es un nombre, "as" será por defecto "code". Si no se proporciona "as", pero si "code" es una referencia de código, Sub::Install intentará encontrar el nombre de la referencia de código dada y la usará como "as".

Eso significa que este código:

Sub::Install::install_sub({
  code => 'twitch',
  from => 'Person::InPain',
  into => 'Person::Teenager',
  as   => 'dance',
});

es lo mismo que:

package Person::Teenager;
Sub::Install::install_sub({
  code => Person::InPain->can('twitch'),
  as   => 'dance',
});

reinstall_sub

Esta rutina se comporta exactamente como "install_sub", pero no emite una advertencia si las advertencias están activas y el destino ya está definido.

install_installers

Esta rutina se proporciona para permitir la compatibilidad de Sub::Install con Sub::Installer. Instala los métodos "install_sub" y "reinstall_sub" en el paquete nombrado por su argumento.

Sub::Install::install_installers('Code::Builder'); # solo para nosotros, por favor
Code::Builder->install_sub({ name => $code_ref });
Sub::Install::install_installers('UNIVERSAL'); # ¿te sientes afortunado, punk?
Anything::At::All->install_sub({ name => $code_ref });

Los instaladores instalados son similares, pero no idénticos, a los proporcionados por Sub::Installer. Aceptan un único hash como argumento. Las pares clave/valor se utilizan como parámetros "as" y "code" para la rutina "install_sub" detallada anteriormente. El nombre del paquete en el que se llama al método se utiliza como parámetro "into".

A diferencia de Sub::Installer, "install_sub" no evaluará cadenas en código, sino que buscará código con nombre en el paquete que llama.

EXPORTACIONES

Sub::Install exporta "install_sub" y "reinstall_sub" solo si se solicitan.

exportador

Sub::Install tiene una subrutina nunca exportada llamada "exporter", que se utiliza para implementar su rutina "import". Toma un hashref de argumentos con nombre, de los cuales solo uno se reconoce actualmente: "exports". Debe ser un arrayref de subrutinas para ofrecer para exportar.

Esta rutina es principalmente para el propio consumo de Sub::Install. En su lugar, considere Sub::Exporter.

VER TAMBIÉN

Sub::Installer
Este módulo es (obviamente) una reacción a Sub::Installer de Damian Conway, que hace lo mismo, pero lo hace metiendo sus sucios dedos en UNIVERSAL. Estaba muy contento con la idea de hacer la instalación de coderefs menos fea, pero no pude resignarme a reemplazar la fealdad de los typeglobs y las estructuras flexibles con la fealdad de los métodos UNIVERSAL.
Sub::Exporter
Este es un reemplazo completo de Exporter.pm, construido sobre Sub::Install.
