Sub::Exporter::Util(3) Documentación de Perl aportada por el usuario Sub::Exporter::Util(3)

NOMBRE

Sub::Exporter::Util - utilidades para facilitar Sub::Exporter

VERSIÓN

versión 0.991

DESCRIPCIÓN

Este módulo proporciona una serie de funciones de utilidad para realizar operaciones comunes o útiles al configurar una configuración de Sub::Exporter. Todas las utilidades pueden ser exportadas, pero ninguna lo es por defecto.

VERSIÓN DE PERL

Esta biblioteca debería ejecutarse en versiones de Perl incluso antiguas. Debería funcionar en cualquier versión de Perl lanzada en los últimos cinco años.

Aunque puede funcionar en versiones antiguas de Perl, no se garantiza que la versión mínima requerida no aumente. La versión puede aumentarse por cualquier motivo, y no hay promesa de que se acepten parches para reducir la versión mínima requerida de Perl.

LAS UTILIDADES

curry_method

exports => {
  some_method => curry_method,
}

Esta utilidad devuelve un generador que producirá una versión "curried" del invocante de un método. En otras palabras, exportará una llamada a método con la clase que exporta integrada como invocante.

Un módulo que importe el código del ejemplo anterior podría hacer esto:

use Some::Module qw(some_method);
my $x = some_method;

Esto sería equivalente a:

use Some::Module;
my $x = Some::Module->some_method;

Si Some::Module se subdivide y se llama al método de importación de la subclase para importar "some_method", la subclase se integrará como invocante.

Si se proporciona un argumento para "curry_method", se utiliza como el nombre del método curried a exportar. Esto significa que podría exportar un constructor de Widget de esta manera:

exports => { widget => curry_method('new') }

Esta utilidad también puede llamarse como "curry_class", por compatibilidad con versiones anteriores.

curry_chain

"curry_chain" se comporta como "curry_method", pero está pensada para generar exportaciones que llamarán a varios métodos sucesivamente.

exports => {
  reticulate => curry_chain(
    new => gather_data => analyze => [ detail => 100 ] => 'results'
  ),
}

Si se importa desde Spliner, llamar a la rutina "reticulate" será equivalente a:

Spliner->new->gather_data->analyze(detail => 100)->results;

Si algún método devuelve algo sobre lo que no se pueden llamar métodos, la rutina falla.

Los argumentos para "curry_chain" forman una lista de opciones. Los nombres son métodos a llamar y los argumentos, si se dan, son referencias a arrays que se descomprimirán y se pasarán como argumentos a esos métodos. "curry_chain" devuelve un generador como los esperados por Sub::Exporter.

¡Atención! actualmente, no hay forma de pasar argumentos desde la rutina generada a las llamadas a métodos. Esto probablemente se resolverá en futuras revisiones permitiendo que los valores de la lista de opciones sean subrutinas que se llamarán con la pila de la rutina generada.

merge_col

exports => {
  merge_col(defaults => {
    twiddle => \'_twiddle_gen',
    tweak   => \&_tweak_gen,
  }),
}

Esta utilidad envuelve el generador dado en uno que fusionará la colección nombrada en sus argumentos antes de llamarlo. Esto significa que puede admitir un recopilador "predeterminado" en múltiples exportaciones sin escribir el código cada vez.

Puede especificar tantos pares de nombres de colección y generadores como desee.

mixin_installer

use Sub::Exporter -setup => {
  installer => Sub::Exporter::Util::mixin_installer,
  exports   => [ qw(foo bar baz) ],
};

Esta utilidad devuelve un instalador que se instalará en una superclase y ajustará la clase que importa ISA para incluir la superclase recién generada.

Si el objetivo de la importación es un objeto, la jerarquía se invierte: la nueva clase será ISA de la clase del objeto, y el objeto será rebautizado.

Requisitos previos: esta utilidad requiere que Package::Generator esté instalado.

like

Es un recopilador que agrega importaciones para cualquier cosa similar a la expresión regular dada.

Si proporciona esta configuración:

exports    => [ qw(igrep imap islurp exhausted) ],
collectors => { -like => Sub::Exporter::Util::like },

Un usuario puede importar desde su módulo de esta manera:

use Your::Iterator -like => qr/^i/; # importa igrep, imap, islurp

o

use Your::Iterator -like => [ qr/^i/ => { -prefix => 'your_' } ];

Se respetan los argumentos de prefijo y sufijo del grupo "like"; otros argumentos se pasan a los generadores para las exportaciones coincidentes.
