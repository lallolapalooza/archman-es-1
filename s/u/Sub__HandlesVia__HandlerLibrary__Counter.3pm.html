Sub::HandlesVia::HandlerLibrary::Counter(3) Documentación de Contribución de Usuarios de Perl Sub::HandlesVia::HandlerLibrary::Counter(3)

NOMBRE

Sub::HandlesVia::HandlerLibrary::Counter - biblioteca de métodos relacionados con contadores

SINOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Int';
  has attr => (
    is => 'rwp',
    isa => Int,
    handles_via => 'Counter',
    handles => {
      'my_dec' => 'dec',
      'my_inc' => 'inc',
      'my_reset' => 'reset',
      'my_set' => 'set',
    },
  );
}

DESCRIPCIÓN

Esta es una biblioteca de métodos para Sub::HandlesVia.

MÉTODOS DELEGABLES

dec( $cantidad? )

Argumentos: Opcional[Int].

Decrementa el contador en $cantidad, o en 1 si no se proporciona ningún valor.

my $object = My::Class->new( attr => 10 );
$object->my_dec;
$object->my_dec;
say $object->attr; ## ==> 8
$object->my_dec( 5 );
say $object->attr; ## ==> 3

inc( $cantidad? )

Argumentos: Opcional[Int].

Incrementa el contador en $cantidad, o en 1 si no se proporciona ningún valor.

my $object = My::Class->new( attr => 0 );
$object->my_inc;
$object->my_inc;
say $object->attr; ## ==> 2
$object->my_inc( 3 );
say $object->attr; ## ==> 5

reset()

Establece el contador a su valor predeterminado, o 0 si no tiene predeterminado.

my $object = My::Class->new( attr => 10 );
$object->my_reset;
say $object->attr; ## ==> 0

set( $valor )

Argumentos: Int.

Establece el contador al valor proporcionado.

my $object = My::Class->new( attr => 0 );
$object->my_set( 5 );
say $object->attr; ## ==> 5
