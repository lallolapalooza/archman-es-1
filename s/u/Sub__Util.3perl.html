Sub::Util(3perl) Guía de referencia del programador de Perl Sub::Util(3perl)

NOMBRE

Sub::Util - Una selección de subrutinas de utilidad para subs y referencias CODE

SINOPSIS

use Sub::Util qw( prototype set_prototype subname set_subname );

DESCRIPCIÓN

"Sub::Util" contiene una selección de subrutinas de utilidad que son útiles para operar sobre subs y referencias CODE.

La razón de su inclusión en este módulo es que la función realiza algún trabajo para el cual una implementación XS es esencial porque no se puede implementar en Perl Puro, y que tiene un uso suficientemente amplio en CPAN como para que su popularidad justifique su inclusión en un módulo principal, que este lo es.

FUNCIONES

prototype

my $proto = prototype( $code )

Desde la versión 1.40.

Devuelve el prototipo de la referencia $code dada, si la tiene, como una cadena. Esto es lo mismo que el operador "CORE::prototype"; se incluye aquí simplemente por simetría y completitud con las otras funciones.

set_prototype

my $code = set_prototype $prototype, $code;

Desde la versión 1.40.

Establece el prototipo de la función dada por la referencia $code, o lo elimina si $prototype es "undef". Devuelve la propia referencia $code.

Precaución: Esta función toma los argumentos en un orden diferente al de la copia anterior del código de "Scalar::Util". Esto es para coincidir con el orden de "set_subname" y otras adiciones potenciales en este archivo. Este orden ha sido elegido ya que permite una concatenación ordenada y simple de otras funciones "Sub::Util::set_*" que puedan estar disponibles, tales como:

my $code =
   set_subname   name_here =>
   set_prototype '&@'      =>
   set_attribute ':lvalue' =>
      sub { ...... };

subname

my $name = subname( $code )

Desde la versión 1.40.

Devuelve el nombre de la referencia $code dada, si la tiene. Los subs con nombre normal darán un nombre completamente calificado que consiste en el paquete y el nombre local separados por "::". Las referencias de código anónimas darán "__ANON__" como nombre local. Si el paquete en el que se compiló el código ha sido eliminado (p. ej., usando "delete_package" de Symbol), se devolverá "__ANON__" como nombre del paquete. Si se ha establecido un nombre usando "set_subname", se devolverá este nombre en su lugar.

Esta función se inspiró en "sub_fullname" de Sub::Identify. Las funciones restantes que implementa "Sub::Identify" se pueden emular fácilmente usando operaciones de expresiones regulares, como

sub get_code_info { return (subname $_[0]) =~ m/^(.+)::(.*?)$/ }
sub sub_name      { return (get_code_info $_[0])[0] }
sub stash_name    { return (get_code_info $_[0])[1] }

Usuarios de Sub::Name, ¡cuidado!: Esta función **no** es igual a "Sub::Name::subname"; devuelve el nombre existente del sub en lugar de cambiarlo. Para establecer o cambiar un nombre, vea en su lugar "set_subname".

set_subname

my $code = set_subname $name, $code;

Desde la versión 1.40.

Establece el nombre de la función dada por la referencia $code. Devuelve la propia referencia $code. Si el $name no está cualificado, se utiliza el paquete del llamador para cualificarlo.

Esto es útil para aplicar nombres a referencias CODE anónimas para que las trazas de pila y situaciones similares den un nombre útil en lugar del predeterminado de "__ANON__". Tenga en cuenta que este nombre solo se utiliza para esta situación; "set_subname" no lo instalará en la tabla de símbolos; tendrá que hacerlo usted mismo si es necesario.

Sin embargo, dado que Perl no utiliza el nombre excepto como valor de retorno de "caller", para trazas de pila o similares, no hay un requisito real de que el nombre sea sintácticamente válido como nombre de función de perl. Esto podría utilizarse para adjuntar información adicional que pudiera ser útil en la depuración de trazas de pila.

Esta función se copió de "Sub::Name::subname" y se renombró según la convención de nomenclatura de este módulo.
