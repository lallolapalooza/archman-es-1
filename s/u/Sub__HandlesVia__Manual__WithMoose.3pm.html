NOMBRE

Sub::HandlesVia::Manual::WithMoose - uso de Sub::HandlesVia con Moose

SINOPSIS

package Cocina {
  use Moose;
  use Sub::HandlesVia;
  use Types::Standard qw( ArrayRef Str );

  has comida => (
    is          => 'ro',
    isa         => ArrayRef[Str],
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'agregar_comida'    => 'push',
      'buscar_comida'   => 'grep',
    },
  );
}

(¡Si tienes un alce en tu cocina, eso podría ser un desastre!)

MANUAL

Sub::HandlesVia te permite delegar métodos de tu clase a los valores de los atributos de tus objetos.

Conceptualmente, te permite definir "$objeto->push_numero($n)" como un atajo para "$objeto->numeros->push($n)" excepto que "$objeto->numeros" es un arrayref, por lo que no tiene métodos que puedas llamar sobre él como "push".

Moose tiene una característica incorporada (rasgos nativos) que proporciona una versión más limitada de esto.

¿Qué Métodos Pueden Ser Delegados?

La opción "handles_via" indica qué biblioteca de métodos debe estar disponible. Los valores válidos incluyen Array, Blessed, Bool, Code, Counter, Enum, Hash, Number, Scalar, y String.

Se puede proporcionar un arrayref para "handles_via", aunque muchas de las opciones son conceptualmente contradictorias.

handles_via => [ 'Number', 'Scalar' ]

Tipos Nativos de Moose

Aunque la sinopsis muestra Types::Standard siendo utilizado para restricciones de tipo, los tipos nativos de Moose también deberían funcionar bien.

package Cocina {
  use Moose;
  use Sub::HandlesVia;

  has comida => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'agregar_comida'    => 'push',
      'buscar_comida'   => 'grep',
    },
  );
}

Sintaxis de Reemplazo para Rasgos Nativos de Moose

Sub::HandlesVia también reconocerá los rasgos de estilo native-traits. ¡Se insertará y los manejará antes de que Moose se dé cuenta!

package Cocina {
  use Moose;
  use Sub::HandlesVia;

  has comida => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    traits      => ['Array'],
    default     => sub { [] },
    handles     => {
      'agregar_comida'    => 'push',
      'buscar_comida'   => 'grep',
    },
  );
}
