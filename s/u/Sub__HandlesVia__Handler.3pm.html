Sub::HandlesVia::Handler(3) Documentación de Perl contribuida por el usuario Sub::HandlesVia::Handler(3)

NOMBRE

Sub::HandlesVia::Handler - plantilla para un método que puede ser delegado

DESCRIPCIÓN

Este módulo es parte de la API interna de Sub::HandlesVia. Es de interés principalmente para personas que extienden Sub::HandlesVia.

Este módulo funciona en conjunto con Sub::HandlesVia::CodeGenerator y subclases de Sub::HandlesVia::Toolkit para construir una cadena de código Perl que puede ser compilada en un método para instalar en tu clase.

CONSTRUCTORES

new( %attributes )

Constructor estándar al estilo Moose.

"lookup( $method, $trait )"

Busca un método de las bibliotecas de manejadores existentes.

my $h = Sub::HandlesVia::Handler->lookup( 'get', 'Array' );

Versión currificada:

my $h = Sub::HandlesVia::Handler->lookup( [ 'get', 0 ], 'Array' );

El $trait puede ser un arrayref de rasgos posibles.

EXPORTA

Nada se exporta por defecto.

"handler %attributes"

Atajo para el constructor "new".

use Sub::HandlesVia::Handler 'handler';

my $h = handler( %attr );
# es lo mismo que
my $h = Sub::HandlesVia::Handler->new( %attr );

ATRIBUTOS

"name" Str

El nombre de la función a la que se delega.

"is_mutator" Bool

Indica si este manejador podría mutar el valor de un atributo. El valor por defecto es intentar detectarlo basándose en el análisis de las plantillas.

"template" Str

Cadena especialmente formateada (ver sección abajo) que contiene el código Perl para implementar el método.

"lvalue_template" Maybe[Str]

Si se define, un atajo para implementarlo cuando el valor de la posición del atributo puede ser usado como lvalue.

"args" Maybe[PositiveOrZeroInt]

El número de argumentos que espera el método que se está generando (no incluye el valor del atributo en sí).

"min_args" y "max_args" Maybe[PositiveOrZeroInt]

Para métodos que toman un número variable de argumentos. Si se omiten, se usa por defecto el valor de "args".

"signature" Maybe[ArrayRef[TypeTiny]]

Una firma para dichos argumentos.

"usage" Str

Una firma para mostrar en la documentación, como '$index, $value'. Si no se proporciona, se generará mágicamente a partir de "args", "min_args" y "max_args".

"curried" Maybe[ArrayRef[Item]]

Un arrayref de argumentos currificados.

"is_chainable" Bool

Si se fuerza que el método generado sea encadenable.

"no_validation_needed" Bool

Si se realiza menos validación de los datos de entrada.

"default_for_reset" Maybe[Str]

Si este manejador tiene que "restablecer" el valor de un atributo a su valor por defecto, y el atributo no tiene un valor por defecto, esta cadena de código Perl se evalúa para proporcionar un valor por defecto. Un ejemplo podría ser "[]".

"prefer_shift_self" Bool

Indica que este manejador prefiere que el generador de código elimine $self de @_.

"documentation" Maybe[Str]

Cadena de pod para describir el manejador.

"_examples" Maybe[CodeRef]

Esta referencia de código, si se llama con los parámetros $class, $attr y $method, generará un ejemplo de código para insertar en el pod.

"additional_validation" Maybe[CodeRef]

Referencia de código que proporciona una API ligeramente molesta. Se describirá más adelante.

"allow_getter_shortcuts" Bool

Por defecto es verdadero. Raramente útil de sobrescribir.

MÉTODOS

has_min_args() y has_max_args()

Indica si este manejador tiene un min o max de argumentos definidos.

install_method( %args )

Los argumentos requeridos son "method_name" y "code_generator". Instala el método delegado en la clase objetivo (tomada del generador de código).

code_as_string( %args )

Mismos argumentos requeridos que "install_method", pero devuelve el código Perl para el método como una cadena.

curry( @args )

Pseudoconstructor.

Crea un nuevo objeto Sub::HandlesVia::Handler como este, pero con los argumentos dados currificados.

"loose"

Pseudoconstructor.

Crea un nuevo objeto Sub::HandlesVia::Handler como este, pero con validación de argumentos más laxa.

"chainable"

Pseudoconstructor.

Crea un nuevo objeto Sub::HandlesVia::Handler como este, pero encadenable.

FORMATO DE PLANTILLA

La plantilla es una cadena de código Perl, excepto si se encuentran las siguientes cosas especiales, que son sustituidas.

$SELF
El invocante.
$SLOT
Acceso directo hashref para el atributo.
$GET
El valor actual del atributo.
@ARG
Cualquier argumento adicional pasado al método delegado.

$ARG[$n] también funcionará.

"#ARG"
El número de argumentos adicionales pasados al método delegado.
$ARG
El primer elemento en @ARG.
$DEFAULT
El valor por defecto del atributo, si se conoce.
"« EXPR »"
Una expresión entre comillas angulares dobles establece el valor del atributo a la expresión.

Por ejemplo, un manejador para dividir por la mitad el valor de un atributo numérico podría ser:

'Sub::HandlesVia::Handler'->new(
  name => 'MiNumero:mitad',
  args => 0,
  template => '« $GET / 2 »',
  lvalue_template => '$GET /= 2',
);
