NOMBRE

Sub::HandlesVia::Manual::WithObjectPad - usando Sub::HandlesVia con Object::Pad

SINOPSIS

use Object::Pad;

class Cocina {
  field @comidas;
  use Sub::HandlesVia::Declare '@comidas', Array => (
    todas_comidas => 'all',
    agregar_comida  => 'push',
  );
}

MANUAL

Sub::HandlesVia te permite delegar métodos de tu clase a los valores de los atributos de tus objetos.

Conceptualmente, te permite definir "$objeto->push_numero($n)" como un atajo para "$objeto->numeros->push($n)" excepto que "$objeto->numeros" es un arrayref, por lo que no tiene métodos que puedas llamar sobre él como "push".

El soporte experimental para Object::Pad es proporcionado por Sub::HandlesVia, incluyendo para campos de array y hash.

Las clases Object::Pad están "selladas" después del tiempo de compilación, evitando que se instalen nuevos métodos en tiempo de ejecución. (En realidad, es trivialmente fácil añadirlos en tiempo de ejecución, pero no usando la API proporcionada por el MOP de Object::Pad, así que no lo hacemos.) Por esto se usa Sub::Handles::Declare, ya que crea métodos delegados en tiempo de compilación.

El primer argumento es el nombre del campo, incluyendo su sigilo.

El segundo argumento es la biblioteca de manejadores. Si el nombre del campo comienza con '@' o '%', se infiere que es "Array"/"Hash".

use Object::Pad;

class Cocina {
  field @comidas;
  use Sub::HandlesVia::Declare '@comidas', (
    todas_comidas => 'all',
    agregar_comida  => 'push',
  );
}

El tercer argumento es un hash de métodos a delegar.

¿A Qué Métodos Se Puede Delegar?

El segundo parámetro ("Array" en la sinopsis) indica qué biblioteca de métodos debe estar disponible. Los valores válidos incluyen Array, Blessed, Bool, Code, Counter, Enum, Hash, Number, Scalar y String.

Se puede proporcionar un arrayref, aunque muchas de las opciones son conceptualmente contradictorias.

use Sub::HandlesVia::Declare 'num', [ 'Number', 'Scalar' ] => (
  ...,
);
