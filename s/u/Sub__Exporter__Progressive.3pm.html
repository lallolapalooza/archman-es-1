NOMBRE

Sub::Exporter::Progressive - Usa Sub::Exporter solo si lo necesitas

VERSIÓN

versión 0.001013

SINOPSIS

package Syntax::Keyword::Gather;
use Sub::Exporter::Progressive -setup => {
  exports => [qw( break gather gathered take )],
  groups => {
    default => [qw( break gather gathered take )],
  },
};
# en otro lugar
# usa Exporter para velocidad
use Syntax::Keyword::Gather;
# en otro lugar
# usa Sub::Exporter para características
use Syntax::Keyword::Gather 'gather', take => { -as => 'grab' };

DESCRIPCIÓN

Sub::Exporter es un módulo increíblemente potente, pero con ese poder viene una gran responsabilidad, er... así como algunas penalizaciones en tiempo de ejecución. Este módulo es un envoltorio de "Sub::Exporter" que permitirá a tus usuarios usar solo Exporter si solo están eligiendo exportaciones, pero usará "Sub::Exporter" si tus usuarios intentan usar las características más avanzadas de "Sub::Exporter", como renombrar exportaciones, si intentan usarlas.

Ten en cuenta que este módulo exportará las variables de paquete @EXPORT, @EXPORT_OK y %EXPORT_TAGS para que "Exporter" funcione. Además, si tu paquete utiliza características avanzadas de "Sub::Exporter" como currying, este módulo solo usará "Sub::Exporter", por lo que podrías usarlo directamente.
