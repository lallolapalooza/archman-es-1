Sub__HandlesVia__HandlerLibrary__Enum(3pm)

Paquete: perl-sub-handlesvia

Sub::HandlesVia::HandlerLibrary::Enum(3) Documentación de Perl aportada por el usuario Sub::HandlesVia::HandlerLibrary::Enum(3)

NOMBRE

Sub::HandlesVia::HandlerLibrary::Enum - biblioteca de métodos relacionados con enumeraciones

SINOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Enum';
  has status => (
    is => 'ro',
    isa => Enum[ 'pass', 'fail' ],
    handles_via => 'Enum',
    handles => {
      'is_pass'      => [ is     => 'pass' ],
      'is_fail'      => [ is     => 'fail' ],
      'assign_pass'  => [ assign => 'pass' ],
      'assign_fail'  => [ assign => 'fail' ],
    },
    default => sub { 'fail' },
  );
}

O, usando un atajo:

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Enum';
  has status => (
    is => 'ro',
    isa => Enum[ 'pass', 'fail' ],
    handles_via => 'Enum',
    handles => {
      'is_pass'      => 'is_pass',
      'is_fail'      => 'is_fail',
      'assign_pass'  => 'assign_pass',
      'assign_fail'  => 'assign_fail',
    },
    default => sub { 'fail' },
  );
}

(Sub::HandlesVia::HandlerLibrary::Enum dividirá por "_").

DESCRIPCIÓN

Esta es una biblioteca de métodos para Sub::HandlesVia.

MÉTODOS DELEGABLES

Esto permite la delegación más o menos compatible con MooseX::Enumeration y MooX::Enumeration, aunque básicamente sea un subconjunto renombrado de Sub::HandlesVia::HandlerLibrary::String de todos modos.

is( $valor )

Devuelve un booleano que indica si la enumeración es ese valor.

my $object = My::Class->new( status => 'pass' );
say $object->is_pass(); ## ==> true
say $object->is_fail(); ## ==> false

assign( $valor )

Establece la enumeración al valor.

my $object = My::Class->new( status => 'pass' );
say $object->is_pass(); ## ==> true
say $object->is_fail(); ## ==> false
$object->assign_fail();
say $object->is_pass(); ## ==> false
say $object->is_fail(); ## ==> true

set( $valor )

Un alias para "assign".

ATyilda DE RESTRICCIÓN DE TIPO

La biblioteca de manejo Enum también permite un atajo "enum" en la especificación del atributo.

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  has status => (
    is          => 'ro',
    enum        => [ 'pass', 'fail' ],
    handles_via => 'Enum',
    handles     => {
      'is_pass'      => [ is     => 'pass' ],
      'is_fail'      => [ is     => 'fail' ],
      'assign_pass'  => [ assign => 'pass' ],
      'assign_fail'  => [ assign => 'fail' ],
    },
    default     => sub { 'fail' },
  );
}

CONSTANTES DE ATyilda

Este módulo proporciona algunas constantes de atajo para indicar una lista de delegaciones.

package My::Class {
  use Moo;
  use Types::Standard qw( Enum );
  use Sub::HandlesVia;
  use Sub::HandlesVia::HandlerLibrary::Enum qw( HandleIs );
  has status => (
    is          => 'ro',
    isa         => Enum[ 'pass', 'fail' ],
    handles_via => 'Enum',
    handles     => HandleIs,
    default     => sub { 'fail' },
  );
}

Cualquiera de estos atajos puede combinarse usando el operador " | ".

has status => (
  is          => 'ro',
  isa         => Enum[ 'pass', 'fail' ],
  handles_via => 'Enum',
  handles     => HandleIs | HandleSet,
  default     => sub { 'fail' },
);

"HandleIs"

Crea delegaciones con nombres como "is_pass" y "is_fail".

"HandleNamedIs"

Crea delegaciones con nombres como "status_is_pass" y "status_is_fail".

"HandleSet"

Crea delegaciones con nombres como "set_pass" y "set_fail".

"HandleNamedSet"

Crea delegaciones con nombres como "status_set_pass" y "status_set_fail".
