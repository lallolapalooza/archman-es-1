Sub::Name(3) Documentación aportada por el usuario de Perl Sub::Name(3)

NOMBRE

Sub::Name - (Re)nombrar un sub

VERSIÓN

versión 0.28

SINOPSIS

use Sub::Name;
subname $nombre, $subref;
$subref = subname foo => sub { ... };

DESCRIPCIÓN

Este módulo tiene una sola función, que también se exporta por defecto:

subname NOMBRE, CODEREF

Asigna un nuevo nombre a la sub referenciada. Si se omite la especificación del paquete en el nombre, se usa el paquete actual. El valor de retorno es la sub.

El nombre solo se utiliza para rutinas informativas (caller, Carp, etc.). No podrás invocar realmente la sub con el nombre dado. Para permitirlo, debes hacer la asignación de globos tú mismo.

Ten en cuenta que para los cierres anónimos (subs que hacen referencia a léxicos declarados fuera de la propia sub) puedes nombrar cada instancia del cierre de forma diferente, lo que puede ser muy útil para la depuración.

VER TAMBIÉN

  • Sub::Identify - para obtener información sobre subs
  • Sub::Util - set_subname es otra implementación de "subname"
