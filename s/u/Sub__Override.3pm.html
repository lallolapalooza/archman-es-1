Sub::Override(3) Documentación de Perl aportada por el usuario Sub::Override(3)

NOMBRE

Sub::Override - Extensión de Perl para sobrescribir fácilmente subrutinas

VERSIÓN

0.12

SINOPSIS

use Sub::Override;
sub foo { 'subrutina original' };
print foo(); # imprime 'subrutina original'
my $override = Sub::Override->new( foo => sub { 'subrutina sobrescrita' } );
print foo(); # imprime 'subrutina sobrescrita'
$override->restore;
print foo(); # imprime 'subrutina original'

DESCRIPCIÓN

El problema

A veces las subrutinas necesitan ser sobrescritas. De hecho, tu autor hace esto frecuentemente para pruebas. Particularmente al probar, usar un Objeto Mock puede ser excesivo cuando todo lo que quieres hacer es sobrescribir una pequeña y minúscula función.

Sobrescribir una subrutina a menudo se hace con una sintaxis similar a la siguiente.

{
  local *Some::sub = sub {'un cierto comportamiento'};
  # haz algo
}
# comportamiento original de la subrutina restaurado

Esto tiene algunos problemas.

{
  local *Get::some_feild = { 'un cierto comportamiento' };
  # haz algo
}

En el ejemplo anterior, no solo hemos escrito mal el nombre de la subrutina, sino que incluso si hubiera habido una subrutina con ese nombre, no la hemos sobrescrito. Estos dos errores pueden ser sutiles de detectar.

Además, si estamos intentando localizar el efecto colocando este código en un bloque, todo el constructo es engorroso.

Hook::LexWrap también nos permite sobrescribir el comportamiento de las subrutinas, pero nunca recuerdo la sintaxis exacta.

Una forma más fácil de reemplazar subrutinas

En su lugar, "Sub::Override" permite al programador simplemente nombrar la subrutina a reemplazar y proporcionar una subrutina para reemplazarla.

my $override = Sub::Override->new('Some::sub', sub {'nuevos datos'});
# lo cual es equivalente a:
my $override = Sub::Override->new;
$override->replace('Some::sub', sub { 'nuevos datos' });

Puedes reemplazar múltiples subrutinas, si es necesario:

$override->replace('Some::sub1', sub { 'nuevos datos1' });
$override->replace('Some::sub2', sub { 'nuevos datos2' });
$override->replace('Some::sub3', sub { 'nuevos datos3' });

Si el reemplazo de la subrutina tiene éxito, se devuelve el objeto. Esto permite al programador encadenar las llamadas, si se prefiere este estilo de programación:

$override->replace('Some::sub1', sub { 'nuevos datos1' })
         ->replace('Some::sub2', sub { 'nuevos datos2' })
         ->replace('Some::sub3', sub { 'nuevos datos3' });

Si la subrutina tiene un prototipo, la nueva subrutina debe declararse con el mismo prototipo que la original:

$override->replace('Some::sub_with_proto', sub ($$) { ($_[0], $_ [1]) });

Una subrutina puede ser reemplazada tantas veces como se desee. Esto es muy útil cuando se prueba cómo se comporta el código con múltiples condiciones.

$override->replace('Some::thing', sub { 0 });
is($object->foo, 'wibble', 'se devuelve wibble si Some::thing es falso');
$override->replace('Some::thing', sub { 1 });
is($object->foo, 'puppies', 'se devuelven puppies si Some::thing es verdadero');

Inyectando una subrutina

Si quieres inyectar una subrutina en un paquete, puedes usar el método inject(). Esto es idéntico a replace(), excepto que requiere que la subrutina no exista:

$override->inject('Some::sub', sub {'nuevos datos'});

Esto es útil si quieres añadir una subrutina a un paquete que aún no la tiene.

Si intentas inyectar una subrutina que ya existe, se lanzará una excepción.

$override->inject('Some::sub', sub {'nuevos datos'}); # funciona
$override->inject('Some::sub', sub {'nuevos datos'}); # lanza una excepción

Llamar a restore() o permitir que $override salga del alcance eliminará la subrutina inyectada.

$override->inject('Some::sub', sub {'nuevos datos'});
$override->restore('Some::sub'); # elimina la subrutina inyectada

Heredando una subrutina

Similar a 'inject', 'inherit' solo te permitirá crear una nueva subrutina en un objeto hijo que herede la rutina del padre, y que no exista en el hijo:

package Parent;
sub foo {}
sub bar {}
package Child;
use parent 'Parent';
sub foo {}

'Inherit' te permitirá configurar una nueva subrutina 'Child::bar' ya que se hereda de Parent. Intentar 'inherit' 'Child::foo' lanzará una excepción ya que 'foo' ya existe en Child. De manera similar, intentar 'inherit' una nueva subrutina 'something' en Child también lanzará una excepción ya que no existe en Parent y no será heredada por Child.

Envolviendo una subrutina

Puede haber ocasiones en las que quieras reemplazar 'condicionalmente' una subrutina - por ejemplo, para sobrescribir la subrutina original solo si se pasan ciertos argumentos. Para esto puedes especificar "wrap" en lugar de "replace". "wrap" es idéntico a "replace", excepto que la subrutina original se pasa como el primer argumento a tu nueva subrutina. Puedes llamar a la sub original a través de 'shift->(@_)':

$override->wrap('Some::sub',
  sub {
    my ($old_sub, @args) = @_;
    return 1 if $args[0];
    return $old_sub->(@args);
  }
);

Restaurando subrutinas

Si el objeto sale del alcance, las subrutinas originales se restauran. Sin embargo, si necesitas restaurar una subrutina temprano, simplemente usa el método restore():

my $override = Sub::Override->new('Some::sub', sub {'nuevos datos'});
# haz cosas
$override->restore;

Lo cual es algo equivalente a:

{
  my $override = Sub::Override->new('Some::sub', sub {'nuevos datos'});
  # haz cosas
}

Si has sobrescrito más de una subrutina con un objeto override, tendrás que nombrar explícitamente la subrutina que deseas restaurar:

$override->restore('This::sub');

Nota que restore() siempre restaurará el comportamiento original de la subrutina sin importar cuántas veces la hayas sobrescrito.

¿En qué paquete está la subrutina?

Normalmente, quieres calificar completamente la subrutina incluyendo el nombre del paquete. Sin embargo, no calificar completamente el nombre de la subrutina asumirá el paquete actual.

package Foo;
use Sub::Override;
sub foo { 23 };
my $override = Sub::Override->new( foo => sub { 42 } ); # asume Foo::foo
print foo(); # imprime 42
$override->restore;
print foo(); # imprime 23

MÉTODOS

new

my $sub = Sub::Override->new;
my $sub = Sub::Override->new($sub_name, $sub_ref);

Crea una nueva instancia de "Sub::Override". Opcionalmente, puedes sobrescribir una subrutina mientras creas un nuevo objeto.

replace

$sub->replace($sub_name, $sub_body);

Reemplaza temporalmente una subrutina con otra subrutina. Devuelve la instancia, por lo que se permiten encadenar métodos:

$sub->replace($sub_name, $sub_body)
    ->replace($another_sub, $another_body);

Este método hará "croak" si la subrutina a reemplazar no existe.

override

my $sub = Sub::Override->new;
$sub->override($sub_name, $sub_body);

"override" es un nombre alternativo para "replace". Son el mismo método.

NAME

Sub::Override - Override subroutines, temporarily or permanently

VERSION

0.12

SYNOPSIS

 use Sub::Override;

 # To override a sub:
 my $sub = Sub::Override->new( 'Foo::bar' => sub { 'hello' } );

 # To replace it with a different sub:
 $sub->replace( 'Foo::bar' => sub { 'world' } );

 # To temporarily inject a sub:
 my $original_sub = Sub::Override->new;
 $original_sub->inject( 'Foo::bar' => sub { 'test' } );

 # To inherit a sub from a parent class:
 my $sub_inherit = Sub::Override->new;
 $sub_inherit->inherit( 'Foo::bar' => sub { 'inherited' } );

 # To wrap a sub:
 my $sub_wrap = Sub::Override->new;
 $sub_wrap->wrap( 'Foo::bar' => sub {
    my $orig = shift;
    my $result = $orig->(@_);
    return "wrapped $result";
 });

 # Restore the original sub (or automatically when $sub goes out of scope)
 $sub->restore;

DESCRIPTION

This module allows you to override subroutines in any package. This is useful for testing, for changing behavior on the fly, and for overriding methods in modules you don't want to modify.

You can also inherit subs from parent classes, wrap subs, and inject subs.

The overridden subroutine is automatically restored when the "Sub::Override" object falls out of scope, or you can manually restore it using the restore method.

METHODS

new

my $sub = Sub::Override->new(
    'Package::Name::sub_name' => $subref_or_coderef,
    'Another::Package::sub_name' => $subref_or_coderef,
    ...
);

Creates a new "Sub::Override" object. Takes a hash of subroutine names to subroutine references (or coderefs).

my $sub = Sub::Override->new( 'Foo::bar' => sub { 'hello' } );

replace

$sub->replace($sub_name, $sub_body);

Replaces the current subroutine override with a new one. This is useful if you need to change the behavior of an already overridden subroutine.

my $sub = Sub::Override->new( 'Foo::bar' => sub { 'first' } );
# ... later ...
$sub->replace( 'Foo::bar' => sub { 'second' } );

inject

$sub->inject($sub_name, $sub_body);

Temporarily injects a subroutine into a package. Returns the instance, so chaining the method is allowed:

$sub->inject($sub_name, $sub_body)
    ->inject($another_sub, $another_body);

inherit

$sub->inherit($sub_name, $sub_body);

Checks that the subroutine exists in a parent class, but not in the current class, and injects it into the current class to inherit the parent's version.

restore

$sub->restore($sub_name);

Restores the previous behavior of the subroutine. This will happen automatically if the "Sub::Override" object falls out of scope.

wrap

$sub->wrap($sub_name, $sub_body);

Temporarily wraps a subroutine with another subroutine. The original subroutine is passed as the first arg to the new subroutine.

EXPORT

None by default.

CAVEATS

If you need to override the same sub several times do not create a new "Sub::Override" object, but instead always reuse the existing one and call "replace" on it. Creating a new object to override the same sub will result in weird behavior.

# Do not do this!
my $sub_first = Sub::Override->new( 'Foo:bar' => sub { 'first' } );
my $sub_second = Sub::Override->new( 'Foo::bar' => sub { 'second' } );
# Do not do this either!
my $sub = Sub::Override->new( 'Foo::bar' => sub { 'first' } );
$sub = Sub::Override->new( 'Foo::bar' => sub { 'second' } );

Both of those usages could result in of your subs being lost, depending on the order in which you restore them.

Instead, call "replace" on the existing $sub.

my $sub = Sub::Override->new( 'Foo::bar' => sub { 'first' } );
$sub->replace( 'Foo::bar' => sub { 'second' } );
