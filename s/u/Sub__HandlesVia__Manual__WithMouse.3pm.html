NOMBRE

Sub::HandlesVia::Manual::WithMouse - usar Sub::HandlesVia con Mouse

SINOPSIS

package Kitchen {
  use Mouse;
  use Sub::HandlesVia;
  use Types::Standard qw( ArrayRef Str );

  has food => (
    is          => 'ro',
    isa         => ArrayRef[Str],
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

(Si tienes un ratón en tu cocina, eso podría no ser muy higiénico.)

MANUAL

Sub::HandlesVia te permite delegar métodos de tu clase a los valores de los atributos de tus objetos.

Conceptualmente, te permite definir "$object->push_number($n)" como un atajo para "$object->numbers->push($n)", excepto que "$object->numbers" es un arrayref, por lo que no tiene métodos que puedas llamar sobre él como "push".

Deberías poder usar Sub::HandlesVia como un reemplazo directo de MouseX::NativeTraits, simplemente reemplazando "traits => ['Array']" en una definición de atributo con "handles_via => 'Array'".

Uso en roles de Mouse

Los roles de Mouse solo se admiten parcialmente.

package R1 {
  use Mouse:Role;
}

package R2 {
  use Mouse:Role;
  use Sub::HandlesVia;

  # definir algunos atributos con delegación
}

# Esta clase está rota.
package C1 {
  use Mouse;
  with 'R1', 'R2';
}

# Esta clase debería funcionar.
package C2 {
  use Mouse;
  with 'R1';
  with 'R2';
}

Para más detalles, consulta https://github.com/tobyink/p5-sub-handlesvia/issues/9.

¡Los parches para solucionar el problema son muy bienvenidos!

¿Qué métodos pueden ser delegados?

La opción "handles_via" indica qué biblioteca de métodos debe estar disponible. Los valores válidos incluyen Array, Blessed, Bool, Code, Counter, Enum, Hash, Number, Scalar y String.

Se puede proporcionar un arrayref para "handles_via", aunque muchas de las opciones son conceptualmente contradictorias.

handles_via => [ 'Number', 'Scalar' ]

Tipos nativos de Mouse

Aunque la sinopsis muestra el uso de Types::Standard para las restricciones de tipos, los tipos nativos de Mouse también deberían funcionar bien.

package Kitchen {
  use Mouse;
  use Sub::HandlesVia;

  has food => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

Sintaxis directa verdadera de MouseX::NativeTraits

Sub::HandlesVia también reconocerá la sintaxis de MouseX::NativeTraits para "traits". ¡Se interpondrá y las manejará antes de que MouseX::NativeTraits se dé cuenta!

package Kitchen {
  use Mouse;
  use Sub::HandlesVia;

  has food => (
    is          => 'ro',
    isa         => 'ArrayRef[Str]',
    traits      => ['Array'],
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}
