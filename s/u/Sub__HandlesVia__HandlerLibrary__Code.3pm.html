Sub::HandlesVia::HandlerLibrary::Code(3) Documentación de Perl aportada por el usuario Sub::HandlesVia::HandlerLibrary::Code(3)

NOMBRE

Sub::HandlesVia::HandlerLibrary::Code - biblioteca de métodos relacionados con el código

SINOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'CodeRef';
  has attr => (
    is => 'rwp',
    isa => CodeRef,
    handles_via => 'Code',
    handles => {
      'my_execute' => 'execute',
      'my_execute_list' => 'execute_list',
      'my_execute_method' => 'execute_method',
      'my_execute_method_list' => 'execute_method_list',
      'my_execute_method_scalar' => 'execute_method_scalar',
      'my_execute_method_void' => 'execute_method_void',
      'my_execute_scalar' => 'execute_scalar',
      'my_execute_void' => 'execute_void',
    },
  );
}

DESCRIPCIÓN

Esta es una biblioteca de métodos para Sub::HandlesVia.

MÉTODOS DELEGABLES

execute( @args )

Llama al coderef, pasándole cualquier argumento.

my $coderef = sub { 'código' };
my $object  = My::Class->new( attr => $coderef );

# Llama a: $coderef->( 1, 2, 3 )
$object->my_execute( 1, 2, 3 );

execute_list( @args )

Llama al coderef, pasándole cualquier argumento, y forzando contexto de lista. Si se llama en contexto escalar, devuelve un arrayref.

my $context;
my $coderef = sub { $context = wantarray(); 'código' };
my $object  = My::Class->new( attr => $coderef );

# Llama a: $coderef->( 1, 2, 3 )
my $result = $object->my_execute_list( 1, 2, 3 );

say Dumper( $result );  ## ==> [ 'código' ]
say $context;           ## ==> true

execute_method( @args )

Llama al coderef como si fuera un método, pasándole cualquier argumento.

my $coderef = sub { 'código' };
my $object  = My::Class->new( attr => $coderef );

# Llama a: $coderef->( $object, 1, 2, 3 )
$object->my_execute_method( 1, 2, 3 );

execute_method_list( @args )

Llama al coderef como si fuera un método, pasándole cualquier argumento, y forzando contexto de lista. Si se llama en contexto escalar, devuelve un arrayref.

my $context;
my $coderef = sub { $context = wantarray(); 'código' };
my $object  = My::Class->new( attr => $coderef );

# Llama a: $coderef->( $object, 1, 2, 3 )

execute_method_scalar( @args )

Llama al coderef como si fuera un método, pasándole cualquier argumento, y forzando contexto escalar.

EJEMPLOS EXTENDIDOS

Usando execute_method

El manejador execute_method permite a una clase proporcionar efectivamente ciertos métodos que pueden ser sobrescritos por parámetros en el constructor.

use strict;
use warnings;
use Data::Dumper;

package My::Processor {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard qw( Str CodeRef );

  has name => (
    is => 'ro',
    isa => Str,
    default => 'Proceso Principal',
  );

  my $NULL_CODEREF = sub {};

  has _debug => (
    is => 'ro',
    isa => CodeRef,
    handles_via => 'Code',
    handles => { debug => 'execute_method' },
    default => sub { $NULL_CODEREF },
    init_arg => 'debug',
  );

  sub _do_stuff {
    my $self = shift;
    $self->debug( 'continuando proceso' );
    return;
  }

  sub run_process {
    my $self = shift;
    $self->debug( 'iniciando proceso' );
    $self->_do_stuff;
    $self->debug( 'finalizando proceso' );
  }
}

my $p1 = My::Processor->new( name => 'Primer Proceso' );
$p1->run_process; # sin salida

my @got;
my $p2 = My::Processor->new(
  name => 'Segundo Proceso',
  debug => sub {
    my ( $processor, $message ) = @_;
    push @got, sprintf( '%s: %s', $processor->name, $message );
  },
);
$p2->run_process; # salida registrada

my @expected = (
  'Segundo Proceso: iniciando proceso',
  'Segundo Proceso: continuando proceso',
  'Segundo Proceso: finalizando proceso',
);
say Dumper( \@got ); ## ==> \@expected
