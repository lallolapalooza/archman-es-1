Sub::HandlesVia(3) Documentación de Perl aportada por el usuario Sub::HandlesVia(3)

NOMBRE

Sub::HandlesVia - implementación alternativa de handles_via

SINOPSIS

package Kitchen {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard qw( ArrayRef Str );

  has food => (
    is          => 'ro',
    isa         => ArrayRef[Str],
    handles_via => 'Array',
    default     => sub { [] },
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}
my $kitchen = Kitchen->new;
$kitchen->add_food('Bacon');
$kitchen->add_food('Eggs');
$kitchen->add_food('Sausages');
$kitchen->add_food('Beans');

my @foods = $kitchen->find_food(sub { /^B/i });

DESCRIPCIÓN

Si ya has usado los rasgos de atributos nativos de Moose, o MooX::HandlesVia antes, deberías tener una idea bastante clara de lo que hace esto.

¿Por qué reinventar la rueda? Bueno, esta es una implementación que debería funcionar bien con Moo, Moose, Mouse y cualquier otro kit de herramientas OO que le lances. Un anillo para gobernarlos a todos, por así decirlo.

Para obtener detalles sobre cómo usarlo, consulta el manual.

Sub::HandlesVia::Manual::WithMoo

Sub::HandlesVia::Manual::WithMoose
Cómo usar Sub::HandlesVia con Moose y Moose::Role.
Sub::HandlesVia::Manual::WithMouse
Cómo usar Sub::HandlesVia con Mouse y Mouse::Role.
Sub::HandlesVia::Manual::WithMite
Cómo usar Sub::HandlesVia con Mite.
Sub::HandlesVia::Manual::WithClassTiny
Cómo usar Sub::HandlesVia con Class::Tiny.
Sub::HandlesVia::Manual::WithObjectPad
Cómo usar Sub::HandlesVia con clases Object::Pad.
Sub::HandlesVia::Manual::WithGeneric
Cómo usar Sub::HandlesVia con otros kits de herramientas OO y clases Perl escritas a mano.

Nota: como Sub::HandlesVia necesita detectar qué kit de herramientas estás utilizando, y a menudo necesita detectar si tu paquete es una clase o un rol, debe cargarse después de Moo/Moose/Mouse/etc. Tu "use Moo" o "use Moose::Role" o lo que sea, debe ir antes de tu "use Sub::HandlesVia".

VER TAMBIÉN

Guías de uso con diferentes kits de herramientas OO: Sub::HandlesVia::Manual::WithMoo, Sub::HandlesVia::Manual::WithMoose, Sub::HandlesVia::Manual::WithMouse, Sub::HandlesVia::Manual::WithMite, Sub::HandlesVia::Manual::WithClassTiny, Sub::HandlesVia::Manual::WithObjectPad, Sub::HandlesVia::Manual::WithGeneric.

Documentación para métodos delegables: Sub::HandlesVia::HandlerLibrary::Array, Sub::HandlesVia::HandlerLibrary::Blessed, Sub::HandlesVia::HandlerLibrary::Bool, Sub::HandlesVia::HandlerLibrary::Code, Sub::HandlesVia::HandlerLibrary::Counter, Sub::HandlesVia::HandlerLibrary::Enum, Sub::HandlesVia::HandlerLibrary::Hash, Sub::HandlesVia::HandlerLibrary::Number, Sub::HandlesVia::HandlerLibrary::Scalar, y Sub::HandlesVia::HandlerLibrary::String.

Otras implementaciones del mismo concepto: Moose::Meta::Attribute::Native, MouseX::NativeTraits, y MooX::HandlesVia con Data::Perl.

Comparación de estos: Sub::HandlesVia::Manual::Comparison

Sub::HandlesVia::Declare es una ayuda para declarar delegaciones de Sub::HandlesVia en tiempo de compilación, útil para Object::Pad y (en menor medida) Class::Tiny.
