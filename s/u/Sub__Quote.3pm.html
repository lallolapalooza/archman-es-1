NOMBRE

Sub::Quote - Generación eficiente de subrutinas mediante eval de cadenas

SINOPSIS

package Silly;
use Sub::Quote qw(quote_sub unquote_sub quoted_from_sub);
quote_sub 'Silly::kitty', q{ print "meow" };
quote_sub 'Silly::doggy', q{ print "woof" };
my $sound = 0;
quote_sub 'Silly::dagron',
  q{ print ++$sound % 2 ? 'burninate' : 'roar' },
  { '$sound' => \$sound };

Y en otros lugares:

Silly->kitty;  # meow
Silly->doggy;  # woof
Silly->dagron; # burninate
Silly->dagron; # roar
Silly->dagron; # burninate

DESCRIPCIÓN

Este paquete proporciona formas eficientes de generar subrutinas a partir de cadenas.

SUBRUTINAS

quote_sub

my $coderef = quote_sub 'Foo::bar', q{ print $x++ . "\n" }, { '$x' => \0 };

Argumentos: ?$name, $code, ?\%captures, ?\%options

$name es la subrutina donde se instalará el coderef.

$code es una cadena que se convertirá en código.

"\%captures" es un hashref de variables que estarán disponibles para el código. Las claves deben ser el nombre completo de la variable que se pondrá a disposición, incluido el sigilo. Los valores deben ser referencias a los valores. Las variables contendrán copias de los valores. Consulte la "Silly::dagron" en la "SINOPSIS" para ver un ejemplo de uso de capturas.

Exportado por defecto.

options

"no_install"
Booleano. Establezca esta opción para no instalar el coderef generado en el nombre de subrutina proporcionado en undefer.
"no_defer"
Booleano. Evita que se genere un envoltorio Sub::Defer para la sub entrecomillada. Si es muy probable que la sub se llame en algún momento, establecer esto es una buena idea. Para una sub que probablemente se incrustará, no se recomienda.
"package"
El paquete en el que se evaluará la sub entrecomillada. Si no se especifica, se utilizará el paquete de la sub que llama a "quote_sub".
"hints"
El valor de $^H para usar en el código que se está evaluando. Esto captura la configuración de la pragmática strict. Si no se especifica, se utilizará el valor del código que llama.
"warning_bits"
El valor de "${^WARNING_BITS}" para usar en el código que se está evaluando. Esto captura las advertencias establecidas. Si no se especifica, se utilizarán las advertencias del código que llama.
"hintshash"
El valor de "%^H" para usar en el código que se está evaluando. Esto captura configuraciones adicionales de pragmáticas. Si no se especifica, se utilizará el valor del código que llama si es posible (en perl 5.10+).
"attributes"
Los "Atributos de subrutina" en perlsub para aplicar a la sub generada. Debe especificarse como una referencia de arreglo. Los atributos se aplicarán tanto a la sub generada como al envoltorio diferido, si se utiliza uno.
"file"
El nombre de archivo aparente a utilizar para el código que se está evaluando.
"line"
El número de línea aparente a utilizar para el código que se está evaluando.

unquote_sub

my $coderef = unquote_sub $sub;

Reemplaza forzosamente la subrutina con código real.

Si $sub no es una sub entrecomillada, no hace nada.

Exportado por defecto.

quoted_from_sub

my $data = quoted_from_sub $sub;
my ($name, $code, $captures, $compiled_sub) = @$data;

Devuelve los argumentos originales para quote_sub, además de la versión compilada si esta sub ya ha sido descifrada.

Tenga en cuenta que $sub puede ser la versión entrecomillada original o la versión compilada para mayor conveniencia.

Exportado por defecto.

inlinify

my $prelude = capture_unroll '$captures', {
  '$x' => 1,
  '$y' => 2,
}, 4;
my $inlined_code = inlinify q{
  my ($x, $y) = @_;
  print $x + $y . "\n";
}, '$x, $y', $prelude;

Toma una cadena de código, una cadena de argumentos, una cadena de código que actúa como un "prelude" y un Booleano que indica si se deben localizar los argumentos.

quotify

my $quoted_value = quotify $value;

Entrecomilla un único valor escalar (no de referencia) para su uso en una cadena de código. El resultado debe reproducir el valor original, incluyendo cadenas, undef, enteros y números de punto flotante. Los números de punto flotante resultantes (incluidos infinitos y no un número) deben ser precisamente iguales al original, si es posible. El formato exacto del número resultante no debe ser fiable, ya que puede incluir flotantes hexadecimales o expresiones matemáticas.

capture_unroll

my $prelude = capture_unroll '$captures', {
  '$x' => 1,
  '$y' => 2,
}, 4;

Argumentos: $from, \%captures, $indent

Genera un fragmento de código adecuado para ser utilizado como prelude para "inlinify". $from es una cadena que se utilizará como hashref en el código resultante. Las claves de %captures son los nombres de las variables y los valores se ignoran. $indent es el número de espacios con los que se indentará el resultado.

qsub

my $hash = {
 coderef => qsub q{ print "hello"; },
 other   => 5,
};

Argumentos: $code

Funciona exactamente como "quote_sub", pero incluye un prototipo para aceptar solo un parámetro. Esto facilita su inclusión en estructuras hash o listas.

Exportado por defecto.

sanitize_identifier

my $var_name = '$variable_for_' . sanitize_identifier('@name');
quote_sub qq{ print \$${var_name} }, { $var_name => \$value };

Argumentos: $identifier

Sanea un valor para que pueda usarse en un identificador.

AMBIENTE

SUB_QUOTE_DEBUG

Hace que el código se envíe a "STDERR" antes de ser evaluado. Se admiten varias formas:

1
Se enviarán todas las subs.
"/foo/"
Las subs se enviarán si su código coincide con la expresión regular dada.
"simple_identifier"
Se enviará cualquier sub con el nombre dado.
"Full::identifier"
Se enviará una sub que coincida con el nombre completo.
"Package::Name::"
Se enviará cualquier sub en el paquete dado (incluidas las subs anónimas).

CAVEATS

Gran parte de esto es simplemente generación de código basada en cadenas y, como resultado, se aplican algunas advertencias.

return

Llamar a "return" desde una sub entrecomillada con quote_sub probablemente no hará lo que usted pretende. En lugar de devolver el código que definió en "quote_sub", devolverá de la función general en la que está compuesta.

Por lo tanto, cuando pase:

quote_sub q{  return 1 if $condition; $morecode }

Podría aparecer en el contexto previsto de la siguiente manera:

sub foo {
  <important code a>
  do {
    return 1 if $condition;
    $morecode
  };
  <important code b>
}

Lo que obviamente devolverá desde foo, cuando todo lo que pretendía era devolver

Sub::Quote(3pm)

NAME

Sub::Quote ‐ create subroutines quoting their environment

SYNOPSIS

  use Sub::Quote;

  my $q = quote_sub { print "hello\n" };
  $q->();

  my $var = 42;
  my $q2 = quote_sub { print "The answer is $var\n" };
  $q2->();

DESCRIPTION

This module allows you to create closures that quote their environment. This is useful for creating code that behaves as if it were defined at the point where quote_sub is called, rather than where the subroutine is actually invoked.

This means that variables in the scope where quote_sub is called will be available to the created subroutine, even if that subroutine is called from a different scope.

SUBROUTINES

quote_sub
Takes a block of code as an argument and returns a subroutine reference. This subroutine will execute the provided code block in the environment where quote_sub was called.

ENVIRONMENT

The created subroutines capture the lexical environment of the point where quote_sub is called. This includes lexical variables, package variables, and any other lexical state.

CAVEATS

When inlining Sub::Quote subs, care should be taken that user pragmas won't affect the rest of the code.

The use of quote_sub can lead to subtle bugs if not used carefully. It's important to understand how lexical scope and closures work in Perl to avoid unexpected behavior.

Be aware of the scope of variables captured by quote_sub. If a variable goes out of scope before the quoted sub is called, accessing that variable within the sub may lead to undefined behavior.

Consider the performance implications. Creating quoted subs might incur some overhead compared to regular subroutines. Profile your code if performance is critical.

The Sub::Quote module preserves the environment of the code creating the quoted subs. This includes the package, strict, warnings, and any other lexical pragmas. This is done by prefixing the code with a block that sets up a matching environment. When inlining Sub::Quote subs, care should be taken that user pragmas won't affect the rest of the code.
