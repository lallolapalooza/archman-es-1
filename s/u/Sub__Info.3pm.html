Sub::Info(3) Documentación aportada por el usuario en Perl Sub::Info(3)

NOMBRE

Sub::Info - Herramienta para inspeccionar subrutinas.

DESCRIPCIÓN

Herramienta para inspeccionar subrutinas.

EXPORTA

Todas las exportaciones son opcionales, debes especificar las subs a importar.

mi $hr = sub_info(\&code)
mi $hr = sub_info(\&code, @numeros_linea)
Esto devuelve un hashref con información sobre la sub: 
{
    ref        => \&code,
    cobj       => $cobj,
    name       => "Some::Mod::code",
    file       => "Some/Mod.pm",
    package    => "Some::Mod",
    # Nota: Estos han sido ajustados basándose en suposiciones.
    start_line => 22,
    end_line   => 42,
    lines      => [22, 42],
    # ¡No es un error, estas líneas son diferentes!
    all_lines  => [23, 25, ..., 39, 41],
};
$info->{ref} => \&code
Esta es la sub original pasada a sub_info().
$info->{cobj} => $cobj
Esta es la representación de objeto C del coderef.
$info->{name} => "Some::Mod::code"
Este es el nombre del coderef. Para coderefs anónimos, puede terminar con '__ANON__'. También ten en cuenta que el paquete 'main' es especial, y 'main::' puede omitirse.
$info->{file} => "Some/Mod.pm"
El archivo en el que se definió la sub.
$info->{package} => "Some::Mod"
El paquete en el que se definió la sub.
$info->{start_line} => 22
$info->{end_line} => 42
$info->{lines} => [22, 42]
Estos tres campos son la línea de inicio, la línea de fin y el array con ambas, *ajustados*. Es importante notar que estas líneas han sido ajustadas y pueden no ser precisas.

Las líneas se obtienen recorriendo los ops. Como tal, la primera línea es la línea de la primera sentencia, y la última línea es la línea de la última sentencia. Esto significa que en subs multilínea, las líneas generalmente están desfasadas en 1. Las líneas en estas claves serán ajustadas por ti si detecta una sub multilínea.

$info->{all_lines} => [23, 25, ..., 39, 41]
Este es un array con las líneas de cada sentencia en la sub. A diferencia de los otros campos de línea, estos no han sido ajustados por ti.
