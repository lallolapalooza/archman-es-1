NOMBRE

SUPER - control de la distribución de métodos de superclase

SINOPSIS

Encuentra el método padre que se ejecutaría si este no estuviera aquí:

sub my_method
{
    my $self = shift;
    my $super = $self->super('my_method'); # ¿Quién es tu papá?
    if ($want_to_deal_with_this)
    {
        # ...
    }
    else
    {
        $super->($self, @_)
    }
}

O al estilo Ruby:

sub my_method
{
    my $self = shift;
    if ($want_to_deal_with_this)
    {
        # ...
    }
    else
    {
        super;
    }
}

O llama manualmente al método super, con respecto a la herencia, y pasando argumentos diferentes:

sub my_method
{
    my $self = shift;
    # el padre maneja los argumentos al revés
    $self->SUPER( reverse @_ );
}

DESCRIPCIÓN

Al crear subclases de una clase, ocasionalmente querrás enviar el control a la superclase, al menos condicionalmente y temporalmente. La sintaxis de Perl para llamar a tu superclase es fea y torpe:

$self->SUPER::method(@_);

especialmente en comparación con su equivalente en Ruby:

super;

Es aún peor en que el mecanismo normal de redispatch de Perl solo despacha al padre de la clase que contiene el método en tiempo de compilación. Eso no funciona muy bien para mixins y roles.

Este módulo proporciona equivalentes más agradables, junto con el método universal "super" para determinar la superclase propia de una clase. Esto te permite hacer cosas como:

goto &{$_[0]->super('my_method')};

si no te gusta desperdiciar preciosos marcos de pila.

Si estás usando roles o mixins o de alguna otra manera importando métodos de otros paquetes que necesitan enviar a sus métodos super, o si quieres pasar argumentos diferentes al método super, usa el método SUPER():

$self->SUPER( qw( otros argumentos aquí ) );

FUNCIONES y MÉTODOS

Este módulo proporciona las siguientes funciones y métodos:

super()
Esta función llama al método super del método que se está ejecutando actualmente, sin importar dónde se encuentre el método super en la jerarquía.

No toma argumentos; pasa los mismos argumentos que se pasaron al método que se está ejecutando actualmente.

El módulo exporta esta función por defecto.

Nota: debes tener la declaración "package" apropiada en su lugar para que esto funcione. Es decir, debes haber compilado el método en el que usas esta función en el paquete desde el cual quieres usarla. Así son las cosas con Perl 5.

"find_parent( $class, $method, $prune, $invocant )"
Intenta encontrar una implementación padre del $method comenzando con $class. Si pasas $prune, no ignorará el método encontrado en ese paquete, si existe allí. Pasa $invocant si el objeto en sí mismo podría tener una idea diferente de sus padres.

El módulo no exporta esta función por defecto. Llámala directamente.

"get_all_parents( $invocant, $class )"
Devuelve todos los padres del $invocant, si soporta el método "__get_parents()" o el contenido de @ISA para $class. Probablemente no deberías llamar a esto por tu cuenta.
SUPER()
Llama al método super del método que se está ejecutando actualmente. Puedes pasar argumentos. Este es un método.

NOTAS

Cuidado: si haces cosas extrañas con la generación de código, asegúrate de nombrar tus subrutinas anónimas. Ver Perl Hacks #57.

Usar "super" no te permite pasar argumentos alternativos al método de tu superclase. Si quieres pasar argumentos diferentes, usa "SUPER" en su lugar. ¡Duh!

Este módulo realiza una pequeña cantidad de Magia Negra para encontrar los argumentos del método que llama a super(). Esto puede confundir a herramientas como "Devel::Cover".

En tu propio código, si haces cosas complicadas con objetos proxy y similares, define "__get_parents()" para devolver una lista de todos los padres del objeto al que realmente quieres enviar.
