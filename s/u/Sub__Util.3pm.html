Sub::Util(3) Documentación de Perl aportada por el usuario Sub::Util(3)

NOMBRE

Sub::Util - Una selección de subrutinas de utilidad para subs y referencias CODE

SINOPSIS

use Sub::Util qw( prototype set_prototype subname set_subname );

DESCRIPCIÓN

"Sub::Util" contiene una selección de subrutinas de utilidad que son útiles para operar en subs y referencias CODE.

La razón para incluir esta función en este módulo es que realiza un trabajo para el cual una implementación XS es esencial porque no se puede implementar en Pure Perl, y que es lo suficientemente utilizado en CPAN como para que su popularidad justifique su inclusión en un módulo central, que este es.

FUNCIONES

prototype

my $proto = prototype( $code )

Desde la versión 1.40.

Devuelve el prototipo de la referencia de código $code dada, si lo tiene, como una cadena de texto. Esto es lo mismo que el operador "CORE::prototype"; se incluye aquí simplemente por simetría y completitud con las otras funciones.

set_prototype

my $code = set_prototype $prototype, $code;

Desde la versión 1.40.

Establece el prototipo de la función dada por la referencia $code, o lo elimina si $prototype es "undef". Devuelve la propia referencia $code.

Precaución: Esta función toma los argumentos en un orden diferente a la copia anterior del código de "Scalar::Util". Esto es para que coincida con el orden de "set_subname", y otras posibles adiciones en este archivo. Este orden ha sido elegido ya que permite una cadena nítida y simple de otras funciones "Sub::Util::set_*" que puedan estar disponibles, como:

my $code =
   set_subname   name_here =>
   set_prototype '&@'      =>
   set_attribute ':lvalue' =>
      sub { ...... };

subname

my $name = subname( $code )

Desde la versión 1.40.

Devuelve el nombre de la referencia de código $code dada, si lo tiene. Los subs con nombre normal darán un nombre completamente calificado que consiste en el paquete y el nombre local separados por "::". Las referencias de código anónimas darán "__ANON__" como nombre local. Si el paquete en el que se compiló el código ha sido eliminado (por ejemplo, usando "delete_package" de Symbol), se devolverá "__ANON__" como nombre del paquete. Si se ha establecido un nombre usando "set_subname", este nombre se devolverá en su lugar.

Esta función se inspiró en "sub_fullname" de Sub::Identify. Las funciones restantes que implementa "Sub::Identify" pueden emularse fácilmente usando operaciones de expresiones regulares, como

sub get_code_info { return (subname $_[0]) =~ m/^(.+)::(.*?)$/ }
sub sub_name      { return (get_code_info $_[0])[0] }
sub stash_name    { return (get_code_info $_[0])[1] }

Usuarios de Sub::Name, ¡cuidado!: Esta función **no** es lo mismo que "Sub::Name::subname"; devuelve el nombre existente del sub en lugar de cambiarlo. Para establecer o cambiar un nombre, consulte en su lugar "set_subname".

set_subname

my $code = set_subname $name, $code;

Desde la versión 1.40.

Establece el nombre de la función dada por la referencia $code. Devuelve la propia referencia $code. Si el $name no está calificado, se utiliza el paquete del llamador para calificarlo.

Esto es útil para aplicar nombres a referencias CODE anónimas para que las trazas de pila y situaciones similares den un nombre útil en lugar de tener el valor predeterminado de "__ANON__". Tenga en cuenta que este nombre solo se utiliza para esta situación; "set_subname" no lo instalará en la tabla de símbolos; tendrá que hacerlo usted mismo si es necesario.

Sin embargo, dado que Perl no utiliza el nombre excepto como valor de retorno de "caller", para trazas de pila o similares, no hay ningún requisito real de que el nombre sea sintácticamente válido como nombre de función de Perl. Esto podría usarse para adjuntar información adicional que podría ser útil en el depuración de trazas de pila.

Esta función se copió de "Sub::Name::subname" y se renombró según la convención de nomenclatura de este módulo.
