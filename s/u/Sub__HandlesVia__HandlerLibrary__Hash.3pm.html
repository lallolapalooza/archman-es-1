Sub__HandlesVia__HandlerLibrary__Hash(3pm)

Paquete: perl-sub-handlesvia

Licencias: PerlArtistic, GPL

Sub::HandlesVia::HandlerLibrary::Hash(3) Documentación de Perl contribuida por el usuario Sub::HandlesVia::HandlerLibrary::Hash(3)

NOMBRE

Sub::HandlesVia::HandlerLibrary::Hash - biblioteca de métodos relacionados con hashes

SINOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'HashRef';
  has attr => (
    is => 'rwp',
    isa => HashRef,
    handles_via => 'Hash',
    handles => {
      'my_accessor' => 'accessor',
      'my_all' => 'all',
      'my_clear' => 'clear',
      'my_count' => 'count',
      'my_defined' => 'defined',
      'my_delete' => 'delete',
      'my_delete_where' => 'delete_where',
      'my_elements' => 'elements',
      'my_exists' => 'exists',
      'my_for_each_key' => 'for_each_key',
      'my_for_each_pair' => 'for_each_pair',
      'my_for_each_value' => 'for_each_value',
      'my_get' => 'get',
      'my_is_empty' => 'is_empty',
      'my_keys' => 'keys',
      'my_kv' => 'kv',
      'my_reset' => 'reset',
      'my_set' => 'set',
      'my_shallow_clone' => 'shallow_clone',
      'my_sorted_keys' => 'sorted_keys',
      'my_values' => 'values',
    },
  );
}

DESCRIPCIÓN

Esta es una biblioteca de métodos para Sub::HandlesVia.

MÉTODOS DELEGABLES

"accessor( $key, $value? )"

Argumentos: Str, Optional[Any].

Actúa como "get" si se le pasa solo una clave, o como "set" si se le pasa una clave y un valor.

all()

Devuelve el hash en contexto de lista.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
my %hash = $object->my_all;

clear()

Vacía el hash.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
$object->my_clear;
say exists $object->attr->{foo}; ## ==> false
say exists $object->attr->{bar}; ## ==> false

count()

Devuelve el número de claves en el hash.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_count; ## ==> 2

defined( $key )

Argumentos: Str.

Indica si un valor existe y está definido en el hashref por su clave.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_defined( 'foo' ); ## ==> 1

delete( $key )

Elimina un valor del hashref por su clave.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
$object->my_delete( 'foo' );
say exists $object->attr->{foo}; ## ==> false

delete_where( $match )

Argumentos: CodeRef|RegexpRef.

Elimina valores del hashref haciendo coincidir las claves con una coderef o una expresión regular.

my $object = My::Class->new( attr => { foo => 0, bar => 1, baz => 2 } );
$object->my_delete_where( sub { $_ eq 'foo' or $_ eq 'bar' } );
say Dumper( $object->attr ); ## ==> { baz => 2 }

my $object2 = My::Class->new( attr => { foo => 0, bar => 1, baz => 2 } );
$object2->my_delete_where( qr/^b/ );
say Dumper( $object2->attr ); ## ==> { foo => 0 }

elements()

Devuelve el hash en contexto de lista.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
my %hash = $object->my_elements;

exists( $key )

Argumentos: Str.

Indica si un valor existe en el hashref por su clave.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_exists( 'foo' ); ## ==> true
say $object->my_exists( 'baz' ); ## ==> false

for_each_key( $coderef )

Argumentos: CodeRef.

Método encadenable que llama a la coderef para cada clave del hash, pasando solo la clave a la coderef.

for_each_pair( $coderef )

Argumentos: CodeRef.

Método encadenable que llama a la coderef para cada par clave-valor del hash, pasando la clave y el valor a la coderef.

for_each_value( $coderef )

Argumentos: CodeRef.

Método encadenable que llama a la coderef para cada valor del hash, pasando solo el valor a la coderef.

get( $key )

Devuelve un valor del hashref por su clave.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_get( 'bar' ); ## ==> 1

is_empty()

Devuelve verdadero si no hay claves en el hash.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
say $object->my_is_empty; ## ==> false
$object->_set_attr( {} );
say $object->my_is_empty; ## ==> true

keys()

Devuelve la lista de claves del hash.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
# dice 'foo' y 'bar' en orden impredecible
say for $object->my_keys;

kv()

Devuelve una lista de arrayrefs, donde cada arrayref es un par clave-valor.

reset()

Restablece el atributo a su valor predeterminado, o a un hashref vacío si no tiene un valor predeterminado.

"set( $key, $value, ... )"

Dado una clave y un valor, agrega la clave al hashref con el valor dado.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
$object->my_set( bar => 2, baz => 1 );
say $object->attr->{foo}; ## ==> 0
say $object->attr->{baz}; ## ==> 1
say $object->attr->{bar}; ## ==> 2

shallow_clone()

Crea un nuevo hashref con las mismas claves y valores que el original.

sorted_keys()

Devuelve una lista ordenada alfabéticamente de las claves del hash.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
# dice 'bar' y luego 'foo'
say for $object->my_sorted_keys;

values()

Devuelve la lista de valores del hash.

my $object = My::Class->new( attr => { foo => 0, bar => 1 } );
# dice '0' y '1' en orden impredecible
say for $object->my_values;
