Sub::HandlesVia::HandlerLibrary::Scalar(3) Documentación de Contribución de Usuarios de Perl Sub::HandlesVia::HandlerLibrary::Scalar(3)

NOMBRE

Sub::HandlesVia::HandlerLibrary::Scalar - biblioteca de métodos relacionados con escalares

SINOPSIS

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Any';
  has attr => (
    is => 'rwp',
    isa => Any,
    handles_via => 'Scalar',
    handles => {
      'my_get' => 'get',
      'my_make_getter' => 'make_getter',
      'my_make_setter' => 'make_setter',
      'my_scalar_reference' => 'scalar_reference',
      'my_set' => 'set',
      'my_stringify' => 'stringify',
    },
  );
}

DESCRIPCIÓN

Esta es una biblioteca de métodos para Sub::HandlesVia.

MÉTODOS DELEGABLES

get()

Obtiene el valor actual del escalar.

make_getter()

Devuelve una referencia de función (coderef) de obtentor.

my $object = My::Class->new( attr => 10 );
my $getter = $object->my_make_getter;
$object->_set_attr( 11 );
say $getter->(); ## ==> 11

make_setter()

Devuelve una referencia de función (coderef) de establecedor.

my $object = My::Class->new( attr => 10 );
my $setter = $object->my_make_setter;
$setter->( 11 );
say $object->attr; ## ==> 11

scalar_reference()

Devuelve una referencia escalar a la ranura del valor del atributo dentro de su objeto.

my $object = My::Class->new( attr => 10 );
my $ref = $object->my_scalar_reference;
$$ref++;
say $object->attr; ## ==> 11

set( $value )

Establece el escalar a un nuevo valor.

stringify()

Obtiene el valor actual del escalar, pero como una cadena.
