DESCRIPCIÓN

Esta es una biblioteca de métodos para Sub::HandlesVia.

MÉTODOS DELEGABLES

"accessor( $índice, $valor? )"

Argumentos: Int, Opcional[Cualquiera].

Actúa como "get" si se le da solo un índice, o como "set" si se le da un índice y un valor.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
$object->my_accessor( 1, 'quux' );
say Dumper( $object->attr ); ## ==> [ 'foo', 'quux', 'baz' ]
say $object->my_accessor( 2 ); ## ==> 'baz'

all()

Todos los elementos en el array, en contexto de lista.

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
my @list = $object->my_all;
say Dumper( \@list ); ## ==> [ 'foo', 'bar' ]

all_true( $coderef )

Argumentos: CodeRef.

Similar a List::Util::all().

any( $coderef )

Argumentos: CodeRef.

Similar a List::Util::any().

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
my $truth  = $object->my_any( sub { /a/ } );
say $truth; ## ==> verdadero

apply( $coderef )

Argumentos: CodeRef.

Ejecuta el coderef (que debería modificar $_) contra cada elemento del array; devuelve el array resultante en contexto de lista.

clear()

Vacía el array.

my $object = My::Class->new( attr => [ 'foo' ] );
$object->my_clear;
say Dumper( $object->attr ); ## ==> []

count()

El número de elementos en el array referenciado.

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
say $object->my_count; ## ==> 2

delete( $índice )

Argumentos: Int.

Elimina el elemento indexado del array y lo devuelve. Los elementos posteriores serán "movidos hacia arriba".

elements()

Todos los elementos en el array, en contexto de lista. (Esencialmente lo mismo que "all".)

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
my @list = $object->my_elements;
say Dumper( \@list ); ## ==> [ 'foo', 'bar' ]

first( $coderef )

Argumentos: CodeRef.

Similar a List::Util::first().

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
my $found  = $object->my_first( sub { /a/ } );
say $found; ## ==> 'bar'

first_index( $coderef )

Argumentos: CodeRef.

Similar a List::MoreUtils::first_index().

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
my $found  = $object->my_first_index( sub { /z$/ } );
say $found; ## ==> 2

flatten()

Todos los elementos en el array, en contexto de lista. (Esencialmente lo mismo que "all".)

my $object = My::Class->new( attr => [ 'foo', 'bar' ] );
my @list = $object->my_flatten;
say Dumper( \@list ); ## ==> [ 'foo', 'bar' ]

flatten_deep( $profundidad? )

Argumentos: Opcional[Int].

Aplana el arrayref en una lista, incluyendo cualquier arrayref anidado. (Tiene el potencial de un bucle infinito.)

my $object = My::Class->new( attr => [ 'foo', [ 'bar', [ 'baz' ] ] ] );
say Dumper( [ $object->my_flatten_deep ] ); ## ==> [ 'foo', 'bar', 'baz' ]
my $object2 = My::Class->new( attr => [ 'foo', [ 'bar', [ 'baz' ] ] ] );
say Dumper( [ $object2->my_flatten_deep(1) ] ); ## ==> [ 'foo', 'bar', [ 'baz' ] ]

for_each( $coderef )

Argumentos: CodeRef.

Método encadenable que ejecuta el coderef en cada elemento del array. El coderef recibirá dos valores: el elemento y su índice.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
$object->my_for_each( sub { say "Item $_[1] es $_[0]." } );

for_each_pair( $coderef )

Argumentos: CodeRef.

Método encadenable que ejecuta el coderef en cada par de elementos del array. El coderef recibirá los dos elementos.

get( $índice )

Argumentos: Int.

Devuelve un único elemento del array por índice.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
say $object->my_get(  0 ); ## ==> 'foo'
say $object->my_get(  1 ); ## ==> 'bar'
say $object->m

grep( $coderef )

Argumentos: CodeRef.

Como "grep" de perlfunc.

head( $count )

Argumentos: Int.

Devuelve los primeros $count elementos del array en contexto de lista.

indexed()

Como "indexed" de builtin.

"insert( $index, $value )"

Argumentos: Int, Any.

Inserta un valor en el array con el índice dado. Los elementos posteriores se "moverán hacia abajo".

Booleano que indica si el array referenciado está vacío.

Argumentos: Int, Optional[CodeRef].

Dado solo un número, devuelve un iterador que lee ese número de elementos del array a la vez. Si también se proporciona una función de retrollamada, la llama repetidamente con esos valores.

my $iter   = $object->my_natatime( 2 );
say Dumper( [ $iter->() ] ); ## ==> [ 'foo', 'bar' ]
say Dumper( [ $iter->() ] ); ## ==> [ 'baz' ]

Argumentos: Optional[Int].

Si no se da $count, devuelve un elemento del array al azar. Si se da $count, crea un nuevo array con esa cantidad de elementos aleatorios del array original (o menos si el array original no es lo suficientemente largo) y lo devuelve como una referencia a array o lista según el contexto.

pop()

Elimina el último elemento del array y lo devuelve.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
say $object->my_pop; ## ==> 'baz'
say $object->my_pop; ## ==> 'bar'
say Dumper( $object->attr ); ## ==> [ 'foo' ]

$object->my_push( 'bar', 'baz' );

Argumentos: Int, Any.

$object->my_set( 1, 'quux' );
say Dumper( $object->attr ); ## ==> [ 'foo', 'quux', 'baz' ]

shallow_clone()

Crea un nuevo arrayref con los mismos elementos que el original.

shift()

Elimina un elemento del principio del array y lo devuelve.

my $object = My::Class->new( attr => [ 'foo', 'bar', 'baz' ] );
say $object->my_shift; ## ==> 'foo'

Devuelve el array en un orden aleatorio; se puede llamar en contexto de lista o escalar y devolverá una referencia a array en este último caso.

shuffle_in_place()

Argumentos: Optional[CodeRef].

Argumentos: Optional[CodeRef].

Como "sort" de perlfunc, pero cambia el atributo para que apunte al array recién ordenado.

Sub::HandlesVia::HandlerLibrary::Array - Perl manual page

NAME

Sub::HandlesVia::HandlerLibrary::Array - Allows attributes to handle array-like delegations.

SYNOPSIS

 package My::Class {
   use Moo;
   use Sub::HandlesVia;
   use Sub::HandlesVia::HandlerLibrary::Array qw( HandleQueue );

   has things => (
     is          => 'ro',
     handles_via => 'Array',
     handles     => HandleQueue,
     default     => sub { [] },
   );
 }

DESCRIPTION

This module provides the Array handler library for Sub::HandlesVia.

It allows you to delegate methods to an array attribute.

DELEGATABLE METHODS

The following methods can be delegated to an array attribute:

all()
Returns the array in list context, or an arrayref in scalar context.
append( @values )
Appends elements to the end of the array.
clear()
Clears the array, removing all elements.
contains( $_value )
Returns true if the array contains the given value, false otherwise.
contains_all( @values )
Returns true if the array contains all the given values, false otherwise.
contains_any( @values )
Returns true if the array contains any of the given values, false otherwise.
delete( $_value )
Deletes the first occurrence of the given value from the array.
delete_all( $_value )
Deletes all occurrences of the given value from the array.
delete_at( $_index )
Deletes the element at the given index from the array.
delete_between( $_start, $_end )
Deletes elements from the given start index to the given end index (inclusive).
delete_first()
Returns and deletes the first element of the array.
delete_last()
Returns and deletes the last element of the array.
duplicate( $_index )
Duplicates the element at the given index.
duplicate_all( $_value )
Duplicates all occurrences of the given value.
each()
Returns an iterator for the array, suitable for use in a for loop.
empty()
Returns true if the array is empty, false otherwise.
first()
Returns the first element of the array.
for_each( $_coderef )
Calls the given coderef for each element of the array, passing the element as the first argument.
insert( $_index, @values )
Inserts elements at the given index.
is_empty()
Returns true if the array is empty, false otherwise.
last()
Returns the last element of the array.
pop()
Removes and returns the last element of the array.
push( @values )
Appends elements to the end of the array.
reverse()
Reverses the array in place.
shift()
Removes and returns the first element of the array.
slice( $_start [, $_end ] )
Returns a slice of the array from the given start index to the given end index (inclusive).
Sorts the array. If a comparison coderef is provided, it is used for sorting.
splice( $_offset [, $_len [, @repl] ] )
Replaces a portion of the array with new elements.
uniq()
Returns the array filtered to remove duplicates; can be called in list context or scalar context and will return an arrayref in the latter case.
uniq_in_place()
Filters the array to remove duplicates, and changes the attribute to point to the filtered array.
uniqnum()
Returns the array filtered to remove duplicates numerically; can be called in list context or scalar context and will return an arrayref in the latter case.
uniqnum_in_place()
Filters the array to remove duplicates numerically, and changes the attribute to point to the filtered array.
uniqstr()
Returns the array filtered to remove duplicates stringwise; can be called in list context or scalar context and will return an arrayref in the latter case.
uniqstr_in_place()
Filters the array to remove duplicates stringwise, and changes the attribute to point to the filtered array.
unshift( @values )
Adds an element to the start of the array.
 my $object = My::Class->new( attr => [ 'foo' ] );
 $object->my_unshift( 'bar', 'baz' );
 say Dumper( $object->attr ); ## ==> [ 'bar', 'baz', 'foo' ]

SHORTCUT CONSTANTS

This module provides some shortcut constants for indicating a list of delegations.

 package My::Class {
   use Moo;
   use Sub::HandlesVia;
   use Sub::HandlesVia::HandlerLibrary::Array qw( HandleQueue );

   has things => (
     is          => 'ro',
     handles_via => 'Array',
     handles     => HandleQueue,
     default     => sub { [] },
   );
 }

These shortcuts can be combined using the " | " operator.

 has things => (
   is          => 'ro',
   handles_via => 'Array',
   handles     => HandleQueue | HandleStack,
   default     => sub { [] },
 );

"HandleQueue"

Creates delegations named like "things_is_empty", "things_size", "things_enqueue", "things_dequeue", and "things_peek".

"HandleStack"

Creates delegations named like "things_is_empty", "things_size", "things_push", "things_pop", and "things_peek".

EXTENDED EXAMPLES

Using for_each

 use strict;
 use warnings;

 package My::Plugin {
   use Moo::Role;
   sub initialize {}
   sub finalize {}
 }

 package My::Processor {
   use Moo;
   use Sub::HandlesVia;
   use Types::Standard qw( ArrayRef ConsumerOf );

   has plugins => (
     is => 'ro',
     isa => ArrayRef[ ConsumerOf['My::Plugin'] ],
     handles_via => 'Array',
     handles => {
       add_plugin => 'push',
       plugin_do => 'for_each',
     },
     default => sub { [] },
   );

   sub _do_stuff {
     return;
   }

   sub run_process {
     my ( $self, @args ) = @_;
     $self->plugin_do( sub {
       my $plugin = shift;
       $plugin->initialize( $self, @args );
     } );
     $self->_do_stuff( @args );
     $self->plugin_do( sub {
       my $plugin = shift;
       $plugin->finalize( $self, @args );
     } );
   }
 }

 my $p = My::Processor->new();

 package My::Plugin::Noisy {
   use Moo; with 'My::Plugin';
   sub initialize {
     my ( $self, $processor, @args ) = @_;
     say "initialize @args"; ## ==> 'initialize 1 2 3'
   }
   sub finalize {
     my ( $self, $processor, @args ) = @_;
     say "finalize @args"; ## ==> 'finalize 1 2 3'
   }
 }

 $p->add_plugin( My::Plugin::Noisy->new );

 $p->run_process( 1, 2, 3 );

Job queue using push and shift

 use strict;
 use warnings;
 use Try::Tiny;

 package My::JobQueue {
   use Moo;
   use Sub::HandlesVia;
   use Types::Standard qw( Bool ArrayRef CodeRef HasMethods is_Object );
   use Try::Tiny;

   has auto_requeue => (
     is => 'ro',
     isa => Bool,
     default => 0,
   );

   has jobs => (
     is => 'ro',
     isa => ArrayRef[ CodeRef | HasMethods['run'] ],
     handles_via => 'Array',
     handles => {
       add_job => 'push',
       _get_job => 'shift',
       is_empty => 'is_empty',
     },
     default => sub { [] },
   );

   sub _handle_failed_job {
     my ( $self, $job ) = @_;
     $self->add_job( $job ) if $self->auto_requeue;
   }

   sub run_jobs {
     my $self = shift;
     while ( not $self->is_empty ) {
       my $job = $self->_get_job;
       try {
         is_Object($job) ? $job->run() : $job->();
       }
       catch {
         $self->_handle_failed_job( $job );
       };
     }
   }
 }

 my $q = My::JobQueue->new();

 my $str = '';
 $q->add_job( sub { $str .= 'A' } );
 $q->add_job( sub { $str .= 'B' } );
 $q->add_job( sub { $str .= 'C' } );

 $q->run_jobs;

 say $str; ## ==> 'ABC'

 # Attempt to push invalid value on the queue
 #
 try {
   $q->add_job( "jobs cannot be strings" );
 }
 catch {
   say $q->is_empty;  ## ==> true
 };
