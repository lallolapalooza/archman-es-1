NOMBRE

Sub::HandlesVia::Toolkit - integración con frameworks OO para Sub::HandlesVia

DESCRIPCIÓN

Este módulo es parte de la API interna de Sub::HandlesVia. Es principalmente de interés para las personas que extienden Sub::HandlesVia.

Detecta qué subclase de Sub::HandlesVia::Toolkit es adecuada para una clase:

my $toolkit = Sub::HandlesVia->detect_toolkit($class);

Extrae información de handles_via de un hash de especificación de atributo "has":

my $shvdata = $toolkit->clean_spec($class, $attrname, \%spec);

Esto no solo devuelve los datos que Sub::HandlesVia necesita, sino que también limpia %spec para que pueda pasarse a una función "has" similar a Moose sin que esta se queje de opciones no reconocidas.

$toolkit->install_delegations($shvdata) if $shvdata;
