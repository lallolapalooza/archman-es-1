NOMBRE

Sub::HandlesVia::Declare - declara delegaciones en tiempo de compilación

SINOPSIS

use Sub::HandlesVia::Declare( $attr, $via => %delegations );

Esto es aproximadamente equivalente a lo siguiente:

use Sub::HandlesVia qw(delegations);

BEGIN {
  delegations(
    attribute    => $attr,
    handles_via  => $via,
    handles      => \%delegations,
  );
};

Excepto que no importa la función "delegations" en tu espacio de nombres.

DESCRIPCIÓN

Útil para Object::Pad y, de alguna manera, agradable para Class::Tiny. Básicamente, cualquier constructor de clases que haga su trabajo en tiempo de compilación.

Object::Pad

use Object::Pad;

class Kitchen {
  has @foods;
  use Sub::HandlesVia::Declare '@foods', Array => (
    all_foods => 'all',
    add_food  => 'push',
  );
}

Si un atributo comienza con '@' o '%', $via puede omitirse.

use Object::Pad;

class Kitchen {
  has @foods;
  use Sub::HandlesVia::Declare '@foods', (
    all_foods => 'all',
    add_food  => 'push',
  );
}

Class::Tiny

package Kitchen;
use Class::Tiny {
  foods  => sub { [] },
  drinks => sub { [ 'water' ] },
};
use Sub::HandlesVia::Declare 'foods', Array => (
  all_foods  => 'all',
  add_food   => 'push',
);
use Sub::HandlesVia::Declare 'drinks', Array => (
  all_drinks => 'all',
  add_drink  => 'push',
);
