NOMBRE

Sub::HandlesVia::Manual::WithClassTiny - uso de Sub::HandlesVia con Class::Tiny

SINOPSIS

package Cocina;

use Class::Tiny {
  comidas  => sub { [] },
  bebidas => sub { [ 'agua' ] },
};

use Sub::HandlesVia::Declare 'comidas', Array => (
  todas_las_comidas  => 'all',
  agregar_comida   => 'push',
);

use Sub::HandlesVia::Declare 'bebidas', Array => (
  todas_las_bebidas => 'all',
  agregar_bebida  => 'push',
);

MANUAL

Sub::HandlesVia te permite delegar métodos de tu clase a los valores de los atributos de tus objetos.

Conceptualmente, te permite definir "$objeto->push_numero($n)" como un atajo para "$objeto->numeros->push($n)" excepto que "$objeto->numeros" es un arrayref, por lo que no tiene métodos que puedas llamar sobre él como "push".

¿Qué métodos pueden ser delegados?

El segundo parámetro ("Array" en la sinopsis) indica qué biblioteca de métodos debe estar disponible. Los valores válidos incluyen Array, Blessed, Bool, Code, Counter, Enum, Hash, Number, Scalar y String.

Se puede proporcionar un arrayref, aunque muchas de las opciones son conceptualmente contradictorias.

use Sub::HandlesVia::Declare 'num', [ 'Number', 'Scalar' ] => (
  ...,
);

Delegación en tiempo de ejecución

En lugar de usar Sub::HandlesVia::Declare, que opera en tiempo de compilación, puedes usar la función "delegations" en tiempo de ejecución. Lo que elijas es en gran medida una cuestión de estilo y preferencia personal.

package Cocina;

use Class::Tiny {
  comidas  => sub { [] },
  bebidas => sub { [ 'agua' ] },
};

use Sub::HandlesVia qw( delegations );

delegations(
  atributo    => 'comidas',
  maneja_via  => 'Array',
  maneja      => {
    todas_las_comidas    => 'all',
    agregar_comida     => 'push',
  },
);

delegations(
  atributo    => 'bebidas',
  maneja_via  => 'Array',
  maneja      => {
    todas_las_bebidas   => 'all',
    agregar_bebida    => 'push',
  },
);
