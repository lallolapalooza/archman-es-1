DOCUMENTACIÓN

Módulo Counting
: sig fin

tipo t

El tipo de semáforos contadores.

valor make : int -> t

make n devuelve un nuevo semáforo contador, con valor inicial n . El valor inicial n debe ser no negativo.

Lanza Invalid_argument si n < 0

valor release : t -> unit

release s incrementa el valor del semáforo s . Si otros hilos están esperando en s , uno de ellos se reinicia. Si el valor actual de s es igual a max_int , el valor del semáforo no cambia y se lanza una excepción Sys_error para señalar desbordamiento.

Lanza Sys_error si el valor del semáforo desbordaría max_int

valor acquire : t -> unit

acquire s bloquea el hilo que llama hasta que el valor del semáforo s no sea cero, luego decrementa atómicamente el valor de s y retorna.

valor try_acquire : t -> bool

try_acquire s retorna inmediatamente false si el valor del semáforo s es cero. De lo contrario, el valor de s se decrementa atómicamente y try_acquire s retorna true .

valor get_value : t -> int

get_value s retorna el valor actual del semáforo s . El valor actual puede ser modificado en cualquier momento por operaciones concurrentes de Semaphore.Counting.release y Semaphore.Counting.acquire . Por lo tanto, la operación get_value es susceptible de condiciones de carrera, y su resultado solo debería usarse para depuración o mensajes informativos.
