val find_first : (elt -> bool) -> t -> elt

find_first f s , donde f es una función monótonamente creciente, devuelve el elemento más bajo e de s tal que f e , o lanza Not_found si no existe tal elemento.

Por ejemplo, find_first (fun e -> Ord.compare e x >= 0) s devolverá el primer elemento e de s donde Ord.compare e x >= 0 (en términos intuitivos: e >= x ), o lanzará Not_found si x es mayor que cualquier elemento de s .

val filter : (elt -> bool) -> t -> t

filter f s devuelve el conjunto de todos los elementos en s que satisfacen el predicado f . Si f satisface a cada elemento en s , se devuelve s sin cambios (el resultado de la función es físicamente igual a s ).

val filter_map : (elt -> elt option) -> t -> t

filter_map f s devuelve el conjunto de todos los v tales que f x = Some v para algún elemento x de s .

Por ejemplo,

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
es el conjunto de las mitades de los elementos pares de s .

NAME

Set.Make - Functor to create ordered sets.

Module

Set.Make : FUNCTOR (O : OrderedType) -> S

Documentation

This module implements ordered sets. The functions for manipulating sets are parameterized by a module O that specifies the ordering used on the elements of type t.

The comparison function O.compare must be total, i.e. for all x, y of type t, `O.compare x y` must return -1, 0 or 1.

The elements of the set are ordered according to O.compare.

The operations are in O(log n) or O(n), where n is the number of elements in the set.

The functor Make can be applied to any module satisfying the OrderedType signature.
