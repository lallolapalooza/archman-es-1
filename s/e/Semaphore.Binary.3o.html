DOCUMENTACIÓN

Módulo Binary
: sig end

type t

El tipo de semáforos binarios.

val make : bool -> t

make b devuelve un nuevo semáforo binario. Si b es true , el valor inicial del semáforo es 1, lo que significa "disponible". Si b es false , el valor inicial del semáforo es 0, lo que significa "no disponible".

val release : t -> unit

release s establece el valor del semáforo s a 1, poniéndolo en estado "disponible". Si otros hilos están esperando en s , uno de ellos se reinicia.

val acquire : t -> unit

acquire s bloquea el hilo que llama hasta que el semáforo s tenga el valor 1 (esté disponible), luego lo establece atómicamente a 0 y devuelve.

val try_acquire : t -> bool

try_acquire s devuelve inmediatamente false si el semáforo s tiene el valor 0. Si s tiene el valor 1, su valor se establece atómicamente a 0 y try_acquire s devuelve true.
