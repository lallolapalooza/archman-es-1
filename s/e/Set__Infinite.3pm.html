NOMBRE

Set::Infinite - Conjuntos de intervalos

SINOPSIS

use Set::Infinite;
$set = Set::Infinite->new(1,2);    # [1..2]
print $set->union(5,6);            # [1..2],[5..6]

DESCRIPCIÓN

Set::Infinite es un módulo de Teoría de Conjuntos para conjuntos infinitos.

Un conjunto es una colección de objetos. Los objetos que pertenecen a un conjunto se llaman sus miembros, o "elementos".

Como objetos permitimos (casi) cualquier cosa: reales, enteros y objetos (como fechas).

Permitimos que los conjuntos sean infinitos.

No se tiene en cuenta el orden de los elementos. Por ejemplo, {1,2} = {2,1}.

No se tiene en cuenta la repetición de elementos. Por ejemplo, {1,2,2} = {1,1,1,2} = {1,2}.

CONSTRUCTOR

new

Crea un nuevo objeto conjunto:

$set = Set::Infinite->new;             # conjunto vacío
$set = Set::Infinite->new( 10 );       # elemento único
$set = Set::Infinite->new( 10, 20 );   # intervalo único
$set = Set::Infinite->new(
          [ 10, 20 ], [ 50, 70 ] );    # dos intervalos
conjunto vacío
$set = Set::Infinite->new;
conjunto con un único elemento
$set = Set::Infinite->new( 10 );
$set = Set::Infinite->new( [ 10 ] );
conjunto con un único intervalo
$set = Set::Infinite->new( 10, 20 );
$set = Set::Infinite->new( [ 10, 20 ] );
# 10 <= x <= 20
conjunto con un único intervalo abierto
$set = Set::Infinite->new(
    {
        a => 10, open_begin => 0,
        b => 20, open_end => 1,
    }
);
# 10 <= x < 20
conjunto con múltiples intervalos
$set = Set::Infinite->new( 10, 20,  100, 200 );
$set = Set::Infinite->new( [ 10, 20 ], [ 100, 200 ] );
$set = Set::Infinite->new(
    {
        a => 10, open_begin => 0,
        b => 20, open_end => 0,
    },
    {
        a => 100, open_begin => 0,
        b => 200, open_end => 0,
    }
);

El método new() espera parámetros *ordenados*.

Si tienes intervalos desordenados, puedes construir el conjunto usando "union":

@ranges = ( [ 10, 20 ], [ -10, 1 ] );
$set = Set::Infinite->new;
$set = $set->union( @$_ ) for @ranges;

Las estructuras de datos pasadas a "new" deben ser *inmutables*. Por lo tanto, no es una buena práctica:

$set = Set::Infinite->new( $object_a, $object_b );
$object_a->set_value( 10 );

Esta es la forma recomendada de hacerlo:

$set = Set::Infinite->new( $object_a->clone, $object_b->clone );
$object_a->set_value( 10 );

FUNCIONES DE CONJUNTO

union

$set = $set->union($b);

Devuelve el conjunto de todos los elementos de ambos conjuntos.

Esta función se comporta como una operación "OR".

$set1 = new Set::Infinite( [ 1, 4 ], [ 8, 12 ] );
$set2 = new Set::Infinite( [ 7, 20 ] );
print $set1->union( $set2 );
# salida: [1..4],[7..20]

intersección

$set = $set->intersection($b);

Devuelve el conjunto de elementos comunes a ambos conjuntos.

Esta función se comporta como una operación "Y".

$set1 = new Set::Infinite( [ 1, 4 ], [ 8, 12 ] );
$set2 = new Set::Infinite( [ 7, 20 ] );
print $set1->intersection( $set2 );
# salida: [8..12]

complemento

menos

diferencia

$set = $set->complement;

Devuelve el conjunto de todos los elementos que no pertenecen al conjunto.

$set1 = new Set::Infinite( [ 1, 4 ], [ 8, 12 ] );
print $set1->complement;
# salida: (-inf..1),(4..8),(12..inf)

La función de complemento puede tomar un parámetro:

$set = $set->minus($b);

Devuelve la diferencia de conjuntos, es decir, los elementos que no pertenecen al conjunto dado.

$set1 = new Set::Infinite( [ 1, 4 ], [ 8, 12 ] );
$set2 = new Set::Infinite( [ 7, 20 ] );
print $set1->minus( $set2 );
# salida: [1..4]

diferencia_simétrica

Devuelve un conjunto que contiene los elementos que están en uno u otro, pero no en ambos. Esta es la versión de "conjunto" de "XOR".

iterate

iterate ( sub { } , @args )

Itera sobre los tramos del conjunto, a través de una subrutina de llamada. Devuelve la unión de todos los resultados parciales.

El argumento de llamada $_[0] es un tramo. Si hay argumentos adicionales, se pasan a la llamada.

La llamada puede devolver un tramo, un hashref (ver "Set::Infinite::Basic"), un escalar, un objeto, o "undef".

[EXPERIMENTAL] "iterate" acepta un argumento opcional "backtrack_callback". El propósito de "backtrack_callback" es *invertir* la función iterate(), superando las limitaciones del algoritmo interno de retroceso. La sintaxis es:

iterate ( sub { } , backtrack_callback => sub { }, @args )

El "backtrack_callback" puede devolver un tramo, un hashref, un escalar, un objeto o "undef".

Por ejemplo, el siguiente fragmento añade una constante a cada elemento de un conjunto ilimitado:

$set1 = $set->iterate(
             sub { $_[0]->min + 54, $_[0]->max + 54 },
          backtrack_callback =>
             sub { $_[0]->min - 54, $_[0]->max - 54 },
          );

CAVEATS

  • notación "span" del constructor 
    $set = Set::Infinite->new(10,1);

    Se interpretará como [1..10]

  • notación "múltiple-span" del constructor 
    $set = Set::Infinite->new(1,2,3,4);

    Se interpretará como [1..2],[3..4] en lugar de [1,2,3,4]. Probablemente quieres ->new([1],[2],[3],[4] en su lugar, o tal vez ->new(1,4)

  • "operador de rango" 
    $set = Set::Infinite->new(1..3);

    Se interpretará como [1..2],3 en lugar de [1,2,3]. Probablemente quieres ->new(1,3) en su lugar.

INTERNOS

El objeto base de *conjunto*, sin recurrencias, es un "Set::Infinite::Basic".

Un *conjunto de recurrencia* se representa mediante un *nombre de método*, uno o dos *objetos padre*, y argumentos adicionales. La clave "list" se establece en un array vacío, y la clave "too_complex" se establece en 1.

Esta es una estructura que contiene la unión de dos "conjuntos complejos":

{
  too_complex => 1,             # "esto es una recurrencia"
  list   => [ ],                # no se usa
  method => 'union',            # nombre de la función
  parent => [ $set1, $set2 ],   # "hojas" en el árbol sintáctico
  param  => [ ]                 # argumentos opcionales para la función
}

Esta es una estructura que contiene el complemento de un "conjunto complejo":

{
  too_complex => 1,             # "esto es una recurrencia"
  list   => [ ],                # no se usa
  method => 'complement',       # nombre de la función
  parent => $set,               # "hoja" en el árbol s

CAVEATS

When using the &-& operator, the second argument must be an infinite set. This limitation is due to the implementation of the "contains" method which is used by the operator.

The following two lines are equivalent:

  use Set::Infinite qw(:all);
  use Set::Infinite qw($integers $reals);
