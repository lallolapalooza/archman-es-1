NOMBRE

SET - cambiar un parámetro en tiempo de ejecución

SINOPSIS

SET [ SESSION | LOCAL ] parámetro_de_configuración { TO | = } { valor | 'valor' | DEFAULT }
SET [ SESSION | LOCAL ] TIME ZONE { valor | 'valor' | LOCAL | DEFAULT }

DESCRIPCIÓN

El comando SET cambia los parámetros de configuración en tiempo de ejecución. Muchos de los parámetros en tiempo de ejecución listados en el Capítulo 19 se pueden cambiar sobre la marcha con SET. (Algunos parámetros solo pueden ser cambiados por superusuarios y usuarios a los que se les ha otorgado el privilegio SET sobre ese parámetro. También hay parámetros que no se pueden cambiar después del inicio del servidor o de la sesión.) SET solo afecta al valor utilizado por la sesión actual.

Si SET (o equivalentemente SET SESSION) se emite dentro de una transacción que posteriormente se aborta, los efectos del comando SET desaparecen cuando la transacción se revierte. Una vez que la transacción circundante se confirma, los efectos persistirán hasta el final de la sesión, a menos que sean anulados por otro SET.

Los efectos de SET LOCAL duran solo hasta el final de la transacción actual, se confirme o no. Un caso especial es SET seguido de SET LOCAL dentro de una misma transacción: el valor de SET LOCAL se verá hasta el final de la transacción, pero después (si la transacción se confirma) el valor de SET tendrá efecto.

Los efectos de SET o SET LOCAL también se cancelan al revertir a un punto de guardado que sea anterior al comando.

Si SET LOCAL se utiliza dentro de una función que tiene una opción SET para la misma variable (ver CREATE FUNCTION (CREATE_FUNCTION(7))), los efectos del comando SET LOCAL desaparecen al salir de la función; es decir, de todos modos se restaura el valor que estaba en vigor cuando se llamó a la función. Esto permite que SET LOCAL se utilice para cambios dinámicos o repetidos de un parámetro dentro de una función, mientras se sigue teniendo la conveniencia de usar la opción SET para guardar y restaurar el valor del llamador. Sin embargo, un comando SET regular anula cualquier opción SET de la función circundante; sus efectos persistirán a menos que se reviertan.


Nota

En las versiones 8.0 a 8.2 de PostgreSQL, los efectos de un SET LOCAL se cancelaban al liberar un punto de guardado anterior, o al salir con éxito de un bloque de excepción PL/pgSQL. Este comportamiento ha sido modificado porque se consideró poco intuitivo.

PARÁMETROS

SESSION

Especifica que el comando surte efecto para la sesión actual. (Este es el valor predeterminado si no aparece ni SESSION ni LOCAL.)

LOCAL

Especifica que el comando surte efecto solo para la transacción actual. Después de COMMIT o ROLLBACK, la configuración a nivel de sesión vuelve a tener efecto. Emitir esto fuera de un bloque de transacción genera una advertencia y, por lo demás, no tiene ningún efecto.

parámetro_de_configuración

Nombre de un parámetro en tiempo de ejecución configurable. Los parámetros disponibles se documentan en el Capítulo 19 y a continuación.

valor

Nuevo valor del parámetro. Los valores se pueden especificar como constantes de cadena, identificadores, números o listas separadas por comas de estos, según corresponda para el parámetro en particular. DEFAULT se puede escribir para especificar la restauración del parámetro a su valor predeterminado (es decir, el valor que tendría si no se hubiera ejecutado ningún SET en la sesión actual).

Además de los parámetros de configuración documentados en el Capítulo 19, hay algunos que solo se pueden ajustar utilizando el comando SET o que tienen una sintaxis especial:

SCHEMA

SET SCHEMA 'valor' es un alias para SET search_path TO valor. Solo se puede especificar un esquema utilizando esta sintaxis.

NAMES

SET NAMES 'valor' es un alias para SET client_encoding TO valor.

SEED

Establece la semilla interna para el generador de números aleatorios (la función random). Los valores permitidos son números de punto flotante entre -1 y 1 inclusive.

La semilla también se puede establecer invocando la función setseed:

SELECT setseed(valor);

TIME ZONE

SET TIME ZONE 'valor' es un alias para SET timezone TO 'valor'. La sintaxis SET TIME ZONE permite una sintaxis especial para la especificación de la zona horaria. Aquí hay ejemplos de valores válidos:

'America/Los_Angeles'

La zona horaria de Berkeley, California.

'Europe/Rome'

La zona horaria de Italia.

-7

La zona horaria 7 horas al oeste de UTC (equivalente a PDT). Los valores positivos son al este de UTC.

INTERVAL '-08:00' HOUR TO MINUTE

La zona horaria 8 horas al oeste de UTC (equivalente a PST).

LOCAL
DEFAULT

Establece la zona horaria a la zona horaria local (es decir, el valor predeterminado del servidor para timezone).

Las configuraciones de zona horaria dadas como números o intervalos se traducen internamente a la sintaxis de zona horaria POSIX. Por ejemplo, después de SET TIME ZONE -7, SHOW TIME ZONE informaría <-07>+07.

Las abreviaturas de zona horaria no son compatibles con SET; consulte la Sección 8.5.3 para obtener más información sobre las zonas horarias.

NOTAS

La función set_config proporciona una funcionalidad equivalente; consulte la Sección 9.28.1. Además, es posible actualizar la vista del sistema pg_settings para realizar el equivalente a SET.

EJEMPLOS

Establecer la ruta de búsqueda de esquemas:

SET search_path TO my_schema, public;

Establecer el estilo de fecha a POSTGRES tradicional con la convención de entrada "día antes del mes":

SET datestyle TO postgres, dmy;

Establecer la zona horaria de Berkeley, California:

SET TIME ZONE 'America/Los_Angeles';

Establecer la zona horaria de Italia:

SET TIME ZONE 'Europe/Rome';

COMPATIBILIDAD

SET TIME ZONE extiende la sintaxis definida en el estándar SQL. El estándar solo permite desplazamientos de zona horaria numéricos mientras que PostgreSQL permite especificaciones de zona horaria más flexibles. Todas las demás funcionalidades de SET son extensiones de PostgreSQL.
