SelectSaver(3perl) Guía de referencia para programadores de Perl SelectSaver(3perl)

NOMBRE

SelectSaver - guarda y restaura el manejador de archivo seleccionado

SINOPSIS

use SelectSaver;
{
   my $saver = SelectSaver->new(FILEHANDLE);
   # FILEHANDLE es seleccionado
}
# se selecciona el manejador anterior
{
   my $saver = SelectSaver->new;
   # puede o no ser seleccionado un nuevo manejador
}
# se selecciona el manejador anterior

DESCRIPCIÓN

Un objeto "SelectSaver" contiene una referencia al manejador de archivo que estaba seleccionado cuando se creó. Si su método "new" recibe un parámetro adicional, entonces ese parámetro se selecciona; de lo contrario, el manejador de archivo seleccionado permanece sin cambios.

Cuando un "SelectSaver" es destruido, este vuelve a seleccionar el manejador de archivo que estaba seleccionado cuando se creó.
