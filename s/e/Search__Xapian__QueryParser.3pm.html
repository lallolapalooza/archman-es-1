NOMBRE

Search::Xapian::QueryParser - Analiza una cadena de consulta en un objeto Search::Xapian::Query

DESCRIPCIÓN

Este módulo convierte una cadena legible por humanos en algo que Xapian pueda entender. La sintaxis soportada está diseñada para ser similar a otros motores de búsqueda web, de modo que los usuarios familiarizados con ellos no tengan que aprender una sintaxis completamente nueva.

SINOPSIS

use Search::Xapian qw/:standard/;
my $qp = new Search::Xapian::QueryParser( [$database] );
$qp->set_stemmer(new Search::Xapian::Stem("english"));
$qp->set_default_op(OP_AND);
$database->enquire($qp->parse_query('a NEAR word OR "a phrase" NOT (too difficult) +eh'));

MÉTODOS

new <database>
Constructor de QueryParser.
set_stemmer <stemmer>
Establece el objeto Search::Xapian::Stem a utilizar para la derivación de términos de consulta.
set_stemming_strategy <strategy>
Establece la estrategia de derivación. Los valores válidos son "STEM_ALL", "STEM_SOME", "STEM_NONE".
set_stopper <stopper>
Establece el objeto Search::Xapian::Stopper a utilizar para identificar palabras vacías (stopwords).
set_default_op <operator>
Establece el operador por defecto.

Este operador se utiliza para combinar elementos de consulta que no son filtros cuando no se utiliza un operador explícito.

Los valores más útiles para esto son OP_OR (el valor por defecto) y OP_AND. OP_NEAR y OP_PHRASE también pueden ser útiles.

Consulte Search::Xapian para ver las descripciones de estas constantes.

get_default_op
Devuelve el operador por defecto actual.
set_database <database>
Pasa un objeto Search::Xapian::Database que se utiliza para comprobar si los términos existen en ciertas situaciones.
parse_query <query_string> [<flags>]
Analiza la cadena de consulta según las reglas definidas en la documentación del analizador de consultas a continuación. Puede especificar ciertas banderas para modificar el comportamiento de la búsqueda: 
FLAG_BOOLEAN, FLAG_PHRASE, FLAG_LOVEHATE, FLAG_BOOLEAN_ANY_CASE,
FLAG_WILDCARD, FLAG_PURE_NOT, FLAG_PARTIAL, FLAG_SPELLING_CORRECTION,
FLAG_SYNONYM, FLAG_AUTO_SYNONYMS, FLAG_AUTO_MULTIWORD_SYNONYMS

Para especificar varias banderas, aplique un "AND bit a bit" (con "|"). Las banderas por defecto son "FLAG_PHRASE|FLAG_BOOLEAN|FLAG_LOVEHATE"

add_prefix <campo> <prefijo>
Añade un prefijo de término probabilístico. Por ejemplo, $qp->add_prefix("autor", "A");

Permite al usuario buscar autor:orwell, lo que buscará el término "Aorwel" (asumiendo que se está utilizando la derivación inglesa). Se pueden mapear varios campos al mismo prefijo (por lo que puede, por ejemplo, hacer que título: y asunto: sean alias el uno del otro).

Parámetros: campo El nombre del campo visible para el usuario prefijo El prefijo de término al que se mapea

add_boolean_prefix <campo> prefijo
Añade un prefijo de término booleano que permite al usuario restringir una búsqueda con un filtro booleano especificado en la consulta de texto libre. Por ejemplo, 
$p->add_boolean_prefix("sitio", "H");

Permite al usuario restringir una búsqueda con sitio:xapian.org, que se convertirá en Hxapian.org combinado con cualquier consulta probabilística con "OP_FILTER".

Se pueden mapear varios campos al mismo prefijo (por lo que puede, por ejemplo, hacer que sitio: y dominio: sean alias el uno del otro).

Parámetros: campo El nombre del campo visible para el usuario prefijo El prefijo de término al que se mapea

stoplist_begin
stoplist_end
unstem_begin
unstem_end
get_description
Devuelve una cadena que describe este objeto.
get_corrected_query_string
Obtiene la cadena de consulta corregida ortográficamente.

Esto solo se establecerá si se especifica FLAG_SPELLING_CORRECTION cuando se llamó por última vez a QueryParser::parse_query().

Si no hubo correcciones, se devuelve una cadena vacía.

set_max_wildcard_expansion <límite>
Especifica la expansión máxima de un término comodín.

Nota: también debe establecer FLAG_WILDCARD para que ocurra la expansión de comodines.

El parámetro límite es el número máximo de términos que cada comodín en la consulta puede expandir, o 0 para ningún límite (que es el valor por defecto).
