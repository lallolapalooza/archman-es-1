NOMBRE

SELECT_INTO - definir una nueva tabla a partir de los resultados de una consulta

SINOPSIS

[ WITH [ RECURSIVE ] consulta_con [, ...] ]
SELECT [ ALL | DISTINCT [ ON ( expresión [, ...] ) ] ]
    [ { * | expresión [ [ AS ] nombre_salida ] } [, ...] ]
    INTO [ TEMPORARY | TEMP | UNLOGGED ] [ TABLE ] nueva_tabla
    [ FROM elemento_desde [, ...] ]
    [ WHERE condición ]
    [ GROUP BY expresión [, ...] ]
    [ HAVING condición ]
    [ WINDOW nombre_ventana AS ( definición_ventana ) [, ...] ]
    [ { UNION | INTERSECT | EXCEPT } [ ALL | DISTINCT ] select ]
    [ ORDER BY expresión [ ASC | DESC | USING operador ] [ NULLS { FIRST | LAST } ] [, ...] ]
    [ LIMIT { conteo | ALL } ]
    [ OFFSET inicio [ ROW | ROWS ] ]
    [ FETCH { FIRST | NEXT } [ conteo ] { ROW | ROWS } ONLY ]
    [ FOR { UPDATE | SHARE } [ OF nombre_tabla [, ...] ] [ NOWAIT ] [...] ]

DESCRIPCIÓN

SELECT INTO crea una nueva tabla y la llena con datos calculados por una consulta. Los datos no se devuelven al cliente, como ocurre con un SELECT normal. Las columnas de la nueva tabla tendrán los nombres y tipos de datos asociados con las columnas de salida del SELECT.

PARÁMETROS

TEMPORARY o TEMP

Si se especifica, la tabla se crea como una tabla temporal. Consulte CREATE TABLE (CREATE_TABLE(7)) para obtener más detalles.

UNLOGGED

Si se especifica, la tabla se crea como una tabla no registrada. Consulte CREATE TABLE (CREATE_TABLE(7)) para obtener más detalles.

nueva_tabla

El nombre (opcionalmente calificado por esquema) de la tabla a crear.

Todos los demás parámetros se describen en detalle en SELECT(7).

NOTAS

CREATE TABLE AS es funcionalmente similar a SELECT INTO. CREATE TABLE AS es la sintaxis recomendada, ya que esta forma de SELECT INTO no está disponible en ECPG o PL/pgSQL, porque interpretan la cláusula INTO de manera diferente. Además, CREATE TABLE AS ofrece un superconjunto de la funcionalidad proporcionada por SELECT INTO.

En contraste con CREATE TABLE AS, SELECT INTO no permite especificar propiedades como el método de acceso de una tabla con USING method o el tablespace de la tabla con TABLESPACE nombre_tablespace. Utilice CREATE TABLE AS si es necesario. Por lo tanto, se elige el método de tabla predeterminado para la nueva tabla. Consulte default_table_access_method para obtener más información.

EJEMPLOS

Crear una nueva tabla films_recent que contenga solo entradas recientes de la tabla films:

SELECT * INTO films_recent FROM films WHERE date_prod >= '2002-01-01';

COMPATIBILIDAD

El estándar SQL utiliza SELECT INTO para representar la selección de valores en variables escalares de un programa anfitrión, en lugar de crear una nueva tabla. Este es, de hecho, el uso que se encuentra en ECPG (consulte el Capítulo 34) y PL/pgSQL (consulte el Capítulo 41). El uso de PostgreSQL de SELECT INTO para representar la creación de tablas es histórico. Algunas otras implementaciones SQL también utilizan SELECT INTO de esta manera (pero la mayoría de las implementaciones SQL admiten CREATE TABLE AS en su lugar). Aparte de tales consideraciones de compatibilidad, es mejor usar CREATE TABLE AS para este propósito en código nuevo.

VER TAMBIÉN
