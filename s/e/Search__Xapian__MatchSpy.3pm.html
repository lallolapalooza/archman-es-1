NOMBRE

Search::Xapian::MatchSpy - clase base abstracta para espías de coincidencias.

DESCRIPCIÓN

Esta es una clase base abstracta para espías de coincidencias en Xapian.

Las subclases generalmente acumularán información vista durante la coincidencia, para calcular funciones agregadas u otros perfiles de los documentos coincidentes.

MÉTODOS

operador() <Documento> <peso>
Virtual - debe ser implementado en las clases que extienden. Registra un documento con el espía de coincidencias.

Esto es llamado por el motor de búsqueda una vez con cada documento visto por el motor de búsqueda durante el proceso de coincidencia. Tenga en cuenta que el motor de búsqueda a menudo no verá todos los documentos que coinciden con la consulta, debido a optimizaciones que permiten omitir documentos de bajo peso y permiten que el proceso de coincidencia termine temprano.

get_description
Devuelve una cadena que describe este objeto.

Esta implementación predeterminada devuelve una respuesta genérica, para evitar forzar a aquellos que derivan sus propias subclases MatchSpy a implementar esto (puede que no les importe lo que get_description() proporcione para su subclase).

Reimplementado en Xapian::ValueCountMatchSpy.

name
Devuelve el nombre de este espía de coincidencias.

Este nombre es utilizado por el backend remoto. Se pasa con los parámetros serializados al servidor remoto para que sepa qué clase crear. Devuelva el nombre completo calificado por el espacio de nombres de su clase aquí. Si no desea admitir el backend remoto en su espía de coincidencias, puede usar la implementación predeterminada que simplemente lanza Xapian::UnimplementedError.

Reimplementado en Xapian::ValueCountMatchSpy.
