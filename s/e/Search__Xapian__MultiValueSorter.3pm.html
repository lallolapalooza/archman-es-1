NOMBRE

Search::Xapian::MultiValueSorter - permite ordenar por varios valores.

DESCRIPCIÓN

Los resultados se ordenan por el primer valor. En caso de empate, se utiliza el segundo. Si este es el mismo para ambos, se utiliza el tercero, y así sucesivamente.

SINOPSIS

use Search::Xapian;
my $db = new Search::Xapian::Database("/ruta/a/db");
my $enq = new Search::Xapian::Enquire($db);
my $sorter = new Search::Xapian::MultiValueSorter(1, 3, 5);
$enq->set_sort_by_key($sorter);

MÉTODOS

new [<valor>...]
Construye y añade los valores listados.
add <valor> [<ascendente>]
Añade otro valor para ordenar. Por defecto, los valores se ordenan ascendentemente, a menos que se especifique lo contrario y sea falso.
