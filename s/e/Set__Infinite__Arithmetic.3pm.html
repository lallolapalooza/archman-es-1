NOMBRE

Set::Infinite::Arithmetic - Operaciones escalares usadas por quantize() y offset()

AUTOR

Flavio Soibelmann Glock - fglock@pucrs.br

%_MODE hash de subrutinas

$a->offset ( value => [1,2], mode => 'offset', unit => 'days' );
$a->offset ( value => [1,2, -5,-4], mode => 'offset', unit => 'days' );

nota: si mode = circle, entonces "-5" cuenta desde el final (como un índice de array negativo de Perl).

$a->offset ( value => [1,2], mode => 'offset', unit => 'days', strict => $a );

la opción 'strict' devolverá intersection($a,offset). Por defecto: ninguno.

%subs_offset2($object, $offset1, $offset2)

&{ $subs_offset2{$unit} } ($object, $offset1, $offset2);

Un hash de funciones que devuelven:

($object+$offset1, $object+$offset2)

en contexto de $unit.

El $object+$offset1 devuelto, $object+$offset2 pueden ser escalares u objetos.

%Offset_to_value($object, $offset)

%Init_quantizer($object)

$Offset_to_value{$unit} ($object, $offset);
$Init_quantizer{$unit} ($object);

Mapea un 'valor de desplazamiento' a un 'valor'

Un hash de funciones que devuelven ( int($object) + $offset ) en contexto de $unit.

Las subrutinas de Init_quantizer deben ser llamadas antes de usar las funciones subs_offset1.

int(objeto)+desplazamiento es un escalar.

Offset_to_value está optimizado para ser llamado múltiples veces sobre el mismo objeto, con diferentes desplazamientos. Es por eso que hay una subrutina de inicialización separada.

$self->{offset} se crea en la inicialización. Es un índice usado por la caché de memorización.
