Xapian::PositionIterator(3) Documentación de Perl aportada por el usuario Xapian::PositionIterator(3)

NOMBRE

Search::Xapian::PositionIterator - Iterar sobre conjuntos de posiciones.

DESCRIPCIÓN

Este iterador representa un flujo de posiciones para un término. Sobrecarga "++" para avanzar el iterador, o puedes llamar explícitamente al método "inc". Esta clase también sobrecarga "eq", "ne", "==", "!=", "" (conversión a cadena) y "0+" (conversión a entero).

MÉTODOS

new
Constructor. Por defecto, es un iterador no inicializado.
clone
inc
Avanza el iterador una posición. (Se llama implícitamente al sobrecargar "++").
skip_to <posicion_termino>
Salta el iterador a la posición de término posicion_termino, o a la primera posición de término después de posicion_termino si posicion_termino no está en la lista de posiciones de término que se están iterando.
equal <termino>
Comprueba si un término es igual a este término. También sobrecargado para los operadores "eq" y "==".
nequal <termino>
Comprueba si un término es diferente a este término. También sobrecargado para los operadores "ne" y "!=".
get_termpos
Devuelve la posición del término en la que se encuentra actualmente el iterador. También implementado como conversión a un entero.
get_description
Devuelve una descripción de este objeto. También implementado como conversión a cadena.

VER TAMBIÉN

Search::Xapian, Search::Xapian::Document
