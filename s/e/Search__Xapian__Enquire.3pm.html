NOMBRE

Search::Xapian::Enquire - Realizar consultas contra una base de datos

DESCRIPCIÓN

Esta clase proporciona una interfaz al sistema de recuperación de información con el propósito de realizar búsquedas.

set_docid_order <orden>
Establece la dirección en la que se ordenan los documentos por ID de documento en el MSet devuelto.

Este orden solo tiene efecto en los documentos que de otro modo tendrían el mismo rango. Para una coincidencia probabilística ponderada sin valor de ordenación, esto significa documentos con el mismo peso. Para una coincidencia booleana, sin valor de ordenación, esto significa todos los documentos. Y si se utiliza un valor de ordenación, esto significa documentos con el mismo valor de ordenación (y también el mismo peso si se ordena por relevancia después de la ordenación).

el orden puede ser ENQ_ASCENDING (el predeterminado, los docids se ordenan en orden ascendente), ENQ_DESCENDING (los docids se ordenan en orden descendente), o ENQ_DONT_CARE (los docids se ordenan en el orden que sea más eficiente para el backend.)

Nota: Si añade documentos en orden estricto de fecha, una búsqueda booleana, es decir, set_weighting_scheme(Search::Xapian::BoolWeight->new()) con set_docid_order(ENQ_DESCENDING) es una forma muy eficiente de realizar "ordenar por fecha, las más nuevas primero".

set_cutoff <porcentaje_corte> [<peso_corte>]
set_sort_by_relevance
Establece la ordenación solo por relevancia. Esta es la opción predeterminada.
set_sort_by_value <clave_ordenación> [<ascendente>]
Establece la ordenación solo por valor.

clave_ordenación - número de valor para reordenar. La ordenación se realiza mediante una comparación de cadenas. Si ascendente es verdadero (el predeterminado), lo más alto es mejor; si ascendente es falso, lo más bajo es mejor.

ascendente - Si es verdadero, los valores de documento que se ordenan más alto por comparación de cadenas son mejores. Si es falso, el orden de clasificación se invierte. (predeterminado verdadero)

set_sort_by_value_then_relevance <clave_ordenación> [<ascendente>]
Establece la ordenación por valor, y luego por relevancia para documentos con el mismo valor.

clave_ordenación - número de valor para reordenar. La ordenación se realiza mediante una comparación de cadenas. Si ascendente es verdadero (el predeterminado), lo más alto es mejor; si ascendente es falso, lo más bajo es mejor.

ascendente - Si es verdadero, los valores de documento que se ordenan más alto por comparación de cadenas son mejores. Si es falso, el orden de clasificación se invierte. (predeterminado verdadero)

set_sort_by_relevance_then_value <clave_ordenación> [<ascendente>]
Establece la ordenación por relevancia y luego por valor.

Tenga en cuenta que con los parámetros predeterminados del esquema de ponderación BM25, los documentos no idénticos rara vez tendrán el mismo peso, por lo que esta configuración dará resultados muy similares a set_sort_by_relevance(). Se vuelve más útil con configuraciones de parámetros BM25 particulares (por ejemplo, BM25Weight(1,0,1,0,0)) o esquemas de ponderación personalizados.

clave_ordenación - número de valor para reordenar. La ordenación se realiza mediante una comparación de cadenas. Si ascendente es verdadero (el predeterminado), lo más alto es mejor; si ascendente es falso, lo más bajo es mejor.

ascendente - Si es verdadero, los valores de documento que se ordenan más alto por comparación de cadenas son mejores. Si es falso, el orden de clasificación se invierte. (predeterminado verdadero)

set_sort_by_key <ordenador> [<ascendente>]
Establece la ordenación solo por clave.

ordenador - el functor a utilizar para construir la clave.

ascendente - Si es verdadero, las claves que se ordenan más alto por comparación de cadenas son mejores. Si es falso, el orden de clasificación se invierte. (predeterminado verdadero)

set_sort_by_key_then_relevance <ordenador> [<ascendente>]
Establece la ordenación por clave, y luego por relevancia para documentos con la misma clave.

ordenador - el functor a utilizar para construir la clave.

ascendente - Si es verdadero, las claves que se ordenan más alto por comparación de cadenas son mejores. Si es falso, el orden de clasificación se invierte. (predeterminado verdadero)

set_sort_by_relevance_then_key <ordenador> [<ascendente>]

ordenador - el functor a utilizar para construir la clave.

ascendente - Si es verdadero, las claves que se ordenan más alto por comparación de cadenas son mejores. Si es falso, el orden de clasificación se invierte. (predeterminado verdadero)
