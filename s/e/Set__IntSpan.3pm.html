DESCRIPCIÓN

"Set::IntSpan" gestiona conjuntos de enteros. Está optimizado para conjuntos que tienen largas secuencias de enteros consecutivos. Estos surgen, por ejemplo, en archivos .newsrc, que mantienen listas de artículos:

alt.foo: 1-21,28,31
alt.bar: 1-14192,14194,14196-14221

Una secuencia de enteros consecutivos también se llama un span.

Los conjuntos se almacenan internamente en un formato codificado de longitud de ejecución (run-length). Esto proporciona tanto un almacenamiento compacto como un cálculo eficiente. En particular, las operaciones de conjunto se pueden realizar directamente en la representación codificada.

"Set::IntSpan" está diseñado para gestionar conjuntos finitos. Sin embargo, también puede representar algunos conjuntos infinitos simples, como { x | x>n }. Esto permite que las operaciones que involucran complementos se lleven a cabo de manera consistente, sin tener que preocuparse por el valor real de INT_MAX en su máquina.

SPANS

Un span es una secuencia de enteros consecutivos. Un span puede ser representado por una referencia de array, en cualquiera de las 5 formas:

Formas finitas

  Span                Conjunto
[ $n,    $n    ]      { n }
[ $a,    $b    ]      { x | a<=x && x<=b}

Formas infinitas

  Span                Conjunto
[ undef, $b    ]      { x | x<=b }
[ $a   , undef ]      { x | x>=a }
[ undef, undef ]      El conjunto de todos los enteros

Algunos métodos operan directamente sobre spans.

ESPECIFICACIONES DE CONJUNTO

Muchos de los métodos toman una especificación de conjunto. Hay cuatro tipos de especificaciones de conjunto.

Vacío

Si se omite una especificación de conjunto, se asume el conjunto vacío. Por lo tanto,

$set = new Set::IntSpan;

crea un nuevo conjunto vacío. De manera similar,

copy $set;

elimina todos los elementos de $set.

Referencia a objeto

Si se proporciona una referencia a objeto, se toma como un objeto "Set::IntSpan".

Lista de ejecución

Si se proporciona una cadena, se toma como una lista de ejecución. Una lista de ejecución especifica un conjunto utilizando una sintaxis similar a la de los archivos newsrc.

Una lista de ejecución es una lista separada por comas de ejecuciones. Cada ejecución especifica un conjunto de enteros consecutivos. El conjunto es la unión de todas las ejecuciones.

Las ejecuciones pueden escribirse en cualquiera de las 5 formas.

Formas finitas

n
{ n }
a-b
{ x | a<=x && x<=b }

Formas infinitas

-n
{ x | x<=n }
n-
{ x | x>=n }
-
El conjunto de todos los enteros

Formas vacías

El conjunto vacío se escribe consistentemente como '' (la cadena nula). También se denota por la forma especial '-' (un solo guión).

Restricciones

Las ejecuciones en una lista de ejecución deben ser disjuntas y deben listarse en orden creciente.

Los caracteres válidos en una lista de ejecución son 0-9, '(', ')', '-' y ','. Los espacios en blanco y el guión bajo (_) se ignoran. No se permiten otros caracteres.

Ejemplos

Lista de ejecución    Conjunto
"-"               { }
"1"               { 1 }
"1-2"             { 1, 2 }
"-5--1"           { -5, -4, -3, -2, -1 }
"(-)"             los enteros
"(--1"            los enteros negativos
"1-3, 4, 18-21"   { 1, 2, 3, 4, 18, 19, 20, 21 }

Referencia a array

Si se proporciona una referencia a array, los elementos del array especifican los elementos del conjunto. El array puede contener

  • enteros
  • spans

El conjunto es la unión de todos los enteros y spans en el array. Los enteros y spans no necesitan ser disjuntos. Los enteros y spans pueden estar en cualquier orden.

Ejemplos

Referencia de array                   Conjunto
[ ]                               { }
[ 1, 1 ]                          { 1 }
[ 1, 3, 2 ]                       { 1, 2, 3 }
[ 1, [ 5, 8 ], 5, [ 7, 9 ], 2 ]   { 1, 2, 5, 6, 7, 8, 9 }
[ undef, undef ]                  los enteros
[ undef, -1 ]                     los enteros negativos

ITERADORES

Cada conjunto tiene un único iterador, que es compartido por todas las llamadas a "first", "last", "start", "next"

ITERATOR

The iterator is a scalar value that can be one of three strings: "first", "last", "prev", and "current". At all times, the iterator is either an element of the set, or "undef".

"first", "last", and "start" set the iterator; "next", and "prev" move it; and "current" returns it. Calls to these methods may be freely intermixed.

Using "next" and "prev", a single loop can move both forwards and backwards through a set. Using "start", a loop can iterate over portions of an infinite set.

MÉTODOS

Creación

$set = "new" "Set::IntSpan" $set_spec
$set = "new" "Set::IntSpan" @set_specs
Crea y devuelve un objeto "Set::IntSpan".

El contenido inicial del conjunto viene dado por $set_spec, o por la unión de todos los @set_specs.

$ok = "valid" "Set::IntSpan" $run_list
Devuelve verdadero si $run_list es una lista de intervalos válida. De lo contrario, devuelve falso y deja un mensaje de error en $@.
$set = "copy" $set $set_spec
Copia $set_spec en $set. El contenido anterior de $set se pierde. Para mayor comodidad, "copy" devuelve $set.
$run_list = "run_list" $set
Devuelve una lista de intervalos que representa $set. La lista de intervalos no contendrá espacios en blanco. $set no se ve afectado.

Por defecto, el conjunto vacío se formatea como '-'; se puede especificar una cadena diferente en $Set::IntSpan::Empty_String.

@elements = "elements" $set
Devuelve una matriz que contiene los elementos de $set. Los elementos se ordenarán numéricamente. En contexto escalar, devuelve una referencia de matriz. $set no se ve afectado.
@sets = "sets" $set
Devuelve los intervalos en $set, como una lista de objetos "Set::IntSpan". Los conjuntos de la lista están en orden.
@spans = "spans" $set
Devuelve los intervalos en $set, como una lista de la forma 
([$a1, $b1],
 [$a2, $b2],
 ...
 [$aN, $bN])

Si un intervalo contiene solo un entero, los límites superior e inferior del intervalo correspondiente serán iguales.

Si el conjunto no tiene límite inferior, entonces $a1 será "undef". De manera similar, si el conjunto no tiene límite superior, entonces $bN será "undef".

Los intervalos de la lista están en orden.

Operaciones de conjunto

Para estas operaciones, se crea y devuelve un nuevo objeto "Set::IntSpan". Los operandos no se ven afectados.

$u_set = "union" $set $set_spec
Devuelve el conjunto de enteros que están en $set o $set_spec.
$i_set = "intersect" $set $set_spec
Devuelve el conjunto de enteros que están en $set y $set_spec.
$x_set = "xor" $set $set_spec
Devuelve el conjunto de enteros que están en $set o $set_spec, pero no en ambos.
$d_set = "diff" $set $set_spec
Devuelve el conjunto de enteros que están en $set pero no en $set_spec.
$c_set = "complement" $set
Devuelve el conjunto de enteros que no están en $set.

Mutadores

Por demanda popular, "Set::IntSpan" ahora tiene formas mutantes de las operaciones de conjunto binarias. Estos métodos alteran el objeto sobre el que se llaman.

$set->"U"($set_spec)
Convierte $set en la unión de $set y $set_spec. Devuelve $set.
$set->"I"($set_spec)
Convierte $set en la intersección de $set y $set_spec. Devuelve $set.
$set->"X"($set_spec)
Convierte $set en la diferencia simétrica de $set y $set_spec. Devuelve $set.
$set->"D"($set_spec)
Convierte $set en la diferencia de $set y $set_spec. Devuelve $set.
$set->"C"
Convierte $set en su propio complemento. Devuelve $set.

Comparación

Devuelve verdadero si $set y $set_spec contienen los mismos elementos.
"equivalent" $set $set_spec
Devuelve verdadero si $set y $set_spec contienen el mismo número de elementos. Todos los conjuntos infinitos son equivalentes.

"subset" $set $set_spec

Devuelve verdadero si $set es finito.

Spans

$holes = "holes" $set
Returns a set containing all the holes in $set, that is, all the integers that are in-between spans of $set.

"holes" is always a finite set.

$cover = "cover" $set
Returns a set consisting of a single span from $set->"min" to $set->"max". This is the same as 
union $set $set->holes
$inset = "inset" $set $n
$smaller = "trim" $set $n
$bigger = "pad" $set $n
"inset" returns a set constructed by removing $n integers from each end of each span of $set. If $n is negative, then -$n integers are added to each end of each span.

In the first case, spans may vanish from the set; in the second case, holes may vanish.

"trim" is provided as a synonym for "inset".

"pad" $set $n is the same as "inset" $set -$n.

Iterators

$set->"first"
Sets the iterator for $set to the smallest element of $set. If there is no smallest element, sets the iterator to "undef". Returns the iterator.
$set->"last"
Sets the iterator for $set to the largest element of $set. If there is no largest element, sets the iterator to "undef". Returns the iterator.
$set->"start"($n)
Sets the iterator for $set to $n. If $n is not an element of $set, sets the iterator to "undef". Returns the iterator.
$set->"next"
Sets the iterator for $set to the next element of $set. If there is no next element, sets the iterator to "undef". Returns the iterator.

"next" will return "undef" only once; the next call to "next" will reset the iterator to the smallest element of $set.

$set->"prev"
Sets the iterator for $set to the previous element of $set. If there is no previous element, sets the iterator to "undef". Returns the iterator.

"prev" will return "undef" only once; the next call to "prev" will reset the iterator to the largest element of $set.

$set->"current"
Returns the iterator for $set.

Indexing

The elements of a set are kept in numerical order. These methods index into the set based on this ordering.

$n = $set->"at"($i)
Returns the $ith element of $set, or "undef" if there is no $ith element. Negative indices count backwards from the end of the set.

Dies if

  • $i is non-negative and $set is "neg_inf"
  • $i is negative and $set is "pos_inf"
$slice = $set->"slice"($from, $to)
Returns a "Set::IntSpan" object containing the elements of $set at indices $from..$to. Negative indices count backwards from the end of the set.

Dies if

  • $from is non-negative and $set is "neg_inf"
  • $from is negative and $set is "pos_inf"
$i = $set->"ord"($n)
The inverse of "at".

Returns the index $i of the integer $n in $set, or "undef" if $n if not an element of $set.

Dies if $set is "neg_inf".

$i = $set->"span_ord"($n)
Returns the index $i of the span containing the integer $n, or "undef" if $n if not an element of $set.

To recover the span containing $n, write

(($set->spans)[$i])

OPERATOR OVERLOADS

For convenience, some operators are overloaded on Set::IntSpan objects.

Set operations

One operand must be a Set::IntSpan object. The other operand may be a Set::IntSpan object or a set specification.

$u_set =  $set + $set_spec;   # union
$i_set =  $set * $set_spec;   # intersect
$x_set =  $set ^ $set_spec;   # xor
$d_set =  $set - $set_spec;   # diff
$c_set = ~$set;               # complement
$set += $set_spec;            # union
$set *= $set_spec;            # intersect
$set ^= $set_spec;            # xor
$set -= $set_spec;            # diff

equality

The string comparison operations are overloaded to compare sets for equality and containment. One operand must be a Set::IntSpan object. The other operand may be a Set::IntSpan object or a set specification.

$set eq $set_spec             # equal
$set ne $set_spec             # not equal
$set le $set_spec             # subset
$set lt $set_spec             # proper subset
$set ge $set_spec             # superset
$set gt $set_spec             # proper superset

equivalence

The numerical comparison operations are overloaded to compare sets by cardinality. One operand must be a Set::IntSpan object. The other operand may be a Set::IntSpan object or an integer.

$set1 ==  $set2
$set1 !=  $set2
$set1 <=  $set2
$set1 <   $set2
$set1 >=  $set2
$set1 >   $set2
$set1 <=> $set2
$set1 cmp $set2
$set1 ==  $n
$set1 !=  $n
$set1 <=  $n
$set1 <   $n
$set1 >=  $n
$set1 >   $n
$set1 <=> $n
$set1 cmp $n

N.B. The "cmp" operator is overloaded to compare sets by cardinality, not containment. This is done so that

sort @sets

will sort a list of sets by cardinality.

conversion

In boolean context, a Set::IntSpan object evaluates to true if it is not empty.

A Set::IntSpan object stringizes to its run list.

FUNCTIONS

$sub_set = "grep_set" { ... } $set
Evaluates the BLOCK for each integer in $set (locally setting $_ to each integer) and returns a Set::IntSpan object containing those integers for which the BLOCK returns TRUE.

Returns

$new_set = $set->grep_set { ... }
Evalúa el BLOQUE para cada entero en $set (estableciendo localmente $_ a cada entero) y devuelve un objeto "Set::IntSpan" que contiene todos los enteros devueltos como resultados de todas esas evaluaciones.

Evalúa el BLOQUE en contexto de lista, por lo que cada elemento de $set puede producir cero, uno o más elementos en el conjunto devuelto. Los elementos pueden devolverse en cualquier orden y no es necesario que sean disjuntos.

Devuelve "undef" si $set es infinito.

$map_set = "map_set" { ... } $set
Evalúa el BLOQUE para cada intervalo en $set y devuelve un objeto "Set::IntSpan" que consta de la unión de todos los intervalos devueltos como resultados de todas esas evaluaciones.

Dentro del BLOQUE, $_ se establece localmente a una referencia de matriz de la forma 

[ $lower, $upper ]

donde $lower y $upper son los límites del intervalo. Si el intervalo contiene un solo entero, entonces $lower y $upper serán iguales. Si el intervalo no tiene límites, entonces el(los) elemento(s) correspondiente(s) de la matriz será(n) "undef".

$sub_set = "grep_spans" { ... } $set
Evalúa el BLOQUE para cada intervalo en $set y devuelve un objeto "Set::IntSpan" que contiene aquellos intervalos para los cuales el BLOQUE devuelve VERDADERO.

Dentro del BLOQUE, $_ se establece localmente a una referencia de matriz de la forma 

[ $lower, $upper ]

como se describe anteriormente para "grep_spans". Cada evaluación del BLOQUE debe devolver una lista de intervalos. Cada lista devuelta puede contener cero, uno o más intervalos. Los intervalos pueden devolverse en cualquier orden y no es necesario que sean disjuntos. Sin embargo, para cada intervalo delimitado, la restricción 

$lower <= $upper
debe cumplirse.

VARIABLES DE CLASE

$Set::IntSpan::Empty_String
$Set::IntSpan::Empty_String contiene la cadena que se devuelve cuando se llama a "run_list" en el conjunto vacío. $Empty_String es inicialmente '-'; alternativamente, puede establecerse en ''. Se deben evitar otros valores para garantizar que "run_list" siempre devuelva una lista de ejecución válida.

"run_list" accede a $Empty_String a través de una referencia almacenada en $set->{"empty_string"}. Las subclases que deseen anular el valor de $Empty_String pueden reasignar esta referencia.

$Set::IntSpan::integer
Hasta la versión 1.16, "Set::IntSpan" especificaba "use integer", porque eran conjuntos de... bueno... enteros. A partir de 2012, los usuarios informan en grupos de noticias sobre números de artículos superiores a 0x7fffffff, lo que interrumpe "Set::IntSpan" en procesadores de 32 bits.

La versión 1.17 elimina "use integer" por defecto. Esto extiende el rango utilizable de "Set::IntSpan" al número de bits en la mantisa de tu representación de punto flotante. Para dobles IEEE 754, esto es 53 bits, o alrededor de 9e15.

Hice una prueba de rendimiento de "Set::IntSpan" en un Pentium 4, y parece que "use integer" proporciona una mejora de velocidad del 2% al 4%, dependiendo de la aplicación.

Si desea recuperar "use integer", ya sea por rendimiento o porque depende de alguna manera de su semántica, escriba 

BEGIN { $Set::IntSpan::integer = 1 }  
        use Set::IntSpan;

DIAGNÓSTICOS

Cualquier método (excepto "valid") hará "die" si se le pasa una lista de ejecución no válida.

"Set::IntSpan::_copy_run_list: Bad syntax:" $runList
(F) $run_list tiene sintaxis incorrecta
"Set::IntSpan::_copy_run_list: Bad order:" $runList
(F) $run_list tiene ejecuciones superpuestas o ejecuciones fuera de orden.
"Set::IntSpan::elements: infinite set"
(F) Se pasó un conjunto infinito a "elements".

NOTAS

Trampas

Cuidado con formas como

union $set [1..5];

Esto pasa un elemento de @set a union, lo cual probablemente no es lo que quieres. Para forzar la interpretación de $set y [1..5] como argumentos separados, usa formas como

union $set +[1..5];

o

$set->union([1..5]);

grep_set y map_set

"grep_set" y "map_set" facilitan la construcción de conjuntos para los cuales la representación interna utilizada por "Set::IntSpan" no es pequeña. Considera:

$billion = new Set::IntSpan '0-1_000_000_000';   # OK  
$odd     = grep_set { $_ & 1 } $billion;         # problema  
$even    = map_set  { $_ * 2 } $billion;         # doble problema

Manejo de errores

Hay dos enfoques comunes para el manejo de errores: excepciones y códigos de retorno. Parece haber algo de religión sobre el tema, por lo que "Set::IntSpan" proporciona soporte para ambos.

Para capturar excepciones, protege las llamadas a métodos con un eval:

$run_list = <STDIN>;  
eval { $set = new Set::IntSpan $run_list };  
$@ and print "$@: try again\n";

Para comprobar los códigos de retorno, utiliza una llamada de método adecuada para validar los argumentos:

$run_list = <STDIN>;  
if (valid Set::IntSpan $run_list)  
   { $set = new Set::IntSpan $run_list }  
else  
   { print "$@ try again\n" }

De manera similar, usa "finite" para proteger las llamadas a "elements":

finite $set and @elements = elements $set;

Llamar a "elements" en un conjunto finito grande puede generar un mensaje de "¡Memoria agotada!", que no se puede (fácilmente) atrapar. Las aplicaciones que deben mantener el control después de un error pueden usar "intersect" para proteger las llamadas a "elements":

@elements = elements { intersect $set "-1_000_000 - 1_000_000" };

o comprueba el tamaño de $set primero:

finite $set and cardinality $set < 2_000_000 and @elements = elements $set;

Limitaciones

Aunque "Set::IntSpan" puede representar algunos conjuntos infinitos, *no* realiza aritmética de precisión infinita. Por lo tanto, los elementos finitos están restringidos al rango de enteros en tu máquina.

Extensiones

Los usuarios informan que puedes construir objetos Set::IntSpan en cualquier cosa que se comporte como un entero. Por ejemplo:

$x   = new Math::BigInt ...;  
$set = new Set::Intspan [ [ $x, $x+5 ] ];

No documento esto como comportamiento soportado, porque no tengo los recursos para probarlo, pero intentaré no romperlo. Si alguien encuentra problemas con él, que me lo haga saber.

Raíces

Los conjuntos implementados aquí se basan en una estructura de datos de Macintosh llamada *región*. Consulte Inside Macintosh para obtener más información.

"Set::IntSpan" se escribió originalmente para administrar listas de ejecución para el módulo "News::Newsrc".
