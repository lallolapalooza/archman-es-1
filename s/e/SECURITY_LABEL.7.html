SECURITY LABEL(7) Documentación de PostgreSQL 18.1 SECURITY LABEL(7)

NOMBRE

SECURITY LABEL — definir o cambiar una etiqueta de seguridad aplicada a un objeto

SINOPSIS

SECURITY LABEL [ FOR proveedor ] ON
{
  TABLE nombre_objeto |
  COLUMN nombre_tabla.nombre_columna |
  AGGREGATE nombre_agregado ( firma_agregado ) |
  DATABASE nombre_objeto |
  DOMAIN nombre_objeto |
  EVENT TRIGGER nombre_objeto |
  FOREIGN TABLE nombre_objeto |
  FUNCTION nombre_funcion [ ( [ [ modo_arg ] [ nombre_arg ] tipo_arg [, ...] ] ) ] |
  LARGE OBJECT oid_objeto_grande |
  MATERIALIZED VIEW nombre_objeto |
  [ PROCEDURAL ] LANGUAGE nombre_objeto |
  PROCEDURE nombre_procedimiento [ ( [ [ modo_arg ] [ nombre_arg ] tipo_arg [, ...] ] ) ] |
  PUBLICATION nombre_objeto |
  ROLE nombre_objeto |
  ROUTINE nombre_rutina [ ( [ [ modo_arg ] [ nombre_arg ] tipo_arg [, ...] ] ) ] |
  SCHEMA nombre_objeto |
  SEQUENCE nombre_objeto |
  SUBSCRIPTION nombre_objeto |
  TABLESPACE nombre_objeto |
  TYPE nombre_objeto |
  VIEW nombre_objeto
} IS { literal_cadena | NULL }
where firma_agregado is:
* |
[ modo_arg ] [ nombre_arg ] tipo_arg [ , ... ] |
[ [ modo_arg ] [ nombre_arg ] tipo_arg [ , ... ] ] ORDER BY [ modo_arg ] [ nombre_arg ] tipo_arg [ , ... ]

DESCRIPCIÓN

SECURITY LABEL aplica una etiqueta de seguridad a un objeto de base de datos. Se puede asociar un número arbitrario de etiquetas de seguridad, una por proveedor de etiquetas, a un objeto de base de datos determinado. Los proveedores de etiquetas son módulos cargables que se registran a sí mismos utilizando la función register_label_provider.


Nota

register_label_provider no es una función SQL; solo se puede llamar desde código C cargado en el backend.

El proveedor de etiquetas determina si una etiqueta dada es válida y si es permisible asignar esa etiqueta a un objeto dado. El significado de una etiqueta dada está igualmente a discreción del proveedor de etiquetas. PostgreSQL no impone restricciones sobre si o cómo un proveedor de etiquetas debe interpretar las etiquetas de seguridad; simplemente proporciona un mecanismo para almacenarlas. En la práctica, esta facilidad está destinada a permitir la integración con sistemas de control de acceso obligatorio (MAC) basados en etiquetas, como SELinux. Dichos sistemas toman todas las decisiones de control de acceso basándose en las etiquetas de los objetos, en lugar de conceptos tradicionales de control de acceso discrecional (DAC) como usuarios y grupos.

Debes ser propietario del objeto de la base de datos para usar SECURITY LABEL.

PARÁMETROS

nombre_objeto
nombre_tabla.nombre_columna
nombre_agregado
nombre_funcion
nombre_procedimiento
nombre_rutina

El nombre del objeto al que se le aplicará la etiqueta. Los nombres de los objetos que residen en esquemas (tablas, funciones, etc.) pueden estar calificados con el nombre del esquema.

proveedor

El nombre del proveedor con el que se asociará esta etiqueta. El proveedor nombrado debe estar cargado y debe consentir la operación de etiquetado propuesta. Si solo hay un proveedor cargado, el nombre del proveedor puede omitirse por brevedad.

modo_arg

El modo de un argumento de función, procedimiento o agregado: IN, OUT, INOUT o VARIADIC. Si se omite, el valor predeterminado es IN. Tenga en cuenta que SECURITY LABEL en realidad no presta atención a los argumentos OUT, ya que solo los argumentos de entrada son necesarios para determinar la identidad de la función. Por lo tanto, es suficiente enumerar los argumentos IN, INOUT y VARIADIC.

nombre_arg

El nombre de un argumento de función, procedimiento o agregado. Tenga en cuenta que SECURITY LABEL en realidad no presta atención a los nombres de los argumentos, ya que solo los tipos de datos de los argumentos son necesarios para determinar la identidad de la función.

tipo_arg

El tipo de datos de un argumento de función, procedimiento o agregado.

oid_objeto_grande

El OID del objeto grande.

PROCEDURAL

Esta es una palabra de relleno.

literal_cadena

La nueva configuración de la etiqueta de seguridad, escrita como un literal de cadena.

NULL

Escriba NULL para eliminar la etiqueta de seguridad.

EJEMPLOS

El siguiente ejemplo muestra cómo se podría establecer o cambiar la etiqueta de seguridad de una tabla:

SECURITY LABEL FOR selinux ON TABLE mytable IS 'system_u:object_r:sepgsql_table_t:s0';

Para eliminar la etiqueta:

SECURITY LABEL FOR selinux ON TABLE mytable IS NULL;

COMPATIBILIDAD

No existe un comando SECURITY LABEL en el estándar SQL.
