NOMBRE

Set::Infinite::Basic - Conjuntos de intervalos 6 =head1 SINOPSIS

use Set::Infinite::Basic;
$set = Set::Infinite::Basic->new(1,2);    # [1..2]
print $set->union(5,6);            # [1..2],[5..6]

DESCRIPCIÓN

Set::Infinite::Basic es un módulo de Teoría de Conjuntos para conjuntos infinitos.

Funciona con números reales, enteros y objetos.

Este módulo no soporta recurrencias. Las recurrencias están implementadas en Set::Infinite.

MÉTODOS

conjunto_vacío

Crea un conjunto vacío.

Si se llama desde un conjunto existente, el conjunto vacío hereda las características de "tipo" y "densidad".

conjunto_universal

Crea un conjunto que contiene "todos" los elementos posibles.

Si se llama desde un conjunto existente, el conjunto universal hereda las características de "tipo" y "densidad".

hasta

Extiende un conjunto hasta otro:

0,5,7 -> hasta 2,6,10

da

[0..2), [5..6), [7..10)

Nota: esta función todavía está en fase experimental.

copiar

clonar

Crea un nuevo objeto a partir de los datos del objeto.

ADVERTENCIAS

$set = Set::Infinite->new(10,1);
    Se interpretará como [1..10]
$set = Set::Infinite->new(1,2,3,4);
    Se interpretará como [1..2],[3..4] en lugar de [1,2,3,4].
    Probablemente quieras ->new([1],[2],[3],[4]) en su lugar,
    o quizás ->new(1,4) 
$set = Set::Infinite->new(1..3);
    Se interpretará como [1..2],3 en lugar de [1,2,3].
    Probablemente quieras ->new(1,3) en su lugar.

INTERNOS

La representación interna de un intervalo es un hash:

{ a =>   inicio del intervalo,
  b =>   fin del intervalo,
  open_begin =>   '0' el intervalo empieza en 'a'
                  '1' el intervalo empieza después de 'a'
  open_end =>     '0' el intervalo termina en 'b'
                  '1' el intervalo termina antes de 'b'
}

Por ejemplo, este conjunto:

[100..200),300,(400..infinito)

está representado por el array de hashes:

list => [
    { a => 100, b => 200, open_begin => 0, open_end => 1 },
    { a => 300, b => 300, open_begin => 0, open_end => 0 },
    { a => 400, b => infinity, open_begin => 0, open_end => 1 },
]

La densidad de un conjunto se almacena en la variable "tolerance":

tolerance => 0;  # el conjunto está formado por números reales.
tolerance => 1;  # el conjunto está formado por enteros.

La variable "type" almacena la clase de objetos que se almacenarán en el conjunto.

type => 'DateTime';   # este es un conjunto de objetos DateTime

El valor de infinito es generado por Perl, cuando encuentra un desbordamiento numérico:

$inf = 100**100**100;
