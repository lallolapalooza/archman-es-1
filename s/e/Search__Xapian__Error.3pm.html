Xapian::Error(3) Documentación de Perl contribuida por el usuario Xapian::Error(3)

NOMBRE

Search::Xapian::Error - Clase base para todas las excepciones en Search::Xapian

DESCRIPCIÓN

Esta es una clase abstracta en C++, es decir, no puede ser instanciada directamente. En Perl no existe tal concepto, pero no deberías necesitar crear instancias de esta clase tú mismo.

MÉTODOS

Todos los objetos de excepción tienen los siguientes métodos

get_msg

Devuelve una cadena con un mensaje de error descriptivo, útil para la salida

get_type

El tipo de este error (por ejemplo, "DocNotFoundError").

get_context

Información de contexto opcional, devuelta como una cadena

get_error_string

Devuelve cualquier cadena de error de errno o similar asociada con este error
