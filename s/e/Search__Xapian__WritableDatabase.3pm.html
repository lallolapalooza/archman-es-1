Search::Xapian::WritableDatabase(3) Documentación Perl aportada por el usuario Search::Xapian::WritableDatabase(3)

NOMBRE

Search::Xapian::WritableDatabase - objeto de base de datos de escritura

DESCRIPCIÓN

Esta clase representa una base de datos Xapian para indexación. Es una subclase de Search::Xapian::Database, que se utiliza para la búsqueda.

MÉTODOS

new <database> o new <path> <modo>
Constructor de clase. Recibe un objeto de base de datos o una ruta y uno de DB_OPEN, DB_CREATE, DB_CREATE_OR_OPEN o DB_CREATE_OR_OVERWRITE. Estos se exportan por Search::Xapian con la opción 'db'.
clone
Devuelve una copia de esta clase.
flush
Vuelca al disco cualquier modificación realizada en la base de datos.

Para mayor eficiencia, cuando se realizan múltiples actualizaciones a una base de datos, es mejor (de hecho, casi indispensable) realizar tantas modificaciones como sea posible en una única pasada sobre la base de datos. Para garantizar esto, Xapian agrupa las modificaciones.

flush puede ser llamado en cualquier momento para asegurar que las modificaciones realizadas se escriban en el disco: si flush tiene éxito, todas las modificaciones anteriores se habrán escrito en el disco.

Si alguna de las modificaciones falla, se lanzará una excepción y la base de datos quedará en un estado en el que cada operación individual de adición, reemplazo o eliminación se ha realizado completamente o no se ha realizado. Entonces, corresponde a la aplicación determinar qué operaciones deben repetirse.

Tenga en cuenta que flush no necesita ser llamado explícitamente; se llamará automáticamente cuando la base de datos se cierre, o cuando se hayan realizado suficientes modificaciones.

add_document <documento>
Añade un nuevo documento a la base de datos.

Este método añade el documento especificado a la base de datos, devolviendo un nuevo identificador de documento.

Nota: esto no significa que el documento aparezca inmediatamente en la base de datos; ver flush() para más detalles.

Al igual que con todas las operaciones de modificación de la base de datos, el efecto es atómico: el documento se añadirá completamente o se producirá un error y se lanzará una excepción (posiblemente en un futuro, cuando se ejecute flush o cuando se cierre la base de datos).

delete_document <doc_id>
Elimina un documento de la base de datos. Este método elimina el documento con el identificador de documento especificado de la base de datos.

Nota: esto no significa que el documento se elimine inmediatamente de la base de datos; ver flush() para más detalles.

Al igual que con todas las operaciones de modificación de la base de datos, el efecto es atómico: el documento se eliminará completamente o no se eliminará y se lanzará una excepción (posiblemente en un futuro, cuando se ejecute flush o cuando se cierre la base de datos).

delete_document_by_term <term>
Elimina cualquier documento indexado por un término de la base de datos. Este método elimina cualquier documento indexado por el término especificado de la base de datos.

El uso previsto es permitir que los UID de otros sistemas se mapeen fácilmente a términos en Xapian, aunque este método probablemente tiene otros usos.

replace_document <doc_id> <document>
Reemplaza un documento dado en la base de datos.

Este método reemplaza el documento con el identificador de documento especificado. La nota es que esto no significa que el documento se modifique inmediatamente en la base de datos; ver flush() para más detalles.

Al igual que con todas las operaciones de modificación de la base de datos, el efecto es atómico: el documento se reemplazará completamente o no se reemplazará y se lanzará una excepción (posiblemente en un futuro, cuando se ejecute flush o cuando se cierre la base de datos).

replace_document_by_term <unique_term> <document>
Reemplaza cualquier documento indexado por un término único.

Este método reemplaza cualquier documento indexado por el término especificado con el documento especificado. Si hay algún documento indexado por el término, se utilizará el ID más bajo posible para el documento, de lo contrario se generará un nuevo ID como en add_document.

El uso previsto es permitir que los UID de otros sistemas se mapeen fácilmente a términos en Xapian, aunque este método probablemente tiene otros usos.

Nota: esto no significa que el(los) documento(s) se modifique(n) inmediatamente en la base de datos; ver flush() para más detalles.

Al igual que con todas las operaciones de modificación de la base de datos, el efecto es atómico: el(los) documento(s) se reemplazará(n) completamente o no se reemplazará(n) y se lanzará una excepción (posiblemente en un futuro, cuando se ejecute flush o cuando se cierre la base de datos).

add_spelling <word> <freqinc>
Añade una palabra a la base de datos de diccionario de corrección ortográfica.

Si la palabra ya existe, su frecuencia se incrementa.

Parámetros:
palabra La palabra a añadir.
freqinc Cuánto incrementar su frecuencia (por defecto 1).

remove_spelling <word> <freqdec>
Elimina una palabra de la base de datos de diccionario de corrección ortográfica.

La frecuencia de la palabra se decrementa, y si se vuelve cero o menor, se elimina completamente.

Parámetros:
palabra La palabra a eliminar.
freqdec Cuánto decrementar su frecuencia (por defecto 1).

reopen
Reabre la base de datos para asegurar que estás utilizando la versión más reciente.
close
Cierra la base de datos. Esto también implica un commit(), a menos que haya una transacción en curso.
