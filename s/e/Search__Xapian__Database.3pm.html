NOMBRE

Search::Xapian::Database - Objeto de base de datos de búsqueda

DESCRIPCIÓN

Esta clase representa una base de datos Xapian para búsqueda. Vea Search::Xapian::WritableDatabase para un objeto adecuado para indexación. Para realizar búsquedas, esta clase trabaja con el objeto Search::Xapian::Query.

MÉTODOS

new <base de datos>
Constructor de clase. Puede tomar una ruta a una base de datos existente o otra clase de base de datos como primer parámetro.
clone
Devuelve un clon de esta clase.
add_database
Añade una base de datos existente (o grupo de bases de datos) a las accedidas por este objeto.
reopen
Reabre la(s) base(s) de datos a la(s) versión(es) más reciente(s) disponible(s). Puede usarse para asegurar que se devuelven los últimos resultados, o para recuperarse de un Xapian::DatabaseModifiedError.
close
Cierra la base de datos. Esto también implica un commit() a menos que haya una transacción en curso.
enquire [<consulta>]
Devuelve un nuevo objeto Search::Xapian::Enquire. Cualquier parámetro adicional se pasa a set_query.
get_doccount
Devuelve el número de documentos indexados en esta base de datos.
get_lastdocid
Devuelve el id del último documento utilizado.
get_doclength <id_doc>
Devuelve la longitud de un documento dado.
get_document <id_doc>
Devuelve un objeto Search::Xapian::Document para el documento dado.
get_avlength
Obtiene la longitud media de los documentos en la base de datos.
get_termfreq <término>
Obtiene el número de documentos en la base de datos indexados por un término dado.
term_exists <término>
devuelve verdadero si este término existe en la base de datos, o falso en caso contrario.
get_description
devuelve una descripción de este objeto.
get_spelling_suggestion
devuelve una corrección ortográfica sugerida.
allterms_begin [<prefijo>]
Devuelve un Search::Xapian::TermIterator que itera sobre la lista de términos para toda la base de datos. Si el argumento opcional prefijo no está vacío, solo se devuelven los términos que comienzan con esa cadena.
allterms_end [<prefijo>]
Devuelve un Search::Xapian::TermIterator que apunta al final de la lista de términos correspondiente a allterms_begin.
termlist_begin <id_doc>
Devuelve un Search::Xapian::TermIterator que apunta al inicio de la lista de términos para un documento dado.
termlist_end <id_doc>
Devuelve un Search::Xapian::TermIterator que apunta al final de la lista de términos para un documento dado.
positionlist_begin <id_doc> <término>
Devuelve un Search::Xapian::PositionIterator que apunta al inicio de la lista de posiciones para un término dado en un documento dado.
positionlist_end <id_doc> <término>
Devuelve un Search::Xapian::PositionIterator que apunta al final de la lista de posiciones para un término dado en un documento dado.
postlist_begin <término>
Devuelve un Search::Xapian::PostingIterator que apunta al inicio de la lista de postings para un término dado.
postlist_end <término>
Devuelve un Search::Xapian::PostingIterator que apunta al final de la lista de postings para un término dado.
keep_alive
Envía una señal de "mantener vivo" a las bases de datos remotas para evitar que caduquen.
get_collection_freq <término>
Obtiene el número de elementos indexados por un término determinado.
