val find_first : (elt -> bool) -> t -> elt

find_first f s , donde f es una función monotónicamente creciente, devuelve el elemento más bajo e de s tal que f e , o lanza Not_found si no existe dicho elemento.

Por ejemplo, find_first (fun e -> Ord.compare e x >= 0) s devolverá el primer elemento e de s donde Ord.compare e x >= 0 (en sentido intuitivo: e >= x ), o lanzará Not_found si x es mayor que cualquier elemento de s .

Transformación

val map : (elt -> elt) -> t -> t

map f s es el conjunto cuyos elementos son f a0 , f a1 ... f
aN , donde a0 , a1 ... aN son los elementos de s .

Los elementos se pasan a f en orden creciente con respecto al ordenamiento sobre el tipo de los elementos.

Si ningún elemento de s es cambiado por f , se devuelve s sin cambios. (Si cada salida de f es físicamente igual a su entrada, el conjunto devuelto es físicamente igual a s .)

Desde 4.04

val filter : (elt -> bool) -> t -> t

filter f s devuelve el conjunto de todos los elementos de s que satisfacen el predicado f . Si f satisface todos los elementos de s , se devuelve s sin cambios (el resultado de la función es entonces físicamente igual a s ).

Antes de 4.03 No se garantizaba la igualdad física.

val filter_map : (elt -> elt option) -> t -> t

filter_map f s devuelve el conjunto de todos los v tales que f x = Some v para algún elemento x de s .

Por ejemplo,

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
es el conjunto de las mitades de los elementos pares de s .

Si ningún elemento de s es cambiado o descartado por f (si f x = Some x para cada elemento x ), entonces se devuelve s sin cambios: el resultado de la función es entonces físicamente igual a s .

NAME

Set.S - The abstract set type.

Module type

functor (Ord : Ordered.S) -> sig ... end

This module type provides a generic implementation of sets. The elements can be of any type, as long as they can be ordered.

Documentation

The abstract set type.

A set with a single element.

Create a set from a list of elements. This is usually more efficient than folding add over the list, except perhaps for lists with many duplicated elements.

Return a set whose elements are all the elements of the original set that satisfy the predicate.

val partition : (elt -> bool) -> t -> t * t

Return a pair of sets (s1, s2), where s1 contains all elements that satisfy the predicate, and s2 all elements that do not satisfy the predicate.

val split : elt -> t -> t * bool * t

split x s returns a triple (l, present, r) such that l is the set of elements of s strictly less than x, r is the set of elements of s strictly greater than x, and present is true if x is present in s, false otherwise.
