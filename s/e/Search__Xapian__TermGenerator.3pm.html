NOMBRE

Search::Xapian::TermGenerator - Analiza un fragmento de texto y genera términos.

DESCRIPCIÓN

Este módulo toma un fragmento de texto y lo analiza para producir palabras que luego se utilizan para generar términos adecuados para la indexación. Los términos generados son adecuados para su uso con objetos Search::Xapian::Query producidos por la clase Search::Xapian::QueryParser.

SINOPSIS

use Search::Xapian;
my $doc = new Search::Xapian::Document();
my $tg = new Search::Xapian::TermGenerator();
$tg->set_stemmer(new Search::Xapian::Stem("english"));
$tg->set_document($doc);
$tg->index_text("El gato se sentó en la alfombra");

MÉTODOS

new
Constructor de TermGenerator.
set_stemmer <stemmer>
Establece el objeto Search::Xapian::Stem a utilizar para generar términos derivados.
set_stopper <stopper>
Establece el objeto Search::Xapian::Stopper a utilizar para identificar palabras vacías.
set_document <document>
Establece el objeto Search::Xapian::Document en el que indexar los términos.
get_document <document>
Obtiene el objeto Search::Xapian::Document establecido actualmente.
index_text <text> [<wdf_inc> [<prefix>]]
Indexa el texto de la cadena <text>. El parámetro opcional <wdf_inc> establece el incremento wdf (por defecto 1). El parámetro opcional <prefix> establece el prefijo de término a utilizar (por defecto no hay prefijo).
index_text_without_positions <text> [<wdf_inc> [<prefix>]]
Igual que index_text, pero no se genera información posicional. Esto significa que la base de datos será significativamente más pequeña, pero la búsqueda de frases y NEAR no será compatible.
increase_termpos [<delta>]
Aumenta el termpos utilizado por index_text en <delta> (por defecto 100).

Esto se puede utilizar para evitar que las búsquedas de frases abarquen dos bloques de texto no conectados (por ejemplo, el título y el cuerpo del texto).

get_termpos
Obtiene la posición actual del término.
set_termpos <termpos>
Establece la posición actual del término.
get_description
Devuelve una descripción de este objeto.
