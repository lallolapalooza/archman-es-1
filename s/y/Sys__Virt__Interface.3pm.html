NOMBRE

Sys::Virt::Interface - Representa y gestiona una interfaz de red de host libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::Interface" representa una interfaz de red de host que permite la configuración de direcciones IP, bonding, vlans y bridges.

MÉTODOS

mi $nombre = $iface->get_name()
Devuelve una cadena con un nombre localmente único de la red
$iface->is_active()
Devuelve un valor verdadero si la interfaz está actualmente en ejecución
mi $nombre = $iface->get_mac()
Devuelve una cadena con la dirección MAC de hardware de la interfaz
mi $xml = $iface->get_xml_description()
Devuelve un documento XML que contiene una descripción completa de la configuración de la red
$iface->create()
Inicia una red cuya configuración fue definida previamente usando el método "define_network" en Sys::Virt.
$iface->undefine()
Elimina la configuración asociada con una red definida previamente con el método "define_network" en Sys::Virt. Si la red está en ejecución, probablemente querrás usar los métodos "shutdown" o "destroy" en su lugar.
$iface->destroy()
Termina inmediatamente la máquina y la elimina del monitor de máquinas virtuales. El manejador $iface no es válido después de que esta llamada se complete y no debe usarse de nuevo.

Las siguientes constantes se pueden utilizar para controlar el comportamiento de las operaciones de definición de interfaz

CONSTANTES XML

Las siguientes constantes se utilizan al consultar XML

Sys::Virt::Interface::XML_INACTIVE
Solicita el XML inactivo, en lugar de la configuración activa actual posiblemente.
