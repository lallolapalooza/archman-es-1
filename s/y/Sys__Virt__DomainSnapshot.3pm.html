NOMBRE

Sys::Virt::DomainSnapshot - Representar y gestionar una instantánea de dominio de invitado de libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::DomainSnapshot" representa una instantánea de un dominio de invitado gestionado por el monitor de máquinas virtuales.

MÉTODOS

mi $cadena = $domss->get_name()
Devuelve el nombre de la instantánea
mi $xml = $domss->get_xml_description($flags)
Devuelve un documento XML que contiene una descripción completa de la configuración de la instantánea del dominio. El parámetro $flags acepta las siguientes constantes
Sys::Virt::DomainSnapshot::XML_SECURE
Incluir información sensible de seguridad en la exportación XML, como contraseñas.
$domss->delete($flags)
Elimina este objeto de instantánea y sus datos. El parámetro opcional $flags controla qué se debe eliminar a través de las constantes "Sys::Virt::DomainSnapshot::DELETE_*".
$domss->revert_to($flags)
Revierte el dominio al estado asociado con esta instantánea. El parámetro opcional $flags controla el estado de la VM después de la reversión a través de las constantes "Sys::Virt::DomainSnapshot::REVERT_*".
$padre = $domss->get_parent();
Devuelve el padre de la instantánea, si existe
$res = $domss->is_current()
Devuelve un valor verdadero si esta es la instantánea actual. Falso en caso contrario.
$res = $domss->has_metadata()
Devuelve un valor verdadero si esta instantánea tiene metadatos asociados.
$count = $domss->num_of_child_snapshot()
Devuelve el número de instantáneas guardadas que son hijas de esta instantánea
@nombres = $domss->list_child_snapshot_names()
Lista los nombres de todas las instantáneas guardadas que son hijas de esta instantánea. Los nombres se pueden usar con "lookup_snapshot_by_name".
@instantaneas = $domss->list_child_snapshots()
Devuelve una lista de todas las instantáneas que son hijas de esta instantánea. Los elementos de la lista devuelta son instancias de la clase Sys::Virt::DomainSnapshot. Este método requiere O(n) llamadas RPC, por lo que se recomienda el método "list_all_children" como una alternativa más eficiente.
mi @instantaneas = $domss->list_all_children($flags)
Devuelve una lista de todas las instantáneas de dominio que son hijas de esta instantánea. Los elementos de la lista devuelta son instancias de la clase Sys::Virt::DomainSnapshot. El parámetro $flags se puede utilizar para filtrar la lista de instantáneas de dominio devueltas.

CONSTANTES

CREACIÓN DE INSTANTÁNEAS

Las siguientes constantes son útiles al crear instantáneas

Sys::Virt::DomainSnapshot::CREATE_CURRENT
Establece la instantánea definida para que sea la instantánea actual
Sys::Virt::DomainSnapshot::CREATE_DISK_ONLY
Solo tomar instantánea del disco, no del estado de la memoria
Sys::Virt::DomainSnapshot::CREATE_HALT
Detener el invitado después de crear la instantánea
Sys::Virt::DomainSnapshot::CREATE_NO_METADATA
No guardar metadatos para la instantánea
Sys::Virt::DomainSnapshot::CREATE_REDEFINE
Reemplazar/establecer los metadatos con la instantánea
Sys::Virt::DomainSnapshot::CREATE_QUIESCE
Poner en estado de reposo los discos del invitado mientras se toma la instantánea
Sys::Virt::DomainSnapshot::CREATE_REUSE_EXT
Reutilizar los archivos de datos de instantánea existentes (si los hay)
Sys::Virt::DomainSnapshot::CREATE_ATOMIC
Crear múltiples instantáneas de disco atómicamente
Sys::Virt::DomainSnapshot::CREATE_LIVE
Crear instantánea mientras el invitado está en ejecución
Sys::Virt::DomainSnapshot::CREATE_VALIDATE
Validar el documento XML contra el esquema

ELIMINACIÓN DE INSTANTÁNEAS

Las siguientes constantes son útiles al eliminar instantáneas

Sys::Virt::DomainSnapshot::DELETE_CHILDREN
Eliminar recursivamente cualquier instantánea hija
Sys::Virt::DomainSnapshot::DELETE_CHILDREN_ONLY
Solo eliminar las instantáneas hijas
Sys::Virt::DomainSnapshot::DELETE_METADATA_ONLY
Solo eliminar los metadatos de la instantánea

LISTADO DE INSTANTÁNEAS

Las siguientes constantes son útiles al listar instantáneas

Sys::Virt::DomainSnapshot::LIST_METADATA
Solo listar instantáneas que tengan metadatos
Sys::Virt::DomainSnapshot::LIST_ROOTS
Solo listar instantáneas que sean nodos raíz en el árbol
Sys::Virt::DomainSnapshot::LIST_DESCENDANTS
Solo listar instantáneas que sean descendientes de la instantánea actual
Sys::Virt::DomainSnapshot::LIST_LEAVES
Solo listar nodos hoja en el árbol de instantáneas
Sys::Virt::DomainSnapshot::LIST_NO_LEAVES
Solo listar nodos no hoja en el árbol de instantáneas
Sys::Virt::DomainSnapshot::LIST_NO_METADATA
Solo listar instantáneas sin metadatos
Sys::Virt::DomainSnapshot::LIST_ACTIVE
Solo listar instantáneas tomadas mientras el invitado estaba en ejecución
Sys::Virt::DomainSnapshot::LIST_INACTIVE
Solo listar instantáneas tomadas mientras el invitado estaba inactivo
Sys::Virt::DomainSnapshot::LIST_EXTERNAL
Solo listar instantáneas almacenadas en imágenes de disco externas
Sys::Virt::DomainSnapshot::LIST_INTERNAL
Solo listar instantáneas almacenadas en imágenes de disco internas
Sys::Virt::DomainSnapshot - Perl's libvirt Domain Snapshot API

NAME

Sys::Virt::DomainSnapshot - Perl's libvirt Domain Snapshot API

DESCRIPTION

This module provides access to the libvirt API for managing virtual machine snapshots.

It is a subclass of Sys::Virt::Object.

METHODS

snapshot_create
Create a new snapshot for the domain.
snapshot_revert
Revert the domain to a previous snapshot.
snapshot_delete
Delete a snapshot.
snapshot_list
List all snapshots for the domain.
snapshot_lookup_by_name
Find a snapshot by its name.
snapshot_get_xml_desc
Get the XML description of a snapshot.

CONSTANTS

LIST CONSTANTS

The following constants are useful when listing snapshots

Sys::Virt::DomainSnapshot::LIST_DISK_ONLY
Only list snapshots taken while the guest was running, which did not include memory state.
Sys::Virt::DomainSnapshot::LIST_TOPOLOGICAL
Sort list in topological order wrt to parent/child relationships.

SNAPSHOT REVERT

The following constants are useful when reverting snapshots

Sys::Virt::DomainSnapshot::REVERT_PAUSED
Leave the guest CPUs paused after reverting to the snapshot state
Sys::Virt::DomainSnapshot::REVERT_RUNNING
Start the guest CPUs after reverting to the snapshot state
Sys::Virt::DomainSnapshot::REVERT_FORCE
Force the snapshot to revert, even if it is risky to do so
Sys::Virt::DomainSnapshot::REVERT_RESET_NVRAM
Reset the firmware NVRAM state from its original template
