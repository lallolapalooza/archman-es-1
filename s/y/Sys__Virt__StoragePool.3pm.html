NOMBRE

Sys::Virt::StoragePool - Representa y gestiona un pool de almacenamiento de libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::StoragePool" representa un pool de almacenamiento gestionado por libvirt. Existen una variedad de implementaciones de pools de almacenamiento para LVM, directorios/sistemas de archivos locales, sistemas de archivos de red, particionamiento de discos, iSCSI y SCSI.

MÉTODOS

mi $uuid = $pool->get_uuid()
Devuelve una cadena de 16 bytes que contiene el identificador único global (UUID) bruto para el pool de almacenamiento.
mi $uuid = $pool->get_uuid_string()
Devuelve una representación de cadena imprimible del UUID bruto, en el formato 'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX'.
mi $name = $pool->get_name()
Devuelve una cadena con un nombre localmente único del pool de almacenamiento.
$pool->is_active()
Devuelve un valor verdadero si el pool de almacenamiento se está ejecutando actualmente.
$pool->is_persistent()
Devuelve un valor verdadero si el pool de almacenamiento tiene un archivo de configuración persistente definido.
mi $xml = $pool->get_xml_description()
Devuelve un documento XML que contiene una descripción completa de la configuración del pool de almacenamiento.
$pool->create()
Inicia un pool de almacenamiento cuya configuración fue definida previamente utilizando el método "define_storage_pool" en Sys::Virt.
$pool->undefine()
Elimina la configuración asociada con un pool de almacenamiento definido previamente con el método "define_storage pool" en Sys::Virt. Si el pool de almacenamiento está en ejecución, es probable que desee utilizar el método "destroy" en su lugar.
$pool->destroy()
Detiene inmediatamente el pool de almacenamiento.
$flag = $pool->get_autostart();
Devuelve un valor verdadero si el pool de almacenamiento está configurado para iniciarse automáticamente al arrancar. Devuelve falso en caso contrario.
$pool->set_autostart($flag)
Establece el estado de la bandera de inicio automático, que determina si el pool de almacenamiento se iniciará automáticamente al arrancar el sistema operativo anfitrión.
$pool->refresh([$flags]);
Actualiza el estado del pool de almacenamiento. Típicamente, esto volverá a escanear la lista de volúmenes de almacenamiento. El parámetro $flags no se utiliza actualmente y, si se omite, predetermina a cero.
$pool->build([$flags]);
Construye el pool de almacenamiento si no existe. Como ejemplo, para un pool de almacenamiento basado en disco, esto aseguraría que existe una tabla de particiones. El parámetro $flags permite controlar la operación de construcción y, si se omite, predeter mina a cero.
$pool->delete([$flags]);
Elimina el pool de almacenamiento. El parámetro $flags permite opcionalmente borrar los datos durante la eliminación y, si se omite, predeter mina a cero.
$info = $pool->get_info()
Recupera información sobre el estado actual del pool de almacenamiento. La referencia hash devuelta tiene las siguientes claves:
estado
El estado actual del pool de almacenamiento. Ver las constantes más adelante.
capacidad
El tamaño lógico total del pool de almacenamiento.
asignación
La asignación física actual del pool de almacenamiento.
disponible
El espacio disponible para la creación de nuevos volúmenes. Esto puede ser menor que la diferencia entre capacidad y asignación si existen restricciones de tamaño/metadatos para los volúmenes.
mi $nnames = $pool->num_of_storage_volumes()
Devuelve el número de volúmenes en ejecución en este pool de almacenamiento. El valor puede usarse como el parámetro "maxnames" para "list_storage_vol_names".
mi @volNames = $pool->list_storage_vol_names($maxnames)
Devuelve una lista de todos los nombres de volúmenes en este pool de almacenamiento. Los nombres pueden usarse con el método "get_volume_by_name".
mi @vols = $pool->list_volumes()
Devuelve una lista de todos los volúmenes en el pool de almacenamiento. Los elementos de la lista devuelta son instancias de la clase Sys::Virt::StorageVol. Este método requiere O(n) llamadas RPC, por lo que el método "list_all_volumes" se recomienda como una alternativa más eficiente.
mi @volumes = $pool->list_all_volumes($flags)
Devuelve una lista de todos los volúmenes de almacenamiento asociados con este pool. Los elementos de la lista devuelta son instancias de la clase Sys::Virt::StorageVol. El parámetro $flags puede usarse para filtrar la lista de volúmenes de almacenamiento devueltos.
mi $vol = $pool->get_volume_by_name($name)
Devuelve el volumen con el nombre $name. El objeto devuelto es una instancia de la clase Sys::Virt::StorageVol.
mi $vol = $pool->create_volume($xml)
Crea un nuevo volumen basado en la descripción XML pasada al parámetro $xml. El objeto devuelto es una instancia de la clase Sys::Virt::StorageVol. Si se proporciona el opcional "clonevol", los datos se copiarán de ese volumen de origen.
mi $vol = $pool->clone_volume($xml, $clonevol);
Crea un nuevo volumen basado en la descripción XML pasada al parámetro $xml. El objeto devuelto es una instancia de la clase Sys::Virt::StorageVol. El nuevo volumen se poblará con datos del volumen fuente de clonación especificado.

CONSTANTES

Los siguientes conjuntos de constantes pueden ser útiles para tratar con algunos de los métodos de este paquete.

DEFINE_STORAGE_POOL

Las siguientes constantes se pueden usar para controlar el comportamiento de las operaciones de definición de pool de almacenamiento.

Sys::Virt::StoragePool::DEFINE_VALIDATE
Valida el documento XML contra el esquema XML.

ESTADOS_DE_POOL

Las siguientes constantes son útiles para interpretar el valor de la clave "state" en la referencia hash devuelta por "get_info".

Sys::Virt::StoragePool::STATE_INACTIVE
El pool de almacenamiento no está activo actualmente.
Sys::Virt::StoragePool::STATE_BUILDING
El pool de almacenamiento aún se está construyendo y aún no está listo para su uso.
Sys::Virt::StoragePool::STATE_RUNNING
El pool de almacenamiento se está ejecutando y se puede consultar para obtener volúmenes.
Sys::Virt::StoragePool::STATE_DEGRADED
El pool de almacenamiento se está ejecutando, pero su funcionamiento está degradado debido a un fallo.
Sys::Virt::StoragePool::STATE_INACCESSIBLE
El pool de almacenamiento no es accesible actualmente.
