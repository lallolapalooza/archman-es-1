NOMBRE

Sys::Virt::Domain - Representar y gestionar un dominio invitado de libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::Domain" representa un dominio invitado gestionado por el monitor de máquinas virtuales.

NAME

Sys::Virt::Domain - Constants related to domains

DESCRIPTION

This module defines constants used for manipulating virtual machines (domains) with Sys::Virt.

METHODS

No methods are exported by this module.

CONSTANTS

The following constants are exported by this module.
