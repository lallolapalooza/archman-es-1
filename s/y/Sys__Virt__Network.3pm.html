NOMBRE

Sys::Virt::Network - Representar y gestionar una red virtual de libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::Network" representa una red virtual gestionada por el monitor de máquinas virtuales.

MÉTODOS

mi $uuid = $net->get_uuid()
Devuelve una cadena de 16 bytes que contiene el identificador único global (UUID) en bruto de la red.
mi $uuid = $net->get_uuid_string()
Devuelve una representación en cadena imprimible del UUID en bruto, en el formato 'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX'.
mi $nombre = $net->get_name()
Devuelve una cadena con un nombre único localmente de la red.
$net->is_active()
Devuelve un valor verdadero si la red se está ejecutando actualmente.
$net->is_persistent()
Devuelve un valor verdadero si la red tiene un archivo de configuración persistente definido.
mi $xml = $net->get_xml_description()
Devuelve un documento XML que contiene una descripción completa de la configuración de la red.
$net->create()
Inicia una red cuya configuración se definió previamente utilizando el método "define_network" en Sys::Virt.
$net->undefine()
Elimina la configuración asociada con una red definida previamente con el método "define_network" en Sys::Virt. Si la red está en ejecución, probablemente quieras usar los métodos "shutdown" o "destroy" en su lugar.
$net->destroy()
Termina inmediatamente la máquina y la elimina del monitor de máquinas virtuales. El manejador $net no es válido después de que esta llamada finalice y no debe usarse de nuevo.
$net->update($comando, $sección, $indice_padre, $xml, $flags=0)
Actualiza la configuración de la red con $xml. El parámetro $sección, que debe ser una de las CONSTANTES DE SECCIÓN XML que se detallan a continuación, indica qué esquema se utiliza en $xml. El parámetro $comando determina qué acción se realiza. Finalmente, el parámetro $flags puede usarse para controlar qué configuración se ve afectada.
$net->get_bridge_name()
Devuelve el nombre del dispositivo bridge asociado con la red virtual.
$flag = $net->get_autostart();
Devuelve un valor verdadero si la red virtual está configurada para iniciarse automáticamente al arrancar. Devuelve falso en caso contrario.
$net->set_autostart($flag)
Establece el estado del indicador de inicio automático, que determina si la red virtual se iniciará automáticamente al arrancar el sistema operativo anfitrión.
@leases = $net->get_dhcp_leases($mac=undef, $flags=0)
Obtiene una lista de todos los leases DHCP activos. Si $mac es indefinido, se devuelven los leases de todas las VMs, de lo contrario, solo se devuelven los leases para la dirección MAC coincidente. El parámetro $flags no se utiliza actualmente y por defecto es cero.

Los elementos del array devuelto son referencias de hash con los siguientes campos:

"iface"
Nombre de la interfaz de red.
"expirytime"
Segundos desde la época hasta que expire el lease.
"type"
Uno de los constantes de tipo de dirección IP de Sys::Virt.
"mac"
La dirección MAC del lease.
"iaid"
El IAID del cliente.
"ipaddr"
La dirección IP del lease.
"prefix"
El prefijo de la dirección IP.
"hostname"
El nombre de host opcional asociado con el lease.
"clientid"
El ID de cliente o DUID.
@port = $net->list_all_ports($flags=0)
Lista todos los puertos asociados con la red. Los elementos del array devuelto son instancias de la clase "Sys::Virt::NetworkPort".
$port = $net->create_port($xml, $flags=0)
Crea un nuevo puerto de red a partir de la descripción $xml dada. El parámetro $flags puede tomar opcionalmente una o más de las constantes de creación de puertos de red. El objeto $port devuelto es una instancia de la clase "Sys::Virt::NetworkPort".
$port = $net->get_port_by_uuid($uuid);
Busca un puerto de red a partir de un UUID en bruto o imprimible. El objeto $port devuelto es una instancia de la clase "Sys::Virt::NetworkPort".
mi $str = $net->get_metadata($type, $uri, $flags =0)
Devuelve el elemento de metadatos de tipo $type asociado con la red. Si $type es "Sys::Virt::Network::METADATA_ELEMENT", el parámetro $uri especifica el espacio de nombres XML a recuperar; de lo contrario, $uri debe ser "undef". El parámetro opcional $flags toma uno de los valores de FLAGS DE ACTUALIZACIÓN XML y por defecto es cero.
$net->set_metadata($type, $val, $key, $uri, $flags=0)
Establece el elemento de metadatos de tipo $type para contener el valor $val. Si $type es "Sys::Virt::Network::METADATA_ELEMENT", los elementos $key y $uri especifican un espacio de nombres XML a usar; de lo contrario, ambos deben ser "undef". El parámetro opcional $flags toma uno de los valores de FLAGS DE ACTUALIZACIÓN XML y por defecto es cero.

NAME

Sys::Virt::Network

DESCRIPTION

Sys::Virt::Network es un módulo Perl que proporciona acceso a la configuración de red en el sistema virtuoso Libvirt.

METHODS

Las siguientes son las funciones disponibles en Sys::Virt::Network

Sys::Virt::Network::NEW
Crear una nueva configuración de red
Sys::Virt::Network::GET
Obtener una configuración de red
Sys::Virt::Network::SET
Establecer una configuración de red
Sys::Virt::Network::DELETE
Eliminar una configuración de red

CONSTANTS

Los siguientes son las constantes disponibles en Sys::Virt::Network

Sys::Virt::Network::XML_INACTIVE
Solicitar el XML inactivo, en lugar de la configuración actual posiblemente activa.
Sys::Virt::Network::SECTION_BRIDGE
El elemento del dispositivo bridge
Sys::Virt::Network::SECTION_DNS_HOST
La sección de registros DNS host
Sys::Virt::Network::SECTION_DNS_SRV
La sección de registros DNS SRV
Sys::Virt::Network::SECTION_DNS_TXT
La sección de registros DNS TXT
Sys::Virt::Network::SECTION_DOMAIN
La sección del nombre de dominio
Sys::Virt::Network::SECTION_FORWARD
La sección del dispositivo forward
Sys::Virt::Network::SECTION_FORWARD_INTERFACE
La sección de la interfaz forward
Sys::Virt::Network::SECTION_FORWARD_PF
La sección de la función física forward
Sys::Virt::Network::SECTION_IP
La sección de la dirección IP
Sys::Virt::Network::SECTION_IP_DHCP_HOST
La sección del host DHCP de la dirección IP
Sys::Virt::Network::SECTION_IP_DHCP_RANGE
La sección del rango DHCP de la dirección IP
Sys::Virt::Network::SECTION_PORTGROUP
La sección del grupo de puertos
Sys::Virt::Network::SECTION_NONE
El elemento de nivel superior del dominio

XML UPDATE FLAGS

Afectar el estado actual del objeto
Sys::Virt::Network::UPDATE_AFFECT_CONFIG
Actualizar siempre el archivo de configuración

Actualizar siempre la configuración en vivo

XML UPDATE COMMANDS

Sin actualización

Eliminar la entrada coincidente

Modificar la entrada coincidente

Insertar la entrada coincidente al principio
Sys::Virt::Network::UPDATE_COMMAND_ADD_LAST
Insertar la entrada coincidente al final

EVENT ID CONSTANTS

Sys::Virt::Network::EVENT_ID_LIFECYCLE
Eventos del ciclo de vida de la red
Sys::Virt::Network::EVENT_ID_METADATA_CHANGE
Se han modificado los metadatos de la red

LIFECYCLE CHANGE EVENTS

Las siguientes constantes permiten interpretar los eventos de cambio de ciclo de vida de la red. Los eventos contienen tanto un cambio de estado como una razón, aunque la razón actualmente no se utiliza.

Sys::Virt::Network::EVENT_DEFINED
Indica que se ha definido una configuración persistente para la red.
Sys::Virt::Network::EVENT_STARTED
La red ha comenzado a ejecutarse
Sys::Virt::Network::EVENT_STOPPED
La red ha dejado de ejecutarse
Sys::Virt::Network::EVENT_UNDEFINED
La configuración persistente ha desaparecido

METADATA TYPE CONSTANTS

Las siguientes constantes controlan el tipo de metadatos a los que se accede

Sys::Virt::Network::METADATA_TITLE
El título corto y amigable de la red
Sys::Virt::Network::METADATA_DESCRIPTION
La descripción textual larga y libre de la red
Sys::Virt::Network::METADATA_ELEMENT
Los elementos de metadatos estructurados para la red
