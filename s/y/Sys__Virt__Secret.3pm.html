NOMBRE

Sys::Virt::Secret - Representar y gestionar un secreto de libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::Secret" representa un secreto gestionado por el monitor de máquina virtual.

MÉTODOS

mi $uuid = $sec->get_uuid()
Devuelve una cadena de 16 bytes que contiene el identificador global único (UUID) crudo para el secreto.
mi $uuid = $sec->get_uuid_string()
Devuelve una representación de cadena imprimible del UUID crudo, en el formato 'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX'.
mi $type = $sec->get_usage_type()
Devuelve el tipo de uso de este secreto. El tipo de uso determina el formato del identificador único para este secreto.
mi $id = $sec->get_usage_id()
Devuelve el identificador del objeto con el que se utilizará el secreto. Para secretos con un tipo de uso de volumen, el identificador es la ruta completa.
mi $xml = $sec->get_xml_description()
Devuelve un documento XML que contiene una descripción completa de la configuración del secreto.
$sec->undefine()
Elimina la configuración asociada con un secreto definido previamente con el método "define_secret" en Sys::Virt.
$bytes = $sec->get_value()
Devuelve los bytes crudos del valor de este secreto, o undef si no hay ningún valor almacenado con el secreto.
$sec->set_value($bytes)
Establece el valor del secreto a $bytes.

CONSTANTES

Esta sección documenta las constantes que se utilizan con varias APIs descritas anteriormente

TIPO DE USO DE SECRETO

Las siguientes constantes se refieren a los diferentes tipos de uso

Sys::Virt::Secret::USAGE_TYPE_NONE
La constante para secretos que no están asignados para su uso con un objeto en particular.
Sys::Virt::Secret::USAGE_TYPE_VOLUME
La constante para secretos que se utilizarán para cifrado de volúmenes de almacenamiento. El ID de uso para los secretos se referirá a la ruta completa del volumen.
Sys::Virt::Secret::USAGE_TYPE_CEPH
La constante para secretos que se utilizarán para la autenticación en volúmenes de almacenamiento CEPH. El ID de uso para los secretos se referirá al nombre del servidor.
Sys::Virt::Secret::USAGE_TYPE_ISCSI
La constante para secretos que se utilizarán para la autenticación en volúmenes de almacenamiento iSCSI. El ID de uso para los secretos se referirá al nombre del servidor.
Sys::Virt::Secret::USAGE_TYPE_TLS
La constante para secretos que se utilizarán para la autenticación en el entorno TLS. El ID de uso para el secreto puede ser cualquier nombre. El UUID del secreto será utilizado por el hipervisor para obtener el valor del secreto.
Sys::Virt::Secret::USAGE_TYPE_VTPM
La constante para secretos que se utilizarán para cifrar el estado del TPM virtual. El ID de uso para el secreto se referirá a la ruta del TPM. El UUID del secreto será utilizado por el hipervisor para obtener el valor del secreto.

FILTRADO DE LISTA

Las siguientes constantes se utilizan para filtrar listas de objetos.

Sys::Virt::Secret::LIST_EPHEMERAL
Incluir secretos marcados como efímeros.
Sys::Virt::Secret::LIST_NO_EPHEMERAL
Incluir secretos no marcados como efímeros.
Sys::Virt::Secret::LIST_PRIVATE
Incluir secretos marcados como privados.
Sys::Virt::Secret::LIST_NO_PRIVATE
Incluir secretos no marcados como privados.

DEFINICIÓN SECRETA

Las siguientes constantes pueden utilizarse para controlar el comportamiento de las operaciones de definición de secretos.

Sys::Virt::Secret::DEFINE_VALIDATE
Validar el documento XML contra el esquema XML.

CONSTANTES ID EVENTO

Sys::Virt::Secret::EVENT_ID_LIFECYCLE
Eventos del ciclo de vida del secreto.
Sys::Virt::Secret::EVENT_ID_VALUE_CHANGED
Eventos de cambio de valor del secreto.

EVENTOS CAMBIO CICLO VIDA

Las siguientes constantes permiten interpretar los eventos de cambio del ciclo de vida del secreto. Los eventos contienen tanto un cambio de estado como una razón, aunque la razón actualmente no se utiliza.

Sys::Virt::Secret::EVENT_DEFINED
Indica que se ha definido una configuración persistente para el secreto.
Sys::Virt::Secret::EVENT_UNDEFINED
La configuración persistente ha desaparecido.
