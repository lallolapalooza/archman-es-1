Sys::Hostname(3perl) Guía de referencia para programadores de Perl Sys::Hostname(3perl)

NOMBRE

Sys::Hostname - Intenta todas las formas imaginables de obtener el nombre del host

SINOPSIS

use Sys::Hostname;
my $host = hostname;

DESCRIPCIÓN

Intenta varios métodos para obtener el nombre del host del sistema y luego almacena en caché el resultado. Prueba la primera opción disponible de gethostname() de la biblioteca C, `$Config{aphostname}`, uname(2), syscall(SYS_gethostname), `hostname`, `uname -n` y el archivo /com/host. Si todo falla, lanza una excepción (croak).

Se eliminan todas las NUL, retornos de carro y saltos de línea del resultado.
