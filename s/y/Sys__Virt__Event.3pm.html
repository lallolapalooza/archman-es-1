NOMBRE

Sys::Virt::Event - Acceso al bucle de eventos

DESCRIPCIÓN

El módulo "Sys::Virt::Event" representa el contrato para integrar libvirt con un bucle de eventos. Este paquete es abstracto y está destinado a ser subclasificado para proporcionar una implementación real.

FUNCIONALIDAD ELIMINADA

Las implementaciones del bucle de eventos solían ser instancias de subclases de "Sys::Virt::Event". En su lugar, ahora se requiere que hereden de "Sys::Virt::EventImpl". Por compatibilidad con versiones anteriores a la 9.4, la herencia de "Sys::Virt::Event" todavía es compatible, pero se eliminará a mediados de 2025.

MÉTODOS

register_default()
Registra la implementación predeterminada del bucle de eventos de libvirt
run_default()
Ejecuta una sola iteración de la implementación predeterminada del bucle de eventos
register($impl)
Registra una implementación de bucle de eventos. La implementación debe ser una instancia de una subclase del paquete "Sys::Virt::EventImpl". Consulte la sección "IMPLEMENTACIÓN DEL BUCLE DE EVENTOS" a continuación para obtener más información.
my $watch = Sys::Virt::Event::add_handle($fd, $events, $coderef)
Añade un observador en el descriptor de archivo $fd para los eventos $events, que es una máscara de las constantes FILE HANDLE EVENTS que se enumeran más adelante. El parámetro $coderef es una subrutina que se invocará cuando se active un evento. La subrutina recibirá tres parámetros: el identificador del observador, el descriptor de archivo y la máscara de eventos. Este método devuelve el identificador del observador que se puede usar para actualizar o eliminar el observador.
Sys::Virt::Event::update_handle($watch, $events)
Actualiza la máscara de eventos para el observador de descriptor de archivo $watch para usar los eventos $events.
Sys::Virt::Event::remove_handle($watch)
Elimina la máscara de eventos para el observador de descriptor de archivo $watch.
my $timer = Sys::Virt::Event::add_timeout($frequency, $coderef, $opaque)
Añade un temporizador para que se active con un intervalo de $frequency milisegundos. El parámetro $coderef es una subrutina que se invocará cuando se active un evento. La subrutina recibirá un parámetro: el identificador del temporizador. Este método devuelve el identificador del temporizador que se puede usar para actualizar o eliminar el temporizador.
Sys::Virt::Event::update_timeout($timer, $frequency)
Actualiza el temporizador $timer para que tenga la frecuencia de $frequency milisegundos. Los valores 0 y -1 tienen un significado especial. El valor 0 hace que la devolución de llamada se invoque en cada iteración del bucle de eventos, mientras que -1 detiene la invocación de la devolución de llamada.
Sys::Virt::Event::remove_timeout($timer)
Elimina el temporizador $timer.

CONSTANTES

EVENTOS DE DESCRIPTOR DE ARCHIVO

Al integrar con un bucle de eventos, las siguientes constantes definen los eventos del descriptor de archivo:

Sys::Virt::Event::HANDLE_READABLE
Hay datos disponibles para leer en el descriptor de archivo sin bloquear.
Sys::Virt::Event::HANDLE_WRITABLE
El descriptor de archivo tiene la capacidad de escribir datos sin bloquear.
Sys::Virt::Event::HANDLE_ERROR
Ocurrió un error en el descriptor de archivo.
Sys::Virt::Event::HANDLE_HANGUP
El extremo remoto del descriptor de archivo se cerró.
