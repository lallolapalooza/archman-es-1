Sys::Syscall(3) Documentación de Perl aportada por el usuario Sys::Syscall(3)

NOMBRE

Sys::Syscall - acceso a llamadas al sistema a las que Perl normalmente no proporciona acceso

SINOPSIS

use Sys::Syscall;

DESCRIPCION

Usa epoll, sendfile, desde Perl. Principalmente soporte para Linux ahora, pero se planean más llamadas al sistema/SO para el futuro.

Exportaciones

Nada por defecto.

Puede exportar: sendfile epoll_ctl epoll_create epoll_wait EPOLLIN EPOLLOUT EPOLLERR EPOLLHUP EPOLL_CTL_ADD EPOLL_CTL_DEL EPOLL_CTL_MOD

Etiquetas de exportación: :epoll y :sendfile

Funciones

Soporte de epoll

$ok = epoll_defined()
Devuelve verdadero si epoll podría estar disponible. (el llamador aún debe probar con epoll_create)
$epfd = epoll_create([ $start_size ])
Crea un nuevo descriptor de archivo epoll. Devuelve -1 si epoll no está disponible.
$rv = epoll_ctl($epfd, $op, $fd, $events)
Ver la página del manual para epoll_ctl
$count = epoll_wait($epfd, $max_events, $timeout, $arrayref)
Ver la página del manual para epoll_wait. $arrayref es un arrayref que será modificado con los elementos devueltos. Los valores puestos en $arrayref son arrayrefs de [$fd, $state].

Soporte de sendfile

$ok = sendfile_defined()
Devuelve verdadero si sendfile debería funcionar en este sistema operativo.
$sent = sendfile($sock_fd, $file_fd, $max_send)
Envía hasta $max_send bytes desde $file_fd a $sock_fd. Devuelve los bytes realmente enviados, o -1 en caso de error.
