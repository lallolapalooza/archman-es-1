Sys::Hostname::Long(3) Documentación de Perl contribuida por usuarios Sys::Hostname::Long(3)

NOMBRE

Sys::Hostname::Long - Intenta todas las formas imaginables de obtener el nombre de host completo

SINOPSIS

use Sys::Hostname::Long;
$host_long = hostname_long;

DESCRIPCIÓN

Cómo obtener el nombre de host completo en perl en múltiples sistemas operativos (mac, windows, unix*, etc)

DISCUSIÓN

Este es el SEGUNDO lanzamiento de este código. Tiene un conjunto mejorado de pruebas e interfaces mejoradas, pero a menudo aún falla al obtener un nombre de host completo. Esta es, por supuesto, la razón por la que escribí el módulo, es difícil obtener nombres de host completos con precisión en cada sistema. En algunos sistemas (por ejemplo, Linux), depende del orden de las entradas en /etc/hosts.

Para facilitar las pruebas, tengo testall.pl para generar una lista de salida de todos los métodos. Por lo tanto, incluso si la lógica es incorrecta, puede ser posible obtener el nombre completo.

Intenta obtener el nombre completo del sistema a través de muchos métodos. La clase Sys::Hostname es la mejor y estándar forma de obtener el nombre de host del sistema. Sin embargo, le falta el nombre de host largo.

Agradecimientos especiales a David Sundstrom y Greg Bacon por el Sys::Hostname original

LIMITACIONES CONOCIDAS

Unix

La mayoría de los sistemas Unix tienen problemas para determinar el nombre de dominio completo, ya que debe configurarse correctamente en algún lugar del sistema. Por ejemplo, en la mayoría de los sistemas Linux (Debian, ?) el nombre de dominio completo debe ser la primera entrada junto al número IP en /etc/hosts

192.168.0.1     fred.somewhere.special   fred

Si es al revés, fallará.
