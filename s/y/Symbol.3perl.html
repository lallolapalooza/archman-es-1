Symbol(3perl) Guía de referencia del programador de Perl Symbol(3perl)

NOMBRE

Symbol - manipular símbolos y sus nombres en Perl

SINOPSIS

use Symbol;
$sym = gensym;
open($sym, '<', "nombre_archivo");
$_ = <$sym>;
# etc.
ungensym $sym;      # sin efecto
# reemplaza el manejador *FOO{IO} pero no $FOO, %FOO, etc.
*FOO = geniosym;
print qualify("x"), "\n";              # "main::x"
print qualify("x", "FOO"), "\n";       # "FOO::x"
print qualify("BAR::x"), "\n";         # "BAR::x"
print qualify("BAR::x", "FOO"), "\n";  # "BAR::x"
print qualify("STDOUT", "FOO"), "\n";  # "main::STDOUT" (global)
print qualify(\*x), "\n";              # devuelve \*x
print qualify(\*x, "FOO"), "\n";       # devuelve \*x
use strict refs;
print { qualify_to_ref $fh } "foo!\n";
$ref = qualify_to_ref $name, $pkg;
use Symbol qw(delete_package);
delete_package('Foo::Bar');
print "eliminado\n" unless exists $Foo::{'Bar::'};

DESCRIPCIÓN

"Symbol::gensym" crea un glob anónimo y devuelve una referencia a él. Dicha referencia a glob puede ser utilizada como manejador de archivo o directorio.

Por compatibilidad hacia atrás con implementaciones más antiguas que no soportaban globs anónimos, "Symbol::ungensym" también está disponible. Pero no hace nada.

"Symbol::geniosym" crea un manejador de IO anónimo. Esto puede ser asignado a un glob existente sin afectar las porciones no-IO del glob.

"Symbol::qualify" convierte nombres de símbolos no calificados en nombres de variables calificados (ej. "mi_variable" -> "MiPaquete::mi_variable"). Si se le da un segundo parámetro, "qualify" lo usa como el paquete predeterminado; de lo contrario, usa el paquete de su llamador. Sin importar, los nombres de variables globales (ej. "STDOUT", "ENV", "SIG") siempre se califican con "main::".

La calificación se aplica solo a nombres de símbolos (cadenas). Las referencias se dejan sin cambios bajo el supuesto de que son referencias a globs, que están calificados por su naturaleza.

"Symbol::qualify_to_ref" es exactamente como "Symbol::qualify" excepto que devuelve una referencia a glob en lugar de un nombre de símbolo, para que puedas usar el resultado incluso si "use strict 'refs'" está activo.

"Symbol::delete_package" borra un espacio de nombres de paquete completo. Nota que esta rutina no se exporta por defecto; puedes querer importarla explícitamente.

ERRORES

"Symbol::delete_package" es un poco demasiado potente. Anula la definición de cada símbolo que vive en el paquete especificado. Dado que Perl, por razones de rendimiento, no realiza una búsqueda en la tabla de símbolos cada vez que se llama a una función o se accede a una variable global, parte del código que ya se ha cargado y que utiliza símbolos en el paquete "Foo" puede dejar de funcionar después de que elimines "Foo", incluso si vuelves a cargar el módulo "Foo" después.
