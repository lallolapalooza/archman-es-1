Módulo Immediate64
: sig end

Este módulo permite definir un tipo t con el atributo immediate64. Este atributo significa que el tipo es inmediato en arquitecturas de 64 bits. En otras arquitecturas, puede o no ser inmediato.

module type Non_immediate = sig end

module type Immediate = sig end

module Make : (Immediate : Immediate) (Non_immediate : Non_immediate) -> sig end
