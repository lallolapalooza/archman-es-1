Sys::Virt::NWFilterBinding(3pm) Documentación de Perl aportada por el usuario Sys::Virt::NWFilterBinding(3pm)

NOMBRE

Sys::Virt::NWFilterBinding - Representar y gestionar un enlace de filtro de red

DESCRIPCIÓN

El módulo "Sys::Virt::NWFilterBinding" representa un enlace entre un filtro de red y un dispositivo de puerto de red.

MÉTODOS

mi $nombre = $enlace->get_port_dev()
Devuelve una cadena con el nombre del dispositivo de puerto de red al que está enlazado
mi $nombre = $enlace->get_filter_name()
Devuelve una cadena con el nombre del filtro de red al que está enlazado
mi $xml = $enlace->get_xml_description()
Devuelve un documento XML que contiene una descripción completa de la configuración de red
$enlace->delete()
Desenlaza el dispositivo de puerto de red del filtro

CONSTANTES PARA CREACIÓN DE ENLACES DE FILTRO DE RED

Al crear enlaces de filtro de red, se pueden usar cero o más de las siguientes constantes:

Sys::Virt::NWFilterBinding::CREATE_VALIDATE
Valida el documento XML contra el esquema XML
