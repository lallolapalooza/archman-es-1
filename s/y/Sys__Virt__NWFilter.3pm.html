Sys::Virt::NWFilter(3pm) Documentación de Perl aportada por el usuario Sys::Virt::NWFilter(3pm)

NOMBRE

Sys::Virt::NWFilter - Representar y gestionar un filtro de red virtual de libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::NWFilter" representa un filtro de red gestionado por el monitor de máquinas virtuales.

MÉTODOS

my $uuid = $filter->get_uuid()
Devuelve una cadena de 16 bytes que contiene el identificador único global (UUID) en bruto para el filtro de red.
my $uuid = $filter->get_uuid_string()
Devuelve una representación en cadena imprimible del UUID en bruto, en el formato 'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX'.
my $name = $filter->get_name()
Devuelve una cadena con un nombre localmente único del filtro de red.
my $xml = $filter->get_xml_description()
Devuelve un documento XML que contiene una descripción completa de la configuración del filtro de red.
$filter->undefine()
Elimina la configuración asociada con un filtro de red definido previamente con el método "define_nwfilter" en Sys::Virt.

Esta sección documenta las constantes que se utilizan con varias API descritas anteriormente.

Las siguientes constantes se pueden utilizar para controlar el comportamiento de las operaciones de definición de filtros de red.
