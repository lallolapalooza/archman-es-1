NOMBRE

Sys::Virt::EventImpl - Clase base de implementación del bucle de eventos

DESCRIPCIÓN

El módulo "Sys::Virt::EventImpl" representa el contrato para integrar libvirt con un bucle de eventos. Este paquete es abstracto y está destinado a ser subclasificado para proporcionar una implementación real.

Este módulo es nuevo en la versión 9.5.0. Para usar este módulo y, al mismo tiempo, admitir versiones anteriores a la 9.5.0, se podría considerar el siguiente código para configurar la herencia.

package YourImpl;
use strict;
use warnings;
BEGIN {
  if (require Sys::Virt::EventImpl) {
     eval "use parent 'Sys::Virt::EventImpl';";
  }
  else {
     eval "use parent 'Sys::Virt::Event';";
  }
}

IMPLEMENTACIÓN DEL BUCLE DE EVENTOS

Al implementar un bucle de eventos, la implementación debe ser una subclase de la clase "Sys::Virt::EventImpl". Debe sobrescribir estas funciones:

mi $watch_id = $self->add_handle( $fd, $events, $callback, $opaque, $ff )
Registra $callback para ser invocado para $events en $fd. Use "_run_handle_callback" para realizar la invocación real desde el bucle de eventos (ver "Ayudantes de callbacks" a continuación).

Además de los eventos explícitamente indicados por $events, "Sys::Virt::Event::HANDLE_ERROR" y "Sys::Virt::Event::HANDLE_HANGUP" siempre deberían activar el callback.

Devuelve un entero positivo $watch_id o -1 en caso de error.

$self->update_handle($watch_id, $events)
Reemplaza los eventos que actualmente activan $watch_id con $events.
mi $ret = $self->remove_handle($watch_id)
Elimina el $callback del $fd.

Devuelve 0 si tiene éxito o -1 si falla.

IMPORTANTE Esto también debe asegurarse de que "_free_callback_opaque" se llame después de que esta función se haya ejecutado: no hacerlo evitará que la conexión sea recolectada por el recolector de basura.

mi $timer_id = $self->add_timeout($frequency, $callback, $opaque, $ff)
$self->update_timeout($timer_id, $frequency)
Reemplaza el intervalo del temporizador con $frequency.
mi $ret = $self->remove_timeout($timer_id)
Descarta el temporizador.

Devuelve 0 si tiene éxito o -1 si falla.

IMPORTANTE Esto también debe asegurarse de que "_free_callback_opaque" se llame después de que esta función se haya ejecutado: no hacerlo evitará que la conexión sea recolectada por el recolector de basura.

Ayudantes de callbacks

$self->_run_handle_callback($watch_id, $fd, $events, $cb, $opaque)
Un método auxiliar para ejecutar un callback en respuesta a uno o más $events en el descriptor de archivo $fd. El número $watch es el identificador único asociado con el descriptor de archivo. Los parámetros $cb y $opaque son el callback y los datos registrados para el manejador.
$self->_run_timeout_callback($timer_id, $cb, $opaque)
Un método auxiliar para ejecutar un callback en respuesta a la expiración de un tiempo de espera identificado por $timer. Los parámetros $cb y $opaque son el callback y los datos registrados para el tiempo de espera.
$self->_free_callback_opaque($ff, $opaque)
Un método auxiliar para liberar los datos asociados con un callback. Los parámetros $ff y $opaque son el callback y los datos registrados para el manejador/tiempo de espera.

IMPORTANTE Este ayudante debe ser llamado fuera de cualquier callback; es decir, *después* de que los callbacks de "remove_handle" o "remove_timeout" se completen.
