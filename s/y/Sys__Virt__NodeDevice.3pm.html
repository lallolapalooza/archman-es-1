Sys::Virt::NodeDevice(3pm) Documentación de Perl contribuida por usuarios Sys::Virt::NodeDevice(3pm)

NOMBRE

Sys::Virt::NodeDevice - Representar y gestionar un pool de almacenamiento de libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::NodeDevice" representa un pool de almacenamiento gestionado por libvirt. Existen una variedad de implementaciones de pools de almacenamiento para LVM, directorios/sistemas de archivos locales, sistemas de archivos de red, particionamiento de discos, iSCSI y SCSI.

MÉTODOS

mi $nombre = $dev->get_name()
Devuelve una cadena con un nombre localmente único del dispositivo
mi $nombre_padre = $dev->get_parent()
Devuelve una cadena con un nombre localmente único del padre del dispositivo, o undef si no tiene padre
mi $xml = $dev->get_xml_description($flags=0)
Devuelve un documento XML que contiene una descripción completa de la configuración del dispositivo de nodo. El parámetro opcional $flags controla la generación del documento XML, por defecto 0 si se omite. Puede ser uno o más de las constantes XML DUMP listadas más adelante en este documento.
$dev->reattach()
Reconecta el dispositivo de nodo a los drivers del dispositivo del sistema operativo anfitrión.
$dev->dettach()
Desconecta el dispositivo de nodo del driver del dispositivo del sistema operativo anfitrión.
$dev->reset()
Reinicia el dispositivo de nodo. El dispositivo debe estar desconectado de los drivers del sistema operativo anfitrión para que esto funcione.
$dev->create($flags=0)
Inicia un dispositivo de nodo cuya configuración fue definida previamente utilizando el método "define_node_device" en Sys::Virt. El parámetro $flags actualmente no se usa y tiene un valor por defecto de cero.
$dev->undefine($flags=0)
Elimina un dispositivo de nodo cuya configuración fue definida previamente utilizando el método "define_node_device" en Sys::Virt. El parámetro $flags actualmente no se usa y tiene un valor por defecto de cero.
$flag = $dev->get_autostart();
Devuelve un valor verdadero si el dispositivo de nodo está configurado para iniciarse automáticamente al arrancar. Devuelve falso en caso contrario.
$dev->set_autostart($flag)
Establece el estado del flag de inicio automático, que determina si el dispositivo de nodo se iniciará automáticamente al arrancar el sistema operativo anfitrión.
$dev->is_active()
Devuelve un valor verdadero si el dispositivo de nodo se está ejecutando actualmente.
$dev->is_persistent()
Devuelve un valor verdadero si el dispositivo de nodo tiene un archivo de configuración persistente definido.
$dev->destroy()
Destruye el dispositivo virtual liberando cualquier recurso del sistema operativo asociado a él.
mi @caps = $dev->list_capabilities()
Devuelve una lista de todas las capacidades del dispositivo.
$dev->update($xml, $flags=0)
Actualiza la definición de un dispositivo de nodo existente con $xml. El parámetro $flags se puede usar para controlar qué configuración se ve afectada (ver XML UPDATE FLAGS) y tiene un valor por defecto de cero (afecta el estado actual del dispositivo de nodo).

Sys::Virt::NodeDevice(3pm) — Perl manual page

NAME

Sys::Virt::NodeDevice — Interface to node devices

DESCRIPTION

This module provides an interface to manage node devices within the libvirt framework. Node devices represent physical hardware attached to the host system that can be managed by libvirt, such as network interfaces, storage controllers, or GPUs.

METHODS

Sys::Virt::NodeDevice->new( connection, type )
Constructor for a new NodeDevice object.
nodeDevice->connection
Returns the connection object associated with this node device.
nodeDevice->get_name
Returns the name of the node device.
nodeDevice->get_parent
Returns the parent of the node device, if any.
nodeDevice->get_model
Returns the model of the node device.
nodeDevice->get_type
Returns the type of the node device.
nodeDevice->is_active
Checks if the node device is currently active.
nodeDevice->is_managed
Checks if the node device is managed by libvirt.
nodeDevice->is_claimed
Checks if the node device is claimed by a domain.
nodeDevice->capability_xml
Returns the XML description of the node device's capabilities.
nodeDevice->config_xml
Returns the XML description of the node device's configuration.
nodeDevice->create_xml( xml, flags )
Creates a new node device based on the provided XML configuration.
nodeDevice->define_xml( xml, flags )
Defines a new node device configuration based on the provided XML.
nodeDevice->undefine
Removes the configuration of a node device.
nodeDevice->destroy
Destroys a node device.
nodeDevice->reset
Resets a node device.
nodeDevice->update_xml( xml, flags )
Updates the configuration of a node device.
nodeDevice->migrate_to_node
Migrates a node device to another node.
nodeDevice->event_register( callback, data )
Registers a callback for node device events.
nodeDevice->event_unregister
Unregisters a callback for node device events.

Include transient devices

Sys::Virt::NodeDevice::EVENT_ID_LIFECYCLE
Node device lifecycle events
Sys::Virt::NodeDevice::EVENT_ID_UPDATE
Node device config update events

LIFECYCLE CHANGE EVENTS

The following constants allow node device lifecycle change events to be interpreted. The events contain both a state change, and a reason though the reason is currently unused.

Sys::Virt::NodeDevice::EVENT_CREATED
Indicates that a device was created
Sys::Virt::NodeDevice::EVENT_DELETED
Indicates that a device has been deleted
Sys::Virt::NodeDevice::EVENT_DEFINED
Indicates that a device configuration has been created
Sys::Virt::NodeDevice::EVENT_UNDEFINED
Indicates that a device configuration has been deleted

NODE DEVICE CREATION

Sys::Virt::NodeDevice::CREATE_XML_VALIDATE
Validate the XML document against schema

NODE DEVICE DEFINE

Sys::Virt::NodeDevice::DEFINE_XML_VALIDATE
Validate the XML document against schema

NODE DEVICE UPDATE

Sys::Virt::NodeDevice::UPDATE_AFFECT_CURRENT
Affect live if node device is active, config if it's not active
Sys::Virt::NodeDevice::UPDATE_AFFECT_LIVE
Affect live state of node device only
Sys::Virt::NodeDevice::UPDATE_AFFECT_CONFIG
Affect persistent config only

XML DUMP OPTIONS

The following constants are used to control the information included in the XML configuration dump

Sys::Virt::NodeDevice::XML_INACTIVE
Report the persistent inactive configuration for the node device.
