Syntax::Keyword::Try::Deparse(3pm) Documentación de Perl contribuida por el usuario Syntax::Keyword::Try::Deparse(3pm)

NOMBRE

"Syntax::Keyword::Try::Deparse" - Soporte de B::Deparse para Syntax::Keyword::Try

DESCRIPCIÓN

Cargar este módulo aplicará algunos trucos a B::Deparse que intentan proporcionar soporte de deparse para código que utiliza la sintaxis proporcionada por Syntax::Keyword::Try.

PENDIENTE

Manejar correctamente los casos de despacho por tipo ("catch($var isa CLASS)", "catch($var =~ m/pattern/)")
