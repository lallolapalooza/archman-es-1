Sys::Virt::NetworkPort(3pm) Documentación de Perl contribuida por el usuario Sys::Virt::NetworkPort(3pm)

NOMBRE

Sys::Virt::NetworkPort - Representar y gestionar un puerto de red virtual de libvirt

DESCRIPCIÓN

El módulo "Sys::Virt::NetworkPort" representa un puerto en una red virtual.

MÉTODOS

mi $uuid = $puerto->get_uuid()
Devuelve una cadena de 16 bytes que contiene el identificador único global (UUID) en bruto para el puerto de red.
mi $uuid = $puerto->get_uuid_string()
Devuelve una representación en cadena imprimible del UUID en bruto, en el formato 'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX'.
mi $xml = $puerto->get_xml_description()
Devuelve un documento XML que contiene una descripción completa de la configuración del puerto de red.
$puerto->delete()
Elimina el puerto de red de la red gestionada.
mi $params = $puerto->get_parameters($flags=0);
Obtiene los parámetros ajustables asociados con el puerto de red. El parámetro $flags no se utiliza actualmente y por defecto es cero. El $params devuelto es una referencia a un hash cuyas claves son una o más de las siguientes constantes:
Sys::Virt::NetworkPort::BANDWIDTH_IN_AVERAGE
El ancho de banda de entrada promedio.
Sys::Virt::NetworkPort::BANDWIDTH_IN_BURST
El ancho de banda de entrada con ráfagas.
Sys::Virt::NetworkPort::BANDWIDTH_IN_FLOOR
El ancho de banda de entrada mínimo.
Sys::Virt::NetworkPort::BANDWIDTH_IN_PEAK
El ancho de banda de entrada pico.
Sys::Virt::NetworkPort::BANDWIDTH_OUT_AVERAGE
El ancho de banda de salida promedio.
Sys::Virt::NetworkPort::BANDWIDTH_OUT_BURST
El ancho de banda de salida con ráfagas.
Sys::Virt::NetworkPort::BANDWIDTH_OUT_PEAK
El ancho de banda de salida pico.
$puerto->set_parameters($params, $flags=0);
Establece los parámetros ajustables asociados con el puerto de red. El parámetro $flags no se utiliza actualmente y por defecto es cero. El parámetro $params es una referencia a un hash cuyas claves son una o más de las constantes listadas para "get_parameters".

CONSTANTES DE CREACIÓN DE PUERTOS DE RED

Al crear puertos de red, se pueden utilizar cero o más de las siguientes constantes:

Sys::Virt::NetworkPort::CREATE_RECLAIM
Proporcionar configuración para reclamar un puerto de red preexistente.
Sys::Virt::NetworkPort::CREATE_VALIDATE
Validar el documento XML contra el esquema XML.
