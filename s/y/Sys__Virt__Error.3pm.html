NOMBRE

Sys::Virt::Error - Objeto de error para APIs de libvirt

DESCRIPCIÓN

La clase "Sys::Virt::Error" proporciona una codificación de los errores de libvirt. Las instancias de este objeto pueden ser lanzadas por prácticamente cualquiera de las APIs de Sys::Virt.

MÉTODOS

$err->stringify
Convierte el objeto a formato de cadena adecuado para imprimir en una consola e informar al usuario del error.
mi $nivel = $err->nivel
Devuelve el nivel de error crudo representado por este error. Uno de los CONSTANTES DE NIVEL DE ERROR
mi $código = $err->código
Devuelve el código de error crudo representado por este error. Uno de los CONSTANTES DE CÓDIGO DE ERROR
mi $desde = $err->dominio
Devuelve el dominio de error que genera este error. Uno de los CONSTANTES DE DOMINIO DE ERROR
mi $mensaje = $err->mensaje
Devuelve un mensaje informativo que describe la condición de error.

NAME

Sys::Virt::Error - Error codes and definitions for Sys::Virt

DESCRIPTION

This module defines a set of constants that represent the error codes returned by the Sys::Virt library.

METHODS

No public methods are exported by this module. The constants defined here can be used directly in your code.
