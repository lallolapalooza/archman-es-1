NOMBRE

SSL_session_reused - consultar si se reutilizó una sesión negociada durante el handshake

SINOPSIS

#include <openssl/ssl.h>
int SSL_session_reused(const SSL *ssl);

DESCRIPCIÓN

Consulta si se reutilizó una sesión negociada durante el handshake.

NOTAS

Durante la negociación, un cliente puede proponer reutilizar una sesión. El servidor busca entonces la sesión en su caché. Si tanto el cliente como el servidor están de acuerdo en la sesión, esta se reutilizará y se establecerá una bandera que la aplicación puede consultar.

VALORES DE RETORNO

Pueden ocurrir los siguientes valores de retorno:

0
Se negoció una nueva sesión.
1
Se reutilizó una sesión.

VER TAMBIÉN

ssl(7), SSL_set_session(3), SSL_CTX_set_session_cache_mode(3)
