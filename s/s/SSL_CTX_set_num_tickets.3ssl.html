SSL_CTX_set_num_tickets(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_NUM_TICKETS(3ssl) OpenSSL SSL_CTX_SET_NUM_TICKETS(3ssl)

NOMBRE

SSL_set_num_tickets, SSL_get_num_tickets, SSL_CTX_set_num_tickets, SSL_CTX_get_num_tickets, SSL_new_session_ticket - controlar el número de tickets de sesión TLSv1.3 que se emiten

SINOPSIS

#include <openssl/ssl.h>
int SSL_set_num_tickets(SSL *s, size_t num_tickets);
size_t SSL_get_num_tickets(const SSL *s);
int SSL_CTX_set_num_tickets(SSL_CTX *ctx, size_t num_tickets);
size_t SSL_CTX_get_num_tickets(const SSL_CTX *ctx);
int SSL_new_session_ticket(SSL *s);

DESCRIPCIÓN

SSL_CTX_set_num_tickets() y SSL_set_num_tickets() pueden ser llamadas por una aplicación de servidor y establecen el número de tickets de sesión TLSv1.3 que se enviarán al cliente después de un handshake completo. Establezca el valor deseado (que podría ser 0) en el argumento num_tickets. Típicamente, estas funciones deben ser llamadas antes del inicio del handshake.

El número predeterminado de tickets es 2. Después de una reanudación, el número de tickets emitidos nunca será superior a 1, independientemente del valor establecido a través de SSL_set_num_tickets() o SSL_CTX_set_num_tickets(). Si num_tickets se establece en 0, no se emitirán tickets ni para una conexión normal ni para una reanudación.

Los tickets también se emiten al recibir un certificado post-handshake del cliente después de una solicitud del servidor utilizando SSL_verify_client_post_handshake(3). Estos nuevos tickets se asociarán con la identidad del cliente actualizada (es decir, incluyendo su certificado y el estado de verificación). El número de tickets emitidos será normalmente el mismo que se utilizó para el handshake inicial. Si el handshake inicial fue un handshake completo, se puede llamar a SSL_set_num_tickets() de nuevo antes de llamar a SSL_verify_client_post_handshake() para actualizar el número de tickets que se enviarán.

Para emitir tickets después de otros eventos (como cambios a nivel de aplicación), SSL_new_session_ticket() es utilizada por una aplicación de servidor para solicitar que se envíe un nuevo ticket cuando sea seguro hacerlo. Solo se permite enviar nuevos tickets de esta manera después de que el handshake inicial haya completado, y solo para conexiones TLS 1.3. Por defecto, la generación y transmisión de tickets se retrasan hasta que el servidor está iniciando una nueva operación de escritura, de modo que se agrupe con otros datos de aplicación que se están escribiendo y se alinee correctamente a un límite de registro. Si la conexión estaba en un límite de registro cuando se llamó a SSL_new_session_ticket(), el ticket puede enviarse inmediatamente (sin esperar a la siguiente escritura de la aplicación) llamando a SSL_do_handshake(). SSL_new_session_ticket() puede ser llamada más de una vez para solicitar que se envíen tickets adicionales; todas esas solicitudes se ponen en cola y se escriben juntas cuando sea seguro hacerlo y se activan con SSL_write() o SSL_do_handshake(). Tenga en cuenta que un retorno exitoso de SSL_new_session_ticket() solo indica que la solicitud de enviar un ticket fue procesada, no que el ticket en sí mismo fue enviado. Para ser notificado cuando el ticket en sí mismo sea enviado, se puede registrar una devolución de llamada de nueva sesión con SSL_CTX_sess_set_new_cb(3) que se invocará a medida que el ticket o los tickets se generen.

SSL_CTX_get_num_tickets() y SSL_get_num_tickets() devuelven el número de tickets establecido por una llamada anterior a SSL_CTX_set_num_tickets() o SSL_set_num_tickets(), o 2 si no se ha hecho ninguna llamada de este tipo.

VALORES DE RETORNO

SSL_CTX_set_num_tickets(), SSL_set_num_tickets() y SSL_new_session_ticket() devuelven 1 en caso de éxito o 0 en caso de fallo.

SSL_CTX_get_num_tickets() y SSL_get_num_tickets() devuelven el número de tickets que se han establecido previamente.

VER TAMBIÉN

ssl(7)

HISTORIA

SSL_new_session_ticket() se añadió en OpenSSL 3.0.0. SSL_set_num_tickets(), SSL_get_num_tickets(), SSL_CTX_set_num_tickets() y SSL_CTX_get_num_tickets() se añadieron en OpenSSL 1.1.1.
