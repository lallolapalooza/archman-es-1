SSL_stream_reset(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_STREAM_RESET(3ssl) OpenSSL SSL_STREAM_RESET(3ssl)

NOMBRE

SSL_stream_reset - reinicia un flujo QUIC

SINOPSIS

#include <openssl/ssl.h>
typedef struct ssl_stream_reset_args_st {
    uint64_t quic_error_code;
} SSL_STREAM_RESET_ARGS;
int SSL_stream_reset(SSL *ssl,
                     const SSL_STREAM_RESET_ARGS *args,
                     size_t args_len);

DESCRIPCIÓN

La función SSL_stream_reset() reinicia la parte de envío de un flujo QUIC cuando se llama en un objeto SSL de flujo QUIC, o en un objeto SSL de conexión QUIC con un flujo predeterminado adjunto.

Si args no es NULL, args_len debe establecerse en sizeof(*args).

quic_error_code es un código de error especificado por la aplicación, que debe estar en el rango [0, 2**62-1]. Si args es NULL, se utiliza un valor de 0.

Reiniciar un flujo indica a una aplicación que la parte de envío del flujo está terminando anormalmente. Cuando un flujo se reinicia, la implementación no garantiza que los datos que ya se han pasado a SSL_write(3) serán recibidos por el par, y los datos que ya se han pasado a SSL_write(3) pero que aún no se han transmitido pueden ser descartados o no. Como tal, solo debes reiniciar un flujo cuando la información transmitida en el flujo ya no importa, por ejemplo, debido a una condición de error.

Esta función no se puede llamar en un flujo unidireccional iniciado por el par, ya que solo el lado de envío de un flujo puede iniciar un reinicio de flujo.

También es posible desencadenar un reinicio de flujo llamando a SSL_free(3); consulta la documentación de SSL_free(3) para obtener más detalles.

La parte receptora del flujo (para flujos bidireccionales) continúa funcionando normalmente.

NOTAS

Esta función corresponde al marco RESET_STREAM de QUIC.

VALORES DE RETORNO

Devuelve 1 en caso de éxito y 0 en caso de fallo.

Esta función falla si se llama en un objeto SSL de conexión QUIC sin un flujo predeterminado adjunto, o en un objeto SSL que no es QUIC.

Después de que la primera llamada a esta función tenga éxito para un flujo determinado, las llamadas posteriores tendrán éxito pero se ignorarán. El código de error de la aplicación utilizado es el pasado a la primera llamada exitosa a esta función.

VER TAMBIÉN

SSL_free(3)

HISTORIA

SSL_stream_reset() se añadió en OpenSSL 3.2.
