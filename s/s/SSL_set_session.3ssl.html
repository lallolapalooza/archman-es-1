SSL_set_session(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_SET_SESSION(3ssl) OpenSSL SSL_SET_SESSION(3ssl)

NOMBRE

SSL_set_session - establece una sesión TLS/SSL para ser utilizada durante la conexión TLS/SSL

SINOPSIS

#include <openssl/ssl.h>
int SSL_set_session(SSL *ssl, SSL_SESSION *session);

DESCRIPCIÓN

SSL_set_session() establece session para ser utilizada cuando se establezca la conexión TLS/SSL. SSL_set_session() solo es útil para clientes TLS/SSL. Cuando se establece la sesión, el contador de referencias de session se incrementa en 1. Si la sesión no se reutiliza, el contador de referencias se decrementa nuevamente durante SSL_connect(). Si la sesión se reutilizó o no, se puede consultar con la llamada a SSL_session_reused(3).

Si ya hay una sesión establecida dentro de ssl (porque se estableció previamente con SSL_set_session() o porque el mismo ssl ya se utilizó para una conexión), se llamará a SSL_SESSION_free() para esa sesión. Esto también ocurre cuando session es un puntero NULL. Si esa sesión antigua todavía está abierta, se considera incorrecta y se eliminará de la caché de sesiones (si se usa). Una sesión se considera abierta si no se llamó a SSL_shutdown(3) para la conexión (o al menos se utilizó SSL_set_shutdown(3) para establecer el estado SSL_SENT_SHUTDOWN).

NOTAS

Los objetos SSL_SESSION mantienen información de enlace interna sobre la lista de caché de sesiones, al ser insertados en la caché de sesiones de un objeto SSL_CTX. Por lo tanto, un objeto SSL_SESSION, independientemente de su contador de referencias, solo debe usarse con un objeto SSL_CTX (y los objetos SSL creados a partir de este objeto SSL_CTX).

VALORES DE RETORNO

Pueden ocurrir los siguientes valores de retorno:

0
La operación falló; compruebe la pila de errores para averiguar el motivo.
1
La operación se completó correctamente.

VER TAMBIÉN

ssl(7), SSL_SESSION_free(3), SSL_get_session(3), SSL_session_reused(3), SSL_CTX_set_session_cache_mode(3)
