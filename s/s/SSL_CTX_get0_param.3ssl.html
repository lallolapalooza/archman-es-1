SSL_CTX_get0_param(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_GET0_PARAM(3ssl) OpenSSL SSL_CTX_GET0_PARAM(3ssl)

NOMBRE

SSL_CTX_get0_param, SSL_get0_param, SSL_CTX_set1_param, SSL_set1_param, SSL_CTX_set_purpose, SSL_CTX_set_trust, SSL_set_purpose, SSL_set_trust - obtener y establecer parámetros de verificación

SINOPSIS

#include <openssl/ssl.h>
X509_VERIFY_PARAM *SSL_CTX_get0_param(SSL_CTX *ctx);
X509_VERIFY_PARAM *SSL_get0_param(SSL *ssl);
int SSL_CTX_set1_param(SSL_CTX *ctx, X509_VERIFY_PARAM *vpm);
int SSL_set1_param(SSL *ssl, X509_VERIFY_PARAM *vpm);
int SSL_CTX_set_purpose(SSL_CTX *ctx, int purpose);
int SSL_set_purpose(SSL *ssl, int purpose);
int SSL_CTX_set_trust(SSL_CTX *ctx, int trust);
int SSL_set_trust(SSL *ssl, int trust);

DESCRIPCIÓN

SSL_CTX_get0_param() y SSL_get0_param() obtienen un puntero interno a los parámetros de verificación para ctx o ssl respectivamente. El puntero devuelto no debe ser liberado por la aplicación que llama.

SSL_CTX_set1_param() y SSL_set1_param() establecen los parámetros de verificación a vpm para ctx o ssl.

Las funciones SSL_CTX_set_purpose() y SSL_set_purpose() son atajos que establecen el parámetro de propósito en el objeto de parámetros de verificación. Estas funciones son equivalentes a llamar directamente a X509_VERIFY_PARAM_set_purpose().

Las funciones SSL_CTX_set_trust() y SSL_set_trust() son atajos similares que establecen el parámetro de confianza en el objeto de parámetros de verificación. Estas funciones son equivalentes a llamar directamente a X509_VERIFY_PARAM_set_trust().

NOTAS

Típicamente, los parámetros se obtienen de una estructura SSL_CTX o SSL usando SSL_CTX_get0_param() o SSL_get0_param() y una aplicación los modifica para adaptarse a sus necesidades: por ejemplo, para añadir una comprobación de nombre de host.

VALORES DE RETORNO

SSL_CTX_get0_param() y SSL_get0_param() devuelven un puntero a una estructura X509_VERIFY_PARAM.

SSL_CTX_set1_param(), SSL_set1_param(), SSL_CTX_set_purpose(), SSL_set_purpose(), SSL_CTX_set_trust() y SSL_set_trust() devuelven 1 en caso de éxito y 0 en caso de fallo.

EJEMPLOS

Verificar que el nombre de host coincide con "www.foo.com" en el certificado del par:

X509_VERIFY_PARAM *vpm = SSL_get0_param(ssl);
X509_VERIFY_PARAM_set1_host(vpm, "www.foo.com", 0);

VER TAMBIÉN

ssl(7), X509_VERIFY_PARAM_set_flags(3)

HISTORIA

Estas funciones se añadieron en OpenSSL 1.0.2.
