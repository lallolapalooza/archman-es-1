SSL_CTX_sess_set_cache_size(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SESS_SET_CACHE_SIZE(3ssl) OpenSSL SSL_CTX_SESS_SET_CACHE_SIZE(3ssl)

NOMBRE

SSL_CTX_sess_set_cache_size, SSL_CTX_sess_get_cache_size - manipular el tamaño de la caché de sesiones

SINOPSIS

#include <openssl/ssl.h>
long SSL_CTX_sess_set_cache_size(SSL_CTX *ctx, long t);
long SSL_CTX_sess_get_cache_size(SSL_CTX *ctx);

DESCRIPCIÓN

SSL_CTX_sess_set_cache_size() establece el tamaño de la caché de sesiones interna del contexto ctx a t. Este valor es una sugerencia y no un valor absoluto; véase las notas a continuación.

SSL_CTX_sess_get_cache_size() devuelve el tamaño de la caché de sesiones actualmente válido.

NOTAS

El tamaño de la caché de sesiones interna es SSL_SESSION_CACHE_MAX_SIZE_DEFAULT, que actualmente es 1024*20, de modo que se pueden almacenar hasta 20000 sesiones. Este tamaño se puede modificar mediante la llamada a SSL_CTX_sess_set_cache_size(). Un caso especial es el tamaño 0, que se utiliza para un tamaño ilimitado.

Si al añadir la sesión la caché excede su tamaño, las sesiones no utilizadas se eliminan del final de la caché. El espacio de la caché también puede ser liberado llamando a SSL_CTX_flush_sessions(3) para eliminar sesiones expiradas.

Si el tamaño de la caché de sesiones se reduce y ya hay más sesiones en la caché de sesiones, las sesiones antiguas se eliminarán la próxima vez que se intente añadir una sesión. Esta eliminación no está sincronizada con la expiración de las sesiones.

VALORES DE RETORNO

SSL_CTX_sess_set_cache_size() devuelve el tamaño previamente válido.

SSL_CTX_sess_get_cache_size() devuelve el tamaño actualmente válido.

VER TAMBIÉN

ssl(7), SSL_CTX_set_session_cache_mode(3), SSL_CTX_sess_number(3), SSL_CTX_flush_sessions(3)
