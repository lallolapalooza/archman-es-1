DESCRIPCIÓN

Todas las funciones descritas en esta página están deprecadas. No hay funciones de reemplazo disponibles por el momento.

Estas funciones proporcionan acceso a los parámetros SRP (Secure Remote Password), un mecanismo de autenticación alternativo para TLS. SRP permite el uso de nombres de usuario y contraseñas sobre canales no cifrados sin revelar la contraseña a un espía. SRP también suministra un secreto compartido al final de la secuencia de autenticación que puede ser utilizado para generar claves de cifrado.

El protocolo SRP, versión 3 está especificado en RFC 2945. SRP versión 6 se describe en RFC 5054 con aplicaciones a la autenticación TLS.

La función SSL_CTX_set_srp_username() establece el nombre de usuario SRP para ctx. Esto debe ser llamado en el cliente antes de crear una conexión con el servidor. La longitud de name debe ser menor o igual a 255 caracteres.

La función SSL_CTX_set_srp_password() establece la contraseña SRP para ctx. Esto puede ser llamado en el cliente antes de crear una conexión con el servidor. Esto anula el efecto de SSL_CTX_set_srp_client_pwd_callback().

La función SSL_CTX_set_srp_strength() establece la fuerza SRP para ctx. Esta es la longitud mínima del primo SRP en bits. Si no se especifica, se utiliza 1024. Si no se satisface con el intercambio de claves del servidor, la conexión será rechazada.

La función SSL_CTX_set_srp_cb_arg() establece un parámetro adicional que se pasará a todas las callbacks posteriores como arg.

La función SSL_CTX_set_srp_username_callback() establece la callback del lado del servidor que se invoca cuando se encuentra un nombre de usuario SRP en un ClientHello. Los parámetros de la callback son la conexión SSL s, un indicador de error escribible ad y el argumento adicional arg establecido por SSL_CTX_set_srp_cb_arg(). Esta callback debe configurar el servidor para el intercambio de claves llamando a SSL_set_srp_server_param() con los parámetros apropiados para el nombre de usuario recibido. El nombre de usuario puede obtenerse llamando a SSL_get_srp_username(). Ver SRP_VBASE_init(3) para analizar el archivo verificador creado por openssl-srp(1) o SRP_create_verifier(3) para generarlo. La callback debe devolver SSL_ERROR_NONE para continuar con el intercambio de claves del servidor, SSL3_AL_FATAL para un error fatal o cualquier valor < 0 para un reintento. En caso de un SSL3_AL_FATAL, se enviará el indicador de alerta dado por *al. Por defecto, este será SSL_AD_UNKNOWN_PSK_IDENTITY.

La función SSL_CTX_set_srp_client_pwd_callback() establece la callback de contraseña del cliente en el cliente. Los parámetros de la callback son la conexión SSL s y el argumento adicional arg establecido por SSL_CTX_set_srp_cb_arg(). La callback se llamará como parte de la generación de los secretos del cliente. Debe devolver la contraseña del cliente en formato de texto o NULL para abortar la conexión. La memoria resultante será liberada por la biblioteca como parte de la resolución de la callback. Esto anula el efecto de SSL_CTX_set_srp_password().

La función SSL_CTX_set_srp_verify_param_callback() establece la callback de verificación de parámetros gN SRP en el cliente. Esto permite al cliente realizar una verificación personalizada al recibir los parámetros propuestos SRP del servidor. Los parámetros de la callback son la conexión SSL s y el argumento adicional arg establecido por SSL_CTX_set_srp_cb_arg(). La callback debe devolver un valor positivo para aceptar los parámetros del servidor. Devolver 0 o un valor negativo abortará la conexión. Los parámetros del servidor pueden obtenerse llamando a SSL_get_srp_N() y SSL_get_srp_g(). La biblioteca ya realiza comprobaciones de sanidad después del handshake (B % N no cero, comprobación contra el parámetro de fuerza) y no son necesarias. Si no se establece ninguna callback, los parámetros g y N se comprobarán con los valores conocidos de RFC 5054.

La función SSL_set_srp_server_param() establece todos los parámetros SRP para la conexión s. N y g son los parámetros del grupo SRP, sa es la sal del usuario, v es el verificador de contraseña e info es la información opcional del usuario.

La función SSL_set_srp_server_param_pw() establece todos los parámetros SRP para la conexión s generando una sal aleatoria y un verificador de contraseña. user es el nombre de usuario, pass es la contraseña y grp es el identificador de los parámetros del grupo SRP para SRP_get_default_gN(3).

La función SSL_get_srp_g() devuelve el generador del grupo SRP para s, o del SSL_CTX subyacente si es NULL.

La función SSL_get_srp_N() devuelve el primo SRP para s, o del SSL_CTX subyacente si es NULL.

La función SSL_get_srp_username() devuelve el nombre de usuario SRP para s, o del SSL_CTX subyacente si es NULL.

La función SSL_get_srp_userinfo() devuelve la información del usuario SRP para s, o del SSL_CTX subyacente si es NULL.

VALORES DE RETORNO

Todas las funciones SSL_CTX_set_* devuelven 1 en caso de éxito y 0 en caso de fallo.

SSL_set_srp_server_param() devuelve 1 en caso de éxito y -1 en caso de fallo.

Las funciones SSL_get_SRP_* devuelven un puntero a los datos solicitados, la memoria es propiedad de la biblioteca y no debe ser liberada por el llamador.

EJEMPLOS

Configurar parámetros SRP en el cliente:

#include <openssl/ssl.h>
const char *username = "usuario";
const char *password = "contraseña";
SSL_CTX *ctx = SSL_CTX_new(TLS_client_method());
if (!ctx)
    /* Error */
if (!SSL_CTX_set_srp_username(ctx, username))
    /* Error */
if (!SSL_CTX_set_srp_password(ctx, password))
    /* Error */

Configurar servidor SRP con archivo verificador:

#include <openssl/srp.h>
#include <openssl/ssl.h>
const char *srpvfile = "password.srpv";
int srpServerCallback(SSL *s, int *ad, void *arg)
{
    SRP_VBASE *srpData = (SRP_VBASE*) arg;
    char *username = SSL_get_srp_username(s);
    SRP_user_pwd *user_pwd = SRP_VBASE_get1_by_user(srpData, username);
    if (!user_pwd)
        /* Error */
        return SSL3_AL_FATAL;
    if (SSL_set_srp_server_param(s, user_pwd->N, user_pwd->g,
        user_pwd->s, user_pwd->v, user_pwd->info) < 0)
        /* Error */
    SRP_user_pwd_free(user_pwd);
    return SSL_ERROR_NONE;
}
SSL_CTX *ctx = SSL_CTX_new(TLS_server_method());
if (!ctx)
    /* Error */
/*
 * seedKey debe contener una secuencia terminada en NUL
 * de bytes aleatorios no NUL
 */
const char *seedKey;
SRP_VBASE *srpData = SRP_VBASE_new(seedKey);
if (SRP_VBASE_init(srpData, (char*) srpvfile) != SRP_NO_ERROR)
   /* Error */
SSL_CTX_set_srp_cb_arg(ctx, srpData);
SSL_CTX_set_srp_username_callback(ctx, srpServerCallback);
