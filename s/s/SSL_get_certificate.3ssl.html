SSL_get_certificate(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_CERTIFICATE(3ssl) OpenSSL SSL_GET_CERTIFICATE(3ssl)

NOMBRE

SSL_get_certificate, SSL_get_privatekey - obtener certificado y clave privada TLS/SSL

SINÓPSIS

#include <openssl/ssl.h>
X509 *SSL_get_certificate(const SSL *s);
EVP_PKEY *SSL_get_privatekey(const SSL *s);

DESCRIPCIÓN

SSL_get_certificate() devuelve un puntero a un objeto X509 que representa un certificado utilizado como identidad del par local.

Se pueden configurar varios certificados; por ejemplo, un servidor podría tener certificados RSA y ECDSA. El certificado que devuelve SSL_get_certificate() se determina de la siguiente manera:

  • Si se llama antes de que ocurra la selección del certificado, devuelve el certificado añadido más recientemente, o NULL si no se ha añadido ningún certificado.
  • Después de que ocurra la selección del certificado, devuelve el certificado que se seleccionó durante el handshake, o NULL si no se seleccionó ningún certificado (por ejemplo, en un cliente donde no se utiliza ningún certificado de cliente).

La selección del certificado ocurre durante el handshake; por lo tanto, el valor devuelto por SSL_get_certificate() durante cualquier callback realizado durante el proceso de handshake dependerá de si ese callback se realiza antes o después de que ocurra la selección del certificado.

Un uso específico para SSL_get_certificate() es dentro de un callback establecido mediante una llamada a SSL_CTX_set_tlsext_status_cb(3). Este callback ocurre después de la selección del certificado, donde se puede utilizar para examinar el certificado elegido por un servidor, por ejemplo, con el propósito de identificar la URL del respondedor OCSP de un certificado para poder obtener una respuesta OCSP.

SSL_get_privatekey() devuelve un puntero al objeto EVP_PKEY correspondiente al certificado devuelto por SSL_get_certificate(), si lo hay.

VALORES DE RETORNO

Estas funciones devuelven punteros a sus respectivos objetos, o NULL si no hay dicho objeto disponible. Los objetos devueltos son propiedad del objeto SSL y no deben ser liberados por los usuarios de estas funciones.

VER TAMBIÉN

ssl(7), SSL_CTX_set_tlsext_status_cb(3)
