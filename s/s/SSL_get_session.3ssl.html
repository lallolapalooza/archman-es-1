SSL_get_session(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_SESSION(3ssl) OpenSSL SSL_GET_SESSION(3ssl)

NOMBRE

SSL_get_session, SSL_get0_session, SSL_get1_session - recuperar datos de sesión TLS/SSL

SINOPSIS

#include <openssl/ssl.h>
SSL_SESSION *SSL_get_session(const SSL *ssl);
SSL_SESSION *SSL_get0_session(const SSL *ssl);
SSL_SESSION *SSL_get1_session(SSL *ssl);

DESCRIPCIÓN

SSL_get_session() devuelve un puntero a la sesión SSL_SESSION utilizada realmente en ssl. El contador de referencias de SSL_SESSION no se incrementa, por lo que el puntero puede invalidarse por otras operaciones.

SSL_get0_session() es lo mismo que SSL_get_session().

SSL_get1_session() es lo mismo que SSL_get_session(), pero el contador de referencias de SSL_SESSION se incrementa en uno.

NOTAS

La sesión ssl contiene toda la información necesaria para restablecer la conexión sin un handshake completo para versiones SSL hasta TLSv1.2 inclusive. En TLSv1.3 es lo mismo, pero las sesiones se establecen después de que haya ocurrido el handshake principal. El servidor enviará la información de la sesión al cliente en el momento que elija, que puede ser un tiempo después de que se establezca la conexión inicial (o nunca). Llamar a estas funciones en el lado del cliente en TLSv1.3 antes de que la sesión se haya establecido, aún devolverá un objeto SSL_SESSION pero ese objeto no se podrá utilizar para reanudar la sesión. Vea SSL_SESSION_is_resumable(3) para información sobre cómo determinar si un objeto SSL_SESSION se puede usar para la reanudación o no.

Además, en TLSv1.3, un servidor puede enviar múltiples mensajes que establecen una sesión para una única conexión. En ese caso, en el lado del cliente, las funciones anteriores solo devolverán información sobre la última sesión que se recibió. En el lado del servidor, solo devolverán información sobre la última sesión que se envió, o si no se enviaron tickets de sesión, la sesión para la conexión actual.

La forma preferida para que las aplicaciones obtengan un objeto SSL_SESSION reanudable es usar una devolución de llamada de nueva sesión como se describe en SSL_CTX_sess_set_new_cb(3). La devolución de llamada de nueva sesión solo se invoca cuando realmente se establece una sesión, por lo que esto evita el problema descrito anteriormente donde una aplicación obtiene un objeto SSL_SESSION que no se puede usar para la reanudación en TLSv1.3. También permite a las aplicaciones obtener información sobre todas las sesiones enviadas por el servidor.

Una sesión se eliminará automáticamente de la caché de sesiones y se marcará como no reanudable si la conexión no se cierra limpiamente, por ejemplo, si ocurre un error fatal en la conexión o si no se llama a SSL_shutdown(3) antes de SSL_free(3).

En TLSv1.3 se recomienda que cada objeto SSL_SESSION solo se use para la reanudación una vez.

SSL_get0_session() devuelve un puntero a la sesión real. Como el contador de referencias no se incrementa, el puntero solo es válido mientras la conexión está en uso. Si se llama a SSL_clear(3) o SSL_free(3), la sesión puede eliminarse por completo (si se considera mala) y el puntero obtenido se invalidará. Incluso si la sesión es válida, puede eliminarse en cualquier momento debido a un tiempo de espera durante SSL_CTX_flush_sessions(3).

Si los datos se deben conservar, SSL_get1_session() incrementará el contador de referencias, de modo que la sesión no se eliminará implícitamente por otras operaciones, sino que permanecerá en memoria. Para eliminar la sesión, se debe llamar explícitamente a SSL_SESSION_free(3) una vez para decrementar el contador de referencias nuevamente.

Los objetos SSL_SESSION mantienen información de enlace interna sobre la lista de caché de sesiones, cuando se insertan en la caché de sesiones de un objeto SSL_CTX. Por lo tanto, un objeto SSL_SESSION, independientemente de su contador de referencias, solo debe usarse con un objeto SSL_CTX (y los objetos SSL creados a partir de este objeto SSL_CTX).

VALORES DE RETORNO

Pueden ocurrir los siguientes valores de retorno:

NULL
No hay ninguna sesión disponible en ssl.
Puntero a un SSL_SESSION
El valor de retorno apunta a los datos de una sesión SSL.

VEA TAMBIÉN

ssl(7), SSL_free(3), SSL_clear(3), SSL_SESSION_free(3)
