SSL_CTX_set_ssl_version(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_SSL_VERSION(3ssl) OpenSSL SSL_CTX_SET_SSL_VERSION(3ssl)

NOMBRE

SSL_CTX_set_ssl_version, SSL_CTX_get_ssl_method, SSL_set_ssl_method, SSL_get_ssl_method - elegir un nuevo método TLS/SSL

SINOPSIS

#include <openssl/ssl.h>
int SSL_CTX_set_ssl_version(SSL_CTX *ctx, const SSL_METHOD *method);
const SSL_METHOD *SSL_CTX_get_ssl_method(const SSL_CTX *ctx);
int SSL_set_ssl_method(SSL *s, const SSL_METHOD *method);
const SSL_METHOD *SSL_get_ssl_method(const SSL *ssl);

DESCRIPCIÓN

SSL_CTX_set_ssl_version() establece un nuevo método TLS/SSL predeterminado method para los objetos SSL creados a partir de este ctx. La mayor parte de la configuración adjunta al objeto SSL_CTX se conserva, con la excepción de los cifrados TLS configurados, que se restablecen a sus valores predeterminados. Los objetos SSL ya creados a partir de este SSL_CTX con SSL_new(3) no se ven afectados, excepto cuando se llama a SSL_clear(3), como se describe a continuación.

SSL_CTX_get_ssl_method() devuelve el SSL_METHOD que se utilizó para construir el SSL_CTX.

SSL_set_ssl_method() establece un nuevo método TLS/SSL method para un objeto ssl particular. Puede restablecerse cuando se llama a SSL_clear().

SSL_get_ssl_method() devuelve un puntero al método TLS/SSL establecido en ssl.

NOTAS

Las opciones de method disponibles se describen en SSL_CTX_new(3).

Cuando se llama a SSL_clear(3) y no hay una sesión conectada a un objeto SSL, el método del objeto SSL se restablece al método establecido actualmente en el objeto SSL_CTX correspondiente.

SSL_CTX_set_version() tiene una semántica inusual y ningún caso de uso claro; normalmente sería preferible crear un nuevo objeto SSL_CTX que intentar reutilizar uno existente de esta manera. Su uso se considera obsoleto.

SSL_set_ssl_method() no se puede utilizar para cambiar un objeto SSL que no sea QUIC a un objeto SSL QUIC o viceversa, ni para cambiar un objeto SSL QUIC de un método QUIC a otro.

VALORES DE RETORNO

Los siguientes valores de retorno pueden ocurrir para SSL_CTX_set_ssl_version() y SSL_set_ssl_method():

0
La nueva elección falló, comprueba la pila de errores para averiguar el motivo.
1
La operación tuvo éxito.

SSL_CTX_get_ssl_method() y SSL_get_ssl_method() siempre devuelven punteros no nulos.

VER TAMBIÉN

SSL_CTX_new(3), SSL_new(3), SSL_clear(3), ssl(7), SSL_set_connect_state(3)

HISTORIA

SSL_CTX_set_ssl_version() quedó obsoleto en OpenSSL 3.0.
