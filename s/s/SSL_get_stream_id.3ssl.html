SSL_get_stream_id(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_STREAM_ID(3ssl) OpenSSL SSL_GET_STREAM_ID(3ssl)

NOMBRE

SSL_get_stream_id, SSL_get_stream_type, SSL_STREAM_TYPE_NONE, SSL_STREAM_TYPE_BIDI, SSL_STREAM_TYPE_READ, SSL_STREAM_TYPE_WRITE, SSL_is_stream_local - obtener información del ID y tipo de flujo QUIC

SINOPSIS

#include <openssl/ssl.h>
uint64_t SSL_get_stream_id(SSL *ssl);
#define SSL_STREAM_TYPE_NONE
#define SSL_STREAM_TYPE_BIDI
#define SSL_STREAM_TYPE_READ
#define SSL_STREAM_TYPE_WRITE
int SSL_get_stream_type(SSL *ssl);
int SSL_is_stream_local(SSL *ssl);

DESCRIPCIÓN

La función SSL_get_stream_id() devuelve el ID del flujo QUIC para un objeto SSL de flujo QUIC, o para un objeto SSL de conexión QUIC que tenga un flujo predeterminado adjunto.

La función SSL_get_stream_type() identifica qué operaciones se pueden realizar en el flujo y devuelve uno de los siguientes valores:

SSL_STREAM_TYPE_NONE
El objeto SSL es un objeto SSL de conexión QUIC sin un flujo predeterminado adjunto.
SSL_STREAM_TYPE_BIDI
El objeto SSL es un objeto SSL no QUIC, o es un objeto de flujo QUIC (o objeto SSL de conexión QUIC con un flujo predeterminado adjunto), y ese flujo es un flujo QUIC bidireccional.
SSL_STREAM_TYPE_READ
El objeto SSL es un objeto de flujo QUIC (o objeto SSL de conexión QUIC con un flujo predeterminado adjunto), y ese flujo es un flujo QUIC unidireccional iniciado por el par remoto; por lo tanto, se puede leer, pero no escribir en él.
SSL_STREAM_TYPE_WRITE
El objeto SSL es un objeto de flujo QUIC (o objeto SSL de conexión QUIC con un flujo predeterminado adjunto), y ese flujo es un flujo QUIC unidireccional iniciado por la aplicación local; por lo tanto, se puede escribir en él, pero no leer de él.

La función SSL_is_stream_local() determina si un flujo se creó localmente.

NOTAS

Si bien QUICv1 asigna un significado específico a los dos bits más bajos de un ID de flujo QUIC, los IDs de flujo QUIC en versiones futuras de QUIC no requieren tener la misma semántica. No determine las propiedades del flujo utilizando estos bits. En su lugar, utilice SSL_get_stream_type() para determinar el tipo de flujo y SSL_get_stream_is_local() para determinar el iniciador del flujo.

SSL_get_stream_type() identifica el tipo de un flujo QUIC basándose en su identidad y no indica si una operación se puede realizar actualmente con éxito en un flujo. Por ejemplo, podría iniciar localmente un flujo unidireccional, escribir en él y luego concluir el flujo usando SSL_stream_conclude(3), lo que significa que ya no se puede escribir en él, pero SSL_get_stream_type() aún devolvería SSL_STREAM_TYPE_WRITE. El valor devuelto por SSL_get_stream_type() no varía durante la vida útil de un flujo.

VALORES DE RETORNO

SSL_get_stream_id() devuelve un ID de flujo QUIC, o UINT64_MAX si se llama en un objeto SSL que no es un objeto SSL QUIC, o si se llama en un objeto SSL de conexión QUIC sin un flujo predeterminado adjunto. Tenga en cuenta que los IDs de flujo QUIC válidos son siempre menores que 2**62.

SSL_get_stream_type() devuelve uno de los valores SSL_STREAM_TYPE.

SSL_is_stream_local() devuelve 1 si se llama en un objeto SSL de flujo QUIC que representa un flujo que se inició localmente. Devuelve 0 si se llama en un objeto SSL de flujo QUIC que representa un flujo que fue iniciado remotamente por un par, y -1 si se llama en cualquier otro tipo de objeto SSL.

VER TAMBIÉN

SSL_new_stream(3), SSL_accept_stream(3)
