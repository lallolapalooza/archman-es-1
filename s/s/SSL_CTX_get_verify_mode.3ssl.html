SSL_CTX_get_verify_mode(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_GET_VERIFY_MODE(3ssl) OpenSSL SSL_CTX_GET_VERIFY_MODE(3ssl)

NOMBRE

SSL_CTX_get_verify_mode, SSL_get_verify_mode, SSL_CTX_get_verify_depth, SSL_get_verify_depth, SSL_get_verify_callback, SSL_CTX_get_verify_callback - obtener los parámetros de verificación establecidos actualmente

SINOPSIS

#include <openssl/ssl.h>
int SSL_CTX_get_verify_mode(const SSL_CTX *ctx);
int SSL_get_verify_mode(const SSL *ssl);
int SSL_CTX_get_verify_depth(const SSL_CTX *ctx);
int SSL_get_verify_depth(const SSL *ssl);
int (*SSL_CTX_get_verify_callback(const SSL_CTX *ctx))(int, X509_STORE_CTX *);
int (*SSL_get_verify_callback(const SSL *ssl))(int, X509_STORE_CTX *);

DESCRIPCIÓN

SSL_CTX_get_verify_mode() devuelve el modo de verificación establecido actualmente en ctx.

SSL_get_verify_mode() devuelve el modo de verificación establecido actualmente en ssl.

SSL_CTX_get_verify_depth() devuelve el límite de profundidad de verificación establecido actualmente en ctx. Si no se ha establecido explícitamente ningún límite, se devuelve -1 y se utilizará el valor predeterminado.

SSL_get_verify_depth() devuelve el límite de profundidad de verificación establecido actualmente en ssl. Si no se ha establecido explícitamente ningún límite, se devuelve -1 y se utilizará el valor predeterminado.

SSL_CTX_get_verify_callback() devuelve un puntero de función a la devolución de llamada de verificación establecida actualmente en ctx. Si no se estableció explícitamente ninguna devolución de llamada, se devuelve el puntero NULL y se utilizará la devolución de llamada predeterminada.

SSL_get_verify_callback() devuelve un puntero de función a la devolución de llamada de verificación establecida actualmente en ssl. Si no se estableció explícitamente ninguna devolución de llamada, se devuelve el puntero NULL y se utilizará la devolución de llamada predeterminada.
