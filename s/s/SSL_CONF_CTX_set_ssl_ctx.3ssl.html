SSL_CONF_CTX_set_ssl_ctx(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CONF_CTX_SET_SSL_CTX(3ssl) OpenSSL SSL_CONF_CTX_SET_SSL_CTX(3ssl)

NOMBRE

SSL_CONF_CTX_finish, SSL_CONF_CTX_set_ssl_ctx, SSL_CONF_CTX_set_ssl - establecer el contexto a configurar

SINOPSIS

#include <openssl/ssl.h>
void SSL_CONF_CTX_set_ssl_ctx(SSL_CONF_CTX *cctx, SSL_CTX *ctx);
void SSL_CONF_CTX_set_ssl(SSL_CONF_CTX *cctx, SSL *ssl);
int SSL_CONF_CTX_finish(SSL_CONF_CTX *cctx);

DESCRIPCIÓN

SSL_CONF_CTX_set_ssl_ctx() establece el contexto asociado a cctx a la estructura SSL_CTX ctx. Cualquier SSL o SSL_CTX previo asociado a cctx se borra. Las llamadas subsiguientes a SSL_CONF_cmd() se enviarán a ctx.

SSL_CONF_CTX_set_ssl() establece el contexto asociado a cctx a la estructura SSL ssl. Cualquier SSL o SSL_CTX previo asociado a cctx se borra. Las llamadas subsiguientes a SSL_CONF_cmd() se enviarán a ssl.

La función SSL_CONF_CTX_finish() debe llamarse después de que todas las operaciones de configuración se hayan completado. Se utiliza para finalizar cualquier operación o para procesar valores predeterminados.

NOTAS

El contexto no tiene por qué estar establecido o puede establecerse a NULL, en cuyo caso solo se realiza la comprobación sintáctica de los comandos, siempre que sea posible.

VALORES DE RETORNO

SSL_CONF_CTX_set_ssl_ctx() y SSL_CTX_set_ssl() no devuelven valor.

SSL_CONF_CTX_finish() devuelve 1 en caso de éxito y 0 en caso de error.

VER TAMBIÉN

ssl(7), SSL_CONF_CTX_new(3), SSL_CONF_CTX_set_flags(3), SSL_CONF_CTX_set1_prefix(3), SSL_CONF_cmd(3), SSL_CONF_cmd_argv(3)

HISTORIAL
