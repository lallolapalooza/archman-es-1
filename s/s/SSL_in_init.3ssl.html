NOMBRE

SSL_in_before, SSL_in_init, SSL_is_init_finished, SSL_in_connect_init, SSL_in_accept_init, SSL_get_state - recuperar información sobre la máquina de estados del handshake

SINOPSIS

#include <openssl/ssl.h>
int SSL_in_init(const SSL *s);
int SSL_in_before(const SSL *s);
int SSL_is_init_finished(const SSL *s);
int SSL_in_connect_init(SSL *s);
int SSL_in_accept_init(SSL *s);
OSSL_HANDSHAKE_STATE SSL_get_state(const SSL *ssl);

DESCRIPCIÓN

SSL_in_init() devuelve 1 si la máquina de estados SSL/TLS está actualmente procesando o esperando mensajes de handshake, o 0 en caso contrario.

SSL_in_before() devuelve 1 si aún no se ha iniciado ningún handshake SSL/TLS, o 0 en caso contrario.

SSL_is_init_finished() devuelve 1 si la conexión SSL/TLS se encuentra en un estado donde se pueden transferir datos de aplicación totalmente protegidos, o 0 en caso contrario.

Tenga en cuenta que en algunas circunstancias (como cuando se están transfiriendo datos tempranos), SSL_in_init(), SSL_in_before() y SSL_is_init_finished() pueden devolver 0.

s NO DEBE ser NULL.

SSL_in_connect_init() devuelve 1 si s actúa como cliente y SSL_in_init() devolvería 1, o 0 en caso contrario.

SSL_in_accept_init() devuelve 1 si s actúa como servidor y SSL_in_init() devolvería 1, o 0 en caso contrario.

SSL_in_connect_init() y SSL_in_accept_init() se implementan como macros.

SSL_get_state() devuelve un valor que indica el estado actual de la máquina de estados del handshake. OSSL_HANDSHAKE_STATE es un tipo enumerado donde cada valor indica un estado discreto de la máquina de estados. Tenga en cuenta que las versiones futuras de OpenSSL pueden definir más estados, por lo que las aplicaciones deben esperar recibir valores de estado no reconocidos. El formato del nombre se compone de una serie de elementos como los siguientes:

protocolo_ST_rol_mensaje

protocolo es uno de TLS o DTLS. DTLS se utiliza cuando un estado es específico del protocolo DTLS. De lo contrario, se utiliza TLS.

rol es uno de CR, CW, SR o SW para indicar "lectura del cliente", "escritura del cliente", "lectura del servidor" o "escritura del servidor" respectivamente.

mensaje es el nombre de un mensaje de handshake que se está enviando o enviando, o que se está procesando o ha sido procesado.

Además, existen algunos estados especiales que no se ajustan al formato anterior. Estos son:

TLS_ST_BEFORE
Aún no se han enviado ni recibido mensajes de handshake.
TLS_ST_OK
El envío/procesamiento de mensajes de handshake ha finalizado.
TLS_ST_EARLY_DATA
Se están procesando datos tempranos
TLS_ST_PENDING_EARLY_DATA_END
Esperando el final del procesamiento de datos tempranos

VALORES DE RETORNO

SSL_in_init(), SSL_in_before(), SSL_is_init_finished(), SSL_in_connect_init() y SSL_in_accept_init() devuelven los valores como se indica anteriormente.

SSL_get_state() devuelve el estado actual del handshake.

VER TAMBIÉN
