SSL_set_connect_state(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_SET_CONNECT_STATE(3ssl) OpenSSL SSL_SET_CONNECT_STATE(3ssl)

NOMBRE

SSL_set_connect_state, SSL_set_accept_state, SSL_is_server - funciones para manipular y examinar el modo cliente o servidor de un objeto SSL

SINOPSIS

#include <openssl/ssl.h>
void SSL_set_connect_state(SSL *ssl);
void SSL_set_accept_state(SSL *ssl);
int SSL_is_server(const SSL *ssl);

DESCRIPCIÓN

SSL_set_connect_state() establece ssl para trabajar en modo cliente.

SSL_set_accept_state() establece ssl para trabajar en modo servidor.

SSL_is_server() comprueba si ssl está trabajando en modo servidor.

NOTAS

Cuando el objeto SSL_CTX se creó con SSL_CTX_new(3), se le asignó un método dedicado para cliente, un método dedicado para servidor, o un método genérico que puede ser utilizado tanto para conexiones de cliente como de servidor. (El método podría haber sido cambiado con SSL_CTX_set_ssl_version(3) o SSL_set_ssl_method(3).)

Al comenzar un nuevo handshake, el motor SSL debe saber si debe llamar a las rutinas de conexión (cliente) o aceptación (servidor). Aunque pueda estar claro por el método elegido, si se solicitó el modo cliente o servidor, las rutinas de handshake deben configurarse explícitamente.

Cuando se utilizan las rutinas SSL_connect(3) o SSL_accept(3), las rutinas de handshake correctas se configuran automáticamente. Al realizar una negociación transparente usando SSL_write_ex(3), SSL_write(3), SSL_read_ex(3), o SSL_read(3), las rutinas de handshake deben configurarse explícitamente de antemano usando SSL_set_connect_state() o SSL_set_accept_state().

Si se llama a SSL_is_server() antes de llamar a SSL_set_connect_state() o SSL_set_accept_state() (ya sea automáticamente o explícitamente), el resultado depende del método utilizado cuando se creó SSL_CTX con SSL_CTX_new(3). Si se pasó un método genérico o un método dedicado para servidor a SSL_CTX_new(3), SSL_is_server() devuelve 1; de lo contrario, devuelve 0.

VALORES DE RETORNO

SSL_set_connect_state() y SSL_set_accept_state() no devuelven información diagnóstica.

SSL_is_server() devuelve 1 si ssl está trabajando en modo servidor o 0 para modo cliente.
