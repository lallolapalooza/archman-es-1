SSL_set_incoming_stream_policy(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_SET_INCOMING_STREAM_POLICY(3ssl) OpenSSL SSL_SET_INCOMING_STREAM_POLICY(3ssl)

NOMBRE

SSL_set_incoming_stream_policy, SSL_INCOMING_STREAM_POLICY_AUTO, SSL_INCOMING_STREAM_POLICY_ACCEPT, SSL_INCOMING_STREAM_POLICY_REJECT - gestionar la política de flujo entrante de QUIC

SINOPSIS

#include <openssl/ssl.h>
#define SSL_INCOMING_STREAM_POLICY_AUTO
#define SSL_INCOMING_STREAM_POLICY_ACCEPT
#define SSL_INCOMING_STREAM_POLICY_REJECT
int SSL_set_incoming_stream_policy(SSL *conn, int policy,
                                          uint64_t app_error_code);

DESCRIPCIÓN

SSL_set_incoming_stream_policy() cambia la política de flujo entrante para una conexión QUIC. Dependiendo de la política configurada, OpenSSL QUIC puede rechazar automáticamente los flujos entrantes iniciados por el par. Esto está destinado a garantizar que las aplicaciones heredadas que utilizan la operación de flujo único con un flujo predeterminado en un objeto SSL de conexión QUIC no reciban flujos iniciados remotamente por un par que esas aplicaciones no están preparadas para manejar.

app_error_code es un código de error de aplicación que se utilizará en cualquier trama QUIC STOP_SENDING o RESET_STREAM generada para implementar la política. El código de error de aplicación predeterminado es 0.

Los valores válidos para policy son:

SSL_INCOMING_STREAM_POLICY_AUTO
Esta es la configuración predeterminada. Los flujos entrantes se aceptan según las siguientes reglas:
  • Si el modo de flujo predeterminado (configurado usando SSL_set_default_stream_mode(3)) se establece en SSL_DEFAULT_STREAM_MODE_AUTO_BIDI (el predeterminado) o SSL_DEFAULT_STREAM_MODE_AUTO_UNI, el flujo entrante se rechaza.
  • De lo contrario (donde el modo de flujo predeterminado es SSL_DEFAULT_STREAM_MODE_NONE), se asume que la aplicación es consciente de los flujos y el flujo entrante se acepta.
SSL_INCOMING_STREAM_POLICY_ACCEPT
Aceptar siempre los flujos entrantes, permitiendo que se pongan en cola usando SSL_accept_stream(3).
SSL_INCOMING_STREAM_POLICY_REJECT
Rechazar siempre los flujos entrantes.

Donde un flujo entrante es rechazado, se rechaza inmediatamente y no es posible acceder al flujo usando SSL_accept_stream(3). El flujo se rechaza usando tramas QUIC STOP_SENDING y RESET_STREAM según corresponda.

VALORES DE RETORNO

Devuelve 1 en caso de éxito y 0 en caso de fallo.

Esta función falla si se llama en un objeto de flujo QUIC SSL, o en un objeto SSL que no es QUIC.

VER TAMBIÉN

SSL_set_default_stream_mode(3), SSL_accept_stream(3)

HISTORIA

SSL_set_incoming_stream_policy() se añadió en OpenSSL 3.2.
