SSL_set_shutdown(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_SET_SHUTDOWN(3ssl) OpenSSL SSL_SET_SHUTDOWN(3ssl)

NOMBRE

SSL_set_shutdown, SSL_get_shutdown - manipular el estado de cierre de una conexión SSL

SINOPSIS

#include <openssl/ssl.h>
void SSL_set_shutdown(SSL *ssl, int mode);
int SSL_get_shutdown(const SSL *ssl);

DESCRIPCIÓN

SSL_set_shutdown() establece el estado de cierre de ssl a mode.

SSL_get_shutdown() devuelve el modo de cierre de ssl.

NOTAS

El estado de cierre de una conexión ssl es una máscara de bits de:

0
Ningún ajuste de cierre todavía.
SSL_SENT_SHUTDOWN
Se envió una alerta de cierre `close_notify` al par, la conexión se considera cerrada y la sesión está cerrada y es correcta.
SSL_RECEIVED_SHUTDOWN
Se recibió una alerta de cierre del par, ya sea una `close_notify` normal o un error fatal.

SSL_SENT_SHUTDOWN y SSL_RECEIVED_SHUTDOWN se pueden establecer al mismo tiempo.

El estado de cierre de la conexión se utiliza para determinar el estado de la sesión ssl. Si la sesión aún está abierta, cuando se llama a SSL_clear(3) o SSL_free(3), se considera incorrecta y se elimina según RFC2246. La condición real para una sesión cerrada correctamente es SSL_SENT_SHUTDOWN (según el RFC de TLS, es aceptable solo enviar la alerta close_notify pero no esperar la respuesta del par, cuando la conexión subyacente está cerrada). SSL_set_shutdown() se puede usar para establecer este estado sin enviar una alerta de cierre al par (ver SSL_shutdown(3)).

Si se recibió un `close_notify`, se establecerá SSL_RECEIVED_SHUTDOWN. Sin embargo, para establecer SSL_SENT_SHUTDOWN, la aplicación aún debe llamar a SSL_shutdown(3) o a SSL_set_shutdown().

SSL_set_shutdown() no es compatible con objetos SSL QUIC.

VALORES DE RETORNO

SSL_set_shutdown() no devuelve información diagnóstica.

SSL_get_shutdown() devuelve el estado de cierre actual tal como está establecido o basado en el estado real de la conexión.

SSL_get_shutdown() devuelve 0 si se llama en un objeto SSL de flujo QUIC. Si se llama en un objeto SSL de conexión QUIC, devuelve un valor con SSL_SENT_SHUTDOWN establecido si se ha enviado CONNECTION_CLOSE al par y devuelve un valor con SSL_RECEIVED_SHUTDOWN establecido si se ha recibido CONNECTION_CLOSE del par o la conexión QUIC está completamente terminada por otras razones.

VER TAMBIÉN

ssl(7), SSL_shutdown(3), SSL_CTX_set_quiet_shutdown(3), SSL_clear(3), SSL_free(3)
