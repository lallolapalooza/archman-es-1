SSL_get0_connection(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET0_CONNECTION(3ssl) OpenSSL SSL_GET0_CONNECTION(3ssl)

NOMBRE

SSL_get0_connection, SSL_is_connection - obtener un objeto SSL de conexión QUIC de un objeto SSL de flujo QUIC

SINOPSIS

#include <openssl/ssl.h>
SSL *SSL_get0_connection(SSL *ssl);
int SSL_is_connection(SSL *ssl);

DESCRIPCIÓN

La función SSL_get0_connection(), cuando se llama en un objeto SSL de flujo QUIC, devuelve el objeto SSL de conexión QUIC al que pertenece el objeto SSL de flujo QUIC.

Cuando se llama en un objeto SSL de conexión QUIC, devuelve el mismo objeto.

Cuando se llama en un objeto no-QUIC, devuelve el mismo objeto que se le pasó.

SSL_is_connection() devuelve 1 para objetos SSL de conexión QUIC y para objetos SSL no-QUIC, pero devuelve 0 para objetos SSL de flujo QUIC.

VALORES DE RETORNO

SSL_get0_connection() devuelve el objeto SSL de conexión QUIC (para un objeto SSL de flujo QUIC) y de lo contrario devuelve el mismo objeto SSL que se le pasó. Siempre devuelve un valor no nulo.

SSL_is_connection() devuelve 1 si el objeto SSL no es un objeto SSL de flujo QUIC y 0 en caso contrario.

VER TAMBIÉN

SSL_new(3), SSL_new_stream(3), SSL_accept_stream(3)

HISTORIA

Estas funciones se añadieron en OpenSSL 3.2.
