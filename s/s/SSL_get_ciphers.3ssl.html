SSL_get_ciphers(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_CIPHERS(3ssl) OpenSSL SSL_GET_CIPHERS(3ssl)

NOMBRE

SSL_get1_supported_ciphers, SSL_get_client_ciphers, SSL_get_ciphers, SSL_CTX_get_ciphers, SSL_bytes_to_cipher_list, SSL_get_cipher_list, SSL_get_shared_ciphers - obtener lista de SSL_CIPHERs disponibles

SINOPSIS

#include <openssl/ssl.h>
STACK_OF(SSL_CIPHER) *SSL_get_ciphers(const SSL *ssl);
STACK_OF(SSL_CIPHER) *SSL_CTX_get_ciphers(const SSL_CTX *ctx);
STACK_OF(SSL_CIPHER) *SSL_get1_supported_ciphers(SSL *s);
STACK_OF(SSL_CIPHER) *SSL_get_client_ciphers(const SSL *ssl);
int SSL_bytes_to_cipher_list(SSL *s, const unsigned char *bytes, size_t len,
                             int isv2format, STACK_OF(SSL_CIPHER) **sk,
                             STACK_OF(SSL_CIPHER) **scsvs);
const char *SSL_get_cipher_list(const SSL *ssl, int priority);
char *SSL_get_shared_ciphers(const SSL *s, char *buf, int size);

DESCRIPCIÓN

SSL_get_ciphers() devuelve la pila de SSL_CIPHERs disponibles para ssl, ordenados por preferencia. Si ssl es NULL o no hay cifrados disponibles, se devuelve NULL.

SSL_CTX_get_ciphers() devuelve la pila de SSL_CIPHERs disponibles para ctx.

SSL_get1_supported_ciphers() devuelve la pila de SSL_CIPHERs habilitados para ssl tal como se enviarían en un ClientHello (es decir, ordenados por preferencia). La lista depende de configuraciones como la lista de cifrados, las versiones de protocolo soportadas, el nivel de seguridad y los algoritmos de firma habilitados. Los cifrados SRP y PSK solo se habilitan si se han aplicado las devoluciones de llamada o configuraciones apropiadas. La lista de cifrados que se enviarían en un ClientHello puede diferir de la lista de cifrados que serían aceptables al actuar como servidor. Por ejemplo, un servidor puede usar cifrados adicionales si hay una brecha en la lista de protocolos soportados, y algunos cifrados pueden no ser utilizables por un servidor si no hay un certificado adecuado configurado. Si ssl es NULL o no hay cifrados disponibles, se devuelve NULL.

SSL_get_client_ciphers() devuelve la pila de SSL_CIPHERs disponibles que coinciden con la lista recibida del cliente en ssl. Si ssl es NULL, no hay cifrados disponibles, o ssl no está operando en modo servidor, se devuelve NULL.

SSL_bytes_to_cipher_list() trata los len octetos suministrados en bytes como una especificación de suite de cifrado del protocolo de red (en el formato de red SSLv2 de tres octetos por cifrado si isv2format es distinto de cero; de lo contrario, el formato de red SSLv3/TLS de dos octetos), y analiza las suites de cifrado soportadas por la biblioteca en las pilas devueltas de objetos SSL_CIPHER sk y Valores de Suite de Cifrado de Señalización scsvs. Las suites de cifrado no soportadas se ignoran. Devuelve 1 en caso de éxito y 0 en caso de fallo.

SSL_get_cipher_list() devuelve un puntero al nombre del SSL_CIPHER listado para ssl con priority. Si ssl es NULL, no hay cifrados disponibles, o hay menos cifrados que priority disponibles, se devuelve NULL.

SSL_get_shared_ciphers() crea una lista separada por dos puntos y terminada en NUL de nombres de SSL_CIPHER que están disponibles tanto en el cliente como en el servidor. buf es el búfer que debe ser poblado con la lista de nombres y size es el tamaño de dicho búfer. Se devuelve un puntero a buf en caso de éxito o NULL en caso de error. Si el búfer suministrado no es lo suficientemente grande como para contener la lista completa de nombres, se devolverá una lista truncada de nombres. Tenga en cuenta que el simple hecho de que una suite de cifrado esté disponible (es decir, esté configurada en la lista de cifrados) y sea compartida por el cliente y el servidor no significa que esté habilitada (consulte la descripción de SSL_get1_supported_ciphers() arriba). Esta función devolverá las suites de cifrado compartidas disponibles independientemente de si están habilitadas o no. Esta es una función solo del lado del servidor y debe llamarse solo después de completar el handshake inicial.

NOTAS

Los detalles de los cifrados obtenidos por SSL_get_ciphers(), SSL_CTX_get_ciphers() SSL_get1_supported_ciphers() y SSL_get_client_ciphers() se pueden obtener utilizando la familia de funciones SSL_CIPHER_get_name(3).

Llame a SSL_get_cipher_list() con priority comenzando desde 0 para obtener la lista ordenada de cifrados disponibles, hasta que se devuelva NULL.

Nota: SSL_get_ciphers(), SSL_CTX_get_ciphers() y SSL_get_client_ciphers() devuelven un puntero a una pila de cifrado interna, que se liberará más tarde cuando el objeto SSL o SSL_SESSION sea liberado. Por lo tanto, el código que llama NO DEBE liberar el valor de retorno en sí mismo.

La pila devuelta por SSL_get1_supported_ciphers() debe ser liberada usando sk_SSL_CIPHER_free().

Las pilas devueltas por SSL_bytes_to_cipher_list() deben ser liberadas usando sk_SSL_CIPHER_free().
