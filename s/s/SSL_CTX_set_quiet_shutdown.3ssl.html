SSL_CTX_set_quiet_shutdown(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_QUIET_SHUTDOWN(3ssl) OpenSSL SSL_CTX_SET_QUIET_SHUTDOWN(3ssl)

NOMBRE

SSL_CTX_set_quiet_shutdown, SSL_CTX_get_quiet_shutdown, SSL_set_quiet_shutdown, SSL_get_quiet_shutdown - manipular el comportamiento de cierre

SINOPSIS

#include <openssl/ssl.h>
void SSL_CTX_set_quiet_shutdown(SSL_CTX *ctx, int mode);
int SSL_CTX_get_quiet_shutdown(const SSL_CTX *ctx);
void SSL_set_quiet_shutdown(SSL *ssl, int mode);
int SSL_get_quiet_shutdown(const SSL *ssl);

DESCRIPCIÓN

SSL_CTX_set_quiet_shutdown() establece la bandera de "cierre silencioso" para ctx a mode. Los objetos SSL creados a partir de ctx heredan el mode válido en el momento en que se llama a SSL_new(3). mode puede ser 0 o 1.

SSL_CTX_get_quiet_shutdown() devuelve la configuración de "cierre silencioso" de ctx.

SSL_set_quiet_shutdown() establece la bandera de "cierre silencioso" para ssl a mode. La configuración permanece válida hasta que ssl se elimina con SSL_free(3) o se vuelve a llamar a SSL_set_quiet_shutdown(). No se modifica cuando se llama a SSL_clear(3). mode puede ser 0 o 1.

SSL_get_quiet_shutdown() devuelve la configuración de "cierre silencioso" de ssl.

Estas funciones no son compatibles con los objetos SSL QUIC. SSL_set_quiet_shutdown() no tiene ningún efecto si se llama en un objeto SSL QUIC.

NOTAS

Normalmente, cuando se finaliza una conexión SSL, las partes deben enviar mensajes de alerta de cierre (close_notify) usando SSL_shutdown(3) para un cierre limpio.

Al establecer la bandera de "cierre silencioso" a 1, SSL_shutdown(3) establecerá las banderas internas en SSL_SENT_SHUTDOWN|SSL_RECEIVED_SHUTDOWN. (Entonces, SSL_shutdown(3) se comporta como si se hubiera llamado a SSL_set_shutdown(3) con SSL_SENT_SHUTDOWN|SSL_RECEIVED_SHUTDOWN.) Por lo tanto, la sesión se considera cerrada, pero no se envía ninguna alerta de cierre (close_notify) al par. Este comportamiento viola el estándar TLS.

El valor predeterminado es el comportamiento normal de cierre, tal como lo describe el estándar TLS.

VALORES DE RETORNO

SSL_CTX_set_quiet_shutdown() y SSL_set_quiet_shutdown() no devuelven información diagnóstica.

SSL_CTX_get_quiet_shutdown() y SSL_get_quiet_shutdown() devuelven la configuración actual.

VER TAMBIÉN
