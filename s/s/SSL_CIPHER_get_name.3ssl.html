SSL_CIPHER_get_name(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CIPHER_GET_NAME(3ssl) OpenSSL SSL_CIPHER_GET_NAME(3ssl)

NOMBRE

SSL_CIPHER_get_name, SSL_CIPHER_standard_name, OPENSSL_cipher_name, SSL_CIPHER_get_bits, SSL_CIPHER_get_version, SSL_CIPHER_description, SSL_CIPHER_get_cipher_nid, SSL_CIPHER_get_digest_nid, SSL_CIPHER_get_handshake_digest, SSL_CIPHER_get_kx_nid, SSL_CIPHER_get_auth_nid, SSL_CIPHER_is_aead, SSL_CIPHER_find, SSL_CIPHER_get_id, SSL_CIPHER_get_protocol_id - obtener propiedades de SSL_CIPHER

SINOPSIS

#include <openssl/ssl.h>
const char *SSL_CIPHER_get_name(const SSL_CIPHER *cipher);
const char *SSL_CIPHER_standard_name(const SSL_CIPHER *cipher);
const char *OPENSSL_cipher_name(const char *stdname);
int SSL_CIPHER_get_bits(const SSL_CIPHER *cipher, int *alg_bits);
const char *SSL_CIPHER_get_version(const SSL_CIPHER *cipher);
char *SSL_CIPHER_description(const SSL_CIPHER *cipher, char *buf, int size);
int SSL_CIPHER_get_cipher_nid(const SSL_CIPHER *c);
int SSL_CIPHER_get_digest_nid(const SSL_CIPHER *c);
const EVP_MD *SSL_CIPHER_get_handshake_digest(const SSL_CIPHER *c);
int SSL_CIPHER_get_kx_nid(const SSL_CIPHER *c);
int SSL_CIPHER_get_auth_nid(const SSL_CIPHER *c);
int SSL_CIPHER_is_aead(const SSL_CIPHER *c);
const SSL_CIPHER *SSL_CIPHER_find(SSL *ssl, const unsigned char *ptr);
uint32_t SSL_CIPHER_get_id(const SSL_CIPHER *c);
uint16_t SSL_CIPHER_get_protocol_id(const SSL_CIPHER *c);

DESCRIPCIÓN

SSL_CIPHER_get_name() devuelve un puntero al nombre de cipher. Si cipher es NULL, devuelve "(NONE)".

SSL_CIPHER_standard_name() devuelve un puntero al nombre estándar RFC de cipher. Si cipher es NULL, devuelve "(NONE)". Si cipher no tiene un nombre estándar, devuelve NULL. Si cipher se definió tanto en SSLv3 como en TLS, devuelve el nombre TLS.

OPENSSL_cipher_name() devuelve un puntero al nombre de OpenSSL de stdname. Si stdname es NULL, o stdname no tiene un nombre de OpenSSL correspondiente, devuelve "(NONE)". Donde ambos existen, stdname debería ser el nombre TLS en lugar del nombre SSLv3.

SSL_CIPHER_get_bits() devuelve el número de bits secretos utilizados para cipher. Si cipher es NULL, se devuelve 0.

SSL_CIPHER_get_version() devuelve una cadena que indica la versión del protocolo SSL/TLS que definió por primera vez el cifrador. Devuelve "(NONE)" si cipher es NULL.

SSL_CIPHER_get_cipher_nid() devuelve el NID del cifrador correspondiente a c. Si no hay cifrador (por ejemplo, para conjuntos de cifrado sin cifrado) entonces se devuelve NID_undef.

SSL_CIPHER_get_digest_nid() devuelve el NID del resumen correspondiente al MAC utilizado por c durante el cifrado/descifrado de registros. Si no hay resumen (por ejemplo, para conjuntos de cifrado AEAD) entonces se devuelve NID_undef.

SSL_CIPHER_get_handshake_digest() devuelve un EVP_MD para el resumen utilizado durante el handshake SSL/TLS al usar el SSL_CIPHER c. Tenga en cuenta que este puede ser diferente del resumen utilizado para calcular el MAC para registros cifrados.

SSL_CIPHER_get_kx_nid() devuelve el NID de intercambio de claves correspondiente al método utilizado por c. Si no hay intercambio de claves, entonces se devuelve NID_undef. Si se puede utilizar cualquier algoritmo de intercambio de claves apropiado (como en el caso de los conjuntos de cifrado TLS 1.3) se devuelve NID_kx_any. Ejemplos (no exhaustivos):

NID_kx_rsa
NID_kx_ecdhe
NID_kx_dhe
NID_kx_psk

SSL_CIPHER_get_auth_nid() devuelve el NID de autenticación correspondiente al método utilizado por c. Si no hay autenticación, entonces se devuelve NID_undef. Si se puede utilizar cualquier algoritmo de autenticación apropiado (como en el caso de los conjuntos de cifrado TLS 1.3) se devuelve NID_auth_any. Ejemplos (no exhaustivos):

NID_auth_rsa
NID_auth_ecdsa
NID_auth_psk

SSL_CIPHER_is_aead() devuelve 1 si el cifrador c es AEAD (por ejemplo, GCM o ChaCha20/Poly1305), y 0 si no lo es.

SSL_CIPHER_find() devuelve una estructura SSL_CIPHER que tiene el ID del cifrador almacenado en ptr. El parámetro ptr es un array de dos elementos de char, que almacena el ID del cifrador TLS de dos bytes (tal como lo asigna IANA) en orden de bytes de red. Este parámetro generalmente se recupera de un paquete TLS utilizando funciones como SSL_client_hello_get0_ciphers(3). SSL_CIPHER_find() devuelve NULL si ocurre un error o si no se encuentra el cifrador indicado.

SSL_CIPHER_get_id() devuelve el ID específico de OpenSSL del cifrador dado c. Ese ID no es el mismo que el ID específico de IANA.

SSL_CIPHER_get_protocol_id() devuelve el ID de dos bytes utilizado en el protocolo TLS del cifrador dado c.

SSL_CIPHER_description() devuelve una descripción textual del cifrador utilizada en el buffer buf de longitud len proporcionado. Si se proporciona buf, debe tener al menos 128 bytes. Si buf es NULL, se asignará usando OPENSSL_malloc(). Si el buffer proporcionado es demasiado pequeño, o falla la asignación, se devuelve NULL.

La cadena devuelta por SSL_CIPHER_description() consta de varios campos separados por espacios en blanco:

<nombre_cifrador>
Representación textual del nombre del cifrador.
<versión_protocolo>
La versión mínima del protocolo que admite el conjunto de cifrado, como TLSv1.2. Tenga en cuenta que esto no siempre es lo mismo que la versión del protocolo en la que se definió por primera vez el conjunto de cifrado, ya que algunos conjuntos de cifrado son compatibles con versiones anteriores.
Kx=<intercambio de claves>
Método de intercambio de claves como RSA, ECDHE, etc.
Au=<autenticación>
Método de autenticación como RSA, None, etc. None es la representación de cifradores anónimos.
Enc=<método de cifrado simétrico>
Método de cifrado, con número de bits secretos, como AESGCM(128).
Mac=<código de autenticación de mensaje>
Resumen del mensaje, como SHA256.

Algunos ejemplos de la salida de SSL_CIPHER_description():

ECDHE-RSA-AES256-GCM-SHA256 TLSv1.2 Kx=ECDH     Au=RSA  Enc=AESGCM(256) Mac=AEAD
RSA-PSK-AES256-CBC-SHA384 TLSv1.0 Kx=RSAPSK   Au=RSA  Enc=AES(256)  Mac=SHA384

VALORES DEVUELTOS

SSL_CIPHER_get_name(), SSL_CIPHER_standard_name(), OPENSSL_cipher_name(), SSL_CIPHER_get_version() y SSL_CIPHER_description() devuelven el valor correspondiente en una cadena terminada en NUL para un cifrador específico o "(NONE)" si no se encuentra el cifrador.

SSL_CIPHER_get_bits() devuelve un entero positivo que representa el número de bits secretos o 0 si ocurrió un error.

SSL_CIPHER_get_cipher_nid(), SSL_CIPHER_get_digest_nid(), SSL_CIPHER_get_kx_nid() y SSL_CIPHER_get_auth_nid() devuelven el valor NID o NID_undef si ocurrió un error.

SSL_CIPHER_get_handshake_digest() devuelve una estructura EVP_MD válida o NULL si ocurrió un error.

SSL_CIPHER_is_aead() devuelve 1 si el cifrador es AEAD o 0 en caso contrario.

SSL_CIPHER_find() devuelve una estructura SSL_CIPHER válida o NULL si ocurrió un error.

SSL_CIPHER_get_id() devuelve un entero de 4 bytes que representa el ID específico de OpenSSL.

SSL_CIPHER_get_protocol_id() devuelve un entero de 2 bytes que representa el ID específico del protocolo TLS.

VER TAMBIÉN

ssl(7), SSL_get_current_cipher(3), SSL_get_ciphers(3), openssl-ciphers(1)

HISTORIA

La función SSL_CIPHER_get_version() se actualizó para devolver siempre la cadena de protocolo correcta en OpenSSL 1.1.0.

La función SSL_CIPHER_description() se cambió para devolver NULL en caso de error, en lugar de una cadena fija, en OpenSSL 1.1.0.

La función SSL_CIPHER_get_handshake_digest() se añadió en OpenSSL 1.1.1.

La función SSL_CIPHER_standard_name() estuvo disponible globalmente en OpenSSL 1.1.1.
