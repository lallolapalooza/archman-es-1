SSL_CTX_set_client_cert_cb(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_CLIENT_CERT_CB(3ssl) OpenSSL SSL_CTX_SET_CLIENT_CERT_CB(3ssl)

NOMBRE

SSL_CTX_set_client_cert_cb, SSL_CTX_get_client_cert_cb - manejar la función de devolución de llamada de certificado de cliente

SINOPSIS

#include <openssl/ssl.h>
void SSL_CTX_set_client_cert_cb(SSL_CTX *ctx,
                                int (*client_cert_cb)(SSL *ssl, X509 **x509,
                                                      EVP_PKEY **pkey));
int (*SSL_CTX_get_client_cert_cb(SSL_CTX *ctx))(SSL *ssl, X509 **x509,
                                                EVP_PKEY **pkey);

DESCRIPCIÓN

SSL_CTX_set_client_cert_cb() establece la devolución de llamada client_cert_cb, que se llama cuando un servidor solicita un certificado de cliente y aún no se ha establecido ningún certificado para el objeto SSL.

Cuando client_cert_cb es NULL, no se utiliza ninguna función de devolución de llamada.

SSL_CTX_get_client_cert_cb() devuelve un puntero a la función de devolución de llamada actualmente establecida.

client_cert_cb es la devolución de llamada definida por la aplicación. Si desea establecer un certificado, se debe establecer una combinación de certificado/clave privada utilizando los argumentos x509 y pkey y se debe devolver "1". El certificado se instalará en ssl, ver las NOTAS y ERRORES. Si no se debe establecer ningún certificado, se debe devolver "0" y no se enviará ningún certificado. Un valor de retorno negativo suspenderá el handshake y la función de handshake retornará inmediatamente. SSL_get_error(3) devolverá SSL_ERROR_WANT_X509_LOOKUP para indicar que el handshake se suspendió. La siguiente llamada a la función de handshake volverá a provocar la llamada a client_cert_cb. Es responsabilidad de client_cert_cb almacenar información sobre el estado de la última llamada, si es necesario continuar.

NOTAS

Durante un handshake (o renegociación), un servidor puede solicitar un certificado al cliente. Solo se debe enviar un certificado de cliente cuando el servidor haya enviado la solicitud.

Cuando se ha establecido un certificado utilizando la familia de funciones SSL_CTX_use_certificate(3), se enviará al servidor. El estándar TLS requiere que solo se envíe un certificado si coincide con la lista de CA aceptables enviada por el servidor. Este requisito se infringe con el comportamiento predeterminado de la biblioteca OpenSSL. Usando la función de devolución de llamada es posible implementar una rutina de selección adecuada o permitir una interacción del usuario para elegir el certificado que se enviará.

Si se define una función de devolución de llamada y aún no se ha definido ningún certificado para el objeto SSL, se llamará a la función de devolución de llamada. Si la función de devolución de llamada devuelve un certificado, la biblioteca OpenSSL intentará cargar los datos de la clave privada y el certificado en el objeto SSL utilizando las funciones SSL_use_certificate() y SSL_use_private_key(). Por lo tanto, instalará permanentemente el certificado y la clave para este objeto SSL. No se restablecerá llamando a SSL_clear(3). Si la devolución de llamada no devuelve ningún certificado, la biblioteca OpenSSL no enviará ningún certificado.

VALORES DE RETORNO

SSL_CTX_get_client_cert_cb() devuelve el puntero de función de client_cert_cb o NULL si la devolución de llamada no está establecida.

ERRORES

La client_cert_cb no puede devolver una cadena de certificados completa, solo puede devolver un certificado de cliente. Si la cadena tiene solo una longitud de 2, el certificado de la CA raíz puede omitirse según el estándar TLS y, por lo tanto, se puede enviar una respuesta conforme al estándar al servidor. Para una cadena más larga, el cliente debe enviar la cadena completa (con la opción de omitir el certificado de la CA raíz). Esto solo se puede lograr agregando los certificados de la CA intermedia al almacén de certificados de confianza para el objeto SSL (lo que resulta en tener que agregar certificados de CA que de otro modo quizás no serían confiables), o agregando los certificados de la cadena usando la función SSL_CTX_add_extra_chain_cert(3), que solo está disponible para el objeto SSL en su conjunto y que, por lo tanto, probablemente solo puede aplicarse a un certificado de cliente, lo que hace que el concepto de la función de devolución de llamada (para permitir la elección entre varios certificados) sea cuestionable.

Una vez que el objeto SSL se ha utilizado junto con la función de devolución de llamada, el certificado se establecerá para el objeto SSL y no se borrará incluso cuando se llame a SSL_clear(3). Por lo tanto, es obligatorio destruir el objeto SSL usando SSL_free(3) y crear uno nuevo para volver al estado anterior.
