SSL_get_all_async_fds(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_ALL_ASYNC_FDS(3ssl) OpenSSL SSL_GET_ALL_ASYNC_FDS(3ssl)

NOMBRE

SSL_waiting_for_async, SSL_get_all_async_fds, SSL_get_changed_async_fds - gestionar operaciones asíncronas

SINOPSIS

#include <openssl/async.h>
#include <openssl/ssl.h>
int SSL_waiting_for_async(SSL *s);
int SSL_get_all_async_fds(SSL *s, OSSL_ASYNC_FD *fd, size_t *numfds);
int SSL_get_changed_async_fds(SSL *s, OSSL_ASYNC_FD *addfd, size_t *numaddfds,
                              OSSL_ASYNC_FD *delfd, size_t *numdelfds);

DESCRIPCIÓN

SSL_waiting_for_async() determina si una conexión SSL está esperando actualmente a que se completen operaciones asíncronas (ver el modo SSL_MODE_ASYNC en SSL_CTX_set_mode(3)).

SSL_get_all_async_fds() devuelve una lista de descriptores de archivo que se pueden usar en una llamada a select() o poll() para determinar si la operación asíncrona actual se ha completado o no. Una operación completada resultará en que aparezcan datos como "listos para leer" en el descriptor de archivo (no se deben leer datos reales del descriptor de archivo). Esta función solo debe llamarse si el objeto SSL está esperando actualmente trabajo asíncrono para completarse (es decir, se ha recibido SSL_ERROR_WANT_ASYNC - ver SSL_get_error(3)). Típicamente, la lista contendrá solo un descriptor de archivo. Sin embargo, si se utilizan varios motores capaces de asincronía, es posible que haya más de uno. El número de descriptores de archivo devueltos se almacena en *numfds y los descriptores de archivo en sí están en *fds. El parámetro fds puede ser NULL, en cuyo caso no se devuelven descriptores de archivo, pero *numfds todavía se rellena. Es responsabilidad del llamante asegurarse de que se asigna suficiente memoria en *fds, por lo que típicamente esta función se llama dos veces (una vez con un parámetro fds NULL y otra vez sin él).

SSL_get_changed_async_fds() devuelve una lista de los descriptores de archivo asíncronos que se han añadido y una lista de los que se han eliminado desde que se recibió la última SSL_ERROR_WANT_ASYNC (o desde que se creó el objeto SSL si no se ha recibido ninguna SSL_ERROR_WANT_ASYNC). Similar a SSL_get_all_async_fds(), es responsabilidad del llamante asegurarse de que *addfd y *delfd tienen suficiente memoria asignada, aunque pueden ser NULL. El número de fds añadidos y el número de fds eliminados se almacenan en *numaddfds y *numdelfds respectivamente.

VALORES DE RETORNO

SSL_waiting_for_async() devolverá 1 si la operación SSL actual está esperando que se complete una operación asíncrona y 0 en caso contrario.

SSL_get_all_async_fds() y SSL_get_changed_async_fds() devuelven 1 en caso de éxito o 0 en caso de error.

NOTAS

En las plataformas Windows, el encabezado <openssl/async.h> depende de algunos de los tipos que habitualmente se ponen a disposición al incluir <windows.h>. El desarrollador de la aplicación probablemente necesitará control sobre cuándo se incluye este último, comúnmente como una de las primeras cabeceras incluidas. Por lo tanto, se define como responsabilidad del desarrollador de la aplicación incluir <windows.h> antes de <openssl/async.h>.

VER TAMBIÉN

ssl(7), SSL_get_error(3), SSL_CTX_set_mode(3)

HISTORIA

Las funciones SSL_waiting_for_async(), SSL_get_all_async_fds() y SSL_get_changed_async_fds() se añadieron en OpenSSL 1.1.0.
