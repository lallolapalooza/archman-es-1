SSL_CTX_config(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_CONFIG(3ssl) OpenSSL SSL_CTX_CONFIG(3ssl)

NOMBRE

SSL_CTX_config, SSL_config - configurar la estructura SSL_CTX o SSL

SINOPSIS

#include <openssl/ssl.h>
int SSL_CTX_config(SSL_CTX *ctx, const char *name);
int SSL_config(SSL *s, const char *name);

DESCRIPCIÓN

Las funciones SSL_CTX_config() y SSL_config() configuran una estructura SSL_CTX o SSL utilizando la configuración name.

Al llamar a SSL_CTX_config() o SSL_config(), una aplicación puede realizar muchas tareas complejas basadas en el contenido del archivo de configuración, simplificando en gran medida el código de configuración de la aplicación. También se puede lograr un grado de previsión: una aplicación puede admitir automáticamente funciones de configuración en versiones más recientes de OpenSSL.

Se debe haber cargado previamente un archivo de configuración, por ejemplo, usando CONF_modules_load_file(). Consulte config(5) para obtener detalles sobre la sintaxis del archivo de configuración.

VALORES DE RETORNO

SSL_CTX_config() y SSL_config() devuelven 1 para éxito o 0 si ocurrió un error.

EJEMPLOS

Si el archivo "config.cnf" contiene lo siguiente:

testapp = test_sect
[test_sect]
# lista de módulos de configuración
ssl_conf = ssl_sect
[ssl_sect]
server = server_section
[server_section]
RSA.Certificate = server-rsa.pem
ECDSA.Certificate = server-ecdsa.pem
Ciphers = ALL:!RC4

Una aplicación podría llamar:

if (CONF_modules_load_file("config.cnf", "testapp", 0) <= 0) {
    fprintf(stderr, "Error procesando archivo de configuración\n");
    goto err;
}
ctx = SSL_CTX_new(TLS_server_method());
if (SSL_CTX_config(ctx, "server") == 0) {
    fprintf(stderr, "Error configurando el servidor.\n");
    goto err;
}

En este ejemplo, se configuran dos certificados y la lista de cifrados sin necesidad de código de aplicación adicional.

VER TAMBIÉN

ssl(7), config(5), SSL_CONF_cmd(3), CONF_modules_load_file(3)

HISTORIA

Las funciones SSL_CTX_config() y SSL_config() se añadieron en OpenSSL 1.1.0.
