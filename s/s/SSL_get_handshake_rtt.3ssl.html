SSL_get_handshake_rtt(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_HANDSHAKE_RTT(3ssl) OpenSSL SSL_GET_HANDSHAKE_RTT(3ssl)

NOMBRE

SSL_get_handshake_rtt - obtener el tiempo de ida y vuelta para el Handshake SSL

SINOPSIS

#include <openssl/ssl.h>
int SSL_get_handshake_rtt(const SSL *s, uint64_t *rtt);

DESCRIPCIÓN

SSL_get_handshake_rtt() recupera el tiempo de ida y vuelta (RTT) para ssl.

Esta métrica se representa en microsegundos (us) como un tipo de datos uint64_t.

NOTAS

Esta métrica se crea tomando dos marcas de tiempo durante el handshake y proporcionando la diferencia entre estos dos tiempos.

Cuando actúa como servidor, se toma una marca de tiempo cuando el servidor termina de escribir al cliente. Esto ocurre durante el ServerFinished en TLS 1.3 y ServerHelloDone en TLS 1.2. La otra marca de tiempo se toma cuando el servidor termina de leer la respuesta del cliente. Esto es después de que el cliente ha respondido con ClientFinished.

Cuando actúa como cliente, se toma una marca de tiempo cuando el cliente termina de escribir el ClientHello y los datos tempranos (si los hay). La otra se toma cuando el cliente termina de leer la respuesta del servidor. Esto es después de ServerFinished en TLS 1.3 y después de ServerHelloDone en TLS 1.2.

Además del retraso de propagación de la red y la sobrecarga de la pila de red, esta métrica incluye el tiempo de procesamiento en ambos puntos finales, ya que se basa en mensajes a nivel de protocolo TLS y el protocolo TLS no está diseñado para medir tiempos de red. En algunos casos, el tiempo de procesamiento puede ser significativo, especialmente cuando el procesamiento incluye operaciones criptográficas asimétricas.

VALORES DEVUELTOS

Devuelve 1 si el RTT del handshake TLS se recupera correctamente. Devuelve 0 si el RTT del handshake TLS aún no se puede determinar. Devuelve -1 si, al recuperar el RTT del handshake TLS, ocurre un error.

HISTORIA

Esta función se añadió en OpenSSL 3.2.
