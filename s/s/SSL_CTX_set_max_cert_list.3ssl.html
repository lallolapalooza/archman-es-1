SSL_CTX_set_max_cert_list(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_MAX_CERT_LIST(3ssl) OpenSSL SSL_CTX_SET_MAX_CERT_LIST(3ssl)

NOMBRE

SSL_CTX_set_max_cert_list, SSL_CTX_get_max_cert_list, SSL_set_max_cert_list, SSL_get_max_cert_list - manipular el tamaño permitido para la cadena de certificados del par

SINOPSIS

#include <openssl/ssl.h>
long SSL_CTX_set_max_cert_list(SSL_CTX *ctx, long size);
long SSL_CTX_get_max_cert_list(SSL_CTX *ctx);
long SSL_set_max_cert_list(SSL *ssl, long size);
long SSL_get_max_cert_list(SSL *ctx);

DESCRIPCIÓN

SSL_CTX_set_max_cert_list() establece el tamaño máximo permitido para la cadena de certificados del par para todos los objetos SSL creados a partir de ctx a <size> bytes. Los objetos SSL heredan la configuración válida para ctx en el momento en que se llama a SSL_new(3).

SSL_CTX_get_max_cert_list() devuelve el tamaño máximo actualmente establecido para ctx.

SSL_set_max_cert_list() establece el tamaño máximo permitido para la cadena de certificados del par para ssl a <size> bytes. Esta configuración permanece válida hasta que se establezca un nuevo valor.

SSL_get_max_cert_list() devuelve el tamaño máximo actualmente establecido para ssl.

NOTAS

Durante el proceso de handshake, el par puede enviar una cadena de certificados. El estándar TLS/SSL no proporciona un tamaño máximo para la cadena de certificados. La biblioteca OpenSSL maneja los datos entrantes mediante un búfer asignado dinámicamente. Para evitar que este búfer crezca sin límites debido a datos recibidos de un par defectuoso o malicioso, se establece un tamaño máximo para la cadena de certificados.

El valor predeterminado para el tamaño máximo de la cadena de certificados es 100kB (30kB en la plataforma DOS de 16 bits). Esto debería ser suficiente para cadenas de certificados habituales (la longitud máxima predeterminada de la cadena de OpenSSL es 10, véase SSL_CTX_set_verify(3), y los certificados sin extensiones especiales tienen un tamaño típico de 1-2kB).

Para aplicaciones especiales, puede ser necesario ampliar el tamaño máximo de la cadena de certificados permitido para ser enviado por el par, véase, por ejemplo, el trabajo sobre el "Perfil de Certificado Proxy de Infraestructura de Clave Pública Internet X.509" y el "Protocolo de Delegación TLS" en http://www.ietf.org/ y http://www.globus.org/ .

En condiciones normales, nunca debería ser necesario establecer un valor inferior al predeterminado, ya que el búfer se maneja dinámicamente y solo utiliza la memoria realmente requerida por los datos enviados por el par.

Si se excede el tamaño máximo permitido de la cadena de certificados, el handshake fallará con un error SSL_R_EXCESSIVE_MESSAGE_SIZE.

VALORES DE RETORNO

SSL_CTX_set_max_cert_list() y SSL_set_max_cert_list() devuelven el valor previamente establecido.

SSL_CTX_get_max_cert_list() y SSL_get_max_cert_list() devuelven el valor actualmente establecido.

VER TAMBIÉN
