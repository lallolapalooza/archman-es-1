SSL_CTX_add_extra_chain_cert(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_ADD_EXTRA_CHAIN_CERT(3ssl) OpenSSL SSL_CTX_ADD_EXTRA_CHAIN_CERT(3ssl)

NOMBRE

SSL_CTX_add_extra_chain_cert, SSL_CTX_get_extra_chain_certs, SSL_CTX_get_extra_chain_certs_only, SSL_CTX_clear_extra_chain_certs - añadir, obtener o borrar certificados de cadena extra

SINOPSIS

#include <openssl/ssl.h>
long SSL_CTX_add_extra_chain_cert(SSL_CTX *ctx, X509 *x509);
long SSL_CTX_get_extra_chain_certs(SSL_CTX *ctx, STACK_OF(X509) **sk);
long SSL_CTX_get_extra_chain_certs_only(SSL_CTX *ctx, STACK_OF(X509) **sk);
long SSL_CTX_clear_extra_chain_certs(SSL_CTX *ctx);

DESCRIPCIÓN

SSL_CTX_add_extra_chain_cert() añade el certificado x509 a los certificados de cadena extra asociados con ctx. Se pueden añadir varios certificados uno tras otro.

SSL_CTX_get_extra_chain_certs() recupera los certificados de cadena extra asociados con ctx, o la cadena asociada con el certificado actual de ctx si la cadena extra está vacía. La pila devuelta no debe ser liberada por el llamante.

SSL_CTX_get_extra_chain_certs_only() recupera los certificados de cadena extra asociados con ctx. La pila devuelta no debe ser liberada por el llamante.

SSL_CTX_clear_extra_chain_certs() borra todos los certificados de cadena extra asociados con ctx.

Estas funciones se implementan como macros.

NOTAS

Al enviar una cadena de certificados, los certificados de cadena extra se envían en orden después del certificado de entidad final.

Si no se especifica ninguna cadena, la biblioteca intentará completar la cadena a partir de los certificados CA disponibles en el almacenamiento de CA de confianza, véase SSL_CTX_load_verify_locations(3).

El certificado x509 proporcionado a SSL_CTX_add_extra_chain_cert() será liberado por la biblioteca cuando se destruya el SSL_CTX. Una aplicación no debe liberar el objeto x509.

RESTRICCIONES

Solo se puede especificar un conjunto de certificados de cadena extra por estructura SSL_CTX. Cadenas diferentes para certificados diferentes (por ejemplo, si el mismo servidor especifica certificados RSA y DSA) o diferentes estructuras SSL con el mismo SSL_CTX padre no se pueden especificar usando esta función. Para una mayor flexibilidad, se deben utilizar funciones como SSL_add1_chain_cert() en su lugar.

VALORES DE RETORNO

SSL_CTX_add_extra_chain_cert() y SSL_CTX_clear_extra_chain_certs() devuelven 1 en caso de éxito y 0 en caso de fallo. Consulte la pila de errores para averiguar el motivo del fallo.
