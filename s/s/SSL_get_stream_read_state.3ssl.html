SSL_get_stream_read_state(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_STREAM_READ_STATE(3ssl) OpenSSL SSL_GET_STREAM_READ_STATE(3ssl)

NOMBRE

SSL_get_stream_read_state, SSL_get_stream_write_state, SSL_get_stream_read_error_code, SSL_get_stream_write_error_code, SSL_STREAM_STATE_NONE, SSL_STREAM_STATE_OK, SSL_STREAM_STATE_WRONG_DIR, SSL_STREAM_STATE_FINISHED, SSL_STREAM_STATE_RESET_LOCAL, SSL_STREAM_STATE_RESET_REMOTE, SSL_STREAM_STATE_CONN_CLOSED - obtener el estado del flujo QUIC

SINOPSIS

#include <openssl/ssl.h>
#define SSL_STREAM_STATE_NONE
#define SSL_STREAM_STATE_OK
#define SSL_STREAM_STATE_WRONG_DIR
#define SSL_STREAM_STATE_FINISHED
#define SSL_STREAM_STATE_RESET_LOCAL
#define SSL_STREAM_STATE_RESET_REMOTE
#define SSL_STREAM_STATE_CONN_CLOSED
int SSL_get_stream_read_state(SSL *ssl);
int SSL_get_stream_write_state(SSL *ssl);
int SSL_get_stream_read_error_code(SSL *ssl, uint64_t *app_error_code);
int SSL_get_stream_write_error_code(SSL *ssl, uint64_t *app_error_code);

DESCRIPCIÓN

SSL_get_stream_read_state() y SSL_get_stream_write_state() obtienen el estado general de las partes de recepción y envío de un flujo QUIC, respectivamente.

Ambas devuelven uno de los siguientes valores:

SSL_STREAM_STATE_NONE
Este valor se devuelve si se llama en un objeto SSL que no es QUIC, o en un objeto SSL de conexión QUIC sin un flujo predeterminado adjunto.
SSL_STREAM_STATE_OK
Este valor se devuelve en un flujo que no ha sido concluido y permanece saludable.
SSL_STREAM_STATE_WRONG_DIR
Este valor se devuelve si se llama a SSL_get_stream_read_state() en un flujo unidireccional iniciado localmente (y por lo tanto solo de envío), o, por el contrario, si se llama a SSL_get_stream_write_state() en un flujo unidireccional iniciado remotamente (y por lo tanto solo de recepción).
SSL_STREAM_STATE_FINISHED
Para SSL_get_stream_read_state(), este valor se devuelve cuando el peer remoto ha señalado el final de la parte de recepción del flujo. Tenga en cuenta que puede haber datos residuales disponibles para leer a través de SSL_read(3) cuando se devuelve este estado.

Para SSL_get_stream_write_state(), este valor se devuelve cuando la aplicación local ha concluido el flujo utilizando SSL_stream_conclude(3). Las llamadas posteriores a SSL_write(3) no tendrán éxito.

SSL_STREAM_STATE_RESET_LOCAL
Este valor se devuelve cuando la parte del flujo aplicable fue reiniciada por la aplicación local.

Para SSL_get_stream_read_state(), esto significa que la parte de recepción del flujo se abortó utilizando un marco QUIC STOP_SENDING transmitido localmente. Aún puede ser posible obtener datos residuales que queden por leer llamando a SSL_read(3).

Para SSL_get_stream_write_state(), esto significa que la parte de envío del flujo se abortó, por ejemplo, porque la aplicación llamó a SSL_stream_reset(3), o porque un objeto SSL de flujo QUIC con una parte de envío no concluida fue liberado usando SSL_free(3). Las llamadas a SSL_write(3) fallarán.

Cuando se devuelve este valor, el código de error de la aplicación que se señaló se puede obtener llamando a SSL_get_stream_read_error_code() o SSL_get_stream_write_error_code() según corresponda.

SSL_STREAM_STATE_RESET_REMOTE
Este valor se devuelve cuando la parte del flujo aplicable fue reiniciada por el peer remoto.

Para SSL_get_stream_read_state(), esto significa que el peer envió un marco QUIC RESET_STREAM para la parte de recepción del flujo; la parte de recepción del flujo fue abortada lógicamente por el peer.

Para SSL_get_stream_write_state(), esto significa que el peer envió un marco QUIC STOP_SENDING para la parte de envío del flujo; el peer ha indicado que no desea recibir más datos en la parte de envío del flujo. Las llamadas a SSL_write(3) fallarán.

Cuando se devuelve este valor, el código de error de la aplicación que se señaló se puede obtener llamando a SSL_get_stream_read_error_code() o SSL_get_stream_write_error_code() según corresponda.

SSL_STREAM_STATE_CONN_CLOSED
La conexión QUIC a la que pertenece el flujo se cerró. Puede obtener información sobre las circunstancias de este cierre utilizando SSL_get_conn_close_info(3). Todavía puede haber datos residuales disponibles para leer a través de SSL_read(3) cuando se devuelve este estado. Las llamadas a SSL_write(3) fallarán. SSL_get_stream_read_state() devolverá este estado si y solo si SSL_get_stream_write_state() también devolverá este estado.

SSL_get_stream_read_error_code() y SSL_get_stream_write_error_code() proporcionan el código de error de la aplicación que se señaló durante la terminación no normal de las partes de recepción o envío de un flujo, respectivamente. En caso de éxito, el código de error de la aplicación se escribe en *app_error_code.

NOTAS

Si se cierra una conexión QUIC, el estado del flujo para todos los flujos transiciona a SSL_STREAM_STATE_CONN_CLOSED, pero no se puede obtener ningún código de error de aplicación utilizando SSL_get_stream_read_error_code() o SSL_get_stream_write_error_code(), ya que el proceso de cierre de la conexión QUIC no provoca que se asocie un código de error de aplicación a cada flujo individual que aún existe en el momento del cierre de la conexión. Sin embargo, puede obtener el código de error general asociado con el cierre de la conexión utilizando SSL_get_conn_close_info(3).

VALORES DE RETORNO

SSL_get_stream_read_state() y SSL_get_stream_write_state() devuelven uno de los valores SSL_STREAM_STATE. Si se llama en un objeto SSL que no es QUIC, o en un objeto SSL de conexión QUIC sin un flujo predeterminado, se devuelve SSL_STREAM_STATE_NONE.

SSL_get_stream_read_error_code() y SSL_get_stream_write_error_code() devuelven 1 en caso de éxito y 0 si el flujo se terminó normalmente. Devuelven -1 en caso de error, por ejemplo, si el flujo todavía está saludable, estaba saludable en el momento del cierre de la conexión, si se llama en un flujo para el cual la parte del flujo correspondiente no existe (por ejemplo, en un flujo unidireccional), o si se llama en un objeto que no es QUIC o en un objeto SSL de conexión QUIC sin un flujo predeterminado adjunto.

VER TAMBIÉN

SSL_stream_conclude(3), SSL_stream_reset(3), SSL_new_stream(3), SSL_accept_stream(3), SSL_get_conn_close_info(3)

HISTORIA

Estas funciones se agregaron en OpenSSL 3.2.

NAME

SSL_get_stream_read_state - get the current read state of the SSL stream

SYNOPSIS

#include <openssl/ssl.h>

SSL_STREAM_STATE SSL_get_stream_read_state(const SSL *s);

DESCRIPTION

The SSL_get_stream_read_state() function returns the current read state of the SSL stream associated with the SSL structure s.

The state is returned as a value of type SSL_STREAM_STATE. The possible return values are:

  • SSL_STREAM_STATE_READY: The stream is ready for reading.
  • SSL_STREAM_STATE_NEED_READ: The stream needs to read more data from the underlying transport.
  • SSL_STREAM_STATE_NEED_WRITE: The stream needs to write data to the underlying transport.
  • SSL_STREAM_STATE_ERROR: An error occurred.
  • SSL_STREAM_STATE_NONE: The stream state is not defined or not applicable.

NOTES

This function is part of the OpenSSL Stream API, which provides a higher-level interface for working with SSL/TLS streams. It is intended to be used in conjunction with other Stream API functions to manage the flow of data over an SSL/TLS connection.

RETURN VALUES

The current read state of the SSL stream.

HISTORY

The SSL_get_stream_read_state() function was added in OpenSSL 3.2.
