SSL_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_NEW(3ssl) OpenSSL SSL_NEW(3ssl)

NOMBRE

SSL_dup, SSL_new, SSL_up_ref - crear una estructura SSL para una conexión

SINOPSIS

#include <openssl/ssl.h>
SSL *SSL_dup(SSL *s);
SSL *SSL_new(SSL_CTX *ctx);
int SSL_up_ref(SSL *s);

DESCRIPCIÓN

SSL_new() crea una nueva estructura SSL que se necesita para mantener los datos de una conexión TLS/SSL. La nueva estructura hereda la configuración del contexto subyacente ctx: método de conexión, opciones, configuraciones de verificación, configuraciones de tiempo de espera. Una estructura SSL tiene un contador de referencias. La creación de una estructura SSL por primera vez incrementa el contador de referencias. Liberarla (usando SSL_free) lo decrementa. Cuando el contador de referencias llega a cero, se liberan todas las memorias o recursos asignados a la estructura SSL.

SSL_up_ref() incrementa el contador de referencias de una estructura SSL existente.

La función SSL_dup() crea y devuelve una nueva estructura SSL del mismo SSL_CTX que se utilizó para crear s. Adicionalmente, duplica un subconjunto de las configuraciones en s en el nuevo objeto SSL.

Para que SSL_dup() funcione, la conexión DEBE estar en su estado inicial y NO DEBE haber iniciado aún el handshake SSL. Para conexiones que no están en su estado inicial, SSL_dup() simplemente incrementa un contador de referencias interno y devuelve el mismo identificador. Puede ser posible usar SSL_clear(3) para reciclar un identificador SSL que no está en su estado inicial para su reutilización, pero es mejor evitarlo. En su lugar, guarde y restaure la sesión, si lo desea, y construya un identificador nuevo para cada conexión.

El subconjunto de configuraciones en s que se duplican son:

cualquier dato de sesión si está configurado (incluido el contexto session_id)
cualquier configuración tmp_dh establecida mediante SSL_set_tmp_dh(3), SSL_set_tmp_dh_callback(3), o SSL_set_dh_auto(3)
cualquier certificado, clave privada o cadena de certificados configurados
cualquier algoritmo de firma configurado, o algoritmos de firma del cliente
cualquier configuración DANE
cualquier Opción establecida mediante SSL_set_options(3)
cualquier Modo establecido mediante SSL_set_mode(3)
cualquier configuración de protocolo mínimo o máximo establecida mediante SSL_set_min_proto_version(3) o SSL_set_max_proto_version(3) (Nota: Solo desde OpenSSL 1.1.1h y posteriores)
cualquier modo de verificación, callback o profundidad establecida mediante SSL_set_verify(3) o SSL_set_verify_depth(3) o cualquier parámetro de verificación X509 configurado
cualquier callback de mensaje o callback de información establecido mediante SSL_set_msg_callback(3) o SSL_set_info_callback(3)
cualquier callback de contraseña predeterminado establecido mediante SSL_set_default_passwd_cb(3)
cualquier callback de generación de ID de sesión establecido mediante SSL_set_generate_session_id(3)
cualquier Lista de Cifrado configurada
estado inicial de aceptación (servidor) o conexión (cliente)
el valor max cert list establecido mediante SSL_set_max_cert_list(3)
el valor read_ahead establecido mediante SSL_set_read_ahead(3)
datos específicos de la aplicación establecidos mediante SSL_set_ex_data(3)
cualquier lista CA o lista CA de cliente establecida mediante SSL_set0_CA_list(3), SSL_set0_client_CA_list() o funciones similares
cualquier nivel de seguridad o callback configurado
cualquier dato serverinfo configurado
cualquier indicio de PSK configurado
cualquier extensión personalizada configurada
cualquier tipo de certificado de cliente configurado a través de SSL_set1_client_certificate_types

SSL_dup() no es compatible con objetos SSL QUIC y devuelve NULL si se llama en dicho objeto.

VALORES DE RETORNO

Los siguientes valores de retorno pueden ocurrir:

NULL
La creación de una nueva estructura SSL falló. Compruebe la pila de errores para averiguar el motivo.
Puntero a una estructura SSL
El valor de retorno apunta a una estructura SSL asignada.

SSL_up_ref() devuelve 1 en caso de éxito y 0 en caso de fallo.
