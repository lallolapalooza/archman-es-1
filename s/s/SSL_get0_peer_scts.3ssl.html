NOMBRE

SSL_get0_peer_scts - obtener SCTs recibidos

SINOPSIS

#include <openssl/ssl.h>
const STACK_OF(SCT) *SSL_get0_peer_scts(SSL *s);

DESCRIPCIÓN

SSL_get0_peer_scts() devuelve las marcas de tiempo de certificado firmadas (SCTs) que se han recibido. Si es la primera vez que se llama a esta función para una instancia SSL dada, examinará las extensiones TLS, la respuesta OCSP y el certificado del par en busca de SCTs. Las llamadas futuras devolverán los mismos SCTs.

RESTRICCIONES

Si no se ha establecido ninguna función de devolución de llamada de validación de Transparencia de Certificados (usando SSL_CTX_set_ct_validation_callback o SSL_set_ct_validation_callback), no se garantiza que esta función devuelva todos los SCTs que el par es capaz de enviar.

VALORES DE RETORNO

SSL_get0_peer_scts() devuelve una lista de los SCTs encontrados, o NULL si ocurre un error.

VER TAMBIÉN

ssl(7), SSL_CTX_set_ct_validation_callback(3)
