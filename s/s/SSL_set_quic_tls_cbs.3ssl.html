SSL_set_quic_tls_cbs(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_SET_QUIC_TLS_CBS(3ssl) OpenSSL SSL_SET_QUIC_TLS_CBS(3ssl)

NOMBRE

OSSL_FUNC_SSL_QUIC_TLS_crypto_send_fn, OSSL_FUNC_SSL_QUIC_TLS_crypto_recv_rcd_fn, OSSL_FUNC_SSL_QUIC_TLS_crypto_release_rcd_fn, OSSL_FUNC_SSL_QUIC_TLS_yield_secret_fn, OSSL_FUNC_SSL_QUIC_TLS_got_transport_params_fn, OSSL_FUNC_SSL_QUIC_TLS_alert_fn, SSL_set_quic_tls_cbs, SSL_set_quic_tls_transport_params, SSL_set_quic_tls_early_data_enabled - Usar la implementación TLS de OpenSSL para una implementación QUIC de terceros

SINOPSIS

#include <openssl/ssl.h>
/* Callbacks QUIC TLS disponibles a través de una tabla OSSL_DISPATCH */
/* ID de función: OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_crypto_send_fn)(SSL *s,
                                                     const unsigned char *buf,
                                                     size_t buf_len,
                                                     size_t *consumed,
                                                     void *arg);
/* ID de función: OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_crypto_recv_rcd_fn)(SSL *s,
                                                   const unsigned char **buf,
                                                   size_t *bytes_read,
                                                   void *arg);
/* ID de función: OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_crypto_release_rcd_fn)(SSL *,
                                                            size_t bytes_read,
                                                            void *arg);
/* ID de función: OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_yield_secret_fn)(SSL *s,
                                                   uint32_t prot_level,
                                                   int direction,
                                                   const unsigned char *secret,
                                                   size_t secret_len,
                                                   void *arg);
/* ID de función: OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_got_transport_params_fn)(SSL *s,
                                                   const unsigned char *params,
                                                   size_t params_len,
                                                   void *arg);
/* ID de función: OSSL_FUNC_SSL_QUIC_TLS_ALERT */
typedef int (*OSSL_FUNC_SSL_QUIC_TLS_alert_fn)(SSL *s,
                                               unsigned char alert_code,
                                               void *arg);
int SSL_set_quic_tls_cbs(SSL *s, const OSSL_DISPATCH *qtdis, void *arg);
int SSL_set_quic_tls_transport_params(SSL *s,
                                      const unsigned char *params,
                                      size_t params_len);
int SSL_set_quic_tls_early_data_enabled(SSL *s, int enabled);

DESCRIPCIÓN

SSL_set_quic_tls_cbs() se puede usar para reemplazar la capa de registro TLS estándar con una capa de registro personalizada para ser utilizada por una implementación QUIC de terceros. Para el objeto SSL dado s, se proporciona un conjunto de callbacks en una tabla OSSL_DISPATCH a través de qtdis. El parámetro arg se pasará como argumento cuando se llamen los diversos callbacks.

Una tabla OSSL_DISPATCH debe consistir en una matriz de entradas OSSL_DISPATCH donde cada entrada es un ID de función y un puntero a función. La matriz debe terminar con una entrada vacía (es decir, un ID de función 0 y un puntero de función NULL).

Llamar a la función SSL_set_quic_tls_cbs() deshabilitará la opción SSL_OP_ENABLE_MIDDLEBOX_COMPAT (si está configurada). Ver SSL_set_options(3). Además, la versión mínima del protocolo TLS se establecerá en TLS1_3_VERSION. Es un error llamar a esta función con algo que no sea un objeto SSL de conexión TLS.

La función de callback OSSL_FUNC_SSL_QUIC_TLS_crypto_send_fn (ID de función OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND) se llama cuando se deben enviar datos de trama CRYPTO al par. Los datos a enviar se proporcionan en el búfer buf, que tiene una longitud de buf_len. La función de callback puede optar por consumir menos datos de los que se proporcionaron en el búfer. En caso de finalización exitosa de la función de callback, el parámetro consumed debe completarse con la cantidad de datos que la función de callback consumió. Esto debe ser menor o igual al valor en buf_len. Los datos CRYPTO deben enviarse utilizando el nivel de cifrado de escritura más reciente establecido a través de la función de callback OSSL_FUNC_SSL_QUIC_TLS_yield_secret_fn (si se ha llamado).

La función de callback OSSL_FUNC_SSL_QUIC_TLS_crypto_recv_rcd_fn (ID de función OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD) se utiliza para recibir datos de trama CRYPTO del par. Cuando OpenSSL quiere leer datos del par, se llama a esta función de callback. La función de callback debe completar *buf con un puntero a un búfer que contenga datos CRYPTO que se hayan recibido del par. El tamaño del búfer debe completarse en *bytes_read. El búfer debe permanecer válido hasta que OpenSSL llame a la función de callback OSSL_FUNC_SSL_QUIC_TLS_crypto_release_rcd_fn. Se asume que los datos de trama CRYPTO se han descifrado utilizando el nivel de protección de lectura más reciente establecido a través de la función de callback yield_secret_cb (si se ha llamado).

La función de callback OSSL_FUNC_SSL_QUIC_TLS_crypto_release_rcd_fn (ID de función OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD) se llama cuando los datos leídos previamente a través de OSSL_FUNC_SSL_QUIC_TLS_crypto_recv_rcd_fn ya no son necesarios. El argumento bytes_read siempre es igual al tamaño del búfer proporcionado previamente en la función de callback crypto_receive_rcd_cb. OpenSSL solo leerá un registro a la vez.

La función de callback OSSL_FUNC_SSL_QUIC_TLS_yield_secret_fn (ID de función OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET) se llama cuando se ha establecido un nuevo secreto. El argumento prot_level identifica el nivel de protección TLS y será uno de OSSL_RECORD_PROTECTION_LEVEL_NONE, OSSL_RECORD_PROTECTION_LEVEL_EARLY, OSSL_RECORD_PROTECTION_LEVEL_HANDSHAKE o OSSL_RECORD_PROTECTION_LEVEL_APPLICATION. El direction será 0 (para el secreto de lectura) o 1 (para el secreto de escritura). El secreto en sí estará en el búfer apuntado por secret y el búfer tendrá una longitud de secret_len.

La función de callback OSSL_FUNC_SSL_QUIC_TLS_got_transport_params_fn (ID de función OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS) se llama cuando se han recibido parámetros de transporte del par. Los parámetros se encuentran en el búfer params, que tiene una longitud de params_len.

La función de callback OSSL_FUNC_SSL_QUIC_TLS_alert_fn (ID de función OSSL_FUNC_SSL_QUIC_TLS_ALERT) se llama cuando OpenSSL intenta enviar una alerta al par. El código de la alerta se proporciona en alert_code.

La función SSL_set_quic_tls_transport_params() se utiliza para establecer los parámetros de transporte que enviará este punto final. Los parámetros se encuentran en el búfer params, que debe tener una longitud de params_len. El búfer que contiene los parámetros debe permanecer válido hasta después de que se hayan enviado los parámetros. Esta función debe haber sido llamada en el momento en que los parámetros de transporte necesiten ser enviados. Para un cliente, esto será antes de que se inicie la conexión. Para un servidor, esto podría ocurrir típicamente durante el got_transport_params_cb.

La función SSL_set_quic_tls_early_data_enabled() se utiliza para habilitar la función 0-RTT para una implementación QUIC de terceros.

VALORES DE RETORNO

Estas funciones devuelven 1 en caso de éxito y 0 en caso de fallo.

Todas las funciones de callback también deberían devolver 1 en caso de éxito y 0 en caso de fallo. Una respuesta de fallo es fatal para la conexión.

EJEMPLOS

Una llamada a SSL_set_quic_tls_cbs() podría parecerse a la siguiente, dadas las definiciones adecuadas de las diversas funciones de callback:

const OSSL_DISPATCH qtdis[] = {
    {OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_SEND, (void (*)(void))crypto_send_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RECV_RCD,
        (void (*)(void))crypto_recv_rcd_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_CRYPTO_RELEASE_RCD,
        (void (*)(void))crypto_release_rcd_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_YIELD_SECRET,
        (void (*)(void))yield_secret_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_GOT_TRANSPORT_PARAMS,
        (void (*)(void))got_transport_params_cb},
    {OSSL_FUNC_SSL_QUIC_TLS_ALERT, (void (*)(void))alert_cb},
    {0, NULL}
 };
if (!SSL_set_quic_tls_cbs(ssl, qtdis, NULL))
    goto err;

HISTORIA

Estas funciones se añadieron en OpenSSL 3.5.
