SSL_load_client_CA_file(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_LOAD_CLIENT_CA_FILE(3ssl) OpenSSL SSL_LOAD_CLIENT_CA_FILE(3ssl)

NOMBRE

SSL_load_client_CA_file_ex, SSL_load_client_CA_file, SSL_add_file_cert_subjects_to_stack, SSL_add_dir_cert_subjects_to_stack, SSL_add_store_cert_subjects_to_stack - cargar nombres de certificados

SINOPSIS

#include <openssl/ssl.h>
STACK_OF(X509_NAME) *SSL_load_client_CA_file_ex(const char *file,
                                                OSSL_LIB_CTX *libctx,
                                                const char *propq);
STACK_OF(X509_NAME) *SSL_load_client_CA_file(const char *file);
int SSL_add_file_cert_subjects_to_stack(STACK_OF(X509_NAME) *stack,
                                        const char *file);
int SSL_add_dir_cert_subjects_to_stack(STACK_OF(X509_NAME) *stack,
                                       const char *dir);
int SSL_add_store_cert_subjects_to_stack(STACK_OF(X509_NAME) *stack,
                                         const char *store);

DESCRIPCIÓN

SSL_load_client_CA_file_ex() lee certificados del archivo y devuelve un STACK_OF(X509_NAME) con los nombres de asunto encontrados. El contexto de biblioteca libctx y la consulta de propiedades propq se utilizan al obtener algoritmos de los proveedores.

SSL_load_client_CA_file() es similar a SSL_load_client_CA_file_ex() pero utiliza NULL para el contexto de biblioteca libctx y la consulta de propiedades propq.

SSL_add_file_cert_subjects_to_stack() lee certificados del archivo y añade su nombre de asunto a la pila ya existente stack.

SSL_add_dir_cert_subjects_to_stack() lee certificados de cada archivo en el directorio dir, y añade su nombre de asunto a la pila ya existente stack.

SSL_add_store_cert_subjects_to_stack() carga certificados de la URI de almacén y añade su nombre de asunto a la pila ya existente stack.

NOTAS

SSL_load_client_CA_file() lee un archivo de certificados con formato PEM y extrae los X509_NAMES de los certificados encontrados. Aunque el nombre sugiere el uso específico como función de soporte para SSL_CTX_set_client_CA_list(3), no se limita a certificados CA.

VALORES DEVUELTOS

Los siguientes valores de retorno pueden ocurrir para SSL_load_client_CA_file_ex() y SSL_load_client_CA_file():

NULL
La operación falló, compruebe la pila de errores para conocer el motivo.
Puntero a STACK_OF(X509_NAME)
Puntero a los nombres de asunto de los certificados leídos correctamente.

Los siguientes valores de retorno pueden ocurrir para SSL_add_file_cert_subjects_to_stack(), SSL_add_dir_cert_subjects_to_stack(), y SSL_add_store_cert_subjects_to_stack():

0 (Fallo)
La operación falló.
1 (Éxito)
La operación tuvo éxito.

EJEMPLOS

Cargar nombres de CAs desde un archivo y usarlo como lista de CAs de cliente:

SSL_CTX *ctx;
STACK_OF(X509_NAME) *cert_names;
...
cert_names = SSL_load_client_CA_file("/ruta/a/CAfile.pem");
if (cert_names != NULL)
    SSL_CTX_set_client_CA_list(ctx, cert_names);
else
    /* error */
...

VER TAMBIÉN

ssl(7), ossl_store(7), SSL_CTX_set_client_CA_list(3)

HISTORIA

SSL_load_client_CA_file_ex() y SSL_add_store_cert_subjects_to_stack() se añadieron en OpenSSL 3.0.
