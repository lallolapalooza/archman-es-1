SSL_set_session_secret_cb(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_SET_SESSION_SECRET_CB(3ssl) OpenSSL SSL_SET_SESSION_SECRET_CB(3ssl)

NOMBRE

SSL_set_session_secret_cb, tls_session_secret_cb_fn - establecer el callback de secreto de sesión

SINOPSIS

#include <openssl/ssl.h>
typedef int (*tls_session_secret_cb_fn)(SSL *s, void *secret, int *secret_len,
                                        STACK_OF(SSL_CIPHER) *peer_ciphers,
                                        const SSL_CIPHER **cipher, void *arg);
int SSL_set_session_secret_cb(SSL *s,
                              tls_session_secret_cb_fn session_secret_cb,
                              void *arg);

DESCRIPCIÓN

SSL_set_session_secret_cb() establece el callback de secreto de sesión a ser utilizado (session_secret_cb), y un argumento opcional (arg) a ser pasado a ese callback cuando sea llamado. Esto solo es útil para una implementación de EAP-FAST (RFC4851). La presencia del callback también modifica la máquina de estados interna de TLS de OpenSSL para que coincida con el comportamiento TLS modificado descrito en RFC4851. Por lo tanto, este callback no debe ser utilizado excepto cuando se implemente EAP-FAST.

Se espera que el callback establezca el secreto maestro a ser utilizado llenando los datos apuntados por *secret. El tamaño del búfer de secreto está inicialmente disponible en *secret_len y puede ser actualizado por el callback (pero no debe ser mayor que el valor inicial).

En el lado del servidor, el conjunto de ciphersuites ofrecidos por el par se proporciona en la pila peer_ciphers. Opcionalmente, el callback puede seleccionar el ciphersuite preferido estableciéndolo en *cipher.

En el lado del cliente, la pila peer_ciphers siempre será NULL. El callback puede especificar el cifrado preferido en *cipher y esto se asociará con el SSL_SESSION, pero no afecta al ciphersuite seleccionado por el servidor.

El callback también recibe un argumento adicional en arg que es el argumento que se proporcionó a la llamada original de SSL_set_session_secret_cb().

VALORES DE RETORNO

SSL_set_session_secret_cb() devuelve 1 en caso de éxito y 0 en caso de fallo.

Si el callback devuelve 1, esto indica que ha establecido el secreto con éxito. Un valor de retorno de 0 indica que el secreto no ha sido establecido. En el cliente, esto provocará un aborto inmediato del handshake.

VER TAMBIÉN

ssl(7), SSL_get_session(3)
