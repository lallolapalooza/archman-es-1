SSL_CTX_set_cipher_list(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_CIPHER_LIST(3ssl) OpenSSL SSL_CTX_SET_CIPHER_LIST(3ssl)

NOMBRE

SSL_CTX_set_cipher_list, SSL_set_cipher_list, SSL_CTX_set_ciphersuites, SSL_set_ciphersuites, OSSL_default_cipher_list, OSSL_default_ciphersuites - elegir lista de SSL_CIPHERs disponibles

SINOPSIS

#include <openssl/ssl.h>
int SSL_CTX_set_cipher_list(SSL_CTX *ctx, const char *str);
int SSL_set_cipher_list(SSL *ssl, const char *str);
int SSL_CTX_set_ciphersuites(SSL_CTX *ctx, const char *str);
int SSL_set_ciphersuites(SSL *s, const char *str);
const char *OSSL_default_cipher_list(void);
const char *OSSL_default_ciphersuites(void);

DESCRIPCIÓN

SSL_CTX_set_cipher_list() establece la lista de cifrados disponibles (TLSv1.2 y anteriores) para ctx usando la cadena de control str. El formato de la cadena se describe en openssl-ciphers(1). La lista de cifrados se hereda de todos los objetos ssl creados a partir de ctx. Esta función no afecta a los suites de cifrado TLSv1.3. Usa SSL_CTX_set_ciphersuites() para configurar estos. ctx **NO DEBE** ser NULL.

SSL_set_cipher_list() establece la lista de cifrados (TLSv1.2 y anteriores) solo para ssl.

SSL_CTX_set_ciphersuites() se utiliza para configurar los suites de cifrado TLSv1.3 disponibles para ctx. Esta es una lista simple separada por dos puntos (":") de nombres de suites de cifrado TLSv1.3 en orden de preferencia. Los nombres válidos de suites de cifrado TLSv1.3 son:

TLS_AES_128_GCM_SHA256
TLS_AES_256_GCM_SHA384
TLS_CHACHA20_POLY1305_SHA256
TLS_AES_128_CCM_SHA256
TLS_AES_128_CCM_8_SHA256
TLS_SHA384_SHA384 - solo integridad
TLS_SHA256_SHA256 - solo integridad

Una lista vacía es permisible. El valor predeterminado para esta configuración es:

"TLS_AES_256_GCM_SHA384:TLS_CHACHA20_POLY1305_SHA256:TLS_AES_128_GCM_SHA256"

SSL_set_ciphersuites() es igual a SSL_CTX_set_ciphersuites() excepto que configura los suites de cifrado para ssl.

OSSL_default_cipher_list() devuelve la cadena de cifrado predeterminada para los cifrados TLSv1.2 (y anteriores). OSSL_default_ciphersuites() devuelve la cadena de cifrado predeterminada para los suites de cifrado TLSv1.3.

NOTAS

La cadena de control str para SSL_CTX_set_cipher_list(), SSL_set_cipher_list(), SSL_CTX_set_ciphersuites() y SSL_set_ciphersuites() debe ser universalmente utilizable y no depender de los detalles de la configuración de la biblioteca (cifrados compilados). Por lo tanto, no se realiza ninguna verificación de sintaxis. Los elementos que no se reconocen, porque los cifrados correspondientes no están compilados o porque están mal escritos, simplemente se ignoran. El fallo solo se marca si no se pudieron recopilar cifrados.

Cabe señalar que la inclusión de un cifrado para ser utilizado en la lista es una condición necesaria. En el lado del cliente, la inclusión en la lista también es suficiente a menos que el nivel de seguridad lo excluya. En el lado del servidor, se aplican restricciones adicionales. Todos los cifrados tienen requisitos adicionales. Los cifrados ADH no necesitan un certificado, pero se deben haber establecido parámetros DH. Todos los demás cifrados necesitan un certificado y clave correspondientes.

Un cifrado RSA solo puede elegirse cuando hay disponible un certificado RSA. Los cifrados RSA que usan DHE necesitan un certificado y clave y parámetros DH adicionales (ver SSL_CTX_set_tmp_dh_callback(3)).

Un cifrado DSA solo puede elegirse cuando hay disponible un certificado DSA. Los cifrados DSA siempre utilizan intercambio de claves DH y, por lo tanto, necesitan parámetros DH (ver SSL_CTX_set_tmp_dh_callback(3)).

Cuando estas condiciones no se cumplen para ningún cifrado en la lista (por ejemplo, un cliente solo admite cifrados RSA de exportación con una longitud de clave asimétrica de 512 bits y el servidor no está configurado para usar claves RSA temporales), se genera el error "no hay cifrado compartido" (SSL_R_NO_SHARED_CIPHER) y la negociación fallará.

OSSL_default_cipher_list() y OSSL_default_ciphersuites() reemplazan SSL_DEFAULT_CIPHER_LIST y TLS_DEFAULT_CIPHERSUITES, respectivamente. Las definiciones de listas de cifrados están obsoletas a partir de la versión 3.0.

VALORES DE RETORNO

SSL_CTX_set_cipher_list() y SSL_set_cipher_list() devuelven 1 si se pudo seleccionar algún cifrado y 0 en caso de fallo completo.

SSL_CTX_set_ciphersuites() y SSL_set_ciphersuites() devuelven 1 si la lista de suites de cifrado solicitada se configuró correctamente, y 0 en caso contrario.

VER TAMBIÉN

ssl(7), SSL_get_ciphers(3), SSL_CTX_use_certificate(3), SSL_CTX_set_tmp_dh_callback(3), openssl-ciphers(1)

HISTORIAL

OSSL_default_cipher_list() y OSSL_default_ciphersites() son nuevas en la versión 3.0.
