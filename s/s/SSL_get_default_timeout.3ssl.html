NOMBRE

SSL_get_default_timeout - obtener el valor predeterminado del tiempo de espera de la sesión

SINOPSIS

#include <openssl/ssl.h>
long SSL_get_default_timeout(const SSL *ssl);

DESCRIPCIÓN

SSL_get_default_timeout() devuelve el valor predeterminado del tiempo de espera asignado a los objetos SSL_SESSION negociados para el protocolo válido para ssl.

NOTAS

Cada vez que se negocia una nueva sesión, se le asigna un valor de tiempo de espera, después del cual no se aceptará para la reutilización de la sesión. Si el valor de tiempo de espera no se estableció explícitamente mediante SSL_CTX_set_timeout(3), se utilizará el tiempo de espera predeterminado codificado para el protocolo.

SSL_get_default_timeout() devuelve este valor codificado, que es de 300 segundos para todos los protocolos actualmente admitidos.
