SSL_CTX_set_new_pending_conn_cb(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_NEW_PENDING_CONN_CB(3ssl) OpenSSL SSL_CTX_SET_NEW_PENDING_CONN_CB(3ssl)

NOMBRE

SSL_CTX_set_new_pending_conn_cb, SSL_set_new_pending_conn_cb_fn - función de devolución de llamada para informar la creación de objetos SSL de conexión QUIC

SINOPSIS

typedef int (*SSL_set_new_pending_conn_cb_fn)(SSL_CTX *c, SSL *new_ssl,
                                              void *arg);
void SSL_CTX_set_new_pending_conn_cb(SSL_CTX *c,
                                    SSL_set_new_pending_conn_cb_fn *f,
                                    void *arg);

DESCRIPCIÓN

SSL_CTX_set_new_pending_conn_cb() establece la función de devolución de llamada new_pending_conn y el argumento de datos de aplicación asociado arg. Al usar el transporte QUIC, el procesamiento del handshake TLS puede ocurrir independientemente del hilo que acepta la conexión que el handshake está estableciendo. Como tal, los objetos SSL que representan la conexión pueden ser asignados e inicializados antes de una llamada a SSL_accept_connection(). Esta devolución de llamada registrada puede ser utilizada para decorar el objeto SSL preasignado o crear otras asociaciones con su SSL padre antes de una llamada a SSL_accept_connection().

VALORES DE RETORNO

SSL_CTX_set_new_pending_conn_cb() no devuelve ningún valor.

SSL_set_new_pending_conn_cb_fn() devuelve un valor entero. Un valor de retorno de 0 indica que la pila QUIC debe descartar este objeto SSL recién creado, lo que implica que la nueva conexión asociada no estará disponible para su manejo en una llamada posterior a SSL_accept_connection(). Un valor de retorno distinto de cero se trata como éxito, permitiendo que la nueva conexión se encole para su procesamiento.

VER TAMBIÉN

SSL_set_ex_data(3)

NOTAS

Las devoluciones de llamada en conexiones QUIC tienen algunas limitaciones que deben tenerse en cuenta al escribir una aplicación.

Las conexiones QUIC pueden comenzar el procesamiento antes de que una aplicación llame a SSL_accept_connection() en ellas. Como tal, puede ocurrir que las devoluciones de llamada se entreguen a las devoluciones de llamada TLS registradas por las aplicaciones antes de que esos objetos SSL se devuelvan en SSL_accept_connection(). Las aplicaciones deben esperar esta posibilidad.

En particular, no se deben mantener referencias a objetos SSL pasados a las devoluciones de llamada para conexiones QUIC hasta que se devuelvan a través de una llamada a SSL_accept_connection.

HISTORIA

SSL_CTX_set_new_pending_conn_cb() se agregó en OpenSSL 3.5
