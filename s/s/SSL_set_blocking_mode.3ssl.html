SSL_set_blocking_mode(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_SET_BLOCKING_MODE(3ssl) OpenSSL SSL_SET_BLOCKING_MODE(3ssl)

NOMBRE

SSL_set_blocking_mode, SSL_get_blocking_mode - configurar el modo de bloqueo para un objeto SSL QUIC

SINOPSIS

#include <openssl/ssl.h>
int SSL_set_blocking_mode(SSL *s, int blocking);
int SSL_get_blocking_mode(SSL *s);

DESCRIPCIÓN

SSL_set_blocking_mode() se puede usar para habilitar o deshabilitar el modo de bloqueo en un objeto SSL de conexión QUIC. Por defecto, el bloqueo está habilitado, a menos que el objeto SSL esté configurado para usar un BIO de lectura o escritura subyacente que no pueda proporcionar un descriptor de sondeo (ver BIO_get_rpoll_descriptor(3)), ya que el modo de bloqueo no puede ser soportado en este caso.

Para habilitar el modo de bloqueo, llame a SSL_set_blocking_mode() con blocking establecido en 1; para deshabilitarlo, llame a SSL_set_blocking_mode() con blocking establecido en 0.

Para recuperar el modo de bloqueo actual, llame a SSL_get_blocking_mode().

El modo de bloqueo significa que llamadas como SSL_read() y SSL_write() se bloquearán hasta que la operación solicitada pueda ser realizada. En modo no bloqueante, estas llamadas fallarán si la operación solicitada no puede realizarse inmediatamente; ver SSL_get_error(3).

Estas funciones solo son aplicables a objetos SSL de conexión QUIC. Otros tipos de objetos SSL, como los de TLS, funcionan automáticamente en modo de bloqueo o no bloqueo en función de si los BIOs de lectura y escritura de red subyacentes proporcionados al objeto SSL están configurados en modo no bloqueante.

Donde se utiliza un objeto SSL de conexión QUIC en modo no bloqueante, la aplicación es responsable de asegurar que el objeto SSL se tickea regularmente; ver SSL_handle_events(3).

El modo de bloqueo se deshabilita automáticamente si la aplicación proporciona a un objeto SSL de conexión QUIC un BIO de red que no puede soportar el modo de bloqueo. Para volver a habilitar el modo de bloqueo en este caso, una aplicación debe establecer un BIO de red que pueda soportar el modo de bloqueo y llamar explícitamente a SSL_set_blocking_mode().

VALORES DE RETORNO

SSL_set_blocking_mode() devuelve 1 en caso de éxito y 0 en caso de fallo. La función falla si se llama en un objeto SSL que no representa una conexión QUIC, o si el modo de bloqueo no se puede usar para la conexión dada.

SSL_get_blocking_mode() devuelve 1 si el bloqueo está actualmente habilitado. Devuelve -1 si se llama en un objeto SSL no soportado.

VER TAMBIÉN

SSL_handle_events(3), SSL_poll(3), openssl-quic(7), openssl-quic-concurrency(7), ssl(7)

HISTORIA

Las funciones SSL_set_blocking_mode() y SSL_get_blocking_mode() se añadieron en OpenSSL 3.2.
