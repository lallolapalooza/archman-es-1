SSL_CTX_set_default_passwd_cb(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_DEFAULT_PASSWD_CB(3ssl) OpenSSL SSL_CTX_SET_DEFAULT_PASSWD_CB(3ssl)

NOMBRE

SSL_CTX_set_default_passwd_cb, SSL_CTX_set_default_passwd_cb_userdata, SSL_CTX_get_default_passwd_cb, SSL_CTX_get_default_passwd_cb_userdata, SSL_set_default_passwd_cb, SSL_set_default_passwd_cb_userdata, SSL_get_default_passwd_cb, SSL_get_default_passwd_cb_userdata - establecer u obtener el callback de contraseña para el manejo de archivos PEM cifrados

SINOPSIS

#include <openssl/ssl.h>
void SSL_CTX_set_default_passwd_cb(SSL_CTX *ctx, pem_password_cb *cb);
void SSL_CTX_set_default_passwd_cb_userdata(SSL_CTX *ctx, void *u);
pem_password_cb *SSL_CTX_get_default_passwd_cb(SSL_CTX *ctx);
void *SSL_CTX_get_default_passwd_cb_userdata(SSL_CTX *ctx);
void SSL_set_default_passwd_cb(SSL *s, pem_password_cb *cb);
void SSL_set_default_passwd_cb_userdata(SSL *s, void *u);
pem_password_cb *SSL_get_default_passwd_cb(SSL *s);
void *SSL_get_default_passwd_cb_userdata(SSL *s);

DESCRIPCIÓN

SSL_CTX_set_default_passwd_cb() establece el callback de contraseña predeterminado que se llama al cargar/almacenar un certificado PEM con cifrado.

SSL_CTX_set_default_passwd_cb_userdata() establece un puntero a datos de usuario, u, que se proporcionará al callback de contraseña al invocarse.

SSL_CTX_get_default_passwd_cb() devuelve un puntero de función al callback de contraseña que está configurado actualmente en ctx. Si no se estableció explícitamente ningún callback, se devuelve el puntero NULL.

SSL_CTX_get_default_passwd_cb_userdata() devuelve un puntero a los datos de usuario actualmente configurados en ctx. Si no se establecieron explícitamente datos de usuario, se devuelve el puntero NULL.

SSL_set_default_passwd_cb(), SSL_set_default_passwd_cb_userdata(), SSL_get_default_passwd_cb() y SSL_get_default_passwd_cb_userdata() realizan la misma función que sus homólogos de SSL_CTX, pero utilizando un objeto SSL.

El callback de contraseña, que debe ser proporcionado por la aplicación, devuelve la contraseña a utilizar durante el descifrado. Al invocarse se proporciona un puntero a los datos de usuario. La función debe almacenar la contraseña en el búfer proporcionado buf, que tiene un tamaño de size. La longitud real de la contraseña debe devolverse a la función que llama. rwflag indica si el callback se utiliza para lectura/descifrado (rwflag=0) o escritura/cifrado (rwflag=1). Para más detalles, véase pem_password_cb(3).

NOTAS

Al cargar o almacenar claves privadas, se puede proporcionar una contraseña para proteger la clave privada. La forma en que se puede proporcionar esta contraseña puede depender de la aplicación. Si solo se maneja una clave privada, puede ser práctico que el callback maneje el diálogo de contraseña de forma interactiva. Si se deben manejar varias claves, puede ser práctico pedir la contraseña una vez, luego mantenerla en memoria y usarla varias veces. En este último caso, la contraseña podría almacenarse en el almacenamiento de datos de usuario y el callback solo devolvería la contraseña ya almacenada.

Al solicitar la contraseña de forma interactiva, el callback puede utilizar rwflag para comprobar si un elemento debe cifrarse (rwflag=1). En este caso, el diálogo de contraseña puede solicitar la misma contraseña dos veces para comparación, a fin de detectar errores tipográficos que harían imposible el descifrado.

Otros elementos en formato PEM (certificados) también pueden cifrarse, aunque no es habitual, ya que la información del certificado se considera pública.

VALORES DE RETORNO

Estas funciones no proporcionan información diagnóstica.

EJEMPLOS

El siguiente ejemplo devuelve la contraseña proporcionada como datos de usuario a la función que llama. Se considera que la contraseña es una cadena terminada en '\0'. Si la contraseña no cabe en el búfer, se trunca.

int my_cb(char *buf, int size, int rwflag, void *u)
{
    strncpy(buf, (char *)u, size);
    buf[size - 1] = '\0';
    return strlen(buf);
}
