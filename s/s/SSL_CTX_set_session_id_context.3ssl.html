SSL_CTX_set_session_id_context(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_SESSION_ID_CONTEXT(3ssl) OpenSSL SSL_CTX_SET_SESSION_ID_CONTEXT(3ssl)

NOMBRE

SSL_CTX_set_session_id_context, SSL_set_session_id_context - establecer el contexto dentro del cual se puede reutilizar una sesión (solo lado del servidor)

SINOPSIS

#include <openssl/ssl.h>
int SSL_CTX_set_session_id_context(SSL_CTX *ctx, const unsigned char *sid_ctx,
                                   unsigned int sid_ctx_len);
int SSL_set_session_id_context(SSL *ssl, const unsigned char *sid_ctx,
                               unsigned int sid_ctx_len);

DESCRIPCIÓN

SSL_CTX_set_session_id_context() establece el contexto sid_ctx de longitud sid_ctx_len dentro del cual una sesión puede ser reutilizada para el objeto ctx.

SSL_set_session_id_context() establece el contexto sid_ctx de longitud sid_ctx_len dentro del cual una sesión puede ser reutilizada para el objeto ssl.

NOTAS

Las sesiones se generan dentro de un cierto contexto. Al exportar/importar sesiones con i2d_SSL_SESSION/d2i_SSL_SESSION sería posible reimportar una sesión generada desde otro contexto (por ejemplo, otra aplicación), lo que podría provocar malfuncionamientos. Por lo tanto, cada aplicación debe establecer su propio contexto de ID de sesión sid_ctx que se utiliza para distinguir los contextos y se almacena en las sesiones exportadas. El sid_ctx puede ser cualquier tipo de dato binario con una longitud determinada; por lo tanto, es posible usar, por ejemplo, el nombre de la aplicación y/o el nombre del host y/o el nombre del servicio...

El contexto del ID de sesión forma parte de la sesión. El contexto del ID de sesión es establecido por el servidor SSL/TLS. Las funciones SSL_CTX_set_session_id_context() y SSL_set_session_id_context(), por lo tanto, solo son útiles en el lado del servidor.

Los clientes de OpenSSL verificarán el contexto del ID de sesión devuelto por el servidor al reutilizar una sesión.

La longitud máxima del sid_ctx está limitada a SSL_MAX_SID_CTX_LENGTH.

ADVERTENCIAS

Si el contexto del ID de sesión no está establecido en un servidor SSL/TLS y se utilizan certificados de cliente, las sesiones almacenadas no se reutilizarán, pero se marcará un error fatal y el handshake fallará.

Si un servidor devuelve un contexto de ID de sesión diferente a un cliente de OpenSSL al reutilizar una sesión, se marcará un error y el handshake fallará. Los servidores de OpenSSL siempre devolverán el contexto de ID de sesión correcto, ya que un servidor de OpenSSL verifica el contexto del ID de sesión en sí mismo antes de reutilizar una sesión, como se describe anteriormente.

VALORES DE RETORNO

SSL_CTX_set_session_id_context() y SSL_set_session_id_context() devuelven los siguientes valores:

0
La longitud sid_ctx_len del contexto del ID de sesión sid_ctx excedió la longitud máxima permitida de SSL_MAX_SID_CTX_LENGTH. El error se registra en la pila de errores.
1
La operación se realizó correctamente.
