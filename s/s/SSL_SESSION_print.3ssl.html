SSL_SESSION_print(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_SESSION_PRINT(3ssl) OpenSSL SSL_SESSION_PRINT(3ssl)

NOMBRE

SSL_SESSION_print, SSL_SESSION_print_fp, SSL_SESSION_print_keylog - imprime información sobre una sesión

SINOPSIS

#include <openssl/ssl.h>
int SSL_SESSION_print(BIO *fp, const SSL_SESSION *ses);
int SSL_SESSION_print_fp(FILE *fp, const SSL_SESSION *ses);
int SSL_SESSION_print_keylog(BIO *bp, const SSL_SESSION *x);

DESCRIPCIÓN

SSL_SESSION_print() imprime información resumida sobre la sesión proporcionada en ses al BIO fp.

SSL_SESSION_print_fp() hace lo mismo que SSL_SESSION_print() excepto que lo imprime al FILE fp.

SSL_SESSION_print_keylog() imprime información de la sesión al BIO proporcionado <bp> en formato de registro de claves NSS.

VALORES DEVUELTOS

SSL_SESSION_print(), SSL_SESSION_print_fp() y SSL_SESSION_print_keylog devuelven 1 en caso de éxito o 0 en caso de error.
