SSL_CTX_set_timeout(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_TIMEOUT(3ssl) OpenSSL SSL_CTX_SET_TIMEOUT(3ssl)

NOMBRE

SSL_CTX_set_timeout, SSL_CTX_get_timeout - manipular valores de tiempo de espera para el almacenamiento en caché de sesiones

SINOPSIS

#include <openssl/ssl.h>
long SSL_CTX_set_timeout(SSL_CTX *ctx, long t);
long SSL_CTX_get_timeout(SSL_CTX *ctx);

DESCRIPCIÓN

SSL_CTX_set_timeout() establece el tiempo de espera para las sesiones recién creadas para ctx a t. El valor de tiempo de espera t debe proporcionarse en segundos.

SSL_CTX_get_timeout() devuelve el valor de tiempo de espera actualmente establecido para ctx.

NOTAS

Cada vez que se crea una nueva sesión, se le asigna una vida útil máxima. Esta vida útil se especifica almacenando la hora de creación de la sesión y el valor de tiempo de espera válido en ese momento. Si la hora real es posterior a la hora de creación más el tiempo de espera, la sesión no se reutiliza.

Debido a esta implementación, todas las sesiones se comportan de acuerdo con el valor de tiempo de espera válido en el momento de la negociación de la sesión. Los cambios en el valor de tiempo de espera no afectan a las sesiones ya establecidas.

La hora de expiración de una sesión individual se puede modificar utilizando la familia de funciones SSL_SESSION_get_time(3).

Las sesiones expiradas se eliminan de la caché de sesiones interna cada vez que se llama a SSL_CTX_flush_sessions(3), ya sea directamente por la aplicación o automáticamente (ver SSL_CTX_set_session_cache_mode(3))

El valor predeterminado para el tiempo de espera de la sesión se decide por protocolo, consulte SSL_get_default_timeout(3). Todos los protocolos actualmente compatibles tienen el mismo valor de tiempo de espera predeterminado de 300 segundos.

Este valor de tiempo de espera se utiliza como indicación de la vida útil del ticket para tickets de sesión sin estado. También se utiliza como valor de tiempo de espera dentro del ticket.

Para TLSv1.3, RFC8446 limita la transmisión de este valor a 1 semana (604800 segundos).

Para TLSv1.2, los tickets generados durante un handshake inicial utilizan el valor especificado. Los tickets generados durante un handshake de reanudación tienen un valor de 0 para la indicación de vida útil del ticket.

VALORES DE RETORNO

SSL_CTX_set_timeout() devuelve el valor de tiempo de espera previamente establecido.

SSL_CTX_get_timeout() devuelve el valor de tiempo de espera actualmente establecido.

VER TAMBIÉN

ssl(7), SSL_CTX_set_session_cache_mode(3), SSL_SESSION_get_time(3), SSL_CTX_flush_sessions(3), SSL_get_default_timeout(3)
