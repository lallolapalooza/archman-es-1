SSL_CONF_CTX_set_flags(3ssl)

SSL_CONF_CTX_SET_FLAGS(3ssl) OpenSSL SSL_CONF_CTX_SET_FLAGS(3ssl)

NOMBRE

SSL_CONF_CTX_set_flags, SSL_CONF_CTX_clear_flags - Establecer o borrar banderas de contexto de configuración SSL

SINOPSIS

#include <openssl/ssl.h>
unsigned int SSL_CONF_CTX_set_flags(SSL_CONF_CTX *cctx, unsigned int flags);
unsigned int SSL_CONF_CTX_clear_flags(SSL_CONF_CTX *cctx, unsigned int flags);

DESCRIPCIÓN

La función SSL_CONF_CTX_set_flags() establece flags en el contexto cctx.

La función SSL_CONF_CTX_clear_flags() borra flags en el contexto cctx.

NOTAS

Las banderas establecidas afectan el comportamiento de las llamadas posteriores a SSL_CONF_cmd() o SSL_CONF_argv().

Actualmente se reconocen los siguientes valores de flags:

SSL_CONF_FLAG_CMDLINE, SSL_CONF_FLAG_FILE
reconocer opciones destinadas al uso en línea de comandos o archivos de configuración. Debe establecerse al menos una de estas banderas.
SSL_CONF_FLAG_CLIENT, SSL_CONF_FLAG_SERVER
reconocer opciones destinadas al uso en clientes o servidores SSL/TLS. Debe establecerse una o ambas de estas banderas.
SSL_CONF_FLAG_CERTIFICATE
reconocer opciones de certificado y clave privada.
SSL_CONF_FLAG_REQUIRE_PRIVATE
Si se establece esta opción, entonces si no se especifica una clave privada para un certificado, intentará cargar una clave privada desde el archivo del certificado cuando se llame a SSL_CONF_CTX_finish(). Si no se puede cargar una clave desde el archivo del certificado, se produce un error.
SSL_CONF_FLAG_SHOW_ERRORS
indicar errores relacionados con opciones no reconocidas o argumentos faltantes en la cola de errores. Si no se establece esta opción, tales errores solo se reflejan en los valores de retorno de SSL_CONF_set_cmd() o SSL_CONF_set_argv().

VALORES DE RETORNO

SSL_CONF_CTX_set_flags() y SSL_CONF_CTX_clear_flags() devuelven el nuevo valor de las banderas después de establecer o borrar las banderas.

VER TAMBIÉN

ssl(7), SSL_CONF_CTX_new(3), SSL_CONF_CTX_set_ssl_ctx(3), SSL_CONF_CTX_set1_prefix(3), SSL_CONF_cmd(3), SSL_CONF_cmd_argv(3)

HISTORIA

Estas funciones se añadieron en OpenSSL 1.0.2.
