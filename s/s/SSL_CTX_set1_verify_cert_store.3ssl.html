SSL_CTX_set1_verify_cert_store(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET1_VERIFY_CERT_STORE(3ssl) OpenSSL SSL_CTX_SET1_VERIFY_CERT_STORE(3ssl)

NOMBRE

SSL_CTX_set0_verify_cert_store, SSL_CTX_set1_verify_cert_store, SSL_CTX_set0_chain_cert_store, SSL_CTX_set1_chain_cert_store, SSL_set0_verify_cert_store, SSL_set1_verify_cert_store, SSL_set0_chain_cert_store, SSL_set1_chain_cert_store, SSL_CTX_get0_verify_cert_store, SSL_CTX_get0_chain_cert_store, SSL_get0_verify_cert_store, SSL_get0_chain_cert_store - establecer la tienda de certificados de verificación o de cadena

SINOPSIS

#include <openssl/ssl.h>
int SSL_CTX_set0_verify_cert_store(SSL_CTX *ctx, X509_STORE *st);
int SSL_CTX_set1_verify_cert_store(SSL_CTX *ctx, X509_STORE *st);
int SSL_CTX_set0_chain_cert_store(SSL_CTX *ctx, X509_STORE *st);
int SSL_CTX_set1_chain_cert_store(SSL_CTX *ctx, X509_STORE *st);
int SSL_CTX_get0_verify_cert_store(SSL_CTX *ctx, X509_STORE **st);
int SSL_CTX_get0_chain_cert_store(SSL_CTX *ctx, X509_STORE **st);
int SSL_set0_verify_cert_store(SSL *ctx, X509_STORE *st);
int SSL_set1_verify_cert_store(SSL *ctx, X509_STORE *st);
int SSL_set0_chain_cert_store(SSL *ctx, X509_STORE *st);
int SSL_set1_chain_cert_store(SSL *ctx, X509_STORE *st);
int SSL_get0_verify_cert_store(SSL *ctx, X509_STORE **st);
int SSL_get0_chain_cert_store(SSL *ctx, X509_STORE **st);

DESCRIPCIÓN

SSL_CTX_set0_verify_cert_store() y SSL_CTX_set1_verify_cert_store() establecen la tienda de certificados utilizada para la verificación de certificados a st.

SSL_CTX_set0_chain_cert_store() y SSL_CTX_set1_chain_cert_store() establecen la tienda de certificados utilizada para la construcción de la cadena de certificados a st.

SSL_set0_verify_cert_store(), SSL_set1_verify_cert_store(), SSL_set0_chain_cert_store() y SSL_set1_chain_cert_store() son similares excepto en que se aplican a la estructura SSL ssl.

SSL_CTX_get0_verify_chain_store(), SSL_get0_verify_chain_store(), SSL_CTX_get0_chain_cert_store() y SSL_get0_chain_cert_store() recuperan los objetos previamente establecidos mediante las llamadas anteriores. Se escribe un puntero al objeto (o NULL si no se ha establecido ningún objeto de este tipo) en *st.

Todas estas funciones se implementan como macros. Aquellas que contienen un 1 incrementan el contador de referencias de la tienda suministrada, por lo que debe liberarse en algún momento después de la operación. Aquellas que contienen un 0 no incrementan los contadores de referencias y la tienda suministrada NO DEBE liberarse después de la operación.

NOTAS

Los punteros de tienda asociados a una estructura SSL_CTX se copian en cualquier estructura SSL cuando se llama a SSL_new(). Como resultado, las estructuras SSL no se verán afectadas si el puntero de tienda SSL_CTX padre se establece en un nuevo valor.

La tienda de verificación se utiliza para verificar la cadena de certificados enviada por el par: es decir, un cliente SSL/TLS utilizará la tienda de verificación para verificar la cadena de certificados del servidor y un servidor SSL/TLS la utilizará para verificar cualquier cadena de certificados del cliente.

La tienda de cadena se utiliza para construir la cadena de certificados. Los detalles del proceso de construcción y verificación de la cadena se describen en "Construcción de la ruta de certificación" en openssl-verification-options(1) y "Validación de la ruta de certificación" en openssl-verification-options(1).

Si se establece el modo SSL_MODE_NO_AUTO_CHAIN o si ya se ha configurado una cadena de certificados (por ejemplo, utilizando funciones como SSL_CTX_add1_chain_cert(3) o SSL_CTX_add_extra_chain_cert(3)), la construcción automática de la cadena se deshabilita.

Si se establece el modo SSL_MODE_NO_AUTO_CHAIN, la construcción automática de la cadena se deshabilita.

Si no se establece la tienda de cadena o de verificación, se utilizará en su lugar la tienda asociada a la SSL_CTX padre para mantener la compatibilidad con versiones anteriores de OpenSSL.

VALORES DE RETORNO

Todas estas funciones devuelven 1 en caso de éxito y 0 en caso de fallo.
