SSL_CTX_use_serverinfo(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_USE_SERVERINFO(3ssl) OpenSSL SSL_CTX_USE_SERVERINFO(3ssl)

NOMBRE

SSL_CTX_use_serverinfo_ex, SSL_CTX_use_serverinfo, SSL_CTX_use_serverinfo_file - usar la extensión serverinfo

SINOPSIS

#include <openssl/ssl.h>
int SSL_CTX_use_serverinfo_ex(SSL_CTX *ctx, unsigned int version,
                              const unsigned char *serverinfo,
                              size_t serverinfo_length);
int SSL_CTX_use_serverinfo(SSL_CTX *ctx, const unsigned char *serverinfo,
                           size_t serverinfo_length);
int SSL_CTX_use_serverinfo_file(SSL_CTX *ctx, const char *file);

DESCRIPCIÓN

Estas funciones cargan extensiones TLS de "serverinfo" en el SSL_CTX. Una extensión "serverinfo" se devuelve en respuesta a un ClientHello Extension vacío.

SSL_CTX_use_serverinfo_ex() carga una o más extensiones serverinfo desde un array de bytes en ctx. El parámetro version especifica el formato del array de bytes proporcionado en *serverinfo que tiene una longitud de serverinfo_length.

Si version es SSL_SERVERINFOV2, entonces las extensiones en el array deben consistir en un contexto de 4 bytes, un tipo de extensión de 2 bytes, una longitud de 2 bytes y luego bytes de longitud de datos de extensión. Los valores de contexto y tipo tienen el mismo significado que para SSL_CTX_add_custom_ext(3). Si se está cargando serverinfo para extensiones que se añadirán a un mensaje de Certificado, entonces la extensión solo se añadirá para el primer certificado del mensaje (que es siempre el certificado de la entidad final).

Si version es SSL_SERVERINFOV1, entonces las extensiones en el array deben consistir en un tipo de extensión de 2 bytes, una longitud de 2 bytes y luego bytes de longitud de datos de extensión. El valor del tipo tiene el mismo significado que para SSL_CTX_add_custom_ext(3). El siguiente valor de contexto predeterminado se usará en este caso:

SSL_EXT_TLS_1_2_AND_BELOW_ONLY | SSL_EXT_CLIENT_HELLO
| SSL_EXT_TLS_1_2_SERVER_HELLO | SSL_EXT_IGNORE_ON_RESUMPTION

SSL_CTX_use_serverinfo() hace lo mismo que SSL_CTX_use_serverinfo_ex(), excepto que no hay parámetro version, por lo que se utiliza una versión predeterminada de SSL_SERVERINFOV1 en su lugar.

SSL_CTX_use_serverinfo_file() carga una o más extensiones serverinfo desde file en ctx. Las extensiones deben estar en formato PEM. Cada extensión debe estar en un formato como se describe anteriormente para SSL_CTX_use_serverinfo_ex(). Cada nombre de extensión PEM debe comenzar con la frase "BEGIN SERVERINFOV2 FOR " para datos SSL_SERVERINFOV2 o "BEGIN SERVERINFO FOR " para datos SSL_SERVERINFOV1.

Si se instala más de un certificado (RSA/DSA) usando SSL_CTX_use_certificate(), la extensión serverinfo se cargará en el último certificado instalado. Si, por ejemplo, el último elemento fue un certificado RSA, los datos de la extensión serverinfo cargados se cargarán para ese certificado. Para usar la extensión serverinfo para varios certificados, se debe llamar a SSL_CTX_use_serverinfo() varias veces, una vez **después** de cada carga de certificado a través de una llamada a SSL_CTX_use_certificate().

VALORES DE RETORNO

En caso de éxito, las funciones devuelven 1. En caso de fallo, las funciones devuelven 0. Consulta la pila de errores para averiguar el motivo.
