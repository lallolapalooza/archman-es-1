SSL_get_version(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_VERSION(3ssl) OpenSSL SSL_GET_VERSION(3ssl)

NOMBRE

SSL_client_version, SSL_get_version, SSL_is_dtls, SSL_is_tls, SSL_is_quic, SSL_version - obtener la información del protocolo de una conexión

SINOPSIS

#include <openssl/ssl.h>
int SSL_client_version(const SSL *s);
const char *SSL_get_version(const SSL *ssl);
int SSL_is_dtls(const SSL *ssl);
int SSL_is_tls(const SSL *ssl);
int SSL_is_quic(const SSL *ssl);
int SSL_version(const SSL *s);

DESCRIPCIÓN

Para los protocolos SSL, TLS y DTLS, SSL_client_version() devuelve la versión numérica del protocolo anunciada por el cliente en el campo legacy_version del ClientHello al iniciar la conexión. Tenga en cuenta que, para TLS, este valor nunca indicará una versión superior a TLSv1.2, incluso si posteriormente se negocia TLSv1.3. Para conexiones QUIC, devuelve OSSL_QUIC1_VERSION.

SSL_get_version() devuelve el nombre del protocolo utilizado para la conexión. SSL_version() devuelve la versión numérica del protocolo utilizada para la conexión. Solo deben llamarse después de que se haya completado el handshake inicial. Antes de eso, los resultados devueltos por estas funciones pueden no ser fiables.

SSL_is_dtls() devuelve 1 si la conexión está utilizando DTLS o 0 si no.

SSL_is_tls() devuelve 1 si la conexión está utilizando SSL/TLS o 0 si no.

SSL_is_quic() devuelve 1 si la conexión está utilizando QUIC o 0 si no.

VALORES DE RETORNO

SSL_get_version() devuelve una de las siguientes cadenas:

SSLv3
La conexión utiliza el protocolo SSLv3.
TLSv1
La conexión utiliza el protocolo TLSv1.0.
TLSv1.1
La conexión utiliza el protocolo TLSv1.1.
TLSv1.2
La conexión utiliza el protocolo TLSv1.2.
TLSv1.3
La conexión utiliza el protocolo TLSv1.3.
DTLSv0.9
La conexión utiliza un protocolo DTLS obsoleto pre-estandarización.
DTLSv1
La conexión utiliza el protocolo DTLSv1.
DTLSv1.2
La conexión utiliza el protocolo DTLSv1.2.
QUICv1
La conexión utiliza el protocolo QUICv1.
desconocido
Esto indica una versión de protocolo desconocida.

SSL_version() y SSL_client_version() devuelven un entero que podría incluir cualquiera de los siguientes:

SSL3_VERSION
La conexión utiliza el protocolo SSLv3.
TLS1_VERSION
La conexión utiliza el protocolo TLSv1.0.
TLS1_1_VERSION
La conexión utiliza el protocolo TLSv1.1.
TLS1_2_VERSION
La conexión utiliza el protocolo TLSv1.2.
TLS1_3_VERSION
La conexión utiliza el protocolo TLSv1.3 (nunca devuelto para SSL_client_version()).
DTLS1_BAD_VER
La conexión utiliza un protocolo DTLS obsoleto pre-estandarización.
DTLS1_VERSION
La conexión utiliza el protocolo DTLSv1.
DTLS1_2_VERSION
La conexión utiliza el protocolo DTLSv1.2.
OSSL_QUIC1_VERSION
La conexión utiliza el protocolo QUICv1.

VER TAMBIÉN

ssl(7)

HISTORIA

La función SSL_is_dtls() se añadió en OpenSSL 1.1.0. Las funciones SSL_is_tls() y SSL_is_quic() se añadieron en OpenSSL 3.2.
