NOMBRE

SSL_CONF_CTX_set1_prefix - Establece el prefijo de comando del contexto de configuración

SINOPSIS

#include <openssl/ssl.h>
unsigned int SSL_CONF_CTX_set1_prefix(SSL_CONF_CTX *cctx, const char *prefix);

DESCRIPCIÓN

La función SSL_CONF_CTX_set1_prefix() establece el prefijo de comando de cctx a prefix. Si prefix es NULL, se restaura al valor predeterminado.

NOTAS

Los prefijos de comando alteran los comandos reconocidos por las llamadas posteriores a SSL_CONF_cmd(). Por ejemplo, para archivos, si se establece el prefijo "SSL", entonces se reconocen nombres de comando como "SSLProtocol", "SSLOptions", etc., en lugar de "Protocol" y "Options". De manera similar, para líneas de comando, si el prefijo es "--ssl-", entonces se reconoce "--ssl-no_tls1_2" en lugar de "-no_tls1_2".

Si se establece la bandera SSL_CONF_FLAG_CMDLINE, las comprobaciones de prefijos distinguen entre mayúsculas y minúsculas y "-" es el valor predeterminado. En el improbable caso de que una aplicación quiera explícitamente establecer ningún prefijo, debe establecerse explícitamente a "".

Si se establece la bandera SSL_CONF_FLAG_FILE, las comprobaciones de prefijos no distinguen entre mayúsculas y minúsculas y ningún prefijo es el valor predeterminado.

VALORES DE RETORNO

SSL_CONF_CTX_set1_prefix() devuelve 1 en caso de éxito y 0 en caso de fallo.

VER TAMBIÉN

ssl(7), SSL_CONF_CTX_new(3), SSL_CONF_CTX_set_flags(3), SSL_CONF_CTX_set_ssl_ctx(3), SSL_CONF_cmd(3), SSL_CONF_cmd_argv(3)
