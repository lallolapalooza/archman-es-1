SSL_CTX_set_record_padding_callback(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET_RECORD_PADDING_CALLBACK(3ssl) OpenSSL SSL_CTX_SET_RECORD_PADDING_CALLBACK(3ssl)

NOMBRE

SSL_CTX_set_record_padding_callback, SSL_set_record_padding_callback, SSL_CTX_set_record_padding_callback_arg, SSL_set_record_padding_callback_arg, SSL_CTX_get_record_padding_callback_arg, SSL_get_record_padding_callback_arg, SSL_CTX_set_block_padding, SSL_CTX_set_block_padding_ex, SSL_set_block_padding, SSL_set_block_padding_ex - instalar una devolución de llamada para especificar el relleno de registros TLS 1.3

SINOPSIS

#include <openssl/ssl.h>
void SSL_CTX_set_record_padding_callback(SSL_CTX *ctx, size_t (*cb)(SSL *s, int type, size_t len, void *arg));
int SSL_set_record_padding_callback(SSL *ssl, size_t (*cb)(SSL *s, int type, size_t len, void *arg));
void SSL_CTX_set_record_padding_callback_arg(SSL_CTX *ctx, void *arg);
void *SSL_CTX_get_record_padding_callback_arg(const SSL_CTX *ctx);
void SSL_set_record_padding_callback_arg(SSL *ssl, void *arg);
void *SSL_get_record_padding_callback_arg(const SSL *ssl);
int SSL_CTX_set_block_padding(SSL_CTX *ctx, size_t block_size);
int SSL_set_block_padding(SSL *ssl, size_t block_size);
int SSL_CTX_set_block_padding_ex(SSL_CTX *ctx, size_t app_block_size, size_t hs_block_size);
int SSL_set_block_padding_ex(SSL *ssl, size_t app_block_size, size_t hs_block_size);

DESCRIPCIÓN

SSL_CTX_set_record_padding_callback() o SSL_set_record_padding_callback() se pueden utilizar para asignar una función de devolución de llamada cb para especificar el relleno de registros TLS 1.3. El valor establecido en ctx se copia a un nuevo SSL mediante SSL_new(). El TLS del kernel no es posible si se establece la devolución de llamada de relleno de registros, y la función de devolución de llamada no se puede establecer si el TLS del kernel ya está configurado para el objeto SSL actual.

SSL_CTX_set_record_padding_callback_arg() y SSL_set_record_padding_callback_arg() asignan un valor arg que se pasa a la devolución de llamada cuando se invoca. El valor establecido en ctx se copia a un nuevo SSL mediante SSL_new().

SSL_CTX_get_record_padding_callback_arg() y SSL_get_record_padding_callback_arg() recuperan el valor arg que se pasa a la devolución de llamada.

SSL_CTX_set_block_padding() y SSL_set_block_padding() rellenan el registro a un múltiplo del tamaño de bloque block_size. Un tamaño de bloque block_size de 0 o 1 deshabilita el relleno de bloque. El límite de block_size es SSL3_RT_MAX_PLAIN_LENGTH.

SSL_CTX_set_block_padding_ex() y SSL_set_block_padding_ex() hacen lo mismo pero permiten al llamador especificar por separado el tamaño del bloque de relleno que se aplicará a los mensajes de saludo y de datos de aplicación.

La devolución de llamada se invoca para cada registro antes de la cifrado. El parámetro type es el tipo de registro TLS que se está procesando; puede ser uno de SSL3_RT_APPLICATION_DATA, SSL3_RT_HANDSHAKE o SSL3_RT_ALERT. El parámetro len es la longitud actual del texto plano del registro antes del cifrado. El parámetro arg es el valor establecido a través de SSL_CTX_set_record_padding_callback_arg() o SSL_set_record_padding_callback_arg().

Estas funciones no se pueden utilizar con objetos SSL QUIC. SSL_set_record_padding_callback() y SSL_set_block_padding() fallan si se llaman en un objeto SSL QUIC.

VALORES DE RETORNO

Las funciones SSL_CTX_get_record_padding_callback_arg() y SSL_get_record_padding_callback_arg() devuelven el valor arg asignado en las funciones set correspondientes.

Las funciones SSL_CTX_set_block_padding() y SSL_set_block_padding() devuelven 1 en caso de éxito o 0 si block_size es demasiado grande.

La devolución de llamada cb devuelve el número de bytes de relleno que se añadirán al registro. Un valor de retorno de 0 indica que no se añadirá ningún relleno. Un valor de retorno que haga que el registro exceda el tamaño máximo del registro (SSL3_RT_MAX_PLAIN_LENGTH) rellenará hasta el tamaño máximo del registro.

La función SSL_CTX_get_record_padding_callback_arg() devuelve 1 en caso de éxito o 0 si la función de devolución de llamada no está configurada porque el TLS del kernel está configurado para el objeto SSL.

NOTAS

El comportamiento predeterminado es no añadir relleno al registro.

Una función de devolución de llamada de relleno proporcionada por el usuario anulará el comportamiento establecido por SSL_set_block_padding() o SSL_CTX_set_block_padding(). Establecer la devolución de llamada proporcionada por el usuario en NULL restaurará el comportamiento de relleno de bloque configurado.

Estas funciones solo se aplican a los registros TLS 1.3 que se están escribiendo.

Los bytes de relleno no se añaden en tiempo constante.

VER TAMBIÉN

ssl(7), SSL_new(3)

HISTORIA

La API de relleno de registros se añadió para el soporte de TLS 1.3 en OpenSSL 1.1.1.

El tipo de retorno de la función SSL_CTX_set_record_padding_callback() se cambió a int en OpenSSL 3.0.

Las funciones SSL_set_block_padding_ex() y SSL_CTX_set_block_padding_ex() se añadieron en OpenSSL 3.4.
