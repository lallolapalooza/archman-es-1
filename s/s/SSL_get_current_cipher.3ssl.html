SSL_get_current_cipher(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_CURRENT_CIPHER(3ssl) OpenSSL SSL_GET_CURRENT_CIPHER(3ssl)

NOMBRE

SSL_get_current_cipher, SSL_get_cipher_name, SSL_get_cipher, SSL_get_cipher_bits, SSL_get_cipher_version, SSL_get_pending_cipher - obtener el SSL_CIPHER de una conexión

SINOPSIS

#include <openssl/ssl.h>
const SSL_CIPHER *SSL_get_current_cipher(const SSL *ssl);
const SSL_CIPHER *SSL_get_pending_cipher(const SSL *ssl);
const char *SSL_get_cipher_name(const SSL *s);
const char *SSL_get_cipher(const SSL *s);
int SSL_get_cipher_bits(const SSL *s, int *np);
const char *SSL_get_cipher_version(const SSL *s);

DESCRIPCIÓN

SSL_get_current_cipher() devuelve un puntero a un objeto SSL_CIPHER que contiene la descripción del cifrado actualmente utilizado de una conexión establecida con el objeto ssl. ssl NO DEBE ser NULL. Ver SSL_CIPHER_get_name(3) para más detalles.

SSL_get_cipher_name() obtiene el nombre del cifrado actualmente en uso. SSL_get_cipher() es idéntico a SSL_get_cipher_name(). SSL_get_cipher_bits() es una macro para obtener el número de bits secretos/de algoritmo utilizados y SSL_get_cipher_version() devuelve el nombre del protocolo.

SSL_get_pending_cipher() devuelve un puntero a un objeto SSL_CIPHER que contiene la descripción del cifrado (si lo hay) que se ha negociado para su uso futuro en la conexión establecida con el objeto ssl, pero que aún no está en uso. Esto puede ocurrir durante el procesamiento del handshake, cuando el flujo de control se puede devolver a la aplicación a través de varios métodos de callback. La secuencia interna de procesamiento del handshake y la invocación de los callbacks no está garantizada que sea estable de una versión a otra, y actualmente solo se garantiza que el callback establecido por SSL_CTX_set_alpn_select_cb() tenga un valor de retorno no NULL. Pueden añadirse otros callbacks a esta lista con el tiempo.

VALORES DE RETORNO

SSL_get_current_cipher() devuelve el cifrado realmente utilizado, o NULL si no se ha establecido ninguna sesión.

SSL_get_pending_cipher() devuelve el cifrado que se utilizará en el próximo cambio de suite de cifrado, o NULL si no se conoce dicho cifrado.

NOTAS

SSL_get_cipher, SSL_get_cipher_bits, SSL_get_cipher_version y SSL_get_cipher_name están implementados como macros.

VER TAMBIÉN

ssl(7), SSL_CIPHER_get_name(3)
