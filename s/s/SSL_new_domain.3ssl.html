Paquete: openssl

SSL_NEW_DOMAIN(3ssl) OpenSSL SSL_NEW_DOMAIN(3ssl)

NOMBRE

SSL_new_domain, SSL_is_domain, SSL_get0_domain - Interfaz de objeto SSL para gestionar dominios de eventos QUIC

SINOPSIS

#include <openssl/ssl.h>
SSL *SSL_new_domain(SSL_CTX *ctx, uint64_t flags);
int SSL_is_domain(SSL *ssl);
SSL *SSL_get0_domain(SSL *ssl);

DESCRIPCIÓN

La función SSL_new_domain() crea un nuevo dominio de eventos QUIC, representado como un objeto SSL. Esto se conoce como un objeto SSL de dominio QUIC (QDSO). El concepto de dominio de eventos QUIC se discute en detalle en openssl-quic-concurrency(7).

El argumento flags para SSL_new_domain() especifica un conjunto de indicadores de dominio. Si el argumento flags de SSL_new_domain() no especifica uno de los indicadores SSL_DOMAIN_FLAG_SINGLE_THREAD, SSL_DOMAIN_FLAG_MULTI_THREAD o SSL_DOMAIN_FLAG_THREAD_ASSISTED, los indicadores de dominio configurados en el SSL_CTX se heredan por defecto y cualquier otro indicador en flags se añade al conjunto de indicadores heredados. De lo contrario, se utilizan los indicadores de dominio en flags. Consulte SSL_CTX_set_domain_flags(3) para obtener detalles sobre los indicadores de dominio disponibles y cómo se pueden configurar en un SSL_CTX.

Un objeto SSL de dominio QUIC se puede gestionar de la misma manera que cualquier otro objeto SSL, en el sentido de que se puede contar su referencia y liberarlo normalmente. Un objeto SSL de dominio QUIC es el padre de una serie de objetos hijos, como objetos SSL de escucha QUIC. Una vez creado un objeto SSL de dominio QUIC, se puede crear un oyente bajo él usando SSL_new_listener_from(3).

SSL_is_domain() devuelve 1 si un objeto SSL es un objeto SSL de dominio QUIC.

SSL_get0_domain() obtiene un puntero al objeto SSL de dominio QUIC en una jerarquía de objetos SSL (si la hay).

Todos los objetos SSL en un dominio de eventos QUIC utilizan los mismos indicadores de dominio, y los indicadores de dominio de un dominio QUIC no se pueden cambiar después de la construcción.

Operaciones Soportadas

Un objeto SSL de dominio QUIC existe para contener otros objetos SSL QUIC y proporcionar un manejo unificado de eventos. Como tal, solo soporta las siguientes operaciones:

  • Contadores de referencia estándar y operaciones de liberación, como SSL_up_ref(3) y SSL_free(3);
  • APIs de procesamiento de eventos y habilitación de sondeo, como SSL_handle_events(3) y SSL_get_event_timeout(3).
  • Creación de oyentes bajo el dominio usando SSL_new_listener_from(3).

El flujo de trabajo básico para usar un objeto de dominio es el siguiente:

  • Crear un nuevo objeto de dominio usando SSL_new_domain() con un SSL_CTX que use un SSL_METHOD compatible (como OSSL_QUIC_server_method(3));
  • Crear oyentes bajo el dominio usando SSL_new_listener_from(3).

Consulte SSL_new_listener_from(3) para obtener detalles sobre el uso de oyentes.

Actualmente, los objetos SSL de dominio solo son compatibles con el uso de QUIC a través de cualquier SSL_METHOD de QUIC.

Valores de Retorno

SSL_new_domain() devuelve un nuevo objeto SSL de dominio o NULL en caso de fallo.

SSL_is_domain() devuelve 0 o 1 dependiendo del tipo de objeto SSL sobre el que se llama.

SSL_get0_domain() devuelve un puntero a un objeto SSL (potencialmente al mismo objeto sobre el que se llama) o NULL.

Ver también

SSL_new_listener_from(3) SSL_handle_events(3), SSL_CTX_set_domain_flags(3), openssl-quic-concurrency(7)
