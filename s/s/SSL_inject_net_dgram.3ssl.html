SSL_inject_net_dgram(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_INJECT_NET_DGRAM(3ssl) OpenSSL SSL_INJECT_NET_DGRAM(3ssl)

NOMBRE

SSL_inject_net_dgram - inyecta un datagrama como si se hubiera recibido de la red

SINOPSIS

#include <openssl/ssl.h>
int SSL_inject_net_dgram(SSL *s, const unsigned char *buf,
                         size_t buf_len,
                         const BIO_ADDR *peer,
                         const BIO_ADDR *local);

DESCRIPCIÓN

Esta función se puede utilizar para inyectar una carga útil de datagrama en un objeto SSL de conexión QUIC. La carga útil se procesa como si se hubiera recibido de la red. Esta función se puede utilizar con fines de depuración o para permitir que los datagramas se alimenten a QUIC desde fuentes alternativas.

buf es obligatorio y debe apuntar a una carga útil de datagrama para inyectar. buf_len es la longitud del búfer en bytes. El búfer se copia y no es necesario que permanezca válido después de que esta función regrese.

peer y local son valores opcionales que apuntan a estructuras BIO_ADDR que describen las direcciones de los puntos finales UDP remotos y locales para el paquete. Aunque el paquete inyectado no fue recibido realmente de la red directamente por OpenSSL, el paquete se procesará como si el datagrama recibido tuviera las direcciones dadas.

VALORES DE RETORNO

Devuelve 1 si tiene éxito o 0 si falla. Esta función siempre falla si se llama en un objeto SSL que no es un objeto SSL de conexión QUIC.

VER TAMBIÉN

OSSL_QUIC_client_method(3), SSL_handle_events(3), SSL_set_blocking_mode(3)

HISTORIA

La función SSL_inject_net_dgram() se agregó en OpenSSL 3.2.
