SSL_get_peer_signature_nid(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_GET_PEER_SIGNATURE_NID(3ssl) OpenSSL SSL_GET_PEER_SIGNATURE_NID(3ssl)

NOMBRE

SSL_get0_peer_signature_name, SSL_get_peer_signature_nid, SSL_get_peer_signature_type_nid, SSL_get0_signature_name, SSL_get_signature_nid, SSL_get_signature_type_nid - obtener tipos de firma de mensajes TLS

SINOPSIS

#include <openssl/ssl.h>
int SSL_get0_peer_signature_name(const SSL *ssl, const char **sigalg);
int SSL_get_peer_signature_nid(SSL *ssl, int *psig_nid);
int SSL_get_peer_signature_type_nid(const SSL *ssl, int *psigtype_nid);
int SSL_get0_signature_name(SSL *ssl, const char **sigalg);
int SSL_get_signature_nid(SSL *ssl, int *psig_nid);
int SSL_get_signature_type_nid(const SSL *ssl, int *psigtype_nid);

DESCRIPCIÓN

SSL_get0_peer_signature_name() establece *sigalg al nombre IANA del esquema de firma https://www.iana.org/assignments/tls-parameters/tls-parameters.xhtml#tls-signaturescheme utilizado por el par para firmar el apretón de manos TLS. El llamador no debe liberar el puntero devuelto. La cadena devuelta debe copiarse si se va a conservar más allá de la vida útil de la conexión SSL.

SSL_get_peer_signature_nid() establece *psig_nid al NID del digest utilizado por el par para firmar mensajes TLS. Se implementa como una macro.

SSL_get_peer_signature_type_nid() establece *psigtype_nid al tipo de firma utilizado por el par para firmar mensajes TLS. Actualmente, el tipo de firma es el NID del tipo de clave pública utilizada para firmar, excepto para la firma PSS, donde es EVP_PKEY_RSA_PSS. Para diferenciar entre firmas rsa_pss_rsae_* y rsa_pss_pss_*, es necesario comprobar el tipo de clave pública en el certificado del par.

SSL_get0_signature_name(), SSL_get_signature_nid() y SSL_get_signature_type_nid() devuelven la información equivalente para el extremo local de la conexión.

VALORES DE RETORNO

Estas funciones devuelven 1 en caso de éxito y 0 en caso de fallo. Existen varias razones posibles para el fallo: el par o el extremo local es un cliente y no firmó el apretón de manos (no utilizó un certificado de cliente), el conjunto de cifrado no tiene firma (por ejemplo, utiliza intercambio de claves RSA o es anónimo), la versión TLS es inferior a 1.2 o las funciones se llamaron demasiado pronto, por ejemplo, antes de que el par firmara un mensaje.

VER TAMBIÉN

ssl(7), SSL_get_peer_certificate(3),

HISTORIA

Las funciones SSL_get0_peer_signature_name() y SSL_get0_signature_name() se añadieron en OpenSSL 3.5.

SSL_get_signature_nid() se añadió en OpenSSL 1.1.1a.
