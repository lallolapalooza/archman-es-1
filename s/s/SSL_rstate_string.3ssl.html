SSL_rstate_string(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_RSTATE_STRING(3ssl) OpenSSL SSL_RSTATE_STRING(3ssl)

NOMBRE

SSL_rstate_string, SSL_rstate_string_long - obtener descripción textual del estado de un objeto SSL durante la operación de lectura

SINOPSIS

#include <openssl/ssl.h>
const char *SSL_rstate_string(SSL *ssl);
const char *SSL_rstate_string_long(SSL *ssl);

DESCRIPCIÓN

SSL_rstate_string() devuelve una cadena de 2 letras que indica el estado de lectura actual del objeto SSL ssl.

SSL_rstate_string_long() devuelve una cadena que indica el estado de lectura actual del objeto SSL ssl.

NOTAS

Al realizar una operación de lectura, el motor SSL/TLS debe analizar el registro, que consta de una cabecera y un cuerpo. Al trabajar en un entorno de bloqueo, SSL_rstate_string[_long]() siempre debería devolver "RD"/"lectura completa".

Esta función solo debería necesitarse raramente en aplicaciones.

VALORES DE RETORNO

SSL_rstate_string() y SSL_rstate_string_long() pueden devolver los siguientes valores:

"RH"/"lectura de cabecera"
Se está evaluando la cabecera del registro.
"RB"/"lectura de cuerpo"
Se está evaluando el cuerpo del registro.
"desconocido"/"desconocido"
El estado de lectura es desconocido. Esto nunca debería ocurrir.

Cuando se utilizan con objetos SSL QUIC, estas funciones siempre devuelven "RH"/"lectura de cabecera" en condiciones normales.
