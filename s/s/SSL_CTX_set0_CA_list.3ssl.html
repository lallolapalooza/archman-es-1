SSL_CTX_set0_CA_list(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SSL_CTX_SET0_CA_LIST(3ssl) OpenSSL SSL_CTX_SET0_CA_LIST(3ssl)

NOMBRE

SSL_CTX_set_client_CA_list, SSL_set_client_CA_list, SSL_get_client_CA_list, SSL_CTX_get_client_CA_list, SSL_CTX_add_client_CA, SSL_add_client_CA, SSL_set0_CA_list, SSL_CTX_set0_CA_list, SSL_get0_CA_list, SSL_CTX_get0_CA_list, SSL_add1_to_CA_list, SSL_CTX_add1_to_CA_list, SSL_get0_peer_CA_list - obtener o establecer la lista de CA

SINOPSIS

#include <openssl/ssl.h>
void SSL_CTX_set_client_CA_list(SSL_CTX *ctx, STACK_OF(X509_NAME) *list);
void SSL_set_client_CA_list(SSL *s, STACK_OF(X509_NAME) *list);
STACK_OF(X509_NAME) *SSL_get_client_CA_list(const SSL *s);
STACK_OF(X509_NAME) *SSL_CTX_get_client_CA_list(const SSL_CTX *ctx);
int SSL_CTX_add_client_CA(SSL_CTX *ctx, X509 *cacert);
int SSL_add_client_CA(SSL *ssl, X509 *cacert);
void SSL_CTX_set0_CA_list(SSL_CTX *ctx, STACK_OF(X509_NAME) *name_list);
void SSL_set0_CA_list(SSL *s, STACK_OF(X509_NAME) *name_list);
const STACK_OF(X509_NAME) *SSL_CTX_get0_CA_list(const SSL_CTX *ctx);
const STACK_OF(X509_NAME) *SSL_get0_CA_list(const SSL *s);
int SSL_CTX_add1_to_CA_list(SSL_CTX *ctx, const X509 *x);
int SSL_add1_to_CA_list(SSL *ssl, const X509 *x);
const STACK_OF(X509_NAME) *SSL_get0_peer_CA_list(const SSL *s);

DESCRIPCIÓN

Las funciones aquí descritas establecen y gestionan la lista de nombres de CA que se envían entre dos pares de comunicación.

Para las versiones 1.2 y anteriores de TLS, la lista de nombres de CA solo se envía del servidor al cliente al solicitar un certificado de cliente. Por lo tanto, cualquier lista de nombres de CA establecida nunca se envía del cliente al servidor y la lista de nombres de CA recuperada por SSL_get0_peer_CA_list() siempre es NULL.

Para TLS 1.3, la lista de nombres de CA se envía utilizando la extensión certificate_authorities y puede ser enviada por un cliente (en el mensaje ClientHello) o por un servidor (al solicitar un certificado).

En la mayoría de los casos, no es necesario establecer nombres de CA en el lado del cliente. La lista de nombres de CA que son aceptables para el cliente se enviará en texto plano al servidor. Esto tiene implicaciones de privacidad y también puede tener implicaciones de rendimiento si la lista es grande. Esta capacidad opcional se introdujo como parte de TLSv1.3 y, por lo tanto, establecer nombres de CA en el lado del cliente no tendrá ningún impacto si esa versión del protocolo ha sido deshabilitada. La mayoría de los servidores no necesitan esto y, por lo tanto, se debe evitar a menos que sea necesario.

Las funciones de "lista de CA de cliente" a continuación solo tienen efecto cuando se llaman en el lado del servidor.

SSL_CTX_set_client_CA_list() establece la lista de CAs enviada al cliente al solicitar un certificado de cliente para ctx. La propiedad de list se transfiere a ctx y el llamador no debe liberarla.

SSL_set_client_CA_list() establece la lista de CAs enviada al cliente al solicitar un certificado de cliente para el ssl elegido, anulando la configuración válida para el objeto SSL_CTX de ssl. La propiedad de list se transfiere a s y el llamador no debe liberarla.

SSL_CTX_get_client_CA_list() devuelve la lista de CAs de cliente establecidas explícitamente para ctx usando SSL_CTX_set_client_CA_list(). El llamador no debe liberar la lista devuelta.

SSL_get_client_CA_list() devuelve la lista de CAs de cliente establecidas explícitamente para ssl usando SSL_set_client_CA_list() o el objeto SSL_CTX de ssl con SSL_CTX_set_client_CA_list(), cuando está en modo servidor. En modo cliente, SSL_get_client_CA_list devuelve la lista de CAs de cliente enviadas desde el servidor, si las hay. El llamador no debe liberar la lista devuelta.

SSL_CTX_add_client_CA() agrega el nombre de la CA extraído de cacert a la lista de CAs enviadas al cliente al solicitar un certificado de cliente para ctx.

SSL_add_client_CA() agrega el nombre de la CA extraído de cacert a la lista de CAs enviadas al cliente al solicitar un certificado de cliente para el ssl elegido, anulando la configuración válida para el objeto SSL_CTX de ssl.

SSL_get0_peer_CA_list() recupera la lista de nombres de CA (si las hay) que el par ha enviado. Esto se puede llamar tanto en el lado del servidor como en el del cliente. El llamador no debe liberar la lista devuelta.

Las funciones de "lista de CA genérica" a continuación son muy similares a las funciones de "lista de CA de cliente", excepto que tienen un efecto tanto en el lado del servidor como en el del cliente. Las listas de nombres de CA gestionadas están separadas, por lo que no puede (por ejemplo) establecer nombres de CA usando las funciones de "lista de CA de cliente" y luego obtenerlos usando las funciones de "lista de CA genérica". Donde se ha utilizado una mezcla de los dos tipos de funciones en el lado del servidor, las funciones de "lista de CA de cliente" tienen prioridad. Típicamente, en el lado del servidor, se prefieren las funciones de "lista de CA de cliente". Como se mencionó anteriormente, en la mayoría de los casos no es necesario establecer nombres de CA en el lado del cliente.

SSL_CTX_set0_CA_list() establece la lista de CAs que se enviarán al par a name_list. La propiedad de name_list se transfiere a ctx y el llamador no debe liberarla.

SSL_set0_CA_list() establece la lista de CAs que se enviarán al par a name_list, anulando cualquier lista establecida en el SSL_CTX padre de s. La propiedad de name_list se transfiere a s y el llamador no debe liberarla.

SSL_CTX_get0_CA_list() recupera cualquier lista de CAs previamente establecida para ctx. El llamador no debe liberar la lista devuelta.

SSL_get0_CA_list() recupera cualquier lista de CAs previamente establecida para s o, si no hay ninguna establecida, recupera la lista del SSL_CTX padre. El llamador no debe liberar la lista devuelta.

SSL_CTX_add1_to_CA_list() agrega el nombre del sujeto de la CA extraído de x a la lista de CAs que se envían al par para ctx.

SSL_add1_to_CA_list() agrega el nombre del sujeto de la CA extraído de x a la lista de CAs que se envían al par para s, anulando la configuración en el SSL_CTX padre.

NOTAS

Cuando un servidor TLS/SSL solicita un certificado de cliente (ver SSL_CTX_set_verify(3)), envía una lista de CAs, para las cuales aceptará certificados, al cliente.

Esta lista debe establecerse explícitamente usando SSL_CTX_set_client_CA_list() o SSL_CTX_set0_CA_list() para ctx y SSL_set_client_CA_list() o SSL_set0_CA_list() para el ssl específico. La lista especificada anula la configuración anterior. Las CAs listadas no se vuelven confiables (list solo contiene los nombres, no los certificados completos); use SSL_CTX_load_verify_locations(3) para cargarlas adicionalmente para la verificación.

Si la lista de CAs aceptables está compilada en un archivo, la función SSL_load_client_CA_file(3) puede usarse para ayudar a importar los datos necesarios.

SSL_CTX_add_client_CA(), SSL_CTX_add1_to_CA_list(), SSL_add_client_CA() y SSL_add1_to_CA_list() se pueden usar para agregar elementos adicionales a la lista de CAs. Si no se especificó ninguna lista antes de usar SSL_CTX_set_client_CA_list(), SSL_CTX_set0_CA_list(), SSL_set_client_CA_list() o SSL_set0_CA_list(), se abre una nueva lista de CAs para ctx o ssl (según corresponda).

VALORES DE RETORNO

SSL_CTX_set_client_CA_list(), SSL_set_client_CA_list(), SSL_CTX_set_client_CA_list(), SSL_set_client_CA_list(), SSL_CTX_set0_CA_list() y SSL_set0_CA_list() no devuelven ningún valor.

SSL_CTX_get_client_CA_list(), SSL_get_client_CA_list(), SSL_CTX_get0_CA_list() y SSL_get0_CA_list() devuelven una pila de nombres de CA o NULL si no se establecen nombres de CA.

SSL_CTX_add_client_CA(),SSL_add_client_CA(), SSL_CTX_add1_to_CA_list() y SSL_add1_to_CA_list() devuelven 1 en caso de éxito y 0 en caso de fallo.

SSL_get0_peer_CA_list() devuelve una pila de nombres de CA enviados por el par o NULL o una pila vacía si no se envió ninguna lista.

EJEMPLOS

Escanear todos los certificados en CAfile y listarlos como CAs aceptables:

SSL_CTX_set_client_CA_list(ctx, SSL_load_client_CA_file(CAfile));
