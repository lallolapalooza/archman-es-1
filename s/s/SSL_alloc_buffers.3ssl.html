Paquete: openssl

SSL_ALLOC_BUFFERS(3ssl) OpenSSL SSL_ALLOC_BUFFERS(3ssl)

NOMBRE

SSL_free_buffers, SSL_alloc_buffers - gestionar búferes de la estructura SSL

SINOPSIS

#include <openssl/ssl.h>
int SSL_free_buffers(SSL *ssl);
int SSL_alloc_buffers(SSL *ssl);

DESCRIPCIÓN

SSL_free_buffers() libera los búferes de lectura y escritura del ssl dado. SSL_alloc_buffers() asigna los búferes de lectura y escritura del ssl dado.

El modo SSL_MODE_RELEASE_BUFFERS libera los búferes de lectura o escritura siempre que los búferes se hayan vaciado. Estas funciones permiten a las aplicaciones controlar manualmente cuándo se liberan y asignan los búferes.

Después de liberar los búferes, estos se reasignan automáticamente al realizar una nueva lectura o escritura. No es necesario llamar a SSL_alloc_buffers(), pero se puede usar para asegurarse de que los búferes estén preasignados. Esto se puede usar para evitar la asignación durante el procesamiento de datos o con CRYPTO_set_mem_functions() para controlar dónde y cómo se asignan los búferes.

Estas funciones no hacen nada cuando se usan con objetos SSL QUIC. Para QUIC, SSL_free_buffers() siempre falla y SSL_alloc_buffers() siempre tiene éxito.

VALORES DE RETORNO

Los siguientes valores de retorno pueden ocurrir:

0 (Fallo)
La función SSL_free_buffers() devuelve 0 cuando hay datos pendientes por leer o escribir. La función SSL_alloc_buffers() devuelve 0 cuando hay un fallo de asignación.
1 (Éxito)
La función SSL_free_buffers() devuelve 1 si los búferes han sido liberados. Este valor también se devuelve si los búferes ya habían sido liberados antes de llamar a SSL_free_buffers(). La función SSL_alloc_buffers() devuelve 1 si los búferes han sido asignados. Este valor también se devuelve si los búferes ya habían sido asignados antes de llamar a SSL_alloc_buffers().
