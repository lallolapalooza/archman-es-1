SSL_CLEAR(3ssl) OpenSSL SSL_CLEAR(3ssl)

NOMBRE

SSL_clear - reinicia el objeto SSL para permitir otra conexión

SINOPSIS

#include <openssl/ssl.h>
int SSL_clear(SSL *ssl);

DESCRIPCIÓN

Reinicia ssl para permitir otra conexión. Se conservan todos los ajustes (método, cifrados, BIOs).

NOTAS

SSL_clear se utiliza para preparar un objeto SSL para una nueva conexión. Aunque se conservan todos los ajustes, un efecto secundario es el manejo de la sesión SSL actual. Si una sesión todavía está abierta, se considera errónea y se eliminará de la caché de sesiones, según lo requerido por RFC2246. Una sesión se considera abierta si no se llamó a SSL_shutdown(3) para la conexión o al menos se utilizó SSL_set_shutdown(3) para establecer el estado SSL_SENT_SHUTDOWN.

Si una sesión se cerró limpiamente, el objeto de sesión se conservará y todos los ajustes correspondientes. Esto significa explícitamente que, por ejemplo, el método especial utilizado durante la sesión se conservará para el próximo handshake. Por lo tanto, si la sesión fue una sesión TLSv1, un objeto cliente SSL utilizará un método cliente TLSv1 para el próximo handshake y un objeto servidor SSL utilizará un método servidor TLSv1, incluso si se eligieron los métodos TLS_*_methods al inicio. Esto podría provocar fallos en la conexión (consulte SSL_new(3) para obtener una descripción de las propiedades del método).

Esta función no es compatible con objetos SSL QUIC y devuelve un fallo si se llama en un objeto de este tipo.

ADVERTENCIAS

SSL_clear() reinicia el objeto SSL para permitir otra conexión. Sin embargo, la operación de reinicio conserva varias configuraciones de las últimas sesiones (algunas de estas configuraciones se realizaron automáticamente durante el último handshake). Solo tiene sentido para una nueva conexión con el mismo par exacto que comparte estas configuraciones, y puede fallar si ese par cambia sus configuraciones entre conexiones. Use la secuencia SSL_get_session(3); SSL_new(3); SSL_set_session(3); SSL_free(3) en su lugar para evitar tales fallos (o simplemente SSL_free(3); SSL_new(3) si no se desea la reutilización de sesiones).

VALORES DEVUELTOS

Los siguientes valores de retorno pueden ocurrir:

0
La operación SSL_clear() no pudo realizarse. Consulte la pila de errores para averiguar el motivo.
1
La operación SSL_clear() fue exitosa.
