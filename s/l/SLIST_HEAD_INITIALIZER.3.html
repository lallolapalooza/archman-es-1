SLIST(3) Manual de funciones de biblioteca SLIST(3)

NOMBRE

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - implementación de una lista enlazada simplemente

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <sys/queue.h>
SLIST_ENTRY(TIPO);
SLIST_HEAD(NOMBRECABECERA, TIPO);
SLIST_HEAD NOMBRECABECERA_INITIALIZER(SLIST_HEAD cabecera);
void SLIST_INIT(SLIST_HEAD *cabecera);
int SLIST_EMPTY(SLIST_HEAD *cabecera);
void SLIST_INSERT_HEAD(SLIST_HEAD *cabecera,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
void SLIST_INSERT_AFTER(struct TIPO *elem_lista,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
struct TIPO *SLIST_FIRST(SLIST_HEAD *cabecera);
struct TIPO *SLIST_NEXT(struct TIPO *elem, SLIST_ENTRY NOMBRE);
SLIST_FOREACH(struct TIPO *var, SLIST_HEAD *cabecera, SLIST_ENTRY NOMBRE);
void SLIST_REMOVE(SLIST_HEAD *cabecera, struct TIPO *elem, TIPO,
                        SLIST_ENTRY NOMBRE);
void SLIST_REMOVE_HEAD(SLIST_HEAD *cabecera,
                        SLIST_ENTRY NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre listas enlazadas simplemente.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo SLIST_ENTRY, llamado NOMBRE. El argumento NOMBRECABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro SLIST_HEAD().

Creación

Una lista enlazada simplemente se encabeza por una estructura definida por la macro SLIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos se enlazan simplemente para una mínima sobrecarga de espacio y manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:


SLIST_HEAD(NOMBRECABECERA, TIPO) cabecera;

donde struct NOMBRECABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la lista. Un puntero a la cabecera de la lista se puede declarar posteriormente como:


struct NOMBRECABECERA *puntero_cabecera;

(Los nombres cabecera y puntero_cabecera son seleccionables por el usuario.)

SLIST_ENTRY() declara una estructura que conecta los elementos de la lista.

SLIST_HEAD_INITIALIZER() se evalúa como un inicializador para la lista cabecera.

SLIST_INIT() inicializa la lista referenciada por cabecera.

SLIST_EMPTY() se evalúa como verdadero si no hay elementos en la lista.

Inserción

SLIST_INSERT_HEAD() inserta el nuevo elemento elem al principio de la lista.

SLIST_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

SLIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

SLIST_NEXT() devuelve el siguiente elemento de la lista.

SLIST_FOREACH() recorre la lista referenciada por cabecera en dirección hacia adelante, asignando cada elemento en turno a var.

Eliminación

SLIST_REMOVE() elimina el elemento elem de la lista.

SLIST_REMOVE_HEAD() elimina el elemento elem del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deberían usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE().

VALOR DE RETORNO

SLIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía, y cero si la lista contiene al menos una entrada.

SLIST_FIRST() y SLIST_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

SLIST_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cabecera de la lista.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

BUGS

SLIST_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. SLIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    SLIST_ENTRY(entrada) entradas;             /* Lista enlazada
                                                   simplemente */
};
SLIST_HEAD(cabecerallista, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabecerallista cabeza;                  /* Cabecera de la lista
                                                       enlazada
                                                       simplemente */
    SLIST_INIT(&cabeza);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    SLIST_INSERT_HEAD(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    SLIST_INSERT_AFTER(n1, n2, entradas);
    SLIST_REMOVE(&cabeza, n2, entrada, entradas);/* Eliminación */
    free(n2);
    n3 = SLIST_FIRST(&cabeza);
    SLIST_REMOVE_HEAD(&cabeza, entradas);      /* Eliminación desde el
                                                   principio */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        SLIST_INSERT_HEAD(&cabeza, n1, entradas);
        n1->datos = i;
    }
                                            /* Recorrido hacia adelante */
    SLIST_FOREACH(np, &cabeza, entradas)
        printf("%i\n", np->datos);
    while (!SLIST_EMPTY(&cabeza)) {           /* Eliminación de la lista */
        n1 = SLIST_FIRST(&cabeza);
        SLIST_REMOVE_HEAD(&cabeza, entradas);
        free(n1);
    }
    SLIST_INIT(&cabeza);
    exit(EXIT_SUCCESS);
}
