SLIST(3) Manual de funciones de la biblioteca SLIST(3)

NOMBRE

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - implementación de una lista simplemente enlazada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
SLIST_ENTRY(TIPO);
SLIST_HEAD(NOMBRE_CABECERA, TIPO);
SLIST_HEAD NOMBRE_CABECERA_INICIALIZADOR(SLIST_HEAD cabecera);
void SLIST_INIT(SLIST_HEAD *cabecera);
int SLIST_EMPTY(SLIST_HEAD *cabecera);
void SLIST_INSERT_HEAD(SLIST_HEAD *cabecera,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
void SLIST_INSERT_AFTER(struct TIPO *listelm,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
struct TIPO *SLIST_FIRST(SLIST_HEAD *cabecera);
struct TIPO *SLIST_NEXT(struct TIPO *elm, SLIST_ENTRY NOMBRE);
SLIST_FOREACH(struct TIPO *var, SLIST_HEAD *cabecera, SLIST_ENTRY NOMBRE);
void SLIST_REMOVE(SLIST_HEAD *cabecera, struct TIPO *elm, TIPO,
                        SLIST_ENTRY NOMBRE);
void SLIST_REMOVE_HEAD(SLIST_HEAD *cabecera,
                        SLIST_ENTRY NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre listas simplemente enlazadas.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo SLIST_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro SLIST_HEAD().

Creación

Una lista simplemente enlazada está encabezada por una estructura definida por la macro SLIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simplemente enlazada para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:


SLIST_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabecera de la lista se puede declarar posteriormente como:


struct NOMBRE_CABECERA *cabecerp;

(Los nombres cabecera y cabecerp son seleccionables por el usuario.)

SLIST_ENTRY() declara una estructura que conecta los elementos de la lista.

SLIST_HEAD_INITIALIZER() se evalúa como un inicializador para la lista cabecera.

SLIST_INIT() inicializa la lista referenciada por cabecera.

SLIST_EMPTY() se evalúa como verdadero si no hay elementos en la lista.

Inserción

SLIST_INSERT_HEAD() inserta el nuevo elemento elem al principio de la lista.

SLIST_INSERT_AFTER() inserta el nuevo elemento elem después del elemento listelm.

Recorrido

SLIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

SLIST_NEXT() devuelve el siguiente elemento de la lista.

SLIST_FOREACH() recorre la lista referenciada por cabecera en dirección hacia adelante, asignando cada elemento en turno a var.

Eliminación

SLIST_REMOVE() elimina el elemento elm de la lista.

SLIST_REMOVE_HEAD() elimina el elemento elm del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deben usar explícitamente esta macro en lugar de la genérica SLIST_REMOVE().

VALOR DEVUELTO

SLIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía, y cero si la lista contiene al menos una entrada.

SLIST_FIRST() y SLIST_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

SLIST_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la lista cabecera.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

BUGS

SLIST_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. SLIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    SLIST_ENTRY(entry) entries;             /* Lista simplemente enlazada */
};
SLIST_HEAD(slisthead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct slisthead head;                  /* Cabecera de lista simplemente enlazada */
    SLIST_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    SLIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    SLIST_INSERT_AFTER(n1, n2, entries);
    SLIST_REMOVE(&head, n2, entry, entries);/* Borrado */
    free(n2);
    n3 = SLIST_FIRST(&head);
    SLIST_REMOVE_HEAD(&head, entries);      /* Borrado desde el principio */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        SLIST_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
                                            /* Recorrido hacia adelante */
    SLIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
    while (!SLIST_EMPTY(&head)) {           /* Borrado de lista */
        n1 = SLIST_FIRST(&head);
        SLIST_REMOVE_HEAD(&head, entries);
        free(n1);
    }
    SLIST_INIT(&head);
    exit(EXIT_SUCCESS);
}

SLIST_ENTRY(3bsd)

BIBLIOTECA SINÓPSIS DESCRIPCIÓN VALOR DE RETORNO ESTÁNDARES HISTORIA ERRORES EJEMPLOS VER TAMBIÉN

BIBLIOTECA

System V, BSD

SINÓPSIS

#include <sys/queue.h>

DESCRIPCIÓN

Las macros SLIST_ENTRY, SLIST_HEAD, SLIST_INIT, SLIST_INSERT_HEAD, SLIST_INSERT_AFTER, SLIST_REMOVE_HEAD, SLIST_REMOVE, SLIST_REMOVE_AFTER, SLIST_NEXT, SLIST_FIRST, SLIST_END, SLIST_EMPTY, SLIST_FOREACH, SLIST_FOREACH_SAFE, SLIST_SWAP, SLIST_MOVE, SLIST_MOVE_SLIST proporcionan soporte para listas enlazadas simples.

Una lista enlazada simple es una colección de elementos (llamados nodos) donde cada nodo contiene un puntero a su sucesor inmediato. La lista en sí misma se mantiene mediante un puntero al primer nodo (la cabecera).

Las listas enlazadas simples son útiles para implementar colas, pilas y otras estructuras de datos dinámicas. Son eficientes para inserciones y eliminaciones en el extremo principal de la lista, pero las inserciones y eliminaciones en el medio o al final pueden ser más lentas ya que requieren recorrer la lista.

Las macros SLIST_ ... definen una interfaz para operar sobre listas enlazadas simples. Permiten definir la estructura de los nodos, inicializar y manipular listas de forma segura y eficiente.

VALOR DE RETORNO

(No aplicable directamente a estas macros, ya que son estructuras de datos y operaciones de manipulación.)

ESTÁNDARES

Estas macros son parte de la implementación BSD de las estructuras de datos enlazadas y no son parte de ningún estándar POSIX o C.

HISTORIA

Las macros SLIST_ ... se introdujeron en la versión 4.4BSD-Lite.

ERRORES

No se conocen errores en la implementación actual.

EJEMPLOS

A continuación se muestra un ejemplo básico de cómo usar las macros SLIST_: 


#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

// Definición de la estructura del nodo
typedef struct {
    int data;
    SLIST_ENTRY(node) entries; // Macro para el puntero de enlace
} node_t;

// Definición de la estructura de la cabecera de la lista
SLIST_HEAD(node_list_t, node);

int main() {
    struct node_list_t head; // Declaración de la cabecera de la lista
    SLIST_INIT(&head);      // Inicialización de la lista

    // Crear y añadir nodos a la lista
    node_t *newNode1 = malloc(sizeof(node_t));
    newNode1->data = 10;
    SLIST_INSERT_HEAD(&head, newNode1, entries);

    node_t *newNode2 = malloc(sizeof(node_t));
    newNode2->data = 20;
    SLIST_INSERT_HEAD(&head, newNode2, entries); // Añade al principio, por lo que 20 estará antes que 10

    node_t *newNode3 = malloc(sizeof(node_t));
    newNode3->data = 30;
    SLIST_INSERT_AFTER(newNode1, newNode3, entries); // Añade newNode3 después de newNode1

    // Recorrer la lista e imprimir los datos
    printf("Contenido de la lista:\n");
    node_t *current;
    SLIST_FOREACH(current, &head, entries) {
        printf("%d\n", current->data);
    }

    // Eliminar nodos (ejemplo: eliminar el primer nodo)
    node_t *nodeToRemove = SLIST_FIRST(&head);
    if (nodeToRemove != NULL) {
        SLIST_REMOVE_HEAD(&head, entries);
        printf("Nodo eliminado: %d\n", nodeToRemove->data);
        free(nodeToRemove);
    }

    // Recorrer la lista de nuevo
    printf("Contenido de la lista después de eliminar:\n");
    SLIST_FOREACH(current, &head, entries) {
        printf("%d\n", current->data);
    }

    // Liberar la memoria restante (importante en aplicaciones reales)
    while (!SLIST_EMPTY(&head)) {
        node_t *temp = SLIST_FIRST(&head);
        SLIST_REMOVE_HEAD(&head, entries);
        free(temp);
    }

    return 0;
}
