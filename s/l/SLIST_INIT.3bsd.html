DESCRIPTION

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser utilizadas tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simples
  3. Colas de cola enlazadas simples
  4. Colas de cola
Las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de una nueva entrada al principio de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento de la lista.
  3. Eliminación en tiempo O(1) de una entrada desde el principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más sencillas de las cuatro estructuras de datos y solo soportan la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO. Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación en tiempo O(n) de cualquier entrada en la lista.
  2. Concatenación en tiempo O(n) de dos listas.

Las colas de cola enlazadas simples añaden la siguiente funcionalidad:

  1. Las entradas se pueden añadir al final de una lista.
  2. Eliminación en tiempo O(n) de cualquier entrada en la lista.
  3. Se pueden concatenar.
Sin embargo:
  1. Todas las inserciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lentas que las listas enlazadas simples.

Las colas de cola enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO.

Todos los tipos de estructuras de datos enlazadas doblemente (listas y colas de cola) permiten además:

  1. Inserción de una nueva entrada antes de cualquier elemento de la lista.
  2. Eliminación en tiempo O(1) de cualquier entrada en la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que el de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más sencillas de las estructuras de datos enlazadas doblemente. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación en tiempo O(n) de dos listas.
  2. Se pueden recorrer hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para iniciar el recorrido y la lista en la que está contenida.

Las colas de cola añaden la siguiente funcionalidad:

  1. Las entradas se pueden añadir al final de una lista.
  2. Se pueden recorrer hacia atrás, de cola a cabeza.
  3. Se pueden concatenar.
Sin embargo:
  1. Todas las inserciones y eliminaciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lentas que las listas enlazadas simples.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que sea de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que sea de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe ser declarada usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, o TAILQ_CLASS_HEAD. Consulte los ejemplos a continuación para obtener más explicaciones sobre cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados simplemente para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe usar una cola de cola enlazada simple si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_EMPTY se evalúa como verdadera si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí está permitido eliminar var así como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento

EJEMPLO DE LISTA DILIGENTE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Cabeza de lista diligente. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Enlace de lista diligente. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Inicializar la lista. */

n1 = malloc(sizeof(struct entry));	/* Insertar al frente. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Eliminar. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminar de la cabeza. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Eliminar la lista. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

COLAS DE COLA DILIGENTES

Una cola de cola diligente se encabeza por una estructura definida mediante la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de cola y otro al último. Los elementos están enlazados de forma simple para minimizar la sobrecarga de espacio y manipulación de punteros, pero con un costo de O(n) para eliminar elementos arbitrarios. Los nuevos elementos pueden ser añadidos a la cola de cola después de un elemento existente, al frente de la cola de cola o al final de la cola de cola. Una estructura STAILQ_HEAD se declara así:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos enlazados a la cola de cola. Una dirección de puntero a la cabeza de la cola de cola puede ser declarada más tarde así:

struct HEADNAME *headp;

(Los nombres head y headp son elegibles por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de cola head.

La macro STAILQ_CONCAT concatenará la cola de cola encabezada por head2 al final de la cola de cola encabezada por head1, vaciando la primera cola.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de cola.

La macro STAILQ_ENTRY declara una estructura que enlaza los elementos de la cola de cola.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de cola o NULL si la cola de cola está vacía.

La macro STAILQ_FOREACH recorre la cola de cola referenciada por head hacia adelante, asignando cada elemento a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento encontrado previamente en la cola de cola y comienza el bucle desde var en lugar del primer elemento de la cola de cola referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de cola referenciada por head hacia adelante, asignando cada elemento a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí está permitido eliminar var y liberarla dentro del bucle de manera segura sin interferir con la travesía.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento encontrado previamente en la cola de cola y comienza el bucle desde var en lugar del primer elemento de la cola de cola referenciada por head.

La macro STAILQ_INIT inicializa la cola de cola referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al frente de la cola de cola.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de cola.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de cola. Si la cola de cola está vacía, el valor devuelto es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de cola, o NULL si este es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento posterior a elm de la cola de cola. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola de cola.

La macro STAILQ_REMOVE_HEAD elimina el elemento en la cabeza de la cola de cola. Para optimizar la eficiencia, los elementos que se van a eliminar de la cabeza de la cola de cola deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola de cola. Su uso debe evitarse ya que recorre toda la cola. Se debe usar una cola de cola doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas de cola largas.

La macro STAILQ_SWAP intercambia los contenidos de head1 y head2.

EJEMPLO DE COLA DE COLA DILIGENTE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Cabeza de cola de cola diligente. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Enlace de cola de cola diligente. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializar la cola. */

n1 = malloc(sizeof(struct entry));	/* Insertar al frente. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertar al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminar. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminar de la cabeza. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Vaciar la cola de cola. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Vaciar la cola de cola más rápido. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS

Una lista se encabeza por una estructura definida mediante la macro LIST_HEAD. Esta estructura contiene un solo puntero al primer elemento de la lista. Los elementos están enlazados doblemente, permitiendo la eliminación de cualquier elemento sin recorrer toda la lista. Los nuevos elementos pueden ser añadidos a la lista después de un elemento existente, antes de un elemento existente, o al frente de la lista. Una estructura LIST_HEAD se declara así:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos enlazados a la lista. Una dirección de puntero a la cabeza de la lista puede ser declarada más tarde así:

struct HEADNAME *headp;

(Los nombres head y headp son elegibles por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatenará la lista encabezada por head2 al final de la lista encabezada por head1, vaciando la primera lista. Su uso debe evitarse ya que recorre toda la lista head1. Se debe usar una cola de cola si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que enlaza los elementos de la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por head hacia adelante, asignando cada elemento a var.

La macro LIST_FOREACH_FROM se comporta de manera idéntica a LIST_FOREACH cuando var es NULL, de lo contrario trata var como un elemento encontrado previamente en la lista y comienza el bucle desde var en lugar del primer elemento de la lista referenciada por head.

La macro LIST_FOREACH_SAFE recorre la lista referenciada por head hacia adelante, asignando cada elemento a var. Sin embargo, a diferencia de LIST_FOREACH(), aquí está permitido eliminar var y liberarla dentro del bucle de manera segura sin interferir con la travesía.

La macro LIST_FOREACH_FROM_SAFE se comporta de manera idéntica a LIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento encontrado previamente en la lista y comienza el bucle desde var en lugar del primer elemento de la lista referenciada por head.

DIAGNOSTICOS

Al depurar queue(3), puede ser útil rastrear los cambios de la cola. Para habilitar el rastreo, defina la macro QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.

También puede ser útil "basurizar" punteros que han sido desvinculados de una cola, para detectar el uso después de la eliminación. Para habilitar el "basurizado" de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH en tiempo de compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido "basurizado" por la opción QUEUE_MACRO_DEBUG_TRASH.
