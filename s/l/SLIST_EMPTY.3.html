SLIST(3) Manual de funciones de biblioteca SLIST(3)

NOMBRE

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - implementación de una lista enlazada simple

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
SLIST_ENTRY(TIPO);
SLIST_HEAD(NOMBRE_DE_CABECERA, TIPO);
SLIST_HEAD SLIST_HEAD_INITIALIZER(SLIST_HEAD cabecera);
void SLIST_INIT(SLIST_HEAD *cabecera);
int SLIST_EMPTY(SLIST_HEAD *cabecera);
void SLIST_INSERT_HEAD(SLIST_HEAD *cabecera,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
void SLIST_INSERT_AFTER(struct TIPO *listelm,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
struct TIPO *SLIST_FIRST(SLIST_HEAD *cabecera);
struct TIPO *SLIST_NEXT(struct TIPO *elem, SLIST_ENTRY NOMBRE);
SLIST_FOREACH(struct TIPO *var, SLIST_HEAD *cabecera, SLIST_ENTRY NOMBRE);
void SLIST_REMOVE(SLIST_HEAD *cabecera, struct TIPO *elem, TIPO,
                        SLIST_ENTRY NOMBRE);
void SLIST_REMOVE_HEAD(SLIST_HEAD *cabecera,
                        SLIST_ENTRY NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre listas enlazadas simples.

En las definiciones de macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo SLIST_ENTRY, llamado NOMBRE. El argumento NOMBRE_DE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro SLIST_HEAD().

Creación

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:


SLIST_HEAD(NOMBRE_DE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_DE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la lista. Un puntero a la cabecera de la lista puede declararse posteriormente como:


struct NOMBRE_DE_CABECERA *puntero_a_cabecera;

(Los nombres cabecera y puntero_a_cabecera son seleccionables por el usuario.)

SLIST_ENTRY() declara una estructura que conecta los elementos de la lista.

SLIST_HEAD_INITIALIZER() se evalúa como un inicializador para la lista cabecera.

SLIST_INIT() inicializa la lista referenciada por cabecera.

SLIST_EMPTY() se evalúa como verdadero si no hay elementos en la lista.

Inserción

SLIST_INSERT_HEAD() inserta el nuevo elemento elem al principio de la lista.

SLIST_INSERT_AFTER() inserta el nuevo elemento elem después del elemento listelm.

Recorrido

SLIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

SLIST_NEXT() devuelve el siguiente elemento de la lista.

SLIST_FOREACH() recorre la lista referenciada por cabecera en la dirección hacia adelante, asignando cada elemento en turno a var.

Eliminación

SLIST_REMOVE() elimina el elemento elem de la lista.

SLIST_REMOVE_HEAD() elimina el elemento elm del principio de la lista. Para una máxima eficiencia, los elementos que se eliminan del principio de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE().

VALOR DE RETORNO

SLIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía, y cero si la lista contiene al menos una entrada.

SLIST_FIRST() y SLIST_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

SLIST_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cabecera de la lista.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ERRORES

SLIST_FOREACH() no permite que var se elimine o libere dentro del bucle, ya que interferiría con el recorrido. SLIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    SLIST_ENTRY(entrada) entradas;             /* Lista enlazada simple */
};
SLIST_HEAD(cabeceradesl, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabeceradesl cabeza;                  /* Cabecera de lista enlazada simple */
    SLIST_INIT(&cabeza);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    SLIST_INSERT_HEAD(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    SLIST_INSERT_AFTER(n1, n2, entradas);
    SLIST_REMOVE(&cabeza, n2, entrada, entradas);/* Eliminación */
    free(n2);
    n3 = SLIST_FIRST(&cabeza);
    SLIST_REMOVE_HEAD(&cabeza, entradas);      /* Eliminación desde el principio */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        SLIST_INSERT_HEAD(&cabeza, n1, entradas);
        n1->datos = i;
    }
                                            /* Recorrido hacia adelante */
    SLIST_FOREACH(np, &cabeza, entradas)
        printf("%i\n", np->datos);
    while (!SLIST_EMPTY(&cabeza)) {           /* Eliminación de la lista */
        n1 = SLIST_FIRST(&cabeza);
        SLIST_REMOVE_HEAD(&cabeza, entradas);
        free(n1);
    }
    SLIST_INIT(&cabeza);
    exit(EXIT_SUCCESS);
}

SLIST_EMPTY(3bsd) — Arch Linux

NAME

SLIST_EMPTY, SLIST_REMOVE_HEAD, SLIST_INSERT_HEAD, SLIST_INSERT_AFTER, SLIST_INSERT_TAIL, SLIST_FOREACH, SLIST_FIND_IF, SLIST_FIND_IF_PREV, SLIST_FIRST, SLIST_NEXT, SLIST_PREV, SLIST_LAST, SLIST_END, SLIST_SWAP, SLIST_INIT, SLIST_EMPTY, SLIST_REMOVE_HEAD, SLIST_REMOVE_AFTER, SLIST_REMOVE, SLIST_INSERT_HEAD, SLIST_INSERT_AFTER, SLIST_INSERT_TAIL — singly linked list macros

LIBRARY

Base definitions

SYNOPSIS

#include <sys/queue.h>

DESCRIPTION

These macros provide an implementation of singly linked lists. They are designed to be used within your own data structures.

A singly linked list is a collection of elements, each of which contains a pointer to the next element. The last element points to NULL.

The macros operate on structures that contain a pointer member, typically named field, which is used to link the elements together.

The following macros are available:

  • SLIST_HEAD(name, type): Declares a singly linked list head of the specified type, named name.
  • SLIST_HEAD_INITIALIZER(head): Returns an initializer for an empty list head.
  • SLIST_ENTRY(type): Declares a singly linked list entry of the specified type.
  • SLIST_INIT(head): Initializes an empty list head.
  • SLIST_EMPTY(head): Returns true if the list is empty.
  • SLIST_FIRST(head): Returns a pointer to the first element in the list.
  • SLIST_NEXT(elm, field): Returns a pointer to the next element after elm, using field as the next pointer.
  • SLIST_FOREACH(var, head, field): Iterates over the list, assigning each element to var.
  • SLIST_FOREACH_SAFE(var, var_safe, head, field): Similar to SLIST_FOREACH, but safe for removal of elements during iteration.
  • SLIST_INSERT_HEAD(head, elm, field): Inserts elm at the head of the list.
  • SLIST_INSERT_TAIL(head, elm, field): Inserts elm at the tail of the list.
  • SLIST_INSERT_AFTER(listelm, elm, field): Inserts elm after listelm.
  • SLIST_REMOVE_HEAD(head, field): Removes the first element from the list.
  • SLIST_REMOVE(head, elm, type, field): Removes elm from the list.
  • SLIST_REMOVE_AFTER(elm, field): Removes the element after elm.
  • SLIST_SWAP(head1, head2, type): Swaps the contents of two list heads.
  • SLIST_FIND_IF(var, head, field, predicate): Finds the first element satisfying the predicate.
  • SLIST_FIND_IF_PREV(var, prev, head, field, predicate): Finds the element before the first element satisfying the predicate.

RETURN VALUE

The macros do not return values in the traditional sense, but modify the list structure or return pointers to list elements.

STANDARDS

These macros are part of the BSD operating systems and are not part of any official standards.

HISTORY

These macros first appeared in 4.4BSD.

BUGS

None known.

EXAMPLES

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct item {
    int value;
    SLIST_ENTRY(item) next;
};

int
main(void) {
    SLIST_HEAD(mylist, item) head;
    struct item *item;
    struct item *item_temp;

    SLIST_INIT(&head);

    item = malloc(sizeof(struct item));
    item->value = 10;
    SLIST_INSERT_HEAD(&head, item, next);

    item = malloc(sizeof(struct item));
    item->value = 20;
    SLIST_INSERT_TAIL(&head, item, next);

    item = malloc(sizeof(struct item));
    item->value = 30;
    SLIST_INSERT_AFTER(head.slh_first, item, next); /* Insert after first element */

    printf("List elements:\n");
    SLIST_FOREACH(item, &head, next) {
        printf("%d\n", item->value);
    }

    while (!SLIST_EMPTY(&head)) {
        item = SLIST_FIRST(&head);
        SLIST_REMOVE_HEAD(&head, next);
        free(item);
    }

    return 0;
}
