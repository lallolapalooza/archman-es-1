SLIST(3) Manual de funciones de biblioteca SLIST(3)

NOMBRE

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - implementación de una lista enlazada simple

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
SLIST_ENTRY(TIPO);
SLIST_HEAD(NOMBRE_DE_CABECERA, TIPO);
SLIST_HEAD NOMBRE_DE_CABECERA_INICIALIZADOR(SLIST_HEAD cabecera);
void SLIST_INIT(SLIST_HEAD *cabecera);
int SLIST_EMPTY(SLIST_HEAD *cabecera);
void SLIST_INSERT_HEAD(SLIST_HEAD *cabecera,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
void SLIST_INSERT_AFTER(struct TIPO *elem_lista,
                        struct TIPO *elem, SLIST_ENTRY NOMBRE);
struct TIPO *SLIST_FIRST(SLIST_HEAD *cabecera);
struct TIPO *SLIST_NEXT(struct TIPO *elem, SLIST_ENTRY NOMBRE);
SLIST_FOREACH(struct TIPO *var, SLIST_HEAD *cabecera, SLIST_ENTRY NOMBRE);
void SLIST_REMOVE(SLIST_HEAD *cabecera, struct TIPO *elem, TIPO,
                        SLIST_ENTRY NOMBRE);
void SLIST_REMOVE_HEAD(SLIST_HEAD *cabecera,
                        SLIST_ENTRY NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre listas enlazadas simples.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo SLIST_ENTRY, llamado NOMBRE. El argumento NOMBRE_DE_CABECERA es el nombre de una estructura definida por el usuario que debe ser declarada utilizando la macro SLIST_HEAD().

Creación

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:


SLIST_HEAD(NOMBRE_DE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_DE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la lista. Un puntero a la cabecera de la lista puede ser declarado posteriormente como:


struct NOMBRE_DE_CABECERA *puntero_cabecera;

(Los nombres cabecera y puntero_cabecera son seleccionables por el usuario.)

SLIST_ENTRY() declara una estructura que conecta los elementos en la lista.

SLIST_HEAD_INITIALIZER() evalúa a un inicializador para la lista cabecera.

SLIST_INIT() inicializa la lista referenciada por cabecera.

SLIST_EMPTY() evalúa a verdadero si no hay elementos en la lista.

Inserción

SLIST_INSERT_HEAD() inserta el nuevo elemento elem al principio de la lista.

SLIST_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

SLIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

SLIST_NEXT() devuelve el siguiente elemento de la lista.

SLIST_FOREACH() recorre la lista referenciada por cabecera en dirección hacia adelante, asignando cada elemento por vez a var.

Eliminación

SLIST_REMOVE() elimina el elemento elem de la lista.

SLIST_REMOVE_HEAD() elimina el elemento elem del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE().

VALOR DE RETORNO

SLIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía, y cero si la lista contiene al menos una entrada.

SLIST_FIRST() y SLIST_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

SLIST_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la lista cabecera.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ERRORES

SLIST_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. SLIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, corrige esta limitación permitiendo que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    SLIST_ENTRY(entrada) entradas;             /* Lista enlazada simple */
};
SLIST_HEAD(cabecera_lista_simple, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabecera_lista_simple cabecera;                  /* Cabecera de
                                               lista enlazada simple */
    SLIST_INIT(&cabecera);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    SLIST_INSERT_HEAD(&cabecera, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    SLIST_INSERT_AFTER(n1, n2, entradas);
    SLIST_REMOVE(&cabecera, n2, entrada, entradas);/* Eliminación */
    free(n2);
    n3 = SLIST_FIRST(&cabecera);
    SLIST_REMOVE_HEAD(&cabecera, entradas);      /* Eliminación del principio */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        SLIST_INSERT_HEAD(&cabecera, n1, entradas);
        n1->datos = i;
    }
                                            /* Recorrido hacia adelante */
    SLIST_FOREACH(np, &cabecera, entradas)
        printf("%i\n", np->datos);
    while (!SLIST_EMPTY(&cabecera)) {           /* Eliminación de la lista */
        n1 = SLIST_FIRST(&cabecera);
        SLIST_REMOVE_HEAD(&cabecera, entradas);
        free(n1);
    }
    SLIST_INIT(&cabecera);
    exit(EXIT_SUCCESS);
}
