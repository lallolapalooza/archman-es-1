DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser utilizadas tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simples
  3. Colas de cola enlazadas simples
  4. Colas de cola
Las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de una nueva entrada al principio de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento de la lista.
  3. Eliminación O(1) de una entrada del principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más sencillas de las cuatro estructuras de datos y solo soportan la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO (Last-In, First-Out). Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación O(n) de cualquier entrada de la lista.
  2. Concatenación O(n) de dos listas.

Las colas de cola enlazadas simples añaden la siguiente funcionalidad:

  1. Se pueden añadir entradas al final de una lista.
  2. Eliminación O(n) de cualquier entrada de la lista.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lento que las listas enlazadas simples.

Las colas de cola enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO (First-In, First-Out).

Todos los tipos de estructuras de datos doblemente enlazadas (listas y colas de cola) permiten adicionalmente:

  1. Inserción de una nueva entrada antes de cualquier elemento de la lista.
  2. Eliminación O(1) de cualquier entrada de la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que el de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más sencillas de las estructuras de datos doblemente enlazadas. Añaden la siguiente funcionalidad sobre lo anterior:

  1. Concatenación O(n) de dos listas.
  2. Pueden ser recorridas hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para iniciar el recorrido y la lista en la que está contenida.

Las colas de cola añaden la siguiente funcionalidad:

  1. Se pueden añadir entradas al final de una lista.
  2. Pueden ser recorridas hacia atrás, de cola a cabeza.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lento que las listas enlazadas simples.

En las definiciones de macro, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que es del tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de macro, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que es del tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe ser declarada usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Ver los ejemplos a continuación para una explicación más detallada de cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados simplemente para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista puede declararse más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe utilizar una cola de cola enlazada simple si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí se permite tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento en la lista después de elm.

La macro SLIST_REMOVE elimina la entrada elm de la lista.

La macro SLIST_SWAP intercambia las listas encabezadas por head1 y head2.

COLAS DE COLA

Las colas de cola son listas doblemente enlazadas que permiten la inserción O(1) al principio y al final de la lista. Las colas de cola están encabezadas por una estructura definida por la macro TAILQ_HEAD. Esta estructura contiene dos punteros, uno al primer elemento de la lista y otro al último. El uso de dos punteros en la cabeza de la lista permite inserciones y eliminaciones O(1) en ambos extremos de la lista. Los elementos de la cola de cola se definen usando la macro TAILQ_ENTRY.

Una estructura de cola de cola se define como:

TAILQ_HEAD(HEADNAME, TYPE);

donde HEADNAME es el nombre de la estructura de la cabeza, y TYPE es el tipo de elemento que se va a enlazar. Un puntero a la cabeza de la cola de cola puede declararse como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de cola head.

La macro TAILQ_INIT inicializa la cola de cola referenciada por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de cola.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de cola.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_REMOVE elimina la entrada elm de la cola de cola.

La macro TAILQ_FOREACH recorre la cola de cola referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_SAFE recorre la cola de cola referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de TAILQ_FOREACH, aquí se permite tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_LAST devuelve el último elemento de la cola de cola referenciada por head.

La macro TAILQ_NEXT devuelve el siguiente elemento en la cola de cola después de elm.

La macro TAILQ_PREV devuelve el elemento anterior en la cola de cola antes de elm.

La macro TAILQ_CONCAT concatena la cola de cola referenciada por head2 al final de la cola de cola referenciada por head1, eliminando todas las entradas de la primera. El uso de esta macro debe ser evitado ya que recorre la totalidad de la lista head1. Se debe utilizar una cola de cola enlazada simple si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro TAILQ_SWAP intercambia las colas de cola referenciadas por head1 y head2.

LISTAS SIMPLES

Una lista simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden agregar a la lista después de un elemento existente, o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro SLIST_EMPTY se evalúa como verdadera si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro SLIST_FOREACH_FROM se comporta de manera idéntica a SLIST_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí se permite tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento después de elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro, ya que recorre toda la lista. Se debe usar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Cabeza de lista simple. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Lista simple. */
	...
} *n1, *n2, *n3, *np;

COLAS CON PUNTA DE LISTAS SIMPLES

Una cola con punta de lista simple está encabezada por una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola con punta y otro al último elemento de la cola con punta. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden agregar a la cola con punta después de un elemento existente, al principio de la cola con punta o al final de la cola con punta. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá y TYPE es el tipo de los elementos que se enlazarán en la cola con punta. Un puntero a la cabeza de la cola con punta se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro STAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola con punta head.

La macro STAILQ_CONCAT concatena la cola con punta encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY se evalúa como verdadera si no hay elementos en la cola con punta.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola con punta.

La macro STAILQ_FIRST devuelve el primer elemento de la cola con punta o NULL si la cola con punta está vacía.

La macro STAILQ_FOREACH recorre la cola con punta referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola con punta referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí se permite tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola con punta referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola con punta.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola con punta.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola con punta. Si la cola con punta está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola con punta, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola con punta. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola con punta.

La macro STAILQ_REMOVE_HEAD elimina el elemento del principio de la cola con punta. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola con punta deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola con punta. Se debe evitar el uso de esta macro, ya que recorre toda la lista. Se debe usar una cola con punta doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas con punta largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

A singly linked list is headed by a structure defined by the LIST_HEAD macro. This structure contains a pointer to the first element in the list. The elements are singly linked so that an arbitrary element can be removed, but only if the pointer to the previous element is known. New elements can be added to the list before or after an existing element, or at the head of the list. A LIST_HEAD structure is declared as follows:

LIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro LIST_ENTRY declares a structure that connects the elements in the list.

The macro LIST_FIRST returns the first element on the list, or NULL if the list is empty.

The macro LIST_INSERT_HEAD inserts the element elm at the head of the list.

The macro LIST_INSERT_AFTER inserts the element elm after the element listelm.

The macro LIST_INSERT_BEFORE inserts the element elm before the element listelm.

The macro LIST_NEXT returns the next element in the list, or NULL if this is the last.

The macro LIST_REMOVE removes the element elm from the list.

The macro LIST_SWAP swaps the contents of head1 and head2.

The macro LIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro LIST_FOREACH_FROM behaves identically to LIST_FOREACH when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike LIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro LIST_FOREACH_FROM_SAFE behaves identically to LIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_INIT initializes the list referenced by head.

The macro LIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro LIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro LIST_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro LIST_NEXT returns the next element in the list, or NULL if this is the last.

The macro LIST_PREV returns the previous element in the list, or NULL if this is the first. List head must contain element elm.

The macro LIST_REMOVE removes the element elm from the list.

The macro LIST_SWAP swaps the contents of head1 and head2.

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are doubly linked so that an arbitrary element can be removed without traversing the tail queue. New elements can be added to the tail queue after an existing element, before an existing element, at the head of the tail queue, or at the end of the tail queue. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro TAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro TAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro TAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro TAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro TAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. var is set to NULL if the loop completes normally, or if there were no elements.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE traverses the tail queue referenced by head in the reverse direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_REVERSE_FROM behaves identically to TAILQ_FOREACH_REVERSE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macros TAILQ_FOREACH_SAFE and TAILQ_FOREACH_REVERSE_SAFE traverse the list referenced by head in the forward or reverse direction respectively, assigning each element in turn to var. However, unlike their unsafe counterparts, TAILQ_FOREACH and TAILQ_FOREACH_REVERSE make it possible to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE_FROM_SAFE behaves identically to TAILQ_FOREACH_REVERSE_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macro TAILQ_INIT initializes the tail queue referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro TAILQ_NEXT returns the next item on the tail queue, or NULL if this item is the last.

The macro TAILQ_PREV returns the previous item on the tail queue, or NULL if this item is the first.

The macro TAILQ_REMOVE removes the element elm from the tail queue.

The macro TAILQ_SWAP swaps the contents of head1 and head2.

NAME

TAILQ_INIT, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_REMOVE, TAILQ_REPLACE, TAILQ_PREPEND, TAILQ_NEXT, TAILQ_PREV, TAILQ_FIRST, TAILQ_LAST, TAILQ_END, TAILQ_PREV_FROM_END, TAILQ_EMPTY, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_FOREACH_SAFE, TAILQ_FOREACH_REVERSE_SAFE, TAILQ_SWAP — tail queue macros

LIBRARY

libbsd

SYNOPSIS

#include <sys/queue.h>

DESCRIPTION

These macros provide an implementation of tail queues. Tail queues are doubly-linked lists that have the additional property that the last element can be accessed in constant time. All tail queue operations are O(1).

A tail queue is defined by the user. The user must also define the structure that will be placed in the queue. This structure must contain a field of type ‘struct’ ‘tailq_entry’, which will be used to link the structure in the queue. Let's call the structure ‘my_list_t’ and the entry field ‘my_list_entry’.

A tail queue head is declared as:

struct my_list_head {
    struct my_list_t *tqh_first;
    struct my_list_t **tqh_last;
};

And the entry structure is declared as:

struct my_list_t {
    struct my_list_t *le_next;
    struct my_list_t **le_prev;
};

Or, more generally:

#define TAILQ_HEAD(name, type) \
struct name { \
    struct type *tqh_first;    \
    struct type **tqh_last;    \
}; \
\
#define TAILQ_ENTRY(type) \
struct { \
    struct type *le_next;      \
    struct type **le_prev;     \
}

A variable ‘head’ of type ‘struct’ ‘my_list_head’ can be initialized using the TAILQ_INIT() macro.

The macros are:

  • TAILQ_INIT(head)
    Initialize the tail queue pointed to by head.
  • TAILQ_INSERT_HEAD(head, elm, field)
    Insert the element elm at the head of the tail queue. field is the name of the tail queue entry field in the element structure.
  • TAILQ_INSERT_TAIL(head, elm, field)
    Insert the element elm at the tail of the tail queue.
  • TAILQ_INSERT_AFTER(head, listelm, elm, field)
    Insert the element elm after the element listelm in the tail queue.
  • TAILQ_INSERT_BEFORE(head, listelm, elm, field)
    Insert the element elm before the element listelm in the tail queue.
  • TAILQ_REMOVE(head, elm, field)
    Remove the element elm from the tail queue.
  • TAILQ_REPLACE(head, elm, elm2, field)
    Replace the element elm with the element elm2.
  • TAILQ_PREPEND(head, elm, field)
    Insert the element elm at the head of the tail queue. This is a synonym for TAILQ_INSERT_HEAD.
  • TAILQ_NEXT(elm, field)
    Return a pointer to the next element in the tail queue.
  • TAILQ_PREV(elm, head, type)
    Return a pointer to the previous element in the tail queue. head is the name of the tail queue head structure, and type is the name of the element structure.
  • TAILQ_FIRST(head)
    Return a pointer to the first element in the tail queue.
  • TAILQ_LAST(head, type)
    Return a pointer to the last element in the tail queue. type is the name of the element structure.
  • TAILQ_END(head)
    Return a pointer to the end of the tail queue. This is used for iteration.
  • TAILQ_PREV_FROM_END(head, type)
    Return a pointer to the last element in the tail queue, if the queue is not empty. type is the name of the element structure.
  • TAILQ_EMPTY(head)
    Return true if the tail queue is empty, false otherwise.
  • TAILQ_FOREACH(var, head)
    Iterate over the elements in the tail queue. var will point to each element in turn.
  • TAILQ_FOREACH_REVERSE(var, head)
    Iterate over the elements in the tail queue in reverse order. var will point to each element in turn.
  • TAILQ_FOREACH_SAFE(var, head, nextvar)
    A safe version of TAILQ_FOREACH. The loop variable var is advanced to the next element using TAILQ_NEXT and stored in nextvar before the loop body is executed. This allows the loop body to safely remove the current element var from the queue.
  • TAILQ_FOREACH_REVERSE_SAFE(var, head, prevvar)
    A safe version of TAILQ_FOREACH_REVERSE. The loop variable var is advanced to the previous element using TAILQ_PREV and stored in prevvar before the loop body is executed. This allows the loop body to safely remove the current element var from the queue.
  • TAILQ_SWAP(head1, head2, type)
    Swap the contents of the tail queues head1 and head2. type is the name of the element structure.

SINGLY-LINKED LISTS

The SLIST_* macros provide an implementation of singly-linked lists.

A singly-linked list is defined by the user. The user must also define the structure that will be placed in the list. This structure must contain a field of type ‘struct’ ‘slist_entry’, which will be used to link the structure in the list. Let's call the structure ‘my_list_t’ and the entry field ‘my_list_entry’.

A singly-linked list head is declared as:

struct my_list_head {
    struct my_list_t *slh_first;

struct my_list_t {
    struct my_list_t *sl_next;
};

    struct type *slh_first; \

A variable ‘head’ of type ‘struct’ ‘my_list_head’ can be initialized using the SLIST_INIT() macro.

The macros are:

  • SLIST_INIT(head)
    Initialize the singly-linked list pointed to by head.
  • SLIST_INSERT_HEAD(head, elm, field)
    Insert the element elm at the head of the singly-linked list. field is the name of the singly-linked list entry field in the element structure.
  • SLIST_INSERT_AFTER(listelm, elm, field)
    Insert the element elm after the element listelm in the singly-linked list.
  • SLIST_REMOVE_HEAD(head, field)
    Remove the head element from the singly-linked list. field is the name of the singly-linked list entry field in the element structure.
  • SLIST_REMOVE(head, elm, field)
    Remove the element elm from the singly-linked list.

  • SLIST_NEXT(elm, field)
    Return a pointer to the next element in the singly-linked list.

  • SLIST_FOREACH(var, head)
    Iterate over the elements in the singly-linked list. var will point to each element in turn.
  • SLIST_FOREACH_SAFE(var, head, nextvar)

    int data;

    entry2->data = 20;
    SLIST_INSERT_HEAD(&my_list, entry2, pointers);

    entry3->data = 30;

    printf("List contents:\n");
    SLIST_FOREACH(current, &my_list) {
        printf("%d\n", current->data);
    }

    SLIST_REMOVE(&my_list, entry2, my_entry, pointers);
    free(entry2);

    SLIST_FOREACH_SAFE(current, &my_list, tmp) {
        SLIST_REMOVE(&my_list, current, my_entry, pointers);
        free(current);
    }

    return 0;
}

SINGLY-LINKED TAIL QUEUES

The STLQ_* macros provide an implementation of singly-linked tail queues.

A singly-linked tail queue is defined by the user. The user must also define the structure that will be placed in the queue. This structure must contain a field of type ‘struct’ ‘stq_entry’, which will be used to link the structure in the queue. Let's call the structure ‘my_list_t’ and the entry field ‘my_list_entry’.

A singly-linked tail queue head is declared as:

struct my_list_head {
    struct my_list_t *stqh_first;
    struct my_list_t **stqh_last;
};

And the entry structure is declared as:

struct my_list_t {
    struct my_list_t *stq_next;
    struct my_list_t **stq_prev;
};

Or, more generally:

#define STQ_HEAD(name, type) \
struct name { \
    struct type *stqh_first; \
    struct type **stqh_last; \
}; \
\
#define STQ_ENTRY(type) \
struct { \
    struct type *stq_next; \
    struct type **stq_prev; \
}

A variable ‘head’ of type ‘struct’ ‘my_list_head’ can be initialized using the STQ_INIT() macro.

The macros are:

  • STQ_INIT(head)
    Initialize the singly-linked tail queue pointed to by head.
  • STQ_INSERT_HEAD(head, elm, field)
    Insert the element elm at the head of the singly-linked tail queue. field is the name of the singly-linked tail queue entry field in the element structure.
  • STQ_INSERT_TAIL(head, elm, field)
    Insert the element elm at the tail of the singly-linked tail queue.
  • STQ_REMOVE_HEAD(head, field)
    Remove the head element from the singly-linked tail queue. field is the name of the singly-linked tail queue entry field in the element structure.
  • STQ_REMOVE(head, elm, field)
    Remove the element elm from the singly-linked tail queue.
  • STQ_FIRST(head)
    Return a pointer to the first element in the singly-linked tail queue.
  • STQ_LAST(head, type)
    Return a pointer to the last element in the singly-linked tail queue. type is the name of the element structure.
  • STQ_NEXT(elm, field)
    Return a pointer to the next element in the singly-linked tail queue.
  • STQ_EMPTY(head)
    Return true if the singly-linked tail queue is empty, false otherwise.
  • STQ_FOREACH(var, head)
    Iterate over the elements in the singly-linked tail queue. var will point to each element in turn.
  • STQ_FOREACH_SAFE(var, head, nextvar)
    A safe version of STQ_FOREACH. The loop variable var is advanced to the next element using STQ_NEXT and stored in nextvar before the loop body is executed. This allows the loop body to safely remove the current element var from the queue.

SINGLY-LINKED TAIL QUEUE EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_entry {
    int data;
    STQ_ENTRY(my_entry) pointers;
};

int
main(void) {
    struct my_head {
        struct my_entry *stqh_first;
        struct my_entry **stqh_last;
    } my_list;
    struct my_entry *current;
    struct my_entry *tmp;

    STQ_INIT(&my_list);

    /* Create and add elements */
    struct my_entry *entry1 = malloc(sizeof(struct my_entry));
    entry1->data = 10;
    STQ_INSERT_HEAD(&my_list, entry1, pointers);

    struct my_entry *entry2 = malloc(sizeof(struct my_entry));
    entry2->data = 20;
    STQ_INSERT_TAIL(&my_list, entry2, pointers);

    /* Iterate and print */
    printf("Queue contents:\n");
    STQ_FOREACH(current, &my_list) {
        printf("%d\n", current->data);
    }

    /* Remove elements */
    STQ_REMOVE_HEAD(&my_list, pointers);
    free(entry1);

    STQ_FOREACH_SAFE(current, &my_list, tmp) {
        STQ_REMOVE(&my_list, current, pointers);
        free(current);
    }

    return 0;
}

LISTS

The LIST_* macros provide an implementation of doubly-linked lists.

A doubly-linked list is defined by the user. The user must also define the structure that will be placed in the list. This structure must contain a field of type ‘struct’ ‘list_entry’, which will be used to link the structure in the list. Let's call the structure ‘my_list_t’ and the entry field ‘my_list_entry’.

A doubly-linked list head is declared as:

struct my_list_head {
    struct my_list_t *list_first;
};

And the entry structure is declared as:

struct my_list_t {
    struct my_list_t *le_next;
    struct my_list_t *le_prev;
};

Or, more generally:

#define LIST_HEAD(name, type) \
struct name { \
    struct type *list_first; \
}; \
\
#define LIST_ENTRY(type) \
struct { \
    struct type *le_next; \
    struct type *le_prev; \
}

A variable ‘head’ of type ‘struct’ ‘my_list_head’ can be initialized using the LIST_INIT() macro.

The macros are:

  • LIST_INIT(head)
    Initialize the doubly-linked list pointed to by head.
  • LIST_INSERT_HEAD(head, elm, field)
    Insert the element elm at the head of the doubly-linked list. field is the name of the doubly-linked list entry field in the element structure.
  • LIST_INSERT_TAIL(head, elm, field)
    Insert the element elm at the tail of the doubly-linked list.
  • LIST_INSERT_AFTER(listelm, elm, field)
    Insert the element elm after the element listelm in the doubly-linked list.
  • LIST_INSERT_BEFORE(listelm, elm, field)
    Insert the element elm before the element listelm in the doubly-linked list.
  • LIST_REMOVE(head, elm, field)
    Remove the element elm from the doubly-linked list.
  • LIST_REPLACE(head, elm, elm2, field)
    Replace the element elm with the element elm2.
  • LIST_FIRST(head)
    Return a pointer to the first element in the doubly-linked list.
  • LIST_NEXT(elm, field)
    Return a pointer to the next element in the doubly-linked list.
  • LIST_PREV(elm, field)
    Return a pointer to the previous element in the doubly-linked list.
  • LIST_EMPTY(head)
    Return true if the doubly-linked list is empty, false otherwise.
  • LIST_FOREACH(var, head)
    Iterate over the elements in the doubly-linked list. var will point to each element in turn.
  • LIST_FOREACH_REVERSE(var, head)
    Iterate over the elements in the doubly-linked list in reverse order. var will point to each element in turn.
  • LIST_FOREACH_SAFE(var, head, nextvar)
    A safe version of LIST_FOREACH. The loop variable var is advanced to the next element using LIST_NEXT and stored in nextvar before the loop body is executed. This allows the loop body to safely remove the current element var from the list.
  • LIST_FOREACH_REVERSE_SAFE(var, head, prevvar)
    A safe version of LIST_FOREACH_REVERSE. The loop variable var is advanced to the previous element using LIST_PREV and stored in prevvar before the loop body is executed. This allows the loop body to safely remove the current element var from the list.
  • LIST_SWAP(head1, head2, type)
    Swap the contents of the doubly-linked lists head1 and head2. type is the name of the element structure.

LIST EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_entry {
    int data;
    LIST_ENTRY(my_entry) pointers;
};

int
main(void) {
    struct my_head {
        struct my_entry *list_first;
    } my_list;
    struct my_entry *current, *tmp;

    LIST_INIT(&my_list);

    /* Create and add elements */
    struct my_entry *entry1 = malloc(sizeof(struct my_entry));
    entry1->data = 10;
    LIST_INSERT_HEAD(&my_list, entry1, pointers);

    struct my_entry *entry2 = malloc(sizeof(struct my_entry));
    entry2->data = 20;
    LIST_INSERT_TAIL(&my_list, entry2, pointers);

    struct my_entry *entry3 = malloc(sizeof(struct my_entry));
    entry3->data = 30;
    LIST_INSERT_AFTER(entry1, entry3, pointers);

    /* Iterate and print */
    printf("List contents (forward):\n");
    LIST_FOREACH(current, &my_list) {
        printf("%d\n", current->data);
    }

    printf("List contents (reverse):\n");
    struct my_entry **prev_ptr = NULL; // Needed for LIST_PREV_FROM_END
    LIST_FOREACH_REVERSE(current, &my_list) {
         printf("%d\n", current->data);
    }

    /* Remove elements */
    LIST_REMOVE(entry1, pointers);
    free(entry1);

    LIST_FOREACH_SAFE(current, &my_list, tmp) {
        LIST_REMOVE(&my_list, current, pointers);
        free(current);
    }

    return 0;
}

TAIL QUEUES

The TAILQ_* macros provide an implementation of tail queues. Tail queues are doubly-linked lists that have the additional property that the last element can be accessed in constant time. All tail queue operations are O(1).

A tail queue is defined by the user. The user must also define the structure that will be placed in the queue. This structure must contain a field of type ‘struct’ ‘tailq_entry’, which will be used to link the structure in the queue. Let's call the structure ‘my_list_t’ and the entry field ‘my_list_entry’.

A tail queue head is declared as:

struct my_list_head {
    struct my_list_t *tqh_first;
    struct my_list_t **tqh_last;
};

And the entry structure is declared as:

struct my_list_t {
    struct my_list_t *le_next;
    struct my_list_t **le_prev;
};

Or, more generally:

#define TAILQ_HEAD(name, type) \
struct name { \
    struct type *tqh_first;    \
    struct type **tqh_last;    \
}; \
\
#define TAILQ_ENTRY(type) \
struct { \
    struct type *le_next;      \
    struct type **le_prev;     \
}

A variable ‘head’ of type ‘struct’ ‘my_list_head’ can be initialized using the TAILQ_INIT() macro.

The macros are:

  • TAILQ_INIT(head)
    Initialize the tail queue pointed to by head.
  • TAILQ_INSERT_HEAD(head, elm, field)
    Insert the element elm at the head of the tail queue. field is the name of the tail queue entry field in the element structure.
  • TAILQ_INSERT_TAIL(head, elm, field)
    Insert the element elm at the tail of the tail queue.
  • TAILQ_INSERT_AFTER(head, listelm, elm, field)
    Insert the element elm after the element listelm in the tail queue.
  • TAILQ_INSERT_BEFORE(head, listelm, elm, field)
    Insert the element elm before the element listelm in the tail queue.
  • TAILQ_REMOVE(head, elm, field)
    Remove the element elm from the tail queue.
  • TAILQ_REPLACE(head, elm, elm2, field)
    Replace the element elm with the element elm2.
  • TAILQ_PREPEND(head, elm, field)
    Insert the element elm at the head of the tail queue. This is a synonym for TAILQ_INSERT_HEAD.
  • TAILQ_NEXT(elm, field)
    Return a pointer to the next element in the tail queue.
  • TAILQ_PREV(elm, head, type)
    Return a pointer to the previous element in the tail queue. head is the name of the tail queue head structure, and type is the name of the element structure.
  • TAILQ_FIRST(head)
    Return a pointer to the first element in the tail queue.
  • TAILQ_LAST(head, type)
    Return a pointer to the last element in the tail queue. type is the name of the element structure.
  • TAILQ_END(head)
    Return a pointer to the end of the tail queue. This is used for iteration.
  • TAILQ_PREV_FROM_END(head, type)
    Return a pointer to the last element in the tail queue, if the queue is not empty. type is the name of the element structure.
  • TAILQ_EMPTY(head)
    Return true if the tail queue is empty, false otherwise.
  • TAILQ_FOREACH(var, head)
    Iterate over the elements in the tail queue. var will point to each element in turn.
  • TAILQ_FOREACH_REVERSE(var, head)
    Iterate over the elements in the tail queue in reverse order. var will point to each element in turn.
  • TAILQ_FOREACH_SAFE(var, head, nextvar)
    A safe version of TAILQ_FOREACH. The loop variable var is advanced to the next element using TAILQ_NEXT and stored in nextvar before the loop body is executed. This allows the loop body to safely remove the current element var from the queue.
  • TAILQ_FOREACH_REVERSE_SAFE(var, head, prevvar)
    A safe version of TAILQ_FOREACH_REVERSE. The loop variable var is advanced to the previous element using TAILQ_PREV and stored in prevvar before the loop body is executed. This allows the loop body to safely remove the current element var from the queue.
  • TAILQ_SWAP(head1, head2, type)
    Swap the contents of the tail queues head1 and head2. type is the name of the element structure.

TAIL QUEUE EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_entry {
    int data;
    TAILQ_ENTRY(my_entry) pointers;
};

int
main(void) {
    struct my_head {
        struct my_entry *tqh_first;
        struct my_entry **tqh_last;
    } my_list;
    struct my_entry *current, *tmp;

    TAILQ_INIT(&my_list);

    /* Create and add elements */
    struct my_entry *entry1 = malloc(sizeof(struct my_entry));
    entry1->data = 10;
    TAILQ_INSERT_HEAD(&my_list, entry1, pointers);

    struct my_entry *entry2 = malloc(sizeof(struct my_entry));
    entry2->data = 20;
    TAILQ_INSERT_TAIL(&my_list, entry2, pointers);

    struct my_entry *entry3 = malloc(sizeof(struct my_entry));
    entry3->data = 30;
    TAILQ_INSERT_AFTER(&my_list, entry1, entry3, pointers);

    /* Iterate and print */
    printf("Queue contents (forward):\n");
    TAILQ_FOREACH(current, &my_list) {
        printf("%d\n", current->data);
    }

    printf("Queue contents (reverse):\n");
    TAILQ_FOREACH_REVERSE(current, &my_list) {
         printf("%d\n", current->data);
    }

    /* Remove elements */
    TAILQ_REMOVE(&my_list, entry1, pointers);
    free(entry1);

    TAILQ_FOREACH_SAFE(current, &my_list, tmp) {
        TAILQ_REMOVE(&my_list, current, pointers);
        free(current);
    }

    return 0;
}

DIAGNOSTICS

When debugging queue(3), it can be useful to trace queue changes. To enable tracing, define the macro QUEUE_MACRO_DEBUG_TRACE at compile time.

It can also be useful to trash pointers that have been unlinked from a queue, to detect use after removal. To enable pointer trashing, define the macro QUEUE_MACRO_DEBUG_TRASH at compile time. The macro QMD_IS_TRASHED(void *ptr) returns true if ptr has been trashed by the QUEUE_MACRO_DEBUG_TRASH option.
