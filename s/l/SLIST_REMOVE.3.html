SLIST(3) Manual de funciones de biblioteca SLIST(3)

NOMBRE

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - implementación de una lista enlazada simple

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <sys/queue.h>
SLIST_ENTRY(TYPE);
SLIST_HEAD(HEADNAME, TYPE);
SLIST_HEAD SLIST_HEAD_INITIALIZER(SLIST_HEAD head);
void SLIST_INIT(SLIST_HEAD *head);
int SLIST_EMPTY(SLIST_HEAD *head);
void SLIST_INSERT_HEAD(SLIST_HEAD *head,
                        struct TYPE *elm, SLIST_ENTRY NAME);
void SLIST_INSERT_AFTER(struct TYPE *listelm,
                        struct TYPE *elm, SLIST_ENTRY NAME);
struct TYPE *SLIST_FIRST(SLIST_HEAD *head);
struct TYPE *SLIST_NEXT(struct TYPE *elm, SLIST_ENTRY NAME);
SLIST_FOREACH(struct TYPE *var, SLIST_HEAD *head, SLIST_ENTRY NAME);
void SLIST_REMOVE(SLIST_HEAD *head, struct TYPE *elm, TYPE,
                        SLIST_ENTRY NAME);
void SLIST_REMOVE_HEAD(SLIST_HEAD *head,
                        SLIST_ENTRY NAME);

DESCRIPCIÓN

Estas macros definen y operan sobre listas enlazadas simples.

En las definiciones de las macros, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo SLIST_ENTRY, llamado NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando la macro SLIST_HEAD().

Creación

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para minimizar el uso de espacio y la manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Se pueden agregar nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:


SLIST_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura que se definirá, y struct TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar posteriormente como:


struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

SLIST_ENTRY() declara una estructura que conecta los elementos de la lista.

SLIST_HEAD_INITIALIZER() se evalúa como un inicializador para la lista head.

SLIST_INIT() inicializa la lista referenciada por head.

SLIST_EMPTY() se evalúa como verdadero si no hay elementos en la lista.

Inserción

SLIST_INSERT_HEAD() inserta el nuevo elemento elm al principio de la lista.

SLIST_INSERT_AFTER() inserta el nuevo elemento elm después del elemento listelm.

Recorrido

SLIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

SLIST_NEXT() devuelve el siguiente elemento de la lista.

SLIST_FOREACH() recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento a su vez a var.

Eliminación

SLIST_REMOVE() elimina el elemento elm de la lista.

SLIST_REMOVE_HEAD() elimina el elemento elm del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deberían usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE().

VALOR DE RETORNO

SLIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía, y cero si la lista contiene al menos una entrada.

SLIST_FIRST() y SLIST_NEXT() devuelven un puntero a la estructura TYPE, ya sea la primera o la siguiente, respectivamente.

SLIST_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la lista head.

ESTÁNDARES

BSD.

HISTORIAL

4.4BSD.

ERRORES

SLIST_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. SLIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    SLIST_ENTRY(entry) entries;             /* Lista enlazada simple */
};
SLIST_HEAD(slisthead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct slisthead head;                  /* Cabeza de lista enlazada
                                               simple */
    SLIST_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    SLIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    SLIST_INSERT_AFTER(n1, n2, entries);
    SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación */
    free(n2);
    n3 = SLIST_FIRST(&head);
    SLIST_REMOVE_HEAD(&head, entries);      /* Eliminación desde el principio */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        SLIST_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
                                            /* Recorrido hacia adelante */
    SLIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
    while (!SLIST_EMPTY(&head)) {           /* Eliminación de la lista */
        n1 = SLIST_FIRST(&head);
        SLIST_REMOVE_HEAD(&head, entries);
        free(n1);
    }
    SLIST_INIT(&head);
    exit(EXIT_SUCCESS);
}
