DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden usarse tanto en código fuente C como C++: listas, listas doblemente enlazadas, listas de cola doblemente enlazadas y colas de cola.

  1. Lista
  2. Lista doblemente enlazada
  3. Lista de cola doblemente enlazada
  4. Cola de cola

Las cuatro estructuras soportan la siguiente funcionalidad:

  1. Inserción de una nueva entrada al frente de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento de la lista.
  3. Eliminación de una entrada del frente de la lista en O(1).
  4. Recorrido hacia adelante de la lista.
  5. Intercambio de los contenidos de dos listas.

Las listas doblemente enlazadas son las más simples de las cuatro estructuras y solo soportan la funcionalidad mencionada. Las listas doblemente enlazadas son ideales para aplicaciones con grandes cantidades de datos y pocas o ninguna eliminación, o para implementar una cola LIFO (último en entrar, primero en salir). Las listas doblemente enlazadas añaden la siguiente funcionalidad:

  1. Eliminación de cualquier elemento de la lista en O(n).
  2. Concatenación de dos listas en O(n).

Las listas de cola doblemente enlazadas añaden la siguiente funcionalidad:

  1. Se pueden añadir entradas al final de una lista.
  2. Eliminación de cualquier elemento de la lista en O(n).
  3. Pueden ser concatenadas.

Sin embargo:

  1. Las inserciones en una lista deben especificar el frente de la lista.
  2. Cada entrada de cabecera requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones son aproximadamente un 20% más lentas que en las listas doblemente enlazadas.

Las listas de cola doblemente enlazadas son ideales para aplicaciones con grandes cantidades de datos y pocas o ninguna eliminación, o para implementar una cola FIFO (primero en entrar, primero en salir).

Las estructuras de datos de tipo doblemente enlazadas (listas y colas de cola) además permiten:

  1. Inserción de una nueva entrada antes de cualquier elemento de la lista.
  2. Eliminación de cualquier elemento de la lista en O(1).

Sin embargo:

  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que en las estructuras de lista doblemente enlazadas.

Las listas son las estructuras de datos de tipo doblemente enlazadas más simples. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación de dos listas en O(n).
  2. Pueden ser recorridas en sentido inverso.

Sin embargo:

  1. Para recorrer en sentido inverso, se debe especificar el elemento inicial y la lista en la que se encuentra.

Las colas de cola añaden la siguiente funcionalidad:

  1. Se pueden añadir entradas al final de una lista.
  2. Pueden ser recorridas en sentido inverso, desde el final hacia el principio.
  3. Pueden ser concatenadas.

Sin embargo:

  1. Todas las inserciones y eliminaciones en una lista deben especificar el frente de la lista.
  2. Cada entrada de cabecera requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones son aproximadamente un 20% más lentas que en las listas doblemente enlazadas.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Consulte los siguientes ejemplos para obtener una explicación adicional de cómo se utilizan estas macros.

LISTAS SIMPLEMENTE ENLAZADAS

Una lista simplemente enlazada se encabeza por una estructura definida mediante la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están simplemente enlazados para minimizar el espacio y la sobrecarga de manipulación de punteros, a pesar de que el tiempo de eliminación para elementos arbitrarios es O(n). Se pueden agregar nuevos elementos a la lista después de un elemento existente o al frente de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos de la lista. Luego se puede declarar un puntero a la cabecera de la lista como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la lista encabezada por head1, vaciando la primera. Se debe evitar el uso de esta macro ya que recorre toda la lista head1. Se debe utilizar una lista de cola doblemente enlazada si se necesita esta macro en rutas de código críticas o para operar sobre listas largas.

La macro SLIST_EMPTY evalúa a true si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en sentido forward, asignando cada elemento en su orden a var.

La macro SLIST_FOREACH_FROM se comporta de manera similar a SLIST_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento previamente encontrado de la lista referenciada por head y comienza el bucle en var en lugar del primer elemento de la lista referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en sentido forward, asignando cada elemento en su orden a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí está permitido tanto eliminar var como liberarlo desde dentro del bucle sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera similar a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento previamente encontrado de la lista referenciada por head y comienza el bucle en var en lugar del primer elemento de la lista referenciada por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al frente de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm en la lista.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple se encabeza con una estructura definida por la macro SLIST_HEAD. Los elementos de la lista se enlazan de forma simple para obtener un espacio mínimo y una sobrecarga mínima de manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la lista en la cabeza de la lista, o después de un elemento existente. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos que se van a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1 eliminando todas las entradas de la primera.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí se permite eliminar var así como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm en la cabeza de la lista.

La macro SLIST_NEXT devuelve el siguiente elemento en la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento después de elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm de la cabeza de la lista. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la lista deberían usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Debe evitarse el uso de esta macro ya que recorre toda la lista. Se debe usar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE LISTA ENLAZADA SIMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Cabeza de lista enlazada simple. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Lista enlazada simple. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Inicializar la lista. */

n1 = malloc(sizeof(struct entry));	/* Insertar en la cabeza. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación de la cabeza. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Eliminación de la lista. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

COLAS CON PUNTA ENLAZADAS SIMPLES

Una cola con punta enlazada simple se encabeza con una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno a el primer elemento en la cola con punta y el otro al último elemento en la cola con punta. Los elementos se enlazan de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola con punta después de un elemento existente, en la cabeza de la cola con punta o al final de la cola con punta. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la cola con punta. Un puntero a la cabeza de la cola con punta se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola con punta head.

La macro STAILQ_CONCAT concatena la cola con punta encabezada por head2 al final de la encabezada por head1 eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola con punta.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola con punta.

La macro STAILQ_FIRST devuelve el primer elemento de la cola con punta o NULL si la cola con punta está vacía.

La macro STAILQ_FOREACH recorre la cola con punta referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro STAILQ_FOREACH_FROM se comporta idénticamente a STAILQ_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola con punta referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de STAILQ_FOREACH() aquí se permite eliminar var así como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta idénticamente a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola con punta referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm en la cabeza de la cola con punta.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola con punta.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola con punta. Si la cola con punta está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola con punta, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola con punta. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola con punta.

La macro STAILQ_REMOVE_HEAD elimina el elemento en la cabeza de la cola con punta. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la cola con punta deberían usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola con punta. Debe evitarse el uso de esta macro ya que recorre toda la lista. Se debe usar una cola con punta doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas con punta largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

	...
	STAILQ_ENTRY(entry) entries;	/* Cola con punta. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializar la cola. */

n1 = malloc(sizeof(struct entry));	/* Insertar en la cabeza. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertar al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminación. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminación de la cabeza. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Eliminación de TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Eliminación de TailQ más rápida. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS

Una lista se encabeza con una estructura definida por la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están doblemente enlazados para que un elemento arbitrario pueda eliminarse sin recorrer la lista. Los nuevos elementos se pueden añadir a la lista después de un elemento existente, antes de un elemento existente, o en la cabeza de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1 eliminando todas las entradas de la primera. El uso de esta macro debe evitarse ya que recorre la totalidad de la lista head1. Se debe usar una cola con punta si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por

">head en la dirección hacia adelante, asignando cada elemento a su vez a var.

La macro LIST_FOREACH_FROM se comporta idénticamente a LIST_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento de LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LISTA referenciada por head.

La macro LIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento a su vez a var. Sin embargo, a diferencia de LIST_FOREACH(), aquí está permitido eliminar var así como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro LIST_FOREACH_FROM_SAFE se comporta idénticamente a LIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento de LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LISTA referenciada por head.

La macro LIST_INIT inicializa la lista referenciada por head.

La macro LIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro LIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro LIST_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro LIST_NEXT devuelve el siguiente elemento de la lista, o NULL si es el último.

La macro LIST_PREV devuelve el elemento anterior de la lista, o NULL si es el primero. La lista head debe contener el elemento elm.

La macro LIST_REMOVE elimina el elemento elm de la lista.

La macro LIST_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE LIST

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Cabecera de la lista. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Lista. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Inicializa la lista. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Inserta antes. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Eliminación. */
free(n2);
					/* Recorrido hacia adelante. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Recorrido seguro hacia adelante. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* Eliminación de la lista. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Eliminación más rápida de la lista. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

COLAS FINALES

Una cola final se encabeza mediante una estructura definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola final y el otro al último elemento de la cola final. Los elementos están doblemente enlazados para que se pueda eliminar un elemento arbitrario sin recorrer la cola final. Se pueden añadir nuevos elementos a la cola final después de un elemento existente, antes de un elemento existente, al principio de la cola final o al final de la cola final. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá y TYPE es el tipo de los elementos que se enlazarán en la cola final. Posteriormente, se puede declarar un puntero a la cabecera de la cola final de la siguiente manera:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola final head.

La macro TAILQ_CONCAT concatena la cola final encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro TAILQ_EMPTY se evalúa como verdadera si no hay elementos en la cola final.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos de la cola final.

La macro TAILQ_FIRST devuelve el primer elemento de la cola final o NULL si la cola final está vacía.

La macro TAILQ_FOREACH recorre la cola final referenciada por head en la dirección hacia adelante, asignando cada elemento a su vez a var. var se establece en NULL si el bucle se completa normalmente o si no había elementos.

La macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento de TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola final referenciada por head en la dirección inversa, asignando cada elemento a su vez a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta idénticamente a TAILQ_FOREACH_REVERSE cuando var es NULL, de lo contrario, trata a var como un elemento de TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referenciada por head en dirección hacia adelante o inversa respectivamente, asignando cada elemento a su vez a var. Sin embargo, a diferencia de sus contrapartes inseguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE hacen posible eliminar var así como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento de TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento de TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

La macro TAILQ_INIT inicializa la cola final referenciada por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola final.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola final.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola final. Si la cola final está vacía, el valor de retorno es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento de la cola final, o NULL si este elemento es el último.

La macro TAILQ_PREV devuelve el elemento anterior de la cola final, o NULL si este elemento es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola final.

La macro TAILQ_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE COLAS FINALES

    TAILQ_HEAD_INITIALIZER(head);
struct tailhead *headp;			/* Cabecera de la cola final. */
struct entry {
	...
	TAILQ_ENTRY(entry) entries;	/* Cola final. */
	...

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */

n1 = malloc(sizeof(struct entry));	/* Inserta al final. */
TAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */

n3 = malloc(sizeof(struct entry));	/* Inserta antes. */

TAILQ_REMOVE(&head, n2, entries);	/* Eliminación. */
free(n2);
					/* Recorrido hacia adelante. */
TAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
TAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	TAILQ_REMOVE(&head, np, entries);
	free(np);
}
					/* Recorrido inverso. */
TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
	np-> ...
					/* Eliminación de la cola final. */
while (!TAILQ_EMPTY(&head)) {
	n1 = TAILQ_FIRST(&head);
	TAILQ_REMOVE(&head, n1, entries);
	free(n1);
}
					/* Eliminación más rápida de la cola final. */
n1 = TAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = TAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}

DESCRIPCIÓN


El queue es un conjunto de funciones que permiten manipular listas enlazadas singulares. Este manual describe las funciones de queue(3) y su uso.






LISTAS ENLAZADAS SINGULARMENTE


Las listas enlazadas singulares son estructuras de datos que permiten insertar y eliminar elementos de forma eficiente. El queue proporciona funciones para manipular estas listas.






EJEMPLO DE LISTA ENLAZADA SINGULAR


#include <libbsd.h>

void
main(void) {
    struct node *n1, *n2;
    n1 = (struct node *)malloc(sizeof(struct node));
    n1->next = NULL;
    n2 = (struct node *)malloc(sizeof(struct node));
    n2->next = n1;
    n1->prev = n2;
    n2->prev = NULL;
    TAILQ_INSERT_TAIL(&n1->list, n2);
}

DIAGNÓSTICO


Cuando se depura queue(3), puede ser útil seguir el cambio de las listas. Para habilitar el trazado, define la macro QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.


También puede ser útil destruir punteros que hayan sido desenlazados de una cola, para detectar el uso después de la eliminación. Para habilitar la destrucción de punteros, define la macro QUEUE_MACRO_DEBUG_TRASH en tiempo de compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido destruido por la opción QUEUE_MACRO_DEBUG_TRASH.
