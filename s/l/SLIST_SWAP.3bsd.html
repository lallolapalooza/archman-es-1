DESCRIPTION

These macros define and operate on four types of data structures which can be used in both C and C++ source code:

  1. Lists
  2. Singly-linked lists
  3. Singly-linked tail queues
  4. Tail queues
All four structures support the following functionality:
  1. Insertion of a new entry at the head of the list.
  2. Insertion of a new entry after any element in the list.
  3. O(1) removal of an entry from the head of the list.
  4. Forward traversal through the list.
  5. Swapping the contents of two lists.

Singly-linked lists are the simplest of the four data structures and support only the above functionality. Singly-linked lists are ideal for applications with large datasets and few or no removals, or for implementing a LIFO queue. Singly-linked lists add the following functionality:

  1. O(n) removal of any entry in the list.
  2. O(n) concatenation of two lists.

Singly-linked tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. O(n) removal of any entry in the list.
  3. They may be concatenated.
However:
  1. All list insertions must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

Singly-linked tail queues are ideal for applications with large datasets and few or no removals, or for implementing a FIFO queue.

All doubly linked types of data structures (lists and tail queues) additionally allow:

  1. Insertion of a new entry before any element in the list.
  2. O(1) removal of any entry in the list.
However:
  1. Each element requires two pointers rather than one.
  2. Code size and execution time of operations (except for removal) is about twice that of the singly-linked data-structures.

Linked lists are the simplest of the doubly linked data structures. They add the following functionality over the above:

  1. O(n) concatenation of two lists.
  2. They may be traversed backwards.
However:
  1. To traverse backwards, an entry to begin the traversal and the list in which it is contained must be specified.

Tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. They may be traversed backwards, from tail to head.
  3. They may be concatenated.
However:
  1. All list insertions and removals must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

In the macro definitions, TYPE is the name of a user defined structure. The structure must contain a field called NAME which is of type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, or TAILQ_ENTRY. In the macro definitions, CLASSTYPE is the name of a user defined class. The class must contain a field called NAME which is of type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, or TAILQ_CLASS_ENTRY. The argument HEADNAME is the name of a user defined structure that must be declared using the macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, or TAILQ_CLASS_HEAD. See the examples below for further explanation of how these macros are used.

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element or at the head of the list. An SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A singly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_FROM behaves identically to SLIST_FOREACH when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_FOREACH_FROM_SAFE behaves identically to SLIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro SLIST_REMOVE removes the element elm from the list.

The macro SLIST_SWAP swaps the contents of the two lists headed by head1 and head2.

free(n3);

					/* Recorrido seguro hacia adelante. */

COLAS DE LISTA SIMPLEMENTE ENLAZADA CON COLA

Una cola de lista simplemente enlazada con cola está encabezada por una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simplemente enlazada para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de un borrado O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos que se enlazarán en la cola. Un puntero a la cabecera de la cola se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola head.

La macro STAILQ_CONCAT concatena la cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY se evalúa como verdadera si no hay elementos en la cola.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos de la cola.

La macro STAILQ_FIRST devuelve el primer elemento de la cola o NULL si la cola está vacía.

La macro STAILQ_FOREACH recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí se permite tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento posterior a elm de la cola. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola.

La macro STAILQ_REMOVE_HEAD elimina el elemento del principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola. Se debe evitar el uso de esta macro, ya que recorre toda la lista. Se debe usar una cola doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE COLA DE LISTA SIMPLEMENTE ENLAZADA CON COLA

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Cabecera de cola de lista simplemente enlazada con cola. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Cola de lista. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializa la cola. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Inserta al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Borrado. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Borrado del principio. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Borrado de la Cola de Lista. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Borrado más rápido de la Cola de Lista. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}

LISTAS

Una lista está encabezada por una estructura definida por la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados doblemente para que un elemento arbitrario pueda ser eliminado sin recorrer la lista. Se pueden añadir nuevos elementos a la lista después de un elemento existente, antes de un elemento existente, o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabecera de la lista se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe usar una cola de lista si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY se evalúa como verdadera si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

LISTS

Las listas simplemente enlazadas son encabezadas por una estructura definida mediante la macro LIST_HEAD. Esta estructura contiene un puntero al primer elemento de la lista. Los elementos son enlazados de forma simple, lo que permite añadir elementos al frente de la lista, eliminar elementos de la lista, y recorrer la lista en una única dirección. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos vinculados a la lista. Una dirección del puntero al cabeza de la lista puede ser declarada más tarde de la siguiente manera:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista referida por head2 al final de la lista referida por head1.

La macro LIST_EMPTY evalúa a true si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referida por head en la dirección forward, asignando cada elemento en su lugar a var.

El macro LIST_FOREACH_FROM funciona de manera idéntica al macro LIST_FOREACH cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle en var en lugar del primer elemento de la lista referida por head.

El macro LIST_FOREACH_SAFE recorre la lista referida por head en la dirección forward, asignando cada elemento en su lugar a var. Sin embargo, a diferencia del LIST_FOREACH(), aquí es permitido remover var y liberar la memoria de var dentro del bucle sin interferir con la travesía.

El macro LIST_FOREACH_FROM_SAFE funciona de manera idéntica al macro LIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle en var en lugar del primer elemento de la lista referida por head.

El macro LIST_INIT inicializa la lista referida por head.

El macro LIST_INSERT_HEAD inserta el elemento nuevo elm al frente de la lista.

El macro LIST_INSERT_AFTER inserta el elemento nuevo elm después del elemento listelm.

El macro LIST_INSERT_BEFORE inserta el elemento nuevo elm antes del elemento listelm.

El macro LIST_NEXT devuelve el elemento siguiente en la lista, o NULL si este es el último.

El macro LIST_PREV devuelve el elemento anterior en la lista, o NULL si este es el primero. La lista head debe contener el elemento elm.

El macro LIST_REMOVE elimina el elemento elm de la lista.

El macro LIST_SWAP intercambia los contenidos de head1 y head2.

LIST EXAMPLE

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* List head. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* List. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insert before. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Deletion. */
free(n2);
					/* Forward traversal. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Safe forward traversal. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);

while (!LIST_EMPTY(&head)) {		/* List Deletion. */
	n1 = LIST_FIRST(&head);

TAIL QUEUES

Una cola de final es encabezada por un estructura definida mediante la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de final y el otro al último elemento de la cola de final. Los elementos son vinculados de forma doble, lo que permite eliminar cualquier elemento sin tener que recorrer la cola de final. Los elementos nuevos pueden ser agregados a la cola de final después de un elemento existente, antes de un elemento existente, al frente de la cola de final, o al final de la cola de final. Una estructura TAILQ_HEAD se declara así:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos vinculados a la cola de final. Una dirección del puntero al cabeza de la cola de final puede ser declarada más tarde así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de final head.

La macro TAILQ_CONCAT concatenará la cola de final referida por head2 al final de la cola de final referida por head1, eliminando todos los elementos de la anterior.

La macro TAILQ_EMPTY evalúa a true si no hay elementos en la cola de final.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos de la cola de final.

La macro TAILQ_FIRST devuelve el primer elemento de la cola de final o NULL si la cola de final está vacía.

La macro TAILQ_FOREACH recorre la cola de final referida por head en la dirección forward, asignando cada elemento en su lugar a var. var se establece a NULL si el bucle termina normalmente, o si no hay elementos.

La macro TAILQ_FOREACH_FROM funciona de manera idéntica a TAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la cola de final y comienza el bucle en var en lugar del primer elemento de la cola de final referida por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de final referida por head en la dirección reversa, asignando cada elemento en su lugar a var.

La macro TAILQ_FOREACH_REVERSE_FROM funciona de manera idéntica a TAILQ_FOREACH_REVERSE cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la cola de final y comienza el bucle en var en lugar del último elemento de la cola de final referida por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referida por head en la dirección forward o reversa respectivamente, asignando cada elemento en su lugar a var. Sin embargo, a diferencia de sus contrapartes inseguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten remover var y liberar su memoria dentro del bucle sin interferir con la travesía.

La macro TAILQ_FOREACH_FROM_SAFE funciona de manera idéntica a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la cola de final y comienza el bucle en var en lugar del primer elemento de la cola de final referida por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE funciona de manera idéntica a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la cola de final y comienza el bucle en var en lugar del último elemento de la cola de final referida por head.

La macro TAILQ_INIT inicializa la cola de final referida por head.

La macro TAILQ_INSERT_HEAD inserta el elemento nuevo elm al frente de la cola de final.

La macro TAILQ_INSERT_TAIL inserta el elemento nuevo elm al final de la cola de final.

La macro TAILQ_INSERT_AFTER inserta el elemento nuevo elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el elemento nuevo elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola de final. Si la cola de final está vacía, el valor devuelto es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento de la cola de final, o NULL si este es el último.

La macro TAILQ_PREV devuelve el elemento anterior de la cola de final, o NULL si este es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de final.

La macro TAILQ_SWAP intercambia los contenidos de head1 y head2.

DIAGNÓSTICOS

Al depurar queue(3), puede ser útil rastrear los cambios en la cola. Para habilitar el rastreo, defina la macro QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.

También puede ser útil "ensuciar" los punteros que han sido desvinculados de una cola, para detectar el uso después de la eliminación. Para habilitar el "ensuciamiento" de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH en tiempo de compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido "ensuciado" por la opción QUEUE_MACRO_DEBUG_TRASH.
