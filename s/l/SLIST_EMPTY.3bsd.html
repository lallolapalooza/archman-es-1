DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser utilizadas tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simples
  3. Colas de cola enlazadas simples
  4. Colas de cola
Las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de una nueva entrada al principio de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento en la lista.
  3. Eliminación en O(1) de una entrada del principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más sencillas de las cuatro estructuras de datos y solo soportan la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO. Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación en O(n) de cualquier entrada en la lista.
  2. Concatenación en O(n) de dos listas.

Las colas de cola enlazadas simples añaden la siguiente funcionalidad:

  1. Las entradas pueden ser añadidas al final de una lista.
  2. Eliminación en O(n) de cualquier entrada en la lista.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones son aproximadamente un 20% más lentas que las listas enlazadas simples.

Las colas de cola enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO.

Todos los tipos de estructuras de datos doblemente enlazadas (listas y colas de cola) permiten adicionalmente:

  1. Inserción de una nueva entrada antes de cualquier elemento en la lista.
  2. Eliminación en O(1) de cualquier entrada en la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) son aproximadamente el doble que los de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más sencillas de las estructuras de datos doblemente enlazadas. Añaden la siguiente funcionalidad sobre lo anterior:

  1. Concatenación en O(n) de dos listas.
  2. Pueden ser recorridas hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para iniciar el recorrido y la lista en la que está contenida.

Las colas de cola añaden la siguiente funcionalidad:

  1. Las entradas pueden ser añadidas al final de una lista.
  2. Pueden ser recorridas hacia atrás, de cola a cabeza.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones son aproximadamente un 20% más lentas que las listas enlazadas simples.

En las definiciones de macro, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que es de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, o TAILQ_ENTRY. En las definiciones de macro, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que es de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe ser declarada usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, o TAILQ_CLASS_HEAD. Consulte los ejemplos a continuación para una mayor explicación sobre cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación en O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Posteriormente, se puede declarar un puntero a la cabeza de la lista como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe utilizar una cola de cola enlazada simple si se necesita esta macro en rutas de código de alto uso o para operar sobre listas largas.

La macro SLIST_EMPTY se evalúa como verdadera si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH() aquí está permitido eliminar var así como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento

SLIST_HEAD

A singly linked list is headed by a structure defined by the macro SLIST_HEAD. This structure contains a single pointer to the first element in the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element, or at the head of the list. A SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro SLIST_EMPTY evaluates to true if there are no items on the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element on the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro SLIST_NEXT returns the next element in the list.

The macro SLIST_REMOVE_AFTER removes the element after elm from the list. Unlike SLIST_REMOVE, this macro does not traverse the entire list.

The macro SLIST_REMOVE_HEAD removes the element elm from the head of the list. For optimum efficiency, elements being removed from the head of the list should explicitly use this macro instead of the generic SLIST_REMOVE macro.

The macro SLIST_REMOVE removes the element elm from the list. Use of this macro should be avoided as it traverses the entire list. A doubly-linked list should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_SWAP swaps the contents of head1 and head2.

struct slisthead *headp;		/* Singly-linked List head. */

n2 = malloc(sizeof(struct entry));	/* Insert after. */

SLIST_REMOVE(&head, n2, entry, entries);/* Deletion. */

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Deletion from the head. */
free(n3);

SINGLY-LINKED TAIL QUEUES

A singly-linked tail queue is headed by a structure defined by the STAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the tail queue after an existing element, at the head of the tail queue, or at the end of the tail queue. A STAILQ_HEAD structure is declared as follows:

STAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro STAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro STAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro STAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro STAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro STAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro STAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var.

The macro STAILQ_FOREACH_FROM behaves identically to STAILQ_FOREACH when var is NULL, else it treats var as a previously found STAILQ element and begins the loop at var instead of the first element in the STAILQ referenced by head.

The macro STAILQ_FOREACH_SAFE traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. However, unlike STAILQ_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro STAILQ_FOREACH_FROM_SAFE behaves identically to STAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found STAILQ element and begins the loop at var instead of the first element in the STAILQ referenced by head.

The macro STAILQ_INIT initializes the tail queue referenced by head.

The macro STAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro STAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro STAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro STAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro STAILQ_NEXT returns the next item on the tail queue, or NULL this item is the last.

The macro STAILQ_REMOVE_AFTER removes the element after elm from the tail queue. Unlike STAILQ_REMOVE, this macro does not traverse the entire tail queue.

The macro STAILQ_REMOVE_HEAD removes the element at the head of the tail queue. For optimum efficiency, elements being removed from the head of the tail queue should use this macro explicitly rather than the generic STAILQ_REMOVE macro.

The macro STAILQ_REMOVE removes the element elm from the tail queue. Use of this macro should be avoided as it traverses the entire list. A doubly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long tail queues.

The macro STAILQ_SWAP swaps the contents of head1 and head2.

LISTS

A list is headed by a structure defined by the LIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are doubly linked so that an arbitrary element can be removed without traversing the list. New elements can be added to the list after an existing element, before an existing element, or at the head of the list. A LIST_HEAD structure is declared as follows:

LIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro LIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro LIST_EMPTY evaluates to true if there are no elements in the list.

The macro LIST_ENTRY declares a structure that connects the elements in the list.

The macro LIST_FIRST returns the first element in the list or NULL if the list is empty.

DESCRIPCION

                    
Estas macros proporcionan una implementación genérica de listas enlazadas simples, doblemente enlazadas y colas de listas (listas doblemente enlazadas con puntero al final).

                    
Todos los tipos de listas utilizan el mismo mecanismo de macro para la manipulación. Cada nodo de la lista debe contener un campo de puntero que se utiliza para enlazar los nodos. El primer argumento de la mayoría de las macros es un puntero a la cabeza de la lista, que es una estructura que contiene punteros al primer y último nodo de la lista (o solo al primer nodo para listas simples).

                    
El segundo argumento a la mayoría de las macros es un puntero a un nodo de la lista.

                    
Cada macro de manipulación de listas que opera en un tipo de nodo específico también requiere un argumento adicional que especifica el nombre del campo de puntero utilizado en la estructura del nodo.

                    
Para todas las listas, cada nodo de la lista debe ser una estructura que contenga al menos un campo de puntero que se utilizará para enlazar los nodos.

                    
Las listas enlazadas simples se definen usando SLIST_HEAD. Los nodos en una lista simple solo tienen un puntero al siguiente nodo.

                    
Las listas doblemente enlazadas se definen usando LIST_HEAD. Los nodos en una lista doblemente enlazada tienen punteros al nodo anterior y al siguiente.

                    
Las colas de listas se definen usando TAILQ_HEAD. Son listas doblemente enlazadas donde la estructura de la cabeza de la lista también almacena un puntero al último nodo.

                

                

                    
LISTAS ENLAZADAS SIMPLES

                    
SLIST_HEAD(name, type)

                    
Declara un tipo de cabeza de lista llamado name. type es el nombre del tipo de datos de la estructura del nodo.

                    
SLIST_HEAD_INITIALIZER(head)

                    
Expresión que se puede utilizar para inicializar una cabeza de lista estática.

                    
SLIST_INIT(head)

                    
Inicializa la lista vacía especificada por head.

                    
SLIST_EMPTY(head)

                    
Devuelve verdadero si la lista está vacía, falso en caso contrario.

                    
SLIST_FOREACH(var, head)

                    
Itera sobre la lista especificada por head. En cada iteración, var se establece en el puntero al nodo actual.

                    
SLIST_FOREACH_SAFE(var, head, nextvar)

                    
Similar a SLIST_FOREACH, pero seguro para su uso cuando los elementos se eliminan de la lista durante la iteración. nextvar debe ser una variable del mismo tipo que var.

                    
SLIST_FOREACH_SIBLING(var, next)

                    
Itera sobre los nodos de una lista simple, similar a SLIST_FOREACH_SAFE pero sin la necesidad de una cabeza de lista explícita. Se asume que var apunta al nodo actual y next apunta al siguiente nodo.

                    
SLIST_NEXT(var, field)

                    
Devuelve un puntero al siguiente nodo en la lista después del nodo especificado por var. field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_INSERT_AFTER(var, add, field)

                    
Inserta el nodo especificado por add después del nodo especificado por var. field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_INSERT_HEAD(head, var, field)

                    
Inserta el nodo especificado por var al principio de la lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_INSERT_TAIL(head, var, field)

                    
Inserta el nodo especificado por var al final de la lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_REMOVE(head, var, type, field)

                    
Elimina el nodo especificado por var de la lista especificada por head. type es el nombre del tipo de datos de la estructura del nodo y field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_REMOVE_HEAD(head, field)

                    
Elimina y devuelve el primer nodo de la lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_REMOVE_AFTER(var, field)

                    
Elimina y devuelve el nodo que sigue al nodo especificado por var. field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_SWAP(head1, head2, type)

                    
Intercambia el contenido de las dos listas especificadas por head1 y head2. type es el nombre del tipo de datos de la estructura de la cabeza de la lista.

    // Iterar sobre la lista
    SLIST_FOREACH(n_tmp, &head) {
        printf("%d ", n_tmp->value);
    }
    // Salida: 10 20
    printf("\n");

    // Eliminar el primer nodo
    n1 = SLIST_REMOVE_HEAD(&head, pointers);
    free(n1);

    // Eliminar un nodo específico
    SLIST_REMOVE(&head, n2, node, pointers);
    free(n2);

    return 0;
}


                

                

                    
COLAS DE LISTAS SIMPLES

                    
SLIST_TAILQ_HEAD(name, type)

                    
Declara un tipo de cabeza de cola de lista llamado name. type es el nombre del tipo de datos de la estructura del nodo.

                    
SLIST_TAILQ_INIT(head)

                    
Inicializa la cola de lista vacía especificada por head.

                    
SLIST_TAILQ_INSERT_HEAD(head, var, field)

                    
Inserta el nodo especificado por var al principio de la cola de lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_TAILQ_INSERT_TAIL(head, var, field)

                    
Inserta el nodo especificado por var al final de la cola de lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
SLIST_TAILQ_REMOVE_HEAD(head, field)

                    
Elimina y devuelve el primer nodo de la cola de lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                

                

                    
LISTAS

                    
LIST_HEAD(name, type)

                    
Declara un tipo de cabeza de lista llamado name. type es el nombre del tipo de datos de la estructura del nodo.

                    
LIST_HEAD_INITIALIZER(head)

                    
Expresión que se puede utilizar para inicializar una cabeza de lista estática.

                    
LIST_INIT(head)

                    
Inicializa la lista vacía especificada por head.

                    
LIST_EMPTY(head)

                    
Devuelve verdadero si la lista está vacía, falso en caso contrario.

                    
LIST_FOREACH(var, head)

                    
Itera sobre la lista especificada por head. En cada iteración, var se establece en el puntero al nodo actual.

                    
LIST_FOREACH_SAFE(var, head, nextvar)

                    
Similar a LIST_FOREACH, pero seguro para su uso cuando los elementos se eliminan de la lista durante la iteración. nextvar debe ser una variable del mismo tipo que var.

                    
LIST_NEXT(var, field)

                    
Devuelve un puntero al siguiente nodo en la lista después del nodo especificado por var. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_PREV(var, field)

                    
Devuelve un puntero al nodo anterior en la lista antes del nodo especificado por var. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_INSERT_AFTER(var, add, field)

                    
Inserta el nodo especificado por add después del nodo especificado por var. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_INSERT_BEFORE(var, add, field)

                    
Inserta el nodo especificado por add antes del nodo especificado por var. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_INSERT_HEAD(head, var, field)

                    
Inserta el nodo especificado por var al principio de la lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_INSERT_TAIL(head, var, field)

                    
Inserta el nodo especificado por var al final de la lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_REMOVE(head, var, field)

                    
Elimina el nodo especificado por var de la lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_REMOVE_HEAD(head, field)

                    
Elimina y devuelve el primer nodo de la lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_REMOVE_TAIL(head, field)

                    
Elimina y devuelve el último nodo de la lista especificada por head. field es el nombre del campo de puntero en la estructura del nodo.

                    
LIST_SWAP(head1, head2, type)

                    
Intercambia el contenido de las dos listas especificadas por head1 y head2. type es el nombre del tipo de datos de la estructura de la cabeza de la lista.

                

                

                    
EJEMPLO DE LISTA

                    
#include <stdio.h>
#include <stdlib.h>
#include <bsd/bsd.h>

typedef struct node {
    int value;
    LIST_ENTRY(node) pointers;
} node_t;

LIST_HEAD(node_list, node) head;

int
main(void)
{
    node_t *n1, *n2, *n_tmp;

    LIST_INIT(&head);

    // Crear y añadir nodos
    n1 = malloc(sizeof(*n1));
    n1->value = 10;
    LIST_INSERT_HEAD(&head, n1, pointers);

    n2 = malloc(sizeof(*n2));
    n2->value = 20;
    LIST_INSERT_TAIL(&head, n2, pointers);

    // Iterar sobre la lista
    LIST_FOREACH(n_tmp, &head) {
        printf("%d ", n_tmp->value);
    }
    // Salida: 10 20
    printf("\n");

    // Eliminar el primer nodo
    n1 = LIST_REMOVE_HEAD(&head, pointers);
    free(n1);

    // Eliminar un nodo específico
    LIST_REMOVE(&head, n2, pointers);
    free(n2);

    return 0;
}

DIAGNOSTICO

                    
Cuando depure queue(3), puede ser útil rastrear los cambios en la cola. Para habilitar el rastreo, defina la macro QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.

                    
También puede ser útil descartar punteros que han sido desvinculados de una cola para detectar el uso después de la eliminación. Para habilitar el descarte de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH en tiempo de compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido descartado por la opción QUEUE_MACRO_DEBUG_TRASH.
