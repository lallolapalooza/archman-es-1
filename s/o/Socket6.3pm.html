NOMBRE

Socket6 - Parte de las definiciones y manipuladores de estructuras de C socket.h relacionadas con IPv6

SINOPSIS

use Socket;
use Socket6;
@res = getaddrinfo('hishost.com', 'daytime', AF_UNSPEC, SOCK_STREAM);
$family = -1;
while (scalar(@res) >= 5) {
    ($family, $socktype, $proto, $saddr, $canonname, @res) = @res;
    ($host, $port) = getnameinfo($saddr, NI_NUMERICHOST | NI_NUMERICSERV);
    print STDERR "Intentando conectar a $host puerto $port...\n";
    socket(Socket_Handle, $family, $socktype, $proto) || next;
    connect(Socket_Handle, $saddr) && last;
    close(Socket_Handle);
    $family = -1;
}
if ($family != -1) {
    print STDERR "conectado a $host puerto $port\n";
} else {
    die "intento de conexión fallido\n";
}

DESCRIPCIÓN

Este módulo proporciona rutinas de conexión a las diversas funciones de IPv6.

Si utiliza el módulo Socket6, asegúrese de especificar también "use Socket" además de "use Socket6".

Las funciones proporcionadas son:

inet_pton FAMILIA, DIRECCIÓN_TEXTO
Esta función toma una dirección IP en formato de presentación (o cadena)
y la convierte a formato numérico (o binario).
El tipo de conversión de dirección IP (IPv4 versus IPv6) se controla
mediante el argumento FAMILIA.
inet_ntop FAMILIA, DIRECCIÓN_BINARIA
Esta función toma una dirección IP en formato numérico (o binario)
y la convierte a formato de presentación (o cadena).
El tipo de conversión de dirección IP (IPv4 versus IPv6) se controla
mediante el argumento FAMILIA.
pack_sockaddr_in6 PUERTO, DIRECCIÓN
Esta función toma dos argumentos: un número de puerto y una estructura
de dirección IPv6 de 16 octetos (tal como la devuelve
inet_pton()).
Devuelve la estructura sockaddr_in6 con estos argumentos empaquetados
en sus campos correctos, así como la familia AF_INET6.
Los otros campos no se establecen y no se debe confiar en sus valores.
pack_sockaddr_in6_all PUERTO, FLOWINFO, DIRECCIÓN, SCOPEID
Esta función toma cuatro argumentos: un número de puerto, una estructura
de dirección IPv6 de 16 octetos (tal como la devuelve
inet_pton()), cualquier información de flujo especial
y cualquier información de alcance específica.
Devuelve una estructura sockaddr_in6 completa con estos argumentos
empaquetados en sus campos correctos, así como la familia AF_INET6.
unpack_sockaddr_in6 NOMBRE
Esta función toma una estructura sockaddr_in6 (tal como la devuelve
pack_sockaddr_in6()) y devuelve una lista de dos elementos:
el número de puerto y la dirección IP de 16 octetos.
Esta función fallará si determina que no se le ha pasado una estructura IPv6.
unpack_sockaddr_in6_all NOMBRE
Esta función toma una estructura sockaddr_in6 (tal como la devuelve
pack_sockaddr_in6()) y devuelve una lista de cuatro elementos:
el número de puerto, la información de flujo, la dirección IP de 16 octetos
y la información de alcance.
Esta función fallará si determina que no se le ha pasado una estructura IPv6.
gethostbyname2 NOMBRE_HOST, FAMILIA
getaddrinfo NOMBRE_NODO, NOMBRE_SERVICIO, [FAMILIA, TIPO_SOCK, PROTOCOLO, BANDERAS]
Esta función convierte nombres de nodo a direcciones y nombres de servicio
a números de puerto.
Si el argumento NOMBRE_NODO no es un valor falso,
se realizará una búsqueda de nombre de nodo a dirección;
de lo contrario, se realizará una búsqueda de nombre de servicio a número de puerto.
Al menos uno de NOMBRE_NODO y NOMBRE_SERVICIO debe tener un valor verdadero.
Si la búsqueda es exitosa, se devuelve una lista que consta de múltiplos de
cinco elementos.
Cada grupo de cinco elementos consta de la familia de direcciones,
el tipo de socket, el protocolo, la dirección IP de 16 octetos y el nombre
canónico (undef si el nombre de nodo pasado ya es el nombre canónico).
Los argumentos FAMILIA, TIPO_SOCK, PROTOCOLO y BANDERAS son todos opcionales.
Esta función fallará si determina que no se le ha pasado una estructura IPv6.
Si la búsqueda no es exitosa, la función devuelve un solo escalar.
Este contendrá la versión en cadena de ese error en contexto de cadena,
y el valor numérico en contexto numérico.
getnameinfo NOMBRE, [BANDERAS]
Esta función toma una estructura de dirección de socket. Si tiene éxito, devuelve
dos cadenas que contienen el nombre del nodo y el nombre del servicio.
El argumento opcional BANDERAS controla qué tipo de búsqueda se realiza.
Si la búsqueda no es exitosa, la función devuelve un solo escalar.
Este contendrá la versión en cadena de ese error en contexto de cadena,
y el valor numérico en contexto numérico.
getipnodebyname HOST, [FAMILIA, BANDERAS]
Esta función toma un nombre de nodo o una cadena de dirección IP
y realiza una búsqueda en ese nombre (o conversión de la cadena).
Devuelve una lista de cinco elementos: el nombre de host canónico,
la familia de direcciones, la longitud en octetos de las direcciones IP
devueltas, una referencia a una lista de estructuras de direcciones IP y
una referencia a una lista de alias para el nombre de host.
Los argumentos FAMILIA y BANDERAS son opcionales.
Nota: Esta función no maneja identificadores de alcance IPv6,
y debe usarse con precaución.
Además, esta función fue marcada como obsoleta en RFC3493.
Debe usarse la función getnameinfo en su lugar.
getipnodebyaddr FAMILIA, DIRECCIÓN
Esta función toma una familia de direcciones IP y una estructura de dirección IP
y realiza una búsqueda inversa en esa dirección.
Devuelve una lista de cinco elementos: el nombre de host canónico,
la familia de direcciones, la longitud en octetos de las direcciones IP
devueltas, una referencia a una lista de estructuras de direcciones IP y
una referencia a una lista de alias para el nombre de host.
Nota: Esta función no maneja identificadores de alcance IPv6,
y debe usarse con precaución.
Además, esta función fue marcada como obsoleta en RFC3493.
Debe usarse la función getaddrinfo en su lugar.
gai_strerror NÚMERO_ERROR
Esta función devuelve una cadena correspondiente al número de error
pasado como argumento.
in6addr_any
Esta función devuelve la dirección comodín de 16 octetos.
in6addr_loopback
Esta función devuelve la dirección de bucle invertido de 16 octetos.
