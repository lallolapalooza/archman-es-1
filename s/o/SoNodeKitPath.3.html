NAME

SoNodeKitPath - Path through nodekits.

SYNOPSIS

#include <Inventor/SbBasic.h>
#include <Inventor/nodes/SoNodeKitPath.h>

Detailed Description

This class represents a path through nodekits. A path is a sequence of nodes starting from the root of the scene graph down to some node.

In a typical scene graph, there may be many paths from the root to any given node. This class is used to represent one such path.

A nodekit is an SoBaseKit subclass. A path consisting of nodekits implies that the path is a sequence of nodekits that are *parts* of each other.

For example, if we have a path SoNodeKitPath p where p.get(0) is an SoNodeKitPath and p.get(1) is an SoNodeKitPath, then p.get(1) must be a part in p.get(0).
