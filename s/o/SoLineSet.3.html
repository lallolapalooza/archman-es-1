DESCRIPTION

An SoLineSet node defines a collection of one or more polylines (connected lines).

The coordinates for the polylines are taken from the current coordinate3 node or from the vertexProperty field. If the vertexProperty field is set, then the coordinates (and normals, materials, texture coordinates, etc.) are fetched from there. Otherwise, they are taken from the nearest preceding SoCoordinate3 node in the scene graph.

The polylines are defined by the numVertices field. This field contains a list of integers, where each integer specifies the number of coordinates in a polyline. The coordinates are fetched in order from the current state or from the vertexProperty node if set. For example, if numVertices is set to [3, 4, 2], this node would specify a line through coordinates 0, 1 and 2, a line through coordinates 3, 4, 5 and 6, and finally a single line segment between coordinates 7 and 8.

Here's a very simple usage example:

#Inventor V2.1 ascii
Separator {
   Coordinate3 {
      point [ 0 0 0, 1 1 1, 2 1 1, 2 2 1, 2 2 2, 2 2 3, 2 3 2, 2 3 3, 3 3 3 ]
   }
   LineSet {
      numVertices [ 3, 4, 2 ]
   }
}

Binding PER_VERTEX, PER_FACE, PER_PART or OVERALL can be set for material, and normals. The default material binding is OVERALL. The default normal binding is PER_VERTEX. If no normals are set, the line set will be rendered with lighting disabled.

The width of the rendered lines can be controlled through the insertion of an SoDrawStyle node in front of SoLineSet node(s) in the scene graph.

    startIndex 0
