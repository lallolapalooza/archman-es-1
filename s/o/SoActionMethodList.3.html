Descripción detallada

La clase SoActionMethodList contiene punteros a funciones para métodos de acción.

Un SoActionMethodList contiene un puntero a función por tipo de nodo. Cada acción contiene un SoActioMethodList para saber qué funciones llamar durante el recorrido del grafo de escena.

Documentación del constructor y destructor

SoActionMethodList::SoActionMethodList (SoActionMethodList *const parentlist)

El constructor. El argumento parentlist es la lista de métodos de acción de la acción padre. Puede ser NULL para listas de métodos de acción que no se basan en la herencia de una acción padre.
