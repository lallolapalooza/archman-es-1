Descripción Detallada

La clase SoGeoLocation se utiliza para georreferenciar los siguientes nodos.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

GeoLocation {
  geoSystem ["GD", "WE"]
  geoCoords 0 0 0
}

Este nodo especifica un sistema de coordenadas geográficas absoluto para los siguientes nodos. Al renderizar (o aplicar otras acciones), Coin añadirá una transformación que convierte la geometría al sistema de coordenadas SoGeoOrigin. Todos los objetos se rotarán para que el eje Z local apunte hacia arriba desde el suelo (en la ubicación geográfica especificada), el eje Y apuntará hacia el polo norte, y el eje X se encontrará usando la regla de la mano derecha.
