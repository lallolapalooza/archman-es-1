Detailed Description

This element keeps track of the current drawing style in the scene graph.

The drawing style dictates how primitives are rendered. There are several predefined styles:

  • INHERITED: The drawing style is inherited from the parent node.
  • POINTS: The primitives are rendered as points.
  • LINES: The primitives are rendered as lines.
  • FILLED: The primitives are rendered as filled shapes.
  • LINES_INVERT: The primitives are rendered as lines with inverted colors.
  • FILL_INVERT: The primitives are rendered as filled shapes with inverted colors.
  • POINTS_INVERT: The primitives are rendered as points with inverted colors.

In addition to the drawing style, this element also stores the line width for point and line styles, and whether the style should override the material's diffuse color.

The methods push, pop, and set are used to manage the drawing style during scene graph traversal. init initializes the element class.
