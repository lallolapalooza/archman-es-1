Descripción Detallada

La clase SoNormalBinding es un nodo para especificar las vinculaciones de vectores normales.

Utilice nodos de este tipo para especificar cómo mapear los vectores normales de los nodos SoNormal en el grafo de escena a los nodos de forma.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

NormalBinding {
    value PER_VERTEX_INDEXED
}

Documentación de Enumeraciones de Miembros

enum SoNormalBinding::Binding

Enumeración de los tipos de mapeo disponibles. Consulte la documentación del nodo SoMaterialBinding para obtener una explicación de los diferentes valores.

Tenga en cuenta que SoNormalBinding::DEFAULT y SoNormalBinding::NONE han sido obsoletos y ambos se mapean a SoNormalBinding::PER_VERTEX_INDEXED.

Enumerador

PER_PART
Obtiene un nuevo vector normal del pool de valores de vectores normales para cada *parte* de la forma, donde la definición de una *parte* depende del tipo de forma.

Los vectores normales se obtienen del índice 0 en adelante, incrementando el índice en el pool de vectores normales en 1 por cada nueva parte en el orden definido por el tipo de forma particular.

Nota importante de portabilidad: anteriormente se permitía con la biblioteca SGI Inventor proporcionar demasiados pocos colores en comparación con el número de partes de las formas subsiguientes en el grafo de escena. La coloración ciclaría entonces a través de los colores disponibles.

Desde SGI Open Inventor v2.1, esto se desautorizó; se deben proporcionar suficientes vectores normales para todas las partes, de lo contrario el comportamiento no se especificará (de hecho, probablemente provocará un bloqueo). Tenga en cuenta que el libro Inventor Mentor contiene una descripción del comportamiento *antiguo* e *inválido* en el Capítulo 5, sección "Binding Nodes" (mitad de la página 128 en la décima impresión).

PER_PART_INDEXED
Obtiene un nuevo vector normal del pool de valores de vectores normales para cada *parte* de la forma, donde la definición de una *parte* depende del tipo de forma.

Los vectores normales se obtienen por la configuración de los valores de índice de la forma.

PER_FACE
Obtiene un nuevo vector normal del pool de valores de vectores normales para cada *cara* poligonal de la forma.

Los vectores normales se obtienen del índice 0 en adelante, incrementando el índice en el pool de vectores normales en 1 por cada nueva cara del nodo de forma.

Tenga en cuenta que las caras individuales después de la teselación de formas complejas (como los nodos SoCylinder) *no* se consideran entidades separadas, y por lo tanto, esta vinculación se tratará de la misma manera que SoNormalBinding::PER_PART para esas.

PER_FACE_INDEXED
Obtiene un nuevo vector normal del pool de valores de vectores normales para cada *cara* poligonal de la forma.

Los vectores normales se obtienen por la configuración de los valores de índice de la forma.

Tenga en cuenta que las caras individuales después de la teselación de formas complejas (como los nodos SoCylinder) *no* se consideran entidades separadas, y por lo tanto, esta vinculación se tratará de la misma manera que SoNormalBinding::PER_PART_INDEXED para esas.

PER_VERTEX
Obtiene un nuevo vector normal del pool de valores de vectores normales para cada *vértice* poligonal, de línea o puntual de la forma.

Los vectores normales se obtienen del índice 0 en adelante, incrementando el índice en el pool de vectores normales en 1 por cada nuevo vértice del nodo de forma.

PER_VERTEX_INDEXED
Obtiene un nuevo vector normal del pool de valores de vectores normales para cada *vértice* poligonal, de línea o puntual de la forma.

Los vectores normales se obtienen por la configuración de los valores de índice de la forma.

DEFAULT
Obsoleto. No utilice este valor.
NONE
Obsoleto. No utilice este valor.

Detailed Description

This node sets the binding for normals. Normals can be bound to vertices or faces. The default is per-vertex binding.

This is a node that can be inserted into a scene graph.

Normal binding determines how normals are applied to primitive shapes.

For example:

  SoNormalBinding {
    value PER_VERTEX
  }

The supported values are defined in the SoNormalBinding::SoNormalBindingType enumeration.

Member Enumeration Documentation

SoNormalBinding::SoNormalBindingType

Describes the different normal binding types.

OFF
Disables normal binding. Normals will not be used.
PER_VERTEX
Normals are specified per vertex. This is the default binding.
PER_FACE
Normals are specified per face. Each primitive (triangle, quad, etc.) has a single normal.
