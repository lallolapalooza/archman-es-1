SOAP::Deserializer(3) Documentación de Perl contribuida por el usuario SOAP::Deserializer(3)

NOMBRE

SOAP::Deserializer - el medio por el cual el kit de herramientas gestiona la conversión de XML a un objeto manejable por un desarrollador

DESCRIPCIÓN

SOAP::Deserializer proporciona el medio por el cual el XML entrante se decodifica en una estructura de datos de Perl.

MÉTODOS

context
Esto proporciona acceso al contexto de llamada de "SOAP::Deserializer". En un contexto del lado del cliente, a menudo significa una referencia a una instancia de SOAP::Lite. En un contexto del lado del servidor, significa una referencia a una instancia de SOAP::Server.

EJEMPLOS

DESERIALIZANDO XML BRUTO A UN OBJETO SOAP::SOM

Una utilidad útil para SOAP::Deserializer es para analizar documentos o fragmentos de XML brutos en un objeto SOAP::SOM. Los desarrolladores de SOAP::Lite usan esta técnica para escribir pruebas unitarias para el propio módulo SOAP::Lite. Es mucho más eficiente para probar aspectos del kit de herramientas que generar llamadas de cliente a través de la red. Esta es una forma perfecta para que los desarrolladores escriban pruebas unitarias para sus tipos de datos personalizados, por ejemplo.

Aquí hay un ejemplo de cómo el contenido XML bruto puede ser analizado en un objeto SOAP::SOM usando SOAP::Deserializer:

$xml = <<END_XML;
<foo>
  <person>
    <foo>123</foo>
    <foo>456</foo>
  </person>
  <person>
    <foo>789</foo>
    <foo>012</foo>
  </person>
</foo>
END_XML
my $som = SOAP::Deserializer->deserialize($xml);
