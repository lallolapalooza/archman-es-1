Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con tres elementos.

Description

This class is inherited from SoField and is used to store 3D vectors composed of 32-bit integers. Coin uses this class for fields that contain 3D vectors of integers.

The vector components are accessed using the indices 0, 1 and 2.

Example:

SoSFVec3i32 myVector;
myVector.setValue(10, 20, 30);
int32_t x = myVector[0]; // x is 10

The SoSFVec3i32 field class supports the standard field operations like reading and writing values, copying, and notification of changes.

The inherited methods SoField::enableNotify(), SoField::getSFType(), SoField::initClass(), SoField::isNotifyEnabled(), SoField::read(), SoField::set(), SoField::write(), SoField::registerReadWrite(), SoField::registerReadOnly() and SoField::unregister() are also available.
