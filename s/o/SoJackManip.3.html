Detailed Description

The SoJackManip wraps an SoJackDragger for convenience.

The manipulator class takes care of wrapping up the SoJackDragger in a simple and convenient API for the application programmer, making it automatically surround the geometry it influences and taking care of the book-keeping routines for its interaction with the relevant fields of an SoTransformation node.

Detailed Description

SoJackManip class.

This is the base class for manipulators that are meant to be combined with other manipulators. The manipulator can be defined by a transform node and a dragger. The manipulator takes the transform node and dragger in its constructor. If no dragger is given, the manipulator will create a default dragger for the given transform node.

Note that this class is intended to be subclassed. A `SoJackManip` instance is a part of a larger manipulator structure.

A `SoJackManip` combines a transform node and a dragger. The dragger is what the user interacts with. When the dragger is moved, the transform node is updated. The transform node is what defines the manipulator's state.
