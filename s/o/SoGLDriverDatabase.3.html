Descripción detallada

La clase SoGLDriverDatabase se utiliza para buscar características rotas/lentas en los drivers OpenGL.

Coin mantendrá una base de datos de drivers en los que hemos encontrado problemas con ciertas características, incluso si el driver OpenGL afirma que las soporta. Este es un esfuerzo para evitar bloqueos de aplicaciones o sistemas operativos cuando Coin intenta usar una característica específica. Usando esta base de datos podemos deshabilitar esta característica, o encontrar otra forma de manejarla para drivers rotos.

Función de conveniencia que comprueba si feature es soportada para context. Si feature es una extensión OpenGL, comprueba si es realmente soportada por el driver y luego llama a SoGLDriverDatabase::isBroken() para comprobar si la característica está rota para context.

Comprueba la base de datos de drivers para ver si feature está marcada como rota.

Comprueba la base de datos de drivers para ver si feature está marcada como lenta.

SbBool SoGLDriverDatabase::isFast (const cc_glglue * context, const SbName & feature) [static]

Comprueba la base de datos de drivers para ver si feature está marcada como rápida.

SbName SoGLDriverDatabase::getComment (const cc_glglue * context, const SbName & feature) [static]

Obtiene el comentario para feature en context, devuelve "undefined" si la característica no tiene entrada. Proporciona extensibilidad a la base de datos.
