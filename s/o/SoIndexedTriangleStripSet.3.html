Descripción

El nodo SoIndexedTriangleStripSet mantiene los datos para renderizar y representar de otro modo las tiras de triángulos.

Use nodos de este tipo como una forma eficaz de dibujar triángulos que están encadenados.

Para más información, consulte la documentación del nodo SoTriangleStripSet.

Para renderizar varias tiras dentro del mismo nodo, simplemente separe los índices de coordenadas con -1. Para más información sobre formas indexadas, consulte la documentación de SoIndexedShape y SoIndexedFaceSet.

Gráfico de escena de ejemplo:

#Inventor V2.1 ascii
Separator {
   Coordinate3 {
      point [
       -2 1 0, -1 -1 0, 0 1 0, 1 -1 0, 2 1 0, # primera tira, z==0
       -2 1 5, -1 -1 5, 0 1 5, 1 -1 5, 2 1 5  # segunda tira, z==5
      ]
   }
   IndexedTriangleStripSet {
      coordIndex [
       0, 1, 2, 3, 4, -1,
       5, 6, 7, 8, 9, -1
      ]
   }
}

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

IndexedTriangleStripSet {
    vertexProperty NULL
    coordIndex 0
    materialIndex -1
    normalIndex -1
    textureCoordIndex -1
}
