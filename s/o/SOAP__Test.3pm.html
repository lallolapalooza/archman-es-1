NOMBRE

SOAP::Test - Framework de prueba para SOAP::Lite

SINOPSIS

use SOAP::Test;
SOAP::Test::Server::run_for('http://localhost/cgi-bin/soap.cgi');

DESCRIPCIÓN

SOAP::Test proporciona un framework simple para probar implementaciones de servidor. Especifique su dirección (endpoint) y ejecute las pruebas proporcionadas contra su servidor. Vea t/1*.t para ejemplos.
