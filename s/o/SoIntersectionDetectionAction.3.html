Descripción Detallada

La clase SoIntersectionDetectionAction se utiliza para detectar primitivas que se cruzan en una escena.

Tenga en cuenta que solo se detectan las colisiones entre la geometría real de la escena, por lo que el contenido de algunos nodos especiales como SoText2 y SoImage (que se proyectan como gráficos de mapa de bits en el plano de la pantalla, y no como polígonos reales) no se considerarán para la detección de colisiones.

Tenga en cuenta también que la clase SoIntersectionDetectionAction no es un componente de alto rendimiento en Coin. Utilizarla de forma continua en grafos de escena complejos está destinado a ser un asesino de rendimiento.

A continuación, se muestra un ejemplo de uso simple para esta clase. Fue escrito como un marco independiente configurado para perfilar y optimizar el SoIntersectionDetectionAction. Prueba la intersección de todas las formas entre sí para el archivo cargado.

Detailed Description

Traversal action for detecting intersections between scene graph objects. This action is used to detect intersections between the primitives of scene graph objects (e.g. SoShape nodes). The action finds pairs of intersecting nodes and calls callbacks for each such pair. Callbacks can report the intersection, or they can abort the intersection detection altogether.

The action traverses the scene graph using the standard traversal mechanisms. For each pair of nodes it visits, it checks if they intersect. The default behavior is to check intersection between all pairs of shapes that are not part of the same primitive (e.g. faces of the same mesh).

To control the traversal, you may set visitation callbacks using addVisitationCallback(). These callbacks are called before the action traverses the children of a node. This allows you to skip parts of the scene graph, or to modify the traversal order.

The intersection detection itself can be controlled by setting a filter callback using setFilterCallback(). This callback is called when two shapes are found to have intersecting bounding boxes, and are about to be checked for real intersection between their primitives. If the callback returns FALSE, the intersection testing will be skipped for that pair.

The actual intersection callbacks are set using addIntersectionCallback(). These callbacks are invoked when two primitives from intersecting shapes are found to intersect.

To make sure that the action does not check intersections between primitives that are part of the same shape (e.g. the faces of a single mesh), you can use the isShapeInternalsEnabled() and setShapeInternalsEnabled() methods. By default, internal primitive intersections are disabled.

The action also supports the general SoAction mechanisms, like setting callbacks for node entry and exit (see SoCallbackAction).

void SoIntersectionDetectionAction::setFilterCallback (SoIntersectionFilterCB * cb, void * closure = NULL) [virtual]

This callback is called when two shapes are found to have intersecting bounding boxes, and are about to be checked for real intersection between their primitives.

When intersection epsilon values are in use, bounding box intersection testing is done approximately and will trigger the filter callback on boxes that are further from each other than the epsilon length.

If the callback returns TRUE, the intersection test will be performed. If the callback returns FALSE, the intersection testing will be skipped.

The API allows only one filter callback.

void SoIntersectionDetectionAction::addIntersectionCallback (SoIntersectionCB * cb, void * closure = NULL) [virtual]

Adds a callback to be called when two intersecting primitives are found in the scene.

If the callback returns ABORT, the intersection detection is aborted. If the callback returns NEXT_SHAPE, the intersection detection between these two shapes are aborted and the action continues checking other shapes. If the callback returns NEXT_PRIMITIVE, the intersection detection testing continues checking the other primitives in these two shapes.
