NOMBRE

SoDecimationPercentageElement - Almacena el porcentaje de decimation para la geometría de escena.

SINOPSIS

Incluye todos los archivos de encabezado necesarios para usar los elementos del nodo Scenegraph.

#include <Inventor/elements/SoDecimationPercentageElement.h>

Descripción Detallada

Este elemento almacena el valor del porcentaje de decimation que se utiliza para aplicar decimation a las geometrías de la escena que pueden ser decimationadas.

El valor del porcentaje de decimation está entre 0.0 y 100.0, y controla cuánta decimation se aplica. Un valor de 0.0 significa que no se aplica decimation, mientras que un valor de 100.0 significa que se aplica la decimation máxima posible.

Este elemento es utilizado por nodos de geometría que admiten decimation, como SoCoordinate3 y SoNormal, para determinar el nivel de decimation a aplicar.
