Descripción detallada

La clase SoVectorOutput se utiliza para establecer archivos de salida vectorial.

SoVectorizeAction creará un SoVectorOutput que generará salida a stdout por defecto. SoVectorizeAction::getOutput() se puede usar para obtener esta salida, y el usuario probablemente querrá establecer un archivo al que generar la salida.

Desde

Coin 2.1

TGS proporciona soporte de HardCopy como una extensión separada para TGS Inventor.
