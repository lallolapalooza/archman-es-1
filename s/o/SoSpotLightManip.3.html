Descripción detallada

La clase SoSpotLightManip se utiliza para manipular nodos de luz puntual.

Un manipulador se utiliza reemplazando el nodo que desea editar en el gráfico con el manipulador. Se utilizan "draggers" (arrastradores) para manipular el nodo. Cuando se completa la manipulación, el nodo se vuelve a insertar en el gráfico, reemplazando al manipulador.

void SoSpotLightManip::copyContents (const SoFieldContainer * from, SbBool copyconnections) [protected], [virtual]

Realiza una copia profunda de todos los datos de from en esta instancia, *excepto* las referencias externas al grafo de escena si copyconnections es FALSE.

Este es el método que debe ser sobrescrito por las subclases de nodo/motor/dragger/loquesea de extensión que necesiten tener en cuenta los datos internos que no se manejan automáticamente.

Para copiar nodos desde el código de la aplicación, no debes invocar esta función directamente, sino llamar a la función SoNode::copy():

SoNode * mynewnode = templatenode->copy();

Lo mismo se aplica a los motores.

Asegúrate de que al sobrescribir el método copyContents() en tu clase de extensión, también llames hacia arriba a su superclase principal en la jerarquía de herencia, ya que copyContents() en, por ejemplo, SoNode y SoFieldContainer realiza un trabajo importante. Debería ser algo así:

void
MyCoinExtensionNode::copyContents(const SoFieldContainer * from,
                                  SbBool copyconnections)
{
  // que las superclases padre hagan lo suyo (copiar campos, copiar
  // nombre de instancia, etc.)
  SoNode::copyContents(from, copyconnections);
  // [..luego copiar datos internos..]
}
