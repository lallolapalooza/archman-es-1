Descripción Detallada

La clase SoJackDragger es un manipulador que se puede trasladar, rotar y escalar.

Así es como se ve el manipulador con su geometría predeterminada en estado inactivo:

La traslación se realiza con este manipulador al seleccionar la caja transparente plana (traslación "x-z") o la parte media sólida del eje (traslación del eje "y"). Mantenga presionada la tecla SHIFT mientras traslada en x-z para restringir a uno de los ejes principales.

Las operaciones de escala uniforme se pueden realizar arrastrando cualquiera de los 6 cubos. No se pueden realizar operaciones de escala no uniforme con este manipulador.

Las rotaciones se invocan haciendo clic y arrastrando las partes lineales de los 3 "ejes" principales de la geometría del manipulador.

NB: Cómo rotar el manipulador puede ser un poco poco intuitivo para el usuario final. Si el manipulador se va a utilizar "tal cual", se debe añadir una buena documentación a su aplicación. Una alternativa es modificar la geometría para aumentar la asequibilidad del manipulador. Consulte la documentación de SoDragger sobre cómo cambiar la geometría de un manipulador.

Una "toma de acción" del SoJackDragger utilizado dentro de un SoClipPlaneManip:

El nombre "Jack dragger" probablemente proviene de que este manipulador fue implementado por SGI para interactuar con un modelo tipo "jack-in-the-box" en la historia de Inventor.

Para conveniencia del programador, este manipulador viene completamente empaquetado dentro de instancias de la clase SoJackManip. El manipulador SoClipPlaneManip también utiliza este manipulador para controlar un nodo SoClipPlane.

void SoJackDragger::setDefaultOnNonWritingFields (void ) [protected], [virtual]

(Nota: Este método no suele ser de interés para el desarrollador de aplicaciones que no deseen extender la biblioteca con nuevos nodekits o clases de dragger. Si lo hacen, véase la información en la documentación de la clase SoBaseKit.)

Este es un método virtual, y el código en él debería llamar a SoField::setDefault() con argumento TRUE para campos que no deben escribirse durante la exportación del gráfico.

Esto se suele hacer cuando:

1.
el valor del campo es NULL y el campo es NULL por defecto
2.
es un nodo de tipo SoGroup o SoSeparator sin hijos
3.
es un nodo de tipo lista y tiene un contenedor de SoGroup o SoSeparator sin hijos
4.
es un nodo no hoja de tipo SoGroup y todos los campos están en sus valores por defecto

Los herederos deben sobrescribir este método para realizar configuraciones adicionales para nuevos campos miembro. Debe recordar llamar al método setDefaultOnNonWritingFields() de su clase base hacia arriba.
