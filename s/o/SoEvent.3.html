Descripción detallada

La clase SoEvent es la clase base para todos los eventos de Coin.

Coin contiene su propio conjunto de clases de eventos, independientes del sistema de ventanas subyacente.

Ante eventos específicos del sistema, una traducción es realizada por las clases de dispositivo específicas de la ventana en una de las clases de objetos de evento de Coin listadas a continuación. El evento es luego enviado típicamente por el área de renderizado a un SoSceneManager que lo aplicará al grafo de escena a través de un SoHandleEventAction.

Los eventos pueden ser capturados por el usuario adjuntando un nodo SoEventCallback al grafo de escena, o pueden ser manejados automáticamente por un dragger o manipulador en el grafo.

Detailed Description

This is an abstract base class for all events. It defines the basic interface for events, such as querying the state of the modifier keys (Shift, Ctrl, Alt) and retrieving the time and position at which the event occurred.

The SoEvent::wasCtrlDown, SoEvent::wasShiftDown, and SoEvent::wasAltDown methods return true if the corresponding key was pressed when the event occurred, and false otherwise.

The SoEvent::getPosition method returns the position of the event in screen coordinates. The SoEvent::getTime method returns the time at which the event occurred.

Subclasses of SoEvent provide more specific information about the type of event (e.g., keyboard events, mouse events, etc.).
