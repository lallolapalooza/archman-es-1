NAME

SoQuadMesh — The quad mesh primitive

Description

SoQuadMesh is a scene graph node that defines a quad mesh primitive.

A quad mesh is a grid of quadrilaterals. The mesh is defined by specifying the number of vertices in each row and column. The actual vertex coordinates are then provided by the children of the SoQuadMesh node. These children should typically be an SoVertex or an SoSeparator node containing an SoVertex node.

The vertices are ordered row by row, and within each row, column by column. So, if verticesPerRow is 4 and verticesPerColumn is 3, there will be 4 * 3 = 12 vertices in total. The first row will contain vertices 0, 1, 2, 3. The second row will contain vertices 4, 5, 6, 7. The third row will contain vertices 8, 9, 10, 11.

If the number of vertices provided by the children does not match the number specified by verticesPerRow and verticesPerColumn, the mesh will be rendered incorrectly or an error may occur.

SoQuadMesh is typically used in conjunction with other nodes like SoShapeHints, SoMaterial, and SoNormal to define the appearance and properties of the mesh.
