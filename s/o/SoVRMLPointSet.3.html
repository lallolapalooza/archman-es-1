SoVRMLPointSet

A VRML PointSet node for rendering points.

Detailed Description

This node represents a collection of points. Its geometry is defined by the SoVRMLCoordinate node specified in the coord field. The points are rendered as small squares (the size of which is determined by the OpenGL state). The color of each point is determined by the SoVRMLColor node specified in the color field. If the color field is NULL, the points are drawn using the material's diffuse color. If a SoVRMLMaterial node is defined for the SoVRMLAppearance node affecting this PointSet node, the emissiveColor of the Material node shall be used to draw the points. If the color field is NULL and there is a SoVRMLMaterial node defined for the SoVRMLAppearance node affecting this PointSet node, the emissiveColor of the Material node shall be used to draw the points. More details on lighting equations can be found in 4.14, Lighting model (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14).
