SoTextureCoordinateSphere - nodo de textura que genera coordenadas de textura esféricas

Nombre

SoTextureCoordinateSphere - nodo de textura que genera coordenadas de textura esféricas

Sinopsis

#include <Inventor/nodes/SoTextureCoordinateSphere.h>

Clase heredada de: SoTextureCoordinate3

Definición de clase:

class SoTextureCoordinateSphere : public SoTextureCoordinate3

Descripción

Este nodo genera coordenadas de textura esféricas. Las coordenadas de textura se generan para que, cuando se aplique un mapa de texturas en una esfera, la textura se envuelva alrededor de la esfera sin distorsión.

Campos

Este nodo no tiene campos adicionales más allá de los definidos en sus clases base.

Uso

El nodo SoTextureCoordinateSphere se utiliza típicamente dentro de una escena de Open Inventor para asignar coordenadas de textura a objetos 3D. Cuando se aplica a una geometría, genera coordenadas de textura que se corresponden con una proyección esférica. Esto es útil para texturizar objetos esféricos o para crear efectos de mapeo de entorno.

Ejemplo de uso:

#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoSphere.h>
#include <Inventor/nodes/SoTexture2.h>
#include <Inventor/nodes/SoTextureCoordinateSphere.h>

// ... dentro de una función o método que construye la escena ...

SoSeparator *root = new SoSeparator;
root->ref();

// Crear una esfera
SoSphere *sphere = new SoSphere;
root->addChild(sphere);

// Crear un nodo de textura y asignar un mapa de texturas (simplificado)
SoTexture2 *texture = new SoTexture2;
// texture->filename = "ruta/a/tu/textura.png"; // Asignar la textura
root->addChild(texture);

// Generar coordenadas de textura esféricas
SoTextureCoordinateSphere *texCoordSphere = new SoTextureCoordinateSphere;
root->addChild(texCoordSphere);

// ... el resto de la escena ...
