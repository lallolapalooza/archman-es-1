Detailed Description

The SoArray class is a group node for setting up regular arrays of subgraphs.

SoArray presents a convenient way of duplicating a node (typically a shape node) or a complete subgraph in 1 to 3 dimensions.

The child node or subgraph can only be translated by regular offsets for all dimensions.

For more flexible functionality for duplication of geometry, see the SoMultipleCopy group node, which can do general transformations (including rotation and scaling) for its child.

FILE FORMAT/DEFAULTS:

Array {
    origin FIRST
    numElements1 1
    numElements2 1
    numElements3 1
    separation1 1 0 0
    separation2 0 1 0
    separation3 0 0 1
}

SbBool SoArray::affectsState (void ) const [virtual]

Returns TRUE if the node could have any effect on the state during traversal.

If it returns FALSE, no data in the traversal state will change from the pre-traversal state to the post-traversal state. The SoSeparator node will for instance return FALSE, as it pushes and pops the state before and after traversal of its children. All SoShape nodes will also return FALSE, as just pushing out geometry data to the rendering engine won't affect the actual rendering state.

The default method returns TRUE, on a "better safe than sorry" philosophy.

Detailed Description

This node creates arrays of nodes. An array is a group where the children are instanced multiple times based on the numElements1, numElements2, and numElements3 fields. These fields specify the number of duplicates for each X, Y, and Z axis, respectively. The separation1, separation2, and separation3 fields specify the distance between the center points of adjacent elements in each respective axis.

The origin field determines how the array elements are distributed relative to the node's local origin. It can be set to:

  • SoArray::FIRST: The origin of the array is the first element.
  • SoArray::CENTER: The origin of the array is the center of all elements.
  • SoArray::LAST: The Origin of the array is the last element.

The SoArray::doAction(), SoArray::callback(), SoArray::GLRender(), SoArray::pick(), SoArray::getBoundingBox(), SoArray::handleEvent(), SoArray::getMatrix(), SoArray::search(), SoArray::getPrimitiveCount(), and SoArray::audioRender() methods are overridden to handle the array instantiation during scene graph traversals.
