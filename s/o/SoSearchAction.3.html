Descripción Detallada

La clase SoSearchAction proporciona métodos para buscar en grafos de escena.

Los nodos se pueden buscar por puntero, tipo y nombre, o una combinación de esos criterios. Los tipos se pueden interpretar como tipos exactos, o el tipo puede coincidir con nodos derivados de él. Se puede buscar cada nodo individualmente, o se pueden seguir las reglas de recorrido normal al buscar (esto es especialmente importante de notar con respecto a los nodos switch).

Al usar más de una de las llamadas setNode(), setType() y setName(), ten en cuenta que la acción buscará nodos con una combinación "Y" de los criterios de búsqueda dados.

Uno de los errores más comunes al usar la clase SoSearchAction es llamar a la función isFound() después de realizar una búsqueda. No devuelve lo que esperarías si no has leído la documentación de esa función.

Ten en cuenta que si realizas operaciones de búsqueda en una instancia de SoSearchAction creada en la pila, puedes obtener algunos efectos secundarios desafortunados si no tienes cuidado. Dado que SoSearchAction mantiene una lista de los caminos encontrados en la última búsqueda, los nodos de estos caminos se desreferenciarán cuando la instancia de pila de SoSearchAction se destruya al final de tu función. Si la raíz de tu grafo de escena tiene entonces un conteo de referencias de cero (a menudo es útil hacer un unrefNoDelete() antes de devolver un nodo de una función para dejar la referencia al llamador), ¡la raíz del nodo se destruirá! Podría ser mejor crear una instancia en el heap de la acción de búsqueda en esos casos, ya que podrás destruir la acción de búsqueda antes de llamar a unrefNoDelete(). Otra solución sería llamar a reset() antes de llamar a unrefNoDelete() en tu objeto, ya que reset() trunca la lista de caminos.

Consulta la documentación de SoTexture2 para ver un ejemplo completo de uso de SoSearchAction.

Documentación de Enumeraciones de Miembros

enum SoSearchAction::LookFor

Especifica el criterio de búsqueda. Esto puede ser una combinación bitwise de los valores disponibles.

Enumerator

NODE
Busca por puntero de nodo.

TYPE
Busca por tipo de nodo.

NAME
Busca por nombre de nodo.


enum SoSearchAction::Interest

Especifica si la acción debe encontrar el primer nodo que coincida, el último o todos los que coincidan.

Enumerator

FIRST
Encuentra solo el primer nodo que coincide.

LAST
Encuentra solo el último nodo que coincide.

ALL
Encuentra todos los nodos que coinciden.


enum SoAction::AppliedCode

Código devuelto por getWhatAppliedTo() para indicar cómo se aplicó la acción.

Enumerator

NODE
La acción se aplicó a un solo nodo.

PATH
La acción se aplicó a un camino.

PATH_LIST
La acción se aplicó a una lista de caminos.


enum SoAction::PathCode

Código devuelto por getPathCode() para indicar la relación entre el camino actual y el camino solicitado por la acción.

Enumerator

NO_PATH
El camino actual no es un subcamino del camino solicitado.

IN_PATH
El camino actual es idéntico al camino solicitado.

BELOW_PATH
El camino actual es un subcamino del camino solicitado.

OFF_PATH
El camino actual está en un nivel diferente al camino solicitado.

void SoSearchAction::setNode (SoNode *const nodeptr)

Establece el puntero node a buscar.

La acción se configurará para establecer el "interés" de búsqueda en LookFor NODE, por lo que no es necesario llamar a SoSearchAction::setFind().

SoNode * SoSearchAction::getNode (void ) const

Devuelve el nodo que la instancia de SoSearchAction está configurada para buscar.

Tenga en cuenta que este método no devuelve lo que se encontró al aplicar la acción, solo devuelve lo que fue configurado específicamente por el usuario con setNode(). Lo que la acción encontró se devuelve mediante getPath() y getPaths().

Configura la instancia de SoSearchAction para buscar nodos del tipo dado, y nodos de clases derivadas del tipo dado si chkderived es TRUE.

La acción se configurará para establecer el "interés" de búsqueda en LookFor TYPE, por lo que no es necesario llamar a SoSearchAction::setFind().

void SoSearchAction::setFind (const int what)

Configura qué buscar en el grafo de escena. what es una máscara de bits de indicadores LookFor.

La configuración de búsqueda predeterminada es ignorar todos los nodos, pero la configuración de setFind() se actualiza automáticamente cuando se llama a cualquiera de SoSearchAction::setNode(), SoSearchAction::setType() o SoSearchAction::setName().

void SoSearchAction::setInterest (const Interest interestarg)

Configura si solo el primer, el último o todos los resultados de búsqueda son de interés. La configuración predeterminada es FIRST.

SoSearchAction::Interest SoSearchAction::getInterest (void ) const

Devuelve si solo los primeros, los últimos o todos los resultados de búsqueda se guardarán.

void SoSearchAction::setSearchingAll (const SbBool searchallarg)

Especifica si se debe realizar un recorrido normal del grafo (searchall es FALSE, que es la configuración predeterminada), o si se debe buscar cada nodo individualmente (searchall es TRUE).

Si el indicador searchall es TRUE, se buscan incluso los nodos considerados "ocultos" por otras acciones (como por ejemplo los hijos deshabilitados de los nodos SoSwitch).

Se debe usar SoBaseKit::setSearchingChildren() para buscar nodos bajo kits de nodos.

SbBool SoSearchAction::isSearchingAll (void ) const

Devuelve la configuración del método de recorrido de la acción.

SoPath * SoSearchAction::getPath (void ) const

Devuelve la ruta al nodo de interés que coincidió con los criterios de búsqueda. Si no se encontró ninguna coincidencia, se devuelve NULL.

Tenga en cuenta que si todos los resultados son de interés, el resultado de una acción de búsqueda debe obtenerse a través de SoSearchAction::getPaths().

SbBool SoSearchAction::duringSearchAll = FALSE [static]

Flag obsoleto, solo presente por compatibilidad con código antiguo de Inventor de SGI/TGS.

Está establecido como TRUE cuando se inició una búsqueda con SoSearchAction::isSearchingAll() igual a TRUE, y se resetea a FALSE después de terminar la búsqueda.

(El flag se usa en SoSwitch::affectsState() de SGI/TGS para conocer cuando SoSwitch::whichChild debe comportarse como SoSwitch::SO_SWITCH_ALL. Tenemos una solución mejor para este problema en Coin.)

void SoSearchAction::beginTraversal (SoNode * node) [protected], [virtual]

Método virtual llamado desde SoAction::apply(), es el punto de entrada para la travesía del árbol de escena.

Puede sobrescrita para inicializar la acción al inicio de la travesía, para inicializaciones específicas en las subclases de acción que heredan SoAction.

Método por defecto llama a traverse(), que debe ser implementado por cualquier sobrescripción de este método (o llamarse SoAction::beginTraversal()) para activar la travesía del árbol de escena.
