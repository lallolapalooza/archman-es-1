DESCRIPCIÓN DETALLADA

La clase SoFullPath permite examinar los hijos ocultos en las rutas.

SoPath solo permite el acceso desde el nodo principal al primer nodo con hijos ocultos, pero no más allá.

Dado que SoFullPath se deriva de SoPath y no contiene datos privados, puede convertir instancias de SoPath al tipo SoFullPath. Esto le permitirá examinar hijos ocultos.

(En realidad, no se supone que deba asignar instancias de esta clase. Solo está disponible como una "interfaz extendida" a la superclase SoPath).

Detailed Description

This class represents a full path to a node within a scene graph. It is essentially a subclass of SoPath that adds functionality for handling hidden nodes.

A full path identifies a specific node by listing all the intermediate nodes from the root of the scene graph down to the target node. This class extends the base SoPath functionality to correctly account for nodes that might be hidden from traversal.

Member Function Documentation

int SoFullPath::getIndexFromTail (const int index) const

This method overrides SoPath::getIndexFromTail() to allow clients to get the child index number for nodes based on their position from the tail, counting hidden nodes.

int SoFullPath::getLength (void ) const

This method returns the length of the path, counting hidden nodes also.
