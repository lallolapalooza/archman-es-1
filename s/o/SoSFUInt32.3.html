Descripción detallada

La clase SoSFUInt32 es un contenedor para un valor entero sin signo de 32 bits.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único valor entero sin signo de 32 bits.

Detailed Description

This field defines an unsigned integer value.

The data type SoSFUInt32 is used to store a single unsigned integer value in Coin.

It is implemented as a simple unsigned int.

The field can be copied using the assignment operator:

  SoSFUInt32 uIntField;
  uIntField = 100;

You can also copy the field from another SoSFUInt32 instance:

  SoSFUInt32 anotherUIntField = uIntField;

Use the setValue() method to set the value:

  uIntField.setValue(200);

Use the getValue() method to get the value:

  unsigned int val = uIntField.getValue();

The field is used in several nodekits, for example:

  • SoRenderStyle to specify the render style of a SoShape object.
  • SoMaterial to specify the diffuse color of an object.

Use the SoSFEnum field type to specify enumerated values.

The field type SoSFUInt32 is part of the Coin data type system and should be used when defining new Coin nodes.
