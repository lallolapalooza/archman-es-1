Descripción detallada

La clase SoSceneManager proporciona la interfaz principal entre el grafo de escena y el kit de herramientas GUI.

La clase de área de renderizado del kit de herramientas GUI que estés utilizando emplea esta clase como interfaz contra el grafo de escena. La gestión de eventos y la provisión de "ganchos" para realizar renderizados son las funciones principales de la clase.

Una instancia de la biblioteca Coin dentro de una aplicación típicamente contendrá un único objeto SoSceneManager. El puntero para este objeto se almacena en la clase de renderizado GUI.

void SoSceneManager::render (const SbBool clearwindow = TRUE, const SbBool clearzbuffer = TRUE) [virtual]

Renderiza el grafo de escena.

Si clearwindow es TRUE, borra el búfer de renderizado antes de dibujar. Si clearzbuffer es TRUE, borra los valores del búfer de profundidad antes de renderizar. Ambos argumentos normalmente deberían ser TRUE, pero pueden establecerse a FALSE para optimizar casos especiales (por ejemplo, al hacer renderizado de alambre no se necesita un búfer de profundidad).

void SoSceneManager::render (SoGLRenderAction * action, const SbBool initmatrices = TRUE, const SbBool clearwindow = TRUE, const SbBool clearzbuffer = TRUE) [virtual]

Método de renderizado utilizado para renderizado seguro en hilos.

Dado que solo un hilo puede usar una SoGLRenderAction, este método le permite proporcionar su propia SoGLRenderAction específica del hilo para renderizar la escena.

Si initmatrices es TRUE, las matrices de modelo y proyección de OpenGL se inicializarán a matrices de identidad antes de aplicar la acción.

Si clearwindow es TRUE, borra el búfer de renderizado antes de dibujar. Si clearzbuffer es TRUE, borra los valores del búfer de profundidad antes de renderizar.

Esta función es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.
