Descripción detallada

La clase SoPathSensor detecta cambios en rutas.

Si necesitas saber cuando una ruta cambia (es decir, nodos en la ruta han sido eliminados, o nuevos nodos se han añadido), usa esta sensor para obtener una notificación.

También puedes usar este sensor para detectar cuando algún nodo en la ruta se cambia.

Una SoPathSensor también puede actuar para callbacks de eliminación por sí sola y no necesita una notificación basada en el tiempo. La callBack de eliminación se invocará cuando se elimine el objeto SoPath, no cuando estés monitoreando un ruta.

Documentación de enumeraciones de miembros

Enumeración SoPathSensor::TriggerFilter

Filtro de notificación, que decide si el sensor debe triggear en cambios de rutas, cambios de nodos en la ruta, o ambos.

Enumeradores

PATH
Triggear solo en cambios de rutas.
NODES
Triggear solo en cambios de nodos. Esto puede ser nodos en la ruta, o nodos que afectan a los nodos en la ruta (nodos que actualizan el estado y están a la izquierda del nodo en la ruta).
PATH_Y_NODOS
Triggear en cambios de rutas y nodos.

Detailed Description

A path sensor is a data sensor that monitors a SoPath.

It is notified whenever the path is modified. This can happen if the path is attached to a node that gets destroyed, or if the path is explicitly modified using methods like SoPath::attach().

The sensor can be configured to store the path that triggered the notification using the setTriggerPathFlag() method. If this flag is set, the path is accessible via getTriggerPath().

void SoPathSensor::notify (SoNotList * l) [protected], [virtual]

Called from entity we are monitoring when it changes.

If this is an immediate sensor, the field and node (if any) causing the change will be stored and can be fetched by getTriggerField() and getTriggerNode(). If the trigger path flag has been set, the path down to the node is also found and stored for later retrieval by getTriggerPath().

Reimplemented from SoDataSensor.

void SoPathSensor::setTriggerPathFlag (bool flag)

If flag is true, the sensor will try to find the path to the node that caused the notification. This can be retrieved using SoDataSensor::getTriggerPath(). Note that this is only possible if the sensor is attached to a path, and the notification is triggered by a change within the subgraph traversed by the path.
