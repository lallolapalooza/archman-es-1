Descripción detallada

La clase SoMFVec2b es un contenedor para vectores SbVec2b.

Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar una matriz de vectores con dos elementos.

SoMFVec2b — Field that contains an array of 2-component vectors of bytes

SYNOPSIS

#include <Inventor/fields/SoMFVec2b.h>

  public:

    void set1Value (int index, const SbVec2b & value);
    void setValue (int8_t x, int8_t y);
    void setValue (const int8_t xy[2]);
