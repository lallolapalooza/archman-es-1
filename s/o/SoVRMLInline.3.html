Detailed Description

The SoVRMLInline class is used to insert VRML files into a scene.

The detailed class documentation is taken verbatim from the VRML97 standard (ISO/IEC 14772-1:1997). It is copyright The Web3D Consortium, and is used by permission of the Consortium:

Inline {
  exposedField MFString url        []
  field        SFVec3f  bboxCenter 0 0 0     # (-,)
  field        SFVec3f  bboxSize   -1 -1 -1  # (0,) or -1,-1,-1
}

The Inline node is a grouping node that reads its children data from a location in the World Wide Web. Exactly when its children are read and displayed is not defined (e.g. reading the children may be delayed until the Inline node's bounding box is visible to the viewer). The url field specifies the URL containing the children. An Inline node with an empty URL does nothing.

Each specified URL shall refer to a valid VRML file that contains a list of children nodes, prototypes, and routes at the top level as described in 4.6.5, Grouping and children nodes.

The results are undefined if the URL refers to a file that is not VRML or if the VRML file contains non-children nodes at the top level.

If multiple URLs are specified, the browser may display a URL of a lower preference VRML file while it is obtaining, or if it is unable to obtain, the higher preference VRML file. Details on the url field and preference order can be found in 4.5, VRML and the World Wide Web (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.5).

The results are undefined if the contents of the URL change after it has been loaded.

The bboxCenter and bboxSize fields specify a bounding box that encloses the Inline node's children. This is a hint that may be used for optimization purposes. The results are undefined if the specified bounding box is smaller than the actual bounding box of the children at any time. A default bboxSize value, (-1, -1, -1), implies that the bounding box is not specified and if needed shall be calculated by the browser. A description of the bboxCenter and bboxSize fields is in 4.6.4, Bounding boxes (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.4).

DESCRIPTION

The SoVRMLInline node is used to reference and display scene graph nodes from an external URL.

It is very similar to the SoGroup node. However, instead of containing child nodes directly, it contains a URL. When the scene graph is traversed, the SoVRMLInline node will attempt to load and instantiate the scene graph referenced by the URL. This loaded scene graph is then traversed instead of the SoVRMLInline node.

If the URL cannot be loaded (e.g. it doesn't exist, or the node references something which is not a scene graph), the SoVRMLInline node will behave like an empty SoGroup node. It will also draw a bounding box indicating its presence.

The visibility of this bounding box can be controlled using the static methods setBoundingBoxVisibility() and getBoundingBoxVisibility(). The color of the bounding box can be controlled using setBoundingBoxColor() and getBoundingBoxColor().

By default, Coin treats the loaded URL as a normal VRML/X3D file. If you want to load Inventor scene graphs, you can enable the readAsSoFile flag using setReadAsSoFile().

The default behavior is to load the URL asynchronously. If you want to load synchronously, you can set the fetchURLCB to a custom callback which loads the URL synchronously.

The SoVRMLInline node implements the SoGroup interface, so you can use addChildren(), removeChildren(), etc. on an SoVRMLInline node. These methods operate on the children of the loaded scene graph.

You can also access the loaded scene graph directly using getChildData() and setChildData(). This is useful if you want to manually load and replace the scene graph.

SoGroup, SoVRMLProtoInstance, SoVRMLNode

SoVRMLInline - A Coin3D node that can load other VRML files

#include <Inventor/nodes/SoVRMLInline.h>

Detailed Description

The SoVRMLInline node is a standard VRML node that allows you to inline other VRML files into your scene. This is useful for creating complex scenes by breaking them down into smaller, manageable parts.

When the scene graph is traversed, the SoVRMLInline node will load the specified VRML file and insert its contents into the scene graph at that point.
