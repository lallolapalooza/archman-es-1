Descripción Detallada

La clase SoVRMLIndexedLineSet se utiliza para representar una forma de línea 3D genérica.

La documentación detallada de la clase se toma textualmente del estándar VRML97 (ISO/IEC 14772-1:1997). Tiene derechos de autor de The Web3D Consortium,

y se usa con permiso del Consortium:

IndexedLineSet {
  eventIn       MFInt32 set_colorIndex
  eventIn       MFInt32 set_coordIndex
  exposedField  SFNode  color             NULL
  exposedField  SFNode  coord             NULL
  field         MFInt32 colorIndex        []     # [-1, inf)
  field         SFBool  colorPerVertex    TRUE
  field         MFInt32 coordIndex        []     # [-1, inf)
}

El nodo IndexedLineSet representa una geometría 3D formada al construir polilíneas a partir de vértices 3D especificados en el campo coord. IndexedLineSet utiliza los índices en su campo coordIndex para especificar las polilíneas conectando vértices del campo coord. Un índice de "-1" indica que la polilínea actual ha terminado y la siguiente comienza. La última polilínea puede (pero no tiene por qué) ir seguida de un "-1". IndexedLineSet se especifica en el sistema de coordenadas local y se ve afectado por las transformaciones de sus ancestros.

El campo coord especifica los vértices 3D del conjunto de líneas y contiene un nodo Coordinate. Las líneas no se iluminan, no se mapean con texturas y no participan en la detección de colisiones. El ancho de las líneas depende de la implementación y cada segmento de línea es sólido (es decir, no discontinuo). Si el campo color no es NULL, deberá contener un nodo Color. Los colores se aplican a la(s) línea(s) de la siguiente manera:

•
Si colorPerVertex es FALSE:
•
Si el campo colorIndex no está vacío, se usa un color para cada polilínea del IndexedLineSet. Debe haber al menos tantos índices en el campo colorIndex como polilíneas en el IndexedLineSet. Si el índice más grande en el campo colorIndex es N, debe haber N+1 colores en el nodo Color. El campo colorIndex no debe contener ninguna entrada negativa.
•
Si el campo colorIndex está vacío, los colores del nodo Color se aplican a cada polilínea del IndexedLineSet en orden. Debe haber al menos tantos colores en el nodo Color como polilíneas.
•
Si colorPerVertex es TRUE:
•
Si el campo colorIndex no está vacío, los colores se aplican a cada vértice del IndexedLineSet de la misma manera exacta en que se utiliza el campo coordIndex para proporcionar coordenadas para cada vértice del nodo Coordinate. El campo colorIndex deberá contener al menos tantos índices como el campo coordIndex y deberá contener marcadores de fin de polilínea (-1) exactamente en los mismos lugares que el campo coordIndex. Si el índice más grande en el campo colorIndex es N, deberá haber N+1 colores en el nodo Color.
•
Si el campo colorIndex está vacío, se utiliza el campo coordIndex para seleccionar colores del nodo Color. Si el índice más grande en el campo coordIndex es N, deberá haber N+1 colores en el nodo Color.

Si el campo color es NULL y hay un Material definido para la Apariencia que afecta a este IndexedLineSet, el emissiveColor del Material deberá usarse para dibujar las líneas. Los detalles sobre las ecuaciones de iluminación tal como afectan a los nodos IndexedLineSet se describen en 4.14, Modelo de iluminación (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14).
