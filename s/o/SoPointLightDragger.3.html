Detailed Description

This class is a dragger widget for translating a point light in a scene graph.

It can be connected to the location field of an SoPointLight node using the translation field.

To use it you will typically want to:

1. Create an instance of SoPointLightDragger.

2. Set its translation field to be the same as the location field of the SoPointLight node you want to control.

3. Add the dragger to the scene graph.

This dragger can be used in place of SoPointLightManip for manual control over the location of a point light.
