Descripción Detallada

La clase SoAlphaTest es un nodo utilizado para controlar la función de prueba alfa de GL.

Con este nodo puedes controlar la función de prueba alfa de OpenGL. La función de prueba alfa te permite descartar fragmentos basándose en su valor alfa. Por ejemplo, si estableces la función a GREATER y el valor a 0.5, solo se renderizarán los fragmentos con un valor alfa mayor que 0.5.

La prueba alfa se utiliza típicamente al renderizar texturas donde todos los píxeles son completamente opacos o completamente transparentes. Los problemas de ordenación de transparencia se evitan cuando se utiliza la prueba alfa en lugar de la mezcla, ya que la prueba de profundidad aún se puede habilitar y no se necesita ordenación ni renderizado retardado.

Para habilitar la prueba alfa en lugar de la mezcla de transparencia, inserta un nodo TransparencyType con el valor = NONE y un nodo AlphaTest con function establecido a GREATER y value a por ejemplo 0.01.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

AlphaTest {
    function NONE
    value 0.5
}

Ten en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.
Desde

Coin 4.0

Documentación de Enumeración de Miembros

enum SoAlphaTest::Function

Enumeración para las diversas funciones alfa.

Enumerador

NONE
No se realiza ninguna prueba alfa.
NEVER
Nunca pasa.
ALWAYS
Siempre pasa.
LESS
Pasa si el valor alfa entrante es menor que el valor alfa almacenado.
LEQUAL
Pasa si el valor alfa entrante es menor o igual que el valor alfa almacenado.
EQUAL
Pasa si el valor alfa entrante es igual al valor alfa almacenado.
GEQUAL
Pasa si el valor alfa entrante es mayor o igual que el valor alfa almacenado.
GREATER
Pasa si el valor alfa entrante es mayor que el valor alfa almacenado.
NOTEQUAL
Pasa si el valor alfa entrante no es igual al valor alfa almacenado.
