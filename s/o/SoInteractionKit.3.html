Detailed Description

The SoInteractionKit class is a base class for draggers.

This nodekit class makes it possible to set surrogate paths for parts. Instead of creating new geometry for the dragger, it is possible to specify an existing path in your scene to be used for interaction. All picks on this path will be handled by the dragger.

The SoInteractionKit is primarily an internal class used as a superclass for the dragger classes, and it is unlikely that it should be of interest to application programmers, unless you have very special needs in your application.

setDefaultOnNonWritingFields

void setDefaultOnNonWritingFields (void ) [protected], [virtual]

(Tenga en cuenta que es poco probable que este método sea de interés para el programador de aplicaciones que no desea extender la biblioteca con nodekits o draggers personalizados. Si está escribiendo extensiones, consulte la información en la documentación de la clase SoBaseKit.)

Este es un método virtual, y el código en él debe llamar a SoField::setDefault() con el argumento TRUE en los campos de parte que no deben escribirse durante las operaciones de exportación del grafo de escena.

Esto se hace típicamente cuando:

1.
el valor del campo es NULL y la parte es NULL por defecto
2.
es un nodo hoja SoGroup o SoSeparator sin hijos
3.
es una parte de lista hoja sin hijos y un contenedor SoGroup o SoSeparator
4.
es una parte no hoja y es de tipo SoGroup y todos los campos están en sus valores predeterminados

Las subclases normalmente deberían anular esto para hacer configuraciones adicionales para nuevos campos miembro. Desde la subclase, recuerde llamar "hacia arriba" al método setDefaultOnNonWritingFields() de su superclase.
