Public Attributes

SoSFEnum sizing

Different strategies for "unsquishing" a nonuniform scaling. Values are used by the SoAntiSquish::sizing field.

Enumerator

X
The X-axis scaling factor is used.
Y
The Y-axis scaling factor is used.
Z
The Z-axis scaling factor is used.
AVERAGE_DIMENSION
The average value of the scaling factors is used.
BIGGEST_DIMENSION
The biggest of all scaling factors is used.
SMALLEST_DIMENSION
The smallest of all scaling factors is used.
LONGEST_DIAGONAL
A unit cube is transformed by the current state transformation matrix. The scaling factor is set to the value of its longest diagonal.

SoSFBool recalcAlways

If this field is TRUE, the transformation matrix is always recalculated when this node is traversed. If FALSE, the transformation matrix is only recalculated if it has changed since the last traversal. The default is TRUE.

Documentación de Datos Miembro

SoSFEnum SoAntiSquish::sizing

La estrategia actual de "desaplastamiento". El valor predeterminado es SoAntiSquish::AVERAGE_DIMENSION.

SoSFBool SoAntiSquish::recalcAlways

Si se deben recalcular automáticamente los parámetros de desaplastamiento para cada recorrido. El valor predeterminado es TRUE.

Puede establecer esto en FALSE e invocar manualmente SoAntiSquish::recalc() si necesita un control más preciso de la geometría influenciada por este nodo.
