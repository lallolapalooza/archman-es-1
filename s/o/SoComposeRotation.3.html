Detailed Description

The SoComposeRotation class is used to compose rotations from angle and axis.

Simple usage example:

#Inventor V2.1 ascii
Separator {
   Transform {
      rotation =
      ComposeRotation { axis 0 1 0  angle =
         ElapsedTime { }.timeOut
      }.rotation
   }
   Cube { }
