Descripción detallada

La clase SoLineWidthElement cambia el valor de la configuración de ancho de línea del estado de renderización.

Las peticiones de la gráfica de escena para cambiar el valor de la línea cuando se rendericen los elementos de línea se realizarán a través de este elemento, que pasa el control a la llamada correspondiente en el bibliotecario de renderización bajo la capa.

Los nodos siguientes que rendericen elementos de línea usarán el valor de la configuración de ancho de línea (por ejemplo, los nodos SoLineSet).

NAME

SoLineWidthElement — Sets the line width.

SYNOPSIS

#include <Inventor/elements/SoLineWidthElement.h>

Methods

SoLineWidthElement::getDefault, SoLineWidthElement::override, SoLineWidthElement::set

Detailed Description

This element keeps track of the line width, which is used by line primitives.

The line width is specified in screen units.

To be able to set the line width, you have to enable GL_LINE_SMOOTH and specify the line width using glLineWidth().
