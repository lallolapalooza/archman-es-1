Descripción detallada

La clase SoPrimitiveVertex representa un vértice individual de una primitiva generada.

Las instancias de SoPrimitiveVertex se construyen al generar datos de primitivas, principalmente durante un recorrido de SoCallbackAction. Dependiendo del contexto, el vértice podría representar un solo punto 3D, uno de los dos vértices en una línea o uno de los tres vértices en un triángulo.

Detailed Description

This structure is used internally by Open Inventor to represent a single vertex in a primitive (e.g. a triangle or quad).

Normally, you won't need to interact with this class directly. However, if you are writing your own primitive nodes (e.g. inheriting from SoNode or SoShapeNode), you may need to use this class to set up the vertex data.

The SoPrimitiveVertex class is an abstract base class, and you will need to use a concrete implementation. Coin provides a default implementation called SoPrimitiveVertex, which is used by the built-in primitive nodes.

If you are writing your own primitive nodes, you can get an instance of the default vertex structure by calling SoPrimitiveVertexElement::sendVertex() within your node's GLRender or render method. This function will return a pointer to an SoPrimitiveVertex object, which you can then fill with vertex data using the various set* methods.

When you are finished setting up the vertex, you must call SoPrimitiveVertexElement::sendVertex() again, passing the same pointer, to signal the end of the vertex. This is necessary so that the vertex data can be properly flushed to the graphics pipeline.

Example:

    // Inside your node's render method...
    SoPrimitiveVertex * pv = SoPrimitiveVertexElement::sendVertex(this);
    if (pv) {
        pv->setPoint(SbVec3f(x, y, z));
        pv->setColor(SbColor(r, g, b));
        // ... set other vertex attributes ...
        SoPrimitiveVertexElement::sendVertex(this); // End of vertex
    }
