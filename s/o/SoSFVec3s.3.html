Descripción Detallada

La clase SoSFVec3s es un contenedor para un vector SbVec3s.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un solo vector con tres elementos.

SoSFVec3s - single-valued field containing a 3-component short vector

SYNOPSIS

#include <Inventor/fields/SoSFVec3s.h>

Detailed Description

This class is the container for a single 3-component vector with short components. It is used within node classes to define fields that hold such vectors.
