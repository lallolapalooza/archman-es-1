Detailed Description

The SoTrackballDragger provides the end-user with rotation and scaling interaction possibilities.

Here's how the dragger looks with its default geometry in the inactive state:

The dragger has three "bands" around a transparent sphere, which when clicked and dragged will rotate around the three principal axes. In addition, the user can define his own rotation axis by holding down a SHIFT key while clicking with the left mouse button and dragging. A new, distinctively colored axis and dragger band will be then be added.

Free-form rotation on the sphere can be done by clicking and dragging outside the predefined "rotation bands".

Scale operations are made available by holding down a CTRL key when clicking with the left mouse button. The dragger is then in scaling mode, and dragging while holding down the mouse button will uniformly scale the trackball sphere.

For the application programmer's convenience, the Coin library also provides a manipulator class called SoTrackballManip, which wraps the SoTrackballDragger into the necessary mechanisms for making direct insertion of this dragger into a scene graph possible with very little effort.

Description

The trackball dragger allows the user to rotate the camera using a virtual trackball. The trackball itself is drawn as a small sphere in the viewer. Dragging the mouse inside the sphere will rotate the camera.

The trackball dragger can be configured to provide separate rotation controls for the X, Y, and Z axes. It can also provide a control for arbitrary axis rotation.

The trackball dragger is an implementation of the SoInteractionKit class, and is derived from SoDragger. Therefore, it inherits all functionality common to draggers. This includes handling translation and scaling, as well as providing callbacks for events. Please refer to the documentation for SoDragger and SoInteractionKit for more information.

The trackball dragger has the following catalog parts:

--> this
The main nodekit for this dragger.
--> callbackList
A list of callbacks that can be attached to this dragger. The default callback, SoCallback, is used to pass interaction events up to the application.
--> topSeparator
A separator node that contains the entire geometry for the trackball dragger.
--> motionMatrix
A matrix transform that will be applied to the camera based on the trackball's motion.
--> surroundScale
A surround scale node that ensures the trackball dragger scales appropriately with respect to the viewer's camera.
--> antiSquish
An anti-squish node that prevents the trackball dragger from appearing squashed when viewed from different angles.
--> geomSeparator
A separator node that contains the geometry for the trackball dragger.
--> rotatorSwitch
A switch node that controls whether the X, Y, and Z axis rotations are enabled.
--> rotator
The geometry for the trackball itself.
--> rotatorActive
The geometry for the trackball when it is active (i.e., being dragged by the user).
--> XRotatorSwitch
A switch node that controls whether the X axis rotation is enabled.
--> XRotator
The geometry for the X axis rotation control.
--> XRotatorActive
The geometry for the X axis rotation control when it is active.
--> YRotatorSwitch
A switch node that controls whether the Y axis rotation is enabled.
--> YRotator
The geometry for the Y axis rotation control.
--> YRotatorActive
The geometry for the Y axis rotation control when it is active.
--> ZRotatorSwitch
A switch node that controls whether the Z axis rotation is enabled.
--> ZRotator
The geometry for the Z axis rotation control.
--> ZRotatorActive
The geometry for the Z axis rotation control when it is active.
--> userAxisRotation
A rotation node that allows for arbitrary axis rotation.
--> userAxisSwitch
A switch node that controls whether the arbitrary axis rotation is enabled.
--> userAxis
The geometry for the arbitrary axis rotation control.
--> userAxisActive
The geometry for the arbitrary axis rotation control when it is active.
--> userRotatorSwitch
A switch node that controls whether the user-defined rotation is enabled.
--> userRotator
The geometry for the user-defined rotation control.
--> userRotatorActive
The geometry for the user-defined rotation control when it is active.

The trackball dragger also provides the following members:

isAnimationEnabled
A boolean flag that indicates whether or not the trackball will start a spin animation after a quick drag-and-release. (Note: This feature is not yet supported in the Coin library.)
setAnimationEnabled
Sets the value of the isAnimationEnabled flag.

void SoTrackballDragger::setDefaultOnNonWritingFields (void ) [protected], [virtual]

(Be aware that this method is unlikely to be of interest to the application programmer who does not want to extend the library with new custom nodekits or draggers. If you indeed are writing extensions, see the information in the SoBaseKit class documentation.)

This is a virtual method, and the code in it should call SoField::setDefault() with argument TRUE on part fields that should not be written upon scene graph export operations.

This is typically done when:

1.
field value is NULL and part is NULL by default
2.
it is a leaf SoGroup or SoSeparator node with no children
3.
it is a leaf listpart with no children and an SoGroup or SoSeparator container
4.
it is a non-leaf part and it is of SoGroup type and all fields are at their default values

Subclasses should usually override this to do additional settings for new member fields. From the subclass, do remember to call "upwards" to your superclass' setDefaultOnNonWritingFields() method.

Reimplemented from SoDragger.
