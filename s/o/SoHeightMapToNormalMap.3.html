class SoHeightMapToNormalMap

Descripción Detallada

Motor para calcular un mapa de normales a partir de un mapa de altura.

Este motor creará un mapa de normales de textura a partir de un mapa de altura. Puedes usarlo en un archivo Inventor así:

Texture2 {
  image = HeightMapToNormalMap {
    sourceImage = Texture2 { filename "HeightMap.jpg" } . image
  } . image
}

Asegúrate de que las conexiones de campo estén activas, así ambos nodos Texture2 y el motor HeightMapToNormalMap se mantendrán en memoria (a menos que desvincules manualmente el motor), incluso aunque solo sea necesario el nodo "externo" Texture2. Esto puede generar una sobrecarga significativa de memoria.

Ten en cuenta que esta clase es una extensión de Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 3.0

Enumeración de formatos de mapa de normales disponibles.

Enumerador

INT8
Codifica las normales como un texto de 3 bytes. Esta es la única opción actualmente, ya que las texturas de float no se pueden soportar convenientemente en Coin.
