SOAP__Schema(3pm)

Paquete: perl-soap-lite

SOAP::Schema(3) Documentación de Perl aportada por el usuario SOAP::Schema(3)

NOMBRE

SOAP::Schema - proporciona un paraguas para la forma en que SOAP::Lite gestiona los esquemas de descripción de servicios

DESCRIPCIÓN

Esta clase proporciona un paraguas para la forma en que SOAP::Lite gestiona los esquemas de descripción de servicios. Actualmente, el único soporte presente es para el Lenguaje de Descripción de Servicios Web (WSDL). Esta es otra de las clases que generalmente no están diseñadas para ser instanciadas directamente por una aplicación, aunque puede serlo si se desea.

MÉTODOS

new(pares opcionales clave/valor)
$schema = SOAP::Schema->new(parse => $schema_uri);

Este es el constructor de la clase. Sin argumentos, crea un objeto vacío de la clase. Cualquier argumento que se pase se trata como pares clave/valor en los que la clave representa uno de los métodos descritos aquí, y el valor es lo que se pasa cuando se invoca el método en sí.

parse(URI de descripción del servicio)
$schema->parse('http://schemas.w3.org/soap.wsdl');

Analiza la representación interna de la descripción del servicio antes de la generación de rutinas stub para proporcionar acceso similar a métodos a los servicios remotos.

access(URI de descripción del servicio)
$schema->access('http://soap.org/service.wsdl');

Carga la descripción del servicio especificada desde la URL dada, utilizando el valor actual del accesor de esquema si no se proporciona ninguno. El contenido completo de la URL se devuelve en caso de éxito, o se lanza una excepción (a través de "die") en caso de error.

load
$schema->load;

Toma la representación interna del servicio y genera stubs de código para los métodos remotos, permitiendo que se llamen como métodos de objeto locales. Los stubs se generan para todas las funciones declaradas en la descripción WSDL con esta llamada porque es un marco de clase suficiente para permitir la creación básica de objetos para usarlos como manejadores.

schema
$current_schema = $schema->schema;

Obtiene (o establece) la representación del esquema actual que será utilizada por este objeto. El valor a pasar al establecer esto es solo la URI del esquema. Esto se pasa a otros métodos como `access` para cargar el contenido real.

services
$hashref = $schema->services;

Obtiene o establece los servicios actualmente almacenados en el objeto. Los servicios se mantienen como una referencia hash, cuyas claves y valores son la lista de valores devueltos por el analizador WSDL. Las claves representan los nombres de los servicios en sí (los nombres se han normalizado en identificadores compatibles con Perl), con valores que también son referencias hash a la representación interna del servicio en sí.

stub
Devuelve el código Perl autogenerado como una cadena. Este código se genera a partir del WSDL proporcionado por la llamada al método "service". El código contiene una definición de paquete para el servicio que se está llamando. 
my $client = SOAP::Lite->new;
my $code = $client->service($WSDL_URL)->stub;
open FILE,">ServicePackage.pm";
print FILE $code;
close FILE;
cache_dir
Establece/recupera el valor del directorio donde se almacenarán en caché los stubs generados. Si "cache_dir" es nulo, no se realizará ningún almacenamiento en caché. 
my $client = SOAP::Lite->new;
my $code = $client->cache_dir("/tmp")->service($WSDL_URL)->stub;

Si "cache_dir" no está definido, no se realizará ningún almacenamiento en caché.

cache_ttl
Establece/recupera el valor del tiempo de vida (en segundos) para los archivos cacheados. Esto solo es relevante cuando se usa junto con "cache_dir".

Si "cache_ttl" se establece en 0, la caché nunca caducará. Los archivos deberán eliminarse manualmente para refrescar la caché.

my $client = SOAP::Lite->new;
my $code = $client->cache_ttl(3600)->cache_dir("/tmp")->service($WSDL_URL)->stub;

El tiempo de vida predeterminado es 0.

useragent(LWP::UserAgent)
my $client = SOAP::Lite->new;
$ua = $client->schema->useragent;
$ua->agent("Fubar! 0.1");
my $response = $client->service("http://localhost/some.wsdl")
                      ->someMethod("Foo");

Obtiene o establece el UserAgent de la clase utilizado para recuperar esquemas a través de la web. Esto permite a los usuarios tener acceso directo al UserAgent para que puedan controlar las credenciales pasadas a un servidor remoto, o la configuración específica de su agente HTTP.

SOAP::Schema::WSDL

Actualmente, el kit de herramientas SOAP::Lite solo admite la carga de descripciones de servicios en sintaxis WSDL. Esta clase gestiona el análisis y almacenamiento de estas especificaciones de servicio. Como regla general, es aún menos probable que esta clase sea utilizada directamente por una aplicación, ya que su presencia debería estar completamente abstraída por la clase anterior (SOAP::Schema). Ninguno de los métodos se define aquí; la clase solo se menciona a modo de referencia.
