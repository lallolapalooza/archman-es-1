NOMBRE

SoTranslate1Dragger - La clase SoTranslate1Dragger proporciona un mecanismo para que el usuario final traduzca a lo largo de un eje.

SINOPSIS

#include <Inventor/draggers/SoTranslate1Dragger.h>

DESCRIPTION

The SoTranslate1Dragger class provides a 1-dimensional translation dragger. It manipulates a single translation field along a line defined by the dragger's orientation.

The dragger is composed of a manipulator geometry (the visible part) and a number of invisible fields that the user can interact with.

The dragger's fields are:

  • translation: An SoSFVec3f field that holds the current translation. The end-user can only modify the first component (X) of this field.
  • minTranslation: An SoSFFloat field that sets the minimum allowed value for the X component of the translation.
  • maxTranslation: An SoSFFloat field that sets the maximum allowed value for the X component of the translation.

The dragger manipulates the translation along the dragger's local X-axis. The application programmer should connect the relevant node fields in the scene graph to the translation field to make them follow the dragger's movement.

The minTranslation and maxTranslation fields are used to constrain the dragger's movement along the X-axis. If minTranslation is less than or equal to maxTranslation, the dragger's movement will be limited to the range specified.

The dragger also includes methods for handling user interaction, such as starting, continuing, and finishing a drag operation. These methods are protected and intended for internal use or for developers creating custom draggers.
