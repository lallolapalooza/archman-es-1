Descripción Detallada

La clase SoLabel es un nodo para mantener información de etiquetas en un grafo de escena.

Use este nodo como una forma conveniente de etiquetar nodos o subgrafos dentro de un grafo de escena.

Los nodos SoLabel no influyen en el recorrido de ninguna manera para ninguna de las acciones incorporadas.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

Label {
    label "<etiqueta indefinida>"
}
