SOAP::Lite::Packager(3) Documentación de Perl contribuida por el usuario SOAP::Lite::Packager(3)

NOMBRE

SOAP::Lite::Packager - esta clase es una clase abstracta que permite múltiples tipos de agentes de empaquetado como MIME y DIME.

DESCRIPCIÓN

La clase SOAP::Lite::Packager es responsable de gestionar un conjunto de "partes". Las partes son información adicional, documentos adicionales o virtualmente cualquier cosa que necesite asociarse con el sobre/carga útil SOAP. El empaquetador tomará estas partes y las codificará/ decodificará o las "empaquetará"/"desempaquetará" a medida que entren y salgan por la red.

MÉTODOS

new
Instancia una nueva instancia de SOAP::Lite::Packager.
partes
Contiene un array de partes. El contenido de este array y sus tipos dependen completamente del Empaquetador que se esté utilizando. Por ejemplo, cuando se utiliza MIME, el contenido de este array son entidades MIME.
push_part
Añade una parte al conjunto de partes gestionadas por la instancia actual de SOAP::Lite::Packager.
parser
Devuelve el analizador utilizado para analizar archivos adjuntos de un flujo de datos.
headers_http
Este es un punto de conexión a la capa HTTP. Proporciona una forma para que un empaquetador añada y/o modifique cabeceras HTTP en una solicitud/ respuesta. Por ejemplo, la mayoría de las capas de empaquetado necesitarán sobrescribir el Content-Type (por ejemplo, multipart/related, o application/dime).

MÉTODOS ABSTRACTOS

Si desea implementar su propio SOAP::Lite::Packager, los métodos siguientes deben ser implementados por usted de acuerdo con los requisitos prescritos de entrada y salida.

package()
La subrutina "package" toma como entrada el sobre SOAP en formato de cadena/SCALAR. Este servirá como contenido de la parte raíz. El empaquetador luego encapsula el sobre con las partes contenidas dentro de "partes" y devuelve el sobre debidamente encapsulado en formato de cadena/SCALAR.
unpackage()
La subrutina "unpackage" toma como entrada datos crudos que necesitan ser analizados en un conjunto de partes. Es responsable de extraer el sobre de la entrada y de poblar "partes" con un ARRAY de partes extraídas de la entrada. Luego devuelve el sobre SOAP en formato de cadena/SCALAR para que SOAP::Lite pueda analizarlo.

FORMATOS DE EMPAQUETADO SOPORTADOS

SOAP::Lite::Packager::MIME

"SOAP::Lite::Packager::MIME" utiliza MIME::Tools para proporcionar la capacidad de enviar y recibir solicitudes y respuestas formateadas como Multipart/Related y Multipart/Form-Data.

MÉTODOS MIME

Los siguientes métodos se utilizan al componer un mensaje formateado en MIME.

transfer_encoding
El valor de la cabecera MIME Content-Transfer-Encoding de la parte raíz. Por defecto: 8bit.
env_id
El valor de la cabecera MIME Content-Id de la parte raíz. Por defecto: <main_envelope>.
env_location
El valor de la cabecera MIME Content-Location de la parte raíz. Por defecto: /main_envelope.
env_type
El valor de la cabecera MIME Content-Type de la parte raíz. Por defecto: text/xml.

OPTIMIZACIÓN DEL ANALIZADOR MIME

El uso de archivos adjuntos a menudo puede resultar en un alto consumo de recursos del sistema dependiendo de cómo esté configurado su analizador MIME. Por ejemplo, puede instruir al analizador para que almacene los archivos adjuntos en memoria o para que utilice archivos temporales. Usar uno u otro puede afectar el rendimiento, la utilización del disco y/o la fiabilidad. Por lo tanto, debe consultar la siguiente URL para obtener técnicas de optimización y consideraciones:

http://search.cpan.org/dist/MIME-tools/lib/MIME/Parser.pm#OPTIMIZING_YOUR_PARSER

Para modificar las opciones de configuración del analizador, consulte la siguiente muestra de código, que además muestra cómo minimizar el uso de memoria:

my $packager = SOAP::Lite::Packager::MIME->new;
# $packager->parser->decode_headers(1); # sin diferencia
# $packager->parser->extract_nested_messages(1); # sin diferencia
$packager->parser->output_to_core(0); # mucha menos memoria
$packager->parser->tmp_to_core(0); # mucha menos memoria
$packager->parser->tmp_recycling(0); # promueve una recolección de basura más rápida
$packager->parser->use_inner_files(1); # sin diferencia
my $client = SOAP::Lite->uri($NS)->proxy($URL)->packager($packager);
$client->someMethod();

EJEMPLO DEL LADO DEL CLIENTE

La siguiente muestra de código muestra cómo utilizar archivos adjuntos en el contexto de un cliente SOAP::Lite.

#!/usr/bin/perl
use SOAP::Lite;
use MIME::Entity;
my $ent = build MIME::Entity
  Type        => "text/plain",
  Path        => "attachment.txt",
  Filename    => "attachment.txt",
  Disposition => "attachment";
$NS = "urn:Majordojo:TemperatureService";
$HOST = "http://localhost/cgi-bin/soaplite.cgi";
my $client = SOAP::Lite
  ->packager(SOAP::Lite::Packager::MIME->new)
  ->parts([ $ent ])
  ->uri($NS)
  ->proxy($HOST);
$response = $client->c2f(SOAP::Data->name("temperature" => '100'));
print $response->valueof('//c2fResponse/foo');

EJEMPLO DEL LADO DEL SERVIDOR

El siguiente código muestra cómo utilizar archivos adjuntos en el contexto de un script CGI. Muestra cómo leer archivos adjuntos entrantes y cómo devolver archivos adjuntos al cliente.

#!/usr/bin/perl -w
use SOAP::Transport::HTTP;
use MIME::Entity;
SOAP::Transport::HTTP::CGI
  ->packager(SOAP::Lite::Packager::MIME->new)
  ->dispatch_with({'urn:Majordojo:TemperatureService' => 'TemperatureService'})
  ->handle;
BEGIN {
  package TemperatureService;
  use vars qw(@ISA);
  @ISA = qw(Exporter SOAP::Server::Parameters);
  use SOAP::Lite;
  sub c2f {
    my $self = shift;
    my $envelope = pop;
    my $temp = $envelope->dataof("//c2f/temperature");
    use MIME::Entity;
    my $ent = build MIME::Entity
      Type        => "text/plain",
      Path        => "printenv",
      Filename    => "printenv",
      Disposition => "attachment";
    # leer archivos adjuntos
    foreach my $part (@{$envelope->parts}) {
      print STDERR "soaplite.cgi: attachment found! (".ref($part).")\n";
      print STDERR "soaplite.cgi: contents => ".$part->stringify."\n";
    }
    # enviar archivos adjuntos
    return SOAP::Data->name('convertedTemp' => (((9/5)*($temp->value)) + 32)),
      $ent;
  }
}
