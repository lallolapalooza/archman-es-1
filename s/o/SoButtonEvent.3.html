Descripción detallada

La clase SoButtonEvent es la clase base para todos los eventos de botón.

Las clases de eventos que resultan de que el usuario pulse botones en algún dispositivo (teclado, ratón o spaceball) heredan todas de esta clase. La clase SoButtonEvent contiene métodos para establecer y obtener el estado de los botones.

SoButtonEvent(3)

Nombre

SoButtonEvent - Evento de botón para una aplicación de visualización de gráficos 3D.

Sinopsis

#include <Inventor/events.h>

class SoButtonEvent : public SoEvent
{
  public:
    // Tipos
    enum ButtonType
    {
      ANY, // Cualquier botón
      BUTTON1, // Botón izquierdo
      BUTTON2, // Botón central
      BUTTON3, // Botón derecho
      BUTTON4, // Botón lateral 1
      BUTTON5 // Botón lateral 2
    };

    // Métodos
    SoButtonEvent();
    virtual ~SoButtonEvent();

    ButtonType getButton(void) const;
    void setButton(ButtonType button);

    // Funciones miembro heredadas

    virtual void        setPosition(int32_t x, int32_t y);

    virtual void        setState(uint32_t state);
    virtual const char* getClassName(void) const;
    virtual SoType      getClassType(void) const;
};

Descripción

Esta clase representa un evento de botón del ratón. Se genera cuando se presiona o se suelta un botón del ratón. La clase SoButtonEvent es la clase base para eventos de presionar y soltar botón del ratón.

Eventos

Los eventos de botón del ratón se generan cuando el usuario interactúa con el ratón. Estos eventos pueden ser utilizados por la aplicación para realizar diversas acciones, como seleccionar objetos, rotar la vista o activar menús contextuales.
