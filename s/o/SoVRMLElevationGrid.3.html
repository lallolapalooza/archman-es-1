Descripción Detallada

La clase SoVRMLElevationGrid se utiliza para representar rejillas de elevación.

La documentación detallada de la clase se toma literalmente del estándar VRML97 (ISO/IEC 14772-1:1997). Se utiliza con permiso del Consorcio Web3D, titular de los derechos de autor del Consorcio:

ElevationGrid {
  eventIn      MFFloat  set_height
  exposedField SFNode   color             NULL
  exposedField SFNode   normal            NULL
  exposedField SFNode   texCoord          NULL
  field        MFFloat  height            []      # (-inf,inf)
  field        SFBool   ccw               TRUE
  field        SFBool   colorPerVertex    TRUE
  field        SFFloat  creaseAngle       0       # [0,inf]
  field        SFBool   normalPerVertex   TRUE
  field        SFBool   solid             TRUE
  field        SFInt32  xDimension        0       # [0,inf)
  field        SFFloat  xSpacing          1.0     # (0,inf)
  field        SFInt32  zDimension        0       # [0,inf)
  field        SFFloat  zSpacing          1.0     # (0,inf)
}

NAME

SoVRMLElevationGrid — defines a grid of elevation points

SYNOPSIS

#include <Inventor/VRMLnodes/SoVRMLElevationGrid.h>

Inheritance

SoShape > SoVRMLElevationGrid

Detailed Description

This node defines a grid of elevation points that are rendered as a surface composed of quadrilaterals.

The grid is defined by the number of points in the X and Z dimensions (xDimension and zDimension), the spacing between points in those dimensions (xSpacing and zSpacing), and the height values for each grid point (height).

The height field is an array of floats, containing xDimension * zDimension values. The values are arranged row by row, corresponding to the Z dimension, for each X coordinate.

The surface can be further customized using the optional color, normal and texCoord fields. If these fields are not specified, the surface will be drawn using default values, and normals will be automatically computed.

The creaseAngle field specifies the angle between the normals of adjacent triangles. If the angle is less than creaseAngle, the two triangles will share the same normal. This is useful for controlling the appearance of sharp edges in the grid. The default value is PI/2 (90 degrees).

The ccw field specifies whether the triangles generated for the grid are counterclockwise. The default is TRUE.

The solid field specifies whether backface culling should be performed. The default is TRUE.
