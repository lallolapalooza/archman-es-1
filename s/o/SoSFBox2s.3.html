Descripción Detallada

La clase SoSFBox2s es un contenedor para un vector SbBox2s.

Este campo se usa donde los nodos, motores u otros contenedores de campos necesitan almacenar un cuadro (box).

Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.
Desde

Coin 2.5

NAME

SoSFBox2s — Field container for a 2-component box with short integers

SYNOPSIS

public:

  // Fields
  // ...

  // Method Virtuals

public:
  // Friend Functions
  friend void         SoSFBox2s::initClass(void);
  friend void         SoSFBox2s::setValue(short xmin, short ymin, short xmax, short ymax);

protected:
  // Friend Functions
  friend SoSFBox2s * SoSFBox2s::operator new(size_t);
  friend void         SoSFBox2s::operator delete(void *, size_t);
};

Detailed Description

Field container for a 2-component box with short integers. This field type holds a bounding box defined by two 2D vectors of short integers, representing the minimum and maximum corner points.

Implements SoField.
