Descripción Detallada

La clase SoFieldSensor detecta cambios en un campo.

Asocia un campo a un sensor de este tipo para ponerlo bajo vigilancia, de modo que puedas actuar sobre los cambios en el campo.

Un SoFieldSensor también puede funcionar solo para propósitos de callback de eliminación y no necesita un callback regular basado en notificaciones.

Documentación de Funciones Miembro

void SoFieldSensor::attach (SoField * field)

Asocia el sensor a un campo. Cada vez que el valor del campo cambia, el sensor se activará y llamará a la función de callback.

Un sensor de campo solo puede asociarse a un único campo a la vez. Cuando este método se invoca varias veces, cada llamada posterior reemplazará el campo que el sensor está monitoreando con el nuevo field.

Cuando el campo dado se elimina, el sensor se desasociará automáticamente.
