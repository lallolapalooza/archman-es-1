Descripción Detallada

La clase SoGetMatrixAction es una acción para acumular la matriz de transformación de un subgrafo.

Esta acción facilita el cálculo y la conversión desde y hacia el sistema de coordenadas global de tu escena y las coordenadas locales de las partes en un modelo jerárquico.

A diferencia de la mayoría de los otros tipos de acción, SoGetMatrixAction no recorre los hijos del nodo al que se aplica, sino solo el nodo en sí. Cuando se aplica a rutas (paths), se detiene en el último nodo y no continúa más allá con los hijos del nodo final.

El uso típico al consultar la posición, orientación y/o escala en espacio mundial sería el siguiente:

// Primero obtén un SoPath a través del grafo de escena hasta el
// nodo ("mynode") sobre el que deseas consultar sus transformaciones
// actuales en espacio mundial.
SoSearchAction * searchaction = new SoSearchAction;
searchaction->setNode(mynode);
searchaction->apply(myscenegraphroot);
SoPath * path = searchaction->getPath();
assert(path != NULL);
// Luego aplica SoGetMatrixAction para obtener la matriz de transformación
// completa desde el espacio mundial.
const SbViewportRegion vpr = myviewer->getViewportRegion();
SoGetMatrixAction * getmatrixaction = new SoGetMatrixAction(vpr);
getmatrixaction->apply(path);
SbMatrix transformation = getmatrixaction->getMatrix();
// Y si deseas acceder a los componentes de transformación individuales
// de la matriz:
SbVec3f translation;
SbRotation rotation;
SbVec3f scalevector;
SbRotation scaleorientation;
transformation.getTransform(translation, rotation, scalevector, scaleorientation);

DESCRIPTION

This action is used to retrieve transformation matrices from the scene graph.

It is designed to be used with the SoGetMatrixAction class which will gather the current transformation matrix for each node encountered during the traversal.

The SoGetMatrixAction class accumulates the transformation matrices of the nodes it encounters during the traversal. The accumulated matrix can be retrieved using the getMatrix() method.

The SoGetMatrixAction can also retrieve the texture transformation matrices using the getTextureMatrix() method.
