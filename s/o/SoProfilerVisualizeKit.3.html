SoProfilerVisualizeKit(3)

NOMBRE

SoProfilerVisualizeKit - Una clase que proporciona una interfaz fácil de usar para construir aplicaciones de visualización de perfiles.

SINAPSIS

#include <Inventor/profiler/SoProfilerVisualizeKit.h>

SoProfilerVisualizeKit *
myProfilerVisualizeKit = new SoProfilerVisualizeKit();

Descripción Detallada

Esta clase es una abstracción de alto nivel que encapsula las clases de visualización de perfiles de OpenInventor. Se puede utilizar para construir rápidamente aplicaciones de visualización de perfiles.
