Descripción detallada

La clase SoAuditorList se utiliza para realizar un seguimiento de los auditores de ciertas clases de objetos.

Esta clase es principalmente para uso interno (desde SoBase) y no debería ser necesario familiarizarse con ella para un uso "ordinario" de Coin.
