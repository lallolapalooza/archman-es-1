Descripción Detallada

La clase SoTextureCombine es un nodo para establecer funciones de combinación de texturas.

Este nodo es más o menos una correspondencia exacta de la extensión OpenGL ARB_texture_env_combine (incluida en OpenGL en la versión 1.3). Consulte http://oss.sgi.com/projects/ogl-sample/registry/ARB/texture_env_combine.txt para obtener más información sobre esta extensión.

Básicamente, este nodo le permite especificar hasta tres fuentes y una función para combinar esas fuentes. Además de la función, es posible aplicar operandos simples a las fuentes. En la siguiente documentación, las fuentes se denominarán Arg0, Arg1 y Arg2, al igual que en la especificación del modo de entorno de texturas ARB.

Es posible especificar tanto una operación de color como de alfa.

Este nodo tiene muchos campos, pero generalmente es suficiente configurar solo uno o muy pocos campos. La operación seleccionada decide qué valores necesita configurar. Un ejemplo común es agregar un mapa de luz a una geometría texturizada. Un mapa de luz puede verse así:

El siguiente ejemplo solo muestra cómo aplicar el mapa de luz a un cubo, con una fuente de luz en cada lado del cubo. Normalmente, las coordenadas de textura se calculan para simular una luz puntual o direccional.

Texture2 { filename "wood.jpg" }
Switch {
  whichChild -3   # se usa para activar/desactivar el mapa de luz
  TextureUnit {
    unit 1
  }
  TextureCombine {
    rgbOperation ADD_SIGNED
    rgbSource [PREVIOUS, TEXTURE]
    rgbOperand [SRC_COLOR, SRC_COLOR ]
    alphaOperation REPLACE
    alphaSource [TEXTURE]
    alphaOperand [SRC_ALPHA]
  }
  Texture2 { filename "lightmap.jpg" }
  TextureUnit { unit 0 }
}
Cube { }

Además de las funciones que puede configurar en rgbOperation (o alphaOperation), es posible crear funciones de textura más complejas combinando dos texturas que ya se han combinado. Puede usar el nodo SoSceneTexture2 para crear esas texturas. A continuación, se muestra un ejemplo que ilustra cómo implementar Arg0*Arg1

•
Arg2*Arg0, donde Arg0 = RGB de la textura1, Arg1 = RGB de la textura2, Arg2 = alfa de la textura 2:
ShapeHints { vertexOrdering COUNTERCLOCKWISE shapeType SOLID }
Separator {
  SceneTexture2 {
    size 256 256
    transparencyFunction NONE
    scene Separator {
      OrthographicCamera {
        height 2
        aspectRatio 1
        position 0 0 1
        viewportMapping LEAVE_ALONE
      }
      LightModel { model BASE_COLOR }
      Coordinate3 {
        point [ -1 -1 0, 1 -1 0, 1 1 0, -1 1 0 ]
      }
      DEF texture1 Texture2 { filename "texture1.png" }
      TextureUnit { unit 1 }
      TextureCombine {
        rgbOperation MODULATE
        rgbSource [ PREVIOUS, TEXTURE ]
        rgbOperand [ SRC_COLOR, SRC_COLOR ]
        alphaOperation REPLACE
        alphaSource [TEXTURE]
        alphaOperand [ SRC_ALPHA ]
      }
      DEF texture2 Texture2 { filename "texture2_with_alpha.png" }
      TextureCoordinate2 {
        point [0 0, 1 0, 1 1, 0 1]
      }
      FaceSet { numVertices 4 }
    }
  }
  TextureUnit { unit 1 }
  TextureCombine {
    rgbOperation ADD
    rgbSource [ PREVIOUS, TEXTURE ]
    rgbOperand [ SRC_COLOR, SRC_COLOR ]
    alphaOperation REPLACE
    alphaSource [TEXTURE]
    alphaOperand [ SRC_ALPHA ]
  }
  SceneTexture2 {
    size 256 256
    transparencyFunction NONE
    scene Separator {
      OrthographicCamera {
        height 2
        aspectRatio 1
        position 0 0 1
        viewportMapping LEAVE_ALONE
      }
      LightModel { model BASE_COLOR }
      Coordinate3 {
        point [ -1 -1 0, 1 -1 0, 1 1 0, -1 1 0 ]
      }
      USE texture1
      TextureUnit { unit 1 }
      TextureCombine {
        rgbOperation MODULATE
        rgbSource [ PREVIOUS, TEXTURE ]
        rgbOperand [ SRC_COLOR, SRC_ALPHA ]
        alphaOperation REPLACE
        alphaSource [TEXTURE]
        alphaOperand [ SRC_ALPHA ]
      }
      USE texture2
      TextureCoordinate2 {
        point [0 0, 1 0, 1 1, 0 1]
      }
      FaceSet { numVertices 4 }
    }
  }
  # map resulting texture onto a Cube
  Cube { }
}

Debería ser posible crear casi cualquier tipo de función de textura utilizando este esquema, a costa de un uso de memoria de textura adicional (las texturas intermedias), por supuesto.
