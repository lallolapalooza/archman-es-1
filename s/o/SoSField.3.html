Descripción Detallada

La clase SoSField es la clase base para campos que contienen solo un único valor.

Todos los tipos de campo que siempre deben contener solo un miembro de valor heredan de esta clase. SoSField es una clase abstracta.

Utilizas los métodos setValue() y getValue() para almacenar o recuperar el valor de los campos de valor único. Ejemplo:

SoSpotLight * lightnode = new SoSpotLight;
lightnode->on.setValue(TRUE); // El campo "on" de SoSpotLight es
                              // un campo de valor único de tipo SoSFBool.
...
...
// Cambiar el interruptor de luz.
if (lightnode->on.getValue() == FALSE)
  lightnode->on = TRUE; // Podemos usar el operador = en lugar de setValue().
else
  lightnode->on = FALSE;
...

Cuando los nodos, motores u otros tipos de contenedores de campo se escriben en un archivo, sus campos de valor único se escriben en el siguiente formato:

containerclass {
  fieldname value
  fieldname value
  ...
}

..como este, por ejemplo, un nodo SpotLight de un gráfico de escena que estará desactivado por defecto al leerlo de nuevo del archivo:

SpotLight {
  on FALSE
}

SoSField - The Coin field class

Detailed Description

The SoSField class is the base class for all the single-valued field classes in the Coin library. It is inherited from SoField.

The SoSField class is an abstract base class. You should never instantiate it directly. Instead, you should instantiate one of its derived classes, such as SoSFBool, SoSFFloat, SoSFInt32, SoSFNode, SoSFPath, SoSFString, SoSFTime, SoSFVec2f, SoSFVec3f, SoSFVec4f, etc.

All derived classes are guaranteed to be implemented using the Coin class hierarchy. This means that each derived class will have a unique SoType object which can be obtained by calling the getClassTypeId() static method.

The SoSField class contains the necessary infrastructure to manage the field's value and to handle notifications when the value changes.

Constructor & Destructor Documentation

SoSField(void)

Protected constructor. Use this constructor in your derived field classes.

The argument type must be the unique SoType object for your field class. You can obtain this by calling SoType::createType() with the base class (SoSField) and your field class name.

Example:

    static SoType s_type = SoType::createType(
        SoSField::getClassTypeId(),
        "MySFNode"
    );
    SoType
    MySFNode::getClassTypeId(void)
    {
        SoSField();
        return s_type;
    }
