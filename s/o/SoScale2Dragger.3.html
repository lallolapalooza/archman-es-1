Detailed Description

This is a 2D dragger. It provides the user with a gizmo that can be used to scale objects in the X and Y dimensions.

The dragger is implemented as a 2D circle with two handles that stick out from the center. Dragging on the circle itself scales the object along the X axis. Dragging on the handles scales the object along both the X and Y axes. The scaling is uniform if the user drags on the handles.

The dragger is implemented using the SoInteractionKit functionality, so it is necessary to invoke SoInteraction::init() before creating any draggers. See the SoInteraction documentation for more information.

The dragger is intended to be used in combination with a SoScale node. The scaleFactor field of the dragger is updated continuously while the user is dragging it. This field is then connected to the scaleFactor field of the SoScale node.

Objects of this class are reference counted and automatically destroyed when their reference count goes to 0.
