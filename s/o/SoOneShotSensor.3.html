Descripción Detallada

La clase SoOneShotSensor es un sensor que se activará una vez.

Dado que SoOneShotSensor es una subclase de SoDelayQueueSensor, se activará tan pronto como el sistema en tiempo de ejecución esté inactivo, o si está continuamente ocupado, se activará dentro de un tiempo fijo (que por defecto es 1/12 de segundo, véase SoSensorManager::setDelaySensorTimeout()).
