Descripción detallada

La clase SoSFVec2s es un contenedor para un vector SbVec2s.

Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con dos elementos.

Véase también

SoMFVec2s Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 2.0
