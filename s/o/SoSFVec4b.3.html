Descripción detallada

La clase SoSFVec4b es un contenedor para un vector SbVec4b.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con cuatro elementos.

Ver también

SbVec4b, SoMFVec4b Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 2.5
