virtual void SoGLShaderProgramElement::init (SoState * state) [virtual]

Esta función inicializa el tipo de elemento en el SoState dado. Se llama para el primer elemento de cada tipo de elemento habilitado en los objetos SoState.

Reimplementado de SoReplacedElement.

virtual void SoGLShaderProgramElement::push (SoState * state) [virtual]

Este método se llama cada vez que se requiere un nuevo elemento en una de las pilas. Esto ocurre cuando se solicita un elemento escribible, usando SoState::getElement() o indirectamente SoElement::getElement(), y la profundidad del elemento actual es menor que la profundidad del estado.

Anule este método si su elemento necesita copiar datos del elemento anterior en la cima de la pila. El método push() se llama en el nuevo elemento, y el elemento anterior se puede encontrar usando SoElement::getNextInStack().

Reimplementado de SoElement.

virtual void SoGLShaderProgramElement::pop (SoState * state, const SoElement * prevTopElement) [virtual]

Este método se llama cuando se extrae el estado, y la profundidad del elemento es mayor que la profundidad actual del estado. pop() se llama en el nuevo elemento superior de la pila, y se pasa un puntero al elemento anterior superior de la pila en prevTopElement.

Anule este método si necesita copiar alguna información de estado del elemento anterior superior de la pila.

Reimplementado de SoElement.

virtual SbBool SoGLShaderProgramElement::matches (const SoElement * element) const [virtual]

Esta función devuelve TRUE si el elemento coincide con otro elemento (de la misma clase), con respecto a la validez de la caché.

Si el elemento de extensión del programador de aplicaciones tiene una función matches(), también debe tener una función copyMatchInfo().

Reimplementado de SoReplacedElement.

virtual SoElement * SoGLShaderProgramElement::copyMatchInfo (void ) const [virtual]

Esta función crea una copia del elemento que contiene información suficiente para que la función matches() funcione.

Se utiliza para ayudar con las operaciones de caché de recorrido del grafo de escena.
