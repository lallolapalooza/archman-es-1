Descripción Detallada

La clase SoSFBox3d es un contenedor para un vector SbBox3d.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar una caja.

Tenga en cuenta que esta clase es una extensión para Coin, y no está disponible en la API original de SGI Open Inventor v2.1.
Desde

Coin 2.5

Detailed Description

A 3D bounding box field.

This field is used to store an axis-aligned bounding box defined by two 3D vectors, one for the minimum coordinates and one for the maximum coordinates.
