Descripción Detallada

La clase SoAction es la clase base para todas las acciones de recorrido.

La aplicación de acciones es el mecanismo básico en Coin para ejecutar varias operaciones en grafos de escena o caminos dentro de grafos de escena, incluyendo operaciones de búsqueda, renderizado, interacción a través de la selección, etc.

La operación básica es instanciar una acción, configurarla con parámetros diversos si es necesario, y luego llamar a su método apply() en el nodo raíz del grafo de escena (o subgrafo de un grafo de escena). La acción recorre entonces el grafo de escena desde el nodo raíz, en profundidad y de izquierda a derecha, aplicando su procesamiento específico en los nodos donde es aplicable.

(La clase SoAction y sus clases derivadas en Coin es una implementación del patrón de diseño comúnmente conocido como el patrón "Visitante".)

Aquí hay un ejemplo simple que muestra cómo usar SoWriteAction para volcar un grafo de escena en formato Inventor a un archivo:

int write_scenegraph(const char * filename, SoNode * root)
{
  SoOutput output;
  if (!output.openFile(filename)) return 0;
  // Aquí está la acción.  ;-)
  SoWriteAction wa(&output);
  wa.apply(root);
  return 1;
}

Después del recorrido, algunos tipos de acción han almacenado información sobre el (sub-)grafo de escena que se recorrió, lo cual puedes consultar a través de métodos como SoGetBoundingBoxAction::getBoundingBox(), SoRayPickAction::getPickedPoint(), SoGetPrimitiveCountAction::getTriangleCount(), etc.

Consulta las diversas acciones incorporadas para obtener más información (es decir, las subclases de esta clase), o mira el código de ejemplo de las aplicaciones de la biblioteca Coin para ver cómo se usan generalmente las acciones.

Para extender la biblioteca Coin con tus propias clases, recomendamos encarecidamente que te familiarices con el excelente libro The Inventor Toolmaker (ISBN 0-201-62493-1), que describe las tareas involucradas en detalle. Este libro fue escrito por los diseñadores originales de SGI Inventor y explica muchas de las ideas de diseño subyacentes, además de tener muchos ejemplos prácticos sobre cómo extender el toolkit de Inventor de maneras que sean fieles a las ideas de diseño fundamentales. (The Inventor Toolmaker también está disponible en la biblioteca en línea de SGI, sin costo. Ver Descargar The Inventor Toolmaker.) Leer el código fuente de las clases incorporadas en Coin también debería resultar muy útil.

// ejemplo independiente.
//
// La técnica general es heredar de SoWriteAction y sobrescribir su

// debería ser suficiente.

void SoAction::beginTraversal (SoNode * node) [protected], [virtual]

Este método virtual se llama desde SoAction::apply(), y es el punto de entrada para el recorrido real del grafo de escena.

Se puede anular para inicializar la acción al inicio del recorrido, para inicializaciones específicas en las subclases de acción que heredan de SoAction.

El método predeterminado simplemente llama a traverse(), lo cual cualquier implementación anulada del método debe hacer también (o llamar a SoAction::beginTraversal()) para activar el recorrido del grafo de escena.

Reimplementado en SoAudioRenderAction, SoCallbackAction, SoGetBoundingBoxAction, SoGetMatrixAction, SoGetPrimitiveCountAction, SoGlobalSimplifyAction, SoGLRenderAction, SoHandleEventAction, SoPickAction, SoRayPickAction, SoReorganizeAction, SoSearchAction, SoShapeSimplifyAction, SoSimplifyAction, SoToVRML2Action, SoToVRMLAction y SoWriteAction.

void SoAction::endTraversal (SoNode * node) [protected], [virtual]

Este método virtual puede anularse para ejecutar código después del recorrido del grafo de escena. El método predeterminado no hace nada.

Reimplementado en SoGLRenderAction.

void SoAction::setTerminated (const SbBool flag) [protected]

Establece el indicador de terminación.
