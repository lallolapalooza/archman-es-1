Descripción Detallada

SoFloatElement es una clase abstracta base para elementos que consisten en un único valor float.

Esta es la superclase de elementos donde el nuevo dato del elemento *reemplaza* al antiguo y donde el dato que el elemento almacena es un valor float simple de precisión simple.

Este elemento es como una versión ligera y conveniente de SoReplacedElement. Se diferencia de SoReplacedElement en que los métodos set() y get() ya están implementados, ya que se sabe que las subclases contendrán solo un valor float.

Detailed Description

This element is used to store and retrieve float values within the scenegraph state.

It is an abstract base class, and concrete implementations (derived classes) store and manage the actual float value.

The standard way to interact with this element is by using the getClassElement(state) method to get a pointer to the element instance for the current state, and then calling setValue() on that instance.

There are also static helper methods like set() and get() available for convenience.

Note: This class is intended for internal use by Coin.
