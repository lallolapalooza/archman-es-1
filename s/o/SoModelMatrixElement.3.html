Descripción Detallada

La clase SoModelMatrixElement se utiliza para gestionar la transformación actual.

El SoModelMatrixElement contiene la matriz de transformación objeto-a-mundo.

La transformación mundo-a-cámara se almacena en la clase SoViewingMatrixElement.

Nota: Algo que puede ser un poco confuso con la API es que SoModelMatrixElement no contiene la misma matriz que la matriz GL_MODELVIEW de OpenGL.

Ver también

SoViewingMatrixElement

void SoModelMatrixElement::push (SoState * state) [virtual]

Este método se llama cada vez que se requiere un nuevo elemento en una de las pilas. Esto ocurre cuando se solicita un elemento escribible, utilizando SoState::getElement() o indirectamente SoElement::getElement(), y la profundidad del elemento actual es menor que la profundidad del estado.

Anule este método si su elemento necesita copiar datos de la parte superior anterior de la pila. El método push() se llama en el nuevo elemento, y el elemento anterior se puede encontrar usando SoElement::getNextInStack().
