Descripción Detallada

La clase SoFieldConverter es la clase base abstracta para los convertidores de campos.

Cuando se intentan conectar campos de diferentes tipos, la biblioteca Coin intenta encontrar una clase convertidora de campos que pueda insertarse entre ellos, actuando como un filtro que convierte los valores del campo maestro a valores que coincidan con el tipo del campo esclavo.

Si es posible una conversión de tipo de valor (como entre un campo SoSFFloat y un campo SoSFInt32, por ejemplo, donde podríamos hacer una simple conversión de tipos para convertir el valor de uno a otro), se inserta un objeto derivado de SoFieldConverter.

Esta clase es la superclase base abstracta de la que todos los convertidores de campos de este tipo deben heredar.

Coin viene con una clase convertidora de campos incorporada que se encarga de todas las conversiones posibles de campo a campo que conocemos. Esto significa que los programadores de aplicaciones rara vez necesitarán preocuparse por esta clase, probablemente solo será útil si expande la biblioteca Coin con sus propias clases de tipos de campo. (Hacerlo se considera un uso avanzado de la biblioteca).
