       Detailed Description
      

      

       This node defines a cube map texture. A cube map texture is a texture that
       is defined by six square textures, which are mapped onto the faces of a
       cube. A cube map texture is typically used for environment mapping,
       reflection mapping, and skyboxing.
      

      

       The six faces are defined in the following order: +X, -X, +Y, -Y, +Z, -Z.
       The faces can be defined using either filenames or image data.
      

      

       The texture coordinates for a cube map are specified as a 3D vector (s, t,
       r). The vector components are used to determine which face of the cube map
       to sample from, and the direction of the vector is used to interpolate
       across the face.
      

      

       The wrapS, wrapT, and model fields control how the
       texture is applied to the geometry.
      

      

       The blendColor field is used when the model is set to
       SoTextureCubeMap::BLEND. It specifies the color to blend with the
       texture.
