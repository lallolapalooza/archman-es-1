Descripción Detallada

La clase SoMarkerSet muestra un conjunto de marcadores de mapa de bits 2D en 3D.

Este nodo utiliza las coordenadas actualmente en el estado (o en el campo vertexProperty) en orden. El campo numPoints especifica el número de puntos en el conjunto.

Además de proporcionar al usuario un conjunto de marcadores estándar para elegir, también es posible especificar sus propios mapas de bits para los marcadores.

Esta clase de nodo es una extensión de la API original SGI Inventor v2.1. Además de ser una extensión de Coin, también está presente en la implementación de Inventor de TGS. (Tenga en cuenta que la implementación de TGS no soporta el valor de índice de marcador NONE.)

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

MarkerSet {
    vertexProperty NULL
    startIndex 0
    numPoints -1
    markerIndex 0
}

void SoMarkerSet::addMarker (int idx, const SbVec2s & size, const unsigned char * bytes, SbBool isLSBFirst = TRUE, SbBool isUpToDown = TRUE) [static]

Reemplaza el mapa de bits para el marcador en idx con la representación dada por las dimensiones size con los datos del mapa de bits en bytes. isLSBFirst e isUpToDown indican cómo están ordenados los datos del mapa de bits. No hace nada si markerIndex es NONE.

Aquí tienes un ejemplo de uso completo que demuestra cómo configurar un marcador especificado por el usuario a partir de un mapa de caracteres. Ten en cuenta que los datos del mapa de bits "multicolor" se convierten a un mapa de bits monocromático antes de pasarlos a addMarker() porque addMarker() solo soporta mapas de bits.

const int WIDTH = 18;
const int HEIGHT = 19;
const int BYTEWIDTH = (WIDTH + 7) / 2;
const char coin_marker[WIDTH * HEIGHT + 1] = {
  ".+                "
  "+@.+              "
  " .@#.+            "
  " +$@##.+          "
  "  .%@&##.+        "
  "  +$@&&*##.+      "
  "   .%@&&*=##.+    "
  "   +$@&&&&=-##.+  "
  "    .%@&&&&&-;#&+ "
  "    +$@&&&&&&=#.  "
  "     .%@&&&&*#.   "
  "     +$@&&&&#.    "
  "      .%@&@%@#.   "
  "      +$%@%.$@#.  "
  "       .%%. .$@#. "
  "       +$.   .$>#."
  "        +     .$. "
  "               .  "
  "                  " };
int byteidx = 0;
unsigned char bitmapbytes[BYTEWIDTH * HEIGHT];
for (int h = 0; h < HEIGHT; h++) {
  unsigned char bits = 0;
  for (int w = 0; w < WIDTH; w++) {
    if (coin_marker[(h * WIDTH) + w] != ' ') { bits |= (0x80 >> (w % 8)); }
    if ((((w + 1) % 8) == 0) || (w == WIDTH - 1)) {
      bitmapbytes[byteidx++] = bits;
      bits = 0;
    }
  }
}

Description

                
The SoMarkerSet node is used to define the markers used by SoMarker nodes. You can use the static methods addMarker(), getMarker() and removeMarker() to manage the set of markers.

                
The markers are identified by an index. By default, SoMarkerSet defines only one marker, a 5x5 cross shape. The index of this marker is MYAPP_CROSS_5_5. It can be set to be displayed by setting the markerIndex field to MYAPP_CROSS_5_5.

                
You can add your own markers by calling SoMarkerSet::addMarker(). This method returns the index of the new marker. You can then use this index in your SoMarker nodes.

SbBool SoMarkerSet::addMarker (int idx, const SbVec2s & size, const unsigned char * bytes, SbBool isLSBFirst)

                    
Adds a new marker to the set. The marker is identified by idx, and is described by size (width and height), bytes (the marker's bitmap data) and isLSBFirst (whether the bitmap data is stored with the least significant bit first).

                    
If a marker with the same index already exists, it will be replaced. If the marker is successfully added, TRUE is returned, otherwise FALSE is returned.

                    
The following example adds an arrow marker:

                    
// add at end
SoMarkerSet::addMarker(MYAPP_ARROW_IDX, SbVec2s(WIDTH, HEIGHT),
                       bitmapbytes, FALSE, TRUE);

                    
This will provide you with an index given by MYAPP_ARROW_IDX which can be used in SoMarkerSet::markerIndex to display the new marker.

                

                

                    
SbBool SoMarkerSet::getMarker (int idx, SbVec2s & size, const unsigned char *& bytes, SbBool & isLSBFirst) [static]

                    
Returns data for marker at idx in the size, bytes and isLSBFirst parameters.

                    
If no marker is defined for given idx, or SoMarkerSet::markerIndex is NONE (not removable), FALSE is returned. If everything is OK, TRUE is returned.

                

                

                    
SbBool SoMarkerSet::removeMarker (int idx) [static]

                    
Removes marker at idx.

                    
If no marker is defined for given idx, or SoMarkerSet::markerIndex is NONE (not removable), FALSE is returned. If everything is OK, TRUE is returned.

                

                

                    
SbBool SoMarkerSet::isMarkerBitSet (int idx, int bitNumber) [static]

Member Data Documentation

                

                    
SoMFInt32 SoMarkerSet::markerIndex

                    
Contains the set of index markers to display, defaults to 0 (CROSS_5_5). The special value NONE renders nothing for that marker.
