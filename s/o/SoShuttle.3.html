Descripción Detallada

La clase SoShuttle se utiliza para oscilar entre dos transiciones.

Se crea una transición suave entre translation0 y translation1 utilizando una función coseno. Al principio del ciclo, se utiliza translation0. A mitad del ciclo, la transición resultante es igual a translation1, y al final del ciclo, volvemos a translation0.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

Shuttle {
    translation 0 0 0
    translation0 0 0 0
    translation1 0 0 0
    speed 1
    on TRUE
}

SO SHUTTLE MANUAL

NAME

SoShuttle - A simple object to manage the Shuttle subsystem of a game.

SYNOPSIS

This class is a subclass of SoObject and inherits all of its methods.

Detailed Description

This class provides an interface for managing the Shuttle subsystem of a game. It allows for the creation, destruction, and manipulation of shuttle objects within the game world. The Shuttle subsystem is responsible for handling all aspects of player-controlled or AI-controlled shuttles, including movement, targeting, weapon systems, and interaction with other game entities.

Constructor & Destructor Documentation

SoShuttle()
The default constructor initializes a new SoShuttle object. It sets up the necessary internal data structures and prepares the subsystem for use.
~SoShuttle()
The destructor releases any resources allocated by the SoShuttle object. This includes cleaning up any active shuttle objects and freeing memory.

Member Function Documentation

createShuttle(int id, const std::string& modelName, const SoVector3& position, const SoQuaternion& rotation)
Creates a new shuttle with the given parameters.
  • id: A unique identifier for the shuttle.
  • modelName: The name of the model to use for the shuttle's appearance.
  • position: The initial position of the shuttle in the game world.
  • rotation: The initial rotation of the shuttle.
Returns the ID of the newly created shuttle.
destroyShuttle(int id)
Destroys the shuttle with the specified ID. If the shuttle exists, it will be removed from the game world and its resources released.
  • id: The ID of the shuttle to destroy.
getShuttle(int id)
Retrieves a pointer to the shuttle object with the specified ID.
  • id: The ID of the shuttle to retrieve.
Returns a pointer to the SoShuttle object or nullptr if no shuttle with that ID exists.
update(float deltaTime)
Updates the state of all shuttles in the subsystem. This function should be called every frame.
  • deltaTime: The time elapsed since the last update.
render()
Renders all active shuttles in the game world. This function should be called as part of the game's rendering loop.

Member Data Documentation

m_shuttles
A map storing all active shuttle objects, keyed by their unique IDs. This is a private member and should not be accessed directly.
