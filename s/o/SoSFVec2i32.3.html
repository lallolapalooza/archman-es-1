Descripción detallada

La clase SoSFVec2i32 es un contenedor para un vector SbVec2i32.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con dos elementos.

Véase también

SbVec2i32, SoMFVec2i32 Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 2.5

SYNOPSIS

Classes

Detailed Description

This class is a container for a 2D vector of signed 32-bit integers. It is derived from SoField.

The vector consists of two components, x and y.
