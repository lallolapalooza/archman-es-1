Descripción detallada

La clase SoError es la clase base para todas las clases de manejo de errores.

El manejador de errores predeterminado simplemente imprime mensajes en el canal de salida de error estándar, pero esto puede ser sobrescrito por las aplicaciones cliente.

Poder sobrescribir el manejador predeterminado es útil cuando se desea recopilar mensajes de error, por ejemplo, al importar un modelo, para presentar posteriormente los mensajes al usuario de cualquier manera personalizada (como, por ejemplo, en un cuadro de mensaje gráfico).

La clase SoError no está diseñada para ser particularmente útil para un "uso directo". Dentro de la biblioteca Coin, solo se utiliza a través de sus subclases.

SoError - Base class for all Coin errors

Detailed Description


This is the base class for all errors in the Coin library. It defines
    an interface for handling errors that is used by all its subclasses.


The error handling mechanism in Coin is based on callbacks. For each
    error class (e.g. SoReadError), an application can register a
    callback function and associated user data. When an error of that class
    occurs, the registered callback is invoked.


The base SoError class provides
    methods to set and retrieve the callback function and user data. It also
    provides a mechanism for storing an optional debug string, which can be
    used to provide more specific information about the error.

Member Function Documentation




void SoError::setHandlerCallback(SoErrorClass_cb_func_ptr callback, void *const data)


Sets the callback function and user data for handling errors of
    this class and its subclasses. The callback function will be
    invoked when an error of this class occurs. The data argument
    is a pointer to user-defined data that will be passed to the callback
    function.


This method is intended to be called by subclasses during their
    initialization to set up their specific error handling mechanisms.






const SoErrorClass_cb_func_ptr SoError::getHandlerCallback()


Returns the currently registered callback function for handling
    errors of this class.






void *const SoError::getHandlerData()


Returns the user data associated with the registered callback
    function.


These two methods (getHandlerCallback and
    getHandlerData) provide a way to retrieve the current
    error handler settings. They essentially wrap around the
    getHandlerCallback() and getHandlerData()
    methods.


Reimplemented in SoDebugError,
    SoMemoryError, and SoReadError.

void SoError::handleError() [protected]


This method calls the appropriate handler for an error instance.
    All error handling goes through this method, and is therefore a good
    candidate for a debugger breakpoint.
