Descripción Detallada

La clase SoSFVec4us es un contenedor para un vector SbVec4us.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un solo vector con cuatro elementos.

Ver también

SbVec4us, SoMFVec4us Ten en cuenta que esta clase es una extensión para Coin, y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 2.5

Detailed Description

This field is used to store vectors with four components, each being an unsigned short integer.

Use setValue() to set the value.
