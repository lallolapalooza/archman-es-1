Descripción detallada

La clase SoTempPath se utiliza para almacenar rutas temporales.

La ruta simplemente desactiva la auditoría en el constructor, y deja al usuario la responsabilidad de mantener la ruta válida.

Documentación de funciones miembro

void SoTempPath::simpleAppend (SoNode *const node, const int index)

Añade un nodo (especificado por node e index de hijo del padre) a la ruta. Este método solo está disponible en SoTempPath, ya que no considerará la auditoría ni los hijos ocultos.

void SoTempPath::replaceTail (SoNode *const node, const int index)

Replace the tail of this path. The node is specified by node and parent child index. This method is only available in SoTempPath, since it will not consider auditing or hidden children.
