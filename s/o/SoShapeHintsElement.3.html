Detailed Description

This element stores shape hints for rendering primitives such as polygons, lines and points.

It's intended for use by shape nodes and is used to give hints to the rendering system about how the shape should be drawn.

The element stores:

  • The winding order of vertices (clockwise or counter-clockwise). This can affect which side of a polygon is considered the front face. See VertexOrdering.
  • The general type of shape being rendered (e.g. polygon, line, point). See ShapeType.
  • Whether faces should be rendered front-side only, back-side only, or both. See FaceType.

The element is often overridden by specific rendering backend implementations (e.g. SoGLShapeHintsElement) to provide backend-specific information.
