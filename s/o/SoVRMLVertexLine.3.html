NAME

SoVRMLVertexLine — VRML97 VertexLine node

SYNOPSIS

#include <Inventor/VRML97/SoVRMLVertexLine.h>

Detailed Description

This node draws lines based on a list of vertex coordinates. It should be used within a VRML97Shape node.

The lines are drawn based on the coordinate values defined in the coord field. The colors can be defined in the color field. If colorPerVertex is TRUE, colors are bound per vertex. Otherwise, colors are bound per line.

It is possible to bind per-vertex colors using the color field and setting colorPerVertex to TRUE. It is also possible to bind per-line colors by setting colorPerVertex to FALSE.

This node requires an SoVRMLCoordinate node in its coord field.
