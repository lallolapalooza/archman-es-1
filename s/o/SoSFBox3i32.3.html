Descripción detallada

La clase SoSFBox3i32 es un contenedor para un vector SbBox3i32.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar una caja.

Tenga en cuenta que esta clase es una extensión para Coin, y no está disponible en la API original de SGI Open Inventor v2.1.
Desde

Coin 2.5

NAME

SoSFBox3i32 — A 3D bounding box field (signed 32-bit integers)

SYNOPSIS

DESCRIPTION

This field is used to store 3D bounding boxes. It is defined by two 3D vectors, which represent the minimum and maximum corner coordinates.

The coordinates are signed 32-bit integers.
