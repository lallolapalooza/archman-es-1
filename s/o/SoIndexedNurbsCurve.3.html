Detailed Description

This node defines a non-uniform rational B-spline (NURBS) curve. A NURBS curve is defined by a set of control points, a knot vector, and a degree.

The control points are specified via the coordIndex field. It refers to indices into the currently active coordinate list. The number of control points used is specified via the numControlPoints field.

The curve's knot vector is specified via the knotVector field. The knot vector is a sequence of non-decreasing numbers that determines the parameter values at which the curve is evaluated.

The degree of the curve is specified via the degree field. If the degree is greater than the number of control points minus one, it is clamped to the number of control points minus one.

The curve is evaluated by sampling it at points along its parameter range. The number of samples is determined by the subdivision field of the SoShape superclass. If subdivision is negative, a default value of 100 is used.

The curve can be evaluated in 2D or 3D space. If the coordinates in the active list are 2D, the curve is evaluated in the XY plane. Otherwise, it is evaluated in 3D space.

The SoIndexedNurbsCurve node inherits from SoShape, so it can be used in scenegraphs and rendered by SoAction traversals.
