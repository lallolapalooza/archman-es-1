Detailed Description

This class implements the OpenGL geometry shader type.

Geometry shaders are programmable shaders that can take arbitrary quasiprimitives (points, lines, triangles) as input and emit an arbitrary number of new primitives (points, line strips, triangle strips) as output.

To use this class, you typically first create an instance of SoVertexShader and SoFragmentShader. Then, create an instance of this class.

Finally, you combine them using SoShaderProgram:

    SoVertexShader *vs = new SoVertexShader;
    vs->setSourceCode(// ... vertex shader code ...);

    SoGeometryShader *gs = new SoGeometryShader;
    gs->setSourceCode(// ... geometry shader code ...);
    gs->inputType.setValue(TRIANGLES_IN);
    gs->outputType.setValue(TRIANGLE_STRIP_OUT);
    gs->maxEmit.setValue(10);

    SoFragmentShader *fs = new SoFragmentShader;
    fs->setSourceCode(// ... fragment shader code ...);

    SoShaderProgram *shaderProgram = new SoShaderProgram;
    shaderProgram->addShaderProgram(vs);
    shaderProgram->addShaderProgram(gs);
    shaderProgram->addShaderProgram(fs);

    Coin/SceneGraph *scene = ...;
    scene->addChild(shaderProgram);

Note that the setGeometryCode method is inherited from SoShaderObject. The original method has been overloaded to also accept the input and output primitive types.

However, isSupported must be called after the OpenGL context has been created.

Reimplemented from SoShaderObject.

Member Function Documentation

setGeometryCode

Sets the source code for the geometry shader.

Various overloads are provided to set the source code from a string, a string literal, or a file. The `SourceType` enum can be used to specify the source code type, and `entryPointName` can be used to specify the name of the entry point function within the source code. `defs` and `includePaths` can be used to provide preprocessor definitions and include paths, respectively.

Reimplemented from SoShaderObject.

isSupported

Returns a boolean indicating whether the requested source type is supported by the OpenGL driver or not.

Beware: To get a correct answer, a valid OpenGL context must be available.

Reimplemented from SoShaderObject.

Static Method

This static version is useful for checking support before creating an instance of the class. However, it still requires a valid OpenGL context to be available.

Member Data Documentation

inputType

The type of geometry used as input to the shader. Default value is TRIANGLES_IN.

outputType

The type of geometry generated from the shader. Default value is TRIANGLE_FAN_OUT.

maxEmit

The maximum number of vertices emitted from the shader. Default value is 8. This corresponds to the GL_GEOMETRY_VERTICES_OUT_EXT enum.
