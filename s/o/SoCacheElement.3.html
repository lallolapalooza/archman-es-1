void SoCacheElement::push (SoState * state) [virtual]

Este método se llama cada vez que se requiere un nuevo elemento en una de las pilas. Esto ocurre cuando se solicita un elemento escribible, usando SoState::getElement() o indirectamente SoElement::getElement(), y la profundidad del elemento actual es menor que la profundidad del estado.

Anule este método si su elemento necesita copiar datos del elemento anterior en la pila. El método push() se llama en el nuevo elemento, y el elemento anterior se puede encontrar usando SoElement::getNextInStack().

void SoCacheElement::pop (SoState * state, const SoElement * prevTopElement) [virtual]

Este método se llama cuando se extrae el estado, y la profundidad del elemento es mayor que la profundidad del estado actual. pop() se llama en el nuevo elemento superior de la pila, y se pasa un puntero al elemento anterior superior de la pila en prevTopElement.

Anule este método si necesita copiar alguna información de estado del elemento anterior superior de la pila.

Detailed Description

This element stores the current cache object in the traversal state.

The cache is automatically managed by the cache mechanism. You should not set or unset the cache element manually. It is managed by the SoCache nodes.

Constructor & Destructor Documentation

void * SoCacheElement::cache (SoState *state) [static]

Returns the cache object for the given state. This method is called by the cache mechanism itself.

SbBool SoCacheElement::anyOpen (SoState *const state) [static]

This method returns TRUE if a cache is currently open.

void SoCacheElement::invalidate (SoState *const state) [static]

This method invalidates open caches. It should be called by uncacheable nodes.

SbBool SoCacheElement::matches (const SoElement * element) const [virtual]

SoCacheElement objects should not be compared because you obviously don't cache them in the cache.

SoCacheElement objects should not be "copied" because you obviously don't cache them in the cache.

This method returns the next cache element. That is the next cache element pointing towards the bottom of the state.

This method adds element to the elements used lists of all the open caches in state.
