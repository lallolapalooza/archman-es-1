NAME

SoMFVec2i32 — field container for array of 2-element vectors

SYNOPSIS

#include <Inventor/fields/SoMFVec2i32.h>

Inherits SoMField.

Inherited field SoField members: enableNotify, getFieldCache, getName, getNode, getTypeId, isDefault, notify, read, registerNotify, setContainer, setDepend, startNotify, touch, unregisterNotify, write

Public member functions inherited from SoField: createOppositeInstance, get, getContainer, getEventOut, getIdx, set, setEventIn

Public member functions inherited from ScdField: None.

Public member functions inherited from ScdObject: None.

Public member functions inherited from ScdBaseField: None.

Public member functions inherited from ScdBaseObject: None.

Detailed Description

This field is used where nodes, engines or other field containers need to store an array of vectors with two elements.

This field supports application data sharing through a setValuesPointer() method. See SoMField documentation for information on how to use this function.

See also

SbVec2i32, SoSFVec2i32 Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.

Since

Coin 2.5
