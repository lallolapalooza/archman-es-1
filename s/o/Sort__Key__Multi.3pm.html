NOMBRE

Sort::Key::Multi - ordenaciones simples de claves múltiples

SINOPSIS

use Sort::Key::Multi qw(sikeysort);
my @data = qw(foo0 foo1 bar34 bar0 bar34 bar33 doz4)
my @sisorted = sikeysort { /(\w+)(\d+)/} @data;

DESCRIPCIÓN

Sort::Key::Multi crea subrutinas de ordenación de claves múltiples y las exporta al paquete llamante.

Los nombres de los ordenadores son de la forma "xxxkeysort" o "xxxkeysort_inplace", donde "xxx" determina el número y los tipos de las claves de la siguiente manera:

+ "i" indica una clave entera, "u" indica una clave entera sin signo, "n" indica una clave numérica, "s" indica una clave de cadena y "l" indica una clave de cadena que obedece la configuración de orden de localización.

+ Los caracteres de tipo pueden ir precedidos de "r" para indicar orden inverso.

+ Un número que sigue a un carácter de tipo indica que el tipo de clave debe repetirse tantas veces (por ejemplo, "i3" es equivalente a "iii" y "rs2" es equivalente a "rsrs").

+ Se pueden usar guiones bajos ("_") libremente entre los indicadores de tipo.

Por ejemplo:

use Key::Sort::Multi qw(iirskeysort
                        i2rskeysort
                        i_i_rs__keysort
                        i2rs_keysort);

exporta al paquete llamante cuatro funciones de ordenación idénticas que toman dos claves enteras que se ordenan en orden ascendente y una clave de cadena que se ordena en orden descendente.

Los ordenadores generados toman como primer argumento una subrutina que se utiliza para extraer las claves de los valores que se pasan dentro de $_, por ejemplo:

my @data = qw(1.3.foo 1.3.bar 2.3.bar 1.4.bar 1.7.foo);
my @s = i2rs_keysort { split /\./, $_ } @data;

VER TAMBIÉN

Para un generador de ordenadores de claves múltiples más general, consulte Sort::Key::Maker.
