Detailed Description

A perspective camera defines a viewing frustum with a specific vertical angle of view (field of view). This is the most common type of camera used for 3D rendering, as it mimics the way the human eye perceives depth.

The camera's viewing frustum is defined by the following parameters:

  • position: The location of the camera in 3D space.
  • direction: The direction the camera is looking.
  • near distance: The distance to the near clipping plane.
  • far distance: The distance to the far clipping plane.
  • height angle: The vertical angle of the viewport (field of view).
  • aspect ratio: The ratio of the viewport's width to its height.

The heightAngle field controls the vertical field of view. A larger angle results in a wider view, while a smaller angle results in a narrower, more magnified view. The default value is 45 degrees.

The aspect parameter in methods like getViewVolume() and viewBoundingBox() is used to specify the aspect ratio of the viewport. This is crucial for ensuring that objects are not distorted during rendering.

SbViewVolume SoPerspectiveCamera::getViewVolume (float aspect) const const [virtual]

Returns the camera's view volume based on the provided viewport aspect ratio. This method calculates the viewing frustum parameters and returns them as an SbViewVolume object.

The aspect parameter is the ratio of the viewport width to its height. If you want to get the view volume as it is used during rendering, you should use getViewVolume(SbViewportRegion & vp, const SbMatrix & mm), or do something like this:

SbViewVolume vv;
float aspectratio = myviewport.getViewportAspectRatio();
switch (camera->viewportMapping.getValue()) {
case SoCamera::CROP_VIEWPORT_FILL_FRAME:
case SoCamera::CROP_VIEWPORT_LINE_FRAME:
case SoCamera::CROP_VIEWPORT_NO_FRAME:
  vv = camera->getViewVolume(0.0f);
  break;
case SoCamera::ADJUST_CAMERA:
  vv = camera->getViewVolume(aspectratio);
  if (aspectratio < 1.0f) vv.scale(1.0f / aspectratio);
  break;
case SoCamera::LEAVE_ALONE:
  vv = camera->getViewVolume(0.0f);
  break;
default:
  assert(0 && "unknown viewport mapping");
  break;
}

Also, for the CROPPED viewport mappings, the viewport might be changed if the viewport aspect ratio is not equal to the camera aspect ratio. See the SoCamera::getView() source-code (private method) to see how this is done.

Implements SoCamera.

void SoPerspectiveCamera::viewAll (const SbBox3f & box, float slack)

Sets up the camera so that the entire bounding box is visible within the viewport, with a given amount of slack (empty space around the box).

The camera's position, orientation, and clipping planes are adjusted accordingly. This method is a convenience function and uses viewBoundingBox() internally.

Implements SoCamera.

void SoPerspectiveCamera::viewBoundingBox (const SbBox3f & box, float aspect, float slack) [virtual]

Convenience method for setting up the camera definition to cover the given bounding box with the given aspect ratio. Multiplies the exact dimensions with a slack factor to have some space between the rendered model and the borders of the rendering area.

If you define your own camera node class, be aware that this method should not set the orientation field of the camera, only the position, focal distance and near and far clipping planes.

Implements SoCamera.
