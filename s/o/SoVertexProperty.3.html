Descripción Detallada

La clase SoVertexProperty recopila la funcionalidad de varios nodos de apariencia.

En lugar de leer datos de la pila de estado actual de la traversa del grafo de escena, los nodos que heredan de SoVertexShape pueden ser configurados con un nodo SoVertexProperty en el campo SoVertexShape::vertexProperty. Las coordenadas, normales, coordenadas de textura e información de material/color se obtendrán del nodo SoVertexProperty de la forma de vértice en lugar de la pila de estado.

El nodo SoVertexProperty proporciona campos para duplicar la funcionalidad de todos estos otros tipos de nodos Inventor: SoCoordinate3, SoTextureCoordinate2, SoTextureCoordinate3, SoNormal, SoPackedColor, SoMaterialBinding y SoNormalBinding.

El nodo SoVertexProperty fue introducido relativamente tarde en el diseño de la API de Inventor por SGI. La idea detrás de él era proporcionar un medio para especificar los datos necesarios para nodos derivados de formas de vértice que serían más eficientes de trabajar que obtener los datos de la pila de estado de traversa.

En la práctica, el efecto no es en absoluto muy notable. Dado que el uso de nodos SoVertexProperty en el campo SoVertexShape::vertexProperty rompe de alguna manera con el diseño básico de la API de Open Inventor (los datos de SoVertexProperty no se envían a la pila de estado de traversa), podría ser mejor desde el punto de vista del diseño utilizar los mecanismos habituales, es decir, configurando los nodos individuales que SoVertexProperty "recopila".

Uno de los inconvenientes será, por ejemplo, que no es posible compartir *partes* del nodo SoVertexProperty entre varias formas, lo cual es algo que se puede hacer fácilmente al configurar nodos individuales que cambian el estado en el grafo de escena.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

VertexProperty {
    vertex [  ]
    normal [  ]
    texCoord [  ]
    orderedRGBA [  ]
    texCoord3 [  ]

    materialBinding OVERALL

PER_PART
An attribute is applied to a whole part (e.g., a face or a triangle).
PER_PART_INDEXED
An attribute is applied to a part, and the attribute data is indexed.
PER_FACE
An attribute is applied to each face of the shape.
PER_FACE_INDEXED
An attribute is applied to each face, and the attribute data is indexed.
PER_LINE
An attribute is applied to each line segment of the shape.
PER_LINE_INDEXED
An attribute is applied to each line segment, and the attribute data is indexed.
PER_POINT
An attribute is applied to each point of the shape.
PER_POINT_INDEXED
An attribute is applied to each point, and the attribute data is indexed.
OVERALL
A single attribute value is applied to the entire shape.
INDEXED
Attribute data is specified using indices, similar to SoIndexedFaceSet.

The binding rules are defined by specific fields within the SoVertexProperty node, such as normalBinding and materialBinding. These fields typically use enumerations defined in related nodes like SoNormalBinding and SoMaterialBinding.

The SoVertexProperty node is crucial for optimizing rendering performance by allowing vertex data to be defined once and reused by multiple shapes.

SoSFEnum SoVertexProperty::materialBinding

Defines how to bind the color values specified in the SoVertexProperty::orderedRGBA set to the parts of the "owner" shape. Must be one of the values in the SoVertexProperty::Binding enum.

Default value of the field is SoVertexProperty::OVERALL.

See also

SoMaterialBinding

SoMFInt32 SoVertexProperty::textureUnit

The texture unit(s) for the texture coordinates. By default this field contains one value, 0, and texture coordinates are then sent to texture unit 0. It's possible to supply multiple values in this field, and the texture coordinates in texCoord or texCoord3 will then be split into those units. The first totalnum/numunits coordinates will be sent to the first unit specified, the next totalnum/numunits coordinates will be sent to the second unit in this field, etc.

See also

SoTextureCoordinate2, SoTextureUnit

Since

Coin 4.0
