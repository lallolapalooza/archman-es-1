Descripción detallada

La clase SoSFVec3b es un contenedor para un vector SbVec3b.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con tres elementos.

Véase también

SbVec3b, SoMFVec3b Tenga en cuenta que esta clase es una extensión de Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 2.5
