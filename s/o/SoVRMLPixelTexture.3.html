NAME


SoVRMLPixelTexture — Texture node that uses a pixel map for the
    texture image.






SYNOPSIS


Inherits from
SoTexture2
.

SoVRMLPixelTexture
 {
  SFImage image
}







DESCRIPTION


This node is inherited from SoTexture2 and defines a texture map using a
    pixel image. The image is defined by the image field.


For a complete description of how the texture is applied to geometry,
    please consult the documentation for the inherited class
    SoTexture2.






FIELDS




image


Specifies the pixel data for the texture. The format of the
    image data is described in the SoInput
    documentation (in the context of reading VRML files). The data is expected
    to be in RGB format, i.e., three bytes per pixel, and the width and height
    of the image must be powers of 2.
