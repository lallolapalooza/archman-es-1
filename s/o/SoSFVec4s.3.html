Descripción Detallada

La clase SoSFVec4s es un contenedor para un vector SbVec4s.

Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar un vector único con cuatro elementos.

Ver también

SbVec4s, SoMFVec4s Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 2.5

Detailed Description

A field containing a 4-component vector of short integers. These are typically used for storing colour, texture coordinates, or positional data.

Implements SoField.
