Descripción Detallada

La clase SoSFVec4d es un contenedor para un vector SbVec4d.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con cuatro elementos.

Ver también

SbVec4d, SoMFVec4d Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 2.5
