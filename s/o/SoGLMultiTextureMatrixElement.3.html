DESCRIPCIÓN DETALLADA

La clase SoGLMultiTextureMatrixElement se utiliza para actualizar la matriz de textura de OpenGL.

Dado que (por alguna extraña razón) la mayoría de las implementaciones de OpenGL tienen una pila de matrices de textura muy pequeña, y dado que la pila de matrices también está rota en muchas implementaciones de OpenGL, la matriz de textura siempre se carga en OpenGL. No hacemos push() ni pop() en las matrices.

Detailed Description

This element is the OpenGL-specific implementation of SoMultiTextureMatrixElement. It handles the actual OpenGL calls to set the texture matrix for the specified texture unit.

This element is part of the Coin library.

void SoGLMultiTextureMatrixElement::push (SoState * state) [virtual]

This method is called every time a new element is required in one of the stacks. This happens when a writable element is requested, using SoState::getElement() or indirectly SoElement::getElement(), and the depth of the current element is less than the state depth.

Override this method if your element needs to copy data from the previous top of stack. The push() method is called on the new element, and the previous element can be found using SoElement::getNextInStack().

void SoGLMultiTextureMatrixElement::pop (SoState * state, const SoElement * prevTopElement) [virtual]

This method is called when the state is popped, and the depth of the element is bigger than the current state depth. pop() is called on the new top of stack, and a pointer to the previous top of stack is passed in prevTopElement.

Override this method if you need to copy some state information from the previous top of stack.
