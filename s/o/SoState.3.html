Descripción detallada

La clase SoState gestiona los datos de estado de recorrido del grafo de escena.

La clase SoState es utilizada por acciones derivadas de la clase SoAction. Gestiona el estado del grafo de escena como pilas de elementos (es decir, instancias de clases derivadas de SoElement).

Para más información sobre el funcionamiento interno de los estados de recorrido en Coin, recomendamos el libro The Inventor Toolmaker (ISBN 0-201-62493-1), también disponible en la biblioteca en línea de SGI. Busque "Toolmaker".

Documentación del constructor y destructor

SoState::SoState (SoAction * laAcción, const SoTypeList & elementosHabilitados)

El constructor. El argumento laAcción es el objeto de acción del cual forma parte el estado, y el argumento elementosHabilitados es una SoTypeList de los elementos que están habilitados para esta acción.

El constructor inserta un elemento predeterminado en los índices de todas las pilas de elementos habilitados. No se llama a SoElement::push() en los elementos iniciales de las pilas de SoState, pero sí a SoElement::init().

SoState::~SoState (void )

El destructor.

Tenga en cuenta que cuando ocurre la destrucción, los eventos retrasados causados por la evaluación perezosa no se realizarán.

Documentación de funciones miembro

SoAction * SoState::getAction (void ) const

Este método devuelve el puntero a la instancia de acción dada en el constructor.

SoElement * SoState::getElement (const int índicePila)

Este método devuelve una instancia modificable del elemento en la cima de la pila con el índicePila dado. Debido a la programación perezosa, esta función puede necesitar realizar algún trabajo, por lo que se debe usar SoState::getConstElement() en su lugar siempre que sea posible.

const SoElement * SoState::getConstElement (const int índicePila) const [inline]

Este método devuelve un puntero al elemento superior de la pila de elementos dada. El elemento es de solo lectura y no debe ser modificado bajo ninguna circunstancia, de lo contrario ocurrirán efectos secundarios extraños.

Tenga en cuenta que esta función lanzará una aserción si el elemento con el valor de identidad de pila dado no está presente actualmente en la pila de estado. Para comprobar si un elemento está presente en la pila, use SoState::isElementEnabled().

void SoState::push (void )

Este método empuja el estado un nivel hacia abajo. Esto guarda el estado para que pueda ser modificado y restaurado posteriormente a este estado llamando a SoState::pop().

El mecanismo de empujar y sacar se realiza de forma perezosa por razones de eficiencia (evita mucha asignación de memoria y copias). Solo cuando un elemento de estado va a ser modificado realmente, ese elemento se empujará de verdad.

void SoState::pop (void )

Este método saca el estado para restaurarlo a un estado anterior. Las extracciones se realizan de forma inmediata, pero el código es muy eficiente, por lo que no hay motivo para preocuparse por la eficiencia.

void SoState::print (FILE *const archivo = stdout) const

Este método es solo para fines de depuración.

SbBool SoState::isElementEnabled (const int índicePila) const [inline]

Este método devuelve TRUE si el elemento con el índice de pila de elemento dado está habilitado, y FALSE en caso contrario.

int SoState::getDepth (void ) const

Este método devuelve la profundidad actual de la pila de estado.

La profundidad es "virtual", no necesariamente física.

void SoState::setCacheOpen (const SbBool abrir)

Controla si una caché está abierta.

SbBool SoState::isCacheOpen (void ) const [inline]

Devuelve si una caché está abierta.
