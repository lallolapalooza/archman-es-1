Detailed Description

La clase SoDirectionalLight es un tipo de nodo para especificar fuentes de luz direccional.

Una fuente de luz direccional proporciona un modelo de fuentes de luz que están a una distancia infinita de la geometría que ilumina, por lo tanto, no tienen una posición definida y consisten en un volumen infinito de rayos paralelos.

Este es, por supuesto, un modelo simplificado de fuentes de luz lejanas, ya que la "distancia infinita" es imposible.

El sol iluminando objetos en la tierra es un buen ejemplo de algo que puede modelarse bastante bien para los propósitos más comunes con una fuente de luz direccional.

Ver también la documentación de la clase padre para obtener información importante sobre las fuentes de luz en general.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

DirectionalLight {
    on TRUE
    intensity 1
    color 1 1 1
    direction 0 0 -1
}

Algo común que hacer con un SoDirectionalLight es conectarlo a una cámara, para que funcione al estilo de una luz frontal para esa cámara. Esto se puede lograr fácilmente enlazando un campo SoRotation::rotation, que influye en la luz, al campo SoCamera::orientation. Aquí hay un archivo iv completo que demuestra la técnica:

#Inventor V2.1 ascii
DEF mycam PerspectiveCamera { }
TransformSeparator {
   SoRotation { rotation = USE mycam.orientation }
   DirectionalLight { direction 0 0 -1 }
}
Cube { }

(El SoTransformSeparator se incluye para mantener el efecto del nodo SoRotation dentro de un ámbito donde solo influirá en la luz, y no en la geometría que sigue a la luz en el grafo de escena.)
