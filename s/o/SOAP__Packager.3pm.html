SOAP::Packager(3) Documentación Perl aportada por el usuario SOAP::Packager(3)

NOMBRE

SOAP::Packager - esta clase es una clase abstracta que permite múltiples tipos de agentes de empaquetado como MIME y DIME.

DESCRIPCIÓN

La clase SOAP::Packager es responsable de gestionar un conjunto de "partes". Las partes son información adicional, documentos adicionales o prácticamente cualquier cosa que necesite asociarse con el Envolvente/carga útil de SOAP. El empaquetador tomará estas partes y las codificará/decodificará o "empaquetará"/"desempaquetará" a medida que entran y salen de la red.

MÉTODOS

new
Instancia un nuevo objeto de SOAP::Packager.
parts
Contiene una matriz de partes. El contenido de esta matriz y sus tipos dependen completamente del Empaquetador que se esté utilizando. Por ejemplo, cuando se usa MIME, el contenido de esta matriz son objetos MIME::Entity.
push_part
Añade una parte al conjunto de partes gestionadas por la instancia actual de SOAP::Packager.
parser
Devuelve el analizador utilizado para analizar los adjuntos de un flujo de datos.
headers_http
Este es un gancho en la capa HTTP. Proporciona una forma para que un empaquetador añada y/o modifique cabeceras HTTP en una solicitud/respuesta. Por ejemplo, la mayoría de las capas de empaquetado necesitarán sobrescribir el Tipo de Contenido (p.ej., multipart/related, o application/dime).

MÉTODOS ABSTRACTOS

Si desea implementar su propio SOAP::Packager, los métodos a continuación deben ser implementados por usted según los requisitos de entrada y salida prescritos.

package()
La subrutina "package" toma como entrada el envolvente SOAP en forma de cadena/SCALAR. Esto servirá como el contenido de la parte raíz. El empaquetador encapsula entonces el envolvente con las partes contenidas en "parts" y devuelve el envolvente correctamente encapsulado en forma de cadena/SCALAR.
unpackage()
La subrutina "unpackage" toma como entrada datos en bruto que necesitan ser analizados en un conjunto de partes. Es responsable de extraer el envolvente de la entrada y poblar "parts" con una MATRIZ de partes extraídas de la entrada. Luego devuelve el Envolvente SOAP en forma de cadena/SCALAR para que SOAP::Lite pueda analizarlo.

FORMATOS DE EMPAQUETADO SOPORTADOS

SOAP::Packager::MIME

"SOAP::Packager::MIME" utiliza MIME::Tools para proporcionar la capacidad de enviar y recibir solicitudes y respuestas con formato Multipart/Related y Multipart/Form-Data.

MÉTODOS MIME

Los siguientes métodos se utilizan al componer un mensaje con formato MIME.

transfer_encoding
El valor de la Cabecera MIME Content-Transfer-Encoding de la parte raíz. Por defecto es: 8bit.
env_id
El valor de la Cabecera MIME Content-Id de la parte raíz. Por defecto es: <main_envelope>.
env_location
El valor de la Cabecera MIME Content-Location de la parte raíz. Por defecto es: /main_envelope.
env_type
El valor de la Cabecera MIME Content-Type de la parte raíz. Por defecto es: text/xml.

OPTIMIZACIÓN DEL ANALIZADOR MIME

El uso de adjuntos puede a menudo resultar en un uso intensivo de los recursos del sistema dependiendo de cómo esté configurado su analizador MIME. Por ejemplo, puede indicar al analizador que almacene los adjuntos en memoria o que utilice archivos temporales. Usar uno u otro puede afectar el rendimiento, la utilización del disco y/o la fiabilidad. Por lo tanto, debería consultar la siguiente URL para obtener técnicas y compensaciones de optimización:

http://search.cpan.org/dist/MIME-tools/lib/MIME/Parser.pm#OPTIMIZING_YOUR_PARSER

Para modificar las opciones de configuración del analizador, consulte la siguiente muestra de código, que además muestra cómo minimizar el uso de memoria:

my $packager = SOAP::Packager::MIME->new;
# $packager->parser->decode_headers(1); # sin diferencia
# $packager->parser->extract_nested_messages(1); # sin diferencia
$packager->parser->output_to_core(0); # mucha menos memoria
$packager->parser->tmp_to_core(0); # mucha menos memoria
$packager->parser->tmp_recycling(0); # promueve una recolección de basura más rápida
$packager->parser->use_inner_files(1); # sin diferencia
my $client = SOAP::Lite->uri($NS)->proxy($URL)->packager($packager);
$client->someMethod();

EJEMPLO DEL LADO DEL CLIENTE

El siguiente ejemplo de código muestra cómo utilizar adjuntos en el contexto de un cliente SOAP::Lite.

#!/usr/bin/perl
use SOAP::Lite;
use MIME::Entity;
my $ent = build MIME::Entity
  Type        => "text/plain",
  Path        => "attachment.txt",
  Filename    => "attachment.txt",
  Disposition => "attachment";
my $NS = "urn:Majordojo:TemperatureService";
my $HOST = "http://localhost/cgi-bin/soaplite.cgi";
my $client = SOAP::Lite
  ->packager(SOAP::Packager::MIME->new)
  ->parts([ $ent ])
  ->uri($NS)
  ->proxy($HOST);
my $response = $client->c2f(SOAP::Data->name("temperature" => '100'));
print $response->valueof('//c2fResponse/foo');

EJEMPLO DEL LADO DEL SERVIDOR

El siguiente código muestra cómo utilizar adjuntos en el contexto de un script CGI. Muestra cómo leer los adjuntos entrantes y cómo devolver adjuntos al cliente.

#!/usr/bin/perl -w
use SOAP::Transport::HTTP;
use MIME::Entity;
SOAP::Transport::HTTP::CGI
  ->packager(SOAP::Packager::MIME->new)
  ->dispatch_with({'urn:Majordojo:TemperatureService' => 'TemperatureService'})
  ->handle;
BEGIN {
  package TemperatureService;
  use vars qw(@ISA);
  @ISA = qw(Exporter SOAP::Server::Parameters);
  use SOAP::Lite;
  sub c2f {
    my $self = shift;
    my $envelope = pop;
    my $temp = $envelope->dataof("//c2f/temperature");
    use MIME::Entity;
    my $ent = build MIME::Entity
      Type        => "text/plain",
      Path        => "printenv",
      Filename    => "printenv",
      Disposition => "attachment";
    # leer adjuntos
    foreach my $part (@{$envelope->parts}) {
      print STDERR "soaplite.cgi: attachment found! (".ref($part).")\n";
      print STDERR "soaplite.cgi: contents => ".$part->stringify."\n";
    }
    # enviar adjuntos
    return SOAP::Data->name('convertedTemp' => (((9/5)*($temp->value)) + 32)),
      $ent;
  }
}
