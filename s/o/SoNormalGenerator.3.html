void SoNormalGenerator::generate (const float creaseAngle, const int32_t * striplens = NULL, const int numstrips = 0)

Inicia la generación de normales. Las normales se generan usando creaseAngle para encontrar qué aristas deben tener sombreado plano y cuáles deben tener sombreado suave.

Si las normales se generan para tiras de triángulos, se deben suministrar striplens y numstrips. Vea src/nodes/SoTriangleStripSet.cpp (generateDefaultNormals()) para un ejemplo de cómo enviar información de tiras de triángulos a este generador. No es trivial, ya que tienes que saber cómo OpenGL/Coin genera triángulos a partir de tiras de triángulos.

NAME

SoNormalGenerator – Generates normals for scenery graph nodes.

SYNOPSIS

#include <Inventor/generators/SoNormalGenerator.h>

#include <Inventor/SbLinear.h>

#include <Inventor/SbBasic.h>

class SoNormalGenerator : public SoNode

Inheritance diagram of this class:

    SoBase
     └ SoNode
          └ SoNormalGenerator

Detailed Description

This class is the base class for normal generators.

Normal generators are used by SoNormal nodes to generate normals for geometry.

virtual void SoNormalGenerator::generateNormals (SoNode * const node, const SoNormal * const normals, const SoTransformation * const transform, const SbBox3f & box, const SbVec3f & up, const SbVec3f & direction)

Generates normals for the given geometry node. This pure virtual function must be implemented by derived classes.

Parameters:

The geometry node for which to generate normals.

The existing normal node, if any.
transform
The transformation node, if any.
box
The bounding box of the geometry.
up
The up vector.
direction
The direction vector.

virtual int32_t SoNormalGenerator::getNumNormals ()

Returns the number of normals generated by this generator. Returns -1 if the number of normals is unknown (e.g. for generators that generate normals on-the-fly).
