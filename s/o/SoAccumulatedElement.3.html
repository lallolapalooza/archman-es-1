Descripción detallada

La clase SoAccumulatedElement es una clase abstracta para almacenar estado acumulado.

Esta es la superclase de elementos donde los nuevos datos del elemento se acumulan con datos más antiguos.

El elemento almacena valores de identificador de nodo para todos los nodos acumulados durante el recorrido para el estado actual. Estos valores de identificador se utilizan para determinar cuándo invalidar cachés.

NAME

SoAccumulatedElement - SoNodeKitPath's node ID element

SYNOPSIS

#include <Inventor/nodes/SoNode.h>
#include <Inventor/elements/SoAccumulatedElement.h>

class SoNodeKitPath;

Detailed Description

This element is used to store the node ID of the node that the current path is composed of. The node ID is the value returned by SoNode::getNodeId().

When traversing the scene graph, Coin's nodekit infrastructure uses this element to track the current node's ID. It's not meant for general use by application developers.

This element is a subclass of SoElement. It is implemented as an accumulated element, meaning that when it is pushed onto the state, its data is appended to the data of the previous element of the same type. When it is popped from the state, the appended data is removed.

The element is implemented using a list of node IDs. These node IDs are added to the list whenever a node is entered during traversal, and removed when the traversal leaves the node.

The element data is stored in the SoState object. The data can be accessed by calling SoAccumulatedElement::getClass(), and the element can be found using SoElement::get(SoState *, SoType). The new element can be found on the stack by calling SoElement::get(SoState *) on the new element's type. The previous element can be found using SoElement::getNextInStack().

Reimplemented from SoElement.
