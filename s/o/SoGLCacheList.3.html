Documentación de Funciones Miembro

SbBool SoGLCacheList::call (SoGLRenderAction * action)

Comprueba si la caché es válida y la ejecuta. Devuelve TRUE si se pudo encontrar una caché válida, FALSE en caso contrario. Tenga en cuenta que cuando se encuentra una caché válida, se ejecuta antes de devolver desde este método.

void SoGLCacheList::open (SoGLRenderAction * action, SbBool autocache = TRUE)

Inicia la grabación de una nueva caché. Recuerde llamar a close() cuando haya terminado de grabar la caché.
