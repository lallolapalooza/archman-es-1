Descripción detallada

La clase SoSFName es un contenedor para un SbName.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar una única cadena de nombre.

Los campos de este tipo almacenan su valor en el archivo como la cadena de nombre entre comillas.

Detailed Description

Field class for a string value. This field type is used to store names, which are typically used for identifying nodes in the scene graph (e.g. SoNode::setName()). The strings are typically limited to characters that are valid in C/C++ identifiers.

The underlying data is stored as a char*.
