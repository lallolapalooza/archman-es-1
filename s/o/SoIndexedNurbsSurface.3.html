Detailed Description

Indexed NURBS surface node.

This node creates a Non-Uniform Rational B-Spline surface, commonly referred to as NURBS surface. For a detailed explanation of NURBS surfaces, please refer to computer graphics literature.

This node works exactly like SoNurbsSurface, except that the control points are specified implicitly via indices into a SoVertexProperty node (or indirectly through the traversal state).

The surface is defined by a set of control points and associated knot vectors. The coordIndex field specifies which control points belong to the surface. The fields numUControlPoints and numVControlPoints define the dimensions of the grid of control points used to define the surface.

The uKnotVector and vKnotVector fields specify the knot vectors for the U and V dimensions, respectively. These vectors define the parametric intervals over which the NURBS basis functions are defined.

Similarly, numSControlPoints, numTControlPoints, sKnotVector, and tKnotVector can be used to define texture coordinates if a SoTextureCoordinateBinding node is also used.

Like other shape nodes, SoIndexedNurbsSurface responds to SoGLRenderAction, SoRayPickAction, and SoGetPrimitiveCountAction.

Will create triangle detail for a SoPickedPoint. This method will only be called internally, when generatePrimitives() is used for picking (SoShape::rayPick() is not overridden).

This method returns NULL in Open Inventor, and subclasses will need to override this method to create details for a SoPickedPoint.

This is not necessary with Coin. Of course, if you choose to override it, it will work in the same way as Open Inventor.

For this to work, you must supply a face or line detail when generating primitives. If you supply NULL for the detail argument in SoShape::beginShape(), you'll have to override this method.
