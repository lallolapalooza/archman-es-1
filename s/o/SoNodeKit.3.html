Descripción detallada

La clase SoNodeKit se utiliza para inicializar las clases del nodo.

La única función de SoNodeKit es ser un marcador de posición para el código de inicialización de nivel superior para todas las clases relacionadas con nodos.

Documentación de funciones miembro

void SoNodeKit::init (void ) [estático]

Inicializa el sistema de nodos.

Tenga en cuenta que este método *no* se llama implícitamente desde SoDB::init(). De hecho, este método llama a SoDB::init() en sí mismo para asegurarse de que todas las clases subyacentes para las clases de nodos se hayan inicializado.

Este método también se llama desde dentro de SoInteraction::init(), ya que la funcionalidad de interacción en Coin depende de las clases de nodos.
