Descripción detallada

La clase SoSFVec2f es un contenedor para un vector SbVec2f.

Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con dos elementos.

NAME

SoSFVec2f - 2D vector field that stores float pairs

SYNOPSIS

#include <Inventor/fields.h>


Inherits from SoSFFloat.


All the methods in class SoSFFloat are available.
This class also provides the following methods:


  void        initClass();
  void        setValue(float x, float y);
  void        setValue(const float xy[2]);

Detailed Description

This field class is used to store 2D vectors with float precision.

The two float values can be accessed as xy[0] and xy[1].
