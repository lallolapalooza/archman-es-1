SoScale Class

SoScale Class

The SoScale class is a node type for scaling scene graph geometry.

Use nodes of this type to apply scaling operations during scene graph traversals for e.g. rendering. Scale values are specified in a triple-value vector, with one scale factor for each of the 3 principal axes.

FILE FORMAT/DEFAULTS:

Scale {
    scaleFactor 1 1 1
}

NAME

SoScale - 3D scaling node

SYNOPSIS

Inherits SoNode.

Inherits SoTransformation.

To create a scale node:

    #include <Inventor/nodes/SoScale.h>

Fields:

    SoSFVec3f             scaleFactor

Action methods:

    virtual void          getPrimitiveCount (SoGetPrimitiveCountAction * action)

Detailed Description

The SoScale node specifies scaling along the 3 axes.

The scaling is applied to the coordinate system that is active when the node's GLRenderAction method is invoked.

The scaling is applied by multiplying the current transformation matrix by a matrix representing the scale. The scaling is applied in the current coordinate system.

The scaling is performed using the values in the scaleFactor field.

For example, if the scaleFactor field is set to [2.0, 1.0, 1.0], all objects rendered after this node will be scaled by a factor of 2.0 along the x-axis and by a factor of 1.0 along the y and z axes.

A uniform scale can be achieved by setting all components of the scaleFactor field to the same value. For example, setting scaleFactor to [2.0, 2.0, 2.0] will scale objects by a factor of 2.0 in all directions.

The default value of the scaleFactor field is [1.0, 1.0, 1.0], which results in no scaling.

To get a non-uniform scale, you must set the components that you do not want to scale to 1.0, not 0.0. For example, to scale only along the x-axis by a factor of 3.0, you would set the scaleFactor field to [3.0, 1.0, 1.0]. Setting a component to 0.0 will effectively remove the object from the scene in that dimension, and negative values will invert the object along that axis.

Note that scaling is a transformation that affects the geometry of objects. It is typically applied before other transformations such as rotation or translation.

Member Data Documentation

SoSFVec3f SoScale::scaleFactor

Specifies scaling along the 3 axes.

To get a uniform scale applied to the affected shapes, set the scaleFactor field to a vector with the same value for all components.

A common error when doing non-uniform scaling in a single direction is to set the value for the other two components of the scaleFactor vector to 0. This is obviously wrong, they should be set to 1 to not scale the shape(s) in the other two directions.

Be careful with setting scaleFactor component values to 0 or to negative values. Most shapes should handle those cases somehow, but the results are undefined unless otherwise specified.

The default value of this vector field is [1.0, 1.0, 1.0].
