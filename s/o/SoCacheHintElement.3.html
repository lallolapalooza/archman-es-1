Detailed Description

This element controls the cache hint for the Coin scenegraph. The cache hint is used by Coin to determine whether or not to cache certain nodes. This can be useful for optimizing the rendering of scenegraphs that are static or dynamic.

The following cache hints are available:

  • CACHE_HINT_DEFAULT: The default cache hint, which is determined by Coin.
  • CACHE_HINT_NEVER: Never cache the node.
  • CACHE_HINT_ALWAYS: Always cache the node.
  • CACHE_HINT_WHEN_STATIC: Cache the node only when it is static.
  • CACHE_HINT_WHEN_DYNAMIC: Cache the node only when it is dynamic.

This element is implemented by SoGLCacheHintElement.
