Detailed Description

This node collects and displays profiling information about the scenegraph during rendering. It can be used to get information about how much time is spent rendering each node type, and it can also be used to find out how many times each node type is rendered.

The information collected by this node is accessible through its fields renderedNodeType and renderingTimePerNodeType.

To use this node, simply add it to your scene graph. The profiling information will then be collected automatically during rendering.

Note that this node does not actually render anything itself. It only collects information about the rendering process.

This node is intended for use by developers who want to optimize their scene graphs. It should not be used in production builds, as it can introduce some overhead.
