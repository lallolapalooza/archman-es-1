NAME

SoAppearanceKit - Appearance kit class for creating and managing appearance nodekits

SYNOPSIS

#include <Inventor/Kits/SoAppearanceKit.h>

Inherits SoBaseKit.

Detailed Description

This class is the base appearance kit. It is used to group together the various nodekit components that define an appearance in OpenInventor. An appearance kit is a kit that is designed to contain nodes that define how a scene graph object should be rendered. This includes information about colors, materials, textures, and other visual properties. The main purpose of this class is to provide a convenient way to set and retrieve these appearance-related settings.
