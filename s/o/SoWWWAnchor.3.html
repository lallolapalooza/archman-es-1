DESCRIPTION

This node is used to define a hyperlink in a VRML scene. When the user clicks on the geometry under this node, the URL defined by the name field will be fetched.

The node has three fields: name, description and map.

The name field contains the URL to be fetched. The description field contains a text which is shown to the user when the mouse is over the link.

The map field controls how the position of the picked node is mapped to the URL. It has two possible values:

NONE
The position of the picked node is not mapped to the URL.
POINT
The position of the picked node is mapped to the URL as object space coordinates, adding a parameter string to the end of the URL. To assure that the URL works with all browsers, the coordinates are divided by commas sent as the hex representation.

If a model by the name of sim.wrl resided at https://github.com/coin3d/ and the picked point had the coordinates [1.5, 10, 6.77], the resulting URL would be "https://github.com/coin3d/sim.wrl?1.5%2c10%2c6.77".
