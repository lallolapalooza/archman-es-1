Descripción detallada

La clase SoMultiTextureMatrixElement se utiliza para gestionar la pila de matrices de textura para las unidades de textura > 0.

La matriz de textura se utiliza para transformar las coordenadas de textura antes de ser utilizadas para mapear texturas sobre polígonos.

Detailed Description

This element holds the texture matrix for texture unit. The unit parameter can be used to specify the texture unit. If it is not specified, it defaults to 0.

This element is inherited from SoAccumulatedElement, which is inherited from SoElement.
