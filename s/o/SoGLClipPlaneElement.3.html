NAME

SoGLClipPlaneElement

OpenGL clipping plane element

SYNOPSIS

#include <Inventor/elements/SoGLClipPlaneElement.h>
                    
class SoGLClipPlaneElement : public SoClipPlaneElement

Inherited members:

protected:
  virtual void      addToElt(const SbPlane & plane, const SbMatrix & modelMatrix);

Description

The SoGLClipPlaneElement class is an element that stores OpenGL clipping plane state.

When OpenGL is initialised, the SoGLClipPlaneElement stores the currently enabled clipping plane settings. When the element is pushed, the stored clipping plane settings are applied. When the element is popped, the previously active clipping plane settings are restored.

The element handles the case where the clipping plane normal is not aligned with the Z-axis. In such cases, the clipping plane equation is transformed to world coordinates by multiplying the plane equation with the inverse transpose of the model-view matrix.

This element is implicitly inherited by SoClipPlane nodes.
