Descripción Detallada

La clase SoSFBox2d es un contenedor para un vector SbBox2d.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar una caja.

Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.
Desde

Coin 2.5
