Descripción Detallada

La SoCallbackList es un contenedor para punteros a funciones de retorno de llamada.

Esta lista almacena punteros a funciones de retorno de llamada (junto con datos adicionales especificados por el usuario para pasar a las funciones de retorno de llamada) y proporciona un método para activar las funciones de retorno de llamada.

void SoCallbackList::clearCallbacks (void )

Elimina todas las funciones de retorno de llamada de la lista.

int SoCallbackList::getNumCallbacks (void ) const

Devuelve el número de funciones de retorno de llamada.

void SoCallbackList::invokeCallbacks (void * callbackdata)

Invoca todas las funciones de retorno de llamada, pasando el userdata y el callbackdata como primer y segundo argumento, respectivamente.

Se activarán todas las funciones de retorno de llamada registradas cuando se invoque el método, incluso si el código de una función de retorno de llamada elimina otra.

Es seguro que una función de retorno de llamada se elimine a sí misma o a cualquier otra función de retorno de llamada durante la ejecución.
