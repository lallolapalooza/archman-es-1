NAME

SoAnnoText3RenderPrintElement - Imprime elementos de texto en 3D para renderizado.

SYNOPSIS

Herencia:

    public virtual class SoAnnoText3RenderPrintElement : public SoText3RenderPrintElement

Detailed Description

Este elemento gestiona la representación de texto en 3D para el renderizado. Permite controlar cómo se imprimen los elementos de texto en el contexto de renderizado. Se basa en la clase base SoText3RenderPrintElement.
