Descripción Detallada

La clase SoCullElement se usa internamente para la exclusión de renderizado y selección.

El elemento almacena todos los planos dentro de los cuales la geometría debe estar, y mantiene un indicador de bits para señalar qué planos deben ser probados.

Este elemento es una extensión para Coin y no está disponible en el Open Inventor original.

El número máximo de planos en este elemento es 32, lo cual debería ser más que suficiente, ya que el tronco de visión está representado por 6 planos, y el número máximo de planos de recorte de OpenGL suele ser 6 u 8.

Este elemento está diseñado para una exclusión rápida y no realizará una exclusión óptima del tronco de visión; una caja podría no ser excluida aunque esté fuera del tronco de visión. La suposición es que el tronco de visión es pequeño en comparación con el modelo del mundo. El elemento simplemente registra todos los planos contra los cuales se debe realizar la exclusión, y el grafo no se excluye hasta que está completamente fuera de uno de los planos.

SoCullElement no está activo para otras acciones que no sean SoGLRenderAction. Es posible habilitarlo para SoCallbackAction actualizándolo en un callback posterior de la cámara. Haga algo como esto:

static SoCallbackAction::Response
camera_cb(void * data, SoCallbackAction * action, const SoNode * node)
{
  SoState * state = action->getState();
  SoCullElement::setViewVolume(state, SoViewVolumeElement::get(state));
  return SoCallbackAction::CONTINUE;
}
[...]
SoCallbackAction cba(myviewport);
cba.addPostCallback(SoCamera::getClassTypeId(), camera_cb, NULL);

Cuando el volumen de visión se establece en SoCullElement en el callback posterior de la cámara, SoCallbackAction realizará la exclusión en Separators y otros nodos de la misma manera que SoGLRenderAction.

SbBool SoCullElement::cullBox (SoState * state, const SbBox3f & box, const SbBool transform = TRUE) [static]

Cull contra box. Si transform es TRUE, el box se asume estar en el espacio de objeto, y se transformará en el espacio de mundo usando la matriz de modelo. Devuelve TRUE si el box está fuera de uno de los planos, y actualiza el elemento para detectar cuando la geometría está completamente dentro de todos los planos.

SbBool SoCullElement::cullTest (SoState * state, const SbBox3f & box, const SbBool transform = TRUE) [static]

Cull contra box. Si transform es TRUE, el box se asume estar en el espacio de objeto, y se transformará en el espacio de mundo usando la matriz de modelo. Devuelve TRUE si el box está fuera de uno de los planos. Esta método no actualiza el estado del elemento, solo realiza un test de cull contra las planas activas.

SbBool SoCullElement::completelyInside (SoState * state) [static]

Devuelve TRUE si la geometría actual está completamente dentro de todos los planos. No se necesita realizar un test de cull si esta es la situación.
