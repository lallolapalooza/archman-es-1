Descripción detallada

La clase SoMFPath es un contenedor para rutas.

Este contenedor de campos almacena una matriz de punteros a rutas. Se encarga de la funcionalidad necesaria para manejar las operaciones de copia, importación y exportación.

Tenga en cuenta que los punteros a rutas almacenados en instancias de campo de este tipo pueden ser punteros NULL.

void SoMFPath::fixCopy (SbBool copyconnections) [virtual]

Este método es llamado internamente después de SoField::copyFrom() durante las copias del grafo de escena y debe realizar las operaciones necesarias para arreglar la instancia del campo después de que haya obtenido un nuevo valor.

El método por defecto en la clase base SoField no hace nada.

Normalmente, el programador de aplicaciones no debería necesitar considerar este método, a menos que construya un tipo de campo complejo que contenga nuevas referencias a instancias de contenedores (es decir, nodos o motores). En ese caso, es necesario reimplementar este método para actualizar los punteros de referencia, ya que podrían haberse duplicado durante la operación de copia.

Reimplementado de SoField.

SbBool SoMFPath::referencesCopy (void ) const [virtual]

Devuelve TRUE si este campo tiene referencias a algún contenedor en el grafo de escena que también se duplica durante la operación de copia.

Tenga en cuenta que este método solo es válido para ser llamado durante las operaciones de copia.

Consulte también la nota sobre la relevancia del método fixCopy() para los programadores de aplicaciones, ya que es aplicable a este método también.

virtual void SoMFPath::deleteValues (int start, int numarg = -1) [virtual]

Elimina elementos de valor desde el índice start hasta e incluyendo el índice start + num - 1.

Los elementos con índices mayores que el último elemento eliminado se moverán hacia abajo en el array de valores.

Si num es igual a -1, elimina desde el índice start hasta el final del array.
