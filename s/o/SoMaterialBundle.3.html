Descripción detallada

La clase SoMaterialBundle simplifica el manejo de materiales.

Cada nodo de forma debe crear (en la pila) una instancia de esta clase y llamar a sendFirst() antes de enviar cualquier cosa a GL. Durante el renderizado, se debe usar send() para enviar los valores de material a GL.

Documentación de funciones miembro

void SoMaterialBundle::setUpMultiple (void )

Actualmente no está en uso. Solo se proporciona para el cumplimiento de OIV.

void SoMaterialBundle::sendFirst (void )

Envía los valores de material iniciales a GL. Debe hacerse una vez en todos los nodos de geometría antes de que comience el renderizado.

void SoMaterialBundle::forceSend (const int index)

Enviará el material a GL incluso si index es igual al índice actual.

Proporcionado para compatibilidad con la API SGI Open Inventor v2.1.

SbBool SoMaterialBundle::isColorOnly (void ) const

Devuelve TRUE si el modelo de luz actual es BASE_COLOR.

void SoMaterialBundle::send (const int index, const SbBool betweenbeginend)

Envía los valores de material con el índice index a GL. Comprobará si el índice actual es igual a index antes de enviar.

betweenbeginend debe ser TRUE si su programa está entre un glBegin() y un glEnd() (es ilegal cambiar el patrón de polígono entre un glBegin() y un glEnd()).
