Detailed Description

The SoHandleBoxManip class wraps an SoHandleBoxDragger for manipulating a transformation.

A manipulator is used by replacing the node you want to edit in the graph with the manipulator. Draggers are used to manipulate the node. When manipulation is finished, the node is put back into the graph, replacing the manipulator.

See also

SoHandleBoxDragger, SoDragger

Manipulador de caja de manejadores para un nodo de transformación. Este manipulador proporciona una caja de manejo que permite la manipulación interactiva de las transformaciones de traslación, rotación y escalado de un nodo.
