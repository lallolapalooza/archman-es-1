Descripción detallada

La clase SoTimerQueueSensor es la clase base abstracta para sensores que se activan con ciertos eventos de temporizador.

Los sensores de temporizador se activan en puntos específicos del tiempo.

Esta clase es una superclase abstracta que recopila la interfaz común de las diversas clases de sensores de temporizador no abstractas. Consulte la documentación de las subclases para obtener información sobre las formas de especificar tiempos base, intervalos, activación única estilo alarma, activaciones repetidas, etc.

Tenga en cuenta que los sensores de temporizador de Coin de ninguna manera deben considerarse de "tiempo real duro". Es decir, *no puede* esperar que un temporizador se active siempre en el momento exacto en que se configuró. Los retrasos en la activación podrían deberse a otras actividades en Coin, a una tarea suspendida o a una carga pesada de otras aplicaciones en el sistema. Todas estas situaciones podrían hacer que el procesamiento de las colas de sensores (desde SoQt / SoWin / SoXt / lo que sea) se retrase ligeramente, lo que a su vez provocaría retrasos en la activación de los sensores de temporizador.

En sistemas modernos, sin embargo, un temporizador generalmente se activará dentro de unos pocos milisegundos de su tiempo designado.

Si un sensor de temporizador no puede activarse en el momento exacto en que se ha programado, se activará en la primera oportunidad después de que haya pasado el tiempo programado.

Aquí hay un ejemplo de uso simple. Es un ejemplo independiente, que solo demuestra cómo configurar un sensor de temporizador repetitivo con una devolución de llamada:

#include <Inventor/Xt/SoXt.h>
#include <Inventor/sensors/SoTimerSensor.h>
#include <cstdio>
static void
timeSensorCallback(void * data, SoSensor * sensor)
{
  SbTime time = SbTime::getTimeOfDay();
  SbString string = time.format("%S.%i");
  (void)printf("%s\n", string.getString());
}
int
main(int argc, char ** argv)
{ 
  SoXt::init("test");
  SoTimerSensor * timeSensor = new SoTimerSensor;
  timeSensor->setFunction(timeSensorCallback);
  timeSensor->setBaseTime(SbTime::getTimeOfDay());
  timeSensor->setInterval(1.0f);
  timeSensor->schedule();
  SoXt::mainLoop();
  return 0;
}

Detailed Description

A timer queue sensor is a sensor that is invoked after a specified amount of time has passed.

The SoTimerQueueSensor class is part of the Coin 3D library.
