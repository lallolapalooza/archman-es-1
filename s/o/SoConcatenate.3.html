Descripción Detallada

La clase SoConcatenate se utiliza para concatenar varias entradas en una salida.

Toma todos los valores de los 10 campos de entrada multivalor en orden y los concatena en la salida multivalor.

Tenga en cuenta que el campo de salida de este motor se desvía un poco del mecanismo de salida "estándar" de la mayoría de las clases de motor: SoConcatenate::output no es una instancia permanente de SoEngineOutput, sino un *puntero* a una instancia de SoEngineOutput. La razón de esto es que es necesario asignar dinámicamente el campo de salida para que coincida con lo que está conectado SoConcatenate::input, ya que el tipo de SoConcatenate::output siempre debe ser el mismo que el tipo de SoConcatenate::input.

El formato de archivo para este campo es un poco especial. Tenga en cuenta la especificación del tipo inicial, que no es necesaria para la mayoría de los demás tipos de campo:

Concatenate {
  type <multivaluefieldtype>
  [...fields...]
}

virtual SoType SoConcatenate::getTypeId (void ) const [virtual]

Devuelve la identificación del tipo de un objeto derivado de una clase que hereda de SoBase. Esto se utiliza para la comprobación de tipos en tiempo de ejecución y la conversión "descendente". Ejemplo de uso:

void foo(SoNode * node)
{
  if (node->getTypeId() == SoFile::getClassTypeId()) {
    SoFile * filenode = (SoFile *)node;  // conversión descendente segura, conoce el tipo
  }
}

Para programadores de aplicaciones que deseen extender la biblioteca con nuevos nodos, motores, kits de nodos, draggers u otros: este método debe ser redefinido en *todas* las subclases. Esto se realiza típicamente como parte de la configuración del sistema de tipos completo para las clases de extensión, lo que generalmente se logra utilizando las macros predefinidas disponibles a través de, por ejemplo, Inventor/nodes/SoSubNode.h (SO_NODE_INIT_CLASS y SO_NODE_CONSTRUCTOR para clases de nodos), Inventor/engines/SoSubEngine.h (para clases de motores) y similares.

Para obtener más información sobre la escritura de extensiones de Coin, consulte la documentación de la clase de las superclases de nivel superior para los diversos grupos de clases.
