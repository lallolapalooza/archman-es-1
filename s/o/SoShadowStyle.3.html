Detailed Description

The SoShadowStyle class is a node for setting the shadow style on nodes.

FILE FORMAT/DEFAULTS:

ShadowStyle {
    style CASTS_SHADOW_AND_SHADOWED
}

Coin 2.5

Enumerator

NO_SHADOWING
Neither casts or receives shadows.
CASTS_SHADOW
Casts shadow, but will no receive any shadows.

Receives shadows, but will not cast any shadow.

NOMBRE

SoShadowStyle — Sombra de estilo de objeto

SINOPSIS

#include <Inventor/nodes/SoShadowStyle.h>

Inherits: SoNode
Inherited by: SoGouraudShadow, SoLightPoint, SoLightSpot, SoModel

DESCRIPCIÓN

Este nodo establece el estilo de sombra para todos los objetos que lo siguen en el grafo de escena. SoShadowStyle es un nodo base abstracto.

Los nodos que heredan de SoShadowStyle son:

  • SoGouraudShadow
  • SoLightPoint
  • SoLightSpot
  • SoModel

NODO DE ACCIÓN

SoShadowStyle es un nodo de estilo. Los nodos de estilo afectan a cómo se renderizan los objetos. En particular, SoShadowStyle influye en cómo se aplican las sombras.
