Descripción Detallada

La clase SoDebugError es el mecanismo interno de paso de mensajes de depuración.

Esta clase cumple básicamente dos propósitos:

1) Es la interfaz de mensajes a través de la cual las condiciones de error y advertencia se pasan al programador que está utilizando la API de la biblioteca Coin para construir aplicaciones. Estos mensajes se generan cuando los métodos de la API se usan de manera incorrecta, o si las acciones en la biblioteca han provocado que entre en un estado inconsistente. Los programadores de Coin deberían poder rastrear rápidamente los errores en el código de su aplicación.

Para que este servicio esté disponible, la biblioteca Coin debe ser compilada con información de depuración. Para las compilaciones de producción, la mayor parte de esta "red de seguridad del programador" se elimina para obtener la máxima velocidad y usar el mínimo espacio (compilar la biblioteca más pequeña posible).

2) Los programadores de aplicaciones Coin pueden llamar a los métodos SoDebugError dentro de su propio código como una forma conveniente de depurar el código de la aplicación, reemplazando las típicas cascadas de llamadas fprintf().

Coin soporta una variable de entorno para establecer puntos de ruptura condicionales. La variable de entorno COIN_DEBUG_BREAK puede establecerse a cualquier número de funciones en forma de una lista separada por comas o espacios. Los nombres de las funciones deben proporcionarse como "nombreclase::nombrefuncion" (es decir, sin tipo de retorno, paréntesis ni tipos o nombres de argumentos). Si se publica un mensaje de depuración desde una de esas funciones, su programa se detendrá (usando assert(0)).

Esto puede ser útil si desea obtener volcados de núcleo o entrar en un depurador cada vez que, por ejemplo, se publica una advertencia o un error desde alguna función (p. ej., "SbVec3f::normalize"). Esta característica solo está habilitada en la versión de depuración de Coin.

NAME

SoDebugError - Debugging and error reporting class

SYNOPSIS

#include <Inventor/SbBasic.h>
#include <Inventor/SbColor.h>
#include <Inventor/SoError.h>
#include <Inventor/SoDebugError.h>


class SoDebugError : public SoError {
public:
  enum ErrorSeverity {
    ERROR = 1,
    WARNING = 2,
    INFO = 3
  };
  static void postError (const char *const source, const char *const format, ...);
  static void postWarning (const char *const source, const char *const format, ...);
  static void postInfo (const char *const source, const char *const format, ...);
  static void initClass (void);
protected:
  virtual SoErrorCB * getHandler (void *& data) const;
};

Detailed Description

This is the debugging and error reporting class.

The Coin library provides several mechanisms for reporting errors and debugging messages. The base class for all error reporting is SoError. This class provides a way to register a callback function which will be invoked whenever an error is posted.

The SoDebugError class is an extension of SoError that provides a more structured way to post error messages. It introduces the concept of error severity levels: ERROR, WARNING, and INFO. These levels can be used to filter error messages, allowing developers to control the verbosity of the debugging output.

The methods postError(), postWarning(), and postInfo() are used to post messages with the corresponding severity levels. These methods take a source argument, which should be the name of the calling function, and a format string, similar to the C standard library printf() function. This allows for formatted error messages.

The initClass() method should be called once at the beginning of the application to initialize the static data members of the class.

The getHandler() method is a protected virtual method that provides access to the error handler callback and its associated data. It is primarily used internally by the Coin library but can be overridden in derived classes for custom error handling.

To use SoDebugError, you typically need to call SoError::init() and then use the postError(), postWarning(), or postInfo() methods.

Example:

  #include <Inventor/SoDebugError.h>
  // ...
  SoDebugError::initClass(); // Call this once at startup
  // ...
  void myFunction() {
    // ...
    SoDebugError::postError("myFunction", "An error occurred: %d", errorCode);
    SoDebugError::postWarning("myFunction", "This is just a warning message.");
    SoDebugError::postInfo("myFunction", "Processing data item %s", itemName);
    // ...
  }
