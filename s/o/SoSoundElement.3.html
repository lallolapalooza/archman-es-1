Detailed Description

Este elemento es usado por el módulo de sonido de Coin para determinar si el grafo de escena está tocando algún nodo de sonido.

Actualmente, los únicos nodos que usan este elemento son los nodos de sonido de VRML (es decir, SoVRMLSound). Este elemento se utiliza para mejorar el rendimiento. Si un grafo de escena no contiene ningún nodo SoVRMLSound, entonces la acción de renderizado de audio de Coin no necesita ser ejecutada. Esto es particularmente útil cuando los objetos 3D no tienen audio asociado.

Los valores predeterminados para este elemento son:

sceneGraphHasSoundNode = FALSE

soundNodeIsPlaying = FALSE

isPartOfActiveSceneGraph = TRUE
