NAME

SoDepthBufferElement — depth buffer element for Coin

SYNOPSIS

#include <Inventor/elements/SoDepthBufferElement.h>

Inherits SoElement.

Inherited by SoGLDepthBufferElement.

  enum SoDepthBufferElement::DepthWriteFunction {
    SoDepthBufferElement::NEVER,
    SoDepthBufferElement::LESS,
    SoDepthBufferElement::EQUAL,
    SoDepthBufferElement::LEQUAL,
    SoDepthBufferElement::GREATER,
    SoDepthBufferElement::NOTEQUAL,
    SoDepthBufferElement::GEQUAL,
    SoDepthBufferElement::ALWAYS
  };

  public:
    // Related methods
    static SbBool               getTestEnable (SoState * state);

    virtual SbBool              matches (const SoElement * element) const;

  protected:
    // Internal methods
    virtual void                setElt (SbBool test, SbBool write, DepthWriteFunction function, SbVec2f range);

    // Constructor and destructor
    SoDepthBufferElement (void );
    virtual ~SoDepthBufferElement ();

  private:
    // To prevent compiler warnings
    void                        operator= (const SoDepthBufferElement &);
};

Description

This element class records whether the depth buffer test is enabled, whether writing to the depth buffer is enabled, the depth buffer comparison function and the depth buffer value range.

It is used by the SoDepthBuffer node to set the OpenGL depth buffer state.
