NAME

SoResetTransform — reset traversal state

SYNOPSIS

 #include <Inventor/nodes/SoResetTransform.h>

enum SoResetTransform::ResetType {
  TRANSFORM,
  BOUNDING_BOX,
  PRIMITIVE_COUNT
};

class SoResetTransform : public SoNode



publicslots:
  SoSFBitMask whatToReset





public:
  static void       initClass();

  virtual void      GLRenderAction(SoGLRenderAction *action);
  virtual void      getMatrix(SoGetMatrixAction *action);
  virtual void      pick(SoPickAction *action);
  virtual void      getPrimitiveCount(SoGetPrimitiveCountAction *action);







Detailed Description


This node is used to reset specific parts of the traversal state.
    For example, it can be used to reset the current transformation matrix so
    that subsequent geometry nodes are not affected by transformations defined
    earlier in the scene graph.


The node has a single field, whatToReset, which
    is an SoSFBitMask. This field controls which parts of the
    state should be reset. The mask is a bitwise OR of the enumerated values
    defined in the ResetType enum:


    
  
  • TRANSFORM: Resets the current transformation matrix.
    • 
  
  • BOUNDING_BOX: Resets the current bounding box.
    • 
  
  • PRIMITIVE_COUNT: Resets the primitive counter.
    • 



When the traversal enters a SoResetTransform
    node, it checks the whatToReset field and modifies the
    traversal state accordingly. This is particularly useful when you want to
    apply transformations or other settings to a specific part of the scene
    graph without affecting other parts.


Example: To apply a transformation to a subtree without affecting
    the rest of the scene, you can insert an SoResetTransform
    node with whatToReset set to TRANSFORM
    before the subtree, and then apply the desired transformation using an
    SoTransform node. The SoResetTransform
    will reset the transformation state before the SoTransform
    node is processed, ensuring that the transformation only affects the nodes
    within the subtree.






Member Enumeration Documentation




enum SoResetTransform::ResetType


This enum defines the different parts of the traversal state that
    can be reset by an SoResetTransform node.



  
TRANSFORM

  
Resets the current transformation matrix in the traversal state.

  
BOUNDING_BOX

  
Resets the current bounding box calculation in the traversal state.

  
PRIMITIVE_COUNT

  
Resets the primitive counter in the traversal state.
