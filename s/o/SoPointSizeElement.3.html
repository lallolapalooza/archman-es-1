Descripción Detallada

El SoPointSizeElement cambia la configuración del tamaño de los puntos del estado de renderizado.

Las solicitudes del grafo de escena para cambiar el tamaño de los puntos al renderizar primitivas de puntos se realizarán a través de este elemento.

La clase SoPointSizeElement en sí es solo una abstracción genérica para las clases So*PointSizeElement subyacentes con código específico para cada biblioteca de renderizado de modo inmediato compatible.

Detailed Description

This element holds the point size for the scene graph traversal.

This element is used to set the size of points in Coin. The point size is specified in screen coordinates. If the point size is set to 1.0, then a point will be one pixel in size. If the point size is set to 2.0, then a point will be two pixels in size, and so on.

The point size is set using the SoPointSizeElement::set() method. The point size is retrieved using the SoPointSizeElement::getSize() method.

The default point size is 1.0.
