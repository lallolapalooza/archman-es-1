Description détaillée

La classe SoExtSelection peut être utilisée pour des fonctionnalités de sélection étendues.

Cette classe vous permet de sélectionner de la géométrie en spécifiant un lasso (un polygone) ou un rectangle à l'écran. Lorsque des objets sont sélectionnés, vous recevrez les mêmes callbacks que pour le nœud SoSelection.

L'interface de programmation d'application de cette classe est quelque peu complexe, en raison de sa fonctionnalité non triviale. Pour voir un exemple d'utilisation *étendu* du nœud SoExtSelection, nous vous conseillons de consulter l'application d'exemple "extselection" dans le répertoire "nodes/" du dépôt Mercurial de SoGuiExamples. Des informations supplémentaires et des liens pour télécharger et compiler ce module devraient être disponibles sur github.com/coin3d/soguiexamples.

Cette classe de nœud est une extension par rapport à l'API originale d'Inventor SGI v2.1. Elle est basée sur l'API d'Inventor de VSG (anciennement TGS) SoExtSelection, et nous visons à être entièrement compatibles avec ce nœud afin de permettre aux utilisateurs de choisir entre l'utilisation d'Inventor Coin et VSG. Veuillez nous contacter si vous trouvez des écarts entre SoExtSelection de Coin et SoExtSelection de VSG.

FORMAT DE FICHIER/VALEURS PAR DÉFAUT:

ExtSelection {
    renderCaching AUTO
    boundingBoxCaching AUTO
    renderCulling AUTO
    pickCulling AUTO
    policy SHIFT
    lassoType NOLASSO
    lassoPolicy FULL_BBOX
    lassoMode ALL_SHAPES
}

TGS Inventor 2.5

Documentation des énumérations des membres

enum SoExtSelection::LassoType

Enum pour le type de sélection par lasso.

Énumérateur

NOLASSO
Fait que ce nœud se comporte comme un nœud SoSelection normal.
LASSO
Sélectionne les objets à l'aide d'un lasso. Les sélections peuvent être annulées par l'utilisateur final en appuyant sur la touche FIN sur le clavier.
RECTANGLE
Sélectionne les objets à l'aide d'un rectangle. Les sélections peuvent être annulées par l'utilisateur final en appuyant sur la touche FIN sur le clavier.

enum SoExtSelection::LassoPolicy

Enum pour spécifier comment les objets sont sélectionnés.

Énumérateur

FULL_BBOX
La boîte englobante entière doit être à l'intérieur du lasso/rectangle.
PART_BBOX
Une partie de la boîte englobante doit intercepter le lasso/rectangle.
FULL
Toutes les primitives doivent être complètement à l'intérieur du lasso/rectangle.
PART
Une primitive doit intercepter le lasso/rectangle.

enum SoExtSelection::LassoMode

Enum pour spécifier le mode de sélection.

Énumérateur

ALL_SHAPES
Toutes les primitives à l'intérieur du lasso/rectangle seront sélectionnées.
VISIBLE_SHAPES
Toutes les primitives *visibles* à l'intérieur du lasso/rectangle seront sélectionnées.

void SoExtSelection::useOverlay (SbBool overlay = TRUE)

Spécifie si les plans de superposition doivent être utilisés pour rendre le lasso.

Cette méthode a été obsolète dans Coin, car la plupart des cartes graphiques ne prennent pas en charge le rendu de superposition. Une meilleure stratégie consiste simplement à "superposer" les graphiques du lasso par-dessus la scène après que tout le reste a été rendu - et c'est la stratégie que nous appliquons dans Coin.

DESCRIPTION

This node is inherited from SoSelection and adds support for lasso and rectangle selection.

When lassoType is set to LASSO or RECTANGLE, the node intercepts the mouse events and draws a lasso or rectangle on the screen. When the mouse button is released, the node selects whatever lies inside the lasso or rectangle.

The default value for lassoType is NOLASSO, so that the node behaves exactly like SoSelection.

The lassoType field can be set to one of the following values:

NOLASSO: Do not draw lasso or rectangle. Behaves like SoSelection. (Default)

RECTANGLE: Draw a rectangle. When the mouse button is released, select whatever lies inside the rectangle.

LASSO: Draw a lasso. When the mouse button is released, select whatever lies inside the lasso.

There are two different types of lasso selection, depending on the value of the lassoPolicy field:

FULL_BBOX: Selects objects whose bounding box is entirely contained within the lasso or rectangle.

INTERSECT: Selects objects whose bounding box intersects the lasso or rectangle.

There are three different modes of selection, depending on the value of the lassoMode field:

ALL_SHAPES: Selects all primitives inside the lasso or rectangle. (Default)

VISIBLE_SHAPES: Selects only those primitives that are visible from the current viewpoint.

BOUNDING_BOX: Selects only the bounding boxes of the primitives inside the lasso or rectangle.

Lasso selection can be programmed by calling the select() method. This method can be called with 2D or 3D coordinates defining the lasso/rectangle.

The lasso/rectangle line can be styled using the setLassoColor(), setLassoWidth(), and setOverlayLassoPattern() methods.

It is also possible to animate the lasso line by calling animateOverlayLasso().

If you want to filter the selection process, you can use the callback methods setLassoFilterCallback(), setTriangleFilterCallback(), setLineSegmentFilterCallback(), and setPointFilterCallback().

The method wasShiftDown() can be used to check whether the SHIFT key was pressed during the latest user interaction.
