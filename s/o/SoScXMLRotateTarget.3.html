NAME

SoScXMLRotateTarget — Rotating target for ScXML.

SYNOPSIS

#include <Inventor/ScXML/nodes/SoScXMLRotateTarget.h>


COIN_DLL_API
class SoScXMLRotateTarget : public SoScXMLTargetNode

Detailed Description

This class is a SoScXMLTargetNode that can be used for ScXML to handle rotate events.

This class is primarily intended for internal use.
