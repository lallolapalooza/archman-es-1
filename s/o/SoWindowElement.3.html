Descripción detallada

La clase SoWindowElement se utiliza para almacenar los atributos actuales de la ventana.

En Coin, este elemento no es compatible con la API de SGI Inventor, ya que contiene elementos específicos de la plataforma, de los que queremos evitar.

En lugar de los tipos específicos de la plataforma, utilizamos punteros void. Lamentamos cualquier inconveniente que esto pueda causar a las personas que utilizan este elemento.

void SoWindowElement::push (SoState * state) [virtual]

Este método se llama cada vez que se requiere un nuevo elemento en una de las pilas. Esto ocurre cuando se solicita un elemento escribible, utilizando SoState::getElement() o indirectamente SoElement::getElement(), y la profundidad del elemento actual es menor que la profundidad del estado.

Reimplemente este método si su elemento necesita copiar datos del elemento superior anterior de la pila. El método push() se llama en el nuevo elemento, y el elemento anterior se puede encontrar utilizando SoElement::getNextInStack().

DESCRIPCIÓN DETALLADA

This element stores the current OpenGL window, OpenGL rendering context, and display information. It is used by SoGLRenderAction to keep track of the rendering context.

The window, context, and display pointers are platform-dependent. On Win32, they correspond to a window handle (HWND), a device context (HDC), and a display pointer (HDC, though it could be a different display pointer depending on the graphics drivers). On X11, they correspond to a window identifier (Window), an OpenGL rendering context (GLXContext), and a display pointer (Display *).

Note that the display parameter is often the same value as the context parameter on some platforms.

An instance of this element is created by SoWin for each window it manages.
