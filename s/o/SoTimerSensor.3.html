Descripción detallada

La clase SoTimerSensor es un sensor que se activará en intervalos dados.

Utilice sensores de esta clase cuando desee que una tarea se repita a un cierto intervalo, sin necesidad de reprogramar explícitamente el sensor (es decir, SoTimerSensor se reprograma automáticamente después de activarse).

Las instancias de SoTimerSensor se utilizan comúnmente para activar actualizaciones de animación a una velocidad de fotogramas constante.

Documentación de funciones miembro

void SoTimerSensor::setBaseTime (const SbTime & baseref)

Establece el tiempo de activación base.

Si utiliza este método, los tiempos de activación serán en intervalos a partir del valor dado.

Sin un tiempo base explícitamente establecido, la próxima invocación de activación después de que haya ocurrido una activación será en el tiempo actual más el tiempo de intervalo. Tenga en cuenta que esto provocará que el temporizador se desvíe.
