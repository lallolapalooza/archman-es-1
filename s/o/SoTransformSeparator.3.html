Descripción detallada

La clase SoTransformSeparator es un nodo de grupo que conserva las transformaciones actuales.

Este nodo funciona de manera similar al nodo de grupo SoSeparator, excepto que solo almacena y restaura la transformación de la matriz modelo actual. Otras configuraciones de apariencia, como materiales, texturas, cámaras, luces, etc., afectarán las partes restantes del grafo de escena después del recorrido, al igual que para el nodo SoGroup.

NAME

SoTransformSeparator - separator node that applies a transform to its children

SYNOPSIS

#include <Inventor/nodes/SoTransformSeparator.h>

class SoTransformSeparator : public SoSeparator

Inherits from SoSeparator.

Inherited by SoTransform.

Detailed Description

This node is a subclass of SoSeparator. It is used to apply a transformation to all the nodes within its children list. The transformation is defined by the SoTransform node, which is implicitly added as the first child of the separator if it does not already exist.

This means that any transformation defined within a SoTransformSeparator node will affect all of its children.

The primary use case for this node is to group a transformation with a subgraph of nodes, applying the transformation to the subgraph without affecting the rest of the scene graph.
