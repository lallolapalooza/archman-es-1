Descripción detallada

La clase SoBase es la superclase de nivel superior para una serie de jerarquías de clases.

SoBase proporciona las interfaces y métodos básicos para la gestión de recuentos de referencias, identificación de tipos e importación/exportación. Todas las clases en Coin que utilizan estos mecanismos descienden de esta clase.

Una cuestión importante con las clases derivadas de SoBase es que *no* deben ser asignadas estáticamente, ni en la memoria estática del módulo ni en los marcos de pila de las funciones. Las clases derivadas de SoBase *siempre* deben ser asignadas dinámicamente desde el montón de memoria con el operador new.

Esto se debe a que las instancias derivadas de SoBase se cuentan por referencias y se autodestruirán en el momento apropiado. Para que esto funcione, deben ser asignadas explícitamente en la memoria del montón. Véase la documentación de la clase SoNode para más información.

Documentación de funciones miembro

void SoBase::ref (void ) const

Incrementa el recuento de referencias del objeto. Esto podría ser necesario hacerlo explícitamente desde el código de usuario para ciertas situaciones (principalmente para evitar la eliminación prematura), pero generalmente es llamado por otras instancias dentro de la biblioteca Coin cuando los objetos se vuelven dependientes unos de otros.

Véase la documentación de la clase SoNode para obtener información más extensa sobre la gestión de referencias.

Véase también

unref(), unrefNoDelete()

void SoBase::unref (void ) const

Disminuye el recuento de referencias de un objeto. Si el recuento de referencias llega a cero, el objeto se eliminará a sí mismo. Ten cuidado al llamar explícitamente a este método, ten en cuenta que generalmente necesitas hacer coincidir las llamadas a nivel de usuario a ref() con llamadas a unref() o unrefNoDelete() para evitar fugas de memoria.

Véase también

ref(), unrefNoDelete()

void SoBase::unrefNoDelete (void ) const

Disminuye el recuento de referencias, pero *no* se elimina a sí mismo si el recuento llega a cero.

virtual SoType SoBase::getTypeId (void ) const [pure virtual]

Devuelve la identificación de tipo de un objeto derivado de una clase que hereda de SoBase. Esto se utiliza para la comprobación de tipos en tiempo de ejecución y para la conversión de tipos "descendente". Ejemplo de uso:

void foo(SoNode * node)
{
  if (node->getTypeId() == SoFile::getClassTypeId()) {
    SoFile * filenode = (SoFile *)node;  // conversión descendente segura, conoce el tipo
  }
}

Para los programadores de aplicaciones que deseen extender la biblioteca con nodos, motores, kits de nodos, selectores o de otro tipo nuevos: este método debe ser sobrescrito en *todos* los subclases. Esto se suele hacer como parte de la configuración del sistema de tipos completo para las clases de extensión, lo que normalmente se logra mediante el uso de las macros predefinidas disponibles a través de, por ejemplo, Inventor/nodes/SoSubNode.h (SO_NODE_INIT_CLASS y SO_NODE_CONSTRUCTOR para las clases de nodo), Inventor/engines/SoSubEngine.h (para las clases de motor) y así sucesivamente.

Para obtener más información sobre cómo escribir extensiones de Coin, consulte la documentación de la clase de las superclases de nivel superior para los diversos grupos de clases.

NAME

SoBase - base class for all Coin objects

SYNOPSIS

#include <Inventor/SoBase.h>

Subclasses
    SoEngine, SoFieldContainer, SoNode, SoProto, SoVRMLParent

Inherited members see <a href="SoOffscreenRenderer.html#SoBase">SoBase</a>

Detailed Description

This is the base class for all Coin objects. It provides basic functionality like reference counting and a mechanism for loading dynamic modules.

The following methods are inherited by <a href="SoNode.html#SoNode">SoNode</a>, <a href="SoEngine.html#SoEngine">SoEngine</a>, <a href="SoFieldContainer.html#SoFieldContainer">SoFieldContainer</a> and <a href="SoProto.html#SoProto">SoProto</a>.

Reference Counting:

All Coin objects (nodes, engines, fields, etc.) are reference counted. When an object is created, its reference count is initialized to one. When a pointer to an object is copied, the reference count is incremented using the ref() method. When a pointer to an object is no longer needed, the reference count should be decremented using the unref() method. When the reference count reaches zero, the object is destroyed.

Reference tracing:

If the reference tracing flag is enabled, Coin will print a warning message to stderr whenever an object's reference count drops to zero, indicating that the object is being destroyed.

This is useful for detecting memory leaks or dangling pointers. The flag can be toggled using the setTraceRefs() and getTraceRefs() methods.

Dynamic modules:

Coin supports loading of dynamic modules, which are shared libraries that extend the functionality of the library. This is done using the SoDLModule::load() method.

See also

SoNode, SoEngine, SoFieldContainer, SoProto, SoDLModule

Deprecated

The following methods are deprecated and will be removed in a future release:

  • SoBase::hasMultipleWriteRefs()

SbBool SoBase::setTraceRefs (SbBool flag)

Enable/disable reference tracing. If flag is TRUE, Coin will print a warning message to stderr whenever an object's reference count drops to zero. This can be useful for detecting memory leaks or dangling pointers.

The return value is the previous state of the flag.

See also

getTraceRefs()
