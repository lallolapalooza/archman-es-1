Descripción Detallada

Nivel de integración para usar eventos Coin con máquinas de estados basadas en SCXML.

Esta clase forma parte de la integración de los tipos Coin con el subsistema SCXML. SoScXMLStateMachines añade conveniencia para usar máquinas de estados SCXML junto con eventos Coin.

Desde

Coin 3.0

SbBool SoScXMLStateMachine::processSoEvent(const SoEvent *event) [virtual]

Procesa un evento Coin y lo transforma en un evento SCXML.

Este método se puede sobrescribir para preprocesar eventos Coin. Por ejemplo, se puede usar para mapear eventos de entrada del ratón en eventos SCXML personalizados.

Devuelve

Devuelve TRUE si el evento fue consumido y debe ser ignorado por otros manejadores de eventos.
