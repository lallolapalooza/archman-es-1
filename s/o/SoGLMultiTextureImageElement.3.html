int32_t SoGLMultiTextureImageElement::getMaxGLTextureSize (void ) [static]

The size returned by this function will just be a very coarse estimate as it only uses the more or less obsoleted technique of calling glGetIntegerv(GL_MAX_TEXTURE_SIZE).

For a better estimate, use SoGLTextureImageElement::isTextureSizeLegal().

NAME

SoGLMultiTextureImageElement - OpenGL multi-texture image element

SYNOPSIS

Inherits from SoTextureImageElement.

This element sets up the necessary OpenGL texture environment for multi-texturing. It is used internally by OpenInventor.

Detailed Description

The SoGLMultiTextureImageElement is an OpenInventor internal element that manages the OpenGL texture environment for multi-texturing. When multiple textures are applied to a scene graph object, this element ensures that the correct OpenGL texture units and parameters are set up to blend or combine these textures as intended.

It inherits from SoTextureImageElement and extends its functionality to handle the complexities of multi-texturing, which involves coordinating multiple texture units, texture coordinates, and texture application modes.
