NOMBRE

SoShaderParameterArray4f - La clase SoShaderParameterArray4f se utiliza para definir un array flotante de cuatro dimensiones como parámetro de shader.

SINOPSIS

#include <Inventor/nodes/SoShaderParameter.h>
