Descripción Detallada

La clase SoInt32Element es la clase base para elementos que simplemente almacenan un entero de 32 bits.

Esta es la superclase de los elementos donde los nuevos datos del elemento *reemplazan* los datos antiguos, y donde los datos que el elemento almacena son un simple valor entero de 32 bits.

Este elemento es como una versión conveniente y ligera de SoReplacedElement. Difiere de SoReplacedElement en que los métodos set() y get() ya están implementados, ya que se sabe que las subclases aún contendrán solo un único valor entero de 32 bits.
