Descripción Detallada

Este elemento mantiene la unidad de textura actual. El valor de esta unidad se utiliza para direccionar la textura en la que se está escribiendo actualmente. Por ejemplo, si tiene varias texturas aplicadas a una geometría, puede usar este elemento para especificar a cuál de ellas se le aplican las operaciones de texturizado posteriores.
