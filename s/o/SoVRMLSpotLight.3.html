Descripción Detallada

La clase SoVRMLSpotLight define una fuente de luz puntual.

La documentación detallada de la clase se toma textualmente del estándar VRML97 (ISO/IEC 14772-1:1997). Se utiliza con permiso del Consorcio Web3D:

SpotLight {
  exposedField SFFloat ambientIntensity  0         # [0,1]
  exposedField SFVec3f attenuation       1 0 0     # [0,inf)
  exposedField SFFloat beamWidth         1.570796  # (0,pi/2]
  exposedField SFColor color             1 1 1     # [0,1]
  exposedField SFFloat cutOffAngle       0.785398  # (0,pi/2]
  exposedField SFVec3f direction         0 0 -1    # (-inf, inf)
  exposedField SFFloat intensity         1         # [0,1]
  exposedField SFVec3f location          0 0 0     # (-inf, inf)
  exposedField SFBool  on                TRUE
  exposedField SFFloat radius            100       # [0, inf)
}

El nodo SpotLight define una fuente de luz que emite luz desde un punto específico a lo largo de un vector de dirección específico y restringida dentro de un ángulo sólido. Las luces puntuales pueden iluminar nodos de geometría que responden a fuentes de luz e intersectan el ángulo sólido definido por el SpotLight. Los nodos SpotLight se especifican en el sistema de coordenadas local y se ven afectados por las transformaciones de sus ancestros.

Una descripción detallada de ambientIntensity, color, intensity y las ecuaciones de iluminación de VRML se proporciona en 4.6.6, Fuentes de luz (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.6). Se puede encontrar más información sobre conceptos de iluminación en 4.14, Modelo de iluminación (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14), incluida una descripción detallada de las ecuaciones de iluminación de VRML.

El campo location especifica un desplazamiento de traslación del punto central de la fuente de luz desde el origen del sistema de coordenadas local de la luz. Este punto es el ápice del ángulo sólido que limita la emisión de luz de la fuente de luz dada.

El campo direction especifica el vector de dirección del eje central de la luz definido en el sistema de coordenadas local.

El campo on especifica si la fuente de luz emite luz. Si on es TRUE, la fuente de luz está emitiendo luz y puede iluminar la geometría en la escena. Si on es FALSE, la fuente de luz no emite luz y no ilumina ninguna geometría.

El campo radius especifica la extensión radial del ángulo sólido y la distancia máxima desde location que puede ser iluminada por la fuente de luz. La fuente de luz no emite luz fuera de este radio. El radio debe ser mayor o igual a cero.

Tanto radius como location se ven afectados por las transformaciones de los ancestros (las escalas afectan al radio y las transformaciones afectan a location).

El campo cutOffAngle especifica el límite exterior del ángulo sólido. La fuente de luz no emite luz fuera de este ángulo sólido.

El campo beamWidth especifica un ángulo sólido interior en el que la fuente de luz emite luz a una intensidad máxima uniforme. La intensidad de emisión de la fuente de luz disminuye desde el ángulo sólido interior (beamWidth) hasta el ángulo sólido exterior (cutOffAngle) como se describe en las siguientes ecuaciones:

angle = el ángulo entre el vector de dirección del Spotlight
        y el vector desde la ubicación del Spotlight hasta el punto
        a iluminar
if (angle >= cutOffAngle):
  multiplier = 0
else if (angle <= beamWidth):
  multiplier = 1
else:
  multiplier = (angle - cutOffAngle) / (beamWidth - cutOffAngle)
intensity(angle) = SpotLight.intensity × multiplier

Si el beamWidth es mayor que el cutOffAngle, el beamWidth se define como igual al cutOffAngle y la fuente de luz emite intensidad completa dentro de todo el ángulo sólido definido por el cutOffAngle. Tanto beamWidth como cutOffAngle deben ser mayores que 0.0 y menores o iguales a pi/2.

La Figura 6.16 representa los campos beamWidth, cutOffAngle, direction, location y radius del nodo SpotLight.


Figura 6.16 -- Nodo SpotLight

La iluminación de SpotLight disminuye con la distancia según lo especificado por tres coeficientes de atenuación. El factor de atenuación es

1/max(attenuation[0] + attenuation[1]×r + attenuation[2]×r^2 , 1),

donde r es la distancia desde la luz hasta la superficie que se está iluminando. El valor predeterminado es sin atenuación. Un valor de atenuación de (0, 0, 0) es idéntico a (1, 0, 0). Los valores de atenuación deben ser mayores o iguales a cero. Una descripción detallada de las ecuaciones de iluminación de VRML se encuentra en 4.14, Modelo de iluminación (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14).
