Descripción detallada

La clase SoSFVec2b es un contenedor para un vector SbVec2b.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con dos elementos.

Ver también

SbVec2b, SoMFVec2b Ten en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

NAME

SoSFVec2b — Single-value field for 2-component short integers

SYNOPSIS

#include <Inventor/fields/SoSFVec2b.h>

Class
SoSFVec2b

Methods

Detailed Description

This field is used to store a 2-component vector of int8_t.

Use this field type for fields that contain 2-component vectors of signed 8-bit integers. Note that the components are stored internally as short integers, so they will always be in the range [-127, 127].

The SoSFVec2b field is a subclass of SoSFVec2b.
