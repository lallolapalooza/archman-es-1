Descripción detallada

La clase SoGLBigImage se utiliza para manejar texturas OpenGL 2D de cualquier tamaño.

Esta clase es interna. Para habilitar/deshabilitar el manejo de texturas de imágenes grandes, debes usar el nodo SoTextureScalePolicy.

La técnica utilizada es la siguiente: dividir la textura en bloques de tamaño x*y iguales. Todas estas subtexturas son de tamaño 2^n, y típicamente son bastante pequeñas (256x256 o menos). Cada triángulo se recorta, basándose en las coordenadas de textura, en varios triángulos más pequeños. Los triángulos usarán solo una subtextura. Luego, los triángulos se proyectan en la pantalla y se calcula el tamaño máximo proyectado para cada subtextura. Las subtexturas fuera del viewport se descartarán. Cada subtextura se reduce a un valor de 2^n cercano al tamaño proyectado, y se crea una textura GL con ese tamaño. Esta textura GL se utiliza al renderizar triángulos que se recortan en esa subtextura.

El mipmapping está deshabilitado para SoGLBigImage. Los problemas de aliasing no deberían ocurrir porque el tamaño proyectado de la textura se calcula sobre la marcha. Cuando el mipmapping está habilitado, la cantidad de memoria de textura utilizada se duplica, y la creación del objeto de textura es mucho más lenta, por lo que evitamos esto para SoGLBigImage.

Ten en cuenta que esta clase es una extensión de Coin y no está disponible en la API original Open Inventor v2.1 de SGI.

Documentación de funciones miembro

void SoGLBigImage::unref (SoState * state = NULL) [virtual]

Esta clase tiene un destructor privado ya que queremos que los usuarios proporcionen el estado GL actual al eliminar la imagen. Esto es para asegurarse de que los objetos de textura GL se liberen lo antes posible. Si proporcionas NULL a este método, los objetos de textura GL no se eliminarán hasta la próxima vez que se aplique una acción de renderizado GL en el contexto de caché de la imagen.
