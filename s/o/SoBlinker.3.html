Detailed Description

The SoBlinker class is a cycling switch node.

This switch node cycles its children SoBlinker::speed number of times per second. If the node has only one child, it will be cycled on and off. Cycling can be turned off using the SoBlinker::on field, and the node then behaves like a normal SoSwitch node.

FILE FORMAT/DEFAULTS:

Blinker {
    whichChild -1
    speed 1
    on TRUE
}

Descripción Detallada

Este nodo es una versión del nodo SoSwitch que se apaga y enciende automáticamente a una velocidad dada. Es útil para hacer que ciertas partes de una escena parpadeen o cambien de visibilidad.

El nodo SoBlinker tiene dos campos:

speed
Especifica la velocidad del parpadeo en ciclos por segundo. Un valor de 1.0 significa que el nodo se apagará y encenderá una vez por segundo. La velocidad debe ser positiva.
on
Controla si el parpadeo está activado o desactivado. Si está establecido en TRUE, el nodo parpadeará. Si está establecido en FALSE, el nodo permanecerá visible (equivalente a un nodo SoSwitch con el selector establecido en SoSwitch::ALL).

El comportamiento exacto de SoBlinker es el siguiente:

  • Si on es FALSE, el nodo SoBlinker siempre se considera ENCENDIDO.
  • Si on es TRUE, el nodo SoBlinker alternará entre ENCENDIDO y APAGADO a la velocidad especificada por speed.

El nodo SoBlinker hereda la funcionalidad de gestión de hijos del nodo SoSwitch. Los hijos del nodo SoBlinker se mostrarán o ocultarán según el estado actual del parpadeo.
