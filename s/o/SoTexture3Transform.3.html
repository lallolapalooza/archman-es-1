Detailed Description

The SoTexture3Transform class is used to define 3D texture transformations.

Textures applied to shapes in the scene can be transformed by "prefixing" in the state with instances of this node type. Translations, rotations and scaling in 3D can all be done.

The default settings of this node's fields equals a "nulltransform", i.e. no transformation.

Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.
FILE FORMAT/DEFAULTS:

Texture3Transform {
    translation 0 0 0
    rotation 0 0 1  0
    scaleFactor 1 1 1
    scaleOrientation 0 0 1  0
    center 0 0 0
}

Detailed Description


This node defines a 3D texture transformation. This transformation
    is applied to the texture coordinates before they are used to look up
    texture values.


The transformation is composed of a translation, a rotation and
    a scaling. The order in which these transformations are applied is
    translation, then rotation, then scaling.


The translation is defined by the translation field. The rotation
    is defined by the rotation field. The scaling is defined by the scaleFactor
    field. The center field defines the center point for the scaling and
    rotation operations.


The scaleOrientation field defines the orientation of the texture
    before scaling. The scaleFactor is applied along the axes of this
    orientation.


The default value for all fields is identity (no translation, no
    rotation, no scaling, and center at the origin).


The scaleFactor and translation fields are of type SoSFVec3f. The
    rotation field is of type SoSFRotation. The center field is of type
    SoSFVec3f.
