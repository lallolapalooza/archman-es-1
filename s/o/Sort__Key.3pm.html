NOMBRE

Sort::Key - la forma más rápida de ordenar cualquier cosa en Perl

SINOPSIS

use Sort::Key qw(keysort nkeysort ikeysort);
@by_name = keysort { "$_->{surname} $_->{name}" } @people;
# ordenar por una clave numérica:
@by_age = nkeysort { $_->{age} } @people;
# ordenar por una clave entera numérica:
@by_sons = ikeysort { $_->{sons} } @people;

DESCRIPCIÓN

Sort::Key proporciona un conjunto de funciones para ordenar listas de valores por algún valor clave calculado.

Es más rápido (normalmente **mucho más rápido**) y usa menos memoria que otras alternativas implementadas alrededor de la función sort de perl (ST, GRT, etc.).

La funcionalidad de ordenación de claves múltiples también se proporciona a través de los módulos complementarios Sort::Key::Multi, Sort::Key::Maker y Sort::Key::Register.

FUNCIONES

Este módulo proporciona un gran número de subrutinas de ordenación, pero todas son variaciones de la de "keysort":

@sorted = keysort { CALC_KEY($_) } @data

que es conceptualmente equivalente a

@sorted = sort { CALC_KEY($a) cmp CALC_KEY($b) } @data

y donde CALC_KEY($_) puede ser cualquier expresión para extraer el valor clave de $_ (no solo una llamada a subrutina).

Por ejemplo, algunas variaciones son "nkeysort" que realiza una comparación numérica, "rkeysort" que ordena los datos en orden descendente, "ikeysort" y "ukeysort" que son versiones optimizadas de "nkeysort" que se pueden usar cuando las claves son enteros o enteros sin signo respectivamente, etc.

Además, se proporcionan versiones de ordenación in situ de los ordenadores. Por ejemplo:

keysort_inplace { CALC_KEY($_) } @data

que es equivalente a

@data = keysort { CALC_KEY($_) } @data

pero siendo (un poco) más rápido y usando menos memoria.

La lista completa de subrutinas que se pueden importar desde este módulo es la siguiente:

keysort { CALC_KEY } @array
devuelve los elementos de @array ordenados por la clave calculada aplicando "{ CALC_KEY }" a ellos.

Dentro de "{ CALC_KEY }", el objeto está disponible como $_.

Por ejemplo:

@a=({name=>john, surname=>smith}, {name=>paul, surname=>belvedere});
@by_name=keysort {$_->{name}} @a;

Esta función respeta el pragma "use locale".

nkeysort { CALC_KEY } @array
similar a "keysort" pero compara las claves numéricamente en lugar de como cadenas.

Esta función respeta el pragma "use integer", es decir:

use integer;
my @s=(2.4, 2.0, 1.6, 1.2, 0.8);
my @ns = nkeysort { $_ } @s;
print "@ns\n"

imprime

0.8 1.6 1.2 2.4 2
rnkeysort { CALC_KEY } @array
funciona como "nkeysort", comparando las claves en orden numérico inverso (o descendente).
ikeysort { CALC_KEY } @array
funciona como "keysort" pero compara las claves como enteros (32 bits o más, no se realiza ninguna comprobación de desbordamiento).
rikeysort { CALC_KEY } @array
funciona como "ikeysort", pero en orden inverso (o descendente).
ukeysort { CALC_KEY } @array
funciona como "keysort" pero compara las claves como enteros sin signo (32 bits o más).

Por ejemplo, se puede utilizar para ordenar eficientemente direcciones IP4:

my @data = qw(1.2.3.4 4.3.2.1 11.1.111.1 222.12.1.34
              0.0.0.0 255.255.255.0) 127.0.0.1);
my @sorted = ukeysort {
                 my @a = split /\./;
                 (((($a[0] << 8) + $a[1] << 8) + $a[2] << 8) + $a[3])
             } @data;

Por ejemplo, estas construcciones son equivalentes:

@sorted = nsort @foo;
@sorted = nkeysort { $_ } @foo;

multikeysorter(@types)
multikeysorter_inplace(@types)
multikeysorter(\&genkeys, @types)
multikeysorter_inplace(\&genkeys, @types)
son la interfaz de bajo nivel para la funcionalidad de ordenación de claves múltiples (normalmente, deberías usar Sort::Key::Maker y Sort::Key::Register o Sort::Key::Multi en su lugar).

Reciben una lista de descripciones de claves y devuelven una referencia a una subrutina de ordenación de claves múltiples.

Los tipos aceptados por defecto son:

string, str, locale, loc, integer, int,
unsigned_integer, uint, number, num

y el soporte para tipos adicionales se puede añadir a través de la subrutina register_type disponible en Sort::Key::Types o la interfaz más amigable disponible en Sort::Key::Register.

Los tipos pueden ir precedidos por un signo menos para indicar orden descendente.

NAME

Sort::Key::Multi - Función de extracción de clave multi-dimensional

SYNOPSIS

my $sorter1 = multikeysorter(sub {length $_, $_}, qw(int str)); my @sorted1 = &$sorter1(qw(foo fo o of oof)); my $sorter2 = multikeysorter(qw(int str)); my @sorted2 = &$sorter2(sub {length $_, $_}, qw(foo fo o of oof));

DESCRIPTION

La función de extracción de clave multi-dimensional. Si no, las sorters generadas esperan un argumento como su primer argumento.

SEE ALSO

función de ordenamiento de Perl, entero, locale.

módulos complementarios Sort::Key::Multi, Sort::Key::Register, Sort::Key::Maker y Sort::Key::Natural.

módulos Sort::Key::IPv4, Sort::Key::DateTime y Sort::Key::OID añaden soporte para tipos de datos adicionales a Sort::Key.

módulo Sort::Key::External permite ordenar listas grandes que no se ajustan en el espacio de memoria disponible.

módulos interesantes de ordenamiento de Perl incluyen Sort::Maker, Sort::Naturally y Sort::External.
