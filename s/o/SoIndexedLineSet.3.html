NOMBRE

SoIndexedLineSet - La clase SoIndexedLineSet se utiliza para renderizar y representar de otro modo líneas indexadas.

SINOPSIS

#include <Inventor/nodes/SoIndexedLineSet.h>

Detailed Description

La clase SoIndexedLineSet se utiliza para renderizar y representar de otra manera líneas indexadas.

La contraparte indexada de SoLineSet. Las líneas se pueden especificar utilizando índices para coordenadas, normales, materiales y coordenadas de textura.

Si no se proporcionan normales en la pila (o en el campo vertexProperty), las líneas se renderizarán con la iluminación deshabilitada.

Para más información sobre conjuntos de líneas, consulte la documentación en SoLineSet. Para más información sobre formas indexadas, consulte la documentación en SoIndexedShape y SoIndexedFaceSet.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

IndexedLineSet {
    vertexProperty NULL
    coordIndex 0
    materialIndex -1
    normalIndex -1
    textureCoordIndex -1
}
