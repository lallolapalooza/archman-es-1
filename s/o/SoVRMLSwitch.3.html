Descripción Detallada

La clase SoVRMLSwitch es un nodo de grupo para atravesar hijos seleccionados.

La documentación detallada de la clase se toma textualmente del estándar VRML97 (ISO/IEC 14772-1:1997). Se utiliza con permiso del Consorcio:

Switch {
  exposedField    MFNode  choice      []
  exposedField    SFInt32 whichChoice -1    # [-1, inf)
}

El nodo de agrupación Switch atraviesa cero o uno de los nodos especificados en el campo choice. 4.6.5, Nodos de agrupación e hijos (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.5), describe detalles sobre los tipos de nodos que son valores legales para choice.

El campo whichChoice especifica el índice del hijo a atravesar, siendo el primer hijo el índice 0. Si whichChoice es menor que cero o mayor que el número de nodos en el campo choice, no se elige nada. Todos los nodos bajo un Switch continúan recibiendo y enviando eventos independientemente del valor de whichChoice. Por ejemplo, si un SoVRMLTimeSensor activo está contenido dentro de una opción inactiva de un Switch, el SoVRMLTimeSensor envía eventos independientemente del estado del Switch.

DESCRIPTION

This node is used to select a single child node from a list of possible children. The child to be activated is determined by the value of the whichChoice field.

If whichChoice is negative, all children are deactivated. If whichChoice is greater than or equal to the number of children, all children are deactivated.

Otherwise, if whichChoice is between 0 and getNumChildren-1 (inclusive), the child at that index is activated, and all other children are deactivated.

Note that the VRML97 specification defines the default value for whichChoice to be 0.

Note that the VRML97 specification defines the default behavior for the Switch node to only activate the selected child if the value of whichChoice is non-negative.

This node is inherited from SoGroup and is therefore functionally equivalent to the SoSwitch node.

This node is not an actual VRML97 node. It is provided for compatibility with the VRML97 specification.

The SoSwitch node is the preferred way to implement this functionality in OpenInventor.

FIELDS

SoSFInt32 whichChoice
The index of the child node that should be activated.

virtual SbBool SoVRMLSwitch::affectsState() const

Returns TRUE if this node might affect the rendering state. For example, nodes that modify the traversal state (like SoTransform nodes) or that are used to set rendering parameters (like SoMaterial nodes) will return TRUE. Grouping nodes that just organize other nodes (like SoGroup or SoSwitch) will return FALSE.

SoNode, SoInfoNode, SoSeparator, SoVRMLNode, SoVRMLSwitch, SoVRMLGroup, SoVRMLText, and SoVRMLNormal will for instance return FALSE, as it pushes and pops the state before and after traversal of its children. All SoShape nodes will also return FALSE, as just pushing out geometry data to the rendering engine won't affect the actual rendering state.

The default method returns TRUE, on a "better safe than sorry" philosophy.

switch node that selects one or more children based on the whichChoice field.

The SoVRMLSwitch node allows you to conditionally render one or more children. It is commonly used to implement interactive menus, state changes, or visibility toggles.

The selection logic is controlled by the whichChoice field. The children are managed through the choice field, which is a standard SoMFNode.

The following values for whichChoice are supported:

  • A non-negative integer: Selects the child at the specified index. If the index is out of bounds, no children are selected.
  • SO_SWITCH_NONE (-1): No children are selected.
  • SO_SWITCH_ALL (-2): All children are selected.
  • SO_SWITCH_INHERIT (-3): The selection is inherited from the parent switch node. If there is no parent switch node, this behaves like SO_SWITCH_ALL.

When the whichChoice field changes, the SoVRMLSwitch node updates its active children accordingly and triggers a scene graph traversal update.

The SoVRMLSwitch node is particularly useful in VRML/X3D contexts where it mirrors the behavior of the VRML/X3D Switch node.

Please note that some methods documented here, while part of the SoVRMLSwitch class for completeness, are inherited from SoGroup and may have different behavior or be less relevant in the specific context of SoVRMLSwitch.

SoSFInt32 SoVRMLSwitch::whichChoice

Selected choice. Can be a positive number from 0 to <numchildren-1>, or one of the constants SO_SWITCH_NODE, SO_SWITCH_ALL or SO_SWITCH_INHERIT. Default value is SO_SWITCH_NONE.
