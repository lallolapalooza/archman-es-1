Descripción detallada

La clase SoInput es una abstracción de la funcionalidad de importación de archivos.

Esta clase se encarga de la mayoría de las tareas de importación de datos en Coin. Pone una capa de abstracción sobre las operaciones de lectura para que sea transparente para el resto del código de Coin si estamos leyendo desde un archivo, desde un buffer de memoria o desde la entrada estándar.

SoInput también se encarga de verificar la validez del archivo, así como de manejar información sobre características en los diversos formatos de archivo que se admiten.

Ejemplo de uso:

int
main(void)
{
  SoDB::init();
  SoInput in;
  if (in.openFile("fab_model.iv")) {
    SoSeparator * root = SoDB::readAll(&in);
    if (root) {
      // Haz cosas con el grafo de escena importado aquí
      // ...
      return 0;
    }
  }
  return 1;
}

Nota importante: hay varios métodos públicos y protegidos que permiten pasar o devolver estructuras FILE* en esta clase. No utilice estos métodos cuando la biblioteca Coin se haya compilado como una DLL de Microsoft Windows, ya que pasar instancias de FILE* de ida y vuelta a DLL es peligroso y lo más probable es que cause un error. Esta es una limitación intrínseca para las DLL de Microsoft Windows.

Esta clase admite una variable de entorno llamada COIN_SOINPUT_SEARCH_GLOBAL_DICT. Cuando se establece en "1", el diccionario global se busca después del diccionario de archivos actual al resolver las palabras clave USE. Esto permite hacer referencia a nodos en otros archivos. La razón para introducir esta característica es que el nodo SoFile vuelve a leer el archivo cada vez que cambia el campo de nombre. La primera vez que se lee el archivo, es posible hacer referencia a nodos en el archivo padre, utilizando la palabra clave USE. Pero, cuando el archivo se vuelve a leer, esto ya no es posible, ya que la lectura ahora comienza en el nodo SoFile, con un diccionario vacío.

void SoInput::setFilePointer (FILE * newFP) [virtual]

Utiliza el puntero de archivo proporcionado como archivo de entrada. La pila de archivos de entrada se vaciará primero. Cerrar un archivo pasado por su puntero de archivo es responsabilidad del usuario de la biblioteca.

Nota importante: no utilice este método cuando la biblioteca Coin se haya compilado como una DLL de Microsoft Windows, ya que pasar instancias de FILE* de ida y vuelta a las DLL es peligroso y lo más probable es que cause un bloqueo. Esta es una limitación intrínseca para las DLL de Microsoft Windows.

Tenga en cuenta que no está permitido pasar un FILE* a un archivo comprimido con gzip en Mac OS X.

SbBool SoInput::openFile (const char * fileName, SbBool okIfNotFound = FALSE) [virtual]

Abre el archivo especificado y lo convierte en el único en la pila de archivos. Si okIfNotFound es FALSE, se mostrará un mensaje de advertencia si el archivo no se pudo abrir.

Devuelve TRUE si el archivo se pudo abrir para lectura, FALSE en caso contrario.

Nota: incluso si su intento de abrir un archivo no tiene éxito, la instancia de SoInput no volverá a leer desde stdin después de que se haya realizado una llamada a este método.

Ver también

setFilePointer(), pushFile(), closeFile()

SbBool SoInput::pushFile (const char * filename) [virtual]

Empuja un nuevo archivo en la parte superior de la pila. Las operaciones de lectura posteriores se realizarán con el nuevo archivo hasta que alcance el final del archivo, momento en el cual el archivo se sacará de la pila y continuaremos con el siguiente archivo en la pila.

Devuelve TRUE si el archivo se pudo abrir para lectura, FALSE en caso contrario.

Ver también

openFile()

void SoInput::closeFile (void ) [virtual]

Elimina todos los archivos de la pila interna. Los archivos abiertos por openFile() o pushFile() también se cerrarán, pero no los archivos provenientes de setFilePointer(), que son responsabilidad del llamador.

Por lo general, no necesita llamar a este método explícitamente, ya que se activará automáticamente en el destructor de SoInput para cerrar cualquier archivo abierto cuando la instancia de SoInput salga del ámbito.

FILE * SoInput::findFile (const char * basename, SbString & fullname) [protected]

Esta API es considerada interna a la biblioteca, ya que es poco probable que sea de interés para el programador de aplicaciones.


Devuelve el flujo actualmente activo.

Escanea los directorios de inclusión en orden y trata de encontrar un archivo con el nombre dado en cualquiera de ellos. Si se encuentra el archivo, coloca el nombre completo con la ruta completa desde el directorio actual del proceso en fullname, abre el archivo y devuelve el puntero al archivo.

Si el archivo no se pudo encontrar o no se pudo abrir para lectura, devuelve NULL.

Nota importante: no utilice este método cuando la biblioteca Coin se haya compilado como una DLL de Microsoft Windows, ya que pasar instancias de FILE* de ida y vuelta a DLL es peligroso y lo más probable es que cause un bloqueo. Esta es una limitación intrínseca para las DLL de Microsoft Windows.
