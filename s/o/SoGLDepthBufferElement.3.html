NAME

SoGLDepthBufferElement — OpenGL-specific depth buffer element

SYNOPSIS

#include <Inventor/GL/elements/SoGLDepthBufferElement.h>

.

class SoGLDepthBufferElement : public SoDepthBufferElement
{
public:
  SoGLDepthBufferElement ();
  virtual ~SoGLDepthBufferElement ();

  virtual void init (void);
  virtual void pop (SoState * state, const SoElement * prevTopElement);
  virtual void setElt (SbBool test, SbBool write, DepthWriteFunction function, SbVec2f range);

protected:
  virtual ~SoGLDepthBufferElement ();
  virtual void setElt (SbBool test, SbBool write, DepthWriteFunction function, SbVec2f range);
};

Detailed Description

This element is the OpenGL-specific implementation of the SoDepthBufferElement.
