Detailed Description

This element holds the shadow culling state. It can be set to enable or disable shadow culling.

Shadow culling is used to optimize rendering of complex scenes by preventing objects that would be occluded by shadows from being rendered.

The element has a single integer value that represents the shadow culling state:

  • 0: Shadow culling is disabled.
  • 1: Shadow culling is enabled.

This element is typically used internally by the Coin rendering engine and may not need to be manipulated directly by application developers.

void SoGLShadowCullingElement::pop (SoState * state, const SoElement * prevTopElement) [virtual]

This method is called when the state is popped, and the depth of the element is bigger than the current state depth. pop() is called on the new top of stack, and a pointer to the previous top of stack is passed in prevTopElement.

Override this method if you need to copy some state information from the previous top of stack.

Reimplemented from SoElement.

void SoGLShadowCullingElement::push (SoState * state) [virtual]

This method is called when the state is pushed, and the depth of the current element is less than the state depth.

Override this method if your element needs to copy data from the previous top of stack. The push() method is called on the new element, and the previous element can be found using SoElement::getNextInStack().
