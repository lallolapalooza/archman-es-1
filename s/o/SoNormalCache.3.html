Descripción Detallada

La clase SoNormalCache se utiliza para almacenar normales cacheadas.

Como una extensión de la API original de SGI Open Inventor v2.1, también es posible generar normales utilizando esta clase.

Es más potente y fácil de usar que la clase SoNormalGenerator. Es posible generar normales por vértice con índices (utilizando mucha menos memoria que las normales por vértice simples), y contiene métodos especiales para generar normales para tiras de triángulos y cuadriláteros.
