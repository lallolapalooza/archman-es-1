Descripción detallada

La clase SoDebug es una pequeña colección de funciones relacionadas con la depuración.

Documentación de funciones miembro

const char * SoDebug::GetEnv (const char * var) [static]

Este es un envoltorio portable de getenv.

coin_getenv()

void SoDebug::RTPrintf (const char * formatstr, ...) [static]

Impresión en tiempo real diseñada para usar cuando el uso de printf() estándar causaría problemas de temporización.

NO IMPLEMENTADO. Actualmente, simplemente reenvía a printf().

void SoDebug::NamePtr (const char * name, void * ptr) [static]

Asocia un nombre con un puntero arbitrario. Puedes obtener el nombre del puntero más tarde con PtrName().

const char * SoDebug::PtrName (void * ptr) [static]

Devuelve el nombre establecido en un puntero con NamePtr(). Si no se ha establecido ningún nombre, se devuelve "<sin nombre>".
