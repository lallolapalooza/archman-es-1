Detailed Description

The SoTextureCoordinateDefault class removes texture coordinates from the state.

Shapes below this node in the scene graph will have to use its default texture coordinates as SoTextureCoordinateDefault cleans out all previously defined texture coordinates and texture coordinate functions.

Detailed Description

The SoTextureCoordinateDefault node generates default texture coordinates. This node is typically used to provide texture coordinates when the geometry itself does not contain them. The generated texture coordinates are based on the bounding box of the primitive. The exact mapping depends on the rendering system and the specific implementation. It is intended to be used as a fallback mechanism for texture coordinate generation.
