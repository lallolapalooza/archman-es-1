Descripción detallada

La clase SoInteraction se encarga de inicializar clases internas.

SoInteraction está presente con el único propósito de proporcionar una interfaz a los métodos de inicialización de las clases en Coin que están relacionadas de alguna manera con la interacción del usuario, como los draggers y manipuladores.

Es poco probable que el programador de aplicaciones necesite preocuparse por esta clase, ya que SoInteraction::init() es llamado por los métodos de inicialización específicos de la GUI.

Documentación de funciones miembro

void SoInteraction::init (void ) [estático]

Llama al método initClass() de estas clases: SoAntiSquish, SoSelection, SoExtSelection, SoSurroundScale, SoInteractionKit, SoDragger, SoClipPlaneManip, SoDirectionalLightManip, SoPointLightManip, SoSpotLightManip, SoTransformManip, SoCenterballManip, SoHandleBoxManip, SoJackManip, SoTabBoxManip, SoTrackballManip, SoTransformBoxManip, SoTransformerManip.

Tenga en cuenta que este método llama a SoDB::init() y SoNodeKit::init() para asegurarse de que todas las clases de las que depende la funcionalidad de interacción se hayan inicializado.

Los programadores de aplicaciones generalmente no deberían tener que invocar este método directamente desde el código de la aplicación, ya que se llama indirectamente desde las funciones init() de las bibliotecas de enlace GUI. Solo si está utilizando su propio enlace GUI (y no una de las bibliotecas SoQt, SoGtk, SoXt, SoWin, Sc21, etc. de Kongsberg Oil & Gas Technologies) tiene que llamar explícitamente a SoInteraction::init().

  // SoQt::init() llama a SoDB::init(), SoNodeKit::init() y
  // SoInteraction::init().
  QWidget * window = SoQt::init( argv[0] );
