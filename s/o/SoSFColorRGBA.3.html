Descripción detallada

La clase SoSFColorRGBA es un contenedor para un valor SbColor4f.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único valor de color (es decir, Rojo + Verde + Azul + Alfa).

Los campos de este tipo almacenan su valor en el archivo como un cuádruple componente "R G B A", donde cada componente de color tiene un valor entre 0.0 y 1.0.

Sets the color value of this field.

The first method sets the value from an SbColorRGBA object. The second and third methods set the value from individual red, green, blue and alpha components. The fourth method takes an array of four floating-point numbers.

The value range for each component is between 0.0 and 1.0.

The value range for H, S and V is between 0.0 and 1.0.
