Descripción detallada

La clase SoNodekitCatalog es un contenedor para diseños de nodekit.

Los nodekits almacenan toda su información jerárquica de diseño y de partes en instancias de esta clase.

Detailed Description

This class contains the definition of the nodekit catalog. The catalog defines the parts which make up a nodekit.

A nodekit is a class that is composed of other nodes. For example, an SoNodekit class might be composed of an SoSeparator, an SoCube, an SoMaterial and an SoTransform. This class is intended to be used as a base class for nodekits that have a predefined structure.

The catalog is defined in the virtual method initClass() of the nodekit class itself. The catalog is a tree-like structure. Each node in the tree is called a part. Parts are identified by an integer part number, or by a name (an SbName).

The catalog provides methods to query the structure, and to get information about the types of nodes that can be created.

It is possible to specify the type of the node which is to be created, and its default value. It is also possible to specify the type of the nodekit's children. In this case, the catalog will check that the children are of the correct type.

The catalog can be extended by deriving from the nodekit class and adding new parts in the new nodekit's initClass() method.

The catalog is immutable after it has been constructed. The initClass() method is responsible for constructing the catalog. Typically, this involves calling addEntry() for each part in the nodekit.

The catalog is a static member of the nodekit class, so it is shared among all instances of the nodekit.

The catalog is automatically generated by the SoNodeKitCatalogGen tool.

Acerca de Arch Linux

Arch Linux es una distribución Linux independiente, optimizada para i686/x86-64, que se esfuerza por ser simple, moderna, pragmática, centrada en el usuario y versátil. La simplicidad se entiende en el sentido de la simplicidad técnica y no necesariamente en la simplicidad de uso.

El objetivo principal de Arch es la simplicidad, y se logra mediante un diseño elegante y un código limpio. Arch Linux sigue el modelo de lanzamiento continuo (rolling release), lo que significa que siempre tendrás la última versión estable del software disponible.

Arch Linux proporciona un entorno base mínimo, configurado por el usuario, con la creencia de que la libertad del usuario reside en la capacidad del usuario para personalizar su sistema según sus necesidades.

Arch Linux se adhiere a la filosofía KISS (Keep It Simple, Stupid), enfocándose en la elegancia técnica y la simplicidad del código, lo que permite a los usuarios comprender y controlar su sistema.
