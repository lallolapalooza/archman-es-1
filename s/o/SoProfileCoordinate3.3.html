Descripción Detallada

La clase SoProfileCoordinate3 es un nodo que especifica un conjunto de coordenadas 3D para perfiles.

Utilice nodos de este tipo para proporcionar coordenadas a los perfiles.

El tercer elemento del vector de coordenadas se utiliza para la normalización. Un nodo de este tipo donde todos los valores de normalización son iguales a 1.0 es el equivalente a configurar un nodo SoProfileCoordinate2.

Tenga en cuenta que un nodo SoProfileCoordinate3 *reemplazará* las coordenadas de perfil ya presentes en el estado (si las hubiera).

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

ProfileCoordinate3 {
    point 0 0 1
}

Detailed Description

A 3D profile coordinate node. This node defines a profile curve using a list of 3D coordinates. It is intended to be used with nodes such as SoExtrusion.

The coordinate points are specified by the point field.

This node is primarily used to define the cross-section shape for extruded objects. The point field holds the vertices of the polygon that will form the cross-section.

When this node is traversed, it adds its primitives to the counters of the action.

Nodes influencing how geometry nodes calculate their primitive count also override this method to change the relevant state variables.
