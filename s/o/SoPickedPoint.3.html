DESCRIPCIÓN DETALLADA

La clase SoPickedPoint se utiliza para especificar puntos seleccionados.

Almacena información diversa sobre el punto seleccionado, como la posición, la normal, la coordenada de textura y el índice de material en el material actual. También puede contener información de detalle (una subclase de SoDetail) para cada nodo en la ruta seleccionada.

SoPickedPoint * SoPickedPoint::copy () const

Devuelve una copia de este punto seleccionado.

Tenga en cuenta que si la biblioteca Coin se ha compilado como una DLL en Microsoft Windows y utiliza este método desde código de aplicación, debe asegurarse de que tanto la DLL de Coin como el ejecutable de la aplicación utilicen la misma instancia de una biblioteca C Run-Time (CRT). De lo contrario, obtendrá corrupción de la memoria del montón al liberar las instancias devueltas, lo que eventualmente provocará fallos misteriosos.
