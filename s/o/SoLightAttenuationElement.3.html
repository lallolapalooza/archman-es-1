Detailed Description

This element contains the light attenuation values. The attenuation of a light source is described by three coefficients: constant, linear and quadratic attenuation. These coefficients are used to compute the light intensity at a given distance from the light source.

The attenuation is calculated using the following formula:

intensity = lightIntensity / (constantAttenuation + linearAttenuation * distance2 + quadraticAttenuation * distance2)

The attenuation coefficients are specified by the fields of the SoLight node.
