DESCRIPTION

This action converts a scene graph into the Encapsulated PostScript (EPS) file format.

The action traverses the scene graph and generates PostScript code for each node. This action is intended primarily for generating hardcopy output from Coin applications.

The PostScript output is generated using the SoPSVectorOutput class. See its man page for details on the PostScript language primitives used.

The generated PostScript code is intended to conform to the Encapsulated PostScript (EPS) file format standard. However, whether the output actually conforms depends heavily on the specific PostScript interpreter that will render the file.

Note that the PostScript language does not support all features of OpenGL or the Open Inventor scene graph. In particular, features like Gouraud shading, transparency and complex text rendering are problematic. This action attempts to emulate these features using PostScript primitives, but the results may not always be visually identical to the OpenGL rendering.

setGouraudThreshold (const double eps)

Sets the Gouraud shading threshold. A threshold of 0.0 will disable Gouraud shading. A smaller value will yield more accurate Gouraud shading. Default is 0.1.

Since the PostScript language has no support for Gouraud shaded triangles, each triangle will be split into subtriangles approximately of size eps PostScript units. One PostScript unit is approximately 1/72 inch.
