Descripción Detallada

La clase SoTriangleStripSet se utiliza para renderizar y controlar tiras de triángulos no indexadas.

Las tiras de triángulos se especifican utilizando el campo numVertices.

Las coordenadas, normales, materiales y coordenadas de textura se obtienen en orden del estado actual o del nodo vertexProperty si está establecido. (Para renderizar tiras de triángulos a partir de índices de vértices, use el nodo SoIndexedTriangleStripSet.)

El campo numVertices puede usarse para múltiples tiras; las coordenadas se obtendrán con un índice monótonamente creciente de las coordenadas en la pila de estado de recorrido (es decir, típicamente del último nodo SoCoordinate3 encontrado durante el recorrido).

Por ejemplo, si numVertices se establece en [3, 4, 5, 3], este nodo especificaría un triángulo a partir de las coordenadas 0, 1 y 2, una tira de triángulos a partir de las coordenadas 3, 4, 5 y 6, una tira de triángulos a partir de las coordenadas 7, 8, 9, 10 y 11, y finalmente un triángulo a partir de las coordenadas 12, 13, 14.

O dicho de otra manera: en una tira de triángulos siempre habrá dos vértices más que triángulos. Tenga en cuenta que está manejando datos a nivel de vértice (no a nivel de polígono), y que los triángulos se distribuyen de esta manera, dados 5 vértices:

1-----3-----5
 \   / \   /
  \ /   \ /
   2-----4

La figura anterior en formato de archivo de grafo de escena:

#Inventor V2.1 ascii
Separator {
  Coordinate3 {
    point [ -2 1 0, -1 -1 0, 0 1 0, 1 -1 0, 2 1 0 ]
  }
  TriangleStripSet {
    numVertices [ 5 ]
  }
}

El grafo de escena anterior en un visor:

Las tiras se convierten en triángulos de la misma manera que OpenGL, por supuesto, por lo que para obtener detalles sobre los detalles sucios, consulte la documentación del tipo de renderizado de primitivas GL_TRIANGLE_STRIP de OpenGL.

Se pueden establecer las uniones PER_PART (por tira), PER_VERTEX, PER_FACE u OVERALL para materiales y normales. La unión de material predeterminada es OVERALL. La unión de normales predeterminada es PER_VERTEX.

FORMATO DE ARCHIVO/PREDETERMINADOS:

TriangleStripSet {
    vertexProperty NULL
    startIndex 0
    numVertices -1
}

Descripción Detallada

Este nodo crea un conjunto de triángulos unidos en bandas. Las bandas de triángulos son más eficientes que los conjuntos de triángulos individuales, ya que cada triángulo de una banda, excepto el primero, comparte dos vértices con el triángulo anterior.

Los datos de vértices se especifican como una lista de vértices 3D (SbVec3f). Los índices de los triángulos se especifican como una lista de enteros, donde cada entero indica el índice del primer vértice de una nueva banda de triángulos. El número de vértices en cada banda está implícito por el número de vértices restantes en la lista de vértices.
