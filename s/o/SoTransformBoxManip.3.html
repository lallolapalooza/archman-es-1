Detailed Description

The SoTransformBoxManip wraps an SoTransformBoxDragger for convenience.

The manipulator class takes care of wrapping up the SoTransformBoxDragger in a simple and convenient API for the application programmer, making it automatically surround the geometry it influences and taking care of the book-keeping routines for its interaction with the relevant fields of an SoTransformation node.

Here's a simple usage example, in the form of an Inventor format file:

#Inventor V2.1 ascii
Separator {
   TransformBoxManip { }
   Group {
      Cone { }
   }
}
Translation { translation 2 4 0 }
Separator {
   TransformBoxManip { }
   Group {
      Sphere { }
   }
}

Detailed Description

This class implements the standard box manipulator. It is a convenient way to interactively rotate, translate, and scale the objects in a scene graph.

It is derived from SoTransformManip, which provides the basic functionality for interactive manipulation of transformations. The box manipulator adds a visual representation of a bounding box around the manipulated object, with handles for rotation, translation, and scaling.

By default, the SoTransformBoxManip manipulates a SoTransform node. However, this can be changed by using the setTranslator method inherited from SoTransformManip.

The manipulator can be added to a scene graph like any other SoNode. When the user interacts with the manipulator (e.g., by clicking and dragging on the handles), the underlying transformation node is updated accordingly.
