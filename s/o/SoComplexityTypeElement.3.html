NAME

SoComplexityTypeElement — node element for setting and retrieving the complexity type

SYNOPSIS

#include <Inventor/elements/SoComplexityTypeElement.h>

Inherits from SoNode.

Inherited by SoCoordinateDetailElement, SoLineStippleElement, SoMaterialElement, SoNurbsCurveElement, SoNurbsSurfaceElement, SoPointDetailElement, SoVertexAttributeElement.

Available since Coin 2.5.

Detailed Description

This class is an abstract base class for node elements that are used to control the complexity of the rendered scene. It is used internally by Coin to manage the complexity of different aspects of the scene graph.

The complexity type determines how detail is reduced for rendering. For example, a highly complex model might be simplified when viewed from a distance. The specific methods for controlling complexity are defined in derived classes.
