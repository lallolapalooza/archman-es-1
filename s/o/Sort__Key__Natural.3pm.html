NOMBRE

Sort::Key::Natural - ordenación natural rápida

SINOPSIS

use Sort::Key::Natural qw(natsort);
my @data = qw(foo1 foo23 foo6 bar12 bar1
              foo bar2 bar-45 foomatic b-a-r-45);
my @sorted = natsort @data;
print "@sorted\n";
# imprime:
#   b-a-r-45 bar1 bar2 bar12 bar-45 foo foo1 foo6 foo23 foomatic
use Sort::Key::Natural qw(natkeysort);
my @objects = (...);
my @sorted = natkeysort { $_->get_id } @objects;

DESCRIPCIÓN

Este módulo extiende la familia de módulos Sort::Key para soportar ordenación natural.

Bajo la ordenación natural, las cadenas se dividen en límites de palabras y números, y las subcadenas resultantes se comparan de la siguiente manera:

  • las subcadenas numéricas se comparan numéricamente
  • las subcadenas alfabéticas se comparan léxicamente
  • las subcadenas numéricas siempre preceden a las subcadenas alfabéticas

Espacios, símbolos y caracteres no imprimibles solo se consideran para dividir la cadena en sus partes, pero no para la ordenación. Por ejemplo "foo-bar-42" se divide en tres subcadenas "foo", "bar" y 42 y después de eso los guiones se ignoran.

Tenga en cuenta que la ordenación distingue entre mayúsculas y minúsculas. Para hacer una ordenación insensible a mayúsculas/minúsculas, debe convertir las claves explícitamente:

my @sorted = natkeysort { lc $_ } @data

Además, una vez que este módulo se carga, el nuevo tipo "natural" (o "nat") estará disponible desde Sort::Key::Maker. Por ejemplo:

use Sort::Key::Natural;
use Sort::Key::Maker i_rnat_keysort => qw(integer -natural);

crea un clasificador multiclave "i_rnat_keysort" que acepta dos claves, la primera para ser comparada como un entero y la segunda en orden natural descendente.

También existe un conjunto alternativo de funciones de ordenación natural que reconocen números de punto flotante. Utilizan el tipo de clave "natwf" (abreviatura de "natural_with_floats").

FUNCIONES

Las funciones que se pueden importar de este módulo son:

natsort @data
devuelve los elementos de @data ordenados en orden natural.
rnatsort @data
devuelve los elementos de @data ordenados en orden natural descendente.
natkeysort { CALC_KEY($_) } @data
devuelve los elementos de @array ordenados naturalmente por las claves resultantes de aplicarles "CALC_KEY".
rnatkeysort { CALC_KEY($_) } @data
es similar a "natkeysort" pero ordena los elementos en orden descendente.
natsort_inplace @data
rnatsort_inplace @data
natkeysort_inplace { CALC_KEY($_) } @data
rnatkeysort_inplace { CALC_KEY($_) } @data
estas funciones son similares respectivamente a "natsort", "rnatsort", "natsortkey" y "rnatsortkey", pero ordenan el array @data in situ (en el lugar).
$key = mkkey_natural $string
dado $string, devuelve una clave que puede ser comparada léxicamente con otra clave obtenida de la misma manera, resultando en el mismo orden que al comparar las cadenas anteriores en orden natural.

Si el argumento $key no se proporciona, por defecto es $_.

natwfsort @data
rnatwfsort @data
natwfkeysort { CALC_KEY($_) } @data
rnatwfkeysort { CALC_KEY($_) } @data
natwfsort_inplace @data
rnatwfsort_inplace @data
natwfkeysort_inplace { CALC_KEY($_) } @data
rnatwfkeysort_inplace { CALC_KEY($_) } @data
este conjunto de funciones, de nombre poco elegante, funciona de la misma manera que su contraparte s/natwf/nat/ con la diferencia de que tienen en cuenta los números de punto flotante incrustados dentro de las cadenas.

En este contexto, un número de punto flotante es una cadena que coincide con la expresión regular "/[+\-]?\d+(\.\d*)?/". Tenga en cuenta que los números con parte exponencial (es decir, 1.12E-12) no se reconocen como tales.

Tenga en cuenta también que los números sin parte entera (es decir, .2 o -.12) tampoco son compatibles.

VER TAMBIÉN

Sort::Key, Sort::Key::Maker.

Otro módulo que proporciona funcionalidad similar es Sort::Naturally.
