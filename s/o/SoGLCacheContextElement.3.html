int SoGLCacheContextElement::get (SoState * state) [static]

Devuelve el ID del contexto.

Tenga en cuenta que la firma de esta función es ligeramente incorrecta: la función debería devolver realmente un uint32_t, como hace SoGLRenderAction::getCacheContext(). Se mantiene así por motivos de compatibilidad.

El valor devuelto siempre será un entero positivo.

int SoGLCacheContextElement::getExtID (const char * str) [static]

Devuelve un ID de extensión basado en la cadena de extensión de GL. El ID de extensión se puede usar para probar rápidamente la disponibilidad de una extensión más tarde, usando extSupported().

void SoGLCacheContextElement::getOpenGLVersion (SoState * state, int & major, int & minor) [static]

SbBool SoGLCacheContextElement::extSupported (SoState * state, int extid) [static]

Devuelve TRUE si la extensión es compatible con el contexto actual. extid debe ser un ID devuelto por getExtId(). El resultado de la prueba se almacena en caché, por lo que este método es bastante rápido y se puede usar en tiempo de ejecución.

uint32_t SoGLCacheContextElement::getUniqueCacheContext (void ) [static]

Devuelve un ID de contexto de caché único, en el rango [1, ->.

Si renderiza el mismo grafo de escena en dos o diferentes contextos de caché, y no está utilizando listas de visualización ni objetos de textura compartidos entre contextos, el ID del contexto de caché debe ser único para que la renderización funcione.

Esta función es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

void SoGLCacheContextElement::scheduleDeleteCallback (const uint32_t contextid, SoScheduleDeleteCB * cb, void * closure) [static]

Se puede utilizar para recibir una devolución de llamada la próxima vez que Coin sepa que el contexto (especificado por contextid) es el contexto OpenGL actual.

Esta función se puede utilizar para liberar recursos OpenGL para un contexto.

Tenga en cuenta que la devolución de llamada se invocará solo una vez y luego se eliminará de la lista interna de devoluciones de llamada programadas.
