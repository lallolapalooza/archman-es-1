Descripción detallada

La clase SoSFEnum es un contenedor para un valor enumerado.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un valor particular de un conjunto enumerado.

Un campo de este tipo almacena su valor en el archivo como el nombre simbólico, en lugar del valor entero real.

Las instancias de SoSFEnum se inicializan a nivel de instancia, generalmente en el constructor del contenedor de campos con las macros SO_NODE_DEFINE_ENUM_VALUE(enumtype, symbolvalue) y SO_NODE_SET_SF_ENUM_TYPE(enumfield, enumtype) para nodos, o para motores; SO_ENGINE_DEFINE_ENUM_VALUE() y SO_ENGINE_SET_SF_ENUM_TYPE().

Ejemplo de inicialización del constructor de la clase SoCone:

SO_NODE_DEFINE_ENUM_VALUE(Part, SIDES);
SO_NODE_DEFINE_ENUM_VALUE(Part, BOTTOM);
SO_NODE_DEFINE_ENUM_VALUE(Part, ALL);
SO_NODE_SET_SF_ENUM_TYPE(parts, Part);

Detailed Description

A single-valued enumeration field. This field holds an integer value which is mapped to a string name. When the field is written, the string name is converted to the integer value. When read, the integer value is converted to the string name.

The available enumeration mappings can be set using the setEnums() method. If setEnums() is not called, the field will only accept integer values.

The SoSFEnum field can be set using an integer value directly or using a string name.

myEnumField = 10; // Set by integer value
myEnumField = "ON"; // Set by string name

The SoSFEnum field can be read as an integer value or as a string name.

int val = myEnumField; // Read as integer value
SbName name = myEnumField; // Read as string name
