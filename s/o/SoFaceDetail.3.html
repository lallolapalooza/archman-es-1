Descripción Detallada

La clase SoFaceDetail se usa para almacenar información detallada de polígonos.

Las instancias de esta clase se usan, entre otras cosas, para almacenar información sobre polígonos después de operaciones de selección (pick), y para almacenar información devuelta a las devoluciones de llamada de teselación.

Tenga en cuenta que una instancia de SoFaceDetail consta de un conjunto de instancias de SoPointDetail, una por cada vértice del polígono que representa.

Description

This class is a part of the Coin3D library. It is used to store information about a face intersection during ray tracing or picking.

The SoFaceDetail class provides a way to access details about the face that was intersected.
