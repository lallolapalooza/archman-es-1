Descripción detallada

La clase SoEngineOutput son las ranuras de salida en las instancias de SoEngine.

SoEngineOutput tiene métodos para el manejo conveniente de las conexiones realizadas desde objetos SoEngine a objetos SoField.

DESCRIPCIÓN DETALLADA

Una SoEngineOutput es la salida de un motor. Para un motor, se puede pensar en esto como un campo de solo escritura, pero el sistema de notificación de Coin está diseñado para que pueda conectarse a esto desde otros campos.

Los campos conectados a una SoEngineOutput se notifican que el valor de la salida ha cambiado (lo que significa que el motor ha sido evaluado).

Note que este método no es parte de la API original de Open Inventor.

void SoEngineOutput::touchSlaves (SoNotList * nl, SbBool donotify)

Notifica a los campos adjuntos a esta salida del motor que el valor de la salida ha cambiado.

Si donotify es TRUE, propaga la notificación a los campos. De lo contrario, simplemente marca los campos como "sucios" para re-evaluación.

Tenga en cuenta que este método no es parte de la API original de Open Inventor.

SoFieldContainer * SoEngineOutput::getFieldContainer (void )

Método de conveniencia que devuelve un contenedor de campos. Este método se puede usar tanto para las salidas de NodeEngine como de Engine.

Esta función es una extensión para Coin y no está disponible en la API original de Open Inventor v2.1 de SGI.
