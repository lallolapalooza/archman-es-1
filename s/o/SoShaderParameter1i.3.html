Instalación en Arch Linux

Este proyecto se puede instalar fácilmente en Arch Linux utilizando el gestor de paquetes AUR (Arch User Repository).

Usando yay

Si tienes instalado yay (un popular ayudante de AUR), puedes instalar el paquete de la siguiente manera: 

yay -S nombre-del-paquete

Reemplaza nombre-del-paquete con el nombre real del paquete en AUR. Puedes buscarlo en el sitio web de AUR.

Instalación manual desde AUR

Si prefieres instalarlo manualmente, puedes seguir estos pasos:

  1. Navega al sitio web de AUR y busca el paquete.
  2. Descarga el archivo PKGBUILD y los archivos asociados (si los hay).
  3. Abre una terminal y navega hasta el directorio donde descargaste los archivos.
  4. Construye e instala el paquete usando makepkg: 
    makepkg -si

Nota: Asegúrate de revisar el contenido del PKGBUILD antes de ejecutar makepkg, especialmente si no estás familiarizado con el paquete o la fuente.

Esta guía cubre la instalación de un paquete en Arch Linux.
