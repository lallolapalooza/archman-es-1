SoScrollingGraphKit

A 2D graph with scrolling capabilities for Coin.

This class is part of the Coin 3D library, a widely used 3D graphics API.

The SoScrollingGraphKit class provides a 2D graph that allows users to scroll through its content. This is particularly useful for visualizing large datasets or graphs that exceed the visible area.
