Descripción Detallada

El SoListenerOrientationElement almacena la orientación del oyente actual.

Esta orientación es establecida por los nodos SoListener y los nodos SoCamera durante la renderización de audio. Cuando un SoListener es visitado por SoAudioRenderAction, añadirá un nuevo SoListenerOrientationElement al estado, conteniendo su orientación y con el flag setbylistener activado. Cuando un SoCamera es visitado por SoAudioRenderAction, añadirá un nuevo SoListenerOrientationElement solo si no hay elementos previos con el flag setbylistener activado.

El SoListenerOrientationElement se usa cuando los nodos SoVRMLSound se renderizan a sí mismos.

Ten en cuenta que esta clase es una extensión para Coin, y no está disponible en la API original de SGI Open Inventor v2.1.

Detailed Description

This element stores the current listener orientation. The listener is the virtual point in 3D space from which the listener's perspective is determined (e.g. in audio applications).

The orientation can be set by the user by adding a SoListener node to the scene graph, or it can be set by a SoCamera node (which inverts the camera's orientation).

This element is an instance of SoReplacedElement, which means that it is used to store a per-traversal state which can be replaced by nodes in the scene graph.
