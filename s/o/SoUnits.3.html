Descripción Detallada

La clase SoUnits es un nodo para establecer tipos de unidades.

Aunque Coin no se preocupa por las unidades que usas en tu grafo de escena *per se*, hay una ventaja en usar nodos SoUnits: tienes una forma de dividir tu grafo de escena en diferentes partes "conceptuales".

Al encontrar nodos SoUnit, los métodos de acción de recorrido se aseguran de que la geometría siguiente se escale en consecuencia.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

Units {
    units METERS
}

NAME

SoUnits - unit definition node

SYNOPSIS

#include <Inventor/nodes/SoUnits.h>

Inherits SoNode.

All members of this class:

SoUnits, ~SoUnits, GLRender, getPrimitiveCount, pick, units

Detailed Description

The <b>SoUnits</b> node defines the units which will be used for subsequent nodes in the traversal.

It affects distance, length, and coordinate values in any subsequent nodes that honor the unit setting. The default unit setting is <b>SoUnits::METERS</b>.

There are a total of 13 supported units defined in the <b>SoUnits::UnitEnum</b> enumeration. The supported units are:

  • SoUnits::INCHES
  • SoUnits::FEET
  • SoUnits::YARDS
  • SoUnits::MILES
  • SoUnits::MILLIMETERS
  • SoUnits::CENTIMETERS
  • SoUnits::METERS
  • SoUnits::KILOMETERS
  • SoUnits::NAUTICAL_MILES
  • SoUnits::ASTRONOMICAL_UNITS
  • SoUnits::LIGHT_YEARS
  • SoUnits::PARSECS
  • SoUnits::UNITS_FROM_METERS (default)
