Descripción detallada

La clase SoGLPointSizeElement cambia la configuración del tamaño del punto del estado de renderizado de OpenGL.

Las solicitudes del grafo de escena para cambiar el tamaño del punto al renderizar primitivas de punto se realizarán a través de este elemento, que las reenvía a la llamada nativa de OpenGL apropiada.

La biblioteca Coin no impone límites a los valores del tamaño del punto, pero tenga en cuenta que el rango y la granularidad de los tamaños de punto válidos dependen de la implementación subyacente de OpenGL. Los programadores de aplicaciones que utilizan primitivas de punto (típicamente a través del nodo SoPointSet) deben considerar estos valores límite. Se pueden adquirir ejecutando el siguiente código dentro de un contexto OpenGL válido:

GLfloat bounds[2];
glGetFloatv(GL_POINT_SIZE_RANGE, bounds);
GLfloat granularity[1];
glGetFloatv(GL_POINT_SIZE_GRANULARITY, granularity);

Otra forma, quizás más conveniente, de adquirir los límites de la implementación de OpenGL con respecto a los tamaños de punto es utilizar el método So@Gui@GLWidget::getPointSizeLimits() en la biblioteca de interfaz de "pegamento" GUI que esté utilizando (SoQt, SoXt, SoGtk, SoWin, ...).

NAME

SoGLPointSizeElement — GL-specific point size element

SYNOPSIS

#include <Inventor/GLES2/elements/SoGLES2PointSizeElement.h>
                    
class SoGLPointSizeElement : public SoFloatElement { ... };

DESCRIPTION

This element is used by Coin to keep track of the current point size when rendering with OpenGL. It is inherited from SoFloatElement.

Initializes the element to its default value. The default value for point size is 0.0.

void SoGLPointSizeElement::push (SoState * state) [virtual]

This method is called every time a new element is required in one of the stacks. This happens when a writable element is requested, using SoState::getElement() or indirectly SoElement::getElement(), and the depth of the current element is less than the state depth.

Override this method if your element needs to copy data from the previous top of stack. The push() method is called on the new element, and the previous element can be found using SoElement::getNextInStack().

Reimplemented from SoElement.

void SoGLPointSizeElement::pop (SoState * state, const SoElement * prevTopElement) [virtual]

This method is called when the state is popped, and the depth of the element is bigger than the current state depth. pop() is called on the new top of stack, and a pointer to the previous top of stack is passed in prevTopElement.

Override this method if you need to copy some state information from the previous top of stack.

Reimplemented from SoElement.
