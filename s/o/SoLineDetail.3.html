Descripción detallada

La clase SoLineDetail se utiliza para almacenar información detallada de líneas 3D.

Las instancias de esta clase se utilizan, entre otras cosas, para almacenar información sobre líneas después de operaciones de selección (pick), y para almacenar información devuelta a las devoluciones de llamada de teselación.
