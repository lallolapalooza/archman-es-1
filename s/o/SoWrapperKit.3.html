Detailed Description

A SoWrapperKit is an SoSeparatorKit that is designed to be used as a wrapper for other nodes. It's typically used to create a group of nodes that are associated with a particular piece of the scene graph, and which can be easily manipulated as a unit. For example, you might use a SoWrapperKit to group a SoMaterial and a SoTexture2 node, and then use the SoWrapperKit to apply those material and texture settings to a group of other nodes.

The main difference between SoWrapperKit and SoSeparatorKit is that SoWrapperKit provides a default set of fields that are designed to be used for wrapping other nodes. These fields include value, which can be used to store any type of SoNode, and children, which can be used to store a list of SoNodes.

By default, SoWrapperKit will create an SoSeparator node as its children. This means that any nodes that are added to the SoWrapperKit will be added as children of the SoSeparator. This is useful for ensuring that the nodes are properly managed and that their state is preserved.
