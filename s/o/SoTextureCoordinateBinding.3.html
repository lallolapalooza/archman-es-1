Detailed Description

The SoTextureCoordinateBinding class says how texture coordinates should be bound to shapes.

SoTextureCoordinateBinding binds current coordinates to subsequent shapes by using either per vertex or per indexed vertex binding.

FILE FORMAT/DEFAULTS:

TextureCoordinateBinding {
    value PER_VERTEX_INDEXED
}

Member Enumeration Documentation

enum SoTextureCoordinateBinding::Binding

The binding types available for the SoTextureCoordinateBinding::value field.

Enumerator

PER_VERTEX
Get a new texture coordinate from the pool of texture coordinates for each vertex of the shape.

Detailed Description

This node defines how texture coordinates are applied to subsequent shape primitives in the scene graph.

The value field can be set to one of the following enumerated constants:

SoTextureCoordinateBinding::BindingType

PER_VERTEX_INDEXED
Texture coordinates are specified individually for each vertex of each primitive. This is the default.
PER_FACE
Texture coordinates are specified for each face (primitive) of a shape node. All vertices of a face share the same texture coordinates.
PER_OBJECT
Texture coordinates are specified for the entire shape node. All faces and vertices within the shape node share the same texture coordinates.
PER_PART
Texture coordinates are specified for each part of a shape node. This is relevant for nodes like SoCADModel. All vertices and faces within a part share the same texture coordinates.
PER_NODE
Texture coordinates are specified for the entire node. This is equivalent to PER_OBJECT, but semantically distinct for future extensions.
