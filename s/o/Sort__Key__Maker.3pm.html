NOMBRE

Sort::Key::Maker - creador de ordenadores multillave

SINOPSIS

# crear una función que ordena cadenas por longitud:
use Sort::Key::Maker sort_by_length => sub { length $_},  qw(integer);
# crear una función de ordenación multillave;
# la primera clave es un entero ordenado en orden descendente,
# la segunda clave es una cadena en orden predeterminado (ascendente):
use Sort::Key::Maker ri_s_keysort => qw(-integer string);
# algunos datos de ejemplo...
my @foo = qw(foo bar t too tood mama);
# y ahora, usa las funciones de ordenación creadas previamente:
# obtener los valores de @foo ordenados por longitud:
my @sorted = sort_by_length @foo;
# ordenar @foo in situ por su longitud y luego por su valor:
ri_s_keysort_inplace { length $_, $_ } @foo;

DESCRIPCIÓN

Sort::Key::Maker es un módulo pragmático que proporciona una interfaz fácil de usar para la funcionalidad de ordenación multillave de Sort::Key.

Crea funciones de ordenación multillave sobre la marcha para cualquier combinación de tipos de clave y las exporta al paquete llamador.

Los tipos de clave aceptados nativamente son:

string, str, locale, loc, integer, int,
unsigned_integer, uint, number, num

y se puede añadir soporte para otros tipos a través de Sort::Key::Register (o también a través de Sort::Key::register_type()).

USO

use Sort::Key::Maker foo_sort => @keys;
exporta dos subrutinas al paquete llamador: "foo_sort (&@)" y "foo_sort_inplace (&\@)".

Estas dos subrutinas requieren una referencia a una subrutina como primer argumento y luego, respectivamente, la lista a ordenar o un array.

Por ejemplo:

use Sort::Key::Maker bar_sort => qw(int int str);
@bar=qw(doo tomo 45s tio);
@sorted = bar_sort { unpack "CCs", $_ } @bar;
# o ordenar @bar in situ
bar_sort_inplace { unpack "CCs", $_ } @bar;
use Sort::Key::Maker foo_sort => \&genmultikey, @keys;
cuando el primer argumento después del nombre del ordenador es una referencia a una subrutina, se utiliza como función de extracción de multillave. Las funciones de ordenación generadas no requieren ni aceptan una, es decir: 
use Sort::Key::Maker sort_by_length => sub { length $_ }, 'int';
my @sorted = sort_by_length qw(foo goo h mama picasso);

VER TAMBIÉN

Sort::Key, Sort::Key::Register.

Sort::Maker, también disponible en CPAN, proporciona una funcionalidad similar.
