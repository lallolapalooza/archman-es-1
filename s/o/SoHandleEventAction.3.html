Descripción detallada

La clase SoHandleEventAction distribuye eventos de usuario al grafo de escena.

Esta es la acción utilizada por las clases del visor GUI para pasar eventos de interacción desde el sistema de ventanas a los nodos del grafo de escena.

SoHandleEventAction también proporciona la funcionalidad para rastrear el objeto actualmente bajo el cursor y funcionalidad para "capturar" el foco del evento.

Uso avanzado:

También puedes obtener la región de viewport accediendo a ella a través de su elemento en el estado de recorrido. Lo haces de la siguiente manera:

#include <Inventor/elements/SoViewportRegionElement.h>
  SoState * state = action->getState();
  SbViewportRegion vp = SoViewportRegionElement::get(state);

La razón para explicar esto es que puedes usar esta técnica genérica cuando necesitas acceder a información de estado cuando no puedes encontrar la función de acceso que necesitas en la implementación de la acción. Puedes usarla, por ejemplo, para recuperar la información del volumen de vista, para la cual no hay métodos de acceso:

#include <Inventor/elements/SoViewVolumeElement.h>
  SoState * state = action->getState();
  SbViewVolume vv = SoViewVolumeElement::get(state);

Cuando haces esto en instancias de acción arbitrarias, debes asegurarte de que el elemento dado esté habilitado para la acción antes de intentar usarlo. Las funciones relevantes para esto son SoState::isElementEnabled() y SoElement::getClassStackIndex().

void SoHandleEventAction::setHandled (void )

Marca la instancia de acción como manejada, terminando así la acción.

La acción solo se marca como manejada cuando un nodo en el grafo "agarra" el evento que esta acción está llevando, por lo que el indicador manejado será FALSE después del recorrido si ningún nodo quiso el evento.

Establece un puntero de nodo que recibirá todos los futuros eventos manejados por esta acción hasta que se llame a releaseGrabber().

void SoHandleEventAction::beginTraversal (SoNode * node) [protected], [virtual]

Este método virtual es llamado desde SoAction::apply(), y es el punto de entrada para el recorrido real del grafo de escena.

Puede ser sobrescrito para inicializar la acción al inicio del recorrido, para inicializaciones específicas en las subclases de acción que heredan de SoAction.

El método predeterminado simplemente llama a traverse(), lo cual cualquier implementación sobrescrita del método debe hacer también (o llamar a SoAction::beginTraversal()) para activar el recorrido del grafo de escena.
