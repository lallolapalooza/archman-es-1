SoGLShapeHintsElement - OpenGL shape hints element

Detailed Description

This element is used for storing shape hint information such as vertex ordering, shape type and face type.

It overrides the base class methods to push/pop the stored information onto/from the OpenGL state stack.

Constructor & Destructor Documentation

The class has no specific constructor or destructor documentation apart from what is inherited from the base class.
