Descripción Detallada

La clase SoTransformManip se utiliza para manipular transformaciones.

Un manipulador se utiliza reemplazando el nodo que deseas editar en el gráfico con el manipulador. Los "draggers" se utilizan para manipular el nodo. Cuando la manipulación finaliza, el nodo se vuelve a colocar en el gráfico, reemplazando al manipulador.

La clase SoTransformManip es una clase abstracta que no debe usarse directamente; utiliza una de sus subclases.

Detailed Description

This is the abstract base class for all transform manipulators. Transform manipulators are used to interactively modify the transformation applied to an object in 3D space.

The class provides basic functionality for managing the transformation fields (translation, rotation, scale, center, scale orientation) and for attaching/detaching sensors to these fields.

Subclasses of SoTransformManip implement the specific interaction logic for different types of transformations. For example, SoRotateSphereManip allows the user to rotate an object around its center, while SoTranslateBoxManip allows translation along the coordinate axes.
