NAME

SoVRMLOrientationInterpolator — interpolates a rotation value over time

SYNOPSIS

#include <Inventor/VRMLnodes/SoVRMLOrientationInterpolator.h>

CLASS SoVRMLOrientationInterpolator : public SoVRMLInterpolator {
  public:
    enum {
      INFO_FIELD_NUM = SoVRMLInterpolator::INFO_FIELD_NUM,
      KEY_VALUE_FIELD_NUM = INFO_FIELD_NUM + 1,
      VALUE_CHANGED_EVENT_NUM = SoVRMLInterpolator::VALUE_CHANGED_EVENT_NUM,
      NUM_FIELDS = SoVRMLInterpolator::NUM_FIELDS
    };
    static void          initClass();
    
    SoVRMLOrientationInterpolator();
    
    SoMFRotation keyValue;
    SoEngineOutput value_changed;
  protected:
    virtual ~SoVRMLOrientationInterpolator();
  private:
    virtual void         outputSlot(const SoEngineOutputSlot &);
    virtual void         touch_();
};

Detailed Description

This interpolator is used to interpolate a rotation value over time.

It takes a list of key-value pairs, where the key is a time value and the value is a rotation. The interpolator will then output a rotation value based on the current time.

The interpolator supports linear interpolation between key frames.

The interpolator outputs events of type SoSFFloat to the value_changed eventOut.

The following example shows how to use the SoVRMLOrientationInterpolator to animate a rotation:

    SoVRMLOrientationInterpolator {
      key [ 0.0, 1.0, 2.0, 3.0 ]
      keyValue [ rotation(0 1 0 0), rotation(0 1 0 1.57),
                 rotation(0 1 0 3.14), rotation(0 1 0 0) ]
    }
