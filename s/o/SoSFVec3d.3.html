Descripción detallada

La clase SoSFVec3d es un contenedor para un vector SbVec3d.

Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar un solo vector con tres elementos.

Ver también

SbVec3d, SoMFVec3d
