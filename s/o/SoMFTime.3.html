La clase SoMFTime es un contenedor para valores SbTime.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesiten almacenar múltiples representaciones de tiempo.

Detailed Description

This field holds an array of SbTime values.

The array is accessed using the standard SoMField interface methods (e.g. getNum(), getValues(), setValues(), etc.).

This field is an array of SbTime values.

The default constructor creates an empty field.

The constructor with an integer argument creates a field with the specified number of elements, each initialized to zero (i.e. the epoch).

The constructor with an array argument creates a field containing a copy of the given array's elements. The array must be NULL terminated. (e.g. a final NULL pointer is added at the end of the array).

The copy constructor creates a field containing a copy of the given field's elements.

The destructor releases the memory allocated for the field's elements.

The copyFrom() method copies the contents of the given field into this one. The fields must be of the same type.

The isSame() method checks if the given field has the same type and contents as this one.

The deleteAllValues() method deletes all values in the field. This is only called internally by the Coin library.

The copyValue() method is used for moving values around internally within a multivalue field. It needs to be overridden in each field so it automatically takes care of running copy constructors where necessary.

The getValues() method returns a pointer to the array of values. The given `start` index indicates the first value to be returned. The returned pointer is only valid as long as the field is not modified.

The initClass() method is used to initialize the class type information for this field type. It is called automatically by the Coin library during initialization.

The getClassTypeId() method returns the SoType object associated with this class. This is used internally by Coin for type identification.

The getTypeId() method returns the SoType object for this specific instance. This is used for runtime type checking.
