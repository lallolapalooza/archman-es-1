enum {
  UNREFERENCED_OUTPUT_MASK = 0x1
}

This method is intended for internal use by the Coin library.

It is called by SoNode::write() to write out the engine's output fields to the given output stream. The stream must be opened for writing.

The default implementation writes out the types of the engine's output fields. Subclasses may override this method to add custom output information or to control how the output fields are written.

The flags argument can be used to control the writing process. The only flag defined currently is UNREFERENCED_OUTPUT_MASK, which, if set, indicates that the output fields should be written even if they are not currently connected to any other engine or node. This is typically used when writing out engines that are part of a scene graph template or other complex structures where some outputs might not be immediately connected.

See also SoEngine::write().

SbBool SoEngine::readInstance (SoInput * in, unsigned short flags) [protected], [virtual]

This method is mainly intended for internal use during file import operations.

It reads a definition of an instance from the input stream in. The input stream state points to the start of a serialized / persistent representation of an instance of this class type.

TRUE or FALSE is returned, depending on if the instantiation and configuration of the new object of this class type went OK or not. The import process should be robust and handle corrupted input streams by returning FALSE.

flags is used internally during binary import when reading user extension nodes, group nodes or engines.

Reimplemented from SoFieldContainer.
