Descripción detallada

La clase SoSFBox2i32 es un contenedor para un vector SbBox2i32.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar una caja.

Ten en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.
Desde

Coin 2.5
