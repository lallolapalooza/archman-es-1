Descripción Detallada

La clase SoSFVec4f contiene un vector SbVec4f.

Este campo se utiliza donde los nodos, engines u otros contenedores de campo necesitan almacenar un vector con cuatro elementos.

Ver también

SbVec4f, SoMFVec4f
