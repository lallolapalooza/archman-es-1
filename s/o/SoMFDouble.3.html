Descripción detallada

La clase SoMFDouble es un contenedor para valores de punto flotante de doble precisión.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un grupo de múltiples valores de punto flotante.

Este campo admite el intercambio de datos de la aplicación a través del método setValuesPointer(). Consulte la documentación de SoMField para obtener información sobre cómo usar esta función.
