Descripción Detallada

La clase SoType es la base del sistema de tipos en tiempo de ejecución de Coin.

Muchas de las clases en la biblioteca Coin deben tener su información de tipo registrada antes de que se creen instancias (incluyendo, pero no limitándose a: motores, nodos, campos, acciones, kits de nodos y manipuladores). El uso de SoType para almacenar esta información proporciona una gran variedad de funcionalidades para trabajar con jerarquías de clases, comparar tipos de clases, instanciar objetos a partir de nombres de clases, etc.

Es posible, por ejemplo, hacer cosas como:

void cleanLens(SoNode * anode)
{
  assert(anode->getTypeId().isDerivedFrom(SoCamera::getClassTypeId()));
  if (anode->getTypeId() == SoPerspectiveCamera::getClassTypeId()) {
    // hacer algo..
  }
  else if (anode->getTypeId() == SoOrthographicCamera::getClassTypeId()) {
    // hacer algo..
  }
  else {
    SoDebugError::postWarning("cleanLens", "Unknown camera type %s!\n",
                              anode->getTypeId().getName());
  }
}

Una característica notable de la clase SoType es que solo tiene 16 bits de longitud y, por lo tanto, debe pasarse por valor por razones de eficiencia.

Una nota importante sobre el uso de SoType para registrar información de clase: las superclases deben registrarse antes que cualquiera de sus clases derivadas.

Consulte también Carga Dinámica de Nodos de Extensión para obtener información adicional relacionada con SoType.

Documentación de Typedefs de Miembro

typedef void *(* SoType::instantiationMethod) (void)

Esta es una typedef de conveniencia para la firma de la función del método de instanciación de una clase tipada. Es una extensión de la API original de Inventor. Mayormente útil solo para propósitos internos.

Un método de instanciación no tomará argumentos y devolverá un puntero nulo a un objeto recién asignado e inicializado del tipo de clase.

Documentación de Funciones Miembro

SoType SoType::fromName (const SbName name) [static]

Esta función estática devuelve el objeto SoType asociado con el nombre name.

Los objetos de tipo para tipos integrados se pueden recuperar por nombre, tanto con como sin el prefijo "So". Para los nodos de extensión cargables dinámicamente, el nombre dado a esta función debe coincidir exactamente.

Si ningún tipo de nodo con el nombre dado se ha inicializado, se busca un nodo de extensión cargable dinámicamente con el nombre dado. Si se encuentra uno, se carga y se inicializa, y se devuelve el objeto SoType para el tipo de clase recién inicializado. Si no se encuentra ningún módulo o falla la inicialización del módulo, se devuelve SoType::badType().

El soporte para nodos de extensión cargables dinámicamente varía de plataforma a plataforma y de conjunto de compiladores a conjunto de compiladores.

Hasta ahora, el código compilado con los siguientes compiladores es compatible: GNU GCC v2-4, Microsoft Visual C++ v6, 2003, 2005 y 2008), SGI MIPSPro v7.

Las extensiones compiladas con compiladores que se sabe que son compatibles binariamente con los compiladores anteriores también son compatibles, como por ejemplo el compilador Intel x86 compatible con MSVC++.

Para admitir la carga dinámica para otros compiladores, necesitamos saber cómo el compilador genera el símbolo "static void classname::initClass(void)". Si tu compilador no es compatible, dinos en coin-support@coin3d.org cuál es y envíanos la salida de un volcado de símbolos en el objeto compartido. Típicamente puedes hacer

$ nm <Node>.so | grep initClass

para encontrar el símbolo relevante con el nombre modificado.

int SoType::getAllDerivedFrom (const SoType type, SoTypeList & list) [static]

Este método agrega todos los tipos de clase derivados de type a list y devuelve el número de tipos agregados a la lista. Los tipos internos no se incluyen en la lista ni se cuentan.

El propio type también se agrega a la lista, ya que un tipo se considera una derivación de su propio tipo.

NB: no escriba código que dependa de ninguna manera del orden de los elementos devueltos en list.

Aquí hay un pequeño ejemplo independiente que muestra cómo se puede usar este método para la introspección, listando todas las subclases de la superclase SoBase:

#include <cstdio>
#include <Inventor/SoDB.h>
#include <Inventor/lists/SoTypeList.h>
static void
list_subtypes(SoType t, unsigned int indent = 0)
{
  SoTypeList tl;
  SoType::getAllDerivedFrom(t, tl);
  for (unsigned int i=0; i < indent; i++) { printf("  "); }
  printf("%s\n", t.getName().getString());
  indent++;
  for (int j=0; j < tl.getLength(); j++) {
    if (tl[j].getParent() == t) { // solo interesados en descendientes directos
      list_subtypes(tl[j], indent);
    }
  }
}

SbBool SoType::canCreateInstance (void ) const

Este método devuelve FALSE para las clases base abstractas y TRUE para los tipos de clase que se pueden instanciar.

void * SoType::createInstance (void ) const

Este método instancia un objeto del tipo actual.

Para los tipos que no se pueden instanciar, se devuelve NULL.

Tenga en cuenta que si la biblioteca Coin se ha compilado como una DLL bajo Microsoft Windows y utiliza este método desde el código de la aplicación, debe asegurarse de que tanto la DLL de Coin como el ejecutable de la aplicación utilizan la misma instancia de una biblioteca CRT (C Run-Time). De lo contrario, obtendrá corrupción del montón de memoria al liberar las instancias devueltas, lo que finalmente provocará fallos misteriosos.


Esto no es perjudicial si solo llama a SoType::createInstance() en tipos de referencia contada de tipos de clase, aunque. Estos incluyen todos los nodos, motores, rutas, kits de nodos, draggers y manipuladores.

const SoType SoType::createType (const SoType parent, const SbName name, const instantiationMethod method = NULL, const uint16_t data = 0) [static]

Este método crea y registra un nuevo tipo de clase.

Las clases que no heredan ninguna otra clase deben usar SoType::badType() para el primer argumento. Las clases abstractas deben usar NULL para el argumento method.

El valor pasado para el parámetro data se puede recuperar con SoType::getData().

const SoType SoType::overrideType (const SoType originalType, const instantiationMethod method = NULL) [static]

Este método hace que el método de instanciación de una nueva clase anule el método de instanciación de una clase existente.

El nuevo tipo debe ser una subclase C++ del tipo de clase original, pero esto no se comprobará.

Si se pasa NULL como segundo argumento, el tipo se considerará no instanciable; no revierte la configuración a la configuración predeterminada como se podría pensar.

Aquí tienes un ejemplo de código *completo* que muestra cómo anular completamente una clase de nodo Coin integrada, para que a) tu clase de extensión específica de la aplicación se instancie en lugar de la clase integrada al importar el grafo de escena, y b) se escriba correctamente al exportar:

#include <Inventor/SoDB.h>
#include <Inventor/actions/SoWriteAction.h>
#include <Inventor/errors/SoDebugError.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoWWWInline.h>
class MyWWWInline : public SoWWWInline {
  SO_NODE_HEADER(MyWWWInline);
public:
  static void initClass(void);
  MyWWWInline(void);
protected:
  virtual ~MyWWWInline();
  virtual SbBool readInstance(SoInput * in, unsigned short flags);
  virtual const char * getFileFormatName(void) const;
};
SO_NODE_SOURCE(MyWWWInline);
MyWWWInline::MyWWWInline(void)
{
  SO_NODE_CONSTRUCTOR(MyWWWInline);
  // Engañar a la biblioteca para que crea que esta es una clase interna,
  // para que se escriba de la misma manera que las clases integradas,
  // en lugar de como una clase de extensión. Hay ligeras diferencias,
  // que quieres evitar al anular una clase como hacemos aquí con
  // MyWWWInline vs SoWWWInline.
  this->isBuiltIn = TRUE;
}
MyWWWInline::~MyWWWInline()
{
}
void
MyWWWInline::initClass(void)
{
  SO_NODE_INIT_CLASS(MyWWWInline, SoWWWInline, "SoWWWInline");
  // Anular el método de instanciación, para que obtengamos MyWWWInline
  // en lugar de instancias SoWWWInline al importar el grafo de escena.
  (void)SoType::overrideType(SoWWWInline::getClassTypeId(),
                             MyWWWInline::createInstance);
}
// Anular SoBase::getFileFormatName() para que el nodo se escriba como
// "WWWInline" en lugar de "MyWWWInline".
const char *
MyWWWInline::getFileFormatName(void) const
{
  return "WWWInline";
}
SbBool
MyWWWInline::readInstance(SoInput * in, unsigned short flags)
{
  SoDebugError::postInfo("MyWWWInline::readInstance", "hepp");
  return SoWWWInline::readInstance(in, flags);
}
int
main(int argc, char ** argv)
{
  SoDB::init();
  MyWWWInline::initClass();
  const char * ivscene =
    "#Inventor V2.1 ascii\n\n"
    "Separator {\n"
    "  WWWInline { }\n"
    "}\n";
  SoInput in;
  in.setBuffer(ivscene, strlen(ivscene));
  SoSeparator * root = SoDB::readAll(&in);
  root->ref();
  SoOutput out;
  SoWriteAction wa(&out);
  wa.apply(root);
  root->unref();
  return 0;
}
