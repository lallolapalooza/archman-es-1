Descripción detallada

La clase SoMFInt32 es un contenedor para valores enteros de 32 bits.

Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar un grupo de múltiples valores enteros de 32 bits.

Este campo soporta el intercambio de datos de la aplicación a través de un método setValuesPointer(). Consulte la documentación de SoMField para obtener información sobre cómo usar esta función.
