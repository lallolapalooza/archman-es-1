NAME

SoMFVec4i32

SYNOPSIS

class SoMFVec4i32

Detalles de la descripción

Esta clase es un contenedor para vectores SbVec4i32.

Este campo se usa donde los nodos, motores o otros contenedores de campo necesitan almacenar un arreglo de vectores con cuatro elementos.

Este campo soporta el intercambio de datos de aplicación a través de un método setValuesPointer(). Consulte la documentación de SoMField para obtener información sobre cómo usar este método.

Ver también

SbVec4i32, SoSFVec4i32 Nota: Esta clase es una extensión del Coin, y no está disponible en el API original de SGI Open Inventor v2.1.

Desde

Coin 2.5
