Descripción detallada

La clase SoAudioDevice se utiliza para controlar un dispositivo de audio.

La clase SoAudioDevice es responsable de la inicialización de un dispositivo de audio, así como de habilitar y deshabilitar el sonido. Es una clase singleton.

El programador de aplicaciones no necesita usar esta clase directamente, ya que el soporte de audio está habilitado por defecto y la configuración predeterminada es razonable.

Coin utiliza OpenAL (http://www.openal.org/, http://developer.soundblaster.com [sección Juegos]) para renderizar audio. OpenAL debería funcionar con cualquier tarjeta de sonido, y en la mayoría de los sistemas operativos modernos (incluyendo Unix, Linux, IRIX, *BSD, Mac OS X y Microsoft Windows). Siempre hay disponibles 2 altavoces, y en algunas combinaciones de sistema operativo y tarjeta de sonido, se admiten configuraciones de altavoces más avanzadas. En Microsoft Windows, OpenAL puede utilizar DirectSound3D para renderizar audio, admitiendo así cualquier configuración de altavoces que el controlador DirectSound3D actual soporte. La configuración de los altavoces se realiza a través del controlador de la tarjeta de sonido, y es transparente tanto para Coin como para OpenAL.

Documentación de funciones miembro

SoAudioDevice * SoAudioDevice::instance () [static]

Devuelve un puntero a la clase SoAudioDevice, que es un singleton.

SbBool SoAudioDevice::init (const SbString & devicetype, const SbString & devicename)

Inicializa el dispositivo de audio. Actualmente, el único devicetype admitido es "OpenAL". El devicename admitido depende del sistema operativo y de las tarjetas de sonido y controladores instalados. En Microsoft Windows, los nombres de dispositivo admitidos son "DirectSound3D", "DirectSound" y "MMSYSTEM". Consulte la documentación de OpenAL (disponible en http://www.openal.org/) para obtener más información.

El programador de aplicaciones puede anular la configuración predeterminada llamando a este método con el tipo y nombre de dispositivo deseados.

El usuario también puede controlar qué devicename utiliza OpenAL estableciendo la variable de entorno COIN_SOUND_DRIVER_NAME. En Microsoft Windows, el nombre del controlador predeterminado es "DirectSound3D", que normalmente debería ser lo que el usuario desea.

SbBool SoAudioDevice::enable ()

Habilita el sonido

void SoAudioDevice::disable ()

Deshabilita el sonido. Silencia efectivamente toda la salida de audio.

SbBool SoAudioDevice::isEnabled ()

Devuelve TRUE si el audio está habilitado.

SbBool SoAudioDevice::haveSound ()

Devuelve TRUE si el dispositivo de audio se ha inicializado correctamente.
