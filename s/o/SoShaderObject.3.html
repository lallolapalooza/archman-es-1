Detailed Description

This class defines an abstract base class for shader objects. Coin supports GLSL, ARB, and Cg shaders.

The following enum defines the supported shader types:

enum SourceType {
  GLSL, // OpenGL Shading Language
  ARB,  // ARB vertex/fragment programs
  CG    // C for Graphics
};

The member fields are:

SbBool isActive;
SoSFEnum sourceType;
SoSFString sourceProgram;
SoMFNode parameter;

To instantiate a shader object, use one of the derived classes, such as:

  • SoGLSLShader
  • SoARBShader
  • SoCgShader

The field sourceProgram can either contain the shader program as a string, or a filename. If a filename is given, the shader type is determined by the file extension. The following extensions are supported:

  • .glsl for GLSL shaders
  • .cg for Cg shaders
  • .vp and .fp for ARB shaders

The field parameter can be used to pass shader parameters (uniform variables) to the shader. Use one of the following classes:

  • SoShaderParameter1f
  • SoShaderParameter2f
  • SoShaderParameter3f
  • SoShaderParameter4f
  • SoShaderParameter1i
  • SoShaderParameter2i
  • SoShaderParameter3i
  • SoShaderParameter4i
  • SoShaderParameterMatrix

SbBool SoShaderObject::readInstance (SoInput * in, unsigned short flags)[protected], [virtual]

This method is mainly intended for internal use during file import operations.

It reads a definition of an instance from the input stream in. The input stream state points to the start of a serialized / persistent representation of an instance of this class type.

TRUE or FALSE is returned, depending on if the instantiation and configuration of the new object of this class type went OK or not. The import process should be robust and handle corrupted input streams by returning FALSE.

flags is used internally during binary import when reading user extension nodes, group nodes or engines.
