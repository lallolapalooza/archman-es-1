Detailed Description

Transform manipulator node.

This node is a base class for all transform manipulators, such as SoTranslateSphereManip, SoRotateCylinderManip, and SoScaleSphereManip. It provides the common functionality for these manipulators, which is to apply transformations to objects in the scene.

The SoTransformerManip itself does not define any specific manipulation behavior. Instead, it serves as a base class that derived classes must implement to provide their unique manipulation logic. The actual manipulation is performed by an embedded dragger object, which is typically an instance of SoTransformerDragger or a derived class.

Key features:

  • Transformation: Manipulates the transformation of an object in the scene graph.
  • Embedded Dragger: Uses an internal dragger object to handle user interaction and define the manipulation gizmos.
  • Callback Mechanism: Supports callbacks for start, timer, and end of manipulation events.

To use a transformer manipulator, you typically:

  • Create an instance of a derived transformer manipulator class (e.g., SoTranslateSphereManip).
  • Add it to your scene graph.
  • Set the tracker field to the node you want to manipulate.

Example:

#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoSphere.h>
#include <Inventor/manipulators/SoTranslateSphereManip.h>

// ...

SoSeparator *root = new SoSeparator;
root->ref();

// Create a sphere to manipulate
SoSphere *sphere = new SoSphere;
root->addChild(sphere);

// Create a transformer manipulator
SoTranslateSphereManip *manip = new SoTranslateSphereManip;
root->addChild(manip);

// Set the tracker to the sphere
manip->tracker.setValue(sphere);

// ... rest of your scene setup
