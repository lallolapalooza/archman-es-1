DETAILED DESCRIPTION

The SoVRMLTransform class is a grouping node that defines a transformation for its children.

The detailed class documentation is taken verbatim from the VRML97 standard (ISO/IEC 14772-1:1997). It is copyright The Web3D Consortium, and is used by permission of the Consortium:

Transform {
  eventIn      MFNode      addChildren
  eventIn      MFNode      removeChildren
  exposedField SFVec3f     center           0 0 0    # (-inf,inf)
  exposedField MFNode      children         []
  exposedField SFRotation  rotation         0 0 1 0  # [-1,1],(-inf,inf)
  exposedField SFVec3f     scale            1 1 1    # (0,inf)
  exposedField SFRotation  scaleOrientation 0 0 1 0  # [-1,1],(-inf,inf)
  exposedField SFVec3f     translation      0 0 0    # (-inf,inf)
  field        SFVec3f     bboxCenter       0 0 0    # (-inf,inf)
  field        SFVec3f     bboxSize         -1 -1 -1 # (0,inf) or -1,-1,-1
}

The Transform node is a grouping node that defines a coordinate system for its children that is relative to the coordinate systems of its ancestors. See 4.4.4, Transformation hierarchy (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.4.4).

4.6.5, Nodos de agrupación e hijos (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.5), proporciona una descripción de los campos y eventos de entrada de hijos, addChildren y removeChildren.

Los campos bboxCenter y bboxSize especifican un cuadro delimitador que encierra a los hijos del nodo Transform. Esto es una pista que puede ser utilizada con fines de optimización. Los resultados no están definidos si el cuadro delimitador especificado es menor que el cuadro delimitador real de los hijos en cualquier momento. Un valor predeterminado de bboxSize, (-1, -1, -1), implica que el cuadro delimitador no está especificado y, si es necesario, será calculado por el navegador. El cuadro delimitador debe ser lo suficientemente grande en todo momento para encerrar la unión de los cuadros delimitadores de los hijos del grupo; no debe incluir ninguna transformación realizada por el propio grupo (es decir, el cuadro delimitador se define en el sistema de coordenadas local de los hijos). Los resultados no están definidos si el cuadro delimitador especificado es menor que el cuadro delimitador real del grupo. Una descripción de los campos bboxCenter y bboxSize se proporciona en 4.6.4, Cuadros delimitadores (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.4).

Los campos translation, rotation, scale, scaleOrientation y center definen una transformación geométrica 3D que consiste en (en orden):

  • una escala (posiblemente) no uniforme alrededor de un punto arbitrario;
  • una rotación alrededor de un punto y eje arbitrarios;
  • una traslación.

El campo center especifica un desplazamiento de traslación desde el origen del sistema de coordenadas local (0,0,0). El campo rotation especifica una rotación del sistema de coordenadas. El campo scale especifica una escala no uniforme del sistema de coordenadas. Los valores de scale deben ser mayores que cero. scaleOrientation especifica una rotación del sistema de coordenadas antes de la escala (para especificar escalas en orientaciones arbitrarias). scaleOrientation se aplica solo a la operación de escala. El campo translation especifica una traslación al sistema de coordenadas.

Dado un punto tridimensional P y un nodo Transform, P se transforma en el punto P' en el sistema de coordenadas de su padre mediante una serie de transformaciones intermedias. En notación de transformación matricial, donde C (center), SR (scaleOrientation), T (translation), R (rotation) y S (scale) son las matrices de transformación equivalentes,

P' = T × C × R × SR × S × -SR × -C × P

El siguiente nodo Transform:

Transform {
  center           C
  rotation         R
  scale            S
  scaleOrientation SR
  translation      T
  children         [...]
}

es equivalente a la secuencia anidada de:

Transform {
  translation T
  children Transform {
    translation C
    children Transform {
      rotation R
      children Transform {
        rotation SR
        children Transform {
          scale S
          children Transform {
            rotation -SR
            children Transform {
              translation -C
              children [...]
            }
          }
        }
      }
    }
  }
}

Detailed Description

This node defines a coordinate system transformation. It is used for translation, rotation, and scaling of objects. The order of transformations is: scale, scale orientation, rotation, and translation. These transformations are applied relative to the center point.

The fields are:

  • translation: A vector defining the translation.
  • rotation: A rotation quaternion.
  • scale: A vector defining the scaling along each axis.
  • scaleOrientation: A rotation quaternion defining the orientation of the scaling axes.
  • center: A point defining the center of the transformations.

This node is part of the VRML scene graph and is commonly used to position and orient objects in the 3D world.
