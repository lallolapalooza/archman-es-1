Descripción detallada

La clase SoVectorizeAction es la clase base para la vectorización de gráficos de escena Coin.

SoVectorizeAction recorrerá el gráfico de escena y convertirá toda la geometría soportada en datos vectoriales. Las subclases podrán entonces usar estos datos para producir archivos vectoriales de diferentes formatos.

Geometría actualmente soportada:

  • Triángulos (los polígonos se teselarán)
  • Segmentos de línea
  • Puntos (pueden dibujarse como círculos o cuadrados)
  • Texto 2D
  • Texto 3D (se convertirá en triángulos)
  • Imágenes (del nodo SoImage)

La geometría se sombreará basándose en el modelo de sombreado de OpenGL, por lo que las luces y los materiales afectarán a la geometría de la misma manera que en un visor Coin estándar. Tenga en cuenta que la transparencia y el mapeo de texturas aún no son compatibles.

Desde

Coin 2.1

TGS proporciona soporte de HardCopy como una extensión separada para TGS Inventor.

Detailed Description

This class defines the interface for a vectorization action. Vectorization actions traverse a scene graph and convert the geometry found into a 2D vector format (like PostScript).

Subclasses of this class will implement the specific vectorization logic for different output formats.
