Detailed Description

This node defines a set of 2D texture coordinates. Texture coordinates are used to map a texture onto a shape.

A list of texture coordinates is provided by the point field. This field is an SoMFVec2f, meaning it can contain zero or more 2D vectors. Each vector represents a texture coordinate. When applied to a shape, the texture coordinates are typically interpolated across the surface of the shape.

Texture coordinates are usually specified in normalized coordinates, meaning they are in the range [0, 1]. The coordinate (0, 0) corresponds to the lower-left corner of the texture image, and (1, 1) corresponds to the upper-right corner. Values outside the [0, 1] range can be used to repeat the texture across the surface.

The point field can also be empty. An empty list means that the texture coordinates will be generated automatically based on the geometry of the shape. This is often equivalent to providing texture coordinates that range from (0, 0) to (1, 1) across the shape.

See also: SoTexture2, SoTextureCoordinate3.
