Descripción Detallada

La clase SoSFVec4ui32 es un contenedor para un vector SbVec4ui32.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con cuatro elementos.

Ver también

SbVec4ui32, SoMFVec4ui32 Tenga en cuenta que esta clase es una extensión de Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Desde

Coin 2.5
