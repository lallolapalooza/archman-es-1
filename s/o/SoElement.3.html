Descripción detallada

SoElement es la clase base abstracta para todos los elementos.

Esta es la clase base para todas las clases de elementos en Coin.

void SoElement::push (SoState * state) [virtual]

Este método se llama cada vez que se requiere un nuevo elemento en una de las pilas. Esto ocurre cuando se solicita un elemento escribible, utilizando SoState::getElement() o indirectamente SoElement::getElement(), y la profundidad del elemento actual es menor que la profundidad del estado.

Anule este método si su elemento necesita copiar datos del elemento anterior en la cima de la pila. El método push() se llama en el nuevo elemento, y el elemento anterior se puede encontrar utilizando SoElement::getNextInStack().

SoElement * SoElement::getElement (SoState *const state, const int stackIndex) [inline], [static], [protected]

Este método devuelve la instancia superior (en la pila state) de la clase de elemento con el índice de pila stackIndex.

La instancia devuelta es escribible. Para crear esta instancia, puede ser necesario realizar alguna evaluación diferida, así que utilice getConstElement() en su lugar si la instancia no debe modificarse.

Si no hay ninguna instancia disponible y no se puede crear, se devuelve NULL.

const SoElement * SoElement::getConstElement (SoState *const state, const int stackIndex) [inline], [static], [protected]

Este método devuelve una referencia al elemento superior de la clase con el índice de pila stackIndex. El elemento devuelto no es mutable.

(No intentes ser listo y eliminar la constancia; si la instancia devuelta se modifica, es muy probable que empiecen a ocurrir errores extraños, difíciles de encontrar y generalmente maravillosos.)

Si no se puede devolver ninguna instancia, se devuelve NULL.
