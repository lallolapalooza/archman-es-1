NAME

SoVRMLVertexShape - non-inline vertex shape node (abstract base class)

SYNOPSIS

#include <Inventor/VRMLnodes/SoVRMLVertexShape.h>

Inheritance diagram:

class SoVRMLVertexShape : public SoShape

Header: Inventor/VRMLnodes/SoVRMLVertexShape.h

Library: libCoin.so

Detailed Description

This is the abstract base class for all non-inline vertex shapes in VRML 2.0. The specific shapes are:

* SoVRMLBox
* SoVRMLCone
* SoVRMLCylinder
* SoVRMLSphere
* SoVRMLIndexedFaceSet
* SoVRMLIndexedLineSet
* SoVRMLPointSet
* SoVRMLText

The main difference between these shapes and the regular Open Inventor shapes is that they use the VRML 2.0 field definitions instead of Open Inventor's fields. For example, VRML 2.0 uses SoSFNode for coordinates, while Open Inventor uses SoMFNode.

This class also contains the standard fields that can be attached to vertex shapes: coord, texCoord, normal, and color.
