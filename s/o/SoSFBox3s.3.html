Descripción detallada

La clase SoSFBox3s es un contenedor para un vector SbBox3s.

Este campo se utiliza cuando nodos, motores u otros contenedores de campos necesitan almacenar un cuadro.

Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Coin 2.0

Description

This class is a container for a 3D bounding box with short components.

It is used as a field type in Coin scene graphs. Fields allow nodes to store and exchange data. They also support features like notification of changes.
