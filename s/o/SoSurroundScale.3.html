Descripción Detallada

La clase SoSurroundScale se utiliza para escalar automáticamente geometría para rodear otra geometría.

Este nodo calcula una transformación (una traslación y una escala) que, al recorrer el nodo, se añadirá a la matriz de modelo actual, haciendo que un cubo por defecto colocado directamente a la derecha de este nodo en el grafo rodee la geometría a la derecha de la rama del contenedor en la que se encuentra este nodo. El contenedor se especifica mediante el campo SoSurroundScale::numNodesUpToContainer.

Al calcular el cuadro delimitador que se va a rodear, la acción del cuadro delimitador se aplicará al nodo contenedor, y los cálculos del cuadro delimitador se reiniciarán después de recorrer el nodo especificado por el campo SoSurroundScale::numNodesUpToReset.

Una forma de pensar en el nodo contenedor es que existe un camino desde el nodo raíz hasta el nodo SoSurroundScale. Este camino tiene un número de nodos. numNodesUpToContainer es el número de nodos en el camino desde el nodo SoSurroundScale hacia el nodo raíz. Al haber contado numNodesUpToContainer desde el nodo SoSurroundScale, habrá llegado al nodo contenedor. El nodo contenedor es el nodo semilla desde el cual se calcula el cuadro delimitador. Todos los nodos por debajo del nodo semilla formarán parte del cuadro delimitador a menos que estén más cerca del nodo SoSurroundScale que numNodesUpToReset.

Para asegurarse de que el(los) nodo(s) que van a ser escalados por el nodo SoSurroundScale no forman parte del cuadro delimitador, se utiliza numNodesUpToReset. También es el número de nodos por encima del nodo SoSurroundScale hacia el nodo raíz. El significado de numNodesUpToReset es que los nodos que están más cerca del SoSurroundNode que el nodo en la posición numNodesUpToReset no deben ser utilizados para cálculos del cuadro delimitador.

Aquí hay un ejemplo completo e independiente que configura un SoTrackballDragger (conectado a un cubo) y utiliza un nodo SoSurroundScale para que escale automáticamente al tamaño del cubo alto y lo traslade a un lado del cubo:

#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/draggers/SoTrackballDragger.h>
#include <Inventor/nodes/SoAntiSquish.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoCube.h>
#include <Inventor/nodes/SoSurroundScale.h>
#include <Inventor/nodes/SoRotation.h>
#include <Inventor/nodes/SoTranslation.h>
int
main(int argc, char **argv)
{
  QWidget * window = SoQt::init(argv[0]);
  if (window == NULL) exit(1);
  SoSeparator * root = new SoSeparator;
  root->ref();
  SoSeparator * surroundsep = new SoSeparator;
  root->addChild(surroundsep);
  SoTranslation * translation = new SoTranslation;
  translation->translation = SbVec3f(12, 0, 0);
  surroundsep->addChild(translation);
  SoSurroundScale * ss = new SoSurroundScale;
  ss->numNodesUpToReset = 1;
  ss->numNodesUpToContainer = 2;
  surroundsep->addChild(ss);
  SoAntiSquish * antisquish = new SoAntiSquish;
  antisquish->sizing = SoAntiSquish::BIGGEST_DIMENSION;
  surroundsep->addChild(antisquish);
  SoTrackballDragger * dragger = new SoTrackballDragger;
  surroundsep->addChild(dragger);
  SoRotation * rotation = new SoRotation;
  rotation->rotation.connectFrom(& dragger->rotation);
  root->addChild(rotation);
  SoCube * cube = new SoCube;
  cube->height = 10.0f;
  root->addChild(cube);
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  viewer->setSceneGraph(root);
  viewer->setViewing(FALSE);
  viewer->setDecoration(FALSE);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  root->unref();
  return 0;
}

Puede ser más fácil ver cómo funciona SoSurroundScale en el ejemplo anterior si se observa el grafo de escena real:

#Inventor V2.1 ascii
Separator {
   Separator {
      Translation {
         translation 12 0 0
      }
      SurroundScale {
         numNodesUpToContainer 2
         numNodesUpToReset 1
      }
      AntiSquish {
         sizing BIGGEST_DIMENSION
      }
      DEF mydragger TrackballDragger {
      }
   }
   Rotation {
      rotation 0 0 1  0 =
      USE mydragger . rotation
   }
   Cube {
      height 10
   }
}

Este nodo es utilizado internamente por los manipuladores para permitirles escalar la geometría de su dragger para que coincida con la geometría del grafo de escena que está modificando, como se demuestra arriba (pero fuera del contexto de un manipulador).

También es generalmente útil para los programadores de aplicaciones que desean que cualquier pieza de geometría dada rodee otra geometría de extensión desconocida o cambiante.

Los nodos SoSurroundScale en el grafo de escena a menudo se emparejan con nodos SoAntiSquish para obtener un escalado uniforme a lo largo de los tres ejes principales, como también se ha hecho en el ejemplo anterior.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

SurroundScale {
    numNodesUpToContainer 0
    numNodesUpToReset 0
}
