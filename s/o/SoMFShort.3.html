Descripción detallada

La clase SoMFShort es un contenedor para valores enteros cortos.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un grupo de múltiples valores enteros cortos.

Este campo admite el intercambio de datos de aplicaciones a través del método setValuesPointer(). Consulte la documentación de SoMField para obtener información sobre cómo usar esta función.

Detailed Description

This class is a container for multiple short integer values. It is derived from the abstract base class SoMField, which is the base class for all multiple-value fields.

The interface for multiple-value fields is defined in SoMField. See the documentation for that class for a list of methods for accessing and manipulating the values within the field.
