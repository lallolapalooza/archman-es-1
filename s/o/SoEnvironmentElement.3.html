Detailed Description

This element keeps track of the current environment settings.

The following parameters are stored:

  • Ambient Intensity: A single value (float) that controls the overall ambient light contribution. (Note: This is a simplification, real-world ambient lighting is typically more complex.)

  • Ambient Color: An SbColor object that defines the color of the ambient light.

  • Attenuation: An SbVec3f object representing the attenuation factors for light sources. The components typically correspond to:

    • Constant attenuation
    • Linear attenuation
    • Quadratic attenuation

  • Fog Type: An integer representing the type of fog effect to be applied. Common values might include NONE, LINEAR, EXPONENTIAL, etc. (The exact enumeration values are defined elsewhere, likely in SoEnvironmentElement.h).

  • Fog Color: An SbColor object specifying the color of the fog.

  • Fog Visibility: A float value controlling the density or opacity of the fog. A value of 0.0 typically means no fog, and higher values increase fog density.

  • Fog Start: A float value indicating where the fog effect begins to become visible, usually measured in scene units from the viewer.
