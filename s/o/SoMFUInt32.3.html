Descripción Detallada

La clase SoMFUInt32 es un contenedor para valores enteros sin signo de 32 bits.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un grupo de múltiples valores enteros sin signo de 32 bits.

Este campo soporta el intercambio de datos de aplicaciones a través de un método setValuesPointer(). Véase la documentación de SoMField para obtener información sobre cómo usar esta función.

Detailed Description

This class defines a multiple-value field that holds unsigned 32-bit integers.

The element type is uint32_t.

A field of this type can hold an arbitrary number of unsigned 32-bit integer values. When indexed into, it returns a reference to the specified element, allowing it to be read or written.

Example:

  // Create a field with two values, 10 and 20
  SoMFUInt32 myField;
  myField.append(10);
  myField.append(20);

  // Access the values
  uint32_t value0 = myField[0];
  uint32_t value1 = myField[1];

  // Modify the second value
  myField[1] = 30;
