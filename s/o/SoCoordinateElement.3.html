Detailed Description

This element is used to store the coordinates from an SoCoordinate node.

When an SoCoordinate node is traversed, it creates a new instance of this element and pushes it onto the element stack. The coordinates are then stored in this element, and subsequent nodes that require coordinate data (like SoIndexedFaceSet) can query the element stack to find the coordinate element and retrieve the coordinates from it.

This is done so that SoIndexedFaceSet and other geometry nodes don't have to check for SoCoordinate nodes every time they need coordinates. They can simply ask the element stack for the current coordinate element.

The element is created as a default element in the SoNode::initClass() method of the SoCoordinate node.
