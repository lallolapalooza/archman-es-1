Descripción Detallada

La clase SoSFVec4ub es un contenedor para un vector SbVec4ub.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único vector con cuatro elementos.

Ver también

SbVec4ub, SoMFVec4ub Tenga en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Detailed Description

This is a single-valued field holding a 4-component unsigned byte vector.

This field type is intended for storing vectors of 4 unsigned bytes, typically used for RGBA color values where each component ranges from 0 to 255.

Implements SoField.
