Detailed Description

This element is used to set texture image data. This class supports multiple texture units, hence the name SoMultiTextureImageElement.

The SoMultiTextureImageElement is derived from SoElement. It is used to store texture image data.

The texture image data is specified by setElt(). This method takes the texture unit number, the node identifier of the texture image node, the size of the image, the number of components (e.g. RGB, RGBA), the pixel data, the wrap modes for each dimension (S, T, R), the texture model, and the blend color.

The wrap modes control how texture coordinates outside the 0.0 to 1.0 range are handled. They can be set to REPEAT, CLAMP, or MIRROR.

The texture model determines how the texture color is combined with the existing fragment color. The models are MODULATE, DECAL, BLEND, REPLACE, and ADD.

The blend color is used when the texture model is set to BLEND.

The hasTransparency() method can be used to query whether the texture image data contains transparency information. The default implementation returns TRUE if the number of components is 2 or 4, as these are common formats for images with alpha channels.

The matches() and copyMatchInfo() methods are provided for caching purposes. matches() returns TRUE if the element matches another element of the same class. copyMatchInfo() creates a copy of the element containing enough information for matches() to work correctly.
