Descripción detallada

El SoListenerDopplerElement almacena la velocidad y el factor Doppler del oyente actual.

La velocidad Doppler (dopplerVelocity) y el factor Doppler (dopplerFactor) son establecidos por los nodos SoListener durante la renderización de audio. El SoListenerDopplerElement se utiliza cuando los nodos SoVRMLSound se renderizan a sí mismos.

Ten en cuenta que esta clase es una extensión para Coin y no está disponible en la API original de SGI Open Inventor v2.1.

SoListenerDopplerElement — element that stores the listener's Doppler velocity and factor

Detailed Description

This element is used to store the listener's Doppler velocity and Doppler factor. It is used by the 3D audio system to calculate the pitch shift of sounds emitted by sources relative to the listener.

Member Data Documentation

SbVec3f SoListenerDopplerElement::dopplerVelocity [protected]

The Doppler velocity of the listener. It is the application programmer's responsibility to set this value. Coin does not update this value automatically based on changes in a listener's position.

float SoListenerDopplerElement::dopplerFactor [protected]

The amount of Doppler effect applied to the listener. The normal range would be [0.0f to 1.0f], where 0.0f is default and disable all Doppler effects.
