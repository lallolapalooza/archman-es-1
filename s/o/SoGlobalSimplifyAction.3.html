virtual void SoGlobalSimplifyAction::beginTraversal (SoNode * node) [protected], [virtual]

Este método virtual se llama desde SoAction::apply() y es el punto de entrada para la traversal real del grafo de escena.

Se puede sobrescribir para inicializar la acción al inicio de la traversal, para inicializaciones específicas en las subclases de acción que heredan de SoAction.

El método predeterminado simplemente llama a traverse(), lo que cualquier implementación sobrescrita del método también debe hacer (o llamar a SoAction::beginTraversal()) para activar la traversal del grafo de escena.
