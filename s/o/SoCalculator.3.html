Descripción detallada

Calculadora de propósito general para flotantes y vectores de flotantes 3D.

El SoCalculator utiliza los valores de los campos de entrada (que son valores flotantes individuales o vectores) como variables en las expresiones de motor de formato libre y coloca los resultados en los campos de salida.

El motor tiene dieciséis campos de entrada; ocho entradas escalares (a, b, c, d, e, f, g, y h), y ocho entradas de vector (A, B, C, D, E, F, G, y H).

Hay ocho campos de salida; cuatro salidas escalares (oa, ob, oc, y od), y cuatro salidas de vector (oA, oB, oC, y oD).

La sintaxis de la expresión es muy similar a C/C++, con un conjunto muy limitado de palabras clave y funciones.

Un ejemplo:

oa = a * (0.5 + b) / c

Multiplicará el valor en a con el valor en b más 0.5, dividirá ese resultado por c, y colocará el resultado en oa. Dado que es un motor, la expresión solo se evaluará cuando alguien intente leer el valor en oa, no cada vez que cambie una entrada.

Todas las entradas son multifields, y si hay varios valores en una entrada, la expresión se evaluará una vez por cada valor del campo de entrada, y la salida creará tantos valores como valores tenga el campo de entrada.

Si hay más de un campo de entrada, y los campos de entrada no tienen el mismo número de valores, el motor creará tantos valores de salida como el campo de entrada con el mayor número de valores. Cuando el índice esté fuera de rango para algún otro campo de entrada, se utilizará el último valor del campo.

Las expresiones vectoriales son similares a las expresiones escalares. Un ejemplo:

oA = A + vec3f(1.0, 0.0, 0.0) * B

Tomará el vector en A, le sumará el valor en B multiplicado por (1,0,0), y colocará el resultado en oA.

Además de la aritmética regular, la sintaxis de SoCalculator también incluye algunas funciones.

Funciones escalares:

  • cos(x) - función coseno (x en radianes)
  • sin(x) - función seno
  • tan(x) - función tangente
  • acos(x) - función arc coseno
  • asin(x) - función arc seno
  • atan(x) - función arc tangente
  • atan2(y, x) - función arc tangente de dos variables (y, x).
  • cosh(x) - función coseno hiperbólico
  • sinh(x) - función seno hiperbólico
  • tanh(x) - función tangente hiperbólica
  • sqrt(x) - función raíz cuadrada
  • pow(x,y) - x elevado a la potencia de y
  • exp(x) - e elevado a la potencia de x
  • log(x) - logaritmo natural de x
  • log10() - logaritmo en base 10 de x
  • ceil(x) - redondea x hacia arriba al entero más cercano
  • floor(x) - redondea x hacia abajo al entero más cercano
  • fabs(x) - valor absoluto
  • fmod(x, y) - resto de dividir x entre y
  • rand(x) - valor pseudoaleatorio entre 0 y 1

Funciones vectoriales:

  • cross(x, y) - producto cruz de x e y
  • dot(x,y) - producto punto de x e y (devuelve valor escalar)
  • length(x) - longitud de x (devuelve valor escalar)
  • normalize(x) - devuelve la versión normalizada de x
  • x[y] - accede a componentes en x (y debe ser un valor escalar en el rango [0,2])

También hay algunas constantes con nombre que se pueden usar:

  • MAXFLOAT
  • MINFLOAT
  • M_E
  • M_LOG2E
  • M_LOG10E
  • M_LN2
  • M_PI
  • M_SQRT2 - raíz cuadrada de 2
  • M_SQRT1_2 - raíz cuadrada de 1/2

El único control de flujo disponible es el operador ?. Un ejemplo:

oa = (a > b) ? (a * 0.5) : (b * c)

(Los paréntesis no son necesarios, solo están ahí para hacer el ejemplo más fácil de leer)

Además de los operadores de comparación estándar (<, >, <=, >=, ==, !=), también puedes usar && (Y) y || (O) para combinar expresiones, y el operador unario ! (NO).

Una última cosa que vale la pena mencionar son las variables temporales. Existen dieciséis variables temporales que se pueden usar en expresiones. ta, tb, tc, td, te, tf, tg, y th son variables escalares, y tA, tB, tC, tD, tE, tF, tG, y tH son variables vectoriales. Generalmente se usan cuando hay más de una expresión que debe evaluarse en orden.

Un ejemplo con tres expresiones:

ta = a * b; tb = c + d; tc = e - f
tA = vec3f(ta, tb, tc) + A
oA = tA * B

El ejemplo solo muestra cómo se pueden usar variables temporales para hacer que tus expresiones sean más fáciles de leer. Ten en cuenta que es posible tener varias sentencias en una sola expresión. Simplemente las separas con punto y coma.

Aquí hay un ejemplo simple de cómo se puede usar un motor SoCalculator en un archivo .iv:

DEF mycamera PerspectiveCamera {
  orientation 1 0 0 1.57
}
DEF headlight DirectionalLight {
  intensity 0.8
  direction 0 0 1
}
Separator {
  # Renderizar un cubo no afectado por la iluminación
  LightModel { model BASE_COLOR }
  BaseColor { rgb = Calculator {
                      a = USE headlight . intensity
                      expression [ "oA = vec3f( a, a, a)" ]
                    } . oA }
  Cube {}
}

En el ejemplo, el color del Cubo es una función de la intensidad de la Luz Direccional, a pesar de que el Cubo se renderiza sin iluminación debido al Modelo de Luz BASE_COLOR.

Detailed Description

This engine evaluates mathematical expressions. The expressions can use a number of input fields and can produce a number of output fields. The expressions are stored in the expression field.

The calculator supports the following input fields:

  a, b, c, d, e, f, g, h  (SoMFFloat)
  A, B, C, D, E, F, G, H  (SoMFVec3f)

The calculator supports the following output fields:

  oa, ob, oc, od          (SoMFFloat)
  oA, oB, oC, oD          (SoMFVec3f)

An example of an expression might be: "oa = a*a + b*b". All fields are optional and you only need to declare the ones you want to use.

The expressions are evaluated whenever any of the input fields change.
