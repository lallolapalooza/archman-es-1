void SoScXMLNavigationTarget::freeSessionData (SbName sessionid) [protected]

Limpia la estructura de datos que se corresponde con el sessionid dado. El argumento constructor es la función responsable de crear el objeto derivado de Datos si la sesión es nueva (o ha sido limpiada anteriormente).

SbName SoScXMLNavigationTarget::getSessionId (const ScXMLEvent * event) [static], [protected]

Devuelve el id de sesión asociado al event. Si no se encuentra ningún id de sesión, se devuelve SbName::empty().

ScXMLStateMachine * SoScXMLNavigationTarget::getStateMachine (const ScXMLEvent * event, SbName sessionid) [static], [protected]

Devuelve la máquina de estados asociada al sessionid dado, o NULL si no hay máquinas de estados registradas para ese id de sesión.

SoScXMLStateMachine * SoScXMLNavigationTarget::getSoStateMachine (const ScXMLEvent * event, SbName sessionid) [static], [protected]

Devuelve la máquina de estados So- asociada al sessionid dado, o NULL si no hay máquinas de estados registradas para ese id de sesión o si la máquina de estados no es del tipo SoScXMLStateMachine.

SoCamera * SoScXMLNavigationTarget::getActiveCamera (const ScXMLEvent * event, SbName sessionid) [static], [protected]

Devuelve la cámara activa actual, o NULL si no hay ninguna cámara activa configurada. Si se devuelve NULL, se habrán emitido mensajes de error.
