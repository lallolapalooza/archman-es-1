Descripción Detallada

La clase SoGLCubeMapImage se utiliza para manejar texturas de mapa de cubos.

Tenga en cuenta que esta clase es una extensión para Coin, y no está disponible en la API original de SGI Open Inventor v2.1.

void SoGLCubeMapImage::unref (SoState * state = NULL) [virtual]

Esta clase tiene un destructor privado ya que queremos que los usuarios proporcionen el estado GL actual al eliminar la imagen. Esto es para asegurar que los objetos de textura GL se liberen lo antes posible. Si proporciona NULL a este método, los objetos de textura GL no se eliminarán hasta la próxima vez que se aplique una acción de renderizado GL en el contexto de caché de la imagen.

Si border != 0, la textura de OpenGL se creará con este tamaño de borde. Ten en cuenta que esto puede ser extremadamente lento en la mayoría del hardware de PC.

Normalmente, el objeto de textura de OpenGL no se crea hasta la primera vez que se necesita, pero si createinstate es != NULL, el objeto de textura se crea inmediatamente. Esto es útil si utilizas un búfer temporal para almacenar los datos de la textura. Ten cuidado al usar esta función, ya que los datos de la textura podrían ser necesarios en una etapa posterior (por ejemplo, para crear un objeto de textura para otro contexto). No será posible crear objetos de textura para otros contextos de caché cuando createinstate sea != NULL.

Además, si se proporciona createinstate y todos los atributos son los mismos que los datos actuales en la imagen, se utilizará glTexSubImage() para insertar los datos de la imagen en lugar de crear un nuevo objeto de textura. Esto es mucho más rápido en la mayoría de los controladores de OpenGL y es muy útil, por ejemplo, al hacer texturas animadas.

Si proporcionas NULL para image, la instancia se reiniciará, lo que provocará la liberación de todas las listas de visualización y la memoria.
