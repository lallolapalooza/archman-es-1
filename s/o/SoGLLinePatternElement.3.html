Descripción detallada

La clase SoGLLinePatternElement cambia el patrón de discontinuidad de línea del estado de renderizado de OpenGL.

Las solicitudes del grafo de escena para cambiar el patrón de discontinuidad al renderizar primitivas de línea OpenGL se realizarán a través de este elemento, que las reenvía a la llamada nativa de OpenGL correspondiente.

NAME

SoGLLinePatternElement - GL line pattern element for Coin

SYNOPSIS

#include <Inventor/GL/elements/SoGLLinePatternElement.h>

class SoGLLinePatternElement : public SoInt32Element
{
public:
  // Construction and destruction.
  virtual ~SoGLLinePatternElement ();

  // Reimplemented from SoElement.
  virtual void        push (SoState * state);
  virtual void        pop (SoState * state, const SoElement * prevTopElement);

  // Returns the GL line pattern value.
  static int32_t      get (SoState * state);

  // Sets the line pattern in the state.
  static void         set (SoState * state, int32_t pattern);

protected:
  // Reimplemented from SoInt32Element.
  virtual void        setElt (int32_t pattern);

private:
  // Private constructor to prevent direct instantiation.
  SoGLLinePatternElement ();
};

Detailed Description

This element holds the current line pattern in the scenegraph. The line pattern is a 16-bit integer which is used to control how lines are rendered (e.g. solid, dashed, dotted).

The element is derived from SoInt32Element, and thus stores an int32_t value.
