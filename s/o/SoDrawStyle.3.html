Descripción Detallada

La clase SoDrawStyle especifica propiedades comunes de renderizado para formas.

Utiliza nodos SoDrawStyle para influir en cómo se renderizarán los nodos de forma que les sigan en el grafo de escena. Este tipo de nodo tiene campos para ayudar a decidir cómo se renderizan ciertos aspectos de formas basadas en puntos, formas basadas en líneas y primitivas de forma rellenas.

Ejemplo de uso de estructura de grafo de escena simple:

#Inventor V2.1 ascii
Separator {
   Sphere { }
   Translation { translation 4 0 0 }
   DrawStyle { style LINES  lineWidth 2 }
   Sphere { }
   Translation { translation 4 0 0 }
   DrawStyle { style POINTS  pointSize 2 }
   Sphere { }
}

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

DrawStyle {
    style FILLED
    pointSize 0
    lineWidth 0
    linePattern 0xffff
    linePatternScaleFactor 1
}

NAME

SoDrawStyle — node for setting drawing style, line width, and point size

SYNOPSIS

Inherits from SoNode.

#include <Inventor/nodes/SoDrawStyle.h>

inherited fields:
    SoSFNode        next
    SoSFBool        renderCaching

fields of this class:
    SoSFEnum    style
    SoSFFloat   pointSize
    SoSFFloat   lineWidth
    SoSFUShort  linePattern
    SoSFInt32   linePatternScaleFactor

Detailed Description

This node is used to control the way geometry is rendered. It can set the drawing style (e.g., points, lines, filled polygons), the size of points, the width of lines, and the pattern of lines.

The drawing style is set by the style field. The possible values are defined in the SoDrawStyle::style enumeration.

The size of points is controlled by the pointSize field. This field is only used when the style is set to SoDrawStyle::POINTS.

The width of lines is controlled by the lineWidth field. This field is only used when the style is set to SoDrawStyle::LINES, or when rendering borders of polygons.

The pattern of lines is controlled by the linePattern and linePatternScaleFactor fields. These fields are used when the style is set to SoDrawStyle::LINES.

Member Enumeration Documentation

SoDrawStyle::style

Enumeration for the drawing style.

POINTS
Draw geometry as points.
LINES
Draw geometry as lines.
LINE_LOOP

LINE_STRIP
Draw geometry as a line strip.
TRIANGLES
Draw geometry as triangles.

Draw geometry as filled polygons with flat shading.

Member Data Documentation

SoSFEnum SoDrawStyle::style

Sets the drawing style. Possible values are defined in the SoDrawStyle::style enumeration. Default value is SoDrawStyle::FLAT.

SoSFFloat SoDrawStyle::pointSize

Size in screen units of points when setting the SoDrawStyle::style to SoDrawStyle::POINTS.

The valid range of point size settings varies according to which OpenGL implementation is used. For the purpose of not trying to set illegal values, the application programmer should at runtime check the valid range. How this can be accomplished is described in the class documentation of SoGLPointSizeElement.

Default value is 0.0f, which is a "tag" value which tells the rendering library to use the default setting.

SoSFFloat SoDrawStyle::lineWidth

Width in screen pixels of SoLineSet and SoIndexedLineSet lines, and also of geometry border lines if setting the SoDrawStyle::style to SoDrawStyle::LINES.

The valid range of line width settings varies according to which OpenGL implementation is used. For the purpose of not trying to set illegal values, the application programmer should at runtime check the valid range. How this can be accomplished is described in the class documentation of SoGLLineWidthElement.

Default value is 0.0f, which is a "tag" value which tells the rendering library to use the default setting.

SoSFUShort SoDrawStyle::linePattern

Pattern as a bitmask used when drawing lines. Default is 0xffff (no "holes").

SoSFInt32 SoDrawStyle::linePatternScaleFactor

Multiplier for the bitmask in linePattern (range 1 - 256). Default is 1.
