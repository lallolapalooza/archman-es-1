Detailed Description

This node defines the fog properties for a VRML scene. The fog effects are rendered using the VRML 2.0 specification.

The fog is applied to all objects within the scene. The fog properties include color, type (linear, exponential, or squared exponential), and visibility range.

The fog is enabled/disabled using the enabled field.
