SbBool SoProfilerElement::matches (const SoElement * element) const [virtual]

Esta función devuelve TRUE si el elemento coincide con otro elemento (de la misma clase), con respecto a la validez de la caché.

Si el elemento de extensión del programador de aplicaciones tiene una función matches(), también debería tener una función copyMatchInfo().

Implementa SoElement.

SoElement * SoProfilerElement::copyMatchInfo (void ) const [virtual]

Esta función crea una copia del elemento que contiene suficiente información para permitir que la función matches() funcione.

Se utiliza para ayudar con las operaciones de caché de recorrido del grafo de escena.
