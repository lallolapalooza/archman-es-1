Detailed Description

This class is a dragger that allows the user to manipulate a bounding box using handles. The bounding box is controlled by the dragger's transformation fields (translation, scale, rotation, matrix).

The dragger itself consists of several parts:

1.
The box: This is the main visual representation of the bounding box. It is composed of 6 faces and 12 edges.
2.
Handles: These are small geometric shapes (usually spheres or cubes) placed at the corners and on the faces of the box. They are used to interact with the box. There are handles for:
  • Scaling along each axis (X, Y, Z).
  • Scaling uniformly in all directions.
  • Translating the box.
  • Rotating the box.

When the user interacts with a handle, the dragger's transformation fields are updated accordingly. The application can connect its own scene graph nodes to these fields to make them follow the dragger's transformations.

The dragger also provides mechanisms for customizing its appearance (colors, feedback) and behavior (pick filter).
