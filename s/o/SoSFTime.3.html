Descripción Detallada

La clase SoSFTime es un contenedor para un valor SbTime.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar una única representación de tiempo.

Un campo de este tipo almacena su valor en un archivo como un número de punto flotante.

Detailed Description

An SoSFTime is a field which contains a single time value.

Time values are represented as floating-point numbers, where unity corresponds to one second. The time value is measured in seconds since the epoch (January 1, 1970, 00:00:00 UTC).

The SoSFTime class inherits the methods for setting and getting the field value from the SoField class.
