DESCRIPCIÓN DETALLADA

La clase SoSFBool es un contenedor para un valor SbBool.

Este campo se usa donde los nodos, motores u otros contenedores de campos necesitan almacenar un valor booleano de encendido/apagado o VERDADERO/FALSO, como por ejemplo, el campo "on" de las clases de nodo SoPointLight, SoSpotLight y SoDirectionalLight.

Detailed Description

SFBool field class.

This is a field type for a boolean value. It has a single value.

To use this field type, include the header file: <Inventor/fields/SoSFBool.h>

In most cases, you will not need to interact with this class directly. The Coin library handles the management of fields, and you typically interact with them through their owning node's methods.

Example of field definition in a custom node:

// In the header file (.h)
class MyNode : public SoNode {
  SO_NODE_HEADER(MyNode);
public:
  static void initClass();
  MyNode();
  SoSFBool   myBoolField;
};

// In the implementation file (.c)
void MyNode::initClass() {
  SO_NODE_INIT_CLASS(MyNode, SoNode, "Node");
  SO_NODE_ADD_FIELD(MyNode, myBoolField, (FALSE)); // Default value FALSE
}
MyNode::MyNode() {
  // No need to do anything here, fields are initialized by initClass()
}

In this example, `myBoolField` is an instance of `SoSFBool` that will be part of the `MyNode` scene graph node. The second argument in `SO_NODE_ADD_FIELD` is the default value for the field.

You can set and get the value of this field like any other field:

  // Get the node
  MyNode *myNode = ...;

  // Set the value
  myNode->myBoolField.setValue(TRUE);

  // Get the value
  SbBool currentValue = myNode->myBoolField.getValue();
