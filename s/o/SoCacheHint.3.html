Descripción Detallada

La clase SoCacheHint es un nodo que contiene pistas sobre cómo almacenar en caché la geometría.

El nodo SoCacheHint se utiliza para establecer pistas para el subsistema de renderizado sobre cómo Coin debe almacenar en caché los datos de vértices.

Tenga en cuenta que esta es una clase experimental. La API puede cambiar mucho antes de que se incluya (si se incluye) en cualquier versión oficial de Coin.

FORMATO DE ARCHIVO/VALORES PREDETERMINADOS:

CacheHint {
    memValue 0.5
    gfxValue 0.5
}
