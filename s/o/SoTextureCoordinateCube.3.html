SoTextureCoordinateCube(3) — Arch Linux

Name

SoTextureCoordinateCube — cube texture coordinate generator

Syntax

#include <Inventor/nodes/SoTextureCoordinateCube.h>

Description

This node generates texture coordinates based on the vertex coordinates, using the cube mapping projection. This node is useful for applying a cubemap texture to a model.

The texture coordinates generated are 3D vectors (vec3f), where each component corresponds to one of the six faces of the cube. The components are typically interpreted as the direction vector from the center of the object to the point on its surface, which is then used to sample the cubemap texture.

Member Function Documentation

The SoTextureCoordinateCube node does not provide any public member functions beyond the standard methods inherited from SoNode and its base classes. All configuration and behavior are controlled through the fields of the node.

The primary fields for this node are:

  • orientation (SoSFEnum): Specifies the orientation of the cube map. Defaults to AXIS_X. Possible values include AXIS_X, AXIS_Y, AXIS_Z, and their inverted counterparts. This field determines which axis is considered "up" or "forward" for the cubemap.
  • scale (SoSFFloat): A scaling factor applied to the generated texture coordinates. Defaults to 1.0.

Example of how to use it within an OpenInventor scene graph:

#include <Inventor/nodes/SoTextureCoordinateCube.h>
#include <Inventor/nodes/SoTexture2.h>
#include <Inventor/nodes/SoMaterial.h>
#include <Inventor/nodes/SoSphere.h>
#include <Inventor/SoDB.h>
#include <Inventor/SbImage.h>

// ... inside a scene creation function ...

SoSeparator *root = new SoSeparator;
root->ref();

// Create a texture map (for demonstration, using a simple gray texture)
// In a real application, you would load a cubemap texture here.
unsigned char data[16*16*3];
for (int i = 0; i < 16*16*3; ++i) {
    data[i] = 128; // Gray color
}
SbImage image(16, 16, 3, data);
SoTexture2 *tex = new SoTexture2;
tex->image.setValue(&image);

SoTextureCoordinateCube *texCoordCube = new SoTextureCoordinateCube;
texCoordCube->orientation.setValue(SoTextureCoordinateCube::AXIS_Y); // Example orientation
texCoordCube->scale.setValue(1.0);

SoMaterial *mat = new SoMaterial;
mat->texture.setValue(tex);

SoSphere *sphere = new SoSphere;

root->addChild(mat);
root->addChild(texCoordCube);
root->addChild(sphere);

// ... add root to your scene ...
