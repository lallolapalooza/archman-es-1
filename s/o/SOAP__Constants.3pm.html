SOAP::Constants(3) Documentación de Perl aportada por el usuario SOAP::Constants(3)

NOMBRE

SOAP::Constants - SOAP::Lite proporciona varias variables para permitir a los programadores y usuarios modificar el comportamiento de SOAP::Lite de formas específicas.

DESCRIPCIÓN

A través de este espacio de nombres se proporcionan una serie de valores de "constantes". Los valores no son constantes en el sentido más estricto; el propósito de los valores detallados aquí es permitir que la aplicación los modifique si desea alterar el comportamiento específico que rigen.

CONSTANTES

$NO_USAR_XML_PARSER

El paquete SOAP::Lite intenta localizar y utilizar el paquete XML::Parser, recurriendo a un analizador interno, puramente Perl, en su ausencia. Este paquete es un analizador rápido, basado en el analizador Expat desarrollado por James Clark. Si la aplicación establece este valor en 1, no se intentará localizar ni utilizar XML::Parser. Hay varias razones por las que podría optar por hacer esto. Si el paquete nunca se va a poner a disposición, no hay razón para realizar la prueba. Establecer este parámetro consume menos tiempo que la prueba del paquete. Además, el código XML::Parser se vincula con las bibliotecas Expat para el lenguaje C. En algunos entornos, esto podría causar un problema al mezclarse con otras aplicaciones que pueden estar vinculadas a una versión diferente de las mismas bibliotecas. Este fue una vez el caso con ciertas combinaciones de Apache, mod_perl y XML::Parser.

$NO_USAR_CHARSET

A menos que este parámetro se establezca en 1, las cabeceras salientes Content-Type incluirán la especificación del conjunto de caracteres utilizado para codificar el propio mensaje. Sin embargo, no todos los puntos finales (cliente o servidor) podrán tratar correctamente esos datos en la cabecera de contenido. Si está tratando con un punto final que espera hacer un examen más literal de la cabecera en su conjunto (en lugar de analizarla por completo), este parámetro puede resultar útil.

$NO_VERIFICAR_CONTENT_TYPE

El tipo de contenido en sí mismo para un mensaje SOAP está bastante claramente definido, y en la mayoría de los casos, una aplicación no tendría ninguna razón para deshabilitar la prueba de esa cabecera. Habiendo dicho esto, el tipo de contenido para SOAP 1.2 sigue siendo solo un borrador recomendado, y los puntos finales mal codificados podrían enviar mensajes válidos con cabeceras Content-Type inválidas. Si bien lo "correcto" sería rechazar tales mensajes, esa no siempre es una opción. Establecer este parámetro en 1 permite que el kit de herramientas omita la prueba del tipo de contenido.

$APLICAR_PARCHE_HTTP_KEEPALIVE

El módulo de transporte HTTP de SOAP::Lite intenta proporcionar un parche simple a LWP::Protocol para habilitar HTTP Keep Alive. De forma predeterminada, este parche está desactivado; si desea activarlo, modifique la constante de la siguiente manera:

$SOAP::Constants::PATCH_HTTP_KEEPALIVE = 1;
