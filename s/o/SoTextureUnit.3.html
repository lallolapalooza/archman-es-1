Detailed Description

The SoTextureUnit class is a node for setting the active texture unit.

When an SoTextureUnit node is inserted into the scene graph, all subsequent texture nodes (SoTexture2, SoTextureCoordinate2, SoTextureCoordinate3, SoTexture2Transform, SoTexture3Transform, SoTextureCoordinateEnvironment, SoTextureCoordinatePlane and SoComplexity) will affect the texture unit set in the unit field.

See the SoGuiExample module for an usage example for this node.

FILE FORMAT/DEFAULTS:

TextureUnit {
    unit 0
    mappingMethod IMAGE_MAPPING
}

Since

Coin 2.2

Detailed Description

This node sets the texture unit parameter for subsequent texture nodes in the scene graph.

It is primarily intended for use with multiple texture units when rendering on hardware that supports it. Using this node, you can specify which texture unit a subsequent texture node should use for its texture image, and you can also modify the texture coordinate generation matrices, etc. for that specific unit.

The default value for the unit field is 0, which corresponds to the first texture unit.

The mappingMethod field is intended to specify the type of texture coordinate generation to be used, but it is not currently supported in Coin and is included only for compatibility with the TGS Inventor API.

Member Enumeration Documentation

enum SoTextureUnit::MappingMethod

This enumeration defines the possible methods for generating texture coordinates. However, this functionality is not currently implemented in Coin.

IMAGE_MAPPING
Specifies image mapping.
SPHERE_MAPPING
Specifies sphere mapping.
CUBE_MAP
Specifies cube mapping.
SHARED_TEXTURE_UNIT
Indicates a shared texture unit.

void SoTextureUnit::getMatrix (SoGetMatrixAction * action) [virtual]

Action method for SoGetMatrixAction. This method is called by the action to apply the node's transformation to the given action.

This method is intended to be overridden by derived classes that wish to influence how their transformations are handled by the SoGetMatrixAction. The default implementation simply applies the node's transformation matrix (if any) to the action's current matrix.

This method is also used by SoGetBoundingBoxAction to influence how geometry nodes calculate their bounding box. Some nodes may override this method to modify the SoGetMatrixAction state variables in order to adjust the bounding box calculation for

this node and to shift the center point for the scene more towards the one for this node.

Nodes influencing how geometry nodes calculate their bounding box also override this method to change the relevant state variables.

Reimplemented from SoNode.

uint32_t SoTextureUnit::getMaxTextureUnit (void ) [static]

Returns the maximum number of texture units for the current GL context. Do not call this method if you don't have a current active GL context. You should also know that your OpenGL driver supports multi-texturing.

This function is provided only to be compatible with TGS Inventor. It's better to use cc_glglue_max_texture_units() if you're using Coin (declared in Inventor/C/glue/gl.h).
