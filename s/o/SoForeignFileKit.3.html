Detailed Description

This class is intended as a base class for foreign file importer and exporter kit classes. It provides a generic interface for checking if a file can be read or written, reading and writing files, and converting foreign file data into a Coin scene graph.

Concrete subclasses should override the pure virtual convert() method and should potentially override the canReadFile(), readFile(), canWriteFile(), and writeFile() methods.

Instances of foreign file kits are usually created using the static convenience methods createForeignFileKit(). These methods automatically determine which concrete subclass should be used based on the file's extension.

Foreign file handlers are registered with the system using the static registerFileExtension() method. This is typically done once during the initialization of the subclass.

The exhaust parameter on several methods is currently unused and is planned to be removed in a future release.
