Descripción detallada

La clase SoTextureCoordinateBundle simplifica el manejo de coordenadas de textura.

Es poco probable que los programadores de aplicaciones necesiten saber cómo usar esta clase, ya que está destinada principalmente a uso interno.

Documentación del constructor y destructor

SoTextureCoordinateBundle::SoTextureCoordinateBundle (SoAction *const action, const SbBool forRendering, const SbBool setUpDefault = TRUE)

Constructor con action siendo la acción aplicada al nodo. El parámetro forRendering debe ser TRUE si el paquete se va a utilizar para enviar coordenadas de textura a GL durante la renderización. setUpDefault debe ser TRUE si se deben generar coordenadas de textura predeterminadas.

Devuelve TRUE si se necesitan coordenadas de textura durante la renderización.

SbBool SoTextureCoordinateBundle::isFunction (void ) const

Devuelve TRUE si se debe utilizar una función de coordenadas de textura.

const SbVec4f & SoTextureCoordinateBundle::get (const int index)

Devuelve las coordenadas de textura en el índice index. Solo debe usarse si SoTextureCoordinateBundle::isFunction() es FALSE.

Devuelve las coordenadas de textura basadas en point y normal. Solo debe usarse si SoTextureCoordinateBundle::isFunction() es TRUE.

void SoTextureCoordinateBundle::send (const int index) const [inline]

Envía las coordenadas de textura a GL. Solo debe usarse si SoTextureCoordinateBundle::isFunction() es FALSE.

void SoTextureCoordinateBundle::send (const int index, const SbVec3f & point, const SbVec3f & normal) const [inline]

Función de conveniencia que hará que sea transparente para el código de renderización si se utilizan coordenadas de textura ordinarias o de función.

SbBool SoTextureCoordinateBundle::needIndices (void ) const

Devuelve TRUE si isFunction() es TRUE, pero los índices de coordenadas de textura son necesarios para el mapeo de relieve o para una de las otras unidades de textura.
