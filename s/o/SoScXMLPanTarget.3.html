Detailed Description

This class is an ScXML event target that provides pan functionality. It is derived from ScXMLEventTarget and implements the logic for handling ScXML events related to panning.

The primary purpose of this class is to connect ScXML event handling with the Coin 3D scene graph's camera manipulation for panning.
