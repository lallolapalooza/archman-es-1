Descripción detallada

La clase SoSFBox2f es un contenedor para un vector SbBox2f.

Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar una caja.

Tenga en cuenta que esta clase es una extensión para Coin, y no está disponible en la API original de SGI Open Inventor v2.1.
Desde

Coin 2.5

SoSFBox2f

Field containing an axis-aligned bounding box in 2D

SYNOPSIS

DESCRIPTION

This field class holds an axis-aligned bounding box. An axis-aligned bounding box is defined by its minimum and maximum corner coordinates.

The fields derived from SoSFBox2f are: SoSFBox2f.
