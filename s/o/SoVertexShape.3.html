SoVertexShape

The SoVertexShape class is the superclass for all vertex based shapes.

Basically, every polygon, line, or point based shape will inherit this class. It contains methods for organizing the normal cache, and also holds the SoVertexShape::vertexProperty field which can be used to set vertex data inside the node.

Método de conveniencia que puede usarse por subclases para devolver o crear un caché de normales. Si el caché actual no es válido, se encarga de liberar el caché antiguo y de crear dependencias elementales al generar el nuevo caché. Cuando el caché de normales esté fuera de uso, debe llamarse readUnlockNormalCache().

Cuando se devuelve de este método, el caché de normales será leído bloqueado, y el llamador debe llamar readUnlockNormalCache() cuando las normales en el caché no estén más necesarias.

Member Data Documentation

SoSFNode SoVertexShape::vertexProperty

Si se establece el campo vertexProperty, debe ser con un nodo SoVertexProperty. De lo contrario, se ignorará. Los nodos derivados de SoVertexShape obtendrán sus datos de coordenadas desde el nodo vertexProperty en lugar de desde el estado global de recorrido.

El campo vertexProperty de nodos derivados de SoVertexShape se comporta de manera un poco diferente con el diseño básico de Open Inventor, ya que sus contenidos no se pasan al estado global. Esto se hace para proporcionar una ruta simple hacia la renderización optimizada de formas basadas en vértices.
