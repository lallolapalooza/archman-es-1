Sort::Key::Types - maneja tipos de datos de Sort::Key

SINOPSIS

use Sort::Key::Types qw(register_type);
register_type(Color => sub { $_->R, $_->G, $_->B }, qw(int, int, int));
# es mejor
# usar Sort::Key::Register ...

DESCRIPCIÓN

La familia de módulos Sort::Key puede extenderse para soportar nuevos tipos de clave utilizando este módulo (o el más amigable Sort::Key::Register).

FUNCIONES

Se proporcionan las siguientes funciones:

Sort::Key::register_type($nombre, \&gensubkeys, @subkeystypes)
registra un nuevo tipo de dato llamado $nombre que define cómo convertirlo a una multi-clave.

&gensubkeys debe convertir el objeto de tipo $nombre pasado en $_ a una lista de valores que componen la multi-clave.

@subkeystypes es la lista de tipos para las multi-claves generadas.

Por ejemplo:

Sort::Key::Types::register_type
               'Person',
               sub { $_->surname,
                     $_->name,
                     $_->middlename },
               qw(str str str);
Sort::Key::Types::register_type
               'Color',
               sub { $_->R, $_->G, $_->B },
               qw(int int int);

Una vez que un tipo de dato ha sido registrado, puede ser usado de la misma manera que los tipos soportados nativamente, incluso para definir nuevos tipos, es decir:

Sort::Key::Types::register_type
               'Family',
               sub { $_->father, $_->mother },
               qw(Person Person);

VER TAMBIÉN

Sort::Key, Sort::Key::Merger, Sort::Key::Register.
