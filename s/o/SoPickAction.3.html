Descripción Detallada

La clase SoPickAction es la clase base para acciones de selección.

La base para todas las funciones de interacción que Coin proporciona para el desarrollador de aplicaciones es la acciones de selección. Los draggers, manipuladores, SoSelection nodes, etc. todos utilizan la funcionalidad proporcionada por las acciones de selección para seleccionar y modificar la geometría de escena de diferentes formas.

Esta clase no debería usarse directamente por el desarrollador de aplicaciones, ya que es más un placeholder para la interfaz común de operaciones de selección. No contiene ningún código real para realizar selecciones de árbol de escenas.

Coin proporciona una acción funcional completa para el desarrollador de aplicaciones a través de la clase SoRayPickAction (que hereda la clase SoPickAction).

Detailed Description

This is the base class for all picking actions. Picking actions are used to traverse the scenegraph and determine which nodes are intersected by a ray or a region.

The primary purpose of a picking action is to find intersections between objects in the scene graph and a specified picking region (ray or window region). The action traverses the scene graph, and for each primitive geometry node it encounters, it checks for intersection. If an intersection is found, the node is added to the action's list of picked objects.

Subclasses of SoPickAction, such as SoRayPickAction, specialize the picking mechanism to handle different types of picking (e.g., ray casting, bounding box picking).

Key functionalities include:

  • Viewport Region Handling: Allows specifying the area or region within the viewport where picking should occur.

  • Culling Control: Enables or disables culling (the process of eliminating objects that are not visible) during the picking traversal to potentially speed up the process.

  • Traversal Management: Provides methods for initiating and controlling the scene graph traversal during the picking process.

The SoPickAction class itself provides the framework for picking, while its derived classes implement the specific picking logic.

void SoPickAction::beginTraversal (SoNode * node) [protected], [virtual]

This virtual method is called from SoAction::apply(), and is the entry point for the actual scene graph traversal.

It can be overridden to initialize the action at traversal start, for specific initializations in the action subclasses inheriting SoAction.

Default method just calls traverse(), which any overridden implementation of the method must do too (or call SoAction::beginTraversal()) to trigger the scene graph traversal.
