Detailed Description

This element is used by SoGetBoundingBoxAction to keep track of the model matrix.

It is a subclass of SoModelMatrixElement, and therefore provides the same functionality, but it is specifically designed for use in bounding box calculations. Its primary purpose is to be able to store and retrieve the model matrix that is used to transform the scene graph into world space.

The SoGetBoundingBoxAction uses this element to accumulate the model matrix transformations from the scene graph. It also uses the static methods reset, pushMatrix, and popMatrix to manage the matrix state during the traversal.
