Notas


La clase SoDragPointDragger es una subclase de SoDragger que proporciona un mecanismo para arrastrar un punto en 3D. El comportamiento exacto de arrastre depende de la configuración de los campos de la clase (como SoDragger).

Se pueden conectar SoDraggerCBs a los eventos de inicio, movimiento y fin del arrastre para controlar o responder a las acciones del usuario.

La función showNextDraggerSet() se utiliza para ciclar entre diferentes configuraciones de arrastradores, lo cual es útil cuando múltiples arrastradores están presentes en la escena.

El campo jumpLimit controla qué tan lejos puede moverse el punto arrastrado antes de que el movimiento se "reinicie", lo cual puede ser útil para evitar saltos bruscos.

Para más detalles sobre las funciones heredadas, consulte la documentación de SoDragger, SoInteractionKit, SoBaseKit, SoNode y SoFieldContainer.

Detailed Description

The SoDragPointDragger class provides mechanisms for moving a point in 3D.

Here's how the dragger looks with its default geometry in the inactive state:

This dragger is convenient to use when it is desirable that the end-user should interact with points by positioning them freely in 3D space.

The dragger consists of a part for 2D motion in a plane (like the SoTranslate2Dragger) and another part on the axis normal to the plane.

While the dragger is inactive (i.e. the user is not currently grabbing and / or dragging its parts), the CTRL keys on the keyboard can be used to switch the orientation of the 2D-plane part and the normal-axis part so the normal-axis part points along one of the other principal axes. This is done by position the mouse pointer over the dragger geometry and pressing and releasing a CTRL key.

Detailed Description

This dragger is used for manipulating a point in 3D space. It provides a simple visual cue (a small sphere) that the user can click and drag.

The dragger translates directly along the 3D axes. The main way the application programmer interacts with this dragger is by connecting relevant node fields in the scene graph to the translation field of this dragger.

The translation field will be continuously updated to reflect the current offset of the dragger from its local origin. The application programmer should connect this field to the appropriate node(s) in the scene graph (e.g., a transformation node) to make the object follow the dragger's movement.

All other public methods are inherited from the base class SoDragger.
