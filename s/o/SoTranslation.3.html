Detailed Description

The SoTranslation node translates its children's scene graph.

The translation is specified by the translation field.

The node influences traversal of the scene graph.

The node is often used to position objects in the scene.

Example:

#include <Inventor/SbLinear.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoCube.h>
#include <Inventor/nodes/SoTranslation.h>

// Create a scene graph
SoSeparator *root = new SoSeparator;
root->ref();

// Create a translation node
SoTranslation *myTranslation = new SoTranslation;
myTranslation->translation.setValue(SbVec3f(10.0, 5.0, 0.0)); // Translate 10 units in X and 5 in Y
root->addChild(myTranslation);

// Add a cube to be translated
root->addChild(new SoCube);

// ... render root ...
