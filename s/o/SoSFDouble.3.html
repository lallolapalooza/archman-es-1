NAME

SoSFDouble — Single-precision floating-point field

SYNOPSIS

#include <Inventor/fields.h>

SoSFDouble

Detailed Description

This field type stores a single-precision floating-point value.

The SoSFDouble field is used by SoNode nodes to hold and manage single-precision floating-point values.

To use this field, you must include the <Inventor/fields.h> header. When creating a new node class, you must also include the SoSFDouble field in the field definitions of your node class.

For example:

SFDouble     myDoubleField;

You can then set and get the value of the field using the setValue() and getValue() methods, respectively:

myDoubleField.setValue(3.14);
float value = myDoubleField.getValue();

The SoSFDouble field is a subclass of SoField.

It is recommended to use SoSFFloat instead of SoSFDouble in new code, as single-precision floating-point values are typically more appropriate for graphics applications.

The SoSFDouble field is automatically initialized by the SoDB library when the Coin library is initialized. This initialization process sets up the type system for all field types, including SoSFDouble.
