Descripción detallada

La clase SoMFMatrix es un contenedor para valores SbMatrix.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar matrices.

Detailed Description

Multiple-value field holding SbMatrix objects.

This field type is used for fields that contain an arbitrary number of SbMatrix objects. It is the multiple-value equivalent of the SoSFMatrix field type.
