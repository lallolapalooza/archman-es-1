Descripción detallada

La clase SoRayPickAction realiza la intersección de rayos con grafos de escena.

Para la interacción con la geometría del grafo de escena, es necesario poder realizar pruebas de intersección para rayos. Esta funcionalidad la proporciona la clase SoRayPickAction.

SoRayPickAction se puede utilizar para pasar rayos arbitrarios a través de la escena para detecciones de intersección, utilizando el método setRay().

Dado que una operación muy común es verificar intersecciones a lo largo del rayo desde el cursor del ratón al hacer clic con el ratón, también contiene métodos de conveniencia

métodos para configurar un rayo desde el plano cercano hasta el plano lejano a partir de las coordenadas del cursor del ratón en 2D. Consulte los métodos setPoint() y setNormalizedPoint(). A continuación, se presenta un ejemplo de uso sencillo para este caso.

Tenga en cuenta que un error común al utilizar una acción de rayo para la selección e intersección desde un punto bajo el cursor del ratón después de un clic de ratón es que se intenta aplicarla a un grafo de escena que no contiene una cámara configurada *explícitamente* por el programador de la aplicación. Sin una cámara como parte del recorrido, la acción de rayo no sabe a través de qué volumen de vista enviar el rayo.

A este respecto, tenga en cuenta que la llamada a getSceneGraph() en las clases de visor de las bibliotecas So* devolverá la raíz del grafo de escena proporcionado por el usuario, no la raíz del grafo de escena interna "real" utilizada por el visor (que siempre debe contener un nodo de cámara). Por lo tanto, las selecciones de rayos realizadas desde el código de la aplicación fallarán al hacer esto:

// inicializando el grafo de escena del visor
SoSeparator * root = new SoSeparator;
root->ref();
SoEventCallback * ecb = new SoEventCallback;
ecb->addEventCallback(SoMouseButtonEvent::getClassTypeId(), event_cb, viewer);
root->addChild(ecb);
root->addChild(new SoCone);
viewer->setSceneGraph( root );
// -- [snip] -------------------------
// intentando la selección por rayo en el método de devolución de llamada event_cb()
SoRayPickAction rp( viewer->getViewportRegion() );
rp.setPoint(mouseevent->getPosition());
rp.apply(viewer->getSceneGraph());
// ERROR: los resultados no serán los esperados, ya que ninguna cámara
// formaba parte del "grafo de escena del usuario"

Mientras que esta es la forma correcta de hacerlo:

// inicializando el grafo de escena del visor
SoSeparator * root = new SoSeparator;
root->ref();
// Es necesario configurar nuestra propia cámara en el "grafo de escena del usuario", o de lo contrario
// la acción de selección por rayo fallará porque la cámara está oculta en la
// raíz específica del visor del grafo de escena.
SoPerspectiveCamera * pcam = new SoPerspectiveCamera;
root->addChild(pcam);
SoEventCallback * ecb = new SoEventCallback;
ecb->addEventCallback(SoMouseButtonEvent::getClassTypeId(), event_cb, viewer);
root->addChild(ecb);
root->addChild(new SoCone);
viewer->setSceneGraph( root );
pcam->viewAll( root, viewer->getViewportRegion() );
// -- [snip] -------------------------
// intentando la selección por rayo en el método de devolución de llamada event_cb()
SoRayPickAction rp( viewer->getViewportRegion() );
rp.setPoint(mouseevent->getPosition());
rp.apply(viewer->getSceneGraph());

O si desea la comodidad de que el visor configure una cámara implícitamente, puede obtener la raíz del grafo de escena "completo" simplemente llamando a:

SoNode * realroot = viewer->getSceneManager()->getSceneGraph();

Detailed Description

This is the action class for ray picking. It is used to find objects in the scene graph that are intersected by a ray originating from the camera.

The rays are defined in screen space, or can be specified in world space.

SoRayPickAction inherits the general picking logic from SoPickAction, but adds ray-specific functionality. Typically, applications will create an instance of this class, configure it with a camera or a specific ray, and then apply it to the scene graph.

A typical use case:

  // Create an action with the given camera
  SoRayPickAction *rayPickAction = new SoRayPickAction(myCamera);

  // Optionally adjust the pick region
  rayPickAction->setRegion(SbBox2f(SbVec2f(-0.1, -0.1), SbVec2f(0.1, 0.1)));

  // Apply the action to the scene graph
  rayPickAction->apply(mySceneGraph);

  // Check if anything was hit
  if (rayPickAction->getNumPickedPoints() > 0) {
    // Get the first picked point
    const SoPickedPoint *pp = rayPickAction->getPickedPoint(0);
    // ... use pp ...
  }

  // Clean up
  delete rayPickAction;

The action can be configured to pick objects within a specific screen-space region (using setObjectSpace()) or with a specific ray (using computeWorldSpaceRay()).

void SoRayPickAction::beginTraversal (SoNode * node) [protected], [virtual]

This virtual method is called from SoAction::apply(), and is the entry point for the actual scene graph traversal.

It can be overridden to initialize the action at traversal start, for specific initializations in the action subclasses inheriting SoAction.

Default method just calls traverse(), which any overridden implementation of the method must do too (or call SoAction::beginTraversal()) to trigger the scene graph traversal.
