Descripción Detallada

La clase SoMFVec2s es un contenedor para vectores SbVec2s.

Este campo se utiliza cuando los nodos, motores u otros contenedores de campos necesitan almacenar una matriz de vectores de dos elementos.

Este campo es una clase de campo múltiple, lo que significa que puede almacenar cero o más valores. Se utiliza para campos como coordinates en SoIndexedFaceSet.

Cada uno de los valores de este campo es un SbVec2s, un vector de 2 elementos que almacena coordenadas de enteros de 16 bits.

Este campo se puede construir o inicializar con una matriz de valores SbVec2s, o con una matriz de coordenadas x e y separadas.

Por ejemplo, para configurar el campo coordinates de un nodo SoFaceSet con tres puntos:

    SbVec2s coords[] = { SbVec2s(10, 20), SbVec2s(30, 40), SbVec2s(50, 60) };
    myFaceSet->coordinates.setValues(0, 3, coords);

O usando valores separados:

    short xcoords[] = { 10, 30, 50 };
    short ycoords[] = { 20, 40, 60 };
    myFaceSet->coordinates.setValues(0, 3, xcoords, ycoords);

Para establecer un solo valor:

    myFaceSet->coordinates.set1Value(1, SbVec2s(35, 45));

Para obtener todos los valores:

    int num = myFaceSet->coordinates.getNum();
    const SbVec2s *coords = myFaceSet->coordinates.getValues(0);
    for (int i = 0; i < num; i++) {
      // Procesa coords[i].x y coords[i].y
    }

Para obtener un solo valor:

    SbVec2s val = myFaceSet->coordinates[1];

Los métodos startEditing() y finishEditing() se pueden usar para acceder a los valores subyacentes de forma más eficiente. Esto es útil si se va a modificar un gran número de valores. Los valores deben ser accedidos usando sólo el puntero devuelto por startEditing() hasta que se llama a finishEditing().

    SbVec2s *ptr = (SbVec2s *)myFaceSet->coordinates.startEditing();
    // Modifica *ptr, *(ptr+1), etc.
    myFaceSet->coordinates.finishEditing();

Los métodos setValuesPointer() se pueden usar para que el campo apunte a una matriz externa de valores. El campo no copiará los valores, sino que simplemente los usará. Es responsabilidad del usuario asegurarse de que la matriz externa permanezca válida mientras el campo la esté utilizando. La versión que toma un puntero short * toma una matriz de valores interleaved (x, y, x, y, ...).

Description

This field type is used to store arrays of SbVec2s (2-element short vectors).

Use the setValuesPointer() method to share application data through this field. See SoMField documentation for information on how to use this function.

See also

SbVec2s, SoSFVec2s Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.

Since

Coin 2.5
