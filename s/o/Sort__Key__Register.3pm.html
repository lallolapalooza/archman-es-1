Sort::Key::Register(3) Documentación de Perl aportada por el usuario Sort::Key::Register(3)

NOMBRE

Sort::Key::Register - indicar a Sort::Key cómo ordenar nuevos tipos de datos.

SINOPSIS

use Sort::Key::Register Person =>
    sub { $_->surname, $_->name },
    qw(string string);
use Sort::Key::Register 'Color::Component' => 'integer';
use Sort::Key::Register Color =>
    sub { $_->R, $_->G, $_->B },
    ('Color::Component') x 3;

DESCRIPCIÓN

Sort::Key::Register permite registrar nuevos tipos de datos con Sort::Key para que puedan ordenarse como los tipos soportados de forma nativa.

Funciona como un módulo pragma y no exporta ninguna función; toda su funcionalidad se proporciona a través de "use":

use Sort::Key::Register ...

Para evitar colisiones entre módulos que registran tipos con el mismo nombre, debes calificarlos con el nombre del paquete.

use Sort::Key::Register 'MyPkg::foo' => sub { $_ }, '-int';
# o usando __PACKAGE__:
use Sort::Key::Register __PACKAGE__, sub { $_ }, '-int';

USO

use Sort::Key::Register $name => \&multikeygen, @keytypes;
registra el tipo $name.

&multikeygen es la función de extracción de claves múltiples para el tipo y @keytypes son los tipos de las claves extraídas.

use Sort::Key::Register $name => $keytype;
este 'use' es útil para tipos simples que se ordenan como otro tipo ya registrado, quizás cambiando la dirección del ordenamiento (ascendente o descendente).

VER TAMBIÉN

Sort::Key, Sort::Key::Maker.
