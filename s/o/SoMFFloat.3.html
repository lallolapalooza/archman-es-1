Descripción Detallada

La clase SoMFFloat es un contenedor para valores de punto flotante.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un grupo de múltiples valores de punto flotante.

Este campo admite el intercambio de datos de la aplicación a través de un método setValuesPointer(). Consulte la documentación de SoMField para obtener información sobre cómo utilizar esta función.

DESCRIPTION

This field holds a single floating-point value.

To set the value of the field, you can use either setValue() to set the first (and only) value, or set1Value().

To get the value, use getValue().

For more information on the functionality of this field, see SoMField and SoField.
