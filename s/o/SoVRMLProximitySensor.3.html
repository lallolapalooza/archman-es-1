Detailed Description

The SoVRMLProximitySensor node detects when the viewer enters or exits a specified rectangular region in 3D space. It is part of the VRML-97 sensor nodes.

The region is defined by the center and size fields. The center field specifies the center of the region, and the size field specifies the extent of the region along each axis.

When the viewer enters the region, the isActive field is set to TRUE, and the enterTime event is generated. When the viewer exits the region, the isActive field is set to FALSE, and the exitTime event is generated.

Additionally, if the viewer is inside the region and its position or orientation changes, the position_changed and orientation_changed events are generated, respectively. These events provide the new position and orientation of the viewer relative to the sensor's coordinate system.

The sensor can be enabled or disabled using the enabled field. If disabled, it will not generate any events.

The coordinate system for the center and size fields is inherited from the parent node. The position_changed and orientation_changed events are also reported in the parent's coordinate system.

The SoVRMLProximitySensor node is typically used to trigger actions or animations when the viewer approaches or enters a certain area of the scene.
