Descripción detallada

La clase SoDetail es la superclase de todas las clases que almacenan información detallada sobre formas particulares.

La información detallada sobre las formas se utiliza en relación con las acciones de selección en Coin. Típicamente contienen la información relevante sobre qué parte particular de la forma intersectó un rayo de selección.

virtual SoDetail * SoDetail::copy (void ) const [virtual puro]

Devuelve una copia profunda de sí mismo.

Tenga en cuenta que si la biblioteca Coin se ha compilado como DLL en Microsoft Windows y utiliza este método desde código de aplicación, debe asegurarse de que tanto la DLL de Coin como el ejecutable de la aplicación utilicen la misma instancia de la biblioteca C Run-Time (CRT). De lo contrario, obtendrá corrupción de la memoria heap al liberar las instancias devueltas, lo que eventualmente conducirá a fallos misteriosos.

virtual SoType SoDetail::getTypeId (void ) const [virtual puro]

Devuelve la identificación del tipo de un detalle derivado de una clase que hereda de SoDetail. Esto se utiliza para la verificación de tipos en tiempo de ejecución y la conversión "hacia abajo".

Ejemplo de uso:

void fuhbear(SoDetail * detail)
{
  if (detail->getTypeId() == SoFaceDetail::getClassTypeId()) {
    // conversión segura hacia abajo, se conoce el tipo
    SoFaceDetail * facedetail = (SoFaceDetail *)detail;
  }
  return; // ignorar si no es un SoFaceDetail
}

Para los programadores de aplicaciones que deseen extender la biblioteca con nuevas clases de detalle: este método debe ser sobrescrito en todas las subclases. Esto se hace típicamente como parte de la configuración del sistema de tipos completo para las clases de extensión, lo que generalmente se logra utilizando las macros predefinidas disponibles a través de Inventor/nodes/SoSubDetail.h: SO_DETAIL_SOURCE y SO_DETAIL_INIT_CLASS.

Implementado en SoConeDetail, SoCubeDetail, SoCylinderDetail, SoFaceDetail, SoLineDetail, SoNodeKitDetail, SoPointDetail y SoTextDetail.
