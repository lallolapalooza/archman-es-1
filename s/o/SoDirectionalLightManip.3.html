Detailed Description

The SoDirectionalLightManip class is used to manipulate SoDirectionalLight nodes.

A manipulator is used by replacing the node you want to edit in the graph with the manipulator. Draggers are used to manipulate the node. When manipulation is finished, the node is put back into the graph, replacing the manipulator.

void SoDirectionalLightManip::copyContents(const SoFieldContainer *from, SbBool copyconnections) [protected], [virtual]

Realiza una copia profunda de todos los datos de from en esta instancia, *excepto* las referencias externas del grafo de escena si copyconnections es FALSE.

Este es el método que deben anular las subclases de nodo de extensión / motor / dragger / lo que sea que necesiten tener en cuenta los datos internos que no se manejan automáticamente.

Para copiar nodos desde el código de la aplicación, no debes invocar esta función directamente, sino llamar a la función SoNode::copy():

SoNode * mynewnode = templatenode->copy();

Lo mismo ocurre con los motores.

Asegúrate de que cuando anules el método copyContents() en tu clase de extensión, también llames a la superclase principal en la jerarquía de herencia, ya que copyContents() en, por ejemplo, SoNode y SoFieldContainer realiza un trabajo importante. Debería ser algo así:

void
MyCoinExtensionNode::copyContents(const SoFieldContainer * from,
                                  SbBool copyconnections)
{
  // Deja que las superclases principales hagan lo suyo (copiar campos,
  // copiar nombre de instancia, etc.)
  SoNode::copyContents(from, copyconnections);
  // [..luego copia los datos internos..]
}

NAME

SoDirectionalLightManip - manipular una luz direccional

SYNOPSIS

<Coin>
#include <Inventor/manips/SoDirectionalLightManip.h>

Detailed Description

Permite la manipulación de una luz direccional. El manipulador se comporta como un objeto de rotación y traslación. La luz direccional se orienta a lo largo del eje Z negativo del manipulador. La intensidad, el color y la atenuación de la luz se ajustan mediante los nodos de control de luz del manipulador.
