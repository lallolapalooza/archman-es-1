SOAP::Client(3) Documentación de Perl contribuida por el usuario SOAP::Client(3)

NOMBRE

SOAP::Client - existe puramente como una superclase para las clases cliente declaradas por los diversos módulos de transporte de SOAP::Lite.

DESCRIPCIÓN

La clase SOAP::Client existe puramente como una superclase para las clases cliente declaradas por los diversos módulos de transporte de SOAP::Lite. Los métodos que proporciona son todos ellos simples accesores; devuelven el valor actual cuando se llaman sin argumentos o establecen el valor del atributo y devuelven la referencia del objeto cuando se llaman con un argumento. Estos atributos incluyen:

MÉTODOS

código, mensaje, estado
Almacena el código de respuesta, el mensaje y el estado del intento de envío más reciente. Para algunos protocolos, como FTP, se usa el mismo valor para los tres debido a la falta de un detalle más granular (el valor predeterminado es asegurar que los tres atributos contengan datos, aunque sean redundantes). Otros protocolos (como HTTP) tienen valores distintos en cada uno.
endpoint
Identifica el punto final actual al que se envían los mensajes. Esto debe coincidir con el valor del método de transporte de la clase SOAP::Transport, pero establecer esto no se propaga al objeto de transporte. Es mejor usar el objeto de transporte (o el acceso directo a través del objeto SOAP::Lite en sí) al establecer esto.
is_success
El éxito o fracaso de la transmisión más reciente se anota aquí como un valor booleano.
options
El atributo options mantiene una referencia a una tabla hash de opciones adicionales y sus valores. En la actualidad, solo una opción es utilizada por cualquiera de los módulos de transporte:
compress_threshold
El valor de esta opción debe ser un valor numérico. Si se establece y si la biblioteca Compress::Zlib está disponible, los mensajes cuyo tamaño en bytes exceda este valor se comprimirán antes de enviarlos. Ambos extremos de la conversación deben tenerla habilitada.

Se pueden definir otras opciones utilizando este mecanismo. Tenga en cuenta que establecer las opciones utilizando este accesorio requiere pasar una referencia de hash completa. Para establecer solo uno o algunos valores, considere recuperar el valor de referencia actual y usarlo para establecer la(s) clave(s).
