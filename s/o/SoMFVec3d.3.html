Description

This is a field that contains an array of 3-element double-precision vectors (SbVec3d). Fields are used to store and pass data in the scene graph.

This field class is used in Coin to store field values that can contain any number of vector elements. The elements are always double-precision 3-element vectors.

It is not generally useful to have fields that only contain a fixed number of elements. For example, if you wanted to store a list of points in a scene graph, you would want to use a multiple field. The alternative to a multiple field is a single field, which can only contain one value.

See also

SbVec3d, SoSFVec3d, SoMFVec3f
