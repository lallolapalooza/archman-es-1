Descripción detallada

La clase SoSFColor es un contenedor para un valor SbColor.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único valor de color (es decir, Rojo + Verde + Azul).

Los campos de este tipo almacenan su valor en el archivo como un triple componente "R G B", donde cada componente de color tiene un valor entre 0.0 y 1.0.
