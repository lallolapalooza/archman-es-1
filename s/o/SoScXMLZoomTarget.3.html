Descripción Detallada

Servicio de destino de eventos SCXML para comportamiento de zoom.

Eventos:

x-coin-navigation.Zoom.*

{ BEGIN _sessionid {string} mouseposition {SbVec2f}

UPDATE _sessionid {string} mouseposition {SbVec2f}

END _sessionid {string} mouseposition {SbVec2f} }

ZOOM _sessionid factor {float}

ZOOM_IN _sessionid {string} [factor] {float=1.2} [count] {float=1}

ZOOM_OUT _sessionid {string} [factor] {float=1.2} [count] {float=1}

RESET _sessionid {string}

NAME

SoScXMLZoomTarget — ScXML zoom target node.

SYNOPSIS

All methods in this class are static, and must be called with the class name followed 
by the :: operator.

SoScXMLZoomTarget();

Detailed Description

ScXML zoom target node.

This node represents a zoom target in ScXML. It is used to control the zooming behavior of a camera within the scene graph.

Member Function Documentation

void SoScXMLZoomTarget::reset (SoCamera * camera) [static]

This function resets the zooming attributes of the camera to the default values.

SbBool SoScXMLZoomTarget::processOneEvent (const ScXMLEvent * event) [protected], [virtual]

This function processes one event. The base class implementation does nothing.

Reimplemented from ScXMLEventTarget.
