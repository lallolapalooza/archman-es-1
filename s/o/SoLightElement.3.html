Detailed Description

This element is used by beam / path tracing applications to keep track of the lights in the scene.

It is used to store the list of active lights and their corresponding world-to-view-reference transformation matrices.

This element is automatically pushed/popped by the SoNode::render method, so you don't need to do it manually.

It is also automatically updated when the scene graph is traversed, so you don't need to update it yourself.

Use the static methods of this class to get information about the lights in the scene.
