Descripción Detallada

La clase SoVRMLVisibilitySensor genera eventos según la visibilidad.

La documentación detallada de la clase se toma verbatim de la estándar VRML97 (ISO/IEC 14772-1:1997). Es propiedad del Web3D Consortium y se utiliza con el permiso del Consorcio:

VisibilitySensor {
  exposedField SFVec3f center   0 0 0      # (-,)
  exposedField SFBool  enabled  TRUE
  exposedField SFVec3f size     0 0 0      # [0,)
  eventOut     SFTime  enterTime
  eventOut     SFTime  exitTime
  eventOut     SFBool  isActive
}

El nodo VisibilitySensor detecta cambios de visibilidad de un cubo rectangular mientras el usuario navega el mundo. VisibilitySensor se utiliza comúnmente para detectar cuando el usuario puede ver un objeto o región específica en el escenario para activar o desactivar cierto comportamiento o animación. El propósito es a menudo atraer la atención del usuario o mejorar el rendimiento.

El campo enabled activa y desactiva el nodo VisibilitySensor. Si enabled está establecido en FALSE, el nodo no envía eventos. Si está establecido en TRUE, el nodo detecta cambios en el estado de visibilidad del cubo especificado y envía eventos a través del evento isActive. Un evento verdadero se envía a isActive cuando cualquier parte del cubo afecta la vista renderizada. Un evento falso se envía cuando el cubo no tiene efecto en la vista. Los navegadores garantizan que, si isActive es FALSE, el cubo no tiene ningún efecto en la vista renderizada. Los navegadores pueden errar liberadamente cuando isActive es TRUE. Por ejemplo, el cubo puede afectar la renderización.

Los campos expuestos center y size especifican la ubicación del centro del objeto en el espacio de objeto y los extremos del cubo (es decir, ancho, altura y profundidad). El nodo VisibilitySensor se ve afectado por las transformaciones jerárquicas de sus padres. Los componentes del campo size deben ser mayores o iguales a cero.

El evento enterTime se genera cuando se genera el evento isActive TRUE, y el evento exitTime cuando se genera el evento isActive FALSE. Un nodo VisibilitySensor leído de un archivo VRML generará eventos isActive TRUE y enterTime si el sensor está activo y el cubo de visibilidad es visible. Un nodo VisibilitySensor insertado en la jerarquía de transformación generará eventos isActive TRUE y enterTime si el sensor está activo y el cubo de visibilidad es visible. Un nodo VisibilitySensor removido de la jerarquía de transformación generará eventos isActive FALSE y exitTime si el sensor está activo y el cubo de visibilidad es visible.

Cada nodo VisibilitySensor se comporta independientemente de todos los otros nodos VisibilitySensor. Cada nodo VisibilitySensor activo que sea afectado por el movimiento del usuario recibe y envía eventos, lo que puede resultar en múltiples nodos VisibilitySensor recibiendo y enviando eventos simultáneamente. A diferencia de los nodos TouchSensor, no existe la noción de un nodo VisibilitySensor más bajo en la jerarquía de escena "capturando" eventos. Los nodos VisibilitySensor duplicados (es decir, DEF/USE) utilizan la unión de todos los cubos definidos por sus instancias. Un nodo instanciado de VisibilitySensor debe detectar cambios de visibilidad para todas las instancias del cubo y enviar eventos adecuadamente.

NAME

SoVRMLVisibilitySensor - A visibility sensor node.

SYNOPSIS

       #include <Inventor/nodes/SoVRMLVisibilitySensor.h>

Inherits from SoVRMLSensor.

Detailed Description

This node defines a visibility sensor. A visibility sensor detects when it enters or exits the view volume of the viewer. When the sensor is activated, it generates an enterTime event. When the sensor is deactivated, it generates an exitTime event. This sensor is similar to the SoVisibilitySensor node, but it is defined by a rectangular cuboid volume, instead of a bounding box.
