NAME

SoVRMLVertexPoint — VRML VertexPoint node class

SYNOPSIS

#include <VRML/vrmlnodes.h>

Detailed Description

The SoVRMLVertexPoint node is a base class for nodes which contain vertex coordinate information.

Its subclasses, for example SoVRMLPointSet, determine what geometry to render based on the SoVRMLCoordinate node provided via the coord field.

Fields

SoSFNode coord
Should contain an SoVRMLCoordinate node.
SoSFNode color
Can contain an SoVRMLColor node when color per point is needed.

void SoVRMLVertexPoint::computeBBox (SoAction * action, SbBox3f & box, SbVec3f & center) [protected], [virtual]

Implemented by SoShape subclasses to let the SoShape superclass know the exact size and weighted center point of the shape's bounding box.

The bounding box and center point should be calculated and returned in the local coordinate system.

The method implements action behavior for shape nodes for SoGetBoundingBoxAction. It is invoked from SoShape::getBoundingBox(). (Subclasses should not override SoNode::getBoundingBox().)

The box parameter sent in is guaranteed to be an empty box, while center is undefined upon function entry.

Implements SoShape.
