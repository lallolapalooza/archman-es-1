Detailed Description

This node is a separator node that highlights scene graph objects when the mouse pointer is located over them.

This node must be used in conjunction with an SoEventCallback node, or have its children perform event handling. The event handling code within this node will query the scene graph to find the object under the mouse pointer.

SoLocateHighlight can be configured to use one of three highlighting styles: EMISSIVE, INVERT, and OUTLINE.

When using the EMISSIVE style, the node injects an SoMaterial node into the scene graph, setting its diffuse color to the value of the color field. If the node has no children, it is drawn using the material defined by the node itself.

The INVERT style uses an SoGLLazyPBuffer to render the scene, and then uses glLogicOp to invert the colors of the object under the mouse pointer.

The OUTLINE style simply draws an outline around the object under the mouse pointer.

The mode field can be set to either AUTO or MANUAL. If set to AUTO, the node will automatically track the mouse pointer and highlight objects. If set to MANUAL, the application must explicitly call the SoLocateHighlight::turnOffCurrentHighlight() or SoLocateHighlight::redrawHighlighted() methods to update the highlighting.

In order to use SoLocateHighlight, you must set the appropriate render pass by calling SoGLRenderAction::setMethod(). The method identifier for SoLocateHighlight is SoLocateHighlight::LOCATE_HIGHLIGHT.

A common usage of this node would be to place it in the scene graph at the root, and then add children. The children can be any Coin nodes, and SoLocateHighlight will highlight them individually.

Member Enumeration Documentation

SoLocateHighlight::Method

The enumeration Method defines the various highlight methods that can be applied to objects.

INVALID
Indicates an invalid or unset method.
LOCATE_HIGHLIGHT
The default highlighting method. This method typically applies an emissive material to the highlighted object.
LOCATE_INVERT
Highlights the object by inverting its colors. This is often achieved using logic operations in OpenGL.
LOCATE_OUTLINE
Highlights the object by drawing an outline around it. This method typically uses OpenGL line drawing primitives.

SoLocateHighlight::Mode

The enumeration Mode specifies how the highlighting should be performed.

AUTO
In automatic mode, the highlighting is updated automatically based on mouse events. The node tracks the mouse cursor and applies highlighting to the object currently under the cursor.
MANUAL
In manual mode, the highlighting is not automatically updated. The application is responsible for explicitly triggering updates using methods like redrawHighlighted() or turnOffCurrentHighlight().

SoLocateHighlight::Style

The enumeration Style defines the visual appearance of the highlighting.

EMISSIVE
The highlighted object appears to emit light. This is typically achieved by adding an emissive component to the object's material properties.
INVERT
The colors of the highlighted object are inverted. This creates a negative-image effect.
OUTLINE
A distinct outline is drawn around the boundary of the highlighted object.

void SoLocateHighlight::GLRenderBelowPath (SoGLRenderAction * action) [virtual]

SGI Open Inventor v2.1 obsoleted support for SoGLRenderAction::addMethod(). Instead, GLRender() might be called directly, and to optimize traversal, the SoSeparator node calls GLRenderBelowPath whenever the path code is BELOW_PATH or NO_PATH (path code is guaranteed not to change). To be compatible with SGI's Inventor (and thereby also TGS') we have chosen to follow their implementation in this respect.

SoSeparator::GLRenderBelowPath() does not traverse its children using SoChildList::traverse(), but calls GLRenderBelowPath() directly for all its children.
