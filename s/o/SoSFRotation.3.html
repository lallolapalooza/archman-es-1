Descripción Detallada

La clase SoSFRotation es un contenedor para una SbRotation.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar una única definición de rotación.

Los campos de este tipo almacenan su valor en el archivo como un vector de eje de rotación más un ángulo de rotación: "axis0 axis1 axis2 angle".

Tenga en cuenta que hay un error muy común que es fácil de cometer al establecer el valor de un campo SoSFRotation, y es usar inadvertidamente el constructor incorrecto de SbRotation. Este ejemplo debería aclarar el problema:

mytransformnode->rotation.setValue(0, 0, 1, 1.5707963f);

El programador claramente intenta establecer una rotación de PI/2 alrededor del eje Z, pero esto fallará, ya que el constructor de SbRotation invocado anteriormente es el que toma como argumentos los 4 flotantes de un cuaternión. Lo que el programador casi con seguridad quería hacer era usar el constructor de SbRotation que toma un vector de rotación y un ángulo de rotación, que se invoca de la siguiente manera:

mytransformnode->rotation.setValue(SbVec3f(0, 0, 1), 1.5707963f);

Detailed Description

This field type holds a single rotation value. A rotation is represented internally by an SbRotation object, which is a unit quaternion.

The field is automatically created by the scene graph node that contains it. Use the standard SoField::setValue() and SoField::getValue() methods to set and get the value.

The getValue() and setValue() methods allow you to get and set the rotation as an axis and an angle. The other setValue() methods allow you to set the rotation from a quaternion representation.
