Descripción detallada

La clase SoSFUShort es un contenedor para un valor entero sin signo corto.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar un único valor de entero corto sin signo.

Detailed Description

short field for Coin Inventor Nodes.

A short field is an instance of the SoSFUShort class. It holds an unsigned short value.

To include the definition of this class, use the following line:

#include <Inventor/fields/SoSFUShort.h>

The SoSFUShort class defines the interface for an unsigned short field. This field is used to hold unsigned short values within Inventor nodes.

An instance of this class is created when a node is initialized. The value is initialized to zero by default.

Use the setValue method to set the value of the field. Use the getValue method to get the value of the field.

The following code snippet shows how to set the value of a short field:

// Assume myNode is an instance of a node with an unsigned short field named "myField"
myNode->myField.setValue(123);

The following code snippet shows how to get the value of a short field:

// Assume myNode is an instance of a node with an unsigned short field named "myField"
unsigned short value = myNode->myField.getValue();
