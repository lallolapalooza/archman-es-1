Descripción Detallada

La clase SoMFBool es un contenedor para valores SbBool.

Este campo se utiliza donde los nodos, motores u otros contenedores de campos necesitan almacenar múltiples valores booleanos de encendido/apagado o VERDADERO/FALSO.

Este campo admite el intercambio de datos de la aplicación a través de un método setValuesPointer(). Consulte la documentación de SoMField para obtener información sobre cómo utilizar esta función.
