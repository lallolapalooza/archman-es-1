Descripción Detallada

La clase SoWriteAction escribe un grafo de escena en un archivo.

Cuando se aplica a una escena, esta acción escribe su contenido en el flujo contenido dentro de una instancia de SoOutput. Este puede ser un archivo, un búfer de memoria o un manejador de archivos del sistema como stdout, por ejemplo.

Se debe escribir *toda* la información considerada parte del grafo de escena, incluyendo no solo los nodos, sino también los valores de campo de los nodos, los campos globales (al menos aquellos con conexiones dentro de la escena a la que se aplica la acción), los motores en la escena, las rutas, etc.

La escena se escribe en el formato de archivo Open Inventor. Los archivos en este formato pueden ser analizados en sus estructuras de grafo de escena utilizando el método SoDB::readAll() (SoDB también contiene algunos otros métodos de importación que puedes usar).

Aquí hay un ejemplo de uso completo e independiente que muestra cómo escribir un grafo de escena en un búfer de memoria:

#include <Inventor/SoDB.h>
#include <Inventor/actions/SoWriteAction.h>
#include <Inventor/nodes/SoCone.h>
#include <Inventor/nodes/SoSeparator.h>
static char * buffer;
static size_t buffer_size = 0;
static void *
buffer_realloc(void * bufptr, size_t size)
{
  buffer = (char *)realloc(bufptr, size);
  buffer_size = size;
  return buffer;
}
static SbString
buffer_writeaction(SoNode * root)
{
  SoOutput out;
  buffer = (char *)malloc(1024);
  buffer_size = 1024;
  out.setBuffer(buffer, buffer_size, buffer_realloc);
  SoWriteAction wa(&out);
  wa.apply(root);
  SbString s(buffer);
  free(buffer);
  return s;
}
int
main(int argc, char ** argv)
{
  SoDB::init();
  SoSeparator * root = new SoSeparator;
  root->ref();
  root->addChild(new SoCone);
  SbString s = buffer_writeaction(root);
  (void)fprintf(stdout, "%s\n", s.getString());
  root->unref();
  return 0;
}

Description

This class is used to write a scene graph to an output stream. The scene graph is written in the Open Inventor file format.

To write a scene graph, you create an instance of SoWriteAction and associate it with an SoOutput object. Then you call the apply() method with the root node of the scene graph you want to write.

    SoWriteAction writeAction;
    SoOutput output;
    output.openFile( "my_scene.iv" );
    writeAction.setOutput( &output );
    writeAction.apply( rootNode );
    output.closeFile();

The SoWriteAction will traverse the scene graph and write each node and its fields to the output stream. The action automatically handles shared nodes and nodes that are not connected to the rest of the scene graph.

The SoWriteAction can also be used to write a scene graph to memory (an SoMemoryStorage object) or to a standard C++ output stream.

Constructor & Destructor Documentation

This section describes the constructor and destructor of the SoWriteAction class. Note that there are no explicit constructors or destructors defined in the public API. The default constructor and destructor provided by the C++ compiler are sufficient for most use cases. The class inherits from SoAction, so its constructor and destructor are implicitly called.

void SoWriteAction::beginTraversal (SoNode * node) [protected], [virtual]

This virtual method is called from SoAction::apply(), and is the entry point for the actual scene graph traversal.

It can be overridden to initialize the action at traversal start, for specific initializations in the action subclasses inheriting SoAction.

Default method just calls traverse(), which any overridden implementation of the method must do too (or call SoAction::beginTraversal()) to trigger the scene graph traversal.
