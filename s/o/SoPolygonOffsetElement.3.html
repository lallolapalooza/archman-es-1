Detailed Description

This element is used to control the polygon offset functionality. This feature can be used to render polygons slightly closer or farther from the viewpoint, which can help to avoid Z-fighting.

The SoPolygonOffsetElement uses two parameters, factor and units, to compute the offset.

  • The factor parameter is multiplied by the polygon's slope to determine the offset amount. A positive factor will offset polygons away from the viewer, while a negative factor will offset them towards the viewer.
  • The units parameter is multiplied by a small constant value to determine the offset amount. This allows polygons with the same slope to be offset by the same amount, even if they are drawn at different depths.

The SoPolygonOffsetElement also has a style parameter, which can be set to FILLED, LINE, or POINT. This determines which polygon primitives the offset will be applied to.

Finally, the SoPolygonOffsetElement has an active parameter, which can be set to TRUE or FALSE. This enables or disables the polygon offset functionality.
