Specio::Subs(3) Documentación de Perl aportada por el usuario Specio::Subs(3)

NOMBRE

Specio::Subs - Crea subrutinas de validación y coerción a partir de tipos Specio

VERSIÓN

versión 0.53

SINOPSIS

use Specio::Subs qw( Specio::Library::Builtins Specio::Library::Perl My::Lib );
if ( is_PackageName($var) ) { ... }
assert_Str($var);
my $person1 = to_Person($var);
my $person2 = force_Person($var);

DESCRIPCIÓN

Este módulo genera un conjunto de subrutinas útiles de validación y coerción para todos los tipos definidos en una o más bibliotecas.

Para usarlo, simplemente importa "Specio::Subs" pasando una lista de uno o más nombres de bibliotecas. Este módulo cargará esas bibliotecas según sea necesario.

Si alguno de los tipos en cualquier biblioteca tiene nombres que no funcionan como parte de un nombre de subrutina de Perl, este módulo lanzará una excepción.

Si tienes instalados Sub::Util o Sub::Name, se utilizará uno de ellos para nombrar las subrutinas generadas.

"EXPORTACIONES"

Las siguientes subrutinas se crean en el paquete importador:

es_$tipo($valor)

Esta subrutina devuelve un booleano que indica si el $valor es válido para el tipo.

asegura_$tipo($valor)

Esta subrutina muere (termina la ejecución) si el $valor no es válido para el tipo.

a_$tipo($valor)

Esta subrutina intenta coaccionar (convertir) $valor al tipo dado. Si no se puede coaccionar, devuelve el $valor original.

Esto solo se crea si el tipo tiene coerciones.

fuerza_$tipo($valor)

Esta subrutina intenta coaccionar (convertir) $valor al tipo dado, y muere (termina la ejecución) si no puede hacerlo.

Esto solo se crea si el tipo tiene coerciones.

API ADICIONAL

Este módulo tiene una subrutina llamada "subs_installed_into". No se exporta pero puede ser llamada por su nombre completamente calificado. Acepta un único argumento, el nombre de un paquete. Devuelve una lista de subrutinas que generó e instaló en el paquete dado, si las hay.

Esto existe para facilitar la escritura de una biblioteca de tipos que combine otras bibliotecas y genere subrutinas de ayuda para exportar todas a la vez.

Ver la documentación de Specio::Exporter para más detalles.
