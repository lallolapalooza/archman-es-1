SPI_PREPARE_CURSOR(3) Documentación de PostgreSQL 18.1 SPI_PREPARE_CURSOR(3)

NOMBRE

SPI_prepare_cursor - prepara una sentencia, sin ejecutarla todavía

SINOPSIS

SPIPlanPtr SPI_prepare_cursor(const char * command, int nargs,
                              Oid * argtypes, int cursorOptions)

DESCRIPCIÓN

SPI_prepare_cursor es idéntico a SPI_prepare, excepto que también permite la especificación de las opciones del planificador para el “cursor”. Esta es una máscara de bits que tiene los valores mostrados en nodes/parsenodes.h para el campo de opciones de DeclareCursorStmt. SPI_prepare siempre toma las opciones del cursor como cero.

Esta función está ahora obsoleta en favor de SPI_prepare_extended.

ARGUMENTOS

const char * command

cadena de comandos

int nargs

número de parámetros de entrada ($1, $2, etc.)

Oid * argtypes

puntero a un array que contiene los OID de los tipos de datos de los parámetros

int cursorOptions

máscara de bits entera de opciones de cursor; cero produce el comportamiento predeterminado

VALOR DE RETORNO

SPI_prepare_cursor tiene las mismas convenciones de retorno que SPI_prepare.

NOTAS

Los bits útiles para establecer en cursorOptions incluyen CURSOR_OPT_SCROLL, CURSOR_OPT_NO_SCROLL, CURSOR_OPT_FAST_PLAN, CURSOR_OPT_GENERIC_PLAN, y CURSOR_OPT_CUSTOM_PLAN. Tenga en cuenta en particular que CURSOR_OPT_HOLD se ignora.
