SPI_CURSOR_FIND(3) Documentación de PostgreSQL 18.1 SPI_CURSOR_FIND(3)

NOMBRE

SPI_cursor_find - buscar un cursor existente por nombre

SINOPSIS

Portal SPI_cursor_find(const char * name)

DESCRIPCIÓN

SPI_cursor_find busca un portal existente por nombre. Esto es principalmente útil para resolver un nombre de cursor devuelto como texto por alguna otra función.

ARGUMENTOS

const char * name

nombre del portal

VALOR DE RETORNO

puntero al portal con el nombre especificado, o NULL si no se encontró ninguno

NOTAS

Tenga en cuenta que esta función puede devolver un objeto Portal que no tiene propiedades similares a un cursor; por ejemplo, podría no devolver tuplas. Si simplemente pasa el puntero del Portal a otras funciones SPI, estas pueden defenderse contra tales casos, pero se debe tener precaución al inspeccionar directamente el Portal.
