Specio::Exporter(3) Documentación de Perl contribuida por el usuario Specio::Exporter(3)

NOMBRE

Specio::Exporter - Clase base para bibliotecas de tipos

VERSIÓN

versión 0.53

SINOPSIS

package MyApp::Type::Library;
use parent 'Specio::Exporter';
use Specio::Declare;
declare( ... );
# más tipos aquí
package MyApp::Foo;
use MyApp::Type::Library

DESCRIPCIÓN

Heredar de este paquete hace que su paquete sea un exportador de tipos. Por defecto, los tipos definidos en un paquete nunca son visibles fuera del paquete. Cuando hereda de este paquete, todos los tipos que define internamente se vuelven disponibles a través de exportaciones.

Los tipos exportados están disponibles a través de la subrutina "t" del paquete importador.

Por defecto, los tipos que su paquete importa no se reexportan:

package MyApp::Type::Library;
use parent 'Specio::Exporter';
use Specio::Declare;
use Specio::Library::Builtins;

En este caso, los tipos proporcionados por Specio::Library::Builtins no se exportan a los paquetes que "use MyApp::Type::Library".

Puede solicitar explícitamente que los tipos se reexporten:

package MyApp::Type::Library;
use parent 'Specio::Exporter';
use Specio::Declare;
use Specio::Library::Builtins -reexport;

En este caso, los paquetes que "use MyApp::Type::Library" obtendrán todos los tipos de Specio::Library::Builtins, así como cualquier tipo definido en "MyApp::Type::Library".

EXPORTACIONES ADICIONALES

Si desea exportar algunas subrutinas adicionales de un paquete que tiene "Specio::Exporter" como padre, defina una sub llamada "_also_export". Esta sub debe devolver una *lista* de subrutinas definidas en su paquete que también deben ser exportadas. Estas subs se exportarán incondicionalmente a cualquier paquete que use su paquete.

COMBINANDO BIBLIOTECAS CON Specio::Subs

Puede combinar la carga de bibliotecas con la generación de subrutinas usando Specio::Subs al usar "_also_export" y "Specio::Subs::subs_installed_into":

package My::Library;
use My::Library::Internal -reexport;
use Specio::Library::Builtins -reexport;
use Specio::Subs qw( My::Library::Internal Specio::Library::Builtins );
sub _also_export {
    return Specio::Subs::subs_installed_into(__PACKAGE__);
}
