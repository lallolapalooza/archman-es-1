Specio::Exception(3) Documentación de Perl aportada por el usuario Specio::Exception(3)

NOMBRE

Specio::Exception - Una clase de excepción para fallos en la restricción de tipos

VERSIÓN

versión 0.53

SINOPSIS

use Try::Tiny;
try {
    $type->validate_or_die($value);
}
catch {
    if ( $_->isa('Specio::Exception') ) {
        print $_->message, "\n";
        print $_->type->name, "\n";
        print $_->value, "\n";
    }
};

DESCRIPCIÓN

Esta clase de excepción es lanzada por Specio cuando falla una verificación de tipo. Emula la API de Throwable::Error, pero no usa ese módulo para evitar añadir una dependencia de Moo.

API

Esta clase proporciona los siguientes métodos:

$excepción->mensaje

El mensaje de error asociado con la excepción.

$excepción->traza_de_pila

Un objeto Devel::StackTrace para la excepción.

$excepción->tipo

El objeto de restricción de tipo contra el cual falló el valor.

$excepción->valor

El valor que falló la verificación de tipo.

$excepción->como_cadena

La excepción como una cadena. Esto incluye el método y la traza de pila.

SOBRECARGA

Esta clase sobrecarga la conversión a cadena para llamar al método "como_cadena".
