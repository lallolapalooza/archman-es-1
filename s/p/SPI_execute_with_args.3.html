Paquete: postgresql

Licencias: PostgreSQL

SPI_EXECUTE_WITH_ARGS(3) Documentación de PostgreSQL 18.1 SPI_EXECUTE_WITH_ARGS(3)

NOMBRE

SPI_execute_with_args - ejecutar un comando con parámetros fuera de línea

SINOPSIS

int SPI_execute_with_args(const char *command,
                          int nargs, Oid *argtypes,
                          Datum *values, const char *nulls,
                          bool read_only, long count)

DESCRIPCIÓN

SPI_execute_with_args ejecuta un comando que puede incluir referencias a parámetros suministrados externamente. El texto del comando se refiere a un parámetro como $n, y la llamada especifica los tipos de datos y los valores para cada símbolo de este tipo. read_only y count tienen la misma interpretación que en SPI_execute.

La principal ventaja de esta rutina en comparación con SPI_execute es que los valores de los datos se pueden insertar en el comando sin tediosos comillas/escapes, y por lo tanto con mucho menos riesgo de ataques de inyección SQL.

Se pueden lograr resultados similares con SPI_prepare seguido de SPI_execute_plan; sin embargo, al usar esta función, el plan de consulta siempre se personaliza para los valores de parámetros específicos proporcionados. Para la ejecución de consultas de un solo uso, se debe preferir esta función. Si el mismo comando debe ejecutarse con muchos parámetros diferentes, cualquiera de los métodos puede ser más rápido, dependiendo del costo de volver a planificar frente al beneficio de planes personalizados.

ARGUMENTOS

const char * command

cadena de comando

int nargs

número de parámetros de entrada ($1, $2, etc.)

Oid * argtypes

una matriz de longitud nargs, que contiene los OID de los tipos de datos de los parámetros

Datum * values

una matriz de longitud nargs, que contiene los valores de los parámetros reales

const char * nulls

una matriz de longitud nargs, que describe cuáles parámetros son nulos

Si nulls es NULL, entonces SPI_execute_with_args asume que ningún parámetro es nulo. De lo contrario, cada entrada de la matriz nulls debe ser ' ' si el valor del parámetro correspondiente no es nulo, o 'n' si el valor del parámetro correspondiente es nulo. (En este último caso, el valor real en la entrada values correspondiente no importa.) Tenga en cuenta que nulls no es una cadena de texto, solo una matriz: no necesita un terminador '\0'.

bool read_only

true para ejecución de solo lectura

long count

número máximo de filas a devolver, o 0 para sin límite

VALOR DE RETORNO

El valor de retorno es el mismo que para SPI_execute.

SPI_processed y SPI_tuptable se establecen como en SPI_execute si se realiza con éxito.
