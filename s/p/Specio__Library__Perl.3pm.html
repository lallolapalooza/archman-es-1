Specio::Library::Perl(3) Documentación de Perl contribuida por el usuario Specio::Library::Perl(3)

NOMBRE

Specio::Library::Perl - Implementa objetos de restricción de tipo para algunas cosas comunes del lenguaje Perl

VERSIÓN

versión 0.53

DESCRIPCIÓN

Esta biblioteca proporciona algunos tipos de cadena adicionales para casos comunes.

NombrePaquete

Un nombre de paquete válido. A diferencia de la restricción "ClassName" de la biblioteca Specio::Library::Builtins, este paquete no necesita ser cargado.

Este tipo permite caracteres Unicode.

NombreMódulo

Igual que "NombrePaquete".

NombreDistribución

Un nombre de distribución válido como "DBD-Pg". Básicamente, es lo mismo que un nombre de paquete con los dobles dos puntos reemplazados por guiones. Tenga en cuenta que existen algunos nombres de distribución históricos que no se ajustan a este patrón, como "CGI.pm".

Este tipo permite caracteres Unicode.

Identificador

Un Identificador es algo que podría usarse como nombre de símbolo u otro identificador (manejador de archivo, manejador de directorio, nombre de subrutina, nombre de formato o etiqueta). Es lo que pones después del sigilo (signo de dólar, arroba, signo de porcentaje) en un nombre de variable. Generalmente, es un conjunto de caracteres de palabra que no comienzan con un dígito.

Este tipo permite caracteres Unicode.

IdentificadorSeguro

Esto es igual que un "Identificador" pero excluye las variables de un solo carácter guion bajo ("_"), "a" y "b", ya que estas son variables especiales para el intérprete de Perl.

CadenaVersiónLax y CadenaVersiónEstricta

Las cadenas de versión laxas y estrictas utilizan los métodos is_lax e is_strict de "version" para comprobar si la cadena dada sería una versión laxa o estricta válida. version::Internals cubre los detalles, pero básicamente: las versiones laxas son todo lo que puedes hacer, y las estrictas omiten muchos de los usos que es mejor evitar.
