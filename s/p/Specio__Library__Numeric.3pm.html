Specio::Library::Numeric(3) Documentación de Perl aportada por el usuario Specio::Library::Numeric(3)

NOMBRE

Specio::Library::Numeric - Implementa objetos de restricción de tipo para algunos tipos numéricos comunes

VERSIÓN

versión 0.53

DESCRIPCIÓN

Esta biblioteca proporciona algunas cadenas numéricas adicionales para casos comunes.

PositiveNum

PositiveOrZeroNum

PositiveInt

PositiveOrZeroInt

NegativeNum

NegativeOrZeroNum

NegativeInt

NegativeOrZeroInt

SingleDigit

Un solo dígito de -9 a 9.
