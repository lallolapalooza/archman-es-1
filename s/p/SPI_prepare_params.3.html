NOMBRE

SPI_prepare_params - preparar una sentencia, sin ejecutarla aún

SINOPSIS

SPIPlanPtr SPI_prepare_params(const char * command,
                              ParserSetupHook parserSetup,
                              void * parserSetupArg,
                              int cursorOptions)

DESCRIPCIÓN

SPI_prepare_params crea y devuelve una sentencia preparada para el comando especificado, pero no ejecuta el comando. Esta función es equivalente a SPI_prepare_cursor, con la adición de que el llamador puede especificar funciones de hook del analizador para controlar el análisis de referencias de parámetros externos.

Esta función está ahora obsoleta en favor de SPI_prepare_extended.

ARGUMENTOS

const char * command

cadena de comando

ParserSetupHook parserSetup

función de configuración de hook del analizador

void * parserSetupArg

argumento de paso para parserSetup

int cursorOptions

máscara de bits entera de opciones de cursor; cero produce el comportamiento predeterminado

VALOR DE RETORNO

SPI_prepare_params tiene las mismas convenciones de retorno que SPI_prepare.
