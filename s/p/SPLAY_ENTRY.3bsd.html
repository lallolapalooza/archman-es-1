DESCRIPCIÓN

Estas macros definen estructuras de datos para diferentes tipos de árboles: árboles splay y árboles rojo-negro.

En las definiciones de las macros, TYPE es la etiqueta de nombre de una estructura definida por el usuario que debe contener un campo llamado FIELD, de tipo SPLAY_ENTRY o RB_ENTRY. El argumento HEADNAME es la etiqueta de nombre de una estructura definida por el usuario que debe declararse usando las macros SPLAY_HEAD() o RB_HEAD(). El argumento NAME debe ser un prefijo de nombre único para cada árbol que se defina.

Los prototipos de las funciones se declaran con SPLAY_PROTOTYPE, RB_PROTOTYPE, o RB_PROTOTYPE_STATIC. Los cuerpos de las funciones se generan con SPLAY_GENERATE, RB_GENERATE, o RB_GENERATE_STATIC. Consulte los ejemplos a continuación para obtener más explicaciones sobre cómo se utilizan estas macros.

ÁRBOLES SPLAY

Un árbol splay es una estructura de datos auto-organizada. Cada operación en el árbol provoca un splay. El splay mueve el nodo solicitado a la raíz del árbol y lo reequilibra parcialmente.

Esto tiene el beneficio de que la localidad de peticiones causa busquedas más rápidas ya que los nodos solicitados se mueven a la parte superior del árbol. Por otro lado, cada búsqueda provoca escrituras en memoria.

El Teorema de Balance limita el tiempo total de acceso para m operaciones e n inserciones en un árbol inicialmente vacío como O((m + n)lg n). El costo amortizado para una secuencia de m accesos a un árbol splay es O(lg n).

Un árbol splay está encabezado por una estructura definida por la macro SPLAY_HEAD(). Una estructura SPLAY_HEAD se declara de la siguiente manera:

SPLAY_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde NOMBRE_CABECERA es el nombre de la estructura a definir, y la struct TIPO es el tipo de los elementos a insertar en el árbol.

La macro SPLAY_ENTRY() declara una estructura que permite conectar elementos en el árbol.

Para poder usar las funciones que manipulan la estructura del árbol, sus prototipos deben declararse con la macro SPLAY_PROTOTYPE(), donde NAME es un identificador único para este árbol en particular. El argumento TYPE es el tipo de la estructura que se está gestionando en el árbol. El argumento FIELD es el nombre del elemento definido por SPLAY_ENTRY().

Los cuerpos de las funciones se generan con la macro SPLAY_GENERATE(). Toma los mismos argumentos que la macro SPLAY_PROTOTYPE(), pero solo debe usarse una vez.

Finalmente, el argumento CMP es el nombre de una función utilizada para comparar los nodos del árbol entre sí. La función toma dos argumentos de tipo struct TYPE *. Si el primer argumento es menor que el segundo, la función devuelve un valor menor que cero. Si son iguales, la función devuelve cero. De lo contrario, debería devolver un valor mayor que cero. La función de comparación define el orden de los elementos del árbol.

La macro SPLAY_INIT() inicializa el árbol referenciado por head.

El árbol splay también se puede inicializar estáticamente utilizando la macro SPLAY_INITIALIZER() de la siguiente manera:

SPLAY_HEAD(NOMBRE_CABECERA, TIPO) cabecera = SPLAY_INITIALIZER(&cabecera);

La macro SPLAY_INSERT() inserta el nuevo elemento elm en el árbol. En caso de éxito, se devuelve NULL. Si ya existe un elemento coincidente en el árbol, la inserción se aborta y se devuelve un puntero al elemento existente.

La macro SPLAY_REMOVE() elimina el elemento elm del árbol apuntado por head. En caso de éxito, se devuelve un puntero al elemento eliminado. Se devuelve NULL si elm no está presente en el árbol.

La macro SPLAY_FIND() se puede utilizar para encontrar un elemento particular en el árbol.

struct TIPO buscar, *res;
buscar.clave = 30;
res = SPLAY_FIND(NOMBRE, &cabecera, &buscar);

Las macros SPLAY_ROOT(), SPLAY_MIN(), SPLAY_MAX(), y SPLAY_NEXT() se pueden usar para recorrer el árbol:

para (np = SPLAY_MIN(NOMBRE, &cabecera); np != NULL; np = SPLAY_NEXT(NOMBRE, &cabecera, np))

O, para mayor simplicidad, se puede usar la macro SPLAY_FOREACH():

SPLAY_FOREACH(np, NOMBRE, &cabecera)

La macro SPLAY_EMPTY() debe usarse para verificar si un árbol splay está vacío.

ÁRBOLES ROJO-NEGRO

Un árbol rojo-negro es un árbol de búsqueda binaria con el color del nodo como un atributo adicional. Cumple un conjunto de condiciones:

  1. cada ruta de búsqueda desde la raíz hasta una hoja consta del mismo número de nodos negros,
  2. cada nodo rojo (excepto la raíz) tiene un padre negro,
  3. cada nodo hoja es negro.

Cada operación en un árbol rojo-negro está limitada a O(lg n). La altura máxima de un árbol rojo-negro es 2lg (n+1).

Un árbol rojo-negro está encabezado por una estructura definida por la macro RB_HEAD(). Una estructura RB_HEAD se declara de la siguiente manera:

RB_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde NOMBRE_CABECERA es el nombre de la estructura a definir, y la struct TIPO es el tipo de los elementos a insertar en el árbol.

La macro RB_ENTRY() declara una estructura que permite conectar elementos en el árbol.

Para poder usar las funciones que manipulan la estructura del árbol, sus prototipos deben declararse con las macros RB_PROTOTYPE() o RB_PROTOTYPE_STATIC(), donde NAME es un identificador único para este árbol en particular. El argumento TYPE es el tipo de la estructura que se está gestionando en el árbol. El argumento FIELD es el nombre del elemento definido por RB_ENTRY().

Los cuerpos de las funciones se generan con las macros RB_GENERATE() o RB_GENERATE_STATIC(). Estas macros toman los mismos argumentos que las macros RB_PROTOTYPE() y RB_PRO

SPLAY TREES

The tree macros operate on a pointer to a structure representing the tree's root. In order to use the tree macros, you must first define a structure that will hold the tree's nodes. This structure must contain a field of type SPLAY_ENTRY(TYPE), where TYPE is the name of your node structure. The tree macros will then use this field to link the nodes.

You must also define a structure to serve as the tree's head. This structure must contain a field of type SPLAY_HEAD(HEADNAME, TYPE), where HEADNAME is the name you wish to give to your tree, and TYPE is the name of your node structure. The tree head structure is used to manage the tree.

The following macros are available:

SPLAY_HEAD
Declares a tree head structure.
SPLAY_ENTRY
Declares a tree node structure.
SPLAY_INIT
Initializes a tree head structure.
SPLAY_INITIALIZER
Provides a static initializer for a tree head structure.
SPLAY_INSERT
Inserts a node into the tree.
SPLAY_REMOVE
Removes a node from the tree.
SPLAY_FIND
Finds a node in the tree.
SPLAY_FIND_LE
Finds the node with the greatest key less than or equal to the search key.
SPLAY_FIND_GE
Finds the node with the smallest key greater than or equal to the search key.
SPLAY_NEXT
Returns the next node in the tree (in-order traversal).
SPLAY_PREV
Returns the previous node in the tree (in-order traversal).
SPLAY_MIN
Returns the minimum node in the tree.
SPLAY_MAX
Returns the maximum node in the tree.
SPLAY_ROOT
Returns the root node of the tree.
SPLAY_EMPTY
Checks if the tree is empty.
SPLAY_FOREACH
Iterates over all nodes in the tree in ascending order.
SPLAY_FOREACH_REVERSE
Iterates over all nodes in the tree in descending order.
SPLAY_FOREACH_SAFE
Iterates over all nodes in the tree in ascending order, allowing safe removal of nodes during iteration.
SPLAY_FOREACH_REVERSE_SAFE
Iterates over all nodes in the tree in descending order, allowing safe removal of nodes during iteration.

The SPLAY_HEAD, SPLAY_ENTRY, SPLAY_INSERT, SPLAY_REMOVE, SPLAY_FIND, SPLAY_FIND_LE, SPLAY_FIND_GE, SPLAY_NEXT, SPLAY_PREV, SPLAY_MIN, SPLAY_MAX, SPLAY_ROOT, SPLAY_EMPTY, SPLAY_FOREACH, SPLAY_FOREACH_REVERSE, SPLAY_FOREACH_SAFE, and SPLAY_FOREACH_REVERSE_SAFE macros require the name of the tree head structure, the name of the node structure, and the name of the SPLAY_ENTRY field within the node structure as arguments.

The SPLAY_INIT macro initializes the tree referenced by head. It should be used once before any other operations on the tree.

The SPLAY_INITIALIZER macro can be used to initialize a tree head structure statically.

SPLAY_HEAD(HEADNAME, TYPE) head = SPLAY_INITIALIZER(&head);

The SPLAY_INSERT macro inserts the new element elm into the tree. Upon success, NULL is returned. If a matching element already exists in the tree, the insertion is aborted, and a pointer to the existing element is returned.

The SPLAY_REMOVE macro removes the element elm from the tree pointed by head. SPLAY_REMOVE() returns elm.

The SPLAY_FIND, SPLAY_FIND_LE, and SPLAY_FIND_GE macros can be used to find a particular element in the tree. SPLAY_FIND() finds the node with the same key as elm. SPLAY_FIND_LE() finds the first node with a key less than or equal to the search key. SPLAY_FIND_GE() finds the first node with a key greater than or equal to the search key.

struct TYPE find, *res;
find.key = 30;
res = SPLAY_FIND(NAME, &head, &find);

The SPLAY_ROOT(), SPLAY_MIN(), SPLAY_MAX(), SPLAY_NEXT(), and SPLAY_PREV() macros can be used to traverse the tree:

for (np = SPLAY_MIN(NAME, &head); np != NULL; np = SPLAY_NEXT(NAME, &head, np))

Or, for simplicity, one can use the SPLAY_FOREACH() or SPLAY_FOREACH_REVERSE() macros:

SPLAY_FOREACH(np, NAME, &head)

The macros SPLAY_FOREACH_SAFE() and SPLAY_FOREACH_REVERSE_SAFE() traverse the tree referenced by head in a forward or reverse direction respectively, assigning each element in turn to np. However, unlike their unsafe counterparts, they permit both the removal of np as well as freeing it from within the loop safely without interfering with the traversal.

The SPLAY_EMPTY macro should be used to check whether a splay tree is empty.

The RB_HEAD, RB_ENTRY, RB_INSERT, RB_REMOVE, RB_FIND, RB_NFIND, RB_NEXT, RB_PREV, RB_MIN, RB_MAX, RB_ROOT, RB_EMPTY, RB_FOREACH, RB_FOREACH_REVERSE, RB_FOREACH_SAFE, and RB_FOREACH_REVERSE_SAFE macros require the name of the tree head structure, the name of the node structure, and the name of the RB_ENTRY field within the node structure as arguments. They also require a pointer to the comparison function. The comparison function, CMP, takes two arguments of type struct TYPE *. If the first argument is smaller than the second, the function returns a value smaller than zero. If they are equal, the function returns zero. Otherwise, it should return a value greater than zero.
