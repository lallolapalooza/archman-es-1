NOMBRE

SPI_scroll_cursor_fetch - obtener algunas filas de un cursor

SINOPSIS

void SPI_scroll_cursor_fetch(Portal portal, FetchDirection direction,
                             long count)

DESCRIPCIÓN

SPI_scroll_cursor_fetch obtiene algunas filas de un cursor. Esto es equivalente al comando SQL FETCH.

ARGUMENTOS

Portal portal

portal que contiene el cursor

FetchDirection direction

uno de FETCH_FORWARD, FETCH_BACKWARD, FETCH_ABSOLUTE o FETCH_RELATIVE

long count

número de filas a obtener para FETCH_FORWARD o FETCH_BACKWARD; número de fila absoluto a obtener para FETCH_ABSOLUTE; o número de fila relativo a obtener para FETCH_RELATIVE

VALOR DE RETORNO

SPI_processed y SPI_tuptable se establecen como en SPI_execute si tiene éxito.

NOTAS

Consulte el comando SQL FETCH(7) para obtener detalles sobre la interpretación de los parámetros direction y count.

Los valores de dirección distintos de FETCH_FORWARD pueden fallar si el plan del cursor no se creó con la opción CURSOR_OPT_SCROLL.
