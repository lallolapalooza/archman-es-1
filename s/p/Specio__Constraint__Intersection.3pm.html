NOMBRE

Specio::Constraint::Intersection - Una clase para restricciones de intersección

VERSIÓN

versión 0.53

SINOPSIS

my $type = Specio::Constraint::Untion->new(...);

DESCRIPCIÓN

Esta es una clase especializada de restricción de tipo para intersecciones, que permitirá un valor que coincida con cada uno de varios tipos distintos.

API

Esta clase proporciona todos los mismos métodos que Specio::Constraint::Simple, con algunas diferencias:

Specio::Constraint::Intersection->new( ... )

El parámetro "parent" se ignora si se pasa, ya que siempre es "undef".

Los parámetros "inline_generator" y "constraint" también se ignoran. Esta clase proporciona su propia referencia de subrutina generadora en línea predeterminada.

Finalmente, esta clase requiere un parámetro adicional, "of". Este debe ser un arrayref de objetos de tipo.

$union->of

Devuelve una referencia de matriz de los tipos individuales que componen esta intersección.

ROLES

Esta clase cumple con los roles de Specio::Constraint::Role::Interface y Specio::Role::Inlinable.
