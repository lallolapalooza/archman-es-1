Specio::Library::Builtins(3) Documentación de Perl contribuida por el usuario Specio::Library::Builtins(3)

NOMBRE

Specio::Library::Builtins - Implementa objetos de restricción de tipo para los tipos incorporados de Perl

VERSIÓN

versión 0.53

DESCRIPCIÓN

Esta biblioteca proporciona un conjunto de tipos paralelos a los proporcionados por Moose.

Los tipos están en la siguiente jerarquía

Item
    Bool
    Maybe (de `a)
    Undef
    Defined
        Value
            Str
                Num
                    Int
                ClassName
        Ref
            ScalarRef (de `a)
            ArrayRef (de `a)
            HashRef (de `a)
            CodeRef
            RegexpRef
            GlobRef
            FileHandle
            Object

Item

Acepta cualquier valor

Bool

Acepta un no-referencia que sea "undef", una cadena vacía, 0, o 1. También acepta cualquier objeto que sobrecargue la boolificación.

Maybe (de `a)

Un tipo parametrizable que acepta "undef" o el tipo "a". Si no está parametrizado, este tipo aceptará cualquier valor.

Undef

Solo acepta "undef".

Value

Acepta cualquier valor que no sea una referencia.

Str

Acepta cualquier valor que no sea una referencia o un objeto que sobrecargue la stringificación.

Num

Acepta casi los mismos valores que "Scalar::Util::looks_like_number", pero no acepta números con espacios al principio o al final, infinitos o NaN. También acepta un objeto que sobrecargue la numificación.

Int

Acepta cualquier valor entero, o un objeto que sobrecargue la numificación y cuyo resultado numificado sea un entero.

ClassName

Acepta cualquier valor que pase la restricción "Str" y cuya cadena sea un paquete cargado.

Ref

Acepta cualquier referencia.

ScalarRef (de `a)

Acepta una referencia escalar o un objeto que sobrecargue la desreferencia escalar. Si está parametrizado, el valor desreferenciado debe ser del tipo "a".

ArrayRef (de `a)

Acepta una referencia a un array o un objeto que sobrecargue la desreferencia de array. Si está parametrizado, los valores en el arrayref deben ser del tipo "a".

HashRef (de `a)

Acepta una referencia a un hash o un objeto que sobrecargue la desreferencia de hash. Si está parametrizado, los valores en el hashref deben ser del tipo "a".

CodeRef

Acepta una referencia de código (subrutina) o un objeto que sobrecargue la desreferencia de código.

RegexpRef

Acepta un objeto regex creado con "qr//" o un objeto que sobrecargue la interpolación de regex.

GlobRef

Acepta una referencia glob o un objeto que sobrecargue la desreferencia glob.

FileHandle

Acepta una referencia glob que sea un manejador de archivo abierto, cualquier objeto "IO::Handle" o subclase, o un objeto que sobrecargue la desreferencia glob y devuelva una referencia glob que sea un manejador de archivo abierto.

Object

Acepta cualquier objeto bendecido.
