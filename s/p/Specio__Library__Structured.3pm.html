Specio::Library::Structured(3) Documentación de Contribución de Usuarios de Perl Specio::Library::Structured(3)

NOMBRE

Specio::Library::Structured - Tipos estructurados para Specio (Dict, Map, Tuple)

VERSIÓN

versión 0.53

SINOPSIS

use Specio::Library::Builtins;
use Specio::Library::String;
use Specio::Library::Structured;
my $map = t(
    'Map',
    of => {
        key   => t('NonEmptyStr'),
        value => t('Int'),
    },
);
my $tuple = t(
    'Tuple',
    of => [ t('Str'), t('Num') ],
);
my $dict = t(
    'Dict',
    of => {
        kv => {
            name => t('Str'),
            age  => t('Int'),
        },
    },
);

DESCRIPCIÓN

Esta biblioteca proporciona un conjunto de tipos estructurados para Specio, "Dict", "Map" y "Tuple". Esta biblioteca también exporta dos subrutinas auxiliares utilizadas para algunos tipos, "optional" y "slurpy".

Todos los tipos estructurados se parametrizan llamando "t( 'Nombre del Tipo', of => ... )". Los argumentos pasados después de "of" varían para cada tipo.

Dict

Un "Dict" es un hashref con un conjunto bien definido de claves y tipos para esas claves.

El argumento pasado a "of" debería ser un único hashref. Ese hashref debe contener una clave "kv" que defina las claves esperadas y los tipos para sus valores. Este valor "kv" es en sí mismo un hashref. Si un par clave/valor es opcional, usa "optional" alrededor del *tipo* para esa clave:

my $person = t(
    'Dict',
    of => {
        kv => {
            first  => t('NonEmptyStr'),
            middle => optional( t('NonEmptyStr') ),
            last   => t('NonEmptyStr'),
        },
    },
);

Si una clave es opcional, puede omitirse por completo, pero si se pasa, su tipo será verificado, por lo que no se puede simplemente establecer en "undef".

También puedes pasar una clave "slurpy". Si se pasa, el "Dict" permitirá otras claves desconocidas, siempre que coincidan con el tipo especificado:

my $person = t(
    'Dict',
    of => {
        kv => {
            first  => t('NonEmptyStr'),
            middle => optional( t('NonEmptyStr') ),
            last   => t('NonEmptyStr'),
        },
        slurpy => t('Int'),
    },
);

Map

Un "Map" es un hashref con tipos especificados para sus claves y valores, pero sin nombres de clave bien definidos.

El argumento pasado a "of" debería ser un único hashref con dos claves, "key" y "value". El tipo para la "key" será típicamente algún tipo de clave, pero si estás usando un hash enlazado o un objeto con sobrecarga de hash, podría concebiblemente ser cualquier tipo de valor.

Tuple

Un "Tuple" es un arrayref con un conjunto fijo de miembros en un orden específico.

El argumento pasado a "of" debería ser un único arrayref que consista en tipos. Puedes marcar una posición en el "Tuple" como opcional envolviendo el tipo en una llamada a "optional":

my $record = t(
    'Tuple',
    of => [
        t('PositiveInt'),
        t('Str'),
        optional( t('Num') ),
        optional( t('Num') ),
    ],
);

Puedes tener tantos elementos "optional" como desees, pero siempre deben venir en secuencia al final de la definición del tupla. No puedes intercalar elementos requeridos y opcionales.

También puedes hacer que la Tupla acepte un número arbitrario de valores envolviendo el último tipo en una llamada a "slurpy":

my $record = t(
    'Tuple',
    of => [
        t('PositiveInt'),
        t('Str'),
        slurpy( t('Num') ),
    ],
);

En este caso, la "Tuple" requerirá los dos primeros elementos y luego permitirá cualquier número (incluyendo cero) de elementos "Num".

No puedes mezclar "optional" y "slurpy" en una definición de "Tuple".

LIMITACIONES

Actualmente, todos los tipos estructurados requieren que los tipos con los que están estructurados puedan ser incrustados. Esto puede cambiar en el futuro, pero incrustar todos tus tipos es una muy buena idea, así que deberías hacerlo de todos modos.
