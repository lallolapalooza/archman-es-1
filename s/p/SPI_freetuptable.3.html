NOMBRE

SPI_freetuptable - liberar un conjunto de filas creado por SPI_execute o una función similar

SINOPSIS

void SPI_freetuptable(SPITupleTable * tuptable)

DESCRIPCIÓN

SPI_freetuptable libera un conjunto de filas creado por una función de ejecución de comandos SPI anterior, como SPI_execute. Por lo tanto, esta función a menudo se llama con la variable global SPI_tuptable como argumento.

Esta función es útil si una función C que utiliza SPI necesita ejecutar múltiples comandos y no quiere conservar los resultados de comandos anteriores hasta que finalice. Tenga en cuenta que cualquier conjunto de filas no liberado será liberado de todos modos en SPI_finish. Además, si se inicia y luego se aborta una subtransacción dentro de la ejecución de una función C que utiliza SPI, SPI libera automáticamente cualquier conjunto de filas creado mientras la subtransacción estaba en curso.

A partir de PostgreSQL 9.3, SPI_freetuptable contiene lógica de protección para proteger contra solicitudes de eliminación duplicadas para el mismo conjunto de filas. En versiones anteriores, las eliminaciones duplicadas provocaban fallos.

ARGUMENTOS

SPITupleTable * tuptable

puntero al conjunto de filas a liberar, o NULL para no hacer nada
