Specio::Constraint::AnyIsa(3) Documentación aportada por el usuario de Perl Specio::Constraint::AnyIsa(3)

NOMBRE

Specio::Constraint::AnyIsa - Una clase para restricciones que requieren un nombre de clase o un objeto que herede de una clase específica

VERSIÓN

versión 0.53

SINOPSIS

my $type = Specio::Constraint::AnyIsa->new(...);
print $type->class;

DESCRIPCIÓN

Esta es una clase de restricción de tipo especializada para tipos que requieren un nombre de clase o un objeto que herede de una clase específica.

API

Esta clase proporciona todos los mismos métodos que Specio::Constraint::Simple, con algunas diferencias:

Specio::Constraint::AnyIsa->nuevo( ... )

El parámetro "parent" se ignora si se pasa, ya que siempre se establece en el tipo "Defined".

Los parámetros "inline_generator" y "constraint" también se ignoran. Esta clase proporciona su propia referencia de subrutina generadora en línea predeterminada.

Esta clase anula el valor predeterminado de "message_generator" si no se proporciona ninguno.

Finalmente, esta clase requiere un parámetro adicional, "class". Este debe ser un único nombre de clase.

$any_isa->clase

Devuelve el nombre de la clase pasado al constructor.

ROLES

Esta clase implementa los roles Specio::Constraint::Role::IsaType, Specio::Constraint::Role::Interface y Specio::Role::Inlinable.
