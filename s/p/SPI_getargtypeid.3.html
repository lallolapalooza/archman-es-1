NOMBRE

SPI_getargtypeid - devuelve el OID del tipo de dato para un argumento de una sentencia preparada por SPI_prepare

SINOPSIS

Oid SPI_getargtypeid(SPIPlanPtr plan, int argIndex)

DESCRIPCIÓN

SPI_getargtypeid devuelve el OID que representa el tipo para el argumento número argIndex de una sentencia preparada por SPI_prepare. El primer argumento tiene el índice cero.

ARGUMENTOS

SPIPlanPtr plan

sentencia preparada (devuelta por SPI_prepare)

int argIndex

índice basado en cero del argumento

VALOR DE RETORNO

El OID del tipo del argumento en el índice dado. Si el plan es NULL o inválido, o argIndex es menor que 0 o no es menor que el número de argumentos declarados para el plan, SPI_result se establece en SPI_ERROR_ARGUMENT y se devuelve InvalidOid.
