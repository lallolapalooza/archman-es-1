NOMBRE

SPI_modifytuple - crear una fila reemplazando campos seleccionados de una fila dada

SINOPSIS

HeapTuple SPI_modifytuple(Relation rel, HeapTuple row, int ncols,
                          int * colnum, Datum * values, const char * nulls)

DESCRIPCIÓN

SPI_modifytuple crea una nueva fila sustituyendo valores nuevos por columnas seleccionadas, copiando las columnas de la fila original en otras posiciones. La fila de entrada no se modifica. La nueva fila se devuelve en el contexto del ejecutor superior.

Esta función solo se puede utilizar mientras se está conectado a SPI. De lo contrario, devuelve NULL y establece SPI_result a SPI_ERROR_UNCONNECTED.

ARGUMENTOS

Relation rel

Se utiliza solo como fuente del descriptor de fila para la fila. (Pasar una relación en lugar de un descriptor de fila es un error de diseño).

HeapTuple row

fila a modificar

int ncols

número de columnas a cambiar

int * colnum

un arreglo de longitud ncols, que contiene los números de las columnas que se van a cambiar (los números de columna comienzan en 1)

Datum * values

un arreglo de longitud ncols, que contiene los nuevos valores para las columnas especificadas

const char * nulls

un arreglo de longitud ncols, que describe cuáles de los nuevos valores son nulos.

Si nulls es NULL, entonces SPI_modifytuple asume que no hay valores nuevos nulos. De lo contrario, cada entrada del arreglo nulls debe ser ' ' si el valor nuevo correspondiente no es nulo, o 'n' si el valor nuevo correspondiente es nulo. (En este último caso, el valor real en la entrada correspondiente de values no importa). Tenga en cuenta que nulls no es una cadena de texto, solo un arreglo: no necesita un terminador '\0'.

VALOR DE RETORNO

nueva fila con modificaciones, asignada en el contexto del ejecutor superior, o NULL en caso de error (ver SPI_result para una indicación de error)

En caso de error, SPI_result se establece de la siguiente manera:

SPI_ERROR_ARGUMENT

si rel es NULL, o si row es NULL, o si ncols es menor o igual a 0, o si colnum es NULL, o si values es NULL.

SPI_ERROR_NOATTRIBUTE

si colnum contiene un número de columna inválido (menor o igual a 0 o mayor que el número de columnas en row)

SPI_ERROR_UNCONNECTED

si SPI no está activo
