Specio::PartialDump(3) Documentación de Perl aportada por el usuario Specio::PartialDump(3)

NOMBRE

Specio::PartialDump - Una copia parcialmente modificada de Devel::PartialDump sin prerrequisitos

VERSIÓN

versión 0.53

SINOPSIS

use Specio::PartialDump qw( partial_dump );
partial_dump( { foo => 42 } );
partial_dump(qw( a b c d e f g ));
partial_dump( foo => 42, bar => [ 1, 2, 3 ], );

DESCRIPCIÓN

Esta es una copia de Devel::PartialDump eliminando todas las partes OO y los prerrequisitos. Es posible que desees usar este módulo en tu propio código para generar mensajes bien formateados cuando falla una restricción de tipo.

Este módulo exporta opcionalmente una subrutina, "partial_dump". Esta subrutina acepta cualquier número de argumentos. Si se le da más de uno, asumirá que se le ha dado una lista de pares clave/valor (para construir un hash) o una lista de valores (para construir un array) y los volcará apropiadamente. Los objetos y referencias se convertirán a cadena de forma sensata.
