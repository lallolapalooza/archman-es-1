Specio::Coercion(3) Documentación de Perl contribuida por el usuario Specio::Coercion(3)

NOMBRE

Specio::Coercion - Una clase que representa una coerción de un tipo a otro

VERSIÓN

versión 0.53

SINOPSIS

my $coercion = $type->coercion_from_type('Int');
my $new_value = $coercion->coerce_value(42);
if ( $coercion->can_be_inlined() ) {
    my $code = $coercion->inline_coercion('$_[0]');
}

DESCRIPCIÓN

Esta clase representa una coerción de un tipo a otro. Internamente, una coerción es un fragmento de código que toma un valor de un tipo y devuelve un nuevo valor de un nuevo tipo. Por ejemplo, una coerción de c<Num> a "Int" podría redondear un número a su entero más cercano y devolver ese entero.

Las coerciónes pueden implementarse como una simple referencia a subrutina o como una subrutina generadora en línea. Usar un generador en línea es más rápido pero más complicado.

API

Esta clase proporciona los siguientes métodos.

Specio::Coercion->new( ... )

Este método crea un nuevo objeto de coerción. Acepta los siguientes parámetros con nombre:

  • from => $type

    El tipo del cual proviene esta coerción. El tipo debe ser un objeto que implemente la interfaz Specio::Constraint::Role::Interface.

    Este parámetro es obligatorio.

  • to => $type

    El tipo al cual se dirige esta coerción. El tipo debe ser un objeto que implemente la interfaz Specio::Constraint::Role::Interface.

    Este parámetro es obligatorio.

  • coercion => sub { ... }

    Una referencia a subrutina que implementa la coerción. Se llamará como un método sobre el objeto y se le pasará un único argumento, el valor a coaccionar.

    Debería devolver el nuevo valor.

    Este parámetro es mutuamente exclusivo con "inline_generator".

    O este parámetro o el parámetro "inline_generator" es obligatorio.

    También puedes pasar esta opción con la clave "using" en la lista de parámetros.

  • inline_generator => sub { ... }

    Esta debe ser una referencia a subrutina que devuelve una cadena que contiene un único término. Este código *no* debe terminar en punto y coma. Este código debe implementar la coerción.

    El generador se llamará como un método sobre la coerción con un único argumento. Ese argumento es el nombre de la variable que se está coaccionando, algo como '$_[0]' o '$var'.

    Este parámetro es mutuamente exclusivo con "coercion".

    O este parámetro o el parámetro "coercion" es obligatorio.

    También puedes pasar esta opción con la clave "inline" en la lista de parámetros.

  • inline_environment => {}

    Esta debe ser una referencia a hash de nombres de variables (con sigilos) y valores para esa variable. Los valores deben ser *referencias* a los valores de las variables.

    Este entorno se utilizará al compilar la coerción como parte de una subrutina. Las variables con nombre se capturarán como clausuras en la subrutina generada, utilizando Eval::Closure.

    Debería ser muy raro necesitar establecer esto en el constructor. Es más probable que una subclase especial de coerción necesite proporcionar valores que genera internamente.

    Este parámetro por defecto es una referencia a hash vacía.

  • declared_at => $declared_at

    Este parámetro debe ser un objeto Specio::DeclaredAt.

    Este parámetro es obligatorio.

$coercion->from(), $coercion->to(), $coercion->declared_at()

Estos métodos son todos accesores de atributos de solo lectura para el atributo correspondiente.

$coercion->description

Esto devuelve una cadena que describe la coerción. Incluye los nombres del tipo de destino ('to') y de origen ('from'), y dónde se declaró la coerción, de modo que obtienes algo como 'coerción de Foo a Bar declarada en el paquete My::Lib (lib/My/Lib.pm) en la línea 42'.

$coercion->coerce($value)

Dado un valor del tipo de origen ('from') correcto, devuelve un nuevo valor del tipo de destino ('to').

Este método no verifica realmente los tipos de los valores dados o devueltos.

$coercion->inline_coercion($var)

Dado un nombre de variable como '$_[0]', esto devuelve una cadena con código para la coerción.

Ten en cuenta que este método fallará si la coerción no tiene un generador en línea.

$coercion->can_be_inlined()

Esto devuelve verdadero si la coerción tiene un generador en línea *y* la restricción de la que proviene puede ser en línea. Esto existe principalmente para el beneficio del método inline_coercion_and_check() para objetos de restricción de tipo.

$coercion->inline_environment()

Esto devuelve un hash que define las variables que necesitan ser cerradas ('closed over') al inlinar la coerción. Las claves son nombres de variables completos como '$foo' o '@bar'. Los valores son *referencias* a una variable del tipo coincidente.

$coercion->clone()

Devuelve un clon de este objeto.

$coercion->clone_with_new_to($new_to_type)

Esto devuelve un clon de la coerción, reemplazando el tipo de destino ('to') por uno nuevo. Esto está destinado a ser utilizado cuando el propio tipo de destino se clona como parte de la importación de ese tipo. Necesitamos asegurarnos de que la coerción recién clonada tenga también el tipo recién clonado.

ROLES

Esta clase implementa el rol Specio::Role::Inlinable.
