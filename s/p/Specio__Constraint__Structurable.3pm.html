Specio::Constraint::Structurable(3) Documentación aportada por el usuario de Perl Specio::Constraint::Structurable(3)

NOMBRE

Specio::Constraint::Structurable - Una clase que representa restricciones estructurables

VERSIÓN

versión 0.53

SINOPSIS

my $tuple = t('Tuple');
my $tuple_of_str_int = $tuple->parameterize( of => [ t('Str'), t('Int') ] );

DESCRIPCIÓN

Esta clase implementa la API para tipos estructurables como "Dict", "Map"< y "Tuple".

API

Esta clase implementa la misma API que Specio::Constraint::Simple, con algunas adiciones.

Specio::Constraint::Structurable->new(...)

El constructor de esta clase acepta dos parámetros adicionales:

  • parameterization_args_builder

    Esta es una subrutina que toma los valores pasados a "of" y devuelve un hash de argumentos nombrados. Estos argumentos se pasarán luego a "structured_constraint_generator" o "structured_inline_generator".

    Esto también debe realizar la comprobación de argumentos para asegurarse de que los argumentos pasados sean válidos. Por ejemplo, el tipo "Tuple" convierte el arrayref pasado a "of" en un hash, comprobando sobre la marcha que el llamador no hizo cosas como intercalar elementos opcionales y obligatorios o mezclar opcionales y slurpy juntos en la definición.

    Este parámetro es obligatorio.

  • name_builder

    Esta es una subrutina que se llama para generar un nombre para el tipo estructurado cuando se crea. Se llamará como un método en el objeto "Specio::Constraint::Structurable". Se le pasará el hash de argumentos devuelto por el "parameterization_args_builder".

    Este parámetro es obligatorio.

  • structured_constraint_generator

    Esta es una subrutina que genera una nueva subrutina de restricción cuando el tipo está estructurado.

    Se llamará como un método en el tipo y se le pasará el hash de argumentos devuelto por el "parameterization_args_builder".

    Este parámetro es mutuamente exclusivo con el parámetro "structured_inline_generator".

    Este parámetro o el parámetro "structured_inline_generator" es obligatorio.

  • structured_inline_generator

    Esta es una subrutina que genera una nueva subrutina de generador en línea cuando el tipo está estructurado.

    Se llamará como un método en el objeto Specio::Constraint::Structured cuando ese objeto necesite generar una restricción en línea. Recibirá el parámetro de tipo como primer argumento y el nombre de la variable como una cadena como segundo.

    Los argumentos restantes serán el hash de parámetros devuelto por el "parameterization_args_builder".

    Esto probablemente parece bastante confuso, por lo que puede ser útil consultar los ejemplos en el código de Specio::Library::Structured::*.

    Este parámetro es mutuamente exclusivo con el parámetro "structured_constraint_generator".

    Este parámetro o el parámetro "structured_constraint_generator" es obligatorio.

$type->parameterize(...)

Este método toma dos argumentos. El argumento "of" debe ser un objeto que implemente el rol de Specio::Constraint::Role::Interface y es obligatorio.

El otro argumento, "declared_at", es opcional. Si no se proporciona, se crea un nuevo objeto Specio::DeclaredAt utilizando una profundidad de pila de llamadas de 1.

Este método devuelve un nuevo objeto Specio::Constraint::Structured.
