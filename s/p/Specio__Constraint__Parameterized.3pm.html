Specio::Constraint::Parameterized(3) Documentación contribuida por el usuario de Perl Specio::Constraint::Parameterized(3)

NOMBRE

Specio::Constraint::Parameterized - una clase que representa restricciones parametrizadas

VERSIÓN

versión 0.53

SINOPSIS

mi $arrayref = t('ArrayRef');
mi $arrayref_de_int = $arrayref->parameterize( de => t('Int') );
mi $padre = $arrayref_de_int->parent; # devuelve ArrayRef
mi $parametro = $arrayref_de_int->parameter; # devuelve Int

DESCRIPCIÓN

Esta clase implementa la API para tipos parametrizados.

API

Esta clase implementa la misma API que Specio::Constraint::Simple, con algunas adiciones.

Specio::Constraint::Parameterized->new(...)

El constructor de esta clase acepta dos parámetros adicionales:

  • padre

    Debería ser el objeto Specio::Constraint::Parameterizable desde el cual se creó este objeto.

    Este parámetro es obligatorio.

  • parametro

    Este es el parámetro de tipo para el tipo parametrizado. Debe ser un objeto que implemente el rol Specio::Constraint::Role::Interface.

    Este parámetro es obligatorio.

$tipo->parametro

Devuelve el tipo que se pasó al constructor.
