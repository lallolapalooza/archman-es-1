SPI_cursor_open_with_args(3)

Paquete: postgresql

Licencias: PostgreSQL

SPI_CURSOR_OPEN_WITH_ARGS(3) Documentación de PostgreSQL 18.1 SPI_CURSOR_OPEN_WITH_ARGS(3)

NOMBRE

SPI_cursor_open_with_args - configurar un cursor utilizando una consulta y parámetros

SINOPSIS

Portal SPI_cursor_open_with_args(const char *nombre,
                                 const char *comando,
                                 int nargs, Oid *argtypes,
                                 Datum *values, const char *nulls,
                                 bool read_only, int cursorOptions)

DESCRIPCIÓN

SPI_cursor_open_with_args configura un cursor (internamente, un portal) que ejecutará la consulta especificada. La mayoría de los parámetros tienen los mismos significados que los parámetros correspondientes de SPI_prepare_cursor y SPI_cursor_open.

Para la ejecución de consultas de un solo uso, esta función debería preferirse a SPI_prepare_cursor seguido de SPI_cursor_open. Si el mismo comando se va a ejecutar con muchos parámetros diferentes, cualquiera de los métodos podría ser más rápido, dependiendo del coste de replanificación versus el beneficio de planes personalizados.

Los datos de los parámetros pasados se copiarán en el portal del cursor, por lo que pueden liberarse mientras el cursor todavía exista.

Esta función está ahora obsoleta en favor de SPI_cursor_parse_open, que proporciona funcionalidad equivalente utilizando una API más moderna para manejar los parámetros de la consulta.

ARGUMENTOS

const char * nombre

nombre para el portal, o NULL para dejar que el sistema seleccione un nombre

const char * comando

cadena de comando

int nargs

número de parámetros de entrada ($1, $2, etc.)

Oid * argtypes

un array de longitud nargs, que contiene los OID de los tipos de datos de los parámetros

Datum * values

un array de longitud nargs, que contiene los valores reales de los parámetros

const char * nulls

un array de longitud nargs, que describe cuáles parámetros son nulos

Si nulls es NULL entonces SPI_cursor_open_with_args asume que ningún parámetro es nulo. De lo contrario, cada entrada del array nulls debe ser ' ' si el valor del parámetro correspondiente no es nulo, o 'n' si el valor del parámetro correspondiente es nulo. (En este último caso, el valor real en la entrada values correspondiente no importa). Tenga en cuenta que nulls no es una cadena de texto, solo un array: no necesita un terminador '\0'.

bool read_only

true para ejecución de solo lectura

int cursorOptions

máscara de bits de enteros de opciones del cursor; cero produce comportamiento predeterminado

VALOR DE RETORNO

Puntero al portal que contiene el cursor. Tenga en cuenta que no hay convención de retorno de error; cualquier error se informará a través de elog.
