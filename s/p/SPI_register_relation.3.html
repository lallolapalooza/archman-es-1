NOMBRE

SPI_register_relation - hacer que una relación nombrada efímera esté disponible por nombre en consultas SPI

SINOPSIS

int SPI_register_relation(EphemeralNamedRelation enr)

DESCRIPCIÓN

SPI_register_relation hace que una relación nombrada efímera, con información asociada, esté disponible para las consultas planificadas y ejecutadas a través de la conexión SPI actual.

ARGUMENTOS

EphemeralNamedRelation enr

la entrada de registro de la relación nombrada efímera

VALOR DE RETORNO

Si la ejecución del comando fue exitosa, se devolverá el siguiente valor (no negativo):

SPI_OK_REL_REGISTER

si la relación se ha registrado con éxito por nombre

En caso de error, se devolverá uno de los siguientes valores negativos:

SPI_ERROR_ARGUMENT

si enr es NULL o su campo name es NULL

SPI_ERROR_UNCONNECTED

si se llama desde una función C no conectada

SPI_ERROR_REL_DUPLICATE

si el nombre especificado en el campo name de enr ya está registrado para esta conexión
