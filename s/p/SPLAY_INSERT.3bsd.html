DESCRIPCIÓN

Estas macros definen estructuras de datos para diferentes tipos de árboles: árboles de desplazamiento y árboles de color rojo-negro.

En las definiciones de las macros, TYPE es el etiquetado del estructura definida por el usuario que debe contener un campo con el nombre FIELD de tipo SPLAY_ENTRY o RB_ENTRY. El argumento HEADNAME es el etiquetado de una estructura definida por el usuario que debe ser declarada usando las macros SPLAY_HEAD() o RB_HEAD(). El argumento NAME debe ser un nombre único de prefijo para cada árbol definido.

Las declaraciones de las funciones se hacen con SPLAY_PROTOTYPE, RB_PROTOTYPE o RB_PROTOTYPE_STATIC. Las cuerpos de las funciones se generan con SPLAY_GENERATE, RB_GENERATE o RB_GENERATE_STATIC. Véase los ejemplos siguientes para una explicación adicional de cómo se utilizan estas macros.

ÁRBOL DE DESPLAZAMIENTO

Un árbol de desplazamiento es un estructura de datos self-organizándose. Cada operación en el árbol causa un desplazamiento. El desplazamiento mueve el nodo solicitado al raíz del árbol y parcialmente reequilibra el árbol.

Este tiene el beneficio de que la localidad de las solicitudes causa consultas más rápidas ya que los nodos solicitados se mueven al cima del árbol. Por otro lado, cada consulta causa escrituras en memoria.

El Teorema de Equilibrio limita el tiempo total de acceso para m operaciones y n inserciones en un árbol inicialmente vacío como O((m + n)lg n). El costo amortizado para un secuencia de m accesos a un árbol de desplazamiento es O(lg n).

Un árbol de desplazamiento está dirigido por una estructura definida por la macro SPLAY_HEAD(). Una estructura SPLAY_HEAD se declara así:

SPLAY_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a insertar en el árbol.

La macro SPLAY_ENTRY declara una estructura que permite conectar elementos en el árbol.

Para utilizar las funciones que manipulan la estructura del árbol, sus prototipos deben declararse con la macro SPLAY_PROTOTYPE, donde NAME es un identificador único para este árbol particular. El argumento TYPE es el tipo de la estructura que gestiona el árbol. El argumento FIELD es el nombre del elemento definido por SPLAY_ENTRY().

Las cuerpos de las funciones se generan con la macro SPLAY_GENERATE. Toma los mismos argumentos que la macro SPLAY_PROTOTYPE(), pero debe usarse solo una vez.

Finalmente, el argumento CMP es el nombre de una función que compara nodos de árboles con cada otros. La función toma dos argumentos de tipo struct TYPE *. Si el primer argumento es menor que el segundo, la función devuelve un valor menor que cero. Si son iguales, devuelve cero. De lo contrario, debe devolver un valor mayor que cero. La función de comparación define el orden de los elementos del árbol.

La macro SPLAY_INIT inicializa el árbol referenciado por head.

El árbol de desplazamiento también puede inicializarse de forma estática usando la macro SPLAY_INITIALIZER así:

SPLAY_HEAD(HEADNAME, TYPE) head = SPLAY_INITIALIZER(&head);

La macro SPLAY_INSERT inserta el nuevo elemento elm en el árbol. Si es exitoso, se devuelve NULL. Si ya existe un elemento con el mismo valor en el árbol, la inserción se aborta y se devuelve un puntero al elemento existente.

La macro SPLAY_REMOVE elimina el elemento elm del árbol apuntado por head. Si es exitoso, se devuelve un puntero al elemento eliminado. Si elm no está en el árbol, se devuelve NULL.

La macro SPLAY_FIND puede usarse para encontrar un elemento particular en el árbol.

struct TYPE find, *res;
find.key = 30;
res = SPLAY_FIND(NAME, &head, &find);

Las macros SPLAY_ROOT, SPLAY_MIN, SPLAY_MAX, y SPLAY_NEXT pueden usarse para recorrer el árbol:

for (np = SPLAY_MIN(NAME, &head); np != NULL; np = SPLAY_NEXT(NAME, &head, np))

O, para simplicidad, se puede usar la macro SPLAY_FOREACH:

SPLAY_FOREACH(np, NAME, &head)

La macro SPLAY_EMPTY debe usarse para verificar si un árbol de desplazamiento está vacío.

ÁRBOL DE COLOR ROJO-NEGRO

Un árbol de color rojo-negro es un árbol de búsqueda binario con el color del nodo como una propiedad adicional. Cumple una serie de condiciones:

  1. Todo camino desde la raíz hasta un nodo hoja contiene el mismo número de nodos negros.
  2. Cada nodo rojo (excepto la raíz) tiene un padre negro.
  3. Cada nodo hoja es negro.

Cada operación en un árbol de color rojo-negro está limitada a O(lg n). La altura máxima de un árbol de color rojo-negro es 2lg(n+1).

Un árbol de color rojo-negro está dirigido por una estructura definida por la macro RB_HEAD. Una estructura RB_HEAD se declara así:

RB_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a insertar en el árbol.

La macro RB_ENTRY declara una estructura que permite conectar elementos en el árbol.

Para utilizar las funciones que manipulan la estructura del árbol, sus prototipos deben declararse con las macros RB_PROTOTYPE o RB_PROTOTYPE_STATIC, donde NAME es un identificador único para este árbol particular. El argumento TYPE es el tipo de la estructura que gestiona el árbol. El argumento FIELD es el nombre del elemento definido por RB_ENTRY().

Las cuerpos de las funciones se generan con las macros RB_GENERATE o RB_GENERATE_STATIC. Estas macros toman los mismos argumentos que la macro RB_PROTOTYPE() y RB_GENERATE().

LIBRARY

libbsd

SYNOPSIS

#include <sys/tree.h>

A red-black tree is defined by a structure of type RB_HEAD(HEADNAME, TYPE). The macros to operate on the tree take the HEADNAME as their first argument. The TYPE is the structure type containing the tree nodes. The tree nodes themselves are declared using RB_ENTRY(TYPE).

The RB_PROTOTYPE macro should be used in a header file to declare the comparison function and the tree head, and the RB_GENERATE macro should be used in one implementation file to define the tree functions.

struct node {
	RB_ENTRY(node) entry;
	int i;
};
intcmp(struct node *, struct node *);
RB_PROTOTYPE(inttree, node, entry, intcmp);
RB_GENERATE(inttree, node, entry, intcmp);

DESCRIPTION

The RB_HEAD macro declares a structure HEADNAME which is used to reference a red-black tree. The TYPE argument is the type of the structure that will be stored in the tree. The TYPE structure must contain a field of type RB_ENTRY(TYPE). This field is used to link the nodes together. The name of this field must be passed as the third argument to RB_PROTOTYPE and RB_GENERATE.

The RB_PROTOTYPE macro declares the tree head structure and the comparison function. The arguments are the name of the tree head, the type of the structure stored in the tree, the name of the entry field within the structure, and the name of the comparison function.

The RB_GENERATE macro generates the tree functions. It takes the same arguments as RB_PROTOTYPE.

The RB_GENERATE_INSERT_H, RB_GENERATE_REMOVE_H, RB_GENERATE_FIND_H, and RB_GENERATE_INORDER_H macros can be used to generate only the insertion, removal, find, and inorder traversal functions respectively. They take the same arguments as RB_GENERATE.

The compare function CMP is used to compare nodes. It must return a negative value if the first argument is smaller than the second, zero if they are equal, and a positive value otherwise. The comparison function defines the ordering of the elements in the tree.

The RB_INIT() macro initializes the tree referenced by head.

The red-black tree can also be initialized statically by using the RB_INITIALIZER() macro like this:

RB_HEAD(HEADNAME, TYPE) head = RB_INITIALIZER(&head);

The RB_INSERT() macro inserts the new element elm into the tree. Upon success, NULL is returned. If a matching element already exists in the tree, the insertion is aborted, and a pointer to the existing element is returned.

The RB_REMOVE() macro removes the element elm from the tree pointed by head. RB_REMOVE() returns elm.

The RB_FIND() and RB_NFIND() macros can be used to find a particular element in the tree. RB_FIND() finds the node with the same key as elm. RB_NFIND() finds the first node greater than or equal to the search key.

struct TYPE find, *res;
find.key = 30;
res = RB_FIND(NAME, &head, &find);

The RB_ROOT(), RB_MIN(), RB_MAX(), RB_NEXT(), and RB_PREV() macros can be used to traverse the tree:

for (np = RB_MIN(NAME, &head); np != NULL; np = RB_NEXT(NAME, &head, np))

Or, for simplicity, one can use the RB_FOREACH() or RB_FOREACH_REVERSE() macros:

RB_FOREACH(np, NAME, &head)

The macros RB_FOREACH_SAFE() and RB_FOREACH_REVERSE_SAFE() traverse the tree referenced by head in a forward or reverse direction respectively, assigning each element in turn to np. However, unlike their unsafe counterparts, they permit both the removal of np as well as freeing it from within the loop safely without interfering with the traversal.

The RB_EMPTY() macro should be used to check whether a red-black tree is empty.

EXAMPLES

The following example demonstrates how to declare a red-black tree holding integers. Values are inserted into it and the contents of the tree are printed in order. Lastly, the internal structure of the tree is printed.

#include <sys/tree.h>
#include <err.h>
#include <stdio.h>
#include <stdlib.h>
struct node {
	RB_ENTRY(node) entry;
	int i;
};
int	intcmp(struct node *, struct node *);
void	print_tree(struct node *);
int
intcmp(struct node *e1, struct node *e2)
{
	return (e1->i < e2->i ? -1 : e1->i > e2->i);
}
RB_HEAD(inttree, node) head = RB_INITIALIZER(&head);
RB_PROTOTYPE(inttree, node, entry, intcmp)
RB_GENERATE(inttree, node, entry, intcmp)
int testdata[] = {
	20, 16, 17, 13, 3, 6, 1, 8, 2, 4, 10, 19, 5, 9, 12, 15, 18,
	7, 11, 14
};
void
print_tree(struct node *n)
{
	struct node *left, *right;

	if (n == NULL) {
		printf("nil");
		return;
	}
	left = RB_LEFT(n, entry);
	right = RB_RIGHT(n, entry);
	if (left == NULL && right == NULL)
		printf("%d", n->i);
	else {
		printf("%d(", n->i);
		print_tree(left);
		printf(",");
		print_tree(right);
		printf(")");
	}
}
int
main(void)
{
	int i;
	struct node *n;

	for (i = 0; i < sizeof(testdata) / sizeof(testdata[0]); i++) {
		if ((n = malloc(sizeof(struct node))) == NULL)
			err(1, NULL);
		n->i = testdata[i];
		RB_INSERT(inttree, &head, n);
	}

	RB_FOREACH(n, inttree, &head) {
		printf("%d\n", n->i);
	}
	print_tree(RB_ROOT(&head));
	printf("\n");
	return (0);
}

HISTORY

The tree macros first appeared in FreeBSD 4.6.

NOTES

Trying to free a tree in the following way is a common error:

SPLAY_FOREACH(var, NAME, &head) {
	SPLAY_REMOVE(NAME, &head, var);
	free(var);
}
free(head);

Since var is free'd, the FOREACH() macro refers to a pointer that may have been reallocated already. Proper code needs a second variable.

for (var = SPLAY_MIN(NAME, &head); var != NULL; var = nxt) {
	nxt = SPLAY_NEXT(NAME, &head, var);
	SPLAY_REMOVE(NAME, &head, var);
	free(var);
}
