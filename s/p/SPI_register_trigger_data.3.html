NOMBRE

SPI_register_trigger_data - hacer que los datos de disparador efímeros estén disponibles en consultas SPI

SINOPSIS

int SPI_register_trigger_data(TriggerData *tdata)

DESCRIPCIÓN

SPI_register_trigger_data hace que las relaciones efímeras capturadas por un disparador estén disponibles para las consultas planificadas y ejecutadas a través de la conexión SPI actual. Actualmente, esto significa las tablas de transición capturadas por un disparador AFTER definido con una cláusula REFERENCING OLD/NEW TABLE AS .... Esta función debe ser llamada por una función manejadora de disparadores PL después de la conexión.

ARGUMENTOS

TriggerData *tdata

el objeto TriggerData pasado a una función manejadora de disparadores como fcinfo->context

VALOR DE RETORNO

Si la ejecución del comando fue exitosa, se devolverá el siguiente valor (no negativo):

SPI_OK_TD_REGISTER

si los datos del disparador capturados (si los hay) se han registrado correctamente

En caso de error, se devolverá uno de los siguientes valores negativos:

SPI_ERROR_ARGUMENT

si tdata es NULL

SPI_ERROR_UNCONNECTED

si se llama desde una función C no conectada

SPI_ERROR_REL_DUPLICATE

si el nombre de alguna relación de datos de disparador transitoria ya está registrado para esta conexión
