NOMBRE

SPI_is_cursor_plan - devuelve verdadero si una sentencia preparada por SPI_prepare puede ser utilizada con SPI_cursor_open

SINOPSIS

bool SPI_is_cursor_plan(SPIPlanPtr plan)

DESCRIPCIÓN

SPI_is_cursor_plan devuelve verdadero si una sentencia preparada por SPI_prepare puede ser pasada como argumento a SPI_cursor_open, o falso si no es así. Los criterios son que el plan representa un único comando y que este comando devuelve tuplas al llamador; por ejemplo, SELECT está permitido a menos que contenga una cláusula INTO, y UPDATE solo está permitido si contiene una cláusula RETURNING.

ARGUMENTOS

SPIPlanPtr plan

sentencia preparada (devuelta por SPI_prepare)

VALOR DE RETORNO

verdadero o falso para indicar si el plan puede producir un cursor o no, con SPI_result establecido en cero. Si no es posible determinar la respuesta (por ejemplo, si el plan es NULL o inválido, o si se llama sin estar conectado a SPI), entonces SPI_result se establece en un código de error adecuado y se devuelve falso.
