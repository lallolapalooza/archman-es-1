Shell__Guess(3pm)

Shell::Guess(3) Documentación de Perl aportada por el usuario Shell::Guess(3)

NOMBRE

Shell::Guess - Hacer una suposición educada sobre el shell en uso

VERSIÓN

versión 0.10

SINOPSIS

adivinando el shell que ejecutó el script Perl:

use Shell::Guess;
my $shell = Shell::Guess->running_shell;
if($shell->is_c) {
  print "setenv FOO bar\n";
} elsif($shell->is_bourne) {
  print "export FOO=bar\n";
}

adivinando el shell de inicio de sesión del usuario actual:

use Shell::Guess;
my $shell = Shell::Guess->login_shell;
print $shell->name, "\n";

adivinando el shell de inicio de sesión de un usuario arbitrario:

use Shell::Guess;
my $shell = Shell::Guess->login_shell('bob');
print $shell->name, "\n";

DESCRIPCIÓN

Shell::Guess hace un intento razonablemente agresivo de determinar el shell que está empleando el usuario, ya sea el shell que ejecutó el script Perl directamente (el shell "en ejecución"), o el shell de inicio de sesión del usuario (el shell de "inicio de sesión"). Lo hace por una variedad de medios disponibles para él, dependiendo de la plataforma en la que se esté ejecutando.

  • getpwent

    En sistemas tipo UNIX con getpwent, eso se puede usar para determinar el shell de inicio de sesión.

  • dscl

    En Mac OS X, getpwent normalmente no proporcionará información útil, por lo que se utiliza el comando dscl en su lugar.

  • sistemas de archivos proc

    En sistemas tipo UNIX con sistemas de archivos proc (como Linux), Shell::Guess intentará usarlos para determinar el shell en ejecución.

  • ps

    En sistemas tipo UNIX sin un sistema de archivos proc, Shell::Guess usará el comando ps para determinar el shell en ejecución.

  • Win32::Getppid y Win32::Process::List

    En Windows, si estos módulos están instalados, se utilizarán para determinar el shell en ejecución. Este método puede diferenciar entre PowerShell, "command.com" y "cmd.exe".

  • ComSpec

    Si el método anterior no es concluyente, se consultará la variable de entorno ComSpec para diferenciar entre "command.com" y "cmd.exe" (PowerShell no se puede detectar de esta manera).

  • valores predeterminados razonables

    Si el shell en ejecución o de inicio de sesión no se puede determinar de otra manera, se utilizará un valor predeterminado razonable para su plataforma como solución alternativa. En OpenVMS es dcl, en Windows 95/98 y MS-DOS es command.com y en Windows NT/2000/XP/Vista/7 es cmd.exe. Las plataformas tipo UNIX recurren al shell bourne.

El uso previsto de este módulo es permitir a un desarrollador de Perl escribir un script que genere configuraciones de shell para el shell llamador para que puedan ser importadas de nuevo en el shell llamador utilizando "eval" y backticks o "source". Por ejemplo, si tu script se ve así:

#!/usr/bin/perl
use Shell::Guess;
my $shell = Shell::Guess->running_shell;
if($shell->is_bourne) {
  print "export FOO=bar\n";
} else($shell->is_c) {
  print "setenv FOO bar\n";
} else {
  die "No soporto el shell ", $shell->name, "\n";
}

Entonces puedes importar FOO a tu shell bash o c así:

% eval `perl script.pl`

o puedes escribir la salida en un archivo de configuración y cargarlo:

% perl script.pl > foo.sh
% source foo.sh

Shell::Config::Generate proporciona una interfaz portable para generar tales configuraciones de shell, y está diseñado para funcionar con este módulo.

MÉTODOS DE CLASE

Estos métodos de clase devuelven una instancia de Shell::Guess, que luego puede ser interrogada por los métodos de instancia en la siguiente sección a continuación.

running_shell

my $shell = Shell::Guess->running_shell;

Devuelve una instancia de Shell::Guess basada en el shell que inició directamente el script Perl actual. Si el shell en ejecución no se puede determinar, devolverá el shell de inicio de sesión.

login_shell

my $shell = Shell::Guess->login_shell;
my $shell = Shell::Guess->login_shell( $username )

Devuelve una instancia de Shell::Guess para el usuario dado. Si no se especifica un nombre de usuario, se utilizará el usuario actual. Si no se puede adivinar ningún shell, se elegirá una alternativa razonable basada en su plataforma.

bash_shell

my $shell = Shell::Guess->bash_shell;

Devuelve una instancia de Shell::Guess para bash.

Los siguientes métodos de instancia devolverán:

  • $shell->name = bash
  • $shell->is_bash = 1
  • $shell->is_bourne = 1
  • $shell->is_unix = 1
  • $shell->default_location = /bin/bash

Todos los demás métodos de instancia devolverán falso

bourne_shell

my $shell = Shell::Guess->bourne_shell;

Devuelve una instancia de Shell::Guess para el shell bourne.

Los siguientes métodos de instancia devolverán:

  • $shell->name = bourne
  • $shell->is_bourne = 1
  • $shell->is_unix = 1
  • $shell->default_location = /bin/sh

Todos los demás métodos de instancia devolverán falso

c_shell

my $shell = Shell::Guess->c_shell;

Devuelve una instancia de Shell::Guess para el shell c.

Los siguientes métodos de instancia devolverán:

  • $shell->name = c
  • $shell->is_c = 1
  • $shell->is_unix = 1
  • $shell->default_location = /bin/csh

Todos los demás métodos de instancia devolverán falso

cmd_shell

my $shell = Shell::Guess->cmd_shell;

Devuelve una instancia de Shell::Guess para el shell cmd de Windows NT (cmd.exe).

Los siguientes métodos de instancia devolverán:

  • $shell->name = cmd
  • $shell->is_cmd = 1
  • $shell->is_win32 = 1
  • $shell->default_location = C:\Windows\system32\cmd.exe

Todos los demás métodos de instancia devolverán falso

command_shell

my $shell = Shell::Guess->command_shell;

Devuelve una instancia de Shell::Guess para el shell de comandos de Windows 95 (command.com).

Los siguientes métodos de instancia devolverán:

  • $shell->name = command
  • $shell->is_command = 1
  • $shell->is_win32 = 1
  • $shell->default_location = C:\Windows\system32\command.com

Todos los demás métodos de instancia devolverán falso

dcl_shell

my $shell = Shell::Guess->dcl_shell;

Devuelve una instancia de Shell::Guess para el shell dcl de OpenVMS.

Los siguientes métodos de instancia devolverán:

  • $shell->name = dcl
  • $shell->is_dcl = 1
  • $shell->is_vms = 1

Todos los demás métodos de instancia devolverán falso

fish_shell

my $shell = Shell::Guess->fish_shell;

Devuelve una instancia de Shell::Guess para el shell fish.
