NOMBRE

Shell — La clase de widget Shell

SINOPSIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPCIÓN

Shell es un widget de nivel superior (con un solo hijo administrado) que encapsula la interacción con el gestor de ventanas.

En el momento en que se administra el hijo de shell, el ancho del hijo se utiliza para ambos widgets si el shell no está realizado y no se ha especificado ningún ancho para el shell. De lo contrario, el ancho del shell se utiliza para ambos widgets. Las mismas relaciones se aplican a la altura del shell y su hijo.

Clases

Shell hereda el comportamiento y los recursos de Composite y Core.

El puntero de clase es shellWidgetClass.

El nombre de la clase es Shell.

NOMBRE

Shell - widget de shell

SINOPSIS

#include <Xm/Shell.h>

DESCRIPCIÓN

La familia de widgets Shell proporciona la base para las ventanas de nivel superior de la aplicación. Se derivan de la clase de widget Composite.

Las ventanas de nivel superior son ventanas que no son secundarias de otros widgets de aplicación. Los ejemplos incluyen ventanas principales, cuadros de diálogo y ventanas emergentes. Los shells son responsables de gestionar el tamaño, la posición y el título de la ventana de nivel superior.

La clase de widget principal es XmShellWidget. Los shells son creados por funciones de creación como XtAppCreateShell y XtVaAppCreateShell.
