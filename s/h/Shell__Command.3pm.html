Shell::Command(3) Documentación de Perl aportada por el usuario Shell::Command(3)

NOMBRE

Shell::Command - Funciones multiplataforma que emulan comandos comunes de shell

SINOPSIS

use Shell::Command;
mv $old_file, $new_file;
cp $old_file, $new_file;
touch @files;

DESCRIPCIÓN

Envoltura delgada alrededor de "ExtUtils::Command". Consulte ExtUtils::Command para obtener una descripción de los comandos disponibles.
