NOMBRE

SHOW - mostrar el valor de un parámetro de tiempo de ejecución

SINOPSIS

SHOW nombre
SHOW ALL

DESCRIPCIÓN

SHOW mostrará la configuración actual de los parámetros de tiempo de ejecución. Estas variables se pueden establecer usando la sentencia SET, editando el archivo de configuración postgresql.conf, a través de la variable de entorno PGOPTIONS (al usar libpq o una aplicación basada en libpq), o a través de banderas de línea de comandos al iniciar el servidor postgres. Ver el Capítulo 19 para detalles.

PARÁMETROS

nombre

El nombre de un parámetro de tiempo de ejecución. Los parámetros disponibles se documentan en el Capítulo 19 y en la página de referencia de SET(7). Además, hay algunos parámetros que se pueden mostrar pero no establecer:

SERVER_VERSION

Muestra el número de versión del servidor.

SERVER_ENCODING

Muestra la codificación del juego de caracteres del lado del servidor. Actualmente, este parámetro se puede mostrar pero no establecer, ya que la codificación se determina en el momento de la creación de la base de datos.

IS_SUPERUSER

Verdadero si el rol actual tiene privilegios de superusuario.

ALL

Muestra los valores de todos los parámetros de configuración, con descripciones.

NOTAS

La función current_setting produce una salida equivalente; ver la Sección 9.28.1. Además, la vista del sistema pg_settings produce la misma información.

EJEMPLOS

Mostrar la configuración actual del parámetro DateStyle:

SHOW DateStyle;
 DateStyle
-----------
 ISO, MDY
(1 row)

Mostrar la configuración actual del parámetro geqo:

SHOW geqo;
 geqo
------
 on
(1 row)

Mostrar todas las configuraciones:

SHOW ALL;
            name         | setting |                description
-------------------------+---------+-------------------------------------------------
 allow_system_table_mods | off     | Permite modificaciones de la estructura de ...
    .
    .
    .
 xmloption               | content | Establece si los datos XML en el análisis implícito ...
 zero_damaged_pages      | off     | Continúa procesando después de cabeceras de página dañadas.
(196 rows)

COMPATIBILIDAD

El comando SHOW es una extensión de PostgreSQL.
