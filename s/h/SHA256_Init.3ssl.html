SHA256_Init(3ssl)

SHA256_INIT(3ssl) OpenSSL SHA256_INIT(3ssl)

NOMBRE

SHA1, SHA1_Init, SHA1_Update, SHA1_Final, SHA224, SHA224_Init, SHA224_Update, SHA224_Final, SHA256, SHA256_Init, SHA256_Update, SHA256_Final, SHA384, SHA384_Init, SHA384_Update, SHA384_Final, SHA512, SHA512_Init, SHA512_Update, SHA512_Final - Algoritmo de Hash Seguro

SINOPSIS

#include <openssl/sha.h>
unsigned char *SHA1(const unsigned char *data, size_t count, unsigned char *md_buf);
unsigned char *SHA224(const unsigned char *data, size_t count, unsigned char *md_buf);
unsigned char *SHA256(const unsigned char *data, size_t count, unsigned char *md_buf);
unsigned char *SHA384(const unsigned char *data, size_t count, unsigned char *md_buf);
unsigned char *SHA512(const unsigned char *data, size_t count, unsigned char *md_buf);

Las siguientes funciones han sido obsoletas desde OpenSSL 3.0, y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int SHA1_Init(SHA_CTX *c);
int SHA1_Update(SHA_CTX *c, const void *data, size_t len);
int SHA1_Final(unsigned char *md, SHA_CTX *c);
int SHA224_Init(SHA256_CTX *c);
int SHA224_Update(SHA256_CTX *c, const void *data, size_t len);
int SHA224_Final(unsigned char *md, SHA256_CTX *c);
int SHA256_Init(SHA256_CTX *c);
int SHA256_Update(SHA256_CTX *c, const void *data, size_t len);
int SHA256_Final(unsigned char *md, SHA256_CTX *c);
int SHA384_Init(SHA512_CTX *c);
int SHA384_Update(SHA512_CTX *c, const void *data, size_t len);
int SHA384_Final(unsigned char *md, SHA512_CTX *c);
int SHA512_Init(SHA512_CTX *c);
int SHA512_Update(SHA512_CTX *c, const void *data, size_t len);
int SHA512_Final(unsigned char *md, SHA512_CTX *c);

DESCRIPCIÓN

Todas las funciones descritas en esta página, excepto SHA1(), SHA224(), SHA256(), SHA384() y SHA512(), están obsoletas. Las aplicaciones deberían usar en su lugar EVP_DigestInit_ex(3), EVP_DigestUpdate(3) y EVP_DigestFinal_ex(3), o la función rápida de un solo disparo EVP_Q_digest(3). SHA1(), SHA224(), SHA256(), SHA384() y SHA512() pueden continuar usándose. También pueden ser reemplazadas por, por ejemplo:

(EVP_Q_digest(d, n, md, NULL, NULL, "SHA256", NULL) ? md : NULL)

SHA-1 (Secure Hash Algorithm) es una función de hash criptográfica con una salida de 160 bits.

SHA1() calcula el hash del mensaje SHA-1 de los n bytes en d y lo coloca en md (que debe tener espacio para SHA_DIGEST_LENGTH == 20 bytes de salida). Si md es NULL, el hash se coloca en un array estático. Nota: establecer md a NULL no es seguro para hilos.

Las siguientes funciones pueden ser usadas si el mensaje no está completamente almacenado en memoria:

SHA1_Init() inicializa una estructura SHA_CTX.

SHA1_Update() puede ser llamada repetidamente con fragmentos del mensaje a hashear (len bytes en data).

SHA1_Final() coloca el hash del mensaje en md, que debe tener espacio para SHA_DIGEST_LENGTH == 20 bytes de salida, y borra el SHA_CTX.

Las familias de funciones SHA224, SHA256, SHA384 y SHA512 operan de la misma manera que para las funciones SHA1. Tenga en cuenta que SHA224 y SHA256 utilizan un objeto SHA256_CTX en lugar de SHA_CTX. SHA384 y SHA512 utilizan SHA512_CTX. El buffer md debe tener espacio para la salida de la variante SHA utilizada (definida por SHA224_DIGEST_LENGTH, SHA256_DIGEST_LENGTH, SHA384_DIGEST_LENGTH y SHA512_DIGEST_LENGTH). Tenga en cuenta también que, al igual que para la función SHA1() anterior, las funciones SHA224(), SHA256(), SHA384() y SHA512() no son seguras para hilos si md es NULL.

VALORES DE RETORNO

SHA1(), SHA224(), SHA256(), SHA384() y SHA512() devuelven un puntero al valor del hash.

SHA1_Init(), SHA1_Update() y SHA1_Final() y las funciones equivalentes SHA224, SHA256, SHA384 y SHA512 devuelven 1 para éxito, 0 en caso contrario.
