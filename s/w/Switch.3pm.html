NOMBRE

Switch - Una sentencia `switch` para Perl, no usar si se puede usar `given`/`when`

SINOPSIS

use Switch;
switch ($val) {
    case 1          { print "número 1" }
    case "a"        { print "cadena a" }
    case [1..10,42] { print "número en lista" }
    case (\@array)  { print "número en lista" }
    case /\w+/      { print "patrón" }
    case qr/\w+/    { print "patrón" }
    case (\%hash)   { print "entrada en hash" }
    case (\&sub)    { print "argumento a subrutina" }
    else            { print "el caso anterior no fue verdadero" }
}

ANTECEDENTES

[Saltar a "DESCRIPCIÓN" si no te importan los porqués de esta estructura de control]

Al intentar diseñar un mecanismo de `case` "navaja suiza" adecuado para Perl, es útil generalizar esta noción de prueba condicional distribuida tanto como sea posible. Específicamente, el concepto de "coincidencia" entre el valor del switch y los diversos valores de los casos no tiene por qué limitarse a la igualdad numérica (o de cadena o referencial), como ocurre en otros lenguajes. De hecho, como ilustra la Tabla 1, Perl ofrece al menos dieciocho formas diferentes en las que dos valores podrían generar una coincidencia.

En realidad, la Tabla 1 cubre 31 alternativas, porque solo las pruebas de igualdad e intersección son conmutativas; en todos los demás casos, los roles de las variables $s y $c podrían invertirse para producir una prueba diferente. Por ejemplo, en lugar de probar un solo hash para la existencia de una serie de claves ("si existe $s->{$c}"), se podría probar la existencia de una única clave en una serie de hashes ("si existe $c->{$s}").

DESCRIPCIÓN

El módulo Switch.pm implementa un mecanismo de `case` generalizado que cubre la mayoría (pero no todas) de las numerosas combinaciones posibles de valores de switch y case descritas anteriormente.

El módulo aumenta la sintaxis estándar de Perl con dos nuevas sentencias de control: "switch" y "case". La sentencia "switch" toma un único argumento escalar de cualquier tipo, especificado entre paréntesis. "switch" almacena este valor como el valor del switch actual en una variable de control (localizada). El valor va seguido de un bloque que puede contener una o más sentencias de Perl (incluida la sentencia "case" descrita a continuación). El bloque se ejecuta incondicionalmente una vez que se ha almacenado el valor del switch.

Una sentencia "case" toma un único argumento escalar (entre paréntesis obligatorios si es una variable; de lo contrario, los paréntesis son opcionales) y selecciona el tipo apropiado de coincidencia entre ese argumento y el valor del switch actual. El tipo de coincidencia utilizado está determinado por los tipos respectivos del valor del switch y el argumento "case", según se especifica en la Tabla 1. Si la coincidencia es exitosa, se ejecuta el bloque obligatorio asociado con la sentencia "case".

En la mayoría de los demás aspectos, la sentencia "case" es semánticamente idéntica a una sentencia "if". Por ejemplo, puede ir seguida de una cláusula "else" y puede usarse como calificador de sentencia posfijo.

Sin embargo, cuando se ejecuta un bloque "case", el control se transfiere automáticamente a la sentencia posterior al bloque "switch" envolvente más cercano, en lugar de a la siguiente sentencia dentro del bloque. En otras palabras, el éxito de cualquier sentencia "case" evita que se ejecuten otros casos en el mismo ámbito. Pero vea "Permitir el paso a través" a continuación.

En conjunto, estas dos nuevas sentencias proporcionan un mecanismo de `case` completamente generalizado:

use Switch;
# Y MÁS TARDE...
%especial = ( woohoo => 1,  d'oh => 1 );
while (<>) {
    chomp;
    switch ($_) {
        case (%especial) { print "homer\n"; }      # si $especial{$_}
        case /[a-z]/i   { print "alfa\n"; }      # si $_ =~ /a-z/i
        case [1..9]     { print "número pequeño\n"; }  # si $_ en [1..9]
        case { $_[0] >= 10 } { print "número grande\n"; } # si $_ >= 10
        print "debe ser puntuación\n" case /\W/;  # si $_ ~= /\W/
    }
}

Tenga en cuenta que los "switch"es pueden anidarse dentro de bloques "case" (o cualquier otro) y una serie de sentencias "case" pueden probar diferentes tipos de coincidencias (membresía en hash, coincidencia de patrón, intersección de array, igualdad simple, etc.) contra el mismo valor de switch.

El uso de pruebas de intersección contra una referencia a un array es particularmente útil para agregar casos integrales:

sub clasificar_digito
{
        switch ($_[0]) { case 0            { return 'cero' }
                         case [2,4,6,8]    { return 'par' }
                         case [1,3,5,7,9]  { return 'impar' }
                         case /[A-F]/i     { return 'hexadecimal' }
                       }
}

Permitir el paso a través

El paso a través (intentar otro caso después de que uno ya haya tenido éxito) suele ser una Mala Idea en una sentencia switch. Sin embargo, esto es Perl, no un estado policial, por lo que SÍ hay una manera de hacerlo, si es que debe.

Si un bloque "case" ejecuta un "next" sin destino, el control se transfiere inmediatamente a la sentencia posterior a la sentencia "case" (es decir, normalmente a otro caso), en lugar de salir del bloque "switch" envolvente.

Por ejemplo:

switch ($val) {
        case 1      { manejar_num_1(); next }    # y probar el siguiente caso...
        case "1"    { manejar_str_1(); next }    # y probar el siguiente caso...
        case [0..9] { manejar_num_cualquiera(); }       # y terminamos
        case /\d/   { manejar_dig_cualquiera(); next }  # y probar el siguiente caso...
        case /.*/   { manejar_str_cualquiera(); next }  # y probar el siguiente caso...
}

Si $val contuviera el número 1, el bloque "switch" anterior llamaría a las tres primeras rutinas "manejar_...", saltando a la siguiente prueba de caso cada vez que encontrara un "next". Después de que se ejecutara el tercer bloque "case", el control saltaría al final del bloque "switch" envolvente.

Por otro lado, si $val contuviera 10, solo se llamarían las dos últimas rutinas "manejar_...".

Tenga en cuenta que este mecanismo permite la noción de *paso a través condicional*. Por ejemplo:

switch ($val)
