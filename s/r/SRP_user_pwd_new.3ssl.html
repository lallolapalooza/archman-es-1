SRP_user_pwd_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SRP_USER_PWD_NEW(3ssl) OpenSSL SRP_USER_PWD_NEW(3ssl)

NOMBRE

SRP_user_pwd_new, SRP_user_pwd_free, SRP_user_pwd_set1_ids, SRP_user_pwd_set_gN, SRP_user_pwd_set0_sv - Funciones para crear un registro de información del verificador de usuario SRP

SINOPSIS

#include <openssl/srp.h>

Las siguientes funciones están obsoletas desde OpenSSL 3.0 y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, consulte openssl_user_macros(7):

SRP_user_pwd *SRP_user_pwd_new(void);
void SRP_user_pwd_free(SRP_user_pwd *user_pwd);
int SRP_user_pwd_set1_ids(SRP_user_pwd *user_pwd, const char *id, const char *info);
void SRP_user_pwd_set_gN(SRP_user_pwd *user_pwd, const BIGNUM *g, const BIGNUM *N);
int SRP_user_pwd_set0_sv(SRP_user_pwd *user_pwd, BIGNUM *s, BIGNUM *v);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. No hay funciones de reemplazo disponibles en este momento.

La función SRP_user_pwd_new() asigna una estructura para almacenar un registro de verificador de usuario.

La función SRP_user_pwd_free() libera la estructura user_pwd. Si user_pwd es NULL, no se hace nada.

La función SRP_user_pwd_set1_ids() establece el nombre de usuario en id y la información opcional del usuario en info para user_pwd. La biblioteca asigna nuevas copias de id e info, el llamante aún es propietario de la memoria original.

La función SRP_user_pwd_set0_sv() establece la sal del usuario en s y el verificador en v para user_pwd. La biblioteca asume la propiedad de los valores, el llamante no debe liberarlos.

La función SRP_user_pwd_set_gN() establece los parámetros del grupo SRP para user_pwd. La memoria no es liberada por SRP_user_pwd_free(); el llamante debe asegurarse de que se libere una vez que ya no se utilice.

VALORES DE RETORNO

SRP_user_pwd_set1_ids() devuelve 1 si tiene éxito y 0 si falla o si id era NULL.

SRP_user_pwd_set0_sv() devuelve 1 si tanto s como v no son NULL, 0 en caso contrario.

VER TAMBIÉN

openssl-srp(1), SRP_create_verifier(3), SRP_VBASE_new(3), SSL_CTX_set_srp_password(3)

HISTORIA

Estas funciones se hicieron públicas en OpenSSL 3.0 y están obsoletas.
