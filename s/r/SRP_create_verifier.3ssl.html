SRP_create_verifier(3ssl)

Paquete: openssl

Licencias: Apache-2.0

SRP_CREATE_VERIFIER(3ssl) OpenSSL SRP_CREATE_VERIFIER(3ssl)

NOMBRE

SRP_create_verifier_ex, SRP_create_verifier, SRP_create_verifier_BN_ex, SRP_create_verifier_BN, SRP_check_known_gN_param, SRP_get_default_gN - Primitivas de autenticación SRP

SINOPSIS

#include <openssl/srp.h>

Las siguientes funciones han sido **marcadas para su eliminación** (deprecated) desde OpenSSL 3.0, y pueden ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int SRP_create_verifier_BN_ex(const char *user, const char *pass, BIGNUM **salt,
                              BIGNUM **verifier, const BIGNUM *N,
                              const BIGNUM *g, OSSL_LIB_CTX *libctx,
                              const char *propq);
char *SRP_create_verifier_BN(const char *user, const char *pass, BIGNUM **salt,
                             BIGNUM **verifier, const BIGNUM *N, const BIGNUM *g);
char *SRP_create_verifier_ex(const char *user, const char *pass, char **salt,
                             char **verifier, const char *N, const char *g,
                             OSSL_LIB_CTX *libctx, const char *propq);
char *SRP_create_verifier(const char *user, const char *pass, char **salt,
                          char **verifier, const char *N, const char *g);
char *SRP_check_known_gN_param(const BIGNUM *g, const BIGNUM *N);
SRP_gN *SRP_get_default_gN(const char *id);

DESCRIPCIÓN

Todas las funciones descritas en esta página están **marcadas para su eliminación** (deprecated). No hay funciones de reemplazo disponibles por el momento.

La función SRP_create_verifier_BN_ex() crea un verificador de contraseña SRP a partir de los parámetros proporcionados, tal como se definen en la sección 2.4 de RFC 5054, utilizando el contexto de biblioteca libctx y la cadena de consulta de propiedades propq. Cualquier algoritmo criptográfico que necesite ser obtenido utilizará libctx y propq. Véase "ALGORITHM FETCHING" en crypto(7).

SRP_create_verifier_BN() es igual a SRP_create_verifier_BN_ex() excepto que se utiliza el contexto de biblioteca y la cadena de consulta de propiedades predeterminados.

Al salir con éxito, *verifier apuntará a un BIGNUM recién asignado que contiene el verificador y (si no se proporcionó una sal) *salt se poblará con un BIGNUM recién asignado que contiene una sal aleatoria. Si *salt no es NULL, se utilizará la sal proporcionada en su lugar. El llamante es responsable de liberar los BIGNUMs *salt y *verifier asignados (use BN_free(3)).

La función SRP_create_verifier() es similar a SRP_create_verifier_BN() pero todos los parámetros numéricos están en una codificación base64 no estándar diseñada originalmente para la compatibilidad con libsrp. Esto está presente principalmente por compatibilidad histórica y se desaconseja su uso. Es posible pasar NULL como N y un ID de grupo SRP como g en su lugar para cargar los valores gN apropiados (véase SRP_get_default_gN()). Si tanto N como g son NULL, se utilizan los parámetros del grupo SRP de 8192 bits. El llamante es responsable de liberar *salt y *verifier asignados (use OPENSSL_free(3)).

La función SRP_check_known_gN_param() verifica que g y N sean parámetros de grupo SRP válidos de la sección A del RFC 5054.

La función SRP_get_default_gN() devuelve los parámetros gN para el tamaño de grupo SRP id del RFC 5054. Los IDs conocidos son "1024", "1536", "2048", "3072", "4096", "6144" y "8192".

VALORES DE RETORNO

SRP_create_verifier_BN_ex() y SRP_create_verifier_BN() devuelven 1 en caso de éxito y 0 en caso de fallo.

SRP_create_verifier_ex() y SRP_create_verifier() devuelven NULL en caso de fallo y un valor no NULL en caso de éxito: "*" si N no es NULL, el ID del grupo seleccionado en caso contrario. Este valor no debe ser liberado.

SRP_check_known_gN_param() devuelve la representación de texto del ID del grupo (es decir, el tamaño de bits del primo) o NULL si los argumentos no son parámetros de grupo SRP válidos. Este valor no debe ser liberado.

SRP_get_default_gN() devuelve NULL si id no es un tamaño de grupo válido, o los parámetros del grupo de 8192 bits si id es NULL.

EJEMPLOS

Generar y almacenar un verificador de contraseña de 8192 bits (manejo de errores omitido para mayor claridad):

#include <openssl/bn.h>
#include <openssl/srp.h>
const char *username = "usuario";
const char *password = "contraseña";
SRP_VBASE *srpData = SRP_VBASE_new(NULL);
SRP_gN *gN = SRP_get_default_gN("8192");
BIGNUM *salt = NULL, *verifier = NULL;
SRP_create_verifier_BN_ex(username, password, &salt, &verifier, gN->N, gN->g,
                          NULL, NULL);
SRP_user_pwd *pwd = SRP_user_pwd_new();
SRP_user_pwd_set1_ids(pwd, username, NULL);
SRP_user_pwd_set0_sv(pwd, salt, verifier);
SRP_user_pwd_set_gN(pwd, gN->g, gN->N);
SRP_VBASE_add0_user(srpData, pwd);

VER TAMBIÉN

openssl-srp(1), SRP_VBASE_new(3), SRP_user_pwd_new(3)

HISTORIA

SRP_create_verifier_BN_ex() y SRP_create_verifier_ex() se introdujeron en OpenSSL 3.0. Todas las demás funciones se añadieron en OpenSSL 1.0.1.

Todas estas funciones fueron marcadas para su eliminación (deprecated) en OpenSSL 3.0.
