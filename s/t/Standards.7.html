XSTANDARDS(7) Manual de Información Miscelánea XSTANDARDS(7)

NOMBRE

XStandards - Estándares y Especificaciones del Sistema de Ventanas X

DESCRIPCIÓN

El objetivo principal del X Consortium fue promover la cooperación dentro de la industria informática en la creación de interfaces de software estándar en todas las capas del entorno del Sistema de Ventanas X. El X Consortium produjo estándares: documentos que definían protocolos de red, interfaces de programación y otros aspectos del entorno X. Estos estándares continúan existiendo en las versiones de X.Org Foundation. La X.Org Foundation también produce especificaciones. Al igual que los Estándares del Sistema de Ventanas X, estos son documentos que definen protocolos de red, interfaces de programación y otros aspectos del entorno X. Bajo los auspicios de The Open Group, los estándares del Sistema de Ventanas X, las especificaciones de X.Org Foundation y otras especificaciones son la base de porciones de las diversas especificaciones CAE de The Open Group.

El estado de varios estándares, especificaciones y el software en la distribución X11R7.0 se explica a continuación.

NO ES ESTÁNDARES

La distribución X11R7.0 contiene implementaciones de *muestra*, no implementaciones de *referencia*. Aunque se cree que gran parte del código es correcto, se debe asumir que el código es erróneo siempre que entre en conflicto con la especificación.

Los únicos estándares del Sistema de Ventanas X son los enumerados anteriormente. Ningún otro documento, archivo de inclusión o software en X11R7.0 tiene un estatus especial dentro del Sistema de Ventanas X. Por ejemplo, ninguno de los siguientes son estándares: interfaces internas del servidor de muestra; la extensión MIT-SHM; el Athena Widget Set; la biblioteca Xmu; la biblioteca Xau; la base de datos RGB; la base de datos X Locale; las fuentes distribuidas con X11R7.0; las aplicaciones distribuidas con X11R7.0; los archivos de inclusión <X11/XWDFile.h>

X REGISTRO

La Fundación X.Org mantiene un registro de ciertos elementos relacionados con X, para ayudar a evitar conflictos y a compartir dichos elementos.

El registro se publica como parte de la distribución del software del Sistema de Ventanas X. La última versión también puede encontrarse en

ftp://ftp.x.org/pub/DOCS/registry
El Registro X y los nombres en él no son estándares del Sistema de Ventanas X.
