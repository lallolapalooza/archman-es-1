STAILQ(3) Library Functions Manual STAILQ(3)

NOMBRE

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implementation of a singly linked tail queue

BIBLIOTECA

Standard C library (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);

                         STAILQ_ENTRY NAME);
void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

Note: Identical macros prefixed with SIMPLEQ instead of STAILQ exist; see VERSIONS.

DESCRIPCIÓN

Estas macros definen y operan sobre colas de listas simples enlazadas por el final (tail queues).

En las definiciones de las macros, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro STAILQ_HEAD().

Creación

Una cola de listas simples enlazadas por el final es encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos que se enlazarán en la cola. Un puntero a la cabeza de la cola se puede declarar más tarde como:


struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

STAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola head.

STAILQ_INIT() inicializa la cola referenciada por head.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elm al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elm al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elm después del elemento listelm.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por head en la dirección hacia adelante, asignando cada elemento sucesivamente a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elm de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben utilizar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

STAILQ_FIRST(), y STAILQ_NEXT() devuelven un puntero a la estructura TYPE primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cola head.

VERSIONES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se les dio nombres diferentes en diferentes BSD. STAILQ se originó en FreeBSD, y SIMPLEQ se originó en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por la falta de un equivalente SIMPLEQ para STAILQ_CONCAT().

BUGS

STAILQ_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado dentro del bucle sin interferir con el recorrido.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* Singly linked tail queue */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Singly linked tail queue
                                               head */
    STAILQ_INIT(&head);                     /* Initialize the queue */
    n1 = malloc(sizeof(struct entry));      /* Insert at the head */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insert at the tail */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insert after */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Deletion */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Deletion from the head */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }

DESCRIPTION

These macros provide a way to define and manipulate singly linked lists. The macros are implemented using a common structure, and the usage is almost identical to the doubly linked list macros. The main difference is that the singly linked list does not have a pointer to the previous element, which simplifies the list structure but reduces the efficiency of some operations.

The macros are defined in the <sys/queue.h> header file. The user must define the structure of the list nodes, which must contain a pointer to the next node. The list head is typically defined as a structure containing a pointer to the first node.

The following macros are available:

STAILQ_HEAD(mylist, type);
Declares a type named `mylist` that represents a singly linked list of elements of type `type`. The list head is a pointer to the first element of the list.
STAILQ_INIT(head);
Initializes the list pointed to by `head` to be an empty list.
STAILQ_EMPTY(head);
Returns true if the list is empty, false otherwise.
STAILQ_FIRST(head);
Returns a pointer to the first element in the list, or NULL if the list is empty.
STAILQ_NEXT(elm, field);
Returns a pointer to the next element in the list after `elm`, or NULL if `elm` is the last element.
STAILQ_LAST(head, type, field);
Returns a pointer to the last element in the list, or NULL if the list is empty.
STAILQ_FOREACH(p, head, field);
Iterates through the list, assigning a pointer to each element to `p` in turn. The `field` argument specifies the name of the pointer field within the list elements that points to the next element.
STAILQ_FOREACH_REVERSE(p, head, type, field);
Iterates through the list in reverse order, assigning a pointer to each element to `p` in turn. This macro is less efficient than `STAILQ_FOREACH` because it requires traversing the list from the beginning to find the previous element.
STAILQ_FOREACH_SAFE(p, head, field);
Similar to `STAILQ_FOREACH`, but safe to use when the list may be modified during iteration (e.g., by removing elements).
STAILQ_FOREACH_REVERSE_SAFE(p, head, type, field);
Similar to `STAILQ_FOREACH_REVERSE`, but safe to use when the list may be modified during iteration.
STAILQ_INSERT_HEAD(head, elm, field);
Inserts the element `elm` at the head of the list pointed to by `head`. The `field` argument specifies the name of the pointer field within the list elements that points to the next element.
STAILQ_INSERT_TAIL(head, elm, field);
Inserts the element `elm` at the tail of the list pointed to by `head`. The `field` argument specifies the name of the pointer field within the list elements that points to the next element.
STAILQ_INSERT_AFTER(head, listelm, elm, field);
Inserts the element `elm` after the element `listelm` in the list pointed to by `head`. The `field` argument specifies the name of the pointer field within the list elements that points to the next element.
STAILQ_INSERT_BEFORE(head, listelm, elm, field);
Inserts the element `elm` before the element `listelm` in the list pointed to by `head`. The `field` argument specifies the name of the pointer field within the list elements that points to the next element.
STAILQ_REMOVE(head, elm, type, field);
Removes the element `elm` from the list pointed to by `head`. The `type` argument specifies the type of the list elements, and `field` specifies the name of the pointer field within the list elements that points to the next element.
STAILQ_REMOVE_HEAD(head, field);
Removes and returns the first element from the list pointed to by `head`. The `field` argument specifies the name of the pointer field within the list elements that points to the next element.
STAILQ_REMOVE_TAIL(head, field);
Removes and returns the last element from the list pointed to by `head`. The `field` argument specifies the name of the pointer field within the list elements that points to the next element.
STAILQ_PREPEND(head, elm, field);
Inserts the element `elm` at the head of the list pointed to by `head`. This macro is equivalent to `STAILQ_INSERT_HEAD`.
STAILQ_CONCAT(head1, head2, field);
Appends the list pointed to by `head2` to the end of the list pointed to by `head1`. The list `head2` will be empty after the operation.
STAILQ_SWAP(head1, head2, type, field);
Swaps the contents of the two lists pointed to by `head1` and `head2`. The `type` argument specifies the type of the list elements, and `field` specifies the name of the pointer field within the list elements that points to the next element.

RETURN VALUE

Macros that return a pointer to an element return NULL if the list is empty or the element is not found. Macros that return a boolean value return true if the condition is met, false otherwise.

VERSIONS

These macros are available in libbsd version 0.10 and later.

BUGS

The `STAILQ_FOREACH_REVERSE` and `STAILQ_FOREACH_REVERSE_SAFE` macros are inefficient as they require traversing the list from the beginning to find the previous element. For more efficient reverse traversal, consider using a doubly linked list.

STANDARDS

The singly linked list macros are similar to those found in BSD systems and are not part of any official C standard. However, they are widely used and provide a convenient way to manage linked lists.

HISTORY

The singly linked list macros first appeared in the 4.4BSD operating system.

EXAMPLES

The following example demonstrates how to use the singly linked list macros to create, populate, and traverse a list:

#include <stdio.h>
#include <stdlib.h>
#include <bsd/sys/queue.h>

/* Define the structure of the list nodes */
struct my_entry {
    int data;
    STAILQ_ENTRY(my_entry) entries;
};

int
main(void)
{
    struct my_list {
        struct my_entry *stqh_first;
        struct my_entry **stqh_last;
    } head;
    struct my_entry *np, *np2;

    /* Initialize the list */
    STAILQ_INIT(&head);

    /* Insert elements into the list */
    np = malloc(sizeof(struct my_entry));
    np->data = 10;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct my_entry));
    np->data = 20;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(struct my_entry));
    np->data = 30;
    STAILQ_INSERT_HEAD(&head, np, entries);

    /* Forward traversal */
    printf("Forward traversal:\n");
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

    /* TailQ deletion */
    printf("\nDeleting elements:\n");
    np = STAILQ_FIRST(&head);
    while (np != NULL) {
        np2 = STAILQ_NEXT(np, entries);
        printf("Freeing element with data: %i\n", np->data);
        free(np);
        np = np2;
    }

    /* Initialize the list again to ensure it's empty */
    STAILQ_INIT(&head);

    printf("\nList is now empty.\n");

    return EXIT_SUCCESS;
}
