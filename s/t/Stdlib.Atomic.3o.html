Módulo Atomic
: (module Stdlib__Atomic)

tipo !'a t

Una referencia atómica (mutable) a un valor de tipo 'a .

val make : 'a -> 'a t

Crea una referencia atómica.

val make_contended : 'a -> 'a t

Crea una referencia atómica que está sola en una línea de caché. Ocupa 4-16 veces más memoria que una asignada con make v .

El propósito principal es evitar el false-sharing (falso compartido) y la consecuente degradación del rendimiento. Cuando una CPU realiza una operación atómica, toma temporalmente posesión de una línea de caché completa que contiene la referencia atómica. Si varias referencias atómicas comparten la misma línea de caché, modificar estas regiones de memoria disjuntas simultáneamente se vuelve imposible, lo que puede crear un cuello de botella. Por lo tanto, como directriz general, si una referencia atómica está experimentando contención, asignarle su propia línea de caché puede mejorar el rendimiento.

val get : 'a t -> 'a

Obtiene el valor actual de la referencia atómica.

val set : 'a t -> 'a -> unit

Establece un nuevo valor para la referencia atómica.

val exchange : 'a t -> 'a -> 'a

Establece un nuevo valor para la referencia atómica y devuelve el valor actual.

val compare_and_set : 'a t -> 'a -> 'a -> bool

compare_and_set r seen v establece el nuevo valor de r a v solo si su valor actual es físicamente igual a seen — la comparación y la asignación ocurren atómicamente. Devuelve true si la comparación tuvo éxito (por lo que la asignación se realizó) y false en caso contrario.

val fetch_and_add : int t -> int -> int

fetch_and_add r n incrementa atómicamente el valor de r en n y devuelve el valor actual (antes del incremento).

val incr : int t -> unit

incr r incrementa atómicamente el valor de r en 1 .

val decr : int t -> unit

decr r decrementa atómicamente el valor de r en 1 .

module Loc : sig end

"Ubicaciones" atómicas, como campos de registros.

Ejemplos

Coordinación Básica de Hilos

Un uso básico es tener contadores globales que se actualizan de forma segura para hilos, por ejemplo, para mantener algún tipo de métrica sobre las E/S realizadas por el programa. Otro uso básico es coordinar la terminación de hilos en un programa determinado, por ejemplo, cuando un hilo encuentra una respuesta, o cuando el programa se cierra por el usuario.

Aquí, por ejemplo, intentaremos encontrar un número cuyo hash cumpla una propiedad básica. Para ello, ejecutaremos varios hilos que probarán números aleatorios hasta que encuentren uno que funcione.

Por supuesto, la salida a continuación es una ejecución de muestra y cambiará cada vez que se ejecute el programa.

    (* uso para la terminación *)
    let stop_all_threads = Atomic.make false
    (* número total de intentos individuales para encontrar un número *)
    let num_attempts = Atomic.make 0
    (* encuentra un número que satisfaga [p], ... probando números aleatorios
       hasta que uno encaje. *)
    let find_number_where (p:int -> bool) =
      let rand = Random.State.make_self_init() in
      while not (Atomic.get stop_all_threads) do
        let n = Random.State.full_int rand max_int in
        ignore (Atomic.fetch_and_add num_attempts 1 : int);
        if p (Hashtbl.hash n) then (
          Printf.printf "encontrado %d (hash=%d)\n%!" n (Hashtbl.hash n);
          Atomic.set stop_all_threads true; (* indicar a todos los hilos que se detengan *)
        )
      done;;
    (* ejecuta varios dominios para buscar un [n] donde [hash n <= 100] *)
    let () =
      let criterion n = n <= 100 in
      let threads =
        Array.init 8
          (fun _ -> Domain.spawn (fun () -> find_number_where criterion))
      in
      Array.iter Domain.join threads;
      Printf.printf "número total de intentos: %d\n%!"
        (Atomic.get num_attempts) ;;
    - : unit = ()
    encontrado 1651745641680046833 (hash=33)
    número total de intentos: 30230350

Pila de Treiber

Otro ejemplo es una pila básica de Treiber (una pila segura para hilos) que puede compartirse de forma segura entre hilos.

Observe cómo tanto push como pop son recursivos, ya que intentan intercambiar la nueva pila (con uno o más elementos) con la pila antigua. Esto es concurrencia optimista: cada iteración de, por ejemplo, push stack x obtiene la pila antigua l y espera que para cuando intente reemplazar l por x::l , nadie más haya tenido tiempo de modificar la lista. Si el compare_and_set falla, significa que fuimos demasiado optimistas y debemos intentarlo de nuevo.

    type 'a stack = 'a list Atomic.t
    let rec push (stack: _ stack) elt : unit =
      let cur = Atomic.get stack in
      let success = Atomic.compare_and_set stack cur (elt :: cur) in
      if not success then
        push stack elt
    let rec pop (stack: _ stack) : _ option =
      let cur = Atomic.get stack in
      match cur with
      | [] -> None
      | x :: tail ->
        let success = Atomic.compare_and_set stack cur tail in
        if success then Some x
        else pop stack
    # let st = Atomic.make []
    # push st 1
    - : unit = ()
    # push st 2
    - : unit = ()
    # pop st
    - : int option = Some 2
    # pop st
    - : int option = Some 1
    # pop st
    - : int option = None
