type spec =
| Unit de (unit -> unit)
(* Llamar a la función con argumento unit
*)
| Bool de (bool -> unit)
(* Llamar a la función con un argumento booleano
*)
| Set de bool ref
(* Establecer la referencia a verdadero
*)
| Clear de bool ref
(* Establecer la referencia a falso
*)
| String de (string -> unit)
(* Llamar a la función con un argumento de cadena
*)
| Set_string de string ref
(* Establecer la referencia al argumento de cadena
*)
| Int de (int -> unit)
(* Llamar a la función con un argumento entero
*)
| Set_int de int ref
(* Establecer la referencia al argumento entero
*)
| Float de (float -> unit)
(* Llamar a la función con un argumento de punto flotante
*)
| Set_float de float ref
(* Establecer la referencia al argumento de punto flotante
*)
| Tuple de spec list
(* Tomar varios argumentos según la lista de especificaciones
*)
| Symbol de string list * (string -> unit)
(* Tomar uno de los símbolos como argumento y llamar a la función con el símbolo
*)
| Rest de (string -> unit)
(* Dejar de interpretar palabras clave y llamar a la función con cada argumento restante
*)
| Rest_all de (string list -> unit)
(* Dejar de interpretar palabras clave y llamar a la función con todos los argumentos restantes
*)
| Expand de (string -> string array)
(* Si los argumentos restantes a procesar son de la forma ["-foo"; "arg"] @ rest donde "foo" está registrado como Expand f , entonces se procesan los argumentos f "arg" @ rest . Solo permitido en parse_and_expand_argv_dynamic .
*)

El tipo concreto que describe el comportamiento asociado a una palabra clave.

type key = string

type doc = string

type usage_msg = string

type anon_fun = string -> unit

val parse : (key * spec * doc) list -> anon_fun -> usage_msg -> unit

Arg.parse speclist anon_fun usage_msg analiza la línea de comandos. speclist es una lista de tuplas (key, spec, doc) . key es la palabra clave de la opción, debe comenzar con el carácter '-' . spec da el tipo de opción y la función a llamar cuando se encuentra esta opción en la línea de comandos. doc es una descripción de una línea de esta opción. anon_fun se llama en argumentos anónimos. Las funciones en spec y anon_fun se llaman en el mismo orden en que sus argumentos aparecen en la línea de comandos.

Si ocurre un error, Arg.parse sale del programa, después de imprimir en la salida estándar un mensaje de error como el siguiente:

- La razón del error: opción desconocida, argumento inválido o faltante, etc.

- usage_msg

- La lista de opciones, cada una seguida por la cadena de documentación correspondiente. Advertencia: las opciones que tienen una cadena de documentación vacía no se incluirán en la lista.

Para que el usuario pueda especificar argumentos anónimos que comienzan con un - , incluya por ejemplo ("-", String anon_fun, doc) en speclist .

Por defecto, parse reconoce dos opciones de unidad, -help y --help , que imprimirán en la salida estándar usage_msg y la lista de opciones, y saldrán del programa. Puede anular este comportamiento especificando sus propias opciones -help y --help en speclist .

val parse_dynamic : (key * spec * doc) list ref -> anon_fun -> usage_msg -> unit

Igual que Arg.parse , excepto que el argumento speclist es una referencia y puede actualizarse durante el análisis. Un uso típico para esta característica es analizar líneas de comandos de la forma:

- comando subcomando options donde la lista de opciones depende del valor del argumento subcomando.

Desde 4.01

val parse_argv : ?current:int ref -> string array -> (key * spec * doc) list -> anon_fun -> usage_msg -> unit

Arg.parse_argv ~current args speclist anon_fun usage_msg analiza el array args como si fuera la línea de comandos. Utiliza y actualiza el valor de ~current (si se proporciona), o Arg.current . Debe establecerlo antes de llamar a parse_argv . El valor inicial de current es el índice del nombre del programa (argumento 0) en el array. Si ocurre un error, Arg.parse_argv lanza Arg.Bad con el mensaje de error como argumento. Si se proporciona la opción -help o --help , Arg.parse_argv lanza Arg.Help con el mensaje de ayuda como argumento.

val parse_argv_dynamic : ?current:int ref -> string array -> (key * spec * doc) list ref -> anon_fun -> string -> unit

Igual que Arg.parse_argv , excepto que el argumento speclist es una referencia y puede actualizarse durante el análisis. Ver Arg.parse_dynamic .

Desde 4.01

val parse_and_expand_argv_dynamic : int ref -> string array ref -> (key * spec * doc) list ref -> anon_fun -> string -> unit

Igual que Arg.parse_argv_dynamic , excepto que el argumento argv es una referencia y puede actualizarse durante el análisis de los argumentos Expand . Ver Arg.parse_argv_dynamic .

Desde 4.05

val parse_expand : (key * spec * doc) list -> anon_fun -> usage_msg -> unit

Igual que Arg.parse , excepto que los argumentos Expand están permitidos y la referencia Arg.current no se actualiza.

Desde 4.05

exception Help de string

Lanzada por Arg.parse_argv cuando el usuario solicita ayuda.

exception Bad de string

Las funciones en spec o anon_fun pueden lanzar Arg.Bad con un mensaje de error para rechazar argumentos inválidos. Arg.Bad también es lanzada por Arg.parse_argv en caso de error.

val usage : (key * spec * doc) list -> usage_msg -> unit

Arg.usage speclist usage_msg imprime en la salida estándar un mensaje de error que incluye la lista de opciones válidas. Este es el mismo mensaje que Arg.parse imprime en caso de error. speclist y usage_msg son los mismos que para Arg.parse .

val usage_string : (key * spec * doc) list -> usage_msg -> string

Devuelve el mensaje que habría impreso Arg.usage , si se le proporcionaron los mismos parámetros.

val align : ?limit:int -> (key * spec * doc) list -> (key * spec * doc) list

Alinea las cadenas de documentación insertando espacios en el primer separador de alineación (tabulador o, si no se encuentra tabulador, espacio), según la longitud de la palabra clave. Utilice un separador de alineación como primer carácter en una cadena de documentación si desea alinear toda la cadena. Las cadenas de documentación correspondientes a los argumentos Symbol se alinean en la línea siguiente.

val current : int ref

Posición (en Sys.argv ) del argumento que se está procesando. Puede cambiar este valor, por ejemplo, para forzar a Arg.parse a omitir algunos argumentos. Arg.parse utiliza el valor inicial de Arg.current como el índice del argumento 0 (el nombre del programa) y comienza a analizar los argumentos en el siguiente elemento.

val read_arg : string -> string array

Arg.read_arg file lee argumentos de línea de comandos terminados por nueva línea del archivo file .

Desde 4.05

val read_arg0 : string -> string array

Idéntico a Arg.read_arg pero asume argumentos de línea de comandos terminados por carácter nulo.

Desde 4.05

NAME

Stdlib.Arg - Command line argument parsing

Module

module Arg : sig ... end

Documentation

The Arg module provides functions for parsing command-line arguments.

The main functions are:

  • Arg.parse: parses arguments according to a specification.
  • Arg.parse_argv: parses arguments according to a specification, given an array of arguments.
  • Arg.parse_cmdline: parses command-line arguments.
  • Arg.current_dir_name: name of the current directory.
  • Arg.usage_msg: usage message string.
  • Arg.usage: prints a usage message and exits.
  • Arg.usage_arg: prints a usage message for a single argument and exits.

The specification is given as a list of triples (specreg, arg, doc):

specreg
A pair of strings. The first string is the option name (e.g., "-f"). The second string is the argument to the option. If the argument is optional, it is enclosed in parentheses. If the option takes no argument, the second string is empty.
arg
A function that takes the option argument (a string) and performs the desired action.
doc
A string describing the option, used to generate the usage message.

There are several predefined functions for the arg component:

Arg.unit
For options that take no argument.
Arg.string
For options that take a string argument.
Arg.int
For options that take an integer argument.
Arg.float
For options that take a floating-point argument.
Arg.tuple (f1, f2)
Applies two functions to the argument.
Arg.symbol symbols
Matches the argument against a list of symbols.
Arg.required f
Makes an option required.

The Arg.parse function takes three arguments:

f
A function that takes the remaining non-option arguments (a string).
s
A usage message string.
l
A list of specifications for the options.

The Arg.parse_argv function is similar to Arg.parse, but takes an array of strings as the arguments to parse.

The Arg.parse_cmdline function parses the command-line arguments passed to the program.

The Arg.current_dir_name variable holds the name of the current directory.

The Arg.usage_msg variable holds the usage message string.

The Arg.usage function prints a usage message and exits.

The Arg.usage_arg function prints a usage message for a single argument and exits.

The following functions are used for writing arguments to a file:

val write_arg : string -> string array -> unit

Arg.write_arg file args writes the arguments args newline-terminated into the file file . If any of the arguments in args contains a newline, use Arg.write_arg0 instead.

Since 4.05

val write_arg0 : string -> string array -> unit

Identical to Arg.write_arg but uses the null character for terminator instead of newline.
