DOCUMENTACIÓN

Módulo Domain
: (módulo Stdlib__Domain)

Advertencia inestable. La interfaz de Dominio puede cambiar en el futuro de formas incompatibles.

tipo !'a t

Un dominio de tipo 'a t se ejecuta independientemente, produciendo finalmente un resultado de tipo 'a, o una excepción

val spawn : (unit -> 'a) -> 'a t

spawn f crea un nuevo dominio que se ejecuta en paralelo con el dominio actual.

Lanza Failure si el programa tiene recursos insuficientes para crear otro dominio.

val join : 'a t -> 'a

join d se bloquea hasta que el dominio d se completa. Si d resulta en un valor, entonces ese es devuelto por join d. Si d lanza una excepción no capturada, entonces esa es relanzada por join d.

tipo id = private int

Los dominios tienen identificadores enteros únicos

val get_id : 'a t -> id

get_id d devuelve el identificador del dominio d

val self : unit -> id

self () es el identificador del dominio en ejecución actual

val before_first_spawn : (unit -> unit) -> unit

before_first_spawn f registra f para ser llamado antes de que el primer dominio sea creado (spawned) por el programa. Las funciones registradas con before_first_spawn se llaman en el dominio principal (inicial). Las funciones registradas con before_first_spawn se llaman en orden 'primero en entrar, primero en salir': la función más antigua añadida con before_first_spawn se llama primero.

Lanza Invalid_argument si el programa ya ha creado un dominio.

val at_exit : (unit -> unit) -> unit

at_exit f registra f para ser llamado cuando el dominio actual termina. Nota que las callbacks de at_exit son locales al dominio y solo aplican al dominio que llama. Las funciones registradas se llaman en orden 'último en entrar, primero en salir': la función añadida más recientemente con at_exit se llama primero. Un ejemplo:

let temp_file_key = Domain.DLS.new_key (fun _ ->
  let tmp = snd (Filename.open_temp_file "" "") in
  Domain.at_exit (fun () -> close_out_noerr tmp);
  tmp)

El fragmento anterior crea una clave que, cuando se recupera por primera vez, abrirá un archivo temporal y registrará una callback de at_exit para cerrarlo, garantizando así que el descriptor no se filtre en caso de que el dominio actual termine.

val cpu_relax : unit -> unit

Si se está en bucle ocupado, llamar a cpu_relax () entre iteraciones mejorará el rendimiento en algunas arquitecturas de CPU

val is_main_domain : unit -> bool

is_main_domain () devuelve verdadero si se llama desde el dominio inicial.

val recommended_domain_count : unit -> int

El número máximo recomendado de dominios que deberían ejecutarse simultáneamente (incluyendo dominios ya en ejecución).

El valor devuelto es al menos 1.

val self_index : unit -> int

El índice del dominio actual. Es un entero único entre los dominios en ejecución, en el intervalo 0; N-1 donde N es el número máximo de dominios ejecutados simultáneamente hasta el momento.

El índice de un dominio terminado puede ser reutilizado para un nuevo dominio. Usa (Domain.self () :> int) en su lugar para un identificador único entre todos los dominios creados por el programa.
