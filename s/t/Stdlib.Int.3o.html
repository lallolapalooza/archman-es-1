Módulo Int
: (module Stdlib__Int)

Enteros

type t = int

El tipo para valores enteros.

val zero : int

zero es el entero 0.

val one : int

one es el entero 1.

val minus_one : int

minus_one es el entero -1.

val neg : int -> int

neg x es ~-x.

val add : int -> int -> int

add x y es la suma x + y.

val sub : int -> int -> int

sub x y es la resta x - y.

val mul : int -> int -> int

mul x y es la multiplicación x * y.

val div : int -> int -> int

div x y es la división x / y. Ver (/) para detalles.

val rem : int -> int -> int

rem x y es el resto x mod y. Ver (mod) para detalles.

val succ : int -> int

succ x es add x 1.

val pred : int -> int

pred x es sub x 1.

val abs : int -> int

abs x es el valor absoluto de x. Es decir, x si x es positivo y neg x si x es negativo. Advertencia: esto puede ser negativo si el argumento es Int.min_int.

val max_int : int

max_int es el entero representable más grande, 2 ^ Sys.int_size - 1 -1.

val min_int : int

min_int es el entero representable más pequeño, -2 ^ Sys.int_size - 1.

val logand : int -> int -> int

logand x y es el AND lógico a nivel de bits de x e y.

val logor : int -> int -> int

logor x y es el OR lógico a nivel de bits de x e y.

val logxor : int -> int -> int

logxor x y es el XOR lógico a nivel de bits de x e y.

val lognot : int -> int

lognot x es la negación lógica a nivel de bits de x.

val shift_left : int -> int -> int

shift_left x n desplaza x a la izquierda en n bits. El resultado no está especificado si n < 0 o n > Sys.int_size.

val shift_right : int -> int -> int

shift_right x n desplaza x a la derecha en n bits. Este es un desplazamiento aritmético: el bit de signo de x se replica y se inserta en los bits vacantes. El resultado no está especificado si n < 0 o n > Sys.int_size.

val shift_right_logical : int -> int -> int

shift_right x n desplaza x a la derecha en n bits. Este es un desplazamiento lógico: se insertan ceros en los bits vacantes independientemente del signo de x. El resultado no está especificado si n < 0 o n > Sys.int_size.

Predicados y comparaciones

val equal : int -> int -> bool

equal x y es true si y solo si x = y.

val compare : int -> int -> int

compare x y es compare x y pero más eficiente.

val min : int -> int -> int

Devuelve el menor de los dos argumentos.

val max : int -> int -> int

Devuelve el mayor de los dos argumentos.

Conversión

val to_float : int -> float

to_float x es x como número de punto flotante.

val of_float : float -> int

of_float x trunca x a un entero. El resultado no está especificado si el argumento es nan o cae fuera del rango de enteros representables.

val to_string : int -> string

to_string x es la representación escrita de x en decimal.

val seeded_hash : int -> int -> int

Una función hash sembrada para enteros, con el mismo valor de salida que Hashtbl.seeded_hash. Esta función permite que este módulo se pase como argumento al functor Hashtbl.MakeSeeded.

Desde 5.1

val hash : int -> int

Una función hash no sembrada para enteros, con el mismo valor de salida que Hashtbl.hash. Esta función permite que este módulo se pase como argumento al functor Hashtbl.Make.

Desde 5.1
