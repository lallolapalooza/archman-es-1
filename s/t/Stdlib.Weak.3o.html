Módulo Weak
: (module Stdlib__Weak)

Funciones de bajo nivel

type !'a t

El tipo de arreglos de punteros débiles (arreglos débiles). Un puntero débil es un valor que el recolector de basura puede borrar cuando el valor ya no es utilizado (a través de punteros normales) por el programa. Tenga en cuenta que las funciones de finalización se ejecutan antes de que se borren los punteros débiles, ya que las funciones de finalización pueden hacer que los valores vuelvan a estar vivos (antes de la versión 4.03, las funciones de finalización se ejecutaban después).

Se dice que un puntero débil está lleno si apunta a un valor, vacío si el valor fue borrado por el recolector de basura.

Notas:

-Los enteros no se asignan y no pueden almacenarse en arreglos débiles.

-Los arreglos débiles no pueden ser serializados utilizando output_value ni las funciones del módulo Marshal.

val create : int -> 'a t

Weak.create n devuelve un nuevo arreglo débil de longitud n. Todos los punteros están inicialmente vacíos.

Lanza Invalid_argument si n no está comprendido entre cero y Obj.Ephemeron.max_ephe_length (límites incluidos).

val length : 'a t -> int

Weak.length ar devuelve la longitud (número de elementos) de ar.

val set : 'a t -> int -> 'a option -> unit

Weak.set ar n (Some el) establece la celda n de ar para que sea un puntero (lleno) a el; Weak.set ar n None establece la celda n de ar como vacía.

Lanza Invalid_argument si n no está en el rango 0 a Weak.length ar - 1.

val get : 'a t -> int -> 'a option

Weak.get ar n devuelve None si la celda n de ar está vacía, Some x (donde x es el valor) si está llena.

Lanza Invalid_argument si n no está en el rango 0 a Weak.length ar - 1.

val get_copy : 'a t -> int -> 'a option

Weak.get_copy ar n devuelve None si la celda n de ar está vacía, Some x (donde x es una copia (superficial) del valor) si está llena. Además de los escollos con valores mutables, la diferencia interesante con get es que get_copy no impide que el recolector de basura incremental borre el valor en su ciclo actual ( get puede retrasar el borrado al siguiente ciclo del recolector de basura).

Lanza Invalid_argument si n no está en el rango 0 a Weak.length ar - 1.

Si el elemento es un bloque personalizado, no se copia.

val check : 'a t -> int -> bool

Weak.check ar n devuelve true si la celda n de ar está llena, false si está vacía. Tenga en cuenta que incluso si Weak.check ar n devuelve true , una llamada subsiguiente a Weak.get ar n puede devolver None.

Lanza Invalid_argument si n no está en el rango 0 a Weak.length ar - 1.

val fill : 'a t -> int -> int -> 'a option -> unit

Weak.fill ar ofs len el establece en el todos los punteros de ar desde ofs hasta ofs + len - 1.

Lanza Invalid_argument si ofs y len no designan un subarreglo válido de ar.

val blit : 'a t -> int -> 'a t -> int -> int -> unit

Weak.blit ar1 off1 ar2 off2 len copia len punteros débiles de ar1 (empezando en off1) a ar2 (empezando en off2). Funciona correctamente incluso si ar1 y ar2 son los mismos.

Lanza Invalid_argument si off1 y len no designan un subarreglo válido de ar1, o si off2 y len no designan un subarreglo válido de ar2.

Conjuntos de hashes débiles

Un conjunto de hashes débiles es un conjunto hasheado de valores. Cada valor puede desaparecer mágicamente del conjunto cuando ya no es utilizado por el resto del programa. Esto se usa normalmente para compartir estructuras de datos sin inducir fugas de memoria. Los conjuntos de hashes débiles se definen sobre valores de un módulo Hashtbl.HashedType; la relación equal y la función hash se toman de ese módulo. Diremos que v es una instancia de x si equal x v es true.

La relación equal debe poder operar sobre una copia superficial de los valores y dar el mismo resultado que con los valores mismos.

Accesos no sincronizados

Los accesos no sincronizados a conjuntos de hashes débiles son un error de programación. Los accesos no sincronizados a un conjunto de hashes débiles pueden llevar a un estado inválido del conjunto de hashes débiles. Por lo tanto, los accesos concurrentes a conjuntos de hashes débiles deben estar sincronizados (por ejemplo, con un Mutex.t).

module type S = sig end

La firma de salida del functor Weak.Make.

module Make : (H : Hashtbl.HashedType) -> sig end

Functor que construye una implementación de la estructura de conjunto de hashes débiles. H.equal no puede ser la igualdad física, ya que solo se le pasan copias superficiales de los elementos del conjunto.
