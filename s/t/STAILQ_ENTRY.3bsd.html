DESCRIPTION

These macros define and operate on four types of data structures which can be used in both C and C++ source code:

  1. Lists
  2. Singly-linked lists
  3. Singly-linked tail queues
  4. Tail queues
All four structures support the following functionality:
  1. Insertion of a new entry at the head of the list.
  2. Insertion of a new entry after any element in the list.
  3. O(1) removal of an entry from the head of the list.
  4. Forward traversal through the list.
  5. Swapping the contents of two lists.

Singly-linked lists are the simplest of the four data structures and support only the above functionality. Singly-linked lists are ideal for applications with large datasets and few or no removals, or for implementing a LIFO queue. Singly-linked lists add the following functionality:

  1. O(n) removal of any entry in the list.
  2. O(n) concatenation of two lists.

Singly-linked tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. O(n) removal of any entry in the list.
  3. They may be concatenated.
However:
  1. All list insertions must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

Singly-linked tail queues are ideal for applications with large datasets and few or no removals, or for implementing a FIFO queue.

All doubly linked types of data structures (lists and tail queues) additionally allow:

  1. Insertion of a new entry before any element in the list.
  2. O(1) removal of any entry in the list.
However:
  1. Each element requires two pointers rather than one.
  2. Code size and execution time of operations (except for removal) is about twice that of the singly-linked data-structures.

Linked lists are the simplest of the doubly linked data structures. They add the following functionality over the above:

  1. O(n) concatenation of two lists.
  2. They may be traversed backwards.
However:
  1. To traverse backwards, an entry to begin the traversal and the list in which it is contained must be specified.

Tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. They may be traversed backwards, from tail to head.
  3. They may be concatenated.
However:
  1. All list insertions and removals must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

In the macro definitions, TYPE is the name of a user defined structure. The structure must contain a field called NAME which is of type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, or TAILQ_ENTRY. In the macro definitions, CLASSTYPE is the name of a user defined class. The class must contain a field called NAME which is of type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, or TAILQ_CLASS_ENTRY. The argument HEADNAME is the name of a user defined structure that must be declared using the macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, or TAILQ_CLASS_HEAD. See the examples below for further explanation of how these macros are used.

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains a single pointer to the first element on the list and a single pointer to the last element on the list. The elements are doubly linked for efficient insertion and removal at either end of the list. New elements can be added to the list after an existing element, before an existing element, at the head of the list, or at the tail of the list. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro TAILQ_INIT initializes the list referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the list.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the tail of the list.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_REMOVE removes the element elm from the list.

The macro TAILQ_LAST returns the last element in the list or NULL if the list is empty.

The macro TAILQ_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro TAILQ_NEXT returns the next element in the list or NULL if the last element was supplied.

The macro TAILQ_PREV returns the previous element in the list or NULL if the first element was supplied.

The macro TAILQ_SWAP swaps the contents of the two lists head1 and head2.

COLAS DE LISTA SIMPLEMENTE ENLAZADA CON COLA

Una cola de lista simplemente enlazada se encabeza por una estructura definida mediante la macro STAILQ_HEAD. Esta estructura contiene dos punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están doblemente enlazados para minimizar la sobrecarga de espacio y la manipulación de punteros, aunque el tiempo de eliminación sea O(n). Los nuevos elementos se pueden agregar a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara así:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos en la cola. Una dirección de puntero a la cabeza de la cola se puede declarar posteriormente así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa como inicializador para la cola head.

La macro STAILQ_CONCAT concatenará la cola encabezada por head2 al final de la cola encabezada por head1, vaciando todos los elementos de la primera cola.

La macro STAILQ_EMPTY evalúa como verdadero si no hay elementos en la cola.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos de la cola.

La macro STAILQ_FIRST devuelve el primer elemento de la cola o NULL si la cola está vacía.

La macro STAILQ_FOREACH recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento encontrado previamente en la cola y comienza el bucle desde var en lugar del primer elemento de la cola referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí es posible eliminar var y liberarlo dentro del bucle sin interferir con la travesía.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento encontrado previamente en la cola y comienza el bucle desde var en lugar del primer elemento de la cola referenciada por head.

La macro STAILQ_INIT inicializa la cola referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola. Si la cola está vacía, el valor devuelto es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento en la cola, o NULL si este es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola.

La macro STAILQ_REMOVE_HEAD elimina el elemento del frente de la cola. Para optimizar la eficiencia, los elementos que se eliminen del frente de la cola deben usar esta macro explícitamente en lugar de la macro general STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola. Su uso debe evitarse ya que recorre toda la lista. Se debe usar una cola doblemente enlazada si esta macro es necesaria en rutas de código de alta utilización o para operar en listas largas.

La macro STAILQ_SWAP intercambia los contenidos de head1 y head2.

LISTS

Una lista enlazada se encabeza por una estructura definida por la macro LIST_HEAD. Esta estructura contiene un puntero al primer elemento de la lista. Los elementos están doblemente enlazados para que un elemento arbitrario pueda ser eliminado sin recorrer la lista. Los nuevos elementos pueden ser insertados en la lista antes o después de un elemento existente, o en la cabeza de la lista. Una estructura LIST_HEAD se declara como sigue:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista puede ser declarado posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro LIST_FOREACH_FROM se comporta idénticamente a LIST_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento de LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LIST referenciada por head.

La macro LIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de LIST_FOREACH(), aquí se permite tanto remover var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro LIST_FOREACH_FROM_SAFE se comporta idénticamente a LIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento de LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LIST referenciada por head.

La macro LIST_INIT inicializa la lista referenciada por head.

La macro LIST_INSERT_HEAD inserta el nuevo elemento elm en la cabeza de la lista.

La macro LIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro LIST_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro LIST_NEXT devuelve el siguiente elemento en la lista, o NULL si este es el último.

La macro LIST_PREV devuelve el elemento anterior en la lista, o NULL si este es el primero. La lista head debe contener el elemento elm.

La macro LIST_REMOVE elimina el elemento elm de la lista.

La macro LIST_SWAP intercambia el contenido de head1 y head2.

COLAS CON COLA

Una cola con cola se encabeza por una estructura definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola con cola y otro al último elemento de la cola con cola. Los elementos están doblemente enlazados para que un elemento arbitrario pueda ser eliminado sin recorrer la cola con cola. Los nuevos elementos pueden ser añadidos a la cola con cola después de un elemento existente, antes de un elemento existente, a la cabeza de la cola con cola, o al final de la cola con cola. Una estructura TAILQ_HEAD se declara como sigue:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá y TYPE es el tipo de los elementos que se enlazarán en la cola con cola. Un puntero a la cabeza de la cola con cola puede ser declarado posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola con cola head.

La macro TAILQ_CONCAT concatena la cola con cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro TAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola con cola.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos de la cola con cola.

La macro TAILQ_FIRST devuelve el primer elemento de la cola con cola o NULL si la cola con cola está vacía.

La macro TAILQ_FOREACH recorre la cola con cola referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. var se establece a NULL si el bucle se completa normalmente, o si no había elementos.

La macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento de TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola con cola referenciada por head en la dirección inversa, asignando cada elemento en turno a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta idénticamente a TAILQ_FOREACH_REVERSE cuando var es NULL, de lo contrario, trata var como un elemento de TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referenciada por head en la dirección hacia adelante o inversa respectivamente, asignando cada elemento en turno a var. Sin embargo, a diferencia de sus contrapartes no seguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE hacen posible tanto remover var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento de TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, de lo contrario, trata var como un elemento de TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

La macro TAILQ_INIT inicializa la cola con cola referenciada por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm en la cabeza de la cola con cola.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola con cola.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola con cola. Si la cola con cola está vacía, el valor de retorno es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento en la cola con cola, o NULL si este elemento es el último.

La macro TAILQ_PREV devuelve el elemento anterior en la cola con cola, o NULL si este elemento es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola con cola.

La macro TAILQ_SWAP intercambia el contenido de head1 y head2.

DIAGNOSTICS

Cuando se debuguea queue(3), puede ser útil trazar los cambios en la cola. Para habilitar la trazabilidad, defina la macro QUEUE_MACRO_DEBUG_TRACE a tiempo de compilación.

También puede ser útil destruir los punteros que se hayan desvinculado de una cola para detectar el uso después de la eliminación. Para habilitar la destrucción de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH a tiempo de compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve true si ptr ha sido destruido por la opción QUEUE_MACRO_DEBUG_TRASH.
