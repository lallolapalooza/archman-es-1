Módulo Stack
: sig end

Pilas LIFO (último en entrar, primero en salir).

Este módulo implementa pilas (LIFO), con modificación in situ.

Advertencia sobre accesos no sincronizados. Los accesos no sincronizados a las pilas son un error de programación.

Accesos no sincronizados

Los accesos no sincronizados a una pila pueden provocar un estado inválido de la cola. Por lo tanto, los accesos concurrentes a las pilas deben sincronizarse (por ejemplo, con un Mutex.t ).

type !'a t

El tipo de pilas que contienen elementos de tipo 'a .

exception Empty

Se lanza cuando se aplica Stack.pop o Stack.top a una pila vacía.

val create : unit -> 'a t

Devuelve una nueva pila, inicialmente vacía.

val push : 'a -> 'a t -> unit

push x s añade el elemento x en la cima de la pila s .

val pop : 'a t -> 'a

pop s elimina y devuelve el elemento superior de la pila s , o lanza Stack.Empty si la pila está vacía.

val pop_opt : 'a t -> 'a option

pop_opt s elimina y devuelve el elemento superior de la pila s , o devuelve None si la pila está vacía.

Desde 4.08

val drop : 'a t -> unit

drop s elimina el elemento superior de la pila s , o lanza Stack.Empty si la pila está vacía.

Desde 5.1

val top : 'a t -> 'a

top s devuelve el elemento superior de la pila s , o lanza Stack.Empty si la pila está vacía.

val top_opt : 'a t -> 'a option

top_opt s devuelve el elemento superior de la pila s , o None si la pila está vacía.

Desde 4.08

val clear : 'a t -> unit

Descarta todos los elementos de una pila.

val copy : 'a t -> 'a t

Devuelve una copia de la pila dada.

val is_empty : 'a t -> bool

Devuelve true si la pila dada está vacía, false en caso contrario.

val length : 'a t -> int

Devuelve el número de elementos en una pila. Complejidad temporal O(1)

val iter : ('a -> unit) -> 'a t -> unit

iter f s aplica f por turnos a todos los elementos de s , desde el elemento en la cima de la pila hasta el elemento en el fondo de la pila. La pila en sí misma no se modifica.

val fold : ('acc -> 'a -> 'acc) -> 'acc -> 'a t -> 'acc

fold f accu s es (f (... (f (f accu x1) x2) ...) xn) donde x1 es la cima de la pila, x2 es el segundo elemento y xn es el elemento del fondo. La pila no se modifica.
