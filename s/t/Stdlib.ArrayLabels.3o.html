Módulo ArrayLabels
: (módulo Stdlib__ArrayLabels)

tipo 'a t = 'a array

Un alias para el tipo de arrays.

val length : 'a array -> int

Devuelve la longitud (número de elementos) del array dado.

val get : 'a array -> int -> 'a

get a n devuelve el elemento número n del array a. El primer elemento tiene el número 0. El último elemento tiene el número length a - 1. También puedes escribir a.(n) en lugar de get a n.

Levanta Invalid_argument si n está fuera del rango 0 a (length a - 1).

val set : 'a array -> int -> 'a -> unit

set a n x modifica el array a en el lugar, reemplazando el elemento número n con x. También puedes escribir a.(n) <- x en lugar de set a n x.

Levanta Invalid_argument si n está fuera del rango 0 a length a - 1.

val make : int -> 'a -> 'a array

make n x devuelve un nuevo array de longitud n, inicializado con x. Todos los elementos de este nuevo array son físicamente iguales a x (en el sentido del predicado ==). Consecuentemente, si x es mutable, se comparte entre todos los elementos del array, y modificar x a través de una de las entradas del array modificará todas las demás entradas al mismo tiempo.

Levanta Invalid_argument si n < 0 o n > Sys.max_array_length. Si el valor de x es un número de punto flotante, entonces el tamaño máximo es solo Sys.max_array_length / 2.

val create_float : int -> float array

create_float n devuelve un nuevo array de punto flotante de longitud n, con datos no inicializados.

Desde 4.03

val init : int -> f:(int -> 'a) -> 'a array

init n ~f devuelve un nuevo array de longitud n, con el elemento número i inicializado con el resultado de f i. En otras palabras, init n ~f tabula los resultados de f aplicados en orden a los enteros 0 a n-1.

Levanta Invalid_argument si n < 0 o n > Sys.max_array_length. Si el tipo de retorno de f es float, entonces el tamaño máximo es solo Sys.max_array_length / 2.

val make_matrix : dimx:int -> dimy:int -> 'a -> 'a array array

make_matrix ~dimx ~dimy e devuelve un array bidimensional (un array de arrays) con primera dimensión dimx y segunda dimensión dimy. Todos los elementos de esta nueva matriz son físicamente iguales a e inicialmente. El elemento (x,y) de una matriz m se accede con la notación m.(x).(y).

Levanta Invalid_argument si dimx o dimy es negativo o mayor que Sys.max_array_length. Si el valor de e es un número de punto flotante, entonces el tamaño máximo es solo Sys.max_array_length / 2.

val init_matrix : dimx:int -> dimy:int -> f:(int -> int -> 'a) -> 'a array array

init_matrix ~dimx ~dimy ~f devuelve un array bidimensional (un array de arrays) con primera dimensión dimx y segunda dimensión dimy, donde el elemento en el índice (x,y) se inicializa con f x y. El elemento (x,y) de una matriz m se accede con la notación m.(x).(y).

Desde 5.2

Levanta Invalid_argument si dimx o dimy es negativo o mayor que Sys.max_array_length. Si el tipo de retorno de f es float, entonces el tamaño máximo es solo Sys.max_array_length / 2.

val append : 'a array -> 'a array -> 'a array

append v1 v2 devuelve un nuevo array que contiene la concatenación de los arrays v1 y v2.

Levanta Invalid_argument si length v1 + length v2 > Sys.max_array_length.

val concat : 'a array list -> 'a array

Igual que ArrayLabels.append, pero concatena una lista de arrays.

val sub : 'a array -> pos:int -> len:int -> 'a array

sub a ~pos ~len devuelve un nuevo array de longitud len, que contiene los elementos desde el número pos hasta pos + len - 1 del array a.

Levanta Invalid_argument si pos y len no designan un subarray válido de a; es decir, si pos < 0, o len < 0, o pos + len > length a.

val copy : 'a array -> 'a array

copy a devuelve una copia de a, es decir, un nuevo array que contiene los mismos elementos que a.

val fill : 'a array -> pos:int -> len:int -> 'a -> unit

fill a ~pos ~len x modifica el array a en el lugar, almacenando x en los elementos desde el número pos hasta pos + len - 1.

Levanta Invalid_argument si pos y len no designan un subarray válido de a.

val blit : src:'a array -> src_pos:int -> dst:'a array -> dst_pos:int -> len:int -> unit

blit ~src ~src_pos ~dst ~dst_pos ~len copia len elementos del array src, comenzando en el elemento número src_pos, al array dst, comenzando en el elemento número dst_pos. Funciona correctamente incluso si src y dst son el mismo array, y los bloques de origen y destino se superponen.

Levanta Invalid_argument si src_pos y len no designan un subarray válido de src, o si dst_pos y len no designan un subarray válido de dst.

val to_list : 'a array -> 'a list

to_list a devuelve la lista de todos los elementos de a.

val of_list : 'a list -> 'a array

of_list l devuelve un nuevo array que contiene los elementos de l.

Levanta Invalid_argument si la longitud de l es mayor que Sys.max_array_length.

Comparación

val equal : eq:('a -> 'a -> bool) -> 'a array -> 'a array -> bool

equal eq a b es true si y solo si a y b tienen la misma longitud n y para todo i en [0 ; n-1], eq a.(i) b.(i) es true.

Desde 5.4

val compare : cmp:('a -> 'a -> int) -> 'a array -> 'a array -> int

compare cmp a b compara a y b según el orden shortlex, es decir, los arrays más cortos son más pequeños y los arrays de igual tamaño se comparan en orden lexicográfico usando cmp para comparar elementos.

Desde 5.4

Iteradores

val iter : f:('a -> unit) -> 'a array -> unit

iter ~f a aplica la función f por turnos a todos los elementos de a. Es equivalente a f a.(0); f a.(1); ...; f a.(length a - 1); ().

val iteri : f:(int -> 'a -> unit) -> 'a array -> unit

Igual que ArrayLabels.iter, pero la función se aplica al índice del elemento como primer argumento, y al elemento mismo como segundo argumento.

val map : f:('a -> 'b) -> 'a array -> 'b array

map ~f a aplica la función f a todos los elementos de a, y construye un array con los resultados devueltos por f: [| f a.(0); f a.(1); ...; f a.(length a - 1) |].

val map_inplace : f:('a -> 'a) -> 'a array -> unit

map_inplace ~f a aplica la función f a todos los elementos de a, y actualiza sus valores en el lugar.

Desde 5.1

val mapi : f:(int -> 'a -> 'b) -> 'a array -> 'b array

Igual que ArrayLabels.map, pero la función se aplica al índice del elemento como primer argumento, y al elemento mismo como segundo

Iterators on one array

val map : f:('a -> 'b) -> 'a array -> 'b array

map ~f a applies function f to all the elements of the array a , and builds an array with the results returned by f : [| f a.(0); ...; f a.(length a - 1)|] .

val mapi : f:(int -> 'a -> 'b) -> 'a array -> 'b array

Same as ArrayLabels.map , but the function is applied to the index of the element as first argument, and the element itself as second argument.

val fold_left : f:('acc -> 'a -> 'acc) -> init:'acc -> 'a array -> 'acc

fold_left ~f ~init a computes f (... (f (f init a.(0)) a.(1)) ...) a.(n-1) , where n is the length of the array a .

val fold_right : f:('a -> 'acc -> 'acc) -> 'a array -> init:'acc -> 'acc

fold_right ~f a ~init computes f a.(0) (f a.(1) ( ... (f a.(n-1) init) ...)) , where n is the length of the array a .

val iter : f:('a -> unit) -> 'a array -> unit

iter ~f a applies the function f to all the elements of the array a , in increasing order.

val iteri : f:(int -> 'a -> unit) -> 'a array -> unit

Same as ArrayLabels.iter , but the function is applied to the index of the element as first argument, and the element itself as second argument.

val map_inplace : f:('a -> 'a) -> 'a array -> unit

map_inplace ~f a applies function f to all the elements of the array a . The array is modified in place.

val mapi_inplace : f:(int -> 'a -> 'a) -> 'a array -> unit

Same as ArrayLabels.map_inplace , but the function is applied to the index of the element as first argument, and the element itself as second argument.

Since 5.1

val fold_left_map : f:('acc -> 'a -> 'acc * 'b) -> init:'acc -> 'a array -> 'acc * 'b array

fold_left_map is a combination of ArrayLabels.fold_left and ArrayLabels.map that threads an accumulator through calls to f .

Since 4.13

Iterators on two arrays

val iter2 : f:('a -> 'b -> unit) -> 'a array -> 'b array -> unit

iter2 ~f a b applies function f to all the elements of a and b .

Since 4.05

Raises Invalid_argument if the arrays are not the same size.

val map2 : f:('a -> 'b -> 'c) -> 'a array -> 'b array -> 'c array

map2 ~f a b applies function f to all the elements of a and b , and builds an array with the results returned by f : [| f a.(0) b.(0); ...; f a.(length a - 1) b.(length b - 1)|] .

Since 4.05

Raises Invalid_argument if the arrays are not the same size.

Array scanning

val for_all : f:('a -> bool) -> 'a array -> bool

for_all ~f [|a1; ...; an|] checks if all elements of the array satisfy the predicate f . That is, it returns (f a1) && (f a2) && ... && (f an) .

Since 4.03

val exists : f:('a -> bool) -> 'a array -> bool

exists ~f [|a1; ...; an|] checks if at least one element of the array satisfies the predicate f . That is, it returns (f a1) || (f a2) || ... || (f an) .

Since 4.03

val for_all2 : f:('a -> 'b -> bool) -> 'a array -> 'b array -> bool

Same as ArrayLabels.for_all , but for a two-argument predicate.

Since 4.11

Raises Invalid_argument if the two arrays have different lengths.

val exists2 : f:('a -> 'b -> bool) -> 'a array -> 'b array -> bool

Same as ArrayLabels.exists , but for a two-argument predicate.

Since 4.11

Raises Invalid_argument if the two arrays have different lengths.

val mem : 'a -> set:'a array -> bool

mem a ~set is true if and only if a is structurally equal to an element of set (i.e. there is an x in set such that compare a x = 0 ).

Since 4.03

val memq : 'a -> set:'a array -> bool

Same as ArrayLabels.mem , but uses physical equality instead of structural equality to compare array elements.

Since 4.03

val find_opt : f:('a -> bool) -> 'a array -> 'a option

find_opt ~f a returns the first element of the array a that satisfies the predicate f , or None if there is no value that satisfies f in the array a .

Since 4.13

val find_index : f:('a -> bool) -> 'a array -> int option

find_index ~f a returns Some i , where i is the index of the first element of the array a that satisfies f x , if there is such an element.

It returns None if there is no such element.

Since 5.1

val find_map : f:('a -> 'b option) -> 'a array -> 'b option

find_map ~f a applies f to the elements of a in order, and returns the first result of the form Some v , or None if none exist.

Since 4.13

val find_mapi : f:(int -> 'a -> 'b option) -> 'a array -> 'b option

Same as find_map , but the predicate is applied to the index of the element as first argument (counting from 0), and the element itself as second argument.

Since 5.1

Arrays of pairs

val split : ('a * 'b) array -> 'a array * 'b array

split [|(a1,b1); ...; (an,bn)|] is ([|a1; ...; an|], [|b1; ...; bn|]) .

Since 4.13

val combine : 'a array -> 'b array -> ('a * 'b) array

combine [|a1; ...; an|] [|b1; ...; bn|] is [|(a1,b1); ...; (an,bn)|] . Raise Invalid_argument if the two arrays have different lengths.

Since 4.13

Sorting and shuffling

val sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Sort an array in increasing order according to a comparison function. The comparison function must return 0 if its arguments compare as equal, a positive integer if the first is greater, and a negative integer if the first is smaller (see below for a complete specification). For example, compare is a suitable comparison function. After calling sort , the array is sorted in place in increasing order. sort is guaranteed to run in constant heap space and (at most) logarithmic stack space.

The current implementation uses Heap Sort. It runs in constant stack space.

Specification of the comparison function: Let a be the array and cmp the comparison function. The following must be true for all x , y , z in a :

- cmp x y > 0 if and only if cmp y x < 0

- if cmp x y >= 0 and cmp y z >= 0 then cmp x z >= 0

When sort returns, a contains the same elements as before, reordered in such a way that for all i and j valid indices of a :

- cmp a.(i) a.(j) >= 0 if i >= j

val stable_sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Same as ArrayLabels.sort , but the sorting algorithm is stable (i.e. elements that compare equal are kept in their original order) and not guaranteed to run in constant heap space.

The current implementation uses Merge Sort. It uses a temporary array of length n/2 , where n is the length of the array. It is usually faster than the current implementation of ArrayLabels.sort .

val fast_sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Same as ArrayLabels.sort or ArrayLabels.stable_sort , whichever is faster on typical input.

val shuffle : rand:(int -> int) -> 'a array -> unit

shuffle ~rand a randomly permutes a 's element using rand for randomness. The distribution of permutations is uniform.

rand must be such that a call to rand n returns a uniformly distributed random number in the range [ 0 ; n-1 ]. Random.int can be used for this (do not forget to Random.self_init the generator).

Arrays and concurrency safety

Care must be taken when concurrently accessing arrays from multiple domains: accessing an array will never crash a program, but unsynchronized accesses might yield surprising (non-sequentially-consistent) results.

Atomicity

Every array operation that accesses more than one array element is not atomic. This includes iteration, scanning, sorting, splitting and combining arrays.

For example, consider the following program:

let size = 100_000_000
let a = ArrayLabels.make size 1
let d1 = Domain.spawn (fun () ->
   ArrayLabels.iteri ~f:(fun i x -> a.(i) <- x + 1) a
)
let d2 = Domain.spawn (fun () ->
  ArrayLabels.iteri ~f:(fun i x -> a.(i) <- 2 * x + 1) a
)
let () = Domain.join d1; Domain.join d2

After executing this code, each field of the array a is either 2 , 3 , 4 or 5 . If atomicity is required, then the user must implement their own synchronization (for example, using Mutex.t ).

Data races

If two domains only access disjoint parts of the array, then the observed behaviour is the equivalent to some sequential interleaving of the operations from the two domains.

Data races

Un data race ocurre cuando dos hilos (dominios en OCaml) acceden a la misma ubicación de memoria, y al menos uno de los accesos es de escritura. En ausencia de data races, el comportamiento observado es equivalente a alguna intercalación secuencial de las operaciones de diferentes dominios.

Siempre que sea posible, se deben evitar las data races utilizando sincronización para mediar los accesos a los elementos del array.

De hecho, en presencia de data races, los programas no fallarán, pero el comportamiento observado puede no ser equivalente a ninguna intercalación secuencial de operaciones de diferentes dominios. Sin embargo, incluso en presencia de data races, una operación de lectura devolverá el valor de alguna escritura previa a esa ubicación (con algunas excepciones para arrays de flotantes).

Arrays de flotantes

Los arrays de flotantes tienen dos advertencias adicionales en presencia de data races.

Primero, la operación blit puede copiar un array byte a byte. Las data races entre una operación blit de este tipo y otra operación pueden producir valores sorprendentes debido al desgarro (tearing): escrituras parciales intercaladas con otras operaciones pueden crear valores flotantes que no existirían con una ejecución secuencial.

Por ejemplo, al final de

let zeros = Array.make size 0.
let max_floats = Array.make size Float.max_float
let res = Array.copy zeros
let d1 = Domain.spawn (fun () -> Array.blit zeros 0 res 0 size)
let d2 = Domain.spawn (fun () -> Array.blit max_floats 0 res 0 size)
let () = Domain.join d1; Domain.join d2
el array res podría contener valores que no sean ni 0. ni max_float.

Segundo, en arquitecturas de 32 bits, obtener o establecer un campo implica dos accesos de memoria separados. En presencia de data races, el usuario puede observar desgarro (tearing) en cualquier operación.
