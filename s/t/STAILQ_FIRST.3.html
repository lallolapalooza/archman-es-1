STAILQ(3) Manual de funciones de biblioteca STAILQ(3)

NOMBRE

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implementación de una cola de lista enlazada simple con cola

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TIPO);
STAILQ_HEAD(NOMBRE_CABECERA, TIPO);
STAILQ_HEAD NOMBRE_CABECERA STAILQ_HEAD_INITIALIZER(STAILQ_HEAD cabecera);
void STAILQ_INIT(STAILQ_HEAD *cabecera);
int STAILQ_EMPTY(STAILQ_HEAD *cabecera);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *cabecera,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *cabecera,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *cabecera, struct TIPO *elemento_lista,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
struct TIPO *STAILQ_FIRST(STAILQ_HEAD *cabecera);
struct TIPO *STAILQ_NEXT(struct TIPO *elem, STAILQ_ENTRY NOMBRE);
STAILQ_FOREACH(struct TIPO *var, STAILQ_HEAD *cabecera, STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE(STAILQ_HEAD *cabecera, struct TIPO *elem, TIPO,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *cabecera,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_CONCAT(STAILQ_HEAD *cabecera1, STAILQ_HEAD *cabecera2);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; véase VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas de lista enlazada simples con cola.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola de lista enlazada simple con cola está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simple para minimizar el espacio y la sobrecarga de manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la cola. Posteriormente, se puede declarar un puntero a la cabecera de la cola como:


struct NOMBRE_CABECERA *puntero_cabecera;

(Los nombres cabecera y puntero_cabecera son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

STAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola cabecera.

STAILQ_INIT() inicializa la cola referenciada por cabecera.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elemento_lista.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por cabecera en la dirección hacia adelante, asignando cada elemento en su turno a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elem de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deberían usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cola cabecera.

VERSIÓNES

Algunos BSDs proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se llamaron de forma diferente en diferentes BSDs. STAILQ se originó en FreeBSD y SIMPLEQ en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por una falta de equivalente SIMPLEQ para STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que var se elimine o se libere dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSDs pero no en glibc, soluciona esta limitación al permitir que var se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    STAILQ_ENTRY(entrada) entradas;        /* Cola enlazada simple con cola */
};
STAILQ_HEAD(cabecera_stail, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabecera_stail cabecera;                  /* Cabecera de cola enlazada simple con cola */
    STAILQ_INIT(&cabecera);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&cabecera, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&cabecera, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    STAILQ_INSERT_AFTER(&cabecera, n1, n2, entradas);
    STAILQ_REMOVE(&cabecera, n2, entrada, entradas); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&cabecera);
    STAILQ_REMOVE_HEAD(&cabecera, entradas);     /* Eliminación desde el principio */
    free(n3);
    n1 = STAILQ_FIRST(&cabecera);
    n1->datos = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        STAILQ_INSERT_HEAD(&cabecera, n1, entradas);
        n1->datos = i;
    }

STAILQ_FIRST(3) — man pages

NAME

STAILQ_FIRST, STAILQ_NEXT, STAILQ_INIT, STAILQ_INSERT_TAIL, STAILQ_FOREACH — list accessors and macros

LIBRARY

libbsd (for some functions)

SYNOPSIS

#include <sys/queue.h>

/* List head structure */
struct queue;

/* List node structure */
struct entry;

/* macros */
STAILQ_FIRST(struct queue *head);
STAILQ_NEXT(struct entry *elm, entries);
STAILQ_INIT(struct queue *head);
STAILQ_INSERT_TAIL(struct queue *head, struct entry *elm, entries);
STAILQ_FOREACH(struct entry *var, struct queue *head, entries);

DESCRIPTION

These macros provide an interface for manipulating singly-linked lists. They are similar to the macros provided by the queue(7) manual page, but they operate on singly-linked lists instead of doubly-linked lists.

A singly-linked list is composed of a list head structure and a list of entry structures. Each entry structure contains a pointer to the next entry in the list. The list head structure contains a pointer to the first entry in the list.

STAILQ_FIRST returns the first entry in the list pointed to by head. If the list is empty, it returns NULL.

STAILQ_NEXT returns the next entry in the list after the entry pointed to by elm. The entries argument specifies the name of the link member within the entry structure.

STAILQ_INIT initializes the list pointed to by head. This should be called before any other list operations.

STAILQ_INSERT_TAIL inserts the entry pointed to by elm at the tail of the list pointed to by head. The entries argument specifies the name of the link member within the entry structure.

STAILQ_FOREACH iterates over the list pointed to by head. In each iteration, the entry is assigned to the variable var. The entries argument specifies the name of the link member within the entry structure.

RETURN VALUE

STAILQ_FIRST returns a pointer to the first entry in the list, or NULL if the list is empty.

STAILQ_NEXT returns a pointer to the next entry in the list, or NULL if the current entry is the last entry in the list.

VERSIONS

These macros are available in libbsd 2.0 and later.

BUGS

None known.

STANDARDS

These macros are based on the BSD queue macros and are not part of any standard.

HISTORY

The singly-linked list macros first appeared in 4.4BSD.

EXAMPLES

The following example demonstrates how to use the STAILQ_FOREACH and STAILQ_INIT macros to traverse and delete a singly-linked list:

struct node {
    int data;
    struct node *next;
};

struct node *np, *n1, *n2;
struct {
    struct node *stqh_first;
    struct node **stqh_last;
} head;

STAILQ_INIT(&head);

/* ... add nodes to the list ... */

                                    /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
