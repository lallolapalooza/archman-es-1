Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; véase VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas de cola enlazadas simples.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRECABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola de cola enlazada simple está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola de cola y otro al último elemento de la cola de cola. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden agregar nuevos elementos a la cola de cola después de un elemento existente, al principio de la cola de cola o al final de la cola de cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRECABECERA, TIPO) cabeza;

donde struct NOMBRECABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola de cola. Un puntero a la cabeza de la cola de cola se puede declarar posteriormente como:


struct NOMBRECABECERA *cabecerap;

(Los nombres cabeza y cabecerap son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola de cola.

STAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola de cola cabeza.

STAILQ_INIT() inicializa la cola de cola referenciada por cabeza.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola de cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola de cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola de cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elemcola.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola de cola o NULL si la cola de cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola de cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola de cola referenciada por cabeza en dirección hacia adelante, asignando cada elemento en su turno a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elem de la cola de cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola de cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola de cola deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola de cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cabeza de la cola cabeza.

VERSIONES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se llamaron de manera diferente en diferentes BSD. STAILQ se originó en FreeBSD y SIMPLEQ se originó en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por la ausencia de un equivalente SIMPLEQ a STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en BSD pero no en glibc, soluciona esta limitación al permitir que var se elimine de forma segura de la lista y se libere dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    STAILQ_ENTRY(entrada) entradas;        /* Cola de cola enlazada simple */
};
STAILQ_HEAD(cabeceracola, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabeceracola cabeza;                  /* Cabeza de cola de cola enlazada simple */
    STAILQ_INIT(&cabeza);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    STAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);
    STAILQ_REMOVE(&cabeza, n2, entrada, entradas); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&cabeza);
    STAILQ_REMOVE_HEAD(&cabeza, entradas);     /* Eliminación del principio */
    free(n3);
    n1 = STAILQ_FIRST(&cabeza);
    n1->datos = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
        n1->datos = i;
    }

SINTAXIS

/* Recorrido forward */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* Borrado de TailQ */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);

DESCRIPCIÓN

Esta función realiza un recorrido forward en la estructura de datos STAILQ. El recorrido se realiza iterando a través de la lista en el orden de inserción, comenzando desde el primer elemento y terminando en el último. El uso de esta función es común en aplicaciones que requieren manejar listas en orden de inserción.

VALOR DE RETORNO

El valor de retorno de esta función es void.
