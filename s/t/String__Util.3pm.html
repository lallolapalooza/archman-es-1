NOMBRE

String::Util -- Funciones de utilidad para el procesamiento de cadenas

DESCRIPCIÓN

String::Util proporciona una colección de funciones pequeñas y útiles para procesar cadenas de diversas maneras.

INSTALACIÓN

cpanm String::Util

USO

Por defecto, no se exporta ninguna función, deben especificarse:

use String::Util qw(trim eqq contains)

alternativamente, puedes usar ":all" para exportar todas las funciones

use String::Util qw(:all)

FUNCIONES

collapse($cadena)

collapse() colapsa todos los espacios en blanco de la cadena a espacios simples. También elimina todos los espacios en blanco iniciales y finales. La entrada indefinida produce una salida indefinida.

$var = collapse("  Hola     mundo!    "); # "Hola mundo!"

hascontent($escalar), nocontent($escalar)

hascontent() devuelve verdadero si el argumento dado está definido y contiene algo más que espacios en blanco.

Un valor indefinido devuelve falso. Una cadena vacía devuelve falso. Un valor que solo contiene espacios en blanco (espacios, tabulaciones, retornos de carro, saltos de línea, retrocesos) devuelve falso. Una cadena que contiene cualquier otro carácter (incluido el cero) devuelve verdadero.

nocontent() devuelve la negación de hascontent().

$var = hascontent("");  # Falso
$var = hascontent(" "); # Falso
$var = hascontent("a"); # Verdadero
$var = nocontent("");   # Verdadero
$var = nocontent("a");  # Falso

trim($cadena), ltrim($cadena), rtrim($cadena)

Devuelve la cadena con todos los espacios en blanco iniciales y finales eliminados.

$var = trim(" mi cadena  "); # "mi cadena"

ltrim() elimina solo los espacios en blanco iniciales.

rtrim() elimina solo los espacios en blanco finales.

nospace($cadena)

Elimina todos los caracteres de espacio en blanco de la cadena dada. Esto incluye los espacios entre palabras.

$var = nospace("  Hola Mundo!   "); # "HolaMundo!"

htmlesc($cadena)

Formatea una cadena para su salida literal en HTML. Un valor indefinido se devuelve como una cadena vacía.

htmlesc() es muy similar a escapeHTML de CGI.pm. Sin embargo, hay algunas diferencias. htmlesc() convierte un valor indefinido en una cadena vacía, mientras que escapeHTML() devuelve undef como undef.

jsquote($cadena)

Escapa y comilla una cadena para su uso en JavaScript. Escapa las comillas simples y rodea la cadena con comillas simples. Devuelve la cadena modificada.

unquote($cadena)

Si la cadena dada comienza y termina con comillas, las elimina. Reconoce comillas simples y dobles. El valor debe comenzar y terminar con el mismo tipo de comillas o no se hará nada con el valor. La entrada indefinida produce una salida indefinida. Algunos ejemplos y lo que devuelven:

unquote(q|'Hendrix'|);   # Hendrix
unquote(q|"Hendrix"|);   # Hendrix
unquote(q|Hendrix|);     # Hendrix
unquote(q|"Hendrix'|);   # "Hendrix'
unquote(q|O'Sullivan|);  # O'Sullivan

opción: llaves

Si la opción de llaves es verdadera, también se eliminan las llaves circundantes como [] y {}. Algunos ejemplos:

unquote(q|[Janis]|, braces=>1);  # Janis
unquote(q|{Janis}|, braces=>1);  # Janis
unquote(q|(Janis)|, braces=>1);  # Janis

repeat($cadena, $conteo)

Devuelve la cadena dada repetida el número de veces indicado. El siguiente comando imprime "Fred" tres veces:

print repeat('Fred', 3), "\n";

Nota que repeat() se creó hace mucho tiempo basándose en una mala comprensión de cómo funciona el operador 'x' de perl. El siguiente comando usando "x" realizaría exactamente la misma función que el comando anterior.

print 'Fred' x 3, "\n";

Usa el que prefieras.

eqq($escalar1, $escalar2)

Devuelve verdadero si los dos valores dados son iguales. También devuelve verdadero si ambos son "undef". Si solo uno es "undef", o si ambos están definidos pero son diferentes, devuelve falso. Aquí hay algunos ejemplos y lo que devuelven.

$var = eqq('x', 'x');     # Verdadero
$var = eqq('x', undef);   # Falso
$var = eqq(undef, undef); # Verdadero

neqq($escalar1, $escalar2)

Lo opuesto a "neqq", devuelve verdadero si los dos valores no son iguales. Aquí hay algunos ejemplos y lo que devuelven.

$var = neqq('x', 'x');     # Falso
$var = neqq('x', undef);   # Verdadero
$var = neqq(undef, undef); # Falso

ords($cadena)

Devuelve la cadena dada representada como el valor ASCII de cada carácter.

$var = ords('Hendrix'); # {72}{101}{110}{100}{114}{105}{120}

opciones

  • convert_spaces=>[verdadero|falso]

    Si convert_spaces es verdadero (que es el valor por defecto) entonces los espacios se convierten a sus valores ord correspondientes. Así, por ejemplo, este código:

    $var = ords('a b', convert_spaces=>1); # {97}{32}{98}

    Este código devuelve lo mismo:

    $var = ords('a b');                    # {97}{32}{98}

    Si convert_spaces es falso, entonces los espacios se devuelven simplemente como espacios. Así que este código:

    ords('a b', convert_spaces=>0);        # {97} {98}
  • alpha_nums

    Si la opción alpha_nums es falsa, entonces los caracteres 0-9, a-z y A-Z no se convierten. Por ejemplo, este código:

    $var = ords('a=b', alpha_nums=>0); # a{61}b

deords($cadena)

Toma la salida de ords() y devuelve la cadena que originalmente creó esa salida.

$var = deords('{72}{101}{110}{100}{114}{105}{120}'); # 'Hendrix'

contains($cadena, $subcadena)

Comprueba si la cadena contiene la subcadena

$var = contains("Hola mundo", "Hola");   # verdadero
$var = contains("Hola mundo", "llo mun"); # verdadero
$var = contains("Hola mundo", "");        # verdadero
$var = contains("Hola mundo", "QQQ");     # falso
$var = contains(undef, "QQQ");             # falso
$var = contains("Hola mundo", undef);     # falso
# También funciona con grep
@arr = grep { contains("gato") } @input;

startswith($cadena, $subcadena)

Comprueba si la cadena comienza con los caracteres de la subcadena

$var = startswith("Hola mundo", "Hola"); # verdadero
$var = startswith("Hola mundo", "H");     # verdadero
$var = startswith("Hola mundo", "");      # verdadero
$var = startswith("Hola mundo", "Q");     # falso
$var = startswith(undef, "Q");



startswith($string,   $substring)


Comprueba si la cadena comienza con los caracteres de la subcadena


$var = startswith("Hello world", "Hello");   # true
$var = startswith("Hello world", "H");       # true
$var = startswith("Hello world", "");        # true
$var = startswith("Hello world", "QQQ");     # false
$var = startswith(undef, "QQQ");             # false
$var = startswith("Hello world", undef);   # false
# También funciona con grep
@arr = grep { startswith("X") } @input;






endswith($string,   $substring)


Comprueba si la cadena termina con los caracteres de la subcadena


$var = endswith("Hello world", "world");   # true
$var = endswith("Hello world", "d");       # true
$var = endswith("Hello world", "");        # true
$var = endswith("Hello world", "QQQ");     # false
$var = endswith(undef, "QQQ");             # false
$var = endswith("Hello world", undef);     # false
# También funciona con grep
@arr = grep { endswith("z") } @input;






crunchlines($string)


Compacta las nuevas líneas contiguas en nuevas líneas únicas. El
    espacio en blanco entre nuevas líneas se ignora, de modo que dos nuevas líneas
    separadas por espacio en blanco se compactan en una única nueva línea.


$var = crunchlines("x\n\n\nx"); # "x\nx";






sanitize($string,   $separator = "_")


Sanea todos los caracteres no alfanuméricos en una cadena a
    guiones bajos. Esto es útil para tomar una URL, un nombre de archivo o una
    descripción de texto y saber que se puede usar de forma segura en una URL o
    un nombre de archivo.


Nota: Esto eliminará cualquier guion bajo inicial o final
    en la cadena


$var = sanitize("http://www.google.com/") # http_www_google_com
$var = sanitize("foo_bar()";              # foo_bar
$var = sanitize("/path/to/file.txt");     # path_to_file_txt
$var = sanitize("Big yellow bird!", "."); # Big.yellow.bird






file_get_contents($string,   $boolean)


Lee un archivo completo del disco en una cadena. Devuelve undef si
    el archivo no se puede leer por ningún motivo. También puede devolver el
    archivo como una matriz de líneas.


$str   = file_get_contents("/tmp/file.txt");    # Devuelve una cadena
@lines = file_get_contents("/tmp/file.txt", 1); # Devuelve una matriz


Nota: Si opta por devolver una matriz, los retornos de carro
    y las nuevas líneas se eliminan del final de cada línea.


Nota: El archivo se lee en modo UTF-8, a menos que
    $FGC_MODE se establezca en una codificación apropiada.






substr_count($haystack,   $needle)


Cuenta las ocurrencias de una subcadena dentro de una cadena más
    grande. Devuelve un valor entero con el número de coincidencias, o
    "undef" si la entrada no es válida.


my $cnt = substr_count("Perl is really rad", "r"); # 3
my $num = substr_count("Perl is really rad", "Q"); # 0
