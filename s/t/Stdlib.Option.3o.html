Opciones

type 'a t = 'a option =
| None
| Some de 'a

El tipo para valores de opción. Ya sea None o un valor Some v .

val none : 'a option

none es None .

val some : 'a -> 'a option

some v es Some v .

val value : 'a option -> default:'a -> 'a

value o ~default es v si o es Some v y default en caso contrario.

val get : 'a option -> 'a

get o es v si o es Some v y lanza una excepción en caso contrario.

Lanza Invalid_argument si o es None .

val bind : 'a option -> ('a -> 'b option) -> 'b option

bind o f es f v si o es Some v y None si o es None .

val join : 'a option option -> 'a option

join oo es Some v si oo es Some (Some v) y None en caso contrario.

val map : ('a -> 'b) -> 'a option -> 'b option

map f o es None si o es None y Some (f v) si o es Some v .

val fold : none:'a -> some:('b -> 'a) -> 'b option -> 'a

fold ~none ~some o es none si o es None y some v si o es Some v .

val iter : ('a -> unit) -> 'a option -> unit

iter f o es f v si o es Some v y () en caso contrario.

Predicados y comparaciones

val is_none : 'a option -> bool

is_none o es true si y solo si o es None .

val is_some : 'a option -> bool

is_some o es true si y solo si o es Some o .

val equal : ('a -> 'a -> bool) -> 'a option -> 'a option -> bool

equal eq o0 o1 es true si y solo si o0 y o1 son ambos None o si son Some v0 y Some v1 y eq v0 v1 es true .

val compare : ('a -> 'a -> int) -> 'a option -> 'a option -> int

compare cmp o0 o1 es un orden total en opciones que usa cmp para comparar valores envueltos por Some _ . None es menor que los valores Some _ .

Conversión

val to_result : none:'e -> 'a option -> ('a, 'e) result

to_result ~none o es Ok v si o es Some v y Error none en caso contrario.

val to_list : 'a option -> 'a list

to_list o es [] si o es None y [v] si o es Some v .

val to_seq : 'a option -> 'a Seq.t

to_seq o es o como una secuencia. None es la secuencia vacía y Some v es la secuencia singleton que contiene v .
