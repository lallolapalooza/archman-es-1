Módulo Complex
: (module Stdlib__Complex)

tipo t = {
re : float ;
im : float ;
}

El tipo de los números complejos. re es la parte real y im la parte imaginaria.

val zero : t

El número complejo 0 .

val one : t

El número complejo 1 .

val i : t

El número complejo i .

val neg : t -> t

Negación unaria.

val conj : t -> t

Conjugado: dado el complejo x + i.y , devuelve x - i.y .

val add : t -> t -> t

Suma

val sub : t -> t -> t

Resta

val mul : t -> t -> t

Multiplicación

val inv : t -> t

Inverso multiplicativo ( 1/z ).

val div : t -> t -> t

División

val sqrt : t -> t

Raíz cuadrada. El resultado x + i.y es tal que x > 0 o x = 0 y y >= 0 . Esta función tiene una discontinuidad a lo largo del eje real negativo.

val norm2 : t -> float

Norma al cuadrado: dado x + i.y , devuelve x^2 + y^2 .

val norm : t -> float

Norma: dado x + i.y , devuelve sqrt(x^2 + y^2) .

val arg : t -> float

Argumento. El argumento de un número complejo es el ángulo en el plano complejo entre el eje real positivo y una línea que pasa por cero y el número. Este ángulo varía de -pi a pi . Esta función tiene una discontinuidad a lo largo del eje real negativo.

val polar : float -> float -> t

polar norm arg devuelve el complejo con norma norm y argumento arg .

val exp : t -> t

Exponenciación. exp z devuelve e elevada a la potencia z .

val log : t -> t

Logaritmo natural (en base e ).

val pow : t -> t -> t

Función de potencia. pow z1 z2 devuelve z1 elevado a la potencia z2 .
