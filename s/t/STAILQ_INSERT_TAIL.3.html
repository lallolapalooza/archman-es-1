STAILQ(3) Manual de funciones de biblioteca STAILQ(3)

NOMBRE

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implementación de una cola simple enlazada al final

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TIPO);
STAILQ_HEAD(NOMBRE_CABECERA, TIPO);
STAILQ_HEAD NOMBRE_CABECERA STAILQ_HEAD_INITIALIZER(STAILQ_HEAD cabecera);
void STAILQ_INIT(STAILQ_HEAD *cabecera);
int STAILQ_EMPTY(STAILQ_HEAD *cabecera);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *cabecera,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *cabecera,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *cabecera, struct TIPO *elemento_lista,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
struct TIPO *STAILQ_FIRST(STAILQ_HEAD *cabecera);
struct TIPO *STAILQ_NEXT(struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
STAILQ_FOREACH(struct TIPO *variable, STAILQ_HEAD *cabecera, STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE(STAILQ_HEAD *cabecera, struct TIPO *elemento, TIPO,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *cabecera,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_CONCAT(STAILQ_HEAD *cabecera1, STAILQ_HEAD *cabecera2);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; ver VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas simples enlazadas al final.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro STAILQ_HEAD().

Creación

Una cola simple enlazada al final se encabeza mediante una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simple para minimizar el espacio y la sobrecarga de manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura que se va a definir, y struct TIPO es el tipo de los elementos que se van a enlazar en la cola. Posteriormente, se puede declarar un puntero a la cabeza de la cola como:


struct NOMBRE_CABECERA *cabecerapi;

(Los nombres cabecera y cabecerapi son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

STAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabecera.

STAILQ_INIT() inicializa la cola referenciada por cabecera.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elemento al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elemento al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elemento después del elemento elemento_lista.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por cabecera en dirección hacia adelante, asignando cada elemento por turno a variable.

Eliminación

STAILQ_REMOVE() elimina el elemento elemento de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola cabecera.

VERSIONES

Algunos sistemas BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se les dio nombres diferentes en diferentes BSDs. STAILQ se originó en FreeBSD y SIMPLEQ en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por la ausencia de un equivalente SIMPLEQ para STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que variable sea eliminada o liberada dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los sistemas BSD pero no en glibc, soluciona esta limitación al permitir que variable se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    STAILQ_ENTRY(entrada) entradas;        /* Cola simple enlazada */
};
STAILQ_HEAD(cabecera_simple, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabecera_simple cabecera;                  /* Cabecera de cola
                                               simple enlazada */
    STAILQ_INIT(&cabecera);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&cabecera, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&cabecera, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    STAILQ_INSERT_AFTER(&cabecera, n1, n2, entradas);
    STAILQ_REMOVE(&cabecera, n2, entrada, entradas); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&cabecera);
    STAILQ_REMOVE_HEAD(&cabecera, entradas);     /* Eliminación desde el principio */
    free(n3);
    n1 = STAILQ_FIRST(&cabecera);
    n1->datos = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        STAILQ_INSERT_HEAD(&cabecera, n1, entradas);
        n1->datos = i;
    }

STAILQ_INSERT_TAIL(3bsd) — Arch Linux

NAME

STAILQ_INSERT_TAIL, STAILQ_INSERT_HEAD, STAILQ_INSERT_AFTER, STAILQ_INSERT_BEFORE, STAILQ_REMOVE, STAILQ_SWAP — macros for manipulating singly linked lists with a consistent tail pointer

LIBRARY

System V Libraries

SYNOPSIS

#include <sys/queue.h>

Macros for manipulating singly linked lists with a consistent tail pointer:

#define STAILQ_HEAD(name, type) \
struct name { \
    struct type *stqh_first; \
    struct type **stqh_last; \
}

#define STAILQ_HEAD_INITIALIZER(head) \
{ NULL, &(head).stqh_first }

#define STAILQ_INIT(head) do { \
    (head)->stqh_first = NULL; \
    (head)->stqh_last = &(head)->stqh_first; \
} while (0)

#define STAILQ_INSERT_HEAD(head, elm, field) do { \
    if (((elm)->field.stqe_next = (head)->stqh_first) != NULL) \
        (head)->stqh_first->field.stqe_prev = &(elm)->field.stqe_next; \
    else \
        (head)->stqh_last = &(elm)->field.stqe_next; \
    (elm)->field.stqe_prev = &(head)->stqh_first; \
    (head)->stqh_first = (elm); \
} while (0)

#define STAILQ_INSERT_TAIL(head, elm, field) do { \
    (elm)->field.stqe_next = NULL; \
    *(head)->stqh_last = (elm); \
    (head)->stqh_last = &(elm)->field.stqe_next; \
} while (0)

#define STAILQ_INSERT_AFTER(head, listelm, elm, field) do { \
    if (((elm)->field.stqe_next = (listelm)->field.stqe_next) != NULL) \
        (elm)->field.stqe_next->field.stqe_prev = &(elm)->field.stqe_next; \
    else \
        (head)->stqh_last = &(elm)->field.stqe_next; \
    (elm)->field.stqe_next = (listelm)->field.stqe_next; \
    (elm)->field.stqe_prev = &(listelm)->field.stqe_next; \
    (listelm)->field.stqe_next = (elm); \
} while (0)

#define STAILQ_INSERT_BEFORE(head, listelm, elm, field) do { \
    (elm)->field.stqe_prev = (listelm)->field.stqe_prev; \
    (elm)->field.stqe_next = (listelm); \
    *(listelm)->field.stqe_prev = (elm); \
    (listelm)->field.stqe_prev = &(elm)->field.stqe_next; \
} while (0)

#define STAILQ_REMOVE(head, elm, type, field) do { \
    if ((elm)->field.stqe_next != NULL) \
        (elm)->field.stqe_next->field.stqe_prev = (elm)->field.stqe_prev; \
    else \
        (head)->stqh_last = (elm)->field.stqe_prev; \
    *(elm)->field.stqe_prev = (elm)->field.stqe_next; \
} while (0)

#define STAILQ_SWAP(head1, head2, type) do { \
    struct type *tmp; \
    tmp = (head1)->stqh_first; \
    (head1)->stqh_first = (head2)->stqh_first; \
    (head2)->stqh_first = tmp; \
    tmp = (head1)->stqh_last; \
    (head1)->stqh_last = (head2)->stqh_last; \
    (head2)->stqh_last = tmp; \
} while (0)

#define STAILQ_FIRST(head)        ((head)->stqh_first)
#define STAILQ_NEXT(elm, field)   ((elm)->field.stqe_next)
#define STAILQ_PREV(elm, type, field) \
    (*(((elm)->field.stqe_prev)))
#define STAILQ_LAST(head, type, field) \
    (struct type *)((char *)((head)->stqh_last) - offsetof(struct type, field.stqe_next))

#define STAILQ_EMPTY(head)        ((head)->stqh_first == NULL)

DESCRIPTION

These macros provide functionality for manipulating singly linked lists with a consistent tail pointer. Such lists are useful for implementing queues and stacks. A singly linked list with a consistent tail pointer allows O(1) insertion and deletion at the tail of the list.

A list is declared using the STAILQ_HEAD macro. The type argument is the name of the structure that will be used for the list elements, and the name argument is the name of the structure that will be used for the head of the list.

Each element in the list must contain a field of type stailq_entry that is used to link the elements together. The field argument to the insertion and deletion macros is the name of this field within the element structure.

The STAILQ_HEAD_INITIALIZER macro can be used to initialize a list head in static or global declarations. The STAILQ_INIT macro initializes an empty list.

The insertion macros add elements to the list:

  • STAILQ_INSERT_HEAD(head, elm, field) adds the element elm to the head of the list pointed to by head.
  • STAILQ_INSERT_TAIL(head, elm, field) adds the element elm to the tail of the list pointed to by head.
  • STAILQ_INSERT_AFTER(head, listelm, elm, field) inserts the element elm after the element listelm in the list pointed to by head.
  • STAILQ_INSERT_BEFORE(head, listelm, elm, field) inserts the element elm before the element listelm in the list pointed to by head.

The deletion macros remove elements from the list:

  • STAILQ_REMOVE(head, elm, type, field) removes the element elm from the list pointed to by head. The type argument is the name of the structure of the elements in the list, and the field argument is the name of the link field within the element structure.

The STAILQ_SWAP macro swaps the contents of two list heads.

The access macros retrieve information about the list:

  • STAILQ_FIRST(head) returns the first element in the list.
  • STAILQ_NEXT(elm, field) returns the next element in the list after elm.
  • STAILQ_PREV(elm, type, field) returns the previous element in the list before elm.
  • STAILQ_LAST(head, type, field) returns the last element in the list.
  • STAILQ_EMPTY(head) returns true if the list is empty, false otherwise.

RETURN VALUE

The access macros return pointers to list elements or boolean values.

VERSIONS

These macros first appeared in FreeBSD 3.0.

BUGS

The STAILQ_PREV macro is provided for completeness but should be used with caution as it involves dereferencing a pointer to a pointer, which can be error-prone. Also, accessing the previous element requires the stqe_prev field to be correctly set, which is only done by STAILQ_INSERT_HEAD, STAILQ_INSERT_AFTER, and STAILQ_INSERT_BEFORE.

STANDARDS

None.

HISTORY

The singly linked lists with a consistent tail pointer were implemented in FreeBSD 3.0. The macros were ported from the BSD kernel to userland libraries.

EXAMPLES

The following example demonstrates how to use the STAILQ macros to create and manipulate a singly linked list:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    struct stailq_entry entries;
};

int
main() {
    struct node *np, *n1, *n2;
    STAILQ_HEAD(mylist, node) head;

    STAILQ_INIT(&head);

    /* Create and insert nodes */
    np = malloc(sizeof(*np));
    np->data = 1;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(*np));
    np->data = 2;
    STAILQ_INSERT_TAIL(&head, np, entries);

    np = malloc(sizeof(*np));
    np->data = 3;
    STAILQ_INSERT_HEAD(&head, np, entries);

    /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

    /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
