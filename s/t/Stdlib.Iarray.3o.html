DOCUMENTACIÓN

Módulo Iarray
: (módulo Stdlib__Iarray)

Operaciones sobre arrays inmutables. Este módulo refleja la API de Array, pero omite funciones que asumen mutabilidad; además de las funciones obviamente mutables, omite la copiar junto con las funciones make, create_float y make_matrix que producen arrays con valores constantes. La excepción es el módulo de funciones de ordenación, que tienen una API de copia para reemplazar la original en consecuencia.

tipo 'a t = 'a iarray

Un alias para el tipo de arrays inmutables.

val length : 'a iarray -> int

Devuelve la longitud (número de elementos) del array inmutable dado.

val get : 'a iarray -> int -> 'a

get a n devuelve el elemento número n del array inmutable a. El primer elemento tiene el índice 0. El último elemento tiene el índice length a - 1.

Lanza Invalid_argument si n está fuera del rango 0 a (length a - 1).

val init : int -> (int -> 'a) -> 'a iarray

init n f devuelve un array inmutable de longitud n, con el elemento número i inicializado al resultado de f i. En otras palabras, init n f tabula los resultados de f aplicados a los enteros 0 a n-1.

Lanza Invalid_argument si n < 0 o n > Sys.max_array_length. Si el retorno de f es float, entonces el tamaño máximo es solo Sys.max_array_length / 2.

val append : 'a iarray -> 'a iarray -> 'a iarray

append v1 v2 devuelve un array inmutable nuevo que contiene la concatenación de los arrays inmutables v1 y v2.

Lanza Invalid_argument si length v1 + length v2 > Sys.max_array_length.

val concat : 'a iarray list -> 'a iarray

Es equivalente a Iarray.append, pero concatena una lista de arrays inmutables.

val sub : 'a iarray -> pos:int -> len:int -> 'a iarray

sub a ~pos ~len devuelve un array inmutable nuevo de longitud len, que contiene los elementos del índice pos a pos + len - 1 del array inmutable a. Esto crea una copia de la parte seleccionada del array inmutable.

Lanza Invalid_argument si pos y len no designan un sub-array válido de a; es decir, si pos < 0 o len < 0 o pos + len > length a.

val to_list : 'a iarray -> 'a list

to_list a devuelve la lista de todos los elementos del array inmutable a.

val of_list : 'a list -> 'a iarray

of_list l devuelve un array inmutable nuevo que contiene los elementos de l.

Lanza Invalid_argument si el tamaño de l es mayor que Sys.max_array_length.

Conversión a y desde arrays mutables

val to_array : 'a iarray -> 'a array

to_array a devuelve una copia mutable del array inmutable a; es decir, un array mutable nuevo que contiene los mismos elementos que a.

val of_array : 'a array -> 'a iarray

of_array ma devuelve una copia inmutable del array mutable ma; es decir, un array inmutable nuevo que contiene los mismos elementos que ma.

Comparación

val equals : ('a -> 'a -> bool) -> 'a iarray -> 'a iarray -> bool

equals eq [|a1; ...; an|] [|b1; ..; bm|] se cumple cuando los dos arrays inmutables tienen la misma longitud, y para cada par de elementos ai, bi en la misma posición tenemos eq ai bi.

val compare : ('a -> 'a -> int) -> 'a iarray -> 'a iarray -> int

Dado que la función cmp define un preorden sobre los elementos, compare cmp a b compara primero a y b por su longitud, y luego, si son iguales, compara sus elementos según el preorden lexicográfico.

Para más detalles sobre funciones de comparación, vea Iarray.sort.

Iteradores

val iter : ('a -> unit) -> 'a iarray -> unit

iter f a aplica la función f a cada elemento de a. Es equivalente a f (get a 0); f (get a 1); ...; f (get a (length a - 1)); ().

val iteri : (int -> 'a -> unit) -> 'a iarray -> unit

Es equivalente a Iarray.iter, pero la función se aplica al índice del elemento como primer argumento y al elemento mismo como segundo argumento.

val map : ('a -> 'b) -> 'a iarray -> 'b iarray

map f a aplica la función f a todos los elementos de a y crea un array inmutable con los resultados devueltos por f: [| f (get a 0); f (get a 1); ...; f (get a (length a - 1)) |].

val mapi : (int -> 'a -> 'b) -> 'a iarray -> 'b iarray

Es equivalente a Iarray.map, pero la función se aplica al índice del elemento como primer argumento y al elemento mismo como segundo argumento.

val fold_left : ('a -> 'b -> 'a) -> 'a -> 'b iarray -> 'a

fold_left f init a calcula f (... (f (f init (get a 0)) (get a 1)) ...) (get a n-1), donde n es la longitud del array inmutable a.

val fold_left_map : ('a -> 'b -> 'a * 'c) -> 'a -> 'b iarray -> 'a * 'c iarray

fold_left_map combina Iarray.fold_left y Iarray.map para pasar un acumulador por cada llamada a f.

val fold_right : ('b -> 'a -> 'a) -> 'b iarray -> 'a -> 'a

fold_right f a init calcula f (get a 0) (f (get a 1) ( ... (f (get a (n-1)) init) ... )), donde n es la longitud del array inmutable a.

Iteradores en dos arrays

val iter2 : ('a -> 'b -> unit) -> 'a iarray -> 'b iarray -> unit

iter2 f a b aplica la función f a todos los elementos de a y b.

Lanza Invalid_argument si los arrays inmutables no son del mismo tamaño.

val map2 : ('a -> 'b -> 'c) -> 'a iarray -> 'b iarray -> 'c iarray

map2 f a b aplica la función f a todos los elementos de a y b, y crea un array inmutable con los resultados devueltos por f: [| f (get a 0) (get b 0); ...; f (get a (length a - 1)) (get b (length b - 1)) |].

Lanza Invalid_argument si los arrays inmutables no son del mismo tamaño.

Escaneo de arrays

val for_all : ('a -> bool) -> 'a iarray -> bool

for_all f [|a1; ...; an|] verifica si todos los elementos del array inmutable satisfacen el predicado f. Es decir, devuelve (f a1) && (f a2) && ... && (f an).

val exists : ('a -> bool) -> 'a iarray -> bool

exists f [|a1; ...; an|] verifica si al menos uno de los elementos del array inmutable satisface el predicado f. Es decir, devuelve (f a1) || (f a2) || ... || (f an).

val for_all2 : ('a -> 'b -> bool) -> 'a iarray -> 'b iarray -> bool

Es equivalente a Iarray.for_all, pero para un predicado de dos argumentos.

Lanza Invalid_argument si los arrays inmutables tienen diferente longitud.

val exists2 : ('a -> 'b -> bool) -> 'a iarray -> 'b iarray -> bool

Es equivalente a Iarray.exists, pero para un predicado de dos argumentos.

Lanza Invalid_argument si los arrays inmutables tienen diferente longitud.

Accesorios de array y función de búsqueda

val find : ('a -> bool) -> 'a iarray -> 'a option

Devuelve el primer elemento del array inmutable que satisface el predicado f, o None si ningún elemento satisface f.

val find_index : ('a -> bool) -> 'a iarray -> int option

Devuelve el índice del primer elemento del array inmutable que satisface el predicado f, o None si ningún elemento satisface f.

val find_all : ('a -> bool) -> 'a iarray -> 'a iarray

Devuelve un array inmutable que contiene todos los elementos del array inmutable de entrada que satisfacen el predicado f.

val filter : ('a -> bool) -> 'a iarray -> 'a iarray

Es sinónimo de Iarray.find_all.

val filter_map : ('a -> 'b option) -> 'a iarray -> 'b iarray

Para cada elemento x del array inmutable de entrada, calcula f x. Devuelve un array inmutable que contiene todos los valores v tales que f x devolvió Some v.

val partition : ('a -> bool) -> 'a iarray -> 'a iarray * 'a iarray

Devuelve un par de arrays inmutables: el primero contiene todos los elementos de la entrada que satisfacen el predicado f, y el segundo contiene todos los elementos que no satisfacen f.

Ordenación

val sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Devuelve un array inmutable que contiene los mismos elementos que el array inmutable dado, pero ordenado. La función de ordenación cmp define el orden.

val rev_sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Es equivalente a Iarray.sort, pero con el orden invertido.

val stable_sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Igual que Iarray.sort, pero garantizando la estabilidad. La ordenación estable preserva el orden relativo de los elementos que son iguales según la función de ordenación.

val sort_index : ('a -> 'a -> int) -> 'a iarray -> int array

Devuelve un array de enteros que representa los índices de los elementos del array inmutable de entrada, ordenados según la función de ordenación cmp.

val sort_unique : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Igual que Iarray.sort, pero eliminando los elementos duplicados. Si la función cmp devuelve 0 para dos elementos, se conservará solo uno de ellos.

Búsqueda y almacenamiento

val binary_search : ('a -> int) -> 'a iarray -> 'a -> int option

Encuentra el índice del elemento en el array inmutable a que se compara con x usando la función de comparación f. El array a debe estar ordenado según f.

NAME

Iarray - immutable arrays

Module

Module Iarray

Documentation

This module provides functions to create and manipulate immutable arrays. Immutable arrays are arrays whose contents cannot be modified after creation. They are often more efficient than mutable arrays, especially when passed as arguments to functions.

Basic operations

val length : 'a iarray -> int

Return the number of elements in the immutable array.

val get : 'a iarray -> int -> 'a

Return the element at the given index in the immutable array. Raises Invalid_argument if the index is out of bounds.

val get_opt : 'a iarray -> int -> 'a option

Return the element at the given index in the immutable array, or None if the index is out of bounds.

val is_empty : 'a iarray -> bool

Return true if the array is empty, false otherwise.

val equal : ('a -> 'a -> bool) -> 'a iarray -> 'a iarray -> bool

Compare two immutable arrays for equality. The first argument is a function used to compare elements. Two arrays are considered equal if they have the same length and all corresponding elements are equal according to the comparison function.

val eq : 'a iarray -> 'a iarray -> bool

Same as Iarray.equal , but uses physical equality (==) to compare elements.

Construction

val empty : unit -> 'a iarray

Return an empty immutable array.

val singleton : 'a -> 'a iarray

Return an immutable array containing a single element.

val make : int -> 'a -> 'a iarray

Return an immutable array of the given length, with all elements equal to the given value.

val init : int -> (int -> 'a) -> 'a iarray

Return an immutable array of the given length, where the element at index i is computed by applying the function f to i.

val of_list : 'a list -> 'a iarray

Create an immutable array from a list.

val of_array : 'a array -> 'a iarray

Create an immutable array from a mutable array.

Substitutions

val sub : 'a iarray -> int -> int -> 'a iarray

Return an immutable array containing the elements of the original array between the given starting index (inclusive) and ending index (exclusive). Raises Invalid_argument if the indices are out of bounds or if the starting index is greater than the ending index.

val blit : 'a iarray -> int -> 'a iarray -> int -> int -> unit

Copy elements from a source immutable array to a destination immutable array. The 5 arguments specify the source array, the starting index in the source array, the destination array, the starting index in the destination array, and the number of elements to copy. Raises Invalid_argument if indices or lengths are out of bounds. Note that this operation is an effectless operation as immutable arrays cannot be modified. This function is provided for compatibility with the mutable array interface.

val append : 'a iarray -> 'a iarray -> 'a iarray

Concatenate two immutable arrays.

val concat : 'a iarray list -> 'a iarray

Concatenate a list of immutable arrays.

val copy : 'a iarray -> 'a iarray

Return a shallow copy of the immutable array.

Mapping and iterating

val map : ('a -> 'b) -> 'a iarray -> 'b iarray

Return an immutable array obtained by applying the function f to each element of the original array.

val mapi : (int -> 'a -> 'b) -> 'a iarray -> 'b iarray

Return an immutable array obtained by applying the function f to each element of the original array, with the index of the element as the first argument.

val iter : ('a -> unit) -> 'a iarray -> unit

Apply the function f to each element of the array. The results are discarded.

val iteri : (int -> 'a -> unit) -> 'a iarray -> unit

Apply the function f to each element of the array, with the index of the element as the first argument. The results are discarded.

val fold_left : ('a -> 'b -> 'a) -> 'a -> 'b iarray -> 'a

Equivalent to List.fold_left.

val fold_right : ('a -> 'b -> 'b) -> 'a iarray -> 'b -> 'b

Equivalent to List.fold_right.

val fold_lefti : (int -> 'a -> 'b -> 'a) -> 'a -> 'b iarray -> 'a

Same as Iarray.fold_left , but the function is also applied to the index of the element.

val fold_righti : (int -> 'a -> 'b -> 'b) -> 'a iarray -> 'b -> 'b

Same as Iarray.fold_right , but the function is also applied to the index of the element.

Searching

val mem : ('a -> 'a -> int) -> 'a -> 'a iarray -> bool

Return true if the given element is present in the array, and false otherwise. The first argument is a comparison function.

val find : ('a -> bool) -> 'a iarray -> 'a

Return the first element of the array that satisfies the predicate f. Raises Not_found if no such element exists.

val find_opt : ('a -> bool) -> 'a iarray -> 'a option

Return the first element of the array that satisfies the predicate f, or None if no such element exists.

val filter : ('a -> bool) -> 'a iarray -> 'a iarray

Return an immutable array containing only the elements of the original array that satisfy the predicate f.

val partition : ('a -> bool) -> 'a iarray -> 'a iarray * 'a iarray

Return a pair of arrays. The first array contains all elements that satisfy the predicate f, and the second array contains all elements that do not satisfy the predicate f.

Arrays of pairs

val split : ('a * 'b) iarray -> 'a iarray * 'b iarray

Split an array of pairs into two arrays of first and second elements.

val combine : 'a iarray -> 'b iarray -> ('a * 'b) iarray

Combine two arrays into an array of pairs. Raises Invalid_argument if the two arrays have different lengths.

Sorting

val sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Return a new array with the elements of the input array sorted in increasing order according to the comparison function. The comparison function must implement a total order. Raises Invalid_argument if the comparison function does not implement a total order.

val rev_sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Same as Iarray.sort , but sorts in decreasing order.

val stable_sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Same as Iarray.sort , but the sorting algorithm is stable. This means that elements that compare equal are guaranteed to remain in their original relative order.

Iterators

val to_seq : 'a iarray -> 'a Seq.t

Convert an immutable array to a sequence.

val to_seqi : 'a iarray -> (int * 'a) Seq.t

Convert an immutable array to a sequence of pairs (index, element).

val of_seq : 'a Seq.t -> 'a iarray

Convert a sequence to an immutable array.
