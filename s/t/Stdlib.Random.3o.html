Funciones básicas

val init : int -> unit

Inicializa el generador local de dominio, usando el argumento como semilla. La misma semilla siempre producirá la misma secuencia de números.

val full_init : int array -> unit

Igual que Random.init pero toma más datos como semilla.

val self_init : unit -> unit

Inicializa el generador local de dominio con una semilla aleatoria elegida de forma dependiente del sistema. Si está disponible un generador de números pseudoaleatorios criptográficamente seguro en la máquina host, se utiliza para proporcionar una semilla altamente aleatoria. De lo contrario, se calcula una semilla menos aleatoria a partir de parámetros del sistema (hora actual, IDs de proceso, estado local del dominio).

val bits : unit -> int

Devuelve 30 bits aleatorios en un entero no negativo.

val int : int -> int

Random.int bound devuelve un entero aleatorio entre 0 (inclusive) y bound (exclusivo). bound debe ser mayor que 0 y menor que 2^30.

Lanza Invalid_argument si bound <= 0 o bound >= 2^30.

val full_int : int -> int

Random.full_int bound devuelve un entero aleatorio entre 0 (inclusive) y bound (exclusivo). bound puede ser cualquier entero positivo.

Si bound es menor que 2^31, entonces Random.full_int bound produce una salida idéntica en sistemas con diferentes tamaños de int.

Si bound es menor que 2^30, entonces Random.full_int bound es igual a Random.int bound.

Si bound es mayor o igual que 2^30 (en sistemas de 64 bits, o entornos no estándar como JavaScript), entonces Random.full_int devuelve un valor mientras que Random.int lanza Invalid_argument.

Desde 4.13

Lanza Invalid_argument si bound <= 0.

val int_in_range : min:int -> max:int -> int

Random.int_in_range ~min ~max devuelve un entero aleatorio entre min (inclusive) y max (inclusive). Ambos, min y max, pueden ser negativos; min debe ser menor o igual que max.

Si ambos límites caben en enteros con signo de 32 bits (es decir, si -2^31 <= min y max < 2^31), entonces int_in_range produce una salida idéntica en sistemas con diferentes tamaños de int.

Desde 5.2

Lanza Invalid_argument si min > max.

val float : float -> float

Random.float bound devuelve un número de punto flotante aleatorio entre 0 y bound (inclusive). Si bound es negativo, el resultado es negativo o cero. Si bound es 0, el resultado es 0.

val bool : unit -> bool

Random.bool () devuelve true o false con una probabilidad del 0.5 cada una.

val bits32 : unit -> Int32.t

Random.bits32 () devuelve 32 bits aleatorios como un entero entre Int32.min_int y Int32.max_int.

Funciones avanzadas

Las funciones del módulo Random.State manipulan explícitamente el estado actual del generador aleatorio. Esto permite utilizar uno o varios PRNG deterministas, incluso en un programa multihilo, sin interferencia de otras partes del programa.

module State : sig end

val get_state : unit -> State.t

get_state() devuelve una copia nueva del estado actual del generador local de dominio (que es utilizado por las funciones básicas).

val set_state : State.t -> unit

set_state s actualiza el estado actual del generador local de dominio (que es utilizado por las funciones básicas) copiando el estado s en él.

val split : unit -> State.t

Extrae un nuevo estado PRNG del estado actual del generador local de dominio utilizado por las funciones predeterminadas. (El estado del generador local de dominio se modifica.) Ver Random.State.split.

Desde 5.0

Stdlib.Random(3o)

RANDOM — generador de números pseudoaleatorios

Sintaxis

random (n)

Descripción

La función random devuelve un entero pseudoaleatorio en el rango de 0 a n-1 (inclusive). Si n es 0 o menor, el comportamiento es indefinido.

Esta función utiliza un generador de números pseudoaleatorios de Mersenne Twister. La secuencia de números generados es la misma en cada ejecución del programa, a menos que la semilla se cambie explícitamente.

Para obtener una secuencia de números aleatorios diferente en cada ejecución, se recomienda sembrar el generador utilizando la función random_seed con un valor basado en el tiempo actual o en otra fuente de entropía.

Ejemplo

```pike x = random(10) # Genera un número aleatorio entre 0 y 9 print(x) ```
