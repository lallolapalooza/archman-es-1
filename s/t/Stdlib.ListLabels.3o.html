val length : 'a list -> int

Devuelve la longitud (número de elementos) de la lista dada.

val compare_lengths : 'a list -> 'b list -> int

Compara las longitudes de dos listas. compare_lengths l1 l2 es equivalente a compare (length l1) (length l2) , excepto que el cálculo se detiene después de llegar al final de la lista más corta.

Desde 4.05

val compare_length_with : 'a list -> len:int -> int

Compara la longitud de una lista con un entero. compare_length_with l len es equivalente a compare (length l) len , excepto que el cálculo se detiene después de como máximo len iteraciones en la lista.

Desde 4.05

val is_empty : 'a list -> bool

is_empty l es verdadero si y solo si l no tiene elementos. Es equivalente a compare_length_with l 0 = 0 .

val concat : 'a list list -> 'a list

Concatena una lista de listas. Los elementos del argumento se concatenan todos juntos (en el mismo orden) para dar el resultado. No es recursiva de cola (longitud del argumento + longitud de la sublista más larga).

val flatten : 'a list list -> 'a list

Igual que ListLabels.concat . No es recursiva de cola (longitud del argumento + longitud de la sublista más larga).

Comparación

val equal : eq:('a -> 'a -> bool) -> 'a list -> 'a list -> bool

equal eq [a1; ...; an] [b1; ..; bm] es verdadero cuando las dos listas de entrada tienen la misma longitud, y para cada par de elementos ai , bi en la misma posición, tenemos eq ai bi .

Nota: la función eq puede ser llamada incluso si las listas tienen longitudes diferentes. Si sabes que tu función de igualdad es costosa, puedes querer comprobar ListLabels.compare_lengths primero.

Desde 4.12

val compare : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> int

compare cmp [a1; ...; an] [b1; ...; bm] realiza una comparación lexicográfica de las dos listas de entrada, utilizando la misma interfaz 'a -> 'a -> int que compare :

- a1 :: l1 es menor que a2 :: l2 (resultado negativo) si a1 es menor que a2 , o si son iguales (resultado 0) y l1 es menor que l2

- la lista vacía [] es estrictamente menor que las listas no vacías

Nota: la función cmp será llamada incluso si las listas tienen longitudes diferentes.

Escaneo de listas

val for_all : f:('a -> bool) -> 'a list -> bool

for_all ~f [a1; ...; an] comprueba si todos los elementos de la lista satisfacen el predicado f . Es decir, devuelve (f a1) && (f a2) && ... && (f an) para una lista no vacía y true si la lista está vacía.

val exists : f:('a -> bool) -> 'a list -> bool

exists ~f [a1; ...; an] comprueba si al menos un elemento de la lista satisface el predicado f . Es decir, devuelve (f a1) || (f a2) || ... || (f an) para una lista no vacía y false si la lista está vacía.

val for_all2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Igual que ListLabels.for_all , pero para un predicado de dos argumentos.

Genera Invalid_argument si se determina que las dos listas tienen longitudes diferentes.

val exists2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Igual que ListLabels.exists , pero para un predicado de dos argumentos.

Genera Invalid_argument si se determina que las dos listas tienen longitudes diferentes.

Manipulación de listas

take n l devuelve el prefijo de l de longitud n , o una copia de l si n > length l . Es la lista vacía si n es negativo.

Advertencia. En la versión 5.3 solamente, esta función genera Invalid_argument para valores negativos de n .

drop n l devuelve el sufijo de l después de n elementos, o [] si n > length l . Es l si n es negativo.

Advertencia. En la versión 5.3 solamente, esta función genera Invalid_argument para valores negativos de n .

Desde 5.3

Desde 5.3

Desde 5.3

val partition : f:('a -> bool) -> 'a list -> 'a list * 'a list

partition ~f l devuelve un par de listas (l1, l2) , donde l1 es la lista de todos los elementos de l que satisfacen el predicado f , y l2 es la lista de todos los elementos de l que no satisfacen f . Se conserva el orden de los elementos en la lista de entrada.

val partition_map : f:('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

partition_map f l devuelve un par de listas (l1, l2) tal que, para cada elemento x de la lista de entrada l :

-si f x es Left y1 , entonces y1 está en l1 , y

-si f x es Right y2 , entonces y2 está en l2 .

Los elementos de salida se incluyen en l1 y l2 en el mismo orden relativo que los elementos de entrada correspondientes en l .

En particular, partition_map (fun x -> if f x then Left x else Right x) l es equivalente a partition f l .

Listas de asociación

val assoc : 'a -> ('a * 'b) list -> 'b

assoc a l devuelve el valor asociado a la clave a en la lista de pares l . Es decir, assoc a [ ...; (a,b); ...] = b si (a,b) es la primera correspondencia de a en la lista l .

Genera Not_found si no hay ningún valor asociado con a en la lista l .

val assoc_opt : 'a -> ('a * 'b) list -> 'b option

assoc_opt a l devuelve el valor asociado a la clave a en la lista de pares l . Es decir, assoc_opt a [ ...; (a,b); ...] = Some b si (a,b) es la primera correspondencia de a en la lista l . Devuelve None si no hay ningún valor asociado con a en la lista l .

Listas de pares

val split : ('a * 'b) list -> 'a list * 'b list

Transforma una lista de pares en un par de listas: split [(a1,b1); ...; (an,bn)] es ([a1; ...; an], [b1; ...; bn]) . No es recursiva de cola.

val combine : 'a list -> 'b list -> ('a * 'b) list

Transforma un par de listas en una lista de pares: combine [a1; ...; an] [b1; ...; bn] es [(a1,b1); ...; (an,bn)] .

Genera Invalid_argument si las dos listas tienen longitudes diferentes. No es recursiva de cola.

NAME

ListLabels - Labeled operations on lists.

Module

ListLabels

Documentation

This module provides functions for manipulating lists. The functions are labeled, meaning that the arguments are given names. This improves readability and reduces the chance of errors.

val sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Sort a list in increasing order according to a comparison function. The comparison function must return 0 if its arguments compare as equal, a positive integer if the first is greater, and a negative integer if the first is smaller (see Array.sort for a complete specification). For example, compare is a suitable comparison function. The resulting list is sorted in increasing order. ListLabels.sort is guaranteed to run in constant heap space (in addition to the size of the result list) and logarithmic stack space.

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val stable_sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort , but the sorting algorithm is guaranteed to be stable (i.e. elements that compare equal are kept in their original order).

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val fast_sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort or ListLabels.stable_sort , whichever is faster on typical input.

val sort_uniq : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort , but also remove duplicates: if multiple elements compare equal, keep only the first.

Before5.4 the element kept was not necessarily the first one.

Since 4.03

val merge : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> 'a list

Merge two lists: Assuming that l1 and l2 are sorted according to the comparison function cmp , merge ~cmp l1 l2 will return a sorted list containing all the elements of l1 and l2 . If several elements compare equal, the elements of l1 will be before the elements of l2 . Not tail-recursive (sum of the lengths of the arguments).
