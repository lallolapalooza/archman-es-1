DESCRIPCIÓN

Estas macros proporcionan una implementación de colas doblemente enlazadas (tail queues), colas simplemente enlazadas (singly-linked lists), listas doblemente enlazadas (doubly-linked lists) y listas simplemente enlazadas con cola (singly-linked tail queues).

Una cola simplemente enlazada se usa para implementar colas de primeros en entrar, primeros en salir (FIFO). Una cola simplemente enlazada con cola se usa para implementar colas de últimos en entrar, primeros en salir (LIFO). Las listas doblemente enlazadas y las colas de cola doblemente enlazadas permiten una iteración más eficiente y permiten que los elementos se eliminen en cualquier lugar de la lista.

La convención es definir una estructura para contener la cabeza de la cola, y luego para cada tipo de elemento en la cola, definir una estructura de entrada que contenga un puntero al siguiente elemento. Por ejemplo:

struct my_list_entry {
…
SLIST_ENTRY(my_list_entry) next; /* or TAILQ_ENTRY, LIST_ENTRY, etc. */
};
typedef struct my_list_entry my_list_entry_t;
SLIST_HEAD(my_list_head, my_list_entry); /* or TAILQ_HEAD, LIST_HEAD */
typedef struct my_list_head my_list_head_t;

Para inicializar una cola, use SLIST_INIT() (o la variante apropiada para el tipo de cola).

Los elementos de la cola se pueden agregar utilizando SLIST_INSERT_HEAD(), SLIST_INSERT_TAIL(), SLIST_INSERT_AFTER() o SLIST_INSERT_BEFORE().

Para eliminar elementos de la cola, use SLIST_REMOVE(), SLIST_REMOVE_HEAD(), SLIST_REMOVE_TAIL() o SLIST_REMOVE_AFTER().

Para acceder a los elementos, use SLIST_FIRST() y SLIST_NEXT() (o SLIST_PREV() para listas doblemente enlazadas).

Para iterar sobre los elementos de la cola, use SLIST_FOREACH() o SLIST_FOREACH_SAFE().

Las macros SLIST_CLASS_ENTRY() y SLIST_CLASS_HEAD() son para fines de documentación y se pueden usar para documentar las estructuras y campos de cola de manera más clara. No tienen ningún efecto en tiempo de ejecución.

Las macros SLIST_CONCAT() y TAILQ_CONCAT() se utilizan para fusionar dos colas. La cola head2 se adjunta al final de la cola head1. La cola head2 estará vacía después de la operación.

Las macros SLIST_SWAP(), STAILQ_SWAP(), LIST_SWAP() y TAILQ_SWAP() intercambian el contenido de las dos colas especificadas.

Las macros SLIST_FOREACH_FROM() y SLIST_FOREACH_SAFE() permiten iterar sobre una cola a partir de un elemento específico.

Las macros TAILQ_FOREACH_REVERSE(), TAILQ_FOREACH_REVERSE_FROM(), TAILQ_FOREACH_REVERSE_SAFE() y TAILQ_FOREACH_REVERSE_FROM_SAFE() permiten iterar sobre una cola en orden inverso.

Las macros SLIST_REMOVE_AFTER(), STAILQ_REMOVE_AFTER() y LIST_REMOVE_AFTER() eliminan el elemento que sigue al elemento especificado.

La macro STAILQ_LAST() devuelve un puntero al último elemento de la cola.

La macro LIST_INSERT_BEFORE() inserta un nuevo elemento antes del elemento especificado.

La macro LIST_PREV() devuelve un puntero al elemento anterior en una lista doblemente enlazada.

La macro SLIST_REMOVE_HEAD() elimina y devuelve el primer elemento de la cola.

La macro STAILQ_REMOVE_HEAD() elimina y devuelve el primer elemento de la cola.

La macro SLIST_REMOVE_AFTER() elimina el elemento que sigue al elemento especificado.

La macro STAILQ_REMOVE_AFTER() elimina el elemento que sigue al elemento especificado.

La macro SLIST_EMPTY() comprueba si la cola está vacía.

La macro STAILQ_EMPTY() comprueba si la cola está vacía.

La macro LIST_EMPTY() comprueba si la cola está vacía.

La macro SLIST_HEAD_INITIALIZER() inicializa una cabeza de cola.

La macro STAILQ_HEAD_INITIALIZER() inicializa una cabeza de cola.

La macro LIST_HEAD_INITIALIZER() inicializa una cabeza de cola.

Para usar estas macros, debe incluir el archivo de cabecera <sys/queue.h>.

EJEMPLOS

Este es un ejemplo de uso de STAILQ para implementar una cola FIFO:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_item {
    int data;
    STAILQ_ENTRY(my_item) next;
};

STAILQ_HEAD(my_queue, my_item);

int
main() {
    struct my_queue queue;
    struct my_item *item;
    struct my_item *tmp;

    STAILQ_INIT(&queue);

    /* Add items to the queue */
    for (int i = 0; i < 5; ++i) {
        item = malloc(sizeof(*item));
        item->data = i;
        STAILQ_INSERT_TAIL(&queue, item, next);
    }

    /* Process items in the queue */
    STAILQ_FOREACH(item, &queue, next) {
        printf("Item data: %d\n", item->data);
    }

    /* Remove items from the queue */
    while (!STAILQ_EMPTY(&queue)) {
        item = STAILQ_FIRST(&queue);
        STAILQ_REMOVE_HEAD(&queue, next);
        printf("Removing item with data: %d\n", item->data);
        free(item);
    }

    return 0;
}

DESCRIPTION

These macros define and operate on four types of data structures which can be used in both C and C++ source code:

  1. Lists
  2. Singly-linked lists
  3. Singly-linked tail queues
  4. Tail queues
All four structures support the following functionality:
  1. Insertion of a new entry at the head of the list.
  2. Insertion of a new entry after any element in the list.
  3. O(1) removal of an entry from the head of the list.
  4. Forward traversal through the list.
  5. Swapping the contents of two lists.

Singly-linked lists are the simplest of the four data structures and support only the above functionality. Singly-linked lists are ideal for applications with large datasets and few or no removals, or for implementing a LIFO queue. Singly-linked lists add the following functionality:

  1. O(n) removal of any entry in the list.
  2. O(n) concatenation of two lists.

Singly-linked tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. O(n) removal of any entry in the list.
  3. They may be concatenated.
However:
  1. All list insertions must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

Singly-linked tail queues are ideal for applications with large datasets and few or no removals, or for implementing a FIFO queue.

All doubly linked types of data structures (lists and tail queues) additionally allow:

  1. Insertion of a new entry before any element in the list.
  2. O(1) removal of any entry in the list.
However:
  1. Each element requires two pointers rather than one.
  2. Code size and execution time of operations (except for removal) is about twice that of the singly-linked data-structures.

Linked lists are the simplest of the doubly linked data structures. They add the following functionality over the above:

  1. O(n) concatenation of two lists.
  2. They may be traversed backwards.
However:
  1. To traverse backwards, an entry to begin the traversal and the list in which it is contained must be specified.

Tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. They may be traversed backwards, from tail to head.
  3. They may be concatenated.
However:
  1. All list insertions and removals must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

In the macro definitions, TYPE is the name of a user defined structure. The structure must contain a field called NAME which is of type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, or TAILQ_ENTRY. In the macro definitions, CLASSTYPE is the name of a user defined class. The class must contain a field called NAME which is of type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, or TAILQ_CLASS_ENTRY. The argument HEADNAME is the name of a user defined structure that must be declared using the macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, or TAILQ_CLASS_HEAD. See the examples below for further explanation of how these macros are used.

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element or at the head of the list. An SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A singly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_FROM behaves identically to SLIST_FOREACH when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_FOREACH_FROM_SAFE behaves identically to SLIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro SLIST_REMOVE removes the element elm from the list.

The macro SLIST_SWAP swaps the contents of the two lists referenced by head1 and head2.

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains pointers to both the first and the last element of the queue. The elements are doubly linked for O(1) insertion and removal at either end of the queue. New elements can be added to the queue after an existing element, before an existing element, at the head of the queue, or at the tail of the queue. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the queue. A pointer to the head of the queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the queue head.

The macro TAILQ_ENTRY declares a structure that connects the elements in the queue.

The macro TAILQ_INIT initializes the queue referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the queue.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the tail of the queue.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_REMOVE removes the element elm from the queue.

The macro TAILQ_REPLACE replaces the element elm with the element elm2 in the queue.

The macro TAILQ_SWAP swaps the contents of the two queues referenced by head1 and head2.

The macro TAILQ_CONCAT concatenates the queue headed by head2 onto the end of the one headed by head1, removing all entries from the former.

The macro TAILQ_FIRST returns the first element in the queue or NULL if the queue is empty.

The macro TAILQ_LAST returns the last element in the queue or NULL if the queue is empty.

The macro TAILQ_NEXT returns the next element in the queue after the element elm or NULL if elm is the last element.

The macro TAILQ_PREV returns the previous element in the queue before the element elm or NULL if elm is the first element.

The macro TAILQ_PREVP returns the previous element in the queue before the element elm or NULL if elm is the first element. This macro is functionally identical to TAILQ_PREV, but is provided for consistency with SLIST_NEXT and LIST_NEXT.

The macro TAILQ_ENQ is an alias for TAILQ_INSERT_TAIL.

The macro TAILQ_DEQ removes and returns the first element from the queue. This macro is functionally identical to TAILQ_POPHead.

The macro TAILQ_POPHead removes and returns the first element from the queue. It returns NULL if the queue is empty.

The macro TAILQ_POPLast removes and returns the last element from the queue. It returns NULL if the queue is empty.

The macro TAILQ_PEEKHead returns the first element in the queue without removing it. It returns NULL if the queue is empty.

The macro TAILQ_PEEKLast returns the last element in the queue without removing it. It returns NULL if the queue is empty.

The macro TAILQ_FOREACH traverses the queue referenced by head in the forward direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_SAFE traverses the queue referenced by head in the forward direction, assigning each element in turn to var. However, unlike TAILQ_FOREACH, here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE traverses the queue referenced by head in the backward direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_REVERSE_SAFE traverses the queue referenced by head in the backward direction, assigning each element in turn to var. However, unlike TAILQ_FOREACH_REVERSE, here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_EMPTY evaluates to true if there are no elements in the queue.

The macro TAILQ_ENTRY_INITIALIZER evaluates to an initializer for a TAILQ_ENTRY.

EXAMPLES

A simple program that uses TAILQ macros:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_data {
    int data;
    TAILQ_ENTRY(my_data) next;
};

TAILQ_HEAD(my_list, my_data) my_list_head;

int
main() {
    struct my_data *item;
    struct my_data *item2;

    TAILQ_INIT(&my_list_head);

    /* Add items to the tail */
    item = malloc(sizeof(*item));
    item->data = 1;
    TAILQ_INSERT_TAIL(&my_list_head, item, next);

    item = malloc(sizeof(*item));
    item->data = 2;
    TAILQ_INSERT_TAIL(&my_list_head, item, next);

    /* Add item to the head */
    item2 = malloc(sizeof(*item2));
    item2->data = 0;
    TAILQ_INSERT_HEAD(&my_list_head, item2, next);

    /* Traverse the list */
    printf("Traversing forward:\n");
    TAILQ_FOREACH(item, &my_list_head, next) {
        printf("Data: %d\n", item->data);
    }

    /* Traverse the list backwards */
    printf("Traversing backward:\n");
    TAILQ_FOREACH_REVERSE(item, &my_list_head, my_list, next) {
        printf("Data: %d\n", item->data);
    }

    /* Remove items */
    item = TAILQ_FIRST(&my_list_head);
    TAILQ_REMOVE(&my_list_head, item, next);
    free(item);

    item = TAILQ_LAST(&my_list_head, my_list);
    TAILQ_REMOVE(&my_list_head, item, next);
    free(item);

    /* Free the remaining item */
    item = TAILQ_FIRST(&my_list_head);
    TAILQ_REMOVE(&my_list_head, item, next);
    free(item);

    return 0;
}

COLAS DE COLA ENLAZADAS SIMPLES

Una cola de cola de cola singly linked está dirigida por una estructura definida mediante la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de cola y el otro al último elemento. Los elementos están vinculados de forma singly linked para minimizar el overhead en el espacio y en la manipulación de punteros, a pesar de que el tiempo de eliminación sea O(n) para elementos arbitrarios. Los nuevos elementos pueden ser insertados en la cola de cola después de un elemento existente, al frente de la cola de cola o al final de la cola de cola. Una estructura STAILQ_HEAD se declara así:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definirse y TYPE es el tipo de los elementos vinculados a la cola de cola. Una dirección del puntero al frente de la cola de cola puede ser declarada más tarde así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de cola head.

La macro STAILQ_CONCAT concatenará la cola de cola dirigida por head2 en la cola de cola dirigida por head1, eliminando todos los elementos de la primera cola de cola.

La macro STAILQ_EMPTY evalúa a true si no hay elementos en la cola de cola.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos de la cola de cola.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de cola o NULL si la cola de cola está vacía.

La macro STAILQ_FOREACH recorre la cola de cola dirigida por head en la dirección forward, asignando cada elemento a var.

La macro STAILQ_FOREACH_FROM comporta idénticamente a STAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la cola de cola y comienza el bucle en var en lugar del primer elemento de la cola de cola dirigida por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de cola dirigida por head en la dirección forward, asignando cada elemento a var. Sin embargo, a diferencia de STAILQ_FOREACH() aquí es permitido eliminar var y liberarla desde dentro del bucle de manera segura sin interferir con la travesía.

La macro STAILQ_FOREACH_FROM_SAFE comporta idénticamente a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la cola de cola y comienza el bucle en var en lugar del primer elemento de la cola de cola dirigida por head.

La macro STAILQ_INIT inicializa la cola de cola dirigida por head.

La macro STAILQ_INSERT_HEAD inserta el elemento nuevo elm al frente de la cola de cola.

La macro STAILQ_INSERT_TAIL inserta el elemento nuevo elm al final de la cola de cola.

La macro STAILQ_INSERT_AFTER inserta el elemento nuevo elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de cola. Si la cola de cola está vacía, el valor devuelto es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de cola, o NULL si este es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola de cola. Aunque no recorre toda la cola de cola, esta macro es diferente de STAILQ_REMOVE.

La macro STAILQ_REMOVE_HEAD elimina el elemento al frente de la cola de cola. Para una eficiencia óptima, los elementos que se van a eliminar del frente de la cola de cola deben usar esta macro explícitamente en lugar del macro genérico STAILQ_REMOVE。

La macro STAILQ_REMOVE elimina el elemento elm de la cola de cola. Su uso debe evitarse ya que recorre toda la lista. Si se necesita esta macro en rutas de código de alto uso o para operar sobre colas de cola largas, se debe usar una cola de cola doblemente ligada.

La macro STAILQ_SWAP intercambia los contents de head1 y head2.

LISTS

A list is headed by a structure defined by the LIST_HEAD macro. This structure contains a single pointer to the first element in the list. The elements are singly linked so that the list must be traversed from the beginning to find an arbitrary element. New elements can be added to the list after an existing element, or at the head of the list. A LIST_HEAD structure is declared as follows:

LIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro LIST_EMPTY evaluates to true if there are no items on the list.

The macro LIST_ENTRY declares a structure that connects the elements in the list.

The macro LIST_FIRST returns the first item on the list or NULL if the list is empty.

The macro LIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro LIST_FOREACH_FROM behaves identically to LIST_FOREACH when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike LIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro LIST_FOREACH_FROM_SAFE behaves identically to LIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_INIT initializes the list referenced by head.

The macro LIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro LIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro LIST_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro LIST_NEXT returns the next element in the list, or NULL if this is the last.

The macro LIST_PREV returns the previous element in the list, or NULL if this is the first. List head must contain element elm.

The macro LIST_REMOVE removes the element elm from the list.

The macro LIST_SWAP swaps the contents of head1 and head2.

    LIST_HEAD_INITIALIZER(head);

struct entry {
	...
	LIST_ENTRY(entry) entries;	/* List. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_REMOVE(n2, entries);		/* Deletion. */
free(n2);
					/* Forward traversal. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Safe forward traversal. */

	...

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are doubly linked so that an arbitrary element can be removed without traversing the tail queue. New elements can be added to the tail queue after an existing element, before an existing element, at the head of the tail queue, or at the end of the tail queue. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro TAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro TAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro TAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro TAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro TAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. var is set to NULL if the loop completes normally, or if there were no elements.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE traverses the tail queue referenced by head in the reverse direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_REVERSE_FROM behaves identically to TAILQ_FOREACH_REVERSE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macros TAILQ_FOREACH_SAFE and TAILQ_FOREACH_REVERSE_SAFE traverse the list referenced by head in the forward or reverse direction respectively, assigning each element in turn to var. However, unlike their unsafe counterparts, TAILQ_FOREACH and TAILQ_FOREACH_REVERSE make it possible to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE_FROM_SAFE behaves identically to TAILQ_FOREACH_REVERSE_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macro TAILQ_INIT initializes the tail queue referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro TAILQ_NEXT returns the next item on the tail queue, or NULL if this item is the last.

The macro TAILQ_PREV returns the previous item on the tail queue, or NULL if this item is the first.

The macro TAILQ_REMOVE removes the element elm from the tail queue.

The macro TAILQ_SWAP swaps the contents of head1 and head2.

NAME

STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_INSERT_AFTER, STAILQ_INSERT_BEFORE, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, STAILQ_REMOVE_TAIL, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_FIRST, STAILQ_NEXT, STAILQ_PREV, STAILQ_LAST, STAILQ_FOREACH, STAILQ_FOREACH_SAFE, STAILQ_INIT, STAILQ_CHECK, STAILQ_PEEK_HEAD, STAILQ_PEEK_TAIL, STAILQ_PEEK_NEXT, STAILQ_PEEK_PREV, STAILQ_PEEK_LAST — Singly linked tail queue macros

SYNOPSIS

#include <sys/queue.h>

/* Singly linked tail queues */

typedef struct STAILQ_HEAD(_tailq, _type) _tailq_head;

/* * Singly linked tail queue element. * Must be the first member of the structure. */

#define STAILQ_ENTRY(type) \ struct \{ \ struct type *STQ_next; \ \}

/* * Singly linked tail queue head. * Must be the first member of the structure. */

#define STAILQ_HEAD(tailq, type) \ struct tailq \{ \ struct type *STQH_first; \ struct type *STQH_last; \ \}

/* * Singly linked tail queue primitives. */

#define STAILQ_INIT(head) \ do \{ \ (head)->STQH_first = NULL; \ (head)->STQH_last = NULL; \ \} while (0)

#define STAILQ_INSERT_HEAD(head, elm, field) \ do \{ \ if ((elm)->field.STQ_next = (head)->STQH_first; \ ) \ (head)->STQH_last = (elm); \ (head)->STQH_first = (elm); \ \} while (0)

#define STAILQ_INSERT_TAIL(head, elm, field) \ do \{ \ (elm)->field.STQ_next = NULL; \ if ((head)->STQH_last != NULL \ ) \ (head)->STQH_last->field.STQ_next = (elm); \ else \ (head)->STQH_first = (elm); \ (head)->STQH_last = (elm); \ \} while (0)

#define STAILQ_INSERT_AFTER(head, listelm, elm, field) \ do \{ \ if ((elm)->field.STQ_next = (listelm)->field.STQ_next; \ ) \ if ((listelm)->field.STQ_next == NULL \ ) \ (head)->STQH_last = (elm); \ (elm)->field.STQ_next = (listelm)->field.STQ_next; \ (listelm)->field.STQ_next = (elm); \ \} while (0)

#define STAILQ_INSERT_BEFORE(head, listelm, elm, field) \ do \{ \ if ((head)->STQH_first == (listelm) \ ) \ STAILQ_INSERT_HEAD(head, elm, field); \ else \{ \ struct type *tmp; \ for (tmp = (head)->STQH_first; \ tmp != NULL && \ tmp->field.STQ_next != (listelm); \ tmp = tmp->field.STQ_next \ ) \ ; \ (elm)->field.STQ_next = (listelm); \ if (tmp != NULL \ ) \ (tmp)->field.STQ_next = (elm); \ \} \ \} while (0)

#define STAILQ_REMOVE_HEAD(head, type, field) \ do \{ \ struct type *elm = (head)->STQH_first; \ if ((elm)->field.STQ_next == NULL \ ) \ (head)->STQH_last = NULL; \ (head)->STQH_first = (elm)->field.STQ_next; \ \} while (0)

#define STAILQ_REMOVE_TAIL(head, type, field) \ do \{ \ struct type *elm; \ if ((head)->STQH_first == NULL \ ) \ (head)->STQH_last = NULL; \ else \{ \ (elm) = (head)->STQH_first; \ if (elm->field.STQ_next == NULL \ ) \ (head)->STQH_first = NULL; \ else \ while (elm->field.STQ_next != NULL \ ) \ elm = elm->field.STQ_next; \ (head)->STQH_last = elm; \ \} \ \} while (0)

#define STAILQ_CONCAT(head1, head2, field) \ do \{ \ if ((head1)->STQH_first != NULL \ ) \{ \ (head1)->STQH_last->field.STQ_next = (head2)->STQH_first; \ (head1)->STQH_last = (head2)->STQH_last; \ STAILQ_INIT(head2); \ \} \ \} while (0)

#define STAILQ_EMPTY(head) \ ((head)->STQH_first == NULL)

#define STAILQ_FIRST(head) \ ((head)->STQH_first)

#define STAILQ_NEXT(elm, field) \ ((elm)->field.STQ_next)

#define STAILQ_LAST(head, type, field) \ ((head)->STQH_last)

#define STAILQ_FOREACH(var, head, field) \ for (struct type *var = STAILQ_FIRST(head); \ var != NULL; \ var = STAILQ_NEXT(var, field) \ )

#define STAILQ_FOREACH_SAFE(var, head, field, nextvar) \ for (struct type *var = STAILQ_FIRST(head), \ *nextvar = STAILQ_NEXT(var, field); \ var != NULL; \ var = nextvar, \ nextvar = STAILQ_NEXT(var, field) \ )

#define STAILQ_CHECK(head) \ ((head)->STQH_first != NULL \ && (head)->STQH_last != NULL \ )

DESCRIPTION

These macros provide an implementation of singly linked tail queues.

A singly linked tail queue is a data structure that allows efficient insertion and deletion of elements. Elements are added to the tail of the queue and removed from the head. The implementation is in the form of a macro, which allows the data structure to be embedded within a regular struct.

To use these macros, you must first define a tail queue head structure. This is done using the STAILQ_HEAD macro:

struct my_list;
STAILQ_HEAD(my_list_head, my_list);

Then, you must define the entry structure for the elements that will be stored in the queue. This is done using the STAILQ_ENTRY macro:

struct my_list {
        STAILQ_ENTRY(my_list) entries;
        int data;
};

Finally, you can declare a tail queue head and use the provided macros to manipulate it:

struct my_list_head my_head;
STAILQ_INIT(&my_head);

These macros provide an implementation of singly linked lists. They are similar to singly linked tail queues, but they do not maintain a pointer to the tail of the list.

SINGLY-LINKED LIST EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
        int data;
        SLIST_ENTRY(node) next;
};

int
main()
{
        struct node *np;
        struct node *curr;
        struct node *next;
        SLIST_HEAD(my_list_head, node) head;

        SLIST_INIT(&head);

        /* Insert elements */
        np = malloc(sizeof(*np));
        np->data = 1;
        SLIST_INSERT_HEAD(&head, np, next);

        np = malloc(sizeof(*np));
        np->data = 2;
        SLIST_INSERT_HEAD(&head, np, next);

        np = malloc(sizeof(*np));
        np->data = 3;
        SLIST_INSERT_HEAD(&head, np, next);

        /* Traverse the list */
        printf("List elements:\n");
        SLIST_FOREACH_SAFE(curr, &head, next, next) {
                printf("data = %d\n", curr->data);
                SLIST_REMOVE(&head, curr, node, next);
                free(curr);
        }

        return 0;
}

DIAGNOSTICS

When debugging queue(3), it can be useful to trace queue changes. To enable tracing, define the macro QUEUE_MACRO_DEBUG_TRACE at compile time.

It can also be useful to trash pointers that have been unlinked from a queue, to detect use after removal. To enable pointer trashing, define the macro QUEUE_MACRO_DEBUG_TRASH at compile time. The macro QMD_IS_TRASHED(void *ptr) returns true if ptr has been trashed by the QUEUE_MACRO_DEBUG_TRASH option.
