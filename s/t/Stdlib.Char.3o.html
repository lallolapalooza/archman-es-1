Caracteres

tipo t = char

Un alias para el tipo de caracteres.

val code : char -> int

Devuelve el código entero del argumento.

val chr : int -> char

Devuelve el carácter con el código entero dado.

Lanza Invalid_argument si el argumento está fuera del rango [ 0x00 ; 0xFF ].

val escaped : char -> string

Devuelve una cadena que representa el carácter dado, con caracteres especiales escapados siguiendo las convenciones léxicas de OCaml. Todos los caracteres fuera del rango imprimible ASCII [ 0x20 ; 0x7E ] se escapan, así como la barra invertida, las comillas dobles y las comillas simples.

Predicados y comparaciones

Ver también el módulo Char.Ascii.

val compare : t -> t -> int

La función de comparación para caracteres, con la misma especificación que compare. Junto con el tipo t, esta función compare permite que el módulo Char se pase como argumento a los functores Set.Make y Map.Make.

val equal : t -> t -> bool

La función de igualdad para caracteres.

Caracteres ASCII

module Ascii : sig end

Soporte del conjunto de caracteres ASCII.

Estas funciones dan significado a los enteros [ 0x00 ; 0x7F ] del conjunto de caracteres ASCII.

Dado que la codificación UTF-8 de Unicode tiene la misma codificación y semántica de caracteres (U+0000 a U+001F) para estos bytes, las funciones pueden usarse de forma segura en elementos de cadenas y bytes codificados en UTF-8. Sin embargo, las funciones solo se ocupan de asuntos relacionados con ASCII. Por ejemplo, la noción de espacio en blanco de Unicode es mucho mayor que el espacio en blanco ASCII determinado por Char.Ascii.is_white.

Hashing

val seeded_hash : int -> t -> int

Una función hash sembrada para caracteres, con el mismo valor de salida que Hashtbl.seeded_hash. Esta función permite que este módulo se pase como argumento al functor Hashtbl.MakeSeeded.

Desde 5.1

val hash : t -> int

Una función hash no sembrada para caracteres, con el mismo valor de salida que Hashtbl.hash. Esta función permite que este módulo se pase como argumento al functor Hashtbl.Make.
