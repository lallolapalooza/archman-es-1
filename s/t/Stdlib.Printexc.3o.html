Desde 4.09

val print : ('a -> 'b) -> 'a -> 'b

Printexc.print fn x aplica fn a x y devuelve el resultado. Si la evaluación de fn x genera alguna excepción, el nombre de la excepción se imprime en la salida de error estándar, y la excepción se vuelve a generar. El uso típico es capturar e informar excepciones que escapan a la aplicación de una función.

val catch : ('a -> 'b) -> 'a -> 'b

Obsoleto. Esta función ya no es necesaria.

Printexc.catch fn x es similar a Printexc.print, pero interrumpe el programa con el código de salida 2 después de imprimir la excepción no capturada. Esta función está obsoleta: el sistema en tiempo de ejecución ahora es capaz de imprimir excepciones no capturadas tan precisamente como lo hace Printexc.catch. Además, llamar a Printexc.catch dificulta el seguimiento de la ubicación de la excepción utilizando el depurador o la facilidad de retroceso de pila. Por lo tanto, no utilice Printexc.catch en código nuevo.

val print_backtrace : out_channel -> unit

Printexc.print_backtrace oc imprime un retroceso de excepción en el canal de salida oc. El retroceso enumera las ubicaciones del programa donde se generó la excepción generada más recientemente y dónde se propagó a través de llamadas a funciones.

Si la llamada no está dentro de un manejador de excepciones, el retroceso devuelto no está especificado. Si la llamada se realiza después de algún código de captura de excepciones (antes en el manejador, o en una guarda `when` durante la coincidencia del manejador de excepciones), el retroceso puede corresponder a una excepción posterior a la manejada.

Desde 3.11

val get_backtrace : unit -> string

Printexc.get_backtrace () devuelve una cadena que contiene el mismo retroceso de excepción que imprimiría Printexc.print_backtrace. Misma restricción de uso que Printexc.print_backtrace.

Desde 3.11

val record_backtrace : bool -> unit

Printexc.record_backtrace b activa (si b = true) o desactiva (si b = false) la grabación de retrocesos de excepciones. Inicialmente, los retrocesos no se graban, a menos que se proporcione la bandera b al programa a través de la variable OCAMLRUNPARAM.

Desde 3.11

val backtrace_status : unit -> bool

Printexc.backtrace_status() devuelve true si los retrocesos de excepciones se están grabando actualmente, false si no.

Desde 3.11

val register_printer : (exn -> string option) -> unit

Printexc.register_printer fn registra fn como un impresor de excepciones. El impresor debe devolver None o generar una excepción si no sabe cómo convertir la excepción pasada, y Some
s con s la cadena resultante si puede convertir la excepción pasada. Las excepciones generadas por el impresor se ignoran.

Al convertir una excepción en una cadena, los impresores se invocarán en orden inverso a su registro, hasta que un impresor devuelva un valor Some s (si no existe tal impresor, el tiempo de ejecución utilizará un impresor genérico).

Al usar este mecanismo, se debe tener en cuenta que un retroceso de excepción se adjunta al hilo que lo vio generarse, en lugar de a la excepción en sí. Prácticamente, esto significa que el código relacionado con fn no debe usar el retroceso si ha generado una excepción por sí mismo antes.

Desde 3.11.2

val use_printers : exn -> string option

Printexc.use_printers e devuelve None si no hay impresores registrados y Some s con s la cadena resultante en caso contrario.

Desde 4.09

Retrocesos en bruto

type raw_backtrace

El tipo raw_backtrace almacena un retroceso en un formato de bajo nivel, que se puede convertir a un formato utilizable utilizando raw_backtrace_entries y backtrace_slots_of_raw_entry abajo.

Convertir retrocesos a backtrace_slot s es más lento que capturar los retrocesos. Si una aplicación procesa muchos retrocesos, puede ser útil utilizar raw_backtrace para evitar o retrasar la conversión.

Los retrocesos en bruto no se pueden serializar. Si necesita serialización, debe usar la matriz devuelta por la función backtrace_slots de la siguiente sección.

Desde 4.01

type raw_backtrace_entry = private int

Una raw_backtrace_entry es un elemento de un raw_backtrace.

Cada raw_backtrace_entry es un entero opaco, cuyo valor no es estable entre diferentes programas, o incluso entre diferentes ejecuciones del mismo binario.

Una raw_backtrace_entry se puede convertir a un formato utilizable utilizando backtrace_slots_of_raw_entry abajo. Tenga en cuenta que, debido a la incrustación (inlining), una sola raw_backtrace_entry puede convertirse en varias backtrace_slot s. Dado que los valores de una raw_backtrace_entry no son estables, no se pueden serializar. Si se van a convertir, la conversión debe ser realizada por el proceso que los generó.

Nuevamente, debido a la incrustación, puede haber múltiples valores distintos de raw_backtrace_entry que se conviertan en backtrace_slot s iguales. Sin embargo, si dos raw_backtrace_entry son iguales como enteros, entonces representan los mismos backtrace_slot s.

Printexc.3o(3o)

Manipulate exceptions and their associated raw backtraces.

NAME

Printexc - Manipulate exceptions and their associated raw backtraces.

Module

Stdlib.Printexc

Documentation

This module provides access to the raw backtraces associated with exceptions. It is useful for debugging and logging purposes.

Printing raw backtraces

val print_raw_backtrace : out_channel -> raw_backtrace -> unit

Prints the given raw backtrace on the given output channel. The output is similar to that of the C function U_except_trace, but it is formatted to be more readable.

Since 4.02

val convert_raw_backtrace : raw_backtrace -> backtrace_slot list option

Converts a raw backtrace to a list of backtrace_slot. Returns None if the raw backtrace cannot be converted (e.g., if it does not contain enough information).

Since 4.02

val print_backtrace : out_channel -> unit

Prints the current exception backtrace on the given output channel. This is equivalent to calling get_callstack(-1) and then printing the result using print_raw_backtrace.

Since 4.02

val record_backtrace : bool -> unit

If record_backtrace is called with true, then exception backtraces are recorded. This is the default behavior. If called with false, backtraces are not recorded, saving memory and time. The initial state is implementation-dependent, but usually it is enabled.

Since 4.02

val set_recording_backtrace : bool -> unit

This is an older name for record_backtrace.

Since 4.02

val backtrace_formatter : (Format.formatter -> raw_backtrace -> unit) ref

This function allows you to customize the printing of raw backtraces. The default formatter prints the backtrace in a human-readable format. You can change the function referenced by this ref to customize the output. For example, to print the backtrace in JSON format.

A raw backtrace may not contain any useful information if the program was not compiled with debugging information (e.g. using ocamlc -g or ocamlopt -g), or if the program is a bytecode program that has not been linked with debug information enabled.

If the backtrace is empty or contains no useful information, the formatter function is still called, but it should handle this case appropriately (e.g. by printing nothing or a message indicating that no information is available).

Note that the standard library's top-level loops automatically print exceptions using the backtrace_formatter, but they must make sure any output channel fn writes on is flushed.

Also note that exceptions raised by user code in the interactive toplevel are not passed to this function as they are caught by the toplevel itself.

If fn raises an exception, both the exceptions passed to fn and raised by fn will be printed with their respective backtrace.

Since 4.02

Manipulation of backtrace information

These functions are used to traverse the slots of a raw backtrace and extract information from them in a programmer-friendly format.

type backtrace_slot

The abstract type backtrace_slot represents a single slot of a backtrace.

Since 4.02

val backtrace_slots : raw_backtrace -> backtrace_slot array option

Returns the slots of a raw backtrace, or None if none of them contain useful information.

In the return array, the slot at index 0 corresponds to the most recent function call, raise, or primitive get_backtrace call in the trace.

Some possible reasons for returning None are as follow:

-none of the slots in the trace come from modules compiled with debug information ( -g )

-the program is a bytecode program that has not been linked with debug information enabled ( ocamlc -g )

Since 4.02

val backtrace_slots_of_raw_entry : raw_backtrace_entry -> backtrace_slot array option

Returns the slots of a single raw backtrace entry, or None if this entry lacks debug information.

Slots are returned in the same order as backtrace_slots : the slot at index 0 is the most recent call, raise, or primitive, and subsequent slots represent callers.

Since 4.02

Raw backtrace slots

type raw_backtrace_slot

This type is used to iterate over the slots of a raw_backtrace . For most purposes, backtrace_slots_of_raw_entry is easier to use.

Like raw_backtrace_entry , values of this type are process-specific and must absolutely not be marshalled, and are unsafe to use for this reason (marshalling them may not fail, but un-marshalling and using the result will result in undefined behavior).

Elements of this type can still be compared and hashed: when two elements are equal, then they represent the same source location (the converse is not necessarily true in presence of inlining, for example).

Since 4.02

val raw_backtrace_length : raw_backtrace -> int

raw_backtrace_length bckt returns the number of slots in the backtrace bckt .

Since 4.02

val get_raw_backtrace_slot : raw_backtrace -> int -> raw_backtrace_slot

get_raw_backtrace_slot bckt pos returns the slot in position pos in the backtrace bckt .

Since 4.02

val convert_raw_backtrace_slot : raw_backtrace_slot -> backtrace_slot

Extracts the user-friendly backtrace_slot from a low-level raw_backtrace_slot .

Since 4.02

val get_raw_backtrace_next_slot : raw_backtrace_slot -> raw_backtrace_slot option

get_raw_backtrace_next_slot slot returns the next slot inlined, if any.

Sample code to iterate over all frames (inlined and non-inlined): 

      (* Iterate over inlined frames *)
      let rec iter_raw_backtrace_slot f slot =
        f slot;
        match get_raw_backtrace_next_slot slot with
        | None -> ()
        | Some slot' -> iter_raw_backtrace_slot f slot'
      (* Iterate over stack frames *)
      let iter_raw_backtrace f bt =
        for i = 0 to raw_backtrace_length bt - 1 do
          iter_raw_backtrace_slot f (get_raw_backtrace_slot bt i)
        done
