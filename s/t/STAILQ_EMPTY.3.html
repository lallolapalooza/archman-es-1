STAILQ(3) Manual de Funciones de Biblioteca STAILQ(3)

NOMBRE

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implementación de una cola de listas enlazadas simples con cola

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TIPO);
STAILQ_HEAD(NOMBRE_CABECERA, TIPO);
STAILQ_HEAD NOMBRE_CABECERA STAILQ_HEAD_INITIALIZER(STAILQ_HEAD cabecera);
void STAILQ_INIT(STAILQ_HEAD *cabecera);
int STAILQ_EMPTY(STAILQ_HEAD *cabecera);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *cabecera,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *cabecera,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *cabecera, struct TIPO *listelm,
                         struct TIPO *elem, STAILQ_ENTRY NOMBRE);
struct TIPO *STAILQ_FIRST(STAILQ_HEAD *cabecera);
struct TIPO *STAILQ_NEXT(struct TIPO *elem, STAILQ_ENTRY NOMBRE);
STAILQ_FOREACH(struct TIPO *var, STAILQ_HEAD *cabecera, STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE(STAILQ_HEAD *cabecera, struct TIPO *elem, TIPO,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *cabecera,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_CONCAT(STAILQ_HEAD *cabecera1, STAILQ_HEAD *cabecera2);

Nota: Existen macros idénticas prefijadas con SIMPLEQ en lugar de STAILQ; véase VERSIONES.

DESCRIPCIÓN

Estas macros definen y operan sobre colas de listas enlazadas simples con cola.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro STAILQ_HEAD().

Creación

Una cola de listas enlazadas simples con cola está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola de listas y otro al último elemento de la cola de listas. Los elementos están enlazados simplemente para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de O(n) para la eliminación de elementos arbitrarios. Se pueden añadir nuevos elementos a la cola de listas después de un elemento existente, al principio de la cola de listas o al final de la cola de listas. Una estructura STAILQ_HEAD se declara de la siguiente manera:


STAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola de listas. Un puntero a la cabecera de la cola de listas se puede declarar posteriormente como:


struct NOMBRE_CABECERA *cabecerp;

(Los nombres cabecera y cabecerp son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos en la cola de listas.

STAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola de listas cabecera.

STAILQ_INIT() inicializa la cola de listas referenciada por cabecera.

STAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola de listas.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola de listas.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola de listas.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento listelm.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola de listas o NULL si la cola de listas está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola de listas, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola de listas referenciada por cabecera en dirección hacia adelante, asignando cada elemento en turno a var.

Eliminación

STAILQ_REMOVE() elimina el elemento elem de la cola de listas.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola de listas. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola de listas deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola de listas encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola cabecera.

VERSIONES

Algunos BSDs proporcionan SIMPLEQ en lugar de STAILQ. Son idénticas, pero por razones históricas se les dio nombres diferentes en diferentes BSDs. STAILQ se originó en FreeBSD, y SIMPLEQ se originó en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticas excepto por la falta de un equivalente SIMPLEQ a STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSDs pero no en glibc, corrige esta limitación al permitir que var se elimine de la lista y se libere de forma segura desde dentro del bucle sin interferir con el recorrido.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    STAILQ_ENTRY(entrada) entradas;        /* Cola de lista enlazada simple */
};
STAILQ_HEAD(cabecerastail, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabecerastail cabeza;                  /* Cabecera de cola de lista enlazada simple */
    STAILQ_INIT(&cabeza);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    STAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);
    STAILQ_REMOVE(&cabeza, n2, entrada, entradas); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&cabeza);
    STAILQ_REMOVE_HEAD(&cabeza, entradas);     /* Eliminación desde el principio */
    free(n3);
    n1 = STAILQ_FIRST(&cabeza);
    n1->datos = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
        n1->datos = i;
    }

STAILQ_EMPTY(3bsd) — Arch manual pages

NAME

STAILQ_EMPTY, STAILQ_FOREACH, STAILQ_FIRST, STAILQ_INIT, STAILQ_NEXT — macros for iterating over and manipulating singly linked lists

LIBRARY

Libc — The C Library

SYNOPSIS

#include <sys/queue.h>

/*
 * Singly linked Tail queue definitions.
 * Note that entries must be suitable for use in a singly linked list,
 * which means that they must contain a field of type STAILQ_ENTRY(type).
 */

/* Define a singly linked tail queue named TYPE. */
#define STAILQ_HEAD(name, type) ...

/* Define an entry in a singly linked tail queue. */
#define STAILQ_ENTRY(type) ...

/* Initialize HEAD to an empty queue. */
#define STAILQ_INIT(HEAD) ...

/*
 * Forward iteration.
 * The loop body is executed for each element in the queue.
 * np is a pointer to the element type.
 */
#define STAILQ_FOREACH(np, HEAD) ...

/*
 * Forward iteration (no need to call STAILQ_NEXT).
 * The loop body is executed for each element in the queue.
 * np is a pointer to the element type.
 */
#define STAILQ_FOREACH_SAFE(np, HEAD, nextp) ...

/* Return the first element in the queue. */
#define STAILQ_FIRST(HEAD) ...

/*
 * Return the next element in the queue.
 * Use this macro to iterate over the queue.
 */
#define STAILQ_NEXT(elm, field) ...

/*
 * Singly linked Tail queue removal functions.
 * The head of the queue is passed as argument.
 * The macros return the removed element or NULL if the queue is empty.
 */
#define STAILQ_REMOVE_HEAD(HEAD, field) ...
#define STAILQ_REMOVE_HEAD_NP(HEAD, field) ...

/*
 * Singly linked Tail queue insertion functions.
 * The head of the queue is passed as argument.
 */
#define STAILQ_INSERT_HEAD(HEAD, elm, field) ...
#define STAILQ_INSERT_TAIL(HEAD, elm, field) ...

/*
 * Singly linked Tail queue lookup functions.
 * The head of the queue is passed as argument.
 */
#define STAILQ_LOOKUP(HEAD, elm, field) ...
#define STAILQ_LOOKUP_GE(HEAD, elm, field, cmp) ...
#define STAILQ_LOOKUP_GT(HEAD, elm, field, cmp) ...
#define STAILQ_LOOKUP_LE(HEAD, elm, field, cmp) ...
#define STAILQ_LOOKUP_LT(HEAD, elm, field, cmp) ...

/*
 * Singly linked Tail queue concatenation functions.
 * The head of the queue is passed as argument.
 */
#define STAILQ_CONCAT(HEAD1, HEAD2, field) ...

/*
 * Singly linked Tail queue concatenation functions.
 * The head of the queue is passed as argument.
 */
#define STAILQ_SWAP(HEAD1, HEAD2, type) ...

/*
 * Singly linked Tail queue functions.
 * The head of the queue is passed as argument.
 */
#define STAILQ_EMPTY(HEAD) ...
#define STAILQ_PREVPTR(HEAD, elm, field) ...
#define STAILQ_LAST(HEAD, field) ...
#define STAILQ_INSERT_AFTER(HEAD, listelm, elm, field) ...
#define STAILQ_INSERT_BEFORE(HEAD, listelm, elm, field) ...
#define STAILQ_REMOVE(HEAD, elm, field) ...
#define STAILQ_REMOVE_AFTER(elm, field) ...
#define STAILQ_FIND(HEAD, elm, field) ...
#define STAILQ_FIND_GE(HEAD, elm, field, cmp) ...
#define STAILQ_FIND_GT(HEAD, elm, field, cmp) ...
#define STAILQ_FIND_LE(HEAD, elm, field, cmp) ...
#define STAILQ_FIND_LT(HEAD, elm, field, cmp) ...

DESCRIPTION

These macros provide a generic way to implement a singly linked list. The STAILQ_* macros operate on a singly linked tail queue, meaning that new elements are added to the tail of the queue.

A singly linked tail queue is defined using the STAILQ_HEAD macro. For example:

struct my_list_head {
    STAILQ_ENTRY(my_list_element) entries;
    int data;
};
STAILQ_HEAD(my_list_head_tag, struct my_list_element);
struct my_list_head_tag my_list;

Each element in the list must contain an entry of the appropriate type, defined using the STAILQ_ENTRY macro. For example:

struct my_list_element {
    STAILQ_ENTRY(my_list_element) entries;
    int data;
};

The STAILQ_INIT macro initializes an empty queue.

The STAILQ_FOREACH macro iterates over the elements of the queue. It expands to a while loop.

The STAILQ_FOREACH_SAFE macro is similar to STAILQ_FOREACH, but it provides a way to safely remove elements from the queue while iterating.

The STAILQ_FIRST macro returns a pointer to the first element in the queue, or NULL if the queue is empty.

The STAILQ_NEXT macro returns a pointer to the next element in the queue, or NULL if the current element is the last element.

The STAILQ_REMOVE_HEAD macro removes and returns the first element of the queue. If the queue is empty, it returns NULL.

The STAILQ_REMOVE_HEAD_NP macro is similar to STAILQ_REMOVE_HEAD but does not require the field argument.

The STAILQ_INSERT_HEAD macro inserts an element at the head of the queue.

The STAILQ_INSERT_TAIL macro inserts an element at the tail of the queue.

The STAILQ_EMPTY macro returns true if the queue is empty, false otherwise.

The STAILQ_PREVPTR macro returns a pointer to the pointer that points to the specified element elm. This can be used to remove the element from the queue.

The STAILQ_LAST macro returns a pointer to the last element in the queue, or NULL if the queue is empty.

The STAILQ_INSERT_AFTER macro inserts an element after the specified element listelm.

The STAILQ_INSERT_BEFORE macro inserts an element before the specified element listelm.

The STAILQ_REMOVE macro removes the specified element elm from the queue.

The STAILQ_REMOVE_AFTER macro removes the element after the specified element elm.

The STAILQ_FIND, STAILQ_FIND_GE, STAILQ_FIND_GT, STAILQ_FIND_LE, and STAILQ_FIND_LT macros search for an element in the queue that matches the specified element elm or satisfies the given comparison function cmp.

The STAILQ_CONCAT macro concatenates two queues, appending the second queue to the first.

The STAILQ_SWAP macro swaps the contents of two queues.

RETURN VALUE

The STAILQ_FIRST macro returns a pointer to the first element, or NULL if the queue is empty. The STAILQ_NEXT macro returns a pointer to the next element, or NULL if the current element is the last element. The STAILQ_REMOVE_HEAD macro returns the removed element or NULL if the queue is empty. The STAILQ_EMPTY macro returns a non-zero value if the queue is empty, and zero otherwise.

VERSIONS

These macros first appeared in FreeBSD 3.0.

BUGS

The STAILQ_FOREACH macro is not safe for removing elements from the queue while iterating. Use STAILQ_FOREACH_SAFE instead.

STANDARDS

The STAILQ_* macros are intended to be compatible with the macros defined in sys/queue.h in FreeBSD.

HISTORY

The STAILQ_* macros were implemented in FreeBSD 3.0.

EXAMPLES

The following example demonstrates how to use the STAILQ_* macros to create, populate, iterate over, and destroy a singly linked tail queue.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_element {
    STAILQ_ENTRY(my_element) entries;
    int data;
};

STAILQ_HEAD(my_list_head_tag, struct my_element);

int
main(void)
{
    struct my_list_head_tag head;
    struct my_element *np, *n1, *n2;

    STAILQ_INIT(&head);

    /* Add elements to the tail of the list */
    for (int i = 0; i < 5; ++i) {
        np = malloc(sizeof(struct my_element));
        if (np == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }
        np->data = i;
        STAILQ_INSERT_TAIL(&head, np, entries);
    }

    /* Forward traversal */
    STAILQ_FOREACH(np, &head)
        printf("%i\n", np->data);

    /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);

    exit(EXIT_SUCCESS);
}
