tipo 'a t = 'a array

Un alias para el tipo de arrays.

valor longitud : 'a array -> int

Devuelve la longitud (número de elementos) del array dado.

valor obtener : 'a array -> int -> 'a

obtener a n devuelve el elemento número n del array a. El primer elemento tiene el número 0. El último elemento tiene el número longitud a - 1. También puedes escribir a.(n) en lugar de obtener a n.

Lanza Invalid_argument si n está fuera del rango 0 a (longitud a - 1).

valor establecer : 'a array -> int -> 'a -> unidad

establecer a n x modifica el array a in situ, reemplazando el elemento número n con x. También puedes escribir a.(n) <- x en lugar de establecer a n x.

Lanza Invalid_argument si n está fuera del rango 0 a longitud a - 1.

valor crear : int -> 'a -> 'a array

crear n x devuelve un array nuevo de longitud n, inicializado con x. Todos los elementos de este nuevo array son inicialmente físicamente iguales a x (en el sentido del predicado ==). En consecuencia, si x es mutable, se comparte entre todos los elementos del array, y modificar x a través de una de las entradas del array modificará todas las demás entradas al mismo tiempo.

Lanza Invalid_argument si n < 0 o n > Sys.max_array_length. Si el valor de x es un número de punto flotante, entonces el tamaño máximo es solo Sys.max_array_length / 2.

valor crear_float : int -> float array

crear_float n devuelve un array de float nuevo de longitud n, con datos no inicializados.

Desde 4.03

valor inicializar : int -> f:(int -> 'a) -> 'a array

inicializar n ~f devuelve un array nuevo de longitud n, con el elemento número i inicializado con el resultado de f i. En otras palabras, inicializar n ~f tabula los resultados de f aplicados en orden a los enteros 0 a n-1.

Lanza Invalid_argument si n < 0 o n > Sys.max_array_length. Si el tipo de retorno de f es float, entonces el tamaño máximo es solo Sys.max_array_length / 2.

valor crear_matriz : dimx:int -> dimy:int -> 'a -> 'a array array

crear_matriz ~dimx ~dimy e devuelve un array bidimensional (un array de arrays) con la primera dimensión dimx y la segunda dimensión dimy. Todos los elementos de esta nueva matriz son inicialmente físicamente iguales a e. El elemento ( x,y ) de una matriz m se accede con la notación m.(x).(y).

Lanza Invalid_argument si dimx o dimy es negativo o mayor que Sys.max_array_length. Si el valor de e es un número de punto flotante, entonces el tamaño máximo es solo Sys.max_array_length / 2.

valor inicializar_matriz : dimx:int -> dimy:int -> f:(int -> int -> 'a) -> 'a array array

inicializar_matriz ~dimx ~dimy ~f devuelve un array bidimensional (un array de arrays) con la primera dimensión dimx y la segunda dimensión dimy, donde el elemento en el índice ( x,y ) se inicializa con f x y. El elemento ( x,y ) de una matriz m se accede con la notación m.(x).(y).

Desde 5.2

Lanza Invalid_argument si dimx o dimy es negativo o mayor que Sys.max_array_length. Si el tipo de retorno de f es float, entonces el tamaño máximo es solo Sys.max_array_length / 2.

valor añadir : 'a array -> 'a array -> 'a array

añadir v1 v2 devuelve un array nuevo que contiene la concatenación de los arrays v1 y v2.

Lanza Invalid_argument si longitud v1 + longitud v2 > Sys.max_array_length.

valor concatenar : 'a array list -> 'a array

Igual que ArrayLabels.añadir, pero concatena una lista de arrays.

valor subvector : 'a array -> pos:int -> len:int -> 'a array

subvector a ~pos ~len devuelve un array nuevo de longitud len, que contiene los elementos del número pos al número pos + len - 1 del array a.

Lanza Invalid_argument si pos y len no designan un subvector válido de a; es decir, si pos < 0, o len < 0, o pos + len > longitud a.

valor copiar : 'a array -> 'a array

copiar a devuelve una copia de a, es decir, un array nuevo que contiene los mismos elementos que a.

valor rellenar : 'a array -> pos:int -> len:int -> 'a -> unidad

rellenar a ~pos ~len x modifica el array a in situ, almacenando x en los elementos del número pos al número pos + len - 1.

Lanza Invalid_argument si pos y len no designan un subvector válido de a.

valor transferir : src:'a array -> src_pos:int -> dst:'a array -> dst_pos:int -> len:int -> unidad

transferir ~src ~src_pos ~dst ~dst_pos ~len copia len elementos del array src, comenzando en el elemento número src_pos, al array dst, comenzando en el elemento número dst_pos. Funciona correctamente incluso si src y dst son el mismo array, y los fragmentos de origen y destino se superponen.

Lanza Invalid_argument si src_pos y len no designan un subvector válido de src, o si dst_pos y len no designan un subvector válido de dst.

valor a_lista : 'a array -> 'a list

a_lista a devuelve la lista de todos los elementos de a.

valor de_lista : 'a list -> 'a array

de_lista l devuelve un array nuevo que contiene los elementos de l.

Lanza Invalid_argument si la longitud de l es mayor que Sys.max_array_length.

Comparación

valor igual : eq:('a -> 'a -> bool) -> 'a array -> 'a array -> bool

igual eq a b es verdadero si y solo si a y b tienen la misma longitud n y para todo i en [ 0 ; n-1 ], eq a.(i) b.(i) es verdadero.

Desde 5.4

valor comparar : cmp:('a -> 'a -> int) -> 'a array -> 'a array -> int

comparar cmp a b compara a y b según el orden shortlex, es decir, los arrays más cortos son más pequeños y los arrays de igual tamaño se comparan en orden lexicográfico usando cmp para comparar elementos.

Desde 5.4

Iteradores

valor iterar : f:('a -> unidad) -> 'a array -> unidad

iterar ~f a aplica la función f sucesivamente a todos los elementos de a. Es equivalente a f a.(0); f a.(1); ...; f a.(longitud a - 1); ().

valor iterar_con_indice : f:(int -> 'a -> unidad) -> 'a array -> unidad

Igual que ArrayLabels.iterar, pero la función se aplica al índice del elemento como primer argumento, y al elemento mismo como segundo argumento.

valor mapear : f:('a -> 'b) -> 'a array -> 'b array

mapear ~f a aplica la función f a todos los elementos de a, y construye un array con los resultados devueltos por f: [| f a.(0); f a.(1); ...; f a.(longitud a - 1) |].

valor mapear_in_situ : f:('a -> 'a) -> 'a array -> unidad

mapear_in_situ ~f a aplica la función f a todos los elementos de a, y actualiza sus valores in situ.

Desde 5.1

valor mapear_con_indice : f:(int -> 'a -> 'b) -> 'a array -> 'b array

Igual que ArrayLabels.mapear, pero la función se aplica al índice del elemento como primer argumento, y al elemento mismo como segundo argumento.

Iteradores en dos arrays

val iter2 : f:('a -> 'b -> unit) -> 'a array -> 'b array -> unit

iter2 ~f a b aplica la función f a todos los elementos de a y b .

Since 4.05

Raises Invalid_argument si los arrays no son del mismo tamaño.

val map2 : f:('a -> 'b -> 'c) -> 'a array -> 'b array -> 'c array

map2 ~f a b aplica la función f a todos los elementos de a y b , y construye un array con los resultados de f : [| f a.(0) b.(0); ...; f a.(length a - 1) b.(length b - 1)|] .

Since 4.05

Raises Invalid_argument si los arrays no son del mismo tamaño.

Escaneo de arrays

val for_all : f:('a -> bool) -> 'a array -> bool

for_all ~f [|a1; ...; an|] verifica si todos los elementos del array satisfacen el predicado f . Es decir, devuelve (f a1) && (f a2) && ... && (f an) .

Since 4.03

val exists : f:('a -> bool) -> 'a array -> bool

exists ~f [|a1; ...; an|] verifica si al menos un elemento del array satisface el predicado f . Es decir, devuelve (f a1) || (f a2) || ... || (f an) .

Since 4.03

val for_all2 : f:('a -> 'b -> bool) -> 'a array -> 'b array -> bool

Igual que ArrayLabels.for_all , pero para un predicado de dos argumentos.

Since 4.11

Raises Invalid_argument si los dos arrays tienen longitudes distintas.

val exists2 : f:('a -> 'b -> bool) -> 'a array -> 'b array -> bool

Igual que ArrayLabels.exists , pero para un predicado de dos argumentos.

Since 4.11

Raises Invalid_argument si los dos arrays tienen longitudes distintas.

val mem : 'a -> set:'a array -> bool

mem a ~set es verdadero si y solo si a es estructuralmente igual a un elemento de set (es decir, existe un x en set tal que compare a x = 0 ).

Since 4.03

val memq : 'a -> set:'a array -> bool

Igual que ArrayLabels.mem , pero utiliza la igualdad física en lugar de la igualdad estructural para comparar los elementos de los arrays.

Since 4.03

val find_opt : f:('a -> bool) -> 'a array -> 'a option

find_opt ~f a devuelve el primer elemento del array a que satisface el predicado f , o None si no hay ningún valor que satisfaga f en a .

Since 4.13

val find_index : f:('a -> bool) -> 'a array -> int option

find_index ~f a devuelve Some i , donde i es el índice del primer elemento del array a que satisface f x , si existe tal elemento.

Devuelve None si no existe tal elemento.

Since 5.1

val find_map : f:('a -> 'b option) -> 'a array -> 'b option

find_map ~f a aplica f a los elementos de a en orden, y devuelve el primer resultado de la forma Some v , o None si no hay resultados.

Since 4.13

val find_mapi : f:(int -> 'a -> 'b option) -> 'a array -> 'b option

Igual que find_map , pero el predicado se aplica al índice del elemento como primer argumento (contando desde 0), y al elemento como segundo argumento.

Since 5.1

Arrays de pares

val split : ('a * 'b) array -> 'a array * 'b array

split [|(a1,b1); ...; (an,bn)|] es ([|a1; ...; an|], [|b1; ...; bn|]) .

Since 4.13

val combine : 'a array -> 'b array -> ('a * 'b) array

combine [|a1; ...; an|] [|b1; ...; bn|] es [|(a1,b1); ...; (an,bn)|] . Lanza Invalid_argument si los dos arrays tienen longitudes distintas.

Since 4.13

Ordenación y aleatorización

val sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Ordena un array en orden ascendente según una función de comparación. La función de comparación debe devolver 0 si sus argumentos son iguales, un número positivo si el primero es mayor, y un número negativo si el primero es menor (ver especificación completa a continuación). Por ejemplo, compare es una función de comparación adecuada. Después de llamar a sort, el array está ordenado.

val rev_sort : cmp:('a -> 'a -> int) -> 'a array -> unit

Igual que sort , pero en orden descendente.

val sort_uniq : cmp:('a -> 'a -> int) -> 'a array -> unit

Igual que sort , pero con la suposición adicional de que todos los elementos del array son distintos. El comportamiento es indefinido si hay elementos duplicados.

val shuffle : array:'a array -> Random.State.t -> unit

Aleatoriza un array in situ utilizando el generador de números aleatorios proporcionado por state .

Since 4.08

NAME

StdLabels.Array — Mutable arrays.

Module

StdLabels.Array

Documentation

This module provides functions for the creation, manipulation, and reading of mutable arrays. The operations are labeled, i.e. they take their arguments as a record.

The array indices are integers ranging from 0 to size-1, where size is the number of elements in the array. Array accesses are unchecked.

Data races

When multiple domains (threads) concurrently access the same mutable array, the accesses must be synchronized to avoid data races. Without synchronization, the behavior is undefined. In the presence of data races, programs may crash or behave in unexpected ways. It is the programmer's responsibility to ensure that accesses to shared mutable data structures are properly synchronized.

If data races are avoided through synchronization mechanisms, the observed behavior is guaranteed to be equivalent to some sequential interleaving of the operations performed by different domains.

Whenever possible, data races should be avoided by using synchronization to mediate the accesses to the array elements.

Indeed, in the presence of data races, programs will not crash but the observed behaviour may not be equivalent to any sequential interleaving of operations from different domains. Nevertheless, even in the presence of data races, a read operation will return the value of some prior write to that location (with a few exceptions for float arrays).

Float arrays

Float arrays have two supplementary caveats in the presence of data races.

First, the blit operation might copy an array byte-by-byte. Data races between such a blit operation and another operation might produce surprising values due to tearing: partial writes interleaved with other operations can create float values that would not exist with a sequential execution.

For instance, at the end of

let zeros = Array.make size 0.
let max_floats = Array.make size Float.max_float
let res = Array.copy zeros
let d1 = Domain.spawn (fun () -> Array.blit zeros 0 res 0 size)
let d2 = Domain.spawn (fun () -> Array.blit max_floats 0 res 0 size)
let () = Domain.join d1; Domain.join d2
the res array might contain values that are neither 0. nor max_float .

Second, on 32-bit architectures, getting or setting a field involves two separate memory accesses. In the presence of data races, the user may observe tearing on any operation.
