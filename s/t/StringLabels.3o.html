Cadenas.

Una cadena s de longitud n es una secuencia de n bytes indexable e inmutable. Por razones históricas, estos bytes se denominan caracteres.

La semántica de las funciones de cadena se define en términos de índices y posiciones. Estos se representan y describen de la siguiente manera:

posiciones 0 1 2 3 4 n-1 n +---+---+---+---+ +-----+ índices | 0 | 1 | 2 | 3 | ... | n-1 | +---+---+---+---+ +-----+

-Un índice i de s es un entero en el rango [ 0 ; n-1 ]. Representa el i -ésimo byte (carácter) de s que se puede acceder mediante el operador de indexación de cadena de tiempo constante s.[i] .

-Una posición i de s es un entero en el rango [ 0 ; n ]. Representa el punto al principio de la cadena, o el punto entre dos índices, o el punto al final de la cadena. El índice del byte i está entre la posición i y i+1 .

Dos enteros start y len se dice que definen una subcadena válida de s si len >= 0 y start , start+len son posiciones de s .

Texto Unicode. Dado que las cadenas son secuencias de bytes arbitrarias, pueden contener cualquier tipo de codificación textual. Sin embargo, la codificación recomendada para almacenar texto Unicode en cadenas de OCaml es UTF-8. Esta es la codificación utilizada por las secuencias de escape Unicode en las literales de cadena. Por ejemplo, la cadena "\u{1F42B}" es la codificación UTF-8 del carácter Unicode U+1F42B.

Más allá de la mutabilidad. Antes de OCaml 4.02, las cadenas se podían modificar en el lugar como secuencias mutables de bytes Bytes.t . OCaml 4 tenía varias opciones de compilador y configuraciones para admitir el período de transición de cadenas mutables a inmutables. Esas opciones ya no están disponibles, y las cadenas ahora son siempre inmutables.

La versión con etiquetas de este módulo se puede usar como se describe en el módulo StdLabels .

Cadenas

type t = string

El tipo para cadenas.

val make : int -> char -> string

make n c es una cadena de longitud n con cada índice conteniendo el carácter c .

Lanza Invalid_argument si n < 0 o n > Sys.max_string_length .

val init : int -> f:(int -> char) -> string

init n ~f es una cadena de longitud n con el índice i conteniendo el carácter f i (llamado en orden creciente de índice).

Desde 4.02

Lanza Invalid_argument si n < 0 o n > Sys.max_string_length .

val empty : string

La cadena vacía.

Desde 4.13

val length : string -> int

length s es la longitud (número de bytes/caracteres) de s .

val get : string -> int -> char

get s i es el carácter en el índice i de s . Esto es lo mismo que escribir s.[i] .

Lanza Invalid_argument si i no es un índice de s .

val of_bytes : bytes -> string

Devuelve una nueva cadena que contiene los mismos bytes que la secuencia de bytes dada.

Desde 4.13

val to_bytes : string -> bytes

Devuelve una nueva secuencia de bytes que contiene los mismos bytes que la cadena dada.

Desde 4.13

val blit : src:string -> src_pos:int -> dst:bytes -> dst_pos:int -> len:int -> unit

Concatenación

Nota. El operador binario (^) concatena dos cadenas.

val concat : sep:string -> string list -> string

concat ~sep ss concatena la lista de cadenas ss , insertando la cadena separadora sep entre cada una.

Lanza Invalid_argument si el resultado es más largo que Sys.max_string_length bytes.

val cat : string -> string -> string

cat s1 s2 concatena s1 y s2 ( s1 ^ s2 ).

Desde 4.13

Lanza Invalid_argument si el resultado es más largo que Sys.max_string_length bytes.

Predicados y comparaciones

val equal : t -> t -> bool

equal s0 s1 es true si y solo si s0 y s1 son iguales carácter por carácter.

Desde 4.05

val compare : t -> t -> int

compare s0 s1 ordena s0 y s1 en orden lexicográfico. compare se comporta como compare en cadenas pero puede ser más eficiente.

val starts_with : prefix:string -> string -> bool

starts_with ~prefix s es true si y solo si s comienza con prefix .

Desde 4.13

val ends_with : suffix:string -> string -> bool

ends_with ~suffix s es true si y solo si s termina con suffix .

Desde 4.13

val contains_from : string -> int -> char -> bool

contains_from s start c es true si y solo si c aparece en s después de la posición start .

Lanza Invalid_argument si start no es una posición válida en s .

val rcontains_from : string -> int -> char -> bool

rcontains_from s stop c es true si y solo si c aparece en s antes de la posición stop+1 .

Lanza Invalid_argument si stop < 0 o stop+1 no es una posición válida en s .

val contains : string -> char -> bool

contains s c es String.contains_from s 0 c .

Extracción de subcadenas

val sub : string -> pos:int -> len:int -> string

sub s ~pos ~len es una cadena de longitud len , que contiene la subcadena de s que comienza en la posición pos y tiene longitud len .

Lanza Invalid_argument si pos y len no designan una subcadena válida de s .

val split_on_char : sep:char -> string -> string list

split_on_char ~sep s es la lista de todas las subcadenas (posiblemente vacías) de s que están delimitadas por el carácter sep . Si s está vacía, el resultado es la lista singleton [""] .

El resultado de la función está especificado por los siguientes invariantes:

-La lista no está vacía.

-Concatenar sus elementos usando sep como separador devuelve una cadena igual a la entrada ( concat (make 1 sep)
(split_on_char sep s) = s ).

-Ninguna cadena en el resultado contiene el carácter sep .

Desde 4.05

Transformación

val map : f:(char -> char) -> string -> string

map f s es la cadena resultante de aplicar f a todos los caracteres de s en orden creciente.

Desde 4.00

val mapi : f:(int -> char -> char) -> string -> string

mapi ~f s es como StringLabels.map pero el índice del carácter también se pasa a f .
