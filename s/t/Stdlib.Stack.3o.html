Módulo Stack
: (módulo Stdlib__Stack)

Accesos no sincronizados

Los accesos no sincronizados a una pila pueden provocar un estado de cola inválido. Por lo tanto, los accesos concurrentes a las pilas deben sincronizarse (por ejemplo, con un Mutex.t ).

tipo !'a t

El tipo de pilas que contienen elementos de tipo 'a .

excepción Empty

Lanzada cuando Stack.pop o Stack.top se aplican a una pila vacía.

valor create : unidad -> 'a t

Devuelve una nueva pila, inicialmente vacía.

valor push : 'a -> 'a t -> unidad

push x s añade el elemento x en la cima de la pila s .

valor pop : 'a t -> 'a

pop s elimina y devuelve el elemento superior de la pila s , o lanza Stack.Empty si la pila está vacía.

valor pop_opt : 'a t -> 'a option

pop_opt s elimina y devuelve el elemento superior de la pila s , o devuelve None si la pila está vacía.

top_opt s devuelve el elemento superior de la pila s , o None si la pila está vacía.

valor clear : 'a t -> unidad

Descarta todos los elementos de una pila.

valor copy : 'a t -> 'a t

Devuelve una copia de la pila dada.

valor is_empty : 'a t -> bool

Devuelve true si la pila dada está vacía, false en caso contrario.

valor length : 'a t -> int

Devuelve el número de elementos en una pila. Complejidad temporal O(1)

valor iter : ('a -> unidad) -> 'a t -> unidad

iter f s aplica f por turnos a todos los elementos de s , desde el elemento en la cima de la pila hasta el elemento en el fondo de la pila. La pila en sí no cambia.

valor fold : ('acc -> 'a -> 'acc) -> 'acc -> 'a t -> 'acc

fold f accu s es (f (... (f (f accu x1) x2) ...) xn) donde x1 es la cima de la pila, x2 el segundo elemento y xn el elemento del fondo. La pila no cambia.
