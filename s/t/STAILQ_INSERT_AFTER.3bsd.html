DESCRIPCIÓN

Estas macros implementan estructuras de datos de listas enlazadas (singly-linked lists), colas de cola enlazadas simples (singly-linked tail queues), listas doblemente enlazadas (doubly-linked lists) y colas de cola doblemente enlazadas (doubly-linked tail queues). Las listas simples y las colas de cola simples son listas enlazadas donde cada nodo apunta solo al siguiente nodo en la lista. Las listas y colas de cola doblemente enlazadas son listas donde cada nodo apunta tanto al nodo siguiente como al nodo anterior en la lista.

La implementación de estas estructuras de datos se basa en macros que operan sobre punteros dentro de las estructuras de datos que se van a enlazar. Esto permite que las estructuras de datos se definan y se usen independientemente de la estructura de datos que las contenga.

Para usar estas macros, debe definir una estructura para sus nodos, que debe contener al menos un campo de puntero para enlazar los nodos. Por ejemplo, para una lista simple, podría definir:

typedef struct my_list_entry {{
/* otros campos de datos */
/* campo de puntero para el enlace */ struct my_list_entry *next;
}} my_list_entry_t;
SLIST_HEAD(my_list_head, my_list_entry);
struct my_list_head my_list;
SLIST_INIT(&my_list);

Las macros para cada tipo de lista son:

SLIST
Listas enlazadas simples.
STAILQ
Colas de cola enlazadas simples. Una cola de cola es una lista enlazada simple que también mantiene un puntero al último elemento. Esto permite inserciones en la cola en tiempo O(1).
LIST
Listas doblemente enlazadas.
TAILQ
Colas de cola doblemente enlazadas. Una cola de cola es una lista doblemente enlazada que también mantiene un puntero al último elemento. Esto permite inserciones y eliminaciones en la cola en tiempo O(1).

Las macros para cada tipo de lista comparten una interfaz similar. Las macros `_CLASS_` son una variante que permite definir la estructura de la cabeza de la lista y la estructura de la entrada de la lista como tipos separados.

Macros SLIST

SLIST_EMPTY(head)
Devuelve verdadero (un valor distinto de cero) si la lista está vacía, falso (cero) en caso contrario.
SLIST_FIRST(head)
Devuelve un puntero al primer elemento de la lista, o NULL si la lista está vacía.
SLIST_NEXT(elm, field)
Devuelve un puntero al siguiente elemento después de elm en la lista, o NULL si elm es el último elemento. field es el nombre del miembro del puntero de enlace en la estructura del nodo.
SLIST_HEAD(name, type)
Define una estructura de cabeza de lista llamada name para elementos de tipo type.
SLIST_ENTRY(type)
Define una estructura de entrada de lista para elementos de tipo type.
SLIST_INIT(head)
Inicializa la lista especificada por head como una lista vacía.
SLIST_INSERT_HEAD(head, elm, field)
Inserta el elemento elmhead. field es el nombre del miembro del puntero de enlace en la estructura del nodo.
SLIST_INSERT_AFTER(listelm, elm, field)
Inserta el elemento elmlistelm en la lista. field es el nombre del miembro del puntero de enlace en la estructura del nodo.
SLIST_REMOVE(head, elm, type, field)
Elimina el elemento elmhead. type es el tipo de la estructura del nodo, y field es el nombre del miembro del puntero de enlace en la estructura del nodo.
SLIST_REMOVE_HEAD(head, field)
Elimina y devuelve el primer elemento de la lista especificada por head. field es el nombre del miembro del puntero de enlace en la estructura del nodo.
SLIST_REMOVE_AFTER(elm, field)
Elimina el elemento que sigue inmediatamente a elm de la lista. field es el nombre del miembro del puntero de enlace en la estructura del nodo.
SLIST_FOREACH(var, head, field)
Itera sobre cada elemento de la lista. var será un puntero al elemento actual en cada iteración. field es el nombre del miembro del puntero de enlace en la estructura del nodo.
SLIST_FOREACH_SAFE(var, head, field, var_temp)
Similar a SLIST_FOREACH, pero seguro para usar dentro de un bucle cuando los elementos pueden ser eliminados. var_temp se usa para almacenar temporalmente el siguiente elemento antes de que var
SLIST_FOREACH_FROM(var, head, field)
Similar a SLIST_FOREACH, pero comienza la iteración desde el elemento actual var.
SLIST_FOREACH_FROM_SAFE(var, head, field, var_temp)
Similar a SLIST_FOREACH_FROM, pero seguro para usar dentro de un bucle cuando los elementos pueden ser eliminados.
SLIST_SWAP(head1, head2, type)
Intercambia el contenido de las dos listas especificadas por head1 y head2. type es el tipo de la estructura de la cabeza de la lista.
SLIST_HEAD_INITIALIZER(head)
Una expresión constante que se puede usar para inicializar una cabeza de lista estáticamente.
SLIST_CONCAT(head1, head2, type, field)
Concatena la lista head2head1. La lista head2type es el tipo de la estructura del nodo, y field es el nombre del miembro del puntero de enlace en la estructura del nodo.
SLIST_CLASS_HEAD(name, type)
Similar a SLIST_HEAD, pero define una estructura de cabeza de lista separada llamada name y la asocia con el tipo de nodo type.
SLIST_CLASS_ENTRY(type)
Define una estructura de entrada de lista llamada type. Esto se usa en combinación con SLIST_CLASS_HEAD.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

typedef struct int_entry {{
int value;
SLIST_ENTRY(int_entry) next;
}} int_entry_t;

SLIST_HEAD(int_list_head, int_entry);

int main(void)
{{
struct int_list_head list;
int_entry_t *entry;
int_entry_t *tmp;

SLIST_INIT(&list);

/* Insertar algunos elementos */
entry = malloc(sizeof(*entry));
entry->value = 10;
SLIST_INSERT_HEAD(&list, entry, next);

entry = malloc(sizeof(*entry));
entry->value = 20;
SLIST_INSERT_HEAD(&list, entry, next);

/* Iterar sobre la lista */
printf("Lista: ");
SLIST_FOREACH_SAFE(entry, &list, next, tmp) {{
printf("%d ", entry->value);
/* Eliminar el elemento si su valor es 10 */
if (entry->value == 10) {{
SLIST_REMOVE(&list, entry, int_entry, next);
free(entry);
}}
}}
printf("\n");

/* Limpiar la memoria restante */
SLIST_FOREACH_SAFE(entry, &list, next, tmp) {{
SLIST_REMOVE(&list, entry, int_entry, next);
free(entry);
}}

return 0;
}}

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se van a enlazar en la lista. Un puntero al encabezado de la lista se puede declarar más tarde como:

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su momento a var.

NAME
     STAILQ_INSERT_AFTER, STAILQ_INSERT_BEFORE, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL
     - list queue macros

LIBRARY
     This is in the BSD compatibility library, see compat(7).

SYNOPSIS
     #include <sys/queue.h>

     void
     STAILQ_INSERT_AFTER(head, prev, elm);

     void
     STAILQ_INSERT_BEFORE(head, elm, next);

     void
     STAILQ_INSERT_HEAD(head, elm);

     void
     STAILQ_INSERT_TAIL(head, elm);

DESCRIPTION
     These macros are used to insert elements into a previously defined
     statically allocated or dynamically allocated singly linked list queue.
     The list is defined by the pointer head which points
     to a struct, in which the first member is a struct stqh_head.
     Elements are defined by struct, in which the first member is a struct
     stqh_entry.

     The macro STAILQ_INSERT_HEAD() inserts the element pointed to by
     elm at the head of the queue pointed to by head.

     The macro STAILQ_INSERT_TAIL() inserts the element pointed to by
     elm at the tail of the queue pointed to by head.

     The macro STAILQ_INSERT_AFTER() inserts the element pointed to by
     elm after the element pointed to by prev.
     The element pointed to by prev must be an element
     already in the queue.

     The macro STAILQ_INSERT_BEFORE() inserts the element pointed to by
     elm before the element pointed to by next.
     The element pointed to by next must be an element
     already in the queue.

SINGLY-LINKED LISTS
     Singly linked lists are doubly linked lists that have been stripped of
     their backward pointers. They are implemented using macros.

     The following macros are available for singly linked lists:

     STAILQ_CONCAT(head1, head2)
             Concatenates the list head2 to the end of the list
             head1. head2 becomes an empty list
             after the operation.

     STAILQ_EMPTY(head)
             Returns true if the list is empty and false otherwise.

     STAILQ_ENTRY(type)
             Declares a singly linked list entry structure of the specified
             type.

     STAILQ_FIRST(head)
             Returns the first element in the list.

     STAILQ_FOREACH(var, head)
             Iterates over all elements in the list. The element in the list
             isennzeichnet by var.

     STAILQ_FOREACH_SAFE(var, head, nextvar)
             Iterates over all elements in the list. The element in the list
             isennzeichnet by var. In each iteration,
             nextvar is set to the next element.

     STAILQ_INIT(head)
             Initializes the list pointed to by head.

     STAILQ_INSERT_AFTER(head, prev, elm)
             Inserts the element elm after the element
             prev.

     STAILQ_INSERT_BEFORE(head, elm, next)
             Inserts the element elm before the element
             next.

     STAILQ_INSERT_HEAD(head, elm)
             Inserts the element elm at the head of the
             list.

     STAILQ_INSERT_TAIL(head, elm)
             Inserts the element elm at the tail of the
             list.

             Returns the next element in the list.

             Removes the element elm from the list.

             Removes and returns the element at the head of the list.

             Removes and returns the element at the tail of the list.

DIAGNOSTICS

When debugging queue(3), it can be useful to trace queue changes. To enable tracing, define the macro QUEUE_MACRO_DEBUG_TRACE at compile time.

It can also be useful to trash pointers that have been unlinked from a queue, to detect use after removal. To enable pointer trashing, define the macro QUEUE_MACRO_DEBUG_TRASH at compile time. The macro QMD_IS_TRASHED(void *ptr) returns true if ptr has been trashed by the QUEUE_MACRO_DEBUG_TRASH option.
