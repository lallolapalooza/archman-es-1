Módulo Ephemeron
: (módulo Stdlib__Ephemeron)

Accesos no sincronizados

Los accesos no sincronizados a una tabla hash débil pueden conducir a un estado de tabla hash débil inválido. Por lo tanto, los accesos concurrentes a una tabla hash débil deben estar sincronizados (por ejemplo, con un Mutex.t ).

module type S = sig end

La firma de salida de los functores Ephemeron.K1.Make y Ephemeron.K2.Make . Estas tablas hash son débiles en las claves. Si todas las claves de una asociación están vivas, la asociación se mantiene, pero si alguna de las claves de la asociación está muerta, la asociación se elimina.

module type SeededS = sig end

La firma de salida de los functores Ephemeron.K1.MakeSeeded y Ephemeron.K2.MakeSeeded .

module K1 : sig end

Ephemerons con una clave.

module K2 : sig end

Ephemerons con dos claves.

module Kn : sig end

Ephemerons con un número arbitrario de claves del mismo tipo.
