Sustracción.

val mul : nativeint -> nativeint -> nativeint

Multiplicación.

val div : nativeint -> nativeint -> nativeint

División entera. Este tipo de división redondea el cociente real de sus argumentos hacia cero, como se especifica para el operador /.

Lanza Division_by_zero si el segundo argumento es cero.

val unsigned_div : nativeint -> nativeint -> nativeint

Mismo que Nativeint.div, pero los argumentos y el resultado se interpretan como enteros nativos no signados.

val rem : nativeint -> nativeint -> nativeint

Resto entero. Si y no es cero, el resultado de Nativeint.rem x y satisface las propiedades siguientes: Nativeint.zero <= Nativeint.rem x y < Nativeint.abs y y x = Nativeint.add (Nativeint.mul (Nativeint.div x y) y)
(Nativeint.rem x y) . Si y es cero, Nativeint.rem x y lanza Division_by_zero .

val unsigned_rem : nativeint -> nativeint -> nativeint

Mismo que Nativeint.rem, pero los argumentos y el resultado se interpretan como enteros nativos no signados.

Sin desde 4.08

val succ : nativeint -> nativeint

Sucesor. Nativeint.succ x es Nativeint.add x Nativeint.one .

val pred : nativeint -> nativeint

Predecessor. Nativeint.pred x es Nativeint.sub x Nativeint.one .

val abs : nativeint -> nativeint

abs x es el valor absoluto de x . En min_int esto es min_int mismo y por lo tanto sigue siendo negativo.

val size : int

La cantidad de bits en un entero nativo. Esto es igual a 32 en un sistema 32-bit y a 64 en un sistema 64-bit.

val max_int : nativeint

El entero nativo más grande, ya sea 2^31 - 1 en un sistema 32-bit, o 2^63 - 1 en un sistema 64-bit.

val min_int : nativeint

El entero nativo más pequeño, ya sea -2^31 en un sistema 32-bit, o -2^63 en un sistema 64-bit.

val logand : nativeint -> nativeint -> nativeint

AND lógico bit a bit.

val logor : nativeint -> nativeint -> nativeint

OR lógico bit a bit.

val logxor : nativeint -> nativeint -> nativeint

XOR lógico bit a bit.

val lognot : nativeint -> nativeint

Negación lógica bit a bit.

val shift_left : nativeint -> int -> nativeint

Nativeint.shift_left x y desplaza x a la izquierda en y bits. El resultado es indefinido si y < 0 o y >= bitsize , donde bitsize es 32 en un sistema 32-bit y 64 en un sistema 64-bit.

val shift_right : nativeint -> int -> nativeint

Nativeint.shift_right x y desplaza x a la derecha en y bits. Este es un desplazamiento aritmético: el bit de signo de x se replica y se inserta en los bits vacíos. El resultado es indefinido si y < 0 o y >= bitsize .

val shift_right_logical : nativeint -> int -> nativeint

Nativeint.shift_right_logical x y desplaza x a la derecha en y bits. Este es un desplazamiento lógico: ceros se insertan en los bits vacíos, independientemente del signo de x . El resultado es indefinido si y < 0 o y >= bitsize .

val of_int : int -> nativeint

Convierte el entero dado (tipo int) a un entero nativo (tipo nativeint).

val to_int : nativeint -> int

Convierte el entero dado (tipo nativeint) a un entero (tipo int ). El bit más significativo se pierde durante la conversión.

val unsigned_to_int : nativeint -> int option

Mismo que Nativeint.to_int, pero interpreta el argumento como un entero no signado. Devuelve None si el valor no signado del argumento no puede ajustarse a un int .

Sin desde 4.08

val of_float : float -> nativeint

Convierte el número flotante dado a un entero nativo, descartando la parte fraccionaria (redondear hacia cero). Si el número flotado truncado está fuera del rango [ Nativeint.min_int, Nativeint.max_int ], no se lanza excepción y se devuelve un entero no especificado, dependiendo de la plataforma.

val to_float : nativeint -> float

Convierte el entero dado a un número flotante.

val of_int32 : int32 -> nativeint

Convierte el entero dado (tipo int32) a un entero nativo.

val to_int32 : nativeint -> int32

Convierte el entero dado a un entero de 32 bits (tipo int32 ). En plataformas 64 bits, el entero nativo de 64 bits se toma módulo 2^32, es decir, se pierden los primeros 32 bits. En plataformas 32 bits, la conversión es exacta.

val of_string : string -> nativeint

Convierte la cadena dada a un entero nativo. La cadena se lee en decimal (por defecto, o si la cadena comienza con 0u ) o en hexadecimal, octal o binario si la cadena comienza con 0x, 0o o 0b respectivamente.

La prefija 0u lee el input como un entero no signado en el rango [0, 2*Nativeint.max_int+1] . Si el input excede Nativeint.max_int se convierte en el entero signado Int64.min_int + input - Nativeint.max_int - 1 .

Throws Failure si la cadena dada no es una representación válida de un entero o si el entero representado excede el rango de enteros representables en el tipo nativeint .

val of_string_opt : string -> nativeint option

Mismo que of_string, pero devuelve None en lugar de lanzar.

Sin desde 4.05

val to_string : nativeint -> string

Devuelve la representación en cadena de su argumento, en decimal.

type t = nativeint

Un alias para el tipo de enteros nativos.

val compare : t -> t -> int

La función de comparación para enteros nativos, con la misma especificación que compare . Además del tipo t , esta función compare permite pasar el módulo Nativeint como argumento a los funtores Set.Make y Map.Make .

val unsigned_compare : t -> t -> int

Mismo que Nativeint.compare , excepto que los argumentos se interpretan como enteros nativos no signados.
