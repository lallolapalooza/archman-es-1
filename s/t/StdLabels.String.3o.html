CADENAS

tipo t = string

El tipo para cadenas.

val make : int -> char -> string

make n c es una cadena de longitud n con cada índice conteniendo el carácter c.

Lanza Invalid_argument si n < 0 o n > Sys.max_string_length.

val init : int -> f:(int -> char) -> string

init n ~f es una cadena de longitud n con el índice i conteniendo el carácter f i (llamado en orden creciente de índice).

EXTRACCIÓN DE SUBSTRINGS

val sub : string -> pos:int -> len:int -> string

sub s ~pos ~len es una cadena de longitud len, conteniendo la subcadena de s que comienza en la posición pos y tiene longitud len.

Lanza Invalid_argument si pos y len no designan una subcadena válida de s.

val split_on_char : sep:char -> string -> string list

split_on_char ~sep s es la lista de todas las subcadenas (posiblemente vacías) de s que están delimitadas por el carácter sep. Si s está vacía, el resultado es la lista singleton [""].

El resultado de la función está especificado por los siguientes invariantes:

-La lista no está vacía.

-Concatenar sus elementos usando sep como separador devuelve una cadena igual a la entrada ( concat (make 1 sep)
(split_on_char sep s) = s ).

-Ninguna cadena en el resultado contiene el carácter sep.

Desde 4.00

val escaped : string -> string

escaped s es s con caracteres especiales representados por secuencias de escape, siguiendo las convenciones léxicas de OCaml.

Todos los caracteres fuera del rango imprimible US-ASCII [0x20;0x7E] son escapados, así como la barra invertida (0x2F) y la comilla doble (0x22).

La función Scanf.unescaped es un inverso izquierdo de escaped, es decir, Scanf.unescaped (escaped s) = s para cualquier cadena s (a menos que escaped s falle).

Lanza Invalid_argument si el resultado es más largo que Sys.max_string_length bytes.

Corrección ortográfica

val edit_distance : ?limit:int -> t -> t -> int

edit_distance s0 s1 es el número de ediciones de un solo carácter (entendidas como inserción, eliminación, sustitución, transposición) que se necesitan para cambiar s0 por s1 .

Si se proporciona limit , la función devuelve limit tan pronto como se determina que s0 y s1 tienen una distancia de al menos limit . Esto es más rápido si tienes un límite fijo, por ejemplo para la corrección ortográfica.

La función asume que las cadenas están codificadas en UTF-8 y utiliza Uchar.t para la noción de carácter. Los errores de decodificación se reemplazan por Uchar.rep . Normalizar las cadenas a NFC da mejores resultados.

Nota. Esto implementa la distancia más simple de Alineación Óptima de Cadenas (OSA), no la distancia Damerau-Levenshtein. Con esta función "ca" y "abc" tienen una distancia de 3 y no de 2.

Desde 5.4

val spellcheck : ?max_dist:(string -> int) -> ((string -> unit) -> unit) -> string -> string list

spellcheck iter_dict s son las cadenas enumeradas por el iterador iter_dict cuya StringLabels.edit_distance a s es la más pequeña y no supera max_dist s . Si se devuelven múltiples correcciones, su orden es el encontrado en iter_dict . El valor predeterminado de max_dist s es:

- 0 si s tiene de 0 a 2 caracteres Unicode.

- 1 si s tiene de 3 a 4 caracteres Unicode.

- 2 en caso contrario.

Si tu diccionario es una lista l , un iter_dict adecuado se da por (fun yield -> List.iter yield l) .

Se asume que todas las cadenas están codificadas en UTF-8, los errores de decodificación se reemplazan por caracteres Uchar.rep .

Decodificación binaria de enteros

Las funciones de esta sección decodifican binariamente enteros de cadenas.

Todas las funciones siguientes lanzan Invalid_argument si los caracteres necesarios en el índice i para decodificar el entero no están disponibles.

La codificación little-endian (respectivamente big-endian) significa que los bytes menos (respectivamente más) significativos se almacenan primero. Big-endian también se conoce como orden de bytes de red. La codificación native-endian es little-endian o big-endian dependiendo de Sys.big_endian .

Los enteros de 32 y 64 bits se representan con los tipos int32 y int64 , que pueden interpretarse como números con signo o sin signo.

Los enteros de 8 y 16 bits se representan con el tipo int , que tiene más bits que la codificación binaria. Estos bits extra se extienden con signo (o se extienden con ceros) para las funciones que decodifican enteros de 8 o 16 bits y los representan con valores int .
