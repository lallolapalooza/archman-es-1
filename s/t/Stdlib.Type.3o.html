Testigo de igualdad de tipos

type (_, _) eq =
| Equal : ('a, 'a) eq

El propósito de eq es representar igualdades de tipos que quizás no sean conocidas por el verificador de tipos (por ejemplo, porque pueden depender de datos dinámicos).

Un valor de tipo (a, b) eq representa el hecho de que los tipos a y b son iguales.

Si uno tiene un valor eq : (a, b) Type.eq que demuestra que los tipos a y b son iguales, puede usarlo para convertir un valor de tipo a a un valor de tipo b mediante coincidencia de patrones en Equal:

      let cast (type a) (type b) (Equal : (a, b) Type.eq) (a : a) : b = a

En tiempo de ejecución, esta función simplemente devuelve su segundo argumento sin cambios.

Identificadores de tipos

module Id : sig end

Identificadores de tipos.

Un identificador de tipo es un valor que denota un tipo. Dados dos identificadores de tipos, se pueden comparar para Type.Id.provably_equal para demostrar que denotan el mismo tipo. Tenga en cuenta que:

-Identificadores desiguales no implican tipos desiguales: un tipo dado puede ser denotado por más de un identificador.

-Los identificadores de tipos se pueden serializar (marshal), pero obtienen una identidad nueva y distinta al deserializarlos (unmarshal), por lo que las igualdades se pierden.

Ver un Type.Id.example de uso.
