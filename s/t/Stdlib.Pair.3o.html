Pares

tipo ('a, 'b) t = 'a * 'b

El tipo para pares.

valor make : 'a -> 'b -> 'a * 'b

make a b es el par (a, b).

valor fst : 'a * 'b -> 'a

fst (a, b) es a.

valor snd : 'a * 'b -> 'b

snd (a, b) es b.

valor swap : 'a * 'b -> 'b * 'a

swap (a, b) es (b, a).

Iteradores

valor fold : ('a -> 'b -> 'c) -> 'a * 'b -> 'c

fold f (a, b) aplica f a a y b.

valor map : ('a -> 'c) -> ('b -> 'd) -> 'a * 'b -> 'c * 'd

map f g (a, b) aplica f a a y g a b.

valor iter : ('a -> unit) -> ('b -> unit) -> 'a * 'b -> unit

iter f g (a, b) primero aplica f a a, y luego g a b.

valor map_fst : ('a -> 'c) -> 'a * 'b -> 'c * 'b

map_fst f p aplica f al primer componente de p.

valor map_snd : ('b -> 'c) -> 'a * 'b -> 'a * 'c

map_snd f p aplica f al segundo componente de p.

Predicados y comparaciones

valor equal : ('a -> 'a -> bool) -> ('b -> 'b -> bool) -> 'a * 'b -> 'a * 'b -> bool

equal eqa eqb (a1, b1) (a2, b2) es true si y solo si eqa a1 a2 y eqb b1 b2 son ambos true.

valor compare : ('a -> 'a -> int) -> ('b -> 'b -> int) -> 'a * 'b -> 'a * 'b -> int

compare cmpa cmpb es un orden total en pares usando cmpa para comparar el primer componente y cmpb para comparar el segundo componente. Se implementa mediante un orden lexicográfico.
