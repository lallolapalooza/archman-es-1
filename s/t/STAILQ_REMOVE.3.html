STAILQ(3) Manual de Funciones de Biblioteca STAILQ(3)

NOMBRE

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - implementación de una cola con enlaces simples y terminador

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
STAILQ_ENTRY(TIPO);
STAILQ_HEAD(NOMBRE_CABECERA, TIPO);
STAILQ_HEAD NOMBRE_CABECERA STAILQ_HEAD_INITIALIZER(STAILQ_HEAD cabecera);
void STAILQ_INIT(STAILQ_HEAD *cabecera);
int STAILQ_EMPTY(STAILQ_HEAD *cabecera);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *cabecera,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *cabecera,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *cabecera, struct TIPO *elemento_lista,
                         struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
struct TIPO *STAILQ_FIRST(STAILQ_HEAD *cabecera);
struct TIPO *STAILQ_NEXT(struct TIPO *elemento, STAILQ_ENTRY NOMBRE);
STAILQ_FOREACH(struct TIPO *variable, STAILQ_HEAD *cabecera, STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE(STAILQ_HEAD *cabecera, struct TIPO *elemento, TIPO,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *cabecera,
                         STAILQ_ENTRY NOMBRE);
void STAILQ_CONCAT(STAILQ_HEAD *cabecera1, STAILQ_HEAD *cabecera2);

Nota: Existen macros idénticos prefijados con SIMPLEQ en lugar de STAILQ; véase VERSIONS.

DESCRIPCIÓN

Estas macros definen y operan sobre colas con enlaces simples y terminador.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo STAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro STAILQ_HEAD().

Creación

Una cola con enlaces simples y terminador está encabezada por una estructura definida por la macro STAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara como sigue:


STAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura que se va a definir, y struct TIPO es el tipo de los elementos que se van a enlazar en la cola. Posteriormente, se puede declarar un puntero a la cabecera de la cola como:


struct NOMBRE_CABECERA *puntero_cabecera;

(Los nombres cabecera y puntero_cabecera son seleccionables por el usuario.)

STAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

STAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola cabecera.

STAILQ_INIT() inicializa la cola referenciada por cabecera.

STAILQ_EMPTY() evalúa a verdadero si no hay elementos en la cola.

Inserción

STAILQ_INSERT_HEAD() inserta el nuevo elemento elemento al principio de la cola.

STAILQ_INSERT_TAIL() inserta el nuevo elemento elemento al final de la cola.

STAILQ_INSERT_AFTER() inserta el nuevo elemento elemento después del elemento elemento_lista.

Recorrido

STAILQ_FIRST() devuelve el primer elemento de la cola o NULL si la cola está vacía.

STAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

STAILQ_FOREACH() recorre la cola referenciada por cabecera en dirección hacia adelante, asignando cada elemento en turno a variable.

Eliminación

STAILQ_REMOVE() elimina el elemento elemento de la cola.

STAILQ_REMOVE_HEAD() elimina el elemento al principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deben usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE().

Otras características

STAILQ_CONCAT() concatena la cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

STAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía y cero si la cola contiene al menos una entrada.

STAILQ_FIRST() y STAILQ_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

STAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cola cabecera.

VERSIÓNES

Algunos BSD proporcionan SIMPLEQ en lugar de STAILQ. Son idénticos, pero por razones históricas se les dio nombres diferentes en diferentes BSD. STAILQ se originó en FreeBSD, y SIMPLEQ se originó en NetBSD. Por razones de compatibilidad, algunos sistemas proporcionan ambos conjuntos de macros. glibc proporciona tanto STAILQ como SIMPLEQ, que son idénticos excepto por la ausencia de un equivalente SIMPLEQ a STAILQ_CONCAT().

ERRORES

STAILQ_FOREACH() no permite que variable sea eliminada o liberada dentro del bucle, ya que interferiría con el recorrido. STAILQ_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que variable sea eliminada de forma segura de la lista y liberada desde dentro del bucle sin interferir con el recorrido.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    STAILQ_ENTRY(entrada) entradas;        /* Cola con enlaces simples y terminador */
};
STAILQ_HEAD(cabecera_simple, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabecera_simple cabeza;                  /* Cabecera de cola con enlaces
                                               simples y terminador */
    STAILQ_INIT(&cabeza);                     /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    STAILQ_INSERT_TAIL(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    STAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);
    STAILQ_REMOVE(&cabeza, n2, entrada, entradas); /* Eliminación */
    free(n2);
    n3 = STAILQ_FIRST(&cabeza);
    STAILQ_REMOVE_HEAD(&cabeza, entradas);     /* Eliminación desde el principio */
    free(n3);
    n1 = STAILQ_FIRST(&cabeza);
    n1->datos = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entrada));
        STAILQ_INSERT_HEAD(&cabeza, n1, entradas);
        n1->datos = i;
    }

STAILQ_REMOVE(3bsd) — Linux man pages

NAME

STAILQ_REMOVE, STAILQ_REMOVE_TAIL, STAILQ_REMOVE_HEAD, STAILQ_REMOVE_AT - remove list entries from doubly-linked list

LIBRARY

libbsd

SYNOPSIS

#include <sys/queue.h>

STAILQ_REMOVE(head, elm, type, field);

STAILQ_REMOVE_TAIL(head, elm, type, field);

STAILQ_REMOVE_HEAD(head, type);

STAILQ_REMOVE_AT(head, elm, type, field);

DESCRIPTION

The STAILQ_REMOVE macros are used to remove entries from a singly linked tail queue. A tail queue is a singly linked list where the tailq_head structure is guaranteed to point to the first element and a NULL pointer is guaranteed to terminate the list. The tailq_tail pointer points to the last element.

A singly linked tail queue is declared using the macro:

STAILQ_HEAD(typename, typename);

where the first typename is the name of the structure that will be used to hold the queue head, and the second typename is the name of the structure that represents the elements in the queue.

Each element in the queue must be a structure that contains a field of type struct stailq_entry. This structure is declared using the macro:

STAILQ_ENTRY(typename);

The macro STAILQ_REMOVE removes the element elm from the queue pointed to by head. The type of the element is specified by type and the name of the entry field within the element is specified by field.

The macro STAILQ_REMOVE_TAIL removes the last element from the queue pointed to by head. The type of the element is specified by type and the name of the entry field within the element is specified by field.

The macro STAILQ_REMOVE_HEAD removes the first element from the queue pointed to by head. The type of the element is specified by type.

The macro STAILQ_REMOVE_AT removes the element elm from the queue pointed to by head. This macro is equivalent to STAILQ_REMOVE. It is provided for compatibility with other list manipulation macros.

The pointers np, n1, and n2 are pointers to the element type type.

RETURN VALUE

None.

VERSIONS

These macros are available in libbsd.

BUGS

None.

STANDARDS

These macros are derived from BSD operating systems.

HISTORY

The tail queue macros first appeared in 3.2BSD.

EXAMPLES

The following example demonstrates how to remove the first element from a tail queue, print its data, and then free the memory.

struct my_head {
    STAILQ_HEAD_ENTRY(my_head) entries;
    int data;
};

struct my_head head;
struct my_head *np, *n1, *n2;

STAILQ_INIT(&head);

/* Add some elements to the queue */
np = malloc(sizeof(*np));
np->data = 1;
STAILQ_INSERT_TAIL(&head, np, entries);
np = malloc(sizeof(*np));
np->data = 2;
STAILQ_INSERT_TAIL(&head, np, entries);

/* Forward traversal */
STAILQ_FOREACH(np, &head, entries)
    printf("%i\n", np->data);
/* TailQ deletion */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
    n2 = STAILQ_NEXT(n1, entries);
    free(n1);
    n1 = n2;
}
STAILQ_INIT(&head);
exit(EXIT_SUCCESS);
}
