DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser utilizadas tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simples
  3. Colas de cola enlazadas simples
  4. Colas de cola
Las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de una nueva entrada al principio de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento en la lista.
  3. Eliminación en O(1) de una entrada desde el principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más sencillas de las cuatro estructuras de datos y solo soportan la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO. Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación en O(n) de cualquier entrada en la lista.
  2. Concatenación en O(n) de dos listas.

Las colas de cola enlazadas simples añaden la siguiente funcionalidad:

  1. Las entradas pueden ser añadidas al final de una lista.
  2. Eliminación en O(n) de cualquier entrada en la lista.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones en la lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lento que en las listas enlazadas simples.

Las colas de cola enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO.

Todas las estructuras de datos de tipos enlazados doblemente (listas y colas de cola) permiten adicionalmente:

  1. Inserción de una nueva entrada antes de cualquier elemento en la lista.
  2. Eliminación en O(1) de cualquier entrada en la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que el de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más sencillas de las estructuras de datos enlazadas doblemente. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación en O(n) de dos listas.
  2. Pueden ser recorridas hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para comenzar el recorrido y la lista en la que está contenida.

Las colas de cola añaden la siguiente funcionalidad:

  1. Las entradas pueden ser añadidas al final de una lista.
  2. Pueden ser recorridas hacia atrás, de cola a cabeza.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de listas deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lento que en las listas enlazadas simples.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que es de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que es de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe ser declarada usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, o TAILQ_CLASS_HEAD. Vea los ejemplos a continuación para más explicación sobre cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación en O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista puede ser declarado más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. El uso de esta macro debe evitarse ya que recorre la totalidad de la lista head1. Se debe usar una cola de cola enlazada simple si se necesita esta macro en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_EMPTY se evalúa como true si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de SLIST_FOREACH() aquí está permitido tanto remover var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento

COLAS ENLAZADAS SIMPLES

Una cola enlazada simple se encabeza mediante una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un puntero al primer elemento de la cola. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación de O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola después de un elemento existente o al principio de la cola. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a enlazar en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la cola head.

La macro SLIST_CONCAT concatena la cola encabezada por head2 al final de la encabezada por head1 eliminando todas las entradas de la primera.

La macro SLIST_EMPTY se evalúa como verdadera si no hay elementos en la cola.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la cola.

La macro SLIST_FIRST devuelve el primer elemento de la cola o NULL si la cola está vacía.

La macro SLIST_FOREACH recorre la cola referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro SLIST_FOREACH_SAFE recorre la cola referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de SLIST_FOREACH, aquí está permitido eliminar var así como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_INIT inicializa la cola referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento en la cola.

La macro SLIST_REMOVE_AFTER elimina el elemento después de elm de la cola. A diferencia de SLIST_REMOVE, esta macro no recorre la cola entera.

La macro SLIST_REMOVE_HEAD elimina el elemento elm del principio de la cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola deberían usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la cola. Debe evitarse el uso de esta macro, ya que recorre la cola entera. Se debería usar una cola doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE COLA ENLAZADA SIMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Cabeza de cola enlazada simple. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Cola enlazada simple. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Inicializa la cola. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación del principio. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Eliminación de la cola. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

COLAS DE EXTREMO ENLAZADAS SIMPLES

Una cola de extremo enlazada simple se encabeza mediante una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de extremo y el otro al último elemento de la cola de extremo. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación de O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola de extremo después de un elemento existente, al principio de la cola de extremo, o al final de la cola de extremo. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a enlazar en la cola de extremo. Un puntero a la cabeza de la cola de extremo se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola de extremo head.

La macro STAILQ_CONCAT concatena la cola de extremo encabezada por head2 al final de la encabezada por head1 eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY se evalúa como verdadera si no hay elementos en la cola de extremo.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola de extremo.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de extremo o NULL si la cola de extremo está vacía.

La macro STAILQ_FOREACH recorre la cola de extremo referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de extremo referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de STAILQ_FOREACH() aquí está permitido tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola de extremo referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de extremo.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de extremo.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de extremo. Si la cola de extremo está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de extremo, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola de extremo. A diferencia de STAILQ_REMOVE, esta macro no recorre la cola de extremo entera.

La macro STAILQ_REMOVE_HEAD elimina el elemento al principio de la cola de extremo. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola de extremo deberían usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola de extremo. Debe evitarse el uso de esta macro, ya que recorre la cola entera. Se debería usar una cola de extremo doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas de extremo largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Cabeza de cola de extremo enlazada simple. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Cola de extremo. */
	...

n1 = malloc(sizeof(struct entry));	/* Inserta al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminación. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminación desde el principio. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);

n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}

LISTS

A list is headed by a structure defined by the LIST_HEAD macro. This structure contains a pointer to the first element in the list. The elements are doubly linked so that an arbitrary element can be removed without traversing the list. New elements can be added to the list after an existing element, or before an existing element. A LIST_HEAD structure is declared as follows:

LIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro LIST_SWAP swaps the contents of head1 and head2.

The macro LIST_EMPTY evaluates to true if there are no items on the list.

The macro LIST_ENTRY declares a structure that connects the elements in the list.

The macro LIST_FIRST returns the first item on the list or NULL if the list is empty.

The macro LIST_NEXT returns the next element in the list, or NULL if this is the last.

The macro LIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro LIST_FOREACH_FROM behaves identically to LIST_FOREACH when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike LIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro LIST_FOREACH_FROM_SAFE behaves identically to LIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_INIT initializes the list referenced by head.

The macro LIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro LIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro LIST_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro LIST_NEXT returns the next element in the list, or NULL if this is the last.

The macro LIST_PREV returns the previous element in the list, or NULL if this is the first. List head must contain element elm.

The macro LIST_REMOVE removes the element elm from the list.

The macro LIST_SWAP swaps the contents of head1 and head2.

    LIST_HEAD_INITIALIZER(head);

struct entry {
	...
	LIST_ENTRY(entry) entries;	/* List. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insert before. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Deletion. */
free(n2);
					/* Forward traversal. */
LIST_FOREACH(np, &head, entries)
	np-> ...

	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);

	n1 = LIST_FIRST(&head);

	free(n1);

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are doubly linked so that an arbitrary element can be removed without traversing the tail queue. New elements can be added to the tail queue after an existing element, before an existing element, at the head of the tail queue, or at the end of the tail queue. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro TAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro TAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro TAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro TAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro TAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. var is set to NULL if the loop completes normally, or if there were no elements.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE traverses the tail queue referenced by head in the reverse direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_REVERSE_FROM behaves identically to TAILQ_FOREACH_REVERSE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macros TAILQ_FOREACH_SAFE and TAILQ_FOREACH_REVERSE_SAFE traverse the list referenced by head in the forward or reverse direction respectively, assigning each element in turn to var. However, unlike their unsafe counterparts, TAILQ_FOREACH and TAILQ_FOREACH_REVERSE make it possible to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE_FROM_SAFE behaves identically to TAILQ_FOREACH_REVERSE_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macro TAILQ_INIT initializes the tail queue referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro TAILQ_NEXT returns the next item on the tail queue, or NULL if this item is the last.

The macro TAILQ_PREV returns the previous item on the tail queue, or NULL if this item is the first.

The macro TAILQ_REMOVE removes the element elm from the tail queue.

The macro TAILQ_SWAP swaps the contents of head1 and head2.
