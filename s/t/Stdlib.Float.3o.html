val fma : float -> float -> float -> float

fma x y z devuelve x * y + z, con el mejor esfuerzo para calcular esta expresión con un solo redondeo, utilizando instrucciones de hardware (proporcionando cumplimiento total de IEEE) o una emulación de software.

En Cygwin de 64 bits, mingw-w64 de 64 bits y MSVC 2017 y anteriores, esta función puede ser emulada debido a errores o limitaciones conocidas en estas plataformas. Nota: dado que la emulación por software de fma es costosa, asegúrese de que está utilizando soporte de hardware para fma si el rendimiento es importante.

val nan : float

Un valor flotante especial que denota el resultado de una operación indefinida como 0.0 /. 0.0. Significa 'not a number' (no es un número). Cualquier operación de punto flotante con nan como argumento devuelve nan como resultado, a menos que se especifique lo contrario en el estándar IEEE 754. En cuanto a las comparaciones de punto flotante, =, <, <=, > y >= devuelven false y <> devuelve true si uno o ambos de sus argumentos es nan.

nan es quiet_nan desde 5.1; antes era un NaN de señalización.

val of_string : string -> float

Convierte la cadena dada a un float. La cadena se lee en decimal (por defecto) o en hexadecimal (marcada por 0x o 0X). El formato de los números flotantes decimales es [-] dd.ddd (e|E) [+|-] dd, donde d representa un dígito decimal. El formato de los números flotantes hexadecimales es [-] 0(x|X) hh.hhh (p|P) [+|-] dd, donde h representa un dígito hexadecimal y d un dígito decimal. En ambos casos, se debe proporcionar al menos una de las partes enteras y fraccionarias; la parte del exponente es opcional. El carácter _ (guion bajo) puede aparecer en cualquier lugar de la cadena y se ignora. Dependiendo de las plataformas de ejecución, se pueden aceptar otras representaciones de números flotantes, pero no se debe confiar en ellas.

Genera Failure si la cadena dada no es una representación válida de un float.

val of_string_opt : string -> float option

Igual que of_string, pero devuelve None en lugar de generar una excepción.

val to_string : float -> string

Devuelve una representación en cadena de un número de punto flotante.

Esta conversión puede implicar una pérdida de precisión. Para un mayor control sobre la forma en que se imprime el número, consulte Printf.

Esta función es un alias de string_of_float.

NAME

Float - Standard floating-point numbers.

Module

Float

Documentation

This module provides functions for manipulating standard IEEE floating-point numbers.

The functions for trigonometric, hyperbolic, and logarithmic calculations expect their arguments to be in radians.

val cos : float -> float

Coseno. El argumento está en radianes.

val sin : float -> float

Seno. El argumento está en radianes.

val tan : float -> float

Tangente. El argumento está en radianes.

val acos : float -> float

Arcocoseno. El argumento debe caer dentro del rango [-1.0, 1.0]. El resultado está en radianes y está entre 0.0 y pi .

val asin : float -> float

Arcoseno. El argumento debe caer dentro del rango [-1.0, 1.0]. El resultado está en radianes y está entre -pi/2 y pi/2 .

val atan : float -> float

Arcotangente. El resultado está en radianes y está entre -pi/2 y pi/2.

val atan2 : float -> float -> float

atan2 y x devuelve el arcotangente de y /. x. Los signos de x e y se utilizan para determinar el cuadrante del resultado. El resultado está en radianes y está entre -pi y pi.

val hypot : float -> float -> float

hypot x y devuelve sqrt(x *. x +. y *. y), es decir, la longitud de la hipotenusa de un triángulo rectángulo con lados de longitud x e y, o, equivalentemente, la distancia del punto (x,y) al origen. Si uno de x o y es infinito, devuelve infinity incluso si el otro es nan.

val cosh : float -> float

Coseno hiperbólico. El argumento está en radianes.

val sinh : float -> float

Seno hiperbólico. El argumento está en radianes.

val tanh : float -> float

Tangente hiperbólica. El argumento está en radianes.

val acosh : float -> float

Arcocoseno hiperbólico. El argumento debe caer dentro del rango [1.0, inf]. El resultado está en radianes y está entre 0.0 y inf.

Since 4.13

val asinh : float -> float

val atanh : float -> float

Arcotangente hiperbólica. El argumento debe caer dentro del rango [-1.0, 1.0]. El resultado está en radianes y abarca toda la línea real.

Since 4.13

val erfc : float -> float

Función de error complementaria ( erfc x = 1 - erf x ). El argumento abarca toda la línea real. El resultado siempre está dentro de [0.0, 2.0].

Since 4.13

val trunc : float -> float

trunc x redondea x al entero más cercano cuyo valor absoluto es menor o igual que x.

Since 4.08

val round : float -> float

round x redondea x al entero más cercano, con los empates (valores fraccionarios de 0.5) redondeados lejos de cero, independientemente de la dirección de redondeo actual. Si x es un entero, +0., -0., nan, o infinito, se devuelve x mismo.

En mingw-w64 de 64 bits, esta función puede ser emulada debido a un error en la biblioteca de tiempo de ejecución C (CRT) en esta plataforma.

Since 4.08

val ceil : float -> float

Redondea hacia arriba a un valor entero. ceil f devuelve el menor valor entero mayor o igual que f. El resultado se devuelve como un float.

val floor : float -> float

Redondea hacia abajo a un valor entero. floor f devuelve el mayor valor entero menor o igual que f. El resultado se devuelve como un float.

val next_after : float -> float -> float

next_after x y devuelve el siguiente valor de punto flotante representable después de x en la dirección de y. Más precisamente, si y es mayor (respectivamente, menor) que x, devuelve el menor (respectivamente, mayor) número representable mayor (respectivamente, menor) que x. Si x es igual a y, la función devuelve y. Si x o y es nan, se devuelve un nan. Tenga en cuenta que next_after max_float infinity = infinity y que next_after 0. infinity es el número denormalizado positivo más pequeño. Si x es el número denormalizado positivo más pequeño, next_after x 0. = 0.

Since 4.08

val copy_sign : float -> float -> float

copy_sign x y devuelve un float cuyo valor absoluto es el de x y cuyo signo es el de y. Si x es nan, devuelve nan. Si y es nan, devuelve x o -. x, pero no se especifica cuál.

val sign_bit : float -> bool

sign_bit x es true si y solo si el bit de signo de x está establecido. Por ejemplo, sign_bit 1. y signbit 0. son false mientras que sign_bit (-1.) y sign_bit (-0.) son true.

Since 4.08

val frexp : float -> float * int

frexp f devuelve el par de la mantisa y el exponente de f. Cuando f es cero, la mantisa x y el exponente n de f son iguales a cero. Cuando f no es cero, se definen por f = x *. 2 ** n y 0.5 <= x < 1.0.

val ldexp : float -> int -> float

ldexp x n devuelve x *. 2 ** n.

val modf : float -> float * float

modf f devuelve el par de la parte fraccionaria y la parte entera de f.

type t = float

Un alias para el tipo de números de punto flotante.

val compare : t -> t -> int

compare x y devuelve 0 si x es igual a y, un entero negativo si x es menor que y, y un entero positivo si x es mayor que y. compare trata nan como igual a sí mismo y menor que cualquier otro valor float. Este tratamiento de nan asegura que compare define una relación de orden total.

val equal : t -> t -> bool

La función de igualdad para números de punto flotante, comparada usando Float.compare.

val min : t -> t -> t

min x y devuelve el mínimo de x e y. Devuelve nan cuando x o y es nan. Además, min (-0.) (+0.) = -0.

Since 4.08

val max : float -> float -> float

max x y devuelve el máximo de x e y. Devuelve nan cuando x o y es nan. Además, max (-0.) (+0.) = +0.

Since 4.08

val min_max : float -> float -> float * float

min_max x y es (min x y, max x y), solo que más eficiente.

Since 4.08

val min_num : t -> t -> t

min_num x y devuelve el mínimo de x e y tratando nan como valores faltantes. Si ambos x e y son nan, se devuelve nan. Además, min_num (-0.) (+0.) = -0.

Since 4.08

val max_num : t -> t -> t

max_num x y devuelve el máximo de x e y tratando nan como valores faltantes. Si ambos x e y son nan, se devuelve nan. Además, max_num (-0.) (+0.) = +0.

Since 4.08

val min_max_num : float -> float -> float * float

min_max_num x y es (min_num x y, max_num x y), solo que más eficiente. Tenga en cuenta que en particular min_max_num x nan = (x, x) y min_max_num nan y = (y, y).

Since 4.08

Una función hash sembrada para floats, con el mismo valor de salida que Hashtbl.seeded_hash. Esta función permite pasar este módulo como argumento al funtor Hashtbl.MakeSeeded.
