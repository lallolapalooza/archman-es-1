StackTrace::Auto(3) Documentación de Perl contribuida por el usuario StackTrace::Auto(3)

NOMBRE

StackTrace::Auto - un rol para generar trazas de pila durante la instanciación

VERSIÓN

versión 1.001

SINOPSIS

Primero, incluye StackTrace::Auto en un Moose o Mooclass...

package Some::Class;
# NOTA: Moo también se puede usar aquí en lugar de Moose
use Moose;
with 'StackTrace::Auto';

...luego crea un objeto de esa clase...

my $obj = Some::Class->new;

...y ahora tienes una traza de pila para la creación del objeto.

print $obj->stack_trace->as_string;

VERSIÓN PERL

Esta biblioteca debería funcionar en versiones de Perl lanzadas hace mucho tiempo. Debería funcionar en cualquier versión de Perl lanzada en los últimos cinco años.

Aunque puede funcionar en versiones antiguas de Perl, no se garantiza que la versión mínima requerida no aumente. La versión puede aumentar por cualquier motivo, y no hay promesa de que se acepten parches para disminuir la versión mínima requerida de Perl.

ATRIBUTOS

stack_trace

Este atributo contendrá un objeto que representa la pila en el momento en que se generó y lanzó el error. Debe ser un objeto que realice el método "as_string".

stack_trace_class

Este atributo puede proporcionarse para usar una clase alternativa para las trazas de pila. El valor predeterminado es Devel::StackTrace.

En general, no necesitarás pensar en este atributo.

stack_trace_args

Este atributo es un arrayref de argumentos para pasar al construir la traza de pila. En general, no necesitarás pensar en él.
