DOCUMENTACIÓN

Módulo Stdlib
: sig end

La biblioteca estándar de OCaml.

Este módulo se abre automáticamente al principio de cada compilación. Por lo tanto, todos los componentes de este módulo pueden ser referenciados por su nombre corto, sin prefijarlos con Stdlib.

En particular, proporciona las operaciones básicas sobre los tipos incorporados (números, booleanos, secuencias de bytes, cadenas, excepciones, referencias, listas, arreglos, canales de entrada/salida, ...) y los módulos.

La excepción Exit no es lanzada por ninguna función de la biblioteca. Se proporciona para su uso en sus programas.

exception Match_failure de (string * int * int)

Excepción lanzada cuando ningún caso de coincidencia de patrones aplica. Los argumentos son la ubicación de la palabra clave `match` en el código fuente (nombre del archivo, número de línea, número de columna).

exception Assert_failure de (string * int * int)

Excepción lanzada cuando una aserción falla. Los argumentos son la ubicación de la palabra clave `assert` en el código fuente (nombre del archivo, número de línea, número de columna).

exception Invalid_argument de string

Excepción lanzada por las funciones de la biblioteca para indicar que los argumentos proporcionados no tienen sentido. La cadena proporciona información al programador. Como regla general, esta excepción no debe ser capturada, denota un error de programación y el código debe modificarse para evitar que se active.

exception Failure de string

Excepción lanzada por las funciones de la biblioteca para indicar que están indefinidas para los argumentos dados. La cadena está destinada a proporcionar información al programador; no debe buscar coincidencias con literales de cadena porque pueden cambiar en versiones futuras (use `Failure _` en su lugar).

exception Not_found

Excepción lanzada por las funciones de búsqueda cuando el objeto deseado no se pudo encontrar.

exception Out_of_memory

Excepción lanzada por el recolector de basura cuando no hay memoria suficiente para completar el cálculo. (No es fiable para las asignaciones en el heap menor).

exception Stack_overflow

Excepción lanzada por el intérprete de bytecode cuando la pila de evaluación alcanza su tamaño máximo. Esto a menudo indica una recursión infinita o excesivamente profunda en el programa del usuario.

Antes de 4.10, no estaba completamente implementado por el compilador de código nativo.

exception Sys_error de string

Excepción lanzada por las funciones de entrada/salida para informar un error del sistema operativo. La cadena está destinada a proporcionar información al programador; no debe buscar coincidencias con literales de cadena porque pueden cambiar en versiones futuras (use `Sys_error _` en su lugar).

exception End_of_file

Excepción lanzada por las funciones de entrada para señalar que se ha alcanzado el final del archivo.

exception Division_by_zero

Excepción lanzada por las operaciones de división y resto enteras cuando su segundo argumento es cero.

exception Sys_blocked_io

Un caso especial de `Sys_error` lanzado cuando no se puede realizar E/S en un canal de E/S no bloqueante.

exception Undefined_recursive_module de (string * int * int)

Excepción lanzada cuando se evalúa una definición de módulo recursivo mal fundada. Los argumentos son la ubicación de la definición en el código fuente (nombre del archivo, número de línea, número de columna).

Aritmética de punto flotante

Los números de punto flotante de OCaml siguen el estándar IEEE 754, utilizando números de precisión doble (64 bits). Las operaciones de punto flotante nunca elevan una excepción por desbordamiento, subdesbordamiento, división por cero, etc. En su lugar, se devuelven números IEEE especiales según corresponda, como infinity para 1.0 /. 0.0, neg_infinity para -1.0 /. 0.0, y nan ('not a number') para 0.0 /. 0.0. Estos números especiales se propagan a través de los cálculos de punto flotante como se espera: por ejemplo, 1.0 /. infinity es 0.0, las operaciones aritméticas básicas (+., -., *., /.) con nan como argumento devuelven nan, ...

val nan : float

Un valor especial de punto flotante que denota el resultado de una operación indefinida como 0.0 /. 0.0 . Significa 'no es un número' (not a number). Cualquier operación de punto flotante con nan como argumento devuelve nan como resultado, a menos que se especifique lo contrario en el estándar IEEE 754. En cuanto a las comparaciones de punto flotante, = , < , <= , > y >= devuelven false y <> devuelve true si uno o ambos de sus argumentos es nan .

nan es un NaN silencioso desde la versión 5.1; era un NaN de señalización antes.

val string_of_int : int -> string

Devuelve la representación en cadena de un entero, en decimal.

val int_of_string_opt : string -> int option

Convierte la cadena dada a un entero. La cadena se lee en decimal (por defecto, o si la cadena comienza con 0u ), en hexadecimal (si comienza con 0x o 0X ), en octal (si comienza con 0o o 0O ), o en binario (si comienza con 0b o 0B ).

El prefijo 0u lee la entrada como un entero sin signo en el rango [0, 2*max_int+1] . Si la entrada excede max_int se convierte al entero con signo min_int + input - max_int - 1 .

El carácter _ (guion bajo) puede aparecer en cualquier lugar de la cadena y se ignora.

Devuelve None si la cadena dada no es una representación válida de un entero, o si el entero representado excede el rango de enteros representables en el tipo int .

val string_of_float : float -> string

Devuelve una representación en cadena de un número de punto flotante.

Esta conversión puede implicar una pérdida de precisión. Para un mayor control sobre la forma en que se imprime el número, consulte Printf .

val float_of_string_opt : string -> float option

Convierte la cadena dada a un flotante. La cadena se lee en decimal (por defecto) o en hexadecimal (marcado con 0x o 0X ).

El formato de los números de punto flotante decimales es [-] dd.ddd (e|E) [+|-] dd , donde d representa un dígito decimal.

El formato de los números de punto flotante hexadecimales es [-] 0(x|X) hh.hhh (p|P) [+|-] dd , donde h representa un dígito hexadecimal y d un dígito decimal.

En ambos casos, se debe proporcionar al menos una de las partes entera y fraccionaria; la parte exponencial es opcional.

El carácter _ (guion bajo) puede aparecer en cualquier lugar de la cadena y se ignora.

Dependiendo de las plataformas de ejecución, se pueden aceptar otras representaciones de números de punto flotante, pero no se debe confiar en ellas.

Devuelve None si la cadena dada no es una representación válida de un flotante.

Operaciones con cadenas de formato

Las cadenas de formato son cadenas de caracteres con convenciones léxicas especiales que definen la funcionalidad de las funciones de entrada/salida con formato. Las cadenas de formato se utilizan para leer datos con funciones de entrada con formato del módulo Scanf y para imprimir datos con funciones de salida con formato de los módulos Printf y Format.

Las cadenas de formato están compuestas por tres tipos de entidades:

- especificaciones de conversión, introducidas por el carácter especial '%' seguido de uno o más caracteres que especifican qué tipo de argumento leer o imprimir,

- indicaciones de formato, introducidas por el carácter especial '@' seguido de uno o más caracteres que especifican cómo leer o imprimir el argumento,

- caracteres literales que son caracteres regulares con convenciones léxicas habituales. Los caracteres literales especifican literales de cadena que se leerán en la entrada o se imprimirán en la salida.

Existe una regla léxica adicional para escapar los caracteres especiales '%' y '@' en las cadenas de formato: si un carácter especial sigue a un carácter '%', se trata como un carácter literal. En otras palabras, "%%" se considera un '%' literal y "%@" como un '@' literal.

NAME

Stdlib - The standard library

Module

This module provides access to the functions and types defined in the OCaml standard library.

The following sections describe the modules that are part of the standard library. All modules are opened by default when you start the OCaml interpreter or when you compile a program.

Documentation

Format strings

For more information about conversion specifications and formatting indications available, read the documentation of modules Scanf , Printf and Format .

Format strings have a general and highly polymorphic type ('a, 'b, 'c, 'd, 'e, 'f) format6 . The two simplified types, format and format4 below are included for backward compatibility with earlier releases of OCaml.

The meaning of format string type parameters is as follows:

- 'a is the type of the parameters of the format for formatted output functions ( printf -style functions); 'a is the type of the values read by the format for formatted input functions ( scanf -style functions).

- 'b is the type of input source for formatted input functions and the type of output target for formatted output functions. For printf -style functions from module Printf , 'b is typically out_channel ; for printf -style functions from module Format , 'b is typically Format.formatter ; for scanf -style functions from module Scanf , 'b is typically Scanf.Scanning.in_channel .

Type argument 'b is also the type of the first argument given to user's defined printing functions for %a and %t conversions, and user's defined reading functions for %r conversion.

- 'c is the type of the result of the %a and %t printing functions, and also the type of the argument transmitted to the first argument of kprintf -style functions or to the kscanf -style functions.

- 'd is the type of parameters for the scanf -style functions.

- 'e is the type of the receiver function for the scanf -style functions.

- 'f is the final result type of a formatted input/output function invocation: for the printf -style functions, it is typically unit ; for the scanf -style functions, it is typically the result type of the receiver function.

type ('a, 'b, 'c, 'd, 'e, 'f) format6 = ('a, 'b, 'c, 'd, 'e, 'f) CamlinternalFormatBasics.format6

type ('a, 'b, 'c, 'd) format4 = ('a, 'b, 'c, 'c, 'c, 'd) format6

type ('a, 'b, 'c) format = ('a, 'b, 'c, 'c) format4

val string_of_format : ('a, 'b, 'c, 'd, 'e, 'f) format6 -> string

Converts a format string into a string.

val format_of_string : ('a, 'b, 'c, 'd, 'e, 'f) format6 -> ('a, 'b, 'c, 'd, 'e, 'f) format6

format_of_string s returns a format string read from the string literal s . Note: format_of_string can not convert a string argument that is not a literal. If you need this functionality, use the more general Scanf.format_from_string function.

val (^^) : ('a, 'b, 'c, 'd, 'e, 'f) format6 -> ('f, 'b, 'c, 'e, 'g, 'h) format6 -> ('a, 'b, 'c, 'd, 'g, 'h) format6

f1 ^^ f2 catenates format strings f1 and f2 . The result is a format string that behaves as the concatenation of format strings f1 and f2 : in case of formatted output, it accepts arguments from f1 , then arguments from f2 ; in case of formatted input, it returns results from f1 , then results from f2 . Right-associative operator, see Ocaml_operators for more information.

Program termination

val exit : int -> 'a

Terminate the process, returning the given status code to the operating system: usually 0 to indicate no errors, and a small positive integer to indicate failure. All open output channels are flushed with flush_all . The callbacks registered with Domain.at_exit are called followed by those registered with at_exit .

An implicit exit 0 is performed each time a program terminates normally. An implicit exit 2 is performed if the program terminates early because of an uncaught exception.

val at_exit : (unit -> unit) -> unit

Register the given function to be called at program termination time. The functions registered with at_exit will be called when the program does any of the following:

-executes exit

-terminates, either normally or because of an uncaught exception

-executes the C function caml_shutdown . The functions are called in 'last in, first out' order: the function most recently added with at_exit is called first.
