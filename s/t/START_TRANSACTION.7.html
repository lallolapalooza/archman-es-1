NOMBRE

START TRANSACTION - iniciar un bloque de transacción

SINOPSIS

START TRANSACTION [ modo_transaccion [, ...] ]
donde modo_transaccion es uno de:
    NIVEL DE AISLAMIENTO { SERIALIZABLE | REPEATABLE READ | READ COMMITTED | READ UNCOMMITTED }
    READ WRITE | READ ONLY
    [ NOT ] DEFERRABLE

DESCRIPCIÓN

Este comando inicia un nuevo bloque de transacción. Si se especifica el nivel de aislamiento, el modo de lectura/escritura o el modo diferible, la nueva transacción tiene esas características, como si se hubiera ejecutado SET TRANSACTION. Es lo mismo que el comando BEGIN.

PARÁMETROS

Consulte SET TRANSACTION (SET_TRANSACTION(7)) para obtener información sobre el significado de los parámetros de esta sentencia.

COMPATIBILIDAD

En el estándar, no es necesario ejecutar START TRANSACTION para iniciar un bloque de transacción: cualquier comando SQL inicia implícitamente un bloque. El comportamiento de PostgreSQL puede verse como la ejecución implícita de un COMMIT después de cada comando que no sigue a START TRANSACTION (o BEGIN), y por lo tanto a menudo se le llama "autocommit". Otros sistemas de bases de datos relacionales pueden ofrecer una característica de autocommit como conveniencia.

El modo de transacción DEFERRABLE es una extensión del lenguaje PostgreSQL.

El estándar SQL requiere comas entre los sucesivos modos_transacción, pero por razones históricas PostgreSQL permite omitir las comas.

Ver también la sección de compatibilidad de SET TRANSACTION (SET_TRANSACTION(7)).

VER TAMBIÉN
