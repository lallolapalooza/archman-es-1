Módulo Stdlib.Condition

DOCUMENTACIÓN

Módulo Condition
: (module Stdlib__Condition)

type t

El tipo de las variables de condición.

val create : unit -> t

create() crea y devuelve una nueva variable de condición. Esta variable de condición debe asociarse (en la mente del programador) con un cierto mutex m y con una cierta propiedad P de la estructura de datos que está protegida por el mutex m .

val wait : t -> Mutex.t -> unit

La llamada wait c m solo está permitida si m es el mutex asociado con la variable de condición c , y solo si m está actualmente bloqueado. Esta llamada desbloquea atómicamente el mutex m y suspende el hilo actual en la variable de condición c . Este hilo puede ser despertado más tarde después de que la variable de condición c haya sido señalada mediante Condition.signal o Condition.broadcast ; sin embargo, también puede ser despertado sin motivo. El mutex m se vuelve a bloquear antes de que wait retorne. No se puede asumir que la propiedad P asociada con la variable de condición c se cumple cuando wait retorna; se debe probar explícitamente si P se cumple después de llamar a wait .

val signal : t -> unit

signal c despierta a uno de los hilos que esperan en la variable de condición c , si hay alguno. Si no hay ninguno, esta llamada no tiene ningún efecto.

Se recomienda llamar a signal c dentro de una sección crítica, es decir, mientras el mutex m asociado con c esté bloqueado.

val broadcast : t -> unit

broadcast c despierta a todos los hilos que esperan en la variable de condición c . Si no hay ninguno, esta llamada no tiene ningún efecto.

Se recomienda llamar a broadcast c dentro de una sección crítica, es decir, mientras el mutex m asociado con c esté bloqueado.
