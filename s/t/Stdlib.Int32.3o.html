Módulo Int32
: (módulo Stdlib__Int32)

val zero : int32

El entero de 32 bits 0.

val one : int32

El entero de 32 bits 1.

val minus_one : int32

El entero de 32 bits -1.

val neg : int32 -> int32

Negación unaria.

val add : int32 -> int32 -> int32

Suma.

val sub : int32 -> int32 -> int32

Resta.

val mul : int32 -> int32 -> int32

Multiplicación.

val div : int32 -> int32 -> int32

División entera. Esta división redondea el cociente real de sus argumentos hacia cero, según lo especificado para (/) .

Raises Division_by_zero si el segundo argumento es cero.

val unsigned_div : int32 -> int32 -> int32

Igual que Int32.div , excepto que los argumentos y el resultado se interpretan como enteros sin signo de 32 bits.

Since 4.08

val rem : int32 -> int32 -> int32

Resto entero. Si y no es cero, el resultado de Int32.rem x y satisface la siguiente propiedad: x = Int32.add (Int32.mul (Int32.div x y) y) (Int32.rem x y) . Si y = 0 , Int32.rem x y lanza Division_by_zero .

val unsigned_rem : int32 -> int32 -> int32

Igual que Int32.rem , excepto que los argumentos y el resultado se interpretan como enteros sin signo de 32 bits.

Since 4.08

val succ : int32 -> int32

Sucesor. Int32.succ x es Int32.add x Int32.one .

val pred : int32 -> int32

Predecesor. Int32.pred x es Int32.sub x Int32.one .

val abs : int32 -> int32

abs x es el valor absoluto de x . En min_int esto es min_int mismo y por lo tanto permanece negativo.

val max_int : int32

El mayor entero de 32 bits representable, 2^31 - 1.

val min_int : int32

El menor entero de 32 bits representable, -2^31.

val logand : int32 -> int32 -> int32

Y lógico a nivel de bits.

val logor : int32 -> int32 -> int32

O lógico a nivel de bits.

val logxor : int32 -> int32 -> int32

O exclusivo lógico a nivel de bits.

val lognot : int32 -> int32

Negación lógica a nivel de bits.

val shift_left : int32 -> int -> int32

Int32.shift_left x y desplaza x a la izquierda por y bits. El resultado no está especificado si y < 0 o y >= 32 .

val shift_right : int32 -> int -> int32

Int32.shift_right x y desplaza x a la derecha por y bits. Este es un desplazamiento aritmético: el bit de signo de x se replica y se inserta en los bits vaciados. El resultado no está especificado si y < 0 o y >= 32 .

val shift_right_logical : int32 -> int -> int32

Int32.shift_right_logical x y desplaza x a la derecha por y bits. Este es un desplazamiento lógico: se insertan ceros en los bits vaciados independientemente del signo de x . El resultado no está especificado si y < 0 o y >= 32 .

val of_int : int -> int32

Convierte el entero dado (tipo int ) a un entero de 32 bits (tipo int32 ). En plataformas de 64 bits, el argumento se toma módulo 2^32.

val to_int : int32 -> int

Convierte el entero de 32 bits dado (tipo int32 ) a un entero (tipo int ). En plataformas de 32 bits, el entero de 32 bits se toma módulo 2^31, es decir, el bit de orden superior se pierde durante la conversión. En plataformas de 64 bits, la conversión es exacta.

val unsigned_to_int : int32 -> int option

Igual que Int32.to_int , pero interpreta el argumento como un entero sin signo. Devuelve None si el valor sin signo del argumento no cabe en un int .

Since 4.08

val of_float : float -> int32

Convierte el número de punto flotante dado a un entero de 32 bits, descartando la parte fraccionaria (trunca hacia cero). Si el número de punto flotante truncado está fuera del rango [ Int32.min_int , Int32.max_int ], no se lanza ninguna excepción y se devuelve un entero no especificado y dependiente de la plataforma.

val to_float : int32 -> float

Convierte el entero de 32 bits dado a un número de punto flotante.

val of_string : string -> int32

Convierte la cadena dada a un entero de 32 bits. La cadena se lee en decimal (por defecto, o si la cadena comienza con 0u ) o en hexadecimal, octal o binario si la cadena comienza con 0x , 0o o 0b respectivamente.

El prefijo 0u lee la entrada como un entero sin signo en el rango [0, 2*Int32.max_int+1] . Si la entrada excede Int32.max_int se convierte al entero con signo Int32.min_int + input - Int32.max_int - 1 .

El carácter _ (guion bajo) puede aparecer en cualquier lugar de la cadena y se ignora.

Raises Failure si la cadena dada no es una representación válida de un entero, o si el entero representado excede el rango de enteros representables en el tipo int32 .

val of_string_opt : string -> int32 option

Igual que of_string , pero devuelve None en lugar de lanzar una excepción.

Since 4.05

val to_string : int32 -> string

Devuelve la representación de cadena de su argumento, en decimal con signo.

val bits_of_float : float -> int32

Devuelve la representación interna del flotante dado según el diseño de bits del formato 'simple' de punto flotante IEEE 754. El bit 31 del resultado representa el signo del flotante; los bits 30 a 23 representan el exponente (sesgado); los bits 22 a 0 representan la mantisa.

val float_of_bits : int32 -> float

Devuelve el número de punto flotante cuya representación interna, según el diseño de bits del formato 'simple' de punto flotante IEEE 754, es el int32 dado.

type t = int32

Un alias para el tipo de enteros de 32 bits.

val compare : t -> t -> int

La función de comparación para enteros de 32 bits, con la misma especificación que compare . Junto con el tipo t , esta función compare permite que el módulo Int32 se pase como argumento a los functores Set.Make y Map.Make .

val unsigned_compare : t -> t -> int

Igual que Int32.compare , excepto que los argumentos se interpretan como enteros sin signo de 32 bits.

Since 4.08

val equal : t -> t -> bool

La función de igualdad para int32.

Since 4.03

val min : t -> t -> t

Devuelve el menor de los dos argumentos.

Since 4.13

val max : t -> t -> t

Devuelve el mayor de los dos argumentos.

Since 4.13

val seeded_hash : int -> t -> int

Una función hash con semilla para ints de 32 bits, con el mismo valor de salida que Hashtbl.seeded_hash . Esta función permite que este módulo se pase como argumento al functor Hashtbl.MakeSeeded .

Since 5.1

val hash : t -> int

Una función hash sin semilla para ints de 32 bits, con el mismo valor de salida que Hashtbl.hash . Esta función permite que este módulo se pase como argumento al functor Hashtbl.Make .

Since 5.1
