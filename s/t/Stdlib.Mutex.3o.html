Módulo Stdlib.Mutex

DOCUMENTACIÓN

Módulo Mutex
: (módulo Stdlib__Mutex)

tipo t

El tipo de los mutex.

val create : unit -> t

Devuelve un nuevo mutex.

val lock : t -> unit

Bloquea el mutex dado. Solo un hilo puede tener el mutex bloqueado en un momento dado. Un hilo que intente bloquear un mutex ya bloqueado por otro hilo se suspenderá hasta que el otro hilo desbloquee el mutex.

Antes de 4.12

Sys_error no se generaba para el bloqueo recursivo (comportamiento dependiente de la plataforma)

Genera Sys_error si el mutex ya está bloqueado por el hilo que llama a Mutex.lock.

val try_lock : t -> bool

Igual que Mutex.lock, pero no suspende el hilo que llama si el mutex ya está bloqueado: simplemente devuelve false inmediatamente en ese caso. Si el mutex está desbloqueado, lo bloquea y devuelve true.

val unlock : t -> unit

Desbloquea el mutex dado. Otros hilos suspendidos intentando bloquear el mutex se reiniciarán. El mutex debe haber sido bloqueado previamente por el hilo que llama a Mutex.unlock.

Antes de 4.12

Sys_error no se generaba al desbloquear un mutex desbloqueado o al desbloquear un mutex desde otro hilo.

Genera Sys_error si el mutex está desbloqueado o fue bloqueado por otro hilo.

val protect : t -> (unit -> 'a) -> 'a

protect mutex f ejecuta f() en una sección crítica donde mutex está bloqueado (usando Mutex.lock); luego se encarga de liberar mutex, independientemente de si f() devolvió un valor o generó una excepción.

Se garantiza que la operación de desbloqueo siempre tendrá lugar, incluso en el caso de que se genere una excepción asíncrona (por ejemplo, Sys.Break) en algún manejador de señales.
