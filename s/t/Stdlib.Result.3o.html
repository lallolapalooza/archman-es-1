Resultados

tipo ('a, 'e) t = ('a, 'e) resultado =
| Ok de 'a
| Error de 'e

El tipo para los valores de resultado. Ya sea un valor Ok v o un error Error e .

val ok : 'a -> ('a, 'e) resultado

ok v es Ok v .

val error : 'e -> ('a, 'e) resultado

error e es Error e .

val valor : ('a, 'e) resultado -> default:'a -> 'a

valor r ~default es v si r es Ok v y default en caso contrario.

val get_ok : ('a, 'e) resultado -> 'a

get_ok r es v si r es Ok v y lanza una excepción en caso contrario.

Lanza Invalid_argument si r es Error _ .

val get_ok' : ('a, string) resultado -> 'a

get_ok' es como Result.get_ok pero en caso de error utiliza el mensaje de error para lanzar Invalid_argument .

Desde 5.4

val get_error : ('a, 'e) resultado -> 'e

get_error r es e si r es Error e y lanza una excepción en caso contrario.

Lanza Invalid_argument si r es Ok _ .

val error_to_failure : ('a, string) resultado -> 'a

error_to_failure r es v si r es Ok v y lanza Failure e si r es Error e .

val bind : ('a, 'e) resultado -> ('a -> ('b, 'e) resultado) -> ('b, 'e) resultado

bind r f es f v si r es Ok v y r si r es Error _ .

val join : (('a, 'e) resultado, 'e) resultado -> ('a, 'e) resultado

join rr es r si rr es Ok r y rr si rr es Error _ .

val map : ('a -> 'b) -> ('a, 'e) resultado -> ('b, 'e) resultado

map f r es Ok (f v) si r es Ok v y r si r es Error _ .

val product : ('a, 'e) resultado -> ('b, 'e) resultado -> ('a * 'b, 'e) resultado

product r0 r1 es Ok (v0, v1) si r0 es Ok v0 y r1 es Ok v2 y en caso contrario devuelve el error de r0 , si existe, o el error de r1 .

Desde 5.4

val map_error : ('e -> 'f) -> ('a, 'e) resultado -> ('a, 'f) resultado

map_error f r es Error (f e) si r es Error e y r si r es Ok _ .

val fold : ok:('a -> 'c) -> error:('e -> 'c) -> ('a, 'e) resultado -> 'c

fold ~ok ~error r es ok v si r es Ok v y error e si r es Error e .

val retract : ('a, 'a) resultado -> 'a

retract r es v si r es Ok v o Error v .

Desde 5.4

val iter : ('a -> unit) -> ('a, 'e) resultado -> unit

iter f r es f v si r es Ok v y () en caso contrario.

val iter_error : ('e -> unit) -> ('a, 'e) resultado -> unit

iter_error f r es f e si r es Error e y () en caso contrario.

Predicados y comparaciones

val is_ok : ('a, 'e) resultado -> bool

is_ok r es true si y solo si r es Ok _ .

val is_error : ('a, 'e) resultado -> bool

is_error r es true si y solo si r es Error _ .

val equal : ok:('a -> 'a -> bool) -> error:('e -> 'e -> bool) -> ('a, 'e) resultado -> ('a, 'e) resultado -> bool

equal ~ok ~error r0 r1 comprueba la igualdad de r0 y r1 utilizando ok y error para comparar respectivamente los valores envueltos por Ok _ y Error _ .

val compare : ok:('a -> 'a -> int) -> error:('e -> 'e -> int) -> ('a, 'e) resultado -> ('a, 'e) resultado -> int

compare ~ok ~error r0 r1 ordena totalmente r0 y r1 utilizando ok y error para comparar respectivamente los valores envueltos por Ok _ y Error _ . Los valores Ok _ son menores que los valores Error _ .

Conversión

val to_option : ('a, 'e) resultado -> 'a option

to_option r es r como una opción, mapeando Ok v a Some v y Error _ a None .

val to_list : ('a, 'e) resultado -> 'a list

to_list r es [v] si r es Ok v y [] en caso contrario.

val to_seq : ('a, 'e) resultado -> 'a Seq.t

to_seq r es r como una secuencia. Ok v es la secuencia singleton que contiene v y Error _ es la secuencia vacía.
