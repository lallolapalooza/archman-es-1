Expresiones regulares y procesamiento de cadenas de alto nivel

Expresiones regulares

La biblioteca Str proporciona expresiones regulares sobre secuencias de bytes. En general, no es adecuada para coincidir con caracteres Unicode.

tipo regexp

El tipo de expresiones regulares compiladas.

val regexp : string -> regexp

Compila una expresión regular. Se reconocen las siguientes construcciones:

- . Coincide con cualquier carácter excepto nueva línea.

- * (postfijo) Coincide con la expresión precedente cero, una o varias veces

- + (postfijo) Coincide con la expresión precedente una o varias veces

- ? (postfijo) Coincide con la expresión precedente una vez o ninguna

- [..] Conjunto de caracteres. Los rangos se denotan con -, como en [a-z]. Un ^ inicial, como en [^0-9], complementa el conjunto. Para incluir un carácter ] en un conjunto, hazlo el primer carácter del conjunto. Para incluir un carácter - en un conjunto, hazlo el primer o el último carácter del conjunto.

- ^ Coincide al principio de línea: ya sea al principio de la cadena coincidente, o justo después de un carácter '\n'.

- $ Coincide al final de línea: ya sea al final de la cadena coincidente, o justo antes de un carácter '\n'.

- \| (infijo) Alternativa entre dos expresiones.

- \(..\) Agrupación y denominación de la expresión encerrada.

- \1 El texto coincidente de la primera expresión \(...\) ( \2 para la segunda expresión, y así sucesivamente hasta \9 ).

- \b Coincide con límites de palabra.

- \ Cita caracteres especiales. Los caracteres especiales son $^\.*+?[].

En las expresiones regulares, a menudo usarás caracteres de barra inversa; es más fácil usar un literal de cadena entrecomillada {|...|} para evitar tener que escapar las barras inversas.

Por ejemplo, la siguiente expresión:

let r = Str.regexp {|hello \([A-Za-z]+\)|} in
      Str.replace_first r {|\1|} "hello world"
devuelve la cadena "world".

Si quieres una expresión regular que coincida con un carácter de barra inversa literal, necesitas duplicarla: Str.regexp {|\\|}.

También puedes usar literales de cadena normales "...", sin embargo, tendrás que escapar las barras inversas. El ejemplo anterior se puede reescribir con un literal de cadena normal como:

let r = Str.regexp "hello \\([A-Za-z]+\\)" in
      Str.replace_first r "\\1" "hello world"

Y la expresión regular para coincidir con una barra inversa se convierte en una barra inversa cuádruple: Str.regexp "\\\\".

val regexp_case_fold : string -> regexp

Igual que regexp, pero la expresión compilada coincidirá con texto de forma insensible a mayúsculas y minúsculas: las letras mayúsculas y minúsculas se considerarán equivalentes.

val quote : string -> string

Str.quote s devuelve una cadena de expresión regular que coincide exactamente con s y nada más.

val regexp_string : string -> regexp

Str.regexp_string s devuelve una expresión regular que coincide exactamente con s y nada más.

val regexp_string_case_fold : string -> regexp

Str.regexp_string_case_fold es similar a Str.regexp_string, pero la expresión regular coincide de forma insensible a mayúsculas y minúsculas.

Coincidencia y búsqueda de cadenas

val string_match : regexp -> string -> int -> bool

string_match r s start comprueba si una subcadena de s que comienza en la posición start coincide con la expresión regular r. El primer carácter de una cadena tiene la posición 0, como de costumbre.

val search_forward : regexp -> string -> int -> int

search_forward r s start busca en la cadena s una subcadena que coincida con la expresión regular r. La búsqueda comienza en la posición start y procede hacia el final de la cadena. Devuelve la posición del primer carácter de la subcadena coincidente.

Lanza Not_found si ninguna subcadena coincide.

val search_backward : regexp -> string -> int -> int

search_backward r s last busca en la cadena s una subcadena que coincida con la expresión regular r. La búsqueda considera primero subcadenas que comienzan en la posición last y procede hacia el principio de la cadena. Devuelve la posición del primer carácter de la subcadena coincidente.

Lanza Not_found si ninguna subcadena coincide.

val string_partial_match : regexp -> string -> int -> bool

Similar a Str.string_match, pero también devuelve verdadero si la cadena argumento es un prefijo de una cadena que coincide. Esto incluye el caso de una coincidencia completa real.

val matched_string : string -> string

matched_string s devuelve la subcadena de s que coincidió con la última llamada a una de las siguientes funciones de coincidencia o búsqueda:

- Str.string_match

- Str.search_forward

- Str.search_backward

- Str.string_partial_match

- Str.global_substitute

- Str.substitute_first

siempre que ninguna de las siguientes funciones haya sido llamada en medio:

- Str.global_replace

- Str.replace_first

- Str.split

- Str.bounded_split

- Str.split_delim

- Str.bounded_split_delim

- Str.full_split

- Str.bounded_full_split

Nota: en el caso de global_substitute y substitute_first, una llamada a matched_string solo es válida dentro del argumento subst, no después de que global_substitute o substitute_first devuelvan.

El usuario debe asegurarse de que el parámetro s sea la misma cadena que se pasó a la función de coincidencia o búsqueda.

val match_beginning : unit -> int

match_beginning() devuelve la posición del primer carácter de la subcadena que coincidió con la última llamada a una función de coincidencia o búsqueda (ver Str.matched_string para más detalles).

val match_end : unit -> int

match_end() devuelve la posición del carácter siguiente al último carácter de la subcadena que coincidió con la última llamada a una función de coincidencia o búsqueda (ver Str.matched_string para más detalles).

val matched_group : int -> string -> string

matched_group n s devuelve la subcadena de s que coincidió con el grupo n \(...\) de la expresión regular que coincidió con la última llamada a una función de coincidencia o búsqueda (ver Str.matched_string para más detalles). Cuando n es 0, devuelve la subcadena que coincidió con toda la expresión regular. El usuario debe asegurarse de que el parámetro s sea la misma cadena que se pasó a la función de coincidencia o búsqueda.

Lanza Not_found si el grupo n de la expresión regular no coincidió. Esto puede suceder con grupos dentro de alternativas \|, opciones ? o repeticiones *. Por ejemplo, la cadena vacía coincidirá con \(a\)*, pero matched_group 1 "" lanzará Not_found porque el primer grupo en sí no coincidió.

val group_beginning : int -> int

group_beginning n devuelve la posición del primer carácter de la subcadena que coincidió con el grupo n de la expresión regular que coincidió con la última llamada a una función de coincidencia o búsqueda (ver Str.matched_string para más detalles).

Lanza Not_found si el grupo n de la expresión regular no coincidió.

Lanza Invalid_argument si hay menos de n grupos en la expresión regular.

val group_end : int -> int

group_end n devuelve la posición del carácter siguiente al último carácter de la subcadena que coincidió con el grupo n del patrón de expresión regular que coincidió en la última llamada a una función de coincidencia o búsqueda (ver Str.matched_string para más detalles).

Raises Not_found si el grupo n de la expresión regular no coincidió.

Raises Invalid_argument si hay menos de n grupos en la expresión regular.

Reemplazo

val global_replace : regexp -> string -> string -> string

global_replace regexp templ s devuelve una cadena idéntica a s, excepto que todas las subcadenas de s que coinciden con regexp han sido reemplazadas por templ. La plantilla de reemplazo templ puede contener \1, \2, etc.; estas secuencias serán reemplazadas por el texto coincidente con el grupo correspondiente en la expresión regular. \0 representa el texto coincidente con toda la expresión regular.

val replace_first : regexp -> string -> string -> string

Igual que Str.global_replace, excepto que solo se reemplaza la primera subcadena que coincide con la expresión regular.

val global_substitute : regexp -> (string -> string) -> string -> string

global_substitute regexp subst s devuelve una cadena idéntica a s, excepto que todas las subcadenas de s que coinciden con regexp han sido reemplazadas por el resultado de la función subst. La función subst se llama una vez por cada subcadena coincidente y recibe s (el texto completo) como argumento.

val substitute_first : regexp -> (string -> string) -> string -> string

Igual que Str.global_substitute, excepto que solo se reemplaza la primera subcadena que coincide con la expresión regular.

val replace_matched : string -> string -> string

replace_matched repl s devuelve el texto de reemplazo repl en el que \1, \2, etc. han sido reemplazados por el texto coincidente con los grupos correspondientes en la expresión regular que coincidió en la última llamada a una función de coincidencia o búsqueda (ver Str.matched_string para más detalles). s debe ser la misma cadena que se pasó a la función de coincidencia o búsqueda.

División

val split : regexp -> string -> string list

split r s divide s en subcadenas, tomando como delimitadores las subcadenas que coinciden con r, y devuelve la lista de subcadenas. Por ejemplo, split (regexp "[ \t]+") s divide s en palabras separadas por espacios en blanco. Una ocurrencia del delimitador al principio o al final de la cadena se ignora.

val bounded_split : regexp -> string -> int -> string list

Igual que Str.split, pero divide en como máximo n subcadenas, donde n es el parámetro entero adicional.

val split_delim : regexp -> string -> string list

Igual que Str.split pero las ocurrencias del delimitador al principio y al final de la cadena se reconocen y se devuelven como cadenas vacías en el resultado. Por ejemplo, split_delim (regexp " ") " abc " devuelve [""; "abc"; ""], mientras que split con los mismos argumentos devuelve ["abc"].

val bounded_split_delim : regexp -> string -> int -> string list

Igual que Str.bounded_split, pero las ocurrencias del delimitador al principio y al final de la cadena se reconocen y se devuelven como cadenas vacías en el resultado.

type split_result =
| Text of string
| Delim of string

val full_split : regexp -> string -> split_result list

Igual que Str.split_delim, pero devuelve los delimitadores así como las subcadenas contenidas entre delimitadores. Los primeros se etiquetan como Delim en la lista de resultados; los segundos se etiquetan como Text. Por ejemplo, full_split (regexp "[{}]") "{ab}" devuelve [Delim "{"; Text "ab"; Delim "}"].

val bounded_full_split : regexp -> string -> int -> split_result list

Igual que Str.bounded_split_delim, pero devuelve los delimitadores así como las subcadenas contenidas entre delimitadores. Los primeros se etiquetan como Delim en la lista de resultados; los segundos se etiquetan como Text.

Extracción de subcadenas

val string_before : string -> int -> string

string_before s n devuelve la subcadena de todos los caracteres de s que preceden a la posición n (excluyendo el carácter en la posición n).

val string_after : string -> int -> string

string_after s n devuelve la subcadena de todos los caracteres de s que siguen a la posición n (incluyendo el carácter en la posición n).

val first_chars : string -> int -> string

first_chars s n devuelve los primeros n caracteres de s. Esta es la misma función que Str.string_before.

val last_chars : string -> int -> string

last_chars s n devuelve los últimos n caracteres de s.
