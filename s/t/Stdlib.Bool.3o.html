Módulo Bool
: (módulo Stdlib__Bool)

Booleanos

tipo t = bool =
| false
| true

El tipo de los booleanos (valores de verdad).

Los constructores false y true se incluyen aquí para que tengan rutas, pero no están destinados a ser utilizados en tipos de datos definidos por el usuario.

val not : bool -> bool

not b es la negación booleana de b .

val (&&) : bool -> bool -> bool

e0 && e1 es la conjunción booleana perezosa de las expresiones e0 y e1 . Si e0 se evalúa a false , e1 no se evalúa. Operador asociativo a la derecha en el nivel de precedencia 3/11.

val (||) : bool -> bool -> bool

e0 || e1 es la disyunción booleana perezosa de las expresiones e0 y e1 . Si e0 se evalúa a true , e1 no se evalúa. Operador asociativo a la derecha en el nivel de precedencia 2/11.

val logand : bool -> bool -> bool

logand b1 b2 es true si y solo si b1 y b2 son ambos true .

val logor : bool -> bool -> bool

logor b1 b2 es true si y solo si b1 o b2 es true .

val logxor : bool -> bool -> bool

logxor b1 b2 es true si exactamente uno de b1 y b2 es true .

Predicados y comparaciones

val equal : bool -> bool -> bool

equal b0 b1 es true si y solo si b0 y b1 son ambos true o ambos false .

val compare : bool -> bool -> int

compare b0 b1 es un orden total en los valores booleanos. false es menor que true .

Conversión

val to_int : bool -> int

to_int b es 0 si b es false y 1 si b es true .

val to_float : bool -> float

to_float b es 0. si b es false y 1. si b es true .

val to_string : bool -> string

to_string b es "true" si b es true y "false" si b es false .

val seeded_hash : int -> bool -> int

Una función hash sembrada para booleanos, con el mismo valor de salida que Hashtbl.seeded_hash . Esta función permite que este módulo se pase como argumento al functor Hashtbl.MakeSeeded .

Desde 5.1
