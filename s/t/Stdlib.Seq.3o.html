Módulo Seq
: (module Stdlib__Seq)

type 'a t = unit -> 'a node

Una secuencia xs de tipo 'a t es una lista retardada de elementos de tipo 'a . Dicha secuencia se consulta realizando una aplicación de función xs() . Esta aplicación de función devuelve un nodo, permitiendo al llamador determinar si la secuencia está vacía o no, y en este último caso, obtener su cabeza y cola.

type 'a node =
| Nil
| Cons de 'a * 'a t

Un nodo es Nil , lo que significa que la secuencia está vacía, o Cons (x, xs) , lo que significa que x es el primer elemento de la secuencia y xs es el resto de la secuencia.

CONSUMIR SECUENCIAS

Las funciones de esta sección consumen su argumento, una secuencia, ya sea parcial o completamente:

- is_empty y uncons consumen la secuencia hasta la profundidad 1. Es decir, demandan el primer argumento de la secuencia, si lo hay.

- iter , fold_left , length , etc., consumen la secuencia hasta el final. Solo terminan si la secuencia es finita.

- for_all , exists , find , etc. consumen la secuencia hasta una cierta profundidad, que es impredecible a priori.

De manera similar, entre las funciones que consumen dos secuencias, se pueden distinguir dos grupos:

- iter2 y fold_left2 consumen ambas secuencias hasta el final, siempre que las secuencias tengan la misma longitud.

- for_all2 , exists2 , equal , compare consumen las secuencias hasta una cierta profundidad, que es impredecible a priori.

Las funciones que consumen dos secuencias se pueden aplicar a dos secuencias de longitudes distintas: en ese caso, se ignoran los elementos sobrantes en la secuencia más larga. (Puede darse el caso de que se demande un elemento sobrante, aunque dicho elemento no se utilice).

Ninguna de las funciones de esta sección es perezosa. Estas funciones son consumidoras: fuerzan la realización de algunos cálculos.

val is_empty : 'a t -> bool

is_empty xs determina si la secuencia xs está vacía.

Se recomienda que la secuencia xs sea persistente. De hecho, is_empty xs demanda la cabeza de la secuencia xs , por lo que, si xs es efímera, puede ocurrir que xs no pueda ser utilizada después de esta llamada.

Desde 4.14

val uncons : 'a t -> ('a * 'a t) option

Si xs está vacía, entonces uncons xs es None .

Si xs no está vacía, entonces uncons xs es Some (x, ys) donde x es la cabeza de la secuencia y ys es su cola.

Desde 4.14

val length : 'a t -> int

length xs es la longitud de la secuencia xs .

No termina si xs es infinita.

Desde 4.14

val iter : ('a -> unit) -> 'a t -> unit

iter f xs invoca f x sucesivamente para cada elemento x de la secuencia xs , de izquierda a derecha.

Solo termina si la secuencia xs es finita.

val fold_left : ('acc -> 'a -> 'acc) -> 'acc -> 'a t -> 'acc

fold_left f _ xs invoca f _ x sucesivamente para cada elemento x de la secuencia xs , de izquierda a derecha.

Un acumulador de tipo 'a se pasa a través de las llamadas a f .

Solo termina si la secuencia xs es finita.

val iteri : (int -> 'a -> unit) -> 'a t -> unit

iteri f xs invoca f i x sucesivamente para cada elemento x ubicado en el índice i de la secuencia xs .

Solo termina si la secuencia xs es finita.

iteri f xs es equivalente a iter (fun (i, x) -> f i x) (zip (ints 0) xs) .

Desde 4.14

val fold_lefti : ('acc -> int -> 'a -> 'acc) -> 'acc -> 'a t -> 'acc

fold_lefti f _ xs invoca f _ i x sucesivamente para cada elemento x ubicado en el índice i de la secuencia xs .

Un acumulador de tipo 'b se pasa a través de las llamadas a f .

Solo termina si la secuencia xs es finita.

fold_lefti f accu xs es equivalente a fold_left (fun accu (i, x) -> f accu i x) accu (zip (ints 0) xs) .

Desde 4.14

val for_all : ('a -> bool) -> 'a t -> bool

for_all p xs determina si todos los elementos x de la secuencia xs satisfacen p x .

Puede no terminar si xs es infinita.

Desde 4.14

val exists : ('a -> bool) -> 'a t -> bool

exists p xs determina si al menos un elemento x de la secuencia xs satisface p x .

Puede no terminar si xs es infinita.

Desde 4.14

val find : ('a -> bool) -> 'a t -> 'a option

find p xs devuelve Some x , donde x es el primer elemento de la secuencia xs que satisface p x , si existe tal elemento.

Devuelve None si no existe tal elemento.

Puede no terminar si xs es infinita.

Desde 4.14

val find_index : ('a -> bool) -> 'a t -> int option

find_index p xs devuelve Some i , donde i es el índice del primer elemento de la secuencia xs que satisface p x , si existe tal elemento.

Devuelve None si no existe tal elemento.

Puede no terminar si xs es infinita.

Desde 5.1

val find_map : ('a -> 'b option) -> 'a t -> 'b option

find_map f xs devuelve Some y , donde x es el primer elemento de la secuencia xs tal que f x = Some _ , si existe tal elemento, y donde y está definido por f x = Some y .

Devuelve None si no existe tal elemento.

Puede no terminar si xs es infinita.

Desde 4.14

val find_mapi : (int -> 'a -> 'b option) -> 'a t -> 'b option

Similar a find_map , pero el predicado se aplica al índice del elemento como primer argumento (contando desde 0), y al elemento mismo como segundo argumento.

Puede no terminar si xs es infinita.

Desde 5.1

val iter2 : ('a -> 'b -> unit) -> 'a t -> 'b t -> unit

iter2 f xs ys invoca f x y sucesivamente para cada par (x, y) de elementos extraídos síncronamente de las secuencias xs y ys .

Si las secuencias xs y ys tienen longitudes diferentes, entonces la iteración se detiene tan pronto como una secuencia se agota; se ignoran los elementos sobrantes en la otra secuencia.

La iteración solo termina si al menos una de las secuencias xs y ys es finita.

iter2 f xs ys es equivalente a iter (fun (x, y) -> f x y) (zip xs ys) .

Desde 4.14

val fold_left2 : ('acc -> 'a -> 'b -> 'acc) -> 'acc -> 'a t -> 'b t -> 'acc

fold_left2 f _ xs ys invoca f _ x y sucesivamente para cada par (x, y) de elementos extraídos síncronamente de las secuencias xs y ys .

Un acumulador de tipo 'a se pasa a través de las llamadas a f .

Si las secuencias xs y ys tienen longitudes diferentes, entonces la iteración se detiene tan pronto como una secuencia se agota; se ignoran los elementos sobrantes en la otra secuencia.

La iteración solo termina si al menos una de las secuencias xs y ys es finita.

fold_left2 f accu xs ys es equivalente a <

b>fold_left (fun accu (x, y) -> f accu x y) (zip xs ys).

Desde 4.14

val for_all2 : ('a -> 'b -> bool) -> 'a t -> 'b t -> bool

for_all2 p xs ys determina si todos los pares (x, y) de elementos extraídos sincrónicamente de las secuencias xs e ys satisfacen p x y.

Si las secuencias xs e ys tienen longitudes diferentes, la iteración se detiene tan pronto como una secuencia se agota; los elementos excedentes en la otra secuencia se ignoran. En particular, si xs o ys está vacía, entonces for_all2 p xs ys es verdadero. Aquí es donde for_all2 y equal difieren: equal eq xs ys solo puede ser verdadero si xs e ys tienen la misma longitud.

Puede no terminar si ambas secuencias xs e ys son infinitas.

for_all2 p xs ys es equivalente a for_all (fun b -> b) (map2 p xs ys).

Desde 4.14

val exists2 : ('a -> 'b -> bool) -> 'a t -> 'b t -> bool

exists2 p xs ys determina si algún par (x, y) de elementos extraídos sincrónicamente de las secuencias xs e ys satisface p x y.

Si las secuencias xs e ys tienen longitudes diferentes, la iteración debe detenerse tan pronto como una secuencia se agote; los elementos excedentes en la otra secuencia se ignoran.

Puede no terminar si ambas secuencias xs e ys son infinitas.

exists2 p xs ys es equivalente a exists (fun b -> b) (map2 p xs ys).

Desde 4.14

val equal : ('a -> 'b -> bool) -> 'a t -> 'b t -> bool

Siempre que la función eq defina una igualdad en los elementos, equal eq xs ys determina si las secuencias xs e ys son punto por punto iguales.

Puede no terminar si ambas secuencias xs e ys son infinitas.

Desde 4.14

val compare : ('a -> 'b -> int) -> 'a t -> 'b t -> int

Siempre que la función cmp defina un preorden en los elementos, compare cmp xs ys compara las secuencias xs e ys según el preorden lexicográfico.

Para más detalles sobre las funciones de comparación, ver Array.sort .

Puede no terminar si ambas secuencias xs e ys son infinitas.

Desde 4.14

Construcción de secuencias

Las funciones en esta sección son perezosas: es decir, devuelven secuencias cuyos elementos se calculan solo cuando se solicitan.

val empty : 'a t

empty es la secuencia vacía. No tiene elementos. Su longitud es 0.

val return : 'a -> 'a t

return x es la secuencia cuyo único elemento es x. Su longitud es 1.

val cons : 'a -> 'a t -> 'a t

cons x xs es la secuencia que comienza con el elemento x, seguida de la secuencia xs.

Escribir cons (f()) xs provoca que la llamada a la función f() se realice inmediatamente. Para que esta llamada se retrase hasta que se consulte la secuencia, se debe escribir en su lugar (fun () -> Cons(f(), xs)).

Desde 4.11

val singleton : 'a -> 'a t

singleton x devuelve la secuencia de un elemento que contiene solo x.

Desde 5.4

val init : int -> (int -> 'a) -> 'a t

init n f es la secuencia f 0; f 1; ...; f (n-1).

n debe ser no negativo.

Si se desea, la secuencia infinita f 0; f 1; ... puede definirse como map f (ints 0).

Desde 4.14

Raises Invalid_argument si n es negativo.

val unfold : ('b -> ('a * 'b) option) -> 'b -> 'a t

unfold construye una secuencia a partir de una función de paso y un estado inicial.

Si f u es None entonces unfold f u es la secuencia vacía. Si f u es Some (x, u') entonces unfold f u es la secuencia no vacía cons x (unfold f u').

Por ejemplo, unfold (function [] -> None | h :: t -> Some (h, t)) l es equivalente a List.to_seq l.

Desde 4.11

val repeat : 'a -> 'a t

repeat x es la secuencia infinita donde el elemento x se repite indefinidamente.

repeat x es equivalente a cycle (return x).

Desde 4.14

val forever : (unit -> 'a) -> 'a t

forever f es una secuencia infinita donde cada elemento se produce (bajo demanda) mediante la llamada a la función f().

Por ejemplo, forever Random.bool es una secuencia infinita de bits aleatorios.

forever f es equivalente a map f (repeat ()).

Desde 4.14

val cycle : 'a t -> 'a t

cycle xs es la secuencia infinita que consiste en un número infinito de repeticiones de la secuencia xs.

Si xs es una secuencia vacía, entonces cycle xs también está vacía.

Consumir (un prefijo de) la secuencia cycle xs una vez puede hacer que la secuencia xs se consuma más de una vez. Por lo tanto, xs debe ser persistente.

Desde 4.14

val iterate : ('a -> 'a) -> 'a -> 'a t

iterate f x es la secuencia infinita cuyos elementos son x, f x, f (f x), y así sucesivamente.

En otras palabras, es la órbita de la función f, comenzando en x.

Desde 4.14

Transformación de secuencias

Las funciones en esta sección son perezosas: es decir, devuelven secuencias cuyos elementos se calculan solo cuando se solicitan.

val map : ('a -> 'b) -> 'a t -> 'b t

map f xs es la imagen de la secuencia xs a través de la transformación f.

Si xs es la secuencia x0; x1; ... entonces map f xs es la secuencia f x0; f x1; ....

val mapi : (int -> 'a -> 'b) -> 'a t -> 'b t

mapi es análogo a map, pero aplica la función f a un índice y un elemento.

mapi f xs es equivalente a map2 f (ints 0) xs.

Desde 4.14

val filter : ('a -> bool) -> 'a t -> 'a t

filter p xs es la secuencia de los elementos x de xs que satisfacen p x.

En otras palabras, filter p xs es la secuencia xs, privada de los elementos x tales que p x es falso.

val filteri : (int -> 'a -> bool) -> 'a t -> 'a t

Igual que Seq.filter, pero el predicado se aplica al índice del elemento como primer argumento (contando desde 0), y al elemento mismo como segundo argumento.

Desde 5.4

val filter_map : ('a -> 'b option) -> 'a t -> 'b t

filter_map f xs es la secuencia de los elementos y tal que f x = Some y, donde x varía sobre xs.

filter_map f xs es equivalente a map Option.get (filter Option.is_some (map f xs)).

val scan : ('b -> 'a -> 'b) -> 'b -> 'a t -> 'b t

Si xs es una secuencia [x0; x1; x2; ...], entonces scan f a0 xs es una secuencia de acumuladores [a0; a1; a2; ...] donde a1 es f a0 x0, a2 es f a1 x1, y así sucesivamente.

Por lo tanto, scan f a0 xs está conceptualmente relacionado con fold_left f a0 xs. Sin embargo, en lugar de realizar una iteración ávida y devolver inmediatamente el acumulador final, devuelve una secuencia de acumuladores.

Por ejemplo, scan (+) 0 transforma una secuencia de enteros en la secuencia de sus sumas parciales.

Si xs tiene longitud n, entonces scan f a0 xs tiene longitud n+1.

Desde 4.14

val take : int -> 'a t -> 'a t

take n xs es la secuencia de los primeros n elementos de xs.

Si xs tiene menos de n elementos, entonces take n xs es equivalente a xs.

n debe ser no negativo.

Desde 4.14

Raises Invalid_argument si n es negativo.

val drop : int -> 'a t -> 'a t

drop n xs es la secuencia xs, privada de sus primeros n elementos.

Si xs tiene menos de n elementos, entonces drop n xs está vacía.

n debe ser no negativo.

drop es perezosa: los primeros n+1 elementos de la secuencia xs solo se demandan cuando se demanda el primer elemento de drop n xs.

Desde 4.14

Raises Invalid_argument si n es negativo.

val take_while : ('a -> bool) -> 'a t -> 'a t

take_while p xs es el prefijo más largo de la secuencia xs donde cada elemento x satisface p x.

Desde 4.14

val drop_while : ('a -> bool) -> 'a t -> 'a t

drop_while p xs es la secuencia xs, privada del prefijo take_while p xs.

Desde 4.14

val group : ('a -> 'a -> bool) -> 'a t -> 'a t t

Siempre que la función eq defina una igualdad en los elementos, group eq xs es la secuencia de las series máximas de elementos duplicados adyacentes de la secuencia xs.

Cada elemento de group eq xs es una secuencia no vacía de elementos iguales.

La concatenación concat (group eq xs) es igual a xs.

Consumir group eq xs, y consumir las secuencias que contiene, puede hacer que xs se consuma más de una vez. Por lo tanto, xs debe ser persistente.

Desde 4.14

val memoize : 'a t -> 'a t

La secuencia memoize xs tiene los mismos elementos que la secuencia xs .

Independientemente de si xs es efímero o persistente, memoize xs es persistente: incluso si se consulta varias veces, xs se consulta como máximo una vez.

La construcción de la secuencia memoize xs se basa internamente en suspensiones proporcionadas por el módulo Lazy . Estas suspensiones no son seguras para hilos. Por lo tanto, la secuencia memoize xs no debe ser consultada por varios hilos de forma concurrente.

Desde 4.14

excepción Forced_twice

Esta excepción se genera cuando una secuencia devuelta por Seq.once (o un sufijo de la misma) se consulta más de una vez.

Desde 4.14

val once : 'a t -> 'a t

La secuencia once xs tiene los mismos elementos que la secuencia xs .

Independientemente de si xs es efímero o persistente, once xs es una secuencia efímera: se puede consultar como máximo una vez. Si se consulta (o un sufijo de la misma) más de una vez, se genera la excepción Forced_twice . Esto puede ser útil, durante la depuración o las pruebas, para garantizar que una secuencia se consume como máximo una vez.

Desde 4.14

Genera Forced_twice si once xs , o un sufijo de la misma, se consulta más de una vez.

val transpose : 'a t t -> 'a t t

Si xss es una matriz (una secuencia de filas), entonces transpose xss es la secuencia de las columnas de la matriz xss .

No se requiere que las filas de la matriz xss tengan la misma longitud.

No se requiere que la matriz xss sea finita (en ninguna dirección).

La matriz xss debe ser persistente.

Desde 4.14

Combinación de secuencias

val append : 'a t -> 'a t -> 'a t

append xs ys es la concatenación de las secuencias xs y ys .

Sus elementos son los elementos de xs , seguidos por los elementos de ys .

Desde 4.11

val concat : 'a t t -> 'a t

Si xss es una secuencia de secuencias, entonces concat xss es su concatenación.

Si xss es la secuencia xs0; xs1; ... entonces concat xss es la secuencia xs0 @ xs1 @ ... .

Desde 4.13

val flat_map : ('a -> 'b t) -> 'a t -> 'b t

flat_map f xs es equivalente a concat (map f xs) .

val concat_map : ('a -> 'b t) -> 'a t -> 'b t

concat_map f xs es equivalente a concat (map f xs) .

concat_map es un alias de flat_map .

Desde 4.13

val zip : 'a t -> 'b t -> ('a * 'b) t

zip xs ys es la secuencia de pares (x, y) extraídos sincrónicamente de las secuencias xs y ys .

Si las secuencias xs y ys tienen longitudes diferentes, entonces la secuencia termina tan pronto como una secuencia se agota; los elementos sobrantes en la otra secuencia se ignoran.

zip xs ys es equivalente a map2 (fun a b -> (a, b)) xs ys .

Desde 4.14

val map2 : ('a -> 'b -> 'c) -> 'a t -> 'b t -> 'c t

map2 f xs ys es la secuencia de los elementos f x y , donde los pares (x, y) se extraen sincrónicamente de las secuencias xs y ys .

Si las secuencias xs y ys tienen longitudes diferentes, entonces la secuencia termina tan pronto como una secuencia se agota; los elementos sobrantes en la otra secuencia se ignoran.

map2 f xs ys es equivalente a map (fun (x, y) -> f x y) (zip xs ys) .

Desde 4.14

val interleave : 'a t -> 'a t -> 'a t

interleave xs ys es la secuencia que comienza con el primer elemento de xs , continúa con el primer elemento de ys , y así sucesivamente.

Cuando una de las secuencias xs y ys se agota, interleave xs ys continúa con el resto de la otra secuencia.

Desde 4.14

val sorted_merge : ('a -> 'a -> int) -> 'a t -> 'a t -> 'a t

Si las secuencias xs y ys están ordenadas según el preorden total cmp , entonces sorted_merge cmp xs ys es la secuencia ordenada obtenida al fusionar las secuencias xs y ys .

Para más detalles sobre las funciones de comparación, consulte Array.sort .

Desde 4.14

val product : 'a t -> 'b t -> ('a * 'b) t

product xs ys es el producto cartesiano de las secuencias xs y ys .

Para cada elemento x de xs y para cada elemento y de ys , el par (x, y) aparece una vez como elemento de product xs ys .

El orden en que aparecen los pares no está especificado.

No se requiere que las secuencias xs y ys sean finitas.

Las secuencias xs y ys deben ser persistentes.

Desde 4.14

val map_product : ('a -> 'b -> 'c) -> 'a t -> 'b t -> 'c t

La secuencia map_product f xs ys es la imagen a través de f del producto cartesiano de las secuencias xs y ys .

Para cada elemento x de xs y para cada elemento y de ys , el elemento f x y aparece una vez como elemento de map_product f xs ys .

El orden en que aparecen estos elementos no está especificado.

No se requiere que las secuencias xs y ys sean finitas.

Las secuencias xs y ys deben ser persistentes.

map_product f xs ys es equivalente a map (fun (x, y) -> f x y) (product xs ys) .

Desde 4.14

División de una secuencia en dos secuencias

val unzip : ('a * 'b) t -> 'a t * 'b t

unzip transforma una secuencia de pares en un par de secuencias.

unzip xs es equivalente a (map fst xs, map snd xs) .

Consultar cualquiera de las secuencias devueltas por unzip xs hace que xs sea consultada. Por lo tanto, consultarlas ambas hace que xs sea consultada dos veces. Así, xs debe ser persistente y barata. Si no es el caso, use unzip (memoize xs) .

Desde 4.14

val split : ('a * 'b) t -> 'a t * 'b t

split es un alias de unzip .

Desde 4.14

val partition_map : ('a -> ('b, 'c) Either.t) -> 'a t -> 'b t * 'c t

partition_map f xs devuelve un par de secuencias (ys, zs) , donde:

- ys es la secuencia de los elementos y tales que f x = Left y , donde x varía sobre xs ;

- zs es la secuencia de los elementos z tales que f x = Right z , donde x varía sobre xs .

partition_map f xs es equivalente a un par de filter_map Either.find_left (map f xs) y filter_map Either.find_right (map f xs) .

Consultar cualquiera de las secuencias devueltas por partition_map f xs hace que xs sea consultada. Por lo tanto, consultarlas ambas hace que xs sea consultada dos veces. Así, xs debe ser persistente y barata. Si no es el caso, use partition_map f (memoize xs) .

Desde 4.14

val partition : ('a -> bool) -> 'a t -> 'a t * 'a t

partition p xs devuelve un par de la sub-secuencia de los elementos de xs que satisfacen p y la sub-secuencia de los elementos de xs que no satisfacen p .

partition p xs es equivalente a filter p xs, filter (fun x -> not (p x)) xs .

Consumir ambas secuencias devueltas por partition p xs hace que xs sea consumida dos veces y que la función f se aplique dos veces a cada elemento de la lista. Por lo tanto, f debe ser pura y barata. Además, xs debe ser persistente y barata. Si no es el caso, use partition p (memoize xs) .

Desde 4.14

Conversión entre secuencias y dispensadores

Un dispensador es una representación de una secuencia como una función de tipo unit -> 'a option . Cada vez que se invoca esta función, devuelve el siguiente elemento de la secuencia. Cuando no hay más elementos, devuelve None . Un dispensador tiene estado interno mutable, por lo tanto es efímero: la secuencia que representa se puede consumir como máximo una vez.

val of_dispenser : (unit -> 'a option) -> 'a t

of_dispenser it es la secuencia de los elementos producidos por el dispensador it . Es una secuencia efímera: se puede consumir como máximo una vez. Si se necesita una secuencia persistente, use memoize (of_dispenser it) .

Desde 4.14

val to_dispenser : 'a t -> unit -> 'a option

to_dispenser xs es un nuevo dispensador en la secuencia xs .

Este dispensador tiene estado interno mutable, que no está protegido por un bloqueo; por lo tanto, no debe ser utilizado por varios hilos de forma concurrente.

Desde 4.14

Secuencias de enteros

val ints : int -> int t

ints i es la secuencia infinita de los enteros que comienzan en i y aumentan.
