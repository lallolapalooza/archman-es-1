DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que se pueden utilizar tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simple
  3. Colas de cola enlazadas simple
  4. Colas de cola
Las cuatro estructuras admiten la siguiente funcionalidad:
  1. Inserción de una nueva entrada al principio de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento de la lista.
  3. Eliminación en O(1) de una entrada del principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simple son las más sencillas de las cuatro estructuras de datos y solo admiten la funcionalidad anterior. Las listas enlazadas simple son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO. Las listas enlazadas simple añaden la siguiente funcionalidad:

  1. Eliminación en O(n) de cualquier entrada de la lista.
  2. Concatenación en O(n) de dos listas.

Las colas de cola enlazadas simple añaden la siguiente funcionalidad:

  1. Las entradas se pueden añadir al final de una lista.
  2. Eliminación en O(n) de cualquier entrada de la lista.
  3. Se pueden concatenar.
Sin embargo:
  1. Todas las inserciones de lista deben especificar la cabecera de la lista.
  2. Cada entrada de cabecera requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lentas que las listas enlazadas simple.

Las colas de cola enlazadas simple son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO.

Todos los tipos de estructuras de datos enlazadas doblemente (listas y colas de cola) permiten además:

  1. Inserción de una nueva entrada antes de cualquier elemento de la lista.
  2. Eliminación en O(1) de cualquier entrada de la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que el de las estructuras de datos enlazadas simple.

Las listas enlazadas son las más sencillas de las estructuras de datos enlazadas doblemente. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación en O(n) de dos listas.
  2. Se pueden recorrer hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para comenzar el recorrido y la lista en la que está contenida.

Las colas de cola añaden la siguiente funcionalidad:

  1. Las entradas se pueden añadir al final de una lista.
  2. Se pueden recorrer hacia atrás, de cola a cabeza.
  3. Se pueden concatenar.
Sin embargo:
  1. Todas las inserciones y eliminaciones de lista deben especificar la cabecera de la lista.
  2. Cada entrada de cabecera requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lentas que las listas enlazadas simple.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que sea de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que sea de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse utilizando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, o TAILQ_CLASS_HEAD. Consulte los ejemplos a continuación para obtener más explicaciones sobre cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLE

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para obtener una sobrecarga mínima de espacio y manipulación de punteros a costa de una eliminación en O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabecera de la lista puede declararse posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro, ya que recorre la totalidad de la lista head1. Se debe utilizar una cola de cola enlazada simple si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta de manera idéntica a SLIST_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí se permite eliminar var así como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

SLIST_HEAD

Una lista enlazada simple se encabeza con una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden agregar a la lista después de un elemento existente, o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

El uso de esta macro debe evitarse ya que recorre la lista head1 en su totalidad. Se debe usar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH, aquí se permite eliminar var así como liberarlo dentro del bucle de forma segura sin interferir con la traversa.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_REMOVE_AFTER elimina el elemento después de elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm de la cabeza de la lista. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Debe evitarse el uso de esta macro ya que recorre toda la lista. Se debe usar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);

struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Lista enlazada simple. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Inicializa la lista. */

n2 = malloc(sizeof(struct entry));	/* Inserta después. */

SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación. */

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación desde la cabeza. */
free(n3);
					/* Traversía hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Traversía segura hacia adelante. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {

COLAS DE EXTREMO ENLAZADAS SIMPLES

Una cola de extremo enlazada simple se encabeza con una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de extremo y otro al último elemento de la cola de extremo. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden agregar a la cola de extremo después de un elemento existente, al principio de la cola de extremo o al final de la cola de extremo. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a enlazar en la cola de extremo. Un puntero a la cabeza de la cola de extremo se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de extremo head.

La macro STAILQ_CONCAT concatena la cola de extremo encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de extremo.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola de extremo.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de extremo o NULL si la cola de extremo está vacía.

La macro STAILQ_FOREACH recorre la cola de extremo referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de extremo referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí se permite eliminar var así como liberarlo dentro del bucle de forma segura sin interferir con la traversa.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola de extremo referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de extremo.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de extremo.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de extremo. Si la cola de extremo está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de extremo, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola de extremo. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola de extremo.

La macro STAILQ_REMOVE_HEAD elimina el elemento al principio de la cola de extremo. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la cola de extremo deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola de extremo. Debe evitarse el uso de esta macro ya que recorre toda la lista. Se debe usar una cola de extremo doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas de extremo largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

	...

n1 = malloc(sizeof(struct entry));	/* Inserta al final. */

					/* Eliminación desde la cabeza. */

free(n3);
					/* Traversía hacia adelante. */

	np-> ...
					/* Traversía segura hacia adelante. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);

	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);

	free(n1);
	n1 = n2;

LISTAS

Una lista se encabeza con una estructura definida por la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma doble para que un elemento arbitrario pueda eliminarse sin recorrer la lista. Los nuevos elementos se pueden agregar a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. El uso de esta macro debe evitarse ya que recorre la totalidad de la lista head1. Se debe usar una cola de extremo si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por hea

DESCRIPTION The LIST macros provide a facility for the manipulation of doubly-linked lists. The TAILQ macros provide a facility for the manipulation of doubly-linked lists that have, in addition, pointers to the first and last elements in the tail queue. The LIST macros manipulate lists which are headed by a structure defined by the LIST_HEAD macro. This structure contains a pointer to the first element in the list. The elements are doubly linked so that an arbitrary element can be removed without traversing the list. New elements can be added to the list before an existing element or after an existing element. A LIST_HEAD structure is declared as follows: .diag LIST_HEAD(HEADNAME, TYPE) head; .diag where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as: .diag struct HEADNAME *headp; .diag (The names head and headp are user selectable.) The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head. The macro LIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1. The macro LIST_EMPTY evaluates to true if there are no items on the list. The macro LIST_ENTRY declares a structure that connects the elements in the list. The macro LIST_FIRST returns the first item on the list or NULL if the list is empty. The macro LIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var. The macro LIST_FOREACH_FROM behaves identically to LIST_FOREACH when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head. The macro LIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike LIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal. The macro LIST_FOREACH_FROM_SAFE behaves identically to LIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head. The macro LIST_INIT initializes the list referenced by head. The macro LIST_INSERT_HEAD inserts the new element elm at the head of the list. The macro LIST_INSERT_AFTER inserts the new element elm after the element listelm. The macro LIST_INSERT_BEFORE inserts the new element elm before the element listelm. The macro LIST_NEXT returns the next element in the list, or NULL if this is the last. The macro LIST_PREV returns the previous element in the list, or NULL if this is the first. List head must contain element elm. The macro LIST_REMOVE removes the element elm from the list. The macro LIST_SWAP swaps the contents of head1 and head2. DIAGNÓSTICOS

Al depurar queue(3), puede ser útil trazar los cambios de la cola. Para habilitar el trazado, defina el macro QUEUE_MACRO_DEBUG_TRACE en el momento de la compilación.

También puede ser útil "ensuciar" los punteros que han sido desvinculados de una cola, para detectar su uso después de la eliminación. Para habilitar el "ensuciamiento" de punteros, defina el macro QUEUE_MACRO_DEBUG_TRASH en el momento de la compilación. El macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido "ensuciado" por la opción QUEUE_MACRO_DEBUG_TRASH.
