DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser usadas tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simples
  3. Colas finales enlazadas simples
  4. Colas finales
Las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de una nueva entrada al principio de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento de la lista.
  3. Eliminación en O(1) de una entrada del principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más simples de las cuatro estructuras de datos y solo soportan la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO. Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación en O(n) de cualquier entrada en la lista.
  2. Concatenación en O(n) de dos listas.

Las colas finales enlazadas simples añaden la siguiente funcionalidad:

  1. Las entradas pueden ser añadidas al final de una lista.
  2. Eliminación en O(n) de cualquier entrada en la lista.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones de lista deben especificar la cabecera de la lista.
  2. Cada entrada de cabecera requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones corren aproximadamente un 20% más lento que las listas enlazadas simples.

Las colas finales enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO.

Todos los tipos de estructuras de datos enlazadas doblemente (listas y colas finales) permiten adicionalmente:

  1. Inserción de una nueva entrada antes de cualquier elemento en la lista.
  2. Eliminación en O(1) de cualquier entrada en la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que el de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más simples de las estructuras de datos enlazadas doblemente. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación en O(n) de dos listas.
  2. Pueden ser recorridas hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para comenzar el recorrido y la lista en la que está contenida.

Las colas finales añaden la siguiente funcionalidad:

  1. Las entradas pueden ser añadidas al final de una lista.
  2. Pueden ser recorridas hacia atrás, de cola a cabeza.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de lista deben especificar la cabecera de la lista.
  2. Cada entrada de cabecera requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones corren aproximadamente un 20% más lento que las listas enlazadas simples.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que sea del tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que sea del tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe ser declarada usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, o TAILQ_CLASS_HEAD. Ver los ejemplos a continuación para una explicación más detallada de cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados simplemente para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación en O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Posteriormente, se puede declarar un puntero a la cabecera de la lista como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro, ya que recorre la totalidad de la lista head1. Se debe usar una cola final enlazada simple si se necesita esta macro en rutas de código de alto uso o para operar sobre listas largas.

La macro SLIST_EMPTY se evalúa como true si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí está permitido eliminar var así como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento

LISTAS SIMPLEMENTE ENLAZADAS

Una lista simplemente enlazada está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simplemente enlazada para minimizar el espacio y la sobrecarga de manipulación de punteros, a expensas de una complejidad O(n) para la eliminación de elementos arbitrarios. Los nuevos elementos se pueden añadir a la lista después de un elemento existente, o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero al encabezado de la lista se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento sucesivamente a var.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento sucesivamente a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí se permite eliminar var así como liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento que sigue a elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deberían usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro, ya que recorre toda la lista. Se debería utilizar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

COLAS DE DATOS SIMPLEMENTE ENLAZADAS

Una cola de datos simplemente enlazada está encabezada por una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de datos y otro al último elemento de la cola de datos. Los elementos están enlazados de forma simplemente enlazada para minimizar el espacio y la sobrecarga de manipulación de punteros, a expensas de una complejidad O(n) para la eliminación de elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola de datos después de un elemento existente, al principio de la cola de datos o al final de la cola de datos. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir y TYPE es el tipo de los elementos que se enlazarán en la cola de datos. Un puntero al encabezado de la cola de datos se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de datos head.

La macro STAILQ_CONCAT concatena la cola de datos encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de datos.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos de la cola de datos.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de datos o NULL si la cola de datos está vacía.

La macro STAILQ_FOREACH recorre la cola de datos referenciada por head en dirección hacia adelante, asignando cada elemento sucesivamente a var.

La macro STAILQ_FOREACH_FROM se comporta idénticamente a STAILQ_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de datos referenciada por head en dirección hacia adelante, asignando cada elemento sucesivamente a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí se permite tanto eliminar var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta idénticamente a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola de datos referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de datos.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de datos.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de datos. Si la cola de datos está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de datos, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento que sigue a elm de la cola de datos. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola de datos.

La macro STAILQ_REMOVE_HEAD elimina el elemento del principio de la cola de datos. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola de datos deberían usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola de datos. Se debe evitar el uso de esta macro, ya que recorre toda la lista. Se debería utilizar una cola de datos doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas de datos largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE COLA DE DATOS SIMPLEMENTE ENLAZADA

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Encabezado de cola de datos simplemente enlazada. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Cola de datos. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializar la cola. */

n1 = malloc(sizeof(struct entry));	/* Insertar al principio. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertar al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminación. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminación desde el principio. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido hacia adelante seguro. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Eliminación de la cola de datos. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Eliminación más rápida de la cola de datos. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS

Una lista está encabezada por una estructura definida por la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están doblemente enlazados para que un elemento arbitrario pueda ser eliminado sin recorrer la lista. Los nuevos elementos se pueden añadir a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero al encabezado de la lista se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro, ya que recorre la totalidad de la lista head1. Se debería utilizar una cola de datos si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por h

LIST EXAMPLE

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Cabeza de lista. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Lista. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Inicializa la lista. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Inserta antes. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Borrado. */
free(n2);
					/* Recorrido hacia adelante. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Recorrido hacia adelante seguro. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* Borrado de lista. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Borrado de lista más rápido. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

TAIL QUEUES

Una cola de punteros está dirigida por una estructura definida mediante la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de punteros y otro al último elemento de la cola de punteros. Los elementos están enlazados doblemente, permitiendo la eliminación de cualquier elemento sin recorrer la cola de punteros. Se pueden agregar nuevos elementos a la cola de punteros después de un elemento existente, antes de un elemento existente, al principio de la cola de punteros o al final de la cola de punteros. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos enlazados en la cola de punteros. Un puntero a la cabeza de la cola de punteros puede declararse más tarde de la siguiente manera:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola de punteros head.

La macro TAILQ_CONCAT concatena la cola de punteros dirigida por head2 al final de la cola de punteros dirigida por head1, vaciando la primera.

La macro TAILQ_EMPTY se evalúa como true si no hay elementos en la cola de punteros.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos de la cola de punteros.

La macro TAILQ_FIRST devuelve el primer elemento de la cola de punteros o NULL si la cola está vacía.

La macro TAILQ_FOREACH recorre la cola de punteros dirigida por head hacia adelante, asignando cada elemento en orden a var. var se establece a NULL si el bucle termina normalmente, o si no hay elementos.

La macro TAILQ_FOREACH_FROM se comporta de forma idéntica a TAILQ_FOREACH cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la cola de punteros y comienza el bucle en var en lugar del primer elemento de la cola de punteros dirigida por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de punteros dirigida por head hacia atrás, asignando cada elemento en orden a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta de forma idéntica a TAILQ_FOREACH_REVERSE cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la cola de punteros y comienza el bucle en var en lugar del último elemento de la cola de punteros dirigida por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista dirigida por head hacia adelante o hacia atrás, asignando cada elemento en orden a var. Sin embargo, a diferencia de sus contrapartes no seguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten eliminar var y liberar su espacio dentro del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta de forma idéntica a TAILQ_FOREACH_SAFE cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la cola de punteros y comienza el bucle en var en lugar del primer elemento de la cola de punteros dirigida por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta de forma idéntica a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la cola de punteros y comienza el bucle en var en lugar del último elemento de la cola de punteros dirigida por head.

La macro TAILQ_INIT inicializa la cola de punteros dirigida por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de punteros.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de punteros.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola de punteros. Si la cola está vacía, el valor devuelto es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento de la cola de punteros, o NULL si este es el último.

La macro TAILQ_PREV devuelve el elemento anterior de la cola de punteros, o NULL si este es el primero.

La macro TAILQ_REMOVE quita el elemento elm de la cola de punteros.

La macro TAILQ_SWAP intercambia los contenidos de head1 y head2.

TAIL QUEUE EXAMPLE

TAILQ_HEAD(tailhead, entry) head =
    TAILQ_HEAD_INITIALIZER(head);
struct tailhead *headp;			/* Cabeza de cola de punteros. */
struct entry {
	...
	TAILQ_ENTRY(entry) entries;	/* Cola de punteros. */
	...
} *n1, *n2, *n3, *np;

TAILQ_INIT(&head);			/* Inicializa la cola. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
TAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Inserta al final. */
TAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
TAILQ_INSERT_AFTER(&head, n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Inserta antes. */
TAILQ_INSERT_BEFORE(n2, n3, entries);

TAILQ_REMOVE(&head, n2, entries);	/* Borrado. */
free(n2);
					/* Recorrido hacia adelante. */
TAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido hacia adelante seguro. */
TAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	TAILQ_REMOVE(&head, np, entries);
	free(np);
}
					/* Recorrido inverso. */
TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
	np-> ...
					/* Borrado de TailQ. */
while (!TAILQ_EMPTY(&head)) {
	n1 = TAILQ_FIRST(&head);
	TAILQ_REMOVE(&head, n1, entries);
	free(n1);
}
					/* Borrado de TailQ más rápido. */
n1 = TAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = TAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
TAILQ_INIT(&head);

DIAGNÓSTICO

Al depurar queue(3), puede ser útil rastrear los cambios en las colas. Para habilitar el rastreo, defina la macro QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.

También puede ser útil "desordenar" los punteros que se han desvinculado de una cola, para detectar el uso después de la eliminación. Para habilitar el "desordenado" de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH en tiempo de compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido "desordenado" por la opción QUEUE_MACRO_DEBUG_TRASH.
