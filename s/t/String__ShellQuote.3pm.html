NOMBRE

String::ShellQuote - citar cadenas para pasarlas a través del shell

SINOPSIS

$cadena = shell_quote @lista;
$cadena = shell_quote_best_effort @lista;
$cadena = shell_comment_quote $cadena;

DESCRIPCIÓN

Este módulo contiene algunas funciones que son útiles para citar cadenas que van a pasar a través del shell o un objeto similar a un shell.

shell_quote [cadena]...
shell_quote cita cadenas para que puedan pasarse a través del shell. Cada cadena se cita de tal manera que el shell la pase como un argumento único y sin más interpretación. Si no se proporcionan cadenas, se devuelve una cadena vacía.

Si alguna cadena no se puede citar de forma segura, shell_quote realizará un croak (generará un error fatal).

shell_quote_best_effort [cadena]...
Esto es como shell_quote, excepto que si la cadena no se puede citar de forma segura, hace lo mejor que puede y devuelve el resultado, en lugar de fallar.
shell_comment_quote [cadena]
shell_comment_quote cita la cadena para que pueda incluirse de forma segura en un comentario estilo shell (el algoritmo actual es que se coloca un carácter de almohadilla (#) después de cualquier salto de línea en la cadena).

Esta rutina podría modificarse para aceptar múltiples argumentos de cadena en el futuro. Todavía no lo he hecho porque no estoy seguro de si las cadenas deben unirse con espacios ($") o nada ($,). ¡Emite tu voto hoy! Asegúrate de justificar tu respuesta.

EJEMPLOS

$cmd = 'fuser 2>/dev/null ' . shell_quote @archivos;
@pids = split ' ', `$cmd`;
print CFG "# Configurado por: ",
            shell_comment_quote($ENV{LOGNAME}), "\n";

ERRORES

Solo se admite el citado del shell Bourne. Me gustaría añadir otros shells (en particular cmd.exe), pero no los conozco. Sería de gran ayuda si alguien proporcionara los detalles.
