NOMBRE

String::Format - capacidades de formateo de cadenas tipo sprintf con definiciones de formato arbitrarias

RESUMEN

String::Format permite capacidades de formateo estilo sprintf con definiciones de formato arbitrarias

SINOPSIS

use String::Format;
my %fruit = (
      'a' => "manzanas",
      'b' => "plátanos",
      'g' => "pomelos",
      'm' => "melones",
      'w' => "sandías",
);
my $format = "Me gustan las %a, los %b, y los %g, pero no los %m ni las %w.";
print stringf($format, %fruit);

# imprime:
# Me gustan las manzanas, los plátanos, y los pomelos, pero no los melones ni las sandías.

DESCRIPCIÓN

String::Format te permite definir secuencias de formato arbitrarias, similares a printf, para ser expandidas. Este módulo sería más útil en archivos de configuración y herramientas de informes, donde los resultados de una consulta necesitan ser formateados de una manera particular. Se inspiró en el formato index_format de mutt y directivas relacionadas (ver <URL:http://www.mutt.org/doc/manual/manual-6.html#index_format>).

FUNCIONES

stringf

String::Format exporta una única función llamada stringf. stringf toma dos argumentos: una cadena de formato (ver CADENAS DE FORMATO, abajo) y una referencia a un hash de pares nombre => valor. Estos pares nombre => valor son lo que se expandirá en la cadena de formato.

CADENAS DE FORMATO

Las cadenas de formato deben coincidir con la siguiente expresión regular:

qr/
   (%             # '%' inicial
    (-)?          # alinear a la izquierda, en lugar de a la derecha
    (\d*)?        # (opcional) ancho mínimo de campo
    (?:\.(\d*))?  # (opcional) ancho máximo de campo
    ({.*?})?      # (opcional) contenido interno
    (\S)          # carácter de formato real
   )/x;

Si el carácter de escape especificado no existe en %args, entonces se utiliza la cadena original. Las opciones de alineación, ancho mínimo y ancho máximo funcionan idénticamente a como se definen en sprintf(3) (cualquier variación es un error y debería ser reportada).

Tenga en cuenta que la definición de sprintf de Perl es un poco más liberal que la regex anterior; las desviaciones fueron intencionales y todas se refieren al formato numérico (los prefijos #, 0 y + fueron omitidos específicamente).

El valor adjunto a la clave puede ser un valor escalar o una referencia a una subrutina; si es una referencia a una subrutina, entonces cualquier cosa entre '{' y '}' ($5 en la regex anterior) se pasará como $_[0] a la referencia de la subrutina. Esto permite entradas como esta:

%args = (
    d => sub { POSIX::strftime($_[0], localtime) }, 
);

Que puede ser invocada con esta cadena de formato:

"Son las %{%M:%S}d ahora, el %{%A, %B %e}d."

Y resultar en (por ejemplo):

Son las 17:45 ahora, el Lunes, Febrero 4.

Tenga en cuenta que, dado que la cadena se pasa sin modificar a la referencia de la subrutina, y strftime haría lo correcto con estos datos, la cadena de formato anterior podría escribirse como:

"Son las %{%M:%S ahora, el %A, %B %e}d."

Por defecto, los formatos 'n', 't', y '%' se definen como una nueva línea, tabulación y '%', respectivamente, si no están ya definidos en el hashref de argumentos que se le pasa. Así que podemos añadir saltos de línea simplemente:

"Son las %{%M:%S ahora, el %A, %B %e}d.%n"

Debido a cómo se analiza la cadena, los caracteres normales "\n" y "\t" se convierten en dos caracteres cada uno, y no se tratan como una nueva línea y una tabulación. Esto es un error.

METODO FABRICA

String::Format también soporta un método de clase, llamado stringfactory, que devolverá una referencia a una subrutina "preparada". stringfactory debe recibir una referencia a un hash de valores; la subrutina devuelta usará estos valores como el hash %args.

my $self = Some::Groovy::Package->new($$, $<, $^T);
my %formats = (
      'i' => sub { $self->id      },
      'd' => sub { $self->date    },
      's' => sub { $self->subject },
      'b' => sub { $self->body    },
);
my $index_format = String::Format->stringfactory(\%formats);
print $index_format->($format1);
print $index_format->($format2);

Esta referencia a subrutina puede asignarse a una entrada de tabla de símbolos local y llamarse normalmente, por supuesto:

*reformat = String::Format->stringfactory(\%formats);
my $reformed = reformat($format_string);
