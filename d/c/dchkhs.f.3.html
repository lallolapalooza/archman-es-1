DCHKHS

Propósito:

!>
!>    DCHKHS comprueba las rutinas del problema de valores propios no simétrico.
!>
!>            DGEHRD factoriza A como  U H U' , donde ' significa transpuesta,
!>            H es hessenberg, y U es una matriz ortogonal.
!>
!>            DORGHR genera la matriz ortogonal U.
!>
!>            DORMHR multiplica una matriz por la matriz ortogonal U.
!>
!>            DHSEQR factoriza H como  Z T Z' , donde Z es ortogonal y
!>            T es , y el vector de valores propios W.
!>
!>            DTREVC calcula las matrices de vectores propios izquierdos y derechos
!>            L y R para T. L es cuasi-triangular inferior, y R es
!>            cuasi-triangular superior.
!>
!>            DHSEIN calcula las matrices de vectores propios izquierdos y derechos
!>            Y y X para H, usando iteración inversa.
!>
!>            DTREVC3 calcula matrices de vectores propios izquierdos y derechos
!>            a partir de una matriz de Schur T y las retrotransforma con Z
!>            a matrices de vectores propios L y R para A. L y R son
!>            matrices GE.
!>
!>    Cuando se llama a DCHKHS, se especifica un número de matrices  () y un
!>    número de matrices . Para cada tamaño ()
!>    y cada tipo de matriz, se generará una matriz y se usará
!>    para probar las rutinas no simétricas de valores propios. Para cada matriz, se realizarán 16
!>    pruebas:
!>
!>    (1)     | A - U H U**T | / ( |A| n ulp )
!>
!>    (2)     | I - UU**T | / ( n ulp )
!>
!>    (3)     | H - Z T Z**T | / ( |H| n ulp )
!>
!>    (4)     | I - ZZ**T | / ( n ulp )
!>
!>    (5)     | A - UZ H (UZ)**T | / ( |A| n ulp )
!>
!>    (6)     | I - UZ (UZ)**T | / ( n ulp )
!>
!>    (7)     | T(Z calculado) - T(Z no calculado) | / ( |T| ulp )
!>
!>    (8)     | W(Z calculado) - W(Z no calculado) | / ( |W| ulp )
!>
!>    (9)     | TR - RW | / ( |T| |R| ulp )
!>
!>    (10)    | L**H T - W**H L | / ( |T| |L| ulp )
!>
!>    (11)    | HX - XW | / ( |H| |X| ulp )
!>
!>    (12)    | Y**H H - W**H Y | / ( |H| |Y| ulp )
!>
!>    (13)    | AX - XW | / ( |A| |X| ulp )
!>
!>    (14)    | Y**H A - W**H Y | / ( |A| |Y| ulp )
!>
!>    (15)    | AR - RW | / ( |A| |R| ulp )
!>
!>    (16)    | LA - WL | / ( |A| |L| ulp )
!>
!>    Los  se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1's en la diagonal.
!>
!>    (4)  Una matriz diagonal con elementos espaciados uniformemente
!>         1, ..., ULP  y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con elementos espaciados geométricamente
!>         1, ..., ULP  y signos aleatorios.
!>    (6)  Una matriz diagonal con  elementos 1, ULP, ..., ULP
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!>    (8)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento por defecto )
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene elementos espaciados uniformemente 1, ..., ULP con signos aleatorios
!>         en la diagonal y elementos aleatorios O(1) en el triángulo
!>         superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene elementos espaciados geométricamente 1, ..., ULP con signos
!>         aleatorios en la diagonal y elementos aleatorios O(1) en el triángulo
!>         superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene  elementos 1, ULP,..., ULP con signos
!>         aleatorios en la diagonal y elementos aleatorios O(1) en el triángulo
!>         superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene valores propios reales o pares conjugados complejos
!>         elegidos aleatoriamente de ( ULP, 1 ) y elementos aleatorios O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene elementos espaciados uniformemente 1, ..., ULP
!>         con signos aleatorios en la diagonal y elementos aleatorios O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene elementos espaciados geométricamente
!>         1, ..., ULP con signos aleatorios en la diagonal y elementos
!>         aleatorios O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene  elementos 1, ULP,..., ULP
!>         con signos aleatorios en la diagonal y elementos aleatorios O(1)
!>         en el triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios reales o pares conjugados
!>         complejos elegidos aleatoriamente de ( ULP, 1 ) y elementos
!>         aleatorios O(1) en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicada por SQRT( desbordamientoow threshold )
!>    (18) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>    (20) Igual que (19), pero multiplicado por SQRT( umbral de desbordamiento )
!>    (21) Igual que (19), pero multiplicado por SQRT( umbral de desbordamiento )
!> 
!>  NSIZES - INTEGER
!>           El número de tamaños de matrices a usar. Si es cero,
!>           DCHKHS no hace nada. Debe ser al menos cero.
!>           No modificado.
!>
!>  NN     - INTEGER array, dimension (NSIZES)
!>           Un array que contiene los tamaños a usar para las matrices.
!>           Los valores cero serán omitidos. Los valores deben ser al menos
!>           cero.
!>           No modificado.
!>
!>  NTYPES - INTEGER
!>           El número de elementos en DOTYPE. Si es cero, DCHKHS
!>           no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>           y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>           que es usar cualquier matriz que esté en A. Esto
!>           solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>           DOTYPE(MAXTYP+1) es .TRUE. .
!>           No modificado.
!>
!>  DOTYPE - LOGICAL array, dimension (NTYPES)
!>           Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN una
!>           matriz de ese tamaño y tipo j será generada.
!>           Si NTYPES es menor que el número máximo de tipos
!>           definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>           MAXTYP no serán generados. Si NTYPES es mayor
!>           que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>           serán ignorados.
!>           No modificado.
!>
!>  ISEED  - INTEGER array, dimension (4)
!>           En la entrada ISEED especifica la semilla del generador de
!>           números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>           si no lo están, serán reducidos módulo 4096. Además, ISEED(4) debe
!>           ser impar. El generador de números aleatorios utiliza una secuencia
!>           congruencial lineal limitada a enteros pequeños, y por lo tanto
!>           debería producir números aleatorios independientes de la máquina. Los
!>           valores de ISEED se modifican a la salida y pueden ser usados en la
!>           siguiente llamada a DCHKHS para continuar la misma secuencia de
!>           números aleatorios.
!>           Modificado.
!>
!>  THRESH - DOUBLE PRECISION
!>           Una prueba se contará como superada si el error,
!>           calculado como se describe arriba, excede THRESH. Tenga en cuenta
!>           que el error está escalado para ser O(1), por lo que THRESH debe
!>           ser un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100. En
!>           particular, no debe depender de la precisión (simple o doble)
!>           ni del tamaño de la matriz. Debe ser al menos cero.
!>           No modificado.
!>
!>  NOUNIT - INTEGER
!>           El número de unidad de FORTRAN para imprimir mensajes de error
!>           (por ejemplo, si una rutina devuelve IINFO distinto de 0).
!>           No modificado.
!>
!>  A      - DOUBLE PRECISION array, dimension (LDA,max(NN))
!>           Se usa para contener la matriz cuyos valores propios se van a
!>           calcular. A la salida, A contiene la última matriz utilizada.
!>           Modificado.
!>
!>  LDA    - INTEGER
!>           La dimensión principal de A, H, T1 y T2. Debe ser
!>           al menos 1 y al menos max( NN ).
!>           No modificado.
!>
!>  H      - DOUBLE PRECISION array, dimension (LDA,max(NN))
!>           La matriz de Hessenberg superior calculada por DGEHRD. A la
!>           salida, H contiene la forma de Hessenberg de la matriz en A.
!>           Modificado.
!>
!>  T1     - DOUBLE PRECISION array, dimension (LDA,max(NN))
!>           La matriz de Schur (=) calculada por DHSEQR
!>           si se calcula Z. A la salida, T1 contiene la forma de Schur de
!>           la matriz en A.
!>           Modificado.
!>
!>  T2     - DOUBLE PRECISION array, dimension (LDA,max(NN))
!>           La matriz de Schur calculada por DHSEQR cuando Z no se calcula.
!>           Debería ser idéntica a T1.
!>           Modificado.
!>
!>  LDU    - INTEGER
!>           La dimensión principal de U, Z, UZ y UU. Debe ser
!>           al menos 1 y al menos max( NN ).
!>           No modificado.
!>
!>  U      - DOUBLE PRECISION array, dimension (LDU,max(NN))
!>           La matriz ortogonal calculada por DGEHRD.
!>           Modificado.
!>
!>  Z      - DOUBLE PRECISION array, dimension (LDU,max(NN))
!>           La matriz ortogonal calculada por DHSEQR.
!>           Modificado.
!>
!>  UZ     - DOUBLE PRECISION array, dimension (LDU,max(NN))
!>           El producto de U por Z.
!>           Modificado.
!>
!>  WR1    - DOUBLE PRECISION array, dimension (max(NN))
!>  WI1    - DOUBLE PRECISION array, dimension (max(NN))
!>           Las partes real e imaginaria de los valores propios de A,
!>           tal como se calcularon cuando se calculó Z.
!>           A la salida, WR1 + WI1*i son los valores propios de la matriz en A.
!>           Modificado.
!>
!>  WR2    - DOUBLE PRECISION array, dimension (max(NN))
!>  WI2    - DOUBLE PRECISION array, dimension (max(NN))
!>           Las partes real e imaginaria de los valores propios de A,
!>           tal como se calcularon cuando se calculó T pero no Z.
!>           A la salida, WR2 + WI2*i son los valores propios de la matriz en A.
!>           Modificado.
!>
!>  WR3    - DOUBLE PRECISION array, dimension (max(NN))
!>  WI3    - DOUBLE PRECISION array, dimension (max(NN))
!>           Similar a WR1, WI1, estos arrays contienen los valores propios de A,
!>           pero aquellos calculados cuando DHSEQR solo calcula los
!>           valores propios, es decir, no los vectores de Schur ni más de la
!>           forma de Schur de lo necesario para calcular los
!>           valores propios.
!>           Modificado.
!>
!>  EVECTL - DOUBLE PRECISION array, dimension (LDU,max(NN))
!>           La matriz de vectores propios (triangular superior) izquierdos para la
!>           matriz en T1. Para pares conjugados complejos, la parte real
!>           se almacena en una fila y la parte imaginaria en la siguiente.
!>           Modificado.
!>
!>  EVEZTR - DOUBLE PRECISION array, dimension (LDU,max(NN))
!>           La matriz de vectores propios (triangular superior) derechos para la
!>           matriz en T1. Para pares conjugados complejos, la parte real
!>           se almacena en una columna y la parte imaginaria en la siguiente.
!>           Modificado.
!>
!>  EVECTY - DOUBLE PRECISION array, dimension (LDU,max(NN))
!>           La matriz de vectores propios izquierdos para la
!>           matriz en H. Para pares conjugados complejos, la parte real
!>           se almacena en una fila y la parte imaginaria en la siguiente.
!>           Modificado.
!>
!>  EVECTX - DOUBLE PRECISION array, dimension (LDU,max(NN))
!>           La matriz de vectores propios derechos para la
!>           matriz en H. Para pares conjugados complejos, la parte real
!>           se almacena en una columna y la parte imaginaria en la siguiente.
!>           Modificado.
!>
!>  UU     - DOUBLE PRECISION array, dimension (LDU,max(NN))
!>           Detalles de la matriz ortogonal calculada por DGEHRD.
!>           Modificado.
!>
!>  TAU    - DOUBLE PRECISION array, dimension(max(NN))
!>           Detalles adicionales de la matriz ortogonal calculada por DGEHRD.
!>           Modificado.
!>
!>  WORK   - DOUBLE PRECISION array, dimension (NWORK)
!>           Espacio de trabajo.
!>           Modificado.
!>
!>  NWORK  - INTEGER
!>           El número de entradas en WORK. NWORK >= 4*NN(j)*NN(j) + 2.
!>
!>  IWORK  - INTEGER array, dimension (max(NN))
!>           Espacio de trabajo.
!>           Modificado.
!>
!>  SELECT - LOGICAL array, dimension (max(NN))
!>           Espacio de trabajo.
!>           Modificado.
!>
!>  RESULT - DOUBLE PRECISION array, dimension (16)
!>           Los valores calculados por las catorce pruebas descritas
!>           anteriormente. Los valores están actualmente limitados a 1/ulp, para
!>           evitar desbordamiento.
!>           Modificado.
!>
!>  INFO   - INTEGER
!>           Si es 0, entonces todo funcionó correctamente.
!>            -1: NSIZES < 0
!>            -2: Algún NN(j) < 0
!>            -3: NTYPES < 0
!>            -6: THRESH < 0
!>            -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>           -14: LDU < 1 o LDU < NMAX.
!>           -28: NWORK es demasiado pequeño.
!>           Si DLATMR, SLATMS o SLATME devuelven un código de error, su
!>           valor absoluto se devuelve.
!>           Si es 1, entonces DHSEQR no pudo encontrar todos los shifts.
!>           Si es 2, entonces el código EISPACK (para bloques pequeños) falló.
!>           Si es >2, entonces 30*N iteraciones no fueron suficientes para encontrar
!>               un valor propio o para descomponer el problema.
!>           Modificado.
!>
!>-----------------------------------------------------------------------
!>
!>     Algunas variables y parámetros locales:
!>     ---- ----- --------- --- ----------
!>
!>     ZERO, ONE       Reales 0 y 1.
!>     MAXTYP          El número de tipos definidos.
!>     MTEST           El número de pruebas definidas: se debe tener cuidado
!>                     de que (1) el tamaño de RESULT, (2) el número de
!>                     pruebas realizadas, y (3) MTEST coincidan.
!>     NTEST           El número de pruebas realizadas en esta matriz
!>                     hasta ahora. Este debe ser menor que MTEST, e
!>                     igual a él en la última prueba. Será menor
!>                     si alguna de las rutinas probadas indica
!>                     que no pudo calcular las matrices que
!>                     serían probadas.
!>     NMAX            El valor más grande en NN.
!>     NMATS           El número de matrices generadas hasta ahora.
!>     NERRS           El número de pruebas que han excedido THRESH
!>                     hasta ahora (calculado por DLAFTS).
!>     COND, CONDS,
!>     IMODE           Valores a pasar a los generadores de matrices.
!>     ANORM           Norma de A; se pasa a los generadores de matrices.
!>
!>     OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>     ULP, ULPINV     Precisión relativa más fina y su inversa.
!>     RTOVFL, RTUNFL,
!>     RTULP, RTULPI   Raíces cuadradas de los 4 valores anteriores.
!>
!>             Los siguientes cuatro arrays decodifican JTYPE:
!>     KTYPE(j)        El tipo general (1-10) para el tipo j.
!>     KMODE(j)        El valor MODE a pasar al generador de matrices
!>                     para el tipo j.
!>     KMAGN(j)        El orden de magnitud ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) ) )
!>     KCONDS(j)       Selecciona si CONDS debe ser 1 o
!>                     1/sqrt(ulp). (0 significa irrelevante.)
!>
