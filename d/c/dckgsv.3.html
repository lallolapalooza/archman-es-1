DCKGS

V

Propósito

: 
!>
!> DCKGSV prueba DGGSVD:
!>        el GSVD para la matriz A de M por N y la matriz B de P por N.
!
>

Parámetro

s
NM 
!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!
>

MVA

L 
!>          MVAL es un array INTEGER, dimensión (NM)
!>          Los valores de la dimensión de filas de la matriz M.
!
>

PVA

L 
!>          PVAL es un array INTEGER, dimensión (NP)
!>          Los valores de la dimensión de filas de la matriz P.
!
>

NVA

L 
!>          NVAL es un array INTEGER, dimensión (NN)
!>          Los valores de la dimensión de columnas de la matriz N.
!
>

NMAT

S 
!>          NMATS es INTEGER
!>          El número de tipos de matriz a probar para cada combinación
!>          de dimensiones de matriz.  Si NMATS >= NTYPES (el máximo
!>          número de tipos de matriz), se generan todos los tipos
!>          diferentes para la prueba.  Si NMATS < NTYPES, se lee otra línea de
!>          entrada para obtener los números de los tipos de matriz a usar.
!
>

ISEE

D 
!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios.  Los elementos del array
!>          deben estar entre 0 y 4095, de lo contrario se reducirán
!>          módulo 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números aleatorios después de
!>          que se han generado todas las matrices de prueba.
!
>

THRES

H 
!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para los ratios de prueba.  Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH.  Para que se
!>          imprima cada ratio de prueba, use THRESH = 0.
!
>

NMA

X 
!>          NMAX es INTEGER
!>          El valor máximo permitido para M o N, usado en la dimensionación
!>          de los arrays de trabajo.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (NMAX*NMAX)
!
>
