NOMBRE

dcb-dcbx - mostrar / manipular DCBX de puerto (Data Center Bridging eXchange)

SINOPSIS


dcb [ OPCIONES ] dcbx { COMANDO | help }

dcb dcbx show dev DEV

dcb dcbx set dev DEV [ host ] [ lld-managed ] [ cee ] [ ieee ] [ static ]

DESCRIPCIÓN

Data Center Bridging eXchange (DCBX) es un protocolo utilizado por los dispositivos DCB para intercambiar información de configuración con pares directamente conectados. El objeto DCBX de Linux es un campo de bits de 1 byte que configura si DCBX se implementa en el dispositivo o en el host, y qué versión del protocolo se debe utilizar. dcb dcbx se utiliza para acceder al objeto DCBX de Linux por puerto.

Hay dos modos principales de operación: en modo host, el protocolo DCBX es implementado por el agente LLDP del host, y las interfaces DCB se utilizan para propagar los parámetros negociados a los dispositivos capaces. En modo lld-managed, la configuración es manejada por el dispositivo, y las interfaces DCB se utilizan para la inspección de los parámetros negociados, y también se pueden utilizar para establecer parámetros iniciales.

PARÁMETROS

Cuando se utiliza con dcb dcbx set, las siguientes palabras clave habilitan la configuración correspondiente. Las palabras clave que no se mencionan en la línea de comandos se consideran deshabilitadas. Cuando se utiliza con show, cada característica habilitada se muestra con su palabra clave correspondiente.

host
lld-managed
El dispositivo está en modo de operación de host y, respectivamente, en modo de operación lld-managed, como se describe anteriormente. En principio, estas dos palabras clave son mutuamente excluyentes, pero dcb dcbx permite establecer ambas y deja que el controlador lo maneje según corresponda.
cee
ieee
El dispositivo soporta CEE (Converged Enhanced Ethernet) y, respectivamente, la versión IEEE de la especificación DCB. Típicamente solo uno de estos se establecerá, pero dcb dcbx no exige esto.
static
indica que el motor soporta configuración estática. No se realiza ninguna negociación real, los parámetros negociados son siempre la configuración inicial.

EJEMPLO & USO

Poner el motor DCB en modo de operación "host", y usar interfaces DCB estandarizadas por IEEE:

# dcb dcbx set dev eth0 host ieee

Mostrar lo que se estableció:

# dcb dcbx show dev eth0
host ieee

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso o un entero positivo en caso de fallo.
