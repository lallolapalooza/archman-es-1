Propósito

: 
!>
!> DCHKGG verifica las rutinas del problema de valores propios
!> generalizado no simétrico.
!>                                T          T        T
!> DGGHRD factoriza A y B como U H V  y U T V , donde   significa
!> transpuesta, H es hessenberg, T es triangular y U y V son
!> ortogonales.
!>                                 T          T
!> DHGEQZ factoriza H y T como  Q S Z  y Q P Z , donde P es
!> triangular superior, S está en forma de Schur generalizada (triangular
!> superior por bloques, con bloques de 1x1 y 2x2 en la diagonal, los
!> bloques de 2x2 corresponden a pares de valores propios generalizados
!> complejos conjugados), y Q y Z son ortogonales. También calcula los
!> valores propios generalizados (alpha(1),beta(1)),...,(alpha(n),beta(n)),
!> donde alpha(j)=S(j,j) y beta(j)=P(j,j) -- así,
!> w(j) = alpha(j)/beta(j) es una raíz del problema de valores propios
!> generalizado
!>
!>     det( A - w(j) B ) = 0
!>
!> y m(j) = beta(j)/alpha(j) es una raíz del problema esencialmente equivalente
!>
!>     det( m(j) A - B ) = 0
!>
!> DTGEVC calcula la matriz L de vectores propios izquierdos y la matriz R
!> de vectores propios derechos para el par de matrices ( S, P ). En la
!> descripción siguiente, l y r son vectores propios izquierdos y derechos
!> correspondientes a los valores propios generalizados (alpha,beta).
!>
!> Cuando se llama a DCHKGG, se especifica un número de matrices  () y un
!> número de matrices . Para cada tamaño ()
!> y cada tipo de matriz, se generará una matriz y se usará
!> para probar las rutinas de eigen no simétricas. Para cada matriz, se realizarán 15
!> pruebas. Los primeros doce  deberían ser
!> pequeños -- O(1). Se compararán con el umbral THRESH:
!>
!>                  T
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  T
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               T
!> (3)   | I - UU  | / ( n ulp )
!>
!>               T
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  T
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  T
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               T
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               T
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)   máx sobre todos los pares de valores propios izquierdos/-vectores (beta/alpha,l) de
!>
!>    | l**H * (beta S - alpha P) | / ( ulp máx( |beta S|, |alpha P| ) )
!>
!> (10)  máx sobre todos los pares de valores propios izquierdos/-vectores (beta/alpha,l') de
!>                           T
!>   | l'**H * (beta H - alpha T) | / ( ulp máx( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios l' son el resultado de pasar Q a
!>       DTGEVC y hacer la transformación inversa (HOWMNY='B').
!>
!> (11)  máx sobre todos los pares de valores propios derechos/-vectores (beta/alpha,r) de
!>
!>       | (beta S - alpha T) r | / ( ulp máx( |beta S|, |alpha T| ) )
!>
!> (12)  máx sobre todos los pares de valores propios derechos/-vectores (beta/alpha,r') de
!>
!>       | (beta H - alpha T) r' | / ( ulp máx( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios r' son el resultado de pasar Z a
!>       DTGEVC y hacer la transformación inversa (HOWMNY='B').
!>
!> Los últimos tres cocientes de prueba normalmente serán pequeños, pero no hay
!> requisito matemático de que lo sean. Por lo tanto,
!> se comparan con THRESH solo si TSTDIF es .TRUE.
!>
!> (13)  | S(Q,Z calculado) - S(Q,Z no calculado) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z calculado) - P(Q,Z no calculado) | / ( |P| ulp )
!>
!> (15)  máx( |alpha(Q,Z calculado) - alpha(Q,Z no calculado)|/|S| ,
!>            |beta(Q,Z calculado) - beta(Q,Z no calculado)|/|P| ) / ulp
!>
!> Además, se verifica la normalización de L y R, y se compara
!> con el umbral THRSHN.
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una matriz identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una matriz identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad de k x k y J un bloque de Jordan
!>                       de (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz
!>                       diagonal con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  es cercano a overflow and small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) U ( J , J ) V     donde U y V son matrices ortogonales aleatorias.
!>
!> (17) U ( T1, T2 ) V    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas aleatorias O(1) por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) U ( T1, T2 ) V    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de máquina.
!>
!> (19) U ( T1, T2 ) V    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorias.
!>
!> (22) U ( big*T1, small*T2 ) V    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) U ( small*T1, big*T2 ) V    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) U ( small*T1, small*T2 ) V  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) U ( big*T1, big*T2 ) V      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) U ( T1, T2 ) V     donde T1 y T2 son matrices triangulares superiores aleatorias.
!>
!>

Parámetros


NSIZES

!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          DCHKGG no hace nada. Debe ser al menos cero.



NN


!>          NN es un array de INTEGER, de dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.



NTYPES


!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, DCHKGG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .



DOTYPE


!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN una
!>          matriz de ese tamaño y de tipo j será generada.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no serán generados. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.



ISEED


!>          ISEED es un array de INTEGER, de dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican a la salida y pueden ser utilizados en la
!>          siguiente llamada a DCHKGG para continuar la misma secuencia de números
!>          aleatorios.



THRESH


!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará exitosa si la relación de error,
!>          calculada como se describe arriba, no excede THRESH.
!>          Tenga en cuenta que el error se escala para ser O(1), por lo que THRESH
!>          debería ser un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100.
!>          En particular, no debería depender de la precisión (simple o doble) o del tamaño
!>          de la matriz. Debe ser al menos cero.



TSTDIF


!>          TSTDIF es LOGICAL
!>          Especifica si las relaciones de prueba 13-15 se calcularán y
!>          compararán con THRESH.
!>          = .FALSE.: Solo se calcularán y probarán las relaciones 1-12.
!>                     Las relaciones 13-15 se establecerán en cero.
!>          = .TRUE.:  Se calcularán y probarán todas las relaciones 1-15.
!>



THRSHN


!>          THRSHN es DOUBLE PRECISION
!>          Umbral para reportar el error de normalización del vector propio.
!>          Si la normalización de cualquier vector propio difiere de 1 en
!>          más de THRSHN*ulp, se imprimirá un mensaje de error especial.
!>          (Esto se maneja por separado de las otras pruebas,
!>          ya que solo un error del compilador o del programa debería causar un
!>          mensaje de error, al menos si THRSHN es al menos 5--10.)



NOUNIT


!>          NOUNIT es INTEGER
!>          El número de unidad de FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IINFO distinto de 0).



A


!>          A es un array de DOUBLE PRECISION, de dimensión
!>                            (LDA, max(NN))
!>          Se utiliza para almacenar la matriz A original. Se utiliza como entrada solo
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.



LDA


!>          LDA es INTEGER
!>          La dimensión principal de A, B, H, T, S1, P1, S2 y P2.
!>          Debe ser al menos 1 y al menos max( NN ).



B


!>          B es un array de DOUBLE PRECISION, de dimensión
!>                            (LDA, max(NN))
!>          Se utiliza para almacenar la matriz B original. Se utiliza como entrada solo
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.



H


!>          H es un array de DOUBLE PRECISION, de dimensión (LDA, max(NN))
!>          La matriz de Hessenberg superior calculada a partir de A por DGGHRD.



T


!>          T es un array de DOUBLE PRECISION, de dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de B por DGGHRD.



S1


!>          S1 es un array de DOUBLE PRECISION, de dimensión (LDA, max(NN))
!>          La matriz de Schur (bloque triangular superior) calculada a partir de H por
!>          DHGEQZ cuando Q y Z también se calculan.



S2


!>          S2 es un array de DOUBLE PRECISION, de dimensión (LDA, max(NN))
!>          La matriz de Schur (bloque triangular superior) calculada a partir de H por
!>          DHGEQZ cuando Q y Z no se calculan.



P1


!>          P1 es un array de DOUBLE PRECISION, de dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de T por DHGEQZ
!>          cuando Q y Z también se calculan.



P2


!>          P2 es un array de DOUBLE PRECISION, de dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de T por DHGEQZ
!>          cuando Q y Z no se calculan.



U


!>          U es un array de DOUBLE PRECISION, de dimensión (LDU, max(NN))
!>          La matriz ortogonal (izquierda) calculada por DGGHRD.



LDU


!>          LDU es INTEGER
!>          La dimensión principal de U, V, Q, Z, EVECTL y EVEZTR. Debe
!>          ser al menos 1 y al menos max( NN ).



V


!>          V es un array de DOUBLE PRECISION, de dimensión (LDU, max(NN))
!>          La matriz ortogonal (derecha) calculada por DGGHRD.



Q


!>          Q es un array de DOUBLE PRECISION, de dimensión (LDU, max(NN))
!>          La matriz ortogonal (izquierda) calculada por DHGEQZ.



Z


!>          Z es un array de DOUBLE PRECISION, de dimensión (LDU, max(NN))
!>          La matriz ortogonal (izquierda) calculada por DHGEQZ.



ALPHR1


!>          ALPHR1 es un array de DOUBLE PRECISION, de dimensión (max(NN))



ALPHI1


!>          ALPHI1 es un array de DOUBLE PRECISION, de dimensión (max(NN))



BETA1


!>          BETA1 es un array de DOUBLE PRECISION, de dimensión (max(NN))
!>
!>          Los valores propios generalizados de (A,B) calculados por DHGEQZ
!>          cuando Q, Z y las matrices de Schur completas se calculan.
!>          A la salida, ( ALPHR1(k)+ALPHI1(k)*i ) / BETA1(k) es el k-ésimo
!>          valor propio generalizado de las matrices en A y B.



ALPHR3


!>          ALPHR3 es un array de DOUBLE PRECISION, de dimensión (max(NN))



ALPHI3


!>          ALPHI3 es un array de DOUBLE PRECISION, de dimensión (max(NN))



BETA3


!>          BETA3 es un array de DOUBLE PRECISION, de dimensión (max(NN))



EVECTL


!>          EVECTL es un array de DOUBLE PRECISION, de dimensión (LDU, max(NN))
!>          La matriz de vectores propios (bloque triangular inferior) izquierdos para
!>          las matrices en S1 y P1. (Ver DTGEVC para el formato).



EVECTR


!>          EVECTR es un array de DOUBLE PRECISION, de dimensión (LDU, max(NN))
!>          La matriz de vectores propios (bloque triangular superior) derechos para
!>          las matrices en S1 y P1. (Ver DTGEVC para el formato).



WORK


!>          WORK es un array de DOUBLE PRECISION, de dimensión (LWORK)



LWORK


!>          LWORK es INTEGER
!>          El número de entradas en WORK. Debe ser al menos
!>          max( 2 * N**2, 6*N, 1 ), para todos los N=NN(j).



LLWORK


!>          LLWORK es un array LOGICAL, de dimensión (max(NN))



RESULT


!>          RESULT es un array de DOUBLE PRECISION, de dimensión (15)
!>          Los valores calculados por las pruebas descritas anteriormente.
!>          Actualmente, los valores están limitados a 1/ulp, para evitar
!>          desbordamiento.



INFO


!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  una rutina devolvió un código de error. INFO es el
!>                valor absoluto del valor INFO devuelto.
