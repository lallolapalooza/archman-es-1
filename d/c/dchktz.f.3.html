Parámetros

DOTYPE 
!>          DOTYPE es una matriz LÓGICA, dimensión (NTYPES)
!>          Los tipos de matriz a utilizar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NM

!>          NM es ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es una matriz ENTERA, dimensión (NM)
!>          Los valores de la dimensión de fila de la matriz M.
!>

NN

!>          NN es ENTERO
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es una matriz ENTERA, dimensión (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

THRESH

!>          THRESH es DOBLE PRECISIÓN
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para tener
!>          cada relación de prueba impresa, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LÓGICO
!>          Indicador que señala si se deben probar las salidas de error.
!>

A

!>          A es una matriz de DOBLE PRECISIÓN, dimensión (MMAX*NMAX)
!>          donde MMAX es el valor máximo de M en MVAL y NMAX es el
!>          valor máximo de N en NVAL.
!>

COPYA

!>          COPYA es una matriz de DOBLE PRECISIÓN, dimensión (MMAX*NMAX)
!>

S

!>          S es una matriz de DOBLE PRECISIÓN, dimensión
!>                      (min(MMAX,NMAX))
!>

TAU

!>          TAU es una matriz de DOBLE PRECISIÓN, dimensión (MMAX)
!>

WORK

!>          WORK es una matriz de DOBLE PRECISIÓN, dimensión
!>                      (MMAX*NMAX + 4*NMAX + MMAX)
!>

NOUT

!>          NOUT es ENTERO
!>          El número de unidad para la salida.
!>
