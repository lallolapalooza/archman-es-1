NOMBRE

dcb-pfc - mostrar / manipular la configuración de PFC (Priority-based Flow Control) del subsistema DCB (Data Center Bridging)

SINOPSIS


dcb [ OPCIONES ] pfc { COMANDO | help }

dcb pfc show dev DEV [ pfc-cap ] [ prio-pfc ] [ macsec-bypass ] [ delay ] [ requests ] [ indications ]

dcb pfc set dev DEV [ prio-pfc MAPA-PFC ] [ macsec-bypass { on | off } ] [ delay ENTERO ]

MAPA-PFC := [ MAPA-PFC ] MAPAJE-PFC

MAPAJE-PFC := { PRIO | all }:{ on | off }

PRIO := { 0 .. 7 }

DESCRIPCIÓN

dcb pfc se utiliza para configurar atributos de Priority-based Flow Control a través de la interfaz DCB (Data Center Bridging) de Linux. PFC permite marcar flujos con una cierta prioridad como sin pérdidas (lossless), y contiene la configuración relacionada, así como los contadores de PFC.

PARÁMETROS

Para parámetros de lectura/escritura, la siguiente descripción solo se aplica a la dirección de escritura, es decir, tal como se usa con el comando set. Para el comando show, el nombre del parámetro debe usarse como una palabra clave simple sin argumentos adicionales. Esto indica a la herramienta que muestre el valor de un parámetro dado. Cuando no se proporcionan parámetros, la herramienta muestra la configuración completa de PFC.

pfc-cap
Una propiedad de solo lectura que muestra el número de clases de tráfico que pueden admitir PFC simultáneamente.
requests
Un recuento de solo lectura de los cuadros PFC enviados por clase de tráfico. Solo se muestra cuando se proporciona -s, o cuando se solicita explícitamente.
indications
Un recuento de solo lectura de los cuadros PFC recibidos por clase de tráfico. Solo se muestra cuando se proporciona -s, o cuando se solicita explícitamente.
macsec-bypass { on | off }
Si la estación emisora es capaz de omitir el procesamiento MACsec cuando MACsec está deshabilitado.
prio-pfc MAPA-PFC
MAPA-PFC utiliza la sintaxis de parámetros de matriz, consulte dcb(8) para obtener detalles. Las claves son prioridades, los valores son indicadores de encendido/apagado de si PFC está habilitado para una prioridad dada.
delay ENTERO
La tolerancia permitida para el retardo de propagación de ida y vuelta del enlace en bits. El valor debe ser 0..65535.

EJEMPLO & USO

Habilitar PFC en las prioridades 6 y 7, dejando el resto intacto:

# dcb pfc set dev eth0 prio-pfc 6:on 7:on

Deshabilitar PFC de todas las prioridades excepto 6 y 7, y configurar el retardo a 4096 bits:

# dcb pfc set dev eth0 prio-pfc all:off 6:on 7:on delay 0x1000

Mostrar lo que se configuró:

# dcb pfc show dev eth0
pfc-cap 8 macsec-bypass off delay 4096
prio-pfc 0:off 1:off 2:off 3:off 4:off 5:off 6:on 7:on

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente o un entero positivo en caso de fallo.
