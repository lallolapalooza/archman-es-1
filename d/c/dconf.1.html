DCONF(1) Comandos de usuario DCONF(1)

NOMBRE

dconf - Herramienta simple para manipular una base de datos dconf

SINOPSIS

dconf read [-d] CLAVE

dconf list DIR

dconf write CLAVE VALOR

dconf reset [-f] RUTA

dconf compile SALIDA DIR_ARCHIVOS_CLAVE

dconf update [DIR_BD]

dconf watch RUTA

dconf dump DIR

dconf load [-f] DIR

dconf help [COMANDO]

DESCRIPCIÓN

El programa dconf puede realizar diversas operaciones en una base de datos dconf, como leer o escribir valores individuales o directorios completos. Esta herramienta opera directamente sobre dconf, sin usar información de esquemas de gsettings. Por lo tanto, no puede realizar comprobaciones de tipo y consistencia en los valores. La utilidad gsettings(1) es una alternativa si se necesitan dichas comprobaciones.

Los argumentos DIR deben ser rutas de directorio (que empiezan y terminan con '/'), los argumentos CLAVE deben ser rutas de clave (que empiezan, pero no terminan con '/') y los argumentos RUTA pueden ser rutas de directorio o de clave.

El argumento SALIDA debe ser la ubicación donde escribir una base de datos dconf (binaria) y el argumento DIR_ARCHIVOS_CLAVE debe ser un directorio .d que contenga archivos de clave.

Los argumentos VALOR deben estar en formato GVariant, por lo que, por ejemplo, una cadena debe incluir comillas explícitas: "'cadena'". Este formato también se utiliza al imprimir valores.

Tenga en cuenta que dconf necesita una conexión al bus de sesión de D-Bus para escribir cambios en la base de datos dconf.

COMANDOS

read

Lee el valor de una clave. Usa -d para imprimir el valor por defecto en lugar del valor establecido por el usuario.

list

Lista las sub-claves y sub-directorios de un directorio.

write

Escribe un nuevo valor en una clave.

reset

Reinicia una clave o un directorio completo. Para directorios, se debe especificar -f.

compile

Compila una base de datos binaria a partir de archivos de clave.

El resultado está siempre en orden de bytes little-endian, por lo que se puede instalar de forma segura en 'share'. Si se utiliza en una máquina big-endian, dconf intercambiará automáticamente los bytes del contenido al leerlo.

update

Actualiza las bases de datos dconf del sistema.

watch

Observa una clave o directorio en busca de cambios.

dump

Vuelca una subruta completa a la salida estándar. La salida está en un formato similar a un archivo de clave, con valores en sintaxis GVariant.

load

Rellena una subruta desde la entrada estándar. El formato esperado es el mismo que el producido por dump. Intentar cambiar claves no escribibles cancela el comando load. Para ignorar los cambios en claves no escribibles en su lugar, usa -f.

help

Muestra la ayuda y sale. Si se proporciona COMANDO, muestra la ayuda para ese comando.

MEDIO AMBIENTE

DCONF_PROFILE

Esta variable de entorno determina qué perfil de dconf se utiliza. Ver dconf(7).
