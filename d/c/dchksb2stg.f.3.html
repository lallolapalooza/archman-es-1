Documentación de Función/Subrutina

subrutina dchksb2stg (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) sd, double precision, dimension( * ) se, double precision, dimension( * ) d1, double precision, dimension( * ) d2, double precision, dimension( * ) d3, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( * ) work, integer lwork, double precision, dimension( * ) result, integer info)

DCHKSB2STG

Propósito:

!>
!> DCHKSB2STG prueba la reducción de una matriz de banda simétrica a forma tridiagonal,
!> utilizada con el problema de valores propios simétricos.
!>
!> DSBTRD factoriza una matriz de banda simétrica A como U S U', donde ' significa
!> transpuesta, S es tridiagonal simétrica y U es ortogonal.
!> DSBTRD puede usar solo la parte triangular inferior o solo la parte triangular
!> superior de A; DCHKSB2STG comprueba ambos casos.
!>
!> DSYTRD_SB2ST factoriza una matriz de banda simétrica A como U S U',
!> donde ' significa transpuesta, S es tridiagonal simétrica y U es
!> ortogonal. DSYTRD_SB2ST puede usar solo la parte triangular inferior o solo la
!> parte triangular superior de A; DCHKSB2STG comprueba ambos casos.
!>
!> DSTEQR factoriza S como Z D1 Z'.
!> D1 es la matriz de valores propios calculados cuando Z no se calcula
!> y de la S resultante de DSBTRD (utilizada como referencia para DSYTRD_SB2ST)
!> D2 es la matriz de valores propios calculados cuando Z no se calcula
!> y de la S resultante de DSYTRD_SB2ST.
!> D3 es la matriz de valores propios calculados cuando Z no se calcula
!> y de la S resultante de DSYTRD_SB2ST.
!>
!> Cuando se llama a DCHKSB2STG, se especifica un número de tamaños de matrices (),
!> un número de anchos de banda () y un número de tipos de matrices. Para cada tamaño (),
!> cada ancho de banda () menor o igual que , y cada tipo de matriz, se generará una
!> matriz y se utilizará para probar la rutina de reducción de banda simétrica. Para cada
!> matriz, se realizarán una serie de pruebas:
!>
!> (1) | A - V S V' | / ( |A| n ulp ) calculada por DSBTRD con
!> UPLO='U'
!>
!> (2) | I - UU' | / ( n ulp )
!>
!> (3) | A - V S V' | / ( |A| n ulp ) calculada por DSBTRD con
!> UPLO='L'
!>
!> (4) | I - UU' | / ( n ulp )
!>
!> (5) | D1 - D2 | / ( |D1| ulp ) donde D1 se calcula por
!> DSBTRD con UPLO='U' y
!> D2 se calcula por
!> DSYTRD_SB2ST con UPLO='U'
!>
!> (6) | D1 - D3 | / ( |D1| ulp ) donde D1 se calcula por
!> DSBTRD con UPLO='U' y
!> D3 se calcula por
!> DSYTRD_SB2ST con UPLO='L'
!>
!> Los se especifican mediante un array NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1) La matriz cero.
!> (2) La matriz identidad.
!>
!> (3) Una matriz diagonal con entradas espaciadas uniformemente
!> 1, ..., ULP y signos aleatorios.
!> (ULP = (primer número mayor que 1) - 1 )
!> (4) Una matriz diagonal con entradas espaciadas geométricamente
!> 1, ..., ULP y signos aleatorios.
!> (5) Una matriz diagonal con entradas 1, ULP, ..., ULP
!> y signos aleatorios.
!>
!> (6) Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!> (7) Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (8) Una matriz de la forma U' D U, donde U es ortogonal y
!> D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!> en la diagonal.
!>
!> (9) Una matriz de la forma U' D U, donde U es ortogonal y
!> D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!> en la diagonal.
!>
!> (10) Una matriz de la forma U' D U, donde U es ortogonal y
!> D tiene entradas 1, ULP,..., ULP con signos aleatorios
!> en la diagonal.
!>
!> (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!> (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>

Parámetros

NSIZES 
!> NSIZES es INTEGER
!> El número de tamaños de matrices a utilizar. Si es cero,
!> DCHKSB2STG no hace nada. Debe ser al menos cero.
!>

NN

!> NN es un array INTEGER, dimension (NSIZES)
!> Un array que contiene los tamaños a utilizar para las matrices.
!> Los valores cero serán omitidos. Los valores deben ser al menos
!> cero.
!>

NWDTHS

!> NWDTHS es INTEGER
!> El número de anchos de banda a utilizar. Si es cero,
!> DCHKSB2STG no hace nada. Debe ser al menos cero.
!>

KK

!> KK es un array INTEGER, dimension (NWDTHS)
!> Un array que contiene los anchos de banda a utilizar para las matrices
!> de banda. Los valores deben ser al menos cero.
!>

NTYPES

!> NTYPES es INTEGER
!> El número de elementos en DOTYPE. Si es cero, DCHKSB2STG
!> no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!> y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!> que es usar cualquier matriz que esté en A. Esto
!> solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!> DOTYPE(MAXTYP+1) es .TRUE..
!>

DOTYPE

!> DOTYPE es un array LOGICAL, dimension (NTYPES)
!> Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!> una matriz de ese tamaño y de tipo j.
!> Si NTYPES es menor que el número máximo de tipos
!> definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!> MAXTYP no se generarán. Si NTYPES es mayor
!> que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!> serán ignorados.
!>

ISEED

!> ISEED es un array INTEGER, dimension (4)
!> A la entrada, ISEED especifica la semilla del generador de números
!> aleatorios. Los elementos del array deben estar entre 0 y 4095;
!> si no, se reducirán módulo 4096. Además, ISEED(4) debe
!> ser impar. El generador de números aleatorios utiliza una secuencia
!> congruencial lineal limitada a enteros pequeños, y por lo tanto
!> debería producir números aleatorios independientes de la máquina. Los
!> valores de ISEED se modifican a la salida y pueden usarse en la
!> siguiente llamada a DCHKSB2STG para continuar la misma secuencia de
!> números aleatorios.
!>

THRESH

!> THRESH es DOUBLE PRECISION

A la entrada, THRESH es el umbral de relación entre el valor máximo y el mínimo de los elementos de la matriz que se utilizarán para generar las matrices de tipos 3 a 15.

NOUN IT

!> NOUNIT es INTEGER
!> Si NOUNIT = 0, entonces se comprueba la ortogonalidad de U.
!> Si NOUNIT = .TRUE., entonces la ortogonalidad de U no se comprueba.
!>

A

!> A es un array DOUBLE PRECISION, dimension (LDA, * )
!> La matriz de banda simétrica de entrada.
!>

LDA

!> LDA es INTEGER
!> El tamaño de la primera dimensión de A. Debe ser al menos el número de
!> filas de A.
!>

SD

!> SD es un array DOUBLE PRECISION, dimension (*)
!> Matriz de banda simétrica utilizada por DSBTRD.
!>

SE

!> SE es un array DOUBLE PRECISION, dimension (*)
!> Matriz de banda simétrica utilizada por DSYTRD_SB2ST.
!>

D1

!> D1 es un array DOUBLE PRECISION, dimension (*)
!> Valores propios calculados por DSBTRD con UPLO='U'.
!>

D2

!> D2 es un array DOUBLE PRECISION, dimension (*)
!> Valores propios calculados por DSYTRD_SB2ST con UPLO='U'.
!>

D3

!> D3 es un array DOUBLE PRECISION, dimension (*)
!> Valores propios calculados por DSYTRD_SB2ST con UPLO='L'.
!>

U

!> U es un array DOUBLE PRECISION, dimension (LDU, *)
!> Matriz ortogonal de salida de la reducción.
!>

LDU

!> LDU es INTEGER
!> El tamaño de la primera dimensión de U. Debe ser al menos N.
!>

WORK

!> WORK es un array DOUBLE PRECISION, dimension (*)
!> Espacio de trabajo utilizado por la rutina.
!>

LWORK

!> LWORK es INTEGER
!> La longitud del array WORK. Debe ser lo suficientemente grande
!> como para alojar las subrutinas internas llamadas.
!>

RESULT

!> RESULT es un array DOUBLE PRECISION, dimension (*)
!> Los resultados de las pruebas.
!>

INFO

!> INFO es INTEGER
!> = 0: todas las pruebas pasaron.
!> >0: una prueba falló para el número de prueba especificado por INFO.
!>

D2

D3

U
