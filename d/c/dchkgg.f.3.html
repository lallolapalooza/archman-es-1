Documentación de Función/Subrutina

subrutina dchkgg (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, logical tstdif, double precision thrshn, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( lda, * ) b, double precision, dimension( lda, * ) h, double precision, dimension( lda, * ) t, double precision, dimension( lda, * ) s1, double precision, dimension( lda, * ) s2, double precision, dimension( lda, * ) p1, double precision, dimension( lda, * ) p2, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldu, * ) v, double precision, dimension( ldu, * ) q, double precision, dimension( ldu, * ) z, double precision, dimension( * ) alphr1, double precision, dimension( * ) alphi1, double precision, dimension( * ) beta1, double precision, dimension( * ) alphr3, double precision, dimension( * ) alphi3, double precision, dimension( * ) beta3, double precision, dimension( ldu, * ) evectl, double precision, dimension( ldu, * ) evectr, double precision, dimension( * ) work, integer lwork, logical, dimension( * ) llwork, double precision, dimension( 15 ) result, integer info)

DCHKGG

Propósito:

!>
!> DCHKGG comprueba las rutinas del problema de valores propios generalizado no simétrico.
!>                                T          T        T
!> DGGHRD factoriza A y B como U H V  y U T V , donde   significa
!> transpuesta, H es hessenberg, T es triangular y U y V son
!> ortogonales.
!>                                 T          T
!> DHGEQZ factoriza H y T como  Q S Z  y Q P Z , donde P es triangular
!> superior, S está en forma de Schur generalizada (triangular por bloques
!> superior, con bloques 1x1 y 2x2 en la diagonal, los bloques 2x2
!> correspondientes a pares de valores propios generalizados
!> complejos conjugados), y Q y Z son ortogonales. También calcula los
!> valores propios generalizados (alpha(1),beta(1)),...,(alpha(n),beta(n)),
!> donde alpha(j)=S(j,j) y beta(j)=P(j,j) -- así,
!> w(j) = alpha(j)/beta(j) es una raíz del problema de valores propios
!> generalizado
!>
!>     det( A - w(j) B ) = 0
!>
!> y m(j) = beta(j)/alpha(j) es una raíz del problema esencialmente equivalente
!>
!>     det( m(j) A - B ) = 0
!>
!> DTGEVC calcula la matriz L de vectores propios izquierdos y la matriz R
!> de vectores propios derechos para el par de matrices ( S, P ). En la
!> descripción siguiente, l y r son vectores propios izquierdos y derechos
!> correspondientes a los valores propios generalizados (alpha,beta).
!>
!> Cuando se llama a DCHKGG, se especifica un número de matrices  () y un
!> número de matrices . Para cada tamaño ()
!> y cada tipo de matriz, se generará una matriz y se usará
!> para probar las rutinas propias no simétricas. Para cada matriz, se realizarán 15
!> pruebas. Los primeros doce  deberían ser
!> pequeños -- O(1). Se compararán con el umbral THRESH:
!>
!>                  T
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  T
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               T
!> (3)   | I - UU  | / ( n ulp )
!>
!>               T
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  T
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  T
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               T
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               T
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)   máximo sobre todos los pares de valores propios/vectores izquierdos (beta/alpha,l) de
!>
!>    | l**H * (beta S - alpha P) | / ( ulp max( |beta S|, |alpha P| ) )
!>
!> (10)  máximo sobre todos los pares de valores propios/vectores izquierdos (beta/alpha,l') de
!>                           T
!>   | l'**H * (beta H - alpha T) | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios l' son el resultado de pasar Q a
!>       DTGEVC y retrotransformar (HOWMNY='B').
!>
!> (11)  máximo sobre todos los pares de valores propios/vectores derechos (beta/alpha,r) de
!>
!>       | (beta S - alpha T) r | / ( ulp max( |beta S|, |alpha T| ) )
!>
!> (12)  máximo sobre todos los pares de valores propios/vectores derechos (beta/alpha,r') de
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       donde los vectores propios r' son el resultado de pasar Z a
!>       DTGEVC y retrotransformar (HOWMNY='B').
!>
!> Los últimos tres cocientes de prueba generalmente serán pequeños, pero no hay
!> requisito matemático de que lo sean. Por lo tanto,
!> se comparan con THRESH solo si TSTDIF es .TRUE.
!>
!> (13)  | S(Q,Z calculado) - S(Q,Z no calculado) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z calculado) - P(Q,Z no calculado) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z calculado) - alpha(Q,Z no calculado)|/|S| ,
!>            |beta(Q,Z calculado) - beta(Q,Z no calculado)|/|P| ) / ulp
!>
!> Además, se comprueba la normalización de L y R, y se compara
!> con el umbral THRSHN.
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una matriz identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una matriz identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad k x k y J un bloque de Jordan
!>                       (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz
!>                       diagonal con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  está cerca desbordamiento y pequeño=1/grande
!>
!> (10) ( pequeño*D, grande*I )
!>
!> (11) ( grande*I, pequeño*D )
!>
!> (12) ( pequeño*I, grande*D )
!>
!> (13) ( grande*D, grande*I )
!>
!> (14) ( pequeño*D, pequeño*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) U ( J , J ) V     donde U y V son matrices ortogonales aleatorias.
!>
!> (17) U ( T1, T2 ) V    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas aleatorias O(1) por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) U ( T1, T2 ) V    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de la máquina.
!>
!> (19) U ( T1, T2 ) V    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) U ( T1, T2 ) V    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorios.
!>
!> (22) U ( grande*T1, pequeño*T2 ) V    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) U ( pequeño*T1, grande*T2 ) V    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) U ( pequeño*T1, pequeño*T2 ) V  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) U ( grande*T1, grande*T2 ) V      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) U ( T1, T2 ) V     donde T1 y T2 son matrices triangulares superiores
!>                         aleatorias.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar.  Si es cero,
!>          DCHKGG no hace nada.  Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos.  Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, DCHKGG
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que utiliza la matriz que esté en A.  Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no serán generados.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, serán reducidos módulo 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican en la salida, y pueden usarse en la
!>          siguiente llamada a DCHKGG para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se contará como  si el , calculado como
!>          se describe arriba, excede THRESH.  Nótese que el error está
!>          escalado para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100.  En particular, no
!>          debe depender de la precisión (simple vs. doble) o del tamaño
!>          de la matriz.  Debe ser al menos cero.
!>

TSTDIF

!>          TSTDIF es LOGICAL
!>          Especifica si las relaciones de prueba 13-15 serán calculadas y
!>          comparadas con THRESH.
!>          = .FALSE.: Solo se calcularán y probarán las relaciones de prueba 1-12.
!>                     Las relaciones 13-15 se establecerán en cero.
!>          = .TRUE.:  Todas las relaciones de prueba 1-15 serán calculadas y
!>                     probadas.
!>

THRSHN

!>          THRSHN es DOUBLE PRECISION
!>          Umbral para reportar el error de normalización de los autovectores.
!>          Si la normalización de cualquier autovector difiere de 1 en
!>          más de THRSHN*ulp, se imprimirá un mensaje de error especial.
!>          (Esto se maneja por separado de las otras pruebas,
!>          ya que solo un error de compilador o de programación debería causar un
!>          mensaje de error, al menos si THRSHN es al menos 5--10.)
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es un array DOUBLE PRECISION, dimensión
!>                            (LDA, max(NN))
!>          Utilizado para contener la matriz A original.  Se usa solo como
!>          entrada si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A, B, H, T, S1, P1, S2, y P2.
!>          Debe ser al menos 1 y al menos max( NN ).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión
!>                            (LDA, max(NN))
!>          Utilizado para contener la matriz B original.  Se usa solo como
!>          entrada si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

H

!>          H es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          La matriz de Hessenberg superior calculada a partir de A por DGGHRD.
!>

T

!>          T es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de B por DGGHRD.
!>

S1

!>          S1 es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          La matriz de Schur (triangular superior por bloques) calculada a partir de H por
!>          DHGEQZ cuando también se calculan Q y Z.
!>

S2

!>          S2 es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          La matriz de Schur (triangular superior por bloques) calculada a partir de H por
!>          DHGEQZ cuando no se calculan Q y Z.
!>

P1

!>          P1 es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de T por DHGEQZ
!>          cuando también se calculan Q y Z.
!>

P2

!>          P2 es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de T por DHGEQZ
!>          cuando no se calculan Q y Z.
!>

U

!>          U es un array DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          La matriz ortogonal (izquierda) calculada por DGGHRD.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U, V, Q, Z, EVECTL, y EVEZTR.  Debe
!>          ser al menos 1 y al menos max( NN ).
!>

V

!>          V es un array DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          La matriz ortogonal (derecha) calculada por DGGHRD.
!>

Q

!>          Q es un array DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          La matriz ortogonal (izquierda) calculada por DHGEQZ.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          La matriz ortogonal (izquierda) calculada por DHGEQZ.
!>

ALPHR1

!>          ALPHR1 es un array DOUBLE PRECISION, dimensión (max(NN))
!>

ALPHI1

!>          ALPHI1 es un array DOUBLE PRECISION, dimensión (max(NN))
!>

BETA1

!>          BETA1 es un array DOUBLE PRECISION, dimensión (max(NN))
!>
!>          Los autovalores generalizados de (A,B) calculados por DHGEQZ
!>          cuando se calculan Q, Z, y las matrices de Schur completas.
!>          En la salida, ( ALPHR1(k)+ALPHI1(k)*i ) / BETA1(k) es el k-ésimo
!>          autovalor generalizado de las matrices en A y B.
!>

ALPHR3

!>          ALPHR3 es un array DOUBLE PRECISION, dimensión (max(NN))
!>

ALPHI3

!>          ALPHI3 es un array DOUBLE PRECISION, dimensión (max(NN))
!>

BETA3

!>          BETA3 es un array DOUBLE PRECISION, dimensión (max(NN))
!>

EVECTL

!>          EVECTL es un array DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          La matriz de autovectores izquierda (triangular inferior por bloques) para
!>          las matrices en S1 y P1.  (Ver DTGEVC para el formato.)
!>

EVECTR

!>          EVECTR es un array DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          La matriz de autovectores derecha (triangular superior por bloques) para
!>          las matrices en S1 y P1.  (Ver DTGEVC para el formato.)
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          El número de entradas en WORK.  Debe ser al menos
!>          max( 2 * N**2, 6*N, 1 ), para todos N=NN(j).
!>

LLWORK

!>          LLWORK es un array LOGICAL, dimensión (max(NN))
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (15)
!>          Los valores calculados por las pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  Una rutina devolvió un código de error.  INFO es el
!>                valor absoluto del valor INFO devuelto.
!>
