NOMBRE

dcmqrti - El Programa Cliente Telnet del Iniciador Terminal

SINOPSIS

dcmqrti [opciones] par_remoto...

DESCRIPCIÓN

El programa dcmqrti (iniciador telnet) es un programa interactivo basado en caracteres diseñado para examinar las bases de datos de imágenes dcmqrscp y enviar imágenes contenidas en estas bases de datos a Nodos de Vendedor. Durante una Demostración DICOM, el programa dcmqrti puede ser activado por un Vendedor iniciando sesión en el ordenador que ejecuta el programa dcmqrscp. Cada vendedor tendrá su propia cuenta de inicio de sesión y el programa dcmqrti se iniciará en lugar de una shell normal al iniciar sesión.

El programa dcmqrti toma un argumento principal, el nombre de host o el nombre simbólico del vendedor (de la tabla de Vendedores en el archivo de configuración) de un Vendedor. Luego busca en el archivo de configuración todos los títulos AE asociados con este nombre de host o nombre de vendedor, y todas las áreas de almacenamiento accesibles para estos títulos AE. Por lo tanto, solo las bases de datos accesibles y las aplicaciones pares descubiertas en el archivo de configuración están disponibles como opciones dentro de la interfaz de usuario de dcmqrti.

PARÁMETROS

par_remoto  nombre de host o nombre simbólico del par del archivo cfg

OPCIONES

generales opciones

  -h    --help
          imprime este texto de ayuda y sale
        --version
          imprime información de la versión y sale
        --arguments
          imprime los argumentos de la línea de comandos expandidos
  -q    --quiet
          modo silencioso, no imprime advertencias ni errores
  -v    --verbose
          modo detallado, imprime detalles del procesamiento
  -d    --debug
          modo de depuración, imprime información de depuración
  -ll   --log-level  [n]ivel: constante de cadena
          (fatal, error, warn, info, debug, trace)
          usa el nivel l para el registrador
  -lc   --log-config  [a]rchivo: cadena
          usa el archivo de configuración f para el registrador
  -c    --config  [a]rchivo: cadena
          usa un archivo de configuración específico
          (predeterminado: /usr/local/etc/dcmtk-<VERSION>/dcmqrscp.cfg)

red opciones

  -to   --timeout  [s]egundos: entero (predeterminado: ilimitado)
          tiempo de espera para las solicitudes de conexión
  -ta   --acse-timeout  [s]egundos: entero (predeterminado: 30)
          tiempo de espera para mensajes ACSE
  -td   --dimse-timeout  [s]egundos: entero (predeterminado: ilimitado)
          tiempo de espera para mensajes DIMSE
  -xi   --propose-implicit
          propone solo el TS implícito VR little endian
  -aet  --aetitle  [t]itulo_ae: cadena
          establece mi título AE (predeterminado: TELNET_INITIATOR)
  -pdu  --max-pdu  [n]úmero de bytes: entero (4096..131072)
          establece el pdu de recepción máximo a n bytes
          (predeterminado: usa el valor del archivo de configuración)

otras opciones

  -u    --disable-new-vr
          deshabilita el soporte para VRs nuevos, convierte a OB
  -rmt  --remote  [t]itulo: cadena
          conecta a la base de datos remota definida en el archivo cfg

NOTAS_dcmqrti

Comandos

Todos los comandos se pueden abreviar. Se permite una abreviatura si no entra en conflicto con otro comando.

Comando "help"

El comando "help" proporciona un resumen de todos los comandos disponibles. Su salida se muestra a continuación. Para separar los ejemplos del texto circundante, todos los ejemplos están delimitados por líneas guionadas. Estas líneas no aparecen al ejecutar el programa.

------------------------------------------------------------
Resumen de Comandos:
help                lista este resumen
?                   ayuda corta
title [#]           lista [establece] el título AE del par actual
database [#]        lista [establece] la base de datos actual
study [#]           lista [establece] el estudio actual
series [#]          lista [establece] la serie actual
image [#]           lista [establece] la imagen actual
display [#]         muestra la imagen actual [específica]
send study [#]      envía el estudio actual [específico]
send series [#]     envía la serie actual [específica]
send image [#]      envía la imagen actual [específica]
echo [#]            verifica la conectividad [# veces]
quit                sale del programa
exit                sinónimo de quit
------------------------------------------------------------

Comando "title"

El comando "title" sin argumento permite al usuario listar las Entidades de Aplicación (AE) remotas conocidas. Un ejemplo de salida podría ser:

------------------------------------------------------------
Títulos AE de Pares:
     AE de Par          Nombre de Host:Número de Puerto
* 0) ACME1            (swallow:2001)
  1) ACME2            (swallow:2002)
  2) UNITED1          (kolibri:2001)
  3) UNITED2          (kolibri:2002)
------------------------------------------------------------

El AE de par actual se marca con un asterisco (*). Cada AE de par tiene un índice (segunda columna) que se puede usar como argumento para el comando "title" con el fin de establecer el AE de par actual. La tercera columna muestra el título AE del AE de par. La cuarta columna muestra el nombre de host y el número de puerto TCP/IP del AE de par.

Cuando se invoca con un índice de argumento, el comando "title" establecerá el AE de par actual. El programa dcmqrti intentará iniciar una asociación con el AE de par actual cuando se le pida enviar un estudio/serie/imagen o enviar un eco.

Comando "database"

El comando "database" sin argumento permite al usuario listar las bases de datos locales conocidas (estas corresponden a los Títulos de Entidad de Aplicación de dcmqrscp). Un ejemplo de salida podría ser:

------------------------------------------------------------
Títulos de Bases de Datos:
     Base de Datos
* 0) COMMON
  1) ACME_QUERY
  2) ACME_STORE
  3) UNITED_QUERY
------------------------------------------------------------

La base de datos actual se marca con un asterisco (*). Cada base de datos tiene un índice (segunda columna) que se puede usar como argumento para el comando "database" con el fin de establecer la base de datos actual. La tercera columna muestra el nombre de la base de datos (es decir, el título de la Entidad de Aplicación de dcmqrscp para el área de almacenamiento particular).

Cuando se invoca con un índice de argumento, el comando "database" establecerá la base de datos actual. La base de datos actual se usa como base para acciones adicionales específicas de la base de datos.

Comando "study"

El comando "study" sin argumento lista los estudios en la base de datos actual. Un ejemplo de salida podría ser:

------------------------------------------------------------
      Paciente                        ID_Paciente    ID_Estudio
*  0) JACKSON^ANDREW^^^              M4997106     20001
   1) GRANT^MARY^^^                  F4997108     20002
   2) ARTHUR^CHESTER^^^              M4997107     20003
   3) JEFFERSON^THOMAS^^^            M4997096     9465
   4) MADISON^DOLLY^^^               F4997097     9443
4 Estudios en Base de Datos: COMMON
------------------------------------------------------------

El estudio actual se marca con un asterisco (*). Cada estudio tiene un índice (segunda columna) que se puede usar como argumento para el comando "study" con el fin de establecer el estudio actual. La tercera columna muestra el nombre del paciente, la cuarta columna el ID del paciente y la quinta columna el ID del estudio.

Cuando se invoca con un índice de argumento, el comando "study" establecerá el estudio actual. El estudio actual se usa como base para acciones adicionales específicas del estudio.

Comando "series"

El comando "series" sin argumento lista las series en el estudio actual. Un ejemplo de salida podría ser:

------------------------------------------------------------
      Serie Modalidad UID_Instancia_Serie
*  0) 1      MR       1.2.840.113654.2.3.1993.201
   1) 2      MR       1.2.840.113654.2.3.1993.202
   2) 3      MR       1.2.

840.113654.2.3.1993.203 3) 4 MR 1.2.840.113654.2.3.1993.204 4) 5 MR 1.2.840.113654.2.3.1993.205 5 Serie en StudyID 05381, Paciente: MONROE^JAMES^^^ (Base de Datos: COMMON) ------------------------------------------------------------

La serie actual está marcada con un asterisco (*). Cada serie tiene un índice (segunda columna) que se puede usar como argumento para el comando "series" para establecer la serie actual. La tercera columna muestra el número de serie, la cuarta columna la modalidad de la serie y la quinta columna el UID de instancia de la serie.

Cuando se invoca con un índice de argumento, el comando "series" establecerá la serie actual. La serie actual se usa como base para acciones futuras específicas de la serie.

La imagen actual está marcada con un asterisco (*). Cada imagen tiene un índice (segunda columna) que se puede usar como argumento para el comando "image" para establecer la imagen actual. La tercera columna muestra el número de imagen y la cuarta columna el UID de instancia de imagen (SOP Instance UID).

Cuando se invoca con un índice de argumento, el comando "image" establecerá la imagen actual. La imagen actual se usa como base para acciones futuras específicas de la imagen.

Comando "display"

El comando display no tiene ningún propósito en la versión actual de DCMTK. Se utilizaba en versiones anteriores para solicitar al Programa de Visualización CTN que mostrara una imagen.

Comando "send"

El comando "send" permite que un estudio/serie completo o una imagen individual se almacene en un AE remoto. Cuando se invoca este comando, el programa dcmqrti operará como un SCU de la Clase de Servicio de Almacenamiento DICOM e intentará iniciar una asociación con el AE par actual (definido a través del comando "title"). Se propondrán contextos de presentación para todas las Clases SOP de Almacenamiento relevantes. Se intentará almacenar todas las imágenes especificadas. Si no se puede negociar ninguna asociación, se imprimirá un mensaje de error. Si una operación de almacenamiento falla o si no hay un contexto de presentación apropiado disponible, se imprimirá un mensaje de error.

El comando "send" existe en tres formas:
        send study [#]
        send series [#]
        send image [#]

La palabra clave "study" significa enviar todas las imágenes del estudio actual. Cuando se invoca con un índice de argumento, se almacenará el estudio especificado en la base de datos actual. La palabra clave "series" significa enviar todas las imágenes de la serie actual. Cuando se invoca con un índice de argumento, se almacenará la serie especificada en el estudio actual. La palabra clave "image" significa enviar la imagen actual. Cuando se invoca con un índice de argumento, se almacenará la imagen especificada en la serie actual.

Cuando se almacena una imagen, se imprimirá un mensaje de la forma:

------------------------------------------------------------
Nueva Asociación Iniciada (swallow:2001,ACME1)
[MsgID 1] Store,
  PatientName: JACKSON^ANDREW^^^, StudyID: 20001,
  Series: 2, Modality: CR, Image: 1,
  Image UID: 1.2.840.113654.2.3.1993.9.123.6.1834
  0%________25%_________50%__________75%________100%
  --------------------------------------------------
[MsgID 1] Completo [Status: Success]
Asociación Liberada (swallow:2001,ACME1)
------------------------------------------------------------

Comando "echo"

El comando "echo" permite al usuario verificar la conectividad con el AE par actual (definido a través del comando "title"). Cuando se invoca, el programa dcmqrti actúa como un SCU de la Clase de Servicio de Verificación.

Cuando se invoca sin argumento, solo se genera un mensaje C-ECHO. Cuando se invoca con un argumento, se enviará el número especificado de mensajes C-ECHO. Se imprimirá un mensaje de la forma:

------------------------------------------------------------
Nueva Asociación Iniciada (localhost:2001,CMOVE)
[MsgID 1] Echo, Completo [Status: Success]
Asociación Liberada (localhost:2001,CMOVE)
------------------------------------------------------------

Comandos "quit", "exit"

Los comandos "quit" y "exit" tienen el mismo efecto. Terminan el programa dcmqrti.

Conformidad DICOM

La aplicación dcmqrti soporta el mismo conjunto de Clases SOP como SCU que la aplicación dcmqrscp; consulte la documentación de dcmqrscp.

La aplicación dcmqrti propondrá contextos de presentación para todas las Clases SOP soportadas mencionadas anteriormente utilizando las siguientes sintaxis de transferencia:

LittleEndianImplicitTransferSyntax  1.2.840.10008.1.2
LittleEndianExplicitTransferSyntax  1.2.840.10008.1.2.1
BigEndianExplicitTransferSyntax     1.2.840.10008.1.2.2

La aplicación dcmqrti no soporta negociación extendida.

Configuración

El programa dcmqrti utiliza el mismo archivo de configuración que el programa dcmqrscp. Consulte la documentación sobre configuración para obtener más información (dcmqrcnf.txt y el archivo de configuración de ejemplo dcmqrscp.cfg).

REGISTRO

El nivel de salida de registro de las diversas herramientas de línea de comandos y bibliotecas subyacentes puede ser especificado por el usuario. Por defecto, solo se escriben errores y advertencias en el flujo de error estándar. Usando la opción --verbose también se informan mensajes informativos como detalles de procesamiento. La opción --debug se puede usar para obtener más detalles sobre la actividad interna, p. ej., para fines de depuración. Se pueden seleccionar otros niveles de registro usando la opción --log-level. En el modo --quiet solo se informan errores fatales. En tales eventos de error muy graves, la aplicación generalmente terminará. Para más detalles sobre los diferentes niveles de registro, consulte la documentación del módulo "oflog".

En caso de que la salida de registro deba escribirse en un archivo (opcionalmente con rotación de archivo de registro), a syslog (Unix) o al registro de eventos (Windows), se puede usar la opción --log-config. Este archivo de configuración también permite dirigir solo ciertos mensajes a un flujo de salida particular y filtrar ciertos mensajes basándose en el módulo o la aplicación donde se generan. Se proporciona un archivo de configuración de ejemplo en <etcdir>/logger.cfg.

LÍNEA DE COMANDOS

Todas las herramientas de línea de comandos utilizan la siguiente notación para los parámetros: los corchetes encierran valores opcionales (0-1), tres puntos suspensivos indican que se permiten múltiples valores (1-n), una combinación de ambos significa 0 a n valores.

Las opciones de línea de comandos se distinguen de los parámetros por un signo '+' o '-' respectivamente. Por lo general, el orden y la posición de las opciones de línea de comandos son arbitrarios (es decir, pueden aparecer en cualquier lugar). Sin embargo, si las opciones son mutuamente excluyentes, se utiliza la aparición más a la derecha. Este comportamiento se ajusta a las reglas de evaluación estándar de los shells Unix comunes.

Además, se pueden especificar uno o más archivos de comandos usando un signo '@' como prefijo del nombre del archivo (p. ej., @command.txt). Dicho argumento de comando se reemplaza por el contenido del archivo de texto correspondiente (múltiples espacios en blanco se tratan como un solo separador a menos que aparezcan entre dos comillas) antes de cualquier otra evaluación. Tenga en cuenta que un archivo de comandos no puede contener otro archivo de comandos. Este enfoque simple pero efectivo permite resumir combinaciones comunes de opciones/parámetros y evita líneas de comandos demasiado largas y confusas (se proporciona un ejemplo en el archivo <datadir>/dumppat.txt).

ENTORNO

La utilidad dcmqrti intentará cargar los diccionarios de datos DICOM especificados en la variable de entorno DCMDICTPATH. Por defecto, es decir, si la variable de entorno DCMDICTPATH no está establecida, se cargará el archivo <datadir>/dicom.dic a menos que el diccionario esté integrado en la aplicación (predeterminado para Windows).

Se debe preferir el comportamiento predeterminado y la variable de entorno DCMDICTPATH solo debe usarse cuando se requieran diccionarios de datos alternativos. La variable de entorno DCMDICTPATH tiene el mismo formato que la variable PATH del shell Unix, de modo que dos puntos (":") separan las entradas. En sistemas Windows, se utiliza un punto y coma (";") como separador. El código del diccionario de datos intentará cargar cada archivo especificado en la variable de entorno DCMDICTPATH. Es un error si no se puede cargar ningún diccionario de datos.
