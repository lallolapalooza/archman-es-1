NOMBRE

dcb-maxrate - muestra / manipula la configuración de tasa máxima de puerto del subsistema DCB (Data Center Bridging)

SINOPSIS


dcb [ OPCIONES ] maxrate { COMANDO | help }

dcb maxrate show dev DEV [ tc-maxrate ]

dcb maxrate set dev DEV [ tc-maxrate MAPA-DE-TASAS ]

MAPA-DE-TASAS := [ MAPA-DE-TASAS ] MAPAJE-DE-TASA

MAPAJE-DE-TASA := { TC | all }:TASA

TC := { 0 .. 7 }

TASA := { ENTERO[bit] | ENTEROKbit | ENTEROMib | ... }

DESCRIPCIÓN

dcb maxrate se utiliza para configurar e inspeccionar la tasa máxima a la que se permite la salida de tráfico de una clase de tráfico dada.

PARÁMETROS

Lo siguiente describe solo la dirección de escritura, es decir, como se usa con el comando set. Para el comando show, el nombre del parámetro se usa como una palabra clave simple sin argumentos adicionales. Esto instruye a la herramienta a mostrar el valor de un parámetro dado. Cuando no se proporcionan parámetros, la herramienta muestra la configuración completa de maxrate.

tc-maxrate MAPA-DE-TASAS
MAPA-DE-TASAS utiliza la sintaxis del parámetro de matriz, consulte dcb(8) para obtener detalles. Las claves son índices de TC, los valores son tasas de tráfico en bits por segundo. Las tasas pueden usar la notación documentada en la sección PARÁMETROS en tc(8). Tenga en cuenta que bajo esa notación, "bit" significa bits por segundo, mientras que "b" significa bytes por segundo. Cuando se muestra, la opción de línea de comandos -i alterna entre el uso de prefijos decádicos e ISO/IEC.

EJEMPLO & USO

Establecer las tasas de todas las clases de tráfico a 25 Gbps, excepto para la TC 6, que tendrá una tasa de 100 Gbps:

# dcb maxrate set dev eth0 tc-maxrate all:25Gbit 6:100Gbit

Mostrar lo que se estableció:

# dcb maxrate show dev eth0
tc-maxrate 0:25Gbit 1:25Gbit 2:25Gbit 3:25Gbit 4:25Gbit 5:25Gbit 6:100Gbit 7:25Gbit

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso o un entero positivo en caso de fallo.
