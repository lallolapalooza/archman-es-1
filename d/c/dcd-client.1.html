NOMBRE

dcd-client - cliente de autocompletado para el lenguaje de programación D

SINOPSIS

dcd-client [-c, --cursorPos posiciónCursor] [-p, --port númeroPuerto] [--tcp] [--socketFile rutaArchivo] [-I directorio] [-h, --help] [-l, --symbolLocation] [-s, --search nombreSímbolo] [-d, --doc] [-q, --query, --status] [--shutdown] [--clearCache] [--version] [nombreArchivo]

DESCRIPCIÓN

dcd-client es un cliente para dcd-server y se usa típicamente por scripts de editores de texto.

OPCIONES

-c, --cursorPos posiciónCursor

Proporciona autocompletado en la posición del cursor dada. La posición del cursor se mide en bytes desde el inicio del código fuente.
-p, --port númeroPuerto
Elige el número de puerto en el que escucha dcd-client. Este interruptor implica --tcp.
--tcp
Escucha en un socket TCP en lugar de un socket de dominio UNIX. Este es el valor predeterminado en Windows.
--socketFile rutaArchivo
Establece la ruta a utilizar para el socket de dominio UNIX. No tiene efecto si se utilizan los interruptores --tcp o --port.
-I directorio
Informa a dcd-server para que almacene en caché los archivos fuente D encontrados en directorio para que se incluyan en las respuestas a futuras solicitudes de dcd-client.
-h, --help
Imprime un mensaje de ayuda
-l, --symbolLocation
Obtiene el nombre del archivo y la posición donde se definió el símbolo en la ubicación del cursor.
-s, --search nombreSímbolo
Enumera las ubicaciones donde se pueden encontrar símbolos con el nombreSímbolo dado.
-d, --doc
Obtiene los comentarios de documentación asociados con el símbolo en la ubicación del cursor.
-q, --query, --status
Consulta el estado del servidor. Devuelve 0 si el servidor se está ejecutando. Devuelve 1 si no se pudo contactar al servidor.
--shutdown
Instruye al servidor para que se apague
--clearCache
Instruye al servidor para que borre su caché de información de autocompletado.
nombreArchivo
Proporciona información de autocompletado para el archivo con el nombre dado.
