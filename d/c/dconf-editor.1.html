NOMBRE

dconf-editor - Editor gráfico para gsettings y dconf

SINOPSIS

dconf-editor [OPCIONES...]
dconf-editor [OPCIONES...] [RUTA]
dconf-editor [OPCIONES...] [ESQUEMA_FIJO | ESQUEMA_REUBICABLE:RUTA] [CLAVE]

DESCRIPCIÓN

El programa dconf-editor proporciona una interfaz gráfica para editar configuraciones que son almacenadas por otras aplicaciones usando las funciones gsettings de la biblioteca glib, o en la base de datos dconf. Las utilidades gsettings(1) y dconf(1) proporcionan funcionalidad similar en la línea de comandos.

OPCIONES

-h, --help
Imprime las opciones de la línea de comandos y sale.
-v, --version
Imprime la versión de lanzamiento y sale.
--list-relocatable-schemas
Imprime la lista de esquemas reubicables y sale.
--I-understand-that-changing-options-can-break-applications
Lanza la aplicación sin mostrar la advertencia inicial.

VER TAMBIÉN

dconf(7) dconf(1) gsettings(1)
