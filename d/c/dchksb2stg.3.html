subrutina dchksb2stg (integer nsizes, integer, dimension( * ) nn, integer nwdths, integer, dimension( * ) kk, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) sd, double precision, dimension( * ) se, double precision, dimension( * ) d1, double precision, dimension( * ) d2, double precision, dimension( * ) d3, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( * ) work, integer lwork, double precision, dimension( * ) result, integer info)

DCHKSB2STG

Propósito:

!>
!> DCHKSB2STG prueba la reducción de una matriz simétrica banda a forma
!> tridiagonal, usada con el problema de valores propios simétrico.
!>
!> DSBTRD factoriza una matriz simétrica banda A como  U S U' , donde ' significa
!> transpuesta, S es simétrica tridiagonal, y U es ortogonal.
!> DSBTRD puede usar ya sea solo el triángulo inferior o solo el superior
!> de A; DCHKSB2STG verifica ambos casos.
!>
!> DSYTRD_SB2ST factoriza una matriz simétrica banda A como  U S U' ,
!> donde ' significa transpuesta, S es simétrica tridiagonal, y U es
!> ortogonal. DSYTRD_SB2ST puede usar ya sea solo el triángulo inferior o solo
!> el superior de A; DCHKSB2STG verifica ambos casos.
!>
!> DSTEQR factoriza S como  Z D1 Z'.
!> D1 es la matriz de valores propios calculada cuando Z no es calculada
!> y a partir de la S resultante de DSBTRD  (usada como referencia para DSYTRD_SB2ST)
!> D2 es la matriz de valores propios calculada cuando Z no es calculada
!> y a partir de la S resultante de DSYTRD_SB2ST .
!> D3 es la matriz de valores propios calculada cuando Z no es calculada
!> y a partir de la S resultante de DSYTRD_SB2ST .
!>
!> Cuando DCHKSB2STG es llamado, un número de tamaños de matriz  (), un número
!> de anchos de banda (), y un número de tipos de matriz  son
!> especificados.  Para cada tamaño (), cada ancho de banda () menor o
!> igual a , y cada tipo de matriz, una matriz será generada
!> y usada para probar la rutina de reducción simétrica banda.  Para cada
!> matriz, un número de pruebas serán realizadas:
!>
!> (1)     | A - V S V' | / ( |A| n ulp )  calculado por DSBTRD con
!>                                         UPLO='U'
!>
!> (2)     | I - UU' | / ( n ulp )
!>
!> (3)     | A - V S V' | / ( |A| n ulp )  calculado por DSBTRD con
!>                                         UPLO='L'
!>
!> (4)     | I - UU' | / ( n ulp )
!>
!> (5)     | D1 - D2 | / ( |D1| ulp )      donde D1 es calculado por
!>                                         DSBTRD con UPLO='U' y
!>                                         D2 es calculado por
!>                                         DSYTRD_SB2ST con UPLO='U'
!>
!> (6)     | D1 - D3 | / ( |D1| ulp )      donde D1 es calculado por
!>                                         DSBTRD con UPLO='U' y
!>                                         D3 es calculado por
!>                                         DSYTRD_SB2ST con UPLO='L'
!>
!> Los tamaños  son especificados por un arreglo NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los tipos  son especificados por un arreglo lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces el tipo de matriz  será generado.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con  entradas 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!> (8)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (10) Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene  entradas 1, ULP,..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!> (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar.  Si es cero,
!>          DCHKSB2STG no hace nada.  Debe ser al menos cero.
!>

NN

!>          NN es un arreglo INTEGER, dimensión (NSIZES)
!>          Un arreglo que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos.  Los valores deben ser al menos
!>          cero.
!>

NWDTHS

!>          NWDTHS es INTEGER
!>          El número de anchos de banda a usar.  Si es cero,
!>          DCHKSB2STG no hace nada.  Debe ser al menos cero.
!>

KK

!>          KK es un arreglo INTEGER, dimensión (NWDTHS)
!>          Un arreglo que contiene los anchos de banda a usar para las matrices
!>          banda.  Los valores deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, DCHKSB2STG
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces un tipo adicional, MAXTYP+1 es
!>          definido, el cual es usar cualquier matriz que esté en A.  Esto
!>          es solo útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN una
!>          matriz de ese tamaño y de tipo j será generada.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a través de
!>          MAXTYP no serán generados.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a través de DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deberían estar entre 0 y 4095;
!>          si no, serán reducidos mod 4096.  Además, ISEED(4) debe
!>      ser impar.  El generador de números aleatorios usa una secuencia
!>      congruencial lineal limitada a enteros pequeños, y así
!>      debería producir números aleatorios independientes de la máquina. Los
!>      valores de ISEED son cambiados en la salida, y pueden ser usados en la
!>      siguiente llamada a DCHKSB2STG para continuar la misma secuencia de números aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará fallida si el , calculado como
!>          se describe anteriormente, supera THRESH.  Tenga en cuenta que el error
!>          está escalado para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100.  En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es un array DOUBLE PRECISION, dimensión
!>                            (LDA, max(NN))
!>          Se usa para almacenar la matriz cuyos eigenvalores deben ser
!>          calculados.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  Debe ser al menos 2 (¡no 1!)
!>          y al menos max( KK )+1.
!>

SD

!>          SD es un array DOUBLE PRECISION, dimensión (max(NN))
!>          Se usa para almacenar la diagonal de la matriz tridiagonal calculada
!>          por DSBTRD.
!>

SE

!>          SE es un array DOUBLE PRECISION, dimensión (max(NN))
!>          Se usa para almacenar la superdiagonal de la matriz tridiagonal
!>          calculada por DSBTRD.
!>

D1

!>          D1 es un array DOUBLE PRECISION, dimensión (max(NN))
!>

D2

!>          D2 es un array DOUBLE PRECISION, dimensión (max(NN))
!>

D3

!>          D3 es un array DOUBLE PRECISION, dimensión (max(NN))
!>

U

!>          U es un array DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          Se usa para almacenar la matriz ortogonal calculada por DSBTRD.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U.  Debe ser al menos 1
!>          y al menos max( NN ).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          El número de entradas en WORK.  Debe ser al menos
!>          max( LDA+1, max(NN)+1 )*max(NN).
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (4)
!>          Los valores calculados por las pruebas descritas anteriormente.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!>

INFO

!>          INFO es INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>
!>-----------------------------------------------------------------------
!>
!>       Algunas Variables y Parámetros Locales:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 y 1.
!>       MAXTYP          El número de tipos definidos.
!>       NTEST           El número de pruebas realizadas, o que pueden
!>                       realizarse hasta ahora, para la matriz actual.
!>       NTESTT          El número total de pruebas realizadas hasta ahora.
!>       NMAX            El valor más grande en NN.
!>       NMATS           El número de matrices generadas hasta ahora.
!>       NERRS           El número de pruebas que han excedido THRESH
!>                       hasta ahora.
!>       COND, IMODE     Valores a pasar a los generadores de matrices.
!>       ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>       OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>       ULP, ULPINV     Precisión relativa más fina y su inversa.
!>       RTOVFL, RTUNFL  Raíces cuadradas de los 2 valores anteriores.
!>               Las siguientes cuatro matrices decodifican JTYPE:
!>       KTYPE(j)        El tipo general (1-10) para el tipo .
!>       KMODE(j)        El valor MODE a pasar al generador de matrices
!>                       para el tipo .
!>       KMAGN(j)        El orden de magnitud ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!>
