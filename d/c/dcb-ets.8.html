.. 7 } DESCRIPCIÓNdcb etsse usa para configurar los atributos de Selección de Transmisión Mejorada a través de la interfaz Linux DCB (Puenteo de Centro de Datos). ETS permite la configuración del mapeo de prioridades a clases de tráfico, el algoritmo de selección de tráfico a usar por cada clase de tráfico,

la asignación de ancho de banda, etc.

Dos TLV de DCB están relacionados con la característica ETS: valores de configuración y de recomendación. Los valores de recomendación se nombran con el prefijo reco-, mientras que los de configuración tienen nombres

simples.

PARÁMETROS Para parámetros de lectura-escritura, lo siguiente describe solo la dirección de escritura, es decir, como se usa con el set comando. Para elshowcomando, el nombre del parámetro se debe usar como una palabra clave simple sin argumentos adicionales. Esto le indica a la herramienta que muestre el valor de un parámetro dado.

Cuando no se dan parámetros, la herramienta muestra la configuración completa de ETS.
