Propósito:

!>
!> DCHKAB es el programa de prueba para la rutina LAPACK de PRECISIÓN DOBLE
!> DSGESV/DSPOSV
!>
!> El programa debe ser impulsado por un archivo de datos corto. Los primeros 5
!> registros especifican las dimensiones del problema y las opciones del programa
!> usando entrada dirigida por lista. Las líneas restantes especifican las rutas
!> de prueba de LAPACK y el número de tipos de matriz a usar en las pruebas.
!> Un ejemplo anotado de un archivo de datos se puede obtener eliminando los
!> primeros 3 caracteres de las siguientes 10 líneas:
!> Archivo de datos para probar DSGESV de LAPACK de PRECISIÓN DOBLE
!> 7                      Número de valores de M
!> 0 1 2 3 5 10 16        Valores de M (dimensión de fila)
!> 1                      Número de valores de NRHS
!> 2                      Valores de NRHS (número de lados derechos)
!> 20.0                   Valor umbral de la relación de prueba
!> T                      Poner T para probar las rutinas LAPACK
!> T                      Poner T para probar las salidas de error
!> DGE    11              Lista de tipos en la siguiente línea si 0 < NTYPES < 11
!> DPO    9               Lista de tipos en la siguiente línea si 0 < NTYPES <  9
!> 
!>  NMAX    INTEGER
!>          El valor máximo permitido para N
!>
!>  MAXIN   INTEGER
!>          El número de valores diferentes que se pueden usar para cada uno de
!>          M, N, NRHS, NB, y NX
!>
!>  MAXRHS  INTEGER
!>          El número máximo de lados derechos
!>
!>  NIN     INTEGER
!>          El número de unidad para entrada
!>
!>  NOUT    INTEGER
!>          El número de unidad para salida
!>
