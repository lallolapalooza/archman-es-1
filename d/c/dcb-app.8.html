NOMBRE

dcb-app - mostrar / manipular la tabla de prioridades de aplicaciones del subsistema DCB (Data Center Bridging)

SINOPSIS


dcb [ OPCIONES ] app { COMANDO | help }

dcb app { show | flush } dev DEV [ default-prio ] [ ethtype-prio ] [ stream-port-prio ] [ dgram-port-prio ] [ port-prio ] [ dscp-prio ] [ pcp-prio ]

dcb app { add | del | replace } dev DEV [ default-prio LISTA-PRIO ] [ ethtype-prio MAPA-ET ] [ stream-port-prio MAPA-PUERTO ] [ dgram-port-prio MAPA-PUERTO ] [ port-prio MAPA-PUERTO ] [ dscp-prio MAPA-DSCP ] [ pcp-prio MAPA-PCP ]

LISTA-PRIO := [ LISTA-PRIO ] PRIO

MAPA-ET := [ MAPA-ET ] MAPEO-ET

MAPEO-ET := ET:PRIO

MAPA-PUERTO := [ MAPA-PUERTO ] MAPEO-PUERTO

MAPEO-PUERTO := PUERTO:PRIO

MAPA-DSCP := [ MAPA-DSCP ] MAPEO-DSCP

MAPEO-DSCP := { DSCP | all }:PRIO

MAPA-PCP := [ MAPA-PCP ] MAPEO-PCP

MAPEO-PCP := PCP:PRIO

ET := { 0x600 .. 0xffff }

PUERTO := { 1 .. 65535 }

DSCP := { 0 .. 63 }

PCP := { 0(nd/de) .. 7(nd/de) }

PRIO := { 0 .. 7 }

DESCRIPCIÓN

dcb app se utiliza para configurar la tabla APP, o tabla de prioridad de aplicaciones, en el subsistema DCB (Data Center Bridging). La tabla APP se utiliza para asignar prioridad al tráfico basándose en el valor de una de varias cabeceras: EtherType, puerto de destino L4, o DSCP. También permite la configuración de la prioridad por defecto del puerto que se elige si ninguna otra regla de priorización se aplica.

Las entradas DCB APP son tuplas de 3 elementos: selector, ID de protocolo y prioridad. El selector es una enumeración que elige uno de los espacios de nombres de priorización. Actualmente, corresponde en su mayor parte a los parámetros configurables descritos a continuación. El ID de protocolo es un valor en el espacio de nombres del selector. Por ejemplo, para el selector EtherType, los IDs de protocolo son los EtherTypes individuales; para DSCP son los puntos de código individuales. La prioridad es la prioridad que se debe asignar al tráfico que coincide con el selector y el ID de protocolo.

La tabla APP es un conjunto de entradas DCB APP. El único requisito es que no se añadan entradas duplicadas. Notablemente, es válido tener una asignación de prioridad conflictiva para el mismo selector e ID de protocolo. Por ejemplo, el conjunto de dos entradas APP (DSCP, 10, 1) y (DSCP, 10, 2), donde los paquetes con DSCP 10 deberían obtener prioridad tanto 1 como 2, forman una tabla APP bien definida. La herramienta dcb app permite la gestión de bajo nivel de la tabla app añadiendo y eliminando tuplas APP individuales a través de los comandos add y del. Por otro lado, el comando replace hace lo que uno típicamente querría en esta situación: primero añade la nueva configuración y luego elimina la obsoleta, de modo que solo una priorización esté en efecto para un selector e ID de protocolo dados.

COMANDOS

show
Muestra todas las entradas con un selector dado. Cuando no se proporciona ningún selector, muestra todas las entradas de la tabla APP categorizadas por selector.
flush
Elimina todas las entradas con un selector dado. Cuando no se proporciona ningún selector, elimina todas las entradas de la tabla APP.
add
del
Añade y, respectivamente, elimina tuplas APP individuales de y hacia la tabla DCB APP.
replace
Toma la lista de entradas mencionadas como parámetro, y añade aquellas que aún no están presentes en la tabla APP. Luego elimina aquellas entradas cuyo selector y ID de protocolo se han mencionado como parámetro, pero no con la misma prioridad exacta. Esto tiene el efecto de, para el selector e ID de protocolo dados, hacer que la tabla solo contenga la prioridad (o prioridades) dadas como parámetro.

PARÁMETROS

La siguiente tabla muestra los parámetros de la manera en que se usarían con los comandos add, del y replace. Para show y flush, el nombre del parámetro debe usarse como una palabra clave simple sin más argumentos.

default-prio LISTA-PRIO
La prioridad que se usará para el tráfico cuya prioridad no esté de otro modo especificada. El argumento es una lista de prioridades individuales. Tenga en cuenta que las reglas default-prio se configuran como tríos (EtherType, 0, PRIO). dcb app traduce estas reglas al nombre simbólico default-prio y viceversa.
ethtype-prio MAPA-ET
MAPA-ET utiliza la sintaxis de parámetros de arreglo, ver dcb(8) para más detalles. Las claves son valores EtherType. Los valores son las prioridades que se asignarán al tráfico con el EtherType coincidente.
stream-port-prio MAPA-PUERTO
dgram-port-prio MAPA-PUERTO
port-prio MAPA-PUERTO
MAPA-PUERTO utiliza la sintaxis de parámetros de arreglo, ver dcb(8) para más detalles. Las claves son números de puerto de destino L4 que coinciden, respectivamente, con tráfico TCP y SCTP, tráfico UDP y DCCP, o cualquiera de los anteriores. Los valores son las prioridades que se asignarán al tráfico coincidente.
dscp-prio MAPA-DSCP
MAPA-DSCP utiliza la sintaxis de parámetros de arreglo, ver dcb(8) para más detalles. Las claves son puntos DSCP, los valores son las prioridades asignadas al tráfico con DSCP coincidente. Los puntos DSCP se pueden escribir directamente como valores numéricos, o utilizando nombres simbólicos especificados en /etc/iproute2/rt_dsfield (sin embargo, tenga en cuenta que el archivo especifica valores de dsfield de 8 bits completos, mientras que dcb app solo usará los seis bits superiores). dcb app show formateará de manera similar los valores DSCP como nombres simbólicos si es posible. La opción de línea de comandos -N desactiva la traducción de la visualización.
pcp-prio MAPA-PCP
MAPA-PCP utiliza la sintaxis de parámetros de arreglo, ver dcb(8) para más detalles. Las claves son PCP/DEI. Los valores son las prioridades asignadas al tráfico con PCP/DEI coincidente. Los valores PCP/DEI se escriben como una combinación de valores numéricos y simbólicos, para acomodar ambos. PCP siempre en forma numérica, p. ej. 0 .. 7 y DEI en forma simbólica, p. ej. 'de' (drop-eligible, elegible para descarte), indicando que el bit DEI es 1, o 'nd' (not-drop-eligible, no elegible para descarte), indicando que el bit DEI es 0. En combinación, 2de:1 se traduce a un mapeo de PCP=2 y DEI=1 a prioridad 1.

EJEMPLO Y USO

Priorizar el tráfico con DSCP 0 a prioridad 0, 24 a 3 y 48 a 6:

# dcb app add dev eth0 dscp-prio 0:0 24:3 48:6

Añadir otra regla para configurar DSCP 24 a prioridad 2 y mostrar el resultado:

# dcb app add dev eth0 dscp-prio 24:2
# dcb app show dev eth0 dscp-prio
dscp-prio 0:0 CS3:2 CS3:3 CS6:6
# dcb -N app show dev eth0 dscp-prio
dscp-prio 0:0 24:2 24:3 48:6

Reconfigurar la tabla para que la única regla para DSCP 24 sea para la asignación de prioridad 4:

# dcb app replace dev eth0 dscp-prio 24:4
# dcb app -N show dev eth0 dscp-prio
dscp-prio 0:0 24:4 48:6

Limpiar todas las reglas DSCP:

# dcb app flush
