T

Propósito

: 
!>
!> DCHKST  comprueba las rutinas del problema de valores propios simétricos.
!>
!>    DSYTRD factoriza A como  U S U' , donde ' significa transpuesta,
!>    S es simétrica tridiagonal, y U es ortogonal.
!>    DSYTRD puede usar solo el triángulo inferior o solo el superior
!>    de A; DCHKST comprueba ambos casos.
!>    U se representa como un producto de transformaciones
!>    de Householder, cuyos vectores se almacenan en las primeras
!>    n-1 columnas de V, y cuyos factores de escala están en TAU.
!>
!>    DSPTRD hace lo mismo que DSYTRD, excepto que A y V se almacenan
!>    en  formato.
!>
!>    DORGTR construye la matriz U a partir del contenido de V y TAU.
!>
!>    DOPGTR construye la matriz U a partir del contenido de VP y TAU.
!>
!>    DSTEQR factoriza S como  Z D1 Z' , donde Z es la matriz
!>    ortogonal de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal.  D2 es la matriz de
!>    valores propios calculada cuando Z no se calcula.
!>
!>    DSTERF calcula D3, la matriz de valores propios, por el
!>    método PWK, que no produce vectores propios.
!>
!>    DPTEQR factoriza S como  Z4 D4 Z4' , para una
!>    matriz tridiagonal simétrica definida positiva.
!>    D5 es la matriz de valores propios calculada cuando Z no se
!>    calcula.
!>
!>    DSTEBZ calcula valores propios seleccionados.  WA1, WA2, y
!>    WA3 denotarán valores propios calculados con alta
!>    precisión absoluta, con diferentes opciones de rango.
!>    WR denotará valores propios calculados con alta precisión
!>    relativa.
!>
!>    DSTEIN calcula Y, los vectores propios de S, dados los
!>    valores propios.
!>
!>    DSTEDC factoriza S como Z D1 Z' , donde Z es la matriz
!>    ortogonal de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal (opción 'I'). También puede
!>    actualizar una matriz ortogonal de entrada, usualmente la salida
!>    de DSYTRD/DORGTR o DSPTRD/DOPGTR (opción 'V'). También puede
!>    solo calcular valores propios (opción 'N').
!>
!>    DSTEMR factoriza S como Z D1 Z' , donde Z es la matriz
!>    ortogonal de vectores propios y D1 es una matriz diagonal con
!>    los valores propios en la diagonal (opción 'I').  DSTEMR
!>    usa la Representación Robusta Relativamente siempre que sea posible.
!>
!> Cuando se llama a DCHKST, se especifica un número de matrices  () y un
!> número de matrices .  Para cada tamaño ()
!> y cada tipo de matriz, se generará una matriz y se usará
!> para probar las rutinas de valores propios simétricos.  Para cada matriz, se realizará un número
!> de pruebas:
!>
!> (1)     | A - V S V' | / ( |A| n ulp ) DSYTRD( UPLO='U', ... )
!>
!> (2)     | I - UV' | / ( n ulp )        DORGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V' | / ( |A| n ulp ) DSYTRD( UPLO='L', ... )
!>
!> (4)     | I - UV' | / ( n ulp )        DORGTR( UPLO='L', ... )
!>
!> (5-8)   Igual que 1-4, pero para DSPTRD y DOPGTR.
!>
!> (9)     | S - Z D Z' | / ( |S| n ulp ) DSTEQR('V',...)
!>
!> (10)    | I - ZZ' | / ( n ulp )        DSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        DSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        DSTERF
!>
!> (13)    0 si los valores propios reales (calculados por conteo de Sturm)
!>         de S están dentro de THRESH de
!>         los de D1.  2*THRESH si no lo están.  (Probado usando
!>         DSTECH)
!>
!> Para S definida positiva,
!>
!> (14)    | S - Z4 D4 Z4' | / ( |S| n ulp ) DPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4' | / ( n ulp )        DPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       DPTEQR('N',...)
!>
!> Cuando S también es diagonalmente dominante por el factor gamma < 1,
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              DSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          DSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              DSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y' | / ( |S| n ulp )  DSTEBZ, SSTEIN
!>
!> (21)    | I - Y Y' | / ( n ulp )          DSTEBZ, SSTEIN
!>
!> (22)    | S - Z D Z' | / ( |S| n ulp )    DSTEDC('I')
!>
!> (23)    | I - ZZ' | / ( n ulp )           DSTEDC('I')
!>
!> (24)    | S - Z D Z' | / ( |S| n ulp )    DSTEDC('V')
!>
!> (25)    | I - ZZ' | / ( n ulp )           DSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           DSTEDC('V') y
!>                                              DSTEDC('N')
!>
!> La prueba 27 está deshabilitada en este momento porque DSTEMR no
!> garantiza alta precisión relativa.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              DSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              DSTEMR('V', 'I')
!>
!> Las pruebas 29 a 34 están deshabilitadas en el presente porque DSTEMR
!> no maneja solicitudes de espectro parcial.
!>
!> (29)    | S - Z D Z' | / ( |S| n ulp )    DSTEMR('V', 'I')
!>
!> (30)    | I - ZZ' | / ( n ulp )           DSTEMR('V', 'I')
!>
!> (31)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         DSTEMR('N', 'I') vs. SSTEMR('V', 'I')
!>
!> (32)    | S - Z D Z' | / ( |S| n ulp )    DSTEMR('V', 'V')
!>
!> (33)    | I - ZZ' | / ( n ulp )           DSTEMR('V', 'V')
!>
!> (34)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         DSTEMR('N', 'V') vs. SSTEMR('V', 'V')
!>
!> (35)    | S - Z D Z' | / ( |S| n ulp )    DSTEMR('V', 'A')
!>
!> (36)    | I - ZZ' | / ( n ulp )           DSTEMR('V', 'A')
!>
!> (37)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         DSTEMR('N', 'A') vs. SSTEMR('V', 'A')
!>
!> Los  se especifican mediante un arreglo NN(1:NSIZES); el valor de
!> cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un arreglo lógico DOTYPE( 1:NTYPES );
!> si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!>
!> (3)  Una matriz diagonal con entradas equiespaciadas
!>      1, ..., ULP  y signos aleatorios.
!>      (ULP = (primer número mayor que 1) - 1 )
!> (4)  Una matriz diagonal con entradas geométricamente espaciadas
!>      1, ..., ULP  y signos aleatorios.
!> (5)  Una matriz diagonal con  entradas 1, ULP, ..., ULP
!>      y signos aleatorios.
!>
!> (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!> (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!> (8)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene entradas equiespaciadas 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!>
!> (9)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene entradas geométricamente espaciadas 1, ..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (10) Una matriz de la forma  U' D U, donde U es ortogonal y
!>      D tiene  entradas 1, ULP,..., ULP con signos
!>      aleatorios en la diagonal.
!>
!> (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!> (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!>
!> (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!> (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!> (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!> (16) Igual que (8), pero los elementos diagonales son todos positivos.
!> (17) Igual que (9), pero los elementos diagonales son todos positivos.
!> (18) Igual que (10), pero los elementos diagonales son todos positivos.
!> (19) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento )
!> (20) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento por abajo )
!> (21) Una matriz tridiagonal diagonalmente dominante con entradas
!>      diagonales geométricamente espaciadas 1, ..., ULP.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar.  Si es cero,
!>          DCHKST no hace nada.  Debe ser al menos cero.
!>

NN

!>          NN es un arreglo INTEGER, dimensión (NSIZES)
!>          Un arreglo que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán.  Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, DCHKST
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es utilizar la matriz que esté en A.  Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no se generarán.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>          se ignorarán.
!>

ISEED

!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debe producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican en la salida, y pueden usarse en la
!>          siguiente llamada a DCHKST para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se contará como  si el , calculado como
!>          se describe arriba, excede THRESH.  Tenga en cuenta que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100.  En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!>

A

!>          A es un arreglo DOUBLE PRECISION de
!>                                  dimensión ( LDA , max(NN) )
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular.  En la salida, A contiene la última matriz realmente
!>          utilizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  Debe ser al
!>          menos 1 y al menos max( NN ).
!>

AP

!>          AP es un arreglo DOUBLE PRECISION de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz A almacenada en formato empaquetado.
!>

SD

!>          SD es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          La diagonal de la matriz tridiagonal calculada por DSYTRD.
!>          En la salida, SD y SE contienen la forma tridiagonal de la
!>          matriz en A.
!>

SE

!>          SE es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          La subdiagonal de la matriz tridiagonal calculada por
!>          DSYTRD.  En la salida, SD y SE contienen la forma tridiagonal de
!>          la matriz en A.
!>

D1

!>          D1 es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por DSTEQR simultáneamente
!>          con Z.  En la salida, los valores propios en D1 corresponden con la
!>          matriz en A.
!>

D2

!>          D2 es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por DSTEQR si Z no se
!>          calcula.  En la salida, los valores propios en D2 corresponden con
!>          la matriz en A.
!>

D3

!>          D3 es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por DSTERF.  En la salida, los
!>          valores propios en D3 corresponden con la matriz en A.
!>

D4

!>          D4 es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por DPTEQR(V).
!>          DPTEQR factoriza S como  Z4 D4 Z4*
!>          En la salida, los valores propios en D4 corresponden con la matriz en A.
!>

D5

!>          D5 es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Los valores propios de A, calculados por DPTEQR(N)
!>          cuando Z no se calcula. En la salida, los
!>          valores propios en D4 corresponden con la matriz en A.
!>

WA1

!>          WA1 es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          como calculados por DSTEBZ.
!>

WA2

!>          WA2 es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          como calculados por DSTEBZ.
!>          Elija valores aleatorios para IL e IU, y solicite los
!>          valores propios del IL-ésimo al IU-ésimo.
!>

WA3

!>          WA3 es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Valores propios seleccionados de A, calculados con alta
!>          precisión absoluta, con diferentes opciones de rango.
!>          como calculados por DSTEBZ.
!>          Determine los valores VL y VU del IL-ésimo y IU-ésimo
!>          valores propios y solicite todos los valores propios en este rango.
!>

WR

!>          WR es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>          Todos los valores propios de A, calculados con alta
!>          precisión absoluta, con diferentes opciones.
!>          como calculados por DSTEBZ.
!>

U

!>          U es un arreglo DOUBLE PRECISION de
!>                             dimensión( LDU, max(NN) ).
!>          La matriz ortogonal calculada por DSYTRD + DORGTR.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U, Z y V.  Debe ser al menos 1
!>          y al menos max( NN ).
!>

V

!>          V es un arreglo DOUBLE PRECISION de
!>                             dimensión( LDU, max(NN) ).
!>          Los vectores de Householder calculados por DSYTRD al reducir A a
!>          forma tridiagonal.  Los vectores calculados con UPLO='U' están
!>          en el triángulo superior, y los vectores calculados con UPLO='L'
!>          están en el triángulo inferior.  (Como se describe en DSYTRD, la
!>          subdiagonal y superdiagonal no se establecen en 1, aunque el
!>          verdadero vector de Householder tiene un 1 en esa posición.  Las
!>          rutinas que usan V, como DORGTR, establecen esas entradas en
!>          1 antes de usarlas, y luego las restauran más tarde.)
!>

VP

!>          VP es un arreglo DOUBLE PRECISION de
!>                      dimensión( max(NN)*max(NN+1)/2 )
!>          La matriz V almacenada en formato empaquetado.
!>

TAU

!>          TAU es un arreglo DOUBLE PRECISION de
!>                             dimensión( max(NN) )
!>

NAME

                    
dchkst - 

                

                

                    
SYNOPSIS

                    
 SUBROUTINE DCHKST( NSIZES, NN, NTYPES, THRESH, LA, LDA, LDU,     &
                                        LWORK, LIWORK, IERR, RESULT, WORK, IWORK,      &
                                        INF, NSIZE, NTYPE )


      CHARACTER * 1          THRESH
      INTEGER                INFO, LA, LDA, LDU, LIWORK, NSIZES, NSIZE, NTYPE,
                             NTEST, NTESTT, NMAX, NMATS, NERRS, NN(*), NTYPES,
                             IWORK(*)
      DOUBLE PRECISION       RESULT(*), WORK(*)


                

                

                    
Function/Subroutine Documentation

                    
This routine checks the nonsymmetric eigenvalue routines.

                    
Purpose

                    
   DCHKST checks the nonsymmetric eigenvalue routines DLATMR, SLATMS,
   DSYTRD, DORGTR, DSTEQR, SSTERF, DPTEQR, DSTEIN, and DORMC2.

                    
Usage

                    
   Call DCHKST( NSIZES, NN, NTYPES, THRESH, LA, LDA, LDU,
                  LWORK, LIWORK, IERR, RESULT, WORK, IWORK, INF, NSIZE, NTYPE )

                    
Arguments

                    

                        
NSIZES

                        

                            
INTEGER. Number of values of N for which
                                to run the tests.

                        

                        
NN

                        

                            
INTEGER array, dimension (NSIZES). The values
                                of N to be used in the tests.

                        

                        
NTYPES

                        

                            
INTEGER. The number of matrix types to be
                                tested.

                        

                        
THRESH

                        

                            
REAL.

                            
A threshold value used in determining whether
                                to proceed with a test.

                        

                        
LA

                        

                            
INTEGER. The dimension of the array A.

                        

                        
A

                        

                            
A is DOUBLE PRECISION array, dimension (LA).

                        

                        
LDA

                        

                            
INTEGER. Leading dimension of the array A used
                                for the matrix. LDA must be at least max(1, NMAX),
                                where NMAX is the maximum value in NN.

                        

                        
LDU

                        

                            
INTEGER. The dimension of the array U.

                        

                        
U

                        

                            
U is DOUBLE PRECISION array, dimension( LDU, max(NN) ).
                                The orthogonal matrix computed by DORGTR, DPOTRF, or
                                DPOTRFS.

                        

                        
WORK

                        

                            
WORK is DOUBLE PRECISION array, dimension( LWORK ).

                        

                        
LWORK

                        

                            
INTEGER. The number of entries in WORK. This
                                must be at least 1 + 4 * Nmax + 2 * Nmax * lg Nmax + 3 * Nmax**2
                                where Nmax = max( NN(j), 2 ) and lg = log base 2.

                        

                        
IWORK

                        

                            
IWORK is INTEGER array, Workspace.

                        

                        
LIWORK

                        

                            
INTEGER. The number of entries in IWORK. This
                                must be at least 6 + 6*Nmax + 5 * Nmax * lg Nmax
                                where Nmax = max( NN(j), 2 ) and lg = log base 2.

                        

                        
RESULT

                        

                            
RESULT is DOUBLE PRECISION array, dimension (26)

                            
The values computed by the tests described
