NOMBRE

dcd-server - servidor de autocompletado para el lenguaje de programación D

SINOPSIS

dcd-server [-I directorio] [-p|--port numeroPuerto] [--tcp] [--socketFile rutaArchivo] [--logLevel nivel] [-h|--help] [--version]

DESCRIPCIÓN

dcd-server almacena en caché información sobre archivos fuente de D que se encontraron

OPCIONES

-p, --port numeroPuerto

Elige el número de puerto en el que dcd-server escucha. Este interruptor implica --tcp.
--tcp
Escucha en un socket TCP en lugar de un socket de dominio UNIX. Este es el valor predeterminado en Windows.
--socketFile rutaArchivo
Establece la ruta a utilizar para el socket de dominio UNIX. No tiene efecto si se utilizan los interruptores --tcp o --port.
--logLevel nivel
Configura el nivel de registro para dcd-server. Los valores válidos son all trace info warning error critical fatal off
-I directorio
Incluye directorio en la lista de directorios para escanear archivos fuente. Esta opción se puede especificar varias veces.
-h, --help
Imprime un mensaje de ayuda.
--version
Imprime el número de versión actual y sale.

ARCHIVOS

dcd-server puede configurarse mediante el uso de un archivo llamado dcd.conf Este archivo debe colocarse en una de las siguientes ubicaciones:

•
/etc/dcd.conf

•
${XDG_CONFIG_HOME}/dcd/dcd.conf

•
${HOME}/.config/dcd/dcd.conf

Cada línea del archivo debe ser una ruta para buscar archivos fuente de D. Una línea en dcd.conf es equivalente a pasar esa misma línea a dcd-server con la opción -I. Las líneas que comienzan con el carácter '#' se ignoran.

A menos que se utilice el interruptor --tcp, dcd-server intentará comunicarse con el cliente a través de un socket de dominio UNIX. dcd-server intentará crear el socket en las siguientes ubicaciones:

•
${XDG_RUNTIME_DIR}/dcd.socket

•
/tmp/dcd-${UID}.socket
