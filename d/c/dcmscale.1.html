NOMBRE

dcmscale - Escalar imágenes DICOM

SINOPSIS

dcmscale [opciones] dcmfile-in dcmfile-out

DESCRIPCIÓN

La utilidad dcmscale lee una imagen DICOM, la escala según la configuración de la línea de comandos y vuelve a escribir la imagen DICOM. Esta utilidad solo admite imágenes DICOM sin comprimir y comprimidas con RLE.

PARÁMETROS

dcmfile-in   Nombre del archivo DICOM de entrada a escalar ("-" para stdin)
dcmfile-out  Nombre del archivo DICOM de salida a escribir ("-" para stdout)

OPCIONES

opciones generales

  -h    --help
          imprimir este texto de ayuda y salir
        --version
          imprimir información de versión y salir
        --arguments
          imprimir los argumentos de la línea de comandos expandidos
  -q    --quiet
          modo silencioso, no imprimir advertencias ni errores
  -v    --verbose
          modo detallado, imprimir detalles del procesamiento
  -d    --debug
          modo depuración, imprimir información de depuración
  -ll   --log-level  [l]evel: constante de cadena
          (fatal, error, warn, info, debug, trace)
          usar el nivel l para el registrador
  -lc   --log-config  [f]ilename: cadena
          usar el archivo de configuración f para el registrador

opciones de entrada

formato del archivo de entrada:
  +f    --read-file
          leer el formato del archivo o el conjunto de datos (predeterminado)
  +fo   --read-file-only
          leer solo el formato del archivo
  -f    --read-dataset
          leer el conjunto de datos sin la meta información del archivo
sintaxis de transferencia de entrada:
  -t=   --read-xfer-auto
          usar el reconocimiento de ST (predeterminado)
  -td   --read-xfer-detect
          ignorar la ST especificada en la cabecera de meta información del archivo
  -te   --read-xfer-little
          leer con la sintaxis de transferencia de VR explícito little endian
  -tb   --read-xfer-big
          leer con la sintaxis de transferencia de VR explícito big endian
  -ti   --read-xfer-implicit
          leer con la sintaxis de transferencia de VR implícito little endian

opciones de procesamiento y codificación de imagen

escalado:
  +a    --recognize-aspect
          reconocer la relación de aspecto de píxeles al escalar (predeterminado)
  -a    --ignore-aspect
          ignorar la relación de aspecto de píxeles al escalar
  +i    --interpolate  [n]úmero de algoritmo: entero
          usar interpolación al escalar (1..4, predeterminado: 1)
  -i    --no-interpolation
          no usar interpolación al escalar
  -S    --no-scaling
          no escalar, ignorar la relación de aspecto de píxeles (predeterminado)
  +Sxf  --scale-x-factor  [f]actor: flotante
          escalar el eje x por el factor, calcular automáticamente el eje y
  +Syf  --scale-y-factor  [f]actor: flotante
          escalar el eje y por el factor, calcular automáticamente el eje x
  +Sxv  --scale-x-size  [n]úmero: entero
          escalar el eje x a n píxeles, calcular automáticamente el eje y
  +Syv  --scale-y-size  [n]úmero: entero
          escalar el eje y a n píxeles, calcular automáticamente el eje x
otras transformaciones:
  +C    --clip-region  [l]eft [t]op [w]idth [h]eight: entero
          recortar la región rectangular de la imagen (l, t, w, h)
UID de instancia SOP:
  +ua   --uid-always
          asignar siempre un nuevo UID de instancia SOP (predeterminado)
  +un   --uid-never
          nunca asignar un nuevo UID de instancia SOP

opciones de salida

formato del archivo de salida:
  +F    --write-file
          escribir el formato del archivo (predeterminado)
  -F    --write-dataset
          escribir el conjunto de datos sin la meta información del archivo
sintaxis de transferencia de salida:
  +t=   --write-xfer-same
          escribir con la misma ST que la entrada (predeterminado)
  +te   --write-xfer-little
          escribir con la sintaxis de transferencia de VR explícito little endian
  +tb   --write-xfer-big
          escribir con la sintaxis de transferencia de VR explícito big endian
  +ti   --write-xfer-implicit
          escribir con la sintaxis de transferencia de VR implícito little endian
representaciones de valor posteriores a 1993:
  +u    --enable-new-vr
          habilitar el soporte para nuevos VR (UN/UT) (predeterminado)
  -u    --disable-new-vr
          deshabilitar el soporte para nuevos VR, convertir a OB
codificación de longitud de grupo:
  +g=   --group-length-recalc
          recalcular las longitudes de grupo si están presentes (predeterminado)
  +g    --group-length-create
          escribir siempre con elementos de longitud de grupo
  -g    --group-length-remove
          escribir siempre sin elementos de longitud de grupo
codificación de longitud en secuencias e ítems:
  +e    --length-explicit
          escribir con longitudes explícitas (predeterminado)
  -e    --length-undefined
          escribir con longitudes indefinidas
relleno al final del conjunto de datos (no con --write-dataset):
  -p=   --padding-retain
          no cambiar el relleno
          (predeterminado si no se usa --write-dataset)
  -p    --padding-off
          sin relleno (implícito si se usa --write-dataset)
  +p    --padding-create  [f]ile-pad [i]tem-pad: entero
          alinear el archivo en múltiplos de f bytes y los ítems en
          múltiplos de i bytes

NOTAS

Los siguientes algoritmos de interpolación preferidos pueden seleccionarse usando la opción --interpolate :

  • 1 = algoritmo de escalado libre con interpolación del conjunto de herramientas pbmplus
  • 2 = algoritmo de escalado libre con interpolación de la revista c't
  • 3 = algoritmo de ampliación con interpolación bilineal de Eduard Stanescu
  • 4 = algoritmo de ampliación con interpolación bicúbica de Eduard Stanescu

REGISTRO

El nivel de salida de registro de las diversas herramientas de línea de comandos y las bibliotecas subyacentes puede ser especificado por el usuario. Por defecto, solo se escriben errores y advertencias en el flujo de error estándar. Usando la opción --verbose también se informan mensajes informativos como detalles del procesamiento. La opción --debug puede usarse para obtener más detalles sobre la actividad interna, por ejemplo, con fines de depuración. Otros niveles de registro pueden seleccionarse usando la opción --log-level. En el modo --quiet solo se informan errores fatales. En tales eventos de error muy graves, la aplicación normalmente terminará. Para más detalles sobre los diferentes niveles de registro, consulte la documentación del módulo "oflog".

En caso de que la salida de registro deba escribirse en un archivo (opcionalmente con rotación de registros), en syslog (Unix) o en el registro de eventos (Windows), puede usarse la opción --log-config . Este archivo de configuración también permite dirigir solo ciertos mensajes a un flujo de salida particular y filtrar ciertos mensajes basándose en el módulo o la aplicación donde se generan. Se proporciona un archivo de configuración de ejemplo en <etcdir>/logger.cfg.

LÍNEA DE COMANDOS

Todas las herramientas de línea de comandos usan la siguiente notación para los parámetros: los corchetes encierran valores opcionales (0-1), tres puntos finales indican que se permiten múltiples valores (1-n), una combinación de ambos significa de 0 a n valores.

Las opciones de la línea de comandos se distinguen de los parámetros por un signo inicial '+' o '-', respectivamente. Normalmente, el orden y la posición de las opciones de la línea de comandos son arbitrarios (es decir, pueden aparecer en cualquier lugar). Sin embargo, si las opciones son mutuamente excluyentes, se usa la aparición más a la derecha. Este comportamiento se ajusta a las reglas de evaluación estándar de los shells Unix comunes.

Además, se pueden especificar uno o más archivos de comando usando el signo '@' como prefijo del nombre de archivo (por ejemplo, @command.txt). Tal argumento de comando se reemplaza por el contenido del archivo de texto correspondiente (múltiples espacios en blanco se tratan como un solo separador a menos que aparezcan entre dos comillas) antes de cualquier otra evaluación. Tenga en cuenta que un archivo de comando no puede contener otro archivo de comando. Este enfoque simple pero efectivo permite resumir combinaciones comunes de opciones/parámetros y evita líneas de comandos largas y confusas (se proporciona un ejemplo en el archivo <datadir>/dumppat.txt).

ENTORNO

La utilidad dcmscale intentará cargar los diccionarios de datos DICOM especificados en la variable de entorno DCMDICTPATH . Por defecto, es decir, si la variable de entorno DCMDICTPATH no está establecida, se cargará el archivo <datadir>/dicom.dic a menos que el diccionario esté compilado en la aplicación (predeterminado para Windows).

Se debe preferir el comportamiento predeterminado y la variable de entorno DCMDICTPATH solo debe usarse cuando se requieran diccionarios de datos alternativos. La variable de entorno DCMDICTPATH tiene el mismo formato que la variable PATH del shell Unix, en la que un dos puntos (":") separa las entradas. En los sistemas Windows, se usa un punto y coma (";") como separador.rador. El código del diccionario de datos intentará cargar cada archivo especificado en la DCMDICTPATH variable de entorno. Es un error si no se puede cargar ningún diccionario de datos.
