DCKCSD

Propósito:

!>
!> DCKCSD prueba DORCSD:
!>        la CSD para una matriz ortogonal X de M por M particionada como
!>        [ X11 X12; X21 X22 ]. X11 es de P por Q.
!>

Parámetros

NM 
!>          NM es INTEGER
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es un array INTEGER, dimensión (NM)
!>          Los valores de la dimensión de filas de la matriz M.
!>

PVAL

!>          PVAL es un array INTEGER, dimensión (NM)
!>          Los valores de la dimensión de filas de la matriz P.
!>

QVAL

!>          QVAL es un array INTEGER, dimensión (NM)
!>          Los valores de la dimensión de columnas de la matriz Q.
!>

NMATS

!>          NMATS es INTEGER
!>          El número de tipos de matriz a probar para cada combinación
!>          de dimensiones de matriz.  Si NMATS >= NTYPES (el número
!>          máximo de tipos de matriz), se generan todos los diferentes
!>          tipos para la prueba.  Si NMATS < NTYPES, se lee otra línea de
!>          entrada para obtener los números de los tipos de matriz a usar.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada, la semilla del generador de números aleatorios. Los
!>          elementos del array deben estar entre 0 y 4095, de lo contrario se
!>          reducirán mód 4096, y ISEED(4) debe ser impar.
!>          En la salida, la siguiente semilla en la secuencia de números
!>          aleatorios después de que se hayan generado todas las matrices
!>          de prueba.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para los cocientes de prueba.  Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH.  Para que
!>          se imprima cada cociente de prueba, use THRESH = 0.
!>

MMAX

!>          MMAX es INTEGER
!>          El valor máximo permitido para M, usado en la dimensionación de
!>          los arrays de trabajo.
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (MMAX*MMAX)
!>

XF

!>          XF es un array DOUBLE PRECISION, dimensión (MMAX*MMAX)
!>

U1

!>          U1 es un array DOUBLE PRECISION, dimensión (MMAX*MMAX)
!>

U2

!>          U2 es un array DOUBLE PRECISION, dimensión (MMAX*MMAX)
!>

V1T

!>          V1T es un array DOUBLE PRECISION, dimensión (MMAX*MMAX)
!>

V2T

!>          V2T es un array DOUBLE PRECISION, dimensión (MMAX*MMAX)
!>

THETA

!>          THETA es un array DOUBLE PRECISION, dimensión (MMAX)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MMAX)
!>

WORK

!>          WORK es un array DOUBLE PRECISION
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION
!>

NIN

!>          NIN es INTEGER
!>          El número de unidad para la entrada.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0 :  salida exitosa
!>          > 0 :  Si DLAROR devuelve un código de error, se devuelve el
!>                 valor absoluto de este.
!>
