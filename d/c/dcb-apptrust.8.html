NOMBRE

dcb-apptrust - muestra / configura la confianza por selector y el orden de confianza de la tabla de prioridad de aplicaciones de la subclase DCB (Data Center Bridging).

SINOPSIS


dcb [ OPCIONES ] apptrust { COMANDO | help }

dcb apptrust show dev DEV [ order ]

dcb apptrust set dev DEV [ order SEL-LIST ]

SEL-LIST := [ SEL-LIST ] SEL

SEL := { ethtype | stream-port | dgram-port | port | dscp | pcp }

DESCRIPCIÓN

dcb apptrust se utiliza para configurar la confianza por selector y el orden de confianza de la Tabla de Prioridad de Aplicaciones, consulte dcb-app(8) para obtener detalles sobre cómo configurar entradas de la tabla de aplicaciones.

La confianza del selector puede ser utilizada por la pila de software, o los controladores (lo más probable es que estos últimos), al consultar la tabla APP, para determinar si una entrada de aplicación debe tener efecto o no. Además, el orden de los selectores confiables dictará qué selector debe tener prioridad, en caso de que haya múltiples selectores de tabla de aplicaciones diferentes presentes.

COMANDOS

show
Muestra todos los selectores confiables.
set
Establece una nueva lista de selectores confiables. Una lista vacía es efectivamente lo mismo que eliminar la confianza por completo.

PARÁMETROS

Lo siguiente describe solo la dirección de escritura, es decir, tal como se usa con el comando set. Para el comando show, el nombre del parámetro se usará como una palabra clave simple sin argumentos adicionales. Esto instruye a la herramienta para que muestre los valores de un parámetro dado.

order SEL-LIST
SEL-LIST es una lista separada por espacios de nombres de selectores. Los valores de selector posibles son: ethtype, stream-port, dgram-port, port, dscp, y pcp

EJEMPLO Y USO

Establece el orden de confianza a: dscp, pcp para eth0:

# dcb apptrust set dev eth0 order dscp pcp

Establece el orden de confianza a: port (stream o dgram), pcp, ethtype para eth1:

# dcb apptrust set dev eth1 order port pcp ethtype

Muestra lo que se estableció:

# dcb apptrust show dev eth0
order: port pcp ethtype

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso o un entero positivo en caso de error.

VER TAMBIÉN
