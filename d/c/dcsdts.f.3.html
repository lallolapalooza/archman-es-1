DCSDTS

Propósito:

!>
!> DCSDTS prueba DORCSD, que, dada una matriz ortogonal particionada M por M
!> X,
!>              Q  M-Q
!>       X = [ X11 X12 ] P   ,
!>           [ X21 X22 ] M-P
!>
!> calcula la CSD (Descomposición de Valores Singulares)
!>
!>       [ U1    ]**T * [ X11 X12 ] * [ V1    ]
!>       [    U2 ]      [ X21 X22 ]   [    V2 ]
!>
!>                             [  I  0  0 |  0  0  0 ]
!>                             [  0  C  0 |  0 -S  0 ]
!>                             [  0  0  0 |  0  0 -I ]
!>                           = [---------------------] = [ D11 D12 ] ,
!>                             [  0  0  0 |  I  0  0 ]   [ D21 D22 ]
!>                             [  0  S  0 |  0  C  0 ]
!>                             [  0  0  I |  0  0  0 ]
!>
!> y también DORCSD2BY1, que, dada
!>          Q
!>       [ X11 ] P   ,
!>       [ X21 ] M-P
!>
!> calcula la CSD 2x1
!>
!>                                     [  I  0  0 ]
!>                                     [  0  C  0 ]
!>                                     [  0  0  0 ]
!>       [ U1    ]**T * [ X11 ] * V1 = [----------] = [ D11 ] ,
!>       [    U2 ]      [ X21 ]        [  0  0  0 ]   [ D21 ]
!>                                     [  0  S  0 ]
!>                                     [  0  0  I ]
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz X.  M >= 0.
!>

P

!>          P es ENTERO
!>          El número de filas de la matriz X11.  P >= 0.
!>

Q

!>          Q es ENTERO
!>          El número de columnas de la matriz X11.  Q >= 0.
!>

X

!>          X es un array de DOBLE PRECISIÓN, dimensión (LDX,M)
!>          La matriz X de M por M.
!>

XF

!>          XF es un array de DOBLE PRECISIÓN, dimensión (LDX,M)
!>          Detalles de la CSD de X, tal como se devuelve por DORCSD;
!>          ver DORCSD para más detalles.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal de los arrays X y XF.
!>          LDX >= max( 1,M ).
!>

U1

!>          U1 es un array de DOBLE PRECISIÓN, dimensión(LDU1,P)
!>          La matriz ortogonal U1 de P por P.
!>

LDU1

!>          LDU1 es ENTERO
!>          La dimensión principal del array U1. LDU >= max(1,P).
!>

U2

!>          U2 es un array de DOBLE PRECISIÓN, dimensión(LDU2,M-P)
!>          La matriz ortogonal U2 de (M-P) por (M-P).
!>

LDU2

!>          LDU2 es ENTERO
!>          La dimensión principal del array U2. LDU >= max(1,M-P).
!>

V1T

!>          V1T es un array de DOBLE PRECISIÓN, dimensión(LDV1T,Q)
!>          La matriz ortogonal V1T de Q por Q.
!>

LDV1T

!>          LDV1T es ENTERO
!>          La dimensión principal del array V1T. LDV1T >=
!>          max(1,Q).
!>

V2T

!>          V2T es un array de DOBLE PRECISIÓN, dimensión(LDV2T,M-Q)
!>          La matriz ortogonal V2T de (M-Q) por (M-Q).
!>

LDV2T

!>          LDV2T es ENTERO
!>          La dimensión principal del array V2T. LDV2T >=
!>          max(1,M-Q).
!>

THETA

!>          THETA es un array de DOBLE PRECISIÓN, dimensión MIN(P,M-P,Q,M-Q)
!>          Los valores CS de X; las matrices esencialmente diagonales C y
!>          S se construyen a partir de THETA; ver la subrutina DORCSD para
!>          detalles.
!>

IWORK

!>          IWORK es un array de ENTEROS, dimensión (M)
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK
!>

RWORK

!>          RWORK es un array de DOBLE PRECISIÓN
!>

RESULT

!>          RESULT es un array de DOBLE PRECISIÓN, dimensión (15)
!>          Las razones de prueba:
!>          Primero, la CSD 2x2:
!>          RESULT(1) = norma( U1'*X11*V1 - D11 ) / ( MAX(1,P,Q)*EPS2 )
!>          RESULT(2) = norma( U1'*X12*V2 - D12 ) / ( MAX(1,P,M-Q)*EPS2 )
!>          RESULT(3) = norma( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(4) = norma( U2'*X22*V2 - D22 ) / ( MAX(1,M-P,M-Q)*EPS2 )
!>          RESULT(5) = norma( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(6) = norma( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(7) = norma( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(8) = norma( I - V2T'*V2T ) / ( MAX(1,M-Q)*ULP )
!>          RESULT(9) = 0        si THETA está en orden creciente y
!>                               todos los ángulos están en [0,pi/2]
!>                     = ULPINV   en caso contrario.
!>          Luego, la CSD 2x1:
!>          RESULT(10) = norma( U1'*X11*V1 - D11 ) / ( MAX(1,P,Q)*EPS2 )
!>          RESULT(11) = norma( U2'*X21*V1 - D21 ) / ( MAX(1,M-P,Q)*EPS2 )
!>          RESULT(12) = norma( I - U1'*U1 ) / ( MAX(1,P)*ULP )
!>          RESULT(13) = norma( I - U2'*U2 ) / ( MAX(1,M-P)*ULP )
!>          RESULT(14) = norma( I - V1T'*V1T ) / ( MAX(1,Q)*ULP )
!>          RESULT(15) = 0        si THETA está en orden creciente y
!>                               todos los ángulos están en [0,pi/2]
!>                     = ULPINV   en caso contrario.
!>          ( EPS2 = MAX( norma( I - X'*X ) / M, ULP ). )
!>
