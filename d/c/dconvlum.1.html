NOMBRE

dconvlum - Convierte archivos VeriLUM a archivos de visualización DCMTK

SINOPSIS

dconvlum archivo-entrada archivo-salida [ambiente]

DESCRIPCIÓN

Programa de línea de comandos que convierte el archivo VeriLUM con datos de curva característica (CCx_xx.dat) a un formato utilizado para la transformación de Barten en este conjunto de herramientas. VeriLUM es un paquete de calibración de ImageSmiths que consta de un fotómetro (con conector serie RS232) y un software para Windows NT.

PARáMETROS

archivo-entrada   Archivo de curva característica VeriLUM a convertir
archivo-salida  Archivo de visualización DCMTK a escribir
ambiente        Luz ambiental (cd/m^2, valor de punto flotante)

NOTAS

El archivo de salida que describe la curva característica de un sistema de visualización (monitor) es un archivo de texto simple. Las líneas que comienzan con '#' se tratan como comentarios y, por lo tanto, se omiten, al igual que las líneas en blanco. Este programa de conversión crea automáticamente dicho archivo (incluidas algunas líneas de comentarios) al transformar la información almacenada en el archivo VeriLUM. El número que sigue a la palabra mágica 'max' define el valor DDL (nivel de conducción digital) máximo (por ejemplo, 255 para pantallas de 8 bits). Esta definición es necesaria antes de que se puedan definir los datos de luminancia. Opcionalmente, el valor de la luz ambiental también se puede especificar en este archivo. El valor de punto flotante (en candela por metro cuadrado) debe seguir a la palabra 'amb'. Finalmente, se definen los valores de luminancia para cada valor DDL (nivel de conducción digital) correspondiente. Las entradas no necesariamente tienen que estar ordenadas o completas, es decir, puede haber menos de 'max' + 1 entradas. Los valores faltantes se calculan mediante interpolación de spline cúbico.

Consulte la parte 14 del estándar DICOM para obtener más detalles sobre la calibración de la pantalla y el modelo de Barten (incluido GSDF).
