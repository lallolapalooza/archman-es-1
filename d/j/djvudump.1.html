NOMBRE

djvudump - Muestra la estructura interna de los archivos DjVu.

SINOPSIS

djvudump [-o archivo_salida] archivos_djvu...

DESCRIPCIÓN

El programa djvudump imprime una representación indentada de la estructura de bloques de cualquier archivo DjVu. Cada línea contiene un ID de bloque seguido del tamaño del bloque. Las líneas están indentadas para reflejar la estructura jerárquica de los archivos IFF. El identificador de página se imprime entre llaves cuando se reconoce un documento DjVu multipágina agrupado. Se proporciona información adicional sobre cada bloque cuando djvudump reconoce el nombre del bloque y sabe cómo resumir los datos del bloque.

OBSERVACIONES

Este programa, de hecho, es capaz de describir cualquier archivo que cumpla con la especificación Electronic Arts IFF 85. Esto incluye una serie de formatos de archivo gráficos y de sonido.

CRÉDITOS
