DJabberd::Component::Node(3) Documentación de Perl aportada por el usuario DJabberd::Component::Node(3)

NOMBRE

DJabberd::Component::Node - Especialización de DJabberd::Agent::Node que sabe que pertenece a un componente

DESCRIPCIÓN

Esta clase abstracta es una especialización de DJabberd::Agent::Node. La única diferencia entre esta clase y su padre es que los nodos representados por esta clase "saben" que pertenecen a un componente y tienen una referencia a ese componente almacenada.

SINOPSIS

Crea tu clase de nodo como una subclase de esta clase:

package MyPackage::DJabberd::MyNode;
use base DJabberd::Component::Node;

# Ejemplo de un agente que responde a mensajes de chat entrantes

sub handle_message {
    my ($self, $vhost, $stanza) = @_;

    my $response = $stanza->make_response();
    $response->set_raw("<body>Hola. Soy un agente de software.</body>");
    $response->deliver($vhost);
}

La clase puede ser instanciada a partir de un método en una instancia de DJabberd::Component:

# $self aquí es un objeto DJabberd::Component
my $node = MyPackage::DJabberd::MyNode->new(
    component => $self,
    nodename => "bob",
);

La instancia creada anteriormente aceptará stanzas dirigidas al nodo "bob" dentro del dominio propiedad del componente dado.

No es posible utilizar directamente subclases de esta clase como plugins de entrega, ya que deben asociarse a un componente en tiempo de ejecución.

VER TAMBIÉN

Ver también DJabberd::Agent::Node, DJabberd::Component.
