DJVUXML(1) Herramientas XML de DjVuLibre DJVUXML(1)

NOMBRE

djvutoxml, djvuxmlparser - Herramientas XML de DjVuLibre.

SINOPSIS

djvutoxml [opciones] ficherodjvuentrada [ficheroxmlsalida]
djvuxmlparser [ -o ficherodjvu ] ficheroxmlentrada

DESCRIPCIÓN

Las Herramientas XML de DjVuLibre permiten editar los metadatos, hipervínculos y texto oculto asociados con los ficheros DjVu. A diferencia de djvused(1) las Herramientas XML de DjVuLibre se basan en la tecnología XML y pueden aprovechar los editores y verificadores XML.

DJVUTOXML

El programa djvutoxml crea un fichero XML ficheroxmlsalida que contiene una referencia al documento DjVu original ficherodjvuentrada así como etiquetas que describen los metadatos, hipervínculos y texto oculto asociados con el fichero DjVu.

Se admiten las siguientes opciones:

--page numpágina
Selecciona una página en un documento multipágina. Sin esta opción, djvutoxml genera el XML correspondiente a todas las páginas del documento.
--with-text
Especifica que el elemento HIDDENTEXT de cada página debe incluirse en la salida. Si se especifica sin la opción --with-anno entonces se implica --without-anno . Si no se especifica ninguna de las opciones --with-text, --without-text, --with-anno, o --without-anno, se implica la opción --with-text y la opción --with-anno .
--without-text
Especifica no generar el elemento HIDDENTEXT para cada página. Si se especifica sin la opción --without-anno entonces se implica la opción --with-anno .
--with-anno
Especifica que el elemento de área MAP de cada página debe incluirse en la salida. Si se especifica sin la opción --with-text entonces se implica la opción --without-text .
--without-anno
Especifica que el elemento de área MAP de cada página no debe incluirse en la salida. Si se especifica sin la opción --without-text entonces se implica la opción --with-text .

DJVUXMLPARSER

Los ficheros producidos por djvutoxml pueden modificarse usando un editor de texto o un editor XML. El programa djvuxmlparser analiza el fichero XML ficheroxmlentrada para modificar los metadatos del fichero DjVu correspondiente.

-o ficherodjvu
En principio, el fichero DjVu de destino es el fichero referenciado por el elemento OBJECT del fichero XML. Esta opción proporciona el medio para anular el nombre de fichero especificado en el elemento OBJECT .

DEFINICIÓN DE TIPO DE DOCUMENTO DJVUXML

El fichero de definición de tipo de documento (DTD)

/usr/share/djvu/pubtext/DjVuXML-s.dtd

define la entrada y salida de las herramientas XML de DjVu.

El DTD DjVuXML-s es una simplificación del DTD HTML:

http://www.w3c.org/TR/1998/REC-html40-19980424/sgml/dtd.html

con algunos atributos nuevos añadidos específicos de DjVu. Cada una de las páginas especificadas de un documento DjVu se representa como elementos OBJECT dentro del elemento BODY del fichero XML. Cada elemento OBJECT puede contener múltiples elementos PARAM para especificar atributos como el nombre de la página, la resolución y el factor gamma. Cada elemento OBJECT también puede contener un elemento HIDDENTTEXT para especificar el texto oculto (generalmente generado con un motor OCR) dentro de la página DjVu. Además, cada elemento OBJECT puede referenciar un único elemento de área MAP que contiene múltiples elementos AREA para representar todas las áreas de hipervínculo y resaltado dentro del documento DjVu.

Elementos PARAM

Los elementos PARAM válidos de un OBJECT de DjVu incluyen, pero no se limitan a, PAGE para especificar el nombre de la página, GAMMA para especificar el factor de corrección gamma (normalmente 2.2), y DPI para especificar la resolución de la página.

Elementos HIDDENTEXT

Los elementos HIDDENTEXT consisten en elementos anidados de PAGECOLUMNS, REGION, PARAGRAPH, LINE, y WORD. El elemento anidado más profundamente especificado debe indicar las coordenadas del límite del elemento en orientación de arriba hacia abajo. El cuerpo del elemento anidado más profundamente debe contener el texto. La mayoría de los documentos DjVu usan ya sea LINE o WORD como el elemento de nivel más bajo, pero cualquier elemento es válido como el elemento de nivel más bajo. Un espacio en blanco siempre se añade entre elementos WORD y un salto de línea siempre se añade entre elementos LINE . Dado que lenguas como el japonés no usan espacios entre palabras, es bastante común que los motores OCR asiáticos usen WORD como caracteres en su lugar.

Elementos MAP

El cuerpo de los elementos MAP consiste en elementos AREA . Además de los atributos listados en

http://www.w3.org/TR/1998/REC-html40-19980424/struct/objects.html#edef-AREA,

se han añadido los atributos bordertype, bordercolor, border, y highlight para especificar el tipo de borde, el color del borde, el ancho del borde y los colores de resaltado respectivamente. Los valores válidos para cada uno de estos atributos están listados en el DTD DjVuXML-s. Además, la forma oval se ha añadido a la lista de formas válidas. Un óvalo usa un cuadro delimitador rectangular.

ERRORES

Quizás habría sido mejor usar hojas de estilo CC2 con elementos HTML estándar en lugar de definir el elemento HIDDENTEXT .

CRÉDITOS

Las herramientas XML de DjVu y el DTD fueron escritos por Bill C. Riemers <docbill@sourceforge.net> y Fred Crary.

    NAME

    djvuxml - an XML parser for DjVu files

    SYNOPSIS

    djvuxml

    DESCRIPTION

    The djvuxml utility is a parser for DjVu files. It reads a DjVu file and outputs its metadata in XML format. This can be useful for various tasks such as extracting information from DjVu documents, transforming them into other formats, or integrating them into other applications.

    OPTIONS

    This command does not take any command line arguments.

    ELEMENTS

    The XML output produced by djvuxml includes various elements that represent the metadata of the DjVu file. Some of the key elements include:

    • DJVUTOXML: The root element for the XML output.
    • DJVUXMLPARSER: Represents the parser itself and its version.
    • DJVUXML DOCUMENT TYPE DEFINITION: Contains the DOCTYPE declaration for the XML document.
    • PARAM Elements: Represents parameters associated with the DjVu document, such as title, author, etc.
    • HIDDENTEXT Elements: Represents hidden text layers within the DjVu file.
    • MAP Elements: Represents map information, such as hyperlinks or regions within the document.

    BUGS

    No known bugs.

    CREDITS

    This utility is part of the DjVuLibre project.
