NOMBRE

DJabberd::Component::External - Interfaz para plugins externos que implementan JEP-0114

DESCRIPCIÓN

Este componente proporciona soporte para conectar componentes externos que soportan el Protocolo de Componentes Jabber especificado en JEP-0114. Especifique el puerto TCP en el que el componente externo se conectará y el secreto que utilizará para autenticarse. Estos deben coincidir con los ajustes equivalentes en la propia configuración del componente.

También puede especificar una opción ListenAddr, que especifica la dirección IP de la interfaz en la que escuchar. Por defecto, solo escuchamos en la dirección de loopback, 127.0.0.1. Alternativamente, puede proporcionar un socket de dominio UNIX (una ruta absoluta que comienza con una barra) y omitir la configuración ListenPort para esperar una conexión en un socket de dominio UNIX. Sin embargo, la mayoría de los componentes no soportan sockets de dominio UNIX.

Tenga en cuenta que este componente solo implementa la variación "aceptar" del protocolo, donde DJabberd abre un socket de escucha y espera a que el componente se conecte. La variación "conectar", donde el componente espera a que DJabberd se conecte a él, no está soportada.

SINOPSIS

<Plugin DJabberd::Component::External>
  ListenPort 23534
  Secret somesecret
</Plugin>
