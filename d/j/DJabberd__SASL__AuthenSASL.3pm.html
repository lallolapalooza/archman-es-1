NOMBRE

DJabberd::SASL::AuthenSASL - Negociación SASL usando Authen::SASL

DESCRIPCIÓN

Este plugin proporciona soporte directo para negociaciones SASL dentro de DJabberd utilizando Authen::SASL (Authen::SASL::Perl, por ahora). Complementa la autenticación iq-auth (XEP-0078) ahora obsoleta.

El uso recomendado es usar STARTTLS y SASL-PLAIN.

SINOPSIS

<VHost yann.cyberion.net>
    <Plugin DJabberd::SASL::AuthenSASL>
        Optional   yes
        Mechanisms PLAIN LOGIN DIGEST-MD5
    </Plugin>
</VHost>

DESCRIPCIÓN

Por ahora solo se admiten los mecanismos PLAIN LOGIN y DIGEST-MD5 (igual que en Authen::SASL. DIGEST-MD5 solo admite el nivel de protección "auth" (quality of protection), por lo que se aconseja encarecidamente incluir TLS y no depender únicamente de DIGEST-MD5 (a diferencia de "auth-int" y "auth-conf").
