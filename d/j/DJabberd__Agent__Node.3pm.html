DJabberd::Agent::Node(3) Documentación de Perl contribuida por el usuario DJabberd::Agent::Node(3)

NOMBRE

DJabberd::Agent::Node - Clase abstracta para un agente que maneja un nodo específico

SINÓPSIS

package MyPackage::DJabberd::MyNode;
use base DJabberd::Agent::Node;

# Ejemplo de un agente que responde a mensajes de chat entrantes

sub handle_message {
    my ($self, $vhost, $stanza) = @_;

    my $response = $stanza->make_response();
    $response->set_raw("<body>Hola. Soy un agente de software.</body>");
    $response->deliver($vhost);
}

Esta clase proporciona una clase padre para agentes que reciben stanzas dirigidas a un nombre de nodo específico dentro de un dominio.

A menudo, a un agente de este tipo se le denomina "Bot". En DJabberd::Bot también se proporciona una API de nivel superior para implementar "chat bots".

USO

Esta clase es una especialización de DJabberd::Agent. En la mayoría de los casos, los usuarios de esta clase utilizarán la API expuesta por DJabberd::Agent. Sin embargo, hay algunos comportamientos especiales a tener en cuenta y algunos métodos adicionales que no forman parte de la clase de agente básica.

handles_destination($self, $to_jid, $vhost)

Esta clase proporciona una versión sobreescrita de este método que responde con un valor verdadero si y solo si el dominio y el nombre de nodo del JID de destino coinciden con los que maneja esta instancia.

vcard($self, $requester_jid)

La versión sobreescrita de este método devolverá una vCard donde el nombre completo se establece en el nombre de nodo de esta instancia. Las subclases probablemente querrán sobreescribir esto para hacer algo más sofisticado.

VER TAMBIÉN
