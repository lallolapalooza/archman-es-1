NOMBRE

djview4 - Visor DjVu independiente

SINOPSIS

djview4 [opciones] [argumento]

DESCRIPCIÓN

Visor independiente para archivos DjVu. Las características incluyen la navegación por documentos, el zoom y el paneo de las imágenes de las páginas, la producción y visualización de miniaturas, la visualización de esquemas de documentos, la búsqueda de palabras específicas en documentos de la capa de texto oculta, la copia de texto oculto al portapapeles, el guardado de páginas y documentos como archivos multipágina empaquetados o indirectos, y la impresión de páginas y documentos. El visor puede mostrar simultáneamente varias páginas utilizando un diseño uno al lado del otro o continuo.

ARGUMENTO DE LÍNEA DE COMANDOS Y OPCIONES

Este programa puede ejecutarse como un programa independiente o como un proceso esclavo para el plugin de navegador DjVu nsdejavu. Al ejecutarse como un programa independiente, el argumento de línea de comandos argumento puede ser:

  • El nombre de archivo de un documento DjVu válido.
  • Una URL de documento DjVu local de la forma:
file:///ruta/nombre.djvu[?djvuopts&clave=valor&...]
Los corchetes delimitan los componentes opcionales de la URL. Se pueden especificar varias opciones utilizando una sintaxis similar a la de los argumentos de CGI. Especificar opciones de esta manera es muy útil para un plugin de navegador ya que no hay argumentos de línea de comandos. En el caso de un visor independiente, todas las opciones se pueden especificar como argumentos de línea de comandos.
*
Una URL de documento DjVu remoto de la forma:
http://host/ruta/nombre.djvu[?djvuopts&clave=valor&...]
https://host/ruta/nombre.djvu[?djvuopts&clave=valor&...]
Navegar documentos DjVu remotos con el visor independiente es menos eficiente que usar el plugin del navegador. El visor independiente no se beneficia de las estrategias de caché y la configuración proxy del navegador. La configuración proxy para el visor independiente se puede establecer de forma independiente con el diálogo de preferencias.

Se reconoce una extensa lista de opciones. La mayoría de las opciones se pueden especificar como argumento de línea de comandos que comienza con el guion convencional (-) o utilizando la sintaxis de argumentos de CGI en la URL del documento. Sin embargo, algunas opciones solo son significativas como argumentos de línea de comandos. Otras opciones solo se reconocen al ejecutar la versión X11 del programa djview4.

OPCIONES DE LÍNEA DE COMANDOS

Las siguientes opciones solo son significativas cuando se especifican en la línea de comandos.

-ayuda
Muestra un breve mensaje de ayuda.
-detallado
Imprime mensajes informativos en la consola. Esta opción es muy útil ya que muestra mensajes sobre las construcciones no reconocidas en las capas de anotación e hipervínculo de DjVu.
-pantalla-completa, -fs
Inicia djview4 en modo de pantalla completa. Usa la tecla ESC para salir del modo de pantalla completa.
-presentacion-diapositivas[=arg]
Inicia djview4 en modo de presentación de diapositivas. El argumento numérico opcional arg especifica el número de segundos antes de pasar a la siguiente página. Usa la tecla ESC para salir del modo de presentación de diapositivas.
-estilo=nombreestilo
Especifica el estilo de la interfaz gráfica de usuario. Los valores reconocidos para nombreestilo dependen de la versión instalada del kit de herramientas Qt. Los nombres de estilo comunes incluyen cde, motif, plastique, platinum y windows.

OPCIONES X11

Las siguientes opciones de línea de comandos son reconocidas por la versión X11 del programa djview4. A diferencia de la mayoría de las opciones de djview4, las opciones X11 que requieren un argumento no utilizan el carácter igual para introducir su argumento.

-pantalla nombrepantalla
Especifica que las ventanas de djview4 deben aparecer en la pantalla X11 nombrepantalla.
-geometria AxH+X+Y
Especifica el tamaño y la posición inicial de la primera ventana utilizando la sintaxis tradicional de especificación de geometría X11. Los argumentos numéricos A y H representan el ancho y la altura inicial de la ventana. Los argumentos numéricos X e Y indican la posición de la ventana en relación con la esquina superior izquierda de la pantalla.
-nombre nombre
Establece el nombre de la aplicación.
-titulo titulo
Establece el título de la primera ventana.
-fn nombrefuente, -fuente nombrefuente
Especifica el nombre de la fuente predeterminada utilizada para botones y menús. La fuente debe especificarse utilizando una cadena de descripción de fuente lógica X.
-bg color, -fondo color
Especifica el color de fondo predeterminado para los elementos de la interfaz gráfica de usuario. El color debe proporcionarse como un nombre de color X11 estándar.
-fg color, -primerplano color
Especifica el color de primer plano predeterminado para los elementos de la interfaz gráfica de usuario. El color debe proporcionarse como un nombre de color X11 estándar.
-btn color
Especifica el color de botón predeterminado. El color debe proporcionarse como un nombre de color X11 estándar.
-ncols contador
Limita el número de colores asignados en una pantalla de 8 bits. El cubo de colores predeterminado contiene 216 colores distintos.
-cmap
Fuerza la asignación de un mapa de color privado en una pantalla de 8 bits. Esto puede aumentar la calidad del color, pero causar parpadeos cuando la ventana del visor se activa.

Muestra una página específica del documento. El visor primero busca una página cuyo identificador coincida con el argumento nombrepagina. De lo contrario, comenzando desde la página actual y dando la vuelta, busca una página cuyo título coincida con el argumento nombrepagina. De lo contrario, si nombrepagina es numérico, se interpreta como un número de página ordinal. De lo contrario, y finalmente, el visor busca una página cuyo nombre coincida con nombrepagina.

ENTORN

O

Establecer la variable de entorno DJVIEW_VERBOSE a un valor distinto de cero equivale a llamar a djview con la opción -verbose. Establecer la variable de entorno DJVIEW_OPENGL a los valores 0 o 1 anula la configuración de preferencias sobre el renderizado

OpenGL.

Cuando el usuario hace clic en un hipervínculo djvu que apunta a una página web, el programa primero intenta ejecutar los programas de navegador web cuyos nombres están listados en la variable de entorno separada por dos puntos BROWSER, luego intenta valores predeterminados sensatos dependientes de la

plataforma.

El idioma de la interfaz de usuario se determina primero intentando encontrar un conjunto completo de archivos de traducción para el idioma especificado en el diálogo de preferencias, luego para los idiomas ISO 639 especificados en la variable de entorno separada por dos puntos LANGUAGE, y finalmente el idioma especificado por la configuración regional del sistema. Si tod

as estas búsquedas fallan, el idioma de la in
terfaz de usuario vuelve al inglés predeterminado.
