NOMBRE

DJabberd::Component::Example - Un componente de servicio de ejemplo para DJabberd

SINOPSIS

<Subdominio ejemplo>
    <Plugin DJabberd::Component::Example>
        Saludo Hola, mundo!
    </Plugin>
</Subdominio>

Esta clase implementa un componente muy simple que responde a todos los mensajes entrantes con un saludo predefinido y que devuelve una vCard para sí mismo cuando se solicita una. Puedes cambiar el saludo devuelto usando la opción de configuración opcional Saludo, como se muestra arriba.

Este ejemplo también expone un nodo llamado "somebloke" que responde a todos los mensajes con una sorpresa británica auténtica.

Este ejemplo utiliza la API de alto nivel proporcionada por DJabberd::Agent, de la cual hereda DJabberd::Component. DJabberd::Component::External sirve como ejemplo de cómo manejar stanzas a un nivel inferior al sobrescribir el método "handle_stanza".
