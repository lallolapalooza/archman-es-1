NOMBRE

djvm - Manipula documentos DjVu multi-página empaquetados.

SINOPSIS

   Creación de un documento empaquetado:

djvm -c[reate] doc.djvu pagina1.djvu ... paginaN.djvu

   Inserción:

djvm -i[nsert] doc.djvu pagina.djvu [numeropagina]

   Eliminación:

djvm -d[elete] doc.djvu numeropagina

   Listado:

djvm -l[ist] doc.djvu

DESCRIPCIÓN

Este programa crea o modifica un documento DjVu multi-página empaquetado. Los documentos empaquetados multi-página se pueden usar directamente o convertir a documento indirecto usando el comando djvmcvt.

OPCIONES

-c[reate]
Crea un documento DjVu empaquetado llamado doc.djvu recopilando los archivos pagina1.djvu a paginaN.djvu.
-i[nsert]
Modifica el documento DjVu empaquetado llamado doc.djvu insertando el archivo pagina.djvu como página numeropagina. Omitir el argumento numeropagina significa que la página se añadirá al final del documento. El archivo pagina.djvu también puede ser un documento DjVu multi-página. Todas las páginas se insertarán en la ubicación especificada.
-d[elete]
Elimina la página numeropagina del documento DjVu multi-página empaquetado doc.djvu.
-l[ist]
Lista todos los archivos componentes en el documento DjVu multi-página doc.djvu.
