DJVUXML(1) Herramientas XML de DjVuLibre DJVUXML(1)

NOMBRE

djvutoxml, djvuxmlparser - Herramientas XML de DjVuLibre.

SINOPSIS

djvutoxml [opciones] archivodjvuentrada [archivoxmlsalida]
djvuxmlparser [ -o archivodjvu ] archivoxmlentrada

DESCRIPCIÓN

Las Herramientas XML de DjVuLibre permiten editar los metadatos, enlaces y texto oculto asociados con los archivos DjVu. A diferencia de djvused(1), las Herramientas XML de DjVuLibre se basan en la tecnología XML y pueden aprovechar los editores y verificadores XML.

DJVUTOXML

El programa djvutoxml crea un archivo XML archivoxmlsalida que contiene una referencia al documento DjVu original archivodjvuentrada, así como etiquetas que describen los metadatos, enlaces e información de texto oculto asociados con el archivo DjVu.

Se admiten las siguientes opciones:

--pagina numeropagina
Selecciona una página en un documento multipágina. Sin esta opción, djvutoxml genera el XML correspondiente a todas las páginas del documento.
--con-texto
Especifica que el elemento HIDDENTEXT para cada página se incluya en la salida. Si se especifica sin el indicador --con-anotaciones, se implican los indicadores --sin-anotaciones. Si no se especifican los indicadores --con-texto, --sin-texto, --con-anotaciones, o --sin-anotaciones, entonces se implican los indicadores --con-texto y --con-anotaciones.
--sin-texto
Especifica que no se genere el elemento HIDDENTEXT para cada página. Si se especifica sin el indicador --sin-anotaciones, se implica el indicador --con-anotaciones.
--con-anotaciones
Especifica que el elemento MAP de área para cada página se incluya en la salida. Si se especifica sin el indicador --con-texto, se implica el indicador --sin-texto.
--sin-anotaciones
Especifica que el elemento MAP de área para cada página no se incluya en la salida. Si se especifica sin el indicador --sin-texto, se implica el indicador --con-texto.

DJVUXMLPARSER

Los archivos producidos por djvutoxml se pueden modificar utilizando un editor de texto o un editor XML. El programa djvuxmlparser analiza el archivo XML archivoxmlentrada para modificar los metadatos del archivo DjVu correspondiente.

-o archivodjvu
En principio, el archivo DjVu de destino es el archivo referenciado por el elemento OBJECT del archivo XML. Esta opción proporciona el medio para anular el nombre de archivo especificado en el elemento OBJECT.

DEFINICIÓN DE TIPO DE DOCUMENTO DJVUXML

El archivo de definición de tipo de documento (DTD)

/usr/share/djvu/pubtext/DjVuXML-s.dtd

define la entrada y salida de las herramientas XML de DjVu.

El DTD DjVuXML-s es una simplificación del DTD de HTML:

http://www.w3c.org/TR/1998/REC-html40-19980424/sgml/dtd.html

con algunos atributos nuevos añadidos, específicos para DjVu. Cada una de las páginas especificadas de un documento DjVu se representa como elementos OBJECT dentro del elemento BODY del archivo XML. Cada elemento OBJECT puede contener múltiples elementos PARAM para especificar atributos como el nombre de la página, la resolución y el factor gamma. Cada elemento OBJECT también puede contener un elemento HIDDENTEXT para especificar el texto oculto (normalmente generado con un motor OCR) dentro de la página DjVu. Además, cada elemento OBJECT puede hacer referencia a un único elemento MAP de área que contiene múltiples elementos AREA para representar todas las áreas de hipervínculos y resaltado dentro del documento DjVu.

   Elementos PARAM

Los elementos PARAM válidos de un OBJECT DjVu incluyen, entre otros, PAGE para especificar el nombre de la página, GAMMA para especificar el factor de corrección gamma (normalmente 2.2) y DPI para especificar la resolución de la página.

   Elementos HIDDENTEXT

Los elementos HIDDENTEXT consisten en elementos anidados de PAGECOLUMNS, REGION, PARAGRAPH, LINE y WORD. El elemento más anidado especificado debe definir las coordenadas límite del elemento en orientación de arriba hacia abajo. El cuerpo del elemento más anidado debe contener el texto. La mayoría de los documentos DjVu utilizan LINE o WORD como el nivel más bajo de elemento, pero cualquier elemento es legal como el nivel más bajo de elemento. Siempre se añade un espacio entre los elementos WORD y un salto de línea siempre se añade entre los elementos LINE. Dado que los idiomas como el japonés no utilizan espacios entre palabras, es muy común que los motores OCR asiáticos utilicen WORD como caracteres en su lugar.

   Elementos MAP

El cuerpo de los elementos MAP consiste en elementos AREA. Además de los atributos listados en

http://www.w3.org/TR/1998/REC-html40-19980424/struct/objects.html#edef-AREA,

los atributos bordertype, bordercolor, border y highlight se han añadido para especificar el tipo de borde, el color del borde, el ancho del borde y los colores de resaltado, respectivamente. Los valores legales para cada uno de estos atributos se enumeran en el DTD DjVuXML-s. Además, la forma oval se ha añadido a la lista legal de formas. Un óvalo utiliza un cuadro delimitador rectangular.

ERRORES

Quizás hubiera sido mejor utilizar hojas de estilo CC2 con elementos HTML estándar en lugar de definir el elemento HIDDENTEXT.
