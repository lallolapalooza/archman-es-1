NOMBRE

djvmcvt - Convierte documentos DjVu multipágina.

SINOPSIS

   Creando un documento empaquetado:

djvmcvt -b[undled] docin.djvu docout.djvu

   Creando un documento indirecto:

djvmcvt -i[ndirect] docin.djvu dir index.djvu

DESCRIPCIÓN

Este programa convierte cualquier documento DjVu multipágina al formato empaquetado o indirecto multipágina. El archivo de entrada docin.djvu debe ser el nombre del archivo de un documento empaquetado o el archivo índice de un documento indirecto.

OPCIONES

-b[undled]
Crea un documento DjVu multipágina empaquetado llamado docout.djvu.
-i[ndirect]
Crea un documento DjVu multipágina indirecto. Todos los archivos que componen el documento indirecto se almacenarán en el directorio dir. El archivo índice se llamará index.djvu.

CRÉDITOS
