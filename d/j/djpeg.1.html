DESCRIPCIÓ

N

djpeg descomprime el archivo JPEG indicado, o la entrada estándar si no se indica ningún archivo, y produce un archi

vo de imagen en la salida estándar. Se puede seleccionar
el formato de salida PBMPLUS (PPM/PGM), BMP, GIF o Targa.

OPCIONE

S

Todos los nombres de interruptores pueden abreviarse; por ejemplo, -grayscale puede escribirse -gray o -gr. La mayoría de los interruptores "básicos" pueden abreviarse hasta una sola letra. Las mayúsculas y minúsculas son equivalentes (así -BMP es lo mismo que -bmp). También se aceptan grafías británicas (p. ej. -greyscale), aunque por brevedad no se mencionan a

continuación.

Los interruptores básicos

son:
-colors
N
Reduce la imagen a un máximo de N colores [característica heredada]. Esto reduce el número de colores utilizados en la imagen de salida para que pueda almacenarse en un formato de archivo con mapa de colores. Esta característica no puede usarse al descomprimir imágenes JPEG sin
pérdida.
-quantize
N
Igual que -colors. -colors es el nombre recomendado. -quantize se proporciona solo por compatibilidad hacia
atrás.
-fa
st
Selecciona las opciones de procesamiento recomendadas para una salida de baja calidad [característica heredada]. (Las opciones predeterminadas se eligen para una salida de la máxima calidad.) Actualmente, esto equivale a -dct fast -nosmooth -onepass -dither ordered. En las CPU modernas, estos ajustes tienen poco o ningún beneficio de rendimiento y se conservan únicamente por compatibilidad hacia
atrás.
-graysca
le
Fuerza la salida en escala de grises incluso si el archivo JPEG es a todo color. Esta característica no puede usarse al descomprimir imágenes JPEG sin pérdida a todo
color.
-r
gb
Fuerza la salida RGB incluso si el archivo JPEG está en escala de grises. Esta característica no puede usarse al descomprimir imágenes JPEG sin pérdida en escala de
grises.
-scale M/
N
Escala la imagen de salida por un factor M/N. Actualmente el factor de escala debe ser M/8, donde M es un entero entre 1 y 16 inclusive, o cualquier fracción reducida de este (como 1/2, 3/4, etc.). Escalar es útil si la imagen es más grande que tu pantalla. Esta característica no puede usarse al descomprimir imágenes JPEG sin
pérdida.
-b
mp
Selecciona el formato de salida BMP (variante de Windows). Se emite el formato de 8 bits con mapa de colores si -colors o -grayscale se especifica, o si el archivo JPEG está en escala de grises; de lo contrario, se emite el formato de 24 bits a todo color. Este formato solo puede usarse al descomprimir imágenes JPEG de 8 bits por
muestra.
-g
if
Selecciona el formato de salida GIF (comprimido con LZW) [característica heredada]. Dado que GIF no admite más de 256 colores, se asume -colors 256 (a menos que especifiques un número menor de colores). Si especificas -fast, el número predeterminado de colores es 216. Este formato solo puede usarse al descomprimir imágenes JPEG con pérdida de 8 bits por muestra o de 12 bits por
muestra.
-gi
f0
Selecciona el formato de salida GIF (sin comprimir) [característica heredada]. Dado que GIF no admite más de 256 colores, se asume -colors 256 (a menos que especifiques un número menor de colores). Si especificas -fast, el número predeterminado de colores es 216. Este formato solo puede usarse al descomprimir imágenes JPEG con pérdida de 8 bits por muestra o de 12 bits por
muestra.
-o
s2
Selecciona el formato de salida BMP (variante OS/2 1.x) [característica heredada]. Se emite el formato de 8 bits con mapa de colores si -colors o -grayscale se especifica, o si el archivo JPEG está en escala de grises; de lo contrario, se emite el formato de 24 bits a todo color. Este formato solo puede usarse al descomprimir imágenes JPEG de 8 bits por
muestra.
-p
nm
Selecciona el formato de salida PBMPLUS (PPM/PGM) (este es el formato predeterminado). Se emite PGM si el archivo JPEG está en escala de grises o si -grayscale se especifica; de lo contrario se emite
PPM.
-tar
ga
Selecciona el formato de salida Targa [característica heredada]. Se emite el formato en escala de grises si el archivo JPEG está en escala de grises o si -grayscale se especifica; de lo contrario, se emite el formato con mapa de colores si -colors se especifica; de lo contrario, se emite el formato de 24 bits a todo color.
Este formato solo puede usarse al desc
omprimir imágenes JPEG de 8 bits por muestra.

Interruptores para usuarios

avanzados:
-dct
int
Usa el método DCT entero preciso (predeterminado)
.
-dct
fast
Usa el método DCT entero menos preciso [característica heredada]. Cuando el software del Independent JPEG Group se publicó por primera vez en 1991, el tiempo de descompresión de una imagen JPEG de 1 megapíxel en una PC de gama media se medía en minutos. Así, el algoritmo DCT entero rápido proporcionaba beneficios de rendimiento notables. Sin embargo, en las CPU modernas que ejecutan libjpeg-turbo, el tiempo de descompresión de una imagen JPEG de 1 megapíxel se mide en milisegundos, y por lo tanto los beneficios de rendimiento del algoritmo rápido son mucho menos notables. En las CPU x86/x86-64 modernas que soportan instrucciones AVX2, los métodos fast y int tienen un rendimiento similar. En otros tipos de CPU, el método fast es generalmente entre un 5-15% más rápido que el método int.

Si la imagen JPEG se comprimió usando un nivel de calidad de 85 o inferior, entonces no debería haber diferencia de calidad perceptible o muy pequeña entre los dos algoritmos. Sin embargo, al descomprimir imágenes que se comprimieron usando niveles de calidad superiores a 85, la diferencia entre los métodos fast y int se vuelve más pronunciada. Con imágenes comprimidas usando quality=97, por ejemplo, el método fast incurre generalmente en una pérdida de unos 4-6 dB en PSNR en comparación con el método int, pero esto puede ser mayor para algunas imágenes. Si puedes evitarlo, no uses el método fast al descomprimir imágenes que se comprimieron usando niveles de calidad superiores a 97. El algoritmo a menudo se degrada con

tales imágenes y puede producir una imagen de salida más dañada que
si la imagen JPEG se hubiera comprimido usando niveles de calidad más bajos.
-dct
float
Usa el método DCT de punto flotante [característica heredada]. El método float no produce resultados significativamente más precisos que el método int, y es mucho más lento. El método float también puede dar resultados diferentes en distintas máquinas debido al comportamiento variable de redondeo, mientras que los métodos enteros deberían dar los mismos resultados en todas las
máquinas.
-dither
fs
Usa el tramado Floyd-Steinberg al cuantizar colores [característica heredada]
.
-dither
ordered
Usa el tramado ordenado al cuantizar colores [característica heredada]
.
-dither
none
No usa tramado al cuantizar colores [característica heredada]. De forma predeterminada, se aplica el tramado Floyd-Steinberg al cuantizar colores. Esto es más lento pero generalmente produce los mejores resultados. El tramado ordenado es un compromiso entre velocidad y calidad. Sin tramado es más rápido pero generalmente se ve horrible. Ten en cuenta que estos interruptores no tienen efecto a menos que se esté realizando la cuantización de colores. El tramado ordenado solo está disponible en el modo -onepas
s.
-icc arch
ivo
Extrae el perfil de gestión de color ICC al archivo
especificado.
-map arch
ivo
Cuantiza a los colores usados en el archivo de imagen especificado [característica heredada]. Esto es útil para producir múltiples archivos con mapas de colores idénticos, o para forzar el uso de un conjunto predefinido de colores. El archivo debe ser un archivo GIF o PPM. Esta opción anula -colors y -onepas
s.
-nosmoo
th
Usa una rutina de sobremuestreo más rápida y de menor
calidad.
-onepa
ss
Utilice un pase en lugar de la cuantización de color de dos pasos [función heredada]. El método de un pase necesita menos memoria, pero produce una imagen de menor calidad. -onepass se ignora a menos que también especifique -colors N. Además, el método de un pase se utiliza siempre para la salida en escala de grises. (El método de dos pasos no tiene ninguna mejora en ese
caso.)
-maxmemory
N
Establece el límite para la cantidad de memoria a utilizar al procesar imágenes grandes. El valor está en miles de bytes, o millones de bytes si se añade "M" al número. Por ejemplo, -max 4m selecciona 4000000 bytes. Si se necesita más espacio, se producirá un
error.
-maxscans
N
Aborta si la imagen JPEG contiene más de N escaneos. Esta función demuestra un método mediante el cual las aplicaciones pueden protegerse contra ataques de denegación de servicio provocados por imágenes JPEG malformadas especialmente elaboradas que contienen numerosos escaneos con datos de imagen faltantes o datos de imagen que consisten solo en "EOB runs" (una función de las imágenes JPEG progresivas que permite representar potencialmente cientos de miles de píxeles adyacentes de valor cero usando solo unos pocos bytes.) Intentar descomprimir tales imágenes JPEG malformadas puede causar una actividad excesiva de la CPU, ya que el descompresor debe procesar completamente cada escaneo (incluso si el escaneo está corrupto) antes de poder proceder al siguiente
escaneo.
-outfile nam
e
Envía la imagen de salida al archivo con nombre, no a la salida
estándar.
-mems
rc
Carga el archivo de entrada en la memoria antes de descomprimir. Esta función se implementó principalmente como una forma de probar el gestor de fuentes en memoria (jpeg_mem_src()
.)
-repo
rt
Informa el progreso de la
descompresión.
-skip Y0,
Y1
Descomprime todas las filas de la imagen JPEG excepto aquellas entre Y0 y Y1 (inclusivo.) Tenga en cuenta que si se está utilizando la escala de descompresión, entonces Y0 y Y1 son relativos a las dimensiones de la imagen
escalada.
-crop WxH+X+
Y
Descomprime solo una subregión rectangular de la imagen, comenzando en el punto X,Y con ancho W y alto H. Si es necesario, X se desplazará a la izquierda hasta el límite iMCU más cercano, y el ancho se incrementará en consecuencia. Tenga en cuenta que si se está utilizando la escala de descompresión, entonces X, Y, W y H son relativos a las dimensiones de la imagen escalada. Actualmente esta opción solo funciona con los formatos de salida PBMPLUS (PPM/PGM), GIF y
Targa.
-stri
ct
Trata todas las advertencias como fatales. Esta función también demuestra un método mediante el cual las aplicaciones pueden protegerse contra ataques provocados por imágenes JPEG malformadas especialmente elaboradas. Habilitar esta opción hará que el descompresor aborte si la imagen JPEG contiene datos de imagen incompletos o
corruptos.
-verbo
se
Habilita la impresión de depuración. Más -v dan más salida. Además, la información de versión se imprime al
inicio.
-deb
ug
