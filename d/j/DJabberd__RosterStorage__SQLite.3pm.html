NOMBRE

DJabberd::RosterStorage::SQLite - almacena tu lista de contactos de jabber en SQLite

SINOPSIS

<Vhost tu_servidor.com>
   ...
   <Plugin DJabberd::RosterStorage::SQLite>
      Database roster.sqlite
   </Plugin>
   ...
 </VHost>

DESCRIPCIÓN

Esto almacena tu lista de contactos de Jabber (lista de amigos) en una base de datos SQLite.

El esquema se crea automáticamente al primer uso.

ADVERTENCIA: ¡BLOQUEA!

Este plugin bloquea. Es decir, no realiza el acceso a la base de datos de forma asíncrona en un hilo separado. Este no es un buen plugin para usar si quieres que DJabberd tenga un buen rendimiento con muchos usuarios.

Dicho esto, una determinada empresa lo está utilizando para ~100 empleados sin problemas.
