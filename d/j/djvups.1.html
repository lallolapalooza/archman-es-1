NOMBRE

djvups - Convierte documentos DjVu a PostScript.

SINOPSIS

djvups [opciones] [djvufile] [outputfile]

DESCRIPCIÓN

Este programa decodifica el archivo DjVu djvufile, y genera un archivo PostScript llamado outputfile. Los datos DjVu se leen de la entrada estándar cuando el argumento djvufile no se especifica o cuando es igual a un guion simple. De manera similar, los datos de salida se escriben en la salida estándar cuando el argumento outputfile no se especifica o es igual a un guion simple.

Las impresoras PostScript tienen diversas capacidades. Investigue las opciones -level y -gray para obtener los mejores resultados.

OPCIONES

-help
Imprime la lista de opciones reconocidas.
-verbose
Muestra una barra de progreso.
-page=pagespec
Especifica las páginas del documento que se convertirán. La especificación de página pagespec contiene uno o más rangos de páginas separados por comas. Un rango de página es un número de página o dos números de página separados por un guion. La especificación 1-10, por ejemplo, imprime las páginas 1 a 10. La especificación 1,3,99999-4 imprime las páginas 1 y 3, seguidas de todas las páginas del documento en orden inverso hasta la página 4.
-format=ps
Produce un archivo PostScript. Esta es la opción predeterminada.
-format=eps
Produce un archivo PostScript encapsulado. Los archivos PostScript encapsulados son adecuados para incrustar imágenes en otros documentos. Un archivo PostScript encapsulado solo puede contener una página. Establecer esta opción anula las opciones -copies, -orientation, -zoom, -cropmarksy -booklet.
-copies=n
Especifica el número de copias a imprimir.
-orientation=orient
Especifica si las páginas deben imprimirse usando la orientación auto, portraito landscape .
-mode=modespec
Especifica cómo deben decodificarse las páginas. El modo predeterminado, color, renderiza todas las capas de los documentos DjVu. El modo black solo renderiza la máscara de la capa de primer plano. Este modo no funciona con imágenes DjVuPhoto porque estos archivos no tienen máscara de capa de primer plano. Los modos foreground y background solo renderizan la capa de primer plano o la capa de fondo de una imagen DjVuDocument.
-zoom=zoomspec
Especifica un factor de zoom zoomspec. El factor de zoom predeterminado, auto, escala la imagen para que se ajuste a la página. El argumento zoomspec también puede ser un número en el rango 25 a 2400 que representa un porcentaje de ampliación relativo al tamaño original del documento.
-frame=yesno
Especificar yes causa la generación de un borde gris fino que representa los límites de las páginas del documento. El valor predeterminado es no.
-cropmarks=yesno
Especificar yes causa la generación de marcas de corte que indican dónde deben cortarse las páginas. El valor predeterminado es no.
-level=languagelevel
Selecciona el nivel de lenguaje del PostScript generado. languagelevel. Los niveles de lenguaje válidos son 1, 2y 3. El nivel 3 produce los archivos PostScript más compactos y de impresión rápida. Algunos de estos archivos, sin embargo, requieren una impresora muy moderna. El nivel 2 es el valor predeterminado. Los archivos PostScript generados son casi tan compactos y funcionan con todas las impresoras PostScript excepto las más antiguas. El nivel 1 puede usarse como opción de último recurso.
-color=yesno
El valor predeterminado, yes, genera un archivo PostScript en color. Especificar el valor no convierte la imagen a escala de grises. El archivo PostScript resultante es más pequeño y marginalmente más portable.
-gray
Esta opción es equivalente a la opción -color=no y se proporciona por conveniencia.
-colormatch=yesno
El valor predeterminado, yes, genera un archivo PostScript usando colores independientes del dispositivo en cumplimiento con la especificación sRGB . Las impresoras modernas producen entonces colores que coinciden con el original lo mejor posible. Especificar el valor no genera un archivo PostScript usando colores dependientes del dispositivo. Esto es a veces útil con impresoras más antiguas. Luego puede usar la opción -gamma para ajustar los colores de salida.
-gamma=gammaspec
Especifica un factor de corrección gamma para los colores PostScript dependientes del dispositivo. El argumento gammaspec debe estar en el rango 0.3 a 5.0. La corrección gamma normalmente pertenece solo a las pantallas catódicas. Se vuelve significativa para las impresoras porque varios modelos interpretan los colores RGB dependientes del dispositivo emulando la respuesta de color de un tubo catódico.
-booklet=opt
Activa el modo de impresión de folleto. El modo de folleto imprime dos páginas en cada lado de una manera adecuada para hacer un folleto doblando las hojas. La opción opt puede tomar los valores no para desactivar el modo de folleto, yes para activar el modo de folleto recto/verso, y recto o verso para imprimir solo un lado de cada hoja.
-bookletmax=max
Especifica el número máximo de páginas por folleto. Una sola impresión podría componerse entonces de varios folletos. El argumento max se redondea hacia arriba al siguiente múltiplo de 4. Especificar 0 establece que no hay un número máximo de páginas y asegura que la impresión producirá un solo folleto. Este es el valor predeterminado.
-bookletalign=align
Especifica un desplazamiento positivo o negativo aplicado al verso de cada hoja. El argumento align se expresa en puntos (un punto es 1/72 de una pulgada, o 0.352 milímetro). Esto es útil con ciertas impresoras para asegurar que tanto el recto como el verso estén correctamente alineados. El valor predeterminado es, por supuesto, 0.
-bookletfold=base[+incr]
Especifica el margen extra dejado entre ambas páginas en una sola hoja. El valor base base se expresa en puntos (un punto es 1/72 de una pulgada, o 0.352 milímetro). Este margen se incrementa para cada hoja exterior por el valor incr expresado en milipuntos. El valor predeterminado es 18+200.
