DROP_CAST(7)

Paquete: postgresql

Licencias: PostgreSQL

DROP CAST(7) Documentación de PostgreSQL 18.1 DROP CAST(7)

NOMBRE

DROP_CAST - eliminar un cast

SINOPSIS

DROP CAST [ IF EXISTS ] (tipo_origen AS tipo_destino) [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP CAST elimina un cast definido previamente.

Para poder eliminar un cast, debes ser propietario del tipo de datos de origen o de destino. Estos son los mismos privilegios que se requieren para crear un cast.

PARÁMETROS

IF EXISTS

No lances un error si el cast no existe. Se emitirá una notificación en este caso.

tipo_origen

El nombre del tipo de datos de origen del cast.

tipo_destino

El nombre del tipo de datos de destino del cast.

CASCADE
RESTRICT

Estas palabras clave no tienen ningún efecto, ya que no hay dependencias en los casts.

EJEMPLOS

Para eliminar el cast del tipo text al tipo int:

DROP CAST (text AS int);

COMPATIBILIDAD

El comando DROP CAST se ajusta al estándar SQL.

VER TAMBIÉN

CREATE CAST (CREATE_CAST(7))
