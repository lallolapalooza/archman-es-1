NOMBRE

DROP_SUBSCRIPTION - eliminar una suscripción

SINOPSIS

DROP SUBSCRIPTION [ IF EXISTS ] nombre [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP SUBSCRIPTION elimina una suscripción del clúster de bases de datos.

Para ejecutar este comando, el usuario debe ser el propietario de la suscripción.

DROP SUBSCRIPTION no se puede ejecutar dentro de un bloque de transacción si la suscripción está asociada a una ranura de replicación. (Puedes usar ALTER SUBSCRIPTION para deshabilitar la ranura).

PARÁMETROS

nombre

El nombre de una suscripción a eliminar.

CASCADE
RESTRICT

Estas palabras clave no tienen ningún efecto, ya que no hay dependencias en las suscripciones.

NOTAS

Al eliminar una suscripción que está asociada a una ranura de replicación en el host remoto (el estado normal), DROP SUBSCRIPTION se conectará al host remoto e intentará eliminar la ranura de replicación (y cualquier ranura de sincronización de tablas restante) como parte de su operación. Esto es necesario para que los recursos asignados a la suscripción en el host remoto se liberen. Si esto falla, ya sea porque el host remoto no es accesible o porque la ranura de replicación remota no se puede eliminar o no existe o nunca existió, el comando DROP SUBSCRIPTION fallará. Para proceder en esta situación, primero deshabilite la suscripción ejecutando ALTER SUBSCRIPTION ... DISABLE, y luego desasóciela de la ranura de replicación ejecutando ALTER SUBSCRIPTION ... SET (slot_name = NONE). Después de eso, DROP SUBSCRIPTION ya no intentará ninguna acción en un host remoto. Tenga en cuenta que si la ranura de replicación remota todavía existe, debería ser eliminada manualmente; de lo contrario, seguirá reservando WAL y podría eventualmente hacer que el disco se llene. Ver también Sección 29.2.1.

Si una suscripción está asociada a una ranura de replicación, entonces DROP SUBSCRIPTION no se puede ejecutar dentro de un bloque de transacción.

EJEMPLOS

Eliminar una suscripción:

DROP SUBSCRIPTION mysub;

COMPATIBILIDAD

DROP SUBSCRIPTION es una extensión de PostgreSQL.

VER TAMBIÉN

CREATE SUBSCRIPTION (CREATE_SUBSCRIPTION(7)), ALTER SUBSCRIPTION (ALTER_SUBSCRIPTION(7))
