DROP_DATABASE(7)

Paquete: postgresql

Licencias: PostgreSQL

DROP DATABASE(7) Documentación de PostgreSQL 18.1 DROP DATABASE(7)

NOMBRE

DROP_DATABASE - eliminar una base de datos

SINOPSIS

DROP DATABASE [ IF EXISTS ] nombre [ [ WITH ] ( opción [, ...] ) ]
donde opción puede ser:
    FORCE

DESCRIPCIÓN

DROP DATABASE elimina una base de datos. Elimina las entradas del catálogo para la base de datos y el directorio que contiene los datos. Solo puede ser ejecutado por el propietario de la base de datos. No puede ser ejecutado mientras estás conectado a la base de datos de destino. (Conéctate a postgres o a cualquier otra base de datos para emitir este comando). Además, si alguien más está conectado a la base de datos de destino, este comando fallará a menos que uses la opción FORCE descrita a continuación.

DROP DATABASE no se puede deshacer. ¡Úsalo con cuidado!

PARÁMETROS

IF EXISTS

No lanzar un error si la base de datos no existe. Se emite una notificación en este caso.

nombre

El nombre de la base de datos a eliminar.

FORCE

Intentar terminar todas las conexiones existentes a la base de datos de destino. No termina si existen transacciones preparadas, ranuras de replicación lógica activas o suscripciones en la base de datos de destino.

Esto termina las conexiones de los trabajadores en segundo plano y las conexiones que el usuario actual tiene permiso para terminar con pg_terminate_backend, descrito en la Sección 9.28.2. Si permanecen conexiones, este comando fallará.

NOTAS

DROP DATABASE no se puede ejecutar dentro de un bloque de transacción.

Este comando no se puede ejecutar mientras se está conectado a la base de datos de destino. Por lo tanto, podría ser más conveniente usar el programa dropdb(1) en su lugar, que es un envoltorio alrededor de este comando.

COMPATIBILIDAD

No existe una sentencia DROP DATABASE en el estándar SQL.

VER TAMBIÉN

CREATE DATABASE (CREATE_DATABASE(7))
