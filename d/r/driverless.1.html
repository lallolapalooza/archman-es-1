NOMBRE

driverless - Utilidad generadora de PPD para impresión sin controlador

SINOPSIS

driverless [-h | --help | --version] [-d | -v | --debug] [list] [_ipps._tcp] [_ipp._tcp] [--std-ipp-uris] | [cat URI_controlador] | [URI_impresora_IPP]

DESCRIPCIÓN

driverless genera archivos PPD para impresoras diseñadas para impresión IPP sin controlador (actualmente impresoras IPP Everywhere, AirPrint, Mopria y Wi-Fi-Direct, impresoras de red y también impresoras IPP-sobre-USB con la ayuda de ippusbxd(8)) consultando la información de capacidades de las impresoras a través de IPP. Se puede llamar para listar impresoras adecuadas en la red y para generar realmente el PPD. También puede ser llamado por CUPS cuando CUPS está listando PPDs/controladores disponibles o creando colas de impresión, haciendo que la configuración de impresoras sin controlador con herramientas de configuración de impresoras funcione de forma transparente.

driverless se coloca en /usr/lib/cups/driver/ para listar impresoras compatibles sin controlador y generar PPDs para ellas. También debería colocarse en /usr/lib/cups/backend/ (preferiblemente mediante un enlace simbólico) para listar URIs de dispositivos IPP para impresoras adecuadas. Las herramientas de configuración de impresoras como system-config-printer, la interfaz web de CUPS en http://localhost:631/ y las utilidades de línea de comandos de CUPS pueden usar driverless con CUPS para listar impresoras compatibles sin controlador, determinar sus URIs de dispositivos IPP y generar PPDs para ellas. Las impresoras se configurarán automática y correctamente para la impresión sin controlador. Tenga en cuenta que la impresión sin controlador requiere comunicación IPP con la impresora.

Un segundo enlace simbólico a /usr/lib/cups/driver/driverless desde /usr/bin/ permite que driverless sea llamado directamente por un usuario.

OPCIONES

-h, --help, --version
Muestra la página de ayuda, incluido el número de versión.
-v, -d, --debug
Modo de depuración, registro detallado a stderr.
list
Lista las URIs de controladores y metadatos para todas las impresoras IPP/IPPS disponibles adecuadas para la generación de archivos PPD sin controlador (para ser utilizado por CUPS).
_ipps._tcp
Busca solo impresoras IPPS que soporten impresión sin controlador.
_ipp._tcp
Busca solo impresoras IPP que soporten impresión sin controlador.
--std-ipp-uris
Muestra las URIs en formato estándar
cat URI_controlador
Genera el archivo PPD para la URI_controlador proporcionada a partir de la salida de "list" (para ser utilizado por CUPS).
URI_impresora_IPP
Genera el archivo PPD para la URI_impresora_IPP proporcionada (las URIs adecuadas se listan al llamar a driverless sin opciones).

Cuando se llama sin opciones, se listarán las URIs de impresora IPP de todas las impresoras IPP compatibles sin controlador disponibles.

VER TAMBIÉN

cups-browsed(8), ippfind(1), ippusbxd(8)

AUTOR

Los autores de driverless se enumeran en /usr/share/doc/cups-filters/AUTHORS.
