Las funciones erand48(), nrand48() y jrand48() requieren que el programa que llama proporcione almacenamiento para los valores sucesivos de X_i en el array especificado como argumento cuando se invocan las funciones. Por eso estas rutinas no tienen que ser inicializadas; el programa que llama simplemente tiene que colocar el valor inicial deseado de X_i en el array y pasarlo como argumento. Al usar argumentos diferentes, erand48(), nrand48() y jrand48() permiten que módulos separados de un programa grande generen varios flujos independientes de números pseudoaleatorios; es decir, la secuencia de números en cada flujo no debe depender de cuántas veces se llamen a las rutinas para generar números para los otros flujos.
