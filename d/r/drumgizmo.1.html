DESCRIPCIÓ

N

DrumGizmo es un plugin de batería multiplataforma de código abierto y una aplicación independiente. Es comparable a varios productos comerciales de plugins de

batería.

DrumGizmo utiliza un formato de archivo de batería abierto, permitiendo a la comunidad crear sus propias baterías. Tiene salida multicanal, lo que hace posible mezclarla tal como

lo harías con una batería real. El humanizador integrado opcional analiza las notas MIDI, ajustando las velocidades en tiempo real. Este cliente puede ser un renderizador MIDI in
dependiente, generando archivos .wav, 1 por cada canal. O usa DrumGizmo como un muestreador de software para una batería electrónica. También hay versiones de plugin disponibles.
