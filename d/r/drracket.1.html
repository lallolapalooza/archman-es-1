DRRACKET(1) Manual de Comandos Generales DRRACKET(1)

NOMBRE

drracket - el entorno de programación Racket

SINOPSIS

drracket [ opción X ... ] [ archivo ... ]

DESCRIPCIÓN

DrRacket es el entorno de programación Racket.

El programa drracket trata los argumentos de línea de comandos que no son interruptores como archivos para abrir.

OPCIONES X

Cuando se ejecuta en X11, DrRacket acepta las siguientes opciones X estándar: -display disp, -geometry geom, -bg color, -background color, -fg color, -foreground color, -fn font, -font font, -iconic, -name name, -rv, -reverse, +rv, -selectionTimeout time, -synchronous, -title name, -xnllanguage lang, -xrm file.

Además, la opción -singleInstance se trata como una opción X (debe aparecer antes que todas las demás opciones), y ejecuta DrRacket en modo de instancia única. En modo de instancia única, cuando una instancia existente se está ejecutando con el mismo host y nombre de ejecutable, todos los argumentos que no sean opciones se tratan como nombres de archivo y se envían a la instancia existente.

MÁS INFORMACIÓN

Para más información, ejecuta


raco docs

para abrir la documentación instalada en tu navegador web.

Alternativamente, consulta la documentación en línea y otra información disponible en


http://racket-lang.org/
