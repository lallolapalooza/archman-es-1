DROP OPERATOR(7) Documentación de PostgreSQL 18.1 DROP OPERATOR(7)

NOMBRE

DROP_OPERATOR - eliminar un operador

SINOPSIS

DROP OPERATOR [ IF EXISTS ] nombre ( { tipo_izquierdo | NONE } , tipo_derecho ) [, ...] [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP OPERATOR elimina un operador existente del sistema de bases de datos. Para ejecutar este comando, debes ser el propietario del operador.

PARÁMETROS

IF EXISTS

No lances un error si el operador no existe. Se emitirá una notificación en este caso.

nombre

El nombre (opcionalmente cualificado por esquema) de un operador existente.

tipo_izquierdo

El tipo de datos del operando izquierdo del operador; escribe NONE si el operador no tiene operando izquierdo.

tipo_derecho

El tipo de datos del operando derecho del operador.

CASCADE

Elimina automáticamente los objetos que dependen del operador (como las vistas que lo utilizan) y, a su vez, todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechaza la eliminación del operador si algún objeto depende de él. Esta es la opción predeterminada.

EJEMPLOS

Eliminar el operador de potencia a^b para el tipo integer:

DROP OPERATOR ^ (integer, integer);

Eliminar el operador prefijo de complemento a nivel de bits ~b para el tipo bit:

DROP OPERATOR ~ (none, bit);

Eliminar múltiples operadores en un solo comando:

DROP OPERATOR ~ (none, bit), ^ (integer, integer);

COMPATIBILIDAD

No existe una sentencia DROP OPERATOR en el estándar SQL.

VER TAMBIÉN

CREATE OPERATOR (CREATE_OPERATOR(7)), ALTER OPERATOR (ALTER_OPERATOR(7))
