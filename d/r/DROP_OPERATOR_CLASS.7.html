DROP_OPERATOR_CLASS(7)

Paquete: postgresql

Licencias: PostgreSQL

DROP OPERATOR CLASS(7) Documentación de PostgreSQL 18.1 DROP OPERATOR CLASS(7)

NOMBRE

DROP OPERATOR CLASS - eliminar una clase de operador

SINOPSIS

DROP OPERATOR CLASS [ IF EXISTS ] nombre USING método_índice [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP OPERATOR CLASS elimina una clase de operador existente. Para ejecutar este comando, debes ser el propietario de la clase de operador.

DROP OPERATOR CLASS no elimina ninguno de los operadores o funciones referenciados por la clase. Si existen índices que dependen de la clase de operador, deberás especificar CASCADE para que la eliminación se complete.

PARÁMETROS

IF EXISTS

No arrojar un error si la clase de operador no existe. Se emitirá una notificación en este caso.

nombre

El nombre (opcionalmente calificado por esquema) de una clase de operador existente.

método_índice

El nombre del método de acceso de índice para el cual es la clase de operador.

CASCADE

Eliminar automáticamente los objetos que dependen de la clase de operador (como los índices), y a su vez todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechazar la eliminación de la clase de operador si algún objeto depende de ella. Este es el comportamiento predeterminado.

NOTAS

DROP OPERATOR CLASS no eliminará la familia de operadores que contiene la clase, incluso si no queda nada más en la familia (en particular, en el caso donde la familia fue creada implícitamente por CREATE OPERATOR CLASS). Una familia de operadores vacía es inofensiva, pero para mantener el orden, podrías desear eliminar la familia con DROP OPERATOR FAMILY; o quizás mejor, usar DROP OPERATOR FAMILY en primer lugar.

EJEMPLOS

Eliminar la clase de operador B-tree widget_ops:

DROP OPERATOR CLASS widget_ops USING btree;

Este comando no tendrá éxito si existen índices que usen la clase de operador. Añada CASCADE para eliminar dichos índices junto con la clase de operador.

COMPATIBILIDAD

No existe una sentencia DROP OPERATOR CLASS en el estándar SQL.

VER TAMBIÉN

ALTER OPERATOR CLASS (ALTER_OPERATOR_CLASS(7)), CREATE OPERATOR CLASS (CREATE_OPERATOR_CLASS(7)), DROP OPERATOR FAMILY (DROP_OPERATOR_FAMILY(7))
