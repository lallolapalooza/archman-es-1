dropbearkey(1) Manual General de Comandos dropbearkey(1)

NOMBRE

dropbearkey - crea claves privadas para su uso con dropbear(8) o dbclient(1)

SINOPSIS

dropbearkey -t tipo -f archivo [-s bits] [-y]

DESCRIPCIÓN

dropbearkey genera una clave privada SSH en formato RSA, DSS, ECDSA o Ed25519, y la guarda en un archivo para su uso con el cliente o servidor Dropbear. Tenga en cuenta que algunas implementaciones SSH usan el término "DSA" en lugar de "DSS"; significan lo mismo.

OPCIONES

-t tipo
Tipo de clave a generar. Debe ser uno de rsa, ecdsa, ed25519 o dss.
-f archivo
Escribe la clave secreta en el archivo archivo. Para la autenticación del cliente, ~/.ssh/id_dropbear se carga por defecto.
-s bits
Establece el tamaño de la clave a bits bits, debe ser múltiplo de 8 (opcional).
-y
Simplemente imprime la clave pública y la huella digital para la clave privada en archivo.

NOTAS

El programa dropbearconvert(1) se puede usar para convertir entre formatos de clave Dropbear y OpenSSH.

Dropbear no admite claves cifradas.

EJEMPLO

generar una clave de host:
# dropbearkey -t rsa -f /etc/dropbear/dropbear_rsa_host_key

extraer una clave pública adecuada para authorized_keys de una clave privada:
# dropbearkey -y -f id_rsa | grep "^ssh-rsa " >> authorized_keys
