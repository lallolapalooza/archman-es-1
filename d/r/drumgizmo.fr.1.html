DESCRIPC Dr
mo

es un plugin así como una aplicación autónoma de batería multiplataforma y de código abierto. Es comparable a varios

productos comerciales de plugin de batería.

DrumGizmo utiliza un formato de fichero de kit de batería abierto, permitiendo a la comunidad crear sus propios kits de batería. Posee una salida multicanal, haciendo posible mezclar exactamente de la misma manera que lo haría con un kit de batería real. El humanizador opcional incluido analiza las notas MIDI, ajustando sus velocidades en tiempo real. Este cliente puede utilizarse como un software autónomo realizando un renderizado MIDI, generando ficheros .wav, 1 por cada canal. O bien, puede utilizar DrumGizmo como un muestreador de software para un kit de batería electrónico. También

están disponibles
versiones en plugin.
