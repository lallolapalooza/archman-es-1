NOMBRE

DROP_ROLE - eliminar un rol de base de datos

SINOPSIS

DROP ROLE [ IF EXISTS ] nombre [, ...]

DESCRIPCIÓN

DROP ROLE elimina los roles especificados. Para eliminar un rol de superusuario, tú mismo debes ser un superusuario; para eliminar roles que no son de superusuario, debes tener el privilegio CREATEROLE y tener la ADMIN OPTION otorgada sobre el rol.

Un rol no puede ser eliminado si todavía está referenciado en alguna base de datos del clúster; se generará un error si es así. Antes de eliminar el rol, debes eliminar todos los objetos que posee (o reasignar su propiedad) y revocar cualquier privilegio que se le haya otorgado al rol sobre otros objetos. Los comandos REASSIGN OWNED y DROP OWNED pueden ser útiles para este propósito; véase la Sección 21.4 para discusión adicional.

Sin embargo, no es necesario eliminar las membresías de roles que involucran al rol; DROP ROLE revoca automáticamente cualquier membresía del rol objetivo en otros roles, y de otros roles en el rol objetivo. Los otros roles no se eliminan ni se ven afectados de otra manera.

PARÁMETROS

IF EXISTS

No genera un error si el rol no existe. Se emite una notificación en este caso.

nombre

El nombre del rol a eliminar.

NOTAS

PostgreSQL incluye un programa dropuser(1) que tiene la misma funcionalidad que este comando (de hecho, llama a este comando) pero puede ser ejecutado desde la línea de comandos.

EJEMPLOS

Para eliminar un rol:

DROP ROLE jonathan;

COMPATIBILIDAD

El estándar SQL define DROP ROLE, pero solo permite eliminar un rol a la vez, y especifica requisitos de privilegios diferentes a los que usa PostgreSQL.
