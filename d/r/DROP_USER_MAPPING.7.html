DROP_USER_MAPPING(7)

Paquete: postgresql

Licencias: PostgreSQL

DROP USER MAPPING(7) Documentación de PostgreSQL 18.1 DROP USER MAPPING(7)

NOMBRE

DROP USER MAPPING - eliminar un mapeo de usuario para un servidor externo

SINOPSIS

DROP USER MAPPING [ IF EXISTS ] FOR { nombre_usuario | USER | CURRENT_ROLE | CURRENT_USER | PUBLIC } SERVER nombre_servidor

DESCRIPCIÓN

DROP USER MAPPING elimina un mapeo de usuario existente del servidor externo.

El propietario de un servidor externo puede eliminar mapeos de usuario para ese servidor para cualquier usuario. Además, un usuario puede eliminar un mapeo de usuario para su propio nombre de usuario si se ha otorgado el privilegio USAGE en el servidor al usuario.

PARÁMETROS

IF EXISTS

No lanzar un error si el mapeo de usuario no existe. Se emite un aviso en este caso.

nombre_usuario

Nombre de usuario del mapeo. CURRENT_ROLE, CURRENT_USER y USER coinciden con el nombre del usuario actual. PUBLIC se utiliza para coincidir con todos los nombres de usuario presentes y futuros en el sistema.

nombre_servidor

Nombre del servidor del mapeo de usuario.

EJEMPLOS

Eliminar el mapeo de usuario bob, servidor foo si existe:

DROP USER MAPPING IF EXISTS FOR bob SERVER foo;

COMPATIBILIDAD

DROP USER MAPPING cumple con ISO/IEC 9075-9 (SQL/MED). La cláusula IF EXISTS es una extensión de PostgreSQL.

VER TAMBIÉN

CREATE USER MAPPING (CREATE_USER_MAPPING(7)), ALTER USER MAPPING (ALTER_USER_MAPPING(7))
