do_strip=" {yes|no}

"
Elimina símbolos de los binarios en el initramfs (predeterminado=sí).

aggressive_strip="{sí|no}"

Elimina más que solo los símbolos y secciones de depuración, para una compilación de initramfs más pequeña. La opción "do_strip=sí" también debe especificarse (predeterminado=no).

do_hardlink="{sí|no}"

Enlaza archivos duros en el initramfs (predeterminado=sí).

prefix=" <directorio> "

Prefija los archivos del initramfs con <directorio>.

hostonly="{sí|no}"

Modo solo para el host: Instala solo lo necesario para arrancar el host local en lugar de un host genérico y genera configuración específica del host (predeterminado=sí).

hostonly_mode="{sloppy|strict}"

Especifica el modo solo para host a usar (predeterminado=sloppy).

En el modo solo para host "sloppy", se instalarán controladores y módulos adicionales, por lo que un cambio menor de hardware no hará que la imagen no sea arrancable (por ejemplo, un teclado cambiado), y la imagen sigue siendo portable entre hosts similares.

Con el modo "strict" habilitado, no se incluirá nada que no sea necesario para arrancar el host local en su estado actual, y los módulos pueden hacer esfuerzos adicionales para ahorrar más espacio. Cambios menores en el hardware o el entorno pueden hacer que la imagen no sea arrancable.

hostonly_cmdline="{sí|no}"

Si se establece en "sí", almacena los argumentos de la línea de comandos del kernel necesarios en el initramfs. Si hostonly="sí" y esta opción no está configurada, se establece automáticamente en "sí". (predeterminado=no)

hostonly_nics+=" [<nic>[ <nic> ...]] "

Solo habilita las NICs listadas en el initramfs. La lista puede estar vacía, por lo que otros módulos pueden instalar solo los controladores de red necesarios.

persistent_policy="<política>"

Usa <política> para direccionar discos y particiones. <política> puede ser cualquier nombre de directorio que se encuentre en /dev/disk (por ejemplo, "by-uuid", "by-label"), o "mapper" para usar nombres de dispositivos /dev/mapper (predeterminado=mapper).

tmpdir="<directorio temporal>"

Especifica el directorio temporal a usar.

Advertencia

Si se hace chroot a una raíz diferente de la raíz real, usa
--fstab y proporciona un /etc/fstab válido.

use_fstab="{sí|no}"

Usa /etc/fstab en lugar de /proc/self/mountinfo (predeterminado=no).

add_fstab+=" <nombre de archivo> "

Agrega entradas de <nombre de archivo> al initramfs /etc/fstab.

add_device+=" <dispositivo> "

Activa <dispositivo> en initramfs, <dispositivo> debe ser el nombre del dispositivo. Esto puede ser útil en modo solo para host para soporte de reanudación cuando tu swap está en LVM o una partición cifrada.

mdadmconf="{sí|no}"

Incluye el /etc/mdadm.conf local (predeterminado=no).

lvmconf="{sí|no}"

Incluye el /etc/lvm/lvm.conf local (predeterminado=no).

fscks=" <herramientas fsck> "

Agrega una lista separada por espacios de herramientas fsck.

Si no se especifica nada, el valor predeterminado es umount mount /sbin/fsck* xfs_db xfs_check xfs_repair e2fsck jfs_fsck btrfsck.

La instalación es oportunista (las herramientas no existentes se ignoran).

nofscks="{sí|no}"

Si se especifica, inhibe la instalación de cualquier herramienta fsck (predeterminado=no).

ro_mnt="{sí|no}"

Monta / y /usr como solo lectura por defecto (predeterminado=no).

kernel_cmdline="parámetros"

Especifica los parámetros de línea de comandos del kernel por defecto. A pesar de su nombre, este comando solo establece los parámetros de initrd.

kernel_only="{sí|no}"

Solo instala controladores y archivos de firmware del kernel (predeterminado=no).

no_kernel="{sí|no}"

No instala controladores y archivos de firmware del kernel (predeterminado=no).

acpi_override="{sí|no}"


Precaución

¡Úsalo solo si sabes lo que estás haciendo!

Anula las tablas ACPI proporcionadas por la BIOS. Para más documentación, lee Documentation/acpi/initrd_table_override.txt https://www.kernel.org/doc/Documentation/acpi/initrd_table_override.txt en las fuentes del kernel. Busca archivos de tabla ACPI (deben tener el sufijo .aml) en el directorio acpi_table_dir= (ver más abajo) y agrégalos a un archivo cpio comprimido separado.

Este archivo cpio se une (concatena, el descomprimido debe ser el primero) al archivo cpio comprimido. El primer archivo cpio, descomprimido, es para datos a los que el kernel debe poder acceder muy temprano (y aún no puede usar algoritmos de descompresión) como microcódigo o tablas ACPI.

(predeterminado=no).

early_microcode="{sí|no}"

Combina microcódigo temprano con el ramdisk (predeterminado=sí).

Especifica el nivel de registro para el error estándar (predeterminado=3).

fileloglvl="{0-6}"

Especifica el nivel de registro para el archivo de registro (predeterminado=4).

Ruta al archivo de registro.

sshkey="<archivo>"

Archivo de clave SSH utilizado con el módulo ssh-client.

show_modules="{sí|no}"

Imprime el nombre de los módulos incluidos en la salida estándar durante la compilación (predeterminado=no).

i18n_vars="<mapeo de variables>"

Mapeo de variables específico de la distribución. Ver dracut/modules.d/10i18n/README para una descripción detallada.

i18n_default_font="<nombre de fuente>"

La fuente <nombre de fuente> a instalar, si no se especifica de otra manera. El valor predeterminado es "eurlatgr".

i18n_install_all="{sí|no}"

Instala todo independientemente del modo genérico o solo para host (predeterminado=no).

reproducible="{sí|no}"

Crea imágenes reproducibles (predeterminado=no).

noimageifnotneeded="{sí|no}"

No crea una imagen en modo solo para host, si no se necesita ningún controlador de kernel y no se generará ningún /etc/cmdline/*.conf en el initramfs (predeterminado=no).

loginstall="<directorio>"

Registra todos los archivos instalados desde el host en <directorio>.

uefi="{sí|no}"

En lugar de crear una imagen initramfs, dracut creará un ejecutable UEFI, que puede ser ejecutado por una BIOS UEFI (predeterminado=no).

El nombre de archivo de salida predeterminado es <EFI>/EFI/Linux/linux-$kernel$-<MACHINE_ID>-<BUILD_ID>.efi. <EFI> puede ser /efi, /boot o /boot/efi dependiendo de dónde esté montada la partición ESP. El <BUILD_ID> se toma de BUILD_ID en /usr/lib/os-release o si existe /etc/os-release y se omite si BUILD_ID no existe o está vacío.

machine_id="{sí|no}"

Afecta el nombre de archivo de salida predeterminado del ejecutable UEFI, incluyendo la parte <MACHINE_ID> (predeterminado=sí).

uefi_stub="<archivo>"

Especifica el cargador stub UEFI, que cargará el kernel adjunto, el initramfs y la línea de comandos del kernel, y arrancará el kernel. El valor predeterminado es /lib/systemd/boot/efi/linux<EFI-MACHINE-TYPE-NAME>.efi.stub.

uefi_splash_image="<archivo>"

Especifica la imagen de bienvenida del cargador stub UEFI. Requiere formato de imagen bitmap (.bmp).

uefi_secureboot_cert="<archivo>", uefi_secureboot_key="<archivo>"

Especifica un certificado y la clave correspondiente, que se utilizan para firmar el ejecutable UEFI creado. Requiere que tanto el certificado como la clave se especifiquen y que sbsign esté instalado.

uefi_secureboot_engine="parámetro"

Especifica un motor a utilizar al firmar el ejecutable UEFI creado. Por ejemplo, "pkcs11"

kernel_image="<archivo>"

Especifica la imagen del kernel, que se incluirá en el ejecutable UEFI. El valor predeterminado es /lib/modules/<KERNEL-VERSION>/vmlinuz o /boot/vmlinuz-<KERNEL-VERSION>.

sbat="parámetros"

Especifica los parámetros SBAT, que se incluirán en el ejecutable UEFI. Por defecto, se utiliza la configuración predeterminada de SBAT.
ng añadido es sbat,1,SBAT Versión,sbat,1,https://github.com/rhboot/shim/blob/main/SBAT.md.

enhanced_cpio="{yes|no}"

Intentar usar el binario dracut-cpio, que optimiza la creación de archivos para sistemas de archivos con copia en escritura (por defecto=no).

Cuando se especifica, los archivos initramfs también se rellenan con datos nulos para asegurar una alineación óptima de los datos para el compartimiento de extensiones. Para conservar los beneficios de la deduplicación de datos de reflink, esto debe usarse junto con los compress="cat" y do_strip="no" parámetros, con los archivos fuente del initramfs, tmpdir área de ensamblaje y destino todos en el mismo sistema de archivos capaz de copia en escritura.

parallel="{yes|no}"

Si se establece en yes, intentar ejecutar tareas en paralelo (actualmente solo soportado para --regenerate-all).

initrdname="<filepattern>"

Especifica el nombre de archivo para el initramfs generado si no se establece de otra manera.

La opción de configuración initrdname debe coincidir con el initr*${kernel}* patrón de archivo y solo un archivo con este patrón debería existir en el directorio desde donde se carga el initramfs.

Por defecto es initramfs-${kernel}.img.

ARCHIVOS

/etc/dracut.conf

Archivo de configuración antiguo. Se recomienda usar archivos individuales en /etc/dracut.conf.d/.

/etc/dracut.conf.d/

Cualquier /etc/dracut.conf.d/*.conf archivo puede sobrescribir los valores en /etc/dracut.conf. Los archivos de configuración se leen en orden alfanumérico. El orden recomendado para la configuración de la distribución o del usuario está en el rango de 50-59.
