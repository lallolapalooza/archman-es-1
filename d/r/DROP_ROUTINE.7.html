Paquete: postgresql

DROP ROUTINE(7) Documentación de PostgreSQL 18.1 DROP ROUTINE(7)

NOMBRE

DROP ROUTINE - eliminar una rutina

SINOPSIS

DROP ROUTINE [ IF EXISTS ] nombre [ ( [ [ modo_argumento ] [ nombre_argumento ] tipo_argumento [, ...] ] ) ] [, ...]
    [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP ROUTINE elimina la definición de una o más rutinas existentes. El término “rutina” incluye funciones agregadas, funciones normales y procedimientos. Consulte DROP AGGREGATE (DROP_AGGREGATE(7)), DROP FUNCTION (DROP_FUNCTION(7)) y DROP PROCEDURE (DROP_PROCEDURE(7)) para ver la descripción de los parámetros, más ejemplos y detalles adicionales.

NOTAS

Las reglas de búsqueda utilizadas por DROP ROUTINE son fundamentalmente las mismas que para DROP PROCEDURE; en particular, DROP ROUTINE comparte el comportamiento de ese comando de considerar una lista de argumentos que no tiene marcadores modo_argumento como posiblemente utilizando la definición estándar de SQL de que los argumentos OUT se incluyen en la lista. (DROP AGGREGATE y DROP FUNCTION no hacen eso).

En algunos casos donde el mismo nombre es compartido por rutinas de diferentes tipos, es posible que DROP ROUTINE falle con un error de ambigüedad cuando un comando más específico (DROP FUNCTION, etc.) funcionaría. Especificar la lista de tipos de argumentos con más cuidado también resolverá tales problemas.

Estas reglas de búsqueda también son utilizadas por otros comandos que actúan sobre rutinas existentes, como ALTER ROUTINE y COMMENT ON ROUTINE.

EJEMPLOS

Para eliminar la rutina foo para el tipo entero:

DROP ROUTINE foo(integer);

Este comando funcionará independientemente de si foo es un agregado, función o procedimiento.

COMPATIBILIDAD

Este comando cumple con el estándar SQL, con estas extensiones de PostgreSQL:

•El estándar solo permite eliminar una rutina por comando.
•La opción IF EXISTS es una extensión.
•La capacidad de especificar modos y nombres de argumentos es una extensión, y las reglas de búsqueda difieren cuando se proporcionan modos.
•Las funciones agregadas definibles por el usuario son una extensión.

VER TAMBIÉN

DROP AGGREGATE (DROP_AGGREGATE(7)), DROP FUNCTION (DROP_FUNCTION(7)), DROP PROCEDURE (DROP_PROCEDURE(7)), ALTER ROUTINE (ALTER_ROUTINE(7))

Tenga en cuenta que no existe un comando CREATE ROUTINE.
