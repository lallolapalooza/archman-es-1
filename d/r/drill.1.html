drill(1) Manual general de comandos drill(1)

NOMBRE

drill - obtener información (de depuración) de DNS(SEC)

SINOPSIS

drill [ OPCIONES ] nombre [ @servidor ] [ tipo ] [ clase ]

DESCRIPCIÓN

drill es una herramienta diseñada para obtener todo tipo de información del DNS. Está diseñada específicamente para usarse con DNSSEC.

El nombre drill es un juego de palabras con dig. Con drill deberías poder obtener aún más información que con dig.

Si no se proporcionan argumentos, la clase por defecto es 'IN' y el tipo es 'A'. Se utilizan los servidores de nombres especificados en /etc/resolv.conf para consultar.

nombre Solicita este nombre.

@servidor Envía la consulta a este servidor. Si no se especifica, utiliza los servidores de nombres de /etc/resolv.conf.

tipo Solicita este tipo de RR. Si el tipo no se proporciona en la línea de comandos, por defecto es 'A'. Excepto cuando se realiza una búsqueda inversa, en cuyo caso el valor por defecto es 'PTR'.

clase Usa esta clase al consultar.

USO DE EJEMPLO

drill mx miek.nl Muestra los registros MX del dominio miek.nl

drill -S jelte.nlnetlabs.nl
Sigue cualquier firma en el dominio jelte.nlnetlab.nl. Esta opción solo está disponible cuando ldns se ha compilado con soporte openssl.
drill -TD www.example.com
Realiza un rastreo (-T) de DNSSEC (-D) desde los servidores raíz hasta www.example.com. Esta opción solo funciona cuando ldns se ha compilado con soporte openssl.
drill -s dnskey jelte.nlnetlabs.nl
Muestra los registros DNSKEY para jelte.nlnetlabs.nl. Para cada registro DNSKEY encontrado, también imprime el registro DS.

OPCIONES

-D
Habilita DNSSEC en la consulta. Cuando se consulta para tipos DNSSEC (DNSKEY, RRSIG, DS y NSEC), esto no se habilita automáticamente.
-T
Rastrea nombre desde la raíz hacia abajo. Al usar esta opción, el argumento @servidor no se utiliza.
-S
Sigue la(s) firma(s) de 'nombre' hasta una clave conocida o lo más alto posible en el árbol.
-I dirección IPv4 o IPv6
Dirección de origen desde la que consultar. La dirección de origen debe estar presente en una interfaz de la máquina que ejecuta drill.
-V nivel
Sé más verboso. Establece el nivel a 5 para ver la consulta real que se envía.
-Q
Modo silencioso, esto anula -V.
-f archivo
Lee la consulta de un archivo. La consulta debe ser volcada con -w.
-i archivo
lee la respuesta del archivo en lugar de la red. Esto ayuda a depurar y puede usarse para verificar si una consulta en disco es válida. Si el archivo contiene datos binarios, se asume que es una consulta en orden de red.
-w archivo
Escribe un paquete de respuesta en el archivo.
-q archivo
Escribe el paquete de consulta en el archivo.
-v
Muestra la versión de drill.
-h
Muestra un mensaje de ayuda corto.

OPCIONES DE CONSULTA

-4
Mantente en ip4. Solo envía consultas a servidores de nombres habilitados para ip4.
-6
Mantente en ip6. Solo envía consultas a servidores de nombres habilitados para ip6.
-a
Usa el mecanismo de reserva de la estructura del resolvedor si la respuesta está truncada (TC=1). Si se recibe un paquete truncado y esta opción está configurada, drill primero enviará una nueva consulta con un tamaño de búfer EDNS0 de 4096.

Si el tamaño del búfer EDNS0 ya estaba establecido en 512 bytes o más, o si la reintento anterior también resulta en una respuesta truncada, la estructura del resolvedor recurrirá a TCP.

-b tamaño
Usa tamaño como el tamaño del búfer en el RR pseudo EDNS0.
-c archivo
Usa archivo en lugar de /etc/resolv.conf para la configuración del servidor de nombres.
-d dominio
Al rastrear (-T), comienza desde este dominio en lugar de la raíz.
-t
Usa TCP/IP al consultar un servidor.
-k archivo_clave
Usa este archivo para leer una clave (de confianza). Cuando se proporciona esta opción, drill intenta validar la respuesta actual con esta clave. No se realiza seguimiento. Cuando drill realiza un rastreo seguro, esta clave se usará como ancla de confianza. Puede contener un DNSKEY o un registro DS.

Alternativamente, cuando se rastrea DNSSEC habilitado (-TD) o se persiguen firmas (-S), si no se especifica -k y existe un ancla de confianza por defecto (/etc/trusted-key.key) que contiene un registro DNSKEY o DS válido, se utilizará como ancla de confianza.

-o m nemónico
Usa esta opción para establecer o desestablecer bits de encabezado específicos. Un bit se establece usando el mnemónico del bit en mayúsculas. Un bit se desestablece cuando el mnemónico se proporciona en minúsculas. Los siguientes mnemónicos son entendidos por drill:


QR, qr: establecer, desestablecer QueRy (por defecto: activado)
AA, aa: establecer, desestablecer Authoritative Answer (por defecto: desactivado)
TC, tc: establecer, desestablecer TrunCated (por defecto: desactivado)
RD, rd: establecer, desestablecer Recursion Desired (por defecto: activado)
CD, cd: establecer, desestablecer Checking Disabled (por defecto: desactivado)
RA, ra: establecer, desestablecer Recursion Available (por defecto: desactivado)
AD, ad: establecer, desestablecer Authenticated Data (por defecto: desactivado)

Por lo tanto: -o CD, habilitará Checking Disabled, lo que indica a la caché que no valide las respuestas que emite.

-p puerto
Usa este puerto en lugar del valor predeterminado de 53.
-r archivo
Al rastrear (-T), usa archivo como archivo de sugerencias de servidores raíz.
-s
Al encontrar un DNSKEY, imprime también el DS equivalente.
-u
Usa UDP al consultar un servidor. Este es el valor predeterminado.
-w archivo
escribe la respuesta en un archivo. El archivo contendrá un volcado hexadecimal de la consulta. Esto se puede usar en conjunto con -f.
-x
Realiza una búsqueda inversa. El argumento de tipo no se usa, se preestablece a PTR.
-y <nombre:clave[:algo]>
especifica una clave tsig base64 con nombre y, opcionalmente, un algoritmo (por defecto es hmac-md5.sig-alg.reg.int).
-z
no aleatoriza la lista de servidores de nombres antes de enviar consultas.

OPCIONES DE CONSULTA EDNS

+nsid
Cuando está establecido, esta opción EDNS incluye una solicitud de ID del servidor de nombres EDNS en la consulta.

ESTADO DE SALIDA

El estado de salida es 0 si la respuesta buscada es segura y de confianza, o insegura. El estado de salida no es 0 si la respuesta buscada es de no confianza o es inválida, o si ocurrió un error al realizar la búsqueda.

ARCHIVOS

/etc/trusted-key.key
El archivo desde el cual se cargan las claves de confianza.
agregado cuando no se proporciona la opción -k.
