DROP TEXT SEARCH CONFIGURATION(7) Documentación de PostgreSQL 18.1 DROP TEXT SEARCH CONFIGURATION(7)

NOMBRE

DROP TEXT SEARCH CONFIGURATION - eliminar una configuración de búsqueda de texto

SINOPSIS

DROP TEXT SEARCH CONFIGURATION [ IF EXISTS ] nombre [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP TEXT SEARCH CONFIGURATION elimina una configuración de búsqueda de texto existente. Para ejecutar este comando, debe ser el propietario de la configuración.

PARÁMETROS

IF EXISTS

No lance un error si la configuración de búsqueda de texto no existe. Se emitirá una notificación en este caso.

nombre

El nombre (opcionalmente cualificado por esquema) de una configuración de búsqueda de texto existente.

CASCADE

Elimine automáticamente los objetos que dependen de la configuración de búsqueda de texto, y a su vez todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechace eliminar la configuración de búsqueda de texto si algún objeto depende de ella. Este es el comportamiento predeterminado.

EJEMPLOS

Eliminar la configuración de búsqueda de texto my_english:

DROP TEXT SEARCH CONFIGURATION my_english;

Este comando no tendrá éxito si existen índices que hagan referencia a la configuración en llamadas a to_tsvector. Agregue CASCADE para eliminar dichos índices junto con la configuración de búsqueda de texto.

COMPATIBILIDAD

No existe una sentencia DROP TEXT SEARCH CONFIGURATION en el estándar SQL.

VER TAMBIÉN

ALTER TEXT SEARCH CONFIGURATION (ALTER_TEXT_SEARCH_CONFIGURATION(7)), CREATE TEXT SEARCH CONFIGURATION (CREATE_TEXT_SEARCH_CONFIGURATION(7))
