DRUMSTICK-DUMPWRK(1) Comandos de usuario DRUMSTICK-DUMPWRK(1)

NOMBRE

drumstick-dumpwrk - Una utilidad de línea de comandos de Drumstick para decodificar archivos WRK (Cakewalk).

SINOPSIS

drumstick-dumpwrk [opciones] {ARCHIVO}

DESCRIPCIÓN

Este programa es un ejemplo y utilidad de Drumstick. Puedes usarlo para decodificar como texto tus archivos WRK creados con Cakewalk o Sonar.

ARGUMENTOS

El siguiente argumento es obligatorio:

ARCHIVO

El nombre del archivo WRK de entrada.

Los siguientes argumentos son opcionales:

-h|--help

Imprime un resumen de las opciones de línea de comandos y sale.

-v|--version

Imprime el número de versión del programa y sale.

--verbose

Salida detallada.
