DROP_STATISTICS(7)

Paquete: postgresql

Licencias: PostgreSQL

DROP STATISTICS(7) Documentación de PostgreSQL 18.1 DROP STATISTICS(7)

NOMBRE

DROP STATISTICS - eliminar estadísticas extendidas

SINOPSIS

DROP STATISTICS [ IF EXISTS ] nombre [, ...] [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP STATISTICS elimina uno o más objetos de estadísticas de la base de datos. Solo el propietario del objeto de estadísticas, el propietario del esquema o un superusuario pueden eliminar un objeto de estadísticas.

PARÁMETROS

IF EXISTS

No genera un error si el objeto de estadísticas no existe. En este caso, se emite un aviso.

nombre

El nombre (opcionalmente calificado por el esquema) del objeto de estadísticas a eliminar.

CASCADE
RESTRICT

Estas palabras clave no tienen ningún efecto, ya que no hay dependencias en las estadísticas.

EJEMPLOS

Para destruir dos objetos de estadísticas en diferentes esquemas, sin fallar si no existen:

DROP STATISTICS IF EXISTS
    accounting.users_uid_creation,
    public.grants_user_role;

COMPATIBILIDAD

No existe un comando DROP STATISTICS en el estándar SQL.

VER TAMBIÉN

ALTER STATISTICS (ALTER_STATISTICS(7)), CREATE STATISTICS (CREATE_STATISTICS(7))
