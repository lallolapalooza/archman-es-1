DRUMSTICK-DUMPMID(1) Comandos de usuario DRUMSTICK-DUMPMID(1)

NOMBRE

drumstick-dumpmid - Utilidad de línea de comandos de Drumstick para decodificar eventos MIDI.

SINOPSIS

drumstick-dumpmid [opciones]

DESCRIPCIÓN

Este programa es un ejemplo y una utilidad de Drumstick. Puedes usarlo para decodificar eventos MIDI estándar como texto.

ARGUMENTOS

El siguiente argumento es obligatorio:

-p|--port= cliente:puerto

Una especificación de cliente:puerto de ALSA que se suscribirá para leer eventos MIDI desde él. La porción del cliente puede ser un número o un nombre, como en "20:0" o "Virtual Piano:0".

Los siguientes argumentos son opcionales:

-h|--help

Imprime un resumen de las opciones de línea de comandos y sale.

-v|--version

Imprime el número de versión del programa y sale.
