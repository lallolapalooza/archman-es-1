DROP POLICY(7) Documentación de PostgreSQL 18.1 DROP POLICY(7)

NOMBRE

DROP_POLICY - eliminar una política de seguridad a nivel de fila de una tabla

SINOPSIS

DROP POLICY [ IF EXISTS ] nombre ON nombre_tabla [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP POLICY elimina la política especificada de la tabla. Tenga en cuenta que si se elimina la última política para una tabla y la tabla aún tiene habilitada la seguridad a nivel de fila mediante ALTER TABLE, se utilizará la política de denegación por defecto. ALTER TABLE ... DISABLE ROW LEVEL SECURITY se puede usar para deshabilitar la seguridad a nivel de fila para una tabla, independientemente de si existen políticas para la tabla o no.

PARÁMETROS

IF EXISTS

No genere un error si la política no existe. Se emitirá una notificación en este caso.

nombre

El nombre de la política a eliminar.

nombre_tabla

El nombre (opcionalmente calificado con esquema) de la tabla sobre la que se aplica la política.

CASCADE
RESTRICT

Estas palabras clave no tienen ningún efecto, ya que no hay dependencias en las políticas.

EJEMPLOS

Para eliminar la política llamada p1 en la tabla llamada my_table:

DROP POLICY p1 ON my_table;

COMPATIBILIDAD

DROP POLICY es una extensión de PostgreSQL.

VER TAMBIÉN

CREATE POLICY (CREATE_POLICY(7)), ALTER POLICY (ALTER_POLICY(7))
