DROP EVENT TRIGGER(7) Documentación de PostgreSQL 18.1 DROP EVENT TRIGGER(7)

NOMBRE

DROP_EVENT_TRIGGER - eliminar un disparador de eventos

SINOPSIS

DROP EVENT TRIGGER [ IF EXISTS ] nombre [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP EVENT TRIGGER elimina un disparador de eventos existente. Para ejecutar este comando, el usuario actual debe ser el propietario del disparador de eventos.

PARÁMETROS

IF EXISTS

No lance un error si el disparador de eventos no existe. Se emitirá un aviso en este caso.

nombre

El nombre del disparador de eventos a eliminar.

CASCADE

Eliminar automáticamente los objetos que dependen del disparador y, a su vez, todos los objetos que dependen de esos objetos (consulte la Sección 5.15).

RESTRICT

Rechazar la eliminación del disparador si algún objeto depende de él. Este es el valor predeterminado.

EJEMPLOS

Destruir el disparador snitch:

DROP EVENT TRIGGER snitch;

COMPATIBILIDAD

No existe una instrucción DROP EVENT TRIGGER en el estándar SQL.

VER TAMBIÉN

CREATE EVENT TRIGGER (CREATE_EVENT_TRIGGER(7)), ALTER EVENT TRIGGER (ALTER_EVENT_TRIGGER(7))
