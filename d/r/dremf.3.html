DESCRIPCIÓ

N

Estas funciones calculan el resto de dividir x entre y. El valor de retorno es x-n*y, donde n es el valor x / y, redondeado al entero más cercano. Si el valor absoluto de x-n*y es 0.5, n se elige para que sea

par.

Estas funciones no se ven afectadas por el modo de redondeo actual (ver fenv(3))

.

La función drem() hace

exactamente
lo mismo.

VALOR DE

RETORNO

En caso de éxito, estas funciones devuelven el resto en punto flotante, x-n*y. Si el valor de retorno es 0, tiene el signo de x

.

Si x o y es un NaN, se devuelve un

NaN.

Si x es un infinito, y y no es un NaN, se produce un error de dominio, y se devuelve un

NaN.

Si y es cero, y x no es un NaN, se produce un error

de dominio, y s
e devuelve un NaN.

S

Ver math_error(7) para información sobre cómo determinar si ha ocurrido un error al llamar a estas

funciones.

errores:

NaN
