NOMBRE

dropbearconvert - convertir entre formatos de clave privada de Dropbear y OpenSSH

SINOPSIS

dropbearconvert tipo_entrada tipo_salida archivo_entrada archivo_salida

DESCRIPCIÓN

Dropbear y OpenSSH son implementaciones SSH con formatos de clave privada diferentes. dropbearconvert puede convertir entre ambos.

Dropbear utiliza el mismo formato de clave pública SSH que OpenSSH; se puede extraer de una clave privada usando dropbearkey -y

Las claves privadas cifradas no son compatibles; use ssh-keygen(1) para descifrarlas primero.

ARGUMENTOS

tipo_entrada
dropbear u openssh
tipo_salida
dropbear u openssh
archivo_entrada
Un archivo de clave privada existente de Dropbear o OpenSSH
archivo_salida
La ruta para escribir el archivo de clave privada convertido. Para la autenticación del cliente, se carga por defecto ~/.ssh/id_dropbear

FORMATOS SOPORTADOS

dropbearconvert puede leer archivos en formato OpenSSH y archivos en formato PEM antiguo ( ssh-keygen -m PEM ). dropbearconvert escribirá archivos en formato OpenSSH, utilizables con OpenSSH 6.5 y posteriores. La lectura de archivos DSS en formato OpenSSH o archivos PKCS8 no es compatible actualmente.

EJEMPLO


# dropbearconvert openssh dropbear ~/.ssh/id_rsa ~/.ssh/id_dropbear
