DROP_FUNCTION(7)

Paquete: postgresql

Licencias: PostgreSQL

DROP FUNCTION(7) Documentación de PostgreSQL 18.1 DROP FUNCTION(7)

NOMBRE

DROP_FUNCTION - eliminar una función

SINOPSIS

DROP FUNCTION [ IF EXISTS ] nombre [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] [, ...]
    [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP FUNCTION elimina la definición de una función existente. Para ejecutar este comando, el usuario debe ser el propietario de la función. Los tipos de argumentos de la función deben especificarse, ya que varias funciones diferentes pueden existir con el mismo nombre y diferentes listas de argumentos.

PARÁMETROS

IF EXISTS

No lanzar un error si la función no existe. Se emitirá un aviso en ese caso.

nombre

El nombre (opcionalmente calificado por el esquema) de una función existente. Si no se especifica una lista de argumentos, el nombre debe ser único en su esquema.

argmode

El modo de un argumento: IN, OUT, INOUT o VARIADIC. Si se omite, el valor predeterminado es IN. Tenga en cuenta que DROP FUNCTION en realidad no presta atención a los argumentos OUT, ya que solo los argumentos de entrada son necesarios para determinar la identidad de la función. Por lo tanto, es suficiente enumerar los argumentos IN, INOUT y VARIADIC.

argname

El nombre de un argumento. Tenga en cuenta que DROP FUNCTION en realidad no presta atención a los nombres de los argumentos, ya que solo los tipos de datos de los argumentos son necesarios para determinar la identidad de la función.

argtype

Los tipos de datos de los argumentos de la función (opcionalmente calificados por el esquema), si los hay.

CASCADE

Eliminar automáticamente los objetos que dependen de la función (como operadores o disparadores), y a su vez todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechazar la eliminación de la función si algún objeto depende de ella. Este es el valor predeterminado.

EJEMPLOS

Este comando elimina la función de raíz cuadrada:

DROP FUNCTION sqrt(integer);

Eliminar múltiples funciones en un solo comando:

DROP FUNCTION sqrt(integer), sqrt(bigint);

Si el nombre de la función es único en su esquema, se puede referir a él sin una lista de argumentos:

DROP FUNCTION update_employee_salaries;

Tenga en cuenta que esto es diferente de

DROP FUNCTION update_employee_salaries();

que se refiere a una función con cero argumentos, mientras que la primera variante puede referirse a una función con cualquier número de argumentos, incluido cero, siempre que el nombre sea único.

COMPATIBILIDAD

Este comando cumple con el estándar SQL, con estas extensiones de PostgreSQL:

•El estándar solo permite eliminar una función por comando.
•La opción IF EXISTS
•La capacidad de especificar modos y nombres de argumentos
