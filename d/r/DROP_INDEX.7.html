DROP INDEX(7) Documentación de PostgreSQL 18.1 DROP INDEX(7)

NOMBRE

DROP_INDEX - eliminar un índice

SINOPSIS

DROP INDEX [ CONCURRENTLY ] [ IF EXISTS ] nombre [, ...] [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP INDEX elimina un índice existente del sistema de bases de datos. Para ejecutar este comando, debes ser el propietario del índice.

PARÁMETROS

CONCURRENTLY

Elimina el índice sin bloquear selecciones, inserciones, actualizaciones y eliminaciones concurrentes en la tabla del índice. Un DROP INDEX normal adquiere un bloqueo ACCESS EXCLUSIVE en la tabla, bloqueando otros accesos hasta que se pueda completar la eliminación del índice. Con esta opción, el comando espera hasta que las transacciones conflictivas hayan finalizado.

Hay varias advertencias a tener en cuenta al usar esta opción. Solo se puede especificar un nombre de índice, y la opción CASCADE no es compatible. (Por lo tanto, un índice que soporta una restricción UNIQUE o PRIMARY KEY no puede eliminarse de esta manera). Además, los comandos regulares de DROP INDEX se pueden realizar dentro de un bloque de transacción, pero DROP INDEX CONCURRENTLY no puede. Por último, los índices en tablas particionadas no se pueden eliminar utilizando esta opción.

Para tablas temporales, DROP INDEX es siempre no concurrente, ya que ninguna otra sesión puede acceder a ellas, y la eliminación de índices no concurrentes es más barata.

IF EXISTS

No genera un error si el índice no existe. Se emite un aviso en este caso.

nombre

El nombre (opcionalmente calificado por esquema) de un índice a eliminar.

CASCADE

Elimina automáticamente los objetos que dependen del índice y, a su vez, todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechaza la eliminación del índice si algún objeto depende de él. Esta es la opción predeterminada.

EJEMPLOS

Este comando eliminará el índice title_idx:

DROP INDEX title_idx;

COMPATIBILIDAD

DROP INDEX es una extensión del lenguaje de PostgreSQL. No hay disposiciones para índices en el estándar SQL.

VER TAMBIÉN
