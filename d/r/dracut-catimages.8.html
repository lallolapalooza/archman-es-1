NOMBRE

dracut-catimages - crea una imagen de disco de arranque inicial concatenando imágenes

SINOPSIS

dracut-catimages [OPCIÓN...] <imagen base de initramfs> [<imagen>...]

DESCRIPCIÓN

dracut-catimages crea una imagen de disco de arranque inicial concatenando varias imágenes de la línea de comandos y de /boot/dracut/*.img

OPCIONES

-f, --force

sobrescribir el archivo initramfs existente.

-i, --imagedir

Directorio con imágenes adicionales para añadir (por defecto: /boot/dracut/)

-o, --overlaydir

Directorio de superposición, que contiene archivos adicionales que se utilizarán para crear una imagen adicional

--nooverlay

No usar el directorio de superposición

--noimagedir

No usar el directorio de imágenes adicional

-h, --help

mostrar texto de ayuda y salir.

--debug

mostrar información de depuración del proceso de construcción

-v, --verbose

salida detallada durante el proceso de construcción

ARCHIVOS

/boot/dracut/*.img

imágenes con las que trabajar

AUTORES

Harald Hoyer
