DROP_SERVER(7)

Paquete: postgresql

Licencias: PostgreSQL

DROP SERVER(7) Documentación de PostgreSQL 18.1 DROP SERVER(7)

NOMBRE

DROP_SERVER - eliminar un descriptor de servidor externo

SINOPSIS

DROP SERVER [ IF EXISTS ] nombre [, ...] [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP SERVER elimina un descriptor de servidor externo existente. Para ejecutar este comando, el usuario actual debe ser el propietario del servidor.

PARÁMETROS

IF EXISTS

No genere un error si el servidor no existe. Se emitirá una notificación en este caso.

nombre

El nombre de un servidor existente.

CASCADE

Elimine automáticamente los objetos que dependen del servidor (como las asignaciones de usuarios) y, a su vez, todos los objetos que dependen de esos objetos (consulte la Sección 5.15).

RESTRICT

Rechace la eliminación del servidor si algún objeto depende de él. Este es el comportamiento predeterminado.

EJEMPLOS

Elimine el servidor foo si existe:

DROP SERVER IF EXISTS foo;

COMPATIBILIDAD

DROP SERVER cumple con la norma ISO/IEC 9075-9 (SQL/MED). La cláusula IF EXISTS es una extensión de PostgreSQL.

VÉASE TAMBIÉN

CREATE SERVER (CREATE_SERVER(7)), ALTER SERVER (ALTER_SERVER(7))
