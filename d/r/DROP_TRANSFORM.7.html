NOMBRE

DROP_TRANSFORM - eliminar una transformación

SINOPSIS

DROP TRANSFORM [ IF EXISTS ] FOR tipo_nombre LANGUAGE lang_nombre [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP TRANSFORM elimina una transformación definida previamente.

Para poder eliminar una transformación, se debe ser propietario del tipo y del lenguaje. Estos son los mismos privilegios que se requieren para crear una transformación.

PARÁMETROS

IF EXISTS

No generar un error si la transformación no existe. Se emitirá un aviso en este caso.

tipo_nombre

El nombre del tipo de dato de la transformación.

lang_nombre

El nombre del lenguaje de la transformación.

CASCADE

Eliminar automáticamente los objetos que dependen de la transformación y, a su vez, todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechazar la eliminación de la transformación si algún objeto depende de ella. Este es el comportamiento predeterminado.

EJEMPLOS

Para eliminar la transformación para el tipo hstore y el lenguaje plpython3u:

DROP TRANSFORM FOR hstore LANGUAGE plpython3u;

COMPATIBILIDAD

Esta forma de DROP TRANSFORM es una extensión de PostgreSQL. Ver CREATE TRANSFORM (CREATE_TRANSFORM(7)) para más detalles.

VER TAMBIÉN
