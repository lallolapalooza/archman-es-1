NOMBRE

drawvalmap - Genera una salida gráfica de los valores de estado de validación encontrados por la biblioteca de validación.

SINOPSIS

drawvalmap <archivo_log>

drawvalmap

DESCRIPCIÓN

drawvalmap es una utilidad simple que puede usarse para mostrar los valores de estado de validación en un formato gráfico. La entrada a este script es un conjunto de mensajes de log que se pueden leer desde un archivo o desde un socket. La salida es un archivo de imagen que contiene una imagen de los diversos valores de estado de la cadena de autenticación del validador.

drawvalmap lee datos de STDIN si la opción archivo de log y la opción de socket no se especifican. Si se proporciona la opción -f, el archivo de imagen de salida se incrusta en un archivo HTML con el nombre dado. El archivo HTML se actualiza automáticamente según el tiempo de actualización proporcionado por la opción -r, lo que permite un seguimiento constante de los cambios en el gráfico del validador.

El uso típico de este script es de la siguiente manera:

# drawvalmap <archivo_log>

No sería raro usar este script con fines de solución de problemas, en cuyo caso la salida generada por un programa controlador se "canalizaría" a este script de la manera que se muestra a continuación.

# dt-validate -o6:stdout secure.example.com. | drawvalmap -f val_log_map.html

En cada caso, el script genera los resultados en un archivo val_log_map.png. En el segundo caso, también se genera un archivo HTML con el nombre val_log_map.html.

OPCIONES

-a dirección-IP
Esto cambia la dirección a la que drawvalmap se enlaza al valor especificado. Esta opción solo tiene efecto si la opción -s también se especifica.
-f archivo.ext
Esto crea una imagen del tipo determinado por la extensión del archivo.
-g xxxx (obsoleto)
Use -f en su lugar.
-h archivo.html
Esto crea un archivo HTML con el nombre dado, que contiene la imagen del mapa de validación.
-i cadena_patrón_ignorar
Esto hace que drawvalmap ignore los registros de log que coinciden con el patrón de ignorar dado.
-l evento_log1,evento_log2
Esto hace que drawvalmap habilite la visualización de eventos para la lista dada de tipos de log. Los siguientes tipos de eventos de log se definen con su estado habilitado predeterminado indicado entre paréntesis: SUCCESS(1), BOGUS(1), DATA_MISSING(1), ERROR(1), y IGNORED(0).
-m cadena_patrón_coincidencia
Esto hace que drawvalmap incluya solo los registros de log que coinciden con el patrón dado. Si un registro de log dado coincide con un patrón dado por la opción -m y también coincide con el patrón dado por la opción -i, el resultado efectivo es ignorar el registro.
-p puerto
Esto cambia el puerto al que drawvalmap se enlaza al valor especificado. Esta opción solo tiene efecto si la opción -s también se especifica.
-r período-actualización
Esto cambia el período de actualización en el archivo HTML al valor dado. El valor predeterminado es 5 segundos.
-s
Esto cambia el modo de operación para leer la entrada desde un socket. La dirección y el puerto predeterminados a los que se enlaza drawvalmap son 127.0.0.1:1053.
