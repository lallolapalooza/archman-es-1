NOMBRE

drtdump - Volcar archivo y conjunto de datos DICOM RT

SINOPSIS

drtdump [opciones] drtfile-in...

DESCRIPCIÓN

La utilidad drtdump vuelca el contenido de un objeto DICOM de Radioterapia (RT) (formato de archivo o conjunto de datos sin procesar) a stdout en forma textual. La salida consta de información esencial sobre el objeto RT en un formato que probablemente sea más fácil de leer que el más genérico de dcmdump.

Si drtdump lee un conjunto de datos sin procesar (datos DICOM sin un metaencabezado de formato de archivo) intentará adivinar la sintaxis de transferencia examinando los primeros bytes del archivo. No siempre es posible adivinar correctamente la sintaxis de transferencia y es mejor convertir un conjunto de datos a formato de archivo siempre que sea posible (usando la utilidad dcmconv ). También es posible usar las opciones -f y -t[ieb] para forzar a drtdump a leer un conjunto de datos con una sintaxis de transferencia particular.

PARÁMETROS

drtfile-in  Nombre de archivo de entrada DICOM RT a volcar ("-" para stdin)

OPCIONES

opciones generales

  -h   --help
         imprimir este texto de ayuda y salir
       --version
         imprimir información de versión y salir
       --arguments
         imprimir los argumentos de la línea de comandos expandidos
  -q   --quiet
         modo silencioso, no imprimir advertencias ni errores
  -v   --verbose
         modo detallado, imprimir detalles del procesamiento
  -d   --debug
         modo de depuración, imprimir información de depuración
  -ll  --log-level  [l]evel: constante de cadena
         (fatal, error, warn, info, debug, trace)
         usar el nivel l para el registrador
  -lc  --log-config  [f]ilename: cadena
         usar el archivo de configuración f para el registrador

opciones de entrada

formato de archivo de entrada:
  +f   --read-file
         leer formato de archivo o conjunto de datos (por defecto)
  +fo  --read-file-only
         leer solo formato de archivo
  -f   --read-dataset
         leer conjunto de datos sin meta-información de archivo
sintaxis de transferencia de entrada:
  -t=  --read-xfer-auto
         usar reconocimiento de ST (por defecto)
  -td  --read-xfer-detect
         ignorar ST especificada en el metaencabezado del archivo
  -te  --read-xfer-little
         leer con ST de VR explícito little endian
  -tb  --read-xfer-big
         leer con ST de VR explícito big endian
  -ti  --read-xfer-implicit
         leer con ST de VR implícito little endian

opciones de salida

impresión:
  +Pf  --print-filename
         imprimir encabezado con nombre de archivo para cada archivo de entrada

REGISTRO

El nivel de salida de registro de las diversas herramientas de línea de comandos y bibliotecas subyacentes puede ser especificado por el usuario. Por defecto, solo se escriben errores y advertencias al flujo de error estándar. Usando la opción --verbose también se reportan mensajes informativos como detalles del procesamiento. La opción --debug puede usarse para obtener más detalles sobre la actividad interna, por ejemplo, para propósitos de depuración. Otros niveles de registro pueden seleccionarse usando la opción --log-level. En el modo --quiet solo se reportan errores fatales. En tales eventos de error muy graves, la aplicación normalmente terminará. Para más detalles sobre los diferentes niveles de registro, ver la documentación del módulo "oflog".

En caso de que la salida de registro deba escribirse en un archivo (opcionalmente con rotación de archivo de registro), a syslog (Unix) o al registro de eventos (Windows), puede usarse la opción --log-config . Este archivo de configuración también permite dirigir solo ciertos mensajes a un flujo de salida particular y filtrar ciertos mensajes basándose en el módulo o la aplicación donde se generan. Un archivo de configuración de ejemplo se proporciona en <etcdir>/logger.cfg.

LÍNEA DE COMANDOS

Todas las herramientas de línea de comandos usan la siguiente notación para los parámetros: los corchetes encierran valores opcionales (0-1), tres puntos finales indican que se permiten múltiples valores (1-n), una combinación de ambos significa de 0 a n valores.

Las opciones de la línea de comandos se distinguen de los parámetros por un signo '+' o '-' inicial, respectivamente. Usualmente, el orden y la posición de las opciones de la línea de comandos son arbitrarios (es decir, pueden aparecer en cualquier lugar). Sin embargo, si las opciones son mutuamente excluyentes, se usa la aparición más a la derecha. Este comportamiento se conforma a las reglas de evaluación estándar de los shells Unix comunes.

Además, uno o más archivos de comandos pueden especificarse usando un signo '@' como prefijo del nombre de archivo (por ejemplo, @command.txt). Tal argumento de comando es reemplazado por el contenido del archivo de texto correspondiente (múltiples espacios en blanco se tratan como un solo separador a menos que aparezcan entre dos comillas) antes de cualquier evaluación posterior. Tenga en cuenta que un archivo de comando no puede contener otro archivo de comando. Este enfoque simple pero efectivo permite resumir combinaciones comunes de opciones/parámetros y evita líneas de comandos largas y confusas (un ejemplo se proporciona en el archivo <datadir>/dumppat.txt).

ENTORNO

La utilidad drtdump intentará cargar los diccionarios de datos DICOM especificados en la variable de entorno DCMDICTPATH . Por defecto, es decir, si la variable de entorno DCMDICTPATH no está establecida, se cargará el archivo <datadir>/dicom.dic a menos que el diccionario esté compilado en la aplicación (por defecto en Windows).

El comportamiento por defecto debería ser preferido y la variable de entorno DCMDICTPATH solo usarse cuando se requieran diccionarios de datos alternativos. La variable de entorno DCMDICTPATH tiene el mismo formato que la variable PATH del shell Unix en el que un dos puntos (":") separa las entradas. En sistemas Windows, se usa un punto y coma (";") como separador. El código del diccionario de datos intentará cargar cada archivo especificado en la variable de entorno DCMDICTPATH . Es un error si no se puede cargar ningún diccionario de datos.

    NAME

    drtdump - dumps (exporta) un directorio de registro (log directory).

    SYNOPSIS

    drtdump [OPCIONES] DIRECTORIO_DE_REGISTRO

    DESCRIPTION

    drtdump es una utilidad que exporta el contenido de un directorio de registro (log directory) en un formato legible para humanos. Esto es útil para depurar problemas o para archivar datos de registro.

    OPTIONS

    Aún no se han especificado opciones. Consulte el archivo fuente para obtener una lista completa.

    NOTES

    Asegúrese de tener los permisos adecuados para leer el directorio de registro especificado.

    LOGGING

    La salida de drtdump se imprime en la salida estándar (stdout).

    COMMAND LINE

    La sintaxis básica es:

    drtdump [OPCIONES] DIRECTORIO_DE_REGISTRO

    Donde DIRECTORIO_DE_REGISTRO es la ruta al directorio que contiene los archivos de registro que desea exportar.
