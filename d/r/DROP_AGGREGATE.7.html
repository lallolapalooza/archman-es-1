DROP AGGREGATE(7) Documentación de PostgreSQL 18.1 DROP AGGREGATE(7)

NOMBRE

DROP AGGREGATE - eliminar una función agregada

SINOPSIS

DROP AGGREGATE [ IF EXISTS ] nombre ( firma_agregada ) [, ...] [ CASCADE | RESTRICT ]
donde firma_agregada es:
* |
[ modo_arg ] [ nombre_arg ] tipo_arg [ , ... ] |
[ [ modo_arg ] [ nombre_arg ] tipo_arg [ , ... ] ] ORDER BY [ modo_arg ] [ nombre_arg ] tipo_arg [ , ... ]

DESCRIPCIÓN

DROP AGGREGATE elimina una función agregada existente. Para ejecutar este comando, el usuario actual debe ser el propietario de la función agregada.

PARÁMETROS

IF EXISTS

No generar un error si el agregado no existe. Se emitirá un aviso en este caso.

nombre

El nombre (opcionalmente calificado por el esquema) de una función agregada existente.

modo_arg

El modo de un argumento: IN o VARIADIC. Si se omite, el valor predeterminado es IN.

nombre_arg

El nombre de un argumento. Tenga en cuenta que DROP AGGREGATE en realidad no presta atención a los nombres de los argumentos, ya que solo se necesitan los tipos de datos de los argumentos para determinar la identidad de la función agregada.

tipo_arg

Un tipo de dato de entrada sobre el cual opera la función agregada. Para referenciar una función agregada de cero argumentos, escriba * en lugar de la lista de especificaciones de argumentos. Para referenciar una función agregada de conjunto ordenado, escriba ORDER BY entre las especificaciones de argumentos directos y agregados.

CASCADE

Eliminar automáticamente los objetos que dependen de la función agregada (como vistas que la utilizan) y, a su vez, todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechazar la eliminación de la función agregada si algún objeto depende de ella. Este es el valor predeterminado.

NOTAS

Las sintaxis alternativas para referenciar agregados de conjunto ordenado se describen en ALTER AGGREGATE (ALTER_AGGREGATE(7)).

EJEMPLOS

Para eliminar la función agregada myavg para el tipo integer:

DROP AGGREGATE myavg(integer);

Para eliminar la función agregada de conjunto hipotético myrank, que toma una lista arbitraria de columnas de ordenación y una lista coincidente de argumentos directos:

DROP AGGREGATE myrank(VARIADIC "any" ORDER BY VARIADIC "any");

Para eliminar múltiples funciones agregadas en un solo comando:

DROP AGGREGATE myavg(integer), myavg(bigint);

COMPATIBILIDAD

No existe una sentencia DROP AGGREGATE en el estándar SQL.

VER TAMBIÉN

ALTER AGGREGATE (ALTER_AGGREGATE(7)), CREATE AGGREGATE (CREATE_AGGREGATE(7))
