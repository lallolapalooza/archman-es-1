DROP TEXT SEARCH TEMPLATE(7) Documentación de PostgreSQL 18.1 DROP TEXT SEARCH TEMPLATE(7)

NOMBRE

DROP_TEXT_SEARCH_TEMPLATE - eliminar una plantilla de búsqueda de texto

SINOPSIS

DROP TEXT SEARCH TEMPLATE [ IF EXISTS ] nombre [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP TEXT SEARCH TEMPLATE elimina una plantilla de búsqueda de texto existente. Debes ser superusuario para usar este comando.

PARÁMETROS

IF EXISTS

No arrojes un error si la plantilla de búsqueda de texto no existe. Se emite un aviso en este caso.

nombre

El nombre (opcionalmente calificado por el esquema) de una plantilla de búsqueda de texto existente.

CASCADE

Elimina automáticamente los objetos que dependen de la plantilla de búsqueda de texto y, a su vez, todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechaza eliminar la plantilla de búsqueda de texto si algún objeto depende de ella. Esta es la opción predeterminada.

EJEMPLOS

Eliminar la plantilla de búsqueda de texto thesaurus:

DROP TEXT SEARCH TEMPLATE thesaurus;

Este comando no tendrá éxito si existen diccionarios de búsqueda de texto que utilicen la plantilla. Añade CASCADE para eliminar dichos diccionarios junto con la plantilla.

COMPATIBILIDAD

No existe la sentencia DROP TEXT SEARCH TEMPLATE en el estándar SQL.

VER TAMBIÉN

ALTER TEXT SEARCH TEMPLATE (ALTER_TEXT_SEARCH_TEMPLATE(7)), CREATE TEXT SEARCH TEMPLATE (CREATE_TEXT_SEARCH_TEMPLATE(7))
