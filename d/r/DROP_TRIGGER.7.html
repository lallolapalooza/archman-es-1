DROP TRIGGER(7) Documentación de PostgreSQL 18.1 DROP TRIGGER(7)

NOMBRE

DROP_TRIGGER - eliminar un disparador

SINOPSIS

DROP TRIGGER [ IF EXISTS ] nombre ON nombre_tabla [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP TRIGGER elimina una definición de disparador existente. Para ejecutar este comando, el usuario actual debe ser el propietario de la tabla para la que se define el disparador.

PARÁMETROS

IF EXISTS

No genere un error si el disparador no existe. Se emitirá un aviso en este caso.

nombre

El nombre del disparador a eliminar.

nombre_tabla

El nombre (opcionalmente calificado por el esquema) de la tabla para la que se define el disparador.

CASCADE

Eliminar automáticamente los objetos que dependen del disparador y, a su vez, todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechazar la eliminación del disparador si algún objeto depende de él. Este es el valor predeterminado.

EJEMPLOS

Destruye el disparador if_dist_exists en la tabla films:

DROP TRIGGER if_dist_exists ON films;

COMPATIBILIDAD

La sentencia DROP TRIGGER en PostgreSQL es incompatible con el estándar SQL. En el estándar SQL, los nombres de los disparadores no son locales a las tablas, por lo que el comando es simplemente DROP TRIGGER nombre.

VER TAMBIÉN

CREATE TRIGGER (CREATE_TRIGGER(7))
