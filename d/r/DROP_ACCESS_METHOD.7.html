Paquete: postgresql

DROP ACCESS METHOD(7) Documentación de PostgreSQL 18.1 DROP ACCESS METHOD(7)

NOMBRE

DROP ACCESS METHOD - eliminar un método de acceso

SINOPSIS

DROP ACCESS METHOD [ IF EXISTS ] nombre [ CASCADE | RESTRICT ]

DESCRIPCIÓN

DROP ACCESS METHOD elimina un método de acceso existente. Solo los superusuarios pueden eliminar métodos de acceso.

PARÁMETROS

IF EXISTS

No arroje un error si el método de acceso no existe. En ese caso se emitirá una notificación.

nombre

El nombre de un método de acceso existente.

CASCADE

Eliminar automáticamente los objetos que dependen del método de acceso (como clases de operadores, familias de operadores e índices), y a su vez todos los objetos que dependen de esos objetos (ver Sección 5.15).

RESTRICT

Rechazar la eliminación del método de acceso si algún objeto depende de él. Esta es la opción predeterminada.

EJEMPLOS

Eliminar el método de acceso heptree:

DROP ACCESS METHOD heptree;

COMPATIBILIDAD

DROP ACCESS METHOD es una extensión de PostgreSQL.

VER TAMBIÉN

CREATE ACCESS METHOD (CREATE_ACCESS_METHOD(7))
