DHTNODE(1) Manual de Comandos Generales DHTNODE(1)

NOMBRE

dhtnode - un simple ejecutor de nodos de línea de comandos OpenDHT.

SINOPSIS

dhtnode [-h] [-v [-l archivo_log] [-L]] [-i [--guardar-identidad archivo]] [-d] [-s] [-n id_red] [-p puerto_local] [-b host_bootstrap[:puerto]] [--certificado archivo] [--claveprivada archivo] [--contraseñaclav privada contraseña] [--servidorproxy puerto] [--clienteproy servidor]

DESCRIPCIÓN

Ejecuta un nodo OpenDHT, con una CLI (por defecto) o como un demonio (con '-d' o '-s'). Los comandos disponibles en el shell interactivo son:

    h, help    Imprime este mensaje de ayuda.
    q, quit    Sale del programa.
    log        Inicia/detiene la impresión de logs de DHT.
    Información del nodo:
    ll         Imprime información básica y estadísticas sobre el nodo actual.
    ls         Imprime información básica sobre las búsquedas actuales.
    ld         Imprime información básica sobre los valores actualmente almacenados en este nodo.
    lr         Imprime la tabla de enrutamiento completa actual de este nodo
    Operaciones en la DHT:
    b ip:puerto             Ping a un nodo potencial en la IP/puerto dados.
    g [clave]               Obtiene los valores en [clave].
    l [clave]               Escucha cambios de valor en [clave].
    p [clave] [str]         Pone el valor de cadena en [clave].
    s [clave] [str]         Pone el valor de cadena en [clave], firmado con nuestra clave
                          privada generada.
    e [clave] [dest] [str]  Pone el valor de cadena en [clave], cifrado para [dest] con
                          su clave pública (si se encuentra).

OPCIONES

-h
Imprime algo de ayuda.
-v
Habilita el modo detallado (log a stdout/stderr por defecto)
-l archivo_log
Escribe el log a un archivo en lugar de stdout/stderr
-L
Escribe el log a syslog en lugar de stdout/stderr
-i
Genera una identidad criptográfica para el nodo.
--guardar-identidad archivo
Guarda la identidad generada (certificado y clave privada) en el prefijo de archivo dado.
--certificado archivo
Carga el certificado de identidad desde el archivo dado.
--claveprivada archivo
Carga la clave privada de identidad desde el archivo dado.
--contraseñaclav privada contraseña
Contraseña a usar para cifrado o descifrado de clave privada (opcional).
-d
Ejecuta el programa en modo demonio (se bifurcará en segundo plano).
-s
Ejecuta el programa en modo servicio (demonio que no se bifurca).
-D
Habilita el descubrimiento automático de pares locales por multidifusión.
-f archivo
Especifica una ruta de archivo para persistir/cargar el estado del nodo.
-n id_red
Especifica el id de la red. Esto te permite conectarte a redes distintas y evita la fusión de dos redes diferentes (disponible desde OpenDHT v0.6.1).
-p puerto_local
Usa el puerto UDP puerto_local para que el programa se vincule.
-b host_bootstrap[:puerto]
Se le debe proporcionar al programa un nodo al que conectarse a la red. Se utiliza esta opción para proporcionar la dirección IP de ese nodo.
--servidorproxy puerto_local
Ejecuta un servidor proxy vinculado a este nodo DHT en el puerto HTTP puerto_local
--clienteproy servidor
Ejecuta este nodo DHT en modo cliente proxy y se conecta a servidor
