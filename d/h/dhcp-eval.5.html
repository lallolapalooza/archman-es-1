lcase (data-expr)


La lcase función devuelve el resultado de evaluar data-expr convertido a minúsculas. Si data-expr
  se evalúa a null, entonces el resultado también es null.


ucase (data-expr)


La ucase función devuelve el resultado de evaluar data-expr convertido a mayúsculas. Si data-expr
  se evalúa a null, entonces el resultado también es null.


option option-name


El option operador devuelve el contenido de la opción especificada en el paquete al que el servidor está respondiendo.


config-option option-name


El config-option operador devuelve el valor de la opción especificada que el cliente o servidor DHCP ha sido configurado para enviar.


gethostname()


La gethostname() función devuelve una cadena de datos cuyo contenido es una cadena de caracteres, los resultados de llamar a gethostname() en el sistema local con un límite de tamaño de 255 bytes (sin incluir el terminador NULL). Esto puede usarse, por ejemplo, para configurar dhclient para enviar el nombre de host local sin conocer el nombre de host local en el momento en que se escribe dhclient.conf.


hardware


El hardware operador devuelve una cadena de datos cuyo primer elemento es el tipo de interfaz de red indicado en el paquete que se está considerando, y cuyos elementos subsiguientes son la dirección de capa de enlace del cliente. Si no hay paquete, o si el campo hlen de RFC2131 es inválido, entonces el resultado es null. Los tipos de hardware incluyen ethernet (1), token-ring (6) y fddi (8). Los tipos de hardware son especificados por el IETF, y los detalles sobre cómo se definen los números de tipo se pueden encontrar en RFC2131 (en la distribución ISC DHCP, esto está incluido en el subdirectorio doc/).


packet (offset, length)


El packet operador devuelve la porción especificada del paquete que se está considerando, o null en contextos donde no se está considerando ningún paquete. Offset y length se aplican al contenido del paquete como en el substring operador.


string


Una cadena, encerrada entre comillas, puede especificarse como una expresión de datos, y devuelve el texto entre las comillas, codificado en ASCII. El carácter de barra invertida ('\') se trata de manera especial, como en la programación en C: '\t' significa TAB, '\r' significa retorno de carro, '\n' significa salto de línea y '\b' significa campana. Cualquier valor octal puede especificarse con '\nnn', donde nnn es cualquier número octal positivo menor que 0400. Cualquier valor hexadecimal puede especificarse con '\xnn', donde nn es cualquier número hexadecimal positivo menor o igual que 0xff.


lista hexadecimal separada por dos puntos


Una lista de valores octetos hexadecimales, separados por dos puntos, puede especificarse como una expresión de datos.


concat (data-expr1, ...,
    data-exprN)


Las expresiones se evalúan, y los resultados de cada evaluación se concatenan en la secuencia en que se enumeran las subexpresiones. Si alguna subexpresión se evalúa a null, el resultado de la concatenación es null.


reverse (numeric-expr1,
    data-expr2)


Las dos expresiones se evalúan, y luego el resultado de evaluar la expresión de datos se invierte en su lugar, usando trozos del tamaño especificado en la expresión numérica. Por ejemplo, si la expresión numérica se evalúa a cuatro, y la expresión de datos se evalúa a doce bytes de datos, entonces la expresión reverse se evaluará a doce bytes de datos, que consisten en los últimos cuatro bytes de los datos de entrada, seguidos de los cuatro bytes del medio, seguidos de los primeros cuatro bytes.


leased-address


En cualquier contexto donde al cliente cuya solicitud se está procesando se le haya asignado una dirección IP, esta expresión de datos devuelve esa dirección IP. En cualquier contexto donde al cliente cuya solicitud se está procesando no se le haya asignado una dirección IP, si esta expresión de datos se encuentra en sentencias ejecutables ejecutadas en nombre de ese cliente, un mensaje de registro que indica "there is no lease associated with this client" se registra en el nivel de depuración (esto se considera información de depuración de dhcpd.conf).


binary-to-ascii (numeric-expr1,
    numeric-expr2, data-expr1,
    data-expr2)


Convierte el resultado de evaluar data-expr2 en una cadena de texto que contiene un número por cada elemento del resultado de evaluar data-expr2. Cada número está separado de los demás por el resultado de evaluar data-expr1. El resultado de evaluar numeric-expr1 especifica la base (2 a 16) a la que se deben convertir los números. El resultado de evaluar numeric-expr2 especifica el ancho en bits de cada número, que puede ser 8, 16 o 32.

Como ejemplo de los tres tipos anteriores de expresiones, para producir el nombre de un registro PTR para la dirección IP que se está asignando a un cliente, se podría escribir la siguiente expresión:




        concat (binary-to-ascii (10, 8, ".",
                                 reverse (1, leased-address)),
                ".in-addr.arpa.");


encode-int (numeric-expr,
    width)


Numeric-expr se evalúa y se codifica como una cadena de datos del ancho especificado, en orden de bytes de red (el byte más significativo primero). Si la expresión numérica se evalúa al valor null, el resultado también es null.


pick-first-value (data-expr1 [ ... exprn ]
    )


La función pick-first-value toma cualquier número de expresiones de datos como sus argumentos. Cada expresión se evalúa, empezando por la primera de la lista, hasta que se encuentra una expresión que no se evalúa a un valor null. Esa expresión se devuelve, y ninguna de las expresiones subsiguientes se evalúa. Si todas las expresiones se evalúan a un valor null, se devuelve el valor null.


host-decl-name


La función host-decl-name devuelve el nombre de la declaración de host que coincidió con el cliente cuya solicitud se está procesando actualmente, si la hay. Si ninguna declaración de host coincidió, el resultado es el valor null.






EXPRESIONES   NUMÉRICAS


Las expresiones numéricas son expresiones que se evalúan a un entero. En general, no se debe asumir que el tamaño máximo de dicho entero sea representable en menos de 32 bits, pero la precisión de dichos enteros puede ser mayor que 32 bits.


Además de los siguientes operadores, varias funciones matemáticas estándar están disponibles. Son:


operación    símbolo
sumar            +
restar       -
dividir         /
multiplicar       *
módulo        %
and bit a bit    &
or bit a bit     |
xor bit a bit    ^


extract-int (data-expr,
  width)


El extract-int operador extrae un valor entero en orden de bytes de red del resultado de evaluar la expresión de datos especificada. Width es el ancho en bits del entero a extraer. Actualmente, los únicos anchos soportados son 8, 16 y 32. Si la evaluación de la expresión de datos no proporciona suficientes bits para extraer un entero del tamaño especificado, se devuelve el valor null.


lease-time


La duración del arrendamiento actual, es decir, la diferencia entre la hora actual y la hora en que el arrendamiento expira.


number


Cualquier número entre cero y el tamaño máximo representable puede especificarse como una expresión numérica.


client-state


El estado actual de la instancia de cliente que se está procesando. Esto solo es útil en archivos de configuración de cliente DHCP. Los valores posibles son:


  
•

  
Booting - El cliente DHCP está en el estado INIT, y aún no tiene una dirección IP. El siguiente mensaje transmitido será un DHCPDISCOVER, que se emitirá en difusión.

  
•

  
Reboot - El cliente DHCP está en el estado INIT-REBOOT. Tiene una dirección IP, pero aún no la está usando. El siguiente mensaje a transmitir será un DHCPREQUEST, que se emitirá en difusión. Si no se recibe respuesta, el cliente se vinculará a su dirección y pasará al estado BOUND.

  
•

  
Select - El cliente DHCP está en el estado SELECTING: ha recibido al menos un mensaje DHCPOFFER, pero está esperando para ver si puede recibir otros mensajes DHCPOFFER de otros servidores. No se envían mensajes en el estado SELECTING.

  
•

  
Request - El cliente DHCP está en el estado REQUESTING: ha recibido al menos un mensaje DHCPOFFER y ha elegido cuál solicitará. El siguiente mensaje a enviar será un mensaje DHCPREQUEST, que se emitirá en difusión.

  
•

  
Bound - El cliente DHCP está en el estado BOUND: tiene una dirección IP. No se transmiten mensajes en este estado.

  
•

  
Renew - El cliente DHCP está en el estado RENEWING: tiene una dirección IP y está intentando contactar al servidor para renovarla. El siguiente mensaje a enviar será un mensaje DHCPREQUEST, que se enviará en unicast directamente al servidor.

  
•

  
Rebind - El cliente DHCP está en el estado REBINDING: tiene una dirección IP y está intentando contactar a cualquier servidor para renovarla. El siguiente mensaje a enviar será un DHCPREQUEST, que se emitirá en difusión.










REFERENCIA:   EXPRESIONES DE ACCIÓN


log (priority, data-expr)




Las sentencias de registro pueden usarse para enviar información a los canales de registro estándar. Una sentencia de registro incluye una prioridad opcional (fatal, error, infoo debug), y una expresión de datos.


Las sentencias de registro toman solo un argumento de expresión de datos, así que si desea emitir múltiples valores de datos, deberá usar el
    concat operador para concatenarlos.




execute (command-path [, data-expr1,
    ... data-exprN]);




La execute sentencia ejecuta un comando externo. El primer argumento es un literal de cadena que contiene el nombre o la ruta del comando a ejecutar. Los otros argumentos, si están presentes, son literales de cadena o expresiones de datos que se evalúan a cadenas de texto, para pasarse como argumentos de línea de comandos al comando.


execute es síncrono; el programa se bloqueará hasta que el comando externo que se está ejecutando haya terminado. Tenga en cuenta que una ejecución de programa extensa (por ejemplo, en un "on commit" en dhcpd.conf) puedeult en un rendimiento deficiente y tiempos de espera. Solo las aplicaciones externas con tiempos de ejecución muy cortos son adecuadas para su uso.


Pasar datos proporcionados por el usuario a una aplicación externa puede ser peligroso. Asegúrese de que la aplicación externa compruebe la validez de los búferes de entrada. Los caracteres ASCII no imprimibles se convertirán en secuencias de escape octales del lenguaje dhcpd.conf ("\nnn"), asegúrese de que su comando externo los maneje como tales.


Es posible usar la instrucción execute en cualquier contexto, no solo en eventos. Si la coloca en un ámbito regular en el archivo de configuración, se ejecutará ese comando cada vez que se evalúe un ámbito.




parse-vendor-option;




La parse-vendor-option instrucción intenta analizar una opción de proveedor (código 43). Solo es útil mientras se procesa un paquete en el servidor y requiere que el administrador ya haya utilizado la
    vendor-option-space instrucción para seleccionar un espacio de proveedor válido.


Esta funcionalidad puede usarse si el servidor necesita tomar diferentes acciones dependiendo de los valores que el cliente colocó en la opción de proveedor y las subopciones no están en ubicaciones fijas. Se maneja como una acción para permitir que un administrador examine las opciones entrantes y elija el espacio de proveedor correcto.
