DHCPCLIENT(1) Servidor demonio FreeRADIUS DHCPCLIENT(1)

NOMBRE

dhcpclient - Envía una solicitud DHCP con atributos RADIUS proporcionados y obtiene la respuesta de salida.

SINOPSIS

dhcpclient [-d directorio_raddb] [-D directorio_diccionario] [-f archivo] [-h] [-i interfaz] [-t tiempo_espera] [-v] [-x] servidor[:puerto] {discover|request|decline|release|inform|auto}

DESCRIPCIÓN

dhcpclient es un programa cliente de prueba DHCP. Puede enviar paquetes DHCP arbitrarios al servidor FreeRADIUS que se ejecuta como servidor DHCP, y luego muestra la respuesta. Se puede utilizar para probar cambios realizados en la configuración del servidor RADIUS o para monitorizar si un servidor RADIUS está activo.

dhcpclient lee pares de atributos/valor de RADIUS de su entrada estándar, o de un archivo especificado en la línea de comandos. Luego, codifica estos pares de atributos/valor utilizando el diccionario y los envía al servidor local/remoto.

OPCIONES

-d directorio_raddb
El directorio que contiene el archivo de diccionario de usuario. El valor predeterminado es /etc/raddb.
-D directorio_diccionario
El directorio que contiene el archivo de diccionario principal. El valor predeterminado es /usr/share/freeradius.
-f archivo[:archivo]
Archivo del que leer los pares atributo/valor. Si no se especifica, se leen de stdin. Esta opción se puede especificar varias veces, en cuyo caso los paquetes se envían en orden por archivo, y dentro de cada archivo, del primer paquete al último. Una línea en blanco separa los paquetes lógicos dentro de un archivo.
-h
Imprime la información de ayuda del uso.
-i interfaz
Selecciona la interfaz a través de la cual enviar/recibir a nivel de paquete en un socket RAW.
-t tiempo_espera
Espera tiempo_espera segundos antes de decidir que el NAS no ha respondido a una solicitud y reenviar el paquete. Puede ser un número de punto flotante, por ejemplo, 2.2.
-v
Imprime información sobre la versión del programa.
-x
Imprime información de depuración.
servidor[:puerto]
El nombre de host o la dirección IP del servidor remoto. Opcionalmente, se puede especificar un puerto UDP. Si no se especifica un puerto UDP, se busca en /etc/services. El nombre del servicio que se busca es radacct para los paquetes de contabilidad, y radius para todas las demás solicitudes. Si no se encuentra un servicio en /etc/services, se utilizan 1813 y 1812 respectivamente.
discover | request | decline | release | inform | auto
Opciones DHCP: utiliza el tipo relevante para la prueba
