DESCRIPCIÓ

N

dhcpcd-run-hooks es utilizado por dhcpcd(8) para ejecutar cualquier script de gancho definido por el sistema y por el usuario. Los scripts de gancho del sistema se encuentran en /usr/lib/dhcpcd/dhcpcd-hooks y los ganchos definidos por el usuario son /etc/dhcpcd.enter-hook. y /etc/dhcpcd.exit-hook. La instalación predeterminada incluye scripts de gancho para configurar /etc/resolv.conf y el nombre de host. Su distribución puede haber incluido otros scripts de gancho para, por ejemplo, configurar ntp o ypbind. También se incluye un gancho de prueba que simplemente hace un eco de las variables dhcp a la consola desde el mensaje

DISCOVER.

Los scripts de gancho se cargan en el shell actual en lugar de ejecutarse en su propio proceso. Esto permite que cada script de gancho, como /etc/dhcpcd.enter-hook, personalice variables de entorno o proporcione funciones alternativas a los ganchos posteriores en la cadena. Como tal, usar las funciones incorporadas del shell exit, exec o similares hará que dhcpcd-run-hooks salga en ese

punto.

Cada vez que dhcpcd-run-hooks es invocado, $interface se establece en la interfaz en la que dhcpcd se está ejecutando y $reason se establece en la razón por la que dhcpcd-run-hooks fue invocado. La información DHCP a configurar se guarda en variables que comienzan con la palabra new_ y la información DHCP antigua a eliminar se guarda en variables que comienzan con la palabra old_. dhcpcd puede mostrar la lista completa de variables que conoce usando el argumento -V, --variables

.
