DH_generate_key(3ssl)

Paquete: openssl

Licencias: Apache-2.0

DH_GENERATE_KEY(3ssl) OpenSSL DH_GENERATE_KEY(3ssl)

NOMBRE

DH_generate_key, DH_compute_key, DH_compute_key_padded - realizar el intercambio de claves Diffie-Hellman

SINOPSIS

#include <openssl/dh.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int DH_generate_key(DH *dh);
int DH_compute_key(unsigned char *key, const BIGNUM *pub_key, DH *dh);
int DH_compute_key_padded(unsigned char *key, const BIGNUM *pub_key, DH *dh);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_derive_init(3) y EVP_PKEY_derive(3).

DH_generate_key() realiza el primer paso de un intercambio de claves Diffie-Hellman generando valores DH privados y públicos. Al llamar a DH_compute_key() o DH_compute_key_padded(), estos se combinan con el valor público de la otra parte para computar la clave compartida.

DH_generate_key() espera que dh contenga los parámetros compartidos dh->p y dh->g. Genera un valor privado DH aleatorio a menos que dh->priv_key ya esté establecido, y computa el valor público correspondiente dh->pub_key, que puede entonces ser publicado.

DH_compute_key() computa el secreto compartido a partir del valor DH privado en dh y el valor público de la otra parte en pub_key y lo almacena en key. key debe apuntar a DH_size(dh) bytes de memoria. El estilo de relleno es RFC 5246 (8.1.2) que elimina los bytes cero iniciales. No es de tiempo constante debido a que los bytes cero iniciales se eliminan. El valor de retorno debe considerarse público.

DH_compute_key_padded() es similar pero almacena un número fijo de bytes. El estilo de relleno es NIST SP 800-56A (C.1) que conserva los bytes cero iniciales. Es de tiempo constante debido a que los bytes cero iniciales se conservan. El valor de retorno debe considerarse público.

VALORES DE RETORNO

DH_generate_key() devuelve 1 en caso de éxito, 0 en caso contrario.

DH_compute_key() devuelve el tamaño del secreto compartido en caso de éxito, -1 en caso de error.

DH_compute_key_padded() devuelve DH_size(dh) en caso de éxito, -1 en caso de error.

Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

EVP_PKEY_derive(3), DH_new(3), ERR_get_error(3), RAND_bytes(3), DH_size(3)

HISTORIA

DH_compute_key_padded() se añadió en OpenSSL 1.0.2.

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
