DH_size(3ssl)

Paquete: openssl

Licencias: Apache-2.0

DH_SIZE(3ssl) OpenSSL DH_SIZE(3ssl)

NOMBRE

DH_size, DH_bits, DH_security_bits - obtener el tamaño del primo de Diffie-Hellman y los bits de seguridad

SINOPSIS

#include <openssl/dh.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int DH_bits(const DH *dh);
int DH_size(const DH *dh);
int DH_security_bits(const DH *dh);

DESCRIPCIÓN

Las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_get_bits(3), EVP_PKEY_get_security_bits(3) y EVP_PKEY_get_size(3).

DH_bits() devuelve el número de bits significativos.

dh y dh->p no deben ser NULL.

DH_size() devuelve el tamaño del primo de Diffie-Hellman en bytes. Puede usarse para determinar cuánta memoria debe asignarse para el secreto compartido computado por DH_compute_key(3).

DH_security_bits() devuelve el número de bits de seguridad de la clave dh dada. Ver BN_security_bits(3).

VALORES DE RETORNO

DH_bits() devuelve el número de bits en la clave, o -1 si dh no contiene ningún parámetro de clave.

DH_size() devuelve el tamaño del primo de Diffie-Hellman en bytes, o -1 si dh no contiene ningún parámetro de clave.

DH_security_bits() devuelve el número de bits de seguridad, o -1 si dh no contiene ningún parámetro de clave.

VER TAMBIÉN

EVP_PKEY_get_bits(3), DH_new(3), DH_generate_key(3), BN_num_bits(3)

HISTORIA

Todas las funciones fueron marcadas como obsoletas en OpenSSL 3.0.
