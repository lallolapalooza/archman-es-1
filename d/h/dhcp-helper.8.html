DHCP-HELPER(8) Manual del Administrador del Sistema DHCP-HELPER(8)

NOMBRE

dhcp-helper - Un agente de retransmisión DHCP/BOOTP.

SINOPSIS

dhcp-helper [OPCIÓN]...

DESCRIPCIÓN

dhcp-helper es un agente de retransmisión DHCP y BOOTP. Escucha las difusiones DHCP y BOOTP en subredes conectadas directamente y las retransmite a servidores DHCP o BOOTP en otro lugar. También retransmite las respuestas de los servidores remotos a hosts parcialmente configurados. Una vez que los hosts están completamente configurados, pueden comunicarse directamente con sus servidores y ya no necesitan los servicios de un relé.

OPCIONES

La única opción requerida es al menos un servidor DHCP al cual retransmitir. La forma más sencilla de configurar dhcp-helper en un router es simplemente darle a la interfaz de la red que contiene el servidor DHCP con una opción -b. Todas las demás interfaces presentes en la máquina aceptarán solicitudes DHCP. En una máquina que no tiene una interfaz en la red que contiene el servidor DHCP, use una opción -s en su lugar.

-s <servidor>
Especifica un servidor DHCP o BOOTP al cual retransmitir. El servidor puede ser dado como un nombre de máquina o dirección IP de cuatro cuádruples. Se pueden especificar más de un servidor.
-b <interfaz>
Retransmite a un servidor DHCP o BOOTP mediante difusión a través de <interfaz>. Esto elimina la necesidad de especificar una dirección de servidor. <interfaz> se añade automáticamente a la lista de interfaces que no recibirán solicitudes DHCP.
-i <interfaz>
Especifica en qué interfaces locales escuchar las difusiones DHCP/BOOTP. Si no se dan opciones -i, se utilizan todas las interfaces excepto las especificadas por opciones -e y las especificadas por opciones -b.
-e <interfaz>
Especifica qué interfaces locales excluir.
-p
Utiliza puertos alternativos (1067/1068) para el cliente y servidor DHCP.
-v
Reporta la versión de la release del software e información de copyright.
-d
Modo de depuración, no cambia UID, no escribe un archivo pid ni se pone en segundo plano.
-r <archivo>
Especifica una ruta alternativa para que dhcp-helper grabe su ID de proceso. Normalmente /var/run/dhcp-helper.pid.
-u <nombredeusuario>
Especifica el ID de usuario al que dhcp-helper cambiará después del inicio. El demonio normalmente debe iniciarse como root, pero soltará los privilegios de root después del inicio cambiando su ID a otro usuario. Normalmente este usuario es "nobody", pero eso se puede anular con este interruptor.

NOTAS

Dhcp-helper requiere un kernel de Linux 2.2 o posterior. Las facilidades de "filtro de paquetes de Linux" y "socket de paquetes" *no* son requeridas, lo cual es la principal ventaja de este software sobre el demonio de retransmisión DHCP de ISC.
