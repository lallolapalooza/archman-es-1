NAME

dhex — editor hexadecimal con modo de diferencia

SYNOPSIS

dhex [-x]

dhex [-h] [-v] [-g] [-k] [-ab -ad -ah -ao dirección base] [-f archivo de configuración] [-m archivo de marcadores] [-ob -od -oh -oo desplazamiento] [-r log de búsqueda] [-sa -sab cadena (ascii)] [-sh -shb cadena (hex)] [-w log de búsqueda] [archivo]

dhex [-h] [-v] [-g] [-k] [-a1b -a1d -a1h -a1o dirección base 1] [-a2b -a2d -a2h -a2o dirección base 2] [-cb] [-cd límite superior] [-cl] [-f archivo de configuración] [-m archivo de marcadores] [-o1b -o1d -o1h -o1o desplazamiento1] [-o2b -o2d -o2h -o2o desplazamiento2] [-r1 log de búsqueda1] [-r2 log de búsqueda2] [-s1a -s1ab -s1h -s1hb cadena (ascii/hex)] [-s2a -s2ab -s2h -s2hb cadena (ascii/hex)] [-w1 log de búsqueda1] [-w2 log de búsqueda2] [archivo1 archivo2]

DESCRIPTION

dhex es un editor hexadecimal. Puede ser utilizado para alterar bytes individuales en archivos grandes. Ya que es un programa en modo texto basado en ncurses, puede ejecutarse en numerosos escenarios. Su característica especial es el modo de diferencia: Con él, el usuario tiene una herramienta visual para la comparación de archivos. Este modo se invoca cuando dhex es llamado con dos archivos en lugar de uno como parámetros.

OPTIONS

Todas las opciones no distinguen entre mayúsculas y minúsculas y pueden ser dadas como caracteres en mayúsculas o minúsculas.

-ab -ad -ah -ao dirección base
Después de cargar un archivo, cada dirección obtiene una dirección base distinta de 0. Con esto, es más fácil trabajar en volcados de memoria parciales. La dirección base puede ser dada como binaria con [-ab] , como decimal con [-ad] , como hexadecimal con [-ah] o como octal con [-ao].
-a1b -a1d -a1h -a1o dirección base 1
 
-a2b -a2d -a2h -a2o dirección base 2
Para el modo de diferencia, es posible establecer dos direcciones base diferentes. De nuevo, una dirección binaria puede ser dada como [-a1b -a2b] , como decimal con [-a1d -a2d] , como hexadecimal con [-a1h -a2h] o como octal con [-a1o -a2o].

Esta dirección base se calcula en los archivos de marcadores así como en los logs de búsqueda.

-cb -cl
Solo modo de diferencia: Los archivos de entrada pueden ser correlacionados desde la línea de comandos con la mejor coincidencia -cb o la más larga -cl. Esto es muy lento.
-cd límite superior
Solo modo de diferencia: Los archivos de entrada pueden ser correlacionados desde la línea de comandos con la diferencia mínima. Para mejorar la velocidad de correlación, se puede proporcionar un límite superior.
-f archivo de configuración
Normalmente, se lee .dhexrc del directorio de inicio del invocador. Con este parámetro, se puede cargar cualquier otro archivo de configuración. Ver dhexrc(5) para una descripción de su formato de archivo.
-g
Muestra la licencia
-x
Inicia el calculador hexadecimal (hexcal)
-h
Muestra la pantalla de ayuda
-k
Inicia la configuración del teclado manualmente antes de que se cargue cualquier archivo. Esto es muy útil al llamar a dhex desde una terminal exótica.
-m archivo de marcadores
Es posible en dhex establecer marcadores y almacenarlos en un archivo de marcadores para su uso posterior. Con este parámetro, el archivo de marcadores se lee al inicio, haciendo innecesario leerlos más tarde a través de la interfaz gráfica. Su formato de archivo se describe en dhex_markers(5).
-ob -od -oh -oo desplazamiento
Después de cargar un archivo, el cursor se establece en 0, y la primera página de bytes se muestra en la pantalla. Con uno de estos parámetros es posible comenzar en cualquier otra ubicación en el archivo. La posición del cursor podría darse como un número binario con [-ob] , como decimal con [-od] , como hexadecimal con [-oh] o como octal con [-oo].
-o1b -o1d -o1h -o1o desplazamiento1
 
-o2b -o2d -o2h -o2o desplazamiento2
Para el modo de diferencia, es posible establecer dos posiciones de cursor diferentes al inicio. De nuevo, las posiciones del cursor pueden darse como un número binario con [-o1b -o2b] , como decimal con [-o1d -o2d] , como hexadecimal con [-o1h -o2h] o como octal con [-o1o -o2o].
