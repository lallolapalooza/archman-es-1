DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine dhsein (character side, character eigsrc, character initv, logical, dimension( * ) select, integer n, double precision, dimension( ldh, * ) h, integer ldh, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, double precision, dimension( * ) work, integer, dimension( * ) ifaill, integer, dimension( * ) ifailr, integer info)

DHSEIN

Propósito:

!>
!> DHSEIN utiliza iteración inversa para encontrar los
!> (auto)vectores derechos y/o izquierdos especificados de una matriz
!> H real en forma de Hessenberg superior.
!>
!> El (auto)vector derecho x y el (auto)vector izquierdo y de la matriz H
!> correspondientes a un valor propio w se definen por:
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> donde y**h denota la transpuesta conjugada del vector y.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo (auto)vectores derechos;
!>          = 'L': calcular solo (auto)vectores izquierdos;
!>          = 'B': calcular ambos (auto)vectores derechos e izquierdos.
!>

EIGSRC

!>          EIGSRC es CHARACTER*1
!>          Especifica la fuente de los valores propios proporcionados en (WR,WI):
!>          = 'Q': los valores propios se encontraron usando DHSEQR; por lo tanto, si
!>                 H tiene elementos subdiagonales cero, y por lo tanto es
!>                 bloque-triangular, entonces el j-ésimo valor propio puede
!>                 ser asumido como un valor propio del bloque que contiene
!>                 la fila/columna j. Esta propiedad permite a DHSEIN
!>                 realizar iteración inversa solo en un bloque diagonal.
!>          = 'N': no se hacen suposiciones sobre la correspondencia
!>                 entre valores propios y bloques diagonales. En este
!>                 caso, DHSEIN siempre debe realizar iteración inversa
!>                 usando toda la matriz H.
!>

INITV

!>          INITV es CHARACTER*1
!>          = 'N': no se proporcionan vectores iniciales;
!>          = 'U': se proporcionan vectores iniciales proporcionados por el usuario
!>                 en los arrays VL y/o VR.
!>

SELECT

!>          SELECT es un array LOGICAL, dimension (N)
!>          Especifica los (auto)vectores a calcular. Para seleccionar el
!>          (auto)vector real correspondiente a un valor propio real WR(j),
!>          SELECT(j) debe establecerse en .TRUE.. Para seleccionar el
!>          (auto)vector complejo correspondiente a un valor propio complejo
!>          (WR(j),WI(j)), con su conjugado complejo (WR(j+1),WI(j+1)),
!>          ya sea SELECT(j) o SELECT(j+1) o ambos deben establecerse en
!>          .TRUE.; luego, en la salida, SELECT(j) es .TRUE. y SELECT(j+1) es
!>          .FALSE..
!>

N

!>          N es INTEGER
!>          El orden de la matriz H. N >= 0.
!>

H

!>          H es un array DOUBLE PRECISION, dimension (LDH,N)
!>          La matriz H en forma de Hessenberg superior.
!>          Si se detecta un NaN en H, la rutina devolverá INFO=-6.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H. LDH >= max(1,N).
!>

WR

!>          WR es un array DOUBLE PRECISION, dimension (N)
!>

WI

!>          WI es un array DOUBLE PRECISION, dimension (N)
!>
!>          En la entrada, las partes real e imaginaria de los valores propios de
!>          H; un par de valores propios conjugados complejos debe almacenarse en
!>          elementos consecutivos de WR y WI.
!>          En la salida, WR puede haber sido modificado ya que los valores propios cercanos
!>          se perturban ligeramente al buscar (auto)vectores independientes.
!>

VL

!>          VL es un array DOUBLE PRECISION, dimension (LDVL,MM)
!>          En la entrada, si INITV = 'U' y SIDE = 'L' o 'B', VL debe
!>          contener vectores de inicio para la iteración inversa para los
!>          (auto)vectores izquierdos; el vector de inicio para cada (auto)vector
!>          debe estar en las mismas columnas en las que se almacenará el (auto)vector.
!>          En la salida, si SIDE = 'L' o 'B', los (auto)vectores izquierdos
!>          especificados por SELECT se almacenarán consecutivamente en las
!>          columnas de VL, en el mismo orden que sus valores propios. Un
!>          (auto)vector complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la parte real
!>          y la segunda la imaginaria.
!>          Si SIDE = 'R', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= max(1,N) si SIDE = 'L' o 'B'; LDVL >= 1 en caso contrario.
!>

VR

!>          VR es un array DOUBLE PRECISION, dimension (LDVR,MM)
!>          En la entrada, si INITV = 'U' y SIDE = 'R' o 'B', VR debe
!>          contener vectores de inicio para la iteración inversa para los
!>          (auto)vectores derechos; el vector de inicio para cada (auto)vector
!>          debe estar en las mismas columnas en las que se almacenará el (auto)vector.
!>          En la salida, si SIDE = 'R' o 'B', los (auto)vectores derechos
!>          especificados por SELECT se almacenarán consecutivamente en las
!>          columnas de VR, en el mismo orden que sus valores propios. Un
!>          (auto)vector complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la parte real
!>          y la segunda la imaginaria.
!>          Si SIDE = 'L', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= max(1,N) si SIDE = 'R' o 'B'; LDVR >= 1 en caso contrario.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR necesario para
!>          almacenar los (auto)vectores; cada (auto)vector real seleccionado
!>          ocupa una columna y cada (auto)vector complejo seleccionado
!>          ocupa dos columnas.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimension ((N+2)*N)
!>

IFAILL

!>          IFAILL es un array INTEGER, dimension (MM)
!>          Si SIDE = 'L' o 'B', IFAILL(i) = j > 0 si el (auto)vector izquierdo
!>          en la i-ésima columna de VL (correspondiente al
!>          valor propio w(j)) no convergió; IFAILL(i) = 0 si el
!>          (auto)vector convergió satisfactoriamente. Si las columnas i-ésima y (i+1)-ésima
!>          de VL contienen un (auto)vector complejo, entonces IFAILL(i) y
!>          IFAILL(i+1) se establecen al mismo valor.
!>          Si SIDE = 'R', IFAILL no se referencia.
!>

IFAILR

!>          IFAILR es un array INTEGER, dimension (MM)
!>          Si SIDE = 'R' o 'B', IFAILR(i) = j > 0 si el (auto)vector derecho
!>          en la i-ésima columna de VR (correspondiente al
!>          valor propio w(j)) no convergió; IFAILR(i) = 0 si el
!>          (auto)vector convergió satisfactoriamente. Si las columnas i-ésima y (i+1)-ésima
!>          de VR contienen un (auto)vector complejo, entonces IFAILR(i) y

!>          IFAILR(i+1) se establecen al mismo valor.
!>          Si SIDE = 'L', IFAILR no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, i es el número de autovectores que
!>                no lograron converger; ver IFAILL e IFAILR para más
!>                detalles.
!>
