NOMBRE

dhclient.leases - base de datos de concesiones del cliente DHCP

DESCRIPCIÓN

El cliente DHCP de Internet Systems Consortium mantiene una base de datos persistente de las concesiones que ha adquirido y que aún son válidas. La base de datos es un archivo ASCII de formato libre que contiene una declaración válida por cada concesión. Si aparece más de una declaración para una concesión dada, se utiliza la última en el archivo. El archivo se escribe como un registro, por lo que esta no es una ocurrencia inusual.

El formato de las declaraciones de concesión se describe en dhclient.conf(5).

ARCHIVOS

DBDIR/dhclient.leases

VER TAMBIÉN

dhclient(8), dhcp-options(5), dhclient.conf(5), dhcpd(8), dhcpd.conf(5), RFC2132, RFC2131.
