subrutina dhsein (character side, character eigsrc, character initv, logical, dimension( * ) select, integer n, double precision, dimension( ldh, * ) h, integer ldh, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, double precision, dimension( * ) work, integer, dimension( * ) ifaill, integer, dimension( * ) ifailr, integer info)

DHSEIN

Propósito:

!>
!> DHSEIN usa iteración inversa para encontrar autovectores derechos y/o
!> izquierdos especificados de una matriz real de Hessenberg superior H.
!>
!> El autovector derecho x y el autovector izquierdo y de la matriz H
!> correspondientes a un autovalor w están definidos por:
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> donde y**h denota la transpuesta conjugada del vector y.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo autovectores derechos;
!>          = 'L': calcular solo autovectores izquierdos;
!>          = 'B': calcular tanto autovectores derechos como izquierdos.
!>

EIGSRC

!>          EIGSRC es CHARACTER*1
!>          Especifica la fuente de los autovalores proporcionados en (WR,WI):
!>          = 'Q': los autovalores se encontraron usando DHSEQR; así, si
!>                 H tiene elementos subdiagonales cero, y por lo tanto es
!>                 triangular por bloques, se puede asumir que el j-ésimo
!>                 autovalor es un autovalor del bloque que contiene
!>                 la j-ésima fila/columna. Esta propiedad permite a DHSEIN
!>                 realizar iteración inversa en un solo bloque diagonal.
!>          = 'N': no se hacen suposiciones sobre la correspondencia
!>                 entre autovalores y bloques diagonales. En este
!>                 caso, DHSEIN siempre debe realizar iteración inversa
!>                 usando la matriz completa H.
!>

INITV

!>          INITV es CHARACTER*1
!>          = 'N': no se proporcionan vectores iniciales;
!>          = 'U': los vectores iniciales proporcionados por el usuario se almacenan en los arreglos
!>                 VL y/o VR.
!>

SELECT

!>          SELECT es un arreglo LOGICAL, dimensión (N)
!>          Especifica los autovectores a calcular. Para seleccionar el
!>          autovector real correspondiente a un autovalor real WR(j),
!>          SELECT(j) debe establecerse en .TRUE.. Para seleccionar el
!>          autovector complejo correspondiente a un autovalor complejo
!>          (WR(j),WI(j)), con conjugado complejo (WR(j+1),WI(j+1)),
!>          SELECT(j) o SELECT(j+1) o ambos deben establecerse en
!>          .TRUE.; luego en la salida SELECT(j) es .TRUE. y SELECT(j+1) es
!>          .FALSE..
!>

N

!>          N es INTEGER
!>          El orden de la matriz H.  N >= 0.
!>

H

!>          H es un arreglo DOUBLE PRECISION, dimensión (LDH,N)
!>          La matriz de Hessenberg superior H.
!>          Si se detecta un NaN en H, la rutina retornará con INFO=-6.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del arreglo H.  LDH >= max(1,N).
!>

WR

!>          WR es un arreglo DOUBLE PRECISION, dimensión (N)
!>

WI

!>          WI es un arreglo DOUBLE PRECISION, dimensión (N)
!>
!>          En la entrada, las partes real e imaginaria de los autovalores de
!>          H; un par de autovalores conjugados complejos debe almacenarse en
!>          elementos consecutivos de WR y WI.
!>          En la salida, WR puede haber sido alterado ya que autovalores cercanos
!>          se perturban ligeramente al buscar autovectores independientes.
!>

VL

!>          VL es un arreglo DOUBLE PRECISION, dimensión (LDVL,MM)
!>          En la entrada, si INITV = 'U' y SIDE = 'L' o 'B', VL debe
!>          contener vectores de inicio para la iteración inversa de los
!>          autovectores izquierdos; el vector de inicio para cada autovector
!>          debe estar en la(s) misma(s) columna(s) en la(s) que el autovector será
!>          almacenado.
!>          En la salida, si SIDE = 'L' o 'B', los autovectores izquierdos
!>          especificados por SELECT se almacenarán consecutivamente en las
!>          columnas de VL, en el mismo orden que sus autovalores. Un
!>          autovector complejo correspondiente a un autovalor complejo es
!>          almacenado en dos columnas consecutivas, la primera conteniendo la parte real
!>          y la segunda la parte imaginaria.
!>          Si SIDE = 'R', VL no es referenciado.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del arreglo VL.
!>          LDVL >= max(1,N) si SIDE = 'L' o 'B'; LDVL >= 1 en otro caso.
!>

VR

!>          VR es un arreglo DOUBLE PRECISION, dimensión (LDVR,MM)
!>          En la entrada, si INITV = 'U' y SIDE = 'R' o 'B', VR debe
!>          contener vectores de inicio para la iteración inversa de los
!>          autovectores derechos; el vector de inicio para cada autovector
!>          debe estar en la(s) misma(s) columna(s) en la(s) que el autovector será
!>          almacenado.
!>          En la salida, si SIDE = 'R' o 'B', los autovectores derechos
!>          especificados por SELECT se almacenarán consecutivamente en las
!>          columnas de VR, en el mismo orden que sus autovalores. Un
!>          autovector complejo correspondiente a un autovalor complejo es
!>          almacenado en dos columnas consecutivas, la primera conteniendo la parte real
!>          y la segunda la parte imaginaria.
!>          Si SIDE = 'L', VR no es referenciado.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del arreglo VR.
!>          LDVR >= max(1,N) si SIDE = 'R' o 'B'; LDVR >= 1 en otro caso.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arreglos VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arreglos VL y/o VR requeridas para
!>          almacenar los autovectores; cada autovector real seleccionado
!>          ocupa una columna y cada autovector complejo seleccionado
!>          ocupa dos columnas.
!>

WORK

!>          WORK es un arreglo DOUBLE PRECISION, dimensión ((N+2)*N)
!>

IFAILL

!>          IFAILL es un arreglo INTEGER, dimensión (MM)
!>          Si SIDE = 'L' o 'B', IFAILL(i) = j > 0 si el autovector
!>          izquierdo en la i-ésima columna de VL (correspondiente al
!>          autovalor w(j)) falló en converger; IFAILL(i) = 0 si el
!>          autovector convergió satisfactoriamente. Si la i-ésima y (i+1)ésima
!>          columna de VL contienen un autovector complejo, entonces IFAILL(i) y
!>          IFAILL(i+1) se establecen al mismo valor.
!>          Si SIDE = 'R', IFAILL no es referenciado.
!>

IFAILR

!>          IFAILR es un arreglo INTEGER, dimensión (MM)
!>          Si SIDE = 'R' o 'B', IFAILR(i) = j > 0 si el autovector
!>          derecho en la i-ésima columna de VR (correspondiente al
!>          autovalor w(j)) falló en converger; IFAILR(i) = 0 si el
!>          autovector convergió satisfactoriamente. Si la i-ésima y (i+1)ésima
!>          columna de VR contienen un autovector complejo, entonces IFAILR(i) y>          IFAILR(i+1) se establecen al mismo valor.
!>          Si SIDE = 'L', IFAILR no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, i es el número de autovectores que
!>                no lograron converger; ver IFAILL e IFAILR para más
!>                detalles.
!>

!>  magnitud tenga magnitud 1; aquí la magnitud de un número complejo
!>  (x,y) se toma como |x|+|y|.
!>
