DHCP_LEASE_TIME(1) Manual General de Comandos DHCP_LEASE_TIME(1)

NOMBRE

dhcp_lease_time - Consulta el tiempo restante de un lease en el servidor DHCP local de dnsmasq.

SINOPSIS

dhcp_lease_time <dirección>

DESCRIPCIÓN

Envía un mensaje DHCPINFORM a un servidor dnsmasq que se ejecuta en el host local e imprime (en stdout) el tiempo restante en cualquier lease para la dirección dada. El tiempo se proporciona como una cadena impresa en stdout.

Si ocurre un error o no existe un lease para la dirección dada, no se envía nada a stdout, se envía un mensaje a stderr y se devuelve un código de error distinto de cero.

Requiere dnsmasq 2.67 o posterior y puede que no funcione con otros servidores DHCP.

El argumento de dirección son direcciones IP en notación de puntos cuádruples y es obligatorio.

LIMITACIONES

Solo funciona con direcciones IPv4 y leases DHCP.

VER TAMBIÉN
