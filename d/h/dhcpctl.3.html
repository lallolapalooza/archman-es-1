DESCRIPCIÓN

El conjunto de funciones dhcpctl proporciona una API que puede ser utilizada para comunicarse y manipular un servidor DHCP de ISC en ejecución. Todas las funciones devuelven un valor de isc_result_t. Los valores de retorno reflejan el resultado de las operaciones en las estructuras de datos locales. Si una operación falla en el servidor por cualquier motivo, el resultado de error se devolverá a través del segundo parámetro de la llamada a dhcpctl_wait_for_completion().

dhcpctl_initialize() prepara las estructuras de datos que la biblioteca necesita para realizar su trabajo. Esta función debe llamarse una vez antes que cualquier otra.

dhcpctl_connect() abre una conexión al servidor DHCP en el host y puerto dados. Si se ha creado un autenticador para la conexión, se proporciona como 4º argumento. En caso de un retorno exitoso, la dirección apuntada por el primer argumento tendrá asignado un nuevo objeto de conexión.

Por ejemplo:

s = dhcpctl_connect(&cxn, "127.0.0.1", 7911, NULL);

se conecta al servidor DHCP en el localhost a través del puerto 7911 (el puerto OMAPI estándar). No se utiliza autenticación para la conexión.

dhcpctl_timed_connect() abre una conexión al servidor DHCP en el host y puerto dados. Si se ha creado un autenticador para la conexión, se proporciona como 4º argumento. En caso de un retorno exitoso, la dirección apuntada por el primer argumento tendrá asignado un nuevo objeto de conexión. Cuánto tiempo espera la función para completar la conexión está dictado por el valor del parámetro timeout. Si el valor es nulo, esperará indefinidamente. De lo contrario, esperará la cantidad de tiempo especificada por timeout (tv_sec:tv_usec). Valores de cero para ambos campos son válidos pero no recomendados. Se muestra un ejemplo a continuación:

Por ejemplo:

struct timeval timeout;
timeout.tv_sec = 5;   /* esperar 5 segundos */
timeout.tv_usec = 0;

s = dhcpctl_connect(&cxn, "127.0.0.1", 7911, NULL, &timeout);

se conecta al servidor DHCP en el localhost a través del puerto 7911 (el puerto OMAPI estándar). No se utiliza autenticación para la conexión. Permite 5 segundos para que la conexión se complete.

dhcpctl_disconnect() cierra la conexión abierta especificada por el primer parámetro, cxn. Tenga en cuenta que esta llamada liberará el objeto de conexión y cxn se establecerá a
nulo. Si el segundo parámetro, force, es distinto de cero, la conexión se cerrará inmediatamente. De lo contrario, el extremo receptor se cerrará pero cualquier dato no enviado se enviará antes de cerrar realmente el socket. Tenga en cuenta que la desconexión solo destruye el objeto de conexión, cualquier otro objeto creado previamente todavía existirá.

Por ejemplo:

s = dhcpctl_disconnect(&cxn, 1);

cerrará la conexión inmediatamente. Esta función debe considerarse EXPERIMENTAL.

dhcpctl_get_value() extrae un valor de un atributo del manejador. El valor puede ser de cualquier longitud y se trata como una secuencia de bytes. El manejador debe haber sido creado primero con dhcpctl_new_object() y abierto con dhcpctl_open_object(). El valor se devuelve a través del parámetro llamado “value”. El último parámetro es el nombre del atributo a

recuperar.

Las dhcpctl_set_value(), dhcpctl_set_string_value(), dhcpctl_set_boolean_value(), y dhcpctl_set_int_value() funciones establecen un valor en el manejador del

objeto.

dhcpctl_object_update() pone en cola una solicitud para que todos los cambios realizados en el manejador del objeto sean enviados al remoto para su procesamiento. Los cambios realizados en los atributos del manejador se aplicarán al objeto remoto si se

permite.

dhcpctl_object_refresh() pone en cola una solicitud para que una copia nueva de todos los valores de los atributos sea enviada desde el remoto para actualizar los valores en el manejador del objeto

local.

dhcpctl_object_remove() pone en cola una solicitud para la eliminación en el servidor del objeto referenciado por el

manejador.

La dhcpctl_set_callback() función establece una función definida por el usuario para ser llamada cuando un evento se completa en el manejador de objeto dado. Esto es necesario para el manejo asíncrono de eventos, a diferencia del manejo sincrónico proporcionado por dhcpctl_wait_for_completion(). Cuando la función es llamada, el primer parámetro es el objeto para el que llegó el evento, el segundo es el estado del mensaje que fue procesado, el tercero es el mismo valor que el segundo parámetro dado a dhcpctl_set_cal

lback().

La dhcpctl_new_authenticator() crea un nuevo objeto autenticador para ser usado para firmar los mensajes que cruzan la red. Los valores “name”, “algorithm”, y “secret” deben coincidir con lo que usa el servidor y están definidos en su archivo de configuración. El objeto creado se devuelve a través del primer parámetro y debe usarse como el 4º parámetro para dhcpctl_connect(). Tenga en cuenta que el valor 'secret' no debe estar codificado en base64, lo cual es diferente de cómo aparece el valor en el archivo dhcpd.

conf.

dhcpctl_new_object() crea un manejador local para un objeto en el servidor. El parámetro “object_type” es el nombre ascii del tipo de objeto al que se accede. p. ej. "lease". eso.

EJEMPLO

S

El siguiente programa se conectará al servidor DHCP que se ejecuta en el host local y obtendrá los detalles del arrendamiento existente para la dirección IP 10.0.0.101. Luego imprimirá la hora en que el arrendamiento vence. Tenga en cuenta que la mayor parte de la comprobación de errores ha sido omitida por

brevedad. 
#include <sys/time.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdarg.h>

#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

#include "omapip/result.h"
#include "dhcpctl.h"

int main (int argc, char **argv) {
	dhcpctl_data_string ipaddrstring = NULL;
	dhcpctl_data_string value = NULL;
	dhcpctl_handle connection = NULL;
	dhcpctl_handle lease = NULL;
	isc_result_t waitstatus;
	struct in_addr convaddr;
	time_t thetime;

        dhcpctl_initialize ();

        dhcpctl_connect (&connection, "127.0.0.1",
			 7911, 0);

        dhcpctl_new_object (&lease, connection,
			    "lease");

        memset (&ipaddrstring, 0, sizeof
		ipaddrstring);

        inet_pton(AF_INET, "10.0.0.101",
		  &convaddr);

	omapi_data_string_new (&ipaddrstring,
			       4, MDL);
	memcpy(ipaddrstring->value, &convaddr.s_addr, 4);

	dhcpctl_set_value (lease, ipaddrstring,
			   "ip-address");

	dhcpctl_open_object (lease, connection, 0);

	dhcpctl_wait_for_completion (lease,
				     &waitstatus);
        if (waitstatus != ISC_R_SUCCESS) {
		/* server not authoritative */
		exit (0);
        }

	dhcpctl_data_string_dereference(&ipaddrstring,
					MDL);

        dhcpctl_get_value (&value, lease, "ends");

	memcpy(&thetime, value->value, value->len);

	dhcpctl_data_string_dereference(&value, MDL);

	fprintf (stdout, "ending time is %s",
		 ctime(&thetime))
;
}
