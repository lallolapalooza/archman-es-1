doble precisión función dzsum1 (entero n, complejo*16, dimensión( * ) cx, entero incx)

DZSUM1 forma la 1-norma del vector complejo usando el valor absoluto verdadero.

Propósito:

!>
!> DZSUM1 toma la suma de los valores absolutos de un vector complejo
!> y devuelve un resultado de doble precisión.
!>
!> Basado en DZASUM de BLAS de Nivel 1.
!> El cambio es usar el valor absoluto 'genuino'.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de elementos en el vector CX.
!>

CX

!>          CX es un arreglo COMPLEX*16, dimensión (N)
!>          El vector cuyos elementos se sumarán.
!>

INCX

!>          INCX es ENTERO
!>          El espaciado entre valores sucesivos de CX. INCX > 0.
!>
