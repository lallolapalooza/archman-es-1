Date::Manip::Interfaces(3) Documentación de Perl aportada por el usuario Date::Manip::Interfaces(3)

NOMBRE

Date::Manip::Interfaces - Una descripción de las interfaces funcionales y OO

DESCRIPCIÓN

Hay tres formas diferentes de usar Date::Manip . A continuación se incluye una descripción completa de cada una. Son:

Interfaz funcional (versión 5)
Date::Manip versión 5 se ejecuta en versiones muy antiguas de perl. Si necesita usar Date::Manip con una versión de perl anterior a 5.10, esta es la única interfaz disponible.
Interfaz funcional (versión 6)
Cuando Date::Manip fue reescrito (versión 6), hizo uso de algunas características de perl 5.10 . Esta es la interfaz recomendada si está manteniendo un script que usa la interfaz funcional, pero donde está disponible una versión más reciente de perl.
Interfaz orientada a objetos
La interfaz OO es la interfaz recomendada siempre que sea posible. Es la única con acceso a toda la funcionalidad del módulo.

VERSIÓN 5 Y VERSIÓN 6

Date::Manip versión 5.xx estuvo disponible durante muchos años, pero sufrió de varias debilidades. Era lento, y no manejaba las zonas horarias o el horario de verano correctamente. Fue escrito como una interfaz funcional, aunque una interfaz orientada a objetos habría sido mejor. Sí tenía la ventaja de ejecutarse en versiones muy antiguas de perl (se sabe que funciona en perl 5.6 y puede funcionar en versiones aún más antiguas de perl).

Date::Manip versión 6.00 fue una reescritura completa del módulo. Para información detallada sobre las diferencias, por favor consulte el documento Date::Manip::Changes5to6. La reescritura fue necesaria para manejar operaciones de zona horaria, además de muchas otras mejoras incluyendo un rendimiento mucho mejor y un análisis más robusto.

La reescritura hizo uso de características introducidas en perl 5.10 que hicieron que las rutinas de análisis de fechas fueran significativamente más limpias. Además, la versión 6.xx fue escrita como un conjunto de módulos orientados a objetos que son mucho más poderosos que la interfaz funcional anterior. Por compatibilidad hacia atrás, una nueva interfaz funcional fue reescrita (que es simplemente un conjunto de funciones envoltorio que llaman a los métodos OO) que es casi completamente compatible hacia atrás con la interfaz versión 5.xx.

La distribución Date::Manip incluye las tres interfaces: la interfaz versión 5 más antigua, y tanto la nueva interfaz OO como la interfaz funcional compatible hacia atrás. Además, las tres se instalan, por lo que puede usar la interfaz que corresponda.

Dado que hay tres interfaces diferentes disponibles, elegir la interfaz es necesario.

Si está ejecutando en un sistema con una versión muy antigua de perl (anterior a 5.10), la interfaz versión 5 es su única opción.

Si está en un sistema ejecutando una versión más reciente de perl, pero necesita mantener un script que fue escrito usando la interfaz funcional, entonces puede usar la interfaz funcional versión 6.

Para todos los demás, se recomienda encarecidamente que use la interfaz orientada a objetos.

A continuación se incluye una descripción más detallada de cada interfaz. Si ya sabe qué interfaz quiere usar, simplemente vaya a la sección "VER TAMBIÉN" en Date::Manip para la documentación de cada interfaz.

INTERFAZ FUNCIONAL (VERSIÓN 5)

Cuando se usa una versión de perl anterior a 5.10, esta es la única interfaz disponible. Esta interfaz está documentada en el documento Date::Manip::DM5. Esta interfaz tiene varias debilidades que deben entenderse al usarla:

Soporte limitado
La interfaz funcional versión 5 ya no está en desarrollo, y solo hay soporte limitado disponible para ella.

A partir de diciembre de 2012, no se hará ningún desarrollo, y no corregiré ningún error restante en la versión 5. Si alguien proporciona un parche para corregir errores, lo aplicaré, siempre que se aplique limpiamente, y el código resultante continúe pasando todas las pruebas. No aplicaré parches para añadir características.

Pretendo eliminar esto en la versión 7.00.

Soporte limitado de zona horaria
El soporte de zona horaria es extremadamente limitado, y a menudo incorrecto. La falta de soporte de zona horaria fue la razón principal para reescribir Date::Manip.

La interfaz versión 5 no maneja correctamente los cambios de horario de verano.

Problemas de rendimiento
Se ha dedicado considerable tiempo a acelerar Date::Manip, y benchmarks bastante simples muestran que la versión 6 es aproximadamente dos veces más rápida que la versión 5.

INTERFAZ FUNCIONAL (VERSIÓN 6)

La interfaz funcional versión 6 es casi completamente idéntica a la interfaz funcional versión 5, excepto que usa los módulos orientados a objetos para hacer todo el trabajo real.

El soporte de zona horaria está muy mejorado, pero todavía es algo limitado. Dado que la interfaz versión 6 es compatible hacia atrás, las fechas no almacenan información de zona horaria en ellas, por lo que el programador es responsable de llevar la cuenta de en qué zona horaria está cada fecha. Si quiere acceso completo al soporte de zona horaria ofrecido en Date::Manip, tiene que usar la interfaz orientada a objetos.

En su mayor parte, los scripts escritos para versiones anteriores de Date::Manip continuarán funcionando (y los scripts escritos para la interfaz funcional versión 6 se ejecutarán con la interfaz versión 5), sin embargo en algunos casos, puede necesitar modificar sus scripts. Por favor consulte el documento Date::Manip::Migration5to6 para una lista de cambios que pueden ser necesarios.

INTERFAZ ORIENTADA A OBJETOS

A partir de la 6.00, Date::Manip consiste en un conjunto de módulos OO. Cada uno tiene su propio documento (vea la sección "VER TAMBIÉN" en Date::Manip).

La interfaz OO consiste en los siguientes módulos: Date::Manip::Date, Date::Manip::Delta, Date::Manip::Recur, Date::Manip::TZ, y Date::Manip::Base.

La interfaz orientada a objetos es la única forma de obtener la funcionalidad completa de Date::Manip. Soporta completamente las zonas horarias (y el horario de verano).

SELECCIÓN DE UNA INTERFAZ

Si está ejecutando una versión antigua de perl, la interfaz funcional versión 5 es la única disponible para usted, y se usará automáticamente.

Si está ejecutando una versión más reciente de perl (5.10 o superior), puede usar los módulos orientados a objetos cargándolos directamente, o puede usar una interfaz funcional.

Si usa una interfaz funcional, usará por defecto la interfaz versión 6, pero puede optar por ejecutar la interfaz versión 5 de una de tres maneras:

Usando la interfaz OO
Incluyendo cualquiera de lo siguiente: 
use Date::Manip::Date;
use Date::Manip::Delta;
use Date::Manip::Recur;
use Date::Manip::TZ;
use Date::Manip::Base;

tiene acceso a la interfaz OO para los tipos apropiados de objetos.

Usar la interfaz funcional por defecto
Incluyendo: 
use Date::Manip;

en su script, se cargará una de las interfaces funcionales. Si está ejecutando una versión de perl anterior a 5.10, será automáticamente la interfaz versión 5. Si está ejecutando una versión más reciente de perl, cargará automáticamente la interfaz versión 6.

Variable de entorno DATE_MANIP
Al establecer la variable de entorno DATE_MANIP en 'DM5' antes de ejecutar el script perl, se usará la interfaz versión 5.
Variable Date::Manip::Backend
Alternativamente, puede establecer la variable Date::Manip::Backend en 'DM5' antes de cargar el módulo. Típicamente, esto se hará se realiza de la siguiente manera: 
BEGIN {
     $Date::Manip::Backend = 'DM5';
}
use Date::Manip;

Una vez que se carga una interfaz funcional, no se puede cambiar entre las interfaces de la versión 5 y la versión 6.
