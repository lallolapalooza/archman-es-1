DAVIX-HTTP(1) Herramienta de peticiones HTTP DAVIX-HTTP(1)

NOMBRE

davix-http - Herramienta de consulta HTTP basada en libdavix

SINOPSIS

davix-http [opciones]... url

DESCRIPCIÓN

davix-http es una herramienta que utiliza libdavix para la ejecución de consultas HTTP.


Se puede utilizar para interactuar con servicios web RESTful.

Consulte libdavix(3) para más detalles.

OPCIONES

Opciones de petición:

--data
Contenido de la petición
--request, -X
Método de petición a usar (ej: GET, PUT, PROPFIND, etc..)

Opciones comunes:

--debug
Modo de depuración
--header, -H
Añadir un campo de cabecera a la petición (ej: -H "Depth: 1" )
--help, -h
Mostrar este mensaje de ayuda
--metalink OPT
Soporte de Metalink. (OPT=failover[por defecto]|no)
--module, -P PLUGIN_NAME
Cargar un plugin o perfil por nombre
--redirection OPT
Soporte de redirección transparente. (OPT=yes[por defecto]|no)
--proxy, -x URL
Servidor proxy SOCKS5 URL. (ej: socks5://login:pass@socks.example.org)
--trace
Rastrea ámbitos específicos, las opciones incluyen:
file - Interfaz de archivos de Davix
posix - Interfaz POSIX de Davix
xml - Salida del analizador XML
ssl - Detalles de SSL y certificados
header - Cabeceras de las consultas HTTP
body - Cuerpos de las consultas HTTP
chain - Información de cadenas de E/S
core - Información de configuración y miscelánea
grid - Información miscelánea de terceros
socket - Información del socket
locks - Información de bloqueo de WebDAV
all - Rastrea todo
--version
Mostrar versión

Opciones de seguridad:

--capath CA_path
Añadir un directorio adicional de autoridades certificadoras
--cert, -E cred_path
Certificado de cliente en formato PEM
--key priv_path
Clave privada en formato PEM
--insecure, -k
Deshabilitar las comprobaciones de credenciales SSL
--userlogin
Nombre de usuario para autenticación de usuario/contraseña
--userpass
Contraseña de usuario para autenticación de usuario/contraseña
--s3secretkey
Autenticación AWS S3: clave secreta
--s3accesskey
Autenticación AWS S3: clave de acceso
--s3region
Autenticación AWS S3: región
--s3token
Token de seguridad de AWS S3 - usado junto con credenciales temporales de STS
--s3alternate
Especifique esta bandera si necesita usar una URL de S3 basada en ruta
--azurekey
Clave de autenticación de Azure

EJEMPLOS

Ejecutar una consulta GET en HTTP
davix-http http://example.org/

Ejecutar una consulta HEAD en HTTP + TLS con autenticación de usuario
davix-http -X HEAD https://login:password@example.org

Ejecutar una consulta PUT con S3 sobre https y un contenido básico
davix-http -X PUT s3s://bucket.example.org/mifile -d "Hola Mundo"
