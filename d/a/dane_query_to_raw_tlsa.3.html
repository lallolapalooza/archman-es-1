NOMBRE

dane_query_to_raw_tlsa - función de API

SINOPSIS

#include <gnutls/dane.h>

int dane_query_to_raw_tlsa(dane_query_t q, unsigned int * data_entries, char *** dane_data, int ** dane_data_len, int * secure, int * bogus);

ARGUMENTOS

dane_query_t q
La estructura de resultado de la consulta
unsigned int * data_entries
Puntero establecido al número de entradas en la consulta
char *** dane_data
Puntero para contener una matriz de elementos rdata de DNS, terminada con un puntero NULL; el llamador debe garantizar que los datos referenciados permanezcan válidos hasta que se llame a dane_query_deinit().
int ** dane_data_len
Puntero para contener la longitud n de bytes de los elementos dane_data
int * secure
Puntero establecido a verdadero si el resultado se valida de forma segura, falso si la validación falla o el dominio consultado no tiene información de seguridad
int * bogus
Puntero establecido a verdadero si el resultado no fue seguro debido a un fallo de seguridad

DESCRIPCIÓN

Esta función proporcionará los datos DANE de la respuesta de la consulta.

Los punteros dane_data y dane_data_len se asignan con gnutls_malloc() para contener los datos de la estructura de resultado de la consulta (los elementos individuales de dane_data simplemente apuntan a los datos originales y no se asignan por separado). Los dane_data devueltos solo son válidos durante la vida útil de q.

DEVUELVE

En caso de éxito, se devuelve DANE_E_SUCCESS (0), de lo contrario, un valor de error negativo.
