NOMBRE

Date::Manip::Lang::polish - Soporte para el idioma polaco.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que soportan el idioma. No está destinado a ser utilizado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DEL IDIOMA

La siguiente es una lista de todas las palabras y expresiones del idioma utilizadas para escribir horas y/o fechas.

Todas las cadenas no distinguen entre mayúsculas y minúsculas.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar un tiempo a continuación. En inglés, usarías la palabra AT en el

ejemplo: 
December 3 at

Palabras que establecen la fecha, la hora, o
ambas
Hay algunas palabras que se pueden usar para especificar una fecha, una hora, o ambas en relación con el momento actual.

Las palabras que establecen la fecha son similares a las palabras en inglés 'yesterday' (ayer) o 'tomorrow' (mañana). Estas se especifican como un delta que se añade a la hora actual para obtener una fecha. La hora NO se establece, por lo tanto, el delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana

y día).

Se pueden usar las siguientes

palabras: 
dzisaj               0:0:0:0:0:0:0
jutro                +0:0:0:1:0:0:0
wczoraj              -0:0:0:1:
0:0:0

Las palabras que establecen solo la hora del día son similares a las palabras en inglés 'noon' (mediodía) o 'midnight'

(medianoche).

Se pueden usar las siguientes

palabras: 
polnoc               00:00:00
poludnie             12:00:00
południe             12:00:00
północ               00:
00:00

También están disponibles palabras que establecen la hora y la fecha completas (en relación con la hora y fecha

actuales).

En inglés, la palabra 'now' (ahora) es una de

estas.

Se pueden usar las siguientes

palabras: 
teraz                0:0:0:0:
0:
0:0
Separadores de Hora/Minuto/Segu
ndo
Al especificar la hora del día, el separador más común es los dos puntos (:) que se puede usar para ambos separadores.

Algunos idiomas usan pares diferentes. Por ejemplo, el francés permite especificar la hora como 13h30:20, por lo que usaría los siguientes

pares: 
: :
h :

La primera columna es el separador hora-minuto y la segunda columna es el separador minuto-segundo. Ambas son expresiones regulares de perl. Al crear una nueva traducción, ten en cuenta que las expresiones regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no incluyas la expresión '[x]' donde 'x' es un carácter

utf-8.

SIEMPRE se permite un par de dos puntos para todos los idiomas. Si un idioma permite pares adicionales, se

listan aquí:

do en es
te idioma
