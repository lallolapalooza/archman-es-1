Data::Perl::Number(3) Documentación de Perl Contribuida por el Usuario Data::Perl::Number(3)

NOMBRE

Data::Perl::Number - Clase envoltorio para números escalares de Perl.

VERSIÓN

versión 0.002011

SINOPSIS

use Data::Perl qw/number/;
my $num = number(123);
$num->add(5); # $num == 128
$num->div(2); # $num == 64

DESCRIPCIÓN

Esta clase es un simple consumidor del rol Data::Perl::Role::Number, que proporciona toda la funcionalidad. Probablemente quieras mirar allí en su lugar.
