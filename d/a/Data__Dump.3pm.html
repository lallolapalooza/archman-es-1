Data::Dump(3) Documentación de Perl aportada por el usuario Data::Dump(3)

NOMBRE

Data::Dump - Impresión con formato de estructuras de datos

SINOPSIS

use Data::Dump qw(dump);
$str = dump(@list);
@copy_of_list = eval $str;
# o úsalo para una impresión de depuración fácil
use Data::Dump; dd localtime;

DESCRIPCIÓN

Este módulo proporciona algunas funciones que recorren su lista de argumentos y devuelven una cadena que contiene código Perl que, cuando se "eval"ua, produce una copia profunda de los argumentos originales.

La característica principal del módulo es que se esfuerza por producir una salida fácil de leer. Ejemplo:

@a = (1, [2, 3], {4 => 5});
dump(@a);

Produce:

"(1, [2, 3], { 4 => 5 })"

Si vuelcas solo un poco de datos, se emiten en una sola línea. Si vuelcas datos más complejos o si hay muchos, se añaden saltos de línea automáticamente para mantenerlo fácil de leer.

Se proporcionan las siguientes funciones (solo las funciones dd* son exportadas por defecto):

dump( ... )
pp( ... )
Devuelve una cadena que contiene una expresión Perl. Si pasas esta cadena a la función incorporada de Perl eval() , debería devolver una copia de los argumentos que pasaste a dump().

Si llamas a la función con múltiples argumentos, la salida se envolverá en paréntesis "( ..., ... )". Si llamas a la función con un solo argumento, la salida no tendrá el envoltorio. Si llamas a la función con un solo argumento escalar (no referencia), simplemente devolverá el escalar entrecomillado si es necesario, pero nunca lo dividirá en múltiples líneas. Si pasas múltiples argumentos o referencias a arrays de hashes, el valor de retorno podría contener saltos de línea para formatearlo para una lectura más fácil. La cadena devuelva nunca estará terminada por "\n", incluso si contiene múltiples líneas. Esto permite que código como este coloque el punto y coma en el lugar esperado:

print '$obj = ', dump($obj), ";\n";

Si dump() se llama en contexto nulo, entonces el volcado se imprime en STDERR y luego se termina con "\n". Podrías encontrar esto útil para impresiones de depuración rápidas, pero las funciones dd*() podrían ser mejores alternativas para esto.

No hay diferencia entre dump() y pp(), excepto que dump() comparte su nombre con un builtin de perl no muy útil. Debido a esto, algunos podrían querer evitar usar ese nombre.

quote( $string )
Devuelve una versión entrecomillada de la cadena proporcionada.

Difiere de dump($string) en que entrecomillará incluso números y no intentará idear expresiones ingeniosas que podrían acortar la salida. Si se proporciona un argumento no escalar, simplemente se convierte en cadena en lugar de ser recorrido.

dd( ... )
ddx( ... )
Estas funciones llamarán a dump() con su argumento e imprimirán el resultado en STDOUT (en realidad, es el manejador de salida actualmente seleccionado, pero STDOUT es el valor predeterminado para eso).

La diferencia entre ellas es solo que ddx() prefijará las líneas que imprime con "# " y marcará la primera línea con el archivo y el número de línea donde fue llamada. Esto está pensado para ser útil para impresiones de depuración del estado dentro de los programas.

dumpf( ..., \&filter )
Abreviatura para llamar a la función dump_filtered() de Data::Dump::Filtered. Esto funciona como dump(), pero el último argumento debería ser una función de retorno de llamada de filtro. A medida que se visitan los objetos, se invoca la función de retorno de llamada del filtro y puede modificar cómo se vuelcan los objetos.

CONFIGURACIÓN

Hay algunas variables globales que se pueden establecer para modificar la salida generada por las funciones de volcado. Es recomendable localizar la configuración de estas.

$Data::Dump::INDENT
Contiene la cadena que se usa para indentar estructuras de datos de múltiples líneas. Su valor predeterminado es " " (dos espacios). Establécelo a "" para suprimir la indentación. Establecerlo a "| " hace una buena visualización incluso si la salida del volcado deja de ser Perl válido.
$Data::Dump::TRY_BASE64
¿Cuán larga debe ser una cadena binaria antes de intentar usar la codificación base64 para la salida del volcado? El valor predeterminado es 50. Establécelo a 0 para deshabilitar los volcados base64.
$Data::Dump::LINEWIDTH
Esto controla cuán ancha debe ser la cadena antes de añadir un salto de línea. El valor predeterminado es 60.

LIMITACIONES

Las referencias a código se volcarán como "sub { ... }". Por lo tanto, "eval"uarlas no reproducirá la rutina original. El operador "..."utilizado también requerirá perl-5.12 o superior para ser evaluado.

Si olvidas importar explícitamente la función "dump" , tu código hará un volcado de núcleo. Eso es porque simplemente llamaste por accidente a la función incorporada "dump" , la cual intencionalmente hace un volcado de núcleo. Debido a esto, también puedes importar la misma función como "pp", mnemotécnico para "impresión con formato".

HISTORIA

El módulo "Data::Dump" surgió de la frustración con el en la mayoría de los casos excelente "Data::Dumper"de Sarathy. Algunas ideas básicas y algo de código se comparten con el módulo de Sarathy.

El módulo "Data::Dump" proporciona una interfaz mucho más simple que "Data::Dumper". No hay interfaz OO disponible y hay menos opciones de configuración de las que preocuparse. El otro beneficio es que el volcado producido no intenta establecer ninguna variable. Solo devuelve lo que es necesario para producir una copia de los argumentos. Esto significa que dump("foo") simplemente devuelve '"foo"', y dump(1..3) simplemente devuelve '(1, 2, 3)'.
