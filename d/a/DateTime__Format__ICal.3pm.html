DESCRIPCIÓ

N

Este módulo entiende los formatos de fecha/hora y duración de ICal, tal como se definen en la RFC 2445. Puede usarse para analizar estos formatos con el fin de crear los objetos correspondiente

s
.

MÉTODO

S

Esta clase ofrece los siguientes

métodos.
  • parse_datetime($string)

    Dada una cadena de fecha/hora de iCal, este método devolverá un nuevo objeto "Date

    Time".

    Si se le da una cadena con

    formato incorrecto, este
    • método puede morir.
  • parse_duration($string)

    Dada una cadena de duración de iCal, este método devolverá un nuevo objeto "DateTime::

    Duration".

    Si se le da una cadena con

    formato incorrecto, este
    • método puede morir.
  • parse_period($string)

    Dada una cadena de periodo de iCal, este método devolverá un nuevo objeto "DateTime::

    Span".

    Si se le da una cadena con

    formato incorrecto, este
    • método puede morir.
  • parse_recurrence( recurrence => $string, ... )

    Dada una descripción de recurrencia de iCal, este método usa "DateTime::Event::ICal" para crear un objeto "DateTime::Set" que representa esa recurrencia. Cualquier parámetro dado a este método además de "recurrence" se pasará directamente al método "DateTime::Event::ICal->

    recur".

    Si se le da una cadena con formato incorrecto, este método puede

    morir.

    Este método acepta los parámetros opcionales "dtstart" y "dtend". Estos parámetros deben ser objetos "Date

    Time".

    La especificación de iCal requiere que "dtstart" siempre se incluya en el conjunto de recurrencia, a menos que sea una declaración "exrule". Dado que no sabemos qué tipo de declaración se está analizando, no incluimos "dtstart" en el

    conjunto de
    • recurrencia.
  • format_datetime($datetime)

    Dado un objeto "DateTime", este método devuelve una cadena de fecha/hora de

    iCal.

    La especificación de iCal requiere que las fechas y horas se formateen como horas flotantes (sin zona horaria), UTC (con un sufijo 'Z') o con un identificador de zona horaria al principio ('TZID=America/Chicago;...'). Si se le pide a este método que formatee un objeto "DateTime" que tiene una zona horaria solo con desplazamiento, el objeto se convertirá internamente a la zona horaria UTC antes de

    formatearse.

    Por ejemplo, este

    código: 
    my $dt = DateTime->new( year => 1900, hour => 15, time_zone => '-0100' );
print $ical->format_datetime($dt)
    ;

    imprimirá la cadena

    "19000101T160000Z
    • ".
  • format_duration($duration)

    Dado un objeto "DateTime::Duration", este método devuelve una cadena de duración de

    iCal.

    El estándar de iCal no permite meses o años en una duración, así que si se da una duración para la cual delta_months() no es ce

    ro, este mé
    • todo morirá.
  • format_period($span)

    Dado un objeto "DateTime::Span", este método devuelve una cadena de periodo de iCal, usando el formato "DateTime/

    DateT
    • ime".
  • format_period_with_duration($span)

    Dado un objeto "DateTime::Span", este método devuelve una cadena de periodo de iCal, usando el formato "DateTime/

    Durat
    • ion".
  • format_recurrence($arg [,$arg...] )

    Este método devuelve una lista de cadenas que contienen declaraciones de ICal. En contexto escalar devuelve una sola cadena que puede contener saltos de línea

    incrustados.

    El argumento puede ser una lista de "DateTime", una lista de "DateTime::Span", un "DateTime::Set", o un "DateTime::Sp

    anSet".

    Los valores "DATE" de ICal no están soportados. Siempre que se encuentra un valor de fecha, se genera un "DATE-TIME

    ".

    Si una recurrencia tiene un "DTSTART" o "DTEND" asociado, esos valores deben formatearse usando format_datetime(). El método format_recurrence() no hará esto por

    usted.

    Si se está formateando un "union" o "complement" de recurrencias, se asume que tienen el mismo valor de "DTSTART

    ".

    Solo se soportan las operaciones "union" y "complement" para recurrencias. Esta es una limitación de la especificación de

    ICal.

    Si se le da un conjunto que no puede formatear, este método puede

    morir.

    Solo los objetos "DateTime::Set::ICal" son formateables. Un conjunto puede cambiar de clase después de algunas operaciones de

    conjunto: 
    $recurrence = $recurrence->union( $dt_set );
# Ok - $recurrence sigue siendo un DT::Set::ICal
$recurrence = $dt_set->union( $recurrence );
# ¡No Ok! - $recurrence es ahora un DT:
    :Set

    Las únicas recurrencias ilimitadas soportadas actualmente son las generadas por el módulo "DateTime::Event::

    ICal".

    Puede añadir soporte de formateo ICal a una recurrencia personalizada usando el módulo "DateTime::Set::

    ICal": 
    $custom_recurrence =
    DateTime::Set::ICal->from_recurrence
        ( recurrence =>
          sub { $_[0]->truncate( to => 'month' )->add( months => 1 ) }
        );
$custom_recurrence->set_ical( include => [ 'FREQ=MONTHLY'
    ]
)
;
