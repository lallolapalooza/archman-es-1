NOMBRE

dane_verify_crt - Función de la API

SINOPSIS

#include <gnutls/dane.h>

int dane_verify_crt(dane_state_t s, const gnutls_datum_t * chain, unsigned chain_size, gnutls_certificate_type_t chain_type, const char * hostname, const char * proto, unsigned int port, unsigned int sflags, unsigned int vflags, unsigned int * verify);

ARGUMENTOS

dane_state_t s
Una estructura de estado DANE (puede ser NULL)
const gnutls_datum_t * chain
Una cadena de certificados
unsigned chain_size
El tamaño de la cadena
gnutls_certificate_type_t chain_type
El tipo de la cadena de certificados
const char * hostname
El nombre de host asociado a la cadena
const char * proto
El protocolo del servicio que se conecta (ej. tcp)
unsigned int port
El puerto del servicio que se conecta (ej. 443)
unsigned int sflags
Banderas para la inicialización de s (si es NULL)
unsigned int vflags
Banderas de verificación; una lista OR'ed de dane_verify_flags_t.
unsigned int * verify
Una lista OR'ed de dane_verify_status_t.

DESCRIPCIÓN

Esta función verificará la cadena de certificados dada contra las restricciones de CA y/o el certificado disponible a través de DANE. Si no se puede obtener información a través de DANE, se establece la bandera DANE_VERIFY_NO_DANE_INFO. Si no hay una firma DNSSEC disponible para el registro DANE, se establece la bandera de verificación DANE_VERIFY_NO_DNSSEC_DATA.

Debido a las muchas opciones posibles de DANE, no hay un único modelo de amenaza contrarrestado. Al notificar al usuario sobre los resultados de la verificación DANE, puede ser mejor mencionar: La verificación DANE no rechazó el certificado, en lugar de mencionar una verificación DANE exitosa.

Tenga en cuenta que esta función está diseñada para ejecutarse además de la verificación de la cadena de certificados PKIX. Para ejecutarse de forma independiente, se debe especificar la bandera DANE_VFLAG_ONLY_CHECK_EE_USAGE; entonces la función comprobará si la clave del par coincide con la clave anunciada en la entrada DANE.

RETORNA

un código de error negativo en caso de error y DANE_E_SUCCESS (0) cuando las entradas DANE se analizaron correctamente, independientemente de si se verificaron (ver verify para esa información). Si no se encontraron entradas utilizables, se devolverá DANE_E_REQUESTED_DATA_NOT_AVAILABLE.
