DESCRIPCIÓ

N

Date::Manip es una serie de módulos diseñados para facilitar cualquier operación común de fecha/hora. Operaciones como comparar dos tiempos, determinar una fecha a una cantidad de tiempo dada de otra, o analizar tiempos internacionales se realizan fácilmente. Trata el tiempo tal como se usa en el calendario gregoriano (el que está actualmente en uso) con soporte completo para cambios de tiempo debido al horario de

verano.

Desde el principio, el enfoque principal de Date::Manip ha sido poder realizar CUALQUIER operación de fecha/hora deseada fácilmente. Existen muchos otros módulos que pueden realizar un subconjunto de estas operaciones más rápido o de manera más eficiente, pero ningún otro módulo puede realizar todas las operaciones disponibles en Date::

Manip.

Date::Manip tiene funcionalidad para trabajar con varios tipos fundamentales de

datos.
fech
as
La palabra fecha se usa extensamente aquí y es algo engañosa. En Date::Manip, una fecha consta de tres piezas de información: una fecha de calendario (año, mes, día), una hora del día (hora, minuto, segundo) y información de zona horaria. Las fechas de calendario y las horas se manejan completamente. Las zonas horarias también se manejan, pero dependiendo de cómo uses Date::Manip, puede haber algunas limitaciones como se discute a
continuación.
del
ta
Un delta es una cantidad de tiempo (es decir, la cantidad de tiempo entre dos fechas diferentes). Piénsalo como la duración de un evento o la cantidad de tiempo entre dos fechas.

Un delta se refiere solo a una cantidad de tiempo. No incluye información sobre una fecha/hora de in

icio o finalización. La mayoría de las personas pensarán en un delta como una cantidad de tiempo, per
o el término 'tiempo' ya se usa tanto en este módulo que no quise usarlo aquí para evitar confusión.
recurren
cia
Un evento recurrente es algo que ocurre de manera regular y
recurrente.
festivos y event
os
Los festivos y eventos s
on básicamente fechas o
recurrencias con nombre.

Entre otras cosas, Date::Manip te

permite:
*
Introducir una fecha en prácticamente cualquier formato que
elijas.
*
Comparar dos fechas, introducidas en formatos muy diferentes, para determinar cuál es
anterior.
*
Extraer cualquier información que desees de una fecha usando una cadena de formato similar al comando date de
Unix.
*
Determinar la cantidad de tiempo entre dos fechas, o añadir una cantidad de tiempo (un delta) a una fecha para obtener una segunda
fecha.
*
Trabajar con fechas usando formatos internacionales (nombres de meses extranjeros, 12/10/95 refiriéndose a octubre en lugar de diciembre, etc.
).
*
Convertir fechas de una zona horaria a
otra.
*
Encontrar una lista d
e fechas donde ocurre
un evento recurrente.

Cada una de estas tareas es

trivial (una o dos líneas co
mo máximo) con este paquete.

Hay tres formas diferentes de usar Date::Manip. Hay tres interfaces (interfaz funcional de versión 5, funcional de versión

6 y orientada a objetos de versión 6). Una descripción completa de cada una se incluye en el documento Date::Manip::Inte
rfaces. La recomendada (y la única con acceso a toda la funcionalidad del módulo) es usar la interfaz Orientada a Objetos.
