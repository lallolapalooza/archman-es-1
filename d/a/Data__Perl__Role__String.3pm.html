Data::Perl::Role::String(3) Documentación de Perl aportada por el usuario Data::Perl::Role::String(3)

NOMBRE

Data::Perl::Role::String - Clase contenedora para cadenas escalares de Perl.

VERSIÓN

version 0.002011

SINOPSIS

use Data::Perl qw/string/;
my $string = string("foo\n");
$string->chomp; # devuelve 1, $string == "foo"

DESCRIPCIÓN

Esta clase proporciona un contenedor y métodos para interactuar con cadenas escalares.

MÉTODOS PROPORCIONADOS

  • new($value)

    Construye un nuevo objeto Data::Perl::String, opcionalmente inicializado a $value si se pasa, y lo devuelve.

  • inc

    Incrementa el valor almacenado en esta ranura usando el operador mágico de autoincremento de cadenas. Nota: Perl no proporciona un comportamiento análogo en "--", por lo que "dec" no está disponible. Este método devuelve el nuevo valor.

    Este método no acepta argumentos.

  • append($string)

    Añade al final la cadena, como ".=", y devuelve el nuevo valor.

    Este método requiere un único argumento.

  • prepend($string)

    Añade al principio la cadena y devuelve el nuevo valor.

    Este método requiere un único argumento.

  • replace($pattern, $replacement)

    Realiza una sustitución de expresiones regulares ("s" en perlop). No hay forma de proporcionar el flag "g", pero se aceptarán referencias de código para el reemplazo, lo que hará que la expresión regular se modifique con una única "e". Se pueden aplicar "/smxi" usando el operador "qr". Este método devuelve el nuevo valor.

    Este método requiere dos argumentos.

  • match($pattern)

    Ejecuta la expresión regular contra la cadena y devuelve el/los valor/es coincidente/s.

    Este método requiere un único argumento.

  • chop

    Igual que "chop" en perlfunc. Este método devuelve el carácter cortado.

    Este método no acepta argumentos.

  • chomp

    Igual que "chomp" en perlfunc. Este método devuelve el número de caracteres eliminados.

    Este método no acepta argumentos.

  • clear

    Establece la cadena a la cadena vacía (no al valor pasado a "default").

    Este método no tiene un valor de retorno definido.

    Este método no acepta argumentos.

  • length

    Igual que "length" en perlfunc, devuelve la longitud de la cadena.

  • substr

    Actúa igual que "substr" en perlfunc. Cuando se llama como escritor, devuelve la subcadena que fue reemplazada, igual que la función incorporada de Perl.

    Este método requiere al menos un argumento y acepta no más de tres.
