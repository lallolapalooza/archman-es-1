NOMBRE

Data::Uniqid - Extensión de Perl para generar fácilmente identificadores únicos

SINOPSIS

use Data::Uniqid qw ( suniqid uniqid luniqid );

$id = suniqid;
$id = uniqid;
$id = luniqid;

DESCRIPCIÓN

Data::Uniqid proporciona tres rutinas sencillas para generar identificadores únicos. Estos identificadores están codificados con un sistema Base62 para hacerlos cortos y manejables (por ejemplo, para usarlos como parte de una URL).

suinqid
  genera un identificador muy corto válido solo para localhost y con una 
  vida útil de 1 día

uniqid
  genera un identificador corto válido en el host local 
luniqid 
  genera un identificador largo válido en cualquier lugar y para siempre
