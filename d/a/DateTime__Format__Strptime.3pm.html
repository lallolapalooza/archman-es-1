NAME

DateTime::Format::Strptime - Parsear y formatear patrones de tiempo strp y strf

VERSION

versión 1.79

SYNOPSIS

use DateTime::Format::Strptime;
my $strp = DateTime::Format::Strptime->new(
    pattern   => '%T',
    locale    => 'en_AU',
    time_zone => 'Australia/Melbourne',
);
my $dt = $strp->parse_datetime('23:16:42');
$strp->format_datetime($dt);
# 23:16:42
# Arrojar error cuando las cosas van mal:
my $strp = DateTime::Format::Strptime->new(
    pattern   => '%T',
    locale    => 'en_AU',
    time_zone => 'Australia/Melbourne',
    on_error  => 'croak',
);
# Hacer algo más cuando las cosas van mal:
my $strp = DateTime::Format::Strptime->new(
    pattern   => '%T',
    locale    => 'en_AU',
    time_zone => 'Australia/Melbourne',
    on_error  => \&phone_police,
);

DESCRIPTION

Este módulo implementa la mayoría de strptime(3), la función POSIX que es el inverso de strftime(3), para "DateTime". Mientras que "strftime" toma un "DateTime" y un patrón y devuelve una cadena, "strptime" toma una cadena y un patrón y devuelve el objeto "DateTime" asociado.

METHODS

Esta clase ofrece los siguientes métodos.

DateTime::Format::Strptime->new(%args)

Este método crea un nuevo objeto. Acepta los siguientes argumentos:

  • pattern

    Este es el patrón a usar para el análisis. Esto es obligatorio.

  • strict

    Esto es un booleano que deshabilita o habilita el modo de coincidencia estricta.

    Por defecto, este módulo convierte su patrón en un regex que coincidirá en cualquier parte de una cadena. Dado el patrón "%Y%m%d%H%M%S" coincidirá con una cadena como 20161214233712. Sin embargo, esto también significa que este patrón coincidirá con cualquier cadena que contenga 14 o más números! Este comportamiento puede ser muy sorprendente.

    Si habilita el modo estricto, entonces el regex generado se envuelve en comprobaciones de límites de la forma "/(?:\A|\b)...(?:\b|\z_/)". Estas comprobaciones aseguran que el patrón solo coincidirá cuando esté al principio o al final de una cadena, o cuando esté separado por otro texto con un límite de palabra ("\w" versus "\W").

    Por defecto, el modo estricto está apagado. Esto se hace para la compatibilidad hacia atrás. Las futuras versiones pueden activarlo por defecto, ya que produce un comportamiento menos sorprendente en muchos casos.

    Dado que el defecto puede cambiar en el futuro, se le anima fuertemente a establecer esto explícitamente al construir todos"DateTime::Format::Strptime" los objetos.

  • time_zone

    La zona horaria predeterminada a usar para los objetos devueltos desde el análisis.

  • zone_map

    Algunas abreviaturas de zona horaria son ambiguas (por ejemplo, PST, EST, EDT). Por defecto, el analizador morirá cuando analice una abreviatura ambigua. Puede especificar un "zone_map" parámetro como una hashref para mapear abreviaturas de zona como desee:

    zone_map => { PST => '-0800', EST => '-0600' }

    Nota que también puede sobrescribir mapeos no ambiguos si así lo desea.

  • locale

    El idioma a usar para los objetos devueltos desde el análisis.

  • on_error

    Esto puede ser uno de 'undef' (la cadena, no un "undef"), 'croak', o una referencia a subrutina.

  • 'undef'

    Este es el comportamiento predeterminado. El módulo devolverá "undef" en errores. El error se puede acceder usando el "$object->errmsg" método. Esto es el comportamiento ideal para uso interactivo donde un usuario podría proporcionar un patrón ilegal o una fecha que no coincide con el patrón.

  • 'croak'

    El módulo arrojará un mensaje de error en errores.

  • sub{...} o \&subname

    Al recibir una referencia de código, el módulo llamará a ese sub en errores. El sub recibe dos parámetros: el objeto y el mensaje de error.

    Si su sub no muere, entonces el formateador continuará como si "on_error" fuera 'undef'.

$strptime->parse_datetime($string)

Dada una cadena en el patrón especificado en el constructor, este método devolverá un nuevo objeto "DateTime".

Si se le da una cadena que no coincide con el patrón, el formateador arrojará o devolverá undef, dependiendo de la configuración de "on_error" en el constructor.

$strptime->format_datetime($datetime)

Dado un objeto "DateTime", este método devuelve una cadena formateada en el formato del objeto. Este método es sinónimo del método strftime de "DateTime".

$strptime->locale

Este método devuelve el idioma pasado al constructor del objeto.

$strptime->pattern

Este método devuelve el patrón pasado al constructor del objeto.

$strptime->time_zone

Este método devuelve la zona horaria pasada al constructor del objeto.

$strptime->errmsg

Si el comportamiento on_error del objeto es 'undef', puede obtener mensajes de error con este método para que pueda averiguar por qué las cosas fallaron.

EXPORTS

Estos subs están disponibles como exportaciones opcionales.

strptime( $strptime_pattern, $string )

Dado un patrón y una cadena, esta función devolverá un nuevo objeto "DateTime".

strftime( $strftime_pattern, $datetime )

Dado un patrón y un objeto "DateTime" esta función devolverá una cadena formateada.

STRPTIME PATTERN TOKENS

Los siguientes tokens están permitidos en la cadena de patrón para strptime (parse_datetime):

  • %%

    El carácter %.

  • %a o %A

    El nombre del día de la semana según el idioma dado, en forma abreviada o el nombre completo.

  • %b o %B o %h

    El nombre del mes según el idioma dado, en forma abreviada o el nombre completo.

  • %c

    El formato de fecha y hora según el idioma dado

n locale.

Tenga en cuenta que este formato puede cambiar sin previo aviso en nuevas versiones de DateTime::Locale. No debe usar este patrón a menos que la cadena que está analizando haya sido generada usando este patrón con DateTime y esté seguro de que esta cadena fue generada con la misma versión de DateTime::Locale que la que usa el analizador.

  • %C

    El número de siglo (0-99).

  • %d o %e

    El día del mes (01-31). Esto también analizará números de un solo dígito.

  • %D

    Equivalente a %m/%d/%y. (Esta es la fecha al estilo estadounidense, muy confusa para los no estadounidenses, especialmente dado que %d/%m/%y se usa ampliamente en Europa. El patrón estándar ISO 8601 es %F.)

  • %F

    Equivalente a %Y-%m-%d. (Esta es la fecha al estilo ISO)

  • %g

    El año correspondiente al número de semana ISO, pero sin el siglo (0-99).

  • %G

    El año de 4 dígitos correspondiente al número de semana ISO.

  • %H

    La hora (00-23). Esto también analizará números de un solo dígito.

  • %I

    La hora en un reloj de 12 horas (1-12).

  • %j

    El número de día en el año (1-366).

  • %m

    El número de mes (01-12). Esto también analizará números de un solo dígito.

  • %M

    El minuto (00-59). Esto también analizará números de un solo dígito.

  • %n

    Espacios en blanco arbitrarios.

  • %N

    Nanosegundos. Para otros valores de subsegundo use "%[number]N".

  • %p o %P

    El equivalente a AM o PM según el locale en uso. Vea DateTime::Locale.

  • %r

    Equivalente a %I:%M:%S %p.

  • %R

    Equivalente a %H:%M.

  • %s

    Número de segundos desde la Época.

  • %S

    El segundo (0-60; 60 puede ocurrir por segundos bisiestos. Vea DateTime::LeapSecond).

  • %t

    Espacios en blanco arbitrarios.

  • %T

    Equivalente a %H:%M:%S.

  • %U

    El número de semana con domingo como primer día de la semana (0-53). El primer domingo de enero es el primer día de la semana 1.

  • %u

    El número de día de la semana (1-7) con lunes = 1. Este es el "DateTime" estándar.

  • %w

    El número de día de la semana (0-6) con domingo = 0.

  • %W

    El número de semana con lunes como primer día de la semana (0-53). El primer lunes de enero es el primer día de la semana 1.

  • %x

    El formato de fecha según el locale dado.

    Tenga en cuenta que este formato puede cambiar sin previo aviso en nuevas versiones de DateTime::Locale. No debe usar este patrón a menos que la cadena que está analizando haya sido generada usando este patrón con DateTime y esté seguro de que esta cadena fue generada con la misma versión de DateTime::Locale que la que usa el analizador.

  • %X

    El formato de hora según el locale dado.

    Tenga en cuenta que este formato puede cambiar sin previo aviso en nuevas versiones de DateTime::Locale. No debe usar este patrón a menos que la cadena que está analizando haya sido generada usando este patrón con DateTime y esté seguro de que esta cadena fue generada con la misma versión de DateTime::Locale que la que usa el analizador.

  • %y

    El año dentro del siglo (0-99). Cuando no se especifica de otro modo un siglo (con un valor para %C), los valores en el rango 69-99 se refieren a años en el siglo veinte (1969-1999); los valores en el rango 00-68 se refieren a años en el siglo veintiuno (2000-2068).

  • %Y

    Un año de 4 dígitos, incluyendo el siglo (por ejemplo, 1991).

  • %z

    Una especificación de zona horaria estándar RFC-822/ISO 8601. (Por ejemplo +1100) [Vea la nota a continuación]

  • %Z

    El nombre de la zona horaria. (Por ejemplo EST -- lo cual es ambiguo) [Vea la nota a continuación]

  • %O

    Este token extendido permite que los nombres de zona horaria de Olson aparezcan en las cadenas analizadas. NOTA: Este patrón no puede pasarse al "DateTime"'s strftime() método, pero puede pasarse a format_datetime().
