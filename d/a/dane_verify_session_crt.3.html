NOMBRE

dane_verify_session_crt - función de API

SINOPSIS

#include <gnutls/dane.h>

int dane_verify_session_crt(dane_state_t s, gnutls_session_t session, const char * hostname, const char * proto, unsigned int port, unsigned int sflags, unsigned int vflags, unsigned int * verify);

ARGUMENTOS

dane_state_t s
Una estructura de estado DANE (puede ser NULL)
gnutls_session_t session
Una sesión gnutls
const char * hostname
El nombre de host asociado con la cadena
const char * proto
El protocolo del servicio que se conecta (p. ej., tcp)
unsigned int port
El puerto del servicio que se conecta (p. ej., 443)
unsigned int sflags
Marcas para la inicialización de s (si es NULL)
unsigned int vflags
Marcas de verificación; una lista OR'ed de dane_verify_flags_t.
unsigned int * verify
Una lista OR'ed de dane_verify_status_t.

DESCRIPCIÓN

Esta función verificará la cadena de certificados de la sesión contra las restricciones de CA y/o el certificado disponible a través de DANE. Ver dane_verify_crt() para más información.

Esto no verificará la validez de la cadena; a menos que la verificación DANE esté restringida a certificados finales, esto debe realizarse por separado usando gnutls_certificate_verify_peers3().

VALOR DEVUELTO

un código de error negativo en caso de error y DANE_E_SUCCESS (0) cuando las entradas DANE se analizaron correctamente, independientemente de si se verificaron (ver verify para esa información). Si no se encontraron entradas utilizables, se devolverá DANE_E_REQUESTED_DATA_NOT_AVAILABLE.
