Data::Structure::Util(3) Documentación de Perl aportada por el usuario Data::Structure::Util(3)

NOMBRE

Data::Structure::Util - Cambia la naturaleza de los datos dentro de una estructura

SINOPSIS

use Data::Structure::Util qw(
  has_utf8 utf8_off utf8_on unbless get_blessed get_refs
  has_circular_ref circular_off signature
);
# obtener los objetos en la estructura de datos
my $objects_arrayref = get_blessed( $data );
# quitar el blessing a todos los objetos
unbless( $data );
if ( has_circular_ref( $data ) ) {
    print "¡Eliminando referencia circular!\n";
    circular_off( $data );
}
# convertir de vuelta a latin1 si es necesario y posible
utf8_off( $data ) if defined has_utf8( $data );

DESCRIPCIÓN

"Data::Structure::Util" es una caja de herramientas para manipular los datos dentro de una estructura de datos. Puede procesar un árbol completo y realizar la operación solicitada en cada elemento apropiado.

Por ejemplo: Puede transformar todas las cadenas dentro de una estructura de datos a utf8 o transformar cualquier cadena utf8 de vuelta a la codificación predeterminada. Puede eliminar el blessing de cualquier referencia. Puede recopilar todos los objetos o detectar si existe una referencia circular.

Está escrito en C para una velocidad decente.

FUNCIONES

Todas las funciones de Data::Structure::Util operan sobre un árbol completo. Si les pasa un escalar simple, operarán sobre ese único escalar. Sin embargo, si les pasa una referencia a un hash, un array o un escalar, entonces iterarán a través de esa estructura y aplicarán la manipulación a todos los elementos, y a su vez, si son referencias a hashes, arrays o escalares, a todos sus elementos, y así sucesivamente, recursivamente.

Por razones de velocidad, todas las manipulaciones que alteran la estructura de datos realizan una manipulación in-situ (in-place), lo que significa que en lugar de devolver una copia alterada de la estructura de datos, devuelven la estructura de datos pasada que ha sido alterada.

Manipulación de Estructuras de Datos

has_circular_ref($ref)
Esta función detecta si la estructura de datos pasada tiene una referencia circular, es decir, si es posible, siguiendo las referencias contenidas en la estructura, volver a una parte de la estructura de datos que ya se ha visitado. Las estructuras de datos que tienen referencias circulares no serán reclamadas automáticamente por el recolector de basura de Perl.

Si se detecta una referencia circular, la función devuelve una referencia a un elemento dentro del circuito; de lo contrario, la función devolverá un valor falso.

Si la versión de perl que está utilizando soporta referencias débiles, entonces cualquier referencia débil que se encuentre dentro de la estructura de datos no será recorrida, lo que significa que las referencias circulares que han tenido sus enlaces debilitados con éxito no serán devueltas por esta función.

circular_off($ref)
Detecta referencias circulares en $ref (como arriba) y debilita un enlace en cada una para que puedan ser recolectadas adecuadamente por el recolector de basura cuando no queden referencias externas a la estructura de datos.

Esto significa que se le dirá a una (o más) de las referencias en la estructura de datos que no debe contar para el conteo de referencias. Debe ser consciente de que si modifica posteriormente la estructura de datos y deja partes de ella solo 'accesibles' a través de referencias debilitadas, esas partes de la estructura de datos serán inmediatamente recolectadas por el recolector de basura, ya que las referencias debilitadas no serán lo suficientemente fuertes para mantener la conexión por sí solas.

Se devuelve el número de referencias debilitadas.

get_refs($ref)
Examina la estructura de datos y devuelve una referencia a un array plano que contiene una copia de cada referencia en la estructura de datos que pasó.

Por ejemplo:

my $foo = {
    first  => [ "inner", "array", { inmost => "hash" } ],
    second => \"refed scalar",
};
use Data::Dumper;
# decirle a Data::Dumper que muestre los nodos varias veces
$Data::Dumper::Deepcopy = 1;
print Dumper get_refs( $foo );
$VAR1 = [
    { 'inmost' => 'hash' },
    [ 'inner', 'array', { 'inmost' => 'hash' } ],
    \'refed scalar',
    {
        'first'  => [ 'inner', { 'inmost' => 'hash' }, 'array' ],
        'second' => \'refed scalar'
    }
];

Como puede ver, la estructura de datos se recorre en profundidad primero, por lo que las referencias más superiores deberían ser los últimos elementos del array. Vea get_blessed($ref) más abajo para una función similar para objetos bendecidos (blessed).

signature($ref)
Devuelve un md5 de la estructura de datos pasada. Cualquier cambio en absoluto en la estructura de datos causará que se devuelva un md5 diferente.

La función examina la estructura, las direcciones, los tipos de valores y los flags para generar la firma, lo que significa que incluso estructuras de datos que se verían idénticas al ser volcadas con Data::Dumper producen firmas diferentes:

$ref1 = { key1 => [] };
$ref2 = $ref1;
$ref2->{key1} = [];
# esto produce el mismo resultado, ya que se ven igual
# aunque son estructuras de datos diferentes
use Data::Dumper;
use Digest::MD5 qw(md5_hex);
print md5_hex( Dumper( $ref1 ) ), " ", md5_hex( Dumper( $ref2 ) ), "\n";
# cb55d41da284a5869a0401bb65ab74c1 cb55d41da284a5869a0401bb65ab74c1
# esto produce resultados diferentes
use Data::Structure::Util qw(signature);
print signature( $ref1 ), " ", signature( $ref2 ), "\n";
# 5d20c5e81a53b2be90521167aefed9db 8b4cba2cbae0fec4bab263e9866d3911

Objetos y Blessing

unbless($ref)
Elimina el blessing de cualquier objeto que se encuentre dentro de la estructura de datos pasada. Por ejemplo: 
my $foo = {
    'a' => bless( { 'b' => bless( {}, "c" ), }, "d" ),
    'e' => [ bless( [], "f" ), bless( [], "g" ), ]
};
use Data::Dumper;
use Data::Structure::Util qw(unbless);
print Dumper( unbless( $foo ) );
$VAR1 = {
    'a' => { 'b' => {} },
    'e' => [ [], [] ]
};

Tenga en cuenta que la estructura busca dentro de los objetos bendecidos (blessed) otros objetos para quitarles el blessing.

get_blessed($ref)
Examina la estructura de datos y devuelve una referencia a un array plano que contiene cada objeto en la estructura de datos que pasó. Por ejemplo: 
my $foo = {
    'a' => bless( { 'b' => bless( {}, "c" ), }, "d" ),
    'e' => [ bless( [], "f" ), bless( [], "g" ), ]
};
use Data::Dumper;
# decirle a Data::Dumper que muestre los nodos varias veces
$Data::Dumper::Deepcopy = 1;
use Data::Structure::Util qw(get_blessed);
print Dumper( get_blessed( $foo ) );
$VAR1 = [
    bless( {}, 'c' ),
    bless( { 'b' => bless( {}, 'c' ) }, 'd' ),
    bless( [], 'f' ),
    bless( [], 'g' )
];

Esta función es esencialmente la misma que "get_refs" pero solo devuelve objetos bendecidos (blessed) en lugar de todos los objetos. Como con esa función, la estructura de datos se recorre en profundidad primero, por lo que los objetos más superiores deberían ser los últimos elementos del array. Tenga en cuenta también (como muestra el ejemplo anterior) que se devuelven objetos dentro de objetos.

Funciones de Manipulación utf8

Estas funciones le permiten manipular el estado de los flags utf8 en los escalares contenidos en la estructura de datos. Información sobre el flag utf8 y su significado se puede encontrar en Encode.

has_utf8($var)
Devuelve $var si el flag utf8 está habilitado para $var o para cualquier escalar que una estructura de datos pasada en $var contenga. 
print "esto se imprimirá"  if defined has_utf8( "\x{1234}" );
print "esto no se imprimirá" if defined has_utf8( "foo bar" );

Tenga en cuenta que no debe comprobar la veracidad del valor de retorno de esta función cuando la llame con un solo escalar, ya que es posible tener una cadena "0" o "" para la cual el flag utf8 esté establecido; ya que "undef" nunca puede tener el flag utf8 establece que la función nunca devolverá un valor definido si la estructura de datos no contiene un escalar con la marca utf8.

_utf8_off($var)
Desactiva recursivamente la marca utf8 en todos los escalares dentro de $var. Esto es lo mismo que la función "_utf8_off" de Encode pero se aplica a cualquier cadena dentro de $var. La estructura de datos se convierte in situ y, por conveniencia, la variable pasada se devuelve desde la función.

Esta función no intenta realizar ninguna conversión de juego de caracteres a las cadenas almacenadas en cualquiera de los escalares de la estructura de datos pasada. Esto significa que si perl almacenaba internamente algún carácter como una secuencia de bytes en la codificación utf8, cada byte de esa secuencia será a partir de ahora tratado como un carácter en sí mismo.

Por ejemplo:

my $emoticons = { smile => "\x{236a}" };
use Data::Structure::Util qw(_utf8_on);
print length( $emoticons->{smile} ), "\n";    # imprime 1
_utf8_off( $emoticons );
print length( $emoticons->{smile} ), "\n";    # imprime 3
_utf8_on($var)
Activa recursivamente la marca utf8 en todos los escalares dentro de $var. Esto es lo mismo que la función "_utf8_on" de Encode pero se aplica a cualquier cadena dentro de $var. La estructura de datos se convierte in situ y, por conveniencia, la variable pasada se devuelve desde la función.

Como arriba, esto no intenta realizar ninguna conversión de juego de caracteres, lo que significa que a menos que tu cadena contenga las secuencias de bytes utf8 válidas para los caracteres que deseas, tendrás problemas. En algunos casos las secuencias de bytes incorrectas pueden provocar un fallo de segmentación en perl. En particular, el motor de expresiones regulares tiene problemas significativos con utf8 inválido que ha sido marcado incorrectamente como utf8. Deberías saber lo que estás haciendo si usas esta función; Considera usar el módulo Encode como alternativa.

Ejemplo contrario al anterior:

my $emoticons = { smile => "\342\230\272" };
use Data::Structure::Util qw(_utf8_on);
print length( $emoticons->{smile} ), "\n";    # imprime 3
_utf8_on( $emoticons );
print length( $emoticons->{smile} ), "\n";    # imprime 1
utf8_on($var)
Esta rutina realiza un "sv_utf8_upgrade" en cada cadena escalar en la estructura de datos pasada que no tiene la marca utf8 activada. Esto hará que perl cambie el método que usa internamente para almacenar la cadena desde la codificación nativa (normalmente Latin-1 a menos que entren en juego los locales) a una codificación utf8 y establezca la marca utf8 para ese escalar. Esto significa que las letras de un solo byte ahora serán representadas por secuencias de múltiples bytes. Sin embargo, siempre que la directiva "use bytes" no esté en vigor, la cadena tendrá la misma longitud porque, en lo que a perl respecta, la cadena todavía contiene el mismo número de caracteres (pero no de bytes).

Esta rutina es significativamente diferente de "_utf8_on"; Esa rutina asume que tu cadena está codificada en utf8 pero fue marcada (erróneamente) en la codificación nativa. Esta rutina asume que tu cadena está codificada en la codificación nativa y está marcada de esa manera, pero preferirías que estuviera codificada y marcada como utf8.

utf8_off($var)
Esta rutina realiza un "sv_utf8_downgrade" en cada cadena escalar en la estructura de datos pasada que tiene la marca utf8 activada. Esto hará que perl cambie el método que usa internamente para almacenar la cadena desde la codificación utf8 a la codificación nativa (normalmente Latin-1 a menos que se usen locales) y desactive la marca utf8 para ese escalar. Esto significa que las secuencias de múltiples bytes que representan un solo carácter serán reemplazadas por un byte por carácter. Sin embargo, siempre que la directiva "use bytes" no esté en vigor, la cadena tendrá la misma longitud porque, en lo que a perl respecta, la cadena todavía contiene el mismo número de caracteres (pero no de bytes).

Ten en cuenta que no todas las cadenas pueden convertirse de utf8 a la codificación nativa; En el caso de que el carácter utf8 no tenga un carácter correspondiente en la codificación nativa, Perl morirá con la excepción "Wide character in subroutine entry".

Esta rutina es significativamente diferente de "_utf8_off"; Esa rutina asume que tu cadena está codificada en utf8 y que simplemente quieres marcarla como si estuviera en la codificación nativa para que perl trate cada byte que compone las secuencias de caracteres como un carácter en sí mismo en la codificación nativa. Esta rutina asume que tu cadena está codificada en utf8, pero quieres que cada carácter que actualmente está representado por cadenas de múltiples bytes sea reemplazado por la representación de un solo byte del mismo carácter.

ERRORES

signature() es sensible al algoritmo de aleatorización de hashes

Este módulo solo recurre a través de hashes, listas y referencias a escalares básicos. No intenta nada más complicado.
