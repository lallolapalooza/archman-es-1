NOMBRE

Date::Manip::Lang::portugue - Soporte para el idioma portugués.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que soportan el idioma. No está destinado a ser utilizado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DEL IDIOMA

La siguiente es una lista de todas las palabras y expresiones del idioma utilizadas para escribir horas y/o fechas.

Todas las cadenas no distinguen entre mayúsculas y minúsculas.

Palabras ignoradas
Al escribir fechas en formas comunes, hay una serie de palabras que típicamente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar una hora. En inglés, usarías la palabra AT en el ejemplo:

December 3 at 12:00

Se pueden usar las siguientes palabras:

as
às

Otra palabra se usa para designar a un miembro de un conjunto. En inglés, usarías tlas palabras IN u OF:

1er día DE December
1er día IN December

Se pueden usar las siguientes palabras:

da
do

Se usa otra palabra para especificar que algo está en una fecha determinada. En inglés, se usaría ON:

ON July 5th

Se pueden usar las siguientes palabras:

na
no
Palabras que establecen la fecha, la hora, o ambas
Hay algunas palabras que se pueden usar para especificar una fecha, una hora, o ambas, relativas al momento actual.

Las palabras que establecen la fecha son similares a las palabras en inglés 'yesterday' o 'tomorrow'. Se especifican como un delta que se añade a la hora actual para obtener una fecha. Sin embargo, la hora NO se establece, por lo que el delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana y día).

Se pueden usar las siguientes palabras:

amanha               +0:0:0:1:0:0:0
amanhã               +0:0:0:1:0:0:0
hoje                 0:0:0:0:0:0:0
ontem                -0:0:0:1:0:0:0

Las palabras que establecen solo la hora del día son similares a las palabras en inglés 'noon' o 'midnight'.

Se pueden usar las siguientes palabras:

meia-noite           00:00:00
meio-dia             12:00:00

También están disponibles palabras que establecen la hora y la fecha completas (relativas a la hora y fecha actuales).

En inglés, la palabra 'now' es una de estas.

Se pueden usar las siguientes palabras:

agora                0:0:0:0:0:0:0
Separadores de Hora/Minuto/Segundo
Al especificar la hora del día, el separador más común es dos puntos (:) el cual puede usarse para ambos separadores.

Algunos idiomas usan pares diferentes. Por ejemplo, francés permite especificar la hora como 13h30:20, por lo que usaría los siguientes pares:

: :
h :

La primera columna es el separador hora-minuto y la segunda columna es el separador minuto-segundo. Ambas son expresiones regulares de perl. Al crear una nueva traducción, tenga en cuenta que las expresiones regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no incluya la expresión '[x]' donde 'x' es un carácter utf-8.

SIEMPRE se permite un par de dos puntos para todos los idiomas. Si un idioma permite pares adicionales, se listan aquí:

No definido en este idioma
Separador de segundos fraccionarios
Al especificar segundos fraccionarios, la forma más común es usar un punto decimal (.). Algunos idiomas pueden especificar un separador diferente que podría usarse. Si se hace, es una expresión regular.

SIEMPRE se permite el punto decimal para todos los idiomas. Si un idioma permite otro separador, se lista aquí:

No definido en este idioma
