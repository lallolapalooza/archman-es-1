Data::Perl::Collection::Hash(3) Documentación de Perl proporcionada por el usuario Data::Perl::Collection::Hash(3)

NOMBRE

Data::Perl::Collection::Hash - Clase envoltorio para la estructura de hash integrada de Perl.

VERSIÓN

versión 0.002011

SINOPSIS

use Data::Perl qw/hash/;
my $hash = hash(a => 1, b => 2);
$array->push(5);
$hash->values; # (1, 2)
$hash->set('foo', 'bar'); # (a => 1, b => 2, foo => 'bar')

DESCRIPCIÓN

Esta clase es un consumidor simple del rol Data::Perl::Role::Collection::Hash, que proporciona toda la funcionalidad. Probablemente quieras mirar allí en su lugar.
