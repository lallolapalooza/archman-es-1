DESCRIPCIÓ

N

darktable es una aplicación de flujo de trabajo de fotografía digital para Linux, Mac OS X y varios otros sistemas

Unix.

La aplicación está diseñada para facilitar la edición y el procesamiento consistente de grandes sesiones de fotos y proporciona una mesa de luz digital fácil de usar y un conjunto de sofisticadas herramientas de postprocesamiento

.

La mayor parte del procesamiento se realiza en modo de punto flotante de 32 bits por canal en el espacio de color independiente del dispositivo CIE L*a*b*. darktable es también totalmente gestionado por color, lo que le da un control total sobre el aspecto de las

fotos.

La aplicación se basa en una arquitectura de complementos moderna, lo que facilita a los desarrolladores de terceros ampliar las capacidades existentes de la aplicación. Todas las funciones de la mesa de luz y del cuarto oscuro están implementadas como complementos, por lo que puede crear sus propios complementos reutilizando el código existente. La mayoría de las cosas específicas del flujo de trabajo también se pueden programar en Lu

a
.

OPCIONE

S
IMG_1234.RAW o carpeta_de_imágen
es/
Opcionalmente puede proporcionar el nombre de archivo de una imagen o el nombre de una carpeta que contenga archivos de imagen. Si se proporciona un nombre de archivo, darktable se inicia en la vista de cuarto oscuro con ese archivo abierto. Si se proporciona una carpeta, darktable se inicia en la vista de mesa de luz con el contenido de esa carpeta como la colección actual. Si ya hay una instancia de darktable en ejecución (usando la misma biblioteca), la imagen o la carpeta se abrirá allí, usando D-Bus para comunicarse entre los dos
procesos.
--cachedir <directorio de
caché>
darktable mantiene una caché de miniaturas de imágenes para una vista previa rápida de imágenes y de binarios OpenCL precompilados para un inicio rápido. Por defecto, la caché se encuentra en "$HOME/.cache/darktable/". Puede existir múltiples cachés de miniaturas en paralelo: una para cada archivo de
biblioteca.
--conf <clave>
=<valor>
darktable admite un rico conjunto de parámetros de configuración que el usuario define en "darktablerc" - el archivo de configuración de darktable en el directorio de configuración del usuario. Puede sobrescribir temporalmente configuraciones individuales en la línea de comandos con esta opción; sin embargo, estas configuraciones no se almacenarán en "darktablerc
".
--configdir <directorio de
configuración>
Esta opción define el directorio donde darktable almacena la configuración específica del usuario. El lugar por defecto es "$HOME/.config/darktable
/".
-d <opción de
depuración>
Esta opción habilita la salida de depuración en la terminal. Hay varios subsistemas de darktable y la depuración de cada uno de ellos se puede activar por separado. Puede usar esta opción varias veces si desea la salida de depuración de más de un subsistema.

--library <archivo de
biblioteca>
darktable mantiene la información de las imágenes en una base de datos sqlite para un acceso rápido. La ubicación por defecto de ese archivo de base de datos es "$HOME/.config/darktable/library.db". Puede proporcionar una ubicación alternativa, por ejemplo, si desea hacer algunos experimentos sin comprometer su library.db original. Si el archivo de base de datos no existe, darktable lo crea por usted. También puede proporcionar ":memory:" como archivo de biblioteca, en cuyo caso la base de datos se mantiene en la memoria del sistema: todos los cambios se descartan cuando darktable
termina.
--localedir <directorio de configuración
regional>
El lugar donde darktable encuentra sus cadenas de texto específicas del idioma. El lugar por defecto depende de su instalación. Los lugares típicos son "/opt/darktable/share/locale/" y "/usr/share/lo
cale/".
--luacmd <comando
lua>
Una cadena que contiene comandos lua para ejecutar después de la inicialización de lua. Estos comandos se ejecutarán después de su archivo "luarc".

Si lua no está compilado,

esta opción será aceptada
pero no hará nada.
--moduledir <directorio de
módulos>
darktable tiene una estructura modular y organiza sus módulos como bibliotecas compartidas para cargar en tiempo de ejecución. Con esta opción le indica a darktable dónde buscar sus bibliotecas compartidas. El lugar por defecto depende de su instalación; los lugares típicos son "/opt/darktable/lib/darktable/" y "/usr/lib/darktable
/".
--noiseprofiles <archivo json de perfiles de
ruido>
El módulo de reducción de ruido con perfil de darktable utiliza datos de perfil específicos de la cámara que se cargan desde un archivo JSON externo. Con esta opción se puede cambiar el archivo a cargar para permitir la prueba de perfiles alternativos. El archivo de perfil por defecto es "noiseprofiles.json" y normalmente se encuentra en "/opt/darktable/share/darktable/" o "/usr/share/darktable
/".
-t <número de hilos
openmp>
darktable usa OpenMP para paralelizar muchos pasos de cálculo y aprovechar todos los núcleos de CPU disponibles. Con esta opción puede especificar el número de hilos a usar. Los valores válidos están entre 1 y 100
.
--tmpdir <directorio
temporal>
El lugar donde darktable almacena sus archivos temporales. Si no se proporciona esta opción, darktable usa el valor por defecto del
sistema.
