ensión de DateTime::Set para crear
conjuntos de recurrencia básicos

SINOPSI

S 
use DateTime;
use DateTime::Event::Recurrence;

my $dt = DateTime->new( year   => 2000,
                        month  => 6,
                        day    => 20,
                      );
my $daily_set = DateTime::Event::Recurrence->daily;
my $dt_next = $daily_set->next( $dt );
my $dt_previous = $daily_set->previous( $dt );
my $bool = $daily_set->contains( $dt );
my @days = $daily_set->as_list( start => $dt1, end => $dt2 );
my $iter = $daily_set->iterator;
while ( my $dt = $iter->next ) {
    print ' ', $dt->datetime;
}

DESCRIPCIÓ

N

Este módulo proporciona métodos de conveniencia que le permiten crear fácilmente objetos "DateTime::Set" para varias recurrencias, como "una vez al mes" o "todos los días". También puede

crear recurrencias más complicadas, como "todos los lune
s, miércoles y jueves a las 10:00 AM y las 2:00 PM".

O
•
yearly monthly weekly daily hourly minutely secondly

Todos estos métodos devuelven un nuevo objeto "DateTime::Set" que representa la recurrencia

dada. 
my $daily_set = DateTime::Event::Recurrence->
daily;

Si no se proporcionan parámetros, entonces los miembros del conjunto ocurren cada uno en el comienzo de la recurrencia especificada. inicio de la recurrencia

especificada.

Por ejemplo, de forma predeterminada, el método monthly() devuelve un conjunto que contiene el primer día de cada

mes.

Sin parámetros, el método weekly() devuelve un conjunto que contiene los lun

es.

Sin embargo, puede pasar parámetros para alterar dónde caen estas fechas y horas. Los parámetros son los mismos que los dados al constructor "DateTime::Duration" para especificar la longitud de una duración. Por ejemplo, para crear un conjunto que representa una recurrencia diaria a las 10:30 cada día, escribimos

esto: 
my $daily_at_10_30_set =
    DateTime::Event::Recurrence->daily( hours => 10, minutes =>
30 );

Para representar cada martes (segundo día de la

semana): 
my $weekly_on_tuesday_set =
    DateTime::Event::Recurrence->weekly( days =>
2 );

Una duración negativa cuenta hacia atrás desde el final del período. Esto se hace de la misma manera que se especifica en RFC 2445

(iCal).

Las duraciones negativas son útiles para crear recurrencias como el último día de cada

mes: 
my $last_day_of_month_set =
    DateTime::Event::Recurrence->monthly( days =>
-1 );

También puede proporcionar múltiples conjuntos de argumentos de duración, como

este: 
my $set = DateTime::Event::Recurrence->daily
              ( hours =>   [ 10, 14,  -1 ],
                minutes => [ 15, 30, -15 ],
);

Esto especifica una recurrencia que ocurre todos los días a estas 9 horas

diferentes: 
10:15,  10:30,  10:45,   # +10h         ( +15min / +30min / last 15min (-15) )
14:15,  14:30,  14:45,   # +14h         ( +15min / +30min / last 15min (-15) )
23:15,  23:30,  23:45,   # last 1h (-1) ( +15min / +30min / last 15min
(-15) )

Para crear un conjunto de recurrencias que ocurren cada treinta segundos, podríamos

hacer esto: 
my $every_30_seconds_set =
    DateTime::Event::Recurrence->minutely( seconds => [ 0, 30
] );

Lo siguiente también es válido. Vea la sección sobre el parámetro

"interval": 
my $every_30_seconds_set =
    DateTime::Event::Recurrence->secondly( interval =>
30
)
;

DateTimes

inválidos

Los valores inválidos se omiten en tiempo de

ejecución.

Por ejemplo, cuando se agregan días a un mes, el resultado se comprueba para ver si contiene un día inexistente (como el 31 o el 30), y las fechas y horas inválidas se

omiten.

Otro ejemplo de esto sería crear un conjunto a través del método daily() y especificar "hours

=>
25".

El parámetro

"days"

El parámetro "days" se puede combinar con recurrencias anuales, mensuales y semanales, resultando en seis posibles

significados: 
# tuesday of every week
my $set = DateTime::Event::Recurrence->weekly( days => 2 );
# 10th day of every month
my $set = DateTime::Event::Recurrence->monthly( days => 10 );
# second full week of every month, on tuesday
my $set = DateTime::Event::Recurrence->monthly( weeks => 2, days => 2 );
# 10th day of every year
my $set = DateTime::Event::Recurrence->yearly( days => 10 );
# 10th day of every december
my $set = DateTime::Event::Recurrence->yearly( months => 12, days => 10 );
# second week of every year, on tuesday
my $set = DateTime::Event::Recurrence->yearly( weeks => 2, days => 2 )
;

Los días de la semana también se pueden llamar por nombre, como se especifica en RFC 2445 (iCal)

: 
my $weekly_on_tuesday_set =
    DateTime::Event::Recurrence->weekly( days => 'tu' )
;

El parámetro "days" tiene como valor predeterminado "el primer día". Vea también la sección sobre el parámetro "week_start_day"

. 
# second full week of every month, on monday
my $set = DateTime::Event::Recurrence->monthly( weeks => 2 );
# second tuesday of every month
my $set = DateTime::Event::Recurrence->monthly( weeks => 2, days => "tu", week_start_day => "1tu"
)
;

Los parámetros "interval" y

"start"

El parámetro "interval" representa con qué frecuencia se repite la regla de

recurrencia.

El parámetro opcional "start" especifica dónde comenzar a

contar: 
my $dt_start = DateTime->new( year => 2003, month => 6, day => 15 );
my $set = DateTime::Event::Recurrence->daily
              ( interval => 11,
                hours    => 10,
                minutes  => 30,
                start    => $dt_start,
              )
;

Esto especifica una recurrencia que sucede a las 10:30 en el día especificado por "start => $dt", y luego cada 11 días antes y después de $dt. Así que obtenemos un conjunto como

este: 
...
2003-06-04T10:30:00,
2003-06-15T10:30:00,
2003-06-26T10:30:00,
..
.

En este caso, el método se usa para especificar la unidad, así que daily() significa que nuestra unidad es un día, y "interval => 11" especifica la cantidad de nuestra

unidad.

El parámetro "st

art" no debe ten
er zona horaria.

El parámetro "week_start_day

"

El "week_start_day" representa cómo se calcula la 'primera semana' de un

período:

"mo", "tu", "we", "th", "fr", "sa", "su" - La primera semana es la que comienza en este día de la semana y tiene la mayoría de los días en este período. Funciona para recurrencias "weekly" y "yearly"

.

"1mo", "1tu", "1we", "1th", "1fr", "1sa", "1su" - La primera semana es la que comienza en este día de la semana y tiene todos los días en este período. Esto funciona para recurrencias weekly(), monthly() y yearly

().

El "week_start_day" tiene como valor predeterminado "1mo", excepto en recurrencias anuales (yearly()) que tienen com

o valor predet
erminado "mo".

Zonas

horarias

Las recurrencias se crean en la zona horaria 'flotante', como se especifica en el módulo "Date

Time".

Si desea especificar una zona horariapara una recurrencia, puedes hacer esto llamando a set_time_zone() en el conjunto

devuelto: 
my $daily = DateTime::Event::Recurrence->daily;
$daily->set_time_zone( 'Europe/Berlin' )
;

También puedes pasar un objeto "DateTime.pm" con una zona horaria a los métodos next() y previous() del

conjunto: 
my $dt = DateTime->today( time_zone => 'Europe/Berlin' );
my $next = $daily->next($dt)
;

Una recurrencia puede verse afectada por los cambios de horario de verano (DST), por lo que sería posible especificar una recurrencia que crea fechas y horas inexistentes. Como "DateTime.pm" lanza una excepción si se le pide crear una fecha y hora inexistente, ten cuidado al establecer una zona horaria para tu

recurrencia.

Podría ser preferible usar siempre "UTC" pa

ra tus conjuntos, y luego convertir el
objeto devuelto a la zona horaria deseada.

Segundos

bisiestos

No hay segundos bisiestos, porque las recurrencias se crean en la zona horaria

'flotante'.

El valor 60 para segundos (el segundo bisiesto) se ignora. Si realmente quieres el segundo bisiesto, entonces especifica el segundo como -

1
.
