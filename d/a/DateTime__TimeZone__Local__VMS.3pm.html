NOMBRE

DateTime::TimeZone::Local::VMS - Determinar la zona horaria del sistema local en VMS

VERSIÓN

versión 2.65

SINOPSIS

my $tz = DateTime::TimeZone->new( name => 'local' );
my $tz = DateTime::TimeZone::Local->TimeZone();

DESCRIPCIÓN

Este módulo proporciona métodos para determinar la zona horaria local en una plataforma VMS.

NOTA: Esto es básicamente un *stub* pendiente de una implementación por parte de alguien que sepa algo sobre VMS.

CÓMO SE DETERMINA LA ZONA HORARIA

Esta clase intenta los siguientes métodos para determinar la zona horaria local:

•
%ENV

Verificamos las siguientes variables de entorno:

  • TZ
  • SYS$TIMEZONE_RULE
  • SYS$TIMEZONE_NAME
  • UCX$TZ
  • TCPIP$TZ
