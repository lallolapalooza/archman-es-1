NOMBRE

Date::Manip::Lang::french - Soporte para el idioma francés.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que admiten el idioma. No está destinado a ser utilizado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DEL IDIOMA

La siguiente es una lista de todas las palabras y expresiones del idioma utilizadas para escribir horas y/o fechas.

Todas las cadenas no distinguen entre mayúsculas y minúsculas.

Horas de la mañana/tarde
Esta es una lista de expresiones utilizadas para designar la hora de la mañana o la tarde cuando una hora se introduce como una hora de 12 en lugar de una hora de 24. Por ejemplo, en inglés, la hora "17:00" podría especificarse como "5:00 PM".

La hora de la mañana y la tarde puede designarse con los siguientes conjuntos de palabras:

du matin
du soir

Palabras ignoradas
Al escribir fechas en formas comunes, hay una serie de palabras que típicamente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar una hora a continuación. En inglés, usarías la palabra AT en el ejemplo:

December 3 at 12:00

Se pueden usar las siguientes palabras:

a
à

Otra palabra se usa para designar a un miembro de un conjunto. En inglés, usarías las palabras IN o OF:

1st day OF December
1st day IN December

Se pueden usar las siguientes palabras:

de
en
du

Otra palabra se usa para especificar que algo está en una fecha determinada. En ingléses, usaría ON:

ON July 5th

Se pueden usar las siguientes palabras:

sur
Palabras que establecen la fecha, la hora, o ambas
Hay algunas palabras que se pueden usar para especificar una fecha, una hora, o ambas en relación con el momento actual.

Las palabras que establecen la fecha son similares a las palabras en inglés 'yesterday' (ayer) o 'tomorrow' (mañana). Estas se especifican como un delta que se añade a la hora actual para obtener una fecha. La hora NO se establece, por lo que el delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana y día).

Se pueden usar las siguientes palabras:

aujourd'hui          0:0:0:0:0:0:0
aujourd’hui          0:0:0:0:0:0:0
demain               +0:0:0:1:0:0:0
hier                 -0:0:0:1:0:0:0

Las palabras que establecen solo la hora del día son similares a las palabras en inglés 'noon' (mediodía) o 'midnight' (medianoche).

Se pueden usar las siguientes palabras:

midi                 12:00:00
minuit               00:00:00

También están disponibles palabras que establecen la hora y la fecha completas (en relación con la hora y fecha actuales).

En inglés, la palabra 'now' (ahora) es una de estas.

Se pueden usar las siguientes palabras:

maintenant           0:0:0:0:0:0:0
Separadores de Hora/Minuto/Segundo
Al especificar la hora del día, el separador más común es los dos puntos (:) que puede usarse para ambos separadores.

Algunos idiomas usan pares diferentes. Por ejemplo, el francés permite especificar la hora como 13h30:20, por lo que usaría los siguientes pares:

: :
h :

La primera columna es el separador hora-minuto y la segunda columna es el separador minuto-segundo. Ambas son expresiones regulares de perl. Al crear una nueva traducción, tenga en cuenta que las expresiones regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no incluya la expresión '[x]' donde 'x' es un carácter utf-8.

Un par de dos puntos SIEMPRE está permitido para todos los idiomas. Si un idioma permite pares adicionales, se listan aquí:

h  :
Separador de segundo fraccionario
Al especificar segundos fraccionarios, la forma más común es usar un punto decimal (.). Algunos idiomas pueden especificar un separador diferente que podría usarse. Si se hace, es una expresión regular.

El punto decimal SIEMPRE está permitido para todos los idiomas. Si un idioma permite otro separador, se lista aquí:

No definido en este idioma
