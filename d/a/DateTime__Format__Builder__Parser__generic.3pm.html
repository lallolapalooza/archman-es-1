MÉTODOS

Útiles

new

Constructor estándar. Devuelve un hash "bendecido" (blessed hash); cualquier argumento se coloca en el hash. Esto es útil para almacenar información entre métodos.

generic_parser

Este es un método proporcionado únicamente para el beneficio de las implementaciones de "Parser". Abstrae de forma semi-ordenada gran parte del trabajo involucrado.

Básicamente, toma parámetros que coinciden con las diversas callbacks de las declaraciones del parser y crea un coderef con todo ello.

Las callbacks reconocidas actualmente son:

  • on_match
  • on_fail
  • preprocess
  • postprocess

Métodos para subclases

Estos son métodos que debes definir al escribir tu propia subclase.

Nota: estos métodos no existen en esta clase. No tiene sentido intentar llamar a "$self->SUPER::do_match( ... )".

do_match

"do_match" es la primera fase. Los argumentos son la fecha y @args. Se debe definir "self", "label", "args". El valor de retorno debe estar definido si coincide con éxito.

post_match

"post_match" se llama después de que se haya ejecutado la callback apropiada de "on_match"/"on_fail". Se le pasa la fecha, el valor de retorno de "do_match" y el hash de parsing.

Su valor de retorno se utiliza como argumento "post" para la callback "postprocess", y como segundo argumento a "make".

make

"make" toma la entrada original, el valor de retorno de "post_match" y el hash de parsing, y debería devolver un objeto "DateTime" o indefinido.

Delegaciones

Para su uso por parte de "Parser", este módulo también delega "valid_params" y "params". Esto es solo para conveniencia para ahorrar escribir lo siguiente:

DateTime::Format::Builder::Parser->valid_params(...)

En lugar de escribir:

$self->valid_params(...);
__PACKAGE__->valid_params(...);
