NOMBRE

Date::Manip::Migration5to6 - cómo actualizar de 5.xx a 6.00

SINOPSIS

Al actualizar de Date::Manip 5.xx a 6.00, es posible que necesites realizar algunos cambios en tus scripts.

El documento Date::Manip::Changes5to6 enumera con más detalle las formas en que cambió Date::Manip, pero muy pocos de ellos realmente implican cambios en tu script.

Cabe señalar que una vez que se realicen los cambios en tu script, este ya no se ejecutará correctamente en la versión 5.xx.

CAMBIOS NECESARIOS Y SUGERIDOS

Los siguientes cambios son necesarios o se sugieren encarecidamente:

Lectura de archivos de configuración con Date_Init
Si usas Date_Init para leer archivos de configuración (si realizas cálculos en modo de negocio, probablemente lo haces), debes eliminar todas las siguientes variables de configuración de tu llamada a Date_Init: 
GlobalCnf=FILE
PersonalCnf=FILE
PathSep=*
IgnoreGlobalCnf=*
PersonalCnfPath=*

y reemplazarlas con:

ConfigFile=FILE

donde FILE ahora es la ruta completa a un archivo de configuración. Además, el argumento ConfigFile debe ser el primer argumento en Date_Init.

Date_ConvTZ
La función Date_ConvTZ ha cambiado. Ahora debe tomar 3 argumentos: 
$date = Date_ConvTZ($date,$from,$to);

Si no se proporciona $from, se utiliza la hora local por defecto. Si no se proporciona $to, se utiliza la hora local por defecto.

La fecha se convierte de la zona horaria $from a la zona horaria $to. Ambas deben ser cualquier zona horaria (o alias) soportada por Date::Manip.

El antiguo argumento $errlevel ya no se maneja.

Variables de configuración ConvTZ y TZ
Si utilizas las variables de configuración ConvTZ o TZ, debes reemplazarlas con SetDate o ForceDate. Consulta el documento Date::Manip::Config para obtener información.

La variable TZ seguirá funcionando hasta diciembre de 2015, momento en el que será eliminada.

Otras variables de configuración obsoletas
Las siguientes variables de configuración han sido declaradas obsoletas, pero seguirán funcionando (aunque serán eliminadas en una fecha futura): 
TZ           (eliminada en marzo de 2016)

Las siguientes variables han sido eliminadas. Si usas alguna de ellas, puede que necesites modificar tus scripts:

IntCharSet
GlobalCnf
PersonalCnf
PathSep
IgnoreGlobalCnf
PersonalCnfPath
ConvTZ
Internal
TodayIsMidnight
DeltaSigns
UpdateCurrTZ
ResetWorkdDay
hoy, ayer, mañana
Si analizas las cadenas "hoy", "ayer" o "mañana" para obtener la hora actual, o 24 horas atrás/adelante, esto ya no funcionará. Estas cadenas ahora se refieren estrictamente a la fecha (por lo que "hoy" es el día actual a medianoche, "ayer" es el día anterior a medianoche, etc.).

Para obtener la hora actual, hace 24 horas o dentro de 24 horas, deberías analizar las cadenas "ahora", "-24:00:00" o "+24:00:00" respectivamente.

No usar Memoize
En la versión 5.xx, se documentó que podías usar el módulo Memoize para acelerar Date::Manip, especialmente al ordenar fechas.

Esta información ya no es correcta. Usar Memoize junto con Date::Manip debería tener poco impacto en el rendimiento, y podría conducir a resultados incorrectos, especialmente si cambias variables de configuración.

Consulta "CAMBIOS GENERALES" en Date::Manip::Changes5to6 para obtener más información.

Si encuentras otros casos en los que sea necesario modificar tu script, por favor envíame un correo electrónico para que pueda agregar esa información a este documento.

ERRORES Y PREGUNTAS

Por favor, consulta la documentación de Date::Manip::Problems para obtener información sobre cómo enviar informes de errores o preguntas al autor.
