DESCRIPCIÓ

N

Esta es una clase base abstracta para objetos respaldados por un socket que proporciona el marco básico para la E/S asíncrona dirigida por eventos, diseñada para ser rápida. Danga::Socket es tanto una clase base para objetos como un bucle de

eventos.

Los llamadores crean subclases de Danga::Socket. El constructor de Danga::Socket se registra a sí mismo con el bucle de eventos de Danga::Socket e invoca callbacks en el objeto para legibilidad, escribibilidad, errores y otras

condiciones.

Debido a que Danga::Socket us

a el módulo "fields", sus sub
clases también deben hacerlo.
