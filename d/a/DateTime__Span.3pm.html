DESCRIPCIÓ

N

"DateTime::Span" es un módulo para manejar intervalos de fecha y hora, también conocidos como rangos o periodos ("desde X hasta Y, incluyendo todas las fechas y horas intermedias")

.

Esto es diferente de un "DateTime::Set", que está compuesto por puntos individuales de fecha y hora en lugar de un rango. También existe un módulo "DateTime::SpanSet" para manej

ar conjuntos de
intervalos.

  • from_datetimes

    Crea un nuevo intervalo basado en una fecha y hora de inicio y una

    de fin.

    Un intervalo 'cerrado' incluye sus fechas

    de fin: 
    $span = DateTime::Span->from_datetimes( start => $dt1, end =>
    $dt2 );

    Un intervalo 'abierto' no incluye sus fechas

    de fin: 
    $span = DateTime::Span->from_datetimes( after => $dt1, before =>
    $dt2 );

    Un intervalo 'semiabierto' incluye una de sus fechas

    de fin: 
    $span = DateTime::Span->from_datetimes( start => $dt1, before => $dt2 );
$span = DateTime::Span->from_datetimes( after => $dt1, end =>
    $dt2 );

    Un intervalo puede tener solo una fecha de inicio, o solo una fecha de fin. Estos intervalos terminan, o comienzan, en una fecha imaginaria 'para

    siempre': 
    $span = DateTime::Span->from_datetimes( start => $dt1 );
$span = DateTime::Span->from_datetimes( end => $dt2 );
$span = DateTime::Span->from_datetimes( after => $dt1 );
$span = DateTime::Span->from_datetimes( before =>
    $dt2 );

    No puedes dar tanto un argumento "start" como "after", ni tampoco puedes dar tanto un argumento "end" como "before". Cualquiera de estas condiciones hará que el método from_datetimes()

    falle.

    Para resumir, una fecha y hora pasada como "start" o

    "end" está incluida en el intervalo. Una fecha y hora pasada
    • como "after" o "before" está excluida del intervalo.
