NOMBRE

Data::Grove -- soporte para estructuras profundamente anidadas

SINOPSIS

use Data::Grove;
$objeto = MiPaquete->new;
package MiPaquete;
@ISA = qw{Data::Grove};

DESCRIPCIÓN

"Data::Grove" proporciona soporte para estructuras de árbol o grafo profundamente anidadas. "Data::Grove" está destinado principalmente a autores de módulos de Perl que escriben módulos con muchos tipos o clases de objetos que necesitan ser manipulados y extendidos de una manera consistente y flexible.

"Data::Grove" se utiliza mejor creando un conjunto central de clases de ``datos'' y luego añadiendo funcionalidad incrementalmente a las clases de datos centrales mediante módulos de ``extensión''. Una razón para este diseño es que las clases de datos puedan ser intercambiadas y los módulos de extensión puedan trabajar con nuevas fuentes de datos. Por ejemplo, estas otras fuentes de datos podrían estar basadas en disco, en red o construidas sobre una base de datos relacional.

Dos módulos de extensión que vienen con "Data::Grove" son "Data::Grove::Parent" y "Data::Grove::Visitor". "Data::Grove::Parent" añade una propiedad `"Parent"' a los objetos grove e implementa un método `"root"' para los objetos grove que devuelve el nodo raíz del árbol desde cualquier lugar del árbol y un método `"rootpath"' para devolver una lista de nodos entre el nodo raíz y ``este'' nodo. "Data::Grove::Visitor" añade métodos de callback `"accept"' y `"accept_name"' que llaman a su manejador o módulo receptor por nombre de tipo de objeto o por el nombre del objeto.

"Data::Grove" los objetos no contienen referencias a padres, la recolección de basura de Perl los eliminará cuando ya no se referencien y las subestructuras puedan ser compartidas entre varias estructuras. "Data::Grove::Parent" se utiliza para crear objetos temporales con punteros a padres.

Las propiedades de las clases de datos se acceden directamente utilizando las funciones hash de Perl (es decir, `"$object->{Property}"'). Los módulos de extensión también pueden definir propiedades que soportan o utilizan, por ejemplo Data::Grove::Parent añade las propiedades `"Parent"' y `"Raw"' y Visitor depende de las propiedades `"Name"' y `"Content"'.

Consulte el módulo "XML::Grove" para ver un ejemplo de implementación de "Data::Grove".

MÉTODOS

new( PROPIEDADES )
Devuelve un nuevo objeto bendecido en SubClass, con las propiedades dadas. PROPIEDADES puede ser una lista de pares clave/valor, un único hash que contenga pares clave/valor, o un objeto "Data::Grove" existente. Si se pasa un "Data::Grove" existente a `new()', se devolverá una copia superficial de ese objeto. Una copia superficial significa que se le devuelve un nuevo objeto, pero todos los objetos subyacentes todavía se refieren a los objetos originales.
