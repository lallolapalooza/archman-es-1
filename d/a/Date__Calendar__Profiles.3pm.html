PRÓLOG

O

Este módulo proporciona algunos perfiles de ejemplo (es decir, esquemas de festivos) para su uso con los Date::Calendar(3) y Date::Calendar::Year(3)

módulos.

No es obligatorio usar estos, siempre puedes crear los tuyos propios (esto es muy fácil). Consulta la sección "CÓMO CREAR LOS TUYOS PROPIOS" más abajo para obtener más instrucciones sobre cómo hacerlo, y toma los perfiles de este módulo como

ejemplos.

No tengo la intención de hacer más correcciones a ninguno de los perfiles de calendario en este módulo a menos que haya razones MUY convincentes para hacerlo. Estos perfiles están destinados únicamente a ser

ejemplos.

La forma recomendada de usar estos perfiles es copiarlos a tu propio código y luego modificarlos según sea necesario. De lo contrario, muchas personas podrían verse negativamente afectadas si hiciera algún cambio en un perfil que alguien ha estado usando durante

años.

a el lector interesado.

DESCRIPCIÓ

N

El método "init()" en el módulo Date::Calendar::Year(3) es responsable de analizar los esquemas de calendario contenidos aquí en el módulo Date::Calendar::

Profiles.

Este método ofrece un "mini-lenguaje" que permite especificar fórmulas de fecha comunes, como por ejemplo una fecha fija simple (en varios formatos diferentes, p. ej. americano o europeo), o cosas como "el segundo domingo de mayo" (Día de la Madre), o "Domingo de Pascua menos 46 días" (Miércoles de Ceniza), por citar solo

algunos.

Consulta la sección "SINTAXIS DE FÓRMULAS DE FECHA" más abajo para más

detalles.

Sin embargo, hay algunas fórmulas más complicadas que no pueden expresarse en términos tan

simples.

La regla de que si un festivo cae en un fin de semana, será sustituido por el viernes o lunes adyacente (el que esté más cerca), es un ejemplo de

esto.

Para poder tratar con tales fórmulas, y para ser lo más flexible posible, el método "init()" ofrece la posibilidad de usar funciones de retorno de llamada (callback) para tratar con tales fechas y

fórmulas.

Consulta la sección "INTERFAZ DE RETORNO DE LLAMADA" más abajo para más detalles sobre este

tema.

Para ayudarte con los casos más comunes de fórmulas extrañas, el módulo Date::Calendar::Profiles exporta las siguientes subrutinas de utilidad (que están destinadas a ser usadas como "filtros" en funciones de retorno de llamada de tu propio)

INTERFAZ DE

CALLBACK

La interfaz de las funciones de callback para usar con el método "init()" del Date::Calendar::Year(3) módulo es muy

simple:

La función de callback recibe dos argumentos cuando se llama, primero el número de año para el cual se debe calcular el día festivo, y segundo el nombre (la "etiqueta") del día festivo en cuestión (que sirve como clave en el hash de un esquema de días festivos)

.

Este segundo parámetro le permite usar la misma función de callback para diferentes días festivos, lo que puede ser más práctico (que funciones de callback separadas) si, por ejemplo, tiene un conjunto de días festivos similares para calcular, como por ejemplo los cuatro domingos antes de Navidad ("Adviento")

.

La función de callback "Advent()" (exportada por el Date::Calendar::Profiles módulo) ejemplifica esta

técnica.

Se espera que la función de callback devuelva una lista ""($year,$month,$day)"" con la fecha exacta del día festivo (el número de año en la salida debe, por supuesto, coincidir con el número de año pasado como parámetro)

.

Se produce un error fatal si la lista devuelta no constituye una fecha válida, en el año

solicitado.

Opcionalmente, la función de callback puede devolver un cuarto valor (después de la fecha) que contiene una cadena, que puede ser "#" o ":

".

La cadena "#" significa que la fecha en cuestión es una fecha puramente conmemorativa, es decir, que no se tiene un día libre de trabajo ese

día.

La cadena ":" significa que la fecha en cuestión es un día festivo "a mediodía", es decir, un día en el que se tiene medio día libre de

trabajo.

En caso de que el día festivo en cuestión no se observara o no existiera en el año solicitado, la función de callback también puede devolver una lista vacía. Esto hará que el método "init()" simplemente descarte este día festivo para ese

año.

El módulo Date::Calendar::Profiles exporta las funciones de callback de ejemplo "Advent1()", "Advent2()", "Advent3()", "Advent4()" y "Advent()", que podrían ayudarle

a crear sus propi
os perfiles.

CÓMO CREAR LOS

SUYOS

Cada perfil de calendario (esquema de días festivos) es un

hash.

El nombre del día festivo (como "Navidad", por ejemplo) sirve como clave en este hash y, por lo tanto, debe ser única (a menos que desee anular un valor predeterminado que se estableció anteriormente, pero vea más abajo para más sobre esto)

.

El valor de cada clave es o bien una cadena, que especifica una fórmula de fecha simple, o la referencia de una función de

callback.

Vea la sección "INTERFAZ DE CALLBACK" arriba para una descripción de la interfaz (entrada y salida) de estas funciones de

callback.

Vea la sección "SINTAXIS DE FÓRMULAS DE FECHA" arriba y la descripción del método "init()" en Date::Calendar::Year(3) para la sintaxis exacta de las cadenas de fórmula de

fecha.

TENGA CUIDADO de que si las claves no son únicas en el código fuente, las entradas posteriores sobrescribirán las anteriores! Es

decir, 
...
"Mi día festivo especial" => "01-11",
"Mi día festivo especial" => "02-11",
..
.

no establecerá dos días festivos con el mismo nombre, uno el primero de noviembre y el otro el segundo de noviembre, ¡sino solo uno, el segundo de

noviembre!

Por lo tanto, para usar conjuntos de valores predeterminados y poder anular algunos de ellos, debe PRIMERO incluir cualquier hash que contenga las definiciones predeterminadas, y DESPUÉS escribir sus propias definiciones (vea también el Date::Calendar::Profiles módulo para ejemplos de esto!), así como

esto: 
$defaults =
{
    "Día festivo #1" => "01-01",
    "Día festivo #2" => "02-02",
    "Día festivo #3" => "03-03"
};
$variant1 =
{
    %$defaults,
    "Día festivo #2" => "09-02",
    "Día festivo #4" => "04-04"
}
;

Esto se debe a la forma en que funcionan los hashes en

Perl.

Los números de año después de los nombres no son realmente necesarios, pero nos permiten mostrar la edad actual de la persona. Si este número de año se omite, simplemente no mostramos la

edad.

Ahora, para consultar esta base de datos de cumpleaños, podemos usar el siguiente pequeño

programa: 
#!perl -w
use strict;
no strict "vars";
use Date::Calc qw(:all);
use Date::Calendar;
$Birthdays =
{
    ... # (ver arriba)
};
@today = Today();
$calendar = Date::Calendar->new( $Birthdays );
$calendar->year( $today[0] );
foreach $key (@ARGV)
{
    if (@list = $calendar->search( $key ))
    {
        foreach $date (@list)
        {
            @labels = $calendar->labels( $date );
            $dow = shift(@labels);
            # Más de una persona podría tener el cumpleaños en la misma fecha:
            $name = $key;
            foreach $person (@labels)
            {
                if (index(lc($person),lc($key)) >= 0)
                {
                    $name = $person;
                    last;
                }
            }
            $delta = Delta_Days(@today, $date->date());
            $age = '';
            if ($name =~ s!\s*(\d+)\s*$!!)
            {
                $age = $today[0] - $1;
                $age-- if ($delta > 0);
                $age = sprintf(" (%2d años)", $age);
            }
            printf
            (
                "%-20.20s: %+5d días => %3.3s %2d-%3.3s-%4d%s\n",
                $name,
                $delta,
                $dow,
                $date->day(),
                Month_to_Text($date->month()),
                $date->year(),
                $age
            );
        }
    }
    else { print "¡No se encontró ninguna entrada en la lista de cumpleaños para '$key'!\n" }
}
__END__

LIMITACIONE

S

Los perfiles de calendario incluidos en este módulo generalmente no tienen en cuenta las irregularidades históricas (aunque algunos sí lo hacen para mostrar cómo se puede hacer), solo proporcionan medios para calcular eventos que se repiten regularmente (por lo tanto, no se debe confiar en los perfiles para la

fidelidad h
istórica).

ERRORES

CONOCIDOS

Se sabe que los perfiles de calendario australiano contienen fechas incorrectas. Esto se debe al hecho de que Australia decreta sus festivos individua

lmente para cada año, dificultando el cálculo de los festivos mediante una fórmula. Se está llevando a cabo un esfuerzo para comparar (y corregir) la
implementación actual con documentos oficiales (páginas web) de las autoridades australianas. Esto no se ha terminado todavía porque es muy laborioso.
