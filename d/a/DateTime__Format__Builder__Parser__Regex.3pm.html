DateTime::Format::Builder::Parser::Regex(3) Documentación de Perl aportada por el usuario DateTime::Format::Builder::Parser::Regex(3)

NOMBRE

DateTime::Format::Builder::Parser::Regex - Análisis de fechas basado en expresiones regulares

VERSIÓN

versión 0.83

SINOPSIS

my $parser = DateTime::Format::Builder->create_parser(
    regex  => qr/^(\d\d\d\d)(\d\d)(\d\d)T(\d\d)(\d\d)(\d\d)$/,
    params => [qw( year month day hour minute second )],
);

ESPECIFICACIÓN

Además de las claves comunes, "Regex" soporta:

  • regex

    regex es una expresión regular que debería capturar elementos de la cadena de fecha y hora. Es un elemento requerido. Esta es la clave cuya presencia indica que es una especificación que pertenece a esta clase.

  • params

    params es un arrayref de nombres de claves. Las capturas de la expresión regular se mapean a estos (el primer elemento a $1, el segundo a $2, y así sucesivamente) y se pasan a "DateTime->new". Es un elemento requerido.

  • extra

    extra es un hashref de argumentos adicionales que desea pasar a "DateTime->new". Por ejemplo, podría establecer el "year" o "time_zone" con valores predeterminados:

    extra => { year => 2004, time_zone => "Australia/Sydney" },
  • constructor es un arrayref o un coderef. Si es un arrayref, el primer elemento es un nombre de clase u objeto, y el segundo elemento es un nombre de método (o coderef ya que Perl lo permite). Los argumentos para la llamada son cualquier cosa en $p y cualquier cosa proporcionada en la opción "extra" anterior.

    Si solo se proporciona un coderef, se llama con los argumentos $self, $p y "extra".

    En resumen:

    $self->$coderef( %{$p}, %{ $self->{extra} } );

    Se espera que el método devuelva un objeto DateTime válido, o "undef" en caso de fallo, pero conceptualmente puede devolver lo que quiera. Siempre que sea 'true'.
