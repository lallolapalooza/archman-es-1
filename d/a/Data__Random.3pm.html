rand_date(

)

Esto devuelve una fecha aleatoria en la forma "AAAA-MM-DD". Actualmente no se admiten años de 2 dígitos. Se hacen esfuerzos para asegurar que se le devuelva una fecha verdaderamente válida, es decir, nunca se le devolverá la fecha 31 de febrero. Vea las opciones abajo para averiguar cómo controlar el rango de fechas. Aquí hay algunos

ejemplos: 
# devuelve una fecha en algún lugar entre la fecha actual y un año desde la fecha actual
$date = rand_date();
# devuelve una fecha en algún lugar entre el 21 de septiembre de 1978 y el 21 de septiembre de 1979
$date = rand_date( min => '1978-9-21' );
# devuelve una fecha en algún lugar entre el 21 de septiembre de 1978 y la fecha actual
$date = rand_date( min => '1978-9-21', max => 'now' );
# devuelve una fecha en algún lugar entre la fecha actual y el 21 de septiembre de 2008
$date = rand_date( min => 'now', max => '2008-9-21' )
;

Vea abajo para los parámetros

posibles.
  • min - la fecha mínima a devolver. Debería estar en la forma "AAAA-MM-DD" o puede alternativamente usar la cadena "now" para representar la fecha actual. El valor por defecto es la fecha
    • actual;
  • max - la fecha máxima a devolver. Debería estar en la fo
    • rma "AAAA-MM-DD" o puede alternativamente usar la
cadena "now" para representar la fecha actual. El
valor por defecto es un año desde la fecha mínima;

rand_time(

)

Esto devuelve una hora aleatoria en la forma "HH:MM:SS". Se admiten horas de 24. Vea las opciones abajo para averiguar cómo controlar el rango de horas. Aquí hay algunos

ejemplos: 
# devuelve una hora aleatoria de 24 horas (entre 00:00:00 y 23:59:59)
$time = rand_time();
# devuelve una hora en algún lugar entre 04:00:00 y el final del día
$time = rand_time( min => '4:0:0' );
# devuelve una hora en algún lugar entre 8:00:00 y la hora actual (si es después de las 8:00)
$time = rand_time( min => '12:00:00', max => 'now' );
# devuelve una fecha en algún lugar entre la hora actual y el final del día
$time = rand_time( min => 'now' )
;

Vea abajo para los parámetros

posibles.
  • min - la hora mínima a devolver. Debería estar en la forma "HH:MM:SS" o puede alternativamente usar la cadena "now" para representar la hora actual. El valor por defecto es 00:00:
    • 00;
  • max - la hora máxima a devolver. Debería estar en
    • la forma "HH:MM:SS" o puede alternativament

Esto devuelve una fecha y hora aleatorias en la forma "AAAA-MM-DD HH:MM:SS". Vea las opciones abajo para averiguar cómo controlar el rango de fecha/hora. Aquí hay algunos
