DESCRIPCIÓ

N

DateTime::Set es un módulo para conjuntos de fecha y hora. Puede usarse para manejar dos tipos diferentes de

conjuntos.

El primero es un conjunto fijo de objetos de fecha y hora predefinidos. Por ejemplo, si quisiéramos crear un conjunto de fechas y horas que contuviera los cumpleaños de las personas de nuestra familia para el año

actual.

El segundo tipo de conjunto que puede manejar es uno basado en una recurrencia, como "todos los miércoles", o "mediodía del día 15 de cada mes". Este tipo de conjunto puede tener fechas y horas de inicio y fin fijas, pero ninguna es requerida. Así que nuestro conjunto "todos los miércoles " podría ser "todos los miércoles desde el principio de los tiempos hasta el final de los tiempos", o "todos los miércoles después de 2003-03-05 hasta el final de los tiempos", o "todos los miércoles entre 2003-03-05 y

2004-01-07".

Este módulo también soporta operaciones de matemática de conjuntos, así que puedes hacer cosas como crear un nuevo conjunto a partir de la unión o diferencia de dos conjuntos, comprobar si una fecha y hora es miembro de un conjunto dado,

etc.

Esto es diferente de un "DateTime::Span", que maneja un rango continuo en lugar de puntos individuales de fecha y hora. También hay un módulo "DateTime::SpanSet" para manej

ar conjuntos
de intervalos.

    Los callbacks pueden devolver objetos "DateTime::Infinite::Future" y "DateTime::Infinite::Past", con el fin de definir recurrencias acotadas. En este caso, ambos callbacks 'next' y 'previous' deben estar

    definidos: 
    # "mensual desde $dt hasta siempre"
my $months = DateTime::Set->from_recurrence(
    next => sub {
        return $dt if $_[0] < $dt;
        $_[0]->truncate( to => 'month' );
        $_[0]->add( months => 1 );
        return $_[0];
    },
    previous => sub {
        my $param = $_[0]->clone;
        $_[0]->truncate( to => 'month' );
        $_[0]->subtract( months => 1 ) if $_[0] == $param;
        return $_[0] if $_[0] >= $dt;
        return DateTime::Infinite::Past->new;
    }, );
