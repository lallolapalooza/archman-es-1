NOMBRE

Date::Manip::Lang::italian - Soporte para el idioma italiano.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que soportan el idioma. No está destinado a ser utilizado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DEL IDIOMA

La siguiente es una lista de todas las palabras y expresiones del idioma utilizadas para escribir horas y/o fechas.

Todas las cadenas no distinguen entre mayúsculas y minúsculas.

Palabras delta para avanzar o retroceder en el tiempo
Al analizar deltas, hay palabras que pueden utilizarse para especificar que el delta se referirá a una hora en el futuro o a una hora en el pasado (relativo a alguna fecha). En inglés, por ejemplo, podrías decir:

Palabras ignoradas
Al escribir fechas en formas comunes, hay una serie de palabras que normalmente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar una hora a continuación. En inglés, usarías la palabra AT en el ejemplo:

December 3 at 12:00

Se pueden usar las siguientes palabras:

alle

Otra palabra se utiliza para designar un miembro de un conjunto. En inglés, usarías las palabras IN u OF:

1st day OF December
1st day IN December

Se pueden usar las siguientes palabras:

della
del
di

Otra palabra se utiliza para especificar que algo está en una fecha determinada. En inglés, usarías ON:

ON July 5th

Se pueden usar las siguientes palabras:

di
Palabras que establecen la fecha, la hora, o ambas
Hay algunas palabras que pueden utilizarse para especificar una fecha, una hora, o ambas relativas al ahora.

Las palabras que establecen la fecha son similares a las palabras en inglés 'yesterday' o 'tomorrow'. Estas se especifican como un delta que se añade a la hora actual para obtener una fecha. La hora NO se establece, por lo que el delta solo se usa parcialmente (solo debería incluir año, mes, semana, y de día)

.

Se pueden usar las siguientes

palabras: 
domani               +0:0:0:1:0:0:0
dopodomani           +0:0:0:2:0:0:0
ieri                 -0:0:0:1:0:0:0
l'altroieri          -0:0:0:2:0:0:0
oggi                 0:0:0:0:
0:0:0

Las palabras que establecen solo la hora del día son similares a las palabras en inglés 'noon' o

'midnight'.

Se pueden usar las siguientes

palabras: 
mezzanotte           00:00:00
mezzogiorno          12:
00:00

También están disponibles palabras que establecen la hora y la fecha completas (relativas a la hora y fecha

actuales).

En inglés, la palabra 'now' es una de

estas.

Se pueden usar las siguientes

palabras:

0:

Separadores de Hora/Minuto/Segu
ndo
Al especificar la hora del día, el separador más común es los dos puntos (:) que puede usarse para ambos separadores.

Algunos idiomas usan pares diferentes. Por ejemplo, el francés permite especificar la hora como 13h30:20, por lo que usaría los siguientes

pares: 
: :
h :

La primera columna es el separador hora-minuto y la segunda columna es el separador minuto-segundo. Ambas son expresiones regulares de perl. Al crear una nueva traducción, tenga en cuenta que las expresiones regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no incluya la expresión '[x]' donde 'x' es un carácter

utf-8.

Un par de dos puntos SIEMPRE está permitido para todos los idiomas. Si un idioma permite pares adicionales, se

listan aquí:
