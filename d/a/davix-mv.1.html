NOMBRE

davix-mv - Herramienta de renombrado basada en libdavix

SINOPSIS


davix-mv [opciones]... url-original url-nuevo

DESCRIPCIÓN

davix-mv es una herramienta para renombrar/mover recursos con servicios compatibles con HTTP, Webdav o REST.
Los comandos pueden renombrar/mover recursos y contenedores de recursos.

davix-mv está impulsado por libdavix. Consulte libdavix(3) para más detalles.

OPCIONES

Opciones Comunes:

--debug
Modo de depuración
--header, -H
Añadir un campo de cabecera a la solicitud (ej: -H "Depth: 1" )
--help, -h
Mostrar este mensaje de ayuda
--metalink OPT
Soporte Metalink. (OPT=failover[predeterminado]|no)
--module, -P NOMBRE_PLUGIN
Cargar un plugin o perfil por nombre
--redirection OPT
Soporte de redirección transparente. (OPT=yes[predeterminado]|no)
--proxy, -x URL
Servidor proxy SOCKS5 URL. (ej: socks5://login:pass@socks.example.org)
--trace
Rastrea ámbitos específicos, las opciones incluyen:
file - Interfaz de archivo de Davix
posix - Interfaz POSIX de Davix
xml - Salida del analizador XML
ssl - Detalles de SSL y certificados
header - Cabeceras de consultas HTTP
body - Cuerpos de consultas HTTP
chain - Información de cadenas de E/S
core - Información de configuración y miscelánea
grid - Información miscelánea de terceros
socket - Información de sockets
locks - Información de bloqueo WebDAV
all - Rastrea todo
--version
Mostrar versión

Opciones de Seguridad:

--capath RUTA_CA
Añadir un directorio adicional de autoridad certificadora
--cert, -E RUTA_CREDENCIAL
Certificado de cliente en formato PEM
--key RUTA_PRIVADA
Clave privada en formato PEM
--insecure, -k
Desactivar comprobaciones de credenciales SSL
--userlogin
Nombre de usuario para autenticación de inicio de sesión/contraseña
--userpass
Contraseña de usuario para autenticación de inicio de sesión/contraseña
--s3secretkey
Autenticación AWS S3: clave secreta
--s3accesskey
Autenticación AWS S3: clave de acceso
--s3region
Autenticación AWS S3: región
--s3token
Token de seguridad AWS S3 - utilizado junto con credenciales temporales de STS
--s3alternate
Especificar este indicador si necesita utilizar una URL S3 basada en ruta
--azurekey
Clave de autenticación de Azure

EJEMPLOS

Renombrar un recurso sobre HTTP
davix-mv http://example.org/rename_me.txt http://example.org/thanks.txt

Mover un recurso en un Almacenamiento de Red con autenticación VOMS
davix-mv -P grid davs://grid-storage.example.org/dir1/dir2/move_me.txt davs://grid-storage.example.org/dir1/move_me.txt
