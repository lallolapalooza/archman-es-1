NOMBRE

Date::Language::Bulgarian - localización para Date::Format

DESCRIPCIÓN

Esta es la localización búlgara para Date::Format. Es importante notar que el código fuente de este módulo está en utf8. Todas las cadenas que produce están en utf8, por lo que actualmente solo es seguro usarlo con inglés. Se le deja solo para intentar convertir la salida al usar diferentes Date::Language::* en la misma aplicación. Esto debería ser abordado en el futuro.

SINOPSIS

use strict; 
use warnings;
use Date::Language;
local $\=$/;
my $template ='%a %b %e %T %Y (%Y-%m-%d %H:%M:%S)';
my $time=1290883821; #o simplemente usa time();
my @lt = localtime($time);
my %languages = qw(English GMT German EEST Bulgarian EET);
binmode(select,':utf8');
foreach my $l(keys %languages){
    my $lang = Date::Language->new($l);
    my $zone = $languages{$l};
    print $/. "$l $zone";
    print $lang->time2str($template, $time);
    print $lang->time2str($template, $time, $zone);
    print $lang->strftime($template, \@lt);
}
