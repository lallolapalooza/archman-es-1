Data::Dump::Filtered(3) Documentación de Perl aportada por el usuario Data::Dump::Filtered(3)

NOMBRE

Data::Dump::Filtered - Impresión bonita con filtrado

DESCRIPCIÓN

Se proporcionan las siguientes funciones:

add_dump_filter( \&filtro )
Registra una función de filtro para ser utilizada por la función regular Data::Dump::dump(). Por defecto, no hay filtros activos.

Dado que registrar filtros tiene un efecto global, puede ser más apropiado usar la función dump_filtered() en su lugar.

remove_dump_filter( \&filtro )
Anula el registro de la función de devolución de llamada dada como función de filtro. Esto deshace el efecto de add_filter.
dump_filtered(..., \&filtro )
Funciona como Data::Dump::dump(), pero el último argumento debe ser una función de devolución de llamada de filtro. A medida que se visitan los objetos, se invoca la función de devolución de llamada del filtro, la cual puede influir en cómo se imprimen los objetos.

Todos los filtros registrados con add_filter() se ignoran cuando se invoca esta interfaz. De hecho, se permite pasar "undef" como \&filtro, y "dump_filtered(..., undef)" es la forma oficial de forzar impresiones sin filtrar.

Función de devolución de llamada de filtro

Una función de devolución de llamada de filtro es una función que se invocará con 2 argumentos: un objeto de contexto y una referencia al objeto que se está visitando actualmente. El valor de retorno debe ser una referencia a un hash o "undef".

sub filter_callback {
    my($ctx, $object_ref) = @_;
    ...
    return { ... }
}

Si la función de devolución de llamada del filtro devuelve "undef" (o nada), se procesa y formatea normalmente el objeto visitado. Si la función de devolución de llamada del filtro devuelve un hash, puede reemplazar o anotar la representación del objeto actual.

Contexto del filtro

El objeto de contexto proporciona métodos que se pueden utilizar para determinar qué tipo de objeto se está visitando actualmente y dónde se encuentra. El objeto de contexto tiene la siguiente interfaz:

$ctx->object_ref
Forma alternativa de obtener una referencia al objeto actual
$ctx->class
Si el objeto está "bendecido" (blessed), esto devuelve la clase. Devuelve "" para objetos no bendecidos.
$ctx->reftype
Devuelve qué tipo de objeto es. Es una cadena como "SCALAR", "ARRAY", "HASH", "CODE", ...
$ctx->is_ref
Devuelve verdadero si se proporcionó una referencia.
$ctx->is_blessed
Devuelve verdadero si el objeto está bendecido. De hecho, esto es solo un alias para "$ctx->class".
$ctx->is_array
Devuelve verdadero si el objeto es un array.
$ctx->is_hash
Devuelve verdadero si el objeto es un hash.
$ctx->is_scalar
Devuelve verdadero si el objeto es un escalar (una cadena o un número).
$ctx->is_code
Devuelve verdadero si el objeto es una función (también conocida como subrutina).
$ctx->container_class
Devuelve la clase del contenedor más interno que contiene este objeto. Devuelve "" si no hay un contenedor bendecido.
$ctx->container_self
Devuelve una expresión textual relativa al objeto contenedor que nombra este objeto. La variable $self en esta expresión es el propio contenedor.
$ctx->object_isa( $class )
Devuelve VERDADERO si el objeto actual es de la clase dada o de una subclase.
$ctx->container_isa( $class )
Devuelve VERDADERO si el contenedor más interno es de la clase dada o de una subclase.
$ctx->depth
Devuelve cuántos niveles de profundidad se ha recurrido en la estructura (a partir de los argumentos originales de dump_filtered()).
$ctx->expr
$ctx->expr( $top_level_name )
Devuelve una expresión textual que denota el objeto actual. En la expresión, $var se utiliza como el nombre del objeto de nivel superior impreso. Esto se puede anular proporcionando un nombre diferente como argumento.

Hash de retorno del filtro

Los siguientes elementos tienen importancia en el hash devuelto:

dump => $cadena
incorpora la cadena dada como la representación del valor actual
object => $valor
imprime el valor dado en lugar del que se visitó y se pasó como $object. Básicamente lo mismo que especificar "dump => Data::Dump::dump($valor)".
comment => $comentario
antepone al valor la cadena de comentario dada
bless => $clase
hace que parezca que el objeto actual es de la $clase dada en lugar de la clase que realmente tiene (si la tiene). Los internos del objeto se imprimen de la manera habitual. La $clase puede ser la cadena vacía para que Data::Dump pretenda que el objeto no estaba bendecido en absoluto.
hide_keys => ['clave1', 'clave2',...]
hide_keys => \&código
Si el $object es un hash, se imprime normalmente pero pretendiendo que las claves listadas no existían. Si el argumento es una función, se llama a la función para determinar si la clave dada debe ocultarse.
