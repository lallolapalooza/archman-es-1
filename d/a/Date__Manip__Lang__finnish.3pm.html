NOMBRE

Date::Manip::Lang::finnish - Soporte del idioma finés.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que soportan el idioma. No está destinado a ser utilizado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DEL IDIOMA

La siguiente es una lista de todas las palabras y expresiones del idioma utilizadas para escribir horas y/o fechas.

Todas las cadenas no distinguen entre mayúsculas y minúsculas.

Horas de la mañana/tarde
Esta es una lista de expresiones utilizadas para designar la hora de la mañana o la tarde cuando una hora se introduce como una hora de 12 en lugar de una de 24. Por ejemplo, en inglés, la hora "17:00" podría especificarse como "5:00 PM".

La hora de la mañana y la tarde puede designarse por los siguientes conjuntos de palabras:

A.M.

Cada o todos
Hay una lista de palabras que especifican cada ocurrencia de algo. Se utilizan en las siguientes frases: 
CADA lunes
TODOS los lunes
TODOS los meses

Se pueden usar las siguientes palabras:

joka
jokainen
Ocurrencia siguiente/anterior/última
Hay una lista de palabras que pueden usarse para especificar la siguiente, anterior, o última ocurrencia de algo. Estas palabras podrían usarse en las siguientes frases: 
PRÓXIMA semana
ÚLTIMO martes
ANTERIOR martes
ÚLTIMO día del mes

Se pueden usar las siguientes palabras:

Ocurrencia siguiente:

ensi

Ocurrencia anterior:

viime

Ocurrencia última:

viimeinen
Palabras delta para avanzar/retroceder en el tiempo
Al analizar deltas, hay palabras que pueden usarse para especificar que el delta se referirá a una hora en el futuro o a una hora en el pasado (relativo a alguna fecha). En inglés, por ejemplo, podrías decir: 
EN 5 días
5 días ATRÁS

Se pueden usar las siguientes palabras para especificar deltas que se refieren a fechas en el pasado o futuro respectivamente:

sitten
ssa
myöhemmin
myohemmin

Palabras ignoradas
Al escribir fechas en formas comunes, hay un número de palabras que normalmente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar una hora a continuación. En inglés, usarías la palabra AT en el ejemplo:

3 de diciembre a las 12:00

Se pueden usar las siguientes palabras:

kello

Se usa otra palabra para designar un miembro de un conjunto. En inglés, usarías las palabras IN u OF:

1er día DE diciembre
1er día EN diciembre

Se pueden usar las siguientes palabras:

No definido en este idioma

Se usa otra palabra para especificar que algo está en una fecha determinada. En inglés, usarías ON:

El 5 de julio

Se pueden usar las siguientes palabras:

No definido en este idioma
Palabras que establecen la fecha, la hora, o ambas
Hay algunas palabras que pueden usarse para especificar una fecha, una hora, o ambas en relación con el momento actual.

Las palabras que establecen la fecha son similares a las palabras en inglés 'yesterday' o 'tomorrow'. Se especifican como un delta que se añade a la hora actual para obtener una fecha. Sin embargo, la hora NO se establece, por lo que el delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana y día).

Se pueden usar las siguientes palabras:

huomenna             +0:0:0:1:0:0:0
tanaan               0:0:0:0:0:0:0
toissapaivana        -0:0:0:2:0:0:0
toissapäivänä        -0:0:0:2:0:0:0
tänään               0:0:0:0:0:0:0
yesterdayeilen       -0:0:0:1:0:0:0
ylihuomenna          +0:0:0:2:0:0:0

Las palabras que establecen solo la hora del día son similares a las palabras en inglés 'noon' o 'midnight'.

Se pueden usar las siguientes palabras:

keskipaiva           12:00:00
keskipaivalla        12:00:00
keskipäivä           12:00:00
keskipäivällä        12:00:00
keskiyo              00:00:00
keskiyolla           00:00:00
keskiyö              00:00:00
keskiyöllä           00:00:00

También están disponibles palabras que establecen la hora y la fecha completas (en relación con la hora y fecha actuales).

En inglés, la palabra 'now' es una de estas.

Se pueden usar las siguientes palabras:

nyt                  0:0:0:0:0:0:0
Separadores de hora/minuto/segundo
Al especificar la hora del día, el separador más común es los dos puntos (:) que puede usarse para ambos separadores.

Algunos idiomas usan pares diferentes. Por ejemplo, el francés permite especificar la hora como 13h30:20, por lo que usaría los siguientes pares:

: :
h :

La primera columna es el separador hora-minuto y la segunda columna es el separador minuto-segundo. Ambas son expresiones regulares de perl. Al crear una nueva traducción, ten en cuenta que las expresiones regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no incluyas la expresión '[x]' donde 'x' es un carácter utf-8.

Un par de dos puntos SIEMPRE está permitido para todos los idiomas. Si un idioma permite pares adicionales, se listan aquí:

\.  \.
Separador de segundos fraccionarios
Al especificar segundos fraccionarios, la forma más común es usar un punto decimal (.). Algunos idiomas pueden especificar un separador diferente que podría usarse. Si se hace esto, es una expresión regular.

El punto decimal SIEMPRE está permitido para todos los idiomas. Si un idioma permite otro separador, se lista aquí:

No definido en este idioma
