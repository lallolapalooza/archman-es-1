Todos estos métodos devuelven una referencia a un array que contiene los datos

especificados.

Los métodos con "format" en el nombre deben devolver cadenas que puedan usarse como parte de una cadena, como "the month of July". Los valores independientes (stand alone) son para su uso en cosas como calendarios en oposición a una

oración.

Las formas estrechas (narrow) pueden no ser únicas (por ejemplo, en el encabezado de columna de días de un calendario está bien tener "T" tanto para Tuesday como para Thursday)

.

El nombre amplio (wide) siempre debe ser el nombre completo de la cosa en cuestión. El nombre estrecho (narrow) debe ser de solo uno o dos

caracteres.

Estos métodos devuelven una referencia a los datos almacenados en el objeto de configuración regional. Si cambias el contenido de esta referencia, esto afectará a los datos en el objeto de configuración regional. ¡Debes clonar los d

atos primero si qu
ieres modificarlos.

Estos métodos devuelven cadenas apropiadas para el "DateTime->format_cldr" método.

$locale->format_for($name)

Se acceden pasando un nombre a "$locale->format_for(...)", donde el nombre es un especificador de formato estilo CLDR.

El valor de retorno es una cadena adecuada para pasar a "$dt->format_cldr", por lo que puede hacer algo como esto:

print $dt->format_cldr( $dt->locale->format_for('MMMdd') )

que para la configuración regional "en" imprimiría algo como "08 Jul".

Tenga en cuenta que la localización también puede incluir texto adicional específico de la configuración regional. Por ejemplo, el formato "MMMMd" para la configuración regional "zh" incluye los caracteres chinos para "día" (日) y mes (月), por lo que obtiene algo como "8月23日".

$locale->available_formats

Debería devolver una lista de todos los nombres de formato que podrían pasarse a "$locale->format_for".

Consulte la documentación de las configuraciones regionales individuales para obtener detalles y ejemplos de estos formatos. Los nombres de formato disponibles varían según la configuración regional.

$locale->glibc_datetime_format

$locale->glibc_date_format

$locale->glibc_date_1_format

$locale->glibc_time_format

$locale->glibc_time_12_format

Estos métodos devuelven cadenas apropiadas para el "DateTime->strftime" método. Sin embargo, se le anima encarecidamente a utilizar los otros métodos de formato, que utilizan los datos de formato CLDR. Se incluyen principalmente para el beneficio de DateTime::Format::Strptime.

$locale->version

La versión de CLDR a partir de la cual se generó esta configuración regional.

$locale->prefers_24_hour_time

Devuelve un booleano que indica si la configuración regional prefiere o no el formato de 24 horas.

$locale->first_day_of_week

Devuelve un número del 1 al 7 que indica el local primer día de la semana, siendo el lunes 1 y el domingo 7.

$locale->locale_data

Devuelve una clonación de los datos originales utilizados para crear esta configuración regional como un hash. Esto está aquí para facilitar la creación de configuraciones regionales personalizadas a través de "DateTime::Locale-"register_data_locale>.
