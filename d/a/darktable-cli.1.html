NOMBRE

darktable-cli - una variante de línea de comandos de darktable

SINOPSIS

darktable-cli IMG_1234.{RAW,...} [<archivo xmp>] <archivo de salida> [opciones] [--core <opciones de darktable>]

Opciones:

--width <ancho máximo>
--height <altura máxima>
--bpp <bpp>
--hq <0|1|false|true>
--upscale <0|1|false|true>
--export_masks <0|1|false|true>
--style <nombre del estilo>
--style-overwrite
--apply-custom-presets <0|1|false|true>
--verbose
--help
--version

DESCRIPCIÓN

darktable es una aplicación de flujo de trabajo de fotografía digital para Linux, Mac OS X y varios otros Unices. Se describe con más detalle en darktable(1).

darktable-cli es una variante de línea de comandos para exportar imágenes dado el archivo raw y el archivo xmp asociado.

OPCIONES

El usuario debe proporcionar un nombre de archivo de entrada y un nombre de archivo de salida. Todos los demás parámetros son opcionales.

<archivo de entrada>
El nombre del archivo de entrada a exportar.
<archivo xmp>
El nombre opcional de un archivo lateral XMP que contiene los datos de la pila de historial a aplicar durante la exportación. Si esta opción no se proporciona, darktable buscará un archivo XMP que pertenezca al archivo de entrada dado.
<archivo de salida>
El nombre del archivo de salida. darktable deriva el formato del archivo de exportación de la extensión del archivo. También puede usar todas las variables disponibles en el módulo de exportación de darktable en el nombre del archivo de salida.
--width <ancho máximo>
Este parámetro opcional permite limitar el ancho de la imagen exportada a ese número de píxeles.
--height <altura máxima>
Este parámetro opcional permite limitar la altura de la imagen exportada a ese número de píxeles.
--bpp <bpp>
Un parámetro opcional para definir la profundidad de bits de la imagen exportada; los valores permitidos dependen del formato del archivo. Actualmente, esta opción aún no es funcional. Si necesita definir la profundidad de bits, necesita usar la siguiente solución: 
--core --conf plugins/imageio/format/<FORMATO>/bpp=<VALOR>

donde FORMATO es el nombre del formato de salida seleccionado, por ejemplo, png.

--hq <0|1|true|false>
Un indicador que define si se debe usar remuestreo de alta calidad durante la exportación. Predeterminado a true.
--upscale <0|1|true|false>
Un indicador que define si se permite la ampliación durante la exportación. Predeterminado a false.
--export_masks <0|1|true|false>
Un indicador que define si las máscaras utilizadas en la imagen se almacenarán como capas en la imagen exportada (siempre que el formato lo admita). Predeterminado a false.
--style <nombre del estilo>
Especifica el nombre de un estilo que se aplicará durante la exportación. Si se especifica un estilo, también se debe especificar la ruta al directorio de configuración de darktable (es decir, --core --configdir ~/.config/darktable). Predeterminado a ningún estilo especificado.
--style-overwrite
El estilo especificado sobrescribe la pila de historial en lugar de añadirse a ella.
--apply-custom-presets
Con esta opción puede decidir si darktable carga su conjunto de parámetros predeterminados desde data.db y los aplica. De lo contrario, se usan los predeterminados que vienen con darktable.

Establezca este indicador en false para ejecutar múltiples instancias.

--verbose
Habilita la salida detallada.
--core <opciones de darktable>
Todos los parámetros de línea de comandos que siguen a --core se pasan al núcleo de darktable y se manejan como parámetros estándar. Consulte darktable(1) para obtener una descripción detallada de las opciones.
