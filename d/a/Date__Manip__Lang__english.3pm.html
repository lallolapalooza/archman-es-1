NOMBRE

Date::Manip::Lang::english - Soporte del idioma inglés.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que soportan el idioma. No está destinado a ser usado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DE IDIOMA

La siguiente es una lista de todas las palabras y expresiones de idioma usadas para escribir horas y/o fechas.

Todas las cadenas no distinguen entre mayúsculas y minúsculas.

Palabras ignoradas
Al escribir fechas en formas comunes, hay un número de palabras que típicamente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar una hora a continuación. En inglés, usarías la palabra AT en el ejemplo:

December 3 at 12:00

Se pueden usar las siguientes palabras:

at

Otra palabra se usa para designar un miembro de un conjunto. En inglés, usarías las palabras IN o OF:

1st day OF December
1st day IN December

Se pueden usar las siguientes palabras:

of
in

Otra palabra se usa para especificar que algo está en una cierta fecha. En inglés, usarías ON:

ON July 5th

Se pueden usar las siguientes palabras:

on
Palabras que establecen la fecha, la hora, o ambas
Hay algunas palabras que pueden usarse para especificar una fecha, una hora, o ambas relativas a ahora.

Las palabras que establecen la fecha son similares a las palabras en inglés 'yesterday' o 'tomorrow'. Se especifican como un delta que se añade a la hora actual para obtener una fecha. La hora NO se establece sin embargo, así que el delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana y día).

Se pueden usar las siguientes palabras:

ereyesterday         -0:0:0:2:0:0:0
overmorrow           +0:0:0:2:0:0:0
today                0:0:0:0:0:0:0
tomorrow             +0:0:0:1:0:0:0
yesterday            -0:0:0:1:0:0:0

Las palabras que establecen solo la hora del día son similares a las palabras en inglés 'noon' o 'midnight'.

Se pueden usar las siguientes palabras:

midnight             00:00:00
noon                 12:00:00

También están disponibles palabras que establecen la hora y fecha completas (relativas a la hora y fecha actuales).

En inglés, la palabra 'now' es una de estas.

Se pueden usar las siguientes palabras:

now                  0:0:0:0:0:0:0
Separadores de hora/minuto/segundoAl especificar la hora del día, el separador más común es los dos puntos (:) el cual puede usarse para ambos separadores.

Algunos idiomas usan pares diferentes. Por ejemplo, el francés permite especificar la hora como 13h30:20, por lo que usaría los siguientes

pares: 
: :
h :

La primera columna es el separador hora-minuto y la segunda columna es el separador minuto-segundo. Ambas son expresiones regulares de perl. Al crear una nueva traducción, tenga en cuenta que las expresiones regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no incluya la expresión '[x]' donde 'x' es un carácter

utf-8.

Un par de dos puntos SIEMPRE está permitido para todos los idiomas. Si un idioma permite pares adicionales, se enumeran

aquí: 
No defini
do en este idioma
