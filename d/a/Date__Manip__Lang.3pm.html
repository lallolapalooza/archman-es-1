Cada término está definido en el documento Date::Manip::Lang::english (o en cualquiera de los documentos de los otros módulos de idioma), así que por favor consulta para averiguar qué significa cada elemento. Luego reemplaza la versión en inglés

Hay algunos requisitos:

1) Cada elemento debe estar definido (excepto los elementos sephm y sepms, que son opcionales)

.

2) El módulo debe estar escrito usando caracteres UTF-8 si el idioma incluye algún

carácter no ASCII.

3) Cada elemento incluye una lista de valores (diferentes variaciones del elemento). En la mayoría de los casos, el orden de los valores para cada elemento no es importante, ya que solo se utilizan para crear una expresión regular para analizar fechas, pero algunos de ellos también se usan para determinar valores imprimibles

usando el método

printf"

(o la función "UnixDate" [[50]]). Estos elementos son: Elemento directiva printf ampm %p day_abb %a day_char %v day_name %A month_abb %b month_name

%B nth %E 
Para cada uno de estos, el valor que debe imprimirse debe
        ser el primer valor de la
lista.

4) Cuando sea posible, si un idioma incluye caracteres que son esencialmente caracteres ASCII con un signo de puntuación, por favor incluye una variación del valor que sea solo ASCII sin el signo de puntuación. Por ejemplo, el nombre en español para Sábado en ASCII sería escrito sabado, pero en realidad, la primera 'a' tiene un acento encima. Esta palabra debe aparecer dos veces... primero en codificación UTF-8 completa, y segundo como todo ASCII. Si el idioma (ruso, por ejemplo) no tiene equivalente ASCII, solo

incluye la representación UTF-8.
