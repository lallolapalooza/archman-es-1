Paquete: perl-datetime-timezone

Licencias: GPL, PerlArtistic

DateTime::TimeZone::Catalog(3) Documentación de Perl aportada por el usuario DateTime::TimeZone::Catalog(3)

NOMBRE

DateTime::TimeZone::Catalog - Proporciona una lista de todos los nombres de zona horaria válidos

DESCRIPCIÓN

Este módulo contiene una lista enumerada de todas las zonas horarias del sistema conocidas, para que las aplicaciones puedan presentar fácilmente una lista de zonas horarias.
