DESCRIPCIÓ

N

Los objetos FBB::DateTime contienen y representan valores de fecha y hora. Se pueden solicitar o modificar campos individuales de fecha y hora, devolviendo tiempos «sanitizados» (por ejemplo, nunca se devuelve una fecha como el 33 de marzo o una hora como las 56 horas; en su lugar se devuelve el siguiente mes o día). Los tiempos pueden especificarse en hora local (según la idea que tenga el ordenador de cuál es la hora local), en Hora Universal Coordinada (UTC), como hora en una zona horaria con nombre, o como hora en una zona horaria definida por el usuario. Consulte la sección ZONAS HORARIAS más abajo para una descripción detallada de cómo se pueden especificar las zonas

horarias.

Las fechas/horas representadas por los objetos DateTime pueden modificarse sumando, restando o estableciendo (std::chrono) segundos, minutos u horas, o especificando (una selección de) campos de las estructur

as tm.

Las modificaciones de fecha/hora se realizan siempre en relación con la zona horaria actual del objeto DateTime (que puede ser UTC, local u otra zona horaria). También se admiten conversiones entre zonas horarias (incluida la «zona horaria» UTC)

.

Los objetos DateTime pueden construirse de muchas maneras. Las fechas y horas pueden especificarse como hora UTC, como hora local, como (std::chrono::minutes) desplazamientos con respecto a la hora UTC, o como fecha y hora en otras zonas horarias (definidas por el usuario). Los desplazamientos negativos de tiempo se refieren a zonas horarias al oeste de Greenwich, y los desplazamientos positivos se refieren a zonas horarias al este de Greenwich: estos desplazamientos representan las diferencias de hora local de las zonas con la hora UTC. Los desplazamientos de zona horaria se calculan siempre módulo 12 horas, ya que las zonas horarias pueden diferir como máximo 12 horas de la

UTC.

Los objetos DateTime siempre contienen puntos de fecha y hora en segundos desde el comienzo de la «época» (medianoche del 1 de enero de 1970 UTC). La función C time(2) devuelve este valor para la fecha y hora actuales (suponiendo que el reloj del ordenador se haya sincronizado correctamente)

.

El Horario de Verano (DST), cuando está definido para las zonas de los objetos DateTime, se aplica automáticamente cuando el DST está activo. Por ejemplo, cuando la hora de un objeto DateTime representa las 12:00 h., y el DST de su zona (usando un desplazamiento estándar de +1 hora) se activa mañana, entonces la hora del objeto muestra las 13:00 h. cuando se añade 1 día a su fecha/hora

actual.

Manejar el tiempo es complejo. La función C time(2) devuelve el tiempo en segundos desde el comienzo de la época. Más allá de eso, la simplicidad termina, y se remite al lector a la cobertura de las complejidades del manejo del tiempo de Eric S. Raymond (2007): véase http://www.catb.org/esr/time-programming (este documen

to también está incluido en
el repositorio de bobcat).

ZONAS

HORARIAS

La clase anidada Zone de DateTime se usa para especificar las zonas horarias. Las zonas horarias tienen varios componentes

configurables:
o
El propio desplazamiento de tiempo. Por ejemplo, la Hora de Europa Central (CET) usa un desplazamiento de una hora: cuando es mediodía en UTC, entonces son las 13:00 h. CET. El desplazamiento de tiempo no tiene que ser múltiplos de horas completas. Por ejemplo, la India usa un desplazamiento de tiempo de +5:30 h. con respecto a la
UTC.
o
Quizás un Horario de Verano (DST). La mayoría de las zonas horarias usan un desplazamiento de DST de +1 hora: cuando en el ejemplo anterior el DST está activo, entonces la hora local de CET es las 14:00 h. Algunos países no usan desplazamientos de DST. Por ejemplo, Afganistán no usa un desplazamiento de
DST.
o
Un intervalo de fechas en el que se usa el DST puede ser estándar. Por ejemplo, comienza a las 02:00 h. (hora local, convirtiéndose en 03:00 DST), el último domingo de marzo, y termina a las 02:00 h. (hora local, restableciendo el DST de 03:00 a 02:00) el último domingo de
octubre.
o
Pueden aplicarse otros intervalos de calendario. Por ejemplo, en 2019 el DST de Nueva Zelanda comienza el 29 de septiembre y termina el 7 de
abril.
o
En la práctica, los desplazamientos de
DST son iguales a 1 hora, aunque no ha
y un requisito formal para ello.

La clase DataTime::Zone ofrece una variedad de medios para especificar zonas horarias con o sin soporte para DST. Los desplazamientos de tiempo pueden ser positivos o negativos y se especifican en horas y opcionalmente en minutos. Por ejemplo, -8 o -8:00 para una zona horaria 8 horas antes que la UTC (mediodía en UTC se convierte en las 04:00 en esta zona horaria) o +5:30 para una zona horaria después que la UTC (mediodía en UTC se convierte en las 17:30 en esa zona horaria). Las zonas horarias pueden darse nombres (que pueden o no ser los nombres de las zonas horarias «estándar» como CET o PST) pero también pueden construirse

proporcionando
o
un mero desplazamiento con respecto a la UTC, sin
DST.
o
un desplazamiento con respecto a la UTC, usando un desplazamiento de tiempo DST estándar (1 hora). En este caso se usa la idea que tiene el ordenador del intervalo de calendario en el que el DST está
activo;
o
un desplazamiento con respecto a la UTC, usando un desplazamien
to de tiempo DST especificado así como un intervalo de ca
lendario especificado, especificando opcionalmente la hora en
la que el intervalo de calendario del DST comienza y/o termina.

#include <iostream>
#include "../datetime"
using namespace std;
using namespace FBB;
void show(DateTime const &dt, char const *label)
{
    cout <<
        label << ": " << dt << "\n"
        "dst: " << dt.dst() << "\n"
        "hh:mm:ss: " << dt.hours() << ’:’ << dt.minutes() << ’:’ <<
                        dt.seconds() << "\n"
        "year-month-monthdaynr: " << dt.year() << ’-’ << dt.month() << ’-’ <<
                                     dt.monthDayNr() << &quot;\n"
        "weekday/weeknr/yearday/yeardaynr: " <<
            dt.weekday() << ’/’ << dt.weekNr() << ’/’ <<
            dt.yearDay() << ’/’ << dt.yearDayNr() << "\n"
        "\n";
}
int main()
{
    time_t now = time(0);
    DateTime utc{ now, DateTime::UTC };
    show(utc, "Hora UTC actual");
    DateTime local{ utc.thisTime() };
    cout << "LA HORA LOCAL DEL ORDENADOR: " << local << ’\n’;
    DateTime dt{ now, DateTime::LOCALTIME };
    show(dt, "Hora LOCAL actual");
    DateTime utc2{ dt.utc() };
    cout << "UTC obtenido de la Hora LOCAL: " << utc2 << ’\n’;
    DateTime jan1{ "2019-01-01 13:00:00+01:00", DateTime::LOCALTIME };
    cout << "1 de enero de 1919, 13:00h: " << jan1 << ’\n’;
    show(jan1, "1 de enero, detalles:");
    cout << "\nOpcionalmente, vuelva a ejecutar especificando otra especificación de zona horaria\n"
            "\n";
}
