NOMBRE

Data::Perl::Collection::Hash::MooseLike - Subclase de Collection::Hash que simula los rasgos nativos de Moose.

VERSIÓN

versión 0.001009

SINOPSIS

use Data::Perl::Collection::Hash::MooseLike;
my $hash = Data::Perl::Collection::Hash::MooseLike->new(a => 1, b => 2);
$hash->values; # (1, 2)
$hash->set('foo', 'bar'); # (a => 1, b => 2, foo => 'bar')

DESCRIPCIÓN

Esta clase proporciona un envoltorio y métodos para interactuar con un hash. Todos los métodos están escritos para emular/coincidir con el comportamiento existente en los rasgos nativos de Moose.

DIFERENCIAS EN LA FUNCIONALIDAD

get($key, $key, ...)
Devuelve valores del hash.

En contexto de lista, devuelve una lista de valores en el hash para las claves dadas. En contexto escalar, devuelve el valor para la última clave especificada.

set($key, $value, ...)
Establece los elementos en el hash a los valores dados. Devuelve los nuevos valores establecidos para cada clave, en el mismo orden que las claves pasadas al método.

Este método requiere al menos dos argumentos y espera un número par de argumentos.

delete($key, $key, ...)
Elimina los elementos con las claves dadas.

En contexto de lista, devuelve una lista de valores en el hash para las claves eliminadas. En contexto escalar, devuelve el valor para la última clave especificada.
