NOMBRE

Date::Manip::Lang::swedish - Soporte para el idioma sueco.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que soportan el idioma. No está destinado a ser utilizado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DEL IDIOMA

La siguiente es una lista de todas las palabras y expresiones del idioma utilizadas para escribir horas y/o fechas.

Todas las cadenas no distinguen entre mayúsculas y minúsculas.

Horas de la mañana/tarde
Esta es una lista de expresiones utilizadas para designar la hora de la mañana o de la tarde cuando una hora se introduce como una hora de 12 en lugar de una hora de 24. Por ejemplo, en inglés, la hora "17:00" podría especificarse como "5:00 PM".

La hora de la mañana y de la tarde puede designarse por los siguientes conjuntos de palabras:

FM
EM
Cada o todos
Hay una lista de palabras que especifican cada ocurrencia de algo. Estas se utilizan en las siguientes frases:

Ocurrencia siguiente/anterior/última

Palabras delta para avanzar/retroceder en el tiempo
Al analizar deltas, hay palabras que pueden usarse para especificar que el delta se referirá a una hora en el futuro o a una hora en el pasado (relativo a alguna fecha). En inglés, por ejemplo, podrías decir: 
EN 5 días
5 días ATRÁS

Se pueden usar las siguientes palabras para especificar deltas que se refieren a fechas en el pasado o futuro respectivamente:

sedan
om
senare
Modo de negocio
Esto contiene dos listas de palabras que pueden usarse para especificar un delta estándar (es decir, no de negocio) o un delta de negocio.

Anteriormente, se usaba para indicar si el delta era aproximado o exacto, pero ahora esta lista no se usa excepto para forzar el delta a ser estándar.

Se pueden usar las siguientes palabras:

Se pueden usar las siguientes palabras para especificar un delta de negocio:

Palabras ignoradas
Al escribir fechas en formas comunes, hay varias palabras que típicamente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar una hora a continuación. En inglés, usarías la palabra AT en el ejemplo:

3 de diciembre a las 12:00

Se pueden usar las siguientes palabras:

kl
kl.
klockan

Otra palabra se usa para designar un miembro de un conjunto. En inglés, usarías las palabras IN o OF:

1er día DE diciembre
1er día EN diciembre

Se pueden usar las siguientes palabras:

om

Otra palabra se usa para especificar que algo está en una fecha determinada. En inglés, usarías ON:

EL 5 de julio

Se pueden usar las siguientes palabras:

pa
på
Palabras que establecen la fecha, la hora, o ambas
Hay algunas palabras que pueden usarse para especificar una fecha, una hora, o ambas respecto al ahora.

Las palabras que establecen la fecha son similares a las palabras en inglés 'ayer' o 'mañana'. Se especifican como un delta que se añade a la hora actual para obtener una fecha. La hora NO se establece, sin embargo, así que el delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana y día).

Se pueden usar las siguientes palabras:

i dag                0:0:0:0:0:0:0
i gar                -0:0:0:1:0:0:0
i går                -0:0:0:1:0:0:0
i morgon             +0:0:0:1:0:0:0
idag                 0:0:0:0:0:0:0
igar                 -0:0:0:1:0:0:0
igår                 -0:0:0:1:0:0:0
imorgon              +0:0:0:1:0:0:0

Las palabras que establecen solo la hora del día son similares a las palabras en inglés 'mediodía' o 'medianoche'.

Se pueden usar las siguientes palabras:

midnatt              00:00:00
mitt pa días        12:00:00
mediodía        12:00:00

También hay disponibles palabras que establecen la fecha y hora completas (relativas a la fecha y hora actuales).

En inglés, la palabra 'now' es una de estas.

Se pueden usar las siguientes palabras:

nu                   0:0:0:0:0:0:0
Separadores de Hora/Minuto/Segundo
Al especificar la hora del día, el separador más común es los dos puntos (:) que puede usarse para ambos separadores.

Algunos idiomas usan pares diferentes. Por ejemplo, el francés permite especificar la hora como 13h30:20, por lo que usaría los siguientes pares:

: :
h :

La primera columna es el separador hora-minuto y la segunda columna es el separador minuto-segundo. Ambas son expresiones regulares de perl. Al crear una nueva traducción, tenga en cuenta que las expresiones regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no incluya la expresión '[x]' donde 'x' es un carácter utf-8.

Un par de dos puntos SIEMPRE está permitido para todos los idiomas. Si un idioma permite pares adicionales, se listan aquí:

\.  :
Separador de segundo fraccionario
Al especificar segundos fraccionarios, la forma más común es usar un punto decimal (.). Algunos idiomas pueden especificar un separador diferente que podría usarse. Si se hace, es una expresión regular.

El punto decimal SIEMPRE está permitido para todos los idiomas. Si un idioma permite otro separador, se lista aquí:

No definido en este idioma
