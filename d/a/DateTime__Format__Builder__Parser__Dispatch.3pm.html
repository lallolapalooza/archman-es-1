DateTime::Format::Builder::Parser::Dispatch(3) Documentación de Perl contribuida por el usuario DateTime::Format::Builder::Parser::Dispatch(3)

NOMBRE

DateTime::Format::Builder::Parser::Dispatch - Despacha analizadores por grupo

VERSIÓN

versión 0.83

SINOPSIS

package SampleDispatch;
use DateTime::Format::Builder (
    parsers => {
        parse_datetime => [
            {
                Dispatch => sub {
                    return 'fnerk';
                }
            }
        ]
    },
    groups => {
        fnerk => [
            {
                regex  => qr/^(\d{4})(\d\d)(\d\d)$/,
                params => [qw( year month day )],
            },
        ]
    }
);

DESCRIPCIÓN

"Dispatch" añade otro tipo de analizador a "Builder" permitiendo el despacho de análisis según nombres de grupo.

ESPECIFICACIÓN

"Dispatch" tiene una sola clave: "Dispatch". El valor debe ser una referencia a una subrutina que devuelva uno de:

  • "undef", lo que significa que no se encontraron grupos.
  • Una lista vacía, lo que significa que no se encontraron grupos.
  • Una cadena única, lo que significa: usar este grupo
  • Una lista de cadenas, lo que significa: usar estos grupos en este orden.

Los grupos se especifican de manera muy parecida al ejemplo en la SINOPSIS. Siguen el mismo formato que cuando se especifican para métodos.

EFECTOS COLATERALES

Tu analizador de grupos también puede ser un analizador de Dispatch. Por lo tanto, podrías terminar potencialmente con un analizador recursivo infinito.
