DateTime::TimeZone::Local(3) Documentación de Perl aportada por el usuario DateTime::TimeZone::Local(3)

NOMBRE

DateTime::TimeZone::Local - Determina la zona horaria del sistema local

VERSIÓN

versión 2.65

SINOPSIS

my $tz = DateTime::TimeZone->new( name => 'local' );
my $tz = DateTime::TimeZone::Local->TimeZone();

DESCRIPCIÓN

Este módulo proporciona una interfaz para determinar la zona horaria del sistema local. La mayor parte de la funcionalidad para hacer esto se encuentra en subclases específicas del sistema operativo.

USO

Esta clase proporciona los siguientes métodos:

DateTime::TimeZone::Local->TimeZone()

Esto intenta cargar una subclase apropiada y le pide que encuentre la zona horaria local. Este método es llamado cuando pasas "local" como nombre de la zona horaria a "DateTime:TimeZone->new()".

Si tu sistema operativo no está explícitamente manejado, puedes crear un módulo con un nombre de la forma "DateTime::TimeZone::Local::$^O". Si existe, se usará en lugar de recurrir a la subclase de Unix.

Si no existe un módulo específico del sistema operativo, recurrimos a usar la subclase de Unix.

Ver DateTime::TimeZone::Local::Unix, DateTime::TimeZone::Local::Android, DateTime::TimeZone::Local::hpux, DateTime::TimeZone::Local::Win32, y DateTime::TimeZone::Local::VMS para detalles específicos del sistema operativo.

SUBCLASES

Si quieres crear una nueva subclase específica del sistema operativo, hay varios métodos proporcionados por este módulo que deberías conocer.

$class->Methods()

Este método debe ser proporcionado por tu clase. Debe proporcionar una lista de métodos que serán llamados para intentar determinar la zona horaria local.

Se espera que cada uno de estos métodos devuelva un nuevo objeto "DateTime::TimeZone" si puede determinar exitosamente la zona horaria.

$class->FromEnv()

Este método intenta encontrar una zona horaria válida en un valor de %ENV. Llama a "$class->EnvVars()" para determinar qué claves mirar.

Para usar esto desde una subclase, simplemente devuelve "FromEnv" como uno de los elementos de "$class->Methods()".

$class->EnvVars()

Este método debe ser proporcionado por tu subclase. Debería devolver una lista de variables de entorno que serán comprobadas por "$class->FromEnv()".

Tu clase siempre debería incluir la clave "TZ" como una de las variables a comprobar.

$class->_IsValidName($name)

Dado un posible nombre de zona horaria, esto devuelve un booleano indicando si el nombre parece válido o no. Siempre devuelve falso para "local" para evitar bucles infinitos.

EJEMPLO DE SUBCLASE

Aquí hay un ejemplo simple de subclase:

package DateTime::TimeZone::SomeOS;
use strict;
use warnings;
use base 'DateTime::TimeZone::Local';
sub Methods { qw( FromEnv FromEther ) }
sub EnvVars { qw( TZ ZONE ) }
sub FromEther
{
    my $class = shift;
    ...
}
