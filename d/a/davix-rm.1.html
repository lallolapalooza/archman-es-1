DAVIX-RM(1) Herramienta de listado DAVIX-RM(1)

NOMBRE

davix-rm - Herramienta de eliminación basada en libdavix.

SINOPSIS

davix-rm [opciones]... url

DESCRIPCIÓN

davix-rm es una herramienta para eliminar recursos con servicios compatibles con HTTP, Webdav o REST.
Los comandos pueden eliminar recursos y contenedores de recursos.
Soporta los protocolos Http (http(s)://), WebDav (dav(s)://) y S3 (s3(s)://).

davix-rm está impulsado por libdavix. Ver libdavix(3) para más detalles.

OPCIONES

Opciones comunes:

--debug
Modo de depuración
--header, -H
Añadir un campo de encabezado a la solicitud (ej: -H "Depth: 1" )
--help, -h
Mostrar este mensaje de ayuda
--metalink OPT
Soporte Metalink. (OPT=failover[predeterminado]|no)
--module, -P NOMBRE_PLUGIN
Cargar un plugin o perfil por nombre
--redirection OPT
Soporte de redirección transparente. (OPT=yes[predeterminado]|no)
--proxy, -x URL
Servidor proxy SOCKS5 URL. (ej: socks5://login:pass@socks.example.org)
--trace
Rastrea ámbitos específicos, las opciones incluyen:
file - Interfaz de archivo de Davix
posix - Interfaz POSIX de Davix
xml - Salida del analizador XML
ssl - Detalles SSL y de certificados
header - Encabezados de las consultas HTTP
body - Cuerpos de las consultas HTTP
chain - Información de cadenas de E/S
core - Información de configuración y miscelánea
grid - Información miscelánea de terceros
socket - Información de sockets
locks - Información de bloqueo WebDAV
all - Rastrea todo
--version
Mostrar versión

Opciones de seguridad:

--capath RUTA_CA
Añadir un directorio adicional de autoridad de certificación
--cert, -E RUTA_CRED
Certificado de cliente en formato PEM
--key ruta_privada
Clave privada en formato PEM
--insecure, -k
Deshabilitar comprobaciones de credenciales SSL
--userlogin
Inicio de sesión de usuario para autenticación de nombre de usuario/contraseña
--userpass
Contraseña de usuario para autenticación de nombre de usuario/contraseña
--s3secretkey
Autenticación AWS S3: clave secreta
--s3accesskey
Autenticación AWS S3: clave de acceso
--s3region
Autenticación AWS S3: región
--s3token
Token de seguridad de AWS S3 - utilizado junto con las credenciales temporales STS
--s3alternate
Especifique este indicador si necesita usar una URL S3 basada en ruta
--azurekey
Clave de autenticación de Azure

EJEMPLOS

Eliminar un archivo a través de http
davix-rm https://example.org/file1

Eliminar un directorio a través de WebDav
davix-rm dav://webdav.example.org/collection/collection_to_delete

Eliminar un recurso en un Almacenamiento Grid con autenticación VOMS
davix-rm -P grid davs://grid-storage.example.org/dir1/dir2/
