DateTime::Format::W3CDTF(3) Documentación de Perl aportada por el usuario DateTime::Format::W3CDTF(3)

NOMBRE

DateTime::Format::W3CDTF - Analizar y formatear cadenas de fecha/hora W3CDTF

VERSIÓN

Este documento describe DateTime::Format::W3CDTF versión 0.08

SINOPSIS

use DateTime::Format::W3CDTF;
my $w3c = DateTime::Format::W3CDTF->new(strict => 1);
my $dt = $w3c->parse_datetime( '2003-02-15T13:50:05-05:00' );
# 2003-02-15T13:50:05-05:00
$w3c->format_datetime($dt);

DESCRIPCIÓN

Este módulo entiende el formato de fecha/hora W3CDTF, un perfil de ISO 8601, definido en http://www.w3.org/TR/NOTE-datetime. Este formato es el formato de fecha nativo de RSS 1.0.

Puede ser utilizado para analizar estos formatos con el fin de crear los objetos apropiados.

MÉTODOS

Esta API es actualmente experimental y puede cambiar en el futuro.

  • new()

    Devuelve un nuevo objeto analizador de W3CDTF. Acepta una única opción "strict":

    DateTime::Format::W3CDTF->new(strict => 1);

    Si es verdadero, parse_datetime() y format_datetime() solo aceptarán y devolverán cadenas en formato W3CDTF, respectivamente. En particular, el formato W3CDTF requiere que todos los componentes de hora tengan zonas horarias.

    Si es falso, las zonas horarias son opcionales.

  • parse_datetime($string)

    Dada una cadena de fecha/hora W3CDTF, este método devolverá un nuevo objeto "DateTime".

    Si se le proporciona una cadena con formato incorrecto, este método puede fallar.

  • format_datetime($datetime)

    Dado un objeto "DateTime", este método devuelve una cadena de fecha/hora W3CDTF.

    NOTA: A partir de la versión 0.4, format_datetime ya no intenta truncar las fechas sin componente de hora. Esto se debe a que "DateTime" no distingue entre una fecha sin componente de hora y la medianoche.

  • format_date($datetime)

    Dado un objeto "DateTime", devuelve una cadena de fecha/hora W3CDTF sin el componente de hora.
