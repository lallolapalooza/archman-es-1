NOMBRE

daxctl destroy-device - Destruir un dispositivo devdax

SINOPSIS

daxctl destroy-device <dax0.0> [<dax1.0>...<daxY.Z>] [<opciones>]

EJEMPLOS

•Destruye dax0.1
# daxctl disable-device dax0.1
disabled 1 device
# daxctl destroy-device dax0.1
destroyed 1 device
•Destruye todos los dispositivos en la región id 0
# daxctl disable-device -r 0 all
disabled 3 devices
# daxctl destroy-device -r 0 all
destroyed 2 devices

DESCRIPCIÓN

Destruye un dispositivo dax en modo devdax.

OPCIONES

-r, --region=

Restringe la operación a los dispositivos que pertenecen a las regiones especificadas. Una región devdax es un rango contiguo de memoria que alberga uno o más dispositivos /dev/daxX.Y, donde X es el id de la región y Y es el id de instancia del dispositivo.

-u, --human

Por defecto, el comando generará datos numéricos crudos fáciles de procesar por máquinas. En cambio, con esta bandera, los números que representan el tamaño del almacenamiento se formatearán como cadenas legibles por humanos con unidades, otros campos se convertirán a cadenas hexadecimales.

-v, --verbose

Emite más mensajes de depuración
