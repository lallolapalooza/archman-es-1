DateTime__LeapSecond(3pm)

Paquete: perl-datetime

Licencias: GPL, PerlArtistic

DateTime::LeapSecond(3pm) Documentación de Perl contribuida por el usuario DateTime::LeapSecond(3pm)

NOMBRE

DateTime::LeapSecond - tabla y utilidades de segundos intercalares

VERSIÓN

versión 1.66

SINOPSIS

use DateTime;
use DateTime::LeapSecond;
print "Los segundos intercalares entre los años 1990 y 2000 son ";
print DateTime::Leapsecond::leap_seconds($utc_rd_2000)
    - DateTime::Leapsecond::leap_seconds($utc_rd_1990);

DESCRIPCIÓN

Este módulo se utiliza para calcular los segundos intercalares para un día Rata Die dado. Se utiliza cuando DateTime no puede compilar la versión XS de este código.

Esta biblioteca es conocida por ser precisa para fechas hasta junio de 2020.

No hay segundos intercalares antes de 1972, porque ese es el año en que se implementó este sistema.

  • leap_seconds($rd)

    Devuelve el número de segundos intercalares acumulados para un día dado.

  • extra_seconds($rd)

    Devuelve el número de segundos intercalares para un día dado, en el rango -2 .. 2.

  • day_length($rd)

    Devuelve el número de segundos para un día dado, en el rango 86398 .. 86402.
