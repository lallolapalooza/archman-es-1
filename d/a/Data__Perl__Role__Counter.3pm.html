Data::Perl::Role::Counter(3) Documentación de Perl contribuida por el usuario Data::Perl::Role::Counter(3)

NOMBRE

Data::Perl::Role::Counter - Clase envoltorio para un contador numérico simple.

VERSIÓN

versión 0.002011

SINOPSIS

use Data::Perl qw/counter/;
my $c = counter(4);
$c->inc;   # $c == 5
$c->reset; # $c == 0

DESCRIPCIÓN

Esta clase proporciona un envoltorio y métodos para un contador numérico simple.

MÉTODOS PROPORCIONADOS

new($value)
Construye un nuevo objeto Data::Perl::Collection::Counter inicializado con el valor proporcionado y lo devuelve.
set($value)
Establece el contador al valor especificado y devuelve el nuevo valor.

Este método requiere un único argumento.

inc
inc($arg)
Incrementa el valor del atributo en la cantidad del argumento, o en 1 si no se proporciona argumento. Este método devuelve el nuevo valor.

Este método acepta un único argumento.

dec
dec($arg)
Disminuye el valor del atributo en la cantidad del argumento, o en 1 si no se proporciona argumento. Este método devuelve el nuevo valor.

Este método acepta un único argumento.

reset
Restablece el valor almacenado en esta ranura a su valor predeterminado y devuelve el nuevo valor.
