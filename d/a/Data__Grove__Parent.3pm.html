Data::Grove::Parent(3) Documentación Perl contribuida por el usuario Data::Grove::Parent(3)

NOMBRE

Data::Grove::Parent - proporciona propiedades de padre a objetos Data::Grove

SINOPSIS

use Data::Grove::Parent;
$root = $object->root;
$rootpath = $object->rootpath;
$tied = $object->add_magic([ $parent ]);
$node = Data::Grove::Parent->new($hash [, $parent]);
$node_list = Data::Grove::ParentList->new($array [, $parent]);

DESCRIPCIÓN

Data::Grove::Parent es una extensión de Data::Grove que añade propiedades de `"Padre"' y `"Raw"' a los objetos Data::Grove y métodos para devolver el nodo raíz de un grove, una lista de nodos entre el nodo raíz y el nodo actual (incluidos), y un método que crea nodos con padre.

Data::Grove::Parent funciona creando un objeto Perl ``tied'' que contiene una referencia al padre (`"Parent"') y una referencia al objeto Data::Grove original (`"Raw"'). Se utiliza la magia de tied para que cada vez que se hace referencia al objeto Data::Grove::Parent, en realidad se hace referencia al objeto subyacente.

Cuando se recupera una lista o una propiedad del objeto Raw, Data::Grove::Parent añade automáticamente magia a la lista o nodo devuelto. Esto significa que solo se llama a `add_magic()' una vez para crear el primer objeto Data::Grove::Parent y luego se utilizan los objetos grove como se haría normalmente.

El uso más obvio de esto es para que no tengas que llamar a un método `"delete"' cuando quieras liberar un grove o parte de un grove; dado que los objetos Data::Grove y Data::Grove::Parent no tienen referencias cíclicas, Perl puede recolectar la basura normalmente.

Un uso secundario es permitirte reutilizar fragmentos de grove o conjuntos de propiedades en varios árboles. ADVERTENCIA: ¡Data::Grove actualmente no te protege de crear tus **propias** referencias cíclicas! Esto podría llevar a bucles infinitos si no tienes cuidado para evitarlos.

MÉTODOS

$object->root()
$object->rootpath()
`root()' devuelve el nodo raíz si `$object' es un objeto `"Data::Grove::Parent"'. `rootpath()' devuelve un array con todos los nodos entre el nodo raíz y `$object' (incluidos).
$tied = $object->add_magic([ $parent ])
`add_magic()' devuelve un objeto "Data::Grove::Parent" con `$object' como su objeto `"Raw"'. Si se proporciona `$parent', este se convierte en el objeto padre del objeto tied.
