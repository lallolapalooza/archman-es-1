NOMBRE

cdawson, dawson - integral de Dawson

SINOPSIS

#include <cerf.h>

double _Complex cdawson ( double _Complex z );

double dawson ( double x );

DESCRIPCIÓN

La función cdawson devuelve la integral de Dawson D(z) = exp(-z^2) integral de 0 a z exp(t^2) dt = sqrt(pi)/2 * exp(-z^2) * erfi(z).

La función dawson toma un argumento real x y devuelve el resultado real D(x).

VER TAMBIÉN

El cálculo de D(z) se basa en la función de Faddeeva w_of_z(3); para calcular D(x), se utiliza la parte imaginaria im_w_of_x(3).

Otras funciones de error complejas: w_of_z(3), voigt(3), cerf(3), erfcx(3), erfi(3).
