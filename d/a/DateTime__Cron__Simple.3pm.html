NOMBRE

DateTime::Cron::Simple - Analizar una entrada cron y verificar contra la hora actual

SINOPSIS

use DateTime::Cron::Simple;
$c = DateTime::Cron::Simple->new($cron);
$boolean = $c->validate_time;
$c->new_cron($cron);

DESCRIPCIÓN

Este módulo es una forma rápida y sucia de determinar si el formato de hora de cron es válido para la fecha y hora actuales.

Una entrada cron sigue el formato de cron de crontab(5).

La función validate_time utiliza la fecha y hora actuales para la comparación, pero también aceptará un objeto DateTime válido como parámetro.

FUNCIONES

new
$c = DateTime::Cron::Simple->new('0-59/2 10,12 * * 5');

Crea una entrada cron.

new_cron
$c->new_cron($cron);

Actualiza la entrada cron al argumento dado.

validate_time
$boolean = $c->validate_time;
$boolean = $c->validate_time($dt);

Valida una fecha y hora contra la entrada cron. Si se omite el argumento, valida contra la hora actual ("DateTime-"now>).

_parse_cron_field
$data = $c->_parse_cron_field($field, $min, $max)

EJEMPLO

use DateTime::Cron::Simple;
$c = DateTime::Cron::Simple->new('0-59/2 10,12 * * 5');
if($c->validate_time) { ... }
$c->new_cron('* * 1 * 0');
if($c->validate_time) { ... }

VER TAMBIÉN

DateTime::Event::Cron

Es muy probable que este módulo sea obsoleto pronto. Fue creado sin coordinación con los desarrolladores de los módulos DateTime, que pueden ser contactados a través de

http://datetime.perl.org/

Este módulo encajaría mejor en el espacio de nombres DateTime::Event o bien tendría su funcionalidad incorporada en DateTime::Event::Cron. Esta versión es transitoria, mientras se estudia la forma correcta de hacerlo.
