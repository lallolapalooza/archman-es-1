NOMBRE

Date::Manip::Lang::spanish - Soporte del idioma español.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que soportan el idioma. No está destinado a ser utilizado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DEL IDIOMA

La siguiente es una lista de todas las palabras y expresiones del idioma utilizadas para escribir horas y/o fechas.

Todas las cadenas no distinguen entre mayúsculas y minúsculas.

Horas de la mañana/tarde
Esta es una lista de expresiones utilizadas para designar la hora de la mañana o la tarde cuando una hora se introduce como una hora de 12 en lugar de una hora de 24. Por ejemplo, en inglés, la hora "17:00" podría especificarse como "5:00 PM".

La hora de la mañana y la tarde puede designarse con los siguientes conjuntos de palabras:

A.M.
PM
P.M.

Palabras delta para avanzar/retroceder en el tiempo
Al analizar deltas, hay palabras que pueden usarse para especificar que el delta se referirá a una hora en el futuro o a una hora en el pasado (relativo a alguna fecha). En inglés, por ejemplo, podrías decir: 
EN 5 días

Se pueden usar las siguientes palabras para especificar deltas que se refieren a fechas en el pasado o futuro respectivamente:

hace
en
later
Modo laboral
Esto contiene dos listas de palabras que pueden usarse para especificar un delta estándar (es decir, no laboral) o un delta laboral.

Anteriormente, se usaba para indicar si el delta era aproximado o exacto, pero ahora esta lista no se usa excepto para forzar el delta a ser estándar.

Se pueden usar las siguientes palabras:

exactamente
aproximadamente

Se pueden usar las siguientes palabras para especificar un delta laboral:

laborales

Palabras
ignoradas
Al escribir fechas en formas comunes, hay una serie de palabras que normalmente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar un momento a continuación. En inglés, usarías la palabra AT en el

ejemplo: 
December 3 at
12:00

palabras:

Palabras que establecen la fecha,
    la hora o 
ambas
  
Hay algunas palabras que se pueden usar para especificar una fecha, una hora o ambas
      en relación con el momento actual.
    
Las palabras que establecen la fecha son similares a las palabras en inglés
        'yesterday' (ayer) o 'tomorrow' (mañana). Estas se especifican como un delta que se añade
        a la hora actual para obtener una fecha. La hora NO se establece, por lo que el
        delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana
        
y día).
    
Se pueden usar las siguientes 
palabras:
        
Hoy                  0:0:0:0:0:0:0
ayer                 -0:0:0:1:0:0:0
manana               +0:0:0:1:0:0:0
mañana               +0:0:0:1:
0:0:0
    
Las palabras que establecen solo la hora del día son similares a las palabras en inglés
        'noon' (mediodía) o 'midnight' 
(medianoche).
    
Se pueden usar las siguientes 
palabras:
        
medianoche           00:00:00
mediodia             12:
00:00
    
También están disponibles palabras que establecen la hora y la fecha completas (en relación con
        la hora y fecha 
actuales).
    
En inglés, la palabra 'now' (ahora) es una de 
estas.
    
Se pueden usar las siguientes 
palabras:
        
Ahora                0:0:0:0:
0:
0:0
  
Separadores de
    hora/minuto/segu
ndo
  
Al especificar la hora del día, el separador más común es los dos puntos (:) que
      se puede usar para ambos separadores.
    
Algunos idiomas usan pares diferentes. Por ejemplo, el francés te permite
        especificar la hora como 13h30:20, por lo que usaría los siguientes
     
   pares:
        
: :

h :
    
La primera columna es el separador hora-minuto y la segunda
        columna es el separador minuto-segundo. Ambas son expresiones regulares de Perl. Al crear una nueva traducción, ten en cuenta que las expresiones
        regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no
        incluyas la expresión '[x]' donde 'x' es un carácter 
utf-8.
    
Un par de dos puntos SIEMPRE está permitido para todos los idiomas. Si un
        idioma permite pares adicionales, se
