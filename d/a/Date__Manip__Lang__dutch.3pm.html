NOMBRE

Date::Manip::Lang::dutch - Soporte para el idioma neerlandés.

SINOPSIS

Este módulo contiene una lista de palabras y expresiones que soportan el idioma. No está destinado a ser usado directamente (otros módulos de Date::Manip lo cargarán según sea necesario).

EXPRESIONES DE IDIOMA

La siguiente es una lista de todas las palabras y expresiones de idioma usadas para escribir horas y/o fechas.

Todas las cadenas no distinguen mayúsculas de minúsculas.

Palabras ignoradas
Al escribir fechas en formas comunes, hay una serie de palabras que típicamente no son importantes.

Frecuentemente hay una palabra que aparece en una frase para designar que se va a especificar una hora a continuación. En inglés, usarías la palabra AT en el ejemplo:

December 3 at 12:00

Se pueden usar las siguientes palabras:

om

Otra palabra se usa para designar a un miembro de un conjunto. En inglés, usarías las palabras IN u OF:

1st day OF December
1st day IN December

Se pueden usar las siguientes palabras:

in
van

Otra palabra se usa para especificar que algo está en una fecha determinada. En inglés, usarías ON:

ON July 5th

Se pueden usar las siguientes palabras:

op
Palabras que establecen la fecha, la hora, o
ambas
Hay algunas palabras que pueden usarse para especificar una fecha, una hora, o ambas relativas a ahora.

Las palabras que establecen la fecha son similares a las palabras en inglés 'yesterday' (ayer) o 'tomorrow' (mañana). Estas se especifican como un delta que se añade a la hora actual para obtener una fecha. La hora NO se establece, por lo que el delta solo se usa parcialmente (solo debería incluir los campos de año, mes, semana

y día).

Se pueden usar las siguientes

palabras: 
eergisteren          -0:0:0:2:0:0:0
gisteren             -0:0:0:1:0:0:0
morgen               +0:0:0:1:0:0:0
overmorgen           +0:0:0:2:0:0:0
vandaag              0:0:0:0:
0:0:0

Las palabras que establecen solo la hora del día son similares a las palabras en inglés 'noon' (mediodía) o 'midnight'

(medianoche).

Se pueden usar las siguientes

palabras: 
middernacht          00:00:00
noen                 12:
00:00

También están disponibles palabras que establecen la hora y la fecha completas (relativas a la hora y fecha

actuales).

En inglés, la palabra 'now' (ahora) es una de

estas.

Se pueden usar las siguientes

palabras: 
nou                  0:0:0:0:0:0:0
nu                   0:0:0:0:
0:
0:0
Separadores de Hora/Minuto/Segu
ndo
Al especificar la hora del día, el separador más común es los dos puntos (:) que puede usarse para ambos separadores.

Algunos idiomas usan pares diferentes. Por ejemplo, el francés permite especificar la hora como 13h30:20, por lo que usaría los siguientes

pares: 
: :
h :

La primera columna es el separador hora-minuto y la segunda columna es el separador minuto-segundo. Ambas son expresiones regulares de perl. Al crear una nueva traducción, tenga en cuenta que las expresiones regulares con caracteres utf-8 pueden ser complicadas. Por ejemplo, no incluya la expresión '[x]' donde 'x' es un carácter

utf-8.

Un par de dos puntos SIEMPRE está permitido para todos los idiomas. Si un idioma permite pares adicionales, se

listan aquí: 
[.]
[uh]
[m]
Separador de segundo
fraccionario
Al especificar segundos fraccionarios, la forma más común es usar un punto decimal (.). Algunos idiomas pueden especificar un separador diferente que podría usarse. Si se hace, es una expresión regular.

El punto decimal SIEMPRE está permitido para todos los idiomas. Si un idioma permite otro separador, se
