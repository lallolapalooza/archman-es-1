Data::HexDump(3) Documentación de Perl contribuida por el usuario Data::HexDump(3)

NOMBRE

Data::HexDump - Volcado hexadecimal

SINOPSIS

Interfaz funcional:

use Data::HexDump;
print HexDump($cadena_datos);

Interfaz OO:

use Data::HexDump;
my $dumper = Data::HexDump->new();
print while $_ = $dumper->dump;

DESCRIPCIÓN

Este módulo generará un volcado hexadecimal de una cadena de datos o archivo. Puede usar la función exportada, como se muestra en la SINOPSIS anterior, o la interfaz OO, descrita a continuación.

El segundo ejemplo de la SINOPSIS generó esta salida:

          00 01 02 03 04 05 06 07 - 08 09 0A 0B 0C 0D 0E 0F  0123456789ABCDEF
00000000  23 21 2F 75 73 72 2F 62 - 69 6E 2F 70 65 72 6C 0A  #!/usr/bin/perl.
00000010  75 73 65 20 73 74 72 69 - 63 74 3B 0A 75 73 65 20  use strict;.use
00000020  77 61 72 6E 69 6E 67 73 - 3B 0A 0A 70 72 69 6E 74  warnings;..print
00000030  20 22 48 65 6C 6C 6F 2C - 20 77 6F 72 6C 64 5C 6E   "Hello, world\n
00000040  22 3B 0A                                           ";.

El resultado se devuelve en una cadena. Cada línea del resultado consiste en el desplazamiento en la fuente en la columna más a la izquierda de cada línea, seguido de una o más columnas de datos de la fuente en hexadecimal. La columna más a la derecha de cada línea muestra los caracteres imprimibles (todos los demás se muestran como puntos individuales).

Interfaz Funcional

Este módulo exporta una única función, "HexDump", que toma un valor escalar y devuelve una cadena que contiene el volcado hexadecimal de los datos pasados.

Interfaz OO

Primero construye un objeto "Data::HexDump", luego le dice de dónde obtener los datos y, a continuación, genera el volcado hexadecimal:

my $dh = Data::HexDump->new();
$dh->data($scalar);      # volcar los datos en este escalar
$dh->fh($fh);            # leer este manejador de archivo
$dh->file($nombre_archivo);    # leer este archivo y volcar el contenido
print while $_ = $dh->dump;

Las diferentes fuentes potenciales de datos se consideran en el orden indicado anteriormente, por lo que si pasa al método "data", las llamadas posteriores a fh() o file() no tendrán efecto.

VER TAMBIÉN

Data::Hexify, por Johan Vromans, es otra opción simple, similar a este módulo. Última versión en 2004.

Data::Hexdumper (por David Cantrell, DCANTRELL) es otro volcado hexadecimal, con más características que este módulo.

App::colourhexdump (por Kent Fredric, RIP) proporciona un script que ofrece salida con color y resaltado de clases de caracteres.

Data::HexDump::Range proporciona más funciones, salida en color y la capacidad de omitir partes no interesantes de los datos de entrada.

Data::HexDump::XXD proporciona volcados hexadecimales como xxd. No indica qué es xxd, ni proporciona un enlace, y no hay salida de ejemplo. Pero si conoce y le gusta xxd, ¡este podría ser el adecuado para usted!

Devel::Hexdump proporciona algunas opciones de configuración, pero existen otros módulos con más características, y este no tiene salida de ejemplo en la documentación.

Data::Peek es una colección de funciones para mostrar datos, incluyendo "DHexDump" que genera un volcado hexadecimal simple a partir de una cadena.

String::HexConvert convertirá cadenas ASCII a hexadecimal y viceversa.
