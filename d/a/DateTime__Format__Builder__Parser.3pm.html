Nombrando su

Cree un módulo y nómbrelo en la forma "DateTime::Format::Builder::Parser::XXX" donde XXX es lo que usted quiera, siempre que no comience con una letra en

minúscula.

Alternativamente, llámelo de otra manera completamente diferente si no le importa que los usuarios carguen explícitamente su

módulo.

Recomendaría mantenerse dentro del espacio de nombres "DateTime::Format::Builder" sin embargo --- en el momento de escribir esto no he pensado en cómo

deberían llamarse los que no se cargan automáticamente. Si
tiene alguna idea, por favor envíeme un correo electrónico.

Declarando argumentos de

especificación

Llame a "<DateTime::Format::Builder::Parser-"valid_params>> con argumentos de estilo "Params::Validate". Por

ejemplo: 
DateTime::Format::Builder::Parser->valid_params(
    params => { type => ARRAYREF },
    Regex  => {
        type      => SCALARREF,
        callbacks => {
            'is a regex' => sub { ref(shift) eq 'Regexp' }
        }
    }
)
;

Comience uno de los nombres de clave con una letra mayúscula. Idealmente, esa clave debería coincidir con el XXX de antes. Esto se usará para ayudar a identificar a qué módulo se le debe dar una especificación de

analizador.

Los nombres de clave on_match, on_fail, postprocess, preprocess, label y length están predefinidos. Se recomienda hacer uso de ellos. Puede ignorar length ya que "sort_parsers" s
