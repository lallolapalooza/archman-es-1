DateTime::TimeZone::Floating(3) Documentación de Perl contribuida por el usuario DateTime::TimeZone::Floating(3)

NOMBRE

DateTime::TimeZone::Floating - Una zona horaria que siempre es local

VERSIÓN

versión 2.65

SINOPSIS

my $floating_tz = DateTime::TimeZone::Floating->new;

DESCRIPCIÓN

Esta clase se utiliza para proporcionar la API de DateTime::TimeZone necesaria para DateTime.pm, pero para horas flotantes, tal como se definen en la especificación RFC 2445. Una hora flotante no tiene zona horaria y tiene un desplazamiento efectivo de cero.

USO

Esta clase tiene los mismos métodos que un objeto de zona horaria real. El método short_name_for_datetime() devuelve la cadena "floating" y el método category() devuelve "undef".

SOPORTE

Los errores pueden enviarse a https://github.com/houseabsolute/DateTime-TimeZone/issues.

CÓDIGO FUENTE
