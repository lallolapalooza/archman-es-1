Data::Perl::Bool::MooseLike(3) Documentación de Contribución de Usuario de Perl Data::Perl::Bool::MooseLike(3)

NOMBRE

Data::Perl::Bool::MooseLike - subclas de data::Perl::Bool que simulan los traits nativos de Moose.

VERSIÓN

version 0.001009

SINOPSIS

# no deberías consumir esta clase directamente.

DESCRIPCIÓN

Esta clase proporciona un envoltorio y métodos para interactuar con un booleano. Todos los métodos están escritos para emular/coincidir con el comportamiento existente que se encuentra en los traits nativos de Moose.

VER TAMBIÉN

  • Data::Perl
  • Data::Perl::Role::Collection::Bool
