DAVIX-LS(1) herramienta de listado DAVIX-LS(1)

NOMBRE

davix-ls - Herramienta de listado basada en libdavix

SINOPSIS

davix-ls [opciones]... url

DESCRIPCIÓN

davix-ls es una herramienta para listar recursos en directorios o colecciones con servicios compatibles con HTTP, Webdav o REST.
El comando soporta WebDav (dav(s)://) y S3 (s3(s)://).

davix-ls está impulsado por libdavix. Ver libdavix(3) para detalles.

OPCIONES

Opciones de Listado:

-l --long-list:
Modo de Listado largo
--s3-listing:
Modo de listado de bucket S3 - plano, semi o jerárquico(por defecto)
--s3-maxkeys:
Número máximo de entradas que devuelve la solicitud de listado de bucket S3. por defecto: 10000

Opciones Comunes:

--debug
Modo de depuración
--header, -H
Añade un campo de encabezado a la solicitud (ej: -H "Depth: 1" )
--help, -h
Muestra este mensaje de ayuda
--metalink OPT
Soporte de Metalink. (OPT=failover[por defecto]|no)
--module, -P PLUGIN_NAME
Carga un plugin o perfil por nombre
--redirection OPT
Soporte de redirección transparente. (OPT=yes[por defecto]|no)
--proxy, -x URL
URL del servidor proxy SOCKS5. (ej: socks5://login:pass@socks.example.org)
--trace
Rastrea ámbitos específicos, las opciones incluyen:
file - Interfaz de archivo Davix
posix - Interfaz POSIX Davix
xml - Salida del analizador XML
ssl - Detalles de SSL y certificados
header - Encabezados de consultas HTTP
body - Cuerpos de HTTP
chain - Información de cadenas de E/S
core - Información de configuración y herramientas de línea de comandos de Davix
grid - Información miscelánea de terceros
socket - Información de socket
locks - Información de bloqueo WebDAV
all - Rastrea todo
--version
Muestra la versión

Opciones de Seguridad:

--capath CA_path
Añade un directorio adicional de autoridad de certificación
--cert, -E cred_path
Certificado de cliente en formato PEM
--key priv_path
Clave privada en formato PEM
--insecure, -k
Deshabilita las comprobaciones de credenciales SSL
--userlogin
Usuario para autenticación de inicio de sesión/contraseña
--userpass
Contraseña de usuario para autenticación de inicio de sesión/contraseña
--s3secretkey
Autenticación AWS S3: clave secreta
--s3accesskey
Autenticación AWS S3: clave de acceso
--s3region
Autenticación AWS S3: región
--s3token
Token de seguridad de AWS S3 - se usa junto con credenciales temporales de STS
--s3alternate
Especifica esta bandera si necesitas usar una URL S3 basada en ruta
--azurekey
Clave de autenticación de Azure

EJEMPLOS

Listado de archivos de directorio WebDav
davix-ls dav://example.org/dir1/dir2/

Listado de bucket AWS S3
davix-ls s3://bucket.example.org/collection/

Listado largo con autenticación VOMS en entorno Grid WebDav
davix-ls -P grid davs://grid-storage.example.org/dir1/dir2/

Listado largo con WebDav + listado de archivos de directorio TLS
davix-ls -l davs://example.org/dir1/dir2/
