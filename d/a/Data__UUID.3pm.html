NOMBRE

Data::UUID - Identificadores Únicos Globales/Universales (GUIDs/UUIDs)

VER EN SU LUGAR?

El módulo Data::GUID proporciona otra interfaz para generar GUIDs. Actualmente, se basa en Data::UUID, pero puede que no lo haga en el futuro. Su interfaz puede ser un poco más sencilla para el programador Perl medio.

SINOPSIS

use Data::UUID;

$ug    = Data::UUID->new;
$uuid1 = $ug->create();
$uuid2 = $ug->create_from_name(<namespace>, <name>);
$res   = $ug->compare($uuid1, $uuid2);
$str   = $ug->to_string( $uuid );
$uuid  = $ug->from_string( $str );

DESCRIPCIÓN

Este módulo proporciona un marco para generar UUIDs de versión 3 (Identificadores Únicos Universales, también conocidos como GUIDs (Identificadores Únicos Globales). Un UUID tiene 128 bits de longitud y se garantiza que será diferente de todos los demás UUIDs/GUIDs generados hasta el año 3400 d.C.

Los UUIDs se utilizaron originalmente en el Network Computing System (NCS) y más tarde en el Entorno de Computación Distribuida (DCE) de la Open Software Foundation. Actualmente, muchas tecnologías diferentes dependen de los UUIDs para proporcionar una identidad única para varios componentes de software. Microsoft COM/DCOM, por ejemplo, utiliza GUIDs de forma muy extensa para identificar de forma única clases, aplicaciones y componentes en sistemas conectados en red.

El algoritmo para la generación de UUIDs, utilizado por esta extensión, se describe en el borrador de Internet "UUIDs and GUIDs" de Paul J. Leach y Rich Salz. (Véase RFC 4122). Proporciona un marco razonablemente eficiente y fiable para generar UUIDs y admite tasas de asignación bastante altas - 10 millones por segundo por máquina - y por lo tanto es adecuado para identificar objetos tanto de vida extremadamente corta como muy persistentes en un sistema dado, así como a través de la red.

Este módulo proporciona varios métodos para crear un UUID. En todos los métodos, "<namespace>" es un UUID y "<name>" es una cadena de forma libre.

# crea un UUID binario (valor binario de 16 bytes de longitud).
$ug->create();
$ug->create_bin();
# crea un UUID binario (valor binario de 16 bytes de longitud) basado en un
# espacio de nombres y una cadena de nombre concretos.
$ug->create_from_name(<namespace>, <name>);
$ug->create_from_name_bin(<namespace>, <name>);
# crea una cadena de UUID, utilizando el formato de cadena UUID convencional,
# como: 4162F712-1DD2-11B2-B17E-C09EFE1DC403
# Tenga en cuenta que los dígitos A-F están en mayúsculas, lo que es contrario a rfc4122
$ug->create_str();
$ug->create_from_name_str(<namespace>, <name>);
# crea una cadena de UUID como una cadena hexadecimal,
# como: 0x4162F7121DD211B2B17EC09EFE1DC403
# Tenga en cuenta que los dígitos A-F están en mayúsculas, lo que es contrario a rfc4122
$ug->create_hex();
$ug->create_from_name_hex(<namespace>, <name>);
# crea una cadena de UUID como una cadena codificada en Base64
$ug->create_b64();
$ug->create_from_name_b64(<namespace>, <name>);
Los UUIDs binarios se pueden convertir en cadenas imprimibles utilizando los siguientes métodos:
# convertir a la representación de cadena convencional
$ug->to_string(<uuid>);
# convertir a cadena hexadecimal (usando letras mayúsculas, en lugar de minúsculas)
$ug->to_hexstring(<uuid>);
# convertir a cadena codificada en Base64
$ug->to_b64string(<uuid>);
Por el contrario, las cadenas de UUID se pueden convertir de nuevo a su forma binaria:
# recrear UUID binario a partir de una cadena
$ug->from_string(<uuid>);
$ug->from_hexstring(<uuid>);
# recrear UUID binario a partir de una cadena codificada en Base64
$ug->from_b64string(<uuid>);
Finalmente, se pueden comparar dos UUIDs binarios utilizando el siguiente método:
# devuelve -1, 0 o 1 dependiendo de si uuid1 es menor
# que, igual a, o mayor que uuid2
$ug->compare(<uuid1>, <uuid2>);

Ejemplos:

use Data::UUID;
# esto crea un nuevo UUID en formato de cadena, basado en el espacio de nombres estándar
# UUID NameSpace_URL y el nombre "www.mycompany.com"
$ug = Data::UUID->new;
print $ug->create_from_name_str(NameSpace_URL, "www.mycompany.com");

EXPORTAR

El módulo permite exportar varios UUIDs de espacio de nombres estándar:

NameSpace_DNS
NameSpace_URL
NameSpace_OID
NameSpace_X500
