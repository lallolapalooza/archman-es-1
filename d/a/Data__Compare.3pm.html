NOMBRE

Data::Compare - comparar estructuras de datos de perl

SINOPSIS

use Data::Compare;
my $h1 = { 'foo' => [ 'bar', 'baz' ],  'FOO' => [ 'one', 'two' ] };
my $h2 = { 'foo' => [ 'bar', 'barf' ], 'FOO' => [ 'one', 'two' ] };
my @a1 = ('one', 'two');
my @a2 = ('bar', 'baz');
my %v = ( 'FOO', \@a1, 'foo', \@a2 );
# simple procedural interface
print 'structures of $h1 and \%v are ',
  Compare($h1, \%v) ? "" : "not ", "identical.\n";
print 'structures of $h1 and $h2 are ',
  Compare($h1, $h2, { ignore_hash_keys => [qw(foo)] }) ? '' : 'not ',
  "close enough to identical.\n";
# OO usage
my $c = new Data::Compare($h1, \%v);
print 'structures of $h1 and \%v are ',
  $c->Cmp ? "" : "not ", "identical.\n";
# or
my $c = new Data::Compare;
print 'structures of $h and \%v are ',
  $c->Cmp($h1, \%v) ? "" : "not ", "identical.\n";

DESCRIPCIÓN

Compara dos estructuras de datos de perl recursivamente. Devuelve 0 si las estructuras difieren, de lo contrario devuelve 1.

Algunos tipos de datos se tratan como casos especiales:

objetos Scalar::Properties
Esto se ha movido a un plugin, aunque la funcionalidad sigue siendo la misma que en la versión anterior. La documentación completa está en Data::Compare::Plugins::Scalar::Properties.
expresiones regulares compiladas, p. ej. qr/foo/
Estas se convierten a cadena antes de la comparación, por lo que lo siguiente coincidirá: 
$r = qr/abc/i;
$s = qr/abc/i;
Compare($r, $s);

y lo siguiente no, a pesar de que coinciden *exactamente* con el mismo texto:

$r = qr/abc/i;
$s = qr/[aA][bB][cC]/;
Compare($r, $s);

Lo siento, es lo mejor que podemos hacer.

referencias CODE y GLOB
Se asume que no coinciden a menos que las referencias sean idénticas, es decir, ambas son referencias a la misma cosa.

También puede personalizar cómo comparamos las estructuras proporcionando opciones en un hashref como tercer parámetro a la función Compare() . Esto aún no está disponible a través de la interfaz orientada a objetos. Estas opciones estarán vigentes para *toda* su comparación, por lo que se aplicarán a estructuras que se encuentren profundamente en sus datos, así como en el nivel superior, ¡así que tenga cuidado!

ignore_hash_keys
un arrayref de cadenas. Al comparar dos hashes, cualquier clave mencionada en esta lista será ignorada.

ESTRUCTURAS CIRCULARES

Comparar una estructura circular consigo misma devuelve verdadero:

$x = \$y;
$y = \$x;
Compare([$x, $y], [$x, $y]);

Y en una nota algo relacionada, si intenta comparar estructuras anidadas absurdamente profundas, el módulo emitirá una advertencia. Para que esto le afecte, necesita tener alrededor de cien niveles de profundidad, y si lo hace, tiene problemas más grandes con los que no puedo ayudarle ;-)

PLUGINS

El módulo acepta plugins para que pueda proporcionar rutinas especializadas para comparar sus propios objetos y tipos de datos. Para más detalles, consulte Data::Compare::Plugins.

Los plugins *no* están disponibles cuando se ejecuta en modo "taint". También puede evitar que cargue plugins proporcionando una lista vacía como argumento a import() - es decir, haciendo esto:

use Data::Compare ();

Se proporcionan algunas funciones para examinar qué funcionalidades han sido disponibles a través de plugins:

plugins
Devuelve una estructura (un hash ref) que describe todas las comparaciones disponibles a través de plugins. Esta función *no* se exporta, por lo que debe llamarse como Data::Compare::plugins(). No toma parámetros.
plugins_printable
Devuelve texto formateado

EXPORTACIONES

Por razones históricas, la función Compare() se exporta. Si no desea esto, pase una lista vacía a import() como se explica en PLUGINS. Si no quiere ninguna exportación pero sí quiere plugins, entonces pase la lista vacía, y luego llame al método de clase register_plugins:

use Data::Compare ();
Data::Compare->register_plugins;

o podría llamarlo como una función si eso le apetece.

ERRORES

El soporte de plugins no está del todo terminado (consulte el issue #5 en Github http://github.com/DrHyde/perl-modules-Data-Compare/issues/5 para más detalles) pero es utilizable. Las partes que faltan son más bien adornos que funcionalidad principal.

Los plugins no están disponibles si no puede cambiar al directorio actual. Esto podría ocurrir si inició su proceso como un usuario privilegiado y luego perdió privilegios. Si esto le afecta, por favor proporcione un parche portable con pruebas.

Los informes de errores deben hacerse en Github o por correo electrónico.
