DateTime::Calendar::Julian(3pm) Documentación de Perl aportada por el usuario DateTime::Calendar::Julian(3pm)

NOMBRE

DateTime::Calendar::Julian - Fechas en el calendario Juliano

SINOPSIS

use DateTime::Calendar::Julian;
$dt = DateTime::Calendar::Julian->new( year  => 964,
                                       month => 10,
                                       day   => 16,
                                     );
# convertir Julian->Gregoriano...
$dtgreg = DateTime->from_object( object => $dt );
print $dtgreg->datetime;  # imprime '0964-10-21T00:00:00'
# ... y de vuelta
$dtjul = DateTime::Calendar::Julian->from_object( object => $dtgreg );
print $dtjul->datetime;  # imprime '0964-10-16J00:00:00'

DESCRIPCIÓN

DateTime::Calendar::Julian implementa el Calendario Juliano. Este módulo implementa todos los métodos de DateTime; ver la página del manual DateTime(3) para todos los métodos.

MÉTODOS

Este módulo implementa un método adicional además de los de DateTime, y cambia la salida de otro método.

  • calendar_name

    Devuelve 'Julian'.

  • gregorian_deviation

    Devuelve la diferencia en días entre el calendario Gregoriano y el Juliano.

  • datetime 
    print $dt->datetime( $sep ), "\n";

    Este método es equivalente a

    join $sep, $dt->ymd( '-' ), $dt->hms( ':' );

    El argumento $sep por defecto es 'J'.

    Advertencia: el argumento opcional se añadió a este método en la versión 1.02, para seguir tardíamente un cambio realizado en la versión 1.43 de DateTime, lanzada el 2017-05-29. La corrección de esto restaura el comportamiento de stringification original de esta clase, que era devolver una cadena ISO-8601 a menos que se configurara un formateador. Antes de este cambio, la stringification separaba la fecha y la hora con una 'T' o una 'J', dependiendo de qué versión de DateTime estuviera instalada.

Nota que a partir de la versión "0.106_01", los métodos relacionados con los trimestres deberían funcionar.

ANTECEDENTES

El calendario Juliano fue introducido por Julio César en el 46 a.C. Tenía un año de doce meses de 365 días, con un año bisiesto en febrero cada cuatro años. Este calendario fue adoptado por la iglesia cristiana en el 325 d.C. Alrededor del 532 d.C., Dionisio el Exiguo trasladó el punto de partida del calendario Juliano al momento calculado del nacimiento de Jesucristo. Aparte de las diferentes opiniones sobre el inicio del año (a menudo el 1 de enero, pero también Navidad, Pascua, 25 de marzo y otras fechas), este calendario permaneció sin cambios hasta la reforma del calendario del papa Gregorio XIII en 1582. Sin embargo, algunos países retrasados usaron el calendario Juliano hasta el siglo XVIII o posterior.

Este módulo utiliza el calendario Juliano proleptic para los años anteriores al 532 d.C., o incluso al 46 a.C. Esto significa que las fechas se calculan como si este calendario hubiera existido sin cambios desde el principio de los tiempos. Se asume que el 1 de enero es el primer día del año.

Tenga en cuenta que los años a.C. se dan como números negativos, siendo 0 el año 1 a.C. (¡no hubo año 0 d.C.!), -1 el año 2 a.C., etc.
