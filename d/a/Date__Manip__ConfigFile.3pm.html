NOMBRE

Date::Manip::ConfigFile - archivo de configuración de ejemplo

DESCRIPCIÓN

Date::Manip es un módulo altamente configurable. Muchas de las opciones se pueden establecer en un archivo de configuración. Este documento incluye un archivo de configuración de ejemplo.

El archivo de configuración consta de tres secciones. La primera sección son variables de configuración. Esto se describe con más detalle en el documento Date::Manip::Config.

La segunda sección es la sección de definición de días festivos. La tercera sección es la sección de definición de eventos. Ambas se describen con más detalle en el documento Date::Manip::Holidays.

ARCHIVO DE CONFIGURACIÓN DE EJEMPLO

El archivo de configuración de ejemplo a continuación funciona para versiones más recientes de Date::Manip. Algunas de las variables de configuración pueden cambiar o ser obsoletas, y algunas pueden no funcionar con versiones anteriores de Date::Manip, por lo que se recomienda encarecidamente que consulte la documentación de la versión de Date::Manip que está utilizando para confirmar cualquier variable de configuración que desee incluir.

################################
# VARIABLES DE CONFIGURACIÓN
################################
# Ver la página del manual de Date::Manip::Config para una descripción de todas
# las variables de configuración.
# Para incluir información de configuración de archivos de configuración adicionales:
ConfigFile              = /ruta/a/otro/archivo/de/configuración
ConfigFile              = /ruta/a/otro/archivo/de/configuración2
# Para manejar otros idiomas
Language                = Spanish
DateFormat              = US
Encoding                =
# Establecer la zona horaria actual:
SetDate                 = now,America/New_York
# Establecer la semana laboral
WorkWeekBeg             = 1
WorkWeekEnd             = 5
WorkDay24Hr             = 0
WorkDayBeg              = 08:00
WorkDayEnd              = 17:00
TomorrowFirst           = 1
# Variables varias
YYtoYYYY                = 89
FirstDay                = 1
Use_POSIX_Printf        = 0
Week1ofYear             = jan4
Printable               = 0
DefaultTime             = midnight
RecurRange              = none
################################
# DÍAS FESTIVOS
################################
# Ver la página del manual de Date::Manip::Holidays para una descripción de
# esta sección.
*HOLIDAYS
# DÍAS FESTIVOS FEDERALES
##################
# Puedes expresar el Día de Año Nuevo como el día real (1 de enero)
# o el día observado (1 de enero o el día laborable más cercano).
# No puedes incluir AMBOS porque una vez que un día se marca como
# festivo, una segunda definición lo tratará igual que un fin de semana
# y elegirá otro día para asignar el festivo (por lo que habría dos días designados como Año Nuevo).
# Jan 1                         = Día de Año Nuevo
1*1:0:1:0:0:0*DWD               = Día de Año Nuevo (observado)
# Dos formas diferentes de definir el día de MLK
tercer lunes de enero             = Cumpleaños de Martin Luther King Jr.
# 1*1:3:1:0:0:0                 = Cumpleaños de Martin Luther King Jr.
# Observado por empleados federales en Washington D.C.
# 20 de enero                        = Día de la inauguración
tercer lunes de febrero             = Cumpleaños de Washington
último lunes de mayo              = Día Conmemorativo
primer lunes de septiembre            = Día del Trabajo
segundo lunes de octubre            = Día de Colón
# 4 de julio                         = Día de la Independencia
1*7:0:4:0:0:0*DWD               = Día de la Independencia
# 11/11                         = Día de los Veteranos
1*11:0:11:0:0:0*DWD             = Día de los Veteranos
# Para definir tanto el Día de Acción de Gracias como el día siguiente, usa las
# siguientes dos líneas:
cuarto jueves de noviembre            = Día de Acción de Gracias
1*11:4:4:0:0:0*FD1              = Día después del Día de Acción de Gracias
# 25 de diciembre                        = Navidad
1*12:0:25:0:0:0*DWD             = Navidad
# DÍAS FESTIVOS DE EJEMPLO
##################
# Puedes definir un festivo único especificando
# el día y el año.
6/2/1999                        = Un festivo especial de prueba para 1999
################################
# EVENTOS
################################
# Ver la página del manual de Date::Manip::Holidays para una descripción de
# esta sección.
*EVENTS
2000-02-01               = Evento01
2000-02-01-12:00:00      = Evento02
02-01                    = Evento03
02-01 12:00:00           = Evento04
1*2:0:3:13:00:00         = Evento05
2000-02-05 10:00:00 ; 2000-02-05 10:59:59 = Evento06
2000-02-05          ; 2000-02-06          = Evento07
02-05               ; 02-06               = Evento08
2000-02-07 10:00:00 ; 0:0:0:0:3:0:0       = Evento09
02-07 10:00:00      ; 0:0:0:0:4:0:0       = Evento10
1*2:0:7:10:00:00    ; 0:0:0:0:5:0:0       = Evento11
