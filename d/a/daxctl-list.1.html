DAXCTL-LIST(1) Manual de daxctl DAXCTL-LIST(1)

NOMBRE

daxctl-list - volcar las regiones Device-DAX de la plataforma, dispositivos y atributos en json.

SINOPSIS

daxctl list [<opciones>]

Recorre todas las regiones device-dax del sistema y lista todas las instancias de dispositivo junto con algunos de sus atributos principales.

Se pueden especificar opciones para limitar la salida a objetos de una clase determinada. Las clases son regiones o dispositivos. Por defecto, daxctl list sin opciones es equivalente a:

daxctl list --devices

EJEMPLO

# daxctl list --regions --devices
{
  "id":1,
  "devices":[
    {
      "chardev":"dax1.0",
      "size":3233808384
    }
  ]
}

OPCIONES

-r, --region=

Una región device-dax es un rango contiguo de memoria que alberga uno o más dispositivos /dev/daxX.Y, donde X es el id de la región e Y es el id de la instancia del dispositivo. La palabra clave all puede especificarse para llevar a cabo la operación en cada región del sistema.

-d, --dev=

Especifica un nombre de dispositivo dax, la tupla <id de región>.<id de instancia>, o la palabra clave all para filtrar el listado. Por ejemplo, para listar la primera instancia de dispositivo en la región1:
# daxctl list --dev=1.0
{
  "chardev":"dax1.0",
  "size":3233808384
}

-D, --devices

Incluir información de instancia de device-dax en el listado (por defecto)

-M, --mappings

Incluir información de mapeo de instancia de device-dax en el listado

-R, --regions

Incluir información de región en el listado

-i, --idle

Incluir dispositivos inactivos (no habilitados / de tamaño cero) en el listado

-u, --human

Por defecto, daxctl list generará datos numéricos sin procesar fáciles de usar por máquinas. En su lugar, con esta bandera, los números que representan el tamaño de almacenamiento se formatearán como cadenas legibles por humanos con unidades, otros campos se convertirán a cadenas hexadecimales. Ejemplo:
# daxctl list
{
  "chardev":"dax1.0",
  "size":32828817408
}
# daxctl list --human
{
  "chardev":"dax1.0",
  "size":"30.57 GiB (32.83 GB)"
}
