Data::Perl::Role::Bool(3) Documentación de Perl aportada por el usuario Data::Perl::Role::Bool(3)

NOMBRE

Data::Perl::Role::Bool - Clase contenedora para valores booleanos.

VERSIÓN

versión 0.002011

SINOPSIS

use Data::Perl qw/bool/;
my $bool = bool(0);
$bool->toggle; # 1
$bool->unset; # 0

DESCRIPCIÓN

Esta clase proporciona un contenedor y métodos para interactuar con valores booleanos.

MÉTODOS PROVISTOS

Ninguno de estos métodos acepta argumentos.

new($value)
Construye un nuevo objeto Data::Perl::Collection::Bool inicializado con el valor pasado y lo devuelve.
set
Establece el valor a 1 y devuelve 1.
unset
Establece el valor a 0 y devuelve 0.
toggle
Alterna el valor. Si es verdadero, lo establece a falso, y viceversa.

Devuelve el nuevo valor.

not
Equivalente a 'not $value'.
