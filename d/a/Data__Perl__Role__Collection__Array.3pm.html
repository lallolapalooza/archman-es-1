Data::Perl::Role::Collection::Array(3) Documentación de Perl aportada por el usuario Data::Perl::Role::Collection::Array(3)

NOMBRE

Data::Perl::Role::Collection::Array - Clase envolvente para la estructura de array incorporada de Perl.

VERSIÓN

versión 0.002011

SINOPSIS

use Data::Perl qw/array/;
my $array = array(1, 2, 3);
$array->push(5);
$array->grep(sub { $_ > 2 })->map(sub { $_ ** 2 })->elements; # (3, 5);

DESCRIPCIÓN

Esta clase proporciona un envoltorio y métodos para interactuar con un array. Todos los métodos que devuelven una lista lo hacen a través de un objeto Data::Perl::Collection::Array.

MÉTODOS PROPORCIONADOS

new($valor, $valor, ....)
Construye un nuevo objeto Data::Perl::Collection::Array inicializado con los valores pasados y lo devuelve.
count
Devuelve el número de elementos en el array. 
$stuff = Data::Perl::Collection::Array->new(qw/foo bar baz boo/);
print $stuff->count; # imprime 4

Este método no acepta ningún argumento.

is_empty
Devuelve un valor booleano que es verdadero cuando el array no tiene elementos. 
$stuff->is_empty ? die "¡No hay opciones!\n" : print "Buen chico.\n";

Este método no acepta ningún argumento.

elements/all
Devuelve todos los elementos del array como un array (no una referencia a array). 
my @options = $stuff->elements;
print "@options\n";    # imprime "foo bar baz boo"

Este método no acepta ningún argumento.

get($índice)
Devuelve un elemento del array por su índice. También puedes usar números de índice negativos, igual que con el manejo de arrays central de Perl. 
my $option = $stuff->get(1);
print "$option\n";    # imprime "bar"

Si el elemento especificado no existe, esto devolverá "undef".

Este método acepta solo un argumento.

pop
Igual que el incorporado de Perl "pop".

Este método no acepta ningún argumento.

push($valor1, $valor2, valor3 ...)
Igual que el incorporado de Perl "push". Devuelve el número de elementos en el nuevo array.

Este método acepta cualquier número de argumentos.

shift
Igual que el incorporado de Perl "shift".

Este método no acepta ningún argumento.

unshift($valor1, $valor2, valor3 ...)
Igual que el incorporado de Perl "unshift". Devuelve el número de elementos en el nuevo array.

Este método acepta cualquier número de argumentos.

splice($desplazamiento, $longitud, @valores)
Igual que el incorporado de Perl "splice". En contexto escalar, esto devuelve el último elemento eliminado, o "undef" si no se eliminaron elementos. En contexto de lista, esto devuelve todos los elementos eliminados del array, envueltos en un objeto Collection::Array.

Este método requiere al menos un argumento.

first( sub { ... } )
Este método devuelve el primer elemento coincidente en el array, igual que la función "first" de List::Util. La coincidencia se realiza con una referencia a subrutina que pasas a este método. La subrutina se llamará contra cada elemento del array hasta que uno coincida o se hayan comprobado todos los elementos. 
my $found = $stuff->find_option( sub {/^b/} );
print "$found\n";    # imprime "bar"

Este método requiere un solo argumento.

first_index( sub { ... } )
Este método devuelve el índice del primer elemento coincidente en el array, igual que la función "first_index" de List::MoreUtils. La coincidencia se realiza con una referencia a subrutina que pasas a este método. La subrutina se llamará contra cada elemento del array hasta que uno coincida o se hayan comprobado todos los elementos.

Este método requiere un solo argumento.

grep( sub { ... } )
Este método devuelve cada elemento que coincide con un criterio dado, igual que la función "grep" central de Perl. Este método requiere una subrutina que implemente la lógica de coincidencia. La lista devuelta se proporciona como un objeto Collection::Array. 
my @found = $stuff->grep( sub {/^b/} );
print "@found\n";    # imprime "bar baz boo"

Este método requiere un solo argumento.

map( sub { ... } )
Este método transforma cada elemento del array y devuelve un nuevo array, igual que la función "map" central de Perl. Este método requiere una subrutina que implemente la transformación. La lista devuelta se proporciona como un objeto Collection::Array. 
my @mod_options = $stuff->map( sub { $_ . "-tag" } );
print "@mod_options\n";    # imprime "foo-tag bar-tag baz-tag boo-tag"

Este método requiere un solo argumento.

reduce( sub { ... } )
Este método convierte un array en un solo valor, pasando a una función el valor hasta ahora y el siguiente valor del array, igual que la función "reduce" de List::Util. La reducción se realiza con una referencia a subrutina que pasas a este método. 
my $found = $stuff->reduce( sub { $_[0] . $_[1] } );
print "$found\n";    # imprime "foobarbazboo"

Este método requiere un solo argumento.

sort
sort( sub { ... } )
Devuelve los elementos del array en orden ordenado.

Puedes proporcionar una referencia a subrutina opcional para ordenar (como puedes con la función "sort" central de Perl). Sin embargo, en lugar de usar $a y $b en esta subrutina, necesitarás usar $_[0] y $_[1]. La lista devuelta se proporciona como un objeto Collection::Array.

# ascendente ASCIIbetical
my @sorted = $stuff->sort();
# Orden alfabético descendente
my @sorted_options = $stuff->sort( sub { lc $_[1] cmp lc $_[0] } );
print "@sorted_options\n";    # imprime "foo boo baz bar"

Este método acepta un solo argumento.

sort_in_place
sort_in_place( sub { ... } )
Ordena el array en el lugar, modificando el valor del atributo.

Puedes proporcionar una referencia a subrutina opcional para ordenar (como puedes con la función "sort" central de Perl). Sin embargo, en lugar de usar $a y $b, necesitarás usar $_[0] y $_[1] en su lugar. La lista devuelta se proporciona como un objeto Collection::Array.

Este método acepta un solo argumento.

reverse
Devuelve los elementos del array en orden invertido. La lista devuelta se proporciona como un objeto Collection::Array.

Este método no acepta ningún argumento.

<dt id="shuffle">shuffle
Devuelve los elementos del array en orden aleatorio, como "shuffle" de List::Util. La lista devuelta se proporciona como un objeto Collection::Array.

Este método no acepta ningún argumento.

uniq
Devuelve el array con todos los elementos duplicados eliminados, como "uniq" de List::MoreUtils. La lista devuelta se proporciona como un objeto Collection::Array.

Este método no acepta ningún argumento.

head($count)
Devuelve los primeros $count elementos del array. Si $count es mayor que el número de elementos en el array, se devuelve el array (sin "undef"espurios). Un $count negativo significa "todos menos los últimos $count elementos". La lista devuelta se proporciona como un objeto Collection::Array.
tail($count)
Devuelve los últimos $count elementos del array. Si $count es mayor que el número de elementos en el array, se devuelve el array (sin "undef"espurios). Un $count negativo significa "todos menos los primeros $count elementos". La lista devuelta se proporciona como un objeto Collection::Array.
join($str)
Une cada elemento del array usando el separador dado como argumento, igual que la función principal de Perl "join" . 
my $joined = $stuff->join(':');
print "$joined\n";    # imprime "foo:bar:baz:boo"

Este método requiere un solo argumento.

print($handle, $str)
Imprime la salida de join($str) en $handle. $handle por defecto es STDOUT, y join $str por defecto es join()'s default de ','. 
$joined = $stuff->print(*STDERR, ';'); # imprime foo;bar;baz en STDERR
set($index, $value)
Dado un índice y un valor, establece el valor del elemento del array especificado.

Este método devuelve el valor en $index después de la operación set.

Este método requiere dos argumentos.

delete($index)
Elimina el elemento en el índice dado del array.

Este método devuelve el valor eliminado, ya sea como array o escalar dependiendo de la semántica del contexto de splice. Tenga en cuenta que si no existe ningún valor, se

devolverá "undef".

Este método requiere un argumento.

insert($index, $value)
Inserta un nuevo elemento en el array en el índice dado.

Este método devuelve el nuevo valor en $index, ya sea como array o escalar dependiendo de la semántica del contexto de splice.

Este método requiere dos argumentos.

clear
Vacía el array completo, como "@array = ()".

Este método no define un valor de retorno.

Este método no acepta ningún argumento.

accessor($index)
accessor($index, $value)
Este método proporciona un accessor get/set para el array, basado en índices de array. Si se pasa un argumento, devuelve el valor en el índice especificado. Si se pasan dos argumentos, establece el valor del índice especificado.

Cuando se llama como setter, este método devuelve el nuevo valor en $index.

Este método acepta uno o dos argumentos.

natatime($n)
natatime($n, $code)
Este método devuelve un iterador que, en cada llamada, devuelve $n elementos más del array, en orden, como "natatime" de List::MoreUtils. Opcionalmente se puede proporcionar un coderef; se llamará en cada grupo de $n elementos en el array.

Este método acepta uno o dos argumentos.

shallow_clone
Este método devuelve un clon superficial de la referencia del array. El valor de retorno es una referencia a un nuevo array con los mismos elementos. Es superficial porque cualquier elemento que fuera una referencia en el original será la misma referencia en el clon.
flatten
Este método devuelve una lista de elementos en el array. Este método es un alias del método elements .
flatten_deep($level)
Este método devuelve una lista aplanada de elementos en el array. Aplanará los arrays contenidos dentro del array raíz recursivamente - la profundidad está controlada por el parámetro opcional $level .
