Data::Dump::Trace(3) Documentación de Perl aportada por el usuario Data::Dump::Trace(3)

NOMBRE

Data::Dump::Trace - Ayudantes para rastrear llamadas a funciones y métodos

SINOPSIS

use Data::Dump::Trace qw(autowrap mcall);
autowrap("LWP::UserAgent" => "ua", "HTTP::Response" => "res");
use LWP::UserAgent;
$ua = mcall(LWP::UserAgent => "new");      # en lugar de LWP::UserAgent->new;
$ua->get("http://www.example.com")->dump;

DESCRIPCIÓN

Se proporcionan las siguientes funciones:

autowrap( $clase )
autowrap( $clase => $prefijo )
autowrap( $clase1 => $prefijo1, $clase2 => $prefijo2, ... )
autowrap( $clase1 => \%info1, $clase2 => \%info2, ... )
Registra clases cuyos objetos se envuelven automáticamente cuando son devueltos por una de las funciones de llamada a continuación. Si se proporciona $prefijo, se usará para nombrar los objetos.

La alternativa es pasar un hash %info para cada clase. Las claves reconocidas son:

prefijo => $cadena
La cadena de prefijo utilizada para nombrar objetos de este tipo.
proto => \%hash
Un hash de prototipos a usar para los métodos cuando se envuelve un objeto.
wrap( nombre => $str, func => \&func, proto => $proto )
wrap( nombre => $str, obj => $obj, proto => \%hash )
Devuelve una función u objeto envuelto. Cuando se invoca una función envuelta, se imprime un rastreo después de que la función subyacente ha devuelto. Cuando se invoca un método en un objeto envuelto, se imprime un rastreo después de que los métodos en los objetos subyacentes han devuelto.

Consulte "Prototipos" para ver la descripción del argumento "proto".

call( $nombre, \&func, $proto, @ARGS )
Llama a la función dada con los argumentos dados. El rastreo utilizará $nombre como nombre de la función.

Consulte "Prototipos" para ver la descripción del argumento $proto.

mcall( $clase, $metodo, $proto, @ARGS )
mcall( $objeto, $metodo, $proto, @ARGS )
Llama al método dado con los argumentos dados.

Consulte "Prototipos" para ver la descripción del argumento $proto.

trace( $simbolo, $prototipo )
Reemplaza la función dada por $simbolo con una función envuelta.

Prototipos

Nota: La sintaxis de la cadena de prototipos descrita aquí es experimental y probablemente cambie en revisiones de esta interfaz.

El argumento $proto para call() y mcall() puede proporcionar opcionalmente un prototipo para la llamada a la función. Esto da al rastreador pistas sobre cómo formatear mejor las listas de argumentos y si hay argumentos de *entrada/salida* o de *salida*. La forma general para la cadena de prototipos es:

<argumentos> = <valor_de_retorno>

El prototipo predeterminado es "@ = @"; lista de valores como entrada y lista de valores como salida.

El valor '%' se puede usar tanto para argumentos como para el valor de retorno para indicar que se utilizan listas de estilo de pares clave/valor.

Alternativamente, los argumentos posicionales individuales se pueden listar, cada uno representado por una letra:

``i''
argumento de entrada
``o''
argumento de salida
``O''
argumento de entrada y salida

Si el prototipo del valor de retorno tiene "!" añadido, entonces señala que esta función establece errno ($!) cuando devuelve un valor falso. El rastreo mostrará el valor actual de errno en ese caso.

Si el prototipo del valor de retorno se parece a un nombre de variable (con el prefijo "$"), y la función devuelve un objeto bendecido, entonces el nombre de la variable se usará como prefijo y el objeto devuelto se rastreará automáticamente.
