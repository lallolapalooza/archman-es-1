@CONFIGFILE@(5) Manual de Formatos de Archivo @CONFIGFILE@(5)

NOMBRE

@CONFIGFILE@ - Archivo de configuración para @PROGRAM_NAME@

DESCRIPCIÓN

Existe un archivo de configuración a nivel de sistema @SYS_CONF_DIR@/@CONFIGFILE@ y archivos de configuración de usuario ~/.@PACKAGE@/@CONFIGFILE@. Cuando @PROGRAM_NAME@ es invocado por root, solo se lee el archivo de configuración del sistema. Cuando es invocado por un usuario ordinario, el archivo de configuración del usuario se lee adicionalmente. La configuración del archivo de usuario tendrá precedencia sobre la configuración del sistema.

El archivo de configuración consiste en líneas donde cada línea contiene un par palabra clave valor. La palabra clave y el valor están separados por espacios y/o tabulaciones.

El archivo puede contener secciones que son solo para un punto de montaje específico. Dicha sección comienza con una línea que contiene la ruta completa del punto de montaje entre corchetes. La sección termina al inicio de la siguiente sección o al final del archivo. Las opciones que se aplicarán a todos los sistemas de archivos montados deben ir antes de las primeras secciones. Las opciones dadas en una sección específica de montaje tendrán precedencia.

EJEMPLO

proxy foo.bar:8080
use_locks 0
[/media/dav]
use_locks 1
[/home/otto/mywebspace]
gui_optimize 1

Todos los sistemas de archivos @PACKAGE@ montados usarán el proxy foo.bar. Todos los sistemas de archivos @PACKAGE@ excepto /media/dav deshabilitarán el uso de bloqueos. /home/otto/mywebspace usará la opción gui_optimize.

REGLAS GENERALES DE SINTAXIS

Las líneas que solo contienen espacios y tabulaciones (líneas vacías) se ignoran.

# indica un comentario. El resto de la línea se ignora.

\ es el carácter de escape.

"" se usa para citar.

Si un valor contiene alguno de los caracteres especiales espacio, tabulación, #, \, o ", este carácter debe ser escapado por un \ precedente. Use ’\ ’ en lugar de ’ ’, ’\#’ en lugar de ’#’, ’\\’ en lugar de ’\’ y ’\"’ en lugar de ’"’.

Los valores que contienen espacios, tabulaciones o # pueden, en su lugar, ser encerrados entre comillas dobles. Pero " y ’ deben ser escapados incluso dentro de comillas dobles. Si la línea de inicio de una sección está entre comillas dobles, los corchetes deben estar dentro de las comillas (como "[/home/otto/con espacio]").

Los valores de opción booleanos (sí/no) deben darse como valor numérico. 0 para no, 1 para sí.

OPCIONES DE CONFIGURACIÓN DISPONIBLES

Opciones Generales

dav_user
Cuando es invocado por root, el demonio @PROGRAM_NAME@ se ejecutará como este usuario. El valor debe darse como nombre, no como ID numérico.
Por defecto: @USER@
Solo permitido en el archivo de configuración del sistema.
dav_group
El grupo del demonio @PROGRAM_NAME@ en ejecución. Los usuarios ordinarios deben ser miembros de este grupo para poder montar un sistema de archivos @PACKAGE@. El valor debe darse como nombre, no como ID numérico.
Por defecto: @GROUP@
Solo permitido en el archivo de configuración del sistema.
buf_size
Tamaño en KiB del búfer utilizado para comunicarse con el sistema de archivos del kernel. Solo útil con fuse, donde las operaciones de lectura y escritura pueden beneficiarse de un búfer más grande.
Por defecto: 16

Opciones Relacionadas con WebDAV

use_proxy
Si se debe usar un proxy para conectarse al servidor WebDAV. 0 = no, 1 = sí. Si no se define ningún proxy en el archivo de configuración o en las variables de entorno https_proxy, http_proxy y all_proxy, esta opción no tiene efecto.
Por defecto: 1
Solo permitido en el archivo de configuración del sistema.
proxy
Nombre del proxy. El nombre debe ser el nombre de dominio completamente calificado (sin esquema). Si el puerto del proxy difiere del valor predeterminado de 8080, debe añadirse, separado por dos puntos. Ejemplos: foo.bar:1704 o foo.bar
Solo permitido en el archivo de configuración del sistema.
trust_ca_cert
Nombre de un archivo de certificado en formato PEM. El nombre del archivo puede darse como ruta absoluta o solo como nombre de archivo. En este último caso, se buscará en los directorios ~/.@PACKAGE@/@CERTS_DIR@ y @SYS_CONF_DIR@/@CERTS_DIR@.
Esta opción es útil cuando el certificado presentado por el servidor no puede ser verificado usando la base de datos del sistema de autoridades certificadoras (CA) de confianza. El archivo de certificado debe contener el certificado autofirmado de la CA de nivel superior en la cadena de confianza. Puede ser un certificado de servidor autofirmado (pero véase también trust_server_cert). Con esta opción, la base de datos de CA del sistema se ignora.
Nota: Incluso si el certificado del servidor es de confianza, eso no significa que sea aceptado. Además, la fecha del certificado debe ser válida y, o bien el CommonName o el SubjectAltName deben coincidir con el nombre de host del servidor.
servercert
Igual que trust_ca_cert pero con un nombre incorrecto.
Obsoleto
trust_server_cert
Nombre de un archivo de certificado en formato PEM. El nombre del archivo puede darse como ruta absoluta o solo como nombre de archivo. En este caso, se buscará en los directorios ~/.@PACKAGE@/@CERTS_DIR@ y @SYS_CONF_DIR@/@CERTS_DIR@.
Útil cuando el certificado del servidor no se puede verificar o incluso es inválido, pero usted sabe que puede confiar en este certificado. Cuando el servidor presenta un certificado que es exactamente igual a este y cuando el servidor es capaz de autenticarse contra la clave pública contenida en este certificado, se establecerá la conexión.
Esta es la opción preferida para certificados de servidor autofirmados.
No se intentarán otras formas de verificar el certificado y el certificado no será verificado en cuanto a su validez.
clientcert
Nombre de un certificado en formato PKCS#12 que se utilizará para autenticarse con el servidor. El nombre del archivo puede darse como ruta absoluta o solo como nombre de archivo. En este último caso, se buscará en los directorios ~/.@PACKAGE@/@CERTS_DIR@/@CLICERTS_DIR@ y @SYS_CONF_DIR@/@CERTS_DIR@/@CLICERTS_DIR@.
Advertencia: Si el certificado del cliente es emitido por una CA intermedia y no por una CA de nivel superior, la especificación TLS requiere que el cliente envíe la cadena completa de certificados (sin el certificado de la CA de nivel superior). davfs2 solo envía el certificado del cliente. Para solucionar este error, el servidor debe almacenar y confiar en la cadena completa de certificados de CA hasta la CA que emitió el certificado del cliente.
secrets
Nombre de un archivo que contiene las credenciales para servidores y el proxy, y contraseñas para descifrar el certificado del cliente. El nombre debe ser una ruta absoluta. El archivo debe ser legible y escribible solo por el propietario (modo 600).
Por defecto: ~/.@PACKAGE@/@SECRETSFILE@
Solo permitido en el archivo de configuración del usuario. El archivo de secretos del sistema es siempre @SYS_CONF_DIR@/@SECRETSFILE@.
ask_auth
Preguntar interactivamente al usuario por las credenciales y contraseñas si no se encuentran en el archivo de secretos. Preguntar al usuario si un certificado de servidor no puede ser verificado. 0 = no, 1 = sí.
Por defecto: 1

Opciones relacionadas con WebDAV y HTTP

lock_protocol
Protocolo que se utilizará para bloquear recursos WebDAV. Los valores posibles son: 0 = sin bloqueo 1 = Lock 2 = LOCK (para el protocolo de bloqueo de Apache) La opción de bloqueo no se puede usar cuando se montan múltiples sistemas de archivos de DAV con el mismo usuario.
Default: 1
lock_owner
Una cadena enviada al servidor para identificar al propietario de un bloqueo. Si un recurso WebDAV es utilizado al mismo tiempo por diferentes clientes usando las mismas credenciales, se deben elegir valores diferentes para lock_owner.
Default: el nombre de usuario de las credenciales
lock_timeout
Cuánto tiempo en segundos deben ser válidos los bloqueos, antes de que el servidor los elimine. El servidor puede ignorar esto y establecer su propio valor de tiempo de espera.
Default: 1800
lock_refresh
Tantos segundos antes de que expire el bloqueo, @PROGRAM_NAME@ intentará renovar el bloqueo. El valor debe ser sustancialmente mayor que delay_upload.
Default: 60
use_expect100
Para evitar la carga de archivos grandes que serán rechazados por el servidor, @PROGRAM_NAME@ utiliza la cabecera expect: 100-continue para obtener el visto bueno del servidor antes de cargar. No todos los servidores entienden esto. 0 = no, 1 = sí.
Default: 0
if_match_bug
Algunos servidores no manejan correctamente las cabeceras If-Match y If-None-Match. Esta opción indica a @PROGRAM_NAME@ que use HEAD en lugar de estas cabeceras. 0 = no, 1 = sí.
Default: 0
drop_weak_etags
Los servidores populares envían un etag débil siempre que no pueden calcular uno fuerte. Este etag débil nunca será válido, pero después de un segundo se convierte silenciosamente en un etag fuerte y válido. Con esta bandera establecida en 1, @PROGRAM_NAME@ nunca usará estos etags débiles. Si la bandera es 0, el indicador de debilidad se eliminará y se asumirá que el etag es fuerte. Existe cierto peligro del Problema de Actualización Perdida con esto. Pero se minimiza al usar bloqueos.
Deberías activarlo, cuando no puedas usar bloqueos y exista el peligro de acceso concurrente al mismo recurso. En este caso, el etag no se usa en absoluto y el recurso no se puede almacenar en caché.
0 = no, 1 = sí.
Default: 0
n_cookies
Algunos servidores solo funcionarán cuando se les permita establecer una cookie y esta cookie se devuelva en solicitudes posteriores. Esta opción establece el número de cookies que estás dispuesto a aceptar e incluir en solicitudes posteriores. davfs2 solo se preocupará por el nombre y el valor de la cookie e ignorará todos los atributos posibles.
Default: 0
precheck
Si la opción if_match_bug está establecida: utiliza solicitudes HEAD para comprobar la existencia o modificación de un archivo para evitar sobrescribir inadvertidamente lo que alguien más cambió. No tiene ningún efecto si la opción if_match_bug es 0. Solo deberías establecerlo en 0 si no hay acceso concurrente al servidor. 0 = no, 1 = sí.
Default: 1
ignore_dav_header
Algunos servidores envían información incorrecta sobre sus capacidades en la cabecera DAV. En este caso, la cabecera debe ser ignorada.
Default: 0
use_compression
Utiliza compresión gzip para descargar archivos, si es compatible con el servidor. Las cargas seguirán sin comprimir.
Default: 0
min_propset
Se ha informado que algunos servidores se ralentizan significativamente cuando se solicitan las propiedades Etag y Last-Modified. Esta opción reducirá el conjunto de propiedades WebDAV solicitadas al servidor al conjunto mínimo. No la uses si tu sistema de archivos se utiliza para leer y escribir. Sin Etag o Last-Modified, davfs2 no podrá comprobar cambios en el servidor, lo que puede resultar en descargas innecesarias y actualizaciones perdidas. Esta opción también deshabilitará efectivamente el almacenamiento en caché de archivos porque los archivos en la caché no se podrán reutilizar.
Default: 0
follow_redirect
Si el servidor redirige una solicitud GET a un recurso diferente (quizás en un servidor diferente), sigue esta redirección.
Actualmente existen algunas restricciones: todas las redirecciones se tratan como redirecciones temporales; si el nuevo servidor requiere autenticación, se utilizan las mismas credenciales que para el servidor original; si la conexión es a través de TLS, el certificado del servidor se verificará con las CA de confianza conocidas por el sistema; los certificados de servidor configurados por el usuario y los certificados de cliente no se utilizan para el nuevo servidor.
Default: 0
sharepoint_href_bug
SharePoint no codifica correctamente los caracteres UTF8 dentro del elemento href. Debido a esto, algunos archivos son invisibles porque el elemento href viola las reglas. Neon 0.31 y versiones más recientes tienen una solución para este error de SharePoint. Esta opción activará esta solución.
Default: 0
server_charset
Al extraer nombres de archivo del componente de ruta de la URL, @PROGRAM_NAME@ asumirá que están codificados usando este conjunto de caracteres y traducirá los nombres de archivo al conjunto de caracteres local. Esto **no** se refiere a la codificación del contenido de los archivos y **no** a las reglas de escape HTTP.
No hay forma en HTTP de conocer la codificación de caracteres del componente de ruta. Puede haber incluso codificaciones diferentes dentro de la misma ruta, ya que la codificación de los nombres de archivo a menudo la definen los clientes que los crearon. Hoy en día, lo mejor es usar solo codificación UTF-8 y no hacer conversión. Si no estás seguro de que todos los clientes entiendan UTF-8, restringe los nombres de archivo a us-ascii puro. Nunca uses caracteres en los nombres de archivo que puedan tener una función especial en algunos sistemas operativos (como /, : y \).
Default: sin conversión de conjunto de caracteres
connect_timeout
Al crear una conexión TCP con el servidor, @PROGRAM_NAME@ esperará esa cantidad de segundos por una respuesta antes de asumir un error. Si se usa un valor de '0', no se establece ningún tiempo de espera explícito y la llamada connect solo tendrá tiempo de espera según lo dictado por la pila TCP.
Este parámetro solo tendrá efecto si la versión de neon en uso (versión de neon > 0.26) y el sistema operativo admiten E/S no bloqueantes.
Default: 10
read_timeout
Cuánto tiempo en segundos @PROGRAM_NAME@ esperará una respuesta del servidor antes de asumir un error.
Default: 30
retry
Cuando @PROGRAM_NAME@ no puede alcanzar el servidor, lo intentará de nuevo después de retry segundos. Para reintentos posteriores, el intervalo se incrementará hasta max_retry segundos.
Default: 30
max_retry
Valor máximo del intervalo de reintento.
Default: 300
max_upload_attempts
Cuando la carga de un archivo modificado falla temporalmente, @PROGRAM_NAME@ lo intentará de nuevo con intervalos crecientes, pero no más a menudo que esto.
Con una conexión deficiente, esto causará tráfico adicional. Para reducir el tráfico causado por intentos fallidos, se puede establecer la opción use_expect100. Pero pruébalo. La mayoría de los proxies y algunos servidores no admiten esta cabecera.
Default: 15
add_header
Es posible que tu servidor espere cabeceras especiales para hacer lo que deseas. A diferencia de otras opciones, esta toma dos valores: el nombre de la cabecera y su valor. Algunos backends ASP para IIS parecen requerir la cabecera específica de Microsoft "Translate: F". Puedes añadirla así:
add_header Translate F
@PROGRAM_NAME@ añadirá la cabecera "Translate: F" en todas las solicitudes.
Esta opción es acumulativa. Puedes introducir más de una opción add_header y se añadirán todas. También las opciones add_header de @SYS_CONF_DIR@/@CONFIGFILE@ y ~/.@PACKAGE@/@CONFIGFILE@ se fusionan.

Opciones relacionadas con la caché

backup_dir
Cada sistema de archivos @PACKAGE@ montado tiene un directorio para almacenar copias de seguridad de archivos que no pudieron ser devueltos al servidor. Esto establece el nombre de este directorio. Deberías revisar este directorio regularmente.
Default: lost+found
cache_dir
El directorio donde @PROGRAM_NAME@ almacenará los archivos cacheados. Para cada punto de montaje se creará un subdirectorio.
En el archivo de configuración global del sistema, esto establecerá la caché global del sistema, utilizada por root. En el archivo de configuración de un usuario, establecerá la caché utilizada por este usuario.
Defaults: @SYS_CACHE_DIR@ y ~/.@PACKAGE@/cache
cache_size
La cantidad de espacio en disco en MiByte que se puede utilizar. @PROGRAM_NAME@ siempre ocupará suficiente espacio para cachear los archivos abiertos, ignorando este valor si es necesario.
Default: 50
table_size
@PROGRAM_NAME@ mantiene una tabla hash con una entrada por cada archivo o directorio conocido. Esto da el número de entradas en esta tabla. Para sistemas de archivos grandes (más de algunos cientos de archivos), aumentar este número puede acelerar las operaciones de archivo. El valor debe ser una potencia de 2.
Default: 1024
dir_refresh
Después de que @PROGRAM_NAME@ ha obtenido información sobre los archivos en un directorio, la considera válida durante este tiempo en segundos. Nota: Esto no afecta la apertura de archivos y la lectura de un directorio por una aplicación.
Default: 60
file_refresh
Cuando un archivo o directorio es abierto por una aplicación, @PROGRAM_NAME@ primero comprobará en el servidor para una versión más reciente. Pero algunas aplicaciones realizan llamadas de apertura sobre el mismo archivo en secuencia corta. Para evitar tráfico innecesario @PROGRAM_NAME@ esperará ese número de segundos antes de enviar una nueva solicitud para la misma información.
Predeterminado:
1
delay_uplo
ad
Cuando se cierra un archivo que ha sido modificado, @PROGRAM_NAME@ esperará ese número de segundos antes de subirlo al servidor. Esto evitará la subida de archivos temporales que serán eliminados inmediatamente después de cerrarse. Si necesita que los archivos aparezcan en el servidor inmediatamente después de cerrarse, establezca esta opción en 0.
Predeterminado:
10
gui_optimi
ze
Cuando se abre un archivo, @PROGRAM_NAME@ tendrá que comprobar en el servidor si existe una versión más reciente. Las interfaces gráficas de usuario tienden a abrir cualquier archivo, ralentizando drásticamente las cosas en directorios grandes. Con esta opción @PROGRAM_NAME@ intentará obtener esta información de todos los archivos de un directorio con una sola petición PROPFIND. 0 = no, 1 = sí.
Predeterminado:
0
minimize_m
em
davfs2 mantiene información sobre archivos y directorios en la memoria de trabajo. Permanecerá allí mientras el sistema de archivos esté montado y el archivo no sea eliminado. De este modo, el uso de memoria por parte de davfs2 crecerá con el tiempo y puede ralentizar davfs2. Con esta opción establecida en 1, davfs2 limpiará regularmente la memoria de la información que no se ha utilizado durante algún tiempo. 0 = no, 1 = sí.
Advertencia: La mayoría de los atributos de los archivos solo se mantienen localmente porque no existe una propiedad WebDAV correspondiente. Por lo tanto, si los usuarios cambian atributos (propietario, grupo, bits de acceso) localmente, estos cambios se perderán y los valores de los atributos se restablecerán a los valores predeterminados.

Envía mensajes de depuración al demonio syslog. El valor indica qué tipo de información debe registrarse. Los mensajes se envían con la facilidad LOG_DAEMON y la prioridad LOG_DEBUG.
