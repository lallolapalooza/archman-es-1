dane_raw_tlsa(3) gnutls dane_raw_tlsa(3)

NOMBRE

dane_raw_tlsa - función de la API

SINOPSIS

#include <gnutls/dane.h>

int dane_raw_tlsa(dane_state_t s, dane_query_t * r, char *const * dane_data, const int * dane_data_len, int secure, int bogus);

ARGUMENTOS

dane_state_t s
La estructura de estado DANE
dane_query_t * r
Una estructura para colocar el resultado
char *const * dane_data
matriz de elementos rdata de DNS, terminada con un puntero NULL; el llamador debe garantizar que los datos referenciados permanezcan válidos hasta que se llame a dane_query_deinit().
const int * dane_data_len
la longitud n en bytes de los elementos dane_data
int secure
verdadero si el resultado se valida de forma segura, falso si la validación falló o el dominio consultado no tiene información de seguridad
int bogus
si el resultado no fue seguro (secure = 0) debido a un fallo de seguridad, y el resultado se debe a un fallo de seguridad, bogus es verdadero.

DESCRIPCION

Esta función rellenará la estructura TLSA (DANE) a partir de los datos del registro DNS crudos proporcionados. El dane_data debe ser válido durante la vida útil de la consulta.

DEVOLUCIONES

En caso de éxito, se devuelve DANE_E_SUCCESS (0), de lo contrario, un valor de error negativo.
