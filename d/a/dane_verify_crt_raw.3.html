dane_verify_crt_raw(3)

Paquete: gnutls

Licencias: GPL-3.0-or-later AND LGPL-2.1-or-later

dane_verify_crt_raw(3) gnutls dane_verify_crt_raw(3)

NOMBRE

dane_verify_crt_raw - función de la API

SINOPSIS

#include <gnutls/dane.h>

int dane_verify_crt_raw(dane_state_t s, const gnutls_datum_t * chain, unsigned chain_size, gnutls_certificate_type_t chain_type, dane_query_t r, unsigned int sflags, unsigned int vflags, unsigned int * verify);

ARGUMENTOS

dane_state_t s
Una estructura de estado DANE (puede ser NULL)
const gnutls_datum_t * chain
Una cadena de certificados
unsigned chain_size
El tamaño de la cadena
gnutls_certificate_type_t chain_type
El tipo de la cadena de certificados
dane_query_t r
Datos DANE para verificar
unsigned int sflags
Banderas para la inicialización de s (si es NULL)
unsigned int vflags
Banderas de verificación; una lista OR de dane_verify_flags_t.
unsigned int * verify
Una lista OR de dane_verify_status_t.

DESCRIPCIÓN

Esta es la función de bajo nivel de dane_verify_crt(). Consulte la función de alto nivel para obtener documentación.

Esta función no realiza ninguna resolución, utiliza entradas en caché de r.

RETORNA

Un código de error negativo en caso de error y DANE_E_SUCCESS (0) cuando las entradas DANE se analizaron correctamente, independientemente de si se verificaron (consulte verify para obtener esa información). Si no se encontraron entradas utilizables, se devolverá DANE_E_REQUESTED_DATA_NOT_AVAILABLE.
