SINOPSI

S 
use Data::OptList;
my $options = Data::OptList::mkopt([
  qw(key1 key2 key3 key4),
  key5 => { ... },
  key6 => [ ... ],
  key7 => sub { ... },
  key8 => { ... },
  key8 => [ ... ],
])
;

...es más o menos lo mismo

que: 
my $options = [
  [ key1 => undef,        ],
  [ key2 => undef,        ],
  [ key3 => undef,        ],
  [ key4 => undef,        ],
  [ key5 => { ... },      ],
  [ key6 => [ ... ],      ],
  [ key7 => sub { ... },  ],
  [ key8 => { ... },      ],
  [ key8 => [ ... ],      ],
]
)
;

DESCRIPCIÓ

N

Los hashes son geniales para almacenar datos con nombre, pero si quieres más de una entrada para un nombre, tienes que usar una lista de pares. Incluso así, esto es realmente aburrido de

escribir: 
$values = [
  foo => undef,
  bar => undef,
  baz => undef,
  xyz => { ... },
]
;

¡Solo mira todos esos undefs! No te preocupes, podemos deshacernos de

ellos: 
$values = [
  map { $_ => undef } qw(foo bar baz),
  xyz => { ... },
]
;

¡Aaaauuugh! Hemos ahorrado un poco de escritura, pero ahora requiere pensamiento para leer, y pensar es incluso peor que escribir... ¡y tiene un error! Parecía correcto, ¿verdad? Bueno, el "xyz => { ... }" es consumido por el map, y no obtenemos los datos que

queríamos.

Con Data::OptList, puedes hacer esto en su

lugar: 
$values = Data::OptList::mkopt([
  qw(foo bar baz),
  xyz => { ... },
])
;

Esto funciona asumiendo que cualquier esca

lar definido es un nombre y cualquier ref
erencia que sigue a un nombre es su valor.

VERSIÓN DE

PERL

Esta biblioteca debería ejecutarse en versiones de perl lanzadas hace mucho tiempo. Debería funcionar en cualquier versión de perl lanzada en los últimos cinco

años.

Aunque puede funcionar en versiones más antiguas de perl, no se garantiza que la versió

n mínima requerida no aumentará. La versión puede aumentarse por cualquier razón, y no
hay promesa de que se acepten parches para reducir la versión mínima de perl requerida.

FUNCIONE

S

mkop

t 
my $opt_list = Data::OptList::mkopt($input, \%arg)
;

Los argumentos válidos

son: 
moniker        - una palabra usada en errores para describir la lista de opciones; se recomienda
require_unique - si es verdadero, ningún nombre puede aparecer más de una vez
must_be        - tipos a los que se limitan los valores de la lista de opciones (descritos más abajo)
name_test      - una referencia a código usada para probar si un valor puede ser un nombre
                 (descrito más abajo, pero probablemente no lo
quieras)

Esto produce un array de arrays; los arrays internos son pares nombre/valor. Los valores serán o "undef" o una

referencia.

Se pueden usar parámetros posicionales para compatibilidad con la antigua interfaz "m

kopt": 
my $opt_list = Data::OptList::mkopt($input, $moniker, $req_uni, $must_be)
;

Valores válidos para $input

: 
undef    -> []
hashref  -> [ [ key1 => value1 ] ... ] # los valores que no son referencias se convierten en undef
arrayref -> cada nombre seguido de un no-nombre se convierte en un par: [ name => ref ]
            cada nombre seguido de undef se convierte en un par: [ name => undef ]
            de lo contrario, se convierte en [ name => undef ] así:
            [ "a", "b", [ 1, 2 ] ] -> [ [ a => undef ], [ b => [ 1, 2 ] ]
]

Por defecto, un nombre es cualquier escalar definido que no sea una referencia. El parámetro "name_test" puede ser una referencia a código que prueba si el argumento pasado es un nombre o no. Esto debería usarse raramente. Las interacciones entre "require_unique" y "name_test" aún no son particularmente elegantes, ya que "require_unique" solo prueba la igualdad de cadenas. Esto puede

cambiar.

El parámetro "must_be" es un escalar o un array de escalares; define qué tipo(s) de referencias pueden ser valores. Si se encuentra un valor no válido, se lanza una excepción. Si no se pasa ningún valor para este argumento, cualquier referencia es válida. Si "must_be" especifica que los valores deben ser CODE, HASH, ARRAY o SCALAR, entonces se usa Params::Util para comprobar si el valor dado puede proporcionar esa interfaz. De lo contrario, se comprueba que el valor dado es un objeto de ese

tipo.

En otras

palabras: 
[ qw(SCALAR HASH Object::Known)
]

Significa

: 
_SCALAR0($value) or _HAS
H($value) or _INSTANCE(
$value, 'Object::Known')

mkopt_has

h 
my $opt_hash = Data::OptList::mkopt_hash($input, $moniker, $must_be)
;

Dada una entrada válida para "mkopt", esta rutina devuelve una referencia a

un hash. Lanzará una ex
cepción si algún nomb
re tiene más de un valor.
