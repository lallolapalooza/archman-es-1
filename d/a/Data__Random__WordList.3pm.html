NOMBRE

Data::Random::WordList - Módulo Perl para obtener palabras aleatorias de una lista de palabras

SINOPSIS

use Data::Random::WordList;
my $wl = new Data::Random::WordList( wordlist => '/usr/dict/words' );
my @rand_words = $wl->get_words(10);
$wl->close();

DESCRIPCIÓN

Data::Random::WordList es un módulo que gestiona un archivo que contiene una lista de palabras.

El módulo espera que cada línea del archivo de lista de palabras contenga solo una palabra. Por lo tanto, podría usarse fácilmente para seleccionar líneas aleatorias de un archivo, pero por coherencia, seguiré refiriéndome a cada línea como una palabra.

El módulo utiliza un manejador de archivos persistente para que no haya mucha sobrecarga cada vez que quieras obtener una lista de palabras aleatorias. Sin embargo, es mucho más eficiente obtener varias palabras a la vez que obtener una palabra a la vez varias veces.

El módulo también se abstiene de leer todo el archivo en memoria, por lo que puede ser más seguro de usar con archivos más grandes.

MÉTODOS

new()

Devuelve una referencia a un nuevo objeto Data::Random::WordList. Usa el parámetro "wordlist" para inicializar el objeto:

•
wordlist - la ruta al archivo de lista de palabras. Si no se proporciona una ruta, se utiliza la lista de palabras distribuida con este módulo.

get_words([NUM])

NUM contiene el número de palabras que deseas de la lista de palabras. NUM por defecto es 1 si no se especifica. get_words() muere si NUM es mayor que el número de palabras en la lista de palabras. Esta función devuelve un array o una referencia a un array dependiendo del contexto en el que se llame.

close()

Cierra el manejador de archivos asociado con la lista de palabras. Es una buena práctica hacerlo cada vez que hayas terminado con la lista de palabras.
