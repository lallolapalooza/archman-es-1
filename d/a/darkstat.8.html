--pidfile nombre_de_archivo
Crea un archivo que contiene el ID del proceso de darkstat. Este archivo se eliminará al apagarse limpiamente. Como con todos los archivos pid, si darkstat muere de forma no limpia, puede quedar un archivo pid obsoleto.

Por ejemplo, inicie darkstat con:

darkstat -i fxp0 --chroot /var/run/darkstat --pidfile darkstat.pid

Y detenga con:

kill `cat /var/run/darkstat/darkstat.pid`

Por defecto, kill(1) enviará SIGTERM, lo que hará que darkstat se apague limpiamente.

--hosts-max cantidad
El número máximo de hosts que se mantendrán en la tabla de hosts. Esto se utiliza para limitar cuántos datos de contabilidad se mantendrán en memoria. El número de --hosts-max debe ser mayor que --hosts-keep
--hosts-keep cantidad
Cuando la tabla de hosts alcanza --hosts-max y se ve tráfico de un nuevo host, limpiamos la tabla de hosts, manteniendo solo los primeros --hosts-keep hosts, ordenados por tráfico total.
--ports-max cantidad
El número máximo de puertos que se rastrearán para cada host. Esto se utiliza para limitar cuántos datos de contabilidad se mantendrán en memoria. El número de --ports-max debe ser mayor que --ports-keep
--ports-keep cantidad
Cuando una tabla de puertos se llena, se conservan estos puertos y el resto se descartan.
--highest-port puerto
Los puertos que son numéricamente más altos que este no aparecerán en las tablas de puertos por host, aunque su tráfico seguirá siendo contabilizado. Esto se puede usar para ocultar puertos efímeros. Por defecto, todos los puertos son rastreados.
--wait segs
No use esto. Es un arreglón para ayudar a las víctimas de NetworkManager y sistemas similares.

Debería iniciar darkstat después de que la interfaz de captura haya subido. Si no puede, especificar la opción --wait hará que darkstat duerma hasta el número especificado de segundos para que la interfaz esté lista. Cero significa esperar indefinidamente.

--hexdump
Muestra volcados hexadecimales del tráfico recibido. Esto es solo para depuración, e implica --verbose y --no-daemon.

USO EJEMPLOS

Para recopilar estadísticas en la interfaz fxp0 :

darkstat -i fxp0

Queremos contabilizar el tráfico en la interfaz orientada a Internet, pero solo servir páginas web a nuestra red local privada donde tenemos la dirección IP 192.168.0.1:

darkstat -i fxp0 -b 192.168.0.1

Queremos servir páginas web en el puerto HTTP estándar:

darkstat -i fxp0 -p 80

Estamos en Optus (cable) y no queremos contabilizar el tráfico ARP constante que estamos recibiendo:

darkstat -i fxp0 -f "not arp"

Solo queremos contabilizar el tráfico SSH:

darkstat -i fxp0 -f "port 22"

No queremos contabilizar el tráfico entre IPs internas:

darkstat -i fxp0 -f "not (src net 192.168.0 and dst net 192.168.0)"

(Para una referencia completa sobre la sintaxis del filtro, consulte la tcpdump(1) página del manual)

Tenemos una red que consta de un servidor de puerta de enlace (192.168.1.1) y algunas estaciones de trabajo (192.168.1.2, 192.168.1.3, etc.) y queremos graficar todo el tráfico que entra y sale de la red local, no solo el del servidor de puerta de enlace (que está ejecutando darkstat):

darkstat -i fxp0 -l 192.168.1.0/255.255.255.0

En algunos sistemas, no podemos capturar en una interfaz "decodificada" sino solo en nas0 que devuelve paquetes encapsulados en PPPoE. Haga la decodificación PPPoE, y anule la IP local manualmente ya que no puede ser detectada automáticamente. Note la máscara de red /32:

darkstat -i nas0 --pppoe -l 192.168.1.1/255.255.255.255

SEÑALES

Para apagar darkstat limpiamente, envíe una señal SIGTERM o SIGINT al proceso padre de darkstat .

Enviar la señal SIGUSR1 hará que darkstat vacíe su base de datos en memoria. Si se estableció un archivo --export , primero guardará la base de datos en el archivo. Enviar SIGUSR2 guardará la base de datos sin vaciarla.

PREGUNTAS FRECUENTES

¿Cuántos bytes representa cada barra en el gráfico?

Pase el cursor del ratón sobre una barra y debería obtener una información emergente diciendo exactamente cuántos bytes de entrada y salida representa la barra.

¿Por qué no hay etiquetas / marcas / una escala en los gráficos?

Porque implementarlas es difícil. Y hacerlo correctamente, y de una manera que funcione en todos los navegadores, parece bastante imposible.

Puede que lo intente algún día. Mientras tanto, los parches serían bienvenidos.

¿Por qué los gráficos están en blanco? Todas las barras son cero.

Los gráficos solo muestran el tráfico de entrada/salida del host local, que se determina obteniendo la dirección IP de la interfaz en la que está capturando.

Puede usar el argumento -l para anular la dirección local con fines de contabilidad. También puede usarlo para hacer contabilidad de toda una subred especificando una máscara de red apropiada.
