DESCRIPCIÓ

N

Dada una lista de escalares o variables de referencia, escribe su contenido en sintaxis de perl. Las referencias también pueden ser objetos. El contenido de cada variable se emite en una sola sentencia de Perl. Maneja correctamente las estructuras autorreferenciales

.

El valor de retorno puede ser "eval"ado para obtener una copia idéntica de la estructura de referencia original. (Por favor, considere las implicaciones de seguridad de evaluar código de fuentes no confiables!

)

Cualquier referencia que sea igual a una de las pasadas será nombrada $VARn (donde n es un sufijo numérico), y otras referencias duplicadas a subestructuras dentro de $VARn serán etiquetadas apropiadamente usando notación de flecha. Puede especificar nombres para valores individuales a volcar si usa el método Dump(), o puede cambiar el prefijo $VAR por defecto a algo más. Vea $Data::Dumper::Varname y $Data::Dumper::Terse en "Variables de configuración o métodos" más

abajo.

La salida por defecto de estructuras autorreferenciales puede ser "eval"ada, pero las referencias anidadas a $VARn serán indefinidas, ya que una estructura recursiva no puede ser construida usando una sola sentencia de Perl. Debería establecer el indicador "Purity" a 1 para obtener sentencias adicionales que rellenarán correctamente estas referencias. Además, si se "eval"úa cuando las restricciones (strictures) están activas, necesita asegurarse de que cualquier variable a la que accede haya sido previamente

declarada.

En la forma de uso extendida, las referencias a volcar pueden recibir nombres especificados por el usuario. Si un nombre comienza con un "*", la salida describirá el tipo desreferenciado de la referencia proporcionada para hashes y arrays, y referencias a código. Se evitará la salida de nombres donde sea posible si el indicador "Terse" está

establecido.

En muchos casos, los métodos utilizados para establecer el estado interno del objeto devolverán el objeto mismo, de modo que las llamadas a métodos pueden encadenarse convenientemente

.

Son posibles varios estilos de salida, todos controlados por la configuración del indicador "Indent". Vea "Variables de configuración o métodos" más abajo para

detalles.

Se pueden usar varias variables de configuración para controlar el tipo de salida generada al usar la interfaz de procedimiento. Estas variables son usualmente "local"izadas en un bloque para que otras partes del código no se vean afectadas por el

cambio.

Estas variables determinan el estado por defecto del objeto creado al llamar al método "new", pero no pueden usarse para alterar el estado del objeto después. Deberían usarse los nombres de métodos equivalentes en su lugar para consultar o establecer el estado interno del

objeto.

ERRORE

S

Debido a las limitaciones de la semántica de llamada a subrutinas de Perl, no puedes pasar un array o un hash. Antepónle un "\" para pasar su referencia en su lugar. Esto se corregirá con el tiempo, ahora que Perl tiene prototipos de subrutinas. Por ahora, necesitas usar la forma de uso extendida, y anteponer el nombre con un "*" para imprimirlo como un hash o un

array.

"Data::Dumper" hace trampa con las referencias CODE. Si se encuentra una referencia de código en la estructura que se está procesando (y si no has establecido el indicador "Deparse"), se insertará en su lugar una subrutina anónima que contiene la cadena '"DUMMY"', y se imprimirá una advertencia si "Purity" está establecido. Puedes "eval" el resultado, pero ten en cuenta que la sub anónima que se crea es solo un marcador de posición. Incluso usando el indicador "Deparse" en algunos casos producirá resultados que se comportan de manera diferente después de ser pasados a "eval"; consulta la documentación de B::

Deparse.

Los objetos SCALAR tienen la solución de "bless" más

extraña.

NOT

A

Diferentes ejecuciones de Perl tendrán un orden diferente de las claves de hash. El cambio se hizo por mayor seguridad, consulta "Algorithmic Complexity Attacks" en perlsec. Esto significa que diferentes ejecuciones de Perl tendrán diferentes salidas de Data::Dumper si los datos contienen hashes. Si necesitas tener salidas idénticas de Data::Dumper de diferentes ejecuciones de Perl, usa la variable de entorno PERL_HASH_SEED, consulta "PERL_HASH_SEED" en perlrun. Usar esto restaura el orden antiguo (específico de la plataforma): una solución aún más elegante podría ser usar el filtro "Sortke

ys" de
Data::
Dumper.
