NOMBRE

DateTime::Locale - Soporte de localización para DateTime.pm

VERSIÓN

versión 1.45

SINOPSIS

use DateTime::Locale;
my $loc = DateTime::Locale->load('en-GB');
print $loc->native_name, "\n", $loc->datetime_format_long, "\n";
# pero en su mayoría solo cosas como ...
my $dt = DateTime->now( locale => 'fr' );
print "Aujourd'hui le mois est " . $dt->month_name, "\n";

DESCRIPCIÓN

DateTime::Locale es principalmente una fábrica para las diversas subclases de localización. También proporciona algunas funciones para obtener información sobre todas las localizaciones disponibles.

Si desea conocer qué métodos están disponibles para los objetos de localización, lea la documentación de DateTime::Locale::FromData.

USO

Este módulo proporciona los siguientes métodos de clase:

DateTime::Locale->load( $locale_code | $locale_name )

Devuelve el objeto de localización para el código o nombre de localización especificado; consulte la documentación de DateTime::Locale::Catalog para obtener la lista de códigos y nombres disponibles. El nombre proporcionado puede ser el inglés o el nombre nativo.

Si la localización solicitada no se encuentra, se realiza una búsqueda de respaldo para encontrar un reemplazo adecuado.

El orden de búsqueda de respaldo es:

{language}-{script}-{territory}
{language}-{script}
{language}-{territory}-{variant}
{language}-{territory}
{language}

Por ejemplo, para el código de localización "es-XX-UNKNOWN" la búsqueda de respaldo sería:

es-XX-UNKNOWN   # Falla - no existe tal localización
es-XX           # Falla - no existe tal localización
es              # Se encuentra - la localización es se devuelve como la
                # coincidencia más cercana al id solicitado

Por ejemplo, para el código de localización "es-Latn-XX" la búsqueda de respaldo sería:

es-Latn-XX      # Falla - no existe tal localización
es-Latn         # Falla - no existe tal localización
es-XX           # Falla - no existe tal localización
es              # Se encuentra - la localización es se devuelve como la
                # coincidencia más cercana al id solicitado

Si no se encuentra un reemplazo adecuado, se lanza una excepción.

La localización cargada se almacena en caché, de modo que los objetos de localización pueden ser singletons. Llamar a "DateTime::Locale->register_from_data", "DateTime::Locale->add_aliases", o "DateTime::Locale->remove_alias" limpia la caché.

DateTime::Locale->codes

my @codes = DateTime::Locale->codes;
my $codes = DateTime::Locale->codes;

Devuelve una lista sin ordenar de los códigos de localización disponibles, o una referencia a un array si se llama en un contexto escalar. Esta lista no incluye alias.

DateTime::Locale->names

my @names = DateTime::Locale->names;
my $names = DateTime::Locale->names;

Devuelve una lista sin ordenar de los nombres de localización disponibles en inglés, o una referencia a un array si se llama en un contexto escalar.

DateTime::Locale->native_names

my @names = DateTime::Locale->native_names;
my $names = DateTime::Locale->native_names;

Devuelve una lista sin ordenar de los nombres de localización disponibles en su idioma nativo, o una referencia a un array si se llama en un contexto escalar. Todos los nombres nativos usan UTF-8 según corresponda.

DateTime::Locale->register_from_data( $locale_data )

Este método le permite registrar una localización personalizada. Los datos de la localización se especifican como un hash (o hashref) donde las claves coinciden con los nombres de los métodos dados en DateTime::Locale::FromData.

Si solo desea hacer algunos cambios pequeños sobre una localización existente, puede obtener los datos de esa localización llamando a "$locale->locale_data".

Aquí hay un ejemplo de cómo hacer una localización personalizada basada en "en-US":

my $locale = DateTime::Locale->load('en-US');
my %data   = $locale->locale_data;
$data{code}               = 'en-US-CUSTOM';
$data{time_format_medium} = 'HH:mm:ss';
DateTime::Locale->register_from_data(%data);
# Imprime 18:24:38
say DateTime->now( locale => 'en-US-CUSTOM' )->strftime('%X');
# Imprime 6:24:38 PM
say DateTime->now( locale => 'en-US' )->strftime('%X');

Las claves que deben estar presentes en el hash son las mismas que los métodos de acceso proporcionados por DateTime::Locale::FromData, excepto las siguientes:

Los métodos *_code
Aunque debe proporcionar una clave "code" , los otros métodos como "language_code" y "script_code" se determinan analizando el código.
Todos los métodos que devuelven "id"
Estos son alias para los métodos correspondientes *code .
"prefers_24_hour_time"
Esto se determina mirando el formato de tiempo corto para ver cómo formatea las horas,
"date_format_default" y "time_format_default"
Estos son los formatos medios correspondientes.
"datetime_format" y "datetime_format_default"
Esto es lo mismo que el formato medio.
"date_formats" y "time_formats"
Estos se calculan según sea necesario.
"available_formats"
Esto debe proporcionarse como un hashref donde las claves son cosas como "Gy" o "MMMEd" y los valores son un formato real como "y G" o "E, MMM d".
"locale_data"
Esto es todo lo que pasa.

CARGA DE LOCALIZACIONES EN UN SISTEMA PRE-FORKING

Si está ejecutando una aplicación que hace pre-forking (por ejemplo con Starman), entonces debería intentar cargar todas las localizaciones que necesitará en el proceso padre. Las localizaciones se cargan bajo demanda, por lo que cargarlas una vez en cada hijo desperdiciaría memoria que de otro modo podría ser compartida.

ERRORES EN LOS DATOS DE CLDR

Tenga en cuenta que todos los datos de localización han sido generados a partir de los datos de localización del proyecto CLDR (Common Locale Data Repository). Los datos están incompletos y pueden contener errores en algunas localizaciones.

Al informar errores en los datos, verifique primero las fuentes de datos primarias y, cuando sea necesario, informe los errores directamente a la fuente primaria a través del sistema de informes de errores de CLDR. Vea http://unicode.org/cldr/filing_bug_reports.html para más detalles.

Una vez que estos errores hayan sido confirmados, reenvíe el informe de errores y las correcciones a la lista de correo de DateTime, datetime@perl.org.
