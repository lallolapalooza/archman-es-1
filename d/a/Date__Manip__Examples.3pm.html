Date::Manip::Examples(3) Documentación de Perl aportada por el usuario Date::Manip::Examples(3)

NOMBRE

Date::Manip::Examples - ejemplos de cómo usar Date::Manip

DESCRIPCIÓN

Este documento incluye varios ejemplos de cómo realizar operaciones comunes con Date::Manip. Me alegrará añadir nuevos ejemplos con el tiempo, y agradezco las sugerencias y ejemplos para incluir.

En la mayoría de los casos, un ejemplo incluirá dos formas diferentes de obtener la respuesta. La primera forma utilizará los nuevos módulos OO (desde la versión 6.00). La segunda utilizará la interfaz funcional del estilo antiguo.

Debe tenerse en cuenta que cada vez que se desee trabajar con zonas horarias alternativas, se recomienda ENCARECIDAMENTE la interfaz OO, ya que la interfaz funcional no conserva la información de la zona horaria con la fecha y, por lo tanto, puede dar resultados incorrectos en algunos casos. Sin embargo, trabajar en la zona horaria del sistema debería dar resultados correctos.

Debe tenerse en cuenta que, en los ejemplos siguientes, parece que el método OO a menudo requiere más líneas de código que la interfaz funcional. Hay varias formas de acortar el método OO, pero para los ejemplos, quise incluir todos los pasos explícitamente.

ANÁLISIS DE UNA FECHA

Las fechas se pueden analizar en prácticamente cualquier forma de uso común:

Método OO
$date = new Date::Manip::Date;
$err = $date->parse("today");
$err = $date->parse("1st Thursday in June 1992");
$err = $date->parse("05/10/93");
$err = $date->parse("12:30 Dec 12th 1880");
$err = $date->parse("8:00pm December tenth");
Funcional
$date = ParseDate("today");
$date = ParseDate("1st Thursday in June 1992");
$date = ParseDate("05/10/93");
$date = ParseDate("12:30 Dec 12th 1880");
$date = ParseDate("8:00pm December tenth");

El manual Date::Manip::Date tiene una lista de todos los formatos válidos.

ANÁLISIS DE UNA CANTIDAD DE TIEMPO

Las cantidades de tiempo (denominadas deltas) también se pueden analizar:

Método OO
$delta = new Date::Manip::Delta;
$err = $delta->parse("in 12 hours");
$err = $delta->parse("-1:30:0");
$err = $delta->parse("4 business days later");
Funcional
$delta = ParseDateDelta("in 12 hours");
$delta = ParseDateDelta("-1:30:0");
$delta = ParseDateDelta("4 business days later");

PARA CALCULAR LA CANTIDAD DE TIEMPO ENTRE DOS FECHAS

$datestr1 = "Jan 30 1999 13:00 EST";
$datestr2 = "2/Mar/1999 15:30:00 +0500";
Método OO
$date1 = new Date::Manip::Date;
$date2 = $date1->new_date();
$err = $date1->parse($datestr1);
$err = $date2->parse($datestr2);

Para obtener una cantidad exacta de tiempo entre las dos fechas (expresada solo en términos de horas, minutos, segundos), utilice:

$delta = $date1->calc($date2);

Para obtener una cantidad aproximada de tiempo (expresada en términos de años, meses, semanas, etc. en términos en los que un humano normalmente pensaría), utilice:

$delta = $date1->calc($date2,"approx");
Funcional
$date1 = ParseDate($string1);
$date2 = ParseDate($string2);

Para obtener una cantidad exacta:

$delta = DateCalc($date1,$date2);

y la cantidad aproximada:

$delta = DateCalc($date1,$date2,1);

El manual Date::Manip::Calc tiene información sobre estos y otros tipos de cálculos.

PARA AÑADIR UNA CANTIDAD DE TIEMPO A UNA FECHA

Para encontrar una segunda fecha una cantidad de tiempo dada antes o después de una primera fecha, utilice lo siguiente:

$datestr  = "Jan 30 1999 13:00 EST";
$deltastr = "12 hours ago";
$deltastr = "in 3 business days";
Método OO
$date = new Date::Manip::Date;
$delta = $date->new_delta();
$date->parse($datestr);
$delta->parse($deltastr);
$d = $date->calc($delta);
Funcional
$date = DateCalc($datestr,$deltastr);

Si el delta es un delta de días laborables, realizará un cálculo en modo de días laborables.

El manual Date::Manip::Calc tiene información sobre estos y otros tipos de cálculos.

COMPARAR DOS FECHAS

Para tomar dos fechas diferentes y ver cuál es anterior, haga lo siguiente:

$datestr1 = "Jan 30 1999 13:00 EST";
$datestr2 = "2/Mar/1999 15:30:00 +0500";
Método OO
$date1 = new Date::Manip::Date;
$date2 = $date1->new_date;
$date1->parse($datestr1);
$date2->parse($datestr2);
$date1->cmp($date2);
   => -1, 0, 1
Funcional
$date1 = ParseDate($datestr1);
$date2 = ParseDate($datestr2);
Date_Cmp($date1,$date2);
   => -1, 0, 1

PARA EXTRAER INFORMACIÓN SOBRE UNA FECHA O UN DELTA

Si tiene una fecha o un delta, puede extraer información sobre ellos de la siguiente manera:

$datestr  = "1:24:08 PM EST Feb 3, 1996";
$deltastr = "12 hours ago";
Método OO
$date = new Date::Manip::Date;
$delta = $date->new_delta();
$date->parse($datestr);
$delta->parse($deltastr);
$str = $date->printf("It is now %T on %b %e, %Y.");
  =>  "It is now 13:24:08 on Feb  3, 1996."
$str = $delta->printf("In %hv hours, %mv minutes, %sv seconds");
  => "In -12 hours, 0 minutes, 0 seconds";
Funcional
$str = UnixDate($datestr,"It is now %T on %b %e, %Y.");
  =>  "It is now 13:24:08 on Feb  3, 1996."
$str = Delta_Format($deltastr,"In %hv hours, %mv minutes, %sv seconds");
  => "In -12 hours, 0 minutes, 0 seconds";

El manual Date::Manip::Date contiene todos los códigos de formato que se pueden usar para extraer información de una fecha. El manual Date::Manip::Delta contiene los códigos para un delta.

TRABAJAR CON LA ÉPOCA

Date::Manip se puede usar fácilmente para trabajar con el número de segundos desde la época (1 de enero de 1970 00:00:00 UTC).

Si tiene una fecha y desea saber cuántos segundos son después de la época, puede hacerlo de las siguientes maneras:

$datestr  = "1999-04-30-15:30:00 EDT";
$secs  = 1234567;
Método OO
Para averiguar cuántos segundos han transcurrido en una fecha determinada, puede hacer lo siguiente: 
$date     = new Date::Manip::Date;
$err      = $date->parse($datestr);
$str      = $date->printf('%s');
   => número de segundos

Para averiguar la fecha que es un número determinado de segundos desde la época, puede utilizar lo siguiente:

$date  = new Date::Manip::Date;
$err   = $date->parse("epoch $secs");

$date ahora contiene la fecha deseada (en la zona horaria local)

Funcional
Para averiguar cuántos segundos han transcurrido: 
$str = UnixDate($datestr,'%s');
  => número de segundos

Para encontrar la fecha que corresponde a un número de segundos desde la época:

$date = ParseDateString("epoch $secs");

Tenga en cuenta que Date::Manip funcionará tanto con segundos positivos (para fechas posteriores a la época) como con segundos negativos (para fechas anteriores a la época).

EVENTOS PERIÓDICOS

Para encontrar una lista de fechas en las que ocurre un evento periódico (incluso recurrencias muy complejas), haga lo siguiente:

Método OO
# Para encontrar el 2º martes de cada mes desde el 1 de enero de 1999 hasta el 30 de abril de 1999
$recur = new Date::Manip::Recur;
$start = $recur->new_date();
$end   = $recur->new_date();
$start->parse("Jan 1 1999");
$end->parse("Apr 30 1999");
$recur->parse("0:1*2:2:0:0:0",$start,$end);
@date = $recur->dates();
# Para encontrar el lunes después de la Pascua en 1997-1999
$recur = new Date::Manip::Recur;
$recur->parse("*1997-1999:0:0:0:0:0:0*EASTER,ND1");
@date = $recur->dates();
Funcional
# Para encontrar el 2º martes de cada mes desde el 1 de enero de 1999 hasta el 30 de abril de 1999
@date = ParseRecur("0:1*2:2:0:0:0","","Jan 1 1999","Apr 30 1999");
# Para encontrar el lunes después de la Pascua en 1997-1999.
@date = ParseRecur("*1997-1999:0:0:0:0:0:0*EASTER,ND1");

El manual de Date::Manip::Recur contiene información sobre eventos periódicos.

TRABAJAR CON FECHAS EN OTRO IDIOMA

Si desea trabajar con fechas en un idioma distinto al inglés (pero solo trabaja con un solo idioma), haga lo siguiente:

Método OO
$date = new Date::Manip::Date;
$date->config("Language","French","DateFormat","non-US");
$date->parse("1er decembre 1990");
Funcional
Date_Init("Language=French","DateFormat=non-US");
$date = ParseDate("1er decembre 1990");

El manual de Date::Manip::Config tiene una lista de todos los idiomas admitidos (en la sección sobre la variable de configuración Language). También se incluye el significado de la variable de configuración DateFormat.

TRABAJAR CON DOS IDIOMAS DIFERENTES

Si desea trabajar con fechas en dos (o más) idiomas, se recomienda ENCARECIDAMENTE que utilice la interfaz OO. La interfaz funcional será mucho más lenta, ya que tiene que reinicializar muchos elementos específicos del idioma cada vez que cambia de un idioma a otro.

Método OO
$date_eng = new Date::Manip::Date;
$date_eng->config("Language","English","DateFormat","US");
$date_fre = new Date::Manip::Date;
$date_fre->config("Language","French","DateFormat","non-US");

Utilice el $date_eng objeto para realizar operaciones en inglés, el $date_fre objeto para realizar operaciones en francés.

Funcional
Si está trabajando con fechas en francés e inglés, puede llamar a lo siguiente para cambiar entre ellas: 
Date_Init("Language=French","DateFormat=non-US");
Date_Init("Language=English","DateFormat=US");

Esto NO se recomienda. Utilice el método OO en su lugar.

ERRORES Y PREGUNTAS

Consulte la documentación de Date::Manip::Problems para obtener información sobre cómo enviar informes de errores o preguntas al autor.
