NOMBRE

Date::Manip::TZdata -- Módulo interno para trabajar con los archivos tzdata

SINOPSIS

use Date::Manip::TZdata;
$tzd  = new Date::Manip::TZdata($dir);

DESCRIPCION

Este módulo no está destinado al uso público. Lo utilizan internamente los scripts para analizar la base de datos de zonas horarias y generar los módulos para cada zona horaria. El módulo se incluye en la distribución únicamente por motivos de exhaustividad. Actualmente, no se ofrece soporte para este módulo, y puede cambiar (y de hecho, puede) sin previo aviso.

Este módulo consta de rutinas para trabajar con los archivos tzdata. Estos archivos se actualizan varias veces al año y son la base de las descripciones de las zonas horarias para la mayoría de los sistemas informáticos.

RUTINAS

new
use Date::Manip::TZdata;
$tzd  = new Date::Manip::TZdata($dir);

Esto encuentra y lee todos los tzdata. Si se pasa $dir, este es el directorio donde se encuentra un directorio tzdata. Por defecto, es el directorio actual.

LIMITACIONES CONOCIDAS

En la lógica de este módulo se asumen algunas suposiciones y limitaciones.

Cuando se produce un cambio de hora, la hora puede cambiar hacia atrás o hacia adelante. Las reglas de cambio de hora se enumeran por año. Se asume que los cambios de hora no ocurrirán tan cerca del final o inicio del año como para cruzar el límite del año (en otras palabras, el año no cambiará como resultado del cambio de hora). Esto no se tiene en cuenta, y se espera que esta situación nunca ocurra.

Además, dado que este módulo se limita estrictamente a años positivos de 4 dígitos (independientemente de si es hora local o universal), y dado que varias partes del módulo cambian de un lado a otro, las fechas válidas para este módulo son del 2 de enero de 0001 al 30 de diciembre de 9999. Esto garantiza que las conversiones de hora local a universal o viceversa nunca harán que las fechas ocurran en los años 0000 o 10000.
