Patrones de Strftime

%c (%a %-d %b %Y, %T) - formato de fecha y hora

 2008-02-05T18:30:30 = mar %-d feb 2008, 18:30:30
 1995-12-22T09:05:02 = ven %-d dic 1995, 09:05:02
-0010-09-15T04:44:23 = sab %-d set -10, 04:44:23

 2008-02-05T18:30:30 = 05.02.2008
 1995-12-22T09:05:02 = 22.12.1995
-0010-09-15T04:44:23 = 15.09.-10

 2008-02-05T18:30:30 = 18:30:30
 1995-12-22T09:05:02 = 09:05:02
