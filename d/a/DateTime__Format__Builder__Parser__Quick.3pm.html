DateTime::Format::Builder::Parser::Quick(3) Documentación de Perl contribuida por el usuario DateTime::Format::Builder::Parser::Quick(3)

NOMBRE

DateTime::Format::Builder::Parser::Quick - Usa otro formateador, simplemente

VERSIÓN

versión 0.83

SINOPSIS

use DateTime::Format::Builder (
    parsers => {
        parse_datetime => [
            { Quick => 'DateTime::Format::HTTP' },
            { Quick => 'DateTime::Format::Mail' },
            { Quick => 'DateTime::Format::IBeat' },
        ]
    }
);
# es lo mismo que
use DateTime::Format::HTTP;
use DateTime::Format::Mail;
use DateTime::Format::IBeat;
use DateTime::Format::Builder (
    parsers => {
        parse_datetime => [
            sub {
                eval { DateTime::Format::HTTP->parse_datetime( $_[1] ) }
            },
            sub {
                eval { DateTime::Format::Mail->parse_datetime( $_[1] ) }
            },
            sub {
                eval { DateTime::Format::IBeat->parse_datetime( $_[1] ) }
            },
        ]
    }
);

(Estos dos fragmentos de código se pueden encontrar en el conjunto de pruebas; uno como quick.t, el otro como fall.t.)

DESCRIPCIÓN

"Quick" agrega un analizador que permite atajos al escribir llamadas bastante estándar y mundanas a otros módulos de formateo.

ESPECIFICACIÓN

"Quick" tiene dos claves, una opcional.

La palabra clave "Quick" debe tener un argumento que sea un objeto o un nombre de clase. Si es un nombre de clase, entonces la clase se usa con "use".

La palabra clave "method" es opcional y tiene un valor predeterminado de "parse_datetime". Es el nombre del método a invocar en el objeto, o una referencia a un fragmento de código.

En cualquier caso, el código resultante se parece a:

my $rv = $Quick->$method($date);
