NOMBRE

DateTime::Infinite - Objetos DateTime de pasado y futuro infinitos

VERSIÓN

version 1.66

SINOPSIS

my $future = DateTime::Infinite::Future->new;
my $past   = DateTime::Infinite::Past->new;

DESCRIPCIÓN

Este módulo proporciona dos subclases de DateTime, "DateTime::Infinite::Future" y "DateTime::Infinite::Past".

Los objetos están siempre en la zona horaria "flotante", y esto no se puede cambiar.

MÉTODOS

El único constructor para estas dos clases es el método "new", como se muestra en la "SINOPSIS". Este método no toma parámetros.

Todos los métodos "get" en este módulo simplemente devuelven infinito, positivo o negativo. Si se espera que el método devuelva una cadena, devuelve la representación de cadena de infinito positivo o negativo utilizada por su sistema. Por ejemplo, en mi sistema, llamar a "$dt->year" devuelve un número que, al imprimirse, aparece como "Inf" o "-Inf".

Esto también se aplica a los métodos que son de característica compuesta, que devuelven las mismas cadenas incluso para cosas como "$dt->ymd" o "$dt->iso8601".

El objeto no es mutable, por lo que los métodos "$dt->set", "$dt->set_time_zone" y "$dt->truncate" son todos métodos que no hacen nada y simplemente devuelven el objeto con el que se les llama.

Obviamente, el método "$dt->is_finite" devuelve falso y el método "$dt->is_infinite" devuelve verdadero.

VER TAMBIÉN

lista de correo datetime@perl.org

ERRORES

Parece haber muchos problemas al tratar con números infinitos en Win32. Puede ser un problema de este código, de Perl o de la implementación matemática IEEE de Win32. De cualquier manera, el módulo puede no comportarse bien en sistemas operativos Win32.

Los errores pueden enviarse en https://github.com/houseabsolute/DateTime.pm/issues.

Hay una lista de correo disponible para los usuarios de esta distribución, <mailto:datetime@perl.org>.

CÓDIGO FUENTE

El repositorio de código fuente de DateTime se puede encontrar en https://github.com/houseabsolute/DateTime.pm.
