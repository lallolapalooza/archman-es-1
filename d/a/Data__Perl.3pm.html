NOMBRE

Data::Perl - Clases base que encapsulan tipos de datos fundamentales de Perl.

VERSIÓN

versión 0.002011

SINOPSIS

use Data::Perl;
my $array = array(1,2,3, qw/a b c/);
$array->count; # 6
my @elements = $array->grep(sub {/b/}); # (b)
my $hash = hash(a => 1, b => 2);
$hash->keys; # ('a', 'b');
my $number = number(5);
$number->add(10); # 15
my $string = string("foo\n");
$string->chomp; # devuelve 1, elimina el salto de línea final
my $counter = counter();
$counter->inc; # el contador ahora es 1
my $sub = code(sub { 'foo' });
$sub->execute; # devuelve 'foo'
$foo

DESCRIPCIÓN

Data::Perl es una colección de clases que encapsulan tipos de datos fundamentales que existen en Perl. Estas clases y métodos, tal como existen hoy, son un intento de reflejar la funcionalidad proporcionada por los Traits Nativos de Moose. Una cosa importante a tener en cuenta es que todas las clases actualmente no realizan validación en la entrada del constructor.

Data::Perl es una clase contenedora para las siguientes clases:

  • Data::Perl::Collection::Hash
  • Data::Perl::Collection::Array
  • Data::Perl::String
  • Data::Perl::Number
  • Data::Perl::Counter
  • Data::Perl::Bool
  • Data::Perl::Code

API ALFA

La API proporcionada por estos módulos se considera actualmente alfa y no está definida. La API CAMBIARÁ. Si está escribiendo código que no volverá a tocar durante años, no lo use hasta que se elimine esta advertencia.

FUNCIONES PROPORCIONADAS

Data::Perl exporta funciones constructoras auxiliares para interactuar con las clases anteriores:

  • hash(clave, valor, ...)

    Devuelve un objeto Data::Perl::Collection::Hash inicializado con los argumentos opcionales de clave/valor proporcionados.

  • array(@args)

    Devuelve un objeto Data::Perl::Collection::Array inicializado con los valores opcionales proporcionados.

  • string($arg)

    Devuelve un objeto Data::Perl::String inicializado con el argumento escalar opcional proporcionado.

  • number($arg)

    Devuelve un objeto Data::Perl::Number inicializado con el argumento escalar opcional proporcionado.

  • counter($arg)

    Devuelve un objeto Data::Perl::Counter inicializado con el argumento escalar opcional proporcionado.

  • bool($arg)

    Devuelve un objeto Data::Perl::Bool inicializado con el valor booleano del argumento escalar proporcionado.

  • code($arg)

    Devuelve un objeto Data::Perl::Code inicializado con el coderef escalar opcional proporcionado como argumento.
