Data::Perl::Role::Collection::Hash(3) Documentación de Perl contribuida por el usuario Data::Perl::Role::Collection::Hash(3)

NOMBRE

Data::Perl::Role::Collection::Hash - Clase envolvente para la estructura de hash integrada de Perl.

VERSIÓN

versión 0.002011

SINOPSIS

use Data::Perl qw/hash/;
my $hash = hash(a => 1, b => 2);
$hash->values; # (1, 2)
$hash->set('foo', 'bar'); # (a => 1, b => 2, foo => 'bar')

DESCRIPCIÓN

Esta clase proporciona una envoltura y métodos para interactuar con un hash. Todos los métodos que devuelven una lista lo hacen a través de un objeto Data::Perl::Collection::Array.

MÉTODOS PROPORCIONADOS

new($key, $valor, ...)
Dada una lista opcional de claves/valores, construye un nuevo objeto Data::Perl::Collection::Hash inicializado con las claves/valores y lo devuelve.
get($key, $key2, $key3...)
Devuelve una lista de valores en el hash para las claves dadas.

Este método requiere al menos un argumento.

set($key => $valor, $key2 => $valor2...)
Establece los elementos en el hash a los valores dados. Devuelve los nuevos valores establecidos para cada clave, en el mismo orden que las claves pasadas al método.

Este método requiere al menos dos argumentos y espera un número par de argumentos.

delete($key, $key2, $key3...)
Elimina los elementos con las claves dadas.

Devuelve una lista de valores en el hash para las claves eliminadas.

keys
Devuelve la lista de claves en el hash.

Este método no acepta ningún argumento.

exists($key)
Devuelve verdadero si la clave dada está presente en el hash.

Este método requiere un solo argumento.

defined($key)
Devuelve verdadero si el valor de una clave dada está definido.

Este método requiere un solo argumento.

values
Devuelve la lista de valores en el hash.

Este método no acepta ningún argumento.

kv
Devuelve los pares clave/valor en el hash como una matriz de referencias a matrices. 
for my $pair ( $object->option_pairs ) {
    print "$pair->[0] = $pair->[1]\n";
}

Este método no acepta ningún argumento.

elements/all
Devuelve los pares clave/valor en el hash como una lista aplanada.

Este método no acepta ningún argumento.

clear
Restablece el hash a un valor vacío, como "%hash = ()".

Este método no acepta ningún argumento.

count
Devuelve el número de elementos en el hash. También útil para no vacío: "has_options => 'count'".

Este método no acepta ningún argumento.

is_empty
Si el hash está poblado, devuelve falso. De lo contrario, devuelve verdadero.

Este método no acepta ningún argumento.

accessor($key)
accessor($key, $valor)
Si se pasa un argumento, devuelve el valor de la clave especificada. Si se pasan dos argumentos, establece el valor de la clave especificada.

Cuando se llama como un setter, este método devuelve el valor que se estableció.

shallow_clone
Este método devuelve un clon superficial de la referencia del hash. El valor de retorno es una referencia a un nuevo hash con las mismas claves y valores. Es superficial porque cualquier valor que fueran referencias en el original serán las mismas referencias en el clon.
_array_class
El nombre de la clase de la que son instancias las listas devueltas; es decir, "Data::Perl::Collection::Array".

Las subclases de esta clase pueden anular este método.

Tenga en cuenta que "each" se omite deliberadamente, debido a su interacción con estado con el iterador del hash. "keys" o "kv" son mucho más seguros.
