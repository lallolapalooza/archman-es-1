NOMBRE

darktable-generate-cache - actualiza la caché de miniaturas de darktable

SINOPSIS

darktable-generate-cache [-h, --help; --version] [-m, --max-mip <0-7>] [--core <opciones de darktable>]

DESCRIPCIÓN

darktable es una aplicación de flujo de trabajo de fotografía digital para Linux, Mac OS X y varios otros Unices. Se describe con más detalle en darktable(1).

darktable-generate-cache actualiza la caché de miniaturas de darktable. Puedes iniciar este programa para generar todas las miniaturas faltantes en segundo plano cuando tu ordenador esté inactivo.

OPCIONES

Todos los parámetros son opcionales. Si se inicia sin parámetros, darktable-generate-cache utiliza valores predeterminados razonables.

-h, --help
Muestra información de uso y termina.
--version
Muestra información de copyright y versión y termina.
--min-mip <0-7>
-m, --max-mip <0-7>
darktable puede manejar y almacenar miniaturas con hasta ocho pasos de resolución diferentes para cada imagen. Estos parámetros definen qué resolución máxima se debe generar y, por defecto, un rango de 0-2. Normalmente no hay necesidad de generar todas las resoluciones posibles aquí; las faltantes serán generadas automáticamente por darktable en el momento en que se necesiten. Cuando se solicita generar múltiples resoluciones a la vez, las imágenes de menor resolución se reducen rápidamente a partir de la imagen de mayor resolución.
--min-imgid <N>
--max-imgid <N>
Especifica el rango de IDs de imagen internos de la base de datos para trabajar. Si no se proporciona un rango, darktable-generate-cache procesará todas las imágenes de la colección completa.
--core <opciones de darktable>
Todos los parámetros de línea de comandos que siguen a --core se pasan al núcleo de darktable y se manejan como parámetros estándar. Consulta darktable(1) para una descripción detallada de las opciones.
