DESCRIPCIÓ

N

Este módulo contiene un conjunto de métodos utilizados por todas las clases de Date::Manip listadas

anteriormente.

Debería estar familiarizado con la documentación de Date::Manip::Objects y Date::Manip::

Config.

En las descripciones de los métodos siguientes, los objetos Date::Manip::Date se usa

rán normalmente como ejemplos, pero (salvo que se indique lo contrario), todas las c
lases listadas anteriormente tienen los mismos métodos y funcionan de la misma manera.

MÉTODOS PARA CREAR

OBJETOS

En los ejemplos siguientes, cualquier variable con un nombre que sea alguna variación de $date ($date, $date1, $date2, ...) es un objeto Date::Manip::Date. De manera similar, $delta, $recur, $tz, y $base se refieren a objetos en la clase

apropiada.

Cualquier variable $obj se refiere a un objeto en cualquiera de las

clases.

w
Hay dos formas de usar el método new. Son: 
$obj2  = new CLASS ($obj1,$string,@parse_opts,\@opts);
$obj2  = $obj1->new($string,@parse_opts,
\@opts)

En ambos casos, todos los argumentos son

opcionales.

Ambos métodos se utilizan para crear un nuevo objeto de una clase determinada. En el primer caso, CLASS es la clase del nuevo objeto. Por

ejemplo: 
$date  = new Date::Manip::Date;
$delta = new Date::Manip::
Delta;

En el segundo método, la clase del nuevo objeto se derivará del primer objeto. Por

ejemplo: 
$date1 = new Date::Manip::Date;
$date2 = $date1->
new();

la clase del segundo objeto ($date2) es Date::Manip::Date porque esa es la clase del objeto ($date1) utilizado para

crearlo.

En el primer método (cuando se pasa un $obj1) y siempre en el segundo método, el nuevo objeto compartirá tanta información del objeto antiguo ($obj1) como sea

posible.

Por ejemplo, si llama a cualquiera

de estas: 
$date2 = new Date::Manip::Date $date1;
$date2 = $date1->
new();

el nuevo objeto de fecha utilizará los mismos objetos Date::Manip::TZ y Date::Manip::Base

incrustados.

Al especificar CLASS e incluir un objeto antiguo, los objetos no necesitan ser de la misma clase. Por ejemplo, lo siguiente es todo

válido: 
$date = new Date::Manip::Date $delta;
$date = new Date::Manip::Date
$tz;

Incluso puede

hacer: 
$date = new Date::Manip::Date
$base;

pero esto tendrá que crear un objeto Date::Manip::TZ completamente nuevo, lo que significa que es posible que no se logre un rendimiento óptimo si ya existe un objeto Date::Manip:

:TZ.

Hay dos casos especiales. Cualquiera de lo siguiente creará un nuevo objeto Date::Manip::Base para manejar múltiples

configuraciones: 
$base2 = new Date::Manip::Base $base1;
$base2 = $base1->
new();

Cualquiera de lo siguiente creará un nuevo objeto Date::Manip::TZ con el mismo objeto Date::Manip::Base incrustado

en él: 
$tz2   = new Date::Manip::TZ $tz1;
$tz2   = $tz1->
new();

El nuevo objeto base inicialmente tendrá la misma configuración que el objeto base original, pero cambiar su configuración no afectará al objeto base

original.

Si se pasa el argumento "\@opts", es una referencia a una lista que contiene una lista adecuada para pasarla al método config (descrito más adelante). En este caso, se creará un nuevo objeto Date::Manip::Base (y quizás un objeto Date::Manip::TZ). El nuevo objeto Base comenzará siendo idéntico al original (si se utilizó un objeto previamente definido para crear el nuevo objeto) con las opciones adicionales en @opts añad

idas.

En otras palabras, lo siguiente es

equivalente: 
$date  = new Date::Manip::Date $obj,\@opts;
$base  = $obj->base();
$base2 = $base->new();
$date = new Date::Manip::Date $base2;
$date->config(@opts)
;

Debe señalarse que las opciones se aplican al NUEVO objeto Date::Manip::Base, no al

antiguo.

Se puede pasar una cadena opcional ($string y opciones de análisis @parse_opts) solo al crear un objeto Date::Manip::Date, Date::Manip::Delta o Date::Manip::Recur. Si se pasa al crear un objeto Date::Manip::TZ o Date::Manip::Base, se emitirá una advertencia, pero la ejecución

continuará.

Si se incluye la cadena, se analizará para dar un valor inicial al objeto. Esto solo se hará DESPUÉS de que se manejen las opciones, por lo que lo siguiente es

equivalente: 
$date = new Date::Manip::Date $string,@parse_opts,\@opts;
$date = new Date::Manip::Date;
$date->config(@opts);
$date->parse($string,@parse_opts)
;

Una vez que se crea un objeto Date::Manip::Date (o cualquier objeto en cualquier otra clase de Date::Manip), siempre debe usarse para crear objetos adicionales para preservar los datos en caché para un rendimiento óptimo y un uso óptimo de la

memoria.

La única advertencia es si está trabajando con múltiples configuraciones como se describe en el documento Date::Manip::Objects. En ese caso, puede necesitar crear objetos completamente nuevos para permitir que se utilicen múltiples objetos Date::Manip:
