NOMBRE

DateTime::TimeZone::Local::Unix - Determinar la zona horaria del sistema local en Unix

VERSIÓN

versión 2.65

SINOPSIS

my $tz = DateTime::TimeZone->new( name => 'local' );
my $tz = DateTime::TimeZone::Local->TimeZone();

DESCRIPCIÓN

Este módulo proporciona métodos para determinar la zona horaria local en una plataforma Unix.

CÓMO SE DETERMINA LA ZONA HORARIA

Esta clase intenta los siguientes métodos para determinar la zona horaria local, en el orden en que se enumeran aquí:

  • $ENV{TZ}

    Comprueba $ENV{TZ} para obtener un nombre de zona horaria válido.

  • /etc/timezone

    Si este archivo existe, se lee y su contenido se utiliza como nombre de zona horaria.

    Tenga en cuenta que este archivo puede estar desactualizado en muchos sistemas, ya que las distribuciones modernas pueden no hacer un buen trabajo actualizando este archivo. Si descubre que este archivo no se actualiza, es posible que desee considerar eliminarlo para que se pueda utilizar uno de los siguientes métodos.

  • /etc/localtime

    Si este archivo es un enlace simbólico a un archivo de zona horaria de la base de datos Olson (generalmente en /usr/share/zoneinfo), entonces utiliza el nombre de la ruta del archivo de destino para determinar el nombre de la zona horaria. Por ejemplo, si la ruta es /usr/share/zoneinfo/America/Chicago, la zona horaria es "America/Chicago".

    Algunos sistemas simplemente copian el archivo relevante a /etc/localtime en lugar de crear un enlace simbólico. En este caso, buscamos en /usr/share/zoneinfo un archivo que tenga el mismo tamaño y contenido que /etc/localtime para determinar la zona horaria local.

  • /etc/TIMEZONE

    Si este archivo existe, se abre y buscamos una línea que comience con "TZ = ...". Si se encuentra, debería indicar un nombre de zona horaria.

  • /etc/sysconfig/clock

    Si este archivo existe, se abre y buscamos una línea que comience con "TIMEZONE = ..." o "ZONE = ...". Si se encuentra, debería indicar un nombre de zona horaria.

  • /etc/default/init

    Si este archivo existe, se abre y buscamos una línea que comience con "TZ=...". Si se encuentra, debería indicar un nombre de zona horaria.

Nota: Algunos sistemas como las máquinas virtuales pueden carecer de alguno de estos archivos. Puede confirmar que este es el caso ejecutando:

$ ls -l /etc/localtime /etc/timezone /etc/TIMEZONE \
    /etc/sysconfig/clock /etc/default/init

En ese caso, cuando intente manejar la zona horaria, es probable que reciba una excepción:

$ perl -wle 'use DateTime; DateTime->now( time_zone => "local" )'
Cannot determine local time zone

En ese caso, debería consultar las páginas del manual de su sistema para obtener detalles sobre cómo abordar ese problema. En un caso reportado, una máquina virtual FreeBSD se había creado sin ninguno de estos archivos. El usuario pudo ejecutar la utilidad tzsetup de FreeBSD. Eso instaló /etc/localtime, después de lo cual el diagnóstico de zona horaria anterior se ejecutó silenciosamente, es decir, sin lanzar una excepción.
