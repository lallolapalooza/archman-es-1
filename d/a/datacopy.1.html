DATACOPY(FreeTDS) FreeTDS (manual de referencia de freetds) DATACOPY(FreeTDS)

NOMBRE

datacopy — mover datos de tablas entre dos servidores

SINOPSIS

datacopy [-vdE] {-t | -a | -c owner} [-b tamaño_lote] [-p tamaño_paquete] [-S servidor/usuario/contraseña/base_de_datos/tabla_o_vista] [-D servidor/usuario/contraseña/base_de_datos/tabla] [-T tamaño_texto]

DESCRIPCIÓN

datacopy es una utilidad distribuida con FreeTDS. datacopy moverá datos de tablas de un servidor a otro sin necesidad de archivos intermedios. datacopy es mucho más rápido y eficiente que freebcp out/in.

datacopy utiliza la API bcp de db-lib integrada en FreeTDS. Esta API también está disponible para los desarrolladores de aplicaciones.

datacopy se puede utilizar para migrar datos entre Sybase ASE y SQL Server o viceversa.

OPCIONES

-t
Trunca la tabla de destino antes de cargar los datos.
-a
Añade datos a la tabla de destino.
-c owner
Crea la tabla de destino con el mismo esquema que la tabla de origen. datacopy enviará un comando ‘CREATE TABLE’ en el servidor de destino utilizando el propietario especificado en el comando, por ejemplo ‘CREATE TABLE owner.table (...).’
-b tamaño_lote
El número de filas por lote de datos copiados. Cada lote de datos se 'confirma' efectivamente en la base de datos. El valor predeterminado es 1000.
-p tamaño_paquete
El número de bytes, por paquete de red, enviados a y desde los servidores. Un tamaño de paquete aumentado puede mejorar el rendimiento.
-T tamaño_texto
Especifica el tamaño de la columna TEXT/IMAGE desde la red.
-v
Produce una salida detallada, incluyendo tiempos de diagnóstico.
-d
Produce salida TDSDUMP de freetds. (¡Solo para depuración seria!)
-S servidor/usuario/contraseña/base_de_datos/tabla_o_vista
La información de conexión para el servidor de origen y la ubicación/nombre de la tabla (o vista) a copiar. Si no se especifica, datacopy solicitará la información al usuario.
-D servidor/usuario/contraseña/base_de_datos/tabla
La información de conexión para el servidor de destino y la ubicación/nombre de la tabla de destino. Si no se especifica, datacopy solicitará la información al usuario.
-E
Mantiene los valores de identidad.

VER TAMBIÉN

freebcp(1), defncopy(1), bsqldb(1), tsql(1), Guía del usuario de FreeTDS.

HISTORIA

datacopy apareció por primera vez en FreeTDS 0.64.
