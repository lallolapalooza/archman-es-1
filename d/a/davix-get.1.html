DAVIX-GET(1) herramienta de descarga DAVIX-GET(1)

NOMBRE

davix-get - Herramienta de descarga basada en libdavix

SINOPSIS

davix-get [opciones]... url davix-get [opciones]... url archivo_local

DESCRIPCIÓN

davix-get es una herramienta para descargar recursos de servicios compatibles con HTTP, Webdav o REST.
El comando soporta los protocolos Http (http(s)://), WebDAV (dav(s)://) y S3 (s3(s)://).

Los recursos de destino pueden ser un archivo individual o una colección.
En el caso de una colección, todas las subcolecciones también se descargarán.

davix-get está impulsado por libdavix. Consulte libdavix(3) para más detalles.

OPCIONES

Opciones comunes:

--debug
Modo de depuración
--header, -H
Añadir un campo de cabecera a la solicitud (ej: -H "Depth: 1" )
--help, -h
Mostrar este mensaje de ayuda
--metalink OPT
Soporte de Metalink. (OPT=failover[predeterminado]|no)
--module, -P NOMBRE_PLUGIN
Cargar un plugin o perfil por nombre
--redirection OPT
Soporte de redirección transparente. (OPT=yes[predeterminado]|no)
--proxy, -x URL
URL del servidor proxy SOCKS5. (ej: socks5://login:pass@socks.example.org)
--trace
Rastrea ámbitos específicos, las opciones incluyen:
file - Interfaz de archivo de Davix
posix - Interfaz POSIX de Davix
xml - Salida del analizador XML
ssl - Detalles de SSL y certificados
header - Cabeceras de las consultas HTTP
body - Cuerpos HTTP
chain - Información de las cadenas de E/S
core - Información de configuración y herramientas de línea de comandos de Davix
grid - Información diversa de terceros
socket - Información de sockets
locks - Información de bloqueo WebDAV
all - Rastrea todo
--version
Mostrar versión

Opciones de seguridad:

--capath RUTA_CA
Añadir una autoridad de certificación adicional
--cert, -E RUTA_CRED
Certificado de cliente en formato PEM
--key ruta_privada
Clave privada en formato PEM
--insecure, -k
Desactivar comprobaciones de credenciales SSL
--userlogin
Nombre de usuario para autenticación de usuario/contraseña
--userpass
Contraseña de usuario para autenticación de usuario/contraseña
--s3secretkey
Autenticación AWS S3: clave secreta
--s3accesskey
Autenticación AWS S3: clave de acceso
--s3region
Autenticación AWS S3: región
--s3token
Token de seguridad AWS S3 - utilizado junto con credenciales temporales de STS
--s3alternate
Especifique esta bandera si necesita utilizar una URL S3 basada en ruta
--azurekey
Clave de autenticación de Azure

EJEMPLOS

Descargar contenido e imprimirlo en stdout
davix-get http://example.org/dir1/dir2/file1

Descargar contenido a un archivo local
davix-get s3://bucket.example.org/collection/file2 /tmp/file2

Descargar contenido a un archivo local con autenticación VOMS en un entorno Grid
davix-get -P grid davs://grid-storage.example.org/dir1/file1 /tmp/file1

Descargar contenido e imprimirlo en stdout, utilizando un token OAuth
davix-get https://example.org/dir1/tmpfile -H "Authorization: Bearer mytoken"

Descargar colección a un directorio local
davix-get dav://example.org/dir ./mydir
