NOMBRE

DateTime::Event::ICal - Extensión de DateTime para Perl para calcular recurrencias rfc2445.

SINOPSIS

use DateTime;
use DateTime::Event::ICal;
my $dt = DateTime->new( year   => 2000,
                        month  => 6,
                        day    => 20,
                      );
my $set = DateTime::Event::ICal->recur( 
     dtstart => $dt,
     freq =>    'daily',
     bymonth => [ 10, 12 ],
     byhour =>  [ 10 ]
);
my $dt_next = $set->next( $dt );
my $dt_previous = $set->previous( $dt );
my $bool = $set->contains( $dt );
my @days = $set->as_list( start => $dt1, end => $dt2 );
my $iter = $set->iterator;
while ( my $dt = $iter->next ) {
    print ' ', $dt->datetime;
}

DESCRIPCIÓN

Este módulo proporciona métodos de conveniencia que le permiten crear fácilmente objetos "DateTime::Set" para recurrencias al estilo rfc2445.

USO

recur
Este método devuelve un objeto DateTime::Set que representa la recurrencia dada. 
my $set = DateTime::Event::ICal->recur( %args );

Este método toma parámetros que corresponden a las partes de la regla especificadas en la sección 4.3.10 de RFC 2445. En lugar de reescribir ese RFC aquí, se le anima a leerlo primero si desea entender qué representan todos estos parámetros.

  • dtstart

    Un objeto DateTime, que es la fecha de inicio.

    Esta fecha y hora no se incluye en la recurrencia, a menos que satisfaga las reglas de la recurrencia.

    Un conjunto puede usarse así para crear reglas de exclusión (rfc2445 "exrule"), que no incluyen "dtstart".

  • until

    Un objeto DateTime que especifica la fecha de fin de la recurrencia. También puede especificarse como "dtend".

  • count

    Un número positivo que indica el número total de recurrencias. Dar tanto un parámetro "count" como uno "until" es inútil, aunque actualmente está permitido.

  • freq

    Uno de:

    "yearly", "monthly", "weekly", "daily",
"hourly", "minutely", "secondly"

    Vea la documentación de "DateTime::Event::Recurrence" para más detalles sobre lo que significan.

  • interval

    El intervalo entre recurrencias. Este es un multiplicador para el valor especificado por "freq". Por defecto es 1.

    Así que si especifica un "freq" de "yearly" y un "interval" de 3, eso significa una recurrencia que ocurre cada tres años.

  • wkst

    Día de inicio de la semana. Puede ser uno de: "mo", "tu", "we", "th", "fr", "sa", "su". El valor por defecto es lunes ("mo").

    Nota: este parámetro aún no está implementado

  • bysecond => [ lista ], byminute => [ lista ], byhour => [ lista ]

    Debe ser uno o más números positivos o negativos, especificados como un escalar o una referencia a un array. Cada número representa un segundo/minuto/hora.

    Vea RFC 2445, sección 4.3.10 para más detalles.

  • byday => [ lista ]

    Debe ser un escalar o una referencia a un array que contenga días de la semana, especificados como "mo", "tu", "we", "th", "fr", "sa", "su"

    El día de la semana puede tener un prefijo:

    "1tu",  # el primer martes del mes o año
"-2we"  # el segundo miércoles desde el final del mes o año

    Vea RFC 2445, sección 4.3.10 para más detalles.

  • bymonthday => [ lista ], byyearday => [ lista ]

    Un escalar o una referencia a un array que contenga números positivos o negativos, pero no cero. Para "bymonthday", los rangos permitidos son de -31 a -1. Para "byyearday", los rangos permitidos son de -366 a -1, y de 1 a 366.

    El día -1 es el último día del mes o del año.

    Vea RFC 2445, sección 4.3.10 para más detalles.

  • byweekno => [ lista ]

    Un escalar o una referencia a un array que contenga números positivos o negativos, pero no cero. Los rangos permitidos son de -53 a -1, y de 1 a 53.

    La primera semana del año es la semana 1.

    El día de inicio de la semana por defecto es lunes.

    La semana -1 es la última semana del año.

    Vea RFC 2445, sección 4.3.10 para más detalles.

  • bymonth => [ lista ]

    Un escalar o una referencia a un array que contenga números positivos o negativos, de -12 a -1 y de 1 a 12.

    El mes -1 es diciembre.

    Vea RFC 2445, sección 4.3.10 para más detalles.

  • bysetpos => [ lista ]

    Puede ser un escalar o una referencia a un array de números positivos y negativos de -366 a -1, y de 1 a 366. Este parámetro se usa en conjunto con uno de los otros parámetros "by...".

    Vea RFC 2445, sección 4.3.10 para más detalles.
