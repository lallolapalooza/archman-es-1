Documentación de Función/Subrutina

subrutina dsyrk (character uplo, character trans, integer n, integer k, double precision alpha, double precision, dimension(lda,*) a, integer lda, double precision beta, double precision, dimension(ldc,*) c, integer ldc)

DSYRK

Propósito:

!>
!> DSYRK  realiza una de las operaciones de rango k simétricas
!>
!>    C := alpha*A*A**T + beta*C,
!>
!> o
!>
!>    C := alpha*A**T*A + beta*C,
!>
!> donde  alpha y beta  son escalares, C es una matriz simétrica de n por n
!> y  A  es una matriz de n por k  en el primer caso y una matriz de k por n
!!> en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar,   UPLO  especifica  si  la parte  triangular  superior  o  inferior
!>           de la  matriz  C  debe ser  referenciada, como sigue:
!>
!>              UPLO = 'U' o 'u'   Solo la parte triangular superior de C
!>                                  será referenciada.
!>
!>              UPLO = 'L' o 'l'   Solo la parte triangular inferior de C
!>                                  será referenciada.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar,  TRANS  especifica la operación a realizar como
!>           sigue:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**T + beta*C.
!>
!>              TRANS = 'T' o 't'   C := alpha*A**T*A + beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**T*A + beta*C.
!>

N

!>          N es INTEGER
!>           Al entrar,  N especifica el orden de la matriz C.  N debe ser
!>           al menos cero.
!>

K

!>          K es INTEGER
!>           Al entrar con  TRANS = 'N' o 'n',  K  especifica  el número
!>           de  columnas   de  la   matriz   A,   y  al   entrar   con
!>           TRANS = 'T' o 't' o 'C' o 'c',  K  especifica  el  número
!>           de filas de la matriz  A.  K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION.
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es una matriz DOUBLE PRECISION, de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de entrar con  TRANS = 'N' o 'n',  la parte  principal  de  n  por  k
!>           de la matriz  A  debe contener la matriz  A,  en caso contrario
!>           la parte principal de  k  por  n  de la matriz  A  debe contener la
!>           matriz A.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A según está declarada
!>           en el programa (sub)llamador.  Cuando TRANS = 'N' o 'n'
!>           entonces  LDA debe ser al menos  max( 1, n ), en caso contrario LDA debe
!>           ser al menos  max( 1, k ).
!>

BETA

!>          BETA es DOUBLE PRECISION.
!>           Al entrar, BETA especifica el escalar beta.
!>

C

!>          C es una matriz DOUBLE PRECISION, de dimensión ( LDC, N )
!>           Antes de entrar con  UPLO = 'U' o 'u',  la parte  principal  de  n  por  n
!>           de la matriz C debe contener la parte triangular superior  de la
!>           matriz simétrica y la parte estrictamente triangular inferior de C
!>           no se referencia.  A la salida, la parte triangular superior de la
!>           matriz C se sobrescribe con la parte triangular superior de la matriz
!>           actualizada.
!>           Antes de entrar con  UPLO = 'L' o 'l',  la parte  principal  de  n  por  n
!>           de la matriz C debe contener la parte triangular inferior de la
!>           matriz simétrica y la parte estrictamente triangular superior de C
!>           no se referencia.  A la salida, la parte triangular inferior de la
!>           matriz C se sobrescribe con la parte triangular inferior de la matriz
!>           actualizada.
!>

LDC

!>          LDC es INTEGER
!>           Al entrar, LDC especifica la primera dimensión de C según está declarada
!>           en el programa (sub)llamador.  LDC  debe ser al menos
!>           max( 1, n ).
!>
