Documentación de Función/Subrutina

subrutina dstegr (character jobz, character range, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

DSTEGR

Propósito:

!>
!> DSTEGR calcula los autovalores seleccionados y, opcionalmente, los autovectores
!> de una matriz tridiagonal simétrica real T. Cualquier matriz no reducida de este tipo tiene
!> un conjunto bien definido de autovalores reales pairwise diferentes, los autovectores reales correspondientes
!> son pairwise ortogonales.
!>
!> El espectro puede calcularse ya sea completa o parcialmente especificando
!> ya sea un intervalo (VL,VU] o un rango de índices IL:IU para los autovalores deseados.
!>
!> DSTEGR es un envoltorio de compatibilidad alrededor de la rutina mejorada DSTEMR.
!> Consulte DSTEMR para más detalles.
!>
!> Un cambio importante es que el parámetro ABSTOL ya no proporciona ningún
!> beneficio y por lo tanto ya no se utiliza.
!>
!> Nota : DSTEGR y DSTEMR solo funcionan en máquinas que siguen
!> el estándar de punto flotante IEEE-754 en su manejo de infinitos y
!> NaNs. La ejecución normal puede crear estos valores excepcionales y por lo tanto
!> puede abortarse debido a una excepción de punto flotante en entornos que
!> no se ajustan al estándar IEEE-754.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo autovalores;
!>          = 'V':  Calcula autovalores y autovectores.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta el IU-ésimo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los N elementos diagonales de la matriz tridiagonal
!>          T. En la salida, D es sobrescrito.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los (N-1) elementos subdiagonales de la matriz tridiagonal
!>          T en los elementos 1 a N-1 de E. E(N) no necesita establecerse en la
!>          entrada, pero se usa internamente como espacio de trabajo.
!>          En la salida, E es sobrescrito.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          Sin uso. Fue la tolerancia de error absoluto para los
!>          autovalores/autovectores en versiones anteriores.
!>

M

!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los autovalores seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz T
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que al menos max(1,M) columnas se
!>          proporcionan en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar una cota superior.
!>          Proporcionar N columnas siempre es seguro.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es un array INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los autovectores en Z, es decir, los índices
!>          que indican los elementos no nulos en Z. El i-ésimo autovector calculado
!>          es no nulo solo en los elementos ISUPPZ( 2*i-1 ) a través de
!>          ISUPPZ( 2*i ). Esto es relevante en el caso cuando la matriz
!>          se divide. ISUPPZ solo se accede cuando JOBZ es 'V' y N > 0.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo
!>          (y mínimo).
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,18*N)
!>          si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por XERBLA.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (LIWORK)
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.  LIWORK >= max(1,10*N)
!>          si se desean los autovectores, y LIWORK >= max(1,8*N)
!>          si solo se van a calcular los autovalores.
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          no se emite ningún mensaje de error relacionado con LIWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, INFO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = 1X, error interno en DLARRE,
!>                si INFO = 2X, error interno en DLARRV.
!>                Aquí, el dígito X = ABS( IINFO ) < 10, donde IINFO es
!>                el código de error no nulo devuelto por DLARRE o
!>                DLARRV, respectivamente.
!>
