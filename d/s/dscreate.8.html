NOMBRE

dscreate

SINOPSIS

dscreate [-h] [-v] [-j] {from-file,interactive,create-template,ds-root} ...

ARGUMENTOS POSICIONALES

dscreate from-file
Crear una instancia del Servidor de Directorio desde un archivo de respuestas inf
dscreate interactive
Iniciar el instalador interactivo para la instalación del Servidor de Directorio
dscreate create-template
Mostrar un archivo de respuestas inf de ejemplo, o proporcionar un nombre de archivo para escribirlo en disco.
dscreate ds-root
Preparar un directorio raíz en el cual un usuario no root puede crear, ejecutar y administrar instancias.

COMANDO 'dscreate from-file'

uso: dscreate from-file [-h] [-n] archivo

archivo
Archivo inf a utilizar con respuestas preparadas. Puede generar un ejemplo de esto con 'dscreate create-template'

OPCIONES 'dscreate from-file'

-n, --dryrun
Validar solo el sistema y las configuraciones. No alterar el sistema.

COMANDO 'dscreate interactive'

uso: dscreate interactive [-h]

COMANDO 'dscreate create-template'

uso: dscreate create-template [-h] [--advanced] [archivo_plantilla]

archivo_plantilla
Escribir plantilla de ejemplo en este archivo

OPCIONES 'dscreate create-template'

--advanced
Agregar opciones avanzadas a la plantilla - el cambio de las opciones avanzadas puede hacer fallar la instalación de su instancia

COMANDO 'dscreate ds-root'

uso: dscreate ds-root [-h] dir_raiz [dir_bin]

dir_raiz
Un directorio que se utilizará como raíz virtual.
dir_bin
Un directorio en el que se instalan los envoltorios de administración. (Debe estar en PATH)

OPCIONES

-v, --verbose
Mostrar rastreo detallado de operaciones durante la ejecución del comando
-j, --json
Devolver el resultado como un mensaje json

COMENTARIOS

Ejemplo de instalación por un usuario no root:
PATH=$HOME/bin:$PATH # Debe estar en .profile
dscreate ds-root $HOME/mydsroot $HOME/bin
hash -d dscreate # comando de bash para asegurar que se usará el nuevo envoltorio dscreate
dscreate interactive
# Nota: Asegúrese de usar un número de puerto no privilegiado (es decir, > 1000)
