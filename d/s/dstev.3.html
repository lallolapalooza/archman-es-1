subrutina dstev (jobz, n, d, e, z, ldz, work, info)
DSTEV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Documentación de la función/subrutina

subrutina dstev (carácter jobz, entero n, doble precisión, dimensión( * ) d, doble precisión, dimensión( * ) e, doble precisión, dimensión( ldz, * ) z, entero ldz, doble precisión, dimensión( * ) work, entero info)

DSTEV calcula todos los valores propios y, opcionalmente, los vectores propios de una matriz simétrica tridiagonal real A.

Propósito:

!>
!> DSTEV calcula todos los valores propios y, opcionalmente, los vectores propios de una
!> matriz simétrica tridiagonal real A.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular los valores propios y los vectores propios.
!>

N

!>          N es ENTERO
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz tridiagonal
!>          A.
!>          En la salida, si INFO = 0, los valores propios en orden ascendente.
!>

E

!>          E es un array de DOBLE PRECISIÓN, dimensión (N-1)
!>          En la entrada, los n-1 elementos subdiagonales de la matriz tridiagonal
!>          A, almacenados en los elementos 1 a N-1 de E.
!>          En la salida, el contenido de E se destruye.
!>

Z

!>          Z es un array de DOBLE PRECISIÓN, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores propios ortonormales
!>          de la matriz A, con la i-ésima columna de Z
!>          conteniendo el vector propio asociado con D(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es ENTERO
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (max(1,2*N-2))
!>          Si JOBZ = 'N', WORK no se referencia.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el algoritmo no convergió; i
!>                elementos fuera de la diagonal de E no convergieron a cero.
!>
