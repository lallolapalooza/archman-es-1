subrutina dsfrk (transr, uplo, trans, n, k, alpha, a, lda, beta, c)
DSFRK realiza una operación simétrica de rango k para matrices en formato RFP.

Documentación de función/subrutina

subrutina dsfrk (character transr, character uplo, character trans, integer n, integer k, double precision alpha, double precision, dimension( lda, * ) a, integer lda, double precision beta, double precision, dimension( * ) c)

DSFRK realiza una operación simétrica de rango k para matrices en formato RFP.

Propósito:

!>
!> Rutina similar a BLAS de nivel 3 para C en formato RFP.
!>
!> DSFRK realiza una de las operaciones simétricas de rango--k
!>
!>    C := alpha*A*A**T + beta*C,
!>
!> o
!>
!>    C := alpha*A**T*A + beta*C,
!>
!> donde alpha y beta son escalares reales, C es una matriz simétrica de n--por--n
!> y A es una matriz de n--por--k en el primer caso y una matriz de k--por--n
!> en el segundo caso.
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la Forma Normal de RFP A;
!>          = 'T':  Se almacena la Forma Transpuesta de RFP A.
!>

UPLO

!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la parte triangular superior o inferior
!>           del arreglo C se va a referenciar según:
!>
!>              UPLO = 'U' o 'u'   Solo se hace referencia a la parte triangular superior de C.
!>
!>              UPLO = 'L' o 'l'   Solo se hace referencia a la parte triangular inferior de C.
!>
!>           Sin cambios a la salida.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar, TRANS especifica la operación a realizar como:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**T + beta*C.
!>
!>              TRANS = 'T' o 't'   C := alpha*A**T*A + beta*C.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz C. N debe ser
!>           al menos cero.
!>           Sin cambios a la salida.
!>

K

!>          K es INTEGER
!>           Al entrar con TRANS = 'N' o 'n', K especifica el número
!>           de columnas de la matriz A, y al entrar con TRANS = 'T'
!>           o 't', K especifica el número de filas de la matriz A. K
!>           debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>           Al entrar, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

A

!>          A es un arreglo de DOUBLE PRECISION, de dimensión (LDA,ka)
!>           donde KA
!>           es K  cuando TRANS = 'N' o 'n', y es N en caso contrario. Antes
!>           de entrar con TRANS = 'N' o 'n', la parte principal N--por--K
!>           del arreglo A debe contener la matriz A, en caso contrario, la parte principal
!>           K--por--N del arreglo A debe contener la matriz A.
!>           Sin cambios a la salida.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A según lo declarado
!>           en el (sub)programa que llama.  Cuando TRANS = 'N' o 'n'
!>           entonces LDA debe ser al menos max( 1, n ), en caso contrario LDA debe
!>           ser al menos max( 1, k ).
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>           Al entrar, BETA especifica el escalar beta.
!>           Sin cambios a la salida.
!>

C

!>          C es un arreglo de DOUBLE PRECISION, de dimensión (NT)
!>           NT = N*(N+1)/2. Al entrar, la matriz simétrica C en formato RFP.
!>           El formato RFP se describe mediante TRANSR, UPLO y N.
!>
