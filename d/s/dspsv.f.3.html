Documentación de la función/subrutina

subrutina dspsv (caracter uplo, entero n, entero nrhs, doble precisión, dimensión( * ) ap, entero, dimensión( * ) ipiv, doble precisión, dimensión( ldb, * ) b, entero ldb, entero info)

DSPSV calcula la solución a un sistema real de ecuaciones lineales A * X = B para matrices OTROS

Propósito:

!>
!> DSPSV calcula la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica de N por N almacenada en formato empaquetado
!> y X y B son matrices de N por NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**T,  si UPLO = 'U', o
!>    A = L * D * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de permutación y matrices triangulares unitarias
!> superiores (inferiores). La forma factorizada de A se utiliza luego para
!> resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es un array DOUBLE PRECISION, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más detalles abajo.
!>
!>          En la salida, la matriz diagonal de bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T, tal como se calcula por DSPTRF, se almacenan como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D, tal como
!>          se determinan por DSPTRF. Si IPIV(k) > 0, entonces las filas y columnas
!>          k e IPIV(k) fueron intercambiadas, y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0,
!>          entonces las filas y columnas k-1 y -IPIV(k) fueron intercambiadas y
!>          D(k-1:k,k-1:k) es un bloque diagonal de 2x2. Si UPLO = 'L' e
!>          IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas k+1 y
!>          -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero. La factorización
!>                se ha completado, pero la matriz diagonal de bloques D
!>                es exactamente singular, por lo que no se pudo calcular la solución.
!>
