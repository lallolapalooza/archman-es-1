DSXT1

Propósito:

!>
!> DSXT1  calcula la diferencia entre un conjunto de valores propios.
!> El resultado se devuelve como el valor de la función.
!>
!> IJOB = 1:   Calcula   max { min | D1(i)-D2(j) | }
!>                         i     j
!>
!> IJOB = 2:   Calcula   max { min | D1(i)-D2(j) | /
!>                         i     j
!>                              ( ABSTOL + |D1(i)|*ULP ) }
!>

Parámetros

IJOB 
!>          IJOB es ENTERO
!>          Especifica el tipo de pruebas a realizar. (Ver arriba.)
!>

D1

!>          D1 es un arreglo de DOBLE PRECISIÓN, dimensión (N1)
!>          El primer arreglo. D1 debe estar en orden creciente, es decir,
!>          D1(j) <= D1(j+1).
!>

N1

!>          N1 es ENTERO
!>          La longitud de D1.
!>

D2

!>          D2 es un arreglo de DOBLE PRECISIÓN, dimensión (N2)
!>          El segundo arreglo. D2 debe estar en orden creciente, es decir,
!>          D2(j) <= D2(j+1).
!>

N2

!>          N2 es ENTERO
!>          La longitud de D2.
!>

ABSTOL

!>          ABSTOL es DOBLE PRECISIÓN
!>          La tolerancia absoluta, utilizada como medida del error.
!>

ULP

!>          ULP es DOBLE PRECISIÓN
!>          Precisión de la máquina.
!>

UNFL

!>          UNFL es DOBLE PRECISIÓN
!>          El número positivo más pequeño cuyo recíproco no
!>          desborda.
!>
