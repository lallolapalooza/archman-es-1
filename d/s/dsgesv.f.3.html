Documentación de Función/Subrutina

subrutina dsgesv (integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( n, * ) work, real, dimension( * ) swork, integer iter, integer info)

DSGESV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE (precisión mixta con refinamiento iterativo)

Propósito:

!>
!> DSGESV calcula la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> DSGESV primero intenta factorizar la matriz en PRECISIÓN SIMPLE
!> y usar esta factorización dentro de un procedimiento de refinamiento
!> iterativo para producir una solución con calidad de error hacia
!> atrás normativo en PRECISIÓN DOBLE (ver abajo). Si el enfoque falla,
!> el método cambia a una factorización y resolución en PRECISIÓN DOBLE.
!>
!> El refinamiento iterativo no será una estrategia ganadora si
!> la relación del rendimiento en PRECISIÓN SIMPLE sobre el rendimiento
!> en PRECISIÓN DOBLE es demasiado pequeña. Una estrategia razonable
!> debería tener en cuenta el número de miembros independientes y el
!> tamaño de la matriz. Esto podría hacerse con una llamada a ILAENV
!> en el futuro. Hasta ahora, siempre intentamos refinamiento iterativo.
!>
!> El proceso de refinamiento iterativo se detiene si
!>     ITER > ITERMAX
!> o para todos los miembros independientes tenemos:
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> donde
!>     o ITER es el número de la iteración actual en el proceso de
!>       refinamiento iterativo
!>     o RNRM es la norma infinito del residuo
!>     o XNRM es la norma infinito de la solución
!>     o ANRM es la norma de operador infinito de la matriz A
!>     o EPS es la épsilon de máquina devuelta por DLAMCH('Epsilon')
!> El valor ITERMAX y BWDMAX están fijados en 30 y 1.0D+00
!> respectivamente.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros independientes, es decir, el número de
!>          columnas de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array DOUBLE PRECISION,
!>          dimensión (LDA,N)
!>          En la entrada, la matriz de coeficientes A de N por N.
!>          En la salida, si el refinamiento iterativo se ha utilizado
!>          con éxito (INFO = 0 y ITER >= 0, ver descripción abajo), entonces A
!>          no se modifica, si se ha utilizado la factorización en doble
!>          precisión (INFO = 0 y ITER < 0, ver descripción abajo), entonces
!>          el array A contiene los factores L y U de la factorización
!>          A = P*L*U; los elementos diagonales unitarios de L no se almacenan.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote que definen la matriz de permutación P;
!>          la fila i de la matriz se intercambió con la fila IPIV(i).
!>          Corresponde a la factorización en precisión simple
!>          (si INFO = 0 y ITER >= 0) o a la factorización en doble
!>          precisión (si INFO = 0 y ITER < 0).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          La matriz de miembros independientes B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si INFO = 0, la matriz de solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (N,NRHS)
!>          Este array se usa para contener los vectores residuales.
!>

SWORK

!>          SWORK es un array REAL, dimensión (N*(N+NRHS))
!>          Este array se usa para contener la matriz en precisión simple
!>          y los miembros independientes o soluciones en precisión simple.
!>

ITER

!>          ITER es INTEGER
!>          < 0: el refinamiento iterativo ha fallado, se ha realizado
!>               la factorización en doble precisión
!>               -1 : la rutina volvió a la precisión completa por
!>                    razones específicas de la implementación o de la máquina
!>               -2 : la reducción de precisión indujo un desbordamiento,
!>                    la rutina volvió a la precisión completa
!>               -3 : fallo de SGETRF
!>               -31: se detuvo el refinamiento iterativo después de la 30ª
!>                    iteración
!>          > 0: el refinamiento iterativo se ha utilizado con éxito.
!>               Devuelve el número de iteraciones
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, U(i,i) calculado en PRECISIÓN DOBLE es
!>                exactamente cero. La factorización se ha completado,
!>                pero el factor U es exactamente singular, por lo que la
!>                solución no pudo ser calculada.
!>
