Documentación de Función/Subrutina

subroutine dsytrd_2stage (character vect, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) tau, double precision, dimension( * ) hous2, integer lhous2, double precision, dimension( * ) work, integer lwork, integer info)

DSYTRD_2STAGE

Propósito:

!>
!> DSYTRD_2STAGE reduce una matriz simétrica real A a la forma tridiagonal
!> simétrica real T mediante una transformación de semejanza ortogonal:
!> Q1**T Q2**T* A * Q2 * Q1 = T.
!>

Parámetros

VECT 
!>          VECT es CHARACTER*1
!>          = 'N':  No se necesita la representación de Householder,
!>                  en particular para la segunda etapa (Banda a
!>                  tridiagonal) y, por lo tanto, LHOUS2 es de tamaño max(1, 4*N);
!>          = 'V':  se necesita la representación de Householder para
!>                  generar Q1 Q2 o para aplicar Q1 Q2,
!>                  entonces LHOUS2 debe consultarse y calcularse.
!>                  (NO DISPONIBLE EN ESTA VERSIÓN).
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          triangular superior N-por-N líder de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia. Si UPLO = 'L', la parte
!>          triangular inferior N-por-N líder de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular estrictamente
!>          superior de A no se referencia.
!>          En la salida, si UPLO = 'U', las superdiagonales de banda
!>          de A se sobrescriben con los elementos correspondientes de la
!>          matriz interna de banda AB, y los elementos por encima de la
!>          KD-superdiagonal, junto con el array TAU, representan la matriz ortogonal
!>          Q1 como un producto de transformaciones elementales; si UPLO
!>          = 'L', la diagonal y las subdiagonales de banda de A se
!>          sobrescriben con los elementos correspondientes de la matriz interna
!>          de banda AB, y los elementos por debajo de la KD-subdiagonal, junto
!>          con el array TAU, representan la matriz ortogonal Q1 como un producto
!>          de transformaciones elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          Los elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N-1)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T.
!>

TAU

!>          TAU es un array DOUBLE PRECISION, de dimensión (N-KD)
!>          Los factores escalares de las transformaciones elementales de
!>          la primera etapa (ver Detalles Adicionales).
!>

HOUS2

!>          HOUS2 es un array DOUBLE PRECISION, de dimensión (MAX(1,LHOUS2))
!>          Almacena la representación de Householder de la segunda etapa,
!>          de banda a tridiagonal.
!>

LHOUS2

!>          LHOUS2 es INTEGER
!>          La dimensión del array HOUS2.
!>          LHOUS2 >= 1.
!>
!>          Si LWORK = -1, o LHOUS2 = -1,
!>          entonces se asume una consulta; la rutina
!>          solo calcula el tamaño óptimo del array HOUS2, devuelve
!>          este valor como la primera entrada del array HOUS2, y XERBLA
!>          no emite ningún mensaje de error relacionado con LHOUS2.
!>          Si VECT='N', LHOUS2 = max(1, 4*n);
!>          si VECT='V', opción aún no disponible.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N = 0, LWORK >= 1, de lo contrario LWORK = MAX(1, dimension).
!>
!>          Si LWORK = -1, o LHOUS2 = -1,
!>          entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con LWORK.
!>          LWORK = MAX(1, dimension) donde
!>          dimension   = max(etapa1,etapa2) + (KD+1)*N
!>                      = N*KD + N*max(KD+1,FACTOPTNB)
!>                        + max(2*KD*KD, KD*NTHREADS)
!>                        + (KD+1)*N
!>          donde KD es el tamaño del bloque de la reducción,
!>          FACTOPTNB es el tamaño del bloque utilizado por el algoritmo
!>          QR o LQ, normalmente FACTOPTNB=128 es una buena opción.
!>          NTHREADS es el número de hilos utilizados cuando
!>          la compilación openMP está habilitada, de lo contrario =1.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
