DSA_sign(3ssl)

Paquete: openssl

Licencias: Apache-2.0

DSA_SIGN(3ssl) OpenSSL DSA_SIGN(3ssl)

NOMBRE

DSA_sign, DSA_sign_setup, DSA_verify - firmas DSA

SINOPSIS

#include <openssl/dsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0 y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int DSA_sign(int type, const unsigned char *dgst, int len,
             unsigned char *sigret, unsigned int *siglen, DSA *dsa);
int DSA_sign_setup(DSA *dsa, BN_CTX *ctx, BIGNUM **kinvp, BIGNUM **rp);
int DSA_verify(int type, const unsigned char *dgst, int len,
               unsigned char *sigbuf, int siglen, DSA *dsa);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_sign_init(3), EVP_PKEY_sign(3), EVP_PKEY_verify_init(3) y EVP_PKEY_verify(3).

DSA_sign() calcula una firma digital sobre el digest de mensaje de len bytes dgst usando la clave privada dsa y coloca su codificación ASN.1 DER en sigret. La longitud de la firma se coloca en *siglen. sigret debe apuntar a DSA_size(dsa) bytes de memoria.

DSA_sign_setup() está definida solo para compatibilidad binaria hacia atrás y no debe usarse. Desde OpenSSL 1.1.0, el tipo DSA es opaco y la salida de DSA_sign_setup() no se puede usar de todos modos: llamar a esta función solo causará sobrecarga y no afectará el cálculo (pre-)efectivo de la firma.

DSA_verify() verifica que la firma sigbuf de tamaño siglen coincide con un digest de mensaje dado dgst de tamaño len. dsa es la clave pública del firmante.

El parámetro type se ignora.

El generador aleatorio debe ser inicializado cuando se llama a DSA_sign() (o DSA_sign_setup()). Si la inicialización o re-inicialización automática del CSPRNG de OpenSSL falla debido a circunstancias externas (ver RAND(7)), la operación fallará.

VALORES DE RETORNO

DSA_sign() y DSA_sign_setup() devuelven 1 en caso de éxito, 0 en caso de error. DSA_verify() devuelve 1 para una firma válida, 0 para una firma incorrecta y -1 en caso de error. Los códigos de error se pueden obtener con ERR_get_error(3).

CONFORMANDO A

Estándar Federal de Procesamiento de Información de EE. UU. FIPS186-4 (Digital Signature Standard, DSS), ANSI X9.30

VER TAMBIÉN

DSA_new(3), ERR_get_error(3), RAND_bytes(3), DSA_do_sign(3), RAND(7)

HISTORIA

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
