NOMBRE

dsymutil - manipula archivos de símbolos de depuración DWARF archivados

SINOPSIS

dsymutil [opciones] ejecutable

DESCRIPCIÓN

dsymutil enlaza la información de depuración DWARF encontrada en los archivos objeto para un ejecutable ejecutable usando la información de símbolos de depuración contenida en su tabla de símbolos. Por defecto, la información de depuración enlazada se coloca en un paquete .dSYM con el mismo nombre que el ejecutable.

OPCIONES

--accelerator=<tipo de acelerador>
Especifica el tipo deseado de tabla aceleradora. Las opciones válidas son 'Apple', 'Dwarf', 'Default' y 'None'.
--arch <arch>
Enlaza información de depuración DWARF solo para los tipos de arquitectura de CPU especificados. Las arquitecturas pueden especificarse por nombre. Al usar esta opción, se devolverá un error si alguna arquitectura no puede ser enlazada correctamente. Esta opción se puede especificar varias veces, una por cada arquitectura deseada. Todas las arquitecturas de CPU serán enlazadas por defecto y cualquier arquitectura que no pueda ser enlazada correctamente provocará que dsymutil devuelva un error.
--build-variant-suffix <suffix=buildvariant>
Especifica el sufijo de variante de compilación utilizado para compilar el archivo ejecutable. Puede haber múltiples variantes para el binario de un producto, cada una compilada de manera ligeramente diferente. Las variantes de compilación más comunes son 'debug' y 'profile'. Establecer la variable de entorno DYLD_IMAGE_SUFFIX hará que dyld cargue la variante especificada en tiempo de ejecución.
--dump-debug-map
Vuelca el mapa de depuración del ejecutable (la lista de los archivos objeto que contienen la información de depuración) en formato YAML y sale. No se realizará ningún enlace DWARF.
-D <ruta>

Especifica un directorio que contenga archivos dSYM para buscar. Esto se utiliza para bibliotecas fusionables, por lo que dsymutil sabe dónde buscar archivos dSYM con información de depuración sobre símbolos presentes en esas bibliotecas.

--fat64
Utiliza una cabecera de 64 bits al emitir binarios universales.
--flat, -f
Produce un archivo dSYM plano. Se añadirá una extensión .dwarf al nombre del ejecutable a menos que el archivo de salida se especifique usando la opción -o.
--gen-reproducer
Genera un reproductor que consiste en los archivos objeto de entrada. Alias para --reproducer=GenerateOnExit.
--help, -h
Imprime esta salida de ayuda.
--keep-function-for-static
Hace que una variable estática conserve la función que la contiene, incluso si de otro modo se omitiría.
--minimize, -z
Cuando se usa al crear un archivo dSYM, esta opción suprimirá la emisión de las secciones .debug_inlines, .debug_pubnames y .debug_pubtypes ya que dsymutil actualmente tiene mejores equivalentes: .apple_names y .apple_types. Cuando se usa junto con la opción --update, esta opción eliminará las tablas aceleradoras redundantes.
--no-object-timestamp
No comprueba la marca de tiempo de los archivos objeto.
--no-odr
No utiliza la Regla de Definición Única (ODR) para unificar tipos de C++.
--no-output
Realiza el enlace en memoria, pero no emite el archivo resultante.
--no-swiftmodule-timestamp
No comprueba la marca de tiempo de los archivos swiftmodule.
--num-threads <hilos>, -j <hilos>
Especifica el número máximo (n) de hilos simultáneos a utilizar al enlazar múltiples arquitecturas.
--object-prefix-map <prefijo=remapeado>
Remapea las rutas de los archivos objeto (pero no las rutas fuente) antes de procesarlos. Utilízalo para objetos Clang donde la ubicación de la caché de módulos fue remapeada usando -fdebug-prefix-map; para ayudar a dsymutil a encontrar la caché de módulos de Clang.
--oso-prepend-path <ruta>
Especifica una ruta a anteponer a todas las rutas de archivos objeto de símbolos de depuración.
--out <nombre_archivo>, -o <nombre_archivo>
Especifica una ruta alternativa para colocar el paquete dSYM. La ruta predeterminada del paquete dSYM se crea añadiendo .dSYM al nombre del ejecutable.
-q, --quiet
Habilita el modo silencioso y limita la salida.
--remarks-drop-without-debug
Descarta las observaciones sin ubicaciones de depuración válidas. Sin esta bandera, se conservan todas las observaciones.
--remarks-output-format <formato>
Especifica el formato a utilizar al serializar las observaciones enlazadas.
--remarks-prepend-path <ruta>
Especifica un directorio para anteponer las rutas de los archivos de observaciones externos.
--reproducer <modo>
Especifica el modo de generación del reproductor. Las opciones válidas son 'GenerateOnExit', 'GenerateOnCrash', 'Use', 'Off'.
--statistics
Imprime estadísticas sobre la contribución de cada archivo objeto a la información de depuración enlazada. Imprime una tabla después del enlace con el nombre del archivo objeto, el tamaño de la información de depuración en el archivo objeto (en bytes) y el tamaño contribuido (en bytes) al dSYM enlazado. La tabla se ordena por el tamaño de salida, listando primero los archivos objeto con la mayor contribución.
-s, --symtab
Vuelca la tabla de símbolos encontrada en ejecutable o en los archivos objeto y sale.
-S
Genera ensamblaje textual en lugar de un archivo acompañante dSYM binario.
--toolchain <toolchain>
Incrusta la toolchain en la lista de propiedades del paquete dSYM.
-u, --update
Actualiza un archivo dSYM existente para contener las últimas tablas aceleradoras y otras optimizaciones DWARF. Esta opción reconstruirá las tablas aceleradoras cifradas '.apple_names' y '.apple_types'.
--use-reproducer <path>
Usa los archivos de objeto de la ruta del reproductor dada. Alias de --reproducer=Use.
--verbose
Muestra información detallada al enlazar.
--verify
Ejecuta el verificador DWARF sobre la información de depuración DWARF enlazada.
-v, --version
Muestra la versión de la herramienta.
-y
Tratar executable como un mapa de depuración YAML en lugar de un ejecutable.

ESTADO DE SALIDA

dsymutil devuelve 0 si la información de depuración DWARF se enlazó correctamente. De lo contrario, devuelve 1.
