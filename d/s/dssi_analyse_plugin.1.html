NOMBRE

dssi_analyse_plugin - describe un plugin DSSI

SINOPSIS

dssi_analyse_plugin [-v|--verbose] [ruta]<nombre_lib>[:<etiqueta>]

DESCRIPCIÓN

dssi_analyse_plugin lista información sobre plugins DSSI dentro de una biblioteca compartida DSSI especificada nombre_lib. Si se proporciona etiqueta, solo se listará la información del plugin con esa etiqueta, de lo contrario, se listarán todos los plugins de la biblioteca compartida. Si no se proporciona ruta, la biblioteca compartida se buscará en la lista de directorios separados por dos puntos especificada en la variable de entorno DSSI_PATH.

OPCIONES

-v
--verbose
Hace que dssi_analyse_plugin sea más detallado en su informe. En particular, listará los nombres de programas predeterminados para cada plugin, si los hay.

EJEMPLOS

El siguiente comando mostrará información sobre todos los plugins de la biblioteca compartida /usr/local/lib/dssi/calf.so, incluyendo los nombres de programas predeterminados:

$ dssi_analyse_plugin -v /usr/local/lib/dssi/calf.so

El siguiente comando buscará la biblioteca compartida trivial_sampler.so utilizando DSSI_PATH y mostrará información sobre el plugin mono_sampler:

$ dssi_analyse_plugin trivial_sampler.so:mono_sampler

ENTORNO

DSSI_PATH
Una lista de directorios separados por dos puntos para escanear en busca de plugins DSSI.

CONFORME A

DSSI RFC versión 1.0.

VER TAMBIÉN

dssi_list_plugins(1), http://dssi.sourceforge.net/
