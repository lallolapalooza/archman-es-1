Documentación de Función/Subrutin

a

subrutina dsytrd_2stage (character vect, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) tau, double precision, dimension( * ) hous2, integer lhous2, double precision, dimension( * ) work, integer lwork, integer

info)

DSYTRD_2STAG

E

Propósito

: 
!>
!> DSYTRD_2STAGE reduce una matriz simétrica real A a una forma tridiagonal simétrica real T mediante una transformación de similitud ortogonal:
!> Q1**T Q2**T* A * Q2 * Q1 = T.
!
>

Parámetro

s
VECT 
!>          VECT es CHARACTER*1
!>          = 'N':  No se necesita la representación de Householder,
!>                  en particular para la segunda etapa (de banda a
!>                  tridiagonal) y por lo tanto LHOUS2 tiene tamaño max(1, 4*N);
!>          = 'V':  la representación de Householder es necesaria para
!>                  ya sea generar Q1 Q2 o aplicar Q1 Q2,
!>                  entonces LHOUS2 debe ser consultado y calculado.
!>                  (NO DISPONIBLE EN ESTA VERSIÓN).
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          triangular superior N-por-N principal de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no es referenciada.  Si UPLO = 'L', la
!>          parte triangular inferior N-por-N principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no es referenciada.
!>          En la salida, si UPLO = 'U', la superdiagonal de banda
!>          de A es sobrescrita por los elementos correspondientes de la
!>          matriz interna de banda-diagonal AB, y los elementos por encima
!>          de la superdiagonal KD, junto con el array TAU, representan la matriz ortogonal
!>          Q1 como un producto de reflectores elementales; si UPLO
!>          = 'L', la diagonal y la subdiagonal de banda de A son sobres-
!>          critas por los elementos correspondientes de la matriz interna de banda-diagonal
!>          AB, y los elementos por debajo de la subdiagonal KD, junto con el
!>          array TAU, representan la matriz ortogonal Q1 como un producto
!>          de reflectores elementales. Vea Detalles Adicionales.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

D 
!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Los elementos diagonales de la matriz tridiagonal T.
!
>

E 
!>          E es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T.
!
>

TA

U 
!>          TAU es un array DOUBLE PRECISION, dimensión (N-KD)
!>          Los factores escalares de los reflectores elementales de
!>          la primera etapa (vea Detalles Adicionales).
!
>

HOUS

2 
!>          HOUS2 es un array DOUBLE PRECISION, dimensión (MAX(1,LHOUS2))
!>          Almacena la representación de Householder de la etapa2
!>          de banda a tridiagonal.
!
>

LHOUS

2 
!>          LHOUS2 es INTEGER
!>          La dimensión del array HOUS2.
!>          LHOUS2 >= 1.
!>
!>          Si LWORK = -1, o LHOUS2 = -1,
!>          entonces se asume una consulta; la rutina
!>          solo calcula el tamaño óptimo del array HOUS2, devuelve
!>          este valor como la primera entrada del array HOUS2, y no se emite
!>          ningún mensaje de error relacionado con LHOUS2 por parte de XERBLA.
!>          Si VECT='N', LHOUS2 = max(1, 4*n);
!>          si VECT='V', opción aún no disponible.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N = 0, LWORK >= 1, de lo contrario LWORK = MAX(1, dimensión).
!>
!>          Si LWORK = -1, o LHOUS2 = -1,
!>          entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>          LWORK = MAX(1, dimensión) donde
!>          dimensión   = max(etapa1,etapa2) + (KD+1)*N
!>                      = N*KD + N*max(KD+1,FACTOPTNB)
!>                        + max(2*KD*KD, KD*NTHREADS)
!>                        + (KD+1)*N
!>          donde KD es el tamaño de bloqueo de la reducción,
!>          FACTOPTNB es el bloqueo usado por el algoritmo QR o LQ,
!>          usualmente FACTOPTNB=128 es una buena elección
!>          NTHREADS es el número de hilos usado cuando
!>          la compilación con openMP está habilitada, de lo contrario =1.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>
