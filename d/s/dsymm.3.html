Documentación de la Función/Subrutina

subroutine dsymm (character side, character uplo, integer m, integer n, double precision alpha, double precision, dimension(lda,*) a, integer lda, double precision, dimension(ldb,*) b, integer ldb, double precision beta, double precision, dimension(ldc,*) c, integer ldc)

DSYMM

Propósito:

!>
!> DSYMM  realiza una de las operaciones de matriz-matriz
!>
!>    C := alpha*A*B + beta*C,
!>
!> o
!>
!>    C := alpha*B*A + beta*C,
!>
!> donde alpha y beta son escalares, A es una matriz simétrica y B y
!> C son matrices de m por n.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>           En la entrada, SIDE especifica si la matriz simétrica A
!>           aparece a la izquierda o a la derecha en la operación, como sigue:
!>
!>              SIDE = 'L' o 'l'   C := alpha*A*B + beta*C,
!>
!>              SIDE = 'R' o 'r'   C := alpha*B*A + beta*C,
!>

UPLO

!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si se hará referencia a la
!>           parte triangular superior o inferior de la matriz simétrica A,
!>           como sigue:
!>
!>              UPLO = 'U' o 'u'   Solo se hará referencia a la parte triangular superior de la matriz simétrica.
!>
!>              UPLO = 'L' o 'l'   Solo se hará referencia a la parte triangular inferior de la matriz simétrica.
!>

M

!>          M es INTEGER
!>           En la entrada, M especifica el número de filas de la matriz C.
!>           M debe ser al menos cero.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de la matriz C.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION.
!>           En la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array DOUBLE PRECISION, dimension ( LDA, ka ), donde ka es
!>           m si SIDE = 'L' o 'l', y n en caso contrario.
!>           Antes de la entrada con SIDE = 'L' o 'l', la parte de m por m
!>           del array A debe contener la matriz simétrica, tal que
!>           cuando UPLO = 'U' o 'u', la parte triangular superior de m por m
!>           del array A debe contener la parte triangular superior de
!>           la matriz simétrica y la parte triangular estrictamente inferior de A
!>           no se referencia. Cuando UPLO = 'L' o 'l', la parte triangular inferior de m por m
!>           del array A debe contener la parte triangular inferior de
!>           la matriz simétrica y la parte triangular estrictamente superior de A
!>           no se referencia.
!>           Antes de la entrada con SIDE = 'R' o 'r', la parte de n por n
!>           del array A debe contener la matriz simétrica, tal que
!>           cuando UPLO = 'U' o 'u', la parte triangular superior de n por n
!>           del array A debe contener la parte triangular superior de
!>           la matriz simétrica y la parte triangular estrictamente inferior de A
!>           no se referencia. Cuando UPLO = 'L' o 'l', la parte triangular inferior de n por n
!>           del array A debe contener la parte triangular inferior de
!>           la matriz simétrica y la parte triangular estrictamente superior de A
!>           no se referencia.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como se declaró
!>           en el programa llamante (subrutina). Cuando SIDE = 'L' o 'l',
!>           LDA debe ser al menos max( 1, m ). En caso contrario, LDA debe
!>           ser al menos max( 1, n ).
!>

B

!>          B es un array DOUBLE PRECISION, dimension ( LDB, N )
!>           Antes de la entrada, la parte principal de m por n del array B debe
!>           contener la matriz B.
!>

LDB

!>          LDB es INTEGER
!>           En la entrada, LDB especifica la primera dimensión de B tal como se declaró
!>           en el programa llamante (subrutina). LDB debe ser al menos
!>           max( 1, m ).
!>

BETA

!>          BETA es DOUBLE PRECISION.
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA
!>           se suministra como cero, C no necesita estar inicializado en la entrada.
!>

C

!>          C es un array DOUBLE PRECISION, dimension ( LDC, N )
!>           Antes de la entrada, la parte principal de m por n del array C debe
!>           contener la matriz C, excepto cuando beta es cero, en cuyo caso C
!>           no necesita estar inicializado en la entrada.
!>           En la salida, el array C se sobrescribe con la matriz actualizada de m por n.
!>

LDC

!>          LDC es INTEGER
!>           En la entrada, LDC especifica la primera dimensión de C tal como se declaró
!>           en el programa llamante (subrutina). LDC debe ser al menos
!>           max( 1, m ).
!>
