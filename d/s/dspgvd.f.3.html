Documentación de Función/Subrutin

a

subrutina dspgvd (integer itype, character jobz, character uplo, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) bp, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

info)

DSPGV

D

Propósito

: 
!>
!> DSPGVD calcula todos los eigenvalores, y opcionalmente, los eigenvectores
!> de un problema de eigenvalores generalizado simétrico-definido real, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.  Aquí A y
!> B se asumen simétricos, almacenados en formato empaquetado, y B es también
!> definido positivo.
!> Si se desean eigenvectores, se usa un algoritmo de divide y vencerás.
!>
!
>

Parámetro

s
ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!
>

JOB

Z 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo eigenvalores;
!>          = 'V':  Calcular eigenvalores y eigenvectores.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

A

P 
!>          AP es un array DOUBLE PRECISION, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          A, empaquetado por columnas en un array lineal.  La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, el contenido de AP se destruye.
!
>

B

P 
!>          BP es un array DOUBLE PRECISION, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          B, empaquetado por columnas en un array lineal.  La j-ésima columna de B
!>          se almacena en el array BP de la siguiente manera:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          En la salida, el factor triangular U o L de la factorización
!>          Cholesky B = U**T*U o B = L*L**T, en el mismo formato de
!>          almacenamiento que B.
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          eigenvectores.  Los eigenvectores se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK requerido.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LWORK >= 2*N.
!>          Si JOBZ = 'V' y N > 1, LWORK >= 1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños requeridos de los arrays WORK e IWORK,
!>          devuelve estos valores como las primeras entradas de los arrays
!>          WORK e IWORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK o LIWORK.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK requerido.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños requeridos de los arrays WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  DPPTRF o DSPEVD devolvió un código de error:
!>             <= N:  si INFO = i, DSPEVD falló en converger;
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon eigenvalores ni eigenvectores.
!
>
