subroutine dsgesv (n, nrhs, a, lda, ipiv, b, ldb, x, ldx, work, swork, iter, info)
DSGESV calcula la solución del sistema de ecuaciones lineales A * X = B para matrices GE (precisión mixta con refinamiento iterativo)

Documentación de Función/Subrutina

subroutine dsgesv (integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( n, * ) work, real, dimension( * ) swork, integer iter, integer info)

DSGESV calcula la solución de un sistema real de ecuaciones lineales A * X = B, donde A es una matriz N por N y X y B son matrices N por NRHS.

Propósito:

!>
!> DSGESV calcula la solución de un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> DSGESV primero intenta factorizar la matriz en PRECISIÓN SIMPLE
!> y usar esta factorización dentro de un procedimiento de refinamiento iterativo
!> para producir una solución con calidad de error residual en norma (normwise backward error)
!> de PRECISIÓN DOBLE (ver abajo). Si el enfoque falla, el método cambia a una
!> factorización y solución en PRECISIÓN DOBLE.
!>
!> El refinamiento iterativo no será una estrategia ganadora si
!> la relación entre el rendimiento en PRECISIÓN SIMPLE y el rendimiento en
!> PRECISIÓN DOBLE es demasiado pequeña. Una estrategia razonable debería tener en cuenta
!> el número de lados derechos y el tamaño de la matriz.
!> Esto podría hacerse con una llamada a ILAENV en el futuro. Hasta ahora,
!> siempre intentamos el refinamiento iterativo.
!>
!> El proceso de refinamiento iterativo se detiene si
!>     ITER > ITERMAX
!> o para todos los RHS tenemos:
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> donde
!>     o ITER es el número de la iteración actual en el proceso
!>       de refinamiento iterativo
!>     o RNRM es la norma infinita del residuo
!>     o XNRM es la norma infinita de la solución
!>     o ANRM es la norma del operador infinito de la matriz A
!>     o EPS es el epsilon de máquina devuelto por DLAMCH('Epsilon')
!> Los valores ITERMAX y BWDMAX están fijados en 30 y 1.0D+00
!> respectivamente.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es array de DOUBLE PRECISION,
!>          dimension (LDA,N)
!>          En la entrada, la matriz de coeficientes N por N A.
!>          En la salida, si el refinamiento iterativo se ha utilizado con éxito
!>          (INFO = 0 y ITER >= 0, ver descripción abajo), entonces A no ha
!>          cambiado, si se ha utilizado la factorización de precisión doble
!>          (INFO = 0 y ITER < 0, ver descripción abajo), entonces el
!>          array A contiene los factores L y U de la factorización
!>          A = P*L*U; los elementos diagonales unitarios de L no se almacenan.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es array de INTEGER, dimension (N)
!>          Los índices de pivote que definen la matriz de permutación P;
!>          la fila i de la matriz fue intercambiada con la fila IPIV(i).
!>          Corresponde a la factorización en precisión simple
!>          (si INFO = 0 e ITER >= 0) o a la factorización en precisión doble
!>          (si INFO = 0 e ITER < 0).
!>

B

!>          B es array de DOUBLE PRECISION, dimension (LDB,NRHS)
!>          La matriz B de N por NRHS del lado derecho.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array de DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Si INFO = 0, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

WORK

!>          WORK es array de DOUBLE PRECISION, dimension (N,NRHS)
!>          Este array se utiliza para almacenar los vectores residuales.
!>

SWORK

!>          SWORK es array de REAL, dimension (N*(N+NRHS))
!>          Este array se utiliza para usar la matriz en precisión simple y los
!>          lados derechos o soluciones en precisión simple.
!>

ITER

!>          ITER es INTEGER
!>          < 0: el refinamiento iterativo ha fallado, se ha realizado una
!>               factorización en precisión doble
!>               -1 : la subrutina recurrió a precisión completa por razones
!>                    específicas de la implementación o de la máquina
!>               -2 : la reducción de precisión provocó un desbordamiento,
!>                    la subrutina recurrió a precisión completa
!>               -3 : fallo de SGETRF
!>               -31: se detuvo el refinamiento iterativo después de la 30ª
!>                    iteración
!>          > 0: se ha utilizado con éxito el refinamiento iterativo.
!>               Devuelve el número de iteraciones
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, U(i,i) calculado en PRECISIÓN DOBLE
!>                es exactamente cero. La factorización se ha completado,
!>                pero el factor U es exactamente singular, por lo que la solución
!>                no pudo calcularse.
!>
