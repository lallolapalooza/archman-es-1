DSTEVR calcula los eigenvalores y, opcionalmente, los autovectores izquierdos y/o derechos para matrices OTHER

Documentación de Función/Subrutin

subrutina dstevr (character jobz, character range, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

DSTEVR calcula los eigenvalores y, opcionalmente, los autovectores izquierdos y/o derechos para matrices

OTHER

Propósito

: 
!>
!> DSTEVR calcula los eigenvalores seleccionados y, opcionalmente, los autovectores
!> de una matriz tridiagonal simétrica real T. Los eigenvalores y
!> autovectores pueden seleccionarse especificando un rango de valores
!> o un rango de índices para los eigenvalores deseados.
!>
!> Siempre que sea posible, DSTEVR llama a DSTEMR para calcular el
!> espectro de eigenvalores usando Representaciones Robustas Relativas. DSTEMR
!> calcula los eigenvalores mediante el algoritmo dqds, mientras que
!> los autovectores ortogonales se calculan a partir de diversas representaciones L D L^T
!> (también conocidas como Representaciones Robustas Relativas). Se evita la
!> ortogonalización de Gram-Schmidt en la medida de lo posible. Más específicamente,
!> los diversos pasos del algoritmo son los siguientes. Para el i-ésimo
!> bloque no reducido de T,
!>    (a) Calcular T - sigma_i = L_i D_i L_i^T, de modo que L_i D_i L_i^T
!>         sea una representación robusta relativa,
!>    (b) Calcular los eigenvalores, lambda_j, de L_i D_i L_i^T con alta
!>        precisión relativa mediante el algoritmo dqds,
!>    (c) Si hay un grupo de eigenvalores cercanos, sigma_i
!>        cercano al grupo, y volver al paso (a),
!>    (d) Dado el eigenvalor aproximado lambda_j de L_i D_i L_i^T,
!>        calcular el autovector correspondiente formando una
!>        factorización retorcida reveladora de rango.
!> La precisión deseada de la salida puede especificarse mediante el parámetro
!> de entrada ABSTOL.
!>
!> Para más detalles, ver , por Inderjit Dhillon,
!> Computer Science Division Technical Report No. UCB//CSD-97-971,
!> UC Berkeley, Mayo 1997.
!>
!>
!> Nota 1 : DSTEVR llama a DSTEMR cuando se solicita el espectro completo
!> en máquinas que se ajustan al estándar de punto flotante ieee-754.
!> DSTEVR llama a DSTEBZ y DSTEIN en máquinas no-ieee y
!> cuando se hacen solicitudes de espectro parcial.
!>
!> La ejecución normal de DSTEVR puede crear NaNs e infinitos y
!> por lo tanto puede abortarse debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos de la manera predeterminada del estándar ieee.
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo eigenvalores;
!>          = 'V':  Calcular eigenvalores y autovectores.
!
>

RANG

E 
!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los eigenvalores.
!>          = 'V': se encontrarán todos los eigenvalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los eigenvalores desde el IL-ésimo hasta el IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman a DSTEBZ y
!>          DSTEIN
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!
>

D 
!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz tridiagonal
!>          A.
!>          En la salida, D puede multiplicarse por un factor constante elegido
!>          para evitar el desbordamiento/sobredesbordamiento al calcular los eigenvalores.
!
>

E 
!>          E es un array DOUBLE PRECISION, dimensión (max(1,N-1))
!>          En la entrada, los (n-1) elementos subdiagonales de la matriz
!>          tridiagonal A en los elementos 1 a N-1 de E.
!>          En la salida, E puede multiplicarse por un factor constante elegido
!>          para evitar el desbordamiento/sobredesbordamiento al calcular los eigenvalores.
!
>

V

L 
!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo donde
!>          se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

V

U 
!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo donde
!>          se buscarán los eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

I

L 
!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

I

U 
!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

ABSTO

L 
!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los eigenvalores.
!>          Un eigenvalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor
!>          o igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si la alta precisión relativa es importante, establezca ABSTOL a
!>          DLAMCH( 'Safe minimum' ). Al hacerlo se garantizará que
!>          los eigenvalores se calculen con alta precisión relativa cuando
!>          sea posible en versiones futuras. El código actual no
!>          hace ninguna garantía sobre la alta precisión relativa, pero
!>          las versiones futuras sí lo harán. Ver J. Barlow y J. Demmel,
!>          , LAPACK Working Note #7, para una discusión
!>          de qué matrices definen sus eigenvalores con alta precisión
!>          relativa.
!
>

M 
!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los eigenvalores seleccionados en
!>          orden ascendente.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz A
!>          correspondientes a los eigenvalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas en
!>          el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y debe usarse una cota superior.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y if
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

ISUPP

Z 
!>          ISUPPZ es un arreglo INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los autovectores en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo
!>          autovector es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) a
!>          ISUPPZ( 2*i ).
!>          Implementado solo para RANGE = 'A' o 'I' y IU - IL = N - 1
!
>

WOR

K 
!>          WORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo (y
!>          mínimo).
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.  LWORK >= max(1,20*N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arreglos WORK e IWORK,
!>          devuelve estos valores como las primeras entradas de los arreglos
!>          WORK e IWORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK o
!>          LIWORK.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (MAX(1,LIWORK))
!>          Al salir, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo (y
!>          mínimo).
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del arreglo IWORK.  LIWORK >= max(1,10*N).
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arreglos WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arreglos WORK e IWORK, y XERBLA no emite ningún mensaje de error relacionado con
!>          LWORK o LIWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  Error interno
!
>
