subrutina dsygvd (itype, jobz, uplo, n, a, lda, b, ldb, w, work, lwork, iwork, liwork, info)
DSYGVD

Documentación de Función/Subrutin

a

subrutina dsygvd (integer itype, character jobz, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) w, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

info)

DSYGV

D

Propósito

: 
!>
!> DSYGVD calcula todos los eigenvalores y, opcionalmente, los eigenvectores
!> de un problema de eigenvalores generalizado simétrico-definido real, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.  Aquí se asume que A y
!> B son simétricas y que B es además definida positiva.
!> Si se desean eigenvectores, se utiliza un algoritmo de divide y vencerás.
!>
!
>

Parámetro

s
ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!
>

JOB

Z 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo eigenvalores;
!>          = 'V':  Calcular eigenvalores y eigenvectores.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior de A de tamaño N por N contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior de A de tamaño N por N contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de eigenvectores.  Los eigenvectores se normalizan
!>          de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se destruye.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB, N)
!>          En la entrada, la matriz simétrica B.  Si UPLO = 'U', la
!>          parte triangular superior de B de tamaño N por N contiene la
!>          parte triangular superior de la matriz B.  Si UPLO = 'L',
!>          la parte triangular inferior de B de tamaño N por N contiene
!>          la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz es
!>          sobrescrita por el factor triangular U o L de la factorización
!>          Cholesky B = U**T*U o B = L*L**T.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LWORK >= 2*N+1.
!>          Si JOBZ = 'V' y N > 1, LWORK >= 1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK e IWORK,
!>          devuelve estos valores como las primeras entradas de los arrays
!>          WORK e IWORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK o LIWORK.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1,                LIWORK >= 1.
!>          Si JOBZ  = 'N' y N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  DPOTRF o DSYEVD devolvió un código de error:
!>             <= N:  si INFO = i y JOBZ = 'N', entonces el algoritmo
!>                    falló en converger; i elementos fuera de la diagonal de una
!>                    forma tridiagonal intermedia no convergieron a
!>                    cero;
!>                    si INFO = i y JOBZ = 'V', entonces el algoritmo
!>                    falló en calcular un eigenvalor mientras trabajaba en
!>                    la submatriz que se encuentra en las filas y columnas INFO/(N+1)
!>                    hasta mod(INFO,N+1);
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon eigenvalores ni eigenvectores.
!
>
