subrutina dsytrd_sy2sb (uplo, n, kd, a, lda, ab, ldab, tau, work, lwork, info)
DSYTRD_SY2SB

Documentación de Función/Subrutin

a

subrutina dsytrd_sy2sb (character uplo, integer n, integer kd, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer lwork, integer

info)

DSYTRD_SY2S

B

Propósito

: 
!>
!> DSYTRD_SY2SB reduce una matriz simétrica real A a una forma
!> simétrica real banda-diagonal AB mediante una transformación de
!> similitud ortogonal:
!> Q**T * A * Q = AB.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

K

D 
!>          KD es INTEGER
!>          El número de superdiagonales de la matriz reducida si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>          La matriz reducida se almacena en el array AB.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          triangular superior N-por-N inicial de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular
!>          inferior estricta de A no se referencia.  Si UPLO = 'L', la
!>          parte triangular inferior N-por-N inicial de A contiene la
!>          parte triangular inferior de la matriz A, y la parte
!>          triangular superior estricta de A no se referencia.
!>          En la salida, si UPLO = 'U', la diagonal y la primera
!>          superdiagonal de A se sobrescriben con los elementos
!>          correspondientes de la matriz tridiagonal T, y los elementos
!>          por encima de la primera superdiagonal, junto con el array
!>          TAU, representan la matriz ortogonal Q como un producto de
!>          reflectores elementales; si UPLO = 'L', la diagonal y la
!>          primera subdiagonal de A se sobrescriben con los elementos
!>          correspondientes de la matriz tridiagonal T, y los elementos
!>          por debajo de la primera subdiagonal, junto con el array
!>          TAU, representan la matriz ortogonal Q como un producto de
!>          reflectores elementales. Ver Detalles Adicionales.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

A

B 
!>          AB es un array DOUBLE PRECISION, dimensión (LDAB,N)
!>          En la salida, el triángulo superior o inferior de la matriz
!>          banda simétrica A, almacenado en las primeras KD+1 filas del
!>          array.  La j-ésima columna de A se almacena en la j-ésima
!>          columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!
>

TA

U 
!>          TAU es un array DOUBLE PRECISION, dimensión (N-KD)
!>          Los factores escalares de los reflectores elementales (ver
!>          Detalles Adicionales).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, o si LWORK = -1,
!>          WORK(1) devuelve el tamaño de LWORK.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK que debería ser calculada
!>          mediante una consulta de espacio de trabajo.
!>          Si N <= KD+1, LWORK >= 1, de lo contrario LWORK = MAX(1, LWORK_QUERY)
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>          LWORK_QUERY = N*KD + N*max(KD,FACTOPTNB) + 2*KD*KD
!>          donde FACTOPTNB es el bloqueo utilizado por el algoritmo QR o
!>          LQ, normalmente FACTOPTNB=128 es una buena elección, de lo
!>          contrario poner LWORK=-1 proporcionará el tamaño de WORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>

!>
!>  Si UPLO = 'U', la matriz Q se representa como un producto de
!>  reflectores elementales
!>
!>     Q = H(k)**T . . . H(2)**T H(1)**T, donde k = n-kd.
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(1:i+kd-1) = 0 y v(i+kd) = 1; conjg(v(i+kd+1:n)) se almacena en la
!>  salida en A(i,i+kd+1:n), y tau en TAU(i).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de
!>  reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = n-kd.
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**T
!>
!>  donde tau es un escalar real, y v es un vector real con
!>  v(kd+1:i) = 0 y v(i+kd+1) = 1; v(i+kd+2:n) se almacena en la
!>  salida en A(i+kd+2:n,i), y tau en TAU(i).
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos
!>  con n = 5:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  ab  ab/v1  v1      v1     v1    )              (  ab                            )
!>    (      ab     ab/v2   v2     v2    )              (  ab/v1  ab                     )
!>    (             ab      ab/v3  v3    )              (  v1     ab/v2  ab              )
!>    (                     ab     ab/v4 )              (  v1     v2     ab/v3  ab       )
!>    (                            ab    )              (  v1     v2     v3     ab/v4 ab )
!>
!>  donde d y e denotan los elementos diagonales y fuera de la diagonal de T, y vi
!>  denota un elemento del vector que define H(i).
!> .
