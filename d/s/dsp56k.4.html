dsp56k(4) Manual de Controladores de Dispositivos dsp56k(4)

NOMBRE

dsp56k - interfaz del dispositivo DSP56001

SINOPSIS

#include <asm/dsp56k.h>
ssize_t read(int fd, void *data, size_t length);
ssize_t write(int fd, void *data, size_t length);
int ioctl(int fd, DSP56K_UPLOAD, struct dsp56k_upload *program);
int ioctl(int fd, DSP56K_SET_TX_WSIZE, int wsize);
int ioctl(int fd, DSP56K_SET_RX_WSIZE, int wsize);
int ioctl(int fd, DSP56K_HOST_FLAGS, struct dsp56k_host_flags *flags);
int ioctl(int fd, DSP56K_HOST_CMD, int cmd);

CONFIGURACIÓN

El dispositivo dsp56k es un dispositivo de caracteres con número mayor 55 y número menor 0.

DESCRIPCIÓN

El Motorola DSP56001 es un procesador de señales digitales de 24 bits completamente programable que se encuentra en los ordenadores compatibles con Atari Falcon030. El archivo especial dsp56k se utiliza para controlar el DSP56001 y para enviar y recibir datos utilizando el puerto host bidireccional con handshake.

Para enviar un flujo de datos al procesador de señales, utilice write(2) al dispositivo y read(2) para recibir los datos procesados. Los datos pueden enviarse o recibirse en cantidades de 8, 16, 24 o 32 bits en el lado del host, pero siempre se verán como cantidades de 24 bits en el DSP56001.

Las siguientes llamadas ioctl(2) se utilizan para controlar el dispositivo dsp56k:

DSP56K_UPLOAD
reinicia el DSP56001 y carga un programa. El tercer argumento de ioctl(2) debe ser un puntero a una estructura struct dsp56k_upload con los miembros .bin apuntando a un programa binario del DSP56001 y .len establecido a la longitud del programa, contada en palabras de 24 bits.
DSP56K_SET_TX_WSIZE
establece el tamaño de palabra de transmisión. Los valores permitidos están en el rango de 1 a 4, y representan el número de bytes que se enviarán a la vez al DSP56001. Estas cantidades de datos se rellenarán con bytes que contienen cero o se truncarán para ajustarse al formato de datos nativo de 24 bits del DSP56001.
DSP56K_SET_RX_WSIZE
establece el tamaño de palabra de recepción. Los valores permitidos están en el rango de 1 a 4, y representan el número de bytes que se recibirán a la vez del DSP56001. Estas cantidades de datos se truncarán o se rellenarán con un byte nulo ('\0') para ajustarse al formato de datos nativo de 24 bits del DSP56001.
DSP56K_HOST_FLAGS
lee y escribe las banderas del host. Las banderas del host son cuatro bits de uso general que pueden ser leídos tanto por el ordenador anfitrión como por el DSP56001. Los bits 0 y 1 pueden ser escritos por el host, y los bits 2 y 3 pueden ser escritos por el DSP56001.
Para acceder a las banderas del host, el tercer argumento de ioctl(2) debe ser un puntero a una estructura struct dsp56k_host_flags. Si se establece un bit 0 o 1 en el miembro .dir, el bit correspondiente en .out se escribirá en las banderas del host. El estado de todas las banderas del host se devolverá en los cuatro bits inferiores del miembro .status.
DSP56K_HOST_CMD
envía un comando del host. Los valores permitidos están en el rango de 0 a 31, y es un comando definido por el usuario manejado por el programa que se ejecuta en el DSP56001.
