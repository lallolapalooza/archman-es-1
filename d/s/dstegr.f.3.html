DSTEGR

Propósito:

!>
!> DSTEGR calcula valores propios y, opcionalmente, vectores propios
!> seleccionados de una matriz tridiagonal simétrica real T. Cualquier matriz
!> no reducida de este tipo tiene un conjunto bien definido de valores propios
!> reales, distintos por pares, los vectores propios reales correspondientes son
!> ortogonales por pares.
!>
!> El espectro puede calcularse de forma completa o parcial especificando
!> un intervalo (VL,VU] o un rango de índices IL:IU para los valores propios
!> deseados.
!>
!> DSTEGR es un envoltorio de compatibilidad sobre la rutina mejorada DSTEMR.
!> Véase DSTEMR para más detalles.
!>
!> Un cambio importante es que el parámetro ABSTOL ya no proporciona ningún
!> beneficio y, por lo tanto, ya no se utiliza.
!>
!> Nota: DSTEGR y DSTEMR solo funcionan en máquinas que siguen el estándar
!> de punto flotante IEEE-754 en el manejo de infinitos y NaNs.
!> La ejecución normal puede crear estos valores excepcionales y, por lo tanto,
!> puede abortar debido a una excepción de punto flotante en entornos que
!> no se ajustan al estándar IEEE-754.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo se calculan los valores propios;
!>          = 'V':  Se calculan los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          En la entrada, los N elementos diagonales de la matriz tridiagonal
!>          T. En la salida, D se sobrescribe.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N)
!>          En la entrada, los (N-1) elementos subdiagonales de la matriz
!>          tridiagonal T en los elementos 1 a N-1 de E. E(N) no necesita
!>          estar establecido en la entrada, pero se usa internamente como espacio de trabajo.
!>          En la salida, E se sobrescribe.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo
!>          a buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo
!>          a buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          No se usa. Era la tolerancia de error absoluta para los
!>          valores propios/vectores propios en versiones anteriores.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array DOUBLE PRECISION, de dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz T
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>          Suministrar N columnas es siempre seguro.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es un array INTEGER, de dimensión ( 2*max(1,M) )
!>          El soporte de los vectores propios en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo vector propio calculado
!>          es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) a
!>          ISUPPZ( 2*i ). Esto es relevante en el caso en que la matriz
!>          se divide. ISUPPZ solo se accede cuando JOBZ es 'V' y N > 0.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo
!>          (y mínimo).
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,18*N)
!>          si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ninguna
!>          advertencia de error relacionada con LWORK es emitida por XERBLA.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (LIWORK)
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.  LIWORK >= max(1,10*N)
!>          si se desean los vectores propios, y LIWORK >= max(1,8*N)
!>          si solo se deben calcular los valores propios.
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          ninguna advertencia de error relacionada con LIWORK es emitida por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, INFO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = 1X, error interno en DLARRE,
!>                si INFO = 2X, error interno en DLARRV.
!>                Aquí, el dígito X = ABS( IINFO ) < 10, donde IINFO es
!>                el código de error distinto de cero devuelto por DLA
