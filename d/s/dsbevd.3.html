subrutina dsbevd (jobz, uplo, n, kd, ab, ldab, w, z, ldz, work, lwork, iwork, liwork, info)
DSBEVD calcula los eigenvalores y, opcionalmente, los autovectores izquierdos y/o derechos para matrices OTHER

Documentación de Función/Subrutin

a

subrutina dsbevd (character jobz, character uplo, integer n, integer kd, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

info)

DSBEVD calcula los eigenvalores y, opcionalmente, los autovectores izquierdos y/o derechos para matrices

OTHER

Propósito

: 
!>
!> DSBEVD calcula todos los eigenvalores y, opcionalmente, los autovectores de
!> una matriz simétrica real de banda A. Si se desean autovectores, se utiliza
!> un algoritmo de división y conquista.
!>
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores;
!>          = 'V':  Calcula los eigenvalores y autovectores.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

K

D 
!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!
>

A

B 
!>          AB es un array DOUBLE PRECISION, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          simétrica de banda A, almacenado en las primeras KD+1 filas
!>          del array.  La j-ésima columna de A se almacena en la j-ésima
!>          columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB es sobrescrito por valores generados durante
!>          la reducción a forma tridiagonal.  Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          dos primeras filas de AB.
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los
!>          autovectores ortonormales de la matriz A, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no es referenciado.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION,
!>                                         dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          SI N <= 1,                LWORK debe ser al menos 1.
!>          Si JOBZ  = 'N' y N > 2, LWORK debe ser al menos 2*N.
!>          Si JOBZ  = 'V' y N > 2, LWORK debe ser al menos
!>                         ( 1 + 5*N + 2*N**2 ).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de los
!>          arrays WORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'V' y N > 2, LIWORK debe ser al menos 3 + 5*N.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de los
!>          arrays WORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el algoritmo falló al converger; i
!>                elementos fuera de la diagonal de una forma tridiagonal
!>                intermedia no convergieron a cero.
!
>
