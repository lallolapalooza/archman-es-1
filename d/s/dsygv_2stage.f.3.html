Documentación de Función/Subrutin

a

subrutina dsygv_2stage (integer itype, character jobz, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) w, double precision, dimension( * ) work, integer lwork, integer

info)

DSYGV_2STAG

E

Propósito

: 
!>
!> DSYGV_2STAGE calcula todos los eigenvalores y, opcionalmente, los autovectores
!> de un problema de autovalores generalizado simétrico-definido real, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.
!> Aquí se asume que A y B son simétricas y que B es además
!> definida positiva.
!> Esta rutina utiliza la técnica de 2 etapas para la reducción a tridiagonal
!> que mostró un mayor rendimiento en arquitecturas recientes y para tamaños
!> grandes N>2000.
!
>

Parámetro

s
ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!
>

JOB

Z 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los eigenvalores;
!>          = 'V':  Calcular eigenvalores y autovectores.
!>                  No disponible en esta versión.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior principal N-by-N de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior principal N-by-N de A contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de autovectores.  Los autovectores se normalizan
!>          de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se destruye.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB, N)
!>          En la entrada, la matriz simétrica definida positiva B.
!>          Si UPLO = 'U', la parte triangular superior principal N-by-N de B
!>          contiene la parte triangular superior de la matriz B.
!>          Si UPLO = 'L', la parte triangular inferior principal N-by-N de B
!>          contiene la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz es
!>          sobrescrita por el factor triangular U o L de la factorización
!>          de Cholesky B = U**T*U o B = L*L**T.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = max(stage1,stage2) + (KD+1)*N + 2*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 2*N
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo usado por el algoritmo QR o LQ,
!>                                   usualmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos usados cuando
!>                                   la compilación con openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  DPOTRF o DSYEV devolvió un código de error:
!>             <= N:  si INFO = i, DSYEV falló en converger;
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon eigenvalores ni autovectores.
!
>
