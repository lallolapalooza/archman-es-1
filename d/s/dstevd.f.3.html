subrutina dstevd (jobz, n, d, e, z, ldz, work, lwork, iwork, liwork, info)
DSTEVD calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices OTRAS

Documentación de la función/subrutina

subrutina dstevd (character jobz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

DSTEVD calcula todos los valores propios y, opcionalmente, los vectores propios de una matriz tridiagonal simétrica real. Si se desean vectores propios, utiliza un algoritmo de división y conquista.

Propósito:

!>
!> DSTEVD calcula todos los valores propios y, opcionalmente, los vectores
!> propios de una matriz tridiagonal simétrica real. Si se desean vectores
!> propios, utiliza un algoritmo de división y conquista.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz
!>          tridiagonal A.
!>          En la salida, si INFO = 0, los valores propios en orden
!>          ascendente.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N-1)
!>          En la entrada, los (n-1) elementos subdiagonales de la matriz
!>          tridiagonal A, almacenados en los elementos 1 a N-1 de E.
!>          En la salida, el contenido de E se destruye.
!>

Z

!>          Z es un array DOUBLE PRECISION, de dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores
!>          propios ortonormales de la matriz A, con la i-ésima columna
!>          de Z conteniendo el vector propio asociado a D(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array DOUBLE PRECISION,
!>                                         de dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si JOBZ  = 'N' o N <= 1, LWORK debe ser al menos 1.
!>          Si JOBZ  = 'V' y N > 1, LWORK debe ser al menos
!>                         ( 1 + 4*N + N**2 ).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula los tamaños óptimos de los
!>          arrays WORK y IWORK, devuelve estos valores como las primeras
!>          entradas de los arrays WORK y IWORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK debe ser al menos 3+5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula los tamaños óptimos de los
!>          arrays WORK y IWORK, devuelve estos valores como las primeras
!>          entradas de los arrays WORK y IWORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor
!>                ilegal
!>          > 0:  si INFO = i, el algoritmo falló en converger; i
!>                elementos fuera de la diagonal de E no convergieron a
!>                cero.
!>
