NOMBRE

dssi_osc_update - envía una solicitud OSC `update' de DSSI

SINOPSIS

dssi_osc_update <URL_OSC>

DESCRIPCIÓN

dssi_osc_update envía una solicitud OSC `update' de DSSI a un host DSSI, luego espera respuestas OSC del host, escribe cualquier respuesta recibida en la salida estándar y sale cuando no ha recibido nada durante cinco segundos. Los hosts DSSI deben responder a una solicitud `update' enviando el estado completo del plugin; este programa se puede usar para recuperar y mostrar ese estado.

OPCIONES

<URL_OSC>
La URL que especifica el host y el plugin, al cual se envía la solicitud. Esto generalmente se obtiene del host, quizás de mensajes de inicio o del diálogo `Acerca de' del host. Por ejemplo:
osc.udp://localhost:19383/dssi/test.1
osc.udp://my.host.org:10886/dssi/xsynth-dssi/Xsynth/chan00

VER TAMBIÉN

dssi_osc_send(1).
