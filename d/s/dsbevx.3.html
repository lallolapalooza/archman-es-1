a

subrutina dsbevx (character jobz, character range, character uplo, integer n, integer kd, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldq, * ) q, integer ldq, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer

info)

DSBEVX calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices

OTHER

Propósito

: 
!>
!> DSBEVX calcula los eigenvalores seleccionados y, opcionalmente, los eigenvectores
!> de una matriz simétrica real de banda A. Los eigenvalores y eigenvectores pueden
!> seleccionarse especificando un rango de valores o un rango de
!> índices para los eigenvalores deseados.
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo eigenvalores;
!>          = 'V':  Calcular eigenvalores y eigenvectores.
!
>

RANG

E 
!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los eigenvalores;
!>          = 'V': se encontrarán todos los eigenvalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los eigenvalores desde el IL-ésimo hasta el IU-ésimo.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

K

D 
!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!
>

A

B 
!>          AB es un array DOUBLE PRECISION, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          simétrica de banda A, almacenado en las primeras KD+1 filas del array. La
!>          j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con los valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!
>

Q 
!>          Q es un array DOUBLE PRECISION, dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz ortogonal N-por-N utilizada en la
!>                         reducción a forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se referencia.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!
>

V

L 
!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo en el que
!>          se buscarán eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

V

U 
!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo en el que
!>          se buscarán eigenvalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

I

L 
!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más pequeño que se devolverá.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

I

U 
!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más grande que se devolverá.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

ABSTO

L 
!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los eigenvalores.
!>          Un eigenvalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los eigenvalores se calcularán con mayor precisión cuando ABSTOL
!>          se establezca al doble del umbral de desbordamiento inferior 2*DLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          eigenvectores no convergieron, intente establecer ABSTOL a
!>          2*DLAMCH('S').
!>
!>          Vea  de Demmel y
!>          Kahan, LAPACK Working Note #3.
!
>

M 
!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los eigenvalores seleccionados en
!>          orden ascendente.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los eigenvectores ortonormales de la matriz A
!>          correspondientes a los eigenvalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el eigenvector asociado con W(i).
!>          Si un eigenvector no converge, entonces esa columna de Z
!>          contiene la última aproximación al eigenvector, y el
!>          índice del eigenvector se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas en
!>          el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar una cota superior.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (7*N)
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (5*N)
!
>

IFAI

L 
!>          IFAIL es un array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene el
!>          iÍndices de los autovectores que no lograron converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, entonces i autovectores no lograron converger.
!>                Sus índices se almacenan en el array IFAIL.
!
>
