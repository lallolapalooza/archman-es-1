Documentación de Función/Subrutina

subrutina dsbev_2stage (character jobz, character uplo, integer n, integer kd, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer lwork, integer info)

DSBEV_2STAGE calcula los eigenvalores y, opcionalmente, los autovectores izquierdos y/o derechos para matrices OTHER

Propósito:

!>
!> DSBEV_2STAGE calcula todos los eigenvalores y, opcionalmente, los autovectores de
!> una matriz simétrica real banda A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores;
!>          = 'V':  Calcula los eigenvalores y autovectores.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array DOUBLE PRECISION, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          simétrica banda A, almacenado en las primeras KD+1 filas del array. La
!>          j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con los valores generados durante la
!>          reducción a forma tridiagonal.  Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los autovectores
!>          ortonormales de la matriz A, con la i-ésima columna de Z
!>          conteniendo el autovector asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión LWORK
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = (2KD+1)*N + KD*NTHREADS + N
!>                                   donde KD es el tamaño de la banda.
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación con openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el algoritmo falló en converger; i
!>                elementos fuera de la diagonal de una forma tridiagonal
!>                intermedia no convergieron a cero.
!>
