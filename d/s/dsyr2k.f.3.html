subrutina dsyr2k (uplo, trans, n, k, alpha, a, lda, b, ldb, beta, c, ldc)
DSYR2K

Documentación de Función/Subrutin

a

subrutina dsyr2k (character uplo, character trans, integer n, integer k, double precision alpha, double precision, dimension(lda,*) a, integer lda, double precision, dimension(ldb,*) b, integer ldb, double precision beta, double precision, dimension(ldc,*) c, integer

ldc)

DSYR2

K

Propósito

: 
!>
!> DSYR2K  realiza una de las operaciones simétricas de rango 2k
!>
!>    C := alpha*A*B**T + alpha*B*A**T + beta*C,
!>
!> o
!>
!>    C := alpha*A**T*B + alpha*B**T*A + beta*C,
!>
!> donde  alpha y beta  son escalares, C es una  matriz simétrica de
!> n por n  y  A y B  son  matrices  de  n por k  en el  primer  caso  y  k por n
!> matrices en el segundo caso.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada,   UPLO  especifica  si  la  parte  triangular  superior o inferior
!>           del  array  C  debe  ser  referenciada  como
!>           sigue:
!>
!>              UPLO = 'U' o 'u'   Solo la  parte triangular superior de  C
!>                                  debe ser referenciada.
!>
!>              UPLO = 'L' o 'l'   Solo la  parte triangular inferior de  C
!>                                  debe ser referenciada.
!
>

TRAN

S 
!>          TRANS es CHARACTER*1
!>           A la entrada,  TRANS  especifica la operación a realizar como
!>           sigue:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*B**T + alpha*B*A**T +
!>                                        beta*C.
!>
!>              TRANS = 'T' o 't'   C := alpha*A**T*B + alpha*B**T*A +
!>                                        beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**T*B + alpha*B**T*A +
!>                                        beta*C.
!
>

N 
!>          N es INTEGER
!>           A la entrada,  N especifica el orden de la matriz C.  N debe ser
!>           al menos cero.
!
>

K 
!>          K es INTEGER
!>           A la entrada con  TRANS = 'N' o 'n',  K  especifica  el número
!>           de  columnas  de las  matrices  A y B,  y a la  entrada  con
!>           TRANS = 'T' o 't' o 'C' o 'c',  K  especifica  el  número
!>           de filas de las matrices  A y B.  K debe ser al menos  cero.
!
>

ALPH

A 
!>          ALPHA es DOUBLE PRECISION.
!>           A la entrada, ALPHA especifica el escalar alpha.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con  TRANS = 'N' o 'n',  la  parte principal  n por k
!>           del array  A  debe contener la matriz  A,  de lo contrario
!>           la parte principal  k por n  del array  A  debe contener  la
!>           matriz A.
!
>

LD

A 
!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A como se declara
!>           en  el  programa  (sub)  que  llama.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDA debe ser al menos  max( 1, n ), de lo contrario  LDA debe
!>           ser al menos  max( 1, k ).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión ( LDB, kb ), donde kb es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con  TRANS = 'N' o 'n',  la  parte principal  n por k
!>           del array  B  debe contener la matriz  B,  de lo contrario
!>           la parte principal  k por n  del array  B  debe contener  la
!>           matriz B.
!
>

LD

B 
!>          LDB es INTEGER
!>           A la entrada, LDB especifica la primera dimensión de B como se declara
!>           en  el  programa  (sub)  que  llama.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDB debe ser al menos  max( 1, n ), de lo contrario  LDB debe
!>           ser al menos  max( 1, k ).
!
>

BET

A 
!>          BETA es DOUBLE PRECISION.
!>           A la entrada, BETA especifica el escalar beta.
!
>

C 
!>          C es un array DOUBLE PRECISION, dimensión ( LDC, N )
!>           Antes de la entrada  con  UPLO = 'U' o 'u',  la parte principal  n por n
!>           triangular superior del array C debe contener la parte
!>           triangular superior  de la  matriz simétrica  y la parte
!>           estrictamente  inferior de C no es referenciada.  A la salida, la
!>           parte triangular superior del array  C es sobrescrita por la
!>           parte triangular superior de la matriz actualizada.
!>           Antes de la entrada  con  UPLO = 'L' o 'l',  la parte principal  n por n
!>           triangular inferior del array C debe contener la parte
!>           triangular inferior  de la  matriz simétrica  y la parte
!>           estrictamente  superior de C no es referenciada.  A la salida, la
!>           parte triangular inferior del array  C es sobrescrita por la
!>           parte triangular inferior de la matriz actualizada.
!
>

LD

C 
!>          LDC es INTEGER
!>           A la entrada, LDC especifica la primera dimensión de C como se declara
!>           en  el  programa  (sub)  que  llama.   LDC  debe  ser  al  menos
!>           max( 1, n ).
!
>
