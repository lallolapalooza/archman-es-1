subrutina dsposv (uplo, n, nrhs, a, lda, b, ldb, x, ldx, work, swork, iter, info)
DSPOSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Documentación de Función/Subrutin

a

subrutina dsposv (character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( n, * ) work, real, dimension( * ) swork, integer iter, integer

info)

DSPOSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

PO

Propósito

: 
!>
!> DSPOSV calcula la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> DSPOSV primero intenta factorizar la matriz en PRECISIÓN SIMPLE
!> y usar esta factorización dentro de un procedimiento de refinamiento iterativo
!> para producir una solución con calidad de error hacia atrás de norma en
!> PRECISIÓN DOBLE (ver más abajo). Si el enfoque falla, el método cambia a una
!> factorización y resolución en PRECISIÓN DOBLE.
!>
!> El refinamiento iterativo no será una estrategia ganadora si
!> la relación entre el rendimiento en PRECISIÓN SIMPLE y el rendimiento en
!> PRECISIÓN DOBLE es demasiado pequeña. Una estrategia razonable debería tener en cuenta
!> el número de miembros libres y el tamaño de la matriz.
!> Esto podría hacerse con una llamada a ILAENV en el futuro. Hasta ahora, siempre
!> intentamos el refinamiento iterativo.
!>
!> El proceso de refinamiento iterativo se detiene si
!>     ITER > ITERMAX
!> o para todos los miembros libres tenemos:
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> donde
!>     o ITER es el número de la iteración actual en el proceso de
!>       refinamiento iterativo
!>     o RNRM es la norma infinita del residuo
!>     o XNRM es la norma infinita de la solución
!>     o ANRM es la norma de operador infinita de la matriz A
!>     o EPS es la épsilon de la máquina devuelta por DLAMCH('Epsilon')
!> El valor ITERMAX y BWDMAX están fijados en 30 y 1.0D+00
!> respectivamente.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de miembros libres, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION,
!>          dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          triangular superior principal de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior principal de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>          En la salida, si el refinamiento iterativo se ha utilizado
!>          con éxito (INFO = 0 y ITER >= 0, ver descripción más abajo), entonces A
!>          no ha cambiado; si se ha utilizado la factorización en precisión doble
!>          (INFO = 0 y ITER < 0, ver descripción más abajo), entonces el
!>          array A contiene el factor U o L de la factorización
!>          de Cholesky A = U**T*U o A = L*L**T.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          La matriz de miembros libres B de N por NRHS.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!
>

X 
!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si INFO = 0, la matriz de solución X de N por NRHS.
!
>

LD

X 
!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (N,NRHS)
!>          Este array se usa para contener los vectores residuales.
!
>

SWOR

K 
!>          SWORK es un array REAL, dimensión (N*(N+NRHS))
!>          Este array se usa para usar la matriz en precisión simple y los
!>          miembros libres o soluciones en precisión simple.
!
>

ITE

R 
!>          ITER es INTEGER
!>          < 0: el refinamiento iterativo ha fallado, se ha realizado la
!>               factorización en precisión doble
!>               -1 : la rutina volvió a la precisión completa por
!>                    razones específicas de la implementación o de la máquina
!>               -2 : la reducción de precisión provocó un desbordamiento,
!>                    la rutina volvió a la precisión completa
!>               -3 : fallo de SPOTRF
!>               -31: detener el refinamiento iterativo después de la 30ª
!>                    iteración
!>          > 0: el refinamiento iterativo se ha utilizado con éxito.
!>               Devuelve el número de iteraciones
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal de orden i
!>                de (DOUBLE PRECISION) A no es positivo, por lo que la
!>                factorización no pudo completarse, y la solución
!>                no ha sido calculada.
!
>
