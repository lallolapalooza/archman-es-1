DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina dsytrf_aa (character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, double precision, dimension( * ) work, integer lwork, integer info)

DSYTRF_AA

Propósito:

!>
!> DSYTRF_AA calcula la factorización de una matriz simétrica real A
!> utilizando el algoritmo de Aasen. La forma de la factorización es
!>
!>    A = U**T*T*U  o  A = L*T*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares unitarias
!> superiores (inferiores), y T es una matriz simétrica tridiagonal.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          superior triangular N-por-N de A contiene la parte triangular
!>          superior de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular N-por-N de A contiene la parte triangular
!>          inferior de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, la matriz tridiagonal se almacena en las diagonales
!>          y las subdiagonales de A justo debajo (o encima) de las diagonales,
!>          y L se almacena debajo (o encima) de las subdiagonales, cuando UPLO
!>          es 'L' (o 'U').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array de INTEGER, dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A fueron intercambiadas con la
!>          fila y columna IPIV(k).
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.
!>          LWORK >= 1, si N <= 1, y LWORK >= 2*N en caso contrario.
!>          Para un rendimiento óptimo LWORK >= N*(1+NB), donde NB es
!>          el tamaño de bloque óptimo, devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>
