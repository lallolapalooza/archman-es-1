Documentación de Función/Subrutina

subrutina dsygvx (integer itype, character jobz, character range, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

DSYGVX

Propósito:

!>
!> DSYGVX calcula autovalores seleccionados y, opcionalmente, autovectores
!> de un problema de autovalores generalizado simétrico-definido, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.  Aquí se asume que A
!> y B son simétricas y que B es también definida positiva.
!> Los autovalores y autovectores pueden seleccionarse especificando un
!> rango de valores o un rango de índices para los autovalores deseados.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo autovalores;
!>          = 'V':  Calcular autovalores y autovectores.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden del lápiz matricial (A,B).  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior de A de tamaño N por N inicial contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior de A de tamaño N por N inicial contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB, N)
!>          En la entrada, la matriz simétrica B.  Si UPLO = 'U', la
!>          parte triangular superior de B de tamaño N por N inicial contiene la
!>          parte triangular superior de la matriz B.  Si UPLO = 'L',
!>          la parte triangular inferior de B de tamaño N por N inicial contiene
!>          la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz es
!>          sobrescrita por el factor triangular U o L de la factorización
!>          Cholesky B = U**T*U o B = L*L**T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo donde
!>          se buscarán los autovalores.  VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo donde
!>          se buscarán los autovalores.  VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los autovalores.
!>          Un autovalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual que cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir C a forma tridiagonal, donde C es la matriz
!>          simétrica del problema simétrico estándar al que se transforma
!>          el problema generalizado.
!>
!>          Los autovalores se calcularán con mayor precisión cuando ABSTOL se
!>          establezca al doble del umbral de desbordamiento inferior 2*DLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          autovectores no convergieron, intente establecer ABSTOL a
!>          2*DLAMCH('S').
!>

M

!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          En la salida normal, los primeros M elementos contienen los
!>          autovalores seleccionados en orden ascendente.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz A
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Los autovectores se normalizan como sigue:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un autovector no converge, entonces esa columna de Z
!>          contiene la última aproximación al autovector, y el
!>          índice del autovector se devuelve en IFAIL.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar una cota superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del arreglo WORK.  LWORK >= max(1,8*N).
!>          Para una eficiencia óptima, LWORK >= (NB+3)*N,
!>          donde NB es el tamaño de bloque para DSYTRD devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite ningún error
!>          relacionado con LWORK por parte de XERBLA.
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (5*N)
!>

IFAIL

!>          IFAIL es un arreglo INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los autovectores que no convergieron.
!>          Si JOBZ = 'N', entonces IFAIL no es referenciado.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  DPOTRF o DSYEVX devolvió un código de error:
!>             <= N:  si INFO = i, DSYEVX falló en converger;
!>                    i autovectores no convergieron.  Sus índices
!>                    están almacenados en el arreglo IFAIL.
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon autovalores ni autovectores.
!>
