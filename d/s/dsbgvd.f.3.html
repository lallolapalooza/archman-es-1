DSBGV

D

Propósito

: 
!>
!> DSBGVD calcula todos los eigenvalores y, opcionalmente, los eigenvectores
!> de un problema de eigenvalores generalizado simétrico-definido positivo en banda,
!> de la forma A*x=(lambda)*B*x. Aquí se supone que A y B son simétricas y
!> en banda, y que B es además definida positiva. Si se desean eigenvectores,
!> se utiliza un algoritmo de divide y vencerás.
!>
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores;
!>          = 'V':  Calcula los eigenvalores y los eigenvectores.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

K

A 
!>          KA es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KA >= 0.
!
>

K

B 
!>          KB es INTEGER
!>          El número de superdiagonales de la matriz B si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KB >= 0.
!
>

A

B 
!>          AB es un array DOUBLE PRECISION, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          simétrica en banda A, almacenado en las primeras ka+1 filas del array.
!>          La j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) para max(1,j-ka)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+ka).
!>
!>          En la salida, el contenido de AB queda destruido.
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KA+1.
!
>

B

B 
!>          BB es un array DOUBLE PRECISION, dimensión (LDBB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          simétrica en banda B, almacenado en las primeras kb+1 filas del array.
!>          La j-ésima columna de B se almacena en la j-ésima columna del array BB
!>          de la siguiente manera:
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) para max(1,j-kb)<=i<=j;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) para j<=i<=min(n,j+kb).
!>
!>          En la salida, el factor S de la factorización de Cholesky dividida
!>          B = S**T*S, tal como lo devuelve DPBSTF.
!
>

LDB

B 
!>          LDBB es INTEGER
!>          La dimensión principal del array BB.  LDBB >= KB+1.
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          eigenvectores, con la i-ésima columna de Z conteniendo el
!>          eigenvector asociado con W(i). Los eigenvectores están
!>          normalizados de modo que Z**T*B*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LWORK >= 2*N.
!>          Si JOBZ = 'V' y N > 1, LWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK e IWORK,
!>          devuelve estos valores como las primeras entradas de los arrays
!>          WORK e IWORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK o LIWORK.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si LIWORK > 0, IWORK(1) devuelve el LIWORK óptimo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LIWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es:
!>             <= N:  el algoritmo no logró converger:
!>                    i elementos fuera de la diagonal de una forma
!>                    tridiagonal intermedia no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces DPBSTF
!>                    devolvió INFO = i: B no es definida positiva.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon eigenvalores ni eigenvectores.
!
>
