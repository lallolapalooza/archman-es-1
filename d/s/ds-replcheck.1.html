NOMBRE

ds-replcheck

SINOPSIS

ds-replcheck [-h] [-v] {online,offline,state} ...

DESCRIPCIÓN

Herramienta de comparación de replicación (v2.0). Este script se puede utilizar para
comparar dos réplicas para ver si están sincronizadas.

OPCIONES

Subcomandos

ds-replcheck online
Compara dos réplicas en línea para encontrar diferencias
ds-replcheck offline
Compara dos archivos LDIF de replicación para encontrar diferencias (archivo LDIF generado por 'db2ldif -r')
ds-replcheck state
Obtiene el estado general de la replicación entre dos réplicas

OPCIONES 'ds-replcheck state'

uso: ds-replcheck online [-h] -m URL -r URL -b SUFFIX -D BINDDN
[-w BINDPW] [-W] [-y PASS_FILE] [-Z CERTDIR]

-m URL, --supplier-url URL
La URL LDAP del servidor proveedor
-r URL, --replica-url URL
La URL LDAP del servidor réplica
-b SUFFIX, --suffix SUFFIX
Sufijo replicado
-D BINDDN, --bind-dn BINDDN
El DN de enlace
-w BINDPW, --bind-pw BINDPW
La contraseña de enlace
-W, --prompt
Solicita la contraseña del DN de enlace
-y PASS_FILE, --pass-file PASS_FILE
Un archivo de texto que contiene la contraseña en texto plano para el dn de enlace
-Z CERTDIR, --cert-dir CERTDIR
El directorio de la base de datos de certificados para conexiones seguras

OPCIONES 'ds-replcheck online'

uso: ds-replcheck online [-h] -m URL -r URL --rid RID -b SUFFIX -D BINDDN
[-w BINDPW] [-W] [-y PASS_FILE] [-l LAG] [-c]
[-Z CERTDIR] [-i IGNORE] [-p PAGESIZE] [-o FILE]

-m URL, --supplier-url MRL
La URL LDAP del servidor proveedor
-r URL, --replica-url URL
La URL LDAP del servidor réplica
-b SUFFIX, --suffix SUFFIX
Sufijo replicado
-D BINDDN, --bind-dn BINDDN
El DN de enlace
-w BINDPW, --bind-pw BINDPW
La contraseña de enlace
-W, --prompt
Solicita la contraseña del DN de enlace
-y PASS_FILE, --pass-file PASS_FILE
Un archivo de texto que contiene la contraseña en texto plano para el dn de enlace
-l LAG, --lag-time LAG
La cantidad de tiempo para ignorar inconsistencias (por defecto 300 segundos)
-c, --conflicts
Muestra información detallada de las entradas en conflicto
-Z CERTDIR, --cert-dir CERTDIR
El directorio de la base de datos de certificados para conexiones seguras
-i IGNORE, --ignore IGNORE
Lista de atributos a ignorar separados por comas
-p PAGESIZE, --page-size PAGESIZE
El tamaño de agrupación de resultados de búsqueda paginada (por defecto 500 entradas)
-o FILE, --out-file FILE
El archivo de salida

OPCIONES 'ds-replcheck offline'

uso: ds-replcheck offline [-h] -m LDIF_FILE -r LDIF_FILE --rid RID -b SUFFIX [-c]
[-i IGNORE] [-o FILE]

-m LDIF_FILE, --supplier-ldif LDIF_FILE
Archivo LDIF del proveedor
-r LDIF_FILE, --replica-ldif LDIF_FILE
Archivo LDIF de la réplica
--rid RID
El identificador de réplica (rid) para el servidor "proveedor"
-b SUFFIX, --suffix SUFFIX
Sufijo replicado
-c, --conflicts
Muestra información detallada de las entradas en conflicto
-i IGNORE, --ignore IGNORE
Lista de atributos a ignorar separados por comas
-o FILE, --out-file FILE
El archivo de salida
-v, --verbose
Salida detallada
