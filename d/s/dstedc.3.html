subrutina dstedc (compz, n, d, e, z, ldz, work, lwork, iwork, liwork, info)
DSTEDC

Documentación de Función/Subrutin

a

subrutina dstedc (character compz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer

info)

DSTED

C

Propósito

: 
!>
!> DSTEDC calcula todos los eigenvalores y, opcionalmente, los eigenvectores de una
!> matriz simétrica tridiagonal utilizando el método de divide y vencerás.
!> Los eigenvectores de una matriz simétrica real completa o de banda también pueden ser
!> encontrados si DSYTRD o DSPTRD o DSBTRD ha sido utilizado para reducir esta
!> matriz a forma tridiagonal.
!>
!
>

Parámetro

s
COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores.
!>          = 'I':  Calcula también los eigenvectores de la matriz tridiagonal.
!>          = 'V':  Calcula también los eigenvectores de la matriz simétrica densa
!>                  original.  Al entrar, Z contiene la matriz ortogonal
!>                  utilizada para reducir la matriz original a
!>                  forma tridiagonal.
!
>

N 
!>          N es INTEGER
!>          La dimensión de la matriz simétrica tridiagonal.  N >= 0.
!
>

D 
!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Al entrar, los elementos diagonales de la matriz tridiagonal.
!>          Al salir, si INFO = 0, los eigenvalores en orden ascendente.
!
>

E 
!>          E es un array DOUBLE PRECISION, dimensión (N-1)
!>          Al entrar, los elementos subdiagonales de la matriz tridiagonal.
!>          Al salir, E ha sido destruido.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDZ,N)
!>          Al entrar, si COMPZ = 'V', entonces Z contiene la matriz ortogonal
!>          utilizada en la reducción a forma tridiagonal.
!>          Al salir, si INFO = 0, entonces si COMPZ = 'V', Z contiene los
!>          eigenvectores ortonormales de la matriz simétrica original,
!>          y si COMPZ = 'I', Z contiene los eigenvectores ortonormales
!>          de la matriz simétrica tridiagonal.
!>          Si  COMPZ = 'N', entonces Z no es referenciado.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1.
!>          Si se desean eigenvectores, entonces LDZ >= max(1,N).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si COMPZ = 'N' o N <= 1 entonces LWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1 entonces LWORK debe ser al menos
!>                         ( 1 + 3*N + 2*N*lg N + 4*N**2 ),
!>                         donde lg( N ) = el entero más pequeño k tal
!>                         que 2**k >= N.
!>          Si COMPZ = 'I' y N > 1 entonces LWORK debe ser al menos
!>                         ( 1 + 4*N + N**2 ).
!>          Nótese que para COMPZ = 'I' o 'V', entonces si N es menor o
!>          igual al tamaño mínimo de división, usualmente 25, entonces LWORK
!>          solo necesita ser max(1,2*(N-1)).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún
!>          mensaje de error relacionado con LWORK por XERBLA.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          Al salir, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si COMPZ = 'N' o N <= 1 entonces LIWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1 entonces LIWORK debe ser al menos
!>                         ( 6 + 6*N + 5*N*lg N ).
!>          Si COMPZ = 'I' y N > 1 entonces LIWORK debe ser al menos
!>                         ( 3 + 5*N ).
!>          Nótese que para COMPZ = 'I' o 'V', entonces si N es menor o
!>          igual al tamaño mínimo de división, usualmente 25, entonces LIWORK
!>          solo necesita ser 1.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          no se emite ningún mensaje de error relacionado con LIWORK por XERBLA.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo falló al calcular un eigenvalor mientras
!>                trabajaba en la submatriz que se encuentra en las filas y columnas
!>                INFO/(N+1) a mod(INFO,N+1).
!
>
