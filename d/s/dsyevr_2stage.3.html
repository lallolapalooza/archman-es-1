DSYEVR_2STAGE calcula los autovalores y, opcionalmente, los autovectores izquierdos y/o derechos para matrices

SY

Propósito

: 
!>
!> DSYEVR_2STAGE calcula autovalores seleccionados y, opcionalmente, autovectores
!> de una matriz simétrica real A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Los autovalores y autovectores pueden ser
!> seleccionados especificando un rango de valores o un rango de
!> índices para los autovalores deseados.
!>
!> DSYEVR_2STAGE primero reduce la matriz A a forma tridiagonal T con una llamada
!> a DSYTRD. Luego, siempre que sea posible, DSYEVR_2STAGE llama a DSTEMR para calcular
!> el espectro propio utilizando Representaciones Robustas Relativamente. DSTEMR
!> calcula autovalores mediante el algoritmo dqds, mientras que los
!> autovectores ortogonales se calculan a partir de varias representaciones L D L^T
!> (también conocidas como Representaciones Robustas Relativamente). La ortogonalización
!> de Gram-Schmidt se evita en la medida de lo posible. Más específicamente,
!> los varios pasos del algoritmo son los siguientes.
!>
!> Para cada bloque (submatriz) no reducido de T,
!>    (a) Calcular T - sigma I  = L D L^T, de modo que L y D
!>        definan todos los autovalores deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los autovalores y
!>        autovectores. La representación estándar (sin factorizar) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los autovalores con la precisión adecuada.
!>        Si se desean los autovectores, el algoritmo alcanza la precisión
!>        completa de los autovalores calculados solo justo antes de
!>        que se deban calcular los vectores correspondientes, ver los pasos c) y d).
!>    (c) Para cada grupo de autovalores cercanos, seleccionar un nuevo
!>        desplazamiento cercano al grupo, encontrar una nueva factorización y refinar
!>        los autovalores desplazados a la precisión adecuada.
!>    (d) Para cada autovalor con una separación relativa suficientemente grande, calcular
!>        el autovector correspondiente formando una factorización torcida
!>        que revela el rango. Volver a (c) para cualquier grupo que permanezca.
!>
!> La precisión deseada de la salida puede ser especificada por el parámetro
!> de entrada ABSTOL.
!>
!> Para más detalles, ver la documentación de DSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, Agosto 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, Mayo 1997.
!>
!>
!> Nota 1 : DSYEVR_2STAGE llama a DSTEMR cuando se solicita el espectro completo
!> en máquinas que se conforman al estándar de punto flotante ieee-754.
!> DSYEVR_2STAGE llama a DSTEBZ y SSTEIN en máquinas no-ieee y
!> cuando se hacen solicitudes de espectro parcial.
!>
!> La ejecución normal de DSTEMR puede crear NaNs e infinitos y
!> por lo tanto puede abortarse debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos de la manera predeterminada del estándar ieee.
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo autovalores;
!>          = 'V':  Calcular autovalores y autovectores.
!>                  No disponible en esta versión.
!
>

RANG

E 
!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta el IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman a DSTEBZ y
!>          DSTEIN
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N inicial de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N-por-N inicial de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

V

L 
!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

V

U 
!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

I

L 
!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

I

U 
!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          autovalor más grande a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

ABSTO

L 
!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los autovalores.
!>          Un autovalor aproximado es aceptado como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la 1-norma de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si la alta precisión relativa es importante, establezca ABSTOL a
!>          DLAMCH( 'Safe minimum' ).  Hacer esto garantizará que
!>          los autovalores se calculen con alta precisión relativa cuando
!>          sea posible en versiones futuras.  El código actual no
!>          hace ninguna garantía sobre alta precisión relativa, pero
!>          las versiones futuras sí lo harán. Véase J. Barlow y J. Demmel,
!>          , LAPACK Working Note #7, para una discusión
!>          de qué matrices definen sus eigenvalores con alta precisión
!>          relativa.
!
>

M 
!>          M es INTEGER
!>          El número total de eigenvalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los eigenvalores seleccionados en
!>          orden ascendente.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz A
!>          correspondientes a los eigenvalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no es referenciado.
!>          Nota: el usuario debe asegurarse de que se proporcionen al menos max(1,M) columnas en
!>          el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar una cota superior.
!>          Proporcionar N columnas siempre es seguro.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

ISUPP

Z 
!>          ISUPPZ es un array INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los autovectores en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo autovector
!>          es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) a través de
!>          ISUPPZ( 2*i ). Esto es una salida de DSTEMR (matriz
!>          tridiagonal). El soporte de los autovectores de A es típicamente
!>          1:N debido a las transformaciones ortogonales aplicadas por DORMTR.
!>          Implementado solo para RANGE = 'A' o 'I' y IU - IL = N - 1
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, 26*N, dimensión) donde
!>                                   dimensión = max(etapa1,etapa2) + (KD+1)*N + 5*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 5*N
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo usado por el algoritmo QR o LQ,
!>                                   usualmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos usados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          Al salir, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1, LIWORK >= 1, de lo contrario LIWORK >= 10*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          no se emite ningún mensaje de error relacionado con LIWORK por parte de XERBLA.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  Error interno
!
>
