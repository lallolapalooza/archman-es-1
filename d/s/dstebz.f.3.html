Documentación de Función/Subrutina

subroutine dstebz (character range, character order, integer n, double precision vl, double precision vu, integer il, integer iu, double precision abstol, double precision, dimension( * ) d, double precision, dimension( * ) e, integer m, integer nsplit, double precision, dimension( * ) w, integer, dimension( * ) iblock, integer, dimension( * ) isplit, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DSTEBZ

Propósito:

!>
!> DSTEBZ calcula los valores propios de una matriz tridiagonal simétrica
!> T. El usuario puede solicitar todos los valores propios, todos los valores propios
!> en el intervalo semiabierto (VL, VU], o los valores propios IL-ésimo a IU-ésimo.
!>
!> Para evitar desbordamiento, la matriz debe ser escalada de tal manera que su
!> elemento más grande no exceda overflow**(1/2) * underflow**(1/4) en valor absoluto, y para mayor
!> precisión, no debe ser mucho menor que eso.
!>
!> Ver W. Kahan, Report CS41, Departamento de Ciencias de la Computación, Universidad de Stanford, 21 de julio de 1966.
!>

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el intervalo
!>                           semiabierto (VL, VU].
!>          = 'I': () se encontrarán los valores propios IL-ésimo a IU-ésimo (de
!>                           la matriz completa).
!>

ORDER

!>          ORDER es CHARACTER*1
!>          = 'B': () los valores propios se agruparán por
!>                              bloque de separación (ver IBLOCK, ISPLIT) y
!>                              se ordenarán de menor a mayor dentro del
!>                              bloque.
!>          = 'E': ()
!>                              los valores propios de la matriz completa
!>                              se ordenarán de menor a mayor.
!>

N

!>          N es INTEGER
!>          El orden de la matriz tridiagonal T. N >= 0.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          explorar para encontrar valores propios. Los valores propios menores o iguales
!>          a VL, o mayores que VU, no serán devueltos. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          explorar para encontrar valores propios. Los valores propios menores o iguales
!>          a VL, o mayores que VU, no serán devueltos. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia absoluta para los valores propios. Un valor propio
!>          (o un clúster) se considera ubicado si se ha determinado que se encuentra
!>          en un intervalo cuyo ancho es ABSTOL o
!>          menor. Si ABSTOL es menor o igual a cero, se usará ULP*|T|,
!>          donde |T| significa la norma 1 de T.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no en cero.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N-1)
!>          Los n-1 elementos fuera de la diagonal de la matriz tridiagonal T.
!>

M

!>          M es INTEGER
!>          El número real de valores propios encontrados. 0 <= M <= N.
!>          (Ver también la descripción de INFO=2,3.)
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques diagonales en la matriz T.
!>          1 <= NSPLIT <= N.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          A la salida, los primeros M elementos de W contendrán los
!>          valores propios. (DSTEBZ puede usar los N-M elementos restantes como
!>          espacio de trabajo.)
!>

IBLOCK

!>          IBLOCK es un array INTEGER, de dimensión (N)
!>          En cada fila/columna j donde E(j) es cero o pequeño, la
!>          matriz T se considera dividida en una matriz diagonal por bloques.
!>          A la salida, si INFO = 0, IBLOCK(i) especifica a qué
!>          bloque (de 1 al número de bloques) pertenece el valor propio W(i).
!>          (DSTEBZ puede usar los N-M elementos restantes como
!>          espacio de trabajo.)
!>

ISPLIT

!>          ISPLIT es un array INTEGER, de dimensión (N)
!>          Los puntos de división, en los que T se divide en submatrices.
!>          La primera submatriz consta de las filas/columnas 1 a ISPLIT(1),
!>          la segunda de las filas/columnas ISPLIT(1)+1 a ISPLIT(2),
!>          etc., y la NSPLIT-ésima consta de las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 a ISPLIT(NSPLIT)=N.
!>          (Solo los primeros NSPLIT elementos se usarán realmente, pero
!>          como el usuario no puede saber de antemano qué valor tendrá NSPLIT,
!>          se deben reservar N palabras para ISPLIT.)
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (4*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  algunos o todos los valores propios no convergieron o
!>                no fueron calculados:
!>                =1 o 3: La bisección falló en converger para algunos
!>                        valores propios; estos valores propios están marcados con un
!>                        número de bloque negativo. El efecto es que los
!>                        valores propios pueden no ser tan precisos como las
!>                        tolerancias absoluta y relativa. Esto generalmente es causado por una aritmética
!>                        inesperadamente imprecisa.
!>                =2 o 3: Solo RANGE='I': No se encontraron todos los valores propios
!>                        IL:IU.
!>                        Efecto: M < IU+1-IL
!>                        Causa:  aritmética no monótona, que causa que la
!>                                secuencia de Sturm no sea monótona.
!>                        Solución: recalcular, usando RANGE='A', y seleccionar
!>                                los valores propios IL:IU. En algunos casos,
!!                                aumentar el PARAMETER puede
!>                                hacer que funcione.
!>                = 4:    RANGE='I', y el intervalo de Gershgorin
!>                        inicialmente usado fue demasiado pequeño. No se
!>                        encontraron valores propios.

!>          debería ser lo suficientemente grande para manejar la peor
!>          máquina que exista. Tenga en cuenta que esto no tiene
!>          efecto en la precisión de la solución.
