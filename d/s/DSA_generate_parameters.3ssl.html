DSA_generate_parameters(3ssl)

Paquete: openssl

Licencias: Apache-2.0

DSA_GENERATE_PARAMETERS(3ssl) OpenSSL DSA_GENERATE_PARAMETERS(3ssl)

NOMBRE

DSA_generate_parameters_ex, DSA_generate_parameters - generar parámetros DSA

SINOPSIS

#include <openssl/dsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0 y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int DSA_generate_parameters_ex(DSA *dsa, int bits,
                               const unsigned char *seed, int seed_len,
                               int *counter_ret, unsigned long *h_ret,
                               BN_GENCB *cb);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 0.9.8 y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

DSA *DSA_generate_parameters(int bits, unsigned char *seed, int seed_len,
                             int *counter_ret, unsigned long *h_ret,
                             void (*callback)(int, int, void *), void *cb_arg);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_paramgen_init(3) y EVP_PKEY_keygen(3) como se describe en EVP_PKEY-DSA(7).

DSA_generate_parameters_ex() genera los primos p y q y un generador g para su uso en DSA y almacena el resultado en dsa.

bits es la longitud del primo p a generar. Para longitudes inferiores a 2048 bits, la longitud de q es de 160 bits; para longitudes mayores o iguales a 2048 bits, la longitud de q se establece en 256 bits.

Si seed es NULL, los primos se generarán aleatoriamente. Si seed_len es menor que la longitud de q, se devuelve un error.

DSA_generate_parameters_ex() coloca el contador de iteraciones en *counter_ret y un contador utilizado para encontrar un generador en *h_ret, a menos que estos sean NULL.

Se puede usar una función de devolución de llamada para proporcionar información sobre el progreso de la generación de claves. Si cb no es NULL, se llamará como se muestra a continuación. Para obtener información sobre la estructura BN_GENCB y la función BN_GENCB_call mencionadas a continuación, consulte BN_generate_prime(3).

DSA_generate_parameters() es similar a DSA_generate_parameters_ex() pero espera una función de devolución de llamada de estilo antiguo; ver BN_generate_prime(3) para obtener información sobre la devolución de llamada de estilo antiguo.

  • Cuando se genera un candidato para q, se llama a BN_GENCB_call(cb, 0, m++) (m es 0 para el primer candidato).
  • Cuando un candidato para q ha pasado una prueba por división de prueba, se llama a BN_GENCB_call(cb, 1, -1). Mientras un candidato para q se prueba mediante pruebas de primalidad de Miller-Rabin, se llama a BN_GENCB_call(cb, 1, i) en el bucle externo (una vez por cada testigo que confirma que el candidato puede ser primo); i es el contador del bucle (comenzando en 0).
  • Cuando se ha encontrado un primo q, se llaman a BN_GENCB_call(cb, 2, 0) y BN_GENCB_call(cb, 3, 0).
  • Antes de generar y probar un candidato para p (distinto del primero), se llama a BN_GENCB_call(cb, 0, counter).
  • Cuando un candidato para p ha pasado la prueba por división de prueba, se llama a BN_GENCB_call(cb, 1, -1). Mientras se prueba mediante la prueba de primalidad de Miller-Rabin, se llama a BN_GENCB_call(cb, 1, i) en el bucle externo (una vez por cada testigo que confirma que el candidato puede ser primo). i es el contador del bucle (comenzando en 0).
  • Cuando se encuentra p, se llama a BN_GENCB_call(cb, 2, 1).
  • Cuando se encuentra el generador, se llama a BN_GENCB_call(cb, 3, 1).

VALORES DE RETORNO

DSA_generate_parameters_ex() devuelve 1 en caso de éxito o 0 en caso contrario. Los códigos de error se pueden obtener mediante ERR_get_error(3).

DSA_generate_parameters() devuelve un puntero a la estructura DSA o NULL si falla la generación de parámetros.

ERRORES

No se admiten longitudes de semilla superiores a 20.

VER TAMBIÉN

DSA_new(3), ERR_get_error(3), RAND_bytes(3), DSA_free(3), BN_generate_prime(3)

HISTORIA

DSA_generate_parameters_ex() fue obsoleto en OpenSSL 3.0.

DSA_generate_parameters() fue obsoleto en OpenSSL 0.9.8; use DSA_generate_parameters_ex() en su lugar.
