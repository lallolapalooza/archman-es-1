DSA_size(3ssl)

Paquete: openssl

Licencias: Apache-2.0

DSA_SIZE(3ssl) OpenSSL DSA_SIZE(3ssl)

NOMBRE

DSA_size, DSA_bits, DSA_security_bits - obtener el tamaño de la firma DSA, bits de clave o bits de seguridad

SINOPSIS

#include <openssl/dsa.h>

Las siguientes funciones han sido obsoletas desde OpenSSL 3.0, y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int DSA_bits(const DSA *dsa);
int DSA_size(const DSA *dsa);
int DSA_security_bits(const DSA *dsa);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_get_bits(3), EVP_PKEY_get_security_bits(3) y EVP_PKEY_get_size(3).

DSA_bits() devuelve el número de bits en la clave dsa: este es el número de bits en el parámetro p.

DSA_size() devuelve el tamaño máximo de una firma DSA codificada en ASN.1 para la clave dsa en bytes. Puede usarse para determinar cuánta memoria debe asignarse para una firma DSA.

DSA_security_bits() devuelve el número de bits de seguridad de la clave dsa dada. Ver BN_security_bits(3).

VALORES DEVUELTOS

DSA_security_bits() devuelve el número de bits de seguridad en la clave, o -1 si dsa no contiene ningún parámetro de clave.

DSA_bits() devuelve el número de bits en la clave, o -1 si dsa no contiene ningún parámetro de clave.

DSA_size() devuelve el tamaño de la firma en bytes, o -1 si dsa no contiene ningún parámetro de clave.

VER TAMBIÉN

EVP_PKEY_get_bits(3), EVP_PKEY_get_security_bits(3), EVP_PKEY_get_size(3), DSA_new(3), DSA_sign(3)

HISTORIA

Todas estas funciones fueron obsoletas en OpenSSL 3.0.
