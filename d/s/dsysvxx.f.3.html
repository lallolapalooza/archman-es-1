Documentación de Función/Subrutina

subroutine dsysvxx (character fact, character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) s, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DSYSVXX

Propósito:

!>
!>    DSYSVXX utiliza la factorización de pivoteo diagonal para calcular la
!>    solución de un sistema de ecuaciones lineales de doble precisión A * X = B,
!>    donde A es una matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normativos como
!>    componentes máximos. DSYSVXX devolverá una solución con un error garantizado
!>    pequeño (O(eps) donde eps es la precisión de la máquina de trabajo) a
!>    menos que la matriz esté muy mal condicionada, en cuyo caso se devuelve
!>    una advertencia. También se calculan y devuelven los números de condición
!>    relevantes.
!>
!>    DSYSVXX acepta factorizaciones y factores de equilibrado proporcionados por
!>    el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada anterior
!>    a DSYSVXX también producirá una solución con errores O(eps) o advertencias,
!>    pero no podemos hacer esa afirmación para factorizaciones y factores de
!>    equilibrado proporcionados por el usuario en general si difieren de lo
!>    que DSYSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para
!>    equilibrar el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibrará o no depende del escalado de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con diag(S)*A*diag(S)
!>    y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    unitaria superior (inferior), y D es simétrica y diagonal por bloques con
!>    bloques diagonales de 1x1 y 2x2.
!>
!>    3. Si algún D(i,i)=0, por lo que D es exactamente singular, entonces la
!>    subrutina retorna con INFO = i. De lo contrario, la forma factorizada de A
!>    se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la inversa del número de condición es menor que la
!>    precisión de la máquina, la subrutina aún continúa para resolver X y
!>    calcular los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará el refinamiento iterativo para intentar obtener un
!>    error pequeño y límites de error. El refinamiento calcula el residuo con
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por diag(R)
!>    para que resuelva el sistema original antes del equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables. Si los valores predeterminados son
!>     aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que el
!>     código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona en la
!>     entrada, y si no, si la matriz A debe equilibrarse antes de factorizarse.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido equilibrada
!>               con los factores de escala dados por S.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A se almacena;
!>       = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>     La matriz simétrica A. Si UPLO = 'U', la parte superior
!>     triangular N por N de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente triangular inferior
!>     de A no se referencia. Si UPLO = 'L', la parte inferior
!>     triangular N por N de A contiene la parte triangular inferior
!>     de la matriz A, y la parte estrictamente triangular superior
!>     de A no se referencia.
!>
!>     A la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array DOUBLE PRECISION, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene la matriz diagonal por bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T tal como fue calculada por DSYTRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y a la salida
!>     devuelve la matriz diagonal por bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene detalles de los intercambios y la estructura de bloques de D,
!>     tal como fue determinada por DSYTRF. Si IPIV(k) > 0, entonces las filas y
!>     columnas k e
IPIV(k) fueron intercambiadas y !> D(k,k) es un bloque diagonal de tamaño 1 por 1. Si UPLO = 'U' y !> IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas k-1 y !> -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k) es un bloque !> diagonal de tamaño 2 por 2. Si UPLO = 'L' y IPIV(k) = IPIV(k+1) < 0, !> entonces las filas y columnas k+1 y -IPIV(k) fueron intercambiadas !> y D(k:k+1,k:k+1) es un bloque diagonal de tamaño 2 por 2. !> !> Si FACT = 'N', entonces IPIV es un argumento de salida y al salir !> contiene detalles de los intercambios y la estructura de bloques !> de D, tal como lo determina DSYTRF. !>

EQUED

!>          EQUED es de tipo CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre cierto si FACT = 'N').
!>       = 'Y':  Equilibrado tanto por filas como por columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

S

!>          S es un arreglo de tipo DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala para A.  Si EQUED = 'Y', A se multiplica por
!>     diag(S) a la izquierda y a la derecha.  S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida.  Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo.  Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
!>     de S debe ser una potencia de la base para garantizar una solución
!>     fiable y estimaciones de error. El escalado por potencias de la base no causa
!>     errores de redondeo a menos que el resultado desborde por arriba o por abajo.
!>     Los errores de redondeo durante el escalado conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

B

!>          B es un arreglo de tipo DOUBLE PRECISION, de dimensión (LDB,NRHS)
!>     En la entrada, la matriz de término independiente B de tamaño N por NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe con diag(S)*B;
!>

LDB

!>          LDB es de tipo INTEGER
!>     La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

X

!>          X es un arreglo de tipo DOUBLE PRECISION, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz de solución X de tamaño N por NRHS al sistema
!>     de ecuaciones original.  Tenga en cuenta que A y B se modifican al salir si
!>     EQUED .ne. 'N', y la solución al sistema equilibrado es
!>     inv(diag(S))*X.
!>

LDX

!>          LDX es de tipo INTEGER
!>     La dimensión principal del arreglo X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es de tipo DOUBLE PRECISION
!>     Número de condición recíproco escalado.  Esta es una estimación del
!>     recíproco del número de condición de Skeel de la matriz A después del
!>     equilibrado (si se realizó).  Si esto es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo.  Tenga en cuenta que el error puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

RPVGRW

!>          RPVGRW es de tipo DOUBLE PRECISION
!>     Crecimiento recíproco del pivote.  Al salir, esto contiene el factor de
!>     crecimiento recíproco del pivote norm(A)/norm(U). Se utiliza la
!>     norma infinito.  Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (equilibrada) podría ser deficiente.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y los límites de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento recíproco del pivote
!>     para las primeras INFO columnas de A.
!>

BERR

!>          BERR es un arreglo de tipo DOUBLE PRECISION, de dimensión (NRHS)
!>     Error hacia atrás relativo componente a componente.  Este es el
!>     error hacia atrás relativo componente a componente de cada vector de solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace de X(j) una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es de tipo INTEGER
!>     Número de límites de error a devolver para cada término independiente
!>     y cada tipo (en norma o componente a componente).  Vea ERR_BNDS_NORM y
!>     ERR_BNDS_COMP más abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un arreglo de tipo DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada término independiente, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector de solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El arreglo se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente se devuelven hasta tres piezas de información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     término independiente.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la entrada siguiente sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco del número de condición en norma
!>              estimado.  Se compara con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la
!>              estimación del error es fiable. Estos recíprocos de los números de condición
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada adecuadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de modo que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Vea la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un arreglo de tipo DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada término independiente, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector de solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El arreglo se indexa por el término independiente i (del cual depende el
!>     error relativo componente a componente), y el tipo de información de
!>     error como se describe a continuación. Actualmente se devuelven hasta tres
!>     piezas de información para cada término independiente. Si
!>     no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
!>     no se accede a ERR_BNDS_COMP.  Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     término independiente.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la entrada siguiente sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco del número de condición componente a componente
!>              estimado.  Se compara con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la
!>              estimación del error es fiable. Estos recíprocos de los números de condición
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              término independiente actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas las sumas absolutas de
!>              filas de Z sean aproximadamente 1.
!>
!>     Vea la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

NPARAMS

!>          NPARAMS es de tipo INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS.  Si <= 0, el
!>     arreglo PARAMS nunca se referencia y se utilizan los valores predeterminados.
!>

PARAMS

!>          PARAMS es un arreglo de tipo DOUBLE PRECISION, de dimensión (NPARAMS)
!>     Especifica los parámetros del algoritmo.  Si una entrada es < 0.0, entonces
!>     esa entrada se rellenará con el valor predeterminado utilizado para ese
!>     parámetro.  Solo se accede a las posiciones hasta NPARAMS; se utilizan los valores
!>     predeterminados para los parámetros de número más alto.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar refinamiento
!>            iterativo o no.
!>         Predeterminado: 1.0D+0
!>            = 0.0:  No se realiza refinamiento y no se calculan
!>                    límites de error.
!>            = 1.0:  Usar el algoritmo de refinamiento de precisión extra.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de cálculos de
!>            residuo permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecer en 100 para permitir la convergencia usando
!>                     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>                     la factorización utiliza una técnica distinta de la
!>                     eliminación gaussiana, las garantías en
!>                     err_bnds_norm y err_bnds_comp pueden dejar de ser
!>                     confiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Bandera que determina si el código
!>            intentará encontrar una solución con un pequeño error relativo
!>            componente a componente en el algoritmo de doble precisión.  Positivo
!>            es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia componente a componente)
!>

WORK

!>          WORK es un arreglo de tipo DOUBLE PRECISION, de dimensión (4*N)
!>

IWORK

!>          IWORK es un arreglo de tipo INTEGER, de dimensión (N)
!>

INFO

!>          INFO es de tipo INTEGER
!>       = 0:  Salida exitosa. La solución para cada término independiente está
!>         garantizada.
!>       < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero.  La factorización
!>         se ha completado, pero el factor U es exactamente singular, por lo
!>         que la solución y los límites de error no pudieron calcularse. Se devuelve RCOND = 0
!>         .       


NAME


DSYSVXX - Approximate solutions to the system of equations Ax = B







SYNOPSIS

Function/Subroutine Documentation








!>   The meaning of information returned in INFO depends on the value
!>   of the parameter L .
!>
!>   If L = 0, INFO is the smallest index J such that
!>   ERR_BNDS_NORM(J,1) is not guaranteed.
!>
!>   If L > 0, INFO is the smallest index J such that
!>   ERR_BNDS_NORM(J,1) or ERR_BNDS_COMP(J,1) is not guaranteed.
!>
!>   If L < 0, INFO is the smallest index J such that
!>   ERR_BNDS_NORM(J,1) or ERR_BNDS_COMP(J,1) is not guaranteed.
!>
!>   The range of values for L is not specified.
!>
!>   If L = 0, the solutions corresponding to the first INFO-1
!>   right-hand sides are guaranteed to be accurate. The solution
!>   corresponding to the INFO-th right-hand side is not guaranteed
!>   to be accurate. The solutions corresponding to other right-
!>   hand sides K with K > INFO may not be guaranteed as well, but
!>   only the first such right-hand side is reported.
!>
!>   If L > 0, the solutions corresponding to the first INFO-1
!>   right-hand sides are guaranteed to be accurate. The solution
!>   corresponding to the INFO-th right-hand side is not guaranteed
!>   to be accurate. The solutions corresponding to other right-
!>   hand sides K with K > INFO may not be guaranteed as well, but
!>   only the first such right-hand side is reported.
!>
!>   If L < 0, the solutions corresponding to the first INFO-1
!>   right-hand sides are guaranteed to be accurate. The solution
!>   corresponding to the INFO-th right-hand side is not guaranteed
!>   to be accurate. The solutions corresponding to other right-
!>   hand sides K with K > INFO may not be guaranteed as well, but
!>   only the first such right-hand side is reported.
!>
!>   If a small componentwise error is not requested (PARAMS(3) = 0.0)
!>   then the Jth right-hand side is the first with a normwise error
!>   bound that is not guaranteed (the smallest J such
!>   that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
!>   the Jth right-hand side is the first with either a normwise or
!>   componentwise error bound that is not guaranteed (the smallest
!>   J such that either ERR_BNDS_NORM(J,1) = 0.0 or
!>   ERR_BNDS_COMP(J,1) = 0.0). See the definition of
!>   ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
!>   about all of the right-hand sides check ERR_BNDS_NORM or
!>   ERR_BNDS_COMP.
!>
