DSA_do_sign(3ssl)

Paquete: openssl

Licencias: Apache-2.0

DSA_DO_SIGN(3ssl) OpenSSL DSA_DO_SIGN(3ssl)

NOMBRE

DSA_do_sign, DSA_do_verify - operaciones de firma DSA en bruto

SINOPSIS

#include <openssl/dsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7).

DSA_SIG *DSA_do_sign(const unsigned char *dgst, int dlen, DSA *dsa);
int DSA_do_verify(const unsigned char *dgst, int dgst_len,
                  DSA_SIG *sig, DSA *dsa);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_sign_init(3), EVP_PKEY_sign(3), EVP_PKEY_verify_init(3) y EVP_PKEY_verify(3).

DSA_do_sign() calcula una firma digital sobre el resumen del mensaje de len bytes dgst usando la clave privada dsa y la devuelve en una estructura DSA_SIG recién asignada.

DSA_sign_setup(3) puede ser usada para precalcular parte de la operación de firma en caso de que la generación de la firma sea crítica en cuanto al tiempo.

DSA_do_verify() verifica si la firma sig coincide con un resumen del mensaje dado dgst de tamaño len. dsa es la clave pública del firmante.

VALORES DE RETORNO

DSA_do_sign() devuelve la firma, NULL en caso de error. DSA_do_verify() devuelve 1 para una firma válida, 0 para una firma incorrecta y -1 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

DSA_new(3), ERR_get_error(3), RAND_bytes(3), DSA_SIG_new(3), DSA_sign(3)

HISTORIA

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
