Documentación de Función/Subrutin

a

subrutina dsyev_2stage (character jobz, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) w, double precision, dimension( * ) work, integer lwork, integer

info)

DSYEV_2STAGE calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices

SY

Propósito

: 
!>
!> DSYEV_2STAGE calcula todos los eigenvalores y, opcionalmente, los eigenvectores de una
!> matriz simétrica real A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal.
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los eigenvalores;
!>          = 'V':  Calcula los eigenvalores y eigenvectores.
!>                  No disponible en esta versión.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          Al entrar, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N principal de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N-por-N principal de A contiene
!>          la parte triangular inferior de la matriz A.
!>          Al salir, si JOBZ = 'V', entonces si INFO = 0, A contiene los
!>          eigenvectores ortonormales de la matriz A.
!>          Si JOBZ = 'N', entonces al salir el triángulo inferior (si UPLO='L')
!>          o el triángulo superior (si UPLO='U') de A, incluyendo la
!>          diagonal, es destruido.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = max(stage1,stage2) + (KD+1)*N + 2*N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 2*N
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo utilizado por el algoritmo QR o LQ,
!>                                   usualmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación con openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el algoritmo falló en converger; i
!>                elementos fuera de la diagonal de una forma tridiagonal
!>                intermedia no convergieron a cero.
!
>
