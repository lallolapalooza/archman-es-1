DSTEMR

Propósito:

!>
!> DSTEMR calcula los valores propios seleccionados y, opcionalmente, los vectores propios
!> de una matriz tridiagonal simétrica real T. Cualquier matriz no reducida de este tipo tiene
!> un conjunto bien definido de valores propios reales, todos ellos diferentes entre sí; los vectores propios reales correspondientes son ortogonales entre sí.
!>
!> El espectro puede calcularse completa o parcialmente especificando
!> un intervalo (VL,VU] o un rango de índices IL:IU para los valores propios deseados.
!>
!> Dependiendo del número de valores propios deseados, estos se calculan mediante
!> bisección o el algoritmo dqds. Los vectores propios numéricamente ortogonales se
!> calculan mediante el uso de varias factorizaciones L D L^T adecuadas cerca de los cúmulos
!> de valores propios cercanos (denominadas RRR, Representaciones Relativamente Robustas). Un esquema informal del algoritmo se detalla a continuación.
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcular T - sigma I  = L D L^T, de modo que L y D
!>        definen todos los valores propios buscados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores propios y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los valores propios con la precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión completa
!>        de los valores propios calculados solo justo antes
!>        de que los vectores correspondientes deban calcularse, véanse los pasos c) y d).
!>    (c) Para cada cúmulo de valores propios cercanos, seleccionar un nuevo
!>        desplazamiento cercano al cúmulo, encontrar una nueva factorización y refinar
!>        los valores propios desplazados con la precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcular
!>        el vector propio correspondiente formando una factorización retorcida que revele rangos. Volver a (c) para cualquier cúmulo que quede.
!>
!> Para más detalles, véase:
!> - Inderjit S. Dhillon y Beresford N. Parlett: 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, agosto de 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mayo de 1997.
!>
!> Más detalles
!> 1.DSTEMR solo funciona en máquinas que siguen el estándar
!> de punto flotante IEEE-754 en su manejo de infinitos y NaNs.
!> Esto permite el uso de bucles internos eficientes que evitan la comprobación de
!> divisores cero.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los N elementos diagonales de la matriz
!>          tridiagonal T. En la salida, D se sobrescribe.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los N-1 elementos subdiagonales de la matriz
!>          tridiagonal T en los elementos 1 a N-1 de E. E(N) no necesita ser establecido en
!>          la entrada, pero se utiliza internamente como espacio de trabajo.
!>          En la salida, E se sobrescribe.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz T
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y puede calcularse con una consulta de espacio de trabajo
!>          estableciendo NZC = -1, véase más abajo.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión líder del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

NZC

!>          NZC es INTEGER
!>          El número de vectores propios a contener en el array Z.
!>          Si RANGE = 'A', entonces NZC >= max(1,N).
!>          Si RANGE = 'V', entonces NZC >= el número de valores propios en (VL,VU].
!>          Si RANGE = 'I', entonces NZC >= IU-IL+1.
!>          Si NZC = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina calcula el número de columnas del array Z que
!>          se necesitan para contener los vectores propios.
!>          Este valor se devuelve como la primera entrada del array Z, y
!>          XERBLA no emite ningún mensaje de error relacionado con NZC.
!>

ISUPPZ

!>          ISUPPZ es un array INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los vectores propios en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo vector propio calculado
!>          es noz

TRYRA

C 
!>          TRYRAC es LOGICAL
!>          Si TRYRAC = .TRUE., indica que el código debe comprobar si
!>          la matriz tridiagonal define sus autovalores con alta precisión
!>          relativa.  Si es así, el código utiliza algoritmos que preservan
!>          la precisión relativa, que podrían ser (un poco) más lentos
!>          dependiendo de la matriz.
!>          Si la matriz no define sus autovalores con alta precisión
!>          relativa, el código puede usar algoritmos posiblemente más rápidos.
!>          Si TRYRAC = .FALSE., no se requiere que el código garantice
!>          autovalores relativamente precisos y puede usar las técnicas
!>          más rápidas posibles.
!>          En la salida, un TRYRAC .TRUE. se establecerá en .FALSE. si la
!>          matriz no define sus autovalores con alta precisión relativa.
!
>

WOR

K 
!>          WORK es un arreglo DOUBLE PRECISION, dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo
!>          (y mínimo).
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= max(1,18*N)
!>          si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (LIWORK)
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del arreglo IWORK.  LIWORK >= max(1,10*N)
!>          si se desean los autovectores, y LIWORK >= max(1,8*N)
!>          si solo se van a calcular los autovalores.
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo IWORK, devuelve
!>          este valor como la primera entrada del arreglo IWORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con LIWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          En la salida, INFO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = 1X, error interno en DLARRE,
!>                si INFO = 2X, error interno en DLARRV.
!>                Aquí, el dígito X = ABS( IINFO ) < 10, donde IINFO es
!>                el código de error distinto de cero devuelto por DLARRE o
!>                DLARRV, respectivamente.
!>
