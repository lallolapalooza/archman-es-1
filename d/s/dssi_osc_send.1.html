dssi_osc_send(1) Manual de comandos generales dssi_osc_send(1)

NOMBRE

dssi_osc_send - enviar mensajes OSC a aplicaciones DSSI.

SINOPSIS

dssi_osc_send <opción> <URL OSC> <valores>

DESCRIPCIÓN

dssi_osc_send envía métodos OSC de DSSI a aplicaciones DSSI. dssi_osc_send se usa típicamente para controlar hosts DSSI (posiblemente para operación con scripts), o para probar interfaces de usuario DSSI.

OPCIONES

-c
Enviar un mensaje de `control'. Requiere que se proporcionen dos valores en la sección <valores>: puerto de control y valor. Por ejemplo, para establecer el puerto de control 1 a 0.1:
dssi_osc_send -c <URL OSC> 1 0.1
-p
Enviar un mensaje de `programa'. Requiere que se proporcionen dos valores en la sección <valores>: banco y número de programa. Por ejemplo, para seleccionar el banco 0, programa número 7:
dssi_osc_send -p <URL OSC> 0 7
-m
Enviar mensaje `midi'. Requiere que se proporcionen cuatro números en la sección <valores>. Por ejemplo, para enviar una nota activa, Do central, velocidad 64:
dssi_osc_send -m <URL OSC> 0 144 60 64
-C
Enviar un mensaje de `configuración'. Los <valores> son el par clave y valor. Por ejemplo, para enviar la clave `load' y el valor `/tmp/patches.pat':
dssi_osc_send -C <URL OSC> load /tmp/patches.pat
-s
Enviar un mensaje de `mostrar'.
dssi_osc_send -s <URL OSC>
-h
Enviar un mensaje de `ocultar'.
dssi_osc_send -h <URL OSC>
-q
Enviar un mensaje de `salir'.
dssi_osc_send -q <URL OSC>
-e
Enviar un mensaje de `saliendo'.
dssi_osc_send -e <URL OSC>
<URL OSC>
La URL a la que conectarse. Por ejemplo:
osc.udp://localhost:19383/dssi/test.1
osc.udp://my.host.org:10886/dssi/xsynth-dssi/Xsynth/chan00

VER TAMBIÉN

dssi_osc_update(1).
