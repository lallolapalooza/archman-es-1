DSYT21

Documentación de Función/Subrutina

subrutina dsyt21 (integer itype, character uplo, integer n, integer kband, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldv, * ) v, integer ldv, double precision, dimension( * ) tau, double precision, dimension( * ) work, double precision, dimension( 2 ) result)

DSYT21

Propósito:

!>
!> DSYT21 generalmente verifica una descomposición de la forma
!>
!>    A = U S U**T
!>
!> donde **T significa transpuesta, A es simétrica, U es ortogonal y S es
!> diagonal (si KBAND=0) o simétrica tridiagonal (si KBAND=1).
!>
!> Si ITYPE=1, entonces U se representa como una matriz densa; de lo contrario U se
!> expresa como un producto de transformaciones de Householder, cuyos vectores
!> se almacenan en el array  y cuyas constantes de escalado están en .
!> Usaremos la letra  para referirnos al producto de transformaciones
!> de Householder (que debería ser igual a U).
!>
!> Específicamente, si ITYPE=1, entonces:
!>
!>    RESULT(1) = | A - U S U**T | / ( |A| n ulp ) y
!>    RESULT(2) = | I - U U**T | / ( n ulp )
!>
!> Si ITYPE=2, entonces:
!>
!>    RESULT(1) = | A - V S V**T | / ( |A| n ulp )
!>
!> Si ITYPE=3, entonces:
!>
!>    RESULT(1) = | I - V U**T | / ( n ulp )
!>
!> Para ITYPE > 1, la transformación U se expresa como un producto
!> V = H(1)...H(n-2),  donde H(j) = I  -  tau(j) v(j) v(j)**T y cada
!> vector v(j) tiene sus primeros j elementos 0 y los n-j elementos restantes
!> almacenados en V(j+1:n,j).
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de pruebas a realizar.
!>          1: U expresada como una matriz ortogonal densa:
!>             RESULT(1) = | A - U S U**T | / ( |A| n ulp )  y
!>             RESULT(2) = | I - U U**T | / ( n ulp )
!>
!>          2: U expresada como un producto V de transformaciones de Householder:
!>             RESULT(1) = | A - V S V**T | / ( |A| n ulp )
!>
!>          3: U expresada tanto como una matriz ortogonal densa como
!>             como un producto de transformaciones de Householder:
!>             RESULT(1) = | I - V U**T | / ( n ulp )
!>

UPLO

!>          UPLO es CHARACTER
!>          Si UPLO='U', se usará el triángulo superior de A y V y
!>          el triángulo inferior (estrictamente) no será referenciado.
!>          Si UPLO='L', se usará el triángulo inferior de A y V y
!>          el triángulo superior (estrictamente) no será referenciado.
!>

N

!>          N es INTEGER
!>          El tamaño de la matriz.  Si es cero, DSYT21 no hace nada.
!>          Debe ser al menos cero.
!>

KBAND

!>          KBAND es INTEGER
!>          El ancho de banda de la matriz.  Solo puede ser cero o uno.
!>          Si es cero, entonces S es diagonal y E no es referenciado.  Si
!>          es uno, entonces S es simétrica tridiagonal.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          La matriz original (sin factorizar).  Se asume que es
!>          simétrica, y solo se referenciará la parte superior (UPLO='U') o solo la inferior
!>          (UPLO='L').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  Debe ser al menos 1
!>          y al menos N.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          La diagonal de la matriz (simétrica tri-) diagonal.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N-1)
!>          La subdiagonal de la matriz (simétrica tri-) diagonal.
!>          E(1) es el elemento (1,2) y (2,1), E(2) es el elemento (2,3) y
!>          (3,2), etc.
!>          No es referenciado si KBAND=0.
!>

U

!>          U es un array DOUBLE PRECISION, dimensión (LDU, N)
!>          Si ITYPE=1 o 3, contiene la matriz ortogonal en
!>          la descomposición, expresada como una matriz densa.  Si ITYPE=2,
!>          entonces no es referenciado.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U.  LDU debe ser al menos N y
!>          al menos 1.
!>

V

!>          V es un array DOUBLE PRECISION, dimensión (LDV, N)
!>          Si ITYPE=2 o 3, las columnas de este array contienen los
!>          vectores de Householder usados para describir la matriz ortogonal
!>          en la descomposición.  Si UPLO='L', entonces los vectores están en
!>          el triángulo inferior, si UPLO='U', entonces en el triángulo
!>          superior.
!>          *NOTA* Si ITYPE=2 o 3, V es modificada y restaurada.  La
!>          subdiagonal (si UPLO='L') o la superdiagonal (si UPLO='U')
!>          se establece a uno, y luego se restablece a su valor original, durante
!>          el curso del cálculo.
!>          Si ITYPE=1, entonces no es ni referenciada ni modificada.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V.  LDV debe ser al menos N y
!>          al menos 1.
!>

TAU

!>          TAU es un array DOUBLE PRECISION, dimensión (N)
!>          Si ITYPE >= 2, entonces TAU(j) es el factor escalar de
!>          v(j) v(j)**T en la transformación de Householder H(j) del
!>          producto  U = H(1)...H(n-2)
!>          Si ITYPE < 2, entonces TAU no es referenciado.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (2*N**2)
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (2)
!>          Los valores calculados por las dos pruebas descritas arriba.  Los
!>          valores están actualmente limitados a 1/ulp, para evitar desbordamiento.
!>          RESULT(1) es siempre modificado.  RESULT(2) es modificado solo
!>          si ITYPE=1.
!>
