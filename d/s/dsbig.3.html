dsbig(3)

LAPACK

NAME

dsbig — Real constants for double precision

SYNOPSIS

        real(dp), parameter la_constants::dsbig =
               real(radix(0._dp), dp)**( - ceiling( (maxexponent(0._dp) +
               digits(0._dp) - 1) * 0.5_dp))

Detailed Description

This is an alias for the constant dsbig. The constant dsbig is defined as:

       dsbig = radix(0._dp)**( - ceiling( (maxexponent(0._dp) + digits(0._dp) - 1) * 0.5_dp) )

where:

       radix(0._dp) is the base of the floating-point representation.
       maxexponent(0._dp) is the maximum exponent in the floating-point representation.
       digits(0._dp) is the number of digits in the mantissa.

This constant represents a small magnitude number related to the underflow threshold for double-precision floating-point numbers.
