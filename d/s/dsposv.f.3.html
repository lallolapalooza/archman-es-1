Documentación de la Función/Subrutina

subrutina dsposv (caracter uplo, entero n, entero nrhs, doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( ldb, * ) b, entero ldb, doble precisión, dimensión( ldx, * ) x, entero ldx, doble precisión, dimensión( n, * ) work, real, dimensión( * ) swork, entero iter, entero info)

DSPOSV calcula la solución a un sistema de ecuaciones lineales reales A * X = B,

Propósito:

!>
!> DSPOSV calcula la solución a un sistema de ecuaciones lineales real
!>    A * X = B,
!> donde A es una matriz simétrica positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> DSPOSV primero intenta factorizar la matriz en PRECISIÓN SIMPLE
!> y utiliza esta factorización dentro de un procedimiento de refinamiento iterativo
!> para producir una solución con calidad de error residual de norma doble en precisión
!> (ver más abajo). Si el enfoque falla, el método cambia a una
!> factorización y resolución en PRECISIÓN DOBLE.
!>
!> El refinamiento iterativo no será una estrategia ganadora si
!> la relación rendimiento en PRECISIÓN SIMPLE sobre rendimiento en
!> PRECISIÓN DOBLE es demasiado pequeña. Una estrategia razonable debería tener en cuenta
!> el número de lados derechos y el tamaño de la matriz.
!> Esto podría hacerse con una llamada a ILAENV en el futuro. Hasta ahora,
!> siempre intentamos el refinamiento iterativo.
!>
!> El proceso de refinamiento iterativo se detiene si
!>     ITER > ITERMAX
!> o para todos los RHS tenemos:
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> donde
!>     o ITER es el número de la iteración actual en el proceso de
!>       refinamiento iterativo
!>     o RNRM es la norma infinita del residuo
!>     o XNRM es la norma infinita de la solución
!>     o ANRM es la norma del operador infinito de la matriz A
!>     o EPS es el epsilon de la máquina devuelto por DLAMCH('Epsilon')
!> Los valores ITERMAX y BWDMAX se fijan en 30 y 1.0D+00 respectivamente.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array de DOBLE PRECISIÓN,
!>          dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte
!>          superior triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular de N por N de A contiene la parte
!!>          inferior triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>          En la salida, si se ha utilizado el refinamiento iterativo con éxito
!>          (INFO = 0 e ITER >= 0, ver descripción abajo), entonces A no cambia,
!>          si se ha utilizado la factorización de doble precisión
!>          (INFO = 0 e ITER < 0, ver descripción abajo), entonces el
!>          array A contiene el factor U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array de DOBLE PRECISIÓN, dimensión (LDB,NRHS)
!>          La matriz B de N por NRHS del lado derecho.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array de DOBLE PRECISIÓN, dimensión (LDX,NRHS)
!>          Si INFO = 0, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (N,NRHS)
!>          Este array se utiliza para contener los vectores residuales.
!>

SWORK

!>          SWORK es un array de REAL, dimensión (N*(N+NRHS))
!>          Este array se utiliza para usar la matriz de precisión simple y los
!>          lados derechos o las soluciones en precisión simple.
!>

ITER

!>          ITER es INTEGER
!>          < 0: el refinamiento iterativo ha fallado, se ha realizado una
!>               factorización en doble precisión
!>               -1 : la rutina recurrió a precisión completa por razones
!>                    específicas de la implementación o de la máquina
!>               -2 : la reducción de la precisión provocó un desbordamiento,
!>                    la rutina recurrió a precisión completa
!>               -3 : fallo de SPOTRF
!>               -31: se detuvo el refinamiento iterativo después de la 30ª
!>                    iteración
!>          > 0: se ha utilizado con éxito el refinamiento iterativo.
!>               Devuelve el número de iteraciones
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal líder de orden i
!>                de (DOBLE PRECISIÓN) A no es positivo, por lo que la
!>                factorización no pudo completarse y la solución
!>                no se ha calculado.
!>

NOMBRE

dsposv - dsposv resuelve un sistema de ecuaciones lineales Ax=B con una matriz simétrica definida positiva A.

SINAPSIS

SUBROUTINE DSPOSV( UPLO, N, NRHS, A, LDA, B, LDB, INFO )

          INTEGER           N
          INTEGER           NRHS
          DOUBLE PRECISION A( LDA, * )
          DOUBLE PRECISION B( LDB, * )
          INTEGER           INFO
          CHARACTER*1       UPLO

DESCRIPCIÓN

dsposv resuelve el sistema de ecuaciones lineales Ax=B con una matriz simétrica real definida positiva A de orden N y con N o más columnas. Se utiliza la factorización de Cholesky de A.

Se busca la solución X de Ax=B.

PARÁMETROS

UPLO (input) CHARACTER*1

Indica si la matriz A se ha almacenado en su forma triangular superior o inferior.

= 'U': Triangular superior

= 'L': Triangular inferior

N (input) INTEGER

El orden de la matriz A. N ≥ 0.

NRHS (input) INTEGER

El número de columnas del vector objetivo B. 0 ≤ NRHS.

A (input/output) DOUBLE PRECISION array, dimension (LDA, N)

En la entrada, la matriz simétrica definida positiva A.

Si UPLO = 'U', la parte triangular superior de A.

Si UPLO = 'L', la parte triangular inferior de A.

En la salida, la matriz A se ha modificado; si se desea conservar el valor original de A, se debe crear una copia.

LDA (input) INTEGER

El ancho de la matriz A. LDA ≥ max(1, N).

B (input/output) DOUBLE PRECISION array, dimension (LDB, NRHS)

En la entrada, el vector objetivo B.

En la salida, la solución X.

LDB (input) INTEGER

El ancho de la matriz B. LDB ≥ max(1, N).

INFO (output) INTEGER

Si INFO = 0, se ejecuta correctamente.

Si INFO < 0, significa que el k-ésimo argumento (en valor absoluto) tenía un valor ilegal.

Si INFO > 0, significa que la factorización de Cholesky de A falló y la matriz no es definida positiva.

El factor i-ésimo de la diagonal es menor o igual que cero, así que no es posible continuar la factorización.

El factor i-ésimo de la diagonal es menor o igual que cero, así que la matriz no es definida positiva.

EJEMPLOS

Ejemplo de uso:

PROGRAM EXAMPLE
  IMPLICIT NONE
  INTEGER, PARAMETER :: N = 4, NRHS = 2
  INTEGER, PARAMETER :: LDA = N, LDB = N
  DOUBLE PRECISION A(LDA, N)
  DOUBLE PRECISION B(LDB, NRHS)
  INTEGER INFO

  ! Inicializar la matriz A y el vector B
  A(1,:) = (/ 1.0D0, 2.0D0, 3.0D0, 4.0D0 /)
  A(2,:) = (/ 2.0D0, 5.0D0, 7.0D0, 9.0D0 /)
  A(3,:) = (/ 3.0D0, 7.0D0, 12.0D0, 15.0D0 /)
  A(4,:) = (/ 4.0D0, 9.0D0, 15.0D0, 21.0D0 /)

  B(:,1) = (/ 1.0D0, 2.0D0, 3.0D0, 4.0D0 /)
  B(:,2) = (/ 5.0D0, 6.0D0, 7.0D0, 8.0D0 /)

  ! Llamar a dsposv para resolver Ax=B
  CALL dsposv('U', N, NRHS, A, LDA, B, LDB, INFO)

  IF (INFO .EQ. 0) THEN
    PRINT *, "La solución es:"
    PRINT *, B
  ELSE IF (INFO .GT. 0) THEN
    PRINT *, "La matriz no es definida positiva. Error en la posición: ", INFO
  ELSE
    PRINT *, "Argumento ilegal en la posición: ", -INFO
  END IF

END PROGRAM EXAMPLE
