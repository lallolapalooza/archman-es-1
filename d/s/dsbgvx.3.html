DSBGV

X

Propósito

: 
!>
!> DSBGVX calcula autovalores seleccionados y, opcionalmente, autovectores
!> de un problema de autovalores generalizado simétrico-definido positivo en banda,
!> de la forma A*x=(lambda)*B*x. Aquí se asume que A y B son simétricas
!> y en banda, y que B es además definida positiva. Los autovalores y
!> autovectores pueden seleccionarse especificando todos los autovalores,
!> un rango de valores o un rango de índices para los autovalores deseados.
!
>

Parámetro

s
JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo autovalores;
!>          = 'V':  Calcula autovalores y autovectores.
!
>

RANG

E 
!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta el IU-ésimo.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!
>

K

A 
!>          KA es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KA >= 0.
!
>

K

B 
!>          KB es INTEGER
!>          El número de superdiagonales de la matriz B si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KB >= 0.
!
>

A

B 
!>          AB es un array DOUBLE PRECISION, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica en banda
!>          A, almacenado en las primeras ka+1 filas del array. La
!>          j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) para max(1,j-ka)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+ka).
!>
!>          En la salida, el contenido de AB se destruye.
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KA+1.
!
>

B

B 
!>          BB es un array DOUBLE PRECISION, dimensión (LDBB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica en banda
!>          B, almacenado en las primeras kb+1 filas del array. La
!>          j-ésima columna de B se almacena en la j-ésima columna del array BB
!>          de la siguiente manera:
!>          si UPLO = 'U', BB(ka+1+i-j,j) = B(i,j) para max(1,j-kb)<=i<=j;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) para j<=i<=min(n,j+kb).
!>
!>          En la salida, el factor S de la factorización de Cholesky dividida
!>          B = S**T*S, tal como lo devuelve DPBSTF.
!
>

LDB

B 
!>          LDBB es INTEGER
!>          La dimensión principal del array BB.  LDBB >= KB+1.
!
>

Q 
!>          Q es un array DOUBLE PRECISION, dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz n-por-n usada en la reducción de
!>          A*x = (lambda)*B*x a su forma estándar, es decir, C*x = (lambda)*x,
!>          y en consecuencia C a su forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se referencia.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  Si JOBZ = 'N',
!>          LDQ >= 1. Si JOBZ = 'V', LDQ >= max(1,N).
!
>

V

L 
!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo en el que
!>          se buscarán autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

V

U 
!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo en el que
!>          se buscarán autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!
>

I

L 
!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño que se devolverá.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

I

U 
!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más grande que se devolverá.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!
>

ABSTO

L 
!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los autovalores.
!>          Un autovalor aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina.  Si ABSTOL es menor o
!>          igual a cero, entonces se usará  EPS*|T|  en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a su forma tridiagonal.
!>
!>          Los autovalores se calcularán con mayor precisión cuando ABSTOL se
!>          establezca al doble del umbral de desbordamiento inferior 2*DLAMCH('S'), no a cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          autovectores no convergieron, intente establecer ABSTOL a
!>          2*DLAMCH('S').
!
>

M 
!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los autovalores en orden ascendente.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          autovectores, con la i-ésima columna de Z conteniendo el
!>          autovector asociado con W(i). Los autovectores están
!>          normalizados de modo que Z**T*B*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!
>

LD

Z 
!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!
>

WOR

K 
!&gt;          WORK es un array de tipo DOUBLE PRECISION, dimensión (7*N)
!
>

IWOR

K 
!>          IWORK es un array de tipo INTEGER, dimensión (5*N)
!
>

IFAI

L 
!>          IFAIL es un array de tipo INTEGER, dimensión (M)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los eigenvalores que no convergieron.
!>          Si JOBZ = 'N', entonces IFAIL no es referenciado.
!
>

INF

O 
!>          INFO es de tipo INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          <= N: si INFO = i, entonces i autovectores no convergieron.
!>                  Sus índices están almacenados en IFAIL.
!>          > N:  DPBSTF devolvió un código de error; es decir,
!>                si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                principal principal de orden i de B no es positivo.
!>                La factorización de B no pudo completarse y
!>                no se calcularon ni eigenvalores ni autovectores.
!
>
