DSYRFS

X

Propósito

: 
!>
!>    DSYRFSX mejora la solución calculada de un sistema de ecuaciones lineales
!>    cuando la matriz de coeficientes es simétrica indefinida, y
!>    proporciona cotas de error y estimaciones de error hacia atrás para la
!>    solución. Además de la cota de error en norma, el código proporciona
!>    la cota de error máxima componente a componente si es posible. Consulte los comentarios para
!>    ERR_BNDS_NORM y ERR_BNDS_COMP para obtener detalles sobre las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido equilibrado
!>    antes de llamar a esta rutina, como se describe en los argumentos EQUED y S
!>    a continuación. En este caso, la solución y las cotas de error devueltas son
!>    para el sistema original sin equilibrar.
!
> 
!>     Algunos parámetros opcionales se agrupan en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores por defecto son aceptables. Si los valores por defecto son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0, lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!
>

EQUE

D 
!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'Y':  Equilibrado tanto por filas como por columnas, es decir, A ha sido
!>               reemplazada por diag(S) * A * diag(S).
!>               El segundo miembro B ha sido cambiado en consecuencia.
!
>

N 
!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>     El número de segundos miembros, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>     principal N-by-N de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente triangular inferior
!>     de A no es referenciada.  Si UPLO = 'L', la parte
!>     triangular inferior principal N-by-N de A contiene la parte
!>     triangular inferior de la matriz A, y la parte estrictamente triangular
!>     superior de A no es referenciada.
!
>

LD

A 
!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!
>

A

F 
!>          AF es un array DOUBLE PRECISION, dimensión (LDAF,N)
!>     La forma factorizada de la matriz A.  AF contiene la matriz
!>     diagonal por bloques D y los multiplicadores utilizados para obtener el
!>     factor U o L de la factorización A = U*D*U**T o A =
!>     L*D*L**T tal como lo calcula DSYTRF.
!
>

LDA

F 
!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!
>

IPI

V 
!>          IPIV es un array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura por bloques de D
!>     tal como los determina DSYTRF.
!
>

S 
!>          S es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala para A.  Si EQUED = 'Y', A se multiplica por
!>     diag(S) a la izquierda y a la derecha.  S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida.  Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo.  Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
!>     de S debería ser una potencia de la base para asegurar una solución confiable
!>     y estimaciones de error. El escalado por potencias de la base no causa
!>     errores de redondeo a menos que el resultado se desborde por abajo o por arriba.
!>     Los errores de redondeo durante el escalado conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>     La matriz del segundo miembro B.
!
>

LD

B 
!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!
>

X 
!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>     A la entrada, la matriz de solución X, tal como la calcula DGETRS.
!>     A la salida, la matriz de solución X mejorada.
!
>

LD

X 
!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!
>

RCON

D 
!>          RCOND es DOUBLE PRECISION
!>     Número de condición recíproco escalado.  Esta es una estimación del
!>     recíproco del número de condición de Skeel de la matriz A después del
!>     equilibrado (si se hizo).  Si esto es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo.  Tenga en cuenta que el error puede seguir siendo pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!
>

BER

R 
!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>     Error hacia atrás relativo componente a componente.  Este es el
!>     error hacia atrás relativo componente a componente de cada vector de solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace de X(j) una solución exacta).
!
>

N_ERR_BND

S 
!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver para cada segundo miembro
!>     y cada tipo (en norma o componente a componente).  Consulte ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!
>

ERR_BNDS_NOR

M 
!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector de solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error como se
!>     describe a continuación. Actualmente se devuelven hasta tres
!>     piezas de información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero siempre que la siguiente entrada sea mayor que
!>              el umbral sqrt(n) * dlamch('Epsilon'). Este límite de
!>              error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado en norma. Se compara con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la
!>              estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia
!>              de la base de modo que todas las sumas absolutas de fila
!>              de Z sean aproximadamente 1.
!>
!>     Consulte Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

ERR_BNDS_COM

P 
!>          ERR_BNDS_COMP es un array de DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array está indexado por el segundo miembro i (del cual depende
!>     el error relativo componente a componente), y el tipo de
!>     información de error como se describe a continuación. Actualmente
!>     se devuelven hasta tres piezas de información para cada segundo
!>     miembro. Si no se solicita precisión componente a componente
!>     (PARAMS(3) = 0.0), entonces no se accede a ERR_BNDS_COMP. Si
!>     N_ERR_BNDS < 3, entonces se devuelven como máximo las primeras
!>     entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error
!>              verdadero siempre que la siguiente entrada sea mayor que
!>              el umbral sqrt(n) * dlamch('Epsilon'). Este límite de
!>              error solo debe confiarse si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado componente a componente. Se compara
!>              con el umbral sqrt(n) * dlamch('Epsilon') para determinar
!>              si la estimación de error es . Estos números de
!>              condición recíprocos son 1 / (norm(Z^{-1},inf) *
!>              norm(Z,inf)) para alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas
!>              las sumas absolutas de fila de Z sean aproximadamente 1.
!>
!>     Consulte Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

NPARAM

S 
!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS. Si es
!>     <= 0, el array PARAMS nunca se referencia y se usan los valores
!>     predeterminados.
!
>

PARAM

S 
!>          PARAMS es un array de DOUBLE PRECISION, dimensión (NPARAMS)
!>     Especifica los parámetros del algoritmo. Si una entrada es <
!>     0.0, entonces esa entrada se rellenará con el valor
!>     predeterminado usado para ese parámetro. Solo se accede a las
!>     posiciones hasta NPARAMS; se usan los valores predeterminados
!>     para los parámetros numerados más alto.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar refinamiento
!>            iterativo o no.
!>         Predeterminado: 1.0D+0
!>            = 0.0:  No se realiza refinamiento y no se calculan
!>                    límites de error.
!>            = 1.0:  Usar el algoritmo de refinamiento de doble
!>                    precisión, posiblemente con cálculos
!>                    doble-unico si el entorno de compilación no
!>                    soporta DOUBLE PRECISION.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de cálculos
!>            de residuo permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecer en 100 para permitir la convergencia
!>                     usando factorizaciones aproximadas o
!>                     factorizaciones distintas de LU. Si la
!>                     factorización usa una técnica distinta de la
!>                     eliminación de Gauss, las garantías en
!>                     err_bnds_norm y err_bnds_comp pueden dejar de
!>                     ser confiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Bandera que determina si el
!>            código intentará encontrar una solución con pequeño error
!>            relativo componente a componente en el algoritmo de doble
!>            precisión. Positivo es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia componente a
!>                     componente)
!
>

WOR

K 
!>          WORK es un array de DOUBLE PRECISION, dimensión (4*N)
!
>

IWOR

K 
!>          IWORK es un array de INTEGER, dimensión (N)
!
>

INF

O 
!>          INFO es INTEGER
!>       = 0:  Salida exitosa. Se garantiza la solución para cada
!>         segundo miembro.
!>       < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero. La
!>         factorización se ha completado, pero el factor U es
!>         exactamente singular, por lo que no se pudieron calcular la
!>         solución y los límites de error. Se devuelve RCOND = 0.
!>       = N+J: La solución correspondiente al J-ésimo segundo miembro
!>         no está garantizada. Las soluciones correspondientes a otros
!>         segundos miembros K con K > J tampoco pueden estar
!>         garantizadas, pero solo se informa del primer segundo miembro
!>         de ese tipo. Si no se solicita un pequeño error componente a
!>         componente (PARAMS(3) = 0.0), entonces el J-ésimo segundo
!>         miembro es el primero con un límite de error en norma que no
!>         está garantizado (el más pequeño J tal que
!>         ERR_BNDS_NORM(J,1) = 0.0). Por defecto (PARAMS(3) = 1.0)
!>         el J-ésimo segundo miembro es el primero con un límite de
!>         error en norma o componente a componente que no está
!>         garantizado (el más pequeño J tal que
!>         ERR_BNDS_NORM(J,1) = 0.0 o ERR_BNDS_COMP(J,1) = 0.0).
!>         Consulte la definición de ERR_BNDS_NORM(:,1) y
!>         ERR_BNDS_COMP(:,1). Para obtener información sobre todos los
!>         segundos miembros, verifique ERR_BNDS_NORM o
!>         ERR_BNDS_COMP.
!
>
