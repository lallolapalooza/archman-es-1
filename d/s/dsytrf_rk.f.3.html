subrutina dsytrf_rk (uplo, n, a, lda, e, ipiv, work, lwork, info)


DSYTRF_RK calcula la factorización de una matriz real simétrica indefinida utilizando el método de pivoteo diagonal de Bunch-Kaufman acotado (rook) (algoritmo bloqueado BLAS3).

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina dsytrf_rk (carácter uplo, entero n, doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( * ) e, entero, dimensión( * ) ipiv, doble precisión, dimensión( * ) work, entero lwork, entero info)

DSYTRF_RK calcula la factorización de una matriz real simétrica indefinida utilizando el método de pivoteo diagonal de Bunch-Kaufman acotado (rook) (algoritmo bloqueado BLAS3).

Propósito:

!> DSYTRF_RK calcula la factorización de una matriz simétrica real A
!> utilizando el método de pivoteo diagonal de Bunch-Kaufman acotado (rook):
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz unitaria superior (o inferior) triangular,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques con
!> bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, llamando a BLAS de Nivel 3.
!> Para más información ver la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte superior N-por-N principal
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no
!>            se referencia.
!>
!>            Si UPLO = 'L': la parte inferior N-por-N principal
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no
!>            se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz simétrica
!>               diagonal por bloques D en la diagonal de A, es decir,
!>               D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz simétrica diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de fila y columna que fueron
!>          intercambiados con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en el que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques
!>          de la matriz simétrica diagonal por bloques D con bloques
!>          diagonales de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información ver la sección
!>          Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          ( en orden de factorización, k disminuye de N a 1 ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en orden de factorización, k aumenta de 1 a N ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO CERO en la salida.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1.  Para el mejor rendimiento
!>          LWORK >= N*NB, donde NB es el tamaño de bloque devuelto
!>          por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y no se emite ningún mensaje de error relacionado con LWORK
!>          por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el argumento k tuvo un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de la columna k de L) son todos ceros. La
!>               factorización se ha completado, pero el bloque

NAME

dsytrf_rk - computes the Bunch-Kaufman factorization of a real symmetric matrix.

SYNOPSIS 

CALL dsytrf_rk(uplo, n, a, lda, ipiv, tau, work, lwork, info)
SUBROUTINE dsytrf_rk(CHARACTER(1) uplo, INTEGER n, REAL(8) a, INTEGER lda, INTEGER ipiv, REAL(8) tau, REAL(8) work, INTEGER lwork, INTEGER info)

Function/Subroutine Documentation

This routine is part of the LAPACK routines that reduce the problem of solving symmetric, Hermitian, or general rectangular systems of linear equations.

The Bunch-Kaufman factorization is a variant of the symmetric factorization using rook interchanges.

This factorization computes a decomposition of a real symmetric matrix A such that A = P * U * T * UT * PT, where P is a permutation matrix, U is upper triangular, and T is block anti-symmetric/symmetric.

This subroutine computes the Bunch-Kaufman factorization of a real symmetric matrix a.

The factorization is performed in block form using partial pivoting for stability.

Arguments:

uplo

CHARACTER*1. Specifies whether the matrix A is upper or lower triangular.

On entry: uplo specifies the form of the matrix A. Only one of these is permitted:

uplo = 'U'

A is upper triangular

uplo = 'L'

A is lower triangular.

n

INTEGER. The order of the matrix A.

a

DOUBLE PRECISION array, dimension (lda, n).

On entry, the symmetric matrix A.

On exit, contains the block anti-symmetric/symmetric matrix T and the super-/sub-diagonal elements of U.

lda

INTEGER. The leading dimension of the array A.

ipiv

INTEGER array, dimension (n).

Details of the interchanges.

The pivot choices may be stored in this array.

tau

DOUBLE PRECISION array, dimension (n).

The scale factors of the elementary triangular transformations.

work

DOUBLE PRECISION array, dimension (lwork).

Workspace array.

lwork

INTEGER. The size of the array work.

lwork >= n. For optimal performance, lwork >= max(n, nb*n), where nb is the block size. If lwork = -1, then the optimal dimension is calculated and returned.

info

INTEGER.

On exit: 0 <= info <= n: If info = i, then the k-th pivot element is zero when i <= k <= n. The factorization has been completed, but it is degenerate. If info > n: If info = -k, the k-th argument had an illegal value.

If INFO = 0, the factorization has completed successfully.

If INFO < 0, it indicates an error in the input parameters.

If INFO > 0, the diagonal matrix D is exactly singular, and division by zero will occur if it is used to solve a system of equations.

NOTE: INFO only stores the first occurrence of a singularity, any subsequent occurrence of singularity is not stored in INFO even though the factorization always completes.
