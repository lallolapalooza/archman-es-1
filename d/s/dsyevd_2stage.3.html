DSYEVD_2STAGE calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices SY Documentación de Función/Subrutina
subrutina dsyevd_2stage (character jobz, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) w, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

DSYEVD_2STAGE calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices

SY

Propósito

:

!> !> DSYEVD_2STAGE calcula todos los eigenvalores y, opcionalmente, los eigenvectores de una !> matriz simétrica real A usando la técnica de 2 etapas para !> la reducción a tridiagonal. Si se desean eigenvectores, se usa un !> algoritmo de dividir y conquistar. !>

!>

Parámetro

s 
J
OB
Z

!> JOBZ es CHARACTER*1 !> = 'N': Calcula solo los eigenvalores; !> = 'V': Calcula los eigenvalores y los eigenvectores. !> No disponible

en esta versión. !>
UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la
!>          parte triangular superior principal N-por-N de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior principal N-por-N de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene los
!>          eigenvectores ortonormales de la matriz A.
!>          Si JOBZ = 'N', entonces en la salida el triángulo inferior (si UPLO='L')
!>          o el triángulo superior (si UPLO='U') de A, incluyendo la
!>          diagonal, es
destruido. !>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

W 
!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los eigenvalores en orden ascendente.
!
>

WO

RK 
!>          WORK es un array DOUBLE PRECISION,
!>                                         dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = max(etapa1,etapa2) + (KD+1)*N + 2*N+1
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + 2*N+1
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo usado por el algoritmo QR o LQ,
!>                                   usualmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos usado cuando
!>                                   la compilación con openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser al menos
!>                                                1 + 6*N + 2*N**2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK e IWORK,
!>          devuelve estos valores como las primeras entradas de los arrays WORK
!>          e IWORK, y no se emite ningún mensaje de error relacionado con LWORK o
!>          LIWORK por parte de
XERBLA. !>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1,                LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'N' y N > 1, LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK debe ser al menos 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK e IWORK, y no se emite ningún mensaje de error relacionado con
!>          LWORK o LIWORK por parte de XERBLA.
!>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i y JOBZ = 'N', entonces el algoritmo falló
!>                en converger; i elementos fuera de la diagonal de una forma
!>                tridiagonal intermedia no convergieron a cero;
!>                si INFO = i y JOBZ = 'V', entonces el algoritmo falló
!>                en calcular un eigenvalor mientras trabajaba en la submatriz
!>                situada en las filas y columnas INFO/(N+1) a
!>                mod(INFO,N+1).
!
