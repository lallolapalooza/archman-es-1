NOMBRE

dsniff - sniffer de contraseñas

SINOPSIS

dsniff [-c] [-d] [-m] [-n] [-i interfaz | -p archivo.pcap] [-s longitud_captura] [-f servicios] [-t disparador[,...]]] [-r|-w archivo_guardado] [expresión]

DESCRIPCIÓN


dsniff es un sniffer de contraseñas que maneja los protocolos FTP, Telnet, SMTP, HTTP, POP, poppass, NNTP, IMAP, SNMP, LDAP, Rlogin, RIP, OSPF, PPTP MS-CHAP, NFS, VRRP, YP/NIS, SOCKS, X11, CVS, IRC, AIM, ICQ, Napster, PostgreSQL, Meeting Maker, Citrix ICA, Symantec pcAnywhere, NAI Sniffer, Microsoft SMB, Oracle SQL*Net, Sybase y Microsoft SQL.

dsniff detecta y analiza mínimamente cada protocolo de aplicación automáticamente, guardando solo las partes interesantes, y utiliza Berkeley DB como formato de archivo de salida, registrando solo los intentos de autenticación únicos. El reensamblaje completo de TCP/IP es proporcionado por libnids(3).

Escribí dsniff con intenciones honestas: para auditar mi propia red y para demostrar la inseguridad de los protocolos de red en texto plano. Por favor, no abuse de este software.

OPCIONES

-c
Realiza el reensamblaje de flujo TCP dúplex medio, para manejar tráfico con enrutamiento asimétrico (como al usar arpspoof(8) para interceptar el tráfico del cliente dirigido a la puerta de enlace local).
-d
Habilita el modo de depuración.
-m
Habilita la detección automática de protocolos.
-n
No resuelve las direcciones IP a nombres de host.
-i interfaz
Especifica la interfaz en la que escuchar.
-p archivo.pcap
En lugar de procesar el contenido de los paquetes observados en la red, procesa el archivo de captura PCAP dado.
-s longitud_captura
Analiza como máximo los primeros longitud_captura bytes de cada conexión TCP, en lugar de los 1024 por defecto.
-f servicios
Carga disparadores desde un archivo de servicios.
-t disparador[,...]
Carga disparadores desde una lista separada por comas, especificada como puerto/proto=servicio (ej. 80/tcp=http).
-r archivo_guardado
Lee las sesiones capturadas desde un archivo_guardado creado con la opción -w.
-w archivo
Escribe las sesiones capturadas en archivo_guardado en lugar de analizarlas e imprimirlas.
expresión
Especifica una expresión de filtro de tcpdump(8) para seleccionar el tráfico a capturar.

Ante una señal de colgado, dsniff volcará su tabla de disparadores actual a dsniff.services.

ARCHIVOS

/usr/share/dsniff/dsniff.magic
