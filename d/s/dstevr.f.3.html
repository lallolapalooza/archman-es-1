DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine dstevr (character jobz, character range, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

DSTEVR calcula los valores propios seleccionados y, opcionalmente, los vectores propios de una matriz triagonal simétrica T. Los valores propios y vectores propios pueden ser seleccionados especificando un rango de valores o un rango de índices para los valores propios deseados.

Propósito:

!>
!> DSTEVR calcula los valores propios seleccionados y, opcionalmente, los
!> vectores propios de una matriz triagonal simétrica T. Los valores propios
!> y vectores propios pueden ser seleccionados especificando un rango de
!> valores o un rango de índices para los valores propios deseados.
!>
!> Siempre que sea posible, DSTEVR llama a DSTEMR para calcular el
!> espectro de valores propios utilizando Representaciones Relativamente
!> Robustas. DSTEMR calcula los valores propios mediante el algoritmo dqds,
!> mientras que los vectores propios ortogonales se calculan a partir de
!> varias representaciones L D L^T (también conocidas como Representaciones
!> Relativamente Robustas). Se evita la ortogonalización de Gram-Schmidt
!> tanto como sea posible. Más específicamente, los diversos pasos del
!> algoritmo son los siguientes. Para el i-ésimo bloque no reducido de T,
!>    (a) Calcula T - sigma_i = L_i D_i L_i^T, tal que L_i D_i L_i^T
!>         es una representación relativamente robusta,
!>    (b) Calcula los valores propios, lambda_j, de L_i D_i L_i^T con alta
!>        precisión relativa mediante el algoritmo dqds,
!>    (c) Si hay un clúster de valores propios cercanos, sigma_i
!>        cercano al clúster, y va al paso (a),
!>    (d) Dado el valor propio aproximado lambda_j de L_i D_i L_i^T,
!>        calcula el vector propio correspondiente formando una
!>        factorización retorcida que revele el rango.
!> La precisión deseada de la salida puede ser especificada por el
!> parámetro de entrada ABSTOL.
!>
!> Para más detalles, ver , por Inderjit Dhillon,
!> Informe Técnico de la División de Ciencias de la Computación No. UCB//CSD-97-971,
!> UC Berkeley, Mayo 1997.
!>
!>
!> Nota 1: DSTEVR llama a DSTEMR cuando se solicita el espectro completo
!> en máquinas que cumplen con el estándar de punto flotante ieee-754.
!> DSTEVR llama a DSTEBZ y DSTEIN en máquinas no ieee y
!> cuando se solicitan espectros parciales.
!>
!> La ejecución normal de DSTEMR puede crear NaNs e infinitos y
!> por lo tanto puede abortar debido a una excepción de punto flotante en
!> entornos que no manejan NaNs e infinitos de la manera predeterminada
!> estándar ieee.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo
!>                 semi-abierto (VL,VU].
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta
!>                 el IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman DSTEBZ y
!>          DSTEIN.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz
!>          triagonal A.
!>          En la salida, D puede ser multiplicado por un factor constante elegido
!>          para evitar el desbordamiento superior/inferior al calcular los valores
!>          propios.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (max(1,N-1))
!>          En la entrada, los (n-1) elementos subdiagonales de la matriz
!>          triagonal A en los elementos 1 a N-1 de E.
!>          En la salida, E puede ser multiplicado por un factor constante elegido
!>          para evitar el desbordamiento superior/inferior al calcular los valores
!>          propios.
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz triagonal obtenida
!>          al reducir A a forma triagonal.
!>
!>          Ver , por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si se desea alta precisión relativa, establezca ABSTOL a
!>          DLAMCH( 'Safe minimum' ). Esto garantizará que los
!>          valores propios se calculen con alta precisión relativa cuando
!>          sea posible en futuras versiones. El código actual no
!>          hace ninguna garantía sobre la alta precisión relativa, pero
!>          las futuras versiones sí lo harán. Ver J. Barlow y J. Demmel,
!>          , LAPACK Working Note #7, para una discusión
!>          de qué matrices definen sus valores propios con alta precisión
!>          relativa.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados
!>          en orden ascendente.
!>

Z

!>          Z es un array DOUBLE PRECISION, de dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Nota: el usuario debe asegurarse de que se suministran al menos
!>          max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y
