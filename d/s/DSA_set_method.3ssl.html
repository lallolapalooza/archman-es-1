DSA_set_method(3ssl)

Paquete: openssl

Licencias: Apache-2.0

DSA_SET_METHOD(3ssl) OpenSSL DSA_SET_METHOD(3ssl)

NOMBRE

DSA_set_default_method, DSA_get_default_method, DSA_set_method, DSA_new_method, DSA_OpenSSL - seleccionar método DSA

SINOPSIS

#include <openssl/dsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0 y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

void DSA_set_default_method(const DSA_METHOD *meth);
const DSA_METHOD *DSA_get_default_method(void);
int DSA_set_method(DSA *dsa, const DSA_METHOD *meth);
DSA *DSA_new_method(ENGINE *engine);
const DSA_METHOD *DSA_OpenSSL(void);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deben usar proveedores en lugar de sustituciones de métodos.

Un DSA_METHOD especifica las funciones que OpenSSL utiliza para las operaciones DSA. Al modificar el método, se pueden utilizar implementaciones alternativas, como aceleradores de hardware. IMPORTANTE: Consulte la sección NOTAS para obtener información importante sobre cómo estas funciones de la API DSA se ven afectadas por el uso de llamadas a la API de ENGINE.

Inicialmente, el DSA_METHOD por defecto es la implementación interna de OpenSSL, tal como la devuelve DSA_OpenSSL().

DSA_set_default_method() establece meth como el método por defecto para todas las estructuras DSA creadas posteriormente. Nota: Esto solo es cierto mientras ningún ENGINE haya sido establecido como por defecto para DSA, por lo que esta función ya no se recomienda. Esta función no es segura para subprocesos y no debe llamarse al mismo tiempo que otras funciones de OpenSSL.

DSA_get_default_method() devuelve un puntero al DSA_METHOD por defecto actual. Sin embargo, la utilidad de este resultado depende de si se está utilizando la API ENGINE, por lo que esta función ya no se recomienda.

DSA_set_method() selecciona meth para realizar todas las operaciones utilizando la clave rsa. Esto reemplazará al DSA_METHOD utilizado por la clave DSA y si el método anterior fue proporcionado por un ENGINE, el identificador de ese ENGINE se liberará durante el cambio. Es posible tener claves DSA que solo funcionen con ciertas implementaciones de DSA_METHOD (por ejemplo, de un módulo ENGINE que soporte claves protegidas por hardware embebidas), y en tales casos, intentar cambiar el DSA_METHOD para la clave puede tener resultados inesperados. Consulte DSA_meth_new(3) para obtener información sobre cómo construir objetos DSA_METHOD personalizados;

DSA_new_method() asigna e inicializa una estructura DSA para que engine se utilice para las operaciones DSA. Si engine es NULL, se utiliza el engine por defecto para las operaciones DSA, y si no se establece ningún ENGINE por defecto, se utiliza el DSA_METHOD controlado por DSA_set_default_method().

VALORES DE RETORNO

DSA_OpenSSL() y DSA_get_default_method() devuelven punteros a los respectivos DSA_METHODs.

DSA_set_default_method() no devuelve ningún valor.

DSA_set_method() devuelve un valor distinto de cero si el meth proporcionado se estableció con éxito como el método para dsa (incluyendo la descarga del identificador del ENGINE si el método anterior fue proporcionado por un ENGINE).

DSA_new_method() devuelve NULL y establece un código de error que puede obtenerse con ERR_get_error(3) si la asignación falla. De lo contrario, devuelve un puntero a la estructura recién asignada.

VER TAMBIÉN

DSA_new(3), DSA_new(3), DSA_meth_new(3)

HISTORIA

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
