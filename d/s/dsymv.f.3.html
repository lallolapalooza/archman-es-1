subrutina dsymv (carácter uplo, entero n, doble precisión alpha, doble precisión, dimensión(lda,*) a, entero lda, doble precisión, dimensión(*) x, entero incx, doble precisión beta, doble precisión, dimensión(*) y, entero incy)

DSYMV

Propósito:

!>
!> DSYMV  realiza la operación de matriz-vector
!>
!>    y := alpha*A*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores de n elementos y
!> A es una matriz simétrica de n por n.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz A se va a referenciar como
!>           sigue:
!>
!>              UPLO = 'U' o 'u'   Sólo se referenciará la parte triangular superior de A.
!>
!>              UPLO = 'L' o 'l'   Sólo se referenciará la parte triangular inferior de A.
!>

N

!>          N es ENTERO
!>           Al entrar, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es DOBLE PRECISIÓN.
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es una matriz DOBLE PRECISIÓN, dimensión ( LDA, N )
!>           Antes de entrar con UPLO = 'U' o 'u', la parte superior triangular
!>           de n por n de la matriz A debe contener la parte triangular superior
!>           de la matriz simétrica y la parte estrictamente triangular inferior de A
!>           no se referencia.
!>           Antes de entrar con UPLO = 'L' o 'l', la parte inferior triangular
!>           de n por n de la matriz A debe contener la parte triangular inferior
!>           de la matriz simétrica y la parte estrictamente triangular superior de A
!>           no se referencia.
!>

LDA

!>          LDA es ENTERO
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, n ).
!>

X

!>          X es una matriz DOBLE PRECISIÓN, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de entrar, la matriz incrementada X debe contener el vector
!>           x de n elementos.
!>

INCX

!>          INCX es ENTERO
!>           Al entrar, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

BETA

!>          BETA es DOBLE PRECISIÓN.
!>           Al entrar, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, Y no necesita ser establecido al entrar.
!>

Y

!>          Y es una matriz DOBLE PRECISIÓN, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de entrar, la matriz incrementada Y debe contener el vector
!>           y de n elementos. A la salida, Y se sobrescribe con el vector
!>           y actualizado.
!>

INCY

!>          INCY es ENTERO
!>           Al entrar, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>
