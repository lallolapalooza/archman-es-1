DSTEMR

Documentación de Función/Subrutina

subrutina dstemr (character jobz, character range, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision vl, double precision vu, integer il, integer iu, integer m, double precision, dimension( * ) w, double precision, dimension( ldz, * ) z, integer ldz, integer nzc, integer, dimension( * ) isuppz, logical tryrac, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

DSTEMR

Propósito:

!>
!> DSTEMR calcula autovalores seleccionados y, opcionalmente, autovectores
!> de una matriz tridiagonal simétrica real T. Cualquier matriz no reducida de
!> este tipo tiene un conjunto bien definido de autovalores reales
!> pairwise diferentes, los autovectores reales correspondientes son
!> ortogonales entre sí.
!>
!> El espectro puede calcularse ya sea completamente o parcialmente especificando
!> ya sea un intervalo (VL,VU] o un rango de índices IL:IU para los
!> autovalores deseados.
!>
!> Dependiendo del número de autovalores deseados, estos se calculan ya sea
!> por bisección o por el algoritmo dqds. Autovectores numéricamente ortogonales
!> se calculan mediante el uso de varias factorizaciones L D L^T adecuadas cerca de
!> cúmulos de autovalores cercanos (referidos como RRRs, Representaciones
!> Robustas Relativamente). Un esquema informal del algoritmo sigue.
!>
!> Para cada bloque (submatriz) no reducido de T,
!>    (a) Calcular T - sigma I  = L D L^T, de modo que L y D
!>        definan todos los autovalores deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los autovalores y
!>        autovectores. La representación estándar (sin factorizar) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los autovalores con precisión adecuada.
!>        Si se desean los autovectores, el algoritmo alcanza la precisión
!>        completa de los autovalores calculados solo justo antes de
!>        que se deban calcular los vectores correspondientes, ver pasos c) y d).
!>    (c) Para cada cúmulo de autovalores cercanos, seleccionar un nuevo
!>        desplazamiento cerca del cúmulo, encontrar una nueva factorización y refinar
!>        los autovalores desplazados con precisión adecuada.
!>    (d) Para cada autovalor con una separación relativa suficientemente grande, calcular
!>        el autovector correspondiente formando una factorización retorcida
!>        que revela el rango. Volver a (c) para cualquier cúmulo que permanezca.
!>
!> Para más detalles, ver:
!> - Inderjit S. Dhillon y Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, Agosto 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, Mayo 1997.
!>
!> Detalles Adicionales
!> 1.DSTEMR solo funciona en máquinas que siguen el estándar de punto flotante IEEE-754
!> en su manejo de infinitos y NaNs.
!> Esto permite el uso de bucles internos eficientes evitando una comprobación para
!> divisores cero.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo autovalores;
!>          = 'V':  Calcular autovalores y autovectores.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>          = 'I': se encontrarán los autovalores desde el IL-ésimo hasta el IU-ésimo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los N elementos diagonales de la matriz tridiagonal
!>          T. En la salida, D es sobrescrito.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los (N-1) elementos subdiagonales de la matriz tridiagonal
!>          T en los elementos 1 a N-1 de E. E(N) no necesita establecerse en la
!>          entrada, pero se usa internamente como espacio de trabajo.
!>          En la salida, E es sobrescrito.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar autovalores. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

M

!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los autovalores seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz T
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que al menos max(1,M) columnas se
!>          proporcionan en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y puede calcularse con una consulta
!>          de espacio de trabajo estableciendo NZC = -1, ver abajo.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

NZC

!>          NZC es INTEGER
!>          El número de autovectores a mantener en el array Z.
!>          Si RANGE = 'A', entonces NZC >= max(1,N).
!>          Si RANGE = 'V', entonces NZC >= el número de autovalores en (VL,VU].
!>          Si RANGE = 'I', entonces NZC >= IU-IL+1.
!>          Si NZC = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina calcula el número de columnas del array Z que
!>          se necesitan para contener los autovectores.
!>          Este valor se devuelve como la primera entrada del array Z, y
!>          no se emite ningún mensaje de error relacionado con NZC por XERBLA.
!>

ISUPPZ

!>          ISUPPZ es un array INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los autovectores en Z, es decir, los índices
!>          que indican los elementos no nulos en Z. El i-ésimo autovector calculado
!>          es no nuloo solo en elementos ISUPPZ( 2*i-1 ) a
!>          ISUPPZ( 2*i ). Esto es relevante en el caso en que la matriz
!>          esté dividida. ISUPPZ solo se accede cuando JOBZ es 'V' y N > 0.
!>

TRYRAC

!>          TRYRAC es LÓGICO
!>          Si TRYRAC = .TRUE., indica que el código debe verificar si
!>          la matriz tridiagonal define sus valores propios con alta precisión relativa.
!>          Si es así, el código utiliza algoritmos que conservan la precisión relativa, que pueden ser (un poco) más lentos dependiendo de la matriz.
!>          Si la matriz no define sus valores propios con alta precisión relativa, el código puede utilizar algoritmos posiblemente más rápidos.
!>          Si TRYRAC = .FALSE., el código no está obligado a garantizar
!>          valores propios de precisión relativa y puede utilizar las técnicas más rápidas posibles.
!>          A la salida, un TRYRAC .TRUE. se establecerá en .FALSE. si la matriz
!>          no define sus valores propios con alta precisión relativa.
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, de dimensión (LWORK)
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK
!>          óptimo (y mínimo).
!>

LWORK

!>          LWORK es un ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,18*N)
!>          si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

IWORK

!>          IWORK es un array de ENTEROS, de dimensión (LIWORK)
!>          A la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es un ENTERO
!>          La dimensión del array IWORK. LIWORK >= max(1,10*N)
!>          si se desean los vectores propios, y LIWORK >= max(1,8*N)
!>          si solo se van a calcular los valores propios.
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LIWORK.
!>

INFO

!>          INFO es un ENTERO
!>          A la salida, INFO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = 1X, error interno en DLARRE,
!>                si INFO = 2X, error interno en DLARRV.
!>                Aquí, el dígito X = ABS( IINFO ) < 10, donde IINFO es
!>                el código de error distinto de cero devuelto por DLARRE o
!>                DLARRV, respectivamente.
!>
