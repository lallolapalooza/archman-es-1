Documentación de la Función/Subrutina

función de precisión doble dsdot (integer n, real, dimension(*) sx, integer incx, real, dimension(*) sy, integer incy)

DSDOT

Propósito:

!>
!> Calcula el producto interno de dos vectores con acumulación y resultado
!> de precisión extendida.
!>
!> Devuelve el producto interno D.P. acumulado en D.P., para S.P. SX y SY
!> DSDOT = suma para I = 0 a N-1 de SX(LX+I*INCX) * SY(LY+I*INCY),
!> donde LX = 1 si INCX .GE. 0, de lo contrario LX = 1+(1-N)*INCX, y LY
!> se define de manera similar usando INCY.
!>

Parámetros

N 
!>          N es ENTERO
!>         número de elementos en el(los) vector(es) de entrada
!>

SX

!>          SX es un array REAL, dimension(N)
!>         vector de precisión simple con N elementos
!>

INCX

!>          INCX es ENTERO
!>          espaciado de almacenamiento entre elementos de SX
!>

SY

!>          SY es un array REAL, dimension(N)
!>         vector de precisión simple con N elementos
!>

INCY

!>          INCY es ENTERO
!>         espaciado de almacenamiento entre elementos de SY
!>

Devuelve

DSDOT 
!>          DSDOT es de PRECISIÓN DOBLE
!>         DSDOT  producto interno de precisión doble (cero si N.LE.0)
!>
