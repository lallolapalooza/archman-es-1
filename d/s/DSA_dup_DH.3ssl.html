DSA_dup_DH(3ssl)

Paquete: openssl

Licencias: Apache-2.0

DSA_DUP_DH(3ssl) OpenSSL DSA_DUP_DH(3ssl)

NOMBRE

DSA_dup_DH - crear una estructura DH a partir de una estructura DSA

SINOPSIS

#include <openssl/dsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

DH *DSA_dup_DH(const DSA *r);

DESCRIPCIÓN

La función descrita en esta página está obsoleta. No existe un reemplazo directo, las aplicaciones deben usar las APIs de EVP_PKEY para operaciones Diffie-Hellman.

DSA_dup_DH() duplica parámetros/claves DSA como parámetros/claves DH. q se pierde durante esta conversión, pero los parámetros DH resultantes contienen su longitud.

VALORES DE RETORNO

DSA_dup_DH() devuelve la nueva estructura DH, y NULL en caso de error. Los códigos de error se pueden obtener con ERR_get_error(3).

NOTA

Tenga cuidado para evitar ataques de subgrupo pequeño al usar esto.

VER TAMBIÉN

DH_new(3), DSA_new(3), ERR_get_error(3)

HISTORIA

Esta función fue marcada como obsoleta en OpenSSL 3.0.
