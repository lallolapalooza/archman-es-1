subrutina dsysvx (character fact, character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DSYSVX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> DSYSVX utiliza la factorización de pivoteo diagonal para calcular la
!> solución de un sistema real de ecuaciones lineales A * X = B,
!> donde A es una matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación de condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A.
!>    La forma de la factorización es
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares superiores (inferiores) unitarias, y D es simétrica y de bloques diagonales con
!>    bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como una advertencia, pero la rutina continúa
!>    resolviendo para X y calculando cotas de error como se describe a continuación.
!>
!> 3. Se resuelve el sistema de ecuaciones para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          suministrada en la entrada o no.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de
!>                  A.  AF e IPIV no serán modificados.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte superior triangular
!>          N por N principal de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior de A
!>          no se referencia.  Si UPLO = 'L', la parte inferior triangular
!>          N por N principal de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array DOUBLE PRECISION, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene la matriz de bloques diagonales D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T, tal como fue calculada por DSYTRF.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>          devuelve la matriz de bloques diagonales D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como fue determinada por DSYTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como fue determinada por DSYTRF.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          La matriz B del lado derecho N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del número de condición recíproco de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          La cota estimada del error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de

WORK

!>          WORK es un array de PRECISIÓN DOBLE, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es un ENTERO
!>          La longitud de WORK. LWORK >= max(1,3*N), y para el mejor
!>          rendimiento, cuando FACT = 'N', LWORK >= max(1,3*N,N*NB), donde
!>          NB es el tamaño de bloque óptimo para DSYTRF.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

IWORK

!>          IWORK es un array de ENTEROS, de dimensión (N)
!>

INFO

!>          INFO es un ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, y i es
!>                <= N: D(i,i) es exactamente cero. La factorización
!>                       se ha completado pero el factor D es exactamente
!>                       singular, por lo que la solución y los límites de error no
!>                       se pudieron calcular. Se devuelve RCOND = 0.
!>                = N+1: D no es singular, pero RCOND es menor que la precisión de la máquina,
!>                       lo que significa que la matriz es singular
!>                       para la precisión de trabajo. Sin embargo, la
!>                       solución y los límites de error se calculan porque
!>                       hay varias situaciones en las que la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.
