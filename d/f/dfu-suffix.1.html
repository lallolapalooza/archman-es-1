DFU-SUFFIX(1) DFU-SUFFIX(1)

NOMBRE

dfu-suffix - agregar, verificar o eliminar el sufijo de archivo de firmware DFU

SINOPSIS

dfu-suffix [opciones] --add ARCHIVO_DFU

dfu-suffix --check ARCHIVO_DFU

dfu-suffix --delete ARCHIVO_DFU

dfu-suffix --help

dfu-suffix --version

DESCRIPCIÓN

El programa dfu-suffix se puede usar para agregar, verificar o eliminar un sufijo de archivo de firmware DFU, recomendado para emparejar de forma segura un archivo de firmware y un dispositivo.

Tenga en cuenta que el estándar DFU recomienda un sufijo, pero no lo requiere. Una herramienta host DFU como dfu-util reconocerá el sufijo y la usará para verificar que el dispositivo coincide, pero no transferirá el sufijo al dispositivo.

OPCIONES

-v, --vid ID_VENDEDOR
Especificar ID de vendedor USB (hexadecimal)
-p, --pid ID_PRODUCTO
Especificar ID de producto USB (hexadecimal)
-d, --did ID_DISPOSITIVO
Especificar ID de dispositivo USB (hexadecimal)
-S, --spec VERSION
Especificar la versión de la especificación DFU (hexadecimal)
-h, --help
Muestra un mensaje de ayuda.
-V, --version
Muestra la versión del software.

EJEMPLOS

dfu-suffix --vid 0123 --add firmware.dfu
Agrega un sufijo que coincide con el vendedor 0x0123 y el ID de producto 0x4567. Dado que el ID de producto y dispositivo no se especifican, contendrán el valor comodín 0xFFFF.
dfu-suffix --check firmware.dfu
Verifica el archivo firmware.dfu en busca de un sufijo DFU válido
dfu-suffix --delete firmware.dfu
Elimina un sufijo DFU válido del archivo firmware.dfu

VALORES DE SALIDA

0
Éxito (también si falta el sufijo)
-64
Error de uso

LIMITACIONES

dfu-suffix no puede distinguir un sufijo DFU roto (por ejemplo, inconsistencia en la suma de verificación) de un sufijo inexistente, por lo que solo se puede eliminar un sufijo válido.
