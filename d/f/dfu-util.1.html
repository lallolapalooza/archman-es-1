NOMBRE

dfu-util - Programador USB de Actualización de Firmware de Dispositivo (DFU)

SINOPSIS

dfu-util -l [-v] [-d vid:pid[,vid:pid]] [-p ruta] [-c configuración] [-i interfaz] [-a alt-intf] [-S serie[,serie]]

dfu-util [-v] [-d vid:pid[,vid:pid]] [-p ruta] [-c configuración] [-i interfaz] [-a alt-intf] [-S serie[,serie]] [-t tamaño] [-Z tamaño] [-w] [-s dirección] [-R] [-D|-U archivo]

dfu-util [-hV]

DESCRIPCIÓN

dfu-util es un programa que implementa el lado del host (computadora) del protocolo DFU (Actualización de Firmware de Dispositivo Universal) de USB.

dfu-util se comunica con dispositivos que implementan el lado del dispositivo del protocolo DFU de USB, y se usa a menudo para actualizar el firmware de dichos dispositivos.

OPCIONES

-l, --list
Lista los dispositivos USB conectados capaces de DFU.
-d, --device [PROVEEDOR en Tiempo de Ejecución]:[PRODUCTO en Tiempo de Ejecución][,[PROVEEDOR en Modo DFU]:[PRODUCTO en Modo DFU]]
Especifica los IDs de proveedor y/o producto en tiempo de ejecución y/o modo DFU del dispositivo DFU con el que trabajar. PROVEEDOR y PRODUCTO son números hexadecimales (no se necesita prefijo), "*" (coincidir con cualquiera), o "-" (no coincidir con nada). Por defecto, se considerará cualquier dispositivo capaz de DFU en modo de tiempo de ejecución o modo DFU.

Si solo tienes un dispositivo DFU compatible con los estándares conectado a tu computadora, este parámetro es opcional. Sin embargo, tan pronto como tengas múltiples dispositivos DFU conectados, dfu-util lo detectará y abortará, pidiéndote que especifiques qué dispositivo usar.

Si solo se especifican IDs en tiempo de ejecución (por ejemplo, "--device 1457:51ab"), entonces además de los IDs en tiempo de ejecución especificados, también se considerarán los dispositivos en modo DFU. Esto es beneficioso para permitir que un dispositivo capaz de DFU se encuentre nuevamente después de un cambio a modo DFU, ya que el proveedor y/o el ID del producto de un dispositivo generalmente cambian en modo DFU.

Si solo se especifican IDs en modo DFU (por ejemplo, "--device ,951:26"), entonces se ignorarán todos los dispositivos en tiempo de ejecución, lo que facilitará la selección de un dispositivo específico en modo DFU.

Si se especifican ambos IDs, en tiempo de ejecución y modo DFU (por ejemplo, "--device 1457:51ab,:2bc"), entonces los componentes no especificados del modo DFU usarán el valor en tiempo de ejecución especificado.

Ejemplos:

--device 1457:51ab,951:26

Trabaja con un dispositivo en modo de tiempo de ejecución con ID de proveedor 0x1457 e ID de producto 0x51ab, o en modo DFU con ID de proveedor 0x0951 e ID de producto 0x0026
--device 1457:51ab,:2bc

Trabaja con un dispositivo en modo de tiempo de ejecución con ID de proveedor 0x1457 e ID de producto 0x51ab, o en modo DFU con ID de proveedor 0x1457 e ID de producto 0x02bc
--device 1457:51ab

Trabaja con un dispositivo en modo de tiempo de ejecución con ID de proveedor 0x1457 e ID de producto 0x51ab, o en modo DFU con cualquier proveedor y producto
--device ,951:26

Trabaja con un dispositivo en modo DFU con ID de proveedor 0x0951 e ID de producto 0x0026
--device *,-

Trabaja con cualquier dispositivo en modo de tiempo de ejecución, e ignora cualquier dispositivo en modo DFU
--device ,

Ignora cualquier dispositivo en modo de tiempo de ejecución, y trabaja con cualquier dispositivo en modo DFU
-p, --path BUS-PUERTO. ... .PUERTO
Especifica la ruta al dispositivo DFU.
-c, --cfg NUM-CONFIG
Especifica la configuración del dispositivo DFU. Ten en cuenta que esto solo se usa para la coincidencia, la configuración no es establecida por dfu-util.
-i, --intf NUM-INTF
Especifica el número de interfaz DFU.
-a, --alt ALT
Especifica la configuración alternativa (altsetting) de la interfaz DFU por nombre o por número.
-S, --serial [SERIE en Tiempo de Ejecución][,[SERIE en Modo DFU]]
Especifica los números de serie en tiempo de ejecución y modo DFU utilizados para restringir aún más las coincidencias de dispositivos. Si varios dispositivos DFU idénticos están conectados simultáneamente a un sistema, el proveedor y el ID del producto serán insuficientes para seleccionar un solo dispositivo. En esta situación, puede ser posible usar este parámetro para especificar un número de serie que también debe coincidir.

Si solo se especifica un número de serie, entonces el mismo número de serie se utiliza tanto en tiempo de ejecución como en modo DFU. Un número de serie vacío coincidirá con cualquier número de serie en el modo correspondiente.

-t, --transfer-size TAMAÑO
Especifica el número de bytes por transferencia USB. El valor óptimo generalmente se determina automáticamente, por lo que esta opción rara vez es útil. Si necesita usar esta opción para un dispositivo, por favor repórtelo como un error.
-Z, --upload-size TAMAÑO
Especifica el tamaño de carga esperado, en bytes. Ten en cuenta que el valor solo se usa para escalar la barra de progreso, el tamaño real de la carga lo determina el dispositivo.
-U, --upload ARCHIVO
Lee el firmware del dispositivo y lo guarda en ARCHIVO.
-D, --download ARCHIVO
Escribe el firmware desde ARCHIVO al dispositivo. Cuando ARCHIVO es -, el firmware se lee desde la entrada estándar (stdin).
-R, --reset
Emite una señal de reinicio USB después de que la carga o descarga haya finalizado.
-E, --detach-delay SEGUNDOS
Al cargar o descargar, espera SEGUNDOS segundos a que el dispositivo se re-enumere después de enviar la solicitud de desconexión antes de rendirse. El valor por defecto es 5 segundos. Esta opción no tiene efecto con -e, ya que eso hace que dfu-util salga inmediatamente después de enviar la solicitud de desconexión.
-w, --wait
Espera hasta que aparezca el dispositivo correspondiente en el bus USB.
-s, --dfuse-address [DIRECCIÓN][:LONGITUD][:MODIFICADORES]
Especifica la dirección de destino para la descarga/carga binaria bruta en dispositivos DfuSe. NO uses esta opción para descargar archivos DfuSe (.dfu). Se puede especificar una longitud para las cargas. Los modificadores se pueden agregar después de la dirección, separados por dos puntos, para realizar comandos especiales de DfuSE como "leave" (salir) del modo DFU, "unprotect" (desproteger) y "mass-erase" (borrado masivo) de la memoria flash. Si se espera que el dispositivo se reinicie a sí mismo después de la operación, se debería agregar "will-reset" (se reiniciará). El modificador "force" (forzar) anulará algunas verificaciones de seguridad, y también es necesario para las operaciones de "unprotect" y "mass-erase".
-v, --verbose
Imprime más información sobre la operación de dfu-util. Una segunda opción -v añade más detalles. Una tercera opción -v activa el registro detallado de las solicitudes USB (salida de depuración de libusb).
-h, --help
Muestra un texto de ayuda y sale.
-V, --version
Muestra información de la versión y sale.

EJEMPLOS

Usando dfu-util en el proyecto OpenMoko

(con el hardware Neo1973)

dfu-util(1) — Arch Linux

NAME

dfu-util - utility for devices conforming to the USB Device Firmware Upgrade (DFU) class specification

SYNOPSIS

dfu-util [-V] [-v] [-q] [-h] [-d dev] [-p path] [-a alt] [-D file] [-R] [-U file] [-S serial] [-r] [-t timeout] [-s spec] [-U file] [-l]

DESCRIPTION

dfu-util is a user mode software utility to download (upload) firmware to (from) devices conforming to the USB Device Firmware Upgrade (DFU) class specification.

It supports DFU specification 1.0, 1.1 and 1.1a (DfuSe). It also supports legacy devices that only implement the DFU protocol without providing a DFU functional descriptor.

dfu-util uses libusb for its communication with the DFU device. The device must be in DFU mode when you run dfu-util.

OPTIONS

A list of options supported by dfu-util:

-V, --version
Print version and exit.

-v, --verbose
Increase verbosity. Can be used multiple times.

-q, --quiet
Decrease verbosity.

-h, --help
Print help and exit.

-d, --device dev
Force use of device dev. dev is a hexadecimal representation of the USB idVendor:idProduct pair, e.g. 0123:4567. If not specified, the first device found is used.

-p, --path path
Force use of device at USB path path. path is a comma-separated list of port numbers, e.g. 1-2.3. If not specified, the first device found is used.

-a, --alt alt
Select alternative interface alt. Defaults to 0.

-D, --download file
Download file to the device.

-R, --reset
Reset the device after download. This is equivalent to issuing a DFU detach (optional) and USB reset.

-U, --upload file
Upload from the device and write to file.

-S, --serial serial
Use device with serial number serial.

-r, --detach-kernel-driver
Attempt to detach the kernel driver. This is needed on some systems, like Linux, where the kernel driver might have claimed the device.

-t, --timeout timeout
Set the USB communication timeout to timeout milliseconds.

-s, --set-address spec
Set the USB address for the device. spec is in the format
offset[:size][+|-].
offset is the address in the DFU device memory map.
size is the number of bytes to transfer.
If '+' is appended, the transfer is assumed to be the last one for this interface.
If '-' is appended, the device is requested to leave DFU mode after the transfer.
This option is used together with -D or -U.

-l, --list
List all DFU devices found.

EXAMPLES

Flashing the rootfs:
$ dfu-util -a rootfs -R -D /path/to/openmoko-devel-image.jffs2

Flashing the kernel:
$ dfu-util -a kernel -R -D /path/to/uImage

Flashing the bootloader:
$ dfu-util -a u-boot -R -D /path/to/u-boot.bin

Copying a kernel into RAM:
$ dfu-util -a 0 -R -D /path/to/uImage

Once this has finished, the kernel will be available at the default load address of 0x32000000 in Neo1973 RAM. Note: You cannot transfer more than 2MB of data into RAM using this method.

Using dfu-util with a DfuSe device

Flashing a .dfu (special DfuSe format) file to the device:
$ dfu-util -D /path/to/dfuse-image.dfu

Reading out 1 KB of flash starting at address 0x8000000:
$ dfu-util -a 0 -s 0x08000000:1024 -U newfile.bin

Flashing a binary file to address 0x8004000 of device memory and ask the device to leave DFU mode:
$ dfu-util -a 0 -s 0x08004000:leave -D /path/to/image.bin
