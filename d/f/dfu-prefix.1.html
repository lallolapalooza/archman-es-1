DFU-PREFIX(1) DFU-PREFIX(1)

NOMBRE

dfu-prefix - añadir, comprobar o eliminar prefijo especial de archivo de firmware

SINOPSIS

dfu-prefix [ -s dirección | -L ] --add ARCHIVO_DFU

dfu-prefix [ -T | -L ] --check ARCHIVO_DFU

dfu-prefix [ -T | -L ] --delete ARCHIVO_DFU

dfu-prefix --help

dfu-prefix --version

DESCRIPCIÓN

El programa dfu-prefix se puede utilizar para añadir, comprobar o eliminar un prefijo utilizado por ciertos fabricantes de hardware. Se soporta el formato Stellaris de TI y el formato LPC de NXP.

Tenga en cuenta que un archivo de firmware DFU estándar no tiene concepto de prefijo, y una herramienta host DFU como dfu-util pasa el prefijo al dispositivo como parte de la carga útil normal del firmware.

OPCIONES

-s, --stellaris-address dirección
(en combinación con --add) Añade prefijo de dirección Stellaris de TI al archivo
-T, --stellaris
(en combinación con --delete o --check) Actúa sobre el prefijo de dirección Stellaris de TI del archivo
-L, --lpc-prefix
(en combinación con --add o --delete o --check) Utiliza el formato de prefijo DFU LPC de NXP
-h, --help
Muestra un mensaje de ayuda.
-V, --version
Muestra la versión del software.

EJEMPLOS

dfu-prefix --stellaris-address 0x0100 --add firmware.dfu
Añade un prefijo Stellaris con dirección de carga 0x0100
dfu-prefix --stellaris --check firmware.dfu
Comprueba si el archivo firmware.dfu tiene un prefijo Stellaris
dfu-prefix --lpc-prefix --delete firmware.dfu
Elimina un prefijo LPC del archivo firmware.dfu

VALORES DE SALIDA

0
Éxito (también si falta el prefijo)
-64
Error de uso
