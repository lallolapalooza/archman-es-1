dfc(1) COMANDOS DE USUARIO dfc(1)

NOMBRE

dfc - informa sobre el uso del espacio en el sistema de archivos con estilo

SINOPSIS

dfc [OPCIÓN(ES)] [-c CUÁNDO] [-e FORMATO] [-p NOMBREFS] [-q ORDENAR POR] [-t TIPOFS] [-u UNIDAD]

DESCRIPCIÓN

dfc(1) es una herramienta similar a df(1) excepto que es capaz de mostrar un gráfico junto con los datos y puede usar color (el modo de color es "color-auto" por defecto pero puede cambiarlo con la opción "-c").

El tamaño disponible corresponde al espacio disponible desde el punto de vista de un usuario y no desde la perspectiva de root (es decir: usa f_bavail en lugar de f_bfree).

Sin ningún argumento, el tamaño se muestra en formato legible para humanos. Tenga en cuenta que al usar el formato legible para humanos, puede haber algo de redondeo al calcular el tamaño. Si desea la máxima precisión, use la opción "-u" y elija la unidad.

dfc(1) también tiene una función incorporada que hace que la salida se ajuste automáticamente según el ancho de la terminal. Si desea anular este comportamiento, use la opción "-f".

OPCIONES

-a
Mostrar todo (no omitir ningún sistema de archivos).
-b
No mostrar la barra del gráfico.
-c [CUÁNDO]
Elija el modo de color donde CUÁNDO es una de las siguientes subopciones:

"always": El color se usará siempre, sin importar qué sea "stdout".

"auto": Este es el valor predeterminado cuando "-c" no está activado. El color se usa solo si "stdout" es una terminal. Por ejemplo, el color se desactivará con esta opción si redirige la salida de dfc(1) a otro comando.

"never": El color nunca se usará.

-d
Mostrar el tamaño usado.
-e [FORMATO]
Le permite exportar la salida de dfc(1) al FORMATO especificado. FORMATO es uno de los siguientes:

"csv": Salida como tipo de archivo "valores separados por comas". Ejemplo de uso:

dfc -e csv > foo.csv

"html": La salida está formateada en HTML. Ejemplo de uso:

dfc -e html -Tadiso -c always > index.html

"json": La salida está formateada en JSON. Ejemplo de uso:

dfc -e json -Tisod > report.json

"tex": La salida está formateada en TeX. Ejemplo de uso:

dfc -e tex -c always > report.tex

"text": Salida de texto (predeterminado).

-f
Anula el comportamiento de autoajuste forzando la visualización de la información. Esta opción puede ser útil al redirigir la salida de dfc(1).
-h
Mostrar un texto de ayuda breve.
-i
Mostrar información sobre inodos.
-l
Mostrar solo información sobre sistemas de archivos montados localmente.
-m
Usar unidades SI (métricas) (es decir: el tamaño se calcula usando potencias de 10 en lugar de potencias de 2).
-M
No imprimir "montado en".
-n
No imprimir la cabecera.
-o
Mostrar las opciones de montaje.
-p [NOMBREFS]
Le permite realizar un filtrado por nombre del sistema de archivos. NOMBREFS puede ser cualquier cosa. Por ejemplo, si desea ver solo el sistema de archivos cuyo nombre comienza con "/dev", usaría lo siguiente:

dfc -p /dev

Esto mostrará solo los sistemas de archivos cuyos nombres son, por ejemplo, "/dev/sda1", "/dev/root", "/dev", etc.

Se admite la selección múltiple. En este caso, NOMBREFS debe ser una lista separada por comas (sin espacios). Por ejemplo, si desea filtrar "/dev" y "tmpfs", usaría lo siguiente:

dfc -p /dev,tmpfs

También puede usar coincidencia negativa para filtrar la salida. Para hacer esto, solo necesita anteponer un "-" a NOMBREFS. En el siguiente ejemplo, dfc(1) mostrará todos los nombres de sistemas de archivos excepto los mencionados:

dfc -p -proc,/dev/sdc,run

-q [ORDENAR POR]
Le permite ordenar la salida basándose en ORDENAR POR.

ORDENAR POR puede tomar uno de estos tres valores: "name", "type", "mount".

Al usar "name", la salida se ordena por el nombre del sistema de archivos. Al usar "type", la salida se ordena por el tipo de sistema de archivos. Al usar "mount", la salida se ordena por los puntos de montaje.

-s
Sumar el uso total.
-t [TIPOFS]
Le permite realizar un filtrado por tipo de sistema de archivos. TIPOFS podría tomar cualquier valor de sistema de archivos conocido. Por ejemplo, "ext4", "ufs", "tmpfs", "reiserfs", etc. También puede usar filtrado con comodines, igual que con la opción -p. Por ejemplo, si usa lo siguiente:


dfc -t ext

Esto permitirá que cualquier tipo de sistema de archivos cuyo nombre comience con "ext" pase por el filtro, por ejemplo, "ext2", "ext3" y "ext4".

La selección múltiple en el sistema de archivos también es posible. En este caso, TIPOFS debe ser una lista separada por comas (sin espacios). Por ejemplo, si desea filtrar "ext4" y "tmpfs", usaría lo siguiente:

dfc -t ext4,tmpfs

También puede usar coincidencia negativa para filtrar la salida. Para hacer esto, solo necesita anteponer un "-" a TIPOFS. En el siguiente ejemplo, dfc(1) mostrará todos los tipos de sistemas de archivos excepto los mencionados:

dfc -t -rootfs,tmpfs

-T
Mostrar el tipo de sistema de archivos.
-u [UNIDAD]
Mostrar el tamaño usando la unidad especificada. UNIDAD puede tomar uno de los siguientes valores:

"h": Legible para humanos (predeterminado cuando no se usa la opción "-u").

"b": Mostrar bytes.

"k": Mostrar el tamaño usando Kio.

"m": Mostrar el tamaño usando Mio.

"g": Mostrar el tamaño usando Gio.

"t": Mostrar el tamaño usando Tio.

"p": Mostrar el tamaño usando Pio.

"e": Mostrar el tamaño usando Eio.

"z": Mostrar el tamaño usando Zio.

"y": Mostrar el tamaño usando Yio.

NOTA: Al usar la opción "-u" junto con la opción "-m", estas subopciones son reemplazadas por sus contrapartes SI.

-v
Imprimir la versión de dfc(1) y salir.
-w
Usar una barra más ancha para el gráfico.
-W
Nombre de ruta ancho (evita la truncación del nombre de archivo). Puede requerir una pantalla más grande.

ARCHIVO DE CONFIGURACIÓN

El archivo de configuración es opcional. Le permite cambiar los colores predeterminados de dfc(1), los valores cuando cambian los colores y el símbolo del gráfico en modo texto, y modificar los colores usados en la exportación HTML.

Si desea usarlo, colóquelo aquí:

$XDG_CONFIG_HOME/dfc/dfcrc

Si su sistema operativo no soporta la Especificación de Directorio Base XDG, debe colocarse aquí:

$HOME/.config/dfc/dfcrc

O, como última opción:

$HOME/.dfcrc

NOTA: Las dos últimas opciones solo pueden elegirse si su SO no soporta la Especificación de Directorio Base XDG.
