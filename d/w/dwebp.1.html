NOMBRE

dwebp - descomprime un archivo WebP a un archivo de imagen

SINOPSIS

dwebp [opciones] archivo_entrada.webp

DESCRIPCIÓN

Esta página del manual documenta el comando dwebp.

dwebp descomprime archivos WebP a imágenes PNG, PAM, PPM o PGM. Nota: Los archivos WebP animados no son compatibles.

OPCIONES

Las opciones básicas son:

-h
Muestra el resumen de uso.
-version
Muestra el número de versión (como mayor.menor.revisión) y sale.
-o cadena
Especifica el nombre del archivo de salida (PNG por defecto). Usar "-" como nombre de salida dirigirá la salida a 'stdout'.
-- cadena
Especifica explícitamente el archivo de entrada. Esta opción es útil si el archivo de entrada comienza con un '-', por ejemplo. Esta opción debe aparecer al final. Cualquier otra opción posterior será ignorada. Si el archivo de entrada es "-", los datos se leerán de stdin en lugar de un archivo.
-bmp
Cambia el formato de salida a BMP sin comprimir.
-tiff
Cambia el formato de salida a TIFF sin comprimir.
-pam
Cambia el formato de salida a PAM (conserva el canal alfa).
-ppm
Cambia el formato de salida a PPM (descarta el canal alfa).
-pgm
Cambia el formato de salida a PGM. La salida consiste en muestras de luma/croma en lugar de RGB, usando la disposición IMC4. Esta opción es principalmente para fines de verificación y depuración.
-yuv
Cambia el formato de salida a YUV crudo. La salida consiste en muestras de luma/croma-U/croma-V en lugar de RGB, guardadas secuencialmente como planos individuales. Esta opción es principalmente para fines de verificación y depuración.
-nofancy
No usar el escalador de alta calidad (fancy) para YUV420. Esto puede resultar en bordes dentados (especialmente los rojos), pero debería ser más rápido.
-nofilter
No usar el proceso de filtrado en bucle, incluso si es requerido por el flujo de bits. Esto puede producir bloques visibles en la salida no conforme, pero hará que la decodificación sea más rápida.
-dither intensidad
Especifica una intensidad de dithering entre 0 y 100. El dithering es un efecto de posprocesamiento aplicado a los componentes de croma en compresión con pérdida. Ayuda a suavizar gradientes y evitar artefactos de banding.
-alpha_dither
Si el archivo comprimido contiene un plano de transparencia que fue cuantizado durante la compresión, este indicador permitirá hacer dithering al plano reconstruido para generar gradientes de transparencia más suaves.
-nodither
Desactiva todo el dithering (por defecto).
-mt
Usar multihilo para la decodificación, si es posible.
-crop posición_x posición_y ancho alto
Recortar la imagen decodificada a un rectángulo con la esquina superior izquierda en las coordenadas (posición_x, posición_y) y tamaño ancho x alto. El área de recorte debe estar completamente contenida dentro del rectángulo fuente. La esquina superior izquierda se alineará a coordenadas pares si es necesario. Esta opción está pensada para reducir la memoria necesaria para recortar imágenes grandes. Nota: el recorte se aplica antes de cualquier escalado.
-flip
Voltear la imagen decodificada verticalmente (puede ser útil para texturas de OpenGL, por ejemplo).
-resize, -scale ancho alto
Redimensionar la imagen decodificada a las dimensiones ancho x alto. Esta opción está principalmente pensada para reducir la memoria necesaria para decodificar imágenes grandes, cuando solo se necesita una versión pequeña (miniatura, vista previa, etc.). Nota: el escalado se aplica después del recorte. Si uno (pero no ambos) de los parámetros ancho o alto es 0, el valor se calculará preservando la relación de aspecto.
-quiet
No imprimir nada.
-v
Imprimir información adicional (tiempo de decodificación en particular).
-noasm
Desactivar todas las optimizaciones de ensamblado.

ESTADO DE SALIDA

Si no hubo problemas durante la ejecución, dwebp sale con el valor de la constante C EXIT_SUCCESS. Esto suele ser cero.

Si ocurre un error, dwebp sale con el valor de la constante C EXIT_FAILURE. Esto suele ser uno.

EJEMPLOS

dwebp picture.webp -o output.png
dwebp picture.webp -ppm -o output.ppm
dwebp -o output.ppm -- ---picture.webp
cat picture.webp | dwebp -o - -- - > output.ppm
