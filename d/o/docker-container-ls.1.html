Lista los contenedores en el repositor

Filtro

s

Filtra la salida basándose en estas condiciones:
- ancestor=([:tag]||image@digest ⟨mailto:image@digest⟩)
contenedores creados a partir de una imagen o de un descendiente.
- before=(|)
- expose=([/]|/[])
- exited= un código de salida de
- health=(starting|healthy|unhealthy|none)
- id= un ID de contenedor
- isolation=(default|process|hyperv) (solo para el demonio de Windows)
- is-task=(true|false)
- label= o label==
- name= un nombre de contenedor
- network=(|)
- publish=([/]|/[])
- since=(|)
- status=(created|restarting|removing|running|paused|exited)

Format

o

La opción de formato (--format) muestra la salida de los contenedores de forma legible utilizando una plantilla de

Go.

Los marcadores de posición válidos para la plantilla de Go se enumeran a continuación:
- .ID - ID del contenedor.
- .Image - ID de la imagen.
- .Command - Comando entrecomillado.
- .CreatedAt - Hora en que se creó el contenedor.
- .RunningFor - Tiempo transcurrido desde que se inició el contenedor.
- .Ports - Puertos expuestos.
- .Status - Estado del contenedor.
- .Size - Tamaño en disco del contenedor.
- .Names - Nombres de los contenedores.
- .Labels - Todas las etiquetas asignadas al contenedor.
- .Label - Valor de una etiqueta específica para este contenedor.
Por ejemplo '{{.Label "com.docker.swarm.cpu"}}'.
- .Mounts - Nombres de los volúmenes montados en este contenedor.
- .Networks - Nombres

de las redes conectad
as a este contenedor.
