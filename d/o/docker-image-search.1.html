NOMBRE

podman-search - Buscar una imagen en un registro

SINOPSIS

podman search [opciones] término

DESCRIPCIÓN

podman search busca en un registro o una lista de registros una imagen coincidente. El usuario puede especificar qué registro buscar anteponiendo el registro al término de búsqueda (por ejemplo, registry.fedoraproject.org/fedora). Por defecto, se utilizan todos los registros de búsqueda no calificados en containers-registries.conf(5).

El número de resultados por defecto es 25. El número de resultados se puede limitar usando la opción --limit. Si se buscan varios registros, el límite se aplica a cada registro. La salida se puede filtrar usando la opción --filter. Para obtener todas las imágenes disponibles en un registro sin un término de búsqueda específico, el usuario puede simplemente introducir el nombre del registro con una barra inclinada al final (ejemplo registry.fedoraproject.org/).

Tenga en cuenta que podman search no es una forma fiable de determinar la presencia o existencia de una imagen. El comportamiento de búsqueda de la API de distribución de Docker v1 y v2 es específico de la implementación de cada registro. Algunos registros pueden no admitir la búsqueda en absoluto. Tenga en cuenta además que la búsqueda sin término de búsqueda solo funciona para registros que implementan la API v2.

podman [OPCIONES GENERALES]

podman search [OPCIONES GENERALES]

podman search [OPCIONES] TÉRMINO

OPCIONES

--authfile=ruta

Ruta del archivo de autenticación. Por defecto es ${XDG_RUNTIME_DIR}/containers/auth.json en Linux, y $HOME/.config/containers/auth.json en Windows/macOS. El archivo es creado por podman login. Si el estado de autorización no se encuentra allí, se consulta $HOME/.docker/config.json, que se establece usando docker login.

Nota: También existe la opción de anular la ruta por defecto del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. Esto se puede hacer con export REGISTRY_AUTH_FILE=ruta.

--cert-dir=ruta

Utiliza los certificados en ruta (*.crt, *.cert, *.key) para conectarse al registro. (Por defecto: /etc/containers/certs.d) Para más detalles, consulta containers-certs.d(5). (Esta opción no está disponible con el cliente Podman remoto, incluyendo máquinas Mac y Windows (excluyendo WSL2)).

--compatible

Después del nombre y la descripción, muestra también los descriptores de estrellas, oficiales y automatizados como lo hace Docker. Podman no muestra estos descriptores por defecto ya que no son compatibles con la mayoría de los registros de contenedores públicos.

--creds=[nombredeusuario[:contraseña]]

El [nombredeusuario[:contraseña]] a usar para autenticarse con el registro, si es necesario. Si uno o ambos valores no se proporcionan, aparece un aviso en la línea de comandos y se puede introducir el valor. La contraseña se introduce sin eco.

Tenga en cuenta que las credenciales especificadas solo se utilizan para autenticarse en los registros de destino. No se utilizan para espejos ni cuando el registro se reescribe (ver containers-registries.conf(5)); para autenticarse en ellos, considere usar un archivo containers-auth.json(5).

--filter, -f=filtro

Filtra la salida basándose en las condiciones proporcionadas (por defecto [])

Los filtros soportados son:

  • stars (int) - número mínimo de estrellas requeridas para mostrar las imágenes
  • is-automated (booleano - true | false) - si la imagen está automatizada o no
  • is-official (booleano - true | false) - si la imagen es oficial o no

--format=formato

Cambia el formato de salida a una plantilla Go

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Automated "[OK]" si la imagen está automatizada
.Description Descripción de la imagen
.Index Registro
.Name Nombre de la imagen
.Official "[OK]" si la imagen es oficial
.Stars Número de estrellas de la imagen
.Tag Etiqueta del repositorio

Nota: usa .Tag solo si --list-tags está establecido.

--help, -h

Imprime el mensaje de uso

--limit=límite

Limita el número de resultados (por defecto 25). Nota: Los resultados de cada registro se limitan a este valor. Ejemplo: si el límite es 10 y se buscan dos registros, el número total de resultados es 20, 10 de cada uno (si hay al menos 10 coincidencias en cada uno). El orden de los resultados de la búsqueda es el orden en que el punto final de la API devuelve los resultados.

--list-tags

Lista las etiquetas disponibles en el repositorio para la imagen especificada. Nota: --list-tags requiere que el término de búsqueda sea un nombre de imagen completamente especificado. El resultado contiene el nombre de la imagen y su etiqueta, una línea por cada etiqueta asociada a la imagen.

--no-trunc

No truncar la salida (por defecto false).

--tls-verify

Requiere HTTPS y verifica los certificados al contactar con los registros (por defecto: true). Si se establece explícitamente en true, se utiliza la verificación TLS. Si se establece en false, no se utiliza la verificación TLS. Si no se especifica, se utiliza la verificación TLS a menos que el registro de destino esté listado como un registro inseguro en containers-registries.conf(5)

EJEMPLOS

Busca imágenes que contengan el nombre especificado, devolviendo las tres primeras imágenes de cada registro definido.

$ podman search --limit 3 fedora
NAME                                           DESCRIPTION
registry.fedoraproject.org/f29/fedora-toolbox
registry.fedoraproject.org/f30/fedora-toolbox
registry.fedoraproject.org/f31/fedora-toolbox
docker.io/library/fedora                       Official Docker builds of Fedora
docker.io/kasmweb/fedora-37-desktop            Fedora 37 desktop for Kasm Workspaces
docker.io/kasmweb/fedora-38-desktop            Fedora 38 desktop for Kasm Workspaces
quay.io/fedora/fedora
quay.io/containerdisks/fedora                  # Fedora Containerdisk Images  <img src="htt...
quay.io/fedora/fedora-minimal

Tenga en cuenta que los descriptores de Estrellas, Oficial y Automatizado solo están disponibles en Docker Hub y, por lo tanto, no se muestran por defecto.

$ podman search --format "{{.Name}}\t{{.Stars}}\t{{.Official}}" alpine --limit 3
docker.io/library/alpine       7956        [OK]
docker.io/alpine/git           192
docker.io/anapsix/alpine-java  474
quay.io/libpod/alpine          0
quay.io/vqcomms/alpine-tools   0
quay.io/wire/alpine-deps       0

Busca y lista las etiquetas para la imagen especificada, devolviendo las cuatro primeras imágenes de cada registro definido.

$ podman search --list-tags registry.access.redhat.com/ubi8 --limit 4
NAME                             TAG
registry.access.redhat.com/ubi8  8.4-211
registry.access.redhat.com/ubi8  8.4-206.1626828523-source
registry.access.redhat.com/ubi8  8.4-199
registry.access.redhat.com/ubi8  8.4-211-source

Nota: Esto solo funciona con registros que implementan la API v2. Si se intenta con un registro v1, se devuelve un error.

ARCHIVOS

registries.conf (/etc/containers/registries.conf)

registries.conf es el archivo de configuración que especifica qué registros de contenedores se consultan al completar nombres de imagen que no incluyen una porción de registro o dominio.
