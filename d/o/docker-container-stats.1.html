docker-container-stats(1)

Paquete: docker

Licencias: Apache-2.0

DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker-container-stats - Muestra un flujo en vivo de las estadísticas de uso de recursos de uno o más contenedores

SINOPSIS

docker container stats [OPCIONES] [CONTENEDOR...]

DESCRIPCIÓN

Muestra un flujo en vivo de las estadísticas de uso de recursos de uno o más contenedores.

Formato

Formatea la salida utilizando la plantilla Go dada.
Marcadores de posición válidos:
.Container - Nombre o ID del contenedor.
.Name - Nombre del contenedor.
.ID - ID del contenedor.
.CPUPerc - Porcentaje de CPU.
.MemUsage - Uso de memoria.
.NetIO - E/S de red.
.BlockIO - E/S de bloque.
.MemPerc - Porcentaje de memoria (No disponible en Windows).
.PIDs - Número de PIDs (No disponible en Windows).

EJEMPLOS

Ejecutando docker container stats en todos los contenedores en ejecución.

$ docker container stats
CONTAINER           CPU %               MEM USAGE / LIMIT     MEM %               NET I/O             BLOCK I/O
1285939c1fd3        0.07%               796 KiB / 64 MiB        1.21%               788 B / 648 B       3.568 MB / 512 KB
9c76f7834ae2        0.07%               2.746 MiB / 64 MiB      4.29%               1.266 KB / 648 B    12.4 MB / 0 B
d1ea048f04e4        0.03%               4.583 MiB / 64 MiB      6.30%               2.854 KB / 648 B    27.7 MB / 0 B

Ejecutando docker container stats en múltiples contenedores por nombre e ID.

$ docker container stats fervent_panini 5acfcb1b4fd1
CONTAINER           CPU %               MEM USAGE/LIMIT     MEM %               NET I/O
5acfcb1b4fd1        0.00%               115.2 MiB/1.045 GiB   11.03%              1.422 kB/648 B
fervent_panini      0.02%               11.08 MiB/1.045 GiB   1.06%               648 B/648 B

Ejecutando docker container stats con formato personalizado en todos los contenedores (en ejecución y detenidos).

$ docker container stats --all --format "table {{.ID}}\t{{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}"
CONTAINER ID                                                       NAME                     CPU %               MEM USAGE / LIMIT
c9dfa83f0317f87637d5b7e67aa4223337d947215c5a9947e697e4f7d3e0f834   ecstatic_noether         0.00%               56KiB / 15.57GiB
8f92d01cf3b29b4f5fca4cd33d907e05def7af5a3684711b20a2369d211ec67f   stoic_goodall            0.07%               32.86MiB / 15.57GiB
38dd23dba00f307d53d040c1d18a91361bbdcccbf592315927d56cf13d8b7343   drunk_visvesvaraya       0.00%               0B / 0B
5a8b07ec4cc52823f3cbfdb964018623c1ba307bce2c057ccdbde5f4f6990833   big_heisenberg           0.00%               0B / 0B

drunk_visvesvaraya y big_heisenberg son contenedores detenidos en el ejemplo anterior.

Ejecutando docker container stats en formato JSON.

$ docker container stats --format json
{"BlockIO":"43.9MB / 0B","CPUPerc":"0.00%","Container":"14c505d03da8","ID":"14c505d03da8","MemPerc":"0.21%","MemUsage":"4.242MiB / 1.944GiB","Name":"registry","NetIO":"4.17kB / 0B","PIDs":"13"}

OPCIONES

-a, --all[=false] Mostrar todos los contenedores (por defecto solo muestra los en ejecución)

--format="" Formatea la salida usando una plantilla personalizada: 'table': Imprime la salida en formato de tabla con encabezados de columna (por defecto) 'table PLANTILLA': Imprime la salida en formato de tabla usando la plantilla Go dada 'json': Imprime en formato JSON 'PLANTILLA': Imprime la salida usando la plantilla Go dada. Consulte https://docs.docker.com/go/formatting/ para más información sobre el formato de salida con plantillas.

--no-stream[=false] Deshabilita el flujo de estadísticas y solo obtiene el primer resultado.

--no-trunc[=false] No truncar la salida.
