NOMBRE

doxygen2man - Una herramienta para generar páginas man a partir de archivos XML de Doxygen

SINOPSIS

doxygen2man [OPCIONES] <archivo XML>

DESCRIPCIÓN

Esta es una herramienta para generar páginas man de API a partir de un archivo de encabezado anotado con Doxygen. Primero, ejecuta doxygen en el archivo y luego ejecuta este programa contra el archivo XML principal que creó y el directorio que contiene los archivos auxiliares. Luego generará muchos archivos man de tipo *.3 que podrá incluir con su biblioteca.

Deberá invocar este programa una vez por cada archivo .h de su biblioteca, utilizando el nombre del archivo .xml generado. Este archivo normalmente se llamará algo como <archivo-incluido>_8h.xml, por ejemplo qbipcs_8h.xml

Si desea una salida HTML, simplemente use nroff en los archivos generados, como lo haría con cualquier otra página man.

OPCIONES

-a
Imprime un volcado ASCII de las páginas man en la salida estándar
-m
Escribe archivos de página man en <directorio de salida>
-P
Imprime la sección PARAMS
-s <n>
Escribe las páginas man en la sección <n> (predeterminado 3)
-p <paquete>
Usa el nombre de <paquete>. Predeterminado <Package>
-H <encabezado>
Establece el encabezado (predeterminado
-I <incluir>
Establece el nombre del archivo de inclusión (predeterminado el del archivo XML o unknown.h)
-i <prefijo>
Establece el prefijo para los archivos de encabezado (por ejemplo, qb/) si están instalados en un subdirectorio de /usr/include
-C <empresa>
Establece el nombre de la empresa en los derechos de autor (predeterminado Red Hat)
-D <fecha>
Fecha a imprimir en la parte superior de las páginas man (formato no verificado, predeterminado: hoy)
-Y <año>
Año a imprimir al final de la línea de derechos de autor (predeterminado: año actual)
-S <año>
Año a imprimir al principio de la línea de derechos de autor (predeterminado: 2010)
-o <dir>
Escribe todas las páginas man en <dir> (predeterminado .)
-d <dir>
Directorio para los archivos XML (./xml/)
-c
Usa la línea de Copyright del archivo de encabezado como línea de copyright en la página man. Esto requiere que doxygen2man tenga acceso al archivo .h original (ver opción -O a continuación) y que la línea de Copyright tenga un formato definido. Debería estar dentro de las primeras 10 líneas del archivo y comenzar con el texto " * Copyright". Si no se encuentra esta línea, se utilizará el año actual o el proporcionado por la opción -Y.
-O
Especifica el directorio que contiene los archivos de encabezado originales. Esto es (actualmente) solo utilizado por la opción -c anterior.
-h
Imprime el texto de uso

VER TAMBIÉN
