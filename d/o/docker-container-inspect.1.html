DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker-container-inspect - Muestra información detallada sobre uno o más contenedores

SINOPSIS

docker container inspect [OPCIONES] CONTENEDOR [CONTENEDOR...]

DESCRIPCIÓN

Muestra información detallada sobre uno o más contenedores

OPCIONES

-f, --format="" Formatea la salida usando una plantilla personalizada: 'json': Imprime en formato JSON 'PLANTILLA': Imprime la salida usando la plantilla Go dada. Consulta https://docs.docker.com/go/formatting/ para obtener más información sobre el formato de la salida con plantillas.

-s, --size[=false] Muestra los tamaños totales de los archivos
