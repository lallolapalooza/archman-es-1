NOMBRE

docker-stats - Muestra una transmisión en vivo de estadísticas de uso de recursos de contenedores

SINOPSIS

docker stats [OPCIONES] [CONTENEDOR...]

DESCRIPCIÓN

Alias de docker container stats.

OPCIONES

-a, --all[=false] Muestra todos los contenedores (por defecto solo muestra los en ejecución)

--format="" Formatea la salida usando una plantilla personalizada: 'table': Imprime la salida en formato de tabla con encabezados de columna (predeterminado) 'table TEMPLATE': Imprime la salida en formato de tabla usando la plantilla Go dada 'json': Imprime en formato JSON 'TEMPLATE': Imprime la salida usando la plantilla Go dada. Consulte https://docs.docker.com/go/formatting/ para obtener más información sobre el formato de salida con plantillas

--no-stream[=false] Deshabilita la transmisión de estadísticas y solo obtiene el primer resultado

--no-trunc[=false] No trunca la salida
