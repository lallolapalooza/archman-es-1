dovecot-lda - Agente de entrega local de correo de Dovecot

SINOPSIS

dovecot-lda [-ek] [-a dirección] [-c archivo_de_configuración] [-d nombre_de_usuario] [-f remitente_del_sobre] [-m buzón] [-o ajuste=valor] [-p ruta] [-r dirección]

DESCRIPCIÓN

El dovecot-lda es un agente de entrega local de correo que toma el correo de un MTA y lo entrega en el buzón de un usuario, manteniendo al mismo tiempo los archivos de índice de Dovecot actualizados.

Las características principales de dovecot-lda son:

  • Indexación del buzón durante la entrega del correo, lo que proporciona un acceso más rápido al buzón posteriormente
  • Aplicación de cuotas mediante el plugin de cuotas
  • Soporte para el lenguaje Sieve mediante el plugin Pigeonhole sieve

OPCIONES

Opciones aceptadas por dovecot-lda:

-a dirección

Dirección de destino (p. ej. usuario+ext@dominio). Si no se especifica, el valor predeterminado se basa en el ajuste lda_original_recipient_header .

-c archivo_de_configuración

Ruta alternativa al archivo de configuración.

-d nombre_de_usuario

Nombre de usuario de destino. nombre_de_usuario. Si se proporciona, la información del usuario se busca en la base de datos de usuarios (userdb). Se usa típicamente con usuarios virtuales, pero no necesariamente con usuarios del sistema.

-e

Si el correo es rechazado, escribe el motivo del rechazo en stderr y sale con el estado 77 (EX_NOPERM). Por defecto, envía un correo de rechazo por sí mismo.

-f remitente_del_sobre

Dirección del remitente del sobre. Si no se especifica y los datos del mensaje comienzan con una línea válida de estilo mbox "From " , la dirección se toma de ella.

-k

No borra todo el entorno al inicio.

-m buzón

  • Si se usa el plugin Sieve, este buzón se usa como el buzón de la acción keep . También se usa si no hay un script Sieve o si el script falla por alguna razón.

-o ajuste=valor

Anula el ajuste de configuración ajuste de /etc/dovecot/dovecot.conf y de la base de datos de usuarios (userdb) con el valordado. Para anular múltiples ajustes, la opción -o puede especificarse varias veces.

-p ruta

Ruta al correo a entregar en lugar de leerlo de stdin. Si se usa maildir, el archivo se enlaza de forma dura con el destino si es posible. Esto permite que un solo correo sea entregado a múltiples usuarios mediante enlaces duros, pero actualmente también impide que deliver actualice el archivo de caché, por lo que no debería usarse a menos que sea realmente necesario.

-r dirección

Dirección final del destinatario del sobre. Por defecto es -a dirección , pero puede diferir si, por ejemplo, se usan alias o al descartar la parte +detail .

ESTADO DE SALIDA

dovecot-lda saldrá con uno de los siguientes valores:

0

La entrega fue exitosa. (EX_OK)

64

Parámetro no válido. (EX_USAGE)

67

Usuario destinatario desconocido. (EX_NOUSER)

77

Se usó la opción -e y el correo fue rechazado. Esto ocurre típicamente cuando el usuario supera su cuota y quota_full_tempfail = no está configurado. (EX_NOPERM)

75

Un fallo temporal. Se devuelve para casi todos los fallos. Consulta el archivo de registro para más detalles. (EX_TEMPFAIL)
