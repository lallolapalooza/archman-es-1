NOMBRE

doveadm-dict - Dovecot mail dictionary utility

SINOPSIS

doveadm [OPCIONES GLOBALES] dict unlimit [-u usuario] [-t timestamp-milisegundos] nombre-filtro-config clave

doveadm [OPCIONES GLOBALES] mail dict unlimit [-A | -u usuario | -F archivo] [-S ruta-socket] [-t timestamp-milisegundos] nombre-filtro-config clave

doveadm [OPCIONES GLOBALES] dict set [-t timestamp-milisegundos] [-e segundos-caducidad] nombre-filtro-config clave valor

doveadm [OPCIONES GLOBALES] mail dict set [-A | -u usuario | -F archivo] [-S ruta-socket] [-t timestamp-milisegundos] [-e segundos-caducidad] nombre-filtro-config clave valor

doveadm [OPCIONES GLOBALES] dict unset [-u usuario] [-t timestamp-milisegundos] nombre-filtro-config clave

doveadm [OPCIONES GLOBALES] mail dict unset [-A | -u usuario | -F archivo] [-S ruta-socket] [-t timestamp-milisegundos] nombre-filtro-config clave

DESCRIPCIÓN

Las operaciones de diccionario de correo permiten gestionar los datos almacenados en los diccionarios de Dovecot. Estos diccionarios se utilizan para almacenar metadatos y configuraciones específicas del buzón.

OPCIONES GLOBALES

Las opciones globales se aplican a todos los comandos de doveadm y permiten configurar el comportamiento general de la herramienta, como la especificación de archivos de configuración alternativos o el control de la salida.

OPCIONES

unlimit

doveadm [OPCIONES GLOBALES] dict unlimit [-u usuario] [-t timestamp-milisegundos] nombre-filtro-config clave

doveadm [OPCIONES GLOBALES] mail dict unlimit [-A | -u usuario | -F archivo] [-S ruta-socket] [-t timestamp-milisegundos] nombre-filtro-config clave

Elimina la caducidad de una clave en el diccionario, dejándola persistente.

-t timestamp-milisegundos

Establece la marca de tiempo también.

clave

La clave a eliminar la caducidad.

set

doveadm [OPCIONES GLOBALES] dict set [-t timestamp-milisegundos] [-e segundos-caducidad] nombre-filtro-config clave valor

doveadm [OPCIONES GLOBALES] mail dict set [-A | -u usuario | -F archivo] [-S ruta-socket] [-t timestamp-milisegundos] [-e segundos-caducidad] nombre-filtro-config clave valor

Establece/crea claves en el diccionario.

-t timestamp-milisegundos

Establece la marca de tiempo también.

-e segundos-caducidad

Establece la duración de caducidad de la clave también.

clave

La clave a establecer.

valor

El valor a establecer.

unset

doveadm [OPCIONES GLOBALES] dict unset [-u usuario] [-t timestamp-milisegundos] nombre-filtro-config clave

doveadm [OPCIONES GLOBALES] mail dict unset [-A | -u usuario | -F archivo] [-S ruta-socket] [-t timestamp-milisegundos] nombre-filtro-config clave

Elimina una clave del diccionario.

-t timestamp-milisegundos

Establece la marca de tiempo también.

clave

La clave a eliminar.

REPORTAR ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
