NOMBRE

docker-update - Actualiza la configuración de uno o más contenedores

SINOPSIS

docker update [OPCIONES] CONTENEDOR [CONTENEDOR...]

DESCRIPCIÓN

Alias para docker container update.

OPCIONES

--blkio-weight=0 Peso relativo de I/O de bloque, entre 10 y 1000, o 0 para deshabilitar (predeterminado 0)

--cpu-period=0 Período del planificador CFS (Completely Fair Scheduler) de la CPU

--cpu-quota=0 Cuota del planificador CFS (Completely Fair Scheduler) de la CPU

--cpu-rt-period=0 Período de tiempo real de la CPU en microsegundos

--cpu-rt-runtime=0 Tiempo de ejecución de tiempo real de la CPU en microsegundos

-c, --cpu-shares=0 Cuotas de CPU (peso relativo)

--cpus= Número de CPUs

--cpuset-cpus="" CPUs en las que permitir la ejecución (0-3, 0,1)

--cpuset-mems="" MEMs en las que permitir la ejecución (0-3, 0,1)

-m, --memory=0 Límite de memoria

--memory-reservation=0 Límite blando de memoria

--memory-swap=0 Límite de swap igual a memoria más swap: -1 para habilitar swap ilimitado

--pids-limit=0 Ajusta el límite de PIDs del contenedor (establecer -1 para ilimitado)

--restart="" Política de reinicio a aplicar cuando un contenedor finaliza
