NOMBRE

podman-farm-remove - Elimina una o varias granjas

SINOPSIS

podman farm remove [opciones] nombre

podman farm rm [opciones] nombre

DESCRIPCIÓN

Elimina una o varias granjas.

OPCIONES

--all, -a

Elimina todas las granjas.

EJEMPLO

Eliminar la granja especificada:

$ podman farm remove granja1

Eliminar todas las granjas:

$ podman farm rm --all

VER TAMBIÉN

podman(1), podman-farm(1)
