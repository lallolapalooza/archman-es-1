Documentación de Función/Subrutina

subrutina dorcsd2by1 (character jobu1, character jobu2, character jobv1t, integer m, integer p, integer q, double precision, dimension(ldx11,*) x11, integer ldx11, double precision, dimension(ldx21,*) x21, integer ldx21, double precision, dimension(*) theta, double precision, dimension(ldu1,*) u1, integer ldu1, double precision, dimension(ldu2,*) u2, integer ldu2, double precision, dimension(ldv1t,*) v1t, integer ldv1t, double precision, dimension(*) work, integer lwork, integer, dimension(*) iwork, integer info)

DORCSD2BY1

Propósito:

!>
!> DORCSD2BY1 calcula la descomposición CS de una matriz X de M por Q con
!> columnas ortonormales que ha sido particionada en una estructura de
!> bloques de 2 por 1:
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 es de P por Q. Las matrices ortogonales U1, U2 y V1 son de P por P,
!> (M-P) por (M-P) y Q por Q, respectivamente. C y S son matrices
!> diagonales no negativas de R por R que satisfacen C^2 + S^2 = I, en
!> las cuales R = MIN(P,M-P,Q,M-Q). I1 es una matriz identidad de K1 por
!> K1 y I2 es una matriz identidad de K2 por K2, donde K1 = MAX(Q+P-M,0),
!> K2 = MAX(Q-P,0).
!>

Parámetros

JOBU1 
!>          JOBU1 es de tipo CHARACTER
!>          = 'Y':      se calcula U1;
!>          de lo contrario:  no se calcula U1.
!>

JOBU2

!>          JOBU2 es de tipo CHARACTER
!>          = 'Y':      se calcula U2;
!>          de lo contrario:  no se calcula U2.
!>

JOBV1T

!>          JOBV1T es de tipo CHARACTER
!>          = 'Y':      se calcula V1T;
!>          de lo contrario:  no se calcula V1T.
!>

M

!>          M es de tipo INTEGER
!>          El número de filas en X.
!>

P

!>          P es de tipo INTEGER
!>          El número de filas en X11. 0 <= P <= M.
!>

Q

!>          Q es de tipo INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <= M.
!>

X11

!>          X11 es un arreglo de tipo DOUBLE PRECISION, dimensión (LDX11,Q)
!>          En la entrada, parte de la matriz ortogonal cuya CSD se desea.
!>

LDX11

!>          LDX11 es de tipo INTEGER
!>          La dimensión principal de X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 es un arreglo de tipo DOUBLE PRECISION, dimensión (LDX21,Q)
!>          En la entrada, parte de la matriz ortogonal cuya CSD se desea.
!>

LDX21

!>          LDX21 es de tipo INTEGER
!>          La dimensión principal de X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA es un arreglo de tipo DOUBLE PRECISION, dimensión (R), en la
!>          cual R = MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) y
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 es un arreglo de tipo DOUBLE PRECISION, dimensión (P)
!>          Si JOBU1 = 'Y', U1 contiene la matriz ortogonal U1 de P por P.
!>

LDU1

!>          LDU1 es de tipo INTEGER
!>          La dimensión principal de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 es un arreglo de tipo DOUBLE PRECISION, dimensión (M-P)
!>          Si JOBU2 = 'Y', U2 contiene la matriz ortogonal U2 de (M-P) por
!>          (M-P).
!>

LDU2

!>          LDU2 es de tipo INTEGER
!>          La dimensión principal de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T es un arreglo de tipo DOUBLE PRECISION, dimensión (Q)
!>          Si JOBV1T = 'Y', V1T contiene la matriz ortogonal V1**T de Q
!>          por Q.
!>

LDV1T

!>          LDV1T es de tipo INTEGER
!>          La dimensión principal de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK es un arreglo de tipo DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>          Si INFO > 0 en la salida, WORK(2:R) contiene los valores PHI(1),
!>          ..., PHI(R-1) que, junto con THETA(1), ..., THETA(R), definen
!>          la matriz en forma de bloques bidiagonales intermedia que
!>          permanece después de la no convergencia. INFO especifica el
!>          número de PHI no nulos.
!>

LWORK

!>          LWORK es de tipo INTEGER
!>          La dimensión del arreglo WORK.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo de espacio de
!>          trabajo, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK.
!>

IWORK

!>          IWORK es un arreglo de tipo INTEGER, dimensión (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO es de tipo INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  DBBCSD no convergió. Vea la descripción de WORK
!>                arriba para más detalles.
!>

Referencias:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
