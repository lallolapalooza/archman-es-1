NOMBRE

docker-search - Buscar en Docker Hub imágenes

SINOPSIS

docker search [OPCIONES] TÉRMINO

DESCRIPCIÓN

Busca en Docker Hub imágenes que coincidan con el TÉRMINO especificado. La tabla de imágenes devuelta muestra el nombre, la descripción (truncada por defecto), el número de estrellas otorgadas, si la imagen es oficial y si es automatizada.

FILTRO

Filtra la salida basándose en estas condiciones:
- estrellas=
- es-automatizada=(verdadero|falso) (obsoleto)
- es-oficial=(verdadero|falso)

EJEMPLOS

Buscar en Docker Hub imágenes clasificadas

Busca en un registro el término 'fedora' y solo muestra aquellas imágenes con una clasificación de 3 o superior:

$ docker search --filter=stars=3 fedora
NAME      DESCRIPTION                        STARS     OFFICIAL
fedora    Official Docker builds of Fedora   1150      [OK]

OPCIONES

-f, --filter= Filtra la salida basándose en las condiciones proporcionadas

--format="" Formatea la salida de la búsqueda usando una plantilla Go

--limit=0 Número máximo de resultados de búsqueda

--no-trunc[=false] No truncar la salida
