DORBD

B

Propósito

: 
!>
!> DORBDB bidiagonaliza simultáneamente los bloques de una matriz
!> ortogonal X particionada de M-por-M:
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**T
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0 0  I ]
!>
!> X11 es P-por-Q. Q no debe ser mayor que P, M-P, ni M-Q. (Si este no es
!> el caso, entonces X debe ser transpuesta y/o permutada. Esto puede
!> hacerse en tiempo constante usando las opciones TRANS y SIGNS. Vea
!> DORCSD para detalles.)
!>
!> Las matrices ortogonales P1, P2, Q1 y Q2 son P-por-P, (M-P)-por-
!> (M-P), Q-por-Q y (M-Q)-por-(M-Q), respectivamente. Se representan
!> implícitamente por vectores de Householder.
!>
!> B11, B12, B21 y B22 son matrices bidiagonales Q-por-Q representadas
!> implícitamente por los ángulos THETA y PHI.
!
>

s

!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden
!>                      fila-mayor;
!>          en otro caso:  X, U1, U2, V1T y V2T se almacenan en orden
!>                      columna-mayor.
!
>

NAME


dorbdb - Calculates the bidiagonal decomposition of a general m by n
    matrix.






SYNOPSIS


SUBROUTINE DORBDB(UPLO, TRANSPOSE, M, N, LDB1, LDB2, LDU,
LDV, D, E, TAU1, TAU2, U, V, WORK, INFO)



Parameters:




UPLO


CHARACTER*1.
    

    = 'U': UPLO specifies that the upper bidiagonal matrices B11 and B12
    are represented.


 = 'L': UPLO specifies that the lower bidiagonal matrices B21 and
    B22 are represented.




TRANSPOSE


CHARACTER*1.
    

    = 'N': Apply the decomposition to the matrix A.


 = 'T': Apply the decomposition to the transpose of the matrix A.




M


INTEGER.
    

    Number of rows of the matrix A.




N


INTEGER.
    

    Number of columns of the matrix A.




LDB1


INTEGER.
    

    Leading dimension of the bidiagonal matrix B11.




LDB2


INTEGER.
    

    Leading dimension of the bidiagonal matrix B21 or B22.




LDU


INTEGER.
    

    Leading dimension of the orthogonal matrix U.




LDV


INTEGER.
    

    Leading dimension of the orthogonal matrix V.




D


DOUBLE PRECISION array, dimension


 (max(1,M)) if TRANSPOSE = 'N', and (max(1,N)) if
    TRANSPOSE = 'T'.
    

    On exit, D contains the diagonal elements of the bidiagonal matrices.




E


DOUBLE PRECISION array, dimension


 (max(1,min(M-1,N))) if TRANSPOSE = 'N', and (max(1,min(M,N-1)))
    if TRANSPOSE = 'T'.
    

    On exit, E contains the subdiagonal elements of the bidiagonal matrices.




TAU1


DOUBLE PRECISION array, dimension


 (max(1,M)) if TRANSPOSE = 'N', and (max(1,N)) if
    TRANSPOSE = 'T'.
    

    On exit, TAU1 contains the scalar factors of the elementary reflectors
    of U.




TAU2


DOUBLE PRECISION array, dimension


 (max(1,min(M-1,N))) if TRANSPOSE = 'N', and (max(1,min(M,N-1)))
    if TRANSPOSE = 'T'.
    

    On exit, TAU2 contains the scalar factors of the elementary reflectors
    of V.




U


DOUBLE PRECISION array, dimension


 (LDU, M) if TRANSPOSE = 'N', and (LDU, N) if
    TRANSPOSE = 'T'.
    

    On exit, U is an orthogonal matrix representing the decomposition of
    the matrix.




V


DOUBLE PRECISION array, dimension


 (LDV, N) if TRANSPOSE = 'N', and (LDV, M) if
    TRANSPOSE = 'T'.
    

    On exit, V is an orthogonal matrix representing the decomposition of
    the matrix.




WORK


DOUBLE PRECISION array, dimension


 (max(M,N))
    

    Workspace array.




INFO


INTEGER.
    

    = 0: successful exit.
    

    < 0: if INFO = -i, the i-th argument had an illegal value.










Function/Subroutine Documentation


The purpose of the subroutine DORBDB is to compute the bidiagonal
    decomposition of a general m by n matrix A.


The bidiagonal decomposition of A is given by


A = U * B * VT


where U and V are orthogonal matrices, and B is a bidiagonal
    matrix.


The bidiagonal matrix B can be represented in two ways, depending
    on the value of the parameter UPLO:


    

  • If UPLO = 'U', B is an upper bidiagonal matrix, and its upper
    bidiagonal part is stored in the arrays D and E.
    • 

  • If UPLO = 'L', B is a lower bidiagonal matrix, and its lower
    bidiagonal part is stored in the arrays D and E.
    • 



The orthogonal matrices U and V are computed as products of
    elementary reflectors.


The subroutine also computes the scalar factors of the elementary
    reflectors in the arrays TAU1 and TAU2.


The parameter TRANSPOSE determines whether the decomposition is
    applied to A or AT. This is useful for computing the CS
    decomposition.


Bidiagonal Representation:




!>          The bidiagonal blocks B11, B12, B21, and B22 are represented
!>          implicitly by angles THETA(1), ..., THETA(Q) and PHI(1), ...,
!>          PHI(Q-1). B11 and B21 are upper bidiagonal, while B21 and B22 are
!>          lower bidiagonal. Every entry in each bidiagonal band is a product
!>          of a sine or cosine of a THETA with a sine or cosine of a PHI. See
!>          [1] or DORCSD for details.
!>
!>          P1, P2, Q1, and Q2 are represented as products of elementary
!>          reflectors. See DORCSD for details on generating P1, P2, Q1, and Q2
!>          using DORGQR and DORGLQ.





Return Values:




!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
