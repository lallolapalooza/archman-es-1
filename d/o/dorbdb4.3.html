subrutina dorbdb4 (integer m, integer p, integer q, double precision, dimension(ldx11,*) x11, integer ldx11, double precision, dimension(ldx21,*) x21, integer ldx21, double precision, dimension(*) theta, double precision, dimension(*) phi, double precision, dimension(*) taup1, double precision, dimension(*) taup2, double precision, dimension(*) tauq1, double precision, dimension(*) phantom, double precision, dimension(*) work, integer lwork, integer

DORBDB

4

Propósito

: 
!>
!> DORBDB4 bidiagonaliza simultáneamente los bloques de una matriz
!> alta y delgada X con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 es P-por-Q, y X21 es (M-P)-por-Q. M-Q no debe ser mayor que P,
!> M-P, o Q. Las rutinas DORBDB1, DORBDB2 y DORBDB3 manejan los casos en
!> los que M-Q no es la dimensión mínima.
!>
!> Las matrices ortogonales P1, P2 y Q1 son P-por-P, (M-P)-por-(M-P),
!> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por
!> vectores de Householder.
!>
!> B11 y B12 son matrices bidiagonales (M-Q)-por-(M-Q) representadas
!> implícitamente por los ángulos THETA, PHI.
!>
!
>

Parámetro

s
M 
!>          M es INTEGER
!>           El número de filas de X11 más el número de filas en X21.
!
>

P 
!>          P es INTEGER
!>           El número de filas en X11. 0 <= P <= M.
!
>

Q 
!>          Q es INTEGER
!>           El número de columnas en X11 y X21. 0 <= Q <= M y
!>           M-Q <= min(P,M-P,Q).
!
>

X1

1 
!>          X11 es un array DOUBLE PRECISION, dimensión (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X11) especifican reflectores para P1 y
!>           las filas de triu(X11,1) especifican reflectores para Q1.
!
>

LDX1

1 
!>          LDX11 es INTEGER
!>           La dimensión principal de X11. LDX11 >= P.
!
>

X2

1 
!>          X21 es un array DOUBLE PRECISION, dimensión (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X21) especifican reflectores para P2.
!
>

LDX2

1 
!>          LDX21 es INTEGER
!>           La dimensión principal de X21. LDX21 >= M-P.
!
>

THET

A 
!>          THETA es un array DOUBLE PRECISION, dimensión (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Detalles Adicionales.
!
>

PH

I 
!>          PHI es un array DOUBLE PRECISION, dimensión (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen por
!>           THETA y PHI. Ver Detalles Adicionales.
!
>

TAUP

1 
!>          TAUP1 es un array DOUBLE PRECISION, dimensión (M-Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           P1.
!
>

TAUP

2 
!>          TAUP2 es un array DOUBLE PRECISION, dimensión (M-Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           P2.
!
>

TAUQ

1 
!>          TAUQ1 es un array DOUBLE PRECISION, dimensión (Q)
!>           Los factores escalares de los reflectores elementales que definen
!>           Q1.
!
>

PHANTO

M 
!>          PHANTOM es un array DOUBLE PRECISION, dimensión (M)
!>           La rutina calcula un vector columna Y de M-por-1 que es
!>           ortogonal a las columnas de [ X11; X21 ]. PHANTOM(1:P) y
!>           PHANTOM(P+1:M) contienen vectores de Householder para Y(1:P) y
!>           Y(P+1:M), respectivamente.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!
>

LWOR

K 
!>          LWORK es INTEGER
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>           solo calcula el tamaño óptimo del array WORK, devuelve
!>           este valor como la primera entrada del array WORK, y no se emite
!>           ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

INF

O 
!>          INFO es INTEGER
!>           = 0:  salida exitosa.
!>           < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!
>

Detalles

Adicionales: 
!>
!>  Los bloques bidiagonales superiores B11, B21 se representan implícitamente por
!>  los ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada entrada
!>  en cada banda bidiagonal es un producto de un seno o coseno de un THETA
!>  con un seno o coseno de un PHI. Ver [1] o DORCSD para detalles.
!>
!>  P1, P2 y Q1 se representan como productos de reflectores elementales.
!>  Ver DORCSD2BY1 para detalles sobre cómo generar P1, P2 y Q1 usando DORGQR
!>  y DORGLQ.
!
>
