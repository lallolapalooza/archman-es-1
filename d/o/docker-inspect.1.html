docker-inspect - Devuelve

información de bajo nive
l sobre objetos de Docker

SINOPSI

S

docker inspect [OPCIONES] NOMBRE|ID [NOMBRE|ID..

.
]

DESCRIPCIÓ

N

Esto muestra la información de bajo nivel sobre los objetos de Docker (por ejemplo, contenedor, imagen, volumen, red, nodo, servicio o tarea) identifica

dos por nombre o ID. De forma predeterminada, esto representará todos los resultados en un array JSON. Si el contenedor y la imagen tienen el mismo nomb
re, esto devolverá el JSON del contenedor para un tipo no especificado. Si se especifica un formato, la plantilla dada se ejecutará para cada resultado.

EJEMPLO

S

Obtener información sobre una imagen cuando el nombre de la imagen entra en conflicto con el nombre del contenedor, por ejemplo, tanto la imagen como el contenedor se llaman

rhel7: 
$ docker inspect --type=image rhel7

 ....
}

Obteniendo la dirección IP de una instancia de

contenedor

Para obtener la dirección IP de un contenedor,

use: 
$ docker inspect --format='{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' d2cc496561d6
172.17.
0.

Listando todos los enlaces de

puertos

Se puede recorrer arrays y mapas en los resultados para producir una salida de texto

simple: 
$ docker inspect --format='{{range $p, $conf := .NetworkSettings.Ports}} \
  {{$p}} -> {{(index $conf 0).HostPort}} {{end}}' d2cc496561d6
  80/tcp ->
80

Puede obtener más información sobre cómo escribir una plantilla de Go desde: https://pkg.go.dev/text/templat

e
.
