NAME


podman pod ps — Print a list of pods






SYNOPSIS


podman pod ps [options]






DESCRIPTION


The podman pod ps command prints a list of
    pods currently managed by Podman. The list can be filtered and formatted in
    various ways.


By default, the command lists pods that are currently running,
    created, or stopped.






OPTIONS




--all, -a


Do not suppress pods in a finished state. This is the default behavior.


--filter ctr-ids=<container_id>


Filter output based on container IDs. Only pods containing at least one of
      the specified container IDs will be shown.


--filter ctr-number=<number>


Filter output based on the number of containers in the pod. For example,
      --filter ctr-number=2 will show pods with exactly
      2 containers.


--filter ctr-status=<status>


Filter output based on the status of containers within the pod. Possible
      values include 'created', 'running', 'stopped', 'exited', 'paused',
      'restarting', 'removing', 'dead', 'created', 'running', 'exited',
      'paused', 'restarting', 'removing', 'dead', 'created', 'running',
      'stopped', 'exited', 'paused', 'restarting', 'removing', 'dead'.
      For example, --filter ctr-status=exited will show
      pods where at least one container has exited.


--filter id=<pod_id>


Filter output based on Pod ID.


--filter label=<key>[=value]


Filter output based on map of labels. For example,
      --filter label=tier=frontend will only show pods
      that have the label tier set to
      frontend. A label filter without a value, e.g.
      --filter label=env, will filter on the presence of
      the label, regardless of its value.


--filter name=<pod_name>


Filter output based on Pod name.


--filter status=<status>


Filter output based on Pod status. Possible values:
      created, running,
      paused, restarting,
      removing, stopped,
      exited, dead,
      degraded.


--filter until=<timestamp>


Filter pods created before a specified timestamp. This timestamp can be a
      duration such as 2m30s, or a date format like
      YYYY-MM-DDTHH:MM:SSZ.


--ctr-names


Display the names of containers within the pods.


--cidfile=<path>


Use the specified cidfile return the pod ID.


-q, --quiet


Only display the numeric Pod IDs.

    time, INFRA ID, and the number of containers in the pod.

1e3424d7e9c0  db-cluster   Degraded    4 minutes ago  d6650a490b69  3
952330c7cff0  web-app      Running     4 minutes ago  b0f247c49669  3
