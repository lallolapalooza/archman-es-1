DORCSD

Propósito:

!>
!> DORCSD calcula la descomposición CS de una matriz ortogonal particionada X de M-por-M:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**T
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 es P-por-Q. Las matrices ortogonales U1, U2, V1 y V2 son P-por-P,
!> (M-P)-por-(M-P), Q-por-Q y (M-Q)-por-(M-Q), respectivamente. C y S son
!> matrices diagonales no negativas R-por-R que satisfacen C^2 + S^2 = I,
!> donde R = MIN(P,M-P,Q,M-Q).
!>

Parámetros

JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      Se calcula U1;
!>          de lo contrario: U1 no se calcula.
!>

JOBU2

!>          JOBU2 es CHARACTER
!>          = 'Y':      Se calcula U2;
!>          de lo contrario: U2 no se calcula.
!>

JOBV1T

!>          JOBV1T es CHARACTER
!>          = 'Y':      Se calcula V1T;
!>          de lo contrario: V1T no se calcula.
!>

JOBV2T

!>          JOBV2T es CHARACTER
!>          = 'Y':      Se calcula V2T;
!>          de lo contrario: V2T no se calcula.
!>

TRANS

!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden de fila principal;
!>          de lo contrario: X, U1, U2, V1T y V2T se almacenan en orden de
!>                      columna principal.
!>

SIGNS

!>          SIGNS es CHARACTER
!>          = 'O':      El bloque inferior izquierdo se hace no positivo (la
!>                       convención);
!>          de lo contrario: El bloque superior derecho se hace no positivo (la
!>                       convención).
!>

M

!>          M es INTEGER
!>          El número de filas y columnas de X.
!>

P

!>          P es INTEGER
!>          El número de filas en X11 y X12. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <= M.
!>

X11

!>          X11 es un array de DOBLE PRECISIÓN, dimensión (LDX11,Q)
!>          En la entrada, parte de la matriz ortogonal cuya CSD se desea.
!>

LDX11

!>          LDX11 es INTEGER
!>          La dimensión principal de X11. LDX11 >= MAX(1,P).
!>

X12

!>          X12 es un array de DOBLE PRECISIÓN, dimensión (LDX12,M-Q)
!>          En la entrada, parte de la matriz ortogonal cuya CSD se desea.
!>

LDX12

!>          LDX12 es INTEGER
!>          La dimensión principal de X12. LDX12 >= MAX(1,P).
!>

X21

!>          X21 es un array de DOBLE PRECISIÓN, dimensión (LDX21,Q)
!>          En la entrada, parte de la matriz ortogonal cuya CSD se desea.
!>

LDX21

!>          LDX21 es INTEGER
!>          La dimensión principal de X11. LDX21 >= MAX(1,M-P).
!>

X22

!>          X22 es un array de DOBLE PRECISIÓN, dimensión (LDX22,M-Q)
!>          En la entrada, parte de la matriz ortogonal cuya CSD se desea.
!>

LDX22

!>          LDX22 es INTEGER
!>          La dimensión principal de X11. LDX22 >= MAX(1,M-P).
!>

THETA

!>          THETA es un array de DOBLE PRECISIÓN, dimensión (R), donde R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) y
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 es un array de DOBLE PRECISIÓN, dimensión (LDU1,P)
!>          Si JOBU1 = 'Y', U1 contiene la matriz ortogonal P-por-P U1.
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 es un array de DOBLE PRECISIÓN, dimensión (LDU2,M-P)
!>          Si JOBU2 = 'Y', U2 contiene la matriz ortogonal (M-P)-por-(M-P)
!>          U2.
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T es un array de DOBLE PRECISIÓN, dimensión (LDV1T,Q)
!>          Si JOBV1T = 'Y', V1T contiene la matriz ortogonal Q-por-Q
!>          V1**T.
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

V2T

!>          V2T es un array de DOBLE PRECISIÓN, dimensión (LDV2T,M-Q)
!>          Si JOBV2T = 'Y', V2T contiene la matriz ortogonal (M-Q)-por-(M-Q)
!>          V2**T.
!>

LDV2T

!> LDV2T es INTEGER !> La dimensión principal de V2T. Si JOBV2T = 'Y', LDV2T >= !> MAX(1,M-Q). !>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>          Si INFO > 0 en la salida, WORK(2:R) contiene los valores PHI(1),
!>          ..., PHI(R-1) que, junto con THETA(1), ..., THETA(R),
!>          definen la matriz en forma bidiagonal-por-bloques intermedia
!>          que queda tras la no convergencia. INFO especifica el número
!>          de PHI no nulos.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución correcta;
!>          > 0: la subrutina ha convergido con (INFO - 1) escalones de
!>               rotación de Jacobi, y los valores de THETA(INFO:R)
!>               no son necesariamente correctos.
!>
