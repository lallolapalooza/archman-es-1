NOMBRE

docker-image-load - Cargar una imagen desde un archivo tar o STDIN

SINOPSIS

docker image load [OPCIONES]

DESCRIPCIÓN

Carga un repositorio empaquetado en tar desde un archivo o el flujo de entrada estándar. Restaura tanto imágenes como etiquetas. Escribe los nombres o IDs de las imágenes importadas en el flujo de salida estándar.

EJEMPLOS

$ docker images
REPOSITORY          TAG                 IMAGE ID            CREATED             SIZE
busybox             latest              769b9341d937        7 weeks ago         2.489 MB
$ docker load --input fedora.tar
# […]
Loaded image: fedora:rawhide
# […]
Loaded image: fedora:20
# […]
$ docker images
REPOSITORY          TAG                 IMAGE ID            CREATED             SIZE
busybox             latest              769b9341d937        7 weeks ago         2.489 MB
fedora              rawhide             0d20aec6529d        7 weeks ago         387 MB
fedora              20                  58394af37342        7 weeks ago         385.5 MB
fedora              heisenbug           58394af37342        7 weeks ago         385.5 MB
fedora              latest              58394af37342        7 weeks ago         385.5 MB

Ver también

docker-image-save(1) para guardar una o más imágenes en un archivo tar (transmitido a STDOUT por defecto).

OPCIONES

-i, --input="" Leer desde el archivo tar, en lugar de STDIN

--platform=[] Cargar solo las plataformas dadas. Formateado como una lista separada por comas de "os[/arch[/variant]]" (por ejemplo, "linux/amd64,linux/arm64/v8").

-q, --quiet[=false] Suprimir la salida de carga
