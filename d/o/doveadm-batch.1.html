NOMBRE

doveadm-batch - Ejecutar múltiples comandos para múltiples usuarios

SINOPSIS

doveadm [-Dv] batch [-S ruta_socket] -A sep comando sep comando [...]
doveadm [-Dv] batch [-S ruta_socket] -F archivo sep comando sep comando [...]
doveadm [-Dv] batch [-S ruta_socket] -u máscara_usuario sep comando sep comando [...]

DESCRIPCIÓN

El comando doveadm batch se utiliza para ejecutar múltiples comandos de doveadm(1) secuencialmente para múltiples usuarios. Esto es principalmente una optimización donde Dovecot puede realizar todas las operaciones del buzón para el mismo usuario a la vez, en lugar de tener que pasar por los usuarios varias veces.

En la primera forma, doveadm(1) iterará sobre todos los usuarios, definidos en las user_db configuradas, y ejecutará la secuencia de comandos para cada uno de ellos.

En la segunda forma, doveadm(1) iterará sobre todos los usuarios listados en el archivo dado.

En la tercera forma, los comandos se ejecutarán para cada usuario que coincida con la máscara_usuario dada.

OPCIONES

Opciones globales de doveadm(1):

-D
Habilita la verbosidad y los mensajes de depuración.
-o configuración=valor
Anula la configuración del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.
-v
Habilita la verbosidad, incluyendo el contador de progreso.

Opciones específicas del comando:

-A
Si la opción -A está presente, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, porque también incluye usuarios con un UID inferior al configurado con la opción first_valid_uid.

Cuando se utiliza el módulo userdb SQL, asegúrese de que la configuración iterate_query en /etc/dovecot/dovecot-sql.conf.ext coincida con el diseño de su base de datos. Al usar el módulo userdb LDAP, asegúrese de que las configuraciones iterate_attrs y iterate_filter en /etc/dovecot/dovecot-ldap.conf.ext coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo
Ejecuta el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo dado. El archivo contiene un nombre de usuario por línea.
-S ruta_socket
El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre_host:puerto), para conectar a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara
Ejecuta el comando solo para el usuario dado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).
Si no se especificó ni la opción -A, ni la opción -F archivo, ni la opción -u usuario, el comando se ejecutará con el entorno del usuario actualmente conectado.

ARGUMENTOS

comando
Cualquier comando de doveadm(1), con argumentos y opciones — excepto las opciones -A, -S y -u.
sep
Un solo carácter utilizado como separador de comandos, por ejemplo, ':'. Tenga cuidado, los caracteres sin comillas, como ; o &, pueden ser interpretados por su shell y doveadm(1) nunca los verá.

EJEMPLO

En este ejemplo, movemos los correos vistos, de más de un mes, para todos los usuarios de example.net al almacenamiento alternativo bajo /nfsmount:

mail_location = mdbox:~/mdbox:ALT=/nfsmount/%h/mdbox

El segundo comando eliminará los mensajes con refcount=0 del almacenamiento principal.

doveadm batch -u \*@example.net : altmove seen savedbefore 30d : purge

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot <dovecot@dovecot.org>. La información sobre cómo reportar errores está disponible en: http://dovecot.org/bugreport.html
