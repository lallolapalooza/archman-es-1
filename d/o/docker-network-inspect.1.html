DESCRIPCIÓ

N

Devuelve información sobre una o más redes. De forma predeterminada, este comando muestra todos los resultados en un objeto JSON. Por ejemplo, si conecta dos contenedores a la red puente (bridge)

predeterminada: 
$ sudo docker run -itd --name=container1 busybox
f2870c98fd504370fb86e59f32cd0753b1ac9b69b7d80566ffc7192a82b3ed27
$ sudo docker run -itd --name=container2 busybox
bda12f8922785d1f160be70736f26c1e331ab8aaf8ed8d56728508f2e2fd472
7

El comando network inspect muestra los contenedores, por id, en sus resultados. Puede especificar un formato alternativo para ejecutar una plantilla determinada para cada resultado. El paquete text/template de Go ⟨https://pkg.go.dev/text/template⟩ describe todos los detalles del

formato.

docker network inspect --verbose para redes superpuestas (overlay) en modo enjambre (swarm) muestra detalles específicos del servicio como la VIP del servicio y las asignaciones de puertos. También muestra las IP de las tareas del servicio y las IP de los nodos donde se están ejecutando las

tareas.

A continuación se muestra un ejemplo de salida para una red superpuesta ov1 que tiene un servicio s1 conectado. El servicio s1 en este caso tiene tres

réplicas.
