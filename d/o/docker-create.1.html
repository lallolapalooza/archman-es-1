--add-host= Añade un mapeo personalizado de host a IP (host:

ip)

--annotation=map[] Añade una anotación al contenedor (se pasa al runtime

OCI)

-a, --attach= Se conecta a STDIN, STDOUT o

STDERR

--blkio-weight=0 Block IO (peso relativo), entre 10 y 1000, o 0 para deshabilitar (por defecto

0)

--blkio-weight-device=[] Peso de Block IO (peso relativo del

dispositivo)

--cap-add= Añade capacidades de

Linux

--cap-drop= Elimina capacidades de

Linux

--cgroup-parent="" Cgroup padre opcional para el

contenedor

--cgroupns="" Espacio de nombres de cgroup a usar (host|private) 'host': Ejecuta el contenedor en el espacio de nombres de cgroup del host de Docker 'private': Ejecuta el contenedor en su propio espacio de nombres de cgroup privado '': Usa el espacio de nombres de cgroup configurado por la
opción default-cgroupns-mode en el demonio (por

defecto)

--cidfile="" Escribe el ID del contenedor en el

archivo

--cpu-count=0 Número de CPU (solo

Windows)

--cpu-percent=0 Porcentaje de CPU (solo

Windows)

--cpu-period=0 Limita el período CFS (Completely Fair Scheduler) de la

CPU

--cpu-quota=0 Limita la cuota CFS (Completely Fair Scheduler) de la

CPU

--cpu-rt-period=0 Limita el período de tiempo real de la CPU en

microsegundos

--cpu-rt-runtime=0 Limita el tiempo de ejecución de tiempo real de la CPU en

microsegundos

-c, --cpu-shares=0 Participaciones de CPU (peso

relativo)

--cpus= Número de

CPUs

--cpuset-cpus="" CPUs en las que permitir la ejecución (0-3, 0,

1)

--cpuset-mems="" MEMs en las que permitir la ejecución (0-3, 0,

1)

--device= Añade un dispositivo del host al

contenedor

--device-cgroup-rule= Añade una regla a la lista de dispositivos permitidos del

cgroup

--device-read-bps=[] Limita la tasa de lectura (bytes por segundo) de un

dispositivo

--device-read-iops=[] Limita la tasa de lectura (IO por segundo) de un

dispositivo

--device-write-bps=[] Limita la tasa de escritura (bytes por segundo) a un

dispositivo

--device-write-iops=[] Limita la tasa de escritura (IO por segundo) a un

dispositivo

--dns= Establece servidores DNS

personalizados

--dns-option= Establece opciones

DNS

--dns-search= Establece dominios de búsqueda DNS

personalizados

--domainname="" Nombre de dominio NIS del

contenedor

--entrypoint="" Sobrescribe el ENTRYPOINT por defecto de la

imagen

-e, --env= Establece variables de

entorno

--env-file= Lee un archivo de variables de

entorno

--expose= Expone un puerto o un rango de

puertos

--gpus= Dispositivos GPU a añadir al contenedor ('all' para pasar todas las

GPUs)

--group-add= Añade grupos adicionales a los que

unirse

--health-cmd="" Comando a ejecutar para comprobar la

salud

--health-interval=0s Tiempo entre la ejecución de la comprobación (ms|s|m|h) (por defecto

0s)

--health-retries=0 Fallos consecutivos necesarios para reportar que no está

saludable

--health-start-interval=0s Tiempo entre la ejecución de la comprobación durante el período de inicio (ms|s|m|h) (por defecto

0s)

--health-start-period=0s Período de inicio para que el contenedor se inicialice antes de empezar la cuenta atrás de health-retries (ms|s|m|h) (por defecto

0s)

--health-timeout=0s Tiempo máximo permitido para que se ejecute una comprobación (ms|s|m|h) (por defecto

0s)

--help[=false] Muestra el

uso

-h, --hostname="" Nombre de host del

contenedor

--init[=false] Ejecuta un init dentro del contenedor que reenvía señales y recoge

procesos

-i, --interactive[=false] Mantiene STDIN abierto aunque no esté

conectado

--io-maxbandwidth=0 Límite máximo de ancho de banda IO para la unidad del sistema (solo

Windows)

--io-maxiops=0 Límite máximo de IOps para la unidad del sistema (solo

Windows)

--ip= Dirección IPv4 (p. ej., 172.30.100.

104)

--ip6= Dirección IPv6 (p. ej., 2001:db8::

33)

--ipc="" Modo IPC a

usar

--isolation="" Tecnología de aislamiento del

contenedor

-l, --label= Establece metadatos en un

contenedor

--label-file= Lee un archivo delimitado por líneas de

etiquetas

--link= Añade un enlace a otro

contenedor

--link-local-ip= Direcciones link-local IPv4/IPv6 del

contenedor

--log-driver="" Controlador de registro para el

contenedor

--log-opt= Opciones del controlador de

registro

--mac-address="" Dirección MAC del contenedor (p. ej., 92:d0:c6:0a:29:

33)

-m, --memory=0 Límite de

memoria

--memory-reservation=0 Límite suave de

memoria

--memory-swap=0 Límite de swap igual a memoria más swap: '-1' para habilitar swap

ilimitado

--memory-swappiness=-1 Ajusta la "swappiness" de la memoria del contenedor (0 a

100)

--mount= Adjunta un montaje de sistema de archivos al

contenedor

--name="" Asigna un nombre al

contenedor

--network= Conecta un contenedor a una

red

--network-alias= Añade un alias de ámbito de red para el

contenedor

--no-healthcheck[=false] Deshabilita cualquier HEALTHCHECK especificado por el

contenedor

--oom-kill-disable[=false] Deshabilita el OOM

Killer

--oom-score-adj=0 Ajusta las preferencias de OOM del host (-1000 a

1000)

--pid="" Espacio de nombres PID a

usar

--pids-limit=0 Ajusta el límite de pids del contenedor (establece -1 para

ilimitado)

--platform="" Establece la plataforma si el servidor es capaz de

multiplataforma

--privileged[=false] Concede privilegios extendidos a este

contenedor

-p, --publish= Publica el/los puerto(s) de un contenedor al

host

-P, --publish-all[=false] Publica todos los puertos expuestos a puertos

aleatorios

--pull="missing" Obtiene la imagen antes de crearla ("always", "|missing",

"never")

-q, --quiet[=false] Suprime la salida de la

obtención

--read-only[=false] Monta el sistema de archivos raíz del contenedor como de solo

lectura

--restart="no" Política de reinicio a aplicar cuando un contenedor

termina

--rm[=false] Elimina automáticamente el contenedor y sus volúmenes anónimos asociados cuando

termina

--runtime="" Runtime a usar para este

contenedor

--security-opt= Opciones de

seguridad

--shm-size=0 Tamaño de

/dev/shm

--stop-signal="" Señal para detener el

contenedor

--stop-timeout=0 Tiempo de espera (en segundos) para detener un

contenedor

--storage-opt= Opciones del controlador de almacenamiento para el

contenedor

--sysctl=map[] Opciones de

sysctl

--tmpfs= Monta un directorio

tmpfs

-t, --tty[=false] Asigna una

pseudo-TTY

--ulimit=[] Opciones de

ulimit

--use-api-socket[=false] Monta el socket de la API de Docker y la autenticación

requerida

-u, --user="" Nombre de usuario o UID (formato: [:]

)

--userns="" Espacio de nombres de usuario a

usar

--uts="" Espacio de nombres UTS a

usar

-v, --volume= Monta un

volumen

--volume-driver="" Controlador de volumen opcional para el

contenedor

--volumes-from= Monta volúmenes del/los contenedor(es)

especificado(s)

-w, --workdir="" Directorio de tra

bajo dentro
del contenedor
