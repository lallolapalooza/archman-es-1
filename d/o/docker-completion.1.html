NOMBRE

docker-completion - Generar scripts de finalización de shell

SINOPSIS

docker completion [opciones] bash | zsh | fish | powershell

DESCRIPCIÓN

docker completion genera scripts de finalización de shell para una variedad de shells. Los shells compatibles son bash, zsh, fish y powershell.

Estos scripts son utilizados por el shell para proporcionar sugerencias y completar comandos cuando se escribe el comando y se presiona [TAB].

Por lo general, estos scripts se instalan automáticamente a través del gestor de paquetes.

OPCIONES

--file, -f=archivo

Escribir la salida generada a un archivo.

--no-desc

No proporcionar descripción en las finalizaciones.
El valor predeterminado es false.

Instalación

BASH

Se debe tener instalado bash-completion en el sistema.

Para cargar el script de finalización en la sesión actual, ejecute:

source <(docker completion bash)

Para que esté disponible para todas las sesiones de bash, ejecute:

docker completion -f /etc/bash_completion.d/docker bash

ZSH

La finalización de shell ya debe estar habilitada en el entorno. Se puede ejecutar lo siguiente:

echo "autoload -U compinit; compinit" >> ~/.zshrc

Para que esté disponible para todas las sesiones de zsh, ejecute:

docker completion -f "${fpath[1]}/_docker" zsh

Una vez que el shell se reinicie, la auto-finalización funcionará.

FISH

Para cargar el script de finalización en la sesión actual, ejecute:

docker completion fish | source

Para que esté disponible para todas las sesiones de fish, ejecute:

docker completion -f ~/.config/fish/completions/docker.fish fish

POWERSHELL

Para cargar el script de finalización en la sesión actual, ejecute:

docker.exe completion powershell | Out-String | Invoke-Expression

Para que esté disponible en todas las sesiones de powershell que tenga un usuario, escriba la salida de finalización en un archivo y cárguelo en el perfil de powershell del usuario. Hay más información sobre los perfiles disponible con Get-Help about_Profiles.

VER TAMBIÉN

docker(1), zsh(1), fish(1), powershell(1)
