NOMBRE

doveadm-flags - Añadir, eliminar o reemplazar las banderas de los mensajes

SINOPSIS

doveadm [OPCIONES GLOBALES] flags [-S ruta_socket] -A comando banderas consulta_busqueda

doveadm [OPCIONES GLOBALES] flags [-S ruta_socket] -F archivo comando banderas consulta_busqueda

doveadm [OPCIONES GLOBALES] flags [-S ruta_socket] --no-userdb-lookup comando banderas consulta_busqueda

doveadm [OPCIONES GLOBALES] flags [-S ruta_socket] -u usuario comando banderas consulta_busqueda

DESCRIPCIÓN

Este comando se utiliza para manipular las banderas de los mensajes.

OPCIONES GLOBALES

doveadm global(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lee ningún archivo de configuración, solo usa los valores predeterminados. El ajuste dovecot_storage_version se establece en la versión más reciente por defecto, pero se puede anular con

-k

Conserva todo el entorno para doveadm, no solo el ajuste import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre_instancia

Si se utilizan varias instancias de Dovecot, elige el archivo de configuración según este nombre de instancia.

Consulta el ajuste instance_name para más información.

-c archivo_config

Lee la configuración del archivo_config proporcionado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o ajuste=valor

Anula el ajuste de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor proporcionado. Para anular varios ajustes, la opción -o se puede especificar varias veces.

OPCIONES

-A

Si está presente la opción -A, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, porque también incluye usuarios con un UID inferior al configurado con el ajuste first_valid_uid.

Cuando se utiliza el módulo userdb SQL, asegúrate de que el ajuste userdb_sql_iterate_query coincida con la disposición de tu base de datos.

Al usar el módulo userdb LDAP, asegúrate de que los ajustes userdb_fields y userdb_ldap_iterate_fields coincidan con tu esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecuta el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo proporcionado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realiza la búsqueda en la base de datos de usuarios. Utiliza la variable de entorno USER para especificar el nombre de usuario.

-S ruta_socket

El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre_host:puerto), para conectar a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket proporcionado.

-u usuario/máscara

Ejecuta el comando solo para el usuario proporcionado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).

ARGUMENTOS

banderas

Banderas de mensaje descritas en RFC 3501, sección 2.3.2 (Atributo de Mensaje de Banderas):

Se pueden especificar una o varias banderas y/o palabras clave.

consulta_busqueda

Manipula las banderas de los mensajes que coinciden con la consulta de búsqueda proporcionada. Consulta doveadm-search-query(7) para obtener detalles.

COMANDOS

flags add

doveadm [OPCIONES GLOBALES] flags add [-u usuario | -A | -F archivo | --no-userdb-lookup] [-S ruta_socket] banderas consulta_busqueda

Este comando se utiliza para ampliar el conjunto actual de banderas con las banderas proporcionadas.

flags remove

doveadm [OPCIONES GLOBALES] flags remove [-u usuario | -A | -F archivo | --no-userdb-lookup] [-S ruta_socket] banderas consulta_busqueda

Para eliminar las banderas proporcionadas del conjunto actual de banderas, utiliza este comando.

flags replace

doveadm [OPCIONES GLOBALES] flags replace [-u usuario | -A | -F archivo | --no-userdb-lookup] [-S ruta_socket] banderas consulta_busqueda

Este comando se utiliza para reemplazar TODAS las banderas actuales con las banderas proporcionadas.

EJEMPLO

Listar y manipular las banderas de mensaje del mensaje con uid 81563:

doveadm fetch -u bob 'uid flags' mailbox dovecot uid 81563
uid: 81563
flags: \Answered \Seen NonJunk
doveadm flags remove -u bob NonJunk mailbox dovecot uid 81563
doveadm flags add -u bob '\Flagged $Forwarded' mailbox dovecot uid 81563

INFORME DE ERRORES

Informa de errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo informar de errores está disponible en: https://dovecot.org/bugreport.html
