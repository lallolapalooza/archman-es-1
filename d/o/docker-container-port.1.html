NOMBRE

docker-container-port - Listar mapeos de puertos o un mapeo específico para el contenedor

SINOPSIS

docker container port CONTENEDOR [PUERTO_PRIVADO[/PROTO]]

DESCRIPCIÓN

Lista los mapeos de puertos para el CONTENEDOR, o busca el puerto público expuesto que está en NAT al PUERTO_PRIVADO.

EJEMPLOS

$ docker ps
CONTAINER ID        IMAGE               COMMAND             CREATED             STATUS              PORTS                                            NAMES
b650456536c7        busybox:latest      top                 54 minutes ago      Up 54 minutes       0.0.0.0:1234->9876/tcp, 0.0.0.0:4321->7890/tcp   test

Descubrir todos los puertos mapeados

$ docker container port test
7890/tcp -> 0.0.0.0:4321
9876/tcp -> 0.0.0.0:1234

Descubrir un mapeo específico

$ docker container port test 7890/tcp
0.0.0.0:4321
$ docker container port test 7890
0.0.0.0:4321

Un ejemplo mostrando un error para un mapeo inexistente

$ docker container port test 7890/udp
2014/06/24 11:53:36 Error: No public port '7890/udp' published for test
