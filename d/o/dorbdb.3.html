Documentación de Función/Subrutina

subrutina dorbdb (character trans, character signs, integer m, integer p, integer q, double precision, dimension( ldx11, * ) x11, integer ldx11, double precision, dimension( ldx12, * ) x12, integer ldx12, double precision, dimension( ldx21, * ) x21, integer ldx21, double precision, dimension( ldx22, * ) x22, integer ldx22, double precision, dimension( * ) theta, double precision, dimension( * ) phi, double precision, dimension( * ) taup1, double precision, dimension( * ) taup2, double precision, dimension( * ) tauq1, double precision, dimension( * ) tauq2, double precision, dimension( * ) work, integer lwork, integer info)

DORBDB

Propósito:

!>
!> DORBDB bidiagonaliza simultáneamente los bloques de una matriz
!> ortogonal X particionada de M-por-M:
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**T
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0 0  I ]
!>
!> X11 es de P-por-Q. Q no debe ser mayor que P, M-P, ni M-Q. (Si este
!> no es el caso, entonces X debe ser transpuesta y/o permutada. Esto
!> puede hacerse en tiempo constante usando las opciones TRANS y SIGNS.
!> Ver DORCSD para más detalles.)
!>
!> Las matrices ortogonales P1, P2, Q1 y Q2 son de P-por-P, (M-P)-por-
!> (M-P), Q-por-Q y (M-Q)-por-(M-Q), respectivamente. Están
!> representadas implícitamente por vectores de Householder.
!>
!> B11, B12, B21 y B22 son matrices bidiagonales de Q-por-Q
!> representadas implícitamente por los ángulos THETA y PHI.
!>

Parámetros

TRANS 
!>          TRANS es de tipo CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden
!>                      por filas (row-major);
!>          en otro caso:  X, U1, U2, V1T y V2T se almacenan en orden
!>                      por columnas (column-major).
!>

SIGNS

!>          SIGNS es de tipo CHARACTER
!>          = 'O':      El bloque inferior izquierdo se hace no
!>                       positivo (la convención);
!>          en otro caso:  El bloque superior derecho se hace no
!>                       positivo (la convención).
!>

M

!>          M es de tipo INTEGER
!>          El número de filas y columnas en X.
!>

P

!>          P es de tipo INTEGER
!>          El número de filas en X11 y X12. 0 <= P <= M.
!>

Q

!>          Q es de tipo INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 es un arreglo de tipo DOUBLE PRECISION, dimensión (LDX11,Q)
!>          En la entrada, es el bloque superior izquierdo de la matriz ortogonal a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las columnas de tril(X11) especifican reflectores para P1,
!>             las filas de triu(X11,1) especifican reflectores para Q1;
!>          en otro caso TRANS = 'T', y
!>             las filas de triu(X11) especifican reflectores para P1,
!>             las columnas de tril(X11,-1) especifican reflectores para Q1.
!>

LDX11

!>          LDX11 es de tipo INTEGER
!>          La dimensión principal de X11. Si TRANS = 'N', entonces LDX11 >=
!>          P; en otro caso LDX11 >= Q.
!>

X12

!>          X12 es un arreglo de tipo DOUBLE PRECISION, dimensión (LDX12,M-Q)
!>          En la entrada, es el bloque superior derecho de la matriz ortogonal a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las filas de triu(X12) especifican los primeros P reflectores
!>             para Q2;
!>          en otro caso TRANS = 'T', y
!>             las columnas de tril(X12) especifican los primeros P reflectores
!>             para Q2.
!>

LDX12

!>          LDX12 es de tipo INTEGER
!>          La dimensión principal de X12. Si TRANS = 'N', entonces LDX12 >=
!>          P; en otro caso LDX11 >= M-Q.
!>

X21

!>          X21 es un arreglo de tipo DOUBLE PRECISION, dimensión (LDX21,Q)
!>          En la entrada, es el bloque inferior izquierdo de la matriz ortogonal a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las columnas de tril(X21) especifican reflectores para P2;
!>          en otro caso TRANS = 'T', y
!>             las filas de triu(X21) especifican reflectores para P2.
!>

LDX21

!>          LDX21 es de tipo INTEGER
!>          La dimensión principal de X21. Si TRANS = 'N', entonces LDX21 >=
!>          M-P; en otro caso LDX21 >= Q.
!>

X22

!>          X22 es un arreglo de tipo DOUBLE PRECISION, dimensión (LDX22,M-Q)
!>          En la entrada, es el bloque inferior derecho de la matriz ortogonal a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las filas de triu(X22(Q+1:M-P,P+1:M-Q)) especifican los últimos
!>             M-P-Q reflectores para Q2,
!>          en otro caso TRANS = 'T', y
!>             las columnas de tril(X22(P+1:M-Q,Q+1:M-P)) especifican los últimos
!>             M-P-Q reflectores para P2.
!>

LDX22

!>          LDX22 es de tipo INTEGER
!>          La dimensión principal de X22. Si TRANS = 'N', entonces LDX22 >=
!>          M-P; en otro caso LDX22 >= M-Q.
!>

THETA

!>          THETA es un arreglo de tipo DOUBLE PRECISION, dimensión (Q)
!>          Las entradas de los bloques bidiagonales B11, B12, B21, B22 pueden
!>          calcularse a partir de los ángulos THETA y PHI. Ver Detalles
!>          Adicionales.
!>

PHI

!>          PHI es un arreglo de tipo DOUBLE PRECISION, dimensión (Q-1)
!>          Las entradas de los bloques bidiagonales B11, B12, B21, B22 pueden
!>          calcularse a partir de los ángulos THETA y PHI. Ver Detalles
!>          Adicionales.
!>

TAUP1

!>          TAUP1 es un arreglo de tipo DOUBLE PRECISION, dimensión (P)
!>          Los factores escalares de los reflectores elementales que definen
!>          P1.
!>

TAUP2

!>          TAUP2 es un arreglo de tipo DOUBLE PRECISION, dimensión (M-P)
!>          Los factores escalares de los reflectores elementales que definen
!>          P2.
!>

TAUQ1

!>          TAUQ1 es un arreglo de tipo DOUBLE PRECISION, dimensión (Q)
!>          Los factores escalares de los reflectores elementales que definen
!>          Q1.
!>

TAUQ2

!>          TAUQ2 es un arreglo de tipo DOUBLE PRECISION, dimensión (M-Q)
!>          Los factores escalares de los reflectores elementales que definen
!>          Q2.
!>

WORK

!>          WORK es un arreglo de tipo DOUBLE PRECISION, dimensión (LWORK)
!>

LWORK

!>          LWORK es de tipo INTEGER
!>          La dimensión del arreglo WORK. LWORK >= M-Q.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles adicionales:

!>
!>  Los bloques bidiagonales B11, B12, B21 y B22 se representan
!>  implícitamente mediante los ángulos THETA(1), ..., THETA(Q) y PHI(1), ...,
!>  PHI(Q-1). B11 y B21 son bidiagonales superiores, mientras que B21 y B22 son
!>  bidiagonales inferiores. Cada entrada en cada banda bidiagonal es un producto
!>  de un seno o coseno de un THETA con un seno o coseno de un PHI. Ver
!>  [1] o DORCSD para más detalles.
!>
!>  P1, P2, Q1 y Q2 se representan como productos de reflectores
!>  elementales. Ver DORCSD para detalles sobre la generación de P1, P2, Q1 y Q2
!>  usando DORGQR y DORGLQ.
!>
