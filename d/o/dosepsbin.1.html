DOSEPSBIN(1) Documentación de Perl aportada por el usuario DOSEPSBIN(1)

NOMBRE

dosepsbin -- Extrae secciones PS/WMF/TIFF de archivos binarios DOS EPS

VERSIÓN

2012-03-22 v1.2

SINOPSIS

El programa dosepsbin analiza un archivo EPS que no es un archivo PostScript ASCII simple, sino que se proporciona como un archivo binario DOS EPS.

dosepsbin [opciones] <archivo de entrada>

Primero, analiza el archivo de entrada, valida su encabezado y resume las secciones disponibles. Dependiendo de las opciones dadas, las secciones se escriben luego en archivos.

Opciones:

--eps-file <archivo>      Escribe la sección PS en <archivo>.
--wmf-file <archivo>      Escribe la sección WMF en <archivo>.
--tiff-file <archivo>     Escribe la sección TIFF en <archivo>.
--inputfile <archivo>     El nombre del archivo de entrada.
--verbose                 Salida detallada.
--quiet                   Solo se imprimen errores y advertencias.
--help                    Mensaje de ayuda breve.
--man                     Documentación completa.
--version                 Imprime la identificación de la versión.

Los archivos para la salida deben ser diferentes del archivo de entrada.

DESCRIPCIÓN

Formato de archivo binario DOS EPS

Un archivo Encapsulated PostScript (EPS) también se puede proporcionar en un formato binario especial para admitir la inclusión de una miniatura. El formato del archivo comienza con un encabezado binario que contiene las posiciones de las secciones posibles:

* PostScript (PS)
* Formato de Metarchivo de Windows (WMF)
* Formato de archivo de imagen etiquetada (TIFF)

La sección PS debe estar presente y se debe proporcionar el archivo WMF o el archivo TIFF.

OPCIONES

--eps-file=<archivo>
La sección PS se escribe en <archivo>. El archivo de salida debe ser diferente del archivo de entrada.
--wmf-file=<archivo>
La sección WMF se escribe en <archivo> si está presente. El archivo de salida debe ser diferente del archivo de entrada.
--tiff-file=<archivo>
La sección TIFF se escribe en <archivo> si está presente. El archivo de salida debe ser diferente del archivo de entrada.
--inputfile=<archivo>
El archivo de entrada también se puede proporcionar directamente en la línea de comandos. Si el archivo no existe, se intenta con el archivo con la extensión `.eps'.
--verbose
Mensajes detallados.
--quiet
No se imprimen mensajes excepto errores y advertencias.
--help
Muestra la pantalla de ayuda.
--man
Imprime la página del manual.
--version
Imprime la identificación de la versión y sale.

EJEMPLOS

El siguiente comando extrae la sección PS del archivo test.eps y almacena el resultado en el archivo test-ps.eps:

dosepsbin --eps-file test-ps.eps test.eps
