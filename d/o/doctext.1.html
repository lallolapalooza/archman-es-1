NOMBRE

doctext - Genera páginas de documentación a partir de archivos fuente

SINOPSIS

doctext [ -mpath ruta ] [ -ext n ] [ -I archivo ] [ -latex ]
[ -html ] [ -index archivo ] [ -indexdir archivo ]
[ -jumpfile archivo ] [ -outfile archivo ]
[ -mapref archivo ] [ -nolocation ] [ -location ]
[ -defn archivo_defn ] [ -dosnl ] [ -skipprefix nombre ]
[ -ignore cadena ] [ -oldargstyle ]
[ -heading cadena ] [ -basedir directorio ] archivos
[ -Wargdesc ] [ -Wnone ]

PARÁMETROS DE ENTRADA

-mpath ruta
- Establece la ruta donde se escribirán las páginas del manual
-ext n
- Establece la extensión (1-9, l, etc.)
-nolocation
- No proporciona el nombre del archivo donde se encuentra la información de la página del manual
-I archivo
- El archivo contiene las inclusiones públicas necesarias para estas rutinas
-latex
- Genera salida latex en lugar de archivos en formato de manual
-html
- Genera salida html (WWW) en lugar de archivos en formato de manual
-man
- Genera salida man (nroff) (por defecto)
-index archivo
- Genera un archivo de índice apropiado para tohtml (para generar archivos WWW)
-defn archivo_defn
- Lee comandos de este archivo después de cargar los comandos predeterminados
-mapref archivo
- Lee la base de datos de hipervínculos y la aplica a la salida
-indexdir directorio
- Establece el directorio raíz para las entradas del archivo de índice. Por ejemplo:
-index foo.cit -indexdir \"http://www.mcs.anl.gov/foo/man\"
-outfile archivo
- Coloca las páginas del manual en el archivo indicado
-heading nombre
- Nombre para el encabezado (centro de la línea superior)
-quotefmt
- Soporta '\\tt' y `\\em`
-oldargstyle
- Permite múltiples '. ' para una lista de argumentos, en lugar de usar '+ .... -' para listas de argumentos con múltiples entradas.
-skipprefix nombre
- omite 'nombre' al principio de cada línea. Esto puede ser utilizado para código fuente Fortran o Shell
-ignore cadena
- omite 'nombre' en una sinopsis de función. Esto puede ser utilizado para eliminar palabras clave especiales necesarias para compilar la rutina pero no necesarias para el usuario (por ejemplo, palabras clave de exportación especiales al compilar DLLs)
-keyword archivo
- Coloca las entradas de palabras clave al final del archivo especificado
-locdir directorio
- Utiliza el directorio en el campo Ubicación:
-dosnl
- Genera archivos estilo DOS (retorno de carro-nueva línea en lugar de solo nueva línea)
archivos
- Nombres de los archivos de los cuales se extraerán los documentos
-Wargdesc
- Advierte sobre argumentos sin descripción
-Wnone
- Desactiva las advertencias

UBICACIÓN
