NOMBRE

doveadm-index - Indexar buzones de correo

SINOPSIS

doveadm [OPCIONES GLOBALES] index [-S ruta_socket] -A [-q] [-n max_recientes] buzon

doveadm [OPCIONES GLOBALES] index [-S ruta_socket] -F archivo [-q] [-n max_recientes] buzon

doveadm [OPCIONES GLOBALES] index [-S ruta_socket] --no-userdb-lookup [-q] [-n max_recientes] buzon

doveadm [OPCIONES GLOBALES] index [-S ruta_socket] -u usuario [-q] [-n max_recientes] buzon

DESCRIPCIÓN

Añade mensajes sin indexar en un buzón de correo al archivo de índice/caché. Si la búsqueda de texto completo está habilitada, también añade los mensajes sin indexar a la base de datos de fts.

El almacenamiento en caché solo añade los campos que se añadieron previamente a las decisiones de caché del buzón, por lo que no hará nada útil para los buzones a los que el cliente del usuario aún no ha accedido. Puede usar el comando doveadm dump para mostrar las decisiones de caché actuales de un buzón específico.

Los mensajes también se pueden añadir automáticamente al índice de búsqueda de texto completo usando:

fts_autoindex = yes

OPCIONES GLOBALES

doveadm(1) global

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lea ningún archivo de configuración, solo use los valores predeterminados. La configuración dovecot_storage_version se establece en la última versión por defecto, pero se puede anular con

-k

Conserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre_instancia

Si se utilizan varias instancias de Dovecot, elija el archivo de configuración en función de este nombre de instancia.

Consulte la configuración instance_name para obtener más información.

-c archivo_configuracion

Lea la configuración del archivo_configuracion proporcionado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia en ejecución de una versión compatible.

-o configuracion=valor

Anula la configuracion de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular varias configuraciones, la opción -o puede especificarse varias veces.

OPCIONES

-A

Si está presente la opción -A, el comando se realizará para todos los usuarios. No se recomienda el uso de esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, ya que también contiene usuarios con un UID inferior al configurado con la configuración first_valid_uid.

Cuando se utiliza el módulo de base de datos de usuarios SQL, asegúrese de que la configuración userdb_sql_iterate_query coincida con el diseño de su base de datos.

Cuando se utiliza el módulo de base de datos de usuarios LDAP, asegúrese de que las configuraciones userdb_fields y userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecute el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo dado. El archivo contiene un nombre de usuario por línea.

-n max_recientes

Un valor entero, que especifica el número máximo de mensajes \Recent en los buzones. Si el buzón contiene más de max_recientes mensajes con la bandera \Recent establecida, el buzón no se indexará. Esto puede ser útil para evitar indexaciones innecesarias para buzones grandes que nunca se abren.

--no-userdb-lookup

No realice la búsqueda en la base de datos de usuarios. Utilice la variable de entorno USER para especificar el nombre de usuario.

-q

Pone en cola la indexación para que sea ejecutada por el proceso indexador. Sin -q, la indexación la realiza directamente el proceso doveadm(1). Algunos controladores no pueden manejar múltiples procesos actualizando los índices simultáneamente, por lo que generalmente se debe usar -q en producción.

-S ruta_socket

El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre_host:puerto), para conectarse a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/mascara

Ejecute el comando solo para el usuario dado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).

ARGUMENTOS

buzon

El nombre del buzón a indexar.

EJEMPLO

Indexar la Bandeja de Entrada de bob:

doveadm index -u bob INBOX

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
