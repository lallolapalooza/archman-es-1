NOMBRE

docker-images - Listar imágenes

SINOPSIS

docker images [OPCIONES] [REPOSITORIO[:ETIQUETA]]

DESCRIPCIÓN

Alias de docker image ls.

OPCIONES

-a, --all[=false] Mostrar todas las imágenes (por defecto oculta las imágenes intermedias)

--digests[=false] Mostrar resúmenes (digests)

-f, --filter= Filtrar la salida según las condiciones proporcionadas

--format="" Dar formato a la salida utilizando una plantilla personalizada: 'table': Imprimir la salida en formato de tabla con encabezados de columna (por defecto) 'table PLANTILLA': Imprimir la salida en formato de tabla utilizando la plantilla Go dada 'json': Imprimir en formato JSON 'PLANTILLA': Imprimir la salida utilizando la plantilla Go dada. Consulte https://docs.docker.com/go/formatting/ para obtener más información sobre cómo formatear la salida con plantillas

--no-trunc[=false] No truncar la salida

-q, --quiet[=false] Mostrar solo los IDs de las imágenes

--tree[=false] Listar imágenes multiplataforma como un árbol (EXPERIMENTAL)
