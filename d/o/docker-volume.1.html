NOMBRE

docker-volume - Gestionar volúmenes

SINOPSIS

docker volume COMANDO

DESCRIPCIÓN

El comando docker volume tiene subcomandos para gestionar volúmenes de datos. Un volumen de datos es un directorio especialmente designado que omite la gestión del controlador de almacenamiento.

Los volúmenes de datos persisten los datos independientemente del ciclo de vida de un contenedor. Cuando eliminas un contenedor, el demonio de Docker no elimina ningún volumen de datos. Puedes compartir volúmenes entre múltiples contenedores. Además, puedes compartir volúmenes de datos con otros recursos informáticos de tu sistema.

Para ver la ayuda de un subcomando, usa:

docker volume COMANDO --help

Para obtener detalles completos sobre el uso de docker volume, visita la documentación en línea de Docker.
