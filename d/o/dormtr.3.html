DORMTR

Propósito:

!>
!> DORMTR sobrescribe la matriz real general M por N, C, con
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> donde Q es una matriz ortogonal real de orden nq, con nq = m si
!> SIDE = 'L' y nq = n si SIDE = 'R'. Q se define como el producto de
!> nq-1  reflectores elementales, tal como se devuelve por DSYTRD:
!>
!> si UPLO = 'U', Q = H(nq-1) . . . H(2) H(1);
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(nq-1).
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda;
!>          = 'R': aplicar Q o Q**T desde la Derecha.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U': El triángulo superior de A contiene reflectores elementales
!>                 de DSYTRD;
!>          = 'L': El triángulo inferior de A contiene reflectores elementales
!>                 de DSYTRD.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'T':  Transpuesta, aplicar Q**T.
!>

M

!>          M es ENTERO
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz C. N >= 0.
!>

A

!>          A es un array de DOBLE PRECISIÓN, dimensión
!>                               (LDA,M) si SIDE = 'L'
!>                               (LDA,N) si SIDE = 'R'
!>          Los vectores que definen los reflectores elementales, tal como
!>          se devuelve por DSYTRD.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.
!>          LDA >= max(1,M) si SIDE = 'L'; LDA >= max(1,N) si SIDE = 'R'.
!>

TAU

!>          TAU es un array de DOBLE PRECISIÓN, dimensión
!>                               (M-1) si SIDE = 'L'
!>                               (N-1) si SIDE = 'R'
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i), tal como se devuelve por DSYTRD.
!>

C

!>          C es un array de DOBLE PRECISIÓN, dimensión (LDC,N)
!>          A la entrada, la matriz C de M por N.
!>          A la salida, C se sobrescribe con Q*C o Q**T*C o C*Q**T o C*Q.
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= N*NB si SIDE = 'L', y
!>          LWORK >= M*NB si SIDE = 'R', donde NB es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tenía un valor ilegal
!>
