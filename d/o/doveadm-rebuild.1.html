NOMBRE

doveadm-rebuild - Comandos relacionados con la reconstrucción de varios aspectos de los correos que coinciden con la consulta de búsqueda dada.

SINOPSIS

doveadm [OPCIONES GLOBALES] [-f formateador] rebuild <comando> [-S ruta_del_socket] -A consulta_de_búsqueda

doveadm [OPCIONES GLOBALES] [-f formateador] rebuild <comando> [-S ruta_del_socket] -F archivo consulta_de_búsqueda

doveadm [OPCIONES GLOBALES] [-f formateador] rebuild <comando> [-S ruta_del_socket] --no-userdb-lookup consulta_de_búsqueda

doveadm [OPCIONES GLOBALES] [-f formateador] rebuild <comando> [-S ruta_del_socket] -u usuario consulta_de_búsqueda

DESCRIPCIÓN


El comando se usa para reconstruir la presencia de adjuntos. doveadm(1) imprimirá el uid del mensaje para cada coincidencia.


opciones, doveadm(1) imprimirá los campos

En la primera forma, doveadm(1) ejecutará el

En la segunda forma, el comando se realizará para todos los usuarios listados en el archivodado.

En la tercera forma, el comando se realizará para el usuario contenido en la variable de entorno USER .

En la última forma, solo se reconstruirán los correos coincidentes del usuario (s) dado.

OPCIONES GLOBALES

Las opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, usar solo los valores por defecto. El ajuste dovecot_storage_version tiene como valor por defecto la última versión, pero puede ser sobrescrito con

-k

Preservar todo el entorno para doveadm, no solo el ajuste import_environment .

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-de-instancia

Si se usan múltiples instancias de Dovecot, elegir el archivo de configuración basado en este nombre de instancia.

Ver el ajuste instance_name para más información.

-c archivo-de-configuración

Leer la configuración del archivo-de-configuracióndado. Por defecto primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o ajuste=valor

Sobrescribe el ajuste de configuración ajuste de /etc/dovecot/dovecot.conf y de la userdb con el valordado. Para sobrescribir múltiples ajustes, la opción -o puede especificarse varias veces.

-f formateador

Especifica el formateador para formatear la salida. Los formateadores soportados son:

flow

imprime cada línea con pares clave=valor .

json

imprime un array JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con un carácter de avance de formulario (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separadas por tabuladores.

table

imprime una cabecera de tabla seguida de líneas de valores ajustadas.

Este comando usa por defecto el formateador de salida flow (sin el prefijo clave =).

OPCIONES

-A

Si la opción -A está presente, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd } , porque contiene también usuarios con un UID inferior al configurado con el ajuste first_valid_uid .

Cuando se usa el módulo userdb SQL, asegúrese de que el ajuste userdb_sql_iterate_query coincida con la estructura de su base de datos.

Cuando se usa el módulo userdb LDAP, asegúrese de que los ajustes userdb_fields y userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecutar el comando para todos los usuarios del archivo. Esto es similar a la opción -A , pero en lugar de obtener la lista de usuarios de la userdb, se leen del archivodado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realizar la búsqueda en la userdb. Usar la variable de entorno USER para especificar el nombre de usuario.

-S ruta_del_socket

El argumento de la opción es o bien una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre_de_host:puerto), para conectarse a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar los comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecutar el comando solo para el usuariodado. También es posible usar los comodines '*' y '?' (p. ej. -u *@example.org).

ARGUMENTOS

consulta_de_búsqueda

Restablece el indicador de adjunto para los mensajes que coinciden con esta consulta de búsqueda. Ver doveadm-search-query(7) para más detalles.

EJEMPLO

Reconstruir el estado de adjuntos del usuario bob:

doveadm rebuild attachments -u bob ALL

    NOMBRE

    doveadm-rebuild — Reconstruye índices de mensajes

    SINOPSIS

    doveadm rebuild [OPCIONES] [ARGUMENTOS]

    DESCRIPCIÓN

    Reconstruye los índices de los mensajes especificados. Esto puede ser útil si los índices se corrompen o se pierden. El comando solo funciona con backends de índice que se puedan reconstruir (por ejemplo, index_dir).

    OPCIONES

    -A, --all

    Procesa todos los buzones de correo del usuario.

    -m <buzón>, --mailbox <buzón>

    Procesa solo el buzón especificado.

    -i <ID_mensaje>, --uid <ID_mensaje>

    Procesa solo el mensaje con el UID especificado.

    -u <usuario>, --user <usuario>

    Procesa solo los buzones del usuario especificado.

    ARGUMENTOS

    Si no se especifican argumentos, se procesarán todos los buzones del usuario actual.

    <usuario>

    Uno o más usuarios de correo cuyos buzones se procesarán.

    <buzón>

    Uno o más buzones de correo que se procesarán.

    <ID_mensaje>

    Uno o más UIDs de mensajes que se procesarán.

    EJEMPLO

    Reconstruir los índices de todos los buzones del usuario 'testuser':

    doveadm rebuild -u testuser -A

    Reconstruir el índice del buzón 'INBOX.Sent' del usuario 'testuser':

    doveadm rebuild -u testuser -m INBOX.Sent

    REPORTAR ERRORES

    Informe de errores a <users@dovecot.org>, la lista de correo de usuarios de Dovecot.
