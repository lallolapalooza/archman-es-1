NOMBRE

doveadm-stats - Inspeccionar o restablecer estadísticas

SINOPSIS

doveadm [OPCIONES GLOBALES] stats add [ --description <cadena> ] [ --exporter <nombre> ] [ --exporter-include <campos> ] [ --fields <campos> ] [--group_by <campos> ] nombre <filtro>

doveadm [OPCIONES GLOBALES] stats dump [ -s <ruta del socket de estadísticas> ] [ -r ] [ -f <campos> ]

doveadm [OPCIONES GLOBALES] stats top [-s <ruta del socket de estadísticas>] [-b] [sort <campo>]

doveadm [OPCIONES GLOBALES] stats remove [ <nombre> ]

doveadm [OPCIONES GLOBALES] stats reopen

DESCRIPCIÓN

Comandos para inspeccionar y editar la generación de estadísticas/métricas de Dovecot.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita verbosidad y mensajes de depuración.

-O

No leer ningún archivo de configuración, usar solo los valores predeterminados. El ajuste dovecot_storage_version tiene como valor predeterminado la última versión, pero puede ser anulado con

-k

Conservar todo el entorno para doveadm, no solo el ajuste import_environment .

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-de-instancia

Si se usan múltiples instancias de Dovecot, elegir el archivo de configuración basado en este nombre de instancia.

Ver el ajuste instance_name para más información.

-c archivo-de-configuración

Leer la configuración del archivo-de-configuracióndado. Por defecto primero lee el socket de configuración, y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o ajuste=valor

Anula el ajuste de configuración /etc/dovecot/dovecot.conf y de la userdb con el valordado. Para anular múltiples ajustes, la opción -o puede especificarse varias veces.

COMANDOS

stats add

doveadm [OPCIONES GLOBALES] stats add [ --description <cadena> ] [ --exporter <nombre> ] [ --exporter-include <campos> ] [ --fields <campos> ] [--group_by <campos> ] nombre <filtro>

doveadm stats add se usa para añadir métricas a las estadísticas.

OPCIONES

--description <cadena>

Descripción legible por humanos de la métrica. Se incluye en el texto HELP enviado a OpenMetrics.

--exporter <nombre>

Exportar los eventos que coincidan con el filtro con este exportador de eventos. Si está vacío, los eventos se usan solo para estadísticas, y no se realiza ninguna exportación.

--exporter-include <campos>

Especifica qué partes del evento se exportan al evento serializado. Los campos están separados por espacios.

--fields <campos>

Una lista de campos incluidos en la métrica. Todos los eventos tienen un campo duration predeterminado que no necesita listarse explícitamente.

--group-by <campos>

Crea un nuevo group_by para generar dinámicamente sub-métricas basadas en los valores del campo especificado.

ARGUMENTOS

nombre

Nombre de la métrica.

filtro

Opciones de filtro:

•
user=<comodín>

: Coincidir con el usuario.

•
domain=<comodín>

: Coincidir con el nombre de dominio DNS.

•
session=<cadena>

: Coincidir con el identificador de sesión.

•
ip=<ip>[/<máscara>]

: Coincidir con la IP local o remota.

•
since=<marca de tiempo>

: Coincidir con la hora de inicio de sesión.

•
connected

: Mostrar solo sesiones conectadas.

stats dump

doveadm [OPCIONES GLOBALES] stats dump [ -s <ruta del socket de estadísticas> ] [ -r ] [ -f <campos> ]

doveadm stats dump se usa para mostrar las estadísticas.

OPCIONES

-f

POR HACER

-r

Restablece las estadísticas después de volcarlas.

-s ruta-del-socket

Ruta del socket de estadísticas.

stats remove

doveadm [OPCIONES GLOBALES] stats remove [ <nombre> ]

doveadm stats remove se usa para eliminar métricas de las estadísticas.

ARGUMENTOS

nombre

El nombre de la métrica a eliminar.

stats reopen

doveadm [OPCIONES GLOBALES] stats reopen

doveadm stats reopen se usa para reabrir los archivos de los exportadores de archivos.
