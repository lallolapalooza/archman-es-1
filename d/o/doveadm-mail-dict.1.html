NOMBRE

doveadm-dict - Comandos relacionados con la manipulación de diccionarios en el contexto del usuario

SINOPSIS

doveadm [OPCIONES GLOBALES] dict comando [-u usuario] [OPCIONES] nombre-del-filtro-de-configuración [argumentos]

doveadm [OPCIONES GLOBALES] mail dict comando [OPCIONES] nombre-del-filtro-de-configuración [argumentos]

DESCRIPCIÓN

doveadm dict y doveadm mail dict pueden usarse para consultar y modificar entradas de diccionario.

El comando doveadm mail dict puede usarse dentro de un contexto de usuario específico. Esto puede ser útil si, por ejemplo, la búsqueda en la userdb devuelve ajustes de diccionario específicos del usuario. De lo contrario, los comandos se comportan de manera idéntica.

nombre-del-filtro-de-configuración

Nombre del filtro a usar al buscar los ajustes del diccionario. Por ejemplo mail_attribute, quota_clone. También es posible usar un nombre de filtro vacío y especificar los ajustes del diccionario usando los parámetros -o .

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita mensajes detallados y de depuración.

-O

No leer ningún archivo de configuración, usar solo los valores predeterminados. El ajuste dovecot_storage_version tiene como valor predeterminado la última versión, pero puede ser sobrescrito con

-k

Conservar todo el entorno para doveadm, no solo el ajuste import_environment .

-v

Habilita mensajes detallados, incluyendo el contador de progreso.

-i nombre-de-instancia

Si se usan múltiples instancias de Dovecot, elegir el archivo de configuración basándose en este nombre de instancia.

Consultar el ajuste instance_name para más información.

-c archivo-de-configuración

Leer la configuración del archivo de configuración dado. Por defecto, primero lee el socket de configuración y luego recurre a archivo-de-configuración. Por defecto /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o ajuste=valor

Sobrescribe el ajuste de configuración ajuste de /etc/dovecot/dovecot.conf y de la userdb con el valordado. Para sobrescribir múltiples ajustes, la opción -o puede especificarse varias veces.

-f formateador

Especifica el formateador para formatear la salida. Los formateadores soportados son:

flow

imprime cada línea con pares clave=valor .

json

imprime un array JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con el carácter de avance de formulario (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separadas por tabuladores.

table

imprime una cabecera de tabla seguida de líneas de valores ajustadas.

OPCIONES

Opciones específicas del comando doveadm dict ::

-u usuario

El usuario a usar.

Opciones específicas del comando doveadm mail dict ::

-A

Si la opción -A está presente, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd } , porque también contiene usuarios con un UID menor que el configurado con el ajuste first_valid_uid .

Cuando se usa el módulo userdb SQL, asegurarse de que el ajuste userdb_sql_iterate_query coincida con la estructura de su base de datos.

Cuando se usa el módulo userdb LDAP, asegurarse de que los ajustes userdb_fields y userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecutar el comando para todos los usuarios en el archivo. Esto es similar a la opción -A , pero en lugar de obtener la lista de usuarios de la userdb, se leen del archivodado. El archivo contiene un nombre de usuario por línea.

-S ruta-del-socket

El argumento de la opción es o bien una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre-de-host:puerto), para conectarse a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecutar el comando solo para el usuariodado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).

COMANDOS

get

doveadm [OPCIONES GLOBALES] dict get [-u usuario] nombre-del-filtro-de-configuración clave

doveadm [OPCIONES GLOBALES] mail dict get [-A | -u usuario | -F archivo] [-S ruta-del-socket] nombre-del-filtro-de-configuración clave

Obtener una clave de un diccionario.

clave

La clave a obtener.

iter

doveadm [OPCIONES GLOBALES] dict iter [-u usuario] [-1RV] nombre-del-filtro-de-configuración prefijo

doveadm [OPCIONES GLOBALES] mail dict iter [-A | -u usuario | -F archivo] [-S ruta-del-socket] [-1RV] nombre-del-filtro-de-configuración prefijo

Encontrar las claves que coinciden con un prefijo en un diccionario.

-1

Coincidencia exacta.

-R

Recursivo.

-V

No imprimir valores, solo nombres de claves.

prefijo

El prefijo de clave a buscar.

Listar las claves en el diccionario.

inc

doveadm [OPCIONES GLOBALES] dict inc [-u usuario] [-t marca-de-tiempo-ms] nombre-del-filtro-de-configuración clave diferencia

doveadm [OPCIONES GLOBALES] mail dict inc [-A | -u usuario | -F archivo] [-S ruta-del-socket] [-t marca-de-tiempo-ms] nombre-del-filtro-de-configuración clave diferencia

Incrementar el valor de una clave numérica en las claves del diccionario.

-t marca-de-tiempo-ms

Establecer también la marca de tiempo.

clave

La clave a incrementar.

diferencia

La cantidad del incremento.

doveadm [OPCIONES GLOBALES] dict doveadm-mail-dict(1)

NAME

doveadm-mail-dict — manipulador de diccionarios de correo

SYNOPSIS

doveadm [GLOBAL OPTIONS] mail dict set [-u user] [-t timestamp-msecs] [-e expire-secs] config-filter-name key value

doveadm [GLOBAL OPTIONS] mail dict unset [-u user] [-t timestamp-msecs] config-filter-name key

DESCRIPTION

El comando doveadm mail dict se utiliza para manipular los diccionarios de Dovecot. Permite establecer o eliminar claves y sus valores asociados.

set

doveadm [GLOBAL OPTIONS] mail dict set [-u user] [-t timestamp-msecs] [-e expire-secs] config-filter-name key value

Establece/crea claves en el diccionario.

-t timestamp-msecs

Establece también la marca de tiempo.

-e expire-secs

Establece también la duración de la clave.

key

La clave a establecer.

value

El valor a establecer.

unset

doveadm [GLOBAL OPTIONS] mail dict unset [-u user] [-t timestamp-msecs] config-filter-name key

Elimina una clave del diccionario.

-t timestamp-msecs

Establece también la marca de tiempo.

key

La clave a eliminar.
