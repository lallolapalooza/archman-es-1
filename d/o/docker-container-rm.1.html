NOMBRE

docker-container-rm - Elimina uno o más contenedores

SINOPSIS

docker container rm [OPCIONES] CONTENEDOR [CONTENEDOR...]

DESCRIPCIÓN

docker container rm eliminará uno o más contenedores del nodo host. Se puede usar el nombre o ID del contenedor. Esto no elimina imágenes. No se puede eliminar un contenedor en ejecución a menos que se use la opción -f. Para ver todos los contenedores en un host, usa el comando docker container ls -a.

EJEMPLOS

Eliminar un contenedor usando su ID

Para eliminar un contenedor usando su ID, que se puede encontrar con un comando docker ps -a, o usar el ID devuelto por el comando docker run, o recuperarlo de un archivo usado para almacenarlo usando docker run --cidfile:

docker container rm abebf7571666

Eliminar un contenedor usando el nombre del contenedor

El nombre del contenedor se puede encontrar usando el comando docker ps -a. Usa ese nombre de la siguiente manera:

docker container rm hopeful_morse

Eliminar un contenedor y todos los volúmenes asociados

$ docker container rm -v redis
redis

Este comando eliminará el contenedor y cualquier volumen asociado con él. Ten en cuenta que si un volumen se especificó con un nombre, no se eliminará.

$ docker create -v awesome:/foo -v /bar --name hello redis
hello
$ docker container rm -v hello

En este ejemplo, el volumen para /foo permanecerá intacto, pero el volumen para /bar se eliminará. El mismo comportamiento se aplica a los volúmenes heredados con --volumes-from.

OPCIONES

-f, --force[=false] Forzar la eliminación de un contenedor en ejecución (usa SIGKILL)

-l, --link[=false] Eliminar el enlace especificado

-v, --volumes[=false] Eliminar volúmenes anónimos asociados con el contenedor
