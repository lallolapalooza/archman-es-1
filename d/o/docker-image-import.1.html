DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker-image-import - Importa el contenido de un tarball para crear una imagen de sistema de archivos

SINOPSIS

docker image import [OPCIONES] archivo|URL|- [REPOSITORIO[:TAG]]

DESCRIPCIÓN

Crea una nueva imagen de sistema de archivos a partir del contenido de un tarball (.tar, .tar.gz, .tgz, .bzip, .tar.xz, .txz) y, opcionalmente, le asigna una etiqueta.

EJEMPLOS

Importar desde una ubicación remota

# docker image import http://example.com/exampleimage.tgz example/imagerepo

Importar desde un archivo local

Importar a Docker a través de una tubería y stdin:

# cat exampleimage.tgz | docker image import - example/imagelocal

Importar con un mensaje de commit.

# cat exampleimage.tgz | docker image import --message "Nueva imagen importada desde tarball" - exampleimagelocal:new

Importar a una imagen de Docker desde un archivo local.

# docker image import /ruta/a/exampleimage.tgz

Importar desde un archivo local y asignar etiqueta

Importar a Docker a través de una tubería y stdin:

# cat exampleimageV2.tgz | docker image import - example/imagelocal:V-2.0

Importar desde un directorio local

# tar -c . | docker image import - exampleimagedir

Aplicar instrucciones específicas de Dockerfile al importar la imagen

Este ejemplo establece la variable de entorno ENV de la imagen de Docker DEBUG a true por defecto.

# tar -c . | docker image import -c="ENV DEBUG=true" - exampleimagedir

Cuando el demonio soporta múltiples sistemas operativos

Si el demonio soporta múltiples sistemas operativos y la imagen que se importa no coincide con el sistema operativo predeterminado, puede ser necesario añadir --platform. Esto sería necesario al importar una imagen de Linux en un demonio de Windows.

# docker image import --platform=linux .\linuximage.tar

Ver también

docker-export(1) para exportar el contenido de un sistema de archivos como un archivo tar a STDOUT.

OPCIONES

-c, --change= Aplica una instrucción de Dockerfile a la imagen creada

-m, --message="" Establece el mensaje de commit para la imagen importada

--platform="" Establece la plataforma si el servidor es capaz de manejar múltiples plataformas
