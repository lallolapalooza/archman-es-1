NOMBRE

docker-container-attach - Adjuntar flujos de entrada, salida y error estándar locales a un contenedor en ejecución

SINOPSIS

docker container attach [OPCIONES] CONTENEDOR

DESCRIPCIÓN

El comando docker attach permite adjuntarse a un contenedor en ejecución utilizando el ID o el nombre del contenedor, ya sea para ver su salida continua o para controlarlo interactivamente. Puede adjuntarse al mismo proceso contenido varias veces simultáneamente, al estilo de compartir pantalla, o ver rápidamente el progreso de su proceso desvinculado.

Para detener un contenedor, use CTRL-c. Esta secuencia de teclas envía SIGKILL al contenedor. Puede desvincularse del contenedor (y dejarlo en ejecución) usando una secuencia de teclas configurable. La secuencia predeterminada es CTRL-p CTRL-q. Puede configurar la secuencia de teclas usando la opción --detach-keys o un archivo de configuración. Consulte config-json(5) para obtener documentación sobre el uso de un archivo de configuración.

Está prohibido redirigir la entrada estándar de un comando docker attach mientras se adjunta a un contenedor habilitado para TTY (es decir, iniciado con -i y -t).

EJEMPLOS

Adjuntándose a un contenedor

En este ejemplo, el comando top se ejecuta dentro de un contenedor de una imagen de Ubuntu, en modo desvinculado, luego se adjunta a él y luego termina el contenedor con CTRL-c:

$ docker run -d --name topdemo alpine top -b
$ docker attach topdemo

Anular la secuencia de desvinculación

Utilice la opción --detach-keys para anular la secuencia de teclas de Docker para desvincularse. Esto es útil si la secuencia predeterminada de Docker entra en conflicto con una secuencia de teclas que utiliza para otras aplicaciones. Hay dos formas de definir su propia secuencia de teclas de desvinculación: como una anulación por contenedor o como una propiedad de configuración en toda su configuración.

Para anular la secuencia de un contenedor individual, utilice el indicador --detach-keys=tecla con el comando docker attach. El formato de la tecla es una letra [a-Z] o ctrl-valor, donde valor es uno de los siguientes:

  • a-z (un solo carácter alfabético minúsculo)
  • @ (símbolo arroba)
  • [ (corchete izquierdo)
  • *\\* (dos barras invertidas)
  • _ (guion bajo)
  • ^ (acento circunflejo)

Estos valores a, ctrl-a, X, o *ctrl-\* son todos ejemplos de secuencias de teclas válidas. Para configurar una secuencia de teclas predeterminada de configuración diferente para todos los contenedores, consulte docker(1).

OPCIONES

--detach-keys="" Anular la secuencia de teclas para desvincular un contenedor

--no-stdin[=false] No adjuntar STDIN

--sig-proxy[=true] Reenviar todas las señales recibidas al proceso
