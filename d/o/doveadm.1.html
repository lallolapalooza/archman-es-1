NOMBRE

doveadm - Utilidad de administración de Dovecot

SINOPSIS

doveadm [-DOkv] [-i nombre-instancia] [-c archivo-config] [-o clave=valor [ .. ]] [-f formateador] comando [opciones-comando] [argumentos-comando]

DESCRIPCIÓN

doveadm es la herramienta de administración de Dovecot. Se puede utilizar para gestionar diversas partes de Dovecot, así como para acceder a los buzones de los usuarios.

Ejecute doveadm help para obtener una lista de los comandos disponibles.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lee ningún archivo de configuración, solo utiliza los valores predeterminados. El ajuste dovecot_storage_version por defecto es la última versión, pero puede ser anulado con

-k

Preserva el entorno completo para doveadm, no solo el ajuste import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-instancia

Si se utilizan múltiples instancias de Dovecot, elige el archivo de configuración basado en este nombre de instancia.

Consulte el ajuste instance_name para más información.

-c archivo-config

Lee la configuración desde el archivo-config proporcionado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o ajuste=valor

Anula el ajuste de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor proporcionado. Para anular múltiples ajustes, la opción -o puede especificarse varias veces.

-f formateador

Especifica el formateador para dar formato a la salida. Los formateadores soportados son:

flow

imprime cada línea con pares clave=valor.

json

imprime un array JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con un carácter de avance de formulario (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separados por tabulaciones.

table

imprime una cabecera de tabla seguida de líneas de valores ajustados.

COMANDOS

Estos comandos interactúan directamente con el proceso maestro de Dovecot.

doveadm reload

Fuerza a dovecot(1) a recargar la configuración.

doveadm stop

Detiene dovecot(1) y todos sus procesos hijos.

NAME

doveadm - Dovecot's administration utility

SYNOPSIS

doveadm [-Dv] [-f fasta] [-o property=value] [-u user] [command]

DESCRIPTION

The doveadm utility is used to manage Dovecot mail server.

The command is composed of a global options and a command. If a command is not specified, doveadm runs in interactive mode.

If no user is specified with the -u option, the current user is used.

GLOBAL OPTIONS

These options can be given before or after the command:

-D
Prints debugging messages. Can be specified multiple times.
-f fasta
Specifies the mail format. Possible values are:

maildir

mbox

dbox

auto (default)

This option is used by the following commands:

backup
dump
import
index
load
move
purge
save
search
sync
-o property=value
Overrides a configuration value. Dovecot is configured in multiple files, and this option allows overriding a specific value.
-u user
Operates on the specified user.
-v
Enables verbosity. Can be specified multiple times.

EXIT STATUS

doveadm will exit with one of the following values:

0

Selected command was executed successful.

64

Command line usage error.

65

Data format error or operation is not possible.

67

User does not exist.

68

Input file, address or other resource does not exist.

73

Cannot create output file.

75

There was some temporary error, check logs.

76

Protocol error during remote host connection.

77

Permission error.

78

Configuration error.

127

Unknown error.
