NOMBRE

doveadm-service-status - Muestra información sobre los servicios de dovecot

SINOPSIS

doveadm [OPCIONES GLOBALES] service status [servicio [...]]

DESCRIPCIÓN

doveadm service status produce una tabla con una línea para cada servicio, que contiene los siguientes detalles:

name

el nombre del servicio

process_count

el número de procesos realmente en ejecución para el servicio

process_avail

el número de procesos adicionales que se pueden generar para el servicio

process_limit

el número máximo de procesos que pueden estar activos para el servicio

client_limit

el número máximo de conexiones que el servicio manejará simultáneamente

throttle_secs

segundos a esperar antes de lanzar otro proceso cuando los procesos están muriendo inesperadamente pronto para el servicio

exit_failure_last

marca de tiempo de cuando el último proceso fue terminado anormalmente para el servicio

exit_failures_in_sec

número de procesos terminados anormalmente para el servicio en el último segundo

last_drop_warning

marca de tiempo de cuando se registró por última vez una advertencia de "dropping client connections" (descartando conexiones de clientes)

listen_pending

si el proceso maestro está encolando conexiones que necesitan ser despachadas

listening

si el servicio está escuchando

doveadm_stop

si el servicio ha sido detenido por doveadm(1)

process_total

el número total de procesos bifurcados para el servicio desde el inicio del servicio.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita verbosidad y mensajes de depuración.

-O

No leer ningún archivo de configuración, usar solo los valores predeterminados. El dovecot_storage_version ajuste tiene como valor predeterminado la última versión, pero se puede sobreescribir con

-k

Preservar todo el entorno para doveadm, no solo el ajuste import_environment .

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-de-instancia

Si se usan múltiples instancias de Dovecot, elegir el archivo de configuración basado en este nombre de instancia.

Ver instance_name ajuste para más información.

-c archivo-de-configuración

Leer la configuración del archivo-de-configuracióndado. Por defecto primero lee el socket de configuración, y luego recurre a /etc/dovecot/dovecot.conf. También se puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o ajuste=valor

Sobreescribe el ajuste de configuración ajuste de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valordado. Para sobreescribir múltiples ajustes, la opción -o puede especificarse múltiples veces.

-f formateador

Especifica el formateador para formatear la salida. Los formateadores soportados son:

flow

imprime cada línea con pares clave=valor .

json

imprime un array JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con el carácter de salto de página (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separadas por tabuladores.

table

imprime una cabecera de tabla seguida de líneas de valores ajustadas.

ARGUMENTOS

servicio (opcional)

Filtra la lista según el servicio o servicios especificados. Por defecto, se listan todos los servicios de dovecot.

EJEMPLOS

doveadm service status
name: imap-login
process_count: 0
process_avail: 0
process_limit: 1
client_limit: 1000
throttle_secs: 0
exit_failure_last: 0
exit_failures_in_sec: 0
last_drop_warning: 0
listen_pending: n
listening: y
doveadm_stop: n
process_total: 0

INFORME DE ERRORES

Informe de errores, incluyendo la salida de doveconf -n , a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. Información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
