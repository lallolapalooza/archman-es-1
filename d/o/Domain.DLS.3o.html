Módulo DLS
: sig end

Almacenamiento local de dominio

tipo 'a clave

Tipo de una clave DLS

val nueva_clave : ?dividir_desde_padre:('a -> 'a) -> (unidad -> 'a) -> 'a clave

nueva_clave f devuelve una nueva clave vinculada al inicializador f para acceder a variables locales de dominio.

Si no se proporciona dividir_desde_padre, el valor para un nuevo dominio se calculará bajo demanda por el nuevo dominio: la primera llamada a obtener llamará al inicializador f y almacenará ese valor.

Advertencia. f puede ser llamado varias veces si otra llamada a obtener ocurre durante la inicialización en el mismo dominio. Solo el valor 'primero' calculado se utilizará, los otros valores ahora inútiles se descartarán. Su función de inicialización debe admitir esta situación o contener lógica para detectar este caso y fallar.

Si se proporciona dividir_desde_padre, la creación de un dominio derivará el valor del hijo (para esta clave) del valor del padre. Este cálculo ocurre en el dominio padre y siempre ocurre, independientemente de si el dominio hijo lo usará. Si la función de división es costosa o requiere cálculo del lado del hijo, considere usar clave 'a Lazy.t:

        let init () = ...
        let split_from_parent parent_value =
          ... cálculo del lado del padre ...;
          lazy (
            ... cálculo del lado del hijo ...
          )
        let key = Domain.DLS.new_key ~split_from_parent init
        let get () = Lazy.force (Domain.DLS.get key)

En este caso, una parte del cálculo ocurre en el dominio hijo; en particular, puede acceder a valor_padre concurrentemente con el dominio padre, lo que puede requerir sincronización explícita para evitar carreras de datos.

val obtener : 'a clave -> 'a

obtener k devuelve v si hay un valor v asociado a la clave k en el estado local del dominio del llamador. Establece el valor de k con su inicializador y lo devuelve en caso contrario.

val establecer : 'a clave -> 'a -> unidad

establecer k v actualiza el estado local del dominio del llamador para asociar la clave k con el valor v. Sobrescribe cualquier valor previo asociado a k, que no puede ser restaurado después.
