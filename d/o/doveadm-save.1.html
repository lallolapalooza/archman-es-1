NOMBRE

doveadm-save - Guardar correo en el buzón de un usuario

SINOPSIS

doveadm [OPCIONES GLOBALES] save [-S ruta_socket] -A [-m buzon] [-U uid] [-g guid] [-r fecha_recibido] [archivo_correo]

doveadm [OPCIONES GLOBALES] save [-S ruta_socket] -F archivo [-m buzon] [-U uid] [-g guid] [-r fecha_recibido] [archivo_correo]

doveadm [OPCIONES GLOBALES] save [-S ruta_socket] --no-userdb-lookup [-m buzon] [-U uid] [-g guid] [-r fecha_recibido] [archivo_correo]

doveadm [OPCIONES GLOBALES] save [-S ruta_socket] -u usuario [-m buzon] [-U uid] [-g guid] [-r fecha_recibido] [archivo_correo]

DESCRIPCIÓN

doveadm save se puede utilizar para guardar mensajes. Esto puede ser útil para scripts y para depuración. No se invoca Sieve para los mensajes guardados, pero se aplica la cuota.

OPCIONES GLOBALES

doveadm(1) global

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lee ningún archivo de configuración, solo usa los valores predeterminados. La configuración dovecot_storage_version se establece en la última versión por defecto, pero se puede anular con

-k

Preserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre_instancia

Si se utilizan varias instancias de Dovecot, elige el archivo de configuración según este nombre de instancia.

Consulta la configuración instance_name para obtener más información.

-c archivo_config

Lee la configuración del archivo_config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración del archivo de configuración /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular varias configuraciones, la opción -o puede especificarse varias veces.

OPCIONES

-A

Si está presente la opción -A, el comando se realizará para todos los usuarios. No se recomienda el uso de esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, porque también incluye usuarios con un UID inferior al configurado con la configuración first_valid_uid.

Cuando se utiliza el módulo userdb SQL, asegúrate de que la configuración userdb_sql_iterate_query coincida con la estructura de tu base de datos.

Cuando se utiliza el módulo userdb LDAP, asegúrate de que las configuraciones userdb_fields y userdb_ldap_iterate_fields coincidan con tu esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecuta el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo dado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realiza la búsqueda en la base de datos de usuarios. Usa la variable de entorno USER para especificar el nombre de usuario.

-S ruta_socket

El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre_host:puerto), para conectar un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecuta el comando solo para el usuario dado. También es posible usar comodines '*' y '?' (por ejemplo, -u *@example.org).

-m buzon

Almacena el correo en el buzón especificado en lugar de en la BANDEJA DE ENTRADA.

-U uid

Guarda el correo usando el UID dado, si es posible.

-g guid

Guarda el correo usando el GUID dado.

-r fecha_recibido

Guarda el correo usando la marca de tiempo de fecha de recepción dada. Esto está en el formato de "marca de tiempo legible" como se describe en doveadm-search-query(7).

ARGUMENTOS

archivo_correo

Los datos del mensaje a guardar.

  • Si archivo_correo es -, el mensaje se lee desde stdin (por defecto).
  • De lo contrario, archivo_correo se resuelve como una ruta de archivo.

EJEMPLO

echo "hola, mundo" | doveadm save -u testuser@testdomain

REPORTAR ERRORES

Reporta errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html

    doveadm-save(1)

    doveadm-save - save mail to Maildir or mbox folder

    SYNOPSIS

    doveadm [-Dv] [-f formatter] [-o property=value] save [-A] [-u user] [-m] [-S mailbox] [<infile]

    DESCRIPTION

    The doveadm save command saves the given mail to a specified Maildir or mbox folder. The mail is read from stdin if no input file is specified.

    OPTIONS

    -A Save mail to all users’ mailboxes.

    -u user Save mail to the specified user’s mailbox.

    -m Save mail to the specified mailbox. Without this option, the mailbox is assumed to be Maildir or mbox format.

    -S mailbox Save mail to the specified mailbox. Without this option, the mailbox is assumed to be Maildir or mbox format.

    See also doveadm-log(1), doveadm-mail-format(7).

    EXAMPLE

    Save the mail from stdin to the user’s INBOX:

    cat email.txt | doveadm save -u user@example.com INBOX
