DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine dorglq (integer m, integer n, integer k, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer lwork, integer info)

DORGLQ

Propósito:

!>
!> DORGLQ genera una matriz real M-por-N, Q, con filas ortonormales,
!> que se define como las primeras M filas de un producto de K reflectores
!> elementales de orden N
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tal como devuelve DGELQF.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q. N >= M.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>          A la entrada, la i-ésima fila debe contener el vector que define
!>          el reflector elemental H(i), para i = 1,2,...,k, tal como devuelve
!>          DGELQF en las primeras k filas de su array de argumentos A.
!>          A la salida, la matriz Q de M-por-N.
!>

LDA

!>          LDA es INTEGER
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array de DOUBLE PRECISION, dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve DGELQF.
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,M).
!>          Para un rendimiento óptimo, LWORK >= M*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tiene un valor ilegal
!>
