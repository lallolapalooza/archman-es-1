NOMBRE

docker-logs - Obtener los registros de un contenedor

SINOPSIS

docker logs [OPCIONES] CONTENEDOR

DESCRIPCIÓN

Alias de docker container logs.

OPCIONES

--details[=false] Mostrar detalles adicionales proporcionados a los registros

-f, --follow[=false] Seguir la salida de los registros

--since="" Mostrar registros desde la marca de tiempo (ej. "2013-01-02T13:23:37Z") o relativa (ej. "42m" para 42 minutos)

-n, --tail="all" Número de líneas a mostrar desde el final de los registros

-t, --timestamps[=false] Mostrar marcas de tiempo

--until="" Mostrar registros antes de una marca de tiempo (ej. "2013-01-02T13:23:37Z") o relativa (ej. "42m" para 42 minutos)
