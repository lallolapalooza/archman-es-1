NOMBRE

podman-unshare - Ejecuta un comando dentro de un nuevo espacio de nombres de usuario modificado

SINOPSIS

podman unshare [opciones] [comando]

DESCRIPCIÓN

Inicia un proceso (por defecto, $SHELL) en un nuevo espacio de nombres de usuario. El espacio de nombres de usuario se configura de tal manera que el UID y el GID principal del usuario que invoca aparecen como UID 0 y GID 0, respectivamente. Cualquier rango que coincida con ese usuario y grupo en /etc/subuid y /etc/subgid también se mapea como si fueran ellos mismos con la ayuda de los ayudantes newuidmap(1) y newgidmap(1).

podman unshare es útil para solucionar problemas de operaciones no privilegiadas y para borrar manualmente datos de almacenamiento y otros datos relacionados con imágenes y contenedores.

También es útil usar el comando podman mount. Si un usuario no privilegiado quiere montar y trabajar con un contenedor, entonces necesita ejecutar podman unshare. La ejecución de podman mount falla para usuarios no privilegiados a menos que el usuario se esté ejecutando dentro de una sesión de podman unshare.

La sesión unshare define dos variables de entorno:

  • CONTAINERS_GRAPHROOT: la ruta a los datos persistentes del contenedor.
  • CONTAINERS_RUNROOT: la ruta a los datos volátiles del contenedor.

IMPORTANTE: Este comando no está disponible con el cliente remoto de Podman.

OPCIONES

--help, -h

Imprime el enunciado de uso

--rootless-netns

Se une al espacio de nombres de red sin root utilizado para la red netavark. Se puede usar para conectarse a un contenedor sin root a través de una dirección IP (red bridge). Esto, de lo contrario, no es posible desde el espacio de nombres de red del host.

Códigos de Salida

El código de salida de podman unshare proporciona información sobre por qué el contenedor no se pudo ejecutar o por qué finalizó. Cuando los comandos podman unshare finalizan con un código distinto de cero, los códigos de salida siguen el estándar de chroot, ver abajo:

125 El error está con el propio Podman.

$ podman unshare --foo; echo $?
Error: unknown flag: --foo
125

126 Al ejecutar un comando contenido y el comando no se puede invocar.

$ podman unshare /etc; echo $?
Error: fork/exec /etc: permission denied
126

127 Al ejecutar un comando contenido y el comando no se encuentra.

$ podman unshare foo; echo $?
Error: fork/exec /usr/bin/bogus: no such file or directory
127

Código de salida código de salida del comando contenido

$ podman unshare /bin/sh -c 'exit 3'; echo $?
3

EJEMPLO

Ejecuta el comando especificado en el espacio de nombres de usuario sin root:

$ podman unshare id
uid=0(root) gid=0(root) groups=0(root),65534(nobody)

Muestra los mapeos del espacio de nombres de usuario para contenedores sin root:

$ podman unshare cat /proc/self/uid_map /proc/self/gid_map
         0       1000          1
         1      10000      65536
         0       1000          1
         1      10000      65536
