Propósito

:

!> !> DORBDB2 bidiagonaliza simultáneamente los bloques de una matriz alta y !> delgada X con columnas ortonormales: !> !> [ B11 ] !> [ X11 ] [ P1 | ] [ 0 ] !> [-----] = [---------] [-----] Q1**T . !> [ X21 ] [ | P2 ] [ B21 ] !> [ 0 ] !> !> X11 es P-por-Q, y X21 es (M-P)-por-Q. P no debe ser mayor que M-P, !> Q, o M-Q. Las rutinas DORBDB1, DORBDB3, y DORBDB4 manejan los casos en !> los que P no es la dimensión mínima. !> !> Las matrices ortogonales P1, P2, y Q1 son P-por-P, (M-P)-por-(M-P), !> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por !> vectores de Householder. !> !> B11 y B12 son matrices bidiagonales P-por-P representadas implícitamente por !> los ángulos THETA, PHI. !>

!>

!>
!>  Los bloques bidiagonales superiores B11, B21 se representan implícitamente por
!>  los ángulos THETA(1), ..., THETA(Q) y PHI(1), ..., PHI(Q-1). Cada entrada
!>  en cada banda bidiagonal es un producto de un seno o coseno de un THETA
!>  con un seno o coseno de un PHI. Ver [1] o DORCSD para detalles.
