NOMBRE

dovecot-sysreport - Utilidad de reporte de sistema de Dovecot

SINOPSIS

dovecot-sysreport [-h|--help] [-c|--core [binario] núcleo [...]] [-d|--destination destino] [-k|--keeptemp]

DESCRIPCIÓN

dovecot-sysreport es una utilidad que debe usarse para recopilar información del sistema actual para ser reportada para correcciones de errores de dovecot. Recopilará la salida de ps de dovecot, el estado del servicio, el estado del proceso, la salida del comando uptime, el registro de errores, un volcado de estadísticas y, si se le indica, un archivo core junto con sus dependencias binarias.

OPCIONES

-h|--help

Imprime un mensaje de ayuda.

-c|--config archivo_config_raíz

Establece el archivo raíz de la configuración de dovecot. Si no se establece, se asumirá que está en la ruta de configuración predeterminada.

-o|--core [ binario ] núcleo [...]

Incluye archivos core junto con sus dependencias extraídas del archivo binario especificado.

-d|--destination destino

Establece la ubicación del archivo donde se debe guardar el archivo del informe. El valor predeterminado es dovecot-sysreport-<hostname>-<timestamp_actual>.tar.gz en la ruta actual.

-k|--keeptemp

Si se establece, los archivos temporales no se eliminarán al final.

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
