Documentación de función/subrutina

subroutine dort01 (character rowcol, integer m, integer n, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( * ) work, integer lwork, double precision resid)

DORT01

Propósito:

!>
!> DORT01 comprueba que la matriz U es ortogonal calculando la relación
!>
!>    RESID = norm( I - U*U' ) / ( n * EPS ), si ROWCOL = 'R',
!> o
!>    RESID = norm( I - U'*U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
!> Alternativamente, si no hay suficiente espacio de trabajo para formar
!> I - U*U' o I - U'*U, la relación se calcula como
!>
!>    RESID = abs( I - U*U' ) / ( n * EPS ), si ROWCOL = 'R',
!> o
!>    RESID = abs( I - U'*U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
!> donde EPS es la precisión de la máquina. ROWCOL solo se usa si m = n;
!> si m > n, ROWCOL se asume como 'C', y si m < n, ROWCOL se
!> asume como 'R'.
!>

Parámetros

ROWCOL 
!>          ROWCOL es CHARACTER
!>          Especifica si las filas o columnas de U deben ser comprobadas
!>          para la ortogonalidad. Se usa solo si M = N.
!>          = 'R':  Comprobar filas ortogonales de U
!>          = 'C':  Comprobar columnas ortogonales de U
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz U.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz U.
!>

U

!>          U es array DOUBLE PRECISION, dimension (LDU,N)
!>          La matriz ortogonal U. U se comprueba para columnas ortogonales
!>          si m > n o si m = n y ROWCOL = 'C'. U se comprueba para
!>          filas ortogonales si m < n o si m = n y ROWCOL = 'R'.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M).
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. Para un rendimiento óptimo, LWORK
!>          debería ser al menos N*(N+1) si ROWCOL = 'C' o M*(M+1) si
!>          ROWCOL = 'R', pero la prueba se realizará incluso si LWORK es 0.
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          RESID = norm( I - U * U' ) / ( n * EPS ), si ROWCOL = 'R', o
!>          RESID = norm( I - U' * U ) / ( m * EPS ), si ROWCOL = 'C'.
!>
