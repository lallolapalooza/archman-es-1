Funciones de configuración

Estas funciones son utilizadas por el analizador léxico para asociar docstrings a las ubicaciones de los tokens.

val set_pre_docstrings : Lexing.position -> docstring list -> unit

Docstrings inmediatamente anteriores a un token

val set_post_docstrings : Lexing.position -> docstring list -> unit

Docstrings inmediatamente posteriores a un token

val set_floating_docstrings : Lexing.position -> docstring list -> unit

Docstrings no inmediatamente adyacentes a un token

val set_pre_extra_docstrings : Lexing.position -> docstring list -> unit

Docstrings inmediatamente posteriores al token que precede a este

val set_post_extra_docstrings : Lexing.position -> docstring list -> unit

Docstrings inmediatamente anteriores al token que sigue a este

Elementos

El Docstrings.docs tipo representa la documentación adjunta a un elemento.

type docs = {
docs_pre : docstring option ;
docs_post : docstring option ;
}

val empty_docs : docs

val docs_attr : docstring -> Parsetree.attribute

val add_docs_attrs : docs -> Parsetree.attributes -> Parsetree.attributes

Convertir la documentación del elemento en atributos y añadirlos a una lista de atributos

val symbol_docs : unit -> docs

Obtener la documentación del elemento para el símbolo actual. Esto también marca esta documentación (para advertencias de ambigüedad).

val symbol_docs_lazy : unit -> docs Lazy.t

val rhs_docs : int -> int -> docs

Obtener la documentación del elemento para los símbolos entre dos posiciones. Esto también marca esta documentación (para advertencias de ambigüedad).

val rhs_docs_lazy : int -> int -> docs Lazy.t

val mark_symbol_docs : unit -> unit

Marcar la documentación del elemento para el símbolo actual (para advertencias de ambigüedad).

val mark_rhs_docs : int -> int -> unit

Marcar como asociada la documentación del elemento para los símbolos entre dos posiciones (para advertencias de ambigüedad)

Campos y constructores

El Docstrings.info tipo representa la documentación adjunta a un campo o constructor.

type info = docstring option

val empty_info : info

val info_attr : docstring -> Parsetree.attribute

val add_info_attrs : info -> Parsetree.attributes -> Parsetree.attributes

Convertir la información del campo en atributos y añadirlos a una lista de atributos

val symbol_info : unit -> info

Obtener la información del campo para el símbolo actual.

val rhs_info : int -> info

Obtener la información del campo que sigue al símbolo en una posición dada.

Comentarios no adjuntos

El Docstrings.text tipo representa documentación que no está adjunta a nada.

type text = docstring list

val empty_text : text

val empty_text_lazy : text Lazy.t

val text_attr : docstring -> Parsetree.attribute

val add_text_attrs : text -> Parsetree.attributes -> Parsetree.attributes

Convertir el texto en atributos y añadirlos a una lista de atributos

val symbol_text : unit -> text

Obtener el texto anterior al símbolo actual.

val symbol_text_lazy : unit -> text Lazy.t

val rhs_text : int -> text

Obtener el texto anterior al símbolo en la posición dada.

val rhs_text_lazy : int -> text Lazy.t

Texto adicional

Puede haber texto adicional adjunto a los delimitadores de un bloque (por ejemplo, struct y end ). Esto se obtiene mediante las siguientes funciones, que se aplican al contenido del bloque en lugar de a los delimitadores.

val symbol_pre_extra_text : unit -> text

Obtener texto adicional anterior al símbolo actual

val symbol_post_extra_text : unit -> text

Obtener texto adicional posterior al símbolo actual

val rhs_pre_extra_text : int -> text

Obtener texto adicional anterior al símbolo en la posición dada

val rhs_post_extra_text : int -> text

Obtener texto adicional posterior al símbolo en la posición dada

val rhs_post_text : int -> text

Obtener texto posterior al símbolo en la posición dada
