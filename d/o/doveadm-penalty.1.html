NOMBRE

doveadm-penalty - Mostrar penalizaciones actuales

SINOPSIS

doveadm [OPCIONES GLOBALES] penalty [-a ruta_socket_anvil] [ip [/ máscara]]

DESCRIPCIÓN

El comando doveadm penalty se puede usar para ver las penalizaciones actuales.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, solo usar valores predeterminados. La configuración dovecot_storage_version tiene como valor predeterminado la última versión, pero se puede anular con

-k

Conservar todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre_instancia

Si se usan múltiples instancias de Dovecot, elegir el archivo de configuración según este nombre de instancia.

Ver la configuración instance_name para más información.

-c archivo_config

Leer la configuración del archivo archivo_config proporcionado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuracion=valor

Anula la configuracion del archivo de configuración /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor proporcionado. Para anular múltiples configuraciones, la opción -o se puede especificar varias veces.

OPCIONES

-a ruta_socket_anvil

Esta opción se usa para especificar un socket alternativo. El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre_host:puerto), para conectar un host remoto a través de un socket TCP.

Por defecto, doveadm(1) usará el socket

ARGUMENTOS

ip [/máscara]

Para reducir/filtrar la salida, proporcione una dirección IP o un rango de red en notación CIDR (ip/máscara).

EJEMPLO

doveadm penalty
IP               penalización última_penalización  última_actualización
192.0.2.222            3 2010-06-15 15:19:27 15:19:27
192.0.2.53             3 2010-06-15 15:19:34 15:19:34

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
