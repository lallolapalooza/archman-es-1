NOMBRE

doveadm-log - Localiza, prueba o reabre los archivos de registro de Dovecot

SINOPSIS

doveadm [OPCIONES GLOBALES] log errors [-s timestamp_minimo]

doveadm [OPCIONES GLOBALES] log find [directorio]

doveadm [OPCIONES GLOBALES] log reopen

doveadm [OPCIONES GLOBALES] log test

DESCRIPCIÓN

OPCIONES GLOBALES

Generales de doveadm(1)

-D

Habilita mensajes de verbosidad y depuración.

-O

No lea ningún archivo de configuración, solo use los valores predeterminados. El ajuste dovecot_storage_version se establece en la última versión de forma predeterminada, pero puede ser anulado con

-k

Conserva todo el entorno para doveadm, no solo el ajuste import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-instancia

Si se utilizan varias instancias de Dovecot, elija el archivo de configuración según este nombre de instancia.

Vea el ajuste instance_name para más información.

-c archivo-config

Lea la configuración desde el archivo-config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o ajuste=valor

Anula el ajuste de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular varios ajustes, la opción -o puede especificarse varias veces.

COMANDOS

log errors

doveadm [OPCIONES GLOBALES] log errors [-s timestamp_minimo]

El comando log errors se utiliza para mostrar los últimos - hasta 1.000 - errores y advertencias. Si no se genera ninguna salida, no se han producido errores desde el último inicio.

-s timestamp_minimo

Un valor entero, que representa los segundos desde la época - también conocido como timestamp Unix. Cuando se proporciona un timestamp_minimo, doveadm(1) solo mostrará los errores ocurridos desde ese momento.

log find

doveadm [OPCIONES GLOBALES] log find [directorio]


El comando se utiliza para mostrar la ubicación de los archivos de registro, a los que dovecot(1) registra sus mensajes a través de

log reopen

doveadm [OPCIONES GLOBALES] log reopen

Este comando hace que doveadm envíe una señal SIGUSR1 al proceso maestro, lo que hace que reabra todos los archivos de registro configurados en los ajustes log_path, info_log_path y debug_log_path. Estos ajustes están configurados en /etc/dovecot/conf.d/10-logging.conf.

El proceso maestro también señala al proceso de registro para que haga lo mismo. Esto es principalmente útil después de rotar manualmente los archivos de registro.

log test

doveadm [OPCIONES GLOBALES] log test

Este comando hace que doveadm escriba el mensaje "Este es el registro de prioridad de Dovecot (timestamp)" en los archivos de registro configurados. Las prioridades utilizadas son: debug, info, warning, error y fatal.

EJEMPLO

Este ejemplo muestra cómo localizar los archivos de registro utilizados por dovecot(1):

doveadm log find
Buscando archivos de registro en /var/log
Debug: /var/log/dovecot.debug
Info: /var/log/mail.log
Warning: /var/log/mail.log
Error: /var/log/mail.log
Fatal: /var/log/mail.log

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
