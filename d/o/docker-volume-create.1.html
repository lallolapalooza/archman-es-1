NOMBRE

docker-volume-create - Crea un volumen

SINOPSIS

docker volume create [OPCIONES] [VOLUMEN]

DESCRIPCIÓN

Crea un nuevo volumen que los contenedores pueden consumir y almacenar datos. Si no se especifica un nombre, Docker genera un nombre aleatorio. Crea un volumen y luego configura el contenedor para usarlo, por ejemplo:

$ docker volume create hello
hello
$ docker run -d -v hello:/world busybox ls /world

El montaje se crea dentro del directorio /src del contenedor. Docker no admite rutas relativas para los puntos de montaje dentro del contenedor.

Múltiples contenedores pueden usar el mismo volumen en el mismo período de tiempo. Esto es útil si dos contenedores necesitan acceso a datos compartidos. Por ejemplo, si un contenedor escribe y el otro lee los datos.

Opciones específicas del controlador

Algunos controladores de volumen pueden requerir opciones para personalizar la creación del volumen. Utilice las banderas -o o --opt para pasar las opciones del controlador:

$ docker volume create --driver fake --opt tardis=blue --opt timey=wimey

Estas opciones se pasan directamente al controlador de volumen. Las opciones para diferentes controladores de volumen pueden hacer cosas diferentes (o nada en absoluto).

El controlador local incorporado en Windows no admite ninguna opción.

El controlador local incorporado en Linux acepta opciones similares al comando mount de Linux:

$ docker volume create --driver local --opt type=tmpfs --opt device=tmpfs --opt o=size=100m,uid=1000

Otro ejemplo:

$ docker volume create --driver local --opt type=btrfs --opt device=/dev/sda2

OPCIONES

--availability="active" Disponibilidad del Volumen del Clúster ("active", "pause", "drain")

-d, --driver="local" Especificar el nombre del controlador de volumen

--group="" Grupo de Volumen del Clúster (volúmenes de clúster)

--label= Establecer metadatos para un volumen

--limit-bytes=0 Tamaño mínimo del Volumen del Clúster en bytes

-o, --opt=map[] Establecer opciones específicas del controlador

--required-bytes=0 Tamaño máximo del Volumen del Clúster en bytes

--scope="single" Ámbito de acceso del Volumen del Clúster ("single", "multi")

--secret=map[] Secretos del Volumen del Clúster

--sharing="none" Compartir el acceso al Volumen del Clúster ("none", "readonly", "onewriter", "all")

--topology-preferred= Una topología en la que el Volumen del Clúster sería preferido

--topology-required= Una topología desde la cual el Volumen del Clúster debe ser accesible

--type="block" Tipo de acceso del Volumen del Clúster ("mount", "block")
