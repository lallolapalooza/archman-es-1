subroutine dorm22 (character side, character trans, integer m, integer n, integer n1, integer n2, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work, integer lwork, integer info)

DORM22 multiplica una matriz general por una matriz ortogonal bandada.

Propósito

!>
!>
!>  DORM22 sobrescribe la matriz real general M por N, C, con
!>
!>                  SIDE = 'L'     SIDE = 'R'
!>  TRANS = 'N':      Q * C          C * Q
!>  TRANS = 'T':      Q**T * C       C * Q**T
!>
!>  donde Q es una matriz ortogonal real de orden NQ, con NQ = M si
!>  SIDE = 'L' y NQ = N si SIDE = 'R'.
!>  La matriz ortogonal Q procesa una estructura de bloques de 2x2
!>
!>         [  Q11  Q12  ]
!>     Q = [            ]
!>         [  Q21  Q22  ],
!>
!>  donde Q12 es una matriz triangular inferior de N1xN1 y Q21 es una
!>  matriz triangular superior de N2xN2.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda;
!>          = 'R': aplicar Q o Q**T desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  aplicar Q (Sin transpuesta);
!>          = 'C':  aplicar Q**T (Transpuesta conjugada).
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

N1
N2

!>          N1 es INTEGER
!>          N2 es INTEGER
!>          La dimensión de Q12 y Q21, respectivamente. N1, N2 >= 0.
!>          Se debe cumplir el siguiente requisito:
!>          N1 + N2 = M si SIDE = 'L' y N1 + N2 = N si SIDE = 'R'.
!>

Q

!>          Q es array DOUBLE PRECISION, dimensión
!>                                       (LDQ,M) si SIDE = 'L'
!>                                       (LDQ,N) si SIDE = 'R'
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= max(1,M) si SIDE = 'L'; LDQ >= max(1,N) si SIDE = 'R'.
!>

C

!>          C es array DOUBLE PRECISION, dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con Q*C o Q**T*C o C*Q**T o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= M*N.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor en la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
