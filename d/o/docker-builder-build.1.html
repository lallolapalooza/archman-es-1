NOMBRE

docker-builder-build - Construir una imagen desde un Dockerfile

SINOPSIS

docker builder build [OPCIONES] RUTA | URL | -

DESCRIPCIÓN

Construye una imagen desde un Dockerfile

OPCIONES

--add-host= Añade un mapeo personalizado host-a-IP ("host:ip")

--build-arg= Establece variables en tiempo de construcción

--cache-from=[] Imágenes a considerar como fuentes de caché

--cgroup-parent="" Establece el cgroup padre para las instrucciones "RUN" durante la construcción

--compress[=false] Comprime el contexto de construcción usando gzip

--cpu-period=0 Limita el período del CFS (Completely Fair Scheduler) de la CPU

--cpu-quota=0 Limita la cuota del CFS (Completely Fair Scheduler) de la CPU

-c, --cpu-shares=0 Cuotas de CPU (peso relativo)

--cpuset-cpus="" CPUs en las que permitir la ejecución (0-3, 0,1)

--cpuset-mems="" MEMs en las que permitir la ejecución (0-3, 0,1)

-f, --file="" Nombre del Dockerfile (Por defecto es "RUTA/Dockerfile")

--force-rm[=false] Elimina siempre los contenedores intermedios

--iidfile="" Escribe el ID de la imagen en el archivo

--isolation="" Tecnología de aislamiento del contenedor

--label= Establece metadatos para una imagen

-m, --memory=0 Límite de memoria

--memory-swap=0 Límite de swap igual a la memoria más swap: -1 para habilitar swap ilimitado

--network="default" Establece el modo de red para las instrucciones RUN durante la construcción

--no-cache[=false] No usar caché al construir la imagen

--platform="" Establece la plataforma si el servidor es capaz de manejar múltiples plataformas

--pull[=false] Siempre intenta descargar una versión más reciente de la imagen

-q, --quiet[=false] Suprime la salida de la construcción e imprime el ID de la imagen en caso de éxito

--rm[=true] Elimina los contenedores intermedios después de una construcción exitosa

--security-opt=[] Opciones de seguridad

--shm-size=0 Tamaño de "/dev/shm"

--squash[=false] Comprime las capas recién construidas en una única capa nueva

-t, --tag= Nombre y opcionalmente una etiqueta en el formato "nombre:etiqueta"

--target="" Establece la etapa de construcción objetivo a construir.

--ulimit=[] Opciones de ulimit
