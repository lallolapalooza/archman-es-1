NOMBRE

docker-volume-ls - Listar volúmenes

SINOPSIS

docker volume ls [OPCIONES]

DESCRIPCIÓN

Lista todos los volúmenes que Docker gestiona. Puede filtrar usando la opción -f o --filter. El formato de filtrado es un par clave=valor. Para especificar más de un filtro, pase múltiples opciones (por ejemplo, --filter "foo=bar" --filter "bif=baz")

Los filtros actualmente soportados son:

  • dangling (booleano - true o false, 1 o 0)
  • driver (nombre de un controlador de volumen)
  • label (label=<clave> o label=<clave>=<valor>)
  • name (nombre de un volumen)

OPCIONES

--cluster[=false] Mostrar solo volúmenes de clúster y usar formato de lista de volúmenes de clúster

-f, --filter= Proporcionar valores de filtro (por ejemplo, "dangling=true")

--format="" Dar formato a la salida utilizando una plantilla personalizada: 'table': Imprimir la salida en formato de tabla con encabezados de columna (predeterminado) 'table TEMPLATE': Imprimir la salida en formato de tabla usando la plantilla Go dada 'json': Imprimir en formato JSON 'TEMPLATE': Imprimir la salida usando la plantilla Go dada. Consulte https://docs.docker.com/go/formatting/ para más información sobre el formato de salida con plantillas

-q, --quiet[=false] Mostrar solo los nombres de los volúmenes

VER TAMBIÉN
