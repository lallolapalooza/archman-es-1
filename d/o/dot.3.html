función de doble precisión dsdot (entero n, real, dimensión(*) sx, entero incx, real, dimensión(*) sy, entero incy)

DSDOT

Propósito:

!>
!> Calcula el producto interior de dos vectores con acumulación y resultado
!> de precisión extendida.
!>
!> Devuelve el producto punto D.P. acumulado en D.P., para SX y SY de S.P.
!> DSDOT = suma para I = 0 a N-1 de  SX(LX+I*INCX) * SY(LY+I*INCY),
!> donde LX = 1 si INCX .GE. 0, de lo contrario LX = 1+(1-N)*INCX, y LY se
!> define de manera similar usando INCY.
!>

Parámetros

N 
!>          N es ENTERO
!>         número de elementos en el/los vector(es) de entrada
!>

SX

!>          SX es un array REAL, dimensión(N)
!>         vector de precisión simple con N elementos
!>

INCX

!>          INCX es ENTERO
!>          espaciado de almacenamiento entre elementos de SX
!>

SY

!>          SY es un array REAL, dimensión(N)
!>         vector de precisión simple con N elementos
!>

INCY

!>          INCY es ENTERO
!>         espaciado de almacenamiento entre elementos de SY
!>

Retorna

DSDOT 
!>          DSDOT es DOBLE PRECISIÓN
!>         DSDOT  producto punto de doble precisión (cero si N.LE.0)
!>

!> y resultado de doble precisión.

!> where LX = 1 if INCX .GE. 0, else LX = 1+(1-N)*INCX, and LY is
!> defined in a similar way using INCY.
!>

Parámetros

N 
!>          N es ENTERO

!>

!>          SB es REAL

!>

!>          SX es un array REAL, dimensión(N)

!>

INCX

!>          INCX es ENTERO
!>          espaciado de almacenamiento entre elementos de SX

SY

Definición en la línea 81 del archivo sdot.f.

real function sdsdot (integer n, real sb, real, dimension(*) sx, integer incx, real, dimension(*) sy, integer incy)

SDSDOT

Propósito:

!>
!>   Calcula el producto interno de dos vectores con acumulación en
!>   precisión extendida.
!>
!>   Devuelve un resultado en precisión simple con el producto punto
!>   acumulado en doble precisión.
!>   SDSDOT = SB + suma para I = 0 a N-1 de SX(LX+I*INCX)*SY(LY+I*INCY),
!>   donde LX = 1 si INCX .GE. 0, de lo contrario LX = 1+(1-N)*INCX, y LY
!>   se define de manera similar usando INCY.
!>

Parámetros

N 
!>          N es INTEGER
!>          número de elementos en el/los vector(es) de entrada
!>

SB

!>          SB es REAL
!>          escalar de precisión simple que se añade al producto interno
!>

SX

!>          SX es un array REAL, dimensión ( 1 + ( N - 1 )*abs( INCX ) )
!>          vector de precisión simple con N elementos
!>

INCX

!>          INCX es INTEGER
!>          espaciado de almacenamiento entre elementos de SX
!>

SY

!>          SY es un array REAL, dimensión ( 1 + ( N - 1 )*abs( INCX ) )
!>          vector de precisión simple con N elementos
!>

INCY

!>          INCY es INTEGER
!>          espaciado de almacenamiento entre elementos de SY
!>
