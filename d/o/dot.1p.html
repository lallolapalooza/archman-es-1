DESCRIPCIÓ

N

El shell ejecutará comandos desde el archivo en el entorno

actual.

Si archivo no contiene una <barra invertida>, el shell usará la ruta de búsqueda especificada por PATH para encontrar el directorio que contiene archivo. A diferencia de la búsqueda normal de comandos, sin embargo, el archivo buscado por la utilidad dot no necesita ser ejecutable. Si no se encuentra ningún archivo legible, un shell no interactivo se abortará; un shell interactivo

escribirá un mensaje de diagnóstico en la salida de error están
dar, pero esta condición no se considerará un error de sintaxis.

JUSTIFICACIÓ

N

Algunas implementaciones antiguas buscaban en el directorio actual el archivo, incluso si el valor de PATH lo deshabilitaba. Este comportamiento fue omitido de este volumen de POSIX.1‐2017 debido a preocupaciones sobre introducir la susceptibilidad a caballos de Troya que el usuario podría estar tratando de evitar al dejar dot fuera de PATH

.

La versión de KornShell de dot toma argumentos opcionales que se establecen en los parámetros posicionales. Esta es una extensión válida que permite que un script dot se comporte de ma

nera idéntica
a una función.
