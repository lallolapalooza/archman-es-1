DOVEADM-DEDUPLICATE(1) Dovecot DOVEADM-DEDUPLICATE(1)

NOMBRE

doveadm-deduplicate - Eliminar mensajes duplicados

SINOPSIS

doveadm [OPCIONES GLOBALES] deduplicate [-u usuario | -A | -F archivo | --no-userdb-lookup] [-S ruta_socket] [-m] consulta_busqueda

DESCRIPCIÓN

La deduplicación entre múltiples buzones no es compatible.

OPCIONES GLOBALES

doveadm(1) global

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, solo usar los predeterminados. El ajuste dovecot_storage_version toma el valor predeterminado de la última versión, pero puede ser anulado con

-k

Preserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre-instancia

Si se utilizan múltiples instancias de Dovecot, elija el archivo de configuración según este nombre de instancia.

Consulte la configuración instance_name para más información.

-c archivo-config

Lea la configuración desde el archivo-config proporcionado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia en ejecución con una versión compatible.

-o ajuste=valor

Anula el ajuste de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor proporcionado. Para anular múltiples ajustes, la opción -o puede especificarse varias veces.

OPCIONES

-A

Si está presente la opción -A, el comando se realizará para todos los usuarios. No se recomienda el uso de esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, ya que también incluye usuarios con un UID inferior al configurado con la configuración first_valid_uid.

Cuando se utiliza el módulo de base de datos de usuarios SQL, asegúrese de que la configuración userdb_sql_iterate_query coincida con su diseño de base de datos.

Al utilizar el módulo de base de datos de usuarios LDAP, asegúrese de que la configuración userdb_fields y userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecuta el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo proporcionado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realiza la búsqueda en la base de datos de usuarios. Utilice la variable de entorno USER para especificar el nombre de usuario.

-m


si se da la opción, doveadm(1) deducirá por la cabecera Message-Id. Por defecto la deduplicación se hará por GUIDs de mensajes.

-S ruta_socket

El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombrehost:puerto), para conectar a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecuta el comando solo para el usuario dado. También es posible usar comodines '*' y '?' (por ejemplo, -u *@example.org).

ARGUMENTOS

consulta_busqueda

EJEMPLO

Este ejemplo muestra cómo listar y eliminar mensajes duplicados de un buzón.

doveadm -f table fetch -u jane 'guid uid' mailbox a_Box | sort
guid                             uid
8aad0f0a30169f4bea620000ca356bad 18751
8aad0f0a30169f4bea620000ca356bad 18756
923e301ab9219b4b4f440000ca356bad 18748
923e301ab9219b4b4f440000ca356bad 18753
doveadm deduplicate -u jane mailbox a_Box
doveadm -f table fetch -u jane 'guid uid' mailbox a_Box | sort
guid                             uid
8aad0f0a30169f4bea620000ca356bad 18751
923e301ab9219b4b4f440000ca356bad 18748
a7999e1530739c4bd26d0000ca356bad 18749

INFORME DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
