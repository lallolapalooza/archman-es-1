NOMBRE

doveadm-purge - Elimina mensajes con refcount=0 de archivos mdbox

SINOPSIS

doveadm [OPCIONES GLOBALES] purge [-S ruta_socket] -A

doveadm [OPCIONES GLOBALES] purge [-S ruta_socket] -F archivo

doveadm [OPCIONES GLOBALES] purge [-S ruta_socket] --no-userdb-lookup

doveadm [OPCIONES GLOBALES] purge [-S ruta_socket] -u usuario

DESCRIPCIÓN

El comando doveadm purge se utiliza para eliminar todos los mensajes con refcount=0 del almacenamiento de correo de un usuario. El refcount de un mensaje se reduce a 0 cuando el usuario (o alguna utilidad de administración) ha eliminado todas las instancias de un mensaje de todos los buzones.

En la primera forma, el comando se ejecutará para todos los usuarios.

En la segunda forma, el comando se ejecutará para todos los usuarios listados en el archivo dado.

En la tercera forma, el comando se realizará para el usuario contenido en la variable de entorno USER.

En la última forma, solo se purgarán los mensajes del (de los) usuario(s) dado(s).

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lea ningún archivo de configuración, solo use los valores predeterminados. La configuración dovecot_storage_version se establece en la última versión, pero puede sobrescribirse con

-k

Conserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre-instancia

Si se utilizan varias instancias de Dovecot, elija el archivo de configuración según este nombre de instancia.

Consulte la configuración instance_name para obtener más información.

-c archivo-config

Lea la configuración del archivo-config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular varias configuraciones, la opción -o puede especificarse varias veces.

OPCIONES

-A

Si está presente la opción -A, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, porque también contiene usuarios con un UID inferior al configurado con la configuración first_valid_uid.

Cuando se utiliza el módulo userdb SQL, asegúrese de que la configuración userdb_sql_iterate_query coincida con su diseño de base de datos.

Cuando se utiliza el módulo userdb LDAP, asegúrese de que las configuraciones userdb_fields y userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecuta el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo dado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realice la búsqueda en la base de datos de usuarios. Utilice la variable de entorno USER para especificar el nombre de usuario.

-S ruta_socket

El argumento de la opción es una ruta absoluta a un socket UNIX local o un nombre de host y puerto (nombre-host:puerto), para conectarse a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecuta el comando solo para el usuario dado. También es posible usar comodines '*' y '?' (por ejemplo, -u *@example.org).

INFORMAR ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
