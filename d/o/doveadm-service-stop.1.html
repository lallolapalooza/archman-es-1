NOMBRE

doveadm-service-stop - Detener servicios de Dovecot

SINOPSIS

doveadm [OPCIONES GLOBALES] service stop servicio [servicio [...]]

DESCRIPCIÓN

doveadm service stop detiene los procesos del servicio Dovecot listados.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, solo usar los predeterminados. La configuración dovecot_storage_version usa por defecto la última versión, pero puede ser anulada con

-k

Preserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-instancia

Si se usan múltiples instancias de Dovecot, elige el archivo de configuración basado en este nombre de instancia.

Ver la configuración instance_name para más información.

-c archivo-config

Lee la configuración del archivo-config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración del archivo de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.

-f formato

Especifica el formato para dar formato a la salida. Los formatos soportados son:

flow

imprime cada línea con pares clave=valor.

json

imprime un array JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con un salto de página (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separadas por tabuladores.

table

imprime una cabecera de tabla seguida de líneas de valores ajustados.

ARGUMENTOS

servicio

La lista de servicios a detener.

EJEMPLOS

$ doveadm service stop stats

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
