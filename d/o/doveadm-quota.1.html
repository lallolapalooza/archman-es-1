NOMBRE

doveadm-quota - Inicializar/recalcular o mostrar el uso actual de cuota

SINOPSIS

doveadm [OPCIONES GLOBALES] [-f formateador] quota [-S ruta_del_socket] comando -A

doveadm [OPCIONES GLOBALES] [-f formateador] quota [-S ruta_del_socket] comando -F archivo

doveadm [OPCIONES GLOBALES] [-f formateador] quota [-S ruta_del_socket] comando --no-userdb-lookup

doveadm [OPCIONES GLOBALES] [-f formateador] quota [-S ruta_del_socket] comando -u usuario

DESCRIPCIÓN

En la primera forma, el comando se realizará para todos los usuarios.

En la segunda forma, el comando se realizará para todos los usuarios listados en el archivodado.

En la tercera forma, el comando se realizará para el usuario contenido en la variable de entorno USER .

En la última forma, el comando afectará solo al usuario(usuarios) coincidente(s).

•
Los comandos quota get y quota recalc solo están disponibles cuando la configuración global mail_plugins contiene el plugin quota .

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, usar solo los valores predeterminados. La configuración dovecot_storage_version tiene como valor predeterminado la última versión, pero se puede sobreescribir con

-k

Conservar todo el entorno para doveadm, no solo la configuración import_environment .

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-de-instancia

Si se usan múltiples instancias de Dovecot, elegir el archivo de configuración basado en este nombre de instancia.

Ver la configuración instance_name para más información.

-c archivo-de-configuración

Leer la configuración del archivo-de-configuracióndado. Por defecto primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También se puede apuntar al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Sobreescribe la configuración de /etc/dovecot/dovecot.conf y de la userdb con el valordado. Para sobreescribir múltiples configuraciones, la opción -o puede especificarse varias veces.

-f formateador

Especifica el formateador para formatear la salida. Los formateadores soportados son:

flow

imprime cada línea con pares clave=valor .

json

imprime un array JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con el carácter de avance de formulario (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separadas por tabuladores.

table

imprime una cabecera de tabla seguida de líneas de valores ajustadas.

OPCIONES

-A

Si la opción -A está presente, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd } , porque también contiene usuarios con un UID menor que el configurado con la configuración first_valid_uid .

Cuando se usa el módulo userdb SQL, asegúrese de que la configuración userdb_sql_iterate_query coincida con la estructura de su base de datos.

Cuando se usa el módulo userdb LDAP, asegúrese de que la configuración userdb_fields y la configuración userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecutar el comando para todos los usuarios en el archivo. Esto es similar a la opción -A , pero en lugar de obtener la lista de usuarios de la userdb, se leen del archivodado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realizar la búsqueda en la userdb. Usar la variable de entorno USER para especificar el nombre de usuario.

-S ruta_del_socket

El argumento de la opción es o bien una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre_de_host:puerto), para conectarse a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecutar el comando solo para el usuariodado. También es posible usar los comodines '*' y '?' (p. ej. -u *@example.org).

COMANDOS

quota get

doveadm [OPCIONES GLOBALES] quota get [-A | -u usuario | -F archivo]

El comando quota get se usa para mostrar el uso actual de la cuota. Los valores de almacenamiento se reportan en kilobytes.

Este comando usa por defecto el formateador de salida table.

quota recalc

doveadm [OPCIONES GLOBALES] quota recalc [-A | -u usuario | -F archivo]

El comando quota recalc se usa para recalcular el uso actual de la cuota.

ARCHIVOS

/etc/dovecot/dovecot.conf

El archivo de configuración principal de Dovecot, incluyendo la sección dict .

/etc/dovecot/conf.d/10-mail.conf

Ubicaciones de buzones y espacios de nombres.

/etc/dovecot/conf.d/90-quota.conf

Configuración de la cuota.

EJEMPLO

Obtener el uso actual de la cuota del usuario jane:

doveadm quota get -u jane
Quota name                        Type    Value  Limit  %
user                              STORAGE 90099 102400 87
user                              MESSAGE 20548  30000 68

INFORME DE ERRORES

Informe de errores, incluyendo la salida de doveconf -n , a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo informar de errores está disponible en: https://dovecot.org/bugreport.html
