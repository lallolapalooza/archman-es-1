NOMBRE

doveadm-pw - Generador y validador de hashes de contraseña de Dovecot

SINOPSIS

doveadm [OPCIONES GLOBALES] pw -l

doveadm [OPCIONES GLOBALES] pw [-p contraseña] [-r rondas] [-s esquema] [-u usuario] [-V]

doveadm [OPCIONES GLOBALES] pw -t hash [-p contraseña] [-u usuario]

DESCRIPCIÓN

doveadm pw se utiliza para generar hashes de contraseña para diferentes esquemas de contraseña y opcionalmente verificar el hash generado.

Todos los hashes de contraseña generados tienen un prefijo {esquema}, por ejemplo {SHA512-CRYPT.HEX}. Todos los passdb tienen un esquema predeterminado para las contraseñas almacenadas sin el prefijo {esquema}. El esquema predeterminado se puede anular almacenando la contraseña con el prefijo del esquema.

Si desea utilizar esta función para verificar o generar contraseñas sin configurar Dovecot primero, puede usar doveadm -O pw para hacerlo.

OPCIONES GLOBALES

doveadm(1) global

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lea ningún archivo de configuración, solo use los valores predeterminados. La configuración dovecot_storage_version se establece en la última versión por defecto, pero se puede anular con

-k

Conserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre-instancia

Si utiliza varias instancias de Dovecot, elija el archivo de configuración según este nombre de instancia.

Consulte la configuración instance_name para obtener más información.

-c archivo-configuración

Lea la configuración del archivo-configuración dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración del archivo de configuración /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular varias configuraciones, la opción -o puede especificarse varias veces.

OPCIONES

-l

Lista todos los esquemas de contraseña compatibles y sale con éxito.

Hay hasta tres esquemas de contraseña opcionales: BLF-CRYPT (Blowfish crypt), SHA256-CRYPT y SHA512-CRYPT. Su disponibilidad depende de la libc que esté utilizando actualmente el sistema.

-p contraseña


Se le proporcionó a doveadm(1), se le pedirá interactivamente una. (¡Tenga cuidado, ya que usar esta opción significa que la contraseña en texto plano estará en el historial de su shell!)

-r rondas

Los esquemas de contraseña BLF-CRYPT, SHA256-CRYPT y SHA512-CRYPT admiten un número variable de rondas de cifrado. La siguiente tabla muestra el número mínimo/máximo de rondas de cifrado por esquema. Cuando se omitió la opción -r, se aplicará el número predeterminado de rondas de cifrado.

| Esquema | Mínimo | Máximo | Predeterminado | | ------- | ------- | ------- | ------- | | BLF-CRYPT | 4 | 31 | 5 | | SHA256-CRYPT | 1000 | 999999999 | 5000 | | SHA512-CRYPT | 1000 | 999999999 | 5000 |

-s esquema

El esquema de contraseña que se utilizará para generar la contraseña cifrada. Por defecto, se utilizará el esquema CRYPT (con el formato bcrypt $2y$). También es posible añadir un sufijo de codificación al esquema. Los sufijos de codificación soportados son: .b64, .base64 y .hex.

Consulte también password_schemes para obtener más detalles sobre los esquemas de contraseñas.

-t hash


opción. Cuando no se especificó ninguna contraseña, doveadm(1) pedirá interactivamente una.

-u usuario


El nombre de usuario también debe proporcionarse, ya que el nombre de usuario es parte del hash generado. Para obtener más información sobre Digest-MD5, lea también auth_digest_md5. Para otros esquemas, esto no es necesario.

-V

Cuando se proporciona esta opción, la contraseña cifrada se verificará internamente. El resultado de la verificación se mostrará después de la contraseña cifrada, entre paréntesis.
