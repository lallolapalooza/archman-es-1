NOMBRE

doveadm-dump - Volcar el contenido del índice/registro binario del buzón de Dovecot

SINOPSIS

doveadm [OPCIONES GLOBALES] dump [-t tipo] ruta [args-específicos-del-tipo]

DESCRIPCIÓN

Dovecot utiliza varios archivos de índice y registro binarios para mejorar el rendimiento al acceder a los correos. Para algunos formatos de buzón, como sdbox y mdbox, los archivos de índice forman parte del formato en sí. Para más detalles sobre los archivos de índice, consulte [[link,design_index_format_main].

doveadm dump se utiliza para mostrar el contenido de esos archivos de índice/registro del buzón, en formato legible por humanos. Esto es principalmente útil para los desarrolladores de Dovecot al depurar algún problema.

OPCIONES GLOBALES

doveadm(1) global

-D

Habilita los mensajes de depuración y verbosidad.

-O

No leer ningún archivo de configuración, solo usar los valores predeterminados. La configuración dovecot_storage_version tiene como valor predeterminado la última versión, pero puede ser anulada con

-k

Preserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre-instancia

Si se usan múltiples instancias de Dovecot, elige el archivo de configuración basándose en este nombre de instancia.

Consulte la configuración instance_name para obtener más información.

-c archivo-config

Lee la configuración del archivo-config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración de configuración de /etc/dovecot/dovecot.conf y del userdb con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse múltiples veces.

OPCIONES

-t tipo


fue omitido, doveadm(1) intenta detectar el tipo de

tipo puede ser:

dbox : => m.n (archivo de buzón sdbox o mdbox)

fts-expunge-log : Volcar la lista de correos eliminados en dovecot-expunges.log.

fts-flatcurve : Volcar las palabras clave indexadas en los directorios de índices fts-flatcurve y sus frecuencias.

imap-compress : Descomprimir un registro de tráfico IMAP, que contiene datos comprimidos usando la extensión IMAP COMPRESSION.

dcrypt-file : Volcar metadatos de un archivo cifrado dcrypt.

args-específicos-del-tipo

private_key=/ruta : para descifrar el contenido del archivo.

password=secreto : para descifrar la clave privada.

dcrypt-key : Volcar metadatos de una clave dcrypt.

args-específicos-del-tipo

private_key=/ruta

para descifrar el contenido del archivo.

password=secreto

para descifrar la clave privada.

dump=pem|dovecot|jwk

para especificar el formato en el que volcar.

index : => dovecot.index, dovecot.map.index

args-específicos-del-tipo

uid=número : Volcar solo el mensaje con UID

log : => dovecot.index.log, dovecot.map.index.log

mailboxlog : => dovecot.mailbox.log

thread : => dovecot.index.thread

ARGUMENTOS

ruta

La ruta al almacenamiento dbox, índice o archivo de registro correspondiente. Si solo se especifica un directorio, doveadm intenta detectar el tipo de archivos que contiene y los vuelca.

EJEMPLO

Observar el contenido del índice de un buzón:

doveadm dump ~/Maildir/.work/

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
