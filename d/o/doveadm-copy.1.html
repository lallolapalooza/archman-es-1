NOMBRE

doveadm-copy - Copia mensajes que coinciden con la consulta de búsqueda dada a otro buzón

SINOPSIS

doveadm [OPCIONES GLOBALES] move [-S ruta_socket] -A destino [user usuario_origen] consulta_busqueda

doveadm [OPCIONES GLOBALES] move [-S ruta_socket] -F archivo destino [user usuario_origen] consulta_busqueda

doveadm [OPCIONES GLOBALES] move [-S ruta_socket] --no-userdb-lookup destino [user usuario_origen] consulta_busqueda

doveadm [OPCIONES GLOBALES] move [-S ruta_socket] -u usuario destino [user usuario_origen] consulta_busqueda

doveadm [OPCIONES GLOBALES] copy [-S ruta_socket] -A destino [user usuario_origen] consulta_busqueda

doveadm [OPCIONES GLOBALES] copy [-S ruta_socket] -F archivo destino [user usuario_origen] consulta_busqueda

doveadm [OPCIONES GLOBALES] copy [-S ruta_socket] --no-userdb-lookup destino [user usuario_origen] consulta_busqueda

doveadm [OPCIONES GLOBALES] copy [-S ruta_socket] -u usuario destino [user usuario_origen] consulta_busqueda

DESCRIPCIÓN

doveadm move se puede utilizar para mover correos entre buzones para uno o varios usuarios. La consulta_busqueda se usa para restringir qué mensajes se mueven al buzón de destino.

doveadm copy se comporta igual que doveadm move, excepto que los mensajes copiados no se eliminarán después de copiarlos.

En la primera forma, doveadm(1) iterará sobre todos los usuarios, encontrados en el configurado

En la segunda forma, doveadm(1) iterará sobre todos los usuarios, encontrados en el dado

En la tercera forma, los correos coincidentes solo se moverán o copiarán para los usuario(s) dados.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, solo usar los valores predeterminados. La configuración dovecot_storage_version tiene como valor predeterminado la última versión, pero se puede anular con

-k

Preserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre_instancia

Si se utilizan múltiples instancias de Dovecot, elija el archivo de configuración según este nombre de instancia.

Consulte la configuración instance_name para más información.

-c archivo_config

Lea la configuración del archivo_config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuracion=valor

Anula la configuracion del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.

OPCIONES

-A

Si la opción -A está presente, el comando se realizará para todos los usuarios. No se recomienda el uso de esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, porque también incluye usuarios con un UID inferior al configurado con la configuración first_valid_uid.

Cuando se utiliza el módulo userdb SQL, asegúrese de que la configuración userdb_sql_iterate_query coincida con el diseño de su base de datos.

Cuando se utiliza el módulo userdb LDAP, asegúrese de que las configuraciones userdb_fields y userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecuta el comando para todos los usuarios en el archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo dado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realizar la búsqueda en la base de datos de usuarios. Utilice la variable de entorno USER para especificar el nombre de usuario.

-S ruta_socket

El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre_host:puerto), para conectar a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/mascara

Ejecuta el comando solo para el usuario dado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).

ARGUMENTOS

destino

El nombre del buzón de destino, al cual se deben mover o copiar los correos. El buzón de destino debe existir, de lo contrario este comando fallará.

consulta_busqueda

Mueve/copia mensajes que coincidan con la consulta de búsqueda dada. Consulte doveadm-search-query(7) para más detalles.

user usuario_origen


seguido de un nombre de usuario válido. Cuando este argumento está presente, doveadm(1) aplicará el

Limitación: Actualmente los usuarios, especificados por -u usuario y user usuario_origen, deben compartir el mismo UID y GID del sistema.

EJEMPLO

Mover los mensajes de Jane - recibidos en septiembre de 2011 - de su Bandeja de entrada a su archivo:

doveadm move -u jane Archive/2011/09 mailbox INBOX BEFORE \
  2011-10-01 SINCE 01-Sep-2011

REPORTE DE ERRORES

Informe de errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo informar errores está disponible en: https://dovecot.org/bugreport.html
