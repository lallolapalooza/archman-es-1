NOMBRE

docker-manifest-push - Empujar una lista de manifiestos a un repositorio

SINOPSIS

docker manifest push [OPCIONES] MANIFEST_LIST

DESCRIPCIÓN

Empuja una lista de manifiestos a un repositorio

OPCIONES

--insecure[=false] Permitir el empuje a un registro inseguro

-p, --purge[=false] Eliminar la lista de manifiestos local después de empujar
