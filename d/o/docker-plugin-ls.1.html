NOMBRE

docker-plugin-ls - Listar plugins

SINOPSIS

docker plugin ls [OPCIONES]

DESCRIPCIÓN

Lista todos los plugins que están actualmente instalados. Puede instalar plugins usando el comando docker plugin install. También puede filtrar usando la bandera -f o --filter.

Filtros

Filtre la salida basándose en estas condiciones:
- enabled=(true|false) - plugins que están habilitados o no
- capability= - filtra plugins basándose en capacidades (actualmente volumedriver, networkdriver, ipamdriver, o authz)

Formato

Formatee la salida usando la plantilla Go dada.
Marcadores válidos:
.ID - ID del Plugin.
.Name - Nombre del Plugin.
.Description - Descripción del Plugin.
.Enabled - Si el plugin está habilitado o no.

EJEMPLOS

Mostrar todos los plugins

$ docker plugin ls
ID                  NOMBRE                                    DESCRIPCIÓN                         HABILITADO
869080b57404        tiborvass/sample-volume-plugin:latest   Un plugin de volumen de ejemplo para Docker   true
141bf6c02ddd        vieux/sshfs:latest                      Plugin sshFS para Docker             false

Mostrar plugins con sus IDs y nombres

$ docker plugin ls --format "{{.ID}}: {{.Name}}"
869080b57404: tiborvass/sample-volume-plugin:latest

Mostrar plugins en formato JSON

$ docker plugin ls --format json
{"Description":"Un plugin de volumen de ejemplo para Docker","Enabled":true,"ID":"2788a2da7e12","Name":"tiborvass/sample-volume-plugin:latest","PluginReference":"docker.io/tiborvass/sample-volume-plugin:latest"}

Mostrar plugins habilitados

$ docker plugin ls --filter enabled=true
ID                  NOMBRE                                    DESCRIPCIÓN                         HABILITADO
869080b57404        tiborvass/sample-volume-plugin:latest   Un plugin de volumen de ejemplo para Docker   true

Mostrar plugins con capacidad volumedriver

$ docker plugin ls --filter capability=volumedriver --format "tabla {{.ID}}\t{{.Name}}"
ID                  Nombre
869080b57404        tiborvass/sample-volume-plugin:latest

OPCIONES

-f, --filter= Proporcionar valores de filtro (por ejemplo, "enabled=true")

--format="" Formatear la salida usando una plantilla personalizada: 'table': Imprimir la salida en formato de tabla con encabezados de columna (predeterminado) 'table PLANTILLA': Imprimir la salida en formato de tabla usando la plantilla Go dada 'json': Imprimir en formato JSON 'PLANTILLA': Imprimir la salida usando la plantilla Go dada. Consulte https://docs.docker.com/go/formatting/ para obtener más información sobre cómo formatear la salida con plantillas

--no-trunc[=false] No truncar la salida

-q, --quiet[=false] Mostrar solo los IDs de los plugins
