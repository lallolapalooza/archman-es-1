NOMBRE

docker-image-tag - Crea una etiqueta TARGET_IMAGE que se refiere a SOURCE_IMAGE

SINOPSIS

docker image tag SOURCE_IMAGE[:TAG] TARGET_IMAGE[:TAG]

DESCRIPCIÓN

Asigna un nuevo alias a una imagen en un registro. Un alias se refiere a todo el nombre de la imagen, incluyendo la etiqueta opcional TAG después de los ':'.

OPCIONES

NOMBRE
El nombre de la imagen, que está compuesto por componentes de nombre separados por barras,
opcionalmente precedido por el nombre de host del registro. El nombre de host debe cumplir con
las reglas estándar de DNS, pero no puede contener guiones bajos. Si está presente un nombre de host,
puede ir opcionalmente seguido de un número de puerto en el formato
:8080. Si no está presente, el comando usa el registro público de Docker ubicado en
registry-1.docker.io por defecto. Los componentes del nombre pueden contener letras minúsculas,
dígitos y separadores. Un separador se define como un punto, uno o
dos guiones bajos, o uno o más guiones. Un componente de nombre no puede comenzar o terminar
con un separador.

TAG
La etiqueta asignada a la imagen para versionar y distinguir imágenes con el mismo
nombre. El nombre de la etiqueta debe ser ASCII válido y puede contener letras minúsculas y
mayúsculas, dígitos, guiones bajos, puntos y guiones. El nombre de una etiqueta no puede comenzar
con un punto o un guion y puede contener un máximo de 128 caracteres.

EJEMPLOS

Etiquetado de una imagen referenciada por ID

Para etiquetar una imagen local con ID "0e5574283393" en el repositorio "fedora" con "version1.0":

docker image tag 0e5574283393 fedora/httpd:version1.0

Etiquetado de una imagen referenciada por Nombre

Para etiquetar una imagen local con el nombre "httpd" en el repositorio "fedora" con "version1.0":

docker image tag httpd fedora/httpd:version1.0

Tenga en cuenta que dado que no se especifica el nombre de la etiqueta, el alias se crea para una versión local existente httpd:latest.

Etiquetado de una imagen referenciada por Nombre y Etiqueta

Para etiquetar una imagen local con el nombre "httpd" y la etiqueta "test" en el repositorio "fedora" con "version1.0.test":

docker image tag httpd:test fedora/httpd:version1.0.test

Etiquetado de una imagen para un repositorio privado

Antes de enviar una imagen a un registro privado y no al registro central de Docker, debe etiquetarla con el nombre de host y el puerto del registro (si es necesario).

docker image tag 0e5574283393 myregistryhost:5000/fedora/httpd:version1.0
