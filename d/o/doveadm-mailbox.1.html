NOMBRE

doveadm-mailbox - Comandos relacionados con el manejo de buzones

SINOPSIS

doveadm [OPCIONES GLOBALES] [-f formateador] comando_buzón [OPCIONES] [ARGUMENTOS]

DESCRIPCIÓN

doveadm mailbox puede usarse para consultar y modificar buzones.

OPCIONES GLOBALES

Global doveadm(1)

-D

Habilita verbosidad y mensajes de depuración.

-O

No leer ningún archivo de configuración, usar solo los valores predeterminados. La dovecot_storage_version configuración tiene como valor predeterminado la última versión, pero puede ser sobrescrita con

-k

Conservar todo el entorno para doveadm, no solo la import_environment configuración.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-de-instancia

Si se usan múltiples instancias de Dovecot, elegir el archivo de configuración basado en este nombre de instancia.

Ver instance_name configuración para más información.

-c archivo-de-configuración

Leer la configuración del archivo-de-configuracióndado. Por defecto primero lee el socket de configuración, y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Sobrescribe la configuración configuración de /etc/dovecot/dovecot.conf y de la userdb con el valordado. Para sobrescribir múltiples configuraciones, la -o opción puede especificarse varias veces.

-f formateador

Especifica el formateador para formatear la salida. Los formateadores soportados son:

flow

imprime cada línea con pares clave=valor .

json

imprime un array JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con el carácter de avance de formulario (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separadas por tabuladores.

table

imprime una cabecera de tabla seguida de líneas de valores ajustadas.

OPCIONES

-A

Si la -A opción está presente, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd } , porque contiene también usuarios con un UID menor que el configurado con la first_valid_uid configuración.

Cuando se usa el módulo userdb SQL, asegúrese de que la userdb_sql_iterate_query configuración coincida con la estructura de su base de datos.

Cuando se usa el módulo userdb LDAP, asegúrese de que la userdb_fields configuración y la userdb_ldap_iterate_fields configuración coincidan con su esquema LDAP. De lo contrario doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecutar el comando para todos los usuarios en el archivo. Esto es similar a la -A opción, pero en lugar de obtener la lista de usuarios de la userdb, se leen del archivodado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realizar la búsqueda en la userdb. Usar la variable de entorno USER para especificar el nombre de usuario.

-S ruta-del-socket

El argumento de la opción es o bien una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre-de-host:puerto), para conectarse a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecutar el comando solo para el usuariodado. También es posible usar los comodines '*' y '?' (por ejemplo -u *@example.org).

ARGUMENTOS

buzón

Es el nombre de un buzón, tal como es visible para los clientes IMAP, excepto en formato UTF-8. El separador de jerarquía entre un buzón padre e hijo es comúnmente '/' o '.', pero esto depende de su formato de almacenamiento de buzones seleccionado y la configuración del espacio de nombres. Los nombres de buzones también pueden requerir un prefijo de espacio de nombres.

COMANDOS

mailbox create

doveadm [OPCIONES GLOBALES] mailbox create [-A | -u usuario | -F archivo | --no-userdb-lookup] [-S ruta-del-socket] [-g guid] [-s] buzón...

Este comando se usa para crear uno o más buzones. El formato de buzón de los buzones creados depende de la mail_driver configuración, o del campo mail del usuario, devuelto por la userdb.

-g guid

Crear el buzón con el GUID especificado.

-s

Este comando se usa para gestionar las claves criptográficas del plugin mail crypt. Consulte doveadm-mailbox-cryptokey(1) para más detalles.

mailbox delete

doveadm [OPCIONES GLOBALES] mailbox delete [-A | -u usuario | -F archivo | --no-userdb-lookup] [-S ruta-del-socket] [-s] [-r] [-e] [-Z] buzón...

Este comando elimina un buzón y purga todos los mensajes que contiene. Si el buzón tiene hijos, no serán eliminados, a menos que se dé -r .

-r

Eliminar buzones recursivamente.

-s

Cancelar la suscripción de los buzones eliminados.

-e

Requerir que los buzones estén vacíos antes de eliminarlos.

-Z

Eliminar el buzón de la manera más eficiente posible, pero el usuario puede no estar en un estado totalmente consistente después. Por ejemplo, la cuota puede ser incorrecta. Esta opción es principalmente útil al eliminar un usuario completo.

mailbox list

doveadm [OPCIONES GLOBALES] mailbox list [-7 | -8] [-A | -u usuario | -F archivo | --no-userdb-lookup] [-S ruta-del-socket] [-s] [buzón ...]

Para obtener una visión general de los buzones existentes use este comando. También es posible usar comodines en el nombre del buzón.

Cuando la -s opción está presente, solo se listarán los buzones suscritos. Las suscripciones listadas también pueden contener buzones que ya han sido eliminados.

-7

Lista los buzones con codificación mUTF-7.

-8

Lista los buzones con codificación UTF-8.

mailbox status

doveadm [GLOBAL OPTIONS] mailbox status [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [-t] fields mailbox...

Muestra el status de uno o más buzones. El mailbox nombre también puede contener comodines.

Este comando usa de forma predeterminada el formatter flow.

-t

Resume los valores de los campos de estado fields messages, recent, unseen y/o vsize de múltiples buzones a una suma (total).

fields

Especifica los campos de estado fields que deben mostrarse.

Para especificar múltiples campos de estado fields, enciérralos entre comillas.

all : Este es un nombre de campo de estado especial. Significa mostrar todos los siguientes fields. Cuando la opción -t está presente, significa mostrar solo los campos messages, recent, unseen y vsize fields.

guid : El mailbox's identificador único global.

highestmodseq : El valor de mod-sequence más alto de todos los mensajes en el mailbox.

messages : El número de mensajes en el mailbox.

deleted : El número de mensajes con la marca \Deleted establecida.

recent : El número de mensajes con la marca \Recent establecida.

uidnext : El valor del siguiente identificador único.

uidvalidity : El valor de validez del identificador único.

unseen : El número de secuencia del primer mensaje no visto en el mailbox.

vsize : El mailbox's tamaño virtual, calculado con terminadores de línea CRLF.

firstsaved : Hora de guardado del primer correo en el buzón.

NAME

doveadm-mailbox

manage mailboxes

SYNOPSIS

doveadm mailbox [GLOBAL OPTIONS] COMMAND [COMMAND OPTIONS]

DESCRIPTION

Manages mailboxes. Supported commands include:

  • mailbox delete
  • mailbox list
  • mailbox move
  • mailbox rename
  • mailbox search
  • mailbox status
  • mailbox subscribe
  • mailbox unsubscribe
  • mailbox cache set
  • mailbox cache purge
  • mailbox cache decision
  • mailbox cache remove
  • mailbox mutf7

GLOBAL OPTIONS

These options apply to all doveadm commands.

-D
Enables debugging.
-F file
Reads additional command line arguments from the specified file.
-n namespace
Specifies the namespace to use. The default is the user's primary namespace.
-o property=value
Overrides a configuration setting. See doveconf(1) for syntax.
-S socket_path
Connects to the given instead of the default commit socket.
-v
Enables verbosity.
-w
Waits for commands to finish.
-?
Prints the help message.

OPTIONS

The following options are available for many commands:

-A
Perform the command for all users.
-u user
Perform the command for the specified user only.
-F file
Read a list of users from the specified file.
--no-userdb-lookup
Do not look up users in userdb. This is useful if the userdb is not available or if you want to use mailboxes from a different userdb.

ARGUMENTS

mailbox
Mailbox name. Wildcards are allowed.
...
One or more mailbox names.

COMMANDS

mailbox delete

doveadm [GLOBAL OPTIONS] mailbox delete [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

Deletes the specified mailboxes. Mailboxes are recursively deleted.

mailbox list

doveadm [GLOBAL OPTIONS] mailbox list [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [-s | --subscribed] [-p | --preview] [-N | --no-list] [-m | --master-user] [-M | --all-mailboxes] [mailbox] ...

Lists mailboxes. By default, lists all mailboxes for all users.

-s, --subscribed

Lists only subscribed mailboxes.

-p, --preview

Prints mailbox previews (e.g. first few messages).

-N, --no-list

Don't list mailboxes from this user, only from other users.

-m, --master-user

List mailboxes for master users when using list for shared mailboxes.

-M, --all-mailboxes

List all mailboxes, including system mailboxes.

mailbox move

doveadm [GLOBAL OPTIONS] mailbox move [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] source_mailbox dest_mailbox

Moves all messages from source_mailbox to dest_mailbox. The source mailbox will be empty after the move. If dest_mailbox does not exist, it will be created.

mailbox rename

doveadm [GLOBAL OPTIONS] mailbox rename [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] old_mailbox new_mailbox

Renames old_mailbox to new_mailbox.

mailbox search

doveadm [GLOBAL OPTIONS] mailbox search [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [-T] [mailbox] ...

Searches for mailboxes matching the given criteria.

-T

Prints the mailbox name and its last modification time.

mailbox status

doveadm [GLOBAL OPTIONS] mailbox status [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [-f format] [mailbox] ...

Shows status information about mailboxes.

-f format

Specifies the output format. Available fields include: messages, recent, unseen, uidvalidity, uidnext, highestmodseq, highestpvtmodseq, size, vsize, trash, drafts, sent, mailbox.

Example: -f "messages vsize uidnext"

mailbox subscribe

doveadm [GLOBAL OPTIONS] mailbox subscribe [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

Subscribes the specified mailboxes for the given users.

mailbox unsubscribe

doveadm [GLOBAL OPTIONS] mailbox unsubscribe [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

Unsubscribes the specified mailboxes for the given users.

mailbox cache set

doveadm [GLOBAL OPTIONS] mailbox cache set [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [--min-next-uid uid] [--min-first-recent-uid uid] [--min-highest-modseq seq] [--min-highest-pvt-modseq seq] mailbox ...

This command is used to set UID validity, next UID, first recent UID and modification sequence values.

Usually this is only ever to be used during migration, or restoring mailbox after disaster. Settings these values is highly discouraged, and is not supported for all mail backends.

mailbox cache purge

doveadm [GLOBAL OPTIONS] mailbox cache purge [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

Purge the dovecot.index.cache file. Most importantly this frees up disk space from mails that were already deleted. Normally there i no need to run this command manually, because the compression is also run automatically.

mailbox cache decision

doveadm [GLOBAL OPTIONS] mailbox cache decision [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [--all] [--fields list of fields] [--last-used unix timestamp] [--decision no|temp|yes] mailbox ...

This command is used to list or change caching decisions for field(s) in mailbox(es). You can list decisions by leaving out decision and last-used parameters.

--all

List or change all fields.

--fields

List or change these comma/space separated fields.

--decision

Set field caching decision. Yes means it's always cached. Temp means it's provisionally cached. No means the field is not cached.

--last-used

Set field's last used timestamp.

NOTE: This command cannot be used to add new fields to cache! You need to first add them to configuration. Setting caching to no will not immediately drop field from cache, it will stop adding the field to cache.

mailbox cache remove

doveadm [GLOBAL OPTIONS] mailbox cache remove [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] search query

Remove any matching mail(s) from cache.

WARNING! This command can erase ALL cached data, causing system slowness.

See doveadm-search-query(7) for the search query syntax.

mailbox mutf7

doveadm [GLOBAL OPTIONS] mailbox mutf7 [-7] mailbox name

Converts the given mailbox name between UTF-8 and mUTF-7 encoding.

-7

Converts from UTF-8 to mUTF-7.

If the option is not given, it converts from mUTF-7 to UTF-8.

EXAMPLE

List subscribed mailboxes, beginning with 'dovecot', of user bob:

doveadm mailbox list -s -u bob dovecot\*
dovecot
dovecot/pigeonhole
dovecot/pigeonhole/2.0

Now have a look at the status of user bob's dovecot mailboxes:

doveadm -f table mailbox status -u bob "messages vsize" dovecot\*
mailbox                                    messages vsize
dovecot                                    20501    93968492
dovecot/pigeonhole                         0        0
dovecot/pigeonhole/2.0                     47       323474

Converting an internationalized mailbox name from mUTF-7 to UTF-8 and vice versa:

doveadm mailbox mutf7 -7 "~peter/mail/&U,BTFw-/&ZeVnLIqe-"
~peter/mail/台北/日本語
doveadm mailbox mutf7 ~peter/mail/台北/日本語
~peter/mail/&U,BTFw-/&ZeVnLIqe-
