-k Mantener todos los archivos de registro y estadísticas temporales creados por CRIU durante el checkpointing y la restauración. Estos archivos no se eliminan si la restauración falla, para una mayor depuración. Si la restauración tiene éxito, estos archivos no son teóricamente necesarios, pero si se necesitan, Podman puede conservar los archivos para un análisis posterior. Esto incluye el directorio de checkpoint con todos los archivos creados durante el checkpointing. El tamaño requerido por el directorio de checkpoint es aproximadamente igual a la cantidad de memoria requerida por los procesos en
