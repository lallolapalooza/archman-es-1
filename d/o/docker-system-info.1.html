NOMBRE

docker-system-info - Muestra información del sistema

SINOPSIS

docker system info [OPCIONES]

DESCRIPCIÓN

Este comando muestra información a nivel de sistema sobre la instalación de Docker. La información mostrada incluye la versión del kernel, el número de contenedores e imágenes. El número de imágenes que se muestra es el número de imágenes únicas. La misma imagen etiquetada con diferentes nombres se cuenta solo una vez.

Si se especifica un formato, se ejecutará la plantilla dada en lugar del formato predeterminado. El paquete text/template de Go describe todos los detalles del formato.

Dependiendo del controlador de almacenamiento en uso, se puede mostrar información adicional, como el nombre del pool, archivo de datos, archivo de metadatos, espacio de datos utilizado, espacio total de datos, espacio de metadatos utilizado y espacio total de metadatos.

El archivo de datos es donde se almacenan las imágenes y el archivo de metadatos es donde se almacenan los metadatos relacionados con esas imágenes. Cuando se ejecuta por primera vez, Docker asigna una cierta cantidad de espacio de datos y espacio de metadatos del espacio disponible en el volumen donde está montado /var/lib/docker.

También puedes especificar el formato de salida:

$ docker info --format '{{json .}}'
{"ID":"4cee4408-10d2-4e17-891c-a41736ac4536","Containers":14, ...}

OPCIONES

-f, --format="" Formatea la salida usando una plantilla personalizada: 'json': Imprime en formato JSON 'PLANTILLA': Imprime la salida usando la plantilla Go dada. Consulta https://docs.docker.com/go/formatting/ para más información sobre cómo formatear la salida con plantillas.
