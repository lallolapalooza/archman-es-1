NOMBRE

HOME/.docker/config.json - Archivo de configuración predeterminado de Docker

INTRODUCCIÓN

Por defecto, la línea de comandos de Docker almacena sus archivos de configuración en un directorio llamado .docker dentro de su directorio $HOME. Docker administra la mayoría de los archivos en el directorio de configuración y usted no debe modificarlos. Sin embargo, puede modificar el archivo config.json para controlar ciertos aspectos de cómo se comporta el comando docker.

Actualmente, puede modificar el comportamiento del comando docker utilizando variables de entorno u opciones de línea de comandos. También puede usar opciones dentro de config.json para modificar algunos de los mismos comportamientos. Al utilizar estos mecanismos, debe tener en cuenta el orden de precedencia entre ellos. Las opciones de línea de comandos anulan las variables de entorno, y las variables de entorno anulan las propiedades que especifica en un archivo config.json.

El archivo config.json almacena una codificación JSON de varias propiedades:

  • La propiedad HttpHeaders especifica un conjunto de encabezados que se incluirán en todos los mensajes enviados desde el cliente Docker al demonio. Docker no intenta interpretar ni comprender estos encabezados; simplemente los inserta en los mensajes. Docker no permite que estos encabezados cambien ningún encabezado que él mismo establezca.
  • La propiedad psFormat especifica el formato predeterminado para la salida de docker ps. Cuando no se proporciona la opción --format con el comando docker ps, el cliente de Docker utiliza esta propiedad. Si esta propiedad no está establecida, el cliente vuelve al formato de tabla predeterminado. Para obtener una lista de las directivas de formato admitidas, consulte docker-ps(1).
  • La propiedad detachKeys especifica la secuencia de teclas predeterminada que desconecta el contenedor. Cuando no se proporciona la opción --detach-keys con docker attach, docker exec, docker run o docker start, el cliente de Docker utiliza esta propiedad. Si esta propiedad no está establecida, el cliente vuelve a la secuencia predeterminada ctrl-p,ctrl-q.
  • La propiedad imagesFormat especifica el formato predeterminado para la salida de docker images. Cuando no se proporciona la opción --format con el comando docker images, el cliente de Docker utiliza esta propiedad. Si esta propiedad no está establecida, el cliente vuelve al formato de tabla predeterminado. Para obtener una lista de las directivas de formato admitidas, consulte docker-images(1).

Puede especificar una ubicación diferente para los archivos de configuración a través de la variable de entorno DOCKER_CONFIG o la opción de línea de comandos --config. Si se especifican ambas, la opción --config anula la variable de entorno DOCKER_CONFIG:

docker --config ~/testconfigs/ ps

Este comando indica a Docker que utilice los archivos de configuración del directorio ~/testconfigs/ al ejecutar el comando ps.

Ejemplos

A continuación, se muestra un archivo config.json de ejemplo:

{
  "HttpHeaders": {
    "MyHeader": "MyValue"
  },
  "psFormat": "table {{.ID}}\\t{{.Image}}\\t{{.Command}}\\t{{.Labels}}",
  "imagesFormat": "table {{.ID}}\\t{{.Repository}}\\t{{.Tag}}\\t{{.CreatedAt}}",
  "detachKeys": "ctrl-e,e"
}
