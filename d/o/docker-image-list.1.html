NOMBRE

podman-images - Lista imágenes en el almacenamiento local

SINOPSIS

podman images [opciones] [imagen]

podman image list [opciones] [imagen]

podman image ls [opciones] [imagen]

DESCRIPCIÓN

Muestra las imágenes almacenadas localmente, sus nombres y sus IDs.

OPCIONES

--all, -a

Mostrar todas las imágenes (por defecto filtra las capas de imagen intermedias). El valor predeterminado es falso.

--digests

Mostrar los resúmenes de las imágenes

--filter, -f=filtro

Proporcionar valores de filtro.

El argumento filtros tiene el formato clave=valor o clave!=valor. Si hay más de un filtro, pase múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros compatibles:

Filtro Descripción
id Filtrar por ID de imagen.
before Filtrar por imágenes creadas antes de la IMAGEN dada (nombre o etiqueta).
containers Filtrar por imágenes con un contenedor en ejecución.
dangling Filtrar por imágenes colgantes (no utilizadas).
digest Filtrar por resumen.
intermediate Filtrar por imágenes que están colgantes y no tienen hijos.
label Filtrar por imágenes con (o sin, en el caso de que se use label!=[...] ) las etiquetas especificadas.
manifest Filtrar por imágenes que son listas de manifiestos.
readonly Filtrar por imágenes de solo lectura o de lectura/escritura.
reference Filtrar por nombre de imagen.
after/since Filtrar por imágenes creadas después de la IMAGEN dada (nombre o etiqueta).
until Filtrar por imágenes creadas hasta la duración o fecha dada.

El filtro id acepta la cadena de ID de imagen.

El filtro before acepta formatos: <nombre-imagen>[:<etiqueta>], <id-imagen> o <imagen@resumen>.

El filtro containers muestra imágenes que tienen un contenedor en ejecución basado en esa imagen.

El filtro dangling muestra imágenes que están ocupando espacio en disco y no tienen ningún propósito. Una imagen colgante es una capa de sistema de archivos que se usó en una compilación anterior de una imagen y ya no es referenciada por ninguna imagen. Se denotan con la etiqueta <none>, consumen espacio en disco y no tienen ningún propósito activo.

El filtro digest acepta la cadena de resumen de la imagen.

El filtro intermediate muestra imágenes que están colgantes y no tienen hijos.

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que muestra imágenes con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que muestra imágenes sin las etiquetas especificadas.

El filtro manifest muestra imágenes que son listas de manifiestos.

El filtro readonly muestra, por defecto, imágenes de solo lectura y de lectura/escritura. Las imágenes de solo lectura se pueden configurar modificando additionalimagestores en el archivo /etc/containers/storage.conf.

El filtro reference acepta el patrón de una referencia de imagen <nombre-imagen>[:<etiqueta>].

Los filtros after o since aceptan formatos: <nombre-imagen>[:<etiqueta>], <id-imagen> o <imagen@resumen>.

El filtro until acepta formatos: duración de golang, tiempo RFC3339, o una marca de tiempo Unix, y muestra todas las imágenes creadas hasta ese momento.

--format=formato

Cambiar el formato de salida predeterminado. Puede ser de un tipo compatible como 'json' o una plantilla Go. Los marcadores de posición válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Containers Número de contenedores que utilizan esta imagen
.Created Tiempo transcurrido desde que se creó la imagen
.CreatedAt Hora en que se creó la imagen, AAAA-MM-DD HH:MM:SS +nnnn
.CreatedSince Lo mismo que .Created
.CreatedTime Lo mismo que .CreatedAt
.Dangling Lo mismo que .IsDangling
.Digest Resumen de la imagen
.History Historial de la capa de imagen
.ID ID de imagen (truncado)
.Id ID de imagen (SHA completo)
.IsDangling ¿Es la imagen colgante? (verdadero/falso)
.IsReadOnly ¿Es la imagen de solo lectura? (verdadero/falso)
.Labels ... map[] de etiquetas
.Names FQIN de la imagen
.ParentId SHA completo del ID de imagen padre, o null (cadena)
.ReadOnly Lo mismo que .IsReadOnly
.RepoDigests map[] de cero o más cadenas repo/nombre@sha256:SHA
.Repository Repositorio de la imagen
.RepoTags map[] de cero o más cadenas FQIN para esta imagen
.SharedSize Siempre parece ser 0
.Size Tamaño de la capa en disco (cadena amigable para humanos)
.Tag Etiqueta de la imagen
.VirtualSize Tamaño de la capa en disco (bytes)

--history

Mostrar el historial de nombres de imágenes. Si una imagen se vuelve a etiquetar o se des-etiqueta, el historial de nombres de la imagen se antepone (imagen más reciente primero). Esto es especialmente útil al deshacer una operación de etiquetado o cuando una imagen no contiene ningún nombre porque ha sido des-etiquetada.

--no-trunc

No truncar la salida (predeterminado falso).

--noheading, -n

Omitir los encabezados de la tabla de la lista.

--quiet, -q

Lista solo los IDs de las imágenes.

--sort=ordenar

Ordenar por created, id, repository, size o tag (predeterminado: created) Al ordenar por repository, también se ordena por la tag como segundo criterio para proporcionar una salida estable.

EJEMPLOS

Listar todas las imágenes no colgantes en el almacenamiento local:

$ podman images
REPOSITORY                         TAG         IMAGE ID      CREATED       SIZE
quay.io/podman/stable              latest      e0b7dabc3352  22 hours ago  331 MB
docker.io/library/alpine           latest      9c6f07244728  5 days ago    5.83 MB
registry.fedoraproject.org/fedora  latest      2ecb6df95994  3 weeks ago   169 MB
quay.io/libpod/testimage           20220615    f26aa69bb3f3  2 months ago  8.4 MB

Listar todas las imágenes que coinciden con el nombre especificado:

$ podman images stable
REPOSITORY             TAG         IMAGE ID      CREATED       SIZE
quay.io/podman/stable  latest      e0b7dabc3352  22 hours ago  331 MB

Listar los IDs de todas las imágenes en el almacenamiento de contenedores:

# podman image ls --quiet
e3d42bcaf643
ebb91b73692b
4526339ae51c

Listar todas las imágenes sin mostrar los encabezados:

# podman images --noheading
docker.io/kubernetes/pause                   latest   e3d42bcaf643   3 years ago   251 kB
<none>                                       <none>   ebb91b73692b   4 weeks ago   27.2 MB
docker.io/library/ubuntu                     latest   4526339ae51c   6 weeks ago   126 MB

Listar todas las imágenes sin truncar la salida:

# podman image list -
