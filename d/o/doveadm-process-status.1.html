DOVEADM-PROCESS-STATUS(1) Dovecot DOVEADM-PROCESS-STATUS(1)

NOMBRE

doveadm-process-status - Muestra información sobre los procesos de dovecot

SINOPSIS

doveadm [OPCIONES GLOBALES] process status [servicio [...]]

DESCRIPCIÓN

doveadm process status produce una tabla con una línea por cada proceso, que contiene los siguientes detalles:

nombre

el nombre del proceso

pid

el pid del proceso

available_count

el número de clientes adicionales que pueden conectarse al proceso

total_count

el número de clientes conectados

idle_start

marca de tiempo cuando el proceso entró en estado inactivo, 0 si está activo

last_status_update

marca de tiempo de la última actualización del proceso

last_kill_sent

marca de tiempo de la última señal SIGINT enviada al proceso

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, solo usar los valores por defecto. La configuración dovecot_storage_version se establece por defecto a la última versión, pero puede ser anulada con

-k

Preserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-instancia

Si se utilizan múltiples instancias de Dovecot, elige el archivo de configuración basándose en este nombre de instancia.

Consulta la configuración instance_name para más información.

-c archivo-configuración

Lee la configuración del archivo-configuración dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración del archivo de configuración /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.

-f formato

Especifica el formato para dar formato a la salida. Los formateadores soportados son:

flow

imprime cada línea con pares de clave=valor.

json

imprime una matriz JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con un carácter de avance de página (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separados por tabuladores.

table

imprime una cabecera de tabla seguida de líneas de valores ajustados.

ARGUMENTOS

servicio (opcional)

Filtra los procesos según el servicio o servicios especificados. Por defecto, se listan todos los procesos de dovecot.

EJEMPLOS

doveadm process status
nombre   pid    available_count total_count idle_start last_status_update last_kill_sent
stats  132400 999             5           0          1685365436         0
log    132356 971             29          0          1685352909         0
config 132357 999             6           0          1685365436         0
anvil  132355 1000            0           1685352908 1685352908         0

INFORME DE ERRORES

Reporta errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
