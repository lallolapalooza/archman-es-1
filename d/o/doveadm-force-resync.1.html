NOMBRE

doveadm-force-resync - Reparar buzones de correo rotos

SINOPSIS

doveadm [OPCIONES GLOBALES] force-resync [-S socket_path] -A mailbox

doveadm [OPCIONES GLOBALES] force-resync [-S socket_path] -F archivo mailbox

doveadm [OPCIONES GLOBALES] force-resync [-S socket_path] --no-userdb-lookup mailbox

doveadm [OPCIONES GLOBALES] force-resync [-S socket_path] -u usuario mailbox

DESCRIPCIÓN

Bajo ciertas circunstancias, puede ocurrir que dovecot(1) no sea capaz de resolver automáticamente problemas con los buzones de correo. En tales situaciones, el

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lea ningún archivo de configuración, solo use los valores predeterminados. La configuración dovecot_storage_version por defecto es la versión más reciente, pero puede ser anulada con

-k

Conserve todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-instancia

Si se utilizan múltiples instancias de Dovecot, elija el archivo de configuración basado en este nombre de instancia.

Ver la configuración instance_name para más información.

-c archivo-configuración

Lea la configuración desde el archivo-configuración dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.

OPCIONES

-A

Si la opción -A está presente, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, porque también incluye usuarios con un UID inferior al configurado con la configuración first_valid_uid.

Cuando se utiliza el módulo userdb SQL, asegúrese de que la configuración userdb_sql_iterate_query coincida con el diseño de su base de datos.

Al utilizar el módulo userdb LDAP, asegúrese de que las configuraciones userdb_fields y userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecuta el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo dado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realiza la búsqueda en la base de datos de usuarios. Use la variable de entorno USER para especificar el nombre de usuario.

-S ruta-socket

El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre-host:puerto), para conectar un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecuta el comando solo para el usuario dado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).

ARGUMENTOS

mailbox

El nombre del buzón de correo a arreglar. Con mdbox todos los buzones de correo se arreglan, por lo que puede usar INBOX, por ejemplo, como nombre.

EJEMPLO

Arreglar la bandeja de entrada de bob:

doveadm force-resync -u bob INBOX

REPORTE DE ERRORES

Informe de errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo informar errores está disponible en: https://dovecot.org/bugreport.html
