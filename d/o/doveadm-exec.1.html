NOMBRE

doveadm-exec - Ejecuta fácilmente comandos del directorio libexec de Dovecot.

SINOPSIS

doveadm [OPCIONES GLOBALES] exec binario [argumentos del binario]

DESCRIPCIÓN

Este comando permite a los administradores y usuarios locales ejecutar simplemente comandos dentro de /usr/libexec/dovecot. Así, por ejemplo, un usuario del sistema conectado podría iniciar una sesión IMAP pre-autenticada, utilizando el comando: doveadm exec imap. Un administrador usaría el comando doveadm exec imap -u nombre de usuario.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lee ningún archivo de configuración, solo usa los valores por defecto. La configuración dovecot_storage_version por defecto es la última versión, pero puede ser anulada con

-k

Conserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-instancia

Si se usan múltiples instancias de Dovecot, elige el archivo de configuración basándose en este nombre de instancia.

Ver la configuración instance_name para más información.

-c archivo-config

Lee la configuración del archivo-config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia en ejecución de versión compatible.

-o configuración=valor

Anula la configuración del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.

ARGUMENTOS

binario

el nombre de un ejecutable ubicado en /usr/libexec/dovecot.

argumentos del binario

opciones y argumentos, que se pasarán al binario.

EJEMPLO

Este ejemplo demuestra cómo entregar un mensaje desde un archivo al buzón de un usuario.

doveadm exec dovecot-lda -d user@example.net -f admin@example.net < ~/stuff/welcome.msg

INFORME DE ERRORES

Reporta errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
