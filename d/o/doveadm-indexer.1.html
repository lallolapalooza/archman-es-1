NOMBRE

doveadm-indexer - Comandos relacionados con la gestión del proceso indexador

SINOPSIS

doveadm [OPCIONES GLOBALES] indexer comando [OPCIONES] [ARGUMENTOS]

DESCRIPCIÓN

doveadm indexer puede ser utilizado para gestionar el proceso indexador.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, solo usar los valores por defecto. La configuración dovecot_storage_version se establece por defecto en la versión más reciente, pero puede ser anulada con

-k

Preservar todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluyendo el contador de progreso.

-i nombre-instancia

Si se utilizan múltiples instancias de Dovecot, elige el archivo de configuración basándose en este nombre de instancia.

Ver la configuración instance_name para más información.

-c archivo-config

Lee la configuración del archivo-config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.

-f formateador

Especifica el formateador para dar formato a la salida. Los formateadores soportados son:

flow

imprime cada línea con pares clave=valor.

json

imprime un array JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con un carácter de avance de página (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separadas por tabulaciones.

table

imprime una cabecera de tabla seguida de líneas de valores ajustados.

COMANDOS

indexer add

doveadm [OPCIONES GLOBALES] indexer add [-h] [-n max_recientes] usuario buzón

Añade una solicitud de indexación para el usuario y el buzón dados a la cola del indexador. Funciona igual que el comando doveadm index -q.

-h

Añade la solicitud de indexación al principio de la cola. Por defecto, la solicitud se añade al final de la cola.

-n max_recientes

Un valor entero, que especifica el número máximo de mensajes \Recent en los buzones. Si el buzón contiene más de max_recientes mensajes con la bandera \Recent establecida, el buzón no será indexado. Esto puede ser útil para evitar indexaciones innecesarias para buzones grandes que nunca se abren.

indexer remove

doveadm [OPCIONES GLOBALES] indexer remove mascara_usuario [mascara_buzon]

Elimina todas las solicitudes del indexador que coincidan con mascara_usuario (y mascara_buzon). Es posible usar comodines. Las solicitudes que están siendo procesadas actualmente por indexer-worker no se listan; usa doveadm kick en su lugar para desconectarlas.

indexer list

doveadm [OPCIONES GLOBALES] indexer list mascara_usuario

Lista todas las solicitudes de indexación en cola que coincidan con mascara_usuario. Es posible usar comodines. Las solicitudes que están siendo procesadas actualmente por indexer-worker no se listan; usa doveadm who en su lugar para verlas.

REPORTE DE ERRORES

Reporta errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
