NOMBRE

docker-swarm-init - Inicializar un swarm

SINOPSIS

docker swarm init [OPCIONES]

DESCRIPCIÓN

Inicializa un swarm

OPCIONES

--advertise-addr="" Dirección anunciada (formato: "[:puerto]")

--autolock[=false] Habilitar el bloqueo automático del gestor (requiriendo una clave de desbloqueo para iniciar un gestor detenido)

--availability="active" Disponibilidad del nodo ("active", "pause", "drain")

--cert-expiry=2160h0m0s Período de validez para los certificados de nodo (ns|us|ms|s|m|h)

--data-path-addr="" Dirección o interfaz a usar para el tráfico de la ruta de datos (formato: "")

--data-path-port=0 Número de puerto a usar para el tráfico de la ruta de datos (1024 - 49151). Si no se establece ningún valor o se establece en 0, se utiliza el puerto predeterminado (4789).

--default-addr-pool=[] pool de direcciones predeterminado en formato CIDR

--default-addr-pool-mask-length=24 longitud de la máscara de subred del pool de direcciones predeterminado

--dispatcher-heartbeat=5s Período de latido del dispatcher (ns|us|ms|s|m|h)

--external-ca= Especificaciones de uno o más puntos de conexión de firma de certificados

--force-new-cluster[=false] Forzar la creación de un nuevo clúster desde el estado actual

--listen-addr=0.0.0.0:2377 Dirección de escucha (formato: "[:puerto]")

--max-snapshots=0 Número de instantáneas Raft adicionales a retener

--snapshot-interval=10000 Número de entradas de registro entre instantáneas Raft

--task-history-limit=5 Límite de retención del historial de tareas
