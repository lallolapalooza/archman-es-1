NOMBRE

docker-image-history - Muestra el historial de una imagen

SINOPSIS

docker image history [OPCIONES] IMAGEN

DESCRIPCIÓN

Muestra el historial de cuándo y cómo se creó una imagen.

EJEMPLOS

$ docker history fedora
IMAGEN          CREADO          CREADO POR                                      TAMAÑO                COMENTARIO
105182bb5e8b   hace 5 días      /bin/sh -c #(nop) ADD file:71356d2ad59aa3119d   372.7 MB
73bd853d2ea5   hace 13 días     /bin/sh -c #(nop) MAINTAINER Lokesh Mandvekar   0 B
511136ea3c5a   hace 10 meses                                                    0 B                 Importado desde -

Mostrar comentarios en el historial de la imagen

El comando docker commit tiene una opción -m para agregar comentarios a la imagen. Estos comentarios se mostrarán en el historial de la imagen.

$ sudo docker history docker:scm
IMAGEN              CREADO        CREADO POR                                      TAMAÑO                COMENTARIO
2ac9d1098bf1        hace 3 meses    /bin/bash                                       241.4 MB            Añadido Apache a la imagen base de Fedora
88b42ffd1c7c        hace 5 meses    /bin/sh -c #(nop) ADD file:1fd8d7f9f6557cafc7   373.7 MB            
c69cab00d6ef        hace 5 meses    /bin/sh -c #(nop) MAINTAINER Lokesh Mandvekar   0 B                 
511136ea3c5a        hace 19 meses                                                       0 B                 Importado desde -

Formatear la salida

La opción de formato (--format) dará formato a la salida del historial utilizando una plantilla Go.

Los marcadores de posición válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.ID ID de la imagen
.CreatedSince Tiempo transcurrido desde que se creó la imagen si --human=true, de lo contrario, la marca de tiempo de cuándo se creó la imagen
.CreatedAt Marca de tiempo de cuándo se creó la imagen
.CreatedBy Comando que se utilizó para crear la imagen
.Size Tamaño en disco de la imagen
.Comment Comentario de la imagen

Al utilizar la opción --format, el comando history imprimirá los datos exactamente como los declara la plantilla o, cuando se utiliza la directiva table, incluirá también las cabeceras de columna.

El siguiente ejemplo utiliza una plantilla sin cabeceras e imprime las entradas ID y CreatedSince separadas por dos puntos para todas las imágenes:

$ docker images --format "{{.ID}}: {{.CreatedSince}} ago"
cc1b61406712: hace 2 semanas
<missing>: hace 2 semanas
<missing>: hace 2 semanas
<missing>: hace 2 semanas
<missing>: hace 2 semanas
<missing>: hace 3 semanas
<missing>: hace 3 semanas
<missing>: hace 3 semanas

OPCIONES

--format="" Formatea la salida utilizando una plantilla personalizada: 'table': Imprime la salida en formato de tabla con cabeceras de columna (por defecto) 'table PLANTILLA': Imprime la salida en formato de tabla utilizando la plantilla Go dada 'json': Imprime en formato JSON 'PLANTILLA': Imprime la salida utilizando la plantilla Go dada. Consulte https://docs.docker.com/go/formatting/ para más información sobre cómo formatear la salida con plantillas.

-H, --human[=true] Imprime tamaños y fechas en formato legible para humanos.

--no-trunc[=false] No truncar la salida.

--platform="" Muestra el historial de la plataforma dada. Formateado como "os[/arch[/variant]]" (por ejemplo, "linux/amd64").

-q, --quiet[=false] Solo muestra los IDs de las imágenes.
