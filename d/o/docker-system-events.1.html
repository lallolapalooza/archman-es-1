docker-system-events(1)

DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker-system-events - Obtener eventos en tiempo real del servidor

SINOPSIS

docker system events [OPCIONES]

DESCRIPCIÓN

Obtener información de eventos del demonio de Docker. La información puede incluir información histórica y en tiempo real.

Los contenedores de Docker informarán de los siguientes eventos:

attach, commit, copy, create, destroy, detach, die, exec_create, exec_detach, exec_start, export, kill, oom, pause, rename, resize, restart, start, stop, top, unpause, update

Las imágenes de Docker informan de los siguientes eventos:

delete, import, load, pull, push, save, tag, untag

Los volúmenes de Docker informan de los siguientes eventos:

create, mount, unmount, destroy

Las redes de Docker informan de los siguientes eventos:

create, connect, disconnect, destroy

OPCIONES

Los parámetros --since y --until pueden ser marcas de tiempo Unix, marcas de tiempo con formato de fecha o cadenas de duración de Go soportadas por ParseDuration ⟨https://pkg.go.dev/time#ParseDuration⟩ (por ejemplo, 10m, 1h30m) calculadas con respecto a la hora de la máquina del cliente. Si no proporciona la opción --since , el comando devuelve solo eventos nuevos y/o en vivo. Los formatos soportados para marcas de tiempo con formato de fecha incluyen RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02T07:00y 2006-01-02. Se utilizará la zona horaria local del cliente si no proporciona ni un Z ni un desfase de zona horaria +-00:00 al final de la marca de tiempo. Al proporcionar marcas de tiempo Unix, introduzca segundos[.nanosegundos], donde segundos es el número de segundos que han transcurrido desde el 1 de enero de 1970 (medianoche UTC/GMT), sin contar los segundos bisiestos (también conocido como época Unix o tiempo Unix), y el campo opcional .nanosegundos es una fracción de segundo de no más de nueve dígitos de longitud.

Escuchando eventos de Docker

2015-01-28T20:21:31.000000000-08:00 59211849bc10: (from whenry/testimage:latest) die

Formato

Si se especifica un formato (--format), se ejecutará la plantilla dada en lugar del formato predeterminado. El paquete text/template de Go describe todos los detalles del formato.

# docker events --filter 'type=container' --format 'Type={{.Type}}  Status={{.Status}}  ID={{.ID}}'
Type=container  Status=create  ID=2ee349dac409e97974ce8d01b70d250b85e0ba8189299c126a87812311951e26
Type=container  Status=attach  ID=2ee349dac409e97974ce8d01b70d250b85e0ba8189299c126a87812311951e26
Type=container  Status=start  ID=2ee349dac409e97974ce8d01b70d250b85e0ba8189299c126a87812311951e26
Type=container  Status=resize  ID=2ee349dac409e97974ce8d01b70d250b85e0ba8189299c126a87812311951e26
Type=container  Status=die  ID=2ee349dac409e97974ce8d01b70d250b85e0ba8189299c126a87812311951e26
Type=container  Status=destroy  ID=2ee349dac409e97974ce8d01b70d250b85e0ba8189299c126a87812311951e26

Si el formato se establece en {{json .}}, los eventos se transmiten como JSON Lines válido. Para obtener información sobre JSON Lines, consulte https://jsonlines.org .
