NOMBRE

docker-ps - Listar contenedores

SINOPSIS

docker ps [OPCIONES]

DESCRIPCIÓN

Alias de docker container ls.

OPCIONES

-a, --all[=false] Mostrar todos los contenedores (por defecto solo muestra los en ejecución)

-f, --filter= Filtrar la salida según las condiciones proporcionadas

--format="" Formatear la salida utilizando una plantilla personalizada: 'table': Imprimir la salida en formato de tabla con encabezados de columna (por defecto) 'table PLANTILLA': Imprimir la salida en formato de tabla utilizando la plantilla Go proporcionada 'json': Imprimir en formato JSON 'PLANTILLA': Imprimir la salida utilizando la plantilla Go proporcionada. Consulte https://docs.docker.com/go/formatting/ para obtener más información sobre el formateo de la salida con plantillas

-n, --last=-1 Mostrar los últimos n contenedores creados (incluye todos los estados)

-l, --latest[=false] Mostrar el último contenedor creado (incluye todos los estados)

--no-trunc[=false] No truncar la salida

-q, --quiet[=false] Mostrar solo los IDs de los contenedores

-s, --size[=false] Mostrar los tamaños totales de los archivos
