NOMBRE

doveadm-instance - Gestiona la lista de instancias de Dovecot en ejecución

SINOPSIS

doveadm [OPCIONES GLOBALES] instance list [-c] [nombre]

doveadm [OPCIONES GLOBALES] instance remove nombre

DESCRIPCIÓN

Los comandos doveadm instance se utilizan para gestionar la lista de instancias de Dovecot que se ejecutan en el servidor. En la mayoría de las instalaciones solo hay una instancia de Dovecot, pero en algunos casos puede ser útil tener más (por ejemplo, ejecutando proxy y backend en el mismo servidor).

Las instancias se añaden a la lista automáticamente cuando se inicia Dovecot. Cada instancia se identifica de forma única por su configuración de base_dir. Las instancias pueden ser nombradas estableciendo instance_name en el dovecot.conf de cada instancia. Cuando una instancia tiene nombre, se puede acceder a ella fácilmente proporcionando el parámetro de línea de comandos -i nombre_instancia para los binarios de Dovecot (por ejemplo, doveadm).

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita los mensajes de depuración y verbosidad.

-O

No lee ningún archivo de configuración, solo usa los valores por defecto. La configuración dovecot_storage_version por defecto es la última versión, pero puede ser anulada con

-k

Preserva el entorno completo para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre-instancia

Si se utilizan múltiples instancias de Dovecot, elige el archivo de configuración basándose en este nombre de instancia.

Consulta la configuración instance_name para más información.

-c archivo-configuración

Lee la configuración del archivo-configuración dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración del archivo /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o puede especificarse varias veces.

-f formateador

Especifica el formateador para dar formato a la salida. Los formateadores soportados son:

flow

imprime cada línea con pares clave=valor.

json

imprime una matriz JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con un carácter de salto de página (^L).

tab

imprime una cabecera de tabla seguida de líneas con valores separados por tabulación.

table

imprime una cabecera de tabla seguida de líneas con valores ajustados.

ARGUMENTOS

nombre

El valor de la configuración instance_name de una instancia. Cada instancia también puede ser identificada de forma única por su configuración base_dir.

COMANDOS

instance list

doveadm [OPCIONES GLOBALES] instance list [-c] [nombre]

Este comando lista las instancias de Dovecot vistas.

-c

Muestra la ruta de configuración en lugar de la información de la instancia.

instance remove

doveadm [OPCIONES GLOBALES] instance remove nombre

Este comando elimina la instancia especificada.

REPORTE DE ERRORES

Reporta errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
