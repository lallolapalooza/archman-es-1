DOXYGEN(1) Comandos de usuario DOXYGEN(1)

NOMBRE

Doxygen - sistema de documentación para varios lenguajes de programación

DESCRIPCIÓN

Doxygen es un sistema de documentación para C++, C, Java, Objective-C, IDL (sabores CORBA y Microsoft), Fortran, Python, VHDL y, hasta cierto punto, PHP, C# y D.

Puedes usar Doxygen de varias maneras:

1) Generar un archivo de configuración de plantilla*:
doxygen [-s] -g [nombreConfig]
2) Actualizar un archivo de configuración existente*:
doxygen [-s] -u [nombreConfig]
3) Generar documentación usando un archivo de configuración existente*:
doxygen [nombreConfig]
4) Generar un archivo de plantilla que controla el diseño de la documentación generada:
doxygen -l [archivoLayout]

Si se omite archivoLayout, se usará DoxygenLayout.xml como nombre de archivo.
Si se usa - para archivoLayout, Doxygen escribirá en la salida estándar.
5) Generar un archivo de hoja de estilos de plantilla para RTF, HTML o LaTeX:
RTF: doxygen -w rtf archivoHojaEstilos
HTML: doxygen -w html archivoCabecera archivoPie hojaEstilos [archivoConfig]
LaTeX: doxygen -w latex archivoCabecera archivoPie hojaEstilos [archivoConfig]
6) Generar un archivo de extensiones RTF:
RTF: doxygen -e rtf archivoExtensiones

Si se usa - para archivoExtensiones, Doxygen escribirá en la salida estándar.
7) Comparar el archivo de configuración utilizado con el archivo de configuración de plantilla:
doxygen -x [archivoConfig]

Comparar el archivo de configuración utilizado con el archivo de configuración de plantilla

sin reemplazar las variables de entorno o las variables de reemplazo de tipo CMake:
doxygen -x_noenv [archivoConfig]
8) Mostrar una lista de emojis incorporados.
doxygen -f emoji nombreArchivoSalida

Si se usa - para nombreArchivoSalida, Doxygen escribirá en la salida estándar.
*) Si se especifica -s, se omitirán los comentarios de los elementos de configuración en el archivo de configuración.
Si se omite nombreConfig, se usará 'Doxyfile' por defecto.
Si se usa - para archivoConfig, Doxygen escribirá / leerá la configuración desde la salida / entrada estándar.

Si se usa -q para una ejecución de documentación de Doxygen, Doxygen lo verá como si se hubiera establecido QUIET=YES.

-v imprime la cadena de versión, -V imprime información extendida de la versión

-h,-? imprime la ayuda de uso

doxygen -d imprime indicadores de uso adicionales para fines de depuración.
