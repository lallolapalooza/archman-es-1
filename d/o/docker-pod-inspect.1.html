Mostrar solo el nombre y estado del

pod: 
$ podman pod inspect --format "{{.Name}}\t{{.State}}" mypod
mypod
Running

Mostrar el ID del pod y el número de

contenedores: 
$ podman pod inspect mypod --format "Pod {{.Name}} ({{.ID}}) has {{.NumContainers}} containers"
Pod mypod (605f5f776e101a6e0ad11ea802cae25eabf299da77122f2963fa65dc6ccf6717) has 2
containers

Mostrar el tiempo de creación del pod y los espacios de nombres

compartidos: 
$ podman pod inspect mypod --format "Created: {{.Created}}\nShared: {{.SharedNamespaces}}"

Shared: [net uts
ipc]

pod: 
$ podman pod inspect --format "Memory: {{.MemoryLimit}}, CPU Period: {{.CPUPeriod}}, CPU Quota: {{.CPUQuota}}" mypod

50000

pod:
