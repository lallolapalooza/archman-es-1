NAME

doveadm-reload - Reload Dovecot configuration

SYNOPSIS

doveadm reload [-A] [-u user] [-F filter]

DESCRIPTION

The doveadm reload command reloads the Dovecot configuration. This is often required after changing configuration files like dovecot.conf or settings related to plugins. This command is typically used by system administrators.

By default, it reloads the configuration for all users. You can target specific users with the -u or -A flags.

GLOBAL OPTIONS

-A
If specified, the command is executed for all users.
-F filter
Execute command only for users matching the given filter. The filter format is the same as for doveadm-users(1).
-u user
Execute command only for the specified user.

COMMANDS

No specific commands are available for doveadm reload as it is a standalone command that performs a single action.

doveadm will exit with one of the following values:

64

Command line usage error.

65

Data format error or operation is not possible.

67

68

Input file, address or other resource does not exist.

73

Cannot create output file.

75

There was some temporary error, check logs.

76

Protocol error during remote host connection.

77

Permission error.

78

Configuration error.

127

Unknown error.
