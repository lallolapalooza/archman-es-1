NOMBRE

docker-start - Inicia uno o más contenedores detenidos

SINOPSIS

docker start [OPCIONES] CONTENEDOR [CONTENEDOR...]

DESCRIPCIÓN

Alias de docker container start.

OPCIONES

-a, --attach[=false] Adjuntar STDOUT/STDERR y reenviar señales

--checkpoint="" Restaurar desde este punto de control

--checkpoint-dir="" Usar un directorio de almacenamiento de puntos de control personalizado

--detach-keys="" Anular la secuencia de teclas para desacoplar un contenedor

-i, --interactive[=false] Adjuntar STDIN del contenedor
