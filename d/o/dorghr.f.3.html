Documentación de la función/subrutina

subrutina dorghr (integer n, integer ilo, integer ihi, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer lwork, integer info)

DORGHR

Propósito:

!>
!> DORGHR genera una matriz ortogonal real Q que se define como el
!> producto de IHI-ILO reflexiones elementales de orden N, como se devuelve
!> por DGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz Q. N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>
!>          ILO e IHI deben tener los mismos valores que en la llamada anterior
!>          de DGEHRD. Q es igual a la matriz identidad excepto en la
!>          submatriz Q(ilo+1:ihi,ilo+1:ihi).
!>          1 <= ILO <= IHI <= N, si N > 0; ILO=1 e IHI=0, si N=0.
!>

A

!>          A es un array de DOBLE PRECISIÓN, dimensión (LDA,N)
!>          A la entrada, los vectores que definen las reflexiones elementales,
!>          como se devuelve por DGEHRD.
!>          A la salida, la matriz ortogonal N por N, Q.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

TAU

!>          TAU es un array de DOBLE PRECISIÓN, dimensión (N-1)
!>          TAU(i) debe contener el factor escalar de la reflexión
!>          elemental H(i), como se devuelve por DGEHRD.
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= IHI-ILO.
!>          Para un rendimiento óptimo LWORK >= (IHI-ILO)*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
