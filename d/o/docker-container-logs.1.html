NOMBRE

docker-container-logs - Obtiene los registros de un contenedor

SINOPSIS

docker container logs [OPCIONES] CONTENEDOR

DESCRIPCIÓN

El comando docker container logs recupera por lotes los registros que existan para un contenedor en el momento de la ejecución. Esto no garantiza el orden de ejecución cuando se combina con un docker run (es decir, tu ejecución puede no haber generado ningún registro en el momento en que ejecutas docker container logs).

El comando docker container logs --follow combina los comandos docker container logs y docker attach. Primero devolverá todos los registros desde el principio y luego continuará transmitiendo nueva salida desde stdout y stderr del contenedor.

Advertencia: Este comando solo funciona para los controladores de registro json-file o journald.

Las opciones --since y --until pueden ser marcas de tiempo Unix, marcas de tiempo con formato de fecha o cadenas de duración Go compatibles con ParseDuration ⟨https://pkg.go.dev/time#ParseDuration⟩ (por ejemplo, 10m, 1h30m) calculadas en relación con la hora de la máquina cliente. Los formatos compatibles para marcas de tiempo con formato de fecha incluyen RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02T07:00, y 2006-01-02. La zona horaria local en el cliente se utilizará si no proporciona un desplazamiento de zona horaria Z o +-00:00 al final de la marca de tiempo. Al proporcionar marcas de tiempo Unix, introduzca segundos[.nanosegundos], donde segundos es el número de segundos transcurridos desde el 1 de enero de 1970 (medianoche UTC/GMT), sin contar los segundos bisiestos (también conocido como época Unix o tiempo Unix), y el campo opcional .nanosegundos es una fracción de segundo de no más de nueve dígitos. Puede combinar las opciones --since o --until con cualquiera o ambas opciones --follow o --tail.

El comando docker container logs --details añadirá atributos adicionales, como variables de entorno y etiquetas, proporcionados a --log-opt al crear el contenedor.

Para recuperar registros anteriores a un punto específico en el tiempo, ejecute:

$ docker run --name test -d busybox sh -c "while true; do $(echo date); sleep 1; done"
$ date
mar 14 nov 2017 16:40:00 CET
$ docker logs -f --until=2s test
mar 14 nov 2017 16:40:00 CET
mar 14 nov 2017 16:40:01 CET
mar 14 nov 2017 16:40:02 CET

OPCIONES

--details[=false] Mostrar detalles adicionales proporcionados a los registros

-f, --follow[=false] Seguir la salida de los registros

--since="" Mostrar registros desde la marca de tiempo (por ejemplo, "2013-01-02T13:23:37Z") o relativa (por ejemplo, "42m" para 42 minutos)

-n, --tail="all" Número de líneas a mostrar desde el final de los registros

-t, --timestamps[=false] Mostrar marcas de tiempo

--until="" Mostrar registros antes de una marca de tiempo (por ejemplo, "2013-01-02T13:23:37Z") o relativa (por ejemplo, "42m" para 42 minutos)
