NOMBRE

dosbox - Emulador de PC x86.

SINOPSIS

dosbox [opciones] [imagen_o_directorio]

dosbox -info

dosbox -version

dosbox -edit configfile

dosbox -securemode

DESCRIPCION

dosbox es un emulador de PC x86 que emula una computadora completa, incluyendo la CPU, la tarjeta de sonido, la tarjeta gráfica, la memoria, el ratón, los puertos serie, etc. Está diseñado para que se puedan ejecutar programas de MS-DOS que no se pueden ejecutar en las computadoras modernas, como juegos antiguos, aplicaciones de DOS o incluso otros sistemas operativos como DR-DOS o FreeDOS.

dosbox usa el motor de emulación de CPU de dosbox-x, que es un fork de la versión oficial de dosbox. El motor de dosbox-x es más avanzado y permite una mejor compatibilidad y rendimiento.

Se puede ejecutar dosbox con varios argumentos en la línea de comandos. Si no se especifica ninguna imagen o directorio, dosbox arrancará con un sistema de archivos vacío. Si se especifica una imagen de disco, dosbox intentará montarla como unidad C:. Si se especifica un directorio, dosbox intentará montar ese directorio como unidad C:.

Se pueden utilizar las siguientes opciones en la línea de comandos:

OPCIONES

-info
Muestra información sobre la versión de dosbox y los archivos de configuración.
-version
Muestra la versión de dosbox y sale.
-edit configfile
Abre el archivo de configuración especificado en el editor de texto predeterminado del sistema.
-securemode
Cambia dosbox a un modo más seguro. En este modo, los comandos internos MOUNT, IMGMOUNT y BOOT no funcionarán. Tampoco será posible crear un nuevo archivo de configuración o un archivo de idioma en este modo. (Advertencia: solo se puede salir de este modo reiniciando dosbox).

El archivo de configuración controla varios ajustes de dosbox: la cantidad de memoria emulada, las tarjetas de sonido emuladas y muchas cosas más. Además, permite el acceso a AUTOEXEC.BAT.

El archivo de idioma controla toda la salida visible de los comandos internos y del dos interno. Consulte la sección ARCHIVOS para obtener más información.

COMANDOS INTERNOS

LOADFIX [-tamaño] [nombreprograma] [parámetros]

LOADFIX -f

Programa para reducir la cantidad de memoria disponible. Útil para programas antiguos que no esperan mucha memoria libre.

[nombreprograma]
El nombre del programa que se ejecuta después de que loadfix consuma su memoria.
[parámetros]
Parámetros dados al ejecutable nombreprograma.
-tamaño
La cantidad de memoria a consumir (en KB). Ejemplo: -32, -64 o -128
-f
Libera toda la memoria consumida por loadfix.
RESCAN

Hace que dosbox relea la estructura de directorios. Útil si ha cambiado algo en una unidad montada fuera de dosbox (¡CTRL-F4 hace esto también!).

IMGMOUNT

Una utilidad para montar imágenes de disco e imágenes de CD-ROM en dosbox.

Lea el README de dosbox para la sintaxis completa y correcta.

BOOT

BOOT iniciará imágenes de disquete o imágenes de disco duro independientemente de la emulación del sistema operativo ofrecida por dosbox. Esto le permitirá jugar disquetes de arranque o arrancar en otros sistemas operativos dentro de dosbox.

Lea el README de dosbox para la sintaxis completa y correcta.

IPX

Necesita habilitar la red IPX en el archivo de configuración de dosbox. Toda la red IPX se gestiona a través del programa interno de dosbox, IPXNET. Para obtener ayuda sobre la red IPX dentro de dosbox, escriba IPXNET HELP y el programa le mostrará los comandos y la documentación relevante.

Lea el README de dosbox para la sintaxis completa y correcta.

KEYB

KEYB puede cambiar la distribución del teclado y la página de códigos utilizada dentro de dosbox.

Lea el README de dosbox para la sintaxis completa y correcta.

ARCHIVOS

Los archivos de configuración y de idioma utilizan un formato similar a los archivos .ini de Windows. Si no se especifica ningún archivo de configuración en la línea de comandos, se cargará automáticamente un archivo llamado dosbox.conf (si está presente en el directorio actual). Si se especifica un archivo de configuración en la línea de comandos, se utilizará ese en su lugar. Si no se especifica ni se encuentra ningún archivo de configuración en el directorio actual, dosbox cargará uno desde ~/.dosbox/. Intentará crear uno si no existe.

Los archivos guardados/grabados se pueden encontrar en directorio_actual/capture (se puede cambiar en el archivo de configuración). ¡El directorio debe existir antes de iniciar dosbox, de lo contrario, no se guardará/grabar nada!

Nota: Una vez que aumente los ciclos de dosbox más allá de la capacidad máxima de su computadora, producirá el mismo efecto que ralentizar la emulación. Este máximo variará de una computadora a otra, no hay un estándar.

REQUISITOS DEL SISTEMA

Máquina rápida. Mi suposición sería un Pentium-2 400+ para obtener una emulación decente de juegos escritos para una máquina 286. Para juegos en modo protegido, se recomienda una máquina de 1 GHz y ¡no espere que funcionen rápido! Asegúrese de leer la siguiente sección sobre cómo acelerarlo un poco.

Para ejecutar juegos que requieren muchos recursos

dosbox emula la CPU, la tarjeta de sonido y gráfica, y algunas otras cosas, todo al mismo tiempo. Puede overclockear dosbox usando CTRL-F12, pero estará limitado por la potencia de su CPU real. Puede ver cuánto tiempo libre tiene su CPU real con varias utilidades (top). Una vez que se utilice el 100% del tiempo de su CPU real, no habrá forma de acelerar dosbox a menos que reduzca la carga generada por las partes no de CPU de dosbox.

Así que:

Cierre todos los programas excepto dosbox.

Overclockee dosbox hasta que se utilice el 100% de su CPU (CTRL-F12).

Dado que la emulación VGA es la parte que más consume recursos de dosbox en términos de uso de CPU real, comenzaremos por aquí. Aumente el número de frames saltados (en incrementos de uno) presionando CTRL-F8. El uso de su CPU debería disminuir. Retroceda un paso y repita esto hasta que el juego se ejecute lo suficientemente rápido para usted. Tenga en cuenta que esto es un compromiso: pierde fluidez de vídeo en lo que gana en velocidad.

NOTAS

Si bien esperamos que, algún día, dosbox ejecute prácticamente todos los programas que se hayan fabricado para PC... aún no hemos llegado. Actualmente, ejecutar dosbox en una PC de 1.7 Gigahertz es aproximadamente el equivalente a una PC 386 de 25MHz. Si bien la versión 0.60 ha agregado soporte para "modo protegido", lo que permite programas más complejos y recientes, tenga en cuenta que este soporte está en sus primeras etapas de desarrollo y no está ni cerca de ser tan completo como el soporte para juegos de 386 en modo real (o anteriores). Tenga en cuenta también que los juegos en "modo protegido" necesitan recursos sustancialmente mayores y pueden requerir un procesador mucho más rápido para que usted lo ejecute correctamente en dosbox.

ERRORES

No todos los programas de DOS funcionan correctamente. dosbox saldrá sin previo aviso si ocurrió un error.
