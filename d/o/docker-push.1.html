NOMBRE

docker-push - Sube una imagen a un registro

SINOPSIS

docker push [OPCIONES] NOMBRE[:TAG]

DESCRIPCIÓN

Alias de docker image push.

OPCIONES

-a, --all-tags[=false] Sube todas las etiquetas de una imagen al repositorio

--platform="" Sube un manifiesto específico de plataforma como una imagen de plataforma única al registro. No se conservarán índices de imágenes ni manifiestos (incluidas las confirmaciones de autenticidad). 'os[/arch[/variant]]': Plataforma explícita (ej. linux/amd64)

-q, --quiet[=false] Suprime la salida detallada
