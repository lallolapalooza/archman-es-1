docker-service-update(1)

Paquete: docker

Licencias: Apache-2.0

DOCKER(1) Manuales de Usuario de Docker DOCKER(1)

NOMBRE

docker-service-update - Actualizar un servicio

SINOPSIS

docker service update [OPCIONES] SERVICIO

DESCRIPCIÓN

Actualizar un servicio

OPCIONES

--args= Argumentos de comando del servicio

--cap-add= Añadir capacidades de Linux

--cap-drop= Eliminar capacidades de Linux

--config-add= Añadir o actualizar un archivo de configuración en un servicio

--config-rm= Eliminar un archivo de configuración

--constraint-add= Añadir o actualizar una restricción de ubicación

--constraint-rm= Eliminar una restricción

--container-label-add= Añadir o actualizar una etiqueta del contenedor

--container-label-rm= Eliminar una etiqueta del contenedor por su clave

--credential-spec= Especificación de credenciales para la cuenta de servicio administrada (solo Windows)

-d, --detach[=false] Salir inmediatamente en lugar de esperar a que el servicio converja

--dns-add= Añadir o actualizar un servidor DNS personalizado

--dns-option-add= Añadir o actualizar una opción DNS

--dns-option-rm= Eliminar una opción DNS

--dns-rm= Eliminar un servidor DNS personalizado

--dns-search-add= Añadir o actualizar un dominio de búsqueda DNS personalizado

--dns-search-rm= Eliminar un dominio de búsqueda DNS

--endpoint-mode="" Modo de punto final (vip o dnsrr)

--entrypoint= Sobrescribir el ENTRYPOINT predeterminado de la imagen

--env-add= Añadir o actualizar una variable de entorno

--env-rm= Eliminar una variable de entorno

--force[=false] Forzar la actualización aunque no haya cambios que la requieran

--generic-resource-add= Añadir un recurso genérico

--generic-resource-rm= Eliminar un recurso genérico

--group-add= Añadir un grupo de usuarios suplementario adicional al contenedor

--group-rm= Eliminar un grupo de usuarios suplementario previamente añadido del contenedor

--health-cmd="" Comando a ejecutar para verificar la salud

--health-interval= Tiempo entre ejecuciones de la verificación (ms|s|m|h)

--health-retries=0 Intentos fallidos consecutivos necesarios para informar como no saludable

--health-start-interval= Tiempo entre ejecuciones de la verificación durante el período de inicio (ms|s|m|h)

--health-start-period= Período de inicio para que el contenedor se inicialice antes de contar los reintentos hacia inestable (ms|s|m|h)

--health-timeout= Tiempo máximo para permitir que se ejecute una verificación (ms|s|m|h)

--host-add= Añadir un mapeo personalizado host-a-IP ("host:ip")

--host-rm= Eliminar un mapeo personalizado host-a-IP ("host:ip")

--hostname="" Nombre de host del contenedor

--image="" Etiqueta de imagen del servicio

--init[=false] Usar un init dentro de cada contenedor de servicio para reenviar señales y recolectar procesos

--isolation="" Modo de aislamiento del contenedor de servicio

--label-add= Añadir o actualizar una etiqueta del servicio

--label-rm= Eliminar una etiqueta por su clave

--limit-cpu= Limitar CPUs

--limit-memory=0 Limitar Memoria

--limit-pids=0 Limitar el número máximo de procesos (predeterminado 0 = sin límite)

--log-driver="" Controlador de registro para el servicio

--log-opt= Opciones del controlador de registro

--max-concurrent= Número de tareas de trabajo a ejecutar simultáneamente (predeterminado igual a --replicas)

--memory-swap=0 Bytes de intercambio (-1 para ilimitado)

--memory-swappiness=-1 Ajustar la 'swappiness' de memoria (0-100), -1 para restablecer al valor predeterminado

--mount-add= Añadir o actualizar un montaje en un servicio

--mount-rm= Eliminar un montaje por su ruta de destino

--network-add= Añadir una red

--network-rm= Eliminar una red

--no-healthcheck[=false] Desactivar cualquier HEALTHCHECK especificado por el contenedor

--no-resolve-image[=false] No consultar el registro para resolver el identificador de imagen y las plataformas admitidas

--oom-score-adj=0 Ajustar las preferencias OOM del host (-1000 a 1000)

--placement-pref-add= Añadir una preferencia de ubicación

--placement-pref-rm= Eliminar una preferencia de ubicación

--publish-add= Añadir o actualizar un puerto publicado

--publish-rm= Eliminar un puerto publicado por su puerto de destino

-q, --quiet[=false] Suprimir la salida de progreso

--read-only[=false] Montar el sistema de archivos raíz del contenedor como solo lectura

--replicas= Número de tareas

--replicas-max-per-node=0 Número máximo de tareas por nodo (predeterminado 0 = sin límite)

--reserve-cpu= Reservar CPUs

--reserve-memory=0 Reservar Memoria

--restart-condition="" Reiniciar cuando se cumpla la condición ("none", "on-failure", "any")

--restart-delay= Retraso entre intentos de reinicio (ns|us|ms|s|m|h)

--restart-max-attempts= Número máximo de reinicios antes de rendirse

--restart-window= Ventana utilizada para evaluar la política de reinicio (ns|us|ms|s|m|h)

--rollback[=false] Revertir a la especificación anterior

--rollback-delay=0s Retraso entre reversiones de tareas (ns|us|ms|s|m|h)

--rollback-failure-action="" Acción en caso de fallo de reversión ("pause", "continue")

--rollback-max-failure-ratio=0 Ratio de fallos a tolerar durante una reversión

--rollback-monitor=0s Duración después de cada reversión de tarea para monitorizar fallos (ns|us|ms|s|m|h)

--rollback-order="" Orden de reversión ("start-first", "stop-first")

--rollback-parallelism=0 Número máximo de tareas a revertir simultáneamente (0 para revertir todas a la vez)

--secret-add= Añadir o actualizar un secreto en un servicio

--secret-rm= Eliminar un secreto

--stop-grace-period= Tiempo de espera antes de forzar la terminación de un contenedor (ns|us|ms|s|m|h)

--stop-signal="" Señal para detener el contenedor

--sysctl-add= Añadir o actualizar una opción Sysctl

--sysctl-rm= Eliminar una opción Sysctl

-t, --tty[=false] Asignar un pseudo-TTY

--ulimit-add=[] Añadir o actualizar una opción ulimit

--ulimit-rm= Eliminar una opción ulimit

--update-delay=0s Retraso entre actualizaciones (ns|us|ms|s|m|h)

--update-failure-action="" Acción en caso de fallo de actualización ("pause", "continue", "rollback")

--update-max-failure-ratio=0 Ratio de fallos a tolerar durante una actualización

--update-monitor=0s Duración después de cada actualización de tarea para monitorizar fallos (ns|us|ms|s|m|h)

--update-order="" Orden de actualización ("start-first", "stop-first")

--update-parallelism=0 Número máximo de tareas a actualizar simultáneamente (0 para actualizar todas a la vez)

-u, --user="" Nombre de usuario o UID (formato: [:])

--with-registry-auth[=false] Enviar detalles de autenticación del registro a los agentes del swarm

-w, --workdir="" Directorio de trabajo dentro del contenedor
