NOMBRE

docker-image-build - Construye una imagen desde un Dockerfile

SINOPSIS

docker image build [OPCIONES] RUTA | URL | -

DESCRIPCIÓN

Alias de docker build.

OPCIONES

--add-host= Añade un mapeo personalizado host-a-IP ("host:ip")

--build-arg= Establece variables en tiempo de compilación

--cache-from=[] Imágenes a considerar como fuentes de caché

--cgroup-parent="" Establece el cgroup padre para las instrucciones "RUN" durante la compilación

--compress[=false] Comprime el contexto de compilación usando gzip

--cpu-period=0 Límita el período del planificador CFS (Completely Fair Scheduler) de la CPU

--cpu-quota=0 Límita la cuota del planificador CFS de la CPU

-c, --cpu-shares=0 Shares de CPU (peso relativo)

--cpuset-cpus="" CPUs en las que permitir la ejecución (0-3, 0,1)

--cpuset-mems="" MEMs en las que permitir la ejecución (0-3, 0,1)

-f, --file="" Nombre del Dockerfile (Por defecto es "RUTA/Dockerfile")

--force-rm[=false] Elimina siempre los contenedores intermedios

--iidfile="" Escribe el ID de la imagen en el archivo

--isolation="" Tecnología de aislamiento de contenedores

--label= Establece metadatos para una imagen

-m, --memory=0 Límite de memoria

--memory-swap=0 Límite de swap igual a memoria más swap: -1 para habilitar swap ilimitada

--network="default" Establece el modo de red para las instrucciones RUN durante la compilación

--no-cache[=false] No usar caché al compilar la imagen

--platform="" Establece la plataforma si el servidor es capaz de manejar múltiples plataformas

--pull[=false] Intentar siempre descargar una versión más reciente de la imagen

-q, --quiet[=false] Suprime la salida de la compilación e imprime el ID de la imagen si tiene éxito

--rm[=true] Elimina los contenedores intermedios después de una compilación exitosa

--security-opt=[] Opciones de seguridad

--shm-size=0 Tamaño de "/dev/shm"

--squash[=false] Aplasta las capas recién creadas en una única capa nueva

-t, --tag= Nombre y opcionalmente una etiqueta en el formato "nombre:etiqueta"

--target="" Establece la etapa de compilación de destino a compilar.

--ulimit=[] Opciones de ulimit
