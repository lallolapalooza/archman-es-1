NOMBRE

docker-container-commit - Crea una nueva imagen a partir de los cambios de un contenedor

SINOPSIS

docker container commit [OPCIONES] CONTENEDOR [REPOSITORIO[:TAG]]

DESCRIPCIÓN

Crea una nueva imagen a partir de un contenedor existente especificado por nombre o ID de contenedor. La nueva imagen contendrá el contenido del sistema de archivos del contenedor, *excluyendo* cualquier volumen de datos. Consulte docker-tag(1) para obtener más información sobre nombres válidos de imágenes y etiquetas.

Aunque el comando docker commit es una forma conveniente de extender una imagen existente, se recomienda preferir el uso de un Dockerfile y docker build para generar imágenes que pretenda compartir con otras personas.

EJEMPLOS

Crear una nueva imagen a partir de un contenedor existente

A un contenedor existente basado en Fedora se le ha instalado Apache mientras se ejecutaba en modo interactivo con el shell bash. Apache también se está ejecutando. Para crear una nueva imagen, ejecute docker ps para encontrar el ID del contenedor y luego ejecute:

$ docker commit -m="Se añadió Apache a la imagen base de Fedora" \
  -a="Un Administrador" 98bd7fc99854 fedora/fedora_httpd:20

Tenga en cuenta que solo se permiten caracteres a-z, 0-9, -_. al nombrar imágenes a partir de un contenedor existente.

Aplicar instrucciones especificadas del Dockerfile al confirmar la imagen

Si un contenedor existente se creó sin la variable de entorno DEBUG establecida en "true", puede crear una nueva imagen basada en ese contenedor obteniendo primero el ID del contenedor con docker ps y luego ejecutando:

$ docker container commit -c="ENV DEBUG=true" 98bd7fc99854 debug-image

OPCIONES

-a, --author="" Autor (ej. "John Hannibal Smith hannibal@a-team.com ⟨mailto:hannibal@a-team.com⟩")

-c, --change= Aplicar instrucción de Dockerfile a la imagen creada

-m, --message="" Mensaje de confirmación

--no-pause[=false] Desactivar la pausa del contenedor durante la confirmación
