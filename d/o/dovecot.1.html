NOMBRE

dovecot - Servidor IMAP y POP3 seguro y altamente configurable

SINOPSIS

dovecot [-Fp] [-c archivo-config]

dovecot -a [-c archivo-config]

dovecot -n [-c archivo-config]

dovecot --build-options

dovecot --help

dovecot --hostdomain

dovecot --version

dovecot reload

dovecot stop

DESCRIPCIÓN

Dovecot es un servidor IMAP y POP3 de código abierto para sistemas Linux/Unix-like, escrito principalmente pensando en la seguridad. Dovecot es una excelente opción tanto para instalaciones pequeñas como grandes. Es rápido, fácil de configurar, no requiere administración especial y utiliza muy poca memoria.

OPCIONES

-a

Volcar toda la configuración a stdout y salir con éxito. Lo mismo que doveconf -a.

-c archivo-config

Iniciar dovecot con una configuración alternativa.

-F

Ejecutar dovecot en primer plano, no desvincularlo (daemonize).

-n

Volcar las configuraciones no predeterminadas a stdout y salir con éxito. Lo mismo que doveconf -n.

-p

Solicitar la contraseña de la clave ssl para el ssl_server_key configurado al iniciar.

--build-options

Mostrar las opciones de compilación de Dovecot y salir con éxito.

--help

Imprimir un mensaje de uso en stdout y salir con éxito.

--hostdomain

Muestra el nombre actual de host.domain del sistema. Si la búsqueda del dominio falla por alguna razón, solo se mostrará el nombre del host.

--version

Mostrar la versión de Dovecot y salir con éxito.

COMANDOS

reload

Forzar a dovecot a recargar su configuración.

stop

Apagar dovecot y todos sus procesos hijos.

Cuando shutdown_clients está configurado en no, las sesiones existentes continuarán usando la configuración anterior después de un dovecot reload. También todas las sesiones permanecerán activas después de un dovecot stop.

Por defecto, todas las sesiones activas se cerrarán.

SEÑALES

Dovecot maneja las siguientes señales como se describe:

HUP

Forzar a dovecot a recargar su configuración.

INT

Apagar dovecot y todos sus procesos hijos.

TERM

Apagar dovecot y todos sus procesos hijos.

USR1

Forzar a dovecot a reabrir todos los archivos de registro configurados (log_path, info_log_path y debug_log_path).

Las señales ALARM y PIPE son ignoradas.

ARCHIVOS

/etc/dovecot/dovecot.conf

Archivo de configuración principal de Dovecot.

/etc/dovecot/conf.d/.conf*

Archivos de configuración de diferentes servicios y ajustes.

REPORTE DE ERRORES

Reportar errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
