NOMBRE

doveadm-user - Realiza una búsqueda de usuario en las userdb de Dovecot

SINOPSIS

doveadm [OPCIONES GLOBALES] user [-a ruta_al_socket_userdb] [-f campo] [-u] [-x info_autenticacion] usuario...

DESCRIPCIÓN

El comando user se utiliza para realizar una búsqueda de usuario, para mostrar qué información ve Dovecot sobre el/los usuario(s), o si existe(n) en las userdb configuradas.

La info_autenticacion puede ser útil cuando la userdb es, por ejemplo, una base de datos SQL y estás usando %variables, como %{protocol} o %{local_ip}, en la configuración userdb_sql_query. O cuando has configurado la userdb de esta manera:

userdb passwd-file {
  passwd_file_path = /etc/%{protocol}.passwd
}

OPCIONES GLOBALES

doveadm(1) global.

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No lee ningún archivo de configuración, solo usa los predeterminados. La configuración dovecot_storage_version tiene como valor predeterminado la última versión, pero puede ser anulada con

-k

Preserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre_instancia

Si se utilizan varias instancias de Dovecot, elige el archivo de configuración según este nombre de instancia.

Consulta la configuración instance_name para obtener más información.

-c archivo_configuración

Lee la configuración del archivo_configuración especificado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuración=valor

Anula la configuración de configuración de /etc/dovecot/dovecot.conf y de la userdb con el valor especificado. Para anular varias configuraciones, la opción -o puede especificarse varias veces.

OPCIONES

-a ruta_al_socket_userdb

Esta opción se utiliza para especificar una ruta absoluta a un socket de dominio UNIX alternativo.

Por defecto, doveadm(1) utilizará el socket

-f campo

Cuando se especifica esta opción y el nombre de un campo de la userdb, doveadm(1) mostrará solo el valor del campo especificado.

-u

Cuando se especifica esta opción, doveadm(1) solo mostrará los valores de

-x info_autenticacion

info_autenticacion especifica condiciones adicionales para el comando user. La cadena de opciones info_autenticacion debe darse como un par nombre = valor. Para condiciones múltiples, la opción -x se puede proporcionar varias veces.

Los nombres posibles para info_autenticacion son:

service

El servicio para el que se debe probar la búsqueda de la userdb. El valor puede ser el nombre de un servicio, comúnmente utilizado con Dovecot. Por ejemplo: imap, pop3 o smtp.

session

Identificador de sesión.

lip

La dirección IP local (servidor) para la prueba.

rip

La dirección IP remota (cliente) para la prueba.

lport

El puerto local, p. ej., 143

rport

El puerto remoto, p. ej., 24567

real_lip

La IP local a la que se conectó el cliente en este host.

real_rip

La IP remota desde donde el cliente se conectó a este host.

real_lport

El puerto local al que el cliente se conectó a este host.

real_rport

El puerto remoto desde donde el cliente se conectó a este host.

forward_<campo>

Campo a reenviar como %{forward:campo} al proceso de autenticación.

ARGUMENTOS

usuario

Es el nombre de inicio de sesión de un usuario. Dependiendo de la configuración, un nombre de inicio de sesión puede ser, por ejemplo, jane o john@example.com. También es posible usar comodines '*' y '?' (p. ej., -u \*@example.org).

EJEMPLO

Realiza una búsqueda de usuario para los usuarios jane y john@example.com:

doveadm user jane john@example.com
userdb: jane
  uid       : 8001
  gid       : 8001
  home      : /home/jane
  mail_path : ~/sdbox
  plugins   : sieve
  quota_storage_size: 150M
userdb: john@example.com
  home      : /srv/mail/8/70312/79832
  uid       : 79832
  gid       : 70312
  mail_path : ~/mdbox

Búsqueda de usuario, usando comodines:

doveadm user \*.?oe@example.net
jane.doe@example.net
judy.roe@example.net
john.doe@example.net

INFORME DE ERRORES

Reporta errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
