NOMBRE

doveadm-fs - Interactuar con el sistema de archivos de almacenamiento de correo abstracto

SINOPSIS

doveadm [OPCIONES GLOBALES] fs comando nombre-filtro-config [ARGUMENTOS]

doveadm [OPCIONES GLOBALES] mail fs comando [OPCIONES] nombre-filtro-config [ARGUMENTOS]

DESCRIPCIÓN

Los comandos doveadm fs se utilizan para interactuar de forma abstracta con el controlador de almacenamiento definido en la configuración de Dovecot. Permite el acceso a la estructura del buzón de correo sin necesidad de conocer los detalles de cómo está diseñado el controlador de almacenamiento.

nombre-filtro-config

Nombre del filtro a utilizar al buscar la configuración de fs. Por ejemplo, mail_attachments, obox, metacache, fts/dovecot. También es posible usar un nombre de filtro vacío y especificar la configuración de fs usando el parámetro -o.

OPCIONES GLOBALES

Opciones globales de doveadm(1)

-D

Habilita la verbosidad y los mensajes de depuración.

-O

No leer ningún archivo de configuración, solo usar los valores predeterminados. El ajuste dovecot_storage_version se establece por defecto en la última versión, pero se puede anular con

-k

Preserva todo el entorno para doveadm, no solo el ajuste import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre-instancia

Si se utilizan varias instancias de Dovecot, elige el archivo de configuración basado en este nombre de instancia.

Ver el ajuste instance_name para más información.

-c archivo-config

Lee la configuración del archivo-config proporcionado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puedes apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o ajuste=valor

Anula el ajuste de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor proporcionado. Para anular varios ajustes, la opción -o se puede especificar varias veces.

-f formateador

Especifica el formateador para dar formato a la salida. Los formateadores compatibles son:

flow

imprime cada línea con pares clave=valor.

json

imprime una matriz JSON de objetos JSON.

pager

imprime cada par clave: valor en su propia línea y separa los registros con un carácter de avance de página (^L).

tab

imprime una cabecera de tabla seguida de líneas de valores separadas por tabulaciones.

table

imprime una cabecera de tabla seguida de líneas de valores ajustadas.

OPCIONES

-A

Si está presente la opción -A, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, porque también contiene usuarios con un UID inferior al configurado con el ajuste first_valid_uid.

Cuando se utiliza el módulo userdb SQL, asegúrate de que el ajuste userdb_sql_iterate_query coincida con el diseño de tu base de datos.

Al utilizar el módulo userdb LDAP, asegúrate de que los ajustes userdb_fields y userdb_ldap_iterate_fields coincidan con tu esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-u usuario/máscara

Ejecuta el comando solo para el usuario especificado. También es posible usar comodines '*' y '?' (por ejemplo, -u *@example.org).

-F archivo

Ejecuta el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo proporcionado. El archivo contiene un nombre de usuario por línea.

-S ruta-socket

El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (hostname:port), para conectar un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket proporcionado.

copy

doveadm [OPCIONES GLOBALES] mail fs copy [-A | -u usuario | -F archivo] [-S ruta-socket] nombre-filtro-config ruta-origen ruta-destino

Copia la ruta de origen a la ruta de destino.

delete

doveadm [OPCIONES GLOBALES] fs delete [-R] [-n contador] nombre-filtro-config ruta [ruta ...]

doveadm [OPCIONES GLOBALES] mail fs delete [-A | -u usuario | -F archivo] [-S ruta-socket] [-R] [-n contador] nombre-filtro-config ruta [ruta ...]

Elimina todos los datos asociados con la ruta proporcionada.

-R

Elimina archivos recursivamente.

-n contador

Número máximo de operaciones paralelas a realizar.

get

doveadm [OPCIONES GLOBALES] fs get nombre-filtro-config ruta

doveadm [OPCIONES GLOBALES] mail fs get [-A | -u usuario | -F archivo] [-S ruta-socket] nombre-filtro-config ruta

Recupera los datos asociados con la ruta proporcionada.

iter

doveadm [OPCIONES GLOBALES] fs iter nombre-filtro-config ruta

doveadm [OPCIONES GLOBALES] mail fs iter [-A | -u usuario | -F archivo] [-S ruta-socket] nombre-filtro-config ruta

Itera sobre todos los archivos de datos en la ruta proporcionada.

NAME

doveadm-fs - filesystem utility

SYNOPSIS

doveadm [GLOBAL OPTIONS] fs COMMAND [ARGS]

DESCRIPTION

This utility is part of the Dovecot mail server suite. It provides various file system related operations, especially for the filesystem mail storage format and for accessing mailboxes through various filesystem drivers.

The fs subcommand supports the following commands:

  get       Retrieve file contents.
  stat      Retrieve file status.

GLOBAL OPTIONS

The following options are available to all doveadm(1) commands:

-D
Enables debugging.
-o property=value
Overrides a configuration directive. Note that in most cases a configuration directive override is not possible here. For example, you can't override the mail driver setting.
-S socket_path
Connect to the given backend service service specified by socket path. This is typically used when multiple Dovecot instances are running. Default is to use the default service socket.
-s
Connect to the default service socket.
-v
Enables verbosity.

OPTIONS

The following options are specific to the fs command and its subcommands:

get

doveadm [GLOBAL OPTIONS] fs get [-h hash] [-m key=value] [-S socket_path] config-filter-name path

doveadm [GLOBAL OPTIONS] mail fs get [-A | -u user | -F file] [-S socket_path] config-filter-name path

Store data at the path provided.

-h hash

Save provided hash as content hash. Must be either MD5 or SHA256 in hexdigits.

-m key=value

Assign a value to a metadata. Can be provided as many times as needed. Requires either metawrap as driver or metadata capable FS-driver.

stat

doveadm [GLOBAL OPTIONS] fs stat config-filter-name path

doveadm [GLOBAL OPTIONS] mail fs stat [-A | -u user | -F file] [-S socket_path] config-filter-name path

Retrieve files status for the path provided. Currently, only the total size (in bytes) of the item is returned.

REPORTING BUGS

Report bugs, including doveconf -n output, to the Dovecot Mailing List ⟨dovecot@dovecot.org⟩. Information about reporting bugs is available at: https://dovecot.org/bugreport.html

EXAMPLE

How to decompress a file.

doveadm -o fs=compress,posix -o fs/compress/fs_driver=compress -o fs/posix/fs_driver=posix -o fs_posix_prefix=/tmp/ fs get "" test.gz

Using a named filter.

doveadm mail fs -u testuser get obox path/to/file
