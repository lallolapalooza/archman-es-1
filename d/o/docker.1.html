DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker - Interfaz de línea de comandos para imágenes y contenedores de Docker

SINOPSIS

docker [OPCIONES] COMANDO [ARG...]

docker [--help|-v|--version]

DESCRIPCIÓN

docker es un cliente para interactuar con el demonio (ver dockerd(8)) a través de la CLI.

La CLI de Docker tiene más de 30 comandos. Los comandos se enumeran a continuación y cada uno tiene su propia página del manual que explica su uso y argumentos.

Para ver la página del manual de un comando, ejecuta man docker .

OPCIONES

--help
Imprime la declaración de uso

--config=""
Especifica la ubicación de los archivos de configuración del cliente Docker. El valor predeterminado es '~/.docker'.

-D, --debug=true|false
Habilita el modo de depuración. El valor predeterminado es false.

-H, --host=[unix:///var/run/docker.sock]: tcp://[host]:[port][path] para enlazar o unix://[/path/to/socket] para usar.
El(los) socket(s) a enlazar en modo demonio especificado(s) usando uno o más
tcp://host:port/path, unix:///path/to/socket, fd://* o fd://socketfd.
Si no se especifica el puerto tcp, entonces por defecto será 2375 cuando
--tls esté desactivado, o 2376 cuando --tls esté activado, o se especifique --tlsverify.

-l, --log-level="debug|info|warn|error|fatal"
Establece el nivel de registro. El valor predeterminado es info.

--tls=true|false
Usa TLS; implícito por --tlsverify. El valor predeterminado es false.

--tlscacert=~/.docker/ca.pem
Confía solo en certificados firmados por esta CA.

--tlscert=~/.docker/cert.pem
Ruta al archivo del certificado TLS.

--tlskey=~/.docker/key.pem
Ruta al archivo de la clave TLS.

--tlsverify=true|false
Usa TLS y verifica el remoto (demonio: verifica cliente, cliente: verifica demonio).
El valor predeterminado es false.

-v, --version=true|false
Imprime la información de la versión y sale. El valor predeterminado es false.

COMANDOS

Usa "docker help" o "docker --help" para obtener una visión general de los comandos disponibles.

EJEMPLOS

Para ejemplos específicos del cliente, consulta la página del manual del comando Docker específico. Por ejemplo:

man docker-run
