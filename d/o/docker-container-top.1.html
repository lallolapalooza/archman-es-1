NOMBRE

docker-container-top - Muestra los procesos en ejecución de un contenedor

SINOPSIS

docker container top CONTENEDOR [OPCIONES_ps]

DESCRIPCIÓN

Muestra el proceso en ejecución del contenedor. OPCION_ps puede ser cualquiera de las opciones que pasaría a un comando ps de Linux.

Toda la información mostrada es desde el punto de vista del host.

EJEMPLOS

Ejecuta docker container top con la opción ps -x:

$ docker container top 8601afda2b -x
PID      TTY       STAT       TIME         COMMAND
16623    ?         Ss         0:00         sleep 99999
