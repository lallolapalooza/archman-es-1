Licencias: Apache-2.0

DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker-container-run - Crea y ejecuta un nuevo contenedor a partir de una imagen

SINOPSIS

docker container run [OPCIONES] IMAGEN [COMANDO] [ARG...]

DESCRIPCIÓN

Alias para docker run.

OPCIONES

--add-host= Añade un mapeo host-a-IP personalizado (host:ip)

--annotation=map[] Añade una anotación al contenedor (se pasa al tiempo de ejecución OCI)

-a, --attach= Se conecta a STDIN, STDOUT o STDERR

--blkio-weight=0 Peso relativo de E/S de bloque, entre 10 y 1000, o 0 para desactivar (por defecto 0)

--blkio-weight-device=[] Peso de E/S de bloque (peso relativo del dispositivo)

--cap-add= Añade capacidades de Linux

--cap-drop= Elimina capacidades de Linux

--cgroup-parent="" Grupo cgroup padre opcional para el contenedor

--cgroupns="" Espacio de nombres de cgroup a usar (host|private) 'host': Ejecuta el contenedor en el espacio de nombres de cgroup del host de Docker 'private': Ejecuta el contenedor en su propio espacio de nombres de cgroup privado '': Usa el espacio de nombres de cgroup configurado por la
opción default-cgroupns-mode en el demonio (por defecto)

--cidfile="" Escribe el ID del contenedor en el archivo

--cpu-count=0 Número de CPU (solo Windows)

--cpu-percent=0 Porcentaje de CPU (solo Windows)

--cpu-period=0 Limita el periodo CFS (Completely Fair Scheduler) de CPU

--cpu-quota=0 Limita la cuota CFS (Completely Fair Scheduler) de CPU

--cpu-rt-period=0 Limita el periodo de tiempo real de CPU en microsegundos

--cpu-rt-runtime=0 Limita el tiempo de ejecución de tiempo real de CPU en microsegundos

-c, --cpu-shares=0 Participaciones de CPU (peso relativo)

--cpus= Número de CPUs

--cpuset-cpus="" CPUs en las que permitir la ejecución (0-3, 0,1)

--cpuset-mems="" MEMs en las que permitir la ejecución (0-3, 0,1)

-d, --detach[=false] Ejecuta el contenedor en segundo plano e imprime el ID del contenedor

--detach-keys="" Anula la secuencia de teclas para desvincular un contenedor

--device= Añade un dispositivo del host al contenedor

--device-cgroup-rule= Añade una regla a la lista de dispositivos permitidos del cgroup

--device-read-bps=[] Limita la velocidad de lectura (bytes por segundo) de un dispositivo

--device-read-iops=[] Limita la velocidad de lectura (E/S por segundo) de un dispositivo

--device-write-bps=[] Limita la velocidad de escritura (bytes por segundo) a un dispositivo

--device-write-iops=[] Limita la velocidad de escritura (E/S por segundo) a un dispositivo

--dns= Establece servidores DNS personalizados

--dns-option= Establece opciones DNS

--dns-search= Establece dominios de búsqueda DNS personalizados

--domainname="" Nombre de dominio NIS del contenedor

--entrypoint="" Sobrescribe el ENTRYPOINT predeterminado de la imagen

-e, --env= Establece variables de entorno

--env-file= Leer un archivo de variables de entorno

--expose= Expone un puerto o un rango de puertos

--gpus= Dispositivos GPU a añadir al contenedor ('all' para pasar todas las GPUs)

--group-add= Añade grupos adicionales a los que unirse

--health-cmd="" Comando a ejecutar para comprobar el estado de salud

--health-interval=0s Tiempo entre la ejecución de la comprobación (ms|s|m|h) (por defecto 0s)

--health-retries=0 Fallos consecutivos necesarios para reportar que no está saludable

--health-start-interval=0s Tiempo entre la ejecución de la comprobación durante el periodo de inicio (ms|s|m|h) (por defecto 0s)

--health-start-period=0s Periodo de inicio para que el contenedor se inicialice antes de comenzar la cuenta atrás de health-retries (ms|s|m|h) (por defecto 0s)

--health-timeout=0s Tiempo máximo permitido para que se ejecute una comprobación (ms|s|m|h) (por defecto 0s)

--help[=false] Imprimir el uso

-h, --hostname="" Nombre de host del contenedor

--init[=false] Ejecutar un init dentro del contenedor que reenvía señales y recoge procesos

-i, --interactive[=false] Mantener STDIN abierto aunque no esté conectado

--io-maxbandwidth=0 Límite máximo de ancho de banda de E/S para el disco del sistema (solo Windows)

--io-maxiops=0 Límite máximo de IOps para el disco del sistema (solo Windows)

--ip= Dirección IPv4 (p. ej., 172.30.100.104)

--ip6= Dirección IPv6 (p. ej., 2001:db8::33)

--ipc="" Modo IPC a usar

--isolation="" Tecnología de aislamiento del contenedor

-l, --label= Establecer metadatos en un contenedor

--label-file= Leer un archivo delimitado por líneas de etiquetas

--link= Añadir enlace a otro contenedor

--link-local-ip= Direcciones link-local IPv4/IPv6 del contenedor

--log-driver="" Controlador de registro para el contenedor

--log-opt= Opciones del controlador de registro

--mac-address="" Dirección MAC del contenedor (p. ej., 92:d0:c6:0a:29:33)

-m, --memory=0 Límite de memoria

--memory-reservation=0 Límite suave de memoria

--memory-swap=0 Límite de swap igual a memoria más swap: '-1' para activar swap ilimitado

--memory-swappiness=-1 Ajustar la propensión al swap de la memoria del contenedor (0 a 100)

--mount= Adjuntar un montaje de sistema de archivos al contenedor

--name="" Asignar un nombre al contenedor

--network= Conectar un contenedor a una red

--network-alias= Añadir alias con ámbito de red para el contenedor

--no-healthcheck[=false] Desactivar cualquier HEALTHCHECK especificado por el contenedor

--oom-kill-disable[=false] Desactivar el OOM Killer

--oom-score-adj=0 Ajustar las preferencias OOM del host (-1000 a 1000)

--pid="" Espacio de nombres PID a usar

--pids-limit=0 Ajustar el límite de pids del contenedor (establecer -1 para ilimitado)

--platform="" Establecer la plataforma si el servidor es compatible con múltiples plataformas

--privileged[=false] Conceder privilegios extendidos a este contenedor

-p, --publish= Publicar el/los puerto(s) del contenedor al host

-P, --publish-all[=false] Publicar todos los puertos expuestos a puertos aleatorios

--pull="missing" Obtener la imagen antes de ejecutarla ("always", "missing", "never")

-q, --quiet[=false] Suprimir la salida de la obtención

--read-only[=false] Montar el sistema de archivos raíz del contenedor como de solo lectura

--restart="no" Política de reinicio a aplicar cuando un contenedor termina

--rm[=false] Eliminar automáticamente el contenedor y sus volúmenes anónimos asociados cuando termina

--runtime="" Tiempo de ejecución a usar para este contenedor

--security-opt= Opciones de seguridad

--shm-size=0 Tamaño de /dev/shm

--sig-proxy[=true] Proxificar las señales recibidas al proceso

--stop-signal="" Señal para detener el contenedor

--stop-timeout=0 Tiempo de espera (en segundos) para detener un contenedor

--storage-opt= Opciones del controlador de almacenamiento para el contenedor

--sysctl=map[] Opciones de sysctl

--tmpfs= Montar un directorio tmpfs

-t, --tty[=false] Asignar una pseudo-TTY

--ulimit=[] Opciones de ulimit

--use-api-socket[=false] Montar por enlace el socket de la API de Docker y la autenticación requerida

-u, --user="" Nombre de usuario o UID (formato: [:])

--userns="" Espacio de nombres de usuario a usar

--uts="" Espacio de nombres UTS a usar

-v, --volume= Montar por enlace un volumen

--volume-driver="" Controlador de volumen opcional para el contenedor

--volumes-from= Montar volúmenes del/los contenedor(es) especificado(s)

-w, --workdir="" Directorio de trabajo dentro del contenedor
