NOMBRE

doveadm-altmove - Mover correos coincidentes al almacenamiento alternativo (solo DBOX)

SINOPSIS

doveadm [OPCIONES GLOBALES] altmove [-r] [-S ruta_socket] -A consulta_búsqueda

doveadm [OPCIONES GLOBALES] altmove [-r] [-S ruta_socket] -F archivo consulta_búsqueda

doveadm [OPCIONES GLOBALES] altmove [-r] [-S ruta_socket] --no-userdb-lookup consulta_búsqueda

doveadm [OPCIONES GLOBALES] altmove [-r] [-S ruta_socket] -u usuario consulta_búsqueda

DESCRIPCIÓN

Este comando se puede utilizar con almacenamiento sdbox o mdbox para mover correos a una ruta de almacenamiento alternativa cuando se especifica mail_alt_path para la ubicación del correo.

En la primera forma, doveadm(1) ejecutará el

En la segunda forma, el comando se realizará para todos los usuarios listados en el archivo dado.

En la tercera forma, el comando se realizará para el usuario contenido en la variable de entorno USER.

En la última forma, solo los correos coincidentes del (los) usuario(s) dado(s) se moverán al almacenamiento alternativo.

OPCIONES GLOBALES

doveadm(1) global

-D

Habilita los mensajes de depuración y verbosidad.

-O

No lea ningún archivo de configuración, solo use los valores predeterminados. La configuración dovecot_storage_version se establece en la última versión por defecto, pero se puede anular con

-k

Conserva todo el entorno para doveadm, no solo la configuración import_environment.

-v

Habilita la verbosidad, incluido el contador de progreso.

-i nombre-instancia

Si se utilizan múltiples instancias de Dovecot, elija el archivo de configuración según este nombre de instancia.

Consulte la configuración instance_name para obtener más información.

-c archivo-config

Lea la configuración del archivo-config dado. Por defecto, primero lee el socket de configuración y luego recurre a /etc/dovecot/dovecot.conf. También puede apuntar esto al socket de configuración de alguna instancia que ejecute una versión compatible.

-o configuracion=valor

Anula la configuración de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular varias configuraciones, la opción -o se puede especificar varias veces.

OPCIONES

-A

Si está presente la opción -A, el comando se realizará para todos los usuarios. No se recomienda usar esta opción en combinación con usuarios del sistema de userdb { driver = passwd }, ya que también contiene usuarios con un UID inferior al configurado con la configuración first_valid_uid.

Cuando se utiliza el módulo userdb SQL, asegúrese de que la configuración userdb_sql_iterate_query coincida con el diseño de su base de datos.

Cuando se utiliza el módulo userdb LDAP, asegúrese de que la configuración userdb_fields y la configuración userdb_ldap_iterate_fields coincidan con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

-F archivo

Ejecute el comando para todos los usuarios del archivo. Esto es similar a la opción -A, pero en lugar de obtener la lista de usuarios de la base de datos de usuarios, se leen del archivo dado. El archivo contiene un nombre de usuario por línea.

--no-userdb-lookup

No realice la búsqueda en la base de datos de usuarios. Utilice la variable de entorno USER para especificar el nombre de usuario.

-r

Cuando se da la opción -r, este comando funciona de la manera opuesta. Los correos se moverán del almacenamiento alternativo de vuelta a la ubicación de correo predeterminada.

-S ruta_socket

El argumento de la opción es una ruta absoluta a un socket de dominio UNIX local, o un nombre de host y puerto (nombre-host:puerto), para conectar a un host remoto a través de un socket TCP.

Esto permite a un administrador ejecutar comandos de correo de doveadm(1) a través del socket dado.

-u usuario/máscara

Ejecute el comando solo para el usuario dado. También es posible usar los comodines '*' y '?' (por ejemplo, -u *@example.org).

ARGUMENTOS

consulta_búsqueda

Los mensajes que coincidan con esta consulta de búsqueda se moverán al almacenamiento alternativo. Consulte doveadm-search-query(7) para obtener más detalles.

ARCHIVOS

/etc/dovecot/conf.d/10-mail.conf

Ubicaciones de buzones y espacios de nombres.

EJEMPLO

Este ejemplo mueve los correos vistos con una antigüedad mayor a una semana al almacenamiento alternativo en /nfsmount:

mail_driver = mdbox
mail_path = ~/mdbox
mail_alt_path = /nfsmount/%{home}/mdbox
doveadm altmove -u johnd@example.com visto guardadobefore 1s<

REPORTE DE ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la lista de correo de Dovecot ⟨dovecot@dovecot.org⟩. La información sobre cómo reportar errores está disponible en: https://dovecot.org/bugreport.html
