NOMBRE

DO - ejecutar un bloque de código anónimo

SINOPSIS

DO [ LANGUAGE nombre_idioma ] codigo

DESCRIPCIÓN

DO ejecuta un bloque de código anónimo, o en otras palabras, una función anónima transitoria en un lenguaje procedural.

El bloque de código se trata como si fuera el cuerpo de una función sin parámetros, que devuelve void. Se analiza y ejecuta una sola vez.

La cláusula LANGUAGE opcional se puede escribir antes o después del bloque de código.

PARÁMETROS

codigo

El código del lenguaje procedural a ejecutar. Debe especificarse como un literal de cadena, al igual que en CREATE FUNCTION. Se recomienda el uso de un literal entre comillas de dólar.

nombre_idioma

El nombre del lenguaje procedural en el que está escrito el código. Si se omite, el valor predeterminado es plpgsql.

NOTAS

El lenguaje procedural a utilizar debe haber sido instalado previamente en la base de datos actual mediante CREATE EXTENSION. plpgsql se instala por defecto, pero otros lenguajes no.

El usuario debe tener el privilegio USAGE para el lenguaje procedural, o debe ser un superusuario si el lenguaje no es de confianza. Este es el mismo requisito de privilegio que para crear una función en el lenguaje.

Si DO se ejecuta en un bloque de transacción, el código del procedimiento no puede ejecutar sentencias de control de transacción. Las sentencias de control de transacción solo están permitidas si DO se ejecuta en su propia transacción.

EJEMPLOS

Otorgar todos los privilegios en todas las vistas del esquema public al rol webuser:

DO $$DECLARE r record;
BEGIN
    FOR r IN SELECT table_schema, table_name FROM information_schema.tables
             WHERE table_type = 'VIEW' AND table_schema = 'public'
    LOOP
        EXECUTE 'GRANT ALL ON ' || quote_ident(r.table_schema) || '.' || quote_ident(r.table_name) || ' TO webuser';
    END LOOP;
END$$;

COMPATIBILIDAD

No existe una sentencia DO en el estándar SQL.
