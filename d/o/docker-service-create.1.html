docker-service-create(1)

Paquete: docker

Licencias: Apache-2.0

DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker-service-create - Crea un nuevo servicio

SINOPSIS

docker service create [OPCIONES] IMAGEN [COMANDO] [ARG...]

DESCRIPCIÓN

Crea un nuevo servicio

OPCIONES

--cap-add= Añade capacidades de Linux

--cap-drop= Elimina capacidades de Linux

--config= Especifica las configuraciones a exponer al servicio

--constraint= Restricciones de colocación

--container-label= Etiquetas del contenedor

--credential-spec= Especificación de credenciales para la cuenta de servicio gestionada (solo Windows)

-d, --detach[=false] Sale inmediatamente en lugar de esperar a que el servicio converja

--dns= Establece servidores DNS personalizados

--dns-option= Establece opciones DNS

--dns-search= Establece dominios de búsqueda DNS personalizados

--endpoint-mode="vip" Modo de punto final (vip o dnsrr)

--entrypoint= Sobrescribe el ENTRYPOINT predeterminado de la imagen

-e, --env= Establece variables de entorno

--env-file= Lee un archivo de variables de entorno

--generic-resource= Recursos definidos por el usuario

--group= Establece uno o más grupos de usuarios suplementarios para el contenedor

--health-cmd="" Comando a ejecutar para comprobar el estado de salud

--health-interval= Tiempo entre la ejecución de la comprobación (ms|s|m|h)

--health-retries=0 Fallos consecutivos necesarios para reportar como no saludable

--health-start-interval= Tiempo entre la ejecución de la comprobación durante el período de inicio (ms|s|m|h)

--health-start-period= Período de inicio para que el contenedor se inicialice antes de contar los reintentos hacia inestable (ms|s|m|h)

--health-timeout= Tiempo máximo permitido para que una comprobación se ejecute (ms|s|m|h)

--host= Establece una o más asignaciones host-a-IP personalizadas (host:ip)

--hostname="" Hostname del contenedor

--init[=false] Usa un init dentro de cada contenedor de servicio para reenviar señales y recoger procesos

--isolation="" Modo de aislamiento del contenedor del servicio

-l, --label= Etiquetas del servicio

--limit-cpu= Limita las CPU

--limit-memory=0 Limita la memoria

--limit-pids=0 Limita el número máximo de procesos (por defecto 0 = ilimitado)

--log-driver="" Controlador de registro para el servicio

--log-opt= Opciones del controlador de registro

--max-concurrent= Número de tareas de trabajo a ejecutar concurrentemente (por defecto igual a --replicas)

--memory-swap=0 Bytes de intercambio (-1 para ilimitado)

--memory-swappiness=-1 Ajusta la propensión al intercambio de memoria (0-100), -1 para restablecer a predeterminado

--mode="replicated" Modo del servicio ("replicated", "global", "replicated-job", "global-job")

--mount= Adjunta un montaje de sistema de archivos al servicio

--name="" Nombre del servicio

--network= Adjuntos de red

--no-healthcheck[=false] Desactiva cualquier HEALTHCHECK especificado por el contenedor

--no-resolve-image[=false] No consulta el registro para resolver el resumen de la imagen y las plataformas soportadas

--oom-score-adj=0 Ajusta las preferencias OOM del host (-1000 a 1000)

--placement-pref= Añade una preferencia de colocación

-p, --publish= Publica un puerto como puerto de nodo

-q, --quiet[=false] Suprime la salida de progreso

--read-only[=false] Monta el sistema de archivos raíz del contenedor como solo lectura

--replicas= Número de tareas

--replicas-max-per-node=0 Número máximo de tareas por nodo (por defecto 0 = ilimitado)

--reserve-cpu= Reserva CPU

--reserve-memory=0 Reserva memoria

--restart-condition="" Reinicia cuando se cumple la condición ("none", "on-failure", "any") (por defecto "any")

--restart-delay= Retraso entre intentos de reinicio (ns|us|ms|s|m|h) (por defecto 5s)

--restart-max-attempts= Número máximo de reinicios antes de abandonar

--restart-window= Ventana utilizada para evaluar la política de reinicio (ns|us|ms|s|m|h)

--rollback-delay=0s Retraso entre reversiones de tareas (ns|us|ms|s|m|h) (por defecto 0s)

--rollback-failure-action="" Acción en caso de fallo de la reversión ("pause", "continue") (por defecto "pause")

--rollback-max-failure-ratio=0 Tasa de fallos a tolerar durante una reversión (por defecto 0)

--rollback-monitor=0s Duración después de cada reversión de tarea para monitorear fallos (ns|us|ms|s|m|h) (por defecto 5s)

--rollback-order="" Orden de reversión ("start-first", "stop-first") (por defecto "stop-first")

--rollback-parallelism=1 Número máximo de tareas revertidas simultáneamente (0 para revertir todas a la vez)

--secret= Especifica secretos a exponer al servicio

--stop-grace-period= Tiempo de espera antes de forzar el cierre de un contenedor (ns|us|ms|s|m|h) (por defecto 10s)

--stop-signal="" Señal para detener el contenedor

--sysctl= Opciones sysctl

-t, --tty[=false] Asigna un pseudo-TTY

--ulimit=[] Opciones ulimit

--update-delay=0s Retraso entre actualizaciones (ns|us|ms|s|m|h) (por defecto 0s)

--update-failure-action="" Acción en caso de fallo de la actualización ("pause", "continue", "rollback") (por defecto "pause")

--update-max-failure-ratio=0 Tasa de fallos a tolerar durante una actualización (por defecto 0)

--update-monitor=0s Duración después de cada actualización de tarea para monitorear fallos (ns|us|ms|s|m|h) (por defecto 5s)

--update-order="" Orden de actualización ("start-first", "stop-first") (por defecto "stop-first")

--update-parallelism=1 Número máximo de tareas actualizadas simultáneamente (0 para actualizar todas a la vez)

-u, --user="" Nombre de usuario o UID (formato: [:])

--with-registry-auth[=false] Envía los detalles de autenticación del registro a los agentes de swarm

-w, --workdir="" Directorio de trabajo dentro del contenedor
