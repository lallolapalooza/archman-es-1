DOAS.CONF(5) Manual de formatos de archivo DOAS.CONF(5)

NOMBRE

doas.conf — archivo de configuración de doas

DESCRIPCIÓN

La utilidad doas(1) ejecuta comandos como otros usuarios de acuerdo con las reglas del archivo de configuración doas.conf.

Las reglas tienen el siguiente formato:

permitir|denegar [opciones] identidad [como destino] [cmd comando [args ...]]

Las reglas consisten en las siguientes partes:

permitir|denegar
La acción que se tomará si esta regla coincide.
opciones
Las opciones son:
nopass
No se requiere que el usuario introduzca una contraseña.
nolog
No registrar la ejecución exitosa de comandos en syslogd(8).
persist
Después de que el usuario se autentique correctamente, no se le volverá a pedir la contraseña durante algún tiempo.
keepenv
Las variables de entorno distintas de las enumeradas en doas(1) se conservan al crear el entorno para el nuevo proceso.
setenv { [variable ...] [variable=valor ...] }
Conservar o establecer las variables especificadas separadas por espacios. Las variables también se pueden eliminar con un ‘-’ al principio o establecerse utilizando la sintaxis posterior. Si el primer carácter de valor es un ‘$’, entonces el valor que se establecerá se tomará de la variable de entorno existente del nombre indicado. Esta opción se procesa después de que se haya creado el entorno predeterminado.
identidad
El nombre de usuario a que coincidir. Los grupos se pueden especificar precediendo con dos puntos (‘:’). También se aceptan identificadores numéricos.
como destino
El usuario de destino para el cual el usuario en ejecución puede ejecutar el comando. El valor predeterminado es todos los usuarios.
cmd comando
El comando que el usuario tiene permitido o denegado ejecutar. El valor predeterminado son todos los comandos. Tenga en cuenta que es mejor especificar rutas absolutas. Si se especifica una ruta relativa, solo se buscará en una PATH restringida.
args [argumento ...]
Argumentos para el comando. Los argumentos del comando proporcionados por el usuario deben coincidir con los especificados. La palabra clave args sola significa que el comando debe ejecutarse sin ningún argumento.

La última regla coincidente determina la acción tomada. Si ninguna regla coincide, la acción se deniega.

Los comentarios se pueden colocar en cualquier lugar del archivo utilizando una almohadilla (‘#’) y se extienden hasta el final de la línea actual.

Se aplican las siguientes reglas de cita:

  • El texto entre un par de comillas dobles (‘"’) se toma tal cual.
  • El carácter de barra invertida (‘\’) escapa al siguiente carácter, incluidos los caracteres de nueva línea, fuera de los comentarios; como resultado, los comentarios no se pueden extender a través de múltiples líneas.
  • Si se utilizan comillas o barras invertidas en una palabra, no se considera una palabra clave.

ARCHIVOS

/etc/doas.conf
Archivo de configuración de doas(1).
/etc/examples/doas.conf
Archivo de configuración de ejemplo.

EJEMPLOS

El siguiente ejemplo permite al usuario aja instalar paquetes desde un espejo preferido; al grupo wheel ejecutar comandos como cualquier usuario conservando las variables de entorno PS1 y SSH_AUTH_SOCK y desactivando ENV; permite a tedu ejecutar procmap como root sin contraseña; y además permite a root ejecutar comandos sin restricciones como sí mismo conservando el PATH original.

permitir persistir setenv { PKG_CACHE PKG_PATH } aja cmd pkg_add
permitir setenv { -ENV PS1=$DOAS_PS1 SSH_AUTH_SOCK } :wheel
permitir nopass tedu como root cmd /usr/sbin/procmap
permitir nopass keepenv setenv { PATH } root como root

VER TAMBIÉN

doas(1), syslogd(8)
