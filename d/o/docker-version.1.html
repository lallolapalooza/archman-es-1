DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker-version - Muestra la información de la versión de Docker

SINOPSIS

docker version [OPCIONES]

DESCRIPCIÓN

El comando version imprime el número de versión actual de todos los componentes de Docker versionados de forma independiente.

EJEMPLOS

Mostrar información de la versión de Docker

La salida predeterminada representa toda la información de la versión dividida en dos secciones; la sección "Cliente" contiene información sobre la CLI de Docker y los componentes del cliente, y la sección "Servidor" contiene información sobre el Motor de Docker y los componentes utilizados por el Motor, como los Runtimes OCI "Containerd" y "Runc".

La información que se muestra puede variar según cómo hayas instalado Docker y qué componentes se estén utilizando. El siguiente ejemplo muestra la salida en una máquina macOS que ejecuta Docker Desktop:

$ docker version
Cliente: Docker Engine - Community
 Versión:           28.5.1
 Versión API:       1.51
 Versión Go:        go1.24.8
 Commit Git:       e180ab8
 Compilado:     Miércoles 8 de octubre de 2025 12:16:17
 OS/Arch:           darwin/arm64
 Contexto:          desktop-linux
Servidor: Docker Desktop 4.49.0 (12345)
 Motor:
  Versión:          28.5.1
  Versión API:      1.51 (versión mínima 1.24)
  Versión Go:       go1.24.8
  Commit Git:       f8215cc
  Compilado:     Miércoles 8 de octubre de 2025 12:18:25
  OS/Arch:          linux/arm64
  Experimental:     false
 containerd:
  Versión:          1.7.27
  Commit Git:       05044ec0a9a75232cad458027ca83437aae3f4da
 runc:
  Versión:          1.2.5
  Commit Git:       v1.2.5-0-g59923ef
 docker-init:
  Versión:          0.19.0
  Commit Git:       de40ad0

Obtener la versión del servidor:

$ docker version --format '{{.Server.Version}}'
28.5.1

Volcar datos sin procesar:

Para ver todos los campos disponibles, puedes usar el formato {{json .}}.

$ docker version --format '{{json .}}'
{"Cliente":"Versión":"28.5.1","ApiVersion":"1.51", ...}

OPCIONES

-f, --format="" Formatea la salida usando una plantilla personalizada: 'json': Imprime en formato JSON 'PLANTILLA': Imprime la salida usando la plantilla Go dada. Consulta https://docs.docker.com/go/formatting/ para obtener más información sobre cómo formatear la salida con plantillas
