DESCRIPCIÓ

N

El comando kick de doveadm se utiliza para desconectar usuarios por user_mask y/o la dirección IP desde la que están

conectados.

En la primera forma, se desconectarán todos los usuarios cuyo nombre de inicio de sesión coincida con el argumento use

r_mask.

En la segunda forma, se desconectarán todos los usuarios conectados desde la dirección IP o el rango de red

indicado.

En la tercera forma, solo se desconectarán los usuarios conectados desde la dirección IP o el rango de red indicado y cuyo nombre de inicio de sesión

coincida.

En la última forma, se desconecta

n todas las conexiones de proxy h
acia el host de destino indicado.
