DESCRIPCIÓ

N

Este comando se puede utilizar para eliminar los correos que coincidan con la consulta de búsqueda dada. Normalmente se usa para eliminar correos antiguos de las bandejas Papelera y/o Correo no deseado de los usuarios. Para probar con qué mensajes coincidiría una consulta de búsqueda dada, puede usar los comandos doveadm fetch o doveadm se

arch.

En la primera forma, el comando se realizará para todos los

usuarios.

En la segunda forma, doveadm(1) eliminará los mensajes de los usuarios listados en el

archivo

En la tercera forma, el comando se realizará para el usuario contenido en la variable de entorno USER

.

En la forma final, solo se eliminarán los correos que coincidan del usuario (u

suarios
) dado.
