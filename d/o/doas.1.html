DOAS(1) Manual de Comandos Generales DOAS(1)

NOMBRE

doas — ejecutar comandos como otro usuario

SINOPSIS

doas [-Lns] [-C config] [-u usuario] comando [argumentos]

DESCRIPCIÓN

La utilidad doas ejecuta el comando dado como otro usuario. El argumento comando es obligatorio a menos que se especifique -C, -L, o -s.

Se le pedirá al usuario que se autentique ingresando su contraseña, a menos que se configure lo contrario.

Por defecto, se crea un nuevo entorno. Las variables HOME, LOGNAME, PATH, SHELL, y USER y la umask(2) se establecen a valores apropiados para el usuario de destino. DOAS_USER se establece al nombre del usuario que ejecuta doas. Las variables DISPLAY y TERM se heredan del entorno actual. Este comportamiento puede ser modificado por el archivo de configuración. El directorio de trabajo no se cambia.

Las opciones son las siguientes:

-C config
Analiza y verifica el archivo de configuración config, luego sale. Si se proporciona comando, doas también realizará la coincidencia de comandos. En este último caso, se imprimirá 'permit', 'permit nopass' o 'deny' en la salida estándar, dependiendo de los resultados de la coincidencia de comandos. No se ejecuta ningún comando.
-L
Borra cualquier autenticación persistente de invocaciones anteriores y luego sale inmediatamente. No se ejecuta ningún comando.
-n
Modo no interactivo, falla si la regla coincidente no tiene la opción nopass.
-s
Ejecuta el shell de SHELL o /etc/passwd.
-u usuario
Ejecuta el comando como usuario. El valor predeterminado es root.

ESTADO DE SALIDA

La utilidad doas sale con código 0 en caso de éxito y >0 si ocurre un error. Puede fallar por una de las siguientes razones:

  • No se pudo analizar el archivo de configuración /etc/doas.conf.
  • El usuario intentó ejecutar un comando que no está permitido.
  • La contraseña era incorrecta.
  • El comando especificado no se encontró o no es ejecutable.

VER TAMBIÉN

su(1), doas.conf(5)

HISTORIA

El comando doas apareció por primera vez en OpenBSD 5.8.
