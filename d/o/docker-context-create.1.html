NOMBRE

docker-context-create - Crea un contexto

SINOPSIS

docker context create [OPCIONES] CONTEXTO

DESCRIPCIÓN

Crea un contexto

Configuración del endpoint de Docker:

NOMBRE DESCRIPCIÓN desde Copia la configuración del endpoint de Docker del contexto con nombre host Endpoint de Docker en el que conectarse ca Certificados de confianza firmados solo por esta CA ruta al archivo de certificado TLS key Ruta al archivo de clave TLS skip-tls-verify Omitir la validación del certificado TLS

Ejemplo:

$ docker context create mi-contexto --description "alguna descripción" --docker "host=tcp://myserver:2376,ca=~/ca-file,cert=~/cert-file,key=~/key-file"

OPCIONES

--description="" Descripción del contexto

--docker=[] establece el endpoint de docker

--from="" crea el contexto a partir de un contexto con nombre

VER TAMBIÉN
