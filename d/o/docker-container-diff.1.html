NOMBRE

docker-container-diff - Inspeccionar cambios en archivos o directorios en el sistema de archivos de un contenedor

SINOPSIS

docker container diff CONTENEDOR

DESCRIPCIÓN

Lista los archivos y directorios modificados en el sistema de archivos de un contenedor desde que se creó el contenedor. Se rastrean tres tipos diferentes de cambios:

Símbolo Descripción
A Se añadió un archivo o directorio
D Se eliminó un archivo o directorio
C Se modificó un archivo o directorio

Puedes usar el ID del contenedor completo o acortado, o el nombre del contenedor establecido con la opción docker run --name.

EJEMPLOS

Inspeccionar los cambios en un contenedor nginx:

$ docker diff 1fdfd1f54c1b
C /dev
C /dev/console
C /dev/core
C /dev/stdout
C /dev/fd
C /dev/ptmx
C /dev/stderr
C /dev/stdin
C /run
A /run/nginx.pid
C /var/lib/nginx/tmp
A /var/lib/nginx/tmp/client_body
A /var/lib/nginx/tmp/fastcgi
A /var/lib/nginx/tmp/proxy
A /var/lib/nginx/tmp/scgi
A /var/lib/nginx/tmp/uwsgi
C /var/log/nginx
A /var/log/nginx/access.log
A /var/log/nginx/error.log
