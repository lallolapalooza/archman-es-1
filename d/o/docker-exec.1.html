NOMBRE

docker-exec - Ejecuta un comando en un contenedor en ejecución

SINOPSIS

docker exec [OPCIONES] CONTENEDOR COMANDO [ARG...]

DESCRIPCIÓN

Alias de docker container exec.

OPCIONES

-d, --detach[=false] Modo separado: ejecuta el comando en segundo plano

--detach-keys="" Anula la secuencia de teclas para separar un contenedor

-e, --env= Establece variables de entorno

--env-file= Lee un archivo de variables de entorno

-i, --interactive[=false] Mantiene abierto STDIN incluso si no está adjunto

--privileged[=false] Otorga privilegios extendidos al comando

-t, --tty[=false] Asigna un pseudo-TTY

-u, --user="" Nombre de usuario o UID (formato: ":")

-w, --workdir="" Directorio de trabajo dentro del contenedor
