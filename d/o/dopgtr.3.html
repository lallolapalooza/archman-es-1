DOPGTR

Propósito:

!>
!> DOPGTR genera una matriz ortogonal real Q que se define como el
!> producto de n-1 reflectores elementales H(i) de orden n, tal como devuelve
!> DSPTRD usando almacenamiento empaquetado:
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': Almacenamiento empaquetado triangular superior utilizado en
!>                 la llamada anterior a DSPTRD;
!>          = 'L': Almacenamiento empaquetado triangular inferior utilizado en
!>                 la llamada anterior a DSPTRD.
!>

N

!>          N es INTEGER
!>          El orden de la matriz Q. N >= 0.
!>

AP

!>          AP es un array de DOBLE PRECISIÓN, dimensión (N*(N+1)/2)
!>          Los vectores que definen los reflectores elementales, tal como
!>          devuelve DSPTRD.
!>

TAU

!>          TAU es un array de DOBLE PRECISIÓN, dimensión (N-1)
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i), tal como devuelve DSPTRD.
!>

Q

!>          Q es un array de DOBLE PRECISIÓN, dimensión (LDQ,N)
!>          La matriz ortogonal N-por-N Q.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N).
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (N-1)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
