NOMBRE

docker-logout - Cerrar sesión en un registro

SINOPSIS

docker logout [SERVER]

DESCRIPCIÓN

Cierra la sesión en un Registro de Docker ubicado en el SERVER especificado. Puede especificar una URL o un nombre de host para el valor de SERVER. Si no especifica un SERVER, el comando intenta cerrar la sesión en el registro público de Docker ubicado en https://registry-1.docker.io/ por defecto.

EJEMPLOS

Cerrar sesión en un registro en su localhost

# docker logout localhost:8080

Ver también

docker-login(1) para iniciar sesión en un registro.
