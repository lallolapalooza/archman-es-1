NOMBRE

docker-container-pause - Pausa todos los procesos dentro de uno o más contenedores

SINOPSIS

docker container pause CONTENEDOR [CONTENEDOR...]

DESCRIPCIÓN

El comando docker container pause suspende todos los procesos en los contenedores especificados. En Linux, esto utiliza el cgroup freezer. Tradicionalmente, al suspender un proceso se utiliza la señal SIGSTOP, que es observable por el proceso que se suspende. Con el cgroup freezer, el proceso no es consciente de que está siendo suspendido y, por lo tanto, no puede capturarlo, ni tampoco puede capturar su reanudación. En Windows, solo los contenedores Hyper-V pueden ser pausados.

Consulte la documentación del cgroup freezer ⟨https://www.kernel.org/doc/Documentation/cgroup-v1/freezer-subsystem.txt⟩> para más detalles.

Utilice docker-container-unpause(1) para reanudar todos los procesos dentro de un contenedor.
