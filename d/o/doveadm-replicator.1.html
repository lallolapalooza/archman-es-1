NOMBRE

doveadm-replicator - Gestionar la replicación de correo de los usuarios

SINOPSIS

doveadm [-Dv] [-f formateador] replicator comando [OPCIONES] [ARGUMENTOS]

DESCRIPCIÓN

Los COMANDOS de doveadm replicator se pueden usar para gestionar la replicación automatizada de correo de los usuarios.

OPCIONES

Opciones globales de doveadm(1):

-D
Habilita la verbosidad y los mensajes de depuración.
-f formateador
Especifica el formateador para dar formato a la salida. Los formateadores soportados son:
flujo
imprime cada línea con pares de clave=valor.
paginador
imprime cada par clave: valor en su propia línea y separa los registros con un carácter de avance de página (^L).
tab
imprime una cabecera de tabla seguida de líneas de valores separados por tabulaciones.
tabla
imprime una cabecera de tabla seguida de líneas de valores ajustados.
-o configuración=valor
Anula la configuración de configuración de /etc/dovecot/dovecot.conf y de la base de datos de usuarios con el valor dado. Para anular múltiples configuraciones, la opción -o se puede especificar varias veces.
-v
Habilita la verbosidad, incluyendo el contador de progreso.

Este comando utiliza por defecto el formateador de salida flujo (sin el prefijo clave=).

Opciones específicas del comando:

-a ruta_socket_replicador
Esta opción se utiliza para especificar una ruta absoluta a un socket de dominio UNIX alternativo.

Por defecto doveadm(1) utilizará el socket /run/dovecot/replicator-doveadm. El socket puede estar ubicado en otro directorio, cuando la configuración base_dir predeterminada se anuló en /etc/dovecot/dovecot.conf.

ARGUMENTOS

mascara_usuario
Especifica para qué usuarios se debe ejecutar el comando. En la mayoría de los casos querrá usar patrones que contengan comodines, por ejemplo, \*@example.net para todos los usuarios del dominio example.net, o simplemente \* para todos los usuarios.

Cuando se utiliza el módulo userdb SQL, asegúrese de que la configuración iterate_query en /etc/dovecot/dovecot-sql.conf.ext coincida con la estructura de su base de datos. Al utilizar el módulo userdb LDAP, asegúrese de que la configuración iterate_attrs y iterate_filter en /etc/dovecot/dovecot-ldap.conf.ext coincida con su esquema LDAP. De lo contrario, doveadm(1) no podrá iterar sobre todos los usuarios.

COMANDOS

replicator agregar

doveadm replicator agregar [-a ruta_socket_replicador] mascara_usuario

Agrega los usuarios especificados al replicador. Si la mascara_usuario contiene comodines "?" o "*", la lista de nombres de usuario se busca en la userdb.

replicator estado-dsync

doveadm replicator estado-dsync [-a ruta_socket_replicador]

Muestra el estado de los procesos dsync en ejecución.

replicator quitar

doveadm replicator quitar [-a ruta_socket_replicador] nombre_usuario

Elimina al usuario especificado del replicador.

replicator replicar

doveadm replicator replicar [-a ruta_socket_replicador] [-f] [-p prioridad] mascara_usuario

Inicia la replicación para los usuarios especificados ahora. Si se proporciona el parámetro -f, se realiza una replicación completa para el usuario. También puede especificar la prioridad, que puede ser alta o baja. Si la máscara de usuario contiene comodines "?" o "*", la lista de nombres de usuario se busca en los usuarios que existen actualmente en el replicador (no en la userdb).

replicator estado

doveadm replicator estado [-a ruta_socket_replicador] mascara_usuario

Muestra el estado de replicación de los usuarios.

REPORTAR ERRORES

Reporte errores, incluyendo la salida de doveconf -n, a la Lista de Correo de Dovecot <dovecot@dovecot.org>. La información sobre cómo reportar errores está disponible en: http://dovecot.org/bugreport.html
