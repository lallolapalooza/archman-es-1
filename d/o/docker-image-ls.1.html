DESCRIPCIÓ

N

Este comando lista las imágenes almacenadas en el repositorio local de

Docker.

Por defecto, las imágenes intermedias, utilizadas durante las compilaciones, no se listan. Parte de la salida, por ejemplo, el ID de la imagen, se trunca por razones de espacio. Sin embargo, el ID de imagen truncado, y a menudo los primeros caracteres, son suficientes para ser utilizados en otros comandos de Docker que usan el ID de la imagen. La salida incluye el repositorio, la etiqueta, el ID de la imagen, la fecha de creación y el tamaño

virtual.

El título REPOSITORIO para el primer título puede parecer confuso. Es esencialmente el nombre de la imagen. Sin embargo, debido a que puedes etiquetar una imagen es

pecífica, y múltiples etiquetas (instancias de imagen) pueden estar asociadas a un solo nombre, el nombre es en realidad un repositorio para todas las imágenes eti
quetadas del mismo nombre. Por ejemplo, considera una imagen llamada ubuntu. Puede estar etiquetada con 24.04 o 22.04, etc. para gestionar diferentes versiones.

Listando las

imágenes

Para listar las imágenes en un repositorio local (no el registro)

ejecuta: 
docker image
ls

La lista contendrá el nombre del repositorio de la imagen, una etiqueta para la imagen, y un ID de imagen, cuándo se creó y su tamaño virtual. Columnas: REPOSITORIO, ETIQUETA, ID DE IMAGEN, CREADO y

TAMAÑO.

El comando docker image ls acepta un argumento [REPOSITORIO[:ETIQUETA]] opcional que restringe la lista a imágenes que coincidan con el argumento. Si especificas REPOSITORIO pero no ETIQUETA, el comando docker image ls lista todas las imágenes en el repositorio

dado. 
docker image ls
java

El valor [REPOSITORIO[:ETIQUETA]] debe ser una "coincidencia exacta". Esto significa que, por ejemplo, docker image ls jav no coincide con la imagen java

.

Si se proporcionan tanto REPOSITORIO como ETIQUETA, solo se listan las imágenes que coincidan con ese repositorio y etiqueta. Para encontrar todas las imágenes locales en el repositorio "java" con la etiqueta "8" puedes

usar: 
docker image ls java:
8

Para obtener una lista detallada de imágenes que contiene todas las imágenes intermedias utilizadas en las compilaciones usa -a

: 
docker image ls
-a

Anteriormente, el comando docker image ls soportaba los argumentos --tree y --dot, que mostraban diferentes visualizaciones de los datos de las imágenes. El núcleo de Docker eliminó esta funcionalidad en la versión 1.7. Si te gustaba esta funcionalidad, todavía puedes encontrarla en la herramienta de terceros dockviz: https://github.com/justone/dockvi

Listando imágenes en un formato

deseado

Al usar la opción --format, el comando de imagen emitirá los datos exactamente como declara la plantilla o, al usar la directiva table, incluirá también los encabezados de columna. Puedes usar caracteres especiales como \t para insertar espaciado de tabulación entre columnas. La directiva json emite objetos en formato

JSON.

El siguiente ejemplo usa una plantilla sin encabezados y emite las entradas ID y Repositorio separadas por dos puntos para todas las

imágenes:
