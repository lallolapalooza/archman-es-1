NOMBRE

docker-login - Autenticar a un registro

SINOPSIS

docker login [OPCIONES] [SERVIDOR]

DESCRIPCIÓN

Inicia sesión en un Registro de Docker ubicado en el SERVIDOR especificado. Puede especificar una URL o un nombre de host para el valor de SERVIDOR. Si no especifica un SERVIDOR, el comando usa el registro público de Docker ubicado en https://registry-1.docker.io/ por defecto. Para obtener un nombre de usuario/contraseña para el registro público de Docker, cree una cuenta en Docker Hub.

docker login requiere que el usuario use sudo o sea root, excepto cuando:

1.
se conecta a un demonio remoto, como un motor docker aprovisionado por docker-machine.
2.
el usuario se añade al grupo docker. Esto afectará la seguridad de su sistema; el grupo docker es equivalente a root. Consulte la superficie de ataque del demonio Docker ⟨https://docs.docker.com/engine/security/#docker-daemon-attack-surface⟩ para obtener detalles.

Puede iniciar sesión en cualquier repositorio público o privado para el cual tenga credenciales. Cuando inicia sesión, el comando almacena credenciales codificadas en $HOME/.docker/config.json en Linux o %USERPROFILE%/.docker/config.json en Windows.

EJEMPLOS

Iniciar sesión en un registro en su localhost

# docker login localhost:8080

Ver también

docker-logout(1) para cerrar sesión en un registro.

OPCIONES

-p, --password="" Contraseña o Token de Acceso Personal (PAT)

--password-stdin[=false] Tomar la Contraseña o Token de Acceso Personal (PAT) de stdin

-u, --username="" Nombre de usuario
