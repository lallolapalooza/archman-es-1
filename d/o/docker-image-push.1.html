DOCKER(1) Manuales de usuario de Docker DOCKER(1)

NOMBRE

docker-image-push - Sube una imagen a un registro

SINOPSIS

docker image push [OPCIONES] NOMBRE[:TAG]

DESCRIPCIÓN

Usa docker image push para compartir tus imágenes al registro Docker Hub ⟨https://hub.docker.com⟩ o a uno autoalojado.

Consulta docker-image-tag(1) para más información sobre nombres válidos de imágenes y etiquetas.

Matar el proceso docker image push, por ejemplo, presionando CTRL-c mientras se ejecuta en una terminal, termina la operación de subida.

Las credenciales del registro se gestionan mediante docker-login(1).

EJEMPLOS

Subir una nueva imagen a un registro

Primero guarda la nueva imagen encontrando el ID del contenedor (usando docker container ls) y luego haz commit a un nuevo nombre de imagen. Ten en cuenta que solo se permiten a-z0-9-_ en los nombres de imágenes:

# docker container commit c16378f943fe rhel-httpd

Ahora, sube la imagen al registro usando el ID de la imagen. En este ejemplo el registro está en un host llamado registry-host y escuchando en el puerto 5000. Para hacer esto, etiqueta la imagen con el nombre o la dirección IP del host, y el puerto del registro:

# docker image tag rhel-httpd registry-host:5000/myadmin/rhel-httpd:latest
# docker image push registry-host:5000/myadmin/rhel-httpd:latest

Comprueba que esto funcionó ejecutando:

# docker image ls

Deberías ver tanto rhel-httpd como registry-host:5000/myadmin/rhel-httpd listados.

Subir todas las etiquetas de una imagen

Usa la opción -a (o --all-tags) para subir todas las etiquetas de una imagen local.

El siguiente ejemplo crea múltiples etiquetas para una imagen y sube todas esas etiquetas a Docker Hub.

$ docker image tag myimage registry-host:5000/myname/myimage:latest
$ docker image tag myimage registry-host:5000/myname/myimage:v1.0.1
$ docker image tag myimage registry-host:5000/myname/myimage:v1.0
$ docker image tag myimage registry-host:5000/myname/myimage:v1

La imagen ahora está etiquetada bajo múltiples nombres:

$ docker image ls
REPOSITORY                          TAG        IMAGE ID       CREATED      SIZE
myimage                             latest     6d5fcfe5ff17   2 hours ago  1.22MB
registry-host:5000/myname/myimage   latest     6d5fcfe5ff17   2 hours ago  1.22MB
registry-host:5000/myname/myimage   v1         6d5fcfe5ff17   2 hours ago  1.22MB
registry-host:5000/myname/myimage   v1.0       6d5fcfe5ff17   2 hours ago  1.22MB
registry-host:5000/myname/myimage   v1.0.1     6d5fcfe5ff17   2 hours ago  1.22MB

Al subir con la opción --all-tags, se suben todas las etiquetas de la imagen registry-host:5000/myname/myimage:

$ docker image push --all-tags registry-host:5000/myname/myimage

OPCIONES

-a, --all-tags[=false] Sube todas las etiquetas de una imagen al repositorio

--platform="" Sube un manifiesto específico de plataforma como una imagen de plataforma única al registro. El índice de imágenes no se subirá, lo que significa que otros manifiestos, incluidas las atribuciones, no se conservarán. 'os[/arch[/variant]]': Plataforma explícita (ej. linux/amd64)

-q, --quiet[=false] Suprime la salida detallada
