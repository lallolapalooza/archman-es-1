detect(3)

Paquete: libchardet

Licencias: MPL

detect(3) Manual de funciones de biblioteca detect(3)

NOMBRE

detect, detect_r - Detectar el conjunto de caracteres y medir la precisión del conjunto de caracteres

SINOPSIS

#include <chardet.h>

short detect (char * inbuf, DetectObj ** outbuf);

short detect_r (char * inbuf, size_t inlen, DetectObj ** outbuf);

DESCRIPCIÓN

Almacena el conjunto de caracteres y la precisión de inbuf en outbuf.

La API detect está obsoleta porque no es compatible con binarios. Úsela o reemplácela con la API detect_r.

Argumentos:

inbuf

Cadena de entrada para la detección
inlen

Longitud de la cadena de entrada para la detección
outbuf

Almacena información de inbuf. La estructura de outbuf es la siguiente. 
typedef struct DetectObject {
	char * encoding;
	float confidence;
} DetectObj;

La variable outbuf debe inicializarse con la API detect_obj_init antes de llamar a esta API de detección.

VALOR DE RETORNO

Devuelve el estado según el caso.

CHARDET_SUCCESS

Detección exitosa
CHARDET_NO_RESULT

Fallo en la detección
CHARDET_NULL_OBJECT

No se inicializó outbuf con chardet_obj_init
CHARDET_OUT_OF_MEMORY

Ocurrió un error de fuera de memoria en una API interna

EJEMPLO

#include <chardet.h>
int main (void) {
	DetectObj *obj;
	char * checkstr = "안녕하세요";
	if ( (obj = detect_obj_init ()) == NULL ) {
		fprintf (stderr, "Fallo de asignación de memoria\n");
		return CHARDET_MEM_ALLOCATED_FAIL;
	}
	//switch (detect (checkstr, &obj))
	switch (detect_r (checkstr, strlen (checkstr), &obj))
	{
		case CHARDET_OUT_OF_MEMORY :
			fprintf (stderr, "Al procesar, ocurrió un error de falta de memoria\n");
			detect_obj_free (&obj);
			return CHARDET_OUT_OF_MEMORY;
		case CHARDET_NULL_OBJECT :
			fprintf (stderr,
					"El 2do argumento de chardet() debe ser asignado con memoria "
					"con la API detect_obj_init\n");
			return CHARDET_NULL_OBJECT;
	}
	# comprueba si el objeto admite BOM con la constante CHARDET_BOM_CHECK
	printf ("codificación: %s, confianza: %f, existe bom: %d\n", obj->encoding, obj->confidence, obj->bom);
	detect_obj_free (&obj);
    return 0;
}
