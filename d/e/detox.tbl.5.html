NOMBRE

detox.tbl — tabla de traducción para detox(1)

DESCRIPCIÓN GENERAL

detox permite la configuración de cómo operan los filtros seguros, ISO-8859-1 y UTF-8 (Unicode). A través de tablas de traducción basadas en texto, es posible ajustar cómo se interpretan estos conjuntos de caracteres.

SINTAXIS

El formato de las tablas de traducción es simple. Hay dos niveles: uno que contiene metadatos y otro que contiene las traducciones reales.

default _
Default especifica la traducción por defecto para un carácter. Un valor por defecto vacío o inexistente indica que cualquier carácter desconocido debería pasar al siguiente filtro. De esta manera, es posible encadenar múltiples tablas de traducción en una secuencia.
start
Indica el inicio de una lista de valores dentro de la tabla de traducción.
start lang
Indica el inicio de una lista de valores específicos del idioma dentro de la tabla de traducción.
end
Indica el final de una lista de valores dentro de la tabla de traducción.
traducción de valor
El valor puede especificarse en decimal (1), hexadecimal (0x01) u octal (01). Las mismas reglas que se aplican a sscanf se aplican aquí.

La traducción puede ser una cadena o una cadena entrecomillada, con comillas simples o dobles.

EJEMPLOS

El siguiente ejemplo muestra una parte de una tabla safe, con solo algunos reemplazos de caracteres especificados.

#
# Este es un ejemplo simple de una tabla "safe". Solo traduce 4 caracteres.
#
# El valor por defecto está comentado, por lo que cualquier carácter que no
# esté en esta tabla será ignorado.
#

# default   _

#
# Este es el bloque de reemplazo principal. Cada línea especifica un carácter y una
# cadena con la que reemplazarlo.
#

start
0x09	_tab_		# los comentarios funcionan en líneas, también
0x24	_dollar_	# $$$
0x26	_and_		# ampersand
end

#
# Inicia un bloque de traducción opcional, específico del idioma. detox leerá
# tu locale y cargará el bloque si la palabra después de start coincide con la
# parte del idioma de tu locale.
#
# En el ejemplo aquí, el carácter $ será reemplazado por "_money_" si el
# usuario está trabajando en inglés. Si el usuario está usando un idioma diferente,
# $ será reemplazado por el valor configurado en el bloque anterior, "_dollar_".
#

start en
0x24	_money_		# money money
end

# EOF

Podrías entonces habilitar esta tabla en tu ~/.detoxrc, junto con otros filtros.

# Ejemplo de detoxrc

sequence default {
	safe {
		filename "/home/MI NOMBRE DE USUARIO/.local/share/detox/safe.tbl";
	};
	safe;
	wipeup;
};

# EOF

Cuando se ejecute detox, ejecutará primero el filtro seguro personalizado, luego ejecutará el filtro safe por defecto y, finalmente, el filtro wipeup. Consulta detoxrc(5) para más detalles sobre los diversos tipos de filtros.
