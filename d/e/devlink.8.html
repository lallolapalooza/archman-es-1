NOMBRE

devlink - Herramienta Devlink

SINOPSIS


devlink [ OPCIONES ] { dev|port|monitor|sb|resource|region|health|trap } { COMANDO | help }

devlink [ -force ] -batch archivo

OPCIONES

-V, --Version
Imprime la versión de la utilidad devlink y sale.
-b, -batch <ARCHIVO>
Lee comandos del archivo proporcionado o de la entrada estándar e invócalos. El primer fallo provocará la terminación de devlink.
-force
No termine devlink ante errores en modo batch. Si hubo algún error durante la ejecución de los comandos, el código de retorno de la aplicación será distinto de cero.
-n, --no-nice-names
Desactiva la impresión de nombres amigables, por ejemplo, nombres de dispositivo de red en lugar de la identificación del puerto devlink.
-j, --json
Genera salida JSON.
-p, --pretty
Cuando se combina con -j, genera una salida JSON formateada.
-v, --verbose
Activa la salida detallada.
-s, --statistics
Muestra estadísticas.
-N, -Netns <NOMBRE_NETNS>
Cambia al espacio de nombres de red especificado.
-i, --iec
Imprime tasas legibles por humanos en unidades IEC (por ejemplo, 1Ki = 1024).
-x, --hex
Imprime números de volcado en formato hexadecimal.

OBJETO

dev
- dispositivo devlink.
port
- puerto devlink.
monitor
- observar mensajes netlink.
sb
- configuración de buffer compartido devlink.
resource
- configuración de recurso del dispositivo devlink.
region
- acceso a región de dirección devlink
health
- reporte y recuperación devlink
trap
- configuración de trampa devlink

COMANDO

Especifica la acción a realizar sobre el objeto. El conjunto de acciones posibles depende del tipo de objeto. Por regla general, es posible mostrar (o listar) objetos, pero algunos objetos no permiten todas estas operaciones o tienen comandos adicionales. El comando help está disponible para todos los objetos. Imprime una lista de comandos disponibles y las convenciones de sintaxis de los argumentos.

Si no se proporciona ningún comando, se asume un comando predeterminado. Normalmente es list o, si los objetos de esta clase no se pueden listar, help.

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso o un entero positivo en caso de fallo.

VER TAMBIÉN

devlink-dev(8), devlink-port(8), devlink-monitor(8), devlink-sb(8), devlink-resource(8), devlink-region(8), devlink-health(8), devlink-trap(8),

REPORTE DE ERRORES

Reporte cualquier error a la lista de correo de desarrolladores de red <netdev@vger.kernel.org> donde se realiza principalmente el desarrollo y mantenimiento. No es necesario estar suscrito a la lista para enviar un mensaje.
