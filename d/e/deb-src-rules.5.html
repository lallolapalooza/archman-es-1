NOMBRE

deb-src-rules - Archivo de reglas del paquete fuente de Debian

SINOPSIS

debian/rules

DESCRIPCIÓN

Este archivo contiene las instrucciones necesarias para construir los paquetes binarios a partir del paquete fuente.

El archivo debian/rules es un Makefile ejecutable, con un shebang que normalmente se establece en "#!/usr/bin/make -f".

Debe admitir los siguientes objetivos de make:

clean
Limpia el árbol de fuentes, deshaciendo cualquier cambio realizado por cualquiera de los objetivos de compilación y binarios. Este objetivo se llamará con privilegios de root.
build-indep
Construye archivos independientes de la arquitectura necesarios para construir cualquier paquete binario independiente de la arquitectura. Si no hay paquetes binarios independientes de la arquitectura que generar, el objetivo aún debe existir pero no hacer nada. Este objetivo no debe requerir privilegios de root.
build-arch
Construye archivos dependientes de la arquitectura necesarios para construir cualquier paquete binario dependiente de la arquitectura. Si no hay paquetes binarios dependientes de la arquitectura que generar, el objetivo aún debe existir pero no hacer nada. Este objetivo no debe requerir privilegios de root.
build
Construye archivos independientes y dependientes de la arquitectura, ya sea dependiendo (al menos transitivamente) de build-indep y/o build-arch o integrando lo que esos objetivos harían. Este objetivo no debe requerir privilegios de root.
binary-indep
Construye paquetes binarios independientes de la arquitectura. Este objetivo debe depender (al menos transitivamente) de build-indep o build. Este objetivo se llamará con privilegios de root.
binary-arch
Construye paquetes binarios dependientes de la arquitectura. Este objetivo debe depender (al menos transitivamente) de build-arch o build. Este objetivo se llamará con privilegios de root.
binary
Construye paquetes binarios independientes y dependientes de la arquitectura, ya sea dependiendo (al menos transitivamente) de binary-indep y/o binary-arch o integrando lo que esos objetivos harían. Este objetivo se llamará con privilegios de root.
