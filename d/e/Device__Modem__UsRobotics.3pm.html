NOMBRE

Device::Modem::UsRobotics - Extensiones de módem USR para controlar el modo automático

SINOPSIS

use Device::Modem::UsRobotics;
my $modem = Device::Modem::UsRobotics->new( port => '/dev/ttyS1' );
$modem->connect( baudrate => 9600 );
my %info = $modem->messages_info();
print "Hay $info{unreleased_voice_msg} mensajes de voz no leídos de $info{stored_voice_msg} en total\n";
print "Hay $info{unreleased_fax_msg} mensajes de fax no leídos de $info{stored_fax_msg} en total\n";
# Obtener detalles del mensaje n. X
my %msg = $modem->message_info(1);
      index type information attributes status day hour minute
      callerid addresshigh addresslow checksum
print 'Este es un mensaje de ', ($msg{type} == 2 ? 'voz' : 'fax'), "\n";
print 'Vino del no. ', $msg{callerid}, "\n";
# ...
# Ahora borra todos los mensajes
$modem->clear_memory();

ADVERTENCIA

Este módulo aún no está documentado y está en pleno desarrollo. Hasta ahora, lee correctamente la información de mensajes de voz/fax, pero al guardar mensajes de voz en disco, a veces se decodifican incorrectamente.

Por lo tanto, si necesita un programa que funcione, eche un vistazo al buen y viejo TkUsr de Ludovic Drolez, a menos que quiera ayudar a desarrollar Device::Modem::UsRobotics.

MÉTODOS

clear_memory()

Se utiliza para borrar permanentemente el espacio de memoria del módem. Hay espacios de memoria separados, uno para mensajes de voz/fax y otro para la configuración del usuario. Ejemplos:

    $modem->clear_memory('user');     # o $modem->clear_memory(1)
$modem->clear_memory('messages'); # o $modem->clear_memory(2)

Para borrar ambos, puedes usar:

$modem->clear_memory('all');      # o $modem->clear_memory(0);

Parámetros:

$memtype
Cadena o entero que selecciona el tipo de memoria a borrar, donde 0 es para "all" (todo), 1 es para memoria de "user" (usuario), 2 es para memoria de "messages" (mensajes).
