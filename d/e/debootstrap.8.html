EJEMPLO

S

Para configurar un sistema stretch [[147]]m:


debootstrap stretch ./stretch-chroot http://deb.debian.org/debian


debootstrap stretch ./stretch-chroot file:///LOCAL_MIRROR/debian

Proceso completo para crear una instalación completa de Debian de sid (inestable) en un chroot:


main # debootstrap sid sid-root http://deb.debian.org/debian/
[ ... observe cómo descarga todo el sistema ]
main # echo "proc sid-root/proc proc defaults 0 0" >> /etc/fstab
main # mount proc sid-root/proc -t proc
main # echo "sysfs sid-root/sys sysfs defaults 0 0" >> /etc/fstab
main # mount sysfs sid-root/sys -t sysfs
main # cp /etc/hosts sid-root/etc/hosts
main # chroot sid-root /bin/bash
