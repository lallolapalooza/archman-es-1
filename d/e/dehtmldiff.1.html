NOMBRE

dehtmldiff - obtener un diff utilizable de una página HTML

SINOPSIS

dehtmldiff [archivo...]

dehtmldiff {[--ayuda] | [--version]}

DESCRIPCIÓN

dehtmldiff crea archivos diff utilizables a partir de páginas HTML. Esto es útil en el escenario donde un parche se ha publicado en una lista de correo visible a través de una página web.

El diff corregido se envía a la salida estándar. Tenga en cuenta que probablemente necesitará usar la opción -l al aplicar el parche, para ignorar las diferencias de espacios en blanco que puedan existir.

OPCIONES

--ayuda

Muestra un breve mensaje de uso.

--version

Muestra el número de versión de dehtmldiff.

LIMITACIONES

La forma en que funciona este comando es bastante primitiva; se reduce a algunos reemplazos simples de texto, seguidos de una pasada de unwrapdiff. Como resultado, todas las limitaciones que se aplican a unwrapdiff también se aplican a dehtmldiff.
