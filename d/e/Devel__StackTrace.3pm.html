frames
p">Cuando se llama a este método sin argumentos, devuelve una lista de
    objetos Devel::StackTrace::Frame. Se devuelven en orden desde arriba (más
    reciente) hasta abajo.


Este método también se puede usar para establecer los frames del objeto si se
    le pasa una lista de objetos Devel::StackTrace::Frame.


Esto es útil si desea filtrar la lista de frames de formas
    más complejas de las que puede manejar el
    "$trace->filter_frames" método:


$stacktrace->frames( my_filter( $stacktrace->frames ) );






$trace->frame($index)


Dado un índice, este método devuelve el frame correspondiente, o undef
    si no hay ningún frame en ese índice. El índice es exactamente como en un array de Perl.
    El primer frame es 0 y se permiten índices negativos.






$trace->frame_count


Devuelve el número de frames en el objeto de traza.






$trace->as_string(\%p)


Llama "$frame->as_string" en
    cada frame de arriba a abajo, produciendo una salida bastante similar a la de los métodos
    cluck/confess del módulo Carp.


El parámetro opcional "\%p" solo tiene una opción. El "max_arg_length"
    parámetro trunca la representación de cadena de cada argumento de subrutina si es
    más larga que este número de caracteres.


Si todos los frames en una traza se omiten, esto simplemente devuelve el "message" pasado al constructor o
    la cadena "Trace begun".






$trace->message


Devuelve el mensaje pasado al constructor. Si no se pasó
    entonces este método devuelve
  "undef".
