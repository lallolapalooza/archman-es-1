NOMBRE

Devel::PatchPerl::Plugin - Se explican los plugins de Devel::PatchPerl

VERSIÓN

versión 2.14

DESCRIPCIÓN

Este documento explica el sistema de plugins de Devel::PatchPerl.

Los plugins son un mecanismo para proporcionar funcionalidad adicional a Devel::PatchPerl.

Los plugins se buscan en el espacio de nombres Devel::PatchPerl::Plugin.

INICIALIZACIÓN

El constructor del plugin es "patchperl".

Un plugin se especifica usando la variable de entorno "PERL5_PATCHPERL_PLUGIN". Puede especificarse de forma completa (es decir, "Devel::PatchPerl::Plugin::Feegle") o como la parte corta (es decir, "Feegle").

$ export PERL5_PATCHPERL_PLUGIN=Devel::PatchPerl::Plugin::Feegle
$ export PERL5_PATCHPERL_PLUGIN=Feegle

Cuando Devel::PatchPerl haya identificado el parche de la fuente de Perl y haya realizado su parcheo, intentará cargar el plugin identificado. Luego llamará al método de clase "patchperl" para el paquete del plugin, con los siguientes parámetros:

'version', la versión de Perl del árbol fuente;
'source', la ruta absoluta al árbol fuente de Perl;
'patchexe', la utilidad 'patch' que se puede usar;

Los plugins se llaman con el directorio de trabajo actual siendo la raíz del árbol fuente de Perl, es decir, "source".

En resumen:

$ENV{PERL5_PATCHPERL_PLUGIN} = 'Devel::PatchPerl::Plugin::Feegle';
my $plugin = $ENV{PERL5_PATCHPERL_PLUGIN};
eval "require $plugin";
eval {
  $plugin->patchperl( version => $vers, source => $srcdir, patchexe => $patch );
};

Los plugins son responsables de verificar que sus parches se aplican a la versión de perl que se está parcheando.

¿QUÉ PUEDEN HACER LOS PLUGINS?

Cualquier cosa que desees a un árbol fuente de Perl.

¿POR QUÉ USAR UNA VARIABLE DE ENTORNO PARA ESPECIFICAR PLUGINS?

Para que la indicación de un plugin a utilizar pueda especificarse independientemente del mecanismo que esté llamando a Devel::PatchPerl para realizar su tarea.

Piensa en perlbrew.
