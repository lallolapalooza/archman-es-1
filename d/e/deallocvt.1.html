NOMBRE

deallocvt - libera consolas virtuales no utilizadas

SINOPSIS

deallocvt [opción...] [N ...]

DESCRIPCIÓN

El comando deallocvt libera la memoria del kernel y las estructuras de datos para todas las consolas virtuales no utilizadas. Si se proporcionan uno o más argumentos N ..., solo se liberan las consolas correspondientes /dev/ttyN.

Una consola virtual no se utiliza si no es la consola en primer plano, y ningún proceso la tiene abierta para lectura o escritura, y no se ha seleccionado ningún texto en su pantalla.

OPCIONES

-C, --console=DEV
el dispositivo de consola a utilizar.
-V, --version
imprime el número de versión.
-h, --help
imprime este mensaje de uso.
