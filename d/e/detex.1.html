DETEX(1) Manual de Comandos Generales DETEX(1)

NOMBRE

detex - un filtro para eliminar comandos de TeX de un archivo .tex.

SINOPSIS

detex [ -clnstw ] [ -e lista-de-entornos ] [ nombre-archivo[.tex] ... ]

DESCRIPCIÓN

Detex lee cada archivo en secuencia, elimina todos los comentarios y secuencias de control de TeX y escribe el resto en la salida estándar. Se elimina todo el texto en modo matemático y modo de visualización. Por defecto, detex sigue los comandos \input. Si un archivo no puede ser abierto, se imprime un mensaje de advertencia y el comando se ignora. Si se usa la opción -n, no se procesarán los comandos \input o \include. Esto permite procesar archivos individuales. Si no se proporciona un archivo de entrada en la línea de comandos, detex lee desde la entrada estándar.

Si la secuencia mágica ``\begin{document}'' aparece en el texto, detex asume que está tratando con código fuente de LaTeX y detex reconoce construcciones adicionales utilizadas en LaTeX. Estas incluyen los comandos \include y \includeonly. La opción -l se puede usar para forzar el modo LaTeX y la opción -t se puede usar para forzar el modo TeX independientemente del contenido de la entrada.

Se ignora el texto en varios modos de entorno de LaTeX. Los modos por defecto son array, eqnarray, equation, longtable, picture, tabular y verbatim. La opción -e se puede usar para especificar una lista de entornos separada por comas, lista-de-entornos, para ignorar. La lista reemplaza los valores por defecto, por lo que especificar una lista vacía efectivamente hace que no se ignore ningún entorno.

La opción -c se puede usar en modo LaTeX para que detex imprima los argumentos de las macros \cite, \ref y \pageref. Esto puede ser útil cuando se envía la salida a un verificador de estilo.

Detex asume que se están utilizando las clases de caracteres estándar para TeX. Detex permite espacios en blanco entre secuencias de control y caracteres mágicos como `{` al reconocer cosas como entornos de LaTeX.

La opción -r intenta reemplazar ingenuamente $..$, $$..$$, \(..\) y \[..\] con sustantivos y verbos (en particular, "sustantivo" y "verbos") de una manera que mantiene las oraciones legibles.

Si se proporciona la bandera -w, la salida es una lista de palabras, una `palabra' (cadena de dos o más letras y apóstrofes que comienzan con una letra) por línea, y todos los demás caracteres se ignoran. Sin -w la salida sigue el original, con las eliminaciones mencionadas anteriormente. Los caracteres de nueva línea se conservan siempre que sea posible para que las líneas de salida coincidan lo más cerca posible con la entrada.

La opción -1 antepondrá a cada línea impresa `nombre-archivo:número-de-línea:` indicando de dónde proviene esa línea en términos del documento (La)TeX original.

La variable de entorno TEXINPUTS se utiliza para encontrar archivos \input y \include. Al igual que TeX, interpreta un `:` inicial o final como el valor predeterminado de TEXINPUTS. No admite la secuencia mágica de expansión de directorio `//'.

Detex ahora maneja las ligaduras básicas de TeX como un caso especial, reemplazando las ligaduras con sustitutos de caracteres aceptables. Esto elimina los errores ortográficos introducidos al simplemente eliminarlos. Las ligaduras son \aa, \ae, \oe, \ss, \o, \l (y sus equivalentes en mayúsculas). Los caracteres especiales "sin punto" \i y \j también se reemplazan por i y j respectivamente.

Tenga en cuenta que las versiones anteriores de detex reemplazaban las secuencias de control con un carácter de espacio para evitar que las palabras se unieran. Sin embargo, esto causaba que los acentos en medio de las palabras rompieran las palabras, generando "errores ortográficos" que no eran deseables. Por lo tanto, la nueva versión simplemente elimina estos acentos. La funcionalidad anterior se puede duplicar esencialmente usando la opción -s.

VER TAMBIÉN

tex(1)

DIAGNÓSTICOS

Se permite la anidación de \input pero el número de archivos abiertos no debe exceder el límite del sistema en el número de archivos abiertos simultáneamente. Detex ignora los caracteres de opción no reconocidos después de imprimir un mensaje de advertencia.

AUTOR

Originalmente escrito por Daniel Trinkle, Departamento de Ciencias de la Computación, Universidad de Purdue.

Mantenido por Piotr Kubowicz https://github.com/pkubowicz/opendetex.

ERRORES

Detex no es un intérprete de TeX (esencialmente lee la entrada con un programa (f)lex), por lo que se confunde fácilmente con algunas construcciones. La mayoría de los errores resultan en una salida excesiva en lugar de insuficiente.

Ejecutar código fuente de LaTeX sin un ``\begin{document}'' a través de detex puede producir errores.

Se animan (ligeramente) las sugerencias de mejoras.
