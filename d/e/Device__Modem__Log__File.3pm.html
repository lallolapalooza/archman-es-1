Device::Modem::Log::File(3) Documentación Perl contribuida por el usuario Device::Modem::Log::File(3)

NOMBRE

Device::Modem::Log::File - Plugin de registro de archivos de texto para la clase Device::Modem

SINOPSIS

use Device::Modem;
my $box = Device::Modem->new( log => 'file', ... );
my $box = Device::Modem->new( log => 'file,name=/tmp/mymodem.log', ... );
...

DESCRIPCIÓN

Esto está pensado como una clase de registro de ejemplo para ser conectada a "Device::Modem" para proporcionar el mecanismo de registro favorito de uno. Solo tienes que implementar tus propios métodos new(), write() y close().

El archivo de texto predeterminado es "/tmp/modem.log". En plataformas Windows, esto va a "%TEMP%/modem.log" o "%TMP%/modem.log", lo que esté definido. Por defecto, si la carpeta del archivo de registro no existe, se crea.

Esta clase es cargada automáticamente por la clase "Device::Modem" cuando se instancia un objeto, y es el mecanismo de registro predeterminado para la clase "Device::Modem".

Normalmente, no deberías necesitar usar esta clase directamente, ya que existen muchísimos otros módulos que registran mejor que este.

Además, debería considerarse si reemplazar "Device::Modem::Log::File" y sus compañeros con esas mejores clases en un futuro algo distante.
