detect_handledata(3)

Paquete: libchardet

Licencias: MPL

detect_handledata(3) Manual de funciones de biblioteca detect_handledata(3)

NOMBRE

detect_handledata, detect_handledata_r - Detectar el conjunto de caracteres y medir la precisión del conjunto de caracteres

SINOPSIS

#include <chardet.h>

short chardet_handledata (Detect ** handle, const char * inbuf, DetectObj ** outbuf);

short chardet_handledata_r (Detect ** handle, const char * inbuf, size_t inlen, DetectObj ** outbuf);

DESCRIPCIÓN

Almacena el conjunto de caracteres y la precisión de inbuf en outbuf

La API detect_handledata está obsoleta porque esta API no es binariamente segura. Utilice o reemplace por la API detect_handledata_r.

Argumentos:

handle

Recurso de manejador Detect asignado por la API detect_init.
inbuf

Cadena de entrada para la detección.
inlen

Longitud de la cadena de entrada para la detección.
outbuf

Almacena información de inbuf. La estructura de outbuf es la siguiente. 
typedef struct DetectObject {
	char * encoding;
	float confidence;
} DetectObj;

La variable outbuf debe inicializarse con la API detect_obj_init antes de llamar a esta API de detección.

VALORES DE RETORNO

Devuelve las siguientes condiciones según el caso.

CHARDET_SUCCESS

Detección exitosa.
CHARDET_NO_RESULT

Fallo en la detección.
CHARDET_NULL_OBJECT

No se inicializó outbuf con chardet_obj_init.
CHARDET_OUT_OF_MEMORY

Se produjo un error de memoria insuficiente en la API interna.

EJEMPLO

#include <chardet.h>
int main (void) {
	Detect    * d;
	DetectObj * obj;
	int i, arrayNum;
	char *str[] = {
		"this is ascii",
		"이건 euc-kr 입니다."
	};
	arrayNum = sizeof (str) / sizeof (str[0]);
	if ( (d = detect_init ()) == NULL ) {
		fprintf (stderr, "chardet handle initialize failed\n");
		return CHARDET_MEM_ALLOCATED_FAIL;
	}
	for ( i=0; i<arrayNum; i++ ) {
		detect_reset (&d);
		if ( (obj = detect_obj_init ()) == NULL ) {
			fprintf (stderr, "Memory Allocation failed\n");
			return CHARDET_MEM_ALLOCATED_FAIL;
		}
		//switch (detect_handledata (&d, str[i], &obj))
		switch (detect_handledata (&d, str[i], strlen(str[i]), &obj))
		{
			case CHARDET_OUT_OF_MEMORY :
				fprintf (stderr, "On handle processing, occured out of memory\n");
				detect_obj_free (&obj);
				return CHARDET_OUT_OF_MEMORY;
			case CHARDET_NULL_OBJECT :
				fprintf (stderr,
						"2st argument of chardet() is must memory allocation "
						"with detect_obj_init API\n");
				return CHARDET_NULL_OBJECT;
		}
		# check support obj->bom with CHARDET_BOM_CHECK constant
		printf ("encoding: %s, confidence: %f, exists bom: %d\n", obj->encoding, obj->confidence, obj->bom);
		detect_obj_free (&obj);
	}
	detect_destroy (&d);
    return 0;
}
