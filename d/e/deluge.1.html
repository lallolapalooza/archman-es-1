DELUGE(1) Manual de comandos generales DELUGE(1)

NOMBRE

deluge - Un cliente BitTorrent

SINOPSIS

deluge [opciones] [archivo-torrent]

DESCRIPCIÓN

Deluge utiliza un modelo cliente/servidor, con deluged siendo el proceso demonio y deluge utilizándose para lanzar una interfaz de usuario.

Por defecto, Deluge se ejecutará en modo Standalone donde la funcionalidad del demonio estará oculta. Puede cambiar al modo Thinclient en el diálogo de Preferencias.

OPCIONES

Opciones de configuración

-c ruta, --config=ruta
Establece la ubicación del directorio de configuración.

Opciones de UI

Vea deluge -h para las interfaces de usuario disponibles.

interfaz_de_usuario [argumentos_ui] Interfaz alternativa a lanzar, con argumentos_ui opcionales
-s ui_predeterminada, --set-default-ui=ui_predeterminada
Establece la UI predeterminada a ejecutar cuando no se especifica ninguna UI.

Opciones de registro

-l archivo, --logfile=archivo
Salida al archivo de registro especificado en lugar de stdout
-L nivel_de_registro, --loglevel=nivel_de_registro
Establece el nivel de registro (el predeterminado es error): none, info, warning, error, debug
-q, --quiet
Establece el nivel de registro en none, igual que -L none
--logrotate[=tamaño-máx]
Habilita la rotación del archivo de registro, con un tamaño máximo opcional, predeterminado: 2M (El número de rotaciones de archivos de registro es 5)
--profile[=archivo]
Perfilado con cProfile. Salida a stdout a menos que se especifique un nombre de archivo.

Opciones de ayuda

-V, --version
Muestra el número de versión del programa y sale.
-h, --help
Muestra el mensaje de ayuda y sale.
