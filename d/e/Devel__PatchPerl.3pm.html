Devel::PatchPerl(3) Documentación de Perl contribuida por el usuario Devel::PatchPerl(3)

NOMBRE

Devel::PatchPerl - Parchear código fuente de perl a la manera de buildperl.pl de Devel::PPPort

VERSIÓN

versión 2.14

SINOPSIS

use strict;
use warnings;
use Devel::PatchPerl;
Devel::PatchPerl->patch_source( '5.6.1', '/ruta/al/directorio/descomprimido/perl/fuente/perl-5.6.1' );

DESCRIPCIÓN

Devel::PatchPerl es una modularización del código de parcheo contenido en el archivo "buildperl.pl" de Devel::PPPort.

No construye perls, simplemente proporciona una interfaz a la funcionalidad de parcheo del código fuente.

FUNCIÓN

"patch_source"
Toma dos parámetros, una versión de "perl" y la ruta al código fuente de perl descomprimido para esa versión. Muere en caso de cualquier error.

Si no se proporciona una versión de "perl", intentará determinar automáticamente la versión de "perl" a partir de la ruta especificada.

Si no se proporciona la ruta al código fuente de perl descomprimido, asumirá el directorio de trabajo actual.

"determine_version"
Toma un parámetro opcional, la ruta al código fuente de perl descomprimido. Devuelve la versión de perl del código fuente en la ubicación dada. Devuelve undef en caso de error.

Si no se proporciona la ruta al código fuente de perl descomprimido, asumirá el directorio de trabajo actual.

SISTEMA DE PLUGINS

Ver Devel::PatchPerl::Plugin para detalles sobre el sistema de plugins de Devel::PatchPerl.

NIVEL DE PARCHE

Devel::PatchPerl normalmente actualizará el archivo "patchlevel.h" en el árbol de fuentes de perl para indicar que ha aplicado parches locales. Este comportamiento se anula si se detecta que está operando en un repositorio de git. Para anular esto y actualizar "patchlevel.h" en un repositorio de Git, establezca la variable de entorno "PERL5_PATCHPERL_PATCHLEVEL" a un valor verdadero.

Alternativamente, llame a "patchperl" con la opción "--patchlevel".

ADVERTENCIA

Devel::PatchPerl está destinado únicamente a facilitar la "construcción" de perls, no a facilitar las "pruebas" de perls. Esto significa que no aplicará parches a las pruebas fallidas en la suite de pruebas de perl.
