DEVLINK-PORT(8) Linux DEVLINK-PORT(8)

NOMBRE

devlink-port - Configuración del puerto devlink

SINOPSIS


devlink [ OPCIONES ] port { COMANDO | help }

OPCIONES := { -V[ersion] | -n[no-nice-names] }

devlink port set DEV/PORT_INDEX [ type { eth | ib | auto } ]

devlink port split DEV/PORT_INDEX count COUNT

devlink port unsplit DEV/PORT_INDEX

devlink port show [ DEV/PORT_INDEX ]

devlink port health { show | recover | diagnose | dump | set }

devlink port add { DEV | DEV/PORT_INDEX } [ flavour FLAVOUR ] [ pfnum PFNUMBER ] [ sfnum SFNUMBER ] [ controller CNUM ]

devlink port del DEV/PORT_INDEX

devlink port function set DEV/PORT_INDEX [ hw_addr ADDR ] [ state { active | inactive } [ roce { enable | disable } ] [ migratable { enable | disable } ] [ ipsec_crypto { enable | disable } ] [ ipsec_packet { enable | disable } ] [ max_io_eqs EQS ]

devlink port function rate { show | set | add | del | help }

devlink dev param set DEV/PORT_INDEX name PARAMETER value VALUE cmode { runtime | driverinit | permanent }

devlink dev param show [ DEV/PORT_INDEX name PARAMETER ]

devlink port help

DESCRIPCIÓN

devlink port set - cambiar los atributos del puerto devlink

DEV/PORT_INDEX - especifica el puerto devlink sobre el que operar. El formato es:


BUS_NAME/BUS_ADDRESS/PORT_INDEX
BUS_NAME/BUS_ADDRESS/PORT_INDEX

type { eth | ib | auto }
establece el tipo de puerto

eth - Ethernet

ib - Infiniband

auto - selección automática

devlink port split - dividir un puerto devlink en varios

DEV/PORT_INDEX - especifica el puerto devlink sobre el que operar.

count COUNT
número de puertos en los que dividir.

devlink port unsplit - deshacer la división de un puerto devlink previamente dividido

Se puede realizar en cualquier puerto dividido del mismo grupo de división.

DEV/PORT_INDEX - especifica el puerto devlink sobre el que operar.

devlink port show - mostrar los atributos del puerto devlink

DEV/PORT_INDEX - especifica el puerto devlink a mostrar. Si se omite este argumento, se listan todos los puertos.

devlink port health - informe y recuperación de salud de devlink

Es un alias para devlink-health(8).

devlink port add - añadir un puerto devlink

DEV - especifica el dispositivo devlink sobre el que operar. o

DEV/PORT_INDEX - especifica el índice de puerto devlink a usar para el nuevo puerto solicitado. Esto es opcional. Cuando se omite, el controlador asigna un índice de puerto único.

flavour { pcipf | pcisf }
establece el tipo de puerto

pcipf - Puerto PCI PF

pcisf - Puerto PCI SF

pfnum PFNUMBER
Especifica el número de PF de PCI en el que crear un dispositivo SF
sfnum SFNUMBER
Especifica el número de SF a asignar al dispositivo del SF. Este campo es opcional para aquellos dispositivos que soportan la asignación automática del número de SF.
controller CNUM
Especifica el número de controlador para el que se crea el puerto SF. Este campo es opcional. Se usa solo cuando el puerto SF se crea para un controlador externo.

devlink port function set - Establecer el(los) atributo(s) de la función del puerto.

DEV/PORT_INDEX - especifica el puerto devlink sobre el que operar.

hw_addr ADDR
Dirección de hardware de la función a establecer. Es una dirección MAC Ethernet cuando el tipo de puerto es Ethernet.
state { active | inactive }
Nuevo estado al que cambiar la función.

active - Una vez que la configuración de la función está hecha, activar la función.

inactive - Para inactivar la función y su(s) dispositivo(s), establecer a inactivo.

roce { enable | disable }
Establecer la capacidad RoCE de la función.
migratable { enable | disable }
Establecer la capacidad de migración de la función.
ipsec_crypto { enable | disable }
Establecer la capacidad de descarga criptográfica IPsec de la función. Controla la descarga de la operación criptográfica del estado XFRM (Cifrado/Descifrado).
ipsec_packet { enable | disable }
Establecer la capacidad de descarga de paquetes IPsec de la función. Controla la descarga del estado y la política XFRM (operación de Cifrado/Descifrado y encapsulación IPsec).
max_io_eqs EQS
Establecer el número máximo de colas de eventos de E/S de la función.

devlink port del - eliminar un puerto devlink

DEV/PORT_INDEX - especifica el puerto devlink a eliminar.

devlink port param set - establecer un nuevo valor para el parámetro de configuración del puerto devlink

DEV/PORT_INDEX - especifica el puerto devlink sobre el que operar.

name PARAMETER
Especificar el nombre del parámetro a establecer.
value VALUE
Nuevo valor a establecer.
cmode { runtime | driverinit | permanent }
Modo de configuración en el que se establece el nuevo valor.

runtime - Establecer el nuevo valor mientras el controlador está en ejecución. Este modo de configuración no requiere ningún reinicio para aplicar el nuevo valor.

driverinit - Establecer el nuevo valor que se aplicará durante la inicialización del controlador. Este modo de configuración requiere reiniciar el controlador con el comando devlink reload para aplicar el nuevo valor.

permanente - El nuevo valor se escribe en la memoria no volátil del dispositivo. Este modo de configuración requiere un reinicio duro para aplicar el nuevo valor.

devlink port param show - mostrar los parámetros de configuración soportados y los atributos del puerto devlink

DEV/PORT_INDEX - especifica el puerto devlink sobre el que operar.

name PARAMETER Especifica el nombre del parámetro a mostrar. Si se omiten este argumento, así como el índice del puerto, se listan todos los parámetros soportados por los puertos del dispositivo devlink.

devlink port function rate - gestionar objetos de tasa de devlink

Es un alias para devlink-rate(8).

EJEMPLOS

devlink port show

Muestra el estado de todos los puertos devlink en el sistema.

devlink port show pci/0000:01:00.0/1

Muestra el estado del puerto devlink especificado.

devlink port set pci/0000:01:00.0/1 type eth

Establece el tipo del puerto devlink especificado a Ethernet.

devlink port split pci/0000:01:00.0/1 count 4

Divide el puerto devlink especificado en cuatro puertos.

devlink port unsplit pci/0000:01:00.0/1

Reúne el puerto devlink especificado que fue dividido previamente.

devlink port health show

Muestra el estado y la configuración de todos los reportadores soportados registrados en todos los puertos devlink.

devlink port health show pci/0000:01:00.0/1 reporter tx

Muestra el estado y la configuración del reportador tx registrado en el puerto devlink pci/0000:01:00.0/1.

devlink port add pci/0000:06:00.0 flavour pcisf pfnum 0 sfnum 88

Añade un puerto devlink de tipo PCI SF en el PCI PF que tiene el número 0 con el número de SF 88. Para hacer uso de la función, una secuencia de ejemplo es añadir un puerto, configurar el atributo de la función y activar la función. Una vez que el uso de la función está completado, desactivar la función y finalmente borrar el puerto. Cuando se desee reutilizar el puerto sin borrarlo, puede ser reconfigurado y activado de nuevo cuando la función está en estado inactivo y el estado operacional de la función es desprendido.

devlink port del pci/0000:06:00.0/1

Borra el puerto devlink creado previamente. Se recomienda primero desactivar la función si la función soporta la gestión de estado.

devlink port function set pci/0000:01:00.0/1 hw_addr 00:00:00:11:22:33

Configura la dirección de hardware de la función PCI representada por el puerto devlink. Si el puerto soporta el cambio en el estado de la función, la dirección de hardware debe ser configurada antes de activar la función.

devlink port function set pci/0000:01:00.0/1 state active

Activa la función. Esto iniciará la enumeración de la función y la carga del controlador.

devlink port function set pci/0000:01:00.0/1 state inactive

Desactiva la función. Esto iniciará la desmontaje de la función, lo que resulta en la descarga del controlador y la eliminación del dispositivo.

devlink port function set pci/0000:01:00.0/1 roce enable

Esto habilitará la funcionalidad RoCE de la función.

devlink port function set pci/0000:01:00.0/1 migratable enable

Esto habilitará la funcionalidad migratable de la función.

devlink port function set pci/0000:01:00.0/1 ipsec_crypto enable

Esto habilitará la funcionalidad de descarga de criptografía IPsec de la función.

devlink port function set pci/0000:01:00.0/1 ipsec_packet enable

Esto habilitará la funcionalidad de descarga de paquetes IPsec de la función.

devlink port function set pci/0000:01:00.0/1 max_io_eqs 4

Esto establecerá el número máximo de colas de eventos de E/S de la función a 4.

devlink port function set pci/0000:01:00.0/1 hw_addr 00:00:00:11:22:33 state active

Configura la dirección de hardware y también activa la función. Cuando una función es activada junto con otra configuración en un solo comando, toda la configuración es aplicada primero antes de cambiar el estado a activo.

devlink dev param show

Muestra (vuelca) todos los parámetros del puerto en todos los dispositivos registrados en el devlink.

devlink dev param set pci/0000:01:00.0/1 name internal_error_reset value true cmode runtime

Establece el parámetro internal_error_reset del puerto devlink especificado (#1) a true.

devlink port add pci/0000:06:00.0 flavour pcisf pfnum 0 sfnum 88 controller 1

Añade un puerto devlink de tipo PCI SF en el controlador 1 que tiene un PCI PF de número 0 con número de SF 88. Para hacer uso de la función, una secuencia de ejemplo es añadir un puerto, configurar el atributo de la función y activar la función. Una vez que el uso de la función está completado, desactivar la función y finalmente borrar el puerto. Cuando se desee reutilizar el puerto sin borrarlo, puede ser reconfigurado y activado de nuevo cuando la función está en estado inactivo y el estado operacional de la función es desprendido.
