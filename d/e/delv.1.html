DESCRIPCIÓ

N

delv es una herramienta para enviar consultas DNS y validar los resultados, usando el mismo resolutor interno y la misma lógica de validación que named <#std-iscman-named>

.

delv envía al servidor de nombres especificado todas las consultas necesarias para obtener y validar los datos solicitados; esto incluye la consulta solicitada originalmente, consultas posteriores para seguir cadenas CNAME o DNAME, consultas para DNSKEY y registros DS para establecer una cadena de confianza para la validación DNSSEC. No realiza resolución iterativa, sino que simula el comportamiento de un servidor de nombres configurado para la validación DNSSEC y el

reenvío.

Por defecto, las respuestas se validan usando el ancla de confianza DNSSEC incorporada para la zona raíz ("."). Los registros devueltos por delv están completamente validados o no estaban firmados. Si la validación falla, se incluye en la salida una explicación del fallo; el proceso de validación se puede rastrear en detalle. Debido a que delv no depende de un servidor externo para llevar a cabo la validación, se puede usar para comprobar la validez de las respuestas DNS en entornos donde los servidores de nombres locales pueden no ser de

confianza.

A menos que se le indique consultar un servidor de nombres específico, delv prueba cada uno de los servidores listados en /etc/resolv.conf. Si no se encuentran direcciones de servidor utilizables, delv envía consultas a las direcciones localhost (127.0.0.1 para IPv4, ::1 para IPv6)

.

Cuando no se proporcionan argumentos ni opciones de línea de comandos, delv realiza una consult

a NS para "." (
la zona raíz).
