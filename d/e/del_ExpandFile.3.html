DESCRIPCIÓ

N

La función ef_expand_file() es parte de la biblioteca tecla (ver la página de manual libtecla(3)). Expande un nombre de archivo especificado, convirtiendo ~user/ y ~/ al inicio del nombre de archivo a los directorios de inicio correspondientes, reemplazando $envvar con el valor de la variable de entorno correspondiente, y luego, si hay algún comodín, haciendo coincidir estos con los nombres de archivo existentes. Las barras invertidas en el nombre de archivo de entrada se interpretan como escapando cualquier significado especial de los caracteres que las siguen. Solo las barras invertidas que están precedidas por otras barras invertidas se conservan en el nombre de archivo

expandido.

En presencia de comodines, la lista devuelta de nombres de archivo solo incluye los nombres de archivos existentes que coinciden con los comodines. De lo contrario, el nombre de archivo original se devuelve después de la expansión de las expresiones de virgulilla y dólar, y el resultado no se comprueba contra archivos existentes. Esto imita el comportamiento de globbing de archivos del shell tcsh de

unix.

Los comodines admitidos y sus significados

son: 
  *        -  Coincide con cualquier secuencia de cero o más caracteres.
  ?        -  Coincide con cualquier carácter único.
  [chars]  -  Coincide con cualquier carácter único que aparezca en
              'chars'. Si 'chars' contiene una expresión de
              la forma a-b, entonces cualquier carácter entre a y
              b, incluyendo a y b, coincide. El carácter '-'
              pierde su significado especial como
              especificador de rango cuando aparece al inicio
              de la secuencia de caracteres. El carácter ']'
              también pierde su significancia como el
              terminador de la expresión de rango si aparece
              inmediatamente después de la '[', en cuyo
              punto se trata como uno de los
              caracteres del rango. Si desea que tanto '-'
              como ']' sean parte del rango, el '-'
              debe venir primero y el ']' segundo.
  [^chars] -  Igual que [chars] excepto que coincide con cualquier
              carácter único que no aparezca en
'chars'.

Tenga en cuenta que los comodines nunca coinciden con el punto inicial en los nombres de archivo que comienzan con '.'. El '.' inicial debe especificarse explícitamente en el nombre de archivo. Esto nuevamente imita el comportamiento de globbing de la mayoría de los shells de unix, y su lógica se basa en el hecho de que en unix, los archivos con nombres que comienzan con '.' son usualmente archivos de configuración ocultos, que no son listados por defecto por el comando

ls.

El siguiente es un ejemplo completo de cómo usar la función de expansión de

archivos. 
  #include <stdio.h>
  #include <libtecla.h>
  int main(int argc, char *argv[])
  {
    ExpandFile *ef;      /* El objeto de recurso de expansión */
    char *filename;      /* El nombre de archivo que se está expandiendo */
    FileExpansion *expn; /* Los resultados de la expansión */
    int i;
    ef = new_ExpandFile();
    if(!ef)
      return 1;
    for(arg = *(argv++); arg; arg = *(argv++)) {
      if((expn = ef_expand_file(ef, arg, -1)) == NULL) {
        fprintf(stderr, "Error expanding %s (%s).\n", arg,
                         ef_last_error(ef));
      } else {
        printf("%s matches the following files:\n", arg);
        for(i=0; i<expn->nfile; i++)
          printf(" %s\n", expn->files[i]);
      }
    }
    ef = del_ExpandFile(ef);
    return 0;
}

  ExpandFile *new_ExpandFile(void
)

Esta función crea los recursos usados por la función ef_expand_file(). En particular, mantiene la memoria que se usa para registrar el arreglo de nombres de archivo coincidentes que es devuelto por ef_expand_file(). Este arreglo se expande según sea necesario, por lo que no hay un límite incorporado al número de archivos que pueden

coincidir.

Esta función elimina los recursos que fueron devueltos por una llamada anterior a new_ExpandFile(). Siempre devuelve NULL (es decir, un objeto eliminado). No hace nada si el argumento ef es NULL

  FileExpansion *ef_expand_file(ExpandFile *ef,
                                const char *path,
                                int
pathlen)

La función ef_expand_file() realiza la expansión de nombres de archivo, como se documenta al inicio de esta sección. Su primer argumento es un objeto de recurso devuelto por new_ExpandFile(). Un puntero al inicio del nombre de archivo a coincidir se pasa a través del argumento path. Este debe ser una cadena normal terminada en NUL, pero a menos que se pase una longitud de -1 en pathlen, solo los primeros pathlen caracteres serán usados en la expansión del nombre de archivo. Si la longitud se especifica como -1, toda la cadena será

expandida.

La función devuelve un puntero a un contenedor cuyo contenido son los resultados de la expansión. Si no había comodines en el nombre de archivo, el miembro nfile será 1, y el miembro exists debe ser consultado si es importante saber si el archivo expandido existe actualmente o no. Si había comodines, entonces el arreglo files[] contenido contendrá los nombres de los nfile archivos existentes que coincidieron con el nombre de archivo con comodines, y el miembro exists tendrá el valor 1. Tenga en cuenta que el contenedor devuelto pertenece al objeto ef especificado, y su contenido cambiará en cada llamada, por lo que si necesita retener los resultados de más de una llamada a ef_expand_file(), debe hacer una copia privada de los resultados devueltos, o crear múltiples objetos de recurso de expansión de archivos mediante múltiples llamadas a new_ExpandF

ile().

En caso de error, se devuelve NULL, y una explicación del error se puede determinar llamando a ef_last_erro

r(ef). 
  const char *ef_last_error(ExpandFile
*ef)

Esta función devuelve el mensaje que describe el error que ocurrió en la última llamada a ef_expand_file(), para el objeto de recurso (ExpandFile *ef)

dado. 
  int ef_list_expansions(FileExpansion *result, FILE *fp,
                         int terminal_width)
;

La función ef_list_expansions() proporciona una manera conveniente de listar las expansiones de nombres de archivo devueltas por ef_expand_file(). Como el comando ls de unix, organiza los nombres de archivo en columnas de igual ancho, cada columna teniendo el ancho del archivo más grande. El número de columnas usadas se determina así por la longitud del nombre de archivo más largo y el ancho de terminal especificado. Tenga cuidado de que los nombres de archivo que son más largos que el ancho de terminal especificado se imprimen sin ser truncados, por lo que puede ocurrir una salida más larga que el ancho de terminal especificado. La lista se escribe en el flujo stdio especificado por el argume

nto
fp.

SEGURIDAD DE

HILOS

En programas multihilo, debe usar la versión libtecla_r.a de la biblioteca. Esta usa funciones reentrantes POSIX donde están disponibles (de ahí el sufijo _r), y desactiva características que dependen de funciones de sistema no reentrantes. Actualmente no hay características desactivadas en este

módulo.

Usando la versión libtecla_r.a de la biblioteca, es seguro usar las instalaciones de este módulo en múltiples hilos, siempre que cada hilo use un objeto ExpandFile asignado por separado. En otras palabras, si dos hilos quieren hacer expansión de archivos, cada uno debería llamar a new_ExpandFile() para asignar sus prop

ios objetos de exp
ansión de archivos.
