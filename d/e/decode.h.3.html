BrotliDecoderResult BrotliDecoderDecompressStream (BrotliDecoderState * state, size_t * available_in, const uint8_t ** next_in, size_t * available_out, uint8_t ** next_out, size_t *

total_out)

Descomprime el flujo de entrada al flujo de salida. Los valores *available_in y *available_out deben especificar el número de bytes direccionables en *next_in y *next_out respectivamente. Cuando *available_out es 0, next_out puede ser

NULL.

Después de cada llamada, *available_in se decrementará por la cantidad de bytes de entrada consumidos, y el puntero *next_in se incrementará por esa cantidad. De manera similar, *available_out se decrementará por la cantidad de bytes de salida escritos, y el puntero *next_out se incrementará por esa

cantidad.

total_out, si no es un puntero nulo, se establecerá en el número de bytes descomprimidos desde la última inicialización del

estado.

Nota

:
La entrada nunca se consume en exceso, por lo que next_in y available_in podrían pasarse al siguiente consumidor después de que la decodificación esté
completa.

Parámetros

:
state instancia del decodificador
available_in in: cantidad de entrada disponible;
out: cantidad de entrada sin usar
next_in puntero al siguiente byte comprimido
available_out in: longitud del búfer de salida;
out: tamaño restante del búfer de salida
next_out cursor del búfer de salida; puede ser NULL si available_out es 0
total_out número de bytes descomprimidos hasta ahora; puede ser NULL

Devuelve

:
BROTLI_DECODER_RESULT_ERROR si la entrada está corrupta, la asignación de memoria falló, los argumentos eran inválidos, etc.; use BrotliDecoderGetErrorCode para obtener el código de error detallado

BROTLI_DECODER_RESULT_NEEDS_MORE_INPUT la decodificación está bloqueada hasta que se proporcione más datos de

entrada

BROTLI_DECODER_RESULT_NEEDS_MORE_OUTPUT la decodificación está bloqueada hasta que se proporcione más espacio de

salida

BROTLI_DECODER_RESULT_SUCCESS la decodificación h

a finalizado, no se consu

const uint8_t* BrotliDecoderTakeOutput (BrotliDecoderState * estado, size_t * tamaño)

Adquiere un puntero al búfer de salida interno. Este método se utiliza para facilitar y hacer más eficientes los enlaces de lenguaje:

1.
insertar datos en BrotliDecoderDecompressStream, hasta que se informe BROTLI_DECODER_RESULT_NEEDS_MORE_OUTPUT
2.
utilizar BrotliDecoderTakeOutput para examinar bytes y copiarlos a la entidad específica del lenguaje

Esto también puede ser útil si existe un flujo de salida que pueda consumir todos los datos proporcionados (por ejemplo, cuando los datos se guardan en el sistema de archivos).

Atención:

Después de cada llamada a BrotliDecoderTakeOutput, se consideran consumidos *tamaño* bytes de salida para todas las llamadas consecutivas a los métodos de la instancia; el puntero devuelto también queda invalidado.

Nota:

No se garantiza que la salida del decodificador sea contigua. Esto significa que después de una llamada sin restricciones de tamaño a BrotliDecoderTakeOutput, la siguiente llamada inmediata a BrotliDecoderTakeOutput puede devolver más datos.

Parámetros:

estado instancia del decodificador
tamaño entrada: número de bytes que el llamador está listo para tomar, 0 si se puede manejar cualquier cantidad;
salida: cantidad de datos apuntada por el puntero devuelto y considerada consumida;
el valor de salida nunca es mayor que el valor de entrada, a menos que sea 0

Devuelve:

puntero a los datos de salida
