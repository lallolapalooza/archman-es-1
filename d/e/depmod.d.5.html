NOMBRE

depmod.d - Directorio de configuración para depmod

SINOPSIS

/etc/depmod.d/*.conf

/run/depmod.d/*.conf

/usr/local/lib/depmod.d/*.conf

/usr/lib/depmod.d/*.conf

/lib/depmod.d/*.conf

DESCRIPCIÓN

Al ejecutarse, depmod lee los archivos de configuración de la ubicación anterior y, basándose en ellos, procesa los módulos disponibles y sus dependencias. Por ejemplo, se puede cambiar el orden de búsqueda, excluir carpetas, sobrescribir la ubicación de módulos específicos y más.

Esto es típicamente útil en casos donde los módulos del kernel incorporados se complementan con versiones compiladas personalizadas de los mismos y el usuario desea afectar la prioridad de procesamiento para anular la versión del módulo suministrada por el kernel.

FORMATO DE CONFIGURACIÓN

Los archivos de configuración contienen un comando por línea, ignorando las líneas en blanco y las que comienzan con '#' (útil para añadir comentarios). Una barra invertida '\' al final de una línea provoca que continúe en la siguiente línea, lo que hace que los archivos sean un poco más limpios.

Consulte la sección COMANDOS a continuación para más detalles.

DIRECTORIOS DE CONFIGURACIÓN Y PRECEDENCIA

Los archivos de configuración se leen de los directorios listados en SINOPSIS en ese orden de precedencia. Una vez que se carga un archivo de un nombre dado, se ignora cualquier archivo del mismo nombre en directorios posteriores.

Todos los archivos de configuración se ordenan lexicográficamente, independientemente del directorio en el que residan. Los archivos de configuración pueden ser reemplazados completamente (al tener un nuevo archivo de configuración con el mismo nombre en un directorio de mayor prioridad) o reemplazados parcialmente (al tener un archivo de configuración que se ordena más tarde).

COMANDOS

search subdirectorio...

Esto le permite especificar el orden en el que los subdirectorios de /lib/modules (u otra ubicación de módulo configurada) serán procesados por depmod. Los directorios se listan en orden, dando la mayor prioridad al primer directorio listado y la menor prioridad al último directorio listado. La palabra clave especial built-in se refiere a los directorios de módulos estándar instalados por el kernel. Otra palabra clave especial external se refiere a la lista de directorios externos, definida por el comando external.

Por defecto, depmod dará mayor prioridad a un directorio llamado updates usando esta cadena de búsqueda incorporada: "updates built-in", pero son posibles arreglos más complejos que se usan en varias distribuciones populares.

override nombre_módulo versión_kernel subdirectorio_módulos

Este comando le permite anular qué versión de un módulo específico se utilizará cuando más de un módulo que comparte el mismo nombre sea procesado por el comando depmod. Es posible especificar un kernel o todos los kernels usando el comodín *. subdirectorio_módulos es el nombre del subdirectorio bajo /lib/modules (u otra ubicación de módulo) donde está instalado el módulo objetivo.

Por ejemplo, es posible anular la prioridad de un módulo de prueba actualizado llamado kmod especificando el siguiente comando: "override kmod * extra". Esto asegurará que cualquier nombre de módulo coincidente instalado bajo el subdirectorio extra dentro de /lib/modules (u otra ubicación de módulo) tendrá prioridad sobre cualquier módulo de nombre similar ya proporcionado por el kernel.

external versión_kernel directorio_módulos_absoluto...

Esto especifica una lista de directorios, que se comprobarán según las prioridades en el comando search. El orden también importa, el primer directorio tiene la mayor prioridad.

La versión_kernel es una expresión regular POSIX o un comodín *, como en override.

exclude directorio_excluido

Esto especifica los directorios finales que se excluirán durante la búsqueda de módulos del kernel.

El directorio_excluido es el directorio final a excluir.
