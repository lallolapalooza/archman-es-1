NOMBRE

deb-postrm - script de mantenedor post-eliminación de paquetes

SINOPSIS

DEBIAN/postrm

DESCRIPCIÓN

Un paquete puede realizar varias acciones post-eliminación a través de scripts de mantenedor, incluyendo un archivo ejecutable postrm en su archivo de control (es decir, DEBIAN/postrm durante la creación del paquete).

El script puede ser llamado de las siguientes maneras:

postrm remove
Después de que el paquete fue eliminado.
postrm purge
Después de que el paquete fue purgado.
old-postrm upgrade new-version
Después de que el paquete fue actualizado.
new-postrm failed-upgrade old-version new-version
Si la llamada anterior upgrade falla.

El new-version se pasa solo desde dpkg 1.18.5.

postrm disappear overwriter-package overwriter-version
Después de que todos los archivos del paquete han sido reemplazados.
new-postrm abort-install
Si preinst falla durante install.
new-postrm abort-install old-version new-version
Si preinst falla durante install para una actualización de un paquete eliminado.

El new-version se pasa solo desde dpkg 1.18.5.

new-postrm abort-upgrade old-version new-version
Si preinst falla durante upgrade.

El new-version se pasa solo desde dpkg 1.18.5.
