ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen_number
Especifica el número de pantalla apropiado en el servidor host.
count_return
Devuelve el número de profundidades.

DESCRIPCIÓN

El AllPlanes macro devuelve un valor con todos los bits establecidos a 1, adecuado para su uso en un argumento de plano de un procedimiento.

El BlackPixel macro devuelve el valor de píxel negro para la pantalla especificada.

El WhitePixel macro devuelve el valor de píxel blanco para la pantalla especificada.

El ConnectionNumber macro devuelve un número de conexión para la visualización especificada.

El DefaultColormap macro devuelve el ID del mapa de colores predeterminado para la asignación en la pantalla especificada.

El DefaultDepth macro devuelve la profundidad (número de planos) de la ventana raíz predeterminada para la pantalla especificada.

La función XListDepths devuelve el array de profundidades disponibles en la pantalla especificada. Si el screen_number especificado es válido y se puede asignar memoria suficiente para el array, XListDepths establece count_return al número de profundidades disponibles. De lo contrario, no establece count_return y devuelve NULL. Para liberar la memoria asignada para el array de profundidades, use XFree.

El DefaultGC macro devuelve el GC predeterminado para la ventana raíz de la pantalla especificada.

El DefaultRootWindow macro devuelve la ventana raíz para la pantalla predeterminada.

El DefaultScreenOfDisplay macro devuelve la pantalla predeterminada de la visualización especificada.

El DefaultScreen macro devuelve el número de pantalla predeterminado referenciado en la rutina XOpenDisplay .

El DefaultVisual macro devuelve el tipo visual predeterminado para la pantalla especificada.

El DisplayCells macro devuelve el número de entradas en el mapa de colores predeterminado.

El DisplayPlanes macro devuelve la profundidad de la ventana raíz de la pantalla especificada.

El DisplayString macro devuelve la cadena que se pasó a XOpenDisplay cuando se abrió la visualización actual.

La función XMaxRequestSize devuelve el tamaño máximo de solicitud (en unidades de 4 bytes) admitido por el servidor sin usar una codificación de protocolo de longitud extendida. Las solicitudes de protocolo individuales al servidor no pueden ser mayores que este tamaño a menos que el servidor admita una codificación de protocolo de longitud extendida. El protocolo garantiza que el tamaño no sea menor de 4096 unidades (16384 bytes). Xlib divide automáticamente los datos en múltiples solicitudes de protocolo según sea necesario para las siguientes funciones: XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectanglesy XPutImage.

La función XExtendedMaxRequestSize devuelve cero si la visualización especificada no admite una codificación de protocolo de longitud extendida; de lo contrario, devuelve el tamaño máximo de solicitud (en unidades de 4 bytes) admitido por el servidor usando la codificación de longitud extendida. Las funciones de Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectanglesy XSetRegion usarán la codificación de longitud extendida según sea necesario, si el servidor la admite. El uso de la codificación de longitud extendida en otras funciones de Xlib (por ejemplo, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, XPutImage) está permitido pero no es obligatorio; una implementación de Xlib puede optar por dividir los datos en múltiples solicitudes más pequeñas.

El LastKnownRequestProcessed macro extrae el número de serie completo de la última solicitud que Xlib sabe que ha sido procesada por el servidor X.

El NextRequest macro extrae el número de serie completo que se usará para la siguiente solicitud.

El ProtocolVersion macro devuelve el número de versión principal (11) del protocolo X asociado con la visualización conectada.

El ProtocolRevision macro devuelve el número de revisión menor del protocolo del servidor X.

El QLength macro devuelve la longitud de la cola de eventos para la visualización conectada.

El RootWindow macro devuelve la ventana raíz.

El ScreenCount macro devuelve el número de pantallas disponibles.

El ScreenOfDisplay macro devuelve un puntero a la pantalla de la visualización especificada.

El ServerVendor macro devuelve un puntero a una cadena terminada en nulo que proporciona alguna identificación del propietario de la implementación del servidor X.

El VendorRelease macro devuelve un número relacionado con la versión del servidor X de un proveedor.
