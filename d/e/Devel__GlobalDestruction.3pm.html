Paquete: perl-devel-globaldestruction

Licencias: PerlArtistic, GPL

Devel::GlobalDestruction(3) Documentación Perl contribuida por el usuario Devel::GlobalDestruction(3)

NOMBRE

Devel::GlobalDestruction - Proporciona una función que devuelve el equivalente de "${^GLOBAL_PHASE} eq 'DESTRUCT'" para versiones antiguas de Perl.

SINOPSIS

package Foo;
use Devel::GlobalDestruction;
use namespace::clean; # para evitar tener un método "in_global_destruction"
sub DESTROY {
    return if in_global_destruction;
    do_something_a_little_tricky();
}

DESCRIPCIÓN

La destrucción global de Perl es un poco complicada de manejar con respecto a los finalizadores, ya que no tiene un orden establecido y los objetos pueden desaparecer a veces.

Escribir destructores defensivos es difícil y molesto, y generalmente, si está ocurriendo la destrucción global, solo necesitas que se ejecuten los destructores que liberan recursos no locales del proceso.

Para estos constructores, puedes evitar el lío simplemente saliendo si la destrucción global está en efecto.

EXPORTACIONES

Este módulo utiliza Sub::Exporter::Progressive, por lo que las exportaciones pueden ser renombradas, aliadas, etc., si Sub::Exporter está presente.

in_global_destruction
Devuelve verdadero si el intérprete está en modo de destrucción global. En Perl 5.14+, esto devuelve "${^GLOBAL_PHASE} eq 'DESTRUCT'", y en versiones anteriores de Perl, lo detecta utilizando el valor de "PL_main_cv" o "PL_dirty".
