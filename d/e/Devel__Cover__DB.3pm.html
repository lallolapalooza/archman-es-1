Devel::Cover::DB(3) Documentación de Perl contribuida por el usuario Devel::Cover::DB(3)

NOMBRE

Devel::Cover::DB - Métricas de cobertura de código para Perl

VERSIÓN

versión 1.51

SINOPSIS

use Devel::Cover::DB;
my $db = Devel::Cover::DB->new(db => "mi_base_de_datos_cobertura");
$db->print_summary([$archivo1, $archivo2], ["declaracion", "pod"]);

DESCRIPCIÓN

Este módulo proporciona acceso a una base de datos de información de cobertura de código.

MÉTODOS

new

my $db = Devel::Cover::DB->new(db => "mi_base_de_datos_cobertura");

Construye la base de datos a partir de la base de datos especificada.

cover

my $cover = $db->cover;

Devuelve un objeto Devel::Cover::DB::Cover. A partir de aquí se puede acceder a todos los datos de cobertura.

my $cover = $db->cover;
for my $archivo ($cover->items) {
    print "$archivo\n";
    my $f = $cover->file($archivo);
    for my $criterio ($f->items) {
        print "  $criterio\n";
        my $c = $f->criterion($criterio);
        for my $ubicacion ($c->items) {
            my $l = $c->location($ubicacion);
            print "    $ubicacion @$l\n";
        }
    }
}

Los datos para diferentes criterios estarán en diferentes formatos, por lo que necesitarán un manejo especial. Esto aún no está documentado, por lo que su mejor opción por ahora es mirar algunos de los informes más simples y/o el código fuente.

Los métodos en el ejemplo anterior son en realidad alias para métodos en Devel::Cover::DB::Base (la clase base para todas las clases Devel::Cover::DB::*):

  • Devel::Cover::DB::Base->values

    Alias para Devel::Cover::DB::Cover->files, Devel::Cover::DB::File->criteria, Devel::Cover::DB::Criterion->locations, y Devel::Cover::DB::Location->data

  • Devel::Cover::DB::Base->get

    Alias para Devel::Cover::DB::Cover->file, Devel::Cover::DB::File->criterion, Devel::Cover::DB::Criterion->location, y Devel::Cover::DB::Location->datum

En lugar de llamar $archivo->criterion("x") también puede llamar $archivo->x.

is_valid

my $valido = $db->is_valid;

Devuelve verdadero si $db es válido (o parece válido, la función es demasiado laxa).
