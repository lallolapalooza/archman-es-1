Devel::StackTrace::Frame(3) Documentación de Perl aportada por el usuario Devel::StackTrace::Frame(3)

NOMBRE

Devel::StackTrace::Frame - Un único fotograma en un rastreo de pila

VERSIÓN

versión 2.05

DESCRIPCIÓN

Ver Devel::StackTrace para más detalles.

MÉTODOS

Ver la documentación de "caller" de Perl para más información sobre lo que devuelven estos métodos.

$frame->paquete

El paquete que creó este fotograma.

$frame->nombre_archivo

El nombre del archivo que creó este fotograma.

$frame->línea

La línea donde se creó el fotograma.

$frame->subrutina

La subrutina que creó este fotograma.

$frame->tiene_argumentos

Esto será verdadero si se creó un nuevo @_ para este fotograma.

$frame->contexto_respuesta

Esto indica el contexto de la llamada para este fotograma. Será verdadero si se llamó en contexto de array, falso en contexto escalar, y "undef" en contexto void.

$frame->texto_eval

Devuelve undef si el fotograma no formaba parte de un eval.

$frame->es_require

Devuelve undef si el fotograma no formaba parte de un require.

$frame->argumentos

Devuelve los argumentos pasados al fotograma. Tenga en cuenta que cualquier argumento que sean referencias se devuelven como referencias, no como copias.

$frame->pistas

Devuelve el valor de $^H para este fotograma.

$frame->mascara_bits

Devuelve el valor de $bitmask para este fotograma.

$frame->como_cadena

Devuelve una cadena que contiene una descripción del fotograma.

SOPORTE
