NOMBRE

deb-preinst - Script del mantenedor de preinstalación de paquetes

SINOPSIS

DEBIAN/preinst

DESCRIPCIÓN

Un paquete puede realizar varias acciones de preinstalación a través de scripts del mantenedor, incluyendo un archivo ejecutable preinst en su archivo de control (es decir, DEBIAN/preinst durante la creación del paquete).

El script puede ser llamado de las siguientes maneras:

nuevo-preinst install
Antes de que se instale el paquete.
nuevo-preinst install versión-antigua versión-nueva
Antes de que se actualice un paquete eliminado.

El argumento versión-nueva se pasa solo desde dpkg 1.18.5.

nuevo-preinst upgrade versión-antigua versión-nueva
Antes de que se actualice el paquete.

El argumento versión-nueva se pasa solo desde dpkg 1.18.5.

viejo-preinst abort-upgrade versión-nueva
Si postrm falla durante la actualización o falla en la actualización fallida.
