DEBIAN-DISTRO-INFO(1) Manual de Comandos Generales DEBIAN-DISTRO-INFO(1)

NOMBRE

debian-distro-info - proporciona información sobre las distribuciones de Debian

SINOPSIS

debian-distro-info [OPCIONES]

OPCIONES

--date=FECHA
fecha para calcular la versión (por defecto: época tomada de la variable de entorno SOURCE_DATE_EPOCH si está establecida, de lo contrario, hoy)
-h, --help
mostrar mensaje de ayuda y salir
--alias=DIST
imprime el alias (oldstable, stable, testing, unstable) relativo al nombre en clave de la distribución pasado como argumento. Solo se aceptan nombres en clave de distribución compuestos por letras ASCII en minúsculas y si la distribución no califica como oldstable, stable, testing o unstable, entonces se devuelve el mismo nombre en clave pasado como argumento.
-a, --all
listar todas las versiones conocidas
-y[HITO], --days[=HITO]
muestra el número de días hasta que la versión especificada alcance el hito especificado. HITO puede ser uno de created, release o eol. Si no se especifica ningún hito, se asume release. Para opciones que devuelven una lista, muestra la salida normal seguida de espacio en blanco y el número de días hasta el hito especificado. Si no se puede calcular el hito, se muestra la cadena '(unknown)'. A menos que se especifique uno de -c, -f o -r, solo se mostrará el número de días.
-d, --devel
última versión de desarrollo
-o, --old
última versión antigua (estable)
--series=SERIE
serie para calcular la versión
-s, --stable
última versión estable
--supported
lista de todas las versiones soportadas, incluidas las versiones de desarrollo
-t, --testing
última versión de prueba
--unsupported
lista de todas las versiones estables no soportadas
-c, --codename
imprimir el nombre en clave (por defecto)
-r, --release
imprimir la versión de lanzamiento
-f, --fullname
imprimir el nombre completo

VER TAMBIÉN

distro-info(1), ubuntu-distro-info(1)
