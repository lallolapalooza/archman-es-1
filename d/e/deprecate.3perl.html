deprecate(3perl) Guía del programador de Perl deprecate(3perl)

NOMBRE

deprecate - pragma de Perl para desaprobar la inclusión de un módulo en el core

SINOPSIS

use deprecate;  # Advertir sobre la ausencia futura si se carga desde el core

DESCRIPCIÓN

Este pragma simplifica el mantenimiento de módulos de doble vida que ya no se incluirán en el core de Perl en una futura versión de Perl, pero que actualmente se incluyen.

El propósito del pragma es alertar a los usuarios sobre el estado de dicho módulo emitiendo una advertencia que los anima a instalar el módulo desde CPAN, de modo que una futura actualización a una versión de Perl que omita el módulo no rompa su código.

Esta advertencia solo se emitirá si el módulo se cargó desde un directorio de biblioteca core, lo que permite incluir la línea "use deprecate" en la versión CPAN del módulo. Debido a que el pragma permanece en silencio cuando el módulo se ejecuta desde un directorio de biblioteca no core, la llamada al pragma no necesita ser modificada o eliminada para la versión core o CPAN del módulo. Se puede distribuir exactamente el mismo código para ambos propósitos.

Advertencia Importante

Tenga en cuenta que cuando un módulo se instala desde CPAN en un directorio de biblioteca core en lugar de los directorios de biblioteca de sitio, el usuario no obtiene protección por haberlo instalado.

Al mismo tiempo, este pragma no puede detectar cuándo un módulo de este tipo se ha instalado desde CPAN al directorio core, por lo que exhortaría al usuario a actualizar de forma interminable e inútil.

Por lo tanto, los módulos que pueden instalarse desde CPAN al directorio core deben asegurarse de no llamar a este pragma cuando lo hayan hecho. Generalmente, esto significa que la lógica exacta del instalador debe reflejarse dentro del módulo. Por ejemplo:

# Makefile.PL
WriteMakefile(
    # ...
    INSTALLDIRS => ( "$]" >= 5.011 ? 'site' : 'perl' ),
);
# lib/Foo/Bar.pm
use if "$]" >= 5.011, 'deprecate';

(El ejemplo anterior muestra el caso más importante de esto: cuando el destino es una versión de Perl anterior a 5.12 (donde los directorios de biblioteca core tienen precedencia sobre los directorios de biblioteca de sitio) y el módulo que se está instalando se incluyó en el core en esa versión de Perl. En esas circunstancias, una actualización del módulo desde CPAN solo es posible instalándolo en la biblioteca core.)

EXPORTAR

Ninguno por defecto. El único método es "import", llamado por "use deprecate;".
