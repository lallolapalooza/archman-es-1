NOMBRE

desktop-file-validate - Valida archivos de entrada de escritorio

SINOPSIS

desktop-file-validate [--no-hints] [--no-warn-deprecated] [--warn-kde] ARCHIVO...

DESCRIPCIÓN

El programa desktop-file-validate es una herramienta para validar archivos de entrada de escritorio según la especificación de entrada de escritorio 1.5.

La especificación describe un formato de archivo para proporcionar información tal como el nombre, icono y descripción de una aplicación. Dicho archivo puede ser utilizado como lanzador de aplicaciones y para mostrar la aplicación en el menú de aplicaciones.

Para obtener información sobre la especificación de entrada de escritorio, consulta http://freedesktop.org/wiki/Specifications/desktop-entry-spec.

Los archivos de entrada de escritorio se denominan comúnmente archivos de escritorio.

OPCIONES

Se soportan las siguientes opciones:

--no-hints
No mostrar sugerencias sobre cosas que podrían mejorarse en el archivo de escritorio.
--no-warn-deprecated
No advertir sobre el uso de elementos obsoletos definidos en versiones anteriores de la especificación.
--warn-kde
Advertir sobre el uso de extensiones de KDE a la especificación. Esto incluye el uso del grupo KDE Desktop Entry, de las claves ServiceTypes, DocPath, Keywords, InitialPreference, Dev, FSType, MountPoint, ReadOnly, UnmountIcon, o de los tipos Service, ServiceType y FSDevice.

ERRORES

Si encuentras errores en el programa desktop-file-validate, por favor repórtalos en https://bugs.freedesktop.org.
