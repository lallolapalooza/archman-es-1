DEBUGEDIT(1) Comandos de usuario DEBUGEDIT(1)

NOMBRE

debugedit - herramienta de manipulación de rutas de origen de depuración

SINOPSIS

debugedit [OPCIÓN...] ARCHIVO

DESCRIPCIÓN

-b, --base-dir=CADENA
directorio base de compilación de objetos
-d, --dest-dir=CADENA
directorio en el que reescribir base-dir
-l, --list-file=CADENA
archivo donde poner la lista de nombres de archivos fuente y de cabecera
-i, --build-id
recalcular la nota de ID de compilación e imprimir el ID en la salida estándar
-s, --build-id-seed=CADENA
si se recalcula la nota de ID de compilación, usar esta cadena como semilla de hash
-n, --no-recompute-build-id
no recalcular la nota de ID de compilación incluso cuando se dan -i o -s
-p, --preserve-dates
Preservar las marcas de tiempo de modificación/acceso

Opciones de ayuda:

-?, --help
Mostrar este mensaje de ayuda
-u, --usage
Mostrar mensaje de uso breve
-V, --version
Mostrar la versión de debugedit
