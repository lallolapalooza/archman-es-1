DEFAULTS(1) Manual del Sistema GNUstep DEFAULTS(1)

NOMBRE

defaults - leer o modificar los valores predeterminados del usuario de GNUstep

SINOPSIS

defaults [ acción ]

DESCRIPCIÓN

El comando 'defaults' te permite leer y modificar los valores predeterminados de un usuario.

Este programa reemplaza los antiguos programas de estilo NeXTstep dread, dwrite y dremove.

Si tienes acceso a la base de datos de valores predeterminados de otro usuario, puedes incluir '-u nombredeusuario' antes de cualquier otra opción para usar la base de datos de ese usuario en lugar de la tuya.

defaults read [ dominio [ clave] ]

lee el valor predeterminado nombrado del dominio especificado. Si no se proporciona ninguna 'clave', lee todos los valores predeterminados del dominio. Si no se proporciona ningún 'dominio', lee todos los valores predeterminados de todos los dominios. Un dominio es el nombre de una aplicación o "NSGlobalDomain", para los valores predeterminados a nivel del sistema. (Los programas en ejecución pueden acceder a otros dos dominios, "NSArgumentDomain", para los argumentos de la línea de comandos, "NSRegistrationDomain", un dominio de segunda oportunidad en el que se pueden registrar "valores predeterminados para valores predeterminados", y posiblemente dominios para configuraciones regionales específicas).

defaults readkey clave

lee el valor predeterminado nombrado de todos los dominios.

defaults write dominio clave valor

escribe 'valor' como el valor predeterminado 'clave' en el dominio especificado. 'valor' debe ser una lista de propiedades entre comillas simples.

defaults write dominio diccionario

escribe 'diccionario' como un reemplazo para el dominio especificado. 'diccionario' debe ser una lista de propiedades entre comillas simples.

defaults write

lee la entrada estándar para obtener valores predeterminados en el formato producido por 'defaults read' y los escribe en la base de datos.

defaults delete [ dominio [ clave] ]

elimina el valor o valores predeterminados especificados del dominio. Si no se proporciona ninguna 'clave', elimina todo el dominio.

defaults delete

lee la entrada estándar para obtener una serie de líneas que contienen pares de dominios y claves para los valores predeterminados a eliminar.

defaults domains

enumera los dominios en la base de datos (uno por línea)

defaults find palabra

busca en los nombres de dominio, nombres de valores predeterminados y cadenas de valores predeterminados para aquellos que sean iguales a la palabra especificada y los enumera en la salida estándar.

defaults plist

muestra información sobre listas de propiedades

defaults help

enumera las opciones para el comando defaults.

ARCHIVOS

~/GNUstep/Defaults/.GNUstepDefaults
contiene los valores predeterminados para un usuario

ERRORES

Ninguno conocido.

DIAGNÓSTICOS

Esperemos que sean autoexplicativos.

HISTORIA

El comando 'defaults' apareció en OpenStep y combinó las capacidades de los comandos anteriores de NeXTstep 'dread', 'dwrite' y 'dremove'.

La versión de GNUstep fue escrita en 1998.

Esta página del manual apareció por primera vez en gnustep-base 1.9.2 (marzo de 2004).
