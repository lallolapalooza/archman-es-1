NOMBRE

default.pa — Script de inicio del servidor de sonido PulseAudio

SINOPSIS

~/.config/pulse/default.pa

/etc/pulse/default.pa

/etc/pulse/system.pa

DESCRIPCIÓN

El servidor de sonido PulseAudio interpreta un script de configuración al inicio, que se utiliza principalmente para definir el conjunto de módulos a cargar. Cuando PulseAudio se ejecuta en modo por usuario y existe ~/.config/pulse/default.pa, se utiliza ese archivo. Cuando PulseAudio se ejecuta en modo por usuario y ese archivo no existe, se utiliza /etc/pulse/default.pa. Cuando PulseAudio se ejecuta como un servicio del sistema, se utiliza /etc/pulse/system.pa.

El script debe contener directivas en el lenguaje CLI de PulseAudio, como se documenta en pulse-cli-syntax(5).

AUTORES

Los desarrolladores de PulseAudio <pulseaudio-discuss (at) lists (dot) freedesktop (dot) org>; PulseAudio está disponible en http://pulseaudio.org/

VER TAMBIÉN

pulse-cli-syntax(5), pulse-daemon.conf(5), pulseaudio(1), pacmd(1)
