NOMBRE

define_key - definir un código de tecla de curses

SINOPSIS

#include <curses.h>
int define_key(const char *definicion, int codigo_tecla);

DESCRIPCIÓN

Esta es una extensión a la biblioteca curses. Permite a una aplicación definir códigos de tecla con sus cadenas de control correspondientes, de modo que la biblioteca ncurses los interprete igual que los códigos predefinidos en la base de datos terminfo.

Si definicion es NULL, se elimina cualquier definición existente para el código de tecla. Del mismo modo, si el código de tecla dado es negativo o cero, se elimina cualquier cadena existente para la definición dada.

VALOR DE RETORNO

O codigo_tecla debe ser mayor que cero, o definicion debe ser distinto de NULL, de lo contrario se devuelve ERR. ERR también puede devolverse si no hay suficiente memoria para asignar los datos necesarios para almacenar la definición. Si no se detecta ningún error, se devuelve OK.

PORTABILIDAD

Estas rutinas son específicas de ncurses. No eran compatibles con las implementaciones de la Versión 7, BSD o System V. Se recomienda que cualquier código que dependa de ellas se condicione utilizando NCURSES_VERSION.
