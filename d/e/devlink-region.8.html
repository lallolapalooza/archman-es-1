NOMBRE

devlink-region - acceso a la región de direcciones devlink

SINOPSIS


devlink [ OPCIONES ] region { COMANDO | help }

OPCIONES := { -V[ersion] | -n[no-nice-names] }

devlink region show [ DEV/REGION ]

devlink region new DEV/REGION [ snapshot SNAPSHOT_ID ]

devlink region del DEV/REGION snapshot SNAPSHOT_ID

devlink region dump DEV/REGION snapshot SNAPSHOT_ID

devlink region read DEV/REGION [ snapshot SNAPSHOT_ID ] address DIRECCION length LONGITUD

devlink region help

DESCRIPCIÓN

devlink region show - Mostrar todos los nombres de regiones de direcciones, instantáneas y tamaños soportados

DEV/REGION - especifica el dispositivo devlink y la región de direcciones a consultar.

devlink region new - Crear una instantánea especificada por nombre de región de direcciones y ID de instantánea

DEV/REGION - especifica el dispositivo devlink y la región de direcciones a instantanear.

snapshot SNAPSHOT_ID - opcionalmente especifica el ID de instantánea a asignar. Si no se especifica, devlink asignará un ID único a la instantánea.

devlink region del - Eliminar una instantánea especificada por nombre de región de direcciones y ID de instantánea

DEV/REGION - especifica el dispositivo devlink y la región de direcciones de la que eliminar la instantánea.

snapshot SNAPSHOT_ID - especifica el ID de instantánea a eliminar.

devlink region dump - Volcar todos los datos disponibles de una región o de una instantánea de una región

DEV/REGION - especifica el dispositivo y la región de direcciones de la que volcar.

snapshot SNAPSHOT_ID - especifica el ID de instantánea de la región a volcar.

devlink region read - Leer desde una dirección de región específica para una longitud dada

DEV/REGION - especifica el dispositivo y la región de direcciones desde la que leer.

snapshot SNAPSHOT_ID - especifica el ID de instantánea de la región a leer.

address DIRECCION - especifica la dirección desde la que leer.

length LONGITUD - especifica la longitud de los datos a leer.

EJEMPLOS

devlink region show

Listar regiones de direcciones y instantáneas disponibles.

devlink region new pci/0000:00:05.0/cr-space

Crear una nueva instantánea desde la región de direcciones cr-space del dispositivo pci/0000:00:05.0.

devlink region del pci/0000:00:05.0/cr-space snapshot 1

Eliminar la instantánea con ID 1 de la región de direcciones cr-space del dispositivo pci/0000:00:05.0.

devlink region dump pci/0000:00:05.0/cr-space snapshot 1

Volcar la instantánea tomada de la región de direcciones cr-space con ID 1.

devlink region read pci/0000:00:05.0/cr-space snapshot 1 address 0x10 length 16

Leer desde la dirección 0x10, 16 bytes de la instantánea con ID 1 tomada de la región de direcciones cr-space.
