DELUGE-CONSOLE(1) Manual de Comandos Generales DELUGE-CONSOLE(1)

NOMBRE

deluge-console - Una interfaz de consola de cliente BitTorrent

SINOPSIS

deluge-console [opciones]

DESCRIPCIÓN

Deluge utiliza un modelo cliente/servidor, con deluged siendo el proceso demonio y deluge-console usándose para lanzar una interfaz de usuario de consola con curses.

Comandos de la consola:

Puedes pasar comandos de consola directamente desde la línea de comandos y usar el separador de punto y coma (;) para ejecutar múltiples comandos. También puede ser necesario encerrar los comandos entre comillas, por ejemplo:


deluge-console 'add <torrent>; info <id_torrent>'

Los siguientes comandos de consola están disponibles:

add Añade torrents
cache Muestra información sobre la caché del disco
config Muestra y establece valores de configuración
connect Conéctate a un nuevo servidor deluge
debug Habilita y deshabilita la depuración
del Alias de rm
exit Alias de quit
gui Habilita el modo interactivo
halt Apaga el servidor deluge
help Muestra ayuda sobre otros comandos
info Muestra información sobre los torrents
manage Muestra y gestiona opciones por torrent
move Mueve la ubicación de almacenamiento de los torrents
pause Pausa los torrents
plugin Gestiona plugins
quit Sale del cliente
reannounce Alias de update_tracker
recheck Fuerza una nueva comprobación de los datos del torrent
resume Reanuda los torrents
rm Elimina un torrent
status Muestra diversa información de estado del demonio
update_tracker Actualiza el rastreador para el(los) torrent(s)

OPCIONES

Opciones de configuración

-c ruta, --config=ruta
Establece la ubicación del directorio de configuración.

Opciones de consola

Estas opciones de conexión del demonio se usarán para los comandos, o si la autoconexión de la interfaz de consola está habilitada.

-d dir_ip, --daemon=dir_ip
Dirección IP del demonio Deluge al que conectarse (por defecto 127.0.0.1)
-p puerto, --port=puerto
Puerto del demonio Deluge al que conectarse (por defecto 58846)
-U usuario, --username=usuario
Nombre de usuario del demonio Deluge a usar al conectarse
-P contraseña, --password=contraseña
Contraseña del demonio Deluge a usar al conectarse

Opciones de registro

-l archivo, --logfile=archivo
Salida al archivo de registro especificado en lugar de stdout
-L nivel_registro, --loglevel=nivel_registro
Establece el nivel de registro (el predeterminado es error): none, info, warning, error, debug
-q, --quiet
Establece el nivel de registro en none, igual que -L none
--logrotate[=tamaño-máx]
Habilita la rotación del archivo de registro, con un tamaño máximo opcional del archivo de registro, predeterminado: 2M (El número de rotaciones del archivo de registro es 5)
--profile[=archivo]
Perfilado con cProfile. Salida a stdout a menos que se especifique un nombre de archivo

Opciones de ayuda

-V, --version
Muestra el número de versión del programa y sale.
-h, --help
Muestra el mensaje de ayuda y sale.
