desktoptojson(8)

Paquete: kservice5

Licencias: LGPL

DESKTOPTOJSON(8) KDE Frameworks: KService DESKTOPTOJSON(8)

NOMBRE

desktoptojson - Convierte un archivo .desktop a un archivo .json.

SINOPSIS

desktoptojson --input ARCHIVO-DESKTOP --output ARCHIVO-JSON

desktoptojson {--version | --help}

DESCRIPCIÓN

El framework KService utiliza la información contenida en los archivos .desktop para localizar servicios, incluyendo plugins para aplicaciones y librerías basadas en Qt5. Sin embargo, el sistema de plugins de Qt5 utiliza datos JSON incrustados en el propio plugin. desktoptojson permite que la información contenida en un archivo .desktop también se utilice como datos incrustados para un plugin de Qt5, convirtiendo las entradas del archivo .desktop en datos JSON.

Los datos JSON generados son un objeto JSON que mapea las entradas del grupo [Desktop Entry] del archivo .desktop. Se ignoran todos los demás grupos. La mayoría de las entradas se convierten simplemente en cadenas JSON, pero ciertas entradas (como Hidden y X-KDE-PluginInfo-EnabledByDefault) se conocen por ser valores booleanos y se convierten como tales, y de forma similar algunas (como X-KDE-ServiceTypes y X-KDE-PluginInfo-Depends) se convierten siempre en arrays de cadenas.

OPCIONES

--input ARCHIVO-DESKTOP

El archivo .desktop a convertir.

--output ARCHIVO-JSON

El archivo donde escribir los datos JSON generados.

--help

Muestra un breve texto de ayuda.

--version

Muestra información de la versión.

USO

La mayoría de los usuarios de esta utilidad utilizarán la macro de CMake kservice_desktop_to_json como parte del proceso de construcción de un plugin.

add_library(myplugin MODULE ${myplugin_SRCS})
kservice_desktop_to_json(myplugin myplugin.desktop)

Esto producirá el archivo JSON myplugin.json, que puede ser referenciado desde las macros K_PLUGIN_FACTORY_WITH_JSON o Q_PLUGIN_METADATA.
