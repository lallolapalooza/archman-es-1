depdiagram-generate(1) Manual de Comandos Generales depdiagram-generate(1)

NOMBRE

depdiagram-generate - Herramientas de generación de documentación de API de KDE

VERSIÓN

5.13.0

USO

uso: depdiagram-generate [-h] [-o ARCHIVO] [--qt] [--detailed]
[--framework FRAMEWORK]
archivos_dot [archivos_dot ...]

argumentos posicionales:
archivos_dot

argumentos opcionales:
-h, --help muestra este mensaje de ayuda y sale
-o ARCHIVO, --output ARCHIVO
Salida a ARCHIVO
--qt Mostrar bibliotecas Qt
--detailed Mostrar objetivos dentro de frameworks
--framework FRAMEWORK
Mostrar solo dependencias del framework FRAMEWORK
