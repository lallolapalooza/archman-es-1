DESCRIPCIÓ

N

Esta es una herramienta sencilla para desarrolladores que encuentra referencias circulares en objetos y otros tipos de referencias. Debido a la gestión de memoria basada en conteo de referencias de Perl, las referencias circulares causarán fugas de

memoria.

EXPORTACI

ÓN

Las find_cycle() y find_weakened_cycle() subrutinas se exportan por

defecto.
find_cycle($object_reference,[$callback]
)
La función find_cycle() recorrerá la referencia del objeto e imprimirá un informe en STDOUT identificando cualquier ciclo de memoria que encuentre.

Si se proporciona una referencia de código de callback opcional, entonces este callback se invocará en cada ciclo que se encuentre. Al callback se le pasará una referencia de array que apunta a una lista de listas con el siguiente

formato: 
$arg = [ ['REFTYPE',$index,$reference,$reference_value],
         ['REFTYPE',$index,$reference,$reference_value],
         ['REFTYPE',$index,$reference,$reference_value],
          ...
]

Cada elemento en la referencia de array describe un borde en el ciclo de memoria. 'REFTYPE' describe el tipo de referencia y es uno de 'SCALAR', 'ARRAY' o 'HASH'. $index es el índice afectado por la referencia, y es undef para un escalar, un entero para una referencia de array, o una clave de hash para un hash. $reference es la referencia de memoria, y $reference_value es su valor desreferenciado. Por ejemplo, si el borde es un ARRAY, entonces la siguiente relación

se cumple: 
$reference->[$index] eq
$reference_value

El primer elemento de la referencia de array es el $object_reference que pasaste a find_cycle() y puede no estar directamente involucrado en el

ciclo.

Si una referencia es una referencia débil producida usando la función weaken() de Scalar::Util, entonc

es no contribui
rá a los ciclos.
find_weakened_cycle($object_reference,[$callback]
)
La función find_weakened_cycle() recorrerá la referencia del objeto e imprimirá un informe en STDOUT identificando cualquier ciclo de memoria que encuentre, incluyendo cualquier ciclo debilitado producido usando weaken() de Scalar::Util.

Si se proporciona una referencia de código de callback opcional, entonces este callback se invocará en cada ciclo que se encuentre. Al callback se le pasará una referencia de array que apunta a una lista de listas con el siguiente

formato: 
$arg = [ ['REFTYPE',$index,$reference,$reference_value,$is_weakened],
         ['REFTYPE',$index,$reference,$reference_value,$is_weakened],
         ['REFTYPE',$index,$reference,$reference_value,$is_weakened],
          ...
]

Cada elemento en la referencia de array describe un borde en el ciclo de memoria. 'REFTYPE' describe el tipo de referencia y es uno de 'SCALAR', 'ARRAY' o 'HASH'. $index es el índice afectado por la referencia, y es undef para un escalar, un entero para una referencia de array, o una clave de hash para un hash. $reference es la referencia de memoria, y $reference_value es su valor desreferenciado. $is_weakened es un booleano que especifica si la referencia está debilitada o no. Por ejemplo, si el borde es un ARRAY, entonces la siguiente relación

se cumple: 
$reference->[$index] eq
$reference_value

El primer elemento de la referencia de array es el $object_reference que pasaste a find_cycle() y puede n

o estar dire

volucrado e
n el ciclo.

Formatos de informe de

ciclos

El callback por defecto imprime un rastro de cada ciclo que encuentra. Puedes controlar el formato del rastro estableciendo la variable de paquete $Devel::Cycle::FORMATTING a uno de "raw," "cooked," o

"roasted".

El formato "raw" imprime referencias de memoria anónimas usando la nomenclatura estándar de ubicación de memoria de Perl. Por ejemplo, un objeto "Foo::Bar" que apunta a un hash ordinario aparecerá en el rastro

así: 
Foo::Bar=HASH(0x8124394)->{'phyllis'} =>
HASH(0x81b4a90)

El formato "cooked" (el por defecto), usa nombres cortos para ubicaciones de memoria anónimas, comenzando con "A" y avanzando con el operador mágico ++. Esto conduce a una presentación mucho más

legible: 
$Foo::Bar=B->{'phyllis'} =>
\%A

El formato "roasted" es similar al formato "cooked", excepto que las referencias de objetos se formatean ligeramente

diferente: 
$Foo::Bar::B->{'phyllis'} =>
\%A

Si una referencia es una referencia débil, entonces tendrá un 'w->' antepuesto,

así: 
w-> $Foo::Bar::B->{'phyllis'} =>
\%A

Para tu comodidad, $Devel::Cycle::FORMATTING se puede

importar: 
use Devel::Cycle qw(:DEFAULT $FORMATTING);
$FORMATTING =
'raw';

Alternativamente, puedes controlar el formateo en tiempo de compilación pasando una de las opciones -raw, -cooked, o -roasted a "use" como se ilustra

aquí: 
use Dev
el::Cycl
e -raw;

Referencias de código

(closures)

Si el módulo PadWalker está instalado, Devel::Cycle también informará ciclos en closures de código. Si PadWalker no está instalado y Devel::Cycle detecta una referencia CODE en una de las estructuras de datos, emitirá una advertencia (una vez por estructura de datos) de que no puede inspeccionar el CODE a menos que PadWalker esté disponible. Puedes desactivar esta advertencia pasando -quiet a Devel::Cycle en tiempo de

compilación: 
use De
vel::C
ycle -
quiet;
