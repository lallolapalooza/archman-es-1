DEFNCOPY(FreeTDS) FreeTDS (manual de referencia de freetds) DEFNCOPY(FreeTDS)

NOMBRE

defncopy — extrae procedimientos y vistas de un servidor Microsoft.

SINOPSIS

defncopy [-v] [-U nombre_usuario] [-P contraseña] [-S servidor] [-D base_de_datos] [-i archivo_entrada] [-o archivo_salida] [propietario.nombre_objeto [propietario.nombre_objeto ...]]

DESCRIPCIÓN

defncopy es un programa de utilidad distribuido con FreeTDS. Reemplaza a un programa similar del mismo nombre distribuido por Sybase.

defncopy lee el texto de un procedimiento almacenado o vista y escribe un script adecuado para recrear el procedimiento o vista. Para tablas, lee la salida de sp_help y construye una sentencia ‘CREATE TABLE’, completa con ‘CREATE INDEX’, también. propietario es opcional si usted o el propietario de la base de datos es el propietario del procedimiento/vista que se está copiando. nombre_objeto es el nombre del objeto del sistema que desea extraer.

OPCIONES

-U nombre_usuario
nombre de inicio de sesión del servidor de base de datos.
-P contraseña
contraseña del servidor de base de datos.
-S servidor
servidor de base de datos al que conectarse.
-D base_de_datos
base de datos a usar. Opcional si el procedimiento/vista que se está extrayendo está en su base de datos predeterminada.
-i archivo_entrada
un script para aplicar a la base de datos. Actualmente no implementado.
-o archivo_salida
un archivo para contener el script, por defecto es la salida estándar.
-v
Muestra información de versión y aviso de derechos de autor.

NOTAS

defncopy es un filtro; lee de la entrada estándar, escribe en la salida estándar y escribe errores en el error estándar. Las opciones -i, -o, y -e anulan estos valores predeterminados.

defncopy utiliza la API db-lib proporcionada por FreeTDS. Esta API está, por supuesto, también disponible para los desarrolladores de aplicaciones.

ESTADO DE SALIDA

defncopy sale con 0 en caso de éxito, y >0 si el servidor no puede procesar la consulta.

defncopy informará de cualquier error devuelto por el servidor, pero continuará procesando.

HISTORIA

defncopy apareció por primera vez en FreeTDS 0.63.

AUTORES

La utilidad defncopy fue escrita por James K. Lowden ⟨jklowden@schemamania.org.⟩

ERRORES

Solo funciona con servidores Microsoft y servidores Sybase antiguos. No crea claves primarias. Muchas opciones están definidas por Sybase que esta versión no implementa. Siéntase libre de corregir esta situación. En teoría, defncopy podría aplicar/producir DDL para cualquier objeto del sistema, pero en la actualidad solo se admiten tablas, procedimientos y vistas, y solo para extracción.
