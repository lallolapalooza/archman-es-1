NOMBRE

desmume - emulador de Nintendo DS

SINOPSIS

desmume [opciones] archivos...

DESCRIPCIÓN

Esta página del manual documenta brevemente el programa desmume

desmume es un emulador de Nintendo DS que ejecuta demos caseras y juegos comerciales.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

--carga-ranura=NUM
Carga la partida guardada de la ranura NUM
--opengl-2d
Habilita el uso de OpenGL para la renderización de pantalla
--conversion-software
Utiliza conversión de color por software durante la renderización de pantalla OpenGL. Puede producir tasas de fotogramas mejores o peores dependiendo del hardware.
--motor-3d=MOTOR
Selecciona la emulación 3D disponible:
0 = 3D deshabilitado
1 = Rastreador de software interno de desmume (por defecto)
2 = opengl de osmesa o gtkglext (si está disponible, dependiendo de las opciones de compilación, ver desmume --help)
--desactivar-sonido
Deshabilita la emulación de sonido
--desactivar-limitador
Deshabilita el limitador de 60 fps
--arm9gdb=NUM_PUERTO
Habilita el stub GDB de ARM9 en el puerto dado
--arm7gdb=NUM_PUERTO
Habilita el stub GDB de ARM7 en el puerto dado
--tipo-guardado=TIPO
Selecciona el tipo de guardado de lo siguiente:
0 = Autodetectar
1 = EEPROM 4 kbit
2 = EEPROM 64 kbit
3 = EEPROM 512 kbit
4 = FRAM 256 kbit
5 = FLASH 2 mbit
6 = FLASH 4 mbit
--fwlang=IDIOMA
Establece el idioma en el firmware, IDIOMA como sigue:
0 = Japonés
1 = Inglés
2 = Francés
3 = Alemán
4 = Italiano
5 = Español
--cflash=RUTA_IMAGEN_DISCO
Habilita la emulación de tarjeta flash compacta de imagen de disco GBAMP
-h, --ayuda
Muestra un resumen de las opciones.
-v, --version
Muestra la versión del programa.

ENTRADA

El cursor del ratón actúa como lápiz óptico, el clic del ratón reemplaza el toque del lápiz óptico.

El teclado se puede configurar y por defecto funciona de la siguiente manera:

F1-F10 carga partida guardada de la ranura 1-10
Shift+F1-F10 guarda partida en la ranura 1-10
Las flechas (no las del teclado numérico) actúan como D-pad
z = A
x = B
a = Y
s = X
q = L
w = R
Enter = START
Left Shift = SELECT
Backspace = LID

Desmume acepta eventos de joystick, que pueden ser configurados por el usuario.
