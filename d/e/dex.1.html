NOMBRE

dex - Ejecución de DesktopEntry

SINOPSIS

dex [opciones] [ArchivoDesktopEntry]...

DESCRIPCIÓN

dex, DesktopEntry Execution, es un programa para generar y ejecutar archivos DesktopEntry de tipo Application.

OPCIONES

-h, --help
Mostrar este mensaje de ayuda y salir
-a, --autostart
Iniciar programas automáticamente
-c RUTA, --create RUTA
Crear un archivo DesktopEntry para el programa en la ruta dada. Un segundo argumento opcional se utiliza para especificar el nombre del archivo DesktopEntry creado, o especificar el nombre del archivo - para imprimir el archivo en la salida estándar. Por defecto, se crea un nuevo archivo con la extensión .desktop.
-d, --dry-run
Ejecución de prueba, no ejecutar ningún comando
-e ENTORNO, --environment ENTORNO
Especificar el Entorno de Escritorio para el cual se realizará el inicio automático; solo funciona en combinación con --autostart
-s RUTASDEBUSQUEDA, --search-paths RUTASDEBUSQUEDA
Lista separada por dos puntos de rutas para buscar archivos de escritorio, reemplazando la lista de búsqueda predeterminada
-t DIRECTORIO, --target-directory DIRECTORIO
Crear archivos en el directorio de destino
--term TERM
El emulador de terminal que se utilizará para ejecutar el programa si se establece Terminal=true en el archivo de escritorio, por defecto es x-terminal-emulator
-w, --wait
Bloquear hasta que el programa finalice
--test
Realizar una autocomprobación
-v, --verbose
Salida detallada
-V, --version
Mostrar información de la versión

EJEMPLOS

Realizar inicio automático/ejecución de todos los programas en las carpetas de inicio automático.

dex -a

Realizar inicio automático/ejecución de todos los programas en las carpetas especificadas.

dex -a -s /etc/xdg/autostart/:~/.config/autostart/

Previsualizar los programas que se ejecutarían en un inicio automático normal.

dex -ad

Previsualizar los programas que se ejecutarían en un inicio automático específico de GNOME.

dex -ad -e GNOME

Crear un DesktopEntry para un programa en el directorio actual.

dex -c /usr/bin/skype

Crear un DesktopEntry para un programa en el directorio de inicio automático.

dex -t ~/.config/autostart -c /usr/bin/skype /usr/bin/nm-applet

Ejecutar un solo programa desde la línea de comandos y habilitar la salida detallada.

dex -v skype.desktop

Ejecutar un solo programa (con Terminal=true en el archivo de escritorio) en gnome-terminal.

dex --term gnome-terminal nvim.desktop

Ejecutar un solo programa y bloquear hasta que finalice.

dex --wait nvim.desktop
