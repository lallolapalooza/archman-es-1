DELUGE-WEB(1) Manual de comandos generales DELUGE-WEB(1)

NOMBRE

deluge-web - Interfaz web del cliente BitTorrent

SINOPSIS

deluge-web [opciones]

DESCRIPCIÓN

Deluge utiliza un modelo cliente/servidor, con deluged siendo el proceso demonio y deluge-web se utiliza para lanzar una interfaz de usuario web basada en ajax.

Por defecto, deluge-web se ejecutará como un demonio en segundo plano. Utilice la opción -d para ejecutar el proceso en primer plano.

La contraseña por defecto es deluge y sirve a la página web http://localhost:8112.

OPCIONES

Opciones de configuración

-c ruta, --config=ruta
Establece la ubicación del directorio de configuración.

Opciones web

-i direccion_ip, --interface=direccion_ip
Dirección IP en la que el servidor web escuchará.
-p puerto, --port=puerto
Puerto en el que el servidor web escuchará.
-b ruta, --base=ruta
Establece la ruta base en la que se está ejecutando la interfaz web (proxy).
--ssl
Fuerza al servidor web a usar ssl.
--no-ssl
Fuerza al servidor web a deshabilitar ssl.

Opciones de registro

-l archivo, --logfile=archivo
Escribe en el archivo de registro especificado en lugar de la salida estándar.
-L nivel_registro, --loglevel=nivel_registro
Establece el nivel de registro (el valor predeterminado es error): none, info, warning, error, debug.
-q, --quiet
Establece el nivel de registro en none, igual que -L none.
--logrotate[=tamaño_máx]
Habilita la rotación del archivo de registro, con un tamaño máximo opcional del archivo, por defecto: 2M (El número de rotaciones del archivo de registro es 5).
--profile[=archivo]
Realiza un perfil con cProfile. Se escribe en la salida estándar a menos que se especifique un nombre de archivo.

Opciones de control de proceso:

-P archivo, --pidfile=archivo
Archivo PID para almacenar el ID del proceso.
-d, --do-not-daemonize
No demonizar (hacer fork) este proceso.
-U, --user=usuario
Cambiar a este usuario al inicio (requiere root).
-g, --group=grupo
Cambiar a este grupo al inicio (requiere root).

Opciones de ayuda

-V, --version
Mostrar el número de versión del programa y salir.
-h, --help
Mostrar el mensaje de ayuda y salir.
