Devel::Cover::Web(3) Documentación de Perl aportada por usuarios Devel::Cover::Web(3)

NOMBRE

Devel::Cover::Web - Archivos para JavaScript o CSS

VERSIÓN

versión 1.51

SINOPSIS

use Devel::Cover::Web "write_file";
write_file $directorio, $archivo;
write_file $directorio, "all";
write_file $directorio, "js";
write_file $directorio, "css";

DESCRIPCIÓN

Este módulo permite escribir archivos JavaScript y CSS en un directorio especificado.

SUBRUTINAS

write_file($directorio, $archivo)

Escribe el archivo especificado en el directorio especificado.
