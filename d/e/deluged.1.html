NOMBRE

deluged - Un cliente BitTorrent demonio

SINOPSIS

deluged [opciones]

DESCRIPCIÓN

Deluge utiliza un modelo cliente/servidor, con deluged siendo el proceso demonio y deluge usándose para lanzar una interfaz de usuario.

Por defecto, deluged se ejecutará como un demonio en segundo plano. Usa la opción -d para ejecutar el proceso en primer plano.

OPCIONES

Opciones de configuración

-c ruta, --config=ruta
Establece la ubicación del directorio de configuración.

Opciones de demonio

-p puerto, --port=puerto
Puerto en el que escuchará el demonio, por defecto es 58846
-i dirección_ip, --interface=dirección_ip
Interfaz en la que el demonio escuchará las conexiones de bittorrent, esta debe ser una dirección IP
-u dirección_ip, --ui-interface=dirección_ip
Interfaz en la que el demonio escuchará las conexiones de la UI, esta debe ser una dirección IP

Opciones de registro de eventos

-l archivo, --logfile=archivo
Salida al archivo de registro especificado en lugar de stdout
-L nivel_log, --loglevel=nivel_log
Establece el nivel de registro (por defecto es error): none, info, warning, error, debug
-q, --quiet
Establece el nivel de registro a none, igual que -L none
--logrotate[=tamaño-máximo]
Habilita la rotación del archivo de registro, con un tamaño máximo opcional del archivo de registro, por defecto: 2M (El número de rotaciones del archivo de registro es 5)
--profile[=archivo]
Perfilado con cProfile. La salida es a stdout a menos que se especifique un nombre de archivo.

Opciones de control de procesos:

-P archivo, --pidfile=archivo
Archivo PID para almacenar el ID del proceso
-d, --do-not-daemonize
No demonizar (forkear) este proceso
-U, --user=usuario
Cambiar a este usuario al iniciar (Requiere root)
-g, --group=grupo
Cambiar a este grupo al iniciar (Requiere root)

Opciones de ayuda

-V, --version
Mostrar el número de versión del programa y salir.
-h, --help
Mostrar mensaje de ayuda y salir.
