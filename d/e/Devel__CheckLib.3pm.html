Devel::CheckLib es un módulo de perl que

SINOPSI

S 
use Devel::CheckLib;
check_lib_or_exit( lib => 'jpeg', header => 'jpeglib.h' );
check_lib_or_exit( lib => [ 'iconv', 'jpeg' ] );

CÓMO

FUNCIONA

Se pasan parámetros con nombre a una función, describiéndole cómo compilar y enlazar con las

bibliotecas.

Funciona intentando compilar algo de código - que por defecto es

esto: 
int main(int argc, char *argv[]) { return 0;
}

y enlazándolo con las bibliotecas especificadas. Si sale algo por el final que parece ejecutable, se ejecuta, y si main() devuelve 0 sabemos que funcionó. Ese pequeño programa se compila una vez por cada biblioteca que especifique, y (sin enlazar) una vez por cada archivo de

cabecera.

Si desea comprobar la presencia de funciones particulares en una biblioteca, o incluso que esas funciones devuelvan resultados particulares, entonces puede pasar su propio cuerpo de función para main()

así: 
check_lib_or_exit(
    function => 'foo();if(libversion() > 5) return 0; else return 1;'
    incpath  => ...
    libpath  => ...
    lib      => ...
    header   => ...
)
;

En ese caso, fallará al compilar si foo() o libversion() no existen, y main() devolverá el valor incorrecto si el valor de retorno de libve

rsion() no es
el que desea.

check_lib_or_exi

t

Se comporta exactamente igual que assert_lib() excepto que en lugar de morir, emite una advertencia (con exactamente el mismo mensaje de error) y sale. Esto está destinado a usarse en Makefile.PL / Build.PL cuando podría querer preguntar al usuario por varias rutas y cosas antes de comprobar que lo que le ha dicho es

correcto.

Si falta alguna biblioteca o cabecera, sale con un valor de salida de 0 para evitar

causar un informe 'FAIL' de CPAN Testers. CPAN Testers debería ignorar este resultado
-- que es lo que desea si una dependencia de biblioteca externa no está disponible.
