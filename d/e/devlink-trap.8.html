DEVLINK-TRAP(8) Linux DEVLINK-TRAP(8)

NOMBRE

devlink-trap - configuración de trampas devlink

SINOPSIS


devlink [ OPCIONES ] trap { COMANDO | help }

OPCIONES := { -v[erbose] | -s[tatistics] }

devlink trap show [ DEV trap TRAP ]

devlink trap set DEV trap TRAP [ action { trap | drop | mirror } ]

devlink trap group show [ DEV group GROUP ]

devlink trap group set DEV group GROUP [ action { trap | drop | mirror } ]
[ policer POLICER ] [ nopolicer ]

devlink trap policer set DEV policer POLICER [ rate RATE ] [ burst BURST ]

devlink trap help

DESCRIPCIÓN

devlink trap show - mostrar trampas de paquetes disponibles y sus atributos

DEV - especifica el dispositivo devlink del cual mostrar las trampas de paquetes. Si este argumento se omite, se listarán todas las trampas de paquetes de todos los dispositivos.

trap TRAP - especifica la trampa de paquetes. Solo aplicable si también se especifica un dispositivo devlink.

devlink trap set - establecer atributos de una trampa de paquetes

DEV - especifica el dispositivo devlink al que pertenece la trampa de paquetes.

trap TRAP - especifica la trampa de paquetes.

action { trap | drop | mirror }
acción de la trampa de paquetes.

trap - la única copia del paquete se envía a la CPU.

drop - el paquete es descartado por el dispositivo subyacente y no se envía una copia a la CPU.

mirror - el paquete es reenviado por el dispositivo subyacente y se envía una copia a la CPU.

devlink trap group show - mostrar grupos de trampas de paquetes disponibles y sus atributos

DEV - especifica el dispositivo devlink del cual mostrar los grupos de trampas de paquetes. Si este argumento se omite, se listarán todos los grupos de trampas de paquetes de todos los dispositivos.

group GROUP - especifica el grupo de trampas de paquetes. Solo aplicable si también se especifica un dispositivo devlink.

devlink trap group set - establecer atributos de un grupo de trampas de paquetes

DEV - especifica el dispositivo devlink al que pertenece el grupo de trampas de paquetes.

group GROUP - especifica el grupo de trampas de paquetes.

action { trap | drop | mirror }
acción de la trampa de paquetes. La acción se establece para todas las trampas de paquetes miembros del grupo de trampas. Las acciones de las trampas que no son de descarte no se pueden cambiar y, por lo tanto, se omiten.
policer POLICER
policía de trampas de paquetes. La policía a vincular al grupo de trampas de paquetes. Un valor de "0" desvinculará la policía actualmente vinculada.
nopolicer
Desvincular la policía de trampas de paquetes del grupo de trampas de paquetes.

devlink trap policer set - establecer atributos de la policía de trampas de paquetes

DEV - especifica el dispositivo devlink al que pertenece la policía de trampas de paquetes.

policer POLICER - especifica la policía de trampas de paquetes.

rate RATE - velocidad de la policía de trampas de paquetes en paquetes por segundo.

burst BURST - tamaño de ráfaga de la policía de trampas de paquetes en paquetes.

EJEMPLOS

devlink trap show

Muestra las trampas de paquetes disponibles.

devlink trap group show

Muestra los grupos de trampas de paquetes disponibles.

devlink -vs trap show pci/0000:01:00.0 trap source_mac_is_multicast

Muestra los atributos y estadísticas de una trampa de paquetes específica.

devlink -s trap group show pci/0000:01:00.0 group l2_drops

Muestra los atributos y estadísticas de un grupo de trampas de paquetes específico.

devlink trap set pci/0000:01:00.0 trap source_mac_is_multicast action trap

Establece la acción de una trampa de paquetes específica en 'trap'.

devlink trap policer show

Muestra las policías de trampas de paquetes disponibles.

devlink -s trap policer show pci/0000:01:00.0 policer 1

Muestra los atributos y estadísticas de una policía de trampas de paquetes específica.

devlink trap policer set pci/0000:01:00.0 policer 1 rate 1000 burst 128

Establece la velocidad y el tamaño de ráfaga de una policía de trampas de paquetes específica.
