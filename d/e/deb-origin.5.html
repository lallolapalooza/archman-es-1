NOMBRE

deb-origin - Archivos de información específicos del proveedor

SINOPSIS

/etc/dpkg/origins/nombre_archivo

DESCRIPCIÓN

Los archivos en /etc/dpkg/origins pueden proporcionar información sobre varios proveedores que están proporcionando paquetes Debian. Estos archivos se utilizan normalmente tanto para determinar el comportamiento de las herramientas y el contenido resultante durante la creación de paquetes dirigidos a un proveedor específico, como para describir la procedencia de los paquetes.

Los paquetes pueden declarar explícitamente su proveedor incluyendo un campo Origin; de lo contrario, se asume que el proveedor de un paquete sin dicho campo es el señalado por el enlace simbólico de origen *predeterminado*.

Contienen una serie de campos, o comentarios cuando la línea comienza con ‘#’. Cada campo comienza con una etiqueta, como Vendor o Parent, seguida de dos puntos y el cuerpo del campo. Los campos están delimitados únicamente por las etiquetas de campo. En otras palabras, el texto del campo puede tener varias líneas de longitud, pero las herramientas unirán las líneas al procesar el cuerpo del campo.

El archivo debe nombrarse según el nombre del proveedor. La convención habitual es nombrar el archivo del proveedor utilizando el nombre del proveedor en minúsculas, pero se permiten algunas variaciones.

Específicamente (desde dpkg 1.21.10), primero, los caracteres no alfanuméricos (‘[^A-Za-z0-9]’) se mapean a guiones (‘-’), luego el nombre resultante se intentará en secuencia convirtiéndolo a minúsculas, manteniéndolo tal cual, convirtiéndolo a minúsculas y luego capitalizándolo (es decir, poniendo en mayúscula el primer carácter), y solo capitalizándolo.

CAMPOS

Vendor: nombre-del-proveedor (requerido)
El valor de este campo determina el nombre del proveedor.
Vendor-URL: url-del-proveedor
El valor de este campo determina la URL del proveedor.
Bugs: url-de-errores
El valor de este campo determina el tipo y la dirección del sistema de seguimiento de errores utilizado por este proveedor. Puede ser una URL mailto o una URL de debbugs (por ejemplo, debbugs://bugs.debian.org/).
Parent: nombre-del-proveedor
El valor de este campo determina el nombre del proveedor del que deriva este proveedor.

EJEMPLO

Vendor: Debian
Vendor-URL: https://www.debian.org/
Bugs: debbugs://bugs.debian.org
