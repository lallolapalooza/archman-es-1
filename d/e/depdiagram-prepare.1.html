NOMBRE

depdiagram-prepare - Generar archivos dot de Graphviz para uno o todos los frameworks

VERSIÓN

5.13.0

USO

uso: depdiagram-prepare [-h] (-s DIR | -a BASE_DIR) dot_dir

argumentos posicionales:
dot_dir Directorio de destino donde se generarán los archivos dot

argumentos opcionales:
-h, --help mostrar este mensaje de ayuda y salir
-s DIR, --single DIR Generar archivos dot para el framework almacenado en DIR
-a BASE_DIR, --all BASE_DIR
Generar archivos dot para todos los frameworks cuyo directorio esté en
BASE_DIR
