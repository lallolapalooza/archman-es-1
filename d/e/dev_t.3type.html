dev_t(3type) dev_t(3type)

NOMBRE

dev_t - ID de dispositivo

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <sys/types.h>
typedef /* ... */  dev_t;

DESCRIPCIÓN

Se utiliza para IDs de dispositivos. Es un tipo de dato entero. Para más detalles sobre este tipo, véase makedev(3).

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

NOTAS

La siguiente cabecera también proporciona este tipo: <sys/stat.h>.

VER TAMBIÉN

mknod(2), stat(3type)
