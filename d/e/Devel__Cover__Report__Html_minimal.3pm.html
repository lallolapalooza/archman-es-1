NOMBRE

Devel::Cover::Report::Html_minimal - Backend HTML para Devel::Cover

VERSIÓN

versión 1.51

SINOPSIS

cover -report html_minimal

DESCRIPCIÓN

Este módulo proporciona un mecanismo de reporte HTML para datos de cobertura. Está diseñado para ser llamado desde el programa "cover".

Basado en un original de Paul Johnson, la salida fue grandemente mejorada por Michael Carman (mjcarman@mchsi.com).

OPCIONES

Las opciones se especifican añadiendo las banderas apropiadas al programa "cover". Este formato de reporte soporta lo siguiente:

outputfile
Especifica el nombre del archivo de salida principal. El valor por defecto es coverage.html. Especifique index.html si solo desea publicar todo el directorio.
pod
Incluye POD (y líneas en blanco) en el reporte del archivo. Esto está activado por defecto. Puede ser desactivado con -nopod.
data
Incluye texto después de los tokens "__DATA__" o "__END__" en el reporte del archivo. Por defecto, este texto se trunca.

Nota: Si su POD está después de un "__END__", debe especificar 'data' para incluirlo, no 'pod'. La opción 'pod' solo se aplica al POD antes del "__END__".

unified
Genera un reporte "unificado" para cada archivo. Los datos detallados que normalmente aparecen en los reportes auxiliares (ramas, condiciones, etc.) se colocan en el reporte del archivo, y no se generan los reportes auxiliares.
summarytitle
Especifica el título del resumen. El valor por defecto es "Coverage Summary".
