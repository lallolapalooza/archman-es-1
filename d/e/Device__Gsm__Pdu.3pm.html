Device::Gsm::Pdu(3) Documentación de Perl contribuida por el usuario Device::Gsm::Pdu(3)

NOMBRE

Device::Gsm::Pdu - biblioteca para gestionar datos codificados en PDU para mensajería GSM

ADVERTENCIA

Este es software C<BETA>, todavía necesita pruebas extensivas y
soporte para comandos GSM personalizados, ¡así que úselo bajo su propio riesgo,
y sin C<NINGUNA> garantía! Diviértete.

AVISO

Este módulo está destinado a ser utilizado internamente por la clase C<Device::Gsm>,
así que probablemente no querrás usarlo directamente.

SINOPSIS

use Device::Gsm::Pdu;
# DA es la dirección de destino
$DA = Device::Gsm::Pdu::encode_address('+39347101010');
$numero = Device::Gsm::Pdu::decode_address( $DA );
# Codificar texto de 7 bits para enviar mensajes
$texto = Device::Gsm::Pdu::encode_text7('hola');

DESCRIPCIÓN

El módulo "Device::Gsm::Pdu" incluye algunas funciones básicas para tratar con SMS en modo PDU, como codificar direcciones GSM (números de teléfono) y, por ahora solo, texto de 7 bits.

FUNCIONES

decode_address( direccion_codificada_pdu )

Toma una dirección codificada en PDU y la decodifica en un número de móvil legible por humanos. Si el tipo de número es internacional, el resultado se antepondrá con un signo `+'.

Claramente, está destinada a ser una función interna.

Ejemplo

print Device::Gsm::Pdu::decode_address( '0B919343171010F0' );
# imprime `+39347101010';

encode_address( numero_movil )

Toma un número de móvil y lo codifica como DA (dirección de destino). Si comienza con un `+' , como en `+39328101010', se trata como un número internacional.

Ejemplo

print Device::Gsm::Pdu::encode_address( '+39347101010' );
# imprime `0B919343171010F0'

encode_text7( cadena_de_texto )

Codifica una cadena de texto ASCII en formato PDU de 7 bits, incluyendo un byte de encabezado que indica que la longitud está en septetos. Este es el único modo 100% compatible para codificar texto.

Ejemplo

print Device::Gsm::Pdu::encode_text7( 'holahola' );
# imprime `0AE832...'

pdu_to_latin1($pdu)

Convierte un PDU (sin el octeto de longitud inicial) a una cadena latin1.

Ejemplo

my $pdu = 'CAFA9C0E0ABBDF7474590E8296E56C103A3C5E97E5';
print Device::Gsm::Pdu::pdu_to_latin1($pdu);
# imprime `Just another Perl hacker'

latin1_to_pdu($texto)

Convierte una cadena de texto en codificación latin1 (ISO-8859-1) a una cadena PDU.

Ejemplo

my $text = "Just another Perl hacker";
print Device::Gsm::Pdu::latin1_to_pdu($text);
# imprime `CAFA9C0E0ABBDF7474590E8296E56C103A3C5E97E5'
