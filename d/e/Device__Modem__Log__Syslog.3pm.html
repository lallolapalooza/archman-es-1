Device::Modem::Log::Syslog(3) Documentación de Perl contribuida por el usuario Device::Modem::Log::Syslog(3)

NOMBRE

Device::Modem::Log::Syslog - Plugin de registro syslog para la clase Device::Modem

SINOPSIS

use Device::Modem;
my $box = Device::Modem->( log => 'syslog', ... );
...

DESCRIPCIÓN

Clase de registro de ejemplo para Device::Modem que registra toda la actividad del módem, comandos, ... en syslog.

Se carga automáticamente al inicio de Device::Modem, solo si especifica el valor "syslog" para el parámetro "log".

Si no tiene instalado el módulo adicional Sys::Syslog, no podrá usar este plugin de registro y será mejor que deje el registro por defecto (en un archivo de texto).

REQUIERE

"Sys::Syslog"

EXPORTA

Ninguno
