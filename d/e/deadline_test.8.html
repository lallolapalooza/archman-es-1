NOMBRE

deadline_test - Programa de prueba de alta resolución

DESCRIPCIÓN

Este programa se utiliza para probar el planificador de fechas límite (tareas SCHED_DEADLINE).

SINOPSIS

deadline_test [ -hb ] [ -c CPUSET ] [ -i INTV ] [ -p PERCENT ] [ -P PERCENT ] [ -r PRIO ] [ -s STEP ] [ -t NUM ]

OPCIONES

-b
Enlaza a la última CPU. (atajo para -c <última cpu>)
-c CPUSET
Lista de CPUs separadas por comas o guiones donde ejecutar las tareas de fecha límite.
-h
Mostrar este menú de ayuda.
-i INTV
La fecha límite más corta para las tareas.
-p PERCENT
El porcentaje de ancho de banda a utilizar (1-90%).
-P PERCENT
El porcentaje del tiempo de ejecución para completar la ejecución (por defecto 100%).
-r PRIO
Añade una tarea RT con la prioridad dada para estresar el sistema.
-s STEP
La cantidad a incrementar la fecha límite para cada tarea en us (por defecto 500us).
-t NUM
El número de hilos a ejecutar como fecha límite (por defecto 1).
