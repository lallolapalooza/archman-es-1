NOMBRE

Devel::SelfStubber - generar stubs para un módulo SelfLoading

SINOPSIS

Para generar solo los stubs:

use Devel::SelfStubber;
Devel::SelfStubber->stub('NOMBRE_MODULO','MI_DIR_LIB');

o para generar todo el módulo con los stubs insertados correctamente

use Devel::SelfStubber;
$Devel::SelfStubber::SOLO_STUBS=0;
Devel::SelfStubber->stub('NOMBRE_MODULO','MI_DIR_LIB');

NOMBRE_MODULO es el nombre del módulo Perl, por ejemplo, Devel::SelfStubber, NO 'Devel/SelfStubber' ni 'Devel/SelfStubber.pm'.

MI_DIR_LIB por defecto es '.' si no se especifica.

DESCRIPCIÓN

Devel::SelfStubber imprime los stubs que necesitas colocar en el módulo antes del token __DATA__ (o puede hacer que imprima el módulo completo con los stubs colocados correctamente). Los stubs aseguran que si se llama a un método, este se cargará. Son necesarios específicamente para métodos heredados que se cargan automáticamente.

Esto se explica mejor con el siguiente ejemplo:

Supongamos cuatro clases, A, B, C y D.

A es la clase raíz, B es una subclase de A, C es una subclase de B, y D es otra subclase de A.

    A
   / \
  B   D
 /
C

Si D llama a un método autoloaded 'foo' que está definido en la clase A, entonces el método se carga en la clase A, y luego se ejecuta. Si C luego llama al método 'foo', y ese método fue re implementado en la clase B, pero configurado para cargarse automáticamente, entonces el mecanismo de búsqueda nunca llega al mecanismo AUTOLOAD en B porque primero encuentra el método ya cargado en A, y por lo tanto usa erróneamente ese. Si el método foo hubiera sido stubbed en B, entonces el mecanismo de búsqueda habría encontrado el stub, y correctamente cargado y utilizado la subrutina de B.

Por lo tanto, para que las clases y subclases tengan una herencia que funcione correctamente con la carga automática, debes asegurarte de que se carguen los stubs.

El SelfLoader puede cargar stubs automáticamente en la inicialización del módulo con la declaración 'SelfLoader->load_stubs();', pero puede que desees evitar la sobrecarga de carga de stubs asociada con tu inicialización (aunque ten en cuenta que el método SelfLoader::load_stubs se llamará tarde o temprano - como muy tarde cuando se esté cargando la primera sub). En este caso, puedes poner los stubs de las subs antes del token __DATA__. Esto se puede hacer manualmente, pero este módulo permite la generación automática de los stubs.

Por defecto, solo imprime los stubs, pero puedes establecer la variable global $Devel::SelfStubber::SOLO_STUBS a 0 y imprimirá todo el módulo con los stubs posicionados correctamente.

Como mínimo, esto es útil para ver qué considera el SelfLoader que son stubs - para asegurar que las futuras versiones del SelfStubber permanezcan en sintonía con el SelfLoader, el SelfStubber utiliza realmente el SelfLoader para determinar qué stubs se necesitan.
