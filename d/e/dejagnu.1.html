DEJAGNU(1) Manual General de Comandos (urm) DEJAGNU(1)

NOMBRE

dejagnu — Lanzador de comandos auxiliares de DejaGnu

SINOPSIS

dejagnu ⟨comando⟩ [--help | opciones...]

dejagnu --help

dejagnu --version

DESCRIPCIÓN

El comando dejagnu busca un script que implemente el comando solicitado, selecciona entre múltiples implementaciones si están disponibles según una lista interna fija, y ejecuta el comando.

OPCIONES

--help
Imprime un mensaje de ayuda en lugar de ejecutar un comando. Si no se proporciona ningún comando, imprime el uso breve para el propio dejagnu.
-V, --version
Imprime un banner de versión para el propio lanzador, incluyendo la versión de DejaGnu. Se ignora cualquier comando proporcionado.
-v, --verbose
Emite salida adicional que describe la operación del propio lanzador dejagnu. Esta opción también se pasa al comando invocado.

Todos los argumentos después del nombre del comando se pasan al comando invocado.

ENTORNO

DEJAGNULIBS
Si está configurado, la ubicación de la biblioteca de DejaGnu en el sistema de archivos. La búsqueda descrita en ARCHIVOS no se realiza si DEJAGNULIBS está configurado.
AWK
Nombre completo del archivo para un intérprete Awk que puede o no ser realmente GNU Awk. Si no está configurado, se buscará en PATH un programa awk. Si el intérprete Awk es realmente GNU Awk, se le dará la opción --posix si se utiliza una implementación de Awk.
GAWK
Nombre completo del archivo para GNU Awk. Si no está configurado, se buscará en PATH un programa gawk.
BASH
Nombre completo del archivo para GNU Bash. Si no está configurado, se buscará en PATH un programa bash. Tenga en cuenta que Bash establece esta variable, incluso cuando se ejecuta como sh, incluso cuando ejecuta un script.
EXPECT
Nombre completo del archivo para Expect, que es un intérprete Tcl con la extensión Expect ya cargada. Si no está configurado, se buscará en PATH un programa expect. Tenga en cuenta que el núcleo de DejaGnu está escrito en Expect, por lo que este intérprete siempre debería estar disponible.
TCLSH
Nombre completo del archivo para un intérprete Tcl. Si no está configurado, se buscará en PATH un programa tclsh.

Tenga en cuenta que GNU Awk se considera un superconjunto de Awk y que Expect se considera un superconjunto de Tcl, lo que permite usar el primero para ejecutar scripts escritos para el segundo. Esto significa que, aunque los programas Awk generalmente se ejecutarán con las extensiones de GNU deshabilitadas utilizando la opción --posix de GNU Awk, los programas Tcl pueden ejecutarse con tclsh o expect y deben escribirse en consecuencia.

ARCHIVOS

$DEJAGNULIBS/commands
Si DEJAGNULIBS está configurado, se espera que todos los scripts de comandos estén en este directorio.

De lo contrario, se utiliza el primer directorio que exista en la siguiente lista, donde @bindir@ representa el directorio que contiene el propio dejagnu.

  • @bindir@/../share/dejagnu/commands
  • @bindir@/../../share/dejagnu/commands
  • /usr/share/dejagnu/commands
  • /usr/local/share/dejagnu/commands

VER TAMBIÉN

La documentación completa de DejaGnu se mantiene como un manual de Texinfo. Si el programa info está correctamente instalado en su sitio, el comando info dejagnu debería darle acceso al manual completo.

AUTORES

Jacob Bachmeyer

ERRORES

El nombre del comando debe preceder a todos los demás argumentos debido a las limitaciones del shell.
