delete(n)

Paquete: tcl

Licencias: TCL

delete(n) [incr Tcl] delete(n)

NOMBRE

itcl::delete - eliminar elementos en el intérprete

SINOPSIS

itcl::delete opción ?arg arg ...?

DESCRIPCIÓN

El comando delete se utiliza para eliminar elementos en el intérprete. Está implementado como un conjunto, por lo que las extensiones pueden añadir sus propias opciones y extender el comportamiento de este comando. Por defecto, el comando delete se encarga de la destrucción de los espacios de nombres.

El argumento opción determina qué acción se lleva a cabo por el comando. Las opciones legales (que pueden abreviarse) son:

eliminar clase nombre ?nombre...?
Elimina una o más clases de [incr Tcl] llamadas nombre. Esto elimina todos los objetos de la clase y también todas las clases derivadas.

Si se produce un error al destruir un objeto, impedirá la destrucción de la clase y de cualquier objeto restante. Para destruir toda la clase sin tener en cuenta los errores, utilice el comando "eliminar espacio de nombres".

eliminar objeto nombre ?nombre...?
Elimina uno o más objetos de [incr Tcl] llamados nombre. Un objeto se elimina invocando todos los destructores de su jerarquía de clases, en orden de más específico a menos específico. Si todos los destructores tienen éxito, se eliminan los datos asociados al objeto y se elimina el nombre como comando del intérprete.

Si el comando de acceso a un objeto reside en otro espacio de nombres, entonces se puede utilizar su nombre calificado:

itcl::delete object foo::bar::x

Si se produce un error al destruir un objeto, el comando delete se interrumpe y el objeto permanece activo. Para destruir un objeto sin tener en cuenta los errores, utilice el comando "rename" para destruir el comando de acceso al objeto.

eliminar espacio de nombres nombre ?nombre...?
Elimina uno o más espacios de nombres llamados nombre. Esto elimina todos los comandos y variables del espacio de nombres, y también elimina todos los espacios de nombres hijos. Cuando se elimina un espacio de nombres, se elimina automáticamente de las listas de importación de todos los demás espacios de nombres.
