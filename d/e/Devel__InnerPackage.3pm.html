Devel::InnerPackage(3) Documentación de Perl Contribuida por el Usuario Devel::InnerPackage(3)

NOMBRE

Devel::InnerPackage - encontrar todos los paquetes internos de un paquete

SINOPSIS

use Foo::Bar;
use Devel::InnerPackage qw(list_packages);
my @inner_packages = list_packages('Foo::Bar');

DESCRIPCIÓN

Dado un archivo como este

package Foo::Bar;
sub foo {}
package Foo::Bar::Quux;
sub quux {}
package Foo::Bar::Quirka;
sub quirka {}
1;

entonces

list_packages('Foo::Bar');

devolverá

Foo::Bar::Quux
Foo::Bar::Quirka

MÉTODOS

list_packages <nombre paquete>

Devuelve una lista de todos los paquetes internos de ese paquete.
