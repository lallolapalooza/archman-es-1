NOMBRE

Devel::PatchPerl::Hints - archivos 'hints' de reemplazo

VERSIÓN

versión 2.14

SINOPSIS

use Devel::PatchPerl::Hints;
if ( my $content = Devel::PatchPerl::Hints->hint_file() ) {
  chmod 0644, 'hints/netbsd.sh' or die "$!";
  open my $hints, '>', 'hints/netbsd.sh' or die "$!";
  print $hints $content;
  close $hints;
}
# Obtener una lista de OS para los que tenemos hints
my @os = Devel::PatchPerl::Hints->hints();

DESCRIPCIÓN

A veces hay un problema con el archivo de "hints" de Perl para un puerto de perl en particular. Este módulo proporciona archivos de "hints" corregidos codificados usando "MIME::Base64".

FUNCIÓN

La función se exporta, pero debe ser importada implícitamente en el paquete solicitante.

use Devel::PatchPerl::Hints qw[hint_file];

También puede ser llamada como un método de clase:

use Devel::PatchPerl::Hints;
my $content = Devel::PatchPerl::Hints->hint_file();
"hint_file"
Toma un argumento opcional que es el nombre del OS (como lo devolvería $^O). Por defecto, usará $^O.

En un contexto escalar, devolverá el contenido decodificado del archivo "hints" adecuado para escribir directamente en un manejador de archivo, o `undef` si no hay un archivo "hints" aplicable para el OS dado o derivado.

Si se llama en un contexto de lista, devolverá una lista. El primer elemento será el nombre del archivo "hints" que necesitará ser modificado, el segundo elemento será una cadena con el contenido decodificado del archivo "hints" adecuado para escribir directamente en un manejador de archivo. De lo contrario, se devolverá una lista vacía.

"hints"
No toma argumentos, devuelve una lista de nombres de OS para los cuales hay archivos "hints".
