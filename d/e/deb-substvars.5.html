Los nombres de variables consisten en alfanuméricos(a-zA-Z0-9), guiones (-) y dos puntos (:) y comienzan con un alfanumérico, y distinguen entre mayúsculas y minúsculas, aunque puedan referirse a otras entidades que sí preservan mayúsculas. Las sustitucio

Eloperador = asigna una variable de sustitución normal, el operador ?= (desde dpkg 1.21.8) asigna una variable de sustitución opcional que no emitirá advertencias incluso si no se usa, y el operador != (desde dpkg 1.22.7) asigna una variable de sustitución requerida que generará un error si no se usa. Se ignoran los espacios en blanco al final de cada línea, las líneas en blanco y las líneas que comienzan con un símbolo #

Sustitución

Las

variables se pueden establecer usando la opción común -V. También se pueden especificar en el archivo debian/substvars (o en cualquier otro archivo especificado usando la opción

común

-T). Después de que se hayan realizado todas las sustituciones, cada ocurrencia de la cadena ${} (que no es una variable de sustitución real) se reemplaza con un signo $. Esto se puede usar como una secuencia de escape,como ${}{ VARIABLE } que terminará como${VARIABLE } en la

salida.

Si se hace referencia a una variable pero no está definida, genera una advertencia y se asume un

valor

vacío. Aunque se realiza la sustitución de variables en todos los campos de control, algunos de esos campos se usan y se necesitan durante la compilación cuando la sustitución aún no se ha producido. Por eso no puede usar variables en los campos Package,

Source

y Architecture. La sustitución de variables ocurre en el contenido de los campos después de que se hayan analizado, por lo que si desea que una variable se expanda en varias líneas, no tiene que incluir un espacio después del salto de línea. Esto se hace implícitamente cuando se emite el campo. Por ejemplo, si la variable ${Description} está establecida en "foo es bar.${Newline}foo es genial." y

si
