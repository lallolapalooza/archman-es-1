Paquete: postgresql

Licencias: PostgreSQL

DELETE(7) Documentación de PostgreSQL 18.1 DELETE(7)

NOMBRE

DELETE - eliminar filas de una tabla

SINOPSIS

[ WITH [ RECURSIVE ] with_query [, ...] ]
DELETE FROM [ ONLY ] table_name [ * ] [ [ AS ] alias ]
    [ USING from_item [, ...] ]
    [ WHERE condition | WHERE CURRENT OF cursor_name ]
    [ RETURNING [ WITH ( { OLD | NEW } AS output_alias [, ...] ) ]
                { * | output_expression [ [ AS ] output_name ] } [, ...] ]

DESCRIPCIÓN

DELETE elimina las filas que cumplen la cláusula WHERE de la tabla especificada. Si la cláusula WHERE no está presente, el efecto es eliminar todas las filas de la tabla. El resultado es una tabla válida, pero vacía.


Consejo

TRUNCATE proporciona un mecanismo más rápido para eliminar todas las filas de una tabla.

Hay dos formas de eliminar filas en una tabla utilizando la información contenida en otras tablas de la base de datos: usando subselecciones, o especificando tablas adicionales en la cláusula USING. Qué técnica es más apropiada depende de las circunstancias específicas.

La cláusula opcional RETURNING hace que DELETE calcule y devuelva valor(es) basados en cada fila realmente eliminada. Se puede calcular cualquier expresión que utilice las columnas de la tabla y/o columnas de otras tablas mencionadas en USING. La sintaxis de la lista RETURNING es idéntica a la de la lista de salida de SELECT.

Debe tener el privilegio DELETE sobre la tabla para eliminar de ella, así como el privilegio SELECT para cualquier tabla en la cláusula USING o cuyos valores se lean en la condition.

PARÁMETROS

with_query

La cláusula WITH le permite especificar una o más subconsultas que pueden ser referenciadas por nombre en la DELETE consulta. Vea la Sección 7.8 y SELECT(7) para más detalles.

table_name

El nombre (opcionalmente calificado por esquema) de la tabla de la que se eliminarán filas. Si se especifica ONLY antes del nombre de la tabla, solo se eliminarán las filas coincidentes de la tabla nombrada. Si no se especifica ONLY, las filas coincidentes también se eliminarán de cualquier tabla que herede de la tabla nombrada. Opcionalmente, se puede especificar * después del nombre de la tabla para indicar explícitamente que se incluyen las tablas descendientes.

alias

Un nombre sustituto para la tabla objetivo. Cuando se proporciona un alias, oculta completamente el nombre real de la tabla. Por ejemplo, dado DELETE FROM foo AS f, el resto de la DELETE sentencia debe referirse a esta tabla como f y no como foo.

from_item

Una expresión de tabla que permite que columnas de otras tablas aparezcan en la condición WHERE. Utiliza la misma sintaxis que la cláusula FROM de una SELECT sentencia; por ejemplo, se puede especificar un alias para el nombre de la tabla. No repita la tabla objetivo como un from_item a menos que desee establecer un join consigo mismo (en cuyo caso debe aparecer con un alias en el from_item).

condition

Una expresión que devuelve un valor de tipo booleano. Solo se eliminarán las filas para las que esta expresión devuelva true.

cursor_name

El nombre del cursor a utilizar en una condición WHERE CURRENT OF. La fila a eliminar es la más recientemente obtenida de este cursor. El cursor debe ser una consulta no agrupada sobre la DELETEtabla objetivo. Tenga en cuenta que WHERE CURRENT OF no puede especificarse junto con una condición booleana. Vea DECLARE(7) para más información sobre el uso de cursores con WHERE CURRENT OF.

output_alias

Un nombre sustituto opcional para las filas OLD o NEW en la lista RETURNING.

De forma predeterminada, los valores antiguos de la tabla objetivo pueden ser devueltos escribiendo OLD.column_name o OLD.*, y los valores nuevos pueden ser devueltos escribiendo NEW.column_name o NEW.*. Cuando se proporciona un alias, estos nombres quedan ocultos y las filas antiguas o nuevas deben referirse utilizando el alias. Por ejemplo RETURNING WITH (OLD AS o, NEW AS n) o.*, n.*.

output_expression

Una expresión a ser calculada y devuelta por el DELETE comando después de que se elimine cada fila. La expresión puede usar cualquier nombre de columna de la tabla nombrada por table_name o tabla(s) listadas en USING. Escriba * para devolver todas las columnas.

Un nombre de columna o * puede calificarse usando OLD o NEW, o el correspondiente output_alias para OLD o NEW, para causar que se devuelvan valores antiguos o nuevos. Un nombre de columna sin calificar, o *, o un nombre de columna o * calificado usando el nombre o alias de la tabla objetivo devolverá valores antiguos.

Para un DELETEsimple, todos los valores nuevos serán NULL. Sin embargo, si una regla ON DELETE causa que se ejecute un INSERT o UPDATE en su lugar, los valores nuevos pueden no ser NULL.

output_name

Un nombre a usar para una columna devuelta.

SALIDAS

Al completarse con éxito, un DELETE comando devuelve una etiqueta de comando de la forma

DELETE count

El count es el número de filas eliminadas. Tenga en cuenta que el número puede ser menor que el número de filas que coincidieron con la condition cuando las eliminaciones fueron suprimidas por un trigger BEFORE DELETE. Si count es 0, ninguna fila fue eliminada por la consulta (esto no se considera un error).

Si el DELETE comando contiene una cláusula RETURNING, el resultado será similar al de una SELECT sentencia que contiene las columnas y valores definidos en la lista RETURNING, calculados sobre la(s) fila(s) eliminada(s) por el comando.

NOTAS

PostgreSQL le permite referenciar columnas de otras tablas en la condición WHERE especificando las otras tablas en la cláusula USING. Por ejemplo, para eliminar todas las películas producidas por un productor dado, se puede hacer:

DELETE FROM films USING producers
  WHERE producer_id = producers.id AND producers.name = 'foo';

Lo que esencialmente está ocurriendo aquí es un join entre films y producers, con todas las filas de films exitosamente unidas siendo marcadas para eliminación. Esta sintaxis no es estándar. Una forma más estándar de hacerlo es:

DELETE FROM films
  WHERE producer_id IN (SELECT id FROM producers WHERE name = 'foo');

En algunos casos el estilo de join es más fácil de escribir o más rápido de ejecutar que el estilo de subselección.

EJEMPLOS

Eliminar todas las películas excepto musicales:

DELETE FROM films WHERE kind <> 'Musical';

Limpiar la tabla films:

DELETE FROM films;

Eliminar tareas completadas, devolviendo los detalles completos de las filas eliminadas:

DELETE FROM tasks WHERE status = 'DONE' RETURNING *;

Eliminar la fila de tasks en la que el cursor c_tasks está actualmente posicionado:

DELETE FROM tasks WHERE CURRENT OF c_tasks;

Aunque no hay una cláusula LIMIT para DELETE, es posible obtener un efecto similar usando el mismo método descrito en la documentación de UPDATE:

WITH delete_batch AS (
  SELECT l.ctid FROM user_logs AS l
    WHERE l.status = 'archived'
    ORDER BY l.creation_date
    FOR UPDATE
    LIMIT 10000
)
DELETE FROM user_logs AS dl
  USING delete_batch AS del
  WHERE dl.ctid = del.ctid;

COMPATIBILIDAD

Este comando se ajusta al estándar SQL, excepto que las cláusulas USING y RETURNING son extensiones de PostgreSQL, al igual que la capacidad de usar WITH con DELETE.
