NOMBRE

deb-old - formato de paquete binario antiguo de Debian

SINOPSIS

nombre-del-archivo.deb

DESCRIPCIÓN

El formato .deb es el formato de archivo de paquete binario de Debian. Esta página del manual describe el formato antiguo, utilizado antes de Debian 0.93. Por favor, consulte deb(5) para obtener detalles sobre el nuevo formato.

FORMATO

El archivo consta de dos líneas de información de formato en texto ASCII, seguidas de dos archivos ustar comprimidos con gzip concatenados.

La primera línea es el número de versión del formato rellenado a 8 dígitos, y es 0.939000 para todos los archivos de formato antiguo.

La segunda línea es una cadena decimal (sin ceros iniciales) que indica la longitud del primer archivo tar comprimido con gzip.

Cada una de estas líneas está terminada por un único carácter de nueva línea.

El primer archivo tar contiene la información de control, como una serie de archivos normales. El archivo control debe estar presente, ya que contiene la información de control principal.

En algunos archivos muy antiguos, los archivos del archivo tar de control pueden estar opcionalmente en un subdirectorio DEBIAN. En ese caso, el subdirectorio DEBIAN también estará en el archivo tar de control, y el archivo tar de control solo contendrá archivos dentro de ese directorio. Opcionalmente, el archivo tar de control puede contener una entrada para ‘.’, es decir, el directorio actual.

El segundo archivo tar comprimido con gzip es el archivo del sistema de archivos, que contiene rutas relativas al directorio raíz del sistema en el que se instalará. Las rutas no tienen barras iniciales.

VER TAMBIÉN

deb(5), deb-control(5), dpkg-deb(1).
