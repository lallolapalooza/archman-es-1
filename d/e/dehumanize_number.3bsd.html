dehumanize_number(3bsd)

Paquete: libbsd

Licencias: custom

humanize_number(3bsd) 3bsd humanize_number(3bsd)

NOMBRE

dehumanize_number, humanize_number — formatea un número en una forma legible para humanos y viceversa

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <stdlib.h> (Ver libbsd(7) para el uso de include.)
int
dehumanize_number(const char *str, int64_t *result);

int
humanize_number(char *buf, size_t len, int64_t number, const char *suffix, int scale, int flags);

DESCRIPCIÓN

La función humanize_number() formatea la cantidad con signo de 64 bits dada en number dentro de buffer. Se añade un espacio y luego suffix al final. buffer debe tener al menos len bytes de longitud.

Si el número formateado (incluyendo suffix) fuera demasiado largo para caber en buffer, entonces divida number por 1024 hasta que quepa. En este caso, prefije suffix con el designador SI apropiado.

Los prefijos son:

Prefijo Descripción Multiplicador
k kilo 1024
M mega 1048576
G giga 1073741824
T tera 1099511627776
P peta 1125899906842624
E exa 1152921504606846976

len debe ser al menos 4 más la longitud de suffix, para asegurar que se genere un resultado útil en buffer. Para usar un prefijo específico, especifíquelo en scale (Multiplicador = 1024 ^ scale). Esto no se puede combinar con ninguno de los scale flags siguientes.

Los siguientes indicadores pueden pasarse en scale:

HN_AUTOSCALE
Formatea el búfer usando el multiplicador más bajo posible.
HN_GETSCALE
Devuelve el número de índice del prefijo (el número de veces number debe dividirse para caber) en lugar de formatearlo al búfer.

Los siguientes indicadores pueden pasarse en flags:

HN_DECIMAL
Si el resultado final es menor que 10, muéstrelo usando un dígito.
HN_NOSPACE
No ponga un espacio entre number y el prefijo.
HN_B
Usa 'B' (bytes) como prefijo si el resultado original no tiene un prefijo.
HN_DIVISOR_1000
Divide number con 1000 en lugar de 1024.

La función dehumanize_number() analiza la cadena que representa un valor integral dado en str y almacena el valor numérico en el entero apuntado por result. La cadena proporcionada puede contener uno de los sufijos, que será interpretado y usado para escalar hacia arriba su valor numérico acompañante.

VALORES DE RETORNO

humanize_number() devuelve el número de caracteres almacenados en buffer (excluyendo el NUL terminante) con éxito, o -1 en caso de fallo. Si se especifica HN_GETSCALE , se devolverá el número de índice del prefijo en su lugar.

dehumanize_number() devuelve 0 si la cadena fue analizada correctamente. Se devuelve un -1 para indicar fallo y un código de error es almacenado en errno.

ERRORES

dehumanize_number() fallará y no se almacenará ningún número en result si:

[EINVAL]
La cadena en str estaba vacía o llevaba un sufijo desconocido.
[ERANGE]
La cadena en str representaba un número que no cabe en result.

VER TAMBIÉN
