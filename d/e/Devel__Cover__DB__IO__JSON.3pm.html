Devel::Cover::DB::IO::JSON(3) Documentación de contribución de usuarios de Perl Devel::Cover::DB::IO::JSON(3)

NOMBRE

Devel::Cover::DB::IO::JSON - Rutinas de E/S basadas en JSON para Devel::Cover::DB

VERSIÓN

versión 1.51

SINOPSIS

use Devel::Cover::DB::IO::JSON;
my $io = Devel::Cover::DB::IO::JSON->new;
my $data = $io->read($file);
$io->write($data, $file);

DESCRIPCIÓN

Este módulo proporciona rutinas de E/S basadas en JSON para Devel::Cover::DB.

VER TAMBIÉN

Devel::Cover JSON::MaybeXS

MÉTODOS

new

my $io = Devel::Cover::DB::IO::JSON->new;

Construye el objeto de E/S.

read

my $data = $io->read($file);

Devuelve una estructura de datos de Perl que representa los datos leídos de $file.

write

$io->write($data, $file);

Escribe $data en $file en el formato especificado al crear $io.
