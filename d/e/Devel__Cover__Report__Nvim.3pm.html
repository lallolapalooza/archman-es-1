NOMBRE

Devel::Cover::Report::Nvim - Backend para mostrar datos de cobertura en Neovim

VERSIÓN

versión 1.51

SINOPSIS

cover -report nvim

DESCRIPCIÓN

Este módulo proporciona un mecanismo de informes para mostrar datos de cobertura en Neovim usando Lua. Está diseñado para ser llamado desde el programa "cover".

De forma predeterminada, la salida de este informe es un archivo llamado "coverage.lua" en el directorio de la base de datos de cobertura. Para usarlo, ejecute

:luafile cover_db/coverage.lua

y debería ver indicadores en la columna izquierda que muestran el estado de cobertura de esa línea.

Los indicadores son los siguientes:

P - Cobertura de Pod
S - Cobertura de sentencias
R - Cobertura de subrutinas
B - Cobertura de ramas
C - Cobertura de condiciones

El último de los criterios, en el orden dado anteriormente, es el que se muestra. Los criterios correctamente cubiertos se muestran en verde. Los criterios incorrectamente cubiertos se muestran en rojo. Cualquier criterio incorrectamente cubiertos anulará un criterio correctamente cubierto.

Si la cobertura del archivo que se está mostrando está desactualizada, la función llamada coverage_old() se llama y se le pasa el nombre del archivo. De manera similar, para datos de cobertura actuales, el archivo coverage_valid() se llama.

Los colores e indicadores se pueden personalizar usando variables vim globales. Establezca estas en su archivo init.lua o init.vim antes de cargar el script de cobertura. script.

Variables de configuración disponibles:

vim.g.devel_cover_fg         -- Color de primer plano para líneas cubiertas (predeterminado: "Green")
vim.g.devel_cover_error_fg   -- Color de primer plano para líneas no cubiertas (predeterminado: "Red")
vim.g.devel_cover_bg         -- Color de fondo para líneas cubiertas (predeterminado: nil)
vim.g.devel_cover_error_bg   -- Color de fondo para líneas no cubiertas (predeterminado: nil)
vim.g.devel_cover_valid_bg   -- Fondo cuando la cobertura está actualizada (predeterminado: nil)
vim.g.devel_cover_old_bg     -- Fondo cuando la cobertura está desactualizada (predeterminado: nil)
vim.g.devel_cover_cterm      -- Estilo de terminal (predeterminado: "bold")
vim.g.devel_cover_gui        -- Estilo de GUI (predeterminado: "bold")
vim.g.devel_cover_linehl     -- Grupo de resaltado de línea para cubiertas (predeterminado: "cov")
vim.g.devel_cover_linehl_error -- Grupo de resaltado de línea para errores (predeterminado: "err")
vim.g.devel_cover_signs      -- Tabla de texto de indicadores personalizados
vim.g.devel_cover_sign_group -- Nombre del grupo de indicadores para columna dedicada (predeterminado: "DevelCover")
vim.g.devel_cover_sign_priority -- Prioridad del indicador dentro del grupo (predeterminado: 10)

Ejemplo de configuración para el tema solarized en init.lua:

-- Establecer colores antes de cargar la cobertura
vim.g.devel_cover_fg = "#859900"        -- verde solarized
vim.g.devel_cover_error_fg = "#dc322f"  -- rojo solarized
vim.g.devel_cover_valid_bg = "#073642"  -- base02 solarized
vim.g.devel_cover_old_bg = "#342a2a"    -- fondo más oscuro con tinte rojizo
vim.g.devel_cover_cterm = "NONE"
vim.g.devel_cover_gui = "NONE"
-- Caracteres de indicador personalizados (opcional)
-- Nota: El mismo carácter se usa tanto para cubiertas/no cubiertas
-- La diferencia se muestra a través de los colores fg/bg definidos arriba
vim.g.devel_cover_signs = {
  pod = "P ",
  subroutine = "R ",
  statement = "· ",  -- Punto sutil para sentencias (lo más común)
  branch = "B ",
  condition = "C "
}
-- O para un aspecto minimalista que dependa puramente de los colores
vim.g.devel_cover_bg = "#002b36"        -- oscuro para cubiertas
vim.g.devel_cover_error_bg = "#2d1616"  -- rojo oscuro para no cubiertas
vim.g.devel_cover_signs = {
  pod = "  ",
  subroutine = "  ",
  statement = "│ ",  -- Barra vertical delgada (discreta)
  branch = "  ",
  condition = "  "
}
-- O usar caracteres Unicode sutiles
vim.g.devel_cover_signs = {
  pod = "¶ ",
  subroutine = "ƒ ",
  statement = "• ",  -- Viñeta pequeña (discreta)
  branch = "» ",
  condition = "? "
}
-- Para una columna de cobertura dedicada (recomendado)
-- Esto mantiene los indicadores de cobertura separados de otros indicadores como diagnósticos
vim.g.devel_cover_sign_group = "DevelCover"  -- Crea su propia columna
-- También puede configurar la apariencia de la columna de indicadores
vim.o.signcolumn = "yes:2"  -- Mostrar 2 columnas de indicadores (1 para diagnósticos, 1 para cobertura)

Alternativa: Aún puede anular mediante devel-cover.lua en su directorio de configuración para personalizaciones más complejas

Esta configuración establece el color de fondo de los indicadores a un rojo oscuro cuando los datos de cobertura están desactualizados.

coverage.lua agrega dos comandos de usuario: :Cov y :Uncov que pueden usarse para alternar el estado de los indicadores de cobertura.

La idea y la plantilla de lua están adaptadas de la versión de Vim que fue robada sin vergüenza de Simplecov-Vim. Ver https://github.com/nyarly/Simplecov-Vim
