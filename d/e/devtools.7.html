NOMBRE

devtools - Herramientas para desarrolladores para la distribución Arch Linux

DESCRIPCIÓN

Devtools contiene herramientas para el mantenimiento de paquetes en Arch Linux. Viene con un frontend de línea de comandos unificado llamado pkgctl que ayuda a interactuar convenientemente con todas las diferentes herramientas que esta colección proporciona.

El conjunto de herramientas varía desde herramientas para construir paquetes en un chroot limpio (mkarchroot, archbuild, ...), herramientas relacionadas con el empaquetado (sogrep, diffpkg, lddd) y herramientas para la gestión de repositorios como (pkgrepo).

PROGRAMAS

La siguiente lista ofrece una breve descripción general; consulte la documentación correspondiente para obtener detalles.

pkgctl(1) Frontend unificado de línea de comandos para devtools

archbuild(1) Construye un paquete de Arch Linux dentro de un chroot limpio

arch-nspawn(1) Ejecuta un comando o sistema operativo en un contenedor de namespace ligero

checkpkg(1) Compara el paquete de compilación actual con la versión del repositorio

diffpkg(1) Compara archivos de paquetes usando diferentes modos

export-pkgbuild-keys(1) Exporta claves de firma de origen válidas desde un PKGBUILD

find-libdeps(1) Encuentra dependencias de soname para un paquete

find-libprovides(1) Encuentra soname's que son proporcionados por un paquete

lddd(1) Encuentra enlaces de bibliotecas rotos en tu sistema

mkarchroot(1) Crea un chroot de Arch en una ubicación especificada con un conjunto especificado de paquetes

makechrootpkg(1) Construye un PKGBUILD en un entorno chroot dado

makerepropkg(1) Reconstruye un paquete para ver si es reproducible

offload-build(1) Construye un PKGBUILD en un servidor remoto usando makechrootpkg

sogrep(1) Encuentra paquetes que utilizan una biblioteca compartida vinculada a una dada

PÁGINA PRINCIPAL
