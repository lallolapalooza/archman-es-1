DESCRIPCIÓ

N

El programa desktop-file-install es una herramienta para instalar y, opcionalmente, editar archivos de escritorio. El programa desktop-file-edit es una herramienta para editar un archivo de escritorio. Son mayormente útiles para desarrolladores y

empaquetadores.

Hay varias opciones disponibles para editar los archivos de escritorio. Las opciones de edición pueden especificarse más de una vez y se procesarán en el mismo orden en que se pasan al

programa.

desktop-file-install y desktop-file-edit siempre intentarán validar el archivo de escritorio resultante. Un fallo en la validación puede provocar la interrupción de la instalación de los archivos de

escritorio.

La lista de categorías y entornos de escritorio registrados está definida en la especificación de menús: http://freedesktop.org/wiki/Specifications/menu-spe

c
.

NOMBRE

desktop-file-install — instala archivos de escritorio en directorios de instalación

SINOPSIS

desktop-file-install [-h|--help] [-v|--version] [-d|--dir directorio] [-m|--mode modo] [-p|--pkgdata-dir directorio] [-i|--in-place] [--dir-in-place directorio] [-o|--overwrite] [--vendor-only] [--no-tag-check] [--add-only] [--delete-only] [--only-root] [--prefix prefijo] [--pkgdata-prefix prefijo] [--variant-prefix prefijo] [--variant-pkgdata-prefix prefijo] [--variant-tag etiqueta] archivo...

DESCRIPCIÓN

El programa desktop-file-install es una utilidad para instalar archivos de escritorio (.desktop) en los directorios apropiados para que el sistema pueda encontrarlos y usarlos. Soporta la especificación de múltiples archivos de entrada, que pueden estar organizados en una estructura de directorios. La estructura de directorios del origen se preservará en el destino, a menos que se use la opción --dir.

También puede ser usado para instalar archivos de escritorio de forma interactiva, si se omite el argumento archivo.

Si se omite la opción --dir y la variable de entorno DESKTOP_FILE_INSTALL_DIR, los archivos se instalarán en el directorio predeterminado, que generalmente es /usr/share/applications.

Esta utilidad debería ser usada por los paquetes que instalen aplicaciones, para asegurar que los archivos .desktop se instalen correctamente.

OPCIONES

-h, --help
Muestra un mensaje de ayuda y sale.
-v, --version
Muestra la información de la versión y sale.
-d, --dir directorio
Instala los archivos de escritorio en el directorio especificado en lugar del directorio predeterminado. Si se especifica múltiples veces, el último directorio será usado.
-m, --mode modo
Establece los permisos del archivo instalado al modo especificado (en formato octal).
-p, --pkgdata-dir directorio
Instala los archivos de datos del paquete en el directorio especificado.
-i, --in-place
Instala los archivos de escritorio en el mismo directorio en el que se encuentran. Esto es útil para pruebas.
--dir-in-place directorio
Similar a --in-place, pero los archivos se instalan en el directorio especificado.
-o, --overwrite
Sobrescribe los archivos de escritorio existentes si ya están instalados. Sin esta opción, si un archivo ya existe, se omitirá.
--vendor-only
Instala solo los archivos de escritorio que son específicos del proveedor (vendor).
--no-tag-check
No verifica las etiquetas de los archivos de escritorio.
--add-only
Solo instala archivos que no existen en el destino.
--delete-only
Solo elimina archivos que existen en el destino.
--only-root
Instala solo los archivos que deben ser instalados por el usuario root.
--prefix prefijo
Añade un prefijo al directorio de instalación.
--pkgdata-prefix prefijo
Añade un prefijo al directorio de datos del paquete.
--variant-prefix prefijo
Añade un prefijo al directorio de instalación para variantes específicas.
--variant-pkgdata-prefix prefijo
Añade un prefijo al directorio de datos del paquete para variantes específicas.
--variant-tag etiqueta
Instala el archivo solo si la etiqueta especificada está presente en el archivo de escritorio.

OPCIONES DE EDICIÓN

Las siguientes opciones se pueden usar para editar los archivos de escritorio antes de instalarlos:

--set-key-value clave=valor
Establece el valor de una clave en el archivo de escritorio. Si la clave no existe, se añadirá. Si existe, se sobrescribirá.
--remove-key clave
Elimina una clave y su valor del archivo de escritorio.
--set-mime-type tipo
Establece el tipo MIME del archivo de escritorio.
--remove-mime-type tipo
Elimina el tipo MIME especificado del archivo de escritorio.
--add-category categoría
Añade una categoría al archivo de escritorio.
--remove-category categoría
Elimina una categoría del archivo de escritorio.
--update-desktop-database
Actualiza la base de datos de archivos de escritorio después de la instalación.

AMBIENTE

DESKTOP_FILE_INSTALL_DIR
Esta variable se establece al construir paquetes RPM. Si la opción --dir y la variable de entorno DESKTOP_FILE_INSTALL_DIR no se utilizan, se antepondrá automáticamente al directorio de instalación predeterminado para instalar los archivos de escritorio apropiadamente al construir paquetes.

ERRORES

Si encuentra errores en el programa desktop-file-install, por favor repórtelos en https://bugs.freedesktop.org.
