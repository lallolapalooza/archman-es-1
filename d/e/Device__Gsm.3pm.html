messages(

Este método es algo inestable y sujeto a cambios, pero por
    ahora parece funcionar. Está destinado aextraer todos los mensajes de texto SMS almacenados en tu tarjeta SIM o teléfono gsm. En contexto de lista, devuelve una lista de mensajes (o valor indefinido si no hay mensajes o hay errores), cada mensaje siendo un

El único parámetro especifica el

mode()


Establece el modo de comando GSM del dispositivo. Acepta un parámetro para establecer el nuevo modo que puede ser la cadena "text" o
    "pdu". Ejemplo:


# Set text mode
$gsm->mode('text');

# Set pdu mode
$gsm->mode('pdu');






model()


Devuelve el nombre o número del modelo del teléfono/dispositivo. Ejemplo:


my $model = $gsm->model();


Por ejemplo, para Siemens C45, $model contiene
    "C45"; para Nokia 6600,
    $model contiene 6600.






network()


Devuelve el operador de red GSM actual registrado o preferido.
    Ejemplo:


my $net_name = $gsm->network();
# Returns 'Wind Telecom Spa'
my($net_name, $net_code) = $gsm->network();
# Returns ('Wind Telecom Spa', '222 88')


Esto obviamente varía dependiendo del país y el operador de red. Para mí ahora, contiene "Wind Telecomunicazioni SpA". No está garantizado que el teléfono móvil devuelva el nombre de red decodificado. También puede devolver un código de red gsm, como "222
    88". En este caso, se intenta decodificar el nombre de la red.


Asegúrate de llamar al network() método cuando ya estés registrado en la red gsm. Ver register()
    método.






signal_quality()


Devuelve la medida de calidad de señal expresada en unidades dBm, donde más cerca de cero es mejor. Un valor de ejemplo es -91 dBm, y el valor reportado es -91. Los valores deberían oscilar entre -113 y -51
    dBm, donde -113 es la calidad de señal mínima y -51 es la calidad máxima teórica.


my $level = $gsm->signal_quality();


Si la calidad de señal no se puede leer o tu dispositivo no soporta este comando, se devolverá un valor indefinido .






software_version()


Devuelve la versión del firmware del dispositivo, tal como la almacena el fabricante. Ejemplo:


my $rev = $gsm->software_revision();


Por ejemplo, para mi Siemens C45, $rev
    contiene 06.






storage()


Permite obtener/establecer el almacenamiento SMS actual, es decir, donde se guardan los mensajes SMS, ya sea la tarjeta SIM o la memoria del teléfono gsm. Los teléfonos/módems que no soportan esta característica (implementada por el comando AT
    "+CPMS" no se verán afectados por este método.


my @msg;
my $storage = $gsm->storage();
print "Current storage is $storage\n";
# Read all messages on sim card
$gsm->storage('SM');
@msg = $gsm->messages();
# Read messages from gsm phone memory
$gsm->storage('ME');
push @msg, $gsm->messages();






test_command()


Este método consulta al dispositivo para saber si un comando AT GSM específico es soportado. Esto se usa solo con comandos GSM (aquellos con el prefijo
    "AT+" ). Por ejemplo, si quiero saber si mi dispositivo soporta el comando "AT+GXXX"
    :


my $gsm = Device::Gsm->new( port => '/dev/myport' );
...
if( $gsm->test_command('GXXX') ) {
    # Ok, command is supported
} else {
    # Nope, no GXXX command
}


Ten en cuenta que si omites el carácter inicial
    "+" , se añade automáticamente. También puedes probar comandos como "^SNBR" o similares, sin que se añada el carácter "+" .


Este método almacena en caché los resultados de la prueba para usarlos en pruebas futuras (al menos hasta que se ejecute connect() o
    disconnect() ).






register()


"Registrarse" en la red GSM es lo que sucede cuando enciendes tu teléfono móvil o equipo GSM y el dispositivo intenta alcanzar la red del operador GSM. Si tu dispositivo requiere un número PIN , se usa aquí (pero recuerda proporcionar el parámetro
    "pin" en el new() constructor de objetos para que esto funcione.


El registro puede tardar unos segundos, no te preocupes por la espera. Después de eso, estás listo para enviar tus mensajes SMS o hacer algunas llamadas de voz. Normalmente no necesitas llamar a register() explícitamente porque se hace automáticamente por ti cuando/sea necesario.


Si el valor de retorno es verdadero, el registro fue exitoso, de lo contrario hay algo mal; probablemente proporcionaste el código PIN incorrecto o la red es inaccesible.






send_sms()


Obviamente, esto envía mensajes de texto SMS. Debería advertirte que no puedes enviar (por ahora) mensajes MMS, tonos de llamada, smart, ota de ningún tipo con este método.


Envía un mensaje SMS rápidamente:


my $sent = $gsm->send_sms(
    content   => 'Hello, world!',   # SMS text
    recipient => '+99000123456',    # recipient phone number
);
if( $sent ) {
    print "OK!";
} else {
    print "Troubles...";
}


Los parámetros permitidos para send_sms() son:



  
"class"

  
El parámetro class puede asumir dos valores:
      "normal" y
      "flash". Los mensajes Flash (o clase cero) son particulares porque se muestran inmediatamente (sin confirmación del usuario) y nunca se almacenan en la memoria del teléfono, mientras que
      "normal" es el valor por defecto.

  
"content"

  
Este es el texto que quieres enviar, consistente en un máximo de 160 caracteres si usas el modo
      PDU y 140 (?) si estás en modo text (más sobre esto
    más adelante).

  
"mode"

  
Puede asumir dos valores (insensible a mayúsculas):
      "pdu" y
      "text".
      "PDU" significa Protocol Data Unit
      y es una especie de codificación binaria de comandos, para ahorrar
      tiempo/espacio, mientras que "text" es el modo de texto normal de comandos
      GSM.
    
Los teléfonos móviles recientes y equipos GSM seguramente tienen soporte para el modo
        "PDU" . Los módulos OEM más antiguos (como Falcom Swing, por ejemplo) no tienen modo PDU, sino solo modo texto. Es solo cuestión de probar.

  

  
"recipient"

  
Número de teléfono del destinatario del mensaje

  
"status_report"

  
Si está presente con un valor verdadero, habilita el envío de mensajes SMS (solo para modo PDU, los SMS en modo texto no se verán influenciados por este parámetro) con el informe de estado, también conocido como informe de entrega, que es un mensaje corto que reporta el estado de tu mensaje enviado. Usualmente esto solo está disponible si tu compañía móvil soporta esta característica, y probablemente se te cobre una pequeña cantidad por este servicio.
    
Cualquier información adicional sobre esto sería bienvenida.

  








service_center()


Si se llama sin parámetros, devuelve el número de teléfono actual del Centro de Servicio SMS. Este es el número al que tu teléfono llama automáticamente al recibir y enviar mensajes de texto SMS, y tu operador de red debería decirte cuál es este número.


Ejemplo:


my $gsm = Device::Gsm->new( port => 'COM1' );
$gsm->connect() or die "Can't connect";
$srv_cnt = $gsm->service_center();
print "My service center number is: $srv_cnt\n";


Si quieres establecer o cambiar este número (si se usa incorrectamente esto puede deshabilitar el envío de mensajes SMS, ¡así que ten cuidado!), puedes probar algo como:


my $ok = $gsm->service_center('+99001234567');
print "Service center changed!\n" if $ok;

SOLUCIÓN DE PROBLEMAS


Si experimentas problemas, por favor verifica dos veces:



  
Permisos del
    dispositivo

  
Quizás no tienes los permisos necesarios para acceder a tu puerto serie, irda o bluetooth. Intenta ejecutar tu script como root, o intenta, si no te importa, "chmod a+rw /dev/ttyS1" (o
      cualquier dispositivo que uses en lugar de
      "/dev/ttyS1").

  
Velocidad de
    conexión

  
Intenta cambiar el parámetro "baudrate" de 19200 (el valor por defecto) a 9600 o viceversa. Este es el responsable del 80% de los problemas, porque no hay autodetección de baudrate.

  
Autodetección del
    dispositivo

  
Si todo lo demás falla, por favor usa la utilidad autoscan en la carpeta
      "bin/" de la distribución
      "Device::Gsm" . Intenta ejecutar esta utilidad autoscan y examina el archivo de log producido en el directorio actual.
    
Si pierdes toda esperanza, envíame este archivo de log para que pueda eventualmente tener alguna pista sobre el problema / fallo.

    
También esta es una herramienta de perfilado, para saber qué comandos son soportados por tu dispositivo, ¡así que por favor envíame perfiles de tus dispositivos, para que pueda añadir mejor soporte para todos los dispositivos en el futuro!

  











  
Spooler

  
Construye un programa spooler simple que envíe todos los SMS almacenados en una cola especial (que podría ser simplemente una carpeta del sistema de archivos).

  
Período
    de validez

  
Soporte "validez" período de opción al enviar SMS. Indica cuánto tiempo el Centro de Servicios SMS debe retener el SMS para su entrega si no se recibe.
