subroutine debchvxx (double precision thresh, character*3 path)

DEBCHVXX

Propósito:

!>
!>  DEBCHVXX ejecutará D**SVXX en una serie de matrices de Hilbert y luego
!>  comparará los límites de error devueltos por D**SVXX para ver si la
!>  respuesta devuelta cae dentro de esos límites.
!>
!>  Se calcularán ocho ratios de prueba. Las pruebas pasarán si son .LT.
!>  THRESH. Hay dos casos que se determinan por 1 / (SQRT( N ) * EPS).
!>  Si ese valor es .LE. al número de condición recíproco componente a componente,
!>  usa el caso garantizado, de lo contrario usa el caso no garantizado.
!>
!>  Ratios de prueba:
!>     Sea Xc X_computada y Xt X_verdadera.
!>     La norma utilizada es la norma infinito.
!>
!>     Sea A el caso garantizado y B el caso no garantizado.
!>
!>       1. Límite de error hacia adelante garantizado en norma.
!>       A: norm ( abs( Xc - Xt ) / norm ( Xt ) .LE. ERRBND( *, nwise_i, bnd_i ) y
!>          ERRBND( *, nwise_i, bnd_i ) .LE. MAX(SQRT(N),10) * EPS.
!>          Si estas condiciones se cumplen, el ratio de prueba se establece como
!>          ERRBND( *, nwise_i, bnd_i ) / MAX(SQRT(N), 10). De lo contrario es 1/EPS.
!>       B: Para este caso, CGESVXX simplemente debería devolver 1. Si es menor que
!>          uno, trátalo igual que en 1A. De lo contrario falla. (¿Establecer ratio de prueba a ERRBND( *, nwise_i, bnd_i ) * THRESH?)
!>
!>       2. Límite de error hacia adelante garantizado componente a componente.
!>       A: norm ( abs( Xc(j) - Xt(j) ) ) / norm (Xt(j)) .LE. ERRBND( *, cwise_i, bnd_i )
!>          para todo j .AND. ERRBND( *, cwise_i, bnd_i ) .LE. MAX(SQRT(N), 10) * EPS.
!>          Si estas condiciones se cumplen, el ratio de prueba se establece como
!>          ERRBND( *, cwise_i, bnd_i ) / MAX(SQRT(N), 10). De lo contrario es 1/EPS.
!>       B: Igual que el ratio de prueba normwise.
!>
!>       3. Error hacia atrás.
!>       A: El ratio de prueba se establece en BERR/EPS.
!>       B: Mismo ratio de prueba.
!>
!>       4. Número de condición recíproco.
!>       A: Se calcula un número de condición con Xt y se compara con el
!>          devuelto por CGESVXX. Sea RCONDc el RCOND devuelto por D**SVXX
!>          y RCONDt el RCOND del valor verdadero. El ratio de prueba se establece como
!>          MAX(RCONDc/RCONDt, RCONDt/RCONDc).
!>       B: El ratio de prueba se establece en 1 / (EPS * RCONDc).
!>
!>       5. Número de condición normwise recíproco.
!>       A: El ratio de prueba se establece en
!>          MAX(ERRBND( *, nwise_i, cond_i ) / NCOND, NCOND / ERRBND( *, nwise_i, cond_i )).
!>       B: El ratio de prueba se establece en 1 / (EPS * ERRBND( *, nwise_i, cond_i )).
!>
!>       6. Número de condición componente a componente recíproco.
!>       A: El ratio de prueba se establece en
!>          MAX(ERRBND( *, cwise_i, cond_i ) / CCOND, CCOND / ERRBND( *, cwise_i, cond_i )).
!>       B: El ratio de prueba se establece en 1 / (EPS * ERRBND( *, cwise_i, cond_i )).
!>
!>     .. Parámetros ..
!>     NMAX está determinado por el número más grande en la inversa de la matriz de Hilbert.
!>     La precisión se agota cuando la entrada más grande es mayor
!>     que 2 elevado al número de bits en la fracción del tipo de datos
!>     utilizado más uno, que es 24 para precisión simple.
!>     NMAX debería ser 6 para precisión simple y 11 para doble.
!>
