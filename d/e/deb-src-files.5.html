NOMBRE

deb-src-files - formato de archivos de distribución Debian

SINOPSIS

debian/files

DESCRIPCIÓN

Este archivo contiene la lista de artefactos que se distribuirán a través del archivo de control .changes.

El archivo debian/files tiene un formato simple delimitado por espacios en blanco.

nombre_archivo sección prioridad [ palabra_clave=valor... ]

nombre_archivo es el nombre del artefacto a distribuir.

sección y prioridad corresponden a los campos de control respectivos disponibles en el .deb. Los valores permitidos son específicos para cada archivo de distribución.

palabra_clave=valor... corresponde a una lista opcional delimitada por espacios en blanco de atributos para esta entrada. La única palabra clave actualmente admitida es automatic con el valor yes, para marcar archivos generados automáticamente.

NOTAS

Este archivo no está destinado a ser modificado directamente, use por favor dpkg-gencontrol o dpkg-distaddfile para añadir entradas a él.

VER TAMBIÉN

dpkg-genchanges(1), dpkg-distaddfile(1).
