DEJAGNU-HELP(1) Manual de comandos generales (urm) DEJAGNU-HELP(1)

NOMBRE

dejagnu help — muestra páginas de manual para comandos auxiliares de DejaGnu

SINOPSIS

dejagnu help [opciones...] ⟨comando⟩

DESCRIPCIÓN

El comando dejagnu help muestra documentación en formato largo para los comandos auxiliares de DejaGnu.

OPCIONES

-v, --verbose
Emite salida adicional describiendo la operación de dejagnu help en sí misma.
-w, --path
Esta opción se pasa simplemente a man.
-W
Esta opción se pasa simplemente a man.

ARCHIVOS

El comando dejagnu help busca páginas de manual en un directorio doc/ junto al directorio commands/ donde se encuentra este script. Si la página se encuentra allí, se pasa un nombre de archivo completo a man. De lo contrario, solo se proporciona el nombre del comando y se realiza la búsqueda descrita en man(1).

VER TAMBIÉN

ERRORES
