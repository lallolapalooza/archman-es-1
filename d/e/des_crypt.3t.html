DES_CRYPT(3) Manual de funciones de biblioteca DES_CRYPT(3)

NOMBRE

des_crypt, ecb_crypt, cbc_crypt, des_setparity — cifrado DES rápido

SINOPSIS

#include <rpc/des_crypt.h>

int
ecb_crypt(char *key, char *data, unsigned datalen, unsigned mode);

int
cbc_crypt(char *key, char *data, unsigned datalen, unsigned mode, char *ivec);

void
des_setparity(char *key);

DESCRIPCIÓN

Las funciones ecb_crypt() y cbc_crypt() implementan el NBS DES (Estándar de cifrado de datos). Estas rutinas son más rápidas y de propósito más general que crypt(3). También son capaces de utilizar hardware DES si está disponible. La función ecb_crypt() cifra en modo ECB (Electronic Code Book), que cifra bloques de datos de forma independiente. La función cbc_crypt() cifra en modo CBC (Cipher Block Chaining), que encadena bloques sucesivos. El modo CBC protege contra inserciones, eliminaciones y sustituciones de bloques. Además, las regularidades en el texto plano no aparecerán en el texto cifrado.

Aquí se explica cómo usar estas rutinas. El primer argumento, key, es la clave de cifrado de 8 bytes con paridad. Para establecer la paridad de la clave, que para DES está en el bit bajo de cada byte, use des_setparity(). El segundo argumento, data, contiene los datos a cifrar o descifrar. El tercer argumento, datalen, es la longitud en bytes de data, que debe ser un múltiplo de 8. El cuarto argumento, mode, se forma mediante la operación OR de varias cosas. Para la dirección de cifrado, realice un OR con DES_ENCRYPT o DES_DECRYPT. Para cifrado por software o por hardware, realice un OR con DES_HW o DES_SW. Si se especifica DES_HW y no hay hardware, el cifrado se realiza por software y la rutina devuelve DESERR_NOHWDEVICE. Para cbc_crypt(), el argumento ivec es el vector de inicialización de 8 bytes para el encadenamiento. Se actualiza al siguiente vector de inicialización al regresar.

ERRORES

[DESERR_NONE]
Sin error.
[DESERR_NOHWDEVICE]
El cifrado tuvo éxito, pero se realizó por software en lugar del hardware solicitado.
[DESERR_HWERR]
Ocurrió un error en el hardware o en el controlador.
[DESERR_BADPARAM]
Parámetro incorrecto en la rutina.

Dado un estado de resultado stat, la macro DES_FAILED(stat) es falsa solo para los dos primeros estados.

DISPONIBILIDAD

Las funciones ecb_crypt(), cbc_crypt(), y des_setparity() forman parte de libtirpc.

VER TAMBIÉN

crypt(3)

RESTRICCIONES

Estas rutinas no están disponibles en RPCSRC 4.0. Esta información se proporciona para describir la interfaz DES esperada por Secure RPC.
