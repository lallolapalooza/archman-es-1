DEVLINK-DPIPE(8) Linux DEVLINK-DPIPE(8)

NOMBRE

devlink-dpipe - visualización de la canalización de plano de datos de devlink

SINOPSIS


devlink [ OPCIONES ] dpipe { table | header } { COMANDO | help }

OPCIONES := { -V[ersion] }

devlink dpipe table show DEV [ name NOMBRE_TABLA ]

devlink dpipe table set DEV name NOMBRE_TABLA

devlink dpipe table dump DEV name NOMBRE_TABLA

devlink dpipe header show DEV

devlink dpipe help

DESCRIPCIÓN

devlink dpipe table show - mostrar atributos de tabla dpipe de devlink

name NOMBRE_TABLA
Especifica la tabla sobre la que operar.

devlink dpipe table set - establecer atributos de tabla dpipe de devlink

name NOMBRE_TABLA
Especifica la tabla sobre la que operar.

devlink dpipe table dump - volcar entradas de tabla dpipe de devlink

name NOMBRE_TABLA
Especifica la tabla sobre la que operar.

devlink dpipe header show - mostrar atributos de cabecera dpipe de devlink

name NOMBRE_TABLA
Especifica la tabla sobre la que operar.

EJEMPLOS

devlink dpipe table show pci/0000:01:00.0

Muestra todas las tablas dpipe en el dispositivo devlink especificado.

devlink dpipe table show pci/0000:01:00.0 name mlxsw_erif

Muestra la tabla dpipe mlxsw_erif en el dispositivo devlink especificado.

devlink dpipe table set pci/0000:01:00.0 name mlxsw_erif counters_enabled true

Activa los contadores en la tabla mlxsw_erif.

devlink dpipe table dump pci/0000:01:00.0 name mlxsw_erif

Vuelca el contenido de la tabla mlxsw_erif.

devlink dpipe header show pci/0000:01:00.0

Muestra todas las cabeceras dpipe en el dispositivo devlink especificado.

VER TAMBIÉN

devlink(8), devlink-dev(8), devlink-monitor(8),
