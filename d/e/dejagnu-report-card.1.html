dejagnu-report-card(1)

DEJAGNU-REPORT-CARD(1) Manual de comandos generales (urm) DEJAGNU-REPORT-CARD(1)

NOMBRE

dejagnu report card — resumir resultados de pruebas de múltiples herramientas

SINOPSIS

dejagnu report card [⟨opción⟩ | ⟨herramienta⟩ | ⟨archivo⟩] ...

DESCRIPCIÓN

El comando dejagnu report card muestra los resultados de las pruebas de múltiples herramientas en formato tabular. La tabla producida lista, para cada herramienta (y si se ejecutaron múltiples pasadas, cada pasada), el número de pruebas pasadas, fallidas, no soportadas, no resueltas y no probadas. Las pruebas que se espera que fallen se cuentan en columnas separadas de las pruebas que se espera que pasen, pero las fallas "conocidas" y las fallas "esperadas" se resumen juntas. Si una prueba generó advertencias o errores, se añade una etiqueta '!W!' o '!E!' al final de la línea relevante.

Además de las opciones, la lista de argumentos puede incluir nombres de herramientas o archivos. dejagnu report card prefiere leer archivos de resumen de DejaGnu y traducirá los nombres correspondientemente:

*.sum
Se utiliza tal cual.
*.log
Se reescribe a *.sum con el mismo prefijo.
*.
Se añade la cadena sum para seleccionar un archivo de resumen. Este procesamiento se realiza por conveniencia al usar la compleción de nombres de archivo de Readline en un shell, que completará hasta el punto.
*
Se toma como nombre de herramienta; se le añade .sum.

OPCIONES

-v, --verbose
Emite salida adicional que describe el funcionamiento de dejagnu report card.

ARCHIVOS

dejagnu report card produce su salida leyendo los archivos de resumen generados por DejaGnu y contando "PASS", "FAIL", etc.

Si no se proporcionan nombres como argumentos, se leen todos los archivos que coinciden con *.sum en el directorio actual.

EJEMPLOS

Un ejemplo simple del propio conjunto de pruebas de DejaGnu

$ dejagnu report card
