Xmodem::Block

Clase que representa un solo bloque de datos Xmodem.

Sinopsis

my $b = Xmodem::Block->new( 1, 'Mis Datos...<hasta-128-caracteres>...' );
if( defined $b ) {
        # Ok, bloque instanciado, verificar su suma de verificación
        if( $b->verify( 'checksum', <mi_suma_verificacion> ) ) {
                ...
        } else {
                ...
        }
} else {
        # Sin bloque
}
# Calcular suma de verificación, crc16, 32, ...
$crc16 = $b->crc16();
$crc32 = $b->crc32();
$chksm = $b->checksum();

Xmodem::Buffer

Clase que implementa un búfer de recepción Xmodem de bloques de datos. Cada bloque de datos está representado por un objeto "Xmodem::Block".

Los bloques se pueden push (insertar) y pop (sacar) del búfer. Se puede obtener el último bloque, o la lista de bloques del búfer.

Sinopsis

my $buf = Xmodem::Buffer->new();
my $b1  = Xmodem::Block->new(1, 'Datos...');
$buf->push($b1);
my $b2  = Xmodem::Block->new(2, 'Más datos...');
$buf->push($b2);
my $last_block = $buf->last();
print 'ahora tengo ', scalar($buf->blocks()), ' en el búfer';

Xmodem::Receiver

Clase de control para iniciar y completar una transferencia de archivo "X-modem" en modo de recepción.

Sinopsis

my $recv = Xmodem::Receiver->new(
        modem    => {Objeto Device::Modem},
        filename => 'nombre del archivo',
        XXX protocol => 'xmodem' | 'xmodem-crc', | 'xmodem-1k'
);
$recv->run();

Métodos de objeto

abort_transfer()
Envía un carácter de cancelación ("can"), que señala al emisor que la transferencia se ha abortado. Esto se emite si recibimos un número de bloque incorrecto, lo que generalmente significa que hemos tenido una línea defectuosa.
modem()
Devuelve el objeto subyacente Device::Modem.
receive_message()
Recupera el mensaje del módem y, si se detecta un bloque, lo divide en las partes apropiadas.
run()
Inicia una nueva transferencia hasta que se complete la recepción del archivo. El único parámetro aceptado es el nombre de archivo local (opcional) a escribir.
send_ack()
Envía un carácter de acuse de recibo ("ack"), para señalar que hemos recibido y almacenado un bloque correcto. Restablece el contador de tiempos de espera y devuelve el objeto "Xmodem::Block" del bloque de datos recibido.
send_timeout()
Envía un carácter de tiempo de espera agotado ("nak"), para señalar que hemos recibido un encabezado de bloque incorrecto (ya sea un carácter de inicio incorrecto o un número de bloque incorrecto), o una suma de verificación de datos incorrecta. Incrementa el contador de tiempos de espera y, al décimo tiempo de espera agotado, aborta la transferencia.
