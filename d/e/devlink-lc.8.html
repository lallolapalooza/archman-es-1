NOMBRE

devlink-lc - configuración de la tarjeta de línea de devlink

SINOPSIS


devlink [ OPCIONES ] lc { COMANDO | help }

OPCIONES := { -V[ersion] }

devlink lc set DEV lc LC_INDEX [ type { LC_TYPE | notype } ]

devlink lc show [ DEV [ lc LC_INDEX ] ]

devlink lc help

DESCRIPCIÓN

devlink lc set - cambiar atributos de la tarjeta de línea

DEV
Especifica el dispositivo devlink a operar.


Formato es:
NOMBRE_BUS/DIRECCIÓN_BUS

lc LC_INDEX
Especifica el índice de una ranura de tarjeta de línea para establecer.
type {
LC_TYPE | notype } Tipo de tarjeta de línea a aprovisionar. Cada controlador proporciona una lista de tipos de tarjetas de línea compatibles, que se muestra en la salida del comando devlink lc show.

devlink lc show - mostrar atributos de la tarjeta de línea

DEV
Especifica el dispositivo devlink a operar. Si este y los argumentos lc se omiten, se listarán todas las tarjetas de línea de todos los dispositivos.
lc LC_INDEX
Especifica el índice de una ranura de tarjeta de línea para mostrar.

EJEMPLOS

devlink lc show

Muestra el estado de todas las tarjetas de línea en el sistema.

devlink lc show pci/0000:01:00.0 lc 1

Muestra el estado de la tarjeta de línea con índice 1.

devlink lc set pci/0000:01:00.0 lc 1 type 16x100G

Establece el tipo de tarjeta de línea especificada en el tipo 16x100G.

devlink lc set pci/0000:01:00.0 lc 1 notype

Borra el aprovisionamiento en una tarjeta de línea.

VER TAMBIÉN
