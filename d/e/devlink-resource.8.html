NOMBRE

devlink-resource - configuración de recursos de dispositivos devlink

SINOPSIS


devlink [ OPCIONES ] resource { COMANDO | help }

OPCIONES := { -v[erbose] }

devlink resource show DEV

devlink resource help

devlink resource set DEV path RESOURCE_PATH size RESOURCE_SIZE

DESCRIPCIÓN

devlink resource show - muestra los recursos del dispositivo devlink

DEV - especifica el dispositivo devlink a mostrar.


El formato es:
NOMBRE_BUS/DIRECCION_BUS

devlink resource set - establece el tamaño del recurso de un recurso específico

DEV - especifica el dispositivo devlink.

path RUTA_RECURSO
Ruta del recurso.
size TAMAÑO_RECURSO
El nuevo tamaño del recurso.

EJEMPLOS

devlink resource show pci/0000:01:00.0

Muestra los recursos del dispositivo devlink especificado.

devlink resource set pci/0000:01:00.0 path /kvd/linear size 98304

Establece el tamaño del recurso especificado para el dispositivo devlink especificado.
