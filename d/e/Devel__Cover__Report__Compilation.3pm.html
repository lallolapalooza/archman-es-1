Devel::Cover::Report::Compilation(3) Documentación de Perl contribuida por el usuario Devel::Cover::Report::Compilation(3)

NOMBRE

Devel::Cover::Report::Compilation - backend para Devel::Cover

VERSIÓN

versión 1.51

SINOPSIS

cover -report compilation

DESCRIPCIÓN

Este módulo proporciona un mecanismo de reporte textual para los datos de cobertura. Está diseñado para ser llamado desde el programa "cover".

Produce un reporte por línea, en un formato similar a los mensajes de error de compilación del propio Perl. Esto facilita su uso con herramientas de desarrollo que entienden formatos de salida de compilación, como el modo de compilación de Emacs, el quickfix de vim o las funciones de navegación de errores de los IDE.

FORMATO DE SALIDA

El reporte de compilación genera salida en los siguientes formatos:

  • Declaraciones 
    Uncovered statement at filename.pm line 42:
  • Ramas 
    Branch never true at filename.pm line 15: condition
Branch never false at filename.pm line 20: unless condition
Branch never reached at filename.pm line 25: condition
  • Condiciones 
    Uncovered condition (left, right) at filename.pm line 30: expr && expr
  • Subrutinas 
    Uncovered subroutine function_name at filename.pm line 50
  • Documentación POD 
    Uncovered pod at filename.pm line 60

USO CON HERRAMIENTAS DE DESARROLLO

Modo de Compilación de Emacs

Para usar con el modo de compilación de Emacs:

M-x compile
cover -report compilation

Luego, usa C-x ` (next-error) para saltar a cada ubicación no cubierta.

Quickfix de Vim

Para usar con el quickfix de vim:

:cgetexpr system('cover -report compilation')
:copen

Luego, usa :cn y :cp para navegar entre las ubicaciones no cubiertas.

TIPOS DE COBERTURA

El reporte de compilación soporta todos los tipos de cobertura estándar de Devel::Cover:

  • statement - Declaraciones individuales de Perl
  • branch - Caminos de ejecución de ramas condicionales
  • condition - Combinaciones de condiciones booleanas
  • subroutine - Cobertura de llamadas a subrutinas
  • pod - Cobertura de documentación POD

Utiliza las opciones estándar del comando "cover" para seleccionar qué tipos reportar:

cover -report compilation +statement +branch +condition +subroutine +pod

FUNCIONES

print_statement($db, $file, $options)

Imprime información de cobertura de declaraciones no cubiertas para el archivo especificado. Genera una línea por declaración no cubierta en el formato:

"Uncovered statement at $file line $line_number:"

print_branches($db, $file, $options)

Imprime información de cobertura de ramas no cubiertas para el archivo especificado. Reporta ramas donde uno o ambos caminos de ejecución no se tomaron. Genera información detallada sobre qué condición de rama nunca fue verdadera, falsa o alcanzada.

print_conditions($db, $file, $options)

Imprime información de cobertura de condiciones no cubiertas para el archivo especificado. Reporta condiciones lógicas que no fueron ejercitadas completamente, mostrando qué partes de expresiones booleanas complejas no fueron probadas.

print_subroutines($db, $file, $options)

Imprime información de cobertura de subrutinas no cubiertas para el archivo especificado. Reporta subrutinas que nunca fueron llamadas durante las pruebas.

print_pod($db, $file, $options)

Imprime información de cobertura de documentación POD (Plain Old Documentation) no cubierta para el archivo especificado. Reporta secciones de documentación POD que no tienen código probado correspondiente.

report($pkg, $db, $options)

Punto de entrada principal para generar reportes de cobertura estilo compilación. Itera sobre todos los archivos y llama a las funciones de impresión apropiadas basándose en los tipos de cobertura solicitados en las opciones.
