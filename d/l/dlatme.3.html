DLATME

Documentación de la Función/Subrutin

a

subrutina dlatme (integer n, character dist, integer, dimension( 4 ) iseed, double precision, dimension( * ) d, integer mode, double precision cond, double precision dmax, character, dimension( * ) ei, character rsign, character upper, character sim, double precision, dimension( * ) ds, integer modes, double precision conds, integer kl, integer ku, double precision anorm, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work, integer

info)

DLATM

E

Propósito

: 
!>
!>    DLATME genera matrices cuadradas no simétricas aleatorias con
!>    autovalores especificados para probar los programas de LAPACK.
!>
!>    DLATME opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>    1. Establece la diagonal en D, donde D puede ser de entrada o
!>         calculado de acuerdo con MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>    2. Si se desean pares de conjugados complejos (MODE=0 y EI(1)='R',
!>         o MODE=5), ciertos pares de elementos adyacentes de D son
!>         interpretados como la parte real y la parte imaginaria de un
!>         par de conjugados complejos; A se convierte así en una matriz
!>         diagonal por bloques, con bloques de 1x1 y 2x2.
!>
!>    3. Si UPPER='T', el triángulo superior de A se establece con
!>         valores aleatorios de la distribución DIST.
!>
!>    4. Si SIM='T', A se multiplica por la izquierda por una matriz
!>         aleatoria X, cuyos valores singulares son especificados por
!>         DS, MODES y CONDS, y por la derecha por la inversa de X.
!>
!>    5. Si KL < N-1, el ancho de banda inferior se reduce a KL usando
!>         transformaciones de Householder.  Si KU < N-1, el ancho de
!>         banda superior se reduce a KU.
!>
!>    6. Si ANORM no es negativa, la matriz se escala para tener
!>         una norma de elemento máximo ANORM.
!>
!>    (Nota: ya que la matriz no puede reducirse más allá de la forma
!>     Hessenberg, no hay opciones de empaquetado disponibles.)
!
>

Parámetro

s
N 
!>          N es INTEGER
!>           El número de columnas (o filas) de A. No se modifica.
!
>

DIS

T 
!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a usar
!>           para generar los autovalores/valores singulares aleatorios, y para
!>           el triángulo superior (ver UPPER).
!>           'U' => UNIFORM( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' para simétrico )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           No se modifica.
!
>

ISEE

D 
!>          ISEED es un array INTEGER, dimensión ( 4 )
!>           En la entrada ISEED especifica la semilla del generador de
!>           números aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           usa una secuencia congruencial lineal limitada a pequeños
!>           enteros, y por lo tanto debe producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED se cambian
!>           en la salida, y pueden usarse en la siguiente llamada a DLATME
!>           para continuar la misma secuencia de números aleatorios.
!>           Se cambia en la salida.
!
>

D 
!>          D es un array DOUBLE PRECISION, dimensión ( N )
!>           Este array se usa para especificar los autovalores de A.  Si
!>           MODE=0, entonces se asume que D contiene los autovalores (pero
!>           ver la descripción de EI), de lo contrario serán
!>           calculados de acuerdo con MODE, COND, DMAX y RSIGN y
!>           colocados en D.
!>           Se modifica si MODE es distinto de cero.
!
>

MOD

E 
!>          MODE es INTEGER
!>           En la entrada, esto describe cómo deben especificarse
!>           los autovalores:
!>           MODE = 0 significa usar D (con EI) como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D con números aleatorios en el rango
!>                    ( 1/COND , 1 ) tal que sus logaritmos
!>                    están uniformemente distribuidos.  Cada par
!>                    impar-par de elementos se usará ya sea como dos
!>                    autovalores reales o como la parte real y la
!>                    parte imaginaria de un par de autovalores
!>                    conjugados complejos; la elección de cuál se hace
!>                    es aleatoria, con probabilidad 50-50, para cada par.
!>           MODE = 6 establece D con números aleatorios de la misma
!>                    distribución que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D está invertido.
!>           Así que si MODE está entre 1 y 4, D tiene entradas que van
!>              de 1 a 1/COND, si está entre -1 y -4, D tiene entradas
!>              que van de 1/COND a 1,
!>           No se modifica.
!
>

CON

D 
!>          COND es DOUBLE PRECISION
!>           En la entrada, esto se usa como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No se modifica.
!
>

DMA

X 
!>          DMAX es DOUBLE PRECISION
!>           Si MODE no es ni -6, 0 ni 6, el contenido de D, tal como
!>           calculado de acuerdo con MODE y COND, será escalado por
!>           DMAX / max(abs(D(i))).  Note que DMAX no necesita ser
!>           positivo: si DMAX es negativo (o cero), D será
!>           escalado por un número negativo (o cero).
!>           No se modifica.
!
>

E

I 
!>          EI es un array CHARACTER*1, dimensión ( N )
!>           Si MODE es 0, y EI(1) no es ' ' (carácter espacio),
!>           este array especifica qué elementos de D (en la entrada) son
!>           autovalores reales y cuáles son la parte real y la parte
!>           imaginaria de un par de autovalores conjugados complejos.  Los
!>           elementos de EI pueden entonces solo tener los valores 'R' e 'I'.  Si
!>           EI(j)='R' y EI(j+1)='I', entonces el j-ésimo autovalor es
!>           CMPLX( D(j) , D(j+1) ), y el (j+1)-ésimo es el conjugado
!>           complejo del mismo.  Si EI(j)=EI(j+1)='R', entonces el j-ésimo
!>           autovalor es D(j) (es decir, real).  EI(1) no puede ser 'I',
!>           ni dos elementos adyacentes de EI pueden ambos tener el valor 'I'.
!>           Si MODE no es 0, entonces EI se ignora.  Si MODE es 0 y
!>           EI(1)=' ', entonces los autovalores serán todos reales.
!>           No se modifica.
!
>

RSIG

N 
!>          RSIGN es CHARACTER*1
!>           Si MODE no es 0, 6, o -6, y RSIGN='T', entonces los
!>           elementos de D, tal como calculados de acuerdo con MODE y COND, serán
!>           multiplicados por un signo aleatorio (+1 o -1).  Si RSIGN='F',
!>           no lo serán.  RSIGN solo puede tener los valores 'T' o
!>           'F'.
!>           No se modifica.
!
>

UPPE

R 
!>          UPPER es CHARACTER*1
!>           Si UPPER='T', entonces los elementos de A por encima de la diagonal
!>           (y por encima de los bloques diagonales de 2x2, si A tiene
!>           autovalores complejos) serán establecidos con números aleatorios de DIST.
!>           Si UPPER='F', no lo serán.  UPPER solo puede tener los
!>           valores 'T' o 'F'.
!>           No se modifica.
!
>

SI

M 
!>          SIM es CHARACTER*1
!>           Si SIM='T', entonces A será operated on by a , i.e., multiplied on the left by a matrix X and
!>           on the right by X inverse.  X = U S V, where U and V are
!>           random unitary matrices and S is a (diagonal) matrix of
!>           singular values specified by DS, MODES, and CONDS.  If
!>           SIM='F', then A will not be transformed.
!>           Not modified.
!
>

D

S 
!>          DS is DOUBLE PRECISION array, dimension ( N )
!>           This array is used to specify the singular values of X,
!>           in the same way that D specifies the eigenvalues of A.
!>           If MODE=0, the DS contains the singular values, which
!>           may not be zero.
!>           Modified if MODE is nonzero.
!
>

MODE

S 
!>          MODES is INTEGER
!
>

COND

S 
!>          CONDS is DOUBLE PRECISION
!>           Same as MODE and COND, but for specifying the diagonal
!>           of S.  MODES=-6 and +6 are not allowed (since they would
!>           result in randomly ill-conditioned eigenvalues.)
!
>

K

L 
!>          KL is INTEGER
!>           This specifies the lower bandwidth of the  matrix.  KL=1
!>           specifies upper Hessenberg form.  If KL is at least N-1,
!>           then A will have full lower bandwidth.  KL must be at
!>           least 1.
!>           Not modified.
!
>

K

U 
!>          KU is INTEGER
!>           This specifies the upper bandwidth of the  matrix.  KU=1
!>           specifies lower Hessenberg form.  If KU is at least N-1,
!>           then A will have full upper bandwidth; if KU and KL
!>           are both at least N-1, then A will be dense.  Only one of
!>           KU and KL may be less than N-1.  KU must be at least 1.
!>           Not modified.
!
>

ANOR

M 
!>          ANORM is DOUBLE PRECISION
!>           If ANORM is not negative, then A will be scaled by a non-
!>           negative real number to make the maximum-element-norm of A
!>           to be ANORM.
!>           Not modified.
!
>

A 
!>          A is DOUBLE PRECISION array, dimension ( LDA, N )
!>           On exit A is the desired test matrix.
!>           Modified.
!
>

LD

A 
!>          LDA is INTEGER
!>           LDA specifies the first dimension of A as declared in the
!>           calling program.  LDA must be at least N.
!>           Not modified.
!
>

WOR

K 
!>          WORK is DOUBLE PRECISION array, dimension ( 3*N )
!>           Workspace.
!>           Modified.
!
>

INF

O 
!>          INFO is INTEGER
!>           Error code.  On exit, INFO will be set to one of the
!>           following values:
!>             0 => normal return
!>            -1 => N negative
!>            -2 => DIST illegal string
!>            -5 => MODE not in range -6 to 6
!>            -6 => COND less than 1.0, and MODE neither -6, 0 nor 6
!>            -8 => EI(1) is not ' ' or 'R', EI(j) is not 'R' or 'I', or
!>                  two adjacent elements of EI are 'I'.
!>            -9 => RSIGN is not 'T' or 'F'
!>           -10 => UPPER is not 'T' or 'F'
!>           -11 => SIM   is not 'T' or 'F'
!>           -12 => MODES=0 and DS has a zero singular value.
!>           -13 => MODES is not in the range -5 to 5.
!>           -14 => MODES is nonzero and CONDS is less than 1.
!>           -15 => KL is less than 1.
!>           -16 => KU is less than 1, or KL and KU are both less than
!>                  N-1.
!>           -19 => LDA is less than N.
!>            1  => Error return from DLATM1 (computing D)
!>            2  => Cannot scale to DMAX (max. eigenvalue is 0)
!>            3  => Error return from DLATM1 (computing DS)
!>            4  => Error return from DLARGE
!>            5  => Zero singular value from DLATM1.
!
>
