subrutina dlalsd (uplo, smlsiz, n, nrhs, d, e, b, ldb, rcond, rank, work, iwork, info)
DLALSD utiliza la descomposición en valores singulares de A para resolver el problema de mínimos cuadrados.

Documentación de la función/subrutina

subrutina dlalsd (carácter uplo, entero smlsiz, entero n, entero nrhs, doble precisión, dimensión( * ) d, doble precisión, dimensión( * ) e, doble precisión, dimensión( ldb, * ) b, entero ldb, doble precisión rcond, entero rank, doble precisión, dimensión( * ) work, entero, dimensión( * ) iwork, entero info)

DLALSD utiliza la descomposición en valores singulares de A para resolver el problema de mínimos cuadrados.

Propósito:

!>
!> DLALSD utiliza la descomposición en valores singulares de A para resolver el problema de mínimos cuadrados.
!> de encontrar X que minimice la norma euclidiana de cada columna de A*X-B, donde A es bidiagonal superior de N por N, y X y B
!> son N por NRHS. La solución X sobrescribe B.
!>
!> Los valores singulares de A menores que RCOND veces el valor singular más grande
!> se tratan como cero al resolver el problema de mínimos cuadrados; en este caso se devuelve una solución de norma mínima.
!> Los valores singulares reales se devuelven en D en orden ascendente.
!>
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>         = 'U': D y E definen una matriz bidiagonal superior.
!>         = 'L': D y E definen una matriz bidiagonal inferior.
!>

SMLSIZ

!>          SMLSIZ es INTEGER
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de computación.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz bidiagonal. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>         El número de columnas de B. NRHS debe ser al menos 1.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>         En la entrada D contiene la diagonal principal de la matriz
!>         bidiagonal. En la salida, si INFO = 0, D contiene sus valores singulares.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N-1)
!>         Contiene las entradas superdiagonales de la matriz bidiagonal.
!>         En la salida, E ha sido destruido.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>         En la entrada, B contiene los lados derechos del problema de mínimos cuadrados.
!>         En la salida, B contiene la solución X.
!>

LDB

!>          LDB es INTEGER
!>         La dimensión principal de B en el subprograma llamador.
!>         LDB debe ser al menos max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>         Los valores singulares de A menores o iguales a RCOND veces
!>         el valor singular más grande se tratan como cero al resolver
!>         el problema de mínimos cuadrados. Si RCOND es negativo,
!>         se utiliza la precisión de la máquina en su lugar.
!>         Por ejemplo, si diag(S)*X=B fuera el problema de mínimos cuadrados,
!>         donde diag(S) es una matriz diagonal de valores singulares, la
!>         solución sería X(i) = B(i) / S(i) si S(i) es mayor que
!>         RCOND*max(S), y X(i) = 0 si S(i) es menor o igual a
!>         RCOND*max(S).
!>

RANK

!>          RANK es INTEGER
!>         El número de valores singulares de A mayores que RCOND veces
!>         el valor singular más grande.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión al menos
!>         (9*N + 2*N*SMLSIZ + 8*N*NLVL + N*NRHS + (SMLSIZ+1)**2),
!>         donde NLVL = max(0, INT(log_2 (N/(SMLSIZ+1))) + 1).
!>

IWORK

!>          IWORK es un array INTEGER, dimensión al menos
!>         (3*N*NLVL + 11*N)
!>

INFO

!>          INFO es INTEGER
!>         = 0:  salida exitosa.
!>         < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>         > 0:  El algoritmo no pudo calcular un valor singular mientras
!>               trabajaba en la submatriz situada en las filas y columnas
!>               INFO/(N+1) hasta MOD(INFO,N+1).
!>
