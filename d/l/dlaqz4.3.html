DLAQZ4

Propósito:

!>
!> DLAQZ4 Ejecuta un barrido QZ multidesplazamiento único
!>

Parámetros

ILSCHUR 
!>          ILSCHUR es LÓGICO
!>              Determina si se actualiza o no la forma completa de Schur
!>

ILQ

!>          ILQ es LÓGICO
!>              Determina si se actualiza o no la matriz Q
!>

ILZ

!>          ILZ es LÓGICO
!>              Determina si se actualiza o no la matriz Z
!>

N

!>          N es ENTERO
!>          El orden de las matrices A, B, Q y Z.  N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>

NSHIFTS

!>          NSHIFTS es ENTERO
!>          El número deseado de desplazamientos a utilizar
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED es ENTERO
!>          El tamaño deseado de las ventanas de cálculo
!>

SR

!>          SR es un arreglo de PRECISIÓN DOBLE. SR contiene
!>          las partes reales de los desplazamientos a utilizar.
!>

SI

!>          SI es un arreglo de PRECISIÓN DOBLE. SI contiene
!>          las partes imaginarias de los desplazamientos a utilizar.
!>

SS

!>          SS es un arreglo de PRECISIÓN DOBLE. SS contiene
!>          la escala de los desplazamientos a utilizar.
!>

A

!>          A es un arreglo de PRECISIÓN DOBLE, dimensión (LDA, N)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del arreglo A.  LDA >= max( 1, N ).
!>

B

!>          B es un arreglo de PRECISIÓN DOBLE, dimensión (LDB, N)
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del arreglo B.  LDB >= max( 1, N ).
!>

Q

!>          Q es un arreglo de PRECISIÓN DOBLE, dimensión (LDQ, N)
!>

LDQ

!>          LDQ es ENTERO
!>

Z

!>          Z es un arreglo de PRECISIÓN DOBLE, dimensión (LDZ, N)
!>

LDZ

!>          LDZ es ENTERO
!>

QC

!>          QC es un arreglo de PRECISIÓN DOBLE, dimensión (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC es ENTERO
!>

ZC

!>          ZC es un arreglo de PRECISIÓN DOBLE, dimensión (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ es ENTERO
!>

WORK

!>          WORK es un arreglo de PRECISIÓN DOBLE, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO >= 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del arreglo WORK.  LWORK >= max(1,N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
