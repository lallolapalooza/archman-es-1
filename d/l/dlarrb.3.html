Documentación de Función/Subrutina

subrutina dlarrb (integer n, double precision, dimension( * ) d, double precision, dimension( * ) lld, integer ifirst, integer ilast, double precision rtol1, double precision rtol2, integer offset, double precision, dimension( * ) w, double precision, dimension( * ) wgap, double precision, dimension( * ) werr, double precision, dimension( * ) work, integer, dimension( * ) iwork, double precision pivmin, double precision spdiam, integer twist, integer info)

DLARRB proporciona bisección limitada para localizar autovalores con mayor precisión.

Propósito:

!>
!> Dada la representación robusta relativamente (RRR) L D L^T, DLARRB
!> realiza una bisección para refinar los autovalores de L D L^T,
!> W( IFIRST-OFFSET ) a través de W( ILAST-OFFSET ), con mayor precisión. Las
!> conjeturas iniciales para estos autovalores se introducen en W, la estimación
!> correspondiente del error en estas conjeturas y sus separaciones se introducen en WERR
!> y WGAP, respectivamente. Durante la bisección, los intervalos
!> [left, right] se mantienen almacenando sus puntos medios y
!> semianchos en las matrices W y WERR respectivamente.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Los N elementos diagonales de la matriz diagonal D.
!>

LLD

!>          LLD es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los (N-1) elementos L(i)*L(i)*D(i).
!>

IFIRST

!>          IFIRST es INTEGER
!>          El índice del primer autovalor a calcular.
!>

ILAST

!>          ILAST es INTEGER
!>          El índice del último autovalor a calcular.
!>

RTOL1

!>          RTOL1 es DOUBLE PRECISION
!>

RTOL2

!>          RTOL2 es DOUBLE PRECISION
!>          Tolerancia para la convergencia de los intervalos de bisección.
!>          Un intervalo [LEFT,RIGHT] ha convergido si
!>          RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>          donde GAP es la (estimada) distancia al autovalor más cercano.
!>

OFFSET

!>          OFFSET es INTEGER
!>          Desplazamiento para las matrices W, WGAP y WERR, es decir, se deben usar los elementos
!>          de estas matrices desde IFIRST-OFFSET
!>          hasta ILAST-OFFSET.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, W( IFIRST-OFFSET ) a través de W( ILAST-OFFSET ) son
!>          estimaciones de los autovalores de L D L^T indexados desde IFIRST
!>          hasta ILAST.
!>          En la salida, estas estimaciones se refinan.
!>

WGAP

!>          WGAP es un array DOUBLE PRECISION, dimensión (N-1)
!>          En la entrada, las (estimadas) separaciones entre autovalores consecutivos
!>          de L D L^T, es decir, WGAP(I-OFFSET) es la separación entre
!>          los autovalores I e I+1. Nótese que si IFIRST = ILAST
!>          entonces WGAP(IFIRST-OFFSET) debe establecerse a ZERO.
!>          En la salida, estas separaciones se refinan.
!>

WERR

!>          WERR es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, WERR( IFIRST-OFFSET ) a través de WERR( ILAST-OFFSET ) son
!>          los errores en las estimaciones de los elementos correspondientes en W.
!>          En la salida, estos errores se refinan.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (2*N)
!>          Espacio de trabajo.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (2*N)
!>          Espacio de trabajo.
!>

PIVMIN

!>          PIVMIN es DOUBLE PRECISION
!>          El pivote mínimo en la secuencia de Sturm.
!>

SPDIAM

!>          SPDIAM es DOUBLE PRECISION
!>          El diámetro espectral de la matriz.
!>

TWIST

!>          TWIST es INTEGER
!>          El índice de torsión para la factorización retorcida que se usa
!>          para el negcount.
!>          TWIST = N: Calcular negcount desde L D L^T - LAMBDA I = L+ D+ L+^T
!>          TWIST = 1: Calcular negcount desde L D L^T - LAMBDA I = U- D- U-^T
!>          TWIST = R: Calcular negcount desde L D L^T - LAMBDA I = N(r) D(r) N(r)
!>

INFO

!>          INFO es INTEGER
!>          Indicador de error.
!>
