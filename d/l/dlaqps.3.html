Documentación de Función/Subrutina

subrutina dlaqps (integer m, integer n, integer offset, integer nb, integer kb, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, double precision, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, double precision, dimension( * ) auxv, double precision, dimension( ldf, * ) f, integer ldf)

DLAQPS calcula un paso de la factorización QR con pivoteo de columnas de una matriz real m por n A utilizando BLAS de nivel 3.

Propósito:

!>
!> DLAQPS calcula un paso de la factorización QR con pivoteo de columnas
!> de una matriz real M por N A utilizando Blas-3. Intenta factorizar
!> NB columnas de A comenzando desde la fila OFFSET+1, y actualiza toda
!> la matriz con Blas-3 xGEMM.
!>
!> En algunos casos, debido a cancelaciones catastróficas, no puede
!> factorizar NB columnas. Por lo tanto, el número real de columnas factorizadas
!> se devuelve en KB.
!>
!> El bloque A(1:OFFSET,1:N) se pivotea correspondientemente, pero no se
!> factoriza.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0
!>

OFFSET

!>          OFFSET es INTEGER
!>          El número de filas de A que han sido factorizadas en
!>          pasos anteriores.
!>

NB

!>          NB es INTEGER
!>          El número de columnas a factorizar.
!>

KB

!>          KB es INTEGER
!>          El número de columnas realmente factorizadas.
!>

A

!>          A es array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, el bloque A(OFFSET+1:M,1:KB) es el factor
!>          triangular obtenido y el bloque A(1:OFFSET,1:N) ha sido
!>          pivoteado correspondientemente, pero no se ha factorizado.
!>          El resto de la matriz, bloque A(OFFSET+1:M,KB+1:N), ha sido
!>          actualizado.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT es array INTEGER, dimensión (N)
!>          JPVT(I) = K <==> La columna K de la matriz completa A ha sido
!>          permutada a la posición I en AP.
!>

TAU

!>          TAU es array DOUBLE PRECISION, dimensión (KB)
!>          Los factores escalares de los reflectores elementales.
!>

VN1

!>          VN1 es array DOUBLE PRECISION, dimensión (N)
!>          El vector con las normas parciales de las columnas.
!>

VN2

!>          VN2 es array DOUBLE PRECISION, dimensión (N)
!>          El vector con las normas exactas de las columnas.
!>

AUXV

!>          AUXV es array DOUBLE PRECISION, dimensión (NB)
!>          Vector auxiliar.
!>

F

!>          F es array DOUBLE PRECISION, dimensión (LDF,NB)
!>          Matriz F**T = L*Y**T*A.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del array F. LDF >= max(1,N).
!>
