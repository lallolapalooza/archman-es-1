Propósito

: 
!>
!> DLATM5 genera matrices involucradas en la Ecuación de Sylvester
!> Generalizada:
!>
!>     A * R - L * B = C
!>     D * R - L * E = F
!>
!> También satisfacen (la condición de diagonalización)
!>
!>  [ I -L ] ( [ A  -C ], [ D -F ] ) [ I  R ] = ( [ A    ], [ D    ] )
!>  [    I ] ( [     B ]  [    E ] ) [    I ]   ( [    B ]  [    E ] )
!>
!
>

Detalles

Adicionales: 
!>
!>  PRTYPE = 1: A y B son bloques de Jordan, D y E son matrices identidad
!>
!>             A : si (i == j) entonces A(i, j) = 1.0
!>                 si (j == i + 1) entonces A(i, j) = -1.0
!>                 en otro caso A(i, j) = 0.0,            i, j = 1...M
!>
!>             B : si (i == j) entonces B(i, j) = 1.0 - ALPHA
!>                 si (j == i + 1) entonces B(i, j) = 1.0
!>                 en otro caso B(i, j) = 0.0,            i, j = 1...N
!>
!>             D : si (i == j) entonces D(i, j) = 1.0
!>                 en otro caso D(i, j) = 0.0,            i, j = 1...M
!>
!>             E : si (i == j) entonces E(i, j) = 1.0
!>                 en otro caso E(i, j) = 0.0,            i, j = 1...N
!>
!>             L =  R se eligen de [-10...10],
!>                  lo cual especifica los miembros libres (C, F).
!>
!>  PRTYPE = 2 o 3: Triangular y/o cuasi-triangular.
!>
!>             A : si (i <= j) entonces A(i, j) = [-1...1]
!>                 en otro caso A(i, j) = 0.0,             i, j = 1...M
!>
!>                 si (PRTYPE = 3) entonces
!>                    A(k + 1, k + 1) = A(k, k)
!>                    A(k + 1, k) = [-1...1]
!>                    sign(A(k, k + 1) = -(sin(A(k + 1, k))
!>                        k = 1, M - 1, QBLCKA
!>
!>             B : si (i <= j) entonces B(i, j) = [-1...1]
!>                 en otro caso B(i, j) = 0.0,            i, j = 1...N
!>
!>                 si (PRTYPE = 3) entonces
!>                    B(k + 1, k + 1) = B(k, k)
!>                    B(k + 1, k) = [-1...1]
!>                    sign(B(k, k + 1) = -(sign(B(k + 1, k))
!>                        k = 1, N - 1, QBLCKB
!>
!>             D : si (i <= j) entonces D(i, j) = [-1...1].
!>                 en otro caso D(i, j) = 0.0,            i, j = 1...M
!>
!>
!>             E : si (i <= j) entonces D(i, j) = [-1...1]
!>                 en otro caso E(i, j) = 0.0,            i, j = 1...N
!>
!>                 L, R se eligen de [-10...10],
!>                 lo cual especifica los miembros libres (C, F).
!>
!>  PRTYPE = 4 Completo
!>             A(i, j) = [-10...10]
!>             D(i, j) = [-1...1]    i,j = 1...M
!>             B(i, j) = [-10...10]
!>             E(i, j) = [-1...1]    i,j = 1...N
!>             R(i, j) = [-10...10]
!>             L(i, j) = [-1...1]    i = 1..M ,j = 1...N
!>
!>             L, R especifican los miembros libres (C, F).
!>
!>  PRTYPE = 5 caso especial común y/o eigenvalores cercanos.
!
>
