subrutina dlat2s (uplo, n, a, lda, sa, ldsa, info)
DLAT2S convierte una matriz triangular de doble precisión a una matriz triangular de precisión simple.

Documentación de la función/subrutina

subrutina dlat2s (character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, real, dimension( ldsa, * ) sa, integer ldsa, integer info)

DLAT2S convierte una matriz triangular de DOBLE PRECISIÓN, SA, a una matriz triangular de PRECISIÓN SIMPLE, A.

Propósito:

!>
!> DLAT2S convierte una matriz triangular de DOBLE PRECISIÓN, SA, a una
!> matriz triangular de PRECISIÓN SIMPLE, A.
!>
!> RMAX es el desbordamiento para la aritmética de PRECISIÓN SIMPLE
!> DLAS2S comprueba que todas las entradas de A están entre -RMAX y
!> RMAX. Si no es así, la conversión se aborta y se eleva una bandera.
!>
!> Esta es una subrutina auxiliar, por lo que no hay comprobación de argumentos.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz de coeficientes triangular A de NxN.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

SA

!>          SA es un array REAL, dimensión (LDSA,N)
!>          Solo la parte UPLO de SA se referencia. En la salida, si INFO=0,
!>          la matriz de coeficientes SA de NxN; si INFO>0, el contenido de
!>          la parte UPLO de SA no está especificado.
!>

LDSA

!>          LDSA es INTEGER
!>          La dimensión principal del array SA.  LDSA >= max(1,M).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          = 1:  una entrada de la matriz A es mayor que el umbral de
!>                desbordamiento de PRECISIÓN SIMPLE, en este caso, el contenido
!>                de la parte UPLO de SA en la salida no está especificado.
!>
