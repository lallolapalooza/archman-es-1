subroutine dla_porfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, logical colequ, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, double precision, dimension( * ) res, double precision, dimension(*) ayb, double precision, dimension( * ) dy, double precision, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

DLA_PORFSX_EXTENDED mejora la solución calculada para un sistema de ecuaciones lineales para matrices simétricas o Hermitianas definidas positivas realizando un refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> DLA_PORFSX_EXTENDED mejora la solución calculada para un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona límites de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por DPORFSX para realizar el refinamiento iterativo.
!> Además del límite de error normwise, el código proporciona el límite de error
!> máximo por componentes si es posible. Ver comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para detalles de los límites de error. Nótese que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia que se utilizará en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>     A la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array DOUBLE PRECISION, dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como es calculada por DPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó el escalado de columnas a A antes de llamar
!>     a esta rutina. Esto es necesario para calcular correctamente la solución y
!>     los límites de error.
!>

C

!>          C es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se ingresa C, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea un subdesbordamiento o desbordamiento. Los errores de
!>     redondeo durante el escalado conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de
!>     error que pueden no ser fiables.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es un array DOUBLE PRECISION, dimensión (LDY,NRHS)
!>     A la entrada, la matriz solución X, tal como es calculada por DPOTRS.
!>     A la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un array DOUBLE PRECISION, dimensión (NRHS)
!>     A la salida, BERR_OUT(j) contiene el error relativo residual por componentes
!>     para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto por componentes de la matriz
!>     o vector Z. Esto es calculado por DLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error se devuelven (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 se devuelven límites de error normwise.
!>     Si N_NORMS >= 2 se devuelven límites de error por componentes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi

ERR_BNDS_COM

P 
!>          ERR_BNDS_COMP es un arreglo de DOBLE PRECISIÓN, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El arreglo está indexado por el segundo miembro i (del cual
!>     depende el error relativo componente a componente), y el tipo de
!>     información de error descrito a continuación. Actualmente se
!>     devuelven hasta tres piezas de información para cada segundo
!>     miembro. Si no se solicita precisión componente a componente
!>     (PARAMS(3) = 0.0), entonces no se accede a ERR_BNDS_COMP. Si
!>     N_ERR_BNDS < 3, entonces se devuelven como máximo las primeras
!>     entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi ciertamente dentro de un factor de 10 del error
!>              real siempre que la siguiente entrada sea mayor que el
!>              umbral sqrt(n) * slamch('Epsilon'). Este límite de error
!>              solo debe ser confiado si el booleano anterior es
!>              verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco componente a componente estimado. Comparado con
!>              el umbral sqrt(n) * slamch('Epsilon') para determinar si
!>              la estimación del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las
!>              sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Este subrutina solo es responsable de establecer el segundo campo
!>     anterior.
!>     Consulte Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

RE

S 
!>          RES es un arreglo de DOBLE PRECISIÓN, dimensión (N)
!>     Espacio de trabajo para mantener el residuo intermedio.
!
>

AY

B 
!>          AYB es un arreglo de DOBLE PRECISIÓN, dimensión (N)
!>     Espacio de trabajo. Este puede ser el mismo espacio de trabajo
!>     pasado para Y_TAIL.
!
>

D

Y 
!>          DY es un arreglo de DOBLE PRECISIÓN, dimensión (N)
!>     Espacio de trabajo para mantener la solución intermedia.
!
>

Y_TAI

L 
!>          Y_TAIL es un arreglo de DOBLE PRECISIÓN, dimensión (N)
!>     Espacio de trabajo para mantener los bits finales de la solución
!>     intermedia.
!
>

RCON

D 
!>          RCOND es DOBLE PRECISIÓN
!>     Número de condición recíproco escalado. Esta es una estimación
!>     del número de condición recíproco de Skeel de la matriz A
!>     después del equilibrado (si se hizo). Si esto es menor que la
!>     precisión de la máquina (en particular, si es cero), la matriz es
!>     singular hasta la precisión de trabajo. Tenga en cuenta que el
!>     error puede seguir siendo pequeño incluso si este número es muy
!>     pequeño y la matriz parece mal condicionada.
!
>

ITHRES

H 
!>          ITHRESH es INTEGER
!>     El número máximo de cálculos de residuo permitidos para el
!>     refinamiento. El valor predeterminado es 10. Para 'aggressive'
!>     establecer a 100 para permitir la convergencia usando
!>     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>     la factorización usa una técnica distinta de la eliminación de
!>     Gauss, las garantías en ERR_BNDS_NORM y ERR_BNDS_COMP pueden ya
!>     no ser confiables.
!
>

RTHRES

H 
!>          RTHRESH es DOBLE PRECISIÓN
!>     Determina cuándo detener el refinamiento si la estimación del
!>     error deja de disminuir. El refinamiento se detendrá cuando la
!>     siguiente solución ya no satisfaga norm(dx_{i+1}) < RTHRESH *
!>     norm(dx_i) donde norm(Z) es la norma infinita de Z. RTHRESH
!>     satisface 0 < RTHRESH <= 1. El valor predeterminado es 0.5. Para
!>     'aggressive' establecer a 0.9 para permitir la convergencia en
!>     matrices extremadamente mal condicionadas. Consulte LAWN 165 para
!>     más detalles.
!
>

DZ_U

B 
!>          DZ_UB es DOBLE PRECISIÓN
!>     Determina cuándo comenzar a considerar la convergencia componente
!>     a componente. La convergencia componente a componente solo se
!>     considera después de que cada componente de la solución Y sea
!>     estable, lo cual definimos como el cambio relativo en cada
!>     componente siendo menor que DZ_UB. El valor predeterminado es
!>     0.25, requiriendo que el primer bit sea estable. Consulte LAWN
!>     165 para más detalles.
!
>

IGNORE_CWIS

E 
!>          IGNORE_CWISE es LOGICAL
!>     Si .TRUE. entonces ignorar la convergencia componente a
!>     componente. El valor predeterminado es .FALSE..
!
>

INF

O 
!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  si INFO = -i, el i-ésimo argumento de DPOTRS tenía un
!>             valor ilegal
!>
