DLASDA calcula la descomposición en valores singulares (SVD) de una matriz real bidiagonal superior con diagonal D y superdiagonal E. Usado por sbdsdc.

Propósito:

!>
!> Utilizando un enfoque de divide y vencerás, DLASDA calcula la
!> descomposición en valores singulares (SVD) de una matriz B real
!> bidiagonal superior N por M con diagonal D y superdiagonal E, donde
!> M = N + SQRE. El algoritmo calcula los valores singulares en la SVD
!> B = U * S * VT. Las matrices ortogonales U y VT se calculan
!> opcionalmente en forma compacta.
!>
!> Una subrutina relacionada, DLASD0, calcula los valores singulares y
!> los vectores singulares en forma explícita.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si los vectores singulares se calcularán
!>         en forma compacta, de la siguiente manera:
!>         = 0: Calcular solo los valores singulares.
!>         = 1: Calcular los vectores singulares de la matriz
!>              bidiagonal superior en forma compacta.
!>

SMLSIZ

!>          SMLSIZ es INTEGER
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de computación.
!>

N

!>          N es INTEGER
!>         La dimensión de fila de la matriz bidiagonal. Esta es
!>         también la dimensión del array de la diagonal principal D.
!>

SQRE

!>          SQRE es INTEGER
!>         Especifica la dimensión de columna de la matriz bidiagonal.
!>         = 0: La matriz bidiagonal tiene dimensión de columna M = N;
!>         = 1: La matriz bidiagonal tiene dimensión de columna M = N + 1.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión ( N )
!>         En la entrada D contiene la diagonal principal de la matriz
!>         bidiagonal. En la salida D, si INFO = 0, contiene sus valores
!>         singulares.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión ( M-1 )
!>         Contiene las entradas de la subdiagonal de la matriz
!>         bidiagonal. En la salida, E ha sido destruido.
!>

U

!>          U es un array DOUBLE PRECISION,
!>         de dimensión ( LDU, SMLSIZ ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, U contiene las
!>         matrices de vectores singulares izquierdos de todos los
!>         subproblemas en el nivel inferior.
!>

LDU

!>          LDU es INTEGER, LDU = > N.
!>         La dimensión principal de los arrays U, VT, DIFL, DIFR, POLES,
!>         GIVNUM y Z.
!>

VT

!>          VT es un array DOUBLE PRECISION,
!>         de dimensión ( LDU, SMLSIZ+1 ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, VT**T contiene las
!>         matrices de vectores singulares derechos de todos los
!>         subproblemas en el nivel inferior.
!>

K

!>          K es un array INTEGER,
!>         de dimensión ( N ) si ICOMPQ = 1 y de dimensión 1 si ICOMPQ = 0.
!>         Si ICOMPQ = 1, en la salida, K(I) es la dimensión de la I-ésima
!>         ecuación secular en el árbol de computación.
!>

DIFL

!>          DIFL es un array DOUBLE PRECISION, de dimensión ( LDU, NLVL ),
!>         donde NLVL = floor(log_2 (N/SMLSIZ))).
!>

DIFR

!>          DIFR es un array DOUBLE PRECISION,
!>                  de dimensión ( LDU, 2 * NLVL ) si ICOMPQ = 1 y
!>                  de dimensión ( N ) si ICOMPQ = 0.
!>         Si ICOMPQ = 1, en la salida, DIFL(1:N, I) y DIFR(1:N, 2 * I - 1)
!>         registran las distancias entre los valores singulares en el nivel
!>         I y los valores singulares en el nivel (I -1), y
!>         DIFR(1:N, 2 * I ) contiene los factores de normalización para
!>         la matriz de vectores singulares derechos. Ver DLASD8 para detalles.
!>

Z

!>          Z es un array DOUBLE PRECISION,
!>                  de dimensión ( LDU, NLVL ) si ICOMPQ = 1 y
!>                  de dimensión ( N ) si ICOMPQ = 0.
!>         Los primeros K elementos de Z(1, I) contienen los componentes
!>         del vector fila de actualización ajustado por deflación para
!>         subproblemas en el nivel I.
!>

POLES

!>          POLES es un array DOUBLE PRECISION,
!>         de dimensión ( LDU, 2 * NLVL ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, POLES(1, 2*I - 1) y
!>         POLES(1, 2*I) contienen los valores singulares nuevos y antiguos
!>         involucrados en las ecuaciones secular en el nivel I.
!>

GIVPTR

!>          GIVPTR es un array INTEGER,
!>         de dimensión ( N ) si ICOMPQ = 1, y no referenciado si
!>         ICOMPQ = 0. Si ICOMPQ = 1, en la salida, GIVPTR( I ) registra
!>         el número de rotaciones de Givens realizadas en el I-ésimo
!>         problema en el árbol de computación.
!>

GIVCOL

!>          GIVCOL es un array INTEGER,
!>         de dimensión ( LDGCOL, 2 * NLVL ) si ICOMPQ = 1, y no
!>         referenciado si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, para cada I,
!>         GIVCOL(1, 2 *I - 1) y GIVCOL(1, 2 *I) registran las ubicaciones
!>         de las rotaciones de Givens realizadas en el nivel I en el
!>         árbol de computación.
!>

LDGCOL

!>          LDGCOL es INTEGER, LDGCOL = > N.
!>         La dimensión principal de los arrays GIVCOL y PERM.
!>

PERM

!>          PERM es un array INTEGER,
!>         de dimensión ( LDGCOL, NLVL ) si ICOMPQ = 1, y no referenciado
!>         si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, PERM(1, I) registra
!>         las permutaciones realizadas en el nivel I del árbol de
!>         computación.
!>

GIVNUM

!>          GIVNUM es un array DOUBLE PRECISION,
!>         de dimensión ( LDU,  2 * NLVL ) si ICOMPQ = 1, y no
!>         referenciado si ICOMPQ = 0. Si ICOMPQ = 1, en la salida, para cada I,
!>         GIVNUM(1, 2 *I - 1) y GIVNUM(1, 2 *I) registran los valores C y S
!>         de la rotación de Givens
