subroutine dlanv2 (double precision a, double precision b, double precision c, double precision d, double precision rt1r, double precision rt1i, double precision rt2r, double precision rt2i, double precision cs, double precision sn)

DLANV2 calcula la factorización de Schur de una matriz real de 2x2 no simétrica en forma estándar:

Propósito:

!>
!> DLANV2 calcula la factorización de Schur de una matriz real de 2x2 no
!> simétrica en forma estándar:
!>
!>      [ A  B ] = [ CS -SN ] [ AA  BB ] [ CS  SN ]
!>      [ C  D ]   [ SN  CS ] [ CC  DD ] [-SN  CS ]
!>
!> donde o bien
!> 1) CC = 0, de modo que AA y DD son autovalores reales de la matriz, o
!> 2) AA = DD y BB*CC < 0, de modo que AA + o - sqrt(BB*CC) son autovalores
!>    conjugados complejos.
!>

Parámetros

A 
!>          A es DOUBLE PRECISION
!>

B

!>          B es DOUBLE PRECISION
!>

C

!>          C es DOUBLE PRECISION
!>

D

!>          D es DOUBLE PRECISION
!>          En la entrada, los elementos de la matriz de entrada.
!>          En la salida, son sobrescritos por los elementos de la forma
!>          de Schur estandarizada.
!>

RT1R

!>          RT1R es DOUBLE PRECISION
!>

RT1I

!>          RT1I es DOUBLE PRECISION
!>

RT2R

!>          RT2R es DOUBLE PRECISION
!>

RT2I

!>          RT2I es DOUBLE PRECISION
!>          Las partes real e imaginaria de los autovalores. Si los
!>          autovalores son un par conjugado complejo, RT1I > 0.
!>

CS

!>          CS es DOUBLE PRECISION
!>

SN

!>          SN es DOUBLE PRECISION
!>          Parámetros de la matriz de rotación.
!>
