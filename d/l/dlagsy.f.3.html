Documentación de función/subrutina

subrutina dlagsy (integer n, integer k, double precision, dimension( * ) d, double precision, dimension( lda, * ) a, integer lda, integer, dimension( 4 ) iseed, double precision, dimension( * ) work, integer info)

DLAGSY

Propósito:

!>
!> DLAGSY genera una matriz simétrica real A, multiplicando previamente y
!> posteriormente una matriz diagonal real D con una matriz ortogonal
!> aleatoria: A = U*D*U'. El semibanda puede reducirse entonces a k mediante
!> transformaciones ortogonales adicionales.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

K

!>          K es INTEGER
!>          El número de subdiagonales no nulas dentro de la banda de A.
!>          0 <= K <= N-1.
!>

D

!>          D es array DOUBLE PRECISION, dimension (N)
!>          Los elementos diagonales de la matriz diagonal D.
!>

A

!>          A es array DOUBLE PRECISION, dimension (LDA,N)
!>          La matriz simétrica A de tamaño n por n generada (se almacena
!>          la matriz completa).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= N.
!>

ISEED

!>          ISEED es array INTEGER, dimension (4)
!>          En la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe
!>          ser impar.
!>          En la salida, la semilla se actualiza.
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimension (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
