Funciones/Subrutinas


función de precisión doble dlanhs (norma, n, a, lda, work)

DLANHS devuelve el valor de la norma 1, norma de Frobenius, norma infinito o el valor absoluto más grande de cualquier elemento de una matriz de Hessenberg superior.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

double precision function dlanhs (character norm, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

DLANHS devuelve el valor de la norma 1, norma de Frobenius, norma infinito o el valor absoluto más grande de cualquier elemento de una matriz de Hessenberg superior.

Propósito:

!>
!> DLANHS  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz de Hessenberg A.
!>

Retorna

DLANHS 
!>
!>    DLANHS = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en DLANHS como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, DLANHS se
!>          establece en cero.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>          La matriz de Hessenberg superior n por n A; la parte de A debajo
!>          de la primera subdiagonal no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I'; de lo contrario, WORK no
!>          se referencia.
!>
