subrutina dlahqr (logical wantt, logical wantz, integer n, integer ilo, integer ihi, double precision, dimension( ldh, * ) h, integer ldh, double precision, dimension( * ) wr, double precision, dimension( * ) wi, integer iloz, integer ihiz, double precision, dimension( ldz, * ) z, integer ldz, integer info)

DLAHQR calcula los valores propios y la factorización de Schur de una matriz de Hessenberg superior, utilizando el algoritmo QR de doble/simple cambio.

Propósito:

!>
!>    DLAHQR es una subrutina auxiliar llamada por DHSEQR para actualizar los
!>    valores propios y la descomposición de Schur ya calculados por DHSEQR,
!>    tratando la submatriz de Hessenberg en las filas y columnas ILO a
!>    IHI.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          = .TRUE. : se requiere la forma de Schur completa T;
!>          = .FALSE.: sólo se requieren los valores propios.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          = .TRUE. : se requiere la matriz de vectores de Schur Z;
!>          = .FALSE.: no se requieren los vectores de Schur.
!>

N

!>          N es INTEGER
!>          El orden de la matriz H.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          Se asume que H ya es cuasi-triangular superior en las
!>          filas y columnas IHI+1:N, y que H(ILO,ILO-1) = 0 (a menos que
!>          ILO = 1). DLAHQR trabaja principalmente con la submatriz de
!>          Hessenberg en las filas y columnas ILO a IHI, pero aplica
!>          transformaciones a todo H si WANTT es .TRUE..
!>          1 <= ILO <= max(1,IHI); IHI <= N.
!>

H

!>          H es array DOUBLE PRECISION, dimension (LDH,N)
!>          En la entrada, la matriz de Hessenberg superior H.
!>          En la salida, si INFO es cero y si WANTT es .TRUE., H es cuasi-triangular
!>          superior en las filas y columnas ILO:IHI, con cualquier
!>          bloque diagonal de 2x2 en forma estándar. Si INFO es cero
!>          y WANTT es .FALSE., el contenido de H no está especificado
!>          en la salida. El estado de salida de H si INFO es no nulo se da
!>          a continuación bajo la descripción de INFO.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H. LDH >= max(1,N).
!>

WR

!>          WR es array DOUBLE PRECISION, dimension (N)
!>

WI

!>          WI es array DOUBLE PRECISION, dimension (N)
!>          Las partes real e imaginaria, respectivamente, de los valores
!>          propios calculados ILO a IHI se almacenan en los elementos
!>          correspondientes de WR y WI. Si dos valores propios se calculan
!>          como un par conjugado complejo, se almacenan en elementos
!>          consecutivos de WR y WI, digamos el i-ésimo y (i+1)-ésimo,
!>          con WI(i) > 0 y WI(i+1) < 0. Si WANTT es .TRUE., los
!>          valores propios se almacenan en el mismo orden que en la diagonal
!>          de la forma de Schur devuelta en H, con WR(i) = H(i,i), y, si
!>          H(i:i+1,i:i+1) es un bloque diagonal de 2x2,
!>          WI(i) = sqrt(H(i+1,i)*H(i,i+1)) y WI(i+1) = -WI(i).
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>          Especificar las filas de Z a las que se deben aplicar
!>          transformaciones si WANTZ es .TRUE..
!>          1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z es array DOUBLE PRECISION, dimension (LDZ,N)
!>          Si WANTZ es .TRUE., en la entrada Z debe contener la matriz
!>          actual Z de transformaciones acumuladas por DHSEQR, y en
!>          la salida Z se ha actualizado; las transformaciones se aplican
!>          sólo a la submatriz Z(ILOZ:IHIZ,ILO:IHI).
!>          Si WANTZ es .FALSE., Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>           = 0:  salida exitosa
!>           > 0:  Si INFO = i, DLAHQR no pudo calcular todos los
!>                  valores propios ILO a IHI en un total de 30 iteraciones
!>                  por valor propio; los elementos i+1:ihi de WR y WI
!>                  contienen aquellos valores propios que han sido
!>                  calculados con éxito.
!>
!>                  Si INFO > 0 y WANTT es .FALSE., entonces en la salida,
!>                  los valores propios no convergidos restantes son los
!>                  valores propios de la matriz de Hessenberg superior
!>                  filas y columnas ILO a INFO del valor final, de salida,
!>                  de H.
!>
!>                  Si INFO > 0 y WANTT es .TRUE., entonces en la salida
!>                  (valor inicial de H)*U  = U*(valor final de H)
!>                  donde U es una matriz ortogonal. El valor final de H
!>                  es de Hessenberg superior y triangular en las filas y
!>                  columnas INFO+1 hasta IHI.
!>
!>                  Si INFO > 0 y WANTZ es .TRUE., entonces en la salida
!>                      (valor final de Z)  = (valor inicial de Z)*U
!>                  donde U es la matriz ortogonal en (*)
!>                  (independientemente del valor de WANTT.)
!>

NOMBRE

dlahqr - calcula los valores propios y vectores propios de una matriz Hessenberg.

SINAPSIS

SUBROUTINE dlahqr(WANTT, WANTZ, N, ILO, IHI, A, LDA, B, LDB, WR, WI, Z, LDZ, WORK, LWORK, INFO)
    IMPLICIT NONE
    LOGICAL                      :: WANTT, WANTZ
    INTEGER                      :: ILO, IHI, N, LDA, LDB, LDZ, LWORK, INFO
    DOUBLE PRECISION             :: A(LDA, *)
    DOUBLE PRECISION             :: B(LDB, *)
    DOUBLE PRECISION             :: WR(*), WI(*)
    DOUBLE PRECISION             :: Z(LDZ, *)
    DOUBLE PRECISION             :: WORK(*)

DESCRIPCIÓN

Esta subrutina calcula los valores propios y, opcionalmente, los vectores propios de una matriz Hessenberg general. Los valores propios se devuelven en las matrices WR y WI. Los vectores propios se devuelven en la matriz Z.

PARÁMETROS

  • WANTT - (entrada) LOGICAL. Especifica si se deben calcular los vectores propios unitarios de la matriz T (una matriz triangular superior).
  • WANTZ - (entrada) LOGICAL. Especifica si se deben calcular los vectores propios de la matriz A.
  • N - (entrada) INTEGER. El orden de la matriz A.
  • ILO - (entrada) INTEGER. Si A es de Hessenberg, ILO y IHI definen el subbloque de Hessenberg que debe ser procesado.
  • IHI - (entrada) INTEGER. Véase ILO.
  • A - (entrada/salida) DOUBLE PRECISION de dimensión (LDA, *) . En la entrada, A contiene la matriz Hessenberg general. En la salida, A contiene la matriz triangular superior T.
  • LDA - (entrada) INTEGER. La longitud de la primera dimensión de A.
  • B - (salida) DOUBLE PRECISION de dimensión (LDB, *) . Si WANTT es .TRUE., B contendrá la matriz triangular unitaria Q tal que B^H A B = T.
  • LDB - (entrada) INTEGER. La longitud de la primera dimensión de B.
  • WR - (salida) DOUBLE PRECISION de dimensión (*). La parte real de los valores propios.
  • WI - (salida) DOUBLE PRECISION de dimensión (*). La parte imaginaria de los valores propios.
  • Z - (salida) DOUBLE PRECISION de dimensión (LDZ, *) . Si WANTZ es .TRUE., Z contiene los vectores propios correspondientes a los valores propios de A.
  • LDZ - (entrada) INTEGER. La longitud de la primera dimensión de Z.
  • WORK - (salida) DOUBLE PRECISION de dimensión (*). Memoria de trabajo.
  • LWORK - (entrada) INTEGER. La longitud de la matriz WORK.
  • INFO - (salida) INTEGER. = 0: éxito; < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.

EJEMPLOS

Este es un ejemplo de cómo usar la subrutina dlahqr:

    PROGRAM EXAMPLE
                    IMPLICIT NONE
                    INTEGER, PARAMETER :: NMAX = 100
                    INTEGER :: N, LDA, LDB, LDZ, LWORK, ILO, IHI, INFO
                    DOUBLE PRECISION :: A(NMAX, NMAX), B(NMAX, NMAX), WR(NMAX), WI(NMAX), Z(NMAX, NMAX), WORK(NMAX*NMAX)
                    LOGICAL :: WANTT, WANTZ
                    INTEGER :: I, J

                    ! Inicializar parámetros
                    N = 4
                    LDA = NMAX
                    LDB = NMAX
                    LDZ = NMAX
                    LWORK = NMAX * NMAX
                    WANTT = .TRUE.
                    WANTZ = .TRUE.

                    ! Definir una matriz A de Hessenberg
                    A = 0.0D0
                    A(1,1) = 1.0D0; A(1,2) = 2.0D0; A(2,1) = 3.0D0; A(2,2) = 4.0D0
                    A(2,3) = 5.0D0; A(3,2) = 6.0D0; A(3,3) = 7.0D0; A(3,4) = 8.0D0
                    A(4,3) = 9.0D0; A(4,4) = 10.0D0

                    ILO = 1
                    IHI = N

                    ! Llamar a la subrutina dlahqr
                    CALL dlahqr(WANTT, WANTZ, N, ILO, IHI, A, LDA, B, LDB, WR, WI, Z, LDZ, WORK, LWORK, INFO)

                    ! Comprobar si hubo errores
                    IF (INFO .NE. 0) THEN
                      PRINT *, 'dlahqr devolvió un error con INFO = ', INFO
                    ELSE
                      ! Imprimir los valores propios
                      PRINT *, 'Valores propios:'
                      DO I = 1, N
                        PRINT '(F10.5, F10.5)', WR(I), WI(I)
                      END DO

                      ! Imprimir la matriz triangular T
                      PRINT *, 'Matriz T:'
                      DO I = 1, N
                        DO J = 1, N
                          PRINT '(F10.5)', A(I,J)
                        END DO
                        PRINT *
                      END DO

                      ! Imprimir la matriz unitaria Q si WANTT es .TRUE.
                      IF (WANTT) THEN
                        PRINT *, 'Matriz Q:'
                        DO I = 1, N
                          DO J = 1, N
                            PRINT '(F10.5)', B(I,J)
                          END DO
                          PRINT *
                        END DO
                      END IF

                      ! Imprimir los vectores propios si WANTZ es .TRUE.
                      IF (WANTZ) THEN
                        PRINT *, 'Vectores propios:'
                        DO I = 1, N
                          DO J = 1, N
                            PRINT '(F10.5)', Z(I,J)
                          END DO
                          PRINT *
                        END DO
                      END IF
                    END IF
                    END PROGRAM EXAMPLE
