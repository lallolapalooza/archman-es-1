subrutina dlatm4 (integer itype, integer n, integer nz1, integer nz2, integer isign, double precision amagn, double precision rcond, double precision triang, integer idist, integer, dimension( 4 ) iseed, double precision, dimension( lda, * ) a, integer lda)

DLATM4

Propósito:

!>
!> DLATM4 genera matrices cuadradas básicas, que luego pueden ser
!> multiplicadas por otras para producir matrices de prueba. Está
!> destinada principalmente a probar las rutinas de valores propios generalizados.
!>
!> Primero genera la diagonal y (posiblemente) la subdiagonal,
!> de acuerdo con los valores de ITYPE, NZ1, NZ2, ISIGN, AMAGN y RCOND.
!> Luego rellena el triángulo superior con números aleatorios, si TRIANG no
!> es cero.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          El tipo de matriz en la diagonal y subdiagonal.
!>          Si ITYPE < 0, entonces se genera el tipo abs(ITYPE) y luego
!>             se invierte extremo por extremo (A(I,J) := A'(N-J,N-I).)  Véase también
!>             la descripción de AMAGN e ISIGN.
!>
!>          Tipos especiales:
!>          = 0: la matriz cero.
!>          = 1: la identidad.
!>          = 2: un bloque de Jordan transpuesto.
!>          = 3: Si N es impar, entonces un bloque de Jordan transpuesto k+1 x k+1
!>                seguido de un bloque de identidad k x k, donde k=(N-1)/2.
!>                Si N es par, entonces k=(N-2)/2, y se añade una entrada diagonal cero
!>                al final.
!>
!>          Tipos de diagonal. La diagonal consiste en NZ1 ceros, luego
!>             k=N-NZ1-NZ2 no ceros. La subdiagonal es cero. ITYPE
!>             especifica las entradas diagonales no nulas como sigue:
!>          = 4: 1, ..., k
!>          = 5: 1, RCOND, ..., RCOND
!>          = 6: 1, ..., 1, RCOND
!>          = 7: 1, a, a^2, ..., a^(k-1)=RCOND
!>          = 8: 1, 1-d, 1-2*d, ..., 1-(k-1)*d=RCOND
!>          = 9: números aleatorios elegidos de (RCOND,1)
!>          = 10: números aleatorios con distribución IDIST (ver DLARND).
!>

N

!>          N es INTEGER
!>          El orden de la matriz.
!>

NZ1

!>          NZ1 es INTEGER
!>          Si abs(ITYPE) > 3, entonces las primeras NZ1 entradas diagonales serán
!>          cero.
!>

NZ2

!>          NZ2 es INTEGER
!>          Si abs(ITYPE) > 3, entonces las últimas NZ2 entradas diagonales serán
!>          cero.
!>

ISIGN

!>          ISIGN es INTEGER
!>          = 0: El signo de las entradas diagonales y subdiagonales se
!>               dejará sin cambios.
!>          = 1: El signo de las entradas diagonales y subdiagonales se
!>               cambiará al azar.
!>          = 2: Si ITYPE es 2 o 3, entonces es lo mismo que ISIGN=1.
!>               En caso contrario, con una probabilidad del 0.5, los pares de
!>               entradas diagonales odd-even A(2*j-1,2*j-1), A(2*j,2*j) se
!>               convertirán en un bloque de 2x2 pre- y post-multiplicando
!>               por rotaciones ortogonales aleatorias distintas. Las entradas
!>               diagonales restantes cambiarán su signo al azar.
!>

AMAGN

!>          AMAGN es DOUBLE PRECISION
!>          Las entradas diagonales y subdiagonales se multiplicarán por
!>          AMAGN.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          Si abs(ITYPE) > 4, entonces la entrada diagonal más pequeña será
!>          la entrada. RCOND debe estar entre 0 y 1.
!>

TRIANG

!>          TRIANG es DOUBLE PRECISION
!>          Las entradas por encima de la diagonal serán números aleatorios con
!>          magnitud acotada por TRIANG (es decir, números aleatorios multiplicados
!>          por TRIANG).
!>

IDIST

!>          IDIST es INTEGER
!>          Especifica el tipo de distribución que se usará para generar una
!>          matriz aleatoria.
!>          = 1: UNIFORME( 0, 1 )
!>          = 2: UNIFORME( -1, 1 )
!>          = 3: NORMAL ( 0, 1 )
!>

ISEED

!>          ISEED es array INTEGER, dimension (4)
!>          A la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los valores de ISEED se modifican a la salida y pueden
!>          utilizarse en la siguiente llamada a DLATM4 para continuar la misma
!>          secuencia de números aleatorios.
!>          Nota: ISEED(4) debe ser impar, para el generador de números aleatorios
!>          utilizado actualmente.
!>

A

!>          A es array DOUBLE PRECISION, dimension (LDA, N)
!>          Array a calcular.
!>

LDA

!>          LDA es INTEGER
!>          Dimensión principal de A. Debe ser al menos 1 y al menos N.
!>
