Documentación de la Función/Subrutina

subrutina dlasd0 (integer n, integer sqre, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, integer smlsiz, integer, dimension( * ) iwork, double precision, dimension( * ) work, integer info)

DLASD0 calcula los valores singulares de una matriz bidiagonal superior real n por m B con diagonal D y fuera de diagonal E. Utilizado por sbdsdc.

Propósito:

!>
!> Utilizando un enfoque de divide y vencerás, DLASD0 calcula la
!> descomposición en valores singulares (SVD) de una matriz bidiagonal
!> superior real N por M, B, con diagonal D y fuera de diagonal E, donde
!> M = N + SQRE. El algoritmo calcula matrices ortogonales U y VT tales que
!> B = U * S * VT. Los valores singulares S se sobrescriben en D.
!>
!> Una subrutina relacionada, DLASDA, calcula solo los valores singulares,
!> y opcionalmente, los vectores singulares en forma compacta.
!>

Parámetros

N 
!>          N es INTEGER
!>         En la entrada, la dimensión de fila de la matriz bidiagonal
!>         superior. Esta es también la dimensión del array de la diagonal
!>         principal D.
!>

SQRE

!>          SQRE es INTEGER
!>         Especifica la dimensión de columna de la matriz bidiagonal.
!>         = 0: La matriz bidiagonal tiene dimensión de columna M = N;
!>         = 1: La matriz bidiagonal tiene dimensión de columna M = N+1;
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>         En la entrada D contiene la diagonal principal de la matriz
!>         bidiagonal.
!>         En la salida D, si INFO = 0, contiene sus valores singulares.
!>

E

!>          E es un array de DOUBLE PRECISION, dimensión (M-1)
!>         Contiene las entradas subdiagonales de la matriz bidiagonal.
!>         En la salida, E ha sido destruido.
!>

U

!>          U es un array de DOUBLE PRECISION, dimensión (LDU, N)
!>         En la salida, U contiene los vectores singulares izquierdos,
!>          si U se pasa como Identidad (N, N).
!>

LDU

!>          LDU es INTEGER
!>         En la entrada, dimensión principal de U.
!>

VT

!>          VT es un array de DOUBLE PRECISION, dimensión (LDVT, M)
!>         En la salida, VT**T contiene los vectores singulares derechos,
!>          si VT se pasa como Identidad (M, M).
!>

LDVT

!>          LDVT es INTEGER
!>         En la entrada, dimensión principal de VT.
!>

SMLSIZ

!>          SMLSIZ es INTEGER
!>         En la entrada, tamaño máximo de los subproblemas en el
!>         fondo del árbol de computación.
!>

IWORK

!>          IWORK es un array de INTEGER, dimensión (8*N)
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (3*M**2+2*M)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un valor singular no convergió
!>
