DLACON estima la norma 1 de una matriz cuadrada, utilizando comunicación inversa para evaluar productos matriz-vector.

Documentación de la función/subrutina

subrutina dlacon (integer n, double precision, dimension( * ) v, double precision, dimension( * ) x, integer, dimension( * ) isgn, double precision est, integer kase)

DLACON estima la norma 1 de una matriz cuadrada, utilizando comunicación inversa para evaluar productos matriz-vector.

Propósito

!>
!> DLACON estima la norma 1 de una matriz real cuadrada A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es ENTERO
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es un array de DOBLE PRECISIÓN, dimensión (N)
!>         En el retorno final, V = A*W,  donde  EST = norm(V)/norm(W)
!>         (W no se devuelve).
!>

X

!>          X es un array de DOBLE PRECISIÓN, dimensión (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**T * X,  si KASE=2,
!>         y DLACON debe ser llamada de nuevo con todos los demás parámetros
!>         sin cambios.
!>

ISGN

!>          ISGN es un array de ENTEROS, dimensión (N)
!>

EST

!>          EST es DOBLE PRECISIÓN
!>         Al entrar con KASE = 1 o 2 y JUMP = 3, EST debe ser
!>         sin cambios desde la llamada anterior a DLACON.
!>         A la salida, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es ENTERO
!>         En la llamada inicial a DLACON, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**T * X.
!>         En el retorno final desde DLACON, KASE volverá a ser 0.
!>
