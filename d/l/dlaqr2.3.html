Documentación de Función/Subrutina

subrutina dlaqr2 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, double precision, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, double precision, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, double precision, dimension( * ) sr, double precision, dimension( * ) si, double precision, dimension( ldv, * ) v, integer ldv, integer nh, double precision, dimension( ldt, * ) t, integer ldt, integer nv, double precision, dimension( ldwv, * ) wv, integer ldwv, double precision, dimension( * ) work, integer lwork)

DLAQR2 realiza la transformación de similitud ortogonal de una matriz de Hessenberg para detectar y desinflar eigenvalores completamente convergidos de una submatriz principal final (deflación temprana agresiva).

Propósito:

!>
!>    DLAQR2 es idéntico a DLAQR3 excepto que evita
!>    la recursión llamando a DLAHQR en lugar de a DLAQR4.
!>
!>    Deflación temprana agresiva:
!>
!>    Esta subrutina acepta como entrada una matriz de Hessenberg superior
!>    H y realiza una transformación de similitud ortogonal
!>    diseñada para detectar y desinflar eigenvalores completamente
!>    convergidos de una submatriz principal final.  En la salida, H ha sido
!>    sobrescrito por una nueva matriz de Hessenberg que es una perturbación de
!>    una transformación de similitud ortogonal de H.  Se espera
!>    que la versión final de H tenga muchas entradas subdiagonales
!>    cero.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          Si es .TRUE., entonces la matriz de Hessenberg H se actualiza
!>          completamente para que el factor de Schur cuasitriangular pueda
!>          ser calculado (en cooperación con la subrutina que llama).
!>          Si es .FALSE., entonces solo se actualiza lo suficiente de H para
!>          preservar los eigenvalores.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          Si es .TRUE., entonces la matriz ortogonal Z se actualiza
!>          para que el factor de Schur ortogonal pueda ser calculado
!>          (en cooperación con la subrutina que llama).
!>          Si es .FALSE., entonces Z no es referenciada.
!>

N

!>          N es INTEGER
!>          El orden de la matriz H y (si WANTZ es .TRUE.) el
!>          orden de la matriz ortogonal Z.
!>

KTOP

!>          KTOP es INTEGER
!>          Se asume que o bien KTOP = 1 o H(KTOP,KTOP-1)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

KBOT

!>          KBOT es INTEGER
!>          Se asume sin comprobación que o bien
!>          KBOT = N o H(KBOT+1,KBOT)=0.  KBOT y KTOP juntos
!>          determinan un bloque aislado a lo largo de la diagonal de la
!>          matriz de Hessenberg.
!>

NW

!>          NW es INTEGER
!>          Tamaño de la ventana de deflación.  1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H es un array DOUBLE PRECISION, dimensión (LDH,N)
!>          En la entrada, la sección inicial N-por-N de H almacena la
!>          matriz de Hessenberg que está sufriendo deflación temprana agresiva.
!>          En la salida, H ha sido transformada por una transformación de
!>          similitud ortogonal, perturbada, y devuelta
!>          a forma de Hessenberg que (se espera) tiene algunas
!>          entradas subdiagonales cero.
!>

LDH

!>          LDH es INTEGER
!>          Dimensión principal de H tal como se declara en la subrutina
!>          que llama.  N <= LDH
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>          Especifica las filas de Z a las que se deben aplicar las
!>          transformaciones si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimensión (LDZ,N)
!>          SI WANTZ es .TRUE., entonces en la salida, la transformación de
!>          similitud ortogonal mencionada anteriormente ha sido
!>          acumulada en Z(ILOZ:IHIZ,ILOZ:IHIZ) desde la derecha.
!>          Si WANTZ es .FALSE., entonces Z no es referenciada.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de Z tal como se declara en la
!>          subrutina que llama.  1 <= LDZ.
!>

NS

!>          NS es INTEGER
!>          El número de eigenvalores no convergidos (es decir, aproximados)
!>          devueltos en SR y SI que pueden ser usados como desplazamientos por
!>          la subrutina que llama.
!>

ND

!>          ND es INTEGER
!>          El número de eigenvalores convergidos descubiertos por esta
!>          subrutina.
!>

SR

!>          SR es un array DOUBLE PRECISION, dimensión (KBOT)
!>

SI

!>          SI es un array DOUBLE PRECISION, dimensión (KBOT)
!>          En la salida, las partes real e imaginaria de los eigenvalores
!>          aproximados que pueden ser usados para desplazamientos son almacenadas
!>          en SR(KBOT-ND-NS+1) a través de SR(KBOT-ND) y
!>          SI(KBOT-ND-NS+1) a través de SI(KBOT-ND), respectivamente.
!>          Las partes real e imaginaria de los eigenvalores convergidos
!>          son almacenadas en SR(KBOT-ND+1) a través de SR(KBOT) y
!>          SI(KBOT-ND+1) a través de SI(KBOT), respectivamente.
!>

V

!>          V es un array DOUBLE PRECISION, dimensión (LDV,NW)
!>          Un array de trabajo NW-por-NW.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V tal como se declara en la
!>          subrutina que llama.  NW <= LDV
!>

NH

!>          NH es INTEGER
!>          El número de columnas de T.  NH >= NW.
!>

T

!>          T es un array DOUBLE PRECISION, dimensión (LDT,NW)
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de T tal como se declara en la
!>          subrutina que llama.  NW <= LDT
!>

NV

!>          NV es INTEGER
!>          El número de filas del array de trabajo WV disponibles para
!>          el espacio de trabajo.  NV >= NW.
!>

WV

!>          WV es un array DOUBLE PRECISION, dimensión (LDWV,NW)
!>

LDWV

!>          LDWV es INTEGER
!>          La dimensión principal de W tal como se declara en la
!>          subrutina que llama.  NW <= LDV
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>          En la salida, WORK(1) es establecido a una estimación del valor
!>          óptimo de LWORK para los valores dados de N, NW, KTOP y KBOT.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array de trabajo WORK.  LWORK = 2*NW
!>          es suficiente, pero una mayor eficiencia puede resultar de valores
!>          mayoreses de LWORK.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; DLAQR2
!>          solo estima el tamaño óptimo del espacio de trabajo para los valores
!>          dados de N, NW, KTOP y KBOT. La estimación se devuelve
!>          en WORK(1). XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>          Ni H ni Z son accedidos.
!>
