Documentación de Función/Subrutin

a

subrutina dlarhs (character*3 path, character xtype, character uplo, character trans, integer m, integer n, integer kl, integer ku, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldb, * ) b, integer ldb, integer, dimension( 4 ) iseed, integer

info)

DLARH

S

Propósito

: 
!>
!> DLARHS elige un conjunto de vectores de solución aleatorios de NRHS y establece
!> los miembros independientes para el sistema lineal
!>    op(A) * X = B,
!> donde op(A) = A o A**T, dependiendo de TRANS.
!
>

Parámetro

s
PATH 
!>          PATH es CHARACTER*3
!>          El tipo de la matriz real A.  PATH puede darse en cualquier
!>          combinación de mayúsculas y minúsculas.  Los tipos válidos incluyen
!>             xGE:  Matriz general m x n
!>             xGB:  Matriz general bandada
!>             xPO:  Simétrica definida positiva, almacenamiento 2-D
!>             xPP:  Simétrica definida positiva empaquetada
!>             xPB:  Simétrica definida positiva bandada
!>             xSY:  Simétrica indefinida, almacenamiento 2-D
!>             xSP:  Simétrica indefinida empaquetada
!>             xSB:  Simétrica indefinida bandada
!>             xTR:  Triangular
!>             xTP:  Triangular empaquetada
!>             xTB:  Triangular bandada
!>             xQR:  Matriz general m x n
!>             xLQ:  Matriz general m x n
!>             xQL:  Matriz general m x n
!>             xRQ:  Matriz general m x n
!>          donde el carácter inicial indica la precisión.
!
>

XTYP

E 
!>          XTYPE es CHARACTER*1
!>          Especifica cómo se determinará la solución exacta X:
!>          = 'N':  Nueva solución; generar una X aleatoria.
!>          = 'C':  Calculada; usar el valor de X en la entrada.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          Especifica si se almacena la parte triangular superior o inferior de la
!>          matriz A, si A es simétrica.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!
>

TRAN

S 
!>          TRANS es CHARACTER*1
!>          Usada solo si A es no simétrica; especifica la operación
!>          aplicada a la matriz A.
!>          = 'N':  B := A    * X  (Sin transponer)
!>          = 'T':  B := A**T * X  (Transponer)
!>          = 'C':  B := A**H * X  (Transpuesta conjugada = Transponer)
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!
>

K

L 
!>          KL es INTEGER
!>          Usada solo si A es una matriz bandada; especifica el número de
!>          subdiagonales de A si A es una matriz bandada general o si A es
!>          simétrica o triangular y UPLO = 'L'; especifica el número
!>          de superdiagonales de A si A es simétrica o triangular y
!>          UPLO = 'U'.  0 <= KL <= M-1.
!
>

K

U 
!>          KU es INTEGER
!>          Usada solo si A es una matriz bandada general o si A es
!>          triangular.
!>
!>          Si PATH = xGB, especifica el número de superdiagonales de A,
!>          y 0 <= KU <= N-1.
!>
!>          Si PATH = xTR, xTP, o xTB, especifica si la matriz
!>          tiene diagonal unidad o no:
!>          = 1:  la matriz tiene diagonal no unidad (por defecto)
!>          = 2:  la matriz tiene diagonal unidad
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de vectores de miembros independientes en el sistema A*X = B.
!
>

A 
!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA,N)
!>          La matriz de prueba cuyo tipo está dado por PATH.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.
!>          Si PATH = xGB, LDA >= KL+KU+1.
!>          Si PATH = xPB, xSB, xHB, o xTB, LDA >= KL+1.
!>          De lo contrario, LDA >= max(1,M).
!
>

X 
!>          X es un arreglo DOUBLE PRECISION (o de salida), dimensión(LDX,NRHS)
!>          En la entrada, si XTYPE = 'C' (para 'Calculada'), entonces X contiene
!>          la solución exacta al sistema de ecuaciones lineales.
!>          En la salida, si XTYPE = 'N' (para 'Nueva'), entonces X se inicializa
!>          con valores aleatorios.
!
>

LD

X 
!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  Si TRANS = 'N',
!>          LDX >= max(1,N); si TRANS = 'T', LDX >= max(1,M).
!
>

B 
!>          B es un arreglo DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          El vector (o vectores) de miembros independientes para el sistema de
!>          ecuaciones, calculado a partir de B = op(A) * X, donde op(A) está
!>          determinado por TRANS.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  Si TRANS = 'N',
!>          LDB >= max(1,M); si TRANS = 'T', LDB >= max(1,N).
!
>

ISEE

D 
!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado en
!>          DLATMS).  Modificado en la salida.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>
