subrutina dlqt02 (integer m, integer n, integer k, double precision, dimension( lda, * ) a, double precision, dimension( lda, * ) af, double precision, dimension( lda, * ) q, double precision, dimension( lda, * ) l, integer lda, double precision, dimension( * ) tau, double precision, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

DLQT02

Propósito:

!>
!> DLQT02 prueba DORGLQ, que genera una matriz m por n, Q, con
!> filas ortonormales que se define como el producto de k
!> reflectores elementales.
!>
!> Dada la factorización LQ de una matriz m por n, A, DLQT02 genera
!> la matriz ortogonal Q definida por la factorización de las primeras k
!> filas de A; compara L(1:k,1:m) con A(1:k,1:n)*Q(1:m,1:n)', y
!> comprueba que las filas de Q son ortonormales.
!>

Parámetros

M 
!>          M es un ENTERO
!>          El número de filas de la matriz Q a generar.  M >= 0.
!>

N

!>          N es un ENTERO
!>          El número de columnas de la matriz Q a generar.
!>          N >= M >= 0.
!>

K

!>          K es un ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es una matriz de DOBLE PRECISIÓN, dimensión (LDA,N)
!>          La matriz m por n, A, que fue factorizada por DLQT01.
!>

AF

!>          AF es una matriz de DOBLE PRECISIÓN, dimensión (LDA,N)
!>          Detalles de la factorización LQ de A, tal como es devuelta por DGELQF.
!>          Consultar DGELQF para más detalles.
!>

Q

!>          Q es una matriz de DOBLE PRECISIÓN, dimensión (LDA,N)
!>

L

!>          L es una matriz de DOBLE PRECISIÓN, dimensión (LDA,M)
!>

LDA

!>          LDA es un ENTERO
!>          La dimensión principal de las matrices A, AF, Q y L. LDA >= N.
!>

TAU

!>          TAU es una matriz de DOBLE PRECISIÓN, dimensión (M)
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización LQ en AF.
!>

WORK

!>          WORK es una matriz de DOBLE PRECISIÓN, dimensión (LWORK)
!>

LWORK

!>          LWORK es un ENTERO
!>          La dimensión de la matriz WORK.
!>

RWORK

!>          RWORK es una matriz de DOBLE PRECISIÓN, dimensión (M)
!>

RESULT

!>          RESULT es una matriz de DOBLE PRECISIÓN, dimensión (2)
!>          Las relaciones de prueba:
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
