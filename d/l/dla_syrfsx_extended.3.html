subroutine dla_syrfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, double precision, dimension( * ) res, double precision, dimension( * ) ayb, double precision, dimension( * ) dy, double precision, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

DLA_SYRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices simétricas indefinidas realizando un refinamiento iterativo de precisión extra y proporciona cotas de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!>
!> DLA_SYRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por DSYRFSX para realizar el refinamiento iterativo.
!> Además de la cota de error normwise, el código proporciona la cota de error
!> máxima por componentes, si es posible. Ver comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para detalles de las cotas de error. Tener en cuenta que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array de DOUBLE PRECISION, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener la factor U o L tal como se calcula por DSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array de INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como se determinan por DSYTRF.
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó la

equilibración de columnas en A antes de llamar a esta subrutina. Esto es necesario para calcular la solución y las cotas de error correctamente.

C

!>          C es un array de DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se introduce C, cada elemento de C debe ser una potencia
!>     del radix para asegurar una solución y estimaciones de error fiables.
!>     La escala por potencias del radix no causa errores de redondeo a menos
!>     que el resultado tenga subdesbordamiento o desbordamiento. Los errores de
!>     redondeo durante la escala conducen a refinar con una matriz que no es
!>     equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

B

!>          B es un array de DOUBLE PRECISION, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es un array de DOUBLE PRECISION, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como se calcula por DSYTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un array de DOUBLE PRECISION, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo hacia atrás por
!>     componentes para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto por componentes de la matriz
!>     o vector Z. Esto se calcula por DLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué cotas de error devolver (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve cotas de error normwise.
!>     Si N_NORMS >= 2 devuelve cotas de error por componentes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array de DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un arreglo de DOBLE PRECISIÓN, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este arreglo contiene información sobre
!>     varios límites de error y números de condición correspondientes
!>     al error relativo componente a componente, que se define como
!>     sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El arreglo está indexado por el lado derecho i (del cual depende
!>     el error relativo componente a componente), y el tipo de
!>     información de error descrito a continuación. Actualmente se
!>     devuelven hasta tres piezas de información para cada lado
!>     derecho. Si no se solicita precisión componente a componente
!>     (PARAMS(3) = 0.0), entonces no se accede a ERR_BNDS_COMP. Si
!>     N_ERR_BNDS < 3, entonces se devuelven como máximo las primeras
!>     entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los
!>     siguientes tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado componente a componente. Se compara
!>              con el umbral sqrt(n) * slamch('Epsilon') para
!>              determinar si la estimación de error es . Estos números
!>              de condición recíprocos son 1 / (norm(Z^{-1},inf) *
!>              norm(Z,inf)) para alguna matriz Z escalada
!>              apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de A*diag(x)
!>              por una potencia de la base de modo que todas las sumas
!>              absolutas de fila de Z sean aproximadamente 1.
!>
!>     Este subrutina es solo responsable de establecer el segundo
!>     campo anterior.
!>     Consulte Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

RES

!>          RES es un arreglo de DOBLE PRECISIÓN, dimensión (N)
!>     Espacio de trabajo para mantener el residuo intermedio.
!>

AYB

!>          AYB es un arreglo de DOBLE PRECISIÓN, dimensión (N)
!>     Espacio de trabajo. Este puede ser el mismo espacio de trabajo
!>     pasado para Y_TAIL.
!>

DY

!>          DY es un arreglo de DOBLE PRECISIÓN, dimensión (N)
!>     Espacio de trabajo para mantener la solución intermedia.
!>

Y_TAIL

!>          Y_TAIL es un arreglo de DOBLE PRECISIÓN, dimensión (N)
!>     Espacio de trabajo para mantener los bits finales de la solución
!>     intermedia.
!>

RCOND

!>          RCOND es DOBLE PRECISIÓN
!>     Número de condición recíproco escalado. Esta es una estimación
!>     del número de condición recíproco de Skeel de la matriz A
!>     después de la equilibración (si se hizo). Si esto es menor que
!>     la precisión de la máquina (en particular, si es cero), la
!>     matriz es singular hasta la precisión de trabajo. Tenga en
!>     cuenta que el error puede ser pequeño incluso si este número es
!>     muy pequeño y la matriz parece mal condicionada.
!>

ITHRESH

!>          ITHRESH es INTEGER
!>     El número máximo de cálculos de residuo permitidos para el
!>     refinamiento. El valor predeterminado es 10. Para 'aggressive'
!>     establezca en 100 para permitir la convergencia usando
!>     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>     la factorización usa una técnica distinta de la eliminación
!>     gaussiana, las garantías en ERR_BNDS_NORM y ERR_BNDS_COMP pueden
!>     ya no ser confiables.
!>

RTHRESH

!>          RTHRESH es DOBLE PRECISIÓN
!>     Determina cuándo detener el refinamiento si la estimación de
!>     error deja de disminuir. El refinamiento se detendrá cuando la
!>     siguiente solución ya no satisfaga norm(dx_{i+1}) < RTHRESH *
!>     norm(dx_i) donde norm(Z) es la norma infinita de Z. RTHRESH
!>     satisface 0 < RTHRESH <= 1. El valor predeterminado es 0.5. Para
!>     'aggressive' establezca en 0.9 para permitir la convergencia en
!>     matrices extremadamente mal condicionadas. Consulte LAWN 165 para
!>     más detalles.
!>

DZ_UB

!>          DZ_UB es DOBLE PRECISIÓN
!>     Determina cuándo comenzar a considerar la convergencia componente
!>     a componente. La convergencia componente a componente solo se
!>     considera después de que cada componente de la solución Y sea
!>     estable, lo cual definimos como el cambio relativo en cada
!>     componente siendo menor que DZ_UB. El valor predeterminado es
!>     0.25, requiriendo que el primer bit sea estable. Consulte LAWN
!>     165 para más detalles.
!>

IGNORE_CWISE

!>          IGNORE_CWISE es LOGICAL
!>     Si .TRUE. entonces ignorar la convergencia componente a
!>     componente. El valor predeterminado es .FALSE..
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  si INFO = -i, el i-ésimo argumento a DLA_SYRFSX_EXTENDED tenía un
!>             valor ilegal
!>
