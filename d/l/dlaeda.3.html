subrutina dlaeda (n, tlvls, curlvl, curpbm, prmptr, perm, givptr, givcol, givnum, q, qptr, z, ztemp, info)
DLAEDA utilizada por DSTEDC. Calcula el vector Z que determina la modificación de rango uno de la matriz diagonal. Se utiliza cuando la matriz original es densa.

Documentación de la función/subrutina

subrutina dlaeda (integer n, integer tlvls, integer curlvl, integer curpbm, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, double precision, dimension( 2, * ) givnum, double precision, dimension( * ) q, integer, dimension( * ) qptr, double precision, dimension( * ) z, double precision, dimension( * ) ztemp, integer info)

DLAEDA utilizada por DSTEDC. Calcula el vector Z que determina la modificación de rango uno de la matriz diagonal. Se utiliza cuando la matriz original es densa.

Propósito:

!>
!> DLAEDA calcula el vector Z correspondiente al paso de fusión en el
!> paso CURLVLth del proceso de fusión con TLVLS pasos para el problema CURPBMth.
!>

Parámetros

N 
!>          N es ENTERO
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

TLVLS

!>          TLVLS es ENTERO
!>         El número total de niveles de fusión en el árbol de divide y vencer
!>         general.
!>

CURLVL

!>          CURLVL es ENTERO
!>         El nivel actual en la rutina de fusión general,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM es ENTERO
!>         El problema actual en el nivel actual de la rutina de fusión
!>         general (contando de arriba a la izquierda a abajo a la derecha).
!>

PRMPTR

!>          PRMPTR es un array de ENTEROS, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM se almacena
!>         la permutación de un nivel.  PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación y, de forma incidental, el
!>         tamaño del problema completo, sin deflación.
!>

PERM

!>          PERM es un array de ENTEROS, dimension (N lg N)
!>         Contiene las permutaciones (de deflación y ordenación) que se
!>         aplicarán a cada bloque de eigenvalores.
!>

GIVPTR

!>          GIVPTR es un array de ENTEROS, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en GIVCOL se almacenan
!>         las rotaciones de Givens de un nivel.  GIVPTR(i+1) - GIVPTR(i)
!>         indica el número de rotaciones de Givens.
!>

GIVCOL

!>          GIVCOL es un array de ENTEROS, dimension (2, N lg N)
!>         Cada par de números indica un par de columnas que participarán
!>         en una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es un array de DOBLE PRECISIÓN, dimension (2, N lg N)
!>         Cada número indica el valor S a utilizar en la
!>         rotación de Givens correspondiente.
!>

Q

!>          Q es un array de DOBLE PRECISIÓN, dimension (N**2)
!>         Contiene los bloques de eigenvalores cuadrados de niveles anteriores,
!>         las posiciones de inicio de los bloques vienen dadas por QPTR.
!>

QPTR

!>          QPTR es un array de ENTEROS, dimension (N+2)
!>         Contiene una lista de punteros que indican dónde en Q se almacena
!>         un bloque de eigenvalores.  SQRT( QPTR(i+1) - QPTR(i) ) indica
!>         el tamaño del bloque.
!>

Z

!>          Z es un array de DOBLE PRECISIÓN, dimension (N)
!>         En la salida, este vector contiene el vector de actualización (la última
!>         fila de la primera matriz de sub-eigenvectores y la primera fila
!>         de la segunda matriz de sub-eigenvectores).
!>

ZTEMP

!>          ZTEMP es un array de DOBLE PRECISIÓN, dimension (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
