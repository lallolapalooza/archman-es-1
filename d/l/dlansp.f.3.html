double precision function dlansp (norm, uplo, n, ap, work)
DLANSP devuelve el valor de la norma 1, la norma de Frobenius, la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica suministrada en forma empaquetada.

Documentación de la Función/Subrutina

double precision function dlansp (character norm, character uplo, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) work)

DLANSP devuelve el valor de la norma 1, la norma de Frobenius, la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica suministrada en forma empaquetada.

Propósito:

!>
!> DLANSP  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma  infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz simétrica real A,  suministrada en forma empaquetada.
!>

Devuelve

DLANSP 
!>
!>    DLANSP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma
!> de los cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial
!> consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en DLANSP según se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se suministra la parte triangular superior o inferior
!>          de la matriz simétrica A.
!>          = 'U':  Se suministra la parte triangular superior de A
!>          = 'L':  Se suministra la parte triangular inferior de A
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, DLANSP
!>          se establece a cero.
!>

AP

!>          AP es un array de DOUBLE PRECISION, dimensión (N*(N+1)/2)
!>          La parte triangular superior o inferior de la matriz simétrica A,
!>          empaquetada por columnas en un array lineal.  La j-ésima columna
!>          de A se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' or '1' or 'O'; de lo contrario,
!>          WORK no se referencia.
!>
