función de doble precisión dla_porcond (carácter uplo, entero n, doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( ldaf, * ) af, entero ldaf, entero cmode, doble precisión, dimensión( * ) c, entero info, doble precisión, dimensión( * ) work, entero, dimensión( * ) iwork)

DLA_PORCOND estima el número de condición de Skeel para una matriz simétrica definida positiva.

Propósito:

!>
!>    DLA_PORCOND Estima el número de condición de Skeel de op(A) * op2(C)
!>    donde op2 está determinado por CMODE de la siguiente manera:
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel cond(A) = norminf( |inv(A)||A| )
!>    se calcula calculando factores de escala R tales que
!>    diag(R)*A*op2(C) está equilibrado por filas y calculando el número
!>    de condición estándar de la norma infinito.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A. N >= 0.
!>

A

!>          A es una matriz de DOBLE PRECISIÓN, dimensión (LDA,N)
!>     En la entrada, la matriz N por N A.
!>

LDA

!>          LDA es ENTERO
!>     La dimensión principal de la matriz A. LDA >= max(1,N).
!>

AF

!>          AF es una matriz de DOBLE PRECISIÓN, dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como fue calculada por DPOTRF.
!>

LDAF

!>          LDAF es ENTERO
!>     La dimensión principal de la matriz AF. LDAF >= max(1,N).
!>

CMODE

!>          CMODE es ENTERO
!>     Determina op2(C) en la fórmula op(A) * op2(C) de la siguiente manera:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es una matriz de DOBLE PRECISIÓN, dimensión (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es ENTERO
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento no es válido.
!>

WORK

!>          WORK es una matriz de DOBLE PRECISIÓN, dimensión (3*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es una matriz de ENTEROS, dimensión (N).
!>     Espacio de trabajo.
!>
