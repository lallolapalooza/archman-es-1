Documentación de Función/Subrutina

subrutina dlarrk (integer n, integer iw, double precision gl, double precision gu, double precision, dimension( * ) d, double precision, dimension( * ) e2, double precision pivmin, double precision reltol, double precision w, double precision werr, integer info)

DLARRK calcula un valor propio de una matriz tridiagonal simétrica con la precisión adecuada.

Propósito:

!>
!> DLARRK calcula un valor propio de una matriz tridiagonal
!> simétrica T con la precisión adecuada. Este es un código auxiliar
!> para ser llamado desde DSTEMR.
!>
!> Para evitar desbordamientos, la matriz debe ser escalada de
!> modo que su elemento más grande no exceda overflow**(1/2) *
!> underflow**(1/4) en valor absoluto, y para mayor precisión,
!> no debe ser mucho menor que eso.
!>
!> Véase W. Kahan, Report CS41, Computer Science Dept., Stanford
!> University, 21 de julio de 1966.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz tridiagonal T. N >= 0.
!>

IW

!>          IW es INTEGER
!>          El índice del valor propio a devolver.
!>

GL

!>          GL es DOUBLE PRECISION
!>

GU

!>          GU es DOUBLE PRECISION
!>          Un límite superior y un límite inferior en el valor propio.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E2

!>          E2 es un array de DOUBLE PRECISION, dimensión (N-1)
!>          Los (n-1) elementos fuera de la diagonal al cuadrado de la
!>          matriz tridiagonal T.
!>

PIVMIN

!>          PIVMIN es DOUBLE PRECISION
!>          El pivote mínimo permitido en la secuencia de Sturm para T.
!>

RELTOL

!>          RELTOL es DOUBLE PRECISION
!>          El ancho relativo mínimo de un intervalo. Cuando un intervalo
!>          es más estrecho que RELTOL multiplicado por el extremo más
!>          grande (en magnitud), se considera suficientemente pequeño,
!>          es decir, convergido. Nota: esto siempre debe ser al menos
!>          radix*machine epsilon.
!>

W

!>          W es DOUBLE PRECISION
!>

WERR

!>          WERR es DOUBLE PRECISION
!>          El límite de error en la aproximación del valor propio
!>          correspondiente en W.
!>

INFO

!>          INFO es INTEGER
!>          = 0:       El valor propio ha convergido
!>          = -1:      El valor propio NO ha convergido
!>

Parámetros Internos:

!>  FUDGE   DOUBLE PRECISION, por defecto = 2
!>          Un valor para ampliar los intervalos de Gershgorin.
!>
