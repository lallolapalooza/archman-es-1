Documentación de Función/Subrutina

subrutina dlaqp3rk (integer m, integer n, integer nrhs, integer ioffset, integer nb, double precision abstol, double precision reltol, integer kp1, double precision maxc2nrm, double precision, dimension( lda, * ) a, integer lda, logical done, integer kb, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, double precision, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, double precision, dimension( * ) auxv, double precision, dimension( ldf, * ) f, integer ldf, integer, dimension( * ) iwork, integer info)

DLAQP3RK calcula un paso de la factorización QR truncada con pivoteo de columnas de una matriz real m-por-n A usando BLAS de Nivel 3 y sobrescribe una matriz real m-por-nrhs B con Q**T * B.

Propósito:

!>
!> DLAQP3RK calcula un paso de la factorización QR truncada con pivoteo de
!> columnas del bloque A(IOFFSET+1:M,1:N) de una matriz real M-por-N A
!> usando BLAS de Nivel 3 como
!>
!>   A * P(KB) = Q(KB) * R(KB).
!>
!> La rutina intenta factorizar NB columnas de A comenzando desde la fila
!> IOFFSET+1 y actualiza la matriz residual con BLAS 3 xGEMM. El número de
!> columnas realmente factorizadas devuelto es menor que NB.
!>
!> El bloque A(1:IOFFSET,1:N) se pivota en consecuencia, pero no se factoriza.
!>
!> La rutina también sobrescribe la matriz de miembros derechos B almacenada
!> en A(IOFFSET+1:M,1:N+1:N+NRHS) con Q(KB)**T * B.
!>
!> Casos en los que el número de columnas factorizadas KB < NB:
!>
!> (1) En algunos casos, debido a cancelaciones catastróficas, no puede
!> factorizar todas las NB columnas y necesita actualizar la matriz residual.
!> Por lo tanto, el número real de columnas factorizadas en el bloque
!> devuelto en KB es menor que NB. El lógico DONE se devuelve como FALSE.
!> La factorización de toda la matriz original A_orig debe continuar con el
!> siguiente bloque.
!>
!> (2) Siempre que se satisfaga el criterio de parada ABSTOL o RELTOL, se
!> detiene la factorización de toda la matriz original A_orig, el lógico
!> DONE se devuelve como TRUE. El número de columnas factorizadas que es
!> menor que NB se devuelve en KB.
!>
!> (3) En caso de que no se usen ambos criterios de parada ABSTOL o RELTOL,
!> y cuando la matriz residual sea una matriz cero en algún paso de
!> factorización KB, se detiene la factorización de toda la matriz original
!> A_orig, el lógico DONE se devuelve como TRUE. El número de columnas
!> factorizadas que es menor que NB se devuelve en KB.
!>
!> (4) Siempre que se detecte NaN en la matriz A o en el arreglo TAU, se
!> detiene la factorización de toda la matriz original A_orig, el lógico
!> DONE se devuelve como TRUE. El número de columnas factorizadas que es
!> menor que NB se devuelve en KB. El parámetro INFO se establece al índice
!> de la columna de la primera aparición de NaN.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

IOFFSET

!>          IOFFSET es INTEGER
!>          El número de filas de la matriz A que deben pivotearse
!>          pero no factorizarse. IOFFSET >= 0.
!>
!>          IOFFSET también representa el número de columnas de toda la
!>          matriz original A_orig que han sido factorizadas en los pasos
!>          anteriores.
!>

NB

!>          NB es INTEGER
!>          Tamaño del bloque de factorización, es decir, el número de
!>          columnas a factorizar en la matriz A. 0 <= NB
!>
!>          Si NB = 0, la rutina sale inmediatamente.
!>             Esto significa que no se realiza la factorización,
!>             las matrices A y B y los arreglos TAU, IPIV
!>             no se modifican.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION, no puede ser NaN.
!>
!>          La tolerancia absoluta (umbral de parada) para la
!>          norma 2 máxima de columna de la matriz residual.
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 máxima de columna de la matriz residual
!>          es menor o igual que ABSTOL.
!>
!>          a) Si ABSTOL < 0.0, entonces este criterio de parada no se
!>                usa, la rutina factoriza columnas dependiendo
!>                de NB y RELTOL.
!>                Esto incluye el caso ABSTOL = -Inf.
!>
!>          b) Si 0.0 <= ABSTOL entonces se usa el valor de entrada
!>                de ABSTOL.
!>

RELTOL

!>          RELTOL es DOUBLE PRECISION, no puede ser NaN.
!>
!>          La tolerancia (umbral de parada) para la razón de la
!>          norma 2 máxima de columna de la matriz residual a la norma 2
!>          máxima de columna de la matriz original A_orig. El algoritmo
!>          converge (detiene la factorización), cuando esta razón es
!>          menor o igual que RELTOL.
!>
!>          a) Si RELTOL < 0.0, entonces este criterio de parada no se
!>                usa, la rutina factoriza columnas dependiendo
!>                de NB y ABSTOL.
!>                Esto incluye el caso RELTOL = -Inf.
!>
!>          d) Si 0.0 <= RELTOL entonces se usa el valor de entrada de
!>                RELTOL.
!>

KP1

!>          KP1 es INTEGER
!>          El índice de la columna con la norma 2 máxima en
!>          toda la matriz original A_orig determinado en la
!>          rutina principal DGEQP3RK. 1 <= KP1 <= N_orig.
!>

MAXC2NRM

!>          MAXC2NRM es DOUBLE PRECISION
!>          La norma 2 máxima de columna de toda la matriz
!>          original A_orig calculada en la rutina principal DGEQP3RK.
!>          MAXC2NRM >= 0.
!>

A

!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA,N+NRHS)
!>          En la entrada:
!>              la matriz A de M-por-N y la matriz B de M-por-NRHS, como en
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          En la salida:
!>          1. Los elementos en el bloque A(IOFFSET+1:M,1:KB) por
!>             debajo de la diagonal junto con el arreglo TAU representan
!>             la matriz ortogonal Q(KB) como un producto de reflectores
!>             elementales.
!>          2. El bloque triangular superior de la matriz A almacenado
!>             en A(IOFFSET+1:M,1:KB) es el factor triangular obtenido.
!>          3. El bloque de la matriz A almacenado en A(1:IOFFSET,1:N)
!>             ha sido pivoteado en consecuencia, pero no factorizado.
!>          4. El resto del arreglo A, bloque A(IOFFSET+1:M,KB+1:N+NRHS).
!>             La parte izquierda A(IOFFSET+1:M,KB+1:N) de este bloque
!>             contiene el residual de la matriz A, y,
!>             si NRHS > 0, la parte derecha dellock
!>             A(IOFFSET+1:M,N+1:N+NRHS) contiene el bloque de
!>             la matriz del segundo miembro B. Ambos bloques han sido
!>             actualizados por multiplicación por la izquierda por Q(KB)**T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

DONE

!>          DONE es LOGICAL
!>          TRUE: a) si la factorización se completó antes de procesar
!>                   todas las columnas min(M-IOFFSET,NB,N) debido al criterio
!>                   ABSTOL o RELTOL,
!>                b) si la factorización se completó antes de procesar
!>                   todas las columnas min(M-IOFFSET,NB,N) debido a que
!>                   la matriz residual es una matriz ZERO.
!>                c) cuando se detectó NaN en la matriz A
!>                   o en el array TAU.
!>          FALSE: en caso contrario.
!>

KB

!>          KB es INTEGER
!>          Rango de factorización de la matriz A, es decir, el rango de
!>          el factor R, que es el mismo que el número de filas no nulas
!>          del factor R.  0 <= KB <= min(M-IOFFSET,NB,N).
!>
!>          KB también representa el número de vectores de Householder
!>          no nulos.
!>

MAXC2NRMK

!>          MAXC2NRMK es DOUBLE PRECISION
!>          La norma 2 de columna máxima de la matriz residual,
!>          cuando la factorización se detuvo en el rango KB. MAXC2NRMK >= 0.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK es DOUBLE PRECISION
!>          La razón MAXC2NRMK / MAXC2NRM de la norma 2 de columna
!>          máxima de la matriz residual (cuando la factorización
!>          se detuvo en el rango KB) a la norma 2 de columna máxima de la
!>          matriz original A_orig. RELMAXC2NRMK >= 0.
!>

JPIV

!>          JPIV es un array INTEGER, dimensión (N)
!>          Índices de columnas pivote, para 1 <= j <= N, la columna j
!>          de la matriz A fue intercambiada con la columna JPIV(j).
!>

TAU

!>          TAU es un array DOUBLE PRECISION, dimensión (min(M-IOFFSET,N))
!>          Los factores escalares de los reflectores elementales.
!>

VN1

!>          VN1 es un array DOUBLE PRECISION, dimensión (N)
!>          El vector con las normas parciales de columna.
!>

VN2

!>          VN2 es un array DOUBLE PRECISION, dimensión (N)
!>          El vector con las normas exactas de columna.
!>

AUXV

!>          AUXV es un array DOUBLE PRECISION, dimensión (NB)
!>          Vector auxiliar.
!>

F

!>          F es un array DOUBLE PRECISION, dimensión (LDF,NB)
!>          Matriz F**T = L*(Y**T)*A.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del array F. LDF >= max(1,N+NRHS).
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N-1).
!>          Es un array de trabajo. ( IWORK se usa para almacenar índices
!>          de columnas para la actualización descendente de normas en la matriz
!>          residual ).
!>

INFO

!>          INFO es INTEGER
!>          1) INFO = 0: salida exitosa.
!>          2) Si INFO = j_1, donde 1 <= j_1 <= N, entonces se detectó NaN
!>             y la rutina detiene el cálculo.
!>             La j_1-ésima columna de la matriz A o el j_1-ésimo
!>             elemento del array TAU contiene la primera aparición
!>             de NaN en el paso de factorización KB+1 (cuando se han
!>             factorizado KB columnas).
!>
!>             En la salida:
!>             KB                  se establece al número de
!>                                    columnas factorizadas sin
!>                                    excepción.
!>             MAXC2NRMK           se establece a NaN.
!>             RELMAXC2NRMK        se establece a NaN.
!>             TAU(KB+1:min(M,N))     no se establece y contiene elementos
!>                                    indefinidos. Si j_1=KB+1, TAU(KB+1)
!>                                    puede contener NaN.
!>          3) Si INFO = j_2, donde N+1 <= j_2 <= 2*N, entonces no se
!>             detectó NaN, pero se detectó +Inf (o -Inf) y
!>             la rutina continúa el cálculo hasta la finalización.
!>             La (j_2-N)-ésima columna de la matriz A contiene la primera
!>             aparición de +Inf (o -Inf) en el paso de factorización
!>             KB+1 (cuando se han factorizado KB columnas).
!>
