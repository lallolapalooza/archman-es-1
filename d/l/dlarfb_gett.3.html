Documentación de Función/Subrutin

a

subrutina dlarfb_gett (character ident, integer m, integer n, integer k, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldwork, * ) work, integer

ldwork)

DLARFB_GET

T

Propósito

: 
!>
!> DLARFB_GETT aplica un reflector de bloque Householder real H desde la
!> izquierda a una matriz real (K+M)-por-N
!> compuesta por dos matrices de bloque: una matriz trapezoidal superior K-por-N A
!> almacenada en el array A, y una matriz rectangular M-por-(N-K) B, almacenada
!> en el array B. El reflector de bloque H está almacenado en una
!> representación WY compacta, donde los reflectores elementales están en los
!> arrays A, B y T. Vea la sección de Detalles Adicionales.
!
>

Parámetro

s
IDENT 
!>          IDENT es CHARACTER*1
!>          Si IDENT = no 'I', o no 'i', entonces V1 es triangular inferior unitaria
!>             y almacenada en el bloque izquierdo K-por-K de
!>             la matriz de entrada A,
!>          Si IDENT = 'I' o 'i', entonces V1 es una matriz identidad y
!>             no se almacena.
!>          Vea la sección de Detalles Adicionales.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de las matrices A y B.
!>          N >= 0.
!
>

K 
!>          K es INTEGER
!>          El número de filas de la matriz A.
!>          K es también el orden de la matriz T, es decir, el número de
!>          reflectores elementales cuyo producto define el bloque
!>          reflector. 0 <= K <= N.
!
>

T 
!>          T es un array DOUBLE PRECISION, dimensión (LDT,K)
!>          La matriz triangular superior K-por-K T en la representación
!>          del reflector de bloque.
!
>

LD

T 
!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>
!>          En la entrada:
!>           a) En la parte trapezoidal superior K-por-N A: la matriz de entrada A.
!>           b) En las columnas por debajo de la diagonal: columnas de V1
!>              (los unos no se almacenan en la diagonal).
!>
!>          En la salida:
!>            A es sobrescrita por el producto rectangular K-por-N H*A.
!>
!>          Vea la sección de Detalles Adicionales.
!
>

LD

A 
!>          LDB es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,N)
!>
!>          En la entrada:
!>            a) En el bloque derecho M-por-(N-K): la matriz de entrada B.
!>            b) En el bloque izquierdo M-por-N: columnas de V2.
!>
!>          En la salida:
!>            B es sobrescrita por el producto rectangular M-por-N H*B.
!>
!>          Vea la sección de Detalles Adicionales.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION,
!>          dimensión (LDWORK,max(K,N-K))
!
>

LDWOR

K 
!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK. LDWORK>=max(1,K).
!>
!
>

Detalles

Adicionales: 
!>
!>    (1) Descripción de la Operación Algebraica.
!>
!>    La matriz A es una matriz K-por-N compuesta por dos matrices de bloque de
!>    columnas, A1, que es K-por-K, y A2, que es K-por-(N-K):
!>    A = ( A1, A2 ).
!>    La matriz B es una matriz M-por-N compuesta por dos matrices de bloque de
!>    columnas, B1, que es M-por-K, y B2, que es M-por-(N-K):
!>    B = ( B1, B2 ).
!>
!>    Realice la operación:
!>
!>       ( A_out ) := H * ( A_in ) = ( I - V * T * V**T ) * ( A_in ) =
!>       ( B_out )        ( B_in )                          ( B_in )
!>                  = ( I - ( V1 ) * T * ( V1**T, V2**T ) ) * ( A_in )
!>                          ( V2 )                            ( B_in )
!>     En la entrada:
!>
!>    a) ( A_in )  consiste en dos columnas de bloque:
!>       ( B_in )
!>
!>       ( A_in ) = (( A1_in ) ( A2_in )) = (( A1_in ) ( A2_in ))
!>       ( B_in )   (( B1_in ) ( B2_in ))   ((     0 ) ( B2_in )),
!>
!>       donde los bloques de columna son:
!>
!>       (  A1_in )  es una matriz triangular superior K-por-K almacenada en la
!>                   parte triangular superior del array A(1:K,1:K).
!>       (  B1_in )  es una matriz rectangular M-por-K de CEROS y no se almacena.
!>
!>       ( A2_in )  es una matriz rectangular K-por-(N-K) almacenada
!>                  en el array A(1:K,K+1:N).
!>       ( B2_in )  es una matriz rectangular M-por-(N-K) almacenada
!>                  en el array B(1:M,K+1:N).
!>
!>    b) V = ( V1 )
!>           ( V2 )
!>
!>       donde:
!>       1) si IDENT == 'I', V1 es una matriz identidad K-por-K, no almacenada;
!>       2) si IDENT != 'I', V1 es una matriz triangular inferior unitaria K-por-K,
!>          almacenada en la parte triangular inferior del array
!>          A(1:K,1:K) (los unos no se almacenan),
!>       y V2 es una matriz rectangular M-por-K almacenada en el array B(1:M,1:K),
!>                 (porque en la entrada B1_in es una matriz rectangular de ceros
!>                  que no se almacena y el espacio se
!>                  usa para almacenar V2).
!>
!>    c) T es una matriz triangular superior K-por-K almacenada
!>       en el array T(1:K,1:K).
!>
!>    En la salida:
!>
!>    a) ( A_out ) consiste en dos columnas de bloque:
!>       ( B_out )
!>
!>       ( A_out ) = (( A1_out ) ( A2_out ))
!>       ( B_out )   (( B1_out ) ( B2_out )),
!>
!>       donde los bloques de columna son:
!>
!>       ( A1_out )  es una matriz cuadrada K-por-K, o una matriz triangular
!>                   superior K-por-K, si V1 es una
!>                   matriz identidad. AiOut se almacena en
!>                   el array A(1:K,1:K).
!>       ( B1_out )  es una matriz rectangular M-por-K almacenada
!>                   en el array B(1:M,K:N).
!>
!>       ( A2_out )  es una matriz rectangular K-por-(N-K) almacenada
!>                   en el array A(1:K,K+1:N).
!>       ( B2_out )  es una matriz rectangular M-por-(N-K) almacenada
!>                   en el array B(1:M,K+1:N).
!>
!>
!>    La operación anterior puede representarse como la misma operación
!>    en cada columna de bloque:
!>
!>       ( A1_out ) := H * ( A1_in ) = ( I - V * T * V**T ) * ( A1_in )
!>       ( B1_out )        (     0 )                          (     0 )
!>
!>       ( A2_out ) := H * ( A2_in ) = ( I - V * T * V**T ) * ( A2_in )
!>       ( B2_out )        ( B2_in )                          ( B2_in )
!>
!>    Si IDENT != 'I':
!>
!>       El cálculo para la columna de bloque 1:
!>
!>       A1_out: = A1_in - V1*T*(V1**T)*A1_in
!>
!>       B1_out: = - V2*T*(V1**T)*A1_in
!>
!>       El cálculo para la columna de bloque 2, que existe si N > K:
!>
!>       A2_out: = A2_in - V1*T*( (V1**T)*A2_in + (V2**T)*B2_in )
!>
!>       B2_out: = B2_in - V2*T*( (V1**T)*A2_in + (V2**T)*B2_in )
!>
!>    Si IDENT == 'I':
!>
!>       La operación para la columna de bloque 1:
!>
!>       A1_out: = A1_in - V1*T**A1_in
!>
!>       B1_out: = - V2*T**A1_in>
!>       El cálculo para el bloque de columnas 2, que existe si N > K:
!>
!>       A2_out: = A2_in - T*( A2_in + (V2**T)*B2_in )
!>
!>       B2_out: = B2_in - V2*T*( A2_in + (V2**T)*B2_in )
!>
!>    (2) Descripción del cálculo algorítmico.
!>
!>    En el primer paso, calculamos el bloque de columnas 2, es decir, A2 y B2.
!>    Aquí, necesitamos usar la matriz de espacio de trabajo rectangular W2 de K por (N-K)
!>    que tiene el mismo tamaño que la matriz A2.
!>    W2 se almacena en la matriz WORK(1:K,1:(N-K)).
!>
!>    En el segundo paso, calculamos el bloque de columnas 1, es decir, A1 y B1.
!>    Aquí, necesitamos usar la matriz de espacio de trabajo cuadrada W1 de K por K
!>    que tiene el mismo tamaño que la matriz A1.
!>    W1 se almacena en la matriz WORK(1:K,1:K).
!>
!>    NOTA: Por lo tanto, en esta rutina, necesitamos la matriz de espacio de trabajo WORK
!>    solo del tamaño WORK(1:K,1:max(K,N-K)) para que pueda contener tanto W2 del
!>    primer paso como W1 del segundo paso.
!>
!>    Caso (A), cuando V1 es triangular inferior unitaria, es decir, IDENT != 'I',
!>    más cálculos que en el Caso (B).
!>
!>    if( IDENT != 'I' ) then
!>     if ( N > K ) then
!>       (Primer paso - bloque de columnas 2)
!>       col2_(1) W2: = A2
!>       col2_(2) W2: = (V1**T) * W2 = (unit_lower_tr_of_(A1)**T) * W2
!>       col2_(3) W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(6) W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Segundo paso - bloque de columnas 1)
!>       col1_(1) W1: = A1
!>       col1_(2) W1: = (V1**T) * W1 = (unit_lower_tr_of_(A1)**T) * W1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>       col1_(6) square A1: = A1 - W1
!>     end if
!>    end if
!>
!>    Caso (B), cuando V1 es una matriz identidad, es decir, IDENT == 'I',
!>    menos cálculos que en el Caso (A)
!>
!>    if( IDENT == 'I' ) then
!>     if ( N > K ) then
!>       (Primer paso - bloque de columnas 2)
!>       col2_(1) W2: = A2
!>       col2_(3) W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Segundo paso - bloque de columnas 1)
!>       col1_(1) W1: = A1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(6) upper-triangular_of_(A1): = A1 - W1
!>     end if
!>    end if
!>
!>    Combinando estos casos (A) y (B), este es el algoritmo resultante:
!>
!>    if ( N > K ) then
!>
!>      (Primer paso - bloque de columnas 2)
!>
!>      col2_(1)  W2: = A2
!>      if( IDENT != 'I' ) then
!>        col2_(2)  W2: = (V1**T) * W2
!>                      = (unit_lower_tr_of_(A1)**T) * W2
!>      end if
!>      col2_(3)  W2: = W2 + (V2**T) * B2 = W2 + (B1**T) * B2]
!>      col2_(4)  W2: = T * W2
!>      col2_(5)  B2: = B2 - V2 * W2 = B2 - B1 * W2
!>      if( IDENT != 'I' ) then
!>        col2_(6)    W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>      end if
!>      col2_(7) A2: = A2 - W2
!>
!>    else
!>
!>    (Segundo paso - bloque de columnas 1)
!>
!>      col1_(1) W1: = A1
!>      if( IDENT != 'I' ) then
!>        col1_(2) W1: = (V1**T) * W1
!>                    = (unit_lower_tr_of_(A1)**T) * W1
!>      end if
!>      col1_(3) W1: = T * W1
!>      col1_(4) B1: = - V2 * W1 = - B1 * W1
!>      if( IDENT != 'I' ) then
!>        col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>        col1_(6_a) below_diag_of_(A1): =  - below_diag_of_(W1)
!>      end if
!>      col1_(6_b) up_tr_of_(A1): = up_tr_of_(A1) - up_tr_of_(W1)
!>
!>    end if
!>
!
>
