DLATM

T

Propósito

: 
!>
!>    DLATMT genera matrices aleatorias con valores singulares especificados
!>    (o simétricas/hermítianas con valores propios especificados)
!>    para probar programas de LAPACK.
!>
!>    DLATMT opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establece la diagonal en D, donde D puede ser de entrada o
!>         calculado de acuerdo con MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Genera una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Genera una matriz densa M x N multiplicando D a la izquierda
!>              y a la derecha por matrices unitarias aleatorias, luego:
!>
!>          Reduce el ancho de banda de acuerdo con KL y KU, usando
!>          transformaciones de Householder.
!>
!>      Método B:
!>          Convierte la matriz de ancho de banda 0 (es decir, diagonal) en una
!>              matriz de ancho de banda 1 usando rotaciones de Givens,
!>              los elementos fuera de banda de vuelta, mucho como en QR; luego
!>              convierte el ancho de banda 1 en un ancho de banda 2, etc.
!>              Tenga en cuenta que para anchos de banda razonablemente pequeños (relativos a
!>              M y N) esto requiere menos almacenamiento, ya que no se genera
!>              una matriz densa.  Además, para matrices simétricas, solo
!>              se genera un triángulo.
!>
!>      Se elige el Método A si el ancho de banda es una fracción grande de la
!>          orden de la matriz, y LDA es al menos M (de modo que se pueda almacenar
!>          una matriz densa.)  Se elige el Método B si el ancho de banda
!>          es pequeño (< 1/2 N para simétricas, < .3 N+M para
!>          no simétricas), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetado
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior por columnas (si es simétrica o
!>               triangular superior)
!>         almacenar la mitad inferior por columnas (si es simétrica o
!>               triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es simétrica
!>               o triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es simétrica
!>               o triangular superior)
!>         almacenar toda la matriz en formato de banda
!>      Si se elige el Método B y se especifica el formato de banda, entonces la
!>         matriz se generará en el formato de banda, por lo que no será necesario
!>         re-empaquetar.
!
>

T 
!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORM( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' para simétrico )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           No se modifica.
!
>

ISEE

D 
!>          ISEED es un arreglo INTEGER, dimensión ( 4 )
!>           En la entrada, ISEED especifica la semilla del generador de
!>           números aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           usa una secuencia congruencial lineal limitada a pequeños
!>           enteros, y por lo tanto debería producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED cambian en
!>           la salida, y pueden usarse en la siguiente llamada a DLATMT
!>           para continuar la misma secuencia de números aleatorios.
!>           Se cambia en la salida.
!
>

SY

M 
!>          SYM es CHARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es simétrica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada no es simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           No se modifica.
!
>

D 
!>          D es un arreglo DOUBLE PRECISION, dimensión ( MIN( M , N ) )
!>           Este arreglo se usa para especificar los valores singulares o
!>           propios de A (ver SYM, arriba.)  Si MODE=0, entonces se asume
!>           que D contiene los valores singulares/propios, de lo contrario
!>           se calcularán de acuerdo con MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Se modifica si MODE es distinto de cero.
!
>

MOD

E 
!>          MODE es INTEGER
!>           En la entrada, esto describe cómo se deben especificar los
!>           valores singulares/propios:
!>           MODE = 0 significa usar D como entrada
!>
!>           MODE = 1 establece D(1)=1 y D(2:RANK)=1.0/COND
!>           MODE = 2 establece D(1:RANK-1)=1 y D(RANK)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(RANK-1))
!>
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D en números aleatorios en el rango
!>                    ( 1/COND , 1 ) de modo que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D en números aleatorios de la misma
!>                    distribución que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D está invertido.
!>           Así que si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1.
!>           Si SYM='S' o 'H', y MODE no es ni 0, ni 6, ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo
!>              aleatorio (es decir, +1 o -1.)
!>           No se modifica.
!
>

CON

D 
!>          COND es DOUBLE PRECISION
!>           En la entrada, se usa como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No se modifica.
!
>

DMA

X 
!>          DMAX es DOUBLE PRECISION
!>           Si MODE no es ni -6, ni 0, ni 6, el contenido de D, tal como
!>           se calcula de acuerdo con MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))); así, el valor propio o singular
!>           absoluto máximo (es decir, la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no necesita ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No se modifica.
!
>

K

DLATMT - Diagonal matrix with Long 1, 2, and 3





SYNOPSIS


SUBROUTINE DLATMT(
   M,
   N,
   DIST,
   SYM,
   MODE,
   COND,
   KL,
   KU,
   PACK,
   A,
   LDA,
   WORK,
   INFO
)



Parameters:




M (INTEGER)


Number of rows of the matrix A.


N (INTEGER)


Number of columns of the matrix A.


DIST (CHARACTER*1)


Specifies the distribution of the matrix A.


SYM (CHARACTER*1)


Specifies properties of the matrix A.


MODE (INTEGER)


Specifies the mode for generating the matrix.


COND (DOUBLE PRECISION)


Specifies the condition number of the matrix.


KL (INTEGER)


Lower bandwidth of the matrix.


KU (INTEGER)


Upper bandwidth of the matrix.


PACK (CHARACTER*1)


Specifies packing of the matrix.


A (DOUBLE PRECISION array, dimension ( LDA, N ))


The matrix to be generated.


LDA (INTEGER)


Leading dimension of the array A.


WORK (DOUBLE PRECISION array, dimension ( 3*MAX( N , M ) ))


Workspace array.


INFO (INTEGER)


Error code.

!>          M is INTEGER
!>          The number of rows of the matrix A.

!>          DIST is CHARACTER*1
!>          Specifies the distribution of the matrix A as follows:
!>          'U' => uniform distribution
!>          'R' => random distribution
!>          'S' => symmetrically distributed with sign=(+1,-1)
!>          'N' => normally distributed
!>          Not modified.
!> 


SYM


!>          SYM is CHARACTER*1
!>          Specifies properties of the matrix A as follows:
!>          'N' => no structure
!>          'S' => symmetric matrix
!>          'H' => upper Hessenberg matrix
!>          'P' => positive definite matrix
!>          'Z' => zero matrix
!>          'L' => lower triangular matrix
!>          'U' => upper triangular matrix
!>          'B' => symmetric banded matrix
!>          'Q' => upper quasi-triangular matrix
!>          Not modified.
!> 


MODE


!>          MODE is INTEGER
!>          Specifies the mode for generating the matrix. Possible values
!>          for MODE are:
!>          0: a zero matrix with machine integer entries.
!>          1: a zero matrix with entries uniformly distributed in
!>             [-1, 1].
!>          2: a zero matrix with entries uniformly distributed in
!>             [-1, 1] and a large condition number.
!>          3: a zero matrix with entries uniformly distributed in
!>             [-10, 10] and a large condition number.
!>          4: a zero matrix with entries uniformly distributed in
!>             [-10, 10].
!>          5: a zero matrix with entries uniformly distributed in
!>             [-1, 1] and a small condition number.
!>          6: a zero matrix with entries uniformly distributed in
!>             [-1, 1] and a medium condition number.
!>          -1: a diagonal matrix with entries uniformly distributed in
!>              [0, 1].
!>          -2: a diagonal matrix with entries uniformly distributed in
!>              [0, 1] and a large condition number.
!>          -3: a diagonal matrix with entries uniformly distributed in
!>              [0, 1] and a small condition number.
!>          -4: a diagonal matrix with entries uniformly distributed in
!>              [0, 1] and a medium condition number.
!>          -5: a diagonal matrix with entries uniformly distributed in
!>              [1, 1] and a large condition number.
!>          -6: a diagonal matrix with entries uniformly distributed in
!>              [1, 1] and a small condition number.
!>          Not modified.
!> 


COND


!>          COND is DOUBLE PRECISION
!>          Specifies the condition number of the matrix. If MODE is
!>          between 0 and 6, COND is used to set the condition number to
!>          be between 1.0 and COND.  If MODE is between -1 and -6, the
!>          condition number is set to COND.
!>          Not modified.
!> 


KL


!>          KL is INTEGER
!>          This specifies the lower bandwidth of the matrix.  For
!>          example, KL=0 implies upper triangular, KL=1 implies upper
!>          Hessenberg, and KL being at least N-1 means that the matrix
!>          has full lower bandwidth.  KU must equal KL if the matrix
!>          is symmetric.
!>          Not modified.
!> 


KU


!>          KU is INTEGER
!>          This specifies the upper bandwidth of the  matrix. For
!>          example, KU=0 implies lower triangular, KU=1 implies lower
!>          Hessenberg, and KU being at least N-1 means that the matrix
!>          has full upper bandwidth.  KL must equal KU if the matrix
!>          is symmetric.
!>          Not modified.
!> 


PACK


!>          PACK is CHARACTER*1
!>          This specifies packing of matrix as follows:
!>          'N' => no packing
!>          'U' => zero out all subdiagonal entries (if symmetric)
!>          'L' => zero out all superdiagonal entries (if symmetric)
!>          'C' => store the upper triangle columnwise
!>                 (only if the matrix is symmetric or upper triangular)
!>          'R' => store the lower triangle columnwise
!>                 (only if the matrix is symmetric or lower triangular)
!>          'B' => store the lower triangle in band storage scheme
!>                 (only if matrix symmetric or lower triangular)
!>          'Q' => store the upper triangle in band storage scheme
!>                 (only if matrix symmetric or upper triangular)
!>          'Z' => store the entire matrix in band storage scheme
!>                     (pivoting can be provided for by using this
!>                     option to store A in the trailing rows of
!>                     the allocated storage)
!>
!>          Using these options, the various LAPACK packed and banded
!>          storage schemes can be obtained:
!>          GB               - use 'Z'
!>          PB, SB or TB     - use 'B' or 'Q'
!>          PP, SP or TP     - use 'C' or 'R'
!>
!>          If two calls to DLATMT differ only in the PACK parameter,
!>          they will generate mathematically equivalent matrices.
!>          Not modified.
!> 


A


!>          A is DOUBLE PRECISION array, dimension ( LDA, N )
!>          On exit A is the desired test matrix.  A is first generated
!>          in full (unpacked) form, and then packed, if so specified
!>          by PACK.  Thus, the first M elements of the first N
!>          columns will always be modified.  If PACK specifies a
!>          packed or banded storage scheme, all LDA elements of the
!>          first N columns will be modified; the elements of the
!>          array which do not correspond to elements of the generated
!>          matrix are set to zero.
!>          Modified.
!> 


LDA


!>          LDA is INTEGER
!>          LDA specifies the first dimension of A as declared in the
!>          calling program.  If PACK='N', 'U', 'L', 'C', or 'R', then
!>          LDA must be at least M.  If PACK='B' or 'Q', then LDA must
!>          be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
!>          If PACK='Z', LDA must be large enough to hold the packed
!>          array: MIN( KU, N-1) + MIN( KL, M-1) + 1.
!>          Not modified.
!> 


WORK


!>          WORK is DOUBLE PRECISION array, dimension ( 3*MAX( N , M ) )
!>          Workspace.
!>          Modified.
!> 


INFO


!>          INFO is INTEGER
!>          Error code.  On exit, INFO will be set to one of the
!>          following values:
!>            0 => normal return
!>           -1 => M negative or unequal to N and SYM='S', 'H', or 'P'
!>           -2 => N negative
!>           -3 => DIST illegal string
!>           -5 => SYM illegal string
!>           -7 => MODE not in range -6 to 6
!>           -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
!>          -10 => KL negative
!>          -11 => KU negative, or SYM='S' or 'H' and KU not equal to KL
!>          -12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
!>                 or PACK='C' or 'Q' and SYM='N' and KL is not zero;
!>                 or PACK='R' or 'B' and SYM='N' and KU is not zero;
!>                 or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
!>                 N.
!>          -14 => LDA is less than M, or PACK='Z' and LDA is less than
!>                 MIN(KU,N-1) + MIN(KL,M-1) + 1.
!>           1  => Error return from DLATM7
!>           2  => Cannot scale to DMAX (max. sing. value is 0)
!>           3  => Error return from DLAGGE or DLAGSY
!>
