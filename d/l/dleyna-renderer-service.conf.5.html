DLEYNA-RENDERER-SERVICE.CONF(5) Manual de formatos de archivo DLEYNA-RENDERER-SERVICE.CONF(5)

NOMBRE

dleyna-renderer-service.conf - Archivo de configuración para dleyna-renderer-service

SINOPSIS

  • /etc/dleyna-renderer-service.conf
  • $XDG_CONFIG_HOME/dleyna-renderer-service.conf

DESCRIPCIÓN

El programa dleyna-renderer-service proporciona el nombre com.intel.dleyna-renderer en el bus de mensajes de la sesión. Es un servicio para descubrir y manipular DLNA Digital Media Renderers (o DMRs).

Los usuarios o administradores nunca deberían necesitar iniciar este demonio, ya que será iniciado automáticamente por dbus-daemon siempre que un proceso envíe un mensaje D-Bus al nombre com.intel.dleyna-renderer en el bus de la sesión.

Este archivo se puede utilizar para configurar el comportamiento del programa dleyna-renderer-service

FORMATO DEL ARCHIVO

El formato del archivo de configuración es el llamado formato de archivo clave (una especie de estilo ini). Consta de secciones (o grupos) de pares clave-valor. Las líneas que comienzan con un '#' y las líneas en blanco se consideran comentarios. Las secciones se inician con una línea de encabezado que contiene la sección entre corchetes '[' y ']', y terminan implícitamente con el inicio de la siguiente sección o el final del archivo. Cada par clave-valor debe estar contenido en una sección.

SECCIÓN GENERAL

conector-nombre=dbus
El nombre del método de comunicación entre procesos a utilizar. El único valor admitido es dbus
nunca-salir=falso|verdadero
Si el proceso debe permanecer activo para siempre o salir cuando el último cliente se desconecte. El valor predeterminado es falso.
puerto
Puerto de origen para mensajes del Protocolo Simple de Descubrimiento de Servicios (o SSDP). El valor predeterminado es 0, lo que significa que se utilizará un puerto aleatorio disponible.
puerto-host-envío
Puerto para el servidor de archivos de host de envío. El valor predeterminado es 0, lo que significa que se utilizará un puerto aleatorio disponible.

SECCIÓN LOG

tipo-log=0|1|2
El método de registro a utilizar. Se admiten tres tecnologías: 0 para syslog, 1 para GLib y 2 para archivo. El valor predeterminado es 0.
nivel-log=0|1|2|...|8
Lista separada por comas de los niveles de registro. Los niveles son 1 para crítico, 2 para error, 3 para advertencia, 4 para mensaje, 5 para info y 6 para depuración. 0 excluye todos los niveles, 7 es una combinación de crítico, error e info, y 8 incluye todos los niveles.

El valor predeterminado es 7.

SECCIÓN NETF

netf-habilitado=verdadero|falso
Si el filtrado de red debe estar habilitado o no. El valor predeterminado es falso.
netf-lista
Lista separada por comas de nombres de interfaz, identificadores de conjunto de servicios (o SSIDs) y direcciones de Protocolo de Internet (o IP). Si se solicita filtrado de red pero la lista está vacía, el filtrado permanece deshabilitado.

La lista está vacía por defecto.
