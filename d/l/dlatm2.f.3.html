double precision function dlatm2 (integer m, integer n, integer i, integer j, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, double precision, dimension( * ) d, integer igrade, double precision, dimension( * ) dl, double precision, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, double precision sparse)

DLATM2

Propósito:

!>
!>    DLATM2 devuelve la entrada (I,J) de una matriz aleatoria de dimensión
!>    (M, N) descrita por los otros parámetros. Es llamada por la
!>    rutina DLATMR para construir matrices de prueba aleatorias. No se realiza
!>    ninguna comprobación de errores en los parámetros, ya que esta rutina es llamada
!>    en un bucle ajustado por DLATMR, que ya ha comprobado los parámetros.
!>
!>    El uso de DLATM2 difiere de SLATM3 en el orden en que se llama al generador
!>    de números aleatorios para rellenar las entradas de la matriz aleatoria.
!>    Con DLATM2, el generador se llama para rellenar la matriz pivoteada
!>    columna por columna. Con DLATM3, el generador se llama para rellenar la
!>    matriz columna por columna, después de lo cual se pivotea. Por lo tanto,
!>    DLATM3 puede usarse para construir matrices aleatorias que difieren solo en su
!>    orden de filas y/o columnas. DLATM2 se usa para construir matrices de banda
!>    evitando llamar al generador de números aleatorios para entradas fuera de la banda
!>    (y por lo tanto, generando números aleatorios
!>
!>    La matriz cuya entrada (I,J) se devuelve se construye como
!>    sigue (esta rutina solo calcula una entrada):
!>
!>      Si I está fuera de (1..M) o J está fuera de (1..N), devuelve cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Genera una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establece la diagonal a D.
!>
!>      Califica la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) según lo especificado por IGRADE.
!>
!>      Permuta, si se desea, las filas y/o columnas según lo especificado por
!>         IPVTNG y IWORK.
!>
!>      Convierte la matriz a formato de banda con ancho de banda inferior KL y
!>         ancho de banda superior KU.
!>
!>      Establece entradas aleatorias a cero según lo especificado por SPARSE.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de la matriz. No modificado.
!>

N

!>          N es INTEGER
!>           Número de columnas de la matriz. No modificado.
!>

I

!>          I es INTEGER
!>           Fila de la entrada a devolver. No modificado.
!>

J

!>          J es INTEGER
!>           Columna de la entrada a devolver. No modificado.
!>

KL

!>          KL es INTEGER
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU es INTEGER
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST es INTEGER
!>           En la entrada, IDIST especifica el tipo de distribución que se va a
!>           utilizar para generar una matriz aleatoria.
!>           1 => UNIFORME( 0, 1 )
!>           2 => UNIFORME( -1, 1 )
!>           3 => NORMAL( 0, 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es array INTEGER de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Cambiado en la salida.
!>

D

!>          D es array DOUBLE PRECISION de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificado.
!>

IGRADE

!>          IGRADE es INTEGER
!>           Especifica la calificación de la matriz como sigue:
!>           0  => sin calificación
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL es array DOUBLE PRECISION ( I o J, según corresponda )
!>           Factores de escala izquierda para calificar la matriz. No modificado.
!>

DR

!>          DR es array DOUBLE PRECISION ( I o J, según corresponda )
!>           Factores de escala derecha para calificar la matriz. No modificado.
!>

IPVTNG

!>          IPVTNG es INTEGER
!>           En la entrada especifica las permutaciones de pivote como sigue:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK es array INTEGER ( I o J, según corresponda )
!>           Este array especifica la permutación utilizada. La
!>           fila (o columna) en la posición K estaba originalmente en
!>           la posición IWORK( K ).
!>           Esto difiere de IWORK para DLATM3. No modificado.
!>

SPARSE

!>          SPARSE es DOUBLE PRECISION entre 0. y 1.
!>           En la entrada especifica la dispersión de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme ( 0, 1 ) x
!>           y se compara con SPARSE; si x es mayor, la entrada de la matriz
!>           no cambia y si x es menor, la entrada se establece
!>           a cero. Por lo tanto, en promedio, una fracción SPARSE de las
!>           entradas se establecerá a cero.
!>           No modificado.
!>
