Documentación de la función/subrutin

a

subrutina dlatms (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, double precision, dimension( * ) d, integer mode, double precision cond, double precision dmax, integer kl, integer ku, character pack, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work, integer

info)

DLATM

S

Propósito

: 
!>
!>    DLATMS genera matrices aleatorias con valores singulares especificados
!>    (o simétricas/hermíticas con valores propios especificados)
!>    para probar los programas de LAPACK.
!>
!>    DLATMS opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establece la diagonal en D, donde D puede ser de entrada o
!>         calculado de acuerdo con MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Genera una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Genera una matriz densa M x N multiplicando D a la izquierda
!>              y a la derecha por matrices unitarias aleatorias, luego:
!>
!>          Reduce el ancho de banda de acuerdo con KL y KU, usando
!>          transformaciones de Householder.
!>
!>      Método B:
!>          Convierte la matriz de ancho de banda 0 (es decir, diagonal) en una
!>              matriz de ancho de banda 1 usando rotaciones de Givens,
!>              elementos fuera de banda hacia atrás, mucho como en QR; luego
!>              convierte el ancho de banda 1 en un ancho de banda 2, etc.
!>              Tenga en cuenta que para anchos de banda razonablemente pequeños (en relación con
!>              M y N) esto requiere menos almacenamiento, ya que no se genera
!>              una matriz densa.  Además, para matrices simétricas, solo
!>              se genera un triángulo.
!>
!>      Se elige el Método A si el ancho de banda es una fracción grande de la
!>          orden de la matriz, y LDA es al menos M (de modo que una matriz densa
!>          pueda almacenarse).  Se elige el Método B si el ancho de banda
!>          es pequeño (< 1/2 N para simétrica, < .3 N+M para
!>          no simétrica), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetado
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior por columnas (si es simétrica o
!>               triangular superior)
!>         almacenar la mitad inferior por columnas (si es simétrica o
!>               triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es simétrica
!>               o triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es simétrica
!>               o triangular superior)
!>         almacenar la matriz completa en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en el formato de banda, por lo que no será necesario
!>         reempaquetar.
!
>

Parámetro

s
M 
!>          M es INTEGER
!>           El número de filas de A. No modificado.
!
>

N 
!>          N es INTEGER
!>           El número de columnas de A. No modificado.
!
>

DIS

T 
!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a usar
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORM( 0, 1 )  ( 'U' por uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' por simétrica )
!>           'N' => NORMAL( 0, 1 )   ( 'N' por normal )
!>           No modificado.
!
>

ISEE

D 
!>          ISEED es un arreglo INTEGER, dimensión ( 4 )
!>           En la entrada ISEED especifica la semilla del generador de números
!>           aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           usa una secuencia congruencial lineal limitada a pequeños
!>           enteros, y por lo tanto debe producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED se cambian en
!>           la salida, y pueden usarse en la siguiente llamada a DLATMS
!>           para continuar la misma secuencia de números aleatorios.
!>           Modificado en la salida.
!
>

SY

M 
!>          SYM es CHARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es simétrica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada no es simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           No modificado.
!
>

D 
!>          D es un arreglo DOUBLE PRECISION, dimensión ( MIN( M , N ) )
!>           Este arreglo se usa para especificar los valores singulares o
!>           propios de A (ver SYM, arriba.)  Si MODE=0, entonces se asume
!>           que D contiene los valores singulares/propios, de lo contrario
!>           se calcularán de acuerdo con MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!
>

MOD

E 
!>          MODE es INTEGER
!>           En la entrada esto describe cómo deben especificarse los valores
!>           singulares/propios:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D como números aleatorios en el rango
!>                    ( 1/COND , 1 ) de modo que sus logaritmos
!>                    estén uniformemente distribuidos.
!>           MODE = 6 establece D como números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D está invertido.
!>           Así que si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           Si SYM='S' o 'H', y MODE no es ni 0, 6, ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo
!>              aleatorio (es decir, +1 o -1.)
!>           No modificado.
!
>

CON

D 
!>          COND es DOUBLE PRECISION
!>           En la entrada, esto se usa como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!
>

DMA

X 
!>          DMAX es DOUBLE PRECISION
!>           Si MODE no es ni -6, 0 ni 6, el contenido de D, tal como
!>           se calculó de acuerdo con MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))); así, el valor propio o singular
!>           absoluto máximo (es decir, la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no necesita ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No modificado.
!
>

K

L 
!>          KL es INTEGER
!>           Esto especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica
!>           Hessenberg superior, y KL siendo al menos M-1 significa que la matriz
!>           tiene ancho de banda inferior completo.  KL debe ser igual a KU si la matriz
!>           es simétrica.
!>           No modificado.
!
>

K

U 
!>          KU es INTEGER
!>           Esto especifica el ancho de banda superior de la matrx. Por
!>           ejemplo, KU=0 implica triangular inferior, KU=1 implica
!>           Hessenberg inferior, y KU al menos N-1 significa que la
!>           matriz tiene ancho de banda superior completo. KL debe ser
!>           igual a KU si la matriz es simétrica.
!>           No modificado.
!
>

PAC

K 
!>          PACK es CHARACTER*1
!>           Especifica el empaquetado de la matriz de la siguiente
!>           manera:
!>           'N' => sin empaquetado
!>           'U' => poner a cero todas las entradas por debajo de la
!>                  diagonal (si es simétrica)
!>           'L' => poner a cero todas las entradas por encima de la
!>                  diagonal (si es simétrica)
!>           'C' => almacenar el triángulo superior por columnas
!>                  (solo si la matriz es simétrica o triangular
!>                  superior)
!>           'R' => almacenar el triángulo inferior por columnas
!>                  (solo si la matriz es simétrica o triangular
!>                  inferior)
!>           'B' => almacenar el triángulo inferior en el esquema de
!>                  almacenamiento en banda (solo si la matriz es
!>                  simétrica o triangular inferior)
!>           'Q' => almacenar el triángulo superior en el esquema de
!>                  almacenamiento en banda (solo si la matriz es
!>                  simétrica o triangular superior)
!>           'Z' => almacenar la matriz completa en el esquema de
!>                  almacenamiento en banda (el pivoteo puede
!>                  proporcionarse usando esta opción para almacenar A
!>                  en las filas finales del almacenamiento asignado)
!>
!>           Usando estas opciones, se pueden obtener los distintos
!>           esquemas de almacenamiento empaquetado y en banda de
!>           LAPACK:
!>           GB               - usar 'Z'
!>           PB, SB o TB     - usar 'B' o 'Q'
!>           PP, SP o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a DLATMS difieren solo en el parámetro
!>           PACK, generarán matrices matemáticamente equivalentes.
!>           No modificado.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión ( LDA, N )
!>           En la salida, A es la matriz de prueba deseada. A se
!>           genera primero en forma completa (sin empaquetar) y luego
!>           se empaqueta, si así lo especifica PACK. Por lo tanto, los
!>           primeros M elementos de las primeras N columnas siempre
!>           serán modificados. Si PACK especifica un esquema de
!>           almacenamiento empaquetado o en banda, todos los LDA
!>           elementos de las primeras N columnas serán modificados; los
!>           elementos del array que no correspondan a elementos de la
!>           matriz generada se establecen a cero.
!>           Modificado.
!
>

LD

A 
!>          LDA es INTEGER
!>           LDA especifica la primera dimensión de A como se declara
!>           en el programa que llama. Si PACK='N', 'U', 'L', 'C' o
!>           'R', entonces LDA debe ser al menos M. Si PACK='B' o 'Q',
!>           entonces LDA debe ser al menos MIN( KL, M-1) (que es igual
!>           a MIN(KU,N-1)). Si PACK='Z', LDA debe ser lo suficientemente
!>           grande para contener el array empaquetado: MIN( KU, N-1) +
!>           MIN( KL, M-1) + 1.
!>           No modificado.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión ( 3*MAX( N , M ) )
!>           Espacio de trabajo.
!>           Modificado.
!
>

INF

O 
!>          INFO es INTEGER
!>           Código de error. En la salida, INFO se establecerá en uno
!>           de los siguientes valores:
!>             0 => retorno normal
!>            -1 => M negativo o distinto de N y SYM='S', 'H' o 'P'
!>            -2 => N negativo
!>            -3 => DIST cadena ilegal
!>            -5 => SYM cadena ilegal
!>            -7 => MODE fuera del rango -6 a 6
!>            -8 => COND menor que 1.0, y MODE no es -6, 0 ni 6
!>           -10 => KL negativo
!>           -11 => KU negativo, o SYM='S' o 'H' y KU no es igual a KL
!>           -12 => PACK cadena ilegal, o PACK='U' o 'L' y SYM='N';
!>                  o PACK='C' o 'Q' y SYM='N' y KL no es cero;
!>                  o PACK='R' o 'B' y SYM='N' y KU no es cero;
!>                  o PACK='U', 'L', 'C', 'R', 'B' o 'Q', y M no es N.
!>           -14 => LDA es menor que M, o PACK='Z' y LDA es menor que
!>                  MIN(KU,N-1) + MIN(KL,M-1) + 1.
!>            1  => Retorno de error de DLATM1
!>            2  => No se puede escalar a DMAX (el valor singular máximo es 0)
!>            3  => Retorno de error de DLAGGE o SLAGSY
!
>
