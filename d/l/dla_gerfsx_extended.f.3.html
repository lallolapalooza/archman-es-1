subrutina dla_gerfsx_extended (integer prec_type, integer trans_type, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) errs_n, double precision, dimension( nrhs, * ) errs_c, double precision, dimension( * ) res, double precision, dimension( * ) ayb, double precision, dimension( * ) dy, double precision, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer

DLA_GERFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices generales mediante la realización de un refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la

solución.

Propósito

: 
!>
!>
!> DLA_GERFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales mediante la realización de un refinamiento iterativo
!> de precisión extra y proporciona límites de error y estimaciones de error
!> hacia atrás para la solución.
!> Esta subrutina es llamada por DGERFSX para realizar el refinamiento iterativo.
!> Además del límite de error en norma, el código proporciona un límite de
!> error componente a componente si es posible. Vea los comentarios para ERRS_N
!> y ERRS_C para detalles de los límites de error. Note que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERRS_N y ERRS_C.
!
>

Parámetro

s
PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a usar en el refinamiento.
!>     El valor está definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple (Single)
!>          = 'D':  Doble (Double)
!>          = 'I':  Indígena (Indigenous)
!>          = 'X' o 'E':  Extra
!
>

TRANS_TYP

E 
!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición sobre A.
!>     El valor está definido por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transponer
!>          = 'T':  Transponer
!>          = 'C':  Transponer conjugada
!
>

N 
!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>     El número de miembros derechos (right-hand-sides), es decir, el número de columnas de la
!>     matriz B.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>     A la entrada, la matriz A de N por N.
!
>

LD

A 
!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!
>

A

F 
!>          AF es un array DOUBLE PRECISION, dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U tal como se calcula con DGETRF.
!
>

LDA

F 
!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!
>

IPI

V 
!>          IPIV es un array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como se calcula con DGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!
>

COLEQ

U 
!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó un equilibrado de columnas a A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y los
!>     límites de error correctamente.
!
>

C 
!>          C es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no es accedido. Si C es de entrada, cada elemento de C debería ser una potencia
!>     de la base para asegurar una solución y estimaciones de error confiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos que
!>     el resultado se desborde por abajo o por arriba. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     confiables.
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>     La matriz de miembros derechos B.
!
>

LD

B 
!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!
>

Y 
!>          Y es un array DOUBLE PRECISION, dimensión (LDY,NRHS)
!>     A la entrada, la matriz solución X, tal como se calcula con DGETRS.
!>     A la salida, la matriz solución mejorada Y.
!
>

LD

Y 
!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!
>

BERR_OU

T 
!>          BERR_OUT es un array DOUBLE PRECISION, dimensión (NRHS)
!>     A la salida, BERR_OUT(j) contiene el error relativo hacia atrás componente a componente
!>     para el miembro derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto es calculado por DLA_LIN_BERR.
!
>

N_NORM

S 
!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (ver ERRS_N
!>     y ERRS_C).
!>     Si N_NORMS >= 1 devuelve límites de error en norma.
!>     Si N_NORMS >= 2 devuelve límites de error componente a componente.
!
>

ERRS_

N 
!>          ERRS_N es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada miembro derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, el cual está definido de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERRS_N(i,:) corresponde al i-ésimo
!>     miembro derecho.
!>
!>     El segundo índice en ERRS_N(:,err) contaen los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado en norma. Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada apropiadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia
!>              de la base para que todas las sumas absolutas de filas
!>              de Z sean aproximadamente 1.
!>
!>     Este subrutina es solo responsable de establecer el segundo
!>     campo anterior.
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

ERRS_

C 
!>          ERRS_C es un arreglo de PRECISIÓN DOBLE, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada segundo miembro, este arreglo contiene información
!>     sobre varios límites de error y números de condición
!>     correspondientes al error relativo componente a componente, que
!>     se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El arreglo está indexado por el segundo miembro i (del cual
!>     depende el error relativo componente a componente), y el tipo de
!>     información de error descrito a continuación. Actualmente se
!>     devuelven hasta tres piezas de información para cada segundo
!>     miembro. Si no se solicita precisión componente a componente
!>     (PARAMS(3) = 0.0), entonces no se accede a ERRS_C. Si
!>     N_ERR_BNDS < 3, entonces se devuelven como máximo las primeras
!>     entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERRS_C(i,:) corresponde al i-ésimo
!>     segundo miembro.
!>
!>     El segundo índice en ERRS_C(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado componente a componente. Se compara
!>              con el umbral sqrt(n) * slamch('Epsilon') para
!>              determinar si la estimación de error es . Estos números
!>              de condición recíprocos son 1 / (norm(Z^{-1},inf) *
!>              norm(Z,inf)) para alguna matriz Z escalada
!>              apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              segundo miembro actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas
!>              las sumas absolutas de filas de Z sean aproximadamente
!>              1.
!>
!>     Este subrutina es solo responsable de establecer el segundo
!>     campo anterior.
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

RE

S 
!>          RES es un arreglo de PRECISIÓN DOBLE, dimensión (N)
!>     Espacio de trabajo para mantener el residuo intermedio.
!
>

AY

B 
!>          AYB es un arreglo de PRECISIÓN DOBLE, dimensión (N)
!>     Espacio de trabajo. Este puede ser el mismo espacio de trabajo
!>     pasado para Y_TAIL.
!
>

D

Y 
!>          DY es un arreglo de PRECISIÓN DOBLE, dimensión (N)
!>     Espacio de trabajo para mantener la solución intermedia.
!
>

Y_TAI

L 
!>          Y_TAIL es un arreglo de PRECISIÓN DOBLE, dimensión (N)
!>     Espacio de trabajo para mantener los bits finales de la
!>     solución intermedia.
!
>

RCON

D 
!>          RCOND es PRECISIÓN DOBLE
!>     Número de condición recíproco escalado. Esta es una estimación
!>     del número de condición recíproco de Skeel de la matriz A
!>     después de la equilibración (si se hizo). Si esto es menor que
!>     la precisión de la máquina (en particular, si es cero), la
!>     matriz es singular hasta la precisión de trabajo. Tenga en
!>     cuenta que el error puede ser pequeño incluso si este número es
!>     muy pequeño y la matriz parece mal condicionada.
!
>

ITHRES

H 
!>          ITHRESH es INTEGER
!>     El número máximo de cálculos de residuo permitidos para el
!>     refinamiento. El valor predeterminado es 10. Para 'aggressive'
!>     establezca en 100 para permitir la convergencia usando
!>     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>     la factorización usa una técnica distinta de la eliminación
!>     gaussiana, las garantías en ERRS_N y ERRS_C pueden dejar de ser
!>     confiables.
!
>

RTHRES

H 
!>          RTHRESH es PRECISIÓN DOBLE
!>     Determina cuándo detener el refinamiento si la estimación de
!>     error deja de disminuir. El refinamiento se detendrá cuando la
!>     siguiente solución ya no satisfaga norm(dx_{i+1}) < RTHRESH *
!>     norm(dx_i) donde norm(Z) es la norma infinita de Z. RTHRESH
!>     satisface 0 < RTHRESH <= 1. El valor predeterminado es 0.5. Para
!>     'aggressive' establezca en 0.9 para permitir la convergencia en
!>     matrices extremadamente mal condicionadas. Vea LAWN 165 para más
!>     detalles.
!
>

DZ_U

B 
!>          DZ_UB es PRECISIÓN DOBLE
!>     Determina cuándo comenzar a considerar la convergencia componente
!>     a componente. La convergencia componente a componente solo se
!>     considera después de que cada componente de la solución Y sea
!>     estable, lo cual definimos como el cambio relativo en cada
!>     componente siendo menor que DZ_UB. El valor predeterminado es
!>     0.25, requiriendo que el primer bit sea estable. Vea LAWN 165
!>     para más detalles.
!
>

IGNORE_CWIS

E 
!>          IGNORE_CWISE es LOGICAL
!>     Si .TRUE. entonces ignorar la convergencia componente a
!>     componente. El valor predeterminado es .FALSE..
!
>

INF

O 
!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  si INFO = -i, el i-ésimo argumento a DGETRS tenía un
!>             valor ilegal
!
>
