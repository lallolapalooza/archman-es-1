subrutina dlags2 (upper, a1, a2, a3, b1, b2, b3, csu, snu, csv, snv, csq, snq)

DLAGS2 calcula matrices ortogonales 2x2 U, V y Q, y las aplica a las matrices A y B de tal forma que las filas de la A y B transformadas sean paralelas.

Documentación de la función/subrutina

subrutina dlags2 (logical upper, double precision a1, double precision a2, double precision a3, double precision b1, double precision b2, double precision b3, double precision csu, double precision snu, double precision csv, double precision snv, double precision csq, double precision snq)

DLAGS2 calcula matrices ortogonales 2x2 U, V y Q, y las aplica a las matrices A y B de tal forma que las filas de la A y B transformadas sean paralelas.

Propósito:

!>
!> DLAGS2 calcula matrices ortogonales 2x2 U, V y Q, tal
!> que si ( UPPER ) entonces
!>
!>           U**T *A*Q = U**T *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> y
!>           V**T*B*Q = V**T *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> o si ( .NOT.UPPER ) entonces
!>
!>           U**T *A*Q = U**T *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> y
!>           V**T*B*Q = V**T*( B1 0  )*Q = ( x  x  )
!>                           ( B2 B3 )     ( 0  x  )
!>
!> Las filas de las A y B transformadas son paralelas, donde
!>
!>   U = (  CSU  SNU ), V = (  CSV SNV ), Q = (  CSQ   SNQ )
!>       ( -SNU  CSU )      ( -SNV CSV )      ( -SNQ   CSQ )
!>
!> Z**T denota la transpuesta de Z.
!>
!>

Parámetros

UPPER 
!>          UPPER es LOGICAL
!>          = .TRUE.: las matrices de entrada A y B son triangulares superiores.
!>          = .FALSE.: las matrices de entrada A y B son triangulares inferiores.
!>

A1

!>          A1 es DOUBLE PRECISION
!>

A2

!>          A2 es DOUBLE PRECISION
!>

A3

!>          A3 es DOUBLE PRECISION
!>          En la entrada, A1, A2 y A3 son elementos de la matriz 2x2
!>          triangular superior (inferior) de entrada A.
!>

B1

!>          B1 es DOUBLE PRECISION
!>

B2

!>          B2 es DOUBLE PRECISION
!>

B3

!>          B3 es DOUBLE PRECISION
!>          En la entrada, B1, B2 y B3 son elementos de la matriz 2x2
!>          triangular superior (inferior) de entrada B.
!>

CSU

!>          CSU es DOUBLE PRECISION
!>

SNU

!>          SNU es DOUBLE PRECISION
!>          La matriz ortogonal deseada U.
!>

CSV

!>          CSV es DOUBLE PRECISION
!>

SNV

!>          SNV es DOUBLE PRECISION
!>          La matriz ortogonal deseada V.
!>

CSQ

!>          CSQ es DOUBLE PRECISION
!>

SNQ

!>          SNQ es DOUBLE PRECISION
!>          La matriz ortogonal deseada Q.
!>
