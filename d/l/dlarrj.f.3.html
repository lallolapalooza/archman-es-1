Documentación de función/subrutina

subrutina dlarrj (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e2, integer ifirst, integer ilast, double precision rtol, integer offset, double precision, dimension( * ) w, double precision, dimension( * ) werr, double precision, dimension( * ) work, integer, dimension( * ) iwork, double precision pivmin, double precision spdiam, integer info)

DLARRJ realiza el refinamiento de las estimaciones iniciales de los valores propios de la matriz T.

Propósito:

!>
!> Dada las aproximaciones iniciales de los valores propios de T, DLARRJ
!> realiza la bisección para refinar los valores propios de T,
!> W( IFIRST-OFFSET ) a W( ILAST-OFFSET ), con mayor precisión. Las
!> suposiciones iniciales para estos valores propios se introducen en W, la
!> estimación correspondiente del error en estas suposiciones en WERR.
!> Durante la bisección, los intervalos [left, right] se mantienen
!> almacenando sus puntos medios y semianchos en los arreglos W y WERR
!> respectivamente.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz.
!>

D

!>          D es DOUBLE PRECISION array, dimension (N)
!>          Los N elementos diagonales de T.
!>

E2

!>          E2 es DOUBLE PRECISION array, dimension (N-1)
!>          Los cuadrados de los (N-1) elementos subdiagonales de T.
!>

IFIRST

!>          IFIRST es INTEGER
!>          El índice del primer valor propio a calcular.
!>

ILAST

!>          ILAST es INTEGER
!>          El índice del último valor propio a calcular.
!>

RTOL

!>          RTOL es DOUBLE PRECISION
!>          Tolerancia para la convergencia de los intervalos de bisección.
!>          Un intervalo [LEFT,RIGHT] ha convergido si
!>          RIGHT-LEFT < RTOL*MAX(|LEFT|,|RIGHT|).
!>

OFFSET

!>          OFFSET es INTEGER
!>          Offset para los arreglos W y WERR, es decir, los elementos IFIRST-OFFSET
!>          a ILAST-OFFSET de estos arreglos se utilizarán.
!>

W

!>          W es DOUBLE PRECISION array, dimension (N)
!>          En la entrada, W( IFIRST-OFFSET ) a W( ILAST-OFFSET ) son
!>          estimaciones de los valores propios de L D L^T indexados IFIRST a
!>          ILAST.
!>          En la salida, estas estimaciones se refinan.
!>

WERR

!>          WERR es DOUBLE PRECISION array, dimension (N)
!>          En la entrada, WERR( IFIRST-OFFSET ) a WERR( ILAST-OFFSET ) son
!>          los errores en las estimaciones de los elementos correspondientes en W.
!>          En la salida, estos errores se refinan.
!>

WORK

!>          WORK es DOUBLE PRECISION array, dimension (2*N)
!>          Espacio de trabajo.
!>

IWORK

!>          IWORK es INTEGER array, dimension (2*N)
!>          Espacio de trabajo.
!>

PIVMIN

!>          PIVMIN es DOUBLE PRECISION
!>          El pivote mínimo en la secuencia de Sturm para T.
!>

SPDIAM

!>          SPDIAM es DOUBLE PRECISION
!>          El diámetro espectral de T.
!>

INFO

!>          INFO es INTEGER
!>          Indicador de error.
!>
