Documentación de Función/Subrutina

subrutine dlaed3 (integer k, integer n, integer n1, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, double precision rho, double precision, dimension( * ) dlambda, double precision, dimension( * ) q2, integer, dimension( * ) indx, integer, dimension( * ) ctot, double precision, dimension( * ) w, double precision, dimension( * ) s, integer info)

DLAED3 usado por DSTEDC. Encuentra las raíces de la ecuación secular y actualiza los vectores propios. Usado cuando la matriz original es tridiagonal.

Propósito:

!>
!> DLAED3 encuentra las raíces de la ecuación secular, tal como se definen por los
!> valores en D, W y RHO, entre 1 y K.  Realiza las llamadas apropiadas a DLAED4 y
!> luego actualiza los vectores propios multiplicando la matriz de vectores propios
!> del par de auto-sistemas que se combinan por la matriz de vectores propios
!> del sistema K-por-K que se resuelve aquí.
!>
!>

Parámetros

K 
!>          K es INTEGER
!>          El número de términos en la función racional a ser resuelta por
!>          DLAED4.  K >= 0.
!>

N

!>          N es INTEGER
!>          El número de filas y columnas en la matriz Q.
!>          N >= K (la deflación puede resultar en N>K).
!>

N1

!>          N1 es INTEGER
!>          La ubicación de la última eigenvalue en la submatriz principal.
!>          min(1,N) <= N1 <= N/2.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>          D(I) contiene las eigenvalues actualizadas para
!>          1 <= I <= K.
!>

Q

!>          Q es un array de DOUBLE PRECISION, dimensión (LDQ,N)
!>          Inicialmente, las primeras K columnas se usan como espacio de trabajo.
!>          En la salida, las columnas de la 1 a la K contienen
!>          los vectores propios actualizados.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  LDQ >= max(1,N).
!>

RHO

!>          RHO es DOUBLE PRECISION
!>          El valor del parámetro en la ecuación de actualización de rango uno.
!>          Se requiere RHO >= 0.
!>

DLAMBDA

!>          DLAMBDA es un array de DOUBLE PRECISION, dimensión (K)
!>          Los primeros K elementos de este array contienen las raíces antiguas
!>          del problema de actualización deflacionado. Estos son los polos
!>          de la ecuación secular.
!>

Q2

!>          Q2 es un array de DOUBLE PRECISION, dimensión (LDQ2*N)
!>          Las primeras K columnas de esta matriz contienen los vectores propios
!>          no deflacionados para el problema dividido.
!>

INDX

!>          INDX es un array de INTEGER, dimensión (N)
!>          La permutación usada para organizar las columnas de la matriz Q
!>          deflacionada en tres grupos (ver DLAED2).
!>          Las filas de los vectores propios encontrados por DLAED4 deben ser
!>          permutadas de manera similar antes de que pueda ocurrir la multiplicación
!>          de matrices.
!>

CTOT

!>          CTOT es un array de INTEGER, dimensión (4)
!>          Un conteo del número total de los varios tipos de columnas
!>          en Q, como se describe en INDX. El cuarto tipo de columna es cualquier
!>          columna que ha sido deflacionada.
!>

W

!>          W es un array de DOUBLE PRECISION, dimensión (K)
!>          Los primeros K elementos de este array contienen los componentes
!>          del vector de actualización ajustado por deflación. Destruido en
!>          la salida.
!>

S

!>          S es un array de DOUBLE PRECISION, dimensión (N1 + 1)*K
!>          Contendrá los vectores propios de la matriz reparada que
!>          se multiplicarán por los vectores propios acumulados previamente
!>          para actualizar el sistema.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  si INFO = 1, una eigenvalue no convergió
!>
