función de precisión doble dlansy (norm, uplo, n, a, lda, work)
DLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica real.

Documentación de Función/Subrutina

función de precisión doble dlansy (carácter norm, carácter uplo, entero n, precisión doble, dimensión( lda, * ) a, entero lda, precisión doble, dimensión( * ) work)

DLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica real.

Propósito:

!>
!> DLANSY  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma de infinito,  o el  elemento de  mayor valor absoluto de una
!> matriz simétrica real A.
!>

Devuelve

DLANSY 
!>
!>    DLANSY = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma de infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en DLANSY como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A se va a referenciar.
!>          = 'U':  Se hace referencia a la parte triangular superior de A
!>          = 'L':  Se hace referencia a la parte triangular inferior de A
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, DLANSY se
!>          establece a cero.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>          principal de n por n de A contiene la parte triangular superior
!>          de la matriz A, y la parte triangular inferior estricta de A
!>          no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>          principal de n por n de A contiene la parte triangular inferior
!>          de la matriz A, y la parte triangular superior estricta de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo contrario,
!>          WORK no se referencia.
!>
