Documentación de la Función/Subrutina

subrutina dlagv2 (doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( ldb, * ) b, entero ldb, doble precisión, dimensión( 2 ) alphar, doble precisión, dimensión( 2 ) alphai, doble precisión, dimensión( 2 ) beta, doble precisión csl, doble precisión snl, doble precisión csr, doble precisión snr)

DLAGV2 calcula la factorización Generalizada de Schur de un par de matrices reales de 2x2 (A,B) donde B es triangular superior.

Propósito:

!>
!> DLAGV2 calcula la factorización Generalizada de Schur de un par
!> de matrices reales de 2x2 (A,B) donde B es triangular superior. Esta subrutina
!> calcula las matrices ortogonales (de rotación) dadas por CSL, SNL y CSR,
!> SNR tales que
!>
!> 1) si el par (A,B) tiene dos valores propios reales (incluyendo tipos
!>    0/0 o 1/0), entonces
!>
!>    [ a11 a12 ] := [  CSL  SNL ] [ a11 a12 ] [  CSR -SNR ]
!>    [  0  a22 ]    [ -SNL  CSL ] [ a21 a22 ] [  SNR  CSR ]
!>
!>    [ b11 b12 ] := [  CSL  SNL ] [ b11 b12 ] [  CSR -SNR ]
!>    [  0  b22 ]    [ -SNL  CSL ] [  0  b22 ] [  SNR  CSR ],
!>
!> 2) si el par (A,B) tiene un par de valores propios conjugados complejos,
!>    entonces
!>
!>    [ a11 a12 ] := [  CSL  SNL ] [ a11 a12 ] [  CSR -SNR ]
!>    [ a21 a22 ]    [ -SNL  CSL ] [ a21 a22 ] [  SNR  CSR ]
!>
!>    [ b11  0  ] := [  CSL  SNL ] [ b11 b12 ] [  CSR -SNR ]
!>    [  0  b22 ]    [ -SNL  CSL ] [  0  b22 ] [  SNR  CSR ]
!>
!>    donde b11 >= b22 > 0.
!>
!>

Parámetros

A 
!>          A es una matriz de DOBLE PRECISIÓN, dimensión (LDA, 2)
!>          En la entrada, la matriz 2x2 A.
!>          En la salida, A es sobrescrita por la "parte A" de la
!>          forma de Schur generalizada.
!>

LDA

!>          LDA es un ENTERO
!>          La dimensión principal del arreglo A. LDA >= 2.
!>

B

!>          B es una matriz de DOBLE PRECISIÓN, dimensión (LDB, 2)
!>          En la entrada, la matriz triangular superior 2x2 B.
!>          En la salida, B es sobrescrita por la "parte B" de la
!>          forma de Schur generalizada.
!>

LDB

!>          LDB es un ENTERO
!>          La dimensión principal del arreglo B. LDB >= 2.
!>

ALPHAR

!>          ALPHAR es una matriz de DOBLE PRECISIÓN, dimensión (2)
!>

ALPHAI

!>          ALPHAI es una matriz de DOBLE PRECISIÓN, dimensión (2)
!>

BETA

!>          BETA es una matriz de DOBLE PRECISIÓN, dimensión (2)
!>          (ALPHAR(k)+i*ALPHAI(k))/BETA(k) son los valores propios del
!>          par (A,B), k=1,2, i = sqrt(-1). Nótese que BETA(k) puede
!>          ser cero.
!>

CSL

!>          CSL es DOBLE PRECISIÓN
!>          El coseno de la matriz de rotación izquierda.
!>

SNL

!>          SNL es DOBLE PRECISIÓN
!>          El seno de la matriz de rotación izquierda.
!>

CSR

!>          CSR es DOBLE PRECISIÓN
!>          El coseno de la matriz de rotación derecha.
!>

SNR

!>          SNR es DOBLE PRECISIÓN
!>          El seno de la matriz de rotación derecha.
!>
