Documentación de la función/subrutina

subrutina dlaed9 (integer k, integer kstart, integer kstop, integer n, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, double precision rho, double precision, dimension( * ) dlambda, double precision, dimension( * ) w, double precision, dimension( lds, * ) s, integer lds, integer info)

DLAED9 utilizada por DSTEDC. Encuentra las raíces de la ecuación secular y actualiza los vectores propios. Se utiliza cuando la matriz original es densa.

Propósito:

!>
!> DLAED9 encuentra las raíces de la ecuación secular, tal como se definen por
!> los valores en D, Z y RHO, entre KSTART y KSTOP. Realiza las
!> llamadas apropiadas a DLAED4 y luego almacena la nueva matriz de
!> vectores propios para su uso en el cálculo del siguiente nivel de
!> vectores Z.
!>

Parámetros

K 
!>          K es INTEGER
!>          El número de términos en la función racional que será resuelta por
!>          DLAED4.  K >= 0.
!>

KSTART

!>          KSTART es INTEGER
!>

KSTOP

!>          KSTOP es INTEGER
!>          Los valores propios actualizados Lambda(I), KSTART <= I <= KSTOP
!>          se calcularán.  1 <= KSTART <= KSTOP <= K.
!>

N

!>          N es INTEGER
!>          El número de filas y columnas en la matriz Q.
!>          N >= K (la delación puede resultar en N > K).
!>

D

!>          D es un array DOUBLE PRECISION, dimension (N)
!>          D(I) contiene los valores propios actualizados
!>          para KSTART <= I <= KSTOP.
!>

Q

!>          Q es un array DOUBLE PRECISION, dimension (LDQ,N)
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  LDQ >= max( 1, N ).
!>

RHO

!>          RHO es DOUBLE PRECISION
!>          El valor del parámetro en la ecuación de actualización de rango uno.
!>          Se requiere RHO >= 0.
!>

DLAMBDA

!>          DLAMBDA es un array DOUBLE PRECISION, dimension (K)
!>          Los primeros K elementos de este array contienen las antiguas raíces
!>          del problema de actualización deflacionado. Estos son los polos
!>          de la ecuación secular.
!>

W

!>          W es un array DOUBLE PRECISION, dimension (K)
!>          Los primeros K elementos de este array contienen los componentes
!>          del vector de actualización ajustado por deflación.
!>

S

!>          S es un array DOUBLE PRECISION, dimension (LDS, K)
!>          Contendrá los vectores propios de la matriz reparada que
!>          se almacenarán para el cálculo posterior del vector Z y
!>          se multiplicarán por los vectores propios acumulados previamente
!>          para actualizar el sistema.
!>

LDS

!>          LDS es INTEGER
!>          La dimensión principal de S.  LDS >= max( 1, K ).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un valor propio no convergió.
!>
