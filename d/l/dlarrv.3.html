Propósito

: 
!>
!> DLARRV calcula los autovectores de la matriz tridiagonal
!> T = L D L**T dados L, D y APROXIMACIONES a los autovalores de L D L**T.
!> Los autovalores de entrada deberían haber sido calculados por DLARRE.
!
>

!>          El orden de la matriz.  N >= 0.
!
>

V

L 
!>          VL es DOUBLE PRECISION
!>          Límite inferior del intervalo que contiene los autovalores
!>          deseados. VL < VU. Necesario para calcular los huecos en el extremo
!>          izquierdo o derecho de los autovalores extremales en el RANGO deseado.
!
>

V

U 
!>          VU es DOUBLE PRECISION
!>          Límite superior del intervalo que contiene los autovalores
!>          deseados. VL < VU.
!>          Nota: VU actualmente no es usado por esta implementación de DLARRV, VU
!>          se pasa a DLARRV porque podría usarse para calcular huecos en el extremo
!>          derecho de los autovalores extremales. Sin embargo, con poca precisión
!>          inicial en LAMBDA y VU, la fórmula puede llevar a una sobreestimación
!>          del hueco derecho y por lo tanto a una 'convergencia' RQI prematura.
!>          Actualmente esto se previene forzando un pequeño hueco derecho. Y así
!>          resulta que VU actualmente no es usado por esta implementación de DLARRV.
!

D 
!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Al entrar, los N elementos diagonales de la matriz diagonal D.
!>          Al salir, D puede ser sobrescrito.

L 
!>          L es un array DOUBLE PRECISION, dimensión (N)
!>          Al entrar, los (N-1) elementos subdiagonales de la matriz
!>          bidiagonal unitaria L están en los elementos 1 a N-1 de L
!>          (si la matriz no está dividida). Al final de cada bloque

!>          Al salir, L es sobrescrito.

!>          hasta ISPLIT( 2 ), etc.
!
>

M 
!>          M es INTEGER
!>          El número total de autovalores de entrada.  0 <= M <= N.

NAME

dlarrv - This subroutine computes the eigenvectors of a symmetric tridiagonal matrix T.

SYNOPSIS

  SUBROUTINE DLARRV( N, D, E, VL, VU, IL, IU, ABSTOL, M, NS, W, Z, LDZ,
                     ISUPPZ, WORK, IWORK, INFO )
    INTEGER N
    DOUBLE PRECISION D( * ), E( * ), VL, VU, ABSTOL, W( * )
    INTEGER IL, IU, M, NS, LDZ, ISUPPZ( * ), IWORK( * )
    DOUBLE PRECISION Z( LDZ, * )
    DOUBLE PRECISION WORK( * )

Function/Subroutine Documentation

N
N is INTEGER
The order of the matrix T. 1 <= N <= N.
D
D is DOUBLE PRECISION array, dimension (N)
The diagonal entries of the tridiagonal matrix T.
E
E is DOUBLE PRECISION array, dimension (N-1)
The off-diagonal entries of the tridiagonal matrix T.
VL
VL is DOUBLE PRECISION
The lower bound of the interval of interest.
VU
VU is DOUBLE PRECISION
The upper bound of the interval of interest.
IL
IL is INTEGER
The lower index for the eigenvectors of interest.
IU
IU is INTEGER
The upper index for the eigenvectors of interest.
ABSTOL
ABSTOL is DOUBLE PRECISION
The threshold below which diffrences in eigenvalues are considered negligible. For example, if ABSTOL is machine epsilon times the average magnitude of the eigenvalues, then the algorithm is roughly working with the full accuracy of the machine.
M
M is INTEGER
The number of eigenvalues (and corresponding eigenvectors) found to be in the interval (VL, VU).
NS
NS is INTEGER
The number of \"small gaps\" found between the eigenvalues which may be used to split T into blocks.
W
W is DOUBLE PRECISION array, dimension (N)
The computed eigenvalues in ascending order.
Z
Z is DOUBLE PRECISION array, dimension (LDZ, N)
The computed eigenvectors. The K-th column Z(1:N, K) is the eigenvector associated with the K-th eigenvalue W(K).
LDZ
LDZ is INTEGER
The leading dimension of the array Z. LDZ >= 1, and if JOBZ = 'V', LDZ >= max(1,N).
ISUPPZ
ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
The support of the eigenvectors in Z, i.e., the indices indicating the nonzero elements in Z. The I-th eigenvector is nonzero only in elements ISUPPZ( 2*I-1 ) through ISUPPZ( 2*I ).
WORK
WORK is DOUBLE PRECISION array, dimension (12*N)
IWORK
IWORK is INTEGER array, dimension (7*N)
INFO
INFO is INTEGER
= 0: successful exit
> 0: A problem occurred in DLARRV.
< 0: One of the called subroutines signaled an internal problem. Needs inspection of the corresponding parameter IINFO for further information.
=-1: Problem in DLARRB when refining a child's eigenvalues.
=-2: Problem in DLARRF when computing the RRR of a child. When a child is inside a tight cluster, it can be difficult to find an RRR. A partial remedy from the user's point of view is to make the parameter MINRGP smaller and recompile. However, as the orthogonality of the computed vectors is proportional to 1/MINRGP, the user should be aware that he might be trading in precision when he decreases MINRGP.
=-3: Problem in DLARRB when refining a single eigenvalue after the Rayleigh correction was rejected.
= 5: The Rayleigh Quotient Iteration failed to converge to full accuracy in MAXITR steps.
