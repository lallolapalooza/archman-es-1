subrutina dlasd1 (nl, nr, sqre, d, alpha, beta, u, ldu, vt, ldvt, idxq, iwork, work, info)
DLASD1 calcula la SVD de una matriz bidiagonal superior B de el tamaño especificado. Usado por sbdsdc.

subrutina dlasd1 (integer nl, integer nr, integer sqre, double precision, dimension( * ) d, double precision alpha, double precision beta, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, integer, dimension( * ) idxq, integer, dimension( * ) iwork, double precision, dimension( * ) work, integer

info)

DLASD1 calcula la SVD de una matriz bidiagonal superior B de el tamaño especificado. Usado por

sbdsdc.

Propósito

: 
!>
!> DLASD1 calcula la SVD de una matriz bidiagonal superior N-por-M B,
!> donde N = NL + NR + 1 y M = N + SQRE. DLASD1 es llamado desde DLASD0.
!>
!> Una subrutina relacionada DLASD7 maneja el caso en el que se desean los valores
!> singulares (y los vectores singulares en forma factorizada).
!>
!> DLASD1 calcula la SVD de la siguiente manera:
!>
!>               ( D1(in)    0    0       0 )
!>   B = U(in) * (   Z1**T   a   Z2**T    b ) * VT(in)
!>               (   0       0   D2(in)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> donde Z**T = (Z1**T a Z2**T b) = u**T VT**T, y u es un vector de dimensión M
!> con ALPHA y BETA en las entradas NL+1 y NL+2 y ceros
!> en otros lugares; y la entrada b está vacía si SQRE = 0.
!>
!> Los vectores singulares izquierdos de la matriz original se almacenan en U, y
!> la transpuesta de los vectores singulares derechos se almacenan en VT, y los
!> valores singulares están en D. El algoritmo consiste en tres etapas:
!>
!>    La primera etapa consiste en desinflar el tamaño del problema
!>    cuando hay múltiples valores singulares o cuando hay ceros en
!>    el vector Z. Por cada tal ocurrencia, la dimensión del
!>    problema de la ecuación secular se reduce en uno. Esta etapa es
!>    realizada por la rutina DLASD2.
!>
!>    La segunda etapa consiste en calcular los valores
!>    singulares actualizados. Esto se hace encontrando las raíces cuadradas de las
!>    raíces de la ecuación secular a través de la rutina DLASD4 (como llamada
!>    por DLASD3). Esta rutina también calcula los vectores singulares de
!>    el problema actual.
!>
!>    La etapa final consiste en calcular los vectores singulares
!>    actualizados directamente usando los valores singulares actualizados. Los vectores
!>    singulares del problema actual se multiplican con los vectores
!>    singulares del problema general.
!
>

Parámetro

s
NL 
!>          NL es INTEGER
!>         La dimensión de filas del bloque superior. NL >= 1.
!
>

N

R 
!>          NR es INTEGER
!>         La dimensión de filas del bloque inferior. NR >= 1.
!
>

SQR

E 
!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR-por-NR.
!>         = 1: el bloque inferior es una matriz rectangular NR-por-(NR+1).
!>
!>         La matriz bidiagonal tiene dimensión de filas N = NL + NR + 1,
!>         y dimensión de columnas M = N + SQRE.
!
>

D 
!>          D es un array DOUBLE PRECISION,
!>                        dimensión (N = NL+NR+1).
!>         En la entrada D(1:NL,1:NL) contiene los valores singulares del
!>         bloque superior; y D(NL+2:N) contiene los valores singulares del
!>         bloque inferior. En la salida D(1:N) contiene los valores singulares
!>         de la matriz modificada.
!
>

ALPH

A 
!>          ALPHA es DOUBLE PRECISION
!>         Contiene el elemento diagonal asociado con la fila añadida.
!
>

BET

A 
!>          BETA es DOUBLE PRECISION
!>         Contiene el elemento fuera de la diagonal asociado con la fila
!>         añadida.
!
>

U 
!>          U es un array DOUBLE PRECISION, dimensión(LDU,N)
!>         En la entrada U(1:NL, 1:NL) contiene los vectores singulares izquierdos
!>         del bloque superior; U(NL+2:N, NL+2:N) contiene los vectores singulares
!>         izquierdos del bloque inferior. En la salida U contiene los vectores
!>         singulares izquierdos de la matriz bidiagonal.
!
>

LD

U 
!>          LDU es INTEGER
!>         La dimensión principal del array U. LDU >= max( 1, N ).
!
>

V

T 
!>          VT es un array DOUBLE PRECISION, dimensión(LDVT,M)
!>         donde M = N + SQRE.
!>         En la entrada VT(1:NL+1, 1:NL+1)**T contiene los vectores
!>         singulares derechos del bloque superior; VT(NL+2:M, NL+2:M)**T contiene
!>         los vectores singulares derechos del bloque inferior. En la salida
!>         VT**T contiene los vectores singulares derechos de la
!>         matriz bidiagonal.
!
>

LDV

T 
!>          LDVT es INTEGER
!>         La dimensión principal del array VT. LDVT >= max( 1, M ).
!
>

IDX

Q 
!>          IDXQ es un array INTEGER, dimensión(N)
!>         Esto contiene la permutación que reintegrará el
!>         subproblema recién resuelto de vuelta al orden ordenado, es decir
!>         D( IDXQ( I = 1, N ) ) estará en orden ascendente.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión( 4 * N )
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión( 3*M**2 + 2*M )
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un valor singular no convergió
!
>
