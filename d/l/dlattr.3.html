subrutina dlattr (entero imat, carácter uplo, carácter trans, carácter diag, entero, dimensión( 4 ) iseed, entero n, doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( * ) b, doble precisión, dimensión( * ) work, entero info)

DLATTR

Propósito:

!>
!> DLATTR genera una matriz de prueba triangular.
!> IMAT y UPLO especifican de forma única las propiedades de la matriz de prueba,
!> que se devuelve en la matriz A.
!>

Parámetros

IMAT 
!>          IMAT es ENTERO
!>          Una clave entera que describe qué matriz generar para esta
!>          ruta.
!>

UPLO

!>          UPLO es CARACTER*1
!>          Especifica si la matriz A será triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CARACTER*1
!>          Especifica si se utilizará la matriz o su transpuesta.
!>          = 'N':  Sin transponer
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada (= Transpuesta)
!>

DIAG

!>          DIAG es CARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

ISEED

!>          ISEED es matriz ENTERA, dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado en
!>          DLATMS). Modificado al salir.
!>

N

!>          N es ENTERO
!>          El orden de la matriz a generar.
!>

A

!>          A es matriz DOBLE PRECISIÓN, dimensión (LDA,N)
!>          La matriz triangular A. Si UPLO = 'U', la parte triangular superior
!>          de la matriz de n por n de la matriz A contiene la matriz triangular
!>          superior, y la parte triangular estrictamente inferior de A no se
!>          referencia. Si UPLO = 'L', la parte triangular inferior de la matriz
!>          de n por n de la matriz A contiene la matriz triangular inferior, y
!>          la parte triangular estrictamente superior de A no se referencia. Si
!>          DIAG = 'U', los elementos diagonales de A se establecen de forma que
!>          A(k,k) = k para 1 <= k <= n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A. LDA >= max(1,N).
!>

B

!>          B es matriz DOBLE PRECISIÓN, dimensión (N)
!>          El vector del lado derecho, si IMAT > 10.
!>

WORK

!>          WORK es matriz DOBLE PRECISIÓN, dimensión (3*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>
