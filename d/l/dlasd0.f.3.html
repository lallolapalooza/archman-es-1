subroutine dlasd0 (integer n, integer sqre, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, integer smlsiz, integer, dimension( * ) iwork, double precision, dimension( * ) work, integer info)

DLASD0 calcula los valores singulares de una matriz real superior bidiagonal n-por-m B con diagonal D y fuera de diagonal E. Usado por sbdsdc.

Propósito:

!>
!> Usando un enfoque de divide y vencerás, DLASD0 calcula la
!> descomposición en valores singulares (SVD) de una matriz B real superior
!> bidiagonal N por M con diagonal D y fuera de diagonal E, donde M = N + SQRE.
!> El algoritmo calcula matrices ortogonales U y VT tales que
!> B = U * S * VT. Los valores singulares S se sobrescriben en D.
!>
!> Una subrutina relacionada, DLASDA, calcula solo los valores singulares,
!> y opcionalmente, los vectores singulares en forma compacta.
!>

Parámetros

N 
!>          N es INTEGER
!>         En la entrada, la dimensión de fila de la matriz superior bidiagonal.
!>         Esta es también la dimensión del array diagonal principal D.
!>

SQRE

!>          SQRE es INTEGER
!>         Especifica la dimensión de columna de la matriz bidiagonal.
!>         = 0: La matriz bidiagonal tiene dimensión de columna M = N;
!>         = 1: La matriz bidiagonal tiene dimensión de columna M = N+1;
!>

D

!>          D es un array DOUBLE PRECISION, dimension (N)
!>         En la entrada, D contiene la diagonal principal de la matriz
!>         bidiagonal.
!>         En la salida, si INFO = 0, D contiene sus valores singulares.
!>

E

!>          E es un array DOUBLE PRECISION, dimension (M-1)
!>         Contiene las entradas subdiagonales de la matriz bidiagonal.
!>         En la salida, E ha sido destruido.
!>

U

!>          U es un array DOUBLE PRECISION, dimension (LDU, N)
!>         En la salida, U contiene los vectores singulares izquierdos,
!>          si U se pasó como (N, N) Identidad.
!>

LDU

!>          LDU es INTEGER
!>         En la entrada, dimensión principal de U.
!>

VT

!>          VT es un array DOUBLE PRECISION, dimension (LDVT, M)
!>         En la salida, VT**T contiene los vectores singulares derechos,
!>          si VT se pasó como (M, M) Identidad.
!>

LDVT

!>          LDVT es INTEGER
!>         En la entrada, dimensión principal de VT.
!>

SMLSIZ

!>          SMLSIZ es INTEGER
!>         En la entrada, tamaño máximo de los subproblemas en la
!>         parte inferior del árbol de computación.
!>

IWORK

!>          IWORK es un array INTEGER, dimension (8*N)
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimension (3*M**2+2*M)
!>

INFO

!>          INFO es INTEGER
!>          = 0: Salida exitosa.
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: Si INFO = 1, un valor singular no convergió.
!>
