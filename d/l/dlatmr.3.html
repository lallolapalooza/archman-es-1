DLATMR

Propósito:

!>
!>    DLATMR genera matrices aleatorias de varios tipos para probar
!>    programas LAPACK.
!>
!>    DLATMR opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Generar una matriz A con entradas aleatorias de distribución DIST
!>         que es simétrica si SYM='S', y no simétrica
!>         si SYM='N'.
!>
!>      Establecer la diagonal a D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>      Calificar la matriz, si se desea, desde la izquierda y/o derecha
!>         según lo especificado por GRADE. Las entradas DL, MODEL, CONDL, DR,
!!>         MODER y CONDR también determinan la calificación como se describe
!>         a continuación.
!>
!>      Permutar, si se desea, las filas y/o columnas según lo especificado por
!>         PIVTNG y IPIVOT.
!>
!>      Establecer entradas aleatorias a cero, si se desea, para obtener una
!>         matriz dispersa aleatoria según lo especificado por SPARSE.
!>
!>      Convertir A en una matriz de banda, si se desea, poniendo a cero la matriz
!>         fuera de una banda de ancho inferior KL y ancho superior KU.
!>
!>      Escalar A, si se desea, para tener una entrada máxima ANORM.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetado
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior por columnas (si es simétrica o
!>             triangular superior cuadrada)
!>         almacenar la mitad inferior por columnas (si es simétrica o
!>             triangular inferior cuadrada)
!>             igual que la mitad superior por filas si es simétrica
!>         almacenar el triángulo inferior en formato de banda (si es simétrica)
!>         almacenar el triángulo superior en formato de banda (si es simétrica)
!>         almacenar la matriz completa en formato de banda
!>
!>    Nota: Si dos llamadas a DLATMR difieren solo en el parámetro PACK,
!>          generarán matrices matemáticamente equivalentes.
!>
!>          Si dos llamadas a DLATMR tienen ancho de banda completo (KL = M-1
!>          y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>          entonces las matrices generadas diferirán solo
!>          en el orden de las filas y/o columnas, y de lo contrario
!>          contendrán los mismos datos. Esta consistencia no puede y
!>          no se mantiene con un ancho de banda inferior al completo.
!>

Parámetros

M 
!>          M es ENTERO
!>           Número de filas de A. No modificado.
!>

N

!>          N es ENTERO
!>           Número de columnas de A. No modificado.
!>

DIST

!>          DIST es CARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar una matriz aleatoria.
!>           'U' => UNIFORME( 0, 1 )  ('U' para uniforme)
!>           'S' => UNIFORME( -1, 1 ) ('S' para simétrica)
!>           'N' => NORMAL( 0, 1 )   ('N' para normal)
!>           No modificado.
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión (4)
!>           En la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debe producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se cambian al salir, y pueden usarse en la siguiente
!>           llamada a DLATMR para continuar la misma secuencia de números aleatorios.
!>           Cambiado al salir.
!>

SYM

!>          SYM es CARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica.
!>           Si SYM='N', la matriz generada es no simétrica.
!>           No modificado.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (min(M,N))
!>           En la entrada, este array especifica las entradas diagonales
!>           de la diagonal de A. D puede ser especificado
!>           en la entrada, o establecido según MODE y COND como se describe
!>           a continuación. Puede ser cambiado al salir si MODE es distinto de cero.
!>

MODE

!>          MODE es ENTERO
!>           En la entrada describe cómo se utilizará D:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    están distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           No modificado.
!>

COND

!>          COND es DOBLE PRECISIÓN
!>           En la entrada, se utiliza como se describe en MODE arriba.
!>           Si se utiliza, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es DOBLE PRECISIÓN
!>           Si MODE no es -6, 0 ni 6, la diagonal se escala por
!>           DMAX / max(abs(D(i))), de modo que la entrada máxima absoluta
!>           de la diagonal sea abs(DMAX). Si DMAX es negativo (o cero),
!>           la diagonal se escalará por un número negativo (o cero).
!>

RSIGN

!>          RSIGN es CARACTER*1
!>           Si MODE no es -6, 0 ni 6, especifica el signo de la diagonal
!>           de la siguiente manera:
!>           'T' => las entradas diagonales se multiplican por 1 o -1
!>                  con probabilidad 0.5
!>           'F' => diagonal sin cambios
!>           No modificado.
!>

GRADE

!>          GRADE es CARACTER*1
!>           Especifica la calificación de la matriz de la siguiente manera:
!>           'N'  => sin calificación
!>           'L'  => la matriz se premultiplica por diag( DL )
!>                   (solo si la matriz no es simétrica)
!>           'R'  => la matriz se postmultiplica por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'B'  => la matriz se premultiplica por diag( DL ) y
!>
multiplicada por la derecha por diag( DR ) !> (solo si la matriz no es simétrica) !> 'S' o 'H' => matriz multiplicada por la izquierda por diag( DL ) y !> por la derecha por diag( DL ) !> ('S' para simétrica, o 'H' para hermítica) !> 'E' => matriz multiplicada por la izquierda por diag( DL ) y !> por la derecha por inv( diag( DL ) ) !> ( 'E' para invariancia de valores propios) !> (solo si la matriz no es simétrica) !> Nota: si GRADE='E', entonces M debe ser igual a N. !> No modificado. !>

D

L 
!>          DL es un arreglo DOUBLE PRECISION, dimensión (M)
!>           Si MODEL=0, entonces en la entrada este arreglo especifica las entradas
!>           diagonales de una matriz diagonal utilizada como se describe bajo GRADE
!>           arriba. Si MODEL no es cero, entonces DL se establecerá de acuerdo
!>           con MODEL y CONDL, de manera análoga a la forma en que D se establece de acuerdo
!>           con MODE y COND (excepto que no hay parámetro DMAX para DL).
!>           Si GRADE='E', entonces DL no puede tener entradas cero.
!>           No se referencia si GRADE = 'N' o 'R'. Se modifica en la salida.
!
>

MODE

L 
!>          MODEL es INTEGER
!>           Esto especifica cómo debe calcularse el arreglo diagonal DL,
!>           igual que MODE especifica cómo debe calcularse D.
!>           No modificado.
!
>

COND

L 
!>          CONDL es DOUBLE PRECISION
!>           Cuando MODEL no es cero, esto especifica el número de condición
!>           del DL calculado.  No modificado.
!
>

D

R 
!>          DR es un arreglo DOUBLE PRECISION, dimensión (N)
!>           Si MODER=0, entonces en la entrada este arreglo especifica las entradas
!>           diagonales de una matriz diagonal utilizada como se describe bajo GRADE
!>           arriba. Si MODER no es cero, entonces DR se establecerá de acuerdo
!>           con MODER y CONDR, de manera análoga a la forma en que D se establece de acuerdo
!>           con MODE y COND (excepto que no hay parámetro DMAX para DR).
!>           No se referencia si GRADE = 'N', 'L', 'H', 'S' o 'E'.
!>           Se modifica en la salida.
!
>

MODE

R 
!>          MODER es INTEGER
!>           Esto especifica cómo debe calcularse el arreglo diagonal DR,
!>           igual que MODE especifica cómo debe calcularse D.
!>           No modificado.
!
>

COND

R 
!>          CONDR es DOUBLE PRECISION
!>           Cuando MODER no es cero, esto especifica el número de condición
!>           del DR calculado.  No modificado.
!
>

PIVTN

G 
!>          PIVTNG es CHARACTER*1
!>           En la entrada especifica las permutaciones de pivoteo de la siguiente manera:
!>           'N' o ' ' => ninguna.
!>           'L' => pivoteo izquierdo o por filas (la matriz debe ser no simétrica).
!>           'R' => pivoteo derecho o por columnas (la matriz debe ser
!>                  no simétrica).
!>           'B' o 'F' => ambos o pivoteo completo, es decir, en ambos lados.
!>                         En este caso, M debe ser igual a N
!>
!>           Si dos llamadas a DLATMR ambas tienen ancho de banda completo (KL = M-1
!>           y KU = N-1), y solo difieren en los parámetros PIVTNG y PACK,
!>           entonces las matrices generadas diferirán solo en el orden de las filas
!>           y/o columnas, y de lo contrario contendrán los mismos datos. Esta consistencia
!>           no puede mantenerse con menos de ancho de banda completo.
!
>

IPIVO

T 
!>          IPIVOT es un arreglo INTEGER, dimensión (N o M)
!>           Este arreglo especifica la permutación utilizada.  Después de
!>           que se genera la matriz básica, las filas, columnas o ambas
!>           se permutan.   Si, por ejemplo, se selecciona pivoteo por filas, DLATMR
!>           comienza con la *última* fila e intercambia la M-ésima fila con la
!>           IPIVOT(M)-ésima fila, luego pasa a la penúltima fila,
!>           intercambiando la (M-1)-ésima fila con la IPIVOT(M-1)-ésima fila,
!>           y así sucesivamente.  En términos de , la permutación es
!>           (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
!>           donde el ciclo más a la derecha se aplica primero.  Este es el
!>           *inverso* del efecto del pivoteo en LINPACK.  La idea
!>           es que factorizar (con pivoteo) una matriz identidad
!>           que ha sido invertida-pivoteada de esta manera debería
!>           resultar en un vector de pivotes idéntico a IPIVOT.
!>           No se referencia si PIVTNG = 'N'. No modificado.
!
>

K

L 
!>          KL es INTEGER
!>           En la entrada especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica Hessenberg
!>           superior, y KL al menos M-1 implica que la matriz no es
!>           banda. Debe ser igual a KU si la matriz es simétrica.
!>           No modificado.
!
>

K

U 
!>          KU es INTEGER
!>           En la entrada especifica el ancho de banda superior de la matriz. Por
!>           ejemplo, KU=0 implica triangular inferior, KU=1 implica Hessenberg
!>           inferior, y KU al menos N-1 implica que la matriz no es
!>           banda. Debe ser igual a KL si la matriz es simétrica.
!>           No modificado.
!
>

SPARS

E 
!>          SPARSE es DOUBLE PRECISION
!>           En la entrada especifica la dispersión de la matriz si se va a generar una
!>           matriz dispersa. SPARSE debe estar entre 0 y 1. Para generar una matriz
!>           dispersa, para cada entrada de la matriz se genera un número aleatorio uniforme
!>           ( 0, 1 ) x y se compara con SPARSE; si x es mayor la entrada de la matriz
!>           no cambia y si x es menor la entrada se establece
!>           a cero. Así que en promedio una fracción SPARSE de las
!>           entradas se establecerán a cero.
!>           No modificado.
!
>

ANOR

M 
!>          ANORM es DOUBLE PRECISION
!>           En la entrada especifica la entrada máxima de la matriz de salida
!>           (la matriz de salida se multiplicará por una constante de modo que
!>           su entrada absoluta más grande sea igual a ANORM)
!>           si ANORM es no negativo. Si ANORM es negativo no se hace
!>           ningún escalado. No modificado.
!
>

PAC

K 
!>          PACK es CHARACTER*1
!>           En la entrada especifica el empaquetado de la matriz de la siguiente manera:
!>           'N' => sin empaquetado
!>           'U' => poner a cero todas las entradas subdiagonales (si es simétrica)
!>           'L' => poner a cero todas las entradas superdiagonales (si es simétrica)
!>           'C' => almacenar el triángulo superior por columnas
!>                  (solo si la matriz es simétrica o triangular superior cuadrada)
!>           'R' => almacenar el triángulo inferior por columnas
!>                  (solo si la matriz es simétrica o triangular inferior cuadrada)
!>                  (igual que la mitad superior por filas si es simétrica)
!>           'B' => almacenar el triángulo inferior en esquema de almacenamiento en banda
!>                  (solo si la matriz es simétrica)
!>           'Q' => almacenar el triángulo superior en esquema de almacenamiento en banda
!>                  (solo si la matriz es simétrica)
!>           'Z' => almacenar la matriz completa en esquema de almacenamiento en banda
!>                      (el pivoteo puede proporcionarse usando esta
!>                      opción para almacenar A en las filas finales del
!>                      almacenamiento asignado)
!>
!>           Usando estas opciones, se pueden obtener los diversos esquemas de
!>           almacenamiento empaquetado y en banda de LAPACK:
!>           GB               - usar 'Z'
!>           PB, SB o TB     - usar 'B' o 'Q'
!>           PP, SP o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a DLATMR difieren solo en el parámetro PACK,
!>           generarán matrices matemáticamente equivalentes.
!>           No modificado.
!
>

A 
!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA,N)
!>           En la salida A es la matriz de prueba deseada. Solo aquellas
!>           entradas de A que son significativas en la salida
!>           serán referenciadas (incluso si A está en formato de almacenamiento
!>           empaquetado o en banda). Las 'esquinas no ocupadas' de A en
!>           formato banda se pondrán a cero.
!
>

LD

A 
!>          LDA es INTEGER
!>           en la entrada LDA especifica la primera dimensión de A como
!>           se declara en el programa que llama.
!>           Si PACK='N', 'U' o 'L', LDA debe ser al menos max ( 1, M ).
!>           Si PACK='C' o 'R', LDA debe ser al menos 1.
!>           Si PACK='B', o 'Q', LDA debe ser MIN ( KU+1, N )
!>           Si PACK='Z', LDA debe ser al menos KUU+KLL+1, donde
!>           KUU = MIN ( KU, N-1 ) y KLL = MIN ( KL, M-1 )
!>           No modificado.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión ( N o M)
!>           Espacio de trabajo. No se referencia si PIVTNG = 'N'. Se modifica en la salida.
!
>

INF

O 
!>          INFO es INTEGER
!>           Parámetro de error en la salida:
!>             0 => retorno normal
!>            -1 => M negativo o no igual a N y SYM='S' o 'H'
!>            -2 => N negativo
!>            -3 => DIST cadena ilegal
!>            -5 => SYM cadena ilegal
!>            -7 => MODE fuera del rango -6 a 6
!>            -8 => COND menor que 1.0, y MODE no es -6, 0 ni 6
!>           -10 => MODE no es -6, 0 ni 6 y RSIGN cadena ilegal
!>           -11 => GRADE cadena ilegal, o GRADE='E' y
!>                  M no igual a N, o GRADE='L', 'R', 'B' o 'E' y
!>                  SYM = 'S' o 'H'
!>           -12 => GRADE = 'E' y DL contiene cero
!>           -13 => MODEL fuera del rango -6 a 6 y GRADE= 'L', 'B', 'H',
!>                  'S' o 'E'
!>           -14 => CONDL menor que 1.0, GRADE='L', 'B', 'H', 'S' o 'E',
!>                  y MODEL no es -6, 0 ni 6
!>           -16 => MODER fuera del rango -6 a 6 y GRADE= 'R' o 'B'
!>           -17 => CONDR menor que 1.0, GRADE='R' o 'B', y
!>                  MODER no es -6, 0 ni 6
!>           -18 => PIVTNG cadena ilegal, o PIVTNG='B' o 'F' y
!>                  M no igual a N, o PIVTNG='L' o 'R' y SYM='S'
!>                  o 'H'
!>           -19 => IPIVOT contiene un número fuera de rango y
!>                  PIVTNG no igual a 'N'
!>           -20 => KL negativo
!>           -21 => KU negativo, o SYM='S' o 'H' y KU no igual a KL
!>           -22 => SPARSE fuera del rango 0. a 1.
!>           -24 => PACK cadena ilegal, o PACK='U', 'L', 'B' o 'Q'
!>                  y SYM='N', o PACK='C' y SYM='N' y ya sea KL
!>                  no igual a 0 o N no igual a M, o PACK='R' y
!>                  SYM='N', y ya sea KU no igual a 0 o N no igual
!>                  a M
!>           -26 => LDA demasiado pequeño
!>             1 => Retorno de error de DLATM1 (calculando D)
!>             2 => No se puede escalar la diagonal a DMAX (la entrada máxima es 0)
!>             3 => Retorno de error de DLATM1 (calculando DL)
!>             4 => Retorno de error de DLATM1 (calculando DR)
!>             5 => ANORM es positivo, pero la matriz construida antes de
!>                  intentar escalarla para tener norma ANORM, es cero
!>
