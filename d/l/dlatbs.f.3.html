subroutine dlatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

DLATBS resuelve un sistema triangular de ecuaciones de banda.

Propósito:

!>
!> DLATBS resuelve uno de los sistemas triangulares
!>
!>    A *x = s*b  o  A**T*x = s*b
!>
!> con escalado para prevenir desbordamientos, donde A es una matriz
!> de banda triangular superior o inferior. Aquí A**T denota la transpuesta
!> de A, x y b son vectores de n elementos, y s es un factor de escalado,
!> usualmente menor o igual que 1, elegido de modo que los componentes de x
!> sean menores que el umbral de desbordamiento. Si el problema no escalado
!> no causa desbordamiento, se llama a la rutina BLAS de nivel 2 DTBSV.
!> Si la matriz A es singular (A(j,j) = 0 para algún j), entonces s se
!> establece a 0 y se devuelve una solución no trivial de A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resuelve A * x = s*b  (Sin transpuesta)
!>          = 'T':  Resuelve A**T* x = s*b  (Transpuesta)
!>          = 'C':  Resuelve A**T* x = s*b  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de las columnas en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. A la salida, las
!>                  normas serán calculadas y almacenadas en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de subdiagonales o superdiagonales en la
!>          matriz triangular A.  KD >= 0.
!>

AB

!>          AB es un array DOUBLE PRECISION, de dimensión (LDAB,N)
!>          La matriz de banda triangular superior o inferior A, almacenada
!>          en las primeras KD+1 filas del array. La j-ésima columna de A
!>          se almacena en la j-ésima columna del array AB como sigue:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

X

!>          X es un array DOUBLE PRECISION, de dimensión (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          A la salida, X se sobrescribe con el vector solución x.
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          El factor de escalado s para el sistema triangular
!>             A * x = s*b  o  A**T* x = s*b.
!>          Si SCALE = 0, la matriz A es singular o está mal escalada, y
!>          el vector x es una solución exacta o aproximada de A*x = 0.
!>

CNORM

!>          CNORM es un array DOUBLE PRECISION, de dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte fuera de la diagonal de la j-ésima
!>          columna de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual
!>          a la norma infinito, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte fuera de la diagonal de la j-ésima
!>          columna de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>

Detalles adicionales:

!>
!> Se calcula un límite aproximado para x; si este es menor que el
!> desbordamiento, se llama a DTBSV, de lo contrario, se utiliza un código
!> específico que verifica posibles desbordamientos o divisiones por cero
!> en cada operación.
!>
!> Se utiliza un esquema por columnas para resolver A*x = b. El algoritmo
!> básico si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       para j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Se definen límites para los componentes de x después de j iteraciones
!> del bucle:
!>     M(j) = límite para x[1:j]
!>     G(j) = límite para x[j+1:n]
!> Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!> Entonces para la iteración j+1 tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> donde CNORM(j+1) es mayor o igual a la norma infinito de la
!> columna j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Dado que |x(j)| <= M(j), usamos la rutina BLAS de nivel 2 DTBSV si el
!> recíproco del M(j) máximo, j=1,..,n, es mayor que
!> max(underflow, 1/overflow).
!>
!> El límite para x(j) también se usa para determinar cuándo un paso en
!> el método por columnas puede realizarse sin temor a desbordamiento. Si
!> el límite calculado es mayor que una constante grande, x se escala para
!> prevenir desbordamiento, pero si el límite se desborda, x se establece
!> a 0, x(j) a 1, y scale a 0, y se encuentra una solución no trivial de
!> A*x = 0.
!>
!> De manera similar, se utiliza un esquema por filas para resolver A**T*x = b.
!> El algoritmo básico para A triangular superior es
!>
!>       para j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Calculamos simultáneamente dos límites
!>       G(j) = límite para ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>       M(j) = límite para x(i), 1<=i<=j
!>
!> Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y añadimos
!> la restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!> Entonces el límite para x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> y podemos llamar a DTBSV de forma segura si 1/M(n) y 1/G(n) son ambos
!> mayores que max(underflow, 1/overflow).
!>

NOMBRE

DLATBS - DLATBS determina la forma de la matriz de coeficientes y la información de las diagonales del problema de sistemas de ecuaciones lineales de banda inferior de matriz triangular.

SINOPSIS

SUBROUTINE DLATBS(
                UPLO, TRANS, DIAG, NORMDD, M, NB, A, LDA, LDABS, K,
                D, Y, SD, WORK, INFO )

CHARACTER(1)  UPLO, TRANS, DIAG, NORMDD
INTEGER       M, NB, LDA, LDABS, K( * ), INFO
REAL(8)       A( LDA, * ), D( * ), Y( * ), SD( * ), WORK( * )

Documentación de Función/Subrutina

Esta subrutina está destinada a ser llamada por el usuario para determinar la forma de la matriz de coeficientes y la información de las diagonales de un problema de sistemas de ecuaciones lineales de banda inferior de matriz triangular.

UPLO: especifica si la matriz es triangular superior o inferior.

  • 'U' o 'u': La matriz es triangular superior.
  • 'L' o 'l': La matriz es triangular inferior.

TRANS: especifica la operación de transposición a realizar.

  • 'N' o 'n': Ninguna transposición.
  • 'T' o 't': Transpuesta.
  • 'C' o 'c': Transpuesta conjugada.

DIAG: especifica si la matriz es unitaria.

  • 'U' o 'u': La matriz es unitaria (la diagonal se considera uno).
  • 'N' o 'n': La matriz no es unitaria.

NORMDD: especifica si la matriz está normalizada por columnas.

  • 'N' o 'n': La matriz no está normalizada por columnas.
  • 'D' o 'd': La matriz está normalizada por columnas.

M: número de filas de la matriz de coeficientes.

NB: número de subdiagonales o superdiagonales de la matriz de banda.

A: matriz de coeficientes.

LDA: longitud de la línea de la matriz A.

LDABS: longitud de la línea de la matriz ABS.

K: información de las diagonales.

D: vector de diagonales.

Y: vector del lado derecho.

SD: vector de diagonales escaladas.

WORK: array de trabajo.

INFO: valor de retorno.

  • 0: éxito.
  • -i: si el i-ésimo argumento no es válido.
