subroutine dlafts (character*3 type, integer m, integer n, integer imat, integer ntests, double precision, dimension( * ) result, integer, dimension( 4 ) iseed, double precision thresh, integer iounit, integer ie)

DLAFTS

Propósito:

!>
!>    DLAFTS prueba el vector de resultados contra el valor umbral para
!>    ver qué pruebas para este tipo de matriz no pasaron el umbral.
!>    La salida va al archivo dado por la unidad IOUNIT.
!> 
!>  TYPE   - CHARACTER*3
!>           Al entrar, TYPE especifica el tipo de matriz a utilizar en los
!>           mensajes impresos.
!>           No modificado.
!>
!>  N      - INTEGER
!>           Al entrar, N especifica el orden de la matriz de prueba.
!>           No modificado.
!>
!>  IMAT   - INTEGER
!>           Al entrar, IMAT especifica el tipo de la matriz de prueba.
!>           Una lista de los diferentes tipos es impresa por DLAHD2
!>           en el archivo de salida si una prueba no pasa el umbral.
!>           No modificado.
!>
!>  NTESTS - INTEGER
!>           Al entrar, NTESTS es el número de pruebas realizadas en las
!>           subrutinas del camino dado por TYPE.
!>           No modificado.
!>
!>  RESULT - DOUBLE PRECISION               array de dimension( NTESTS )
!>           Al entrar, RESULT contiene las relaciones de prueba de las pruebas
!>           realizadas en el programa de llamada.
!>           No modificado.
!>
!>  ISEED  - INTEGER            array de dimension( 4 )
!>           Contiene la semilla aleatoria que generó la matriz utilizada
!>           para las pruebas cuyas relaciones están en RESULT.
!>           No modificado.
!>
!>  THRESH - DOUBLE PRECISION
!>           Al entrar, THRESH especifica el umbral aceptable de las
!>           relaciones de prueba. Si RESULT( K ) > THRESH, entonces la K-ésima prueba
!>           no pasó el umbral y se imprimirá un mensaje.
!>           No modificado.
!>
!>  IOUNIT - INTEGER
!>           Al entrar, IOUNIT especifica el número de unidad del archivo
!>           al que se imprimen los mensajes.
!>           No modificado.
!>
!>  IE     - INTEGER
!>           Al entrar, IE contiene el número de pruebas que han
!>           fallado en pasar el umbral hasta ahora.
!>           Actualizado a la salida si alguna de las relaciones en RESULT también falla.
!>
