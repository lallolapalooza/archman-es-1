subrutina dlaqz2 (logical, intent(in) ilq, logical, intent(in) ilz, integer, intent(in) k, integer, intent(in) istartm, integer, intent(in) istopm, integer, intent(in) ihi, double precision, dimension( lda, * ) a, integer, intent(in) lda, double precision, dimension( ldb, * ) b, integer, intent(in) ldb, integer, intent(in) nq, integer, intent(in) qstart, double precision, dimension( ldq, * ) q, integer, intent(in) ldq, integer, intent(in) nz, integer, intent(in) zstart, double precision, dimension( ldz, * ) z, integer, intent(in) ldz)

DLAQZ2

Propósito:

!>
!>      DLAQZ2 persigue un bulto de desplazamiento 2x2 en un lápiz matricial hacia abajo
!>      una sola posición
!>

Parámetros

ILQ 
!>          ILQ es LOGICAL
!>              Determina si se actualiza o no la matriz Q
!>

ILZ

!>          ILZ es LOGICAL
!>              Determina si se actualiza o no la matriz Z
!>

K

!>          K es INTEGER
!>              Índice que indica la posición del bulto.
!>              A la entrada, el bulto se encuentra en
!>              (A(k+1:k+2,k:k+1),B(k+1:k+2,k:k+1)).
!>              A la salida, el bulto se encuentra en
!>              (A(k+2:k+3,k+1:k+2),B(k+2:k+3,k+1:k+2)).
!>

ISTARTM

!>          ISTARTM es INTEGER
!>

ISTOPM

!>          ISTOPM es INTEGER
!>              Las actualizaciones a (A,B) se restringen a
!>              (istartm:k+3,k:istopm). Se asume
!>              sin comprobación que istartm <= k+1 y
!>              k+2 <= istopm
!>

IHI

!>          IHI es INTEGER
!>

A

!>          A es array DOUBLE PRECISION, dimension (LDA,N)
!>

LDA

!>          LDA es INTEGER
!>              La dimensión principal de A tal como se declara en
!>              el procedimiento que llama.
!>

B

!>          B es array DOUBLE PRECISION, dimension (LDB,N)
!>

LDB

!>          LDB es INTEGER
!>              La dimensión principal de B tal como se declara en
!>              el procedimiento que llama.
!>

NQ

!>          NQ es INTEGER
!>              El orden de la matriz Q
!>

QSTART

!>          QSTART es INTEGER
!>              Índice de inicio de la matriz Q. Las rotaciones se aplican
!>              a las columnas k+2-qStart:k+4-qStart de Q.
!>

Q

!>          Q es array DOUBLE PRECISION, dimension (LDQ,NQ)
!>

LDQ

!>          LDQ es INTEGER
!>              La dimensión principal de Q tal como se declara en
!>              el procedimiento que llama.
!>

NZ

!>          NZ es INTEGER
!>              El orden de la matriz Z
!>

ZSTART

!>          ZSTART es INTEGER
!>              Índice de inicio de la matriz Z. Las rotaciones se aplican
!>              a las columnas k+1-qStart:k+3-qStart de Z.
!>

Z

!>          Z es array DOUBLE PRECISION, dimension (LDZ,NZ)
!>

LDZ

!>          LDZ es INTEGER
!>              La dimensión principal de Q tal como se declara en
!>              el procedimiento que llama.
!>
