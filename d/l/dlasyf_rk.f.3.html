subrutina dlasyf_rk (uplo, n, nb, kb, a, lda, e, ipiv, w, ldw, info)
DLASYF_RK calcula una factorización parcial de una matriz simétrica real indefinida utilizando el método de pivote diagonal Bunch-Kaufman acotado (rook).

Documentación de Función/Subrutina

subrutina dlasyf_rk (character uplo, integer n, integer nb, integer kb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) e, integer, dimension( * ) ipiv, double precision, dimension( ldw, * ) w, integer ldw, integer info)

DLASYF_RK calcula una factorización parcial de una matriz simétrica real indefinida utilizando el método de pivote diagonal Bunch-Kaufman acotado (rook).

Propósito:

!> DLASYF_RK calcula una factorización parcial de una matriz simétrica
!> real A utilizando el método de pivote diagonal Bunch-Kaufman acotado
!> (rook). La factorización parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!>
!> DLASYF_RK es una rutina auxiliar llamada por DSYTRF_RK. Utiliza
!> código bloqueado (llamando a BLAS de Nivel 3) para actualizar la submatriz
!> A11 (si UPLO = 'U') o A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si se almacena la parte triangular superior o inferior de la
!>          matriz simétrica A:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es INTEGER
!>          El número máximo de columnas de la matriz A que deben ser
!>          factorizadas.  NB debe ser al menos 2 para permitir bloques pivote
!>          de 2 por 2.
!>

KB

!>          KB es INTEGER
!>          El número de columnas de A que fueron realmente factorizadas.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte triangular superior N por N
!>            principal de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no es
!>            referenciada.
!>
!>            Si UPLO = 'L': la parte triangular inferior N por N
!>            principal de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no es
!>            referenciada.
!>
!>          En la salida, contiene:
!>            a) SOLO los elementos diagonales de la matriz diagonal por bloques
!>               simétrica D en la diagonal de A, es decir D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el arreglo E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

E

!>          E es un arreglo DOUBLE PRECISION, dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz diagonal por bloques simétrica D
!>          con bloques diagonales de 1 por 1 o 2 por 2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal D(k) de 1 por 1, donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A como sigue. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en el que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura por bloques de
!>          la matriz diagonal por bloques simétrica D con bloques diagonales
!>          de 1 por 1 o 2 por 2 que corresponden a 1 o 2 intercambios
!>          en cada paso de la factorización.
!>
!>          Si UPLO = 'U',
!>          ( en el orden de factorización, k disminuye de N a 1 ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1 por 1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,N-KB+1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2 por 2.
!>               (NOTA: las entradas negativas en IPIV aparecen SOLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k e -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 e -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b) siempre es ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en el orden de factorización, k aumenta de 1 a N ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1 por 1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,1:KB).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2 por 2.
!>               (NOTA: las entradas negativas en IPIV aparecen SOLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k e -IPIV(k) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 e -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b) siempre es ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>

W

!>          W es un arreglo DOUBLE PRECISION, dimensión (LDW,NB)
!>

LDW

!>          LDW es INTEGER
!>          La dimensión principal del arreglo W.  LDW >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto D(k,k) es exactamente cero, y los elementos
!>               superdiagonales delumn k de U (o los elementos subdiagonales de la
!>               columna k de L ) son todos ceros. La factorización ha
!>               sido completada, pero la matriz de bloques diagonales D es
!>               exactamente singular, y ocurrirá una división por cero si
!>               se usa para resolver un sistema de ecuaciones.
!>
!>               NOTA: INFO solo almacena la primera aparición de
!>               una singularidad, cualquier aparición posterior de singularidad
!>               no se almacena en INFO aunque la factorización
!>               siempre se completa.
!>
