NOMBRE

dlb - Bibliotecario de datos de NetHack

SINOPSIS

dlb { xct } [ vfIC ] argumentos... [ archivos... ]

DESCRIPCIÓN

Dlb es una herramienta de archivado de archivos en el espíritu (y tradición) de tar para NetHack versión 3.1 y superior. Se utiliza para mantener los archivos de archivo de los cuales NetHack lee archivos de nivel especiales y otra información de solo lectura. Tenga en cuenta que al igual que tar, los especificadores de comando y opción se especifican como una cadena continua y van seguidos de cualquier argumento requerido en el mismo orden que los especificadores de opción.

Esta instalación es opcional y puede ser excluida durante la configuración de NetHack.

COMANDOS

El comando x hace que dlb extraiga el contenido del archivo en el directorio actual.

El comando c hace que dlb cree un nuevo archivo a partir de los archivos en el directorio actual.

El comando t enumera los archivos en el archivo.

OPCIONES Y ARGUMENTOS

v salida detallada

f archivo especifica el archivo. Por defecto, si no se especifica f, es LIBFILE (generalmente el archivo nhdat en el área de juego).

I lfile especifica el archivo que contiene la lista de archivos a incluir o extraer del archivo si no se enumeran archivos en la línea de comandos. Por defecto para la creación de archivos si no se enumeran archivos es LIBLISTFILE.

C dir cambia de directorio. Cambia de directorio antes de intentar leer cualquier archivo (incluyendo el archivo y el lfile).

EJEMPLOS

Crea el archivo predeterminado a partir de la lista de archivos predeterminada:
dlb c

Enumera el contenido del archivo 'foo':
dlb tf foo

VER TAMBIÉN

ERRORES

No es una buena emulación de tar; - no significa stdin ni stdout. Debería incluir una instalación de compresión opcional. No todos los archivos de solo lectura de NetHack pueden leerse desde un archivo; examinar el código fuente es la única forma de saber cuáles se pueden leer.
