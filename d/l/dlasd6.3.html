DLASD6 calcula la SVD de una matriz bidiagonal superior actualizada obtenida fusionando dos matrices más pequeñas añadiendo una fila. Utilizado por sbdsdc.

Propósito:

!>
!> DLASD6 calcula la SVD de una matriz bidiagonal superior B
!> actualizada, obtenida fusionando dos matrices más pequeñas añadiendo una fila. Esta
!> rutina se usa únicamente para el problema que requiere todos los valores
!> singulares y opcionalmente las matrices de vectores singulares en forma
!> factorizada.
!> B es una matriz N por M con N = NL + NR + 1 y M = N + SQRE.
!> Una subrutina relacionada, DLASD1, maneja el caso en el que se desean
!> todos los valores singulares y vectores singulares de la matriz bidiagonal.
!>
!> DLASD6 calcula la SVD de la siguiente manera:
!>
!>               ( D1(in)    0    0       0 )
!>   B = U(in) * (   Z1**T   a   Z2**T    b ) * VT(in)
!>               (   0       0   D2(in)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> donde Z**T = (Z1**T a Z2**T b) = u**T VT**T, y u es un vector de dimensión M
!> con ALPHA y BETA en las entradas NL+1 y NL+2 y ceros en
!> el resto; y la entrada b está vacía si SQRE = 0.
!>
!> Los valores singulares de B pueden calcularse usando D1, D2, los primeros
!> componentes de todos los vectores singulares derechos del bloque inferior, y
!> los últimos componentes de todos los vectores singulares derechos del bloque
!> superior. Estos componentes se almacenan y actualizan en VF y VL,
!> respectivamente, en DLASD6. Por lo tanto, U y VT no se referencian
!> explícitamente.
!>
!> Los valores singulares se almacenan en D. El algoritmo consta de dos
!> etapas:
!>
!>       La primera etapa consiste en reducir el tamaño del problema
!>       cuando hay valores singulares múltiples o si hay un cero
!>       en el vector Z. Para cada una de estas ocurrencias, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa se
!>       realiza mediante la rutina DLASD7.
!>
!>       La segunda etapa consiste en calcular los valores
!>       singulares actualizados. Esto se hace encontrando las raíces de la
!>       ecuación secular mediante la rutina DLASD4 (llamada por DLASD8).
!>       Esta rutina también actualiza VF y VL y calcula las distancias
!>       entre los valores singulares actualizados y los valores singulares
!>       antiguos.
!>
!> DLASD6 se llama desde DLASDA.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>         Especifica si los vectores singulares deben calcularse en
!>         forma factorizada:
!>         = 0: Calcular solo los valores singulares.
!>         = 1: Calcular también los vectores singulares en forma factorizada.
!>

NL

!>          NL es INTEGER
!>         La dimensión de filas del bloque superior.  NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de filas del bloque inferior.  NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR por NR.
!>         = 1: el bloque inferior es una matriz rectangular NR por (NR+1).
!>
!>         La matriz bidiagonal tiene dimensión de filas N = NL + NR + 1,
!>         y dimensión de columnas M = N + SQRE.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión ( NL+NR+1 ).
!>         En la entrada D(1:NL,1:NL) contiene los valores singulares del
!>         bloque superior, y D(NL+2:N) contiene los valores singulares
!>         del bloque inferior. En la salida D(1:N) contiene los valores
!>         singulares de la matriz modificada.
!>

VF

!>          VF es un array DOUBLE PRECISION, dimensión ( M )
!>         En la entrada, VF(1:NL+1) contiene los primeros componentes de todos
!>         los vectores singulares derechos del bloque superior; y VF(NL+2:M)
!>         contiene los primeros componentes de todos los vectores singulares derechos
!>         del bloque inferior. En la salida, VF contiene los primeros componentes
!>         de todos los vectores singulares derechos de la matriz bidiagonal.
!>

VL

!>          VL es un array DOUBLE PRECISION, dimensión ( M )
!>         En la entrada, VL(1:NL+1) contiene los últimos componentes de todos
!>         los vectores singulares derechos del bloque superior; y VL(NL+2:M)
!>         contiene los últimos componentes de todos los vectores singulares derechos
!>         del bloque inferior. En la salida, VL contiene los últimos componentes de
!>         todos los vectores singulares derechos de la matriz bidiagonal.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>         Contiene el elemento diagonal asociado con la fila añadida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>         Contiene el elemento fuera de la diagonal asociado con la fila
!>         añadida.
!>

IDXQ

!>          IDXQ es un array INTEGER, dimensión ( N )
!>         Contiene la permutación que reintegrará el
!>         subproblema recién resuelto al orden clasificado, es decir,
!>         D( IDXQ( I = 1, N ) ) estará en orden ascendente.
!>

PERM

!>          PERM es un array INTEGER, dimensión ( N )
!>         Las permutaciones (de la deflación y la clasificación) a aplicar
!>         a cada bloque. No se referencia si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR es INTEGER
!>         El número de rotaciones de Givens que tuvieron lugar en este
!>         subproblema. No se referencia si ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL es un array INTEGER, dimensión ( LDGCOL, 2 )
!>         Cada par de números indica un par de columnas que participan
!>         en una rotación de Givens. No se referencia si ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL es INTEGER
!>         dimensión principal de GIVCOL, debe ser al menos N.
!>

GIVNUM

!>          GIVNUM es un array DOUBLE PRECISION, dimensión ( LDGNUM, 2 )
!>         Cada número indica el valor C o S a usar en la
!>         rotación de Givens correspondiente. No se referencia si ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM es INTEGER
!>         La dimensión principal de GIVNUM y POLES, debe ser al menos N.
!>
<p class="Pp">POLOS

!>          POLOS es un arreglo DOUBLE PRECISION, dimensión ( LDGNUM, 2 )
!>         Al salir, POLOS(1,*) es un arreglo que contiene los nuevos valores
!>         singulares obtenidos de la solución de la ecuación secular, y
!>         POLOS(2,*) es un arreglo que contiene los polos en la ecuación
!>         secular. No se referencia si ICOMPQ = 0.
!>

DIFL

!>          DIFL es un arreglo DOUBLE PRECISION, dimensión ( N )
!>         Al salir, DIFL(I) es la distancia entre el I-ésimo valor singular
!>         actualizado (no deflado) y el I-ésimo valor singular antiguo
!>         (no deflado).
!>

DIFR

!>          DIFR es un arreglo DOUBLE PRECISION,
!>                   dimensión ( LDDIFR, 2 ) si ICOMPQ = 1 y
!>                   dimensión ( K ) si ICOMPQ = 0.
!>          Al salir, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) no está
!>          definido y no será referenciado.
!>
!>          Si ICOMPQ = 1, DIFR(1:K,2) es un arreglo que contiene los
!>          factores de normalización para la matriz de vectores singulares derechos.
!>
!>         Consulte DLASD8 para detalles sobre DIFL y DIFR.
!>

Z

!>          Z es un arreglo DOUBLE PRECISION, dimensión ( M )
!>         Los primeros elementos de este arreglo contienen los componentes
!>         del vector fila de actualización ajustado por deflación.
!>

K

!>          K es INTEGER
!>         Contiene la dimensión de la matriz no deflada,
!>         Este es el orden de la ecuación secular relacionada. 1 <= K <=N.
!>

C

!>          C es DOUBLE PRECISION
!>         C contiene basura si SQRE =0 y el valor C de una rotación
!>         de Givens relacionada con el espacio nulo derecho si SQRE = 1.
!>

S

!>          S es DOUBLE PRECISION
!>         S contiene basura si SQRE =0 y el valor S de una rotación
!>         de Givens relacionada con el espacio nulo derecho si SQRE = 1.
!>

WORK

!>          WORK es un arreglo DOUBLE PRECISION, dimensión ( 4 * M )
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión ( 3 * N )
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un valor singular no convergió
!>
