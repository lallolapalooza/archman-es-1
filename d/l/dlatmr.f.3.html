DLATM

R

Propósito

: 
!>
!>    DLATMR genera matrices aleatorias de varios tipos para probar
!>    los programas de LAPACK.
!>
!>    DLATMR opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Genera una matriz A con entradas aleatorias de la distribución DIST
!>         que es simétrica si SYM='S', y no simétrica
!>         si SYM='N'.
!>
!>      Establece la diagonal a D, donde D puede ser de entrada o
!>         calculado de acuerdo con MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>      Escala la matriz, si se desea, desde la izquierda y/o la derecha
!>         como lo especifica GRADE. Las entradas DL, MODEL, CONDL, DR,
!>         MODER y CONDR también determinan el escalado como se describe
!>         a continuación.
!>
!>      Permuta, si se desea, las filas y/o columnas como lo especifican
!>         PIVTNG e IPIVOT.
!>
!>      Establece entradas aleatorias a cero, si se desea, para obtener una matriz dispersa aleatoria
!>         como lo especifica SPARSE.
!>
!>      Hace que A sea una matriz de banda, si se desea, poniendo a cero la matriz
!>         fuera de una banda de ancho inferior KL y ancho superior KU.
!>
!>      Escala A, si se desea, para tener una entrada máxima ANORM.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetado
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior por columnas (si es simétrica o
!>             triangular superior cuadrada)
!>         almacenar la mitad inferior por columnas (si es simétrica o
!>             triangular inferior cuadrada)
!>             igual que la mitad superior por filas si es simétrica
!>         almacenar el triángulo inferior en formato de banda (si es simétrica)
!>         almacenar el triángulo superior en formato de banda (si es simétrica)
!>         almacenar toda la matriz en formato de banda
!>
!>    Nota: Si dos llamadas a DLATMR difieren solo en el parámetro PACK,
!>          generarán matrices matemáticamente equivalentes.
!>
!>          Si dos llamadas a DLATMR ambas tienen ancho de banda completo (KL = M-1
!>          y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>          entonces las matrices generadas diferirán solo
!>          en el orden de las filas y/o columnas, y de lo contrario
!>          contendrán los mismos datos. Esta consistencia no puede ser y
!>          no se mantiene con menos que el ancho de banda completo.
!
>

Parámetro

s
M 
!>          M es INTEGER
!>           Número de filas de A. No modificado.
!
>

N 
!>          N es INTEGER
!>           Número de columnas de A. No modificado.
!
>

DIS

T 
!>          DIST es CHARACTER*1
!>           A la entrada, DIST especifica el tipo de distribución a ser usada
!>           para generar una matriz aleatoria.
!>           'U' => UNIFORM( 0, 1 )  ( 'U' por uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' por simétrica )
!>           'N' => NORMAL( 0, 1 )   ( 'N' por normal )
!>           No modificado.
!
>

ISEE

D 
!>          ISEED es un arreglo INTEGER, dimensión (4)
!>           A la entrada ISEED especifica la semilla del generador de números
!>           aleatorios. Deberían estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debería ser impar. El generador de números aleatorios
!>           usa una secuencia congruencial lineal limitada a pequeños
!>           enteros, y por lo tanto debería producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED son cambiados en
!>           la salida, y pueden ser usados en la siguiente llamada a DLATMR
!>           para continuar la misma secuencia de números aleatorios.
!>           Cambiado en la salida.
!
>

SY

M 
!>          SYM es CHARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica.
!>           Si SYM='N', la matriz generada no es simétrica.
!>           No modificado.
!
>

D 
!>          D es un arreglo DOUBLE PRECISION, dimensión (min(M,N))
!>           A la entrada este arreglo especifica las entradas diagonales
!>           de la diagonal de A. D puede ser especificado
!>           a la entrada, o establecido de acuerdo con MODE y COND como se describe
!>           a continuación. Puede ser cambiado en la salida si MODE es distinto de cero.
!
>

MOD

E 
!>          MODE es INTEGER
!>           A la entrada describe cómo debe usarse D:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tal que sus logaritmos
!>                    estén uniformemente distribuidos.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D está invertido.
!>           Así que si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           No modificado.
!
>

CON

D 
!>          COND es DOUBLE PRECISION
!>           A la entrada, usado como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!
>

DMA

X 
!>          DMAX es DOUBLE PRECISION
!>           Si MODE no es ni -6, 0 ni 6, la diagonal es escalada por
!>           DMAX / max(abs(D(i))), de modo que la entrada absoluta máxima
!>           de la diagonal es abs(DMAX). Si DMAX es negativo (o cero),
!>           la diagonal será escalada por un número negativo (o cero).
!
>

RSIG

N 
!>          RSIGN es CHARACTER*1
!>           Si MODE no es ni -6, 0 ni 6, especifica el signo de la diagonal
!>           como sigue:
!>           'T' => las entradas diagonales son multiplicadas por 1 o -1
!>                  con probabilidad .5
!>           'F' => diagonal sin cambios
!>           No modificado.
!
>

GRAD

E 
!>          GRADE es CHARACTER*1
!>           Especifica el escalado de la matriz como sigue:
!>           'N'  => sin escalado
!>           'L'  => matriz premultiplicada por diag( DL )
!>                   (solo si la matriz no es simétrica)
!>           'R'  => matriz postmultiplicada por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'B'  => matriz premultiplicada por diag( DL ) y                         postmultiplicada por diag( DR )
!>                   (solo si la matriz no es simétrica)
!>           'S' o 'H'  => matriz premultiplicada por diag( DL ) y
!>                          postmultiplicada por diag( DL )
!>                          ('S' para simétrica, o 'H' para hermítica)
!>           'E'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>                         ( 'E' para invariancia de valores propios)
!>                   (solo si la matriz no es simétrica)
!>                   Nota: si GRADE='E', entonces M debe ser igual a N.
!>           No modificado.
!
>

D

L 
!>          DL es un arreglo DOUBLE PRECISION, dimensión (M)
!>           Si MODEL=0, entonces en la entrada este arreglo especifica las
!>           entradas diagonales de una matriz diagonal utilizada como se
!>           describe bajo GRADE arriba. Si MODEL no es cero, entonces DL
!>           se establecerá de acuerdo con MODEL y CONDL, de manera análoga
!>           a la forma en que D se establece de acuerdo con MODE y COND
!>           (excepto que no hay parámetro DMAX para DL).
!>           Si GRADE='E', entonces DL no puede tener entradas cero.
!>           No se referencia si GRADE = 'N' o 'R'. Modificado en la salida.
!
>

MODE

L 
!>          MODEL es INTEGER
!>           Esto especifica cómo se debe calcular el arreglo diagonal DL,
!>           igual que MODE especifica cómo se debe calcular D.
!>           No modificado.
!
>

COND

L 
!>          CONDL es DOUBLE PRECISION
!>           Cuando MODEL no es cero, esto especifica el número de condición
!>           del DL calculado.  No modificado.
!
>

D

R 
!>          DR es un arreglo DOUBLE PRECISION, dimensión (N)
!>           Si MODER=0, entonces en la entrada este arreglo especifica las
!>           entradas diagonales de una matriz diagonal utilizada como se
!>           describe bajo GRADE arriba. Si MODER no es cero, entonces DR
!>           se establecerá de acuerdo con MODER y CONDR, de manera análoga
!>           a la forma en que D se establece de acuerdo con MODE y COND
!>           (excepto que no hay parámetro DMAX para DR).
!>           No se referencia si GRADE = 'N', 'L', 'H', 'S' o 'E'.
!>           Modificado en la salida.
!
>

MODE

R 
!>          MODER es INTEGER
!>           Esto especifica cómo se debe calcular el arreglo diagonal DR,
!>           igual que MODE especifica cómo se debe calcular D.
!>           No modificado.
!
>

COND

R 
!>          CONDR es DOUBLE PRECISION
!>           Cuando MODER no es cero, esto especifica el número de condición
!>           del DR calculado.  No modificado.
!
>

PIVTN

G 
!>          PIVTNG es CHARACTER*1
!>           En la entrada especifica las permutaciones de pivoteo como sigue:
!>           'N' o ' ' => ninguna.
!>           'L' => pivoteo izquierdo o por filas (la matriz debe ser no simétrica).
!>           'R' => pivoteo derecho o por columnas (la matriz debe ser
!>                  no simétrica).
!>           'B' o 'F' => ambos o pivoteo completo, es decir, en ambos lados.
!>                         En este caso, M debe ser igual a N
!>
!>           Si dos llamadas a DLATMR ambas tienen ancho de banda completo (KL = M-1
!>           y KU = N-1), y solo difieren en los parámetros PIVTNG y PACK,
!>           entonces las matrices generadas diferirán solo en el orden de las
!>           filas y/o columnas, y de lo mismo contendrán los mismos datos.
!>           Esta consistencia no puede mantenerse con menos de ancho de banda completo.
!
>

IPIVO

T 
!>          IPIVOT es un arreglo INTEGER, dimensión (N o M)
!>           Este arreglo especifica la permutación utilizada.  Después de
!>           que la matriz básica es generada, las filas, columnas, o ambas
!>           son permutadas.   Si, por ejemplo, se selecciona pivoteo por filas,
!>           DLATMR comienza con la *última* fila e intercambia la M-ésima
!>           fila con la IPIVOT(M)-ésima fila, luego pasa a la penúltima fila,
!>           intercambiando la (M-1)-ésima fila con la IPIVOT(M-1)-ésima fila,
!>           y así sucesivamente.  En términos de , la permutación es
!>           (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
!>           donde el ciclo más a la derecha se aplica primero.  Este es el
!>           *inverso* del efecto del pivoteo en LINPACK.  La idea
!>           es que factorizar (con pivoteo) una matriz identidad
!>           que ha sido inversamente pivoteada de esta manera debería
!>           resultar en un vector de pivote idéntico a IPIVOT.
!>           No se referencia si PIVTNG = 'N'. No modificado.
!
>

K

L 
!>          KL es INTEGER
!>           En la entrada especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica
!>           Hessenberg superior, y KL al menos M-1 implica que la matriz no es
!>           banda. Debe ser igual a KU si la matriz es simétrica.
!>           No modificado.
!
>

K

U 
!>          KU es INTEGER
!>           En la entrada especifica el ancho de banda superior de la matriz. Por
!>           ejemplo, KU=0 implica triangular inferior, KU=1 implica
!>           Hessenberg inferior, y KU al menos N-1 implica que la matriz no es
!>           banda. Debe ser igual a KL si la matriz es simétrica.
!>           No modificado.
!
>

SPARS

E 
!>          SPARSE es DOUBLE PRECISION
!>           En la entrada especifica la dispersión de la matriz si se va a
!>           generar una matriz dispersa. SPARSE debe estar entre
!>           0 y 1. Para generar una matriz dispersa, para cada entrada de la
!>           matriz se genera un número aleatorio uniforme ( 0, 1 ) x y se
!>           compara con SPARSE; si x es mayor la entrada de la matriz
!>           no cambia y si x es menor la entrada se establece
!>           a cero. Así en promedio una fracción SPARSE de las
!>           entradas se establecerán a cero.
!>           No modificado.
!
>

ANOR

M 
!>          ANORM es DOUBLE PRECISION
!>           En la entrada especifica la entrada máxima de la matriz de salida
!>           (la matriz de salida será multiplicada por una constante de modo
!>           que su entrada absoluta más grande sea igual a ANORM)
!>           si ANORM es no negativo. Si ANORM es negativo no se hace
!>           escalado. No modificado.
!
>

PAC

K 
!>          PACK es CHARACTER*1
!>           En la entrada especifica el empaquetado de la matriz como sigue:
!>           'N' => sin empaquetado
!>           'U' => poner a cero todas las entradas subdiagonales (si es simétrica)
!>           'L' => poner a cero todas las entradas superdiagonales (si es simétrica)
!>           'C' => almacenar el triángulo superior por columnas
!>                  (solo si la matriz es simétrica o triangular superior cuadrada)
!>           'R' => almacenar el triángulo inferior por columnas
!>                  (solo si la matriz es simétrica o triangular inferior cuadrada)
!>                  (igual que la mitad superior por filas si es simétrica)
!>           'B' => almacenar el triángulo inferior en esquema de almacenamiento banda
!>                  (solo si la matriz es simétrica)
!>           'Q' => almacenar el triángulo superior en esquema de almacenamiento banda
!>                  (solo si la matriz es simétrica)
!>           'Z' => almacenar la matriz completa en esquema de almacenamiento banda
!>                      (el pivoteo puede proporcionarse usando esta
!>                      opción para almacenar A en las filas finales de
!>                      el almacenamiento asignado)
!>
!>           Usando estas opciones, se pueden obtener los diversos
!>           esquemas de almacenamiento empaquetado y de banda de LAPACK:
!>           GB               - usar 'Z'
!>           PB, SB o TB     - usar 'B' o 'Q'
!>           PP, SP o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a DLATMR difieren solo en el parámetro PACK,
!>           generarán matrices matemáticamente equivalentes.
!>           No modificado.
!
>

A 
!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA,N)
!>           En la salida A es la matriz de prueba deseada. Solo aquellas
!>           entradas de A que son significativas en la salida
!>           serán referenciadas (incluso si A está en formato de almacenamiento
!>           empaquetado o de banda). Los 'rincones no ocupados' de A en
!>           formato banda serán puestos a cero.
!
>

LD

A 
!>          LDA es INTEGER
!>           en la entrada LDA especifica la primera dimensión de A como
!>           está declarada en el programa que llama.
!>           Si PACK='N', 'U' o 'L', LDA debe ser al menos max ( 1, M ).
!>           Si PACK='C' o 'R', LDA debe ser al menos 1.
!>           Si PACK='B', o 'Q', LDA debe ser MIN ( KU+1, N )
!>           Si PACK='Z', LDA debe ser al menos KUU+KLL+1, donde
!>           KUU = MIN ( KU, N-1 ) y KLL = MIN ( KL, M-1 )
!>           No modificado.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión ( N o M)
!>           Espacio de trabajo. No se referencia si PIVTNG = 'N'. Modificado en la salida.
!
>

INF

O 
!>          INFO es INTEGER
!>           Parámetro de error en la salida:
!>             0 => retorno normal
!>            -1 => M negativo o desigual a N y SYM='S' o 'H'
!>            -2 => N negativo
!>            -3 => DIST cadena ilegal
!>            -5 => SYM cadena ilegal
!>            -7 => MODE fuera del rango -6 a 6
!>            -8 => COND menor que 1.0, y MODE ni -6, 0 ni 6
!>           -10 => MODE ni -6, 0 ni 6 y RSIGN cadena ilegal
!>           -11 => GRADE cadena ilegal, o GRADE='E' y
!>                  M no igual a N, o GRADE='L', 'R', 'B' o 'E' y
!>                  SYM = 'S' o 'H'
!>           -12 => GRADE = 'E' y DL contiene cero
!>           -13 => MODEL fuera del rango -6 a 6 y GRADE= 'L', 'B', 'H',
!>                  'S' o 'E'
!>           -14 => CONDL menor que 1.0, GRADE='L', 'B', 'H', 'S' o 'E',
!>                  y MODEL ni -6, 0 ni 6
!>           -16 => MODER fuera del rango -6 a 6 y GRADE= 'R' o 'B'
!>           -17 => CONDR menor que 1.0, GRADE='R' o 'B', y
!>                  MODER ni -6, 0 ni 6
!>           -18 => PIVTNG cadena ilegal, o PIVTNG='B' o 'F' y
!>                  M no igual a N, o PIVTNG='L' o 'R' y SYM='S'
!>                  o 'H'
!>           -19 => IPIVOT contiene número fuera de rango y
!>                  PIVTNG no igual a 'N'
!>           -20 => KL negativo
!>           -21 => KU negativo, o SYM='S' o 'H' y KU no igual a KL
!>           -22 => SPARSE fuera del rango 0. a 1.
!>           -24 => PACK cadena ilegal, o PACK='U', 'L', 'B' o 'Q'
!>                  y SYM='N', o PACK='C' y SYM='N' y ya sea KL
!>                  no igual a 0 o N no igual a M, o PACK='R' y
!>                  SYM='N', y ya sea KU no igual a 0 o N no igual
!>                  a M
!>           -26 => LDA demasiado pequeño
!>             1 => Retorno de error de DLATM1 (calculando D)
!>             2 => No se puede escalar la diagonal a DMAX (la entrada máxima es 0)
!>             3 => Retorno de error de DLATM1 (calculando DL)
!>             4 => Retorno de error de DLATM1 (calculando DR)
!>             5 => ANORM es positivo, pero la matriz construida antes de
!>                  intentar escalarla para tener norma ANORM, es cero
!
>
