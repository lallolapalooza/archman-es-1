Documentación de la Función/Subrutina

subroutine dlqt01 (integer m, integer n, double precision, dimension( lda, * ) a, double precision, dimension( lda, * ) af, double precision, dimension( lda, * ) q, double precision, dimension( lda, * ) l, integer lda, double precision, dimension( * ) tau, double precision, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

DLQT01

Propósito:

!>
!> DLQT01 prueba DGELQF, que calcula la factorización LQ de una matriz m-por-n
!> A, y prueba parcialmente DORGLQ que forma la matriz ortogonal n-por-n
!> Q.
!>
!> DLQT01 compara L con A*Q', y comprueba que Q es ortogonal.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array de DOBLE PRECISIÓN, dimensión (LDA,N)
!>          La matriz m-por-n A.
!>

AF

!>          AF es un array de DOBLE PRECISIÓN, dimensión (LDA,N)
!>          Detalles de la factorización LQ de A, tal como devuelve DGELQF.
!>          Ver DGELQF para más detalles.
!>

Q

!>          Q es un array de DOBLE PRECISIÓN, dimensión (LDA,N)
!>          La matriz ortogonal n-por-n Q.
!>

L

!>          L es un array de DOBLE PRECISIÓN, dimensión (LDA,max(M,N))
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, Q y L.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU es un array de DOBLE PRECISIÓN, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales, tal como
!>          devuelve DGELQF.
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es un array de DOBLE PRECISIÓN, dimensión (max(M,N))
!>

RESULT

!>          RESULT es un array de DOBLE PRECISIÓN, dimensión (2)
!>          Los ratios de prueba:
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
