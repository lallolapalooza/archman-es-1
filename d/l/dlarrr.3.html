Documentación de función/subrutina

subrutina dlarrr (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, integer info)

DLARRR realiza pruebas para decidir si la matriz tridiagonal simétrica T justifica cálculos costosos que garantizan alta precisión relativa en los valores propios.

Propósito:

!>
!> Realiza pruebas para decidir si la matriz tridiagonal simétrica T
!> justifica cálculos costosos que garantizan alta precisión relativa
!> en los valores propios.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz. N > 0.
!>

D

!>          D es un array de DOUBLE PRECISION, dimension (N)
!>          Los N elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array de DOUBLE PRECISION, dimension (N)
!>          En la entrada, las primeras (N-1) entradas contienen los elementos
!>          subdiagonales de la matriz tridiagonal T; E(N) se establece en CERO.
!>

INFO

!>          INFO es INTEGER
!>          INFO = 0 (predeterminado) : la matriz justifica cálculos que preservan
!>                                     la precisión relativa.
!>          INFO = 1                 : la matriz justifica cálculos que garantizan
!>                                     solo precisión absoluta.
!>
