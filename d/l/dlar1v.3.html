Documentación de la Función/Subrutina

subrutina dlar1v (integer n, integer b1, integer bn, double precision lambda, double precision, dimension( * ) d, double precision, dimension( * ) l, double precision, dimension( * ) ld, double precision, dimension( * ) lld, double precision pivmin, double precision gaptol, double precision, dimension( * ) z, logical wantnc, integer negcnt, double precision ztz, double precision mingma, integer r, integer, dimension( * ) isuppz, double precision nrminv, double precision resid, double precision rqcorr, double precision, dimension( * ) work)

DLAR1V calcula la columna r (escalada) de la inversa de la submatriz en las filas b1 a bn de la matriz tridiagonal LDLT - λI.

Propósito:

!>
!> DLAR1V calcula la columna r (escalada) de la inversa de
!> la submatriz en las filas B1 a BN de la matriz tridiagonal
!> L D L**T - sigma I. Cuando sigma está cerca de un autovalor, el
!> vector calculado es un autovector preciso. Usualmente, r corresponde
!> al índice donde el autovector es de mayor magnitud.
!> Los siguientes pasos logran esta computación:
!> (a) Transformación qd estacionaria, L D L**T - sigma I = L(+) D(+) L(+)**T,
!> (b) Transformación qd progresiva, L D L**T - sigma I = U(-) D(-) U(-)**T,
!> (c) Cálculo de los elementos diagonales de la inversa de
!>     L D L**T - sigma I combinando las transformaciones anteriores, y eligiendo
!>     r como el índice donde la diagonal de la inversa es (una de las)
!>     de mayor magnitud.
!> (d) Cálculo de la columna r (escalada) de la inversa usando la
!>     factorización torcida obtenida combinando la parte superior de la
!>     transformación estacionaria y la parte inferior de la progresiva.
!>

Parámetros

N 
!>          N es INTEGER
!>           El orden de la matriz L D L**T.
!>

B1

!>          B1 es INTEGER
!>           Primer índice de la submatriz de L D L**T.
!>

BN

!>          BN es INTEGER
!>           Último índice de la submatriz de L D L**T.
!>

LAMBDA

!>          LAMBDA es DOUBLE PRECISION
!>           El desplazamiento. Para calcular un autovector preciso,
!>           LAMBDA debería ser una buena aproximación a un autovalor
!>           de L D L**T.
!>

L

!>          L es un array DOUBLE PRECISION, dimensión (N-1)
!>           Los (n-1) elementos subdiagonales de la matriz bidiagonal unitaria
!>           L, en los elementos 1 a N-1.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>           Los n elementos diagonales de la matriz diagonal D.
!>

LD

!>          LD es un array DOUBLE PRECISION, dimensión (N-1)
!>           Los n-1 elementos L(i)*D(i).
!>

LLD

!>          LLD es un array DOUBLE PRECISION, dimensión (N-1)
!>           Los n-1 elementos L(i)*L(i)*D(i).
!>

PIVMIN

!>          PIVMIN es DOUBLE PRECISION
!>           El pivote mínimo en la secuencia de Sturm.
!>

GAPTOL

!>          GAPTOL es DOUBLE PRECISION
!>           Tolerancia que indica cuándo las entradas del autovector son despreciables
!>           con respecto a su contribución al residuo.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimensión (N)
!>           En la entrada, todas las entradas de Z deben establecerse en 0.
!>           En la salida, Z contiene la columna r (escalada) de la
!>           inversa. El escalado es tal que Z(R) es igual a 1.
!>

WANTNC

!>          WANTNC es LOGICAL
!>           Especifica si NEGCNT debe calcularse.
!>

NEGCNT

!>          NEGCNT es INTEGER
!>           Si WANTNC es .TRUE. entonces NEGCNT = el número de pivotes < pivmin
!>           en la factorización de la matriz L D L**T, y NEGCNT = -1 en caso contrario.
!>

ZTZ

!>          ZTZ es DOUBLE PRECISION
!>           El cuadrado de la norma 2 de Z.
!>

MINGMA

!>          MINGMA es DOUBLE PRECISION
!>           El recíproco del elemento diagonal de mayor (en magnitud)
!>           de la inversa de L D L**T - sigma I.
!>

R

!>          R es INTEGER
!>           El índice de torción para la factorización torcida usada para
!>           calcular Z.
!>           En la entrada, 0 <= R <= N. Si R se introduce como 0, R se establece a
!>           el índice donde (L D L**T - sigma I)^{-1} es de mayor
!>           magnitud. Si 1 <= R <= N, R no cambia.
!>           En la salida, R contiene el índice de torción usado para calcular Z.
!>           Idealmente, R designa la posición de la entrada máxima en el
!>           autovector.
!>

ISUPPZ

!>          ISUPPZ es un array INTEGER, dimensión (2)
!>           El soporte del vector en Z, es decir, el vector Z es
!>           distinto de cero solo en los elementos ISUPPZ(1) a ISUPPZ( 2 ).
!>

NRMINV

!>          NRMINV es DOUBLE PRECISION
!>           NRMINV = 1/SQRT( ZTZ )
!>

RESID

!>          RESID es DOUBLE PRECISION
!>           El residuo del vector FP.
!>           RESID = ABS( MINGMA )/SQRT( ZTZ )
!>

RQCORR

!>          RQCORR es DOUBLE PRECISION
!>           La corrección del Cociente de Rayleigh para LAMBDA.
!>           RQCORR = MINGMA*TMP
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (4*N)
!>
