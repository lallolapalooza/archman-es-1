Documentación de Función/Subrutina

subrutina dlatps (character uplo, character trans, character diag, character normin, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

DLATPS resuelve un sistema de ecuaciones triangular con la matriz almacenada en almacenamiento empaquetado.

Propósito:

!>
!> DLATPS resuelve uno de los sistemas triangulares
!>
!>    A *x = s*b  o  A**T*x = s*b
!>
!> con escalamiento para prevenir desbordamiento, donde A es una matriz
!> triangular superior o inferior almacenada en forma empaquetada. Aquí
!> A**T denota la transpuesta de A, x y b son vectores de n elementos, y
!> s es un factor de escalamiento, usualmente menor o igual a 1, elegido
!> de modo que los componentes de x serán menores que el umbral de
!> desbordamiento. Si el problema sin escalar no causará desbordamiento,
!> se llama a la rutina de BLAS de Nivel 2 DTPSV. Si la matriz A es
!> singular (A(j,j) = 0 para algún j), entonces s se establece a 0 y se
!> devuelve una solución no trivial a A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b  (Sin transponer)
!>          = 'T':  Resolver A**T* x = s*b  (Transponer)
!>          = 'C':  Resolver A**T* x = s*b  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de columna en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. En la salida,
!>                  las normas serán calculadas y almacenadas en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array DOUBLE PRECISION, dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por
!>          columnas en un array lineal. La j-ésima columna de A se
!>          almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          En la salida, X es sobrescrito por el vector solución x.
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          El factor de escalamiento s para el sistema triangular
!>             A * x = s*b  o  A**T* x = s*b.
!>          Si SCALE = 0, la matriz A es singular o está mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.
!>

CNORM

!>          CNORM es un array DOUBLE PRECISION, dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte fuera de la diagonal de la j-ésima
!>          columna de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual
!>          a la norma infinita, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte fuera de la diagonal de la
!>          j-ésima columna de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  Se calcula una cota aproximada para x; si esa es menor que el
!>  desbordamiento, se llama a DTPSV, de lo contrario, se usa código
!>  específico que verifica posibles desbordamientos o división por cero
!>  en cada operación.
!>
!>  Se usa un esquema por columnas para resolver A*x = b. El algoritmo
!>  básico si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       para j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!>  Definir cotas para los componentes de x después de j iteraciones del
!>  bucle:
!>     M(j) = cota para x[1:j]
!>     G(j) = cota para x[j+1:n]
!>  Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!>  Entonces para la iteración j+1 tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  donde CNORM(j+1) es mayor o igual a la norma infinita de la columna
!>  j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Dado que |x(j)| <= M(j), usamos la rutina de BLAS de Nivel 2 DTPSV
!>  si el recíproco del mayor M(j), j=1,..,n, es mayor que
!>  max(desbordamiento inferior, 1/desbordamiento).
!>
!>  La cota para x(j) también se usa para determinar cuándo se puede
!>  realizar un paso en el método por columnas sin temor a desbordamiento.
!>  Si la cota calculada es mayor que una constante grande, x se escala
!>  para prevenir desbordamiento, pero si la cota desborda, x se establece
!>  a 0, x(j) a 1, y scale a 0, y se encuentra una solución no trivial a
!>  A*x = 0.
!>
!>  De manera similar, se usa un esquema por filas para resolver A**T*x = b.
!>  El algoritmo básico para A triangular superior es
!>
!>       para j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       fin
!>
!>  Calculamos simultáneamente dos cotas
!>       G(j) = cota para ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>       M(j) = cota para x(i), 1<=i<=j
!>
!>  Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y
!>  añadimos la restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!>  Entonces la cota para x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  y podemos llamar con seguridad a DTPSV si 1/M(n) y 1/G(n) son ambos
!>  mayores que max(desbordamiento inferior, 1/desbordamiento).
!>
