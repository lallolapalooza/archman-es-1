DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina dlamrg (integer n1, integer n2, double precision, dimension( * ) a, integer dtrd1, integer dtrd2, integer, dimension( * ) index)

DLAMRG crea una lista de permutación para fusionar las entradas de dos conjuntos ordenados independientemente en un único conjunto ordenado en orden ascendente.

Propósito:

!>
!> DLAMRG creará una lista de permutación que fusionará los elementos
!> de A (que está compuesto por dos conjuntos ordenados independientemente)
!> en un único conjunto que se ordena en orden ascendente.
!>

Parámetros

N1 
!>          N1 es INTEGER
!>

N2

!>          N2 es INTEGER
!>         Estos argumentos contienen las longitudes respectivas de las dos
!>         listas ordenadas a fusionar.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (N1+N2)
!>         Los primeros N1 elementos de A contienen una lista de números
!>         que están ordenados en orden ascendente o descendente.
!>         Lo mismo ocurre con los N2 elementos finales.
!>

DTRD1

!>          DTRD1 es INTEGER
!>

DTRD2

!>          DTRD2 es INTEGER
!>         Estos son los pasos que se tomarán a través del array A.
!>         Los pasos permitidos son 1 y -1. Indican si un subconjunto
!>         de A está ordenado en orden ascendente (DTRDx = 1) o
!>         descendente (DTRDx = -1).
!>

INDEX

!>          INDEX es un array de INTEGER, dimensión (N1+N2)
!>         A la salida, este array contendrá una permutación tal que
!>         si B( I ) = A( INDEX( I ) ) para I=1,N1+N2, entonces B
!>         estará ordenado en orden ascendente.
!>
