subrutina dlagts (job, n, a, b, c, d, in, y, tol, info)
DLAGTS resuelve el sistema de ecuaciones (T-λI)x = y o (T-λI)^Tx = y, donde T es una matriz tridiagonal general y λ un escalar, utilizando la factorización LU calculada por slagtf.

Documentación de función/subrutina

subrutina dlagts (integer job, integer n, double precision, dimension( * ) a, double precision, dimension( * ) b, double precision, dimension( * ) c, double precision, dimension( * ) d, integer, dimension( * ) in, double precision, dimension( * ) y, double precision tol, integer info)

DLAGTS resuelve el sistema de ecuaciones (T-λI)x = y o (T-λI)^Tx = y, donde T es una matriz tridiagonal general y λ un escalar, utilizando la factorización LU calculada por slagtf.

Propósito:

!>
!> DLAGTS puede ser utilizado para resolver uno de los sistemas de ecuaciones
!>
!>    (T - lambda*I)*x = y   o   (T - lambda*I)**T*x = y,
!>
!> donde T es una matriz tridiagonal n x n, para x, después de la
!> factorización de (T - lambda*I) como
!>
!>    (T - lambda*I) = P*L*U ,
!>
!> por la rutina DLAGTF. La elección de la ecuación a ser resuelta es
!> controlada por el argumento JOB, y en cada caso hay una opción
!> para perturbar elementos diagonales de U cero o muy pequeños,
!> esta opción está destinada a su uso en aplicaciones como la iteración inversa.
!>

Parámetros

JOB 
!>          JOB es INTEGER
!>          Especifica el trabajo a ser realizado por DLAGTS como sigue:
!>          =  1: Se deben resolver las ecuaciones  (T - lambda*I)x = y,
!>                pero los elementos diagonales de U no deben ser perturbados.
!>          = -1: Se deben resolver las ecuaciones  (T - lambda*I)x = y
!>                y, si ocurriera desbordamiento, los elementos diagonales
!>                de U deben ser perturbados. Ver argumento TOL abajo.
!>          =  2: Se deben resolver las ecuaciones  (T - lambda*I)**Tx = y,
!>                pero los elementos diagonales de U no deben ser perturbados.
!>          = -2: Se deben resolver las ecuaciones  (T - lambda*I)**Tx = y
!>                y, si ocurriera desbordamiento, los elementos diagonales
!>                de U deben ser perturbados. Ver argumento TOL abajo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T.
!>

A

!>          A es array DOUBLE PRECISION, dimension (N)
!>          En la entrada, A debe contener los elementos diagonales de U
!>          tal como fueron devueltos por DLAGTF.
!>

B

!>          B es array DOUBLE PRECISION, dimension (N-1)
!>          En la entrada, B debe contener los elementos de la primera
!>          superdiagonal de U tal como fueron devueltos por DLAGTF.
!>

C

!>          C es array DOUBLE PRECISION, dimension (N-1)
!>          En la entrada, C debe contener los elementos subdiagonales de L
!>          tal como fueron devueltos por DLAGTF.
!>

D

!>          D es array DOUBLE PRECISION, dimension (N-2)
!>          En la entrada, D debe contener los elementos de la segunda
!>          superdiagonal de U tal como fueron devueltos por DLAGTF.
!>

IN

!>          IN es array INTEGER, dimension (N)
!>          En la entrada, IN debe contener detalles de la matriz P tal como
!>          fueron devueltos por DLAGTF.
!>

Y

!>          Y es array DOUBLE PRECISION, dimension (N)
!>          En la entrada, el vector del lado derecho y.
!>          En la salida, Y se sobrescribe con el vector solución x.
!>

TOL

!>          TOL es DOUBLE PRECISION
!>          En la entrada, con  JOB < 0, TOL debe ser la perturbación mínima
!>          a realizar a los elementos diagonales muy pequeños de U.
!>          TOL debe elegirse normalmente como aproximadamente eps*norm(U),
!>          donde eps es la precisión relativa de la máquina, pero si TOL se
!>          suministra como no positivo, entonces se reinicia a
!>          eps*max( abs( u(i,j) ) ).
!>          Si  JOB > 0  entonces TOL no se referencia.
!>
!>          En la salida, TOL se cambia como se describe anteriormente, sólo
!>          si TOL es no positivo en la entrada. De lo contrario, TOL
!>          no se modifica.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>          > 0:  ocurriría desbordamiento al calcular el elemento INFO-ésimo
!>                del vector solución x. Esto sólo puede ocurrir
!>                cuando JOB se suministra como positivo y significa
!>                que un elemento diagonal de U es muy pequeño, o que
!>                los elementos del vector del lado derecho y son muy
!>                grandes.
!>
