Documentación de la función/subrutina

subroutine dla_wwaddw (integer n, double precision, dimension( * ) x, double precision, dimension( * ) y, double precision, dimension( * ) w)

DLA_WWADDW añade un vector a un vector de doble precisión simple.

Propósito:

!>
!>    DLA_WWADDW añade un vector W a un vector de doble precisión simple (X, Y).
!>
!>    Esto funciona para toda la aritmética de punto flotante hexadecimal y binaria de IBM existente,
!>    pero no para la decimal.
!>

Parámetros

N 
!>          N es INTEGER
!>            La longitud de los vectores X, Y y W.
!>

X

!>          X es un array DOUBLE PRECISION, dimension (N)
!>            La primera parte del vector de acumulación de doble precisión simple.
!>

Y

!>          Y es un array DOUBLE PRECISION, dimension (N)
!>            La segunda parte del vector de acumulación de doble precisión simple.
!>

W

!>          W es un array DOUBLE PRECISION, dimension (N)
!>            El vector a añadir.
!>
