DLATMT

Propósito:

!>
!>    DLATMT genera matrices aleatorias con valores singulares especificados
!>    (o simétricas/hermíticas con valores propios especificados)
!>    para probar los programas de LAPACK.
!>
!>    DLATMT opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establece la diagonal en D, donde D puede ser de entrada o
!>         calculado de acuerdo con MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Genera una matriz con la estructura de banda apropiada, por uno
!>         de dos métodos:
!>
!>      Método A:
!>          Genera una matriz densa M x N multiplicando D a la izquierda
!>              y a la derecha por matrices unitarias aleatorias, luego:
!>
!>          Reduce el ancho de banda de acuerdo con KL y KU, usando
!>          transformaciones de Householder.
!>
!>      Método B:
!>          Convierte la matriz de ancho de banda 0 (es decir, diagonal) en una
!>              matriz de ancho de banda 1 usando rotaciones de Givens,
!>              elementos fuera de banda de vuelta, mucho como en QR; luego
!>              convierte el ancho de banda 1 en un ancho de banda 2, etc.
!>              Tenga en cuenta que para anchos de banda razonablemente pequeños (relativo a
!>              M y N) esto requiere menos almacenamiento, ya que no se
!>              genera una matriz densa.  Además, para matrices simétricas, solo
!>              se genera un triángulo.
!>
!>      Se elige el Método A si el ancho de banda es una fracción grande de la
!>          orden de la matriz, y LDA es al menos M (para que una matriz densa
!>          pueda almacenarse.)  Se elige el Método B si el ancho de banda
!>          es pequeño (< 1/2 N para simétrica, < .3 N+M para
!>          no simétrica), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetado
!>         poner a cero la mitad superior (si es simétrica)
!>         poner a cero la mitad inferior (si es simétrica)
!>         almacenar la mitad superior por columnas (si es simétrica o
!>               triangular superior)
!>         almacenar la mitad inferior por columnas (si es simétrica o
!>               triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es simétrica
!>               o triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es simétrica
!>               o triangular superior)
!>         almacenar la matriz completa en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en el formato de banda, por lo que no será
!>         necesario reempaquetar.
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de A. No modificado.
!>

N

!>          N es INTEGER
!>           El número de columnas de A. No modificado.
!>

DIST

!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORM( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORM( -1, 1 ) ( 'S' para simétrica )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           No modificado.
!>

ISEED

!>          ISEED es un array de INTEGER, dimensión ( 4 )
!>           En la entrada ISEED especifica la semilla del generador de
!>           números aleatorios. Deberían estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debería ser impar. El generador de números aleatorios
!>           usa una secuencia congruencial lineal limitada a pequeños
!>           enteros, y por lo tanto debería producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED se cambian al
!>           salir, y pueden usarse en la siguiente llamada a DLATMT
!>           para continuar la misma secuencia de números aleatorios.
!>           Modificado al salir.
!>

SYM

!>          SYM es CHARACTER*1
!>           Si SYM='S' o 'H', la matriz generada es simétrica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es simétrica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada es no simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           No modificado.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión ( MIN( M , N ) )
!>           Este array se usa para especificar los valores singulares o
!>           propios de A (ver SYM, arriba.)  Si MODE=0, entonces se
!>           asume que D contiene los valores singulares/propios, de lo contrario
!>           se calcularán de acuerdo con MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es INTEGER
!>           En la entrada esto describe cómo se deben especificar los
!>           valores singulares/propios:
!>           MODE = 0 significa usar D como entrada
!>
!>           MODE = 1 establece D(1)=1 y D(2:RANK)=1.0/COND
!>           MODE = 2 establece D(1:RANK-1)=1 y D(RANK)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(RANK-1))
!>
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) de modo que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D está invertido.
!>           Así que si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           Si SYM='S' o 'H', y MODE no es ni 0, 6, ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo
!>              aleatorio (es decir, +1 o -1.)
!>           No modificado.
!>

COND

!>          COND es DOUBLE PRECISION
!>           En la entrada, esto se usa como se describe bajo MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es DOUBLE PRECISION
!>           Si MODE no es ni -6, 0 ni 6, el contenido de D, tal como
!>           se calcula de acuerdo con MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))); así, el valor propio o singular
!>           máximo absoluto (es decir, la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no necesita ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No modificado.
!>

RANK

!>          RANK es INTEGER
!>           El rango de la matriz a generar solo para los modos 1,2,3.
!>           D( RANK+1:N ) = 0.
!>           No modificado.
!>

KL

!>          KL es INTEGER
!>           Esto especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica
!>           Hessenberg superior, y KL siendo al menos M-1 significa

NAME

                    
DLATMT — Latent triangle matrix

                

                

                    
SYNOPSIS

                    
SUBROUTINE DLATMT(
   M, N, DIST, SYM, MODE, COND, DMAX, PACK, A, LDA, WORK, INFO)
      INTEGER          :: M, N, INFO
      CHARACTER(LEN=1) :: DIST, SYM, PACK
      CHARACTER(LEN=*) :: MODE
      DOUBLE PRECISION :: COND, DMAX
      DOUBLE PRECISION, DIMENSION( LDA, * ) :: A
      DOUBLE PRECISION, DIMENSION( * ) :: WORK
                    

                

                

                    
Function/Subroutine Documentation

                    
DLATMT constructs a triangular-tridiagonal matrix that is
                        suitable for testing the LAPACK routines that compute the
                        singular value decomposition (SVD) and the eigenvalue
                        problem (EVP) for general, symmetric, Hermitian, or
                        skew-symmetric matrices.

                    
Arguments:

                    

                        
M

                        

                            
M is INTEGER

                            
The number of rows of the matrix A.

                            
Not modified.

                        

                        
N

                        

                            
N is INTEGER

                            
The number of columns of the matrix A.

                            
Not modified.

                        

                        
DIST

                        

                            
DIST is CHARACTER*1

                            
Specifies the storage scheme for the
                                matrix A as follows:

                            
'U' => A is stored in the upper triangle (packed or full).
'L' => A is stored in the lower triangle (packed or full).
'G' => A is stored as a general matrix.
                            

                            
Not modified.

                        

                        
SYM

                        

                            
SYM is CHARACTER*1

                            
Specifies the properties of the matrix A
                                as follows:

                            
'N' => general matrix
'S' => symmetric matrix
'H' => symmetric matrix (Hermitian)
'P' => skew-symmetric matrix
                            

                            
Not modified.

                        

                        
MODE

                        

                            
MODE is INTEGER

                            
Specifies the way the matrix is
                                constructed. The valid values are:

                            
-6 => DIAG(A) = 1.0
-5 => DIAG(A) = 1.0, Off-Diagonals = 1.0/row/col index
-4 => DIAG(A) = 1.0, Off-Diagonals = 1.0 / (row + col) index
-3 => DIAG(A) = 1.0, Off-Diagonals = 1.0 / (row - col + N) index
-2 => DIAG(A) = 1.0, Off-Diagonals = 1.0 / (row - col) index
-1 => DIAG(A) = 1.0, Off-Diagonals = 1.0
 0 => DIAG(A) = random, Off-Diagonals = random
 1 => DIAG(A) = random, Off-Diagonals = 1.0
 2 => DIAG(A) = random, Off-Diagonals = 1.0 / (row - col) index
 3 => DIAG(A) = random, Off-Diagonals = 1.0 / (row - col + N) index
 4 => DIAG(A) = random, Off-Diagonals = 1.0 / (row + col) index
 5 => DIAG(A) = random, Off-Diagonals = 1.0/row/col index
 6 => DIAG(A) = 1.0, Off-Diagonals = 1.0 / sqrt(row*col) index
                            

                            
Not modified.

                        

                        
COND

                        

                            
COND is DOUBLE PRECISION

                            
The condition number of the matrix A.

                            
Not modified.

                        

                        
DMAX

                        

                            
DMAX is DOUBLE PRECISION

                            
The maximum absolute value of the
                                diagonal elements of A.

                            
Not modified.

                        

                        
PACK

                        

                            
PACK is CHARACTER*1

                            
Specifies packing of matrix as follows:

                            
'N' => no packing
'U' => zero out all subdiagonal entries (if symmetric)
'L' => zero out all superdiagonal entries (if symmetric)
'C' => store the upper triangle columnwise
       (only if the matrix is symmetric or upper triangular)
'R' => store the lower triangle columnwise
       (only if the matrix is symmetric or lower triangular)
'B' => store the lower triangle in band storage scheme
       (only if matrix symmetric or lower triangular)
'Q' => store the upper triangle in band storage scheme
       (only if matrix symmetric or upper triangular)
'Z' => store the entire matrix in band storage scheme
           (pivoting can be provided for by using this
           option to store A in the trailing rows of
           the allocated storage)
                            

                            
Using these options, the various LAPACK packed and banded
                                storage schemes can be obtained:

                            
GB               - use 'Z'
PB, SB or TB     - use 'B' or 'Q'
PP, SP or TP     - use 'C' or 'R'
                            

                            
If two calls to DLATMT differ only in the PACK parameter,
                                they will generate mathematically equivalent matrices.

                            
Not modified.

                        

                        
A

                        

                            
A is DOUBLE PRECISION array, dimension ( LDA, N )

                            
On exit A is the desired test matrix. A is first generated
                                in full (unpacked) form, and then packed, if so specified
                                by PACK. Thus, the first M elements of the first N
                                columns will always be modified. If PACK specifies a
                                packed or banded storage scheme, all LDA elements of the
                                first N columns will be modified; the elements of the
                                array which do not correspond to elements of the generated
                                matrix are set to zero.

                            
Modified.

                        

                        
LDA

                        

                            
LDA is INTEGER

                            
LDA specifies the first dimension of A as declared in the
                                calling program. If PACK='N', 'U', 'L', 'C', or 'R', then
                                LDA must be at least M. If PACK='B' or 'Q', then LDA must
                                be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
                                If PACK='Z', LDA must be large enough to hold the packed
                                array: MIN( KU, N-1) + MIN( KL, M-1) + 1.

                            
Not modified.

                        

                        
WORK

                        

                            
WORK is DOUBLE PRECISION array, dimension ( 3*MAX( N , M ) )

                            
Workspace.

                            
Modified.

                        

                        
INFO

                        

                            
INFO is INTEGER

                            
Error code. On exit, INFO will be set to one of the
                                following values:

                            
0  => normal return
-1 => M negative or unequal to N and SYM='S', 'H', or 'P'
-2 => N negative
-3 => DIST illegal string
-5 => SYM illegal string
-7 => MODE not in range -6 to 6
-8 => COND less than 1.0, and MODE neither -6, 0 nor 6
-10 => KL negative
-11 => KU negative, or SYM='S' or 'H' and KU not equal to KL
-12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
       or PACK='C' or 'Q' and SYM='N' and KL is not zero;
       or PACK='R' or 'B' and SYM='N' and KU is not zero;
       or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
       N.
-14 => LDA is less than M, or PACK='Z' and LDA is less than
       MIN(KU,N-1) + MIN(KL,M-1) + 1.
1  => Error return from DLATM7
2  => Cannot scale to DMAX (max. sing. value is 0)
3  => Error return from DLAGGE or DLAGSY
