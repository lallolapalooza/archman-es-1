NOMBRE

dlb - bibliotecario de datos de NetHack

SINOPSIS

dlb { xct } [ vfIC ] argumentos... [ archivos... ]

DESCRIPCIÓN

Dlb es una herramienta de archivado de archivos al estilo (y tradición) de tar para NetHack versión 3.1 y superior. Se utiliza para mantener los archivos de archivo de los que NetHack lee archivos de nivel especiales y otra información de solo lectura. Tenga en cuenta que, al igual que tar, los especificadores de comando y opción se especifican como una cadena continua y van seguidos de cualquier argumento requerido en el mismo orden que los especificadores de opción.

Esta utilidad es opcional pero se incluye en esta configuración de NetHack.

COMANDOS

El comando x hace que dlb extraiga el contenido del archivo en el directorio actual.

El comando c hace que dlb cree un nuevo archivo a partir de los archivos en el directorio actual.

El comando t lista los archivos en el archivo.

OPCIONES Y ARGUMENTOS

v salida detallada

f archivo especifica el archivo. Por defecto, si no se especifica f, es LIBFILE (generalmente el archivo nhdat en el área de juegos).

I lfile especifica el archivo que contiene la lista de archivos a incluir o extraer del archivo si no se listan archivos en la línea de comandos. El valor por defecto para la creación de archivos si no se listan archivos es LIBLISTFILE.

C dir cambiar directorio. Cambia de directorio antes de intentar leer cualquier archivo (incluido el archivo y el archivo lfile).

EJEMPLOS

Crear el archivo por defecto a partir de la lista de archivos por defecto:
dlb c

Listar el contenido del archivo 'foo':
dlb tf foo

ERRORES

No es una buena emulación de tar; - no significa stdin ni stdout. Debería incluir una instalación de compresión opcional. No todos los archivos de solo lectura para NetHack se pueden leer desde un archivo; examinar el código fuente es la única forma de saber cuáles se pueden leer.
