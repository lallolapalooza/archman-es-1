función de doble precisión dlanhs (norma, n, a, lda, trabajo)
DLANHS devuelve el valor de la norma 1, la norma de Frobenius, la norma infinito o el valor absoluto más grande de cualquier elemento de una matriz superior de Hessenberg.

Documentación de la función/subrutina

función de doble precisión dlanhs (carácter norma, entero n, doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( * ) trabajo)

DLANHS devuelve el valor de la norma 1, la norma de Frobenius, la norma infinito o el valor absoluto más grande de cualquier elemento de una matriz superior de Hessenberg.

Propósito:

!>
!> DLANHS  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma de infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz de Hessenberg A.
!>

Devoluciones

DLANHS 
!>
!>    DLANHS = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma de infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor que se devolverá en DLANHS como se describe
!>          arriba.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, DLANHS se
!>          establece en cero.
!>

A

!>          A es una matriz DOUBLE PRECISION, de dimensión (LDA,N)
!>          La matriz de Hessenberg superior n x n A; la parte de A debajo de
!>          la primera subdiagonal no se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A.  LDA >= max(N,1).
!>

TRABAJO

!>          TRABAJO es una matriz DOUBLE PRECISION, de dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I'; de lo contrario, TRABAJO no
!>          se referencia.
!>
