DLASD7 combina los dos conjuntos de valores singulares en un único conjunto ordenado. Luego intenta reducir el tamaño del problema. Hay dos formas en que puede ocurrir la deflación: cuando dos o más valores singulares están juntos o si hay una entrada diminuta en el vector Z. Por cada ocurrencia de este tipo, el orden del problema de la ecuación secular relacionada se reduce en uno.

DLASD7 es llamada desde DLASD6.

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>          Especifica si se deben calcular los vectores singulares
!>          en forma compacta, como sigue:
!>          = 0: Solo calcular valores singulares.
!>          = 1: Calcular vectores singulares de la matriz
!>               bidiagonal superior en forma compacta.
!>

NL

!>          NL es INTEGER
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR por NR.
!>         = 1: el bloque inferior es una matriz rectangular NR por (NR+1).
!>
!>         La matriz bidiagonal tiene
!>         N = NL + NR + 1 filas y
!>         M = N + SQRE >= N columnas.
!>

K

!>          K es INTEGER
!>         Contiene la dimensión de la matriz no desdeflada, este
!>         es el orden de la ecuación secular relacionada. 1 <= K <= N.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión ( N )
!>         En la entrada D contiene los valores singulares de las dos submatrices
!>         a combinar. En la salida D contiene los N-K valores singulares
!>         actualizados restantes (los que fueron desdeflados) ordenados
!>         en orden creciente.
!>

Z

!>          Z es un array de DOUBLE PRECISION, dimensión ( M )
!>         En la salida Z contiene el vector de fila de actualización en la ecuación
!>         secular.
!>

ZW

!>          ZW es un array de DOUBLE PRECISION, dimensión ( M )
!>         Espacio de trabajo para Z.
!>

VF

!>          VF es un array de DOUBLE PRECISION, dimensión ( M )
!>         En la entrada, VF(1:NL+1) contiene los primeros componentes de todos
!>         los vectores singulares derechos de la matriz superior; y VF(NL+2:M)
!>         contiene los primeros componentes de todos los vectores singulares
!>         derechos de la matriz inferior. En la salida, VF contiene los primeros
!>         componentes de todos los vectores singulares derechos de la matriz
!>         bidiagonal.
!>

VFW

!>          VFW es un array de DOUBLE PRECISION, dimensión ( M )
!>         Espacio de trabajo para VF.
!>

VL

!>          VL es un array de DOUBLE PRECISION, dimensión ( M )
!>         En la entrada, VL(1:NL+1) contiene los últimos componentes de todos
!>         los vectores singulares derechos de la matriz superior; y VL(NL+2:M)
!>         contiene los últimos componentes de todos los vectores singulares
!>         derechos de la matriz inferior. En la salida, VL contiene los últimos
!>         componentes de todos los vectores singulares derechos de la matriz
!>         bidiagonal.
!>

VLW

!>          VLW es un array de DOUBLE PRECISION, dimensión ( M )
!>         Espacio de trabajo para VL.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>         Contiene el elemento diagonal asociado con la fila añadida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>         Contiene el elemento fuera de la diagonal asociado con la fila
!>         añadida.
!>

DSIGMA

!>          DSIGMA es un array de DOUBLE PRECISION, dimensión ( N )
!>         Contiene una copia de los elementos diagonales (K-1 valores singulares
!>         y un cero) en la ecuación secular.
!>

IDX

!>          IDX es un array de INTEGER, dimensión ( N )
!>         Este contendrá la permutación utilizada para ordenar el contenido de
!>         D en orden ascendente.
!>

IDXP

!>          IDXP es un array de INTEGER, dimensión ( N )
!>         Este contendrá la permutación utilizada para colocar los valores
!>         desdeflados de D al final del array. En la salida IDXP(2:K)
!>         apunta a los valores D no desdeflados y IDXP(K+1:N)
!>         apunta a los valores singulares desdeflados.
!>

IDXQ

!>          IDXQ es un array de INTEGER, dimensión ( N )
!>         Este contiene la permutación que ordena por separado los dos
!>         subproblemas en D en orden ascendente. Nota que las entradas en
!>         la primera mitad de esta permutación deben moverse primero una
!>         posición hacia atrás; y las entradas en la segunda mitad
!>         deben tener primero NL+1 sumado a sus valores.
!>

PERM

!>          PERM es un array de INTEGER, dimensión ( N )
!>         Las permutaciones (de deflación y ordenación) que se aplicarán
!>         a cada bloque singular. No referenciado si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR es INTEGER
!>         El número de rotaciones de Givens que tuvieron lugar en este
!>         subproblema. No referenciado si ICOMPQ = 0.
!>

GIVCOL
