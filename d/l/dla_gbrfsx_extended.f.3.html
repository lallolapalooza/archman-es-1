DLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices bandas generales realizando refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la

solución.

Propósito

: 
!>
!>
!> DLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando refinamiento iterativo de precisión extra
!> y proporciona límites de error y estimaciones de error hacia atrás para la
!> solución.
!> Esta subrutina es llamada por DGBRFSX para realizar refinamiento iterativo.
!> Además del límite de error en norma, el código proporciona el límite de
!> error componente a componente máximo si es posible. Véanse los comentarios
!> para ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de los límites de error.
!> Nótese que esta subrutina solo es responsable de establecer los segundos
!> campos de ERR_BNDS_NORM y ERR_BNDS_COMP.
!
>

Parámetro

s
PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a usar en el refinamiento.
!>     El valor está definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!
>

TRANS_TYP

E 
!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición sobre A.
!>     El valor está definido por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transponer
!>          = 'T':  Transponer
!>          = 'C':  Transponer con conjugado
!
>

N 
!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!
>

K

L 
!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!
>

K

U 
!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0
!
>

NRH

S 
!>          NRHS es INTEGER
!>     El número de miembros derechos, es decir, el número de columnas de la
!>     matriz B.
!
>

A

B 
!>          AB es un array DOUBLE PRECISION, dimensión (LDAB,N)
!>          En la entrada, la matriz AB de N por N.
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDBA >= max(1,N).
!
>

AF

B 
!>          AFB es un array DOUBLE PRECISION, dimensión (LDAFB,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U tal como se calcula con DGBTRF.
!
>

LDAF

B 
!>          LDAFB es INTEGER
!>     La dimensión principal del array AF.  LDAFB >= max(1,N).
!
>

IPI

V 
!>          IPIV es un array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como se calcula con DGBTRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!
>

COLEQ

U 
!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó equilibrado de columnas a A antes de
!>     llamar a esta rutina. Esto es necesario para calcular la solución y los
!>     límites de error correctamente.
!
>

C 
!>          C es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si C es de entrada, cada elemento de C debería ser una potencia
!>     de la base para asegurar una solución y estimaciones de error confiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos
!>     que el resultado desborde por arriba o por abajo. Los errores de redondeo
!>     durante el escalado conducen a refinar con una matriz que no es equivalente
!>     a la matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     confiables.
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>     La matriz de miembros derechos B.
!
>

LD

B 
!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!
>

Y 
!>          Y es un array DOUBLE PRECISION, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como se calcula con DGBTRS.
!>     En la salida, la matriz solución Y mejorada.
!
>

LD

Y 
!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!
>

BERR_OU

T 
!>          BERR_OUT es un array DOUBLE PRECISION, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error hacia atrás relativo
!>     componente a componente para el miembro derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto se calcula con DLA_LIN_BERR.
!
>

N_NORM

S 
!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (véanse ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve límites de error en norma.
!>     Si N_NORMS >= 2 devuelve límites de error componente a componente.
!
>

ERR_BNDS_NOR

M 
!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada miembro derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, el cual está definido como sigue:
!>
!>     NorError relativo en norma en el i-ésimo vector de solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error descrito
!>     a continuación. Actualmente se devuelven hasta tres piezas de
!>     información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco en norma estimado. Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de
!>              la base de modo que todas las sumas absolutas de filas de Z
!>              sean aproximadamente 1.
!>
!>     Esta subrutina solo es responsable de establecer el segundo campo
!>     anterior.
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

ERR_BNDS_COM

P 
!>          ERR_BNDS_COMP es un array de DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector de
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array está indexado por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información
!>     de error descrito a continuación. Actualmente se devuelven hasta
!>     tres piezas de información para cada lado derecho. Si no se
!>     solicita precisión componente a componente (PARAMS(3) = 0.0), no
!>     se accede a ERR_BNDS_COMP. Si N_ERR_BNDS < 3, se devuelven como
!>     máximo las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco componente a componente estimado. Se compara con
!>              el umbral sqrt(n) * slamch('Epsilon') para determinar si
!>              la estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de A*diag(x) por
!>              una potencia de la base de modo que todas las sumas
!>              absolutas de filas de Z sean aproximadamente 1.
!>
!>     Esta subrutina solo es responsable de establecer el segundo campo
!>     anterior.
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!
>

RE

S 
!>          RES es un array de DOUBLE PRECISION, dimensión (N)
!>     Espacio de trabajo para contener el residuo intermedio.
!
>

AY

B 
!>          AYB es un array de DOUBLE PRECISION, dimensión (N)
!>     Espacio de trabajo. Puede ser el mismo espacio de trabajo pasado
!>     para Y_TAIL.
!
>

D

Y 
!>          DY es un array de DOUBLE PRECISION, dimensión (N)
!>     Espacio de trabajo para contener la solución intermedia.
!
>

Y_TAI

L 
!>          Y_TAIL es un array de DOUBLE PRECISION, dimensión (N)
!>     Espacio de trabajo para contener los bits inferiores de la
!>     solución intermedia.
!
>

RCON

D 
!>          RCOND es DOUBLE PRECISION
!>     Número de condición recíproco escalado. Esta es una estimación del
!>     número de condición recíproco de Skeel de la matriz A después de
!>     la equilibración (si se realizó). Si es menor que la precisión de
!>     la máquina (en particular, si es cero), la matriz es singular a
!>     la precisión de trabajo. Tenga en cuenta que el error puede seguir
!>     siendo pequeño incluso si este número es muy pequeño y la matriz
!>     parece estar mal condicionada.
!
>

ITHRES

H 
!>          ITHRESH es INTEGER
!>     El número máximo de cálculos de residuo permitidos para el
!>     refinamiento. El valor predeterminado es 10. Para 'aggressive'
!>     establezca en 100 para permitir la convergencia usando
!>     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>     la factorización usa una técnica distinta de la eliminación
!>     gaussiana, las garantías en ERR_BNDS_NORM y ERR_BNDS_COMP pueden
!>     dejar de ser fiables.
!
>

RTHRES

H 
!>          RTHRESH es DOUBLE PRECISION
!>     Determina cuándo detener el refinamiento si la estimación de
!>     error deja de disminuir. El refinamiento se detendrá cuando la
!>     siguiente solución ya no satisfaga norm(dx_{i+1}) < RTHRESH *
!>     norm(dx_i) donde norm(Z) es la norma infinita de Z. RTHRESH
!>     satisface 0 < RTHRESH <= 1. El valor predeterminado es 0.5. Para
!>     'aggressive' establezca en 0.9 para permitir la convergencia en
!>     matrices extremadamente mal condicionadas. Vea LAWN 165 para más
!>     detalles.
!
>

DZ_U

B 
!>          DZ_UB es DOUBLE PRECISION
!>     Determina cuándo empezar a considerar la convergencia componente a
!>     componente. La convergencia componente a componente solo se
!>     considera después de que cada componente de la solución Y esté
!>     estable, lo cual definimos como que el cambio relativo en cada
!>     componente sea menor que DZ_UB. El valor predeterminado es 0.25,
!>     requiriendo que el primer bit esté estable. Vea LAWN 165 para más
!>     detalles.
!
>

IGNORE_CWIS

E 
!>          IGNORE_CWISE es LOGICAL
!>     Si es .TRUE. entonces ignora la convergencia componente a
!>     componente. El valor predeterminado es .FALSE..
!
>

INF

O 
!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  si INFO = -i, el i-ésimo argumento de DGBTRS tenía un
!>             valor ilegal
!
>
