Documentación de Función/Subrutina

subrutina dlarrd (character range, character order, integer n, double precision vl, double precision vu, integer il, integer iu, double precision, dimension( * ) gers, double precision reltol, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) e2, double precision pivmin, integer nsplit, integer, dimension( * ) isplit, integer m, double precision, dimension( * ) w, double precision, dimension( * ) werr, double precision wl, double precision wu, integer, dimension( * ) iblock, integer, dimension( * ) indexw, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLARRD calcula los eigenvalores de una matriz simétrica tridiagonal con la precisión adecuada.

Propósito:

!>
!> DLARRD calcula los eigenvalores de una matriz simétrica tridiagonal
!> T con la precisión adecuada. Este es un código auxiliar que debe ser
!> llamado desde DSTEMR.
!> El usuario puede solicitar todos los eigenvalores, todos los eigenvalores
!> en el intervalo semiabierto (VL, VU], o los eigenvalores desde el IL-ésimo hasta el IU-ésimo.
!>
!> Para evitar el desbordamiento, la matriz debe escalarse de modo que su
!> elemento más grande no sea mayor que overflow**(1/2) * underflow**(1/4) en valor absoluto, y para la mayor
!> precisión, no debería ser mucho menor que eso.
!>
!> Vea W. Kahan , Report CS41, Computer Science Dept., Stanford
!> University, July 21, 1966.
!>

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los eigenvalores.
!>          = 'V': () se encontrarán todos los eigenvalores en el intervalo semiabierto
!>                           (VL, VU].
!>          = 'I': () se encontrarán los eigenvalores desde el IL-ésimo hasta el IU-ésimo (de la
!>                           matriz completa).
!>

ORDER

!>          ORDER es CHARACTER*1
!>          = 'B': () los eigenvalores se agruparán por
!>                              bloque separado (vea IBLOCK, ISPLIT) y
!>                              se ordenarán de menor a mayor dentro
!>                              del bloque.
!>          = 'E': ()
!>                              los eigenvalores de la matriz completa
!>                              se ordenarán de menor a
!>                              mayor.
!>

N

!>          N es INTEGER
!>          El orden de la matriz tridiagonal T.  N >= 0.
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo donde
!>          se buscarán los eigenvalores.  Los eigenvalores menores o iguales
!>          que VL, o mayores que VU, no serán devueltos.  VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo donde
!>          se buscarán los eigenvalores.  Los eigenvalores menores o iguales
!>          que VL, o mayores que VU, no serán devueltos.  VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más pequeño a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          eigenvalor más grande a ser devuelto.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

GERS

!>          GERS es un array DOUBLE PRECISION, dimensión (2*N)
!>          Los N intervalos de Gerschgorin (el i-ésimo intervalo de Gerschgorin
!>          es (GERS(2*i-1), GERS(2*i)).
!>

RELTOL

!>          RELTOL es DOUBLE PRECISION
!>          La anchura relativa mínima de un intervalo.  Cuando un intervalo
!>          es más estrecho que RELTOL veces el extremo de mayor
!>          (en magnitud), entonces se considera
!>          suficientemente pequeño, es decir, convergido.  Nota: esto debería
!>          ser siempre al menos radix*machine epsilon.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los (n-1) elementos fuera de la diagonal de la matriz tridiagonal T.
!>

E2

!>          E2 es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los (n-1) elementos fuera de la diagonal al cuadrado de la matriz tridiagonal T.
!>

PIVMIN

!>          PIVMIN es DOUBLE PRECISION
!>          El pivote mínimo permitido en la secuencia de Sturm para T.
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques diagonales en la matriz T.
!>          1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT es un array INTEGER, dimensión (N)
!>          Los puntos de división, en los que T se divide en submatrices.
!>          La primera submatriz consiste en las filas/columnas 1 a ISPLIT(1),
!>          la segunda en las filas/columnas ISPLIT(1)+1 a ISPLIT(2),
!>          etc., y la NSPLIT-ésima consiste en las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 a ISPLIT(NSPLIT)=N.
!>          (Solo los primeros NSPLIT elementos serán realmente usados, pero
!>          como el usuario no puede saber a priori qué valor tendrá NSPLIT,
!>          se deben reservar N palabras para ISPLIT.)
!>

M

!>          M es INTEGER
!>          El número real de eigenvalores encontrados. 0 <= M <= N.
!>          (Vea también la descripción de INFO=2,3.)
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Al salir, los primeros M elementos de W contendrán las
!>          aproximaciones de los eigenvalores. DLARRD calcula un intervalo
!>          I_j = (a_j, b_j] que incluye el eigenvalor j. La aproximación
!>          del eigenvalor se da como el punto medio del intervalo
!>          W(j)= ( a_j + b_j)/2. El error correspondiente está acotado por
!>          WERR(j) = abs( a_j - b_j)/2
!>

WERR

!>          WERR es un array DOUBLE PRECISION, dimensión (N)
!>          La cota de error sobre la aproximación del eigenvalor correspondiente
!>          en W.
!>

WL

!>          WL es DOUBLE PRECISION
!>

WU

!>          WU es DOUBLE PRECISION
!>          El intervalo (WL, WU] contiene todos los eigenvalores deseados.
!>          Si RANGE='V', entonces WL=VL y WU=VU.
!>          Si RANGE='A', entonces WL y WU son las cotas de Gerschgorin globales
!>                        sobre el espectro.
!>          Si RANGE='I', entonces WL y WU son calculados por DLAEBZ a partir del
!>                        índice range especificado.
!
>

IBLOC

K 
!>          IBLOCK es un arreglo INTEGER de dimensión (N)
!>          En cada fila/columna j donde E(j) es cero o pequeña, la
!>          matriz T se considera que se divide en una matriz
!>          diagonal por bloques.  En la salida, si INFO = 0, IBLOCK(i) especifica a qué
!>          bloque (de 1 al número de bloques) pertenece el autovalor W(i).
!>          (DLARRD puede usar los N-M elementos restantes como
!>          espacio de trabajo.)
!
>

INDEX

W 
!>          INDEXW es un arreglo INTEGER de dimensión (N)
!>          Los índices de los autovalores dentro de cada bloque (submatriz);
!>          por ejemplo, INDEXW(i)= j y IBLOCK(i)=k implican que el
!>          i-ésimo autovalor W(i) es el j-ésimo autovalor en el bloque k.
!
>

WOR

K 
!>          WORK es un arreglo DOUBLE PRECISION de dimensión (4*N)
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER de dimensión (3*N)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  algunos o todos los autovalores no convergieron o
!>                no fueron calculados:
!>                =1 o 3: La bisección no convergió para algunos
!>                        autovalores; estos autovalores están marcados por un
!>                        número de bloque negativo.  El efecto es que los
!>                        autovalores pueden no ser tan precisos como las
!>                        tolerancias absolutas y relativas.  Esto es
!>                        generalmente causado por aritmética inesperadamente inexacta.
!>                =2 o 3: Solo RANGE='I': No se encontraron todos los autovalores
!>                        IL:IU.
!>                        Efecto: M < IU+1-IL
!>                        Causa:  aritmética no monótona, causando que la
!>                                secuencia de Sturm sea no monótona.
!>                        Solución: recalcular, usando RANGE='A', y seleccionar
!>                                los autovalores IL:IU.  En algunos casos,
!>                                aumentar el PARÁMETRO  puede
!>                                hacer que funcione.
!>                = 4:    RANGE='I', y el intervalo de Gershgorin
!>                        utilizado inicialmente era demasiado pequeño.  No se calcularon
!>                        autovalores.
!>                        Causa probable: su máquina tiene aritmética de punto flotante
!>                                        imprecisa.
!>                        Solución: Aumentar el PARÁMETRO ,
!>                              recompilar e intentar de nuevo.
!
>

Parámetros

internos: 
!>  FUDGE   DOUBLE PRECISION, por defecto = 2
!>          Un  para ensanchar los intervalos de Gershgorin.  Idealmente,
!>          un valor de 1 debería funcionar, pero en máquinas con aritmética
!>          imprecisa, esto necesita ser mayor.  El valor por defecto para
!>          las versiones publicadas debería ser lo suficientemente grande para manejar
!>          la peor máquina existente.  Tenga en cuenta que esto no tiene efecto
!>          en la precisión de la solución.
!
>
