DLANSB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz de banda simétrica.

Documentación de Función/Subrutina

doble precisión función dlansb (carácter norma, carácter upo, entero n, entero k, doble precisión, dimensión( lab, * ) ab, entero lab, doble precisión, dimensión( * ) trabajo)

DLANSB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz de banda simétrica.

Propósito:

!>
!> DLANSB  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma del infinito,  o el elemento de  mayor valor absoluto  de una
!> matriz de banda simétrica A de n por n,  con k super-diagonales.
!>

Devuelve

DLANSB 
!>
!>    DLANSB = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norma1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norma1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma del infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma
!> de cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial
!> consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor que se devolverá en DLANSB como se describe
!>          arriba.
!>

UPO

!>          UPO es CHARACTER*1
!>          Especifica si se proporciona la parte triangular superior o inferior
!>          de la matriz de banda A.
!>          = 'U':  Se proporciona la parte triangular superior
!>          = 'L':  Se proporciona la parte triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, DLANSB se
!>          establece a cero.
!>

K

!>          K es INTEGER
!>          El número de super-diagonales o sub-diagonales de la
!>          matriz de banda A.  K >= 0.
!>

AB

!>          AB es un array DOUBLE PRECISION, dimensión (LAB,N)
!>          La parte superior o inferior de la matriz de banda simétrica A,
!>          almacenada en las primeras K+1 filas de AB. La j-ésima columna de A
!>          se almacena en la j-ésima columna del array AB de la siguiente
!>          manera:
!>          si UPO = 'U', AB(k+1+i-j,j) = A(i,j) para max(1,j-k)<=i<=j;
!>          si UPO = 'L', AB(1+i-j,j)   = A(i,j) para j<=i<=min(n,j+k).
!>

LAB

!>          LAB es INTEGER
!>          La dimensión principal del array AB.  LAB >= K+1.
!>

TRABAJO

!>          TRABAJO es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I' o '1' o 'O'; en caso contrario,
!>          TRABAJO no se hace referencia.
!>
