subroutine dlasq5 (i0, n0, z, pp, tau, sigma, dmin, dmin1, dmin2, dn, dnm1, dnm2, ieee, eps)
DLASQ5 calcula una transformación dqds en forma de ping-pong. Usado por sbdsqr y sstegr.

Documentación de Función/Subrutina

subroutine dlasq5 (integer i0, integer n0, double precision, dimension( * ) z, integer pp, double precision tau, double precision sigma, double precision dmin, double precision dmin1, double precision dmin2, double precision dn, double precision dnm1, double precision dnm2, logical ieee, double precision eps)

DLASQ5 calcula una transformación dqds en forma de ping-pong, una versión para máquinas IEEE y otra para máquinas no IEEE.

Propósito:

!>
!> DLASQ5 calcula una transformación dqds en forma de ping-pong, una
!> versión para máquinas IEEE y otra para máquinas no IEEE.
!>

Parámetros

I0 
!>          I0 es ENTERO
!>        Primer índice.
!>

N0

!>          N0 es ENTERO
!>        Último índice.
!>

Z

!>          Z es un array de DOBLE PRECISIÓN, de dimensión ( 4*N )
!>        Z contiene el array qd. EMIN se almacena en Z(4*N0) para evitar
!>        un argumento adicional.
!>

PP

!>          PP es ENTERO
!>        PP=0 para ping, PP=1 para pong.
!>

TAU

!>          TAU es DOBLE PRECISIÓN
!>        Este es el desplazamiento.
!>

SIGMA

!>          SIGMA es DOBLE PRECISIÓN
!>        Este es el desplazamiento acumulado hasta este paso.
!>

DMIN

!>          DMIN es DOBLE PRECISIÓN
!>        Valor mínimo de d.
!>

DMIN1

!>          DMIN1 es DOBLE PRECISIÓN
!>        Valor mínimo de d, excluyendo D( N0 ).
!>

DMIN2

!>          DMIN2 es DOBLE PRECISIÓN
!>        Valor mínimo de d, excluyendo D( N0 ) y D( N0-1 ).
!>

DN

!>          DN es DOBLE PRECISIÓN
!>        d(N0), el último valor de d.
!>

DNM1

!>          DNM1 es DOBLE PRECISIÓN
!>        d(N0-1).
!>

DNM2

!>          DNM2 es DOBLE PRECISIÓN
!>        d(N0-2).
!>

IEEE

!>          IEEE es LÓGICO
!>        Indicador para aritmética IEEE o no IEEE.
!>

EPS

!>          EPS es DOBLE PRECISIÓN
!>        Este es el valor de épsilon utilizado.
!>
