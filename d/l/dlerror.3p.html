DLERROR(3P) Manual del programador POSIX DLERROR(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

dlerror — obtener información de diagnóstico

SINOPSIS

#include <dlfcn.h>
char *dlerror(void);

DESCRIPCION

La función dlerror() devolverá una cadena de caracteres terminada en nulo (sin un <salto de línea> al final) que describe el último error que ocurrió durante el procesamiento de enlaces dinámicos. Si no se han producido errores de enlace dinámico desde la última invocación de dlerror(), dlerror() devolverá NULL. Por lo tanto, invocar dlerror() una segunda vez, inmediatamente después de una invocación anterior, resultará en que se devuelva NULL.

Es responsabilidad de la implementación determinar si la función dlerror() es segura para hilos. Una implementación segura para hilos devolverá solo los errores que ocurran en el hilo actual.

VALOR DE RETORNO

Si tiene éxito, dlerror() devolverá una cadena de caracteres terminada en nulo; de lo contrario, se devolverá NULL.

La aplicación no debe modificar la cadena devuelta. El puntero devuelto puede ser invalidado o el contenido de la cadena puede ser sobrescrito por una llamada posterior a dlerror() en el mismo hilo (si dlerror() es segura para hilos) o en cualquier hilo (si dlerror() no es segura para hilos). El puntero devuelto también puede ser invalidado si el hilo que llama termina.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

El siguiente ejemplo imprime el último error de enlace dinámico:

...
#include <dlfcn.h>
char *errstr;
errstr = dlerror();
if (errstr != NULL)
    printf ("Ocurrió un error de enlace dinámico: (%s)\n", errstr);
...

USO DE APLICACION

Dependiendo del entorno de la aplicación con respecto a eventos de ejecución asíncronos, como señales u otros cálculos asíncronos que comparten el espacio de direcciones, las aplicaciones conformes deben utilizar una sección crítica para recuperar el puntero de error y el búfer.
