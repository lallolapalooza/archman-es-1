función de precisión doble dlanst (norma, n, d, e)

DLANST devuelve el valor de la norma 1, o la norma de Frobenius, o la norma del infinito, o el elemento de mayor valor absoluto de una matriz real simétrica tridiagonal.

Documentación de la función/subrutina

double precision function dlanst (character norm, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e)

DLANST devuelve el valor de la norma 1, o la norma de Frobenius, o la norma del infinito, o el elemento de mayor valor absoluto de una matriz real simétrica tridiagonal A.

Propósito:

!>
!> DLANST  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma del infinito, o el elemento de mayor valor absoluto de una
!> matriz real simétrica tridiagonal A.
!>

Devuelve

DLANST 
!>
!>    DLANST = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la norma uno de una matriz (suma máxima de columnas),
!> normI  denota la norma del infinito de una matriz (suma máxima de filas) y
!> normF  denota la norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en DLANST como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, DLANST se
!>          establece a cero.
!>

D

!>          D es un array DOUBLE PRECISION, dimension (N)
!>          Los elementos diagonales de A.
!>

E

!>          E es un array DOUBLE PRECISION, dimension (N-1)
!>          Los elementos (n-1) sub-diagonales o super-diagonales de A.
!>
