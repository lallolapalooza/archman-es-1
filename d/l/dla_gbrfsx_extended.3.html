subrutina dla_gbrfsx_extended (integer prec_type, integer trans_type, integer n, integer kl, integer ku, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldy, * ) y, integer ldy, double precision, dimension(*) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, double precision, dimension(*) res, double precision, dimension(*) ayb, double precision, dimension(*) dy, double precision, dimension(*) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

DLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices generales con banda realizando un refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!>
!> DLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión
!> extra y proporciona límites de error y estimaciones de error hacia
!> atrás para la solución. Esta subrutina es llamada por DGBRFSX para
!> realizar el refinamiento iterativo. Además del límite de error en
!> norma, el código proporciona un límite de error componente a componente
!> máximo si es posible. Véanse los comentarios para ERR_BNDS_NORM y
!> ERR_BNDS_COMP para más detalles sobre los límites de error. Nótese que
!> esta subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a usar en el refinamiento.
!>     El valor está definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple (Single)
!>          = 'D':  Doble (Double)
!>          = 'I':  Indígena (Indigenous)
!>          = 'X' o 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición sobre A.
!>     El valor está definido por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transponer
!>          = 'T':  Transponer
!>          = 'C':  Transponer con conjugado
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0
!>

NRHS

!>          NRHS es INTEGER
!>     El número de miembros independientes (right-hand-sides), es decir, el número de columnas de la
!>     matriz B.
!>

AB

!>          AB es un array DOUBLE PRECISION, dimensión (LDAB,N)
!>          A la entrada, la matriz AB de N por N.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDBA >= max(1,N).
!>

AFB

!>          AFB es un array DOUBLE PRECISION, dimensión (LDAFB,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U tal como los calcula DGBTRF.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AF.  LDAFB >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Los índices de permutación de la factorización A = P*L*U
!>     tal como los calcula DGBTRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE., entonces se realizó un equilibrado de columnas a A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y los
!>     límites de error correctamente.
!>

C

!>          C es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no es accedido. Si C es de entrada, cada elemento de C debería ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos que
!>     el resultado se desborde por arriba o por abajo. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>     La matriz de miembros independientes B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es un array DOUBLE PRECISION, dimensión (LDY,NRHS)
!>     A la entrada, la matriz solución X, tal como la calcula DGBTRS.
!>     A la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un array DOUBLE PRECISION, dimensión (NRHS)
!>     A la salida, BERR_OUT(j) contiene el error relativo hacia atrás
!>     componente a componente para el miembro independiente j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto es calculado por DLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (véanse ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve límites de error en norma.
!>     Si N_NORMS >= 2 devuelve límites de error componente a componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada miembro independiente, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Normise relative error in the ith solution vector:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error como se
!>     describe a continuación. Actualmente se devuelven hasta tres piezas
!>     de información.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado en norma. Se compara con el umbral
!>              sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de
!>              la base para que todas las sumas absolutas de filas de Z
!>              sean aproximadamente 1.
!>
!>     Este subrutina solo es responsable de establecer el segundo campo
!>     anterior.
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array de tipo DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector de
!>     solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array está indexado por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información
!>     de error como se describe a continuación. Actualmente se devuelven
!>     hasta tres piezas de información para cada lado derecho. Si no se
!>     solicita precisión componente a componente (PARAMS(3) = 0.0), no se
!>     accede a ERR_BNDS_COMP. Si N_ERR_BNDS < 3, se devuelven como
!>     máximo las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Número de condición
!>              recíproco estimado componente a componente. Se compara
!>              con el umbral sqrt(n) * slamch('Epsilon') para determinar
!>              si la estimación de error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para
!>              alguna matriz Z escalada adecuadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de A*diag(x) por
!>              una potencia de la base para que todas las sumas absolutas
!>              de filas de Z sean aproximadamente 1.
!>
!>     Este subrutina solo es responsable de establecer el segundo campo
!>     anterior.
!>     Vea Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

RES

!>          RES es un array de tipo DOUBLE PRECISION, dimensión (N)
!>     Espacio de trabajo para mantener el residual intermedio.
!>

AYB

!>          AYB es un array de tipo DOUBLE PRECISION, dimensión (N)
!>     Espacio de trabajo. Este puede ser el mismo espacio de trabajo
!>     pasado para Y_TAIL.
!>

DY

!>          DY es un array de tipo DOUBLE PRECISION, dimensión (N)
!>     Espacio de trabajo para mantener la solución intermedia.
!>

Y_TAIL

!>          Y_TAIL es un array de tipo DOUBLE PRECISION, dimensión (N)
!>     Espacio de trabajo para mantener los bits de orden inferior de la
!>     solución intermedia.
!>

RCOND

!>          RCOND es de tipo DOUBLE PRECISION
!>     Número de condición recíproco escalado. Esta es una estimación del
!>     número de condición recíproco de Skeel de la matriz A después de
!>     la equilibración (si se hizo). Si es menor que la precisión de la
!>     máquina (en particular, si es cero), la matriz es singular hasta
!>     la precisión de trabajo. Tenga en cuenta que el error puede seguir
!>     siendo pequeño incluso si este número es muy pequeño y la matriz
!>     parece mal condicionada.
!>

ITHRESH

!>          ITHRESH es de tipo INTEGER
!>     El número máximo de cálculos de residuo permitidos para el
!>     refinamiento. El valor predeterminado es 10. Para 'aggressive'
!>     establezca en 100 para permitir la convergencia usando
!>     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>     la factorización usa una técnica distinta de la eliminación
!>     gaussiana, las garantías en ERR_BNDS_NORM y ERR_BNDS_COMP pueden
!>     dejar de ser confiables.
!>

RTHRESH

!>          RTHRESH es de tipo DOUBLE PRECISION
!>     Determina cuándo detener el refinamiento si la estimación de error
!>     deja de disminuir. El refinamiento se detendrá cuando la
!>     siguiente solución ya no satisfaga norm(dx_{i+1}) < RTHRESH *
!>     norm(dx_i) donde norm(Z) es la norma infinita de Z. RTHRESH
!>     satisface 0 < RTHRESH <= 1. El valor predeterminado es 0.5. Para
!>     'aggressive' establezca en 0.9 para permitir la convergencia en
!>     matrices extremadamente mal condicionadas. Vea LAWN 165 para más
!>     detalles.
!>

DZ_UB

!>          DZ_UB es de tipo DOUBLE PRECISION
!>     Determina cuándo empezar a considerar la convergencia componente a
!>     componente. La convergencia componente a componente solo se
!>     considera después de que cada componente de la solución Y sea
!>     estable, lo cual definimos como el cambio relativo en cada
!>     componente siendo menor que DZ_UB. El valor predeterminado es
!>     0.25, requiriendo que el primer bit sea estable. Vea LAWN 165 para
!>     más detalles.
!>

IGNORE_CWISE

!>          IGNORE_CWISE es de tipo LOGICAL
!>     Si es .TRUE. entonces ignorar la convergencia componente a
!>     componente. El valor predeterminado es .FALSE..
!>

INFO

!>          INFO es de tipo INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  si INFO = -i, el i-ésimo argumento a DGBTRS tenía un
!>             valor ilegal
!>
