Documentación de función/subrutina

subrutina dlaein (logical rightv, logical noinit, integer n, double precision, dimension( ldh, * ) h, integer ldh, double precision wr, double precision wi, double precision, dimension( * ) vr, double precision, dimension( * ) vi, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) work, double precision eps3, double precision smlnum, double precision bignum, integer info)

DLAEIN calcula un vector propio derecho o izquierdo especificado de una matriz de Hessenberg superior mediante iteración inversa.

Propósito:

!>
!> DLAEIN usa iteración inversa para encontrar un vector propio derecho o izquierdo
!> correspondiente al valor propio (WR,WI) de una matriz H de Hessenberg superior real.
!>

Parámetros

RIGHTV 
!>          RIGHTV es LOGICAL
!>          = .TRUE. : calcular vector propio derecho;
!>          = .FALSE.: calcular vector propio izquierdo.
!>

NOINIT

!>          NOINIT es LOGICAL
!>          = .TRUE. : no se suministra vector inicial en (VR,VI).
!>          = .FALSE.: se suministra vector inicial en (VR,VI).
!>

N

!>          N es INTEGER
!>          El orden de la matriz H.  N >= 0.
!>

H

!>          H es un array de DOUBLE PRECISION, dimensión (LDH,N)
!>          La matriz de Hessenberg superior H.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H.  LDH >= max(1,N).
!>

WR

!>          WR es DOUBLE PRECISION
!>

WI

!>          WI es DOUBLE PRECISION
!>          Las partes real e imaginaria del valor propio de H cuyo
!>          vector propio derecho o izquierdo correspondiente se debe calcular.
!>

VR

!>          VR es un array de DOUBLE PRECISION, dimensión (N)
!>

VI

!>          VI es un array de DOUBLE PRECISION, dimensión (N)
!>          En la entrada, si NOINIT = .FALSE. y WI = 0.0, VR debe contener
!>          un vector de inicio real para la iteración inversa usando el valor
!>          propio real WR; si NOINIT = .FALSE. y WI.ne.0.0, VR y VI
!>          deben contener las partes real e imaginaria de un vector
!>          de inicio complejo para la iteración inversa usando el valor
!>          propio complejo (WR,WI); de lo contrario, VR y VI no necesitan
!>          ser establecidos.
!>          En la salida, si WI = 0.0 (valor propio real), VR contiene el
!>          vector propio real calculado; si WI.ne.0.0 (valor propio complejo),
!>          VR y VI contienen las partes real e imaginaria del vector
!>          propio complejo calculado. El vector propio se normaliza
!>          de modo que el componente de mayor magnitud tenga magnitud 1;
!>          aquí la magnitud de un número complejo (x,y) se toma como
!>          |x| + |y|.
!>          VI no se referencia si WI = 0.0.
!>

B

!>          B es un array de DOUBLE PRECISION, dimensión (LDB,N)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= N+1.
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (N)
!>

EPS3

!>          EPS3 es DOUBLE PRECISION
!>          Un pequeño valor dependiente de la máquina que se utiliza para perturbar
!>          valores propios cercanos y para reemplazar pivotes cero.
!>

SMLNUM

!>          SMLNUM es DOUBLE PRECISION
!>          Un valor dependiente de la máquina cercano al umbral de subdesbordamiento.
!>

BIGNUM

!>          BIGNUM es DOUBLE PRECISION
!>          Un valor dependiente de la máquina cercano al umbral de desbordamiento.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          = 1:  la iteración inversa no convergió; VR se establece en el
!>                último iterante, y también VI si WI.ne.0.0.
!>
