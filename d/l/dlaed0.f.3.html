subrutina dlaed0 (icompq, qsiz, n, d, e, q, ldq, qstore, ldqs, work, iwork, info)


DLAED0 utilizada por DSTEDC. Calcula todos los valores propios y los vectores propios correspondientes de una matriz tridiagonal simétrica no reducida utilizando el método de divide y vencerás.

Documentación de función/subrutina

subrutina dlaed0 (integer icompq, integer qsiz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldqs, * ) qstore, integer ldqs, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLAED0 utilizada por DSTEDC. Calcula todos los valores propios y los vectores propios correspondientes de una matriz tridiagonal simétrica no reducida utilizando el método de divide y vencerás.

Propósito:

!>
!> DLAED0 calcula todos los valores propios y los vectores propios correspondientes de
!> una matriz tridiagonal simétrica utilizando el método de divide y vencerás.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>          = 0:  Calcula solo los valores propios.
!>          = 1:  Calcula también los vectores propios de la matriz simétrica densa
!>                original.  En la entrada, Q contiene la matriz ortogonal utilizada
!>                para reducir la matriz original a forma tridiagonal.
!>          = 2:  Calcula los valores propios y los vectores propios de la matriz
!>                tridiagonal.
!>

QSIZ

!>          QSIZ es INTEGER
!>         La dimensión de la matriz ortogonal utilizada para reducir
!>         la matriz completa a forma tridiagonal.  QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es array de DOUBLE PRECISION, dimension (N)
!>         En la entrada, la diagonal principal de la matriz tridiagonal.
!>         En la salida, sus valores propios.
!>

E

!>          E es array de DOUBLE PRECISION, dimension (N-1)
!>         Los elementos fuera de la diagonal de la matriz tridiagonal.
!>         En la salida, E ha sido destruido.
!>

Q

!>          Q es array de DOUBLE PRECISION, dimension (LDQ, N)
!>         En la entrada, Q debe contener una matriz ortogonal N x N.
!>         Si ICOMPQ = 0    Q no se referencia.
!>         Si ICOMPQ = 1    En la entrada, Q es un subconjunto de las columnas de la
!>                          matriz ortogonal utilizada para reducir la matriz
!>                          completa a forma tridiagonal, correspondiente
!>                          al subconjunto de la matriz completa que se
!>                          está descomponiendo en este momento.
!>         Si ICOMPQ = 2    En la entrada, Q será la matriz identidad.
!>                          En la salida, Q contiene los vectores propios de la
!>                          matriz tridiagonal.
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q. Si se desean vectores propios,
!>         entonces LDQ >= max(1,N). En cualquier caso, LDQ >= 1.
!>

QSTORE

!>          QSTORE es array de DOUBLE PRECISION, dimension (LDQS, N)
!>         Se referencia solo cuando ICOMPQ = 1. Se utiliza para almacenar partes
!>         de la matriz de vectores propios cuando tienen lugar las multiplicaciones
!>         de actualización.
!>

LDQS

!>          LDQS es INTEGER
!>         La dimensión principal del array QSTORE. Si ICOMPQ = 1,
!>         entonces LDQS >= max(1,N). En cualquier caso, LDQS >= 1.
!>

WORK

!>          WORK es array de DOUBLE PRECISION,
!>         Si ICOMPQ = 0 o 1, la dimensión de WORK debe ser al menos
!>                     1 + 3*N + 2*N*lg N + 3*N**2
!>                     ( lg( N ) = el entero más pequeño k
!>                                 tal que 2^k >= N )
!>         Si ICOMPQ = 2, la dimensión de WORK debe ser al menos
!>                     4*N + N**2.
!>

IWORK

!>          IWORK es array de INTEGER,
!>         Si ICOMPQ = 0 o 1, la dimensión de IWORK debe ser al menos
!>                        6 + 6*N + 5*N*lg N.
!>                        ( lg( N ) = el entero más pequeño k
!>                                    tal que 2^k >= N )
!>         Si ICOMPQ = 2, la dimensión de IWORK debe ser al menos
!>                        3 + 5*N.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo falló al calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>
