DLARRB proporciona bisección limitada para localizar autovalores con mayor precisión.

subrutina dlarrb (integer n, double precision, dimension( * ) d, double precision, dimension( * ) lld, integer ifirst, integer ilast, double precision rtol1, double precision rtol2, integer offset, double precision, dimension( * ) w, double precision, dimension( * ) wgap, double precision, dimension( * ) werr, double precision, dimension( * ) work, integer, dimension( * ) iwork, double precision pivmin, double precision spdiam, integer twist, integer

DLARRB proporciona bisección limitada para localizar autovalores con mayor

precisión.

Propósito

: 
!>
!> Dada la representación robusta relativamente (RRR) L D L^T, DLARRB
!> realiza una bisección para refinar los autovalores de L D L^T,
!> W( IFIRST-OFFSET ) a través de W( ILAST-OFFSET ), con mayor precisión. Las
!> conjeturas iniciales para estos autovalores se introducen en W, la
!> estimación correspondiente del error en estas conjeturas y sus huecos se
!> introducen en WERR y WGAP, respectivamente. Durante la bisección, los
!> intervalos [left, right] se mantienen almacenando sus puntos medios y
!> semianchos en los arreglos W y WERR respectivamente.
!
>

Parámetro

s
N 
!>          N es INTEGER
!>          El orden de la matriz.
!
>

D 
!>          D es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Los N elementos diagonales de la matriz diagonal D.
!
>

LL

D 
!>          LLD es un arreglo DOUBLE PRECISION, dimensión (N-1)
!>          Los (N-1) elementos L(i)*L(i)*D(i).
!
>

IFIRS

T 
!>          IFIRST es INTEGER
!>          El índice del primer autovalor a calcular.
!
>

ILAS

T 
!>          ILAST es INTEGER
!>          El índice del último autovalor a calcular.
!
>

RTOL

1 
!>          RTOL1 es DOUBLE PRECISION
!
>

RTOL

2 
!>          RTOL2 es DOUBLE PRECISION
!>          Tolerancia para la convergencia de los intervalos de bisección.
!>          Un intervalo [LEFT,RIGHT] ha convergido si
!>          RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>          donde GAP es la distancia (estimada) al autovalor
!>          más cercano.
!
>

OFFSE

T 
!>          OFFSET es INTEGER
!>          Desplazamiento para los arreglos W, WGAP y WERR, es decir, se
!>          deben usar los elementos de estos arreglos desde IFIRST-OFFSET
!>          hasta ILAST-OFFSET.
!
>

W 
!>          W es un arreglo DOUBLE PRECISION, dimensión (N)
!>          En la entrada, W( IFIRST-OFFSET ) a través de W( ILAST-OFFSET ) son
!>          estimaciones de los autovalores de L D L^T indexados desde IFIRST
!>          hasta ILAST.
!>          En la salida, estas estimaciones se refinan.
!
>

WGA

P 
!>          WGAP es un arreglo DOUBLE PRECISION, dimensión (N-1)
!>          En la entrada, los huecos (estimados) entre autovalores
!>          consecutivos de L D L^T, es decir, WGAP(I-OFFSET) es el hueco entre
!>          los autovalores I e I+1. Tenga en cuenta que si IFIRST = ILAST
!>          entonces WGAP(IFIRST-OFFSET) debe establecerse en ZERO.
!>          En la salida, estos huecos se refinan.
!
>

WER

R 
!>          WERR es un arreglo DOUBLE PRECISION, dimensión (N)
!>          En la entrada, WERR( IFIRST-OFFSET ) a través de WERR( ILAST-OFFSET ) son
!>          los errores en las estimaciones de los elementos correspondientes en W.
!>          En la salida, estos errores se refinan.
!
>

WOR

K 
!>          WORK es un arreglo DOUBLE PRECISION, dimensión (2*N)
!>          Espacio de trabajo.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (2*N)
!>          Espacio de trabajo.
!
>

PIVMI

N 
!>          PIVMIN es DOUBLE PRECISION
!>          El pivote mínimo en la secuencia de Sturm.
!
>

SPDIA

M 
!>          SPDIAM es DOUBLE PRECISION
!>          El diámetro espectral de la matriz.
!
>

TWIS

T 
!>          TWIST es INTEGER
!>          El índice de torsión para la factorización retorcida que se usa
!>          para el negcount.
!>          TWIST = N: Calcular negcount desde L D L^T - LAMBDA I = L+ D+ L+^T
!>          TWIST = 1: Calcular negcount desde L D L^T - LAMBDA I = U- D- U-^T
!>          TWIST = R: Calcular negcount desde L D L^T - LAMBDA I = N(r) D(r) N(r)
!
>

INF

O 
!>          INFO es INTEGER
!>          Indicador de error.
!
>
