DLA_GERCOND estima el número de condición de Skeel para una matriz general.

función de doble precisión dla_gercond (carácter trans, entero n, doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, entero cmode, doble precisión, dimensión( * ) c, entero info, doble precisión, dimensión( * ) work, entero, dimensión( * ) iwork)

DLA_GERCOND estima el número de condición de Skeel para una matriz general.

Propósito:

!>
!>    DLA_GERCOND estima el número de condición de Skeel de op(A) * op2(C)
!>    donde op2 se determina por CMODE como sigue:
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel cond(A) = norminf( |inv(A)||A| )
!>    se calcula obteniendo factores de escala R tales que
!>    diag(R)*A*op2(C) está equilibrado por filas y calculando el número
!>    de condición estándar de la norma infinito.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transpuesta)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array de DOUBLE PRECISION, dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U calculada por DGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array de INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     calculada por DGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

CMODE

!>          CMODE es INTEGER
!>     Determina op2(C) en la fórmula op(A) * op2(C) como sigue:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es un array de DOUBLE PRECISION, dimensión (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (3*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es un array de INTEGER, dimensión (N).
!>     Espacio de trabajo.
!>
