DLATM3

Propósito:

!>
!>    DLATM3 devuelve la entrada (ISUB,JSUB) de una matriz aleatoria de
!>    dimensión (M, N) descrita por los otros parámetros. (ISUB,JSUB)
!>    es la posición final de la entrada (I,J) después de la permutación
!>    según IPVTNG e IWORK. DLATM3 es llamada por la
!>    rutina DLATMR para construir matrices de prueba aleatorias. No se realiza
!>    verificación de errores en los parámetros, porque esta rutina es llamada en
!>    un bucle cerrado por DLATMR que ya ha verificado los parámetros.
!>
!>    El uso de DLATM3 difiere de SLATM2 en el orden en que el
!>    generador de números aleatorios es llamado para rellenar las entradas aleatorias
!>    de la matriz. Con DLATM2, el generador es llamado para rellenar la
!>    matriz pivoteada columna por columna. Con DLATM3, el generador es llamado para rellenar la
!>    matriz columna por columna, después de lo cual es pivoteada. Así, DLATM3 puede
!>    ser usada para construir matrices aleatorias que difieren solo en su
!>    orden de filas y/o columnas. DLATM2 es usada para construir matrices de banda
!>    mientras se evita llamar al generador de números aleatorios para
!>    entradas fuera de la banda (y por lo tanto generando números aleatorios
!>    en diferentes órdenes para diferentes órdenes de pivoteo).
!>
!>    La matriz cuya entrada (ISUB,JSUB) es devuelta es construida como
!>    sigue (esta rutina solo calcula una entrada):
!>
!>      Si ISUB está fuera de (1..M) o JSUB está fuera de (1..N), devolver cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Generar una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establecer la diagonal a D.
!>
!>      Escalar la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) como se especifica por IGRADE.
!>
!>      Permutar, si se desea, las filas y/o columnas como se especifica por
!>         IPVTNG e IWORK.
!>
!>      Convertir la matriz en banda para tener ancho de banda inferior KL y ancho
!>         de banda superior KU.
!>
!>      Establecer entradas aleatorias a cero como se especifica por SPARSE.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de la matriz. No modificado.
!>

N

!>          N es INTEGER
!>           Número de columnas de la matriz. No modificado.
!>

I

!>          I es INTEGER
!>           Fila de la entrada no pivoteada a ser devuelta. No modificado.
!>

J

!>          J es INTEGER
!>           Columna de la entrada no pivoteada a ser devuelta. No modificado.
!>

ISUB

!>          ISUB es INTEGER
!>           Fila de la entrada pivoteada a ser devuelta. Modificado en la salida.
!>

JSUB

!>          JSUB es INTEGER
!>           Columna de la entrada pivoteada a ser devuelta. Modificado en la salida.
!>

KL

!>          KL es INTEGER
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU es INTEGER
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST es INTEGER
!>           En la entrada, IDIST especifica el tipo de distribución a ser
!>           usada para generar una matriz aleatoria.
!>           1 => UNIFORM( 0, 1 )
!>           2 => UNIFORM( -1, 1 )
!>           3 => NORMAL( 0, 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es un arreglo INTEGER de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Modificado en la salida.
!>

D

!>          D es un arreglo DOUBLE PRECISION de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificado.
!>

IGRADE

!>          IGRADE es INTEGER
!>           Especifica el escalado de la matriz como sigue:
!>           0  => sin escalado
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL es un arreglo DOUBLE PRECISION ( I o J, según corresponda )
!>           Factores de escala izquierdos para escalar la matriz. No modificado.
!>

DR

!>          DR es un arreglo DOUBLE PRECISION ( I o J, según corresponda )
!>           Factores de escala derechos para escalar la matriz. No modificado.
!>

IPVTNG

!>          IPVTNG es INTEGER
!>           En la entrada especifica las permutaciones de pivoteo como sigue:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK es un arreglo INTEGER ( I o J, según corresponda )
!>           Este arreglo especifica la permutación usada. La
!>           fila (o columna) originalmente en la posición K está en
!>           la posición IWORK( K ) después del pivoteo.
!>           Esto difiere de IWORK para DLATM2. No modificado.
!>

SPARSE

!>          SPARSE es DOUBLE PRECISION entre 0. y 1.
!>           En la entrada especifica la dispersión de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme ( 0, 1 ) x y se
!>           compara con SPARSE; si x es mayor la entrada de la matriz
!>           no cambia y si x es menor la entrada se establece
!>           a cero. Así en promedio una fracción SPARSE de las
!>           entradas será establecida a cero.
!>           No modificado.
!>
