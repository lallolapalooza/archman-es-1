subrutina dlasr (side, pivot, direct, m, n, c, s, a, lda)
DLASR aplica una secuencia de rotaciones de plano a una matriz rectangular general.

Documentación de la Función/Subrutina

subrutina dlasr (character side, character pivot, character direct, integer m, integer n, double precision, dimension( * ) c, double precision, dimension( * ) s, double precision, dimension( lda, * ) a, integer lda)

DLASR aplica una secuencia de rotaciones de plano a una matriz real A, ya sea desde la izquierda o desde la derecha.

Propósito:

!>
!> DLASR aplica una secuencia de rotaciones de plano a una matriz real A,
!> desde la izquierda o la derecha.
!>
!> Cuando SIDE = 'L', la transformación toma la forma
!>
!>    A := P*A
!>
!> y cuando SIDE = 'R', la transformación toma la forma
!>
!>    A := A*P**T
!>
!> donde P es una matriz ortogonal que consiste en una secuencia de z rotaciones
!> de plano, con z = M si SIDE = 'L' y z = N si SIDE = 'R',
!> y P**T es la transpuesta de P.
!>
!> Cuando DIRECT = 'F' (secuencia hacia adelante), entonces
!>
!>    P = P(z-1) * ... * P(2) * P(1)
!>
!> y cuando DIRECT = 'B' (secuencia hacia atrás), entonces
!>
!>    P = P(1) * P(2) * ... * P(z-1)
!>
!> donde P(k) es una matriz de rotación de plano definida por la rotación
!> de 2x2
!>
!>    R(k) = (  c(k)  s(k) )
!>         = ( -s(k)  c(k) ).
!>
!> Cuando PIVOT = 'V' (pivote variable), la rotación se realiza
!> para el plano (k,k+1), es decir, P(k) tiene la forma
!>
!>    P(k) = (  1                                            )
!>           (       ...                                     )
!>           (              1                                )
!>           (                   c(k)  s(k)                  )
!>           (                  -s(k)  c(k)                  )
!>           (                                1              )
!>           (                                     ...       )
!>           (                                            1  )
!>
!> donde R(k) aparece como una modificación de rango 2 a la matriz identidad
!> en las filas y columnas k y k+1.
!>
!> Cuando PIVOT = 'T' (pivote superior), la rotación se realiza
!> para el plano (1,k+1), por lo que P(k) tiene la forma
!>
!>    P(k) = (  c(k)                    s(k)                 )
!>           (         1                                     )
!>           (              ...                              )
!>           (                     1                         )
!>           ( -s(k)                    c(k)                 )
!>           (                                 1             )
!>           (                                      ...      )
!>           (                                             1 )
!>
!> donde R(k) aparece en las filas y columnas 1 y k+1.
!>
!> Del mismo modo, cuando PIVOT = 'B' (pivote inferior), la rotación
!> se realiza para el plano (k,z), dando a P(k) la forma
!>
!>    P(k) = ( 1                                             )
!>           (      ...                                      )
!>           (             1                                 )
!>           (                  c(k)                    s(k) )
!>           (                         1                     )
!>           (                              ...              )
!>           (                                     1         )
!>           (                 -s(k)                    c(k) )
!>
!> donde R(k) aparece en las filas y columnas k y z. Las rotaciones se
!> realizan sin formar explícitamente P(k).
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          Especifica si la matriz de rotación de plano P se aplica
!>          a A por la izquierda o por la derecha.
!>          = 'L':  Izquierda, calcular A := P*A
!>          = 'R':  Derecha, calcular A:= A*P**T
!>

PIVOT

!>          PIVOT es CHARACTER*1
!>          Especifica el plano para el cual P(k) es una matriz de rotación
!>          de plano.
!>          = 'V':  Pivote variable, el plano (k,k+1)
!>          = 'T':  Pivote superior, el plano (1,k+1)
!>          = 'B':  Pivote inferior, el plano (k,z)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Especifica si P es una secuencia hacia adelante o hacia atrás
!>          de rotaciones de plano.
!>          = 'F':  Adelante, P = P(z-1)*...*P(2)*P(1)
!>          = 'B':  Atrás, P = P(1)*P(2)*...*P(z-1)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. Si m <= 1, se produce un retorno
!>          inmediato.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. Si n <= 1, se produce un retorno
!>          inmediato.
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Los cosenos c(k) de las rotaciones de plano.
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Los senos s(k) de las rotaciones de plano. La parte de rotación
!>          de plano de 2x2 de la matriz P(k), R(k), tiene la forma
!>          R(k) = (  c(k)  s(k) )
!>                 ( -s(k)  c(k) ).
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          La matriz A de M por N. A la salida, A se sobrescribe con P*A si
!>          SIDE = 'L' o con A*P**T si SIDE = 'R'.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>
