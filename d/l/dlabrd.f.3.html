DLABRD reduce las primeras nb filas y columnas de una matriz general a una forma bidiagonal.

Documentación de Función/Subrutina

subrutina dlabrd (integer m, integer n, integer nb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) tauq, double precision, dimension( * ) taup, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldy, * ) y, integer ldy)

DLABRD reduce las primeras nb filas y columnas de una matriz general a una forma bidiagonal.

Propósito:

!>
!> DLABRD reduce las primeras NB filas y columnas de una matriz real general
!> A de m por n a forma bidiagonal superior o inferior mediante una
!> transformación ortogonal Q**T * A * P, y devuelve las matrices X e Y
!> que se necesitan para aplicar la transformación a la parte no reducida de A.
!>
!> Si m >= n, A se reduce a forma bidiagonal superior; si m < n, a forma
!> bidiagonal inferior.
!>
!> Esta es una rutina auxiliar llamada por DGEBRD
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas en la matriz A.
!>

N

!>          N es INTEGER
!>          El número de columnas en la matriz A.
!>

NB

!>          NB es INTEGER
!>          El número de filas y columnas iniciales de A que se reducirán.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz general de m por n a reducir.
!>          En la salida, las primeras NB filas y columnas de la matriz son
!>          sobrescritas; el resto del array no cambia.
!>          Si m >= n, los elementos en y por debajo de la diagonal en las primeras NB
!>            columnas, con el array TAUQ, representan la matriz ortogonal
!>            Q como un producto de reflectores elementales; y
!>            los elementos por encima de la diagonal en las primeras NB filas, con el
!>            array TAUP, representan la matriz ortogonal P como un producto
!>            de reflectores elementales.
!>          Si m < n, los elementos por debajo de la diagonal en las primeras NB
!>            columnas, con el array TAUQ, representan la matriz ortogonal
!>            Q como un producto de reflectores elementales, y
!>            los elementos en y por encima de la diagonal en las primeras NB filas,
!>            con el array TAUP, representan la matriz ortogonal P como
!>            un producto de reflectores elementales.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (NB)
!>          Los elementos diagonales de las primeras NB filas y columnas de
!>          la matriz reducida.  D(i) = A(i,i).
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (NB)
!>          Los elementos fuera de la diagonal de las primeras NB filas y columnas de
!>          la matriz reducida.
!>

TAUQ

!>          TAUQ es un array DOUBLE PRECISION, dimensión (NB)
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz ortogonal Q. Ver Detalles Adicionales.
!>

TAUP

!>          TAUP es un array DOUBLE PRECISION, dimensión (NB)
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz ortogonal P. Ver Detalles Adicionales.
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (LDX,NB)
!>          La matriz X de m por nb requerida para actualizar la parte no reducida
!>          de A.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,M).
!>

Y

!>          Y es un array DOUBLE PRECISION, dimensión (LDY,NB)
!>          La matriz Y de n por nb requerida para actualizar la parte no reducida
!>          de A.
!>

LDY

!>          LDY es INTEGER
!>          La dimensión principal del array Y. LDY >= max(1,N).
!>

Detalles Adicionales:

!>
!>  Las matrices Q y P se representan como productos de reflectores
!>  elementales:
!>
!>     Q = H(1) H(2) . . . H(nb)  y  P = G(1) G(2) . . . G(nb)
!>
!>  Cada H(i) y G(i) tiene la forma:
!>
!>     H(i) = I - tauq * v * v**T  y G(i) = I - taup * u * u**T
!>
!>  donde tauq y taup son escalares reales, y v y u son vectores reales.
!>
!>  Si m >= n, v(1:i-1) = 0, v(i) = 1, y v(i:m) se almacena en la salida en
!>  A(i:m,i); u(1:i) = 0, u(i+1) = 1, y u(i+1:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Si m < n, v(1:i) = 0, v(i+1) = 1, y v(i+1:m) se almacena en la salida en
!>  A(i+2:m,i); u(1:i-1) = 0, u(i) = 1, y u(i:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Los elementos de los vectores v y u juntos forman la matriz V de m por nb
!>  y la matriz U**T de nb por n que se necesitan, junto con X e Y, para aplicar
!>  la transformación a la parte no reducida de la matriz, usando una actualización
!>  por bloques de la forma:  A := A - V*Y**T - X*U**T.
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos
!>  con nb = 2:
!>
!>  m = 6 y n = 5 (m > n):          m = 5 y n = 6 (m < n):
!>
!>    (  1   1   u1  u1  u1 )           (  1   u1  u1  u1  u1  u1 )
!>    (  v1  1   1   u2  u2 )           (  1   1   u2  u2  u2  u2 )
!>    (  v1  v2  a   a   a  )           (  v1  1   a   a   a   a  )
!>    (  v1  v2  a   a   a  )           (  v1  v2  a   a   a   a  )
!>    (  v1  v2  a   a   a  )           (  v1  v2  a   a   a   a  )
!>    (  v1  v2  a   a   a  )
!>
!>  donde a denota un elemento de la matriz original que no cambia,
!>  vi denota un elemento del vector que define H(i), y ui un elemento
!>  del vector que define G(i).
!>

    dlabrd.f(3)

    NAME

    dlabrd - description

    SYNOPSIS

    CALL DLABRD( M, N, NB, A, LDA, LDQ, Q, LDVT, VT, WORK, LWORK )

    DESCRIPTION

    DLABRD is a general-purpose subarray reduction routine. It reduces the first NB rows and columns of a real general matrix A to upper and lower bidiagonal form by unitary transformations, and it reduces A to the form A = Q * T * VT, where T is the trapezoidal matrix 

          T = [ A1  A2 ]
          [ 0   A3 ]

    A1 is NB by NB, A2 is NB by (N-NB), and A3 is (M-NB) by (N-NB).

    Arguments

    M
    (input) INTEGER.
    The number of rows of the matrix A. M >= 0.
    N
    (input) INTEGER.
    The number of columns of the matrix A. N >= 0.
    NB
    (input) INTEGER.
    The number of rows and columns to be reduced. NB >= 0.
    A
    (input/output) DOUBLE PRECISION array, dimension (LDA,N).
    On entry, the M by N matrix A.
    On exit, the elements of A below and to the left of the NB by NB
    submatrix A1 are overwritten by information to implement the
    unitary transformations.
    LDA
    (input) INTEGER.
    The leading dimension of the array A. LDA >= max(1,M).
    LDQ
    (input) INTEGER.
    The leading dimension of the array Q. LDQ >= max(1,M).
    Q
    (output) DOUBLE PRECISION array, dimension (LDQ,NB).
    On exit, Q contains the block of M by NB unitary factors U that
    implement the transformations for the reduction of A.
    LDVT
    (input) INTEGER.
    The leading dimension of the array VT. LDVT >= max(1,NB).
    VT
    (output) DOUBLE PRECISION array, dimension (LDVT,N).
    On exit, VT contains the block of NB by N unitary factors V**T that
    implement the transformations for the reduction of A.
    WORK
    (workspace) DOUBLE PRECISION array, dimension (LWORK).
    LWORK
    (input) INTEGER.
    The dimension of the array WORK. LWORK >= max(1,N).
    For optimum performance, LWORK should be at least M*NB.

    OPTION

    This routine is used as a preprocessing step in algorithms to reduce a bidiagonal matrix to diagonal form.

    EXAMPLES

    Example Usage: 

          PROGRAM EX_DLABRD
      IMPLICIT NONE
      INTEGER LDA, LDQ, LDVT, M, N, NB, LWORK
      PARAMETER (M=4, N=5, NB=2)
      DOUBLE PRECISION A(M,N), Q(M,NB), VT(NB,N), WORK(M*NB)
      INTEGER I, J
      LDA = M
      LDQ = M
      LDVT = NB
      LWORK = M*NB
C
C     Initialize A to some values
C
      A(1,1) = 1.0D0
      A(1,2) = 2.0D0
      A(1,3) = 3.0D0
      A(1,4) = 4.0D0
      A(1,5) = 5.0D0
      A(2,1) = 6.0D0
      A(2,2) = 7.0D0
      A(2,3) = 8.0D0
      A(2,4) = 9.0D0
      A(2,5) = 10.0D0
      A(3,1) = 11.0D0
      A(3,2) = 12.0D0
      A(3,3) = 13.0D0
      A(3,4) = 14.0D0
      A(3,5) = 15.0D0
      A(4,1) = 16.0D0
      A(4,2) = 17.0D0
      A(4,3) = 18.0D0
      A(4,4) = 19.0D0
      A(4,5) = 20.0D0
C
      PRINT *, 'Initial matrix A:'
      DO I = 1, M
          PRINT '(4(F6.1, 2X))', (A(I,J), J=1,N)
      END DO
C
      CALL DLABRD( M, N, NB, A, LDA, LDQ, Q, LDVT, VT, WORK, LWORK )
C
      PRINT *, ' '
      PRINT *, 'Matrix A after DLABRD:'
      DO I = 1, M
          PRINT '(4(F6.1, 2X))', (A(I,J), J=1,N)
      END DO
      PRINT *, ' '
      PRINT *, 'Matrix Q:'
      DO I = 1, M
          PRINT '(4(F6.1, 2X))', (Q(I,J), J=1,NB)
      END DO
      PRINT *, ' '
      PRINT *, 'Matrix VT:'
      DO I = 1, NB
          PRINT '(4(F6.1, 2X))', (VT(I,J), J=1,N)
      END DO
C
      END PROGRAM EX_DLABRD
