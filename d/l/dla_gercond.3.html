double precision function dla_gercond (trans, n, a, lda, af, ldaf, ipiv, cmode, c, info, work, iwork)
DLA_GERCOND estima el número de condición de Skeel para una matriz general.

Documentación de función/subrutina

double precision function dla_gercond (character trans, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, integer cmode, double precision, dimension( * ) c, integer info, double precision, dimension( * ) work, integer, dimension( * ) iwork)

DLA_GERCOND estima el número de condición de Skeel para una matriz general.

Propósito:

!>
!>    DLA_GERCOND estima el número de condición de Skeel de op(A) * op2(C)
!>    donde op2 está determinado por CMODE de la siguiente manera:
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel cond(A) = norminf( |inv(A)||A| )
!>    se calcula calculando factores de escala R tales que
!>    diag(R)*A*op2(C) está equilibrado por filas y calculando el número
!>    de condición de norma infinito estándar.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transpuesta)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es array DOUBLE PRECISION, dimension (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array DOUBLE PRECISION, dimension (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U como lo calcula DGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     como lo calcula DGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

CMODE

!>          CMODE es INTEGER
!>     Determina op2(C) en la fórmula op(A) * op2(C) como sigue:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es array DOUBLE PRECISION, dimension (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimension (3*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es array INTEGER, dimension (N).
!>     Espacio de trabajo.
!>
