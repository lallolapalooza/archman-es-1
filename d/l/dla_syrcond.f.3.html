función de precisión doble dla_syrcond (carácter uplo, entero n, precisión doble, dimensión( lda, * ) a, entero lda, precisión doble, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, entero cmode, precisión doble, dimensión( * ) c, entero info, precisión doble, dimensión( * ) work, entero, dimensión( * ) iwork)

DLA_SYRCOND estima el número de condición de Skeel para una matriz simétrica indefinida.

Propósito:

!>
!>    DLA_SYRCOND estima el número de condición de Skeel de op(A) * op2(C)
!>    donde op2 está determinado por CMODE de la siguiente manera:
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel cond(A) = norminf( |inv(A)||A| )
!>    se calcula calculando factores de escala R tales que
!>    diag(R)*A*op2(C) esté equilibrado por filas y calculando el número
!>    de condición de norma infinita estándar.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A. N >= 0.
!>

A

!>          A es una matriz DOUBLE PRECISION, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal de la matriz A. LDA >= max(1,N).
!>

AF

!>          AF es una matriz DOUBLE PRECISION, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L tal como lo calcula DSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal de la matriz AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV es una matriz INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como los determina DSYTRF.
!>

CMODE

!>          CMODE es INTEGER
!>     Determina op2(C) en la fórmula op(A) * op2(C) de la siguiente manera:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es una matriz DOUBLE PRECISION, dimensión (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es una matriz DOUBLE PRECISION, dimensión (3*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es una matriz INTEGER, dimensión (N).
!>     Espacio de trabajo.
!>
