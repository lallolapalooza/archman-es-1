DLA_SYRCOND estima el número de condición de Skeel para una matriz indefinida simétrica.

Propósito:

!>
!>    DLA_SYRCOND estima el número de condición de Skeel de  op(A) * op2(C)
!>    donde op2 se determina por CMODE de la siguiente manera
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    El número de condición de Skeel cond(A) = norminf( |inv(A)||A| )
!>    se calcula calculando factores de escala R tales que
!>    diag(R)*A*op2(C) sea equilibrado por filas y calculando el número
!>    de condición de norma infinito estándar.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>       = 'U':  El triángulo superior de A se almacena;
!>       = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es ENTERO
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es una matriz de DOBLE PRECISIÓN, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es ENTERO
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz de DOBLE PRECISIÓN, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L tal como es calculado por DSYTRF.
!>

LDAF

!>          LDAF es ENTERO
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es una matriz de ENTEROS, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como es determinada por DSYTRF.
!>

CMODE

!>          CMODE es ENTERO
!>     Determina op2(C) en la fórmula op(A) * op2(C) de la siguiente manera:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C es una matriz de DOBLE PRECISIÓN, dimensión (N)
!>     El vector C en la fórmula op(A) * op2(C).
!>

INFO

!>          INFO es ENTERO
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento no es válido.
!>

WORK

!>          WORK es una matriz de DOBLE PRECISIÓN, dimensión (3*N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es una matriz de ENTEROS, dimensión (N).
!>     Espacio de trabajo.
!>
