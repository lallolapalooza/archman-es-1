dict(n) Comandos internos de Tcl dict(n)

NOMBRE

dict - Manipula diccionarios

SINOPSIS

dict opción argumento ?argumento ...?

DESCRIPCIÓN

Realiza una de varias operaciones sobre valores de diccionario o variables que contienen valores de diccionario (ver la sección VALORES DE DICCIONARIO a continuación para una descripción), dependiendo de opción. Las opciones legales (que pueden abreviarse) son:

dict append variableDiccionario clave ?cadena ...?
Añade la cadena (o cadenas) dada al valor al que la clave dada mapea en el valor del diccionario contenido en la variable dada, escribiendo el valor resultante del diccionario de vuelta a esa variable. Las claves inexistentes se tratan como si mapearan a una cadena vacía. Se devuelve el valor del diccionario actualizado.
dict create ?clave valor ...?
Devuelve un nuevo diccionario que contiene cada uno de los mapeos clave/valor listados como argumentos (claves y valores alternándose, con cada clave seguida de su valor asociado).
dict exists valorDiccionario clave ?clave ...?
Devuelve un valor booleano que indica si la clave dada (o ruta de claves a través de un conjunto de diccionarios anidados) existe en el valor del diccionario dado. Esto devuelve un valor verdadero exactamente cuando dict get en esa ruta tendrá éxito.
dict filter valorDiccionario tipoFiltro argumento ?argumento ...?
Toma un valor de diccionario y devuelve un nuevo diccionario que contiene solo aquellos pares clave/valor que coinciden con el tipo de filtro especificado (que puede abreviarse). Los tipos de filtro admitidos son:
dict filter valorDiccionario clave ?patrónGlob ...?
La regla de clave solo coincide con aquellos pares clave/valor cuyas claves coinciden con alguno de los patrones dados (en el estilo de string match).
dict filter valorDiccionario script {variableClave variableValor} script
La regla de script prueba la coincidencia asignando la clave a la variableClave y el valor a la variableValor, y luego evaluando el script dado que debería resultar en un valor booleano (incluyendo el par clave/valor solo cuando se devuelve un valor verdadero). Tenga en cuenta que el primer argumento después de la palabra de selección de regla es una lista de dos elementos. Si el script regresa con una condición de TCL_BREAK, no se considerarán más pares clave/valor para su inclusión en el diccionario resultante, y una condición de TCL_CONTINUE es equivalente a un resultado falso. Los pares clave/valor se prueban en el orden en que se insertaron las claves en el diccionario.
dict filter valorDiccionario valor ?patrónGlob ...?
La regla de valor solo coincide con aquellos pares clave/valor cuyos valores coinciden con alguno de los patrones dados (en el estilo de string match).
dict for {variableClave variableValor} valorDiccionario cuerpo
Este comando toma tres argumentos, el primero es una lista de dos elementos de nombres de variables (para la clave y el valor respectivamente de cada mapeo en el diccionario), el segundo es el valor del diccionario sobre el que iterar, y el tercero es un script que se evaluará para cada mapeo con las variables de clave y valor configuradas apropiadamente (a la manera de foreach). El resultado del comando es una cadena vacía. Si cualquier evaluación del cuerpo genera un resultado TCL_BREAK, no se iterarán más pares del diccionario y el comando dict for terminará exitosamente de inmediato. Si cualquier evaluación del cuerpo genera un resultado TCL_CONTINUE, esto se tratará exactamente como un resultado normal TCL_OK. El orden de iteración es el orden en que se insertaron las claves en el diccionario.
dict get valorDiccionario ?clave ...?
Dado un valor de diccionario (primer argumento) y una clave (segundo argumento), esto recuperará el valor para esa clave. Donde se proporcionan varias claves, el comportamiento del comando será como si el resultado de dict get $dictVal $clave se pasara como primer argumento a dict get con los argumentos restantes como argumentos (posiblemente posteriores). Esto facilita las búsquedas en diccionarios anidados. Por ejemplo, los dos comandos siguientes son equivalentes:
dict get $dict foo bar spong
dict get [dict get [dict get $dict foo] bar] spong

Si no se proporcionan claves, dict get devolverá una lista que contiene pares de elementos de manera similar a array get. Es decir, el primer elemento de cada par sería la clave y el segundo elemento sería el valor para esa clave.

Es un error intentar recuperar un valor para una clave que no está presente en el diccionario.

dict incr variableDiccionario clave ?incremento?
Esto añade el valor de incremento dado (un entero que por defecto es 1 si no se especifica) al valor al que la clave dada mapea en el valor del diccionario contenido en la variable dada, escribiendo el valor resultante del diccionario de vuelta a esa variable. Las claves inexistentes se tratan como si mapearan a 0. Es un error incrementar un valor para una clave existente si ese valor no es un entero. Se devuelve el valor del diccionario actualizado.
dict info valorDiccionario
Esto devuelve información (destinada a mostrarse a las personas) sobre el diccionario dado, aunque el formato de estos datos depende de la implementación del diccionario. Para diccionarios implementados por tablas hash, se espera que esto devuelva la cadena producida por Tcl_HashStats, similar a array statistics.
dict keys valorDiccionario ?patrónGlob?
Devuelve una lista de todas las claves en el valor del diccionario dado. Si se proporciona un patrón, solo se devolverán aquellas claves que coincidan con él (según las reglas de string match). Las claves devueltas estarán en el orden en que se insertaron en el diccionario.
dict lappend variableDiccionario clave ?valor ...?
Esto añade los elementos dados al valor de lista al que la clave dada mapea en el valor del diccionario contenido en la variable dada, escribiendo el valor resultante del diccionario de vuelta a esa variable. Las claves inexistentes se tratan como si mapearan a una lista vacía, y es legal que no haya elementos que añadir a la lista. Es un error que el valor al que la clave mapea no sea representable como una lista. Se devuelve el valor del diccionario actualizado.
dict map {variableClave variableValor} valorDiccionario cuerpo
Este comando aplica una transformación a cada elemento de un diccionario, devolviendo un nuevo diccionario. Toma tres argumentos: el primero es una lista de dos elementos de nombres de variables (para la clave y el valor respectivamente de cada mapeo en el diccionario), el segundo es el valor del diccionario sobre el que iterar, y el tercero es un script que se evaluará para cada mapeo con las variables de clave y valor configuradas apropiadamente (a la manera de lmap). En una iteración donde el script evaluado se completa normalmente (TCL_OK, en lugar de un error, etc.) el resultado del script se coloca en un diccionario acumulador utilizando la clave que es el contenido actual de la variable variableClave en ese momento. El resultado del comando dict map es el diccionario acumulador después de que todas las claves hayan sido iteradas.

Si la evaluación del cuerpo para cualquier paso particular genera un break, no se iterarán más pares del diccionario y el comando dict map terminará exitosamente de inmediato. Si la evaluación del cuerpo para un paso particular genera un resultado continue, la iteración actual se aborta y el diccionario acumulador no se modifica. El orden de iteración es el orden natural del diccionario (típicamente la inserción)

dict merge dictionaryValue?dictionaryValue ...?
Este comando toma dos o más diccionarios y devuelve un nuevo diccionario que contiene la unión de los diccionarios de entrada. Si una clave aparece en más de un diccionario de entrada, el valor asociado con esa clave en el último diccionario de entrada en el que aparece se utilizará en el diccionario resultante.
dict set dictionaryVariable key ?value?
Este comando establece el valor asociado con la clave dada en el diccionario contenido en la variable dada. Si la clave no existe, se crea. Si el valor no se especifica, entonces el valor de la clave se eliminará del diccionario. El valor del diccionario actualizado se devuelve.
dict size dictionaryValue
Devuelve el número de pares clave/valor en el valor del diccionario dado.
dict uniques ?dictionaryValue?
Este comando devuelve un diccionario que contiene solo los pares clave/valor del diccionario de entrada donde los valores son únicos. Si se encuentran múltiples claves con el mismo valor, se conservará el último par clave/valor encontrado. Si no se proporciona ningún diccionario de entrada, se utiliza el valor de la pila de argumentos de Tcl.
dict update dictionaryVariable key ?value?
Este comando es similar a dict set, pero en lugar de establecer el valor, llama a un script que tiene acceso al valor actual de la clave y potencialmente puede cambiarlo. El script debe ser un script de Tcl válido. Se le pasa el valor actual de la clave. El script se ejecuta y se espera que devuelva un nuevo valor para la clave. Si el script no devuelve nada, o si se llama a dict update sin un valor, la clave se elimina del diccionario. Si la clave no existe, se crea y el valor se establece en el resultado del script. El valor del diccionario actualizado se devuelve.
dict values dictionaryValue ?globPattern?
Devuelve una lista de todos los valores en el valor del diccionario dado. Si se proporciona un patrón, solo se devolverán aquellos valores que coincidan con él (según las reglas de string match). Los valores devueltos estarán en el orden en que se insertaron en el diccionario.

DICTIONARY VALUES

La mayoría de los comandos dict operan sobre "valores de diccionario". Un valor de diccionario es una representación de un valor de Tcl que cumple con el invariante de que su tipo de Tcl subyacente es un diccionario. Los valores de diccionario pueden ser variables que contienen un valor de diccionario, o pueden ser el resultado de otro comando de Tcl que devuelve un valor de diccionario.

En la mayoría de los casos, los comandos dict esperan que el valor proporcionado sea un diccionario válido. Si se proporciona un valor que no es un diccionario válido, se producirá un error.

Los valores devueltos por los comandos dict que devuelven un valor de diccionario son siempre un valor de diccionario válido.

EJEMPLO

El siguiente ejemplo ilustra el uso de varios comandos dict:

set myDict [dict create a 1 b 2 c 3]
dict append myDict a ",4"
puts [dict get myDict a]       ;# Imprime 1,4
puts [dict keys myDict]       ;# Imprime a b c
puts [dict values myDict]     ;# Imprime 1,4 2 3
dict for {key val} $myDict {
    puts "key=$key, value=$val"
}
# Imprime:
# key=a, value=1,4
# key=b, value=2
# key=c, value=3

VALORES DE

DICCIONARIO

Los diccionarios son valores que contienen un mapeo eficiente que preserva el orden de claves arbitrarias a valores arbitrarios. Cada clave en el diccionario se asigna a un solo valor. Tienen un formato textual que es exactamente el de cualquier lista con un número par de elementos, con cada asignación en el diccionario representada como dos elementos en la lista. Cuando un comando toma un diccionario y produce un nuevo diccionario basado en él (ya sea devolviéndolo o escribiéndolo de vuelta en la variable de la que se leyó el diccionario inicial) el nuevo diccionario tendrá el mismo orden de claves, módulo cualquier clave eliminada y con nuevas claves añadidas al final. Cuando una cadena se interpreta como un diccionario y de otro modo tendría claves duplicadas, solo se usa el último valor para una clave particular; las otras se ignoran, lo que significa que, “apple banana” y “apple carrot apple banana” son diccionarios equivalentes (con diferentes representaciones de cadena)

.

Las operaciones que derivan un nuevo diccionario de uno antiguo (p. ej., actualizaciones como dict set y dict unset) preservan el orden de las claves en el diccionario. Las excepciones a esto son para cualquier nueva

clave que añadan, que se añaden a la secuencia, y cu
alquier clave que se elimina, que se excisa del orden.

Uso básico de

diccionario: 
# Make a dictionary to map extensions to descriptions
set filetypes [dict create .txt "Text File" .tcl "Tcl File"]
# Add/update the dictionary
dict set filetypes .tcl "Tcl Script"
dict set filetypes .tm  "Tcl Module"
dict set filetypes .gif "GIF Image"
dict set filetypes .png "PNG Image"
# Simple read from the dictionary
set ext ".tcl"
set desc [dict get $filetypes $ext]
puts "$ext is for a $desc"
# Somewhat more complex, with existence test
foreach filename [glob *] {
    set ext [file extension $filename]
    if {[dict exists $filetypes $ext]} {
        puts "$filename is a [dict get $filetypes $ext]"
    }
}

proc sumDictionary {varName} {
    upvar 1 $varName vbl
    foreach key [dict keys $vbl] {
        # Manufacture an entry in the subdictionary
