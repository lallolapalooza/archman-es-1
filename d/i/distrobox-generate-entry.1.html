NOMBRE

distrobox generate-entry

DESCRIPCIÓN

distrobox-generate-entry creará un icono de escritorio para uno de los distroboxes disponibles. Este se eliminará cuando elimines el distrobox correspondiente.

SINOPSIS

distrobox generate-entry

--help/-h:      mostrar este mensaje
--all/-a:       realizar para todos los distroboxes
--delete/-d:        eliminar la entrada
--icon/-i:      especificar un icono personalizado [/ruta/al/icono] (por defecto, automático)
--root/-r:      realizar en distroboxes con privilegios de root
--verbose/-v:       mostrar más verbosidad
--version/-V:       mostrar versión

EJEMPLOS

Generar una entrada para un contenedor

distrobox generate-entry nombre-de-mi-contenedor

Especificar un icono personalizado para la entrada

distrobox generate-entry nombre-de-mi-contenedor --icon /ruta/al/icono.png

Generar una entrada para todos los distroboxes

distrobox generate-entry --all

Eliminar una entrada

distrobox generate-entry nombre-del-contenedor --delete
