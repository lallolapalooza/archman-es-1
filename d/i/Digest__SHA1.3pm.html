DESCRIPCIÓ

N

El módulo "Digest::SHA1" le permite usar el algoritmo de resumen de mensajes NIST SHA-1 desde programas de Perl. El algoritmo toma como entrada un mensaje de longitud arbitraria y produce como salida una "huella digital" o "resumen de mensaje" de 160 bits de la

entrada.

En 2005, se identificaron fallos de seguridad en SHA-1, a saber, que podría existir una posible debilidad matemática, lo que indicaba que sería deseable una función hash más fuerte. El módulo Digest::SHA implementa los algoritmos más fuertes de la familia

SHA.

El módulo "Digest::SHA1" proporciona una interfaz procedimental para un uso sencillo, así como una interfaz or

ientada a objetos que puede manejar mensajes de longi
tud arbitraria y que puede leer archivos directamente.

FUNCIONE

S

Las siguientes funciones se pueden exportar desde el módulo "Digest::SHA1". No se exportan funciones de forma

predeterminada.
sha1($data,.
..)
Esta función concatenará todos los argumentos, calculará el resumen SHA-1 de este "mensaje" y lo devolverá en forma binaria. La cadena devuelta tendrá 20 bytes de longitud.

El resultado de sha1("a", "b",

"c") será exactamente el mismo q
ue el resultado de sha1("abc").
sha1_hex($data,.
..)
Igual que sha1(), pero devolverá el resumen en forma hexadecimal. La longitud de la cadena devuelta será 40 y solo contendrá caracteres de este conjunto: '0'..'9' y 'a'..
'f'.
sha1_base64($data,.
..)
Igual que sha1(), pero devolverá el resumen como una cadena codificada en base64. La longitud de la cadena devuelta será 27 y solo contendrá caracteres de este conjunto: 'A'..'Z', 'a'..'z', '0'..'9', '+' y '/'.

Tenga en cuenta que la cadena codificada en base64 devuelta no está rellenada para que s

ea múltiplo de 4 bytes de longitud. Si desea interoperabilidad con otros resúmenes sha1 c
odificados en base64, es posible que desee añadir la cadena redundante "=" al resultado.
sha1_transform($da
ta)
Implementa la transformación básica SHA1 en un bloque de 64 bytes. El argumento $data y el resumen devuelto $digest están en forma binaria
. Este algoritmo
se utiliza en
NIST FIPS 186-2

La interfaz orientada a objetos de "Digest::SHA1" se describe en esta sección. Después de que se haya creado un objeto "Digest::SHA1", añadirá datos a él y finalmente pedirá el resumen en un formato adecuado. Se puede usar un solo objeto para calcular múltiples

resúmenes.

Se proporcionan los siguientes

métodos:

new
El constructor devuelve un nuevo objeto "Digest::SHA1" que encapsula el estado del algoritmo de resumen de mensajes SHA-1.

Si se llama como método de instancia (es decir, $sha1->new) simplemente restablecerá el estado del objeto al estado de

un objeto recién creado. En este c
aso no se crea ningún objeto nuevo.

reset
Esto es solo un alias para $sha1->
new.
$sha1->
clone
Esta es una copia del objeto $sha1. Es útil cuando no desea destruir el estado del resumen, pero necesita un valor intermedio del resumen, p. ej. al calcular resúmenes iterativamente en un flujo de datos continuo. Ejemplo: 
my $sha1 = Digest::SHA1->new;
while (<>) {
    $sha1->add($_);
    print "Line $.: ", $sha1->clone->hexdigest,
"\n";
}

..)
El $data proporcionado como argumento se añade al mensaje para el que calculamos el resumen. El valor de retorno es el objeto $sha1 en sí mismo.

El $io_handle se leerá hasta EOF y su contenido se añadirá al mensaje para el que calculamos el resumen. El valor de retorno es el objeto $sha1 en sí mismo.

El método addfile() hará croak() si falla la lectura de datos por alguna razón. Si hace croak, es impredecible en qué estado estará el objeto $sha1. El método addfile() podría haber sido capaz de leer el archivo parcialmente antes de que fallara. Probablemente sea prudente descartar o restablecer el objeto $sha1 si esto

ocurre.
