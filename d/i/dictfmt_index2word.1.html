NOMBRE

dictfmt_index2word - Crea un archivo de índice .word a partir de un archivo .index de base de datos DICTD

SINOPSIS

dictfmt_index2word [OPCIONES] [archivo_indice]

DESCRIPCIÓN

dictfmt_index2word crea un archivo de índice de palabras en la salida estándar para el archivo de índice dado en la entrada estándar o en la línea de comandos. Un archivo de índice de palabras indexa cada subpalabra de las palabras principales compuestas del archivo .index, al archivo .dict subyacente. Un archivo de índice de palabras normalmente se llama <nombre_base>.word, pero esto no es obligatorio siempre que se utilice el nombre correcto en el archivo de configuración de dictd.

OPCIONES

--help
muestra un mensaje de uso y sale
--locale localidad
usa la localidad para ordenar el archivo .word. Si se omite esta opción, se utiliza la localidad predeterminada "C".
archivo_indice
el archivo .index a convertir.
