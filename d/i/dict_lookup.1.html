NOMBRE

dict_lookup - Cliente del Protocolo DICT

SINOPSIS

dict_lookuop [opciones]

DESCRIPCIÓN

dict_lookup lee la selección X, luego abre un emulador de terminal y ejecuta el cliente dict en él, permitiendo al usuario ver el contenido utilizando un paginador. Tiene sentido configurar el lanzamiento de dict_lookup en un atajo de teclado en el gestor de ventanas.

OPCIONES

-h
muestra el mensaje de ayuda.
-x x
coordenada X del emulador de terminal.
-x Y
coordenada Y del emulador de terminal.
-s AxA
ancho y alto del emulador de terminal separados por 'x'.
-q consulta
consulta, si se especifica, la selección X no se lee.

ENTORNO

dict_lookup reconoce las siguientes variables de entorno. El valor por defecto se especifica entre corchetes.

D_AWK_PROG
intérprete AWK a utilizar. [awk]
D_XCLIP_PROG
aplicación xclip. [xclip]
D_XTERM_PROG
xterm o emulador de terminal equivalente. [xterm]
D_UTF8_LOCALE
localización UTF-8. [en_US.UTF-8]
D_DICT_PROG
programa cliente de diccionario. [dict]
D_DICT_SERVER
Opción para el cliente de diccionario que especifica el servidor. [-h dict.org]
D_DICT_PORT
Opción para el cliente de diccionario que especifica el puerto. [-p 2628]
D_DICT_DB_OPT
Opción para el cliente de diccionario que especifica la base de datos. [-d foldoc]
D_XTERM_CLASS
Opción para el emulador de terminal que especifica la clase. [-class XTerm]
D_XTERM_NAME
Opción para el emulador de terminal que especifica el nombre. [-name xterm_dict]
D_XTERM_TITLE
Opción para el emulador de terminal que especifica el título. [-title dict_lookup]
D_TEXT_WIDTH
Programa que calcula el ancho del texto para un texto dado. [cyrillic_text_width] cyrillic_text_width no funciona correctamente para japonés, coreano, chino y otros idiomas.
D_TERM_X
Coordenada X del emulador de terminal. [+200]
D_TERM_Y
Coordenada Y del emulador de terminal. [+200]
D_TERM_H
Altura del emulador de terminal. [+40]
D_PAGER
Paginador. [less]

VER TAMBIÉN

dict(1), less(1), xterm(1), dictd(8), http://www.dict.org, RFC 2229
