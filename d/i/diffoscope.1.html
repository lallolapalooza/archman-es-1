DIFFOSCOPE(1) Comandos de usuario DIFFOSCOPE(1)

NOMBRE

diffoscope - comparación en profundidad de archivos, archivos comprimidos y directorios

SINOPSIS

diffoscope --help
diffoscope [OPTIONS] [--json output_diff] path1 path2
diffoscope [OPTIONS] diff
diffoscope [OPTIONS] < diff

""

DESCRIPCIÓN

diffoscope intentará averiguar qué hace que los archivos o directorios sean diferentes. Descomprimirá recursivamente archivos comprimidos de muchos tipos y transformará varios formatos binarios a una forma más legible para los humanos para compararlos. Puede comparar dos tarballs, imágenes ISO o PDF con la misma facilidad.

Puede ser manipulado mediante códigos de error, y se puede producir un informe con las diferencias detectadas. El informe puede ser texto o HTML. Cuando no se ha seleccionado ningún tipo de informe, diffoscope escribe por defecto un informe de texto en la salida estándar.

diffoscope fue iniciado inicialmente por el proyecto Debian de "compilaciones reproducibles" y ahora se desarrolla como parte de la iniciativa (más amplia) ???Reproducible Builds??? https://reproducible-builds.org. Está destinado a poder entender rápidamente por qué dos compilaciones del mismo paquete producen diferentes salidas. diffoscope se llamaba anteriormente debbindiff.

Consulte la EJEMPLOS DE LÍNEA DE COMANDOS sección más abajo para empezar, así como explicaciones más detalladas de todas las opciones de la línea de comandos. La misma información también está disponible en /usr/share/doc/diffoscope/README.rst o similar.

path1
Primer archivo o directorio a comparar.
path2
Segundo archivo o directorio a comparar.

opciones:

--debug
Mostrar mensajes de depuración
--pdb
Abrir el depurador pdb de Python en caso de fallos
--status-fd FD
Enviar estado legible por máquina al descriptor de archivo FD
--progress, --no-progress
Mostrar una barra de progreso aproximada. Por defecto: sí si stdin es un tty, de lo contrario no.
--no-default-limits
Deshabilitar la mayoría de los límites de salida y de cálculo de diferencias por defecto.
--load-existing-diff INPUT_FILE
Cargar una diferencia existente desde un archivo. Especifique "-" para leer una diferencia de diffoscope desde stdin.

tipos de salida:

--text OUTPUT_FILE
Escribir salida de texto plano en el archivo dado (use - para stdout)
--text-color WHEN
Cuándo emitir diferencias con color. WHEN es uno de {never, auto, always}. Por defecto: auto, lo que significa sí si la salida es un terminal, de lo contrario no.
--output-empty
Si no hubo diferencias, emitir una diferencia vacía para cada tipo de salida que se especificó. En --text salida, se escribe un archivo vacío.
--html OUTPUT_FILE
Escribir informe HTML en el archivo dado (use - para stdout)
--html-dir OUTPUT_DIR
Escribir informe HTML de múltiples archivos en el directorio dado
--css URL
Enlace a un CSS adicional para el informe HTML
--jquery URL
URL de enlace a jQuery, para --html y --html-dir salida. Si esta es una URL relativa inexistente, diffoscope creará un enlace simbólico a una instalación del sistema. (Rutas buscadas: /usr/share/javascript/jquery/jquery.js.) Si no se da, --html salida no usará JS pero --htmldir sí si se puede encontrar; dé "disable" para deshabilitar JS en todas las salidas.
--json OUTPUT_FILE
Escribir salida de texto JSON en el archivo dado (use - para stdout)
--markdown OUTPUT_FILE
Escribir salida de texto Markdown en el archivo dado (use - para stdout)
--restructured-text OUTPUT_FILE
Escribir salida de texto RsT en el archivo dado (use - para stdout)
--difftool TOOL
Comparar diferencias una por una usando el comando externo especificado similar a git-difftool(1)
--profile [OUTPUT_FILE]
Escribir información de perfilado en el archivo dado (use - para stdout)

límites de salida:

--diff-context LINES
Líneas de contexto de diff unificado a mostrar. (por defecto: 7)
--max-text-report-size BYTES
Máximo de bytes escritos en --text informe. (0 para deshabilitar, por defecto: 0)
--max-report-size BYTES
Máximo de bytes de un informe en un formato dado, a través de todas sus páginas. Note que algunos formatos, tales como --html, pueden estar restringidos por límites aún más pequeños tales como --max-page-size. (0 para deshabilitar, por defecto: 41943040)
--max-diff-block-lines LINES
Número máximo de líneas emitidas por bloque de diff unificado, a través de todas las páginas. (0 para deshabilitar, por defecto: 1024)
--max-page-size BYTES
Máximo de bytes de la página de nivel superior (--html-dir) o única (--html) página. (por defecto: 41943040, permanece en efecto incluso con --no-default-limits)
--max-page-diff-block-lines LINES
Número máximo de líneas emitidas por bloque de diff unificado en la página de nivel superior (--html-dir) o única (--html) página, antes de desbordarlo a una página secundaria (--html-dir) o saltarse el resto del bloque de diff. (por defecto: 128, permanece en efecto incluso con --no-default-limits)

cálculo de diferencias:

--new-file
Tratar archivos ausentes como vacíos
--exclude GLOB_PATTERN
Excluir archivos cuyos nombres (incluyendo cualquier parte de directorio) coincidan con GLOB_PATTERN. Use esta opción para ignorar archivos basándose en sus nombres.
--exclude-command REGEX_PATTERN
Excluir comandos que coincidan con REGEX_PATTERN. Por ejemplo '^readelf.*\s--debug-dump=info' y '^radare2.*' pueden tardar mucho tiempo y las diferencias aquí probablemente son diferencias secundarias causadas por algo representado en otro lugar. Use esta opción para deshabilitar comandos que usan muchos recursos.
--exclude-directory-metadata {auto,yes,no,recursive}
Excluir metadatos de directorio. Útil si se comparan archivos cuyos metadatos a nivel de sistema de archivos no están destinados a ser distribuidos a otros sistemas. Esto es cierto para la mayoría de los constructores de paquetes de distribuciones, pero no es cierto para la salida de comandos tales como `make install`. Los metadatos de los miembros del archivo permanecen sin excluir excepto si se establece la opción "recursive". Use esta opción para ignorar permisos, marcas de tiempo, xattrs etc. Por defecto: 'no' si se comparan dos directorios, de lo contrario 'yes'. Note que los metadatos de "archivo" son en realidad una propiedad de su directorio contenedor y no son relevantes al distribuir el archivo a través de sistemas.
--extended-filesystem-attributes, --no-extended-filesystem-attributes
Comprobar atributos extendidos del sistema de archivos potencialmente costosos tales como ACLs POSIX, atributos lsattr(1)/chattr(1) etc. (por defecto: False)
--diff-mask REGEX_PATRÓN
Reemplaza/unifica subcadenas que coincidan con la expresión regular REGEX_PATTERN de las cadenas de salida antes de aplicar el diff. Por ejemplo, para filtrar un número de versión o una ruta modificada.
--fuzzy-threshold FUZZY_THRESHOLD
Umbral para la coincidencia difusa (0 para desactivar, 110 es el valor predeterminado, 400 es una alta difuminación)
--tool-prefix-binutils PREFIX
Prefijo para los nombres de los programas de binutils, por ejemplo, "aarch64-linux-gnu-" para un binario de una arquitectura diferente o "g" si está en un sistema no GNU.
--max-diff-input-lines LINES
Número máximo de líneas que se pasan a diff(1) (0 para desactivar, predeterminado: 4194304)
--max-container-depth DEPTH
Profundidad máxima para la recursión en los contenedores. (No se puede desactivar por razones de seguridad, predeterminado: 50)
--timeout SECONDS
Intento de mejor esfuerzo de un tiempo de espera global en segundos. Si está activado, diffoscope no recursará en ningún sub-archivo adicional después de X segundos de tiempo de ejecución total. (predeterminado: sin tiempo de espera) [experimental]
--max-diff-block-lines-saved LINES
Número máximo de líneas guardadas por bloque de diff. La mayoría de los usuarios no deberían necesitar esto, a menos que se queden sin memoria. Esto trunca la salida de diff(1) antes de emitirla en un informe, y afecta a todos los tipos de salida, incluyendo --text y --json. (0 para desactivar, predeterminado: 0)
--use-dbgsym WHEN
Cuándo usar automáticamente los paquetes -dbgsym correspondientes al comparar archivos .deb. WHEN es uno de {no, auto, yes}. Predeterminado: auto, lo que significa yes si se especifican dos archivos .changes o .buildinfo, y no en caso contrario.
--force-details
Fuerza la recursión en las profundidades de los formatos de archivo incluso si los archivos tienen el mismo contenido, realmente útil solo para depurar diffoscope. Predeterminado: False

ESTADO DE SALIDA

El estado de salida es 0 si las entradas son iguales, 1 si son diferentes, 2 si hay un problema.

EJEMPLOS DE LÍNEA DE COMANDOS

Para comparar dos archivos en profundidad y producir un informe HTML, ejecute algo como:

$ diffoscope --html output.html build1.changes build2.changes

diffoscope saldrá con 0 si no hay diferencias y 1 si las hay.

Para obtener todas las opciones posibles, ejecute:

$ diffoscope --help

Si tiene suficiente RAM, puede mejorar el rendimiento ejecutando:

$ TMPDIR=/run/shm diffoscope very-big-input-0/ very-big-input-1/

Por defecto, esto le permite usar hasta la mitad de la RAM; para más, añada algo como:

tmpfs   /run/shm    tmpfs   size=80%    0   0

a su /etc/fstab; consulte man mount para más detalles.

DEPENDENCIAS EXTERNAS

diffoscope requiere Python 3 y los siguientes módulos disponibles en PyPI: libarchive-c https://pypi.python.org/pypi/libarchive-c, python-magic https://pypi.python.org/pypi/python-magic.

Los distintos comparadores dependen de la disponibilidad de comandos externos. Para obtener una lista de ellos, ejecute:

$ diffoscope --list-tools
