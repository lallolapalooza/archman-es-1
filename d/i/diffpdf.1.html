DIFFPDF(1) Manual de Comandos Generales DIFFPDF(1)

NOMBRE

diffpdf - compara dos archivos PDF textual o visualmente

SINOPSIS

diffpdf [archivo1] [archivo2]

DESCRIPCIÓN

Esta página del manual documenta muy brevemente el comando diffpdf. (Haga clic en el botón Ayuda de la GUI o presione F1 para obtener más información).

DiffPDF es una aplicación GUI utilizada para comparar dos archivos PDF.
Por defecto, la comparación es de las palabras en cada par de páginas, pero también se admite la comparación carácter por carácter (por ejemplo, para idiomas logográficos). Y también hay soporte para comparar las páginas por apariencia (por ejemplo, si se modifica un diagrama o si se reforma un párrafo, o se cambia una fuente). También es posible comparar páginas o rangos de páginas específicos. Por ejemplo, si hay dos versiones de un archivo PDF, una con las páginas 1-12 y la otra con las páginas 1-13 debido a que se ha añadido una página extra como página 4, se pueden comparar especificando dos rangos de páginas, 1-12 para la primera y 1-3, 5-13 para la segunda. Esto hará que DiffPDF compare las páginas en los pares (1, 1), (2, 2), (3, 3), (4, 5), (5, 6), y así sucesivamente, hasta (12, 13).

Si el programa recibe dos nombres de archivo PDF en la línea de comandos, se iniciará y comparará esos archivos en modo Texto (o en modo Apariencia si los nombres de archivo van precedidos de -a o --appearance).

VER TAMBIÉN

Para una herramienta de línea de comandos para comparar archivos PDF, consulte http://www.qtrac.eu/comparepdf.html.
