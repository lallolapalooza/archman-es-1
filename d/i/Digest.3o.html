Módulo Digest
: sig end

Resumen del mensaje.

Este módulo proporciona funciones para calcular 'digests', también conocidos como 'hashes', de cadenas o archivos de longitud arbitraria. Los algoritmos de hash soportados son BLAKE2 y MD5.

Funciones básicas

Las funciones en esta sección utilizan la función de hash MD5 para producir resúmenes de 128 bits (16 bytes). MD5 no es criptográficamente seguro. Por lo tanto, estas funciones no deben utilizarse para aplicaciones sensibles a la seguridad. Las funciones BLAKE2 a continuación son criptográficamente seguras.

type t = string

El tipo de resúmenes: cadenas de 16 bytes.

val compare : t -> t -> int

La función de comparación para resúmenes de 16 bytes, con la misma especificación que compare y la implementación compartida con String.compare . Junto con el tipo t , esta función compare permite que el módulo Digest se pase como argumento a los functores Set.Make y Map.Make .

Desde 4.00

val equal : t -> t -> bool

La función de igualdad para resúmenes de 16 bytes.

Desde 4.03

val string : string -> t

Devuelve el resumen de la cadena dada.

val bytes : bytes -> t

Devuelve el resumen de la secuencia de bytes dada.

Desde 4.02

val substring : string -> int -> int -> t

Digest.substring s ofs len devuelve el resumen de la subcadena de s que comienza en el índice ofs y contiene len caracteres.

val subbytes : bytes -> int -> int -> t

Digest.subbytes s ofs len devuelve el resumen de la subsecuencia de s que comienza en el índice ofs y contiene len bytes.

Desde 4.02

val channel : in_channel -> int -> t

Si len es no negativo, Digest.channel ic len lee len caracteres del canal ic y devuelve su resumen, o lanza End_of_file si se llega al final del archivo antes de leer len caracteres. Si len es negativo, Digest.channel ic len lee todos los caracteres de ic hasta llegar al final del archivo y devuelve su resumen.

val file : string -> t

Devuelve el resumen del archivo cuyo nombre se proporciona.

val output : out_channel -> t -> unit

Escribe un resumen en el canal de salida dado.

val input : in_channel -> t

Lee un resumen del canal de entrada dado.

val to_hex : t -> string

Devuelve la representación hexadecimal imprimible del resumen dado.

Lanza Invalid_argument si el argumento no son exactamente 16 bytes.

val of_hex : string -> t

Convierte una representación hexadecimal de nuevo al resumen correspondiente.

Interfaz genérica

module type S = sig end

La firma para una función de hash que produce resúmenes de longitud hash_length a partir de cadenas de caracteres, arrays de bytes y archivos.

Desde 5.2

Funciones de hash específicas

module BLAKE128 : S

BLAKE128 es la función hash BLAKE2b que produce resúmenes de 128 bits (16 bytes). Es criptográficamente segura. Sin embargo, el tamaño pequeño de los resúmenes permite ataques de fuerza bruta en 2{^64} intentos.

Desde 5.2

module BLAKE256 : S

BLAKE256 es la función hash BLAKE2b que produce resúmenes de 256 bits (32 bytes). Es criptográficamente segura, y los resúmenes son lo suficientemente grandes como para frustrar ataques de fuerza bruta.

Desde 5.2

module BLAKE512 : S

BLAKE512 es la función hash BLAKE2b que produce resúmenes de 512 bits (64 bytes). Es criptográficamente segura, y los resúmenes son lo suficientemente grandes como para frustrar ataques de fuerza bruta.

Desde 5.2

module MD5 : S

MD5 es la función hash MD5. Produce resúmenes de 128 bits (16 bytes) y no es en absoluto criptográficamente segura. Solo debe usarse para compatibilidad con diseños anteriores que exigen el uso de MD5.

Desde 5.2
