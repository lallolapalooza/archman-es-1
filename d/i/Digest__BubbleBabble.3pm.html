NOMBRE

Digest::BubbleBabble - Crea huellas digitales bubble-babble

SINOPSIS

# Crea una huella digital de una cadena simple.
use Digest::BubbleBabble qw( bubblebabble );
my $fingerprint = bubblebabble( Digest => "Piña" );
# Crea una huella digital de un hash SHA-1.
use Digest::SHA1 qw( sha1 );
$fingerprint = bubblebabble( Digest => sha1("hola") );

DESCRIPCIÓN

Digest::BubbleBabble toma un resumen de mensaje (a menudo generado por cualquiera de los algoritmos de resumen de mensajes MD5 o SHA-1) y crea una huella digital de ese resumen en formato "bubble babble". Bubble babble es un método para representar un resumen de mensaje como una cadena de palabras "reales", para hacer que la huella digital sea más fácil de recordar. Las "palabras" no son necesariamente palabras reales, pero se parecen más a palabras que una cadena de caracteres hexadecimales.

El cifrado de huellas digitales bubble babble es utilizado por la suite SSH2 (y, en consecuencia, por Net::SSH::Perl, la implementación de Perl de SSH) para mostrar huellas digitales de claves fáciles de recordar. La clave (una clave DSA o RSA) se convierte a un formato textual, se resume usando Digest::SHA1 y se ejecuta a través de bubblebabble para crear la huella digital de la clave.

USO

Digest::BubbleBabble exporta condicionalmente una función llamada bubblebabble; para importar la función debes elegir importarla, así:

use Digest::BubbleBabble qw( bubblebabble );

bubblebabble( Digest => $digest )

Actualmente solo toma un par de argumentos, cuya clave debe ser Digest, cuyo valor es el resumen de mensaje real $digest. Debes generar este resumen de mensaje tú mismo usando Digest::MD5 o Digest::SHA1.

Devuelve la forma bubble babble del resumen.
