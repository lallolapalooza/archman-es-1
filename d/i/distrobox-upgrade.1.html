DISTROBOX-UPGRADE(1) Manual de usuario DISTROBOX-UPGRADE(1)

NOMBRE

distrobox-upgrade

DESCRIPCIÓN

distrobox-upgrade entrará en la lista especificada de contenedores y realizará una actualización utilizando el gestor de paquetes del contenedor.

SINOPSIS

distrobox upgrade

--help/-h:      mostrar este mensaje
--all/-a:       realizar para todos los distroboxes
--running:      realizar solo para distroboxes en ejecución
--root/-r:      lanzar podman/docker/lilipod con privilegios de root. Nota: si necesitas root, esta es la forma preferida
            en lugar de "sudo distrobox" (nota: si se utiliza un programa diferente a 'sudo' para privilegios de root,
            especifícalo a través de la variable de entorno DBX_SUDO_PROGRAM, o la variable de configuración 'distrobox_sudo_program')
--verbose/-v:       mostrar más verbosidad
--version/-V:       mostrar versión

EJEMPLOS

Actualizar todos los distroboxes

distrobox-upgrade --all

Actualizar todos los distroboxes en ejecución

distrobox-upgrade --all --running

Actualizar un distrobox específico

distrobox-upgrade alpine-linux

Actualizar una lista de distroboxes

distrobox-upgrade alpine-linux ubuntu22 my-distrobox123

Actualizar automáticamente todo el distro

Puedes crear un servicio systemd para realizar distrobox-upgrade automáticamente, este ejemplo muestra cómo ejecutarlo diariamente:

~/.config/systemd/user/distrobox-upgrade.service

[Unit]
Description=distrobox-upgrade Actualización Automática
[Service]
Type=simple
ExecStart=distrobox-upgrade --all
StandardOutput=null

~/.config/systemd/user/distrobox-upgrade.timer

[Unit]
Description=distrobox-upgrade Disparador de Actualización Automática
[Timer]
OnBootSec=1h
OnUnitInactiveSec=1d
[Install]
WantedBy=timers.target

Luego, simplemente haz un systemctl --user daemon-reload && systemctl --user enable --now distrobox-upgrade.timer
