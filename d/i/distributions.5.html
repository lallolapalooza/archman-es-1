NOMBRE

distributions - Valores recomendados para el campo de cabecera Distribution

DESCRIPCIÓN

El archivo pathetc/distributions contiene una lista de distribuciones relevantes y sus descripciones. Proporciona información local para los publicadores que deseen añadir un campo de cabecera Distribution a sus artículos para restringir su propagación, aunque no garantiza que tales artículos no se filtren a otros lugares debido a una mala configuración de un servidor de noticias al que se alimentan. Véase newsfeeds(5) para más información sobre cómo un servidor de noticias maneja el campo de cabecera Distribution.

Cada línea de este archivo consta de un área de distribución seguida de su descripción (codificada en UTF-8) después de al menos un espacio en blanco. Por ejemplo:

fr      Local a Francia.
local   Local a este servidor de noticias.
nj      Local a Nueva Jersey.
usa     Local a los Estados Unidos de América.

Las líneas en blanco y las líneas que comienzan con un signo de número ("#") se ignoran.

Cualquier cliente que emita el comando LIST DISTRIBUTIONS obtiene estos valores recomendados, si están disponibles. Sin embargo, tenga en cuenta que el uso del comando LIST DISTRIBUTIONS no está muy extendido (aunque está documentado en RFC 6048) y la mayoría de los clientes de noticias nunca pedirán este archivo.

Si este archivo está vacío, no es un error. El servidor simplemente enviará al cliente una respuesta vacía. Y si el archivo falta, el servidor también enviará al cliente una respuesta adecuada para indicar que la lista de distribuciones no se mantiene en el servidor.

El campo de cabecera Distribution también puede ser establecido automáticamente por nnrpd si distrib.pats(5) está correctamente configurado.

HISTORIA

VEASE TAMBIÉN
