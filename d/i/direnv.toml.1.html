[whitelist

]

Especificar directivas de lista blanca marca jerarquías de directorios específicas o directorios específicos como "confiables" -- direnv evaluará cualquier archivo .envrc coincidente independientemente de si han sido permitidos específicamente. Esta función debe usarse con mucho cuidado, ya que cualquier persona con la capacidad de escribir archivos en ese directorio (incluidos los colaboradores en repositorios de VCS) podrá ejecutar código arbitrario en su

computadora.

Hay dos tipos de directivas de lista blanca

admitidas:

prefi

x

Acepta una matriz de cadenas. Si alguna de las cadenas de esta lista es un prefijo de la ruta absoluta de un archivo .envrc, ese archivo se permitirá implícitamente, independientemente del contenido o del uso anterior de direnv allow o direnv d

eny.

Ejemplo

: 
[whitelist]
prefix = [ "/home/user/code/project-a", "~/code/project-b"
]

En este ejemplo, los siguientes archivos .envrc se permitirán

implícitamente:
  • /home/user/code/project-a/.
    • envrc
  • /home/user/code/project-a/subdir/.
    • envrc
  • ~/code/project-b/.
    • envrc
  • ~/code/project-b/subdir/.
    • envrc
  • y así
    • sucesiv
amente

En este ejemplo, los siguientes archivos .envrc no se permitirán implícitamente (aunque pueden permitirse explícitamente ejecutando direnv a

llow):
  • /home/user/project-c/.
    • envrc
  • /opt/ra
    • ndom
/.e
nvrc

exac

t

Acepta una matriz de cadenas. Cada cadena puede ser un nombre de directorio o la ruta completa a un archivo .envrc. Si se pasa un nombre de directorio, se tratará como si se hubiera pasado a sí mismo con /.envrc añadido. Después de resolver el nombre de archivo, cada cadena se comprobará para ver si coincide exactamente con la ruta absoluta de un archivo .envrc. Si coinciden exactamente, ese archivo .envrc se permitirá implícitamente, independientemente del contenido o del uso anterior de direnv allow o direnv d

eny.

Ejemplo

: 
[whitelist]
exact = [ "/home/user/project-a/.envrc", "~/project-b/subdir-a"
