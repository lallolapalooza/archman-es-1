NOMBRE

dispatch_semaphore_create, dispatch_semaphore_signal, dispatch_semaphore_wait — semáforo de conteo sincronizado

SINOPSIS

#include <dispatch/dispatch.h>

dispatch_semaphore_t
dispatch_semaphore_create(long count);

long
dispatch_semaphore_signal(dispatch_semaphore_t semaphore);

long
dispatch_semaphore_wait(dispatch_semaphore_t semaphore, dispatch_time_t timeout);

DESCRIPCIÓN

Los semáforos de dispatch se utilizan para sincronizar hilos.

La función dispatch_semaphore_wait() decrementa el semáforo. Si el valor resultante es menor que cero, espera una señal de un hilo que incrementa el semáforo llamando a dispatch_semaphore_signal() antes de regresar. El parámetro timeout se puede crear con las funciones dispatch_time(3) o dispatch_walltime(3). Si se alcanza el tiempo de espera sin recibir una señal, el semáforo se reincrementa antes de que la función regrese.

La función dispatch_semaphore_signal() incrementa el semáforo de conteo. Si el valor anterior era menor que cero, despierta a uno de los hilos que están esperando en dispatch_semaphore_wait() antes de regresar.

SINCRONIZACIÓN DE FINALIZACIÓN

Si el parámetro count es igual a cero, entonces el semáforo es útil para sincronizar la finalización del trabajo. Por ejemplo:

sema = dispatch_semaphore_create(0);

dispatch_async(queue, ^{
	foo();
	dispatch_semaphore_signal(sema);
});

bar();

dispatch_semaphore_wait(sema, DISPATCH_TIME_FOREVER);

GRUPO DE RECURSOS FINITOS

Si el parámetro count es mayor que cero, entonces el semáforo es útil para administrar un grupo finito de recursos. Por ejemplo, una biblioteca que quiere limitar el uso de descriptores Unix:

sema = dispatch_semaphore_create(getdtablesize() / 4);

En cada asignación de FD de Unix:

dispatch_semaphore_wait(sema, DISPATCH_TIME_FOREVER);
fd = open("/etc/services", O_RDONLY);

Cuando se cierra cada FD:

close(fd);
dispatch_semaphore_signal(sema);

VALORES DE RETORNO

La función dispatch_semaphore_create() devuelve NULL si no hay memoria disponible o si el parámetro count es menor que cero.

La función dispatch_semaphore_signal() devuelve un valor distinto de cero cuando se despierta un hilo. De lo contrario, devuelve cero.

La función dispatch_semaphore_wait() devuelve cero si tiene éxito y un valor distinto de cero después de que expira el tiempo de espera. Si el tiempo de espera es DISPATCH_TIME_FOREVER, entonces dispatch_semaphore_wait() espera para siempre y siempre devuelve cero.

MODELO DE MEMORIA

Los semáforos de dispatch se conservan y se liberan mediante llamadas a dispatch_retain() y dispatch_release().

ADVERTENCIAS

Los semáforos de dispatch desequilibrados no se pueden liberar. Para un semáforo dado, las llamadas a dispatch_semaphore_signal() y dispatch_semaphore_wait() deben estar equilibradas antes de que se les llame dispatch_release().
