Dir::Self(3) Documentación de Perl contribuida por el usuario Dir::Self(3)

NOMBRE

Dir::Self - una constante __DIR__ para el directorio en el que se encuentra tu archivo fuente

SINOPSIS

use Dir::Self;

use lib __DIR__ . "/lib";

my $conffile = __DIR__ . "/config";

DESCRIPCIÓN

Perl tiene dos pseudo-constantes que describen la ubicación actual en tu código fuente: "__FILE__" y "__LINE__". Este módulo añade "__DIR__", que se expande al directorio en el que se encuentra tu archivo fuente, como una ruta de archivo absoluta.

Esto es útil si tu código quiere acceder a archivos en el mismo directorio, como módulos auxiliares o datos de configuración. Esto es un poco como FindBin, excepto que no se limita al programa principal, es decir, también puedes usarlo en módulos. Y realmente funciona.

A partir de la versión 0.10, cada uso de "__DIR__" recalcula el nombre del directorio; esto asegura que los archivos en directorios diferentes que comparten el mismo nombre de paquete obtengan resultados correctos. Si no quieres esto, "use Dir::Self qw(:static)" creará una constante "__DIR__" verdadera en tu paquete que contendrá el nombre del directorio en el momento de la llamada "use".
