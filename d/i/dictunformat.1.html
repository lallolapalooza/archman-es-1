DICTUNFORMAT(1) Manual del usuario de Linux DICTUNFORMAT(1)

NOMBRE

dictunformat - crear un archivo de base de datos sin formato a partir de un archivo .dict y .index

SINOPSIS

dictunformat [OPCIONES] nombre_archivo_indice

DESCRIPCIÓN

dictunformat toma un archivo de índice de diccionario como parámetro y un archivo de base de datos de diccionario en la entrada estándar y produce una base de datos sin formato que puede ser utilizada para crear una base de datos DICT mediante dictfmt -t. Esto puede ser útil si se desea crear un diccionario para una localización diferente a aquella para la que se creó el original, o si se desea corregir o complementar un diccionario preexistente.

OPCIONES

--help
muestra un mensaje de uso y sale.
--headword-separator sep
sep es el separador de palabras clave utilizado al crear el diccionario original. (Ver --headword-separator en dictfmt (1)).
nombre_archivo_indice
es el archivo .index del diccionario original.
