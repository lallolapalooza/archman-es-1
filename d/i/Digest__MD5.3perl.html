NOMBRE

Digest::MD5 - Interfaz de Perl para el algoritmo MD5

SINOPSIS

# Estilo funcional
use Digest::MD5 qw(md5 md5_hex md5_base64);
my $digest = md5($data);
my $digest = md5_hex($data);
my $digest = md5_base64($data);
# Estilo orientado a objetos
use Digest::MD5;
my $ctx = Digest::MD5->new;
$ctx->add($data);
$ctx->addfile($file_handle);
$digest = $ctx->digest;
$digest = $ctx->hexdigest;
$digest = $ctx->b64digest;

DESCRIPCIÓN

El "Digest::MD5" módulo le permite usar el algoritmo de resumen de mensajes MD5 de RSA Data Security Inc. desde programas de Perl. El algoritmo toma como entrada un mensaje de longitud arbitraria y produce como salida una "huella digital" o "resumen de mensaje" de 128 bits de la entrada.

Tenga en cuenta que el algoritmo MD5 no es tan fuerte como solía ser. Desde 2005 ha sido fácil generar diferentes mensajes que producen el mismo resumen MD5. Todavía parece difícil generar mensajes que produzcan un resumen determinado, pero probablemente sea prudente pasar a algoritmos más fuertes para aplicaciones que dependan del resumen para identificar de forma única un mensaje.

El "Digest::MD5" módulo proporciona una interfaz procedimental para uso sencillo, así como una interfaz orientada a objetos que puede manejar mensajes de longitud arbitraria y que puede leer archivos directamente.

FUNCIONES

El siguiente módulo proporciona las siguientes funciones "Digest::MD5" . Ninguna de estas funciones se exporta de forma predeterminada.

md5($data,...)
Esta función concatenará todos los argumentos, calculará el resumen MD5 de este "mensaje" y lo devolverá en forma binaria. La cadena devuelta tendrá 16 bytes de longitud.

El resultado de md5("a", "b", "c") será exactamente el mismo que el resultado de md5("abc").

md5_hex($data,...)
Igual que md5(), pero devolverá el resumen en forma hexadecimal. La longitud de la cadena devuelta será 32 y solo contendrá caracteres de este conjunto: '0'..'9' y 'a'..'f'.
md5_base64($data,...)
Igual que md5(), pero devolverá el resumen como una cadena codificada en base64. La longitud de la cadena devuelta será 22 y solo contendrá caracteres de este conjunto: 'A'..'Z', 'a'..'z', '0'..'9', '+' y '/'.

Tenga en cuenta que la cadena codificada en base64 devuelta no está rellenada para que sea múltiplo de 4 bytes de longitud. Si desea interoperabilidad con otros resúmenes md5 codificados en base64, es posible que desee añadir la cadena redundante "==" al resultado.

MÉTODOS

La interfaz orientada a objetos para "Digest::MD5" se describe en esta sección. Después de que se haya creado un "Digest::MD5" objeto, le añadirá datos y finalmente pedirá el resumen en un formato adecuado. Un solo objeto se puede usar para calcular múltiples resúmenes.

Se proporcionan los siguientes métodos:

$md5 = Digest::MD5->new
El constructor devuelve un nuevo "Digest::MD5" objeto que encapsula el estado del algoritmo de resumen de mensajes MD5.

Si se llama como un método de instancia (es decir, $md5->new) simplemente restablecerá el estado del objeto al estado de un objeto recién creado. En este caso no se crea ningún objeto nuevo.

$md5->reset
Esto es solo un alias para $md5->new.
$md5->clone
Esta es una copia del $md5 objeto. Es útil cuando no desea destruir el estado del resumen, pero necesita un valor intermedio del resumen, por ejemplo, al calcular resúmenes iterativamente en un flujo de datos continuo. Ejemplo: 
my $md5 = Digest::MD5->new;
while (<>) {
    $md5->add($_);
    print "Línea $.: ", $md5->clone->hexdigest, "\n";
}
$md5->add($data,...)
El $data proporcionado como argumento se añade al mensaje para el que calculamos el resumen. El valor de retorno es el $md5 objeto mismo.

Todas estas líneas tendrán el mismo efecto en el estado del $md5 objeto:

$md5->add("a"); $md5->add("b"); $md5->add("c");
$md5->add("a")->add("b")->add("c");
$md5->add("a", "b", "c");
$md5->add("abc");
$md5->addfile($io_handle)
El $io_handle se leerá hasta EOF y su contenido se añadirá al mensaje para el que calculamos el resumen. El valor de retorno es el $md5 objeto mismo.

El addfile() método croak() si falla al leer datos por alguna razón. Si produce un error, es impredecible cuál será el estado del $md5 objeto. El addfile() método podría haber podido leer el archivo parcialmente antes de fallar. Es probablemente prudente descartar o restablecer el $md5 objeto si esto ocurre.

En la mayoría de los casos, querrá asegurarse de que el $io_handle esté en "binmode" antes de pasarlo como argumento al addfile() método.

$md5->add_bits($data, $nbits)
$md5->add_bits($bitstring)
Dado que el algoritmo MD5 está orientado a bytes, solo puede añadir bits como múltiplos de 8, por lo que probablemente quiera usar simplemente add() en su lugar. El add_bits() método se proporciona por compatibilidad con otras implementaciones de resúmenes. Consulte Digest para la descripción de los argumentos que add_bits() toma.
$md5->digest
Devuelve el resumen binario para el mensaje. La cadena devuelta tendrá 16 bytes de longitud.

Tenga en cuenta que la "digest" operación es efectivamente una operación destructiva de lectura única. Una vez que se ha realizado, el "Digest::MD5" objeto se "restablece" automáticamente y se puede usar para calcular otro valor de resumen. Llame a $md5->clone->digest si desea calcular el resumen sin restablecer el estado del resumen.

$md5->hexdigest
Igual que $md5->digest, pero devolverá el resumen en forma hexadecimal. La longitud de la cadena devuelta será 32 y solo contendrá caracteres de este conjunto: '0'..'9' y 'a'..'f'.
$md5->b64digest
Igual que $md5->digest, pero devolverá el resumen como una cadena codificada en base64. La longitud de la cadena devuelta será 22 y solo contendrá caracteres de este conjunto: 'A'..'Z', 'a'..'z', '0'..'9', '+' y '/'.

La cadena codificada en base64 devuelta no está rellenada para ser un múltiplo de 4 bytes de longitud. Si desea interoperabilidad con otros resúmenes md5 codificados en base64, es posible que desee añadir la cadena "==" al resultado.

@ctx = $md5->context
$md5->context(@ctx)
Guarda o restaura el estado interno. Cuando se llama sin argumentos, devuelve una lista: número de bloques procesados, un búfer de estado interno de 16 bytes y, opcionalmente, hasta 63 bytes de datos sin procesar si los hay. Cuando se le pasan esos mismos argumentos, restaura el estado. Esto solo es útil para operaciones especializadas.

EJEMPLOS

La forma más sencilla de usar esta biblioteca es importar la md5_hex() función (o una de sus primas):

use Digest::MD5 qw(md5_hex);
print "El resumen es ", md5_hex("foobarbaz"), "\n";

El ejemplo anterior imprimiría el mensaje:

El resumen es 6df23dc03f9b54cc38a0fc1483df6e21

La misma suma de comprobación también se puede calcular en estilo OO:

use Digest::MD5;
my $md5 = Digest::MD5->new;
$md5->add('foo', 'bar');
$md5->add('baz');
my $digest = $md5->hexdigest;
print "El resumen es $digest\n";

Con el estilo OO, puede dividir el mensaje arbitrariamente. Esto signins de modo que ya no estamos limitados a tener espacio para el mensaje completo en memoria, es decir, podemos manejar mensajes de cualquier tamaño.

Esto es útil al calcular el checksum de archivos:

use Digest::MD5;
my $filename = shift || "/etc/passwd";
open (my $fh, '<', $filename) or die "Can't open '$filename': $!";
binmode($fh);
my $md5 = Digest::MD5->new;
while (<$fh>) {
    $md5->add($_);
}
close($fh);
print $md5->b64digest, " $filename\n";

O podemos usar el método addfile para una lectura más eficiente del archivo:

use Digest::MD5;
my $filename = shift || "/etc/passwd";
open (my $fh, '<', $filename) or die "Can't open '$filename': $!";
binmode ($fh);
print Digest::MD5->new->addfile($fh)->hexdigest, " $filename\n";

Dado que el algoritmo MD5 solo está definido para cadenas de bytes, no se puede usar en cadenas que contengan caracteres con un número ordinal superior a 255 (cadenas Unicode). Las funciones y métodos MD5 emitirán un error fatal si intentas alimentarlos con tales datos de entrada:

use Digest::MD5 qw(md5_hex);
my $str = "abc\x{300}";
print md5_hex($str), "\n";  # emite un error fatal
# Wide character in subroutine entry

Lo que puedes hacer es calcular el checksum MD5 de la representación UTF-8 de tales cadenas. Esto se consigue filtrando la cadena a través de la función encode_utf8() :

use Digest::MD5 qw(md5_hex);
use Encode qw(encode_utf8);
my $str = "abc\x{300}";
print md5_hex(encode_utf8($str)), "\n";
# 8c2d46911f3f5a326455f0ed7a8ed3b3
