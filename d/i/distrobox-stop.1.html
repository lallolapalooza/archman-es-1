DISTROBOX-STOP(1) Manual de usuario DISTROBOX-STOP(1)

NOMBRE

distrobox stop
distrobox-stop

DESCRIPCIÓN

distrobox-stop detiene un distrobox en ejecución.

Los Distroboxes se dejan en ejecución, incluso después de salir de ellos, para que las entradas subsiguientes sean realmente rápidas. Así es como se pueden detener.

SINOPSIS

distrobox stop

--all/-a:       detener todos los distroboxes
--yes/-Y:       no interactivo, detener sin preguntar
--help/-h:      mostrar este mensaje
--root/-r:      iniciar podman/docker/lilipod con privilegios de root. Ten en cuenta que si necesitas root, esta es
            la forma preferida sobre "sudo distrobox" (nota: si usas un programa distinto de 'sudo' para privilegios
            de root, especifícalo a través de la variable de entorno DBX_SUDO_PROGRAM, o la variable de configuración
            'distrobox_sudo_program')
--verbose/-v:       mostrar más verbosidad
--version/-V:       mostrar versión

EJEMPLOS

distrobox-stop container-name1 container-name2
distrobox-stop container-name
distrobox-stop --all

También puedes usar variables de entorno para especificar el gestor de contenedores y el nombre:

DBX_CONTAINER_MANAGER="docker" DBX_CONTAINER_NAME=test-alpine distrobox-stop

VARIABLES DE ENTORNO

DBX_CONTAINER_MANAGER
DBX_CONTAINER_NAME
DBX_NON_INTERACTIVE
DBX_SUDO_PROGRAM
