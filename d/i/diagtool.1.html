NOMBRE

diagtool - herramienta de diagnósticos de clang

SINOPSIS

diagtool comando [argumentos]

DESCRIPCIÓN

diagtool es una combinación de cuatro herramientas para manejar diagnósticos en clang.

SUBCOMANDOS

diagtool está dividido en varios subcomandos, cada uno adaptado a un propósito diferente. Un breve resumen de cada comando sigue, con más detalles en las secciones posteriores.

  • find-diagnostic-id - Imprime el id del diagnóstico dado.
  • list-warnings - Lista las advertencias y sus flags correspondientes.
  • show-enabled - Muestra qué advertencias están habilitadas para una línea de comandos dada.
  • tree - Muestra los flags de advertencia en una vista de árbol.

find-diagnostic-id

diagtool find-diagnostic-id nombre-del-diagnóstico

list-warnings

diagtool list-warnings

show-enabled

diagtool show-enabled [opciones] nombre-archivo ...

tree

diagtool tree [grupo-de-diagnóstico]
