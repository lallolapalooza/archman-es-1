NOMBRE

dircolors - configuración de color para ls

SINOPSIS

dircolors [OPCIÓN]... [ARCHIVO]

DESCRIPCIÓN

Genera comandos para establecer la variable de entorno LS_COLORS.

Determinar el formato de la salida:

-b, --sh, --bourne-shell
genera código para el shell Bourne para establecer LS_COLORS
-c, --csh, --c-shell
genera código para el shell C para establecer LS_COLORS
-p, --print-database
muestra la base de datos de valores predeterminados
--print-ls-colors
genera los colores completamente escapados para visualización
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

Si se especifica ARCHIVO, léelo para determinar qué colores usar para qué tipos de archivo y extensiones. De lo contrario, se utiliza una base de datos precompilada. Para más detalles sobre el formato de estos archivos, ejecuta 'dircolors --print-database'.
