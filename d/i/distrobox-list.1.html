DISTROBOX-LIST(1) Manual de usuario DISTROBOX-LIST(1)

NOMBRE

distrobox list
distrobox-list

DESCRIPCIÓN

distrobox-list lista las distroboxes disponibles. Las detecta y las lista por separado del resto de los contenedores normales.

SINOPSIS

distrobox list

--help/-h:      mostrar este mensaje
--no-color:     desactivar el formato de color
--root/-r:      iniciar podman/docker/lilipod con privilegios de root. Nota: si necesitas root, esta es la forma preferida
            sobre "sudo distrobox" (nota: si usas un programa distinto de 'sudo' para privilegios de root es necesario,
            especifícalo a través de la variable de entorno DBX_SUDO_PROGRAM, o la variable de configuración 'distrobox_sudo_program')
--verbose/-v:       mostrar más verbosidad
--version/-V:       mostrar versión

EJEMPLOS

distrobox-list

También puedes usar variables de entorno para especificar el gestor de contenedores

DBX_CONTAINER_MANAGER="docker" distrobox-list

VARIABLES DE ENTORNO

DBX_CONTAINER_MANAGER
DBX_SUDO_PROGRAM
