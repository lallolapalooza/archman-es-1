DirHandle(3perl) Guía de Referencia del Programador de Perl DirHandle(3perl)

NOMBRE

DirHandle - (obsoleto) Suministra métodos de objeto para manejadores de directorios

SINOPSIS

# Enfoque recomendado desde Perl 5.6: no usar DirHandle
if (opendir my $d, '.') {
    while (readdir $d) { algo($_); }
    rewind $d;
    while (readdir $d) { otra_cosa($_); }
}
# cómo usarías este módulo si fueras a hacerlo
use DirHandle;
if (my $d = DirHandle->new(".")) {
    while (defined($_ = $d->read)) { algo($_); }
    $d->rewind;
    while (defined($_ = $d->read)) { otra_cosa($_); }
}

DESCRIPCIÓN

No hay ninguna razón para usar este módulo hoy en día.

El método "DirHandle" proporciona una interfaz alternativa a las funciones opendir(), closedir(), readdir() y rewinddir().

Hasta Perl 5.5, opendir() no podía autovivificar un manejador de directorio desde "undef", por lo que usar un manejador léxico requería usar una función de Symbol para crear un glob anónimo, lo que tomaba un paso adicional. "DirHandle" encapsula esto, lo que permitía un código más limpio que opendir(). Desde Perl 5.6, opendir() por sí solo ha sido todo lo que necesitas para manejadores léxicos.
