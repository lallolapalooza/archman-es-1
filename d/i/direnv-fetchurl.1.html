NOMBRE

direnv fetchurl - Obtener una URL a disco

SINOPSIS

direnv fetchurl []

DESCRIPCIÓN

Este comando descarga la URL dada a una ubicación fija en disco, basada en el contenido del archivo recuperado.

Esto se ha introducido para evitar una dependencia de curl o wget, al mismo tiempo que se promueve una forma más segura de obtener datos de Internet. Utilice esto en lugar de curl <url> | sh.

Este comando tiene dos modos de operación:

1.
Simplemente pasar la URL para descubrir el hash de integridad.
2.
Pasar la URL y el hash de integridad para obtener la ubicación en disco.

Dado que la ubicación en disco se basa en el hash, también actúa como una caché. Una implicación de este diseño es que las URLs deben ser estables y siempre devolver el mismo contenido.

Los archivos descargados se marcan como de solo lectura y ejecutables, por lo que también se pueden utilizar para obtener y ejecutar binarios estáticos.

OPCIONES


Una URL HTTP que devuelve contenido en solicitudes HTTP GET. Los redireccionamientos 301 y otros se siguen.


Cuando se pasa, la integridad del contenido recuperado se validará
contra el hash dado. La codificación del hash se basa en la especificación
SRI de W3C (ver https://www.w3.org/TR/SRI/ ).

SALIDA

direnv fetchurl produce una salida diferente según el argumento.

Si se pasa el hash-integridad, se mostrará la ruta a la ubicación en disco, si la recuperación fue exitosa.

Si solo se pasa la url, se mostrará el hash junto con instrucciones legibles. Si la salida estándar no es una tty, solo se mostrará el hash.

EJEMPLO

$ ./direnv fetchurl https://releases.nixos.org/nix/nix-2.3.7/install
Found hash: sha256-7Gxl5GzI9juc/U30Igh/pY+p6+gj5Waohfwql3jHIds=
Invoke fetchurl again with the hash as an argument to get the disk location:
  direnv fetchurl "https://releases.nixos.org/nix/nix-2.3.7/install" "sha256-7Gxl5GzI9juc/U30Igh/pY+p6+gj5Waohfwql3jHIds="
  #=> /home/zimbatm/.cache/direnv/cas/sha256-7Gxl5GzI9juc_U30Igh_pY+p6+gj5Waohfwql3jHIds=

VARIABLES DE ENTORNO

XDG_CACHE_HOME
Esta variable se utiliza para seleccionar la ubicación en disco de las URLs
obtenidas como $XDG_CACHE_HOME/direnv/cas. Si XDG_CACHE_HOME no está configurada o está vacía,
por defecto será $HOME/.cache.
