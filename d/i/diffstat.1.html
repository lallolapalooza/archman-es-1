DESCRIPCIÓ

N

Este programa lee la salida de diff y muestra un histograma de las inserciones, eliminaciones y modificaciones por archivo. Diffstat es un programa útil para revisar archivos de parche grandes y complejos. Lee de uno o más archivos de entrada que contienen la salida de diff, produciendo un histograma de las líneas totales modificadas para cada archivo

referenciado.

Si el nombre del archivo de entrada termina con “.bz2”, “.gz”, “.lzma”, “.xz”, “.zst”, “.z” o “.Z”, diffstat leerá los datos sin comprimir a través de una tubería desde el programa correspondiente. También puede inferir el tipo de compresión de los archivos enviados a través de la entrada

estándar.

Diffstat reconoce los tipos de salida más populares de diff

Si no se da ningún nombre de archivo en la línea de comandos, diffstat lee las diferenci

AMBIENTE

Diffstat se ejecuta en un entorno POSIX.

Puede anular las rutas compiladas de los programas utilizados para descomprimir archivos de entrada estableciendo variables de entorno correspondientes a su nombre:

DIFFSTAT_BZCAT_PATH
DIFFSTAT_BZIP2_PATH
DIFFSTAT_COMPRESS_PATH
DIFFSTAT_GZIP_PATH
DIFFSTAT_LZCAT_PATH
DIFFSTAT_PCAT_PATH
DIFFSTAT_UNCOMPRESS_PATH
DIFFSTAT_XZ_PATH
DIFFSTAT_ZCAT_PATH
DIFFSTAT_ZSTD_PATH

Sin embargo, diffstat asume que el programa resultante utiliza las mismas opciones de línea de comandos, por ejemplo, "-c" para descomprimir a la salida estándar.

ARCHIVOS

Diffstat es un módulo binario único, que no utiliza archivos auxiliares.

ERRORES

Diffstat hace muchas suposiciones sobre el formato de la salida de diff.

No hay forma de obtener un nombre de archivo de la salida estándar de diff entre dos archivos sin opciones. Las diffs de contexto funcionan, al igual que las diffs unificadas.

No hay una forma fácil de determinar el grado de solapamiento entre las visualizaciones "antes" y "después" de las líneas modificadas. Diffstat simplemente cuenta el número de líneas insertadas y eliminadas para aproximar las líneas modificadas para la opción -m.
