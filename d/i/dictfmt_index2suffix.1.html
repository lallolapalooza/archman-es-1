NOMBRE

dictfmt_index2suffix - Crea un archivo .suffix a partir de un archivo .index de una base de datos DICTD

SINOPSIS

dictfmt_index2suffix [OPCIONES] [archivo_indice]

DESCRIPCIÓN

dictfmt_index2suffix crea un archivo de índice de sufijos en la salida estándar para el archivo de índice proporcionado en la entrada estándar o en la línea de comandos. Un archivo de índice de sufijos es igual que el archivo .index, excepto que los caracteres de las palabras clave están invertidos. Un archivo de índice de sufijos normalmente se llama <basename>.suffix, pero esto no es obligatorio siempre que se use el nombre correcto en el archivo de configuración de dictd.

OPCIONES

--help
muestra un mensaje de uso y sale
--locale localización
usa la localización para ordenar el archivo .suffix. Si se omite esta opción, se usa la localización predeterminada "C".
archivo_indice
el archivo .index a convertir.
