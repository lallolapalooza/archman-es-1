NOMBRE

distccmon-text - Muestra los trabajos de compilación actuales en formato de texto.

SINTAXIS

distccmon-text [RETRASO]

DESCRIPCIÓN

Muestra los trabajos de compilación actuales en formato de texto. distccmon-text debe ejecutarse en la máquina cliente, con la misma configuración para DISTCC_DIR (o el directorio de inicio) que el usuario que ejecuta el cliente distcc.

OPCIONES

RETRASO
actualiza repetidamente después de retraso (fraccionario) segundos.

FORMATO DE SALIDA

La salida de distccmon-text contiene una línea por cada trabajo que se está compilando actualmente. Cada línea contiene las siguientes columnas:

PID
ID del proceso cliente de distcc.
ESTADO
Identifica la fase de operación. En orden, pueden ser "Startup", "Blocked", "Connected", "Preprocess", "Conect", "Send", "Receive" y "Done".
ARCHIVO
El nombre del archivo de entrada, si se conoce.
HOST[SLOT]
El nombre de host de la compilación. Puede ir seguido entre corchetes por el índice de la ranura para ese host.

Cuando se especifica un retraso, cada bloque de salida se termina con una línea en blanco.

EJEMPLOS

Para mostrar los trabajos activos actualmente (actualizado cada segundo):

distccmon-text 1

Para mostrar el estado una vez:

distccmon-text
