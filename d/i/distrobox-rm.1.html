DISTROBOX-RM(1) Manual de Usuario DISTROBOX-RM(1)

NOMBRE

distrobox rm
distrobox-rm

DESCRIPCIÓN

distrobox-rm elimina una de las distroboxes disponibles.

SINOPSIS

distrobox rm

--all/-a:       eliminar todas las distroboxes
--force/-f:     forzar la eliminación
--rm-home:      eliminar el home montado si difiere del del usuario anfitrión
--root/-r:      lanzar podman/docker/lilipod con privilegios de root. Nota: si necesitas root, esta es la forma preferida
            en lugar de "sudo distrobox" (nota: si se utiliza un programa distinto de 'sudo' para los privilegios de root,
            especifícalo a través de la variable de entorno DBX_SUDO_PROGRAM, o la variable de configuración 'distrobox_sudo_program')
--help/-h:      mostrar este mensaje
--verbose/-v:       mostrar más verbosidad
--version/-V:       mostrar versión

EJEMPLOS

distrobox-rm nombre-contenedor [--force] [--all]

También puedes usar variables de entorno para especificar el gestor de contenedores y el nombre:

DBX_CONTAINER_MANAGER="docker" DBX_CONTAINER_NAME=test-alpine distrobox-rm

VARIABLES DE ENTORNO

DBX_CONTAINER_MANAGER
DBX_CONTAINER_NAME
DBX_NON_INTERACTIVE
DBX_SUDO_PROGRAM
