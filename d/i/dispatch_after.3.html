dispatch_after(3) Manual de funciones de biblioteca dispatch_after(3)

NOMBRE

dispatch_after — planifica bloques para ejecución diferida

SINOPSIS

#include <dispatch/dispatch.h>

void
dispatch_after(dispatch_time_t when, dispatch_queue_t queue, void (^block)(void));

void
dispatch_after_f(dispatch_time_t when, dispatch_queue_t queue, void *context, void (*function)(void *));

DESCRIPCIÓN

La función dispatch_after() envía el bloque a la cola dada en el momento especificado por el parámetro when. El parámetro when es un valor creado por dispatch_time() o dispatch_walltime(). El envío del bloque puede ser retrasado por el sistema para mejorar el consumo de energía y el rendimiento del sistema. El sistema aplica un margen (ver dispatch_source_set_timer(3)) que es igual a una décima parte del intervalo entre when y el momento en que se llama a la función, con el margen limitado a al menos un milisegundo y como máximo un minuto.

Para una descripción más detallada sobre el envío de bloques a colas, ver dispatch_async(3).

ADVERTENCIAS

dispatch_after() retiene la cola pasada.

Se soporta la especificación de DISPATCH_TIME_NOW como parámetro when, pero no es tan eficiente como llamar a dispatch_async().

El resultado de pasar DISPATCH_TIME_FOREVER como parámetro when no está definido.

FUNDAMENTOS

La función dispatch_after() es una envoltura alrededor de dispatch_after_f().

VER TAMBIÉN

dispatch(3), dispatch_async(3), dispatch_time(3)
