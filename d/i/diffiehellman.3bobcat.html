FBB::DiffieHellman(3bobcat) Cálculos de clave Diffie Hellman FBB::DiffieHellman(3bobcat)

NOMBRE

FBB::DiffieHellman - PKI Diffie-Hellman, cálculo de claves compartidas

SINOPSIS

#include <bobcat/diffiehellman>
Opción de enlace: -lbobcat -lcrypto

DESCRIPCIÓN

La clase FBB::DiffieHellman calcula claves compartidas (secretos compartidos) utilizando el algoritmo Diffie-Hellman (1976). El algoritmo Diffie-Hellman utiliza información pública y privada, proporcionando una infraestructura de clave pública (PKI). La información pública consta de un primo (por ejemplo, un número primo que consta de 1024 bits), un generador (para el cual comúnmente se utiliza el valor 5) y (usando ** para representar el operador de potencia en valores enteros) el valor generador ** privado mod primo, donde privado es un número grande seleccionado aleatoriamente, que es la información privada.

El algoritmo Diffie-Hellman se utiliza comúnmente para calcular una clave compartida que puede usarse para cifrar información enviada entre dos partes. Una parte, que en esta página del manual se llama el iniciador, calcula el primo y define el generador. El primo es calculado por el primer constructor de FBB::DiffieHellman, mientras que el generador se pasa a este constructor como uno de sus argumentos. Para el generador, a menudo se utiliza el valor 5.

A continuación, el iniciador pasa su información pública, que consta del primo, el generador y el valor pow(generador, privado) mod primo a la otra parte, que en esta página del manual se llama el par. La información pública se escribe en forma binaria, big-endian, en un archivo utilizando el miembro save. El iniciador puede guardar opcionalmente la información privada en un archivo separado también.

El par, por lo tanto, recibe la información pública del iniciador. La información pública del iniciador es leída por un constructor de FBB::DiffieHellman que espera el nombre de un archivo o un std::istream que contiene la información pública del iniciador.

Habiendo obtenido el primo y el generador, la información pública (y, opcionalmente, privada) del par se guarda también llamando a save. Esto resulta, entre otras cosas, en el valor pow(generador, privado) mod primo, pero ahora usando la información privada del par.

En este punto, el par ya es capaz de calcular la clave compartida. La clave se devuelve llamando al miembro key, que devuelve la clave compartida como una serie de bytes almacenados en un std::string.

Antes de que el iniciador pueda calcular la clave compartida, el valor generador ** privado mod primo del par debe estar disponible. El par envía los datos públicos guardados al iniciador. El iniciador luego pasa los datos públicos del par, ya sea por nombre de archivo o por std::istream, al miembro key, devolviendo la clave compartida.

Secreto directo perfecto y Diffie Hellman efímero

Si el iniciador y el par deciden no guardar su información privada, se pueden obtener Secreto directo perfecto y Diffie Hellman efímero. Aquí, el procedimiento se aplica de la siguiente manera:

o
El iniciador y el par han acordado y intercambiado de forma segura un secreto común de larga duración, que puede usarse en combinación con, por ejemplo, métodos de cifrado simétrico.
o
Aplicando el procedimiento mencionado anteriormente, la información privada nunca se guarda en un archivo. En consecuencia, la clave compartida, una vez calculada, no puede ser reconstruida.
o
El valor generador ** privado mod primo no se envía al par ni al iniciador "en claro", sino que se cifra utilizando el secreto común de larga duración. Dado que la implementación actual guarda toda la información pública en un archivo, probablemente sea más fácil cifrar el archivo que contiene la información pública.
o
Los destinatarios, habiendo recibido la información pública cifrada de la otra parte, la descifran utilizando el secreto compartido de larga duración y calculan la clave compartida.
o
Como la información secreta no se conserva, la clave compartida no puede ser reconstruida, mientras que un ataque Man-In-The-Middle se previene intercambiando solo información pública cifrada.
o
La clave compartida ahora se puede utilizar para cifrar una sesión de comunicación.

Cifrado de documentos usando Diffie Hellman

Al igual que con la PKI en general, el método de intercambio de claves Diffie Hellman no se utiliza normalmente para cifrar documentos. En cambio, se utiliza habitualmente para intercambiar la clave que se utiliza para métodos de cifrado simétrico como 3DES y CBC. Estos métodos de cifrado simétrico están disponibles a través de, por ejemplo, las clases EncryptBuf, DecryptBuf y ISymCryptStream de Bobcat.

CONSTRUCTORES

o
DiffieHellman(size_t primeLength = 1024, size_t generator = 5, bool progress = false):
Este constructor calcula un número primo de la longitud especificada e inicializa la información pública con el generador indicado. La longitud del primo debe ser al menos 1024 o se lanzará una FBB::Exception. Si progress es true, el progreso del proceso de construcción del primo se muestra en std::cout mediante una serie de puntos, guiones y signos más. La generación de un primo adecuado puede fallar, lo que resultará en el lanzamiento de una FBB::Exception. A menos que el generador se especifique como 2 o 5, la advertencia cannot check the validity of generator ... se inserta en el objeto wmsg de mstream(3bobcat). También se inserta una advertencia si el generador proporcionado no es un generador para el primo calculado.
Este constructor debe ser llamado por el iniciador para comenzar el procedimiento de cálculo de la clave compartida Diffie-Hellman.
o
DiffieHellman(FBB::BigInt const &prime, size_t generator = 5, bool progress = false):
Alternativamente, este constructor puede ser utilizado por el iniciador después de haber construido el primo a utilizar por separado. El primo debe tener al menos 1024 bits de longitud.
o
DiffieHellman(std::string const &initiatorPublicFileName):
Este constructor debe ser llamado por el par, después de haber recibido la información pública del iniciador. Pone a disposición del par la información pública del iniciador, después de lo cual la información pública y privada del par puede ser calculada.
o
DiffieHellman(std::stream &initiatorPublicStream):
Este constructor actúa como el constructor anterior, esperando un std::istream en lugar de un nombre de archivo. Debe ser llamado por el par, después de haber recibido la información pública del iniciador. Pone a disposición del par la información pública del iniciador, después de lo cual la información pública y privada del par puede ser calculada.
o
DiffieHellman(std::string const &initiatorPublicFileName, std::string const &initiatorPrivateFileName):
A menos que el objeto DiffieHellman del iniciador todavía esté disponible, este constructor debe ser llamado nuevamente por el iniciador, para cargar los datos públicos y privados del iniciador.
o
DiffieHellman(std::stream &initiatorPublicStream, std::stream &initiatorPrivateStream):
Este constructor actúa como el constructor anterior, esperando std::istreams en lugar de nombres de archivo. Debe ser llamado por el iniciador, para cargar la información pública y privada del iniciador.

Los constructores de copia y movimiento (y los operadores de asignación) están disponibles.

EJEMPL

O

Cuando se llama sin argumentos, el programa de ejemplo genera parámetros Diffie-Hellman escribiendo la información pública y privada del iniciador en, respectivamente, init.pub y init.s

ec.

Cuando se llama con un argumento, init.pub se lee, y la información pública y privada del par se escribe en, respectivamente, peer.pub y peer.sec. A continuación, la clave compartida (del par) se escribe en peerkey

.

Cuando se llama con dos argumentos, init.pub y init.sec se leen, así como la información pública del par (en el archivo peer.pub). A continuación, la clave compartida (del iniciador) se escribe en initkey

.

Los archivos peerkey y initkey deberían ser

idénticos. 
#include <fstream>
#include <iostream>
#include <bobcat/exception>
#include "../diffiehellman"
using namespace FBB;
using namespace std;
int main(int argc, char **argv)
try
{
    if (argc == 1)
    {
        cout << "1: create prime and generator, write to ’params’\n"
                "2: create secret and public parts, arg 2: 0 or 1,\n"
                "   write secret and public parts to <arg 2>.sec and "
                                                     "<arg 2>.pub\n"
                "3: create common key arg 2: 0 or 1,\n"
                "   0: write common0 using 0.pub, 0.sec and 1.pub\n"
                "   1: write common1 using 1.pub, 1.sec and 0.pub\n"
                ;
        return 0;
    }
    switch (*argv[1])                       // using generator == 5
    {
        case ’1’:
        {
            ofstream out = Exception::factory<ofstream>("params");
            out << hex << DiffieHellman::prime(1024, true, true) << ’\n’;
        }
        break;
        case ’2’:
        {
            char *nr = argv[2];
            if (nr == 0 || "01"s.find(*nr) == string::npos)
                throw Exception{} << "mode ’2’ needs 0 or 1 as 2nd argument";
            ifstream in = Exception::factory<ifstream>("params");
            BigInt prime;
            in >> hex >> prime;
            DiffieHellman dh{ prime };
            dh.save(nr);
        }
        break;
        case ’3’:
        {
            char *nr = argv[2];
            if (nr == 0 || "01"s.find(*nr) == string::npos)
                throw Exception{} << "mode ’3’ needs 0 or 1 as 2nd argument";
            DiffieHellman dh{ nr + ".pub"s, nr + ".sec"s };
            cout << "common key computed by " << nr << ":\n" <<
                hex << dh.key((nr[0] == ’0’ ? ’1’ : ’0’) + ".pub"s) << ’\n’;
        }
        break;
        default:
        throw Exception{} << "undefined action `" << *argv[1] <<’\’’;
    }
}
catch (std::exception const &exc)
{
    std::cout << exc.what() << ’\n’;
}
