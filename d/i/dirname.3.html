basename(3) Manual de funciones de biblioteca basename(3)

NOMBRE

basename, dirname - analizar componentes de ruta de acceso

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <libgen.h>
char *dirname(char *path);
char *basename(char *path);

DESCRIPCIÓN

Advertencia: existen dos funciones basename() diferentes; véase más abajo.

Las funciones dirname() y basename() dividen una cadena de ruta de acceso terminada en nulo en componentes de directorio y nombre de archivo. En el caso habitual, dirname() devuelve la cadena hasta, pero sin incluir, la barra final ('/'), y basename() devuelve el componente que sigue a la barra final ('/'). Los caracteres de barra ('/') finales no se cuentan como parte de la ruta de acceso.

Si path no contiene una barra ('/'), dirname() devuelve la cadena "." mientras que basename() devuelve una copia de path. Si path es la cadena "/", entonces tanto dirname() como basename() devuelven la cadena "/". Si path es un puntero nulo o apunta a una cadena vacía, entonces tanto dirname() como basename() devuelven la cadena ".".

Al concatenar la cadena devuelta por dirname(), una "/" y la cadena devuelta por basename() se obtiene una ruta de acceso completa.

Tanto dirname() como basename() pueden modificar el contenido de path, por lo que puede ser conveniente pasar una copia al llamar a una de estas funciones.

Estas funciones pueden devolver punteros a memoria asignada estáticamente que puede ser sobrescrita por llamadas posteriores. Alternativamente, pueden devolver un puntero a alguna parte de path, por lo que la cadena a la que se refiere path no debe modificarse ni liberarse hasta que el puntero devuelto por la función ya no sea necesario.

La siguiente lista de ejemplos (tomada de SUSv2) muestra las cadenas devueltas por dirname() y basename() para diferentes rutas:

path dirname basename
/usr/lib /usr lib
/usr/ / usr
usr . usr
/ / /
. . .
.. . ..

VALOR DE RETORNO

Tanto dirname() como basename() devuelven punteros a cadenas terminadas en nulo. (No pase estos punteros a free(3).)

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
basename (), dirname () Seguridad de hilos MT-Safe

VERSIÓNES

Existen dos versiones diferentes de basename(): la versión POSIX descrita anteriormente y la versión GNU, a la que se accede después de


    #define _GNU_SOURCE         /* Véase feature_test_macros(7) */
    #include <string.h>

La versión GNU nunca modifica su argumento y devuelve la cadena vacía cuando path tiene una barra final, y en particular también cuando es "/". No existe una versión GNU de dirname().

Con glibc, se obtiene la versión POSIX de basename() cuando se incluye <libgen.h>, y la versión GNU en caso contrario.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

ERRORES

En la implementación de glibc, las versiones POSIX de estas funciones modifican el argumento path y fallan con segmentación si se llaman con una cadena estática como "/usr/".

Antes de glibc 2.2.1, la versión de glibc de dirname() no manejaba correctamente las rutas con barras finales ('/'), y generaba un error de segmentación si se le daba un argumento NULL.

EJEMPLOS

El siguiente fragmento de código demuestra el uso de basename() y dirname(): 

char *dirc, *basec, *bname, *dname;
char *path = "/etc/passwd";
dirc = strdup(path);
basec = strdup(path);
dname = dirname(dirc);
bname = basename(basec);
printf("dirname=%s, basename=%s\n", dname, bname);

VER TAMBIÉN

basename(1), dirname(1)
