DESCRIPCIÓ

N

Los objetos FBB::DigestBuf son objetos std::streambuf que pueden usarse para inicializar objetos std::

ostream.

Se calcula el resumen de mensaje de toda la información insertada en tal std::ostr

eam.

Todos los resúmenes de mensaje definidos por la biblioteca OpenSSL que pueden seleccionarse por nombre pueden usarse en combinación con objetos

DigestBuf.

Los algoritmos de resumen de mensaje actualmente soportados se muestran con openssl list -digest-commands. Los nombres de los algoritmos de resumen pueden usarse

para seleccionar un algoritmo de resumen par
a el constructor de la clase, más abajo.

CONSTRUCTORE

S
o
DigestBuf(char const *digestName, size_t bufsize = 1024):
Este constructor inicializa el streambuf, configurándolo para el algoritmo de resumen de mensaje especificado con type. Los algoritmos de resumen de mensaje especificados en la sección DESCRIPCIÓN pueden usarse aquí. Por ejemplo, para usar el algoritmo sha256 especifique "sha256
".
El argumento bufsize especifica el tamaño del búfer interno usado por DigestBuf para almacenar temporalmente los caracteres entrantes. El argumento
predeterminado proporcionado debería
estar bien en todos los casos normales.

Los constructores de copia y mov

imiento y los operadores de asig
nación no están disponibles.

El operador de inserción es una función libre definida en el espacio de nombres FBB. Inserta un valor hash como una serie de valores mostrados en hexadecimal en el ostream proporcionado. Vea el

FUNCIONES

MIEMBRO

Todos los miembros de std::streambuf están disponibles, ya que FBB::DigestBuf hereda de esta

clase.
o
void eoi():
Este miembro finaliza el cálculo del resumen de mensaje. Es necesario porque el objeto DigestBuf no tiene medios externos para decidir si toda la información para la que calcular el resumen ha sido recibida o no. El enfoque general a seguir al calcular un resumen de mensaje es por lo tanto: 
    1. crear un objeto DigestBuf
    2. usarlo para crear un objeto std::ostream
    3. insertar informaci
ón en el objeto ostream 4. llamar al miembro eoi() del objeto DigestBuf o insertar el man
ipulador eoi en el ostream (vea más abajo) 5. obtener/procesar el valor hash del objeto DigestBuf.
o
std::string const &hash() const:
Este miembro devuelve el valor hash calculado por el objeto DigestBuf. Su valor solo está definido después de haber llamado a close(). El valor hash se devuelve en un objeto std::string. El miembro length() de esta cadena contiene el número de caracteres usados por el valor hash, y su miembro data() se refiere a los caracteres del valor hash. Tenga en cuenta que el valor de carácter de un valor hash puede ser 0 (no confundir con ’0’
).
o
void reset():
Este miembro reinicializa el cálculo del resumen de mensaje. Una vez que se ha calculado un resumen de mensaje para, digamos, un flujo streamA, este miembro puede llamarse, después de lo cual el resumen para un flujo streamB puede calcularse usando el mismo objeto
Dig
estB
uf.

MANIPULADO

R
o
FBB::eoi:
El manipulador eoi puede insertarse en el ostream para completar el resumen. Realiza las mismas acciones que el miembro eoi. Si se inserta en un std::ostream s
imple, n
o ocurr
e nada.

EJEMPL

O 
#include <iostream>
#include <ostream>
#include <bobcat/digestbuf>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
    DigestBuf digestbuf(argc == 1 ? "sha256" : argv[1]);
    ostream out(&digestbuf);
    string hw("hello world\n");
    out << hw << eoi;
    cout << ">" << digestbuf << "<" << endl;
    digestbuf.reset();
    out.write(hw.c_str(), hw.length()) << eoi;
    cout << ">" << digestbuf << "<" << endl;
}
catch(exception const &err)
{
    cout << err.what() << endl;
    return 1;
}
