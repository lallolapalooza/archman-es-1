dirent.h(0P) Manual del programador POSIX dirent.h(0P)

PROLOG

Esta página de manual es parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página de manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

dirent.h — formato de las entradas de directorio

SINOPSIS

#include <dirent.h>

DESCRIPCIÓN

El formato interno de los directorios no está especificado.

La cabecera <dirent.h> definirá el siguiente tipo:

DIR
Un tipo que representa un flujo de directorio. El tipo DIR puede ser un tipo incompleto.

También definirá la estructura dirent que incluirá los siguientes miembros:

ino_t  d_ino       Número de serie del archivo.
char   d_name[]    Cadena del nombre de archivo de la entrada.

La cabecera <dirent.h> definirá el tipo ino_t tal como se describe en <sys/types.h>.

El array d_name es de tamaño no especificado, pero contendrá un nombre de archivo de como máximo {NAME_MAX} bytes seguido de un byte nulo de terminación.

Se declararán las siguientes funciones y también pueden definirse como macros. Se proporcionarán prototipos de función.

int            alphasort(const struct dirent **, const struct dirent **);
int            closedir(DIR *);
int            dirfd(DIR *);
DIR           *fdopendir(int);
DIR           *opendir(const char *);
struct dirent *readdir(DIR *);
int            readdir_r(DIR *restrict, struct dirent *restrict,
                   struct dirent **restrict);
void           rewinddir(DIR *);
int            scandir(const char *, struct dirent ***,
                   int (*)(const struct dirent *),
                   int (*)(const struct dirent **,
                   const struct dirent **));
void           seekdir(DIR *, long);
long           telldir(DIR *);

Las siguientes secciones son informativas.

USO DE APLICACIONES

Ninguno.

FUNDAMENTOS RACIONALES

Información similar a la contenida en la cabecera <dirent.h> se encuentra en un archivo <sys/dir.h> en 4.2 BSD y 4.3 BSD. El equivalente en estas implementaciones de struct dirent de este volumen de POSIX.1‐2017 es struct direct. El nombre del archivo se cambió porque el nombre <sys/dir.h> también se usaba en implementaciones anteriores para referirse a definiciones relacionadas con el método de acceso más antiguo; esto producía conflictos de nombres. El nombre de la estructura se cambió porque este volumen de POSIX.1‐2017 no define completamente lo que hay en la estructura, por lo que podría ser diferente en algunas implementaciones de struct direct.

El nombre de un array de char de tamaño no especificado no debe usarse como lvalue. El uso de:

sizeof(d_name)

es incorrecto; use en su lugar:

strlen(d_name)

El array de char d_name no tiene un tamaño fijo. Las implementaciones pueden necesitar declarar struct dirent con un tamaño de array para d_name de 1, pero el número real de bytes proporcionados coincide (o solo excede ligeramente) la longitud de la cadena del nombre de archivo.
