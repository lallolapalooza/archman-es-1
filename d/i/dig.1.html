DESCRIPCIÓ

N

dig es una herramienta flexible para interrogar servidores de nombres DNS. Realiza búsquedas DNS y muestra las respuestas que son devueltas por los servidores de nombres que fueron consultados. La mayoría de los administradores DNS utilizan dig para solucionar problemas de DNS debido a su flexibilidad, facilidad de uso y claridad de salida. Otras herramientas de búsqueda tienden a tener menos funcionalidad que dig

.

Aunque dig normalmente se usa con argumentos de línea de comandos, también tiene un modo de operación por lotes para leer solicitudes de búsqueda desde un archivo. Un breve resumen de sus argumentos y opciones de línea de comandos se imprime cuando se proporciona la opción -h. La implementación de BIND 9 de dig permite emitir múltiples búsquedas desde la línea de

comandos.

A menos que se le indique consultar un servidor de nombres específico, dig prueba cada uno de los servidores listados en /etc/resolv.conf. Si no se encuentran direcciones de servidor utilizables, dig envía la consulta al host

local.

Cuando no se proporcionan argumentos ni opciones de línea de comandos, dig realiza una consulta NS para "." (la raíz)

.

Es posible establecer valores predeterminados por usuario para dig a través de ${HOME}/.digrc. Este archivo se lee y cualquier opción en él se aplica antes de los argumentos de la línea de comandos. La opción -r desactiva esta función, para scripts que necesitan un comportamiento

predecible.

Los nombres de clase IN y CH se superponen con los nombres de dominio de nivel superior IN y CH. Utilice las opciones -t y -c para especificar el tipo y la clase, use -q para especificar el nombre de dominio, o use "IN." y "CH." al buscar estos dominios de nivel superior

.

CONSULTAS

MÚLTIPLES

La implementación de BIND 9 de dig soporta la especificación de múltiples consultas en la línea de comandos (además de soportar la opción -f batch file). Cada una de esas consultas puede proporcionarse con su propio conjunto de indicadores, opciones y opciones de

consulta.

En este caso, cada argumento de consulta representa una consulta individual en la sintaxis de la línea de comandos descrita arriba. Cada una consiste en cualquiera de las opciones e indicadores estándar, el nombre a buscar, un tipo y clase de consulta opcionales, y cualquier opción de consulta que deba aplicarse a esa

consulta.

También puede proporcionarse un conjunto global de opciones de consulta, que debe aplicarse a todas las consultas. Estas opciones de consulta globales deben preceder al primer tupla de nombre, clase, tipo, opciones, indicadores y opciones de consulta proporcionado en la línea de comandos. Cualquier opción de consulta global (excepto +cmd y +short) puede ser anulada por un conjunto específico de opciones de consulta. Por

ejemplo: 
dig +qr www.i
sc.org any -x
127.0.0.1 isc
.org ns +noqr

muestra cómo dig puede usarse desde la línea de comandos para hacer tres búsquedas: una consulta ANY para www.isc.org, una búsqueda inversa de 127.0.0.1, y una consulta para los registros NS de isc.org. Se aplica una opción de consulta global de +qr, de modo que dig muestra la consulta inicial que hizo para cada búsqueda. La consulta final tiene una opción de consulta local de +noqr, lo que significa que dig no imprime la consulta inicial cuando busca los

registros
NS para

isc.

org.
