diameterc(1) Comandos de usuario diameterc(1)

NOMBRE

diameterc - Compila un diccionario diameter a código fuente de Erlang

SINOPSIS

diameterc [<opciones>] <archivo>

DESCRIPCIÓN

La utilidad diameterc se utiliza para compilar un archivo de diccionario diameter a código fuente de Erlang. El código fuente resultante implementa la interfaz diameter requerida para codificar y decodificar los mensajes y AVPs del diccionario.

El módulo diameter_make proporciona una interfaz de compilación alternativa.

USO

Compila un único archivo de diccionario a código fuente de Erlang. Las opciones válidas son las siguientes.

-i <dir>

Antepone el directorio especificado a la ruta de código. Úselo para apuntar a archivos beam compilados a partir de diccionarios heredados, @inherits en un archivo de diccionario crea una dependencia de beam, no una dependencia de erl/hrl.

Se pueden especificar múltiples opciones -i.

-o <dir>

Escribe el código fuente generado en el directorio especificado. Por defecto es el directorio de trabajo actual.

-E

Suprime la generación de archivos .erl.

-H

Suprime la generación de archivos .hrl.

--name <nombre>

Nombra el módulo de salida.

--prefix <prefijo>

Transforma el diccionario de entrada antes de la compilación, estableciendo @name o @prefix a la cadena especificada.

--inherits <arg>

Transforma el diccionario de entrada antes de la compilación, añadiendo @inherits de la cadena especificada.

Dos formas de --inherits tienen un significado especial:

--inherits -
--inherits Prev/Mod

La primera tiene el efecto de borrar cualquier herencia previa, la segunda de reemplazar una herencia previa de Prev por una de Mod. Esto permite cambiar la semántica del diccionario de entrada sin modificar el archivo.

Se pueden especificar múltiples opciones --inherits.

CÓDIGO DE SALIDA

Devuelve 0 en caso de éxito, un valor distinto de cero en caso de fallo.

VER TAMBIÉN

diameter_make, diameter_dict(4)
