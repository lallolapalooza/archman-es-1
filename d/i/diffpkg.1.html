NOMBRE

diffpkg - Compara archivos de paquetes usando diferentes modos.

SINOPSIS

diffpkg [OPCIONES] [MODOS] [ARCHIVO|NOMBREPAQUETE...]

DESCRIPCIÓN

Busca un paquete construido localmente que corresponda al PKGBUILD y descarga la última versión de ese paquete de los repositorios de Pacman. Luego compara los archivos de paquetes usando diferentes modos, mientras utiliza una simple lista de contenido de tar por defecto.

Cuando se le da un paquete, úselo para compararlo con el construido localmente. Cuando se le dan dos paquetes, compárelos entre sí.

En cualquier caso, un nombre de paquete se convertirá en un nombre de archivo desde la caché o el pool, y diffpkg procederá como si este nombre de archivo se hubiera especificado inicialmente.

OPCIONES

-M, --makepkg-config

Establece un archivo de configuración alternativo para makepkg

-P, --pool=DIR

Busca el objetivo de la diferencia en el directorio del pool (por defecto '/srv/ftp/pool')

-v, --verbose

Proporciona una salida más detallada/sin filtrar

-h, --help

Muestra un texto de ayuda

OPCIONES DE SALIDA

--color[=CUÁNDO]

Colorea la salida; CUÁNDO puede ser 'nunca', 'siempre' o 'automático'; --color sin argumento significa --color=automático

-u, -U, --unified

Muestra 3 líneas de contexto unificado

-y, --side-by-side

Muestra en dos columnas

-W, --width[=NÚM]

Muestra como máximo NÚM (por defecto 'automático') columnas de impresión; NÚM puede ser 'automático', 'columnas' o un número. 'automático' se resolverá a la longitud máxima de línea de ambos archivos, garantizando que la diferencia no se corte.

MODOS

-l, --list

Activa el modo de diferencia de lista de contenido de tar (por defecto)

-d, --diffoscope

Activa el modo de diferencia de diffoscope

-p, --pkginfo

Activa el modo de diferencia de .PKGINFO

-b, --buildinfo

Activa el modo de diferencia de .BUILDINFO

PÁGINA PRINCIPAL

https://gitlab.archlinux.org/archlinux/devtools
