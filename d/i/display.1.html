display(1) Manual de Comandos Generales display(1)

NOMBRE

display - muestra una imagen o una secuencia de imágenes en cualquier servidor X.

SINOPSIS

magick display [opciones] archivo-de-entrada

DESCRIPCIÓN GENERAL

El programa display es un miembro del conjunto de herramientas ImageMagick(1). Úselo para mostrar una imagen o una secuencia de imágenes en cualquier servidor X.

Para obtener más información sobre el comando display, dirija su navegador a file:///usr/share/doc/ImageMagick-7/www/display.html o a https://imagemagick.org/script/display.php.

DESCRIPCIÓN

Configuraciones de la imagen:
-alpha opción on, activate, off, deactivate, set, opaque, copy
transparent, extract, background, o shape
-antialias elimina el aliasing de píxeles
-authenticate valor descifra la imagen con esta contraseña
-backdrop muestra la imagen centrada sobre un fondo
-colormap tipo Shared o Private
-colorspace tipo espacio de color alternativo para la imagen
-comment cadena anota la imagen con un comentario
-compress tipo tipo de compresión de píxeles al escribir la imagen
-decipher nombre-de-archivo convierte píxeles cifrados en píxeles sin cifrar
-deskew umbral endereza una imagen
-define formato:opción
define una o más opciones de formato de imagen
-delay centésimas muestra la siguiente imagen después de una pausa
-density geometría densidad horizontal y vertical de la imagen
-depth valor profundidad de la imagen
-display servidor muestra la imagen en este servidor X
-dispose método método de eliminación de capas
-dither método aplica difusión de error a la imagen
-tipo endian finianness (MSB o LSB) de la imagen
-equalize realiza ecualización de histograma en una imagen
-filter tipo usa este filtro al redimensionar una imagen
-format "cadena" salida de características de imagen formateadas
-fuzz distancia los colores dentro de esta distancia se consideran iguales
-geometry geometría tamaño y ubicación preferidos de la ventana de la imagen
-gravity tipo colocación horizontal y vertical del fondo
-identify identifica el formato y las características de la imagen
-immutable la imagen mostrada no puede ser modificada
-interlace tipo tipo de esquema de entrelazado de la imagen
-interpolate método método de interpolación de color de píxeles
-label cadena asigna una etiqueta a una imagen
-limit tipo valor límite de recursos de la caché de píxeles
-loop iteraciones repite las imágenes y luego sale
-map tipo muestra la imagen usando este Mapa de Colores Estándar
-matte almacena el canal mate si la imagen tiene uno
-monitor monitorea el progreso
-page geometría tamaño y ubicación de un lienzo de imagen
-profile nombre-de-archivo añade, elimina o aplica un perfil de imagen
-quality valor nivel de compresión JPEG/MIFF/PNG
-quantize espacio-de-color reduce los colores en este espacio de color
-quiet suprime todos los mensajes de advertencia
-regard-warnings presta atención a los mensajes de advertencia
-remote comando ejecuta un comando en un proceso display remoto
-repage geometría tamaño y ubicación de un lienzo de imagen (operador)
-respect-parentheses la configuración permanece vigente hasta el límite del paréntesis
-sampling-factor geometría
factor de muestreo horizontal y vertical
-scenes rango rango de escenas de la imagen
-seed valor semilla para una nueva secuencia de números pseudoaleatorios
-set propiedad valor establece una propiedad de la imagen
-size geometría ancho y alto de la imagen
-support factor soporte de redimensionamiento: > 1.0 es borroso, < 1.0 es nítido
-texture nombre-de-archivo nombre de la textura para mosaico en el fondo de la imagen
-transparent-color color
color transparente
-treedepth valor profundidad del árbol de colores
-update segundos detecta cuándo se modifica el archivo de imagen y vuelve a mostrarlo
-verbose imprime información detallada sobre la imagen
-visual tipo muestra la imagen usando este tipo visual
-virtual-pixel método
método de acceso a píxeles virtuales
-window id muestra la imagen en el fondo de esta ventana
-window-group id sale del programa cuando se destruye este id de ventana
-write nombre-de-archivo escribe la imagen en un archivo

Operadores de la imagen:
-auto-orient orienta automáticamente la imagen
-border geometría rodea la imagen con un borde de color
-channel mask establece la máscara del canal de la imagen
-clip recorta a lo largo de la primera ruta del perfil 8BIM
-clip-path id recorta a lo largo de una ruta con nombre del perfil 8BIM
-colors valor número preferido de colores en la imagen
-contrast mejora o reduce el contraste de la imagen
-crop geometría tamaño y ubicación preferidos de la imagen recortada
-despeckle reduce las manchas dentro de una imagen
-edge factor aplica un filtro para detectar bordes en la imagen
-enhance aplica un filtro digital para mejorar una imagen ruidosa
-extent geometría establece el tamaño de la imagen
-extract geometría extrae un área de la imagen
-flip voltea la imagen en la dirección vertical
-flop voltea la imagen en la dirección horizontal
-frame geometría rodea la imagen con un borde ornamental
-gamma valor nivel de corrección gamma
-monochrome transforma la imagen a blanco y negro
-negate reemplaza cada píxel con su color complementario
-normalize transforma la imagen para abarcar el rango completo de colores
-raise valor aclara/oscurece los bordes de la imagen para crear un efecto 3D
-resample geometría cambia la resolución de una imagen
-resize geometría redimensiona la imagen
-roll geometría desplaza una imagen vertical u horizontalmente
-rotate grados aplica una rotación Paeth a la imagen
-sample geometría escala la imagen con muestreo de píxeles
-segment valor segmenta una imagen
-sharpen geometría enfoca la imagen
-strip elimina de la imagen todos los perfiles y comentarios
-threshold valor umbraliza la imagen
-thumbnail geometría crea una miniatura de la imagen
-trim recorta los bordes de la imagen

Operadores de secuencia de imágenes:
-coalesce fusiona una secuencia de imágenes
-flatten aplana una secuencia de imágenes

Opciones diversas:
-debug eventos muestra información de depuración extensa
-help imprime las opciones del programa
-log format formato de la información de depuración
-list tipo imprime una lista de argumentos de opción admitidos
-version imprime la información de la versión

Además de las opciones enumeradas anteriormente, puede especificar estos recursos X estándar como opciones de línea de comandos: -background, -bordercolor, -borderwidth, -font, -foreground, -iconGeometry, -iconic, -mattecolor, -name, -shared-memory, -usePixmap o -title.

Por defecto, el formato de imagen de `file' se determina por su número mágico. Para especificar un formato de imagen en particular, preceda el nombre del archivo con un nombre de formato de imagen y dos puntos (es decir, ps:image) o especifique el tipo de imagen como sufijo del nombre de archivo (es decir, image.ps). Especifique 'file' como '-' para la entrada o salida estándar.

Botones:
1 presione para mostrar u ocultar el widget de comandos
2 presione y arrastre para ampliar una región de una imagen
3 presione para cargar una imagen de un directorio de imágenes visual

NOTA

El programa display usa por defecto la resolución de la pantalla X. Para mostrar formatos vectoriales en su tamaño previsto, anule la resolución predeterminada:


display -density 72 drawing.svg
