Módulo BLAKE512
: S

BLAKE512 es la función hash BLAKE2b que produce resúmenes de 512 bits (64 bytes). Es criptográficamente segura y los resúmenes son lo suficientemente grandes como para frustrar ataques de fuerza bruta.

Desde 5.2

tipo t = cadena

El tipo de resúmenes.

valor hash_length : int

La longitud de los resúmenes, en bytes.

valor compare : t -> t -> int

Compara dos resúmenes, con la misma especificación que compare.

valor equal : t -> t -> bool

Comprueba la igualdad de dos resúmenes.

valor string : cadena -> t

Devuelve el resumen de la cadena dada.

valor bytes : bytes -> t

Devuelve el resumen de la secuencia de bytes dada.

valor substring : cadena -> int -> int -> t

substring s ofs len devuelve el resumen de la subcadena de s que comienza en el índice ofs y contiene len caracteres.

valor subbytes : bytes -> int -> int -> t

subbytes s ofs len devuelve el resumen de la sub-secuencia de s que comienza en el índice ofs y contiene len bytes.

valor channel : in_channel -> int -> t

Lee caracteres del canal y devuelve su resumen. Consulte Digest.channel para ver la especificación completa.

valor file : cadena -> t

Devuelve el resumen del archivo cuyo nombre se proporciona.

valor output : out_channel -> t -> unit

Escribe un resumen en el canal de salida proporcionado.

valor input : in_channel -> t

Lee un resumen del canal de entrada proporcionado.

valor to_hex : t -> cadena

Devuelve la representación hexadecimal imprimible del resumen dado.

Genera Invalid_argument si la longitud del argumento no es hash_length.

valor of_hex : cadena -> t

Convierte una representación hexadecimal de nuevo en el resumen correspondiente.

Genera Invalid_argument si la longitud del argumento no es 2 * hash_length, o si los argumentos contienen caracteres que no son hexadecimales.
