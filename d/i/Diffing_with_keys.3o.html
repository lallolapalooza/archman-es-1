Al comparar listas donde cada elemento tiene una clave distinta, podemos refinar el parche de comparación introduciendo dos movimientos de edición compuestos: intercambios y movimientos.

Swap (intercambio) intercambia la posición de dos elementos. El coste de Swap se establece en 2 * cambio - epsilon . Move (movimiento) cambia la posición de un elemento. El coste de Move se establece en borrado + adición - epsilon .

Cuando el coste borrado + adición es mayor que cambio y con estos pesos específicos, el parche óptimo con Swap s y Move s se puede calcular directa y económicamente a partir del parche óptimo original.

}

tipo ('l, 'r, 'diff) desajuste =
| Nombre de {
pos : int ;
got : string ;
expected : string ;
tipos_coinciden : bool ;
}
| Tipo de {
pos : int ;
got : 'l ;
expected : 'r ;
razon : 'diff ;
}

tipo ('l, 'r, 'diff) cambio =
| Cambio de ('l, 'r, 'diff) desajuste
| Intercambio de {
pos : int * int ;
primero : string ;
ultimo : string ;
}
| Movimiento de {
nombre : string ;
got : int ;
expected : int ;
}
| Insercion de {
pos : int ;
insertar : 'r ;
}
| Borrado de {
pos : int ;
borrar : 'l ;
}

Esta versión especializada de cambios introduce dos cambios compuestos: Movimiento y Intercambio
