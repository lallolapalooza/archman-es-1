NOMBRE

dispatch_once — ejecuta un bloque solo una vez

SINOPSIS

#include <dispatch/dispatch.h>

void
dispatch_once(dispatch_once_t *predicado, void (^bloque)(void));

void
dispatch_once_f(dispatch_once_t *predicado, void *contexto, void (*funcion)(void *));

DESCRIPCIÓN

La función dispatch_once() proporciona un mecanismo simple y eficiente para ejecutar un inicializador exactamente una vez, similar a pthread_once(3). El código bien diseñado oculta el uso de la inicialización perezosa. Por ejemplo:

FILE *obtener_archivo_log(void)
{
	static dispatch_once_t pred;
	static FILE *archivo_log;

	dispatch_once(&pred, ^{
		archivo_log = fopen(MI_ARCHIVO_LOG, "a");
	});

	return archivo_log;
}

FUNDAMENTOS

La función dispatch_once() es un envoltorio para dispatch_once_f().
