DisplayOfCCC(3) FUNCIONES DE XLIB DisplayOfCCC(3)

NOMBRE

DisplayOfCCC, VisualOfCCC, ScreenNumberOfCCC, ScreenWhitePointOfCCC, ClientWhitePointOfCCC - Macros de Contexto de Conversión de Color

SINTAXIS

Display *DisplayOfCCC(XcmsCCC ccc);

Visual *VisualOfCCC(XcmsCCC ccc);

int ScreenNumberOfCCC(XcmsCCC ccc);

XcmsColor *ScreenWhitePointOfCCC(XcmsCCC ccc);

XcmsColor *ClientWhitePointOfCCC(XcmsCCC ccc);

ARGUMENTOS

ccc
Especifica el CCC.

DESCRIPCIÓN

La macro DisplayOfCCC devuelve la pantalla asociada con el CCC especificado.

La macro VisualOfCCC devuelve la visual asociada con el CCC especificado.

La macro ScreenNumberOfCCC devuelve el número de pantalla asociada con el CCC especificado.

La macro ScreenWhitePointOfCCC devuelve el punto blanco de pantalla de la pantalla asociada con el CCC especificado.

La macro ClientWhitePointOfCCC devuelve el punto blanco del cliente de la pantalla asociada con el CCC especificado.

VER TAMBIÉN
