NOMBRE

distrib.pats - Valores predeterminados para el campo de encabezado Distribution

DESCRIPCIÓN

El archivo pathetc/distrib.pats es utilizado por nnrpd para determinar el cuerpo predeterminado del campo de encabezado Distribution. Las líneas en blanco y las líneas que comienzan con un signo numérico ("#") se ignoran. Todas las demás líneas consisten en tres campos separados por dos puntos:

<peso>:<patrón>:<valor>

El primer campo es el peso a asignar a esta coincidencia. Si un grupo de noticias coincide con varias líneas, se utilizará la línea con el peso más alto. Este debe ser un entero arbitrario mayor que cero. El orden de las líneas en el archivo solo es importante si los grupos tienen el mismo peso (en cuyo caso, se utilizará la primera línea coincidente).

El segundo campo es el nombre de un grupo de noticias o un patrón estilo uwildmat para especificar un conjunto de grupos de noticias.

El tercer campo es el cuerpo que debe usarse para el campo de encabezado Distribution de un artículo publicado, si esta línea se eligió como la mejor coincidencia y el usuario no proporcionó ningún campo de encabezado Distribution. Puede ser una cadena vacía, especificando que no se debe agregar ningún campo de encabezado Distribution. Si no está vacío, es mejor usar solo caracteres US-ASCII para ese campo; de lo contrario, asegúrese de que esté codificado en UTF-8.

Cuando nnrpd recibe una publicación que aún no contiene un campo de encabezado Distribution, cada grupo de noticias al que se publica un artículo se verificará en este archivo por turno, y la línea coincidente con el peso más alto se utilizará como cuerpo del campo de encabezado Distribution. Si ninguna línea coincide, o si la línea coincidente tiene una cadena vacía para su tercer campo, no se agregará ningún campo de encabezado. En caso de que nnrpd agregue una distribución, asegúrese de que no sea rechazada por la entrada "ME" de newsfeeds.

Una lista de distribuciones recomendadas se puede especificar y describir en distributions(5).
