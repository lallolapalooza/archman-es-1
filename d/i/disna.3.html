subrutina ddisna (character job, integer m, integer n, double precision, dimension( * ) d, double precision, dimension( * ) sep, integer

info)

DDISN

A

Propósito

: 
!>
!> DDISNA calcula los números de condición recíprocos para los autovectores
!> de una matriz simétrica real o Hermitiana compleja o para los vectores singulares
!> izquierdos o derechos de una matriz general m-por-n. El número de condición recíproco
!> es el 'hueco' entre el autovalor o valor singular correspondiente y el más cercano.
!>
!> La cota de error, medida por ángulo en radianes, en el I-ésimo
!> vector calculado viene dada por
!>
!>        DLAMCH( 'E' ) * ( ANORM / SEP( I ) )
!>
!> donde ANORM = 2-norm(A) = max( abs( D(j) ) ).  SEP(I) no se permite
!> que sea menor que DLAMCH( 'E' )*ANORM para limitar el tamaño de
!> la cota de error.
!>
!> DDISNA también puede usarse para calcular cotas de error para autovectores de
!> el problema de eigen simétrico definido generalizado.
!
>

Parámetro

s
JOB 
!>          JOB es CHARACTER*1
!>          Especifica para qué problema se deben calcular los números de condición recíprocos:
!>          = 'E':  los autovectores de una matriz simétrica/Hermitiana;
!>          = 'L':  los vectores singulares izquierdos de una matriz general;
!>          = 'R':  los vectores singulares derechos de una matriz general.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz. M >= 0.
!
>

N 
!>          N es INTEGER
!>          Si JOB = 'L' o 'R', el número de columnas de la matriz,
!>          en cuyo caso N >= 0. Se ignora si JOB = 'E'.
!
>

D 
!>          D es un arreglo DOUBLE PRECISION, dimensión (M) si JOB = 'E'
!>                              dimensión (min(M,N)) si JOB = 'L' o 'R'
!>          Los autovalores (si JOB = 'E') o valores singulares (si JOB =
!>          'L' o 'R') de la matriz, en orden creciente o decreciente.
!>          Si son valores singulares, deben ser no negativos.
!
>

SE

P 
!>          SEP es un arreglo DOUBLE PRECISION, dimensión (M) si JOB = 'E'
!>                               dimensión (min(M,N)) si JOB = 'L' o 'R'
!>          Los números de condición recíprocos de los vectores.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!
>

Auto
