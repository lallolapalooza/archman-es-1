DESCRIPCIÓ

N

Los módulos "Digest::" calculan resúmenes, también llamados "huellas dactilares" o "hashes", de algunos datos, llamados un mensaje. El resumen es (usualmente) alguna cadena de tamaño pequeño/fijo. El tamaño real del resumen depende del algoritmo utilizado. El mensaje es simplemente una secuencia de bytes o bits

arbitrarios.

Una propiedad importante de los algoritmos de resumen es que el resumen probablemente cambiará si el mensaje cambia de alguna manera. Otra propiedad es que las funciones de resumen son funciones unidireccionales, es decir, debería ser difícil encontrar un mensaje que corresponda a algún resumen dado. Los algoritmos difieren en lo "probable" y lo "difícil", así como en su eficiencia de

cálculo.

Tenga en cuenta que las propiedades de los algoritmos cambian con el tiempo, a medida que los algoritmos son analizados y las máquinas se vuelven más rápidas. Si su aplicación, por ejemplo, depende de que sea "imposible" generar el mismo resumen para un mensaje diferente, es recomendable hacer fácil la inserción de algoritmos más fuertes a medida que los utilizados se debilitan. Usar la interfaz documentada aquí debería facilitar el cambio de algoritmos más

adelante.

Todos los módulos "Digest::" proporcionan la misma interfaz de programación. Una interfaz funcional para uso simple, así como una interfaz orientada a objetos que puede manejar mensajes de longitud arbitraria y que puede leer archivos

directamente.

El resumen se puede entregar en tres

formatos:
binar
io
Esta es la forma más compacta, pero no es adecuada para imprimirse o incrustarse en lugares que no pueden manejar datos
arbitrarios.
he
x
Una cadena del doble de largo de dígitos hexadecimales en
minúsculas.
base
64
Una cadena de caracteres imprimibles portables. Esta es la representación codificada en b
ase64 del resumen con cualquier relleno final eliminado. La cadena será aproximadamente u
n 30% más larga que la versión binaria. MIME::Base64 le dice más sobre esta codificación.

La interfaz funcional es simplemente funciones importables con el mismo nombre que el algoritmo. Las funciones toman el mensaje como argumento y devuelven el resumen.

Ejemplo: 
use Digest::MD5 qw(md5);
$digest = md5($message)
;

"_hex" o "_base64" añadido al nombre, que

El constructor devuelve algún objeto que encapsula el estado del algoritmo de resumen de mensaje. Puede añadir datos al objeto y finalmente pedir el resumen. El "XXX" debe, por supuesto, ser reemplazado por el nombre propio del algoritmo de resumen que desea usar.

Las dos primeras formas son simplemente azúcar sintáctico que carga automáticamente el módulo correcto en el primer uso. La segunda forma le permite usar nombres de algoritmos que contienen letras que no son identificadores legales de perl, por ejemplo "SHA-1". Si no se puede encontrar ninguna implementación para el algoritmo dado, se lanza una

excepción.

resumen.

El método add_bits() es una alternativa a add() que permite añadir bytes parciales al mensaje. La mayoría de los usuarios pueden simplemente ignorar este método, ya que las aplicaciones típicas solo involucran datos de bytes completos.

La forma de dos argumentos de add_bits() añadirá los primeros $nbits bits de $data. Para el último byte potencialmente parcial solo se usan los bits de orden superior "$nbits % 8". Si $nbits es mayor que "length($data) * 8", entonces este método haría lo mismo que "$ctx->add($d
