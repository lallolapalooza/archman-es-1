NOMBRE

Digest.S - La firma de una función hash que produce resúmenes de longitud hash_length a partir de cadenas de caracteres, matrices de bytes y archivos.

TIPO DE MÓDULO

Module type Digest.S

DOCUMENTACIÓN

Module type S
= sig end

La firma de una función hash que produce resúmenes de longitud hash_length a partir de cadenas de caracteres, matrices de bytes y archivos.

Desde 5.2

type t = string

El tipo de los resúmenes.

val hash_length : int

La longitud de los resúmenes, en bytes.

val compare : t -> t -> int

Compara dos resúmenes, con la misma especificación que compare .

val equal : t -> t -> bool

Prueba la igualdad de dos resúmenes.

val string : string -> t

Devuelve el resumen de la cadena dada.

val bytes : bytes -> t

Devuelve el resumen de la secuencia de bytes dada.

val substring : string -> int -> int -> t

substring s ofs len devuelve el resumen de la subcadena de s que comienza en el índice ofs y contiene len caracteres.

val subbytes : bytes -> int -> int -> t

subbytes s ofs len devuelve el resumen de la subsecuencia de s que comienza en el índice ofs y contiene len bytes.

val channel : in_channel -> int -> t

Lee caracteres del canal y devuelve su resumen. Consulte Digest.channel para la especificación completa.

val file : string -> t

Devuelve el resumen del archivo cuyo nombre se proporciona.

val output : out_channel -> t -> unit

Escribe un resumen en el canal de salida dado.

val input : in_channel -> t

Lee un resumen del canal de entrada dado.

val to_hex : t -> string

Devuelve la representación hexadecimal imprimible del resumen dado.

Genera Invalid_argument si la longitud del argumento no es hash_length ,

val of_hex : string -> t

Convierte una representación hexadecimal de nuevo en el resumen correspondiente.

Genera Invalid_argument si la longitud del argumento no es 2 * hash_length , o si los argumentos contienen caracteres no hexadecimales.
