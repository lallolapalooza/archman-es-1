Digest::HMAC(3) Documentación de Perl aportada por el usuario Digest::HMAC(3)

NOMBRE

Digest::HMAC - Hashing con clave para autenticación de mensajes

SINOPSIS

# Estilo funcional
use Digest::HMAC qw(hmac hmac_hex);
$digest = hmac($data, $key, \&myhash);
print hmac_hex($data, $key, \&myhash);
# Estilo OO
use Digest::HMAC;
$hmac = Digest::HMAC->new($key, "Digest::MyHash");
$hmac->add($data);
$hmac->addfile(*FILE);
$digest = $hmac->digest;
$digest = $hmac->hexdigest;
$digest = $hmac->b64digest;

DESCRIPCIÓN

HMAC se utiliza para verificar la integridad de mensajes entre dos partes que comparten una clave secreta, y funciona en combinación con algún otro algoritmo de Digest, usualmente MD5 o SHA-1. El mecanismo HMAC se describe en el RFC 2104.

HMAC sigue la interfaz común "Digest::", pero el constructor toma la clave secreta y el nombre de algún otro "Digest::" simple como argumento.

Las funciones hmac() y hmac_hex() y el constructor Digest::HMAC->new() también toman un argumento opcional $blocksize. El algoritmo HMAC asume que el digeridor hashing itera una función de compresión básica sobre bloques de datos y el $blocksize debe coincidir con la longitud en bytes de dichos bloques.

El $blocksize por defecto es 64, lo cual es adecuado para las funciones de digestión MD5 y SHA-1. Para algoritmos más fuertes, es probable que el blocksize necesite ser incrementado.

VER TAMBIÉN

Digest::HMAC_MD5, Digest::HMAC_SHA1
