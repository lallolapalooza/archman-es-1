dillo(1) COMANDOS DE USUARIO dillo(1)

NOMBRE

dillo - navegador web

SINOPSIS

dillo [OPCIÓN]... [--] [URL|ARCHIVO]...

DESCRIPCIÓN

Dillo es un navegador web gráfico ligero que pretende ser seguro. Maneja HTTP internamente, y las URI FILE, FTP y DATA se manejan a través de un sistema de plugins (dpi). Además, se puede habilitar el soporte EXPERIMENTAL HTTPS. Tanto FTP como el gestor de descargas de Dillo utilizan el descargador wget(1).

Dillo muestra archivos HTML, de texto, PNG, JPEG, GIF, SVG y WebP. Maneja cookies, autenticación HTTP (básica y digest), proxy (básico) y algo de CSS.

Los conjuntos de marcos (framesets) se muestran como enlaces a los marcos, y actualmente no hay soporte para javascript ni video.

Para utilizar la función de guionado (hyphenation), los archivos de patrones de CTAN deben instalarse en /usr/lib/dillo/hyphenation/. Esto se puede hacer con el script dillo-install-hyphenation. Llámalo con códigos de idioma ISO-639-1 como argumentos, o sin argumentos para obtener más ayuda.

OPCIONES

-f, --fullwindow
Iniciar en modo de ventana completa: ocultar la barra de direcciones, los botones de navegación, el menú y la barra de estado.
-g, -geometry GEO
Establecer la posición inicial de la ventana donde GEO es AxA[{+-}X{+-}Y].
-h, --help
Mostrar este texto de ayuda y salir.
-l, --local
No cargar imágenes ni hojas de estilo, ni seguir redirecciones, para estos ARCHIVOS o URL. Esto está pensado para usarse con correo electrónico HTML.
-v, --version
Mostrar información de la versión y salir.
-x, --xid XID
Abrir la primera ventana de Dillo en una ventana existente cuyo ID de ventana sea XID.

CÓDIGO DE SALIDA

0
Sin error.
1
Error interno.
2
Error en los argumentos de la línea de comandos.

ENTORNO

HOME (o HOMEDRIVE y HOMEPATH en Cygwin)
Directorio de inicio del usuario.
http_proxy
URL del proxy a través del cual enviar tráfico HTTP/HTTPS.

ARCHIVOS

dpid
Daemon de plugins de Dillo
dpidc
Programa de control para dpid.
~/.dillo/bm.txt
Marcadores de usuario
~/.dillo/certs/
Certificados guardados para HTTPS.
~/.dillo/cookies.txt
Cookies almacenadas
~/.dillo/cookiesrc
Configuración de cookies
~/.dillo/dillorc
Archivo de configuración.
~/.dillo/domainrc
Reglas para solicitudes entre dominios.
~/.dillo/dpid_comm_keys
Claves utilizadas en la comunicación del daemon dpid.
~/.dillo/dpidrc
Contiene el nombre del directorio que contiene los dpis, y asocia archivos dpi con protocolos.
~/.dillo/keysrc
Atajos de teclado.
~/.dillo/style.css
Hoja de estilo de usuario.
/usr/lib/dillo/hyphenation/
Archivos de patrones de guionado.
