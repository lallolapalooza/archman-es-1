NOMBRE

distrobox-export

DESCRIPCIÓN

Exportación de aplicaciones y binarios

distrobox-export se encarga de exportar una aplicación o un binario del contenedor al host.

La aplicación exportada estará fácilmente disponible en tu lanzador normal y se lanzará automáticamente desde el contenedor desde el que se exporta.

SINOPSIS

distrobox-export

--app/-a:       nombre de la aplicación a exportar o ruta absoluta al archivo desktop a exportar
--bin/-b:       ruta absoluta del binario a exportar
--list-apps:        listar aplicaciones exportadas desde este contenedor
--list-binaries     listar binarios exportados desde este contenedor, usa -ep para especificar rutas personalizadas a buscar
--delete/-d:        eliminar aplicación o binario exportado
--export-label/-el: etiqueta a añadir al nombre de la aplicación exportada.
            Usa "none" para deshabilitar.
            Por defecto es (on \$container_name)
--export-path/-ep:  ruta donde exportar el binario
--extra-flags/-ef:  flags adicionales a añadir al comando
--enter-flags/-nf:  flags a añadir a distrobox-enter
--sudo/-S:      especificar si el elemento exportado debe ejecutarse como sudo
--help/-h:      mostrar este mensaje
--verbose/-v:       mostrar más verbosidad
--version/-V:       mostrar versión

Puede que desees instalar aplicaciones gráficas o herramientas CLI en tu distrobox. Usar distrobox-export desde dentro del contenedor te permitirá usarlas desde el propio host.

EJEMPLOS

distrobox-export --app mpv [--extra-flags "flags"] [--delete] [--sudo]
distrobox-export --bin /ruta/a/bin [--export-path ~/.local/bin] [--extra-flags "flags"] [--delete] [--sudo]

Ejemplo de exportación de aplicaciones

distrobox-export --app abiword

Esta herramienta simplemente copiará los archivos .desktop originales junto con los iconos necesarios, añadirá el prefijo /usr/local/bin/distrobox-enter -n nombre_distrobox -e ... a los comandos a ejecutar y los guardará en tu home para ser utilizados directamente desde el host como una aplicación normal.

distrobox-export --app /opt/aplicacion/mi-app.desktop

Esto omitirá la búsqueda del archivo desktop en rutas canónicas y simplemente usará la ruta de archivo proporcionada.

Ejemplo de exportación de binarios

distrobox-export --bin /usr/bin/code --extra-flags "--foreground" --export-path $HOME/.local/bin

En el caso de exportar binarios, tendrás que especificar dónde exportarlo (--export-path) y la herramienta creará un pequeño script de envoltura que distrobox-enter -e desde el host, el binario deseado. Esto puede ser útil con el uso de direnv para tener diferentes versiones del mismo binario basadas en tu env o proyecto.

Los binarios exportados se exportarán en la ruta “–export-path” elegida como un script de envoltura que actúa naturalmente tanto en el host como en el contenedor.

Flags adicionales

Puedes especificar flags adicionales para añadir al comando, por ejemplo, si quieres exportar una aplicación electron, podrías añadir el flag “–foreground” al comando:

distrobox-export --app atom --extra-flags "--foreground"
distrobox-export --bin /usr/bin/vim --export-path ~/.local/bin --extra-flags "-p"

Esto funciona para binarios y aplicaciones. Los flags adicionales solo se usan cuando la aplicación o binario exportado se utiliza desde el host; su uso dentro del contenedor no los incluirá.

Des-exportar

La opción “–delete” des-exportará una aplicación o binario

distrobox-export --app atom --delete
distrobox-export --bin /usr/bin/vim --export-path ~/.local/bin --delete

Ejecutar como root en el contenedor

La opción “–sudo” lanzará el elemento exportado como root dentro del distrobox.

Notas

Ten en cuenta que puedes usar –app O –bin pero no juntos. [IMAGEN: exportación-app] exportación-app

NOTA: algunas aplicaciones electron como vscode y atom necesitan flags adicionales para funcionar desde dentro del contenedor, usa la opción --extra-flags para proporcionar una serie de flags, por ejemplo:

distrobox-export --app atom --extra-flags "--foreground"
