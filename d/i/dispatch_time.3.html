dispatch_time(3) Manual de funciones de la biblioteca dispatch_time(3)

NOMBRE

dispatch_time, dispatch_walltime — Calcular hitos temporales

SINOPSIS

#include <dispatch/dispatch.h>

static const dispatch_time_t DISPATCH_TIME_NOW = 0ull;
static const dispatch_time_t DISPATCH_WALLTIME_NOW = ~1ull;
static const dispatch_time_t DISPATCH_TIME_FOREVER = ~0ull;

dispatch_time_t
dispatch_time(dispatch_time_t base, int64_t offset);

dispatch_time_t
dispatch_walltime(struct timespec *base, int64_t offset);

DESCRIPCIÓN

Las funciones dispatch_time() y dispatch_walltime() proporcionan un mecanismo sencillo para expresar hitos temporales para su uso con funciones de dispatch que requieren tiempos de espera o operan según un horario.

El tipo dispatch_time_t es un entero semi-opaco, con solo los valores especiales DISPATCH_TIME_NOW, DISPATCH_WALLTIME_NOW y DISPATCH_TIME_FOREVER definidos externamente. Todos los demás valores se representan utilizando un formato interno que no es seguro para aritmética o comparación de enteros. El formato interno está sujeto a cambios.

La función dispatch_time() devuelve un hito relativo a un hito existente después de sumar offset nanosegundos. Si el parámetro base se mapea internamente a un reloj de pared o es DISPATCH_WALLTIME_NOW, entonces el valor devuelto es relativo al reloj de pared. De lo contrario, si base es DISPATCH_TIME_NOW, entonces se utiliza el tiempo actual del reloj de host predeterminado. En plataformas Apple, el valor del reloj de host predeterminado se obtiene de mach_absolute_time().

La función dispatch_walltime() es útil para crear un hito relativo a un punto fijo en el tiempo utilizando el reloj de pared, según lo especificado por el parámetro opcional base. Si base es NULL, entonces se utiliza el tiempo actual del reloj de pared. dispatch_walltime(NULL, offset) es equivalente a dispatch_time(DISPATCH_WALLTIME_NOW, offset).

CONDICIONES DE BORDE

Las funciones dispatch_time() y dispatch_walltime() detectan condiciones de desbordamiento y subdesbordamiento al aplicar el parámetro offset.

El desbordamiento provoca que se devuelva DISPATCH_TIME_FOREVER. Cuando base es DISPATCH_TIME_FOREVER, el parámetro offset se ignora.

El subdesbordamiento provoca que se devuelva el valor más pequeño representable para un reloj dado.

EJEMPLOS

Crear un hito dentro de dos segundos, relativo al reloj predeterminado:

milestone = dispatch_time(DISPATCH_TIME_NOW, 2 * NSEC_PER_SEC);

Crear un hito dentro de dos segundos, en tiempo de reloj de pared:

milestone = dispatch_time(DISPATCH_WALLTIME_NOW, 2 * NSEC_PER_SEC);

Crear un hito para usar como un tiempo de espera infinito:

milestone = DISPATCH_TIME_FOREVER;

Crear un hito el martes 19 de enero de 2038:

struct timespec ts;
ts.tv_sec = 0x7FFFFFFF;
ts.tv_nsec = 0;
milestone = dispatch_walltime(&ts, 0);

Usar un delta negativo para crear un hito una hora antes del anterior:

milestone = dispatch_walltime(&ts, -60 * 60 * NSEC_PER_SEC);

VALOR DE RETORNO

Estas funciones devuelven un valor abstracto para usar con dispatch_after(), dispatch_group_wait(), dispatch_semaphore_wait(), o dispatch_source_set_timer().
