NOMBRE

distrobox-init

DESCRIPCIÓN

Inicializa el distrobox (no se debe lanzar manualmente)

distrobox-init es el punto de entrada de un distrobox creado. Ten en cuenta que ESTO DEBE ejecutarse desde dentro de un distrobox, no funcionará si lo ejecutas desde tu host.

Esto no está diseñado para ser utilizado manualmente, sino que es utilizado por distrobox-create para configurar el punto de entrada del contenedor.

distrobox-init se encargará de instalar las dependencias que falten (por ejemplo, sudo), configurar el usuario y los grupos, montar directorios del host para garantizar una integración estrecha.

SINOPSIS

distrobox-init

--name/-n:      nombre de usuario
--user/-u:      uid del usuario
--group/-g:     gid del usuario
--home/-d:      ruta/a/home del usuario
--help/-h:      mostrar este mensaje
--additional-packages:  paquetes a instalar adicionalmente
--init/-I:      si usar init o no
--pre-init-hooks:   comandos a ejecutar antes de init
--nvidia:       intentar integrar los drivers nVidia del host en el invitado
--upgrade/-U:       ejecutar init en modo actualización
--verbose/-v:       mostrar más verbosidad
--version/-V:       mostrar versión
--:         fin de argumentos, ejecutar el resto como comando a ejecutar durante init

EJEMPLOS

distrobox-init --name test-user --user 1000 --group 1000 --home /home/test-user
distrobox-init --upgrade
