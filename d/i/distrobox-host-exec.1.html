NOMBRE

distrobox-host-exec

DESCRIPCIÓN

distrobox-host-exec permite ejecutar comandos en el host, mientras se está dentro de un contenedor.

Internamente, distrobox-host-exec utiliza host-spawn, un proyecto que nos permite ejecutar comandos de vuelta en el host. Si la herramienta no se encuentra, se le pedirá al usuario que la instale.

SINOPSIS

Simplemente pase a “distrobox-host-exec” cualquier comando y todos sus argumentos, si los hay.

--help/-h:      mostrar este mensaje
--verbose/-v:       mostrar más verbosidad
--version/-V:       mostrar versión
--yes/-Y:       Responder automáticamente sí a la solicitud:
                            host-spawn se instalará en el sistema invitado
                            si host-spawn no se detecta.
                            Este comportamiento es el predeterminado al ejecutarse en un shell no interactivo.

Si no se proporciona ningún comando, ejecutará “$SHELL”.

Alternativamente, puede crear un enlace simbólico de un nombre de comando a distrobox-host-exec y luego llamar a ese comando por su nombre en el host, mientras está dentro de un contenedor.

EJEMPLOS

Ejecutar comandos individuales

distrobox-host-exec ls
distrobox-host-exec bash -l
distrobox-host-exec flatpak run org.mozilla.firefox
distrobox-host-exec podman ps -a

Entrar en shell del host

~$: distrobox-host-exec # Sin comando, ejecuta "$SHELL" en el host
~$: distrobox-host-exec # Este comando ahora se ejecuta en el host
¡Debes ejecutar distrobox-host-exec dentro de un contenedor!

Crear enlaces simbólicos a comandos del host

Use el nombre del comando del host para crear un enlace simbólico a distrobox-host-exec. Luego puede llamar al comando del host desde dentro del contenedor.

~$: git # No tenemos git en el contenedor
bash: git: comando no encontrado
~$: sudo ln -s /usr/bin/distrobox-host-exec /usr/local/bin/git
~$: git version
git version 2.51.1

Puede controlar podman en el host desde dentro del contenedor de la siguiente manera:

~$: ln -s /usr/bin/distrobox-host-exec /usr/local/bin/podman
~$: ls -l /usr/local/bin/podman
lrwxrwxrwx. 1 root root 51 Jul 11 19:26 /usr/local/bin/podman -> /usr/bin/distrobox-host-exec
~$: podman version
...esto se ejecuta en el host...
