DIRNAME(3P) Manual de programador POSIX DIRNAME(3P)

PROLOG

Esta página del manual forma parte del Manual de programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

dirname — informar el nombre del directorio padre de una ruta de archivo

SINOPSIS

#include <libgen.h>
char *dirname(char *path);

DESCRIPCIÓN

La función dirname() tomará un puntero a una cadena de caracteres que contiene una ruta de archivo y devolverá un puntero a una cadena que es la ruta del directorio padre de ese archivo. La función dirname() no realizará la resolución de rutas; el resultado no se verá afectado por la existencia o el tipo de archivo de path. Los caracteres '/' finales en la ruta que no sean también caracteres '/' iniciales no se contarán como parte de la ruta.

Si path no contiene un '/', entonces dirname() devolverá un puntero a la cadena ".". Si path es un puntero nulo o apunta a una cadena vacía, dirname() devolverá un puntero a la cadena ".".

La función dirname() puede modificar la cadena apuntada por path y puede devolver un puntero a almacenamiento estático que luego puede ser sobrescrito por una llamada posterior a dirname().

La función dirname() no necesita ser segura para hilos.

VALOR DE RETORNO

La función dirname() devolverá un puntero a una cadena tal como se describe anteriormente.

La función dirname() puede modificar la cadena apuntada por path y puede devolver un puntero a almacenamiento interno. El puntero devuelto puede invalidarse o el almacenamiento puede sobrescribirse en una llamada posterior a dirname(). El puntero devuelto también puede invalidarse si el hilo que llama termina.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

El siguiente fragmento de código lee una ruta de archivo, cambia el directorio de trabajo actual al directorio padre y abre el archivo.

char *path = NULL, *pathcopy;
size_t buflen = 0;
ssize_t linelen = 0;
int fd;
linelen = getline(&path, &buflen, stdin);
path[linelen-1] = 0;
pathcopy = strdup(path);
if (chdir(dirname(pathcopy)) < 0) {
    ...
}
if ((fd = open(basename(path), O_RDONLY)) >= 0) {
    ...
    close (fd);
}
...
free (pathcopy);
free (path);

La sección EXAMPLES de la función basename() (ver basename()) incluye una tabla que muestra los resultados del procesamiento de varias rutas de ejemplo por las funciones basename() y dirname() y por las utilidades basename y dirname.

USO DE LA APLICACIÓN

Las funciones dirname() y basename() juntas proporcionan una ruta completa. La expresión dirname(path) obtiene la ruta del directorio donde se encuentra basename(path).

Dado que el significado de los "//" iniciales depende de la implementación, dirname("//foo) puede devolver "//" o '/' (pero nada más).

FUNDAMENTO

Ninguno.

DIRECCIONES FUTURAS

Ninguna.
