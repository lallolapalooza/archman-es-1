NOMBRE

digest_file_auth - Ayudante de autenticación de archivos digest para Squid.

Versión 1.1

SINOPSIS

digest_file_auth [-c] archivo

DESCRIPCIÓN

digest_file_auth es un programa de autenticación binario instalado para Squid. Maneja el protocolo de autenticación digest y se autentica contra un backend de archivo de texto. Este programa detectará automáticamente la existencia de un ID de canal de concurrencia y se ajustará apropiadamente. Puede ser utilizado con cualquier valor de 0 o superior para el parámetro de concurrencia de hijos de auth_param=.

OPCIONES

-c
Aceptar contraseñas cifradas con digest en lugar de texto plano en el archivo de contraseñas.

CONFIGURACIÓN

Formato del archivo de base de datos de nombres de usuario:

- las líneas de comentarios son posibles y deben comenzar con un '#';
- las líneas vacías o en blanco son posibles;
- el formato de entrada de texto plano es nombredeusuario:contraseña
- el formato de entrada HA1 es nombredeusuario:dominio:HA1

Para construir un backend integrado en el directorio, necesita poder calcular el HA1 devuelto a squid. Para evitar almacenar una contraseña en texto plano, puede calcular MD5(nombredeusuario:dominio:contraseña) cuando el usuario cambia su contraseña, y almacenar la tupla nombredeusuario:dominio:HA1. Luego, encontrar la coincidencia de nombredeusuario:dominio cuando squid solicite el HA1.

Esta implementación podría mejorarse utilizando una tripleta de este tipo para el formato de archivo. Sin embargo, almacenar tal tripleta no mejora significativamente la seguridad: si se ve comprometida, la combinación nombredeusuario:dominio:HA1 es el "equivalente en texto plano"; para fines de autenticación digest, permiten el acceso al usuario. La sincronización de contraseñas no es abordada por digest, solo se evita la interceptación en tránsito.
