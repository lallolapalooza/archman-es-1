NOMBRE

Digest::file - Calcula resúmenes de archivos

SINOPSIS

# Comando "md5sum" de pocas palabras
use Digest::file qw(digest_file_hex);
for (@ARGV) {
    print digest_file_hex($_, "MD5"), "  $_\n";
}

DESCRIPCIÓN

Este módulo proporciona 3 funciones de conveniencia para calcular el resumen de archivos. Se proporcionan las siguientes funciones:

digest_file( $archivo, $algoritmo, [$arg,...] )
Esta función calculará y devolverá el resumen binario de los bytes del archivo dado. La función fallará si no puede abrir o leer el archivo.

El $algoritmo es una cadena como "MD2", "MD5", "SHA-1", "SHA-512". Los argumentos adicionales se pasan al constructor para la implementación del algoritmo dado.

digest_file_hex( $archivo, $algoritmo, [$arg,...] )
Igual que digest_file(), pero devuelve el resumen en formato hexadecimal.
digest_file_base64( $archivo, $algoritmo, [$arg,...] )
Igual que digest_file(), pero devuelve el resumen como una cadena codificada en base64.
