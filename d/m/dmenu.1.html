NOMBRE

dmenu - menú dinámico

SINOPSIS

dmenu [-bfiv] [-l líneas] [-m monitor] [-p prompt] [-fn fuente] [-nb color] [-nf color] [-sb color] [-sf color] [-w windowid]

dmenu_run ...

DESCRIPCIÓN

dmenu es un menú dinámico para X, que lee una lista de elementos separados por saltos de línea desde la entrada estándar (stdin). Cuando el usuario selecciona un elemento y presiona Intro, su elección se imprime en la salida estándar (stdout) y dmenu termina. Escribir texto filtrará los elementos que coincidan con las palabras clave introducidas.

dmenu_run es un script utilizado por dwm(1) que lista los programas en el directorio $PATH del usuario y ejecuta el resultado en su $SHELL.

OPCIONES

-b
dmenu aparece en la parte inferior de la pantalla.
-f
dmenu captura el teclado antes de leer la entrada estándar si no se está leyendo desde una tty. Esto es más rápido, pero bloqueará X hasta que la entrada estándar alcance el final del archivo.
-i
dmenu compara los elementos del menú sin distinguir entre mayúsculas y minúsculas.
-l líneas
dmenu lista los elementos verticalmente, con el número de líneas dado.
-m monitor
dmenu se muestra en el monitor número proporcionado. Los números de monitor comienzan desde 0.
-p prompt
define el texto que se muestra a la izquierda del campo de entrada.
-fn fuente
define la fuente o conjunto de fuentes utilizado.
-nb color
define el color de fondo normal. Se admiten formatos #RGB, #RRGGBB y nombres de colores de X.
-nf color
define el color de primer plano normal.
-sb color
define el color de fondo seleccionado.
-sf color
define el color de primer plano seleccionado.
-v
imprime la información de la versión en la salida estándar y sale.
-w windowid
incrustar en la ventana con el identificador windowid.

USO

dmenu se controla completamente con el teclado. Los elementos se seleccionan usando las teclas de flecha, Av Pág, Re Pág, Inicio y Fin.

Tab
Copia el elemento seleccionado al campo de entrada.
Intro
Confirma la selección. Imprime el elemento seleccionado en la salida estándar y sale, devolviendo éxito.
Ctrl-Intro
Confirma la selección. Imprime el elemento seleccionado en la salida estándar y continúa.
Shift-Intro
Confirma la entrada. Imprime el texto introducido en la salida estándar y sale, devolviendo éxito.
Escape
Sale sin seleccionar un elemento, devolviendo fallo.
Ctrl-Izquierda
Mueve el cursor al inicio de la palabra actual
Ctrl-Derecha
Mueve el cursor al final de la palabra actual
