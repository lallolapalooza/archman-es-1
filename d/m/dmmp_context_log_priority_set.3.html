NOMBRE

dmmp_context_log_priority_set - Establecer la prioridad del registro.

SINOPSIS

void dmmp_context_log_priority_set (struct dmmp_context *ctx, int priority);

ARGUMENTOS

ctx
Puntero de 'struct dmmp_context'. Si este puntero es NULL, su programa será terminado por assert.
prioridad
int, prioridad del registro.

DESCRIPCIÓN

Cuando la biblioteca genera un mensaje de registro, solo los mensajes de igual o mayor importancia (menor valor) serán reenviados a la función de manejo de registros. Los valores de prioridad de registro válidos son:

* DMMP_LOG_PRIORITY_ERROR -- 3

* DMMP_LOG_PRIORITY_WARNING -- 4

* DMMP_LOG_PRIORITY_INFO -- 5

* DMMP_LOG_PRIORITY_DEBUG -- 7

RETORNO

void
