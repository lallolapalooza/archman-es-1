NOMBRE

dmmp_context_new - Crear struct dmmp_context.

SINOPSIS

struct dmmp_context * dmmp_context_new (void);

ARGUMENTOS

void
sin argumentos

DESCRIPCIÓN

El nivel de registro predeterminado (DMMP_LOG_PRIORITY_DEFAULT) es DMMP_LOG_PRIORITY_WARNING, lo que significa que solo los mensajes de advertencia y error se enviarán a la función manejadora de registros. La función manejadora de registros predeterminada imprimirá el mensaje de registro en STDERR. Para cambiar esto, use dmmp_context_log_func_set para configurar su propia función manejadora de registros; consulte la página del manual libdmmp.h(3) para obtener más detalles.

RETORNO

Puntero a 'struct dmmp_context'. Debe ser liberado por dmmp_context_free.
