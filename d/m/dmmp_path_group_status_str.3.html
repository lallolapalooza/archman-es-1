dmmp_path_group_status_str(3) API de Device Mapper Multipath - Manual de libdmmp dmmp_path_group_status_str(3)

NOMBRE

dmmp_path_group_status_str - Convierte el estado del grupo de rutas a cadena.

SINOPSIS

const char * dmmp_path_group_status_str (uint32_t pg_status);

ARGUMENTOS

pg_status
uint32_t. Estado del grupo de rutas. Cuando el valor proporcionado no es un estado de grupo de rutas válido, devuelve "Invalid argument".

DESCRIPCIÓN

Convierte el estado del grupo de rutas uint32_t a cadena (const char *).

RETORNO

const char *. Las cadenas válidas son:

* "Invalid argument"

* "undef"

* "enabled"

* "disabled"

* "active"
