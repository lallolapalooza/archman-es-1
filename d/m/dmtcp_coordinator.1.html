DMTCP_COORDINATOR(1) Punto de control multihilo distribuido DMTCP_COORDINATOR(1)

NOMBRE

dmtcp_coordinator -- coordina puntos de control entre múltiples procesos.

SINOPSIS

dmtcp_coordinator [OPCIONES]

DESCRIPCIÓN

dmtcp_coordinator coordina puntos de control entre múltiples procesos.

OPCIONES

-p,
--coord-port puerto (variable de entorno DMTCP_COORD_PORT)
Puerto en el que escuchar (por defecto: 7779)
--port-file nombre_archivo

Archivo donde escribir el número de puerto del oyente. (Útil con --coord-port 0, que se usa para asignar un puerto aleatorio)
--ckptdir ruta (variable de entorno DMTCP_CHECKPOINT_DIR)

Directorio donde almacenar dmtcp_restart_script.sh (por defecto: ./)
--tmpdir ruta (variable de entorno DMTCP_TMPDIR)

Directorio donde almacenar archivos temporales (por defecto: variable de entorno TMDPIR o /tmp)
--exit-on-last

Salir automáticamente cuando el último cliente se desconecte
--exit-after-ckpt

Salir automáticamente después de crear un punto de control
--daemon

Ejecutar silenciosamente en segundo plano después de separarse del proceso padre.
-i,
--interval <val> (variable de entorno DMTCP_CHECKPOINT_INTERVAL)
Tiempo en segundos entre puntos de control automáticos (por defecto: 0, deshabilitado)
-q, --quiet

Omitir el aviso de copyright.
--help

Imprimir este mensaje y salir.
--version

Imprimir información de la versión y salir.

Comandos para el Coordinador

l: Listar nodos conectados
s: Imprimir mensaje de estado
c: Crear punto de control para todos los nodos
i: Imprimir intervalo de punto de control actual
(Para cambiar el intervalo de punto de control, use dmtcp_command)
k: Matar todos los nodos
q: Matar todos los nodos y salir
?: Mostrar este mensaje
