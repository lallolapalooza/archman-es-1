DMTCP_COMMAND(1) Comprobación de puntos de control multihilo distribuida DMTCP_COMMAND(1)

NOMBRE

dmtcp_command -- envía un comando al coordinador de DMTCP remotamente.

SINOPSIS

dmtcp_commmand [OPCIONES] comando [comando...]

DESCRIPCIÓN

dmtcp_command es una herramienta para enviar comandos de usuario al coordinador de DMTCP de forma remota.

OPCIONES

-h, --coord-host nombre_host (variable de entorno DMTCP_COORD_HOST)

Nombre del host donde se ejecuta dmtcp_coordinator (por defecto: localhost)
-p, --port puerto (variable de entorno DMTCP_PORT)

Puerto donde se ejecuta dmtcp_coordinator (por defecto: 7779)
--quiet

Omitir el aviso de copyright
--help

Imprimir este mensaje y salir.
--version

Imprimir información de la versión y salir.

Comandos para el Coordinador

-s, --status

Imprimir mensaje de estado
-c, --checkpoint

Realizar un punto de control de todos los nodos
-bc, --bcheckpoint

Realizar un punto de control de todos los nodos, bloqueando hasta que termine
-i, --interval <valor>

Actualizar el intervalo de punto de control a <valor> segundos (0=nunca)
-k, --kill

Matar a todos los nodos
-q, --quit

Matar a todos los nodos y salir

REPORTE DE ERRORES

Reportar errores a: dmtcp-forum@lists.sourceforge.net
Página principal de DMTCP: http://dmtcp.sourceforge.net
