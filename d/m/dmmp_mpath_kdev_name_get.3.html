NOMBRE

dmmp_mpath_kdev_name_get - Recupera el nombre DEVNAME de un mpath específico.

SINOPSIS

const char * dmmp_mpath_kdev_name_get (struct dmmp_mpath *dmmp_mp);

ARGUMENTOS

dmmp_mp
Puntero de 'struct dmmp_mpath'. Si este puntero es NULL, su programa será terminado por assert.

DESCRIPCIÓN

Recupera el nombre DEVNAME utilizado por el uevent del kernel para el mpath especificado. Por ejemplo: 'dm-1'.

RETORNO

const char *. No es necesario liberar esta memoria, los recursos se liberarán cuando se llame a dmmp_mpath_array_free.
