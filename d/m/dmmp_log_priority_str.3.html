dmmp_log_priority_str(3) API de Device Mapper Multipath - Manual de libdmmp dmmp_log_priority_str(3)

NOMBRE

dmmp_log_priority_str - Convierte la prioridad del registro a cadena.

SINOPSIS

const char * dmmp_log_priority_str (int prioridad);

ARGUMENTOS

prioridad
int. Prioridad del registro.

DESCRIPCIÓN

Convierte la prioridad del registro a cadena (const char *).

RETORNO

const char *. Las cadenas válidas son:

* "ERROR" para DMMP_LOG_PRIORITY_ERROR

* "WARN " para DMMP_LOG_PRIORITY_WARNING

* "INFO " para DMMP_LOG_PRIORITY_INFO

* "DEBUG" para DMMP_LOG_PRIORITY_DEBUG

* "Argumento no válido" para una prioridad de registro no válida.
