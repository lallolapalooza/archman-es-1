!>
!> Programa de prueba para las Blas de Nivel 3 en DOBLE PRECISIÓN.

!> El programa debe ser ejecutado mediante un archivo de datos corto. Los primeros 14 registros
!> del archivo se leen mediante entrada dirigida por lista, los últimos 7 registros

!> de datos eliminando los primeros 3 caracteres de

!> 'dblat3.out'      NOMBRE DEL ARCHIVO DE SALIDA RESUMEN
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO RESUMEN
!> 'DBLAT3.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA

!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN CASO DE FALLOS.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR DE UMBRAL DE LA RAZÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 3                 NÚMERO DE VALORES DE ALPHA
!> 0.0 1.0 0.7       VALORES DE ALPHA

!> DTRMM   T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
