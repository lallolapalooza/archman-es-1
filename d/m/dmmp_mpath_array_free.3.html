dmmp_mpath_array_free(3) API de Device Mapper Multipath - Manual de libdmmp dmmp_mpath_array_free(3)

NOMBRE

dmmp_mpath_array_free - Libera un array de punteros 'struct dmmp_mpath'.

SINOPSIS

void dmmp_mpath_array_free (struct dmmp_mpath **dmmp_mps, uint32_t dmmp_mp_count);

ARGUMENTOS

dmmp_mps
Puntero al array de 'struct dmmp_mpath'.
dmmp_mp_count
uint32_t, el tamaño del array de punteros 'dmmp_mps'.

DESCRIPCIÓN

Libera el array de punteros 'dmmp_mps' generado por dmmp_mpath_array_get. Si el puntero 'dmmp_mps' proporcionado es NULL o dmmp_mp_count == 0, no hace nada.

RETORNO

void
