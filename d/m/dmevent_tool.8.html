NOMBRE

dmevent_tool - Una utilidad utilizada para cargar un DSO en dmeventd y registrar/desregistrar dispositivos para su monitorización

SINOPSIS

dmevent_tool -[Vhmru] {nombre del dispositivo RAID} {Nombre del DSO}

DESCRIPCIÓN

dmevent_tool es una utilidad del espacio de usuario utilizada para registrar/desregistrar DSOs con el demonio dmeventd.

Si se utiliza con el parámetro de línea de comandos -m, los usuarios pueden mostrar todos los dispositivos activamente monitorizados por dmeventd.

OPCIONES

-V Muestra la versión de dmevent_tool

-{h/?} Muestra esta información de ayuda

-m[r|u] Lista todos los dispositivos de mapeo de dispositivos actualmente activos y su estado actual con dmeventd para dispositivos registrados (-r)/no registrados (-m)
Sintaxis: dmevent_tool -m[u|r]

-a[r|u] ¡Igual que -m, pero solo para dispositivos con UUID!
Sintaxis: dmevent_tool -a[u|r]

-r Registra un dispositivo con dmeventd
Sintaxis: dmevent_tool -r <nombre del dispositivo> <ruta a la biblioteca DSO>
Ejemplo: dmevent_tool -r isw_abcdeh_Volume0 libdmraid-events.so

-u Desregistra un dispositivo con dmeventd
Sintaxis: dmevent_tool -u <nombre del dispositivo> [<ruta a la biblioteca DSO>]
Ejemplo: dmevent_tool -u isw_abcdefgh_Volume0

EJEMPLOS

dmevent_tool -m se utiliza para mostrar todos los dispositivos activamente monitorizados
dmevent_tool -m
Nombre del dispositivo: isw_defeaigdde_Volume0_dmraid00
DSO registrado: libdmraid-events.so
UUID: isw_defeaigdde_Volume0_dmraid00
estado: Activo
n.º de dispositivo principal: 253
n.º de dispositivo secundario: 0
dispositivo de solo lectura: No
número de eventos del kernel registrados: 0
unidades SATA en este grupo de volúmenes: /dev/sdb /dev/sdc

dmevent_tool -r se utiliza para registrar un dispositivo de grupo de volúmenes con dmeventd
dmevent_tool -r isw_defeaigdde_Volume0_dmraid00 libdmraid-events.so

dmevent_tool -u se utiliza para desregistrar un grupo de volúmenes de dmeventd
dmevent_tool -u isw_defeaigdde_Volume0_dmraid00

DIAGNÓSTICOS

dmevent_tool devuelve un código de salida de 0 para éxito o 1 para error.
