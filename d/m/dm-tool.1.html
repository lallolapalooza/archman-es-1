DM-TOOL(1) Manual de Comandos Generales DM-TOOL(1)

NOMBRE

dm-tool - una herramienta para controlar el gestor de pantalla

SINOPSIS

dm-tool [ OPCIONES ] COMANDO [ ARGUMENTOS ]

DESCRIPCIÓN

dm-tool es una herramienta para comunicarse con el gestor de pantalla LightDM.

OPCIONES

-h, --help
Muestra las opciones de ayuda
--version
Muestra la versión de lanzamiento
--session-bus
Intenta conectarse al gestor de pantalla utilizando el bus de sesión. Esto es útil si estás ejecutando un gestor de pantalla en modo de prueba. Si esta opción no está presente, dm-tool se conectará utilizando el bus del sistema.
Los siguientes comandos están disponibles:
switch-to-greeter
Cambia al greeter adecuado para iniciar sesión en una nueva sesión.
switch-to-user NOMBRE_USUARIO [SESIÓN]
Cambia a una sesión de usuario. Si este usuario ya ha iniciado sesión, el gestor de pantalla cambiará a esa sesión; de lo contrario, se iniciará una nueva sesión. Si se requiere autenticación, se iniciará un greeter para recopilarla. Si se proporciona la opción de sesión, se utilizará este tipo de sesión; de lo contrario, se utilizará el valor predeterminado para este usuario.
switch-to-guest [SESIÓN]
Cambia a una sesión de invitado. Si la sesión de invitado ya está activa, el gestor de pantalla cambiará a esa sesión; de lo contrario, se iniciará la sesión de invitado. Si se proporciona la opción de sesión, se utilizará este tipo de sesión; de lo contrario, se utilizará el valor predeterminado para el usuario invitado.
lock
Bloquea el asiento actual. Esto cambiará a un greeter con una indicación de que la pantalla está bloqueada. Puedes volver a esta sesión autenticándote en el greeter.
list-seats
Lista los asientos activos y las sesiones que se están ejecutando.
add-nested-seat
Inicia un servidor X dentro de una sesión y lo conecta a un gestor de pantalla.
add-local-x-seat NÚMERO_DE_PANTALLA
Conecta un servidor X existente al gestor de pantalla.
add-seat TIPO [NOMBRE=VALOR...]
Añade un asiento dinámico.

AMBIENTE

XDG_SEAT_PATH
Utilizado por dm-tool para determinar en qué sesión del gestor de pantalla se está ejecutando. Al ejecutar dm-tool fuera de un gestor de pantalla, utiliza su comando list-seats para mostrar las sesiones activas y establecer la sesión a la que conectarse con: export XDG_SEAT_PATH=/org/freedesktop/DisplayManager/SeatX donde SeatX es una de las sesiones listadas.
