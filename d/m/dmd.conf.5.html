NOMBRE

dmd.conf - archivo de configuración para dmd(1)

SINOPSIS

/etc/dmd.conf

DESCRIPCIÓN

dmd buscará el archivo de inicialización dmd.conf en los siguientes directorios:

1.
El directorio de trabajo actual.
2.
$HOME
3.
El directorio que contiene el ejecutable dmd.
4.
/etc

Si se encuentra, la configuración de las variables de entorno en el archivo anulará cualquier configuración existente.

Esto es útil para hacer que dmd sea independiente de programas con uso conflictivo de variables de entorno.

SINTAXIS

Las variables de entorno siguen el encabezado de sección [Environment], en pares nombre=valor o nombre?=valor. Los comentarios son líneas que comienzan con ;. Los nombres de las variables siempre se convierten a mayúsculas, por lo que si usas name=value, en realidad se escribirá la variable con el nombre NAME. Si se usa la sintaxis name?=value, la variable con NAME solo se escribirá si se definió antes (en ese caso se preserva el valor original).

EJEMPLO

; Archivo dmd.conf para dmd

; Los nombres encerrados entre %% se buscan en el entorno existente

; y se insertan. El nombre especial %@P% se reemplaza con la ruta

; a este archivo.

[Environment]

DFLAGS="-I%@P%/../src/phobos"

ARCHIVOS

/etc/dmd.conf
