dmraid {-V/--version} DESCRIPCIÓN
dmraid descubre dispositivos de bloque y RAID por software (por ejemplo, ATARAID) utilizando múltiples manejadores de formato de metadatos diferentes que soportan varios formatos (por ejemplo, la serie Highpoint 37x). Ofrece la activación de conjuntos RAID compuestos por 2 o más dispositivos RAID descubiertos, la visualización de propiedades de dispositivos y conjuntos (vea la opción
-

l

para los formatos de metadatos soportados). El acceso al dispositivo de bloque de los conjuntos RAID activados se produce a través de los nodos device-mapper
/dev/mapper/NombreDelConjuntoRAID. NombreDelConjuntoRAID comienza con el nombre del formato (vea la opción
-l [[89]]), el cual puede usarse para acceder fácilmente a todos los conjuntos RAID de un formato específico con ciertas opciones (por ejemplo,
-a
más abajo).

En caso de que se elijan manejadores de formato de metadatos con -f , solo los conjuntos RAID con dicho(s) formato(s) pueden ser activados o desactivados. {-R| --rebuild} conjunto-RAID
[ruta-dispositivo]
Reconstruye el array RAID después de que un disco haya fallado y se haya añadido uno nuevo. Para sistemas basados en chipsets Intel, hay dos métodos en los que se añade un nuevo disco al sistema.

1. Usando OROM para identificar un nuevo disco
Durante el reinicio del sistema, entre a OROM y marque el nuevo disco como el disco de reconstrucción.
Después de arrancar al SO, use el comando dmraid para

reconstruir.


Ejemplo: dmraid -R

raid_set

2. Usando dmraid para identificar un nuevo disco
Arranque al SO y use el comando dmraid con el nuevo disco como segundo

parámetro.


Ejemplo: dmraid -R raid_set

/dev/sdc

3. Usando un disco de reserva en caliente
Marque un disco como reserva en caliente usando el comando "dmraid -f isw -S". Luego use el comando dmraid para iniciar la

reconstrucción.


Ejemplo:

dmraid -R
raid_set

Elimina uno o todos los existentes Configura un dispositivo RAID por software y almacena los datos de configuración en un grupo de dispositivos de disco duro que consiste en este array. Este comando requiere las siguientes opciones:

-f FORMAT-handler
mformato de metadatos (ver "dmraid -l")
--type digit[digit...]
especifica el nivel de RAID del conjunto de RAID por software.
0: raid0
1: raid1
5: raid5
01: raid01 (isw raid10)
--size: [digits[k|K|m|M|g|G][b|B]]
especifica el tamaño del conjunto de RAID. El número es un entero seguido de [kKmMgG] y/o [bB].
b: byte (predeterminado)
B: bloque (512 bytes)
K o K: en base a 1024
m o M: en base a 1024*1024
g o G: en base a 1024*1024*1024
Si esta opción falta, se establece en el valor predeterminado preconfigurado por el proveedor. Tenga en cuenta que diferentes proveedores pueden aplicar diferentes restricciones en la granularidad del tamaño o el valor mínimo.
--strip: [digits[k|K|m|M|g|G][b|B]]
especifica el tamaño de banda de un conjunto RAID1, RAID5 y RAID10 (como arriba)
--disk: device-path[{,| }device-path...]

"dmraid -ay" activa todos los conjuntos de RAID por software descubiertos.
"dmraid -an" desactiva todos los conjuntos de RAID por software activos que no estén abiertos (p. ej., sistema de archivos montado en ellos).
"dmraid -ay -f pdc" (pdc buscado desde "dmraid -l") activa todos los conjuntos de RAID por software con formato Promise descubiertos e ignora todos los demás formatos soportados.
"dmraid -r" descubre todos los dispositivos de RAID por software soportados en su sistema, p. ej.:
