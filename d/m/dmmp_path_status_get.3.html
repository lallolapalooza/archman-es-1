dmmp_path_status_get(3) API de Múltiple Ruta de Device Mapper - Manual de libdmmp dmmp_path_status_get(3)

NOMBRE

dmmp_path_status_get - Recupera el estado de la ruta.

SINOPSIS

uint32_t dmmp_path_status_get (struct dmmp_path *dmmp_p);

ARGUMENTOS

dmmp_p
Puntero de 'struct dmmp_path'. Si este puntero es NULL, su programa será terminado por aserción.

DESCRIPCIÓN

Los estados válidos de la ruta son:

* DMMP_PATH_STATUS_UNKNOWN

* DMMP_PATH_STATUS_DOWN

La ruta está inactiva y no debe intentar enviarle comandos.

* DMMP_PATH_STATUS_UP

La ruta está activa y se pueden enviar E/S a ella.

* DMMP_PATH_STATUS_SHAKY

Solo para el verificador emc_clariion cuando la ruta no está disponible para operaciones "normales".

* DMMP_PATH_STATUS_GHOST

Solo para los verificadores hp_sw y rdac. Indica una ruta "pasiva/en espera" en arreglos HP activo/pasivo. Estas rutas devolverán respuestas válidas a ciertos comandos SCSI (tur, read_capacity, inquiry, start_stop), pero fallarán los comandos de E/S. La ruta necesita un comando de inicialización para poder tener éxito en las E/S.

* DMMP_PATH_STATUS_PENDING

Disponible para todos los verificadores asíncronos cuando una E/S de verificación está en curso.

* DMMP_PATH_STATUS_TIMEOUT

Solo para el verificador tur cuando el comando ha expirado.

* DMMP_PATH_STATUS_DELAYED

Si una ruta falla después de estar activa durante menos de delay_watch_checks verificaciones, cuando vuelve a estar activa, no se marcará como activa hasta que lo haya estado durante delay_wait_checks verificaciones. Durante este tiempo, se marca como "retrasada".

RETORNO

uint32_t.
