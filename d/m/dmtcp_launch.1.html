Paquete: dmtcp

DMTCP_LAUNCH(1) Distributed MultiThreaded CheckPointing DMTCP_LAUNCH(1)

NOMBRE

dmtcp_launch -- lanza un proceso bajo control de DMTCP.

SINOPSIS

dmtcp_launch [OPCIONES] <comando> [args...]

DESCRIPCIÓN

dmtcp_launch lanza un proceso bajo control de DMTCP.

Un uso típico es:
rm ckpt_a.out_*.dmtcp # Elimina copias antiguas de la imagen de checkpoint
dmtcp_launch --interval 5 a.out
dmtcp_command --checkpoint # Ejecutar esto en otra ventana
# Matar el proceso a.out en ejecución actualmente
dmtcp_restart ckpt_a.out_*.dmtcp

OPCIONES

Conexión al Coordinador DMTCP

-h, --coord-host nombre_host (variable de entorno DMTCP_COORD_HOST)

Nombre del host donde se ejecuta dmtcp_coordinator (por defecto: localhost)
-p, --coord-port puerto (variable de entorno DMTCP_COORD_PORT)

Puerto donde se ejecuta dmtcp_coordinator (por defecto: 7779)
--port-file nombre_archivo

Archivo donde escribir el número de puerto del oyente. (Útil con --coord-port 0, que se utiliza para asignar un puerto aleatorio)
-j, --join

Unirse a un coordinador existente, generar un error si no existe uno previamente
--new-coordinator

Crear un nuevo coordinador en el puerto dado. Fallar si ya existe uno en el puerto dado. El puerto se puede especificar con --coord-port, o con la variable de entorno DMTCP_COORD_PORT. Si no se especifica ningún puerto, iniciar el coordinador en un puerto aleatorio (igual que especificar el puerto '0').
--no-coordinator

Ejecutar el proceso en modo autónomo sin coordinador.
Utilizar dmtcp_command o --interval para solicitar checkpoints.
-i, --interval segundos (variable de entorno DMTCP_CHECKPOINT_INTERVAL)

Tiempo en segundos entre checkpoints automáticos. 0 implica nunca (solo ckpt manual); si no se establece y no hay variable de entorno, se utiliza el valor predeterminado establecido en dmtcp_coordinator o dmtcp_command. No permitido si se especifica --join

Generación de imágenes de checkpoint

--gzip, --no-gzip (variable de entorno DMTCP_GZIP=[01])

Habilitar/deshabilitar la compresión de imágenes de checkpoint (por defecto: 1 (habilitado))
ADVERTENCIA: gzip añade segundos. Sin gzip, el ckpt suele ser < 1s
--ckptdir ruta (variable de entorno DMTCP_CHECKPOINT_DIR)

Directorio para almacenar imágenes de checkpoint (por defecto: directorio actual al lanzar)
--ckpt-open-files

Realizar checkpoint de archivos abiertos y restaurar el directorio de trabajo antiguo. (por defecto: no hacer ninguno)
--checkpoint-open-files

Obsoleto. Usar --ckpt-open-files en su lugar.
--ckpt-signal signo

Número de señal utilizado internamente por DMTCP para el checkpointing (por defecto: 12)
--ckpt-signal signo

Obsoleto. Usar --ckpt-signal en su lugar.

Habilitar/deshabilitar plugins

--with-plugin plugins (variable de entorno DMTCP_PLUGIN)

Lista de plugins DMTCP separados por dos puntos para ser precargados con DMTCP. (Se requieren rutas absolutas.)
--batch-queue, --rm

Habilitar soporte para gestores de recursos (Torque PBS y SLURM). (por defecto: deshabilitado)
--ptrace

Habilitar soporte para llamadas al sistema PTRACE para gdb/strace etc. (por defecto: deshabilitado)
--modify-env

Actualizar variables de entorno basándose en el entorno en el host de reinicio (por ejemplo, DISPLAY=$DISPLAY). Esto se puede establecer en un archivo dmtcp_env.txt. (por defecto: deshabilitado)
--ib, --infiniband

Habilitar el plugin InfiniBand. (por defecto: deshabilitado)
--disable-alloc-plugin (variable de entorno DMTCP_ALLOC_PLUGIN=[01])

Deshabilitar el plugin alloc (por defecto: habilitado).
--disable-dl-plugin (variable de entorno DMTCP_DL_PLUGIN=[01])

Deshabilitar el plugin dl (por defecto: habilitado).
--disable-all-plugins (SOLO PARA EXPERTOS, PARA DEPURACIÓN)

Deshabilitar todos los plugins.

Otras opciones

--prefix ruta

Prefijo donde está instalado DMTCP en los nodos remotos.
--tmpdir ruta (variable de entorno DMTCP_TMPDIR)

Directorio para almacenar archivos temporales (por defecto: $TMDPIR/dmtcp-$USER@$HOST o /tmp/dmtcp-$USER@$HOST)
-q, --quiet (o establecer la variable de entorno DMTCP_QUIET = 0, 1 o 2)

Omitir mensajes NOTE; si se proporciona dos veces, también omitir advertencias
--help

Imprimir este mensaje y salir.
--version

Imprimir información de la versión y salir.
