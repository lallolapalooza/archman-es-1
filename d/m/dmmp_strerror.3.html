dmmp_strerror(3) API de Device Mapper Multipath - Manual de libdmmp dmmp_strerror(3)

NOMBRE

dmmp_strerror - Convierte un código de error a cadena.

SINOPSIS

const char * dmmp_strerror (int rc);

ARGUMENTOS

rc
int. Código de retorno de las funciones de libdmmp. Cuando el código de error proporcionado no es un código de error válido, devuelve "Argumento inválido".

DESCRIPCIÓN

Convierte un código de error (int) a cadena (const char *):

* DMMP_OK -- "OK"

* DMMP_ERR_BUG -- "Error de la biblioteca libdmmp"

* DMMP_ERR_NO_MEMORY -- "Sin memoria"

* DMMP_ERR_IPC_TIMEOUT -- "Tiempo de espera al comunicarse con multipathd, intente establecer un valor de tiempo de espera mayor a través de dmmp_context_timeout_set ()"

* DMMP_ERR_IPC_ERROR -- "Error al comunicarse con el demonio multipathd"

* DMMP_ERR_NO_DAEMON -- "El demonio multipathd no está iniciado"

* DMMP_ERR_INCOMPATIBLE -- "La versión del demonio multipathd no es compatible con la biblioteca actual"

* Otro número de error inválido -- "Argumento inválido"

DEVOLUCIÓN

const char *. El significado del código de error proporcionado.
