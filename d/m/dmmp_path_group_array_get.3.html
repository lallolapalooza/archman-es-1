dmmp_path_group_array_get(3) API de Device Mapper Multipath - Manual de libdmmp dmmp_path_group_array_get(3)

NOMBRE

dmmp_path_group_array_get - Recupera el array de punteros de grupos de rutas.

SINOPSIS

void dmmp_path_group_array_get (struct dmmp_mpath *dmmp_mp, struct dmmp_path_group ***dmmp_pgs, uint32_t *dmmp_pg_count);

ARGUMENTOS

dmmp_mp
Puntero de 'struct dmmp_mpath'. Si este puntero es NULL, tu programa será terminado por assert.
dmmp_pgs
Puntero de salida del array de punteros 'struct dmmp_path_group'. Si este puntero es NULL, tu programa será terminado por assert.
dmmp_pg_count
Puntero de salida de uint32_t. Contiene el tamaño del array de punteros 'dmmp_pgs'. Si este puntero es NULL, tu programa será terminado por assert.

DESCRIPCIÓN

Recupera los grupos de rutas de un mpath específico.

La memoria del array de punteros de salida es mantenida por 'struct dmmp_mpath', no es necesario liberar esta memoria, los recursos serán liberados cuando se llame a dmmp_mpath_array_free.

RETORNO

void
