DMTCP_RESTART(1) Comprobación distribuida multihilo DMTCP_RESTART(1)

NOMBRE

dmtcp_restart -- reinicia procesos a partir de imágenes de punto de control dadas.

SINOPSIS

dmtcp_restart [OPCIONES] ckpt1.dmtcp [ckpt2.dmtcp...]

DESCRIPCIÓN

dmtcp_restart reinicia procesos a partir de los archivos de imagen de punto de control proporcionados. Tenga en cuenta que DMTCP también genera un script de shell para reiniciar todos los procesos. Se escribe en el directorio actual del coordinador por defecto.

OPCIONES

Conexión al Coordinador DMTCP

-h, --coord-host nombre_host (variable de entorno DMTCP_COORD_HOST)

Nombre del host donde se ejecuta dmtcp_coordinator (por defecto: localhost)
-p, --coord-port puerto (variable de entorno DMTCP_COORD_PORT)

Puerto donde se ejecuta dmtcp_coordinator (por defecto: 7779)
--port-file nombre_archivo

Archivo donde escribir el número de puerto del oyente. (Útil con --port 0, que se utiliza para asignar un puerto aleatorio)
-j, --join

Unirse a un coordinador existente, generar un error si no existe uno previamente
--new-coordinator

Crear un nuevo coordinador en el puerto dado. Fallar si ya existe uno en el puerto dado. El puerto se puede especificar con --coord-port, o con la variable de entorno DMTCP_COORD_PORT. Si no se especifica ningún puerto, iniciar el coordinador en un puerto aleatorio (lo mismo que especificar el puerto '0').
-i, -interval segundos (variable de entorno DMTCP_CHECKPOINT_INTERVAL)

Tiempo en segundos entre puntos de control automáticos. 0 implica nunca (solo puntos de control manuales); si no se establece y no hay variable de entorno, utilizar el valor por defecto establecido en dmtcp_coordinator o dmtcp_command. No permitido si se especifica --join

Otras opciones

--run-as-root

Permitir que root ejecute dmtcp_restart y deshabilitar la comprobación de uid. (por defecto: deshabilitado)
--no-strict-uid-checking (variable de entorno DMTCP_DISABLE_UID_CHECKING)

Deshabilitar la comprobación de uid para la imagen de punto de control. Esto permite que la imagen de punto de control sea reiniciada por un usuario diferente al que la creó.
--ckptdir ruta (variable de entorno DMTCP_CHECKPOINT_DIR)

Directorio donde almacenar las imágenes de punto de control (por defecto: utilizar el mismo directorio utilizado en el punto de control anterior)
--tmpdir ruta (variable de entorno DMTCP_TMPDIR)

Directorio donde almacenar archivos temporales (por defecto: $TMDPIR/dmtcp-$USER@$HOST o /tmp/dmtcp-$USER@$HOST)
-q, --quiet (o establecer la variable de entorno DMTCP_QUIET = 0, 1 o 2)

Omitir mensajes de NOTA; si se da dos veces, también omitir las ADVERTENCIAS
--help

Imprimir este mensaje y salir.
--version

Imprimir información de la versión y salir.
