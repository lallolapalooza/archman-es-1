NOMBRE

DBD::Gofer::Transport::stream - transporte de DBD::Gofer para streaming stdio

SINOPSIS

DBI->connect('dbi:Gofer:transport=stream;url=ssh:usuario@host.ejemplo.com;dsn=dbi:...',...)

o, habilitar estableciendo la variable de entorno DBI_AUTOPROXY:

export DBI_AUTOPROXY='dbi:Gofer:transport=stream;url=ssh:usuario@host.ejemplo.com'

DESCRIPCIÓN

Sin el parámetro "url=", lanza un subproceso como

perl -MDBI::Gofer::Transport::stream -e run_stdio_hex

y le alimenta peticiones y lee respuestas de él. Pero eso no es muy útil.

Con un parámetro "url=ssh:usuario@host.ejemplo.com", usa ssh para lanzar el subproceso en un sistema remoto. ¡Eso es mucho más útil!

Le proporciona acceso remoto seguro a bases de datos DBI en cualquier sistema al que pueda iniciar sesión. Usar ssh también le proporciona compresión opcional y muchas otras características (consulte el manual de ssh para saber cómo configurar eso y muchas otras opciones a través del archivo ~/.ssh/config).

El comando real invocado es algo como:

ssh -xq ssh:usuario@host.ejemplo.com bash -c $setup $run

donde $run es el comando mostrado arriba, y $command es

. .bash_profile 2>/dev/null || . .bash_login 2>/dev/null || . .profile 2>/dev/null; exec "$@"

que intenta (de una manera limitada y bastante no portable) configurar el entorno (PATH, PERL5LIB etc) como lo haría si hubiera iniciado sesión en ese sistema.

El ""perl"" utilizado en el comando será por defecto el valor de $^X cuando no se usa ssh. En la mayoría de los sistemas, esa es la ruta completa del perl que se está ejecutando actualmente.

PERSISTENCIA

Actualmente, las conexiones de stream de gofer persisten (permanecen conectadas) después de que todos los manejadores de base de datos se hayan desconectado. Esto hace que las conexiones posteriores en el mismo proceso sean muy rápidas.

Actualmente, hasta 5 conexiones de stream de gofer diferentes (basadas en url) pueden persistir. Si hay más de 5 en la caché cuando se realiza una nueva conexión, la caché se limpia antes de añadir la nueva conexión. Simple pero efectivo.

POR HACER

Documentar el atributo go_perl

Reconectar automáticamente (dentro de lo razonable) si hay un error de transporte.

Decidir el valor por defecto para la conexión persistente: ¿activado o desactivado? ¿límites? ¿ttl?
