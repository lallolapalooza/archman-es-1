programa dblat3

DBLAT3

Propósito:

!>
!> Programa de prueba para el Nivel 3 de BLAS de DOBLE PRECISIÓN.
!>
!> El programa debe ser dirigido por un archivo de datos corto. Los primeros 14 registros
!> se leen usando entrada de lista dirigida, los últimos 7 registros
!> se leen usando el formato ( A6, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las siguientes 21 líneas:
!> 'dblat3.out'      NOMBRE DEL ARCHIVO DE SALIDA RESUMIDO
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO RESUMIDO
!> 'DBLAT3.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO USADO SI .LT. 0)
!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN CASOS DE FALLO.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR UMBRAL DE LA RELACIÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 3                 NÚMERO DE VALORES DE ALPHA
!> 0.0 1.0 0.7       VALORES DE ALPHA
!> 3                 NÚMERO DE VALORES DE BETA
!> 0.0 1.0 1.3       VALORES DE BETA
!> DGEMM   T PARA PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DSYMM   T PARA PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DTRMM   T PARA PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DTRSM   T PARA PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DSYRK   T PARA PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DSYR2K  T PARA PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DGEMMTR T PARA PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!>
!> Detalles Adicionales
!> ===================
!>
!> Ver:
!>
!>    Dongarra J. J., Du Croz J. J., Duff I. S. and Hammarling S.
!>    Un Conjunto de Subprogramas Básicos de Álgebra Lineal de Nivel 3.

!>    South Cass Avenue, Argonne, Illinois 60439, EE. UU.
