NOMBRE

dblink_connect_u - abre una conexión persistente a una base de datos remota, de forma insegura

SINOPSIS

dblink_connect_u(text connstr) devuelve text
dblink_connect_u(text connname, text connstr) devuelve text

DESCRIPCIÓN

dblink_connect_u() es idéntica a dblink_connect(), excepto que permitirá a los usuarios no superusuarios conectarse utilizando cualquier método de autenticación.

Si el servidor remoto selecciona un método de autenticación que no implica una contraseña, puede ocurrir suplantación y posterior escalada de privilegios, ya que la sesión parecerá originada por el usuario con el que se ejecuta el servidor PostgreSQL local. Además, incluso si el servidor remoto demanda una contraseña, es posible que la contraseña se proporcione desde el entorno del servidor, como un archivo ~/.pgpass perteneciente al usuario del servidor. Esto no solo abre un riesgo de suplantación, sino la posibilidad de exponer una contraseña a un servidor remoto no confiable. Por lo tanto, dblink_connect_u() se instala inicialmente con todos los privilegios revocados a PUBLIC, haciéndola no invocable excepto por superusuarios. En algunas situaciones, puede ser apropiado otorgar permiso EXECUTE para dblink_connect_u() a usuarios específicos considerados confiables, pero esto debe hacerse con cuidado. También se recomienda que cualquier archivo ~/.pgpass perteneciente al usuario del servidor *no* contenga registros que especifiquen un nombre de host comodín.

Para más detalles, consulte dblink_connect().
