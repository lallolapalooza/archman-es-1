SINOPSI

S

Este módulo es una clase base para escribir otros DBD. No está destinado a funcio

nar como un DBD en sí mismo (aunque es posible). Si desea acceder a archivos plan
os, use DBD::AnyData o DBD::CSV (ambos de los cuales son subclases de DBD::File).

DESCRIPCIÓ

N

El módulo DBD::File no es un controlador DBI verdadero, sino una clase base abstracta de la que derivar controladores DBI concretos. La implicación es que estos controladores trabajan con archivos planos, por ejemplo archivos CSV o archivos INI. El módulo se basa en el módulo SQL::Statement, un motor SQL

simple.

Consulte DBI para detalles sobre DBI, SQL::Statement para detalles sobre SQL::Statement y DBD::CSV, DBD::DBM o DBD::AnyData para ejemplos de

controladores.

f_met

a

Área de datos privada que hace alias de "sql_meta" en DBI::DBD::SqlEngine, la cual contiene información sobre las tablas que este módulo maneja. Los metadatos de la tabla pueden no estar disponibles hasta que la tabla haya sido accedida por primera vez, por ejemplo, emitiendo un select sobre ella; sin embargo, es posible pre-inicializar atributos para cada tabla que

use.

DBD::File reconoce los atributos (públicos) "f_ext", "f_dir", "f_file", "f_encoding", "f_lock", "f_lockfile", "f_schema", además de los atributos "sql_meta" en DBI::DBD::SqlEngine que ya soporta. Sea muy cuidadoso al modificar atributos que no conoce, la consecuencia podría ser una tabla destruida o

corrupta.

"f_file" es un atributo aplicable solo a metadatos de tabla y no encontrará un atributo correspondiente en el dbh. Aunque puede ser razonable tener varias tablas con los mismos nombres de columna, no lo es para el mismo nombre de archivo. Si necesita acceso al mismo archivo usando diferentes nombres de tabla, use "SQL::Statement" como motor SQL y la palabra clave

"AS": 
SELECT * FROM tbl AS t1, tbl AS t2 WHERE t1.id = t2.
id ass="Pp">"f_file" puede ser una ruta absoluta o un nombre de ruta relativo, pero si es relativo, se interpreta como relativo al atributo "f_dir" de los metadatos de la tabla.
