DESCRIPCIÓ

Este documento describe la instalación y configuración de DBD::MariaDB, el controlador DBI de Perl para las bases de datos MariaDB y MySQL. Antes de continuar, asegúrese de tener los prerrequisitos disponibles: Perl, MariaDB/MySQL y DBI. Para más detalles, consulte la sección separada "PRERREQUISITOS"

.

Finalmente, si encuentra algún problema, no olvide leer la

sección sobre problemas conocidos "PROBLEMAS CONOCIDOS". Si
eso no le ayuda, debería consultar la sección "SOPORTE".
