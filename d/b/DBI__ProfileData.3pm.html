DESCRIPCIÓ

N

Este módulo ofrece la capacidad de leer, manipular y formatear datos de perfil de DBI::

ProfileDumper.

Conceptualmente, un perfil consiste en una serie de registros, o nodos, cada uno de los cuale

s tiene un conjunto de estadísticas y un conjunto de claves. Cada registro debe tener un con
junto único de claves, pero no se requiere que cada registro tenga el mismo número de claves.

Filte

r

El parámetro "Filter" se puede usar para proporcionar una referencia a código que puede manipular los datos del perfil mientras se están leyendo. Esto es más útil para editar sentencias SQL de modo que sentencias ligeramente diferentes en los datos crudos se fusionen y agreguen en los datos cargados. Por

ejemplo: 
Filter => sub {
    my ($path_ref, $data_ref) = @_;
    s/foo = '.*?'/foo = '...'/ for @$path_ref;
}

Aquí hay un ejemplo que realiza algo de normalización en el SQL. Convierte todos los números a "N" y todas las cadenas entre comillas a "S". También puede convertir dígitos a N dentro de nombres. Finalmente, resume cláusulas largas "IN (...)

".

Es agresivo y simplista, pero a menudo es suficiente, y sirve como ejemplo que puede adaptar a sus propias

necesidades: 
Filter => sub {
    my ($path_ref, $data_ref) = @_;
    local $_ = $path_ref->[0]; # el elemento que contiene la sentencia SQL
    s/\b\d+\b/N/g;             # 42 -> N
    s/\b0x[0-9A-Fa-f]+\b/N/g;  # 0xFE -> N
    s/'.*?'/'S'/g;             # cadenas entre comillas simples (no maneja escapes)
    s/".*?"/"S"/g;             # cadenas entre comillas dobles (no maneja escapes)
    # convertir nombres como log_20001231 en log_NNNNNNNN, controlado por $opt{n}
    s/([a-z_]+)(\d{$opt{n},})/$1.('N' x length($2))/ieg if $opt{n};
    # abreviar sentencias masivas "in (...)" y similares
    s!(([NS],){100,})!sprintf("$2,{repeated %d times}",length($1)/2)!eg;
}

A menudo es mejor realizar este tipo de normalización en el DBI mientras se

recopilan los datos, para evitar que se use demasiada memoria al almacenar
datos de perfil para muchas sentencias SQL diferentes. Consulte DBI::Profile.

Devuelve una referencia al arreglo de nodos ordenado. Cada elemento en el arreglo es un solo registro en el conjunto de datos. Los primeros siete elementos son los mismos que los elementos proporcionados por DBI::Profile. Después de eso, cada clave está en un elemento separado. Por

$nodes = [

             0.00140702724456787,    # 4, duración más larga
             1023115819.83019,       # 5, tiempo del primer evento
             1023115819.86576,       # 6, tiempo del último evento
             'SELECT foo FROM bar'   # 7, key1
             'execute'               # 8, key2
                                     # 6+N, keyN
           ],

         ]
;
