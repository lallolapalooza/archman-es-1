NOMBRE

DBD::Gofer::Transport::null - Transporte cliente de DBD::Gofer para pruebas

SINOPSIS

mi $dsn_original = "..."
DBI->connect("dbi:Gofer:transport=null;dsn=$original_dsn",...)

o, habilitar estableciendo la variable de entorno DBI_AUTOPROXY:

export DBI_AUTOPROXY="dbi:Gofer:transport=null"

DESCRIPCIÓN

Conéctese a través de DBD::Gofer pero ejecute las peticiones dentro del mismo proceso.

Esta es una forma rápida y sencilla de probar la compatibilidad de las aplicaciones con las (pocas) restricciones que impone DBD::Gofer.

También proporciona una forma simple y portable para que el conjunto de pruebas de DBI se utilice para probar DBD::Gofer en todas las plataformas sin configuración previa.

Además, midiendo la diferencia en el rendimiento entre conexiones normales y conexiones a través de "dbi:Gofer:transport=null", se puede medir el costo básico de usar DBD::Gofer. Además, el costo adicional de transportes más avanzados se puede aislar comparando su rendimiento con el del transporte nulo.

El script "t/85gofer.t" en la distribución de DBI incluye un benchmark comparativo.
