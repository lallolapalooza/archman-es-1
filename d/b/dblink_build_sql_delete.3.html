dblink_build_sql_delete(3)

Paquete: postgresql

Licencias: PostgreSQL

DBLINK_BUILD_SQL_DELETE(3) Documentación de PostgreSQL 18.1 DBLINK_BUILD_SQL_DELETE(3)

NOMBRE

dblink_build_sql_delete - construye una sentencia DELETE usando los valores proporcionados para los valores de campo de clave primaria

SINOPSIS

dblink_build_sql_delete(text relname,
                        int2vector primary_key_attnums,
                        integer num_primary_key_atts,
                        text[] tgt_pk_att_vals_array) returns text

DESCRIPCIÓN

dblink_build_sql_delete puede ser útil para realizar una replicación selectiva de una tabla local a una base de datos remota. Construye un comando SQL DELETE que eliminará la fila con los valores de clave primaria dados.

ARGUMENTOS

relname

Nombre de una relación local, por ejemplo foo o myschema.mytab. Incluya comillas dobles si el nombre tiene mayúsculas y minúsculas o contiene caracteres especiales, por ejemplo "FooBar"; sin comillas, la cadena se convertirá a minúsculas.

primary_key_attnums

Números de atributos (basados en 1) de los campos de clave primaria, por ejemplo 1 2.

num_primary_key_atts

El número de campos de clave primaria.

tgt_pk_att_vals_array

Valores de los campos de clave primaria que se utilizarán en el comando DELETE resultante. Cada campo se representa en forma de texto.

VALOR DE RETORNO

Devuelve la sentencia SQL solicitada como texto.

NOTAS

A partir de PostgreSQL 9.0, los números de atributos en primary_key_attnums se interpretan como números de columna lógicos, correspondientes a la posición de la columna en SELECT * FROM relname. Las versiones anteriores interpretaban los números como posiciones de columna físicas. Hay una diferencia si alguna columna a la izquierda de la columna indicada se ha eliminado durante la vida útil de la tabla.

EJEMPLOS

SELECT dblink_build_sql_delete('"MyFoo"', '1 2', 2, '{"1", "b"}');
           dblink_build_sql_delete
---------------------------------------------
 DELETE FROM "MyFoo" WHERE f1='1' AND f2='b'
(1 row)
