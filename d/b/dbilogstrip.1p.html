dbilogstrip(1p)

Paquete: perl-dbi

Licencias: GPL, PerlArtistic

DBILOGSTRIP(1) Documentación de Perl aportada por el usuario DBILOGSTRIP(1)

NOMBRE

dbilogstrip - filtro para normalizar registros de rastreo de DBI para comparación

SINOPSIS

Lee el archivo de rastreo de DBI "dbitrace.log" y escribe una versión simplificada en "dbitrace_stripped.log"

dbilogstrip dbitrace.log > dbitrace_stripped.log

Ejecuta "yourscript.pl" dos veces, cada una con un conjunto diferente de argumentos, con DBI_TRACE habilitado. Filtra la salida y el rastreo a través de "dbilogstrip" en un archivo separado para cada ejecución. Luego compara usando diff. (Este ejemplo asume que estás usando un shell estándar.)

DBI_TRACE=2 perl yourscript.pl ...args1... 2>&1 | dbilogstrip > dbitrace1.log
DBI_TRACE=2 perl yourscript.pl ...args2... 2>&1 | dbilogstrip > dbitrace2.log
diff -u dbitrace1.log dbitrace2.log

DESCRIPCIÓN

Reemplaza cualquier dirección hexadecimal, por ejemplo, 0x128f72ce con "0xN".

Reemplaza cualquier referencia a ID de proceso o ID de hilo, como "pid#6254" con "pidN".

Por lo tanto, una línea de rastreo de DBI como esta:

-> STORE for DBD::DBM::st (DBI::st=HASH(0x19162a0)~0x191f9c8 'f_params' ARRAY(0x1922018)) thr#1800400

se verá así:

-> STORE for DBD::DBM::st (DBI::st=HASH(0xN)~0xN 'f_params' ARRAY(0xN)) thrN
2025-07-13 perl v5.42.0
