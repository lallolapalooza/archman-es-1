NOMBRE

dblink_get_result - obtiene el resultado de una consulta asíncrona

SINOPSIS

dblink_get_result(text connname [, bool fail_on_error]) retorna setof record

DESCRIPCIÓN

dblink_get_result recopila los resultados de una consulta asíncrona enviada previamente con dblink_send_query. Si la consulta aún no ha finalizado, dblink_get_result esperará hasta que lo haga.

ARGUMENTOS

connname

Nombre de la conexión a utilizar.

fail_on_error

Si es verdadero (el valor predeterminado cuando se omite), un error lanzado en el lado remoto de la conexión provoca que también se lance un error localmente. Si es falso, el error remoto se informa localmente como un NOTICE, y la función no devuelve ninguna fila.

VALOR DE RETORNO

Para una consulta asíncrona (es decir, una declaración SQL que devuelve filas), la función devuelve la(s) fila(s) producida(s) por la consulta. Para usar esta función, necesitará especificar el conjunto esperado de columnas, como se discutió previamente para dblink.

Para un comando asíncrono (es decir, una declaración SQL que no devuelve filas), la función devuelve una única fila con una única columna de texto que contiene la cadena de estado del comando. Todavía es necesario especificar que el resultado tendrá una única columna de texto en la cláusula FROM de llamada.

NOTAS

Esta función *debe* llamarse si dblink_send_query devolvió 1. Debe llamarse una vez por cada consulta enviada, y una vez adicional para obtener un resultado de conjunto vacío, antes de que la conexión pueda ser utilizada nuevamente.

Al usar dblink_send_query y dblink_get_result, dblink recupera todo el resultado de la consulta remota antes de devolver cualquier parte de él al procesador de consultas local. Si la consulta devuelve un gran número de filas, esto puede resultar en una hinchazón temporal de memoria en la sesión local. Puede ser mejor abrir dicha consulta como un cursor con dblink_open y luego recuperar un número manejable de filas a la vez. Alternativamente, use dblink() simple, que evita la hinchazón de memoria al almacenar en búfer grandes conjuntos de resultados en disco.
