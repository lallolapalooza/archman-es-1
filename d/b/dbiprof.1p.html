NOMBRE

dbiprof - cliente de línea de comandos para DBI::ProfileData

SINOPSIS

Ver un informe de las diez consultas con el tiempo de ejecución total más largo en el archivo de volcado de perfil prof1.out:

dbiprof prof1.out

Ver las 10 consultas ejecutadas con mayor frecuencia en el archivo de perfil dbi.prof (el predeterminado):

dbiprof --sort count

Ver el mismo informe con 15 entradas:

dbiprof --sort count --number 15

DESCRIPCIÓN

Esta herramienta es un cliente de línea de comandos para DBI::ProfileData. Te permite analizar el archivo de datos de perfil producido por DBI::ProfileDumper y generar varios informes útiles.

OPCIONES

Este programa acepta las siguientes opciones:

--number N
Produce este número de elementos en el informe. El valor predeterminado es 10. Si se establece en "all", se muestran todos los resultados.
--sort campo
Ordena los resultados por el campo dado. Actualmente no se admite la ordenación por varios campos (se aceptan parches). Los campos de ordenación disponibles son:
total
Ordena por el tiempo total de ejecución en todas las ejecuciones. Este es el ordenamiento predeterminado.
longest
Ordena por la ejecución individual más larga.
count
Ordena por el número total de ejecuciones.
first
Ordena por el tiempo empleado en la primera ejecución.
shortest
Ordena por la ejecución individual más corta.
key1
Ordena por el valor del primer elemento de la Ruta, que debe ser numérico. También puedes ordenar por "key2" y "key3".
--reverse
Invierte el ordenamiento seleccionado. Por ejemplo, para ver un informe del tiempo total más corto: 
dbiprof --sort total --reverse
--match keyN=valor
Considera solo los elementos donde la clave especificada coincide con el valor dado. Las claves se numeran a partir de 1. Por ejemplo, supongamos que utilizaste una Ruta de DBI::Profile como: 
[ DBIprofile_Statement, DBIprofile_Methodname ]

Y llamaste a dbiprof como:

dbiprof --match key2=execute

Tu informe solo mostraría consultas execute, excluyendo prepares, fetches, etc.

Si el valor dado comienza y termina con barras ("/") se tratará como una expresión regular. Por ejemplo, para incluir solo consultas SELECT donde key1 es la sentencia:

dbiprof --match key1=/^SELECT/

Por defecto, la expresión de coincidencia no distingue mayúsculas y minúsculas, pero esto se puede cambiar con la opción --case-sensitive.

--exclude keyN=valor
Elimina elementos para los que la clave especificada coincide con el valor dado. Por ejemplo, para excluir todas las entradas de preparación donde key2 es el nombre del método: 
dbiprof --exclude key2=prepare

Al igual que "--match", si el valor dado comienza y termina con barras ("/") se tratará como una expresión regular. Por ejemplo, para excluir consultas UPDATE donde key1 es la sentencia:

dbiprof --match key1=/^UPDATE/

Por defecto, la expresión de exclusión no distingue mayúsculas y minúsculas, pero esto se puede cambiar con la opción --case-sensitive.

--case-sensitive
El uso de esta opción hace que --match y --exclude funcionen distinguiendo mayúsculas y minúsculas. El valor predeterminado es desactivado.
--delete
Establece la opción "DeleteFiles" en DBI::ProfileData, lo que hace que los archivos se eliminen después de leerlos. Consulta DBI::ProfileData para más detalles.
--dumpnodes
Imprime la lista de nodos en forma de estructura de datos de perl. Usa la opción "-sort" si quieres que la lista esté ordenada.
--version
Imprime el número de versión de dbiprof y sale.
