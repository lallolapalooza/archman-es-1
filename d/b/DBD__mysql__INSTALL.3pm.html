Este documento describe la instalación y configuración de DBD::mysql, el controlador DBI de Perl para la base de datos MySQL. Antes de continuar leyendo, asegúrate de tener los prerrequisitos disponibles: Perl, MySQL y DBI. Para más detalles, consulta la sección separada "PRERREQUISITOS"

Dependiendo de tu versión de Perl, podría ser posible usar una distribución binaria de DBD::mysql. Si es posible, esto se recomienda. De lo contrario, necesitarás instalar desde el código fuente. En ese caso, definitivamente necesitarás un compilador C. La instalación desde binarios y desde el código fuente se describen en secciones separadas. "INSTALACIÓN BINARIA". CONEXIONES CIFRADAS via

SSL

Conectarse a sus servidores a través de una conexión cifrada (SSL) es solo posible si habilitó esta configuración en tiempo de compilación. Desde la versión 4.034, esto es el valor

predeterminado.

Intentar conectarse a un servidor que requiere una conexión cifrada sin haber compilado primero DBD::mysql con la opción "--ssl" resultará en un error que hace que las cosas parezcan como si su contraseña fuera

incorrecta.

Si desea compilar DBD::mysql sin soporte SSL, lo cual probablemente solo querrá hacer si por alguna razón no puede instalar los encabezados de libssl, puede hacerlo pasando la opción "--nossl" a Makefile.PL o configurando

la variable de entorn
o DBD_MYSQL_NOSSL a '1'.
