DESCRIPCI

ÓN

El programa dbmail-export le per

mite exportar un buzón de DBMail
a un buzón con formato mbox.

OPCIONE

S 
-u, --
user u
suario

especifica el propietario del buzón que desea exportar, usando los comodines ? y * para coincidir con uno o ninguno, o uno o más caracteres en el nombre de usuario,

respectivamente.

-m, --

mailbox
buzón

especifica el buzón que desea

exportar.

-o, --out

archivo
especifica el archivo en el que se guardará el correo
exportado.

-b, --basedir

directoriobase
especifica el directorio base en el que se guardarán los buzones
exportados.

-s, --search

búsqueda
usa una cadena de búsqueda IMAP para seleccionar mensajes (por defecto: 1:*), por ejemplo, para exportar todos los mensajes recibidos en mayo, use: "1:* SINCE 1-May-2007 BEFORE
1-Jun-2007"

-d,

--set-del-flag
marca los mensajes exportados como \\Deleted (use dbmail-util para establecer el estado como borrado)
.

-D, --set-del-statu

s
establece el estado de los mensajes exportados como borrados (use dbmail-util para purgarlos)
.

-r,

--recursive
exporta buzones recursivamente (por defecto: verdadero, a menos que también se especifique la opción -m)
.

S
Para exportar y eliminar todos los mensajes pertenecientes al
usuario

Joe en el

buzón
In
b
ox

con más de 30 días de antigüedad, pruebe este comando en

Linux:

dbmail-export --user joe \ --mailbox inbox \ --out joesinbox.mbox \ --set-del-flag \ --search "1:* BEFORE `date '+%e-%b-%Y' -d '30 days ago'`" Una versión para BSD: dbmail-export --user joe \ --mailbox inbox \ --out joesinbox.mbox \ --set-del-flag \ --search "1:* BEFORE `date -v-30d

'+%e-%b-%Y'`" 
Observe el cuidadoso uso de comillas en bash y las comillas invertidas
    que invoc
an el comando date(1). date(1) tiene excelentes funciones para obtener fechas re
lativas. Si está usando un shell diferente, puede necesitar comillas diferentes.

Para exportar todos los buzones llamados Spam de todos los usuarios a directorios individuales siguiendo el patrón SpamDump/<nombredeusuario>/Spam, pruebe

este comando: 
dbmail-export --use
r \* --mailbox Spam
--basedir SpamDump

Observe la barra invertida para evitar que el shell expanda el *, ya que queremos que ese * sea pasado a DBMail para que se expanda basándose en la lista interna de

usuarios.
