Paquete: postgresql

Licencias: PostgreSQL

DBLINK_GET_CONNECTIONS(3) Documentación de PostgreSQL 18.1 DBLINK_GET_CONNECTIONS(3)

NOMBRE

dblink_get_connections - devuelve los nombres de todas las conexiones dblink nombradas abiertas

SINOPSIS

dblink_get_connections() devuelve text[]

DESCRIPCIÓN

dblink_get_connections devuelve una matriz con los nombres de todas las conexiones dblink nombradas abiertas.

VALOR DE RETORNO

Devuelve una matriz de texto con los nombres de las conexiones, o NULL si no hay ninguna.

EJEMPLOS

SELECT dblink_get_connections();
