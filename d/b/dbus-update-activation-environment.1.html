DBUS-UPDATE-ACTIVA(1) Comandos de usuario DBUS-UPDATE-ACTIVA(1)

NOMBRE

dbus-update-activation-environment - actualiza el entorno utilizado para los servicios de activación de D-Bus

SINOPSIS

dbus-update-activation-environment [--systemd] [--verbose] --all | VAR... | VAR=VAL...

DESCRIPCIÓN

dbus-update-activation-environment actualiza la lista de variables de entorno utilizadas por dbus-daemon --session cuando activa servicios de sesión sin utilizar systemd.

Con la opción --systemd, si una instancia de systemd --user está disponible en D-Bus, también actualiza la lista de variables de entorno utilizadas por systemd --user cuando activa servicios de usuario, incluyendo los servicios de sesión de D-Bus para los que dbus-daemon ha sido configurado para delegar la activación a systemd. Esto es muy similar al comando import-environment proporcionado por systemctl(1).

Las variables que son especiales para dbus-daemon o systemd pueden ser establecidas, pero sus valores serán anulados cuando se inicie un servicio. Por ejemplo, no es útil añadir DBUS_SESSION_BUS_ADDRESS al entorno de activación de dbus-daemon, aunque todavía podría ser útil añadirla al entorno de activación de systemd.

OPCIONES

--all

Establece todas las variables de entorno presentes en el entorno utilizado por dbus-update-activation-environment.

--systemd

Establece variables de entorno también para los servicios de usuario de systemd, así como para los servicios de sesión D-Bus tradicionales.

--verbose

Muestra mensajes en la salida de error estándar explicando lo que está haciendo dbus-update-activation-environment.

VAR

Si VAR está presente en el entorno de dbus-update-activation-environment, la establece con el mismo valor para los servicios de D-Bus. Su valor debe ser UTF-8 (si no, se omite con una advertencia). Si VAR no está presente en el entorno, este argumento se ignora silenciosamente.

VAR=VAL

Establece VAR a VAL, que debe ser UTF-8.

EJEMPLOS

dbus-update-activation-environment está diseñado principalmente para ser utilizado en los scripts de inicio de sesión X11 de las distribuciones de Linux, en conjunción con el diseño del "bus de usuario".

Para propagar DISPLAY y XAUTHORITY a dbus-daemon y, si está presente, a systemd, y propagar DBUS_SESSION_BUS_ADDRESS a systemd:

        dbus-update-activation-environment --systemd \
            DBUS_SESSION_BUS_ADDRESS DISPLAY XAUTHORITY

Para propagar todas las variables de entorno excepto XDG_SEAT, XDG_SESSION_ID y XDG_VTNR a dbus-daemon (y, si está presente, a systemd) para compatibilidad con scripts de inicio de sesión X11 heredados:

        # en un subshell para que las variables permanezcan establecidas en el
        # script padre
        (
          unset XDG_SEAT
          unset XDG_SESSION_ID
          unset XDG_VTNR
          dbus-update-activation-environment --systemd --all
        )

ESTADO DE SALIDA

dbus-update-activation-environment sale con el estado 0 en caso de éxito, EX_USAGE (64) si las opciones de línea de comandos son inválidas, EX_OSERR (71) si no puede conectarse al bus de sesión, o EX_UNAVAILABLE (69) si no puede establecer las variables de entorno. Otros códigos de salida distintos de cero podrían añadirse en futuras versiones.

ENTORNO

DBUS_SESSION_BUS_ADDRESS, XDG_RUNTIME_DIR y/o DISPLAY se utilizan para encontrar la dirección del bus de sesión.

LIMITACIONES

dbus-daemon no proporciona una forma de anular variables de entorno después de que hayan sido establecidas (aunque systemd sí lo hace), por lo que dbus-update-activation-environment tampoco ofrece esta funcionalidad.

POSIX no especifica la codificación de nombres o valores de variables de entorno no ASCII y permite que contengan cualquier byte distinto de cero, pero ni dbus-daemon ni systemd soportan variables de entorno con nombres o valores que no sean UTF-8. En consecuencia, dbus-update-activation-environment asume que cualquier nombre o valor que parezca ser UTF-8 válido está destinado a ser UTF-8, e ignora otros nombres o valores con una advertencia.

ERRORES

Por favor, envíe informes de errores al rastreador de errores de D-Bus o a la lista de correo. Consulte https://www.freedesktop.org/wiki/Software/dbus/.
