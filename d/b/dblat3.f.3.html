program dblat3

DBLAT3

Propósito:

!>
!> Programa de prueba para las Blas de Nivel 3 de doble precisión.
!>
!> El programa debe ser impulsado por un archivo de datos corto. Los primeros 14 registros
!> del archivo se leen utilizando entrada dirigida por lista, los últimos 7 registros
!> se leen utilizando el formato ( A6, L2 ). Se puede obtener un ejemplo anotado de un archivo
!> de datos eliminando los primeros 3 caracteres de las
!> siguientes 21 líneas:
!> 'dblat3.out'      NOMBRE DEL ARCHIVO DE SALIDA DE RESUMEN
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO DE RESUMEN
!> 'DBLAT3.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO SE USA SI ES .LT. 0)
!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN CASO DE FALLOS.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR DE UMBRAL DE LA RELACIÓN DE PRUEBA
!> 6                 NÚMERO DE VALORES DE N
!> 0 1 2 3 5 9       VALORES DE N
!> 3                 NÚMERO DE VALORES DE ALPHA
!> 0.0 1.0 0.7       VALORES DE ALPHA
!> 3                 NÚMERO DE VALORES DE BETA
!> 0.0 1.0 1.3       VALORES DE BETA
!> DGEMM   T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DSYMM   T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DTRMM   T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DTRSM   T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DSYRK   T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DSYR2K  T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!> DGEMMTR T PONER F PARA NO PROBAR. MISMAS COLUMNAS.
!>
!> Detalles adicionales
!> ===============
!>
!> Ver:
!>
!>    Dongarra J. J., Du Croz J. J., Duff I. S. y Hammarling S.
!>    Un conjunto de subprogramas básicos de álgebra lineal de Nivel 3.
!>
!>    Memorando técnico N.º 88 (Revisión 1), División de Matemáticas y
!>    Ciencias de la Computación, Laboratorio Nacional Argonne, 9700
!>    South Cass Avenue, Argonne, Illinois 60439, EE. UU.
!>
!> -- Escrito el 8 de febrero de 1989.
