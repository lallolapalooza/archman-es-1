Se han planteado varios argumentos para el soporte de características como índices en columnas y cursores para DBD::CSV (que es también un controlador basado en DBD::File). Argumentos similares podrían hacerse para DBD::DBM, DBD::

Para mejorar el rendimiento de los motores SQL subyacentes, parece necesaria una reimplementaci
