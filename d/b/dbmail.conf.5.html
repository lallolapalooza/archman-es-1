NOMBRE

dbmail.conf - archivo de configuración para el Agente de Entrega de Mensajes de DBMail.

SINOPSIS

Hay 8 secciones: DBMAIL, SMTP, LMTP, POP, IMAP, SIEVE, LDAP, DELIVERY. El archivo de configuración predeterminado tiene documentación para todas las configuraciones.

 # el registro.

 #           511 = Todo
