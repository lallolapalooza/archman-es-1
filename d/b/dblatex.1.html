DBLATEX(1) Página del manual de Dblatex DBLATEX(1)

NOMBRE

dblatex - convertir DocBook a LaTeX, DVI, PostScript y PDF

SINOPSIS

dblatex [opciones] {archivo | -}

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando dblatex. Para más detalles, lea el manual en PDF; vea abajo.

dblatex es un programa que transforma sus documentos DocBook SGML/XML a DVI, PostScript o PDF traduciéndolos primero a LaTeX puro. También se soportan las marcas MathML 2.0. Comenzó como un clon de DB2LaTeX.

OPCIONES

A continuación se incluye un resumen de las opciones. Para una descripción completa, consulte el manual en PDF.

-h, --help

Muestra un mensaje de ayuda y sale.

-b backend, --backend=backend

Controlador backend a usar: pdftex (por defecto), dvips, o xetex.

-B, --no-batch

Se imprime toda la salida de tex.

-c config, -S config, --config=config

Archivo de configuración. Se puede usar un archivo de configuración para agrupar todas las opciones y personalizaciones a aplicar.

-d, --debug

Modo de depuración: Conserva el directorio temporal en el que dblatex trabaja realmente.

-D, --dump

Descarga la pila de errores cuando ocurre un error (propósito de depuración).

-e indexstyle, --indexstyle indexstyle

Archivo de estilo de índice para pasar a makeindex en lugar del estilo de índice predeterminado de dblatex.

-f figure_format, --fig-format=figure_format

Formato de figura de entrada: fig, eps. Se usa cuando no se deduce de la extensión del archivo de figura.

-F input_format, --input-format=input_format

Formato de archivo de entrada: sgml, xml (por defecto).

-i texinputs, --texinputs texinputs

Ruta añadida a TEXINPUTS

-I figure_path, --fig-path=figure_path

Ruta de búsqueda adicional de las figuras.

-l bst_path, --bst-path=bst_path

Ruta de búsqueda adicional de los estilos BibTeX.

-L bib_path, --bib-path=bib_path

Ruta de búsqueda adicional de las bases de datos BibTeX.

-m xslt, --xslt=xslt

Motor XSLT a usar. Los motores disponibles son: xsltproc (por defecto), 4xslt, saxon.

-o output, --output=output

Nombre del archivo de salida. Cuando no se especifica, se usa el nombre del archivo de entrada, con la extensión del formato de salida. La opción se ignora si se dividen varios libros de un conjunto. En este caso se aplica la opción -O en su lugar.

-O output_dir, --output-dir=output_dir

Directorio de salida de los libros creados a partir de un conjunto. Cuando no se especifica, se usa el directorio de trabajo actual en su lugar. La opción se ignora si se genera un solo documento, y se tiene en cuenta la opción -o.

-p xsl_user, --xsl-user=xsl_user

Una hoja de estilo XSL de usuario a usar. Se pueden especificar varias hojas de estilo de usuario, pero el orden de las opciones es significativo: una hoja de estilo de usuario tiene precedencia sobre las hojas de estilo de usuario definidas previamente.

-P param=value, --param=param=value

Establece un parámetro XSL desde la línea de comandos.

-q, --quiet

Menos verboso, solo muestra los mensajes de salida de TeX y los mensajes de error.

-r [plugin:]script, --texpost=[plugin:]script

Script llamado al final de la compilación de tex. Su función es modificar el archivo tex o uno de los archivos de compilación antes de la última pasada. El script puede ser un plugin de python. En este caso, añada el prefijo 'plugin:'.

-s latex_style, --texstyle=latex_style

Estilo LaTeX a aplicar. Puede ser un nombre de paquete o directamente una ruta de paquete latex. Un nombre de paquete debe estar sin ruta de directorio y sin la extensión '.sty'. Por el contrario, una ruta de paquete latex completa puede contener una ruta de directorio, pero debe terminar con la extensión '.sty'.

-t format, --type=format

Formato de salida. Formatos disponibles: tex, dvi, ps, pdf (por defecto).

--dvi

Salida DVI. Equivalente a -tdvi.

--pdf

Salida PDF. Equivalente a -tpdf.

--ps

Salida PostScript. Equivalente a -tps.

-T style, --style=style

Estilo de salida, los predefinidos son: db2latex, simple, native (por defecto).

-v, --version

Muestra la versión de dblatex.

-V, --verbose

Modo verboso, muestra los comandos en ejecución

-x xslt_options, --xslt-opts=xslt_options

Argumentos pasados directamente al motor XSLT

-X, --no-external

Deshabilita el soporte de archivos de texto externos. Este soporte es necesario para las llamadas a archivos externos referenciados por textdata o imagedata, pero se puede deshabilitar si el documento no contiene dichas llamadas. Deshabilitar este soporte puede mejorar el rendimiento del procesamiento para documentos grandes.

ARCHIVOS Y DIRECTORIOS

$HOME/.dblatex/

Directorio de configuración del usuario.

/etc/dblatex/

Directorio de configuración a nivel de sistema.

Los estilos de salida predefinidos se encuentran en el directorio de documentación del paquete instalado.

VARIABLES DE ENTORNO

DBLATEX_CONFIG_FILES

Directorios de configuración adicionales que pueden contener archivos de configuración de dblatex.

EJEMPLOS

Para producir myfile.pdf a partir de myfile.xml:

dblatex myfile.xml

Para establecer algunos parámetros XSL desde la línea de comandos:

dblatex -P latex.babel.language=de myfile.xml

Para usar tu hoja de estilo XSL:

dblatex -p myconfig.xsl myfile.xml

Para usar el estilo de salida db2latex:

dblatex -T db2latex myfile.xml

Para aplicar tu propio estilo latex:

dblatex -s mystyle myfile.xml
dblatex -s /path/to/mystyle.sty myfile.xml

Para pasar argumentos adicionales al motor XSLT:

dblatex -x "--path /path/to/load/entity" myfile.xml

Para usar dblatex y perfilar:

xsltproc --param profile.attribute "'output'" \
         --param profile.value "'pdf'" \
         /path/to/profiling/profile.xsl \
         myfile.xml | dblatex -o myfile.pdf -

Para construir un conjunto de libros:

dblatex -O /path/to/chunk/dir -Pset.book.num=all myfile.xml
