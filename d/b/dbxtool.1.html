NOMBRE

dbxtool - mecanismo para distribuir y aplicar actualizaciones de DBX de UEFI Secure Boot

SINOPSIS

dbxtool [--dbx=archivo_dbx | -d archivo_dbx ] [ --list | -l ] [ --verbose | -v ] [ --apply | -a ] [ directorio_actualizaciones | actualizacion0 [ ... actualizacionN ]]

DESCRIPCIÓN

dbxtool es una herramienta de línea de comandos y un servicio systemd de un solo disparo para aplicar actualizaciones de DBX de UEFI Secure Boot.

OPCIONES

--dbx=archivo_dbx
Utiliza un archivo especificado para dbx en lugar de la variable del sistema. Esta opción solo funciona con --list.
--list
Lista las entradas de DBX en la base de datos del sistema, o en una copia de la misma o en un archivo de actualización.
--verbose
Muestra mucha información detallada sobre lo que está haciendo dbxtool.
--apply
Aplica las actualizaciones especificadas en la línea de comandos. No funciona con --dbx. Este argumento requiere un argumento directorio_actualizaciones o uno o más argumentos actualizacionN.
directorio_actualizaciones
Directorio de actualizaciones de dbx. Los nombres de archivo deben terminar en ".bin". Este argumento solo funciona con --apply.
actualizacion0
Una actualización individual de dbx. Este argumento solo funciona con --apply.
