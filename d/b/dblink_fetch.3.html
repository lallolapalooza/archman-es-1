NOMBRE

dblink_fetch - devuelve filas de un cursor abierto en una base de datos remota

SINOPSIS

dblink_fetch(text cursorname, int howmany [, bool fail_on_error]) returns setof record
dblink_fetch(text connname, text cursorname, int howmany [, bool fail_on_error]) returns setof record

DESCRIPCIÓN

dblink_fetch recupera filas de un cursor previamente establecido por dblink_open.

ARGUMENTOS

connname

Nombre de la conexión a utilizar; omita este parámetro para utilizar la conexión sin nombre.

cursorname

El nombre del cursor del que se va a recuperar.

howmany

El número máximo de filas a recuperar. Se recuperan las siguientes howmany filas, comenzando desde la posición actual del cursor, avanzando. Una vez que el cursor llega a su fin, no se producen más filas.

fail_on_error

Si es verdadero (el valor predeterminado cuando se omite), un error lanzado en el lado remoto de la conexión provoca que también se lance un error localmente. Si es falso, el error remoto se informa localmente como un NOTICE, y la función no devuelve ninguna fila.

VALOR DE RETORNO

La función devuelve la(s) fila(s) recuperada(s) del cursor. Para utilizar esta función, deberá especificar el conjunto esperado de columnas, como se discutió previamente para dblink.

NOTAS

En caso de una discrepancia entre el número de columnas de retorno especificadas en la cláusula FROM y el número real de columnas devueltas por el cursor remoto, se lanzará un error. En este caso, el cursor remoto aún se avanza tantas filas como si el error no hubiera ocurrido. Lo mismo ocurre con cualquier otro error que ocurra en la consulta local después de que se haya realizado la FETCH remota.

EJEMPLOS

SELECT dblink_connect('dbname=postgres options=-csearch_path=');
 dblink_connect
----------------
 OK
(1 fila)
SELECT dblink_open('foo', 'select proname, prosrc from pg_proc where proname like ''bytea%''');
 dblink_open
-------------
 OK
(1 fila)
