DBWRAP_TOOL(1) Herramientas de administración del sistema DBWRAP_TOOL(1)

NOMBRE

dbwrap_tool - herramienta de manipulación de TDB/CTDB de bajo nivel usando la interfaz dbwrap

SINOPSIS

dbwrap_tool [-?|--help] [--usage] [--persistent] [--non-persistent] [-d|--debuglevel=NIVEL_DEBUG] [--debug-stdout] [--configfile=ARCHIVO_CONFIGURACION] [--option=nombre=valor] [-l|--log-basename=BASE_ARCHIVO_LOG] [--leak-report] [--leak-report-full] {<base_de_datos>} {<operacion>} [<clave> [<tipo> [<valor>]]]

DESCRIPCIÓN

Esta herramienta forma parte de la suite samba(7).

El programa dbwrap_tool se utiliza para leer y manipular bases de datos TDB/CTDB utilizando la interfaz dbwrap.

Las siguientes operaciones de base de datos están disponibles:

•fetch: obtener un registro
•store: crear o modificar un registro
•delete: eliminar un registro
•exists: comprobar la existencia de un registro
•erase: eliminar todos los registros
•listkeys: listar todos los registros disponibles
•listwatchers: listar los procesos que están esperando cambios en un registro

Los siguientes tipos están disponibles:

•int32: entero con signo de 32 bits
•uint32: entero sin signo de 32 bits
•string: "hola mundo"
•hex: cadenas hexadecimales como "68656C6C6F20776F726C6400" ("hola mundo")

OPCIONES

--persistent

Abrir la base de datos como una base de datos persistente.

Se debe especificar exactamente una de las opciones --persistent o --non-persistent.

--non-persistent

Abrir la base de datos como una base de datos no persistente.

Advertencia: abrir una base de datos como no persistente cuando actualmente no hay ningún otro abridor, borrará la base de datos.

Se debe especificar exactamente una de las opciones --persistent o --non-persistent.

-?|--help

Imprime un resumen de las opciones de la línea de comandos.

--usage

Muestra un breve mensaje de uso.

-d|--debuglevel=nivel

nivel es un entero de 0 a 10. El valor predeterminado si este parámetro no se especifica es 1 para aplicaciones cliente.

Cuanto mayor sea este valor, más detalles se registrarán en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán errores críticos y advertencias graves. El nivel 1 es un nivel razonable para el uso diario: genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse al investigar un problema. Los niveles superiores a 3 están diseñados para uso exclusivo de desarrolladores y generan ENORMES cantidades de datos de registro, la mayoría de los cuales son extremadamente crípticos.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro nivel de registro en el archivo /etc/samba/smb.conf.

--debug-stdout

Redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes registran en STDERR.

--configfile=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información de este archivo puede ser general para cliente y servidor o proporcionar solo opciones específicas del cliente como client smb encrypt. Consulte /etc/samba/smb.conf para obtener más información. El nombre del archivo de configuración predeterminado se determina en el momento de la compilación.

--option=<nombre>=<valor>

Establece la opción de smb.conf(5) "<nombre>" al valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o un valor incluye un espacio, envuelva todo --option=nombre=valor entre comillas.

-l|--log-basename=directorio_log

Nombre base del directorio para los archivos de registro/depuración. La extensión ".nombre_programa" se agregará (por ejemplo, log.smbclient, log.smbd, etc...). El cliente nunca elimina el archivo de registro.

--leak-report

Habilita la generación de informes de fugas de talloc al salir.

--leak-report-full

Habilita la generación de informes completos de fugas de talloc al salir.

-V|--version

Imprime el número de versión del programa.

COMANDOS

fetch

dbwrap_tool <base_de_datos> fetch <clave> <tipo>

store

dbwrap_tool <base_de_datos> store <clave> <tipo> <valor>

delete

dbwrap_tool <base_de_datos> delete <clave>

exists

dbwrap_tool <base_de_datos> exists <clave>

erase

dbwrap_tool <base_de_datos> erase

listkeys

dbwrap_tool <base_de_datos> listkeys

listwatchers

dbwrap_tool <base_de_datos> listwatchers

EJEMPLOS

Listar todas las claves de winbindd_idmap.tdb

dbwrap_tool --persistent winbindd_idmap.tdb listkeys

Obtener el registro con clave "USER HWM" como uint32

dbwrap_tool --persistent winbindd_idmap.tdb fetch "USER HWM" uint32

Eliminar el registro con clave "USER HWM"

dbwrap_tool --persistent winbindd_idmap.tdb delete "USER HWM"

Almacenar y sobrescribir el registro "USER HWM" con el valor 214

uint32: dbwrap_tool --persistent winbindd_idmap.tdb store "USER HWM" uint32 214 hex: dbwrap_tool --persistent winbindd_idmap.tdb store "USER HWM" hex D6000000
