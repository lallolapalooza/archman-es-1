DBPROBE(1) Manual de comandos generales DBPROBE(1)

NOMBRE

dbprobe - información sobre el tiempo de respuesta y la disponibilidad de la base de datos

SINOPSIS

dbprobe.pl [retraso]

DESCRIPCIÓN

La utilidad dbprobe es utilizada por pmdadbping(1) para medir el tiempo de respuesta de una base de datos. Se ejecuta una consulta dada en la base de datos en el intervalo solicitado (retraso, que por defecto es de 60 segundos). Esta medida de tiempo de respuesta puede ser exportada a través del framework Performance Co-Pilot para monitorización en vivo e histórica usando pmdadbping(1).

VER TAMBIÉN

PCPIntro(1), pmcd(1), pmdadbping(1) y DBI(3).
