NOMBRE

DBD::SQLite::VirtualTable::FileContent -- tabla virtual para visualizar el contenido de archivos

SINOPSIS

Dentro de Perl :

$dbh->sqlite_create_module(fcontent => "DBD::SQLite::VirtualTable::FileContent");

Luego, dentro de SQL :

CREATE VIRTUAL TABLE tbl USING fcontent(
   source      = tabla_origen,
   content_col = columna_contenido,
   path_col    = columna_ruta,
   expose      = "ruta, col1, col2, col3", -- o "*"
   root        = "/foo/bar"
   get_content = Foo::Bar::leer_desde_archivo
  );
SELECT col1, ruta, contenido FROM tbl WHERE ...;

DESCRIPCIÓN

Una tabla virtual "FileContent" está enlazada a alguna tabla origen subyacente, que tiene una columna que contiene rutas a archivos. La tabla virtual se comporta como una vista de base de datos sobre la tabla de origen, con una columna añadida que expone el contenido de esos archivos.

Esto es especialmente útil como "contenido externo" para alguna tabla fulltext (ver DBD::SQLite::Fulltext_search): la tabla de índice almacena metadatos sobre archivos, y luego el motor fulltext puede indexar tanto los metadatos como el contenido de los archivos.

PARÁMETROS

Los parámetros para crear una tabla virtual "FileContent" se especifican dentro de la declaración "CREATE VIRTUAL TABLE", al igual que las declaraciones de columnas regulares, pero con un signo '='. Los parámetros autorizados son:

"source"
El nombre de la tabla origen. Este parámetro es obligatorio. Todos los demás parámetros son opcionales.
"content_col"
El nombre de la columna virtual que expone el contenido del archivo. El valor por defecto es "content".
"path_col"
El nombre de la columna en "source" que contiene las rutas a los archivos. El valor por defecto es "path".
"expose"
Una lista separada por comas (dentro de comillas dobles) de nombres de columnas de origen que serán expuestas por la tabla virtual. El valor por defecto es "*", lo que significa todas las columnas de origen.
"root"
Un directorio raíz opcional que se antepondrá a la columna path al abrir archivos.
"get_content"
Nombre completamente cualificado de una función de Perl para leer el contenido de los archivos. La implementación por defecto simplemente lee el archivo completo en una cadena; pero este hook puede apuntar a implementaciones más sofisticadas, como por ejemplo una función que elimine etiquetas HTML. La función enganchada se llama así: 
$contenido_archivo = $get_content->($ruta, $raiz);
