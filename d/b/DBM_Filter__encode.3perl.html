DBM_Filter::encode(3perl) Guía del programador de Perl DBM_Filter::encode(3perl)

NOMBRE

DBM_Filter::encode - filtro para DBM_Filter

SINOPSIS

use SDBM_File; # o DB_File, GDBM_File, NDBM_File, ODBM_File
use DBM_Filter ;
$db = tie %hash, ...
$db->Filter_Push('encode' => 'iso-8859-16');

DESCRIPCIÓN

Este filtro DBM te permite elegir la codificación de caracteres que se almacenará en el archivo DBM. El uso es

$db->Filter_Push('encode' => CODIFICACIÓN);

donde "CODIFICACIÓN" debe ser un nombre de codificación válido que el módulo Encode reconozca.

Se generará un error fatal si:

1.
El módulo Encode no está disponible.
2.
La codificación solicitada no es compatible con el módulo Encode.

VER TAMBIÉN

DBM_Filter, perldbmfilter, Encode
