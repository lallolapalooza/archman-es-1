DESC

RIP
CIÓN

El programa dbmail-util ofrece una limpieza de la base de datos y una comprobación de integridad. Todos los mensajes establecidos para eliminación (estado 2) serán marcados para eliminación final (estado 3). Todos los mensajes marcados para eliminación final serán borrados de la base de datos. La comprobación de integridad buscará mimeparts, valores de

cabecera, mensajes y buzones no conectados. 
Por defecto, las comprobaciones son de solo lectura. Pase la opción --
no para responder no a cualquier aviso. Pase la opción --yes para rea
lizar cambios de lectura/escritura, respondiendo sí a cualquier aviso.

-d,

--set-deleted

Pone en cola todos los mensajes marcados con el estado DELETE (2) para el purgado final, estableciendo el valor del estado en PURGE (3). El campo de estado se establece en DELETE mediante los comandos IMAP-EXPUNGE

o POP3-DELE.
-p,
--purge-deleted

Elimina todos los mensajes con un valor de PURGE (3) en el campo de estado. Para purgar mensajes actualmente marcados con el estado DELETE (2), ejecute con las opciones -pd dos veces. Esto no se recomienda; es mejor dejar un período de gracia para los mensajes antiguos antes de borrarlos permanentemente de

la base de datos.
