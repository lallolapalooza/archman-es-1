NOMBRE

dbmail-deliver - inserta mensajes en DBMail.

SINOPSIS

dbmail-deliver [opciones comunes] --to-address dirección [opciones]
dbmail-deliver [opciones comunes] --to-header campoh [opciones]
dbmail-deliver [opciones comunes] --to-user nombresdeusuario [opciones]

DESCRIPCIÓN

El programa dbmail-deliver inserta mensajes desde la línea de comandos o desde cualquier MTA en DBMail. El programa lee de la entrada estándar.

OPCIONES

-d, --to-address direcciones...

Entrega mensajes a los destinatarios especificados por direcciones. Esta opción se usa principalmente para la entrega desde un MTA. Separe múltiples direcciones con espacios.

-t, --to-header campoh

Entrega mensajes al encabezado MIME del destinatario especificado en campoh. El encabezado predeterminado a usar es el encabezado "Delivered-To:". El campoh debe estar en minúsculas, por ejemplo, delivered-to

-u, --to-user nombresdeusuario...

Entrega mensajes directamente al nombre de usuario dado. Separe múltiples nombres de usuario con espacios.

-m, --mailbox nombredebuzón

Entrega mensajes al buzón nombredebuzón del destinatario. Si este buzón aún no existe, se crea. Los scripts Sieve se ejecutarán normalmente, posiblemente alterando el buzón de destino.

-M, --mailbox-force nombredebuzón

Entrega mensajes al buzón nombredebuzón del destinatario. Si este buzón aún no existe, se crea. Los scripts Sieve no se ejecutan. No se realizan comprobaciones de permisos para la creación del buzón o la entrega de mensajes.

-r, return-path rutaderetorno

Establece la ruta de retorno para devoluciones y otros informes de error a rutaderetorno.

OPCIONES COMUNES

-f, --config archivoconfig

Especifique un archivo de configuración alternativo.

Use dbmail-<utilidad> --help para mostrar la ubicación predeterminada.

-q, --quiet

Omite silenciosamente las indicaciones interactivas y los mensajes de estado útiles que de otro modo se imprimirían en la salida estándar. Use dos -q para silenciar los errores que de otro modo se imprimirían en el error estándar.

-v, --verbose

Opere de forma detallada. Algunas de las utilidades del conjunto DBMail pueden tomar dos -v para verbosidad adicional. Aquellas que no entiendan esta convención no se quejarán de tener el -v adicional y simplemente operarán a su nivel de verbosidad normal.

-V, --version

Muestra la versión y los derechos de autor, luego sale.

-h, --help

Muestra un breve resumen de las opciones, luego sale.
