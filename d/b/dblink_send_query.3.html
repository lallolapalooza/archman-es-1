NOMBRE

dblink_send_query - envía una consulta asíncrona a una base de datos remota

SINOPSIS

dblink_send_query(text connname, text sql) returns int

DESCRIPCIÓN

dblink_send_query envía una consulta para ser ejecutada asíncronamente, es decir, sin esperar inmediatamente el resultado. No debe haber ninguna consulta asíncrona ya en progreso en la conexión.

Después de despachar con éxito una consulta asíncrona, el estado de finalización se puede verificar con dblink_is_busy, y los resultados se recopilan finalmente con dblink_get_result. También es posible intentar cancelar una consulta asíncrona activa usando dblink_cancel_query.

ARGUMENTOS

connname

Nombre de la conexión a utilizar.

sql

La sentencia SQL que desea ejecutar en la base de datos remota, por ejemplo, `select * from pg_class`.

VALOR DE RETORNO

Devuelve 1 si la consulta se despachó con éxito, 0 en caso contrario.

EJEMPLOS

SELECT dblink_send_query('dtest1', 'SELECT * FROM foo WHERE f1 < 3');
