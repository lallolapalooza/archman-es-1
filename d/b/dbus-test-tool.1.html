DBUS-TEST-TOOL(1) Comandos de usuario DBUS-TEST-TOOL(1)

NOMBRE

dbus-test-tool - Generador de tráfico y herramienta de prueba de D-Bus

SINOPSIS

dbus-test-tool black-hole [--session | --system] [--name=NOMBRE] [--no-read]

dbus-test-tool echo [--session | --system] [--name=NOMBRE] [--sleep-ms=MS]

dbus-test-tool spam [--session | --system] [--dest=NOMBRE] [--count=N] [--flood] [--ignore-errors] [--messages-per-conn=N] [--no-reply] [--queue=N] [--seed=SEMILLA] [--string | --bytes | --empty] [--payload=S | --stdin | --message-stdin | --random-size]

DESCRIPCIÓN

dbus-test-tool es una herramienta multipropósito para depurar y perfilar D-Bus.

dbus-test-tool black-hole se conecta a D-Bus, opcionalmente solicita un nombre, y luego no responde a los mensajes. Normalmente lee y descarta mensajes de su socket D-Bus, pero puede configurarse para dormir indefinidamente sin leer.

dbus-test-tool echo se conecta a D-Bus, opcionalmente solicita un nombre, y luego envía una respuesta vacía a cada llamada de método, después de un retraso opcional.

dbus-test-tool spam se conecta a D-Bus y realiza llamadas de método repetidas, normalmente con el nombre com.example.Spam.

OPCIONES

Opciones comunes

--session

Conectarse al bus de sesión. Este es el valor predeterminado.

--system

Conectarse al bus del sistema.

Modo black-hole

--name=NOMBRE

Antes de continuar, solicita la propiedad del nombre de bus conocido NOMBRE, por ejemplo com.example.NoReply. Por defecto, no se solicita ningún nombre, y la herramienta solo puede ser dirigida por un nombre de bus único como :1.23.

--no-read

No leer del socket D-Bus.

Modo echo

--name=NOMBRE

Antes de continuar, solicita la propiedad del nombre de bus conocido NOMBRE, por ejemplo com.example.Echo. Por defecto, no se solicita ningún nombre, y la herramienta solo puede ser dirigida por un nombre de bus único como :1.23.

--sleep-ms=MS

Bloquear durante MS milisegundos antes de responder a una llamada de método.

Modo spam

--dest=NOMBRE

Enviar llamadas de método al nombre de bus conocido o único NOMBRE. El valor predeterminado es el dbus-daemon, org.freedesktop.DBus.

--count=N

Enviar N llamadas de método en total. El valor predeterminado es 1.

--queue=N

Enviar N llamadas de método antes de esperar respuestas, luego enviar una nueva llamada por cada respuesta recibida, manteniendo N llamadas de método "en vuelo" en todo momento hasta que se envíe el número de mensajes especificado con la opción --count. El valor predeterminado es 1, a menos que se use --flood.

--flood

Enviar todos los mensajes sin esperar una respuesta, equivalente a --queue con un N arbitrariamente grande.

--no-reply

Establecer la bandera "no se desea respuesta" en los mensajes. Esto implica --flood, ya que deshabilita las respuestas que se usarían para una longitud de --queue finita.

--messages-per-conn=N

Si se proporciona, enviar N llamadas de método en la misma conexión, luego desconectar y reconectar. El valor predeterminado es usar la misma conexión para todas las llamadas de método.

--string

El contenido de cada mensaje es una cadena UTF-8. Este es el valor predeterminado. La cadena real utilizada se proporciona en la opción --payload o --stdin, con el valor predeterminado de "hello, world!".

--bytes

El contenido de cada mensaje es un array de bytes. Los bytes reales utilizados se proporcionan en la opción --payload o --stdin, con el valor predeterminado de la codificación ASCII de "hello, world!".

--empty

Los mensajes no tienen contenido.

--payload=S

Usar S como --string o --bytes en los mensajes. El valor predeterminado es "hello, world!".

--stdin

Leer de la entrada estándar hasta que se alcance el final del archivo, y usar eso como --string o --bytes en los mensajes.

--message-stdin

Leer un mensaje completo de llamada de método binario de D-Bus de la entrada estándar, y usar eso para cada llamada de método.

--random-size

Leer números decimales ASCII separados por espacios en blanco de la entrada estándar, elegir uno al azar para cada mensaje y enviar un mensaje cuyo contenido sea una cadena de esa longitud.

--seed=SEMILLA

Usar SEMILLA como la semilla para el generador de números pseudoaleatorios, para tener secuencias de mensajes aleatorios algo repetibles.

ERRORES

Por favor, envíe informes de errores al rastreador de errores de D-Bus o a la lista de correo. Ver https://www.freedesktop.org/wiki/Software/dbus/.
