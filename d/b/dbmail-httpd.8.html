NOMBRE

dbmail-httpd - habla el protocolo HTTP-1.1

SINOPSIS

dbmail-httpd [--config archivo_config] [--pidfile archivo_pid]
dbmail-httpd [--config archivo_config] [--pidfile archivo_pid] --no-daemon
dbmail-httpd [--config archivo_config] [--pidfile archivo_pid] --inetd

DESCRIPCIÓN

Expone el modelo de datos de DBMail a través de una API REST-full.

Por favor, consulte contrib/dbmailclient.php para las rutas de URL soportadas.

OPCIONES

-p, --pidfile archivo_pid

Especifica un archivo PID alternativo. Por defecto, los demonios usan dbmail-<daemon>.pid para sus archivos PID, guardándolos en el directorio especificado por la entrada pid_directory en dbmail.conf o, si esta no existe, el valor establecido por la opción de configuración --localstatedir, y se detendrán si no se puede escribir el archivo PID. Use la opción -p archivo_pid para colocar el archivo PID en la ubicación preferida de su sistema.

-n, --no-daemon

No demonizar: modo inetd. El programa permanece conectado a la consola desde la que se inició y leerá y escribirá en stdin/stdout. Esto es útil para depuración cuando se combina con la opción -v. También se utiliza para ejecutar desde (x)inetd.

-D, --inetd

No demonizar: El programa permanece conectado a la consola y escuchará en los sockets de red definidos en dbmail.conf. Esto se utiliza principalmente para xinetd (Extended Internet Service Daemon).

OPCIONES COMUNES

-f, --config archivo_config

Especifica un archivo de configuración alternativo.

Use dbmail-<utilidad> --help para mostrar la ubicación predeterminada.

-q, --quiet

Omite silenciosamente las indicaciones interactivas y los mensajes de estado útiles que de otro modo se imprimirían en la salida estándar. Use dos -q para silenciar los errores que de otro modo se imprimirían en la salida de error estándar.

-v, --verbose

Opera de forma detallada. Algunas de las utilidades del conjunto DBMail pueden aceptar dos -v para obtener información adicional. Aquellas que no entienden esta convención no se quejarán de tener la -v adicional y operarán simplemente a su nivel de detalle normal.

-V, --version

Muestra la versión y los derechos de autor, luego sale.

-h, --help

Muestra un breve resumen de las opciones, luego sale.
