DBSCAN(1) Manual de Comandos Generales DBSCAN(1)

NOMBRE

dbscan - escanea un archivo de índice de base de datos del Directorio del Servidor y vuelca el contenido

SINOPSIS

dbscan -f <nombre_archivo> [-R] [-t <tamaño>] [-K <id_entrada>] [-k <clave>] [-l <tamaño>] [-G <n>] [-n] [-r] [-s]

DESCRIPCIÓN

Escanea un archivo de índice de base de datos del Directorio del Servidor y vuelca el contenido.

OPCIONES

A continuación se incluye un resumen de las opciones:

opciones comunes:
-A, --ascii
volcar como datos ascii
-D, --db-type <nombre_archivo>
especificar tipo de base de datos: bdb o mdb
-f, --dbi <nombre_archivo>
especificar instancia de base de datos
-R, --raw
volcar como datos crudos
-t, --truncate-entry <tamaño>
tamaño de truncado de entrada (bytes)
opciones de archivo de entrada:
-K, --entry-id <id_entrada>
buscar solo un id de entrada específico
opciones de archivo de índice:
-G, --id-list-min-size <n>
mostrar solo entradas de índice con más de <n> ids
-I, --import <archivo>
Importar instancia de base de datos desde archivo. Requiere el parámetro --do-it ADVERTENCIA! Solo las instancias de base de datos id2entry y replication_changelog pueden ser importadas por dbscan.
-k, --key <clave>
buscar solo una clave específica
-l, --id-list-max-size <tamaño>
longitud máxima de la lista de ids volcada (por defecto 4096; 40 bytes <= tamaño <= 1048576 bytes)
-n, --show-id-list-lenghts
mostrar las longitudes de las listas de ids
--remove
eliminar una instancia de base de datos. Requiere el parámetro --do-it
-r, --show-id-list
mostrar el contenido de la lista de ids
-S, --stats
mostrar estadísticas
-X, --export <archivo>
Exportar instancia de base de datos a archivo
otras opciones:
-s, --summary
Resumen de los recuentos del índice
-L, --list
Listar las instancias de base de datos
--do-it
se requiere confirmación para acciones que modifican el contenido de la base de datos
-h, --help-it
mostrar el uso

USO

Ejemplos de uso:

Listar las instancias de la base de datos
dbscan -L /var/lib/dirsrv/slapd-supplier1/db
Volcar el archivo de entrada:
dbscan -f id2entry.db4
Mostrar claves de índice en cn.db4:
dbscan -f cn.db4
Mostrar claves de índice en cn en lmdb:
dbscan -f /var/lib/dirsrv/slapd-supplier1/db/userroot/cn.db
(Nota: Usa dbscan -L db_home_dir para obtener la ruta de la instancia de base de datos)
Mostrar claves de índice y el recuento de entradas que tienen la clave en mail.db4:
dbscan -r -f mail.db4
Mostrar claves de índice y los IDs que tienen más de 20 IDs en sn.db4:
dbscan -r -G 20 -f sn.db4
Mostrar resumen de objectclass.db4:
dbscan -s -f objectclass.db4
