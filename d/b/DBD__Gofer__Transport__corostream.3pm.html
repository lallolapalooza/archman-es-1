NOMBRE

DBD::Gofer::Transport::corostream - Transporte de stream asíncrono de DBD::Gofer usando Coro y AnyEvent

SINOPSIS

DBI_AUTOPROXY="dbi:Gofer:transport=corostream" perl script-de-perl-que-usa-dbi.pl

o

$dsn = ...; # el DSN para el driver y la base de datos que deseas usar
$dbh = DBI->connect("dbi:Gofer:transport=corostream;dsn=$dsn", ...);

DESCRIPCIÓN

La GRAN VENTAJA de usar Coro es que permite el uso de frameworks DBI existentes como DBIx::Class.

PROBLEMAS CONOCIDOS Y LIMITACIONES

- Usa Coro::Select, por lo que altera CORE::select globalmente
  La clase padre probablemente necesita ser refactorizada para permitir un enfoque más encapsulado.
- No previene múltiples solicitudes concurrentes
  Probablemente solo necesita un semáforo por conexión
- Coro tiene muchas advertencias. Comprador, ¡cuidado!.

APÉNDICE

Código de ejemplo:

#!perl
use strict;
use warnings;
use Time::HiRes qw(time);
BEGIN { $ENV{PERL_ANYEVENT_STRICT} = 1; $ENV{PERL_ANYEVENT_VERBOSE} = 1; }
use AnyEvent;
BEGIN { $ENV{DBI_TRACE} = 0; $ENV{DBI_GOFER_TRACE} = 0; $ENV{DBD_GOFER_TRACE} = 0; };
use DBI;
$ENV{DBI_AUTOPROXY} = 'dbi:Gofer:transport=corostream';
my $ticker = AnyEvent->timer( after => 0, interval => 0.1, cb => sub {
    warn sprintf "-tick- %.2f\n", time
} );
warn "conectando...\n";
my $dbh = DBI->connect("dbi:NullP:");
warn "...conectado\n";
for (1..3) {
    warn "entrando en DBI...\n";
    $dbh->do("sleep 0.3"); # pseudo-sql entendido por el driver DBD::NullP
    warn "...retornado\n";
}
warn "hecho.";
