DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine dbdt04 (character uplo, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) s, integer ns, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( * ) work, double precision resid)

DBDT04

Propósito:

!>
!> DBDT04 reconstruye una matriz bidiagonal B a partir de su SVD (parcial):
!>    S = U' * B * V
!> donde U y V son matrices ortogonales y S es diagonal.
!>
!> La relación de prueba para probar la descomposición de valores singulares es
!>    RESID = norm( S - U' * B * V ) / ( n * norm(B) * EPS )
!> donde VT = V' y EPS es la precisión de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz B es superior o inferior bidiagonal.
!>          = 'U':  Superior bidiagonal
!>          = 'L':  Inferior bidiagonal
!>

N

!>          N es INTEGER
!>          El orden de la matriz B.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz bidiagonal B.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los n-1 elementos superdiagonales de la matriz bidiagonal B
!>          si UPLO = 'U', o los n-1 elementos subdiagonales de B si
!>          UPLO = 'L'.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (NS)
!>          Los valores singulares de la SVD (parcial) de B, ordenados en
!>          orden decreciente.
!>

NS

!>          NS es INTEGER
!>          El número de valores/vectores singulares de la SVD (parcial)
!>          de B.
!>

U

!>          U es un array DOUBLE PRECISION, dimensión (LDU,NS)
!>          La matriz ortogonal n por ns U en S = U' * B * V.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= max(1,N)
!>

VT

!>          VT es un array DOUBLE PRECISION, dimensión (LDVT,N)
!>          La matriz ortogonal n por ns V en S = U' * B * V.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (2*N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          La relación de prueba:  norm(S - U' * B * V) / ( n * norm(B) * EPS )
!>
