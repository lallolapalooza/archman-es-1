DBI::DBD::

SqlEngine

Este es el paquete principal que contiene las rutinas para inicializar controladores DBI basados en DBI::DBD::SqlEngine. Principalmente se invoca el método "DBI::DBD::SqlEngine::driver", ya sea directamente desde DBI cuando el controlador es inicializado o desde la clase

derivada. 
package DBD::DBM;
use base qw( DBI::DBD::SqlEngine );
sub driver
{
    my ( $class, $attr ) = @_;
    ...
    my $drh = $class->SUPER::driver( $attr );
    ...
    return $drh;
}

No es necesario implementar tu propio método driver siempre que no se requiera inicialización adicional (p. ej., instalar más métodos privados del controlador). No necesitas llamar a "setup_driver" ya que DBI::DBD::

SqlEngine se
encarga de ello.

Este atributo contiene un hash con prioridades como clave y un array que contiene los atributos $dbh que deben ser inicializados durante antes/después de otros atributos.

La prioridad predeterminada de las claves de atributos no listadas es 50. Es bien sabido que muchos atributos necesitan ser establecidos antes de que se inicialicen algunas configuraciones de tablas. Por ejemplo, para DBD::DBM,

            dbm_type => "GDBM_File",
