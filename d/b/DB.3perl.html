DB(3perl) Guía de referencia para programadores de Perl DB(3perl)

NOMBRE

DB - interfaz programática para la API de depuración de Perl

SINOPSIS

package CLIENT;
use DB;
@ISA = qw(DB);
# estos métodos (heredados) pueden ser llamados por el cliente
CLIENT->register()      # registrar un nombre de paquete cliente
CLIENT->done()          # des-registrar de la API de depuración
CLIENT->skippkg('hide::hide')  # pedir a DB que no se detenga en este paquete
CLIENT->cont([DONDE])       # ejecutar algo más (hasta BREAK o 
                            # otro punto de interrupción)
CLIENT->step()              # paso a paso
CLIENT->next()              # saltar sobre
CLIENT->ret()               # retornar desde la subrutina actual
CLIENT->backtrace()         # devolver la descripción de la pila de llamadas
CLIENT->ready()             # llamar cuando la configuración del cliente esté lista
CLIENT->trace_toggle()      # alternar el modo de traza de llamadas a subrutinas
CLIENT->subs([SUBS])        # devolver información de subrutinas
CLIENT->files()             # devolver la lista de todos los archivos conocidos por DB
CLIENT->lines()             # devolver las líneas en el archivo actualmente cargado
CLIENT->loadfile(ARCHIVO,LÍNEA) # cargar un archivo y notificar a otros clientes
CLIENT->lineevents()        # devolver información sobre líneas con acciones
CLIENT->set_break([DONDE],[COND])
CLIENT->set_tbreak([DONDE])
CLIENT->clr_breaks([LISTA])
CLIENT->set_action(DONDE,ACCIÓN)
CLIENT->clr_actions([LISTA])
CLIENT->evalcode(CADENA)  # evaluar CADENA en el contexto del código en ejecución
CLIENT->prestop([CADENA]) # ejecutar en el contexto del código antes de detenerse
CLIENT->poststop([CADENA])# ejecutar en el contexto del código antes de reanudar
# Estos métodos serán llamados en los momentos apropiados.
# Las versiones de stub proporcionadas no hacen nada.
# Ninguno de estos puede bloquear.
CLIENT->init()          # llamado cuando la API de depuración se inicializa
CLIENT->stop(ARCHIVO,LÍNEA) # cuando la ejecución se detiene
CLIENT->idle()          # mientras está detenido (puede ser un bucle de eventos del cliente)
CLIENT->cleanup()       # justo antes de la salida
CLIENT->output(LISTA)    # llamado para imprimir cualquier salida que
                        # la API deba mostrar

DESCRIPCIÓN

La información de depuración de Perl es frecuentemente requerida no solo por depuradores, sino también por módulos que necesitan alguna información "especial" para hacer su trabajo correctamente, como los analizadores de rendimiento.

Este módulo abstrae y proporciona todos los ganchos hacia la funcionalidad interna de depuración de Perl, de modo que las diversas implementaciones de depuradores de Perl (o paquetes que quieran simplemente acceder a los datos de depuración "privilegiados") puedan beneficiarse del desarrollo de este código común. Actualmente utilizado por Swat, el depurador gráfico de perl/Tk.

Tenga en cuenta que múltiples "front-ends" pueden conectarse a esta API de depuración simultáneamente. Esto está destinado a facilitar cosas como depurar con una línea de comandos y una interfaz gráfica al mismo tiempo, depurar depuradores, etc. [Suena bien, pero esto necesita un soporte serio -- GSAR]

En particular, esta API no no proporciona las siguientes funciones:

  • visualización de datos
  • procesamiento de comandos
  • gestión de alias de comandos
  • interfaz de usuario (tty o gráfica)

Estas están destinadas a ser servicios realizados por los clientes de esta API.

Este módulo intenta estar impecable con respecto a "use strict;" y cuando las advertencias están habilitadas.

Variables Globales

Los siguientes nombres globales "públicos" pueden ser leídos por los clientes de esta API. Tenga cuidado de que estos deben considerarse "solo lectura".

$DB::sub
Nombre de la subrutina actualmente en ejecución.
%DB::sub
Las claves de este hash son los nombres de todas las subrutinas conocidas. Cada valor es una cadena codificada que tiene el formato sprintf(3) "("%s:%d-%d", nombrearchivo, líneadesde, líneahasta)".
$DB::single
Bandera de paso a paso. Será verdadera si la API se detendrá en la siguiente sentencia.
$DB::signal
Bandera de señal. Se establecerá en un valor verdadero si se capturó una señal. Los clientes pueden verificar esta bandera para abortar operaciones costosas en tiempo.
$DB::trace
Esta bandera se establece en verdadero si la API está rastreando a través de las llamadas a subrutinas.
@DB::args
Contiene los argumentos de la subrutina actual, o el arreglo @ARGV
si está en el contexto de nivel superior.
@DB::dbline
Lista de líneas en el archivo actualmente cargado.
%DB::dbline Acciones en el archivo actual (las claves son números de línea). Los valores son cadenas que tienen el formato sprintf(3)"("%s\000%s", condicióninterrupción, códigoacción)"
.
$DB::package
Espacio de nombres del paquete del código actualmente en ejecución.
$DB::filename
Nombre del archivo actualmente cargado.
$DB::subname
Nombre completamente calificado de la subrutina actualmente en ejecución.
$DB::lineno

Número de línea que se ejecutará a continuación.

Métodos de retorno de llamada del cliente

Los siguientes métodos "virtuales" pueden ser definidos por el cliente. Serán llamados por la API en puntos apropiados. Tenga en cuenta que a menos que se especifique lo contrario, la API de depuración solo define versiones vacías, no funcionales de estos métodos.CLIENT->
init()
Llamado después de que la API de depuración se inicializa a sí misma.
CLIENT->prestop([CADENA])
Usualmente heredado del paquete DB. Si no se pasan argumentos, devuelve la cadena de acción de prestop.CLIENT->
stop()
Llamado cuando la ejecución se detiene (con argumentos archivo, línea).CLIENT->
idle()
Llamado mientras está detenido (puede ser un bucle de eventos del cliente).
CLIENT->poststop([CADENA])
Usualmente heredado del paquete DB. Si no se pasan argumentos, devuelve la cadena de acción de poststop.
CLIENT->evalcode(CADENA) Usualmente heredado del paquete DB. Pedir que una CADENA sea"eval"
-uada en el contexto del código en ejecución.CLIENT->
cleanup()
Llamado justo antes de la salida.
CLIENT->output(LISTA)

Llamado cuando la API debe mostrar un mensaje (advertencias, errores, etc.).

ERRORES

La interfaz definida por este módulo carece de algunas de las adiciones posteriores a la funcionalidad de depuración de perl. Como tal, esta interfaz debe considerarse altamente experimental y sujeta a cambios.
