DBUS-UUIDGEN(1) Comandos de usuario DBUS-UUIDGEN(1)

NOMBRE

dbus-uuidgen - Utilidad para generar UUIDs

SINOPSIS

dbus-uuidgen [--version] [--ensure [=NOMBRE_ARCHIVO]] [--get [=NOMBRE_ARCHIVO]]

DESCRIPCIÓN

El comando dbus-uuidgen genera o lee un ID único universal.

Tenga en cuenta que el UUID de D-Bus no tiene relación con RFC 4122 y no genera UUIDs compatibles con esa especificación. Muchos sistemas tienen un comando separado para eso (a menudo llamado "uuidgen").

Consulte https://www.freedesktop.org/wiki/Software/dbus/ para obtener más información sobre D-Bus.

El uso principal de dbus-uuidgen es ejecutarse en el script post-instalación de un paquete D-Bus de la siguiente manera:

  dbus-uuidgen --ensure

Esto asegurará que /var/lib/dbus/machine-id exista y contenga el uuid. No sobrescribirá un uuid existente, ya que este id debe permanecer fijo para una sola máquina hasta el próximo reinicio, como mínimo.

Las propiedades importantes del UUID de la máquina son que 1) no cambia hasta el próximo reinicio y 2) es diferente para cualquier par de instancias en ejecución del kernel del SO. Es decir, si dos procesos ven el mismo UUID, también deberían ver la misma memoria compartida, sockets de dominio UNIX, pantallas X locales, resolución de localhost.localdomain, IDs de proceso, etc.

Si ejecuta dbus-uuidgen sin opciones, simplemente imprime un nuevo uuid creado de la nada.

Si lo ejecuta con --get, imprime el UUID de la máquina por defecto, o el UUID en el archivo especificado si especifica un archivo.

Si intenta cambiar un machine-id existente en un sistema en ejecución, probablemente resultará en cosas malas. No intente cambiar este archivo. Además, no lo haga igual en dos sistemas diferentes; debe ser diferente siempre que haya dos kernels en ejecución.

El UUID debe ser diferente en dos máquinas virtuales diferentes, porque hay dos kernels diferentes.

OPCIONES

Se admiten las siguientes opciones:

--get[=NOMBRE_ARCHIVO]

Si no se proporciona un nombre de archivo, se utiliza por defecto localstatedir/lib/dbus/machine-id (localstatedir suele ser /var). Si este archivo existe y es válido, el uuid del archivo se imprime en stdout. De lo contrario, el comando sale con un estado distinto de cero.

--ensure[=NOMBRE_ARCHIVO]

Si no se proporciona un nombre de archivo, se utiliza por defecto localstatedir/lib/dbus/machine-id (localstatedir suele ser /var). Si este archivo existe, se validará y se devolverá un código de error si contiene algo incorrecto. Si el archivo no existe, se creará con un nuevo uuid en él. En caso de éxito, no imprime nada.

--version

Imprime la versión de dbus-uuidgen
