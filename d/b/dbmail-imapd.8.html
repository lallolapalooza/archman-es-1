DESCRIPCIÓ

N

El demonio dbmail-imapd es un servidor IMAP4r1 con todas las

funcionalidades
.

OPCIONE

S

-p, --pidfile

archivo_pid
Especifica un archivo pid alternativo. Por defecto, los demonios usan dbmail-<demonio>.pid como sus archivos pid, guardándolos en el directorio especificado por la entrada pid_directory en dbmail.conf o, si este no existe, el valor establecido por la opción de configuración --localstatedir, y se detendrán si el archivo pid no se puede escribir. Usa la opción -p archivo_pid para colocar el archivo pid en la ubicación preferida de tu
sistema.

-n,

--no-daemon
No convertir en demonio: modo inetd. El programa permanece adjunto a la consola desde la que se inició y leerá y escribirá en stdin/stdout. Esto es útil para depurar cuando se combina con la opción -v. También se usa para ejecutar desde (x)
inetd.

-D,

--inetd
No convertir en demonio: El programa permanece adjunto a la consola y
escuchará en los sockets de red definidos en dbmail.conf. Esto se usa
principalmente para xinetd (Demonio de Servicio de Internet Extendido)

EJEMPL

O

Para

xinetd: 
-----------------------------------------------------------
# /etc/xinet.d/dbmail-imap
#
service imap
{
        socket_type     = stream
        wait            = no
        user            = root
        server          = /usr/local/sbin/dbmail-imapd
        protocol        = tcp
        server_args     = -n
        log_on_failure  += USERID
        disable         = no
}
---------------------------------------------------------
