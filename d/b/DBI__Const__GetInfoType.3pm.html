NOMBRE

DBI::Const::GetInfoType - Datos que describen los códigos de tipo GetInfo

SINOPSIS

use DBI::Const::GetInfoType;

DESCRIPCIÓN

Importa un hash %GetInfoType que mapea los nombres de los códigos de tipo GetInfo a sus valores numéricos correspondientes. Por ejemplo:

$version_base_datos = $dbh->get_info( $GetInfoType{SQL_DBMS_VER} );

La interfaz de este módulo es nueva y nada más allá de lo escrito aquí está garantizado.
