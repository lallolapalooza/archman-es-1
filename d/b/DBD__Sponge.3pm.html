DBD::Sponge(3) Documentación de Perl contribuida por el usuario DBD::Sponge(3)

NOMBRE

DBD::Sponge - Crear un manejador de sentencias DBI a partir de datos de Perl

SINOPSIS

my $sponge = DBI->connect("dbi:Sponge:","","",{ RaiseError => 1 });
my $sth = $sponge->prepare($statement, {
        rows => $data,
        NAME => $names,
        %attr
    }
);

DESCRIPCIÓN

DBD::Sponge es útil para hacer que una estructura de datos de Perl sea accesible a través de un manejador de sentencias DBI estándar. Esto puede ser útil para los autores de módulos DBD que necesiten transformar datos de esta manera.

MÉTODOS

connect()

my $sponge = DBI->connect("dbi:Sponge:","","",{ RaiseError => 1 });

Aquí hay una sintaxis de ejemplo para crear un manejador de base de datos para el controlador Sponge. No se necesitan nombre de usuario ni contraseña.

prepare()

my $sth = $sponge->prepare($statement, {
        rows => $data,
        NAME => $names,
        %attr
    }
);
  • El $statement aquí es una sentencia arbitraria o un nombre que desea proporcionar como identidad de sus datos. Si está utilizando DBI::Profile, aparecerá en los datos del perfil.

    En general, se espera que esté preparando un manejador de sentencias como si se hubiera ejecutado una sentencia de tipo "select".

  • $data es una referencia a los datos que está proporcionando, dada como un array de arrays.
  • $names es una referencia a un array de nombres de columnas para los $data que está proporcionando. El número y el orden deben coincidir con el número y el orden de las columnas de los $data.
  • %attr es un hash de otros atributos DBI estándar que podría pasar a una sentencia prepare.

    Actualmente, solo se admiten NAME, TYPE y PRECISION.

ERRORES

El uso de este módulo para preparar sentencias tipo INSERT no está documentado actualmente.
