Documentación de Función/Subrutina

subroutine dbdt01 (integer m, integer n, integer kd, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldpt, * ) pt, integer ldpt, double precision, dimension( * ) work, double precision resid)

DBDT01

Propósito:

!>
!> DBDT01 reconstruye una matriz general A a partir de su forma bidiagonal
!>    A = Q * B * P**T
!> donde Q (m por min(m,n)) y P**T (min(m,n) por n) son matrices ortogonales
!> y B es bidiagonal.
!>
!> La relación de prueba para verificar la reducción es
!>    RESID = norm(A - Q * B * P**T) / ( n * norm(A) * EPS )
!> donde EPS es la precisión de la máquina.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de las matrices A y Q.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y P**T.
!>

KD

!>          KD es INTEGER
!>          Si KD = 0, B es diagonal y el array E no se referencia.
!>          Si KD = 1, la reducción fue realizada por xGEBRD; B es
!>          bidiagonal superior si M >= N, y bidiagonal inferior si M < N.
!>          Si KD = -1, la reducción fue realizada por xGBBRD; B es
!>          siempre bidiagonal superior.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

Q

!>          Q es un array DOUBLE PRECISION, de dimensión (LDQ,N)
!>          La matriz ortogonal m por min(m,n) Q en la reducción
!>          A = Q * B * P**T.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,M).
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (min(M,N))
!>          Los elementos diagonales de la matriz bidiagonal B.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (min(M,N)-1)
!>          Los elementos superdiagonales de la matriz bidiagonal B si
!>          m >= n, o los elementos subdiagonales de B si m < n.
!>

PT

!>          PT es un array DOUBLE PRECISION, de dimensión (LDPT,N)
!>          La matriz ortogonal min(m,n) por n P**T en la reducción
!>          A = Q * B * P**T.
!>

LDPT

!>          LDPT es INTEGER
!>          La dimensión principal del array PT.
!>          LDPT >= max(1,min(M,N)).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (M+N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          La relación de prueba:
!>          norm(A - Q * B * P**T) / ( n * norm(A) * EPS )
!>
