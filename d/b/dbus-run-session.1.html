DBUS-RUN-SESSION(1) Comandos de usuario DBUS-RUN-SESSION(1)

NOMBRE

dbus-run-session - iniciar un proceso como una nueva sesión D-Bus

SINOPSIS

dbus-run-session [--config-file NOMBRE_ARCHIVO] [--dbus-daemon BINARIO] [--] PROGRAMA [ARGUMENTOS...]

dbus-run-session --help

dbus-run-session --version

DESCRIPCIÓN

dbus-run-session se utiliza para iniciar una instancia de bus de sesión de dbus-daemon desde un script de shell, e iniciar un programa especificado en esa sesión. El dbus-daemon se ejecutará mientras lo haga el programa, después de lo cual terminará.

Un uso es ejecutar un shell con su propio dbus-daemon en una sesión de modo texto o SSH, y hacer que el dbus-daemon termine automáticamente al salir del sub-shell, de la siguiente manera:

dbus-run-session -- bash

o para reemplazar completamente el shell de inicio de sesión, combinando dbus-run-session con el comando interno exec:

exec dbus-run-session -- bash

Otro uso es ejecutar pruebas de regresión y cosas similares en una sesión D-Bus aislada, para evitar interferir con la sesión D-Bus "real" o depender de que ya haya una sesión D-Bus activa, por ejemplo:

dbus-run-session -- make check

o (en automake(1)):

  AM_TESTS_ENVIRONMENT = export MY_DEBUG=all;
  LOG_COMPILER = dbus-run-session
  AM_LOG_FLAGS = --

OPCIONES

--config-file=NOMBRE_ARCHIVO, --config-file NOMBRE_ARCHIVO

Pasa --config-file=NOMBRE_ARCHIVO al bus daemon, en lugar de pasarle el argumento --session. Ver dbus-daemon(1).

--dbus-daemon=BINARIO, --dbus-daemon BINARIO

Ejecuta BINARIO como dbus-daemon(1), en lugar de buscar en el PATH de la forma habitual un ejecutable llamado dbus-daemon.

--help

Imprime la información de uso y sale.

--version

Imprime la versión de dbus-run-session y sale.

ESTADO DE SALIDA

dbus-run-session sale con el estado de salida de PROGRAMA, 0 si se usaron las opciones --help o --version, 127 en caso de un error dentro de dbus-run-session, o 128+n si el PROGRAMA fue terminado por la señal n.

ENTORNO

Se busca en el PATH para encontrar PROGRAMA, y (si la opción --dbus-daemon no se usa o su argumento no contiene un carácter /) para encontrar dbus-daemon.

La dirección del bus de sesión se pone a disposición de PROGRAMA en la variable de entorno DBUS_SESSION_BUS_ADDRESS.

Las variables DBUS_SESSION_BUS_PID, DBUS_SESSION_BUS_WINDOWID, DBUS_STARTER_BUS_TYPE y DBUS_STARTER_ADDRESS se eliminan del entorno, si están presentes.

ERRORES

Por favor, envíe informes de errores a la lista de correo o al rastreador de errores de D-Bus, ver https://www.freedesktop.org/wiki/Software/dbus/

AUTOR

Ver https://dbus.freedesktop.org/doc/AUTHORS

VER TAMBIÉN
