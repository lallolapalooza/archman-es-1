subrutina dbdsdc (uplo, compq, n, d, e, u, ldu, vt, ldvt, q, iq, work, iwork, info)
DBDSDC

Documentación de Función/Subrutin

a

subrutina dbdsdc (character uplo, character compq, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( * ) q, integer, dimension( * ) iq, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer

info)

DBDSD

C

Propósito

: 
!>
!> DBDSDC calcula la descomposición en valores singulares (SVD) de una matriz
!> real N-por-N (superior o inferior) bidiagonal B:  B = U * S * VT,
!> usando un método de división y conquista, donde S es una matriz diagonal
!> con elementos diagonales no negativos (los valores singulares de B), y
!> U y VT son matrices ortogonales de vectores singulares izquierdos y derechos,
!> respectivamente. DBDSDC puede usarse para calcular todos los valores singulares,
!> y opcionalmente, vectores singulares o vectores singulares en forma compacta.
!>
!> El código actualmente llama a DLASDQ si solo se desean valores singulares.
!> Sin embargo, puede modificarse ligeramente para calcular valores singulares
!> usando el método de división y conquista.
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  B es bidiagonal superior.
!>          = 'L':  B es bidiagonal inferior.
!
>

COMP

Q 
!>          COMPQ es CHARACTER*1
!>          Especifica si los vectores singulares deben calcularse
!>          de la siguiente manera:
!>          = 'N':  Calcular solo valores singulares;
!>          = 'P':  Calcular valores singulares y calcular vectores
!>                  singulares en forma compacta;
!>          = 'I':  Calcular valores singulares y vectores singulares.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz B.  N >= 0.
!
>

D 
!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Al entrar, los n elementos diagonales de la matriz bidiagonal B.
!>          Al salir, si INFO=0, los valores singulares de B.
!
>

E 
!>          E es un array DOUBLE PRECISION, dimensión (N-1)
!>          Al entrar, los elementos de E contienen los elementos
!>          fuera de la diagonal de la matriz bidiagonal cuya SVD se desea.
!>          Al salir, E ha sido destruido.
!
>

U 
!>          U es un array DOUBLE PRECISION, dimensión (LDU,N)
!>          Si  COMPQ = 'I', entonces:
!>             Al salir, si INFO = 0, U contiene los vectores singulares izquierdos
!>             de la matriz bidiagonal.
!>          Para otros valores de COMPQ, U no se referencia.
!
>

LD

U 
!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1.
!>          Si se desean vectores singulares, entonces LDU >= max( 1, N ).
!
>

V

T 
!>          VT es un array DOUBLE PRECISION, dimensión (LDVT,N)
!>          Si  COMPQ = 'I', entonces:
!>             Al salir, si INFO = 0, VT**T contiene los vectores singulares
!>             derechos de la matriz bidiagonal.
!>          Para otros valores de COMPQ, VT no se referencia.
!
>

LDV

T 
!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1.
!>          Si se desean vectores singulares, entonces LDVT >= max( 1, N ).
!
>

Q 
!>          Q es un array DOUBLE PRECISION, dimensión (LDQ)
!>          Si  COMPQ = 'P', entonces:
!>             Al salir, si INFO = 0, Q e IQ contienen los vectores
!>             singulares izquierdos y derechos en una forma compacta,
!>             requiriendo O(N log N) de espacio en lugar de 2*N**2.
!>             En particular, Q contiene todos los datos DOUBLE PRECISION en
!>             LDQ >= N*(11 + 2*SMLSIZ + 8*INT(LOG_2(N/(SMLSIZ+1))))
!>             palabras de memoria, donde SMLSIZ es devuelto por ILAENV y
!>             es igual al tamaño máximo de los subproblemas en la
!>             parte inferior del árbol de cálculo (usualmente alrededor de 25).
!>          Para otros valores de COMPQ, Q no se referencia.
!
>

I

Q 
!>          IQ es un array INTEGER, dimensión (LDIQ)
!>          Si  COMPQ = 'P', entonces:
!>             Al salir, si INFO = 0, Q e IQ contienen los vectores
!>             singulares izquierdos y derechos en una forma compacta,
!>             requiriendo O(N log N) de espacio en lugar de 2*N**2.
!>             En particular, IQ contiene todos los datos INTEGER en
!>             LDIQ >= N*(3 + 3*INT(LOG_2(N/(SMLSIZ+1))))
!>             palabras de memoria, donde SMLSIZ es devuelto por ILAENV y
!>             es igual al tamaño máximo de los subproblemas en la
!>             parte inferior del árbol de cálculo (usualmente alrededor de 25).
!>          Para otros valores de COMPQ, IQ no se referencia.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          Si COMPQ = 'N' entonces LWORK >= (4 * N).
!>          Si COMPQ = 'P' entonces LWORK >= (6 * N).
!>          Si COMPQ = 'I' entonces LWORK >= (3 * N**2 + 4 * N).
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (8*N)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo falló al calcular un valor singular.
!>                El proceso de actualización de división y conquista falló.
!
>
