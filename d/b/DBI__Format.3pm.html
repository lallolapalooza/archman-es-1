NOMBRE

DBI::Format - Un paquete para mostrar tablas de resultados

SINOPSIS

# crear un nuevo objeto de resultado
$r = DBI::Format->new('var1' => 'val1', ...);
# Prepararlo para la salida creando una cabecera
$r->header($sth, $fh);
# En un bucle, mostrar filas
while ($ref = $sth->fetchrow_arrayref()) {
  $r->row($ref);
}
# Finalmente crear un pie de página
$r->trailer();

DESCRIPCIÓN

ESTE PAQUETE AÚN ES MUY EXPERIMENTAL. LAS COSAS CAMBIARÁN.

Este paquete se utiliza para hacer configurable la salida de DBI::Shell. La idea es derivar una subclase para cualquier tipo de tabla de salida que pueda crear. Ejemplos son:

  • un formato de salida muy simple como el ofrecido por DBI::neat_list(). "SUBCLASES DISPONIBLES".
  • un formato de caja, como el ofrecido por el módulo Data::ShowTable.
  • formato HTML, como el utilizado en binarios CGI
  • postscript, para ser enviado a lpr o algo similar

En el futuro, el paquete también debería admitir métodos interactivos, por ejemplo, autocompletado.

Estos son los métodos disponibles:

new(@attr)
new(\%attr)
(Método de clase) Este es el constructor. Es mejor llamar a un constructor de subclase. El constructor acepta una lista de pares clave/valor o una referencia a hash.
header($sth, $fh)
(Método de instancia) Se llama cuando se debe crear una nueva tabla de resultados para mostrar los resultados del manejador de sentencias $sth. El argumento (opcional) $fh es un manejador de IO (o cualquier objeto que soporte un método de print), normalmente se usa un objeto IO::Wrap para STDIN.

El método consultará a $sth por sus atributos NAME, NUM_OF_FIELDS, TYPE, SCALE y PRECISION y típicamente imprimirá una cabecera. En general, no debe asumir que $sth es realmente un manejador de sentencias DBI y es mejor tratarlo como una referencia a hash con los atributos mencionados.

row($ref)
(Método de instancia) Imprime el contenido de la referencia de array $ref. Normalmente se obtiene esta referencia de array llamando a $sth->fetchrow_arrayref().
trailer
(Método de instancia) Una vez que haya pasado todas las filas de resultado al paquete de resultados, debe llamar al método trailer. Este método puede, por ejemplo, imprimir el número de filas de resultado.

SUBCLASES DISPONIBLES

En primer lugar, puede utilizar el propio paquete DBI::Format: no es una clase base abstracta, sino un valor predeterminado muy simple que utiliza DBI::neat_list().

Cajas ASCII

Esta subclase utiliza internamente el modo Box del módulo Data::ShowTable. Data::ShowTable(3).

Crudo

La fila se escribe sin formato. Las columnas devueltas en una lista separada por comas o por un separador definido por el usuario.

Cadena

La fila se escribe utilizando un formato de cadena. Las versiones futuras incluirán la capacidad de establecer el formato de cadena.
