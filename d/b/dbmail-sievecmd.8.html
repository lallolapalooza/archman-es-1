NOMBRE

dbmail-sievecmd - manipula scripts Sieve en DBMail.

SINOPSIS

dbmail-sievecmd [opciones comunes] -u nombredeusuario --list
dbmail-sievecmd [opciones comunes] -u nombredeusuario --activate nombrede script
dbmail-sievecmd [opciones comunes] -u nombredeusuario --deactivate nombrede script
dbmail-sievecmd [opciones comunes] -u nombredeusuario --show nombrede script
dbmail-sievecmd [opciones comunes] -u nombredeusuario --import archivo
dbmail-sievecmd [opciones comunes] -u nombredeusuario --edit nombrede script
dbmail-sievecmd [opciones comunes] -u nombredeusuario --remove nombrede script

DESCRIPCIÓN

DBMail almacena scripts Sieve en DBMail. Estos scripts se utilizan para clasificar el correo entrante para los usuarios de correo electrónico. Cada usuario tiene su propio espacio de scripts y puede cargar scripts al demonio dbmail-sieved(8). La utilidad dbmail-sievecmd(8) proporciona un método conveniente para que el administrador del sistema trabaje con scripts Sieve desde la línea de comandos.

OPCIONES

-u, --user nombredeusuario

Especifica el usuario cuyos scripts vamos a modificar.

-l, --list

Lista los scripts pertenecientes al usuario.

-a, --activate nombrede script

Activa nombrede script, desactivando todos los demás scripts.

-d, --deactivate nombrede script

Desactiva nombrede script si estaba activo.

-c, --show nombrede script

Muestra el script nombrado.

-i, --import scriptname < archivo

Crea un script llamado nombrede script importando archivo.

-e, --edit nombrede script

Edita el contenido del script nombrado.

(Si no se proporciona ningún script, se muestra el script activo)

-r, --remove nombrede script

Elimina el script nombrado. Si el script estaba activo, no habrá ningún script activo después de su eliminación.

OPCIONES COMUNES

-f, --config archivo de configuración

Especifica un archivo de configuración alternativo.

Utilice dbmail-<utilidad> --help para mostrar la ubicación predeterminada.

-q, --quiet

Omite silenciosamente las preguntas interactivas y los mensajes de estado útiles que de otro modo se imprimirían en stdout. Use dos -q para silenciar los errores que de otro modo se imprimirían en stderr.

-v, --verbose

Opera de forma verbosa. Algunas de las utilidades del conjunto DBMail pueden aceptar dos -v para una verbosidad adicional. Aquellas que no entienden esta convención no se quejarán de tener la -v adicional y simplemente operarán con su verbosidad normal.

-V, --version

Muestra la versión y los derechos de autor, y luego sale.

-h, --help

Muestra un breve resumen de las opciones y luego sale.
