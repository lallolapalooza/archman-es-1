NOMBRE

DBD::SQLite::Cookbook - El libro de cocina de DBD::SQLite

DESCRIPCIÓN

Este es el libro de cocina de DBD::SQLite.

Está destinado a proporcionar un lugar para mantener una variedad de funciones y formatos para su uso en API de callback en DBD::SQLite.

FUNCIONES DE AGREGACIÓN

Varianza

Esta es una función de agregación simple que devuelve una varianza. Se adapta de una implementación de ejemplo en pysqlite.

package variance;

sub new { bless [], shift; }

sub step {
    my ( $self, $value ) = @_;

    push @$self, $value;
}

sub finalize {
    my $self = $_[0];

    my $n = @$self;

    # La varianza es NULL a menos que haya más de una fila
    return undef unless $n || $n == 1;

    my $mu = 0;
    foreach my $v ( @$self ) {
        $mu += $v;
    }
    $mu /= $n;

    my $sigma = 0;
    foreach my $v ( @$self ) {
        $sigma += ($v - $mu)**2;
    }
    $sigma = $sigma / ($n - 1);

    return $sigma;
}

# NOTA: Si usas una versión anterior de DBI (< 1.608),
# usa $dbh->func(..., "create_aggregate") en su lugar.
$dbh->sqlite_create_aggregate( "variance", 1, 'variance' );

Luego, la función se puede usar así:

SELECT group_name, variance(score)
FROM results
GROUP BY group_name;

Varianza (Eficiente en memoria)

Una función de varianza más eficiente, optimizada para el uso de memoria a expensas de la precisión:

package variance2;

sub new { bless {sum => 0, count=>0, hash=> {} }, shift; }

sub step {
    my ( $self, $value ) = @_;
    my $hash = $self->{hash};

    # al truncar y hashear, podemos consumir muchos más puntos de datos
    $value = int($value); # cambia según la necesidad de precisión
                          # usa sprintf para precisión arbitraria de punto flotante
    if (exists $hash->{$value}) {
        $hash->{$value}++;
    } else {
        $hash->{$value} = 1;
    }
    $self->{sum} += $value;
    $self->{count}++;
}

sub finalize {
    my $self = $_[0];

    # La varianza es NULL a menos que haya más de una fila
    return undef unless $self->{count} > 1;

    # calcular promedio
    my $mu = $self->{sum} / $self->{count};

    my $sigma = 0;
    while (my ($h, $v) = each %{$self->{hash}}) {
        $sigma += (($h - $mu)**2) * $v;
    }
    $sigma = $sigma / ($self->{count} - 1);

    return $sigma;
}

Luego, la función se puede usar así:

SELECT group_name, variance2(score)
FROM results
GROUP BY group_name;

Varianza (Altamente escalable)

Una tercera implementación de varianza, diseñada para conjuntos de datos arbitrariamente grandes:

package variance3;

sub new { bless {mu=>0, count=>0, S=>0}, shift; }

sub step {
    my ( $self, $value ) = @_;
    $self->{count}++;
    my $delta = $value - $self->{mu};
    $self->{mu} += $delta/$self->{count};
    $self->{S} += $delta*($value - $self->{mu});
}

sub finalize {
    my $self = $_[0];
    return $self->{S} / ($self->{count} - 1);
}

Luego, la función se puede usar así:

SELECT group_name, variance3(score)
FROM results
GROUP BY group_name;
