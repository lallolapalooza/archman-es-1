NOMBRE

dblink_error_message - obtiene el último mensaje de error en la conexión nombrada

SINOPSIS

dblink_error_message(text connname) returns text

DESCRIPCIÓN

dblink_error_message recupera el mensaje de error remoto más reciente para una conexión dada.

ARGUMENTOS

connname

Nombre de la conexión a utilizar.

VALOR DE RETORNO

Devuelve el último mensaje de error, o OK si no ha habido ningún error en esta conexión.

NOTAS

Cuando se inician consultas asíncronas mediante dblink_send_query, el mensaje de error asociado con la conexión podría no actualizarse hasta que se consuma el mensaje de respuesta del servidor. Esto generalmente significa que dblink_is_busy o dblink_get_result deberían llamarse antes que dblink_error_message, para que cualquier error generado por la consulta asíncrona sea visible.

EJEMPLOS

SELECT dblink_error_message('dtest1');
