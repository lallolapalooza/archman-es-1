DBBCS

D

Propósito

: 
!>
!> DBBCSD calcula la descomposición CS de una matriz ortogonal en
!> forma de bloques bidiagonales,
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**T
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X es de M por M, su bloque superior izquierdo es de P por Q, y Q no debe ser mayor
!> que P, M-P, o M-Q. (Si Q no es el índice más pequeño, entonces X debe ser
!> transpuesta y/o permutada. Esto se puede hacer en tiempo constante usando las
!> opciones TRANS y SIGNS. Consulte DORCSD para más detalles.)
!>
!> Las matrices bidiagonales B11, B12, B21 y B22 se representan
!> implícitamente por los ángulos THETA(1:Q) y PHI(1:Q-1).
!>
!> Las matrices ortogonales U1, U2, V1T y V2T son de entrada/salida.
!> Las matrices de entrada se pre- o post-multiplican por las matrices
!> de vectores singulares correspondientes.
!
>

Parámetro

s
JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      U1 se actualiza;
!>          de lo contrario:  U1 no se actualiza.
!
>

JOBU

2 
!>          JOBU2 es CHARACTER
!>          = 'Y':      U2 se actualiza;
!>          de lo contrario:  U2 no se actualiza.
!
>

JOBV1

T 
!>          JOBV1T es CHARACTER
!>          = 'Y':      V1T se actualiza;
!>          de lo contrario:  V1T no se actualiza.
!
>

JOBV2

T 
!>          JOBV2T es CHARACTER
!>          = 'Y':      V2T se actualiza;
!>          de lo contrario:  V2T no se actualiza.
!
>

TRAN

S 
!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden
!>                      de filas (row-major);
!>          de lo contrario:  X, U1, U2, V1T y V2T se almacenan en orden
!>                      de columnas (column-major).
!
>

M 
!>          M es INTEGER
!>          El número de filas y columnas en X, la matriz ortogonal en
!>          forma de bloques bidiagonales.
!
>

P 
!>          P es INTEGER
!>          El número de filas en el bloque superior izquierdo de X. 0 <= P <= M.
!
>

Q 
!>          Q es INTEGER
!>          El número de columnas en el bloque superior izquierdo de X.
!>          0 <= Q <= MIN(P,M-P,M-Q).
!
>

THET

A 
!>          THETA es un array DOUBLE PRECISION, dimensión (Q)
!>          A la entrada, los ángulos THETA(1),...,THETA(Q) que, junto con
!>          PHI(1), ...,PHI(Q-1), definen la matriz en forma de bloques
!>          bidiagonales. A la salida, los ángulos cuyos cosenos y senos definen los
!>          bloques diagonales en la descomposición CS.
!
>

PH

I 
!>          PHI es un array DOUBLE PRECISION, dimensión (Q-1)
!>          Los ángulos PHI(1),...,PHI(Q-1) que, junto con THETA(1),...,
!>          THETA(Q), definen la matriz en forma de bloques bidiagonales.
!
>

U

1 
!>          U1 es un array DOUBLE PRECISION, dimensión (LDU1,P)
!>          A la entrada, una matriz de P por P. A la salida, U1 se post-multiplica
!>          por la matriz de vectores singulares izquierdos común a [ B11 ; 0 ] y
!>          [ B12 0 0 ; 0 -I 0 0 ].
!
>

LDU

1 
!>          LDU1 es INTEGER
!>          La dimensión principal del array U1, LDU1 >= MAX(1,P).
!
>

U

2 
!>          U2 es un array DOUBLE PRECISION, dimensión (LDU2,M-P)
!>          A la entrada, una matriz de (M-P) por (M-P). A la salida, U2 se
!>          post-multiplica por la matriz de vectores singulares izquierdos común a
!>          [ B21 ; 0 ] y [ B22 0 0 ; 0 0 I ].
!
>

LDU

2 
!>          LDU2 es INTEGER
!>          La dimensión principal del array U2, LDU2 >= MAX(1,M-P).
!
>

V1

T 
!>          V1T es un array DOUBLE PRECISION, dimensión (LDV1T,Q)
!>          A la entrada, una matriz de Q por Q. A la salida, V1T se pre-multiplica
!>          por la transpuesta de la matriz de vectores singulares
!>          derechos común a [ B11 ; 0 ] y [ B21 ; 0 ].
!
>

LDV1

T 
!>          LDV1T es INTEGER
!>          La dimensión principal del array V1T, LDV1T >= MAX(1,Q).
!
>

V2

T 
!>          V2T es un array DOUBLE PRECISION, dimensión (LDV2T,M-Q)
!>          A la entrada, una matriz de (M-Q) por (M-Q). A la salida, V2T se
!>          pre-multiplica por la transpuesta de la matriz de vectores
!>          singulares derechos común a [ B12 0 0 ; 0 -I 0 ] y
!>          [ B22 0 0 ; 0 0 I ].
!
>

LDV2

T 
!>          LDV2T es INTEGER
!>          La dimensión principal del array V2T, LDV2T >= MAX(1,M-Q).
!
>

B11

D 
!>          B11D es un array DOUBLE PRECISION, dimensión (Q)
!>          Cuando DBBCSD converge, B11D contiene los cosenos de THETA(1),
!>          ..., THETA(Q). Si DBBCSD no converge, entonces B11D
!>          contiene la diagonal del bloque superior izquierdo parcialmente
!>          reducido.
!
>

B11

E 
!>          B11E es un array DOUBLE PRECISION, dimensión (Q-1)
!>          Cuando DBBCSD converge, B11E contiene ceros. Si DBBCSD no
!>          converge, entonces B11E contiene la superdiagonal del
!>          bloque superior izquierdo parcialmente reducido.
!
>

B12

D 
!>          B12D es un array DOUBLE PRECISION, dimensión (Q)
!>          Cuando DBBCSD converge, B12D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si DBBCSD no converge, entonces
!>          B12D contiene la diagonal del bloque superior derecho
!>          parcialmente reducido.
!
>

B12

E 
!>gt;          B12E es un array DOUBLE PRECISION, dimensión (Q-1)
!>          Cuando DBBCSD converge, B12E contiene ceros. Si DBBCSD no
!>          converge, entonces B12E contiene la subdiagonal del
!>          bloque superior-derecho parcialmente reducido.
!
>

B21

D 
!>          B21D es un array DOUBLE PRECISION, dimensión (Q)
!>          Cuando DBBCSD converge, B21D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si DBBCSD no converge, entonces
!>          B21D contiene la diagonal del bloque inferior-izquierdo
!>          parcialmente reducido.
!
>

B21

E 
!>          B21E es un array DOUBLE PRECISION, dimensión (Q-1)
!>          Cuando DBBCSD converge, B21E contiene ceros. Si DBBCSD no
!>          converge, entonces B21E contiene la subdiagonal del
!>          bloque inferior-izquierdo parcialmente reducido.
!
>

B22

D 
!>          B22D es un array DOUBLE PRECISION, dimensión (Q)
!>          Cuando DBBCSD converge, B22D contiene los senos negativos de
!>          THETA(1), ..., THETA(Q). Si DBBCSD no converge, entonces
!>          B22D contiene la diagonal del bloque inferior-derecho
!>          parcialmente reducido.
!
>

B22

E 
!>          B22E es un array DOUBLE PRECISION, dimensión (Q-1)
!>          Cuando DBBCSD converge, B22E contiene ceros. Si DBBCSD no
!>          converge, entonces B22E contiene la subdiagonal del
!>          bloque inferior-derecho parcialmente reducido.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= MAX(1,8*Q).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array de trabajo, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si DBBCSD no convergió, INFO especifica el número
!>                de entradas distintas de cero en PHI, y B11D, B11E, etc.,
!>                contienen la matriz parcialmente reducida.
!
>

Parámetros

internos: 
!>  TOLMUL  DOUBLE PRECISION, por defecto = MAX(10,MIN(100,EPS**(-1/8)))
!>          TOLMUL controla el criterio de convergencia del bucle QR.
!>          Los ángulos THETA(i), PHI(i) se redondean a 0 o PI/2 cuando
!>          están dentro de TOLMUL*EPS de cualquiera de los límites.
!
>
