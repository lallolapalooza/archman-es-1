NOMBRE

dbmail-users - gestiona la base de datos de usuarios de DBMail.

SINOPSIS

dbmail-users [MODO] [OPCIONES DE MODO]
dbmail-users --add-user usuario [opciones]
dbmail-users --change-user usuario [opciones]
dbmail-users --delete-user usuario
dbmail-users --empty-user-mailboxes usuario [opciones]
dbmail-users --list-users
dbmail-users --list-user usuario
dbmail-users --change-user usuario --password contraseña --pw-type tipoc
dbmail-users --change-user usuario --add-alias dirección
dbmail-users --change-user usuario --delete-alias dirección
dbmail-users --forward dirección --add-forward dirección
dbmail-users --forward dirección --delete-forward dirección

DESCRIPCIÓN

El programa dbmail-users te permite gestionar los usuarios de DBMail. Te permite añadir, eliminar y modificar usuarios, así como mostrar información sobre un usuario específico o mostrar una lista de usuarios existentes. También tiene la capacidad de añadir/eliminar alias separados.

MODO

-a, --add-user usuario

Añadir un usuario

-c, --change-user usuario

Cambiar detalles de un usuario

-d, --delete-user usuario

Eliminar un usuario

-e, --empty-user-mailboxes usuario

Vaciar todas las bandejas de correo de un usuario

-L, --list-users

Listar información de todos los usuarios

-l, --list-user usuariospec

Listar información de usuarios coincidentes

-x, --forward alias

Crear una dirección de reenvío externa

OPCIONES DE MODO

--enable

habilitar autenticación para el usuario

--disable

deshabilitar autenticación para el usuario

-w --password

Especificar la contraseña del usuario en la línea de comandos.

Usar con --change-user

-W, --pw-file archivo

Leer desde un archivo o solicitar la contraseña de un usuario.+ Usar con --add-user y --change-user

-p, --pw-type tipo

El tipo de contraseña puede ser uno de los siguientes: plaintext, crypt, md5-hash, md5-digest, crypt-raw, md5-hash-raw, md5-digest-raw, md5-base64, md5-base64-raw, whirlpool, sha512, sha256, sha1, tiger.

Usar con --add-user y --change-user

-P, --pw-shadow archivo

Obtener la contraseña cifrada del archivo shadow.

Usar con --add-user y --change-user

-u, --user usuario

Nuevo nombre de usuario

Usar con --change-user para cambiar el nombre de usuario

-g, --client cid

Asignar el usuario a un cliente.

Usar con --add-user y --change-user

-m, --max-quota max

Establecer la cuota máxima de correo en <bytes>B, <kbytes>K, o <mbytes>M, por defecto en bytes. Si se establece en 0, no habrá límite.

Usar con --add-user y --change-user

-s, --add-alias alias[,alias...]

Añade una lista de alias de destinatario. Un alias es una dirección de correo electrónico que se entrega al sistema de correo DBMail y debe ser entregada a este usuario.

Usar con --add-user y --change-user

-S, --delete-alias alias[,alias...]

Elimina una lista de alias de destinatario. Usa los comodines ? y * para coincidir con cualquier carácter individual y cualquier número de caracteres, respectivamente.

Usar con --add-user y --change-user

-t, --add-forward reenvío[,reenvío...]

Añade una lista de reenvíos de entrega.

Usar con --forward

-T, --delete-forward reenvío[,reenvío...]

Elimina una lista de reenvíos de entrega. Usa los comodines ? y * para coincidir con cualquier carácter individual y cualquier número de caracteres, respectivamente.

Usar con --forward

--security-password

especificar una contraseña de respaldo de seguridad separada

--security-action

seleccionar el valor de la acción de seguridad (por defecto 0)

OPCIONES COMUNES

-f, --config archivo de config

Especificar un archivo de configuración alternativo.

Usa dbmail-<utilidad> --help para mostrar la ubicación predeterminada.

-q, --quiet

Omite silenciosamente las solicitudes interactivas y los mensajes de estado útiles que de otro modo se imprimirían en stdout. Usa dos -q para silenciar errores que de otro modo se imprimirían en stderr.

-v, --verbose

Opera de forma detallada. Algunas de las utilidades del conjunto DBMail pueden tomar dos -v para una verbosidad extra. Aquellas que no entienden esta convención no se quejarán de tener la -v adicional y operarán simplemente a su nivel de verbosidad normal.

-V, --version

Muestra la versión y los derechos de autor, luego sal.

-h, --help

Muestra un breve resumen de las opciones, luego sal.

ALIAS Y REENVÍOS

¿Qué son los alias y los reenvíos y cuál es la diferencia entre ellos?

Los usuarios son conocidos por el mundo exterior por su dirección de correo electrónico. Para evitar confusiones, DBMail utiliza alias para las direcciones de correo electrónico entrantes y reenvíos para las direcciones salientes donde un usuario se ha mudado a otra organización y su correo se reenvía a su nueva dirección.

Los usuarios de DBMail reciben correo utilizando uno o más alias.

Cuando un usuario se muda a otra organización o dominio, se puede reenviar su correo.

ALIAS

Al crear una nueva cuenta de usuario, deberías añadir un alias inicial que entregue a la cuenta de usuario, o hacer que la cuenta tenga el formato de una dirección de correo electrónico completamente cualificada. Por ejemplo, el usuario llamado Baz creado así:

dbmail-users --add-user baz --pw-type crypt --password secret

Después de crear la cuenta, añades un alias:

dbmail-users --change-user baz --add-alias baz@ejemplo.com

Puedes añadir múltiples alias llamando a dbmail-users repetidamente, o llamándolo con una lista de alias separados por comas:

dbmail-users --change-user baz --add-alias baz@ejemplo.com,baz@ejemplo.org

También se admiten tres modos de captura general, para dominios, subdominios y partes locales:

dbmail-users --add-user baz --add-alias @ejemplo.com
dbmail-users --add-user baz --add-alias @.todosubs.ejemplo.com
dbmail-users --add-user baz --add-alias baz@

El primer ejemplo captura el correo dirigido a cualquier usuario @ejemplo.com y lo entrega a la BANDEJA DE ENTRADA de Baz. El segundo ejemplo captura el correo dirigido a cualquier usuario en cualquier subdominio de .todosubs.ejemplo.com (¡no incluyendo el propio todosubs.ejemplo.com!). El tercer ejemplo captura el correo dirigido a baz@ en cualquier dominio.

No hay soporte para entregar a una bandeja de correo particular que no sea BANDEJA DE ENTRADA a través del sistema de alias. Por favor, utiliza un script Sieve para ordenar el correo de esta manera.

REENVÍOS

Los mensajes entrantes dirigidos a direcciones de correo electrónico particulares pueden reenviarse a direcciones de correo electrónico externas, enviarse a un comando (cuando van precedidos por | pipe) o enviarse con una línea From estilo mbox a un comando (cuando van precedidos por ! bang). Por ejemplo:

dbmail-users --forward bar@ejemplo.com --add-alias bar@otro.ejemplo.net
dbmail-users --forward bar@ejemplo.com --add-alias "|/usr/sbin/superspamtrapper"
dbmail-users --forward bar@ejemplo.com --add-alias "!cat > /var/spool/mail/bar/whatever.mbox"

Los reenvíos pueden listarse usando el mismo comando --list que para los usuarios. Por ejemplo, para ver a dónde podría reenviarse la dirección local bar@ejemplo.com, usa lo siguiente:

dbmail-users --list-user bar@ejemplo.com
  reenvío [bar@ejemplo.com] a [bar@ejemplo.net]
  reenvío [bar@ejemplo.com] a [|/usr/sbin/superspamtrapper]
  reenvío [bar@ejemplo.com] a [!cat > /var/spool/mail/bar/whatever.mbox]
