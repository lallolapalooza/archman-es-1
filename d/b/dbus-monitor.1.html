DBUS-MONITOR(1) Comandos de usuario DBUS-MONITOR(1)

NOMBRE

dbus-monitor - sonda de depuración para imprimir mensajes del bus de mensajes

SINOPSIS

dbus-monitor [--system | --session | --address DIRECCIÓN] [--profile | --monitor | --pcap | --binary] [observaciones expresiones]

DESCRIPCIÓN

El comando dbus-monitor se utiliza para monitorizar mensajes que circulan a través de un bus de mensajes D-Bus. Consulte https://www.freedesktop.org/wiki/Software/dbus/ para obtener más información sobre el panorama general.

Existen dos buses de mensajes conocidos: el bus de mensajes a nivel de sistema (instalado en muchos sistemas como el servicio "messagebus") y el bus de mensajes de la sesión de inicio de sesión por usuario (iniciado cada vez que un usuario inicia sesión). Las opciones --system y --session dirigen dbus-monitor para monitorizar los buses del sistema o de la sesión, respectivamente. Si no se especifica ninguna, dbus-monitor monitoriza el bus de la sesión.

dbus-monitor tiene dos modos de salida de texto diferentes: el modo de monitorización de estilo 'clásico' y el modo de perfilado. El formato de perfilado es un formato compacto con una sola línea por mensaje e información de tiempo con resolución de microsegundos. Las opciones --profile y --monitor seleccionan el formato de salida de perfilado y de monitorización, respectivamente.

dbus-monitor también tiene dos modos de salida binaria. El modo binario, seleccionado por --binary, emite todo el flujo de mensajes binarios (sin el apretón de manos de autenticación inicial). El modo PCAP, seleccionado por --pcap, añade una cabecera de archivo PCAP al principio de la salida y antepone una cabecera de mensaje PCAP a cada mensaje; esto produce un archivo binario que puede ser leído por, por ejemplo, Wireshark.

Si no se especifica ningún modo, dbus-monitor utiliza el formato de salida de monitorización.

Para que dbus-monitor pueda ver los mensajes que le interesan, debe especificar un conjunto de expresiones de observación como las que esperaría pasar a la función dbus_bus_add_match.

La configuración del bus de mensajes puede impedir que dbus-monitor vea todos los mensajes, especialmente si ejecuta el monitor como un usuario que no es root.

OPCIONES

--system

Monitoriza el bus de mensajes del sistema.

--session

Monitoriza el bus de mensajes de la sesión. (Este es el valor predeterminado.)

--address DIRECCIÓN

Monitoriza un bus de mensajes arbitrario dado en DIRECCIÓN.

--profile

Utiliza el formato de salida de perfilado.

--monitor

Utiliza el formato de salida de monitorización. (Este es el valor predeterminado.)

EJEMPLO

Aquí tienes un ejemplo de cómo usar dbus-monitor para observar que el monitor de escritura de gnome diga cosas

  dbus-monitor "type='signal',sender='org.gnome.TypingMonitor',interface='org.gnome.TypingMonitor'"
