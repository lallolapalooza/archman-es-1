DBD::MariaDB - controlador de base de datos para Perl

Este es el controlador DBI de Perl para acceder a bases de datos MariaDB y MySQL.

El objetivo de nuestro esfuerzo fue corregir la compatibilidad con MariaDB, el soporte de Unicode en Perl y errores relacionados con la seguridad.

Este controlador DBI de Perl es una bifurcación del controlador DBD::mysql y se creó porque los problemas mencionados en el DBD::mysql original no se habían abordado durante más de un año.

Uso

El uso de este controlador DBI de Perl se describe en DBD::MariaDB.

Instalación

La instalación se describe en DBD::MariaDB::INSTALL.
