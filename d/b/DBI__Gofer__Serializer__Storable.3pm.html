DBI::Gofer::Serializer::Storable(3) Documentación de Perl contribuida por el usuario DBI::Gofer::Serializer::Storable(3)

NOMBRE

DBI::Gofer::Serializer::Storable - Serialización de Gofer usando Storable

SINOPSIS

$serializer = DBI::Gofer::Serializer::Storable->new();
$string = $serializer->serialize( $data );
($string, $deserializer_class) = $serializer->serialize( $data );
$data = $serializer->deserialize( $string );

DESCRIPCIÓN

Usa Storable::nfreeze() para serializar y Storable::thaw() para deserializar.

El método serialize() establece localmente $Storable::forgive_me = 1; para que no falle si encuentra cualquier tipo de dato que no se pueda serializar, como referencias de código.

Ver también DBI::Gofer::Serializer::Base.
