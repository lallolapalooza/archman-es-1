NOMBRE

dnf5-repo - Comando de Repositorios

SINOPSIS

dnf5 repo <subcomando> [opciones] [<espec-repo>...]

DESCRIPCIÓN

El comando repo en DNF5 ofrece varias consultas para obtener información sobre los repositorios configurados en el sistema.

SUBCOMANDOS

list
Lista los repositorios disponibles.
info
Muestra información detallada sobre los repositorios.

OPCIONES

--all
Muestra información sobre todos los repositorios conocidos.
--enabled
Muestra información solo sobre los repositorios habilitados.
Este es el comportamiento por defecto.
--disabled
Muestra información solo sobre los repositorios deshabilitados.

EJEMPLOS

dnf5 repo info --all
Imprime información detallada sobre todos los repositorios conocidos.
dnf5 repo list --disabled *-debuginfo
Imprime los repositorios deshabilitados relacionados con la depuración.
dnf5 config-manager setopt repo_id.enabled=0
Deshabilita permanentemente un repositorio usando el comando del plugin
config-manager. Ver dnf5-config-manager(8) para más detalles.
