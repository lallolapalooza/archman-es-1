NOMBRE

dnf5-versionlock - Comando Versionlock

SINOPSIS

dnf5 versionlock <subcomando> <espec-paquete-N>...

DESCRIPCIÓN

El comando versionlock en DNF5 toma un conjunto de nombres y versiones de paquetes y excluye todas las demás versiones de esos paquetes. Esto te permite proteger los paquetes de ser actualizados por versiones más nuevas. Alternativamente, acepta una versión de paquete específica para excluir de las actualizaciones, por ejemplo, para cuando es necesario omitir una versión específica de un paquete que tiene problemas conocidos.

El plugin recorrerá cada entrada del archivo versionlock y excluirá cualquier paquete del nombre dado que no coincida con las condiciones listadas dentro del archivo. Esto es básicamente lo mismo que usar dnf5 --exclude para el nombre del paquete en sí (ya que no puedes excluir paquetes instalados), pero dnf seguirá viendo las versiones que tienes instaladas/con versionlock como disponibles para que dnf reinstall aún funcione.

Ten en cuenta que el comando versionlock no aplica exclusiones en operaciones no transaccionales como repoquery, list, info, etc.

SUBCOMANDOS

add
Añade un versionlock para todos los paquetes disponibles que coincidan con la especificación. Significa que solo las versiones de los paquetes representados por espec-paquete-N están disponibles para operaciones transaccionales. Las NEVRAs para bloquear se buscan primero entre los paquetes instalados y luego (si no se encuentra ninguna) en todos los paquetes actualmente disponibles.
exclude
Añade una exclusión (dentro de versionlock) para los paquetes disponibles que coincidan con la especificación. Significa que los paquetes representados por espec-paquete-N serán excluidos de las operaciones transaccionales.
clear
Elimina todas las entradas de versionlock.
delete
Elimina cualquier entrada de versionlock que coincida.
list
Lista las entradas actuales de versionlock.

EJEMPLOS

dnf5 versionlock add acpi
Si el paquete acpi está instalado, bloquéalo a la versión actualmente instalada. Si no está instalado, bloquéalo a cualquier versión de las disponibles actualmente.
dnf5 versionlock list
Muestra la configuración actual de versionlock.
dnf5 versionlock delete acpi
Elimina cualquier regla para el paquete acpi.
dnf5 versionlock exclude iftop-1.2.3-7.fc38
Excluye la versión iftop-1.2.3-7.fc38.

FORMATO DEL ARCHIVO VERSIONLOCK

El archivo versionlock es un archivo TOML almacenado en la ubicación /etc/dnf/versionlock.toml. El archivo debe contener la clave version, la versión actualmente soportada es 1.0. Luego contiene packages - una lista de entradas de bloqueo. Cada entrada consta del nombre del paquete y una lista de condiciones. La especificación del nombre del paquete admite el mismo patrón de comodines que el shell. Todas las condiciones deben ser verdaderas para que un paquete coincida (se combinan usando un AND lógico). Todas las entradas se combinan juntas usando una operación OR lógica.

Ejemplo de archivo versionlock

version = "1.0"
# mantener el paquete bash en la versión 0:5.2.15-5.fc39
[[packages]]
name = "bash"               # nombre del paquete
comment = "descripción"     # descripción opcional de la entrada
[[packages.conditions]]     # condiciones para el paquete "bash"
key = "evr"                 # se soportan las claves epoch, evr y arch
comparator = "="            # se soportan los operadores <, <=, =, >=, >, y !=
value = "0:5.2.15-5.fc39"   # patrón a coincidir
# excluir la versión iftop-1.2.3-7.fc38 (dnf5 versionlock exclude iftop-1.2.3-7.fc38)
[[packages]]
name = "iftop"
[[packages.conditions]]
key = "evr"
comparator = "!="
value = "0:1.0-0.31.pre4.fc39"
# mantener el paquete acpi en la versión principal 3
[[packages]]
name = "acpi"
[[packages.conditions]]
key = "evr"
comparator = "<"
value = "4"
[[packages.conditions]]
key = "evr"
comparator = ">="
value = "3"
# mantener todos los paquetes *nvidia* en la versión 3:570.*
[[packages]]
name = "*nvidia*"
[[packages.conditions]]
key = "evr"
comparator = ">="
value = "3:570"
[[packages.conditions]]
key = "evr"
comparator = "<"
value = "3:571"
