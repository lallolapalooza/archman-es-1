NOMBRE

dnf5-copr - Comando Copr

SINOPSIS

dnf5 copr <subcomando> [opciones] [argumentos]

DESCRIPCIÓN

El comando copr en DNF5 se utiliza para gestionar los repositorios de Copr (complementos proporcionados por usuarios/comunidad/terceros) en el sistema local.

SUBCOMANDOS

list
Lista los repositorios de Copr.
enable <especificador-proyecto> [<chroot>]
Descarga la información del repositorio de un servidor Copr y la instala como un archivo /etc/yum.repos.d/*.repo.
disable <especificador-proyecto>
Deshabilita el repositorio Copr especificado (si existe), mantiene el archivo /etc/yum.repos.d/*.repo - solo establece enabled=0.
remove <especificador-proyecto>
Elimina el repositorio Copr especificado del sistema. También elimina el archivo /etc/yum.repos.d/*.repo.
debug
Imprime información útil sobre el sistema para la depuración.

OPCIONES

--hub
Servidor principal de Copr (interfaz web/API). Por defecto es copr.fedorainfracloud.org.

ARGUMENTOS

<especificador-proyecto>
Identificador del proyecto Copr a habilitar. Utiliza el formato PROPIETARIO/PROYECTO o HUB/PROPIETARIO/PROYECTO.

HUB puede ser el nombre del host de la interfaz de Copr (por ejemplo, copr.fedorainfracloud.org) o el atajo (por ejemplo, fedora). Si no se especifica HUB, se utiliza el predeterminado o el especificado con --hub <ARG>.

PROPIETARIO es un nombre de usuario o un @nombre de grupo.

PROYECTO puede ser un nombre de proyecto simple o un "directorio de proyecto" que contenga dos puntos, por ejemplo, proyecto:personalizado:123.

Ejemplo: fedora/@footeam/coolproject.

<chroot>
Chroot especificado en el formato NOMBRE-VERSIÓN-ARQUITECTURA, por ejemplo, fedora-rawhide-ppc64le. Cuando no se especifica, el comando dnf copr intenta detectarlo.

EJEMPLOS

dnf5 copr enable rhscl/perl516 epel-6-x86_64
Habilita el repositorio Copr rhscl/perl516, utilizando el chroot epel-6-x86_64.
dnf5 copr disable rhscl/perl516
Deshabilita el repositorio Copr rhscl/perl516
dnf5 copr list
Lista los repositorios Copr configurados en el sistema.
