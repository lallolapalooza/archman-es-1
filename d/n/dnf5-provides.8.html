NOMBRE

dnf5-provides - Comando de provisión

SINOPSIS

dnf5 provides [opciones globales] <especificación-paquete-PFB>...

DESCRIPCIÓN

El comando provides en DNF5 encuentra los paquetes que proveen la <especificación-paquete-PFB> dada.

EJEMPLOS

dnf5 provides tito
Muestra qué paquetes proveen el comando tito.
dnf5 provides /usr/bin/tito
Muestra qué paquete provee el archivo /usr/bin/tito
dnf5 provides zless
No hay una provisión para zless, pero existe un paquete que contiene zless.
Muestra el paquete que provee el archivo /usr/bin/zless

Nota:

Nuevo comportamiento: si uno o más paquetes no se encuentran, DNF5 ahora devolverá el código de salida 1 y listará todas las provisiones que no coinciden al final de la salida.
dnf5 provides rpm paquete_inexistente
Muestra las provisiones para rpm e informa en stderr que paquete_inexistente
no coincidió con ningún resultado.
