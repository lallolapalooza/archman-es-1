NOMBRE

dnf5-history - Comando de historial

SINOPSIS

dnf5 history <subcomando> [opciones] [<especificación-de-transacción>]

DESCRIPCIÓN

El comando history en DNF5 permite al usuario ver qué ha sucedido en transacciones anteriores y ofrece varias operaciones sobre estas transacciones, como deshacerlas y rehacerlas. Para poder usar las transacciones en estos comandos, se asume que se registraron mientras se usaba la opción de configuración history_record .

Para más información sobre <especificación-de-transacción> véase dnf5-specs(7), Especificación de patrones <#transaction-spec-label>.

SUBCOMANDOS

list
Lista información sobre las transacciones registradas en el sistema.
Si no se especifica <especificación-de-transacción> se usan todas las transacciones.
info
Imprime detalles sobre transacciones específicas.
Si no se especifica <especificación-de-transacción> se usa la última transacción.
undo
Revierte todas las acciones de la transacción especificada.
Se debe especificar exactamente una transacción mediante <especificación-de-transacción>.
redo
Repite la transacción especificada.
Usa automáticamente --ignore-extras y --ignore-installed.
A diferencia del resto de comandos de historial, sobrescribe los motivos de los paquetes de la transacción que ya están instalados.
Este comando es útil para finalizar transacciones interrumpidas.
Se debe especificar exactamente una transacción mediante <especificación-de-transacción>.
rollback
Deshace todas las transacciones realizadas después de la transacción especificada.
Se debe especificar exactamente una transacción mediante <especificación-de-transacción>.
store
Almacena la transacción en un directorio.
Si no se especifica <especificación-de-transacción> se usa la última transacción.

OPCIONES PARA LIST E INFO

--reverse
Invierte el orden de las transacciones en la salida.
--contains-pkgs=NOMBRE_DE_PAQUETE,...
Muestra solo las transacciones que contienen paquetes con los nombres especificados.
Esta es una opción de lista. Se admiten comodines.

OPCIONES PARA UNDO, ROLLBACK Y REDO

--skip-unavailable
Permite omitir acciones sobre paquetes que no es posible realizar.
--offline
Almacena la transacción para realizarla sin conexión. Véase el comando offline <#offline-command-ref-label>, dnf5-offline(8).
--store=RUTA
Almacena la transacción actual en un directorio en la RUTA especificada en lugar de ejecutarla.
La transacción almacenada puede realizarse con el comando replay <#replay-command-ref-label>, dnf5-replay(8).

OPCIONES PARA UNDO Y ROLLBACK

--ignore-extras
No considera como errores los paquetes extra incorporados a la transacción.
Aun así se informará de ellos como advertencias.
--ignore-installed
No considera como errores las discrepancias entre los paquetes instalados y los de la transacción almacenada.
Aun así se informará de ellos como advertencias.
Usar esta opción puede resultar en una transacción vacía.
Para acciones de instalación, omite los paquetes ya instalados.
Para acciones de actualización, omite los grupos o entornos que no están instalados.
Para acciones de eliminación, omite los paquetes/grupos/entornos no instalados.

EJEMPLOS

dnf5 history list
Lista todas las transacciones, imprimiendo primero la más reciente.
dnf5 history info 4
Muestra información detallada sobre la cuarta transacción.
dnf5 history info last
Muestra información detallada sobre la última transacción.
dnf5 history info last-1
Muestra información detallada sobre la penúltima transacción.
dnf5 history list 4..8
Lista las transacciones con id en el rango de 4 a 8.
dnf5 history undo last
Deshace la última transacción.
dnf5 history undo 4 --ignore-extras
Deshace la cuarta transacción ignorando los paquetes extra incorporados a la transacción de reversión.

    dnf5-history.8

    dnf5-history — Muestra el historial de transacciones de DNF.

    NOMBRE

    dnf5-history — Muestra el historial de transacciones de DNF.

    SINAPSIS

    dnf5 history [comando] [opciones] [argumentos]

    DESCRIPCIÓN

    El comando dnf5 history permite ver el historial de transacciones realizadas con DNF. Cada transacción es identificada por un ID único y contiene información sobre las acciones llevadas a cabo (instalación, eliminación, actualización, etc.), los paquetes afectados y la fecha/hora en que se realizó.

    OPCIONES

    Este comando reconoce las siguientes opciones:

    info [ID]
    Muestra información detallada sobre una transacción específica o la más reciente si no se proporciona ID.
    list [opciones]
    Lista las transacciones. Se pueden aplicar filtros con opciones como --user, --since, --until.
    undo [ID]
    Revierte una transacción específica. DNF intentará deshacer los cambios realizados por esa transacción.
    redo [ID]
    Vuelve a aplicar una transacción que haya sido deshecha previamente.
    rollback [ID]
    Revierte todas las transacciones hasta (pero sin incluir) la transacción especificada. Es útil para volver a un estado anterior del sistema.
    package-list --id
    Lista los paquetes que fueron modificados en una transacción específica.
    --user
    Filtra el historial para mostrar solo las transacciones realizadas por el usuario especificado.
    --since
    Muestra solo las transacciones realizadas después de la fecha y hora especificadas.
    --until
    Muestra solo las transacciones realizadas antes de la fecha y hora especificadas.

    ARCHIVOS

    Los datos del historial de transacciones se almacenan generalmente en:

    • /var/log/dnf.log
    • /var/lib/dnf/history/

    ESTADO DE SALIDA

    0 si la operación fue exitosa.

    1 si ocurrió un error.

    EJEMPLOS

    Para ver las 5 transacciones más recientes:

    dnf5 history list --limit 5

    Para ver detalles de la transacción con ID 123:

    dnf5 history info 123

    Para deshacer la transacción con ID 456:

    dnf5 history undo 456

    Para rebobinar hasta la transacción con ID 789 (deshaciendo todas las transacciones posteriores):

    dnf5 history rollback 789
