NOMBRE

dnf5-download - Comando de descarga

SINOPSIS

dnf5 download [opciones] <especificaciones-paquete-NPFB>...

DESCRIPCIÓN

El comando download en DNF5 se utiliza para descargar paquetes binarios y de origen definidos en los argumentos especificaciones-paquete-NPFB al directorio de trabajo actual.

OPCIONES

--arch
Limita a los paquetes de las arquitecturas dadas. Esta opción se puede usar varias veces.
--resolve
Resuelve las dependencias de los paquetes especificados y descarga los faltantes.
--alldeps
Para usarse junto con --resolve, descarga todas las dependencias, sin omitir las ya instaladas.
--from-repo=ID_REPO,...
Los paquetes (o sus proporcionados) especificados explícitamente en la línea de comandos solo se buscarán en los repositorios especificados.
Estos repositorios se habilitan automáticamente.
La habilitación y deshabilitación de repositorios aún se aplican. Las dependencias de estos paquetes se resolverán de cualquier repositorio habilitado.
--destdir=<ruta>
Establece el directorio que se utilizará para descargar los paquetes. La ubicación predeterminada es el directorio de trabajo actual.
--skip-unavailable
Permite omitir los paquetes que no están disponibles en los repositorios. Se descargarán todos los paquetes disponibles.
--srpm
Descarga el rpm fuente. Habilita los repositorios fuente de todos los repositorios binarios habilitados.
--url
Imprime la lista de URLs donde se pueden descargar los rpms en lugar de descargarlos.
--urlprotocol
Para usarse junto con --url. Filtra las URLs a los protocolos especificados: http, https, ftp o file. Esta opción se puede usar varias veces.
--allmirrors
Para usarse junto con --url. Imprime URLs separadas por espacios de todos los espejos disponibles para cada paquete.

EJEMPLOS

dnf5 download kernel-headers-0:5.17.0-300.fc36.i686
Descarga el paquete kernel-headers usando el formato NEVRA completo.
dnf5 download rpm rpm-devel
Descarga todos los paquetes con el nombre rpm o rpm-devel.
dnf5 download maven-compiler-plugin --resolve --alldeps
Descarga el paquete maven-compiler-plugin con todas sus dependencias.
dnf5 download --destdir /tmp/mis_paquetes maven-compiler-plugin
Descarga el paquete maven-compiler-plugin al directorio /tmp/mis_paquetes.
dnf5 download --url --urlprotocol http python
Lista la URL http para descargar el paquete python.
dnf5 download python --arch x86_64
Descarga python con la arquitectura x86_64.
dnf5 download dnf5 --srpm
Descarga el rpm fuente de dnf5.
