NOMBRE

dnf5-system-state - Estado del sistema

DESCRIPCIÓN

El estado del sistema DNF5 consiste en varios archivos TOML con su ubicación determinada por la opción de configuración system_state_dir (dnf5.conf(5), system_state_dir <#system-state-dir-options-label>). DNF5 utiliza el estado del sistema para:

1.
Almacenar las razones por las que cada paquete instalado se agregó al sistema. Las razones pueden ser "user" para paquetes que el usuario solicitó explícitamente a DNF5 que instalara, "dependency" y "weak dependency" para paquetes incluidos como dependencias de otro paquete, "group" para paquetes instalados por un grupo, o "external" para paquetes instalados por otra herramienta (p. ej., rpm).
2.
Rastrear grupos instalados y paquetes instalados por estos grupos.
3.
Rastrear grupos ambientales instalados.

La forma de almacenar el estado del sistema DNF5 es un detalle interno de implementación y puede cambiar en cualquier momento. Para modificar el estado, siempre utilice la interfaz de línea de comandos de DNF5 o la API de DNF5.

RECUPERACIÓN DE UN ESTADO DEL SISTEMA CORRUPTO

Si los archivos de estado del sistema se corrompen, simplemente haga una copia de seguridad y elimine el archivo TOML corrupto mencionado en el mensaje de error. Se regenerará durante la próxima transacción DNF5 exitosa. Los archivos regenerados pueden carecer de algunos datos, como las razones por las que se instalaron los paquetes o los repositorios de los que se instalaron.
