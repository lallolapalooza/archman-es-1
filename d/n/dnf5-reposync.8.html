NOMBRE

dnf5-reposync - Comando Reposync

SINOPSIS

dnf5 [OPCIONES GLOBALES] reposync [OPCIONES]

DESCRIPCIÓN

El comando reposync crea copias locales de repositorios remotos. Evita la redescarga de paquetes que ya están presentes en el directorio local.

Por defecto, reposync sincroniza todos los repositorios habilitados. Sin embargo, puedes personalizar el conjunto de repositorios a sincronizar utilizando opciones estándar de DNF5 como --repo, --enable-repo, o --disable-repo.

OPCIONES

--arch=<arquitectura>, -a <arquitectura>
Descarga solo paquetes para la arquitectura especificada. Esta opción se puede especificar varias veces. El comportamiento por defecto es descargar paquetes para todas las arquitecturas.
--delete
Elimina paquetes locales que ya no están presentes en el repositorio remoto.
--destdir=<ruta>
Especifica la ruta raíz donde se almacenarán los repositorios descargados, en relación con el directorio de trabajo actual. Por defecto, es el directorio de trabajo actual. Cada repositorio descargado tendrá un subdirectorio con el nombre de su ID dentro de esta ruta.
--download-metadata
Descarga todos los metadatos del repositorio. La copia descargada es instantáneamente utilizable como repositorio sin necesidad de ejecutar createrepo_c. Cuando se usa con --newest-only, solo se descargan las versiones más recientes de los paquetes. Sin embargo, los metadatos seguirán referenciando también paquetes más antiguos. Para evitar problemas causados por archivos RPM faltantes, considera actualizar los metadatos usando createrepo_c --update. De lo contrario, DNF encontrará errores al intentar instalar paquetes antiguos.
--gpgcheck, -g
Elimina paquetes que fallan la verificación de firma OpenPGP después de descargarlos. El comando sale con un código de 1 si se elimina al menos un paquete.

Nota: Para repositorios configurados con gpgcheck=0, las firmas OpenPGP no se verifican, incluso cuando se usa esta opción.

--metadata-path=<ruta>
Especifica la ruta raíz donde se almacenan los archivos de metadatos descargados. Si no se especifica, por defecto toma el valor de --destdir.
--newest-only, -n
Descarga solo las versiones más recientes de los paquetes de cada repositorio.
--norepopath
Evita que el ID del repositorio se agregue a la ruta de descarga. Esta opción solo se puede usar cuando se sincroniza un único repositorio. (El comportamiento por defecto agrega el ID del repositorio a la ruta).
--remote-time
Intenta establecer las marcas de tiempo de los archivos locales descargados para que coincidan con las del lado remoto.
--safe-write-path=<ruta>
Define el prefijo de ruta del sistema de archivos donde reposync tiene permiso para escribir archivos. Si no se especifica, por defecto es la ruta de descarga del repositorio. Esta opción es útil para repositorios que usan ubicaciones relativas de paquetes que salen del directorio del repositorio (por ejemplo, ../packages_store/foo.rpm).

Precaución: Cualquier archivo bajo safe-write-path puede ser sobrescrito. Esta opción solo se puede usar cuando se sincroniza un único repositorio.

--srpm
Descarga paquetes fuente. Equivalente a usar --arch=src.
--urls, -u
Imprime las URLs de los archivos que se descargarían sin descargarlos realmente.

EJEMPLOS

dnf reposync --repoid=el_repo
Sincroniza todos los paquetes del repositorio con el ID el_repo. La copia sincronizada se guarda en el subdirectorio el_repo del directorio de trabajo actual.
dnf reposync --destdir=/mi/ruta/repos/ --repoid=el_repo
Sincroniza todos los paquetes del repositorio con el ID el_repo. En este caso, los archivos se guardan en el directorio /mi/ruta/repos/el_repo.
dnf reposync --repoid=el_repo --download-metadata
Sincroniza todos los paquetes y metadatos del repositorio el_repo.

El repositorio sincronizado con la opción --download-metadata puede ser usado directamente con DNF, por ejemplo, usando la opción --repofrompath:

dnf --repofrompath=reposincronizado,el_repo --repoid=reposincronizado list --available
