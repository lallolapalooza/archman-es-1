NOMBRE

dnsget - utilidad de consulta DNS

SINOPSIS

dnsget [-v|-q] [-c clase] [-t tipo] [-o opt,opt,...] nombre...

DESCRIPCIÓN

dnsget es una simple utilidad de línea de comandos para realizar consultas DNS, similar a host(1) y dig(1). Es utilizable tanto para escenarios interactivos/de depuración como en scripts. El programa está implementado utilizando la biblioteca udns(3).

Por defecto, dnsget produce una salida legible por humanos, similar a

alias.example.com. CNAME www.example.com.
www.example.com. A 192.168.1.1
www.example.com. MX 10 mx.example.com.
que es suficiente para ver cómo se resuelve un nombre dado. El formato de salida se puede controlar con las opciones -v y -q; la primera aumenta el nivel de verbosidad hasta imprimir todo el contenido DNS de todos los paquetes enviados y recibidos, lo cual es adecuado para depurar problemas de DNS, mientras que la segunda reduce el nivel, haciendo la salida más silenciosa, hasta el resultado desnudo sin mensajes de error, lo cual es bueno para scripts.

OPCIONES

Las siguientes opciones son reconocidas por dnsget:

-v
produce una salida más detallada. Más -v significa más detalles que se producirán. Con una única -v, dnsget imprimirá el contenido de todos los paquetes DNS recibidos (en formato legible), mientras que con -vv, también mostrará todos los paquetes DNS salientes.
-q
lo opuesto a -v: produce una salida menos detallada. Con una única -q, dnsget solo mostrará los datos (decodificados) de los registros de recursos (RR) DNS finales, mientras que -qq también suprime los mensajes de error.
-t tipo
solicita registro(s) del tipo dado tipo. Por defecto, dnsget solicitará un registro de dirección IPv4 (A), o un registro PTR si el argumento en cuestión es una dirección IPv4 o IPv6. Los tipos reconocidos incluyen A, AAAA, MX, TXT, CNAME, PTR, NS, SOA, ANY y otros.
-c clase
solicita registro(s) DNS de la clase dada clase. Por defecto, dnsget utiliza la clase IN. Las clases válidas incluyen IN, CH, HS, ANY.
-a
(opción de compatibilidad) Equivalente a establecer el tipo de consulta a ANY y aumentar el nivel de verbosidad (-v).
-C
(planeado)
-x
(planeado)
-o opt,opt,...
(puede especificarse varias veces). Establece opciones del resolvedor (en formato opción:valor) como si se hubieran establecido en la variable de entorno $RES_OPTIONS, o establece indicadores de consulta:
timeout:seg
Establece el tiempo de espera inicial de la consulta a seg.
attempts:num
reintenta cada consulta num veces antes de fallar.
udpbuf:bytes
establece el tamaño del buffer UDP DNS a bytes bytes. Los valores válidos van desde 512 hasta 65535. Si bytes es mayor que 512, se utilizarán extensiones EDNS0 (RFC 2671).
port:num
Utiliza el número de puerto UDP dado num en lugar del puerto predeterminado 53 (domain).
aa
establece el bit de consulta AA (solo autoridad).
nord
no establece el bit de consulta RD (recursión deseada) (establecido por defecto).
dnssec o do
establece el indicador de consulta DNSSEC OK (DO) (dnsget no verifica las firmas DNSSEC, solo las muestra; esto se establece en el RR EDNS).
cd
establece el bit de consulta CD (comprobación deshabilitada).
-n servidor_nombre
Utiliza el(los) servidor(es) de nombres dado(s) (puede especificarse más de una vez) en lugar del predeterminado. El uso de esta opción tiene el mismo efecto que las variables de entorno $NSCACHEIP o $NAMESERVERS, con la única diferencia de que por ahora solo se reconocen direcciones IPv4, y es posible especificar nombres (que se resolverán utilizando la configuración predeterminada) en lugar de direcciones IP.
-h
imprime ayuda breve y sale.

VALOR DE RETORNO

Cuando todos los nombres se resuelven con éxito, dnsget sale con estado de salida cero. Si al menos un nombre no se encontró, dnsget saldrá con el código de retorno 100. Si ocurrió algún otro error durante la resolución de nombres, saldrá con el código 99. En caso de error de uso o inicialización, dnsget devolverá 1.

VER TAMBIÉN
