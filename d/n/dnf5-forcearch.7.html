NOMBRE

dnf5-forcearch - Parámetro Forcearch

DESCRIPCIÓN

El parámetro --forcearch=<arquitectura> anula la arquitectura del sistema detectada por DNF 5. Permite consultar repositorios de paquetes no compatibles con tu sistema anfitrión e instalarlos. Se puede especificar cualquier arquitectura, pero usar un paquete con una arquitectura no soportada nativamente por tu CPU requerirá algún tipo de emulación, p. ej., usando qemu-user-static.

--forcearch es compatible con los siguientes comandos: distro-sync, download, group, info, install, list, makecache, repo, repoquery, search y swap.

EJEMPLOS

dnf5 install --forcearch=aarch64 mi-paquete-ejemplo
Instala la versión de mi-paquete-ejemplo para la arquitectura AArch64, independientemente de la arquitectura del sistema anfitrión.
dnf5 download --forcearch=s390x hola
Descarga el paquete hola para la arquitectura s390x.
dnf5 repoquery --forcearch=aarch64 --arch=aarch64
Consulta todos los paquetes disponibles para la arquitectura AArch64. Si tu sistema tiene una arquitectura nativa diferente, entonces tanto --arch como --forcearch son necesarios aquí. --arch filtrará solo los paquetes con la arquitectura aarch64, y --forcearch establecerá las variables de sustitución "arch" y "basearch" para asegurar que se consulten los repositorios correctos.
