NOMBRE

dnf5-search - Comando de búsqueda

SINOPSIS

dnf5 search [opciones] <patrón>...

DESCRIPCIÓN

El comando search en DNF5 se utiliza para buscar paquetes haciendo coincidir palabras clave dadas por el usuario contra varios metadatos.

Por defecto, el comando busca todas las claves solicitadas (operación AND) en los campos Nombre o Resumen de los metadatos del paquete RPM. La coincidencia no distingue entre mayúsculas y minúsculas y se admiten comodines.

OPCIONES

--all
Busca patrones también dentro de los campos Descripción y URL.
Al aplicar esta opción, la búsqueda lista los paquetes que coinciden con al menos una de las claves (operación OR).
--showduplicates
Muestra todas las versiones de los paquetes, no solo las más recientes.

EJEMPLOS

dnf5 search kernel
Busca la palabra clave kernel dentro de los campos de metadatos del paquete Nombre o Resumen.
dnf5 search rpm dbus
Busca paquetes que contengan ambas palabras clave rpm y dbus dentro de los campos Nombre o Resumen.
dnf5 search --all fedora gnome kde
Busca paquetes que contengan cualquiera de las palabras clave dadas en los campos Nombre, Resumen, Descripción o URL.
