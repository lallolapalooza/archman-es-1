DNSBLOG(8) Manual del administrador del sistema DNSBLOG(8)

NOMBRE

dnsblog - Registrador DNS de lista de permitidos/bloqueados de Postfix

SINOPSIS

dnsblog [opciones genéricas del demonio de Postfix]

DESCRIPCIÓN


El servidor dnsblog(8) implementa un servicio de búsqueda DNS ad-hoc de listas de permitidos/bloqueados. Esto podría ser reemplazado eventualmente por un cliente UDP que esté integrado directamente en el servidor postscreen(8).

PROTOCOLO

Con cada conexión, el servidor dnsblog(8) recibe un nombre de dominio de lista de permitidos/bloqueados DNS, una dirección IP y un ID. Si la dirección IP está listada en la lista de permitidos/bloqueados DNS, el servidor dnsblog(8) registra la coincidencia y responde con los argumentos de la consulta más una lista de direcciones con las direcciones IP resultantes, separadas por espacios, y el TTL de la respuesta. De lo contrario, responde con los argumentos de la consulta más una lista de direcciones vacía y el TTL de la respuesta; el TTL de la respuesta es -1 si no hay respuesta, o una respuesta negativa que no contiene un registro SOA. Finalmente, el servidor dnsblog(8) cierra la conexión.

DIAGNÓSTICOS


Los problemas y transacciones se registran en syslogd(8) o postlogd(8).

PARÁMETROS DE CONFIGURACIÓN

Los cambios en main.cf se capturan automáticamente, ya que los procesos dnsblog(8) se ejecutan solo durante un tiempo limitado. Utilice el comando "postfix reload" para acelerar un cambio.

El texto a continuación solo proporciona un resumen de los parámetros. Consulte postconf(5) para obtener más detalles, incluidos ejemplos.

config_directory (ver salida de 'postconf -d')
La ubicación predeterminada de los archivos de configuración main.cf y master.cf de Postfix.
daemon_timeout (18000s)
Cuánto tiempo puede tardar un proceso demonio de Postfix en manejar una solicitud antes de que sea terminado por un temporizador de vigilancia incorporado.
postscreen_dnsbl_sites (vacío)
Lista opcional de patrones con dominios de lista de permitidos/bloqueados DNS, filtros y factores de peso.
ipc_timeout (3600s)
El límite de tiempo para enviar o recibir información a través de un canal de comunicación interno.
process_id (solo lectura)
El ID del proceso de un comando o proceso demonio de Postfix.
process_name (solo lectura)
El nombre del proceso de un comando o proceso demonio de Postfix.
queue_directory (ver salida de 'postconf -d')
La ubicación del directorio de colas de nivel superior de Postfix.
syslog_facility (mail)
La instalación de syslog del registro de Postfix.
syslog_name (ver salida de 'postconf -d')
Un prefijo que se antepone al nombre del proceso en los registros de syslog, de modo que, por ejemplo, "smtpd" se convierte en "prefijo/smtpd".

Disponible en Postfix 3.3 y posteriores:

service_name (solo lectura)
El nombre del servicio master.cf de un proceso demonio de Postfix.
