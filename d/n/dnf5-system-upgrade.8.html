NOMBRE

dnf5-system-upgrade - Comando System-Upgrade

SINOPSIS

dnf5 system-upgrade <subcomando> [opciones]

DESCRIPCIÓN

El comando system-upgrade se utiliza para actualizar el sistema a una nueva versión principal. Primero, el subcomando download descarga los paquetes mientras el sistema se está ejecutando normalmente. Luego, el subcomando reboot reinicia el sistema en un entorno mínimo "offline" para aplicar las actualizaciones.

dnf5 system-upgrade es la forma recomendada de actualizar un sistema a una nueva versión principal. Antes de continuar, asegúrate de que tu sistema esté completamente actualizado (dnf5 --refresh upgrade).

system-upgrade comparte muchos subcomandos con el subcomando offline <#offline-command-ref-label>.

SUBCOMANDOS

clean
Ver dnf5-offline(8), Comando offline <#offline-command-ref-label>
download
Descarga todos los paquetes necesarios para actualizar a una nueva versión principal y comprueba que puedan ser instalados.
log
Ver dnf5-offline(8), Comando offline <#offline-command-ref-label>
reboot
Ver dnf5-offline(8), Comando offline <#offline-command-ref-label>

OPCIONES

--releasever=<versión>
Requerido. La versión a la que actualizar. Establece $releasever en todos los repositorios habilitados. Normalmente un número, o rawhide.
--no-downgrade
Comportarse como dnf5 update: no instalar paquetes de la nueva versión si son más antiguos que los que están instalados actualmente. Esto es lo contrario del comportamiento predeterminado, que se comporta como dnf5 distro-sync, instalando siempre paquetes de la nueva versión, incluso si son más antiguos que la versión actualmente instalada.
--allowerasing
Permitir la eliminación de paquetes instalados para resolver cualquier posible problema de dependencia.
--number=<número de arranque>
Ver dnf5-offline(8), Comando offline <#offline-command-ref-label>
--poweroff
Ver dnf5-offline(8), Comando offline <#offline-command-ref-label>

ENTORNO

Ver dnf5-offline(8), Comando offline <#offline-command-ref-label>.

EJEMPLOS

Uso típico de actualización

dnf5 --refresh upgrade

dnf5 system-upgrade download --releasever 40

dnf5 system-upgrade reboot

Mostrar registros del último intento de actualización

dnf5 system-upgrade log --number=-1
