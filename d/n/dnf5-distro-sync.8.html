NOMBRE

dnf5-distro-sync - Comando Distro-Sync

SINOPSIS

dnf5 distro-sync [opciones] [<especificaciones-paquete-NPFB>...]

DESCRIPCIÓN

El comando distro-sync en DNF5 sirve para sincronizar los paquetes instalados con su última versión disponible de cualquier repositorio habilitado. Actualiza, degrada o mantiene paquetes según sea necesario.

Se pueden pasar argumentos opcionales <especificaciones-paquete-NPFB> para seleccionar solo paquetes específicos a sincronizar.

OPCIONES

--allowerasing
Permite la eliminación de paquetes instalados para resolver cualquier problema potencial de dependencias.
--skip-broken
Resuelve cualquier problema de dependencia eliminando los paquetes que causan problemas de la transacción.
--skip-unavailable
Permite omitir paquetes que no se pueden sincronizar. Todos los paquetes restantes se sincronizarán.
--installed-from-repo=REPO_ID,...
Filtra los paquetes instalados por el ID del repositorio del que fueron instalados.
--from-repo=REPO_ID,...
Los paquetes (o sus proporciona) especificados explícitamente en la línea de comandos solo se buscarán en los repositorios especificados.
Estos repositorios se habilitan automáticamente.
La habilitación y deshabilitación de repositorios aún se aplica. Las dependencias de estos paquetes se resolverán desde cualquier repositorio habilitado.
--downloadonly
Descarga el conjunto de paquetes resuelto sin ejecutar una transacción RPM.
--offline
Almacena la transacción para que se realice sin conexión. Consulte el comando offline <#offline-command-ref-label>, dnf5-offline(8).
--store=PATH
Almacena la transacción actual en un directorio en la ruta PATH especificada en lugar de ejecutarla.
La transacción almacenada puede ser realizada por el comando replay <#replay-command-ref-label>, dnf5-replay(8).

EJEMPLOS

dnf5 distro-sync
Sincroniza todo el sistema a la última versión disponible de los paquetes.
dnf5 distro-sync vim
Sincroniza el paquete vim a la última versión disponible.
