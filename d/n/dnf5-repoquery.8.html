NOMBRE

dnf5-repoquery - Comando Repoquery

SINOPSIS

dnf5 repoquery [opciones] [<paquete-espec-NIF>...]

DESCRIPCIÓN

El comando repoquery en DNF5 se utiliza para consultar paquetes coincidiendo con varios criterios de entrada del usuario. Los argumentos definidos en la lista de especificaciones se utilizan como <paquete-archivo-espec>.

OPCIONES

--advisories=NOMBRE_AVISO,...
Incluir el contenido contenido en avisos con el nombre especificado.
Esta es una opción de lista.
Los valores esperados son los identificadores de los avisos, por ejemplo FEDORA-2201-123.
Cualquier comando de transacción (instalar, actualizar) fallará con un error si no existe un aviso en la lista; esto se puede evitar usando el interruptor --skip-unavailable.
--advisory-severities=SEVERIDAD_AVISO,...
Incluir el contenido contenido en avisos con la severidad especificada.
Esta es una opción de lista.
Los valores aceptados son: critical, important, moderate, low, none.
--arch=ARQUITECTURA,...
Limitar a paquetes de estas arquitecturas.
Esta es una opción de lista.
--available
Consultar paquetes disponibles.
Este es el comportamiento por defecto.
Se puede combinar con --installed para consultar tanto paquetes instalados como disponibles.
--bugfix
Incluir el contenido contenido en avisos de corrección de errores.
--bzs=ID_BUGZILLA,...
Incluir el contenido contenido en avisos que corrigen un ticket con el ID de Bugzilla dado.
Esta es una opción de lista.
Los valores esperados son identificadores numéricos, por ejemplo 123123.
Cualquier comando de transacción (instalar, actualizar) fallará con un error si no hay un aviso que corrija el ticket dado; esto se puede evitar usando el interruptor --skip-unavailable.
--cves=ID_CVE,...
Incluir el contenido contenido en avisos que corrigen un ticket con el ID de CVE (Vulnerabilidades y Exposiciones Comunes) dado.
Esta es una opción de lista.
Los valores esperados son identificadores de cadena en formato CVE, por ejemplo CVE-2201-0123.
Cualquier comando de transacción (instalar, actualizar) fallará con un error si no hay un aviso que corrija el ticket dado; esto se puede evitar usando el interruptor --skip-unavailable.
--disable-modular-filtering
Incluir paquetes de flujos de módulos inactivos.
--duplicates
Limitar a paquetes duplicados instalados (es decir, más versiones de paquete para el mismo nombre y arquitectura).
Los paquetes installonly se excluyen de este conjunto.
--enhancement
Incluir el contenido contenido en avisos de mejora.
--exactdeps
Limitar a paquetes que requieren <capacidad> especificada por --whatrequires o --whatdepends.
Esta opción solo se puede apilar con --whatrequires o --whatdepends.
--extras
Limitar a paquetes instalados que no están presentes en ningún repositorio disponible.
-f, --file=ARCHIVO,...
Limitar a paquetes que poseen estos archivos.
Esta es una opción de lista.
--installed
Consultar paquetes instalados.
Se puede combinar con --available para consultar tanto paquetes instalados como disponibles.
--installed-from-repo=ID_REPO,...
Filtra los paquetes instalados por el ID del repositorio del que fueron instalados.
--installonly
Limitar a paquetes installonly instalados.
--latest-limit=N
Limitar a los N paquetes más recientes para un nombre.arquitectura dado (o todos excepto los N más recientes si N es negativo).
--leaves
Limitar a grupos de paquetes instalados que no son requeridos por otros paquetes instalados.
--newpackage
Incluir el contenido contenido en avisos de paquete nuevo.
--providers-of=ATRIBUTO_PAQUETE
Después de que termine el filtrado, obtener el atributo seleccionado de los paquetes y mostrar los paquetes que lo proporcionan.
Los paquetes mostrados se limitan por las opciones --available, --installed y --arch .
Soporta: conflicts, depends, enhances, obsoletes, provides, recommends, requires, requires_pre, suggests, supplements.
--recent
Limitar a paquetes cambiados recientemente.
--recursive
Esta opción solo se puede apilar con --whatrequires o --providers-of=requires.
Cuando se usa con --whatrequires: extiende la salida con paquetes que requieren algo proporcionado por los paquetes mostrados.
Cuando se usa con --providers-of=requires: extiende la salida con paquetes que proporcionan algo requerido por los paquetes mostrados.
Repite la extensión de la salida mientras se añadan nuevos paquetes.
Los paquetes añadidos se limitan por las opciones --available, --installed y --arch .
--security
Incluir el contenido contenido en avisos de seguridad.
--srpm
Después de que termine el filtrado, usar los RPM de origen correspondientes a los paquetes para la salida.
Habilita los repositorios de origen.
--unneeded
Limitar a paquetes instalados innecesarios (es decir, paquetes que se instalaron como dependencias pero que ya no son necesarios).
Este interruptor lista los paquetes que se eliminarán después de ejecutar el comando autoremove .
--upgrades
Limitar a paquetes disponibles que proporcionan una actualización para algún paquete ya instalado.
--userinstalled
Limitar a paquetes que no se instalaron como dependencias o dependencias débiles.
Esto significa limitar a paquetes que se instalaron a petición del usuario o indirectamente como parte de un perfil de módulo o grupo de comps. Además, devuelve paquetes con una razón desconocida.
El resultado puede verse influido por la opción "exclude" en el archivo de configuración.
Para obtener la razón exacta de la instalación, usa la opción --queryformat '%{name} %{reason}\n' .
--whatconflicts=CAPABILITY,...
Limitar a los paquetes que entran en conflicto con alguna de <capabilities>.
Esta es una opción de lista.
--whatdepends=CAPABILITY,...
Limitar a los paquetes que requieren, mejoran, recomiendan, sugieren o complementan alguna de <capabilities>.
Esta es una opción de lista.
--whatenhances=CAPABILITY,...
Limitar a los paquetes que mejoran alguna de <capabilities>. Use --whatdepends si desea listar todos los paquetes dependientes.
Esta es una opción de lista.
--whatobsoletes=CAPABILITY,...
Limitar a los paquetes que obsoletan alguna de <capabilities>.
Esta es una opción de lista.
--whatprovides=CAPABILITY,...
Limitar a los paquetes que proporcionan alguna de <capabilities>. Las capacidades que especifican un archivo proporcionan <#file-provides-ref-label> y también se comparan con los archivos proporcionados.
Esta es una opción de lista.
--whatrecommends=CAPABILITY,...
Limitar a los paquetes que recomiendan alguna de <capabilities>. Use --whatdepends si desea listar todos los paquetes dependientes.
Esta es una opción de lista.
--whatrequires=CAPABILITY,...
Limitar a los paquetes que requieren alguna de <capabilities>. Use --whatdepends si desea listar todos los paquetes dependientes.
Esta es una opción de lista.
--whatsuggests=CAPABILITY,...
Limitar a los paquetes que sugieren alguna de <capabilities>. Use --whatdepends si desea listar todos los paquetes dependientes.
Esta es una opción de lista.
--whatsupplements=CAPABILITY,...
Limitar a los paquetes que complementan alguna de <capabilities>. Use --whatdepends si desea listar todos los paquetes dependientes.
Esta es una opción de lista.

OPCIONES DE FORMATO

Establece qué información se muestra sobre cada paquete. Las siguientes son mutuamente excluyentes, es decir, se puede especificar como máximo una. Si no se proporciona ninguna opción de formato, los paquetes seleccionados se muestran en "%{full_nevra}" queryformat.

--conflicts
Como --qf "%{conflicts}" pero sin duplicados y ordenado por línea.
--depends
Como --qf "%{depends}" pero sin duplicados y ordenado por línea.
--enhances
Como --qf "%{enhances}" pero sin duplicados y ordenado por línea.
--files
Como --qf "%{files}" pero sin duplicados y ordenado por línea.
--obsoletes
Como --qf "%{obsoletes}" pero sin duplicados y ordenado por línea.
--provides
Como --qf "%{provides}" pero sin duplicados y ordenado por línea.
--recommends
Como --qf "%{recommends}" pero sin duplicados y ordenado por línea.
--requires
Como --qf "%{requires}" pero sin duplicados y ordenado por línea.
--requires-pre
Como --qf "%{requires_pre}" pero sin duplicados y ordenado por línea.
--sourcerpm
Como --qf "%{sourcerpm}" pero sin duplicados y ordenado por línea.
--suggests
Como --qf "%{suggests}" pero sin duplicados y ordenado por línea.
--supplements
Como --qf "%{supplements}" pero sin duplicados y ordenado por línea.
--location
Como --qf "%{location}" pero sin duplicados y ordenado por línea.
-i, --info
Muestra información detallada sobre el paquete.
--changelogs
Imprime los registros de cambios del paquete.
--querytags
Muestra las etiquetas disponibles para --queryformat.
--queryformat=<formato>
Formato de visualización para los paquetes. La <formato> cadena puede contener etiquetas (%{<tag>}) que se reemplazan con los atributos correspondientes del paquete.
El valor predeterminado es "%{full_nevra}". La <formato> cadena se expande y se deduplica para cada paquete.
* arch - Muestra la arquitectura del paquete.
* buildtime - Muestra la hora de compilación del paquete en tiempo Unix.
* conflicts - Muestra las capacidades con las que entra en conflicto el paquete. Separadas por saltos de línea.
* debug_name - Muestra el nombre del paquete de debuginfo del paquete.
* depends - Muestra las capacidades de las que depende, que mejora, recomienda, sugiere o complementa el paquete. Separadas por saltos de línea.
* description - Muestra la descripción del paquete.
* downloadsize - Muestra el tamaño de descarga del paquete.
* enhances - Muestra las capacidades mejoradas por el paquete. Separadas por saltos de línea.
* epoch - Muestra la época del paquete.
* evr - Muestra la época:versión-revisión del paquete. La época 0 se omite.
* files - Muestra los archivos del paquete. Separados por saltos de línea.
* from_repo - Muestra el id del repositorio desde el que se instaló el paquete. Vacío para paquetes no instalados.
* full_nevra - Muestra el nombre-época:versión-revisión.arquitectura del paquete. Incluso la época 0 está incluida.
* group - Muestra el grupo del paquete. Este no es el grupo de Comps.
* location - Muestra la ubicación del paquete.
* installsize - Muestra el tamaño de instalación del paquete.
* installtime - Muestra la hora de instalación del paquete.
* license - Muestra la licencia del paquete.
* name - Muestra el nombre del paquete.
* obsoletes - Muestra las capacidades obsoletadas por el paquete. Separadas por saltos de línea.
* packager - Muestra el empaquetador del paquete.
* prereq_ignoreinst - Muestra los requisitos de requires_pre seguros de eliminar de un paquete instalado. Vacío para paquetes no instalados. Separados por saltos de línea.
* provides - Muestra las capacidades proporcionadas por el paquete. Separadas por saltos de línea.
* reason - Muestra la razón por la que se instaló el paquete.
* recommends - Muestra las capacidades recomendadas por el paquete. Separadas por saltos de línea.
* regular_requires - Muestra las capacidades requeridas por el paquete sin sus %pre, %post, %preun y %postun requisitos. Separadas por saltos de línea.
* release - Muestra la revisión del paquete.
* repoid - Muestra el id del repositorio en el que se encuentra el paquete.
* reponame - Muestra el nombre del repositorio en el que se encuentra el paquete.
* requires - Muestra las capacidades requeridas por el paquete (combina regular_requires y requires_pre).
* requires_pre - Para un paquete instalado, muestra las capacidades de las que depende para ejecutar sus %pre, %post, %preun y %postun scripts. Para un paquete no instalado, muestra solo los requisitos de %pre y $post . Separadas por saltos de línea.
* source_debug_name - Muestra el nombre del paquete de debuginfo para el paquete fuente del paquete.
* source_name - Muestra el nombre del RPM fuente del paquete.
* sourcerpm - Muestra el RPM fuente del paquete.
* suggests - Muestra las capacidades sugeridas por el paquete. Separadas por saltos de línea.
* summary - Muestra el resumen del paquete.
* supplements - Muestra las capacidades complementadas por el paquete. Separadas por saltos de línea.
* url - Muestra la url del paquete.
* vendor - Muestra el proveedor del paquete.
* version - Muestra la versión del paquete.
La <formato> cadena también puede contener \n que se reemplazará con un carácter de nueva línea en la salida.

EJEMPLOS

dnf5 repoquery /etc/koji.conf
Lista los paquetes que proporcionan el archivo dado.
dnf5 repoquery *http*
Lista los paquetes que contienen http dentro de su nombre.
dnf5 repoquery --installed --security
Lista los paquetes instalados incluidos en algún aviso de seguridad.
