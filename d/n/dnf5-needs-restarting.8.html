NOMBRE

dnf5-needs-restarting - Comando Needs-restarting

SINOPSIS

dnf5 needs-restarting [--services | -s]

DESCRIPCIÓN

El comando needs-restarting determina si el sistema debe reiniciarse para aplicar completamente los cambios de las instalaciones y actualizaciones de paquetes. Sin opciones, dnf5 needs-restarting informará si algún paquete importante fue instalado o actualizado desde el arranque. Este conjunto de paquetes importantes incluye el kernel, systemd, cada paquete listado aquí: https://access.redhat.com/solutions/27943, y cualquier paquete marcado con un aviso de reboot_suggested.

El comando needs-restarting saldrá con el código 1 si se recomienda un reinicio, o, cuando se invoca con --services, si algún servicio de systemd necesita reiniciarse. Si no se recomienda ninguna acción, needs-restarting saldrá con el código 0.

OPCIONES

-s, --services
Enumera los servicios de systemd que necesitan reiniciarse. Si el paquete que proporciona el servicio, o alguna de sus dependencias, se han actualizado desde que se inició el servicio, entonces se recomendará reiniciar el servicio. Tenga en cuenta que este enfoque es bastante agresivo para recomendar un reinicio cuando puede que no sea estrictamente necesario.
