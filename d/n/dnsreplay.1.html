DNSREPLAY(1) Servidor Autoritativo de PowerDNS DNSREPLAY(1)

NOMBRE

dnsreplay - Una herramienta de depuración de servidor DNS de PowerDNS

SINOPSIS

dnsreplay [OPCIÓN]... NOMBRE_ARCHIVO DIRECCION [PUERTO]

DESCRIPCIÓN

Este programa toma preguntas y respuestas grabadas y las reproduce al servidor DNS especificado, informando después qué porcentaje de respuestas coincidió, fueron peores o mejores.

dnsreplay compara las respuestas y algunas otras métricas con las reales con las encontradas en el archivo volcado.

Por defecto, solo reproducirá consultas con el flag de deseo de recursión activado.

OPCIONES

NOMBRE_ARCHIVO
se espera que sea un archivo PCAP. Las consultas se envían al servidor DNS especificado como DIRECCION y PUERTO.
DIRECCION
dirección IPv4 o IPv6 del servidor DNS al que reproducir NOMBRE_ARCHIVO.
PUERTO
si se omite, se usará 53.
--help, -h
Muestra un resumen de las opciones.
--ecs-mask <VALOR>
Al reenviar una dirección IP con EDNS, enmascara el primer octeto con este valor.
--ecs-stamp <BANDERA>
Agrega la dirección IP original como Opción de Subred de Cliente EDNS al reenviar al servidor de referencia.
--packet-limit <NUMERO>
Detenerse después de reproducir NUMERO paquetes. El valor predeterminado para NUMERO es 0, lo que significa sin límite.
--pcap-dns-port <VALOR>
Examinar paquetes desde o hacia este puerto en el PCAP. El valor predeterminado es 53.
--quiet <BANDERA>
Si BANDERA se establece en 1, dnsreplay no será muy ruidoso con su salida. Este es el valor predeterminado.
--recursive <BANDERA>
Si BANDERA se establece en 1, dnsreplay solo reproducirá consultas con el flag de deseo de recursión activado. Este es el valor predeterminado.
--source-from-pcap <BANDERA>
Si BANDERA se establece en 1, dnsreplay enviará las consultas reproducidas desde la dirección IP y puerto de origen presentes en el archivo PCAP. Esto requiere soporte IP_TRANSPARENT. El valor predeterminado es 0, lo que significa que las consultas reproducidas se enviarán desde una dirección local.
--source-ip <VALOR>
Enviar las consultas reproducidas desde la IP de origen especificada en VALOR. El valor predeterminado es enviarlas desde una dirección local.
--source-port <VALOR>
Enviar las consultas reproducidas desde el puerto de origen especificado en VALOR. El valor predeterminado es enviarlas desde un puerto aleatorio seleccionado por el kernel.
--speedup <FACTOR>
Reproducir consultas con este FACTOR de aceleración. El valor predeterminado es 1.
--timeout-msec <MSEC>
Esperar al menos MSEC milisegundos por una respuesta. El valor predeterminado es 500.

ERRORES

dnsreplay no tiene un manejo seguro para los tiempos de espera. Maneja como máximo alrededor de 65536 respuestas pendientes.

VER TAMBIÉN
