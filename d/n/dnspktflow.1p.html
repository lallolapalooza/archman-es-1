DNSPKTFLOW(1) Documentación de Perl aportada por el usuario DNSPKTFLOW(1)

NOMBRE

dnspktflow - Analiza y dibuja diagramas de flujo DNS a partir de un archivo tcpdump

SINOPSIS

dnspktflow -o output.png file.tcpdump
dnspktflow -o output.png -x -a -t -q file.tcpdump

DESCRIPCIÓN

La aplicación dnspktflow toma un archivo de volcado de tráfico de red tcpdump tcpdump , lo procesa con la aplicación tshark tshark y luego muestra los flujos de paquetes DNS resultantes en una imagen de "diagrama de flujo". dnspktflow puede generar una sola imagen o una serie de imágenes que luego pueden mostrarse en secuencia como una animación.

dnspktflow fue escrito como una utilidad de depuración para ayudar a rastrear consultas y respuestas DNS, especialmente en lo que respecta a búsquedas habilitadas para DNSSEC.

REQUISITOS

Esta aplicación requiere los siguientes módulos y componentes de software de Perl para funcionar:

graphviz                  (http://www.graphviz.org/)
GraphViz                  (módulo Perl)
tshark                    (http://www.wireshark.org/)

Se requiere lo siguiente para generar presentaciones en pantalla:

MagicPoint                (http://member.wide.ad.jp/wg/mgp/)

Si los siguientes módulos están instalados, se habilitará una interfaz gráfica para la comunicación con dnspktflow:

QWizard                   (módulo Perl)
Getopt::GUI::Long         (módulo Perl)

OPCIONES

dnspktflow admite una amplia variedad de opciones de línea de comandos. Estas opciones se describen a continuación en los siguientes grupos funcionales: selección de paquetes de entrada, opciones de archivo de salida, opciones de visualización de salida, opciones gráficas y depuración.

Selección de paquetes de entrada

Estas opciones determinan los paquetes que serán seleccionados por dnspktflow.

-i STRING
--ignore-hosts=STRING
Una expresión regular de nombres de host a ignorar en los campos de consulta/respuesta.
-r STRING
--only-hosts=STRING
Una expresión regular de nombres de host a analizar en los campos de consulta/respuesta.
-f
--show-frame-num
Muestra los números de trama de los paquetes.
-b INTEGER
--begin-frame=INTEGER
Comienza en el paquete de trama NÚMERO.

Opciones de archivo de salida

Estas opciones determinan el tipo y la ubicación de la salida de dnspktflow.

-o STRING
--output-file=STRING
Nombre del archivo de salida (por defecto: out%03d.png en formato PNG.)
--fig
El formato de salida debe ser fig.
-O STRING
--tshark-out=STRING
Guarda la salida de tshark tshark en este archivo.
-m
--multiple-outputs
Una imagen por solicitud (utilice %03d en el nombre del archivo.)
-M STRING
--magic-point=STRING
Guarda una presentación MagicPoint para la salida.

Opciones de visualización de salida:

Estas opciones determinan detalles específicos de la salida de dnspktflow.

--layout-style
Selecciona el estilo de diseño de graphviz a utilizar (dot, neato, twopi, circo o fdp).
-L
--last-line-labels-only
Muestra solo datos en la última línea dibujada.
-z INTEGER
--most-lines=INTEGER
Muestra como máximo INTEGER conexiones.
-T
--input-is-tshark-out
El archivo de entrada ya ha sido procesado por tsharktshark .

Opciones gráficas:

Estas opciones determinan los campos incluidos en la salida de dnspktflow.

-t
--show-type
Muestra el tipo de mensaje en la imagen de resultado.
-q
--show-queries
Muestra las preguntas de consulta en la imagen de resultado.
-a
--show-answers
Muestra las respuestas a las consultas en la imagen de resultado.
-A
--show-authoritative
Muestra información autoritativa en la imagen de resultado.
-x
--show-additional
Muestra información adicional en la imagen de resultado.
-l
--show-label-lines
Muestra líneas que conectan etiquetas con líneas.
--fontsize=INTEGER
Tamaño de fuente

Depuración:

Estas opciones pueden ayudar en la depuración de dnspktflow.

-d
--dump-pkts
Vuelca los datos recopilados de los paquetes.
-h
--help
Muestra la ayuda para las opciones de línea de comandos.
