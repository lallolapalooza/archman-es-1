DESCRIPCIÓ

N

CLI alternativo a dnf upgrade con instalaciones específicas para hacerlo adecuado para ser ejecutado automáticamente y regularmente desde temporizadores systemd, trabajos de cron y

similares.

La operación de la herramienta está controlada por archivos de configuración. Los valores predeterminados se establecen desde /usr/share/dnf5/dnf5-plugins/automatic.conf config file. Las anulaciones específicas del host desde /etc/dnf/automatic.conf son entonces

aplicadas.

La herramienta sincroniza los metadatos de los paquetes según sea necesario y luego verifica si hay actualizaciones disponibles para el sistema dado y luego sale, descarga los paquetes o descarga y aplica las actualizaciones. El resultado de la operación es entonces reportado por un mecanismo seleccionado, por ejemplo a través de la salida estándar, correo electrónico o mensajes

MOTD.

La unidad del temporizador systemd dnf5-automatic.timer se comportará como especifica el archivo de configuración (ver más abajo) con respecto a si descargar y aplicar

actualizaciones
.

AUTOMATIC

El servicio se ejecuta típicamente usando el temporizador systemd dnf5-automatic.timer. Para configurar el servicio, personalice el /etc/dnf/automatic.conf file. Puedes copiar el archivo de configuración de la distribución desde /usr/share/dnf5/dnf5-plugins/automatic.conf y usar como base, o crear tu propio archivo de configuración desde cero con solo las anulaciones
