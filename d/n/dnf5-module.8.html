NOMBRE

dnf5-module - Comando de Módulos

SINOPSIS

dnf5 module <subcomando> [opciones] [<espec-módulo>...]

DESCRIPCIÓN

La modularidad es una forma alternativa de construir, organizar y distribuir paquetes.

Actualmente, solo hay soporte básico disponible para la gestión de módulos, ya que ya no se soportan en las distribuciones RPM principales.

Para más detalles, consulte: https://docs.pagure.org/modularity/.

SUBCOMANDOS

list
Lista los flujos de módulos. Las opciones --enabled y --disabled reducen la lista solicitada.
info
Muestra detalles sobre los flujos de módulos.
enable
Habilita los flujos de módulos y hace que sus paquetes estén disponibles.
disable
Deshabilita los módulos, incluidos todos sus flujos.
reset
Restablece el estado del módulo para que ya no esté habilitado ni deshabilitado.

OPCIONES PARA LIST Y INFO

--enabled
Muestra solo módulos habilitados.
--disabled
Muestra solo módulos deshabilitados.

OPCIONES PARA ENABLE, DISABLE, RESET

--skip-broken
Resuelve cualquier problema de dependencia eliminando los elementos que causan problemas de la transacción.
Se utiliza con el comando enable.
--skip-unavailable
Permite omitir módulos que no están disponibles en los repositorios.
Se procesarán todos los elementos restantes.

EJEMPLOS

dnf5 module list
Lista todos los flujos de módulos disponibles para tu sistema.
dnf5 module enable nodejs:8
Hace que los paquetes del flujo Node.js 8 estén disponibles para su instalación.
