DNSDOMAINNAME(1) Comandos de usuario DNSDOMAINNAME(1)

NOMBRE

dnsdomainname - muestra el nombre de dominio DNS

SINOPSIS

dnsdomainname [OPCIÓN...]

DESCRIPCIÓN

Muestra la parte de dominio del nombre de host completo del sistema.

La herramienta utiliza gethostname para obtener el nombre de host del sistema y getaddrinfo para resolverlo en un nombre canónico. Se muestra la parte después del primer punto ('.') del nombre canónico.
