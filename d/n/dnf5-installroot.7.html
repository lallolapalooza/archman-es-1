NOMBRE

dnf5-installroot - Parámetro Installroot

DESCRIPCIÓN

El parámetro --installroot se utiliza para especificar un installroot alternativo, relativo a donde se instalarán todos los paquetes. Piénselo como hacer chroot <root> dnf, excepto que usar --installroot permite que DNF5 funcione antes de que se cree el chroot.

El directorio cachedir, system_cachedir, los archivos log, releasever y gpgkey se toman o se almacenan en el installroot. Las claves OpenPGP se importan en el installroot desde una ruta relativa al host que se puede especificar en la sección de repositorios de los archivos de configuración.

El archivo de configuración, reposdir y las vars se toman desde el interior del installroot, a menos que se pase el argumento de línea de comandos --use-host-config, en cuyo caso la configuración y el entorno del sistema host se utilizarán.

Nota: Cuando se especifica una ruta en un argumento de línea de comandos (--config=RUTA_ARCHIVO_CONFIG en el caso del archivo de configuración, --setopt=reposdir=/ruta/a/repodir para reposdir, --setopt=cachedir=/ruta/a/cachedir para cachedir, --setopt=system_cachedir=/ruta/a/system_cachedir para system_cachedir, --setopt=logdir=/ruta/a/logdir para logdir, o --setopt=varsdir=/rutas/a/varsdir para vars), entonces esta ruta es siempre relativa al host sin excepciones. pluginpath y pluginconfpath son relativos al host.

Nota: También puede que desee utilizar la opción de línea de comandos --releasever=RELEASEVER al crear el installroot, de lo contrario, el valor $releasever se toma de la rpmdb dentro del installroot (y por lo tanto está vacío en el momento de la creación y la transacción fallará). Si se utiliza --use-host-config, el releasever se detectará desde el sistema host (/). La nueva ruta de installroot en el momento de la creación no contiene los archivos de repositorio, releasever y dnf.conf.

En un sistema modular, también puede que desee utilizar la opción de línea de comandos --setopt=module_platform_id=<nombre_plataforma_modulo:stream> al crear el installroot, de lo contrario, el valor module_platform_id se tomará del archivo /etc/os-release dentro del installroot (y por lo tanto estará vacío en el momento de la creación, la dependencia modular podría no cumplirse y el contenido de los módulos podría excluirse).

EJEMPLOS

dnf5 --installroot=INSTALLROOT --releasever=RELEASEVER install system-release
Establece permanentemente el releasever del sistema en el directorio INSTALLROOT a RELEASEVER.
dnf5 --installroot=INSTALLROOT --setopt=reposdir=RUTA --config /ruta/dnf.conf upgrade
Actualiza los paquetes dentro del installroot desde un repositorio descrito por --setopt usando la configuración de /ruta/dnf.conf.
