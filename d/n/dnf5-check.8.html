NOMBRE

dnf5-check - Comando de verificación

SINOPSIS

dnf5 check [opciones]

DESCRIPCIÓN

Verifica la base de datos de paquetes local y produce información sobre cualquier problema que encuentre. El conjunto de verificaciones realizadas se puede especificar con opciones.

OPCIONES

--dependencies
Muestra dependencias y conflictos faltantes.
--duplicates
Muestra paquetes duplicados.
--obsoleted
Muestra paquetes obsoletos.

EJEMPLOS

dnf5 check
Muestra todos los problemas.
dnf5 check --dependencies --obsoleted
Muestra dependencias faltantes, conflictos y paquetes obsoletos.
