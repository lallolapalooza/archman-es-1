NOMBRE

dnf5-filtering - Filtrado de paquetes

DESCRIPCIÓN

El filtrado de paquetes elimina paquetes del conjunto de paquetes disponibles, haciéndolos invisibles para la mayoría de los comandos DNF5. Como resultado, estos paquetes no pueden ser incluidos en ninguna transacción.

Hay varias formas en que un paquete puede ser filtrado:

FILTRADO DE EXCLUSIONES GLOBALES

El filtrado de exclusiones se puede ajustar utilizando las opciones de configuración includepkgs o excludepkgs en el archivo de configuración de DNF5. Para deshabilitar las exclusiones, puede usar la opción de configuración disable_excludes:

dnf5 --setopt=disable_excludes=* install bash

Para obtener detalles sobre las opciones de configuración, consulte dnf5.conf(5), la referencia de configuración de DNF5 <#dnf5-conf-label>.

FILTRADO DE EXCLUSIONES DEL REPOSITORIO

Similar a las exclusiones globales, pero esta configuración es específica del repositorio y solo afecta a los paquetes dentro del repositorio donde se establecen las exclusiones.

FILTRADO DE EXCLUSIONES DEL USUARIO

Los usuarios de la API tienen una opción adicional para ajustar los paquetes excluidos utilizando los métodos *_user_excludes() y *_user_includes del objeto PackageSack. Ver API de PackageSack.

VERSIONLOCK

Además, la funcionalidad versionlock se implementa utilizando el filtrado de exclusiones. Sin embargo, estas exclusiones solo se aplican durante las operaciones transaccionales. Para obtener más detalles, consulte dnf5-versionlock(8), el comando Versionlock <#versionlock-command-ref-label>.

FILTRADO MODULAR

Para obtener detalles sobre cómo funciona el filtrado modular, consulte dnf5-modularity(7), la documentación de modularidad <#modularity-misc-ref-label>.

Con la modularidad, solo los paquetes RPM de los flujos de módulos activos se incluyen en el conjunto de paquetes disponibles. Los paquetes RPM de flujos de módulos inactivos, así como los paquetes no modulares con el mismo nombre o que proporcionan un paquete de un flujo de módulos activo, se filtran. El filtrado modular no se aplica a los paquetes agregados desde la línea de comandos, los paquetes instalados o los paquetes de repositorios con module_hotfixes=true en su archivo .repo.

No se recomienda deshabilitar el filtrado modular, ya que podría provocar que el sistema entre en un estado roto. Para deshabilitar el filtrado modular para un repositorio en particular, especifique module_hotfixes=true en el archivo .repo o use --setopt=<repo_id>.module_hotfixes=true.
