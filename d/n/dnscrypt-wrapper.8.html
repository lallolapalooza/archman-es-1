NOMBRE

dnscrypt-wrapper - Crea una plantilla de sitio web vacía casi lista para su implementación.

SINOPSIS

dnscrypt-wrapper [-h] [-a <str>] [-r <str>] [-U] [-u <str>] [-l <str>] [-p <str>] [-d] [-V] [-v] [--gen-cert-file] [--gen-crypt-keypair] [--gen-provider-keypair] [--show-provider-publickey-fingerprint] [--provider-cert-file=<str>] [--provider-name=<str>] [--provider-publickey-file=<str>] [--provider-secretkey-file=<str>] [--crypt-secretkey-file=<str>] [--cert-file-expire-days=<int>]

DESCRIPCIÓN

dnscrypt-wrapper DNSCrypt es un protocolo que autentica las comunicaciones entre un cliente DNS y un resolvedor DNS. Previene la suplantación de DNS. Utiliza firmas criptográficas para verificar que las respuestas provienen del resolvedor DNS elegido y no han sido manipuladas.

OPCIONES

-h, --help,
Muestra el mensaje de ayuda de dnscrypt-wrapper y sale.
-a <str>, --listen-address=<str>
Establece la dirección local para escuchar (por defecto: 0.0.0.0:53).
 <str>-r, --resolver-address=<str>
Establece el servidor resolvedor DNS ascendente (<dirección:puerto>).
-U, --unauthenticated
Permite y reenvía consultas no autenticadas (por defecto: desactivado).
-u <str>, --user=<str>
Ejecuta el servicio como el usuario indicado.
-l <str>, --logfile=<str>
Ruta del archivo de logs (por defecto: stdout).
-p <str>, --pidfile=<str>
Ruta del archivo PID (por defecto: ninguno).
-d, --daemonize
Ejecuta como demonio (por defecto: desactivado).
-V, --verbose
Establece el servicio para que sea más verboso. Especifica más -VVV para aumentar la verbosidad.
-v, --version
Muestra la información de la versión y sale.
--gen-cert-file
Genera un certificado pre-firmado
--gen-crypt-keypair
Genera un par de claves de cifrado
--gen-provider-keypair
Genera un par de claves de proveedor
--show-provider-publickey-fingerprint
Muestra la huella digital de la clave pública del proveedor
--provider-cert-file=<str>
Archivo de certificado (por defecto: ./dnscrypt.cert)
--provider-name=<str>
Nombre del proveedor.
--provider-publickey-file=<str>
Archivo de clave pública del proveedor (por defecto: ./public.key).
--provider-secretkey-file=<str>
Archivo de clave secreta del proveedor (por defecto: ./secret.key).
--crypt-secretkey-file=<str>
Archivo de clave secreta de cifrado (por defecto: ./crypt_secret.key).
--cert-file-expire-days=<int>
Días de expiración del archivo de certificado (por defecto: 365).
