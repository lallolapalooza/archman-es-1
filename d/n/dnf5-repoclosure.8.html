NOMBRE

dnf5-repoclosure - Comando Repoclosure

SINOPSIS

dnf5 repoclosure [opciones] [<espec-pkg>...]

DESCRIPCIÓN

El comando repoclosure te permite analizar los metadatos de paquetes de múltiples repositorios. Comprueba todas las dependencias de los paquetes y proporciona una lista de paquetes que tienen dependencias no resueltas.

Por defecto, repoclosure considera todos los repositorios habilitados al comprobar las dependencias. Sin embargo, puedes personalizar el conjunto de repositorios utilizando opciones estándar de DNF5 como --repo, --enable-repo o --disable-repo.

OPCIONES

--arch <arquitectura>
Consulta solo paquetes para la arquitectura especificada, se puede especificar varias veces (el valor predeterminado es todas las arquitecturas compatibles con tu sistema).
--best
Comprueba solo los paquetes más recientes por arquitectura.
--check=ID_REPO,...
Especifica los repositorios a comprobar, se puede especificar varias veces (el valor predeterminado es todos los repositorios habilitados).
Los valores aceptados son IDs de repositorio o un patrón de IDs.
--newest
Comprueba solo los paquetes más recientes en los repositorios.
<espec-pkg>
Comprueba la clausura solo para este paquete.

EJEMPLOS

dnf5 repoclosure
Muestra una lista de dependencias no resueltas para todos los repositorios habilitados.
dnf5 repoclosure --repo rawhide --arch noarch --arch x86_64
Muestra una lista de dependencias no resueltas para el repositorio rawhide y paquetes con arquitectura noarch y x86_64.
dnf5 repoclosure --repo rawhide zmap
Muestra una lista de dependencias no resueltas para el paquete zmap del repositorio rawhide.
dnf5 repoclosure --repo rawhide --check myrepo
Muestra una lista de dependencias no resueltas para myrepo, un complemento del repositorio rawhide.
