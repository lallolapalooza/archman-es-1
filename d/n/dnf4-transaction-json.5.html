NOMBRE

dnf4-transaction-json - JSON de transacción almacenado de DNF

El formato de transacción almacenado se considera inestable y puede cambiar de forma incompatible en cualquier momento. Funcionará si se utiliza la misma versión de dnf para almacenar y reproducir (o entre versiones siempre que se mantenga igual).

OBJETO DE NIVEL SUPERIOR

version
Tipo: cadena de texto

La versión del formato de transacción almacenado, en la forma MAJOR.MINOR.

MAJOR La versión denota cambios incompatibles hacia atrás (dnf antiguo no funcionará con el JSON de transacción nuevo).

MINOR La versión denota la extensión del formato sin romper la compatibilidad hacia atrás (dnf antiguo puede funcionar con el JSON de transacción nuevo).

rpms
Tipo: una matriz de objetos rpm

Una lista de paquetes RPM en la transacción.

groups
Tipo: una matriz de objetos de grupo

Una lista de grupos en la transacción.

environments
Tipo: una matriz de objetos de grupo

Una lista de grupos de entorno en la transacción.

OBJETO RPM

action
Tipo: cadena de texto

Valores posibles: Downgrade, Downgraded, Install, Obsoleted, Reason Change, Reinstall, Reinstalled, Removed, Upgrade, Upgraded

La acción realizada sobre el paquete en la transacción.

nevra
Tipo: cadena de texto

NEVRA (name-epoch:version-release.arch) del paquete.

reason
Tipo: cadena de texto

Valores posibles: dependency, clean, group, unknown, user, weak-dependency

La razón por la que el paquete fue incluido en la transacción.

repo_id
Tipo: cadena de texto

El id del repositorio del que proviene este paquete. Tenga en cuenta que los ids de repositorio se definen en la configuración local del repositorio y pueden diferir entre sistemas.

OBJETO DE GRUPO

action
Tipo: cadena de texto

Valores posibles: Install, Upgrade, Removed

La acción realizada sobre el grupo en la transacción.

id
Tipo: cadena de texto

El id del grupo.

package_types
Tipo: cadena de texto

Valores posibles: conditional, default, mandatory, optional

Los tipos de paquetes del grupo que serán instalados. Válido solo para la acción Install .

packages
Tipo: una matriz de objetos grupo-paquete

Los paquetes que pertenecen al grupo en la transacción.

OBJETO DE ENTORNO

action
Tipo: cadena de texto

Valores posibles: Install, Upgrade, Removed

La acción realizada sobre el grupo de entorno en la transacción.

id
Tipo: cadena de texto

El id del grupo de entorno.

package_types
Tipo: cadena de texto

Valores posibles: conditional, default, mandatory, optional

Los tipos de paquetes del grupo de entorno que serán instalados. Válido solo para la acción Install .

group
Tipo: una matriz de objetos grupo-entorno

Los grupos que pertenecen al entorno en la transacción.

OBJETO GRUPO-PAQUETE

installed
Tipo: booleano

Si el paquete se considera instalado como parte del grupo.

name
Tipo: cadena de texto

El nombre del paquete.

package_type
Tipo: cadena de texto

Valores posibles: conditional, default, mandatory, optional

El tipo de paquete en el grupo.

OBJETO GRUPO-ENTORNO

group_type
Tipo: cadena de texto

Valores posibles: mandatory, optional

El tipo de grupo en el entorno.

id
Tipo: cadena de texto

El id del grupo.

installed
Tipo: booleano

Si el grupo se considera instalado como parte del entorno.
