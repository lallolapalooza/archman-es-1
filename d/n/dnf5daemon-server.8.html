NOMBRE

dnf5daemon-server - Servicio de gestión de paquetes con una interfaz DBus

SINOPSIS

systemctl start dnf5daemon-server

DESCRIPCIÓN

dnf5daemon-server es la interfaz D-Bus para el gestor de paquetes libdnf5.

ARCHIVOS

Configuración de dnf5daemon-server
/etc/dnf/dnf5daemon-server.conf

Utilice la sección [main] para anular cualquier opción de configuración principal de DNF5. Consulte dnf5.conf(5), Opciones de configuración principales <#conf-main-options-label>.
