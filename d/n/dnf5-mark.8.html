NOMBRE

dnf5-mark - Comando Mark

SINOPSIS

dnf5 mark <subcomando> [opciones globales] [<id-grupo>] <especificaciones-paquete-NPFB>...

DESCRIPCIÓN

El comando mark en DNF5 se utiliza para cambiar la razón de los paquetes instalados definidos en los argumentos especificaciones-paquete-NPFB.

SUBCOMANDOS

usuario
Marca el paquete como instalado por el usuario.

Esto puede ser útil si algún paquete se instaló como una dependencia y se desea que permanezca en el sistema cuando se ejecute el comando remove junto con la opción de configuración clean_requirements_on_remove establecida en True.

dependencia
Marca el paquete como una dependencia.

Esto puede ser útil si usted como usuario no necesita un paquete específico. El paquete permanece instalado en el sistema, pero será eliminado cuando se ejecute el comando remove junto con la opción de configuración clean_requirements_on_remove establecida en True.

Debería usar esta operación en lugar del comando remove si no está seguro de si el paquete es un requisito de otro paquete instalado por el usuario en el sistema.

debil
Marca el paquete como una dependencia débil.
grupo
Marca el paquete como instalado por el grupo definido en el argumento id-grupo.

Esto puede ser útil si algún paquete se instaló como una dependencia o por el usuario y se desea protegerlo y tratarlo como un miembro del grupo, como durante el comando group remove.

OPCIONES

--skip-unavailable
Permite omitir los paquetes que no están instalados en el sistema. Todos los paquetes instalados restantes serán marcados.
--offline
Almacena la transacción para que se realice sin conexión. Consulte el comando offline <#offline-command-ref-label>, dnf5-offline(8).
--store=RUTA
Almacena la transacción actual en un directorio en la RUTA especificada en lugar de ejecutarla.
La transacción almacenada puede ser realizada por el comando replay <#replay-command-ref-label>, dnf5-replay(8).

EJEMPLOS

dnf5 mark user fuse-devel
Marca el paquete fuse-devel como instalado por el usuario.
dnf5 mark group xfce-desktop vim-enhanced
Marca el paquete vim-enhanced como instalado por el grupo xfce-desktop.
