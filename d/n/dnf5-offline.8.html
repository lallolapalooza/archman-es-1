NOMBRE

dnf5-offline - Comando sin conexión

SINOPSIS

dnf5 offline <subcomando> [opciones]

DESCRIPCIÓN

El comando offline se utiliza para gestionar transacciones "sin conexión", transacciones que se ejecutan cuando el sistema se inicia en un entorno mínimo. Ejecutar una transacción en este entorno reducido puede ser más seguro que ejecutarla cuando el sistema se inicia normalmente, ya que es menos probable que la transacción interfiera con los procesos en ejecución.

Las transacciones sin conexión se pueden iniciar especificando la bandera --offline en cualquier operación (install, upgrade, distro-sync, etc.), o a través de dnf5 system-upgrade download. Una vez iniciada una transacción sin conexión, ejecute dnf5 offline reboot para reiniciar y comenzar la transacción.

Los datos para las transacciones sin conexión se almacenan en el directorio "estado del sistema" en /usr/lib/sysimage/libdnf5/offline.

SUBCOMANDOS

clean
Elimina cualquier transacción sin conexión almacenada y borra los archivos de paquetes cacheados.
log
Se utiliza para ver una lista de reinicios durante los cuales se intentó una transacción sin conexión, o para mostrar los registros de un intento de transacción sin conexión. Los registros de uno de los reinicios se pueden ver especificando uno de los números de la primera columna con el argumento --number. Se pueden usar números negativos para numerar los reinicios de último a primero. Por ejemplo, log --number=-1 se puede usar para ver los registros de la última transacción sin conexión.
reboot
Prepara el sistema para realizar la transacción sin conexión y se reinicia para iniciar la transacción. Este comando solo se puede ejecutar después de que se haya iniciado una transacción sin conexión (por ejemplo, mediante dnf5 system-upgrade download).
status
Muestra el estado de la transacción sin conexión actual.
_execute
Ejecuta la transacción en el entorno sin conexión.

Advertencia:

Solo para uso interno. No está destinado a ser ejecutado por el usuario.

OPCIONES

--number=<número de reinicio>
Muestra el registro especificado por el número. Ejecute dnf5 offline log con --number primero para obtener una lista de registros de donde elegir.
Se utiliza con el subcomando log.
--poweroff
El sistema se apagará después de completar la transacción en lugar de reiniciarse. Si la transacción falló, el sistema se reiniciará en lugar de apagarse, incluso con esta bandera.
Se utiliza con el subcomando reboot.

ENTORNO

DNF_SYSTEM_UPGRADE_NO_REBOOT
Si está establecida, el sistema no será reiniciado ni apagado por DNF5 cuando el flujo de trabajo normal lo haría.

EJEMPLOS

dnf5 install --offline hello
Prepara la instalación del paquete hello como una transacción sin conexión.
dnf5 offline status
Muestra el estado de la transacción sin conexión actual.
dnf5 offline reboot --poweroff
Reinicia y ejecuta la transacción sin conexión, luego apaga el sistema después de que la transacción se complete.
dnf5 offline log
Lista los reinicios durante los cuales se intentó una transacción sin conexión.
dnf5 offline log --number=-1
Ver el registro del último reinicio durante el cual se intentó una transacción sin conexión.
