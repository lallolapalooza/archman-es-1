Nota: Aunque la mayoría de los siguientes métodos pueden ser invocados con éxito por un usuario normal, algunos de ellos requieren la autenticación de un usuario administrativo (por ejemplo, Goal.do_transaction(), Repo.confirm_key(), Repo.enable(), Repo.disable()). Esta autenticación se gestiona mediante la llamada al método CheckAuthorization() de la interfaz D-Bus de Polkit org.freedesktop.PolicyKit1.Authority. Para esta llamada se establece la bandera AllowUserInteraction, lo que indica que si hay un agente de autenticación disponible, la llamada se bloquea mientras

se solicita al usuario que se autentique. Se establece un tiempo
de espera fijo de 2 minutos para la interacción del usuario.

    interface org.rpm.dnf.v0.rpm.Rpm
    method list(a{sv} options) -> (aa{sv} packages)
    Arguments
    •
    options (a{sv}) -- an array of key/value pairs
    Returns
    •
    packages (aa{sv}) -- array of returned packages with requested attributes

    Get list of packages that match to given filters. Since the method returns packages directly in the D-Bus method reply message, which has a limited size, there is a possibility that the requested package set size would exceed this limit. If you request a large number of packages and/or a great number of package attributes, please consider using the list_fd() method.

    Following options and filters are supported:

    •
    package_attrs: list of strings
    list of package attributes that are returned. Supported attributes are name, epoch, version, release, arch, repo_id, from_repo_id, is_installed, install_size, download_size, buildtime, sourcerpm, summary, url, license, description, files, changelogs, provides, requires, requires_pre, conflicts, obsoletes, recommends, suggests, enhances, supplements, evr, nevra, full_nevra, reason, vendor, group.
    •
    with_nevra: bool (default true)
    match patterns against available packages NEVRAs
    •
    with_provides: bool (default true)
    match patterns against available packages provides
    •
    with_filenames: bool (default true)
    match patterns against names of the files in available packages
    •
    with_binaries: bool (default true)
    match patterns against names of the binaries in /usr/(s)bin in available packages
    •
    with_src: bool (default true)
    include source rpms into the results
    •
    icase: bool (default true)
    ignore case while matching patterns
    •
    patterns: list of strings
    any package matching to any of patterns is returned
    •
    scope: string (default "all")
    limit packages to one of "all", "installed", "available", "upgrades", "upgradable"
    •
    arch: list of strings
    limit the resulting set only to packages of given architectures
    •
    repo: list of strings
    limit the resulting set only to packages from given repositories
    •
    latest-limit: int
    limit the resulting set to only <limit> of latest packages for every name and architecture
    •
    whatprovides: list of strings
    limit the resulting set only to packages that provide any of given capabilities
    •
    whatdepends: list of strings
    limit the resulting set only to packages that require, enhance, recommend, suggest or supplement any of given capabilities
    •
    whatrequires: list of strings
    limit the resulting set only to packages that require any of given capabilities
    •
    whatrecommends: list of strings
    limit the resulting set only to packages that recommend any of given capabilities
    •
    whatenhances: list of strings
    limit the resulting set only to packages that enhance any of given capabilities
    •
    whatsuggests: list of strings
    limit the resulting set only to packages that suggest any of given capabilities
    •
    whatsupplements: list of strings
    limit the resulting set only to packages that supplement any of given capabilities
    •
    whatobsoletes: list of strings
    limit the resulting set only to packages that obsolete any of given capabilities
    •
    whatconflicts: list of strings
    limit the resulting set only to packages that conflict with any of given capabilities

    Unknown options are ignored.

método recent_changes(a{sv} opciones) -> (a{saa{sv}} changeset)
Argumentos
•
opciones (a{sv}) -- un array de pares clave/valor
Retorna
•
changeset (a{saa{sv}}) -- un diccionario {"<tipo_de_cambio>":[<paquete>,<paquete>,...]}

Obtener una lista de paquetes que han sido modificados recientemente. La clave "tipo_de_cambio" en el diccionario de salida puede ser uno de los siguientes: "installed", "removed", "upgraded", o "downgraded". Los paquetes en la salida se representan como diccionarios que contienen el conjunto de atributos solicitados para los paquetes modificados.

Para paquetes instalados, actualizados y degradados, se devuelve la versión actualmente instalada.

Para paquetes actualizados y degradados, también se incluye el atributo "original_evr", que contiene la EVR del paquete antes del cambio.

Si se solicita, los paquetes actualizados también pueden incluir un campo de lista "advisories", que indica el nombre de las actualizaciones que contienen la versión actualizada (es decir, actualmente instalada) del paquete. Si la opción "all_advisories" está activada, también se incluyen los avisos para todas las versiones entre la original y la actualmente instalada.

Para los paquetes eliminados, solo se proporcionan el nombre, la arquitectura y la EVR de la versión eliminada.

Se admiten las siguientes opciones y filtros:

•
upgraded_packages: booleano, por defecto "true"
Si se deben incluir los paquetes actualizados en la salida.
•
downgraded_packages: booleano, por defecto "true"
Si se deben incluir los paquetes degradados en la salida.
•
installed_packages: booleano, por defecto "true"
Si se deben incluir los paquetes instalados en la salida.
•
removed_packages: booleano, por defecto "true"
Si se deben incluir los paquetes eliminados en la salida.
•
include_advisory: booleano, por defecto "true"
Si se deben incluir "advisories" en los atributos de los paquetes actualizados.
•
all_advisories: booleano, por defecto "false"
Solo tiene sentido con include_advisory=true. Incluir también los avisos para todas las versiones entre la original y la actualmente instalada.
•
package_attrs: lista de cadenas, por defecto ["name", "summary", "evr", "arch"]
Lista de atributos de paquete que se devuelven para cada paquete modificado. Los atributos soportados son los mismos que en el método list() de la interfaz Rpm.
•
since: int64, marca de tiempo unix
Obtener cambios desde un punto en el tiempo dado.

Las opciones desconocidas se ignoran.
