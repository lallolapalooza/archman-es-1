DNSSEC_TOOLS(1) Manual de comandos generales DNSSEC_TOOLS(1)

NOMBRE

DNSSEC-Tools - Un conjunto de herramientas y bibliotecas para usar DNSSEC

DESCRIPCIÓN

El paquete DNSSEC-Tools contiene una amplia variedad de herramientas que son útiles para operadores de zonas, operadores de resolutores, operadores de red, desarrolladores de aplicaciones y usuarios finales de DNSSEC.

El mejor lugar para aprender sobre las herramientas que forman parte del paquete es el siguiente sitio web, que clasifica las herramientas según la audiencia prevista:

http://www.dnssec-tools.org/wiki/index.php/DNSSEC-Tools_Components

Además, asegúrese de consultar los tutoriales disponibles en:

http://www.dnssec-tools.org/wiki/index.php/Tutorials

LICENCIA

Las DNSSEC-Tools tienen licencia bajo una licencia BSD, cuyos detalles se pueden encontrar en el archivo COPYING que se encuentra dentro de la distribución.
