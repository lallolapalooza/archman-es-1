NOMBRE

dnf5-environment - Comando de entorno

SINOPSIS

dnf5 environment <subcomando> [opciones] [<especificación-entorno>...]

DESCRIPCIÓN

El comando environment en DNF5 ofrece varias consultas para obtener información sobre entornos y grupos relacionados con ellos. Puede instalar entornos con el comando install como install @id-entorno.

Se pueden pasar argumentos opcionales de especificación-entorno para filtrar solo los entornos con nombres dados.

SUBCOMANDOS

list
Lista los entornos disponibles.
info
Muestra detalles sobre los entornos.

OPCIONES

--available
Muestra solo los entornos disponibles. Aquellos que no están instalados, pero son conocidos por DNF5.
--installed
Muestra solo los entornos instalados.

EJEMPLOS

dnf5 environment list
Muestra una lista de todos los entornos.
dnf5 environment info "KDE Plasma Workspaces"
Muestra información detallada sobre el entorno KDE.
