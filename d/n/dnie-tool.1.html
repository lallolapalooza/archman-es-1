NOMBRE

dnie-tool - muestra información sobre tokens de seguridad basados en DNIe

SINOPSIS

dnie-tool [OPCIONES]

DESCRIPCIÓN

La utilidad dnie-tool se utiliza para mostrar información adicional sobre DNIe, el Documento Nacional de Identidad electrónico español.

OPCIONES

--idesp, -i

Muestra el valor IDESP del DNIe.

--data, -d

Muestra información personal del DNIe. Lee e imprime el número de DNIe y el Nombre y Apellidos del Usuario.

--all, -a

Muestra toda la información disponible. Este comando es equivalente a -d -i -V -s

--serial, -s

Muestra el Número de Serie del DNIe.

--version, -V

Muestra la versión del sw del DNIe. Muestra la versión del software del sistema operativo del DNIe en la tarjeta.

--pin pin, -p pin

Estas opciones se pueden usar para especificar el valor del PIN en la línea de comandos. Si el valor se establece en env:VARIABLE, se utiliza el valor de la variable de entorno especificada. Por defecto, se solicita el código en la línea de comandos si es necesario.

Tenga en cuenta que en la mayoría de los sistemas operativos, cualquier usuario puede mostrar la línea de comandos de cualquier proceso en el sistema utilizando utilidades como ps(1). Por lo tanto, debería preferir pasar los códigos a través de una variable de entorno en un sistema no seguro.

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--wait, -w

Hace que dnie-tool espere a que se inserte el token en el lector.

--verbose, -v

Hace que dnie-tool sea más verboso. Especifique esta bandera varias veces para habilitar la salida de depuración en la biblioteca opensc.
