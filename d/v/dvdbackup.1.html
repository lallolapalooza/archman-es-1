dvdbackup(1) Manual de comandos generales dvdbackup(1)

NOMBRE

dvdbackup - Herramienta para hacer copias de seguridad de DVDs

SINOPSIS

dvdbackup [OPCIÓN]...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando dvdbackup. Esta página del manual fue escrita para la distribución Debian porque el programa original no tiene una página del manual. dvdbackup es una herramienta para extraer datos de DVDs de vídeo. Tiene las ventajas de ser pequeño, rápido y fácil de usar.

OPCIONES

A continuación se incluye un resumen de las opciones.

-h, --help
muestra un breve mensaje de uso
-V, --version
muestra información de la versión
-I, --info
para obtener información sobre el DVD
-M, --mirror
hace una copia de seguridad de todo el DVD
-F, --feature
hace una copia de seguridad de la característica principal del DVD
-T X, --titleset=X
hace una copia de seguridad del conjunto de títulos X
-t X, --title=X
hace una copia de seguridad del título X
-s X, --start=X
hace una copia de seguridad desde el capítulo X
-e X, --end=X
hace una copia de seguridad hasta el capítulo X
-i DISPOSITIVO, --input=DISPOSITIVO
donde DISPOSITIVO es tu dispositivo de DVD. Esta opción solo necesita ser usada si el nodo de tu dispositivo de DVD no es /dev/dvd
-o DIRECTORIO, --output=DIRECTORIO
donde DIRECTORIO es tu destino de copia de seguridad. Si no se proporciona, se usará el directorio de trabajo actual.
-v, --verbose
muestra más información sobre el progreso
-n NOMBRE, --name=NOMBRE
(opcional) establece el título - útil si la autodetección falla
-a 0, --aspect=0
para obtener una relación de aspecto de 4:3 en lugar de 16:9 si ambas están presentes
-r {a,b,m}, --error={a,b,m}
selecciona el manejo de errores de lectura: a=abortar, b=saltar bloque, m=saltar bloques múltiples (por defecto)
-p, --progress
muestra información de progreso mientras se copian los VOBs

Notas sobre opciones

-a es una opción para el modificador -F y no tiene efecto en otras opciones
-s y -e preferiblemente deben usarse juntos con -t

Información general de copia de seguridad

Si tu directorio de copia de seguridad es /mi/dir/copia/seguridad/dvd/ especificado con la opción -o, entonces dvdbackup creará una estructura DVD-Video bajo /mi/dir/copia/seguridad/dvd/NOMBRE_DEL_TÍTULO/VIDEO_TS. Si se omite la opción -o, se usará el directorio actual.

Dado que el título es "único", puedes usar el mismo directorio para todas tus copias de seguridad de DVD. Si resulta tener un título genérico, dvdbackup saldrá con un valor de retorno de 2, y necesitarás especificar un nombre de título con la opción -n.

dvdbackup siempre imitará la estructura original de DVD-Video. Por lo tanto, si, por ejemplo, usas -M (mirror), obtendrás un duplicado exacto del original. Esto significa que cada archivo tendrá el mismo tamaño que el original. Lo mismo ocurre con las opciones -F y -T.

Sin embargo, la opción -t y (-t -s/-e) es un poco diferente; los sectores de título se escribirán en el archivo original pero no en el mismo desplazamiento que el original, ya que puede haber huecos en la estructura de celdas que no llenamos.

EJEMPLOS

dvdbackup -I
recopila información sobre el DVD. /dev/dvd es el dispositivo predeterminado que se intenta; necesitas usar -i si el nombre de tu dispositivo es diferente.
dvdbackup -M
realiza una copia de seguridad de todo el DVD. Esta acción crea una estructura DVD-Video válida que se puede grabar en un DVD-/+R(W) con la ayuda de genisoimage.
dvdbackup -F
realiza una copia de seguridad de la característica principal del DVD. Esta acción crea una estructura DVD-Video válida del conjunto de títulos de la característica. Ten en cuenta que esto no resultará en una imagen visible inmediatamente; necesitarás otro programa como dvdauthor para ayudar a construir los archivos IFO.

dvdbackup, por defecto, obtiene la versión 16:9 de la característica principal si también hay una versión 4:3 en el DVD. Para obtener la versión 4:3 usa -a 0.

dvdbackup hace todo lo posible para hacer una suposición inteligente sobre cuál es la característica principal del DVD; en caso de fallo, por favor, envía un informe de error.

dvdbackup -T 2
realiza una copia de seguridad del conjunto de títulos 2, es decir, todos los archivos VTS_02_X.XXX. Esta acción crea una estructura DVD-Video válida del conjunto de títulos especificado. Ten en cuenta que esto no resultará en una imagen visible inmediatamente; necesitarás otro programa como dvdauthor para ayudar a construir los archivos IFO.
dvdbackup -t 1
realiza una copia de seguridad del título 1. Esta acción realiza una copia de seguridad de todas las celdas que forman el título especificado. Ten en cuenta que puede haber huecos de sectores entre una celda y otra. dvdbackup realizará una copia de seguridad de todos los sectores que pertenecen al título, pero omitirá los sectores que no forman parte del título.
dvdbackup -t 1 -s 20 -e 25
Esta acción realizará una copia de seguridad de los capítulos 20 a 25 del título 1; al igual que con la copia de seguridad de un título, puede haber huecos de sectores entre un capítulo (celda) y otro. dvdbackup realizará una copia de seguridad de todos los sectores que pertenecen al título 1, capítulos 20 a 25, pero omitirá los sectores que no forman parte del título 1, capítulos 20 a 25.

Para hacer una copia de seguridad de un solo capítulo, por ejemplo, el capítulo 20, haz -s 20 -e 20.
Para hacer una copia de seguridad desde el capítulo 20 hasta el último capítulo, usa solo -s 20.
Para hacer una copia de seguridad hasta el capítulo 20 desde el primer capítulo, usa solo -e 20.

Puedes omitir la opción -t y dejar que el programa adivine el título, aunque no se recomienda.

Si especificas un capítulo que es mayor que el último capítulo del título, dvdbackup truncará al capítulo más alto del título.

ESTADO DE SALIDA

0
en caso de éxito
1
en caso de error de uso
2
en caso de error en el nombre del título
-1
en caso de fallo

dvdbackup - copia el contenido de un DVD a un disco duro.

SYNOPSIS

dvdbackup [-M|-I|-N|-c|-C|-l|-p] [-F] [-d directorio] [-o directorio] [-n nombre] [-a ángulo] [-b tamaño_buffer] [-m] [-r] [-v] [-h]

DESCRIPTION

dvdbackup es una utilidad para copiar el contenido de un DVD a un disco duro. Los datos se guardan en un archivo en el disco duro. La imagen se puede volver a grabar en un DVD más tarde utilizando cualquier programa de grabación de DVD.

dvdbackup puede operar en dos modos:

  • Modo de copia: Copia el contenido de un DVD al disco duro. El DVD se lee en su totalidad, sin importar su tamaño.

  • Modo de información: Muestra información sobre el DVD en el dispositivo.

Ambos modos se seleccionan utilizando las opciones -M, -I, -N, -c, -C, -l, o -p.

OPTIONS

A continuación se describen las opciones disponibles:

  • -M, --mount: Monta el DVD en el directorio especificado por la opción -d. Si no se especifica ningún directorio, se utiliza el valor predeterminado (/media/cdrom).

  • -I, --info: Muestra información sobre el DVD en el dispositivo. El DVD debe estar insertado.

  • -N, --no-mount: Desmonta el DVD del directorio especificado por la opción -d. Si no se especifica ningún directorio, se utiliza el valor predeterminado (/media/cdrom).

  • -c, --copy: Copia el contenido del DVD al disco duro. El DVD se lee en su totalidad, sin importar su tamaño. La imagen se guarda en el directorio especificado por la opción -o y con el nombre especificado por la opción -n. Si no se especifican estos directorios/nombres, se utilizan los valores predeterminados.

  • -C, --copy-and-no-mount: Copia el contenido del DVD al disco duro y luego lo desmonta. Similar a la opción -c, pero desmonta el DVD después de la copia.

  • -l, --list: Lista los títulos del DVD en el dispositivo. El DVD debe estar insertado.

  • -p, --print-filenames: Imprime los nombres de los archivos del DVD en el dispositivo. El DVD debe estar insertado.

  • -F, --force: Fuerza la copia, incluso si el DVD ya ha sido copiado. Esto sobrescribirá el archivo existente.

  • -d directorio, --device-dir directorio: Especifica el directorio donde se encuentra el dispositivo DVD. El valor predeterminado es /media/cdrom.

  • -o directorio, --output-dir directorio: Especifica el directorio donde se guardará el archivo de imagen del DVD. El valor predeterminado es el directorio actual.

  • -n nombre, --name nombre: Especifica el nombre del archivo de imagen del DVD. Si no se especifica, se utiliza el nombre del volumen del DVD.

  • -a ángulo, --angle ángulo: Especifica el ángulo de la cámara para la copia de películas multiángulo. El valor predeterminado es 1.

  • -b tamaño_buffer, --buffer-size tamaño_buffer: Especifica el tamaño del búfer de lectura en MB. El valor predeterminado es 1024.

  • -m, --mirror: Crea una imagen de espejo del DVD. Esto crea un archivo que es una copia exacta del contenido del DVD, incluyendo la estructura de directorios.

  • -r, --recursive: Copia el contenido del DVD de forma recursiva. Esto es útil para copiar DVD de datos.

  • -v, --verbose: Muestra información detallada sobre el proceso de copia.

  • -h, --help: Muestra un mensaje de ayuda y sale.

Option notes

Las opciones -M, -I, -N, -c, -C, -l, y -p son mutuamente excluyentes. Solo se puede especificar una de ellas.

Las opciones -F, -d, -o, -n, -a, -b, -m, -r, -v se pueden combinar con las opciones -M, -I, -N, -c, -C, -l, y -p.

General backup information

Antes de copiar un DVD, asegúrese de que el dispositivo DVD esté montado correctamente. Si no lo está, puede montarlo manualmente o utilizar la opción -M.

Para copiar un DVD, utilice la opción -c. Especifique el directorio de salida con -o y el nombre del archivo con -n si lo desea. Si no se especifica, se utilizarán los valores predeterminados.

Para crear una imagen de espejo del DVD, utilice la opción -m junto con -c.

Para copiar DVD de datos de forma recursiva, utilice la opción -r junto con -c.

EXAMPLES

Copiar un DVD al directorio actual con el nombre del volumen del DVD:

dvdbackup -c

Copiar un DVD al directorio /mnt/backups con el nombre my_dvd.iso:

dvdbackup -c -o /mnt/backups -n my_dvd.iso

Crear una imagen de espejo de un DVD en el directorio /mnt/backups:

dvdbackup -c -m -o /mnt/backups

Listar los títulos de un DVD:

dvdbackup -l

Mostrar información sobre un DVD:

dvdbackup -I

Montar un DVD en /media/dvd:

dvdbackup -M -d /media/dvd

Desmontar un DVD de /media/dvd:

dvdbackup -N -d /media/dvd

EXIT STATUS

dvdbackup devuelve 0 si la operación se realizó correctamente, y un valor distinto de cero si ocurrió un error.
