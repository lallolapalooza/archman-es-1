DVIPDFMX(1) Manual de Comandos Generales DVIPDFMX(1)

NOMBRE

dvipdfmx, xdvipdfmx, dvipdfm - produce archivos PDF directamente desde archivos DVI

SINOPSIS

dvipdfmx o dvipdfm [opciones] archivo[.dvi]

DESCRIPCIÓN

El programa dvipdfmx genera un archivo PDF a partir de un archivo DVI. Los archivos DVI son la salida producida por TeX. groff también puede generar archivos DVI usando grodvi(-Tdvi).

En TeX Live, dvipdfm es otra encarnación de dvipdfmx en lugar de un programa separado. Se intenta la compatibilidad en la medida de lo posible.

xdvipdfmx es otra encarnación. Se utiliza como backend para xetex(1) y no está destinado a ser invocado directamente.

dvipdfmx reconoce varios comandos \special comúnmente utilizados, que son extensiones al formato DVI. Específicamente, entiende especiales de color, especiales de tamaño de papel, especiales de tpic (que le permiten ser utilizado con pic), especiales de hypertex y algunos especiales de PostScript. Estas extensiones permiten que los documentos contengan color, figuras y enlaces (hipervínculos). El programa intenta imitar el comportamiento de dvips siempre que sea posible, de modo que muchos paquetes de macros producidos para ser utilizados con dvips también funcionarán con dvipdfmx. Además, dvipdfmx entiende sus propios comandos \special específicos para permitir el acceso a funciones de PDF tales como anotaciones y marcadores.

A partir de diciembre de 2018, un especial específico de dvipdfmx es pdf:trailerid, que especifica el /ID en el trailer de PDF. Se utiliza de la siguiente manera (desde el nivel TeX):
\special{pdf:trailerid [ (0123456789abcdef) (01234567890abcdef) ]}
Es decir, el especial toma un array (los corchetes) de dos cadenas PDF de 16 bytes (los paréntesis). Esta es la misma sintaxis que \pdfvariable trailerid de LuaTeX, mientras que es diferente de \pdftrailerid de pdfTeX. Debe aparecer en la primera página de salida, de lo contrario se ignora.

Los especiales no reconocidos generarán mensajes de advertencia. Los paquetes que puedan necesitar una opción de driver dvipdfm o dvipdfmx incluyen geometry, hyperref, bookmark, graphicx y xcolor.

Para problemas relacionados con los cuadros delimitadores (y por lo tanto, los tamaños de imagen), consulte extractbb(1).

OPCIONES

A diferencia de muchos otros programas, los valores de los argumentos deben separarse de los nombres de las opciones por un espacio, no por un signo =; los nombres de las opciones no se pueden abreviar; y - y -- no se pueden intercambiar.

-c
Ignorar (o aceptar) los \specials de color. Por defecto, los \specials de color se interpretan normalmente (se puede cambiar en el archivo de configuración). La opción -c puede utilizarse para producir un documento en blanco y negro a partir de un documento que contiene comandos \special de TeX en color.
--dvipdfm
Habilita el modo de emulación dvipdfm. Este es el valor predeterminado si el nombre del ejecutable es `dvipdfm'.
-d number
Especifica el número de dígitos decimales en la salida PDF; debe estar entre 0 y 5, el valor predeterminado es 2.
-e
Ignorado, para compatibilidad (semi-) con dvipdfm.
-f map_file
Lee el archivo de mapa de fuentes dado por map_file. El archivo de mapa predeterminado en TeX Live es pdftex.map, como se define en el archivo de configuración.
--help
Muestra un mensaje de ayuda y sale con éxito.
-i cfgfile
Lee cfgfile como otro archivo de inclusión, después de leer el archivo predeterminado dvipdfmx.cfg.
--kpathsea-debug number
Hace que Kpathsea muestre información de depuración; `-1' para todo (voluminoso).
-l
Selecciona el modo horizontal (landscape). En otras palabras, intercambia las dimensiones x e y del papel.
-m mag
Magnifica el documento de entrada por mag.
-o filename
Establece el nombre del archivo de salida PDF; usa `-` para la salida estándar. Por defecto, el nombre del archivo de salida se deriva de la entrada, es decir, archivo.pdf.
-p paper
Selecciona el tamaño del papel por nombre (por ejemplo, letter, legal, ledger, tabloid, a3, a4, o a5 )
--pdfm-str-utf8
Asume que las cadenas PDFMark en los comandos \special están codificadas en UTF-8.
-q
Modo silencioso.
-r size
Establece la resolución de las fuentes de mapa de bits a size puntos por pulgada. Las fuentes de mapa de bits son generadas por la biblioteca Kpathsea, que utiliza Metafont. Las fuentes de mapa de bits se incluyen como fuentes de Tipo 3 en el archivo de salida PDF. El valor predeterminado es 600.
-s page_specifications
Selecciona las páginas del archivo DVI a procesar; el valor predeterminado es `-`, lo que significa todas las páginas. Las page_specifications consisten en una lista separada por comas de page_ranges: 
page_specifications := page_specification[,page_specifications]
donde 
page_specification := single_page|page_range
page_range := [first_page]-[last_page]
Una first_page vacía se trata como la primera página del archivo DVI, y una last_page vacía se trata como la última página del archivo DVI.

Ejemplos:

-s 1,3,5
incluye las páginas 1, 3 y 5;
-s -
incluye todas las páginas;
-s -,-
incluye dos copias de todas las páginas del archivo DVI; y
-s 1-10
incluye las primeras diez páginas del archivo DVI.
-t
Busca imágenes en miniatura de cada página en el directorio denominado por la variable de entorno TMPDIR. Las imágenes en miniatura deben nombrarse con un formato específico: el mismo nombre base que el archivo DVI y el número de página como extensión del nombre de archivo. dvipdfmx no genera dichas miniaturas por sí mismo, pero se distribuye con un programa envoltorio llamado dvipdft que sí lo hace.
--version
Muestra un mensaje de ayuda y sale con éxito.
-v
Aumenta la verbosidad. Los resultados de la opción -v son acumulativos (por ejemplo, -vv aumenta la verbosidad en dos incrementos). La verbosidad máxima es cuatro.
-x x_offset
Establece el margen izquierdo a x_offset. El margen izquierdo predeterminado es 1.0in. La dimensión se puede especificar en cualquier unidad entendida por TeX (por ejemplo, bp, pt, in, cm).
-y y_offset
Establece el margen superior a y_offset. El margen superior predeterminado es 1.0in. La dimensión se puede especificar en cualquier unidad entendida por TeX (por ejemplo, bpt, pt, in, cm).
-z number
Establece el nivel de compresión a compression_level. Los niveles de compresión varían de 0 (sin compresión) a 9 (compresión máxima) y corresponden a los valores entendidos por zlib; el valor predeterminado es 9.
-C number
Marcas de opción misceláneas; consulte la salida de --help para obtener detalles.
-D template
Plantilla de línea de comandos de conversión de PostScript a PDF; el valor predeterminado se toma del archivo de configuración, que también proporciona todos los detalles y menciona varias posibilidades.
-E
Intenta siempre incrustar fuentes, ignorando las licencias, etc.
-I number
Tiempo de vida de la caché de imágenes en horas; el valor predeterminado es -2, lo que significa no cachear imágenes en absoluto. Un valor de -1 significa borrar todas las imágenes antiguas y al
así que nuevas imágenes; 0 significa borrar todas las imágenes antiguas pero dejar las nuevas imágenes.
-K número
Longitud de clave de cifrado; predeterminado 40.
-M
Procesar la salida PostScript de MetaPost.
-O número
Establecer la profundidad máxima de los elementos de marcador abiertos; predeterminado 0.
-P número
Establecer los indicadores de permiso para el cifrado PDF; predeterminado 0x003C.
-S
Habilitar el cifrado PDF.
-V número
Establecer la versión menor del PDF; predeterminado 5 (desde el archivo de configuración).

CAJAS DE CONTENIDO DE IMÁGENES

Al incluir imágenes con dvipdfmx, sus cajas de contenido deberían generarse ejecutando extractbb. El resultado estará en un archivo .xbb ; la información xbb es la misma que para el formato PDF.

ENTORNO

dvipdfmx utiliza la biblioteca kpathsea para localizar los archivos que abre. Por lo tanto, las variables de entorno documentadas en la documentación de la biblioteca Kpathsea influyen en dvipdfmx. También utiliza el valor de la variable de entorno TMPDIR como el directorio para buscar miniaturas de cada página.

ARCHIVOS

La ubicación precisa de los siguientes archivos está determinada por la configuración de la biblioteca Kpathsea . La ubicación puede determinarse usando kpsewhich, por ejemplo,

kpsewhich -progname=dvipdfmx -format='other text files' dvipdfmx.cfg
dvipdfmx.cfg
Archivo de configuración predeterminado
dvipdfmx-unsafe.cfg
Archivo de configuración que ejecuta Ghostscript sin comprobaciones de seguridad; úselo solo con archivos fuente de confianza. Actualmente es necesario para usar PSTricks con XeTeX: xetex -output-driver="xdvipdfmx -i dvipdfmx-unsafe.cfg -q -E" ...
pdftex.map
El archivo de mapa de fuentes predeterminado (esto puede cambiarse en el archivo de configuración).
*.tfm
Métricas de fuentes TeX
*.vf
Archivos de fuentes virtuales TeX
*.pfb
Archivos de fuentes PostScript Type 1
texmf.cnf
El archivo de configuración de la biblioteca Kpathsea. La ubicación de este archivo puede encontrarse escribiendo 
kpsewhich texmf.cnf
