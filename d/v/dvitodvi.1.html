DVITODVI(1) Manual de Comandos Generales DVITODVI(1)

NOMBRE

dvitodvi - reorganiza páginas en un archivo DVI

SINOPSIS

dvitodvi [ -q ] [ -i archivo_entrada ] [ -o archivo_salida ] [ -wancho ] [ -halto ] especificaciones_paginas [ archivo_entrada [ archivo_salida ] ]

DESCRIPCIÓN

Dvitodvi reorganiza páginas de un archivo DVI, creando un nuevo archivo DVI. Dvitodvi puede usarse para realizar un gran número de reorganizaciones arbitrarias de documentos, incluyendo la disposición para impresión 2-en-1, 4-en-1, folletos, inversión, selección de caras delanteras o traseras de documentos, escalado, etc.

Las especificaciones_paginas siguen la sintaxis:

especificaciones_paginas
= [modulo:][mag@]specs
specs
= spec[+specs][,specs]
spec
= [-]num_pagina[(xoff,yoff)]

modulo es el número de páginas en cada bloque. El valor de modulo debe ser mayor que 0; el valor por defecto es 1. El parámetro opcional mag ajusta la magnificación del archivo por la magnificación especificada. La magnificación y el módulo pueden especificarse en orden inverso si se desea. Las specs son las especificaciones de página para las páginas en cada bloque. El valor de num_pagina en cada spec debe estar entre 0 (para la primera página del bloque) y modulo-1 (para la última página de cada bloque) inclusive. Las dimensiones opcionales xoff y yoff desplazan la página la cantidad especificada (positiva). xoff e yoff están en puntos de PostScript, pero pueden ir seguidos de las unidades cm o in para convertir a centímetros o pulgadas, o el indicador w o h para especificar como múltiplo del ancho o alto. Si se especifica el signo menos opcional, la página es relativa al final del documento, en lugar del inicio.

Si las especificaciones_pagina están separadas por +, las páginas se fusionarán en una sola página; si están separadas por , estarán en páginas separadas. Si solo hay una especificación de página, con num_pagina cero, se puede omitir num_pagina.

La opción -w proporciona el ancho que se utiliza para el especificador de dimensión w, y la opción -h proporciona el alto que se utiliza para el especificador de dimensión h. Estas dimensiones también se utilizan (después de escalar) para establecer la ruta de recorte para cada página.

Dvitodvi normalmente imprime los números de página de las páginas reorganizadas; la opción -q suprime esto.

EJEMPLOS

Esta sección contiene algunos ejemplos de reorganización. Para poner dos páginas en una hoja (de papel A3 apaisado), la especificación de página a utilizar es:

2:0+1(21cm,0)

Para reducir una página A3 a tamaño A4, la especificación de página a utilizar es:

700@(-.3in,-.3in)

Para seleccionar todas las páginas impares en orden inverso, use:

2:-0

ERRORES

Dvitodvi no ajusta algunos de los parámetros en el postámbulo. Esto puede ser un problema si estos valores se utilizan para dimensionar ciertas estructuras en los programas de conversión de salida.
