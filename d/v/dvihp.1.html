DVIHP(1) Manual de Comandos Generales DVIHP(1)

NOMBRE

dvihp - convertir un archivo DVI de TeX a PCL de Hewlett-Packard

SINOPSIS

dvihp [opciones] archivo.dvi[.dvi]

DESCRIPCIÓN

dvihp traduce el archivo.dvi dado a PCL de Hewlett-Packard usando dvicopy(1) y luego $DVILJ (dvilj4 por defecto).

En ausencia de otras opciones, canaliza el PCL a $SPOOL (lpr por defecto).

OPCIONES

Las opciones se reconocen de dvips siempre que sea posible:

-A
imprimir páginas impares
-B
imprimir páginas pares
-d n
establecer bits de depuración a n (ver documentación)
-D n
establecer la resolución a n
-f
ejecutar como filtro
-l n
no imprimir páginas después de n
-m
alimentación manual
-n n
imprimir n páginas
-O a,b
establecer/cambiar el desplazamiento del papel a a,b mm.
-o s
salida a s en lugar de encolar
-p n
no imprimir páginas antes de n.
-Ps
pasar directamente a lpr.
-v
operación detallada.
-x n
establecer la magnificación a n.
--help
escribir resumen de uso.

Otras opciones se pasan al programa dvilj.

ERRORES

Envía informes de errores por correo electrónico a tex-k@tug.org.

VER TAMBIÉN

dvicopy(1), dvilj4(1).
