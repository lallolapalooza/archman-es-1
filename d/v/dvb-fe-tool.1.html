dvb-fe-tool(1) Comandos de usuario dvb-fe-tool(1)

NOMBRE

dvb-fe-tool - Herramienta DVBv5 para inspeccionar/cambiar la configuración del frontend

SINOPSIS

dvb-fe-tool [OPCIÓN]...

DESCRIPCIÓN

dvbv5-fe-tool es una herramienta de línea de comandos para servicios de televisión digital que es compatible con la versión 5 de la API DVB, y compatible hacia atrás con la API DVB v3 más antigua.

dvb-fe-tool es una herramienta para inspeccionar y cambiar los parámetros de sintonía directamente en el frontend de televisión digital. Si se llama sin ningún parámetro, mostrará las capacidades del dispositivo.

OPCIONES

Las siguientes opciones son válidas:
-3, --dvbv3
Usar solo DVBv3
-a, --adapter=ADAPTADOR
Adaptador de televisión digital a usar. Predeterminado: 0.
-A, --acoustical
emite pitidos si la calidad de la señal es buena. También habilita el modo femon. Tenga en cuenta que el pitido de la consola debe estar habilitado en su gestor de ventanas.
-d, --set-delsys=PARÁMS
Establece el sistema de entrega al especificado en PARÁMS. use help para mostrar todos los sistemas de entrega soportados.
-f, --frontend=FRONTEND
Frontend de televisión digital a usar. Predeterminado: 0.
-g, --get
Obtiene los parámetros del frontend.
-m, --femon
Monitorea el estado de bloqueo del frontend y las estadísticas disponibles para un frontend que ya está transmitiendo vía alguna otra aplicación. Esto abre el frontend en modo de solo lectura.
-v, --verbose
Habilita mensajes de depuración.
-?, --help
Muestra la ayuda de uso.
--usage
Da un mensaje de uso corto.
-V, --version
Imprime la versión del programa.

ESTADO DE SALIDA

En caso de éxito, devuelve 0.

EJEMPLOS

Mostrando las capacidades del dispositivo

Este es el comportamiento predeterminado. Abrirá el frontend y mostrará qué capacidades soporta y cuál es la versión de la API DVB.

Estableciendo el sistema de entrega

Algunos dispositivos (como el ejemplo anterior) soportan múltiples sistemas de entrega. Las aplicaciones DVB más antiguas podrían no ser capaces de cambiar de un sistema de entrega a otro, ya que esta función se añadió solo en la versión 5.5 de la API DVB.

Esta función permite usar esas aplicaciones heredadas.

$ dvb-fe-tool -d dvbc/annex_c
Cambiando el sistema de entrega a: DVBC/ANNEX_C

Obteniendo la configuración actual del frontend

La herramienta también puede usarse para obtener la configuración actual. En este caso, abrirá el frontend en modo de solo lectura, permitiendo que se llame mientras alguna otra aplicación de televisión digital se está ejecutando.

$ dvb-fe-tool -g
FREQUENCY = 573000000
MODULATION = QAM/256
INVERSION = AUTO
SYMBOL_RATE = 5217000
INNER_FEC = NONE
DELIVERY_SYSTEM = DVBC/ANNEX_A

Monitoreando el frontend

El dvb-fe-tool también puede usarse para monitorear las estadísticas de un frontend DVB sin tocar el dispositivo, usando el parámetro --femon (o -m). El uso típico es poder leer las estadísticas mientras algún otro programa o aplicación DVB está en uso.

En este modo, seguirá imprimiendo las estadísticas del frontend cada segundo, hasta que el programa se aborte con CTRL-C:

Por ejemplo, mientras dvbv5-zap está sintonizando algún canal, producirá:

$ dvb-fe-tool --femon
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.40dB UCB= 370 postBER= 28.0x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.80dB UCB= 370 postBER= 25.3x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.30dB UCB= 370 postBER= 25.7x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.30dB UCB= 370 postBER= 28.4x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.50dB UCB= 370 postBER= 26.5x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.50dB UCB= 370 postBER= 26.9x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.20dB UCB= 370 postBER= 28.6x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.70dB UCB= 370 postBER= 26.7x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.80dB UCB= 370 postBER= 23.3x10^-6 PER= 0
Lock   (0x1f) Quality= Good Signal= 100.00% C/N= 36.50dB UCB= 370 postBER= 26.7x10^-6 PER= 0

Si el dispositivo de error estándar es la consola, los mensajes se colorearán de acuerdo con la calidad de la señal.

Los tipos y unidades de estadísticas presentados dependerán de los que soporte el hardware que esté usando. Por lo tanto, pueden variar de un hardware a otro.

En este modo, también soporta emitir una señal audible si la calidad es buena, usando el parámetro '-A'.

Tenga en cuenta que, en sistemas Linux modernos, el audio del sistema debe estar habilitado en su gestor de ventanas y el tema de audio debe estar configurado para producir un audio cuando se envía BELL (carácter) a la terminal.

NOTA:

C/N en las estadísticas anteriores significa relación Portadora a Ruido. Esta es la relación Señal a Ruido medida en la portadora piloto o simplemente la relación Señal a Ruido para tipos de modulación donde solo se usa una portadora, como DVB-C o DVB-S.
