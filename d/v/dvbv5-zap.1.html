dvbv5-zap(1) Comandos de usuario dvbv5-zap(1)

NOMBRE

dvbv5-zap - Herramienta DVBv5 para sintonizar servicios

SINOPSIS

dvbv5-zap [OPCIÓN]... nombre-canal

dvbv5-zap [OPCIÓN]... nombre-frecuencia (para modo monitor o todos los PID)

DESCRIPCIÓN

dvbv5-zap es una herramienta de línea de comandos para sintonizar servicios de TV digital que cumple con la versión 5 de la API DVB y es compatible con versiones anteriores de la API DVB v3.

dvbv5-zap utiliza por defecto un nuevo formato de archivo de canal/servicio que es capaz de soportar todos los tipos de estándares de TV digital. También puede soportar el formato heredado utilizado por las aplicaciones heredadas de dvb-apps.

La herramienta dvbv5-zap puede utilizarse en varios modos diferentes, dependiendo de los parámetros utilizados.

Tenga en cuenta que, para poder utilizarlo en modo de grabación, donde tanto los ID de paquete (PID) de audio como de video se envían a un nodo de registro dvr, el archivo de entrada debe contener los PID; es decir, deben haber sido producidos por una aplicación de zap de TV digital como dvbv5-zap.

OPCIONES

-c, --canales= archivo-nombre-canal
Lee la lista de canales del 'archivo'. Por defecto es ~/.tzap/channels.conf.
-3, --dvbv3
Fuerza a dvbv5-zap a usar solo DVBv3. Útil para probar si el soporte de la API heredada está funcionando.
-a, --adaptador=adaptador#
Usa el adaptador dado. Valor por defecto: 0.
-A, --pid_audio=pid_audio#
Selecciona un ID de paquete (PID) de audio diferente. Por defecto se utiliza el primer PID de audio encontrado en el archivo-nombre-canal.
-C, --cc=codigo_pais
Establece el país por defecto que utilizarán los analizadores MPEG-TS, en código de dos letras ISO 3166-1. Si no se especifica, el conjunto de caracteres por defecto se adivina a partir de las variables de entorno de la configuración regional.
-d, --demux=demux#
Utiliza el demultiplexor dado. Valor por defecto: 0.
-f, --frontend=frontend#
Utiliza el frontend dado. Valor por defecto: 0.
-I, --formato-entrada=formato
Formato del archivo de entrada. Tenga en cuenta que las capacidades se ignoran. Puede ser:
canal - para archivo de canal compatible con dvb-apps;

zap - para archivo zap compatible con dvb-apps;

dvbv5 (por defecto) - para el formato de aplicaciones dvbv5.

-l, --lnbf=tipo_LNBf
Tipo de LNBf a utilizar. 'help' muestra los disponibles.
-L, --buscar=cadena
Busca una cadena dentro del tráfico. Solo se utiliza en modo monitor.
-m, --monitor
Habilita el modo monitor. En este modo, monitorizará el tráfico DVB de todos los ID de paquete (PID) recibidos por el dispositivo, mostrando los ID de paquete (opcionalmente filtrados por una cadena), y presentando algunas estadísticas de tráfico: número de paquetes por segundo, número de Kbytes por segundo y tráfico total. Estas estadísticas se muestran por PID y el total por MPEG-TS.
-o, --salida=archivo
Nombre del archivo de salida. Si se especifica, emitirá el contenido del MPEG-TS al archivo con el primer PID de video y el primer PID de audio (o el especificado por pid_audio#). Use -o - para dirigir la salida a stdout.
-p, --pat
Agrega tablas PAT y PMT de MPEG-TS a la grabación TS (implica -r).
-P, --todos-pids
No filtra ningún PID. En su lugar, emite todos.
-r, --grabar
Configura la interfaz /dev/dvb/adapteradaptador#/dvr0 para grabación MPEG-TS.
-s, --silencio
Aumenta el silencio (se puede usar más de una vez).
-S, --numero_satelite=numero_satelite
Número de satélite. Solo se utiliza en sistemas de entrega por satélite. Si no se especifica, deshabilita el conmutador de satélite DISEqC.
-t, --tiempo-espera=segundos
Cantidad de segundos que se mantendrá la herramienta en funcionamiento para sintonizar y grabar. Útil si desea grabar un programa cuya duración conoce.
-U, --freq_bpf=frecuencia
Frecuencia del filtro paso banda SCR/Unicable a utilizar, en kHz. Solo se utiliza en sistemas de entrega por satélite.
-v, --detallado
Sea detallado. Útil para comprobar si el MPEG-TS está funcionando correctamente. Esta opción se puede usar varias veces para aumentar la verbosidad.
-V, --pid_video=programa_pid_video#
Programa PID de video a utilizar (por defecto 0)
-w, --lna=LNA
Habilita, deshabilita o pone la alimentación LNA en modo automático. No todos los frontends lo soportan. Los valores válidos son:

0 - deshabilitar

1 - habilitar
-1 - automático
-W, --esperar=tiempo
Añade tiempo de espera adicional para completar el comando DISEqC.
-x, --salir
Salir después de sintonizar.
-X, --bajo_trafico
También muestra tráfico DVB con menos de 1 paquete por segundo. Solo se utiliza en modo monitor.
-?, --ayuda
Muestra la ayuda de uso.
--uso
Da un mensaje corto de uso.
--version
Imprime la versión del programa.

ESTADO DE SALIDA

En caso de éxito, devuelve 0.

EJEMPLOS

Grabar un canal

El uso típico es sintonizar un canal y ponerlo en modo de grabación:

$ dvbv5-zap -c dvb_channel.conf 'music' -r
using demux '/dev/dvb/adapter0/demux0'
reading channels from file 'dvb_channel.conf'
service has pid type 05: 204
tuning to 573000000 Hz
audio pid 104
dvb_set_pesfilter 104
Lock (0x1f) Quality= Good Signal= 100.00% C/N= -13.80dB UCB= 70 postBER= 3.14x10^-3 PER= 0
DVR interface '/dev/dvb/adapter0/dvr0' can now be opened

El canal se puede ver reproduciendo el contenido de la interfaz DVR, con algún reproductor que reconozca el formato MPEG-TS.

Por ejemplo, este canal solo de audio se puede reproducir con mplayer:

$ mplayer -cache 800 /dev/dvb/adapter0/dvr0

Monitorear un canal

La herramienta dvbv5-zap también se puede utilizar para monitorear un canal DVB:

$ dvbv5-zap -c dvb_channel.conf 573000000 -m
using demux '/dev/dvb/adapter0/demux0'
reading channels from file 'dvb_channel.conf'
service has pid type 05:  204
tuning to 573000000 Hz

  dvb_set_pesfilter to 0x2000
