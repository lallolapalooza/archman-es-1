DVILJ(1) TeX Live DVILJ(1)

NOMBRE

dvilj4, dvilj4l, dvilj2p, dvilj - convierte un archivo DVI de TeX a PCL, para impresoras HP LaserJet

SINOPSIS

dvilj [--Dnumber] [-ccopies] [-dmode] [-D] [-E] [-eoutputfile]
      [-ffrompage] [-g] [-hheaderfile] [-l] [-Mflag] [-mmag] [-ppages]
      [-q] [-r] [-ttopage] [-spagesize] [-v] [-Vmode] [-w] [-xxoff(mm)]
      [-yyoff(mm)] [-Xxoff(dots)] [-Yyoff(dots)] [-z] [filename]

DESCRIPCIÓN

dvilj y sus hermanos convierten los archivos ".dvi" generados por TeX en comandos PCL (el lenguaje de control de impresión de Hewlett-Packard) adecuados para imprimir en una HP LaserJet+, HP LaserJet IIP (usando dvilj2p), HP LaserJet 4 (usando dvilj4), e impresoras totalmente compatibles.

dvilj4 también proporciona soporte para las fuentes integradas Intellifont y TrueType; los archivos TFM y VF se proporcionan en la distribución. Las fuentes virtuales no son soportadas directamente por dvilj, así que debe ejecutar dvicopy(1) primero, o de otro modo expandir las fuentes virtuales. Todos los programas se generan a partir de un único archivo fuente

dvi2xx.c . Usualmente se invocan mediante un script de shell o como un filtro de impresora de línea. Uno de esos scripts,dvihp(1) , está incluido en la distribución. Proporciona opciones de línea de comandos similares a las dedvips(1) .OPCIONES

OPERANDOS

Si no se especifican operandos, se muestra un breve mensaje de uso.

filename
El nombre del archivo DVI que debe ser convertido por dvilj. Debe ser siempre localizable (seekable).

El nombre del archivo de salida se construye a partir de filename. O bien una extensión ".dvi" es reemplazada por ".lj", o se añade la extensión ".lj" .

Si filename es -, el archivo DVI se lee de la entrada estándar y el documento PCL resultante se escribe en la salida estándar. (Por favor, recuerde que el archivo DVI debe ser localizable (seekable), incluso si es stdin.)

COMANDOS \special DE TeX SOPORTADOS

Los comandos "\special" soportados por dvilj tienen la sintaxis genérica

\special{key1=value key1="value with space"}
\special{key3 = value key4 = 'note optional spaces around equal sign'}

Es decir, los specials son una secuencia de pares clave/valor, separados por un signo igual. Los espacios alrededor del signo igual se ignoran. El valor es o bien una palabra separada por espacios, o una cadena entre comillas. Se pueden usar tanto comillas dobles como simples, indistintamente. No hay soporte para escapar caracteres de comillas en los valores; si quiere usar comillas dobles y simples en un mismo valor, no tiene suerte.
