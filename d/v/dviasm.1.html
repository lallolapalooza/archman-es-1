DVIASM(1) Manual de Comandos Generales DVIASM(1)

NOMBRE

DVIasm - un programa de utilidad de TeX para editar archivos DVI directamente

SINOPSIS

dviasm [<opciones>] <archivo_dvi>|<archivo_volcado_dvi>

DESCRIPCIÓN

DVIasm es un programa de utilidad de TeX diseñado para editar archivos DeVice-Independent (DVI) directamente. Consiste en un único script de Python, dviasm.py, en formato de texto legible por humanos. Se ejecuta en cualquier plataforma en la que esté instalado Python 3.

Las características de DVIasm incluyen:
1) Desensambla un archivo DVI (o un archivo XDV de XeTeX) en un archivo de texto legible por humanos, cuyo contenido es fácil de modificar.
2) Ensambla el archivo de texto de salida de nuevo en el formato binario.
Existen varias alternativas para volcar y editar archivos DVI:
1) DVItype desarrollado por Donald E. Knuth soporta la conversión unidireccional de DVI a formato de texto. También hay algunos derivados: pDVItype para pTeX, upDVItype para upTeX, ODVItype para Omega.
2) Los programas dv2dt y dt2dv se pueden usar en pares para permitir la conversión bidireccional entre DVI y el Lenguaje de Texto DVI (DTL).
3) El programa dvispc (parte del visor DVIOUT) también tiene la capacidad de convertir entre DVI y texto.

Entre estos, DVIasm está diseñado para permitir a los usuarios editar archivos DVI fácilmente, por ejemplo, unificando ``right1''-``right4'' en un único comando ``right'' que se puede usar independientemente de la cantidad de movimiento.

OPCIONES

--version
Muestra el número de versión del programa y sale.
-h, --help
Muestra este mensaje de ayuda y sale.
-u <STR>, --unit=<STR>
Establece la unidad [predeterminado: `pt']. Los valores permitidos son: `sp', `pt', `bp', `mm', `cm' y `in'.
-o <ARCHIVO>, --output=<ARCHIVO>
Establece el nombre de archivo para la salida en lugar de stdout.
-e <STR>, --encoding=<STR>
Establece la codificación para la entrada/salida del texto volcado [predeterminado: `utf8']. Los valores permitidos son: `ascii', `latin1', `utf8', `sjis' y `eucjp'. Cuando se usa con la opción -p (o --ptex), los valores permitidos son solo `utf8', `sjis' y `eucjp'.
# NOTA: Esta característica no soporta el volcado a través de stdout.
-x <STR>, --xxx-encoding=<STR>
Establece la codificación para interpretar las cadenas `xxx:' [predeterminado: `none']. Los valores permitidos son: `none', `utf8', `sjis' y `eucjp'.
Esta opción permite a los usuarios especificar la codificación correcta para volcar/compilar el contenido de \special.
Los usos típicos son los siguientes:
1) Por defecto, el contenido de \special se vuelca/compila como secuencias de escape de byte a byte en formato `\x..'. Esto sería suficiente cuando no necesites leer/editar el contenido de \special.
3) Para usuarios de XeTeX y upTeX, `-x utf8' sería útil ya que estos motores usan UTF-8 para codificar cadenas dentro de comandos \special.
2) Para usuarios de pTeX con DVI codificado en ISO-2022-JP, sería útil seleccionar la opción apropiada `-x eucjp' (para Unix) o `-x sjis' (para Windows) para que sea consistente con la codificación Kanji interna utilizada por el motor pTeX.
-t <INT>, --tabsize=<INT>
Establece el tamaño de tabulación para push/pop [predeterminado: 2].
-p, --ptex
Vuelca y compila DVI codificado en ISO-2022-JP para pTeX japonés. Esta opción es necesaria para decodificar o codificar caracteres japoneses que se componen (usando `set2' o `put2') correctamente.
-s <STR>, --subfont=<STR>
Especifica la lista de fuentes con el esquema de subfuente UCS2 en formato separado por comas. Si <STR> está vacío, la lista de subfuentes interna predefinida se deshabilita.
Esta opción sería útil, por ejemplo, al usar el paquete CJK.

AUTORES

La primera versión fue escrita en Python 2 por Jin-Hwan Cho en 2007. Khaled Hosny comenzó a dar soporte para volcar/compilar el formato XDV de XeTeX en 2014. Arthur Reutenauer portó el script a Python 3 en 2019. El mantenedor actual de DVIasm es Hironobu Yamashita, desde 2020.
