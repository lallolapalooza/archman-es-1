TeX \special SOPORTADOS Los

comandos

"\special" soportados por dvilj tienen la sintaxis genérica \special{key1=valu

e 
key1="value with space"}
\special{key3 = value key4 = 'note optional spaces around equal sign'}
Es decir, los
specials

son una secuencia de pares clave/valor, separados por un signo igual. Los espacios alrededor del signo igual se ignoran. El valor es o bien una palabra separada por espacios, o una cadena entre comillas. Se pueden usar tanto comillas dobles como simples, indistintamente. No hay soporte para escapar caracteres de comillas en los valores; si quiere usar comillas dobles y simples en un mismo valor, no hay

suerte.

Las siguientes combinaciones clave/valor son

válidas:
hpfile=arch
ivo
Inserta archivo en la posición actual. archivo se busca con kpathsea(3), ver más abajo.

El contenido del archivo debe ser válido para esta impresora, es decir, debe contener secuencias de escape PCL o comandos HP-GL/2. Si el archivo es un archivo gráfico, esto significa típicamente que la esquina superior izquierda del gráfico se coloca en la posición

actual.

Las secuencias de escape de posicionamiento absoluto PCL en archivo se reescriben como comandos de posicionamiento relativ

o; la coordenada más baja que a
parezca se usa como referencia.
hpfile_verbatim=arch
ivo
Inserta archivo literalmente en la posición actual, sin ningún cambio en el contenido del archivo. archivo se busca con kpathsea(3), ver más abajo.

Esto se usa principalmente

para mantener posiciones
absolutas en archivos PCL.

s
Convierte el archivo PostScript archivo a HP PCL, mediante Ghostscript con el dispositivo "ljetplus", e inserta el archivo gráfico resultante en la posición actual, reescribiendo las secuencias de escape de posición absoluta. archivo se busca con kpathsea(3), ver más abajo.

Los pares clave/valor acompañantes son obligatorios, pueden especificarse en un orden arbitrario. Los valores x0, x1, y0, y1, y s son enteros. (x0,y0) es la esquina inferior izquierda, (x1,y1) la esquina superior derecha de la

Tenga en cuenta: La semántica específica de este especial no es conocida. En particular, el parámetro rwi es algún factor de escala; pero incluso mirando el código fuente no está del todo claro qué pretendía implementar aquí el autor del especial. Además, no está claro qué dimensiones se usan para especificar las esquinas, puntos PostScript o puntos

PCL.

Si ocurre que conoce la semántica de psfile, o si dedicó el trabajo a analizarla, por favor infórmenos en tex-k@tug.org, para que podamos actualizar esta página d

Búsqueda de Archivos

Incluidos

Los especiales de inclusión de archivos adecuados buscan el archivo con kpathsea(3). La ruta de búsqueda se configura por la variable "DVILJINPUTS" y, si el archivo no se encuentra en esa ruta de búsqueda, por la variable "TEXINPUTS"

.

La búsqueda vía "DVILJINPUTS" cubre el caso de uso en el que se tienen gráficos comunes a nivel de sitio que deben incluirse en documentos, por ejemplo, firmas escaneadas. La búsqueda vía "TEXINPUTS" cubre el caso de uso en el que se tienen gráficos como parte del documento

actual.

"dvilj" se usa como el nombre ".PROGRAM" en texmf.cnf, para todas las variantes del controla

dor, independientemente del
nombre real del programa.

"TEX_HUSH"

Kpathsea(3) tiene el concepto de supresión de advertencias con la variable de configuración "TEX_HUSH", por favor consulte su nodo Info TeX support / Suppressing warnings. Esa variable contiene identificadores separados por dos puntos que especifican las advertencias que deben

suprimirse.

Si "special" está entre los valores listados, dvilj ya no emite advertencias sobre especiales que no conoce. Pero si hay un especial reconocido y si ese especial tiene un parámetro inválido, entonces se emite una advertencia de todos modos, independientemente del contenido de "TEX

IMPRESIÓN DE PÁGINA

DOBLE

Si la impresora tiene una unidad dúplex instalada, la impresión dúplex puede exigirse con la opción

-d.

De lo contrario, la opción de línea de comandos -D hace que la impresora imprima en modo de página doble, es decir, hablando en términos generales, imprimiendost las páginas pares y luego las impares de un documento. Si -D se usa para imprimir tanto las páginas pares como las impares (-D se usa sin el 1 u 2 opcional) lo siguiente ocurrirá después de que se haya impreso la mitad de las páginas: LJ: la impresora se detiene, muestra el mensaje "FEED" y enciende el LED de alimentación manual. La impresora continúa cuando se introduzcan las páginas impresas en el alimentador manual de páginas, o cuando el operador presione el botón de continuar (después de colocar primero las páginas impresas en la bandeja de papel)

.

Si -D1 se especificó, solo se imprimirán las páginas impares, -D2 se puede usar para las páginas pares. Un "-" final (como en -D-, -D1- o -D2-) suprime la impresión de páginas vacías que de otro modo se generarían para el

relleno.

El controlador permite la -D opción para ambas direcciones de impresión (impresión de frente a atrás o de atrás a frente). Intenta ser inteligente en ciertos casos: cuando un documento tiene un número impar de páginas, inserta en el lugar correcto una página vacía; cuando un documento comienza con la página 0, el controlador inserta una página vacía después de la página 0; cuando se imprime una parte de un documento que comienza con un número de página par, imprime esta página en el reverso de la primera página para asegurar que las páginas impares siempre estén en el anverso. La página 0 se trata como una página

impar.

La opción de doble cara funciona para todos los LJ, no solo para el nuevo modelo D que imprime a doble cara (en realidad, no sé si tiene mucho sentido en el nuevo LJ II D en absoluto)

.

Advertencia sobre la opción de doble cara: cuando se usa con frecuencia o en archivos muy grandes, puede ser necesario limpiar la impresora mucho más

frecuentemente.

La opción de línea de comandos -pX se puede usar para abortar la impresión después de la salida de X páginas (puede dar lugar a resultados extraños junto con -D). Personalmente, no me gusta esta opción. La forma segura de imprimir una parte de un documento es usando -f (desde) y -t (

has
ta).
