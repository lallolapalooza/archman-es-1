IMPRESSION DE PAGES

DOUBLES

Si l'imprimante a une unité duplex installée, l'impression duplex peut être demandée avec l' option

-d.

Sinon, l'option de ligne de commande -D fait imprimer à l'imprimante en mode double page, c'est-à-dire, grossièrement parlant, en imprimant d'abord las páginas pares y luego las páginas impares de un documento. Si -D se usa para imprimir tanto páginas pares como impares (-D se usa sin el 1 u 2 opcional) lo siguiente ocurrirá después de que se haya impreso la mitad de las páginas: LJ: la impresora se detiene, muestra el mensaje "FEED" y enciende el LED de alimentación manual. La impresora continúa cuando se introducen las páginas impresas en el alimentador manual de páginas, o cuando el operador pulsa el botón de continuar (después de colocar primero las páginas impresas en la bandeja de papel)

.

Si -D1 se especificó, solo se imprimirán páginas impares, -D2 se puede usar para páginas pares. Un "-" final (como en -D-, -D1- o -D2-) suprime la impresión de páginas vacías que se generan para el relleno de otra

manera.

El controlador permite la -D opción para ambas direcciones de impresión (impresión de frente a atrás o de atrás a frente). Intenta ser inteligente en ciertos casos: cuando un documento tiene un número impar de páginas, inserta en el lugar correcto una página vacía; cuando un documento comienza con la página 0, el controlador inserta una página vacía después de la página 0; cuando se imprime una parte de un documento que comienza con un número de página par, imprime esta página en el reverso de la primera página para asegurar que las páginas impares siempre estén en el anverso. La página 0 se trata como una página

impar.

La opción de doble cara funciona para todas las LJ, no solo para el nuevo modelo D que hace impresión a doble cara (en realidad, no sé si tiene mucho sentido en la nueva LJ II D en absoluto)

.

Advertencia sobre la opción de doble cara: cuando se usa con frecuencia o en archivos muy grandes, puede ser necesario limpiar la impresora mucho más

frecuentemente.

La opción de línea de comandos -pX se puede usar para abortar la impresión después de la salida de X páginas (puede llevar a resultados extraños junto con -D). Personalmente no me gusta esta opción. La forma segura de imprimir una parte de un documento es usando -f (desde) y -t (

has
ta).
