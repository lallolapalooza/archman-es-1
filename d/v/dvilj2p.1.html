DVILJ(1) TeX Live DVILJ(1)

NOMBRE

dvilj4, dvilj4l, dvilj2p, dvilj - convierte un archivo DVI de TeX a PCL, para impresoras HP LaserJet

SINOPSIS

dvilj [--Dnumero] [-ccopias] [-dmodo] [-D] [-E] [-esalida]
      [-ddesdepagina] [-g] [-ahojadeencabezado] [-l] [-Mbandera] [-mmag] [-ppaginas]
      [-q] [-r] [-athasppagina] [-ttamaño] [-v] [-Vmodo] [-w] [-xxdesplazamiento(mm)]
      [-yydesplazamiento(mm)] [-Xxdesplazamiento(puntos)] [-Yydesplazamiento(puntos)] [-z] [nombrearchivo]

DESCRIPCIÓN

dvilj y sus hermanos convierten archivos ".dvi" de salida de TeX en comandos PCL (el Lenguaje de Control de Impresora de Hewlett-Packard) adecuados para imprimir en una HP LaserJet+, HP LaserJet IIP (usando dvilj2p), HP LaserJet 4 (usando dvilj4), e impresoras totalmente compatibles.

dvilj4 también proporciona soporte para las fuentes Intellifont y TrueType integradas; los archivos TFM y VF se proporcionan en la distribución. Las fuentes virtuales no son soportadas directamente por dvilj, por lo que debes ejecutar dvicopy(1) primero, o expandir las fuentes virtuales de otra manera.

Todos los programas se generan a partir de un único archivo fuente dvi2xx.c. Generalmente se llaman a través de un script de shell o como un filtro de impresora. Uno de esos scripts, dvihp(1), se incluye en la distribución. Proporciona opciones de línea de comandos similares a las de dvips(1).

OPCIONES

--Dnúmero
Depurar según los bits de número; véase el manual de kpathsea(3) para los valores. También activa la verbosidad general.
-cnúmero
Imprimir cada página número veces (incluyendo la original).
-dnúmero
imprimir en modo dúplex. La opción -d1 significa encuadernación por el borde largo, -d2 significa encuadernación por el borde corto. Esta opción solo es seleccionable en dvilj4 y dvilj2p.
-D[-12]
Impresión a doble cara - ver abajo; -D1 imprime solo páginas impares, -D2 es para páginas pares, un guion final suprime la impresión de páginas de relleno vacías.
-E
Cambia la impresora al modo económico (solo dvilj4).
-esalida
Enviar la salida al archivo salida en lugar del nombre base del archivo dvi extendido con ".lj". Si salida es - (como en "-e-") la salida se dirige a la salida estándar y puede ser enviada directamente a un spooler.
-fnúmeropagina
Imprimir páginas con números de página TeX mayores o iguales a númeropagina.
-g
Modo Go: no restablecer la impresora al inicio del trabajo.
-harchivoencabezado
Copiar archivoencabezado a la salida antes de la traducción del archivo DVI. Se utiliza para enviar comandos arbitrarios a la impresora láser.
-l
Imprimir la salida en modo horizontal (apaisado); solo soportado por dvilj2p y dvilj4.
-Mbandera
Llamar (o no) a mktexpk(1) para generar fuentes bajo demanda. -M1 y -M son equivalentes. -M0 habilita la invocación de mktexpk(1). (Esto es lo mismo que en dvips(1).) El comportamiento por defecto (es decir, si no se proporciona ninguna opción -M) se elige en tiempo de compilación; tal como se distribuye, mktexpk está habilitado.
-mmagnificacion

-m4 equivalente a -m#2074
-m5 equivalente a -m#2488
-pnumerodepaginas
Imprimir numerodepaginas páginas después de la página de inicio.
-q
Operación silenciosa: omitir estadísticas finales, etc.
-r
Invertir el orden de las páginas.
-stamañopagina
Especificar el tamaño de página:

-s46: Papel JIS B4 (250mm x 354mm)

(Pero la impresión por debajo del borde inferior del papel no debería molestar a ninguna impresora PCL que funcione correctamente.) Por favor, recuerde que la bandeja de papel correcta debe estar instalada para el tamaño de papel seleccionado, así que use esta opción solo si tiene control total sobre su destino de impresión.

-tnúmeropagina
Imprimir páginas con números de página TeX menores o iguales a númeropagina.
-v
Modo detallado: listar fuentes utilizadas, etc.
-Vmodo
Modo de compatibilidad. Como modo, use "K" para Kyocera, "B" para Brother, 6 para impresoras LJ6.
-w
Omitir advertencias.
-xdesplazamiento
Desplazamiento global x en mm en la página de salida relativo al origen de 1 pulgada/1 pulgada.
-ydesplazamiento
Desplazamiento global y en mm en la página de salida relativo al origen de 1 pulgada/1 pulgada.
-Xdesplazamiento
Desplazamiento global x en puntos en la página de salida (anula el origen de 1 pulgada/1 pulgada).
-Ydesplazamiento
Desplazamiento global y en puntos en la página de salida (anula el origen de 1 pulgada/1 pulgada).
-z
Imprimir una página de prueba con el contador de páginas al final del trabajo.

OPERANDOS

Si no se especifican operandos, se muestra un breve mensaje de uso.

nombrearchivo
El nombre del archivo DVI que será convertido por dvilj. Siempre debe ser buscable.

El nombre del archivo de salida se construye a partir de nombrearchivo. O bien se reemplaza la extensión ".dvi" por ".lj", o se añade la extensión ".lj".

Si nombrearchivo es -, el archivo DVI se lee de la entrada estándar y el documento PCL resultante se escribe en la salida estándar. (Por favor, recuerde que el archivo DVI debe ser buscable, incluso si es stdin.)

COMANDOS TeX \special SOPORTADOS

Los comandos "\special" soportados por dvilj tienen la sintaxis genérica

\special{clave1=valor clave1="valor con espacio"}
\special{clave3 = valor clave4 = 'nota espacios opcionales alrededor del signo igual'}

Es decir, los especiales son una secuencia de pares clave/valor, separados por un signo igual. Los espacios alrededor del signo igual se ignoran. El valor es una palabra separada por espacios, o una cadena entre comillas. Se pueden usar tanto comillas dobles como simples, alternativamente. No hay soporte para citar caracteres de comillas en los valores; si quieres tanto comillas dobles como simples en un valor, mala suerte.

Las siguientes combinaciones de clave/valor son válidas:

hpfile
Especifique un archivo a incluir en la salida. El nombre de archivo está limitado a 8 caracteres y la extensión a 3.
setpagedevice
Utilice el comando PCL 5e Set Page Device. Las opciones son: 
@u{...}            # Imprime en modo unútil
@p{width,height}    # Establece el tamaño de página
@o{orientation}     # Establece la orientación (0=vertical, 1=horizontal)
@r{x-offset,y-offset} # Establece desplazamiento relativo
@s{x-origin,y-origin} # Establece desplazamiento absoluto
@l{left,top,right,bottom} # Establece los márgenes de impresión
@t{chars}           # Imprime el texto dado
@f{font}            # Establece la fuente
@i{n}               # Establece el interlineado
@a{n}               # Establece el espaciado horizontal
@g{width,height,dots} # Dibuja un rectángulo
@c{x,y,width,height} # Dibuja un círculo

El significado de x-offset, y-offset y width, height se explica en la documentación PCL 5e. Para los puntos, véase PCL5.PDF en la documentación del controlador de impresora HP.

Nota: esta opción solo es válida para dvilj4 y dvilj2p.

halftone
Establece el patrón de tramado (halftone). Los valores van de 0 a 4. El valor por defecto es 2.
xfill
Rellena el espacio horizontalmente.
yfill
Rellena el espacio verticalmente.
xchar
Establece el espaciado horizontal de los caracteres.
ychar
Establece el espaciado vertical de los caracteres.
paper
Establece el tamaño del papel, de manera similar a la opción de línea de comandos -s.
printerror
Imprime el mensaje de error dado en la impresora.
setlanguage
Establece el lenguaje de la impresora (PCL o PJL).
printpage
Imprime el número de página dado.
setresolution
Establece la resolución en puntos por pulgada.

IMPRESIÓN DE PÁGINA

DOBLE

Si la impresora tiene una unidad dúplex instalada, se puede exigir la impresión dúplex con la opción

-d.

De lo contrario, la opción de línea de comandos -D hace que la impresora imprima en modo de página doble, es decir, hablando en términos generales, imprimiendost las páginas pares y luego las impares de un documento. Si -D se usa para imprimir tanto las páginas pares como las impares (-D se usa sin el 1 o 2 opcional) lo siguiente ocurrirá después de que se haya impreso la mitad de las páginas: LJ: la impresora se detiene, muestra el mensaje "FEED" y enciende el LED de alimentación manual. La impresora continúa cuando las páginas impresas se insertan en el alimentador manual de papel, o cuando el operador presiona el botón de continuar (después de colocar primero las páginas impresas en la bandeja de papel)

.

Si -D1 se especificó, solo se imprimirán las páginas impares, -D2 se puede usar para las páginas pares. Un "-" final (como en -D-, -D1- o -D2-) suprime la impresión de páginas vacías que se generan para el relleno de lo

contrario.

El controlador permite la -D opción para ambas direcciones de impresión (impresión de frente a atrás o de atrás a frente). Intenta ser inteligente en ciertos casos: cuando un documento tiene un número impar de páginas, inserta en el lugar correcto una página vacía; cuando un documento comienza con la página 0, el controlador inserta una página vacía después de la página 0; cuando se imprime una parte de un documento que comienza con un número de página par, imprime esta página en el reverso de la primera página para asegurar que las páginas impares siempre estén en el frente. La página 0 se trata como una página

impar.

La opción de doble cara funciona para todas las LJ, no solo para el nuevo modelo D que hace impresión a doble cara (realmente, no sé si tiene mucho sentido en la nueva LJ II D en absoluto)

.

Advertencia sobre la opción de doble cara: Cuando se usa con frecuencia o en archivos muy grandes, puede ser necesario limpiar la impresora mucho más

frecuentemente.

La opción de línea de comandos -pX se puede usar para abortar la impresión después de la salida de X páginas (puede llevar a resultados extraños junto con -D). Personalmente no me gusta esta opción. La forma segura de imprimir una parte de un documento es usando -f (desde) y -t (

has
ta).
