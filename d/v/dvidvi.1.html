DVIDVI(L) DVIDVI(L)

NOMBRE

dvidvi - selecciona y/o reorganiza páginas en un archivo TeX dvi

SINOPSIS

dvidvi [parámetro] infile outfile

DESCRIPCIÓN

Introducción

El programa dvidvi convierte un archivo dvi en otro archivo dvi, con quizás algunos cambios.

Parámetros

-f n página n es la primera página seleccionada
-l n página n es la última página seleccionada
-n n selecciona como máximo n páginas. Nótese que n es el número de páginas seleccionadas, independientemente del número de páginas realmente contenidas en una hoja -i { n1..n2 | n1 }[,...]
incluye páginas (se permiten rangos). Cuando se utiliza esta opción, SÓLO se seleccionan las páginas especificadas. Sin embargo, podemos excluir de estas páginas con la opción -x -x { n1..n2 | n1 }[,...]
excluye páginas (se permiten rangos) -q trabaja en modo silencioso, es decir, no imprime en la pantalla mensajes sobre cómo se está realizando el trabajo. -r invierte el orden de las páginas.

Los números de página para las opciones anteriores -f -l -i y -x se pueden especificar de diferentes maneras.
1) Si se da un número n, se interpreta como la n-ésima página desde el principio del archivo .dvi. Por supuesto, este número es independiente del número de página asignado por TeX. 2) Los números de página de TeX son los que están realmente escritos en la página; estos números de página se pueden modificar, por ejemplo, usando los comandos TeX \pagenumbering, \setcounter{page}{n}, y \addtocounter{page}{n}. Un número de página de TeX se puede especificar precediendo el número n con el carácter @. Por lo tanto, si se especifica -f @25 -l @30 se seleccionan las páginas entre 25 y 30, siendo estos números los asignados por TeX. 3) Sin embargo, varias páginas pueden tener el mismo número de página de TeX en un archivo .dvi. Por ejemplo, las páginas introductorias de un libro se numeran i, ii, y así sucesivamente hasta que comienza el primer capítulo y luego, las páginas se numeran 1, 2, etc. En este caso, las páginas numeradas i y 1 en el archivo .dvi tienen el mismo número de página de TeX. Si desea seleccionar, por ejemplo, la segunda aparición de la página numerada 1, puede especificar un número de página como (@2)1. Así @1 es equivalente a (@1)1. Por ejemplo, si especifica -f (@2)1 -l(@2)10 selecciona las páginas entre 1 y 10 del primer capítulo, no las páginas introductorias entre i y x.

Hay otro parámetro que le dice a dvidvi cómo desea cambiar el diseño y las especificaciones de la página. Este es el parámetro -m.
* El número que precede a los dos puntos es el valor del módulo. Todo se hará en bloques de páginas de este tamaño. Si no hay dos puntos, el valor por defecto se asume que es uno. El último bloque de páginas se rellena con tantas páginas en blanco como sea necesario. * Después de los dos puntos hay una lista de números de página separados por comas. Estos números de página son con respecto al bloque de páginas actual y deben estar en el rango de cero a menos uno del valor del módulo. Si un signo negativo precede al número, la página se toma del bloque espejo; si hay m bloques, el bloque espejo del bloque n es el bloque numerado m-n-1. En pocas palabras, es el bloque numerado igual, solo que desde el final. Esto se puede usar para invertir páginas. Si no se proporciona ningún número, el número de página por defecto es 1. * Después de cada número de página hay un valor de desplazamiento opcional entre paréntesis, que consiste en un par de dimensiones separadas por comas. Cada dimensión es un número decimal con una unidad de medida opcional. La unidad de medida por defecto son pulgadas, o la última unidad de medida utilizada. Todas las unidades están en dimensiones reales. Las unidades de medida admisibles son las mismas que admite TeX: in, mm, cm, pt, pc, dd y cc.

EJEMPLOS


-m - Invierte el orden de las páginas. Esta vez, tanto el módulo como el número de página se dejan por defecto. -m 2:0 Selecciona las páginas primera, tercera, quinta, etc. del archivo. Imprime esta después de imprimir la siguiente, sacando el papel de la bandeja de alimentación y volviéndolo a insertar en la alimentación de papel. -m 2:-1 Selecciona las páginas segunda, cuarta, etc. y las escribe en orden inverso. -m 4:-1,2(4.25in,0in) -m 4:-3,0(4.25in,0in)
Útil para imprimir un pequeño folleto, cuatro páginas por hoja, a doble cara, para grapar en el medio. Imprime la primera, vuelve a colocar la pila en la impresora boca abajo y imprime la segunda. Las especificaciones 'in' son superfluas. -m ,(1pt,1)
¡Asusta a tu administrador del sistema! De hecho, las cosas se vuelven tan borrosas con esta opción que es posible que desees enviar cartas a tus enemigos impresas de esta manera. Cartas *largas*. -m 4:0(5.5in,4.25),3(0,4.25) -m 4:1(0in,4.25),2(5.5,4.25)
Imprime una tarjeta de cuatro páginas en una sola hoja. Imprime la primera, rota el papel 180 grados y vuelve a alimentarlo. (Las personas de PostScript pueden hacer trucos divertidos con PostScript, por lo que esto no es necesario).
