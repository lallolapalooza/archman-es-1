DVCONNECT(1) Manual de comandos generales DVCONNECT(1)

NOMBRE

dvconnect - recibir o transmitir DV en bruto usando el dispositivo video1394

SINOPSIS

dvconnect [ opciones ] archivos dv brutos o '-- -' para stdin/stdout

DESCRIPCIÓN

dvconnect captura flujos DV brutos desde o envía flujos DV brutos al dispositivo video1394 de Linux IEEE 1394.

--version
muestra el número de versión de dvconnect.
-s, --send
enviar datos en lugar de capturar.
-v, --verbose
muestra información de estado mientras se recibe / envía.
-c, --channel=número
canal para enviar / recibir (rango: 0 - 63, predeterminado = 63).
-k, --kbuffers=número
número de búferes de trama video1394 del kernel a usar. predeterminado = 8.
--start-frame=conteo
comenzar en la trama número conteo (predeterminado es 0).
-e, --end-frame=conteo
finalizar en la trama número conteo (predeterminado es ilimitado).
--cip-n-ntsc=número
contador de tiempo cip n ntsc (predeterminado: 2436).
--cip-d-ntsc=número
contador de tiempo cip d ntsc (predeterminado: 38400).
--syt-offset=número
desplazamiento syt (predeterminado: 10000 rango: 10000-26000).
-b, --buffers=número
número máximo de búferes del hilo de E/S de archivo a usar. predeterminado = 250.
-u, --underrun-data=nombrearchivo
archivo con la trama a enviar en caso de subdesbordamientos.
-d, --device=nombrearchivo
Especifica el dispositivo video1394 (predeterminado /dev/video1394/0).

Opciones de ayuda

-?, --help
Muestra el mensaje de ayuda.
--usage
Muestra un mensaje de uso breve.
