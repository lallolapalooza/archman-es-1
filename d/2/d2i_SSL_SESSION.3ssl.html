d2i_SSL_SESSION(3ssl)

Paquete: openssl

Licencias: Apache-2.0

D2I_SSL_SESSION(3ssl) OpenSSL D2I_SSL_SESSION(3ssl)

NOMBRE

d2i_SSL_SESSION, d2i_SSL_SESSION_ex, i2d_SSL_SESSION - convertir el objeto SSL_SESSION de/a representación ASN1

SINÓPSIS

#include <openssl/ssl.h>
SSL_SESSION *d2i_SSL_SESSION(SSL_SESSION **a, const unsigned char **pp,
                             long length);
SSL_SESSION *d2i_SSL_SESSION_ex(SSL_SESSION **a, const unsigned char **pp,
                                long length, OSSL_LIB_CTX *libctx,
                                const char *propq);
int i2d_SSL_SESSION(SSL_SESSION *in, unsigned char **pp);

DESCRIPCIÓN

Estas funciones decodifican y codifican un objeto SSL_SESSION. Para detalles de codificación, véase d2i_X509(3).

Los objetos SSL_SESSION mantienen información de enlace interna sobre la lista de caché de sesiones, cuando se insertan en la caché de sesiones de un objeto SSL_CTX. Por lo tanto, un objeto SSL_SESSION, independientemente de su contador de referencias, solo debe usarse con un objeto SSL_CTX (y los objetos SSL creados a partir de este objeto SSL_CTX).

VALORES DEVUELTOS

d2i_SSL_SESSION() y d2i_SSL_SESSION_ex() devuelven un puntero al objeto SSL_SESSION recién asignado. En caso de error, se devuelve el puntero NULL y el mensaje de error puede recuperarse de la pila de errores.

i2d_SSL_SESSION() devuelve el tamaño de la representación ASN1 en bytes. Cuando la sesión no es válida, se devuelve 0 y no se realiza ninguna operación.

VER TAMBIÉN

ssl(7), SSL_SESSION_free(3), SSL_CTX_sess_set_get_cb(3), d2i_X509(3)

HISTORIAL

La función d2i_SSL_SESSION_ex() se añadió en OpenSSL 3.2.
