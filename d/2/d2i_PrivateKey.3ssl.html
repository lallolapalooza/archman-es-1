d2i_PrivateKey(3ssl)

Paquete: openssl

Licencias: Apache-2.0

D2I_PRIVATEKEY(3ssl) OpenSSL D2I_PRIVATEKEY(3ssl)

NOMBRE

d2i_PrivateKey_ex, d2i_PrivateKey, d2i_PublicKey, d2i_KeyParams, d2i_AutoPrivateKey_ex, d2i_AutoPrivateKey, i2d_PrivateKey, i2d_PKCS8PrivateKey, i2d_PublicKey, i2d_KeyParams, i2d_KeyParams_bio, d2i_PrivateKey_ex_bio, d2i_PrivateKey_bio, d2i_PrivateKey_ex_fp, d2i_PrivateKey_fp, d2i_KeyParams_bio, i2d_PrivateKey_bio, i2d_PrivateKey_fp - funciones de decodificación y codificación para leer y guardar estructuras EVP_PKEY

SINOPSIS

#include <openssl/evp.h>
EVP_PKEY *d2i_PrivateKey_ex(int type, EVP_PKEY **a, const unsigned char **pp,
                            long length, OSSL_LIB_CTX *libctx,
                            const char *propq);
EVP_PKEY *d2i_PrivateKey(int type, EVP_PKEY **a, const unsigned char **pp,
                         long length);
EVP_PKEY *d2i_PublicKey(int type, EVP_PKEY **a, const unsigned char **pp,
                        long length);
EVP_PKEY *d2i_KeyParams(int type, EVP_PKEY **a, const unsigned char **pp,
                        long length);
EVP_PKEY *d2i_AutoPrivateKey_ex(EVP_PKEY **a, const unsigned char **pp,
                                long length, OSSL_LIB_CTX *libctx,
                                const char *propq);
EVP_PKEY *d2i_AutoPrivateKey(EVP_PKEY **a, const unsigned char **pp,
                             long length);
int i2d_PrivateKey(const EVP_PKEY *a, unsigned char **pp);
int i2d_PKCS8PrivateKey(const EVP_PKEY *a, unsigned char **pp);
int i2d_PublicKey(const EVP_PKEY *a, unsigned char **pp);
int i2d_KeyParams(const EVP_PKEY *a, unsigned char **pp);
int i2d_KeyParams_bio(BIO *bp, const EVP_PKEY *pkey);
EVP_PKEY *d2i_KeyParams_bio(int type, EVP_PKEY **a, BIO *in);
#include <openssl/x509.h>
EVP_PKEY *d2i_PrivateKey_ex_bio(BIO *bp, EVP_PKEY **a, OSSL_LIB_CTX *libctx,
                                const char *propq);
EVP_PKEY *d2i_PrivateKey_bio(BIO *bp, EVP_PKEY **a);
EVP_PKEY *d2i_PrivateKey_ex_fp(FILE *fp, EVP_PKEY **a, OSSL_LIB_CTX *libctx,
                               const char *propq);
EVP_PKEY *d2i_PrivateKey_fp(FILE *fp, EVP_PKEY **a);
int i2d_PrivateKey_bio(BIO *bp, const EVP_PKEY *pkey);
int i2d_PrivateKey_fp(FILE *fp, const EVP_PKEY *pkey);

DESCRIPCIÓN

d2i_PrivateKey_ex() decodifica una clave privada usando el algoritmo type. Intenta usar cualquier formato específico de clave o el formato PKCS#8 sin cifrar PrivateKeyInfo. El parámetro type debe ser una constante de algoritmo de clave pública como EVP_PKEY_RSA. Ocurre un error si la clave decodificada no coincide con type. Algunas implementaciones de decodificación de claves privadas pueden usar algoritmos criptográficos (por ejemplo, para derivar automáticamente la clave pública si no está incluida explícitamente en la codificación). En este caso, se utilizan el contexto de biblioteca proporcionado libctx y la cadena de consulta de propiedad propq. Si tiene éxito y el parámetro a no es NULL, la función asigna el puntero de la estructura EVP_PKEY devuelto a *a, sobrescribiendo cualquier valor anterior.

d2i_PrivateKey() hace lo mismo que d2i_PrivateKey_ex() excepto que utiliza el contexto de biblioteca predeterminado y la cadena de consulta de propiedad. d2i_PublicKey() hace lo mismo para claves públicas. d2i_KeyParams() hace lo mismo para parámetros de clave.

Las funciones d2i_PrivateKey_ex_bio() y d2i_PrivateKey_bio() son similares a d2i_PrivateKey_ex() y d2i_PrivateKey() respectivamente, excepto que decodifican los datos leídos del BIO dado. Las funciones d2i_PrivateKey_ex_fp() y d2i_PrivateKey_fp() son las mismas excepto que leen los datos del FILE dado.

d2i_AutoPrivateKey_ex() y d2i_AutoPrivateKey() son similares a d2i_PrivateKey_ex() y d2i_PrivateKey() respectivamente, excepto que intentan detectar automáticamente el formato de clave privada.

i2d_PrivateKey() codifica a. Utiliza un formato específico de la clave o, si no hay ninguno definido para ese tipo de clave, el formato PKCS#8 sin cifrar PrivateKeyInfo. i2d_PKCS8PrivateKey() hace lo mismo utilizando solo el formato PKCS#8 sin cifrar PrivateKeyInfo. i2d_PublicKey() hace lo mismo para claves públicas. i2d_KeyParams() hace lo mismo para parámetros de clave. Estas funciones son similares a las funciones d2i_X509(); véase d2i_X509(3). i2d_PrivateKey_bio() y i2d_PrivateKey_fp() hacen lo mismo, excepto que codifican a un BIO o FILE respectivamente. De nuevo, estas funcionan de manera similar a las funciones descritas en d2i_X509(3).

NOTAS

Todas las funciones que operan sobre datos en memoria actualizan el puntero de datos *pp después de una operación exitosa, al igual que las otras funciones d2i e i2d; véase d2i_X509(3).

Todas estas funciones utilizan formato DER y claves sin cifrar. Las aplicaciones que deseen cifrar o descifrar claves privadas deben utilizar otras funciones como d2i_PKCS8PrivateKey() en su lugar.

Para decodificar una clave con el tipo EVP_PKEY_EC, d2i_PublicKey() requiere que *a sea una estructura EVP_PKEY no NULL a la que se le haya asignado una estructura EC_KEY que haga referencia al EC_GROUP correcto.

VALORES DE RETORNO

Las funciones d2i_PrivateKey_ex(), d2i_PrivateKey(), d2i_AutoPrivateKey_ex(), d2i_AutoPrivateKey(), d2i_PrivateKey_ex_bio(), d2i_PrivateKey_bio(), d2i_PrivateKey_ex_fp(), d2i_PrivateKey_fp(), d2i_PublicKey(), d2i_KeyParams() y d2i_KeyParams_bio() devuelven una estructura EVP_PKEY válida o NULL si ocurre un error. El código de error se puede obtener llamando a ERR_get_error(3).

i2d_PrivateKey(), i2d_PKCS8PrivateKey(), i2d_PublicKey() e i2d_KeyParams() devuelven el número de bytes codificados correctamente o un valor negativo si ocurre un error. El código de error se puede obtener llamando a ERR_get_error(3).

i2d_PrivateKey_bio(), i2d_PrivateKey_fp() y i2d_KeyParams_bio() devuelven 1 si se codifican correctamente o cero si ocurre un error.

VER TAMBIÉN

crypto(7), d2i_PKCS8PrivateKey_bio(3)

HISTORIA

d2i_PrivateKey_ex(), d2i_PrivateKey_ex_bio(), d2i_PrivateKey_ex_fp() y d2i_AutoPrivateKey_ex() se añadieron en OpenSSL 3.0.

i2d_PKCS8PrivateKey() se añadió en OpenSSL 3.6.
