d2i_PKCS8PrivateKey_bio(3ssl)

D2I_PKCS8PRIVATEKEY_BIO(3ssl) OpenSSL D2I_PKCS8PRIVATEKEY_BIO(3ssl)

NOMBRE

d2i_PKCS8PrivateKey_bio, d2i_PKCS8PrivateKey_fp, i2d_PKCS8PrivateKey_bio, i2d_PKCS8PrivateKey_fp, i2d_PKCS8PrivateKey_nid_bio, i2d_PKCS8PrivateKey_nid_fp - funciones de clave privada en formato PKCS#8

SINOPSIS

#include <openssl/pem.h>
EVP_PKEY *d2i_PKCS8PrivateKey_bio(BIO *bp, EVP_PKEY **x, pem_password_cb *cb, void *u);
EVP_PKEY *d2i_PKCS8PrivateKey_fp(FILE *fp, EVP_PKEY **x, pem_password_cb *cb, void *u);
int i2d_PKCS8PrivateKey_bio(BIO *bp, const EVP_PKEY *x, const EVP_CIPHER *enc,
                            char *kstr, int klen,
                            pem_password_cb *cb, void *u);
int i2d_PKCS8PrivateKey_fp(FILE *fp, const EVP_PKEY *x, const EVP_CIPHER *enc,
                           char *kstr, int klen,
                           pem_password_cb *cb, void *u);
int i2d_PKCS8PrivateKey_nid_bio(BIO *bp, const EVP_PKEY *x, int nid,
                                char *kstr, int klen,
                                pem_password_cb *cb, void *u);
int i2d_PKCS8PrivateKey_nid_fp(FILE *fp, const EVP_PKEY *x, int nid,
                               char *kstr, int klen,
                               pem_password_cb *cb, void *u);

DESCRIPCIÓN

Las funciones PKCS#8 codifican y decodifican claves privadas en formato PKCS#8 utilizando algoritmos de cifrado basados en contraseña de PKCS#5 v1.5 y PKCS#5 v2.0.

Aparte del uso de DER en lugar de PEM, estas funciones son idénticas a las funciones PEM correspondientes descritas en PEM_read_PrivateKey(3).

NOTAS

Estas funciones son actualmente la única forma de almacenar claves privadas cifradas utilizando el formato DER.

Actualmente, todas las funciones utilizan BIOs o punteros FILE, no hay funciones que soporten protección por contraseña y que trabajen directamente con memoria: esto se puede solucionar fácilmente convirtiendo los buffers a BIOs de memoria, véase BIO_s_mem(3) para más detalles. Si no se requiere protección por contraseña, la función i2d_PKCS8PrivateKey(3) codifica una clave privada a un formato PKCS#8 DER sin cifrar.

Estas funciones no hacen ninguna suposición sobre la frase de contraseña recibida del callback de contraseña. Simplemente se tratará como una secuencia de bytes.

VALORES DE RETORNO

d2i_PKCS8PrivateKey_bio() y d2i_PKCS8PrivateKey_fp() devuelven una estructura EVP_PKEY válida o NULL si ocurrió un error.

i2d_PKCS8PrivateKey_bio(), i2d_PKCS8PrivateKey_fp(), i2d_PKCS8PrivateKey_nid_bio() y i2d_PKCS8PrivateKey_nid_fp() devuelven 1 en caso de éxito o 0 en caso de error.

VER TAMBIÉN

i2d_PKCS8PrivateKey(3), PEM_read_PrivateKey(3), passphrase-encoding(7)
