DESCRIPCIÓ

N

d2 compila y renderiza file.d2 a file.svg | file.png | file.pdf | file.pptx | file.gif | file.t

xt.

Por defecto es file.svg si no se pasa ninguna ruta de

salida.

Pasa - para que d2 lea de stdin o escriba en

stdout.

Nunca uses la existencia del archivo de salida para comprobar el éxito. Usa siempre el estado de salida de d2. Esto se debe a que a veces, cuando ocurren errores durante la renderización, d2 aún escribe una renderización parcial de todos modos para permitir la iteración sobre un diagrama

roto.

Ver más documentación, el código fuente y la licencia en https://oss.terrastru

ct.com/d2.

Iconos alojados en https://icons.terras

truct.com.

Ejecutor del playground en https://play

.d2lan
g.com.

OPCIONE

S
-w, --watch fal
se
Vigila cambios en la entrada y recarga en vivo. Usa $PORT y $HOST para especificar la dirección de
escucha.
-h, --host localho
st
Dirección de escucha del host cuando se usa con watc
h.
-p, --port
0
Puerto de escucha cuando se usa con watc
h.
-t, --theme
0
Establece el ID del tema del
diagrama.
--dark-theme -
1
El tema a usar cuando el navegador del visor está en modo oscuro. Cuando se deja sin definir --theme se usa tanto para el modo claro como para el oscuro. Ten en cuenta que los estilos explícitos establecidos en el código D2 seguirán aplicándose y esto puede producir resultados inesperados. Planeamos resolver esto haciendo que los mapas de estilos en D2 sean específicos para modo claro/oscuro. Ver https://github.com/terrastruct/d2/issues/8
31.
-s, --sketch fal
se
Renderiza el diagrama para que parezca que fue dibujado a
mano.
--center fl
ag
Centra el SVG en el viewbox que lo contiene, como la pantalla de tu
navegador.
--scale -
1
Escala la salida. Por ejemplo, 0.5 para reducir a la mitad el tamaño predeterminado. El valor predeterminado -1 significa que los SVG se ajustarán a la pantalla y todos los demás usarán su tamaño de renderizado predeterminado. Establecerlo en 1 desactiva el ajuste del SVG a la
pantalla.
--font-regul
ar
Ruta al archivo .ttf a usar para la fuente regular. Si no se proporciona ninguna, se usa Source Sans Pro
Regular.
--font-ital
ic
Ruta al archivo .ttf a usar para la fuente cursiva. Si no se proporciona ninguna, se usa Source Sans Pro
Regular-Italic.
--font-bo
ld
Ruta al archivo .ttf a usar para la fuente negrita. Si no se proporciona ninguna, se usa Source Sans Pro
Bold.
--font-semib
old
Ruta al archivo .ttf a usar para la fuente seminegrita. Si no se proporciona ninguna, se usa Source Sans Pro
Semibold.
--font-mo
no
Ruta al archivo .ttf a usar para la fuente monoespaciada. Si no se proporciona ninguna, se usa Source Code Pro
Regular.
--font-mono-b
old
Ruta al archivo .ttf a usar para la fuente monoespaciada negrita. Si no se proporciona ninguna, se usa Source Code Pro
Bold.
--font-mono-ita
lic
Ruta al archivo .ttf a usar para la fuente monoespaciada cursiva. Si no se proporciona ninguna, se usa Source Code Pro
Italic.
--font-mono-semib
old
Ruta al archivo .ttf a usar para la fuente monoespaciada seminegrita. Si no se proporciona ninguna, se usa Source Code Pro
Semibold.
--pad 10
0
Píxeles de relleno alrededor del diagrama
renderizado.
--animate-interval
0
Si se proporciona, múltiples tableros se empaquetan como 1 SVG que transiciona a través de cada tablero en el intervalo (en milisegundos). Solo se puede usar con exportaciones SVG y
GIF.
--browser tr
ue
Ejecutable del navegador que watch abre. Establecerlo a 0 no abre ningún
navegador.
-l, --layout dag
re
Establece el motor de diseño del diagrama a la cadena pasada. Para una lista de opciones disponibles, ejecuta layou
t.
-b, --bundle tr
ue
Agrupa todos los recursos y capas en el svg de
salida.
--force-appendix fal
se
Se añade un apéndice para tooltips y enlaces a las exportaciones PNG ya que no son interactivas. Establecer esto a true añade un apéndice también a las exportaciones
SVG.
--targ
et
Tablero objetivo a renderizar. Pasa una cadena vacía para apuntar al tablero raíz. Si el objetivo termina con '*', se renderizará con todos sus escenarios, pasos y capas. De lo contrario, solo se renderizará el tablero objetivo. Por ejemplo, --target='' para renderizar solo el tablero raíz o --target='layers.x.*' para renderizar la capa 'x' con todos sus
hijos.
-d, --deb
ug
Imprime registros de
depuración.
--img-cache tr
ue
En modo watch, las imágenes usadas en los iconos se almacenan en caché para compilaciones posteriores. Esto debería desactivarse si las imágenes podrían
cambiar.
--timeout 12
0
El número máximo de segundos que D2 se ejecuta antes de agotar el tiempo de espera y salir. Al renderizar un diagrama grande, se recomienda aumentar este
valor.
--check fal
se
Comprueba que los archivos especificados estén formateados
correctamente.
--salt stri
ng
Añade un valor de sal para asegurar que la salida use IDs únicos. Esto es útil al generar múltiples diagramas idénticos para incluirlos en el mismo documento HTML, de modo que los IDs duplicados no causen HTML inválido. El valor de sal es una cadena que se añadirá a los IDs en la
salida.
-h, --he
lp
Imprime información de uso y
sale.
-v, --versi
on
Imprime información de versión y
sale.
--stdout-format stri
ng
Establece el formato de salida al escribir en stdout. Los formatos soportados son: png, svg, ascii, txt, pdf, pptx, gif. Solo se usa cuando la salida está configurada como stdout
(-).
--no-xml-tag fal
se
Omite la etiqueta XML (<?xml ...?>) de los archivos SVG de salida. Útil al generar SVG para incrustarlos directamente en
HTML.
--omit-version fal
se
omite la versión de D2 de la imagen
generada.
--ascii-mode extend
ed
Modo de renderizado ASCII para sa
lidas de texto. Opciones: 'standa
rd' (caracteres ASCII básicos) o
'extended' (caracteres Unicode).
