Documentación de función/subrutina

subrutina dpstf2 (caracter uplo, entero n, doble precisión, dimensión( lda, * ) a, entero lda, entero, dimensión( n ) piv, entero rank, doble precisión tol, doble precisión, dimensión( 2*n ) work, entero info)

DPSTF2 calcula la factorización de Cholesky con pivoteo completo de una matriz real simétrica semidefinida positiva.

Propósito:

!>
!> DPSTF2 calcula la factorización de Cholesky con pivoteo completo
!> de una matriz real simétrica semidefinida positiva A.
!>
!> La factorización tiene la forma
!>    P**T * A * P = U**T * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**T,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior, y
!> P se almacena como el vector PIV.
!>
!> Este algoritmo no intenta verificar si A es semidefinida positiva.
!> Esta versión del algoritmo llama a BLAS de nivel 2.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          superior izquierda de dimensión n por n de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la
!>          parte inferior izquierda de dimensión n por n de A contiene la
!>          parte triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización de
!>          Cholesky como se describió anteriormente.
!>

PIV

!>          PIV es un array INTEGER, de dimensión (N)
!>          PIV es tal que las entradas no nulas son P( PIV(K), K ) = 1.
!>

RANK

!>          RANK es INTEGER
!>          El rango de A dado por el número de pasos que completó el algoritmo.
!>

TOL

!>          TOL es DOUBLE PRECISION
!>          Tolerancia definida por el usuario. Si TOL < 0, se usará
!>          N*U*MAX( A( K,K ) ). El algoritmo termina en el paso (K-1)
!>          si el pivote <= TOL.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (2*N)
!>          Espacio de trabajo.
!>

INFO

!>          INFO es INTEGER
!>          < 0: Si INFO = -K, el K-ésimo argumento tenía un valor ilegal.
!>          = 0: el algoritmo se completó con éxito, y
!>          > 0: la matriz A es de rango deficiente con rango calculado
!>               como se devuelve en RANK, o no es semidefinida positiva.
!>               Consulte la Sección 7 de la Nota de trabajo #161 de LAPACK
!>               para obtener más información.
!>
