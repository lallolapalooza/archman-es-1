NOMBRE

dpkg-genchanges - genera archivos .changes de Debian

SINOPSIS

dpkg-genchanges [opción...]

DESCRIPCIÓN

dpkg-genchanges lee información de un árbol de fuentes Debian desempaquetado y construido, y de los archivos que ha generado, y genera un archivo de control de carga útil de Debian (archivo .changes).

OPCIONES

--build=tipo
Especifica el tipo de construcción a partir de una lista separada por comas de componentes (desde dpkg 1.18.5).

Los valores permitidos son:

source
Cargar el paquete fuente.
any
Cargar los paquetes binarios específicos de arquitectura.
all
Cargar los paquetes binarios independientes de arquitectura.
binary
Cargar los paquetes binarios específicos e independientes de arquitectura. Este es un alias para any,all.
full
Cargar todo. Este es un alias para source,any,all, y lo mismo que el caso por defecto cuando no se especifica ninguna opción de construcción.
-g
Equivalente a --build=source,all (desde dpkg 1.17.11).
-G
Equivalente a --build=source,any (desde dpkg 1.17.11).
-b
Equivalente a --build=binary o --build=any,all.
-B
Equivalente a --build=any.
-A
Equivalente a --build=all.
-S
Equivalente a --build=source.

Las opciones -sx controlan si el archivo fuente original se incluye en la carga útil si se genera algún fuente (es decir, si no se han utilizado -b o -B).

-si
Por defecto, o si se especifica, la fuente original se incluirá solo si el número de versión upstream (la versión sin época y sin revisión de Debian) es diferente del número de versión upstream de la entrada del changelog anterior.
-sa
Fuerza la inclusión de la fuente original.
-sd
Fuerza la exclusión de la fuente original e incluye solo la diferencia (diff).
-vversión
Hace que se utilice la información del changelog de todas las versiones estrictamente posteriores a versión.
-Cdescripción-cambios
Lee la descripción de los cambios del archivo descripción-cambios en lugar de usar la información del archivo changelog del árbol de fuentes.
-mdirección-mantenedor
Usa dirección-mantenedor como el nombre y la dirección de correo electrónico del mantenedor de este paquete, en lugar de usar la información del archivo de control del árbol de fuentes.
-edirección-mantenedor
Usa dirección-mantenedor como el nombre y la dirección de correo electrónico del mantenedor de esta carga útil, en lugar de usar la información del changelog del árbol de fuentes.
-Vnombre=valor
Establece una variable de sustitución de salida. Ver deb-substvars(5) para una discusión sobre la sustitución de salida.
-Tarchivo-variables-sustitucion
Lee las variables de sustitución en el archivo-variables-sustitucion; el valor por defecto es debian/substvars. No se realiza ninguna sustitución de variables en ninguno de los campos que se generan, excepto en el contenido extraído del campo Description de cada paquete binario (desde dpkg 1.19.0), sin embargo, la variable especial Format anulará el campo del mismo nombre. Esta opción se puede usar múltiples veces para leer variables de sustitución de múltiples archivos (desde dpkg 1.15.6).
-Dcampo=valor
Anula o agrega un campo del archivo de control de salida.
-Ucampo
Elimina un campo del archivo de control de salida.
-carchivo-control
Especifica el archivo de control fuente principal para leer información. El valor por defecto es debian/control.
-larchivo-changelog
Especifica el archivo changelog para leer información. El valor por defecto es debian/changelog.
-farchivo-lista-archivos
Lee la lista de archivos a cargar aquí, en lugar de usar debian/files.
-Fformato-changelog
Especifica el formato del changelog. Ver dpkg-parsechangelog(1) para información sobre formatos alternativos.
-udirectorio-archivos-carga
Busca los archivos a cargar en directorio-archivos-carga en lugar de en .. (dpkg-genchanges necesita encontrar estos archivos para poder incluir sus tamaños y sumas de verificación en el archivo .changes).
-q
Normalmente dpkg-genchanges producirá mensajes informativos en el error estándar, por ejemplo sobre cuántos de los archivos fuente del paquete se están cargando. -q suprime estos mensajes.
-O[nombre-archivo]
Imprime el archivo de cambios en la salida estándar (el valor por defecto) o en nombre-archivo si se especifica (desde dpkg 1.18.5).
-?, --help
Muestra el mensaje de uso y sale.
--version
Muestra la versión y sale.

AMBIENTE

DEB_HOST_ARCH
Establece la arquitectura host.
DPKG_COLORS
Establece el modo de color (desde dpkg 1.18.5). Los valores actualmente aceptados son: auto (por defecto), always y never.
DPKG_NLS
Si está establecido, se usará para decidir si activar el soporte de idioma nativo, también conocido como internacionalización (o i18n) (desde dpkg 1.19.0). Los valores aceptados son: 0 y 1 (por defecto).

FICHEROS

debian/files
La lista de archivos generados que forman parte de la carga útil que se está preparando. dpkg-genchanges lee los datos aquí al producir un archivo .changes.

VER TAMBIÉN
