NOMBRE

Dpkg::Deps::Multiple - módulo base para representar dependencias múltiples

DESCRIPCIÓN

El módulo Dpkg::Deps::Multiple proporciona objetos que implementan varios tipos de dependencias. Es la clase base para Dpkg::Deps::{AND,OR,Union}.

MÉTODOS

$dep = Dpkg::Deps::Multiple->new(@deps);
Crea un nuevo objeto, con la lista de dependencias en @deps.
$dep->reset()
Borra cualquier información de dependencia almacenada en $dep para que $dep->is_empty() devuelva true.
$dep->add(@deps)
Añade nuevos objetos de dependencia al final de la lista.
$dep->get_deps()
Devuelve una lista de subdependencias.
$dep->sort()
Ordena alfabéticamente la lista interna de dependencias.
$dep->arch_is_concerned($arch)
Devuelve true si al menos una de las subdependencias se aplica a esta arquitectura.
$dep->reduce_arch($arch)
Simplifica las dependencias para contener solo la información relevante para la arquitectura dada. Las subdependencias no relevantes se eliminan simplemente.

Esto recorta la lista de restricciones de arquitectura de los objetos Dpkg::Deps::Simple.

$dep->has_arch_restriction()
Devuelve la lista de nombres de paquetes que tienen dicha restricción.
$dep->profile_is_concerned()
Devuelve true si al menos una de las subdependencias se aplica a este perfil.
$dep->reduce_profiles()
Simplifica las dependencias para contener solo la información relevante para el perfil dado. Las subdependencias no relevantes se eliminan simplemente.

Esto recorta la lista de restricciones de perfil de los objetos Dpkg::Deps::Simple.

$dep->is_empty()
Devuelve true si la dependencia está vacía y no contiene información útil. Esto es cierto cuando un (descendiente de) Dpkg::Deps::Multiple contiene una lista vacía de dependencias.
$dep->merge_union($other_dep)
Este método no tiene sentido para este objeto y siempre fallará.
