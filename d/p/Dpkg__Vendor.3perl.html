NOMBRE

Dpkg::Vendor - obtener acceso a cierta información específica del proveedor

DESCRIPCIÓN

Los archivos en $Dpkg::CONFDIR/origins/ pueden proporcionar información sobre varios proveedores que distribuyen paquetes Debian. Actualmente, esos archivos se ven así:

Vendor: Debian
Vendor-URL: https://www.debian.org/
Bugs: debbugs://bugs.debian.org

Si el proveedor deriva de otro proveedor, el archivo debe documentar la relación listando la distribución base en el campo Parent:

Parent: Debian

El archivo debe nombrarse según el nombre del proveedor. La convención usual es nombrar el archivo del proveedor usando el nombre del proveedor en minúsculas, pero se permite alguna variación. En particular, los espacios se mapean a guiones ('-'), y el archivo puede tener la misma capitalización que el campo Vendor, o puede estar en mayúsculas.

FUNCIONES

$dir = get_vendor_dir()
Devuelve el nombre del directorio de orígenes de dpkg actual, donde se almacenan los archivos del proveedor.
$fields = get_vendor_info([$name])
Devuelve un objeto Dpkg::Control con la información analizada del archivo del proveedor correspondiente en $Dpkg::CONFDIR/origins/. Si se omite $name, utilizará $Dpkg::CONFDIR/origins/default, que se supone que es un enlace simbólico al proveedor del sistema operativo actualmente instalado. Devuelve undef si no hay archivo para el proveedor dado.
$name = get_vendor_file([$name])
Comprueba si existe un archivo para el proveedor dado y devuelve su nombre.

El nombre del archivo del proveedor se derivará del nombre del proveedor, reemplazando cualquier número de caracteres no alfanuméricos (es decir, [^A-Za-z0-9]) por "-", luego se intentará el nombre resultante en secuencia, pasándolo a minúsculas, dejándolo tal cual, pasándolo a minúsculas y luego capitalizándolo, y capitalizándolo.

$name = get_current_vendor()
Devuelve el nombre del proveedor actual. Si DEB_VENDOR está configurado, lo utiliza primero, de lo contrario, recurre al análisis de $Dpkg::CONFDIR/origins/default. Si ese archivo no existe, devuelve undef.
$object = get_vendor_object($name)
Devuelve el objeto Dpkg::Vendor::* del proveedor correspondiente. Si se omite $name, devuelve el objeto del proveedor actual. Si no se puede identificar ningún proveedor, devuelve el objeto Dpkg::Vendor::Default.

El nombre del módulo se derivará del nombre del proveedor, dividiendo las partes alrededor de grupos de separadores de caracteres no alfanuméricos (es decir, [^A-Za-z0-9]), ya sea capitalizando o poniendo en minúsculas y capitalizando cada parte, y luego uniéndolas sin los separadores. Por lo tanto, la capitalización esperada se basa en la del campo Vendor en el archivo origins.

ejecutar_hook_proveedor($hookid, @params)
Ejecuta un hook implementado por el objeto proveedor actual.

CAMBIOS

Versión 1.03 (dpkg 1.22.12)

Comportamiento obsoleto: get_vendor_file() y get_vendor_object() ya no admiten el comportamiento obsoleto de 1.02.

Versión 1.02 (dpkg 1.21.10)

Comportamiento obsoleto: get_vendor_file() carga archivos de proveedor sin reasignación de caracteres especiales. get_vendor_object() carga nombres de módulos de proveedor sin eliminación de caracteres especiales.

Versión 1.01 (dpkg 1.17.0)

Nueva función: get_vendor_dir().

Versión 1.00 (dpkg 1.16.1)

Marca el módulo como público.
