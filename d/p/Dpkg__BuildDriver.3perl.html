NOMBRE

Dpkg::BuildDriver - dirigir la construcción de un paquete Debian

DESCRIPCIÓN

Esta clase es utilizada por dpkg-buildpackage para dirigir la construcción de un paquete Debian.

Nota: Este es un módulo privado, su API puede cambiar en cualquier momento.

MÉTODOS

$bd = Dpkg::BuildDriver->new(%opts)
Crea un nuevo objeto Dpkg::BuildDriver. Cargará un módulo controlador de construcción según lo solicitado en el campo Build-Drivers del objeto Dpkg::Control::Info $opts{ctrl} o, si no está presente, recurrirá a cargar el controlador predeterminado debian-rules.

Opciones:

ctrl (requerido)
Un objeto Dpkg::Control::Info.
root_cmd
Una cadena con el comando gain-root-command a utilizar cuando se necesite ejecutar un comando con derechos de root. Si es necesario y no se establece, se utilizará fakeroot por defecto si está disponible, o el módulo fallará.
as_root
Un booleano para forzar las llamadas al objetivo debian/rules como root, incluso si normalmente no requerirían ser ejecutadas como root. Esta opción se aplica a todos los objetivos de forma global.

Nota: Esta opción solo es relevante para los controladores que utilizan debian/rules.

debian_rules
Un array que contiene el comando para ejecutar el archivo debian/rules y cualquier argumento adicional. Por defecto es debian/rules.

Nota: Esta opción solo es relevante para los controladores que utilizan debian/rules.

rrr_override
Una cadena que anula el valor del campo Rules-Requires-Root.

Nota: Esta opción solo es relevante para los controladores que utilizan debian/rules.

$bd->pre_check()
Realiza comprobaciones específicas del controlador de construcción, antes de cualquier otra cosa.

Esto se ejecutará después del hook init, y antes de "dpkg-source --before-build".

Nota: Este es un método opcional que puede omitirse en la implementación del controlador.

$bool = $bd->need_build_task($build_task, $binary_task)
Devuelve si necesitamos usar la tarea de construcción.

Nota: Este método es necesario mientras soportemos construir como root. Una vez que esto no sea necesario, este método será obsoleto.

$bd->run_build_task($build_task, $binary_task)
Ejecuta la tarea de construcción para la construcción.

Nota: Este es un método opcional necesario mientras soportemos construir como root. Una vez que esto no sea necesario, este método será obsoleto.

$bd->run_task($task)
Ejecuta la tarea dada para la construcción.
