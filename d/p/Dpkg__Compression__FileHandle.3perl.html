Dpkg::Compression::FileHandle(3perl) libdpkg-perl Dpkg::Compression::FileHandle(3perl)

NOMBRE

Dpkg::Compression::FileHandle - clase que maneja de forma transparente la compresión de archivos

SINOPSIS

use Dpkg::Compression::FileHandle;
my ($fh, @lines);
$fh = Dpkg::Compression::FileHandle->new(filename => 'sample.gz');
print $fh "Something\n";
close $fh;
$fh = Dpkg::Compression::FileHandle->new();
open($fh, '>', 'sample.bz2');
print $fh "Something\n";
close $fh;
$fh = Dpkg::Compression::FileHandle->new();
$fh->open('sample.xz', 'w');
$fh->print("Something\n");
$fh->close();
$fh = Dpkg::Compression::FileHandle->new(filename => 'sample.gz');
@lines = <$fh>;
close $fh;
$fh = Dpkg::Compression::FileHandle->new();
open($fh, '<', 'sample.bz2');
@lines = <$fh>;
close $fh;
$fh = Dpkg::Compression::FileHandle->new();
$fh->open('sample.xz', 'r');
@lines = $fh->getlines();
$fh->close();

DESCRIPCIÓN

Dpkg::Compression::FileHandle es una clase que puede usarse como cualquier manejador de archivos (filehandle) y que maneja de forma transparente los archivos comprimidos. Por defecto, el esquema de compresión se deduce del nombre del archivo, pero puedes anular este comportamiento con el método set_compression().

Si no abres el archivo explícitamente, se abrirá automáticamente en la primera operación de lectura o escritura basándose en el nombre de archivo establecido en el momento de la creación (o más tarde con el método set_filename() ).

Una vez que un archivo ha sido abierto, el manejador de archivos debe cerrarse antes de poder abrir otro archivo.

FUNCIONES ESTÁNDAR

Las funciones estándar que actúan sobre manejadores de archivos deberían aceptar un objeto Dpkg::Compression::FileHandle de forma transparente, incluyendo open() (solo al usar la variante con 3 parámetros), close(), binmode(), eof(), fileno(), getc(), print(), printf(), read(), sysread(), say(), write(), syswrite(), seek(), sysseek(), tell().

Sin embargo, ten en cuenta que seek() y sysseek() solo funcionarán en archivos sin comprimir, ya que los archivos comprimidos son realmente tuberías (pipes) hacia los programas de compresión y no puedes hacer seek en una tubería.

MÉTODOS DE FileHandle

La clase hereda de IO::File, por lo que todos los métodos que funcionan en esta clase deberían funcionar también para Dpkg::Compression::FileHandle. Sin embargo, puede haber excepciones.

MÉTODOS PÚBLICOS

$fh = Dpkg::Compression::FileHandle->new(%opts)
Crea un nuevo manejador de archivos que soporta compresión/descompresión en tiempo real.

Opciones:

filename
Ver $fh->set_filename().
compression
Ver $fh->set_compression().
compression_level
Ver $fh->set_compression_level().
add_comp_ext
Si se establece en true, la extensión correspondiente al esquema de compresión seleccionado se añade automáticamente al nombre de archivo registrado. Obviamente, es incompatible con la detección automática del método de compresión.
$fh->ensure_open($mode, %opts)
Asegura que el archivo esté abierto en el modo solicitado ("r" para lectura y "w" para escritura). Las opciones se pasan a la llamada spawn() del compresor, si se usa uno. Abre el archivo con el nombre registrado si es necesario. Si el archivo ya está abierto pero no en el modo solicitado, genera un error.
$fh->set_compression($comp)
Define el método de compresión utilizado. $comp debería ser uno de los métodos soportados por Dpkg::Compression o "none" o "auto". "none" indica que el archivo no está comprimido y "auto" indica que el método debe deducirse basándose en la extensión del nombre de archivo utilizado.
$fh->set_compression_level($level)
Indica el nivel de compresión deseado. Debería ser un valor aceptado por la función compression_is_valid_level() de Dpkg::Compression.
$fh->set_filename($name, [$add_comp_ext])
Usa $name como nombre de archivo cuando el archivo deba ser abierto/creado. Si se pasa $add_comp_ext , indica si la extensión por defecto del método de compresión debe añadirse automáticamente al nombre de archivo (o no).
$file = $fh->get_filename()
Devuelve el nombre de archivo que se usaría cuando el manejador de archivos deba ser abierto (tanto en modo lectura como escritura). Esta función genera un error si "add_comp_ext" está habilitado mientras el método de compresión está establecido en "auto". El nombre de archivo devuelto incluye la extensión del método de compresión si "add_comp_ext" está habilitado.
$ret = $fh->use_compression()
Devuelve "0" si no se usa compresión y el método de compresión utilizado en caso contrario. Si la compresión está establecida en "auto", el valor devuelto depende de la extensión del nombre de archivo obtenido con el método get_filename() .
$real_fh = $fh->get_filehandle()
Devuelve el manejador de archivos subyacente real. Útil si deseas pasarlo en una clase derivada.

CLASES DERIVADAS

Si deseas crear una clase que herede de Dpkg::Compression::FileHandle, debes tener en cuenta que el objeto es una referencia a un GLOB que es devuelta por Symbol::gensym() y como tal no es un HASH.

Puedes almacenar datos internos en un hash, pero debes usar "*$self-"{...}> para acceder al hash asociado, como en el ejemplo siguiente:

sub set_option {
    my ($self, $value) = @_;
    *$self->{option} = $value;
}
