ARCHIVOS

debian/source/format

Este archivo contiene en una sola línea el formato que debe usarse para construir el paquete fuente (los formatos posibles se describen arriba). No se permiten espacios al principio o al final.

debian/source/include-binaries

Este archivo contiene una lista de rutas de archivos binarios (uno por línea) relativas al directorio raíz de la fuente que deben incluirse en el tarball de debian. Se eliminan los espacios iniciales y finales. Las líneas que comienzan con ‘#’ son comentarios y se omiten. Las líneas vacías se ignoran.

debian/source/options

Este archivo contiene una lista de opciones largas que deben anteponerse automáticamente al conjunto de opciones de la línea de comandos de una dpkg-source --build o dpkg-source --print-format llamada. Opciones como --compression y --compression-level son muy adecuadas para este archivo.

Cada opción debe ponerse en una línea separada. Las líneas vacías y las líneas que comienzan con ‘#’ se ignoran. El ‘--’ inicial debe eliminarse y no se permiten opciones cortas. Se permiten espacios opcionales alrededor del símbolo ‘=’ y se permiten comillas opcionales alrededor del valor. Aquí hay un ejemplo de un archivo así:

# let dpkg-source create a debian.tar.bz2 with maximal compression
compression = "bzip2"
compression-level = 9
# use debian/patches/debian-changes as automatic patch
single-debian-patch
# ignore changes on config.{sub,guess}
extend-diff-ignore = "(^|/)(config.sub|config.guess)$"

Nota: format las opciones no se aceptan en este archivo, debería usar debian/source/format en su lugar.

debian/source/local-options

Exactamente igual que debian/source/options excepto que el archivo no se incluye en el paquete fuente generado. Puede ser útil almacenar una preferencia vinculada al mantenedor o al repositorio VCS donde se mantiene el paquete fuente.

debian/source/local-patch-header

debian/source/patch-header

Texto de forma libre que se coloca en la parte superior del parche automático generado en los formatos “2.0” o “3.0 (quilt)”. local-patch-header no se incluye en el paquete fuente generado mientras que patch-header sí.

debian/patches/vendor.series

debian/patches/series

Este archivo lista todos los parches que deben aplicarse (en el orden dado) sobre el paquete fuente original. Se eliminan los espacios iniciales y finales. El vendor será el nombre en minúsculas del proveedor actual, o debian si no hay proveedor definido. Si el archivo de series específico del proveedor no existe, se usará el archivo de series sin proveedor. Las líneas que comienzan con ‘#’ son comentarios y se omiten. Las líneas vacías se ignoran. Las líneas restantes comienzan con un nombre de archivo de parche (relativo al directorio debian/patches/ ) hasta el primer carácter de espacio o el final de la línea. Se pueden seguir opciones opcionales de quilt hasta el final de la línea o el primer ‘#’ precedido por uno o más espacios (lo que marca el inicio de un comentario hasta el final de la línea).

SEGURIDAD

Examinar paquetes fuente no confiables o extraerlos en directorios de preparación debe considerarse un límite de seguridad, y cualquier violación de ese límite derivada de estas operaciones debe considerarse una vulnerabilidad de seguridad. Pero el manejo de paquetes fuente no confiables no debe hacerse a la ligera, ya que la superficie de ataque incluye cualquier comando de compresión soportado, comandos para manejar formatos de datos específicos (como tar(1) o patch(1)) además de los formatos de paquete fuente y los archivos de control en sí. Realizar estas operaciones sobre datos no confiables como root está fuertemente desaconsejado.

La construcción de paquetes fuente solo debe realizarse sobre datos confiables.

ERRORES
