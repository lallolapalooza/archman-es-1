NOMBRE

dpkg-scansources - crea archivos de índice Sources

SINOPSIS

dpkg-scansources [opción...] directorio-binarios [archivo-de-anulación [prefijo-ruta]] > Sources

DESCRIPCIÓN

dpkg-scansources escanea el directorio-binarios dado en busca de archivos .dsc. Estos se utilizan para crear un índice de fuentes de Debian, que se envía a la salida estándar.

El archivo-de-anulación, si se proporciona, se utiliza para establecer prioridades en las estrofas del índice resultante y para anular el campo de mantenedor dado en los archivos .dsc. El archivo puede estar comprimido (desde dpkg 1.15.5). Consulte deb-override(5) para conocer el formato de este archivo.

Nota: Dado que el archivo de anulación se indexa por paquete binario, no por paquete fuente, hay un pequeño problema aquí. La implementación actual utiliza la prioridad más alta de todos los paquetes binarios producidos por un archivo .dsc para la prioridad del paquete fuente, y la entrada de anulación del primer paquete binario listado en el archivo .dsc para modificar la información del mantenedor. Esto podría cambiar.

El prefijo-ruta, si se proporciona, se antepone al campo directorio en el índice de fuentes generado. Generalmente lo utiliza para que los campos de directorio contengan la ruta desde la parte superior de la jerarquía del archivo de Debian.

Nota: Si desea acceder al archivo Sources generado con apt(8), probablemente necesitará comprimir el archivo con gzip(1) (generando un archivo Sources.gz). apt(8) ignora los archivos Sources sin comprimir excepto en el acceso local (es decir, fuentes file://).

OPCIONES

-n, --no-sort
No ordenar las estrofas del índice. Normalmente se ordenan por nombre de paquete fuente.
-e, --extra-override archivo
Escanear archivo para encontrar anulaciones suplementarias (desde dpkg 1.15.4; el archivo puede estar comprimido desde dpkg 1.15.5). Consulte deb-extra-override(5) para más información sobre su formato.
-s, --source-override archivo
Utilizar archivo como archivo de anulación de fuentes (el archivo puede estar comprimido desde dpkg 1.15.5). El valor predeterminado es el nombre del archivo de anulación que especificó con .src añadido.

El archivo de anulación de fuentes tiene un formato diferente al del archivo de anulación de binarios. Contiene solo dos campos separados por espacios en blanco, el primero es el nombre del paquete fuente y el segundo es la sección. Las líneas en blanco y las líneas de comentarios se ignoran de la manera habitual. Si un paquete aparece en ambos archivos, la anulación de fuentes tiene prioridad para establecer la sección.

--debug
Activar depuración.
--help
Mostrar el mensaje de uso y salir.
--version
Mostrar la versión y salir.

ENTORNO

DPKG_COLORS
Establece el modo de color (desde dpkg 1.18.5). Los valores actualmente aceptados son: auto (predeterminado), always y never.
DPKG_NLS
Si está configurado, se utilizará para decidir si se activa el Soporte de Idioma Nativo, también conocido como internacionalización (o i18n) (desde dpkg 1.19.0). Los valores aceptados son: 0 y 1 (predeterminado).

VER TAMBIÉN

deb-override(5), deb-extra-override(5), dpkg-scanpackages(1).
