DPOSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

PO

Propósito

: 
!>
!>    DPOSVXX usa la factorización de Cholesky A = U**T*U o A = L*L**T
!>    para calcular la solución a un sistema de ecuaciones lineales de
!>    doble precisión A * X = B, donde A es una matriz simétrica definida
!>    positiva de N por N y X y B son matrices de N por NRHS.
!>
!>    Si se solicita, se devuelven tanto límites de error en norma como
!>    límites de error máximo componente a componente. DPOSVXX devolverá
!>    una solución con un error garantizado diminuto (O(eps) donde eps es
!>    la precisión de trabajo de la máquina) a menos que la matriz esté
!>    muy mal condicionada, en cuyo caso se devuelve una advertencia. Los
!>    números de condición relevantes también se calculan y se devuelven.
!>
!>    DPOSVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; vea las definiciones de las opciones
!>    FACT y EQUED. Resolver con refinamiento y usando una factorización
!>    de una llamada anterior a DPOSVXX también producirá una solución
!>    con errores O(eps) o advertencias, pero no podemos hacer esa
!>    afirmación para factorizaciones y factores de equilibrado
!>    proporcionados por el usuario si difieren de lo que DPOSVXX
!>    produciría por sí mismo.
!
>

Descripción

: 
!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para equilibrar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibra o no depende de la
!>    escala de la matriz A, pero si se usa equilibración, A se
!>    sobrescribe por diag(S)*A*diag(S) y B por diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz
!>    triangular inferior.
!>
!>    3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina devuelve con INFO = i. De lo contrario, se usa
!>    la forma factorizada de A para estimar el número de condición de la
!>    matriz A (vea el argumento RCOND). Si el recíproco del número de
!>    condición es menor que la precisión de la máquina, la rutina
!>    continúa para resolver X y calcular límites de error como se
!>    describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X usando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina usará refinamiento iterativo para intentar obtener un
!>    error pequeño y límites de error. El refinamiento calcula el
!>    residuo con al menos el doble de la precisión de trabajo.
!>
!>    6. Si se usó equilibración, la matriz X se premultiplica por
!>    diag(S) de modo que resuelve el sistema original antes del
!>    equilibrado.
!
> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores por defecto son aceptables. Si los valores por defecto
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0 lo que
!>     impide que el código fuente acceda al argumento PARAMS.
!
>

Parámetro

s
FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada, y si no, si la matriz A debe
!>     equilibrarse antes de ser factorizada.
!>       = 'F':  En la entrada, AF contiene la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por S.
!>               A y AF no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>     En la entrada, la matriz simétrica A, excepto si FACT = 'F' y EQUED =
!>     'Y', entonces A debe contener la matriz equilibrada
!>     diag(S)*A*diag(S).  Si UPLO = 'U', la parte triangular superior
!>     principal N por N de A contiene la parte triangular superior de la
!>     matriz A, y la parte estrictamente triangular inferior de A no se
!>     referencia.  Si UPLO = 'L', la parte triangular inferior principal
!>     N por N de A contiene la parte triangular inferior de la matriz A,
!>     y la parte estrictamente triangular superior de A no se
!>     referencia.  A no se modifica si FACT = 'F' o 'N', o si FACT = 'E' y EQUED =
!>     'N' en la salida.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe por
!>     diag(S)*A*diag(S).
!
>

LD

A 
!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!
>

A

F 
!>          AF es un array DOUBLE PRECISION, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>     entrada contiene el factor triangular U o L de la factorización
!>     de Cholesky A = U**T*U o A = L*L**T, en el mismo formato de
!>     almacenamiento que A.  Si EQUED .ne. 'N', entonces AF es la forma
!>     factorizada de la matriz equilibrada diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la
!>     salida devuelve el factor triangular U o L de la factorización
!>     de Cholesky A = U**T*U o A = L*L**T de la matriz original
!>     A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y en la
!>     salida devuelve el factor triangular U o L de la factorización
!>     de Cholesky A = U**T*U o A = L*L**T de la matriz equilibrada
!>     A (see la descripción de A para la forma de la
!>     matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre cierto si FACT = 'N').
!>       = 'Y':  Equilibrado tanto por filas como por columnas, es decir, A ha sido
!>               reemplazada por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de fila para A.  Si EQUED = 'Y', A se multiplica por
!>     diag(S) a la izquierda y a la derecha.  S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida.  Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo.  Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
!>     de S debería ser una potencia de la base para asegurar una solución
!>     fiable y estimaciones de error. El escalado por potencias de la base no causa
!>     errores de redondeo a menos que el resultado desborde por arriba o por abajo.
!>     Los errores de redondeo durante el escalado conducen a refinar con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>     En la entrada, la matriz del lado derecho B de tamaño N-por-NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe con diag(S)*B;
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz solución X de tamaño N-por-NRHS al sistema original
!>     de ecuaciones.  Tenga en cuenta que A y B se modifican en la salida si
!>     EQUED .ne. 'N', y la solución al sistema equilibrado es
!>     inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Recíproco del número de condición escalado.  Esta es una estimación del
!>     recíproco del número de condición de Skeel de la matriz A después del
!>     equilibrado (si se hizo).  Si esto es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo.  Tenga en cuenta que el error puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     Recíproco del crecimiento del pivote.  En la salida, esto contiene el recíproco
!>     del factor de crecimiento del pivote norm(A)/norm(U). Se usa la
!>     norma.  Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (equilibrada) podría ser pobre.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y los límites de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el recíproco del factor de crecimiento del pivote
!>     para las primeras INFO columnas de A.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>     Error hacia atrás relativo componente a componente.  Este es el
!>     error hacia atrás relativo componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (en norma o componente a componente).  Vea ERR_BNDS_NORM y
!>     ERR_BNDS_COMP más abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Error relativo en norma en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco estimado del
!>              número de condición en norma.  Se compara con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la estimación
!>              de error es . Estos recíprocos de los números de condición
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de modo que todas las sumas absolutas de filas de Z sean aproximadamente 1.
!>
!>     Vea la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información de
!>     error como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada lado derecho. Si
!>     la precisión componente a componente no se solicita (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no se accede.  Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              recíproco del número de condición es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo
!>              debe confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Recíproco del número de condición: Recíproco estimado del
!>              número de condición componente a componente.  Se compara con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la estimación
!>              de error es . Estos recíprocos de los números de condición
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z escalada apropiadamente.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base de modo que todas las sumas
!>              absolutas de filas de Z sean aproximadamente 1.
!>
!>     Vea la Nota de Trabajo de Lapack 165 para más detalles y precauciones
!>     adicionales.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS.  Si <= 0, el
!>     array PARAMS nunca se referencia y se usan valores predeterminados.
!>

PARAMS

!>          PARAMS es un array DOUBLE PRECISION, dimensión NPARAMS
!>     Especifica los parámetros del algoritmo.  Si una entrada es < 0.0, entonces
!>     esa entrada se rellenará con el valor predeterminado usado para ese
!>     parámetro.  Solo se accede a las posiciones hasta NPARAMS; se usan los valores
!>     predeterminados para los parámetros de número más alto.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar refinamiento
!>            iterativo o no.
!>         Predeterminado: 1.0D+0
!>            = 0.0:  No se realiza refinamiento y no se calculan
!>                    límites de error.
!>            = 1.0:  Usar el algoritmo de refinamiento de precisión extra.
!>              (otros valores están reservados para uso futuro)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Número máximo de cálculos de residuo
!>            permitidos para el refinamiento.
!>         Predeterminado: 10
!>         Agresivo: Establecer en 100 para permitir la convergencia usando
!>                     factorizaciones aproximadas o factorizaciones distintas de LU. Si
!>                     la factorización usa una técnica distinta de la
!>                     eliminación gaussiana, las garantías en
!>                     err_bnds_norm y err_bnds_comp pueden dejar de ser
!>                     confiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Bandera que determina si el código
!>            intentará encontrar una solución con pequeño error relativo
!>            componente a componente en el algoritmo de doble precisión.  Positivo
!>            es verdadero, 0.0 es falso.
!>         Predeterminado: 1.0 (intentar convergencia componente a componente)
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (4*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa. La solución a cada lado derecho está
!>         garantizada.
!>       < 0:  Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>       > 0 y <= N:  U(INFO,INFO) es exactamente cero.  La factorización
!>         se ha completado, pero el factor U es exactamente singular, por lo que
!>         la solución y los límites de error no pudieron calcularse. Se devuelve RCOND = 0.
!>       = N+J: La solución correspondiente al J-ésimo lado derecho no está
!>         garantizada. Las soluciones correspondientes a otros lados
!>         derechos K con K > J pueden no estar garantizadas tampoco, pero
!>         solo se informa del primer lado derecho de este tipo. Si no se solicita un pequeño
!>         error componente a componente (PARAMS(3) = 0.0) entonces
!>         el J-ésimo lado derechoight-hand side is the first with a normwise error
!>         bound that is not guaranteed (the smallest J such
!>         that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
!>         the Jth right-hand side is the first with either a normwise or
!>         componentwise error bound that is not guaranteed (the smallest
!>         J such that either ERR_BNDS_NORM(J,1) = 0.0 or
!>         ERR_BNDS_COMP(J,1) = 0.0). See the definition of
!>         ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
!>         about all of the right-hand sides check ERR_BNDS_NORM or
!>         ERR_BNDS_COMP.
!
>
