NOMBRE

dpkg-build-api - nivel de API de construcción de paquetes fuente dpkg

SINOPIS

Build-Depends:
 dpkg-build-api (= 1),

DESCRIPCIÓN

El nivel de API de construcción de paquetes fuente dpkg, define una interfaz versionada para paquetes fuente, donde cada nivel de API proporciona comportamientos y garantías específicas.

Estas interfaces pueden ser adoptadas por los paquetes de forma gradual y eliminadas más fácilmente que con cambios de comportamiento globales.

La declaración de este nivel de API se realiza a través de las dependencias de construcción, en una de las secciones Build-Depends, Build-Depends-Indep o Build-Depends-Arch, o a través de la variable de entorno DPKG_BUILD_API, que anulará estas si ambas están presentes, y podría emitir una advertencia en caso de que sean diferentes.

NIVELES DE API

v2
Este nivel aún está en desarrollo y no se puede declarar a través de dependencias de construcción.
v1
Este es el nivel recomendado. Desde dpkg 1.22.0.

Cambios desde v0:

  • dpkg-shlibdeps ya no utiliza la variable de entorno LD_LIBRARY_PATH. En su lugar, se debe utilizar la opción -l.
  • dpkg-buildpackage utiliza por defecto el valor no para Rules-Requires-Root. Para restaurar el comportamiento de v0 (de antes de dpkg 1.22.13), Rules-Requires-Root debe configurarse a binary-targets.
  • dpkg-buildpackage espera que todos los objetivos requeridos de debian/rules sean compatibles y ya no tiene código de respaldo de compatibilidad. Los objetivos requeridos son clean, build, build-indep, build-arch, binary-indep y binary-arch.
  • vendor.mk utiliza por defecto dpkg_vendor_derives_from_v1 para la macro dpkg_vendor_derives_from. Para restaurar el comportamiento de v0, establezca dpkg_vendor_derives_from a dpkg_vendor_derives_from_v0.
  • default.mk incluye por defecto buildtools.mk.
v0
Este es el nivel global actual, equivalente a no especificar ninguno. Las interfaces y los comportamientos proporcionados están sujetos a las actualizaciones normales de la interfaz global, que tienden a requerir ciclos de desaprobación más largos y/o transiciones coordinadas.
