DESCRIPCIÓ

N

dpkg-genbuildinfo lee información de un árbol de código fuente de Debian desempaquetado y compilado y de los archivos que ha generado, y genera un archivo de control de Debian que describe el entorno de compilación y los artefactos de compilación (archivo .buildinfo)

.

Este programa

se introdujo en
dpkg 1.18.11.

DEB_BUILD_OPTI
ONS
Esta variable se puede usar para habilitar o deshabilitar varias características que afectan la información incluida en el archivo .buildinfo, a través de la opción buildinfo (desde dpkg 1.18.19). Esta opción contiene una lista de características separadas por comas, precedidas por los modificadores ‘+’ o ‘-’, para indicar si se deben habilitar o deshabilitar. La característica especial “all” se puede usar para habilitar o deshabilitar todas las demás características. La característica “path” controla si se debe incluir incondicionalmente el campo Build
-Path.
DEB_BUILD_AR
CH
Establece la arquitectura de compilación. Esto afecta el valor del campo Build-Architecture, y la comprobación del modo de compilación
cruzada.
DEB_HOST_AR
CH
Establece la arquitectura de destino. Esto afecta el nombre de archivo utilizado para el archivo .buildinfo, y la comprobación del modo de compilación
cruzada.
DPKG_COLO
RS
Establece el modo de color (desde dpkg 1.18.5). Los valores aceptados actualmente son: auto (predeterminado), always y neve
r.
