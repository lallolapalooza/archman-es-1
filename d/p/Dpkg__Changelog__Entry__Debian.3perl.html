NOMBRE

Dpkg::Changelog::Entry::Debian - representa una entrada de changelog de Debian

DESCRIPCIÓN

Esta clase representa una entrada de changelog de Debian. Implementa la interfaz genérica Dpkg::Changelog::Entry. Solo se describen las funciones específicas de esta implementación, el resto se hereda.

MÉTODOS

@items = $entry->get_change_items()
Devuelve una lista de elementos de cambio. Cada elemento contiene al menos una línea. Una línea de cambio que comienza con un asterisco indica el inicio de un nuevo elemento. Cualquier línea de cambio como ""[ Raphaël Hertzog ]"" se trata como un elemento propio, incluso si inicia un conjunto de elementos atribuidos a esta persona (la siguiente línea necesariamente comenzará un nuevo elemento).
@errors = $entry->parse_header()
@errors = $entry->parse_trailer()
Devuelve una lista de errores. Cada elemento de la lista es un mensaje de error que describe el problema. Si se devuelve la lista vacía, no se han encontrado errores.
$entry->normalize()
Normaliza el contenido. Elimina los espacios en blanco al final de las líneas, utiliza una única línea vacía para separar cada parte.
$src = $entry->get_source()
Devuelve el nombre del paquete fuente asociado a la entrada del changelog.
$ver = $entry->get_version()
Devuelve la versión asociada a la entrada del changelog.
@dists = $entry->get_distributions()
Devuelve una lista de distribuciones de destino para esta versión.
$ctrl = $entry->get_optional_fields()
Devuelve un conjunto de campos opcionales expuestos por la entrada del changelog. Siempre devuelve un objeto Dpkg::Control (posiblemente vacío, sin embargo).
$urgency = $entry->get_urgency()
Devuelve la urgencia de la carga asociada.
$maint = $entry->get_maintainer()
Devuelve la cadena que identifica a la persona que firmó esta entrada del changelog.
$time = $entry->get_timestamp()
Devuelve la marca de tiempo de la entrada del changelog.
$time = $entry->get_timepiece()
Devuelve la marca de tiempo de la entrada del changelog como un objeto Time::Piece.

Esta función puede devolver undef si no hubo marca de tiempo.

FUNCIONES DE UTILIDAD

$bool = match_header($line)
Comprueba si la línea coincide con una línea de encabezado de changelog válida.
$bool = match_trailer($line)
Comprueba si la línea coincide con una línea final de changelog válida.
@closed_bugs = find_closes($changes)
Toma una cadena como argumento y encuentra declaraciones "Closes: #123456, #654321" como las admite el software Debian Archive en ella. Devuelve todos los números de errores cerrados en un array.
