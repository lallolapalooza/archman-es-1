Dpkg::Path(3perl) libdpkg-perl Dpkg::Path(3perl)

NOMBRE

Dpkg::Path - algunas funciones comunes de manejo de rutas

DESCRIPCIÓN

Proporciona algunas funciones para manejar varias rutas.

FUNCIONES

get_pkg_root_dir($file)
Esta función escaneará hacia arriba en la jerarquía de directorios para encontrar el directorio que contiene el subdirectorio "DEBIAN" y devolverá su ruta. Este directorio es el directorio raíz de un paquete que se está construyendo.

Si no se encuentra ningún subdirectorio DEBIAN, devolverá undef.

relative_to_pkg_root($file)
Devuelve el nombre del archivo relativo a get_pkg_root_dir($file).
guess_pkg_root_dir($file)
Esta función intenta adivinar el directorio raíz del árbol de compilación del paquete. Primero usará get_pkg_root_dir(), pero recurrirá a una verificación más imprecisa: utilizará el directorio padre que sea un subdirectorio del directorio debian.

Aún puede devolver undef si se proporciona un archivo fuera del subdirectorio debian.

check_files_are_the_same($file1, $file2, $resolve_symlink)
Esta función verifica que ambos archivos son los mismos comprobando que los números de dispositivo y los números de inodo devueltos por stat()/lstat() sean iguales. Si $resolve_symlink es verdadero, se usa stat(), de lo contrario se usa lstat().
canonpath($file)
Esta función devuelve una ruta limpia. Simplifica los // dobles y elimina los /./ y /../ de forma inteligente. Para /../ simplifica la ruta solo si el elemento anterior no es un enlace simbólico. Por lo tanto, solo debe usarse en nombres de archivo reales.
$newpath = resolve_symlink($symlink)
Devuelve el nombre del archivo al que apunta el enlace simbólico. El nuevo nombre es canónico por canonpath().
check_directory_traversal($basedir, $dir)
Esta función verifica que el directorio $dir no contenga ningún enlace simbólico que vaya más allá de $basedir (que debe ser igual o un padre de $dir).
$cmdpath = find_command($command)
Devuelve la ruta del comando si está definido y disponible en una ruta absoluta o relativa o en la $PATH, de lo contrario devuelve undef.
$control_file = get_control_path($pkg, $filetype)
Devuelve la ruta del archivo de control de tipo $filetype para el paquete dado.
@control_files = get_control_path($pkg)
Devuelve la ruta de todos los archivos de control disponibles para el paquete dado.
$file = find_build_file($basename)
Selecciona la variante correcta del archivo dado: la variante específica de la arquitectura ("$basename.$arch") tiene prioridad sobre la variante específica del SO ("$basename.$os") que tiene prioridad sobre la variante predeterminada ("$basename"). Si ninguno de los archivos existe, devuelve undef.
@files = find_build_file($basename)
Devuelve las variantes disponibles del archivo dado. Devuelve una lista vacía si ninguno de los archivos existe.
