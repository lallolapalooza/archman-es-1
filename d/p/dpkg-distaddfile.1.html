NOMBRE

dpkg-distaddfile - añade entradas a debian/files

SINOPSIS

dpkg-distaddfile [opción...] nombre-archivo sección prioridad

DESCRIPCIÓN

dpkg-distaddfile añade una entrada para un archivo con nombre a debian/files.

Toma tres argumentos no opcionales: el nombre del archivo y la sección y prioridad para el archivo .changes.

El nombre del archivo debe especificarse relativo al directorio donde dpkg-genchanges esperará encontrar los archivos, usualmente .., en lugar de ser una ruta relativa al directorio actual cuando se ejecuta dpkg-distaddfile.

OPCIONES

-flista-de-archivos
Lee o escribe la lista de archivos a subir aquí, en lugar de usar debian/files.
-?, --help
Muestra el mensaje de uso y sale.
--version
Muestra la versión y sale.

ENTORNO

DPKG_COLORS
Establece el modo de color (desde dpkg 1.18.5). Los valores actualmente aceptados son: auto (por defecto), always y never.
DPKG_NLS
Si está configurado, se usará para decidir si activar o no el soporte de idioma nativo, también conocido como internacionalización (o i18n) (desde dpkg 1.19.0). Los valores aceptados son: 0 y 1 (por defecto).

ARCHIVOS

debian/files
La lista de archivos generados que forman parte de la subida que se está preparando. dpkg-distaddfile puede ser usado para añadir archivos adicionales.

VER TAMBIÉN
