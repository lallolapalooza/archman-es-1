NOMBRE

Dpkg::BuildTypes - rastrear tipos de compilación

DESCRIPCIÓN

El módulo Dpkg::BuildTypes es utilizado por varias herramientas para rastrear y decidir qué artefactos necesitan ser compilados.

Los tipos de compilación son constantes de bits que se exportan por defecto. Múltiples tipos pueden ser combinados usando el operador OR.

Nota: Este es un módulo privado, su API puede cambiar en cualquier momento.

CONSTANTES

BUILD_DEFAULT
Esta compilación es la predeterminada.
BUILD_SOURCE
Esta compilación incluye artefactos fuente.
BUILD_ARCH_DEP
Esta compilación incluye artefactos binarios dependientes de la arquitectura.
BUILD_ARCH_INDEP
Esta compilación incluye artefactos binarios independientes de la arquitectura.
BUILD_BINARY
Esta compilación incluye artefactos binarios.
BUILD_FULL
Esta compilación incluye artefactos fuente y binarios.

FUNCIONES

build_has_any($bits)
Devuelve un booleano indicando si el tipo de compilación actual tiene alguno de los $bits especificados.
build_has_all($bits)
Devuelve un booleano indicando si el tipo de compilación actual tiene todos los $bits especificados.
build_has_none($bits)
Devuelve un booleano indicando si el tipo de compilación actual no tiene ninguno de los $bits especificados.
build_is($bits)
Devuelve un booleano indicando si el tipo de compilación actual es el conjunto especificado de $bits.
set_build_type($build_type, $build_option, %opts)
Establece el tipo de compilación actual a $build_type, el cual fue especificado a través de la opción de línea de comandos $build_option.

La función comprobará y abortará en asignaciones de tipos de compilación incompatibles, este comportamiento puede ser deshabilitado usando la opción booleana "nocheck".

set_build_type_from_options($build_types, $build_option, %opts)
Establece el tipo de compilación actual a partir de una lista de componentes de tipo de compilación separados por comas.

La función comprobará y abortará en asignaciones de tipos de compilación incompatibles, este comportamiento puede ser deshabilitado usando la opción booleana "nocheck".

set_build_type_from_targets($build_targets, $build_option, %opts)
Establece el tipo de compilación actual a partir de una lista de componentes de objetivo de compilación separados por comas.

La función comprobará y abortará en asignaciones de tipos de compilación incompatibles, este comportamiento puede ser deshabilitado usando la opción booleana "nocheck".

get_build_options_from_type()
Obtiene el tipo de compilación actual como un conjunto de opciones de cadena separadas por comas.
