NOMBRE

Dpkg::Gettext - envoltorio de conveniencia para Locale::gettext

DESCRIPCIÓN

El módulo Dpkg::Gettext es un envoltorio de conveniencia sobre el módulo Locale::gettext, para garantizar que siempre tengamos funciones gettext funcionales y para añadir algunos alias comúnmente utilizados.

ENTORNO

DPKG_NLS
Cuando se establece en 0, esta variable de entorno deshabilitará el Soporte de Idioma Nacional en todos los módulos Dpkg.

VARIABLES

$Dpkg::Gettext::DEFAULT_TEXT_DOMAIN
Especifica el nombre del dominio de texto predeterminado a utilizar con los alias de función cortos. Esto está destinado a ser utilizado por los módulos Dpkg, de modo que puedan producir mensajes localizados incluso cuando el programa que llama ha establecido el dominio actual con textdomain(). Si desea utilizar los alias para sus propios módulos, es posible que desee establecer esta variable a undef, o a otro dominio, pero entonces los módulos Dpkg no producirán mensajes localizados.

FUNCIONES

$domain = textdomain($new_domain)
Fallback de compatibilidad textdomain() cuando Locale::gettext no está disponible.

Si $new_domain no es undef, establecerá el dominio actual a $new_domain. Devuelve el dominio actual, después de posiblemente haberlo cambiado.

$trans = gettext($msgid)
Fallback de compatibilidad gettext() cuando Locale::gettext no está disponible.

Devuelve $msgid.

$trans = ngettext($msgid, $msgid_plural, $n)
Fallback de compatibilidad ngettext() cuando Locale::gettext no está disponible.

Devuelve $msgid si $n es 1 o $msgid_plural de lo contrario.

$trans = g_($msgid)
Llama a dgettext() sobre $msgid y devuelve su traducción para la configuración regional actual. Si dgettext() no está disponible, simplemente devuelve $msgid.
$trans = C_($msgctxt, $msgid)
Llama a dgettext() sobre $msgid y devuelve su traducción para el $msgctxt específico proporcionado. Si dgettext() no está disponible, simplemente devuelve $msgid.
$trans = P_($msgid, $msgid_plural, $n)
Llama a dngettext(), devolviendo la traducción correcta para la forma plural dependiendo de $n. Si dngettext() no está disponible, devuelve $msgid si $n es 1 o $msgid_plural de lo contrario.
$msgid = N_($msgid)
Una pseudo función que sirve como marcador para la extracción automatizada de mensajes, pero no llama a gettext(). La traducción en tiempo de ejecución se realiza en un lugar diferente del código.

Versión 1.01 (dpkg 1.18.0)

Ahora los alias cortos (g_ y P_) llamarán a funciones conscientes del dominio con $DEFAULT_TEXT_DOMAIN.

Nuevas funciones: g_(), C_().

Función obsoleta: _g().
