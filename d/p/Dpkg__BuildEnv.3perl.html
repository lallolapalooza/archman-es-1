NOMBRE

Dpkg::BuildEnv - realizar un seguimiento del entorno de compilación

DESCRIPCIÓN

El módulo Dpkg::BuildEnv es utilizado por dpkg-buildflags para realizar un seguimiento de las variables de entorno de compilación que se están utilizando y modificando.

Nota: Este es un módulo privado, su API puede cambiar en cualquier momento.

FUNCIONES

establecer($nombrevar, $valor)
Actualiza la variable de entorno de compilación $nombrevar con el valor $valor. La registra como accedida y modificada.
obtener($nombrevar)
Obtiene el valor de la variable de entorno de compilación $nombrevar. La registra como accedida.
tiene($nombrevar)
Devuelve un booleano que indica si la variable de entorno existe. La registra como accedida.
@lista = listar_accedidas()
Devuelve una lista de todas las variables de entorno que han sido accedidas.
@lista = listar_modificadas()
Devuelve una lista de todas las variables de entorno que han sido modificadas.
