NOMBRE

Dpkg::Deps::OR - lista de dependencias OR

DESCRIPCIÓN

Esta clase representa una lista de dependencias de las cuales solo una debe cumplirse para que la dependencia sea verdadera. Hereda de Dpkg::Deps::Multiple.

MÉTODOS

$dep->output([$fh])
El método output() utiliza " | " para unir la lista de sub-dependencias.
$dep->implies($other_dep)
Devuelve 1 cuando $dep implica a $other_dep. Devuelve 0 cuando $dep implica NO($other_dep). Devuelve undef cuando no hay implicación. $dep y $other_dep no necesitan ser del mismo tipo.
$dep->get_evaluation($facts)
Evalúa la dependencia dada una lista de paquetes instalados y una lista de paquetes virtuales proporcionados. Estas listas forman parte del objeto Dpkg::Deps::KnownFacts dado como parámetro.

Devuelve 1 cuando es verdadera, 0 cuando es falsa, undef cuando falta información para concluir.

$dep->simplify_deps($facts, @assumed_deps)
Simplifica la dependencia tanto como sea posible dados la lista de hechos (ver objeto Dpkg::Deps::KnownFacts) y una lista de otras dependencias que se sabe que son verdaderas.
