NOMBRE

DPMSInfo - devuelve información sobre el estado actual de DPMS

SINOPSIS

cc [ flag ... ] archivo ... -lXext [ biblioteca ... ]
#include <X11/extensions/dpms.h>
Status DPMSInfo
(
      Display *display,
      CARD16 *power_level,
      BOOL *state
);

ARGUMENTOS

display
Especifica la conexión con el servidor X
power_level
Especifica el nivel de potencia actual
state
Especifica el estado actual de DPMS

DESCRIPCIÓN

La función DPMSInfo devuelve información sobre el estado actual de Señalización de Gestión de Energía de Pantalla (DPMS). El parámetro de retorno state indica si DPMS está habilitado (TRUE) o deshabilitado (FALSE). El parámetro de retorno power_level indica el nivel de potencia actual (uno de DPMSModeOn, DPMSModeStandby, DPMSModeSuspend o DPMSModeOff.)

VALORES DE RETORNO

TRUE
La función DPMSInfo devuelve TRUE, si se devuelven valores.
FALSE
La función DPMSInfo devuelve FALSE, si no se devuelven valores.
