Dpkg::Control::FieldsCore(3perl) libdpkg-perl Dpkg::Control::FieldsCore(3perl)

NOMBRE

Dpkg::Control::FieldsCore - gestiona (lista de campos de control oficiales)

DESCRIPCIÓN

Los módulos contienen una lista de nombres de campos con metadatos asociados que explican en qué tipo de información de control están permitidos. Los tipos son las constantes CTRL_* exportadas por Dpkg::Control.

FUNCIONES

$f = field_capitalize($field_name)
Devuelve el nombre del campo debidamente capitalizado. Todos los caracteres están en minúsculas, excepto el primero de cada palabra (las palabras están separadas por un guion en los nombres de los campos).
$bool = field_is_official($fname)
Devuelve verdadero si el campo es oficial y conocido.
$bool = field_is_allowed_in($fname, @types)
Devuelve verdadero (1) si el campo $fname está permitido en todos los tipos listados en la lista. Tenga en cuenta que puede utilizar conjuntos de tipos en lugar de tipos individuales (ej: CTRL_FILE_CHANGES | CTRL_CHANGELOG).

field_allowed_in(A|B, C) devuelve verdadero solo si el campo está permitido en C y en A o B.

Se devuelve undef para campos no oficiales.

$new_field = field_transfer_single($from, $to, $field)
Si es apropiado, copia el valor del campo llamado $field tomado del objeto Dpkg::Control $from al objeto Dpkg::Control $to.

Los campos oficiales se copian solo si el campo está permitido en ambos tipos de objetos. Los campos personalizados se tratan de manera específica. Cuando el destino no está entre CTRL_DSC, CTRL_DEB o CTRL_FILE_CHANGES, entonces siempre se copian tal cual (se conserva el prefijo X-). De lo contrario, no se copian excepto si el objeto de destino coincide con el destino codificado en el nombre del campo. La X inicial que denota campos personalizados puede ir seguida de una o más letras entre "S" (Source: corresponde a CTRL_DSC), "B" (Binary: corresponde a CTRL_DEB) o "C" (Changes: corresponde a CTRL_FILE_CHANGES).

Devuelve undef si no se copió nada o el nombre del nuevo campo añadido a $to en caso contrario.

@field_list = field_transfer_all($from, $to)
Transfiere todos los campos apropiados de $from a $to. Llama a field_transfer_single() en todos los campos disponibles en $from.

Devuelve la lista de campos que se han añadido a $to.

@field_list = field_ordered_list($type)
Devuelve una lista ordenada de campos para un tipo dado de información de control. Esta lista puede usarse para mostrar los campos en un orden predecible. La lista puede estar vacía para tipos donde el orden no es muy importante.
($source, $version) = field_parse_binary_source($ctrl)
Analiza el campo Source en una estrofa de control de paquete binario. El campo contiene el nombre del paquete fuente del que se compiló, y opcionalmente un espacio y la versión fuente entre paréntesis si es diferente de la versión binaria.

Devuelve una lista con el nombre $source y la $version fuente, o undef o una lista vacía cuando $ctrl no contiene una estrofa de control de paquete binario. Ni $source ni $version se validan, pero eso se puede hacer con Dpkg::Package::pkg_name_is_illegal() y Dpkg::Version::version_check().

@field_list = field_list_src_dep()
Lista de campos que contienen información similar a dependencias en un paquete fuente de Debian.
@field_list = field_list_pkg_dep()
Lista de campos que contienen información similar a dependencias en un paquete binario de Debian. Los campos que expresan dependencias reales están ordenados de más fuerte a más débil.
$dep_type = field_get_dep_type($field)
Devuelve el tipo de dependencia expresada por el campo dado. Puede ser "normal" para un campo de dependencia real (Pre-Depends, Depends, ...) o "union" para otros campos de relación que comparten la misma sintaxis (Conflicts, Breaks, ...). Devuelve undef para campos que no son dependencias.
$sep_type = field_get_sep_type($field)
Devuelve el tipo de separador de valor del campo. Puede ser uno de FIELD_SEP_UNKNOWN, FIELD_SEP_SPACE, FIELD_SEP_COMMA o FIELD_SEP_LINE.
$value = field_get_default_value($field)
Devuelve el valor predeterminado (si lo hay) para el campo. Si no hay valor predeterminado, devuelve "undef".
field_register($field, $allowed_types, %opts)
Registra un nuevo campo como permitido en información de control de los tipos especificados. %opts es opcional.
$bool = field_insert_after($type, $ref, @fields)
Coloca el campo después de otro ($ref) en la salida de información de control del tipo $type.

Devuelve verdadero si el campo se insertó, de lo contrario, falso.

$bool = field_insert_before($type, $ref, @fields)
Coloca el campo antes de otro ($ref) en la salida de información de control del tipo $type.

Devuelve verdadero si el campo se insertó, de lo contrario, falso.
