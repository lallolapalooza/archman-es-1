subroutine dppequ (character uplo, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) s, double precision scond, double precision amax, integer info)

DPPEQU

Propósito:

!>
!> DPPEQU calcula escalados de fila y columna destinados a equilibrar una
!> matriz simétrica definida positiva A en almacenamiento empaquetado y reducir
!> su número de condición (con respecto a la norma dos). S contiene los
!> factores de escala, S(i)=1/sqrt(A(i,i)), elegidos de modo que la matriz escalada
!> B con elementos B(i,j)=S(i)*A(i,j)*S(j) tenga unos en la diagonal.
!> Esta elección de S pone el número de condición de B dentro de un factor N del
!> número de condición más pequeño posible sobre todos los escalados diagonales
!> posibles.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array DOUBLE PRECISION, de dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz simétrica A, empaquetado
!>          por columnas en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es DOUBLE PRECISION
!>          Si INFO = 0, S contiene la relación del S(i) más pequeño con
!>          el S(i) más grande. Si SCOND >= 0.1 y AMAX no es demasiado
!>          grande ni demasiado pequeño, no vale la pena escalar con S.
!>

AMAX

!>          AMAX es DOUBLE PRECISION
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está muy
!>          cerca de un desbordamiento o muy cerca de un subdesbordamiento, la matriz
!>          debería escalarse.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal no es positivo.
!>
