NOMBRE

dpkg-checkbuilddeps - comprobar dependencias y conflictos de compilación

SINOPSIS

dpkg-checkbuilddeps [opción...] [archivo-de-control]

DESCRIPCIÓN

Este programa comprueba los paquetes instalados en el sistema contra las dependencias de compilación y conflictos de compilación listados en el archivo de control. Si alguno no se cumple, los muestra y sale con un código de retorno distinto de cero.

Por defecto, se lee debian/control, pero se puede especificar un nombre de archivo de control alternativo en la línea de comandos.

OPCIONES

--admindir=dir
Cambia la ubicación de la base de datos de dpkg (desde dpkg 1.14.0). La ubicación por defecto es /var/lib/dpkg.
-A
Ignora las líneas Build-Depends-Arch y Build-Conflicts-Arch (desde dpkg 1.16.4). Usar cuando solo se compilarán paquetes independientes de la arquitectura, o combinar con -B cuando solo se vaya a compilar un paquete fuente.
-B
Ignora las líneas Build-Depends-Indep y Build-Conflicts-Indep. Usar cuando solo se compilarán paquetes dependientes de la arquitectura, o combinar con -A cuando solo se vaya a compilar un paquete fuente.
-I
Ignora las dependencias y conflictos de compilación integrados (desde dpkg 1.18.2). Estas son dependencias implícitas que suelen ser necesarias en una distribución específica, el llamado conjunto de paquetes Build-Essential.
-d cadena-de-dependencias-de-compilacion
-c cadena-de-conflictos-de-compilacion
Usa las dependencias/conflictos de compilación dados en lugar de los contenidos en el archivo debian/control (desde dpkg 1.14.17).
-a arquitectura
Comprueba las dependencias/conflictos de compilación asumiendo que el paquete descrito en el archivo de control se compilará para la arquitectura host dada en lugar de la arquitectura del sistema actual (desde dpkg 1.16.2).
-P perfil[,...]
Comprueba las dependencias/conflictos de compilación asumiendo que el paquete descrito en el archivo de control se compilará para el(los) perfil(es) de compilación dados (desde dpkg 1.17.2). El argumento es una lista de nombres de perfil separados por comas.
-?, --help
Muestra el mensaje de uso y sale.
--version
Muestra la versión y sale.

AMBIENTE

DEB_HOST_ARCH
Establece la arquitectura host. Esto afecta a la lógica de resolución de dependencias, que podría no coincidir con lo que dpkg del sistema considera satisfactorio.
DEB_BUILD_PROFILES
Si está configurado, se usará como el(los) perfil(es) de compilación activos para el paquete que se está compilando. Es una lista de nombres de perfil separados por espacios. Anulado por la opción -P.
DPKG_COLORS
Establece el modo de color (desde dpkg 1.18.5). Los valores aceptados actualmente son: auto (por defecto), always y never.
DPKG_NLS
Si está configurado, se usará para decidir si activar o no el soporte de idioma nativo, también conocido como internacionalización (o i18n) (desde dpkg 1.19.0). Los valores aceptados son: 0 y 1 (por defecto).
