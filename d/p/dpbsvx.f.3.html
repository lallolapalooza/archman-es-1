Documentación de Función/Subrutin

a

subrutina dpbsvx (character fact, character uplo, integer n, integer kd, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldafb, * ) afb, integer ldafb, character equed, double precision, dimension( * ) s, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer

info)

DPBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices

OTHER

Propósito

: 
!>
!> DPBSVX usa la factorización de Cholesky A = U**T*U o A = L*L**T para
!> calcular la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz de banda simétrica definida positiva de N por N y X
!> y B son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de
!> la condición.
!
>

Descripción

: 
!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibra o no depende del
!>    escalado de la matriz A, pero si se usa el equilibrado, A se
!>    sobrescribe por diag(S)*A*diag(S) y B por diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se usa la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**T * U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz de banda triangular superior y L es una
!>    matriz de banda triangular inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina retorna con INFO = i. De lo contrario, la forma
!>    factorizada de A se usa para estimar el número de condición de la matriz
!>    A.  Si el recíproco del número de condición es menor que la precisión
!>    de la máquina, se retorna INFO = N+1 como una advertencia, pero la rutina
!>    continúa para resolver X y calcular límites de error como
!>    se describe a continuación.
!>
!> 4. Se resuelve el sistema de ecuaciones para X usando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular límites de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes
!>    del equilibrado.
!
>

Parámetro

s
FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona a la entrada, y si no, si la matriz A debe
!>          equilibrarse antes de ser factorizada.
!>          = 'F':  A la entrada, AFB contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S.  AB y AFB no serán
!>                  modificados.
!>          = 'N':  La matriz A será copiada a AFB y factorizada.
!>          = 'E':  La matriz A será equilibrada si es necesario, luego
!>                  copiada a AFB y factorizada.
!
>

UPL

O 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!
>

N 
!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!
>

K

D 
!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!
>

A

B 
!>          AB es un array DOUBLE PRECISION, dimensión (LDAB,N)
!>          A la entrada, el triángulo superior o inferior de la matriz de banda
!>          simétrica A, almacenado en las primeras KD+1 filas del array, excepto
!>          si FACT = 'F' y EQUED = 'Y', entonces A debe contener la
!>          matriz equilibrada diag(S)*A*diag(S).  La j-ésima columna de A
!>          se almacena en la j-ésima columna del array AB como sigue:
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) para max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(N,j+KD).
!>          Vea a continuación para más detalles.
!>
!>          A la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe por
!>          diag(S)*A*diag(S).
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del array A.  LDAB >= KD+1.
!
>

AF

B 
!>          AFB es un array DOUBLE PRECISION, dimensión (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y a la entrada
!>          contiene el factor triangular U o L de la factorización
!>          de Cholesky A = U**T*U o A = L*L**T de la matriz de banda
!>          A, en el mismo formato de almacenamiento que A (vea AB).  Si EQUED = 'Y',
!>          entonces AFB es la forma factorizada de la matriz equilibrada A.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y a la salida
!>          retorna el factor triangular U o L de la factorización
!>          de Cholesky A = U**T*U o A = L*L**T.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y a la salida
!>          retorna el factor triangular U o L de la factorización
!>          de Cholesky A = U**T*U o A = L*L**T de la matriz
!>          equilibrada A (vea la descripción de A para la forma de la
!>          matriz equilibrada).
!
>

LDAF

B 
!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= KD+1.
!
>

EQUE

D 
!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre cierto si FACT = 'N').
!>          = 'Y':  Se realizó el equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!
>

S 
!>          S es un array DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'.  S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un argumento
!>          de salida.  Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          A la entrada, la matriz de lados derechos B de N por NRHS.
!>          A la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe por diag(S) * B.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!> </pre>

X

!>          X es un arreglo de tipo DOUBLE PRECISION, con dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, es la matriz de solución X de tamaño N por NRHS para
!>          el sistema original de ecuaciones.  Nótese que si EQUED = 'Y',
!>          A y B se modifican al salir, y la solución al
!>          sistema equilibrado es inv(diag(S))*X.
!
>

LD
X

!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  LDX >= max(1,N).
!
>

RCON
D

!>          RCOND es DOUBLE PRECISION
!>          La estimación del número de condición recíproco de la matriz
!>          A después del equilibrio (si se realizó).  Si RCOND es menor que la
!>          precisión de máquina (en particular, si RCOND = 0), la matriz
!>          es singular a la precisión de trabajo.  Esta condición se
!>          indica mediante un código de retorno de INFO > 0.
!
>

FER
R

!>          FERR es un arreglo de tipo DOUBLE PRECISION, con dimensión (NRHS)
!>          La estimación del límite de error hacia adelante para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución real correspondiente a X(j), FERR(j)
!>          es una estimación del límite superior para la magnitud del elemento
!>          más grande en (X(j) - XTRUE) dividida por la magnitud del
!>          elemento más grande en X(j).  La estimación es tan fiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error real.
!
>

BER
R

!>          BERR es un arreglo de tipo DOUBLE PRECISION, con dimensión (NRHS)
!>          El error relativo hacia atrás componente a componente de cada vector
!>          de solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!
>

WOR
K

!>          WORK es un arreglo de tipo DOUBLE PRECISION, con dimensión (3*N)
!
>

IWOR
K

!>          IWORK es un arreglo de tipo INTEGER, con dimensión (N)
!
>

INF
O

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse, y la solución no ha sido
!>                       calculada. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión de
!>                       máquina, lo que significa que la matriz es singular
!>                       a la precisión de trabajo.  Sin embargo, la
!>                       solución y los límites de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.

!
>

!>  El esquema de almacenamiento en banda se ilustra con el siguiente ejemplo, cuando
!>  N = 6, KD = 2, y UPLO = 'U':

!>  Almacenamiento bidimensional de la matriz simétrica A:
!>
!>     a11  a12  a13
!>          a22  a23  a24
!>               a33  a34  a35
!>                    a44  a45  a46
!>                         a55  a56
!>     (aij=conjg(aji))         a66
!>
!>  Almacenamiento en banda del triángulo superior de A:
!>
!>      *    *   a13  a24  a35  a46
!>      *   a12  a23  a34  a45  a56
!>     a11  a22  a33  a44  a55  a66
!>
!>  De manera similar, si UPLO = 'L' el formato de A es el siguiente:
!>
!>     a11  a22  a33  a44  a55  a66
!>     a21  a32  a43  a54  a65   *
!>     a31  a42  a53  a64   *    *
!>
!>  Los elementos del arreglo marcados con * no son utilizados por la rutina.
