subrutina dptsvx (character fact, integer n, integer nrhs, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) df, double precision, dimension( * ) ef, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer info)

DPTSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PT

Propósito:

!>
!> DPTSVX usa la factorización A = L*D*L**T para calcular la solución
!> a un sistema real de ecuaciones lineales A*X = B, donde A es una
!> matriz tridiagonal simétrica definida positiva de N por N
!> y X y B son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una
!> estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', la matriz A se factoriza como A = L*D*L**T, donde L
!>    es una matriz bidiagonal inferior unitaria y D es diagonal. La
!>    factorización también puede considerarse con la forma
!>    A = U**T*D*U.
!>
!> 2. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina regresa con INFO = i. De lo contrario, la
!>    forma factorizada de A se usa para estimar el número de condición
!>    de la matriz A. Si el recíproco del número de condición es menor
!>    que la precisión de la máquina, se devuelve INFO = N+1 como una
!>    advertencia, pero la rutina continúa resolviendo para X y
!>    calculando los límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X usando la forma
!>    factorizada de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz de
!>    solución calculada y calcular límites de error y estimaciones de
!>    error hacia atrás para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          proporcionada en la entrada.
!>          = 'F':  En la entrada, DF y EF contienen la forma factorizada de A.
!>                  D, E, DF y EF no serán modificados.
!>          = 'N':  La matriz A será copiada a DF y EF y
!>                  factorizada.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

D

!>          D es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un arreglo DOUBLE PRECISION, dimensión (N-1)
!>          Los (n-1) elementos subdiagonales de la matriz tridiagonal A.
!>

DF

!>          DF es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Si FACT = 'F', entonces DF es un argumento de entrada y en la entrada
!>          contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**T de A.
!>          Si FACT = 'N', entonces DF es un argumento de salida y en la salida
!>          contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**T de A.
!>

EF

!>          EF es un arreglo DOUBLE PRECISION, dimensión (N-1)
!>          Si FACT = 'F', entonces EF es un argumento de entrada y en la entrada
!>          contiene los (n-1) elementos subdiagonales del factor
!>          bidiagonal unitario L de la factorización L*D*L**T de A.
!>          Si FACT = 'N', entonces EF es un argumento de salida y en la salida
!>          contiene los (n-1) elementos subdiagonales del factor
!>          bidiagonal unitario L de la factorización L*D*L**T de A.
!>

B

!>          B es un arreglo DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          La matriz de miembros derechos B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1,N).
!>

X

!>          X es un arreglo DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz de solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del arreglo X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El recíproco del número de condición de la matriz A. Si RCOND
!>          es menor que la precisión de la máquina (en particular, si
!>          RCOND = 0), la matriz es singular a la precisión de trabajo.
!>          Esta condición se indica con un código de retorno de INFO > 0.
!>

FERR

!>          FERR es un arreglo DOUBLE PRECISION, dimensión (NRHS)
!>          El límite de error hacia adelante para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento
!>          más grande en (X(j) - XTRUE) dividido por la magnitud del
!>          elemento más grande en X(j).
!>

BERR

!>          BERR es un arreglo DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector de solución X(j) (es decir, el cambio relativo más
!>          pequeño en cualquier elemento de A o B que hace que X(j) sea
!>          una solución exacta).
!>

WORK

!>          WORK es un arreglo DOUBLE PRECISION, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse, y la solución no ha sido
!>                       calculada. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       a la precisión de trabajo. Sin embargo, la
!>                       solución y los límites de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.
!>
