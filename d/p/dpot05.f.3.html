DOCUMENTACIÓN DE LA Función/Subrutina

subroutine dpot05 (character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

DPOT05

Propósito:

!>
!> DPOT05 comprueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz simétrica de n por n.
!>
!> RESLTS(1) = comprobación del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( (n+1)*EPS + (*) ), donde
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si se almacena la parte triangular superior o inferior
!>          de la matriz simétrica A.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el orden
!>          de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimension (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>          de n por n de A contiene la parte triangular superior de la matriz A,
!>          y la parte estrictamente triangular inferior de A no se referencia.
!>          Si UPLO = 'L', la parte triangular inferior de n por n de A contiene
!>          la parte triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array DOUBLE PRECISION, dimension (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es un array DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Los vectores de solución exactos. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimension (NRHS)
!>          Los límites de error hacia adelante estimados para cada vector de
!>          solución X. Si XTRUE es la solución verdadera, FERR acota la
!>          magnitud de la entrada más grande en (X - XTRUE) dividida por la
!>          magnitud de la entrada más grande en X.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimension (NRHS)
!>          El error de retroceso relativo componente a componente de cada
!>          vector de solución (es decir, el cambio relativo más pequeño en
!>          cualquier entrada de A o B que haga que X sea una solución exacta).
!>

RESLTS

!>          RESLTS es un array DOUBLE PRECISION, dimension (2)
!>          El máximo sobre los vectores de solución NRHS de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
