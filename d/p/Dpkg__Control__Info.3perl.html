NOMBRE

Dpkg::Control::Info - analizar archivos como debian/control

DESCRIPCIÓN

Proporciona una clase para acceder a los datos de archivos que siguen la misma sintaxis que debian/control.

MÉTODOS

$c = Dpkg::Control::Info->new(%opts)
Crea un nuevo objeto Dpkg::Control::Info. Carga debian/control por defecto. Si se pasa un único escalar, se usará como nombre de archivo a cargar en lugar del predeterminado. Si el nombre de archivo es "-", analiza la entrada estándar. Si el nombre de archivo es undef, no se realizará ninguna carga.

Opciones:

filename
Carga el archivo desde el nombre de archivo, en lugar de debian/control.
$c->reset()
Reinicia lo que se leyó.
$c->parse($fh, $description)
Analiza un archivo de control desde el manejador de archivo dado. Sale en caso de errores. $description se usa para describir el manejador de archivo, idealmente es un nombre de archivo o una descripción de dónde provienen los datos. Se usa en mensajes de error. Los datos del objeto se reinician antes de analizar nuevos archivos de control.
$c->load($file)
Carga el contenido de $file. Sale en caso de errores. Si el archivo es "-", carga desde la entrada estándar.
$c->[0]
$c->get_source()
Devuelve un objeto Dpkg::Control que contiene los campos relacionados con el paquete fuente.
$c->get_pkg_by_idx($idx)
Devuelve un objeto Dpkg::Control que contiene los campos relacionados con el paquete binario número $idx (comenzando en 1).
$c->get_pkg_by_name($name)
Devuelve un objeto Dpkg::Control que contiene los campos relacionados con el paquete binario llamado $name.
$c->get_packages()
Devuelve una lista que contiene los objetos Dpkg::Control para todos los paquetes binarios.
$str = $c->output([$fh])
Devuelve el contenido de la información en una cadena. Si se especifica $fh, lo imprime en el manejador de archivo.
"$c"
Devuelve una representación en cadena del contenido.
@{$c}
Devuelve una lista de objetos Dpkg::Control, el primero corresponde a la información de la fuente y los siguientes son la información de los paquetes binarios.
