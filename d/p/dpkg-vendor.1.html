NOMBRE

dpkg-vendor - consulta información sobre proveedores de distribución

SINOPSIS

dpkg-vendor [opción...] comando

DESCRIPCIÓN

dpkg-vendor es una herramienta para consultar información sobre los proveedores listados en /etc/dpkg/origins. /etc/dpkg/origins/default contiene información sobre el proveedor actual.

Los archivos de origen proporcionan metadatos sobre proveedores específicos, como su URL o dónde enviar informes de errores, y se utilizan normalmente tanto para determinar el comportamiento de las herramientas y los contenidos resultantes durante la compilación de paquetes dirigidos a un proveedor específico, como para describir la procedencia de los paquetes.

Los paquetes pueden declarar explícitamente su proveedor incluyendo un campo Origin; de lo contrario, se asume que el proveedor de un paquete sin dicho campo es el indicado por el enlace simbólico *default* de origen.

El enlace simbólico *default* también se utiliza para indicar el origen de la instalación actual gestionada por dpkg, ya sea una distribución completa o una superposición sobre un sistema base existente que contenga un sistema de empaquetado nativo o ninguno.

Este programa se introdujo en dpkg 1.15.1.

COMANDOS

--is proveedor
Sale con 0 si el proveedor actual es proveedor. De lo contrario, sale con 1.
--derives-from proveedor
Sale con 0 si la distribución del proveedor actual es un derivado de proveedor, de lo contrario sale con 1. Utiliza el campo Parent para explorar todos los ancestros del proveedor actual.
--query campo
Imprime en la salida estándar el valor del campo específico del proveedor para el proveedor actual.
--help
Muestra el mensaje de uso y sale.
--version
Muestra la versión y sale.

OPCIONES

--vendor proveedor
Asume que el proveedor actual es proveedor en lugar de descubrirlo con la variable de entorno DEB_VENDOR o /etc/dpkg/origins/default.

AMBIENTE

DEB_VENDOR
Esta configuración define el proveedor actual. Si no está establecida, descubrirá el proveedor actual leyendo /etc/dpkg/origins/default.
DPKG_COLORS
Establece el modo de color (desde dpkg 1.18.5). Los valores aceptados actualmente son: auto (por defecto), always (siempre) y never (nunca).
DPKG_NLS
Si está establecida, se utilizará para decidir si se activa la Soporte de Idioma Nativo, también conocido como internacionalización (o i18n) (desde dpkg 1.19.0). Los valores aceptados son: 0 y 1 (por defecto).

ARCHIVOS

Soporte de empaquetado

/usr/share/dpkg/vendor.mk
Fragmento de Makefile que establece el proveedor actual y su padre en variables, y proporciona macros de make para verificar si hay derivados (desde dpkg 1.16.1).
