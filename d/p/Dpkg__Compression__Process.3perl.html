NOMBRE

Dpkg::Compression::Process - ejecutar procesos de compresión/descompresión

DESCRIPCIÓN

Este módulo proporciona una interfaz orientada a objetos para ejecutar y gestionar procesos de compresión/descompresión.

MÉTODOS

$proc = Dpkg::Compression::Process->new(%opts)
Crear una nueva instancia del objeto.

Opciones:

compresión
Ver $proc->set_compression().
nivel_de_compresión
Ver $proc->set_compression_level().
$proc->set_compression($comp)
Selecciona el método de compresión a usar. Genera un error si el método no es soportado según compression_is_supported() (de Dpkg::Compression).
$proc->set_compression_level($level)
Selecciona el nivel de compresión a usar. Genera un error si el nivel no es válido según compression_is_valid_level() (de Dpkg::Compression).
@exec = $proc->get_compress_cmdline()
@exec = $proc->get_uncompress_cmdline()
Devuelve una lista lista para ser pasada a exec(), su primer elemento es el nombre del programa (ya sea para compresión o descompresión) y los elementos siguientes son parámetros para el programa.

Cuando el programa se ejecuta, actúa como un filtro entre su entrada estándar y su salida estándar.

$proc->compress(%opts)
Inicia un programa compresor. Debes indicar desde dónde leerá sus datos sin comprimir y dónde escribirá sus datos comprimidos. Esto se logra pasando un parámetro "to_*" y un parámetro "from_*" como los aceptados por Dpkg::IPC::spawn().

Debes llamar a wait_end_process() después de llamar a este método para cerrar correctamente el subproceso (y verificar que terminó sin errores).

Opciones:

Ver Dpkg::IPC::spawn().

$proc->uncompress(%opts)
Inicia un programa descompresor. Debes indicar desde dónde leerá sus datos comprimidos y dónde escribirá sus datos sin comprimir. Esto se logra pasando un parámetro "to_*" y un parámetro "from_*" como los aceptados por Dpkg::IPC::spawn().

Debes llamar a wait_end_process() después de llamar a este método para cerrar correctamente el subproceso (y verificar que terminó sin errores).

Opciones:

Ver Dpkg::IPC::spawn().

$proc->wait_end_process(%opts)
Llama a Dpkg::IPC::wait_child() para esperar hasta que el subproceso haya terminado y verificar su código de retorno. Cualquier opción dada será reenviada a la función wait_child(). Notablemente, puedes usar la opción "nocheck" para verificar el código de retorno tú mismo en lugar de dejar que wait_child() lo haga por ti.

Opciones:

Ver Dpkg::IPC::wait_child().
