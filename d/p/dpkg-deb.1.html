-z , --compression-level=nivel-compres
ión
Especificar qué nivel de compresión usar en el backend del compresor, al construir un paquete (el valor por defecto es 9 para gzip, 6 para xz, 3 para zstd; opción larga desde dpkg 1.22.9). Los valores aceptados son específicos del compresor. Para gzip, de 0-9 con 0 siendo mapeado al compresor none. Para xz de 0-9. Para zstd de 0-22, con niveles de 20 a 22 habilitando su modo ultra. Antes de dpkg 1.16.2 el nivel 0 era equivalente al compresor none para todos los
compresores.
-S , --compression-strategy=estrategia-compres
ión
Especificar qué estrategia de compresión usar en el backend del compresor, al construir un paquete (desde dpkg 1.16.2, opción larga desde dpkg 1.22.9). El valor permitidoson none (desde dpkg 1.16.4), filtered, huffman, rle y fixed para gzip (desde dpkg 1.17.0) y extreme para xz.
-Z, --compression=tipo-de-compresión
Especifica qué tipo de compresión usar al construir un paquete (opción larga desde dpkg 1.22.9). Los valores permitidos son gzip, xz (desde dpkg 1.15.6), zstd (desde dpkg 1.21.18) y none (el valor predeterminado es xz).
--[no-]uniform-compression
Especifica que se deben usar los mismos parámetros de compresión para todos los miembros del archivo (es decir, control.tar y data.tar; desde dpkg 1.17.6). De lo contrario, solo el miembro data.tar usará esos parámetros. Los únicos tipos de compresión admitidos que se pueden usar de forma uniforme son none, gzip, xz y zstd. La opción --no-uniform-compression desactiva la compresión uniforme (desde dpkg 1.19.0). La compresión uniforme es la predeterminada (desde dpkg 1.19.0).
--threads-max=hilos
Establece el número máximo de hilos permitidos para los compresores que admiten operaciones multihilo (desde dpkg 1.21.9).
--root-owner-group
Establece el propietario y el grupo de cada entrada en los datos del árbol del sistema de archivos como root con id 0 (desde dpkg 1.19.0).

Nota: Esta opción puede ser útil para compilaciones sin root (ver rootless-builds.txt), pero no debe usarse cuando las entradas tienen un propietario o grupo que no es root. El soporte para estos se añadirá más adelante en forma de un manifiesto meta.

--deb-format=formato
Establece la versión del formato de archivo usada al construir (desde dpkg 1.17.0). Los valores permitidos son 2.0 para el nuevo formato y 0.939000 para el antiguo (el valor predeterminado es 2.0).

El antiguo formato de archivo es menos fácil de analizar por herramientas no Debian y ahora está obsoleto; su único uso es al construir paquetes para ser analizados por versiones de dpkg anteriores a la 0.93.76 (septiembre de 1995), que se publicó solo para i386 a.out.

--no-check
Inhibe las comprobaciones habituales de dpkg-deb --buildsobre el contenido propuesto de un archivo. De esta manera, puede construir cualquier archivo que desee, sin importar cuán defectuoso sea.

Opción admitida desde dpkg 1.22.12.

--nocheck
Este es un alias para --no-check.
-v, --verbose
Habilita la salida detallada (desde dpkg 1.16.1). Actualmente esto solo afecta a --extract haciéndolo comportarse como --vextract.
-D, --debug
Habilita la salida de depuración. Esto no es muy interesante.

ESTADO DE SALIDA

0
La acción solicitada se realizó con éxito.
2
Error fatal o irrecuperable debido a un uso incorrecto de la línea de comandos, o interacciones con el sistema, como accesos a la base de datos, asignaciones de memoria, etc.

ENTORNO

DPKG_DEB_THREADS_MAX
Establece el número máximo de hilos permitidos para los compresores que admiten operaciones multihilo (desde dpkg 1.21.9).

La opción --threads-max tiene prioridad sobre este valor.

DPKG_DEB_COMPRESSOR_TYPE
Establece el tipo de compresor a usar (desde dpkg 1.21.10).

La opción -Z tiene prioridad sobre este valor.

DPKG_DEB_COMPRESSOR_LEVEL
Establece el nivel de compresión a usar (desde dpkg 1.21.10).

La opción -z tiene prioridad sobre este valor.

DPKG_COLORS
Establece el modo de color (desde dpkg 1.18.5). Los valores aceptados actualmente son: auto (predeterminado), always y never.
DPKG_NLS
Si está definido, se usará para decidir si activar el soporte de idioma nativo, también conocido como soporte de internacionalización (o i18n) (desde dpkg 1.22.7). Los valores aceptados son: 0 y 1 (predeterminado).
DPKG_PATH_PASSWD
Establece la ruta del archivo passwd del sistema. Esta ruta es relativa al directorio --root . El valor predeterminado es /etc/passwd.

Desde dpkg 1.22.16.

DPKG_PATH_GROUP
Establece la ruta del archivo group del sistema. Esta ruta es relativa al directorio --root . El valor predeterminado es /etc/group.

Desde dpkg 1.22.16.

TMPDIR
Si está definido, dpkg-deb lo usará como el directorio en el que crear archivos y directorios temporales.
SOURCE_DATE_EPOCH
Si está definido, se usará como la marca de tiempo (como segundos desde la época) en el contenedor ar(5)de deb(5) y se usará para limitar la hora de modificación (mtime) en las entradas del archivo tar(5) .

Desde dpkg 1.18.8.

NOTAS

¡No intente usar solo dpkg-deb para instalar software! Debe usar dpkg propiamente para asegurarse de que todos los archivos estén colocados correctamente, de que se ejecuten los scripts del paquete y de que su estado y contenido se registren.

SEGURIDAD

Examinar archivos de paquetes no confiables o extraerlos en directorios de ensamblaje debe considerarse un límite de seguridad, y cualquier violación de ese límite que resulte de estas operaciones debe considerarse una vulnerabilidad de seguridad. Pero el manejo de archivos de paquetes no confiables no debe hacerse a la ligera, ya que el área de superficie incluye cualquier biblioteca de compresión admitida, además de los propios formatos de archivo y archivos de control. Se desaconseja encarecidamente realizar estas operaciones sobre datos no confiables como root.

La construcción de archivos de paquetes solo debe realizarse sobre datos de confianza.

ERRORES

dpkg-deb -I paquete1.deb paquete2.deb hace lo incorrecto.

No hay autenticación en los archivos .deb ; de hecho, ni siquiera hay una suma de comprobación directa. (Herramientas de nivel superior como APT admiten la autenticación de los paquetes .deb obtenidos de un repositorio dado, y la mayoría de los paquetes hoy en día proporcionan un archivo de control md5sum generado por debian/rules. Aunque esto no es admitido directamente por las herramientas de nivel inferior.)
