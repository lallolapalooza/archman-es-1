Dpkg::Control(3perl) libdpkg-perl Dpkg::Control(3perl)

NOMBRE

Dpkg::Control - analiza y manipula información oficial similar a control

DESCRIPCIÓN

El objeto Dpkg::Control es una versión inteligente de Dpkg::Control::Hash. Asocia un tipo a la información de control. Ese tipo se puede utilizar para saber qué campos están permitidos y en qué orden deben ser emitidos.

Los tipos son constantes que se exportan por defecto. Aquí está la lista completa:

CTRL_UNKNOWN
Este tipo es el tipo por defecto, indica que el tipo de información de control aún no se conoce.
CTRL_TMPL_SRC
Corresponde a la primera estanza del paquete fuente en un debian/control archivo en un paquete fuente de Debian.
CTRL_TMPL_PKG
Corresponde a las estanzas posteriores del paquete binario en un debian/control archivo en un paquete fuente de Debian.
CTRL_REPO_RELEASE
Corresponde a un Release archivo en un repositorio.
CTRL_REPO_SRC
Corresponde a una estanza en un Sources archivo de un repositorio de paquetes fuente.
CTRL_REPO_PKG
Corresponde a una estanza en un Packages archivo de un repositorio de paquetes binarios.
CTRL_DSC
Corresponde a un archivo .dsc de un paquete fuente de Debian.
CTRL_DEB
Corresponde al control archivo generado por dpkg-gencontrol (DEBIAN/control) y al mismo archivo dentro de los paquetes .deb.
CTRL_FILE_BUILDINFO
Corresponde a un archivo .buildinfo.
CTRL_FILE_CHANGES
Corresponde a un archivo .changes.
CTRL_FILE_VENDOR
Corresponde a un archivo de proveedor en $Dpkg::CONFDIR/origins/.
CTRL_FILE_STATUS
Corresponde a una estanza en el archivo status de dpkg ($Dpkg::ADMINDIR/status).
CTRL_CHANGELOG
Corresponde a la salida de dpkg-parsechangelog.
CTRL_COPYRIGHT_HEADER
Corresponde a la estanza de encabezado en un debian/copyright archivo en formato legible por máquina.
CTRL_COPYRIGHT_FILES
Corresponde a una estanza de archivos en un debian/copyright archivo en formato legible por máquina.
CTRL_COPYRIGHT_LICENSE
Corresponde a una estanza de licencia en un debian/copyright archivo en formato legible por máquina.
CTRL_TESTS
Corresponde a un archivo de control de pruebas de paquete fuente en debian/tests/control.
CTRL_INFO_SRC
Alias obsoleto para CTRL_TMPL_SRC.
CTRL_INFO_PKG
Alias obsoleto para CTRL_TMPL_PKG.
CTRL_PKG_SRC
Alias obsoleto para CTRL_DSC.
CTRL_PKG_DEB
Alias obsoleto para CTRL_DEB.
CTRL_INDEX_SRC
Alias obsoleto para CTRL_REPO_SRC.
CTRL_INDEX_PKG
Alias obsoleto para CTRL_REPO_PKG.

MÉTODOS

Todos los métodos de Dpkg::Control::Hash están disponibles. Los que se enumeran a continuación son nuevos o están anulados con un comportamiento diferente.

$c = Dpkg::Control->new(%opts)
Crea un nuevo objeto de control deb822.

Opciones:

type
Establece el tipo de control deb822, utilizado para configurar los valores predeterminados de otras opciones.

Ver set_options() para más detalles.

$c->set_options(%opts)
Cambia el valor de una o más opciones.

Opciones:

type
Establece el tipo de objeto de control deb822, utilizado para definir los valores predeterminados de otras opciones.

El orden de salida también se establece para que coincida con la lista ordenada devuelta por Dpkg::Control::Fields::field_ordered_list($type).

name
Establece una descripción textual del tipo de información de control.
allow_pgp
Establece si el analizador acepta firmas OpenPGP alrededor de la información de control deb822.

Por defecto, se establece en 1 para CTRL_DSC, CTRL_FILE_CHANGES y CTRL_REPO_RELEASE, y en 0 en caso contrario.

allow_duplicate
Establece si el analizador permite campos duplicados en la información de control deb822.
keep_duplicate
Establece si el analizador mantendrá los valores de los campos duplicados encontrados en la información de control deb822 (cuando allow_duplicate está habilitado), como referencias a matrices.
drop_empty
Establece si los campos vacíos se descartan durante la salida.

Por defecto, se establece en 0 para CTRL_TMPL_SRC y CTRL_TMPL_PKG, y en 1 en caso contrario.

$c->get_type()
Devuelve el tipo de información de control almacenada. Ver el parámetro type establecido durante new().
