Documentación de Función/Subrutina

subrutina dpocon (character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision anorm, double precision rcond, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DPOCON

Propósito:

!>
!> DPOCON estima la recíproca del número de condición (en la
!> norma 1) de una matriz real simétrica definida positiva usando
!> la factorización de Cholesky A = U**T*U o A = L*L**T calculada por DPOTRF.
!>
!> Se obtiene una estimación para norm(inv(A)), y se calcula la recíproca del
!> número de condición como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T, tal como se calcula por DPOTRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>          La norma 1 (o norma infinito) de la matriz simétrica A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La recíproca del número de condición de la matriz A,
!>          calculada como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (3*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
