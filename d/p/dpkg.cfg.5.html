NOMBRE

dpkg.cfg - archivo de configuración de dpkg

DESCRIPCIÓN

Este archivo contiene opciones predeterminadas para dpkg. Cada línea contiene una única opción que es exactamente igual a una opción normal de la línea de comandos para dpkg, excepto que no se usan los guiones iniciales. Las comillas que rodean los valores de las opciones se eliminan. Se permiten comentarios comenzando una línea con un signo de almohadilla (‘#’).
