NOMBRE

DPMSForceLevel - fuerza una pantalla compatible con DPMS a entrar en el nivel de potencia especificado

SINOPSIS

cc [ flag ... ] archivo ... -lXext [ biblioteca ... ]
#include <X11/extensions/dpms.h>
Status DPMSForceLevel ( Display *display, CARD16 level );

ARGUMENTOS

display
Especifica la conexión con el servidor X
level
Especifica el nivel al que forzar la potencia

DESCRIPCIÓN

La función DPMSForceLevel fuerza una pantalla compatible con DPMS a entrar en el nivel de potencia especificado. El level debe ser uno de los siguientes cuatro estados: DPMSModeOn, DPMSModeStandby, DPMSModeSuspend, o DPMSModeOff. Valores distintos a estos resultarán en un error BadValue. Si DPMS está deshabilitado en la pantalla, intentar establecer el nivel de potencia en la pantalla resultará en un error de protocolo BadMatch.

VALORES DE RETORNO

TRUE
La función DPMSForceLevel siempre devuelve TRUE.

ERRORES

BadValue
Se especificó un nivel distinto de DPMSModeOn, DPMSModeStandby, DPMSModeSuspend, o DPMSModeOff.
BadMatch
DPMS está deshabilitado en la pantalla especificada.
