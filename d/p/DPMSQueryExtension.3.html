NOMBRE

DPMSQueryExtension - consulta al servidor X para determinar la disponibilidad de la Extensión DPMS

SINOPSIS

cc [ opción ... ] archivo ... -lXext [ biblioteca ... ]
#include <X11/extensions/dpms.h>
Bool DPMSQueryExtension
(
      Display *display,
      int *event_base,
      int *error_base
);

ARGUMENTOS

display
Especifica la conexión al servidor X
event_base
Especifica la ubicación de retorno para el evento base asignado
error_base
Especifica la ubicación de retorno para el error base asignado

DESCRIPCIÓN

La función DPMSQueryExtension consulta al servidor X para determinar la disponibilidad de la Extensión de Señalización de Gestión de Energía de Pantalla (DPMS). Si la extensión está disponible, devuelve TRUE, y event_base y error_base se establecen en los números base de evento y error, respectivamente. De lo contrario, el valor de retorno es FALSE y los valores de event_base y error_base no están definidos.

VALORES DE RETORNO

TRUE
La función DPMSQueryExtension devuelve TRUE si la extensión está disponible, y event_base y error_base se establecen en el número base de evento y el número base de error para la extensión, respectivamente.
FALSE
La función DPMSQueryExtension devuelve FALSE si la extensión no está disponible, y los valores de event_base y error_base no están definidos.
