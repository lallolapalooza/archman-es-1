DPIPE(1) Manual de Comandos Generales DPIPE(1)

NOMBRE

dpipe - comando de tubería bidireccional

SINOPSIS

dpipe [ comando [ args ] ] = [ comando [ args ] ]
dpipe [ comando [ args ] ] = [ comando [ args ] ] [ = [ comando [ args ] ] ] ...

DESCRIPCIÓN

dpipe es una herramienta general para ejecutar dos comandos redirigiendo la salida estándar del primer comando a la entrada estándar del segundo y viceversa. Es la extensión bidireccional de la sintaxis | (tubería) utilizada por todos los shells. Se ha elegido el signo = como metáfora de dos líneas de comunicación paralelas entre los comandos. También es posible concatenar varias herramientas. Los programas intermedios se comunican usando la entrada estándar y la salida estándar con la herramienta precedente y alternan la entrada estándar y la salida (respectivamente los descriptores de archivo número 3 y 4) hacia la siguiente herramienta. Si una herramienta intermedia debe procesar solo los datos que fluyen en una dirección, use { o } como sufijo para el signo = precedente y prefijo del siguiente.
Esta herramienta se ha escrito como una herramienta para la Red Ethernet Distribuida Virtual.

EJEMPLO

dpipe a = b
los procesos a y b están conectados bidireccionalmente: la entrada estándar de a está conectada a la salida estándar de b y viceversa
dpipe a = b = c
a y b están conectados como se describe arriba. La entrada estándar alterna de b está conectada a la salida estándar de c y la salida estándar alterna de b a la entrada estándar de c
dpipe a =} b }= c
esto es un ciclo de tuberías: la salida estándar de a está conectada a la entrada estándar de b, la salida estándar de b con la entrada estándar de c, y la salida estándar de c a la entrada estándar de a
dpipe a =} b }={ c {= d = e
todas las notaciones se pueden mezclar. esto es a -> b -> d -> c y de vuelta a a; los puertos alternos de d están conectados a e
