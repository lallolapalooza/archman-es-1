Documentación de función/subrutina

subrutina dpbt01 (character uplo, integer n, integer kd, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldafac, * ) afac, integer ldafac, double precision, dimension( * ) rwork, double precision resid)

DPBT01

Propósito:

!>
!> DPBT01 reconstruye una matriz de banda simétrica positiva definida A de
!> su factorización L*L' o U'*U y calcula el residuo
!>    norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>    norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> donde EPS es la epsilon de la máquina, L' es la transpuesta conjugada de
!> L, y U' es la transpuesta conjugada de U.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de super-diagonales de la matriz A si UPLO = 'U',
!>          o el número de sub-diagonales si UPLO = 'L'.  KD >= 0.
!>

A

!>          A es un array de DOUBLE PRECISION, dimension (LDA,N)
!>          La matriz simétrica original de banda A.  Si UPLO = 'U', la
!>          parte triangular superior de A está almacenada como una matriz
!>          de banda; si UPLO = 'L', la parte triangular inferior de A
!>          está almacenada. Las columnas del triángulo apropiado están
!>          almacenadas en las columnas de A y las diagonales del triángulo
!>          están almacenadas en las filas de A. Ver DPBTRF para más detalles.
!>

LDA

!>          LDA es INTEGER.
!>          La dimensión principal del array A.  LDA >= max(1,KD+1).
!>

AFAC

!>          AFAC es un array de DOUBLE PRECISION, dimension (LDAFAC,N)
!>          La forma factorizada de la matriz A. AFAC contiene el factor
!>          L o U de la factorización L*L' o U'*U en formato de almacenamiento
!>          de banda, tal como se calcula por DPBTRF.
!>

LDAFAC

!>          LDAFAC es INTEGER
!>          La dimensión principal del array AFAC.
!>          LDAFAC >= max(1,KD+1).
!>

RWORK

!>          RWORK es un array de DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          Si UPLO = 'L', norm(L*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U'*U - A) / ( N * norm(A) * EPS )
!>
