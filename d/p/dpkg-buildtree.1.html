NOMBRE

dpkg-buildtree - auxiliar para operaciones de árbol de compilación durante la compilación de paquetes

SINOPSIS

dpkg-buildtree [opción...] [comando]

DESCRIPCIÓN

dpkg-buildtree es una herramienta para realizar operaciones comunes en el árbol de compilación de un paquete fuente.

Este programa fue introducido en dpkg 1.22.3.

COMANDOS

clean
Elimina todos los artefactos generados durante una compilación por las diversas herramientas de dpkg, y las rutas de nombres utilizadas o controladas por las herramientas de dpkg que son seguras de limpiar. Estos archivos se utilizan para rastrear el estado entre ejecuciones de compilación de paquetes, y en muchos casos son detalles de implementación internos que al empaquetador no le deben preocupar, o son directorios de preparación que contienen artefactos de compilación.
is-rootless
Comprueba si el árbol de compilación se puede compilar sin privilegios de root (desde dpkg 1.22.12).

Este comando se puede usar de forma segura incluso con versiones donde el comando aún no estaba disponible, ya que la opción predeterminada será la histórica, donde se requería root.

--help
Muestra el mensaje de uso y sale.
--version
Muestra la versión y sale.

AMBIENTE

DPKG_COLORS
Establece el modo de color. Los valores aceptados actualmente son: auto (predeterminado), always y never.
DPKG_NLS
Si está establecido, se utilizará para decidir si activar o no la compatibilidad con el idioma nativo, también conocida como internacionalización (o i18n). Los valores aceptados son: 0 y 1 (predeterminado).

ARCHIVOS

Archivos limpiados

debian/files
debian/files.new
Archivos generados por dpkg-distaddfile(1).
debian/substvars
debian/substvars.new
Archivos generados por dpkg-shlibdeps(1).
debian/tmp
Directorio de preparación que contiene el contenido que se utilizará al crear un paquete. Tanto dpkg-gencontrol(1) como dpkg-gensymbols(1) generan archivos dentro.

EJEMPLOS

Uso en debian/rules

Puedes llamar a dpkg-buildtree clean desde el objetivo debian/rules clean, después de haber realizado otras limpiezas necesarias.

Por ejemplo, para un sistema de compilación tipo autoconf:

clean:
      [ ! -f Makefile ] || $(MAKE) distclean
      dpkg-buildtree clean
