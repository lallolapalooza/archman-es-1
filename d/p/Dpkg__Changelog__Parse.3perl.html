NOMBRE

Dpkg::Changelog::Parse - Analizador genérico de changelog para dpkg-parsechangelog

DESCRIPCIÓN

Este módulo proporciona un conjunto de funciones que reproducen todas las características de dpkg-parsechangelog.

FUNCIONES

$fields = changelog_parse(%opts)
Esta función analizará un changelog. En contexto de lista, devuelve tantos objetos Dpkg::Control como el analizador haya creado. En contexto de escalar, solo devolverá el primero. Si el analizador no devolvió ningún dato, devolverá una lista vacía en contexto de lista o undef en contexto escalar. Si el analizador falló, morirá. Cualquier error de análisis se imprimirá como advertencia en la salida estándar de error, pero esto se puede deshabilitar pasando $opts{verbose} a 0.

El análisis en sí lo realiza un módulo analizador (buscado en los directorios de bibliotecas estándar de perl). Ese módulo se nombra según el formato que es capaz de analizar, con el nombre en mayúsculas. Por defecto, es Dpkg::Changelog::Debian (del formato "debian") o el nombre del formato buscado en las últimas 40 líneas del propio changelog (extraído con esta expresión regular de perl "\schangelog-format:\s+([0-9a-z]+)\W"). Pero se puede sobrescribir con $opts{changelogformat}.

Todas las demás claves en %opts se reenvían al constructor del módulo analizador.

Opciones:

archivo
Establece el archivo changelog a analizar. Por defecto es debian/changelog.
etiqueta
Establece el nombre del changelog utilizado en los mensajes de salida. Por defecto es $opts{archivo}.
compresion
Establece un valor booleano sobre si cargar el archivo sin soporte de compresión. Si el archivo es el predeterminado, la compresión está deshabilitada, de lo contrario, el predeterminado es habilitar la compresión.
formato_changelog
Establece el formato de entrada del changelog a utilizar.
formato
Establece el formato de salida a utilizar. Por defecto es "dpkg".
verboso
Establece si se deben imprimir los errores de análisis como advertencias en la salida estándar de error. Por defecto es verdadero.
