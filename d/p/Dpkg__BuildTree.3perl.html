NOMBRE

Dpkg::BuildTree - manejar acciones del árbol de construcción

DESCRIPCIÓN

El módulo Dpkg::BuildTree proporciona funciones para manejar acciones del árbol de construcción.

Nota: Este es un módulo privado, su API puede cambiar en cualquier momento.

MÉTODOS

$bt = Dpkg::BuildTree->new(%opts)
Crea un nuevo objeto Dpkg::BuildTree.

Opciones:

dir
El directorio del árbol de construcción. Si no se especifica, asume el directorio de trabajo actual.
$bt->clean()
Limpia el árbol de construcción, eliminando cualquier artefacto generado por dpkg.
$bt->needs_root()
Comprueba si el árbol de construcción necesita ser construido como root.
