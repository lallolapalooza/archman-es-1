NOMBRE

Dpkg::Deps::KnownFacts - lista de paquetes reales y virtuales instalados

DESCRIPCIÓN

Esta clase representa una lista de paquetes instalados y una lista de paquetes virtuales proporcionados (por el conjunto de paquetes instalados).

MÉTODOS

$facts = Dpkg::Deps::KnownFacts->new();
Crea un nuevo objeto.
$facts->add_installed_package($package, $version, $arch, $multiarch)
Registra que la versión dada del paquete está instalada. Si $version/$arch no está definido, sabemos que el paquete está instalado pero no sabemos qué versión/arquitectura es. $multiarch es el campo Multi-Arch del paquete. Si $multiarch es indefinido, será equivalente a "Multi-Arch: no".

Tenga en cuenta que $multiarch solo se utiliza si se proporciona $arch.

$facts->add_provided_package($virtual, $relation, $version, $by)
Registra que el paquete "$by" proporciona el paquete $virtual. $relation y $version corresponden a la relación asociada dada en el campo Provides (si está presente).
$facts->evaluate_simple_dep()
Este método es privado y no debe usarse excepto desde dentro de Dpkg::Deps.

CAMBIOS

Versión 2.00 (dpkg 1.20.0)

Método eliminado: $facts->check_package().

Versión 1.01 (dpkg 1.16.1)

Nueva opción: $facts->add_installed_package() ahora acepta 2 parámetros suplementarios ($arch y $multiarch).

Método obsoleto: $facts->check_package() está obsoleto, no debería haber sido parte de la API pública.

Versión 1.00 (dpkg 1.15.6)

Marca el módulo como público.
