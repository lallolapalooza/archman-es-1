NOMBRE

Dpkg::Arch - manejar arquitecturas

DESCRIPCIÓN

El módulo Dpkg::Arch proporciona funciones para manejar arquitecturas Debian, comodines y mapeo desde y hacia triplas GNU.

Por defecto no se exporta ningún símbolo. La etiqueta :all se puede usar para importar todos los símbolos. Las etiquetas :getters, :parsers, :mappers y :operators se pueden usar para importar subconjuntos específicos de símbolos.

FUNCIONES

$arch = get_raw_build_arch()
Obtiene la arquitectura de compilación Debian cruda, sin tener en cuenta las variables del entorno.
$arch = get_build_arch()
Obtiene la arquitectura de compilación Debian, usando DEB_BUILD_ARCH del entorno si está disponible.
$arch = get_raw_host_arch()
Obtiene la arquitectura host Debian cruda, sin tener en cuenta las variables del entorno.
$arch = get_host_arch()
Obtiene la arquitectura host Debian, usando DEB_HOST_ARCH del entorno si está disponible.
@arch_list = get_valid_arches()
Obtiene un array con todas las arquitecturas Debian actualmente conocidas.
$multiarch = gnutriplet_to_multiarch($gnutriplet)
Mapea una tripla GNU a una tripla multiarch Debian.
$multiarch = debarch_to_multiarch($arch)
Mapea una arquitectura Debian a una tripla multiarch Debian.
$gnutriplet = debarch_to_gnutriplet($arch)
Mapea una arquitectura Debian a una tripla GNU.
$arch = gnutriplet_to_debarch($gnutriplet)
Mapea una tripla GNU a una arquitectura Debian.
$bool = debarch_eq($arch_a, $arch_b)
Evalúa la igualdad de una arquitectura Debian, comparándola con otra arquitectura Debian. No se realiza coincidencia de comodines.
$bool = debarch_is($arch, $arch_wildcard)
Evalúa la identidad de una arquitectura Debian, coincidiendo con un comodín de arquitectura.
$bool = debarch_is_wildcard($arch)
Evalúa si una arquitectura Debian es un comodín de arquitectura.
$bool = debarch_is_illegal($arch, %opts)
Valida un nombre de arquitectura.

Opciones:

positive
Si se establece en un valor verdadero, solo se aceptarán arquitecturas positivas, de lo contrario se permitirán arquitecturas negadas.
$bool = debarch_is_concerned($arch, @arches)
Evalúa si una arquitectura Debian se aplica a la lista de restricciones de arquitecturas, como se encuentra normalmente en las dependencias dentro de corchetes.
@array = debarch_list_parse($arch_list, %opts)
Analiza una lista de arquitecturas.

Opciones:

positive
Si se establece en un valor verdadero, solo se aceptarán arquitecturas positivas, de lo contrario se permitirán arquitecturas negadas.

CAMBIOS

Versión 1.03 (dpkg 1.19.1)

Nuevo argumento: Acepta una opción "positive" en debarch_is_illegal() y debarch_list_parse().

Versión 1.02 (dpkg 1.18.19)

Nuevas etiquetas de importación: ":all", ":getters", ":parsers", ":mappers", ":operators".

Versión 1.01 (dpkg 1.18.5)

Nuevas funciones: debarch_is_illegal(), debarch_list_parse().

Versión 1.00 (dpkg 1.18.2)

Marca el módulo como público.
