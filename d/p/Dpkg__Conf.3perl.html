NOMBRE

Dpkg::Conf - analizar archivos de configuración de dpkg

DESCRIPCIÓN

El objeto Dpkg::Conf se puede usar para leer opciones de un archivo de configuración. Puede exportar un array que luego se puede analizar exactamente como @ARGV.

MÉTODOS

$conf = Dpkg::Conf->new(%opts)
Crear un nuevo objeto Dpkg::Conf.

Opciones:

allow_short
Si se establece en verdadero (por defecto es falso), se permiten opciones cortas en el archivo de configuración; deben ir precedidas de un único guion.
@$conf
@opciones = $conf->get_options()
Devuelve la lista de opciones que se pueden analizar como @ARGV.
$conf->load($file)
Lee opciones de un archivo. Devuelve el número de opciones analizadas.
$conf->load_system_config($file)
Lee opciones de un archivo de configuración del sistema.

Devuelve el número de opciones analizadas.

$conf->load_user_config($file)
Lee opciones de un archivo de configuración del usuario. Intentará usar el directorio XDG, ya sea $XDG_CONFIG_HOME/dpkg/ o $HOME/.config/dpkg/.

Devuelve el número de opciones analizadas.

$conf->load_config($file)
Lee opciones de los archivos de configuración del sistema y del usuario.

Devuelve el número de opciones analizadas.

$conf->parse($fh)
Analiza opciones de un manejador de archivo. Cuando se llama varias veces, las opciones analizadas se acumulan.

Devuelve el número de opciones analizadas.

$conf->filter(%opts)
Filtra la lista de opciones de configuración.

Opciones:

remove
Una función que devuelve un booleano, utilizada para decidir si eliminar la opción de configuración, ejecutada como $opts{remove}->($option).
keep
Una función que devuelve un booleano, utilizada para decidir si mantener la opción de configuración, ejecutada como $opts{keep}->($option).
$string = $conf->output([$fh])
Escribe las opciones en el manejador de archivo dado (si está definido) y devuelve una representación en cadena del contenido que se escribiría.
"$conf"
Devuelve una representación en cadena del contenido.
$conf->save($file)
Guarda las opciones en un archivo.

CAMBIOS

Eliminados métodos: $conf->get(), $conf->set().

Opción obsoleta: 'format_argv' en $conf->filter().

Métodos obsoletos: $conf->get(), $conf->set().

Nuevos métodos: $conf->load_system_config(), $conf->load_system_user(), $conf->load_config().

Versión 1.02 (dpkg 1.18.5)

Nueva opción: Acepta la nueva opción 'format_argv' en $conf->filter().

Nuevos métodos: $conf->get(), $conf->set().

Versión 1.01 (dpkg 1.15.8)

Nuevo método: $conf->filter()
