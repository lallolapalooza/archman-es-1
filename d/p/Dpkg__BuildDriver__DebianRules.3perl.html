NOMBRE

Dpkg::BuildDriver::DebianRules - construir un paquete Debian usando debian/rules

DESCRIPCIÓN

Esta clase es utilizada por dpkg-buildpackage para dirigir la construcción de un paquete Debian, usando debian/rules.

Nota: Este es un módulo privado, su API puede cambiar en cualquier momento.

MÉTODOS

$bd = Dpkg::BuildDriver::DebianRules->new(%opts)
Crea un nuevo objeto Dpkg::BuildDriver::DebianRules.

Soporta o requiere las mismas opciones de Dpkg::BuildDriver->new().

$bd->pre_check()
Realiza verificaciones específicas del controlador de construcción, antes de cualquier otra cosa.

Esto verifica si el archivo debian/rules es ejecutable y, si no lo es, lo hace ejecutable.

$bool = $bd->need_build_task($build_task, $binary_task)
Devuelve si necesitamos usar la tarea de construcción.

Nota: Este método es necesario mientras soportemos la construcción como root. Una vez que ya no sea necesario, este método será obsoleto.

$bd->run_build_task($build_task, $binary_task)
Ejecuta la tarea de construcción para la compilación.

Nota: Este método es necesario mientras soportemos la construcción como root. Una vez que ya no sea necesario, este método será obsoleto.

$bd->run_task($task)
Ejecuta la tarea dada para la construcción.
