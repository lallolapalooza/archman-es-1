DPMSSetTimeouts(3) FUNCIONES X DPMSSetTimeouts(3)

NOMBRE

DPMSSetTimeouts - permite a las aplicaciones establecer los valores de tiempo de espera utilizados por el servidor X para los tiempos de DPMS

SINOPSIS

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/dpms.h>
Status DPMSSetTimeouts
(
      Display *display,
      CARD16 standby,
      CARD16 suspend,
      CARD16 off
);

ARGUMENTOS

display
Especifica la conexión con el servidor X
standby
Especifica el nuevo tiempo de espera de espera en segundos
suspend
Especifica el nuevo tiempo de espera de suspensión en segundos
off
Especifica el nuevo tiempo de espera de apagado en segundos

DESCRIPCIÓN

La función DPMSSetTimeouts permite a las aplicaciones establecer los valores de tiempo de espera utilizados por el servidor X para los tiempos de Señalización de Gestión de Energía de Pantalla (DPMS).

El valor standby es la cantidad de tiempo de inactividad, en segundos, antes de que se active el modo de espera. Los efectos reales de este modo dependen de las características del monitor y de la tarjeta de memoria de vídeo. El modo de espera se implementa apagando la señal de sincronización horizontal y emitiendo la señal de sincronización vertical. El modo de espera proporciona el tiempo de recuperación más rápido del monitor. Tenga en cuenta también que muchos monitores implementan este modo idéntico al modo de suspensión. Un valor de cero deshabilita el modo de espera.

El valor suspend es la cantidad de tiempo de inactividad, en segundos, antes de que se active el segundo nivel de ahorro de energía. Las características físicas y eléctricas del modo de suspensión se definen en la implementación. Para hardware compatible con DPMS, el ajuste del modo de suspensión se implementa emitiendo la señal de sincronización horizontal y apagando la señal de sincronización vertical. En general, se considera que la recuperación del modo de suspensión es más lenta que la del modo de espera, pero más rápida que la del modo de apagado. Sin embargo, puede variar de un monitor a otro. Como se mencionó anteriormente, muchos monitores implementan este modo idéntico al modo de espera. Un valor de cero deshabilita este modo.

El valor off es la cantidad de tiempo de inactividad, en segundos, antes de que se active el tercer y último nivel de ahorro de energía. Las características físicas y eléctricas del modo de apagado se definen en la implementación. En hardware compatible con DPMS, se implementa apagando las señales de sincronización horizontal y vertical, lo que resulta en la desconexión del monitor. El tiempo de recuperación depende de la implementación. Normalmente, el tiempo de recuperación está muy cerca del tiempo de encendido del monitor. Un valor de cero deshabilita este modo.

Cronológicamente, el modo standby ocurre antes o simultáneamente con el modo suspend, y el modo suspend debe ocurrir antes o simultáneamente con el modo off. Por lo tanto, los valores de tiempo de espera de modo distintos de cero deben ser mayores o iguales a los valores de tiempo de espera de modos anteriores. Si se suministran valores inconsistentes, se producirá un error BadValue.

VALORES DE RETORNO

VERDADERO
La función DPMSSetTimeouts devuelve VERDADERO cuando la función se ha realizado con éxito.

ERRORES

BadValue
Un argumento está fuera de rango.
