DPPSVX calcula la solución del sistema de ecuaciones lineales A * X = B para otras matrices

Propósito:

!>
!> DPPSVX utiliza la factorización de Cholesky A = U**T*U o A = L*L**T para
!> calcular la solución de un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica definida positiva N-por-N almacenada en
!> formato empaquetado y X y B son matrices N-por-NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibrará o no depende de la
!>    escala de la matriz A, pero si se usa el equilibrado, A se
!>    sobrescribe con diag(S)*A*diag(S) y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular
!>    inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina retorna con INFO = i. De lo contrario, la forma
!>    factorizada de A se utiliza para estimar el número de condición de la
!>    matriz A. Si la recíproca del número de condición es menor que la
!>    precisión de la máquina, se retorna INFO = N+1 como una advertencia,
!>    pero la rutina aún continúa para resolver X y calcular los límites de
!>    error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución
!>    calculada y obtener límites de error y estimaciones de error hacia
!>    atrás para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de
!>    equilibrar.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra o no en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de factorizarla.
!>          = 'F':  En la entrada, AFP contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S. AP y AFP no
!>                  serán modificados.
!>          = 'N':  La matriz A se copiará en AFP y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es un array de DOUBLE PRECISION, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          A, empaquetado por columnas en un array lineal, excepto si FACT = 'F'
!>          y EQUED = 'Y', entonces A debe contener la matriz equilibrada
!>          diag(S)*A*diag(S).  La j-ésima columna de A se almacena en
!>          el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles. A no se modifica si
!>          FACT = 'F' o 'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>          diag(S)*A*diag(S).
!>

AFP

!>          AFP es un array de DOUBLE PRECISION, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T, en el mismo formato de almacenamiento
!>          que A. Si EQUED .ne. 'N', entonces AFP es la forma factorizada
!>          de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**T * U o A = L * L**T de la matriz original
!>          A.
!>
!>          Si FACT = 'E', entonces AFP es un argumento de salida y en la salida
!>          devuelve el factor triangular U o L de la factorización de Cholesky
!>          A = U**T * U o A = L * L**T de la matriz equilibrada
!>          A (ver la descripción de AP para la forma de la
!>          matriz equilibrada).
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'Y':  Se realizó equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

S

!>          S es un array de DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala para A; no se accede si EQUED = 'N'. S es
!>          un argumento de entrada si FACT = 'F'; de lo contrario, S es un
!>          argumento de salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S
!>          debe ser positivo.
!>

B

!>          B es un array de DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de N-por-NRHS.
!>          En la salida, si EQUED = 'N', B no se modifica; si EQUED = 'Y',
!>          B se sobrescribe con diag(S) * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array de DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N-por-NRHS a
!>          la ecuación original. Tenga en cuenta que si EQUED = 'Y',
!>          A y B se modifican en la salida, y la solución del
!>          sistema equilibrado es inv(diag(S))*X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECI
SION
!>          La estimación del número de condición recíproco de la matriz
!>          A después de la ecualización (si se realizó). Si RCOND es menor que la
!>          precisión de la máquina (en particular, si RCOND = 0), la matriz
!>          es singular a la precisión de trabajo. Esta condición es
!>          indicada por un código de retorno de INFO > 0.
!>

FERR

!>          FERR es un arreglo DOUBLE PRECISION, de dimensión (NRHS)
!>          La estimación de la cota de error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución real correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del mayor
!>          elemento en (X(j) - XTRUE) dividida por la magnitud del
!>          mayor elemento en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error real.
!>

BERR

!>          BERR es un arreglo DOUBLE PRECISION, de dimensión (NRHS)
!>          El error relativo hacia atrás componente a componente de cada vector
!>          solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un arreglo DOUBLE PRECISION, de dimensión (3*N)
!>

IWORK

!>          IWORK es un arreglo INTEGER, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse, y la solución no ha sido
!>                       calculada. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       a la precisión de trabajo. Sin embargo, la
!>                       solución y las cotas de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que la
!>                       que sugeriría el valor de RCOND.
!>
