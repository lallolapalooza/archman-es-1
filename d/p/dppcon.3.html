subrutina dppcon (character uplo, integer n, double precision, dimension( * ) ap, double precision anorm, double precision rcond, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DPPCON

Propósito:

!>
!> DPPCON estima la inversa del número de condición (en la
!> norma 1) de una matriz simétrica real definida positiva empaquetada
!> utilizando la factorización de Cholesky A = U**T*U o A = L*L**T calculada por
!> DPPTRF.
!>
!> Se obtiene una estimación de norm(inv(A)), y se calcula la inversa del número
!> de condición como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array DOUBLE PRECISION, de dimensión (N*(N+1)/2)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**T*U o A = L*L**T, empaquetado por columnas en un
!>          array lineal. La j-ésima columna de U o L se almacena en el
!>          array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) para j<=i<=n.
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>          La norma 1 (o norma infinito) de la matriz simétrica A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La inversa del número de condición de la matriz A,
!>          calculada como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (3*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>
