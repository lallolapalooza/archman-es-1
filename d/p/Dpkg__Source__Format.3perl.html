NOMBRE

Dpkg::Source::Format - manipula archivos debian/source/format

DESCRIPCIÓN

Este módulo proporciona una clase que puede manipular archivos debian/source/format de paquetes fuente de Debian.

MÉTODOS

$f = Dpkg::Source::Format->new(%opts)
Crea un nuevo objeto correspondiente al archivo debian/source/format de un paquete fuente.

Opciones:

filename
Establece el nombre de archivo a usar para analizar y establecer el formato.
format
Establece y valida el formato a usar en lugar de cargar el archivo por defecto, si no se ha especificado un nombre de archivo.
$f->set_from_parts($major[, $minor[, $variant]])
Establece el formato fuente a partir de sus partes. La parte $major es obligatoria. Las partes $minor y $variant son opcionales.

Aviso: Esta función no realiza validación.

($major, $minor, $variant) = $f->set($format)
Establece (y valida) el formato fuente $format especificado. Devolverá las partes del formato analizado como una lista, las partes opcionales $minor y $variant podrían ser undef.
($major, $minor, $variant) = $f->get()
$format = $f->get()
Obtiene el formato fuente, ya sea como un escalar formateado correctamente, o como una lista de sus partes, donde las partes opcionales $minor y $variant pueden ser undef.
$count = $f->parse($fh, $desc)
Analiza la cadena de formato fuente desde $fh, con la descripción del manejador de archivo $desc.
$count = $f->load($filename)
Analiza el contenido de $filename para una cadena de formato de paquete fuente.
$str = $f->output([$fh])
"$f"
Devuelve una cadena que representa la versión del formato del paquete fuente. Si se establece $fh, imprime la cadena en el manejador de archivo.
$f->save($filename)
Guarda el formato del paquete fuente en el $filename dado.
