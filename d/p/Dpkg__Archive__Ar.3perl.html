NOMBRE

Dpkg::Archive::Ar - Soporte para archivos ar de Unix

DESCRIPCIÓN

Este módulo proporciona una clase para manejar archivos ar de Unix. Soporta el formato común, sin extensiones GNU o BSD.

Nota: Este es un módulo privado, su API puede cambiar en cualquier momento.

MÉTODOS

$ar = Dpkg::Archive::Ar->new(%opts)
Crea un nuevo objeto para manejar archivos ar de Unix.

Opciones:

filename
El nombre del archivo para abrir o crear.
create
Un booleano que indica si el archivo debe ser creado; de lo contrario, si no existe, el constructor no lo abrirá, creará ni escaneará.
$ar->create_archive($filename)
Crea el archivo.
$ar->open_archive($filename)
Abre el archivo.
$ar->parse_magic()
Lee y analiza la cadena mágica del archivo, y la valida.
$ar->parse_member()
Lee y analiza el miembro del archivo y lo registra para su posterior manejo.
$ar->skip_member($member)
Salta este miembro al siguiente. Obtiene el valor de una sustitución dada.
$ar->scan_archive()
Escanea el archivo en busca de todos sus archivos miembros y metadatos.
$ar->get_members()
Obtiene la lista de miembros en el archivo.
$ar->extract_member($member)
Extrae el miembro especificado al directorio actual.
$ar->write_member($member)
Escribe el $member proporcionado en el archivo.
$ar->add_file($filename)
Añade el $filename especificado al archivo.
$ar->close_archive()
Cierra el archivo y libera cualquier recurso asignado.
