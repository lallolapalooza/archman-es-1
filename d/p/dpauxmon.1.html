NOMBRE

dpauxmon - Proporciona interfaces para capturar datos del canal DisplayPort AUX.

SINOPSIS

dpauxmon [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --extcap-capture-filter=<filtro de captura> ] [ --capture ] [ --fifo=<ruta a archivo o tubería> ] [ --interface_id=<ID de interfaz para capturar> ]

dpauxmon --extcap-interfaces

dpauxmon --extcap-interface=<interfaz> --extcap-dlts

dpauxmon --extcap-interface=<interfaz> --extcap-config

dpauxmon --extcap-interface=<interfaz> --fifo=<ruta a archivo o tubería> --capture --interface_id=id_interfaz

DESCRIPCIÓN

dpauxmon es una herramienta extcap que puede capturar datos del canal DisplayPort AUX desde controladores del kernel de Linux utilizando la interfaz netlink genérica.

Interfaces soportadas:

1.dpauxmon

OPCIONES

--help

Imprime los argumentos del programa.

--version

Imprime la versión del programa.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Utiliza las interfaces especificadas.

--extcap-dlts

Lista los DLTs de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--capture

Inicia la captura desde la interfaz especificada y la guarda en la ubicación especificada por --fifo.

--fifo=<ruta a archivo o tubería>

Guarda el paquete capturado en un archivo o lo envía a través de una tubería.

--interface_idt=<id de interfaz>

La interfaz para la captura.

EJEMPLOS

Para ver los argumentos del programa:

dpauxmon --help

Para ver la versión del programa:

dpauxmon --version

Para ver las interfaces:

dpauxmon --extcap-interfaces

Solo se soporta una interfaz (dpauxmon).

Salida de ejemplo

interface {value=dpauxmon}{display=DisplayPort AUX channel capture}

Para ver los DLTs de la interfaz:

dpauxmon --extcap-interface=dpauxmon --extcap-dlts

Salida de ejemplo

dlt {number=275}{name=dpauxmon}{display=DisplayPort AUX channel monitor DLT}

Para ver las opciones de configuración de la interfaz:

dpauxmon --extcap-interface=dpauxmon --extcap-config

Salida de ejemplo

dpauxmon --extcap-interface=dpauxmon --extcap-config
arg {number=0}{call=--interface_id}{display=Interface Id}
    {type=unsigned}{tooltip=The Interface Id}
    {required=true}

Para capturar:

dpauxmon --extcap-interface=dpauxmon --fifo=/tmp/dpauxmon.pcap --capture --interface_id 0
