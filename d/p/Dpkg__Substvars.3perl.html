Dpkg::Substvars(3perl) libdpkg-perl Dpkg::Substvars(3perl)

NOMBRE

Dpkg::Substvars - manejar la sustitución de variables en cadenas

DESCRIPCIÓN

Proporciona una clase que es capaz de sustituir variables en cadenas.

MÉTODOS

$s = Dpkg::Substvars->new($file)
Crea un nuevo objeto que puede realizar sustituciones. Por defecto contiene sustituciones genéricas como ${Newline}, ${Space}, ${Tab}, ${dpkg:Version} y ${dpkg:Upstream-Version}.

Se leerán sustituciones adicionales desde el $file pasado como parámetro.

Lleva un registro de qué sustituciones se usaron realmente (solo contando substvars(), no get()), y advierte sobre las substvars no usadas cuando se le pide. Las sustituciones que siempre están presentes no se incluyen en estas advertencias.

$s->set($key, $value)
Añade/reemplaza una sustitución.
$s->set_as_used($key, $value)
Añade/reemplaza una sustitución y la marca como usada (no se producirán advertencias incluso si no se usa).
$s->set_as_auto($key, $value)
Añade/reemplaza una sustitución y la marca como usada y automática (no se producirán advertencias incluso si no se usa), y no se emitirá en el archivo de substvars.
$s->set_as_optional($key, $value)
Añade/reemplaza una sustitución y la marca como usada y opcional (no se producirán advertencias incluso si no se usa).
$s->set_as_required($key, $value)
Añade/reemplaza una sustitución y la marca como requerida (se producirá un error si no se usa).
$s->get($key)
Obtiene el valor de una sustitución dada.
$s->delete($key)
Elimina una sustitución dada.
$s->mark_as_used($key)
Evita las advertencias sobre una sustitución no usada, por ejemplo si es proporcionada por defecto.
$s->parse($fh, $desc)
Añade nuevas sustituciones leídas desde el manejador de archivos. $desc se usa para identificar el manejador de archivos en los mensajes de error.

Devuelve el número de sustituciones que se han analizado con éxito.

$s->load($file)
Añade nuevas sustituciones leídas desde $file.
$s->set_version_substvars($sourceversion, $binaryversion)
Define ${binary:Version}, ${source:Version} y ${source:Upstream-Version} basándose en las cadenas de versión dadas.

Nunca se advertirá sobre estas si no se usan.

$s->set_arch_substvars()
Define las variables de arquitectura: ${Arch}.

Nunca se advertirá sobre esta si no se usa.

$s->set_vendor_substvars()
Define las variables del proveedor: ${vendor:Name} y ${vendor:Id}.

Nunca se advertirá sobre estas si no se usan.

$s->set_desc_substvars()
Define las variables de descripción de la fuente: ${source:Synopsis} y ${source:Extended-Description}.

Nunca se advertirá sobre estas si no se usan.

$s->set_field_substvars($ctrl, $prefix)
Define las variables de campo a partir de un objeto Dpkg::Control, con cada variable teniendo la forma "${$prefix:$field}".

Nunca se advertirá sobre estas si no se usan.

$newstring = $s->substvars($string)
Sustituye las variables en $string y devuelve el resultado en $newstring.
$s->warn_about_unused()
Emite advertencias sobre cualquier variable que fue establecida pero no usada.
$s->set_msg_prefix($prefix)
Define un prefijo que se muestra antes de todos los mensajes de advertencia/error emitidos por el módulo.
$s->filter(%opts)
Filtra las variables de sustitución.

Opciones:

remove
Una función que devuelve un booleano, usada para decidir si se debe eliminar una variable de sustitución, ejecutada como $opts{remove}->($var).
keep
Una función que devuelve un booleano, usada para decidir si se debe conservar la variable de sustitución, ejecutada como $opts{keep}->($var).
"$s"
Devuelve una representación de cadena de todas las variables de sustitución excepto las automáticas.
$str = $s->output([$fh])
Devuelve todas las variables de sustitución excepto las automáticas. Si se pasa $fh las imprime en el manejador de archivos.
$s->save($file)
Almacena todas las variables de sustitución excepto las automáticas en el archivo indicado.

CAMBIOS

Versión 2.03 (dpkg 1.22.15)

Nuevos métodos: $s->set_as_optional(), $s->set_as_required().

Versión 2.02 (dpkg 1.22.7)

Nueva característica: Añadir soporte para variables de sustitución requeridas.

Versión 2.01 (dpkg 1.21.8)

Nueva característica: Añadir soporte para variables de sustitución opcionales.

Versión 2.00 (dpkg 1.20.0)

Método eliminado: $s->no_warn().

Nuevo método: $s->set_vendor_substvars().

Versión 1.06 (dpkg 1.19.0)

Nuevo método: $s->set_desc_substvars().

Versión 1.05 (dpkg 1.18.11)

Substvar obsoleta: Emite un error al usar la substvar Source-Version.

Nueva devolución: $s->parse() ahora devuelve el número de substvars analizadas.

Nuevo método: $s->set_field_substvars().

Versión 1.04 (dpkg 1.18.0)

Nuevo método: $s->filter().

Versión 1.03 (dpkg 1.17.11)

Nuevo método: $s->set_as_auto().

Versión 1.02 (dpkg 1.16.5)

Nuevo argumento: Aceptar un $binaryversion en $s->set_version_substvars(), pasar un único argumento sigue siendo soportado.

Nuevo método: $s->mark_as_used().

Método obsoleto: $s->no_warn(), usar $s->mark_as_used() en su lugar.

Versión 1.01 (dpkg 1.16.4)

Nuevo método: $s->set_as_used().

Versión 1.00 (dpkg 1.15.6)

Marcar el módulo como público.
