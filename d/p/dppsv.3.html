Documentación de Función/Subrutina

subrutina dppsv (carácter uplo, entero n, entero nrhs, doble precisión, dimensión( * ) ap, doble precisión, dimensión( ldb, * ) b, entero ldb, entero info)

DPPSV calcula la solución a un sistema real de ecuaciones lineales A * X = B,

Propósito:

!>
!> DPPSV calcula la solución a un sistema real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica definida positiva de N por N almacenada en
!> formato empaquetado y X y B son matrices de N por NRHS.
!>
!> Se utiliza la descomposición de Cholesky para factorizar A como
!>    A = U**T* U,  si UPLO = 'U', o
!>    A = L * L**T,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es una matriz triangular inferior.
!> Luego, se utiliza la forma factorizada de A para resolver el sistema de
!> ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es un array de DOUBLE PRECISION, de dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz simétrica
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más detalles abajo.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización de
!>          Cholesky A = U**T*U o A = L*L**T, en el mismo formato de
!>          almacenamiento que A.
!>

B

!>          B es un array de DOUBLE PRECISION, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal líder de orden i
!>                de A no es positivo, por lo que la factorización no pudo
!>                completarse y la solución no ha sido calculada.
!>

!>  cuando N = 4, UPLO = 'U':
!>
!>  Almacenamiento bidimensional de la matriz simétrica A:
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  Almacenamiento empaquetado del triángulo superior de A:
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
