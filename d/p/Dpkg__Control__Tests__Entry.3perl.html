NOMBRE

Dpkg::Control::Tests::Entry - representa una entrada de conjunto de pruebas

DESCRIPCIÓN

Esta clase representa una entrada de conjunto de pruebas.

MÉTODOS

Todos los métodos de Dpkg::Control están disponibles. Los que se enumeran a continuación son nuevos o se anulan con un comportamiento diferente.

$entry = Dpkg::Control::Tests::Entry->new(%opts)
Crea un nuevo objeto. No representa una entrada de prueba de control real hasta que se haya analizado o construido desde cero con éxito.

Las opciones se pasan al constructor de Dpkg::Control->new().

$entry->parse($fh, $desc)
Analiza una entrada de prueba de control desde un manejador de archivos. Cuando se llama varias veces, los campos analizados se acumulan.

Devuelve verdadero si el análisis fue un éxito.
