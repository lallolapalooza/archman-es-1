subrutina dpstf2 (uplo, n, a, lda, piv, rank, tol, work, info)


DPSTF2 calcula la factorización de Cholesky con pivoteo completo de una matriz real simétrica semidefinida positiva.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina dpstf2 (carácter uplo, entero n, doble precisión, dimensión( lda, * ) a, entero lda, entero, dimensión( n ) piv, entero rank, doble precisión tol, doble precisión, dimensión( 2*n ) work, entero info)

DPSTF2 calcula la factorización de Cholesky con pivoteo completo de una matriz real simétrica semidefinida positiva A.

Propósito:

!>
!> DPSTF2 calcula la factorización de Cholesky con pivoteo completo
!> de una matriz real simétrica semidefinida positiva A.
!>
!> La factorización tiene la forma
!>    P**T * A * P = U**T * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**T,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior, y
!> P se almacena como el vector PIV.
!>
!> Este algoritmo no intenta verificar que A sea semidefinida positiva.
!> Esta versión del algoritmo llama a BLAS de nivel 2.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array de DOBLE PRECISIÓN, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular principal de n por n de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia.  Si UPLO = 'L', la
!>          parte inferior triangular principal de n por n de A contiene la
!>          parte triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización
!>          de Cholesky anterior.
!>

PIV

!>          PIV es un array de ENTEROS, dimensión (N)
!>          PIV es tal que las entradas no nulas son P( PIV(K), K ) = 1.
!>

RANK

!>          RANK es INTEGER
!>          El rango de A dado por el número de pasos que completó el algoritmo.
!>

TOL

!>          TOL es DOBLE PRECISIÓN
!>          Tolerancia definida por el usuario. Si TOL < 0, entonces se usará
!>          N*U*MAX( A( K,K ) ). El algoritmo termina en el paso (K-1) si el
!>          pivote <= TOL.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (2*N)
!>          Espacio de trabajo.
!>

INFO

!>          INFO es INTEGER
!>          < 0: Si INFO = -K, el argumento K tenía un valor ilegal.
!>          = 0: el algoritmo se completó con éxito, y
!>          > 0: la matriz A es de rango deficiente con el rango calculado
!>               como se devuelve en RANK, o no es semidefinida positiva. Ver
!>               la Sección 7 de LAPACK Working Note #161 para más
!>               información.
!>
