DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina dptt05 (integer n, integer nrhs, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

DPTT05

Propósito:

!>
!> DPTT05 verifica los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz simétrica tridiagonal de orden n.
!>
!> RESLTS(1) = verificación del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( NZ*EPS + (*) ), donde
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             y NZ = número máximo de no ceros en cualquier fila de A, más 1
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, dimension (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array DOUBLE PRECISION, dimension (N-1)
!>          Los n-1 elementos subdiagonales de la matriz tridiagonal A.
!>

B

!>          B es un array DOUBLE PRECISION, dimension (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Los vectores de solución calculada. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es un array DOUBLE PRECISION, dimension (LDXACT,NRHS)
!>          Los vectores de solución exacta. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimension (NRHS)
!>          Los límites de error directo estimados para cada vector solución
!>          X.  Si XTRUE es la solución verdadera, FERR limita la magnitud
!>          de la entrada más grande en (X - XTRUE) dividida por la magnitud
!>          de la entrada más grande en X.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimension (NRHS)
!>          El error residual relativo componente a componente de cada vector
!>          solución (es decir, el cambio relativo más pequeño en cualquier
!>          entrada de A o B que hace que X sea una solución exacta).
!>

RESLTS

!>          RESLTS es un array DOUBLE PRECISION, dimension (2)
!>          El máximo sobre los vectores solución NRHS de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
