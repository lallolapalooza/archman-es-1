NOMBRE

dpkg-buildapi - devuelve el nivel de API de compilación a usar durante la compilación de paquetes

SINOPSIS

dpkg-buildapi [opción...] [comando]

DESCRIPCIÓN

dpkg-buildapi es una herramienta para recuperar el nivel de dpkg-build-api(7) a usar durante la compilación de paquetes fuente Debian.

Este programa se introdujo en dpkg 1.22.0.

COMANDOS

--help
Muestra el mensaje de uso y sale.
--version
Muestra la versión y sale.

OPCIONES

-carchivo-control
Especifica el archivo de control fuente principal del que leer información. Por defecto es debian/control.

ENTORNO

DPKG_BUILD_API
El nivel de API de compilación a usar. Esto está pensado para ser utilizado internamente por las herramientas ejecutadas desde debian/rules para evitar tener que analizar debian/control varias veces, y no para establecer el nivel global de API de compilación desde debian/rules, de lo contrario los controladores de compilación (como dpkg-buildpackage(1)) no podrán acceder a él.
DPKG_COLORS
Establece el modo de color. Los valores actualmente aceptados son: auto (por defecto), always (siempre) y never (nunca).
DPKG_NLS
Si está configurado, se usará para decidir si se activa el Soporte de Idioma Nativo, también conocido como internacionalización (o i18n). Los valores aceptados son: 0 y 1 (por defecto).

ARCHIVOS

Soporte de empaquetado

/usr/share/dpkg/buildapi.mk
Fragmento de Makefile que analiza el nivel de API de compilación en una variable.
