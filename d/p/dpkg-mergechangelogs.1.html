NOMBRE

dpkg-mergechangelogs - fusión de 3 vías de archivos debian/changelog

SINOPSIS

dpkg-mergechangelogs [opción...] viejo nuevo-a nuevo-b [salida]

DESCRIPCIÓN

Este programa utilizará las 3 versiones proporcionadas del changelog de Debian para generar un archivo de changelog fusionado. El changelog resultante se almacena en el archivo salida o se envía a la salida estándar si ese parámetro no se proporciona.

Cada entrada se identifica por su número de versión y se asume que no entran en conflicto; simplemente se fusionan en el orden correcto (por número de versión decreciente). Cuando se usa --merge-prereleases, se descarta la parte del número de versión después de la última tilde, de modo que 1.0-1~exp1 y 1.0-1~exp5 se consideran la misma entrada. Cuando la misma versión está disponible tanto en nuevo-a como en nuevo-b, se intenta una fusión estándar de 3 vías basada en líneas (siempre que el módulo Algorithm::Merge esté disponible — forma parte del paquete libalgorithm-merge-perl —, de lo contrario, se obtiene un conflicto global en el contenido de la entrada).

Este programa se introdujo en dpkg 1.15.7.

OPCIONES

--merge-unreleased
Ignora el número de versión cuando las entradas se marcan como UNRELEASED (desde dpkg 1.21.0).

Esto es útil cuando tienes desarrollos divergentes para versiones que aún no han sido liberadas. Por ejemplo, se libera 2.1-1, luego el desarrollo ocurre para el nuevo 2.2-1 y luego para 2.3-1, donde tiene sentido terminar con una entrada fusionada para 2.3-1 que incluya todo el desarrollo realizado en 2.2-1.

-m, --merge-prereleases
Descarta la parte después de la última tilde en el número de versión al realizar la comparación de versiones para identificar si dos entradas son la misma o no.

Esto es útil cuando sigues usando la misma entrada de changelog pero aumentas su número de versión regularmente. Por ejemplo, podrías tener 2.3-1~exp1, 2.3-1~exp2, ... hasta la versión oficial 2.3-1 y todas son la misma entrada de changelog que ha evolucionado con el tiempo.

--help
Muestra el mensaje de uso y sale.
--version
Muestra la versión y sale.

MEDIO AMBIENTE

DPKG_COLORS
Establece el modo de color (desde dpkg 1.18.5). Los valores aceptados actualmente son: auto (por defecto), always y never.
DPKG_NLS
Si está configurado, se utilizará para decidir si activar o no el soporte de Lenguaje Nativo, también conocido como internacionalización (o i18n) (desde dpkg 1.19.0). Los valores aceptados son: 0 y 1 (por defecto).

LIMITACIONES

Todo lo que no sea analizado por Dpkg::Changelog se pierde durante la fusión. Esto podría incluir comentarios que no deberían estar allí, etc.

INTEGRACIÓN CON GIT

Si deseas utilizar este programa para fusionar archivos de changelog de Debian en un repositorio git, primero debes registrar un nuevo controlador de fusión en .git/config o ~/.gitconfig:

[merge "dpkg-mergechangelogs"]
   name = controlador de fusión de debian/changelog
   driver = dpkg-mergechangelogs -m %O %A %B %A

Luego debes configurar el atributo de fusión para el archivo debian/changelog, ya sea en .gitattributes dentro del propio repositorio, o en .git/info/attributes:

debian/changelog merge=dpkg-mergechangelogs
2025-06-30 1.22.21-dirty
