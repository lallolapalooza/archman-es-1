RANGO

Una selección de rango se describe por una referencia a un hash donde las claves y valores permitidos se describen a

continuación.

Las siguientes opciones toman un número de versión como

valor.
sin
ce
Hace que se use la información del changelog de todas las versiones estrictamente posteriores a version
.
unt
il
Hace que se use la información del changelog de todas las versiones estrictamente anteriores a version
.
fr
om
Similar a "since" pero también incluye la información para la version especificada en sí
misma.
t
o
Similar a "until" pero también incluye la información para la version especifi
cada en s
í misma.

Las siguientes opciones no toman números de versión como

valores:
al
l
Si se establece a un valor verdadero, se devuelven todas las entradas del changelog, esto anula todas las demás
opciones.
cou
nt
Espera un entero con signo como valor. Devuelve "value" entradas desde la parte superior del changelog si se establece a un entero positivo, y abs(value) entradas desde el final si se establece a un entero
negativo.
offs
et
Espera un entero con signo como valor. Cambia el punto de partida para "count", ya sea contado desde la parte superior (entero positivo) o desde el final (entero negativo). "offset" no tiene efecto si "count" tamp
oco fue
dado.
