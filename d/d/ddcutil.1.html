ddcutil(1) Manual de Comandos Generales ddcutil(1)

NOMBRE

ddcutil - Consultar y cambiar la configuración del monitor

SINOPSIS

ddcutil [opciones] comando [argumentos-del-comando] [opciones]

Las opciones se pueden escribir antes o después del comando y sus argumentos.

DESCRIPCIÓN

ddcutil se utiliza para consultar y cambiar la configuración del monitor. La configuración que se puede controlar con ddcutil es, en términos generales, aquella que se puede cambiar usando los botones del monitor y su pantalla en pantalla (OSD). La configuración específica varía de un monitor a otro.

ddcutil se comunica con monitores que implementan el Conjunto de Comandos de Control de Monitor (MCCS) utilizando el protocolo DDC/CI sobre un bus I2C. Normalmente, el controlador de video del monitor expone el bus I2C como dispositivos llamados /dev/i2c-n. Alternativamente, ddcutil puede comunicarse con monitores que utilizan USB para comunicar MMCS, siempre que los monitores cumplan con la Especificación de Clase de Control de Monitor USB.

El Conjunto de Comandos de Control de Monitor describe una colección de características de Panel de Control Virtual (VCP) que un monitor puede implementar. Cada característica se identifica mediante un solo byte. Por ejemplo, la característica x10 es el control de brillo.

Los casos de uso comunes incluyen cambiar el brillo y el color del monitor. Usando scripts, los cambios se pueden realizar mediante pulsaciones de teclas, o en respuesta a la hora del día. Otro caso de uso común es cambiar la fuente de entrada del monitor.

Un caso de uso más complejo para ddcutil es como parte de la gestión del perfil de color. La calibración del monitor es relativa a la configuración actual del monitor, por ejemplo, ganancia roja. ddcutil permite guardar la configuración relacionada con el color en el momento en que se calibra un monitor, y luego restaurarla cuando se aplica la calibración.

Esta página del manual describe los comandos y opciones de ddcutil más importantes para el usuario típico. Para una documentación completa, use la opción --help o consulte el sitio web http://www.ddcutil.com. Si se especifica la opción --verbose junto con --help, se mostrará ayuda más detallada sobre los argumentos de las opciones.

La opción --hh muestra todas las opciones reconocidas por ddcutil. Estas incluyen nombres de opciones obsoletos (que han sido reemplazados por nombres más descriptivos), opciones experimentales y opciones de interés solo para desarrolladores.

RESTRICCIONES

ddcutil no admite monitores de portátiles, que no implementan DDC/CI.

COMANDOS

Comandos Principales

Estos son los comandos de ddcutil más utilizados.

detect
Detecta monitores que tienen un Panel de Control Virtual.
vcpinfo [ codigo-caracteristica | grupo-caracteristicas ]
Describe los códigos de características VCP. según se definen en la especificación MCCS. Utilice la opción --verbose para ver los valores de las características no continuas.
capabilities
Consulta la cadena de capacidades del monitor
getvcp [ codigo-caracteristica | grupo-caracteristicas ] ...
Informa del valor de una característica VCP, o de un grupo de valores de características. Se puede especificar más de un código de característica. Sin embargo, los códigos y grupos de características no se pueden combinar.
setvcp codigo-caracteristica [+|-] nuevo-valor ...
Establece el valor de una característica VCP. Si se especifica + o -, debe estar rodeado de espacios y indica un cambio de valor relativo de una característica VCP continua. Se pueden especificar varios pares característica/valor (con o sin [+|1]).

Comandos Secundarios

Estos comandos abordan situaciones especiales.

dumpvcp nombre-archivo
Guarda los valores de las características VCP relacionadas con el perfil de color en un archivo. Si no se especifica un nombre de archivo, se genera uno y se guarda en $HOME/.local/share/ddcutil,
loadvcp nombre-archivo
Establece los valores de las características VCP desde un archivo. El monitor al que se aplicarán los valores se determina por la identificación del monitor almacenada en el archivo. Si se especifica un monitor en la línea de comandos, debe identificar el mismo monitor que se determinó a partir de los valores del archivo. Si el monitor no está conectado, no ocurre nada.
scs
Emite la solicitud DDC/CI Save Current Settings. La mayoría de los monitores no implementan este comando. Algunos lo requieren para que los valores cambiados por setvcp surtan efecto.
chkusbmon
Prueba si un dispositivo hiddev podría ser un monitor conectado por USB, para su uso en reglas udev.
discard all|capabilities|dsa cache[s]
Descarta archivos cacheados utilizados para la mejora del rendimiento.
traceable-functions
Lista las funciones que se pueden rastrear específicamente usando una opción como --trcfunc o --trcfrom
noop
No ejecuta un comando. Simplemente procesa las opciones.

Comandos de Diagnóstico

Estos comandos diagnostican problemas en la configuración del sistema que afectan la operación de ddcutil, y recopilan información para el diagnóstico remoto de problemas.

environment
Sondea el entorno de instalación de ddcutil.
usbenv
Sondea los aspectos USB del entorno de instalación de ddcutil.
probe
Explora las capacidades y características de un solo monitor.
interrogate
Recopila la máxima información para el diagnóstico de problemas. Incluye la salida de ddcutil environment --verbose para cada monitor detectado, la salida de ddcutil capabilities --verbose y ddcutil probe --verbose.

ARGUMENTOS DE COMANDO

codigo-caracteristica

Un código de característica se especifica por su número de característica hexadecimal de 2 caracteres, con o sin el prefijo "0x", por ejemplo, 0x10, 10

grupo-caracteristicas

Los siguientes son los grupos de características más útiles. Para obtener una lista completa, use la opción --help.

ALL|KNOWN
Todos los códigos de características entendidos por ddcutil
COLOR
Busca códigos de características relacionados con el color
PROFILE
Subconjunto de códigos de características relacionadas con el color que se guardan y restauran mediante dumpvcp y loadvcp
SCAN
Busca todos los códigos de características posibles 0x00..0xff, excepto aquellos que se sabe que son de solo escritura

Los nombres de los grupos de características se pueden abreviar a los 3 primeros caracteres. No se distingue entre mayúsculas y minúsculas. por ejemplo, "COL", "pro".

nuevo-valor

Normalmente, es un número decimal en el rango 0..255, o un número hexadecimal en el rango x00..xff. De forma más general, este es en realidad un valor de dos bytes, es decir, x00..xffff, y algunas características en algunos monitores utilizan este rango extendido.

EJEMPLOS

ddcutil detect
Identificar todos los monitores conectados.

ddcutil getvcp supported

Mostrar todas las configuraciones que el monitor por defecto soporta y que ddcutil entiende.

ddcutil getvcp 10 --display 2
Consultar el valor de luminosidad del segundo monitor.

ddcutil setvcp 10 30 --bus 4

Establecer el valor de luminosidad para el monitor en el bus /dev/i2c-4.

ddcutil vcpinfo --verbose

Mostrar información detallada sobre las características VCP que ddcutil entiende.

ddcutil interrogate > ~/ddcutil.out

Recopilar la máxima información sobre las capacidades del monitor y el entorno de ejecución, y dirigir la salida a un archivo.

DIAGNÓSTICOS

Devuelve 0 en caso de éxito, 1 en caso de fallo.

La solicitud de ayuda se considera un éxito.
