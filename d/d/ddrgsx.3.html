DDRGS

X

Propósito

: 
!>
!> DDRGSX comprueba el controlador experto DGGESX para el problema de
!> valores propios generalizados no simétricos (forma de Schur).
!>
!> DGGESX factoriza A y B como Q S Z' y Q T Z', donde ' significa
!> transpuesta, T es triangular superior, S está en forma de Schur
!> generalizada (triangular por bloques superior, con bloques 1x1 y 2x2
!> en la diagonal, los bloques 2x2 correspondientes a pares de valores
!> propios generalizados complejos conjugados), y Q y Z son
!> ortogonales. También calcula los valores propios generalizados
!> (alpha(1),beta(1)), ..., (alpha(n),beta(n)). Así, w(j) = alpha(j)/beta(j)
!> es una raíz de la ecuación característica
!>
!>     det( A - w(j) B ) = 0
!>
!> Opcionalmente también reordena los valores propios para que un
!> grupo seleccionado de valores propios aparezca en el bloque
!> diagonal principal de las formas de Schur; calcula un número de
!> condición recíproco para el promedio de los valores propios
!> seleccionados; y calcula un número de condición recíproco para los
!> subespacios deflacionantes derecho e izquierdo correspondientes a
!> los valores propios seleccionados.
!>
!> Cuando DDRGSX se llama con NSIZE > 0, se usan cinco (5) tipos de
!> pares de matrices integradas para probar la rutina DGGESX.
!>
!> Cuando DDRGSX se llama con NSIZE = 0, lee datos de matrices de
!> prueba para probar DGGESX.
!>
!> Para cada par de matrices, se realizarán las siguientes pruebas y
!> se compararán con el umbral THRESH excepto para las pruebas (7) y (9):
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A está en forma de Schur (es decir, forma cuasitriangular)
!>
!> (6)   máximo sobre j de D(j)  donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>           y S y T son aquí los bloques diagonales 2 x 2 de S y T
!>           correspondientes a los valores propios j-ésimo y j+1-ésimo.
!>
!> (7)   si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron seleccionados.
!>
!> (8)   el valor estimado DIF no difiere de los valores verdaderos de
!>       Difu y Difl en más de un factor 10*THRESH. Si la estimación DIF
!>       es igual a cero, los valores verdaderos correspondientes de Difu
!>       y Difl deberían ser menores que EPS*norm(A, B). Si el valor
!>       verdadero de Difu y Difl es igual a cero, la estimación DIF
!>       debería ser menor que EPS*norm(A, B).
!>
!> (9)   Si DGGESX devuelve INFO = N+3, la reordenación
!>       y verificamos que DIF = PL = PR = 0 y que el valor verdadero de
!>       Difu y Difl es < EPS*norm(A, B). Contamos los eventos cuando
!>       INFO=N+3.
!>
!> Para las matrices de prueba leídas, se ejecutan las pruebas anteriores
!> excepto que el valor exacto para DIF (y PL) son datos de entrada.
!> Adicionalmente, se ejecuta una prueba más para las matrices de prueba
!> leídas:
!>
!> (10)  el valor estimado PL no difiere del valor verdadero de
!>       PLTRU en más de un factor THRESH. Si la estimación PL es igual
!>       a cero, el valor verdadero correspondiente de PLTRU debería ser
!>       menor que EPS*norm(A, B). Si el valor verdadero de PLTRU es
!>       igual a cero, la estimación PL debería ser menor que
!>       EPS*norm(A, B).
!>
!> Nótese que para las pruebas integradas, se generan y prueban un
!> total de 10*NSIZE*(NSIZE-1) pares de matrices. NSIZE debería
!> mantenerse pequeño.
!>
!> SVD (rutina DGESVD) se usa para calcular el valor verdadero de DIF_u
!> y DIF_l al probar los problemas de prueba integrados.
!>
!> Matrices de Prueba Integradas
!> =============================
!>
!> Todas las matrices de prueba integradas son el bloque 2 por 2 de
!> matrices triangulares
!>
!>          A = [ A11 A12 ]    y      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> donde para diferentes tipos de A11 y A22 se dan como sigue.
!> A12 y B12 se eligen de modo que la ecuación de Sylvester generalizada
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> tenga soluciones prescritas R y L.
!>
!> Tipo 1:  A11 = J_m(1,-1) y A_22 = J_k(1-a,1).
!>          B11 = I_m, B22 = I_k
!>          donde J_k(a,b) es el bloque de Jordan k por k con ``a'' en
!>          la diagonal y ``b'' en la superdiagonal.
!>
!> Tipo 2:  A11 = (a_ij) = ( 2(.5-sin(i)) ) y
!>          B11 = (b_ij) = ( 2(.5-sin(ij)) ) para i=1,...,m, j=i,...,m
!>          A22 = (a_ij) = ( 2(.5-sin(i+j)) ) y
!>          B22 = (b_ij) = ( 2(.5-sin(ij)) ) para i=m+1,...,k, j=i,...,k
!>
!> Tipo 3:  A11, A22 y B11, B22 se eligen como para el Tipo 2, pero
!>          cada segundo bloque diagonal en A_11 y cada tercer bloque
!>          diagonal en A_22 se hacen como bloques 2 por 2.
!>
!> Tipo 4:  A11 = ( 20(.5 - sin(ij)) ) y B22 = ( 2(.5 - sin(i+j)) )
!>             para i=1,...,m,  j=1,...,m y
!>          A22 = ( 20(.5 - sin(i+j)) ) y B22 = ( 2(.5 - sin(ij)) )
!>             para i=m+1,...,k,  j=m+1,...,k
!>
!> Tipo 5:  (A,B) tienen potencialmente valores propios cercanos o comunes y
!>          una gran desviación de la diagonalidad por bloques. A_11 se
!>          elige como la submatriz principal m x m de A_1:
!>                  |  1  b                            |
!>                  | -b  1                            |
!>                  |        1+d  b                    |
!>                  |         -b 1+d                   |
!>           A_1 =  |                  d  1            |
!>                  |                 -1  d            |
!>                  |                        -d  1     |
!>                  |                        -1 -d     |
!>                  |                               1  |
!>          y A_22 se elige como la submatriz principal k x k de A_2:
!>                  | -1  b                            |
!>                  | -b -1                            |
!>                  |       1-d  b                     |
!>                  |       -b  1-d                    |
!>           A_2 =  |                 d 1+b            |
!>                  |               -1-b d             |
!>                  |                       -d  1+b    |
!>                  |                      -1+b  -d    |
!>                  |                              1-d |
!>          y la matriz B se eligen como matrices identidad (ver DLATM5).
!>
!
>

Parámetro

s
NSIZE 
!>          NSIZE es INTEGER
!>          El tamaño máximo de las matrices a utilizar. NSIZE >= 0.
!>          Si NSIZE = 0, no se usan matrices de prueba incorporadas, sino
!>          que se usan matrices de prueba leídas desde un archivo para probar DGGESX.
!
>

NCMA

X 
!>          NCMAX es INTEGER
!>          NMAX máximo permitido para generar la matriz de Kronecker
!>          en la llamada a DLAKF2
!
>

THRES

H 
!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará fallida si , calculado como
!>          se describe anteriormente, supera THRESH.  Tenga en cuenta que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, p. ej., 10 o 100.  En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  THRESH >= 0.
!
>

NI

N 
!>          NIN es INTEGER
!>          El número de unidad FORTRAN para leer el archivo de datos de
!>          problemas a resolver.
!
>

NOU

T 
!>          NOUT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0).
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA, NSIZE)
!>          Se usa para almacenar la matriz cuyos eigenvalores se van a
!>          calcular.  Al salir, A contiene la última matriz realmente usada.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal de A, B, AI, BI, Z y Q,
!>          LDA >= max( 1, NSIZE ). Para la prueba de lectura,
!>          LDA >= max( 1, N ), N es el tamaño de las matrices de prueba.
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDA, NSIZE)
!>          Se usa para almacenar la matriz cuyos eigenvalores se van a
!>          calcular.  Al salir, B contiene la última matriz realmente usada.
!
>

A

I 
!>          AI es un array DOUBLE PRECISION, dimensión (LDA, NSIZE)
!>          Copia de A, modificada por DGGESX.
!
>

B

I 
!>          BI es un array DOUBLE PRECISION, dimensión (LDA, NSIZE)
!>          Copia de B, modificada por DGGESX.
!
>

Z 
!>          Z es un array DOUBLE PRECISION, dimensión (LDA, NSIZE)
!>          Z contiene los vectores de Schur izquierdos calculados por DGGESX.
!
>

Q 
!>          Q es un array DOUBLE PRECISION, dimensión (LDA, NSIZE)
!>          Q contiene los vectores de Schur derechos calculados por DGGESX.
!
>

ALPHA

R 
!>          ALPHAR es un array DOUBLE PRECISION, dimensión (NSIZE)
!
>

ALPHA

I 
!>          ALPHAI es un array DOUBLE PRECISION, dimensión (NSIZE)
!
>

BET

A 
!>          BETA es un array DOUBLE PRECISION, dimensión (NSIZE)
!>
!>          Al salir, (ALPHAR + ALPHAI*i)/BETA son los eigenvalores.
!
>

C 
!>          C es un array DOUBLE PRECISION, dimensión (LDC, LDC)
!>          Almacena la matriz generada por la subrutina DLAKF2, esta es la
!>          matriz formada por productos de Kronecker utilizada para estimar
!>          DIF.
!
>

LD

C 
!>          LDC es INTEGER
!>          La dimensión principal de C. LDC >= max(1, LDA*LDA/2 ).
!
>

S 
!>          S es un array DOUBLE PRECISION, dimensión (LDC)
!>          Valores singulares de C
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= MAX( 5*NSIZE*NSIZE/2 - 2, 10*(NSIZE+1) )
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (LIWORK)
!
>

LIWOR

K 
!>          LIWORK es INTEGER
!>          La dimensión del array IWORK. LIWORK >= NSIZE + 6.
!
>

BWOR

K 
!>          BWORK es un array LOGICAL, dimensión (LDA)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  Una rutina devolvió un código de error.
