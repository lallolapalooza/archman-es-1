DDRGEV3

Propósito:

!>
!> DDRGEV3 comprueba la rutina controladora del problema de eigenvalores
!> generalizados no simétricos DGGEV3.
!>
!> DGGEV3 calcula para un par de matrices no simétricas n-por-n (A,B) los
!> eigenvalores generalizados y, opcionalmente, los eigenvectores izquierdos
!> y derechos.
!>
!> Un eigenvalor generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Generalmente se
!> representa como el par (alpha,beta), ya que hay una interpretación
!> razonable para beta=0, e incluso para ambos siendo cero.
!>
!> Un eigenvector generalizado derecho correspondiente a un eigenvalor
!> generalizado w para un par de matrices (A,B) es un vector r tal que
!> (A - wB) * r = 0. Un eigenvector generalizado izquierdo es un vector l tal
!> que l**H * (A - wB) = 0, donde l**H es el conjugado-transpuesto de l.
!>
!> Cuando se llama a DDRGEV3, se especifica un número de matriz () y un
!> número de matriz . Para cada tamaño () y cada tipo de matriz, se
!> generará un par de matrices (A, B) y se usará para pruebas. Para cada par
!> de matrices, se realizarán las siguientes pruebas y se compararán con el
!> umbral THRESH.
!>
!> Resultados de DGGEV3:
!>
!> (1)  máximo sobre todos los pares eigenvalor/vectores izquierdos (alpha/beta,l) de
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      donde VL**H es el conjugado-transpuesto de VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!> (3)  máximo sobre todos los pares eigenvalor/vectores izquierdos (alpha/beta,r) de
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!> (5)  W(full) = W(partial)
!>      W(full) denota los eigenvalores calculados cuando tanto l como r
!>      también son calculados, y W(partial) denota los eigenvalores
!>      calculados cuando solo W, solo W y r, o solo W y l son
!>      calculados.
!>
!> (6)  VL(full) = VL(partial)
!>      VL(full) denota los eigenvectores izquierdos calculados cuando tanto l
!>      como r son calculados, y VL(partial) denota el resultado
!>      cuando solo l es calculado.
!>
!> (7)  VR(full) = VR(partial)
!>      VR(full) denota los eigenvectores derechos calculados cuando tanto l
!>      como r también son calculados, y VR(partial) denota el resultado
!>      cuando solo l es calculado.
!>
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican por un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los  se especifican por un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una matriz identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una matriz identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad k x k y J un bloque de Jordan
!>                       (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz
!>                       diagonal con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  está cerca del desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas aleatorias O(1) por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de la máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorios.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares superiores
!>                         aleatorias.
!>
!>

Parámetros

NSIZES 
!>          NSIZES es un valor ENTERO
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          DDRGEV3 no hace nada. NSIZES >= 0.
!>

NN

!>          NN es un array ENTERO, de dimensión (NSIZES)
!>          Un array que contiene los tamaños que se usarán para las matrices.
!>          Los valores cero se omitirán. NN >= 0.
!>

NTYPES

!>          NTYPES es un valor ENTERO
!>          El número de elementos en DOTYPE. Si es cero, DDRGEV3
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que consiste en usar la matriz que esté en A. Esto
!>          sólo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LÓGICO, de dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array ENTERO, de dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no lo están, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios utiliza una secuencia
!>          congruencial lineal limitada a enteros pequeños, por lo que
!>          debe producir números aleatorios independientes de la máquina.
!>          Los valores de ISEED se modifican en la salida y pueden usarse en la
!>          siguiente llamada a DDRGEV3 para continuar la misma secuencia de números
!>          aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará exitosa si el error calculado,
!>          tal como se describe arriba, excede THRESH. Nótese que el error se
!>          escala para que sea O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble) o del tamaño
!>          de la matriz. Debe ser al menos cero.
!>

NOUNIT

!>          NOUNIT es un valor ENTERO
!>          El número de unidad de FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve IERR distinto de 0.)
!>

A

!>          A es un array DOUBLE PRECISION,
!>                                       de dimensión(LDA, max(NN))
!>          Se utiliza para almacenar la matriz A original. Se utiliza solo como entrada
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA es un valor ENTERO
!>          La dimensión principal de A, B, S y T.
!>          Debe ser al menos 1 y al menos max( NN ).
!>

B

!>          B es un array DOUBLE PRECISION,
!>                                       de dimensión(LDA, max(NN))
!>          Se utiliza para almacenar la matriz B original. Se utiliza solo como entrada
!>          si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S es un array DOUBLE PRECISION,
!>                                 de dimensión (LDA, max(NN))
!>          La matriz de forma de Schur calculada a partir de A por DGGEV3. En la salida, S
!>          contiene la matriz de forma de Schur correspondiente a la matriz
!>          en A.
!>

T

!>          T es un array DOUBLE PRECISION,
!>                                 de dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de B por DGGEV3.
!>

Q

!>          Q es un array DOUBLE PRECISION,
!>                                 de dimensión (LDQ, max(NN))
!>          La matriz de (vectores propios izquierdos) calculada por DGGEV3.
!>

LDQ

!>          LDQ es un valor ENTERO
!>          La dimensión principal de Q y Z. Debe
!>          ser al menos 1 y al menos max( NN ).
!>

Z

!>          Z es un array DOUBLE PRECISION, de dimensión( LDQ, max(NN) )
!>          La matriz ortogonal (de vectores propios derechos) calculada por DGGEV3.
!>

QE

!>          QE es un array DOUBLE PRECISION, de dimensión( LDQ, max(NN) )
!>          QE contiene los vectores propios derechos o izquierdos calculados.
!>

LDQE

!>          LDQE es un valor ENTERO
!>          La dimensión principal de QE. LDQE >= max(1,max(NN)).
!>

ALPHAR

!>          ALPHAR es un array DOUBLE PRECISION, de dimensión (max(NN))
!>

ALPHAI

!>          ALPHAI es un array DOUBLE PRECISION, de dimensión (max(NN))
!>

BETA

!>          BETA es un array DOUBLE PRECISION, de dimensión (max(NN))
!>
!>          Los valores propios generalizados de (A,B) calculados por DGGEV3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) es el k-ésimo
!>          valor propio generalizado de A y B.
!>

ALPHR1

!>          ALPHR1 es un array DOUBLE PRECISION, de dimensión (max(NN))
!>

ALPHI1

!>          ALPHI1 es un array DOUBLE PRECISION, de dimensión (max(NN))
!>

BETA1

!>          BETA1 es un array DOUBLE PRECISION, de dimensión (max(NN))
!>
!>          Al igual que ALPHAR, ALPHAI, BETA, estos arrays contienen los
!>          valores propios de A y B, pero los calculados cuando DGGEV3 solo
!>          calcula una descomposición eigendecomposición parcial, es decir, no los
!>          valores propios ni los vectores propios izquierdos y derechos.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (LWORK)
!>

LWORK

!>          LWORK es un valor ENTERO
!>          El número de entradas en WORK. LWORK >= MAX( 8*N, N*(N+1) ).
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, de dimensión (2)
!>          Los valores calculados por las pruebas descritas anteriormente.
!>          Actualmente, los valores se limitan a 1/ulp, para evitar desbordamientos.
!>

INFO

!>          INFO es un valor ENTERO
!>          = 0: Salida exitosa
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: Una rutina devolvió un código de error. INFO es el
!>                valor absoluto del valor INFO devuelto.
!>
