DDRVE

S

Propósito

: 
!>
!>    DDRVES verifica el controlador DGEES del problema de valores propios no simétricos (forma de Schur).
!>
!>    Cuando se llama a DDRVES, se especifica un número de tamaños de matriz y un número de tipos de matriz. Para cada tamaño y cada tipo de matriz, se generará una matriz y se usará para probar las rutinas de valores propios no simétricas. Para cada matriz, se realizarán 13 pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenación de valores propios)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de eigenvectores de Schur, y T está en forma de Schur (sin ordenación de valores propios).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenación de valores propios).
!>
!>    (4)     0     si WR+sqrt(-1)*WI son valores propios de T
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (6)     0     si valores propios(con VS) = valores propios(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de eigenvectores de Schur, y T está en forma de Schur (con ordenación de valores propios).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de valores propios).
!>
!>    (10)    0     si WR+sqrt(-1)*WI son valores propios de T
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (12)    0     si valores propios(con VS) = valores propios(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de valores propios que fueron SELECCIONADOS
!>
!>    Los tamaños se especifican mediante un arreglo NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!>    Los tipos se especifican mediante un arreglo lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1's en la diagonal.
!>
!>    (4)  Una matriz diagonal con elementos espaciados uniformemente
!>         1, ..., ULP y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con elementos espaciados geométricamente
!>         1, ..., ULP y signos aleatorios.
!>    (6)  Una matriz diagonal con elementos 1, ULP, ..., ULP
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicada por una constante cerca del umbral de desbordamiento
!>    (8)  Igual que (4), pero multiplicada por una constante cerca del umbral de desbordamiento inferior
!>
!>    (9)  Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene elementos espaciados uniformemente 1, ..., ULP con signos aleatorios en la diagonal y elementos aleatorios O(1) en el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene elementos espaciados geométricamente 1, ..., ULP con signos aleatorios en la diagonal y elementos aleatorios O(1) en el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene elementos 1, ULP,..., ULP con signos aleatorios en la diagonal y elementos aleatorios O(1) en el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene valores propios reales o pares conjugados complejos elegidos aleatoriamente de ( ULP, 1 ) y elementos aleatorios O(1) en el triángulo superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene elementos espaciados uniformemente 1, ..., ULP con signos aleatorios en la diagonal y elementos aleatorios O(1) en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene elementos espaciados geométricamente
!>         1, ..., ULP con signos aleatorios en la diagonal y elementos aleatorios O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene elementos 1, ULP,..., ULP
!>         con signos aleatorios en la diagonal y elementos aleatorios O(1) en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios reales o pares conjugados complejos elegidos aleatoriamente de ( ULP, 1 ) y elementos aleatorios O(1) en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicada por una constante cerca del umbral de desbordamiento
!>    (18) Igual que (16), pero multiplicada por una constante cerca del umbral de desbordamiento inferior
!>
!>    (19) Matriz no simétrica con elementos aleatorios elegidos de (-1,1).
!>         Si N es al menos 4, todos los elementos en las primeras dos filas y la última fila, y la primera columna y las últimas dos columnas son cero.
!>    (20) Igual que (19), pero multiplicada por una constante cerca del umbral de desbordamiento
!>    (21) Igual que (19), pero multiplicada por una constante cerca del umbral de desbordamiento inferior
!
>

Parámetro

s
NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero, DDRVES no hace nada. Debe ser al menos cero.
!
>

N

N 
!>          NN es un arreglo INTEGER, dimensión (NSIZES)
!>          Un arreglo que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser al menos cero.
!
>

NTYPE

S 
!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, DDRVES no hace nada. Debe ser al menos cero. Si es MAXTYP+1 y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1, que es usar cualquier matriz que esté en A. Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), los tipos NTYPES+1 hasta
!>          MAXTYP no serán generados.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!
>

ISEE

D 
!>          ISEED es un arreglo INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no, serán reducidos mód 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican en la salida, y pueden usarse en la
!>          siguiente llamada a DDRVES para continuar la misma secuencia de números
!>          aleatorios.
!
>

THRES

H 
!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará fallida si el , calculado como
!>          se describe anteriormente, supera THRESH.  Nótese que el error
!>          está escalado para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100.  En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  Debe ser al menos cero.
!
>

NOUNI

T 
!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve INFO distinto de 0).
!
>

A 
!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          Usado para contener la matriz cuyos eigenvalores deben ser
!>          calculados.  En la salida, A contiene la última matriz realmente usada.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal de A, y H. LDA debe ser
!>          al menos 1 y al menos max(NN).
!
>

H 
!>          H es un arreglo DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          Otra copia de la matriz de prueba A, modificada por DGEES.
!
>

H

T 
!>          HT es un arreglo DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          Otra copia más de la matriz de prueba A, modificada por DGEES.
!
>

W

R 
!>          WR es un arreglo DOUBLE PRECISION, dimensión (max(NN))
!
>

W

I 
!>          WI es un arreglo DOUBLE PRECISION, dimensión (max(NN))
!>
!>          Las partes real e imaginaria de los eigenvalores de A.
!>          En la salida, WR + WI*i son los eigenvalores de la matriz en A.
!
>

WR

T 
!>          WRT es un arreglo DOUBLE PRECISION, dimensión (max(NN))
!
>

WI

T 
!>          WIT es un arreglo DOUBLE PRECISION, dimensión (max(NN))
!>
!>          Como WR, WI, estos arreglos contienen los eigenvalores de A,
!>          pero aquellos calculados cuando DGEES solo calcula una
!>          descomposición eigenc parcial, es decir, sin vectores de Schur.
!
>

V

S 
!>          VS es un arreglo DOUBLE PRECISION, dimensión (LDVS, max(NN))
!>          VS contiene los vectores de Schur calculados.
!
>

LDV

S 
!>          LDVS es INTEGER
!>          Dimensión principal de VS. Debe ser al menos max(1,max(NN)).
!
>

RESUL

T 
!>          RESULT es un arreglo DOUBLE PRECISION, dimensión (13)
!>          Los valores calculados por las 13 pruebas descritas anteriormente.
!>          Los valores están actualmente limitados a 1/ulp, para evitar desbordamiento.
!
>

WOR

K 
!>          WORK es un arreglo DOUBLE PRECISION, dimensión (NWORK)
!
>

NWOR

K 
!>          NWORK es INTEGER
!>          El número de entradas en WORK.  Este debe ser al menos
!>          5*NN(j)+2*NN(j)**2 para todos los j.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (max(NN))
!
>

BWOR

K 
!>          BWORK es un arreglo LOGICAL, dimensión (max(NN))
!
>

INF

O 
!>          INFO es INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algunos NN(j) < 0
!>           -3: NTYPES < 0
!>           -6: THRESH < 0
!>           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>          -17: LDVS < 1 o LDVS < NMAX, donde NMAX es max( NN(j) ).
!>          -20: NWORK demasiado pequeño.
!>          Si  DLATMR, SLATMS, SLATME o DGEES devuelve un código de error,
!>              se devuelve el valor absoluto del mismo.
!>
!>-----------------------------------------------------------------------
!>
!>     Algunas Variables y Parámetros Locales:
!>     ---- ----- --------- --- ----------
!>
!>     ZERO, ONE       Real 0 y 1.
!>     MAXTYP          El número de tipos definidos.
!>     NMAX            El valor más grande en NN.
!>     NERRS           El número de pruebas que han excedido THRESH
!>     COND, CONDS,
!>     IMODE           Valores a pasar a los generadores de matrices.
!>     ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>     OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>     ULP, ULPINV     Precisión relativa más fina y su inversa.
!>     RTULP, RTULPI   Raíces cuadradas de los 4 valores anteriores.
!>
!>             Los siguientes cuatro arreglos decodifican JTYPE:
!>     KTYPE(j)        El tipo general (1-10) para el tipo .
!>     KMODE(j)        El valor MODE a pasar al generador de
!>                     matrices para el tipo .
!>     KMAGN(j)        El orden de magnitud ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!>     KCONDS(j)       Selecciona si CONDS debe ser 1 o
!>                     1/sqrt(ulp).  (0 significa irrelevante.)
!
>
