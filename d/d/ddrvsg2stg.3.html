subroutine ddrvsg2stg (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) d, double precision, dimension( * ) d2, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( lda, * ) ab, double precision, dimension( ldb, * ) bb, double precision, dimension( * ) ap, double precision, dimension( * ) bp, double precision, dimension( * ) work, integer nwork, integer, dimension( * ) iwork, integer liwork, double precision, dimension( * ) result, integer info)

DDRVSG2STG

Propósito:

!>
!>      DDRVSG2STG verifica los drivers del problema general de autovalores
!>      simétricos reales.
!>
!>              DSYGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real.
!>
!>              DSYGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real usando un algoritmo de divide y vencerás.
!>
!>              DSYGVX calcula autovalores seleccionados y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real.
!>
!>              DSPGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real en almacenamiento empaquetado.
!>
!>              DSPGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real en almacenamiento empaquetado usando
!>              un algoritmo de divide y vencerás.
!>
!>              DSPGVX calcula autovalores seleccionados y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real en almacenamiento empaquetado.
!>
!>              DSBGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real por bandas.
!>
!>              DSBGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real por bandas usando un algoritmo de
!>              divide y vencerás.
!>
!>              DSBGVX calcula autovalores seleccionados y, opcionalmente,
!>              los autovectores de un problema general de autovalores
!>              simétrico-definido real por bandas.
!>
!>      Cuando se llama a DDRVSG2STG, se especifica un número de tamaños de
!>      matrices () y un número de tipos de matrices. Para cada tamaño ()
!>      y cada tipo de matriz, se generará una matriz A del tipo dado;
!>      también se generará una matriz B aleatoria bien condicionada y el par
!>      (A,B) se utilizará para probar los drivers.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) DSYGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>              | D - D2 | / ( |D| ulp )   donde D es calculado por
!>                                         DSYGV y  D2 es calculado por
!>                                         DSYGV_2STAGE. Esta prueba
!>                                         solo se realiza para DSYGV
!>
!>      (2) igual que (1) pero llamando a DSPGV
!>      (3) igual que (1) pero llamando a DSBGV
!>      (4) igual que (1) pero con UPLO = 'L'
!>      (5) igual que (4) pero llamando a DSPGV
!>      (6) igual que (4) pero llamando a DSBGV
!>
!>      (7) DSYGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) igual que (7) pero llamando a DSPGV
!>      (9) igual que (7) pero con UPLO = 'L'
!>      (10) igual que (9) pero llamando a DSPGV
!>
!>      (11) DSYGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) igual que (11) pero llamando a DSPGV
!>      (13) igual que (11) pero con UPLO = 'L'
!>      (14) igual que (13) pero llamando a DSPGV
!>
!>      DSYGVD, DSPGVD y DSBGVD realizaron las mismas 14 pruebas.
!>
!>      DSYGVX, DSPGVX y DSBGVX realizaron las pruebas anteriores de 14 con
!>      los parámetros RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los tamaños se especifican mediante un array NN(1:NSIZES); el valor
!>      de cada elemento NN(j) especifica un tamaño.
!>      Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., se generará el tipo de matriz j.
!>      Este tipo se utiliza para la matriz A que tiene un semi-ancho de banda KA.
!>      B se genera como una matriz positiva definida bien condicionada
!>      con semi-ancho de banda KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1) La matriz cero.
!>      (2) La matriz identidad.
!>
!>      (3) Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4) Una matriz diagonal con entradas espaciadas geométricamente
!>           1, ..., ULP y signos aleatorios.
!>      (5) Una matriz diagonal con  entradas
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6) Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7) Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8) Una matriz de la forma  U* D U, donde U es ortogonal y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (9) Una matriz de la forma  U* D U, donde U es ortogonal y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma  U* D U, donde U es ortogonal y
!>           D tiene  entradas 1, ULP,..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          DDRVSG2STG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>
El número de elementos en DOTYPE. Si es cero, DDRVSG2STG !> no hace nada. Debe ser al menos cero. Si es MAXTYP+1 !> y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1, !> el cual debe usar cualquier matriz que esté en A. Esto !> solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y !> DOTYPE(MAXTYP+1) es .TRUE. . !> No modificado. !> !> DOTYPE Arreglo LOGICAL, dimensión (NTYPES) !> Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se !> generará una matriz de ese tamaño y de tipo j. !> Si NTYPES es menor que el número máximo de tipos !> definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 hasta !> MAXTYP no serán generados. Si NTYPES es mayor !> que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES) !> serán ignorados. !> No modificado. !> !> ISEED Arreglo INTEGER, dimensión (4) !> En la entrada ISEED especifica la semilla del generador de !> números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095; !> si no lo están, serán reducidos módulo 4096. Además, ISEED(4) debe !> ser impar. El generador de números aleatorios usa una secuencia !> congruencial lineal limitada a enteros pequeños, y por lo tanto !> debería producir números aleatorios independientes de la máquina. Los !> valores de ISEED son modificados en la salida, y pueden usarse en la !> siguiente llamada a DDRVSG2STG para continuar la misma secuencia de !> números aleatorios. !> Modificado. !> !> THRESH DOUBLE PRECISION !> Una prueba se contará como fallida si el error, calculado como !> se describe arriba, excede THRESH. Note que el error !> está escalado para ser O(1), por lo que THRESH debería ser un múltiplo !> razonablemente pequeño de 1, p. ej., 10 o 100. En particular, !> no debería depender de la precisión (simple vs. doble) !> ni del tamaño de la matriz. Debe ser al menos cero. !> No modificado. !> !> NOUNIT INTEGER !> El número de unidad FORTRAN para imprimir mensajes de error !> (p. ej., si una rutina devuelve IINFO distinto de 0.) !> No modificado. !> !> A Arreglo DOUBLE PRECISION, dimensión (LDA , max(NN)) !> Usado para contener la matriz cuyos eigenvalores deben ser !> calculados. En la salida, A contiene la última matriz realmente !> usada. !> Modificado. !> !> LDA INTEGER !> La dimensión principal de A y AB. Debe ser al !> menos 1 y al menos max( NN ). !> No modificado. !> !> B Arreglo DOUBLE PRECISION, dimensión (LDB , max(NN)) !> Usado para contener la matriz simétrica definida positiva para !> el problema generalizado. !> En la salida, B contiene la última matriz realmente !> usada. !> Modificado. !> !> LDB INTEGER !> La dimensión principal de B y BB. Debe ser al !> menos 1 y al menos max( NN ). !> No modificado. !> !> D Arreglo DOUBLE PRECISION, dimensión (max(NN)) !> Los eigenvalores de A. En la salida, los eigenvalores en D !> corresponden con la matriz en A. !> Modificado. !> !> Z Arreglo DOUBLE PRECISION, dimensión (LDZ, max(NN)) !> La matriz de autovectores. !> Modificado. !> !> LDZ INTEGER !> La dimensión principal de Z. Debe ser al menos 1 y !> al menos max( NN ). !> No modificado. !> !> AB Arreglo DOUBLE PRECISION, dimensión (LDA, max(NN)) !> Espacio de trabajo. !> Modificado. !> !> BB Arreglo DOUBLE PRECISION, dimensión (LDB, max(NN)) !> Espacio de trabajo. !> Modificado. !> !> AP Arreglo DOUBLE PRECISION, dimensión (max(NN)**2) !> Espacio de trabajo. !> Modificado. !> !> BP Arreglo DOUBLE PRECISION, dimensión (max(NN)**2) !> Espacio de trabajo. !> Modificado. !> !> WORK Arreglo DOUBLE PRECISION, dimensión (NWORK) !> Espacio de trabajo. !> Modificado. !> !> NWORK INTEGER !> El número de entradas en WORK. Debe ser al menos !> 1+5*N+2*N*lg(N)+3*N**2 donde N = max( NN(j) ) y !> lg( N ) = entero más pequeño k tal que 2**k >= N. !> No modificado. !> !> IWORK Arreglo INTEGER, dimensión (LIWORK) !> Espacio de trabajo. !> Modificado. !> !> LIWORK INTEGER !> El número de entradas en WORK. Debe ser al menos 6*N. !> No modificado. !> !> RESULT Arreglo DOUBLE PRECISION, dimensión (70) !> Los valores calculados por las 70 pruebas descritas arriba. !> Modificado. !> !> INFO INTEGER !> Si 0, entonces todo se ejecutó correctamente. !> -1: NSIZES < 0 !> -2: Alguno de los NN(j) < 0 !> -3: NTYPES < 0 !> -5: THRESH < 0 !> -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ). !> -16: LDZ < 1 o LDZ < NMAX. !> -21: NWORK demasiado pequeño. !> -23: LIWORK demasiado pequeño. !> Si DLATMR, SLATMS, DSYGV, DSPGV, DSBGV, SSYGVD, SSPGVD, !> DSBGVD, DSYGVX, DSPGVX o SSBGVX devuelve un código de error, !> se devuelve su valor absoluto. !> Modificado. !> !> ---------------------------------------------------------------------- !> !> Algunas Variables y Parámetros Locales: !> ---- ----- --------- --- ---------- !> ZERO, ONE Real 0 y 1. !> MAXTYP El número de tipos definidos. !> NTEST El número de pruebas que se han ejecutado !> en esta matriz. !> NTESTT El número total de pruebas para esta llamada. !> NMAX El valor más grande en NN. !> NMATS El número de matrices generadas hasta ahora. !> NERRS El número de pruebas que han excedido THRESH !> hasta ahora (calculado por DLAFTS). !> COND, IMODE Valores a ser pasados a los generadores de matrices. !> ANORM Norma de A; pasada a los generadores de matrices. !> !> OVFL, UNFL Umbrales de desbordamiento y subdesbordamiento. !> ULP, ULPINV Precisión relativa más fina y su inversa. !> RTOVFL, RTUNFL Raíces cuadradas de los 2 valores anteriores. !> Los siguientes cuatro arreglos decodifican JTYPE: !> KTYPE(j) El tipo general (1-10) para el tipo . !> KMODE(j) El valor MODE a ser pasado al generador de !> matrices para el tipo . !> KMAGN(j) El orden de magnitud ( O(1), !> O(overflow^(1/2) ), O(underflow^(1/2) ) !>
