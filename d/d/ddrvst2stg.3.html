DDRVST2STG

Propósito:

!>
!>      DDRVST2STG  comprueba los drivers del problema de valores propios simétricos.
!>
!>              DSTEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica tridiagonal real.
!>
!>              DSTEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz simétrica tridiagonal real.
!>
!>              DSTEVR calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz simétrica tridiagonal real
!>              utilizando la Representación Robusta Relativa donde sea posible.
!>
!>              DSYEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real.
!>
!>              DSYEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real.
!>
!>              DSYEVR calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real
!>              utilizando la Representación Robusta Relativa donde sea posible.
!>
!>              DSPEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado.
!>
!>              DSPEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado.
!>
!>              DSBEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real.
!>
!>              DSBEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real.
!>
!>              DSYEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real utilizando
!>              un algoritmo de división y conquista.
!>
!>              DSPEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado, utilizando un algoritmo de división y conquista.
!>
!>              DSBEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real,
!>              utilizando un algoritmo de división y conquista.
!>
!>      Cuando se llama a DDRVST2STG, se especifica un número de tamaños de matriz () y un
!>      número de tipos de matriz. Para cada tamaño ()
!>      y cada tipo de matriz, se generará una matriz y se utilizará
!>      para probar las rutinas driver apropiadas. Para cada matriz y cada
!>      rutina driver llamada, se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de vectores propios devuelta cuando se da la opción
!>      de vector propio, y D1 y D2 son los valores propios
!>      devueltos con y sin la opción de vector propio.
!>
!>      Los tamaños () se especifican mediante una matriz NN(1:NSIZES); el valor
!>      de cada elemento NN(j) especifica un tamaño.
!>      Los tipos de matriz se especifican mediante una matriz lógica DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .VERDADERO., se generará el tipo de matriz j.
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con valores propios espaciados uniformemente
!>           1, ..., ULP  y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con valores propios espaciados geométricamente
!>           1, ..., ULP  y signos aleatorios.
!>      (5)  Una matriz diagonal con  valores propios
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9)  Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (10) Una matriz de la forma  U' D U, donde U es ortogonal y
!>           D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>      (16) Una matriz de banda con semi-ancho de banda elegido aleatoriamente entre
!>           0 y N-1, con valores propios espaciados uniformemente 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          DDRVST2STG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Una matriz que contiene los tamaños a utilizar para las matrices.
!>          Se omitirán los valores cero. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, DDRVST2STG
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar la matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSO. y
!>          DOTYPE(MAXTYP+1) es .VERDADERO. .
!>          No modificado.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Un array lógico que especifica qué tipos de matrices generar.
!>          No modificado.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          El generador de números aleatorios está inicializado con
!>          ISEED(1:4).  No modificado.
!>
!>  THRESH  DOUBLE PRECISION
!>          Umbral de puntos flotantes para la máquina.  Se utiliza para
!>          determinar el valor de ULP.  No modificado.
!>
!>  NOUNIT  INTEGER
!>          Indica si se deben devolver las matrices unitarias.
!>          = 0: devuelve la matriz unitaria U' que transforma la matriz A en diagonal.
!>          /= 0: no devuelve la matriz unitaria.
!>          No modificado.
!>
!>  A       DOUBLE PRECISION array, dimension (LDA, *)
!>          La matriz de entrada.
!>
!>  LDA     INTEGER
!>          El tamaño de la primera dimensión de A.
!>
!>  D1      DOUBLE PRECISION array, dimension (*)
!>          Valores propios devueltos por los drivers.
!>
!>  D2      DOUBLE PRECISION array, dimension (*)
!>          Valores propios devueltos por los drivers.
!>
!>  D3      DOUBLE PRECISION array, dimension (*)
!>          Valores propios devueltos por los drivers.
!>
!>  D4      DOUBLE PRECISION array, dimension (*)
!>          Valores propios devueltos por los drivers.
!>
!>  EVEIGS  DOUBLE PRECISION array, dimension (*)
!>          Valores propios devueltos por los drivers.
!>
!>  WA1     DOUBLE PRECISION array, dimension (*)
!>          Espacio de trabajo.
!>
!>  WA2     DOUBLE PRECISION array, dimension (*)
!>          Espacio de trabajo.
!>
!>  WA3     DOUBLE PRECISION array, dimension (*)
!>          Espacio de trabajo.
!>
!>  U       DOUBLE PRECISION array, dimension (LDU, *)
!>          Matriz unitaria devuelta por los drivers.
!>
!>  LDU     INTEGER
!>          El tamaño de la primera dimensión de U.
!>
!>  V       DOUBLE PRECISION array, dimension (LDU, *)
!>          Matriz unitaria devuelta por los drivers.
!>
!>  TAU     DOUBLE PRECISION array, dimension (*)
!>          Valores de reflexión devueltos por los drivers.
!>
!>  Z       DOUBLE PRECISION array, dimension (LDU, *)
!>          Matriz unitaria devuelta por los drivers.
!>
!>  WORK    DOUBLE PRECISION array, dimension (*)
!>          Espacio de trabajo.
!>
!>  LWORK   INTEGER
!>          El tamaño del array WORK.
!>
!>  IWORK   INTEGER array, dimension (*)
!>          Espacio de trabajo para enteros.
!>
!>  LIWORK  INTEGER
!>          El tamaño del array IWORK.
!>
!>  RESULT  DOUBLE PRECISION array, dimension (16)
!>          Los errores de salida relativos.
!>
!>  INFO    INTEGER
!>          = 0:  satisfactorio.
!>          < 0:  si el i-ésimo argumento tenía un valor de entrada ilegal.
!>                En particular, llamamos a las rutinas de LAPACK
!>                y devolvemos el valor de INFO de esas llamadas.
!>
!>
!>-----------------------------------------------------------------------------
!>
!>      Esta subrutina llama a las siguientes rutinas de LAPACK:
!>
!>      DSTEV, DSTEVX, DSTEVR, DSYEV, DSYEVX, DSYEVR, DSPEV, DSPEVX,
!>      DSBEV, DSBEVX, DSYEVD, DSPEVD, DSBEVD.
!>
!>      Para cada una de estas rutinas, se realizan las siguientes pruebas:
!>
!>      1. Se comprueba la precisión de los valores propios y los vectores propios.
!>         | A - V D V' | / ( |A| * n * ulp )
!>
!>      2. Se comprueba la ortogonalidad de los vectores propios.
!>         | I - V V' | / ( n * ulp )
!>
!>      3. Se comprueba la consistencia de los valores propios devueltos
!>         por las diferentes rutinas.
!>         | D1 - D2 | / ( |D1| * ulp )
!>
!>      Aquí, D es la matriz diagonal de valores propios y V es la matriz
!>      de vectores propios.
!>
!>      El valor de ULP se determina utilizando la rutina de utilidad ML_ULPS.
!>      El valor de n se toma del tamaño de la matriz.
!>
!>      Se generan diferentes tipos de matrices (cero, identidad, diagonal
!>      con espaciado uniforme/geométrico, aleatorias, banda) para probar
!>      las rutinas en diferentes condiciones.
!>
!>      Los parámetros THRESH, NN, DOTYPE, ISEED, NOUNIT se utilizan para
!>      controlar la generación de matrices y la ejecución de las pruebas.
!>      Los arrays WORK, LWORK, IWORK, LIWORK se utilizan para el espacio
!>      de trabajo de las rutinas de LAPACK.
!>      El array RESULT almacena los errores relativos calculados para cada prueba.
!>      El parámetro INFO indica el estado de la ejecución.
!>
