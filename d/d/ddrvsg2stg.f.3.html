DDRVSG2STG

Propósito:

!>
!>      DDRVSG2STG verifica los controladores del problema de autovalores generalizado simétrico real.
!>
!>              DSYGV calcula todos los autovalores y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real.
!>
!>              DSYGVD calcula todos los autovalores y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real utilizando un algoritmo
!>              de dividir y conquistar.
!>
!>              DSYGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real.
!>
!>              DSPGV calcula todos los autovalores y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real en almacenamiento empaquetado.
!>
!>              DSPGVD calcula todos los autovalores y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real en almacenamiento empaquetado
!>              utilizando un algoritmo de dividir y conquistar.
!>
!>              DSPGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real en almacenamiento empaquetado.
!>
!>              DSBGV calcula todos los autovalores y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real en banda.
!>
!>              DSBGVD calcula todos los autovalores y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real en banda utilizando un
!>              algoritmo de dividir y conquistar.
!>
!>              DSBGVX calcula autovalores seleccionados y, opcionalmente,
!>              autovectores de un problema de autovalores generalizado
!>              simétrico-definido positivo real en banda.
!>
!>      Cuando se llama a DDRVSG2STG, se especifica un número de tamaños de matriz  () y un
!>      número de tipos de matriz . Para cada tamaño ()
!>      y cada tipo de matriz, se generará una matriz A del tipo dado;
!>      también se genera una matriz B aleatoria bien condicionada
!>      y el par (A,B) se utiliza para probar los controladores.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) DSYGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>              | D - D2 | / ( |D| ulp )   donde D es calculado por
!>                                         DSYGV y  D2 es calculado por
!>                                         DSYGV_2STAGE. Esta prueba
!>                                         solo se realiza para DSYGV
!>
!>      (2) como (1) pero llamando a DSPGV
!>      (3) como (1) pero llamando a DSBGV
!>      (4) como (1) pero con UPLO = 'L'
!>      (5) como (4) pero llamando a DSPGV
!>      (6) como (4) pero llamando a DSBGV
!>
!>      (7) DSYGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) como (7) pero llamando a DSPGV
!>      (9) como (7) pero con UPLO = 'L'
!>      (10) como (9) pero llamando a DSPGV
!>
!>      (11) DSYGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) como (11) pero llamando a DSPGV
!>      (13) como (11) pero con UPLO = 'L'
!>      (14) como (13) pero llamando a DSPGV
!>
!>      DSYGVD, DSPGVD y DSBGVD realizan las mismas 14 pruebas.
!>
!>      DSYGVX, DSPGVX y DSBGVX realizan las 14 pruebas anteriores con
!>      el parámetro RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los  se especifican mediante un arreglo NN(1:NSIZES); el valor
!>      de cada elemento NN(j) especifica un tamaño.
!>      Los  se especifican mediante un arreglo lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>      Este tipo se utiliza para la matriz A que tiene semianchura KA.
!>      B se genera como una matriz definida positiva bien condicionada
!>      con semianchura KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con elementos equiespaciados
!>           1, ..., ULP  y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con elementos geométricamente espaciados
!>           1, ..., ULP  y signos aleatorios.
!>      (5)  Una matriz diagonal con  elementos
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento por defecto )
!>
!>      (8)  Una matriz de la forma  U* D U, donde U es ortogonal y
!>           D tiene elementos equiespaciados 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9)  Una matriz de la forma  U* D U, donde U es ortogonal y
!>           D tiene elementos geométricamente espaciados 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma  U* D U, donde U es ortogonal y
!>           D tiene  elementos 1, ULP,..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento por defecto )
!>
!>      (13) matriz simétrica con elementos aleatorios elegidos de (-1,1).
!>      (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento por defecto)
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          DDRVSG2STG no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un arreglo que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE.   Si es cero, DDRVSG2STG
!>          no hace nada.  Debe ser al menos cero.  Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que debe usar la matriz que haya en A.  Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  Arreglo LÓGICO, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>          No modificado.
!>
!>  ISEED   Arreglo ENTERO, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se cambian en la salida, y pueden usarse en la
!>          siguiente llamada a DDRVSG2STG para continuar la misma secuencia de números aleatorios.
!>          Modificado.
!>
!>  THRESH  DOBLE PRECISIÓN
!>          Una prueba se considerará fallida si el , calculado como
!>          se describe arriba, excede THRESH.  Nótese que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, p. ej., 10 o 100.  En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  Debe ser al menos cero.
!>          No modificado.
!>
!>  NOUNIT  ENTERO
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!>          No modificado.
!>
!>  A       Arreglo DOBLE PRECISIÓN, dimensión (LDA , max(NN))
!>          Usado para contener la matriz cuyos eigenvalores deben ser
!>          calculados.  En la salida, A contiene la última matriz realmente
!>          usada.
!>          Modificado.
!>
!>  LDA     ENTERO
!>          La dimensión principal de A y AB.  Debe ser al
!>          menos 1 y al menos max( NN ).
!>          No modificado.
!>
!>  B       Arreglo DOBLE PRECISIÓN, dimensión (LDB , max(NN))
!>          Usado para contener la matriz simétrica definida positiva para
!>          el problema generalizado.
!>          En la salida, B contiene la última matriz realmente
!>          usada.
!>          Modificado.
!>
!>  LDB     ENTERO
!>          La dimensión principal de B y BB.  Debe ser al
!>          menos 1 y al menos max( NN ).
!>          No modificado.
!>
!>  D       Arreglo DOBLE PRECISIÓN, dimensión (max(NN))
!>          Los eigenvalores de A. En la salida, los eigenvalores en D
!>          corresponden con la matriz en A.
!>          Modificado.
!>
!>  Z       Arreglo DOBLE PRECISIÓN, dimensión (LDZ, max(NN))
!>          La matriz de autovectores.
!>          Modificado.
!>
!>  LDZ     ENTERO
!>          La dimensión principal de Z.  Debe ser al menos 1 y
!>          al menos max( NN ).
!>          No modificado.
!>
!>  AB      Arreglo DOBLE PRECISIÓN, dimensión (LDA, max(NN))
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  BB      Arreglo DOBLE PRECISIÓN, dimensión (LDB, max(NN))
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  AP      Arreglo DOBLE PRECISIÓN, dimensión (max(NN)**2)
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  BP      Arreglo DOBLE PRECISIÓN, dimensión (max(NN)**2)
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  WORK    Arreglo DOBLE PRECISIÓN, dimensión (NWORK)
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  NWORK   ENTERO
!>          El número de entradas en WORK.  Este debe ser al menos
!>          1+5*N+2*N*lg(N)+3*N**2 donde N = max( NN(j) ) y
!>          lg( N ) = entero más pequeño k tal que 2**k >= N.
!>          No modificado.
!>
!>  IWORK   Arreglo ENTERO, dimensión (LIWORK)
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  LIWORK  ENTERO
!>          El número de entradas en WORK.  Este debe ser al menos 6*N.
!>          No modificado.
!>
!>  RESULT  Arreglo DOBLE PRECISIÓN, dimensión (70)
!>          Los valores calculados por las 70 pruebas descritas arriba.
!>          Modificado.
!>
!>  INFO    ENTERO
!>          Si 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algunos NN(j) < 0
!>           -3: NTYPES < 0
!>           -5: THRESH < 0
!>           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>          -16: LDZ < 1 o LDZ < NMAX.
!>          -21: NWORK demasiado pequeño.
!>          -23: LIWORK demasiado pequeño.
!>          Si  DLATMR, SLATMS, DSYGV, DSPGV, DSBGV, SSYGVD, SSPGVD,
!>              DSBGVD, DSYGVX, DSPGVX o SSBGVX devuelve un código de error,
!>              se devuelve el valor absoluto del mismo.
!>          Modificado.
!>
!> ---------------------------------------------------------------------
!>
!>       Algunas Variables y Parámetros Locales:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 y 1.
!>       MAXTYP          El número de tipos definidos.
!>       NTEST           El número de pruebas que se han ejecutado
!>                       en esta matriz.
!>       NTESTT          El número total de pruebas para esta llamada.
!>       NMAX            El valor más grande en NN.
!>       NMATS           El número de matrices generadas hasta ahora.
!>       NERRS           El número de pruebas que han excedido THRESH
!>                       hasta ahora (calculado por DLAFTS).
!>       COND, IMODE     Valores a pasar a los generadores de matrices.
!>       ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>       OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>       ULP, ULPINV     Precisión relativa más fina y su inversa.
!>       RTOVFL, RTUNFL  Raíces cuadradas de los 2 valores anteriores.
!>               Los siguientes cuatro arreglos decodifican JTYPE:
!>       KTYPE(j)        El tipo general (1-10) para el tipo .
!>       KMODE(j)        El valor MODE a pasar al generador de
!>                       matrices para el tipo .
!>       KMAGN(j)        El orden de magnitud ( O(1),
!>                       O(desbordamiento^(1/2) ), O(subdesbordamiento^(1/2) )
!>
