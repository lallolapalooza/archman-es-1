NOMBRE

ddbugtopbm - convertir bocetos de Diddle o DiddleBug a archivos PBM

SINOPSIS

ddbugtopbm

EJEMPLOS

ddbugtopbm </ruta/al/directorio/de/copia/de/seguridad/palm/DiddleBugDB.pdb
ddbugtopbm </ruta/al/directorio/de/copia/de/seguridad/palm/DiddleDB.pdb
ddbugtopbm </ruta/al/directorio/de/copia/de/seguridad/palm/DiddleIDB.pdb

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

ddbugtopbm convierte todos los bocetos presentes en una base de datos utilizada por los programas de PalmOS Diddle o DiddleBug a archivos PBM con nombres apropiados. La copia de seguridad de la base de datos de DiddleBug que debes usar como entrada para este programa generalmente se llama DiddleBugDB.pdb. O si usas el Diddle original, tiene dos bases de datos separadas: DiddleDB.pdb, que contiene bocetos "de borrador" sin nombre, y DiddleIDB.pdb, que contiene los bocetos guardados (y con nombre) que se listan en su opción `index'. Puedes pasarle a este programa cualquiera de estos tres por la entrada estándar.

USO DEL PROGRAMA

Recomiendo que *no* ejecutes ddbugtopbm desde tu directorio de copia de seguridad de Palm, es decir, no lo ejecutes desde el directorio donde la base de datos estará normalmente. En su lugar, ejecútalo desde algún otro directorio (quizás podrías crear un directorio solo para guardar los archivos PBM, para mantener las cosas simples) y usa una ruta absoluta o relativa a la base de datos.

Los nombres de archivo utilizados para los PBM de salida se basan en los nombres dados a cada boceto; si tienes un boceto sin nombre, se le da un nombre parecido a sketch-0123.pbm.

Mientras que los bocetos con nombre sobrescribirán cualquier archivo PBM existente con el mismo nombre, los sin nombre no lo harán; simplemente intentarán usar otro nombre de archivo. (Creo que este es probablemente el enfoque correcto, ya que en realidad no puedes distinguir los bocetos sin nombre.)

LIMITACIONES

El lector de la base de datos DiddleBug solo se sabe que funciona con bases de datos de la versión 2.50 de DiddleBug. Pero probablemente debería funcionar en versiones posteriores, y creo que también funcionará en bases de datos de la versión 2.15.

Podría fallar si se le alimenta con una base de datos vacía y no realiza mucha (si es que alguna) verificación de la entrada.
