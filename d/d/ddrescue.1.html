DDRESCUE(1) Comandos de usuario DDRESCUE(1)

NOMBRE

ddrescue - herramienta de recuperación de datos

SINOPSIS

ddrescue [opciones] archivo_entrada archivo_salida [archivo_mapa]

DESCRIPCIÓN

GNU ddrescue es una herramienta de recuperación de datos. Copia datos de un archivo o dispositivo de bloques (disco duro, cdrom, etc.) a otro, intentando rescatar primero las partes buenas en caso de errores de lectura.

Utilice siempre un archivo de mapa, a menos que sepa que no lo necesitará. Sin un archivo de mapa, ddrescue no puede reanudar un rescate, solo iniciarlo de nuevo. Tenga cuidado de no especificar por error un archivo de mapa antiguo de un rescate no relacionado.

NOTA: En versiones de ddrescue anteriores a la 1.20, el archivo de mapa se llamaba 'logfile'. El formato es el mismo; solo ha cambiado el nombre.

Si reinicia, verifique los nombres de los dispositivos antes de reiniciar ddrescue. No use las opciones '-F' o '-G' sin leer el manual primero.

OPCIONES

-h, --help
muestra esta ayuda y sale
-V, --version
muestra información de la versión y sale
-a, --min-read-rate=<bytes>
tasa mínima de lectura de áreas buenas en bytes/s
-A, --try-again
marca como no intentados los bloques no recortados, no raspados
-b, --sector-size=<bytes>
tamaño del sector del dispositivo de entrada [por defecto 512]
-B, --binary-prefixes
muestra multiplicadores binarios en números [SI]
-c, --cluster-size=<sectores>
sectores a copiar a la vez [128]
-C, --complete-only
no lee datos nuevos más allá de los límites del archivo de mapa
-d, --idirect
usa acceso directo al disco para el archivo de entrada
-D, --odirect
usa acceso directo al disco para el archivo de salida
-e, --max-bad-areas=[+]<n>
número máximo de áreas [nuevas] defectuosas permitidas
-E, --max-error-rate=<bytes>
tasa máxima permitida de errores de lectura por segundo
-f, --force
sobrescribe el dispositivo o partición de salida
-F, --fill-mode=<tipos>
rellena bloques de los tipos dados con datos (?*/-+l)
-G, --generate-mode
genera un archivo de mapa aproximado a partir de una copia parcial
-H, --test-mode=<archivo>
establece el mapa de bloques buenos/defectuosos a partir del archivo de mapa dado
-i, --input-position=<bytes>
posición de inicio del dominio en el archivo de entrada [0]
-I, --check-input-size
compara el tamaño del archivo de entrada con el tamaño en el archivo de mapa
-J, --check-on-error
vuelve a leer el último sector bueno después de cada error
-K, --skip-size=[<i>][,<max>]
tamaño inicial, máximo para omitir en caso de error de lectura
-L, --loose-domain
acepta un archivo de mapa de dominio desordenado con huecos
-m, --domain-mapfile=<archivo>
restringe el dominio a bloques terminados en el <archivo>
-M, --retrim
marca todos los bloques fallidos como no recortados
-n, --no-scrape
omite la fase de raspado
-N, --no-trim
omite la fase de recorte
-o, --output-position=<bytes>
posición de inicio en el archivo de salida [ipos]
-O, --reopen-on-error
reabre el archivo de entrada después de cada error de lectura
-p, --preallocate
preasigna espacio en el disco para el archivo de salida
-P, --data-preview[=<lineas>]
muestra algunas líneas de los últimos datos leídos [3]
-q, --quiet
suprime todos los mensajes
-r, --retry-passes=<n>
sale después de <n> pasadas de reintento (-1=infinito) [0]
-R, --reverse
invierte la dirección de todas las pasadas
-s, --size=<bytes>
tamaño máximo de datos de entrada a copiar
-S, --sparse
usa escrituras dispersas para el archivo de salida
-t, --truncate
trunca el archivo de salida a tamaño cero
-T, --timeout=<intervalo>
tiempo máximo desde la última lectura exitosa
-u, --unidirectional
ejecuta todas las pasadas en la misma dirección
-v, --verbose
sea verboso (un segundo -v da más información)
-w, --ignore-write-errors
hace que el modo de relleno ignore los errores de escritura
-W, --compare-before-write
omite escrituras superfluas en modo de rescate
-x, --extend-outfile=<bytes>
extiende el tamaño del archivo de salida para que sea al menos tan largo
-X, --max-read-errors=<n>
número máximo de errores de lectura permitidos
-y, --synchronous
usa escrituras síncronas para el archivo de salida
-Z, --max-read-rate=<bytes>
tasa máxima de lectura en bytes/s
--ask
pide confirmación antes de iniciar la copia
--bad-sector-data=<archivo>
trata los sectores con datos de <archivo> como errores de lectura
--command-mode
ejecuta comandos desde la entrada estándar
--continue-on-errno=<n>[,<n>]
trata el código errno <n> como no fatal
--cpass=<rango>
selecciona qué pasada(s) de copia ejecutar
--delay-slow=<intervalo>
retraso inicial antes de verificar lecturas lentas [30]
--log-events=<archivo>
registra eventos significativos en el <archivo>
--log-rates=<archivo>
registra tasas y tamaños de error en el <archivo>
--log-reads=<archivo>
registra todas las operaciones de lectura en el <archivo>
--mapfile-interval=[i][,i]
guarda/sincroniza el archivo de mapa en el intervalo dado [automático]
--max-slow-reads=<n>
número máximo de lecturas lentas permitidas
--pause-on-error=<intervalo>
tiempo de espera después de cada error de lectura [0]
--pause-on-pass=<intervalo>
tiempo de espera entre pasadas [0]
--reset-slow
reinicia las lecturas lentas si la tasa aumenta por encima del mínimo
--same-file
permite que el archivo de entrada y el archivo de salida sean el mismo archivo
