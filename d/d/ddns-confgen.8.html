NOMBRE

ddns-confgen - herramienta de generación de claves ddns

SINOPSIS

ddns-confgen [-a algoritmo] [-h] [-k nombre_clave] [-q] [-s nombre] [-z zona]

DESCRIPCIÓN

ddns-confgen es una utilidad que genera claves para su uso en firmas TSIG. Las claves resultantes pueden utilizarse, por ejemplo, para asegurar actualizaciones dinámicas de DNS a una zona, o para el canal de comandos de rndc <#std-iscman-rndc>.

El nombre de la clave se puede especificar mediante el parámetro -k y por defecto es ddns-key. La clave generada va acompañada de texto de configuración e instrucciones que se pueden utilizar con nsupdate <#std-iscman-nsupdate> y named <#std-iscman-named> al configurar DNS dinámico, incluyendo una declaración de ejemplo update-policy. (Este uso es similar al comando rndc-confgen <#std-iscman-rndc-confgen> para configurar la seguridad del canal de comandos.)

Tenga en cuenta que named <#std-iscman-named> puede configurar una clave DDNS local para su uso con nsupdate -l <#cmdoption-nsupdate-l>; lo hace cuando una zona está configurada con update-policy local;. ddns-confgen solo es necesario cuando se requiere una configuración más elaborada: por ejemplo, si se va a utilizar nsupdate <#std-iscman-nsupdate> desde un sistema remoto.

OPCIONES

-a algoritmo
Esta opción especifica el algoritmo a utilizar para la clave TSIG. Las opciones disponibles son: hmac-md5, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384 y hmac-sha512. El valor predeterminado es hmac-sha256. Las opciones no distinguen entre mayúsculas y minúsculas, y se puede omitir el prefijo "hmac-".
-h
Esta opción imprime un breve resumen de las opciones y argumentos.
-k nombre_clave
Esta opción especifica el nombre de la clave de autenticación DDNS. El valor predeterminado es ddns-key cuando no se especifica ni la opción -s ni la opción -z; de lo contrario, el valor predeterminado es ddns-key como una etiqueta separada seguida del argumento de la opción, por ejemplo, ddns-key.example.com. El nombre de la clave debe tener el formato de un nombre de dominio válido, que consta de letras, dígitos, guiones y puntos.
-q
Esta opción habilita el modo silencioso, que imprime solo la clave, sin texto explicativo ni ejemplos de uso. Esto es esencialmente idéntico a tsig-keygen <#std-iscman-tsig-keygen>.
-s nombre
Esta opción genera un ejemplo de configuración para permitir actualizaciones dinámicas de un solo nombre de host. El texto de ejemplo de named.conf <#std-iscman-named.conf> muestra cómo establecer una política de actualización para el nombre especificado utilizando el tipo de nombre "name". El nombre de clave predeterminado es ddns-key.nombre. Tenga en cuenta que no se puede utilizar el tipo de nombre "self", ya que el nombre a actualizar puede diferir del nombre de la clave. Esta opción no se puede utilizar con la opción -z.
-z zona
Esta opción genera un ejemplo de configuración para permitir actualizaciones dinámicas de una zona. El texto de ejemplo de named.conf <#std-iscman-named.conf> muestra cómo establecer una política de actualización para la zona especificada utilizando el tipo de nombre "zonesub", lo que permite actualizaciones a todos los nombres de subdominio dentro de esa zona. Esta opción no se puede utilizar con la opción -s.
