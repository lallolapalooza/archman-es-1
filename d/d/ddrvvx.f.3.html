DDRVV

X

Propósito

: 
!>
!>    DDRVVX verifica el controlador experto del problema de valores propios no simétrico
!>    DGEEVX.
!>
!>    DDRVVX utiliza tanto matrices de prueba generadas aleatoriamente dependiendo de
!>    los datos proporcionados en la secuencia de llamada, como de datos
!>    leídos de un archivo de entrada e incluyendo números de condición
!>    precalculados con los que compara los que él calcula.
!>
!>    Cuando se llama a DDRVVX, se especifican en la secuencia de llamada un número de matriz  () y un
!>    número de matriz . Para cada tamaño () y cada tipo de matriz, se generará
!>    una matriz y se usará para probar las rutinas de eigen no simétricas. Para
!>    cada matriz, se realizarán 9 pruebas:
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de vectores propios derechos unitarios.
!>      W es una matriz diagonal por bloques, con un bloque 1x1 para cada
!>      valor propio real y un bloque 2x2 para cada par
!>      conjugado complejo. Si los valores propios j y j+1 son un par conjugado complejo,
!>      es decir, WR(j) = WR(j+1) = wr y WI(j) = - WI(j+1) = wi, entonces el
!>      bloque 2 x 2 correspondiente al par será:
!>
!>              (  wr  wi  )
!>              ( -wi  wr  )
!>
!>      Un bloque así multiplicando una matriz n x 2  ( ur ui ) por la
!>      derecha será lo mismo que multiplicar  ur + i*ui  por  wr + i*wi.
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de vectores propios izquierdos unitarios, A**H es la
!>      transpuesta conjugada de A, y W es como arriba.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y componente real más grande
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y componente real más grande
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     W(full) = W(partial)
!>
!>      W(full) denota los valores propios calculados cuando también se calculan VR, VL, RCONDV
!>      y RCONDE, y W(partial) denota los
!>      valores propios calculados cuando solo se calculan algunos de VR, VL, RCONDV y
!>      RCONDE.
!>
!>    (6)     VR(full) = VR(partial)
!>
!>      VR(full) denota los vectores propios derechos calculados cuando se calculan VL, RCONDV
!>      y RCONDE, y VR(partial) denota el resultado
!>      cuando solo se calculan algunos de VL y RCONDV.
!>
!>    (7)     VL(full) = VL(partial)
!>
!>      VL(full) denota los vectores propios izquierdos calculados cuando se calculan VR, RCONDV
!>      y RCONDE, y VL(partial) denota el resultado
!>      cuando solo se calculan algunos de VR y RCONDV.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (full) =
!>                 SCALE, ILO, IHI, ABNRM (partial)
!>            1/ulp en caso contrario
!>
!>      SCALE, ILO, IHI y ABNRM describen cómo se equilibra la matriz.
!>      (full) es cuando también se calculan VR, VL, RCONDE y RCONDV, y
!>      (partial) es cuando algunos no se calculan.
!>
!>    (9)     RCONDV(full) = RCONDV(partial)
!>
!>      RCONDV(full) denota los números de condición recíprocos de los
!>      vectores propios derechos calculados cuando también se calculan VR, VL y RCONDE.
!>      RCONDV(partial) denota los números de condición
!>      recíprocos cuando solo se calculan algunos de VR, VL y RCONDE.
!>
!>    Los  se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1's en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP  y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP  y signos aleatorios.
!>    (6)  Una matriz diagonal con  entradas 1, ULP, ..., ULP
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicada por una constante cerca de
!>         el umbral de desbordamiento
!>    (8)  Igual que (4), pero multiplicada por una constante cerca de
!>         el umbral de desbordamiento por debajo
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>         en la diagonal y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>         aleatorios en la diagonal y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene  entradas 1, ULP,..., ULP con signos
!>         aleatorios en la diagonal y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene valores propios reales o pares conjugados complejos elegidos
!>         aleatoriamente de ( ULP, 1 ) y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con signos aleatorios en la diagonal y random O(1) entradas
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas geométricamente espaciadas
!>         1, ..., ULP con signos aleatorios en la diagonal y entradas
!>         aleatorias O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas 1, ULP,..., ULP
!>         con signos aleatorios en la diagonal y entradas aleatorias
!>         O(1) en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene autovalores reales o conjugados
!>         complejos elegidos aleatoriamente de ( ULP, 1 ) y entradas
!>         aleatorias O(1) en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento
!>    (18) Igual que (16), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento inferior
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>         Si N es al menos 4, todas las entradas en las dos primeras filas y la última
!>         fila, y la primera columna y las dos últimas columnas son cero.
!>    (20) Igual que (19), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento
!>    (21) Igual que (19), pero multiplicada por una constante
!>         cerca del umbral de desbordamiento inferior
!>
!>     Además, se leerá un archivo de entrada desde el número de unidad lógico
!>     NIUNIT. El archivo contiene matrices junto con autovalores precalculados
!>     y números de condición recíprocos para los autovalores
!>     y autovectores derechos. Para estas matrices, además de las pruebas
!>     (1) a (9) calcularemos las siguientes dos pruebas:
!>
!>   (10)  |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>      RCONDV es el número de condición recíproco del autovector derecho
!>      calculado por DGEEVX y RCDVIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDV) es el número de condición de
!>      RCONDV, y tiene en cuenta los errores al calcular RCONDV, de modo
!>      que la cantidad resultante debería ser O(ULP). cond(RCONDV) es
!>      esencialmente dado por norm(A)/RCONDE.
!>
!>   (11)  |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>      RCONDE es el número de condición recíproco del autovalor
!>      calculado por DGEEVX y RCDEIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDE) es el número de condición
!>      de RCONDE, y tiene en cuenta los errores al calcular RCONDE,
!>      de modo que la cantidad resultante debería ser O(ULP). cond(RCONDE)
!>      es esencialmente dado por norm(A)/RCONDV.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. NSIZES debe ser al
!>          menos cero. Si es cero, no se prueban matrices generadas
!>          aleatoriamente, pero se probarán las matrices de prueba
!>          leídas de NIUNIT.
!>

NN

!>          NN es un array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños a usar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. NTYPES debe ser al menos
!>          cero. Si es cero, no se prueban matrices de prueba generadas
!>          aleatoriamente, pero se probarán las matrices de prueba
!>          leídas de NIUNIT. Si es MAXTYP+1 y NSIZES es 1, entonces se
!>          define un tipo adicional, MAXTYP+1, que es usar
!>          cualquier matriz que esté en A. Esto solo es útil si
!>          DOTYPE(1:MAXTYP) es .FALSE. y DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a DOTYPE(NTYPES)
!>          se ignorarán.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se cambian en la salida, y pueden usarse en la
!>          siguiente llamada a DDRVVX para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se contará como fallida si el , calculado como
!>          se describe arriba, excede THRESH. Tenga en cuenta que el error
!>          se escala para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100. En particular,
!>          no debería depender de la precisión (simple vs. doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>

NIUNIT

!>          NIUNIT es INTEGER
!>          El número de unidad FORTRAN para leer el archivo de datos de
!>          problemas a resolver.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve INFO distinto de 0.)
!>

A

!>          A es un array DOUBLE PRECISION, dimensión
!>                      (LDA, max(NN,12))
!>          Se usa para contener la matriz cuyos autovalores se van a
!>          calcular. En la salida, A contiene la última matriz realmente usada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A y H.
!>          LDA >= max(NN,12), ya que 12 es la dimensión de la matriz más grande
!>          en el archivo de entrada precalculado.
!>

H

!>          H es un array DOUBLE PRECISION, dimensión
!>                      (LDA, max(NN,12))
!>          Otra copia de la matriz de prueba A, modificada por DGEEVX.
!>

WR

!>          WR es un array DOUBLE PRECISION, dimensión (max(NN))
!>

WI

!>          WI es un array DOUBLE PRECISION, dimensión (max(NN))
!>
!>          Las partes real e imaginaria de los autovalores de A.
!>          En la salida, WR + WI*i son los autovalores de la matriz en A.
!>

WR1

!>          WR1 es un array DOUBLE PRECISION, dimensión (max(NN,12))
!>

WI1

!>          WI1 es un array DOUBLE PRECISION, dimensión (max(NN,12))
!>
!>          Como WR, WI, estos arrays contienen los autovalores de A,
!>          pero aquellos calculados cuando DGEEVX solo calcula una
!>          descomposición parcial de autovalores, es decir, no los autovalores y
!>          autovectores izquierdos y derechos.
!>

VL

!>          VL es un array DOUBLE PRECISION, dimensión
!>                      (LDVL, max(NN,12))
!>          VL contiene los autovectores izquierdos calculados.
!>

LDVL

!>          LDVL es INTEGER
!>          Dimensión principal de VL. Debe ser al menos max(1,max(NN,12)).
!>

VR

!>          VR es un array DOUBLE PRECISION, dimensión
!>                      (LDVR, max(NN,12))
!>          VR contiene los autovectores derechos calculados.
!>

LDVR

!>          LDVR es INTEGER
!>          Dimensión principal de VR. Debe ser al menos max(1,max(NN,12)).
!>

LRE

!>          LRE es un array DOUBLE PRECISION, dimensión
!>                      (LDLRE, max(NN,12))
!>          LRE contiene los autovectores derechos o izquierdos calculados.
!>

LDLRE

!>          LDLRE es INTEGER
!>          Dimensión principal de LRE. Debe ser al menos max(1,max(NN,12))
!>

RCONDV

!>          RCONDV es un array DOUBLE PRECISION, dimensión (N)
!>          RCONDV contiene los números de condición recíprocos calculados
!>          para los autovectores.
!>

RCNDV1

!>          RCNDV1 es un array DOUBLE PRECISION, dimensión (N)
!>          RCNDV1 contiene más números de condición recíprocos calculados
!>          para los autovectores.
!>

RCDVIN

!>          RCDVIN es un array DOUBLE PRECISION, dimensión (N)
!>          Cuando COMP = .TRUE. RCDVIN contiene los números de condición
!>          recíprocos precalculados para los autovectores a comparar con
!>          RCONDV.
!>

RCONDE

!>          RCONDE es un array DOUBLE PRECISION, dimensión (N)
!>          RCONDE contiene los números de condición recíprocos calculados
!>          para los autovalores.
!>

RCNDE1

!>          RCNDE1 es un array DOUBLE PRECISION, dimensión (N)
!>          RCNDE1 contiene más números de condición recíprocos calculados
!>          para los autovalores.
!>

RCDEIN

!>          RCDEIN es un array DOUBLE PRECISION, dimensión (N)
!>          Cuando COMP = .TRUE. RCDEIN contiene los números de condición
!>          recíprocos precalculados para los autovalores a comparar con
!>          RCONDE.
!>

SCALE

!>          SCALE es un array DOUBLE PRECISION, dimensión (N)
!>          Contiene información que describe el balanceo de la matriz.
!>

SCALE1

!>          SCALE1 es un array DOUBLE PRECISION, dimensión (N)
!>          Contiene información que describe el balanceo de la matriz.
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (11)
!>          Los valores calculados por las siete pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (NWORK)
!>

NWORK

!>          NWORK es INTEGER
!>          El número de entradas en WORK. Este debe ser al menos
!>          max(6*12+2*12**2,6*NN(j)+2*NN(j)**2) =
!>          max(    360     ,6*NN(j)+2*NN(j)**2)    para todos j.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (2*max(NN,12))
!>

INFO

!>          INFO es INTEGER
!>          Si 0, entonces salida exitosa.
!>          Si <0, entonces el parámetro de entrada -INFO es incorrecto.
!>          Si >0, DLATMR, SLATMS, SLATME o DGET23 devolvieron un código
!>                 de error, y INFO es su valor absoluto.
!>
!>-----------------------------------------------------------------------
!>
!>     Algunas variables y parámetros locales:
!>     ---- ----- --------- --- ----------
!>
!>     ZERO, ONE       Real 0 y 1.
!>     MAXTYP          El número de tipos definidos.
!>     NMAX            El valor más grande en NN o 12.
!>     NERRS           El número de pruebas que han superado THRESH
!>     COND, CONDS,
!>     IMODE           Valores a pasar a los generadores de matrices.
!>     ANORM           Norma de A; se pasa a los generadores de matrices.
!>
!>     OVFL, UNFL      Umbrales de desbordamiento y desbordamiento por defecto.
!>
ULP, ULPINV Precisión relativa más fina y su inversa. !> RTULP, RTULPI Raíces cuadradas de los 4 valores anteriores. !> !> Los siguientes cuatro arrays decodifican JTYPE: !> KTYPE(j) El tipo general (1-10) para el tipo . !> KMODE(j) El valor MODE a pasar
al generador de !> matrices para el tipo . !> KMAGN(j) El orden de magnitud ( O(1), !> O(overflow^(1/2) ), O(underflow^(1/2) ) !> KCONDS(j) Selecciona si CONDS debe ser 1 o !> 1/sqrt(ulp). (0 significa irrelevante.)
