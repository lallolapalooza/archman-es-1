DDRVB

D

Propósito

: 
!>
!> DDRVBD comprueba los controladores de descomposición en valores singulares (SVD)
!> DGESVD, DGESDD, DGESVDQ, DGESVJ, DGEJSV, y DGESVDX.
!>
!> Tanto DGESVD como DGESDD factorizan A = U diag(S) VT, donde U y VT son
!> ortogonales y diag(S) es diagonal con las entradas del arreglo S
!> en su diagonal. Las entradas de S son los valores singulares,
!> no negativos y almacenados en orden decreciente. U y VT pueden
!> opcionalmente no calcularse, sobrescribirse en A, o calcularse parcialmente.
!>
!> A es M por N. Sea MNMIN = min( M, N ). S tiene dimensión MNMIN.
!> U puede ser M por M o M por MNMIN. VT puede ser N por N o MNMIN por N.
!>
!> Cuando se llama a DDRVBD, se especifica un número de tamaños de matriz (M's y N's)
!> y un número de tipos de matriz. Para cada tamaño (M,N)
!> y cada tipo de matriz, y para el espacio de trabajo mínimo así como
!> un espacio de trabajo adecuado para permitir el bloqueo, se generará
!> una matriz M x N y se usará para probar las rutinas SVD. Para cada matriz, A será
!> factorizada como A = U diag(S) VT y se calcularán los siguientes 12 pruebas:
!>
!> Prueba para DGESVD:
!>
!> (1)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)    | I - U'U | / ( M ulp )
!>
!> (3)    | I - VT VT' | / ( N ulp )
!>
!> (4)    S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (5)    | U - Upartial | / ( M ulp ) donde Upartial es un U
!>        parcialmente calculado.
!>
!> (6)    | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT
!>        parcialmente calculado.
!>
!> (7)    | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares del SVD parcial
!>
!> Prueba para DGESDD:
!>
!> (8)    | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)    | I - U'U | / ( M ulp )
!>
!> (10)   | I - VT VT' | / ( N ulp )
!>
!> (11)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (12)   | U - Upartial | / ( M ulp ) donde Upartial es un U
!>        parcialmente calculado.
!>
!> (13)   | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT
!>        parcialmente calculado.
!>
!> (14)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares del SVD parcial
!>
!> Prueba para DGESVDQ:
!>
!> (36)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)   | I - U'U | / ( M ulp )
!>
!> (38)   | I - VT VT' | / ( N ulp )
!>
!> (39)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para DGESVJ:
!>
!> (15)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)   | I - U'U | / ( M ulp )
!>
!> (17)   | I - VT VT' | / ( N ulp )
!>
!> (18)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para DGEJSV:
!>
!> (19)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)   | I - U'U | / ( M ulp )
!>
!> (21)   | I - VT VT' | / ( N ulp )
!>
!> (22)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para DGESVDX( 'V', 'V', 'A' )/DGESVDX( 'N', 'N', 'A' )
!>
!> (23)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)   | I - U'U | / ( M ulp )
!>
!> (25)   | I - VT VT' | / ( N ulp )
!>
!> (26)   S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (27)   | U - Upartial | / ( M ulp ) donde Upartial es un U
!>        parcialmente calculado.
!>
!> (28)   | VT - VTpartial | / ( N ulp ) donde VTpartial es un VT
!>        parcialmente calculado.
!>
!> (29)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>        vector de valores singulares del SVD parcial
!>
!> Prueba para DGESVDX( 'V', 'V', 'I' )
!>
!> (30)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)   | I - U'U | / ( M ulp )
!>
!> (32)   | I - VT VT' | / ( N ulp )
!>
!> Prueba para DGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Los tamaños de matriz se especifican con los arreglos MM(1:NSIZES) y
!> NN(1:NSIZES); el valor de cada par de elementos (MM(j),NN(j))
!> especifica un tamaño. Los tipos de matriz se especifican con un arreglo lógico
!> DOTYPE( 1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!> (3)  Una matriz de la forma U D V, donde U y V son ortogonales y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!> (4)  Igual que (3), pero multiplicada por el umbral de desbordamiento inferior / ULP.
!> (5)  Igual que (3), pero multiplicada por el umbral de desbordamiento superior * ULP.
!
>

Parámetro

s
NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matriz (M,N) contenidos en los vectores
!>          MM y NN.
!
>

M

M 
!>          MM es un arreglo INTEGER, dimensión (NSIZES)
!>          Los valores de la dimensión de filas de la matriz M.
!
>

N

N 
!>          NN es un arreglo INTEGER, dimensión (NSIZES)
!>          Los valores de la dimensión de columnas de la matriz N.
!
>

NTYPE

S 
!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, DDRVBD
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar las matrices que estén en A y B.
!>          Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE es un arreglo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño (m,n), se generará una matriz
!>          de tipo j. Si NTYPES es menor que el
!>          número máximo de tipos definidos (PARÁMETRO MAXTYP), entonces
!>          los tipos NTYPES+1 hasta MAXTYP no se generarán. Si
!>          NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) hasta
!>          DOTYPE(NTYPES) serán ignorados.
!> </pre>

ISEE
D

!>          ISEED es un arreglo de tipo INTEGER, dimensión (4)
!>          En la entrada, es la semilla del generador de números aleatorios. Los elementos del arreglo
!>          deben estar entre 0 y 4095; si no lo están, se reducirán módulo 4096. Además, ISEED(4) debe ser impar.
!>          En la salida, ISEED se modifica y puede usarse en la siguiente llamada a
!>          DDRVBD para continuar la misma secuencia de números aleatorios.
!
>

THRES
H

!>          THRESH es de tipo DOUBLE PRECISION
!>          El valor umbral para las proporciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Las proporciones
!>          de prueba se escalan para ser O(1), por lo que THRESH debe ser un pequeño
!>          múltiplo de 1, p. ej., 10 o 100. Para que se imprima cada proporción de prueba,
!>          use THRESH = 0.
!
>

A

!>          A es un arreglo de tipo DOUBLE PRECISION, dimensión (LDA,NMAX)
!>          donde NMAX es el valor máximo de N en NN.
!
>

LD
A

!>          LDA es de tipo INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1,MMAX),
!>          donde MMAX es el valor máximo de M en MM.
!
>

U

!>          U es un arreglo de tipo DOUBLE PRECISION, dimensión (LDU,MMAX)
!
>

LD
U

!>          LDU es de tipo INTEGER
!>          La dimensión principal del arreglo U. LDU >= max(1,MMAX).
!
>

V
T

!>          VT es un arreglo de tipo DOUBLE PRECISION, dimensión (LDVT,NMAX)
!
>

LDV
T

!>          LDVT es de tipo INTEGER
!>          La dimensión principal del arreglo VT. LDVT >= max(1,NMAX).
!
>

ASA
V

!>          ASAV es un arreglo de tipo DOUBLE PRECISION, dimensión (LDA,NMAX)
!
>

USA
V

!>          USAV es un arreglo de tipo DOUBLE PRECISION, dimensión (LDU,MMAX)
!
>

VTSA
V

!>          VTSAV es un arreglo de tipo DOUBLE PRECISION, dimensión (LDVT,NMAX)
!
>

S

!>          S es un arreglo de tipo DOUBLE PRECISION, dimensión
!>                      (max(min(MM,NN)))
!
>

SSA
V

!>          SSAV es un arreglo de tipo DOUBLE PRECISION, dimensión
!>                      (max(min(MM,NN)))
!
>

E

!>          E es un arreglo de tipo DOUBLE PRECISION, dimensión
!>                      (max(min(MM,NN)))
!
>

WOR
K

!>          WORK es un arreglo de tipo DOUBLE PRECISION, dimensión (LWORK)
!
>

LWOR
K

!>          LWORK es de tipo INTEGER
!>          El número de entradas en WORK. Este debe ser al menos
!>          max(3*MN+MX,5*MN-4)+2*MN**2 para todos los pares
!>          pares (MN,MX)=( min(MM(j),NN(j), max(MM(j),NN(j)) )
!
>

IWOR
K

!>          IWORK es un arreglo de tipo INTEGER, dimensión al menos 8*min(M,N)
!
>

NOU
T

!>          NOUT es de tipo INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!
>

INF
O

!>          INFO es de tipo INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algún MM(j) < 0
!>           -3: Algún NN(j) < 0
!>           -4: NTYPES < 0
!>           -7: THRESH < 0
!>          -10: LDA < 1 o LDA < MMAX, donde MMAX es max( MM(j) ).
!>          -12: LDU < 1 o LDU < MMAX.
!>          -14: LDVT < 1 o LDVT < NMAX, donde NMAX es max( NN(j) ).
!>          -21: LWORK demasiado pequeño.
!>          Si DLATMS, o DGESVD devuelve un código de error, se
!>              devuelve su valor absoluto.
