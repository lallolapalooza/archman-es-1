DDRGSX

Propósito:

!>
!> DDRGSX comprueba el controlador experto DGGESX para el problema de valores propios generalizados no simétricos (forma de Schur).
!>
!> DGGESX factoriza A y B como Q S Z' y Q T Z', donde ' significa transpuesta, T es triangular superior, S está en forma de Schur generalizada (triangular por bloques, con bloques de 1x1 y 2x2 en la diagonal, los bloques de 2x2 corresponden a pares complejos conjugados de valores propios generalizados), y Q y Z son ortogonales. También calcula los valores propios generalizados (alpha(1),beta(1)), ..., (alpha(n),beta(n)). Así, w(j) = alpha(j)/beta(j) es una raíz de la ecuación característica
!>
!>     det( A - w(j) B ) = 0
!>
!> Opcionalmente también reordena los valores propios para que un grupo seleccionado de valores propios aparezca en el bloque diagonal principal de las formas de Schur; calcula un número de condición recíproco para el promedio de los valores propios seleccionados; y calcula un número de condición recíproco para los subespacios deflactores derechos e izquierdos correspondientes a los valores propios seleccionados.
!>
!> Cuando DDRGSX se llama con NSIZE > 0, se utilizan cinco (5) tipos de pares de matrices incorporadas para probar la rutina DGGESX.
!>
!> Cuando DDRGSX se llama con NSIZE = 0, lee datos de matrices de prueba para probar DGGESX.
!>
!> Para cada par de matrices, se realizarán las siguientes pruebas y se compararán con el umbral THRESH, excepto para las pruebas (7) y (9):
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A está en forma de Schur (es decir, forma cuasitriangular)
!>
!> (6)   máximo sobre j de D(j)  donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>           y S y T son aquí los bloques diagonales de 2 x 2 de S y T
!>           correspondientes a los valores propios j-ésimo y j+1-ésimo.
!>
!> (7)   si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron seleccionados.
!>
!> (8)   el valor estimado DIF no difiere de los valores verdaderos de
!>       Difu y Difl en más de un factor 10*THRESH. Si la estimación DIF
!>       es igual a cero, los valores verdaderos correspondientes de Difu y Difl
!>       deberían ser menores que EPS*norm(A, B). Si el valor verdadero de Difu
!>       y Difl es igual a cero, la estimación DIF debería ser menor que
!>       EPS*norm(A, B).
!>
!> (9)   Si DGGESX devuelve INFO = N+3, la reordenación
!>       y comprobamos que DIF = PL = PR = 0 y que el valor verdadero de
!>       Difu y Difl es < EPS*norm(A, B). Contamos los eventos cuando
!>       INFO=N+3.
!>
!> Para las matrices de prueba leídas, se ejecutan las pruebas anteriores excepto que el
!> valor exacto para DIF (y PL) son datos de entrada. Adicionalmente, hay
!> una prueba más ejecutada para las matrices de prueba leídas:
!>
!> (10)  el valor estimado PL no difiere del valor verdadero de
!>       PLTRU en más de un factor THRESH. Si la estimación PL es igual
!>       a cero, el valor verdadero correspondiente de PLTRU debería ser menor que
!>       EPS*norm(A, B). Si el valor verdadero de PLTRU es igual a cero, la
!>       estimación PL debería ser menor que EPS*norm(A, B).
!>
!> Nótese que para las pruebas incorporadas, se generan y prueban un total de 10*NSIZE*(NSIZE-1)
!> pares de matrices. NSIZE debería mantenerse pequeño.
!>
!> SVD (rutina DGESVD) se usa para calcular el valor verdadero de DIF_u
!> y DIF_l al probar los problemas de prueba incorporados.
!>
!> Matrices de Prueba Incorporadas
!> ==============================
!>
!> Todas las matrices de prueba incorporadas son el bloque de 2 por 2 de matrices
!> triangulares
!>
!>          A = [ A11 A12 ]    y      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> donde para diferentes tipos de A11 y A22 se dan como sigue.
!> A12 y B12 se eligen de modo que la ecuación de Sylvester generalizada
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> tenga las soluciones prescritas R y L.
!>
!> Tipo 1:  A11 = J_m(1,-1) y A_22 = J_k(1-a,1).
!>          B11 = I_m, B22 = I_k
!>          donde J_k(a,b) es el bloque de Jordan de k por k con ``a'' en la
!>          diagonal y ``b'' en la superdiagonal.
!>
!> Tipo 2:  A11 = (a_ij) = ( 2(.5-sin(i)) ) y
!>          B11 = (b_ij) = ( 2(.5-sin(ij)) ) para i=1,...,m, j=i,...,m
!>          A22 = (a_ij) = ( 2(.5-sin(i+j)) ) y
!>          B22 = (b_ij) = ( 2(.5-sin(ij)) ) para i=m+1,...,k, j=i,...,k
!>
!> Tipo 3:  A11, A22 y B11, B22 se eligen como para el Tipo 2, pero cada
!>          segundo bloque diagonal en A_11 y cada tercer bloque diagonal
!>          en A_22 se hacen como bloques de 2 por 2.
!>
!> Tipo 4:  A11 = ( 20(.5 - sin(ij)) ) y B22 = ( 2(.5 - sin(i+j)) )
!>             para i=1,...,m,  j=1,...,m y
!>          A22 = ( 20(.5 - sin(i+j)) ) y B22 = ( 2(.5 - sin(ij)) )
!>             para i=m+1,...,k,  j=m+1,...,k
!>
!> Tipo 5:  (A,B) y tienen potencialmente valores propios cercanos o comunes y
!>          una desviación muy grande de la diagonalidad por bloques. A_11 se elige
!>          como la submatriz principal de A_1 de tamaño m x m:
!>                  |  1  b                            |
!>                  | -b  1                            |
!>                  |        1+d  b                    |
!>                  |         -b 1+d                   |
!>           A_1 =  |                  d  1            |
!>                  |                 -1  d            |
!>                  |                        -d  1     |
!>                  |                        -1 -d     |
!>                  |                               1  |
!>          y A_22 se elige como la submatriz principal de A_2 de tamaño k x k:
!>                  | -1  b                            |
!>                  | -b -1                            |
!>                  |       1-d  b                     |
!>                  |       -b  1-d                    |
!>           A_2 =  |                 d 1+b            |
!>                  |               -1-b d             |
!>                  |

Function/Subroutine Documentation

          
This routine tests the driver subroutine DGGESX.

          
It is intended to be used to test the correctness of
            the LAPACK routines for computing the generalized Schur
            factorization of a pair of general matrices A and B:

          
           A*Z = S*T and B*Z = S*U


          
where Z is an orthogonal matrix, and T and U are upper
            triangular matrices.

          
The arrays A, B, AI, BI, Z, Q, ALPHAR, ALPHAI, BETA, C, S,
            WORK, IWORK, and BWORK are integer arrays that contain test
            matrices and workspace.

          
The matrix AI is a copy of A, and BI is a copy of B.
            These are modified by DGGESX.

          
Z holds the left Schur vectors, and Q holds the right
            Schur vectors.

          
The eigenvalues are computed as (ALPHAR + ALPHAI*i)/BETA.

          
The matrix C is formed by Kronecker products, and S
            contains its singular values. This is used for estimating the
            condition number (DIF) of the generalized eigenvalue problem.

          
The actual error is computed as:

          
          ( DGGESX( A, B, ... ) - 1 ) / ( NSIZE * DLAMCH( 'E' ) )


          
where DLAMCH( 'E' ) is the machine epsilon for
            double precision.

          
If THRESH is less than or equal to zero, then the test
            is performed using the default value of 100.

          
The test matrices are generated by the subroutine DLAKF2.
            If the input matrices A and B are chosen as identity matrices (see
            DLATM5).

          
Parameters

          

            NSIZE
            
!>          NSIZE is INTEGER
!>          The maximum size of the matrices to use. NSIZE >= 0.
!>          If NSIZE = 0, no built-in tests matrices are used, but
!>          read-in test matrices are used to test DGGESX.
!>

            NCMAX
            
!>          NCMAX is INTEGER
!>          Maximum allowable NMAX for generating Kroneker matrix
!>          in call to DLAKF2
!>

            THRESH
            
!>          THRESH is DOUBLE PRECISION
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  THRESH >= 0.
!>

            NIN
            
!>          NIN is INTEGER
!>          The FORTRAN unit number for reading in the data file of
!>          problems to solve.
!>

            NOUT
            
!>          NOUT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>

            A
            
!>          A is DOUBLE PRECISION array, dimension (LDA, NSIZE)
!>          Used to store the matrix whose eigenvalues are to be
!>          computed.  On exit, A contains the last matrix actually used.
!>

            LDA
            
!>          LDA is INTEGER
!>          The leading dimension of A, B, AI, BI, Z and Q,
!>          LDA >= max( 1, NSIZE ). For the read-in test,
!>          LDA >= max( 1, N ), N is the size of the test matrices.
!>

            B
            
!>          B is DOUBLE PRECISION array, dimension (LDA, NSIZE)
!>          Used to store the matrix whose eigenvalues are to be
!>          computed.  On exit, B contains the last matrix actually used.
!>

            AI
            
!>          AI is DOUBLE PRECISION array, dimension (LDA, NSIZE)
!>          Copy of A, modified by DGGESX.
!>

            BI
            
!>          BI is DOUBLE PRECISION array, dimension (LDA, NSIZE)
!>          Copy of B, modified by DGGESX.
!>

            Z
            
!>          Z is DOUBLE PRECISION array, dimension (LDA, NSIZE)
!>          Z holds the left Schur vectors computed by DGGESX.
!>

            Q
            
!>          Q is DOUBLE PRECISION array, dimension (LDA, NSIZE)
!>          Q holds the right Schur vectors computed by DGGESX.
!>

            ALPHAR
            
!>          ALPHAR is DOUBLE PRECISION array, dimension (NSIZE)
!>

            ALPHAI
            
!>          ALPHAI is DOUBLE PRECISION array, dimension (NSIZE)
!>

            BETA
            
!>          BETA is DOUBLE PRECISION array, dimension (NSIZE)
!>
!>          On exit, (ALPHAR + ALPHAI*i)/BETA are the eigenvalues.
!>

            C
            
!>          C is DOUBLE PRECISION array, dimension (LDC, LDC)
!>          Store the matrix generated by subroutine DLAKF2, this is the
!>          matrix formed by Kronecker products used for estimating
!>          DIF.
!>

            LDC
            
!>          LDC is INTEGER
!>          The leading dimension of C. LDC >= max(1, LDA*LDA/2 ).
!>

            S
            
!>          S is DOUBLE PRECISION array, dimension (LDC)
!>          Singular values of C
!>

            WORK
            
!>          WORK is DOUBLE PRECISION array, dimension (LWORK)
!>

            LWORK
            
!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          LWORK >= MAX( 5*NSIZE*NSIZE/2 - 2, 10*(NSIZE+1) )
!>

            IWORK
            
!>          IWORK is INTEGER array, dimension (LIWORK)
!>

            LIWORK
            
!>          LIWORK is INTEGER
!>          The dimension of the array IWORK. LIWORK >= NSIZE + 6.
!>

            BWORK
            
!>          BWORK is LOGICAL array, dimension (LDA)
!>

            INFO
            
!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  A routine returned an error code.
!>
