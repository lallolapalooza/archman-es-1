DDRVS

T

Propósito

: 
!>
!>      DDRVST comprueba los controladores del problema de valores propios simétrico.
!>
!>              DSTEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz tridiagonal simétrica real.
!>
!>              DSTEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz tridiagonal simétrica real.
!>
!>              DSTEVR calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz tridiagonal simétrica real
!>              utilizando la Representación Robusta Relativa donde sea posible.
!>
!>              DSYEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real.
!>
!>              DSYEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real.
!>
!>              DSYEVR calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real
!>              utilizando la Representación Robusta Relativa donde sea posible.
!>
!>              DSPEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado.
!>
!>              DSPEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado.
!>
!>              DSBEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real.
!>
!>              DSBEVX calcula valores propios seleccionados y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real.
!>
!>              DSYEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real utilizando
!>              un algoritmo de dividir y conquistar.
!>
!>              DSPEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz simétrica real en
!>              almacenamiento empaquetado, utilizando un algoritmo de dividir y conquistar.
!>
!>              DSBEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda simétrica real,
!>              utilizando un algoritmo de dividir y conquistar.
!>
!>      Cuando se llama a DDRVST, se especifica un número de tamaños de matriz y un
!>      número de tipos de matriz. Para cada tamaño y cada tipo de matriz,
!>      se generará una matriz y se utilizará para probar los controladores
!>      correspondientes. Para cada matriz y cada rutina controladora llamada,
!>      se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de vectores propios devuelta cuando se
!>      da la opción de vectores propios y D1 y D2 son los valores propios
!>      devueltos con y sin la opción de vectores propios.
!>
!>      Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con valores propios equiespaciados
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con valores propios geométricamente espaciados
!>           1, ..., ULP y signos aleatorios.
!>      (5)  Una matriz diagonal con n valores propios
!>           1, ULP, ..., ULP y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!>      (8)  Una matriz de la forma U' D U, donde U es ortogonal y
!>           D tiene entradas equiespaciadas 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9)  Una matriz de la forma U' D U, donde U es ortogonal y
!>           D tiene entradas geométricamente espaciadas 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma U' D U, donde U es ortogonal y
!>           D tiene n entradas 1, ULP,..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!>      (16) Una matriz de banda con semiancho de banda elegido aleatoriamente entre
!>           0 y N-1, con valores propios equiespaciados 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicada por SQRT( umbral de desbordamiento inferior )
!
> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          DDRVST no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, DDRVST
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1, que
!>          es usar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) es .VERDADERO, entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán.  Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!>          No modificado.
!>
!>  ISEED   Arreglo INTEGER, dimensión (4)
!>          En la entrada ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del arreglo deben estar entre 0 y 4095;
!>          si no lo están, se reducirán módulo 4096.  Además, ISEED(4) debe
!>          ser impar.  El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican en la salida, y pueden usarse en la
!>          siguiente llamada a DDRVST para continuar la misma secuencia de números aleatorios.
!>          Modificado.
!>
!>  THRESH  DOUBLE PRECISION
!>          Una prueba se considerará fallida si el , calculado como
!>          se describe arriba, excede THRESH.  Nótese que el error
!>          se escala para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100.  En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz.  Debe ser al menos cero.
!>          No modificado.
!>
!>  NOUNIT  INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!>          No modificado.
!>
!>  A       Arreglo DOUBLE PRECISION, dimensión (LDA , max(NN))
!>          Usado para almacenar la matriz cuyos eigenvalores deben
!>          calcularse.  En la salida, A contiene la última matriz realmente
!>          usada.
!>          Modificado.
!>
!>  LDA     INTEGER
!>          La dimensión principal de A.  Debe ser al
!>          menos 1 y al menos max( NN ).
!>          No modificado.
!>
!>  D1      Arreglo DOUBLE PRECISION, dimensión (max(NN))
!>          Los eigenvalores de A, calculados por DSTEQR simultáneamente
!>          con Z.  En la salida, los eigenvalores en D1 corresponden con la
!>          matriz en A.
!>          Modificado.
!>
!>  D2      Arreglo DOUBLE PRECISION, dimensión (max(NN))
!>          Los eigenvalores de A, calculados por DSTEQR si Z no es
!>          calculado.  En la salida, los eigenvalores en D2 corresponden con
!>          la matriz en A.
!>          Modificado.
!>
!>  D3      Arreglo DOUBLE PRECISION, dimensión (max(NN))
!>          Los eigenvalores de A, calculados por DSTERF.  En la salida, los
!>          eigenvalores en D3 corresponden con la matriz en A.
!>          Modificado.
!>
!>  D4      Arreglo DOUBLE PRECISION, dimensión
!>
!>  EVEIGS  Arreglo DOUBLE PRECISION, dimensión (max(NN))
!>          Los eigenvalores calculados por DSTEV('N', ... )
!>          (Me reservo el derecho de cambiar esto por la salida de
!>          cualquier algoritmo que calcule los eigenvalores más precisos).
!>
!>  WA1     Arreglo DOUBLE PRECISION, dimensión
!>
!>  WA2     Arreglo DOUBLE PRECISION, dimensión
!>
!>  WA3     Arreglo DOUBLE PRECISION, dimensión
!>
!>  U       Arreglo DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          La matriz ortogonal calculada por DSYTRD + DORGTR.
!>          Modificado.
!>
!>  LDU     INTEGER
!>          La dimensión principal de U, Z y V.  Debe ser al
!>          menos 1 y al menos max( NN ).
!>          No modificado.
!>
!>  V       Arreglo DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          Los vectores de Householder calculados por DSYTRD al reducir A a
!>          forma tridiagonal.
!>          Modificado.
!>
!>  TAU     Arreglo DOUBLE PRECISION, dimensión (max(NN))
!>          Los factores de Householder calculados por DSYTRD al reducir A
!>          a forma tridiagonal.
!>          Modificado.
!>
!>  Z       Arreglo DOUBLE PRECISION, dimensión (LDU, max(NN))
!>          La matriz ortogonal de eigenvectores calculada por DSTEQR,
!>          DPTEQR y DSTEIN.
!>          Modificado.
!>
!>  WORK    Arreglo DOUBLE PRECISION, dimensión (LWORK)
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  LWORK   INTEGER
!>          El número de entradas en WORK.  Este debe ser al menos
!>          1 + 4 * Nmax + 2 * Nmax * lg Nmax + 4 * Nmax**2
!>          donde Nmax = max( NN(j), 2 ) y lg = logaritmo base 2.
!>          No modificado.
!>
!>  IWORK   Arreglo INTEGER,
!>             dimensión (6 + 6*Nmax + 5 * Nmax * lg Nmax )
!>          donde Nmax = max( NN(j), 2 ) y lg = logaritmo base 2.
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  RESULT  Arreglo DOUBLE PRECISION, dimensión (105)
!>          Los valores calculados por las pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!>          Modificado.
!>
!>  INFO    INTEGER
!>          Si es 0, entonces todo se ejecutó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algunos NN(j) < 0
!>           -3: NTYPES < 0
!>           -5: THRESH < 0
!>           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>          -16: LDU < 1 o LDU < NMAX.
!>          -21: LWORK demasiado pequeño.
!>          Si  DLATMR, DLATMS, DSYTRD, DORGTR, DSTEQR, DSTERF,
!>              o DORMTR devuelve un código de error, se
!>              devuelve su valor absoluto.
!>          Modificado.
!>
!>-----------------------------------------------------------------------
!>
!>       Algunas Variables y Parámetros Locales:
!>       ---- ----- --------- --- ----------
!>       ZERO, ONE       Real 0 y 1.
!>       MAXTYP          El número de tipos definidos.
!>       NTEST           El número de pruebas realizadas, o que pueden
!>                       realizarse hasta ahora, para la matriz actual.
!>       NTESTT          El número total de pruebas realizadas hasta ahora.
!>       NMAX            El valor más grande en NN.
!>       NMATS           El número de matrices generadas hasta ahora.
!>       NERRS           El número de pruebas que han excedido THRESH
!>                       hasta ahora (calculado por DLAFTS).
!>       COND, IMODE     Valores a pasar a los generadores de matrices.
!>       ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>       OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>       ULP, ULPINV     Precisión relativa más fina y su inversa.
!>       RTOVFL, RTUNFL  Raíces cuadradas de los 2 valores anteriores.
!>               Los siguientes cuatro arreglos decodifican JTYPE:
!>       KTYPE(j)        El tipo general (1-10) para el tipo .
!>       KMODE(j)        El valor MODE a pasar al generador de
!>                       matrices para el tipo .
!>       KMAGN(j)        El orden de magnitud ( O(1),
!>                       O(overflow^(1/2) ), O(underflow^(1/2) )
!>
!>     Las pruebas realizadas son:                 Rutina probada
!>    1= | A - U S U' | / ( |A| n ulp )         DSTEV('V', ... )
!>    2= | I - U U' | / ( n ulp )               DSTEV('V', ... )
!>    3= |D(con Z) - D(sin Z)| / (|D| ulp)      DSTEV('N', ... )
!>    4= | A - U S U' | / ( |A| n ulp )         DSTEVX('V','A', ... )
!>    5= | I - U U' | / ( n ulp )               DSTEVX('V','A', ... )
!>    6= |D(con Z) - EVEIGS| / (|D| ulp)        DSTEVX('N','A', ... )
!>    7= | A - U S U' | / ( |A| n ulp )         DSTEVR('V','A', ... )
!>    8= | I - U U' | / ( n ulp )               DSTEVR('V','A', ... )
!>    9= |D(con Z) - EVEIGS| / (|D| ulp)        DSTEVR('N','A', ... )
!>    10= | A - U S U' | / ( |A| n ulp )        DSTEVX('V','I', ... )
!>    11= | I - U U' | / ( n ulp )              DSTEVX('V','I', ... )
!>    12= |D(con Z) - D(sin Z)| / (|D| ulp)     DSTEVX('N','I', ... )
!>    13= | A - U S U' | / ( |A| n ulp )        DSTEVX('V','V', ... )
!>    14= | I - U U' | / ( n ulp )              DSTEVX('V','V', ... )
!>    15= |D(con Z) - D(sin Z)| / (|D| ulp)     DSTEVX('N','V', ... )
!>    16= | A - U S U' | / ( |A| n ulp )        DSTEVD('V', ... )
!>    17= | I - U U' | / ( n ulp )              DSTEVD('V', ... )
!>    18= |D(con Z) - EVEIGS| / (|D| ulp)       DSTEVD('N', ... )
!>    19= | A - U S U' | / ( |A| n ulp )        DSTEVR('V','I', ... )
!>    20= | I - U U' | / ( n ulp )              DSTEVR('V','I', ... )
!>    21= |D(con Z) - D(sin Z)| / (|D| ulp)     DSTEVR('N','I', ... )
!>    22= | A - U S U' | / ( |A| n ulp )        DSTEVR('V','V', ... )
!>    23= | I - U U' | / ( n ulp )              DSTEVR('V','V', ... )
!>    24= |D(con Z) - D(sin Z)| / (|D| ulp)     DSTEVR('N','V', ... )
!>
!>    25= | A - U S U' | / ( |A| n ulp )        DSYEV('L','V', ... )
!>    26= | I - U U' | / ( n ulp )              DSYEV('L','V', ... )
!>    27= |D(con Z) - D(sin Z)| / (|D| ulp)     DSYEV('L','N', ... )
!>    28= | A - U S U' | / ( |A| n ulp )        DSYEVX('L','V','A', ... )
!>    29= | I - U U' | / ( n ulp )              DSYEVX('L','V','A', ... )
!>    30= |D(con Z) - D(sin Z)| / (|D| ulp)     DSYEVX('L','N','A', ... )
!>    31= | A - U S U' | / ( |A| n ulp )        DSYEVX('L','V','I', ... )
!>    32= | I - U U' | / ( n ulp )              DSYEVX('L','V','I', ... )
!>    33= |D(con Z) - D(sin Z)| / (|D| ulp)     DSYEVX('L','N','I', ... )
!>    34= | A - U S U' | / ( |A| n ulp )        DSYEVX('L','V','V', ... )
!>    35= | I - U U' | / ( n ulp )              DSYEVX('L','V','V', ... )
!>    36= |D(con Z) - D(sin Z)| / (|D| ulp)     DSYEVX('L','N','V', ... )
!>    37= | A - U S U' | / ( |A| n ulp )        DSPEV('L','V', ... )
!>    38= | I - U U' | / ( n ulp )              DSPEV('L','V', ... )
!>    39= |D(con Z) - D(sin Z)| / (|D| ulp)     DSPEV('L','N', ... )
!>    40= | A - U S U' | / ( |A| n ulp )        DSPEVX('L','V','A', ... )
!>    41= | I - U U' | / ( n ulp )              DSPEVX('L','V','A', ... )
!>    42= |D(con Z) - D(sin Z)| / (|D| ulp)     DSPEVX('L','N','A', ... )
!>    43= | A - U S U' | / ( |A| n ulp )        DSPEVX('L','V','I', ... )
!>    44= | I - U U' | / ( n ulp )              DSPEVX('L','V','I', ... )
!>    45= |D(con Z) - D(sin Z)| / (|D| ulp)     DSPEVX('L','N','I', ... )
!>    46= | A - U S U' | / ( |A| n ulp )        DSPEVX('L','V','V', ... )
!>    47= | I - U U' | / ( n ulp )              DSPEVX('L','V','V', ... )
!>    48= |D(con Z) - D(sin Z)| / (|D| ulp)     DSPEVX('L','N','V', ... )
!>    49= | A - U S U' | / ( |A| n ulp )        DSBEV('L','V', ... )
!>    50= | I - U U' | / ( n ulp )              DSBEV('L','V', ... )
!>    51= |D(con Z) - D(sin Z)| / (|D| ulp)     DSBEV('L','N', ... )
!>    52= | A - U S U' | / ( |A| n ulp )        DSBEVX('L','V','A', ... )
!>    53= | I - U U' | / ( n ulp )              DSBEVX('L','V','A', ... )
!>    54= |D(con Z) - D(sin Z)| / (|D| ulp)     DSBEVX('L','N','A', ... )
!>    55= | A - U S U' | / ( |A| n ulp )        DSBEVX('L','V','I', ... )
!>    56= | I - U U' | / ( n ulp )              DSBEVX('L','V','I', ... )
!>    57= |D(con Z) - D(sin Z)| / (|D| ulp)     DSBEVX('L','N','I', ... )
!>    58= | A - U S U' | / ( |A| n ulp )        DSBEVX('L','V','V', ... )
!>    59= | I - U U' | / ( n ulp )              DSBEVX('L','V','V', ... )
!>    60= |D(con Z) - D(sin Z)| / (|D| ulp)     DSBEVX('L','N','V', ... )
!>    61= | A - U S U' | / ( |A| n ulp )        DSYEVD('L','V', ... )
!>    62= | I - U U' | / ( n ulp )              DSYEVD('L','V', ... )
!>    63= |D(con Z) - D(sin Z)| / (|D| ulp)     DSYEVD('L','N', ... )
!>    64= | A - U S U' | / ( |A| n ulp )        DSPEVD('L','V', ... )
!>    65= | I - U U' | / ( n ulp )              DSPEVD('L','V', ... )
!>    66= |D(con Z) - D(sin Z)| / (|D| ulp)    DSPEVD('L','N', ... )
!>    67= | A - U S U' | / ( |A| n ulp )        DSBEVD('L','V', ... )
!>    68= | I - U U' | / ( n ulp )              DSBEVD('L','V', ... )
!>    69= |D(con Z) - D(sin Z)| / (|D| ulp)    DSBEVD('L','N', ... )
!>    70= | A - U S U' | / ( |A| n ulp )        DSYEVR('L','V','A', ... )
!>    71= | I - U U' | / ( n ulp )              DSYEVR('L','V','A', ... )
