subrutina ddrvsx (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer niunit, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( lda, * ) h, double precision, dimension( lda, * ) ht, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( * ) wrt, double precision, dimension( * ) wit, double precision, dimension( * ) wrtmp, double precision, dimension( * ) witmp, double precision, dimension( ldvs, * ) vs, integer ldvs, double precision, dimension( ldvs, * ) vs1, double precision, dimension( 17 ) result, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, logical, dimension( * ) bwork, integer info)

DDRVSX

Propósito:

!>
!>    DDRVSX comprueba el problema experto del autovalor no simétrico (forma de Schur)
!>    DGEESX.
!>
!>    DDRVSX utiliza matrices de prueba generadas aleatoriamente dependiendo de
!>    los datos proporcionados en la secuencia de llamada, así como datos
!>    leídos de un archivo de entrada e incluyendo números de condición precalculados
!>    con los que compara los que calcula.
!>
!>    Cuando se llama a DDRVSX, se especifica un número de tamaños de matriz ()
!>    y un número de tipos de matriz.  Para cada tamaño ()
!>    y cada tipo de matriz, se generará y utilizará una matriz
!>    para probar las subrutinas de autovalores no simétricos.  Para cada matriz, se realizarán 15
!>    pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenación de autovalores)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de los autovectores de Schur, y T está en forma de Schur
!>      (sin ordenación de autovalores).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenación de autovalores).
!>
!>    (4)     0     si WR+sqrt(-1)*WI son autovalores de T
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (6)     0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de los autovectores de Schur, y T está en forma de Schur
!>      (con ordenación de autovalores).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de autovalores).
!>
!>    (10)    0     si WR+sqrt(-1)*WI son autovalores de T
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara WR, WI con y
!>            sin números recíprocos de condición
!>            (con ordenación de autovalores)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara T con y sin
!>            números recíprocos de condición
!>            (con ordenación de autovalores)
!>
!>    (12)    0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara VS con y sin
!>            números recíprocos de condición
!>            (con ordenación de autovalores)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            autovalores que fueron SELECCIONADOS
!>            Si el espacio de trabajo es suficiente, también compara SDIM con y
!>            sin números recíprocos de condición
!>
!>    (14)    si RCONDE es el mismo independientemente de si VS y/o RCONDV se calcularon
!>
!>    (15)    si RCONDV es el mismo independientemente de si VS y/o RCONDE se calcularon
!>
!>    Los tamaños de matriz se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1s en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y signos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1)
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y signos aleatorios.
!>    (6)  Una matriz diagonal con N entradas 1, ULP,..., ULP^{N-1}
!>         y signos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento
!>    (8)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento
!>
!>    (9)  Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene N entradas 1, ULP,..., ULP^{N-1} en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene autovalores reales o de pares conjugados complejos elegidos
!>         aleatoriamente de ( ULP, 1 ) y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         en la diagonal y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene N entradas 1, ULP,..., ULP^{N-1}
!>         en la diagonal y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene autovalores reales o de pares conjugados complejos
!>         elegidos aleatoriamente de ( ULP, 1 ) y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicado por una constante
!>         cercana al umbral de desbordamiento
!>    (18) Igual que (16), pero multiplicado por una constante
!>         cercana al umbral de subdesbordamiento
!>
!>    (
19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1). !> Si N es al menos 4, todas las entradas en las dos primeras filas y la última !> fila, y la primera columna y las dos últimas columnas son cero. !> (20) Igual que (19), pero multiplicada por una constante !> cerca del umbral de desbordamiento !> (21) Igual que (19), pero multiplicada por una constante !> cerca del umbral de desbordamiento inferior !> !> Además, se leerá un archivo de entrada desde el número de unidad lógica !> NIUNIT. El archivo contiene matrices junto con autovalores precalculados !> y números de condición recíprocos para el promedio de autovalores !> y el subespacio invariante derecho. Para estas matrices, en !> adición a las pruebas (1) a (15) calcularemos las siguientes dos !> pruebas: !> !> (16) |RCONDE - RCDEIN| / cond(RCONDE) !> !> RCONDE es el número de condición recíproco promedio de autovalores !> calculado por DGEESX y RCDEIN (el valor verdadero precalculado) !> se proporciona como entrada. cond(RCONDE) es el número de condición !> de RCONDE, y tiene en cuenta los errores al calcular RCONDE, !> de modo que la cantidad resultante debería ser O(ULP). cond(RCONDE) !> es esencialmente dado por norm(A)/RCONDV. !> !> (17) |RCONDV - RCDVIN| / cond(RCONDV) !> !> RCONDV es el número de condición recíproco del subespacio invariante !> derecho calculado por DGEESX y RCDVIN (el valor verdadero precalculado !> ) se proporciona como entrada. cond(RCONDV) es el número de condición !> de RCONDV, y tiene en cuenta los errores al calcular RCONDV en !> cuenta, de modo que la cantidad resultante debería ser O(ULP). !> cond(RCONDV) es esencialmente dado por norm(A)/RCONDE. !>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. NSIZES debe ser al
!>          menos cero. Si es cero, no se probarán matrices generadas
!>          aleatoriamente, pero se probarán las matrices de prueba leídas de NIUNIT.
!>

NN

!>          NN es un array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser al
!>          menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. NTYPES debe ser al menos
!>          cero. Si es cero, no se probarán matrices de prueba generadas
!>          aleatoriamente, pero se probarán las matrices de prueba leídas de NIUNIT.
!>          Si es MAXTYP+1 y NSIZES es 1, entonces se
!>          define un tipo adicional, MAXTYP+1, que es usar
!>          cualquier matriz que esté en A. Esto solo es útil si
!>          DOTYPE(1:MAXTYP) es .FALSE. y DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 a través de
!>          MAXTYP no serán generados. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) a través de DOTYPE(NTYPES)
!>          serán ignorados.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, serán reducidos módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se cambian en la salida, y pueden usarse en la
!>          siguiente llamada a DDRVSX para continuar la misma secuencia de
!>          números aleatorios.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se contará como fallida si el , calculado como
!>          se describe arriba, excede THRESH. Nótese que el error
!>          se escala para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100. En particular,
!>          no debería depender de la precisión (simple vs. doble)
!>          o del tamaño de la matriz. Debe ser al menos cero.
!>

NIUNIT

!>          NIUNIT es INTEGER
!>          El número de unidad FORTRAN para leer el archivo de datos de
!>          problemas a resolver.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve INFO distinto de 0.)
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          Usado para contener la matriz cuyos autovalores se van a
!>          calcular. En la salida, A contiene la última matriz realmente usada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A, y H. LDA debe ser al
!>          menos 1 y al menos max( NN ).
!>

H

!>          H es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          Otra copia de la matriz de prueba A, modificada por DGEESX.
!>

HT

!>          HT es un array DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          Otra copia más de la matriz de prueba A, modificada por DGEESX.
!>

WR

!>          WR es un array DOUBLE PRECISION, dimensión (max(NN))
!>

WI

!>          WI es un array DOUBLE PRECISION, dimensión (max(NN))
!>
!>          Las partes real e imaginaria de los autovalores de A.
!>          En la salida, WR + WI*i son los autovalores de la matriz en A.
!>

WRT

!>          WRT es un array DOUBLE PRECISION, dimensión (max(NN))
!>

WIT

!>          WIT es un array DOUBLE PRECISION, dimensión (max(NN))
!>
!>          Como WR, WI, estos arrays contienen los autovalores de A,
!>          pero aquellos calculados cuando DGEESX solo calcula una
!>          descomposición parcial de eigen, es decir, sin vectores de Schur
!>

WRTMP

!>          WRTMP es un array DOUBLE PRECISION, dimensión (max(NN))
!>

WITMP

!>          WITMP es un array DOUBLE PRECISION, dimensión (max(NN))
!>
!>          Más almacenamiento temporal para autovalores.
!>

VS

!>          VS es un array DOUBLE PRECISION, dimensión (LDVS, max(NN))
!>          VS contiene los vectores de Schur calculados.
!>

LDVS

!>          LDVS es INTEGER
!>          Dimensión principal de VS. Debe ser al menos max(1,max(NN)).
!>

VS1

!>          VS1 es un array DOUBLE PRECISION, dimensión (LDVS, max(NN))
!>          VS1 contiene otra copia de los vectores de Schur calculados.
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (17)
!>          Los valores calculados por las 17 pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar desbordamiento.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          El número de entradas en WORK. Este debe ser al menos
!>          max(3*NN(j),2*NN(j)**2) para todos j.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (max(NN)*max(NN))
!>

BWORK

!>          BWORK es un array LOGICAL, dimensión (max(NN))
!>

INFO

!>          INFO es INTEGER
!>          Si 0,  salida exitosa.
!>            <0,  el parámetro de entrada -INFO es incorrecto
!>            >0,  DLATMR, SLATMS, SLATME o DGET24 devolvieron un código
!>                 de error y INFO es su valor absoluto
!>
!>-----------------------------------------------------------------------
!>
!>     Algunas Variables y Parámetros Locales:
!>     ---- ----- --------- --- ----------
!>     ZERO, ONE       Real 0 y 1.
!>     MAXTYP          El número de tipos definidos.
!>     NMAX            El valor más grande en NN.
!>     NERRS           El número de pruebas que han excedido THRESH
!>     COND, CONDS,
!>     IMODE           Valores a pasar a los generadores de matrices.
!>     ANORM           Norma de A; pasada a los generadores de matrices.
!>
!>     OVFL, UNFL      Umbrales de desbordamiento y desbordamiento inferior.
!>     ULP, ULPINV     Precisión relativa más fina y su inversa.
!>     RTULP, RTULPI   Raíces cuadradas de los 4 valores anteriores.
!>             Los siguientes cuatro arrays decodifican JTYPE:
!>     KTYPE(j)        El tipo general (1-10) para el tipo .
!>     KMODE(j)        El valor MODE a pasar al generador de
!>                     matrices para el tipo .
!>     KMAGN(j)        El orden de magnitud ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!>     KCONDS(j)       Selecciona si CONDS debe ser 1 o
!>                     1/sqrt(ulp).  (0 significa irrelevante.)
!>
