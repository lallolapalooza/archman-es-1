DDRESCUELOG(1) Comandos de Usuario DDRESCUELOG(1)

NOMBRE

ddrescuelog - herramienta para archivos de mapa de ddrescue

SINOPSIS

ddrescuelog [opciones] archivo-mapa

DESCRIPCIÓN

GNU ddrescuelog es una herramienta que manipula archivos de mapa de ddrescue, muestra el contenido de los archivos de mapa, convierte archivos de mapa a/desde otros formatos, compara archivos de mapa, prueba el estado de recuperación y puede eliminar un archivo de mapa si la recuperación está hecha. Las operaciones de ddrescuelog pueden ser restringidas a una o varias partes del archivo de mapa si se usan las opciones de configuración de dominio.

Use un guion '-' como archivo de mapa para leer el archivo de mapa desde la entrada estándar (también en las opciones que toman un argumento de archivo de mapa) o para escribir el archivo de mapa creado por '--create-mapfile' a la salida estándar.

NOTA: En versiones de ddrescue anteriores a la 1.20, el archivo de mapa se llamaba 'logfile'. El formato es el mismo; solo ha cambiado el nombre.

OPCIONES

-h, --help
mostrar esta ayuda y salir
-V, --version
mostrar información de versión y salir
-a, --change-types=<ot>,<nt>
cambiar los tipos de bloque del archivo de mapa
-A, --annotate-mapfile
añadir comentarios con posiciones/tamaños legibles
-b, --block-size=<bytes>
tamaño del bloque (sector) en bytes [por defecto 512]
-B, --binary-prefixes
mostrar multiplicadores binarios en números [SI]
-c, --create-mapfile[=<tt>]
crear archivo de mapa a partir de una lista de bloques [+-]
-C, --complete-mapfile[=<t>]
completar archivo de mapa añadiendo bloques del tipo t [?]
-d, --delete-if-done
eliminar el archivo de mapa si la recuperación está terminada
-D, --done-status
devolver 0 si la recuperación está terminada
-f, --force
sobrescribir archivos de salida existentes
-F, --format=<nombre>
formato para -c y -l (list, bitmap-[bl]e)
-i, --input-position=<bytes>
posición de inicio del dominio de recuperación [0]
-l, --list-blocks=<tipos>
imprimir números de bloque de los tipos dados (?*/-+)
-L, --loose-domain
aceptar archivo de mapa de dominio desordenado con huecos
-m, --domain-mapfile=<archivo>
restringir el dominio a bloques terminados en <archivo>
-n, --invert-mapfile
invertir tipos de bloque (terminado <--> otros)
-o, --output-position=<bytes>
posición de salida en el archivo de salida [ipos]
-p, --compare-mapfile=<archivo>
comparar tipos de bloque en el dominio de ambos archivos
-P, --compare-as-domain=<archivo>
similar a -p pero compara solo bloques terminados
-q, --quiet
suprimir todos los mensajes
-s, --size=<bytes>
tamaño máximo del dominio de recuperación a procesar
-t, --show-status
mostrar un resumen del contenido del archivo de mapa
-v, --verbose
ser detallado (un segundo -v da más información)
-x, --xor-mapfile=<archivo>
hacer XOR de los bloques terminados en el archivo con el archivo de mapa
-y, --and-mapfile=<archivo>
hacer AND de los bloques terminados en el archivo con el archivo de mapa
-z, --or-mapfile=<archivo>
hacer OR de los bloques terminados en el archivo con el archivo de mapa
--shift
desplazar todas las posiciones de bloque por (opos - ipos)

Los números pueden estar en decimal, hexadecimal u octal, y pueden ir seguidos de un multiplicador: s = sectores, k = 1000, Ki = 1024, M = 10^6, Mi = 2^20, etc...

Estado de salida: 0 para una salida normal, 1 para problemas ambientales (archivo no encontrado, opciones de línea de comandos inválidas, errores de E/S, etc.), 2 para indicar un archivo de entrada corrupto o inválido, 3 para un error de consistencia interna (por ejemplo, un error) que provocó que ddrescuelog entrara en pánico.
