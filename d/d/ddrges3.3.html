DDRGES

3

Propósito

: 
!>
!> DDRGES3 comprueba el controlador del problema de valores propios generalizados no simétricos (forma de Schur)
!> DGGES3.
!>
!> DGGES3 factoriza A y B como Q S Z'  y Q T Z' , donde ' significa
!> transpuesta, T es triangular superior, S está en forma de Schur generalizada
!> (triangular por bloques superior, con bloques de 1x1 y 2x2 en la diagonal,
!> los bloques de 2x2 corresponden a pares de valores propios generalizados
!> complejos conjugados), y Q y Z son ortogonales. También
!> calcula los valores propios generalizados (alpha(j),beta(j)), j=1,...,n,
!> Así, w(j) = alpha(j)/beta(j) es una raíz de la ecuación
!> característica
!>                 det( A - w(j) B ) = 0
!> Opcionalmente también reordena los valores propios de modo que un
!> grupo seleccionado de valores propios aparece en el bloque diagonal inicial de
!> las formas de Schur.
!>
!> Cuando se llama a DDRGES3, se especifica un número de matrices  () y un
!> número de matrices . Para cada tamaño ()
!> y cada TIPO de matriz, se generará un par de matrices (A, B)
!> y se usará para las pruebas. Para cada par de matrices, se realizarán
!> las siguientes 13 pruebas y se compararán con el umbral THRESH excepto
!> las pruebas (5), (11) y (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!>
!> (5)   si A está en forma de Schur (es decir, forma cuasitriangular)
!>       (sin ordenación de valores propios)
!>
!> (6)   si los valores propios = bloques diagonales de la forma de Schur (S, T),
!>       es decir, probar el máximo sobre j de D(j)  donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       y S y T son aquí los bloques diagonales de 2 x 2 de S y T
!>       correspondientes a los valores propios j-ésimo y (j+1)-ésimo.
!>       (sin ordenación de valores propios)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( | (A,B) | n ulp )
!>            (con ordenación de valores propios).
!>
!> (8)   | I - QQ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (10)  si A está en forma de Schur (es decir, forma cuasitriangular)
!>       (con ordenación de valores propios).
!>
!> (11)  si los valores propios = bloques diagonales de la forma de Schur (S, T),
!>       es decir, probar el máximo sobre j de D(j)  donde:
!>
!>       si alpha(j) es real:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       si alpha(j) es complejo:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       y S y T son aquí los bloques diagonales de 2 x 2 de S y T
!>       correspondientes a los valores propios j-ésimo y (j+1)-ésimo.
!>       (con ordenación de valores propios).
!>
!> (12)  si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron SELECCIONados.
!>
!> Matrices de Prueba
!> ==================
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices nulas)
!>
!> (2)  ( I, 0 )         (una matriz identidad y una matriz nula)
!>
!> (3)  ( 0, I )         (una matriz identidad y una matriz nula)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad de k x k y J un bloque de Jordan
!>                       de (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz
!>                       diagonal con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  está cerca del desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas aleatorias O(1) por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de la máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorios.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares
!>                         superiores aleatorias.
!>
!
>

Parámetro

s
NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero,
!>          DDRGES3 no hace nada. NSIZES >= 0.
!
>

N

N 
!>          NN es un array de tipo INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos. NN >= 0.
!
>

NTYPE

S 
!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, DDRGES3
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que consiste en usar la matriz que haya en A en la entrada.
!>          Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!
>

DOTYP

E 
!>          DOTYPE es un array de tipo LOGICAL, dimensión (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se
!>          generará una matriz de ese tamaño y de tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARÁMETRO MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no serán generados. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!>          serán ignorados.
!
>

ISEE

D 
!>          ISEED es un array de tipo INTEGER, dimensión (4)
!>          En la entrada, ISEED especifica la semilla del generador de
!>          números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, serán reducidos módulo 4096. Además, ISEED(4) debe
!>          ser impar. El generador de números aleatorios usa una secuencia
!>          congruencial lineal limitada a enteros pequeños, y por lo tanto
!>          debería producir números aleatorios independientes de la máquina. Los
!>          valores de ISEED se modifican en la salida, y pueden usarse en la
!>          siguiente llamada a DDRGES3 para continuar la misma secuencia de
!>          números aleatorios.
!
>

THRES

H 
!>          THRESH es DOUBLE PRECISION
!>          Una prueba se considerará fallida si el error, calculado como
!>          se describe arriba, supera THRESH. Nótese que el error está
!>          escalado para ser O(1), por lo que THRESH debería ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100. En particular, no
!>          debería depender de la precisión (simple vs. doble) ni del tamaño
!>          de la matriz. THRESH >= 0.
!
>

NOUNI

T 
!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (p. ej., si una rutina devuelve IINFO distinto de 0.)
!
>

A 
!>          A es un array de tipo DOUBLE PRECISION,
!>                                       dimensión(LDA, max(NN))
!>          Usado para contener la matriz A original. Se usa solo como
!>          entrada si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal de A, B, S y T.
!>          Debe ser al menos 1 y al menos max( NN ).
!
>

B 
!>          B es un array de tipo DOUBLE PRECISION,
!>                                       dimensión(LDA, max(NN))
!>          Usado para contener la matriz B original. Se usa solo como
!>          entrada si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y
!>          DOTYPE(MAXTYP+1)=.TRUE.
!
>

S 
!>          S es un array de tipo DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          La matriz de forma de Schur calculada a partir de A por DGGES3. En la salida, S
!>          contiene la matriz de forma de Schur correspondiente a la matriz
!>          en A.
!
>

T 
!>          T es un array de tipo DOUBLE PRECISION, dimensión (LDA, max(NN))
!>          La matriz triangular superior calculada a partir de B por DGGES3.
!
>

Q 
!>          Q es un array de tipo DOUBLE PRECISION, dimensión (LDQ, max(NN))
!>          La matriz ortogonal (izquierda) calculada por DGGES3.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal de Q y Z. Debe
!>          ser al menos 1 y al menos max( NN ).
!
>

Z 
!>          Z es un array de tipo DOUBLE PRECISION, dimensión( LDQ, max(NN) )
!>          La matriz ortogonal (derecha) calculada por DGGES3.
!
>

ALPHA

R 
!>          ALPHAR es un array de tipo DOUBLE PRECISION, dimensión (max(NN))
!
>

ALPHA

I 
!>          ALPHAI es un array de tipo DOUBLE PRECISION, dimensión (max(NN))
!
>

BET

A 
!>          BETA es un array de tipo DOUBLE PRECISION, dimensión (max(NN))
!>
!>          Los eigenvalores generalizados de (A,B) calculados por DGGES3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) es el k-ésimo
!>          eigenvalor generalizado de A y B.
!
>

WOR

K 
!>          WORK es un array de tipo DOUBLE PRECISION, dimensión (LWORK)
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= MAX( 10*(N+1), 3*N*N ), donde N es la mayor
!>          dimensión de matriz.
!
>

RESUL

T 
!>          RESULT es un array de tipo DOUBLE PRECISION, dimensión (15)
!>          Los valores calculados por las pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar desbordamiento.
!
>

BWOR

K 
!>          BWORK es un array de tipo LOGICAL, dimensión (N)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  una rutina devolvió un código de error. INFO es el
!>                valor absoluto del valor INFO devuelto.
!
>
