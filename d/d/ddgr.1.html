DDGR(1) Comandos de usuario DDGR(1)

NOMBRE

ddgr - Buscar en DuckDuckGo desde la terminal

SINOPSIS

ddgr [OPCIONES] [PALABRA_CLAVE [PALABRA_CLAVE ...]]

DESCRIPCIÓN

ddgr es una herramienta de línea de comandos para buscar en DuckDuckGo (versión html). ddgr muestra el título, la URL y el contexto de texto de cada resultado. Los resultados se obtienen por páginas. Hay atajos de teclado disponibles para la navegación entre páginas. Los resultados se indexan y se puede abrir una URL de resultado en un navegador usando el número de índice. No hay archivo de configuración, ya que los alias cumplen la misma función para esta utilidad. Soporta búsquedas secuenciales en una sola instancia.

Características


* Rápido y limpio; color personalizado
* Diseñado para máxima legibilidad con espacio mínimo
* Respuestas instantáneas (soportado por la versión html de DDG)
* Número personalizado de resultados por página
* Navegación, integración con navegador
* Scripts de autocompletado de búsqueda y opciones (Bash, Fish, Zsh)
* Bangs de DuckDuckGo (junto con autocompletado)
* Abrir el primer resultado en el navegador (Me siento con suerte)
* REPL para búsquedas continuas
* Palabras clave (por ejemplo, `filetype:mime`, `site:somesite.com`)
* Limitar búsqueda por tiempo, especificar región, deshabilitar búsqueda segura
* Soporte de proxy HTTPS, opcionalmente deshabilitar User Agent
* Do Not Track activado por defecto
* Soporta script de manejador de URL personalizado o utilidad de línea de comandos
* Documentación exhaustiva, página man con ejemplos
* Dependencias mínimas

OPCIONES

-h, --help
Mostrar texto de ayuda y salir.
-n, --num=N
Mostrar N resultados por página (por defecto 10). N debe estar entre 0 y 25. N=0 deshabilita la paginación fija y muestra el número real de resultados obtenidos por página.
-r, --reg=REG
Búsqueda específica de región, por ejemplo 'us-en' para EE. UU. (por defecto); visita https://duckduckgo.com/params.
-C, --nocolor
Deshabilitar la salida en color.
--colors=COLORES
Establecer los colores de salida. Consulta la sección COLORES más abajo para más detalles.
-j, --ducky
Abrir el primer resultado en un navegador web; implica --noprompt. ¿Te sientes con suerte?
-t, --time=PERIODO
Limitar la búsqueda por tiempo [d=último día, w=última semana, m=último mes, y=último año] (por defecto=cualquier momento).
-w, --site=SITIO
Buscar en un sitio usando DuckDuckGo.
-x, --expand
Expandir las URLs en lugar de mostrar solo el nombre de dominio (por defecto).
-p, --proxy=URI
Tunelizar el tráfico a través de un proxy HTTP. URI es de la forma [http[s]://][usuario:contraseña@]host[:puerto]. El servidor proxy debe soportar el tunelizado HTTP CONNECT y no debe bloquear el puerto 443 para los hosts de DuckDuckGo relevantes. Si no se proporciona un proxy explícitamente, se utilizará la variable de entorno https_proxy o HTTPS_PROXY (si está disponible) en su lugar.
--unsafe
Deshabilitar la búsqueda segura.
--noua
Deshabilitar el agente de usuario. Los resultados se obtienen más rápido.
--json
Salida en formato JSON; implica --noprompt.
--gb, --gui-browser
Abrir un bang directamente en un navegador gráfico.
--np, --noprompt
Realizar la búsqueda y salir; no pedir más interacciones.
--rev, --reverse
Listar las entradas en orden inverso.
--url-handler=UTIL
Script personalizado o utilidad de línea de comandos para abrir URLs con.
--show-browser-logs
No suprimir la salida del navegador al abrir un resultado en el navegador; es decir, conectar stdout y stderr del navegador a stdout y stderr de ddgr en lugar de /dev/null. Por defecto, la salida del navegador se suprime (debido a que ciertos navegadores gráficos emiten mensajes a la consola) a menos que la variable de entorno BROWSER sea un navegador de texto conocido: elinks, links, lynx, w3m o www-browser.
-v, --version
Mostrar el número de versión y salir.
-d, --debug
Habilitar depuración.

TECLAS DE OMNIPROMMPT

n, p, f
Obtener el siguiente, el anterior o el primer conjunto de resultados de búsqueda.
índice
Abrir el resultado correspondiente al índice en el navegador.
o [índice|rango|t ...]
Abrir índices de resultados separados por espacios, rangos numéricos o todos los índices, si se especifica 't', en el navegador.
O [índice|rango|t ...]
Funciona de manera similar a la tecla 'o', pero intenta ignorar los navegadores de texto (incluso si BROWSER está configurado) y abre los enlaces en un navegador gráfico.
d palabras_clave
Iniciar una nueva búsqueda en DuckDuckGo para palabras_clave con las opciones originales. Esta tecla debe usarse para buscar teclas de omniprompt (incluyéndose a sí misma) e índices.
x
Alternar la expansión de URL.
c índice
Copiar la URL al portapapeles.
q, ^D, doble Enter
Salir de ddgr.
?
Mostrar la ayuda de omniprompt.
*
Cualquier otra cadena inicia una nueva búsqueda con las opciones originales.

COLORES

ddgr te permite personalizar el esquema de colores a través de una cadena de seis letras, recordando a LSCOLORS de BSD. Las seis letras representan los colores de

-
índices
-
títulos
-
URLs
-
metadatos/información de publicación
-
resúmenes
-
prompts
respectivamente. La cadena de seis letras se pasa como argumento a la opción --colors, o como el valor de la variable de entorno DDGR_COLORS.
Ofrecemos los siguientes colores/estilos:
Letra Color/Estilo
a negro
b rojo
c verde
d amarillo
e azul
f magenta
g cian
h blanco
i negro brillante
j rojo brillante
k verde brillante
l amarillo brillante
m azul brillante
n magenta brillante
o cian brillante
p blanco brillante
B negrita
U subrayado
_ ninguno
La cadena predeterminada es hVd.Vf.

EJEMPLOS

Buscar 'arch linux' y mostrar 5 resultados por página:

$ ddgr -n 5 arch linux

Buscar en el sitio de Arch Linux:

$ ddgr -w archlinux.org arch linux

Buscar resultados publicados en la última semana:

$ ddgr -t w arch linux

Abrir el primer resultado en el navegador:

$ ddgr -j arch linux

Usar un proxy para la búsqueda:

$ ddgr -p http://user:pass@proxy.example.com:8080 arch linux

Deshabilitar búsqueda segura y usar una región específica:

$ ddgr --unsafe -r de-de arch linux

Cambiar los colores de salida:

$ ddgr --colors=Kbl_V_ arch linux

Salida JSON (sin prompt interactivo):

$ ddgr --json arch linux

Búsqueda continua (REPL):

$ ddgr
luego escribe tus consultas y pulsa Enter. Usa 'q' para salir.

Abrir múltiples resultados (índices 1 y 3-5):

$ ddgr arch linux
luego dentro de ddgr escribe: o 1 3-5

Abrir todos los resultados en un navegador gráfico:

$ ddgr arch linux
luego dentro de ddgr escribe: O a

CONFIGURACIÓN

No hay archivo de configuración. Las opciones pueden ser establecidas mediante variables de entorno (mayúsculas):

DDGR_COLORS
Permite personalizar la cadena de colores. Véase la sección COLORS.
HTTPS_PROXY
Define el proxy a usar para conexiones HTTPS. Véase la opción --proxy.
BROWSER
Especifica el navegador a usar para abrir URLs. Véase la opción --show-browser-logs.
DDGR_URL_HANDLER
Especifica el script o utilidad para abrir URLs. Véase la opción --url-handler.
