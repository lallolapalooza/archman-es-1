Documentación de función/subrutina

subroutine dqlt02 (integer m, integer n, integer k, double precision, dimension( lda, * ) a, double precision, dimension( lda, * ) af, double precision, dimension( lda, * ) q, double precision, dimension( lda, * ) l, integer lda, double precision, dimension( * ) tau, double precision, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

DQLT02

Propósito:

!>
!> DQLT02 prueba DORGQL, que genera una matriz m por n, Q, con
!> columnas ortonormales que se define como el producto de k reflectores
!> elementales.
!>
!> Dada la factorización QL de una matriz A de m por n, DQLT02 genera
!> la matriz ortogonal Q definida por la factorización de las últimas k
!> columnas de A; compara L(m-n+1:m,n-k+1:n) con
!> Q(1:m,m-n+1:m)'*A(1:m,n-k+1:n), y verifica que las columnas de Q
!> son ortonormales.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q a generar.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q a generar.
!>          M >= N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          La matriz A de m por n factorizada por DQLT01.
!>

AF

!>          AF es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          Detalles de la factorización QL de A, como la devuelve DGEQLF.
!>          Ver DGEQLF para más detalles.
!>

Q

!>          Q es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>

L

!>          L es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A, AF, Q y L. LDA >= M.
!>

TAU

!>          TAU es un array DOUBLE PRECISION, de dimensión (N)
!>          Los factores escalares de los reflectores elementales correspondientes
!>          a la factorización QL en AF.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (M)
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, de dimensión (2)
!>          Las razones de prueba:
!>          RESULT(1) = norm( L - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
