NOMBRE

dqtool --- Muestra el contenido de un archivo de búfer de disco creado con {{ site.product.short_name }}.

Sinopsis

dqtool [comando] [opciones]

Descripción

NOTA: La aplicación dqtool se distribuye con la aplicación de registro del sistema syslog-ng OSE y normalmente forma parte del paquete syslog-ng OSE. La última versión de la aplicación syslog-ng OSE está disponible en la página de syslog-ng OSE.

Esta página del manual es solo un resumen.

La aplicación dqtool es una utilidad que se puede usar para mostrar y formatear los mensajes almacenados en un archivo de búfer de disco.

El comando cat

cat [opciones] [archivo]

Utilice el comando cat para mostrar los mensajes de registro almacenados en el archivo de búfer de disco (también llamado cola de disco), y también información de la cabecera del archivo de cola de disco. Los mensajes se imprimen en la salida estándar (stdout), por lo que es posible utilizar grep y otras herramientas para encontrar mensajes de registro particulares, por ejemplo, dqtool cat /var/log/messages.lgs |grep 192.168.1.1.

El comando cat tiene las siguientes opciones:

•
--debug o -d

Imprime mensajes de diagnóstico y depuración en stderr.

•
--help o -h

Muestra un breve mensaje de ayuda.

•
--template=<plantilla> o -t

Formatea los mensajes usando la plantilla especificada.

•
--verbose o -v

Imprime mensajes detallados en stderr.

•
--version o -V

Muestra información de la versión.

Ejemplo: El comando cat

./dqtool cat ../var/syslog-ng-00000.qf

La salida se ve así:

Disk-buffer state loaded; filename='../var/syslog-ng-00000.qf', qoutlength='65', qbackloglength='0', qoverflowlength='9205', qdisklength='0' Mar 3 10:52:05 tristram localprg[1234]: seq: 0000011630, runid: 1267609923, stamp: 2010-03-03T10:52:05 PADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADD Mar 3 10:52:05 tristram localprg[1234]: seq: 0000011631, runid: 1267609923, stamp: 2010-03-03T10:52:05 PADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADDPADD

El comando relocate

relocate [opciones] [archivos]

Utilice el comando relocate para mover o renombrar archivos de búfer de disco (también llamados colas de disco). Tenga en cuenta que esta opción modifica el archivo persistente. Detenga syslog-ng OSE antes de usar este comando.

El comando relocate tiene las siguientes opciones:

•
--all o -a

Reubica cada archivo de búfer de disco que aparece en el archivo persistente de syslog-ng OSE.

•
--new_path o -n

El directorio donde desea mover los archivos de búfer de disco. Por ejemplo: /var/disk-buffers

•
--persist o -p

La ruta al archivo persistente de syslog-ng OSE. El comando relocate actualiza automáticamente las entradas de los archivos de búfer de disco en el archivo persistente.

Ejemplos

Reubicar un único archivo de cola:

bin/dqtool relocate --new_path /tmp/dq --persist var/syslog-ng.persist /tmp/syslog-ng-00000.rqf

Reubicar múltiples archivos de cola:

bin/dqtool relocate --new_path /tmp/dq --persist var/syslog-ng.persist /tmp/syslog-ng-00000.rqf /tmp/syslog-ng-00001.rqf

Reubicar cada archivo de cola:

bin/dqtool relocate --new_path /tmp/dq --persist var/syslog-ng.persist --all
