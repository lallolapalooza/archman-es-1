DQRT17

Propósito:

!>
!> DQRT17 calcula la razón
!>
!>    norm(R**T * op(A)) / ( norm(A) * alpha * max(M,N,NRHS) * EPS ),
!>
!> donde R = B - op(A)*X, op(A) es A o A**T, dependiendo de TRANS, EPS
!> es la epsilon de la máquina, y
!>
!>    alpha = norm(B) si IRESID = 1 (problema de residuo cero)
!>    alpha = norm(R) si IRESID = 2 (en caso contrario).
!>
!> La norma utilizada es la norma 1.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica si se utiliza la transpuesta de A o no.
!>          = 'N':  Sin transpuesta, op(A) = A.
!>          = 'T':  Transpuesta, op(A) = A**T.
!>

IRESID

!>          IRESID es INTEGER
!>          IRESID = 1 indica problema de residuo cero.
!>          IRESID = 2 indica residuo no cero.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.
!>          Si TRANS = 'N', el número de filas de la matriz B.
!>          Si TRANS = 'T', el número de filas de la matriz X.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.
!>          Si TRANS = 'N', el número de filas de la matriz X.
!>          Si TRANS = 'T', el número de filas de la matriz B.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X y B.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= M.
!>

X

!>          X es un array de DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si TRANS = 'N', la matriz X de n por nrhs.
!>          Si TRANS = 'T', la matriz X de m por nrhs.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.
!>          Si TRANS = 'N', LDX >= N.
!>          Si TRANS = 'T', LDX >= M.
!>

B

!>          B es un array de DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          Si TRANS = 'N', la matriz B de m por nrhs.
!>          Si TRANS = 'T', la matriz B de n por nrhs.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.
!>          Si TRANS = 'N', LDB >= M.
!>          Si TRANS = 'T', LDB >= N.
!>

C

!>          C es un array de DOUBLE PRECISION, dimensión (LDB,NRHS)
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= NRHS*(M+N).
!>
