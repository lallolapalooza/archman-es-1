NOMBRE

dune-config - configuración del sistema de compilación dune

SINOPSIS

~/.config/dune/config

DESCRIPCIÓN

A menos que se pase --no-config o -p, Dune leerá un archivo de configuración del directorio de inicio del usuario. Este archivo se utiliza para controlar varios aspectos del comportamiento de Dune.

El archivo de configuración es normalmente ~/.config/dune/config en sistemas Unix y Local Settings/dune/config en el directorio de inicio del usuario en Windows. Sin embargo, es posible especificar un archivo de configuración alternativo con la opción --config-file.

La primera línea del archivo debe tener el formato (lang dune X.Y) donde X.Y es la versión del lenguaje dune utilizada en el archivo.

El resto del archivo debe estar escrito en sintaxis S-expression y estar compuesto por una lista de estancias. Las siguientes secciones describen las estancias disponibles.

CACHÉ

Sintaxis: (cache ENABLED)


Esta estancia determina si la caché de compilación de dune está habilitada. Ver https://dune.readthedocs.io/en/stable/caching.html para más detalles. Los valores válidos para ENABLED son enabled o disabled.

MODOS DE PANTALLA

Sintaxis: (display MODE)

Esta estancia controla cómo Dune informa al usuario de lo que está haciendo. Este parámetro también se puede establecer desde la línea de comandos mediante --display MODE. Los siguientes modos de pantalla están disponibles:

progress
Este es el valor predeterminado, Dune muestra y actualiza una línea de estado a medida que se completan los objetivos de compilación.
quiet
Solo mostrar errores.
short
Imprimir una línea por comando que se está ejecutando, con el nombre del binario a la izquierda y la razón por la que se está ejecutando a la derecha.
verbose
Imprimir las líneas de comandos completas de los programas que está ejecutando Dune, con algunos colores para ayudar a diferenciar los programas.

Tenga en cuenta que cuando el modo de pantalla seleccionado es progress y la salida no es una terminal, entonces se selecciona el modo quiet en su lugar. Esta regla no se aplica cuando se ejecuta Dune dentro de Emacs. Dune detecta si se está ejecutando desde dentro de Emacs o no mirando la variable de entorno INSIDE_EMACS que se establece por Emacs. Si desea el mismo comportamiento con otro editor, puede establecer esta variable. Si su editor ya establece otra variable, por favor abra un ticket en el proyecto ocaml/dune de GitHub para que podamos agregarle soporte.

TRABAJOS

Sintaxis: (jobs NUMBER)

Establece el número máximo de trabajos que Dune puede ejecutar en paralelo. Esto también se puede establecer desde la línea de comandos a través de -j NUMBER.

El valor predeterminado para este valor es el número de procesadores.

ENTORNOS AISLADOS

Sintaxis: (sandboxing_preference MODE ...)

Controla el orden de preferencia del modo de entorno aislado utilizado por dune. Dune utilizará el primer elemento de esta lista que esté permitido por la especificación de dependencias de la acción, o recurrirá al valor predeterminado codificado. Ver man dune-build para la descripción de los modos individuales.
