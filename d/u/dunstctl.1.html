NOMBRE

dunstctl - utilidad de control por línea de comandos para dunst

SINOPSIS

dunstctl COMANDO [PARÁMETRO]

COMANDOS

accion posición_notificación
Realiza la acción predeterminada o, si no está disponible, abre el menú contextual de la notificación en la posición dada (comenzando el conteo desde arriba, siendo la primera notificación 0).
cerrar [ID]
Cierra la notificación superior que se está mostrando actualmente. Opcionalmente, puedes pasar un ID para cerrar la notificación correspondiente (si está presente).
cerrar-todo
Cierra todas las notificaciones que se están mostrando actualmente.
contexto
Abre el menú contextual, presentando todas las acciones y URLs disponibles para las notificaciones abiertas actualmente.
contar [mostrando/historial/esperando]
Devuelve el número de notificaciones mostradas, en historial y en espera. Si no se proporciona ningún argumento, se imprimirá todo.
historial
Exporta el historial como JSON.
historial-limpiar
Elimina todas las notificaciones del historial.
historial-sacar [ID]
Vuelve a mostrar la notificación que se cerró más recientemente. Esto se puede llamar varias veces para mostrar notificaciones más antiguas, hasta el límite de historial configurado en dunst. Opcionalmente, puedes pasar un ID a historial-sacar, en cuyo caso se mostrará la notificación con ese ID.
historial-quitar ID
Elimina la notificación con el ID dado del historial.
esta-pausado
Comprueba si dunst se está ejecutando actualmente o está pausado. Si dunst está pausado, las notificaciones se guardarán pero no se mostrarán hasta que se reactive.
establecer-pausa verdadero/falso/alternar
Establece el estado de pausa de dunst. Si es falso, dunst se ejecuta normalmente, si es verdadero, dunst está pausado (con un nivel máximo de pausa de 100). Consulta el comando esta-pausado y la página del manual de dunst para obtener más información.
obtener-nivel-pausa
Obtiene el nivel de pausa actual de dunst, donde 0 es no pausado y 100 es máximamente pausado.

Esto se puede combinar con override_pause_level de la notificación para mostrar selectivamente notificaciones específicas mientras está en pausa.

establecer-nivel-pausa [nivel]
Establece el nivel de pausa, donde 0 es no pausado y 100 es máximamente pausado.

Esto se puede combinar con override_pause_level de la notificación para mostrar selectivamente notificaciones específicas mientras está en pausa.

regla nombre_regla habilitar/deshabilitar/alternar
Habilita, deshabilita o alterna la regla identificada por su nombre. Esto se puede usar para activar o desactivar temporalmente reglas específicas.
reglas [--json]
Exporta todas las reglas configuradas actualmente (opcionalmente en formato JSON).
recargar [dunstrc ...]
Recarga la configuración de la instancia de dunst en ejecución. Opcionalmente, puedes especificar qué archivos de configuración usar. De lo contrario, se recargará la configuración especificada por la primera invocación de dunst. Cuando dunst se recarga, todas las reglas se reaplican a la notificación original, por lo que no se tienen en cuenta las modificaciones realizadas por reglas anteriores.
depurar
Intenta contactar con dunst y comprueba fallos comunes entre dunstctl y dunst. Útil si algo no funciona.
ayuda
Muestra todos los comandos disponibles con una breve descripción.
