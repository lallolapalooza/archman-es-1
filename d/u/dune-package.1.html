DUNE-PACKAGE(1) Manual de Dune DUNE-PACKAGE(1)

NOMBRE

dune-package - Gestión experimental de paquetes

SINOPSIS

dune package COMANDO …

DESCRIPCIÓN

Comandos para la gestión de paquetes de OCaml

COMANDOS

habilitado [OPCIÓN]…
Comprueba si el proyecto indica que las funciones de gestión de paquetes de dune deben estar habilitadas. Sale con 0 si la gestión de paquetes está habilitada y con 1 en caso contrario.
lock [OPCIÓN]… [LOCKDIRS]…
Crea un archivo de bloqueo
outdated [OPCIÓN]… [LOCKDIRS]…
Comprueba si hay paquetes desactualizados
print-solver-env [OPCIÓN]… [LOCKDIRS]…
Imprime una descripción del entorno que se utilizaría para resolver dependencias y luego sale sin intentar resolver las dependencias ni generar el archivo de bloqueo. Diseñado para ser utilizado para depurar situaciones en las que no se encuentra una solución para las dependencias de un proyecto.
validate-lockdir [OPCIÓN]… [LOCKDIRS]…
Valida que un directorio de bloqueo contenga una solución para paquetes locales

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--help[=FMT] (predeterminado=auto)
Muestra esta ayuda en formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable de entorno TERM sea dumb o no esté definida.
--version
Muestra la información de la versión.

MÁS AYUDA

Usa `dune COMANDO --help' para obtener ayuda sobre un comando individual.

ESTADO DE SALIDA

dune package sale con:

0
en caso de éxito.
1
si ocurrió un error.
130
si fue interrumpido por una señal.

ERRORES

Consulta los informes de errores en https://github.com/ocaml/dune/issues
