NOMBRE

dub-dustmite - Crear casos de prueba reducidos para errores de compilación

SINOPSIS

dub dustmite <ruta-destino> OPCIONES... [-- <argumentos-aplicación...>]

DESCRIPCIÓN

Este comando utiliza la utilidad Dustmite para aislar la causa de los errores de compilación en un proyecto DUB.

Creará una copia de todos los paquetes involucrados y ejecutará dustmite en esta copia, dejando un caso de prueba reducido.

La determinación de la condición de error deseada se realiza comprobando el código de estado del compilador/enlazador, así como su salida (stdout y stderr combinados). Si se proporcionan --program-status o --program-regex y el binario generado es un ejecutable, se ejecutará y su salida también se incorporará a la decisión final.

OPCIONES

--compiler-status=VALOR

El código de estado esperado de la ejecución del compilador

--compiler-regex=VALOR

Una expresión regular utilizada para coincidir con la salida del compilador

--linker-status=VALOR

El código de estado esperado de la ejecución del enlazador

--linker-regex=VALOR

Una expresión regular utilizada para coincidir con la salida del enlazador

--program-status=VALOR

El código de estado esperado del ejecutable compilado

--program-regex=VALOR

Una expresión regular utilizada para coincidir con la salida del programa

--test-package=VALOR

Realizar una ejecución de prueba - generalmente solo se usa internamente

--combined

Compila múltiples paquetes con una única ejecución de compilador

--no-redirect

No redirigir los flujos de stdout/stderr del comando de prueba

--strategy=VALOR

Establecer la estrategia (careful/lookback/pingpong/indepth/inbreadth)

-j

Establecer el número de procesos de previsualización

--trace

Guardar todas las reducciones intentadas en DIR.trace

-b, --build=VALOR

Especifica el tipo de compilación a realizar. Tenga en cuenta que establecer la variable de entorno DFLAGS anulará el tipo de compilación con banderas personalizadas. Nombres posibles:
debug, plain, release, release-debug, release-nobounds, unittest, profile, profile-gc, docs, ddox, cov, cov-ctfe, unittest-cov, unittest-cov-ctfe, syntax y tipos personalizados

-c, --config=VALOR

Compila la configuración especificada. Las configuraciones se pueden definir en dub.json

--override-config=VALOR

Utiliza la configuración especificada para una dependencia determinada. Se puede especificar varias veces. Formato: --override-config=<dependencia>/<configuración>

--compiler=VALOR

Especifica el binario del compilador a utilizar (puede ser una ruta). Se reconocen prefijos y sufijos arbitrarios a los identificadores a continuación (por ejemplo, ldc2 o dmd-2.063) y se emparejan con el tipo de compilador correcto:
dmd, gdc, ldc, gdmd, ldmd

-a, --arch=VALOR

Forzar una arquitectura diferente (por ejemplo, x86 o x86_64)

-d, --debug=VALOR

Define el identificador de versión `debug` especificado al compilar - se puede usar varias veces

--d-version=VALOR

Define el identificador de `version` especificado al compilar - se puede usar varias veces. ¡Úselo con moderación, un gran poder conlleva una gran responsabilidad! Para versiones comúnmente usadas o combinadas y versiones que los dependientes deban poder usar, cree configuraciones en su paquete.

--nodeps

No resuelva las dependencias faltantes antes de compilar

--build-mode=VALOR

Especifica la forma en que se invocan el compilador y el enlazador. Valores válidos:
separate (predeterminado), allAtOnce, singleFile

--single

Trata el nombre del paquete como un nombre de archivo. El archivo debe contener un comentario de receta de paquete.

--force-remove

Opción obsoleta que no hace nada.

--filter-versions

[Experimental] Filtra los identificadores de versión y los identificadores de versión de depuración para mejorar la eficiencia de la caché de compilación.
