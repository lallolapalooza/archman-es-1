Dumpvalue(3perl) Guía de referencia del programador de Perl Dumpvalue(3perl)

NOMBRE

Dumpvalue - proporciona volcado de pantalla de datos de Perl.

SINOPSIS

use Dumpvalue;
my $dumper = Dumpvalue->new;
$dumper->set(globPrint => 1);
$dumper->dumpValue(\*::);
$dumper->dumpvars('main');
my $dump = $dumper->stringify($some_value);

DESCRIPCIÓN

Creación

Se crea un nuevo volcador mediante una llamada

$d = Dumpvalue->new(option1 => value1, option2 => value2)

Opciones reconocidas:

"arrayDepth", "hashDepth"
Imprime solo los primeros N elementos de arrays y hashes. Si es falso, imprime todos los elementos.
"compactDump", "veryCompact"
Cambia el estilo del volcado de arrays y hashes. Si es verdadero, un array corto puede imprimirse en una línea.
"globPrint"
Si imprimir o no el contenido de los globs.
"dumpDBFiles"
Vuelca arrays que contienen los contenidos de archivos depurados.
"dumpPackages"
Vuelca tablas de símbolos de paquetes.
"dumpReused"
Vuelca el contenido de direcciones "reutilizadas".
"tick", "quoteHighBit", "printUndef"
Cambia el estilo del volcado de cadenas. El valor predeterminado de "tick" es "auto", se puede habilitar el volcado estilo comillas dobles o comillas simples estableciéndolo a """ o "'". Por defecto, los caracteres con el bit alto establecido se imprimen *tal cual*. Si "quoteHighBit" está establecido, se citarán.
"usageOnly"
Volcado rudimentario de uso de memoria por paquete. Si está establecido, "dumpvars" calcula el tamaño total de las cadenas en las variables del paquete.
unctrl
Cambia el estilo de impresión de cadenas. Los valores posibles son "unctrl" y "quote".
subdump
Si intentar encontrar el nombre de la subrutina dado una referencia.
bareStringify
Si escribir la forma no sobrecargada de los objetos con stringify sobrecargado.
quoteHighBit
Si imprimir caracteres con el bit alto establecido en binario o "tal cual".
stopDbSignal
Si abortar la impresión si la bandera de señal del depurador está activada.

Más tarde en la vida del objeto, los métodos pueden ser consultados con el método get() y el método set() (que aceptan múltiples argumentos).

Métodos

dumpValue
$dumper->dumpValue($value);
$dumper->dumpValue([$value1, $value2]);

Imprime un volcado en el manejador de archivo actualmente seleccionado.

dumpValues
$dumper->dumpValues($value1, $value2);

Igual que "$dumper->dumpValue([$value1, $value2]);".

stringify
my $dump = $dumper->stringify($value [,$noticks] );

Devuelve el volcado de un solo escalar sin imprimir. Si el segundo argumento es verdadero, el valor de retorno no contiene comillas envolventes. No maneja estructuras de datos.

dumpvars
$dumper->dumpvars('mi_paquete');
$dumper->dumpvars('mi_paquete', 'foo', '~bar$', '!......');

Los argumentos opcionales se consideran cadenas literales a menos que comiencen con "~" o "!", en cuyo caso se interpretan como expresiones regulares (posiblemente negadas).

El segundo ejemplo imprime entradas con nombres "foo", y también entradas con nombres que terminan en "bar", o son más cortas que 5 caracteres.

set_quote
$d->set_quote('"');

Establece las opciones "tick" y "unctrl" a valores adecuados para la impresión con el carácter de cita dado. Los valores posibles son "auto", "'" y """.

set_unctrl
$d->set_unctrl('unctrl');

Establece la opción "unctrl" con verificación de argumento inválido. Los valores posibles son "unctrl" y "quote".

compactDump
$d->compactDump(1);

Establece la opción "compactDump". Si el valor es 1, se establece a un número grande razonable.

veryCompact
$d->veryCompact(1);

Establece las opciones "compactDump" y "veryCompact" simultáneamente.

set
$d->set(option1 => value1, option2 => value2);
get
@values = $d->get('option1', 'option2');
