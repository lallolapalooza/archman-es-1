DUMPSEG(8) Manual del Administrador del Sistema DUMPSEG(8)

NOMBRE

dumpseg - imprime información de segmentos de NILFS2

SINOPSIS

dumpseg [-hV]

dumpseg [dispositivo] número-de-segmento ...

DESCRIPCIÓN

El programa dumpseg es una herramienta de análisis para los registros en disco de un sistema de archivos NILFS2 que se encuentra en dispositivo. Muestra la configuración de cada registro almacenado en los segmentos especificados por uno o más números-de-segmento. El término segmento aquí significa un bloque contiguo de bloques de disco que representan una unidad de asignación de espacio en disco de NILFS2. Cuando se omite dispositivo, intenta encontrar un sistema de archivos NILFS2 activo en /proc/mounts.

dumpseg es una herramienta para depuración en lugar de administración. Para listar un resumen de segmentos, está disponible lssu(1) en su lugar.

OPCIONES

-h, --help
Muestra el mensaje de ayuda y sale.
-V, --version
Muestra la versión y sale.

DESCRIPCIÓN DE CAMPOS

dumpseg muestra la configuración de cada registro con los siguientes campos, donde cada campo se imprime en el estilo de ``nombre-del-campo = valor''.

tiempo de creación
Fecha y hora de creación del registro.
nfinfo
Número de resúmenes de información de archivos.
finfo
Resumen de información de archivos. Esta información comienza con los siguientes campos:
ino
Número de inodo del archivo.
cno
Número del punto de control al que pertenecen los bloques incluidos en el archivo. Para escrituras normales, este es igual al número del último punto de control. Para las escrituras involucradas en la recolección de basura, indica un número de punto de control anterior.
nblocks
Número de bloques del archivo escritos en el registro. Este número es la suma del número de bloques de datos y bloques de nodos B-tree. El contenido de estos bloques se escribe secuencialmente en la parte de carga útil del registro. Solo se escriben en cada registro los bloques modificados o recién creados.
ndatblk
Número de bloques de datos del archivo escritos en el registro.
Luego, para cada bloque de actualización en el archivo, seguirá la siguiente información bajo estos encabezados.
vblocknr
Número de bloque virtual. No se imprime para los bloques de datos del archivo de traducción de direcciones de disco (archivo DAT).
blkoff
Número de desplazamiento de bloque. No se imprime para los bloques de nodos B-tree, excepto para el archivo DAT.
level
Nivel del bloque del nodo B-tree. Se imprime solo para el archivo DAT.
blocknr
Dirección del bloque en el dispositivo. Este no es un campo real en el resumen, sino que se calcula a partir de la dirección del disco de cada registro.

AUTOR

Koji Sato

DISPONIBILIDAD
