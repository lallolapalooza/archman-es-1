NOMBRE

dumpelf - volcar la estructura interna de ELF

SINOPSIS

dumpelf [opciones] ELFs

DESCRIPCIÓN

dumpelf es una utilidad de espacio de usuario para volcar todas las estructuras internas de ELF en las estructuras C equivalentes para depuración o propósitos de referencia.

OPCIONES

-h, --help

Mostrar uso condensado y salir

-V, --version

Imprimir versión y salir

-v, --verbose

Ser verboso (se puede usar más de una vez)

PÁGINA DE INICIO
