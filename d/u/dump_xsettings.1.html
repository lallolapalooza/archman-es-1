NOMBRE

dump_xsettings - imprime la configuración de aplicaciones X11 de un proveedor de XSETTINGS

SINOPSIS

dump_xsettings [opciones]

DESCRIPCIÓN

La especificación XSETTINGS proporciona un método para notificar a las aplicaciones X11 sobre cambios en la configuración del sistema. dump_xsettings imprime la configuración actual de una pantalla X en el formato de archivo de configuración de xsettingsd(1).

OPCIONES

-h, --help
Muestra un mensaje de ayuda y sale.
-s, --screen=PANTALLA
Usa la pantalla X numerada PANTALLA (el valor predeterminado es 0).
