NOMBRE

dub-describe - Imprime una descripción JSON del proyecto y sus dependencias

SINOPSIS

dub describe [<paquete>[@<especificación-versión>]] OPCIONES...

DESCRIPCIÓN

Imprime una descripción de compilación JSON para el paquete raíz y todas sus dependencias en un formato similar a un archivo de descripción de paquete JSON. Esto es útil principalmente para IDEs.

Se aplican todas las opciones habituales que también se usan para compilar/ejecutar/generar.

Cuando se proporciona --data=VALOR, se mostrarán configuraciones de compilación específicas para un proyecto en su lugar (por defecto, formateado para el compilador actual).

La opción --data=VALOR se puede especificar varias veces para recuperar varias piezas de información a la vez. También se acepta una lista separada por comas (ej: --data=dflags,libs). Los datos se mostrarán en el mismo orden solicitado en la línea de comandos.

Los valores aceptados para --data=VALOR son:

main-source-file, dflags, lflags, libs, linker-files, source-files, versions, debug-versions, import-paths, string-import-paths, import-files, options

Los siguientes también son aceptados por --data si se usa --data-list:

target-type, target-path, target-name, working-directory, copy-files, string-import-files, pre-generate-commands, post-generate-commands, pre-build-commands, post-build-commands, pre-run-commands, post-run-commands, requirements

OPCIONES

-b, --build=VALOR

Especifica el tipo de compilación a realizar. Tenga en cuenta que establecer la variable de entorno DFLAGS anulará el tipo de compilación con indicaciones personalizadas. Nombres posibles:
debug, plain, release, release-debug, release-nobounds, unittest, profile, profile-gc, docs, ddox, cov, cov-ctfe, unittest-cov, unittest-cov-ctfe, syntax y tipos personalizados

-c, --config=VALOR

Compila la configuración especificada. Las configuraciones se pueden definir en dub.json

--override-config=VALOR

Utiliza la configuración especificada para una dependencia determinada. Se puede especificar varias veces. Formato: --override-config=<dependencia>/<configuración>

--compiler=VALOR

Especifica el binario del compilador a utilizar (puede ser una ruta). Se reconocen prefijos y sufijos arbitrarios a los identificadores a continuación (por ejemplo, ldc2 o dmd-2.063) y se emparejan con el tipo de compilador adecuado:
dmd, gdc, ldc, gdmd, ldmd

-a, --arch=VALOR

Fuerza una arquitectura diferente (por ejemplo, x86 o x86_64)

-d, --debug=VALOR

Define el identificador de versión `debug` especificado al compilar. Se puede usar varias veces

--d-version=VALOR

Define el identificador de `version` especificado al compilar. Se puede usar varias veces. ¡Úselo con moderación, un gran poder conlleva una gran responsabilidad! Para versiones usadas comúnmente o combinadas, y versiones que los dependientes puedan usar, cree configuraciones en su paquete.

--nodeps

No resuelva las dependencias faltantes antes de compilar

--build-mode=VALOR

Especifica la forma en que se invoca el compilador y el enlazador. Valores válidos:
separate (predeterminado), allAtOnce, singleFile

--single

Trata el nombre del paquete como un nombre de archivo. El archivo debe contener un comentario de receta de paquete.

--force-remove

Opción obsoleta que no hace nada.

--filter-versions

[Experimental] Filtra los identificadores de versión y los identificadores de versión de depuración para mejorar la eficiencia de la caché de compilación.

--import-paths

Atajo para --data=import-paths --data-list

--string-import-paths

Atajo para --data=string-import-paths --data-list

--data=VALOR

Simplemente lista los valores de una configuración de compilación particular, ya sea solo para este paquete o incluyendo recursivamente todas las dependencias. Acepta una lista separada por comas. Consulte arriba para obtener más detalles y posibilidades aceptadas para VALOR.

--data-list

Muestra la información de --data en formato de lista (línea por línea), en lugar de formatearla para una línea de comandos del compilador.

--data-0

Muestra la información de --data utilizando delimitadores nulos, en lugar de espacios o saltos de línea. El resultado se puede usar con, por ejemplo, xargs -0.

OPCIONES COMUNES

Vea dub(1)

ESTADO DE SALIDA

0
DUB tuvo éxito
1
errores de uso, flags de línea de comandos desconocidos
2
paquete no encontrado, el paquete no se pudo cargar, error misceláneo
