Dust(1) Manual de Comandos Generales Dust(1)

NOMBRE

Dust - Como du pero más intuitivo

SINOPSIS

dust [-d|--depth] [-T|--threads] [--config] [-n|--number-of-lines] [-p|--full-paths] [-X|--ignore-directory] [-I|--ignore-all-in-file] [-L|--dereference-links] [-x|--limit-filesystem] [-s|--apparent-size] [-r|--reverse] [-c|--no-colors] [-C|--force-colors] [-b|--no-percent-bars] [-B|--bars-on-right] [-z|--min-size] [-R|--screen-reader] [--skip-total] [-f|--filecount] [-i|--ignore-hidden] [-v|--invert-filter] [-e|--filter] [-t|--file-types] [-w|--terminal-width] [-P|--no-progress] [--print-errors] [-D|--only-dir] [-F|--only-file] [-o|--output-format] [-S|--stack-size] [-j|--output-json] [-M|--mtime] [-A|--atime] [-y|--ctime] [--files0-from] [--collapse] [-m|--filetime] [-h|--help] [-V|--version] [PATH]

DESCRIPCIÓN

Como du pero más intuitivo

OPCIONES

-d, --depth=PROFUNDIDAD
Profundidad a mostrar
-T, --threads=HILOS
Número de hilos a usar
--config=ARCHIVO
Especificar un archivo de configuración a usar
-n, --number-of-lines=NÚMERO
Número de líneas de salida a mostrar. (Por defecto es altura_terminal - 10)
-p, --full-paths
Los subdirectorios no tendrán su ruta acortada
-X, --ignore-directory=RUTA
Excluir cualquier archivo o directorio con esta ruta
-I, --ignore-all-in-file=ARCHIVO
Excluir cualquier archivo o directorio con una expresión regular que coincida con las listadas en este archivo, las entradas del archivo se añadirán a las expresiones regulares de exclusión proporcionadas por --invert_filter
-L, --dereference-links
desreferenciar enlaces simbólicos - Tratar los enlaces simbólicos como directorios y entrar en ellos
-x, --limit-filesystem
Contar solo los archivos y directorios en el mismo sistema de archivos que el directorio proporcionado
-s, --apparent-size
Usar la longitud del archivo en lugar de bloques
-r, --reverse
Imprimir el árbol al revés (el más grande arriba)
-c, --no-colors
No se imprimirán colores (Útil para comandos como: watch)
-C, --force-colors
Forzar la impresión de colores
-b, --no-percent-bars
No se mostrarán barras de porcentaje ni porcentajes
-B, --bars-on-right
Barras de porcentaje movidas al lado derecho de la pantalla
-z, --min-size=TAMAÑO_MINIMO
Tamaño mínimo de archivo para incluir en la salida
-R, --screen-reader
Para lectores de pantalla. Elimina barras. Añade una nueva columna: nivel de profundidad (Puede que quieras usar también -p para ruta completa)
--skip-total
No se mostrará la fila total
-f, --filecount
El 'tamaño' del directorio es el número de archivos hijos en lugar del tamaño en disco
-i, --ignore-hidden
No mostrar archivos ocultos
-v, --invert-filter=REGEX
Excluir rutas de archivo que coincidan con esta expresión regular. Para excluir archivos png escribe: -v "\.png$"
-e, --filter=REGEX
Incluir solo rutas de archivo que coincidan con esta expresión regular. Para archivos png escribe: -e "\.png$"
-t, --file-types
mostrar solo estos tipos de archivo
-w, --terminal-width=ANCHO
Especificar el ancho de la salida, anulando la detección automática del ancho de la terminal
-P, --no-progress
Deshabilitar la indicación de progreso
--print-errors
Imprimir rutas con errores
-D, --only-dir
Solo se mostrarán directorios
-F, --only-file
Solo se mostrarán archivos. (Encuentra tus archivos más grandes)
-o, --output-format=FORMATO
Cambia el tamaño de visualización de la salida. 'si' imprimirá tamaños en potencias de 1000. 'b', 'k', 'm', 'g', 't', 'kb', 'mb', 'gb', 'tb' imprimirán todo el árbol en ese tamaño

Valores posibles:

  • si: prefijo SI (potencias de 1000)
  • b: byte (B)
  • k: kibibyte (KiB)
  • m: mebibyte (MiB)
  • g: gibibyte (GiB)
  • t: tebibyte (TiB)
  • kb: kilobyte (kB)
  • mb: megabyte (MB)
  • gb: gigabyte (GB)
  • tb: terabyte (TB)
-S, --stack-size=TAMAÑO_STACK
Especificar memoria a usar como tamaño de pila (stack) - usar si ves: 'fatal runtime error: stack overflow' (memoria baja por defecto=1048576, memoria alta =1073741824)
-j, --output-json
Imprimir el árbol de directorios como json en el directorio actual
-M, --mtime=MTIME
+/-n coincide con archivos modificados hace más/menos de n días, y n coincide con archivos modificados exactamente hace n días, los días se redondean hacia abajo. Es decir, +n => (-inf, actual-(n+1)), n => [actual-(n+1), actual-n), y -n => [actual-n, +inf)
-A, --atime=ATIME
igual que -mtime, pero basado en el tiempo de acceso al archivo
-y, --ctime=CTIME
igual que -mtime, pero basado en el tiempo de cambio del archivo
--files0-from=FILES0_FROM
ejecutar dust en nombres de archivo terminados en NUL especificados en el archivo; si el argumento es -, entonces leer los nombres desde la entrada estándar
--collapse=COLLAPSE
Mantener estos directorios colapsados
-m, --filetime=FILETIME
El 'tamaño' del directorio es el tiempo máximo de archivo de los archivos hijos en lugar del tamaño en disco. mientras que a/c/m para el último tiempo de acceso/cambio/modificación

Valores posibles:

  • a: último tiempo de acceso
  • c: último tiempo de cambio
  • m: último tiempo de modificación
-h, --help
Imprimir ayuda (ver un resumen con '-h')
-V, --version
Imprimir versión
[PATH]
Archivos o directorios de entrada
