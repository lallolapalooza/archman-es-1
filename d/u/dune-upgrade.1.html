DUNE-UPGRADE(1) Manual de Dune DUNE-UPGRADE(1)

NOMBRE

dune-upgrade - Actualiza proyectos entre versiones principales de Dune.

SINOPSIS

dune upgrade [OPCIÓN]…

DESCRIPCIÓN

dune upgrade actualiza todos los proyectos del espacio de trabajo a la última versión principal de Dune

OPCIONES

--action-stderr-on-success=VAL
Igual que --action-stdout-on-success pero para la salida estándar de error en lugar de la salida estándar. Un buen valor por defecto para los grandes monorepositorios es --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Esto asegura que una compilación exitosa tenga una salida vacía y "limpia".
--action-stdout-on-success=VAL
Especifica cómo tratar la salida estándar de las acciones cuando tienen éxito. Los valores posibles son: print para simplemente imprimirlo en la salida de Dune, swallow para ignorarlo por completo y must-be-empty para hacer cumplir que la acción no imprimió nada. Con must-be-empty, Dune considerará que la acción falló si imprimió algo en su salida estándar. El valor por defecto es print.
--build-info
Muestra información de compilación.
--display-separate-messages
Separa los mensajes de error con una línea en blanco.
--error-reporting=VAL (ausente=deterministic)
Controla cuándo se informan los errores de compilación. early informa de los errores tan pronto como se descubren. deterministic informa de los errores al final de la compilación en un orden determinista. twice informa de cada error dos veces: una vez tan pronto como se descubre y luego de nuevo al final de la compilación, en un orden determinista.
-f, --force
Fuerza la reejecución de las acciones asociadas a los alias incluso si sus dependencias no han cambiado.
--file-watcher=VAL (ausente=automatic)
Mecanismo para detectar cambios en el código fuente. Automático para hacer que dune ejecute un programa externo para detectar cambios. Manual para notificar a dune que los archivos han cambiado manualmente.
--passive-watch-mode
Similar a [--watch], pero solo inicia una compilación cuando se le indica externamente mediante un RPC.
--sandbox=VAL (ausente DUNE_SANDBOX env)
Establece el modo de aislamiento (sandboxing). Algunas acciones requieren un cierto modo de aislamiento, por lo que ignorarán esta configuración. Los valores permitidos son: none, symlink, copy, hardlink.
--stop-on-first-error
Detiene la compilación tan pronto como se encuentra un error.
-w, --watch
En lugar de terminar la compilación después de completarse, espera continuamente cambios en los archivos.
--wait-for-filesystem-clock
Dune calcula el resumen (digest) del contenido de los archivos para una mejor incrementalidad. Estos resúmenes también están en caché. En algunos casos, Dune necesita descartar algunas entradas de la caché de resúmenes para que las cosas sean fiables. Esta opción hace que Dune espere a que avance el reloj del sistema de archivos para que no necesite descartar nada. Probablemente no debas preocuparte por esta opción; es principalmente útil para los desarrolladores de Dune para hacer que las pruebas de la caché de resúmenes de Dune sean más reproducibles.

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--always-show-command-line
Muestra siempre las líneas de comando completas de los programas ejecutados por dune.
--auto-promote
Promueve los archivos automáticamente. Esto es similar a ejecutar dune promote después de la compilación.
--build-dir=FILE (ausente DUNE_BUILD_DIR env)
Directorio de compilación especificado. _build si no se especifica
--cache=VAL (ausente DUNE_CACHE env)
Habilita o deshabilita la caché de Dune (uno de disabled, enabled-except-user-rules o enabled). El valor por defecto es `enabled-except-user-rules'.
--cache-check-probability=VAL (ausente DUNE_CACHE_CHECK_PROBABILITY env)
Comprueba la reproducibilidad de la compilación reejecutando reglas elegidas aleatoriamente y comparando sus resultados con los almacenados en la caché de Dune. Nota: al aumentar la probabilidad de tales comprobaciones, ralentizas la compilación. La probabilidad por defecto es cero, es decir, no se comprueba ninguna regla.
--cache-storage-mode=VAL (ausente DUNE_CACHE_STORAGE_MODE env)
Modo de almacenamiento de la caché de Dune (uno de auto, hardlink o copy). El valor por defecto es `hardlink'.
--config-file=FILE
Carga este archivo de configuración en lugar del predeterminado.
--debug-artifact-substitution
Imprime información de depuración sobre la sustitución de artefactos
--debug-backtraces
Imprime siempre las trazas de excepciones.
--debug-cache=VAL
Muestra mensajes de depuración en los fallos de caché (cache misses) para las capas de caché dadas. El valor es una lista de nombres de capas de caché separados por comas. Todas las capas de caché disponibles: shared,workspace-local,fs.
--debug-dependency-path
En caso de error, imprime la ruta de dependencia desde los objetivos de la línea de comando hasta la regla que falló.
--debug-digests
Explica por qué Dune decide volver a calcular el resumen de algunos archivos
--debug-load-dir
Imprime información de depuración sobre la carga de directorios
--debug-package-logs (ausente DUNE_DEBUG_PACKAGE_LOGS env)
Imprime siempre los registros estándar al compilar paquetes
--default-target=TARGET (ausente=@@default)
Establece el objetivo predeterminado que se usa cuando no se especifica ninguno para dune build.
--diff-command=VAL (ausente DUNE_DIFF_COMMAND env)
Comando de shell para usar para comparar archivos. Usa - para deshabilitar la impresión de la diferencia.
--disable-promotion (ausente DUNE_DISABLE_PROMOTION env)
Deshabilita todas las reglas de promoción
--display=MODE
Controla el modo de visualización de Dune. Ver dune-config(5) para más detalles. Los valores válidos para esta opción son progress, verbose, short, quiet o tui.
--dump-gc-stats=FILE
Vuelca las estadísticas del recolector de basura a un archivo después de que la compilación esté completa.
--dump-memo-graph=FILE
Vuelca el grafo de dependencias a un archivo después de que la compilación esté completa.
--dump-memo-graph-format=FORMAT (ausente=gexf)
Establece el formato de archivo usado por --dump-memo-graph
--dump-memo-graph-with-timing
Vuelve a ejecutar cada nodo en caché en el grafo Memo después de compilar e incluye la duración de la ejecución en la salida de --dump-memo-graph. Dado que todos los nodos contienen un valor en caché, cada medición solo contabilizará un solo nodo.
--help[=FMT] (predeterminado=auto)
Muestra esta ayuda en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable de entorno TERM sea dumb o esté indefinida.
--ignore-lock-dir
Ignora el directorio dune.lock/.
--ignore-promoted-rules
Ignora las reglas con (mode promote), excepto las que tienen (only ...). La variable %{ignoring_promoted_rules} en los archivos dune refleja si esta opción se pasó o no.
--instrument-with=BACKENDS (ausente DUNE_INSTRUMENT_WITH env)
Habilita la instrumentación mediante BACKENDS. BACKENDS es una lista de nombres de bibliotecas separados por comas, cada uno de los cuales debe declarar un backend de instrumentación.
-j JOBS
Ejecuta no más de JOBS comandos simultáneamente.
--no-buffer
No almacena en búfer la salida de los comandos ejecutados por dune. Por defecto, dune almacena en búfer la salida de los subcomandos, para evitar la intercalación cuando se ejecutan múltiples comandos en paralelo. Sin embargo, esto puede ser un problema al depurar pruebas de larga duración. Con --no-buffer, los comandos tienen acceso directo al terminal. Ten en cuenta que como resultado, su salida no será capturada en el archivo de registro. Deberías usar esta opción en conjunto con -j 1, para evitar la intercalación. Además, deberías usar --verbose también, para asegurarte de que los comandos se imprimen antes de ser ejecutados.
--no-config
No carga el archivo de configuración
--no-print-directory
Suprime los mensajes de "Entering directory".
--only-packages=PACKAGES
Ignora las estanzas que se refieren a un paquete que no está en PACKAGES. PACKAGES es una lista de nombres de paquetes separados por comas. Ten en cuenta que esto tiene el mismo efecto que borrar las estanzas relevantes

NAME

dune-upgrade - Upgrade dune configuration files

SYNOPSIS

dune upgrade [OPTIONS]

DESCRIPTION

This command is used to upgrade your dune configuration files.

OPTIONS

Most of the options described below are passed directly to the underlying dune build command. Note that the default values may differ depending on the context.

--abort-if-cannot-reproduce
Abort the build if dune cannot reproduce a result from cache.
--action-runner=VAL
Use VAL as action runner.
--cache-transport=VAL
Use VAL as the cache transport.
--build-dir=DIR
Use DIR as the build directory. The default is _build.
--build-only-packages=PACKAGES
Only build the listed packages. This option is meant for dune itself and not for users. dune upgrade doesn't do anything with this option.
--build-stdout-on-error
On error, print the stdout of the failed action. This is useful for debugging build errors, but can also lead to large logs.
--cas-store=DIR
Use DIR as the Content-Addressable Storage.
--check-suffix=SUFFIX
Specify a suffix for generated files to check. This option is meant for dune itself.
--clear-all-caches
Clear all the caches.
--clear-backward-compatible-caches
Clear caches that were created with previous versions of Dune.
--config-cache=VAL (absent DUNE_CONFIG_CACHE env)
Select the configuration cache.
--create-install-dir[=VAL] (default=true)
When installing packages, create the corresponding directories in the destination.
--debug-scheduler
Debug the scheduler.
--delete-old-unused-filters
Delete filters that are not used anymore.
--dep-conflicts
Print dependency conflicts.
--diff=CMD
Use CMD to show differences between files.
--disable-setenv
Disable the setenv mechanism.
--dry-run
Print the actions that would be taken without executing them.
--dump-ast=FILE
Dump the AST of the Dune files to FILE.
--dune-file-encoding=VAL
Set the dune file encoding.
--error-details=VAL
Set error details level.
--executable-wildcard=EVALUATION
Set evaluation of executable wildcards.
--external-lib-deps=VAL
Set external library dependencies.
--file-tree-magic=VAL
Set file tree magic value.
--finalize-all
Finalize all artefacts.
--finalize-copy-contents
Finalize by copying contents.
--finalize-hardlink-tree
Finalize by hardlinking the tree.
--findlib-path=PATH
Add PATH to the findlib path.
--force
Force the build.
--forbid-empty-buckets
Forbid empty buckets.
--forbid-version=VERSION
Forbid specified Dune version.
--frozen-install-customize-entries
Freeze install customization entries.
--ignore-promoted-rules
Ignore promoted rules.
--implicit-libs=VAL
Set implicit libraries.
--install-env-vars
Install environment variables.
--install-expansions
Install expansions.
--jobs=N, -j N
Use N parallel jobs. The default is the number of cores.
--legacy-bytestring-reader
Use the legacy bytestring reader.
--legacy-compiler-hooks
Use legacy compiler hooks.
--legacy-hash-size
Use legacy hash size.
--local-discovery-timeout=FLOAT
Set timeout for local discovery.
--log-partition-size=N
Set log partition size.
--log-redirect=MODE
Redirect logs. Supported modes: all, output, all-or-output.
--main-module-inclusion=VAL
Set main module inclusion.
--no-archive-deps
Do not archive dependencies.
--no-auto-promote
Disable automatic promotion.
--no-buffer-logs
Do not buffer logs.
--no-config
Do not load the user's configuration.
--no-print-directory
Do not print the current directory.
--no-terminal
Disable terminal handling.
--only-make-install-files
Only create install files.
--only-packages=PACKAGES
Only build the specified packages. This option is meant for dune itself and not for users. dune upgrade doesn't do anything with this option.
--only-reachable-packages
Only build reachable packages.
--open-implicit-libs
Open implicit libraries.
--profile=VAL (absent DUNE_PROFILE env)
Select the build profile, for instance dev or release. The default is dev.
--promote=MODE
Set the promotion mode. Supported modes: auto, always, never.
--promote-install-files[=VAL] (default=true)
Promote any generated <package>.install files to the source tree.
--require-dune-project-file[=VAL] (default=true)
Fail if a dune-project file is missing.
--restore-cache
Restore the cache.
--retry-dependencies=N
Retry dependencies up to N times.
--root=DIR
Use this directory as workspace root instead of guessing it. Note that this option doesn't change the interpretation of targets given on the command line. It is only intended for scripts.
--sandbox=VAL (absent DUNE_SANDBOX env)
Set the sandbox mode. Supported modes: local, external, promote.
--save-ir=VAL
Save intermediate representation.
--scan-build=DIR
Run scan-build in DIR.
--section=SECTION
Select a section of the manual.
--setenv=VAR=VAL
Set environment variable VAR to VAL.
--show-details=VAL
Set the details level for showing errors.
--show-ffis
Show foreign function interface symbols.
--solve-deps
Solve dependencies.
--stack-optimize
Use stack optimization.
--store-orig-source-dir (absent DUNE_STORE_ORIG_SOURCE_DIR env)
Store original source location in dune-package metadata.
--strict-opaque-closetypes
Enforce strict opaque closetypes.
--terminal-persistence=MODE
Change how the log of build results are displayed to the console between rebuilds while in --watch mode. Supported modes: preserve, clear-on-rebuild, clear-on-rebuild-and-flush-history.
--trace-extended
Output extended trace data (requires trace-file).
--trace-file=FILE
Output trace data in catapult format (compatible with chrome://tracing).
--unlock-phantom-deps
Unlock phantom dependencies.
--upgrade-legacy-action-db
Upgrade legacy action database.
--used-filters
Print used filters.
--verbose
Same as --display verbose
--version
Show version information.
--watch
Watch for changes and rebuild automatically.
--watch-exclusions=REGEX
Adds a POSIX regular expression that will exclude matching directories from `dune build --watch`. The option --watch-exclusions can be repeated to add multiple exclusions. Semicolons can be also used as a separator. If no exclusions are provided, then a standard set of exclusions is used; however, if one or more --watch-exclusions are used, none of the standard exclusions are used. The standard exclusions are: ^_opam /_opam ^_esy /_esy ^\.#.* /\.#.* ~$ ^#[^#]*#$ /#[^#]*#$ ^4913$ /4913$ /.git /.hg :/windows
--workspace=FILE (absent DUNE_WORKSPACE env)
Use this specific workspace file instead of looking it up.
-x VAL
Cross-compile using this toolchain.

MORE HELP

Use `dune COMMAND --help' for help on a single command.

EXIT STATUS

dune upgrade exits with:

0
on success.
1
if an error happened.
130
if it was interrupted by a signal.

ENVIRONMENT

These environment variables affect the execution of upgrade:

DUNE_BUILD_DIR
Specified build directory. _build if unspecified
DUNE_CACHE
Enable or disable Dune cache (one of disabled, enabled-except-user-rules or enabled). Default is `enabled-except-user-rules'.
DUNE_CACHE_CHECK_PROBABILITY
Check build reproducibility by re-executing randomly chosen rules and comparing their results with those stored in Dune cache. Note: by increasing the probability of such checks you slow down the build. The default probability is zero, i.e. no rules are checked.
DUNE_CACHE_STORAGE_MODE
Dune cache storage mode (one of auto, hardlink or copy). Default is `hardlink'.
DUNE_DEBUG_PACKAGE_LOGS
Always print the standard logs when building packages
DUNE_DIFF_COMMAND
Shell command to use to diff files. Use - to disable printing the diff.
DUNE_DISABLE_PROMOTION
Disable all promotion rules
DUNE_INSTRUMENT_WITH
Enable instrumentation by BACKENDS. BACKENDS is a comma-separated list of library names, each one of which must declare an instrumentation backend.
DUNE_PROFILE
Build profile. dev if unspecified or release if -p is set.
DUNE_SANDBOX
Sandboxing mode to use by default. (see --sandbox)
DUNE_STORE_ORIG_SOURCE_DIR
Store original source location in dune-package metadata.
DUNE_WORKSPACE
Use this specific workspace file instead of looking it up.
