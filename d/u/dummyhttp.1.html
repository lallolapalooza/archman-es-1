dummyhttp(1) Manual de comandos generales dummyhttp(1)

NOMBRE

dummyhttp - Servidor HTTP súper simple que responde con un cuerpo fijo y un código de respuesta fijo

SINOPSIS

dummyhttp [-q|--quiet] [-v|--verbose]... [-p|--port] [-H|--headers] [-c|--code] [-b|--body] [-i|--interface] [-d|--delay] [--print-completions] [--print-manpage] [--tls-cert] [--tls-key] [-h|--help] [-V|--version]

DESCRIPCIÓN

Servidor HTTP súper simple que responde con un cuerpo fijo y un código de respuesta fijo

OPCIONES

-q, --quiet
Silencioso (no registrar nada)
-v, --verbose
Detallado (registrar datos de solicitudes entrantes y salientes). Si se proporciona dos veces, también registrará los datos del cuerpo.
-p, --port <PUERTO> [predeterminado: 8080]
Puerto en el que escuchar
-H, --headers <CABECERAS>
Cabeceras a enviar (formato: clave:valor)
-c, --code <CÓDIGO> [predeterminado: 200]
Código de estado HTTP a enviar
-b, --body <CUERPO> [predeterminado: dummyhttp]
Cuerpo HTTP a enviar

Soporta plantillas basadas en Tera (https://tera.netlify.app/docs/) con algunas funciones adicionales además de las integradas predeterminadas:

uuid() - genera un UUID aleatorio lorem(words) - genera `words` palabras de ipsum lorem.

Ejemplo: dummyhttp -b "Hola {{ uuid() }}, es {{ now() | date(format="%Y") }} {{ lorem(words=5)}}"

-i, --interface <INTERFAZ> [predeterminado: 0.0.0.0]
Interfaz a la que vincularse
-d, --delay <RETRASO> [predeterminado: 0]
Retraso en milisegundos antes de enviar la respuesta en milisegundos
--print-completions <shell>
Generar archivo de completado para un shell

[posibles valores: bash, elvish, fish, powershell, zsh]

--print-manpage
Generar página de manual
--tls-cert <TLS_CERT>
Certificado TLS a utilizar
--tls-key <TLS_KEY>
Clave privada TLS a utilizar
-h, --help
Imprimir ayuda (ver un resumen con '-h')
-V, --version
Imprimir versión
