NOMBRE

dub-add-path - Añade una ruta de búsqueda de paquetes predeterminada

SINOPSIS

dub add-path <ruta> OPCIONES...

DESCRIPCIÓN

Añade una ruta de búsqueda de paquetes predeterminada. Todas las carpetas secundarias directas de esta ruta se buscarán para obtener descripciones de paquetes y se pondrán a disposición como paquetes. Usar este comando tiene el efecto equivalente a llamar a 'dub add-local' en cada una de las carpetas secundarias manualmente.

Cualquier paquete registrado usando add-path tendrá preferencia sobre los paquetes descargados del registro de paquetes al buscar dependencias durante una operación de compilación.

La versión de los paquetes se determinará por uno de los siguientes:


- Para copias de trabajo GIT, la última etiqueta (git describe) se utiliza para determinar la versión


- Si el paquete contiene un campo "version" en la descripción del paquete, se utiliza este


- Si ninguno de los anteriores aplica, se asume "~master"

OPCIONES

--system

OBSOLETO: Use --cache=system en su lugar

OPCIONES COMUNES

Ver dub(1)
