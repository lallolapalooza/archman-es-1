DUNE-FORMAT-DUNE-FILE(1) Manual de Dune DUNE-FORMAT-DUNE-FILE(1)

NOMBRE

dune-format-dune-file - Formatea archivos dune.

SINOPSIS

dune format-dune-file [--dune-version=VERSIÓN] [OPCIÓN]… [ARCHIVO]

DESCRIPCIÓN

dune format-dune-file lee un archivo dune y genera una versión formateada. Este es un comando de bajo nivel, destinado a implementar soporte para editores, por ejemplo. Para reformatear un proyecto dune, consulte la sección "Formateo automático" del manual.

ARGUMENTOS

ARCHIVO
Ruta al archivo dune que se va a analizar.

OPCIONES

--dune-version=VERSIÓN (ausente=3.20)
Qué versión del lenguaje Dune utilizar.

OPCIONES COMUNES

--help[=FMT] (predeterminado=auto)
Muestra esta ayuda en formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable de entorno TERM sea dumb o no esté definida.
--version
Muestra información de la versión.

ESTADO DE SALIDA

dune format-dune-file sale con:

0
en caso de éxito.
1
si ocurrió un error.
130
si fue interrumpido por una señal.
