NAME

dune - sistema de construcción componible para OCaml

SYNOPSIS

dune build [--watch]

dune runtest [--watch]

dune exec NAME

dune utop [DIR]

dune install

dune init project NAME [PATH] [--libs=l1,l2 --ppx=p1,p2 --inline-tests]

DESCRIPTION

Dune es un sistema de construcción diseñado exclusivamente para proyectos en OCaml. Se centra en proporcionar al usuario una experiencia consistente y se encarga de la mayoría de los detalles de bajo nivel del compilador OCaml. Todo lo que tiene que hacer es proporcionar una descripción de su proyecto y Dune hará el resto.

El esquema que implementa está inspirado en el utilizado dentro de Jane Street y adaptado al mundo de código abierto. Ha madurado con el tiempo y es utilizado diariamente por cientos de desarrolladores, lo que significa que está altamente probado y productivo.

COMMON OPTIONS

Estas opciones son comunes a todos los comandos.

--help[=FORMATO] (default=auto)
Mostrar esta ayuda en el formato FORMATO. El valor FORMATO debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain cuando la variable de entorno TERM es dumb o no definida.
--version
Mostrar información de versión.

MORE HELP

Use `dune COMANDO --help' para obtener ayuda sobre un comando individual.

EXIT STATUS

dune sale con:

0
en caso de éxito.
1
si ha ocurrido un error.
130
si fue interrumpido por una señal.

ENVIRONMENT

Estas variables de entorno afectan la ejecución de dune:

CLICOLOR
Si es diferente de 0, se soportan los colores ANSI y se deben utilizar cuando el programa no se esté canalizando. Si es igual a 0, no se deben generar códigos de escape de color ANSI
CLICOLOR_FORCE
Si es diferente de 0, los colores ANSI deben activarse sin importar nada.
DUNE_CACHE_ROOT
Si se establece, determina la ubicación de la caché compartida global de la máquina.
