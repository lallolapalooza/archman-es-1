NOMBRE

dune-ocaml - Grupo de comandos relacionados con OCaml.

SINOPSIS

dune ocaml COMANDO …

COMANDOS

doc [OPCIÓN]…
Compila y visualiza la documentación de un proyecto OCaml.
dump-dot-merlin [OPCIÓN]… [RUTA]
Imprime la configuración de Merlin.
merlin COMANDO …
Grupo de comandos relacionados con merlin.
ocaml-merlin [OPCIÓN]…
Inicia un servidor de configuración de merlin.
top [OPCIÓN]… [DIR]
Imprime una lista de directivas de toplevel para incluir directorios y cargar archivos cma.
top-module [OPCIÓN]… MÓDULO
Imprime una lista de directivas de toplevel para cargar un módulo en el toplevel.
utop [OPCIÓN]… [DIR] [ARGS]…
Carga una biblioteca en utop.

OPCIONES COMUNES

--help[=FMT] (por defecto=auto)
Muestra esta ayuda en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain cuando la variable de entorno TERM es dumb o no está definida.
--version
Muestra la información de la versión.

ESTADO DE SALIDA

dune ocaml sale con:

0
en caso de éxito.
1
si ocurrió un error.
130
si fue interrumpido por una señal.
