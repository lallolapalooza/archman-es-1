NOMBRE

dumpimage - extraer datos de imágenes U-Boot

SINOPSIS

dumpimage [-T tipo] -l imagen
dumpimage [-T tipo] [-p posición] -o archivo_salida imagen
dumpimage -h
dumpimage -V

DESCRIPCIÓN

dumpimage lista y extrae datos de imágenes U-Boot. Si se especifica -l, dumpimage lista los componentes en imagen. De lo contrario, dumpimage extrae el componente en posición a archivo_salida.

OPCIONES

-h
Imprime información de uso y sale.
-l
Imprime la información de la cabecera para imagen, incluyendo una lista de componentes.
-o archivo_salida
El archivo al que se escribirá el componente extraído.
-p posición
Especifica la posición del componente a extraer. Debe ser un índice numérico, comenzando en 0. Si no se especifica, la posición predeterminada es 0.
-T tipo
Especifica el tipo de la imagen. Si no se especifica, el tipo de imagen se detectará automáticamente. Una lista de tipos de imagen soportados se puede imprimir ejecutando mkimage -T list.
-V
Imprime información de la versión y sale.

ERRORES

Por favor, informe de los errores en el rastreador de errores de U-Boot.

EJEMPLOS

Crear una imagen de múltiples archivos y luego extraer parte de esa imagen

$ 
mkimage -A x86 -O linux -T multi -n x86 \
-d vmlinuz:initrd.img:System.map multi.img
