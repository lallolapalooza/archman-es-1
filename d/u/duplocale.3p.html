DUPLOCALE(3P) Manual POSIX del Programador DUPLOCALE(3P)

PROLOG

Esta página del manual forma parte del Manual POSIX del Programador. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

duplocale — duplicar un objeto de configuración regional

SINOPSIS

#include <locale.h>
locale_t duplocale(locale_t locobj);

DESCRIPCIÓN

La función duplocale() creará una copia duplicada del objeto de configuración regional al que hace referencia el argumento locobj.

Si el argumento locobj es LC_GLOBAL_LOCALE, duplocale() creará un nuevo objeto de configuración regional que contendrá una copia de la configuración regional global determinada por la función setlocale().

El comportamiento no está definido si el argumento locobj no es un identificador de objeto de configuración regional válido.

VALOR DE RETORNO

Al completarse con éxito, la función duplocale() devolverá un identificador para un nuevo objeto de configuración regional. De lo contrario, duplocale() devolverá (locale_t)0 y establecerá errno para indicar el error.

ERRORES

La función duplocale() fallará si:

ENOMEM
No hay suficiente memoria disponible para crear el objeto de configuración regional o cargar los datos de la configuración regional.

EJEMPLOS

Creación de una Versión Modificada de un Objeto de Configuración Regional Existente

El siguiente ejemplo muestra un fragmento de código para crear una versión ligeramente modificada de un objeto de configuración regional existente. La función toma un objeto de configuración regional y un nombre de configuración regional, y reemplaza los datos de la categoría LC_TIME en el objeto de configuración regional con los de la configuración regional nombrada.

#include <locale.h>
...
locale_t
with_changed_lc_time (locale_t obj, const char *name)
{
    locale_t retval = duplocale (obj);
    if (retval != (locale_t) 0)
    {
        locale_t changed = newlocale (LC_TIME_MASK, name, retval);
        if (changed == (locale_t) 0)
            /* Se produjo un error. Liberar todos los recursos asignados. */
            freelocale (retval);
        retval = changed;
    }
    return retval;
}

USO DE LA APLICACIÓN

Se recomienda el uso de la función duplocale() para situaciones en las que un objeto de configuración regional se está utilizando en varios lugares, y es posible que la vida útil del objeto de configuración regional finalice antes de que se completen todos los usos. Otra razón para duplicar un objeto de configuración regional es si se necesita una forma ligeramente modificada. Esto se puede lograr mediante una llamada a newlocale() después de la llamada a duplocale().

Al igual que con la función newlocale(), los identificadores de los objetos de configuración regional creados por la función duplocale() deben liberarse mediante una llamada correspondiente a freelocale().

La función duplocale() también se puede usar en conjunto con uselocale((locale_t)0). Esto devuelve la configuración regional en efecto para el hilo que llama, pero puede tener el valor LC_GLOBAL_LOCALE. Pasar LC_GLOBAL_LOCALE a funciones como isalnum_l() resulta en un comportamiento no definido, pero las aplicaciones pueden convertirlo en un objeto de configuración regional utilizable mediante duplocale().
