duplocale(3) Manual de Funciones de Biblioteca duplocale(3)

NOMBRE

duplocale - duplicar un objeto de localización

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <locale.h>
locale_t duplocale(locale_t locobj);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

duplocale():

    Desde glibc 2.10:
        _XOPEN_SOURCE >= 700
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

La función duplocale() crea un duplicado del objeto de localización al que se refiere locobj.

Si locobj es LC_GLOBAL_LOCALE, duplocale() crea un objeto de localización que contiene una copia de la localización global determinada por setlocale(3).

VALOR DE RETORNO

En caso de éxito, duplocale() devuelve un identificador para el nuevo objeto de localización. En caso de error, devuelve (locale_t) 0 y establece errno para indicar el error.

ERRORES

ENOMEM
Memoria insuficiente para crear el objeto de localización duplicado.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

glibc 2.3.

NOTAS

Duplicar una localización puede servir a los siguientes propósitos:

•
Para crear una copia de un objeto de localización en el que una o más categorías van a ser modificadas (usando newlocale(3)).
•
Para obtener un identificador para la localización actual que pueda ser usado en otras funciones que emplean un identificador de localización, como toupper_l(3). Esto se hace aplicando duplocale() al valor devuelto por la siguiente llamada:

loc = uselocale((locale_t) 0);

Esta técnica es necesaria, ya que la llamada anterior a uselocale(3) puede devolver el valor LC_GLOBAL_LOCALE, lo que resulta en un comportamiento indefinido si se pasa a funciones como toupper_l(3). Llamar a duplocale() puede usarse para asegurar que el valor LC_GLOBAL_LOCALE se convierta en un objeto de localización utilizable. Ver EJEMPLOS, abajo.

Cada objeto de localización creado por duplocale() debe ser desasignado usando freelocale(3).

EJEMPLOS

El programa a continuación usa uselocale(3) y duplocale() para obtener un identificador para la localización actual que luego se pasa a toupper_l(3). El programa toma un argumento de línea de comandos, una cadena de caracteres que se convierte a mayúsculas y se muestra en la salida estándar. Un ejemplo de su uso es el siguiente:


$ ./a.out abc;
ABC

Origen del programa

#define _XOPEN_SOURCE 700
#include <ctype.h>
#include <err.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    locale_t loc, nloc;
    if (argc != 2) {
        fprintf(stderr, "Uso: %s cadena\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Esta secuencia es necesaria, porque uselocale() podría devolver
       el valor LC_GLOBAL_LOCALE, que no se puede pasar como argumento
       a toupper_l().  */
    loc = uselocale((locale_t) 0);
    if (loc == (locale_t) 0)
        err(EXIT_FAILURE, "uselocale");
    nloc = duplocale(loc);
    if (nloc == (locale_t) 0)
        err(EXIT_FAILURE, "duplocale");
    for (char *p = argv[1]; *p; p++)
        putchar(toupper_l(*p, nloc));
    printf("\n");
    freelocale(nloc);
    exit(EXIT_SUCCESS);
}
