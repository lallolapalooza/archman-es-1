DUNE-SUBST(1) Manual de Dune DUNE-SUBST(1)

NOMBRE

dune subst - Sustituye marcas de agua en archivos fuente.

SINOPSIS

dune subst [--build-info] [OPCIÓN]…

DESCRIPCIÓN

Sustituye cadenas %%ID%% en archivos fuente, de forma similar a lo que hace topkg en la configuración por defecto.

Este comando solo está destinado a ser llamado cuando un usuario fija un paquete a su versión de desarrollo. En particular, reemplaza las cadenas %%VERSION%% por la versión obtenida del vcs. Actualmente, solo se admite git y la versión se obtiene de la salida de:

  $ git describe --always --dirty --abbrev=7

dune subst sustituye las variables que topkg sustituye con la configuración por defecto:

- %%NAME%%, el nombre del proyecto (del archivo dune-project)

- %%VERSION%%, salida de git describe --always --dirty --abbrev=7

- %%VERSION_NUM%%, igual que %%VERSION%% pero sin la potencial 'v' o 'V' inicial

- %%VCS_COMMIT_ID%%, hash del commit del vcs

- %%PKG_MAINTAINER%%, contenido del campo maintainer: del archivo opam

- %%PKG_AUTHORS%%, contenido del campo authors: del archivo opam

- %%PKG_HOMEPAGE%%, contenido del campo homepage: del archivo opam

- %%PKG_ISSUES%%, contenido del campo issues: del archivo opam

- %%PKG_DOC%%, contenido del campo doc: del archivo opam

- %%PKG_LICENSE%%, contenido del campo license: del archivo opam

- %%PKG_REPO%%, contenido del campo repo: del archivo opam

Para llamar a dune subst cuando tu paquete está fijado, añade esta línea al campo build: de tu archivo opam:

  [dune "subst"] {pinned}

Ten en cuenta que este comando está destinado a ser llamado solo desde archivos opam y se comporta de manera un poco diferente a otros comandos de dune. En particular, no intenta detectar la raíz y debe ser llamado desde la raíz del proyecto.

OPCIONES

--build-info
Mostrar información de compilación.

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--debug-backtraces
Imprimir siempre los rastreos de excepciones.
--help[=FMT] (predeterminado=auto)
Mostrar esta ayuda en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable de entorno TERM sea dumb o no esté definida.
--version
Mostrar información de la versión.

MÁS AYUDA

Usa `dune COMANDO --help' para obtener ayuda sobre un solo comando.

ESTADO DE SALIDA

dune subst sale con:

0
en caso de éxito.
1
si ocurrió un error.
130
si fue interrumpido por una señal.

ERRORES

Consulta los informes de errores en https://github.com/ocaml/dune/issues
