Licencias: MIT

DUB-RUN(1) The D Language Foundation DUB-RUN(1)

NOMBRE

dub-run - Compila y ejecuta un paquete (comando por defecto)

SINOPSIS

dub run [<paquete>[@<especificación-de-versión>]] OPCIONES... [-- <argumentos-de-aplicación...>]

DESCRIPCIÓN

Compila y ejecuta un paquete (usa el paquete principal en el directorio de trabajo actual por defecto)

OPCIONES

--temp-build

Compila el proyecto en la carpeta temporal si es posible.

--rdmd

Usa rdmd en lugar de invocar directamente al compilador

-f, --force

Fuerza una recompilación incluso si el objetivo está actualizado .

-y, --yes

Respuesta automática a las preguntas. Asume "sí" como respuesta a todas las preguntas interactivas.

-n, --non-interactive

No entrar en modo interactivo.

-d, --deep

Compila todas las dependencias, incluso cuando el objetivo principal es una biblioteca estática .

-b, --build=VALOR

Especifica el tipo de compilación a realizar. Nota que la variable de entorno DFLAGS anulará el tipo de compilación con banderas personalizadas. Nombres posibles:
debug, plain, release, release-debug, release-nobounds, unittest, profile, profile-gc, docs, ddox, cov, cov-ctfe, unittest-cov, unittest-cov-ctfe, syntax y tipos personalizados

-c, --config=VALOR

Compila la configuración especificada. Las configuraciones se pueden definir en dub.json

--override-config=VALOR

Utiliza la configuración especificada para una dependencia determinada. Se puede especificar varias veces. Formato: --override-config=<dependencia>/<configuración>

--compiler=VALOR

Especifica el binario del compilador a usar (puede ser una ruta). Se reconocen sufijos y prefijos arbitrarios a los identificadores a continuación (por ejemplo, ldc2 o dmd-2.063) y se emparejan con el tipo de compilador adecuado:
dmd, gdc, ldc, gdmd, ldmd

-a, --arch=VALOR

Fuerza una arquitectura diferente (por ejemplo, x86 o x86_64)

-d, --debug=VALOR

Define el identificador de versión `debug` especificado al compilar - se puede usar varias veces

--d-version=VALOR

Define el identificador de versión `version` especificado al compilar - se puede usar varias veces. ¡Úselo con moderación, un gran poder conlleva una gran responsabilidad! Para versiones de uso común o combinadas y versiones que los dependientes deban poder usar, cree configuraciones en su paquete.

--nodeps

No resolver dependencias faltantes antes de compilar

--build-mode=VALOR

Especifica la forma en que se invocan el compilador y el enlazador. Valores válidos:
separate (por defecto), allAtOnce, singleFile

--single

Trata el nombre del paquete como un nombre de archivo. El archivo debe contener un comentario de receta del paquete.

--force-remove

Opción obsoleta que no hace nada.

--filter-versions

[Experimental] Filtra identificadores de versión e identificadores de versión de depuración para mejorar la eficiencia de la caché de compilación.

--combined

Intenta compilar todo el proyecto en una sola ejecución del compilador.

--print-builds

Imprime la lista de tipos de compilación disponibles

--print-configs

Imprime la lista de configuraciones disponibles

--print-platform

Imprime los identificadores para la plataforma de compilación actual tal como se usan para los campos de compilación en dub.json

--parallel

Ejecuta múltiples instancias del compilador en paralelo, si es posible.

OPCIONES COMUNES

Ver dub(1)

ESTADO DE SALIDA

0
DUB tuvo éxito
1
errores de uso, flags de línea de comandos desconocidos
2
paquete no encontrado, fallo al cargar el paquete, error misceláneo
