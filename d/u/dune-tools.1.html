DUNE-TOOLS(1) Manual de Dune DUNE-TOOLS(1)

NOMBRE

dune-tools - Grupo de comandos para herramientas encapsuladas.

SINOPSIS

dune tools COMANDO …

COMANDOS

ejec COMANDO …
Grupo de comandos para ejecutar herramientas encapsuladas.
instalar COMANDO …
Grupo de comandos para instalar herramientas encapsuladas.
cual COMANDO …
Grupo de comandos para imprimir la ruta a las herramientas encapsuladas.

OPCIONES COMUNES

--help[=FMT] (por defecto=auto)
Muestra esta ayuda en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable de entorno TERM sea dumb o no esté definida.
--version
Muestra información de la versión.

ESTADO DE SALIDA

dune tools sale con:

0
en caso de éxito.
1
si ocurrió un error.
130
si fue interrumpido por una señal.
