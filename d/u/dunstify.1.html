NOMBRE

dunstify - un programa para enviar notificaciones de escritorio

SINOPSIS

dunstify [OPCIÓN...] RESUMEN [CUERPO]

DESCRIPCIÓN

Dunstify es una alternativa a notify-send que se puede usar para enviar notificaciones de escritorio desde la línea de comandos.

OPCIONES

-?, --help
Mostrar opciones de ayuda.
-a, --appname=NOMBRE
Establecer el nombre de la aplicación de la notificación.
-u, --urgency=URG
Establecer el nivel de urgencia (baja, normal, crítica) de la notificación.
-h, --hints=PISTA
Especifica las pistas a pasar. Los tipos válidos son BOOLEAN, INT, DOUBLE, STRING, BYTE y VARIANT.
-A, --action=ACCIÓN
Especifica las acciones a mostrar al usuario.
-t, --timeout=TIEMPO_DE_ESPERA
El tiempo en milisegundos hasta que la notificación expire.
-i, --icon=ICONO
Especifica un icono para mostrar con la notificación.
-I, --raw_icon=RUTA
Ruta al icono que se enviará como datos de imagen cruda.
-c, --category=TIPO
La categoría de esta notificación.
--capabilities
Imprime las capacidades del servidor y sale.
-s, --serverinfo
Imprime información del servidor y sale.
-p, --printid
Imprime el ID, que se puede usar para actualizar/reemplazar esta notificación.
-r, --replace=ID
Establece el ID de esta notificación al ID de la notificación a reemplazar.
-C, --close=ID
Cierra la notificación con el ID especificado.
-b, --block
Bloquea hasta que la notificación se cierre e imprime la razón del cierre.

VER TAMBIÉN

notify-send(1), dunst(5), dunstctl(1), dunst(1)
