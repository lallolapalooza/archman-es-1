DUMPEXFAT(8) Manual del Administrador del Sistema DUMPEXFAT(8)

NOMBRE

dumpexfat - volcar sistema de archivos exFAT

SINOPSIS

dumpexfat [ -s ] [ -u ] [ -f archivo ] [ -V ] dispositivo

DESCRIPCIÓN

dumpexfat vuelca detalles sobre el sistema de archivos exFAT, incluida información de bajo nivel. Todos los tamaños están en bytes.

OPCIONES

Opciones de línea de comandos disponibles:

-s
Volcar solo información del superbloque. Puede ser útil para sistemas de archivos muy corruptos.
-u
Volcar rangos de sectores utilizados comenzando desde 0 y separados por espacios. Puede ser útil para herramientas de copia de seguridad.
-f archivo
Imprimir una lista de fragmentos que componen el archivo dado. Cada fragmento se imprime en su propia línea, como el desplazamiento de inicio (en bytes) en el sistema de archivos y la longitud (en bytes).
-V
Imprimir versión y copyright.

CÓDIGOS DE SALIDA

Se devuelve cero en caso de éxito. Cualquier otro código significa un error.
