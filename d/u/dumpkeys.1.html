DUMPKEYS(1) Manual de Comandos Generales DUMPKEYS(1)

NOMBRE

dumpkeys - vuelca las tablas de traducción del teclado

SINOPSIS

dumpkeys [OPCIONES]

DESCRIPCIÓN

dumpkeys escribe en la salida estándar el contenido actual de las tablas de traducción del controlador del teclado, en el formato especificado por keymaps(5).

Usando las diversas opciones, se puede controlar el formato de la salida y también obtener otra información del kernel y de los programas dumpkeys(1) y loadkeys(1).

OPCIONES

-h --help
Imprime el número de versión del programa y un breve mensaje de uso en la salida de error estándar del programa y sale.
-i --short-info
Imprime algunas características del controlador de teclado del kernel. Los elementos mostrados son:
Rango de códigos de teclas soportado por el kernel
Esto indica qué valores se pueden usar después de la palabra clave keycode en los archivos de tabla de teclas. Consulte keymaps(5) para más información y la sintaxis de estos archivos.

Número de acciones enlazables a una tecla

Esto indica cuántas acciones diferentes puede generar una sola tecla usando diversas teclas modificadoras. Si el valor es 16, por ejemplo, puede definir hasta 16 acciones diferentes para una tecla combinada con modificadores. Cuando el valor es 16, el kernel probablemente conoce cuatro teclas modificadoras, que puede presionar en diferentes combinaciones con la tecla para acceder a todas las acciones enlazadas.

Rangos de códigos de acción soportados por el kernel

Este elemento contiene una lista de rangos de códigos de acción en notación hexadecimal. Estos son los valores que se pueden usar en el lado derecho de una definición de tecla, es decir, los vv en una línea
keycode xx = vv vv vv vv

(consulte keymaps(5) para más información sobre el formato de las líneas de definición de teclas). dumpkeys(1) y loadkeys(1) soportan una notación simbólica, que es preferible a la numérica, ya que los códigos de acción pueden variar de un kernel a otro, mientras que los nombres simbólicos suelen permanecer iguales. Sin embargo, la lista de rangos de códigos de acción se puede utilizar para determinar si el kernel realmente soporta todos los símbolos que loadkeys(1) conoce, o si quizás hay algunas acciones soportadas por el kernel que no tienen un nombre simbólico en su programa loadkeys(1). Para ver esto, compare la lista de rangos con la lista de símbolos de acción, consulte la opción --long-info a continuación.

Número de teclas de función soportadas por el kernel

Esto indica el número de códigos de acción que se pueden utilizar para generar cadenas de caracteres. Estos códigos de acción están tradicionalmente enlazados a las diversas teclas de función y edición del teclado y están definidos para enviar secuencias de escape estándar. Sin embargo, puede redefinirlas para que envíen líneas de comandos comunes, direcciones de correo electrónico o lo que prefiera. Especialmente si el número de este elemento es mayor que el número de teclas de función y edición de su teclado, puede tener algunos códigos de acción "libres" que puede enlazar a combinaciones de AltGr-letra, por ejemplo, para generar cadenas útiles. Consulte loadkeys(1) para más detalles.

Cadenas de función

Puede ver sus definiciones actuales de teclas de función con el comando
dumpkeys --funcs-only
-l -s --long-info
Esta opción indica a dumpkeys que imprima una lista de información detallada. La salida es la misma que con --short-info, más la lista de símbolos de acción soportados por loadkeys(1) y dumpkeys(1), junto con los valores numéricos de los símbolos.
-n --numeric
Esta opción hace que dumpkeys omita la conversión de los valores de código de acción a notación simbólica e imprima los valores en formato hexadecimal en su lugar.
-f --full-table
Esto hace que dumpkeys omita todas las heurísticas de acceso directo (consulte keymaps(5)) y genere las asociaciones de teclas en formato canónico. Primero se imprime una línea de mapas de teclas que describe las combinaciones de modificadores actualmente definidas. Luego, para cada tecla, se imprime una fila con una columna para cada combinación de modificadores. Por ejemplo, si el mapa de teclas actual en uso utiliza siete modificadores, cada fila tendrá siete columnas de códigos de acción. Este formato puede ser útil, por ejemplo, para programas que procesan la salida de dumpkeys.
-Sforma --shape=forma
Formas disponibles:
2 salida predeterminada.
4 una línea por cada código de tecla.
8 una línea por cada par (modificador,código de tecla).
16 una línea por cada código de tecla hasta el primer hueco.
-1 --separate-lines
Esto fuerza a dumpkeys a escribir una línea por cada par (modificador,código de tecla). Prefija la palabra plain para los códigos de tecla simples.
-t --funcs-only
Cuando se proporciona esta opción, dumpkeys imprime solo las definiciones de cadenas de teclas de función. Normalmente, dumpkeys imprime tanto las asociaciones de teclas como las definiciones de cadenas.
-k --keys-only
Cuando se proporciona esta opción, dumpkeys imprime solo las asociaciones de teclas. Normalmente, dumpkeys imprime tanto las asociaciones de teclas como las definiciones de cadenas.
-d --compose-only
Cuando se proporciona esta opción, dumpkeys imprime solo las combinaciones de teclas de composición. Esta opción solo está disponible si su kernel tiene soporte para la tecla de composición.
-cconjunto_de_caracteres --charset=conjunto_de_caracteres
Esto instruye a dumpkeys a interpretar los valores de códigos de caracteres según el conjunto de caracteres especificado. Esto afecta solo a la traducción de valores de códigos de caracteres a nombres simbólicos. Los valores válidos para conjunto_de_caracteres actualmente son iso-8859-X, donde X es un dígito entre 1 y 9. Si no se especifica ningún conjunto_de_caracteres, se utiliza iso-8859-1 como predeterminado. Esta opción produce una línea de salida `charset "iso-8859-X"', indicando a loadkeys cómo interpretar el mapa de teclas. (Por ejemplo, "división" es 0xf7 en iso-8859-1 pero 0xba en iso-8859-8.)
-Cdispositivo --console=dispositivo
El dispositivo de consola afectado se puede especificar usando la opción -C (o --console). Esta opción admite exactamente un nombre de dispositivo.
-v --verbose
Activa la salida detallada.
-V --version
Imprime el número de versión y sale.

ARCHIVOS

/usr/share/kbd/keymaps
El directorio recomendado para los archivos de tabla de teclas.

VER TAMBIÉN

loadkeys(1), keymaps(5)
