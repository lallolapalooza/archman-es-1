NOMBRE

dub-test - Ejecuta las pruebas del paquete seleccionado

SINOPSIS

dub test [<paquete>[@<especificación-versión>]] OPCIONES... [-- <argumentos-aplicación...>]

DESCRIPCIÓN

Compila el paquete y ejecuta todas las pruebas unitarias contenidas.

Si no se proporciona una configuración explícita, se preferirá una configuración "unittest" existente para las pruebas. Si no existe ninguna, se utilizará la primera configuración de tipo biblioteca y, si tampoco existe, se elegirá la primera configuración de ejecutable.

Cuando se especifica un archivo principal personalizado (--main-file), solo se pueden usar configuraciones de biblioteca. De lo contrario, dependiendo del tipo de configuración seleccionada, se utilizará un archivo principal existente (y deberá ajustarse correctamente para ejecutar solo las pruebas unitarias para 'version(unittest)'), o DUB generará uno para configuraciones de tipo biblioteca.

Finalmente, si el paquete contiene una dependencia con el paquete "tested", el archivo principal generado automáticamente lo utilizará para ejecutar las pruebas unitarias.

OPCIONES

--temp-build

Compila el proyecto en la carpeta temporal si es posible.

--main-file=VALOR

Especifica un archivo personalizado que contiene la función main() a utilizar para ejecutar las pruebas.

--combined

Intenta compilar todo el proyecto en una sola ejecución del compilador.

--parallel

Ejecuta múltiples instancias del compilador en paralelo, si es posible.

-f, --force

Fuerza una recompilación incluso si el objetivo está actualizado.

--coverage

Habilita la generación de estadísticas de cobertura de código.

--coverage-ctfe

Habilita la generación de estadísticas de cobertura de código (incluyendo CTFE).

-b, --build=VALOR

Especifica el tipo de compilación a realizar. Tenga en cuenta que establecer la variable de entorno DFLAGS anulará el tipo de compilación con indicadores personalizados. Nombres posibles:
debug, plain, release, release-debug, release-nobounds, unittest, profile, profile-gc, docs, ddox, cov, cov-ctfe, unittest-cov, unittest-cov-ctfe, syntax y tipos personalizados

-c, --config=VALOR

Compila la configuración especificada. Las configuraciones se pueden definir en dub.json

--override-config=VALOR

Utiliza la configuración especificada para una dependencia determinada. Se puede especificar varias veces. Formato: --override-config=<dependencia>/<config>

--compiler=VALOR

Especifica el binario del compilador a utilizar (puede ser una ruta). Se reconocen sufijos y prefijos arbitrarios a los identificadores a continuación (por ejemplo, ldc2 o dmd-2.063) y se emparejan con el tipo de compilador correcto:
dmd, gdc, ldc, gdmd, ldmd

-a, --arch=VALOR

Fuerza una arquitectura diferente (por ejemplo, x86 o x86_64).

-d, --debug=VALOR

Define el identificador de versión `debug` especificado al compilar - se puede usar varias veces.

--d-version=VALOR

Define el identificador de `version` especificado al compilar - se puede usar varias veces. Úselo con moderación, con gran poder viene una gran responsabilidad. Para versiones comúnmente usadas o combinadas y versiones que los dependientes puedan usar, cree configuraciones en su paquete.

--nodeps

No resuelva las dependencias faltantes antes de compilar.

--build-mode=VALOR

Especifica la forma en que se invocan el compilador y el enlazador. Valores válidos:
separate (predeterminado), allAtOnce, singleFile

--single

Trata el nombre del paquete como un nombre de archivo. El archivo debe contener un comentario de receta de paquete.

--force-remove

Opción obsoleta que no hace nada.

--filter-versions

[Experimental] Filtra los identificadores de versión y los identificadores de versión de depuración para mejorar la eficiencia de la caché de compilación.

OPCIONES COMUNES

Ver dub(1)
