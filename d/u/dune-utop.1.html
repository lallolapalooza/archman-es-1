DUNE-UTOP(1) Manual de Dune DUNE-UTOP(1)

NOMBRE

dune-utop - Cargar biblioteca en utop.

SINOPSIS

dune utop [OPCIÓN]… [DIR] [ARG]…

DESCRIPCIÓN

dune utop DIR compila y ejecuta el nivel superior de utop con las bibliotecas definidas en DIR.

OPCIONES

--action-stderr-on-success=VAL
Igual que --action-stdout-on-success pero para la salida estándar de errores en lugar de la salida estándar. Un buen valor predeterminado para repositorios mono grandes es --action-stdout-on-success=swallow --action-stderr-on-success=must-be-empty. Esto asegura que una compilación exitosa tenga una salida "limpia" y vacía.
--action-stdout-on-success=VAL
Especifica cómo tratar la salida estándar de las acciones cuando tienen éxito. Los valores posibles son: print para imprimirla en la salida de Dune, swallow para ignorarla completamente y must-be-empty para forzar que la acción no imprima nada. Con must-be-empty, Dune considerará que la acción falló si imprimió algo en su salida estándar. El valor predeterminado es print.
--build-info
Mostrar información de compilación.
--context=CONTEXTO (ausente=default)
Seleccionar el contexto donde compilar/ejecutar utop.
--display-separate-messages
Separar los mensajes de error con una línea en blanco.
--error-reporting=VAL (ausente=deterministic)
Controla cuándo se informan los errores de compilación. early informa los errores tan pronto como se descubren. deterministic informa los errores al final de la compilación en un orden determinista. twice informa cada error dos veces: una tan pronto como se descubre el error y luego nuevamente al final de la compilación, en un orden determinista.
-f, --force
Forzar la reejecución de las acciones asociadas a alias, incluso si sus dependencias no han cambiado.
--file-watcher=VAL (ausente=automatic)
Mecanismo para detectar cambios en el código fuente. automatic para que dune ejecute un programa externo para detectar cambios. manual para notificar a dune que los archivos han cambiado manualmente.
--passive-watch-mode
Similar a [--watch], pero solo inicia una compilación cuando se le indica externamente por RPC.
--sandbox=VAL (ausente DUNE_SANDBOX env)
Establecer el modo de sandboxing. Algunas acciones requieren un modo de sandboxing específico, por lo que ignorarán esta configuración. Los valores permitidos son: none, symlink, copy, hardlink.
--stop-on-first-error
Detener la compilación tan pronto como se encuentre un error.
-w, --watch
En lugar de terminar la compilación después de completarse, esperar continuamente los cambios en los archivos.
--wait-for-filesystem-clock
Dune genera hashes del contenido de los archivos para mejorar la incrementalidad. Estos hashes se almacenan en caché. En algunos casos, Dune necesita descartar algunas entradas de caché de hashes para que las cosas sean confiables. Esta opción hace que Dune espere a que avance el reloj del sistema de archivos para no tener que descartar nada. Probablemente no deberías preocuparte por esta opción; es principalmente útil para los desarrolladores de Dune para que las pruebas de Dune de la caché de hashes sean más reproducibles.

OPCIONES COMUNES

Estas opciones son comunes a todos los comandos.

--always-show-command-line
Mostrar siempre las líneas de comando completas de los programas ejecutados por dune.
--auto-promote
Promover archivos automáticamente. Esto es similar a ejecutar dune promote después de la compilación.
--build-dir=ARCHIVO (ausente DUNE_BUILD_DIR env)
Directorio de compilación especificado. _build si no se especifica.
--cache=VAL (ausente DUNE_CACHE env)
Habilitar o deshabilitar la caché de Dune (uno de disabled, enabled-except-user-rules o enabled). El valor predeterminado es `enabled-except-user-rules'.
--cache-check-probability=VAL (ausente DUNE_CACHE_CHECK_PROBABILITY env)
Verificar la reproducibilidad de la compilación reejecutando reglas elegidas aleatoriamente y comparando sus resultados con los almacenados en la caché de Dune. Nota: al aumentar la probabilidad de tales comprobaciones, se ralentiza la compilación. La probabilidad predeterminada es cero, es decir, no se comprueba ninguna regla.
--cache-storage-mode=VAL (ausente DUNE_CACHE_STORAGE_MODE env)
Modo de almacenamiento de la caché de Dune (uno de auto, hardlink o copy). El valor predeterminado es `hardlink'.
--config-file=ARCHIVO
Cargar este archivo de configuración en lugar del predeterminado.
--debug-artifact-substitution
Imprimir información de depuración sobre la sustitución de artefactos.
--debug-backtraces
Imprimir siempre los rastreos de excepciones.
--debug-cache=VAL
Mostrar mensajes de depuración en las ausencias de caché para las capas de caché dadas. El valor es una lista separada por comas de nombres de capas de caché. Todas las capas de caché disponibles: shared,workspace-local,fs.
--debug-dependency-path
En caso de error, imprimir la ruta de dependencia desde los objetivos en la línea de comandos hasta la regla que falló.
--debug-digests
Explicar por qué Dune decide volver a generar hashes de algunos archivos.
--debug-load-dir
Imprimir información de depuración sobre la carga de directorios.
--debug-package-logs (ausente DUNE_DEBUG_PACKAGE_LOGS env)
Imprimir siempre los registros estándar al compilar paquetes.
--default-target=TARGET (ausente=@@default)
Establecer el objetivo predeterminado que se utiliza cuando no se especifica ninguno para dune build.
--diff-command=VAL (ausente DUNE_DIFF_COMMAND env)
Comando de shell a utilizar para comparar archivos. Usar - para deshabilitar la impresión de la diferencia.
--disable-promotion (ausente DUNE_DISABLE_PROMOTION env)
Deshabilitar todas las reglas de promoción.
--display=MODO
Controlar el modo de visualización de Dune. Consulte dune-config(5) para más detalles. Los valores válidos para esta opción son progress, verbose, short, quiet o tui.
--dump-gc-stats=ARCHIVO
Volcar las estadísticas del recolector de basura a un archivo después de que la compilación se complete.
--dump-memo-graph=ARCHIVO
Volcar el grafo de dependencias a un archivo después de que la compilación se complete.
--dump-memo-graph-format=FORMATO (ausente=gexf)
Establecer el formato de archivo utilizado por --dump-memo-graph.
--dump-memo-graph-with-timing
Reejecutar cada nodo en caché del grafo Memo después de compilar e incluir la duración de la ejecución en la salida de --dump-memo-graph. Como todos los nodos contienen un valor en caché, cada medición solo representará un solo nodo.
--help[=FMT] (predeterminado=auto)
Mostrar esta ayuda en el formato FMT. El valor FMT debe ser uno de auto, pager, groff o plain. Con auto, el formato es pager o plain siempre que la variable de entorno TERM sea dumb o indefinida.
--ignore-lock-dir
Ignorar el directorio dune.lock/.
--ignore-promoted-rules
Ignorar reglas con (mode promote), excepto las que tienen (only ...). La variable %{ignoring_promoted_rules} en los archivos dune refleja si se pasó o no esta opción.
--instrument-with=BACKENDS (ausente DUNE_INSTRUMENT_WITH env)
Habilitar instrumentación por parte de BACKENDS. BACKENDS es una lista separada por comas de nombres de bibliotecas, cada una de las cuales debe declarar un backend de instrumentación.
-j JOBS
Ejecutar como máximo JOBS comandos simultáneamente.
--no-buffer
No almacenar en búfer la salida de los comandos ejecutados por dune. Por predeterminado, dune almacena en búfer la salida de los subcomandos, para evitar la intercalación cuando se ejecutan varios comandos en paralelo. Sin embargo, esto puede ser un problema al depurar pruebas de larga duración. Con --no-buffer, los comandos tienen acceso directo a la terminal. Tenga en cuenta que, como resultado, su salida no se capturará en el archivo de registro. Debe usar esta opción junto con -j 1, para evitar la intercalación. Además, también debe usar --verbose, para asegurarse de que los comandos se impriman antes de que se ejecuten.
--no-config
No cargar el archivo de configuración.
--no-print-directory
Suprimir los mensajes de "Entering directory".
--only-packages=PACKAGES
Ignorar estrofas que se refieren a un paquete que no está en PACKAGES. PACKAGES es una lista separada por comas.

dune-utop(1) — Arch Linux

NAME

dune-utop

SYNOPSIS

dune utop [OPTIONS] [TARGETS]

DESCRIPTION

This command invokes utop, the toplevel to use with Dune.

If no targets are specified, dune will try to find an appropriate toplevel.

When targets are specified, dune will build them and then invoke utop with the appropriate camlfind packages.

This command is an alias for:dune build @install -- ...

And the arguments are passed to utop.

OPTIONS

Dune accepts the following options. They can be given on the command line or in the environment variable DUNE_FLAGS.

--action-abi=VAL
Use the specified action ABI.
--build-only-packages=PACKAGES
When running in release mode, only build the listed packages. This is mostly useful when the workspace contains multiple packages and you only want to build one of them.
--build-std
Build the standard library.
--build-test-results=FILE
Use FILE as the build report. By default, logs are printed to stderr.
--build-timestamps-dir=DIR
Directory for timestamp files. This is meant for the build system internals.
-C DIR
Change directory to DIR before processing arguments. This affects how targets are interpreted.
--check-irrelevant
Check that no rules are defined in irrelevant directories.
--check-macrons
Check that no macrons are used in dune files.
--check-targets
Check that the specified targets exist.
--clear-build-dir
Clear the build directory before building.
--clone-source-tree
Clone the source tree when caching.
--compute-fingerprints
Compute fingerprints for all actions.
--config=FILE
Use FILE as the configuration file.
--create-install-dir
Create the install directory when installing packages.
--debug-dependency-rules
Print the dependency rules for each action.
--debug-findlib
Enable debug logging for findlib.
--debug-log=FILE
Write debug logs to FILE.
--debug-package-logs
Print the logs for package builds.
--debug-package-rules
Print the rules for package builds.
--debug-recursion-stack-depth=N
Set the recursion stack depth for debugging.
--dev-mode
Use the development mode.
--diff-command=CMD
Use CMD to diff files. Use - to disable diffing.
--disable-promotion
Disable all promotion rules.
--display=VAL
Change the way build results are displayed. Supported values: quiet, brief, standard, verbose, spammy.
--dump-ast=DIR
Dump the ASTs to DIR.
--dump-sexps=DIR
Dump the S-expressions to DIR.
--dry-run
Only print the actions that would be performed.
--error-code-diff
When an error occurs, show the diff between the expected and actual files.
--executable-rules
Enable executable rules.
--export-generated-ml-ast
Export generated ML ASTs.
--file-set-cache
Use file set cache.
--file-set-cache-debug
Enable debug logging for file set cache.
--findlib-path=PATHS
Add PATHS to the findlib path.
--force-reachable-reachable-deps
Force reachable reachable dependencies.
--for-release-of-packages=PACKAGES
Shorthand for --release --only-packages PACKAGE. You must use this option in your <package>.opam files, in order to build only what's necessary when your project contains multiple packages as well as getting reproducible builds.
--ignore-promoted-rules
Ignore promoted rules.
--implicit-transitive-deps-backend=VAL
Set the implicit transitive dependencies backend.
--implicit-transitive-deps-backend-debug
Enable debug logging for implicit transitive dependencies backend.
--instrument-with=BACKENDS
Enable instrumentation by BACKENDS. BACKENDS is a comma-separated list of library names.
--jobs=N, -j N
Use N units of concurrency. Defaults to the number of CPUs.
--kind=VAL
Use the specified backend. Supported values: default, panic.
--log-transformer=CMD
Use CMD to transform the logs.
--logs=DIR
Directory for logs.
--no-config
Do not load configuration files.
--no-print-directory
Do not print the directory names when building.
--no-recursion-filtering
Do not filter recursive dependencies.
--no-source-timestamps
Do not use source timestamps.
--no-tracking
Do not track build actions.
--only-packages=PACKAGES
Build only the specified packages. Note that this has the same effect as deleting the relevant stanzas from dune files. It is mostly meant for releases. During development, it is likely that what you want instead is to build a particular <package>.install target.
--profile=VAL (absent DUNE_PROFILE env)
Select the build profile, for instance dev or release. The default is dev.
--promote-install-files[=VAL] (default=true)
Promote any generated <package>.install files to the source tree.
--release
Put dune into a reproducible release mode. Shorthand for --root . --ignore-promoted-rules --no-config --profile release --always-show-command-line --promote-install-files --require-dune-project-file --default-target @install. You should use this option for release builds. For instance, you must use this option in your <package>.opam files. Except if you already use -p, as -p implies this option.
--require-dune-project-file[=VAL] (default=true)
Fail if a dune-project file is missing.
--root=DIR
Use this directory as workspace root instead of guessing it. Note that this option doesn't change the interpretation of targets given on the command line. It is only intended for scripts.
--sandbox=MODE
Run Dune actions in a sandbox. Supported modes: local, system, none.
--store-orig-source-dir (absent DUNE_STORE_ORIG_SOURCE_DIR env)
Store original source location in dune-package metadata.
--terminal-persistence=MODE
Change how the log of build results are displayed to the console between rebuilds while in --watch mode. Supported modes: preserve, clear-on-rebuild, clear-on-rebuild-and-flush-history.
--trace-extended
Output extended trace data (requires trace-file).
--trace-file=FILE
Output trace data in catapult format (compatible with chrome://tracing).
--verbose
Same as --display verbose
--version
Show version information.
--watch
Run Dune in watch mode. Dune will re-run the build whenever a file changes.
--watch-exclusions=REGEX
Adds a POSIX regular expression that will exclude matching directories from `dune build --watch`. The option --watch-exclusions can be repeated to add multiple exclusions. Semicolons can be also used as a separator. If no exclusions are provided, then a standard set of exclusions is used; however, if one or more --watch-exclusions are used, none of the standard exclusions are used. The standard exclusions are: ^_opam /_opam ^_esy /_esy ^\.#.* /\.#.* ~$ ^#[^#]*#$ /#[^#]*#$ ^4913$ /4913$ /.git /.hg :/windows
--workspace=FILE (absent DUNE_WORKSPACE env)
Use this specific workspace file instead of looking it up.
-x VAL
Cross-compile using this toolchain.

MORE HELP

Use dune COMMAND --help for help on a single command.

EXIT STATUS

dune utop exits with:

0
on success.
1
if an error happened.
130
if it was interrupted by a signal.

ENVIRONMENT

These environment variables affect the execution of utop:

DUNE_BUILD_DIR
Specified build directory. _build if unspecified
DUNE_CACHE
Enable or disable Dune cache (one of disabled, enabled-except-user-rules or enabled). Default is `enabled-except-user-rules'.
DUNE_CACHE_CHECK_PROBABILITY
Check build reproducibility by re-executing randomly chosen rules and comparing their results with those stored in Dune cache. Note: by increasing the probability of such checks you slow down the build. The default probability is zero, i.e. no rules are checked.
DUNE_CACHE_STORAGE_MODE
Dune cache storage mode (one of auto, hardlink or copy). Default is `hardlink'.
DUNE_DEBUG_PACKAGE_LOGS
Always print the standard logs when building packages
DUNE_DIFF_COMMAND
Shell command to use to diff files. Use - to disable printing the diff.
DUNE_DISABLE_PROMOTION
Disable all promotion rules
DUNE_INSTRUMENT_WITH
Enable instrumentation by BACKENDS. BACKENDS is a comma-separated list of library names, each one of which must declare an instrumentation backend.
DUNE_PROFILE
Build profile. dev if unspecified or release if -p is set.
DUNE_SANDBOX
Sandboxing mode to use by default. (see --sandbox)
DUNE_STORE_ORIG_SOURCE_DIR
Store original source location in dune-package metadata.
DUNE_WORKSPACE
Use this specific workspace file instead of looking it up.
