DUMP.F2FS(8) Manual del Administrador del Sistema DUMP.F2FS(8)

NOMBRE

dump.f2fs - recuperar entradas de directorio y archivo de una imagen formateada en F2FS

SINOPSIS

dump.f2fs [ -i número de inodo ] [ -I número de inodo ] [ -n rango NAT ] [ -M Mapa de bloques ] [ -s rango SIT ] [ -a rango SSA ] [ -b dirección de bloque ] [ -d nivel de depuración ] dispositivo

DESCRIPCIÓN

dump.f2fs se utiliza para recuperar metadatos de f2fs (generalmente en una partición de disco). dispositivo es el archivo especial correspondiente al dispositivo (por ejemplo, /dev/sdXX).

Actualmente, puede recuperar 1) un archivo dado su número de inodo, 2) entradas NAT a un archivo, 3) entradas SIT a un archivo, 4) entradas SSA a un archivo, 5) información inversa de la dirección de bloque dada.

El código de salida devuelto por dump.f2fs es 0 en caso de éxito y -1 en caso de error.

OPCIONES

-i número de inodo
Especifica un número de inodo para volcar.
-I número de inodo
Especifica un número de inodo y escanea el disco completo para volcar, incluyendo el bloque de inodo de historial.
-n rango NAT
Especifica un rango presentado por nids para volcar entradas NAT.
-M Mapa de bloques
Muestra todas las direcciones de bloque asignadas dado el número de inodo.
-s rango SIT
Especifica un rango presentado por números de segmento para volcar entradas SIT.
-a rango SSA
Especifica un rango presentado por números de segmento para volcar entradas SSA.
-b dirección de bloque
Especifica una dirección de bloque para recuperar su información de metadatos.
-d nivel de depuración
Especifica el nivel de opciones de depuración. El número predeterminado es 0, que muestra mensajes de depuración básicos.
