subrutina dggev3 (character jobvl, character jobvr, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) work, integer lwork,

DGGEV3 calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdo y/o derecho para matrices GE (algoritmo por

bloques)

Propósito

:

!> !> DGGEV3 calcula para un par de matrices reales no simétricas N-por-N (A,B) !> los eigenvalores generalizados, y opcionalmente, los eigenvectores generalizados !> izquierdo y/o derecho. !> !> Un eigenvalor generalizado para un par de matrices (A,B) es un escalar !> lambda o una razón alpha/beta = lambda, tal que A - lambda*B es !> singular. Generalmente se representa como el par (alpha,beta), ya que !> hay una interpretación razonable para beta=0, e incluso para ambos !> siendo cero. !> !> El eigenvector derecho v(j) correspondiente al eigenvalor lambda(j) !> de (A,B) satisface !> !> A * v(j) = lambda(j) * B * v(j). !> !> El eigenvector izquierdo u(j) correspondiente al eigenvalor lambda(j) !> de (A,B) satisface !> !> u(j)

**H * A = lambda(j) * u(j)**H * B . !> !> donde u(j)**H es el conjugado-transpuesto de u(j). !> !>

!>          BETA es un array DOUBLE PRECISION, dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los eigenvalores generalizados.  Si ALPHAI(j) es cero, entonces
!>          el j-ésimo eigenvalor es real; si es positivo, entonces el j-ésimo y
!>          el (j+1)-ésimo eigenvalores son un par complejo conjugado, con
!>          ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente desbordar o subdesbordar, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente la razón
!>          alpha/beta.  Sin embargo, ALPHAR 
y ALPHAI siempre serán menores
!>          y generalmente comparables en magnitud con norm(A), y
!>          BETA siempre menor y generalmente comparable con norm(B).
!>

V
L

!>          VL es un array DOUBLE PRECISION, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los eigenvectores izquierdos u(j) se almacenan uno
!>          tras otro en las columnas de VL, en el mismo orden que
!>          sus eigenvalores. Si el j-ésimo eigenvalor es real, entonces
!>          u(j) = VL(:,j), la j-ésima columna de VL. Si el j-ésimo y
!>          el (j+1)-ésimo eigenvalores forman un par complejo conjugado, entonces
!>          u(j) = VL(:
,j)+i*VL(:,j+1) y u(j+1) = VL(:,j)-i*VL(:,j+1).
!>          Cada eigenvector se escala de modo que el componente más grande tenga
!>          abs(parte real)+abs(parte imaginaria)=1.
!>          No se referencia si JOBVL = 'N'.
!>
