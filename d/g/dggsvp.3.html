DGGSVP

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina DGGSVP3.
!>
!> DGGSVP calcula matrices ortogonales U, V y Q tales que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz A12 de dimensión K-por-K y la matriz B13 de dimensión L-por-L son
!> triangulares superiores no singulares; A23 es triangular superior de dimensión L-por-L si M-K-L >= 0,
!> de lo contrario A23 es trapezoidal superior de dimensión (M-K)-por-L.  K+L = el rango
!> numérico efectivo de la matriz (A**T,B**T)**T de dimensión (M+P)-por-N.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición de Valor Singular Generalizada (GSVD), ver la subrutina
!> DGGSVD.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  se calcula la matriz ortogonal U;
!>          = 'N':  no se calcula U.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V':  se calcula la matriz ortogonal V;
!>          = 'N':  no se calcula V.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q':  se calcula la matriz ortogonal Q;
!>          = 'N':  no se calcula Q.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          A la entrada, la matriz A de dimensión M-por-N.
!>          A la salida, A contiene la matriz triangular (o trapezoidal)
!>          descrita en la sección Propósito.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,N)
!>          A la entrada, la matriz B de dimensión P-por-N.
!>          A la salida, B contiene la matriz triangular descrita en
!>          la sección Propósito.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es DOUBLE PRECISION
!>

TOLB

!>          TOLB es DOUBLE PRECISION
!>
!>          TOLA y TOLB son los umbrales para determinar el rango
!>          numérico efectivo de la matriz B y de un subbloque de A. Generalmente,
!>          se establecen en
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El valor de TOLA y TOLB puede afectar al tamaño de los errores
!>          hacia atrás de la descomposición.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          A la salida, K y L especifican la dimensión de los subbloques
!>          descritos en la sección Propósito.
!>          K + L = rango numérico efectivo de (A**T,B**T)**T.
!>

U

!>          U es un array DOUBLE PRECISION, dimensión (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz ortogonal U.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!>

V

!>          V es un array DOUBLE PRECISION, dimensión (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz ortogonal V.
!>          Si JOBV = 'N', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!>

Q

!>          Q es un array DOUBLE PRECISION, dimensión (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz ortogonal Q.
!>          Si JOBQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N)
!>

TAU

!>          TAU es un array DOUBLE PRECISION, dimensión (N)
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (max(3*N,M,P))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles adicionales:

La subrutina utiliza la subrutina de LAPACK DGEQPF para la factorización QR con pivoteo de columnas para detectar el rango numérico efectivo de la matriz A. Puede ser reemplazada por una mejor estrategia de determinación de rango.
