Documentación de la Función/Subrutina

subroutine dgeequ (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

DGEEQU

Propósito:

!>
!> DGEEQU calcula los factores de escala de filas y columnas destinados a
!> equilibrar una matriz A de M por N y reducir su número de condición.
!> R devuelve los factores de escala de fila y C los factores de escala
!> de columna, elegidos para intentar que el elemento más grande de cada
!> fila y columna de la matriz B con elementos B(i,j)=R(i)*A(i,j)*C(j)
!> tenga un valor absoluto de 1.
!>
!> R(i) y C(j) están restringidos a estar entre SMLNUM = el número seguro
!> más pequeño y BIGNUM = el número seguro más grande. El uso de estos
!> factores de escala no garantiza la reducción del número de condición
!> de A, pero funciona bien en la práctica.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>          La matriz de M por N cuyos factores de 
!>          equilibrado deben ser calculados.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

R

!>          R es un array de DOUBLE PRECISION, dimensión (M)
!>          Si INFO = 0 o INFO > M, R contiene los factores de escala
!>          de fila para A.
!>

C

!>          C es un array de DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, C contiene los factores de escala de columna
!>          para A.
!>

ROWCND

!>          ROWCND es DOUBLE PRECISION
!>          Si INFO = 0 o INFO > M, ROWCND contiene la relación del
!>          R(i) más pequeño con el R(i) más grande.  Si ROWCND >= 0.1 y
!>          AMAX no es ni demasiado grande ni demasiado pequeño, no
!>          merece la pena escalar con R.
!>

COLCND

!>          COLCND es DOUBLE PRECISION
!>          Si INFO = 0, COLCND contiene la relación del C(i) más
!>          pequeño con el C(i) más grande.  Si COLCND >= 0.1, no
!>          merece la pena escalar con C.
!>

AMAX

!>          AMAX es DOUBLE PRECISION
!>          Valor absoluto del elemento de matriz más grande. Si AMAX
!>          está muy cerca del desbordamiento o muy cerca del
!>          subdesbordamiento, la matriz debería ser escalada.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= M:  la i-ésima fila de A es exactamente cero
!>                >  M:  la (i-M)-ésima columna de A es exactamente cero
!>
