Documentación de Función/Subrutina

subrutina dgesvdq (character joba, character jobp, character jobr, character jobu, character jobv, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldv, * ) v, integer ldv, integer numrank, integer, dimension( * ) iwork, integer liwork, double precision, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer info)

DGESVDQ calcula la descomposición en valores singulares (SVD) con un Método de SVD QR Precondicionado con QR para matrices GE

Propósito:

!>
!> DGESVDQ calcula la descomposición en valores singulares (SVD) de una matriz real A
!> de M por N, donde M >= N. La SVD de A se escribe como
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> donde SIGMA es una matriz diagonal de N por N, U es una matriz
!> ortonormal de M por N, y V es una matriz ortogonal de N por N. Los
!> elementos diagonales de SIGMA son los valores singulares de A. Las
!> columnas de U y V son los vectores singulares izquierdo y derecho de A,
!> respectivamente.
!>

Parámetros

JOBA 
!>  JOBA es CHARACTER*1
!>  Especifica el nivel de precisión en la SVD calculada
!>  = 'A' La precisión solicitada corresponde a tener el error hacia atrás
!>        acotado por || delta A ||_F <= f(m,n) * EPS * || A ||_F,
!>        donde EPS = DLAMCH('Epsilon'). Esto autoriza a DGESVDQ a
!>        truncar el factor triangular calculado en una factorización QR
!>        reveladora de rango siempre que la parte truncada esté por
!>        debajo del umbral del orden de EPS * ||A||_F. Este es el nivel
!>        de truncamiento agresivo.
!>  = 'M' De manera similar a 'A', pero el truncamiento es más suave: se
!>        permite solo cuando hay una caída en la diagonal del
!>        factor triangular en la factorización QR. Este es el nivel de
!>        truncamiento medio.
!>  = 'H' Se solicita alta precisión. No se intenta la determinación del
!>        rango numérico basada en la factorización QR reveladora de rango.
!>  = 'E' Igual que 'H', y además se estima el número de condición de A
!>        escalado por columnas y se devuelve en RWORK(1).
!>        N^(-1/4)*RWORK(1) <= ||pinv(A_scaled)||_2 <= N^(1/4)*RWORK(1)
!>

JOBP

!>  JOBP es CHARACTER*1
!>  = 'P' Las filas de A se ordenan en orden decreciente con respecto a
!>        ||A(i,:)||_\infty. Esto mejora la precisión numérica a costa
!>        de un movimiento de datos adicional. Recomendado para robustez numérica.
!>  = 'N' Sin pivoteo de filas.
!>

JOBR

!>          JOBR es CHARACTER*1
!>          = 'T' Después de la factorización QR inicial con pivoteo, se aplica DGESVD a
!>          la transpuesta R**T del factor triangular R calculado. Esto implica
!>          algo de movimiento de datos adicional (transposiciones de matrices). Útil para
!>          experimentos, investigación y desarrollo.
!>          = 'N' El factor triangular R se da como entrada a DGESVD. Esto puede ser
!>          preferible ya que implica menos movimiento de datos.
!>

JOBU

!>          JOBU es CHARACTER*1
!>          = 'A' Se calculan los M vectores singulares izquierdos y se devuelven en la
!>          matriz U. Ver la descripción de U.
!>          = 'S' o 'U' Se calculan N = min(M,N) vectores singulares izquierdos y se devuelven
!>          en la matriz U. Ver la descripción de U.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan NUMRANK vectores
!>          singulares izquierdos y se devuelven en la matriz U.
!>          = 'F' Los N vectores singulares izquierdos se devuelven en forma factorizada como el
!>          producto del factor Q de la factorización QR inicial y los
!>          N vectores singulares izquierdos de (R**T , 0)**T. Si se usa pivoteo de filas,
!>          entonces la información necesaria sobre el pivoteo de filas se almacena en
!>          IWORK(N+1:N+M-1).
!>          = 'N' No se calculan los vectores singulares izquierdos.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'A', 'V' Se calculan los N vectores singulares derechos y se devuelven en
!>          la matriz V.
!>          = 'R' Se determina el rango numérico NUMRANK y solo se calculan NUMRANK vectores
!>          singulares derechos y se devuelven en la matriz V. Esta opción es
!>          permitida solo si JOBU = 'R' o JOBU = 'N'; de lo contrario, es ilegal.
!>          = 'N' No se calculan los vectores singulares derechos.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  M >= N >= 0.
!>

A

!>          A es un arreglo DOUBLE PRECISION de dimensiones LDA x N
!>          En la entrada, la matriz de entrada A.
!>          En la salida, si JOBU .NE. 'N' o JOBV .NE. 'N', el triángulo inferior de A contiene
!>          los vectores de Householder como los almacena DGEQP3. Si JOBU = 'F', estos vectores de
!>          Householder junto con WORK(1:N) pueden usarse para restaurar los factores Q de
!>          la factorización QR inicial con pivoteo de A. Ver la descripción de U.
!>

LDA

!>          LDA es INTEGER.
!>          La dimensión principal del arreglo A.  LDA >= max(1,M).
!>

S

!>          S es un arreglo DOUBLE PRECISION de dimensión N.
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!>

U

!>          U es un arreglo DOUBLE PRECISION, dimensión
!>          LDU x M si JOBU = 'A'; ver la descripción de LDU. En este caso,
!>          en la salida, U contiene los M vectores singulares izquierdos.
!>          LDU x N si JOBU = 'S', 'U', 'R' ; ver la descripción de LDU. En este
!>          caso, U contiene los primeros N o los primeros NUMRANK vectores singulares izquierdos.
!>          LDU x N si JOBU = 'F' ; ver la descripción de LDU. En este caso U
!>          contiene una matriz ortogonal N x N que puede usarse para formar los vectores
!>          singulares izquierdos.
!>          Si JOBU = 'N', U no se referencia.
!>

LDU

!>          LDU es INTEGER.
!>          La dimensión principal del arreglo U.
!>          Si JOBU = 'A', 'S', 'U', 'R',  LDU >= max(1,M).
!>          Si JOBU = 'F',                 LDU >= max(1,N).
!>          De lo contrario,               LDU >= 1.
!>

V

!>          V es un arreglo DOUBLE PRECISION, dimensión
!>          LDV x N si JOBV = 'A', 'V', 'R' o si JOBA = 'E' .
!>          Si JOBV = 'A', o 'V',  V contiene la matriz ortogonal N por N  V**T;
!>          Si JOBV = 'R', V contiene las primeras NUMRANK filas de V**T (los vectores
!>          singulares derechos, almacenados por filas, de los NUMRANK valores singulares más grandes).
!>          Si JOBV = 'N' y JOBA = 'E', V se usa como espacio de trabajo.
!>          Si JOBV = 'N', y JOBA.NE.'E', V no se referencia.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del arreglo V.
!>          Si JOBV = 'A', 'V', 'R',  o JOBA = 'E', LDV >= max(1,N).
!>          De lo contrario,                         LDV >= 1.







NAME


dgesvdq — computes the singular value decomposition (SVD) of a
    real M-by-N matrix A, optionally followed by the application of
    orthogonal transformations to a				      M-by-P (left) or N-by-P (right)
    matrix.






SYNOPSIS


    SUBROUTINE DGESVDQ( JOBU, JOBV, JOBQ, JOBP, M, N, A, LDA, S, U, LDU, V,
                        LDV, Q, LDQ, WORK, LWORK, IWORK, LIWORK, RWORK, LRWORK,
                        INFO )



This subroutine calls routines from the following LAPACK routines:


    LAPACK: DGEQPF, DGESVD, DLARFP, DLARF, DLACPY, DLAMCH, DGEQRT, DGEQRT2,
            DGEQRTF, DGEQRTX, DGEQRTXX, DGEQRTS, DGEQRTSS, DGEQRTSX,
            DLAPY2, DLANRB, DTRSM, DLASDT, DSTEQR, DSTERF, DLASQP, DLANGE,
            DLASSQ, DLASCL, DGEJSV, DGEQRV, DGEQRF, DGELS, DGELQF, DGEQP3
    BLAS:   DGEMM, DGER, DNRM2, DASUM, DROT, DROTMG, DROTM, DAXPY, DSCAL,
            DCOPY, DSWAP, IZAMAX







Function/Subroutine Documentation


JOBU


!>          JOBU is CHARACTER*1
!>          Specifies whether to compute the left singular vectors (U).
!>          JOBU = 'A': All M rows of U are returned in arrays U and Q.
!>          JOBU = 'S': The first min(M,N) rows of U are returned in the array Q.
!>          JOBU = 'U': The first min(M,N) rows of U are returned in arrays U and Q.
!>          JOBU = 'R': The first min(M,N) rows of U are returned in arrays U and Q.
!>          JOBU = 'N': No singular vectors are computed.
!> 


JOBV


!>          JOBV is CHARACTER*1
!>          Specifies whether to compute the right singular vectors (V).
!>          JOBV = 'A': All N rows of V are returned in arrays V and Q.
!>          JOBV = 'S': The first min(M,N) rows of V are returned in the array Q.
!>          JOBV = 'U': The first min(M,N) rows of V are returned in arrays V and Q.
!>          JOBV = 'R': The first min(M,N) rows of V are returned in arrays V and Q.
!>          JOBV = 'N': No singular vectors are computed.
!> 


JOBQ


!>          JOBQ is CHARACTER*1
!>          Specifies whether to compute the transformation matrix Q.
!>          JOBQ = 'N': Q is not computed.
!>          JOBQ = 'Q': Q is computed.
!> 


JOBP


!>          JOBP is CHARACTER*1
!>          Specifies whether to compute the column pivoting permutation.
!>          JOBP = 'N': No column pivoting is performed.
!>          JOBP = 'P': Column pivoting is performed.
!> 


M


!>          M is INTEGER
!>          The number of rows of A. M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of A. N >= 0.
!> 


A


!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, A is overwritten by the computed singular values,
!>          left singular vectors, and right singular vectors.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!> 


S


!>          S is DOUBLE PRECISION array, dimension (max(1,min(M,N)))
!>          On exit, S contains the singular values, sorted in non-increasing order.
!>          The singular values are scaled such that 1.0 <= S(i) <= 2.0.
!> 


U


!>          U is DOUBLE PRECISION array, dimension (LDU, M)
!>          On exit, U contains the left singular vectors if JOBU = 'A'.
!>          U contains the first min(M,N) rows of the left singular vectors if
!>          JOBU = 'U', 'S', or 'R'.
!> 


LDU


!>          LDU is INTEGER
!>          The leading dimension of the array U.
!>          If JOBU = 'A', LDU >= M.
!>          If JOBU = 'U', 'S', or 'R', LDU >= min(M,N).
!> 


V


!>          V is DOUBLE PRECISION array, dimension (LDV, N)
!>          On exit, V contains the right singular vectors if JOBV = 'A'.
!>          V contains the first min(M,N) rows of the right singular vectors if
!>          JOBV = 'U', 'S', or 'R'.
!> 


LDV


!>          LDV is INTEGER
!>          The leading dimension of the array V.
!>          If JOBV = 'A', LDV >= N.
!>          If JOBV = 'U', 'S', or 'R', LDV >= min(M,N).
!> 


Q


!>          Q is DOUBLE PRECISION array, dimension (LDQ, P) where P is M if
!>          JOBU = 'A', and P is min(M,N) if JOBU = 'U', 'S', or 'R'.
!>          On exit, Q contains the orthogonal matrix Q, which is used to
!>          transform A.
!> 


LDQ


!>          LDQ is INTEGER
!>          The leading dimension of the array Q.
!>          If JOBQ = 'Q', LDQ >= max(1, M) if JOBU = 'A' or 'U'
!>                           LDQ >= max(1, min(M,N)) if JOBU = 'S' or 'R'
!> 


NUMRANK


!>          NUMRANK is INTEGER
!>          NUMRANK is the numerical rank first determined after the rank
!>          revealing QR factorization, following the strategy specified by the
!>          value of JOBA. If JOBV = 'R' and JOBU = 'R', only NUMRANK
!>          leading singular values and vectors are then requested in the call
!>          of DGESVD. The final value of NUMRANK might be further reduced if
!>          some singular values are computed as zeros.
!> 


IWORK


!>          IWORK is INTEGER array, dimension (max(1, LIWORK)).
!>          On exit, IWORK(1:N) contains column pivoting permutation of the
!>          rank revealing QR factorization.
!>          If JOBP = 'P', IWORK(N+1:N+M-1) contains the indices of the sequence
!>          of row swaps used in row pivoting. These can be used to restore the
!>          left singular vectors in the case JOBU = 'F'.
!>
!>          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>          IWORK(1) returns the minimal LIWORK.
!> 


LIWORK


!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.
!>          LIWORK >= N + M - 1,     if JOBP = 'P' and JOBA .NE. 'E';
!>          LIWORK >= N              if JOBP = 'N' and JOBA .NE. 'E';
!>          LIWORK >= N + M - 1 + N, if JOBP = 'P' and JOBA = 'E';
!>          LIWORK >= N + N          if JOBP = 'N' and JOBA = 'E'.
!>
!>          If LIWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the WORK, IWORK, and RWORK arrays, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


WORK


!>          WORK is DOUBLE PRECISION array, dimension (max(2, LWORK)), used as a workspace.
!>          On exit, if, on entry, LWORK.NE.-1, WORK(1:N) contains parameters
!>          needed to recover the Q factor from the QR factorization computed by
!>          DGEQP3.
!>
!>          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>          WORK(1) returns the optimal LWORK, and
!>          WORK(2) returns the minimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK. It is determined as follows:
!>          Let  LWQP3 = 3*N+1,  LWCON = 3*N, and let
!>          LWORQ = { MAX( N, 1 ),  if JOBU = 'R', 'S', or 'U'
!>                  { MAX( M, 1 ),  if JOBU = 'A'
!>          LWSVD = MAX( 5*N, 1 )
!>          LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 5*(N/2), 1 ), LWORLQ = MAX( N, 1 ),
!>          LWQRF = MAX( N/2, 1 ), LWORQ2 = MAX( N, 1 )
!>          Then the minimal value of LWORK is:
!>          = MAX( N + LWQP3, LWSVD )        if only the singular values are needed;
!>          = MAX( N + LWQP3, LWCON, LWSVD ) if only the singular values are needed,
!>                                   and a scaled condition estimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD, LWORQ ) if the singular values and the left
!>                                   singular vectors are requested;
!>          = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the singular values and the left
!>                                   singular vectors are requested, and also
!>                                   a scaled condition estimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD )        if the singular values and the right
!>                                   singular vectors are requested;
!>          = N + MAX( LWQP3, LWCON, LWSVD ) if the singular values and the right
!>                                   singular vectors are requested, and also
!>                                   a scaled condition etimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD, LWORQ ) if the full SVD is requested with JOBV = 'R';
!>                                   independent of JOBR;
!>          = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the full SVD is requested,
!>                                   JOBV = 'R' and, also a scaled condition
!>                                   estimate requested; independent of JOBR;
!>          = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ) ) if the
!>                         full SVD is requested with JOBV = 'A' or 'V', and
!>                         JOBR ='N'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ ) )
!>                         if the full SVD is requested with JOBV = 'A' or 'V', and
!>                         JOBR ='N', and also a scaled condition number estimate
!>                         requested.
!>          = MAX( N + MAX( LWQP3, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) ) if the
!>                         full SVD is requested with JOBV = 'A', 'V', and JOBR ='T'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) )
!>                         if the full SVD is requested with JOBV = 'A' or 'V', and
!>                         JOBR ='T', and also a scaled condition number estimate
!>                         requested.
!>          Finally, LWORK must be at least two: LWORK = MAX( 2, LWORK ).
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the WORK, IWORK, and RWORK arrays, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


RWORK


!>          RWORK is DOUBLE PRECISION array, dimension (max(1, LRWORK)).
!>          On exit,
!>          1. If JOBA = 'E', RWORK(1) contains an estimate of the condition
!>          number of column scaled A. If A = C * D where D is diagonal and C
!>          has unit columns in the Euclidean norm, then, assuming full column rank,
!>          N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1).
!>          Otherwise, RWORK(1) = -1.
!>          2. RWORK(2) contains the number of singular values computed as
!>          exact zeros in DGESVD applied to the upper triangular or trapezoidal
!>          R (from the initial QR factorization). In case of early exit (no call to
!>          DGESVD, such as in the case of zero matrix) RWORK(2) = -1.
!>
!>          If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>          RWORK(1) returns the minimal LRWORK.
!> 


LRWORK


!>          LRWORK is INTEGER.
!>          The dimension of the array RWORK.
!>          If JOBP ='P', then LRWORK >= MAX(2, M).
!>          Otherwise, LRWORK >= 2
!>
!>          If LRWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the WORK, IWORK, and RWORK arrays, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if DBDSQR did not converge, INFO specifies how many superdiagonals
!>          of an intermediate bidiagonal form B (computed in DGESVD) did not
!>          converge to zero.
!>

Further Details:

!>
!>   1. The data movement (matrix transpose) is coded using simple nested
!>   DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
!>   Those DO-loops are easily identified in this source code - by the CONTINUE
!>   statements labeled with 11**. In an optimized version of this code, the
!>   nested DO loops should be replaced with calls to an optimized subroutine.
!>   2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
!>   column norm overflow. This is the minial precaution and it is left to the
!>   SVD routine (CGESVD) to do its own preemptive scaling if potential over-
!>   or underflows are detected. To avoid repeated scanning of the array A,
!>   an optimal implementation would do all necessary scaling before calling
!>   CGESVD and the scaling in CGESVD can be switched off.
!>   3. Other comments related to code optimization are given in comments in the
!>   code, enclosed in [[double brackets]].
!>
