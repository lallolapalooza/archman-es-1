subrutina dget39 (doble precisión rmax, entero lmax, entero ninfo, entero knt)

DGET39

Propósito:

!>
!> DGET39 prueba DLAQTR, una rutina para resolver el sistema cuasi
!> triangular superior real o complejo especial
!>
!>      op(T)*p = scale*c,
!> o
!>      op(T + iB)*(p+iq) = scale*(c+id),
!>
!> en aritmética real. T es cuasi-triangular superior.
!> Si es complejo, entonces el primer bloque diagonal de T debe ser
!> de 1x1, B tiene la estructura especial
!>
!>                B = [ b(1) b(2) ... b(n) ]
!>                    [       w            ]
!>                    [           w        ]
!>                    [              .     ]
!>                    [                 w  ]
!>
!> op(A) = A o A', donde A' denota la transpuesta conjugada de
!> la matriz A.
!>
!> En la entrada, X = [ c ]. En la salida, X = [ p ].
!>                  [ d ]                  [ q ]
!>
!> Scale es una salida menor o igual a 1, elegida para evitar
!> desbordamiento en X.
!> Esta subrutina está especialmente diseñada para la estimación
!> del número de condición en la rutina de problemas de valores propios DTRSNA.
!>
!> El código de prueba verifica que el siguiente residuo es del orden de 1:
!>
!>      ||(T+i*B)*(x1+i*x2) - scale*(d1+i*d2)||
!>    -----------------------------------------
!>        max(ulp*(||T||+||B||)*(||x1||+||x2||),
!>            (||T||+||B||)*smlnum/ulp,
!>            smlnum)
!>
!> (El término (||T||+||B||)*smlnum/ulp tiene en cuenta un posible
!>  desbordamiento gradual o no gradual en x1 y x2.)
!>

Parámetros

RMAX 
!>          RMAX es DOBLE PRECISIÓN
!>          Valor de la razón de prueba más grande.
!>

LMAX

!>          LMAX es ENTERO
!>          Número de ejemplo donde se alcanza la razón de prueba más grande.
!>

NINFO

!>          NINFO es ENTERO
!>          Número de ejemplos donde INFO es distinto de cero.
!>

KNT

!>          KNT es ENTERO
!>          Número total de ejemplos probados.
!>
