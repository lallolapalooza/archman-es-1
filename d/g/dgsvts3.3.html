DGSVTS3

Propósito:

!>
!> DGSVTS3 prueba DGGSVD3, que calcula el GSVD de una matriz A de M por N
!> y una matriz B de P por N:
!>              U'*A*Q = D1*R y V'*B*Q = D2*R.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,M)
!>          La matriz A de M por N.
!>

AF

!>          AF es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          Detalles del GSVD de A y B, tal como lo devuelve DGGSVD3,
!>          ver DGGSVD3 para más detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A y AF.
!>          LDA >= max( 1,M ).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,P)
!>          Al entrar, la matriz B de P por N.
!>

BF

!>          BF es un array DOUBLE PRECISION, dimensión (LDB,N)
!>          Detalles del GSVD de A y B, tal como lo devuelve DGGSVD3,
!>          ver DGGSVD3 para más detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de los arrays B y BF.
!>          LDB >= max(1,P).
!>

U

!>          U es un array DOUBLE PRECISION, dimensión(LDU,M)
!>          La matriz ortogonal U de M por M.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M).
!>

V

!>          V es un array DOUBLE PRECISION, dimensión(LDV,M)
!>          La matriz ortogonal V de P por P.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P).
!>

Q

!>          Q es un array DOUBLE PRECISION, dimensión(LDQ,N)
!>          La matriz ortogonal Q de N por N.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N).
!>

ALPHA

!>          ALPHA es un array DOUBLE PRECISION, dimensión (N)
!>

BETA

!>          BETA es un array DOUBLE PRECISION, dimensión (N)
!>
!>          Los pares de valores singulares generalizados de A y B, las
!>          matrices ``diagonales'' D1 y D2 se construyen a partir de
!>          ALPHA y BETA, ver la subrutina DGGSVD3 para detalles.
!>

R

!>          R es un array DOUBLE PRECISION, dimensión(LDQ,N)
!>          La matriz triangular superior R.
!>

LDR

!>          LDR es INTEGER
!>          La dimensión principal del array R. LDR >= max(1,N).
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N)
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK,
!>          LWORK >= max(M,P,N)*max(M,P,N).
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (max(M,P,N))
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (6)
!>          Las razones de prueba:
!>          RESULT(1) = norm( U'*A*Q - D1*R ) / ( MAX(M,N)*norm(A)*ULP)
!>          RESULT(2) = norm( V'*B*Q - D2*R ) / ( MAX(P,N)*norm(B)*ULP)
!>          RESULT(3) = norm( I - U'*U ) / ( M*ULP )
!>          RESULT(4) = norm( I - V'*V ) / ( P*ULP )
!>          RESULT(5) = norm( I - Q'*Q ) / ( N*ULP )
!>          RESULT(6) = 0        si ALPHA está en orden decreciente;
!>                    = ULPINV   en caso contrario.
!>
